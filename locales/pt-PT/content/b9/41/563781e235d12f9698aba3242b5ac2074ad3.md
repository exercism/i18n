# Testes

## Executar os testes

Quando estiveres no diretório de um exercício, deves ver dois subdiretórios:

* `src` contém a tua solução para o exercício
* `spec` contém os testes que deves executar para o exercício

Se estiveres no diretório certo (ou seja, aquele que contém `src` e `spec`), podes executar os testes desse exercício com o comando `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Isto vai executar todos os ficheiros de teste no diretório `spec`.

Em cada ficheiro de teste, todos os testes exceto o primeiro foram ignorados.

Assim que tiveres um teste a passar, podes deixar de ignorar o próximo se alterares `pending` para `it`.

## Formatação do Crystal

Antes de submeteres, recomenda-se que executes `crystal tool format` na tua solução.

Podes formatar tudo no teu diretório atual com:

```bash
$ crystal tool format ./
```

Ou podes formatar ficheiros seletivamente com:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## Submeter a tua solução

Certifica-te de que submetes o ficheiro de código-fonte no diretório `src` quando submeteres a tua solução:

```bash
$ exercism submit src/<exercise>.cr
```
