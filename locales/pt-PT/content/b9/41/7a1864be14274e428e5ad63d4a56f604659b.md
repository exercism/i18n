# Introdução

O Common Lisp usa os operadores aritméticos habituais para a maioria das operações, mas é algo invulgar por usar uma "notação prefixa" em vez da mais familiar "notação infixa".

De forma mais visual:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Embora a notação prefixa transforme algumas operações como `2 + 2` na forma um pouco menos familiar `(+ 2 2)`, torna muito mais fácil operar com vários números ao mesmo tempo.

## Matemática básica

O Common Lisp tem todas as funções típicas: `+`, `-`, `*`, `/` para adição, subtração, multiplicação e divisão.

Quando consideras a divisão, podes querer saber o resto de uma divisão. Isso é feito pela função `mod` (de módulo), que recebe um número e um divisor como argumentos:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## Comparar números

Por fim, podes achar útil comparar números diferentes com funções como `=` (igual), `/=` (não igual a) e `>=` (maior ou igual a).
Quando estas comparações são verdadeiras (como em `(= 1 1)`), devolvem `T` e, quando não são (como em `(> 0 1)`), devolvem `NIL`.
