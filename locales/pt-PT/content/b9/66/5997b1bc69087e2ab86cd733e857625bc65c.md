# Testes

## Configuração

Segue as [instruções de instalação do WebAssembly][docs-exercism-wasm] para instalar as dependências necessárias.

## Requisitos

Instala as dependências do exercício:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## Fazer passar os testes

Todos os exercícios incluem um conjunto de testes para te ajudar a validar a tua solução antes de a submeteres.
Para executar estes testes, abre uma linha de comandos no diretório do exercício e executa:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

Em alguns conjuntos de testes, todos os testes excepto o primeiro foram ignorados.

Assim que conseguires fazer passar um teste, podes ativar o seguinte alterando `xtest` para `test`.

## Escrever testes personalizados

Se quiseres escrever testes adicionais e personalizados, cria um novo ficheiro `custom.spec.js` e submete-o juntamente com a tua solução e com o novo ficheiro:

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
