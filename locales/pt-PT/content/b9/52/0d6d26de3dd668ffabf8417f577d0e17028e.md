## Geral

Não implementes a struct `SimpleLinkedList` como um invólucro em torno de um `Vec`. Em vez disso, aloca os nós na heap.

Isto pode ser implementado assim:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

O campo `head` aponta para o primeiro elemento (Node) desta lista ligada.

Esta implementação exige também uma struct `Node` com os seguintes campos:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data` contém os dados armazenados, e `next` aponta para o nó seguinte (se existir) ou para None.

## Porquê `Option<Box<Node<T>>>` e não apenas `Option<Node<T>>`?

Tenta tu. Vais receber o seguinte erro.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

O problema é que, em tempo de compilação, é preciso saber o tamanho de `next`. Como `next` é recursivo ("um nó tem um nó que tem um nó..."), o compilador não sabe quanta memória há de ser alocada. Por outro lado, [Box](https://doc.rust-lang.org/std/boxed/) é um ponteiro para a heap com um tamanho definido.
