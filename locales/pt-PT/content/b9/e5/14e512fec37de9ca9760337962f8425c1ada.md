Mas as coisas estão um pouco desorganizadas: as coordenadas da Azara parecem estar formatadas e ordenadas de forma diferente das do Rui, e eles têm de andar sempre a olhar de uma lista para a outra para perceber que tesouros correspondem a que locais.
Como são aspirantes a pythonistas, vieram pedir-te ajuda para escrever um pequeno programa (na verdade, um conjunto de funções) para organizar melhor a informação da sua caça ao tesouro.


## 1. Extrair coordenadas

Implementa a função `get_coordinate()` que recebe um par `(treasure, coordinate)` da lista da Azara e devolve apenas a coordenada do mapa extraída.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. Formatar coordenadas

Implementa a função `convert_coordinate()` que recebe uma coordenada no formato "2A" e devolve um tuplo no formato `("2", "A")`.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. Comparar coordenadas

Implementa a função `compare_records()` que recebe um par `(treasure, coordinate)` e um registo `(location, coordinate, quadrant)` e compara as coordenadas de cada um.
Devolve **`True`** se as coordenadas "corresponderem" e devolve **`False`** se não corresponderem.
Reformata as coordenadas conforme for necessário para uma comparação correta.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. Combinar registos correspondentes

Implementa a função `create_record()` que recebe um par `(treasure, coordinate)` da lista da Azara e um registo `(location, coordinate, quadrant)` da lista do Rui e devolve `(treasure, coordinate, location, coordinate, quadrant)` **se as coordenadas corresponderem**.
Se as coordenadas _não_ corresponderem, devolve a string **"not a match"**.
Reformata a coordenada conforme for necessário para uma comparação correta.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
