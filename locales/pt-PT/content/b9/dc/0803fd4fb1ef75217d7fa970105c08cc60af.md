# Acerca de

Um valor Boolean representa se uma condição é `true` ou `false`.
Em Go, o tipo `bool` só pode assumir um destes dois valores.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## Operadores lógicos

Os operadores lógicos atuam sobre um ou dois valores Boolean e produzem um resultado Boolean.

| Operador | Nome | Comportamento                                       |
| -------- | ---- | --------------------------------------------------- |
| `!`      | NOT  | Devolve o oposto de um único valor Boolean          |
| `&&`     | AND  | Devolve `true` apenas quando ambos os lados são `true` |
| `\|\|`   | OR   | Devolve `true` se algum dos lados for `true`        |

Usa o `!` (NOT) quando precisas do oposto de um valor Boolean:

```go
!isDoorLocked // false
```

Usa o `&&` (AND) quando ambas as condições têm de ser `true`:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

Usa o `||` (OR) quando pelo menos uma das condições tem de ser `true`:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

Os operadores lógicos são avaliados por esta ordem: primeiro o `!`, depois o `&&` e por fim o `||`.
Usa parênteses para agrupar o código e controlar que operações acontecem primeiro:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
