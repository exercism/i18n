# Strings

`STR` guarda texto. Uma string escreve-se entre aspas duplas.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

Uma `STR` nunca muda depois de existir. Tudo o que se segue responde com uma *nova* string, em vez de alterar aquela sobre a qual se perguntou.

## Juntar

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

O `+` também junta um número a uma string, e é assim que um número entra numa frase:

```sather
"Opus " + 27           -- "Opus 27"
```

## Comprimento

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

O `.size` conta carateres, e a resposta é um `INT`.

## Partes

| Chamada | Resposta |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

Pedir mais do que existe devolve o que existe, em vez de falhar.

## Comparar

O `=` pergunta se duas strings são o mesmo texto, e o `/=` se diferem.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

As maiúsculas e minúsculas fazem diferença. O `.upper` e o `.lower` dão uma cópia toda em maiúsculas ou toda em minúsculas, que é a forma habitual de comparar sem nos preocuparmos com isso:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## Uma nota sobre o tamanho

Uma `STR` é uma sequência de bytes, e o `.size` conta bytes. No caso de texto em inglês, é o mesmo que contar letras. Num texto com acentos ou com outros alfabetos, já não é, porque essas letras ocupam mais do que um byte cada.
