# especificação incorreta

[comment]: # (Este aviso é apresentado quando a solução tem uma especificação de tipos diferente da do exemplo)

Certifica-te de que a especificação de tipos de `two_fer/1` está correta. A função aceita um argumento, uma string, e devolve um argumento, também uma string.

O tipo certo para strings é [`String.t()`](https://hexdocs.pm/elixir/String.html#t:t/0).

> Os tipos `String.t()` e `binary()` são equivalentes para as ferramentas de análise. No entanto, para quem lê a documentação, `String.t()` dá a entender que se trata de um binário codificado em UTF-8.

O [tipo `string()`](https://hexdocs.pm/elixir/typespecs.html#the-string-type) significa uma charlist, não uma string do Elixir.

> O Elixir desaconselha o uso do tipo `string()`. O tipo `string()` refere-se às strings do Erlang, que no Elixir são conhecidas como "charlists". Não se referem às strings do Elixir, que são binários codificados em UTF-8.
