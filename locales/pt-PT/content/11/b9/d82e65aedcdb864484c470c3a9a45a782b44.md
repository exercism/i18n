# Instruções

O Andrew, um programador da sua empresa, construiu recentemente um utilitário leve de geração de consultas SQL para uma ferramenta de migração de base de dados.
A sua primeira implementação, ingénua, funcionou perfeitamente para pequenos conjuntos de dados.
No entanto, durante migrações grandes em produção, a aplicação começou a consumir memória em excesso e a ter dificuldades sob carga elevada.
Depois de analisar o desempenho da aplicação, o Andrew percebeu que a concatenação normal de strings dentro de ciclos obrigava o Go a realocar memória constantemente.
Agora, precisa da tua ajuda para refatorar o utilitário com o `strings.Builder` do Go, para garantir que a aplicação escala bem e aguenta grandes volumes de texto sem esmagar a memória.

## 1. Gerar consultas SELECT

Implementa a função `BuildSelectQuery`.
Recebe um nome de tabela (`string`) e um slice de nomes de colunas (`[]string`).
Deve devolver uma instrução SQL `SELECT` completamente formada e terminada com ponto e vírgula.
Se o slice de colunas estiver vazio ou for `nil`, a consulta deve recorrer ao asterisco `*` para selecionar todas as colunas.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Gerar instruções INSERT em lote

Implementa a função `BuildBatchInserts`.
Recebe um nome de tabela (`string`) e um slice bidimensional que representa linhas da base de dados (`[][]ColumnValue`).
Cada elemento de uma linha associa um nome de coluna específico ao respetivo valor em string.
A função deve devolver um slice de strings SQL `INSERT` individuais.
O formato estruturado do slice garante uma ordem de saída das consultas previsível e estável.
Se o slice de linhas de entrada estiver vazio, devolve um slice de strings vazio.
Se alguma linha individual estiver vazia, ignora-a.
Os valores em string dentro da cláusula `VALUES` devem ser envolvidos em aspas simples `'`.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
