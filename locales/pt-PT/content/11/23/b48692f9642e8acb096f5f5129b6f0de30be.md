# Dicas

## Geral

- Uma `struct` é uma sequência de elementos nomeados, chamados campos, cada um com um nome e um tipo.

## 1. Cria um carro telecomandado

- Cria uma nova instância de uma [struct][struct] e preenche os campos, exceto `distance`.
- Cria uma função que devolve o tipo da struct recém-criada e atualiza os campos em conformidade.

## 2. Cria uma pista de corridas

- Define uma nova [struct][struct] com 1 campo.
- Cria uma função que devolve o tipo da nova struct criada e atualiza os campos em conformidade.

## 3. Conduz o carro

- Adiciona um novo campo para registar a distância percorrida.
- Tens de verificar se há bateria suficiente para conduzir o carro.

## 4. Verifica se um carro telecomandado consegue terminar uma corrida

- Assume que o carro está mesmo a começar a corrida.
- Tens de calcular a distância máxima que o carro consegue percorrer com o nível de bateria atual.
- O número de vezes que o carro pode ser conduzido pode ser calculado com `battery / batteryDrain`.
- A distância máxima que o carro pode percorrer é o produto da velocidade do carro pelo número de vezes que pode ser conduzido.
- Sabendo a distância máxima que o carro pode percorrer, compara-a com a distância da pista de corridas.
