# Dicas

## 1. Define o tempo esperado no forno, em minutos

- Tens de definir uma [var][vars] com [def].

## 2. Calcula o tempo restante no forno, em minutos

- Tens de definir uma [função][functions] com um único parâmetro.
- Podes usar e referir-te à var definida anteriormente pelo seu nome.
- O resultado da avaliação da última expressão de uma função é devolvido automaticamente pela função; todas as funções devolvem esse valor.
- Podes usar as funções principais para [operações com números][operators] para subtrair valores.

## 3. Calcula o tempo de preparação, em minutos

- Tens de definir uma [função][functions] com um único parâmetro.
- Podes usar as funções principais para [operações com números][operators] para multiplicar valores.

## 4. Calcula o tempo decorrido, em minutos

- Tens de definir uma [função][functions] com dois parâmetros.
- Podes [chamar][calling] uma das outras funções que definiste anteriormente.
- Podes usar as funções principais para [operações com números][operators] para somar valores.
