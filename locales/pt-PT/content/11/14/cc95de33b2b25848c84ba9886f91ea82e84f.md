# Instruções

Adiciona as contagens de minas a um tabuleiro de Campo Minado concluído.

O Campo Minado é um jogo popular em que o jogador tem de encontrar as minas com a ajuda de pistas numéricas que indicam quantas minas estão diretamente adjacentes (na horizontal, na vertical ou na diagonal) a uma casa.

Neste exercício, tens de criar código que conta o número de minas adjacentes a uma determinada casa vazia e substitui essa casa pela contagem.

O tabuleiro é um retângulo composto por carateres de espaço em branco (' '). Uma mina é representada pelo caráter asterisco ('\*').

Se um determinado espaço não tiver nenhuma mina adjacente, deixa essa casa em branco.

## Exemplos

Por exemplo, podes receber um tabuleiro 5 x 4 como este (os espaços vazios são aqui representados pelo caráter '·' para visualização no ecrã):

```
·*·*·
··*··
··*··
·····
```

E o teu código vai transformá-lo nisto:

```
1*3*1
13*31
·2*2·
·111·
```
