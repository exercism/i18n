# Instalação

## Instalar o Dart

Encontras as instruções para instalar o Dart SDK no site do Dart: [Obtém o Dart][get-dart]

## Plugin de Dart para o teu IDE ou editor

Se usas um IDE ou um editor, [adiciona um plugin de Dart][editors] se existir para o editor da tua escolha.

[get-dart]: https://dart.dev/get-dart
[editors]:  https://dart.dev/tools#editors
