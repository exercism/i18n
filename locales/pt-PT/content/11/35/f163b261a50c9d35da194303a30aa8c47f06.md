# Apêndice às instruções

## Dicas

Para completar este exercício, precisas de criar o tipo de dados `Robot`,
como uma variável mutável, e o tipo de dados `RunState`. Também precisas de
implementar as seguintes funções:

- `initialState`
- `mkRobot`
- `resetName`
- `robotName`

Vais encontrar uma declaração de dados fictícia e assinaturas de tipo já
preparadas, mas cabe-te a ti definir as funções e criar um tipo de dados com
significado, um newtype ou um sinónimo de tipo. Para modelar o estado, este
exercício usa a
[mónada `State`](https://en.wikibooks.org/wiki/Haskell/Understanding_monads/State).
Mais concretamente, combinamos a mónada `State` com a mónada `IO` recorrendo
aos [transformadores de mónada `StateT`](http://book.realworldhaskell.org/read/monad-transformers.html).
Todos os testes são executados com `initialState` como o estado que é
passado ao `evalStateT`.
