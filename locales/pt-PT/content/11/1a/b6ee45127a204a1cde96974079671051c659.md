# Testes

Para correr os testes na linha de comandos, executa o seguinte comando a partir do diretório do exercício:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## GUI

Para correr os testes através da GUI do simulador MARS, `include` a tua implementação no fim do `runner.mips`; basta descomentar a última linha.
