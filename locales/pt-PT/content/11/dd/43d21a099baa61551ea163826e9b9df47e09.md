# Instruções

Tens um pequeno posto meteorológico na margem do Vltava, em Praga, e em cada turno apontas as leituras de temperatura num registo em texto simples, uma leitura por linha. Cinco palavrinhas tratam da contabilidade de um turno.

Cada palavra recebe o caminho para o ficheiro de registo.

## 1. Lê todas as leituras

Define `read-readings` para devolver todas as leituras do registo como um array de strings, uma por linha.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. Encontra a leitura mais recente

Define `latest-reading` para devolver a leitura mais recente, a última linha do registo.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. Lê o registo em bruto

Define `log-text` para devolver o ficheiro de registo completo como uma única string, exatamente como está guardado.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. Regista uma leitura

Define `record-reading` para acrescentar uma nova leitura ao fim do registo, na sua própria linha, sem alterar as leituras anteriores. Não devolve nada.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. Reescreve o registo

Define `rewrite-log` para substituir todo o registo por um novo array de leituras, uma por linha.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
