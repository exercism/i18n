# Instruções

Os endpoints HTTP ficam melhores com verificação de tipos. Adicionar um tipo Record a um pedido POST garante que os dados corretos são enviados de cada vez.

## Objetivos

- Modifica o código fornecido.
- Adiciona os atributos necessários a este record para aceitar dois operandos e um operador.
- Adiciona uma função de recurso HTTP que aceite um pedido POST no caminho '/calc'.
- A função deve aceitar o tipo record Calculation como payload e devolver um objeto JSON genérico.

### Aceita

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Devolve

```json
{ "expression": "4+10.2", "result": 14.2 }
```
