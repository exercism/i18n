# Introdução

Em Cairo, o conceito de propriedade aplica-se às _variáveis_ e define as regras que determinam quem as pode usar.
Cada variável declarada só pode ser usada uma vez, o que significa que, depois de ser usada, será destruída ou movida, consoante o tipo de utilização.

A _destruição_ pode acontecer de várias formas:

- uma variável sai do âmbito (com ou sem utilização);
- uma struct é desestruturada;
- destruição explícita com `destruct()`

_Mover_ um valor significa simplesmente passar esse valor para outra função.

A linguagem Cairo usa um sistema de tipos lineares, que aproveita para garantir que todo o código é demonstrável (e verificável), ao mesmo tempo que abstrai a memória imutável da Cairo VM.
