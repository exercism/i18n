## Instruções

Foste contratado por um centro de reciclagem.
Devido à falta de espaço, todos os produtos são colocados no mesmo tapete transportador, mas isso fez com que materiais diferentes se misturassem e ficassem inutilizáveis.
Para resolver isto, foi-te pedido que criasses funções para identificar o tipo de um produto.

### 1. Verifica se um valor é um boolean

Implementa a função `isBoolean`, que verifica se um valor é um boolean.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Verifica se um valor é um número.

Implementa a função `isNumber`, que verifica se um valor é um `number` ou `bigint` _finito_, ou seja, que não é `NaN` nem `Infinity`.

Às vezes, o dispositivo de leitura de IDs avaria e lê um valor não numérico como `NaN` (Not a Number) ou `Infinity`.
A tua função também deve conseguir lidar com isto corretamente.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Verifica se um valor é um objeto

Implementa a função `isObject`, que deve verificar se o valor é um objeto.
No tapete, `null` não é nada e não é considerado um objeto.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Verifica se uma string é numérica

Implementa a função `isNumericString`, que deve verificar se o valor é uma string composta apenas por algarismos, ou por um sinal de menos seguido de algarismos, que indica um número negativo.
Só devem ser considerados números inteiros; os decimais não são considerados numéricos nesta verificação do robô de reciclagem.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Verifica se um objeto é eletrónico

Implementa a função `isElectronic`, que verifica se um objeto é uma instância da classe `ElectronicDevice` fornecida ou de uma das suas subclasses.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Verifica se um valor é um array não vazio

Implementa a função `isNonEmptyArray`, que verifica se um valor é um array não vazio.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Verifica se um valor é um array vazio

Implementa a função `isEmptyArray`, que verifica se um valor é um array vazio.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Verifica se um objeto tem uma propriedade ou método `type`

Implementa a função `hasType`, que verifica se um objeto tem uma propriedade ou um método `type`.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Lança um erro se um objeto não tiver uma propriedade ou método `id`

Implementa a função `assertHasId`, que lança um `Error` se um objeto não tiver a propriedade `id`.

Se um objeto tiver a propriedade `id`, a função não deve devolver nada.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Verifica se um objeto tem uma propriedade `id`

Implementa a função `hasIdProperty`, que verifica se um objeto tem uma propriedade `id`.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Verifica se um objeto tem uma propriedade `type` definida

Implementa a função `hasDefinedType`, que verifica se um objeto tem uma propriedade `type` que não é `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
