# Sobre

`TUPLE:` declara uma classe com fendas nomeadas. O Factor gera
automaticamente uma palavra construtora (com o nome da classe
sufixado com `new`), um construtor `boa` («por ordem dos
argumentos»), uma sintaxe literal `T{ class … }` e palavras de
acesso por fenda.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

O sistema de acesso em [`accessors`][accessors] fornece quatro
variantes por fenda: `name>>`, `>>name`, `change-name` e o par
mutável `[ … ] change-name`. `>>name` e `change-name` alteram o
tuplo; usa primeiro `clone` quando precisares de deixar o
original intacto.

Os tuplos suportam `=` por igualdade estrutural e, quando
impressos, mostram os valores das fendas que não são os
predefinidos.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
