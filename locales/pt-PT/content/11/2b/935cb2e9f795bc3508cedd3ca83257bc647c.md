# Dicas

## 1. Define uma função para verificar se a lista de línguas está vazia

- Podes usar um dos [métodos][list] do tipo List para verificar se está vazia.

## 2. Define uma função para adicionar uma língua à lista

- Podes usar um dos [métodos][list] do tipo List para adicionar elementos.
- Não te esqueças: os métodos que devolvem `void` não precisam de nenhuma instrução `return`.

## 3. Define uma função para remover uma língua da lista

- Podes usar um dos [métodos][list] do tipo List para remover elementos.
- Não te esqueças: os métodos que devolvem `void` não precisam de nenhuma instrução `return`.

## 4. Define uma função para devolver o primeiro item da lista

- Podes usar um dos [métodos][list] do tipo List para obter elementos num determinado índice.

## 5. Define uma função para devolver quantas línguas há na lista

- Podes usar um dos [métodos][list] do tipo List para obter o tamanho da lista.

## 6. Define uma função para determinar se uma língua está na lista

- Podes usar um dos [métodos][list] do tipo List para verificar se um elemento está contido na lista.

## 7. Define uma função para determinar se a lista é entusiasmante

- Experimenta usar um método já definido na classe.
