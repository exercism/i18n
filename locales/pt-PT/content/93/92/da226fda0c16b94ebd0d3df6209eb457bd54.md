# Sobre

As listas em C# são coleções de valores primitivos ou de instâncias de structs ou classes. São implementadas na biblioteca de classes base como [`List<T>`][lists-docs], em que `T` é o tipo do item da lista. A API expõe um conjunto rico de métodos para criar e manipular listas.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

Normalmente, a definição de uma coleção inclui um marcador de posição entre sinais de menor e maior, muitas vezes `T` por convenção. Isto permite que quem usa a coleção especifique que tipo de itens deve guardar nela.

Ao contrário de [concept:csharp/arrays](), as listas podem redimensionar-se dinamicamente.

## LINQ

A API integrada de `List<T>` é rica: inclui mapeamentos e filtros como `ConvertAll`, `FindAll` e `Foreach`. A sua [sintaxe de iteração][for-each] é muito clara e precisas mesmo de conhecer esta API. Ainda assim, o Language Integrated Query ([LINQ][linq]) está disponível para muitas tarefas, é ainda mais poderoso e amplamente usado, e tem a vantagem de oferecer uma interface consistente entre coleções de bibliotecas, coleções de terceiros e as tuas próprias classes.
