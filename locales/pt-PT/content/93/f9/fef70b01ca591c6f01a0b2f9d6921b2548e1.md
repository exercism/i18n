# Aprendizagem

O COBOL tem uma variedade de recursos para ajudar tanto programadores experientes como principiantes, embora alguns possam ser obscuros. Felizmente, aqui está uma compilação de algumas fontes populares.

## Livros

- [Beginning COBOL for Programmers][Coughlan Book]  
Este livro de Michael Coughlan aborda os fundamentos da escrita em COBOL até ao padrão de 2002. Inclui também exercícios para praticar programação, que foram concluídos e reunidos neste [repositório do GitHub][Book Exercises].

- [Ebooks gratuitos de COBOL][Free Books]

## Documentação

- [GnuCOBOL's Programmer's Guide][Gnu Guide]  
Este recurso aborda os elementos do compilador GnuCOBOL e é atualizado regularmente à medida que o próprio compilador muda.

## Cursos

- [Open Mainframe Project COBOL Course][Open Mainframe]  
Este curso aborda o dialeto IBM no ambiente VSCode fornecido.
