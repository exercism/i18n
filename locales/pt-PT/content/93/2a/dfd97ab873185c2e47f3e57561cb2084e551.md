# Anexo

## Comportamento do Zipper

O Zipper oferece uma forma funcional de navegar numa árvore de `Node`.

Todas as chamadas ao Zipper devem devolver um _novo_ objeto Zipper.
Se o Zipper não alterar valores (ou seja, se não tiver sido chamado nenhum método `Set*`), deve usar a mesma árvore subjacente.
Quando é chamado um método `Set*`, o novo Zipper deve ter uma nova árvore, deixando a árvore original inalterada.

As chamadas ao Zipper que mudam o foco para um `Node` inválido devem devolver um erro.
