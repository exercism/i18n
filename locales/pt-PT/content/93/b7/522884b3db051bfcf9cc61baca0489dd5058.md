# Instruções

Vais escrever algum código para gerir uma lista de linguagens de programação que queres aprender.

## 1. Adicionar uma linguagem a uma lista

Altera a sub-rotina `add-language`, que recebe uma lista de linguagens e um nome de linguagem como argumentos, para devolver uma lista com a nova linguagem acrescentada ao fim.

## 2. Remover uma linguagem de uma lista

Altera a sub-rotina `remove-language` para remover a última linguagem de uma lista dada.

## 3. Obter a primeira linguagem de uma lista

Altera a sub-rotina `first-language` para devolver a primeira linguagem de uma lista dada.

## 4. Obter a última linguagem de uma lista

Altera a sub-rotina `last-language` para devolver a última linguagem de uma lista dada.

## 5. Obter uma fatia de linguagens de uma lista

Altera a sub-rotina `get-languages`, que recebe uma lista de linguagens e uma lista de números dos elementos pretendidos, para devolver uma fatia da lista dada.

## 6. Verificar se uma linguagem existe numa lista

Altera a sub-rotina `has-language`, que recebe uma lista de linguagens e um nome de linguagem como argumentos, para devolver `True` ou `False`, a indicar se a linguagem existe na lista dada.
