# Classes imutáveis

Um `SCOREBOARD` é uma coisa que muda. Dois nomes para um mesmo quadro de
resultados veem a mesma pontuação, porque só há um quadro e ambos os nomes
apontam para ele.

Uma marcação não é assim. `350 degrees` não se transforma noutra coisa;
simplesmente *é*. Os números comportam-se assim, tal como as strings. E as
tuas próprias classes também podem.

## imutável

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

Duas palavras mudam tudo. Um objeto de uma classe imutável é um **valor**,
não uma coisa para a qual se aponta:

- é copiado quando é atribuído ou passado, por isso mais ninguém pode alterar
  o teu;
- nunca pode ser void;
- e não é possível atribuir valores aos seus atributos.

## Alterar um criando outro

Como `degrees := 90` não é permitido, `attr` dá outra coisa: uma rotina que
recebe o novo valor e devolve **um novo objeto** com esse valor alterado.

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

O original fica intacto. É esse o padrão, e é assim que `create` é escrito:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

Não há `new` aqui. Um objeto imutável existe sempre, por isso `b : SAME` já
é um, com todos os atributos no seu valor vazio.

Uma rotina que «altera» uma marcação devolve, por isso, uma nova:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## Comparação

Os valores são comparados pelo que contêm, não pela identidade do objeto,
mas tens de dizer como. Escreve `is_eq`, e o `=` vai usá-lo:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

Sem isso, o `=` entre duas marcações não compila.

## O que escolher

Usa uma classe imutável quando a coisa não tem identidade e nada nela pode
mudar de forma sensata: uma marcação, um ponto, uma data, um comprimento.
Usa uma classe normal quando a coisa é uma coisa particular a que acontecem
coisas: um quadro de resultados, um arnês, um ficheiro.

O critério é saber se "o mesmo" significa "igual" ou "exatamente o mesmo".
