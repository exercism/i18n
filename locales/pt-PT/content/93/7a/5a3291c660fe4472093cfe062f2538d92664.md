# Introdução

As structs são uma extensão construída sobre [mapas][exercism-maps] que fornece verificações em tempo de compilação e valores predefinidos. Uma struct recebe o nome do módulo em que é definida. Para definir uma struct, usa a construção `defstruct`. A construção vem habitualmente logo a seguir à definição do módulo. O `defstruct` aceita uma lista de átomos (para valores predefinidos `nil`) ou uma lista de palavras-chave (para valores predefinidos especificados). Os campos sem valores predefinidos têm de vir antes dos campos com valores predefinidos.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Aceder aos campos e atualizá-los

Como as structs são construídas sobre mapas, podemos usar a maioria das funções de mapas para obter e manipular valores. O _Access Behaviour_ **não** está implementado para structs. Em vez disso, recomenda-se o uso do _operador de acesso estático_ `.` para aceder aos campos de uma struct.

- obter/recuperar valores de campos:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- atualizar valores de campos

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Correspondência de padrões

As structs podem ser usadas na correspondência de padrões com ou sem o nome da struct.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Ao incluir o nome da struct no padrão, garantes que tanto o lado esquerdo como o lado direito são structs do mesmo tipo.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## Impor a inicialização dos valores dos campos

Podemos usar o atributo de módulo `@enforce_keys` com uma lista de chaves de campo para garantir que os valores são inicializados quando a struct é criada. Se uma chave não estiver listada, o seu valor será `nil`, como se vê no exemplo acima. Se uma chave obrigatória não for inicializada, é lançado um erro.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
