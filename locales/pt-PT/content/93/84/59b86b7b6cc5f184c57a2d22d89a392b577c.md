# Introdução às asserções de tipo

As interfaces em Go podem introduzir ambiguidade em relação ao tipo subjacente.
Uma asserção de tipo permite-nos extrair o valor concreto subjacente de um valor de interface, com esta sintaxe: `interfaceVariable.(concreteType)`.

Por exemplo:

```go
var input interface{} = 12
number := input.(int)
```

NOTA: isto provoca um panic se a variável de interface não contiver um valor do tipo concreto.

Podemos testar se um valor de interface contém um tipo concreto específico recorrendo aos dois valores devolvidos pela asserção de tipo: o valor subjacente e um valor Boolean que indica se a asserção foi bem-sucedida.
Por exemplo:

```go
str, ok := input.(string) // no panic if input is not a string
```

Se `input` contiver uma `string`, então `str` será o valor subjacente e `ok` será true.
Se `input` não contiver uma `string`, então `str` será o valor zero do tipo `string` (ou seja, `""` - a string vazia) e `ok` será false.
Não ocorre qualquer panic em nenhum dos casos.

## Switch de tipos

Um **switch de tipo** pode realizar várias asserções de tipo em série.
Tem a mesma sintaxe de uma asserção de tipo (`interfaceVariable.(concreteType)`), mas o `concreteType` é substituído pela palavra-chave `type`.
Vejamos um exemplo:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
