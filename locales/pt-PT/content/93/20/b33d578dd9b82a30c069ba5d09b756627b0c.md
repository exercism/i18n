# Instalação

Para instalar o Julia no teu sistema, segue as instruções da [página de downloads da linguagem Julia](https://julialang.org/downloads/).

~~~~exercism/caution
Não é recomendado instalar o Julia através do gestor de pacotes do teu sistema operativo.
Esses pacotes não são mantidos oficialmente e podem causar problemas.
~~~~

Para uma instalação local, existem plugins disponíveis para um grande número de editores/IDEs.
A [extensão para o VS Code](https://github.com/julia-vscode/julia-vscode) é a mais popular.
Podes encontrar integrações para outros editores na organização [JuliaEditorSupport](https://github.com/JuliaEditorSupport) no GitHub.

Se preferires um ambiente mais interativo, podes usar notebooks Jupyter com o [IJulia](https://github.com/JuliaLang/IJulia.jl) ou usar o [Pluto.jl](https://github.com/fonsp/Pluto.jl) para notebooks reativos simples em Julia.

Uma forma simples de começar com o Julia sem precisares de uma instalação local é o [Nextjournal](https://nextjournal.com/), uma IDE online baseada em notebooks.
Podes aceder-lhe a partir do teu navegador, iniciar sessão e começar a resolver exercícios.
Se só queres um REPL online, podes usar o [Repl.it](https://repl.it/languages/julia).
