# Apêndice às instruções

## Implementação

Há alturas em que precisas de lidar com problemas inesperados que surgem durante a execução do código.
Em Dart, podes usar exceções para lidar com estas situações.

Para lançar uma exceção em Dart, usa a palavra-chave `throw` seguida de uma instância da exceção específica que queres lançar.
Por exemplo, `throw Exception()` lança uma instância do tipo base Exception.

Neste exercício, precisas de definir uma exceção personalizada chamada `InvalidNucleotideException`.
Esta exceção deve ser lançada quando se encontra um nucleótido inválido.
Os testes só verificam que é lançada uma instância de `InvalidNucleotideException`, por isso és livre de a implementar como quiseres, desde que seja lançada corretamente.

Para mais informações sobre exceções em Dart, consulta a [documentação sobre exceções](https://dart.dev/language/error-handling).
Podes criar exceções personalizadas [implementando a interface Exception](https://dart.dev/language#interfaces-and-abstract-classes).
