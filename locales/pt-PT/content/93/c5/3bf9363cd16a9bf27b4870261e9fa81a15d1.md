# Conversão de tipos

A conversão de tipos também é conhecida como coerção de tipos.
A conversão de tipos acontece quando dois valores de tipos diferentes são convertidos para o mesmo tipo para realizar uma operação.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

Quando a expressão é avaliada, o valor do tipo `string` é convertido implicitamente para `int`, para corresponder ao que o operador `*` espera.
A decisão sobre que tipo converter é tomada pelo PHP de acordo com as regras da operação, e estas regras variam muito.

A coerção de tipos acontece também quando chamamos funções e métodos:

```php
strlen(12321);
# => 5
```

## Conversão explícita

Em vez de depender da coerção implícita, podemos forçar explicitamente que um valor seja avaliado como um determinado tipo, usando a conversão ao estilo do `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Isto converte o valor para o tipo indicado entre parênteses `(...)`.
Todos os tipos primitivos podem ser usados como tipo de destino: `bool`, `int`, `float`, `string`, `array`, `object`.

## Conversão apenas temporária

A conversão de tipos, implícita ou explícita, **não altera** o tipo do valor guardado numa variável.
Apenas o valor de entrada da operação é convertido.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## Perda de informação

Quando um valor é convertido para outro tipo, pode haver perda de informação nesse processo:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

Depender da conversão, explícita ou implícita, pode originar erros num sistema maior.

## Conversão explícita para `array` e `object`

Os valores também podem ser convertidos para os tipos `array` e `object`.
Se um valor que não é um array nem um objeto for convertido para `array`, passa a ser um único elemento dentro de um array:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

Quando é convertido para `object`, o valor é atribuído a uma propriedade pública com o nome `scalar`:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` é o tipo de uma classe anónima integrada no PHP.
