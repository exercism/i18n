# Sobre

O Perl é uma linguagem de programação criada por Larry Wall, lançada pela primeira vez em 1987.

## Pacotes e módulos

Um pacote é uma coleção de código, muitas vezes contida num ficheiro de módulo com o mesmo nome e a extensão `.pm`.
O módulo pode depois ser importado para outro ficheiro, normalmente com a palavra-chave `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Variáveis

Existem variáveis escalares (`$foo`), de array (`@bar`) e de hash (`%baz`).
Para simplificar, aqui só vamos usar variáveis escalares.
Um valor escalar pode ser o seguinte: uma string, um número, um Boolean ou uma [referência][perlreftut] a algo.
A ausência de um valor é `undef`.


As palavras-chave `my` e `our` declaram uma variável no âmbito lexical, por exemplo `my $foo;`.
Com `our`, a variável também fica associada a uma variável de pacote com o mesmo nome.
Há outras formas de declarar variáveis que não vamos abordar aqui.

Podes atribuir um valor a uma variável com o operador `=`, por exemplo `$foo = 1;`, o que pode ser feito ao mesmo tempo que declaras a variável, por exemplo `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Sub-rotinas

A palavra-chave `sub` declara uma [sub-rotina][perlsub].
A palavra-chave `return` termina a sub-rotina e devolve os valores especificados, ou uma lista vazia se não for indicado nenhum.
Sem um `return` especificado, o valor devolvido é determinado pelo contexto (escalar, lista ou vazio) da sub-rotina utilizada e da sua última instrução.

```perl
sub hello () {
    return 'Hello, World!';
}
```

As versões recentes do Perl permitem-te especificar parâmetros formais numa [assinatura][perlsubsig].
A lista de parâmetros pode conter variáveis escalares, de array ou de hash.
Uma lista de parâmetros vazia significa que a sub-rotina aceita zero argumentos.
As versões mais antigas do Perl exigiam obter os argumentos a partir da variável especial `@_`, o que não vamos abordar aqui.
