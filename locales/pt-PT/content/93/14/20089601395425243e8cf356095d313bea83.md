# Apêndice às instruções

## Implementação

A tua função vai receber um array de strings.
Cada string representa uma mão composta por 5 cartas separadas por espaços.
Uma carta é representada por um número e o seu naipe.

Deves devolver um array com a melhor mão ou, em caso de empate, as melhores mãos.
Cada mão deve ser uma string no mesmo formato da que te foi dada inicialmente.
