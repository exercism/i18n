# Dicas

## 1. Imprimir um crachá para um funcionário

- Podes usar um [modelo de string][string-template] para criar strings de descrição.
- Existe um [método incorporado para converter uma string em maiúsculas][to-upper-case].

## 2. Imprimir um crachá para um novo funcionário

- Deves verificar se o ID é `null` antes de o usar.
- Podes usar um [operador de igualdade][kotlin-operators] para verificar se um valor é `null`.

## 3. Imprimir um crachá para o proprietário

- Podes usar o [operador Elvis][elvis-operator] para usar um valor alternativo quando uma variável é `null`.
