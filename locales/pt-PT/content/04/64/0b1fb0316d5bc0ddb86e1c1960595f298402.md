# Instruções

Escreve um protótipo da aplicação de leitor de música.

Para o protótipo, cada música será representada apenas por um número.
Dado um intervalo de números (os IDs das músicas), cria uma lista simplesmente ligada.

Dada uma lista simplesmente ligada, deves conseguir inverter a lista para reproduzir as músicas pela ordem inversa.

~~~~exercism/note
A lista ligada é uma estrutura de dados fundamental na informática, usada frequentemente na implementação de outras estruturas de dados.

O tipo mais simples de lista ligada é a lista **simplesmente** ligada.
Isso significa que cada elemento (ou «nó») contém dados, a par de algo que aponta para o nó seguinte da lista.

Se quiseres aprofundar os teus conhecimentos sobre listas ligadas, espreita [este artigo][intro-linked-list], que explica tudo com uns desenhos muito bons.

[intro-linked-list]: https://medium.com/basecs/whats-a-linked-list-anyway-part-1-d8b7e6508b9d
