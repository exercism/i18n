# ignora-me

## Entrada

O teu programa vai receber o enigma alfamético como uma única string através da entrada padrão (stdin). A string do enigma segue o formato `WORD1 + WORD2 + ... == RESULT`.

Por exemplo:

```text
SEND + MORE == MONEY
```

## Saída

Se o enigma tiver uma solução, imprime uma única linha composta por pares `LETTER=DIGIT` separados por espaços, ordenados alfabeticamente pela letra.

Para o exemplo acima, a saída deve ser:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

Se o enigma tiver múltiplas soluções válidas, imprimir qualquer uma delas é aceitável.

Se o enigma não tiver solução, não imprimas nada (uma linha vazia).
