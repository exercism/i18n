# Instruções

És o contramestre de um cargueiro costeiro. O porão, o compartimento mais baixo do casco, recolhe águas residuais, e em cada turno o equipamento do porão tem de ser aberto, posto a funcionar e guardado. Aconteça o que acontecer durante a bombagem, o equipamento *tem* de voltar ao seu estado guardado.

Os testes dão-te `<test-pump>` para adquirires bombas novas. Cada bomba tem uma fenda `opened>>` que lê `t` enquanto está aberta e `f` depois de ser descartada.

## 1. Drenar o porão

Define `drain-bilge` para libertar uma única bomba. Chamar `drain-bilge` duas vezes à mesma bomba não deve fazer mal: o framework trata disso por ti.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. Rotina de bombagem

Define `pump-out` para receber uma bomba e uma quotation, colocar a bomba na pilha para a quotation usar e libertar a bomba depois, *mesmo que a quotation lance uma exceção*.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. Rotina de turno completo

Define `shift-routine` para receber duas bombas e uma quotation. Abre um âmbito de destruidores, regista *as duas* bombas para libertação incondicional e depois chama a quotation. As duas bombas acabam por ser libertadas, quer a quotation termine normalmente, quer lance uma exceção.

A quotation recebe as duas bombas na pilha como valores de entrada.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. Bombagem arriscada

Às vezes uma bomba está emprestada: só a queres descartar se algo correr mal, caso contrário o próximo turno precisa que ela fique aberta. Define `risky-pump-out` para receber uma bomba e uma quotation, registar a bomba para libertação **apenas em caso de falha** e chamar a quotation com a bomba na pilha.

Se a quotation tiver sucesso, a bomba fica aberta. Se a quotation lançar uma exceção, a bomba é libertada e a exceção propaga-se.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. Um disposable personalizado: a válvula

Completa o conjunto de ferramentas com um disposable novinho em folha: uma `valve`. A tupla já está declarada para ti:

```factor
TUPLE: valve < disposable is-open ;
```

- Define `<valve> ( -- valve )` para construir uma válvula nova através de `new-disposable`, com `is-open` definido como `t`.
- Implementa `M: valve dispose*` para alterar `is-open` para `f`.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
