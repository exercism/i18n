# Sobre

## Igualdade

Podes verificar se dois tipos de Elm «são iguais» com o [operador de igualdade][equality-operator] `(==)`.
O operador de desigualdade é `(/=)` (*não* `!=` como em muitas linguagens).

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

Ambos os valores comparados têm de ser do mesmo tipo.
O operador de igualdade funciona com literais, tuplas, registos e tipos personalizados.
O operador verifica a igualdade estrutural, o que significa que valores iguais têm conteúdo e estrutura profunda iguais, independentemente da anotação de tipo ou da posição na memória.

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Repara que *nunca deves* comparar funções, pois isso faz o programa rebentar em tempo de execução.
Encontras mais informações sobre essa limitação [aqui][equality-operator].

## Comparações

Os [operadores de comparação][comparison-operators] `(<)`, `(<=)`, `(>)`, `(>=)` e as funções `min`, `max`, `compare` funcionam com tipos `comparable`.
O tipo `comparable` é um tipo especial que agrupa todos os tipos incorporados que podem ser comparados: números, carateres, strings, listas de coisas comparáveis e tuplas de coisas comparáveis.
Os carateres são comparados pelos seus [pontos de código Unicode][unicode-codepoint].

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

Os tipos semelhantes a sequências (strings, listas e tuplas) são comparados por [ordem lexicográfica][lexicographic-order].
Resumindo, os elementos da sequência são comparados aos pares, por ordem, até se encontrar um elemento menor ou até uma sequência terminar.

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

Valores de outros tipos, como registos ou tipos personalizados, não podem ser comparados diretamente.

Alguns tipos incorporados exigem que o seu conteúdo seja `comparable`, como as chaves de `Set` ou de `Dict`, uma vez que a sua estrutura depende de uma ordenação interna.
Isso implica que os tipos personalizados podem não poder ser guardados num `Set`, embora existam alternativas da comunidade: [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] e outras.

As listas de valores `comparable` podem ser ordenadas com `List.sort` e as listas de valores que podem ser mapeados para valores comparáveis podem ser ordenadas com `List.sortBy`.
Se precisares de uma ordenação hierárquica (ordenar por uma propriedade e desempatar com outra), podes usar tuplas ou listas com `List.sortBy` (entre outras [alternativas][sort-by]), uma vez que as tuplas e as listas são ordenadas por ordem lexicográfica.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

A função `compare` recebe dois valores `comparable` e devolve um `Order`.
Um `Order` é um tipo que verifica numa única operação se um valor é maior (`GT`), igual (`EQ`) ou menor (`LT`) do que outro.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

É possível construir funções de comparação para tipos arbitrários e usá-las, por exemplo, para ordenar com `List.sortWith`:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
