# Números

`INT` guarda um número inteiro. Neste Sather tem exatamente 32 bits, por isso conta de -2147483648 a 2147483647.

```sather
   goals : INT is
      return 42;
   end;
```

## Argumentos

Uma rotina recebe argumentos entre parênteses, cada um com um tipo:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Os argumentos que partilham um tipo podem partilhar a declaração, que é o estilo habitual:

```sather
   total(first, second : INT) : INT is
```

## Aritmética

| Operador | Significado |
| --- | --- |
| `+` | somar |
| `-` | subtrair, e negar |
| `*` | multiplicar |
| `/` | dividir, descartando o resto |
| `%` | o resto dessa divisão |

`/` entre dois `INT`s nunca produz uma fração:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

Se quiseres uma fração, precisas de `FLTD`, que aparece mais à frente.

A multiplicação e a divisão têm maior precedência do que a adição e a subtração, como na aritmética normal. Os parênteses agrupam quando precisas de outra coisa:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## Rotinas úteis em INT

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

`.str` é a forma de um número fazer parte de uma frase, depois de conheceres as strings.
