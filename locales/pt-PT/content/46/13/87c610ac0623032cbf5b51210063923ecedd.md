# Sobre

As funções **definidas pelo utilizador** são criadas com a palavra-chave `function`. Depois, esta deve ser seguida por um nome de função e uma lista de argumentos.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

As funções podem ser chamadas num ficheiro antes de serem definidas, pois são elevadas para o topo do seu âmbito.

## Nomenclatura

Os nomes de funções em PHP seguem as regras de outros identificadores: têm de começar com um sublinhado ou uma letra, podendo depois ser seguidos por qualquer número de letras, números ou sublinhados.
