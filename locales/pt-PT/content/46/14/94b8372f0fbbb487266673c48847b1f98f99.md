# Operador ternário

Os _operadores ternários_ podem ser vistos como uma versão compacta de um _if-else_.
Normalmente são usados em instruções return (mas não só), bastando uma única linha para tomar a decisão: devolvem o valor da esquerda se a expressão for `true` e o valor da direita se for `false`.

Muitas expressões simples de _if/else_ podem ser simplificadas com _operadores ternários_.

```java
// this ternary statement
return 5 > 4 ? true : false;

// is equivalent to this if/else
if ( 5 > 4 ) {
    return true;
} else {
    return false;
}
```

Então, como decidir entre um _if-else_ e um _ternário_?
Os _operadores ternários_ usam-se em cenários simples, em que só precisas de devolver um valor com base numa condição e não é necessário qualquer cálculo extra.
Usa um _if-else_ para tudo o resto: condições aninhadas, expressões grandes e situações em que é preciso mais do que uma linha para decidir o valor devolvido.

Embora possas aninhar _operadores ternários_, o código torna-se muitas vezes difícil de ler.
Nesses casos, é preferível usar ifs aninhados.

```java
// hard to read
int value = expr1 ? expr2 && expr3 ? val1 : (val2 + val3) : expr4;

// easier to read
if (expr1){

    if (expr2 && expr3){

        return val1;
    }

    return val2 + val3;
}
return val4;


```

Os _operadores ternários_ e as instruções _if/else_ são um bom exemplo de que, ao programar, tens várias formas de alcançar o mesmo resultado.
