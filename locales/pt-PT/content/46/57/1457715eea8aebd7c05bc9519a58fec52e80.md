Sobre o YAMLScript
==================

Então estás pronto para aprender [YAMLScript](https://yamlscript.org)?!

Parabéns!

Estás prestes a embarcar numa viagem que vai mudar a forma como pensas sobre dados e programação.

Pelo caminho, vais aprender:

* Muito mais sobre a sintaxe da linguagem de dados [YAML](https://wikipedia.org/wiki/YAML)
* Uma grande parte dos conceitos de programação de [Lisp](https://en.wikipedia.org/wiki/Lisp)
* Como fazer as coisas com [programação funcional](
  https://wikipedia.org/wiki/Functional_programming) e estruturas de dados
  imutáveis
* O suficiente da linguagem de programação [Clojure](https://wikipedia.org/wiki/Clojure)
  para fazeres estragos

O YAMLScript é uma linguagem de programação nova, funcional e de código aberto, com uma sintaxe baseada em YAML, que transpila para código Clojure, o qual é depois avaliado por um intérprete de runtime binário nativo chamado `ys`.

O YAMLScript é uma excelente escolha para resolver exercícios do Exercism.
Todos os exercícios deste percurso foram resolvidos em 3 a 50 linhas de YAMLScript confortavelmente espaçadas (10 a 15, em média).

É uma ótima linguagem para aprender programação funcional e conceitos de Lisp, ao mesmo tempo que usa uma sintaxe limpa, amigável e bastante indolor, inspirada nas melhores partes de YAML, Clojure, Perl, Python, JavaScript e CoffeeScript.
