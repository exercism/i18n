# Contador de linhas de código

O contador de linhas de código (LoC) recebe uma solução e conta as suas linhas de código.

Por predefinição, só são contadas as linhas de código dos ficheiros submetidos pelo estudante.
Se o estudante tiver submetido um ficheiro de teste, esse será ignorado.

Embora isto funcione bem para a maioria das submissões, alguns tracks podem precisar de ignorar ficheiros adicionais.
Para isso, permitimos que o contador de linhas de código seja [personalizado por track][lines-of-code-counter-customize].

## Implementação

Utilizamos a biblioteca [tokei][tokei] para fazer a contagem propriamente dita.
Como os pull requests muitas vezes não são integrados rapidamente, criámos o nosso próprio [fork][tokei-fork].
Isto permite-nos iterar mais depressa e adicionar suporte para qualquer linguagem que queiramos.

## Linguagens suportadas

Podes verificar se a tua linguagem é suportada de base procurando-a no ficheiro [languages.json][languages.json].

### Adicionar uma nova linguagem

Se a tua linguagem **não** for suportada, podes adicionar suporte da seguinte forma:

1. Adicionar uma entrada para a tua linguagem ao ficheiro [languages.json].
   Consulta a [documentação sobre como adicionar linguagens][adding-language] para mais informações.
2. Adicionar testes para verificar que a contagem funciona corretamente para a tua linguagem.
   Consulta a [documentação sobre como adicionar testes][adding-tests] para mais informações.

Depois de fazeres estas alterações, abre um pull request no [repositório exercism/tokei][tokei-fork].
Aqui está um [pull request de exemplo][example-pr] que adiciona suporte para a linguagem Arturo.
