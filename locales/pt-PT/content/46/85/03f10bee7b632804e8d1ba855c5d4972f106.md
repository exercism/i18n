# Instruções

És responsável pelo horário de partidas de um pequeno ferry que serve uma ilha.
As partidas são registadas como datas e precisas de alguns auxiliares para
trabalhar com elas.

## 1. Registar a data de uma partida

Define `make-date` de modo a receber um ano, um mês e um dia, e devolver o
timestamp correspondente.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. Dar nome ao dia da semana

Define `weekday-name` de modo a receber o timestamp de uma partida e devolver o
nome do dia da semana em que calha.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. Anos bissextos

Define `leap?` de modo a receber um ano e devolver se é um ano bissexto.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. Dias de um mês

Define `month-length` de modo a receber um ano e um mês e devolver o número de
dias desse mês (não te esqueças de fevereiro).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. Dias mais tarde

Define `add-days` de modo a receber um timestamp e um número de dias, e devolver
o timestamp correspondente a esse número de dias mais tarde.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
