# Instruções

O mosaico do centro de artes comunitário acabou de ser instalado no
mês passado, e agora a Magpie Marg descobriu-o. Na maioria dos dias,
troca uma ou duas tesselas por outras mais brilhantes do **tesouro**
que tem ali perto, ou arranca uma tessela e desaparece durante uma
hora.

Tu és o voluntário que regista cada alteração. O próprio mosaico é
um **array de tamanho fixo**: um espaço por cada posição de tessela,
que guarda uma string de cor ou `f` para "em falta". O tesouro da
Magpie Marg é um **vector** de tesselas soltas que ela roubou.

## 1. Cria uma linha nova

Define `fresh-mosaic` para receber um comprimento `n` e devolver um array
de `n` espaços vazios (cada um `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Coloca uma tessela

Define `place-tile` para receber uma linha, uma posição e uma cor, e
atualizar a linha no local, de modo a que a posição indicada passe a ter
essa cor. A palavra não devolve nada.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Lasca uma tessela

Define `chip-tile` para receber uma linha e uma posição, e atualizar a
linha no local, de modo a que a posição indicada volte a ser `f`.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Muda a cor de uma tessela

Define `recolour-tile` para receber uma linha, uma posição e uma quotation
de um argumento, e atualizar a linha no local aplicando a quotation à
tessela nessa posição.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Faz um instantâneo antes de Marg chegar

Define `snapshot-mosaic` para receber uma linha e devolver uma cópia
independente que não será afetada por mutações posteriores do original.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg mete uma tessela no bolso

Define `stash-tile` para receber o tesouro da Marg (um vector) e uma cor,
e acrescentar a cor ao tesouro. Não devolve nada.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg devolve uma tessela

Define `return-tile` para receber o tesouro da Marg e remover e devolver
a tessela guardada mais recentemente (a que está no topo).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
