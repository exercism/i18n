# Introdução

## Listas de palavras-chave

As listas de palavras-chave são uma estrutura de dados de chave-valor.

```elixir
[month: "April", year: 2018]
```

As listas de palavras-chave são listas de [tuplas][exercism-tuples] `{key, value}` e também podem ser escritas dessa forma, mas a sintaxe mais curta é a mais utilizada.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

As chaves numa lista de palavras-chave têm de ser [átomos][exercism-atoms], mas os valores podem ser qualquer coisa. Cada chave pode ser usada mais do que uma vez. Os pares chave-valor numa lista de palavras-chave estão ordenados.

Podes trabalhar com listas de palavras-chave usando as mesmas abordagens que usas com listas, ou podes usar o módulo `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
