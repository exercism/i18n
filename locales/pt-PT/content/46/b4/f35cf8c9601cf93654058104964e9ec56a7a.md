# Dicas

## 1. Define o tempo esperado no forno em minutos

- Tens de definir uma [constante][constants] que deve conter o valor [inteiro][integers] indicado na receita.
- A constante tem de ser definida na [classe][classes] `Lasagna`.
- Tem de ser definida fora de um método.

## 2. Calcula o tempo restante no forno em minutos

- Tens de definir um [método][methods] com um único parâmetro para o tempo já decorrido.
- Podes usar o operador matemático (`-`) para subtrair valores.
- Podes usar a [constante][constants] que definiste anteriormente.

## 3. Calcula o tempo de preparação em minutos

- Tens de definir um [método][methods] com um único parâmetro para o número de camadas.
- Podes usar o operador matemático (`*`) para multiplicar valores.

## 4. Calcula o tempo total de trabalho em minutos

- Tens de definir um [método][methods] com dois parâmetros nomeados.
- Podes chamar um dos outros métodos que definiste anteriormente.
- Podes usar o operador matemático (`+`) para somar valores.
