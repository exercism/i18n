# Módulos e caminhos em Cairo

O Cairo usa **módulos** para organizar o código.

Os módulos ajudam a estruturar os projetos e a controlar a visibilidade de itens como funções, structs e traits.

## Definir módulos

Os módulos definem-se com `mod` e podem ser aninhados:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

As funções, os structs e os traits são **privados por omissão**.

Usa `pub` para os tornar acessíveis fora do seu módulo.

## Caminhos: absolutos ou relativos

Para te referires a um item noutro módulo, podes usar:

- **Caminhos absolutos** (a começar em `crate::`):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Caminhos relativos** (a começar no módulo atual):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Isto funciona se `front_of_house` estiver no mesmo módulo.

## Trazer módulos para o âmbito com `use`

Escrever caminhos completos repetidamente é incómodo.

A palavra-chave `use` permite referências mais curtas:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

O `use` aplica-se **apenas no âmbito onde aparece**; se precisares dele noutro local, tens de o repetir.

### Utilização idiomática do `use`

- Traz **módulos** para o âmbito, não funções:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  Em vez de:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- Para **traits, structs e enums**, usa o caminho completo:

  ```rust
  use core::num::traits::BitSize;
  ```

### Alias com `as`

Renomeia as importações quando for necessário:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Importar vários itens

Em vez de várias instruções `use`, agrupa as importações:

```rust
use shapes::{Square, Circle, Triangle};
```

## Reexportar com `pub use`

Para expor um módulo numa estrutura diferente, usa `pub use`:

```rust
pub use crate::front_of_house::hosting;
```

Agora, o código externo pode usar `restaurant::hosting::add_to_waitlist()` em vez de `restaurant::front_of_house::hosting::add_to_waitlist()`.

## Usar pacotes externos com o Scarb

Para adicionar uma dependência, atualiza o `Scarb.toml`:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Usa `scarb add <package>` para adicionar dependências e `scarb rm <package>` para as remover.

## O operador glob (`*`)

Para importar tudo de um módulo:

```rust
use core::num::traits::*;
```

Deves usá-lo com cuidado, pois pode tornar o código mais difícil de ler.
