# Introdução

Uma [`string`][ref-string] em Kotlin é uma sequência imutável de carateres Unicode.

[`Immutable`][wiki-immutable] significa que qualquer operação sobre uma string tem de devolver uma nova string: a string original nunca pode mudar.

[`Unicode`][wiki-unicode] significa que a maioria dos sistemas de escrita do mundo pode ser representada, mas (ao contrário de linguagens mais antigas, como C) não existe uma correspondência de 1:1 entre carateres e bytes.

Uma string é delimitada por aspas duplas `" "`.

Alguns caracteres precisam de escape: `\\`, mais os habituais caracteres não imprimíveis, como `\t` (tabulação) e `\n` (nova linha).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

As strings com várias linhas são delimitadas por 3 aspas duplas e podem conter texto arbitrário (sem necessidade de escape).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Usa o [trimIndent][trimIndent-doc] para remover a indentação comum das linhas.
Isto é útil para formatar a string:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Em alternativa, o [trimMargin][trimMargin-doc] permite-te especificar um delimitador.
Cada linha da `String` começa então depois do delimitador.
O delimitador predefinido é `|`, mas podes especificar um delimitador diferente como parâmetro.
Por exemplo:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

As strings podem ser concatenadas com `+`, mas é melhor limitar isto a casos curtos e simples.
Há outras opções, muitas vezes melhores.

## Modelos de string

Isto refere-se ao que outras linguagens chamam "interpolação".

Se uma string contiver um símbolo de dólar `$` seguido de um identificador, ou contiver chavetas (`{expression}`) à volta de uma expressão, esses elementos são substituídos, respetivamente, pelo valor ou pelo resultado da expressão.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

As chavetas `{ }` são necessárias à volta das expressões quando a interpretação seria, de outro modo, ambígua.

Em geral, usar modelos de string é uma forma mais eficiente e idiomática de combinar strings do que usar `+`.

## Funções de string

O Kotlin disponibiliza _muitas_ [`functions`][ref-string-functions] para manipular strings.

Na sua maioria, estas são [`extensions functions`][ref-extensions] e não membros da classe `String`, embora isto tenha pouca influência na forma como as usamos.

~~~~exercism/note
As páginas de [documentação][ref-string-functions] do Kotlin, bastante complexas, escondem as funções de extensão na vista predefinida.
Não te esqueças de clicar em `Members & Extensions` para expandir esta secção.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Os exemplos seguintes mostram apenas uma pequena seleção do que está disponível:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
