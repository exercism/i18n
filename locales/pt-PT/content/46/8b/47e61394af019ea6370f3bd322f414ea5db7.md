# Dicas

## 1. Começar do zero

- Para criar um array, podes usar `make-array`.
- As dimensões de um array indicam-se como uma lista de `make-array`.
- Para definir todos os elementos com um valor inicial, usa o parâmetro de palavra-chave `:inital-element`.

## 2. Começar a partir de um tabuleiro existente

- Para definir o conteúdo inicial de um array, usa o parâmetro de palavra-chave `:initial-contents`.

## 3. Condição de vitória

- Podes usar `aref` para obter o valor de uma célula de um array.
- Podes usar `eq` para determinar se dois símbolos são iguais.
- Podes usar `and` para combinar duas expressões `eq` e comparar três itens.

## 4. Numa linha

- Os argumentos de `aref` (para um array bidimensional) são a "linha" e a "coluna".

## 5. Numa coluna

- Os argumentos de `aref` (para um array bidimensional) são a "linha" e a "coluna".
