# Dicas

## Programação orientada a objetos

* `reset_names` é um **método de classe**.
  Consulta as [Variáveis de classe][class-vars] no Guia da Linguagem MoonScript.
* Vais precisar de acompanhar o estado de todas as instâncias de robô (que nomes já foram atribuídos).
  As variáveis de classe são perfeitas para isto, mas pensa também em que outras abordagens podem funcionar.

## Dicas de desempenho

* Uma boa estratégia para atribuir nomes a todos os robôs é gerar primeiro os 676 000 nomes e baralhar essa lista.
  Depois, cada robô novo pode simplesmente ficar com o nome seguinte da lista baralhada.

[class-vars]: https://moonscript.org/reference/#the-language/object-oriented-programming/class-variables
