# Acerca de

O Swift é uma linguagem de programação compilada e multiparadigma, concebida com três objetivos principais:

- **Segurança**: funcionalidades incorporadas na linguagem ajudam a detetar e a evitar erros antes de o teu código ser executado em produção.
- **Velocidade**: um desempenho otimizado, comparável ao das linguagens baseadas em C.
- **Expressividade**: uma sintaxe limpa e moderna, agradável e fácil de ler e de escrever.

A Apple apresentou o Swift em 2014 como uma alternativa moderna ao Objective-C, a linguagem usada até então no desenvolvimento para iOS e macOS.
Hoje, o Swift é open source e funciona em plataformas Apple, Linux e Windows.

## Primeiros passos

### Variáveis

Podes guardar e dar nome a valores definindo uma [variável][constants-variables].
Depois de definires uma variável, podes usar o seu nome para te referires a esse valor ao longo do código.
As variáveis são _mutáveis_, ou seja, os seus valores podem mudar depois de serem definidos.

Define uma variável com a palavra-chave `var`:

```swift
var variableName = 10
```

O Swift é uma linguagem de tipos estáticos, o que significa que todos os valores têm um tipo conhecido em tempo de compilação.
Podes declarar um tipo explicitamente com uma [anotação de tipo][type annotations] ou deixar o compilador do Swift [inferir o tipo][type-inferring] a partir do valor atribuído:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Podes atualizar o valor de uma variável com o operador de atribuição (`=`):

~~~~exercism/note
O tipo de uma variável não pode mudar depois de ser declarada.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Podes declarar uma variável sem valor inicial, indicando o seu tipo, mas tens de lhe atribuir um valor antes de a usares:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Constantes

As [constantes][constants-variables] também associam um nome a um valor, mas os seus valores não podem ser alterados depois da atribuição.
São _imutáveis_.
Define uma constante com a palavra-chave `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Operadores aritméticos

O Swift disponibiliza os [operadores aritméticos][arithmetical-operators] habituais para matemática básica:

- Adição: `+`
- Subtração: `-`
- Multiplicação: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Funções

Em Swift, as [funções][functions] são blocos de código autónomos que realizam uma tarefa específica.
As funções podem receber valores de entrada, devolver um valor e ser passadas como valores a outras funções.
Define uma função com a palavra-chave `func`, seguida do nome da função, de uma lista de parâmetros entre parênteses e de um tipo de retorno opcional:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

As funções em Swift usam [rótulos de argumento][argument-labels], que fazem com que o código se leia como frases naturais:

- O **rótulo de argumento** é usado quando se chama a função.
- O **nome do parâmetro** é usado dentro do corpo da função para aceder ao valor.

Se indicares apenas um nome, o Swift usa-o como rótulo de argumento e como nome do parâmetro ao mesmo tempo:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Se não quiseres um rótulo de argumento ao chamar a função, escreve um underscore (`_`) antes do nome do parâmetro:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Todos os parâmetros de uma função são constantes (`let`) por predefinição, o que significa que os seus valores não podem ser modificados dentro do corpo da função.

Para devolver um valor de uma função, indica o tipo de retorno depois de `->` e usa a palavra-chave `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Quando uma função não devolve um valor, o seu tipo de retorno é `Void` (equivalente a um tuplo vazio, `()`).
Nessas funções, podes omitir tanto o tipo de retorno `-> Void` como a instrução `return`.

### Comentários

O Swift suporta duas formas de [comentários][comments]:

- Os **comentários de uma linha** começam com `//` e vão até ao fim da linha.
- Os **comentários de várias linhas** ficam entre `/*` e `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
