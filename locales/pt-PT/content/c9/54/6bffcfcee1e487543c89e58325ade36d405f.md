# Instalação

Segue as instruções para o teu sistema na página de instalação em [golang.org](http://golang.org/doc/install).

## Versão do Go

Este percurso usa o Go 1.26.

Podes usar uma versão anterior do Go se modificares o ficheiro `go.mod` de cada exercício e alterares a linha `go 1.26`.
No entanto, os testes usam funcionalidades introduzidas no Go 1.22 e não funcionam com uma versão anterior sem alterações.
