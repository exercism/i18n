# Testes

## Correr os testes

Para correr os testes, executa o seguinte comando:

```bash
dotnet test
```

Para correr os testes automaticamente à medida que alteras cada ficheiro de código-fonte, executa o seguinte comando:

```bash
dotnet watch test
```

## Resolver o exercício

Resolver um exercício significa fazer com que todos os seus testes passem. Por predefinição, apenas um teste (o primeiro) é executado quando corres os testes. Isto é intencional, pois permite que te concentres apenas em fazer com que esse teste passe. Assim que ele passar, podes ativar o teste seguinte ao remover `Skip = "Remove this Skip property to run this test"` do atributo `[Fact]` ou `[Theory]` do teste. Quando todos os testes estiverem ativados e a tua implementação fizer com que todos passem, terás resolvido o exercício!

Para te ajudar a começar, cada exercício vem com um ficheiro de implementação inicial. Podes usar este ficheiro como ponto de partida para construir a tua solução. Sente-te à vontade para remover ou alterar este ficheiro se achares que é o que deves fazer.

## Usar pacotes

Deves conseguir resolver a maioria dos exercícios sem usar quaisquer pacotes externos. No entanto, nos exercícios em que queres mesmo usar um pacote externo, podes adicioná-lo ao teu projeto ao executar o seguinte comando:

```bash
dotnet add package [package-name]
```
