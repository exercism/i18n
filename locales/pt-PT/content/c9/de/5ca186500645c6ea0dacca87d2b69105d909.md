# Instruções

Implementa um programa que traduz de inglês para Pig Latin.

O Pig Latin é uma linguagem inventada, típica das brincadeiras de crianças, que tem como objetivo ser confusa.
Obedece a algumas regras simples (abaixo), mas, quando é falado depressa, torna-se realmente difícil de entender para quem não é criança (e para quem não é falante nativo).

- **Regra 1**: Se uma palavra começa com um som de vogal, acrescenta o som "ay" ao fim da palavra.
  Repara que "xr" e "yt" no início de uma palavra produzem sons de vogal (por exemplo, "xray" -> "xrayay", "yttria" -> "yttriaay").
- **Regra 2**: Se uma palavra começa com um som de consoante, move-o para o fim da palavra e acrescenta depois o som "ay" ao fim da palavra.
  Os sons de consoante podem ser formados por várias consoantes, ou seja, um grupo consonântico (por exemplo, "chair" -> "airchay").
- **Regra 3**: Se uma palavra começa com um som de consoante seguido de "qu", move-o para o fim da palavra e acrescenta depois o som "ay" ao fim da palavra (por exemplo, "square" -> "aresquay").
- **Regra 4**: Se uma palavra contém um "y" depois de um grupo consonântico, ou como segunda letra numa palavra de duas letras, esse "y" produz um som de vogal (por exemplo, "rhythm" -> "ythmrhay", "my" -> "ymay").

Existem ainda mais algumas regras para casos-limite e também há variantes regionais.
