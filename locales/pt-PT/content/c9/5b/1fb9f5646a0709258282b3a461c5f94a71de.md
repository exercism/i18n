# Apêndice às instruções

## Registos

| Registo | Utilização       | Tipo     | Descrição                                                          |
| ------- | ---------------- | -------- | ------------------------------------------------------------------ |
| `$a0`   | valor de entrada | inteiro  | ano a verificar                                                    |
| `$v0`   | valor devolvido  | boolean  | o valor de entrada é um ano bissexto (`0` = `false`, `1` = `true`) |
| `$t0-9` | temporário       | qualquer | usado para armazenamento temporário                                |
