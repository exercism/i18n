# Recursos de aprendizagem recomendados

Bem-vindo à aprendizagem de ColdFusion (CFML)! O CFML é uma linguagem de scripting da JVM, dinâmica e fracamente tipada. Tem dois tipos de ficheiro diferentes. Os ficheiros `.cfm` (ColdFusion markup)_ são puramente procedimentais e usam a sintaxe baseada em tags para criar templates de HTML. Se estiveres a construir um site, usarias estes ficheiros para as vistas:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

O outro tipo de ficheiro é o `.cfc` (ColdFusion Component), e é assim que declaras uma classe. Os components são usados para lógica de negócio, modelos e controladores. Normalmente, estes usam a sintaxe de script, que é parecida com JavaScript.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
