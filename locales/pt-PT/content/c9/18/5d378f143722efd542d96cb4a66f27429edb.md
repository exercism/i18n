# Sobre

As expressões regulares em Gleam seguem a especificação **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), tal como outras linguagens populares como Java, JavaScript ou Ruby.

O módulo `gleam/regex` oferece funções para trabalhar com expressões regulares.

~~~~exercism/note
Este exercício pressupõe que já conheces a sintaxe das expressões regulares, incluindo classes de carateres, quantificadores, grupos e capturas.

Se precisares de rever os teus conhecimentos de expressões regulares, consulta uma destas fontes: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

A forma mais comum de criar expressões regulares é usar a função `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

A função `regex.from_string` devolve um `Error` se a sintaxe da expressão regular for inválida, por isso usou-se aqui uma asserção let para garantir que a expressão regular é válida.

A função `regex.check` pode ser usada para verificar se uma expressão regular corresponde a uma string.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Capturas

Se quiseres capturar subcadeias com uma expressão regular, podes usar a função `regex.scan` para obter uma lista de correspondências.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Modificadores

O comportamento de uma expressão regular pode ser modificado criando-a com a função `regex.compile` e passando opções.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
