# Transformação de JSON de combustível

## Enunciado do problema

Todos os empregados da ABC Corp recebem um subsídio de combustível ilimitado. Os empregados têm de enviar um registo sempre que abastecem os seus veículos. Esses registos são acrescentados ao mesmo ficheiro JSON e processados no final do mês.

Como membro da equipa de operações digitais, a tua tarefa é ler este ficheiro JSON e escrever os resultados noutro ficheiro JSON. O ficheiro de saída deve conter uma entrada para cada empregado, com os seguintes detalhes:

- Número de empregado
- Número de abastecimentos
- Custo total do combustível
- Total de galões
- Total de milhas acumuladas

Recebes dois argumentos do tipo `string`.

1. Caminho do ficheiro JSON de entrada.
1. Caminho do ficheiro JSON de saída.

O ficheiro JSON de entrada contém um array de objetos JSON. Cada objeto JSON tem a seguinte forma.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

A tua tarefa é transformar a entrada JSON no seguinte formato JSON e escrever o conteúdo no caminho indicado. O ficheiro de saída deve conter uma entrada para cada empregado, ordenadas por `employeeId` em ordem crescente.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## Restrições

- Número de registos de abastecimento `n` no ficheiro JSON de entrada:  0 <= n <= 1000
- Número de empregados na empresa: 97
- O preço do combustível é por galão
- Não faltam registos de abastecimento

## Sugestões

- Usa o [módulo `ballerina/io`](https://lib.ballerina.io/ballerina/io/latest) para ler e escrever ficheiros JSON.
- Converte os valores JSON em tipos específicos da aplicação para trabalhares com os dados de forma segura em termos de tipos. Para mais informações, consulta o exemplo [Converter para um tipo definido pelo utilizador](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) nos Ballerina By Examples (BBE).

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- A [desestruturação de registos](https://ballerina.io/learn/by-example/destructure-records-using-query) pode ser útil para reduzir a verbosidade do código.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- Usa funções com corpo de expressão para funções com uma única expressão. Por exemplo, funções que têm apenas a instrução de retorno.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
