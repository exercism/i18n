# Sobre

Common Lisp usa os operadores aritméticos habituais para a maioria das operações, mas é um pouco peculiar por usar uma "notação prefixa" em vez da mais familiar "notação infixa".

De forma mais visual:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Embora a notação prefixa transforme algumas operações como `2 + 2` na forma pouco familiar `(+ 2 2)`, torna muito mais fácil operar com mais do que um número de cada vez.

## Operadores aritméticos com um único argumento

Como pequena peculiaridade, os operadores `-` e `/` têm um significado especial quando são aplicados a um único número:

```lisp
;; A single number passed to `-` is simply negated
(- 4)   ; => -4
(- -32) ; => 32
;; A single number passed to `/` returns the reciprocal
(/ 8)   ; => 1/8
(/ 0.1) ; => 10.0
```

## Comparar números

Por fim, podes achar útil comparar números diferentes com funções como `=` (igual), `/=` (diferente de) e `>=` (maior ou igual a).
Quando estas comparações são verdadeiras (como em `(= 1 1)`), devolvem `T`, e quando não são (como em `(> 0 1)`), devolvem `NIL`.

## Predicados numéricos

A linguagem também inclui alguns predicados úteis, como `zerop`, `evenp` e `oddp`, que verificam as condições óbvias.

## Referência

```lisp
;; Addition
(+ 1 2 3 4 5) ; => 15

;; Subtraction
(- 15 3 2)    ; => 10
(- 42)        ; => -42

;; Multiplication
(* 4 3 2 1)   ; => 24

;; Division
(/ 64 16 2)   ; => 2
(/ 5)         ; => 1/5

;; Exponentiation
(expt 2 8)    ; => 256

;; Square Root
(sqrt 25)     ; => 25

;; Modulo (Similar to remainder)
(mod 10 3)    ; => 1

;; Equality
(= 2 2)       ; => T
(= 3 5)       ; => NIL
```
