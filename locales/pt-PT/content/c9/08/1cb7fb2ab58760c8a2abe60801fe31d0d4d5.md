# Introdução

O ciclo `for` é uma das instruções mais usadas para executar repetidamente alguma lógica.
Em JavaScript, é composto pela palavra-chave `for`, um _cabeçalho_ entre parênteses e um bloco de código que contém o _corpo_ do ciclo, entre chavetas.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

Normalmente, a inicialização cria uma variável contadora, a condição verifica se o ciclo deve continuar ou parar e o passo incrementa o contador no fim de cada repetição.
As diferentes partes do cabeçalho são separadas por pontos e vírgulas.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
