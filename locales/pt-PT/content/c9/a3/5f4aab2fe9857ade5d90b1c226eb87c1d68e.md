# Dicas

## 1. Verifica se a ação 'Ataque Rápido' é possível

- O operador lógico NOT (`!`) pode ser colocado antes de uma expressão para negar o seu valor.
- Vê [este artigo da MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_Operators#Logical_NOT_!) sobre operadores lógicos.

## 2. Verifica se a ação 'Espiar' é possível

- As expressões lógicas são avaliadas da esquerda para a direita e são testadas quanto a possíveis 'curto-circuitos'.
- Para compreenderes bem o mecanismo da esquerda para a direita, dá uma vista de olhos a [este artigo](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence)!

## 3. Verifica se a ação 'Sinalizar Prisioneiro' é possível

- Operadores lógicos por ordem de precedência (do mais alto para o mais baixo): `!`, `&&`, `||`.
- Vê [este artigo da MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#Precedence_And_Associativity) sobre a precedência de operadores.

## 4. Verifica se a ação 'Libertar Prisioneiro' é possível

- `()` é o operador com a precedência mais alta. Usa-o para agrupar expressões lógicas.
