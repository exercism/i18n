# Introdução

Embora o Swift tenha muitos tipos diferentes, cada um deles encaixa numa de duas classificações: _tipos de valor_ e _tipos de referência_. Em Swift, as estruturas são tipos de valor e as classes são tipos de referência.

A principal diferença entre tipos de valor e tipos de referência é que, quando atribuis um tipo de valor a uma variável ou a uma constante, ou quando o passas a uma função, o que é atribuído ou passado é na verdade uma cópia do valor, e não esse valor em particular. Alterar uma cópia de uma estrutura não afeta as outras cópias. Nos tipos de referência, o que é atribuído ou passado é uma referência ao valor, pelo que dois nomes diferentes podem referir-se à mesma instância de uma classe. Isto pode levar a que a instância original seja alterada quando lhe acedes através de outro nome.
