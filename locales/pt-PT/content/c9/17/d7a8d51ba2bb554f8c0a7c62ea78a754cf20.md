# Listas

`LIST{T}` é uma coleção ordenada e expansível, suportada por um array que é substituído por um maior quando fica cheio.

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes[0]                     -- "muddy boots"
   notes[0] := "clean boots";
   notes.size
   notes.is_empty
   notes.has("clean boots")
   notes.remove_index(0);
```

## Array ou lista?

| | `ARRAY{T}` | `LIST{T}` |
| --- | --- | --- |
| tamanho | fixo na criação | muda |
| acrescentar | não | sim |
| remover | não | sim |
| indexação | `a[i]` | `l[i]` |
| sobrecarga | nenhuma | um tamanho, e espaço de sobra |

Usa um `ARRAY` quando o tamanho é conhecido e definitivo: uma fila de dançarinos, uma semana de contagens. Usa uma `LIST` quando as coisas chegam ou partem.

## No local, não funcional

`append`, `remove_index` e `[i] :=` alteram a própria lista. Não é preciso voltar a atribuir nada, e uma lista que entregas a uma rotina não fica protegida contra ela.

É o oposto de `FMAP` e `FSET`, e vale a pena saber bem qual delas tens em mãos. Regra geral: um `F` no início do nome significa funcional, e tudo o resto é alterado no local.

Para entregar uma lista que ninguém possa estragar, dá uma cópia:

```sather
   return notes.copy;
```

## O custo de acrescentar

Acrescentar é barato em média. Quando o array de suporte fica cheio, é criado um novo com o dobro do tamanho e tudo é copiado. Por isso, na maioria das vezes, acrescentar não custa quase nada, e de vez em quando custa uma cópia. Ao longo de muitos acrescentos, isso dá uma média constante por operação, e é por isso que se duplica em vez de crescer uma unidade de cada vez.

`remove_index` não é barato: tudo o que vem depois da posição removida avança uma posição. Remover repetidamente a partir do início de uma lista comprida é lento de uma forma que é fácil não notar.

## Rotinas úteis

| Chamada | O que faz |
| --- | --- |
| `l.append(x)` | acrescenta no fim |
| `l.insert_before(i, x)` | acrescenta numa posição |
| `l.remove_index(i)` | retira uma posição |
| `l.has(x)` | está lá dentro? |
| `l.copy` | uma cópia independente |
| `l.str` | o conteúdo, entre chavetas |
| `l.elt!`, `l.ind!` | percorre os valores, ou as posições |
