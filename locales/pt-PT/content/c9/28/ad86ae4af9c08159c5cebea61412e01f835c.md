## Importar

Um módulo é normalmente carregado com a palavra-chave `use`.
Isto carrega o módulo e chama o método `import`, importando todos os símbolos exportados.

Os símbolos no array `@EXPORT` do pacote são importados por predefinição.
Os símbolos no array `@EXPORT_OK` do pacote têm de ser importados explicitamente.

Antes do Perl `v5.37`, um módulo tinha de terminar com um valor verdadeiro (normalmente `1`), para indicar que tinha sido carregado com sucesso.
Isso deixa de ser necessário quando usas a funcionalidade [`module_true`][module_true].

## Exportar

Para que um símbolo seja importado, tem de ser exportado primeiro.
O módulo [Exporter][Exporter] está incluído no Perl e é uma das opções mais convenientes para exportar.

Definir o módulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Usar o módulo:
```perl
use Foo ('bar');

bar();
```

## Pragma

Um pragma é um módulo que influencia algum aspeto do comportamento do Perl.

Os pragmas [`strict`][strict] e [`warnings`][warnings] são habitualmente recomendados, para restringir construções inseguras e assinalar potenciais problemas, respetivamente.
O pragma `strict` é ativado juntamente com `use v5.12` ou superior.
O pragma `warnings` é ativado juntamente com `use v5.35` ou superior.

O pragma [`feature`][feature] permite-te ativar funcionalidades do Perl mais recentes e experimentais.
Quando indicas uma versão específica do Perl à palavra-chave `use`, esta ativa o conjunto de funcionalidades dessa versão.

## Módulos principais

A par do [Exporter][Exporter], o Perl tem uma grande variedade de [módulos principais][perl-core-modules] disponíveis para usar.
Alguns exemplos úteis para os exercícios que podes encontrar aqui incluem [List::Util][List::Util], [Time::Piece][Time::Piece] e [Math::BigRat][Math::BigRat].

## CPAN

Além dos módulos principais, o [CPAN][metacpan] tem milhares de módulos adicionais criados pela comunidade Perl disponíveis para instalação.
O percurso de Perl usa um [cpanfile][test-runner-cpanfile] para instalar uma seleção de módulos que podes usar com o executor de testes de Perl do Exercism.
