# Testes

Para executar o teste através do DrRacket, basta abrires o ficheiro de teste e clicares no botão "Run", no canto superior direito.

Para executar o teste a partir da linha de comandos, corre o teste a partir do diretório do exercício com o seguinte comando:

```
raco test <exercise>-test.rkt
```

em que `<exercise>` deve ser substituído pelo identificador do exercício.
