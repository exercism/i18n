# Sobre

Os [dicionários][dictionaries] são um dos principais tipos de coleção do Swift.
Um dicionário armazena associações não ordenadas entre chaves únicas e os valores correspondentes.
Todas as chaves de um dicionário têm de ser do mesmo tipo, e todos os valores também têm de partilhar o mesmo tipo.

Os literais de dicionário escrevem-se como pares `key: value` separados por vírgulas e entre parênteses retos:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

Os tipos de dicionário podem escrever-se explicitamente de duas formas: `Dictionary<Key, Value>` ou a sintaxe abreviada `[Key: Value]`.

Para criar um dicionário vazio, especifica explicitamente os tipos das chaves e dos valores:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## Aceder a valores

Podes aceder aos valores através da notação de subscrito: coloca a chave entre parênteses retos depois do nome do dicionário.
Como uma chave pode não existir no dicionário, o acesso por subscrito devolve um *opcional* (`Value?`).
Se a chave existir, o Swift devolve o valor encapsulado; caso contrário, devolve `nil`:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

Para evitares trabalhar com opcionais, podes fornecer um valor predefinido através do parâmetro `default`:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## Modificar dicionários

Nos dicionários mutáveis declarados com `var`, podes adicionar ou atualizar pares chave-valor através de atribuição por subscrito:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## Iterar sobre um dicionário

Podes iterar sobre cada par chave-valor de um dicionário com um ciclo `for-in`.
Cada item é fornecido como um tuplo `(key, value)`:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## Ordenar dicionários

Como os dicionários não têm ordem, ordená-los produz um array de pares chave-valor.
Podes passar um closure ao método `sorted(by:)` que compara dois tuplos `(key, value)` e devolve `true` se o primeiro tuplo dever aparecer antes do segundo:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
