# Instruções

Neste exercício vais organizar corridas entre vários tipos de carros telecomandados. Cada carro tem as suas próprias características de velocidade e de consumo de bateria.

Os carros começam com a bateria cheia (100%). Cada vez que conduzes o carro com o telecomando, este percorre em metros a velocidade do carro e diminui a percentagem de bateria restante pelo valor do seu consumo de bateria.

Se a bateria de um carro estiver abaixo da percentagem do seu consumo de bateria, já não podes conduzir o carro.

Cada pista de corrida tem o seu próprio comprimento. Os carros são testados verificando se conseguem terminar a pista sem ficar sem bateria.

## 1. Cria um carro telecomandado

Define uma lista `car` com os seguintes elementos:

- speed
- battery_drain
- battery
- distance_traveled

Permite criar um carro telecomandado definindo uma função `new_car` que recebe a velocidade do carro em metros e a percentagem do consumo de bateria como os seus dois parâmetros, e devolve uma lista `car`.

Num carro novo, a bateria está a 100% e a distância percorrida é zero.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. Cria uma pista de corrida

Define outra lista chamada `track` com o único elemento `track_length`.
Permite criar uma pista de corrida definindo uma função `new_track` que recebe a distância da pista em metros:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. Verifica se a bateria está descarregada

Implementa a função `battery_drained()` que indica se a bateria está descarregada.
Considera-se que a bateria está descarregada se não houver o suficiente para avançar mais uma vez.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. Conduz o carro

Implementa a função `drive` que atualiza o número de metros percorridos com base na velocidade do carro e reduz a bateria de acordo com o consumo de bateria.
Se não houver bateria suficiente para conduzir mais uma vez, o carro não se move.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. Verifica se um carro telecomandado consegue terminar uma corrida

Para terminar uma corrida, um carro tem de conseguir percorrer o comprimento da corrida. Isto significa não ficar sem bateria antes de cruzar a linha de chegada. 

Implementa a função `can_finish` que recebe um `car` e um `track` como parâmetros e devolve `TRUE` se o carro conseguir terminar a corrida; caso contrário, devolve `FALSE`.

Assume que estás atualmente na linha de partida da corrida e liga o motor do carro para a corrida. Tem em conta que a bateria do carro pode não estar necessariamente totalmente carregada quando a corrida começa.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. Guarda se o carro consegue terminar uma pista com a bateria cheia

Criaste várias pistas de comprimentos diferentes e precisas de guardar se o teu carro as consegue completar quando está totalmente carregado.

Implementa a função `store_track` que recebe um carro, uma pista e um nome de pista, e devolve um carro atualizado com um elemento extra.
Este elemento deve ter o `name` da pista, e o valor deve ser uma sub-lista com o `track_length` e se o carro a consegue `complete`.

O carro fornecido no argumento pode não estar totalmente carregado, por isso certifica-te de que reinicias a bateria e a distância percorrida antes de o utilizares.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
