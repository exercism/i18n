# Introdução

## Números de vírgula flutuante

Um número de vírgula flutuante é um número com zero ou mais algarismos depois do separador decimal. Por exemplo: `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

Tipos de vírgula flutuante diferentes podem guardar quantidades diferentes de algarismos depois do separador decimal; a isto chama-se precisão.

O C# tem três tipos de vírgula flutuante:

- `float`: 4 bytes (precisão de cerca de 6 a 9 algarismos). Escreve-se `2.45f`.
- `double`: 8 bytes (precisão de cerca de 15 a 17 algarismos). É o tipo mais comum. Escreve-se `2.45` ou `2.45d`.
- `decimal`: 16 bytes (precisão de 28 a 29 algarismos). Usa-se normalmente quando se trabalha com dados monetários, pois a sua precisão reduz a probabilidade de erros de arredondamento. Escreve-se `2.45m`.

Como se pode ver, cada tipo consegue guardar um número diferente de algarismos. Por exemplo, se tentares guardar o PI num `float`, só ficam guardadas as primeiras 6 casas decimais (com o último algarismo guardado arredondado).

## Ciclos while

Neste exercício, podes querer usar um ciclo. Há várias formas de escrever ciclos em C#, mas o ciclo `while` é o mais adequado aqui:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## Ciclos do/while

Se o código de um ciclo tiver de ser executado sempre pelo menos uma vez, podes usar um ciclo `do`/`while`:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
