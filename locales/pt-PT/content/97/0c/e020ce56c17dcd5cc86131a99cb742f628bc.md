# Apêndice às instruções

## Implementação

O track Crystal adiciona um teste opcional para verificar se as letras possíveis podem ser qualquer caráter Unicode, e não apenas carateres alfabéticos ASCII.
Estes testes não estão acessíveis a partir do editor web, mas são o comportamento predefinido quando os executas localmente.

Para desativar estes testes, ao chamar o test runner, adiciona a seguinte flag: `--tag "~optional"`
