# Aprender PowerShell

Uma excelente forma de começares a aprender PowerShell é escolher um recurso de aprendizagem na [secção de aprendizagem][learning section] do site da PowerShell.
Tem uma enorme quantidade de informação e ligações para uma grande variedade de tópicos de PowerShell.

O PowerShell também tem um sistema de ajuda auto-documentado muito completo.
Podes explorar grande parte do que o PowerShell oferece com o cmdlet `Get-Help`.
Dentro do PowerShell, experimenta:

```PowerShell
Get-Help about
```

Vais ver cerca de 3 páginas de tópicos que podes explorar.
Duas outras funções que te vão ser muito úteis são:

- Get-Command
- Get-Member

Queres saber o que estas fazem?
Experimenta `Get-Help Get-Command` e `Get-Help Get-Member`, claro.

## Verbos e substantivos do PowerShell

O PowerShell segue uma convenção Verbo-Substantivo bastante rigorosa para dar nome aos seus cmdlets.
Inicialmente, isto pode ser uma experiência desconcertante para programadores experientes.
Embora possas dar o nome que quiseres às tuas funções, familiarizares-te e adotares os verbos padrão vai melhorar a tua programação em PowerShell.

Para veres uma lista de todos os verbos aprovados, basta executar:

```PowerShell
Get-Verb
```
