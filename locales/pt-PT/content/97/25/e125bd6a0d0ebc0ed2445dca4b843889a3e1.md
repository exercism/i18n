# Sobre

Todos os programas que já executaste, quer seja um jogo, um navegador web ou uma aplicação de telemóvel, acabam por ser uma longa lista de instruções muito pequenas que o processador executa uma de cada vez.
É com a linguagem assembly que escreves essas instruções.
Em vez de variáveis, listas e ciclos `for`, trabalhas com os blocos de construção do próprio processador: um pequeno conjunto de registos, endereços de memória e saltos de uma instrução para outra.

O RISC-V (pronuncia-se "risk five") é uma arquitetura de processadores que teve início na Universidade da Califórnia, em Berkeley, em 2010.
Ao contrário da maioria das arquiteturas de processadores, é uma norma aberta: ninguém tem de pagar ou pedir autorização para construir um chip RISC-V, e a especificação está disponível gratuitamente para qualquer pessoa ler.
Encontram-se chips RISC-V em microcontroladores, computadores de placa única, dispositivos de armazenamento e muito mais.

O RISC-V é uma boa primeira linguagem assembly porque foi concebido para ser simples.
As suas instruções seguem um pequeno número de padrões regulares, e os seus 32 registos têm funções claras e consistentes, por isso há muito menos para memorizar do que com os processadores da maioria dos portáteis.
Essa simplicidade é também a razão pela qual muitas universidades usam hoje o RISC-V para ensinar como funcionam os computadores.

Aqui está um pequeno exemplo, uma função que soma dois números:

```riscvasm
add_numbers:
        add     a0, a0, a1      /* a0 = a0 + a1 */
        ret                     /* return to the caller, with the answer in a0 */
```

Neste percurso escreves assembly RISC-V de 32 bits.
Não precisas de nenhum hardware RISC-V: os teus programas são testados num emulador, que finge ser um processador RISC-V.
Podes resolver os exercícios no editor online, ou no teu próprio computador com ferramentas gratuitas.

Aprender assembly exige paciência, mas compensa.
Depois de veres como um ciclo ou uma chamada de função se apresentam ao processador, todas as outras linguagens de programação passam a fazer um pouco mais de sentido.
