# Introdução

Para além das classes de carateres e dos quantificadores, as expressões regulares conseguem descrever *estrutura* e *contexto*. Estas funcionalidades fazem parte do mesmo vocabulário [`regexp`][regexp] e do mesmo literal `R/ /`.

Os parênteses curvos `( )` agrupam parte de um padrão, para que um quantificador ou um `|` («isto ou aquilo») se aplique ao grupo inteiro; um `?` depois de um grupo torna-o opcional:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

As âncoras fixam um padrão numa posição: `^` (início), `$` (fim) e `\b` (um limite de palavra).

Um *lookaround* faz a correspondência com base no que rodeia um ponto, sem o consumir:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

Uma letra de opção depois do `/` final altera o padrão todo; o `i` faz com que não distinga maiúsculas de minúsculas:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

O Factor usa *lookaround* em vez de grupos de captura: não tem extração de grupos de captura, retrorreferências nem quantificadores preguiçosos.
