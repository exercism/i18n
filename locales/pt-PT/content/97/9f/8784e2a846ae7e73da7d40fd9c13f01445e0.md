# Adenda às instruções

## Implementação

Para completar este exercício, tens de criar o tipo de dados `LinkedList` e implementar as seguintes funções:

- `new`
- `cons`
- `nil`
- `fromList`
- `head`
- `tail`
- `isNil`
- `reverseLinkedList`
- `toList`

Vais encontrar já no código uma declaração de tipo provisória e as assinaturas de tipo, mas cabe-te a ti definir as funções e criar um tipo de dados que faça sentido.
