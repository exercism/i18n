# Instruções

Neste exercício, vais escrever código para te ajudar a preparar a compra de um veículo.

Tens três tarefas: uma para determinar se precisas de carta de condução, outra para te ajudar a escolher entre dois veículos e outra para estimar o preço aceitável de um veículo usado.

## 1. Determinar se vais precisar de carta de condução

Alguns tipos de veículos exigem carta de condução para serem conduzidos.
Assume que só os tipos `"car"` e `"truck"` exigem carta, tudo o resto pode ser conduzido sem carta.

Implementa a função `needs_license(kind)`, que recebe o tipo de veículo como string e devolve um Boolean a indicar se precisas de carta de condução para esse tipo de veículo.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. Escolher entre dois veículos possíveis para comprar

Avalias as tuas opções de veículos disponíveis.
Consegues reduzi-las a duas opções, mas precisas de ajuda para tomar a decisão final.
Para isso, implementa a função `choose_vehicle(option1, option2)`, que recebe dois veículos como argumentos e devolve uma decisão que inclui a opção que vem primeiro na ordem lexicográfica.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

A string devolvida deve seguir o padrão "<CHOSEN_VEHICLE> is clearly the better choice.", em que `<CHOSEN_VEHICLE>` é a opção escolhida de entre os argumentos recebidos.

## 3. Calcular uma estimativa para o preço de um veículo usado

Agora que já tomaste uma decisão, queres garantir que consegues um preço justo no concessionário.
Como estás interessado em comprar um veículo usado, o preço depende da idade do veículo.
Para uma estimativa aproximada, assume que, se o veículo tiver menos de 3 anos, custa 80% do preço original que tinha quando era novo.
Se tiver pelo menos 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos mas menos de 10, custa 70% do preço original.

Implementa a função `calculate_resell_price(original_price, age)` que aplica esta lógica com `if`, `else if` e `else` (há outras formas, se quiseres praticar).
Recebe o preço original e a idade do veículo como argumentos e devolve o preço estimado no concessionário.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> Nota: o valor devolvido é do tipo `double`.
