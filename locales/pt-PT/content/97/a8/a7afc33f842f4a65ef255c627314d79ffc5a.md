# Anexo às instruções

## Informações específicas do Arturo

Neste exercício, espera-se que devolvas as idades através de uma [grandeza física][physical-quantities] com uma unidade personalizada que representa a duração de um ano nesse planeta.
Em Arturo, uma quantidade é composta por um valor numérico e por uma [unidade de medida][unit-of-measurement] associada.

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
A unidade `yr incorporada no Arturo converte-se em 31556952 segundos.
Por isso, vais ter de definir e usar a tua própria unidade de ano com base no número de segundos mencionado anteriormente nas instruções.
~~~~

As quantidades podem ser [convertidas][convert] para outra unidade compatível.
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
Devido às limitações de precisão dos números de vírgula flutuante, o Arturo guarda por vezes o escalar como um número racional.
A função [`to`][to] pode ser usada para obter o valor como um número de vírgula flutuante aproximado.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

O Arturo também nos permite [especificar][specify] as nossas próprias unidades para as quantidades.

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
