# Ferramentas para contribuidores

Os estudantes precisam apenas das ferramentas indicadas em [INSTALLATION.md](INSTALLATION.md).
Os contribuidores precisam de mais algumas, porque os scripts do percurso as usam:

- `git`, para clonar o repositório e abrir pull requests.
- `jq`, usado por `bin/verify-exercises` e `bin/add-practice-exercise`.
- `curl`, usado por `bin/fetch-configlet`.
- Python 3.11 ou posterior, para o gerador de testes.
- `clang-format`, que o gerador de testes executa nos ficheiros que escreve.
- `pre-commit`, que executa as verificações do repositório antes de cada commit.

Instala-as com o comando da tua distribuição e depois segue os passos em «Configurar o repositório».

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## Configurar o repositório

A partir da raiz do repositório:

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
