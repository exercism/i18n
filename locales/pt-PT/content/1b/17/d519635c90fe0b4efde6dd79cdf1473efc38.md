# Instruções

Neste exercício, vais escrever um programa para te ajudar a preparar-te para comprar um veículo.

Tens duas tarefas: determinar se vais precisar de tirar a carta de condução e estimar o preço aceitável para um veículo usado.

## 1. Determina se vais precisar de carta de condução

Alguns tipos de veículos exigem carta de condução para os conduzir.
Assume que só os veículos que contêm `car` ou `truck` exigem carta; todos os outros podem ser conduzidos sem carta.

Implementa um par `pattern {action}` que corresponda quando o primeiro campo é `needs_license`.
Deve obter o tipo de veículo a partir do segundo campo e imprimir "true" se precisares de carta para esse tipo de veículo.
Se não precisares de carta, não precisas de imprimir nada.

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. Calcula uma estimativa para o preço de um veículo usado

Agora que já tomaste a tua decisão, queres garantir que consegues um preço justo no concessionário.
Como estás interessado em comprar um veículo usado, o preço depende da idade do veículo.
Para uma estimativa aproximada, assume que, se o veículo tiver menos de 3 anos, custa 80% do preço original que tinha quando era novo.
Se tiver mais de 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos mas não mais de 10 anos, custa 70% do preço original.

Implementa um par `pattern {action}` que corresponda quando o primeiro campo é `resell_price`.
Deve obter o preço original do veículo a partir do segundo campo e a idade a partir do terceiro campo.
A ação deve imprimir o preço estimado.

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
