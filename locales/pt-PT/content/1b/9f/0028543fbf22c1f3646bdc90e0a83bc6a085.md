# Introdução

As expressões regulares em Elixir seguem a especificação **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), tal como outras linguagens populares como Java, JavaScript ou Ruby.

O módulo `Regex` oferece funções para trabalhar com expressões regulares. Algumas das funções do módulo `String` também aceitam expressões regulares como argumentos.

~~~~exercism/note

## Sigilos

A forma mais comum de criar expressões regulares é usar o sigilo `~r`.

```elixir
~r/test/
```

Repara que todos os sigilos de Elixir suportam [diferentes tipos de delimitadores][sigils], não apenas `/`.

## Correspondência

O operador `=~/2` pode ser usado para fazer uma correspondência de expressão regular que devolve um resultado `boolean`. Em alternativa, também existem funções `match?/2` no módulo `Regex` e no módulo `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## Captura

Se uma simples verificação boolean não for suficiente, usa a função `Regex.run/3` para obter uma lista com todas as capturas (ou `nil` se não houver correspondência). O primeiro elemento da lista devolvida é sempre a correspondência com a expressão regular completa, e os elementos seguintes são os grupos correspondidos.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## Modificadores

O comportamento de uma expressão regular pode ser modificado acrescentando flags especiais. Quando usas um sigilo para criar uma expressão regular, acrescenta os modificadores depois do segundo delimitador.

Os modificadores mais comuns são:
- `i` - faz com que a correspondência não distinga maiúsculas de minúsculas.
- `u` - ativa padrões específicos de Unicode como `\p` e faz com que classes de carateres como `\w`, `\s`, etc. também correspondam a Unicode.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
