# Anexo às instruções

## Sobre Enum

A instrução enum permite-te criar um conjunto de rótulos fortemente tipado.
Podes usar essa enumeração no código sem precisares de fazer análise sintática nem de verificar se há erros ortográficos.

As enumerações são representadas internamente como números inteiros, com um valor inicial de zero.
Por predefinição, o PowerShell atribui ao primeiro rótulo da lista o valor zero e atribui aos restantes rótulos números inteiros consecutivos.

Exemplo:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

Para saberes mais sobre o Enum no PowerShell, consulta o [módulo Enum.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)
