# Testes

Escolhe o teu sistema operativo atual:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# Correr os testes

## Windows

1. Abre a Command Prompt.

2. Obtém o primeiro exercício:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. Muda de diretório para a pasta do exercício:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. Corre os testes:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(Não te preocupes se os testes falharem na primeira vez que os corres, é assim que começas cada exercício.)*

5. Resolve o exercício. 
    Lê o `instructions.md` e vê como resolver o exercício ([ver no GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Boa sorte, diverte-te e bem-vindo à track COBOL!

----

## macOS

1. Abre uma janela do Terminal.

2. Obtém o primeiro exercício:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. Muda de diretório para a pasta do exercício:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. Corre os testes:

    ```
     $ bash test.sh
    ```
    *(Não te preocupes se os testes falharem na primeira vez que os corres, é assim que começas cada exercício.)*

    Dica: se receberes uma mensagem a dizer que falta o `basename`, podes usar o [brew](https://brew.sh/) para instalar o coreutils. (`brew install coreutils`)

5. Resolve o exercício. 

    Lê o `instructions.md` e vê como resolver o exercício ([ver no GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Boa sorte, diverte-te e bem-vindo à track COBOL!
