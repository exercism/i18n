# Condicionais

O Crystal tem aquilo a que se chamam expressões de controlo. Estas servem para controlar a forma como o programa corre e recebem um valor verdadeiro ou falso.
Existem operadores que podem ser usados para criar valores verdadeiros ou falsos; são os [operadores de igualdade e de comparação][equality-and-comparison].

Há duas expressões de controlo principais que determinam qual o código que vai correr e qual não vai.
Ou seja, qual o ramo que vai ser executado.

Essas duas são: a expressão `if` e a expressão `unless`.

## Operadores de comparação

Os operadores de comparação servem para comparar valores e devolvem um valor `true` ou `false`.
Estes operadores exigem que os dois valores comparados sejam do mesmo tipo.
Se os valores não forem do mesmo tipo, o compilador dá um erro.
Aqui está uma lista dos operadores de comparação e um exemplo de quando dão um valor `true`:

| Método | Descrição             | Exemplo |
| ------ | --------------------- | ------- |
| <      | menor que             | 4 < 5   |
| <=     | menor ou igual        | 4 <= 4  |
| >      | maior que             | 3 > 1   |
| >=     | maior ou igual        | 2 >= 2  |

## Operadores de igualdade

Os operadores de igualdade são semelhantes aos operadores de comparação, mas servem para verificar se dois valores são iguais ou não.

O operador `==` verifica se dois valores são iguais, incluindo o tipo do valor.
Se os valores forem iguais, devolve `true`; caso contrário, devolve `false`.
O operador `==` pode comparar qualquer tipo de valor com qualquer outro tipo de valor.
O `!=` funciona da mesma forma, mas devolve `true` se os valores não forem iguais e `false` se forem iguais.

## Operador nave espacial

O operador nave espacial é um operador de comparação especial, e o seu nome deriva da sua aparência.
É especial porque não devolve um valor verdadeiro ou falso, mas sim um número.
Escreve-se `<=>` e serve para comparar dois valores.
Devolve `1` se o valor da esquerda for maior que o da direita, `-1` se o valor da esquerda for menor que o da direita e `0` se os valores forem iguais.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## A condicional `if`

A condicional [`if`][if] serve para verificar se uma determinada condição é verdadeira ou falsa.
Se a condição for verdadeira, o código dentro da condicional `if` é executado.
Uma condicional `if` termina com a palavra-chave `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## A condicional `unless`

A condicional [`unless`][unless] funciona de forma muito semelhante à condicional `if`, mas executa o código que está dentro dela se a condição for falsa.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## A condicional `else`

A condicional `else` pode ser usada em conjunto com as condicionais `if` e `unless`.
A condicional `else` é executada se o ramo do `if` ou o ramo do `unless` não for executado.

~~~~exercism/warning
Embora se possa usar um ramo `else` em conjunto com `unless,` isso é desaconselhado, porque prejudica a legibilidade.
Em vez disso, recomenda-se usar `if !condition` com um ramo `else`.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## Condicionais em cascata

A condicional `elsif` pode ser usada em conjunto com a condicional `if`.
A condicional `elsif` é executada se o ramo do `if` não for executado e a condição da condicional `elsif` for verdadeira.
As condicionais `elsif` podem ser encadeadas e será executada a primeira condição verdadeira.
Pode também haver uma condicional `else` no fim da condicional `if`, que corre se nenhuma das anteriores tiver sido verdadeira.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## Operador ternário

O Crystal tem um operador ternário, uma condicional if-else numa só linha: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## if e unless como sufixo

A condicional `if` e a condicional `unless` também podem ser usadas como [sufixo][if-as-suffix]. Isto é útil quando queres executar uma única linha de código se uma condição for verdadeira.
Faz-se colocando a condicional `if` ou `unless` depois do código que queres executar.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## Tipos com condicionais

Quando é atribuída a tipos diferentes, a variável fica com os dois tipos.
Isto acontece porque o compilador não sabe qual o ramo que vai ser executado.
Esta atribuição múltipla, também conhecida como união, será explicada em conceitos posteriores.
Podes ver isto no exemplo seguinte:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
