# Instruções

Implementa um sistema reativo básico.

A programação reativa é um paradigma de programação que se centra na forma como os valores são calculados em função uns dos outros, para que a alteração de um valor se propague automaticamente aos restantes, como acontece numa folha de cálculo.

Implementa um sistema reativo básico com células cujos valores podes definir («células de entrada») e células com valores calculados em função de outras células («células de cálculo»).
Implementa as atualizações de modo a que, quando um valor de entrada muda, os valores se propaguem até se atingir um novo estado estável do sistema.

Além disso, as células de cálculo devem permitir o registo de callbacks de notificação de alterações.
Chama os callbacks de uma célula quando o valor dessa célula num novo estado estável tiver mudado em relação ao estado estável anterior.
