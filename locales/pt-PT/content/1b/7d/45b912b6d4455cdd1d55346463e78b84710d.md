# Ajuda

Sítios onde podes procurar ajuda para questões de AWK:

* [Etiqueta `awk` do Stack Overflow][so].
* consulta a secção Resources da [página de informações da etiqueta `awk` do Stack Overflow][so-info].
* abre um problema no repositório Github [exercism/awk][github].
* IRC: `irc://irc.liberachat.net/#awk`, `irc://irc.liberachat.net/#exercism`
    * vê o [Libera.chat][libera] se não estiveres familiarizado com o IRC.
