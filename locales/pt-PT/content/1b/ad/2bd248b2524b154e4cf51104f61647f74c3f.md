# Marcador de posição

## Funções de tempo

Este exercício exige a utilização das [Funções de tempo][time-func] do GNU awk.

Nas funções de análise e formatação de datas e horas, certifica-te de que **defines o sinalizador UTC**.
Para demonstrar:

```sh
export TZ=Asia/Kolkata
gawk 'BEGIN {
    time = 1234567890
    print strftime("%Y-%m-%d %T", time)     # format for local timezone
    print strftime("%Y-%m-%d %T", time, 1)  # format for UTC
}'
```

produz:

```none
2009-02-14 05:01:30
2009-02-13 23:31:30
```

[time-func]: https://www.gnu.org/software/gawk/manual/html_node/Time-Functions.html
