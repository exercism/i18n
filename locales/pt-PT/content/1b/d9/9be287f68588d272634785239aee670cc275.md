# Dicas

## 1. Cria uma nova lista

- Podes criar uma lista vazia usando a sintaxe `[]`.

## 2. Define uma lista existente

- Podes criar listas com vários elementos usando a sintaxe `["a", "b", "c"]`.

## 3. Adiciona uma nova linguagem a uma lista

- Podes usar a sintaxe de expansão (`[x, ..list]`) para adicionar um elemento ao início de uma lista.

## 4. Conta as linguagens na lista

- Existe uma função no módulo `gleam/list` para [contar os elementos de uma lista][length].

## 5. Inverte a lista

- Existe uma função no módulo `gleam/list` para [inverter uma lista][reverse].

## 6. Verifica se a lista é entusiasmante

- Podes usar correspondência de padrões, com os padrões de lista e de expansão de listas, para corresponder a estruturas de lista específicas.

[reverse]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#reverse
[length]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#length
