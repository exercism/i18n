# sem literais de números inteiros

O Elixir tem uma [sintaxe especial](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html#unicode-and-code-points) para escrever números inteiros que correspondem a [pontos de código Unicode](https://en.wikipedia.org/wiki/Code_point): podes usar um `?` antes do caráter para revelar o seu ponto de código.

Por exemplo,

```elixir
?a === 97
?\s === 32
?ß === 223
?互 === 20114
```

No contexto da manipulação de pontos de código, esta notação é muito mais legível do que os números, por isso deves preferi-la sempre.
