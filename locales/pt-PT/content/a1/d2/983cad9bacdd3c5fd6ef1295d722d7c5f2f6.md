# Introdução

## Definir variáveis

Definir uma variável significa atribuir um valor a um nome. Em Scala existem dois tipos de variáveis, os val e os var.

Um `val` é imutável, por isso o seu valor não pode ser alterado depois da primeira atribuição:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

Um `var`, por oposição, pode ser reatribuído com um novo valor do mesmo tipo:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala é uma linguagem de tipos estáticos, o que significa que tudo tem um tipo em tempo de compilação. Uma variável pode ser definida indicando explicitamente o seu tipo, ou deixando o compilador de Scala inferir o tipo com base no valor atribuído (a chamada inferência de tipos). Por isso, as duas definições de variável seguintes são equivalentes:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

Depois de definida, o tipo de uma variável nunca pode mudar.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## Definir métodos dentro de classes

Scala é uma _linguagem orientada a objetos_ e exige que todos os métodos sejam definidos dentro de uma _classe_. A palavra-chave `class` serve para definir uma classe.

```scala
class Calculator {
  // ...
}
```

Dentro de uma classe, os métodos podem ser definidos começando pela palavra-chave `def` seguida de um nome. Cada método pode ter zero ou mais parâmetros, que são listados separados por vírgulas dentro de parênteses. Todos os parâmetros têm de ter o tipo indicado explicitamente; não existe inferência de tipos para parâmetros. A seguir à lista de parâmetros, indica-se o tipo devolvido pelo método, separado por dois pontos.

Depois da definição do método vem um sinal `=`, que dá início ao corpo do método. No exemplo seguinte, o corpo do método é composto por duas instruções, envolvidas por chavetas.

O método devolve o valor da última expressão; neste caso, o método `add` devolve o valor da variável `sum`:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

Há algumas melhorias que se podem fazer para encurtar esse método e melhorar a legibilidade:

- como a variável `sum` só é usada uma vez, para devolver o valor, pode ser omitida
- os métodos compostos por uma única instrução não precisam de chavetas
- o tipo devolvido pelo método pode ser inferido tal como o tipo de uma variável

Isso dá origem ao seguinte método de uma só linha, com a mesma funcionalidade:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## Instanciar classes e chamar métodos

Para invocar um método, começa-se por criar uma instância de uma classe e depois chama-se o método nessa instância, com argumentos:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Comentários

Scala suporta dois tipos de comentários, comentários de uma só linha e comentários com várias linhas:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
