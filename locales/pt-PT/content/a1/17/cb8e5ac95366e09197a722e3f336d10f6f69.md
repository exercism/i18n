# Instruções

Vais ajudar namorados do secundário a declarar o seu amor nas redes
sociais, gerando um coração unicode com as iniciais do casal:

```
❤ J.  +  M. ❤
```

## 1. Limpa o nome

Define `cleanupname`, que recebe um nome da pilha. Substitui cada `-`
por um espaço e depois retira os espaços em branco no início e no fim.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. Obtém a primeira letra do nome

Define `firstletter`, que recebe um nome. Reutiliza `cleanupname` da
tarefa anterior, obtém o primeiro caráter do resultado e devolve-o como
uma string de um único caráter.

```factor
"Jane" firstletter .
! => "J"
```

## 3. Formata a primeira letra como inicial

Define `initial`, que recebe um nome. Reutiliza `firstletter` da tarefa
anterior, passa-a para maiúscula e acrescenta-lhe um `.`.

```factor
"Robert" initial .
! => "R."
```

## 4. Coloca as iniciais dentro do coração

Define `couple`, que recebe dois nomes da pilha. Reutiliza `initial` da
tarefa anterior em cada nome e depois monta o resultado:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
