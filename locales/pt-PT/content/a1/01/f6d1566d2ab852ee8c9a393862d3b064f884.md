# Dicas

## Geral

Este exercício leva-te a escrever filtros `jq` para quatro tarefas.
Como um programa `jq` é uma _única expressão_, esses quatro filtros têm de ser unidos com vírgulas.
Usa parênteses em torno das subexpressões para controlar a ordem das operações.

## 1. Extrair o nome da lista de compras

- Podes aceder ao conteúdo do ficheiro com o filtro `.`.
- Podes aceder a uma propriedade de um objeto com notação de ponto ou com notação de parênteses retos.

## 2. Contar quantos ingredientes são necessários

- Tens de produzir o comprimento de um array.

## 3. Quanto açúcar?

- Tens de selecionar o ingrediente com o nome "sugar".
- Tens de aceder a uma das suas propriedades.

## 4. Mapear os ingredientes que podem ser substituídos

- Tens de concatenar dois arrays.
- Tens de selecionar elementos específicos do array resultante.
- Tens de gerar um objeto chave:valor para cada um desses elementos.
- Tens de combinar estes objetos num único objeto.
