# Instruções

Estás a gerir um sistema que consiste em algumas aplicações que produzem muitos logs. Queres escrever um pequeno programa que agregue esses logs e lhes atribua rótulos de acordo com o seu nível de gravidade. Todas as aplicações no teu sistema usam os mesmos códigos de log, mas algumas das aplicações legacy não suportam todos os códigos.

| Código de log | Rótulo de log | Suportado em aplicações legacy? |
|---------------|---------------|--------------------------------|
| 0             | trace         | não                            |
| 1             | debug         | sim                            |
| 2             | info          | sim                            |
| 3             | warning       | sim                            |
| 4             | error         | sim                            |
| 5             | fatal         | não                            |
| outro / não suportado | unknown | -                        |

## 1. Determinar o rótulo de log

Implementa a função `LogLevel.to_label/2`. Deve receber um código inteiro e um sinalizador booleano que te indica se o log vem de uma aplicação legacy, e devolver o rótulo de uma linha de log como um átomo.

Os códigos de log não especificados na tabela devem devolver um rótulo _unknown_. Os códigos de log especificados na tabela como não suportados em aplicações legacy também devem devolver um rótulo _unknown_ se o log vier de uma aplicação legacy.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Enviar um alerta

É preciso notificar alguém quando acontecem coisas inesperadas.

Implementa a função `LogLevel.alert_recipient/2` para determinar a quem o alerta deve ser enviado. A função deve receber um código inteiro e um sinalizador booleano que te indica se o log vem de uma aplicação legacy, e devolver o nome do destinatário como um átomo.

Usa a função `LogLevel.to_label/2` da tarefa anterior. Se o rótulo do log for _error_ ou _fatal_, envia o alerta para a equipa de _ops_. Se receberes um log com um rótulo _unknown_ de um sistema legacy, envia o alerta para a equipa _dev1_, outros rótulos unknown devem ser enviados para a equipa _dev2_. Todos os outros rótulos de log podem ser ignorados em segurança devolvendo _false_.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
