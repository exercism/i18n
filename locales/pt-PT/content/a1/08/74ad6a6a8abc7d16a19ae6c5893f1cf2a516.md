# Anexo às instruções

Escreve por cima da string do número de telefone fornecida.
Se o número de telefone for inválido, substitui-o por uma string vazia.

## Registos

| Registo | Utilização    | Tipo     | Descrição                                        |
| -------- | ------------- | -------- | ------------------------------------------------ |
| `$a0`    | entrada/saída | endereço | número de telefone como string terminada em nulo |
| `$t0-9`  | temporário    | qualquer | utilizado para armazenamento temporário          |
