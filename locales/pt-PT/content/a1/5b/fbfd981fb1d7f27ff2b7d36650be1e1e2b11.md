# Testes

## Executar os testes

Depois de concluíres os [passos de instalação][test-installation-steps], podes começar a partir de qualquer diretório de exercício (por exemplo, `~/exercism/gdscript/two-fer`) e executar o script (que está um nível acima, em `../`) para testar a tua solução local desse exercício:

```sh
../test-local-gdscript-solution.sh
```

## Resolver um exercício

Resolver um exercício significa fazer passar todos os seus testes.

Para te ajudar a começar, cada exercício vem com um ficheiro GDScript com o nome do exercício (por exemplo, `exercism/gdscript/two-fer/two_fer.gd`).
Podes usar este ficheiro como ponto de partida para construir a tua solução.
Podes alterá-lo à vontade conforme for necessário, mas os testes esperam que os nomes das funções sejam os que foram fornecidos originalmente.

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
