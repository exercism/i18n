# Testes

## Executar os testes

Executa a especificação de testes com:

```bash
$ gradle test
```

## Ativar mais testes

Assim que o teu código passar em todos os testes ativos, ativa outro teste removendo o `@Ignore` que precede o próximo teste que te interessa. Faz isto eliminando a linha `@Ignore` ou comentando-a, adicionando duas barras no início da linha.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
