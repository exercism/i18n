# Introdução

Em Kotlin, as classes permitem encapsular dados e comportamento.
Uma classe declara-se com a palavra-chave `class`.
Por exemplo:

```kotlin
class Car
```

Cria uma instância da classe chamando-a.

```kotlin
val instance = Car()
```

## Propriedades

Nos exemplos acima, a classe `Car` foi declarada sem quaisquer propriedades.
As propriedades da classe podem ser declaradas no corpo, entre `{}`, usando `var` para as propriedades mutáveis e `val` para as imutáveis.
Por exemplo:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

Em alternativa, as propriedades podem ser definidas num construtor que as recebe.

## Construtores

O Kotlin tem dois tipos de construtores: primários e secundários.
O construtor primário é declarado na mesma linha que a declaração da classe.
Por exemplo:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

A palavra-chave `constructor` pode ser omitida se não houver anotações nem modificadores de visibilidade:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Quando a classe só tem propriedades, o Kotlin permite defini-la sem corpo, sem necessidade de chavetas `{}`:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

Uma classe só pode ter um construtor primário.
Os construtores secundários são construtores adicionais, que podem ser acrescentados declarando-os no corpo da classe com a palavra-chave `constructor`.
Por exemplo:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

Os construtores secundários têm de invocar o construtor primário chamando `this`.

## Blocos de inicialização

O construtor primário define as propriedades da classe.
Se for preciso fazer mais alguma coisa durante a criação do objeto, podes usar blocos `init` para realizar ações adicionais.

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## Funções

As funções podem ser definidas no corpo da classe.
Por exemplo:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## Visibilidade

As propriedades e as funções podem ser `private`, `public`, `internal` ou `protected`.

- `private`: o acesso só é possível dentro da classe
- `protected`: o acesso é possível a partir de elementos da própria classe e também de quaisquer subclasses
- `internal`: o acesso é possível a partir de elementos do mesmo módulo
- `public`: o acesso é possível a partir de outros componentes que usem a classe

Por exemplo:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
