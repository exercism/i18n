# Sobre

Uma [instrução `switch`][switch] compara um valor com vários padrões possíveis.
É uma alternativa mais limpa e legível a encadear várias instruções `if-else`.

Uma instrução `switch` começa com a palavra-chave `switch`, seguida do valor a testar.
Cada correspondência possível é introduzida pela palavra-chave `case`.
A palavra-chave `default` define um caso de recurso que é executado se nenhum dos casos explícitos corresponder.
Tal como as cadeias `if-else`, uma instrução `switch` só executa o bloco de código associado ao primeiro caso que corresponde.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera a seguinte cadeia `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Isto pode ser escrito de forma mais clara com uma instrução `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Vinculação de valores e cláusulas `where`

Um caso de `switch` pode associar os valores correspondidos a constantes ou variáveis temporárias, para usares no corpo desse caso.
Os casos também podem incluir uma cláusula `where`, que verifica condições Boolean adicionais antes de corresponderem:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
