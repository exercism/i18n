# Executar os testes

Escolhe o teu sistema operativo:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Abre o Command Prompt.
2. Obtém o primeiro exercício:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Muda para o diretório do exercício:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Executa os testes:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Não te preocupes se os testes falharem ao início, é assim que começas cada exercício.)_

5. Resolve o exercício. Encontra e segue o guia `instructions.append.md` ([ver no GitHub][hello-world-tutorial]).

Boa sorte! Diverte-te!

## macOS

1. Na janela do terminal, obtém o primeiro exercício:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Muda para o diretório do exercício:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. Executa os testes:

   ```sh
   ./gradlew test
   ```

   _(Não te preocupes se os testes falharem ao início, é assim que começas cada exercício.)_

4. Resolve o exercício. Encontra e segue o guia `instructions.append.md` ([ver no GitHub][hello-world-tutorial]).

Boa sorte! Diverte-te!

## Linux

1. Na janela do terminal, obtém o primeiro exercício:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Muda para o diretório do exercício:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. Executa os testes:

   ```sh
   ./gradlew test
   ```

   _(Não te preocupes se os testes falharem ao início, é assim que começas cada exercício.)_

   Se receberes o seguinte erro:

   ```sh
   ./gradlew: Permission denied
   ```

   Então falta ao ficheiro a permissão de execução. Para corrigir isto, executa:

   ```sh
   chmod +x ./gradlew
   ```

   E agora já deves conseguir executar o comando anterior.

4. Resolve o exercício. Encontra e segue o guia `instructions.append.md` ([ver no GitHub][hello-world-tutorial]).

Boa sorte! Diverte-te!
