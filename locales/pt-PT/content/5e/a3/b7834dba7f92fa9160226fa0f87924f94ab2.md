# Dicas

## Geral

- Consulta a [referência da linguagem para arrays][ref-arrays]
- Consulta a [referência das funções para arrays][ref-array-functions]

## 1. Define uma função que devolve uma lista de linguagens vazia

- Consulta a [referência da linguagem][ref-arrays]
- Podes devolver um array vazio

## 2. Altera a função para criar uma lista a partir de qualquer número de linguagens

- Consulta a referência das funções para [argumentos de comprimento variável][variable-arguments]

## 3. Define uma função para adicionar uma linguagem à lista

- Cria uma nova função para realizar a operação
- Reutiliza uma [função existente][ref-array-functions] ou usa a [sintaxe de inserção][square-bracket-syntax]

## 4. Define uma função para remover um item da lista de linguagens

- Cria uma nova função para realizar a operação
- Reutiliza uma [função existente][ref-array-functions] para realizar a operação

## 5. Define uma função para obter o primeiro item da lista

- Cria uma nova função para realizar a operação
- Usa a [sintaxe de índice][index-syntax] para obter o primeiro elemento

## 6. Define uma função que devolve quantas linguagens há na lista

- Cria uma nova função para realizar a operação
- Reutiliza uma [função existente][ref-array-functions] para realizar a operação
