# Introdução

`when` é a palavra-chave para filtrar exceções. Coloca-se depois da instrução catch e pode receber uma expressão Boolean que contenha quaisquer valores que estejam no âmbito nesse momento. Se a expressão for avaliada como true, executa-se o bloco associado a essa instrução `catch`; caso contrário, verifica-se a instrução `catch` seguinte, se existir.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
