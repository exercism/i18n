# Referência de Rust

## Conceitos

Os exercícios de conceitos de Rust ensinam conceitos desde os fundamentos até ao domínio da linguagem. Estão classificados e listados abaixo.

Os conceitos do Exercism existem para servir quem aprende de formas práticas, por isso diferem das ideias abstratas. Este documento define o que estes conceitos significam em Rust. Adicionámos abaixo um agrupamento visual para ajudar quem mantém uma track a criar um documento de referência eficaz. Esses agrupamentos _não_ constituem divisões pedagógicas. Por isso, não os uses como referência quando ensinas.

As caixas de seleção indicam se os conceitos já são ensinados na lista de mapeamento de exercícios.

## Mapeamento de exercícios de conceitos

Embora o ideal seja ter um único exercício de conceitos para cada um dos conceitos listados acima, que ensine exatamente um conceito e exija apenas os seus pré-requisitos, fazê-lo não é totalmente prático. Por exemplo, seria difícil conceber um exercício que ensinasse o que são funções sem exigir qualquer conhecimento de primitivos; do mesmo modo, seria difícil ensinar primitivos, com um conjunto de testes, sem qualquer conhecimento de funções.

Os exercícios desta tabela devem formar um DAG que acabará por cobrir todos os conceitos listados acima.

| exercício                | pré-requisitos                               | ensina                                                   | narrativa |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | funções, conjuntos de testes                             | devolve o literal `&str` `"hello world"` |
| `compiled-calculator`    | `hello-world`                                | inteiros, atribuição de variáveis                        | realiza um conjunto de operações matemáticas e devolve o resultado implicitamente |
| `conditionals`           | `hello-world`                                | condicionais                                             | deve ser estruturado com três ramos `if` / `else if` / `else`; devolução implícita |
| `slices`                 | `hello-world`, `compiled-calculator`         | slices                                                   | extrai uma slice de um parâmetro que é uma slice de inteiros |
| `loops`                  | `slices`                                     | iteração básica sobre uma slice                          | de preferência com devolução antecipada, para que seja complicado exprimi-lo como um iterador |
| `iterator-use`           | `slices`                                     | utilização de iteradores, `collect`                      |
| `integer-sizes`          | `compiled-calculator`                        | inteiros que não sejam `i32`, conversão de tipos         | continuam todos com sinal |
| `unsigned-ints`          | `integer-sizes`                              | inteiros sem sinal                                       |
| `indexing`               | `integer-sizes`, `slices`                    | indexação, `usize`                                       |
| `floats`                 | `compiled-calculator`                        | números de vírgula flutuante                             | provavelmente o mesmo exercício da calculadora compilada, com resultados não inteiros |
| `bools`                  | `compiled-calculator`                        | Boolean, operadores booleanos                            |
| `char`                   | `compiled-calculator`                        | tipo de dados `char`                                     | deve incluir alguns exemplos de carateres largos |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | nota: imutável! |
| `string-use`             | `str-use`                                    | `String`                                                 | nota: com ownership, mutável |
| `format-macro`           | `string-use`                                 | macro `format!`                                          |
| `str-vs-string`          | `str-use`, `string-use`                      | combinação, conversão, custos, etc.                      |
| `generics-basics`        | `integer-sizes`, `floats`                    | usar traits externas como limites, noções básicas de genéricos | provavelmente ainda a calculadora compilada, mas genérica |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | criar e usar uma estrutura para gerir dados              | `Person` tem nome, altura e quantidade de sapatos que possui |
| `implicit-return`        | `compiled-calculator`                        | âmbitos, expressões, devolução implícita                 |
| `explicit-return`        | `implicit-return`, `conditionals`            | instrução `return` explícita                             |
| `methods`                | `structs`, `explicit-return`                 | blocos `impl`, métodos                                   |
| `tuples`                 | `structs`                                    | tuplas                                                   | ensina como estruturas anónimas; ensina a sintaxe `.0` |
| `tuple-structs`          | `tuples`, `structs`                          | estruturas de tuplas (tuplas com nome)                   |
| `basic-enums`            | `unsigned-ints`                              | enumerações básicas (sem campos), `match`                |
| `enums`                  | `basic-enums`, `tuple-structs`               | sintaxe de tuplas para variantes de enumerações          |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | imutabilidade por omissão; mutabilidade explícita        |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | provavelmente só dependerá de `option` ou de `result`, consoante a implementação |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | API Entry                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | implementar uma trait manualmente                        | provavelmente implementa `Iterator` |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
