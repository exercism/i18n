# Sobre

[`fold`][fold] é um [adaptador de iterador consumível][consuming iterator adaptor] que aplica uma função a cada elemento da iteração, acumulando o resultado num novo valor.

Cada iteração de `fold` recebe dois argumentos. O primeiro é um valor inicial para o acumulador. O segundo é uma closure que, por sua vez, recebe dois argumentos: o acumulador e um item. O valor devolvido pela closure passa a ser o valor seguinte do acumulador.
Quando o iterador se esgota, é devolvido o valor final do acumulador.

Podes usar o `fold` quando queres transformar uma coleção num único valor. Por exemplo, se quiseres a soma de todos os números pares

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

Imprime `30`.

O que se pode fazer com o `fold` também se pode fazer, muitas vezes, com outra função ou conjunto de funções. No exemplo acima, usar [`filter`][filter] sobre `(1..=10)` e depois [`sum`][sum] seria menos verboso e daria o mesmo resultado, assim

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

Outras funções usadas com mais frequência do que o `fold` incluem [`product`][product] e [`collect`][collect].

Um acumulador não serve apenas para valores numéricos. Por exemplo

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

Imprime `FeeFiFoFum`
