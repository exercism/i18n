# Como testar no percurso MoonScript

Testar no percurso MoonScript é exatamente como [testar no percurso Lua][lua-tests].
A partir do diretório de um exercício, escreve:

```console
$ busted
```

## Testes pendentes

Este percurso segue a metodologia de [Desenvolvimento Orientado a Testes][tdd] do Exercism.
Recebes uma suite de testes completa, mas só o primeiro teste está "ativo".

Para ativares os testes, muda o comando de um teste de `pending` para `it`.

Se gostas de correr todos os testes o tempo todo, podes usar uma ferramenta de linha de comandos para os alterar todos de uma vez.
Eis um exemplo com perl (que está instalado em praticamente todo o lado):

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

Quando estás a trabalhar no editor online, o executor de testes corre automaticamente todos os testes.

## Usar o LuaRocks

O Lua, por si só, é uma linguagem muito pequena.
O [LuaRocks][luarocks] é o gestor de pacotes dos módulos de Lua.

Tens toda a liberdade para usar qualquer módulo nas tuas soluções, mas nem todos estarão disponíveis no executor de testes online.
O executor de testes disponibiliza estes:

**Já disponíveis como dependências do `busted`**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**Já disponíveis como dependências do MoonScript**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**Data e hora**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
