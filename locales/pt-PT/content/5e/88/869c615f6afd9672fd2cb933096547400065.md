# Instruções

És um observador de aves entusiasta que mantém uma contagem diária das aves que visitam o teu jardim. As contagens são guardadas num array, do dia mais antigo para o mais recente.

## 1. A contagem de hoje

Define `today` para retirar o array de contagens diárias da pilha e devolver a contagem de hoje.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Incrementa a contagem de hoje

Define `increment-todays-count` para devolver um novo array com a contagem de hoje aumentada em uma unidade. O array original não deve ser modificado.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. Houve algum dia sem aves?

Define `has-day-without-birds?` para devolver `t` se pelo menos um dia registou zero aves, caso contrário `f`.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Soma os primeiros dias

Define `count-for-first-days` para receber um array de contagens e um número `n`, e devolver a soma das primeiras `n` contagens.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Conta os dias movimentados

Um dia movimentado é aquele com cinco ou mais aves. Define `busy-days` para devolver o número de dias movimentados no array.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Preenche os dias em falta

Se não observaste todos os dias de um período de `n` dias, preenche os dias em falta no final com `0`. Define `pad-missing-days` para receber um array de contagens e um comprimento desejado `n`, e devolver um array com comprimento de pelo menos `n` cujas posições extra são `0`. As contagens existentes devem ser preservadas sem alterações; se o array recebido já tiver pelo menos `n` elementos, devolve-o sem alterações.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
