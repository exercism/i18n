# Dicas

## Geral

- O tuplo `plot`, os símbolos `registrations` e `next-id`, e o símbolo
  `not-found` já estão declarados no ficheiro do exercício.
- Para estado ao nível do módulo, usa `set-global`, `get-global` e
  `change-global`.

## 1. Abre o jardim e lista os seus registos

- `V{ } clone` é o valor inicial certo para `registrations`
  (faz sempre `clone` para que o literal não seja partilhado entre chamadas).
- `1 next-id set-global` define o contador.
- Para `list-registrations`, basta um único `registrations get-global`.

## 2. Regista um canteiro

- Lê primeiro o `next-id` e depois usa `plot boa` para construir o canteiro
  a partir do `id` e do `name`.
- Incrementa o contador com `next-id [ 1 + ] change-global`.
- O `push` (em [`sequences`][sequences]) acrescenta a um vetor no próprio
  local, o que é perfeito para `registrations get-global`.

## 3. Liberta um canteiro

- Uma definição `:: release ( id -- )` torna o `id` disponível dentro do
  predicado do filtro.
- `[ id>> id = ] reject` mantém todos os canteiros cuja fenda `id` *não*
  corresponde ao `id` local. Usa-o como corpo de um `change-global`.

## 4. Obtém um canteiro registado

- O `find` devolve `( index elt/f )`. O `nip` descarta o índice.
- `[ not-found ] unless*` substitui o símbolo quando não se encontra nada.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
