# Dicas

## Geral

- Para um nome poder ter vários tipos diferentes, tens de usar um [tipo de união][union-type].
- Para uma variável de instância poder ser usada numa expressão de controlo [`if var.is_a?(Type)`][if-is-a], primeiro tem de ser atribuída a uma variável local.

## 1. Definir uma palavra-passe

- Tens de definir uma classe com o nome `PasswordLock`.
- Tens de definir um método de inicialização que receba como argumento um `String`, um `Int32` ou um `Float64`.
- Tens de definir uma [variável de instância][instance-variable] `@password` que fica com o valor do argumento passado ao construtor.

## 2. Encriptar a palavra-passe

- Define um método de instância chamado `encrypt`.
- O método deve modificar a [variável de instância][instance-variable] `@password` para que fique encriptada.
- Para que um determinado ramo só possa ser executado se a variável for de um tipo específico, tens de usar o método [`is_a?`][is-a] numa expressão de controlo.

## 3. Verificar se uma palavra-passe está correta

- Podes usar métodos já definidos para encriptar a tentativa de palavra-passe fornecida.
