# Introdução

O vocabulário [`random`][random] do Factor disponibiliza uma palavra genérica, `random`, que se adapta ao seu argumento, além de auxiliares para baralhar e amostrar sequências.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

A `random` de um número inteiro `n` devolve um valor em `[0, n)`; a de uma sequência devolve um elemento aleatório. O `randomize` baralha no próprio local e o `sample` extrai elementos distintos.

Por omissão, estas palavras recorrem a um gerador global com semente do relógio do sistema. Para tornar os resultados reproduzíveis, instala um gerador com semente através de `<mersenne-twister>` (de [`random.mersenne-twister`][mt]) e de `with-random`:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
