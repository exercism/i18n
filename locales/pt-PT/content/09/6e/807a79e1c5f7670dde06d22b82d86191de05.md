# não escrever para a consola

Remove as funções que escrevem para a consola, porque os testes não precisam delas e tornam o código um pouco mais difícil de ler.

Normalmente, estas instruções são adicionadas para ajudar a fazer debug do código. No entanto, uma abordagem melhor é fazer debug do código ao correr um ou mais testes unitários. Isto tem a vantagem adicional de te poderes concentrar num caso de teste específico. Aqui estão alguns links que explicam como fazer debug de código Scala ao correr testes unitários em várias IDEs:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
