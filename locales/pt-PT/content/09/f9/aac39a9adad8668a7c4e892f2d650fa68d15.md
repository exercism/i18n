# Introdução

[Stringer][stringer-interface] é uma interface para definir o formato de string dos valores.

A interface é composta por um único método `String`:

```go
type Stringer interface {
    String() string
}
```

Os tipos que querem implementar esta interface têm de ter um método `String()` que devolva uma representação do tipo em string fácil de ler para uma pessoa.
O pacote [fmt][fmt-package] (e muitos outros) procura este método para formatar e imprimir valores.

## Exemplo: Distâncias

Imagina que estás a trabalhar numa aplicação que lida com distâncias geográficas medidas em unidades diferentes.
Definimos os tipos `DistanceUnit` e `Distance` da seguinte forma:

```go
type DistanceUnit int

const (
	Kilometer    DistanceUnit = 0
	Mile         DistanceUnit = 1
)

type Distance struct {
	number float64
	unit   DistanceUnit
}
```

No exemplo acima, `Kilometer` e `Mile` são constantes do tipo `DistanceUnit`.

Estes tipos não implementam a interface `Stringer`, porque não têm o método `String`.
Por isso, as funções de `fmt` imprimem os valores de `Distance` usando o "formato predefinido" do Go:

```go
mileUnit := Mile
fmt.Sprint(mileUnit)
// => 1
// The result is '1' because that is the underlying value of the 'Mile' constant (see constant declarations above)

dist := Distance{number: 790.7, unit: Kilometer}
fmt.Sprint(dist)
// => {790.7 0}
// not a very useful output!
```

Para tornar o resultado mais informativo, implementamos a interface `Stringer` para os tipos `DistanceUnit` e `Distance`, acrescentando um método `String` a cada um deles:

```go
func (sc DistanceUnit) String() string {
	units := []string{"km", "mi"}
	return units[sc]
}

func (d Distance) String() string {
	return fmt.Sprintf("%v %v", d.number, d.unit)
}
```

As funções do pacote `fmt` chamam estes métodos ao formatar valores de `Distance`:

```go
kmUnit := Kilometer
kmUnit.String()
// => km

mileUnit := Mile
mileUnit.String()
// => mi

dist := Distance{
	number: 790.7,
	unit: Kilometer,
}
dist.String()
// => 790.7 km
```
