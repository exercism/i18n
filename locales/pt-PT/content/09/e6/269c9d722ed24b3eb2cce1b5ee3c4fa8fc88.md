# Introdução

## Pacotes e módulos

### Importação

Normalmente, um módulo é carregado com a palavra-chave `use`.
Isto carrega o módulo e chama o método `import`, importando quaisquer símbolos exportados.

Os símbolos no array `@EXPORT` do pacote são importados por predefinição.
Os símbolos no array `@EXPORT_OK` do pacote têm de ser importados explicitamente.

### Exportação

Para que um símbolo seja importado, primeiro tem de ser exportado.
O módulo [Exporter][Exporter] vem incluído com o Perl e é uma das opções mais convenientes para exportar.

Definição do módulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Utilização do módulo:
```perl
use Foo ('bar');

bar();
```

### Módulos principais

Além do [Exporter][Exporter], o Perl tem uma grande variedade de [módulos principais][perl-core-modules] disponíveis para usar.
Alguns exemplos úteis para exercícios que podes encontrar aqui incluem o [List::Util][List::Util], o [Time::Piece][Time::Piece] e o [Math::BigRat][Math::BigRat].

### CPAN

Além dos módulos principais, o [CPAN][metacpan] tem milhares de módulos adicionais criados pela comunidade Perl disponíveis para instalação.
O percurso de Perl usa um [cpanfile][test-runner-cpanfile] para instalar uma seleção de módulos que podem ser usados com o test runner de Perl do Exercism.
