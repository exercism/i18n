# Instruções

Dada uma string de algarismos, calcula o maior produto de uma substring contígua de algarismos de comprimento n.

Por exemplo, para o valor de entrada `'1027839564'`, o maior produto para uma série de 3 algarismos é 270 (9 * 5 * 6), e o maior produto para uma série de 5 algarismos é 7560 (7 * 8 * 3 * 9 * 5).

Repara que estas séries só têm de ocupar *posições adjacentes* no valor de entrada; os algarismos não precisam de ser *numericamente consecutivos*.

Para o valor de entrada `'73167176531330624919225119674426574742355349194934'`, o maior produto para uma série de 6 algarismos é 23520.
