# Ajuda

## Precisas de mais ajuda?

- Vai ao [fórum da comunidade do Exercism](https://forum.exercism.org) para obteres apoio e fazeres perguntas (ou só para conversar!)
  - Usa a categoria [Exercism Support](https://forum.exercism.org/c/support/8) se tiveres algum problema com o editor web ou com o download ou a submissão dos teus exercícios localmente.
  - Usa a categoria [Programming:jq](https://forum.exercism.org/c/programming/jq/133) para assuntos específicos de jq.
- Junta-te à comunidade no [servidor de Discord do Exercism](https://exercism.org/r/discord).
- Podes usar o [StackOverflow](https://stackoverflow.com/questions/tagged/jq) para procurar o teu problema e ver se já foi respondido.
  Também podes fazer e responder a perguntas.
- O [registo de problemas do GitHub](https://github.com/exercism/jq/issues) é onde acompanhamos o desenvolvimento e a manutenção dos exercícios de `jq` no Exercism.
  Se nenhuma das ligações acima te ajudar, fica à vontade para abrir um problema aqui.
