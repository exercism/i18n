# Instruções

És um observador de aves entusiasta que regista quantas aves visitaram o teu jardim em cada dia.

Decidiste levar a tua observação de aves a um novo nível e criar algumas ferramentas que te vão ajudar a acompanhar e a processar os dados.

Escolheste guardar os dados numa lista de números inteiros.
O primeiro número da lista é o número de aves que visitaram o teu jardim hoje, o segundo ontem, e assim sucessivamente.

```exercism/note
Em aplicações do mundo real, deves usar sempre os módulos principais sempre que for aplicável; no entanto, para aprenderes sobre recursão, não uses nenhuma das funções do `List` neste exercício.
```

## 1. Verifica quantas aves visitaram hoje

Implementa a função `today`.
Deve receber uma lista com as contagens diárias de aves e devolver a contagem de hoje.
Se a lista estiver vazia, deve devolver `Nothing`; caso contrário, a contagem é envolvida num `Just`.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Incrementa a contagem de hoje

Implementa a função `incrementDayCount`.
Deve receber uma lista com as contagens diárias de aves e incrementar a contagem de hoje em 1.
Se a lista estiver vazia, devolve `[1]`.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Verifica se houve um dia sem aves a visitar o jardim

Implementa a função `hasDayWithoutBirds`.
Deve receber uma lista com as contagens diárias de aves.
Deve devolver `True` se houve pelo menos um dia em que nenhuma ave visitou o jardim, e `False` caso contrário.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Calcula o número total de aves que visitaram o jardim

Implementa a função `total`.
Deve receber uma lista com as contagens diárias de aves e devolver o número total de aves que visitaram o teu jardim desde que começaste a recolher os dados.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Calcula o número de dias movimentados

Há dias mais movimentados do que outros.
Um dia movimentado é aquele em que cinco ou mais aves visitaram o teu jardim.

Implementa a função `busyDays`.
Deve receber uma lista com as contagens diárias de aves e devolver o número de dias movimentados.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
