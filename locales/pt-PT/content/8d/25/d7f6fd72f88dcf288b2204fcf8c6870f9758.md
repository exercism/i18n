# Instruções

Neste exercício vais brincar com um carro telecomandado, para o qual finalmente poupaste dinheiro suficiente.

Os carros começam com a bateria cheia (100%). Cada vez que conduzes o carro com o telecomando, este percorre 20 metros e gasta um por cento da bateria. A alcunha do carro só é conhecida depois de o carro ser criado.

O carro telecomandado tem um ecrã LED sofisticado que mostra duas informações:

- A distância total que já percorreu, apresentada como: `"<METERS> meters"`.
- A carga restante da bateria, apresentada como: `"Battery at <PERCENTAGE>%"`.

Se a bateria estiver a 0%, já não podes conduzir o carro e o ecrã da bateria mostra `"Battery empty"`.

## 1. Cria um carro telecomandado novo em folha

Implementa a função `RemoteControlCar.new/0` para devolver uma struct de carro telecomandado novo em folha:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

A alcunha é exigida pela struct; certifica-te de que inicializas um valor na função `new`, mas não na struct.

## 2. Cria um carro telecomandado novo em folha com uma alcunha

Implementa a função `RemoteControlCar.new/1` para devolver uma struct de carro telecomandado novo em folha com uma alcunha fornecida:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. Mostra a distância

Implementa a função `RemoteControlCar.display_distance/1` para devolver a distância tal como é apresentada no ecrã LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

Certifica-te de que a função só aceita uma struct `RemoteControlCar` como argumento.

## 4. Mostra a percentagem da bateria

Implementa a função `RemoteControlCar.display_battery/1` para devolver a percentagem da bateria tal como é apresentada no ecrã LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

Certifica-te de que a função só aceita uma struct `RemoteControlCar` como argumento. Se a bateria estiver a 0%, o ecrã da bateria mostra "Battery empty".

## 5. Conduzir altera a bateria e a distância percorrida

Implementa a função `RemoteControlCar.drive/1` que:

- aumenta em 20 o número de metros percorridos
- gasta 1% da bateria

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

Certifica-te de que a função só aceita uma struct `RemoteControlCar` como argumento.

## 6. Tem em conta a condução com a bateria descarregada

Atualiza a função `RemoteControlCar.drive/1` para não aumentar a distância percorrida nem diminuir a percentagem da bateria quando a bateria está gasta (a 0%):

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
