# Acerca de

Tal como se pode criar um ponteiro para um `int` ou para outro tipo de dados básico, também se pode criar um ponteiro para uma função.
Um ponteiro para função pode ser usado para passar uma função a outra função.
Uma função que é passada a outra função como valor de um parâmetro é designada por função de primeira classe.
Uma função que recebe uma ou mais funções como parâmetro, ou que devolve uma função, é designada por função de ordem superior.

No exemplo seguinte, `is_even` e `is_odd` são funções de primeira classe.
A função de ordem superior é `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
A assinatura de função `bool (*func) (int)`, para o primeiro argumento de `test_number`, corresponde à assinatura das funções passadas.
Tanto `is_even` como `is_odd` recebem um parâmetro `int` e devolvem um `bool`.
Em `(*func)`, `func` representa o nome da função a usar.
Se fosse usado `(*fn)`, a chamada seria feita assim: `printf(text, number, fn(number)? "true": "false");`.
Para satisfazer o parâmetro do ponteiro para função, passamos o nome de uma função com a assinatura esperada ao chamar `test_number`.
Assim, vemos que o nome de uma função aponta para o endereço dessa função.

Chamar um ponteiro para função com a assinatura errada resulta em comportamento indefinido (UB).
Dependendo do compilador, pode não compilar, ou pode compilar com ou sem avisos, mas depois sofrer uma falha em tempo de execução.
