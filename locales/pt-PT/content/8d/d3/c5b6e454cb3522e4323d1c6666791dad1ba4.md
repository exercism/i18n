# Instruções

Neste exercício, vais implementar a lógica da missão de um novo jogo de RPG que um amigo está a desenvolver.
A personagem principal do jogo é a Annalyn, uma rapariga corajosa com um cão de estimação feroz e leal, o Kazak.
A certa altura, são emboscados por um monstro que atacam.

## 1. Define attackWithSword1

Define `attackWithSword1`.
Esta função deve receber um `MonsterDamage` (uma `String` que descreve o dano causado ao monstro) e um `Int` que indica a força do ataque.
Deve devolver a string existente, acrescentando-lhe "Attacked with sword of strength {strength}." ao fim.

## 2. Define attackWithClaw1

Define `attackWithClaw1`.
Esta função deve receber um `MonsterDamage` e um `Int` que indica a força do ataque.
Deve devolver a string existente, acrescentando-lhe "Attacked with claw of strength {strength}." ao fim.

## 3. Define attack1

A Annalyn ataca com uma espada e tem uma força de 5.

O Kazak, o seu cão de estimação leal, ataca com as garras e tem uma força de 1.

Define `attack1`. Esta função deve receber um `MonsterDamage` e realizar os seguintes ataques, pela ordem correta:

- Annalyn
- Kazak
- Kazak
- Annalyn

A implementação desta função vai ser um pouco trabalhosa, porque `attackWithSword1` e `attackWithClaw1` não têm a estrutura de dados principal (`MonsterDamage`) como último parâmetro (não o estão a fazer da forma recomendada).
Não é possível / aconselhável usar aplicação parcial neste caso inicial.

## 4. Define attackWithSword2

Define `attackWithSword2`.
É igual a `attackWithSword1`, exceto que os parâmetros estão trocados.

## 5. Define attackWithClaw2

Define `attackWithClaw2`.
É igual a `attackWithClaw2`, exceto que os parâmetros estão trocados.

## 6. Define attack2

Define `attack2`.

É igual a `attack1`, mas deve usar `attackWithSword2` e `attackWithClaw2`.

Por favor, implementa a função usando [aplicação parcial][partial-application] e o [operador pipe `(|>)`][pipe-operator].
A implementação deverá agora ser mais elegante, porque `attackWithSword2` e `attackWithClaw2` têm `MonsterDamage` (a estrutura de dados principal) como último parâmetro, como é recomendado.

## 7. Define attack3

Define `attack3`.

É igual a `attack2`, mas deve ser implementada usando composição de funções / o operador [`(>>)`][forward-composition].

Esta implementação também deverá ser elegante e mais pequena do que `attack2`, embora possa ser potencialmente mais difícil de compreender.
