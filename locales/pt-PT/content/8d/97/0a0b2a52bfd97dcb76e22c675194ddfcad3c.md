# Dicas

## 1. Cria um novo residente

- Revisita o [conceito de struct](/tracks/go/concepts/structs) para saberes como criar structs.

## 2. Valida a informação do residente

- O valor zero de uma string é `""`.
- O valor zero de um mapa é `nil`.
- Revisita o [conceito de mapas](/tracks/go/concepts/maps) para saberes como determinar se uma chave existe num mapa.

## 3. Apaga a informação do residente

- Um residente é considerado apagado quando todos os seus campos estão com o valor zero.
- Revisita o [conceito de valores zero](/tracks/go/concepts/zero-values) para saberes o valor zero de cada tipo em Go.

## 4. Conta os residentes

- Revisita o [conceito de iteração com range](/tracks/go/concepts/range-iteration) para saberes como iterar sobre uma slice.
