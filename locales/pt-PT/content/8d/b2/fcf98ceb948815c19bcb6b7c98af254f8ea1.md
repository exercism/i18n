# Instruções

O teu amigo Linus é maquinista e conduz comboios de mercadorias entre cidades.
Apesar de ser fantástico a lidar com comboios, não é grande coisa com logística nem com computadores.
Gostaria de contar com a tua ajuda na programação para organizar os detalhes dos comboios e corrigir erros nos dados das rotas.

~~~~exercism/note
Este exercício podia ser facilmente resolvido com fatiamento, indexação e vários métodos de `Dict`.
No entanto, queremos que pratiques o empacotamento (ou seja, *slurping*), o desempacotamento (ou seja, *splatting*) e a atribuição múltipla ao resolver cada uma das tarefas abaixo.
~~~~

## 1. Cria um vetor com todos os vagões

O teu amigo tem andado a registar o identificador (ID) de cada vagão, mas nunca sabe quantos vagões é que o sistema vai ter de processar em cada momento.
Seria muito mais fácil para o resto do programa de logística ter estes dados empacotados num único `Vector`.

Implementa uma função `get_vector_of_wagons(args...)` que aceita um número arbitrário de IDs de vagões.
Cada ID será um número inteiro positivo.
A função deve então `return` os IDs indicados como um único `Vector`.

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. Corrige o vetor dos vagões

A esta altura, já estás a começar a perceber os dados e a forma como são usados no programa de logística.
O sistema de IDs atribui sempre à locomotiva o ID **1**, e aos restantes vagões do comboio um ID maior do que **1**, escolhido aleatoriamente.

O teu amigo teve de ligar dois vagões novos ao comboio e esqueceu-se de atualizar o sistema!
Agora, os dois primeiros vagões do `Vector` do comboio têm de ser movidos para o fim, senão fica tudo fora de ordem.

Para complicar ainda mais, o teu amigo acabou de descobrir um segundo `Vector` que parece conter IDs de vagões em falta.
Só se lembra de que, depois de mover os vagões novos, os IDs deste segundo `Vector` devem ficar imediatamente a seguir à locomotiva designada.

O Linus ficaria muito grato se corrigisses os erros e consolidares os dados.

Implementa uma função `fix_vector_of_wagons(each_wagons_id, missing_wagons)` que recebe dois `Vectors` com IDs de vagões.
Deve reposicionar os dois primeiros itens do primeiro `Vector` para o fim e inserir os valores do segundo `Vector` atrás (_à direita_) do ID da locomotiva (**1**).
A função deve então `return` um `Vector` com as modificações.

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. Adiciona as paragens em falta

Agora que todos os dados dos vagões estão corretos, o Linus gostaria que atualizasses a informação de encaminhamento do sistema.
Ao longo de uma rota de transporte, um comboio pode fazer paragens em várias estações para carregar e/ou descarregar mercadorias.
Cada viagem pode ter um número diferente destes pontos de entrega intermédios.
O teu amigo gostaria que atualizasses o `Dict` de encaminhamento do sistema com qualquer informação de entrega em falta ou adicional.

Implementa uma função `add_missing_stops(route, stops...)` que recebe um `Dict` de encaminhamento seguido de um número variável de Pairs `stop_number => city`.
A tua função deve então devolver o `Dict` de encaminhamento atualizado com uma `key` adicional que contém um `Vector` com todas as paragens adicionadas, pela ordem correta.

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. Estende a informação de encaminhamento

O Linus tem andado a trabalhar no programa de encaminhamento e reparou que faltam alguns detalhes importantes em certas rotas.
A informação inicial das rotas foi construída como um `Dict` e o teu amigo gostaria que atualizasses esse `Dict` com tudo o que possa estar em falta.
Cada rota do sistema exige detalhes ligeiramente diferentes, por isso o Linus preferia mesmo uma solução genérica.

Implementa uma função chamada `extend_route_information(route; more_route_information...)` que recebe um `Dict` com as cidades de origem e de destino entre as quais a rota do comboio passa, mais um número variável de argumentos de palavra-chave com detalhes de encaminhamento, como a velocidade, o comprimento ou a temperatura do comboio.
A função deve devolver um `Dict` consolidado com toda a informação de encaminhamento.

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
