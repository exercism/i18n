# Ajuda

Abaixo encontras alguns recursos para obter ajuda se tiveres problemas:

- O [site principal do projeto Futhark][main] aloja [documentação][docs], [exemplos][examples], uma [referência da linguagem][language-reference] e muito mais.
- [Parallel Programming in Futhark][book] é um livro pensado como uma introdução à linguagem.
- A [comunidade do Exercism no Discord][exercism-discord]
- O canal `#futhark` na [Libera][libera]
- O [canal de Gitter do futhark][gitter]
- O [/r/futhark/][reddit] é um subreddit para linguagens do tipo APL.

Além disso, o [StackOverflow][so] é um bom sítio para procurar o teu problema ou a tua dúvida e ver se já foi respondido.
Se não, podes sempre [perguntar][ask-so] ou [responder][answer-so] à pergunta de outra pessoa.
