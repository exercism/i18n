# Sobre

O Haxe é uma linguagem fortemente tipada, mas o sistema de tipos pode ser subvertido quando é preciso. Atribuir um valor a um nome chama-se definir uma variável. Podes definir uma variável indicando explicitamente o seu tipo ou deixando o compilador do Haxe inferir o tipo com a [palavra-chave `var`](var). Por isso, as duas definições de variável seguintes são equivalentes:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Podes atualizar uma variável com o operador `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

O compilador dá um erro quando tentas atribuir um valor de tipo diferente do da variável:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Em Haxe, o código escreve-se normalmente dentro de uma _função_, também chamada de [_método_](method). Estas funções podem receber parâmetros (argumentos) e devolver valores com a palavra-chave `return`. As funções são invocadas com a sintaxe `()`. Todas as funções têm de ter um tipo de retorno.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Em Haxe, o âmbito define-se entre os carateres `{` e `}`.

O Haxe suporta dois tipos de comentários. Os de uma linha são precedidos de `//` e os comentários de várias linhas são inseridos entre `/*` e `*/`.
