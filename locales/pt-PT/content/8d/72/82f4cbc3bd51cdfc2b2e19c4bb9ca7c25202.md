# Instruções

Estás a trabalhar num sistema para simplificar o processo de início de sessão na rede da tua organização. As tarefas dizem respeito à parte da autenticação. O sistema usa reconhecimento facial para provar a identidade.

Em todas as ocorrências, o parâmetro da cor dos olhos tem a garantia de não ser nulo.

## 1. Garante que os traços faciais coincidem

Implementa `Authenticator.AreSameFace()` para verificar se dois rostos coincidem.

Adiciona rotinas de igualdade para a classe `FacialFeatures`.

```csharp
Authenticator.AreSameFace(new FacialFeatures("green", 0.9m), new FacialFeatures("green", 0.9m);
// => true
Authenticator.AreSameFace(new FacialFeatures("blue", 0.9m), new FacialFeatures("green", 0.9m);
// => false
```

## 2. Autentica o administrador do sistema

Apesar dos teus protestos, o administrador do sistema insiste em ter uma identidade incorporada durante os testes de aceitação, para que possa ser sempre autenticado.

O email do administrador é admin@exerc.ism. Tem os olhos verdes e um filtrum com 0,9 de largura.

Adiciona rotinas de igualdade para a classe `Identity`.

Implementa o método `Authenticator.IsAdmin()` para verificar se a identidade fornecida corresponde à do administrador.

```csharp
var authenticator = new Authenticator();
authenticator.IsAdmin(new Identity("admin@exerc.ism", new FacialFeatures("green", 0.9m)));
// => true
authenticator.IsAdmin(new Identity("admin@thecompetition.com", new FacialFeatures("green", 0.9m)));
// => false
```

## 3. Regista novas identidades

Implementa o método `Authenticator.Register()`, que guarda uma identidade no próprio autenticador, de modo que as chamadas a `IsRegistered()` devolvam `true` para essa identidade; caso contrário, `IsRegistered()` devolve `false`.

Para detetar tentativas duplicadas de registar uma identidade, se a identidade já tiver sido registada, `Authenticator.Register()` devolve `false`; caso contrário, devolve `true`.

```csharp
var authenticator = new Authenticator();
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.IsRegistered(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => false
```

## 4. Impede que identidades inválidas sejam autenticadas

Implementa o método `Authenticator.IsRegistered()` e certifica-te de que devolve false quando não foi registada nenhuma identidade.

```csharp
var authenticator = new Authenticator();
authenticator.IsRegistered(new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.8m)));
// => false
```

## 5. Adiciona diagnósticos para detetar várias tentativas de autenticação

Foi reportado um bug em que o método `Authenticator.IsRegistered()` é chamado várias vezes em rápida sucessão para a mesma identidade. Acreditas que há algum tipo de problema de "ressalto", em que o mesmo registo está a ser submetido várias vezes. A tua tarefa é adicionar uma rotina de diagnóstico `Authenticator.AreSameObject()` para apoiar os testes que forem realizados. A rotina compara dois objetos e devolve `true` se forem exatamente a mesma instância; caso contrário, `false`.

```csharp
var identityA = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityB = identityA;
Authenticator.AreSameObject(identityA, identityB);
// => true

var identityC = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityD = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
Authenticator.AreSameObject(identityC, identityD);
// => false
```
