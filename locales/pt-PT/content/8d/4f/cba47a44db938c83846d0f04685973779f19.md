# Introdução

Todas as funções do [módulo `Enum`][exercism-enum] são _imediatas_. Quando fazes várias operações sobre enumeráveis com o módulo `Enum`, cada operação vai gerar um resultado intermédio.

O módulo `Stream` é uma alternativa _preguiçosa_ ao módulo `Enum`, que é _imediato_. Oferece muitas das mesmas funções que o `Enum`, mas, em vez de gerar resultados intermédios, constrói uma série de cálculos que só são executados quando a stream é passada a uma função do módulo `Enum`.

As streams implementam o _protocolo [Enumerable][exercism-protocols]_ e são componíveis: podes encadeá-las umas nas outras para criar funcionalidades mais complexas.

[exercism-enum]: https://exercism.org/tracks/elixir/concepts/enum
[exercism-protocols]: https://exercism.org/tracks/elixir/concepts/protocols
