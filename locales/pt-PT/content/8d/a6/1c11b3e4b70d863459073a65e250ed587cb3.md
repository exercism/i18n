# Instruções

Converte um número binário, representado como uma string (por exemplo, '101010'), no seu equivalente decimal, partindo dos princípios básicos.

Implementa a conversão de binário para decimal. Dado um número binário de entrada sob a forma de string, o teu programa deve produzir um resultado decimal. O programa deve saber lidar com entradas inválidas.

## Nota

- Implementa a conversão tu mesmo.
  Não uses outra coisa para fazer a conversão por ti.

## Sobre o sistema binário (base 2)

O sistema decimal é um sistema de base 10.

Um número como 23 em notação de base 10 pode ser entendido como uma combinação linear de potências de 10:

- O algarismo mais à direita é multiplicado por 10^0 = 1
- O algarismo seguinte é multiplicado por 10^1 = 10
- ...
- O _n_ésimo algarismo é multiplicado por 10^_(n-1)_.
- Todos estes valores são somados.

Ou seja: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

O sistema binário é semelhante, mas usa potências de 2 em vez de potências de 10.

Ou seja: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
