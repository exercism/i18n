# Dicas

## 1. Verifica se o comando é válido

- Usa o método [test()][mdn-regex-test] para devolveres um Boolean.
- Lembra-te de que podemos usar [flags][mdn-flags] no fim da expressão regular para funcionalidades adicionais, como não distinguir maiúsculas de minúsculas.

## 2. Remove os emojis encriptados

- Neste caso, temos de usar o construtor [RegExp][mdn-regular-expressions] para construir a nossa expressão regular.
- Como todos os emojis partilham a mesma encriptação, podemos usar `[0-9]` para procurar qualquer algarismo depois da palavra `emoji`.
- O caráter `+` corresponde a um ou mais itens consecutivos.
- Usa o método [split()][mdn-regex-split] juntamente com a expressão regular de cada emoji para eliminares toda a encriptação.
- Por fim, devolve este array dividido como string, usando o método [join()][mdn-join].

## 3. Verifica se o número de telefone é válido

- Neste exercício, estamos a brincar com `groups and ranges`. Lê esta [documentação][mdn-groups] para saberes mais sobre o assunto.
- Este [artigo][phone-validation] explica muito bem as diferentes formas de validar números.
- Também podes querer usar esta [referência rápida][mdn-regex-cheatsheet] para teres uma visão geral das funcionalidades disponíveis nas expressões regulares.
- Usa o método `test()` para verificar se o número de telefone é válido ou não.
- Devolve a resposta final com um simples `if statement`.

## 4. Obtém o link do site

- Estamos a procurar palavras que estão unidas por um ou mais `.(dots)`.
- Lembra-te de colocar a flag `g` no fim, para conseguirmos obter todos os domínios em qualquer frase.
- Usa o método [match()][mdn-regex-match] para devolver um array com todas as correspondências anteriores.

## 5. Cumprimenta o utilizador

- Primeiro, usa o método [replace()][mdn-regex-replace] diretamente na string dada.
- Usa [grupos de captura com nome][mdn-groups] para guardares o `name` e o `surname` em valores diferentes.
- Passa uma desestruturação `(...match)` à função de substituição, para conseguires obter o nome e o apelido no objeto dentro dos grupos correspondentes.
- Usa o método `pop()` para guardares o objeto correspondido com `name` e `surname`.
- Por fim, implementa uma `template String` para conseguires obter os valores do objeto da expressão regular. Vê [este][mdn-capturing-groups] exemplo para saberes como o match() guarda os objetos.
