# Instruções adicionais

## Implementação

Neste exercício vais instanciar uma classe e adicionar alguns métodos de instância. Podes consultar [Escrever classes em Ruby][writing-classes] para veres como se faz.

Um HighScore aceita um array com um ou mais números, cada um a representar uma 'pontuação de jogo'.
A classe Array pode servir-te de inspiração para trabalhar com arrays, vê a [documentação do Ruby][ruby-docs-array].
