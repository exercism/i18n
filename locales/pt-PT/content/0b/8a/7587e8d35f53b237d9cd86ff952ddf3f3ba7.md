# Dicas

## Geral

- Se tiveres dificuldades com o exercício, talvez queiras dar uma vista de olhos a [Interfaces in the Tour of Go][interfaces-tour-of-go] para veres mais exemplos.

## 1. Cria a funcionalidade abstrata de saudação

- Volta ao exemplo `Counter` da introdução para descobrires como se define uma interface.
- Revisita o [conceito de funções][concept-functions] para recordares como se escrevem assinaturas de funções em Go.
- O tipo abstrato `Greeter` pode ser usado numa assinatura de função da mesma forma que um tipo concreto normal, como `string`.
- Para implementares `SayHello`, chama os métodos do argumento do tipo `Greeter`.
  Depois, usa a formatação de strings ou a concatenação de strings para construíres o resultado final.

## 2. Implementa o italiano

- Revisita o [conceito de structs][concept-structs] para veres como se define um tipo struct.
- Para resolveres a tarefa, o struct não precisa de nenhum campo.
- Depois de definires o struct, vais querer acrescentar-lhe os métodos `LanguageName` e `Greet`.
  Revisita o [conceito de métodos][concept-methods] para descobrires como adicionar um método a um tipo.

- Vê as dicas da tarefa 2.
