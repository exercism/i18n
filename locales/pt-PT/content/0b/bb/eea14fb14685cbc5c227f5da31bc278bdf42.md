# tem função main

Remove a função `Main`, uma vez que os testes não a exigem e só tornam o código um pouco mais difícil de ler.

Normalmente, a função `Main` é adicionada para ajudar a fazer debug ao código. No entanto, uma abordagem melhor é fazer debug ao código enquanto corres um ou mais testes unitários. Isto tem a vantagem adicional de poderes concentrar-te num caso de teste específico. Aqui ficam alguns links que explicam como fazer debug a código Scala ao correr testes unitários em vários ambientes de desenvolvimento integrado (IDE):

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
