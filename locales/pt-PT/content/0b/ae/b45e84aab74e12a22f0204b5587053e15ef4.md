# Sobre

`Nil` no Gleam é um tipo com um único valor, também chamado `Nil`. É semelhante a `void` noutras linguagens, no sentido em que é usado quando uma função não tem nenhum valor mais adequado para devolver.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Os valores em Gleam não são "nil-able" nem "nullable", ao contrário do que acontece noutras linguagens. Um valor só pode ser `Nil` se o seu tipo for `Nil`, e um valor de qualquer outro tipo nunca pode ser `Nil`.
