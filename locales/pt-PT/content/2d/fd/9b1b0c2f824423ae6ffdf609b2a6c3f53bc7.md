# Instruções

Estás a trabalhar num jogo para um sistema embutido de baixo consumo e precisas de escrever várias funções utilitárias que vão ser usadas por outras partes do jogo.

## 1. Calcula o quociente e o resto de uma divisão

O quociente é o resultado de uma divisão.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

Exemplo:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. Escolhe itens em posições pares de um iterador

Isto vai ajudar a ativar uma otimização do buffer do ecrã, promete o teu chefe.

Os iteradores são itens que expõem os métodos definidos pela [trait `Iterator`](https://doc.rust-lang.org/std/iter/trait.Iterator.html). Essa documentação é bastante extensa, porque oferecem muitos métodos; aqui ficam as propriedades mais relevantes:

- Um iterador é um fluxo de itens de comprimento arbitrário
- Têm um [método `enumerate`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate) que devolve um tuplo `(i, val)` para cada valor
- Têm um [método `filter`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter) que usa uma closure para determinar se deve produzir um elemento do iterador
- Têm um [método `map`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map) que usa uma closure para modificar elementos do iterador

Como a tua função pode correr sobre qualquer tipo de iterador, usa `impl` para indicar que se trata de uma instância de uma trait e não de um item simples. Da mesma forma, a sintaxe `<Item=T>` significa apenas que não importa que tipo de item o iterador produz; a tua função pode produzir os elementos pares de qualquer iterador.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

Exemplos:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. Calcula a distância de Manhattan de uma posição à origem

Para facilitar o mapeamento, tens uma tuple struct `Position`:

```rust
struct Position(i16, i16);
```

Precisas de implementar um método `manhattan` em `Position` que devolve a [distância de Manhattan](https://en.wikipedia.org/wiki/Taxicab_geometry) dessa posição à origem (`Position(0, 0)`).

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

Exemplo:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
