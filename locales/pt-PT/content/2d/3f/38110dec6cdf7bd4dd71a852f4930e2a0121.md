# Sobre

O Swift disponibiliza instruções de transferência de controlo para alterar o fluxo de execução dos ciclos e das instruções switch.
Para além do `return`, o Swift inclui `continue`, `break`, rótulos de ciclo e `fallthrough`.

## Continue

A instrução `continue` diz a um ciclo para parar de executar a iteração atual e começar imediatamente a iteração seguinte.
Num ciclo `while` ou `repeat-while`, salta diretamente para a verificação da condição.
Num ciclo `for-in`, avança para o elemento seguinte da sequência.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

A instrução `break` sai imediatamente de todo o ciclo ou instrução switch.
A execução retoma na primeira linha de código a seguir ao ciclo ou ao switch.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Instruções com rótulo

Em ciclos aninhados, podes querer que o `break` ou o `continue` afetem um ciclo exterior em vez do ciclo mais interior.
Podes rotular um ciclo colocando antes dele um nome seguido de dois pontos (`labelName:`).
Depois, podes passar esse rótulo ao `break` ou ao `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

No Swift, as instruções `switch` não passam para o case seguinte por predefinição; a execução para automaticamente no fim do case correspondido.
Se quiseres explicitamente que a execução continue para o case seguinte sem avaliar o seu padrão, usa a palavra-chave `fallthrough`:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
