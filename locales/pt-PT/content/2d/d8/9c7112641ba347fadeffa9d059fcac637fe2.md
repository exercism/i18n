# Instruções adicionais

## Implementação

Define `type Classification` para conter os valores de classificação dos números naturais. Podes escolher a representação que quiseres para este tipo.

Define três constantes de Classification com os nomes

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

Implementa uma função com o nome Classify que aceita um parâmetro de entrada do tipo int64 e devolve um valor do tipo Classification e um valor de erro.

Cria um erro com o nome ErrOnlyPositive, que é devolvido quando o valor de entrada não é um número inteiro positivo.
