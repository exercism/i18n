# Testes

## Executar os testes
Para executar os testes de uma implementação específica de um exercício, segue estes passos recomendados:

1. cria a tua implementação em `[SLUG].v`
1. entra no diretório onde se encontram `[SLUG].v` e `run_test.v`
1. executa `v -stats test run_test.v`

## Testes em V
Para mais informações sobre como fazer testes em V, consulta a [documentação oficial](https://github.com/vlang/v/blob/master/doc/docs.md#testing)
