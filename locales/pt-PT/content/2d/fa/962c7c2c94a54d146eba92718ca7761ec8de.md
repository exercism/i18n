# sem export nomeado

Não se encontrou [`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export). Os testes não passam sem isto.

Certifica-te de que `%{export.name}` existe e acrescenta `export` à frente:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
