# Instruções

Estás a ajudar num censo de aves. Todos os dias, alguém se senta num observatório e conta o que passa a voar, e as contagens do dia chegam num array.

As cinco tarefas vão todas para a classe `BIRD_SURVEY`.

## 1. O total

Soma a contagem de cada dia.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

Um censo sem nenhum dia conta zero aves.

## 2. O melhor dia

Devolve a maior contagem. Se não houver dias, a resposta é zero.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. Os dias movimentados

Quantos dias tiveram uma contagem acima de um certo número?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

Acima é acima: uma contagem de exatamente 2 não conta.

## 4. Observatórios a verificar

No primeiro dia do censo verificas um observatório, no segundo dia dois, e assim por diante. Quantas verificações de observatórios são ao todo?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

Ou seja, 1 + 2 + 3 + 4.

## 5. O primeiro dia movimentado

Qual foi o primeiro dia com uma contagem acima de um certo número? Os dias são numerados a partir de zero, tal como as posições de um array. Se nenhum dia foi assim tão movimentado, a resposta é `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
