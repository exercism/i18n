# Introdução

Em Common Lisp, as strings são [vetores][concept-vectors] de [carateres][concept-characters]. Escrevem-se como carateres entre aspas duplas (_por exemplo_, "Hello World!").

O predicado `stringp` só devolve verdadeiro se o valor dado for uma string.

As strings podem ser divididas em substrings com a função `subseq`, que recebe a string, um índice de início e, opcionalmente, um índice de fim. A indexação começa em zero.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

As strings podem ser comparadas quanto à igualdade com `string=`. Se não for preciso distinguir maiúsculas de minúsculas, podes usar `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Podes fazer operações como converter strings para maiúsculas, convertê-las para minúsculas ou capitalizá-las com `string-upcase`, `string-downcase` e `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
