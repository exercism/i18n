# Dicas

## 1. Implementa a interface `Stringer` para o tipo `TemperatureUnit`

- O tipo `TemperatureUnit` já está criado para ti e representa uma unidade de temperatura
- Repara que já existem 2 constantes criadas para ti deste tipo: `Celsius` e `Fahrenheit`, que representam uma temperatura em Celsius e Fahrenheit, respetivamente
- Adiciona um método `String()` ao tipo `TemperatureUnit` para que satisfaça a interface `Stringer`.
  Este método tem de devolver a string `"°C"` se a unidade de temperatura for Celsius ou `"°F"` se a unidade de temperatura for Fahrenheit

## 2. Implementa a interface `Stringer` para o tipo `Temperature`

- Adiciona um método `String()` ao tipo `Temperature` para que satisfaça a interface `Stringer`
- O método `String()` deve devolver uma string com o valor numérico da temperatura e a unidade de temperatura separados por um espaço (`<temperature> <unit>`)
- A estrutura `Temperature` contém um `TemperatureUnit` e um `int`.
  Podes usar [fmt.Sprintf][sprintf] para te ajudar a formatar esta string
- Como o `TemperatureUnit` já implementa a interface `Stringer` (da tarefa 1), as funções do pacote `fmt`, como [fmt.Sprintf][sprintf], vão saber como formatá-lo quando usares os [verbos de formatação][fmt] `%v` ou `%s`

## 3. Implementa a interface `Stringer` para o tipo `SpeedUnit`

- O tipo `SpeedUnit` já está criado para ti e representa uma unidade de temperatura
- Repara que já existem 2 constantes criadas para ti deste tipo: `KmPerHour` e `MilesPerHour`, que representam uma velocidade em quilómetros por hora e milhas por hora, respetivamente
- Adiciona um método `String()` ao tipo `SpeedUnit` para que satisfaça a interface `Stringer`.
  Este método tem de devolver a string `"km/h"` se a unidade de velocidade for quilómetros por hora ou `"mph"` se a unidade de velocidade for milhas por hora.

## 4. Implementa a interface `Stringer` para `Speed`

- Adiciona um método `String()` ao tipo `Speed` para que satisfaça a interface `Stringer`
- O método `String()` deve devolver uma string com o valor numérico da velocidade e a unidade de velocidade separados por um espaço (`<speed> <unit>`)
- A `Speed` contém um `SpeedUnit` e um `int`.
  Podes usar [fmt.Sprintf][sprintf] para te ajudar a formatar esta string
- Como a estrutura `TemperatureUnit` já implementa a interface `Stringer` (da tarefa 3), as funções do pacote `fmt`, como [fmt.Sprintf][sprintf], vão saber como formatá-la quando usares os [verbos de formatação][fmt] `%v` ou `%s`
- Para inserir um `%` na string final quando usares [fmt.Sprintf][sprintf], usa `%%` na string de formatação.

## 5. Implementa a interface `Stringer` para o tipo `MeteorologyData`

- A `Speed` contém campos `Temperature` e `Speed`, entre outros campos.
  Podes usar [fmt.Sprintf][sprintf] para te ajudar a formatar esta string
- O método `String` deve devolver os dados meteorológicos no seguinte formato: `"<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity"`
- Como os tipos `Temperature` e `Speed` já implementam a interface `Stringer` (das tarefas 2 e 4), as funções do pacote `fmt`, como [fmt.Sprintf][sprintf], vão saber como formatá-los quando usares os [verbos de formatação][fmt] `%v` ou `%s`

[fmt]: https://pkg.go.dev/fmt
[sprintf]: https://pkg.go.dev/fmt#Sprintf
