# Sobre

`reduce` é o fold geral do Factor: percorre uma sequência, fazendo passar um acumulador por uma quotation binária que recebe o acumulador atual e o elemento seguinte e produz o novo acumulador.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

Um valor inicial personalizado permite que `reduce` expresse folds que `sum` ou `product` não conseguem. Por exemplo, o maior valor numa sequência com um valor por omissão caso todos os elementos percam:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

O valor inicial `0` participa na comparação, por isso uma sequência só com valores negativos continua a produzir `0` em vez do seu menor valor.

## `produce`: o unfold

O dual de `reduce` é `produce` (em [`sequences`][sequences]): enquanto `reduce` *consome* uma sequência, `produce` *gera* uma. Uma quotation de predicado testa o estado atual; enquanto devolver um valor verdadeiro, uma quotation de corpo produz o elemento seguinte.

```
produce ( pred quot -- seq )
```

Usados em conjunto, `reduce` e `produce` formam o par fold/unfold do Factor.

## Reduções cumulativas

A família de reduções cumulativas em [`math.statistics`][math.statistics] devolve uma sequência com o mesmo comprimento da sequência de entrada, em que cada elemento é a redução sobre o prefixo até essa posição, inclusive:

| palavra       | operação acumulada |
|---------------|--------------------|
| `cum-sum`     | total acumulado    |
| `cum-product` | produto acumulado  |
| `cum-min`     | mínimo acumulado   |
| `cum-max`     | máximo acumulado   |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

As reduções cumulativas são úteis quando queres inspecionar *como* uma quantidade evoluiu ao longo da sequência, e não apenas o seu valor final. Encadeá-las também é útil: a saída de uma redução cumulativa é, ela própria, uma sequência, pronta para alimentar outra.
