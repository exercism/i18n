# Introdução

Se queres construir algo com um Raspberry Pi, provavelmente vais precisar de _resistências_.
Tal como nos exercícios anteriores `Resistor Color Duo` e `Resistor Color Trio`, vais traduzir as bandas de cor das resistências em etiquetas legíveis por humanos.

- Cada resistência tem um valor.
- As resistências são pequenas, tão pequenas que, se imprimissem nelas o valor de resistência, seria difícil de ler.
  Para contornar este problema, os fabricantes imprimem nas resistências bandas com código de cores, para indicar os seus valores de resistência.
- Cada banda funciona como um algarismo de um número.
  Por exemplo, se imprimissem uma banda brown (valor 1) seguida de uma banda green (valor 5), isso corresponderia ao número 15.

## Instruções

Neste exercício vais criar um programa útil, para não teres de memorizar os valores das bandas.
O programa recebe 1, 4 ou 5 cores e devolve o valor correto, em ohms.
As bandas de cor estão codificadas da seguinte forma:

- Black: 0
- Brown: 1
- Red: 2
- Orange: 3
- Yellow: 4
- Green: 5
- Blue: 6
- Violet: 7
- Grey: 8
- White: 9

Em `resistor-color trio` descodificaste as três primeiras cores.
Por exemplo: orange-orange-brown correspondia ao valor principal `330`.
Neste exercício vais ter de acrescentar a _tolerância_ à mistura.
A tolerância é a quantidade máxima que um valor pode estar acima ou abaixo do valor principal.
Por exemplo, se a última banda for green, a tolerância máxima será ±0.5%.

A banda de tolerância terá um destes valores:

- Grey - 0.05%
- Violet - 0.1%
- Blue - 0.25%
- Green - 0.5%
- Brown - 1%
- Red - 2%
- Gold - 5%
- Silver - 10%

A resistência de quatro bandas é composta assim:

| Banda_1 | Banda_2 | Banda_3      | Banda_4   |
| ------- | ------- | ------------ | --------- |
| Valor_1 | Valor_2 | Multiplicador | Tolerância |

Ou seja:

- orange-orange-brown-green corresponderia a 330 ohms com uma tolerância de ±0.5%.
- orange-orange-red-grey corresponderia a 3300 ohms com uma tolerância de ±0.05%.

A diferença entre uma resistência de quatro bandas e uma de cinco bandas é que a de cinco bandas tem uma banda extra, para indicar um valor mais preciso.

| Banda_1 | Banda_2 | Banda_3 | Banda_4      | Banda_5   |
| ------- | ------- | ------- | ------------ | --------- |
| Valor_1 | Valor_2 | Valor_3 | Multiplicador | Tolerância |

Ou seja:

- orange-orange-orange-black-green corresponderia a 333 ohms com uma tolerância de ±0.5%.
- orange-red-orange-blue-violet corresponderia a 323M ohms com uma tolerância de ±0.10.

Também existem resistências de uma só banda.
As resistências de uma só banda têm apenas a cor black, com um valor de 0.

Este exercício consiste em traduzir as cores das bandas das resistências numa etiqueta:

"... ohms ...%"

Por isso, se os valores de entrada forem "orange", "orange", "black", "green", o programa deve devolver:

"33 ohms ±0.5%"

Quando há mais de mil ohms, dizemos "kiloohms".
 É semelhante a dizer "quilómetro" para 1000 metros e "quilograma" para 1000 gramas.

Por isso, se os valores de entrada forem "orange", "orange", "orange", "grey", o programa deve devolver:

"33 kiloohms ±0.05%"

Quando há mais de um milhão de ohms, dizemos "megaohms".

Por isso, se os valores de entrada forem "orange", "orange", "blue", "red", o programa deve devolver:

"33 megaohms ±2%"
