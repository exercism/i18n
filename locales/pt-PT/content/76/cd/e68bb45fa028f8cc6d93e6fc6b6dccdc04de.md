# Dicas

## Geral

- Um número inteiro pode ser definido como um ou mais algarismos consecutivos.

## 1. Define o tempo esperado de forno, em minutos

- Tens de definir um [método][methods] sem argumentos.
- Tens de devolver um número inteiro (vê os [tipos incorporados][built-in types]).

## 2. Calcula o tempo de forno restante, em minutos

- Tens de definir um [método][methods] com um único parâmetro.
- O parâmetro do método é um número inteiro.
- Tens de devolver um número inteiro (vê os [tipos incorporados][built-in types]).
- Podes usar o operador `-` para subtrair valores.

## 3. Calcula o tempo de preparação, em minutos

- Tens de definir um [método][methods] com um único parâmetro.
- O parâmetro do método é um número inteiro.
- Tens de devolver um número inteiro (vê os [tipos incorporados][built-in types]).
- Podes usar o operador `*` para multiplicar valores.

## 4. Calcula o tempo decorrido, em minutos

- Tens de definir um [método][methods] com dois parâmetros.
- Os parâmetros do método são do tipo inteiro.
- Tens de devolver um número inteiro (vê os [tipos incorporados][built-in types]).
- Podes [invocar][invocation] um dos outros métodos que definiste anteriormente.
- Podes usar o operador `+` para somar valores.
