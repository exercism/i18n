# Sobre

A [forma especial with][with] oferece uma forma de te concentrares no "caminho feliz" de uma série de passos que podem falhar e de tratares das falhas mais tarde.

Imagina que queres validar um nome de utilizador com várias verificações. Podes recorrer ao `case`:

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

Pode parecer legível agora, mas se acrescentares mais verificações aninhadas, vai ficar mais confuso. Nesta situação, usa o `with`:


```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

Em cada passo, se uma cláusula corresponder, a cadeia continua até que o bloco `do` seja executado. Se uma correspondência falhar, a cadeia para e é devolvida a cláusula que não correspondeu.

Podes usar guards na cadeia, bem como o operador `=` para correspondências normais.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

Por fim, tens a opção de usar um bloco `else` para apanhar correspondências falhadas e alterar o valor devolvido.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

O `else` é como uma instrução `case` para qualquer valor da cláusula `with` que não corresponda. Usa-se o primeiro valor que corresponder.
