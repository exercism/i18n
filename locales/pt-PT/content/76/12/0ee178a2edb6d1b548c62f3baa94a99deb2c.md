# Acerca de

Uma vez que as strings são [vetores][concept-vectors], que são sequências (ambos abordados noutros conceitos), todas as funções que trabalham com sequências funcionam também com strings, como `position`, `map`, `remove`, `concatenate`, _etc._

Há também funções mais específicas de strings para fazer coisas como comparar strings e ver qual delas é alfabeticamente menor ou maior, `string<` e `string>`; e funções para remover carateres à esquerda, à direita ou de ambos os lados de uma string (`string-trim`).
Consulta a [secção da Hyperspec sobre strings][hyper-string] para todos os detalhes.
