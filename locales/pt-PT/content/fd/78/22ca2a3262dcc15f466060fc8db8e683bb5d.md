# Introdução

O Swift tem um conjunto de instruções que podem ser usadas para alterar o fluxo de controlo normal dos ciclos.
São conhecidas como instruções de transferência de controlo.
Já viste o `return`; este conceito vai apresentar outras, que incluem `continue`, `break` e rótulos.
Não vamos abordar o `fallthrough` neste conceito, mas podes ler sobre ele no [livro de Swift][fallthrough].

## Continue

Por vezes é necessário saltar antecipadamente para a iteração seguinte de um ciclo, sem completar o resto das instruções da iteração atual do ciclo.
A palavra-chave `continue` pode ser usada para isso.
Quando o `continue` é executado, o ciclo salta para a verificação seguinte, para ver se a próxima iteração do ciclo pode ser executada, isto é, o `while` nos ciclos while e repeat-while, ou a verificação de se há outro elemento na sequência nos ciclos for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

O break serve para sair de um ciclo antecipadamente.
Quando o `break` é executado, o ciclo termina imediatamente e o programa continua com a primeira instrução depois do ciclo.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Rótulos

Quando os ciclos estão aninhados, há alturas em que podes querer usar `break` ou `continue` para sair ou reiniciar os ciclos exteriores que contêm o ciclo onde o `break` ou o `continue` são usados.
Em casos como estes, podes usar rótulos para especificar o ciclo de que queres sair ou que queres reiniciar.
Podes rotular um ciclo colocando um nome seguido de dois pontos antes do `while`, `repeat` ou `for` que inicia o ciclo.

Para veres o efeito de usar rótulos desta forma, repara no seguinte ciclo.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
