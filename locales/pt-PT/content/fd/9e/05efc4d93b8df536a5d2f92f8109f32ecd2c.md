# Introdução

Se queres construir algo com um Raspberry Pi, provavelmente vais usar _resistências_.
Tal como nos exercícios anteriores `Resistor Color Duo` e `Resistor Color Trio`, vais traduzir as faixas de cor das resistências em etiquetas legíveis para humanos.

- Cada resistência tem um valor de resistência.
- As resistências são pequenas, tão pequenas que, se imprimissem nelas o valor da resistência, seria difícil de ler.
  Para contornar este problema, os fabricantes imprimem faixas com código de cor nas resistências, para indicar os seus valores de resistência.
- Cada faixa funciona como um algarismo de um número.
  Por exemplo, se imprimissem uma faixa castanha (valor 1) seguida de uma faixa verde (valor 5), corresponderia ao número 15.
