# Introdução

Em Go, uma constante é um valor simples e imutável associado a um nome com a palavra-chave `const`:

```go
const myWebsite = "Exercism"
```

Estas constantes não têm tipo, mas recebem um tipo predefinido com base na sua sintaxe sempre que é necessário um tipo, por exemplo quando são passadas a um método.
Podes criar constantes com tipo adicionando um tipo de forma explícita:

```go
const myWebsite string = "Exercism"
```

Go não tem enumerações como algumas outras linguagens, mas tem um identificador predeclarado chamado `iota` para criar constantes enumeradas.
As constantes dentro de um bloco são repetidas implicitamente:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
