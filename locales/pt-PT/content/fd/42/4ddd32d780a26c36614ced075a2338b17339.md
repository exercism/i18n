# Instruções

És um grande fã do [canal de Youtube Numberphile](https://www.youtube.com/watch?v=PeUbRXnbmms) e acabaste de ver um vídeo interessante sobre a _Sequência de Números de Lucas_. Queres criar esta sequência com Elixir.

Ao conceber a tua função, queres tirar partido da _avaliação preguiçosa_, para poderes gerar tantos números quantos quiseres, mas só se precisares. Por isso decides usar um stream.

## 1. Detetar argumentos inválidos

Adiciona uma cláusula de guarda para lançar um erro se for usado um valor que não seja um inteiro, ou um inteiro menor que 1, para gerar a sequência. Fazer isto como primeiro passo evita erros de recursão infinita em passos posteriores.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. Gerar os casos base

Sabes que a sequência tem dois números iniciais que não seguem a mesma regra. Escreve duas cláusulas de caso base para devolver esses números:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. Criar o caso generalizado

Para qualquer sequência com mais de 2 elementos, sabes que tens de somar os dois números anteriores para obter o número seguinte, e assim por diante. Escreve o caso generalizado.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
