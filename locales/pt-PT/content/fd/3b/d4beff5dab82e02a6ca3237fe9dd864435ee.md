# Testes

Para correres os testes a partir do diretório do exercício, usa o comando:

```sh
odin test .
```

Enquanto estás a testar, o Odin consegue fazer "vet" ao teu código: pode procurar coisas como importações e variáveis não utilizadas. Corre os testes com:

```sh
odin test . -vet
```

Para mais opções, consulta `odin test -help`.
