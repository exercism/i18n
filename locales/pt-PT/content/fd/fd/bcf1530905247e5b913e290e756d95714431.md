# Introduction

Um *heap* é uma coleção que conhece sempre o seu menor elemento e permite removê-lo rapidamente, a implementação natural de uma *fila de prioridade*. Os heaps vivem no vocabulário [`heaps`][heaps].

`<min-heap>` constrói um heap vazio cuja menor chave sai primeiro; `<max-heap>` é a imagem espelhada. Cada item é um *valor* guardado sob uma *chave*, e a chave é a prioridade:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Um heap é *mutável*: `heap-push` altera-o no próprio local. `heap-peek` devolve o valor e a chave da frente sem os remover, `heap-pop` remove-os e devolve-os, e `heap-pop-all` esvazia o heap numa lista de associações de pares `{ key value }`, por ordem de prioridade:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
