# Instruções

O sistema de autenticação que viste pela última vez em [exercise:csharp/developer-privileges]() precisa de alguma atenção. Foi-te atribuída a tarefa de limpar o código. Um projeto de limpeza destes não só facilita a vida aos futuros responsáveis pela manutenção, como também revela e corrige algumas vulnerabilidades de segurança.

## 1. Define como const os campos e as propriedades adequados

Esta é uma tarefa de refatoração. Adiciona o modificador `const` a todos os membros de `Authenticator` ou `Identity` que consideres adequados.

## 2. Define os campos adequados como readonly

Esta é uma tarefa de refatoração. Adiciona o modificador `readonly` a todos os campos da classe `Authenticator` ou da estrutura `Identity` que consideres adequados.

## 3. Garante que a classe não pode ser alterada depois de criada

Remove o acessor `set` ou torna-o `private` em qualquer propriedade adequada da classe `Authenticator` ou da estrutura `Identity`.

## 4. Garante que não é possível adulterar o administrador

Neste momento, o campo de identidade do administrador é devolvido por uma chamada a `Admin`. Isto não é o ideal, pois quem chama pode modificar o campo. Encontra uma forma de impedir que quem chama modifique os dados do administrador no objeto `Authenticator`.

## 5. Garante que não é possível adulterar os programadores

Neste momento, o dicionário que contém as identidades de programadores privilegiados codificadas diretamente é devolvido por uma chamada a `GetDevelopers()`. Isto não é o ideal, pois quem chama pode modificar o dicionário. Encontra uma forma de impedir que quem chama modifique os dados dos programadores no objeto `Authenticator`.
