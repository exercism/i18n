# Testes

Para correr os testes, abre uma linha de comandos na pasta do exercício e executa o [comando `dotnet test`](https://docs.microsoft.com/en-us/dotnet/core/tools/dotnet-test).
Em alternativa, a maioria dos IDEs tem suporte incorporado para correr testes, incluindo o [Visual Studio](https://docs.microsoft.com/en-us/visualstudio/test/run-unit-tests-with-test-explorer), o [Rider](https://www.jetbrains.com/help/rider/Unit_Testing_in_Solution.html) e o [Visual Studio Code](https://github.com/OmniSharp/omnisharp-vscode/wiki/How-to-run-and-debug-unit-tests).
Consulta a [página de testes](https://exercism.org/docs/tracks/csharp/tests) para mais informações.

## Testes ignorados

Inicialmente, só o primeiro teste estará ativado.
O objetivo é incentivar-te a resolver o exercício passo a passo.
Assim que conseguires passar o primeiro teste, remove a propriedade `Skip` do teste seguinte e trabalha para o fazer passar também.
