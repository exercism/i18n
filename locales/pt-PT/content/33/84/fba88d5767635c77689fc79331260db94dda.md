# Instruções

É a final da temporada no clube local. Estás a gerir a tabela classificativa na linha de chegada: os corredores cruzam a meta por ordem, as faixas precisam de etiquetas e o registo oficial tem de ser anotado antes da próxima série.

Os nomes dos corredores chegam num array, por ordem de chegada: o nome na posição 0 é o vencedor, o da posição 1 é o segundo classificado, e assim por diante.

## 1. Atribuir dorsais

Define `assign-bibs` para receber um array de nomes de corredores e devolver um array de pares `{ position name }`, com a posição em primeiro lugar.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Etiquetas de faixa

Define `lane-labels` para receber um array de nomes de corredores e devolver strings como `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. Etiquetar os corredores

Define `tag-racers` para receber um array de nomes de corredores *e* uma string com uma marca, devolvendo etiquetas da forma `"<tag>/<index>: <name>"`. A mesma marca fica incorporada em todas as etiquetas.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. Registar as chegadas

Define `record-finishes` para receber um array de nomes de corredores e um registo (um vector). Para cada corredor, acrescenta ao registo uma string da forma `"<index>: <name>"`, modificando o registo no próprio local. Não devolve nada.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Sinos de volta

Define `lap-bells` para receber um número `laps` e devolver uma string composta por `"ding "` repetido `laps` vezes.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
