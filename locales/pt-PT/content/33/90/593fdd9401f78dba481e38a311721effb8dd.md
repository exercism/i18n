# Apêndice às instruções

## Implementação

Neste exercício vais implementar um procedimento que deve alocar a string que devolve. Desalocar a string é da responsabilidade de quem chama o procedimento.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
