# Testes

Para descarregar um exercício, por exemplo `hello-world`, abre um terminal e executa:

```bash
exercism download --track roc --exercise hello-world
```

Depois, vai para o diretório do exercício e edita o código para resolver o exercício. Por exemplo:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

Cada exercício vem com um conjunto de testes. Podes correr os testes com o comando `roc test`, por exemplo:

```
roc test hello-world-test.roc
```

Se já resolveste o exercício, deves ver 0 testes falhados, por exemplo:

```
All (5) tests passed in 123.4 ms.
```

No entanto, se o teu código tiver algum erro, vais ver algo assim:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

Isto deve ajudar-te a corrigir o código. Assim que o teu código funcionar, podes submetê-lo com o comando `exercism submit` (consulta o `HELP.md` no diretório do exercício para mais detalhes).
