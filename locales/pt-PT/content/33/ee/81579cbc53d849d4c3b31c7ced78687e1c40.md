# Instruções

Neste exercício vais escrever código para manteres o registo de uma lista de linguagens de programação que queres aprender no Exercism.

Tens nove tarefas, que vão todas envolver lidar com listas.

## 1. Cria uma nova lista

Para manteres o registo das linguagens que queres aprender, vais precisar de criar uma nova lista.

Implementa o método estático `Languages.NewList()` que devolve uma nova lista vazia.

```csharp
Languages.NewList()
// => empty list
```

## 2. Define uma lista existente

Atualmente, tens um pedaço de papel com a lista das linguagens que queres aprender: C#, Clojure e Elm.

Implementa o método estático `Languages.GetExistingLanguages()` para devolver a lista.

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. Adiciona uma nova linguagem a uma lista

À medida que exploras o Exercism e encontras linguagens mais interessantes, queres adicioná-las à tua lista.

Implementa a função estática `Languages.AddLanguage()` para adicionar uma nova linguagem ao fim da tua lista.

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. Conta as linguagens na lista

Contar as linguagens uma a uma é inconveniente.

Implementa o método estático `Languages.CountLanguages()` para contar o número de linguagens na tua lista.

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. Verifica se uma linguagem está na lista

Implementa o método estático `Languages.HasLanguage()` para verificar se uma linguagem está presente.

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. Inverte a lista

A certa altura, percebes que a tua lista está na verdade ordenada ao contrário!

Implementa o método estático `Languages.ReverseList()` para inverter a tua lista.

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. Verifica se a lista é entusiasmante

Embora gostes de todas as linguagens, o C# tem um lugar especial no teu coração. Como tal, ficas realmente entusiasmado com uma lista de linguagens se uma das seguintes condições for verdadeira:

- A primeira da lista é C#.
- O segundo item da lista é C# e a lista contém duas ou três linguagens.

Implementa o método estático `Languages.IsExciting()` para verificar se uma lista de linguagens é entusiasmante:

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.Remove linguagem

Implementa o método estático `Languages.RemoveLanguage()` para remover uma linguagem especificada da lista.

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. Verifica se todas as linguagens na lista são únicas

Implementa o método estático `Languages.IsUnique()` para verificar se alguma das linguagens se repete na lista.

A lista de linguagens (ou seja, o parâmetro) tem a garantia de não estar vazia quando este método é chamado e não importa se a lista for modificada.

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
