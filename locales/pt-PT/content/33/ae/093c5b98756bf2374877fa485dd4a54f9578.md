# Sobre

Jai é uma linguagem de sistemas concebida e criada pelo lendário programador de jogos Jonathan Blow.
Nasceu da frustração com a sobrecarga e a complexidade das linguagens existentes.

Os principais objetivos de conceção da Jai são a velocidade e a produtividade.
O compilador é incrivelmente rápido e os binários produzidos são muito compactos, com um runtime mínimo.

Uma das funcionalidades de destaque da Jai é o suporte para metaprogramação.
Tens acesso a todos os dados que o compilador usa internamente e podes manipulá-los como quiseres.
A Jai vai ainda mais longe: permite-te executar código Jai arbitrário em _tempo de compilação_!

Como o próprio sistema de compilação está inteiramente escrito em Jai, não precisas de aprender uma ferramenta de compilação à parte: basta escreveres código Jai para acederes ao sistema de compilação.

A Jai foi criada para ajudar a construir o jogo Order of the Sinking Star; por isso, vais descobrir que a Jai é ideal para construir jogos.
