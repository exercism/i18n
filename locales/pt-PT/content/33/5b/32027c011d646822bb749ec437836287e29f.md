# Import

A [forma especial `import`][import] permite-te usar funções e macros de um módulo externo sem usar o nome do módulo.

Importar um módulo externo inteiro pode criar conflitos com funções locais já existentes. Para evitar isso, tens duas opções: `:except` e `:only`. Ambas esperam uma lista de palavras-chave, em que a chave é o nome da função e o valor é a aridade da função.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

Normalmente, as importações são adicionadas no início da definição do módulo, mas podem ser adicionadas em qualquer lugar. Têm âmbito lexical, o que significa que uma importação adicionada dentro da definição de uma função não estará disponível noutra função.

As importações não utilizadas provocam avisos do compilador.

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
