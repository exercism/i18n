# Introdução

## Listas

Uma lista em Gleam é uma coleção imutável de zero ou mais valores. Os valores de uma lista têm de ser todos do mesmo tipo. Como as listas são imutáveis, depois de uma lista ser construída, o seu valor nunca pode mudar. Quaisquer funções ou operadores que pareçam modificar uma lista (como adicionar um elemento) devolvem, na verdade, uma nova lista.

As listas podem ser definidas da seguinte forma:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

A forma mais comum de adicionar um elemento a uma lista é através da sintaxe de espalhamento:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

O módulo [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) da biblioteca padrão do Gleam contém muitas funções úteis para trabalhar com listas. Este módulo é muito usado no código em Gleam, por isso é bom conhecê-lo bem.

Os padrões de listas podem ser usados em expressões case para fazer correspondência com listas e atribuir os valores nelas contidos a variáveis:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Além de fazer correspondência com listas de comprimento exato, a sintaxe de espalhamento pode ser usada para fazer correspondência com listas com pelo menos um certo comprimento:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

A sintaxe de espalhamento também pode ser usada para atribuir o resto da lista a uma variável:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

As expressões case devem ter um padrão para cada valor possível do tipo com que se está a fazer correspondência, por isso é frequente usar um padrão de descarte (`_`) no fim para tratar os valores que restarem.
