# Sobre

Uma [`list`][lists] em F# é uma coleção imutável de zero ou mais valores. Os valores numa lista têm de ser todos do mesmo tipo. Como as listas são imutáveis, depois de uma lista ser construída, o seu valor nunca pode mudar. As listas de F# têm uma _cabeça_ (o primeiro elemento) e uma _cauda_ (tudo o que vem depois do primeiro elemento). A cauda de uma lista é ela própria uma lista.

As listas podem ser definidas da seguinte forma:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

A forma mais comum de adicionar um elemento a uma lista é através do operador `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

As listas podem ser concatenadas com o operador `@` ou `List.append`:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

As listas são manipuladas por funções e operadores definidos no [módulo `List`][list-module]. Algumas destas funções também estão disponíveis como [propriedades][list-properties] de uma instância de `list`:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

Não há aqui uma opção certa ou errada. Em geral, as funções do módulo `List` dão-se melhor com a inferência de tipos, enquanto as propriedades permitem um código mais conciso.

Quaisquer funções/operadores que pareçam modificar uma lista (como adicionar um elemento) devolvem, na verdade, uma nova lista. No entanto, o desempenho normalmente não é um problema, porque a implementação das listas evita alocações/cópias desnecessárias.

Como as listas são implementadas como listas simplesmente ligadas, acrescentar um elemento ao início (com o operador `::`) é muito rápido, enquanto aceder a um elemento por índice pode ser relativamente lento.

As listas também podem ser processadas com correspondência de padrões através dos padrões [_list_][list-pattern] e [_cons_][cons-pattern]:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Também podes _descartar_ um valor ao fazer correspondência de padrões; quando _não_ te importas com um valor num caso específico (ou seja, não vais _usar_ um valor), podes usar um sublinhado (`'_'`) para indicar isso:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

O `'_'` único deve vir sempre _por último_ na correspondência de padrões; todos os valores que _não_ correspondam a nenhum dos outros casos serão tratados por este caso.
