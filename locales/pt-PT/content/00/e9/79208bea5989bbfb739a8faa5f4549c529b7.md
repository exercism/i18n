# Dicas

O teu código deve conter uma função frequency :: Int -> [Text] -> Map Char Int que
recebe um número de trabalhadores a usar em paralelo e uma lista de textos, e devolve
a frequência total de cada letra no texto.

## Benchmark

Verifica como a alteração do número de trabalhadores afeta o desempenho da tua solução,
correndo o benchmark. Usa `stack bench` para o correr. Não hesites em modificar
`bench/Benchmark.hs` para explorar o desempenho da tua solução com dados de entrada
diferentes.
