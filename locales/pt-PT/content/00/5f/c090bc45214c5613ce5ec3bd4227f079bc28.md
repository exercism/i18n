# Instruções

Enquanto trabalhas na _Instruments of Texas_, é-te pedido que trabalhes numa calculadora experimental de Notação Polaca Inversa [RPN] escrita em Elixir. A tua equipa tem um problema: algumas operações lançam erros e derrubam o processo. Foi-te pedido que escrevas uma função que encapsule a função de operação, para que os erros possam ser tratados de forma mais elegante com código Elixir idiomático.

## 1. Avisa a equipa

Implementa a função `calculate!/2` para chamar a função de operação com a pilha como único argumento. A função de operação está definida noutro local, mas sabes que pode ou terminar com sucesso ou lançar um erro.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> Os nomes de funções que terminam em `!` são um aviso aos programadores de que essa função pode lançar um erro

## 2. Encapsula o erro

Ao fazeres mais pesquisa, reparas que muitas funções usam átomos e tuplos para indicar o sucesso ou a falha. Implementa `calculate/2` com esta estratégia.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. Transmite a mensagem

Alguns dos erros contêm informação importante que os teus colegas precisam de ter para garantir o correto funcionamento do sistema. Implementa `calculate_verbose/2` para transmitir a mensagem de erro. O erro é uma struct que tem um campo `:message`.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
