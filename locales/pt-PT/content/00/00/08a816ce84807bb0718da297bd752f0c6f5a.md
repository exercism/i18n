# Introdução

Uma *expressão regular* (regex) é um pequeno padrão que descreve o
aspeto que um texto deve ter. As ferramentas de regex do Factor estão no
vocabulário [`regexp`][regexp], e um padrão escreve-se entre `R/ ` e `/`.

A maioria dos carateres de um padrão representa-se a si mesma. Alguns
elementos especiais representam *tipos* de caráter ou *quantos* esperar:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

Assim, `R/ [A-Z]{2}-\d{4}/` significa «duas maiúsculas, um hífen, quatro algarismos».

O `matches?` testa se uma string *inteira* corresponde ao padrão:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

Outras palavras olham para *dentro* de uma string: `all-matching-subseqs`
devolve todas as correspondências, `count-matches` conta-as,
`re-contains?` indica se há alguma correspondência, e `re-replace`
substitui cada correspondência por texto novo:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
