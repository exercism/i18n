# Introdução

Os tuplos são uma forma leve de agrupar um conjunto fixo de dados de tipos arbitrários. Um tuplo não tem
um nome próprio; dar um nome a uma estrutura de dados transforma-a num `struct`. Os campos de um tuplo não têm
nome; acede-se a eles por desestruturação ou por posição.

## Sintaxe

### Criação

Os tuplos são sempre criados com uma expressão de tuplo:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Os tuplos podem ter um número arbitrário de elementos.

### Acesso por desestruturação

É possível aceder aos elementos de um tuplo por desestruturação. Isto significa apenas atribuir nomes de
variáveis aos elementos individuais do tuplo, consumindo-o.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Acesso por posição

Também é possível aceder aos elementos de um tuplo através de um índice posicional numérico. A indexação,
como sempre, começa no 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Structs de tuplo

Também te vão pedir para trabalhar com structs de tuplo. Tal como as structs normais, estes são tipos com
nome; ao contrário das structs normais, têm campos anónimos. A sua sintaxe é muito semelhante à sintaxe
normal de tuplos. É possível usar tanto a desestruturação como o acesso posicional.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### Visibilidade dos campos

Todos os campos dos tuplos anónimos são sempre públicos. No entanto, os campos das structs de tuplo têm
visibilidade individual, que por defeito é privada, tal como os campos das structs normais. Podes tornar os
campos públicos com o modificador `pub`, tal como numa struct normal.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
