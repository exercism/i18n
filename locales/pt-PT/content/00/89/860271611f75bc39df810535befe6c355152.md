# Substitui os comentários provisórios

Substitui os comentários provisórios por uma descrição breve, mas útil, do pacote, e por uma ou duas frases que expliquem o que a função faz, que parâmetros recebe e o que devolve.
Comentários precisos e úteis sobre como usar o código são muito importantes para os programadores de Go.
Este é um excelente guia para escrever bons comentários: [Effective Go: Commentary](https://golang.org/doc/effective_go.html#commentary).
A ferramenta `godoc` produz automaticamente documentação a partir dos comentários do código, quando é executada.
Vê [godoc.org](https://godoc.org) para veres exemplos do resultado.
