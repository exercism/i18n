# Introdução

Uma forma comum de executar lógica condicional em JavaScript é a condicional.
É composta pela palavra-chave `if`, uma condição entre parênteses curvos e um bloco de código entre chavetas.
O bloco de código só é executado se a condição for avaliada como `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Podes usá-la isoladamente ou combiná-la com a palavra-chave `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Para aninhar outra condição na cláusula `else`, podes usar `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
