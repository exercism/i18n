# Introdução

O Common Lisp tem um conceito chamado The Printer, que inclui todas as funções para escrever representações textuais de dados Lisp. Uma dessas funções é `format`, que permite ao programador formatar os dados como quiser.

As capacidades de `format` e do Printer do Lisp em geral são um tema enorme. Aqui vamos descrever o básico da utilização de `format`.

## A função FORMAT

A função `format` recebe pelo menos dois argumentos: um stream para onde imprimir e uma string de controlo que define o que é impresso e como.

Os streams são um conceito à parte, que será descrito noutro sítio. Para já, basta saber que a impressão é feita para o stream e que há dois valores especiais para este argumento: `t` e `nil`. O `t` significa imprimir para a saída padrão (na verdade, o stream ao qual está ligada a variável `*standard-output*`), e o `nil` significa criar uma string e devolvê-la.

Repara que o `format` avalia sempre para `nil`, exceto no último caso, em que se especifica `nil` como stream. É uma forma comum de fazer simples interpolação ou construção de strings.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## Diretivas de formato

A string de controlo pode conter «diretivas de formato», que dão instruções ao `format` sobre o que imprimir e como interpretar quaisquer outros parâmetros que este receba. De certa forma, a string de controlo é um programa que o `format` vai interpretar e executar. Todas as diretivas começam com `~` e são seguidas de um caráter (_por exemplo_, `~A`, `~D`, `~&`). O facto de o caráter ser maiúsculo ou minúsculo não interessa.

A maioria das diretivas de formato limita-se a interpolar um argumento do `format` na saída. Diz-se que «consome» esse argumento. Há diretivas que não consomem argumentos e outras que consomem mais do que um. Uma diretiva permite até saltar de um sítio para outro na lista de argumentos ou ignorar argumentos.

## Formatação básica

Uma diretiva de formato muito versátil é `~A`. Esta imprime uma versão «legível por humanos» dos dados.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

Outra diretiva de formato útil é `~S`. Esta imprime uma versão «legível por máquinas» dos dados. Isto pode ser muito útil se quiseres conseguir interpretar a saída produzida como dados Lisp. Para muitas coisas, o resultado é igual ao de `~A`, mas repara que, no caso das strings, por exemplo, a saída inclui as aspas (com escape quando a string fica dentro de outra), para que o valor possa voltar a ser lido como uma string.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

Há mais duas diretivas muito úteis: `~%` e `~&`. A primeira imprime um caráter de nova linha e a segunda imprime uma «linha nova». A diferença é que `~%` imprime sempre uma nova linha, enquanto `~&` só imprime uma se não estiveres já no início de uma linha. Nenhuma delas consome um argumento.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

Por fim, `~~` é uma diretiva simples que imprime um `~` literal.
