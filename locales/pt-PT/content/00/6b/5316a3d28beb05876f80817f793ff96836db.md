# Sobre

Em Elixir, as funções podem ter um despacho dinâmico.

Todos os nomes de módulos são átomos. Todos os nomes de módulos em Elixir recebem automaticamente o prefixo `Elixir.` ao serem compilados.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

O Elixir consegue resolver uma função a invocar em tempo de execução, usando o nome do módulo para fazer a pesquisa. A pesquisa pode ser feita dinamicamente se o nome do módulo estiver ligado a uma variável.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
