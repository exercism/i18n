# Introdução

Por vezes, precisas de ver uma sequência como uma série de *pedaços* em vez de elemento a elemento. Os vocabulários [`grouping`][grouping], [`splitting`][splitting] e [`splitting.monotonic`][splitting.monotonic] dão-te quatro formas de o fazer.

## `group`: blocos disjuntos de tamanho *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

Se o comprimento da sequência não for um múltiplo de *n*, o último bloco fica mais curto do que *n*.

## `clump`: janela deslizante sobreposta de tamanho *n*

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

Se a sequência for mais curta do que *n*, o resultado fica vazio.

## `split-when`: divide onde um predicado dispara

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

Cada elemento tem a sua própria chamada ao predicado; os elementos que dão verdadeiro são os *pontos de quebra* e não ficam no resultado.

## `monotonic-split`: divide segmentos onde uma verificação de pares adjacentes falha

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

O predicado é aplicado a *pares adjacentes*. Enquanto devolve verdadeiro, o segmento continua; quando devolve `f`, começa um novo pedaço. Com `[ = ]` obténs segmentos de elementos iguais; com `[ <= ]` obténs segmentos não decrescentes; e assim por diante.

## Quando usar cada um

- **`group`/`clump`**: sabes o *tamanho* que queres.
- **`split-when`**: sabes como é um *elemento de quebra*.
- **`monotonic-split`**: sabes o que faz com que dois elementos adjacentes *continuem a pertencer ao mesmo grupo*.
