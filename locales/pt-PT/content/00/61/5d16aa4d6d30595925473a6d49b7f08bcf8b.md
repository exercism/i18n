# Instruções

No circo, cada arnês tem uma classificação de carga em quilogramas, e ninguém sobe antes de os números serem verificados.

A classe `SAFETY_HARNESS` precisa do seguinte. O esqueleto dá-te a classe e o respetivo atributo; acrescenta o resto. Cada rotina abaixo tem um contrato, e as dicas dizem quais.

## 1. Monta um arnês

`create` recebe a carga para a qual o arnês está classificado e devolve um arnês. Uma classificação de zero ou menos não é arnês nenhum, por isso tem de ser uma `pre`.

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. Quanto sobra?

`spare_capacity` recebe a carga que está no arnês e devolve quanto mais este poderia aguentar. A carga não pode ser negativa, nem pode exceder o limite: ambas são `pre`. A resposta nunca é negativa, o que é uma `post`.

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. Quão cheio está?

`percent_used` recebe a carga e devolve-a como percentagem do limite, arredondada por baixo. A carga não pode ser negativa, e a resposta nunca é negativa.

```sather
harness.percent_used(60)
-- => 50
```

## 4. É seguro?

`is_safe` recebe a carga e responde se esta está dentro do limite. Pode-se perguntar por qualquer carga, incluindo uma disparatada, por isso não há uma `pre` na carga, mas escreve uma `post` a dizer que a resposta é true exatamente quando a carga está dentro do limite.

```sather
harness.is_safe(200)
-- => false
```
