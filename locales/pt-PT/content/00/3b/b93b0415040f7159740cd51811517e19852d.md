# Testes

Precisas de ter o [Godot instalado][installation] corretamente para usar o executor de testes.

## Executar os testes

O [executor de testes][test runner] é usado para carregar e testar soluções.
Para executar o executor de testes, descarrega-o localmente e depois usa o `godot` para o executar.
No futuro, o executor de testes será descarregado automaticamente juntamente com os exercícios quando usares o `exercism download`.

### Obter o executor de testes

Podes usar o seguinte excerto de shell para descarregar o executor de testes.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### Executar o executor de testes

O executor de testes é executado com o `godot` em modo headless (sem IDE).
`-s` ou `--script` diz ao Godot para executar o script do executor de testes.
O executor de testes espera dois argumentos: o slug e o caminho para o diretório da solução.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

Por exemplo,

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
