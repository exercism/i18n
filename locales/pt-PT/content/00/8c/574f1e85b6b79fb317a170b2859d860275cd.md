# Noções básicas

Um programa Sather é feito de **classes**. Uma classe é uma caixa com nome que guarda
rotinas. Uma **rotina** é um pedaço de trabalho com nome que produz uma resposta.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

A ler isto de cima para baixo:

- `class GREETER is` abre a caixa e dá-lhe um nome. Os nomes das classes escrevem-se em
  maiúsculas.
- `hello : STR is` inicia uma rotina chamada `hello` que produz um `STR`, um
  pedaço de texto a que se chama *string*. O `: STR` é uma promessa sobre o tipo
  de resposta que vem de volta.
- `return "Hello!";` devolve a resposta. O texto escreve-se entre aspas
  duplas.
- `end;` fecha a rotina, e o segundo `end;` fecha a classe.

Tudo o que vem depois de `--` numa linha é um **comentário**. O Sather ignora-o;
está ali para as pessoas.

```sather
-- This line is for the reader, not the computer.
```

Para usar uma rotina de outro sítio, escreve o nome da classe, dois pontos duplos, e
o nome da rotina:

```sather
GREETER::hello        -- this is "Hello!"
```

Dentro da mesma classe podes omitir o nome da classe:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

Uma rotina que não recebe argumentos chama-se sem parênteses: `hello`, e não
`hello()`.
