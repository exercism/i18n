# Instruções

Uma escola perto de ti tem uma associação de estudantes muito ativa.
A associação de estudantes é gerida por um presidente e, a cada 2 anos,
realizam-se eleições para eleger um novo presidente.

Na eleição deste ano, decidiu-se que era necessário um novo sistema digital
para contar os votos. A escola precisa da tua ajuda para construir este novo sistema.

## 1. Obter o número de votos de um `ElectionResult`

O novo sistema vai precisar de uma forma de obter o número de votos a partir de um contador.

A struct do resultado eleitoral já está criada para ti e está definida assim:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

Como todos os membros da `struct` são públicos, não precisas de escrever um `constructor` para inicializar um objeto `ElectionResult`.
Em vez disso, podes usar uma `initializer list`:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

Cria uma função `vote_count` que recebe uma referência a um `ElectionResult` como argumento e devolve o número de votos do `ElectionResult`.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. Incrementar os votos de um `ElectionResult`

Finalmente chegou a hora de processar os votos!
Agora precisas de uma forma de incrementar os votos de um `ElectionResult`.

Cria uma função `void` `increment_vote_count` que recebe uma referência a um `ElectionResult` como argumento e um número de votos, e incrementa o `ElectionResult` nesse número de votos.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. Contagem de votos e presidência

A escola entregou os seus votos e agora é altura de verificar os resultados para descobrir o vencedor.

Cria uma função `determine_result` que recebe uma referência a uma contagem final e devolve uma referência ao `ElectionResult` do novo presidente.
Também deve alterar o nome do vencedor, acrescentando-lhe o prefixo "President".
A contagem final é dada na forma de uma `reference` a `std::vector<ElectionResult>`, um vector com os `ElectionResults` de todos os candidatos participantes.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

Para simplificar, podes assumir o seguinte:
- O `vector` tem pelo menos um elemento.
- Não haverá empates no primeiro lugar.
