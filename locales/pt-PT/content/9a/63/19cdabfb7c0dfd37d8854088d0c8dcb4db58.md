# Sobre

Um parâmetro de um método pode tornar-se opcional se lhe atribuíres um valor predefinido. Quando um parâmetro é opcional, quem chama o método não é obrigado a fornecer um argumento para esse parâmetro; nesse caso, é usado o valor predefinido. Os [parâmetros opcionais][optional-arguments] _têm de_ ficar no fim da lista de parâmetros: não podem ser seguidos de parâmetros não opcionais. Se um método tiver vários parâmetros opcionais, podes especificar apenas alguns deles com [argumentos nomeados][named-arguments].

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

O valor de um parâmetro opcional tem de ser um dos seguintes:

- Uma expressão constante (por exemplo, `"hi"`, `2`, `DayOfWeek.Friday`, `null`, etc.)
- Uma expressão `new` de um tipo de valor
- Uma expressão `default` de um tipo de valor
