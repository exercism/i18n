# Instruções

És analista de dados numa empresa que analisa dados meteorológicos no Noroeste Pacífico.
Vais trabalhar com uma base de dados que contém uma tabela `weather_readings` com as seguintes colunas.

* `date`: A data em que a amostra foi recolhida.
* `location`: O nome da cidade onde a amostra foi recolhida.
* `temperature`: A temperatura, em graus Fahrenheit.
* `wind_speed`: A velocidade do vento, em milhas por hora.

Em cada uma das tarefas seguintes, o teu trabalho é obter o conjunto de resultados indicado, utilizando uma instrução `SELECT`.
Repara que, em cada caso, o conjunto de resultados será armazenado numa nova tabela (uma tabela por tarefa), através de uma instrução `CREATE TABLE` previamente escrita.
Por agora, não te preocupes com o `CREATE TABLE`; isso será abordado noutra lição.
Concentra-te apenas em adicionar a instrução `SELECT` adequada para realizar a tarefa indicada.

## 1. Obtém todos os dados

Obtém todos os dados da tabela `weather_readings`.

## 2. Obtém apenas os dados de localização e temperatura

Obtém apenas os valores de localização e temperatura da tabela `weather_readings`.

## 3. Obtém apenas os dados de Seattle

Obtém apenas os dados relativos à localização de Seattle.

## 4. Obtém apenas os dados com velocidade do vento num intervalo específico

Obtém apenas os dados em que a velocidade do vento está entre 5 e 15 milhas por hora.
