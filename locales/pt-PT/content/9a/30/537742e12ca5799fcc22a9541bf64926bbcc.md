# Adenda às instruções

## Memória reservada

O buffer da string de entrada usa os bytes 64 a 191 da memória linear.


## Formato de saída

A série de números é esperada como um único array contínuo de números u8; este será dividido por comprimento na desserialização:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
