# Sobre

## Ciclos for

Uma instrução `for` repete um bloco de código.
A sua primeira linha controla a frequência com que o bloco se repete:

```go
for init; condition; post {
    // loop body
}
```

- A instrução **init** é executada uma vez antes da primeira iteração. É comum declarar e inicializar uma variável contadora usada pelo ciclo.
- A **condition** é uma expressão Boolean avaliada antes de cada iteração. O ciclo para quando esta é avaliada como `false`.
- A instrução **post** é executada depois de cada iteração concluída. Pode ser usada para atualizar um contador.

Não coloques `init; condition; post` entre parênteses.
No entanto, as chavetas `{ }` que rodeiam o corpo do ciclo são sempre obrigatórias.

Este ciclo começa `i` em `1`, imprime o valor atual de `i`, incrementa-o para a iteração seguinte e para quando `i` chega a `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## Outras formas de ciclo

### Ciclo só com condição

As instruções init e post podem ser omitidas.
Uma instrução `for` só com uma condição tem o mesmo propósito que um ciclo `while` noutras linguagens.
O Go não tem a palavra-chave `while`.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Ciclo infinito

Uma instrução `for` pode ser escrita sem condição:

```go
for {
    // loop body
}
```

Este ciclo não termina por si só.
A execução tem de sair do ciclo explicitamente, por exemplo com `break` ou `return`.

## Controlar ciclos

### Break e continue

Neste ciclo, o `break` sai do ciclo:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

O `continue` salta o resto do corpo do ciclo atual e passa à iteração seguinte:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### Break e continue com rótulos

Com ciclos aninhados, um `break` ou um `continue` sem rótulo aplica-se ao ciclo mais interior.
Para rotular um ciclo exterior, coloca um identificador seguido de dois pontos na linha imediatamente acima dele.
Depois, escreve o rótulo do ciclo a seguir ao `break` ou ao `continue` para direcionar a ação para esse ciclo:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
