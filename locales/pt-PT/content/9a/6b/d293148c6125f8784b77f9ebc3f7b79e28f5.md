# Dicas

## Geral

- Certifica-te de que lês a documentação dos [decoders][decode] e dos [encoders][encode]
- A [documentação do GitHub][github] que inspirou este exercício contém mais informação sobre os objetos JSON
- Deves conseguir usar [`Decode.decodeString`][decode-decodeString] para testares os teus decoders com dados arbitrários

## 1. O ID, por favor!

Podes resolver a tarefa com as seguintes funções:

- [`int`][decode-int]
- [`field`][decode-field]

## 2. Qual é o meu nome, mesmo?

Há duas formas principais de resolver a tarefa:

- usar [`maybe`][decode-maybe]
- usar [`oneOf`][decode-oneOf] com dois decoders possíveis, um que usa uma combinação de [`field`][decode-field], [`string`][decode-string] e [`map`][decode-map], e outro que usa [`succeed`][decode-succeed]

## 3. User? Quase não o conheço!

Podes resolver a tarefa com as seguintes funções:

- `decodeId` e `decodeName`
- `User` usado como construtor de tipo
- [`map5`][decode-map5]
- [`field`][decode-field]
- [`int`][decode-int]
- [`string`][decode-string]
- [`bool`][decode-bool]

## 4. Sou um comentário forte e independente

Podes resolver a tarefa com as seguintes funções:

- [`field`][decode-field]
- [`int`][decode-int]
- [`nullable`][decode-nullable]

## 5. Trabalho extra

Podes resolver a tarefa com as seguintes funções:

- [`field`][decode-field]
- [`string`][decode-string]
- [`andThen`][decode-andThen]
- uma instrução case que verifica o conteúdo da string que está a ser descodificada
- [`succeed`][decode-succeed]
- [`fail`][decode-fail]

## 6. O despertar dos links

Podes resolver a tarefa com as seguintes funções:

- [`field`][decode-field]
- [`dict`][decode-dict]
- [`string`][decode-string]

## 7. Sim, comentários

Podes resolver o `decodeComment` com as seguintes funções:

- `decodeId`, `decodePullRequestReviewId`, `decodeUser`, `decodeSide`, `decodeLinks`
- `Comment` usado como construtor de tipo
- [`6`][decode-6]
- [`field`][decode-field]
- [`string`][decode-string]

Podes resolver o `decodeComments` com as seguintes funções:

- `decodeComment`
- [`list`][decode-list]

## 8. Tudo se liga

Todas as funções necessárias para esta tarefa estão definidas na [documentação dos encoders][encode], e potencialmente algumas do [módulo `Maybe`][maybe]
