# Introdução

O tipo `Option` é o mecanismo da linguagem F# para lidar com valores que podem existir ou não.
Oferece uma alternativa segura em termos de tipos ao uso de `null`, comum noutras linguagens para lidar com esse tipo de valores.
É usado em muitas funções da biblioteca padrão do F#, por isso é essencial compreendê-lo para usar a biblioteca padrão do F# com eficácia.

## Utilização 

O tipo `Option` é um tipo genérico (tem um tipo subjacente).  
Os valores de `Option` são `Some value`, que representa um valor concreto, ou `None`, que representa a ausência de valor.

A função seguinte mostra como criar um valor `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` é a sintaxe pós-fixada equivalente a `Option<T>`; as duas formas sintáticas podem ser usadas indistintamente.
No entanto, segundo o F# Style Guide, a notação pós-fixada é preferida para tipos Option (ver [secção do F# Style Guide sobre formatação de tipos e anotações de tipo](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

## Ler o conteúdo de um valor Option

A forma idiomática de ler um valor `Option` é através de correspondência de padrões, como mostra o exemplo seguinte:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Desembrulhar Options com valores predefinidos

Os `Option`s podem ser "desembrulhados" (convertidos no tipo que contêm) ao fornecer valores predefinidos com a função `Option.defaultValue`. 
Isto é particularmente útil quando queres garantir que o valor não é `None`.
Por exemplo:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
