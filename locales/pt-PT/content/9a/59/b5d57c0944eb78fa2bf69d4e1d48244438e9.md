# Instruções

És um observador de aves entusiasta que acompanha quantas aves visitaram o teu jardim nos últimos sete dias.

Tens seis tarefas, todas relacionadas com o número de aves que visitaram o teu jardim.

## 1. Verifica quais foram as contagens da semana passada

Para poderes comparar, tens sempre por perto uma cópia das contagens da semana passada, que foram: 0, 2, 5, 3, 7, 8 e 4. Define a ligação `lastWeek` que contém as contagens da semana passada:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Verifica quantas aves visitaram ontem

Implementa a função `yesterday` para devolver quantas aves visitaram o teu jardim ontem. As contagens de aves estão ordenadas por dia: o primeiro elemento é a contagem do dia mais antigo e o último é a contagem de hoje.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Calcula o número total de aves visitantes

Implementa a função `total` para devolver o número total de aves que visitaram o teu jardim:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Verifica se houve um dia sem aves visitantes

Implementa a função `dayWithoutBirds`, que devolve `true` se houve um dia em que zero aves visitaram o jardim; caso contrário, devolve `false`:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Incrementa a contagem de hoje

Implementa a função `incrementTodaysCount` para incrementar a contagem de hoje e devolver as contagens atualizadas:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Verifica se a semana é invulgar

Ao longo do último ano, descobriste que algumas semanas têm os mesmos padrões invulgares:
- Em cada dia par da semana, não havia aves
- Em cada dia par da semana, foram avistadas exatamente 10 aves
- Em cada dia ímpar da semana, foram avistadas exatamente 5 aves

Implementa a função `unusualWeek`, que devolve `true` se o padrão de contagem de aves desta semana corresponder a um dos padrões invulgares:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Repara que a paridade dos dias é indexada a partir de 1, não de 0: o primeiro elemento do array corresponde a um dia ímpar)
