# Sobre

Por predefinição, as variáveis ficam limitadas ao âmbito em que são definidas. Se forem definidas num ficheiro fora de uma função ou classe, ficam limitadas ao âmbito do ficheiro. Se forem definidas numa função ou classe, ficam limitadas ao âmbito da função ou da classe.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Âmbito global

Usar a palavra-chave `global` antes de uma atribuição a uma variável cria uma variável com âmbito global. Este padrão é muitas vezes desaconselhado, porque cria [código fortemente acoplado](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>).

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Âmbito estático

Usar a palavra-chave `static` antes de uma atribuição ou declaração de variável preserva o âmbito da variável, mas o seu valor é preservado entre âmbitos de execução.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

Neste exemplo, a variável `$count` é inicializada a 0 _apenas na primeira chamada à função_. Em todas as chamadas seguintes, o valor passa para a chamada seguinte. Por isso, cada invocação da função devolve um número inteiro crescente.
