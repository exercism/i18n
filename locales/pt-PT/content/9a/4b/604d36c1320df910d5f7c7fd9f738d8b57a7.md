# Dicas

## Geral

- [Os conjuntos][sets] são coleções mutáveis e não ordenadas, sem elementos duplicados.
- Os conjuntos podem conter qualquer tipo de dados.
- Os conjuntos são [iteráveis][iterable].
- Os conjuntos são usados sobretudo para remover rapidamente duplicados de outras coleções ou para testar pertença.
- Os conjuntos também suportam operações matemáticas como `union`, `intersection`, `difference` e `symmetric difference`

## 1. Limpar os ingredientes dos pratos

- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Os vetores são iteráveis.
- Lembra-te: os tuplos podem ser formados com `(element_1, element_2)`.

## 2. Cocktails e mocktails

- Um `Set` é _disjunto_ de outro conjunto se os dois conjuntos não partilharem elementos.
- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Os vetores são iteráveis.
- As strings podem ser concatenadas com o sinal `*` e a interpolação pode ser feita com `$()`.

## 3. Categorizar os pratos

- Usar ciclos para iterar pelas categorias de refeições disponíveis pode ser útil aqui.
- Se todos os elementos de `set_1` estiverem contidos em `set_2`, então `set_1 ⊆ set_2`.
- O método equivalente a `set ⊆ iterable` é `issubset(set, iterable)`
- Os tuplos podem conter qualquer tipo de dados, incluindo outros tuplos. Os tuplos podem ser formados com `(element_1, element_2)`.
- Os elementos de um tuplo podem ser acedidos a partir da esquerda com um índice de base 1, ou a partir da direita com um índice baseado em `end` (por exemplo, `tuple[end]`).
- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Os vetores são iteráveis.
- As strings podem ser concatenadas com o sinal `*` e a interpolação pode ser feita com `$()`.

## 4. Etiquetar alergénios e alimentos restritos

- Uma _interseção_ de conjuntos são os elementos partilhados entre `set_1` e `set_2`.
- O método de conjunto equivalente a `set ∩ iterable` é `intersect(set, iterable)` ou `∩(set, iterable)`.
- Os elementos de um tuplo podem ser acedidos a partir da esquerda com um índice de base 1, ou a partir da direita com um índice baseado em `end` (por exemplo, `tuple[end]`).
- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Os vetores são iteráveis.
- Os tuplos podem ser formados com `(element_1, element_2)`.

## 5. Compilar uma "lista principal" de ingredientes

- Uma _união_ de conjuntos é quando os elementos de `set_1` e `set_2` são combinados num único `Set`.
- O método de conjunto equivalente a `set ∪ iterable` é `union(set, iterable)` ou `∪(set, iterable)`
- Usar ciclos para iterar pelos vários pratos pode ser útil aqui, mas o splatting também pode funcionar.

## 6. Separar os aperitivos para servir em tabuleiros

- Uma _diferença_ de conjuntos é quando os elementos de `set_2` são removidos de `set_1`, por exemplo, `setdiff(set_1, set_2)`.
- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Os vetores são iteráveis.
- O construtor Vector pode receber qualquer [iterável][iterable] como argumento. Os conjuntos são iteráveis.

## 7. Encontrar ingredientes usados em apenas uma receita

- Uma _diferença simétrica_ de conjuntos é quando os elementos aparecem em `set_1` ou em `set_2`, mas não em **_ambos_** os conjuntos.
- Uma _diferença simétrica_ de conjuntos é o mesmo que subtrair a _interseção_ dos `Set` à _união_ dos `Set`, por exemplo, `setdiff(set_1 ∪ set_2, set_1 ∩ set_2)`
- Uma _diferença simétrica_ de mais de dois `Sets` inclui elementos que se repetem mais de duas vezes nos `Sets` de entrada. Para remover esses elementos repetidos entre conjuntos, é preciso subtrair as _interseções_ entre pares de conjuntos à diferença simétrica.
- Usar ciclos para iterar pelos vários pratos pode ser útil aqui, mas o splatting também pode funcionar.
