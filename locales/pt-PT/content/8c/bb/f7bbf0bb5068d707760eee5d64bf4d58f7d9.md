# Instalação

## Instala o ambiente de execução do R
Visita a [página inicial do CRAN](https://cran.r-project.org/). Aí encontras ligações de descarregamento para Linux, Mac OSX e Windows. Descarrega e executa o instalador para o teu sistema operativo.

## Instala o IDE RStudio (recomendado)
O RStudio é um ambiente de desenvolvimento integrado (IDE) popular e multiplataforma para programar em R (e também suporta outras linguagens, como Python, JavaScript e Markdown). Usar o RStudio facilita a escrita das tuas soluções de código e a execução dos testes.

Descarrega e instala a [versão estável atual do RStudio](https://www.rstudio.com/products/rstudio/download/). Ou, em alternativa, obtém a [versão de pré-visualização](https://www.rstudio.com/products/rstudio/download/preview/) de uma versão futura.

## Instala a extensão de R para o Visual Studio Code (alternativa)
A extensão de R para o Visual Studio Code suporta realce de sintaxe avançado, preenchimento automático de código, linting, formatação, interação com terminais de R, visualização de dados, gráficos, variáveis do espaço de trabalho, páginas de ajuda, gestão de pacotes e trabalho com documentos R Markdown.

Descarrega e instala a [versão atual da extensão de R](https://code.visualstudio.com/docs/languages/r)

## Instala os pacotes de R para correr os testes
O executor de testes das especificações é a biblioteca [`testthat`](https://github.com/hadley/testthat) de Hadley Wickham, que é uma escolha popular entre os autores de pacotes de R.

Para instalar esta biblioteca, escreve o seguinte na consola do RStudio (ou onde quer que estejas a usar R).

```{R}
install.packages("testthat")
```

Embora seja pouco provável que _precises_ de instalar pacotes para resolver os problemas do Exercism, podes querer trazer um pacote de utilitários de uso geral como o [`tidyverse`](https://github.com/tidyverse/tidyverse) que se adeque ao teu estilo de programação. Para instalar e carregar um pacote como o `tidyverse`:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
