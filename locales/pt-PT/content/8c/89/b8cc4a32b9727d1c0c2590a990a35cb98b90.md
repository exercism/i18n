## 1. Adicionar uma pessoa à fila

- Há [um método][append] para acrescentar um elemento a um array.

## 2. Onde estão os meus amigos?

- Há [um método][index] para obter o índice de um elemento num array.

## 3. Posso juntar-me a eles?

- Podes usar métodos já definidos para obter o índice do amigo e inserir a pessoa nesse índice.
- Há [um método][insert] para inserir um elemento num índice específico de um array.

## 4. Pessoa antipática na fila

- Há [um método][delete] para eliminar um elemento de um array.

## 5. Ordenar a lista da fila

- Há [um método][sort] para ordenar um array.
