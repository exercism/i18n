### Exportar funções

Exportar funções foi abordado no primeiro conceito, por isso aqui fica uma revisão rápida.

Cada ficheiro em Elm é um módulo e tem de conter uma instrução `module` antes de todo o resto do código.

Os nomes dos módulos têm de corresponder ao nome do ficheiro, por isso o módulo `Calculator` tem de estar no ficheiro Calculator.elm, e o módulo `Parser.Utils` tem de estar no ficheiro Parser/Utils.elm.

Tudo o que é definido dentro de um módulo tem âmbito privado e não pode ser acedido a partir de fora desse módulo, a menos que esteja listado em `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### Importar funções de outros módulos

Para acederes a funções definidas noutros módulos, importas esses módulos.
Quando importas um módulo, ficas com acesso a todas as funções que ele expôs.
Mas a forma como lhes acedes varia consoante a maneira como importas o módulo.

As importações qualificadas são o comportamento predefinido, e para acederes a uma função desse módulo (por exemplo, a função `map` do módulo `List`) escreves o nome do módulo como prefixo (`List.map`).

As importações abertas dão acesso direto às funções expostas desse módulo, sem prefixo. Fazem-se com a palavra-chave `exposing`, como um espelho da que usas nas exportações. Podes expor todas as funções disponíveis (com `..`) ou apenas algumas (por exemplo, `map`).

Também podes importar tipos e os respetivos construtores de outros módulos, mas isso é um conceito mais à frente.

Dá-se preferência às importações qualificadas, para maior clareza e para evitar conflitos de nomes.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

### Anotações de tipo

As anotações de tipo definem-se com `name : parameter types -> return type`, sendo os tipos dos parâmetros também separados por `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Podes usar parênteses para definir parâmetros de funções (que são eles próprios definidos com a mesma sintaxe, daí a necessidade dos parênteses).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

### Números

Em Elm existem dois tipos de números, definidos pelos tipos `Int` e `Float`.
O `Int` corresponde ao conjunto dos números inteiros positivos e negativos.
O `Float` corresponde ao conjunto dos números reais, limitado pela precisão do computador.
As operações definidas sobre números costumam funcionar num tipo ou no outro, mas não misturando os dois.
Existem funções para converter entre os dois, como `toFloat`, que converte `Int` em `Float`, e `round`, `floor`, `ceiling` ou `truncate`, que convertem um `Float` num `Int` com semânticas diferentes.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

### Operações com strings

Para descrever palavras e frases no código, o Elm tem um tipo `String` nativo.
Os literais de string escrevem-se entre aspas duplas, como `"Hello World!"`.
O operador de concatenação de strings `++` e o operador de igualdade `==` estão disponíveis por predefinição.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

A maioria das outras funções de string está no módulo `String`, que tem de ser importado.

https://package.elm-lang.org/packages/elm/core/latest/String
