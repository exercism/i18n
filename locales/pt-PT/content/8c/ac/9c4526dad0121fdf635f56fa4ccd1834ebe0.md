# Cabeçalho fictício

## Usar ou não `grep`, eis a questão

Embora este exercício se resolva trivialmente bastando passar os
argumentos ao `grep`, implementa este exercício apenas com Bash. O objetivo
deste percurso do Exercism é aprender a usar os comandos internos do Bash para
resolver problemas.

Para resolver este exercício, vais precisar de:

* analisar os argumentos da linha de comandos: o [`getopts`](https://stackoverflow.com/tags/getopts/info) é útil para isso.
* iterar sobre as linhas de um ficheiro: para isso, consulta a [FAQ n.º 1 do Bash](https://mywiki.wooledge.org/BashFAQ/001)
* usar correspondência de expressões regulares: o Bash consegue fazê-lo com o operador `=~`
  dentro de [`[[ ... ]]`](https://www.gnu.org/software/bash/manual/bash.html#index-_005b_005b)
