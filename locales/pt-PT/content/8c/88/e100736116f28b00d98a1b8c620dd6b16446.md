# Instruções

Se quiseres construir algo com um Raspberry Pi, provavelmente vais usar _resistências_.
Para este exercício, precisas de saber duas coisas sobre elas:

- Cada resistência tem um valor de resistência.
- As resistências são pequenas, tão pequenas que, se imprimisses nelas o valor da resistência, seria difícil de ler.

Para resolver este problema, os fabricantes imprimem faixas com um código de cores nas resistências para indicar os seus valores de resistência.
Cada faixa tem uma posição e um valor numérico.

As primeiras 2 faixas de uma resistência têm um esquema de codificação simples: cada cor corresponde a um único número.

A terceira faixa é um multiplicador.

Neste exercício vais criar um programa útil para não teres de te lembrar dos valores das faixas.

Podes encontrar mais informações sobre a codificação de cores das resistências no [artigo da Wikipédia sobre o código de cores eletrónico][e-color-code].

## 1. Define um vetor com nomes

As cores estão codificadas da seguinte forma:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

Cria o vetor com nomes, `resistor_bands`, que deve ter as cores como nomes e os números como valores.

## 2. Devolve o valor associado a uma faixa

Primeiro, vais querer conseguir encontrar o valor único de qualquer faixa colorida.

Define uma função `band_value(band)` que recebe um `string` com a cor de uma faixa.
A função devolve o valor associado a essa cor.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. Devolve o valor associado a duas faixas

As duas primeiras faixas de uma resistência combinam-se para formar um único número.
Se as duas primeiras faixas tiverem os números respetivos `m` e `n`, combinam-se para formar o número único `mn`.

Define uma função `two_band_value(bands)` que recebe um `vector` de `string`s com duas cores de faixa.
A função devolve o valor associado à combinação dessas duas cores.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. Devolve os ohms associados às três faixas

Por fim, vais precisar de encontrar a classificação completa em ohms, usando as duas primeiras faixas em conjunto com a terceira.
Para isso, precisas de encontrar o valor de duas faixas e um multiplicador.
Podes pensar no multiplicador como o número de zeros que são acrescentados ao valor das duas faixas.

Define uma função `ohms(bands)` que recebe um `vector` de `string`s com três cores de faixa.
A função devolve a classificação em ohms associada à combinação das três cores.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
