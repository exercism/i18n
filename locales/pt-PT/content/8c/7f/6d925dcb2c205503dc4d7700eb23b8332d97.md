# Introdução

`call` (em [`kernel`][kernel]) executa uma citação. Quando o efeito de pilha da citação não pode ser inferido, normalmente porque a citação veio de outro sítio, declara o efeito em `call` explicitamente:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Como as citações são valores, um array pode conter uma mistura de números e citações, fazendo com que "um programa" seja apenas outra sequência:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
