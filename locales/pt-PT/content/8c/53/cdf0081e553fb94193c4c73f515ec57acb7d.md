# Contribuir com um conceito + exercício de conceito

Um [exercício de conceito][product-concept] tem como objetivo ensinar um único conceito numa determinada linguagem.
Deve ter um objetivo de aprendizagem claro e fornecer código base suficiente para evitar que o estudante tenha de aprender código desnecessário.
O conceito associado tem a sua própria documentação, independente do exercício de conceito.
Os conceitos podem ter outros conceitos como pré-requisitos e ficar bloqueados até que os exercícios de conceito dos conceitos pré-requisitos estejam concluídos.
A dificuldade dos exercícios de conceito não deve aumentar à medida que o percurso avança.
Qualquer programador familiarizado com os conceitos pré-requisitos deve conseguir resolver um exercício de conceito em 5 a 10 minutos.

Agora que já sabemos o que é um exercício de conceito, vamos detalhar como implementar um, bem como o conceito associado.
Para referência, estão disponíveis as especificações detalhadas de um [exercício de conceito][concept-exercise-spec] e de um [conceito][concept-spec] no [repositório de documentação][docs-repo] do Exercism.
Este documento reúne informação de várias fontes para servir de guia passo a passo prático sobre como contribuir com um exercício de conceito.

Também estão representados como um grafo de dependências no [site do Exercism][concepts-graph-exercism].

Os conceitos já implementados devem aparecer com um fundo verde e um contorno mais forte.
Tem em atenção que o grafo acima está em constante mudança e pode alterar-se à medida que percebemos que os pré-requisitos devem ser diferentes.

## 2. Define os objetivos de aprendizagem

É importante saber o que um exercício de conceito pretende ensinar e o que está fora do âmbito, por isso vamos criar o nosso primeiro ficheiro: `exercises/concept/<story-name>/.meta/design.md`.
Como os exercícios de conceito têm o nome da história que usam, ainda não a conhecemos, por isso vamos manter `story-name` por agora e substituí-lo mais tarde.
A [especificação do `design.md`][design-spec] indica que este documento deve definir o objetivo geral do exercício, os vários objetivos de aprendizagem, o que está fora do âmbito, o conceito associado que desbloqueia e os conceitos pré-requisitos necessários para conseguir completar o exercício.
Podes usar o [`design.md` do exercício de conceito Boolean][design-bool] como ponto de partida.

## 3. Escreve uma introdução ao conceito para o exercício

Assim que os objetivos de aprendizagem estiverem claros, é altura de escrever uma introdução que explique o conceito o suficiente para o estudante conseguir depois resolver o exercício.
Cria um ficheiro `exercises/concept/<story-name>/.docs/introduction.md`.
O conteúdo detalhado deste ficheiro está explicado na [respetiva especificação][exercise-intro-spec].
Podes usar a [`introduction.md` do exercício de conceito Boolean][intro-bool] como ponto de partida.

As informações fornecidas devem introduzir o conceito apenas o suficiente para o estudante conseguir descobrir sozinho a solução do exercício.
Usa termos técnicos adequados para facilitar a pesquisa online do estudante.
Tenta evitar links e explica as coisas de forma concisa no próprio texto.
Introduz a sintaxe do código com blocos de código.

## 4. Encontra uma história para o exercício

Cada exercício de conceito tem de se basear numa história ou num tema.
Tentamos torná-los o mais inclusivos possível, sabendo que o Exercism é usado em todo o mundo.
A primeira opção é reutilizar uma história existente da [lista de histórias registadas na documentação][stories].
Se quiseres criar uma história nova, não hesites em mencionar @exercism/leadership no teu PR.
Podes agora renomear o diretório `exercises/concept/<story-name>/` para corresponder à tua história.

## 5. Escreve as instruções do exercício

Assim que a história estiver encontrada, temos de escrever instruções precisas que enumerem as tarefas que o estudante terá de realizar.
Tanto a história como as instruções são escritas no documento `exercises/concept/<story-name>/.docs/instructions.md`.
Como explicado na [especificação desse documento][instructions-spec], cada tarefa tem o seu próprio título markdown de nível 2 (`## 1. Do X`), seguido de uma descrição e de um exemplo de utilização do código.
Podes usar as [`instructions.md` do exercício de conceito Boolean][instructions-bool] como ponto de partida.

Além das `instructions.md`, também precisamos de um ficheiro `hints.md`.
Deve conter os mesmos títulos de nível 2 (`## 1. Do X`) que o ficheiro de instruções, para que sejam dadas as dicas certas consoante a tarefa em que se está a trabalhar.
Também pode haver uma secção `## General` para dicas que se aplicam a todas as tarefas.
As dicas não devem revelar diretamente a solução.
Além disso, tem em atenção que as pessoas que clicam nas dicas podem já estar confusas/sobrecarregadas/frustradas com o exercício.
Há mais informação sobre este documento na [respetiva especificação][hints-spec] e podes usar as [`hints.md` do exercício de conceito Boolean][hints-bool] como ponto de partida.

## 6. Abre um pull request em rascunho para validar o design

Agora é uma boa altura para abrir um pull request em rascunho para o teu exercício de conceito!
Já temos material suficiente para avaliar o exercício e reformulá-lo, se for necessário, antes de o fixarmos no estado atual para os restantes ficheiros necessários.
Não te preocupes se as verificações automáticas de integração contínua falharem por falta de documentos, vamos criá-los mais tarde!

## 7. Escreve o código

Vamos escrever o código como se estivéssemos a resolver o exercício e, mais tarde, vamos mover ficheiros para cumprir as especificações.
Vamos começar por copiar o conteúdo do diretório [`template/`][template] para dentro do nosso diretório `exercises/concept/<story-name>/`.
Isto significa que temos os seguintes ficheiros:

```txt
elm.json           # elm project configuration file
src/Exercise.elm   # code for the exercise
tests/Tests.elm    # tests for the exercise
```

Depois, renomeia `Exercise.elm` para usar o PascalCase do nome da história.
Por exemplo, `annalyns-infiltration` passa a `AnnalynsInfiltration.elm`.
Dentro desse ficheiro de código, podes agora escrever todas as funções descritas nas `instructions.md` que acabámos de escrever.

Assim que o exercício estiver implementado, atualiza o conteúdo do ficheiro `tests/Tests.elm` para incluir testes relevantes que sigam naturalmente a ordem das tarefas nas `instructions.md`.
**Evita usar `Fuzz`** nos testes dos exercícios de conceito, uma vez que não se dá bem com a capacidade de depurar o código com `Debug.log`.
Em vez disso, inclui alguns testes unitários de casos limite e de casos gerais.
**Evita usar expressões `let` diretamente sob chamadas às funções `test` ou `describe`** nos testes dos exercícios de conceito, uma vez que o [executor de testes do elm ainda não suporta isto](https://github.com/exercism/elm-test-runner/issues/30).

Assim que tanto o exercício como os testes estiverem prontos e a funcionar bem, faz o seguinte:

- Copia `src/<ExerciseSlug>.elm` para `.meta/Exemplar.elm`. A tua implementação serve de referência, uma implementação "exemplar" para o exercício, que é usada quando se correm os testes do percurso.
- Remove todas as implementações dentro de `src/<ExerciseSlug>.elm`, deixando um ficheiro inicial pronto para o estudante começar o exercício.

## 8. Escreve a documentação do conceito

Cria um diretório `concepts/<concept>/` para o conceito associado ao nosso exercício `exercises/concept/<story-name>`.
Dentro dessa nova pasta, criamos dois documentos markdown, [`introduction.md`][concept-intro-spec] e [`about.md`][concept-about-spec], e um ficheiro [`links.json`][concept-links-spec] (os links levam à respetiva especificação).

O ficheiro de conceito `introduction.md` contém a apresentação que os estudantes verão na página do conceito enquanto não tiverem concluído o exercício de conceito associado.
Deve dar-lhes uma boa visão geral do que vão aprender se começarem o exercício associado.
Em contrapartida, o ficheiro de conceito `about.md` contém o resumo do conceito que o estudante só verá na página do conceito depois de ter concluído o exercício de conceito associado.
Por isso, o conteúdo é semelhante ao do ficheiro `exercises/concept/<story-name>/.docs/introduction.md` que já escrevemos, mas não é igual.
Sugiro começar pelo documento de introdução do exercício e simplificá-lo até à sua essência para o ficheiro de conceito `introduction.md`.
E, para o documento `about.md`, começa pela introdução do exercício e completa-a de forma a que toda a informação relevante sobre o conceito esteja presente nessa página.
O `links.json` fornece links úteis com informação adicional sobre um conceito.
Podem ser documentação oficial, um bom tutorial, etc.
Estes links não substituem os links mais contextuais dentro do ficheiro about.md de um conceito, mas fornecem um conjunto rápido de pontos de referência abrangentes para o estudante.
Os links podem também ter, opcionalmente, um campo icon_url, que pode ser usado para personalizar o ícone mostrado quando o link é apresentado. Se não for especificado, o ícone assume por omissão o favicon.
Podes encontrar ícones disponíveis em [github.com/exercism/website-icons/tree/main/exercises][icons].

## 9. Completa os diferentes ficheiros de configuração

Agora que o código e a documentação estão prontos, faltam-nos apenas alguns ficheiros de configuração para completar este PR:

- [`concepts/<concept>/.meta/config.json`][concept-config-json]: considera-te autor, acrescenta potenciais revisores como contribuidores e adiciona uma "blurb" (descrição curta).
- [`exercises/concept/<story-name>/.meta/config.json`][exercise-config-json]: contém os autores (tu), os contribuidores, a blurb e outras coisas. Consulta a especificação indicada.
- `config.json`: adiciona uma [entrada de conceito][track-config-json-concept] e uma [entrada de exercício de conceito][track-config-json-concept-exercise] ao ficheiro `config.json` do percurso. Usa "wip" ou "beta" como valor da chave status do exercício de conceito. Os UUIDs podem ser gerados com o [executável configlet][configlet] fornecido pelo Exercism.
