# Dicas

## Geral

- Lê sobre recursão no [guia de introdução oficial][getting-started-recursion].
- Lê sobre recursão em [elixirschool.com][elixir-school-recursion].
- Usa funções com várias cláusulas e pattern matching.
- Tenta dividir um problema num caso base e num caso recursivo. Por exemplo, imagina que queres contar quantos biscoitos há no pote de biscoitos com uma abordagem recursiva. O caso base é um pote vazio: tem zero biscoitos. Se o pote não estiver vazio, o número de biscoitos no pote é igual a um biscoito mais o número de biscoitos no pote depois de retirares um biscoito.

## 1. Verifica quantas aves visitaram hoje

- Esta tarefa não precisa de recursão.
- Podes aceder ao primeiro elemento de uma lista com [pattern matching][getting-started-pattern-matching].

## 2. Incrementa a contagem de hoje

- Esta tarefa não precisa de recursão.
- Podes aceder ao primeiro elemento de uma lista com [pattern matching][getting-started-pattern-matching].

## 3. Verifica se houve um dia sem aves visitantes

- Usa recursão para iterar sobre os elementos da lista até encontrares um dia sem aves visitantes.
- O caso base é uma lista vazia.

## 4. Calcula o número total de aves visitantes

- Usa recursão para iterar sobre cada elemento da lista.
- O caso base é uma lista vazia.

## 5. Calcula o número de dias movimentados

- Usa recursão para iterar sobre cada elemento da lista.
- O caso base é uma lista vazia.
- Uma função pode ter mais do que um caso recursivo.
- Usa uma [guard][kernel-equal-or-greater-than] numa das cláusulas da função.
