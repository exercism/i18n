# Instruções

Neste exercício vais escrever código para ajudar uma empresa de letreiros a criar mensagens personalizadas para os seus letreiros.

## 1. Cria um letreiro de ocasião

Implementa o método `build_sign( )` que aceita uma string como parâmetro `occasion` e uma string com o nome de alguém como parâmetro `name`. Os dois parâmetros são integrados num modelo de string para produzir a mensagem que aparece no letreiro.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Cria um letreiro de aniversário

Implementa o método `build_birthday_sign( )` que aceita uma idade e, com base nessa idade, determina parte da mensagem do letreiro. Se a idade for 50 ou mais, o letreiro inclui a palavra _mature_; caso contrário, inclui a palavra _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Cria um letreiro de fim de curso

Implementa o método `graduation_for( )` que recebe um nome como parâmetro do tipo string e um ano como parâmetro numérico, e usa modelos de string para criar uma frase para um letreiro que usa uma mudança de linha para separar as duas linhas da mensagem.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Calcula o custo de um letreiro

Implementa a função `cost_of( sign currency )` que recebe uma string com o conteúdo do letreiro e uma string que representa a moeda.
O letreiro tem um preço base de 20 na moeda indicada. Além disso, cada letra custa 2. (Os espaços em branco contam para o cálculo.)
A frase devolvida inclui o custo de criar o letreiro, escrito com duas casas decimais, seguido da string da moeda.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
