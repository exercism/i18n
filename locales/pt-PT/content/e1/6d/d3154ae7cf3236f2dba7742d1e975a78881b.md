# Testes

Navega até ao diretório que contém o ficheiro `${slug}_test.sql` adequado, em que `${slug}` é o nome do exercício, com hífenes em vez de espaços e tudo em minúsculas (por exemplo, `hello-world_test.sql` para o exercício `Hello World`).

```bash
sqlite3 -bail < ${slug}_test.sql
```

Podes usar instruções `SELECT` para depurar.
A saída será enviada para `user_output.md` e mostrada no editor web se os testes falharem.

Podes encontrar mais informações na [documentação do track de sqlite sobre testes](https://exercism.org/docs/tracks/sqlite/tests).
