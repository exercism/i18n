# Dicas

## Geral

- Um [valor inteiro][integers] pode ser definido como um ou mais algarismos consecutivos.
- Uma [string][string] literal é uma sequência de carateres delimitada por aspas duplas.

## 1. Define o tempo de forno esperado em minutos

- Tens de definir uma [função][functions] sem argumentos.
- Tens de devolver um [inteiro][integers].

## 2. Calcula o tempo de forno restante em minutos

- Tens de definir uma [função][functions] com um único argumento.
- Tens de [devolver implicitamente um inteiro][return] a partir de uma função.
- O argumento da função é um [inteiro][integers].
- Podes usar o [operador matemático de subtração][operators] para subtrair valores.

## 3. Calcula o tempo de preparação em minutos

- Tens de definir uma [função][functions] com um único argumento.
- Tens de [devolver implicitamente um inteiro][return] a partir de uma função.
- O argumento da função é um [inteiro][integers].
- Podes usar o [operador matemático de multiplicação][operators] para multiplicar valores.

## 4. Calcula o tempo total de trabalho em minutos

- Tens de definir uma [função][functions] com dois argumentos.
- Tens de [devolver implicitamente um inteiro][return] a partir de uma função.
- O argumento da função é um [inteiro][integers].
- Podes invocar uma das outras funções que já definiste anteriormente.
- Podes usar o [operador matemático de adição][operators] para somar valores.

## 5. Cria uma notificação de que a lasanha está pronta

- Tens de definir uma [função][functions] sem argumentos.
- Tens de devolver uma [string][string].
