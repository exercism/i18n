# Introdução

Uma [instrução switch][switch] compara um valor com vários padrões de correspondência possíveis.
Oferece uma alternativa mais limpa e legível do que encadear várias instruções `if-else`.

Uma instrução `switch` começa com a palavra-chave `switch`, seguida do valor a testar.
Cada correspondência possível é introduzida com a palavra-chave `case`.
A palavra-chave `default` define um caso de recurso que é executado quando nenhum dos casos explícitos corresponde.
Tal como as cadeias de `if-else`, uma instrução `switch` só executa o bloco de código associado ao primeiro caso correspondente.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera a seguinte cadeia de `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Isto pode ser escrito de forma mais clara com uma instrução `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
