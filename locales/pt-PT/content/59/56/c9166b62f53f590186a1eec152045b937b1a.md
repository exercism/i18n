# Apêndice às instruções

## Notas

O objetivo deste exercício é investigar alguns dos paralelos entre uma instância de um módulo WebAssembly e uma instância de uma classe em linguagens de programação orientada a objetos.

Na tua solução, uma instância de WebAssembly deve ser considerada uma instância de uma conta bancária, e as variáveis globais mutáveis do WebAssembly devem ser usadas para modelar estados privados, como numa classe.

Não deves precisar de memória linear!
