# Dicas

## 1. Duplica todas as cartas

- Há um método incorporado ótimo para [transformações simples][map_method_docs] como esta.

## 2. Cria várias cópias de cada 3 encontrado no baralho

- Há um método incorporado perfeito para transformações personalizadas ou [acumulações][reduce_method_docs] (como somar um array, etc.)

## 3. Encontra duas cartas no meio exato do baralho

- Há um método incorporado para [cortar e dividir][slice_method_docs] arrays em segmentos mais pequenos.

## 4. As duas cartas exteriores vão reaparecer no meio do baralho

- Há um método incorporado para [inserir ou remover][splice_method_docs] itens no meio de um array.
- O array também tem métodos incorporados para remover o primeiro e o último elementos, vê a [documentação de Array da MDN][array_docs].

## 5. Todas as cartas que não sejam 2 desaparecem

- Há um método incorporado para [filtrar][filter_method_docs] ou excluir itens num array.

## 6. Converte um baralho baralhado num baralho perfeitamente ordenado

- Há um método incorporado para [ordenar][sort_method_docs].

## 7. Reordena o baralho

- Há um método incorporado para [inverter][reverse_method_docs] um array.
