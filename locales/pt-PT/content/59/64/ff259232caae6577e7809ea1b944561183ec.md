# Introdução

## Datas e horas

A biblioteca padrão do Elixir oferece 4 módulos diferentes para trabalhar com datas e horas, cada um com o seu próprio struct.

- O módulo `Date`. Podes criar um struct `Date` com o sigilo `~D`.

  ```elixir
  ~D[2021-01-01]
  ```

- O módulo `Time`. Podes criar um struct `Time` com o sigilo `~T`.

  ```elixir
  ~T[12:00:00]
  ```

- O módulo `NaiveDateTime` para datas e horas sem fuso horário. Podes criar um struct `NaiveDateTime` com o sigilo `~N`.

  ```elixir
  ~N[2021-01-01 12:00:00]
  ```

- O módulo `DateTime` para datas e horas com fuso horário. Usar este módulo para fusos horários diferentes de UTC exige uma dependência externa, uma base de dados de fusos horários.

### Comparações

Para comparar datas ou horas entre si, procura uma função `compare` ou `diff` no módulo correspondente. Os operadores de comparação como `==`, `>` e `<` _parecem_ funcionar, mas não fazem uma comparação semântica correta para esses structs.
