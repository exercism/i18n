# Ciclos

```sather
   loop
      ...
   end;
```

O Sather tem exatamente uma instrução de ciclo. Não existe `while` nem `for`; ambos são construídos a partir de `loop` e de algo que o termina.

## Variáveis

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=` declara e assume o tipo a partir do valor indicado. Quando uma variável tem de existir antes de haver um valor para ela, declara-a antes com um tipo:

```sather
   total : INT;
   total := 0;
```

Uma variável declarada sem valor começa em zero para `INT`, em `false` para `BOOL` e em void para uma string ou um objeto.

## Terminar um ciclo

| Escrito | Termina o ciclo |
| --- | --- |
| `until!(q)` | quando `q` é verdadeiro |
| `while!(q)` | quando `q` é falso |
| `break!` | imediatamente |

Os três podem aparecer em qualquer lugar do corpo, e um ciclo pode usar mais do que um.

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## O ponto de exclamação

`until!`, `while!` e `break!` terminam em `!` porque são **iteradores**, ou seja, coisas que só podem aparecer dentro de um ciclo e que o podem terminar. Escrever um fora de um ciclo é um erro, não um aviso. Nos exercícios seguintes vais usar os outros iteradores da biblioteca e, mais adiante, vais escrever novos.

## Ciclos infinitos

Um ciclo sem nada que o termine corre para sempre. Por vezes é isso que se quer, mas muito mais frequentemente significa que o valor que a condição do ciclo testa nunca é alterado. Se um programa ficar preso, a primeira coisa a verificar é se algo dentro do ciclo o aproxima de parar.
