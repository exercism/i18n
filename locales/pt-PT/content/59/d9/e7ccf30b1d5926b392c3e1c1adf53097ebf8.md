# Instruções

Neste exercício vais jogar um jogo de interpretação de papéis chamado "Wizard and Warriors", que te permite jogar como Wizard ou como Warrior.

As regras para determinar quantos pontos de dano causam são diferentes para Warriors e Wizards.

Para um Warrior, as regras são as seguintes:

- Causa 6 pontos de dano se a personagem que está a atacar não for vulnerável
- Causa 10 pontos de dano se a personagem que está a atacar for vulnerável

Para um Wizard, as regras são as seguintes:

- Causa 12 pontos de dano se o Wizard tiver preparado um feitiço com antecedência
- Causa 3 pontos de dano se o Wizard não tiver preparado um feitiço com antecedência

Em geral, as personagens nunca são vulneráveis. No entanto, os Wizards _são_ vulneráveis se não tiverem preparado um feitiço.

Tens seis tarefas que trabalham com personagens Warrior e Wizard.

## 1. Descreve uma personagem

Substitui o método `ToString()` da classe `Character` para devolver uma descrição da personagem, formatada como `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. Torna as personagens não vulneráveis por omissão

Garante que o método `Character.Vulnerable()` devolve sempre `false`.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Permite que os Wizards preparem um feitiço

Implementa o método `Wizard.PrepareSpell()` para permitir que um Wizard prepare um feitiço com antecedência.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. Torna os Wizards vulneráveis quando não tiverem preparado um feitiço

Garante que o método `Vulnerable()` devolve `true` se o Wizard não tiver preparado um feitiço; caso contrário, devolve `false`.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Calcula os pontos de dano de um Wizard

Implementa o método `Wizard.DamagePoints()` para devolver os pontos de dano causados: 12 pontos de dano quando um feitiço tiver sido preparado, 3 pontos de dano quando não.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Calcula os pontos de dano de um Warrior

Implementa o método `Warrior.DamagePoints()` para devolver os pontos de dano causados: 10 pontos de dano quando o alvo é vulnerável, 6 pontos de dano quando não.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
