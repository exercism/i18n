# Dicas

## Geral

- As instâncias de struct criam-se declarando o nome da struct seguido dos valores dos campos entre chavetas.
- Podes usar `@T` para declarar snapshots de um tipo `T`, por exemplo `let i: @u32 = @1;` declara uma variável `i` que é um snapshot do valor `u32` `1`;
- Podes extrair um valor de um snapshot com o operador `*` (desnap), por exemplo `let int = *an_int_snapshot;`.
- Podes declarar um valor como mutável com a palavra-chave `mut`, como em `let mut i = 1;`.

## 1. Cria um contador de votos

- Tens de criar um apontador para uma struct `VoteCounter`, ou seja, um `@VoteCounter`.
- Podes atribuir o parâmetro `value` diretamente ao criar uma instância da struct.

## 2. Obtém o número de votos de um contador

- Podes usar o operador `*` num snapshot para o desnapar e obter o seu valor, por exemplo `*my_snapshot`

## 3. Incrementa os votos de um contador

- Em vez de modificares o snapshot `@VoteCounter`, tens de devolver uma nova instância de `VoteCounter` com os votos incrementados.
- Podes desnapar o valor subjacente do contador de votos com o operador `*`, ou chamar a função que criaste na tarefa anterior.

## 4. Cria os resultados da eleição

- Cria uma nova struct ou variável `ElectionResult` com os campos `name` e `vote_counter` preenchidos com os valores dos argumentos da função.
- Podes criar um snapshot de `VoteCounter` usando o operador `@` antes do nome da variável ou da declaração da struct, ou chamar a função `new_vote_counter` que fizeste numa das tarefas anteriores.

## 5. Anuncia os resultados

- Embora recebas um snapshot de um `ElectionResult`, podes aceder aos seus campos com a notação de ponto `.`, como se não fosse um snapshot!
- Constrói a mensagem acedendo aos campos `name` e `vote_counter` da struct.
- Ao desnapar um snapshot aninhado, tens de aplicar tantos operadores `*` quantos os snapshots a desnapar:

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. Recontagem dos votos

- Por causa da [forma como os dicionários são implementados][dictionaries underneath], é obrigatório que sejam mutáveis tanto para os modificar como para ler a partir deles, o que significa que as alterações que fizeres ao dicionário dentro da função ficam visíveis fora da função.
- Para incrementar o valor de uma chave num `let mut m: Felt252Dict<u32>`, deves combinar as funções `get` e `insert`: `m.insert('mykey', m.get('mykey') + 1);`

[dictionaries underneath]: https://book.cairo-lang.org/ch03-02-dictionaries.html#dictionaries-underneath
