# Apêndice às instruções

## Notas de implementação

Define uma função recognizeDigit como descrito no Passo 1 das instruções, mas faz com que reconheça todos os dez algarismos, de 0 a 9.
Escolhe os parâmetros e os valores devolvidos que quiseres, mas torna-a útil como sub-rotina para o passo 2.

Para o passo 2, define

func Recognize(string) []string

e implementa-a usando recognizeDigit.

As strings de entrada testadas aqui têm um \n no início de cada linha e
não têm \n no fim da última linha. (Isto torna os literais de string brutos
mais legíveis.)

Para pontos extra, lida com dados mal formatados de forma elegante.
O que deves fazer com uma célula parcial?
Descartá-la?
Preenchê-la com espaços?
Assinalá-la com o caráter `"?"`?
O que deves fazer se o primeiro caráter não for `\n`?
