# Anexo às instruções

## Indexação a partir de zero

Lembra-te de que, embora as pessoas contem habitualmente com indexação a partir de 1 (ou seja, «o 6.º primo é 13»), muitas linguagens de programação, incluindo Rust, usam indexação a partir de zero (ou seja, `primes[5] == 13`). Usa a indexação a partir de zero na tua implementação.
