# Depurar localmente

Quando corres os testes do percurso de Bash com o [Bats](https://github.com/bats-core/bats-core), o Bats captura tanto o STDOUT como o STDERR para as asserções de saída.

```exercism/caution
Isto funciona localmente com o `bats`, mas **não** no editor online do Exercism.
```

Se quiseres imprimir a saída de depuração sem afetar o resultado do teste, escreve-a para o descritor de ficheiro (fd) 3.

```bash
echo 'debug message' >&3
```

O Bats mostra a saída escrita para o fd 3 durante a execução dos testes, mas não a inclui em asserções como `assert_output`.

Exemplo de execução:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

Isto é útil quando estás a correr os testes localmente.
