# Dicas

## Geral

- [Imprimir valores][exercism-debugging] não faz parte da solução, mas podes usar [`var_dump();`][php-vardump] para perceberes o que o PHP vê.
- Um [valor inteiro][php-integers] pode ser definido como um ou mais algarismos consecutivos.
- Os literais [string][php-string] são uma sequência de carateres rodeada por aspas duplas.

## 1. Define o tempo de forno esperado, em minutos

- Tens de [devolver explicitamente][php-return] um valor de uma função.
- Tens de devolver um [inteiro][php-integers].

## 2. Calcula o tempo de forno restante, em minutos

- Tens de [devolver explicitamente][php-return] um valor de uma função.
- O argumento da função é um [inteiro][php-integers].
- Podes usar o [operador matemático de subtração][php-operators] para subtrair valores.
- Podes [invocar uma das outras funções][exercism-methods] da classe.

## 3. Calcula o tempo de preparação, em minutos

- Tens de [devolver explicitamente][php-return] um valor de uma função.
- O argumento da função é um [inteiro][php-integers].
- Podes usar o [operador matemático de multiplicação][php-operators] para multiplicar valores.

## 4. Calcula o tempo total de trabalho, em minutos

- Tens de [devolver explicitamente][php-return] um valor de uma função.
- Os argumentos da função são [inteiros][php-integers].
- Podes [invocar uma das outras funções][exercism-methods] da classe.
- Podes usar o [operador matemático de adição][php-operators] para somar valores.

## 5. Cria uma notificação de que a lasanha está pronta

- Tens de [devolver explicitamente][php-return] um valor de uma função.
- Tens de devolver uma [string][php-string].
