# Introdução

Uma exceção definida pelo utilizador é qualquer classe definida no teu código que derive de `System.Exception`. Está sujeita a todas as regras da herança de classes, mas, além disso, o compilador e o runtime da linguagem tratam estas classes de forma especial, permitindo que as suas instâncias sejam lançadas e capturadas fora do fluxo de controlo normal, como se explica no exercício `exceptions`.

As exceções definidas pelo utilizador são frequentemente usadas para transportar informação extra, como uma mensagem e outros dados relevantes, que fica à disposição das rotinas de captura.
