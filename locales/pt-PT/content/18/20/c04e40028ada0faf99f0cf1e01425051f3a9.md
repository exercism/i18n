# Dicas

## Geral

- Cada tarefa é uma única palavra, cujo corpo é constituído por palavras de baralhar do vocabulário `kernel`. Não é preciso fazer contas.
- Usa `.s` no listener para imprimir a pilha inteira enquanto experimentas.

## 1. Troca as duas caixas do topo

- Uma única palavra de baralhar troca os dois valores do topo: `swap`.

## 2. Tira a caixa entornada

- `drop` remove o valor do topo; as duas caixas que ficam por baixo permanecem intactas.

## 3. Guarda uma cópia da caixa que está por baixo

- `over` copia o segundo valor a contar do topo para o topo.

## 4. Arruma o baralho

- Traz a caixa de baixo para o topo com `rot`, deita-a fora com `drop`, duplica o novo topo com `dup` e usa `rot` outra vez para pôr as peças em ordem. Segue a pilha, palavra a palavra:
  `x y z` → `y z x` → `y z` → `y z z` → `z z y`.
