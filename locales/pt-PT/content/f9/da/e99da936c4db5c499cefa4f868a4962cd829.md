# Introdução

Este exercício baseia-se na pilha de dados e na notação de efeitos de pilha que conheceste em [Cargo Shuffle][cargo-shuffle]. Aqui vais escrever palavras que combinam valores Boolean.

## Palavras de reorganização

As palavras de reorganização mais comuns estão em [`kernel`][kernel]:

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## Booleans

Os dois literais Boolean são `t` e `f`. O `f` é o único valor que o Factor considera falso: tudo o resto, incluindo `0` e coleções vazias, é verdadeiro.

```factor
t .    ! => t
f .    ! => f
```

## Palavras Boolean

Estas três palavras Boolean do vocabulário `kernel`:

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

O `?` em cada saída é a convenção da notação de efeitos de pilha para "um Boolean".

Vais precisar de `swap` para uma das tarefas abaixo.
