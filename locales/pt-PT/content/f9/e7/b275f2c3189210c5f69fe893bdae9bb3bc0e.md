# Introdução

Tal como uma condicional _if/else_, uma instrução `switch` permite-te alterar o fluxo do programa ao executar código de forma condicional.
A diferença é que uma instrução `switch` só consegue comparar o valor de uma expressão primitiva ou de uma string com valores constantes predefinidos.

Algumas palavras-chave são úteis quando usas uma instrução `switch`.

- `switch`: esta palavra-chave permite-te declarar a estrutura do switch.
  É seguida da expressão ou da variável que vai alterar o resultado.
- `case`: vais usar esta palavra-chave para declarar as diferentes possibilidades para o resultado.
- `break`: a palavra-chave `break` é muito útil para parar a execução do switch no fim do fluxo pretendido.
  Se te esqueceres dela, o programa continua e pode dar origem a resultados inesperados.
- `default`: como o nome indica, usa-a como resultado predefinido quando nenhum outro caso corresponde ao resultado da tua expressão.

Na sua forma mais simples, testam uma expressão primitiva ou uma string e tomam uma decisão com base no seu valor.
Por exemplo:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
