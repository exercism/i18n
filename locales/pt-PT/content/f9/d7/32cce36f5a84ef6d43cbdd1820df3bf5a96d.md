# Dicas

## 1. Definir o intervalo de filas e colunas

- Tens de definir duas [constantes][constants] que devem conter um [intervalo][range] de filas e colunas.
- As filas devem ser um intervalo de [inteiros][integers] de 1 a 8.
- As colunas devem ser um intervalo de [carateres][characters] de 'A' a 'H'.
- A constante tem de ser definida no [módulo][module] `Chess`.

## 2. Verificar se a casa é válida

- Tens de verificar se um valor está dentro de um intervalo.
- Há [um método][include] que podes usar para verificar se um valor está dentro de um intervalo.

## 3. Obter a alcunha do jogador

- Podes obter uma substring usando o [operador de intervalo][range-operator] como índice.
- Há [um método][upcase] que podes usar para converter uma string em maiúsculas.

## 4. Criar a mensagem de jogada

- Podes indexar a string da casa para obter a fila e a coluna.
- Podes usar os métodos já definidos para obter a alcunha do jogador e para verificar se a jogada é válida.
