# Introdução

Uma *quotation* é um pedaço de código entre parênteses retos, `[ ]`. É um valor: podes colocá-la na pilha, passá-la a outra word ou guardá-la num array.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

A maioria das words de ordem superior recebe uma quotation como segundo argumento:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

O corpo de uma quotation é apenas código Factor normal: os mesmos operadores e efeitos de pilha que usas em todo o lado.

Quando constróis código a partir de dados, concatenando fragmentos ou mapeando tokens para operações, o resultado é uma sequência; passa-o por `>quotation` para o poderes chamar:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
