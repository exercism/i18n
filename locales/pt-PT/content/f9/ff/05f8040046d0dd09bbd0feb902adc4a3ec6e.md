# Sobre

Uma expressão Boolean é uma pergunta feita a um ou mais valores, à qual se pode responder com `true` ou `false`.
Uma expressão verdadeira devolve `1`; uma expressão falsa devolve `0`.
Além disso, os números também têm valores de verdadeiro ou falso. Zero é `false`; um valor diferente de zero é `true`.

O código C antigo ou usa diretamente o tipo `int` para valores Boolean, ou o programador pode ter definido constantes como `TRUE` e `FALSE` para fazer corresponder `1` e `0` a uma representação Boolean.

Com a versão C99, foi adicionado o tipo `_Bool`.
O ficheiro de cabeçalho `stdbool.h` define três novos símbolos Boolean: `bool`, `true` e `false`.
`true` corresponde a `1`; `false` corresponde a `0`; e `bool` corresponde a `_Bool`.
Por isso, em vez de usar `int` diretamente ou de criar as suas próprias correspondências Boolean, os programadores podem incluir `stdbool.h` e obter automaticamente símbolos Boolean no seu código.

## Operadores de comparação

O C suporta seis operadores de comparação: `==` (igual), `!=` (diferente), `>` (maior que), `<` (menor que), `>=` (maior ou igual a), `<=` (menor ou igual a).
Estes operadores comparam as relações entre valores e resolvem-nas em valores Boolean.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Operadores Boolean

O C suporta três operadores Boolean: `||` (ou), `&&` (e) e `!` (não).

O `!` é usado com um operando.
Inverte o valor Boolean do operando.
Por exemplo, `0` é `false`, mas `!0` é `true`.

O `||` e o `&&` são usados com dois operandos.
O operando à direita só é avaliado quando o operando à esquerda ainda não determina o resultado da expressão.
Isto é, o `||` só avalia o seu operando à direita quando o seu operando à esquerda é avaliado como `false`.
O `&&` só avalia o seu operando à direita quando o seu operando à esquerda é avaliado como `true`.

## Avaliação de curto-circuito

Não avaliar todos os operandos é conhecido como "avaliação de curto-circuito".
A avaliação de curto-circuito é uma forma sucinta e poderosa de lidar com certas situações.
Por exemplo, um idioma comum é verificar se um apontador não é `NULL` e (&&), se não for `NULL`, desreferenciá-lo, evitando assim desreferenciar um apontador `NULL`.
Mas a avaliação de curto-circuito também pode originar bugs.
Por vezes, um programador esquece-se de que o operando à direita de `||` ou `&&` pode não ser sempre avaliado.
Se o operando à direita for uma expressão com um efeito secundário que se espera que aconteça sempre, então será um bug que depende do valor Boolean do operando à esquerda.

## Devolver uma expressão Boolean

O resultado de uma expressão Boolean pode ser devolvido diretamente.
Por exemplo, esta instrução `if`

```c
if (count > 0)
    return true;
else
    return false;
end
```

podia ser substituída por

```c
return count > 0;
```
