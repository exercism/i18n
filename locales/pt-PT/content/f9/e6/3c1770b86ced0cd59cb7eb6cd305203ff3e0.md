# Instruções

Chegou finalmente o dia que esperaste durante tanto tempo: és agora o orgulhoso proprietário de uma bela quinta nos Alpes.

Continuas a não gostar de acordar demasiado cedo de manhã para alimentar as tuas vacas.
Como és um excelente engenheiro, construíste um dispensador de comida, o `FEED-M-ALL`.

A última coisa de que precisas para terminar o teu projeto é um pedaço de código que calcule a quantidade de forragem que cada vaca deve receber.
É importante que cada vaca receba a mesma quantidade; tens de evitar conflitos.
As vacas são muito sensíveis.

Felizmente, não precisas de descobrir sozinho todas as fórmulas para calcular as quantidades de forragem.
Usas uma misteriosa biblioteca externa que encontraste na internet.
Supostamente, deve resultar nas vacas mais felizes.
A biblioteca expõe um tipo que cumpre a seguinte interface.
Vais apoiar-te nisto no código que escreveres.

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

À medida que trabalhas no teu código, vais melhorar o tratamento de erros para o tornar mais robusto e mais fácil de depurar mais tarde, quando o usares no teu dia a dia na quinta.

## 1. Divide a comida de forma igual

Antes de mais, concentras-te em escrever o código necessário para calcular a quantidade de forragem por vaca.

Implementa uma função `DivideFood` que aceita, como argumentos, um `FodderCalculator` e um número de vacas (um número inteiro).
*Para esta tarefa, assumes que o número de vacas recebido é sempre maior do que zero.*
A função deve devolver a quantidade de comida por vaca como `float64` ou um erro, caso tenha ocorrido algum.

Para fazer o cálculo, precisas primeiro de obter a quantidade total de forragem para todas as vacas.
Fazes isso chamando o método `FodderAmount` e passando-lhe o número de vacas.
Além disso, precisas de um fator pelo qual essa quantidade tem de ser multiplicada.
Obténs esse fator chamando o método `FatteningFactor`.
Com estes dois valores e o número de vacas, podes agora calcular a quantidade de comida por vaca (como `float64`).
É isso que a função `DivideFood` deve devolver.

Se um dos métodos que chamas devolver um erro, a execução deve parar e esse erro deve ser devolvido (tal como está) pela função `DivideFood`.

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. Verifica o número de vacas

Enquanto trabalhavas na primeira tarefa acima, percebeste que a biblioteca externa que usas não tem tanta qualidade como pensavas.
Por exemplo, não consegue lidar corretamente com valores de entrada inválidos.
Queres contornar esta limitação acrescentando uma verificação do valor de entrada no teu próprio código.

Escreve uma função `ValidateInputAndDivideFood` com a mesma assinatura que a `DivideFood` acima.

- Se o número de vacas recebido for maior do que 0, a função deve chamar `DivideFood` e devolver o resultado dessa chamada.
- Se o número de vacas for 0 ou menos, a função deve devolver um erro com a mensagem `"invalid number of cows"`.

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. Melhora o tratamento de erros

Verificar o número de vacas antes de o passar adiante foi uma boa ideia, mas não estás totalmente satisfeito com a mensagem de erro pouco específica.
Decides fazer melhor, criando um tipo de erro personalizado chamado `InvalidCowsError`.

O erro personalizado deve conter o número de vacas (`int`) e uma mensagem personalizada (`string`), e o método `Error` deve serializar os dados no seguinte formato:

```txt
{number of cows} cows are invalid: {custom message}
```

Agora que tens o teu erro personalizado, implementa uma função `ValidateNumberOfCows` que aceita o número de vacas como número inteiro e devolve um erro (ou nil).

- Se o número de vacas for menor do que 0, a função devolve um `InvalidCowsError` com a mensagem personalizada definida como `"there are no negative cows"`.
- Se o número de vacas for 0, a função devolve um `InvalidCowsError` com a mensagem personalizada definida como `"no cows don't need food"`.
- Caso contrário, a função devolve `nil` para indicar que a validação foi bem-sucedida.

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

Depois do trabalho árduo de montar esta função de validação, reparas que já anoiteceu e deixas a tua secretária para apreciar o pôr do sol sobre as montanhas.
Deixas para outro dia a tarefa de adicionar efetivamente a nova função de validação ao teu código.
