# Dicas

## 1. Calcula o preço de uma pizza

- Cria uma função recursiva que devolve o preço de um ingrediente extra somado ao preço da pizza sem esse ingrediente.
- Se for lançado o erro `Maximum call stack size exceeded`, verifica se não te esqueceste do caso base.
- Se te aparecer um `Memory Allocation Error`, verifica se estás a duplicar o array de ingredientes de entrada em vez de o modificar.

## 2. Calcula o preço total de um pedido

- Usando `pizzaPrice`, calcula o preço de cada pizza do array e adiciona-o a uma soma.
- Se for lançado o erro `Maximum call stack size exceeded` e mais de um teste estiver a falhar, verifica se não te esqueceste do caso base. Se apenas um teste estiver a falhar, experimenta implementar isto com um ciclo!
- Se te aparecer um `Memory Allocation Error`, verifica se estás a duplicar o array de entrada em vez de o modificar.
