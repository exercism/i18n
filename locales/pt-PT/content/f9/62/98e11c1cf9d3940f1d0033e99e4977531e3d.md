# Sobre

O valor `null` serve para indicar a _ausência_ de um valor. Um tipo **nullable** é um tipo que permite que uma variável assuma o valor `null`. Para tornar qualquer tipo nullable, envolvemo-lo com `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Para verificar se um valor é `null` neste momento, usa simplesmente uma expressão `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
