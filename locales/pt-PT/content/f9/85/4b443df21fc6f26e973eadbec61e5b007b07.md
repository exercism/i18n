# Introdução

## Operadores de comparação

O R tem um conjunto de operadores igual ao de muitas outras linguagens:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Ramificação

A forma básica de um if-else é

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

Neste caso, tanto os parênteses `()` à volta do Boolean como as chavetas `{}` à volta da instrução são obrigatórios.
Uma condicional `if` simples pode ser encurtada:

```R
if (x == 0) return("success")
```
