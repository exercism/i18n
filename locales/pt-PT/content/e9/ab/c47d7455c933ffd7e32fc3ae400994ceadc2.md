# Recursos

## Referência

- O [RISC-V reference card][reference-card] lista as instruções, as pseudo-instruções e os registos.
- A [RISC-V calling convention][psabi] descreve que registos guardam os parâmetros de entrada e os resultados de uma função, e quais é que uma função tem de preservar.
- As [RISC-V specifications][isa-manual] descrevem exatamente o que faz cada instrução.
- O [GNU assembler manual][gas-directives] descreve diretivas como `.section`, `.string`, `.word` e `.global`.

## Ferramentas

- O [Compiler Explorer][godbolt] mostra o assembly que um compilador produz para um fragmento de código C.
  A ligação abre-o com um compilador RISC-V de 32 bits, para poderes comparar as tuas próprias soluções com o que um compilador escreveria.

## Comunidade

- A [RISC-V International][riscv-org] é a organização que zela pela norma RISC-V.
- O [r/RISCV][reddit] é uma comunidade do Reddit que partilha notícias sobre chips, placas e software RISC-V.
- O [Stack Overflow][stack-overflow] tem perguntas e respostas sobre assembly de RISC-V.
