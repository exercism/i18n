# Executar os testes de Ceylon

Antes de poderes executar os testes, tens de compilar o teu código com o comando [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html).

Executamos os testes com o comando [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html).

O `ceylon test` precisa do nome de um módulo para correr os testes.
No track de Ceylon, cada exercício tem apenas um único módulo.

Por isso, podes executar os testes com:

```bash
ceylon compile && ceylon test $(basename source/*)
```
