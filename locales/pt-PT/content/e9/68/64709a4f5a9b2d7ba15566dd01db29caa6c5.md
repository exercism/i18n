# Adenda às instruções

## Desafios

- Consegues implementar esta solução sem usar quaisquer ciclos `for`? (ou seja, usando [iteradores][iterators] em vez disso)
- Embora seja relativamente simples ter duas estruturas de dados em `Matrix` (uma a representar as linhas e outra as colunas), consegues implementar esta solução sem teres de guardar duas cópias separadas do valor de entrada no teu struct?

## Métodos úteis
- [`map()`][map]
- [`filter()`][filter]
- [`lines()`][lines]
- [`split()`][split]
- [`parse()`][parse]
