# Introdução

Para conheceres o básico sobre argumentos de funções, consulta o [conceito de função][function concept].

## Nomes dos parâmetros

Os [nomes dos parâmetros][parameters], tal como os nomes das variáveis, têm de começar por uma letra ou um underscore e podem conter letras, underscores ou números.
Os nomes dos parâmetros não devem conter espaços nem pontuação.


## Argumentos posicionais

Os argumentos posicionais são valores passados a uma função pela mesma ordem dos parâmetros a que ficam associados.
Opcionalmente, podem ser passados indicando o nome do parâmetro:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

A primeira chamada a concat passa os argumentos por posição.
A segunda chamada a concat passa os argumentos por _nome_, o que permite trocar a ordem dos argumentos.

Repara que os argumentos posicionais não podem vir depois de argumentos passados por nome (_também chamados [argumentos nomeados][keyword-arguments]. **Não** devem ser confundidos com parâmetros var-posicionais nem com [**kwargs][kwargs]_).

Este conjunto de argumentos:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

resulta neste erro:

```
SyntaxError: positional argument follows keyword argument
```

## Valores predefinidos dos argumentos

Os [valores predefinidos][default arguments] de um ou mais argumentos podem ser indicados na lista de parâmetros.
Isto permite chamar a função com _menos_ argumentos, se for necessário.
Os valores predefinidos podem ser substituídos ao chamar a função com novos argumentos em vez dos predefinidos:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## Argumentos nomeados

Os argumentos nomeados usam o nome do parâmetro quando se passam argumentos a uma função.
Opcionalmente, podem ser indicados por posição:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
