# Testes

Para correres os testes fornecidos, vais precisar da gem Minitest. Abre uma janela de terminal e executa o seguinte comando para instalar o minitest:

```
gem install minitest
```


Executa os testes a partir do diretório do exercício com o seguinte comando:

```
ruby <snake-case-exercise>_test.rb
```

Substitui `<snake-case-exercise>` pelo nome do teu exercício em snake_case.

## Saída com cores

Podes usar `require 'minitest/pride'` ou executar o seguinte comando para obteres a saída com cores:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
