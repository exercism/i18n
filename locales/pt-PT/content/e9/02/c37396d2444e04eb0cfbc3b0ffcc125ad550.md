# Dicas

## 1. Define os tipos `Usd`, `Eur` e `Jpy`

- Os tipos `Usd`, `Eur` e `Jpy` podem ser definidos sem construtores recorrendo à sintaxe `pub type TypeName`.

## 2. Define o tipo `Money`.

- O tipo `Money` deve ter um parâmetro de tipo fantasma para a moeda.

## 3. Define as funções `dollar`, `euro` e `yen`

- A anotação de retorno das funções `dollar`, `euro` e `yen` deve ser `Money(currency)`, em que `currency` é o parâmetro de tipo adequado do tipo `Money`.

## 4. Define a função `total`

- A anotação de retorno da função `total` deve usar o mesmo parâmetro de tipo que o argumento.
