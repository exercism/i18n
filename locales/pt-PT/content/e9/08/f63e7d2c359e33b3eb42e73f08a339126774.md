# Acerca de

- O tipo [binário][binary] é uma especialização do tipo [bitstring][bitstring].
- Os binários são compostos por [bytes][wiki-byte].
  - Um byte tem 8 [bits][wiki-bit].
  - Um byte pode representar números de `0` a `255`
  - Valores inteiros [hexadecimais][wiki-hexadecimal] são comuns quando se trabalha com bytes: `0x00` a `0xFF`.
- Os literais binários definem-se com a [forma especial `<<>>`][special-form].
  - Se usares um inteiro maior do que `255` para um byte, só os últimos 8 bits são usados, a menos que especifiques a [unidade e/ou o tamanho a usar][bin-size] com o operador [`::`][type-operator].
- Podes usar [`<>/2`][bin-concat] para concatenar bitstrings, binários ou strings.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

Um _byte nulo_ é outro nome para `<<0>>`.

## As strings são dados binários codificados

- As strings são dados binários codificados no formato [UTF-8][wiki-utf8].
  - São codificadas em blocos de 8 bits (um byte), usando até 4 bytes para representar mais de 255 carateres.
  - O [comprimento de uma string][string-length] pode não ser o mesmo que o seu [tamanho em bytes][byte-size].

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## Pattern matching em dados binários

- Podes fazer pattern matching a um binário como um todo, ou usar a forma especial para corresponder a apenas uma parte.
  - Apenas a última parte de um pattern match pode ter um tamanho variável.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

Isto também pode ser feito com strings:

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
