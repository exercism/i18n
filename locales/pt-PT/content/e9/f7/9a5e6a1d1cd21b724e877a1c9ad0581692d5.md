# Instruções

És o telegrafista sem fios de um cargueiro. O sinal chega por uma linha ruidosa (a maquinaria do navio, o estático do tempo, uma conversa estrangeira ocasional), entremeado com o verdadeiro Morse que estás a tentar ouvir. Para apanhares a mensagem, fazes passar o fio por um dispositivo *tape* que elimina tudo exceto os símbolos de Morse válidos (`.`, `-` e o espaço que separa as letras).

O teu trabalho é construir a tape como um fluxo de entrada personalizado do Factor.

## 1. Define a tape

Define um tuplo `tape` que estende `disposable` e tem uma única fenda, `wire`, para o fluxo de entrada subjacente.

```factor
TUPLE: tape < disposable wire ;
```

Depois escreve o construtor `<tape> ( wire -- tape )`. Usa `new-disposable` (e não `new`) para que o framework de destruição registe a tape, e guarda o fluxo subjacente na fenda `wire`.

## 2. Integra o mixin input-stream

Declara `tape` como um `input-stream`:

```factor
INSTANCE: tape input-stream
```

Isso faz com que os combinadores predefinidos do protocolo sejam encaminhados para a tua classe.

## 3. Lê um símbolo de Morse

Implementa `M: tape stream-read1 ( tape -- elt/f )`. Lê bytes do fio subjacente até encontrares um de `CHAR: .`, `CHAR: -` ou `CHAR: \s` (espaço). Devolve esse byte. Se o fio devolver `f` (fim do fluxo), devolve `f` também; a tape chegou ao fim.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. Delega o tipo de elemento

Implementa `M: tape stream-element-type ( tape -- type )` delegando no fio: a tape não altera o tipo de elementos que são lidos.

## 5. Liberta os recursos

Implementa `M: tape dispose* ( tape -- )`. O framework chama o teu método exatamente uma vez por cada `dispose`; basta libertares o fio subjacente.

Com estas cinco peças no lugar, a tape funciona como um fluxo de entrada normal: `with-input-stream`, `stream-read` e as restantes palavras do protocolo são encaminhadas automaticamente para os teus métodos.
