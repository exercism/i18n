# Sobre

O conceito básico de `try .. rescue` pode ser estendido para suportar as cláusulas `else` e `after`:

- O bloco `else`:
  - Onde ocorre uma correspondência de padrões com o resultado bem-sucedido do bloco try.
- O bloco `after`:
  - Onde são invocadas funções, quer o bloco try tenha sucesso, quer seja resgatado, desde que o programa esteja a correr.
  - O resultado do bloco `after` não é devolvido ao âmbito que fez a chamada.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
