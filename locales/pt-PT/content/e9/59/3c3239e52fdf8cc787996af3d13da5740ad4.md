# Anexo às instruções

## Registos

| Registo  | Utilização | Tipo    | Descrição                          |
| -------- | ---------- | ------- | ---------------------------------- |
| `$a0`    | parâmetro de entrada | inteiro | índice do primo           |
| `$v0`    | valor devolvido      | inteiro | valor do n-ésimo primo    |
| `$t0-9`  | temporário           | qualquer | usado para armazenamento temporário |
