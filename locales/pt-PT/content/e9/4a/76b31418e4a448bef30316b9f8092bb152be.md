# Sobre

O assembly x86-64 é a linguagem de programação para a versão de 64 bits do
conjunto de instruções x86. Baseia-se no conjunto de instruções original do
8086, de 1978.

A linguagem assembly é diferente de linguagens de alto nível como C# e Java.
Não existem variáveis, objetos nem ciclos. Em vez disso, vais ter de lidar com
registos, endereços de memória e saltos.

Aprender assembly pode ser intimidante ao início, mas vai dar-te uma melhor
compreensão de como o teu computador funciona. Pode até melhorar as tuas
competências de programação em linguagens de alto nível.
