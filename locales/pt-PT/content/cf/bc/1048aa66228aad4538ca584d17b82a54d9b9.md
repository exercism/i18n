# Instruções

Estás a criar um jogo online simples em que um amigo pode adivinhar um número secreto. Queres dar algum feedback, mas sem revelar a resposta com um palpite. Precisas de criar uma função que devolva respostas diferentes conforme a relação entre o palpite e o número secreto.

| Condição                                                      | Resposta       |
| ------------------------------------------------------------- | -------------- |
| Quando o palpite coincide com o número secreto                | "Correct"      |
| Quando o palpite é mais um ou menos um do que o número secreto | "So close"     |
| Quando o palpite é maior do que o número secreto              | "Too high"     |
| Quando o palpite é menor do que o número secreto              | "Too low"      |
| Quando não é feito nenhum palpite                             | "Make a guess" |

Todos os palpites e números secretos são números inteiros.

## 1. Devolve a resposta quando o palpite coincide com o número secreto

Implementa a função `compare/2`, que recebe dois argumentos, `secret_number` e `guess`, ambos números inteiros.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. Devolve a resposta quando o palpite é maior do que o número secreto

Modifica a função `compare` para responder a palpites maiores do que o número secreto.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. Devolve a resposta quando o palpite é menor do que o número secreto

Modifica a função `compare` para responder a palpites menores do que o número secreto.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. Devolve as respostas quando o palpite é mais um ou menos um do que o número secreto

Modifica a função `compare` para responder a palpites próximos do número secreto.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. Devolve a resposta quando não há palpite

Modifica a função `compare` para responder à ausência de palpite.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
