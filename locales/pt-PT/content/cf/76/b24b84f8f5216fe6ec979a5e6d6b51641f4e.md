# Instalação

## Requisitos do percurso da linguagem PowerShell

O percurso da linguagem PowerShell do Exercism requer que estejam instalados no teu sistema:

- PowerShell ou Windows PowerShell Core
- o módulo do framework Pester de testes e mocks

(PS: o suporte para o PowerShell está limitado a correções críticas. O PowerShell Core é mantido de forma consistente e tem maior suporte multiplataforma)

### Instalar o PowerShell

O PowerShell vem pré-instalado em todos os sistemas operativos Windows a partir do Windows 7 SP1.

Podes encontrar a versão mais recente do PowerShell e instruções de instalação para todas as plataformas (Linux, macOS e Windows) [aqui][installation].

O código-fonte e a instalação manual do [PowerShell][source-code] também estão disponíveis.

### Instalar e atualizar o framework Pester

O [Pester][pester] é o framework de testes do PowerShell.
Desde a versão 4.0.9, é compatível com o PowerShell Core no Windows, Linux e MacOS (com algumas limitações).

Vem pré-instalado no Windows 10, mas recomenda-se que o atualizes executando o seguinte comando do PowerShell:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

Para atualizações subsequentes, executa:

```PowerShell
Update-Module -Name Pester
```

Se necessário, encontras mais instruções de instalação em: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## Utilizar uma IDE

Se queres uma experiência de edição mais completa, provavelmente queres usar uma IDE.
Estas são as IDEs mais populares que suportam a criação de projetos PowerShell:

### Todas as plataformas

- [PowerShell ISE (Integrated Scripting Environment)][ise], IDE gráfica incorporada que vem com o PowerShell (apenas no Windows).
  Para iniciar o PowerShell ISE, escreve `powershell_ise.exe` numa consola do PowerShell.
- [Visual Studio Code][vsc] com a [extensão PowerShell][vsc-extension].
  O Visual Studio Code também te permite executar os testes e depurar o teu código.
- [Sublime Text 3][sublime] com o [pacote PowerShell][sublime-package].
