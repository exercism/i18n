# Dicas

## Geral

- Lê sobre [charlists][getting-started-charlists], [Unicode e code points][getting-started-code-points] e [`case`][getting-started-case] no guia oficial Getting Started.
- Lê sobre [charlists][elixirschool-charlists] e [`case`][elixirschool-case] no elixirschool.com.

## 1. Sanitiza os nomes de utilizador existentes, removendo tudo exceto as letras minúsculas

- Usa recursão para iterar sobre uma charlist.
- Existe [uma função incorporada][kernel-case] que nos permite comparar um dado valor com vários padrões.
- Existe [uma sintaxe especial][syntax-reference-code-points] para obter o code point de um caráter. Pode ser usada em guards.
- As charlists são listas de code points e, como os code points são números, podem ser [comparados][kernel-greater-than] entre si.
- As letras latinas minúsculas têm todas [code points consecutivos][unicode-character-reference], por ordem alfabética.
- Existe [uma função incorporada][kernel-concat-list] que te permite concatenar duas listas.

## 2. Permite underscores

- Existe [uma sintaxe especial][syntax-reference-code-points] para obter o code point de um caráter. Pode ser usada em guards e também funciona para carateres de pontuação.
- Existe [uma função incorporada][kernel-concat-list] que te permite concatenar duas listas.

## 3. Substitui carateres alemães

- Existe [uma sintaxe especial][syntax-reference-code-points] para obter o code point de um caráter. Pode ser usada em guards e também funciona para letras não ASCII.
- Existe [uma função incorporada][kernel-concat-list] que te permite concatenar duas listas.
