# Introdução

Uma função permite-te agrupar código numa unidade reutilizável.
É composta pela palavra-chave `func`, pelo nome da função e por uma lista, separada por vírgulas, de zero ou mais parâmetros e respetivos tipos entre parênteses.

## Parâmetros de função

Todos os parâmetros têm de ser tipados explicitamente; não existe inferência de tipos para os parâmetros.
Não há valores predefinidos para os parâmetros, por isso todos os parâmetros da função são obrigatórios.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

Os parâmetros do mesmo tipo podem ser declarados em conjunto, seguidos de uma única declaração de tipo.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Parâmetros vs. argumentos

Vamos ver rapidamente dois termos que são frequentemente confundidos: `parameters` e `arguments`.
Os parâmetros de função são os nomes definidos na assinatura da função, como `greeting` e `name` na função `PrintGreetingName` acima.
Os argumentos de função são os valores concretos passados aos parâmetros da função quando invocamos a função.
Por exemplo, no exemplo abaixo, `"Hello"` e `"Katrina"` são os argumentos passados aos parâmetros `greeting` e `name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## Valores devolvidos

Os parâmetros da função são seguidos de zero ou mais valores devolvidos, que também têm de ser tipados explicitamente.
Um único valor devolvido fica sem parênteses; vários valores devolvidos são envolvidos em parênteses.
Os valores são devolvidos ao código que fez a chamada através da palavra-chave `return`.
Pode haver várias instruções `return` numa função.
A execução da função termina assim que encontra uma dessas instruções `return`.
Se uma função tiver de devolver vários valores, estes são separados por vírgulas.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Invocar funções

Invocar uma função consiste em indicar o nome da função e passar argumentos para cada um dos parâmetros da função, entre parênteses.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Valores devolvidos com nome e return nu

Tal como os parâmetros, os valores devolvidos também podem ter um nome.
Se forem usados valores devolvidos com nome, uma instrução `return` sem argumentos devolve esses valores.
É a isto que se chama um return 'nu'.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
