# Métodos de string

A `String` tem vários métodos que podem ser usados para manipular strings.  
Estes métodos são chamados na própria string e são frequentemente encadeados para realizar várias operações sobre uma string.

A seguir está uma lista de alguns dos métodos mais comuns.
Consulta a [documentação da API `String`][string-api] para veres uma lista completa de métodos.

## String#upcase & String#downcase

O método [`upcase`][upcase] devolve uma nova string com todos os carateres convertidos para maiúsculas.

```crystal
"hello".upcase
# => "HELLO"
```

O método [`downcase`][downcase] devolve uma nova string com todos os carateres convertidos para minúsculas.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

Vários métodos conseguem fazer conversões de maiúsculas e minúsculas mais específicas.
Isso pode ser útil quando queres converter uma string para um formato específico.
Aqui está uma lista de alguns dos métodos mais comuns:

| Método                            | Descrição                                                                                                          | Exemplo                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | Converte a primeira letra para maiúscula e as restantes para minúsculas                                            | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | Converte underscores em camelcase                                                                                  | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | O mesmo que String#camelcase, mas deixa o primeiro caráter em minúscula                                            | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | Converte todos os carateres para minúsculas e coloca um underscore entre uma letra minúscula e uma letra maiúscula | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | Coloca a primeira letra de cada palavra em maiúscula e as restantes em minúsculas                                  | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

A linguagem Crystal tem métodos para substituir partes de uma string.
Estes são conhecidos como [`sub`][sub] (_substitution_) e [`gsub`][gsub] (_global substitution_).

Estes métodos podem receber uma string, um char ou uma regex como primeiro argumento e uma string ou um char como segundo argumento.
O primeiro argumento é a parte da string que vai ser substituída, e o segundo argumento é a substituição.
O tipo `Char` e as regex serão explicados em conceitos posteriores.

O método `sub` substitui a primeira ocorrência do primeiro argumento pelo segundo argumento.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

O método `gsub` funciona da mesma forma que o `sub`, mas substitui todas as ocorrências do primeiro argumento pelo segundo argumento.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

O chomp e o strip podem ser usados para remover carateres indesejados de uma string.

Por defeito, o método [`chomp`][chomp] remove os últimos carateres `\r`, `\n` ou `\r\n` de uma string.
Se o método for chamado com um argumento, remove o valor indicado do fim da string, caso esse valor exista no fim da string.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Por defeito, o método [`strip`][strip] remove todos os espaços em branco do início e do fim de uma string.
Se o método for chamado com um argumento, remove esse argumento do início e do fim da string, caso esse argumento exista no início ou no fim da string.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

Podes usar o método [`reverse`][reverse] para inverter uma string.
Este método devolve uma nova string com os carateres na ordem inversa.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

O método [`index`][index] pode ser usado para encontrar o índice de um caráter numa string.
O método `index` recebe uma `String`, um `Char` ou uma regex como argumento.
Pode receber um segundo argumento opcional para indicar o índice a partir do qual pesquisar.
O método `index` devolve o índice da primeira ocorrência do argumento.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Podes usar o método [`delete_at`][delete_at] para remover um caráter de uma string.
O método `delete_at` recebe um índice como argumento e remove o caráter nesse índice.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

O método [`insert`][insert] pode ser usado para inserir uma string num índice específico.
O método `insert` recebe um índice como primeiro argumento e uma string como segundo argumento.
O método `insert` devolve uma nova string com o segundo argumento inserido nesse índice.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
