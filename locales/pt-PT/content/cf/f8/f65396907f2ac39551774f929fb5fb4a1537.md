# Introdução

Neste exercício tens de executar lógica de forma condicional. A forma mais comum de o fazer em C# é usar uma condicional `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

A condição de uma condicional `if` tem de ser do tipo `bool`. O C# não tem o conceito de valores _truthy_.
