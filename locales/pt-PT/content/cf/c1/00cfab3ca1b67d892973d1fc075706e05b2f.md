# Introdução

## Funções com várias cláusulas

O Elixir facilita as práticas do **Princípio Aberto-Fechado** ao permitir que as funções tenham várias cláusulas. Assim, em vez de uma lógica de controlo extensa e fixa no código, podes escrever funções direcionadas que adicionam ou removem comportamento com facilidade.

O Elixir oferece _várias cláusulas de função_ e _guardas_ para escreveres:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

Em tempo de execução, o Elixir testa, de cima para baixo do ficheiro de código, qual a cláusula de função a invocar.

As variáveis que não são usadas devem ser precedidas por um underscore.

## Guardas

As guardas servem para impedir que o Elixir invoque funções, com base na avaliação dos argumentos feita pelas funções de guarda. As guardas começam com a palavra-chave `when`, seguida de uma expressão booleana. As funções de guarda são funções especiais que:

- Têm de ser puras e não podem alterar quaisquer estados globais.
- Têm de devolver estritamente valores `true` ou `false`.

Encontras uma lista de guardas comuns na [documentação do Elixir][kernel-guards]. Inclui verificação de tipos, aritmética básica, comparações e operadores estritamente booleanos.

## Argumentos predefinidos

As funções podem declarar valores predefinidos para um ou mais argumentos. Vamos considerar esta função:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Quando é compilado, o Elixir cria uma definição de função para `number/0` (sem argumentos) e `number/1` (um argumento).

Se mais do que um argumento tiver valores predefinidos, os valores predefinidos são aplicados à função da esquerda para a direita, para preencher os argumentos em falta.

Se a função tiver mais do que uma cláusula, os argumentos predefinidos devem ser definidos num cabeçalho de função (uma função sem corpo) antes das cláusulas da função:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
