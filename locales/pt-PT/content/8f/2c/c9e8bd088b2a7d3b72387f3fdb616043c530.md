# Dicas

## 1. Configurar os tipos de utilizador e as permissões.

- Para tratar cada enumerador de `AccountStatus`, podes usar uma instrução `if`, mas uma [instrução `switch`][switch] é uma ótima alternativa.


## 2. Promover trolls apenas a outros trolls.

- Podes comparar enumerações como qualquer outro tipo com os operadores `!=` e `==`.

## 3. Verificar as permissões de diferentes utilizadores.

- Se resolveres a tarefa com uma instrução `switch`, os [fallthroughs][fallthrough] podem ser úteis.
- Podes usar [etiquetas sequenciais][fallthrough] e a etiqueta [default][switch] para agrupar permissões.

## 4. Conceder acesso ao jogo e emparelhar jogadores.

- A tua principal preocupação são as contas `guest` e `troll`; para as outras combinações, não precisas de separar a tua lógica.

## 5. Criar a fila por prioridade.

- Se ordenares corretamente a tua enumeração `AccountStatus`, podes usar `static_cast<int>` para comparar os enumeradores de forma compacta.
