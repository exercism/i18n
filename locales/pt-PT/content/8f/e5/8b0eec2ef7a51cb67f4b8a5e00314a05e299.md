# Integração de funcionários numa base de dados

## Enunciado do problema

A ABC Corp planeia manter numa base de dados toda a informação sobre pagamentos de pequenas despesas aos funcionários. Estás a ajudar o departamento financeiro da ABC Corp a implementar esta base de dados. Como a ABC Corp está a expandir as suas operações, adicionar novos funcionários ao sistema é um requisito frequente devido às novas contratações.

A tua tarefa é adicionar os dados do novo funcionário fornecidos à tabela `Employee` da base de dados e devolver o valor da coluna `employee_id`, gerada automaticamente, sem fazeres outra consulta à base de dados para a encontrares. Se ocorrer um erro durante a execução, deve ser devolvido `-1`.

## Detalhes da base de dados

Usa a base de dados H2 fornecida para este problema.

> O ficheiro da base de dados de exemplo é `gofigure.mv.db` e o nome da base de dados é `gofigure`. Está incluído na pasta `db`.

As tabelas seguintes já existem na base de dados H2 de exemplo, com alguns dados de exemplo. Os nomes das colunas e os tipos de dados são os que se seguem.

**Nome da tabela** : `Employee`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | inteiro, chave primária de incremento automático       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | inteiro        |

**Nome da tabela**: `Payment`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | inteiro, chave primária de incremento automático       |
| `date`            | data        |
| `amount`          | decimal        |
| `employee_id`     | inteiro        |
| `reason`          | string        |

* O ficheiro da base de dados é `gofigure.mv.db`. Usa o URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nome de utilizador: `root`
* Palavra-passe: `root`

## Restrições

* Usa o ficheiro da base de dados H2 fornecido na pasta `db` para validares as consultas e o exemplo em Ballerina
* Usa a abordagem dos parâmetros de dependência do Maven para adicionares o controlador da base de dados H2 como dependência de plataforma no teu Ballerina.toml
* Não faças outra consulta à base de dados para encontrares o id gerado automaticamente


## Ambiente de testes

* Podes executar os testes com `bal test`, e os testes serão executados contra a base de dados de exemplo fornecida.
