# Instruções

Neste exercício, a tua tarefa é escrever o software de um dispositivo de encriptação que funciona realizando transformações sobre dados. Precisas de uma forma de criar flexivelmente funções complicadas, combinando funções mais simples.

Em cada tarefa, devolve um bloco que possa ser invocado a partir do âmbito de quem chama.

## 1. Cria um somador

Implementa `secret-add`.
Deve devolver uma função que recebe um argumento e lhe soma o argumento passado a `secret-add`.

## 2. Cria um subtrator

Implementa `secret-subtract`.
Deve devolver uma função que recebe um argumento e subtrai a esse argumento o segredo passado a `secret-subtract`.

## 3. Cria um multiplicador

Implementa `secret-multiply`.
Deve devolver uma função que recebe um argumento e multiplica-o pelo segredo passado a `secret-multiply`.

## 4. Cria um divisor

Implementa `secret-divide`.
Deve devolver uma função que recebe um argumento e divide-o pelo segredo passado a `secret-divide`.

## 5. Cria um combinador de funções

Implementa `secret-combine`.
Deve devolver uma função que recebe um argumento e lhe aplica, pela ordem, as duas funções passadas a `secret-combine`.
