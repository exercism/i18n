# Introdução

Usar `try..rescue` é uma construção poderosa para capturar erros quando eles ocorrem. Capturar erros permite que as funções devolvam valores definidos quando é necessário. A construção `try..rescue` oferece-nos ainda duas funcionalidades adicionais que podemos utilizar:

- o bloco `else`
  - Quando o bloco try tem sucesso, o resultado é comparado com este bloco.
- o bloco `after`
  - Quer o bloco try tenha sucesso, quer lance um erro, o código no bloco `after` é sempre executado, desde que o programa esteja a correr nesse momento.
  - O resultado do bloco `after` não é devolvido ao âmbito de quem fez a chamada.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
