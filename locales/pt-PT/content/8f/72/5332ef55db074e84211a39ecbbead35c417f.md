## Instruções

A tua tarefa é gerar os labirintos perfeitos para o Mickey e a Minerva: aqueles que têm apenas uma solução e nenhuma secção isolada.
Eis o que precisas de saber:

- O labirinto tem uma forma retangular com uma abertura no início e no fim.
- O labirinto tem salas e passagens, que se cruzam em ângulos retos.
- O programa deve aceitar dois parâmetros: rows e columns. O labirinto deve ter entre 5 e 100 células.
- Um labirinto com `x` colunas de largura e `y` linhas de altura deve ter `2x + 1` carateres de largura e `2y + 1` carateres de altura.
- Se não for fornecida nenhuma semente, gera um labirinto aleatório. Se a mesma semente for fornecida várias vezes, o labirinto resultante deve ser o mesmo de cada vez.
- Usa [carateres de desenho de caixas][Box-drawing] para desenhar paredes e um símbolo de seta (⇨) para a entrada à esquerda e a saída à direita.

Está na hora de criar alguns labirintos perfeitos para estes ratos aventureiros!

### Exemplos

1. O labirinto quadrado pequeno de 5x5 células (ou 11x11 carateres)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. O labirinto retangular de 6x18 células
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
