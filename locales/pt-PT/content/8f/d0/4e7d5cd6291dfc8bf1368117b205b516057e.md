# Operador de resolução de âmbito

O operador de resolução de âmbito (`::`) permite-nos referenciar uma classe para aceder às suas constantes de nome, propriedades estáticas ou métodos estáticos.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Usar `self` e `static` com o operador de resolução de âmbito

Pode ser necessário que um objeto referencie o seu próprio âmbito. Para facilitar isto, a palavra-chave `self` permite que uma classe referencie o seu próprio âmbito. Usar a palavra-chave `self` desacopla a classe do seu próprio nome, o que torna o código mais fácil de manter ao longo do tempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Usa a palavra-chave `static` com o operador de resolução de âmbito para fazer uma ligação tardia da referência à classe descendente atual.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Usar `parent` com o operador de resolução de âmbito

A palavra-chave `parent` é usada para referenciar constantes, propriedades ou métodos da classe-mãe. Habitualmente, é usada para chamar o construtor da classe-mãe quando um objeto está a ser instanciado:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Ressalvas

### Visibilidade de constantes, propriedades e métodos

O operador de resolução de âmbito continua a seguir as regras definidas pelos modificadores de visibilidade `public`, `private` e `protected`.
