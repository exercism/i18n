# Instruções

É o Dia de São Valentim. A tua cara-metade tem algumas ideias de atividades e está a pedir-te para avaliares cada uma: `yes`, `no` ou `maybe`.

As atividades são representadas como arrays de 2 elementos `{ tag value }`, em que `tag` é um dos seguintes: `board-game`, `chill`, `movie`, `restaurant` ou `walk`.

| atividade                 | forma                       |
| ------------------------- | --------------------------- |
| Jogar um jogo de tabuleiro | `{ board-game f }`          |
| Relaxar                   | `{ chill f }`               |
| Ver um filme de `genre`   | `{ movie genre }`           |
| Comer num restaurante de `cuisine` | `{ restaurant cuisine }` |
| Caminhar `km` quilómetros | `{ walk km }`               |

O género é um dos seguintes: `crime`, `horror`, `romance`, `thriller`. A cozinha é `korean` ou `turkish`.

## 1. Avalia a cozinha

Define `rate-restaurant` para tirar uma cozinha da pilha e devolver a tua aprovação:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. Avalia o género do filme

Define `rate-movie` para receber um género e devolver:

- `romance` → `yes`
- qualquer outro género → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. Avalia a caminhada

Define `rate-walk` para receber um número de quilómetros e devolver:

- mais de `11` → `yes`
- mais de `6`, até `11` → `maybe`
- caso contrário → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. Avalia a atividade

Define `rate-activity` para tirar uma atividade `{ tag value }` da pilha e devolver a tua aprovação. Reutiliza os auxiliares acima:

- `board-game`, `chill` → sempre `no`
- `movie` → delega em `rate-movie`
- `restaurant` → delega em `rate-restaurant`
- `walk` → delega em `rate-walk`

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. Contabiliza as aprovações

Define `approval-counts` para receber uma lista de atividades e devolver um array de 3 elementos `{ yes-count maybe-count no-count }` com a contagem de quantas foram avaliadas de cada forma.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
