# Adenda às instruções

## Algumas notas adicionais para a implementação em C++

Este exercício usa o [contentor vector][vector].
Podes achar útil usar o cabeçalho [algorithm][algorithm] para resolver este exercício.

Algumas das funções de algorithm precisam de [`iterators`][iterator] como argumentos.
Podem ser vistos como marcadores do início e do fim de um contentor.
Se quiseres percorrer o contentor completo, começas com `my_container.begin()` e acabas com `my_container.end()`.
Se só queres os elementos 2, 3 e 4 de um vector, podes usar `my_vector.begin() + 2` e `my_vector.begin() + 4`.

Os últimos testes verificam a [imutabilidade][immutability].
Nenhuma das funções que tens de escrever deve alterar as pontuações do jogo.

Se quiseres praticar mais um pouco, podes implementar uma função que adiciona novas pontuações ao jogo.
