# Instalação

Ao contrário das linguagens mais recentes, o COBOL tem vários compiladores bem mantidos, embora cada um tenha as suas próprias vantagens.

## GnuCobol

O GnuCOBOL é o compilador COBOL livre e de código aberto da Free Software Foundation. Transcompila COBOL para um programa em C antes de usar o GCC para o compilar num executável. Encontras as instruções de instalação [aqui][GnuCOBOL].

## IBM Cobol

Enquanto fabricante de mainframes, a IBM mantém o seu próprio dialeto de COBOL, que funciona no seu z/OS e noutros sistemas operativos modernos. Podes obter o IBM COBOL gratuitamente através de uma candidatura ao [ambiente COBOL para o VSCode][IBM COBOL], que faz parte do [Open Mainframe Project][Open Mainframe].

[GnuCOBOL]: https://gnucobol.sourceforge.io/faq/index.html#using-gnucobol
