Embora seja possível concatenar strings manualmente em Haxe, o Haxe suporta a [interpolação de strings][string-interpolation], que oferece uma sintaxe mais curta e mais prática:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

Como se mostra acima, as strings interpoladas ficam entre aspas simples (`'`), ao contrário das [strings][strings] normais, e podem conter identificadores especiais, denotados pelo símbolo de dólar (`$`), que desencadeiam a interpolação.

É possível incluir expressões completas com `${expr}`, em que `expr` é qualquer expressão Haxe válida:

```haxe
trace('the next number is ${x + 1}');
```

Para suprimir a interpolação quando queres mesmo um símbolo de dólar, podes usar `$$`:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

Por último, repara que a interpolação de strings é uma funcionalidade de tempo de compilação que não tem qualquer impacto no desempenho em tempo de execução. Internamente, o compilador do Haxe gera o código equivalente ao da concatenação manual.

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
