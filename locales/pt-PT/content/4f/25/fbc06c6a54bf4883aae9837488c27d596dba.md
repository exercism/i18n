# Executar os testes

No terminal, vai para o diretório base do exercício e executa os testes com:

```bash
$ gleam test
```

Isto executa o ficheiro de teste que está na subpasta `test`, um ficheiro cujo nome termina em `_test.gleam`

## Funções de teste

Os testes usam um [framework de testes personalizado](https://github.com/exercism/gleam-test-runner/tree/main/runner).
Qualquer função pública no diretório `test` cujo nome termine em `_test` é considerada um teste pelo framework de testes.

Por exemplo:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
