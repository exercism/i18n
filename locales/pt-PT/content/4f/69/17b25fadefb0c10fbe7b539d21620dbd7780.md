# Instruções

O teu amigo acabou de te enviar uma mensagem com um segredo importante.
Para não facilitar a leitura a outras pessoas, a mensagem foi encriptada através de uma série de manipulações de bits.
Vais precisar de escrever as funções que ajudam a desencriptar a mensagem.

## 1. Desloca os bits para trás

O primeiro passo para desencriptar a mensagem é desfazer o deslocamento feito no processo de encriptação, deslocando os bits de volta para a direita.
Haverá passos seguintes no processo de desencriptação que assumem que são inseridos zeros do lado esquerdo.

Implementa a função `shift_back()`, que recebe um valor e o número de posições a deslocar, e realiza o deslocamento.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Define alguns bits

De seguida, há alguns bits que precisam de ser colocados a 1.

Implementa a função `set_bits()`, que recebe um valor e uma máscara e devolve o resultado de colocar os bits no valor a 1.
Um bit de `value` deve ser colocado a 1 quando o bit em `mask` também for 1.
Todos os outros bits devem permanecer inalterados.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Inverte bits específicos

Alguns bits são invertidos durante a encriptação.
Vão precisar de ser invertidos de volta para desencriptar a mensagem.

Implementa a função `flip_bits()`, que recebe um valor e a máscara.
A máscara indica quais os bits do valor a inverter.
Se o bit for 1 em `mask`, o bit é invertido em `value`.
Todos os outros bits permanecem inalterados.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Limpa bits específicos

Por fim, há também certos bits que ficam sempre a 0 depois de desencriptados.

Implementa a função `clear_bits()`, que recebe um valor e uma máscara.
Os bits em `value` devem ser colocados a 0 quando o bit na máscara for 1.
Todos os outros bits devem permanecer inalterados.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
