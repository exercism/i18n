## 1. Define o tipo `Fiberator`

- `n` é a quantidade de números a gerar.
- Mantém-no simples: não é precisa mais nenhuma informação.

## 2. Implementa o(s) método(s) `iterate`

- Vê a Introdução para detalhes importantes de implementação.
- O argumento `state` não tem de ser um número inteiro. Pode ser de qualquer tipo.
- Pensa em que valores precisas para calcular o elemento seguinte. Uma tupla desses valores deve ser o argumento `state`.
- O método `iterate` devolve uma `Tuple` com dois valores `(item, state)`. `item` é o número de Fibonacci, ou seja, o `item` em `for item in Fiberator(10)`.
- Se o teu `state` inclui vários valores, considera usar uma tupla nomeada para clarificar o significado de cada valor.
  - Isto é útil para desempacotar, mas não é obrigatório.
