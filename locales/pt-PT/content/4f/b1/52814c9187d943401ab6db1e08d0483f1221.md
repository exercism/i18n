# Adenda às instruções

## Declaração de constantes

Neste exercício, pedimos-te que declares uma série de constantes usadas para identificar diferentes tipos de triângulos.
Escolhe o tipo de dados que consideras mais adequado para isto e faz passar os testes.

Depois, pode valer a pena ler sobre o identificador predefinido do Go [iota](https://golang.org/ref/spec#Iota).
Há [um excelente artigo sobre o assunto](https://splice.com/blog/iota-elegant-constants-golang/).
