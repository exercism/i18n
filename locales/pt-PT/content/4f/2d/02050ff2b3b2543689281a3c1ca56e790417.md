# Dicas

## 1. Os três números

- O cabeçalho da classe nomeia a classe abstrata depois de `<`: `class JUGGLING < $ACT is`.
- Cada um tem de definir tanto `name` como `minutes`, exatamente como a classe abstrata os declara. Se faltar um, surge um erro de compilação que indica o nome da rotina.
- Cada um precisa também de um `create`, senão `#JUGGLING` não tem nada que chamar. `create : SAME is return new; end;` é tudo o que é preciso para dois deles.
- `TRAPEZE` precisa de um atributo para a altura, e de um `create` que o recebe.
- O `+` junta um número a uma string, por isso `"Trapeze at " + height + "m"` não precisa de conversão.

## 2. O espetáculo

- O tipo do argumento é `ARRAY{$ACT}`. É isso que permite que um único array guarde os três tipos.
- `acts.elt!` devolve um `$ACT`. Chamar `.minutes` a esse valor executa por si só o método certo: isso é o despacho, e é o objetivo do exercício. Não há nada para verificar nem nenhum `typecase` para escrever.
- `billing` constrói uma string num ciclo, por isso `FSTR`, e o `", "` vai antes de todos os nomes exceto o primeiro.
- `longest` guarda o melhor número até agora. Começar os melhores minutos em `-1` faz com que o primeiro número o supere sempre, o que resolve o espetáculo vazio sem um caso especial: o nome fica `""`.
