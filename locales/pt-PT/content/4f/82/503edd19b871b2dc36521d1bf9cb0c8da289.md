# Introdução

O Python tem duas construções de ciclo.
Os ciclos `while` servem para iteração _indefinida_ (não contada) e os ciclos `for` para iteração _definida_ (contada).
As palavras-chave `break`, `continue` e `else` ajudam a personalizar o comportamento dos ciclos.
As funções `range(<length of sequence>)` e `enumerate(<iterable>)` ajudam na contagem e na indexação dos ciclos.


Nos ciclos `while` não se especifica um número de repetições a executar; continuam enquanto a expressão `loop` ou o "teste" for avaliada como `True`.
O ciclo termina quando a expressão do ciclo for avaliada como `False`.

```python
while expression:
    set_of_statements
```

Os ciclos `for` percorrem os valores de qualquer sequência e terminam quando não há mais valores a devolver.
A função `range(<length of sequence>)` fornece um contador de ciclo ou uma sequência quando não há uma estrutura de dados ou outro iterável para percorrer.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
