# Anexo às instruções

## Dica de desempenho

Todas as entradas e saídas estão em ASCII.
As `String` e as `&str` do Rust são utf8, por isso, embora se possa pensar que `"Hello".chars()` é simples, na verdade tem de verificar cada char para ver se ocupa 1, 2, 3 ou 4 `u8`.
Se soubermos que uma `&str` é ASCII, podemos chamar `.as_bytes()` e referir os dados subjacentes como `&[u8]` (uma fatia de bytes).
Iterar sobre uma fatia de bytes ASCII é muito mais rápido, porque não há pontos de código envolvidos: cada byte ASCII ocupa um único `u8`.
