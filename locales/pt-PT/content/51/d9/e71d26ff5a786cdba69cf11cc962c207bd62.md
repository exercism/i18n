# Instruções

A tua tarefa é resolver um puzzle binário.
Todos os puzzles binários têm exatamente _uma_ solução, que pode ser encontrada aplicando estas regras:

1. Cada célula tem de conter um zero ou um um.
2. Não pode haver mais de dois algarismos iguais adjacentes. Assim, se duas células adjacentes contiverem o mesmo algarismo, as células ao lado desses algarismos têm de conter o outro algarismo.
3. Cada linha e cada coluna têm de conter o mesmo número de zeros e de uns.
4. Cada linha e cada coluna são únicas.

Vais receber um puzzle incompleto na forma de linhas de zeros e uns, com marcadores de posição (`_`) para os valores desconhecidos.
O objetivo é definires as regras do puzzle binário, o que vai permitir que os testes determinem os valores dos marcadores de posição (não és tu que o fazes).
A tua implementação tem de usar a [Programação Lógica com Restrições sobre Domínios Finitos (CLP(FD))](https://www.swi-prolog.org/man/clpfd.html) do Prolog, que é perfeita para este tipo de tarefas.
