# Sobre

As sequências em Factor existem em duas variantes quando precisas de as *modificar*:

- Os **arrays** (`{ … }`) têm um comprimento fixo. Podes alterar o que está
  *em* cada posição com `set-nth` / `change-nth`, mas não os podes aumentar
  nem diminuir.
- Os **vectors** (`V{ … }`) têm comprimento variável. O `push` acrescenta ao
  fim e o `pop` remove e devolve o último elemento.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| palavra         | efeito                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`: array de `n` cópias de `elt` |
| `<vector>`      | `( n -- vector )`: vector vazio com capacidade `n` |
| `V{ }`          | literal de vector vazio                        |
| `set-nth`       | `( elt n seq -- )`: atribui o elemento no índice `n` |
| `change-nth`    | `( i seq quot -- )`: aplica `quot` ao elemento em `i` |
| `push`          | `( elt seq -- )`: acrescenta a um vector       |
| `suffix!`       | `( seq elt -- seq )`: acrescenta no local, devolve o vector |
| `pop`           | `( seq -- elt )`: remove e devolve o último    |
| `pop*`          | `( seq -- )`: remove o último e descarta-o     |
| `clone`         | `( obj -- copy )`: cópia nova e independente   |
| `new-sequence`  | `( n exemplar -- newseq )`: sequência nova da mesma classe que `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )`: variante redimensionável nova |

Quando alteras uma sequência que quem chama passou, a alteração fica
visível para quem chama: estão a segurar o mesmo objeto. Se não é isso
que queres, faz primeiro `clone` para obteres uma cópia independente.
