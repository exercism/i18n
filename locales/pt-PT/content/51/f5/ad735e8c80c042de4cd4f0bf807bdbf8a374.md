# Dicas

## Geral

- Usa o tipo de lista [integrado (ligada)][list].
- Usa as funções integradas do módulo [`Stream`][stream] para criar um stream.

## 1. Detetar argumentos inválidos

- Usa um [guard][guards] para detetar os casos em que não é passado um número inteiro como argumento a `generate/1`.

## 2. Gerar os casos base

- Podes usar várias [cláusulas de função][multiple-fn-clauses] e [pattern matching][pattern-matching] para criar as funções dos casos base.

## 3. Criar o caso generalizado

- Usa a função [`Stream.iterate/2`][stream-iterate] para gerar uma sequência de números, em que o seguinte é criado a partir do anterior.
- Os números iniciais são o `2` e depois o `1`, que podes passar juntos através de um tuplo para formar um par `{2, 1}`
- Certifica-te de que o número seguinte é a soma dos dois números anteriores a ele.
- Para avaliar o stream numa lista, usa uma função do [`Enum`][enum].
