# Introdução

Um ciclo é uma forma de executar repetidamente uma ou mais instruções em conjunto.
Cada execução de um conjunto de instruções chama-se uma iteração.

## Ciclo `while`

Um ciclo `while` executa um conjunto de instruções enquanto uma expressão Boolean no topo do ciclo for verdadeira.
Quando a expressão Boolean for falsa, o ciclo deixa de ser executado e a execução passa para a linha de código seguinte ao ciclo.

Se a expressão Boolean for avaliada como falsa desde o início, o ciclo `while` não chega a ser executado e a execução passa para a linha de código seguinte ao ciclo.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

É importante que exista uma condição para terminar o ciclo; caso contrário, trata-se de um ciclo infinito que vai bloquear todo o avanço do código.
Se ao código acima se retirasse o `++` do `i`, seria um ciclo infinito.

## Ciclo `do`

Num ciclo `do`, a expressão Boolean é testada no final do ciclo.
Um ciclo `do` é sempre executado pelo menos uma vez, como no exemplo seguinte

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Com um ciclo `while`, isto seria mais verboso

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Ciclo `for`

Muitas vezes, um ciclo atualiza uma variável e termina quando a variável atinge um determinado valor.
Um ciclo `for` é uma forma de inicializar, atualizar e testar uma ou mais variáveis numa única linha, dentro de parênteses.
A primeira secção serve para inicializar a variável, a segunda para a testar e a terceira para atualizar o valor da variável.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Isto é menos verboso do que o ciclo `while` equivalente e, ainda assim, continua a ser legível.
