# Introdução

As charlists criam-se com o sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Repara que, em versões mais antigas do Elixir, as charlists são representadas como `'hello'` com aspas simples.
~~~~

Embora sejam muito parecidas com as strings, estes dois tipos de dados são bastante diferentes um do outro. Uma charlist é uma lista de números inteiros. Os números inteiros representam os valores Unicode de um determinado caráter, também conhecidos como pontos de código.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Podes colocar `?` antes de um caráter para obter o respetivo ponto de código.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Como as charlists são listas, podes trabalhar com elas como com qualquer outra lista: com recursão e correspondência de padrões.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Podes concatenar duas listas com `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Quanto maior for a primeira lista, mais lenta é a concatenação, por isso evita acrescentar repetidamente elementos a listas de comprimento arbitrário.
