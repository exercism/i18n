# Ajuda

Aqui tens alguns recursos para obteres ajuda, caso encontres problemas

* A [Documentação oficial][official-docs] aborda a sintaxe, as funcionalidades da linguagem e os módulos da biblioteca padrão.
* O [Discord do Arturo][discord] é o servidor Discord oficial do Arturo.
* O [Rosetta Code][rosetta-code] tem mais de 770 exemplos de código em Arturo para as mais diversas tarefas.
