# Dicas

## Geral

- O tipo fornecido é recursivo: `Nil` representa uma lista vazia e `Cons(value, rest)` contém um elemento e outra lista.
  Usa estas mesmas formas num `match` para inspecionar uma lista ou numa expressão para construir uma.

- As operações devolvem listas atualizadas em vez de modificarem os seus argumentos.
