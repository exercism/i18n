# Instruções

Neste exercício vais brincar com um carro telecomandado, para o qual finalmente poupaste dinheiro suficiente para o comprar.

Os carros começam com a bateria cheia (100%). Cada vez que conduzes o carro com o telecomando, ele percorre 20 metros e gasta um por cento da bateria.

O carro telecomandado tem um visor LED sofisticado que mostra duas informações:

- A distância total percorrida, apresentada como: `"Driven <METERS> meters"`.
- A carga restante da bateria, apresentada como: `"Battery at <PERCENTAGE>%"`.

Se a bateria estiver a 0%, já não consegues conduzir o carro e o visor da bateria mostra `"Battery empty"`.

Tens seis tarefas, e cada uma delas vai trabalhar com instâncias de carros telecomandados.

## 1. Compra um carro telecomandado novo em folha

Implementa o método (_static_) `RemoteControlCar.Buy()` para devolver uma instância de um carro telecomandado novo em folha:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. Mostra a distância percorrida

Implementa o método `RemoteControlCar.DistanceDisplay()` para devolver a distância tal como é apresentada no visor LED:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. Mostra a percentagem da bateria

Implementa o método `RemoteControlCar.BatteryDisplay()` para devolver a percentagem da bateria tal como é apresentada no visor LED:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. Atualiza o número de metros percorridos ao conduzir

Implementa o método `RemoteControlCar.Drive()` que atualiza o número de metros percorridos:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. Atualiza a percentagem da bateria ao conduzir

Atualiza o método `RemoteControlCar.Drive()` para atualizar a percentagem da bateria:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. Impede a condução quando a bateria está descarregada

Atualiza o método `RemoteControlCar.Drive()` para não aumentar a distância percorrida nem diminuir a percentagem da bateria quando a bateria está descarregada (a 0%):

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
