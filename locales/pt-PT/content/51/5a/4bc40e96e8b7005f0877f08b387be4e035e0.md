# Instruções

Neste exercício vais escrever código para imprimir crachás com nomes para funcionários da fábrica.

## 1. Imprime um crachá para um funcionário

Os funcionários têm um ID, um nome e o nome do departamento. 
As etiquetas dos crachás dos funcionários são formatadas da seguinte forma: `"[id] - name - DEPARTMENT"`.
Implementa o método `printBadge()` para devolver a etiqueta do crachá de um funcionário:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Repara que o departamento deve ser escrito em maiúsculas na etiqueta.
~~~~

## 2. Imprime um crachá para um novo funcionário

Devido a uma particularidade do sistema informático, os novos funcionários às vezes ainda não têm um ID quando começam a trabalhar na fábrica.
Como os crachás são obrigatórios, vão receber um crachá temporário sem o prefixo do ID. 
Modifica o método `printBadge()` para suportar novos funcionários que ainda não têm um ID:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime um crachá para o dono

Até o dono da fábrica tem de usar um crachá a toda a hora.
No entanto, um dono não tem departamento. 
Neste caso, a etiqueta deve imprimir `"OWNER"` em vez do nome do departamento.
Modifica o método `printBadge()` para imprimir uma etiqueta para o dono:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Repara que é possível que o dono também seja um novo funcionário:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
