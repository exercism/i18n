# Introdução

O módulo `Agent` facilita uma abstração para criar [processos e o ciclo _receive-send_][exercism-processes]. A partir daqui, vamos chamar _'processos agente'_ aos processos iniciados com o módulo `Agent`. Um _processo agente_ pode ser escolhido para representar um estado partilhado central.

Para iniciar um _processo agente_, o `Agent` disponibiliza a função `start/2`. A função fornecida ao iniciar o _processo agente_ com `start` devolve o estado inicial do processo:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Tal como o `Map` ou o `List`, o `Agent` disponibiliza muitas funções para trabalhar com _processos agente_.

É habitual organizar e encapsular toda a funcionalidade relacionada com o `Agent` num módulo para o domínio que está a ser modelado.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
