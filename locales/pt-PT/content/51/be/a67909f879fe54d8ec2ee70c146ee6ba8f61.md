# Instruções

Recebe uma lista aninhada e devolve uma única lista achatada com todos os valores, exceto nil/null.

O desafio é escrever uma função que aceita uma estrutura aninhada do tipo lista, com profundidade arbitrária, e devolve uma estrutura achatada sem quaisquer valores nil/null.

Por exemplo:

entrada: [1,[2,3,null,4],[null],5]
saída: [1,2,3,4,5]
