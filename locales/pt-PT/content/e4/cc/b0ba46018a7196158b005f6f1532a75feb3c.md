# Instruções

Neste exercício vais escrever código para ajudar uma empresa de placas a criar mensagens personalizadas para as suas placas.

## 1. Cria uma placa de ocasião

Implementa a função `buildSign(occasion, name)`, que recebe uma string como parâmetro `occasion` e uma string com o nome de alguém como parâmetro `name`.
Os dois parâmetros serão incorporados numa template string para produzir a mensagem na placa.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Cria uma placa de aniversário

Implementa a função `buildBirthdaySign(age)`, que recebe uma idade e, com base nessa idade, determina parte da mensagem na placa.
Se a idade for 50 ou mais, a placa refere o utilizador como _mature_; caso contrário, refere-o como _young_.
O resultado esperado exato é mostrado abaixo:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Cria uma placa de final de curso

Implementa a função `graduationFor(name, year)`, que recebe um nome como parâmetro string e um ano como parâmetro numérico, e utiliza interpolação de strings para criar uma frase para uma placa, com uma nova linha a separar as duas linhas da mensagem.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Calcula o custo de uma placa

Implementa a função `costOf(sign, currency)`, que recebe uma string com o conteúdo da placa e uma string que representa a moeda.
A placa tem um preço base de 20 na moeda indicada. Além disso, cada letra custa 2. (Os espaços em branco também contam para o cálculo.)
A frase devolvida inclui o custo de criação da placa, escrito com duas casas decimais, seguido da string da moeda.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
