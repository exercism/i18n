# Acerca de

O Haxe tem dois tipos de números: inteiros e números de vírgula flutuante:

- `Int`: representa um número inteiro.
- `Float`: representa um número de vírgula flutuante de precisão dupla de 64 bits.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Embora qualquer `Int` possa ser usado onde se espera um `Float` (ou seja, `Int` **é atribuível a** ou **unifica com** `Float`), o contrário não é verdade: atribuir um `Float` a um `Int` pode causar perda de precisão e, por isso, não é permitido implicitamente.

## Comparação

Dois números são iguais se tiverem o mesmo valor.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

Para o último caso, consulta [0.30000000000000004.com][0.30000000000000004.com] para uma breve explicação.
