# Dicas

## 1. Define o tempo previsto no forno em minutos

- Uma função global e com nome define-se com
  [`defun`][cookbook-functions].
- Uma função "devolve" (_por exemplo_, avalia para) o valor da última
  expressão do seu corpo.
- Uma definição de função pode incluir uma string de documentação
  opcional depois da lista de parâmetros.

## 2. Calcula o tempo restante no forno em minutos

- Vais precisar de escrever uma [função][cookbook-functions] com um
  único parâmetro.
- Podes usar [`-`][hyper-subtract] para subtrair números.

* Podes invocar outra função colocando o nome da função como o
  primeiro elemento de uma expressão (_por exemplo_ `(func)`).

## 3. Calcula o tempo de preparação em minutos

- Precisas de definir uma [função][cookbook-functions] com um único
  parâmetro.
- Podes usar [`*`][hyper-multiply] para multiplicar números.

## 4. Calcula o tempo decorrido em minutos

- Precisas de definir uma [função][cookbook-functions] com dois
  parâmetros.
- Podes usar [`+`][hyper-plus] para somar números.
