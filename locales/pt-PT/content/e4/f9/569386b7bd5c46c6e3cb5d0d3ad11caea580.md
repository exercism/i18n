# Sobre

`case` é o mecanismo de escolha múltipla do Factor baseado na igualdade. É a
ferramenta certa quando a escolha depende de um *único* valor ser igual a
uma de várias alternativas, e não quando cada ramo precisa de um teste
diferente (para isso, usa `cond`).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Algumas coisas que vale a pena ter em conta:

- A igualdade faz-se com `=`. Tudo o que aceite `=` serve de chave: números,
  strings, carateres, símbolos e até tuplos.
- Os ramos *correspondentes* veem a pilha *sem* o valor de entrada. Os ramos
  *predefinidos* veem-no ainda no topo.
- Um `case` sem ramo predefinido e sem nenhuma cláusula correspondente lança um erro.

Sempre que possível, o `case` é compilado para uma tabela de saltos. Por
isso, não é apenas açúcar sintático para uma cadeia de `if`: também é rápido.
