# Introdução

Quando precisas de uma fila de `n` valores em que cada um depende da sua posição, o `<iota>` e o `map` do Factor trabalham em conjunto para fazer o trabalho sem escreveres um contador de ciclo.

## `<iota>` e `map`

O `<iota>` (em [`sequences`][sequences]) recebe um número inteiro não negativo `n` e devolve uma sequência *virtual* dos números inteiros `0, 1, …, n-1`. O `map` percorre-a depois, aplicando a tua citação a cada elemento:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

A citação recebe um número inteiro, o índice, e deixa na pilha o valor para essa posição.

## Iterar e repetir por contagem

Quando só precisas dos *efeitos secundários* de visitar cada índice, e não de uma nova sequência, o `each-integer` (em [`math`][math]) executa uma citação sobre `0, 1, …, n-1`:

```
each-integer ( n quot: ( i -- ) -- )
```

O `replicate` (em [`sequences`][sequences]) chama uma citação `n` vezes e recolhe os resultados, ignorando o índice. Dá jeito para construir `n` valores independentes:

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## Intervalos limitados

Quando o intervalo de índices não começa em `0`, ou queres que seja inclusivo nos dois extremos, o vocabulário [`ranges`][ranges] fornece literais com notação de parênteses. Os parênteses retos incluem o extremo; os parênteses curvos excluem-no.

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

Alguns atalhos comuns de um argumento:

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

O `<iota>` é a forma mais comum; o `[a..b]` e afins são a ferramenta certa quando o intervalo começa noutro sítio que não o `0` ou precisa de um limite superior inclusivo.

## Limites inferiores abertos e intervalos possivelmente vazios

Os parênteses retos *incluem* um extremo; os parênteses curvos *excluem* esse extremo. O mesmo truque à esquerda dá `(a..b]` e `(a..b)`:

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

O `0 n (a..b]` dá `{ 1 … n }` para `n > 0` e `{ }` para `n = 0`, a forma natural quando se itera por todos os números inteiros positivos até `n`, inclusive.

## Intervalos descendentes

As quatro formas de parênteses, `[a..b]`, `[a..b)`, `(a..b]` e `(a..b)`, contam *para baixo* quando `a > b`, em vez de darem um resultado vazio:

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## Construir uma string por posição

O `map` produz a forma que a sua citação devolver. Se a citação deixar um código de caráter na pilha, o `>string` (em [`strings`][strings]) transforma o resultado numa string:

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

O `CHAR: A` é interpretado como o número inteiro `65`. A citação aqui duplica o índice e soma essa base, o que dá em letras maiúsculas alternadas. Qualquer aritmética que acumules em cima do índice decide que caráter acaba nessa posição.

## Escolher por posição

Quando o caráter depende de uma *condição* sobre o índice, fazes a escolha dentro da citação:

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

As três primeiras posições testam `i 3 <` como `t`, por isso recebem `a`; as restantes recebem `b`. A mesma forma, `[ <test> [ <yes> ] [ <no> ] if ]`, cobre testes de paridade com `even?` / `odd?` (em [`math`][math]) e testes de cada k-ésima posição com `mod` e `zero?`.
