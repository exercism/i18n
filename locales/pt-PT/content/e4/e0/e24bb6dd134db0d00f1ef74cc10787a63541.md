# Ignorar

## Unicode e aglomerados de grafemas

Este exercício inclui testes com strings Unicode que contêm aglomerados de grafemas.
As funções de processamento de strings incorporadas no Perl não são suficientes para lidar com estas strings.
Aqui ficam alguns recursos que te podem ajudar:

* [Trata as strings Unicode como aglomerados de grafemas][foy]
* [Extrai por grafema em vez de por ponto de código (regex)][christiansen]

[foy]: https://www.effectiveperlprogramming.com/2011/06/treat-unicode-strings-as-grapheme-clusters/
[christiansen]: https://www.perl.com/pub/2012/05/perlunicookbook-extract-by-grapheme-instead-of-codepoint-regex.html/
