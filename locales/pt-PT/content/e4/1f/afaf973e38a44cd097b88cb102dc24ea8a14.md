# Ciclos `for-in`

Os ciclos são um conceito fundamental da programação: permitem-te executar um bloco de código várias vezes.
Em Swift, existem dois tipos de ciclos: os ciclos [`for-in`][for-loops] e os ciclos `while`.
Neste capítulo, vais aprender os ciclos `for-in`.

Os ciclos `for` permitem-te iterar sobre uma sequência de valores, um elemento de cada vez, associando cada um a uma variável à tua escolha.
O Swift permite-te iterar sobre vários tipos de sequências, como intervalos, arrays e strings (e outros tipos que serão abordados mais adiante).
Quando todos os elementos da sequência tiverem sido percorridos, o ciclo termina.

Os ciclos `for` declaram-se com a palavra-chave `for`, seguida de um nome de variável, da palavra-chave `in` e de uma sequência de valores sobre a qual iterar.
A variável indicada no ciclo `for-in` é imutável, ou seja, não podes alterar o seu valor dentro do ciclo.
Eis um exemplo de um ciclo `for-in` que itera sobre um array de números:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
A variável `number` é declarada no ciclo `for-in` e só está disponível dentro do âmbito do ciclo.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Iterar sobre um intervalo

Também podes iterar sobre um intervalo de números com um ciclo `for-in`.
Isto permite-te executar um bloco de código um número específico de vezes. Por exemplo, o intervalo `1...5` percorre os números 1, 2, 3, 4 e 5, por isso o ciclo executa-se 5 vezes.
Às vezes podes querer iterar sobre índices, numa estrutura de dados como um array; nesse caso, usa um intervalo `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Iterar sobre uma string

Também podes iterar sobre uma string com um ciclo `for-in`.
Isto permite-te percorrer cada caráter da string; repara, em particular, que o tipo indicado no ciclo é `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

O Swift também disponibiliza uma função `stride` que te permite criar uma sequência sobre um intervalo com um passo específico.
Essa sequência pode depois ser percorrida com um ciclo `for-in`.
A função `stride` está definida como [`stride(from:to:by:)`][stride-to] ou [`stride(from:through:by:)`][stride-through]; a primeira é exclusiva e a segunda é inclusiva.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Repara que o parâmetro `to` é exclusivo, por isso o ciclo itera até ao número anterior ao parâmetro `to`, enquanto o parâmetro `through` é inclusivo, ou seja, neste caso também incluiria o `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
