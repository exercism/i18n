# Introdução

Kotlin é uma linguagem de programação **estaticamente tipada** desenvolvida pela JetBrains. Isto significa que o tipo das variáveis é definido em tempo de compilação.

## Variáveis

Tal como noutras linguagens de programação estaticamente tipadas, o tipo de cada variável deve ser definido em tempo de compilação. Podes evitar declarações de tipo explícitas quando o compilador as consegue inferir a partir do contexto.

Kotlin tem variáveis imutáveis (`val`) e mutáveis (`var`). O valor de uma variável imutável não pode ser alterado depois de lhe ser atribuído o valor inicial. Na maior parte das vezes, vais usar este tipo de variável.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

O valor de uma variável mutável pode ser alterado uma ou mais vezes:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Os pontos e vírgulas em Kotlin são opcionais, exceto em alguns casos especiais que vamos ver mais adiante.

## Funções

As funções em Kotlin são definidas com a palavra-chave `fun` e são _cidadãos de primeira classe_ (não tem a ver com POO). Isto significa que as podes declarar (as chamadas `top-level functions`) diretamente em ficheiros (por exemplo, em Java só podes definir métodos dentro de classes, não em ficheiros):

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

As funções podem receber argumentos. Cada argumento tem um nome e um tipo. Ao contrário das variáveis, o tipo dos argumentos não pode ser inferido. As funções podem ter zero ou mais argumentos:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

As funções em Kotlin podem ou não devolver um valor:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

Para devolver um valor a partir de uma função, usa-se a palavra-chave `return`:

```kotlin
fun getName(): String {
    return "Alice"
}
```

As funções podem ter parâmetros com valores predefinidos. Estes valores são usados quando são omitidos no local onde a função é invocada:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## Comentários

Usa `//` para definir um comentário de uma linha:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

ou `/*` e `*/` para definir comentários de várias linhas:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
