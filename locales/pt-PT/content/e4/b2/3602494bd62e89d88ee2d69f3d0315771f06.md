# Instruções adicionais

## Instruções específicas para SML

As árvores binárias de pesquisa são úteis para qualquer tipo de dados ordenado, não apenas para números.

A secção 2.6 de [Notes on Programming SML/NJ][notes] aborda o polimorfismo, e a secção 4.1 aborda a utilização de funções _compare_.

[notes]: https://www.cs.cornell.edu/riccardo/prog-smlnj/notes-011001.pdf
