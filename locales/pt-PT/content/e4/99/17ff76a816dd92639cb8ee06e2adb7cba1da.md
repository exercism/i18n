# Introdução

Os arrays são sequências de comprimento fixo do Factor: podes alterar os elementos, mas não o comprimento. Já sabes escrever um literal de array (`{ … }`) e como fatiar e agregar um. Este exercício aborda o pequeno conjunto de ferramentas que surge quando constróis arrays a partir de valores na pilha e depois consultas ou reorganizas o seu conteúdo.

## Construir a partir da pilha

`1array`, `2array`, `3array` e `4array` (em [`arrays`][arrays]) retiram 1, 2, 3 ou 4 valores do topo da pilha e agrupam-nos:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## Juntar

`concat` (em [`sequences`][sequences]) recebe uma sequência cujos elementos são, eles próprios, sequências e achata-a um nível. `join` faz o mesmo, com um separador inserido entre cada par:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## Inverter

`reverse` devolve uma nova sequência com os elementos na ordem inversa:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## É um array?

`array?` (em [`arrays`][arrays]) é o predicado de tipo. É verdadeiro para qualquer valor criado por `<array>`, `1array`/`2array`/..., ou por um literal de array `{ … }`, e falso para tudo o resto (incluindo vetores, strings e outras sequências):

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## Consultar

`index` devolve a posição do primeiro elemento igual ao valor de entrada, ou `f` se não estiver presente. `member?` devolve apenas um Boolean. Ambas recebem o **elemento primeiro** e a **sequência em segundo lugar**. `members` (em [`sets`][sets]) devolve os elementos *únicos* de uma sequência (a operação de deduplicação) e `all-unique?` (também em `sets`) testa se a sequência já não tem duplicados:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
