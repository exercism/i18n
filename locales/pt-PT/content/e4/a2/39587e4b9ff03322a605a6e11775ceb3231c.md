# Introdução

Imagina que queres todos os números inteiros não negativos até 1000.
Seria ridículo teres de os escrever todos num array.

Para isso existe o tipo `range`:

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

Os intervalos são muito comuns: não só para te poupar trabalho a escrever, mas também como tipos devolvidos por funções.

Repara que os intervalos _não_ são vetores.
São apenas um conjunto de instruções para gerar uma sequência (avaliação "preguiçosa", ou um "iterador").

Se precisares de um intervalo como vetor, usa a função `collect()` para o converter:

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

É possível especificar o tamanho do passo, neste caso 0.3:

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

Portanto, a sintaxe é `start:stepsize:stop`.
Ambos os limites são _inclusivos_, como se vê no exemplo com inteiros.
Se o tamanho do passo não dividir exatamente `stop - start`, o último elemento não ultrapassa `stop`.

## Intervalos de letras

Também se podem usar sequências não numéricas em intervalos.
O exemplo mais simples são as letras ASCII:

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

O tipo `Char` será abordado com mais detalhe noutro conceito.
Por agora, trata-os apenas como carateres individuais entre plicas.

## Funções e operadores para intervalos

Verifica os limites de um intervalo com `first()` e `last()`.

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## Mais sobre indexação de vetores

Intervalos de inteiros e vetores podem ser usados na indexação de vetores:

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
