# Recursos

## Módulos

O Perl vem equipado com um conjunto de módulos principais, que podes encontrar listados no [perldoc](https://perldoc.perl.org/modules). Normalmente, vais poder usar qualquer um destes módulos de imediato. (Algumas distribuições podem exigir que instales os módulos principais separadamente).

O [Awesome Perl](https://github.com/hachiojipm/awesome-perl) é uma lista curada de módulos úteis e remete também para uma seleção de outras listas de recomendações.

Há vários instaladores de módulos disponíveis para o Perl, que te permitem instalar uma grande variedade de módulos disponíveis no [CPAN](https://metacpan.org/).

### App::cpm
Um instalador de módulos muito rápido e simples.
Há um tutorial disponível no [CPAN](https://metacpan.org/pod/App::cpm::Tutorial).

Já terás isto instalado se seguiste as instruções do `local::lib` da [documentação de instalação](https://exercism.org/tracks/perl5/installation).

Basta correr `cpm install` para instalar os módulos necessários a partir de um `cpanfile` e usar `--with-recommends` ou `--with-suggested` para instalar os módulos recomendados ou sugeridos, respetivamente.

Corre `cpm install Module::Name` para instalar um módulo específico localmente, ou corre `cpm install -g Module::Name` para instalar globalmente.

### App::cpanminus
O instalador de módulos mais conhecido e mais utilizado que existe.
Encontras as instruções de instalação no [CPAN](https://metacpan.org/pod/App::cpanminus).

Corre `cpanm -L local --installdeps .` para instalar os módulos necessários a partir de um `cpanfile`.
Corre `cpanm -L local Module::Name` para instalar um módulo específico localmente, ou corre `cpanm Module::Name` para instalar globalmente.

## Estilo de código e análise estática

Se procuras bons conselhos gerais sobre como escrever código Perl, o [Perl Best Practices][PBP], de Damian Conway, é uma boa referência.

Para embelezar o teu código, podes usar o módulo [Perl::Tidy][PerlTidy].

Podes depois usar o programa utilitário `perltidy` fornecido para reformatar o teu código.

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

O `perltidy` tem *imensas* opções de configuração para todos os gostos. Estão documentadas [aqui][perltidyDocs].

Existe também o [tidyview], uma interface visual que te permite ajustar as diferentes opções e ver o resultado de imediato.

Se queres impor práticas de programação, existe também o [Perl::Critic][perlcritic]. Vem com as regras descritas no livro *Perl Best Practices* que mencionámos atrás, mas existem imensos plugins e pode ser personalizado para se adaptar a quaisquer regras de código internas.

Para usar:

    $ perlcritic some_script.pl

A ferramenta tem imensos ajustes de configuração; consulta a sua [documentação][perlcriticdocs] para saberes tudo sobre eles.
