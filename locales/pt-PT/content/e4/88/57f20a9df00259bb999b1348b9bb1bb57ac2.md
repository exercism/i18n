# Introdução

Em Python, um [tuplo][tuple] é uma coleção _imutável_ de itens em _sequência_.
Como a maioria das coleções, os `tuples` podem conter qualquer tipo de dados (ou vários), incluindo outros `tuples`.
Os tuplos suportam todas as [operações comuns de sequências][common sequence operations], mas **não** suportam [operações de sequências mutáveis][mutable sequence operations].

Podes iterar sobre os elementos de um tuplo com a construção `for item in <tuple>`.
Se precisares tanto do índice como do valor do elemento, podes usar `for index, item in enumerate(<tuple>)`.
Como em qualquer sequência, podes aceder aos elementos dentro de `tuples` através de _notação de parênteses retos_, usando um `0-based index` a contar da esquerda ou um `-1-based index` a contar da direita.
Também podes copiar tuplos, total ou parcialmente, usando a notação de fatias (_`<tuple>[<start>:<stop>:<step>]`_).


## Construção de tuplos

Podes formar tuplos de várias formas, usando o construtor da classe `tuple(<iterable>)` ou a declaração literal `tuple`.

### Usar o construtor `tuple()` vazio ou com um _iterável_:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

As strings são iteráveis, por isso usar um único `str` como argumento do construtor `tuple()` pode dar resultados surpreendentes:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

Nos iteráveis únicos, os elementos são adicionados um a um:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### Declarar um tuplo como _literal_:

Como o construtor `tuple(<iterable>)` só aceita _iteráveis_ (ou nada) como argumentos, é muito mais fácil criar
 um tuplo de um só elemento com o método literal.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

Podes incluir estruturas de dados aninhadas como elementos de um `tuple`, incluindo outros `tuples`:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## Concatenação de tuplos

Podes concatenar tuplos com o operador de adição `+`, que desempacota cada `tuple` e cria um novo `tuple` combinado.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## Aceder aos elementos dentro de um tuplo

Podes aceder aos elementos dentro de um `tuple` através de _notação de parênteses retos_, usando um `0-based index` a contar da esquerda ou um `-1-based index` a contar da direita.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## Iterar sobre os elementos de um tuplo

Podes _iterar sobre_ os elementos dentro de um `tuple` num ciclo, usando a sintaxe `for item in <tuple>`.
Se precisares tanto dos índices como dos valores, podes usar `for index, item in enumerate(<tuple>)`.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## Verificar a pertença num tuplo

Podes usar o operador `in` para verificar se um elemento pertence a um `tuple`.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
