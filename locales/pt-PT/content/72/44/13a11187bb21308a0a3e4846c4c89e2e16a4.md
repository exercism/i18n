# Introdução

Em Python, o `None` é frequentemente usado para representar a ausência de um valor: um marcador para definir uma variável, um objeto ou um argumento `null` (vazio).

Se já ouviste falar ou usaste um tipo `NULL` ou `nil` noutra linguagem de programação, este uso do `None` em Python vai parecer-te familiar. O `None` ajuda-te a declarar variáveis ou argumentos de função para os quais ainda não tens valores. Estes podem depois ser reatribuídos a valores específicos, conforme for necessário.

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

O `None` é avaliado como `False` quando usado numa verificação condicional, por isso é útil para validar a «presença» ou a «ausência» de um valor, _qualquer_ valor: um padrão frequentemente usado quando uma função ou um processo pode devolver um objeto ou uma mensagem de erro.

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
