# Anexo

## Notas de implementação

Vais escrever uma implementação de uma lista duplamente ligada.

Implementa um Node para guardar um valor e ponteiros para os nós anterior e seguinte.

Depois, implementa uma LinkedList que guarda referências ao primeiro e ao último nó e oferece uma interface semelhante a um array para adicionar e remover itens:

- `push` (*insere um valor no fim*);
- `pop` (*remove um valor no fim*);
- `shift` (*remove um valor no início*);
- `unshift` (*insere um valor no início*);
- `delete` (*remove o primeiro nó correspondente*)

Para manteres a tua implementação simples, os testes não vão cobrir condições de erro.
Em concreto: `pop` ou `shift` nunca serão chamados numa lista vazia.
