# Instruções

Geres os jogos de azar na arcada do passadiço à beira-mar. Os jogadores lançam os dados, a máquina de garras apanha um prémio e a mesa de cartas precisa que se baralhe o baralho e se distribuam as mãos: tudo alimentado pelo acaso. No fim da noite, também queres uma funcionalidade de «replay», para que um jogo contestado possa ser executado outra vez a partir da mesma semente.

## 1. Lança um dado

Define `roll-die` de modo a receber o número de lados e devolver um lançamento no intervalo de `1` a `sides`, inclusive.

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. Apanha um prémio

Define `pick-prize` de modo a receber uma sequência de prémios e devolver um deles ao acaso.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. Baralha o baralho

Define `shuffle-deck` de modo a receber um baralho (uma sequência) e devolvê-lo com as cartas numa ordem aleatória.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. Distribui uma mão

Define `deal-hand` de modo a receber um baralho e um número `n`, e devolver `n` cartas *distintas* do baralho.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. Repete a partir de uma semente

Define `play-seeded` de modo a receber uma semente e uma quotation, e executar a quotation com um gerador inicializado a partir desse número inteiro, para que a mesma semente reproduza sempre o mesmo resultado. O resultado da quotation deve ser devolvido a quem a chamou.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
