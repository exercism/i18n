# Instruções

Neste exercício vais trabalhar com contas poupança.
Todos os anos, o saldo da tua conta poupança é atualizado com base na sua taxa de juro.
A taxa de juro que o teu banco te dá depende da quantidade de dinheiro na tua conta (o seu saldo):

- 3,213% para um saldo inferior a `0` dólares (o saldo fica ainda mais negativo).
- 0,5% para um saldo maior ou igual a `0` dólares e inferior a `1000` dólares.
- 1,621% para um saldo maior ou igual a `1000` dólares e inferior a `5000` dólares.
- 2,475% para um saldo maior ou igual a `5000` dólares.

Tens quatro tarefas, cada uma delas vai lidar com o teu saldo e a sua taxa de juro.

## 1. Calcula a taxa de juro

Implementa a função `InterestRate()` para calcular a taxa de juro com base no saldo indicado:

```go
InterestRate(200.75)
// => 0.5
```

Repara que o valor devolvido é um `float32`.

## 2. Calcula os juros

Implementa a função `Interest()` para calcular os juros com base no saldo indicado:

```go
Interest(200.75)
// => 1.003750
```

Repara que o valor devolvido é um `float64`.

## 3. Calcula a atualização anual do saldo

Implementa a função `AnnualBalanceUpdate()` para calcular a atualização anual do saldo, tendo em conta a taxa de juro:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

Repara que o valor devolvido é um `float64`.

## 4. Calcula os anos necessários até atingires o saldo pretendido

Implementa a função `YearsBeforeDesiredBalance()` para calcular o número mínimo de anos necessários para atingir o saldo pretendido, tendo em conta que, a cada ano, os juros são adicionados ao saldo.
Isto significa que o saldo após um ano é: saldo inicial + juros do saldo inicial.
O saldo após o segundo ano é: saldo após um ano + juros do saldo após um ano.
E assim sucessivamente, até que o saldo do ano atual seja maior ou igual ao saldo pretendido.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

Repara que o valor devolvido é um `int`.
