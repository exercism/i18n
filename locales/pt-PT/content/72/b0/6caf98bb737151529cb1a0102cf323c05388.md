# Testes

Para usares o CLI para executar o teste do exercício, corre o seguinte comando a partir do diretório do exercício:

```bash
clojure -M:test
```

## REPL

Para usares o REPL para executar o teste do exercício, corre o seguinte comando a partir do diretório do exercício:

```bash
$ clojure -m cljs.main -re node
```

Depois, faz `require` do namespace de teste do exercício e do namespace de teste do Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Muda o ns para o namespace de teste:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

Depois, chama `run-tests`:

```clojure
=> (cljs.test/run-tests)
```
