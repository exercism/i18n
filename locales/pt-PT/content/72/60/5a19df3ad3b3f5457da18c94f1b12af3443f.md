# Instruções

Neste exercício, vais escrever algum código para te ajudar a preparar-te para comprar um veículo.

Tens três tarefas: uma para determinar se vais precisar de ajuda para escolher entre dois veículos, outra para determinar que carta de condução vais precisar e outra para estimar o preço aceitável de um veículo usado.

## 1. Calcula se consegues pagar as prestações mensais de um determinado carro

Os stands de automóveis da tua cidade estão todos com uma promoção de cinco anos e 0% de juros, que gostarias de aproveitar.
Mas não tens a certeza se consegues suportar as prestações mensais do carro que queres.

A prestação mensal é o preço total do carro dividido pelo número de meses do período de cinco anos.

Implementa a função `canIBuy(vehicle:price:monthlyBudget:)`, que recebe os seguintes argumentos:
- `vehicle`: o nome do veículo que queres comprar.
- `price`: o preço do veículo que queres comprar.
- `monthlyBudget`: a quantia de dinheiro que consegues pagar todos os meses.

A função deve devolver a seguinte mensagem, de acordo com as seguintes condições:
- Se a prestação mensal do veículo for menor ou igual ao orçamento mensal, devolve a mensagem `"Yes! I'm getting a <vehicle>"`.
- Se a prestação mensal do veículo for superior ao teu orçamento mensal em até 10% (inclusive), devolve a mensagem `"I'll have to be frugal if I want a <vehicle>"`.
- Se a prestação mensal do veículo for mais de 10% superior ao teu orçamento mensal, devolve a mensagem `"Darn! No <vehicle> for me"`.

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. Determina o tipo de carta de condução de que vais precisar

Decidiste comprar um veículo usado e precisas de determinar que tipo de carta de condução vais precisar para o conduzir.

Implementa a função `licenseType(numberOfWheels:)`, que recebe o argumento `numberOfWheels`, o número de rodas do veículo que queres comprar.

A função deve devolver a seguinte mensagem, de acordo com as seguintes condições:
- Se o número de rodas for 2 ou 3, devolve a mensagem `"You will need a motorcycle license for your vehicle"`.
- Se o número de rodas for 4 ou 6, devolve a mensagem `"You will need an automobile license for your vehicle"`.
- Se o número de rodas for 18, devolve a mensagem `"You will need a commercial trucking license for your vehicle"`.
- Se o número for qualquer outro, devolve a mensagem `"We do not issue licenses for those types of vehicles"`.

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. Calcula uma estimativa do preço de um veículo usado

Agora que já tomaste a tua decisão, queres ter a certeza de que consegues um preço justo no stand.
Como estás interessado em comprar um veículo usado, o preço depende da idade do veículo.
Para uma estimativa aproximada, assume que, se o veículo tiver menos de 3 anos, custa 80% do preço original que tinha quando era novo.
Se tiver pelo menos 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos mas não mais de 10 anos, custa 70% do preço original.

Implementa a função `calculateResellPrice(originalPrice:yearsOld:)`, que recebe os argumentos `originalPrice`, que contém o preço original do veículo, e `yearsOld`, que contém a idade do veículo em anos.
A função deve devolver o preço de revenda do veículo.

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
