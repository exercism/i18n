# Anexo às instruções

## Sugestões

Para completares este exercício, tens de implementar a função `anagramsFor`,
que recebe uma *palavra* e um grupo de *palavras* e devolve as que são
anagramas da *palavra* dada.

Tens de devolver os anagramas pela mesma ordem em que aparecem na lista de
palavras candidatas.


Se é a primeira vez que resolves este exercício, recomenda-se que te cinjas à
assinatura fornecida:

```haskell
anagramsFor :: String -> [String] -> [String]
```

Mais tarde, pode ser boa ideia revisitar este problema e explorar outros tipos
de dados e bibliotecas:

- `Text`, do pacote *text*.
- `Sequence` e `Set`, do pacote *containers*.
- `MultiSet`, do pacote *multiset*

A suite de testes foi deliberadamente concebida para aceitar quase qualquer
assinatura de tipo que faça sentido, por isso encorajamos-te a encontrar a que
achares melhor.
