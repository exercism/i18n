# Instalar o Swift

O Swift está disponível em macOS, Linux e Windows.
O processo de instalação varia consoante o sistema operativo que estás a usar.
É importante notar que, quanto ao suporte de Linux, o Swift só é suportado (oficialmente) nas seguintes distribuições:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

Se estiveres a usar uma distribuição de Linux diferente, terás de encontrar uma forma de instalar o Swift por tua conta.

## Xcode (macOS)

O Swift vem incluído no Xcode, o IDE da Apple para desenvolvimento em macOS e iOS.
Para o percurso de Swift do Exercism, vais precisar de ter o Xcode 16.0 ou superior instalado.
O Xcode está disponível gratuitamente na [Mac App Store][xcode].
Existem versões adicionais do Xcode (incluindo a beta mais recente) no [centro de programadores da Apple][apple-developer-center].

## macOS e Linux

Para macOS e Linux, existe um gestor de instalação do Swift chamado [swiftly][swiftly].
É uma ferramenta de linha de comandos que te permite instalar e gerir várias versões do Swift no teu sistema.
O comando para instalar o swiftly no macOS encontra-se [aqui][swiftly-macos], e [aqui][swiftly-linux] para Linux.

Outro método de instalação para macOS é o [Homebrew][homebrew].
Para Linux, podes instalar a partir do tarball do [site oficial do Swift][tarball].

## Windows

A forma recomendada de instalar o Swift no Windows é usar o [instalador WinGet][winget-windows].
Também é possível instalar o Swift com o gestor de pacotes Scoop ou fazer uma instalação manual.
Para todas as opções, consulta a página [Instalar o Swift para Windows][swift-windows].
