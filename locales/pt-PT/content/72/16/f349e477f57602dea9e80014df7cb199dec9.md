# Instalação

## Opções de instalação

A versão atual do Unison está disponível para Mac OS X, Linux de 64 bits e Windows! Esperamos que, se estiveres a experimentar o Unison, venhas falar connosco no fórum do Exercism ou no [Discord do Unison](https://unison-lang.org/discord). Vem fazer perguntas e reportar os problemas com que te depares! Queremos que tenhas uma experiência acolhedora e positiva quando estiveres a começar! 😊

O Unison pode ser descarregado com o [homebrew](https://brew.sh/), o [Nix](https://github.com/ceedubs/unison-nix/#usage) ou diretamente através de binários empacotados. Todas estas opções de download estão descritas na [página de instruções de instalação do nosso site](https://www.unison-lang.org/learn/quickstart/#installation-options). Assim que tiveres o UCM instalado, volta aqui!

### Opção 1: usar o Homebrew

Primeiro, [instala o homebrew](https://brew.sh/) se ainda não o tens.

Depois, na linha de comandos, introduz estes comandos:

```
brew tap unisonweb/unison
brew install unison-language
```

Isto vai instalar o executável do gestor de bases de código do Unison, o `ucm`. Se estiveres a atualizar de uma versão anterior, basta fazer

```
brew upgrade unison-language.
```

Nota: se te for pedido um nome de utilizador e uma palavra-passe do GitHub nesta altura, certifica-te de que escreveste unisonweb/unison corretamente.

### Opção 2: instalação manual para utilizadores de Mac e Linux

[As ligações para instalação manual em Linux e Mac estão aqui](https://www.unison-lang.org/learn/quickstart/#installation-options), na respetiva secção de download manual de Linux e Mac.

Vais correr um comando na tua shell parecido com este, mas a ligação acima tem o binário mais atualizado:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### Opção 3: instalação manual para utilizadores de Windows

1. Define a tua aplicação de terminal predefinida como “Windows Terminal” para obteres os melhores resultados. Procura por “Terminal” nas Settings, ou segue [este guia.](https://bit.ly/3IXwdlY)
2. Se não tiveres a certeza de que já o tens, instala o Git:
  * Através do winget: `winget install --id Git.Git -e --source winget`
  * Se estiveres no Windows 10 e não tiveres o winget, podes instalá-lo a partir da [Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1) e depois correr o comando acima.
3. [Descarrega o UCM com a ligação fornecida aqui](https://www.unison-lang.org/learn/quickstart/#installation-options) e extrai-o para o local que quiseres.
4. Corre o `ucm.exe`

### Opção 4: instalação com o Nix
Vai a [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) e segue as instruções do readme que lá estão.

## Cria a tua base de código do Unison

Corre o `ucm` para inicializar uma base de código do Unison em `$HOME/.unison`. É aqui que o Unison vai guardar as definições de funções, os tipos, os namespaces, e assim por diante. Por predefinição, o Gestor de Bases de Código do Unison (abreviado “UCM”) começa a descarregar a biblioteca padrão, chamada `base`, que vais usar para escrever código Unison. Pode demorar um pouco! 🕰

## Fluxo de trabalho do Unison

Quando quiseres escrever código Unison, usas o comando `ucm` para iniciar o gestor de bases de código. O UCM vai então observar as alterações a qualquer ficheiro com a extensão `.u` na pasta a partir da qual é chamado. Por exemplo, podes estar a implementar funções num ficheiro chamado `scratch.u`, numa pasta chamada `~/exercism/unison/my-exercise/`. Deves fazer `cd` para `~/exercism/unison/my-exercise/` e correr o `ucm`. Assim garantes que o UCM está a vigiar as alterações ao teu ficheiro `scratch.u`.

Se alguma vez ficares confuso sobre em que pasta o `ucm` está a vigiar alterações a ficheiros, essa informação aparece no ecrã de boas-vindas quando inicias o CLI.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[Vê mais dicas de fluxo de trabalho aqui!](https://exercism.org/docs/tracks/unison/workflow)

## Suporte para editores

Podes usar qualquer editor de texto para escrever os teus ficheiros `.u`. O Unison tem [suporte para LSP](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown), por isso o teu IDE preferido pode ajudar-te com coisas como ver os tipos ao passar o rato e o preenchimento automático. Abaixo estão listados alguns editores populares com suporte para Unison:

### Vim

Com o [vim-plug](https://github.com/junegunn/vim-plug):

1. Instala o [`vim-plug`](https://github.com/junegunn/vim-plug) se ainda não o tens.
2. Acrescenta o seguinte ao teu .vimrc: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. Executa o comando do vim `:PlugInstall`.

Para mais informações, corre `:help unison`
dentro do vim ou consulta a [documentação de ajuda online](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt).

### Atom
Na consola, corre:

```
apm install unisonweb/atom-unison
```

### VS Code

1. Abre a vista de Extensions clicando no ícone de Extensions na Activity Bar, ao lado do VS Code, ou com ⇧⌘X.
2. Procura por "unison"
3. Instala a [extensão do Unison para o VS Code](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)

### Emacs
Instala o [`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs).
