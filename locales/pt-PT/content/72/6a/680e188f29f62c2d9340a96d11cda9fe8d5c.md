# Executar os testes

Para executar os testes de um exercício, executa o script `<exercise>.test` no diretório do exercício:

```bash
tclsh <exercise>.test
```

Na maioria dos exercícios, todos os testes exceto o primeiro serão "skipped".
Isto permite-te, enquanto programador, praticar desenvolvimento orientado por testes: programando apenas o suficiente para passar cada teste, um a um.
Para anular os comandos de skip, define a variável de ambiente `RUN_ALL` com um valor verdadeiro válido do Tcl \[1\] antes de executar o conjunto de testes:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Os valores true/false do Tcl estão documentados na página de manual da função da biblioteca C [Tcl_GetBoolean][bool].

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
