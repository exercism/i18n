# Instruções

Vais escrever algum código para gerir um inventário de itens numa loja.
O inventário será uma referência para um hash que contém os itens do inventário e a quantidade de cada um.

## 1. Cria um novo inventário a partir dos itens

Modifica a sub-rotina `InventoryManagement::create_inventory`, que recebe uma referência para um array de itens como argumento, para devolver uma referência para um hash de inventário recém-criado, com os nomes dos itens como chaves e a quantidade como valores.

## 2. Adiciona os itens ao inventário

Modifica a sub-rotina `InventoryManagement::add_items`, que recebe uma referência para um hash de inventário e uma referência para um array de itens como argumentos, para devolver uma referência para um hash com os itens adicionados ao inventário.

## 3. Remove os itens do inventário

Modifica a sub-rotina `InventoryManagement::remove_items`, que recebe uma referência para um hash de inventário e uma referência para um array de itens como argumentos, para devolver uma referência para um hash com os itens removidos do inventário.
As quantidades dos itens não devem ficar abaixo de zero.

## 4. Elimina o item do inventário por completo

Modifica a sub-rotina `InventoryManagement::delete_item`, que recebe uma referência para um hash de inventário e um nome de item como argumentos, para devolver uma referência para um hash com o item eliminado do inventário por completo.
