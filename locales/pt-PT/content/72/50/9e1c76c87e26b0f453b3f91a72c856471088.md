# Acréscimo às instruções

## Nota

Podes achar os dicionários do Pharo úteis para completar este exercício.
O Pharo tem várias formas de construir dicionários, incluindo `Dictionary new: at:put:` e uma sintaxe literal que usa `Association`s.
Uma `Association` tem a forma `key -> value` e podes transformá-la num dicionário assim: `{ 'key' -> 'value' } asDictionary`.
Lembra-te que no Smalltalk, todos os operadores infixos são associativos à direita e que podes explorar ao vivo qualquer uma das classes mencionadas acima.
