# Testes

Para testar a tua solução, basta executar:

```bash
make test
```

Isto executa o ficheiro de testes `<exercise-name>-test.ys`, que contém todos os
testes que precisas de passar para a tua solução estar correta.
Deves estudar o ficheiro de testes para perceberes exatamente o que a tua solução
tem de fazer.

> Nota: da primeira vez que executas `make test`, também é garantido que a versão
> correta do intérprete `ys` de YAMLScript fica instalada no sítio certo.

Se executares `make test` antes de alterares algum ficheiro, todos os testes falham.
Este é o comportamento correto e esperado.
O processo normal de desenvolvimento do exercício é melhores a tua solução
iterativamente, executando `make test` depois de cada alteração, até todos os
testes passarem.

Se quiseres executar apenas um teste específico (enquanto te concentras nessa parte
da solução), podes adicionar este par chave/valor a esse teste:

```yaml
  ONLY: true
```

Se quiseres ignorar testes específicos (enquanto trabalhas noutras partes da
solução), podes adicionar este par chave/valor a esses testes:

```yaml
  SKIP: true
```


## Pré-requisitos para testar

De momento, o YAMLScript corre no MacOS e no Linux.

O teu computador tem de ter instalados os seguintes comandos muito comuns:

* `bash` - Podes executar os testes em qualquer shell, mas o `bash` tem de estar disponível.
* `make` - Tens de usar o GNU `make` para executar os testes.
  Em alguns ambientes, pode ter um nome diferente de `make`.
  Possivelmente `gmake`.
* `prove` - Este programa faz parte de qualquer instalação normal do Perl.
* `curl` - Serve para instalar o ys, caso ainda não esteja instalado.

É muito provável que já tenhas todos estes programas instalados.
