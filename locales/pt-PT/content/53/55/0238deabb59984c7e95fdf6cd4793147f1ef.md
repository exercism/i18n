# Módulo

As comparações com o módulo são perfeitamente válidas em Crystal, mas há uma forma mais legível de comparar o resto de uma divisão: o método [`divisible_by?`][divisible_by].
Ou, melhor ainda, se quiseres verificar se um número é ímpar ou par, usa os métodos [`odd?`][odd?] e [`even?`][even?].

Por exemplo:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```
