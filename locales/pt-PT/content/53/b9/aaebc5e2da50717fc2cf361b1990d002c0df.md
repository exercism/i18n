# Instalação

## Instalar o .NET 10

A track de Visual Basic usa o .NET 10.
Para compilar e testar os exercícios localmente, instala [o SDK do .NET 10 para o teu sistema operativo][install-sdk]:
Instala o SDK, não apenas o runtime.

## Verifica a tua instalação

Abre um novo terminal e executa:

```bash
dotnet --version
```

O comando deve mostrar `10.0.0` ou uma versão posterior.

## Suporte de editores

O SDK do .NET e um editor de texto simples são tudo o que precisas para completar os exercícios.
Para funcionalidades mais avançadas, como o preenchimento automático de código e a depuração, considera um destes editores:

- [Visual Studio 2026][visual-studio] no Windows
- [Visual Studio Code][visual-studio-code] no Windows, Linux ou macOS
- [JetBrains Rider][rider] no Windows, Linux ou macOS

[rider]: https://www.jetbrains.com/rider/
