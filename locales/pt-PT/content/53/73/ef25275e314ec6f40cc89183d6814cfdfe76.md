# Sobre

Ao percorrer uma sequência, às vezes o elemento sozinho não chega: também precisas da posição. As palavras de iteração *indexada* do Factor dão à quotation de cada elemento as duas coisas, com o índice no topo da pilha. `times` é a palavra relacionada para iteração contada, sem uma sequência subjacente.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| palavra      | efeito                                                                |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )` (mas vê mais abaixo)                         |

Uma subtileza do `times`: embora a sua quotation esteja documentada como `( -- )`, a palavra é `inline`, por isso uma quotation com efeitos equilibrados, como `( str -- str )`, funciona bem e encadeia a pilha ao longo das iterações. Isso dá-te um acumulador contado sem qualquer estado mutável:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

O mesmo truque funciona para `each-index` e `map-index`: o efeito declarado por elemento é um *mínimo*, não um máximo.
