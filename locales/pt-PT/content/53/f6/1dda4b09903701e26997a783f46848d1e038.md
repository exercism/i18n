# Testes

Para correres os testes, executa o comando `sbt test` no diretório do exercício.
Consulta a [página de testes](https://exercism.org/docs/tracks/scala/tests) para mais informações.

## Testes ignorados

Inicialmente, só o primeiro teste estará ativo.
Isto serve para te incentivar a resolver o exercício passo a passo.
Assim que o primeiro teste passar, remove a palavra-chave `pending` do início do teste seguinte e trabalha para que esse teste também passe.
