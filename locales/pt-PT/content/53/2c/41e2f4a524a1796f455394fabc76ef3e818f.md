# Strings

Uma string é uma cadeia de carateres, rodeada por aspas.
Tanto as aspas simples como as aspas duplas são suportadas.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Expansão de variáveis em strings

Nas strings com aspas duplas, se uma variável for referenciada enquanto está no âmbito, o valor é inserido na string.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Suporte de codificação de carateres

Historicamente, as funções de string em PHP só suportavam carateres ASCII e não suportavam as codificações Unicode modernas.
Os carateres ASCII ocupam 1 byte cada, ao passo que os carateres Unicode podem ter 1 a 4 bytes.
Se precisares de manipular strings Unicode com segurança, consulta as [versões multibyte][multi-byte-fns] das funções históricas.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
