# Instalação

## Instalar a Clojure CLI

O Clojure disponibiliza ferramentas de linha de comandos para: executar um REPL interativo (ciclo Ler-Avaliar-Imprimir), executar programas Clojure e avaliar expressões Clojure.
Aconselhamos-te a usar a Clojure CLI nos exercícios. Para instalar a [Clojure CLI](https://clojure.org/guides/deps_and_cli):

### Windows
Para instruções de instalação no Windows, consulta: [Instalação da Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_windows).

### Linux
Para instruções de instalação na maioria das plataformas, consulta: [Instalação da Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_linux).

### Homebrew para Mac OS X
Atualiza o teu Homebrew:

``` bash
$ brew update
```

Instala a Clojure CLI:
``` bash
$ brew install node clojure/tools/clojure
```

O `Node` é necessário para o ambiente node.

## Testar a instalação

Para testar se a instalação está correta, corre `clojure --help`; se tudo tiver corrido bem, mostra-te a versão.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
