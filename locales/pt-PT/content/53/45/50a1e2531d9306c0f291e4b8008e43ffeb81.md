# Anexo às instruções

## Registos

| Registo | Utilização       | Tipo     | Descrição                               |
| ------- | ---------------- | -------- | --------------------------------------- |
| `$a0`   | de entrada       | inteiro  | número natural a fatorizar              |
| `$a1`   | de entrada/saída | endereço | array de destino para os fatores primos |
| `$v0`   | de saída         | inteiro  | número de fatores                       |
| `$t0-9` | temporário       | qualquer | utilizado para armazenamento temporário |
