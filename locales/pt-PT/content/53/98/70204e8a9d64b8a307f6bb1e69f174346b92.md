# Sobre

Podes usar [tipos de enumeração][enumeration types] sempre que tens um conjunto fixo de valores constantes. Usar um `enum` dá-te uma forma segura do ponto de vista de tipos de interagir com valores constantes. Definir um enum faz-se com a palavra-chave `enum`. Para nos referirmos a um membro do enum, escrevemos antes dele o nome do enum e um ponto (por exemplo, `Status.Active`).

Cada membro do enum é uma associação entre um nome e um valor `int`. Se o primeiro membro não tiver um valor explícito, o seu valor é definido como `0`. Se não for definido explicitamente um valor para um membro do enum, o seu valor é automaticamente definido como o valor do membro anterior mais `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

Os enums são muito declarativos. Compara as duas chamadas de método seguintes:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

Para quem lê o código, a segunda versão (com enum) é mais fácil de compreender.

## Enums com tipo numérico

Embora o tipo numérico predefinido dos valores seja `int`, podes alterá-lo especificando explicitamente qualquer outro tipo [numérico integral][integral numeric].

O enum seguinte usa o tipo numérico `byte` para os seus valores:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## Converter para um membro de enum

Deves sempre considerar usar um enum sempre que quiseres modelar algo semelhante a um Boolean. Além dos benefícios de legibilidade já mencionados, os enums têm outra vantagem sobre o Boolean: podem sempre acrescentar-se novos valores a um enum, ao passo que um valor Boolean nunca será mais do que `true` ou `false`. Usar um enum é, por isso, mais à prova de futuro.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Repara que, embora _possas_ converter valores inteiros para um enum, isso pode dar resultados inesperados quando o valor inteiro não corresponde a nenhum valor do enum:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Fazer parse de um enum

Por vezes é útil converter uma string num membro de enum com base no seu nome, com [`Enum.Parse`][enum parse]:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Para verificar se um nome ou um valor existe no enum, podes usar [`Enum.TryParse`][enum tryparse] ou [`Enum.IsDefined`][enum isdefined]; ambos devolvem um Boolean que indica se o membro do enum existe:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
