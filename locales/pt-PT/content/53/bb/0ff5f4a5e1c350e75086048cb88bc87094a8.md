# Introdução

## Variáveis e atribuição

R é uma linguagem de tipagem dinâmica, por isso, em geral, não é necessário especificar o tipo de uma variável. O operador de atribuição preferido é `<-` 

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

Usar `=` em vez de `<-` funciona muitas vezes, mas nem sempre, e é desaconselhado por ser um mau estilo.
Se estiveres a trabalhar no RStudio, podes inseri-lo com o atalho de teclado `Alt-minus`.

Os operadores são, na sua maioria, convencionais, mas repara em `%/%` e `%%`:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

Em R, `#` inicia um comentário de uma linha.
Não existe uma sintaxe separada para comentários de várias linhas.

## Funções

Para definir uma função:

```R
squareit <- function(x) {
    x * x
}
```

As funções podem ter zero ou mais argumentos, separados por vírgulas.
Os parênteses `()` são necessários com `function()`, mesmo que não haja parâmetros.

Podem especificar-se valores predefinidos para os argumentos de uma função, embora tenham de vir depois de todos os argumentos sem valor predefinido, e usa `=` e não `<-` para atribuir o valor predefinido.
Como exemplo bastante inútil:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

As chavetas `{ }` não são estritamente necessárias para corpos de função com uma única linha, mas incluí-las é considerado um bom estilo.

O R devolve automaticamente o valor final de uma função, como nos exemplos acima.

`return()` pode ser usado em qualquer parte do corpo da função para tornar um valor devolvido explícito.

Chamar uma função funciona da mesma forma que em muitas outras linguagens:

```R
squareit(3)
#> [1] 9
```
