# Instruções

A Heidi, uma jovem alienígena de Forth, precisa de adiantar trabalho no seu projeto de alfabetos humanos e pergunta-te se a podes ajudar a programar algumas palavras de que vai precisar.

## 1. Comparar dois carateres

Define `compare-chars` para receber dois carateres e devolver o símbolo `less`, `greater` ou `equal`, conforme o primeiro seja menor que, maior que ou igual ao segundo. A comparação distingue maiúsculas de minúsculas.

```factor
CHAR: A CHAR: B compare-chars .   ! => less
CHAR: B CHAR: A compare-chars .   ! => greater
CHAR: A CHAR: A compare-chars .   ! => equal
CHAR: A CHAR: a compare-chars .   ! => less
```

## 2. Determinar o tamanho de um caráter

A Heidi precisa de saber se um caráter é "big" (maiúsculo), "small" (minúsculo) ou se não tem tamanho. Define `size-of-char` para devolver `big`, `small` ou `no-size`.

```factor
CHAR: A size-of-char .       ! => big
CHAR: a size-of-char .       ! => small
CHAR: 5 size-of-char .       ! => no-size
CHAR: space size-of-char .   ! => no-size
```

## 3. Alterar o tamanho de um caráter

Por vezes, a Heidi precisa de mudar um caráter para um tamanho diferente. Define `change-size-of-char` para receber um caráter e um tamanho pretendido (`big` ou `small`) e devolver o caráter com a caixa correspondente.

```factor
CHAR: a big change-size-of-char .     ! => 65   (CHAR: A)
CHAR: A small change-size-of-char .   ! => 97   (CHAR: a)
```

## 4. Determinar o tipo de um caráter

A Heidi também precisa de saber que *tipo* de caráter é. Define `type-of-char` para devolver:

- `alpha` para qualquer letra (maiúscula ou minúscula)
- `numeric` para um algarismo decimal
- `space` para o caráter de espaço
- `newline` para o caráter de nova linha
- `unknown` caso contrário

```factor
CHAR: A type-of-char .       ! => alpha
CHAR: 5 type-of-char .       ! => numeric
CHAR: space type-of-char .   ! => space
CHAR: \n type-of-char .      ! => newline
CHAR: ! type-of-char .       ! => unknown
```
