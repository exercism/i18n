# Testes

Para correres os testes deste percurso, tens de instalar o DUnitX. Consulta as instruções de [instalação](http://www.exercism.org/docs/tracks/delphi/installation) para mais informações.

### Carregar exercícios no Delphi

Se o Delphi estiver instalado corretamente e os ficheiros `*.dpr` estiverem associados ao Delphi, basta fazeres duplo clique no ficheiro `*.dpr` fornecido para o Delphi arrancar e carregar o exercício/projeto.

O atalho de teclado `control + F9` compila o projeto; em alternativa, podes premir `F9` para compilar e executar o projeto.

Também podes optar por iniciar o Delphi e carregar o teu projeto através do menu pendente `File`.
