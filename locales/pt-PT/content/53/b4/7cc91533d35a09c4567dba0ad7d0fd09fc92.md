# Intervalos

Os [intervalos][range] representam um intervalo entre dois valores.
Os tipos mais comuns que suportam intervalos são `Integer` e `String`.
Podem ser usados para muitas coisas, como criar rapidamente uma coleção, cortar strings, verificar se um valor está num intervalo e iterar.
São criados com o operador de intervalo `..` ou `...` (inclusivo e exclusivo, respetivamente).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

A razão para existirem dois operadores de intervalo é permitir criar intervalos que incluem ou excluem o valor final, o que pode ser útil, por exemplo, quando trabalhas com índices baseados em zero.

Também podes criar intervalos com o inicializador `Range`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Quando crias um intervalo em Ruby com os operadores `..` ou `...` e queres chamar um método ao intervalo, tens de envolver o intervalo em parênteses.
Caso contrário, o método é chamado sobre o segundo argumento do operador de intervalo.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Obter substrings

Quando queres cortar uma string, podes usar o operador de intervalo para obter uma substring.
Ou seja, crias um intervalo com o índice inicial e final da substring.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Também podes usar índices negativos para obter a substring a partir do fim da string.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Métodos de intervalo

Os intervalos têm um conjunto de métodos que podes usar para trabalhar com eles.
Por exemplo, estes métodos permitem obter a soma de todos os valores do intervalo ou verificar se o intervalo inclui um valor.

| Método                  | Descrição                                                             | Exemplo                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Devolve a soma de todos os valores do intervalo                          | `(1..5).sum # => 15`            |
| [`size`][size]          | Devolve o tamanho do intervalo                                           | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Devolve `true` se o intervalo incluir o valor dado, caso contrário `false` | `(1..5).include?(3) # => true` |

## Intervalos sem fim e sem início

Um intervalo pode ser sem fim e sem início.
O intervalo sem fim ou sem início tem o valor inicial ou final igual a `nil`, mas ao definir o intervalo podes omitir o `nil`.

Usar intervalos sem início e sem fim é útil quando queres, por exemplo, cortar uma string desde o início ou até ao fim.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Se não for usado numa coleção, o intervalo sem fim pode provocar uma sequência sem fim, caso não seja usado com cuidado.
~~~~

## Intervalos de strings

Também podes usar strings em intervalos, o que te permite obter todas as strings entre duas strings.
O comportamento pode ser um pouco inesperado com certas strings, por isso usa-o com cuidado.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
