# Dicas

## Geral

- Em cada tarefa, cada função deve devolver uma closure, usando os argumentos fornecidos.

## 1. Translada as coordenadas

- Os argumentos fornecidos indicam a quantidade a transladar o par de coordenadas ao longo dos eixos _x_ e _y_.

## 2. Escala as coordenadas

- Os argumentos fornecidos indicam a quantidade a escalar o par de coordenadas nos eixos _x_ e _y_.

## 3. Compõe as funções de transformação

- O resultado da primeira transformação é um array, mas as funções de transformação recebem dois argumentos numéricos. Vais ter de obter os valores a partir do array.
- Lembra-te de que a ordem pela qual as funções são executadas é importante.

## 4. Guarda os resultados das funções

- Nesta função, só tens de memorizar o resultado da última transformação.
- Para devolver o resultado da última transformação, tens de verificar se os argumentos de entrada são os mesmos.
