# Adicionar um novo percurso

O primeiro passo de todos para adicionar um novo percurso de linguagem ao Exercism é:

- [Pedir um novo percurso de linguagem](/docs/building/tracks/new/request-new)

Depois de concluíres esse passo, os passos seguintes são:

- [Juntar-te à nossa comunidade](/docs/building/tracks/new/join-our-community)
- [Selecionar a variante da linguagem de programação](/docs/building/tracks/new/select-programming-language-variant) (se aplicável)
- [Selecionar o framework de testes](/docs/building/tracks/new/select-testing-framework)
- [Adicionar o primeiro exercício](/docs/building/tracks/new/add-first-exercise)
- [Configurar a integração contínua](/docs/building/tracks/new/setup-continuous-integration)
- [Adicionar os exercícios iniciais](/docs/building/tracks/new/add-initial-exercises)
- [Criar o executor de testes](/docs/building/tracks/new/build-test-runner)
- [Configurar as ferramentas](/docs/building/tracks/new/configure-tooling)
- [Preparar o lançamento](/docs/building/tracks/new/prepare-for-launch)
- [Testar o percurso](/docs/building/tracks/new/test-track)
- [Encontrar responsáveis pela manutenção](/docs/building/tracks/new/find-maintainers)
- [Lançar!](/docs/building/tracks/new/launch)
- [Ativar o realce de sintaxe](/docs/building/tracks/new/syntax-highlighting)
- [Implementar ferramentas adicionais](/docs/building/tracks/new/implement-tooling)
- [Preparar para contribuições de código aberto de desconhecidos](/docs/building/tracks/new/prepare-for-contributions)
