# Sobre

Quando modelas dados que só podem assumir um conjunto específico de estados possíveis, como os dias da semana, as direções da bússola ou os botões de um comando, os tipos básicos como `Int` ou `String` têm grandes desvantagens.
Com inteiros ou strings, o teu código tem de verificar constantemente se há valores inválidos (como um código de estado `999` ou uma gralha como `"leftt"`), e quem lê o código não consegue perceber facilmente o que os números representam.

O Swift resolve este problema com [*enumerações*][enumerations] (frequentemente abreviadas para *enums*).
Uma enumeração define um tipo comum para um grupo de valores relacionados e com nome. Como o compilador conhece de antemão todos os casos possíveis, consegue verificar a exatidão e a completude do teu código em tempo de compilação.
As enumerações também podem ter métodos, inicializadores e propriedades calculadas.

## Definir enumerações

Define uma enumeração com a palavra-chave `enum` seguida do nome do tipo, com os casos listados entre chavetas.
Por convenção do Swift, o nome do tipo usa `UpperCamelCase`, enquanto cada caso usa `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

Também podes definir vários casos numa única linha, separados por vírgulas:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Para te referires a um caso de uma enumeração, escreve o nome do tipo da enumeração, um ponto (`.`), e o nome do caso. Quando o tipo é conhecido ou pode ser inferido pelo compilador, podes omitir o nome do tipo e usar a sintaxe abreviada com ponto:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Enumerações e instruções `switch`

As enumerações funcionam perfeitamente com [instruções `switch`][enums-and-switches].
Como um `switch` em Swift tem de ser exaustivo, o compilador garante que tratas todos os casos possíveis:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Se te esqueceres de algum caso sem forneceres uma cláusula `default`, o compilador dá um erro:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Muitas vezes é preferível listar todos os casos explicitamente em vez de usares `default`. Assim, se adicionares um novo caso no futuro, o compilador avisa-te imediatamente para atualizares todas as instruções `switch` que tratam dessa enumeração.

## Métodos e inicializadores

As enumerações podem definir métodos e inicializadores personalizados tal como as classes e as estruturas. Dentro de um método de uma enumeração, `self` refere-se ao valor do caso atual:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Valores brutos

Os casos de uma enumeração podem ser pré-preenchidos com valores predefinidos chamados [*valores brutos*][raw-values].
Todos os valores brutos de uma enumeração têm de partilhar o mesmo tipo (como `Int`, `String` ou `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Podes inicializar uma enumeração a partir de um valor bruto com `init(rawValue:)`. Como pode ser fornecido um valor bruto inválido, este inicializador devolve um opcional:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

O Swift consegue atribuir automaticamente valores brutos a enumerações de `String` e `Int`:

- Nas enumerações de `String`, o valor bruto de cada caso é, por predefinição, o nome do caso.
- Nas enumerações de `Int`, os valores brutos começam em `0` e aumentam de 1 em 1, salvo indicação em contrário.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Valores associados

Os casos de uma enumeração também podem armazenar valores personalizados de tipos variados a par de cada caso, conhecidos como [*valores associados*][associated-values]:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Uma enumeração pode usar valores brutos ou valores associados, mas não ambos.

## Enumerações recursivas

Uma [enumeração recursiva][recursive-enumerations] é uma enumeração que tem outra instância da própria enumeração como valor associado de um ou mais casos.
Para ativar a recursão, marca o caso (ou a enumeração inteira) com a palavra-chave `indirect`:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
