# Introdução

Haskell tem um tipo, `Num`, que é o tipo base de todos os tipos numéricos.
Existem quatro subtipos principais dentro do tipo numérico: [`Int`][int], [`Integer`][integer], [`Double`][double] e [`Float`][float].

Em Haskell existem dois tipos de números inteiros.
`Int` é um inteiro de tamanho fixo, enquanto `Integer` é um inteiro de precisão arbitrária.

Um `Integer` guarda qualquer número, por maior que seja, até ao limite da memória da tua máquina, ao passo que um `Int` corresponde ao conjunto dos números inteiros positivos e negativos que se podem representar em 32 ou 64 bits (garantidamente, pelo menos, de -2^29 a 2^29 - 1).

Tem em atenção que, ao escreveres números negativos, deves usar parênteses para evitar ambiguidade.

```haskell
1

(-1)
```

Um `Float` corresponde ao conjunto dos números reais, limitado pela precisão do computador.
As operações definidas sobre números funcionam habitualmente com um tipo ou com o outro, mas não com ambos.
Um `Double` é um número de vírgula flutuante com precisão dupla.

```haskell
10.5
```

## Converter entre inteiros e números de vírgula flutuante

Com a função `toFloat`, podes converter um `Int` ou um `Integer` num `Float`.

```haskell
toFloat 1
-- -> 1.0
```

Existe também a função `fromIntegral`, que converte qualquer tipo numérico no tipo numérico que for inferido como necessário.

```haskell
fromIntegral 1
-- -> 1.0
```

Para converter um `Float` num `Int`, podes usar as funções [`round`][round], [`floor`][floor] ou [`ceiling`][ceiling].
A função `round` arredonda para o inteiro mais próximo, `floor` arredonda para baixo e `ceiling` arredonda para cima.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## Operadores aritméticos

Podes usar os [operadores aritméticos básicos][math] com os tipos numéricos.
Os operadores são `+`, `-`, `*`, `/` e `%`.
Ao usar estes operadores, os tipos dos números têm de coincidir.
A função `fromIntegral` faz a conversão para que os tipos coincidam.

### Adição, subtração e multiplicação

O operador `+` serve para a adição, o operador `-` para a subtração e o operador `*` para a multiplicação.

| Operador | Exemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Divisão

A divisão serve para dividir números.
O operador `/` é usado para a divisão.
O resultado é sempre um número de vírgula flutuante.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
Nalgumas linguagens de programação, ao dividir por zero, o resultado é um erro.

Em Haskell, ao dividir por zero, o resultado é `Infinity` ou `-Infinity`.
A única exceção é dividir zero por zero, que dá `NaN` (Not a Number).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## Divisão inteira

A divisão inteira serve para dividir números inteiros e obter a parte inteira do resultado.
Haskell tem duas funções de divisão inteira, que diferem na forma como arredondam quando o resultado é negativo:

- `div` arredonda para baixo, em direção ao infinito negativo.
- `quot` arredonda em direção ao zero.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Dividir por zero na divisão inteira resulta numa exceção.
Isto é diferente da divisão normal.
~~~~

### Resto

O resto de uma divisão inteira pode ser obtido com `mod` ou `rem`.
Diferem no sinal do resultado quando um dos números é negativo:

- `mod` anda de par com `div`, e o seu resultado tem o mesmo sinal que o divisor.
- `rem` anda de par com `quot`, e o seu resultado tem o mesmo sinal que o dividendo.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Para quaisquer `x` e `y` (com `y` diferente de zero), verificam-se estas leis:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Quando ambos os números são positivos, `div` e `quot` dão o mesmo resultado, tal como `mod` e `rem`.
Nesse caso, `quot` e `rem` podem ser ligeiramente mais eficientes, porque `div` e `mod` precisam de passos extra para lidar com números negativos.
~~~~

~~~~exercism/caution
Dividir por zero com `mod` ou `rem` resulta numa exceção.
Isto é diferente da divisão normal.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## Exponenciação

Haskell tem três operadores de «elevar à potência», que funcionam de forma diferente e recebem tipos de argumentos diferentes.

- `**` recebe dois **números de vírgula flutuante** e usa logaritmos para calcular a potência.
- `^^` recebe um **número de vírgula flutuante** e eleva-o a uma potência **inteira** positiva ou negativa.
- `^` recebe **qualquer tipo numérico** e eleva-o a uma potência **inteira** positiva.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## Prioridade e parênteses

Haskell permite usar parênteses (`()`), que podem agrupar expressões.
Isto é útil quando queres alterar a ordem das operações.

Ao usar vários operadores aritméticos, a ordem das operações é a mesma que na matemática, também conhecida como [PEMDAS][pemdas].
Segue a ordem dos parênteses (`()`), dos expoentes (`**`), da multiplicação (`*`) e da divisão (`/`), e da adição (`+`) e da subtração (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
