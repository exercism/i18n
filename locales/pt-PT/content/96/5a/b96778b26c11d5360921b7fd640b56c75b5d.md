# Instruções

O contramestre faz todos os dias um briefing de vigia no convés: uma saudação fixa, uma chamada dos tripulantes em serviço e, no fim, uma ordem de dispensa. Vais decompor o briefing em pequenas linhas com nome e compô-las depois.

Neste exercício vais editar **dois ficheiros**:

- `bosuns-briefing/helpers/helpers.factor`, com pequenos auxiliares reutilizáveis. Vocabulário: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`, o ficheiro principal que compõe os auxiliares. Vocabulário: `bosuns-briefing`.

## 1. Saudação

Em `helpers.factor`, define `greeting` de modo a devolver a string fixa de abertura `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Linha da tripulação

Em `helpers.factor`, define `crew-line` de modo a receber uma string com um nome e a devolver esse nome precedido de `"  - "` (dois espaços, um hífen e um espaço).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Dispensa

Em `helpers.factor`, define `closing` de modo a devolver a string fixa de dispensa `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. Lista da tripulação

Em `bosuns-briefing.factor`, define `roster` de modo a receber um array de nomes de tripulantes e a devolver uma única string com várias linhas, em que cada nome é formatado por `crew-line` e as linhas são unidas por mudanças de linha.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Briefing

Em `bosuns-briefing.factor`, define `briefing` de modo a receber um array de nomes de tripulantes e a devolver o briefing completo como uma única string: a saudação na primeira linha, a lista da tripulação nas linhas seguintes e a dispensa na última linha. Usa os auxiliares e o `roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
