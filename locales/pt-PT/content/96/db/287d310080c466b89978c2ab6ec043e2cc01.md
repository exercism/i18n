# Dicas

## Geral

- Um [valor inteiro][integers] pode ser definido como um ou mais algarismos consecutivos.
- Um [valor do tipo map][maps] guarda dados de chave-valor

## 1. Dado um tabuleiro de xadrez e uma coluna, conta quantas casas estão ocupadas

- Podes percorrer um [map][maps]
- Verifica se o valor é verdadeiro.
  Se for, incrementa.
  Isto serve para contar as peças.
- Tens de [devolver explicitamente um número inteiro][return] de uma função.

## 2. Dado um tabuleiro de xadrez e uma fila, conta quantas casas estão ocupadas

- Primeiro, tens de verificar se a fila está dentro dos limites.
- Percorre o tabuleiro.
- Soma um se a casa estiver ocupada.

## 3. Conta quantas casas existem no tabuleiro de xadrez dado

- Há muitas formas de resolver isto.
- Isto deve devolver quantas casas estão configuradas no tabuleiro de xadrez.

## 4. Conta quantas casas estão ocupadas no tabuleiro de xadrez dado
