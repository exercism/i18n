# Apêndice às instruções

## Sobre a ability Stream

Uma `Stream` é uma ability do Unison que serve para emitir valores.

Podes usar a ability `Stream` se tiveres uma função que deve produzir valores como efeito secundário enquanto está a ser chamada. Por exemplo, esta função devolve o último valor da lista, mas emite um total acumulado à medida que cada elemento é visto:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

Podemos materializar a Stream como uma List, a par do valor devolvido da função que a produz, com um handler de abilities:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
