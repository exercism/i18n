# Introdução

O tipo `Result` é a solução da linguagem Elm para reportar erros e um facilitador da recuperação de erros. É um pouco semelhante ao tipo `Maybe`, mas, embora o `Maybe` possa ser devolvido por funções que podem falhar, não te diz nada sobre o motivo da falha. O `Result` inclui esse contexto sobre o motivo pelo qual algo falhou.

O tipo `Result` é definido da seguinte forma:

```elm
type Result error value
  = Ok value
  | Err error
```

Esta é conhecida como uma definição de "tipo personalizado" na terminologia de Elm.
O `error` e o `value` em `OK value` e `Error error` representam uma variável de tipo, o que significa que pode ser qualquer tipo, como `Int`, `Bool` ou `String`.
Assim, um `Result String Int` é uma variável que se espera que contenha um `Int`, e, se houver um erro, este será representado como uma `String`.
Existe um [módulo Result](https://package.elm-lang.org/packages/elm/core/latest/Result) com muitas funções auxiliares úteis para trabalhar com resultados.
