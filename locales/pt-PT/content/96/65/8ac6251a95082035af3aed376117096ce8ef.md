# Instruções

Neste exercício, vais escrever algum código para te ajudar a preparar-te para comprar um veículo.

Tens três tarefas: uma para determinar se precisas de carta de condução, outra para te ajudar a escolher entre dois veículos e outra para estimar o preço aceitável de um veículo usado.

## 1. Determinar se vais precisar de carta de condução

Alguns tipos de veículos exigem carta de condução para serem conduzidos.
Assume que apenas os tipos `"car"` e `"truck"` exigem carta; todos os outros podem ser conduzidos sem carta.

Implementa a função `NeedsLicense(kind)`, que recebe o tipo de veículo e devolve um Boolean que indica se precisas de carta para esse tipo de veículo.

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. Escolher entre dois veículos potenciais para comprar

Avalias as tuas opções de veículos disponíveis.
Consegues reduzi-las a duas opções, mas precisas de ajuda para tomar a decisão final.
Para isso, implementa a função `ChooseVehicle(option1, option2)`, que recebe dois veículos como argumentos e devolve uma decisão que inclui a opção que vem primeiro por ordem lexicográfica.

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcular uma estimativa para o preço de um veículo usado

Agora que tomaste uma decisão, queres garantir que consegues um preço justo no stand.
Como estás interessado em comprar um veículo usado, o preço depende da idade do veículo.
Para uma estimativa aproximada, assume que, se o veículo tiver menos de 3 anos, custa 80% do preço original que tinha quando era novo.
Se tiver pelo menos 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos mas menos de 10 anos, custa 70% do preço original.

Implementa a função `CalculateResellPrice(originalPrice, age)`, que aplica esta lógica usando `if`, `else if` e `else` (há outras formas, se quiseres praticar).
Recebe o preço original e a idade do veículo como argumentos e devolve o preço estimado no stand.

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**Nota** que o valor devolvido é um `float64`.
