# Dicas

## Geral

- Os arrays em Swift usam índices a começar em zero. O primeiro índice de um array é `0`.

## 1. Obtém uma carta de um monte

- Para obteres o item de posição `n` de um slice, [usa um subscript][array-access].
- Um array começa sempre no índice `0`

## 2. Troca uma carta do monte

- Para definires o item de posição `n` de um array, [usa um subscript][array-access] e atribui-lhe um novo valor.
- Um array começa sempre no índice `0`

## 3. Insere uma carta no topo do monte

- Existe um [método de array][array-append-docs] para adicionar um novo valor ao fim do array.

## 4. Remove uma carta do monte

- Existe um [método de array][array-removeat-docs] que pode ser usado para remover elementos num índice específico.

## 5. Remove a carta do topo do monte

- Existe um [método de array][array-removelast-docs] para remover o último elemento do array.

## 6. Insere uma carta na base do monte

- Existe um [método de array][array-insert-docs] para adicionar um novo valor num índice específico do array.
- Um array começa sempre no índice `0`

## 7. Remove uma carta da base do monte

- Existe um [método de array][array-removefirst-docs] para remover o primeiro elemento do array.

## 8. Verifica o tamanho do monte

- Os arrays têm uma [propriedade][array-count-docs] para obter o seu comprimento.

## 9. Conta o número de cartas pares no monte

- Podes percorrer os elementos de um array com um [ciclo for-in][for-in-loops].
- Os tipos inteiros em Swift têm o método [`isMultiple(of:)`][int-ismultiple-docs] para testar se são múltiplos de outro número inteiro.
