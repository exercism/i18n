# Ajuda

- [The Zig Programming Language Documentation][documentation] é uma excelente visão geral de todas as funcionalidades da linguagem que o Zig oferece a quem a utiliza.
- [Zig Guide][zig-guide] é uma introdução excelente que explica as funcionalidades que a linguagem Zig tem para oferecer.
- [Ziglings][ziglings] é altamente recomendado.
  Aprende Zig corrigindo pequenos programas com erros.
- [The Zig Programming Language Discord][discord-zig] é o principal [Discord][discord].
  É uma ótima forma de entrares em contacto com a comunidade Zig em geral e de obteres ajuda rápida e direta para qualquer problema relacionado com Zig.
- [#zig][irc] no irc.freenode.net é o principal canal IRC do Zig.
- [/r/Zig][reddit] é o principal subreddit do Zig.
- [Stack Overflow][stack-overflow] pode ser usado para descobrir trechos de código e soluções para problemas que já tenham sido colocados e talvez resolvidos por outras pessoas.
