# Anexo às instruções

## Dados mutáveis em Prolog

Por predefinição, os valores em Prolog são _imutáveis_, ou seja, nunca mudam (tens de introduzir uma nova variável para cada novo valor).
Embora isto seja ótimo para a grande maioria dos casos de utilização, este exercício _exige_ mesmo que os valores sejam alterados.
Para alterar dados em Prolog, podes usar o predicado [setarg].

[setarg]: https://www.swi-prolog.org/pldoc/doc_for?object=setarg/3
