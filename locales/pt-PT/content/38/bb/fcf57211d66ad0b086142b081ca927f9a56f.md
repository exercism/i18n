# Introdução

## Sobrecarga de métodos

Em Java, a sobrecarga de métodos é uma funcionalidade que permite que uma classe tenha mais do que um método com o mesmo nome, desde que as suas listas de parâmetros sejam diferentes.
Está relacionada com polimorfismo em tempo de compilação (ou estático).
Este conceito é crucial para criar métodos que realizam tarefas semelhantes, mas com parâmetros diferentes.

### Porquê sobrecarregar métodos?

A sobrecarga de métodos aumenta a legibilidade do programa.
Métodos diferentes podem receber o mesmo nome, mas com parâmetros diferentes.
Dependendo do número de parâmetros ou do tipo de parâmetros, é chamado o método correspondente.

### Como sobrecarregar métodos?

A chave para a sobrecarga de métodos é a assinatura do método.
Dois métodos são considerados diferentes se tiverem assinaturas diferentes.
Há duas formas de sobrecarregar um método:

1. **Número diferente de parâmetros**: Os métodos podem ter o mesmo nome, mas um número diferente de parâmetros.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Tipos diferentes de parâmetros**: Os métodos podem ter o mesmo nome e o mesmo número de parâmetros, mas com
   tipos diferentes.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### Pontos a reter

- Os métodos sobrecarregados têm de alterar a lista de argumentos.
- Os métodos sobrecarregados também podem alterar o tipo de retorno, mas alterar apenas o tipo de retorno não constitui sobrecarga de métodos.
- Os métodos podem ser sobrecarregados na mesma classe ou numa subclasse.

Neste conceito, vamos explorar vários exemplos e nuances da sobrecarga de métodos em Java.
