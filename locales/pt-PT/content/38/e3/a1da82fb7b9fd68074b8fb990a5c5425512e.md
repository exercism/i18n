# Dicas

## Geral

- Existem três [operadores Boolean][operators] para trabalhar com valores Boolean.
- Podes combinar vários operadores numa única expressão.

## 1. Verifica se é possível fazer um ataque rápido

- Os [operadores Boolean][operators] também podem ser aplicados a parâmetros Boolean.
- Ao contrário de muitas outras linguagens, a negação Boolean _não_ é feita com o operador `!`.

[operators]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/boolean-operators
