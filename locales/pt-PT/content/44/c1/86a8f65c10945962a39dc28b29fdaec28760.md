# Introdução

Os booleanos em Go são representados pelo tipo booleano predeclarado `bool`, cujos valores podem ser `true` ou `false`.
É um tipo definido.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go suporta três operadores lógicos que podem avaliar expressões até obter valores booleanos, devolvendo `true` ou `false`.

| Operador    | O que significa                                  |
| ----------- | ------------------------------------------------ |
| `&&` (and)  | É verdadeiro se ambas as afirmações forem verdadeiras. |
| `\|\|` (or) | É verdadeiro se pelo menos uma das afirmações for verdadeira. |
| `!` (not)   | É verdadeiro apenas se a afirmação for falsa.     |
