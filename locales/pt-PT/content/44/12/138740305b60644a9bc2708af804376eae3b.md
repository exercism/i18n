# Introdução

Para criar uma instância de uma classe, chamas o seu [_construtor_][constructor] através do operador `new`. Um construtor é um método especial dentro de uma classe cujo objetivo é inicializar a classe. No Haxe, o método construtor chama-se `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Tal como os métodos normais, os construtores podem ter parâmetros. Estes parâmetros são (normalmente) guardados em campos privados e acedidos mais tarde.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

**Não** podes criar uma nova instância de uma classe se não tiver um construtor. Assim, usar um construtor vazio é a única forma.

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
