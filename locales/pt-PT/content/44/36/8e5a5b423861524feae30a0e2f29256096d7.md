# Instruções

Neste exercício vais trabalhar num agendador de marcações para um salão de beleza em Nova Iorque que abriu a 15 de setembro de 2012.

Tens cinco tarefas, todas relacionadas com datas de marcações.
As horas estão em formato de 24 horas (sem AM/PM).
Para manter as questões de fuso horário o mais simples possível, assume que tudo usa UTC.

## 1. Interpretar uma data de marcação só com números

Implementa a função `schedule_appointment()` para interpretar uma representação textual de uma data de marcação para o formato `DateTime` correspondente.

Repara que o valor de entrada está na ordem mês/dia/ano, ao estilo dos Estados Unidos.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Verificar se uma marcação já passou

Implementa a função `has_passed()`, que recebe uma data de marcação e verifica se a marcação se situa algures no passado:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Verificar se a marcação é à tarde

Implementa a função `is_afternoon_appointment()`, que recebe uma data de marcação e verifica se a marcação é à tarde (>= 12:00 e < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Verificar o dia da semana de uma marcação

Implementa a função `day_of_week()`, que devolve o dia da semana _numérico_.
O salão está fechado aos domingos, por isso segunda-feira é o dia 1 e sábado é o dia 6.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. Reagendar uma marcação

Quando um cliente precisa de reagendar uma marcação, esta é automaticamente marcada para a sexta-feira seguinte, à mesma hora do dia (por ser o dia mais calmo da semana).

Implementa a função `reschedule()`, que recebe a marcação original (como string de texto na ordem mês/dia/ano) e devolve uma marcação reagendada.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

Se a marcação original era de segunda a quinta-feira, reagenda para a sexta-feira _desta_ semana.
Para marcações de sexta-feira ou sábado, reagenda para a sexta-feira da semana _seguinte_.
