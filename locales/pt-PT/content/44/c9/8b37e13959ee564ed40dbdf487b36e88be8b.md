# Sobre

O Elixir usa [_Behaviours_][behaviours] para fornecer interfaces genéricas comuns, ao mesmo tempo que permite implementações específicas para cada módulo que implementa o behaviour. Um desses behaviours é o _Access Behaviour_.

O _Access Behaviour_ fornece uma interface comum para obter dados baseados em chaves a partir de uma estrutura de dados. Está implementado para mapas e listas de palavras-chave.

O módulo [`Access`][access] define os callbacks necessários para a interface. Os módulos [`Map`][map] e [`Keyword`][keyword] implementam depois os callbacks necessários [`fetch/2`][map-fetch], [`get_and_update/3`][map-get-and-update] e [`pop/2`][map-pop].

Para usar o behaviour, podes colocar _parênteses retos_ a seguir a uma variável ligada e depois usar a chave para obter o valor associado a essa chave. Os mapas suportam chaves de qualquer tipo, enquanto as listas de palavras-chave só suportam chaves do tipo átomo.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

Se a chave não existir na estrutura de dados, é devolvido `nil`. Isto pode dar origem a comportamentos indesejados, porque não lança um erro.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

Repara que o próprio `nil` implementa o Access Behaviour e devolve sempre `nil` para qualquer chave.

```elixir
nil[:key]
# => nil
```

As structs não implementam o Access behaviour.
