# Sobre

Um `vector` em Clojure é uma coleção sequencial, indexada e imutável de zero ou mais valores. Isto significa que, depois de um vetor ser criado, este não pode ser modificado. As funções que operam sobre vetores devolvem um novo vetor, enquanto o vetor original permanece inalterado. Os valores num vetor podem ser de tipos heterogéneos. Os vetores podem ser definidos da seguinte forma:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

Os elementos podem ser obtidos de um vetor através de um índice. Os vetores em Clojure são baseados em zero, o que significa que o índice do primeiro elemento é sempre zero:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

O vetor original mantém-se inalterado:

```clojure
numbers
;;=> [2 3 5]
```

Para guardar o valor atualizado, temos de o passar adiante ou de o capturar numa var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
