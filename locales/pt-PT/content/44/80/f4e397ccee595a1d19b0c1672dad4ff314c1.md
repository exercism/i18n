# Instalação

Consulta [System/Installation][install-link] para saberes como preparar o teu sistema.

~~~exercism/caution
Se tiveres o Java Development Kit (JDK) instalado, o executável `jconsole` pode entrar em conflito com a Java Console, que usa o mesmo nome.

Entre as soluções possíveis estão:

- Mudar o nome do executável `jconsole` da linguagem de programação J para algo único (por exemplo, `jconsole-jlang`).

- Ajustar as variáveis de ambiente ou o PATH do teu sistema para dar prioridade ao `jconsole` da linguagem de programação J.

- **Para quem usa Linux**, existe um script bash em `bin/install.sh` que cria uma **ligação simbólica** chamada `ijconsole` no diretório `/usr/`. Podes usar essa ligação escrevendo `ijconsole` no teu terminal.
~~~

Depois de instalares o J, abre uma consola J no teu terminal e introduz os seguintes comandos para instalar o framework de testes unitários:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
