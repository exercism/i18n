# Sobre

Uma `string` em Clojure é uma string Java, ou seja, um objeto que representa texto imutável sob a forma de uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.), e define-se da seguinte forma:

```clojure
(def fruit "Apple")
```

A biblioteca `clojure.string` fornece muitas funções padrão de manipulação e processamento de strings. Além disso, todos os métodos Java habituais para operar sobre strings estão disponíveis através da interoperabilidade.
