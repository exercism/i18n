# Introdução

## Comparação

Em Go, os números podem ser comparados com os seguintes operadores relacionais e de igualdade.

| Comparação        | Operador  |
| ------------------| --------- |
| igual             | `==`      |
| diferente         | `!=`      |
| menor             | `<`       |
| menor ou igual    | `<=`      |
| maior             | `>`       |
| maior ou igual    | `>=`      |

O resultado da comparação é sempre um valor Boolean, ou seja, `true` ou `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

Os operadores de comparação acima também podem ser usados para comparar strings.
Nesse caso, aplica-se uma ordem lexicográfica (de dicionário).
Por exemplo:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## Condicionais

As condicionais em Go são semelhantes às condicionais de outras linguagens.
O tipo subjacente de qualquer operação condicional é o tipo `bool`, que pode ter o valor `true` ou `false`.
As condicionais são frequentemente usadas como mecanismos de controlo de fluxo para verificar várias condições.

Para verificar um caso específico, pode usar-se uma condicional `if`, que executa o seu código se a condição subjacente for `true`, assim:

```go
var value string

if value == "val" {
    return "was val"
}
```

Em situações com mais do que um caso, podem encadear-se várias condicionais `if` com as cláusulas `else if` e `else`.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

As condicionais também podem incluir uma instrução curta de inicialização, que pode ser usada para inicializar uma ou mais variáveis para a condicional.
Por exemplo:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> Nota: quaisquer variáveis criadas na instrução de inicialização saem do âmbito após o fim da condicional.
