# Testes

Se tiveres o binário phix no teu path, introduz o comando:

```bash
p test 
```
Isto vai executar o ficheiro de teste (test.exw).

Se o binário phix não estiver no PATH, no Windows introduz

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem.
Por predefinição, todos os testes no ficheiro test.exw são executados.
Para ignorar um teste, acrescenta dois hífenes (o marcador de comentário padrão do Phix) ao início da linha.

Repara que os testes não têm em conta nenhuma flag include=false no tests.toml. Cabe antes ao autor do test.exw mantê-las manualmente nesse ficheiro para refletirem a realidade, em benefício do site do Exercism (por exemplo, para recolher estatísticas da track), mas nada na própria track faz uso delas, incluindo especificamente o gerador de testes e o test runner.
