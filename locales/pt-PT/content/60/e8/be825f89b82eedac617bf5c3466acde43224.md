# Dicas

## Geral

- As palavras de leitura estão em [`io`][io]; os construtores de
  fluxos de strings e `with-string-writer` estão em
  [`io.streams.string`][io.streams.string].
- Para a tarefa de esvaziar o fluxo de escrita, as variáveis locais
  (`::` e `:>`) mantêm o corpo legível quando precisas de usar o
  mesmo fluxo duas vezes.

## 1. Ouve tudo até ao fim

- Basta uma palavra: `stream-contents`.

## 2. Conta as mensagens

- `stream-lines` divide o fluxo num array de linhas;
  `length` devolve a contagem.

## 3. Ecoa a última chamada

- O mesmo `stream-lines` que acima, depois `last`, depois `>upper`
  (de `ascii`).

## 4. Transmite uma mensagem

- `stream-write` escreve a mensagem, `stream-flush` fá-la sair. O
  fluxo de escrita é usado duas vezes, por isso recorre a variáveis
  locais `::`: `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. Captura a saída de uma quotation

- Basta uma palavra: `with-string-writer`. Acrescenta `inline` depois
  do `;` final, para que o compilador consiga ver através do
  argumento quotation: `: capture ( quot -- captured ) with-string-writer ; inline`.
