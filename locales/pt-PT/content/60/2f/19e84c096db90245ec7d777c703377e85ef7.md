# Dicas

## Geral

- Lê sobre [erros][errors] no guia Getting Started.
- Lê sobre [`try`][docs-try] na documentação.

## 1. Avisa a equipa

- Permite que a função da operação lance o seu erro.
- Para invocar uma função guardada numa variável, usa o operador `.`.

## 2. Envolve o erro

- Recorre a try .. rescue para devolver o resultado pretendido.

## 3. Transmite a mensagem

- Recorre a try .. rescue para devolver o resultado pretendido.
- O bloco rescue permite-te fazer correspondência de padrões com o nome do módulo do erro e também associar o erro a uma variável.

[errors]: https://hexdocs.pm/elixir/try-catch-and-rescue.html#errors
