# Palavras-chave estáticas de classe

Uma classe é uma unidade de organização de código em PHP, que representa muitas vezes uma instância de uma coisa, de um serviço ou de um procedimento.
Com as palavras-chave `static` e `self`, podes ter propriedades e métodos que existem em referência à classe, para todas as instâncias (ou para nenhuma).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limitação

Os métodos estáticos de classe só podem chamar outras propriedades estáticas ou métodos da própria classe.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
