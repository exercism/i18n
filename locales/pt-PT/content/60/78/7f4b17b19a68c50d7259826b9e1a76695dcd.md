# Dicas

## Geral

- Lê a documentação oficial sobre [intervalos][range].

## 1. Define o intervalo das filas

- Existe um [operador especial][range-creation-operator] para criar intervalos.

## 2. Define o intervalo das colunas

- Existe um [operador especial][range-creation-operator] para criar intervalos.
- Existe uma [sintaxe especial][unicode-code-points] para escrever o ponto de código de um caráter sem saberes explicitamente o seu valor.

## 3. Transforma o intervalo das filas numa lista de filas

- Os intervalos implementam o protocolo `Enumerable`.
- Existe uma [função incorporada][enum-to-list] para converter uma estrutura de dados enumerável numa lista.

## 4. Transforma o intervalo das colunas numa lista de colunas

- Os intervalos implementam o protocolo `Enumerable`.
- Existe uma [função incorporada][enum-map] para converter uma estrutura de dados enumerável numa lista enquanto modifica os seus elementos.
- A [forma especial bitstring][bitstring-special-form] pode ser usada para converter um ponto de código numa string.
