# Sobre

O Batch scripting é uma linguagem de scripting usada sobretudo para executar comandos no Windows Command Prompt (cmd.exe).
Permite automatizar tarefas, gerir ficheiros e controlar o ambiente do sistema através de uma série de instruções de linha de comandos.

Embora o Batch scripting seja simples, consegue dar resposta a uma grande variedade de tarefas, desde operações básicas com ficheiros até processos de automatização mais complexos.

Os ficheiros Batch têm a extensão `.bat` ou `.cmd` e podem ser executados diretamente pelo intérprete de comandos do Windows.

A flexibilidade do Batch scripting faz dele uma ferramenta poderosa para administradores de sistema, programadores e utilizadores avançados que precisam de automatizar tarefas de rotina ou de criar ferramentas personalizadas de linha de comandos.
