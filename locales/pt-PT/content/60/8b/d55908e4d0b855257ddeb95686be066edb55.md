# Introdução

Um [atributo do C# (`Attribute`)](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) fornece uma forma de decorar uma declaração para lhe associar metadados: uma classe, um método, um enum, um campo, uma propriedade ou qualquer [outra declaração suportada](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Podes aplicar um atributo adicionando-o na linha anterior à declaração, com um `ClassAttribute` e um `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Estes metadados declarativos apenas associam informação estruturada adicional ao código e não modificam o seu comportamento. No entanto, outras partes do código usam esses metadados para alterar o comportamento do alvo, ou para acrescentar, alterar, remover ou restringir algumas das suas funcionalidades.

Existem muitos [atributos predefinidos e reservados](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), por exemplo: `Flags`, `Obsolete`, `Conditional`. Cada um tem uma finalidade específica que podes consultar na documentação do C#. Repara que o nome completo de um atributo como [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) é `FlagsAttribute`, por convenção, mas o sufixo _Attribute_ pode ser omitido quando é aplicado a uma declaração.
