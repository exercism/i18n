# Dicas

## Geral

- Lê sobre protocolos no [guia oficial Getting Started][getting-started-protocols] ou em [elixirschool.com][elixir-school-protocols].

## 1. Define a comestibilidade

- Existe uma [macro especial][kernel-defprotocol] para definir protocolos.
- Os protocolos são compostos por um ou mais cabeçalhos de funções.
- Um cabeçalho de função é como uma definição de função, mas sem o bloco `do`. Define o nome da função e os seus argumentos, mas não o que ela faz.

## 2. Torna os pães comestíveis

- Existe uma [macro especial][kernel-defimpl] para implementar um protocolo para um determinado tipo de dados.
- Implementar um protocolo significa escrever uma definição de função para cada cabeçalho de função do protocolo.

## 3. Torna as poções de mana comestíveis

- Existe uma [macro especial][kernel-defimpl] para implementar um protocolo para um determinado tipo de dados.
- Implementar um protocolo significa escrever uma definição de função para cada cabeçalho de função do protocolo.

## 4. Torna os venenos comestíveis

- Implementar um protocolo significa escrever uma definição de função para cada cabeçalho de função do protocolo.
