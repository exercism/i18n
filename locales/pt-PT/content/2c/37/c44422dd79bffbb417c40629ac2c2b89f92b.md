# Dicas

## Geral

- As [tuplas](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) são agrupamentos imutáveis de valores sem nome mas ordenados, possivelmente de tipos diferentes.
- Os elementos dentro das tuplas podem ser [obtidos](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values) através de correspondência de padrões, de desconstrução de tuplas ou com funções auxiliares.

## 1. Extrair as coordenadas

- Lembra-te: as tuplas permitem o acesso através de funções auxiliares ou de desconstrução.
- Vê a [análise de strings](https://docs.microsoft.com/en-us/dotnet/api/system.int32.parse?view=net-5.0) para obteres um número a partir de uma string.

## 2. Formatar as coordenadas

- Vê os [exemplos](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#examples) para mais detalhes sobre a criação de tuplas.
- Vê o [corte de strings](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/strings#string-indexing-and-slicing) para mais detalhes sobre strings.

## 3. Encontrar as coordenadas correspondentes

## 4. Combinar os registos correspondentes

- Lembra-te de que as tuplas suportam [correspondência de padrões](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values).
