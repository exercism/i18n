# Instalação

Estão disponíveis [binários do Uiua pré-compilados][releases], por isso não é preciso compilar.
Consulta o [guia de instalação oficial][install-guide] para as instruções mais recentes, incluindo a integração com o IDE e os tipos de letra.

```exercism/note
De momento, o nosso test-runner online usa a versão `0.18.1`.
Como o processo de desenvolvimento do Uiua é rápido, isto pode mudar, por isso tem isto em conta se não conseguires reproduzir os resultados dos testes a partir do site.
```

Depois de transferires o Uiua para o local pretendido, tens de o adicionar ao PATH do teu sistema.

- **macOS:** Usa o Finder para abrir `Applications > Utilities > Terminal`. Introduz `export PATH="/path/to/uiua:$PATH"` para executar o Uiua a partir de qualquer local.

- **Windows:** Abre «Edit Environment Variables» a partir do menu Iniciar. Em «Path», adiciona a tua pasta do Uiua.

- **Linux:** Abre o Terminal e adiciona `export PATH="/path/to/uiua:$PATH"` a `~/.bashrc` ou `~/.profile` para um acesso mais fácil.

[releases]: https://github.com/uiua-lang/uiua/releases
