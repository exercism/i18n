# Instruções case

Quando comparamos um valor com uma lista de possibilidades, uma cadeia de
`elsif` repete a mesma coisa vezes sem conta:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

O `case` diz isso uma só vez:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

O valor vai depois do `case`. Cada `when` indica um valor com que o comparar, e
só o primeiro que corresponder é executado.

## Vários valores num só when

Um `when` pode listar vários valores, separados por vírgulas:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

Isto funciona com números inteiros, carateres e strings, ou seja, tudo o que se
possa comparar com `=`.

## O else não é opcional

**Um `case` que não corresponde a nada e não tem `else` é um erro que faz o
programa parar quando acontece.**

Isso é diferente do `if`, em que omitir o `else` significa simplesmente que não
acontece nada. Também é diferente da maioria das linguagens, em que um `case`
sem correspondência não faz nada discretamente.

Por isso, todos os `case` precisam de um `else`, mesmo quando tens a certeza de
que os `when` já cobrem todos os valores. Mais tarde acrescenta-se uma quarta
zona, o `case` não é atualizado para corresponder, e o programa para no primeiro
passageiro que a use.

## Só um when é executado

Quando um `when` corresponde, as instruções que se seguem ao seu `then` são
executadas e o `case` termina: o programa continua depois do `end`. Nunca se
olha para os `when` que estão abaixo, por isso não há nada que precises de
escrever para impedir que o seguinte também seja executado.
