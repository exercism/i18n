# Introdução

Uma extensão estática permite a pseudoextensão de tipos existentes sem modificar o seu código-fonte. Isto é conseguido através da instrução `using`. As extensões estáticas podem ser uma ferramenta poderosa que permite acrescentar funcionalidades a tipos sem os alterar realmente.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
