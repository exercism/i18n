# Anexo às instruções

## Instruções específicas do track

A tua tarefa é escrever uma função `nucleotideCounts` que recebe como parâmetro de entrada uma string e devolve um array associativo que conta quantas vezes cada nucleótido aparece.
Se a string for uma sequência inválida, a função deve lançar um `IllegalArgumentError` com a mensagem `Invalid nucleotide in strand`.
