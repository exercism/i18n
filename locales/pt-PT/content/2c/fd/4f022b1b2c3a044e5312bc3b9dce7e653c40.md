# Tarefas

As tarefas são issues do GitHub em que gostaríamos que as pessoas ajudassem, desde rever texto até construir exercícios de conceito.
São apresentadas no site e ligam às issues correspondentes no GitHub.
Cada tarefa é etiquetada com uma ou mais propriedades, que são preenchidas a partir das etiquetas da issue.
Depois, podes filtrar as tarefas com base nas respetivas propriedades.

## Etiquetas

Para que uma issue seja considerada uma tarefa, tem de estar etiquetada com uma ou mais etiquetas específicas de tarefas.
Assim, os mantenedores podem escolher que só algumas issues apareçam como tarefas.

Cada etiqueta de tarefa é definida como: `x:<type>/<value>` e são suportados cinco tipos de tarefa:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### Etiqueta de ação

As etiquetas `x:action/<value>` descrevem o tipo de trabalho em que o contribuidor vai estar envolvido ao trabalhar na issue.

| Etiqueta            | Descrição                                     |
| ------------------- | --------------------------------------------- |
| `x:action/create`   | Trabalhar em algo de raiz                     |
| `x:action/fix`      | Corrigir uma issue                            |
| `x:action/improve`  | Melhorar funcionalidades ou conteúdos já existentes |
| `x:action/proofread`| Rever texto                                   |
| `x:action/sync`     | Sincronizar o conteúdo com a sua versão mais recente |

### Etiqueta de conhecimento

As etiquetas `x:knowledge/<value>` descrevem quantos conhecimentos do Exercism são exigidos ao contribuidor.

| Etiqueta                     | Descrição                                          |
| ---------------------------- | -------------------------------------------------- |
| `x:knowledge/none`           | Não é preciso nenhum conhecimento do Exercism      |
| `x:knowledge/elementary`     | É preciso pouco conhecimento do Exercism           |
| `x:knowledge/intermediate`   | É preciso bastante conhecimento do Exercism        |
| `x:knowledge/advanced`       | É preciso um conhecimento abrangente do Exercism   |

### Etiqueta de módulo

As etiquetas `x:module/<value>` indicam em que parte do Exercism o contribuidor vai trabalhar.

| Etiqueta                       | Descrição                        |
| ------------------------------ | -------------------------------- |
| `x:module/analyzer`            | Trabalhar nos analyzers          |
| `x:module/concept`             | Trabalhar em conceitos           |
| `x:module/concept-exercise`    | Trabalhar em exercícios de conceito |
| `x:module/generator`           | Trabalhar em geradores de exercícios |
| `x:module/practice-exercise`   | Trabalhar em exercícios de prática |
| `x:module/representer`         | Trabalhar nos representers       |
| `x:module/test-runner`         | Trabalhar nos test runners       |

### Etiqueta de tamanho

As etiquetas `x:size/<value>` descrevem a quantidade de trabalho prevista para um contribuidor.

| Etiqueta          | Descrição                       |
| ----------------- | ------------------------------- |
| `x:size/tiny`     | Quantidade mínima de trabalho   |
| `x:size/small`    | Pequena quantidade de trabalho  |
| `x:size/medium`   | Quantidade média de trabalho    |
| `x:size/large`    | Grande quantidade de trabalho   |
| `x:size/massive`  | Quantidade enorme de trabalho   |

### Etiqueta de tipo

As etiquetas `x:type/<value>` descrevem o tipo de trabalho em que o contribuidor vai estar envolvido.

| Etiqueta          | Descrição                                                                                                                                                                                                    |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`       | Trabalhar em integração contínua (por exemplo, fluxos de trabalho do GitHub Actions)                                                                                                                          |
| `x:type/coding`   | Escrever código que não faz parte do conteúdo destinado aos estudantes. Normalmente são tarefas associadas a ferramentas de produção (por exemplo, test runners), ferramentas internas (geradores) ou bibliotecas que o Exercism mantém. |
| `x:type/content`  | Trabalhar em conteúdo (por exemplo, exercícios, conceitos)                                                                                                                                                    |
| `x:type/docker`   | Trabalhar em Dockerfiles                                                                                                                                                                                      |
| `x:type/docs`     | Trabalhar em documentação                                                                                                                                                                                     |

## Etiquetas claimed e unclaimed

Para ocultar uma tarefa porque já há alguém a trabalhar nela, uma issue pode receber a etiqueta `x:status/claimed`.
