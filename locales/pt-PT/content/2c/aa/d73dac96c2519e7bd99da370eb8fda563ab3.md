# Apêndice às instruções

## Instruções específicas da track

Tradicionalmente, os resultados encriptados têm os espaços e a pontuação removidos e são convertidos para maiúsculas ou minúsculas. No entanto, quando um teste especifica um bPreserve com o valor true, nenhuma dessas coisas deve acontecer; quando é false, o resultado só deve conter as letras minúsculas `a..z`, caso em que a desencriptação perfeita não é realmente possível, mas podes ficar descansado que o código de testes é suficientemente inteligente para o saber.
