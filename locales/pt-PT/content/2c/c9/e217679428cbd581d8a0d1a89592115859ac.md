# Sobre

Podes executar código condicionalmente com [expressões `if/elif/else`][conditional-expression]. As condições usadas numa expressão `if/elif/else` têm de ser do tipo `bool`. O F# não tem o conceito de valores _truthy_.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

Como `if/elif/else` é uma expressão, pode ser associada a um nome ou devolvida por uma função.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

Todos os ramos têm de devolver o mesmo tipo. Se não o fizeres, ocorre um erro de compilação:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

Os ramos `else` e `elif` são opcionais, mas apenas se o tipo da expressão devolvida for [`unit`][unit-type].

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

Uma expressão `if/else` também pode ser colocada numa única linha. Isto só deve ser usado para expressões `if` simples.

```fsharp
let y = if x > 5 then 10 else 20
```
