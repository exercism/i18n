# Instruções

Neste exercício vais escrever código para processar uma lista de linguagens de programação que planeias praticar na plataforma Exercism.

Tens seis tarefas.

## 1. Criar uma nova lista

Antes de poderes adicionar linguagens, tens de começar por criar uma nova lista. Define uma função que devolve uma lista vazia.

```clojure
(new-list)
;; => ()
```

## 2. Adicionar uma nova linguagem à lista

À medida que exploras o Exercism e encontras linguagens que queres aprender, vais precisar de as adicionar à tua lista. Define uma função para adicionar uma nova linguagem ao início da tua lista.

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. Verificar a última linguagem adicionada

Vais querer verificar rapidamente que linguagem acabaste de adicionar. Define uma função que devolve a primeira linguagem da tua lista.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Remover a primeira linguagem da lista

Por vezes, mudas de ideias em relação a uma linguagem que acabaste de adicionar. Define uma função para remover a primeira linguagem da tua lista.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Contar as linguagens da lista

Contar as linguagens uma a uma é pouco prático. Define uma função para contar o número de linguagens da tua lista.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Juntar tudo

Define uma função `learning-list`, na qual vais usar algumas das funções que definiste acima.

- Cria uma lista vazia
- Adiciona 2 novas linguagens de programação à lista.

  - "Clojure"
  - "Lisp"

- Remove "Lisp" da lista, porque podes não ter tempo suficiente ao longo do ano, e é bastante semelhante a Clojure.
- Adiciona mais 2 linguagens de programação à lista.

  - "Java"
  - "JavaScript"

- Devolve o número total de linguagens. Sugestão: devem ser 3.

```clojure
(learning-list)
;; => 3
```
