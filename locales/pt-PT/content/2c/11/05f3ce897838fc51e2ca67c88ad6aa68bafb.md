# Sobre

## Boolean

O PowerShell tem o tipo [`bool`][booleans], que representa os valores true e false.
Neste tipo existem apenas dois valores: `True` e `False`.
Podes associar estes valores a variáveis com o prefixo `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Podemos usar [operadores lógicos][logical-operators] como `-and`, `-or` e `-not` para combinar e avaliar expressões Boolean.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## Conversão e veracidade

O PowerShell consegue tratar implicitamente qualquer tipo como Boolean.
No entanto, também podes usar o acelerador de tipo Boolean `[bool]` para fazer uma conversão explícita.

Eis algumas regras gerais que o PowerShell usa para converter outros tipos em valores Boolean:

$false:
- Strings vazias como `''` ou `""`
- Valores nulos como `$null`
- Tipos numéricos com o valor zero (0)

$true:
- Strings não vazias
- Instâncias de qualquer outro tipo que não seja uma coleção

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

Para regras mais detalhadas sobre a conversão de valores Boolean a partir de tipos de coleção, consulta [aqui][collection-conversion].
