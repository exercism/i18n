# Anexo às instruções

## Mensagens de exceção

Por vezes, é necessário [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando o fazes, deves incluir sempre uma **mensagem de erro significativa** que indique qual é a origem do erro. Isto torna o teu código mais legível e ajuda imenso no debug. Nos casos em que sabes que a origem do erro vai ser de um determinado tipo, podes optar por lançar um dos [tipos de erro incorporados](https://docs.python.org/3/library/exceptions.html#base-classes), mas deves continuar a incluir uma mensagem significativa.

Este exercício em particular exige que uses a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para «lançar» um `ValueError` quando a função `convert()` recebe uma string que não é um número OCR válido. Os testes só passam se fizeres `raise` da `exception` e incluíres uma mensagem com ela.

Para lançares um `ValueError` com uma mensagem, escreve a mensagem como argumento do tipo `exception`:

```python
# when the rows aren't multiples of 4
raise ValueError("Number of input lines is not a multiple of four")

# when the columns aren't multiples of 3
raise ValueError("Number of input columns is not a multiple of three")
```
