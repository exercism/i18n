# Apêndice às instruções

## Dicas

Para teres aqui o nível de desafio adequado, deves usar apenas funcionalidades presentes no Prelude. Tenta não usar Data.List, Data.Char, Data.Bits nem Numeric.

Tenta usar seq, $! ou BangPatterns de forma adequada, para garantir que a solução é eficiente.

Não é necessário tratar entradas inválidas.
