# Instruções

Neste exercício, tens de implementar algumas regras do clássico jogo Pac-Man.

Tens quatro regras para implementar, todas relacionadas com os estados do jogo.

## 1. Define se o Pac-Man come um fantasma

Implementa uma função que recebe se o Pac-Man tem uma pastilha de energia ativa e se o Pac-Man está a tocar num fantasma, e que devolve um valor boolean se o Pac-Man consegue comer o fantasma. A função só deve devolver `true` se o Pac-Man tiver uma pastilha de energia ativa e estiver a tocar num fantasma.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Define se o Pac-Man marca pontos

Implementa uma função que recebe se o Pac-Man está a tocar numa pastilha de energia e se o Pac-Man está a tocar num ponto, e que devolve um valor boolean se o Pac-Man marcou pontos. A função deve devolver `true` se o Pac-Man estiver a tocar numa pastilha de energia ou num ponto.

```lua
rules.score(true, true)
-- => true
```

## 3. Define se o Pac-Man perde

Implementa uma função que recebe se o Pac-Man tem uma pastilha de energia ativa e se o Pac-Man está a tocar num fantasma, e que devolve um valor boolean se o Pac-Man perde. A função deve devolver `true` se o Pac-Man estiver a tocar num fantasma e não tiver uma pastilha de energia ativa.

```lua
rules.lose(false, true)
-- => true
```

## 4. Define se o Pac-Man ganha

Implementa uma função que recebe se o Pac-Man comeu todos os pontos, se o Pac-Man tem uma pastilha de energia ativa e se o Pac-Man está a tocar num fantasma, e que devolve um valor boolean se o Pac-Man ganha. A função deve devolver `true` se o Pac-Man tiver comido todos os pontos e não tiver perdido, de acordo com os argumentos definidos na parte 3.

```lua
rules.win(false, true, false)
-- => false
```
