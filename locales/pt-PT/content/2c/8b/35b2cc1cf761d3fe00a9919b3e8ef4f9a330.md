# Dicas

## Geral

Lembra-te de que isto é um [MVP][mvp].
Isso significa que não precisas de complicar com o tratamento de erros nem com diferentes cenários de «casos limite».
Não há problema em ser simples e direto nas funções que escreves.

A secção sobre dicionários do [tutorial oficial][dicts-docs] e a [referência oficial da biblioteca][mapping-types-dict] para o tipo de mapeamento são excelentes sítios onde procurar mais ajuda com todos estes métodos.


## 1. Adiciona item(ns) ao carrinho de compras do utilizador

- Vais precisar de iterar por cada item em `items_to_add`.
- Podes evitar um `KeyError` quando falta uma chave usando um [método][set-default] de `dict` que recebe um _valor por omissão_ como um dos seus argumentos.
- Também é possível fazer o mesmo manualmente no `loop`, recorrendo a algumas verificações e tratamento de erros, mas o método de `dict` é mais fácil.

## 2. Lê os itens listados na aplicação de notas do utilizador

- Lembra-te: o Python tem um método para _tudo_. Este é um _classmethod_ que é uma forma fácil de [preencher um `dict`][fromkeys] com chaves.
- Este método de `dict` devolve um _novo dicionário_, preenchido com valores por omissão. Se não for dado nenhum valor, o valor por omissão passa a ser `None`

## 3. Atualiza a secção «Ideias» da receita

- Não penses demasiado nisto!  Isto resolve-se com **uma** única chamada a um método de `dict`.
- A palavra-chave aqui é .... [_update_][update].

## 4. Ordena os itens no carrinho do utilizador

- Que método chamarias para obter uma [vista iterável dos itens][items] do dicionário?
- Se tivesses uma `list` ou um `tuple`, que função [`built-in`][builtins] poderias usar para os ordenar?
- A função built-in que queres é a que devolve uma _cópia_ e não altera o original.

## 5. Envia o carrinho de compras do utilizador para a loja para processamento

- Ter aqui um dicionário novo e vazio como `fulfillment_cart` pode dar jeito para ir adicionando itens.
- `Looping` pelos membros do carrinho pode ser a forma mais direta de aceder às coisas aqui.
- Que método chamarias para obter uma [vista iterável só das chaves][keys] do dicionário?
- Lembra-te de que podes obter o `value` de uma dada chave usando a sintaxe `<dict name>[<key_name>]`.
- Se tivesses uma `list` ou um `tuple`, que função [`built-in`][builtins] poderias usar para os ordenar?
- Lembra-te de que a função `built-in` pode receber um argumento opcional `reverse=True`.

## 6. Atualiza o inventário da loja para refletir o que o utilizador encomendou.

- Há um método que te dá uma vista iterável dos pares (`key`, `value`) do dicionário.
- Podes aceder a um item de um _tuplo aninhado_ usando a _notação de parênteses retos_:  `<tuple>[<nested_tuple>][<index_of_value>]`
- Não te esqueças de verificar se a contagem de inventário chega a zero, vais precisar de adicionar a mensagem "Out of Stock".
