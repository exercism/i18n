# Instruções

Estás a desenvolver um sistema para ajudar a equipa do site de um clube de futebol a fazer relatórios dos jogos.
Os dados são recebidos de várias fontes e canalizados para um único fluxo depois de serem limpos.

## 1. Devolve as descrições dos jogadores com base no número da camisola

A equipa joga sempre em 4-3-3 e nunca aceitou a alteração de 1965 às regras que permite substituições, quanto mais plantéis alargados.

As descrições dos jogadores são as seguintes:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Implementa o método estático `FootballMatchReports.onField()` para devolver a descrição de um jogador com base no número da camisola.

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. Devolve "invalid" se o número da camisola não fizer parte da lista oficial

Modifica o método `FootballMatchReports.onField()` para devolver 'invalid' quando é processado um número de camisola fora do intervalo 1-11.

```java
FootballMatchReports.onField(13);
// => "invalid"
```
