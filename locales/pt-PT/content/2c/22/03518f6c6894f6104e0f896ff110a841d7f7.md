# Dicas

## 1. Gerar as letras dos lugares

- O valor devolvido deve ser do _tipo_ `generator`.
- Podes ter uma sequência de letras de `A` a `D` e percorrê-la em ciclo.
- Usa `yield` para devolver a letra seguinte.

## 2. Gerar os lugares

- O valor devolvido deve ser do _tipo_ `generator`.
- A fila `13` deve ser ignorada, por isso passa de `12` para `14`.
- Tem em atenção que os valores devolvidos devem estar ordenados do mais baixo para o mais alto. `1A, 1B, 2A, ...`
- Aqui, pode ser boa ideia reutilizar ou chamar funções que já definiste.

## 3. Atribuir lugares aos passageiros

- Certifica-te de que os números dos lugares não têm espaços.
- Aqui, pode ser boa ideia reutilizar ou chamar funções que já definiste.

## 4. Códigos dos bilhetes

- Podes usar `len()` para obter o comprimento de uma string.
- Podes usar `"<string>" * <int>` para repetir uma string.
