Em JavaScript, as lentes são um conceito de programação funcional que te permite aceder e modificar dados de forma modular e imutável. São, essencialmente, pares componíveis de funções puras, umas para ler e outras para escrever, que incidem sobre um campo específico de um objeto.

As lentes podem simplificar o código, torná-lo mais reutilizável e evitar erros de programação comuns. Por exemplo, podes usar lentes para:

- Aceder e modificar estruturas de dados aninhadas sem teres de te preocupar com a estrutura específica dos dados.
- Atualizar dados de forma pura, sem modificar o objeto original.
- Compor várias lentes entre si para criar lentes mais complexas, capazes de aceder e modificar dados de várias formas.
