# Introdução aos ciclos for-each

O [ciclo for-each](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) oferece um mecanismo para executar um bloco de código para cada elemento de uma coleção.
Alguma documentação (por exemplo, a documentação da Oracle) refere-se a estes ciclos como ciclos for melhorados.

Aqui está a sintaxe geral:

```java
for(declaration: collection) {
    body;
}
```

A `declaration` declara a variável usada para guardar os valores atribuídos a partir da coleção.

A `collection` é um array ou uma coleção que contém os valores que vão ser atribuídos à variável do ciclo.

O `body` contém as instruções que vão ser executadas uma vez por cada valor da coleção.

Por exemplo:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

que produz:

```text
a
e
i
o
u
```

Em geral, um ciclo `for-each` é preferível a um ciclo `for` pelas seguintes razões:

- Um ciclo `for-each` percorre garantidamente _todos_ os valores.
- Um ciclo `for-each` é mais _declarativo_, o que significa que o código comunica _o que_ está a fazer, em vez de _como_ o está a fazer.
- Um ciclo `for-each` é à prova de erro, ao passo que com ciclos `for` é fácil cometer um erro de um a mais ou a menos (pensa em usar `<` em vez de `<=`).
- Um ciclo `for-each` funciona com todos os tipos de coleção, incluindo aqueles que não suportam o acesso aos elementos através de um índice (por exemplo, um `Set`).
