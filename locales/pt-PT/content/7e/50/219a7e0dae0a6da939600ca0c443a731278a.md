# Instruções

És um observador de aves entusiasta que acompanha quantas aves visitaram o teu jardim nos últimos sete dias.

Tens seis tarefas, todas relacionadas com o número de aves que visitaram o teu jardim.

## 1. Verifica quantas aves visitaram hoje

Implementa a função `today()` para devolver quantas aves visitaram o teu jardim hoje. As contagens de aves estão ordenadas por dia: o primeiro elemento é a contagem do dia mais antigo e o último é a contagem de hoje.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Incrementa a contagem de hoje

Implementa a função `increment_todays_count()` para incrementar a contagem de hoje:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Verifica se houve algum dia sem aves a visitar

Implementa a função `has_day_without_birds()` que devolve `TRUE` se houve um dia em que zero aves visitaram o jardim; caso contrário, devolve `FALSE`:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Calcula o número de aves que visitaram nos primeiros dias

Implementa a função `count_for_first_days()` que devolve o número de aves que visitaram o teu jardim desde o início da semana, mas limita a contagem ao número de dias indicado a partir do início da semana.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Calcula o número de dias movimentados

Há dias mais movimentados do que outros. Um dia movimentado é aquele em que cinco ou mais aves visitaram o teu jardim.
Implementa a função `busy_days()` para devolver o número de dias movimentados:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. Calcula o total acumulado de visitas de aves na última semana

Tens curiosidade em saber quantas aves, no total, já visitaram o jardim esta semana.
Calcula os totais acumulados para cada dia.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. Ordena os nomes dos dias conforme a sua movimentação

Suspeitas que as visitas das aves são afetadas pelos padrões de trânsito nas estradas próximas, sendo diferentes aos fins de semana e durante a semana.

Ordena as abreviaturas dos dias por ordem _descendente_ do número de aves que visitaram o jardim.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
