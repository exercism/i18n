# Instruções

Elyse, futura maga, continua o seu treino. Vão ser-lhe dadas várias pilhas de cartas com que precisa de fazer os seus truques.
Para facilitar um pouco as coisas, usa apenas as cartas de 1 a 10.

Neste exercício, usa métodos incorporados para analisar o conteúdo de um vetor.

## 1. Determinar se uma carta está presente

A Elyse quer determinar se uma carta está presente na pilha, ou seja, se a pilha contém um número específico.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. Encontrar a posição de uma carta

A Elyse quer saber a posição (índice) de uma carta na pilha. 
Se a carta não estiver na pilha, devolve `-1`.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. Determinar se cada carta é par

A Elyse quer saber se todas as cartas são pares, ou seja, se cada número na pilha é um número par.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. Verificar se a pilha contém uma carta com valor ímpar

A Elyse quer saber se há um número ímpar na pilha.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. Obter a primeira carta ímpar da pilha

A Elyse quer saber o valor da primeira carta que é ímpar.  
Se não houver nenhuma carta ímpar na pilha, devolve `-1`.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. Determinar a posição da primeira carta par

A Elyse quer saber a posição da primeira carta que é par.
Se não houver nenhuma carta par na pilha, devolve `-1`.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
