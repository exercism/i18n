# Instruções

Neste exercício vais processar linhas de registo.

Cada linha de registo é uma string formatada como `"[<LEVEL>]: <MESSAGE>"`.

Há três níveis de registo: `INFO`, `WARNING` e `ERROR`.

Tens três tarefas. Cada uma retira uma única linha de registo da pilha.

## 1. Obter a mensagem de uma linha de registo

Define `message` para devolver a mensagem da linha de registo. Qualquer
espaço em branco no início ou no fim deve ser removido.

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. Obter o nível de registo de uma linha de registo

Define `log-level` para devolver o nível da linha de registo, em minúsculas.

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. Reformatar uma linha de registo

Define `reformat` para colocar a mensagem primeiro e o nível de registo em
minúsculas entre parênteses, a seguir.

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***Nota:*** Todas as strings deste exercício são ASCII. Os exercícios
seguintes irão abordar o tratamento de strings que tem em conta o Unicode.
