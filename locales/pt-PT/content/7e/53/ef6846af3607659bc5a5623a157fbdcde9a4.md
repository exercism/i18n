# O operador ternário

Uma condicional ternária é uma forma mais curta de escrever instruções `if/else` simples.
Se uma instrução `if/else` tiver apenas dois ramos, um para quando a condição é verdadeira e outro para quando é falsa, pode ser reescrita como uma condicional ternária.

As condicionais ternárias usam uma combinação dos símbolos `?` e `:` para separar as partes de uma condicional:
```ruby
condition ? true_branch : false_branch
```

O código à esquerda do `?` é a condição e o código à direita contém os dois ramos possíveis, separados pelo `:`.
Se a condição for _verdadeira_, é executado o código do lado _esquerdo_ do `:`.
Se a condição for _falsa_, é executado o código à _direita_ do `:`.

Por exemplo:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

pode ser reescrito como:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
