# About

O tipo `Bool` é um dos blocos de construção da linguagem.
Serve para descrever se algo é verdadeiro ou falso, com os respetivos valores `True` e `False`.
O nome `Bool` é a abreviatura de booleano, um ramo da matemática ligado ao pensamento lógico, que deve o seu nome ao trabalho de George Boole.

## Operadores Boolean

Há duas funções e dois operadores para manipular valores do tipo `Bool`.

- `not : Bool -> Bool`
  Esta função transforma `True` em `False` e `False` em `True`.
- `(&&) : Bool -> Bool -> Bool`
  Este operador, chamado «AND», recebe dois valores Boolean e devolve `True` se ambos forem `True`.
  Por exemplo, `True && True` devolve `True`, mas `True && False` devolve `False`.
- `(||) : Bool -> Bool -> Bool`
  Este operador, chamado «OR», recebe dois valores Boolean e devolve `True` se pelo menos um deles for `True`.
  Por exemplo, `False || False` devolve `False`, mas `True || False` devolve `True`.
- `xor : Bool -> Bool -> Bool`
  Esta função (não é um operador), chamada «XOR», recebe dois valores Boolean e devolve `True` se e só se um for `True` e o outro for `False`.

Os operadores `&&` e `||` não têm a mesma prioridade.
A prioridade de `&&` é mais alta do que a de `||`, tal como acontece com a multiplicação `*` e a adição `+`.
Por consequência, a expressão `True || False && False` é equivalente a `True || (False && False)`, que é diferente de `(True || False) && False`.
Enquanto a primeira devolve `True`, a segunda devolve `False`.

## Ramificação condicional

Os valores Boolean são extremamente úteis para criar ramos no teu código que só são executados se certas condições se verificarem.
Em Elm, isso faz-se com uma expressão `if-then-else`, usada da seguinte forma.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

O valor `someCondition` pode ser qualquer expressão que devolva um `Bool`.
Se esse valor Boolean for `True`, o código executa `doSomething`.
Caso contrário, é `False` e o código executa `doSomethingElse`.
O ramo `else` é obrigatório, ao contrário do que acontece noutras linguagens de programação.

Se precisares de encadear condições, basta encadear as expressões `if-then-else`.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
