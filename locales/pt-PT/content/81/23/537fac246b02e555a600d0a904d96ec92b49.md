# Sobre

Como todos os tipos de dados padrão do Clojure são imutáveis, a linguagem oferece *tipos de referência*, que permitem uma mutação controlada. Os mais simples e mais usados são os átomos.

Os átomos são criados com a função `atom`, que recebe um valor inicial:

```clojure
(def players (atom ()))
```

Desreferencia-se o valor atual do átomo com `deref` ou com a forma abreviada `@`:

```clojure
@players
;;=> ()
```

O valor atual do átomo `players` pode ser modificado com `swap!`, que atualiza o valor aplicando-lhe uma função:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

A função `reset!` substitui o valor de um átomo sem ter em conta o seu valor atual:

```clojure
(reset! players ())
```
