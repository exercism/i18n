# Introdução

## Números inteiros

Há dois tipos diferentes de números em Elixir: números inteiros e números de vírgula flutuante.

Os números inteiros são números sem parte fracionária.

```elixir
integer = 3
# => 3
```

## Números de vírgula flutuante

Os números de vírgula flutuante são números com um ou mais algarismos depois do separador decimal. Usam o formato de vírgula flutuante de precisão dupla de 64 bits.

```elixir
float = 3.45
# => 3.45
```

### Trabalhar com números

Nos módulos [`Integer`][integer-functions] e [`Float`][float-functions] podes encontrar algumas funções úteis para trabalhar com esses tipos. Os operadores aritméticos básicos estão definidos no módulo [`Kernel`][kernel-arithmetic-operators].

### Conversão

Os números inteiros e os números de vírgula flutuante podem ser misturados numa única expressão aritmética. Usar um número de vírgula flutuante numa expressão garante que o resultado também será um número de vírgula flutuante.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

No entanto, ao dividir, o resultado será sempre um número de vírgula flutuante, mesmo que só se usem números inteiros.

```elixir
6 / 2
# => 3.0
```

Para converter um número de vírgula flutuante num número inteiro, podes descartar a parte decimal com [`trunc/1`][trunc-1].
