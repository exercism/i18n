# Instruções

Um novo clube de poesia abriu na cidade e estás a pensar aparecer.
Como já houve incidentes no passado, o clube tem uma política de entrada muito específica que tens de dominar antes de tentares entrar.

Há duas portas no clube de poesia, uma da frente e uma de trás, e ambas estão vigiadas.
Para conseguires entrar, tens de descobrir a palavra-passe do dia.

A palavra-passe baseia-se sempre num poema e pode ser obtida num processo de dois passos.

1. O guarda recita o poema, um verso de cada vez, e tens de responder com a letra adequada desse verso.
2. O guarda diz-te agora, de uma só vez, todas as letras com que respondeste, e tens de as escrever num papel com um formato específico.

Os detalhes do processo dependem da porta pela qual estás a tentar entrar.

~~~~exercism/note
Todas as strings deste exercício estão codificadas em ASCII e terminadas em NUL.
Isto significa que todos os carateres usam codificação ASCII e que cada string termina quando se encontra o '\0' (o caráter NUL, com o valor `0`).
~~~~

~~~~exercism/note
Estas são as instruções de string mencionadas neste conceito:

| instrução  | o que faz                                                                                                                |
|------------|--------------------------------------------------------------------------------------------------------------------------|
| `lods`       | carrega um valor de uma posição de memória indicada por `rsi` para `rax`                                                 |
| `stos`       | armazena um valor de `rax` numa posição de memória indicada por `rdi`                                                    |
| `movs`       | copia um valor de uma posição de memória indicada por `rsi` e armazena-o numa posição de memória indicada por `rdi`      |

Todas elas têm de ter um sufixo que indique o tamanho da operação:

| sufixo | tamanho          |
|--------|------------------|
| `b`    | byte             |
| `w`    | word (2 bytes)   |
| `d`    | dword (4 bytes)  |
| `q`    | qword (8 bytes)  |

Todas as instruções de string também modificam os endereços em `rsi` e/ou `rdi` (apenas nos registos que a instrução usa).
Por predefinição, incrementam os endereços pelo tamanho da operação.

O prefixo `rep` pode ser adicionado a qualquer das instruções de string acima para a repetir um número de vezes igual a `rcx`.
~~~~

## 1. Obter a primeira letra de um verso

Para determinares as letras da palavra-passe da porta da frente, tens de responder com a primeira letra do verso do poema que o guarda te recita.

Para chegarem a uma palavra-passe bonita, os membros do clube de poesia gostam de usar poemas _acrósticos_.
Isto significa que a primeira letra de cada verso forma uma palavra.
Aqui está um exemplo de um dos seus escritores preferidos, Michael Lockwood.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Por isso, quando o guarda recitar **Stands so high**, respondes **S**; quando o guarda recitar **Huge hooves too**, respondes **H**.

Implementa a função `front_door_response` que recebe como argumento o endereço de memória de um verso do poema e devolve a primeira letra desse verso.
Essa letra tem de ser devolvida como um caráter codificado em ASCII, ocupando 1 byte.

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. Capitalizar uma palavra

Agora que tens todas as letras corretas, só precisas de capitalizar corretamente a palavra para obteres a palavra-passe da porta da frente.

Implementa a função `front_door_password` que recebe como argumento o endereço de memória de uma string que contém apenas as letras combinadas que encontraste na tarefa 1.
Deve modificar a string de entrada [in-place][in-place], para que fique corretamente capitalizada.
Isto significa que a string correta deve ficar guardada na mesma posição de memória da entrada.

A função não tem valor devolvido.

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. Obter a última letra de um verso

Para determinares as letras da palavra-passe da porta de trás, tens de responder com a última letra do verso do poema que o guarda te recita.

Os membros do clube de poesia são mesmo espertos.
O poema mencionado antes também é _teléstico_, o que significa que a última letra de cada verso também forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recitar **Stands so high**, respondes **h**; quando o guarda recitar **Huge hooves too**, respondes **o**.

Repara que, às vezes, o guarda faz pausas estilísticas (sob a forma de pontuação ou de espaços em branco) ao recitar o poema.
Tens de ignorar essas pausas para obteres a letra correta.

Implementa a função `back_door_response` que recebe como argumento o endereço de memória de um verso do poema e devolve a última letra desse verso.
Essa letra tem de ser devolvida como um caráter codificado em ASCII, ocupando 1 byte.

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. Sê educado

Para entrares no clube de poesia pela porta de trás, tens de ser especialmente educado.
Por isso, para obteres a palavra-passe, desta vez tens de capitalizar corretamente a palavra e acrescentar `", please."` no fim.

Implementa a função `back_door_password` que aceita como argumentos, por esta ordem:

1. O endereço de memória de um buffer onde será guardada a string resultante.
2. O endereço de memória de uma string que contém as letras combinadas que encontraste na tarefa 3.

A função deve guardar a versão educada da palavra-passe capitalizada no [buffer][buffer].
Um _buffer_ é um array que pode ser usado para guardar valores em memória, de modo a movê-los entre funções diferentes.

Esta função não tem valor devolvido.

```c
back_door_password("horse");
// => "Horse, please."
```
