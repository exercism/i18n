# Sobre

Em Rust, os métodos são funções definidas para uma struct (ou um `enum` ou um objeto `trait`).
Isto muda a forma de chamada: em vez de `frobnicate(foo)`, um método é chamado como `foo.frobnicate()`.

Os métodos são semelhantes às funções: são declarados com a palavra-chave `fn`,
têm um nome e podem ter parâmetros e valores devolvidos.

Ao contrário das funções, o primeiro parâmetro de um método é sempre `self` (ou uma variante),
que representa a instância da struct sobre a qual o método está a ser chamado (mais detalhes abaixo).

Vamos criar um `enum` para as casas de Hogwarts e uma `struct` que descreve a `age` e a `house` de um feiticeiro:

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## Definir métodos

Para definir métodos para a struct `Wizard`, começamos um bloco `impl` (abreviatura de implementation) para `Wizard`.

```rust
impl Wizard { }
```

Tudo o que está dentro deste bloco `impl` fica associado ao tipo `Wizard`.
Repara que uma struct pode ter vários blocos `impl`.

### Usar `self`

Um método tem de ter um parâmetro chamado `self`, do tipo `Self`, como primeiro parâmetro.
O tipo `Self` é um alias para o tipo a que o bloco `impl` diz respeito.
No nosso exemplo, `Self` representa `Wizard`.

Por conveniência, o Rust permite-nos abreviar isto escrevendo apenas o nome `self` no lugar do primeiro parâmetro.
Os tipos de `self` mais comuns nos métodos são:

- `self`: Abrevia `self: Self`. A assinatura apenas com `self` consome a instância.
- `&self`: Abrevia `self: &Self`. Isto faz um empréstimo imutável da instância.
- `&mut self`: Abrevia `self: &mut Self`. Isto faz um empréstimo mutável da instância.

Em código mais avançado, podes também encontrar assinaturas como `self: Pin<&self>`, `self: Rc<Self>`, etc.
Isto, no entanto, está fora do âmbito deste tutorial.

### Definir um método com `&self`

Se quisermos implementar um método `info` para mostrar a informação básica do feiticeiro,
podemos defini-lo dentro de um bloco `impl` para `Wizard`:

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

Repara que, na assinatura de `info`, fazemos um empréstimo imutável da instância com `&self`.
Assim, podemos ler os campos `age` e `house` de uma instância de `Wizard` sem os alterar.
Se tivéssemos usado um `self` que consome a instância em vez de um empréstimo, a instância ficaria inacessível depois de o método ser chamado.

Com o método `info` implementado, podemos imprimir a informação básica de um feiticeiro:

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### Definir um método com `&mut self`

Se quisermos implementar um método que altera os campos de uma instância de uma struct,
fazemos um empréstimo mutável da instância com `&mut self` na assinatura do método.

Digamos que queremos criar uma nova regra em Hogwarts que permita aos alunos mudar de casa.
Podíamos implementar um método `switch_house` da seguinte forma:

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

Agora podemos trocar a casa de um feiticeiro que estuda em Hogwarts:

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## Vários blocos 'impl'

Em Rust, cada item pode ter vários blocos `impl`.
Por isso, podemos agrupar todos os métodos no mesmo bloco `impl` ou ter vários blocos `impl` para grupos diferentes de métodos.
Ambas as abordagens são sintaxe válida, mas a organização típica de um projeto usa um único bloco `impl` por cada conjunto distinto de restrições `where` ao nível do `impl`.

## Funções associadas

É possível definir funções dentro de um bloco `impl` que não contêm um parâmetro `self`.
Como não têm o parâmetro `self`, não são métodos.
No entanto, continuam associadas ao tipo implementado e são chamadas nomeando esse tipo.
Por esse motivo, chamam-se funções associadas (ou funções associadas a um tipo).

Já viste algumas funções associadas, como `String::from()`:

```rust
let some_string = String::from("This is an associated function but not a method");
```

Os construtores são frequentemente implementados como funções associadas.
Vamos criar uma função `new` associada ao tipo `Wizard`:

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

Repara que podemos usar `Self` em vez de `Wizard` para indicar o tipo que será devolvido pela função.
Não é obrigatório usar o alias de tipo `Self` desta forma, mas pode simplificar a implementação em tipos com nomes complicados ou extensos.
Agora podemos executar o seguinte:

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
