# Sobre

Um ciclo `do-while` é uma alternativa a um ciclo `while`, e a única diferença é que um `do-while` é executado pelo menos uma vez:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

Os casos em que faz sentido usar um ciclo `do-while` são muito raros, por isso usa-se antes o `while` normal.
