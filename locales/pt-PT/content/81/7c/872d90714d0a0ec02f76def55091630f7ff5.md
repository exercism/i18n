# Instruções

A tua tarefa é descobrir se uma frase é um pangrama.

Um pangrama é uma frase que usa todas as letras do alfabeto pelo menos uma vez.
Não se distingue maiúsculas de minúsculas, por isso não importa se uma letra é minúscula (por exemplo, `k`) ou maiúscula (por exemplo, `K`).

Neste exercício, uma frase é um pangrama se contiver cada uma das 26 letras do alfabeto inglês.
