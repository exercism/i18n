# Ajuda

Se tiveres dificuldades, podes recorrer a um dos seguintes recursos para obteres ajuda:

- [The Racket Reference](http://docs.racket-lang.org/reference/index.html)
- O [/r/racket](https://www.reddit.com/r/racket) é o subreddit do Racket.
- Podes usar o [StackOverflow](http://stackoverflow.com/questions/tagged/racket) para procurar o teu problema e ver se já foi respondido. Também podes fazer e responder a perguntas.
