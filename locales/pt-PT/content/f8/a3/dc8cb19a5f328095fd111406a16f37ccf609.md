# Instruções específicas do SQLite

* A coluna **candidates** contém uma lista de strings codificada em JSON.
  Exemplo:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* A coluna **result** deve conter também uma lista de strings codificada em JSON.

## Esquema da tabela

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
