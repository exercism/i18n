# Introdução

O JavaScript é uma linguagem dinâmica, que suporta estilos orientados a objetos, imperativos e declarativos (por exemplo, programação funcional).

## Variáveis

Há algumas formas principais de atribuir valores a nomes em JavaScript: usar variáveis ou constantes.
No Exercism, as variáveis escrevem-se sempre em [camelCase][wiki-camel-case]; as constantes escrevem-se em [SCREAMING_SNAKE_CASE][wiki-snake-case].
Não existe um guia oficial a seguir, e várias empresas e organizações têm guias de estilo diferentes.
_Escreve as variáveis como bem quiseres_.
A vantagem de as escrever da forma como os exercícios estão preparados é que ficam destacadas de forma diferente na interface web e na maioria dos IDEs.

Em JavaScript, as variáveis podem ser definidas com a palavra-chave [`const`][mdn-const], [`let`][mdn-let] ou [`var`][mdn-var].

Uma variável pode referenciar valores diferentes ao longo da sua vida quando usas `let` ou `var`.
Por exemplo, `myFirstVariable` pode ser definida e redefinida muitas vezes com o operador de atribuição `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

Ao contrário de `let` e `var`, as variáveis definidas com `const` só podem ser atribuídas uma vez.
Isto é usado para definir constantes em JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## Declarações de funções

Em JavaScript, as unidades de funcionalidade são encapsuladas em _funções_, normalmente agrupando funções no mesmo ficheiro se pertencerem umas às outras.
Estas funções têm parâmetros (para poderem receber argumentos) e podem _devolver_ um valor com a palavra-chave `return`.
As funções são invocadas com a sintaxe `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

Neste exemplo, o nome da função é `add`.
Tem dois parâmetros, `num1` e `num2`.
Devolve um valor: o resultado da expressão `num1 + num2`

Depois, a função `add` é _chamada_ com dois argumentos: `1` e `3`.
O resultado da função, o valor devolvido, é `4`.

```exercism/note
💡 Em JavaScript há _muitas_ formas diferentes de declarar uma função.
Algumas dessas outras formas parecem diferentes de usar a palavra-chave `function`.
O percurso tenta introduzi-las gradualmente, mas se já as conheces, sente-te à vontade para usar qualquer uma delas.
Na maioria dos casos, usar uma ou outra não é melhor nem pior.
```

## Expor a Outros Ficheiros

Para tornar uma `function`, uma constante ou uma variável disponível em _outros ficheiros_, é preciso [exportá-las][mdn-export] com a palavra-chave `export`.
Outro ficheiro pode depois [importá-las][mdn-import] com a palavra-chave `import`.
Isto também é conhecido como o sistema de módulos.

Um bom exemplo é como funcionam todos os testes.
Cada exercício tem pelo menos um ficheiro, por exemplo `lasagna.js`, que contém a _implementação_.
A _implementação_ é `export`ada do ficheiro, ficando disponível para importar noutro ficheiro.
Além disso, há pelo menos outro ficheiro, por exemplo `lasagna.spec.js`, que contém os _testes_.
Este ficheiro faz `import` das entidades públicas (ou seja, `export`adas) para poder testar a implementação:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
