# Introdução

Está na altura de abordar um dos paradigmas centrais do C++: a programação orientada a objetos (POO).
A POO gira em torno de `classes`: tipos de dados definidos pelo utilizador, com o seu próprio conjunto de funções relacionadas.
Vamos começar pelo básico e abordaremos temas mais avançados mais adiante na árvore do programa.

## Membros

As classes podem ter **variáveis membro** e **funções membro**.
São acedidas através do operador de **seleção de membro** `.`.
Tal como acontece com as variáveis fora das `classes`, é aconselhável inicializar as variáveis membro com um valor na declaração.
Esse valor torna-se então o valor predefinido dos objetos criados a partir desta classe.

## Encapsulamento e ocultação de informação

As classes oferecem a opção de restringir o acesso aos seus membros.
Os dois casos básicos são `private` e `public`.
Os membros `private` não são acessíveis a partir de fora da classe.
Os membros `public` podem ser chamados livremente.
Todos os membros são `private` por predefinição e têm de ser marcados explicitamente para poderem ser usados fora da classe.

## Exemplo básico

A definição de uma nova `class` pode ver-se no exemplo seguinte.
Repara no `;` depois da definição.

```cpp
class Wizard {
  public:               // from here on all members are accessible publicly
    int cast_spell() {  // defines the public member function cast_spell
      return damage;
    }
    std::string name{}; // defines the public member variable `name`
  private:              // from here on all members are private
    int damage{5};      // defines the private member variable `damage`
};

```

Podes aceder a todas as variáveis a partir de dentro da classe.
Repara em `damage` dentro da função `cast_spell`.
Não podes ler nem alterar membros `private` fora da classe:

```cpp
Wizard silverhand{};
// calling the `cast_spell` function is okay, it is public:
silverhand.cast_spell();
// => 5

// name is public and can be changed:
silverhand.name = "Laeral";

// damage is private:
silverhand.damage = 500;
 // => Compilation error
```

## Construtores

Os construtores oferecem a possibilidade de atribuir valores às variáveis membro na criação do objeto.
Têm o mesmo nome da `class` e não têm tipo de retorno.
Uma classe pode ter vários construtores.
Isto é útil se nem sempre precisares de definir todas as variáveis.

```cpp
class Wizard {
  public:
    Wizard(std::string new_name) {
      name = new_name;
    }
    Wizard(std::string new_name, int new_damage) {
      name = new_name;
      damage = new_damage;
    }
    int cast_spell() {
      return damage;
    }
    std::string name{};
  private:
    int damage{5};
};

Wizard el{"Eleven"};       // deals  5 damage
Wizard vecna{"Vecna", 50}; // deals 50 damage
```

Os construtores são um tema vasto e têm muitas nuances.
Se não definires explicitamente um `constructor` para a tua `class`, então (e só então) o compilador faz esse trabalho por ti.
Foi o que aconteceu no primeiro exemplo acima.
O objeto _silverhand_ é criado através da chamada ao construtor predefinido, sem argumentos.
Todas as variáveis ficam com o valor indicado na definição da classe.
Se não tivesses indicado valores nessa definição, as variáveis poderiam ficar por inicializar, o que pode ter consequências indesejadas.

## Structs

As structs vêm das raízes originais da linguagem em C e são tão antigas como o próprio C++.
São, na prática, a mesma coisa que as `classes`, com uma exceção importante.
Por predefinição, tudo numa `class` é `private`.
As structs, por outro lado, são `public` até serem definidas em contrário.
Convencionalmente, a palavra-chave `struct` é frequentemente usada para **estruturas só com dados**.
A palavra-chave `class` é preferida para objetos que precisam de garantir certas propriedades.
Um desses invariantes poderia ser que o `damage` da tua `class` `Wizard` nunca fique negativo.
A variável `damage` é privada e qualquer função que altere o damage garantiria que o invariante se mantém.
