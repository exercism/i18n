# Dicas

## Geral

- Lê sobre aritmética básica no [guia Getting Started][getting-started-basic-arithmetic] oficial.
- Explora os módulos [`Float`][float-functions] e [`Kernel`][kernel-arithmetic-operators] para conheceres as funções e os operadores que trabalham com números de vírgula flutuante.

## 1. Calcula o valor diário a partir de um valor por hora

- As [operações aritméticas básicas][kernel-arithmetic-operators] em que um argumento é um número inteiro e o outro é um número de vírgula flutuante devolvem um número de vírgula flutuante.

## 2. Calcula um preço com desconto

- As [operações aritméticas básicas][kernel-arithmetic-operators] em que um argumento é um número inteiro e o outro é um número de vírgula flutuante devolvem um número de vírgula flutuante.

## 3. Calcula o valor mensal a partir de um valor por hora e de um desconto

- Existe uma [função incorporada][kernel-trunc] para converter números de vírgula flutuante em números inteiros.
- Existe uma [função incorporada][float-ceil] para arredondar números de vírgula flutuante por excesso.

## 4. Calcula o número de dias de trabalho a partir de um orçamento, de um valor por hora e de um desconto

- Existe uma [função incorporada][float-floor] para arredondar números de vírgula flutuante por defeito, com a precisão pretendida.
