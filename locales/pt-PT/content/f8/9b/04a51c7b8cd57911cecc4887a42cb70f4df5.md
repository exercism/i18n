# Sobre

Existem três tipos de vírgula flutuante em C#: `double`, `float` e `decimal`. O tipo mais utilizado é o `double`, enquanto o `decimal` é normalmente usado quando se trabalha com dados monetários. Um `double` escreve-se como `2.45` ou `2.45d`, um `float` como `2.45f` e um `decimal` como `2.45m`.

Cada tipo de vírgula flutuante tem a sua própria [precisão, intervalo aproximado e tamanho][docs-microsoft.com-characteristics-of-the-floating-point-types].

Algumas conversões entre tipos de vírgula flutuante são [automáticas (implícitas)][docs-microsoft.com-implicit-numeric-conversion], mas outras são [manuais (explícitas)][docs-microsoft.com-explicit-numeric-conversion].

```csharp
decimal account = 125m * (decimal)1.2f;
```

Tem sempre cuidado ao verificar a igualdade de valores de tipos de vírgula flutuante, porque valores que podem parecer representar o mesmo valor podem, na verdade, ser diferentes. Vê [este artigo][docs.microsoft.com_precision-in-comparisons] para mais informações.

Podes encontrar uma breve introdução aos números de vírgula flutuante em [0.30000000000000004.com][0.30000000000000004.com]. A [página Float Toy][evanw.github.io-float-toy] tem uma boa explicação gráfica de como os bits de um número de vírgula flutuante são convertidos num valor de vírgula flutuante propriamente dito.
