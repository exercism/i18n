# Instruções

A tua amiga Li Mei gere um bar de sumos onde vende deliciosos sumos de várias frutas.
És um cliente frequente na loja dela e percebeste que podias facilitar a vida à tua amiga.
Decides usar as tuas competências de programação para ajudar a Li Mei no trabalho dela.

## 1. Determina quanto tempo demora a fazer um sumo

A Li Mei gosta de dizer aos clientes, com antecedência, quanto tempo têm de esperar por um sumo da ementa que encomendaram.
Tem dificuldade em lembrar-se dos números exatos porque o tempo que demora a misturar os sumos varia:

| ID  | Bebida                  | Tempo |
| --- | ----------------------- | ----- |
| 1   | Pura Alegria de Morango | 1     |
| 2   | Energizante             | 3     |
| 3   | Jardim Verde            | 3     |
| 4   | Ilha Tropical           | 4     |
| 5   | Tudo ou Nada            | 5     |
| 6   | Sentir-se Bem           | 4     |
| 7   | Especial de Hoje        | 7     |
| 8   | Escolha do Cliente      | 10    |

Escreve uma função `time_to_make_juice` que recebe um ID de um sumo, como número de 32 bits, e devolve o tempo que demora a fazer o sumo, também como número de 32 bits.

```c
time_to_make_juice(2);
// => 3
```

## 2. Determina quanto tempo demora a fazer todos os sumos encomendados

A Li Mei precisa de reabastecer as suas provisões periodicamente, por isso precisa de saber com antecedência quanto tempo vai demorar a preparar todos os pedidos que tem disponíveis no momento.

Para ajudar a tua amiga, escreve uma função `time_to_prepare` que recebe um array com os IDs de cada sumo encomendado e o número de sumos do array.
Esta função deve devolver o tempo total necessário para preparar todas as bebidas do array.

Podes considerar que cada ID, o número de IDs do array e o valor devolvido são todos números de 32 bits.
O resultado cabe sempre num número de 32 bits.

```c
time_to_prepare({2, 3, 8}, 3);
// => 16
```

## 3. Reabastece a reserva de gomos de lima

Muitas das criações da Li Mei incluem gomos de lima, seja como ingrediente, seja como decoração.
Por isso, quando começa o turno de manhã, tem de garantir que o recipiente dos gomos de lima está cheio para o dia que se segue.

Implementa a função `limes_to_cut`, que recebe o número de gomos de lima que a Li Mei precisa de cortar, um array que representa a reserva de limas inteiras que tem à mão e o número de limas do array.

Cada lima é representada no array por um caráter com o seu tamanho.
Limas de tamanhos diferentes dão à Li Mei um número diferente de gomos:

| Tamanho | Gomos |
| ------- | ----- |
| 'S'     | 6     |
| 'M'     | 8     |
| 'L'     | 10    |

~~~~exercism/note
Um caráter é um número de 8 bits e pode ser usado como qualquer número de 8 bits:

| Caráter | Valor |
|---------|-------|
| 'S'     | 83    |
| 'M'     | 77    |
| 'L'     | 76    |

Também pode ser usado diretamente nas instruções, sendo equivalente ao seu valor:

```x86asm
mov dl, 'S'
cmp cl, 'M'
```
~~~~

A Li Mei corta sempre as limas pela ordem em que aparecem no array, começando pelo primeiro elemento.
Continua até atingir o número de gomos de que precisa ou até ficar sem limas.

A Li Mei gostaria de saber com antecedência quantas limas precisa de cortar.

Podes considerar que o número de gomos necessários, o número de limas do array e o valor devolvido são todos números de 32 bits.
O resultado cabe sempre num número de 32 bits.

```c
limes_to_cut(25, {'S', 'S', 'L', 'M', 'S'}, 5);
// => 4
```

## 4. Termina o turno

A Li Mei trabalha sempre até às 15h.
Depois, é o seu empregado Dmitry que assume.
Muitas vezes, há bebidas que foram encomendadas mas que ainda não estão preparadas quando o turno da Li Mei acaba.
O Dmitry prepara então os sumos que faltam.

Para facilitar a passagem de turno, implementa a função `remaining_orders`, que recebe:

- O número de minutos que faltam para o turno da Li Mei acabar.
- Um array com os IDs de cada sumo encomendado que ainda não foi preparado.

A função deve devolver o número de pedidos que a Li Mei preparou antes do fim do seu dia de trabalho.

O tempo que falta para o turno acabar é sempre maior do que 0.
O array de sumos a preparar nunca está vazio e o turno acaba sempre antes de se chegar ao fim do array.
Além disso, os pedidos são preparados pela ordem em que aparecem no array.
Se a Li Mei começa a misturar um sumo, acaba-o sempre, mesmo que tenha de trabalhar mais um pouco.

Podes considerar que o número de minutos que faltam, cada ID do array e o valor devolvido são todos números de 32 bits.
O resultado cabe sempre num número de 32 bits.

```c
remaining_orders(5, {5, 5, 3});
// => 1
```
