# Introdução

## Argumentos com etiqueta

Por vezes, quando uma função recebe muitos argumentos, pode ser difícil lembrarmo-nos da ordem em que devem ser indicados. Para facilitar a leitura, o Gleam permite etiquetar os argumentos com um nome.

Para etiquetar um argumento, indica o nome da etiqueta antes do nome do argumento, separados por um espaço.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Ao chamar uma função com argumentos etiquetados, podes indicar os argumentos por qualquer ordem. Todas estas chamadas a `replace` são equivalentes:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

As etiquetas são sempre opcionais. Mesmo que uma função tenha argumentos etiquetados, podes continuar a chamá-la sem etiquetas.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
