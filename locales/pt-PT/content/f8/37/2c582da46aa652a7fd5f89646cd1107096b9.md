# Conceitos de Luhn

O Luhn é um algoritmo de validação que combina afirmações textuais e numéricas. As soluções em Rust privilegiam abordagens funcionais.

## Geral

### primitivos

- `&str` e `char`
  - os estudantes têm de perceber a distinção entre um `char` individual e uma `&str`, para excluir ou incluir corretamente partes do parâmetro de entrada
- número inteiro
  - compreender os números inteiros é importante para fazer a validação numérica necessária
- Boolean
  - essenciais para afirmações de identidade e comparações finais

### características dos iteradores

- encadeamento
  - é importante compreender as cadeias de iteradores aqui, para resolver o problema de forma ordenada.
- `map`, `filter`, turbofish e possivelmente `fold`
  - combinar map e filter dá um padrão de projeto fundamental para problemas de validação como este. As soluções com `fold` são também mais concisas.
  - o turbofish é necessário em algumas soluções para dizer ao Rust que tipo estás a criar a partir de uma expressão encadeada

## Solução de exemplo 1

a [solução](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d) do york

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## Solução de exemplo 2

Canónica

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
