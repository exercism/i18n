# Anexo às instruções

## Registos

| Registo | Utilização | Tipo    | Descrição                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | entrada     | inteiro | número do quadrado, no intervalo 1..64           |
| `$v0`    | saída     | inteiro | os 32 bits menos significativos da saída         |
| `$v1`    | saída     | inteiro | os 32 bits mais significativos da saída          |
| `$t0-9`  | temporário | qualquer     | para armazenamento temporário                    |
