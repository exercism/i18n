# Instruções específicas de SQLite

Este exercício requer que definas a coluna `result` da tabela `etl` com o valor correto, com base no objeto JSON que se encontra na coluna `input`. As chaves do objeto de resultado têm de estar ordenadas alfabeticamente.

## Esquema da tabela

```sql
CREATE TABLE "etl" ("input" TEXT, "result" TEXT);
```
