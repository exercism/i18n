# Instalação

## Mac

Instala com o Homebrew através de `brew install swi-prolog`.
Em alternativa, descarrega o código-fonte para a tua máquina a partir do [site do SWI Prolog](http://www.swi-prolog.org/download/devel).

## Windows

Descarrega o código-fonte para a tua máquina a partir do [site do SWI Prolog](http://www.swi-prolog.org/download/devel).

## Linux

Segue as instruções para a tua distribuição [aqui](http://www.swi-prolog.org/build/unix.html).
