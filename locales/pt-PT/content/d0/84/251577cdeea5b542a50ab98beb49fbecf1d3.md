# Sobre

## Vários valores devolvidos

Em Swift, as funções podem [devolver vários valores][multiple-return-values] ao devolver um tuplo:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    return (reverse: String(str.reversed()), length: str.count)
}

let result = reverseAndLength("Hello")
print(result.reverse) // Prints "olleH"
print(result.length)  // Prints 5
```

## Omitir a palavra-chave `return`

Quando o corpo de uma função é constituído por uma única expressão, podes [omitir a palavra-chave `return`][implicit-returns]:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    (reverse: String(str.reversed()), length: str.count)
}
```

Esta sintaxe de return implícito aplica-se a todas as funções que devolvem um valor, não apenas às que devolvem tuplos.
