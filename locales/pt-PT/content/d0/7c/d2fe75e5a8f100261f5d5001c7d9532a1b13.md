# Introdução

`Nil` em Gleam é um tipo com um único valor, também chamado `Nil`. É semelhante a `void` noutras linguagens, no sentido em que é usado quando uma função não tem nenhum valor mais adequado para devolver.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Em Gleam, os valores não são «nil-áveis» nem «anuláveis» como nalgumas outras linguagens. Um valor só pode ser `Nil` se o seu tipo for `Nil`, e um valor de qualquer outro tipo nunca pode ser `Nil`.
