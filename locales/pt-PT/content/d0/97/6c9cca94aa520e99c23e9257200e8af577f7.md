# Testes

Para correres os testes, executa o comando `go test` dentro do diretório do exercício.

Se o conjunto de testes incluir benchmarks, podes executá-los com as flags `--bench` e `--benchmem`:

    go test -v --bench . --benchmem

Tem em atenção que cada revisor vai correr os benchmarks numa máquina diferente, com especificações diferentes, por isso os resultados destes testes de benchmark podem variar.
