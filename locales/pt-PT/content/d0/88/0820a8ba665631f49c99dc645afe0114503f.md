# Instruções

Neste exercício vais escrever código para ajudar um freelancer a comunicar com um gestor de projeto, fornecendo alguns utilitários que calculam rapidamente tarifas diárias e mensais, opcionalmente com um determinado desconto.

Primeiro, estabelecemos algumas regras entre o freelancer e o gestor de projeto:

A tarifa diária é 8 vezes a tarifa horária.
Um mês tem 22 dias faturáveis.
O freelancer propõe aplicar um desconto se o gestor de projeto optar por deixar o freelancer faturar mensalmente, o que pode dar jeito se houver um determinado orçamento com que o gestor de projeto tenha de trabalhar.

Os descontos são representados como números fracionários que correspondem a percentagens, por exemplo 25.0 (25%).

## 1. Calcula a tarifa diária a partir de uma tarifa horária

Implementa uma função que calcula a tarifa diária a partir de uma tarifa horária:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

A tarifa diária devolvida deve ser um número de vírgula flutuante.

## 2. Calcula um preço com desconto

Implementa uma função que calcula o preço depois de aplicar um desconto.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

O valor devolvido deve ser sempre um número de vírgula flutuante, sem qualquer arredondamento.

## 3. Calcula a tarifa mensal a partir de uma tarifa horária e de um desconto

Implementa uma função que calcula a tarifa mensal e aplica um desconto:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

A tarifa mensal devolvida deve ser arredondada para cima (por excesso) até ao inteiro mais próximo.

## 4. Calcula o número de dias de trabalho a partir de um orçamento, de uma tarifa horária e de um desconto

Implementa uma função que recebe um orçamento, uma tarifa horária e um desconto, e calcula quantos dias de trabalho isso cobre.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

O número de dias devolvido deve ser arredondado para baixo (por defeito) a uma casa decimal.
