# Testes

Para correr os testes, executa o seguinte comando:

```bash
make
```

## Testes ignorados

Resolver um exercício significa fazer passar todos os seus testes.
Por predefinição, só um teste (o primeiro) é executado quando corres os testes.
Isto é intencional, pois permite-te concentrar-te apenas em fazer passar esse único teste.
Quando esse teste passar, podes ativar o teste seguinte removendo a linha `TEST_IGNORE()`.
Quando tiveres ativado todos os testes e a tua implementação os fizer passar todos, resolveste o exercício!
