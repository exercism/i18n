# marcador de posição

## Como resolver com bash

O `bash` não tem formas integradas de **analisar** strings de data e hora.
Este exercício obriga-te a recorrer a um utilitário externo.

* A opção `-d` do comando `date` do GNU consegue analisar [uma grande variedade de formatos][gnu-date].
* Se usas Mac, vê o [comando `date` do BSD][bsd-date] e a sua opção `-f`.
* O Perl está amplamente disponível, e o seu [módulo `Time::Piece`][time-piece] pode ser usado para analisar timestamps.

O bash consegue **formatar** datas sem ferramentas externas.
Dado um valor de tempo inteiro (segundos desde a época), [o formatador `%()T` do `printf`][bash-printf] consegue aplicar formatação ao estilo "strftime".

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```
