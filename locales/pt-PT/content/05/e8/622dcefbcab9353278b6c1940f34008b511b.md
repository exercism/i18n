# Instruções

Neste exercício vais escrever algum código para te ajudar a fazer uma lasanha fantástica a partir do teu livro de receitas preferido.

Tens quatro tarefas, todas relacionadas com o tempo gasto a cozinhar a lasanha.

## 1. Define o tempo esperado no forno em minutos

Define uma constante chamada `$expected_minutes_in_oven`.
De acordo com o livro de receitas, o tempo esperado no forno é de 40 minutos:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. Calcula o tempo restante no forno em minutos

Este valor recebe como valor de entrada os minutos reais que a lasanha já passou no forno e devolve quantos minutos a lasanha ainda tem de ficar no forno, com base no tempo esperado no forno em minutos da tarefa anterior.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. Calcula o tempo de preparação em minutos

O tempo de preparação é quanto demora a preparar a lasanha antes de a colocar no forno.
Demora 2 minutos a preparar cada camada.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. Calcula o tempo total de trabalho em minutos

Calcula quantos minutos, no total, dedicaste a cozinhar a lasanha.
É a soma do tempo de preparação em minutos com o tempo, em minutos, que a lasanha já passou no forno até agora.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
