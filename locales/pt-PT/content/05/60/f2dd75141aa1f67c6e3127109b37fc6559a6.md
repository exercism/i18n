# Instalação

- macOS: corre `brew install futhark`
- linux: corre `brew install futhark`
- Windows: usa o WSL ou segue [as instruções específicas para Windows][windows-specific-instructions]

Encontras métodos de instalação alternativos nas [instruções de instalação oficiais][instructions].

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
