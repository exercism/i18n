# Dicas

## 1. Cria um novo quadro de recordes

- Cria um novo objeto com chavetas.
- Escreve a chave como uma string, para que a chave possa conter espaços.
- Separa a chave e o valor com dois pontos.

## 2. Adiciona jogadores a um quadro de pontuações

- Usa a notação de parênteses retos para adicionar uma chave com um nome que está guardado numa variável (o argumento).
- Usa o operador de atribuição (`=`) para definir um valor para a nova chave.
- Em alternativa, usa o [operador `+`][man-plus] para juntar o objeto recebido a um novo.
- Lembra-te de que são precisos parênteses à volta das expressões das chaves de objetos.

## 3. Remove jogadores de um quadro de pontuações

- Usa a [expressão del][man-del].
- Faz referência à chave como fizeste na tarefa anterior (notação de parênteses retos).
- Lembra-te de que o argumento de `del` é uma _expressão de índice_ e não apenas uma string.

## 4. Aumenta a pontuação de um jogador

- Primeiro, pensa em como expressar o novo valor que queres atribuir.
- Depois, usa o operador de atribuição como na tarefa 2, para definir esse novo valor.
- Se ainda não o fizeste, podes usar o [operador de atribuição aritmética][man-update-assignment] `+=`.

## 5. Aplica os pontos de bónus de segunda-feira

- Este é um bom sítio para usar `to_entries`/`from_entries`, ou `with_entries` para iterar sobre o objeto
- Para cada chave, define o novo valor como fizeste na tarefa 4.

## 6. Encontra a pontuação total

- Queremos iterar sobre os _valores_ do objeto.
  Podemos usar [`map_values`][man-map_values] ou [`.[]`][man-brackets] para produzir um fluxo de valores.
- A expressão `add` pode ser usada para calcular a soma de uma lista de números.
