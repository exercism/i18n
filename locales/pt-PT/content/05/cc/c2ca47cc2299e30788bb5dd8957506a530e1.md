# Testes

## Testar interativamente

Inicia o REPL a partir do diretório para onde descarregaste o exercício.

Podes correr os testes ao carregar o ficheiro de testes para o REPL com `(load "exercise-test")` (substitui "exercise" pelo nome adequado). Depois, avalia `(exercise-test:run-tests)` para correr todos os testes.

Se escreveres o código diretamente no REPL, basta avaliar `(exercise-test:run-tests)`.

Se escreveres o código no ficheiro Lisp do exercício, carrega-o com `(load "exercise")` e depois avalia `(exercise-test:run-tests)`.

## Testar a partir da linha de comandos

Podes lançar os testes com esta invocação na linha de comandos (mais uma vez, substitui "exercise" pelo nome adequado em dois sítios)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
