# Introdução

As classes são um elemento fundamental dos programas em Swift.
Permitem agrupar propriedades (dados) e métodos (funções) relacionados em unidades de funcionalidade autónomas.

### Definir classes

Para definir uma classe, usa a palavra-chave `class` seguida do nome da classe, com a definição da classe entre chavetas:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

O corpo de uma classe pode conter propriedades armazenadas, que são definidas e se comportam como constantes (`let`) ou variáveis (`var`) normais.

### Instâncias

Uma definição de classe funciona como um modelo: define um novo tipo e descreve o aspeto dos seus valores, mas não cria instâncias por si só.

Para criar uma *instância* de uma classe, chama o seu inicializador escrevendo o nome da classe seguido de parênteses:

```swift
let someCharacter = GameCharacter()
```

Isto cria uma nova instância cujas propriedades são inicializadas com os valores predefinidos especificados na definição da classe.
Nas propriedades opcionais sem valores predefinidos explícitos (como `name`), o Swift atribui-lhes `nil` por predefinição.

### Aceder às propriedades

Acedes às propriedades de uma instância com a *notação de ponto*: escreve o nome da instância, um ponto (`.`) e o nome da propriedade.
A notação de ponto também funciona para propriedades aninhadas.

Podes usar a notação de ponto para ler valores e, se a propriedade for mutável (`var`), atribuir novos valores:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Métodos

Além das propriedades, as classes podem definir *métodos*: funções associadas à classe.

Define os métodos dentro do corpo da classe com a sintaxe `func` habitual.
Se um método modificar uma propriedade, essa propriedade tem de ser declarada com `var`:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Chama os métodos de uma instância com a notação de ponto, tal como fazes com as propriedades:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Cada instância de uma classe tem uma propriedade implícita chamada `self`, que se refere à própria instância.
Embora seja frequentemente omitido ao referir propriedades ou métodos, o `self` é normalmente usado para distinguir entre nomes de propriedades e nomes de parâmetros de métodos quando partilham o mesmo nome.
