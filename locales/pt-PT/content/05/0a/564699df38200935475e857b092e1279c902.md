# Dicas

## 1. Geral

- Lê sobre ficheiros no [guia oficial de primeiros passos][getting-started-file].
- Lê sobre ficheiros em [joyofelixir.com][joy-of-elixir-file].
- Dá uma vista de olhos à [documentação do módulo `File`][file].

## 1. Ler endereços de email de um ficheiro

- Existe uma [função incorporada][file-read] para ler o conteúdo de um ficheiro de uma só vez.

## 2. Abrir um ficheiro de registo para escrita

- Existe uma [função incorporada][file-open] para abrir um ficheiro.
- O segundo argumento dessa função é uma lista de modos que permite especificar que o ficheiro deve ser aberto para escrita.

## 3. Registar um email enviado

- As funções para ler e escrever num ficheiro aberto com [`File.open!/1`][file-open] estão no módulo [`IO`][io].
- Existe uma [função incorporada][io-puts] para escrever uma string num ficheiro, seguida de uma nova linha.

## 4. Fechar o ficheiro de registo

- Existe uma [função incorporada][file-close] para fechar um ficheiro.

## 5. Enviar a newsletter

- Todas as operações necessárias sobre ficheiros já foram implementadas nos passos anteriores.
- Antes de escrever num ficheiro, é preciso abri-lo.
- Depois de terminadas todas as operações de escrita num ficheiro, o ficheiro deve ser fechado.
