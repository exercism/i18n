# Anexo às instruções

## Lidar com casos limite

Linguagens diferentes no Exercism têm expetativas diferentes sobre qual deve ser o resultado se o comprimento das substrings for zero.
No percurso de Rust, não temos um teste para esse caso, por isso podes fazer o que achares mais adequado.

Considera as vantagens e as desvantagens das seguintes possibilidades:
- Rebentar o programa com `panic!`.
- Devolver um `Result::Err`. (não é possível aqui, porque a assinatura da função é fornecida)
- Devolver um vetor vazio.
- Devolver um vetor que contém tantas strings vazias como o comprimento da string "digits" **mais um**. (isto tem algumas propriedades matemáticas interessantes!)
