# Adenda às instruções

## Dicas

Uma das utilizações das tuplas é devolver vários valores a partir de uma função. Neste exercício, escreve uma função que devolve uma tupla (a parte x e y de uma coordenada).

Para mais informações sobre tuplas, consulta [esta ligação](https://docs.microsoft.com/en-us/dotnet/api/system.tuple).
