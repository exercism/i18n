## GNU awk e a aritmética de precisão arbitrária

Por omissão, os números em `awk` são representados como números de vírgula
flutuante de precisão dupla. Isto dá 53 bits de precisão (ver a [Tabela
16.3][table-16.3] no manual). Infelizmente, isto não chega para completar
este exercício (aviso de spoiler: um dos testes exige 63 bits de precisão).

Uma precisão insuficiente tem este aspeto:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

O GNU `awk` tem a capacidade de usar números de precisão arbitrária, desde que
as bibliotecas relevantes tenham sido compiladas no executável `awk`. Verifica
a tua versão do awk e procura por "GNU MPFR":
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

Se estiver presente, ativa essa capacidade com a opção `-M`:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

E se o meu `awk` não tiver a opção `-M`? Vais ter de chamar um programa
externo capaz de fazer aritmética de precisão arbitrária, como o `bc`. Vê a
secção [Usar o getline numa variável a partir de um pipe][getline-pipe] para
veres um exemplo de como fazer isto.
