# Introdução

Um `bit` é o valor mais elementar da computação.
A palavra `bit` é a abreviatura de "binary digit", isto é, dígito binário.
É uma unidade de armazenamento de dados no ambiente de execução, suficientemente grande para conter um objeto que pode ter um de dois valores.
Como tal, tem um valor binário de `1` ou `0`.
Todos os outros tipos de dados são compostos por vários `bits`.
Por exemplo, um `byte` é habitualmente composto por oito `bits`.

## Máscaras de bits

Uma máscara de bits pode ser qualquer valor usado para definir bits individuais.
Por exemplo, o alfabeto inglês tem vinte e seis letras.
Um valor com pelo menos vinte e seis bits, como um inteiro sem sinal de 32 bits, pode ser usado como máscara de bits para definir uma condição `true` ou `false` para cada letra do alfabeto inglês.
Qualquer valor com bits suficientes para tratar um conjunto de condições `true` ou `false` pode servir de máscara de bits.
Definir e ler os bits individuais faz-se com operadores bit a bit.

## Operadores bit a bit

Digamos que queremos manter registo das letras que ocorrem numa `string`.
Para o nosso exemplo, vamos usar apenas as vinte e seis letras do alfabeto inglês.
A nossa máscara de bits será um inteiro sem sinal de 32 bits.
Um `0` representa que a letra não ocorre.
Um `1` representa que a letra ocorre uma ou mais vezes.
No início, a representação em bits da nossa máscara de bits será 32 `0s` seguidos: `00000000000000000000000000000000`.
A posição mais à direita será para `A`.
A segunda a contar da esquerda será para `B`, e assim por diante.
Imagina que estamos a processar todas as letras da string dentro de um ciclo, por isso queremos uma única linha de código que sirva para definir qualquer letra.

### Operador de deslocamento à esquerda bit a bit: uma forma de posicionar um bit

`<<` é o operador bit a bit de deslocamento para a esquerda.

Se a nossa letra for `A`, não queremos deslocar nada para a esquerda; mas se a nossa letra for `B`, queremos deslocar uma posição para a esquerda; e se a nossa letra for `C`, queremos deslocar duas posições para a esquerda, e assim por diante.
Embora possamos ver os `chars` como letras como `A` ou `B`, um `char` é implementado na memória como um tipo inteiro, por isso podemos fazer cálculos simples com um `char`.
Dada uma variável chamada `letter` que representa o `char` que estamos a processar, podemos deslocar para a esquerda o número de posições necessário deslocando `1` para a esquerda a diferença entre `letter` e o `char` `A`, assim: `1 << letter - 'A'`.
`A` - `A` é `0`, por isso deslocaria `0` posições para a esquerda se `letter` fosse `A`.
`B` - `A` é `1`, por isso deslocaria `1` posição para a esquerda se `letter` fosse `B`, e assim por diante.

### Operador OR inclusivo bit a bit: uma forma de definir um bit

Depois de sabermos _onde_ queremos definir um bit, podemos de facto defini-lo com o operador OR inclusivo bit a bit, que é `|`.
O resultado do operador `|` será `1` em cada posição em que o operando da esquerda ou o da direita tenha o bit definido.
Assim, o resultado de `0010 | 0001` seria `0011`.
(É importante lembrar que o valor é `11` em binário, mas é `3` em decimal.)
Para atribuir o resultado a um valor, o operador `|` pode ser combinado com o operador de atribuição para definir os bits assim: `|=`.
Para simplificar, o exemplo seguinte não usa um ciclo, mas demonstra como poderíamos processar as letras `ABA` numa máscara de bits.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Definimos a parte mais à direita da nossa máscara como `0001` para `A` e, em seguida, definimos a máscara como `0011` para `B`.
Definir outro `A` não altera a máscara existente.
Poderíamos ter evitado definir o bit outra vez se tivéssemos verificado se `A` já estava definido.

### Operador AND bit a bit: uma forma de ler um bit

`&` é o operador AND bit a bit.
O resultado do operador `&` será `1` em cada posição em que tanto o operando da esquerda como o da direita tenham o bit definido.
Assim, o resultado de `0011 & 0001` seria `0001`.
Podemos ver isto em ação no exemplo seguinte.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Operador OR exclusivo bit a bit: uma forma de inverter um bit

`^` é o operador OR exclusivo bit a bit.
Um operador OR _inclusivo_ implica que existe um operador OR _exclusivo_ com um comportamento diferente.
O resultado do operador `^` será `1` em cada posição em que _apenas um_ dos operandos, o da esquerda ou o da direita, tenha o bit definido.
Assim, o resultado de `0001 ^ 0011` seria `0010`.
O bit mais à direita não ficará definido porque _ambos_ os operandos têm `1` na posição mais à direita.
A operação OR exclusivo é por vezes representada como XOR.
Se o resultado de um valor sujeito a XOR for ele próprio sujeito a XOR, obtém-se o valor original.
Isto pode ser usado para uma encriptação muito simples, em que a mesma chave serve para encriptar e desencriptar os dados.
Por exemplo

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## Campos de bits

Já vimos como os bits empacotados num tipo de dados simples podem ser acedidos pela sua posição.
Os bits empacotados numa `struct` podem ser acedidos pelo nome.
Um tipo de dados assim chama-se `bit field`.
Um caso de uso para `bit fields` pode ser quando é preciso um conjunto de flags ON/OFF e se pretende minimizar o uso de memória.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

A sintaxe `unsigned int variable_name : 1;` cria um campo de `1` bit dentro de um `unsigned int` colocado na struct.
Em vez de um `unsigned int`, poderia usar-se um `signed int` ou, a partir do C99, um tipo `bool`.
Uma struct que contenha campos de bits também pode conter campos de outros tipos de dados, como `number_of_lights` no exemplo acima.
