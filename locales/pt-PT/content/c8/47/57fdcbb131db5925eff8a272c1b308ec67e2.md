# Instruções

A tua amiga Li Mei tem um bar de sumos onde vende deliciosos sumos de fruta mistos. És um cliente frequente na loja dela e apercebeste-te de que lhe podias facilitar um pouco a vida com algum código em Factor.

## 1. Determina quanto tempo demora a misturar um sumo

A Li Mei gosta de dizer aos clientes com antecedência quanto tempo têm de esperar por um sumo do menu. Tem dificuldade em lembrar-se dos números exatos porque o tempo que demora a misturar os sumos varia:

- `"Pure Strawberry Joy"` demora `0.5` minutos.
- `"Energizer"` e `"Green Garden"` demoram `1.5` minutos cada um.
- `"Tropical Island"` demora `3` minutos.
- `"All or Nothing"` demora `5` minutos.
- Todas as outras bebidas (por exemplo, ofertas especiais) demoram `2.5` minutos.

Define `time-to-mix-juice` para retirar o nome de um sumo da pilha e devolver o número de minutos que demora a misturar essa bebida.

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. Reabastece a reserva de gomos de lima

Muitas das criações da Li Mei incluem gomos de lima, seja como ingrediente, seja como parte da decoração. Por isso, quando começa o turno de manhã, tem de se certificar de que o recipiente de gomos de lima está cheio para o resto do dia.

Define `wedges-from-lime` para receber o tamanho de uma lima e devolver o número de gomos que ela produz: `6` a partir de uma lima `"small"`, `8` de uma `"medium"`, `10` de uma `"large"`.

De seguida, define `limes-to-cut` para receber o número de gomos `needed` e um array de `limes` (tamanhos das limas pela ordem de corte). Corta as limas uma a uma, pela ordem, e para assim que tiver gomos suficientes ou quando ficar sem limas. Devolve o número de limas que teve de cortar.

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. Lista os tempos de mistura de cada pedido na fila

A Li Mei gosta de saber quanto tempo vai demorar a misturar os pedidos que os clientes estão à espera.

Define `order-times` para receber um array de pedidos e devolver um array com o tempo de mistura de cada pedido, pela mesma ordem.

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. Termina o turno

A Li Mei trabalha sempre até às 3 da tarde. Depois, é o seu empregado Dmitry que assume o turno. Muitas vezes há bebidas que foram pedidas mas ainda não foram preparadas quando o turno da Li Mei termina; o Dmitry prepara então os sumos restantes.

Para facilitar a passagem de turno, define `remaining-orders` para receber o número de minutos `time-left` do turno da Li Mei e um array de `orders` (sumos que foram pedidos mas ainda não foram preparados). Devolve os pedidos que o Dmitry terá de assumir, ou seja, aqueles que a Li Mei não tem tempo de começar antes de o turno terminar.

`time-left` é sempre maior do que `0`. Os pedidos são preparados pela ordem em que aparecem no array. Quando a Li Mei começa um sumo, acaba-o sempre, mesmo que tenha de trabalhar um pouco mais. Se tiver tempo para começar todos os pedidos, devolve um array vazio.

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
