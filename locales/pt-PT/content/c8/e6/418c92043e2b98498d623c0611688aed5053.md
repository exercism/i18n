# Dicas

## 1. Extrair os erros

- Podes fazer correspondência de padrões com erros usando a sintaxe `Error(value)`.

## 2. Remover o prefixo da equipa

- Podes fazer correspondência de padrões com prefixos de string usando a sintaxe `"prefix" <> rest`.

## 3. Separar a região e a equipa

- Podes dividir uma string num caráter com a [função `string.split`][split].
- Podes fazer correspondência de padrões com listas usando a sintaxe `[a, b, c]`.

[split]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#split
