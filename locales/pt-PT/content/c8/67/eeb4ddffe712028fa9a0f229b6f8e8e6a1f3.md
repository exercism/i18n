# Acerca de

O operador ternário condicional serve para escrever uma expressão compacta que devolve um de dois valores alternativos, dependendo de uma condição.
É frequentemente designado apenas por «operador ternário».
O nome vem do facto de o operador ter três operandos: `predicate ? consequent-expression : alternative-expression`
Pode ser usado como alternativa a condicionais if-else curtas.

Tal como acontece com as condicionais `if`, o JavaScript faz uma conversão implícita de tipos para avaliar a condição.
Se a condição for verdadeira, é devolvido o operando à esquerda dos dois pontos.
Caso contrário, o resultado da expressão ternária é o operando à direita dos dois pontos.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
