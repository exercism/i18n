# Instruções

O Josh está a trabalhar num novo jogo de interpretação de papéis e precisa da tua ajuda para implementar algumas das mecânicas.

## 1. Define uniões de tipos

Define uma união de tipos de `String` e `Missing` com o nome `StringOrMissing`, que pode ser usada em código posterior.
Define uma união de tipos de `Int64` e `Nothing` com o nome `IntOrNothing`, que pode ser usada em código posterior.

## 2. Implementa o tipo composto Player

O tipo composto Player deve conter quatro campos, cada um com uma anotação de tipo e um valor predefinido:
- O `name` é um `StringOrMissing`, com um valor predefinido de `missing`
- O `level` é um `Int64`, com um valor predefinido de `0`
- O `health` é um `Int64`, com um valor predefinido de `100`
- O `mana` é um `IntOrNothing`, com um valor predefinido de `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. Apresenta-te

Implementa a função `introduce`.

Os jogadores furtivos podem estar a esconder o nome e serão apresentados como `"Mighty Magician"`.
Caso contrário, usa apenas o nome do jogador para o apresentar.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. Implementa os métodos de incremento

A função auxiliar `increment` tem dois métodos, cada um com uma assinatura de função diferente.
O argumento de cada um precisa de uma anotação de tipo para tornar a assinatura explícita.

O método `increment` para nomes deve receber o `name` de um jogador.
- Se o nome for `missing`, devolve o título "The Great".
- Caso contrário, o título " the Great" é acrescentado ao nome.

Este método `increment` devolve o novo nome.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

O método `increment` para mana deve receber o `mana` de um jogador.
- Se a mana do jogador for `missing`, devolve um valor de `50`.
- Caso contrário, a mana deve ser aumentada em `100`.

Este método `increment` devolve a mana atualizada.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. Implementa a função `title!`

O nível mais alto do jogo é `42`.  Para reconhecer o feito dos jogadores que alcançam este nível, é atribuído um título aos seus nomes.  A função `title!` atualiza o nome de um jogador da seguinte forma.

- Se o nível do jogador for 42, o nome é atualizado com a função `increment`.
- Caso contrário, o nome mantém-se inalterado.

Em qualquer dos casos, a função `title!` devolve o nome do jogador.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. Implementa a função `revive!`

A função `revive!` deve verificar que a personagem do jogador está mesmo morta (a sua saúde chegou a `0`).

Se o jogador estiver morto:
- O jogador deve ser reanimado com `100` de saúde.
- A mana do jogador deve ser incrementada com a função `increment`.

Se o jogador estiver vivo, não lhe acontece nada.

A função `revive!` deve devolver o jogador.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
