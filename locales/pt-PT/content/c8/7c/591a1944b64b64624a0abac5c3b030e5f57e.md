# Introdução

Existem basicamente dois tipos de ciclos:

1. Repetir até que se verifique uma condição.
2. Iterar sobre os elementos de uma coleção.

Ambos são possíveis em Julia, embora o segundo seja provavelmente mais comum.

## O ciclo `while`

Para problemas em aberto, em que o número de repetições do ciclo é desconhecido à partida, Julia tem o ciclo `while`.

A forma básica é bastante simples:

```julia
while condition
    do_something()
end
```

Neste caso, o programa continua a repetir o ciclo até que `condition` deixe de ser `true`.

Existem duas formas de sair do ciclo mais cedo:

- Um `break` faz com que o ciclo termine, e a execução continua na linha seguinte ao `end` do ciclo.
- Um `return x` interrompe a execução da função atual e devolve o valor `x` a quem a chamou.

Com estas opções disponíveis, por vezes é prático criar um ciclo "infinito" com `while true ... end` e depois contar com uma condição de paragem dentro do corpo do ciclo para acionar um `break` ou um `return`.

## Iterar sobre uma coleção

O exemplo mais simples é iterar sobre um intervalo.

Se quisermos fazer algo 10 vezes:

```julia
for n in 1:10
    do_something(n)
end
```

Se a iteração atual não satisfizer determinada condição, é possível saltar imediatamente para a iteração seguinte com um `continue`:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

Numa forma mais curta, o bloco `if` pode ser substituído por `is_useless(n) && continue`.

Podes iterar sobre muitos outros tipos de coleção: elementos de um array, carateres de uma string, chaves de um dicionário...

Os exemplos até agora iteram sobre o intervalo `1:10`, em que o valor é também o índice do ciclo.

De forma mais geral, podemos precisar do índice e não apenas do valor.
Para isso, usa-se a função `eachindex()`, por exemplo `for i in eachindex(my_array) ... end`.
