# Introdução

Um vetor é um array unidimensional.
Podem conter elementos de tipos diferentes.

## Criar vetores

Os vetores podem ser criados com a função `vector` ou com a sua forma de leitura `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## Aceder a elementos

Para acederes a elementos de um vetor, usa `aref`; os índices começam em zero:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
