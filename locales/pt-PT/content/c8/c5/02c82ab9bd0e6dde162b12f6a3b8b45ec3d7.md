# If, Elseif, Else

As instruções condicionais com `if`, `elseif` e `else` são uma parte fundamental do fluxo de controlo de um programa.
A instrução `if` avalia uma expressão e, se o resultado for `true`, executa o ramo de código correspondente.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Se a expressão não for um valor Boolean, a avaliação determina se o valor é "verdadeiro" ou "não falso".
Em PHP, os seguintes valores são considerados falsos:

- Boolean `false`
- o número inteiro `0`
- o número de vírgula flutuante `0.0` e `-0.0`
- um array vazio `[]`
- uma string vazia `""` ou uma string numérica `"0"`
- `null`

Todos os outros valores são considerados verdadeiros.

## Responder a várias condições

Depois de uma instrução `if`, podes encadear várias condições com `elseif` e `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Apenas uma condicional avaliada como verdadeira será executada.
Por isso, se várias condições puderem ser avaliadas como verdadeiras, a ordem em que estão escritas é importante.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
