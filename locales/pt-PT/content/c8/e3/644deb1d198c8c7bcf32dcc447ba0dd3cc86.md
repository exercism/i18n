# Sobre

Uma crate é uma unidade de compilação em Rust. Uma crate pode ser compilada num binário ou numa biblioteca. Na maior parte das vezes, vais usar o `cargo` para gerir dependências externas. Adicionar uma dependência pode ser tão simples como acrescentar uma linha ao teu ficheiro `Cargo.toml`.

- [introdução a pacotes e ao Cargo no livro do Rust](https://doc.rust-lang.org/book/ch07-00-managing-growing-projects-with-packages-crates-and-modules.html)
