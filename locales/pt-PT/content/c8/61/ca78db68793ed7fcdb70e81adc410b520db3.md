# Sobre

Um dos aspetos essenciais de trabalhar com números em F# é a distinção entre inteiros (números sem algarismos depois do separador decimal) e números de vírgula flutuante (números com zero ou mais algarismos depois do separador decimal).

Os dois tipos numéricos mais utilizados em F# são o `int` (um inteiro de 32 bits) e o `float` (um número de vírgula flutuante de 64 bits).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

Tanto os inteiros como os números de vírgula flutuante podem usar o caráter `_` como _separador de algarismos_, o que pode ser útil ao definir números grandes:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

A aritmética faz-se com os [operadores aritméticos padrão][arithmetic-operators] (`+`, `-`, `*`, etc.). Os números podem ser comparados com os [operadores de comparação padrão][comparison-operators] (`<`, `>=`, etc.) e com os operadores de igualdade (`=`) e de desigualdade (`<>`).

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

Para converter entre tipos numéricos, é preciso usar o [operador de conversão][conversion-operators] incorporado. Estes operadores têm o nome do tipo para o qual vão converter.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

Ao converter entre tipos, tem sempre cuidado. Se um valor não puder ser representado pelo tipo de destino, o valor vai _transbordar_.
