# Instruções

Neste exercício tens de implementar algumas funções para manipular uma lista de linguagens de programação.

## 1. Define uma função que devolve uma lista de linguagens vazia

Define a função `language_list`, que não recebe argumentos e devolve uma lista vazia.

```php
<?php

language_list();
// => []
```

## 2. Modifica a função para criar uma lista a partir de qualquer número de linguagens

Modifica a função `language_list` para que receba um argumento variádico de linguagens (strings).
Deve devolver a lista resultante com as linguagens na lista.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. Define uma função para adicionar uma linguagem à lista

Define a função `add_to_language_list`, que recebe 2 argumentos: um array de linguagens e a nova linguagem.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. Define uma função para remover um item da lista de linguagens

Define a função `prune_language_list` para remover a primeira linguagem do array de linguagens.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. Define uma função para obter o primeiro item da lista

Define a função `current_language`, que recebe 1 argumento (uma _lista de linguagens_).
Deve devolver a primeira linguagem da lista.
Assume que a lista terá sempre pelo menos um item.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. Define uma função que devolve quantas linguagens há na lista

Define a função `language_list_length`, que recebe 1 argumento (uma _lista de linguagens_).
Deve devolver o número de linguagens na lista.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
