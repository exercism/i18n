# Anexo às instruções

## Instruções específicas do percurso

Precisas de definir dois verbos chamados `allergic_to` e `list`.

## Parâmetros de entrada

1. O verbo `allergic_to` é uma **díade**, em que:

    - O **Argumento esquerdo** é uma string que contém o nome do alergénio.
    - O **Argumento direito** é a pontuação obtida.

1. O verbo `list` é uma **mónade**, em que:

    - O único argumento é a pontuação obtida.

Os teus verbos serão chamados com estes argumentos, tal como se segue:

```j
  'cats' allergic_to 255
  list 5
```

## Saídas

A saída do verbo `allergic_to` é um **boolean**

A saída de `list` é uma **lista de caixas**
