# Introdução

## Funções

No Gleam, as funções são definidas usando a sintaxe `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Esta função recebe dois argumentos, ambos do tipo `Int`, e devolve um valor do tipo `Int`. Não existe a palavra-chave `return` no Gleam, o valor da última expressão de uma função é sempre _devolvido implicitamente_.

As anotações de tipo para os argumentos e o tipo de retorno são opcionais, e o Gleam verifica sempre completamente os tipos do teu código. Normalmente, os programadores de Gleam dão anotações de tipo às suas funções por clareza, mas podes omiti-las se quiseres.

```gleam
pub fn add(x, y) {
  x + y
}
```

Uma função pode ser chamada usando a sintaxe `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Variáveis

No Gleam, as variáveis são definidas usando a sintaxe `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

As variáveis podem ser declaradas com anotações de tipo. Tal como os argumentos de funções, estas são opcionais, embora a maioria dos programadores de Gleam omita as anotações de tipo das variáveis por brevidade.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Literais de string

No Gleam, as strings são escritas com aspas duplas.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Comentários no código

Os comentários podem ser usados para deixar notas para outros programadores que leiam o código-fonte. Os comentários em Gleam são linhas únicas precedidas por `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
