# Instruções

Neste exercício, estás a ajudar a tua irmã mais nova a rever a redação dela para a escola. O professor procura pontuação correta, gramática e uma excelente escolha de palavras.

Tens quatro tarefas para limpar e modificar strings.

## 1. Coloca o título da redação com iniciais maiúsculas

Qualquer boa redação precisa de um título devidamente formatado.
Implementa a função `capitalize_title(<title>)` que recebe um título `str` como parâmetro e coloca a primeira letra de cada palavra em maiúscula.
Esta função deve devolver uma `str` com as iniciais maiúsculas.


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. Verifica se cada frase termina com um ponto final

Queres garantir que a pontuação na redação está perfeita.
Implementa a função `check_sentence_ending()` que recebe `sentence` como parâmetro. Esta função deve devolver um `bool`.


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. Limpa o espaçamento

Para a redação parecer profissional, é preciso remover o espaçamento desnecessário.
Implementa a função `clean_up_spacing()` que recebe `sentence` como parâmetro.
A função deve remover os espaços em branco a mais no início e no fim da frase, devolvendo uma nova `str` com a frase atualizada.


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. Substitui palavras por sinónimos

Para tornar a redação _ainda melhor_, podes substituir alguns dos adjetivos pelos respetivos sinónimos.
Escreve a função `replace_word_choice()` que recebe `sentence`, `old_word` e `new_word` como parâmetros.
Esta função deve substituir todas as ocorrências de `old_word` por `new_word` e devolver uma nova `str` com a frase atualizada.


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
