# Dicas

## Geral

- O pacote [`roc-random`](https://github.com/kili-ilo/roc-random) está disponível com o alias `random` na aplicação de teste.
  O stub importa `random.Random`.

- Um `Random.Generator(a)` descreve como gerar um valor do tipo `a`.

- Usa `Random.list` para combinar sorteios e `Random.map` para transformar os respetivos resultados.

- `Random.step(state, generator)` devolve `{ value, state }`; leva o estado atualizado de um grupo simulado para o seguinte, para não repetires a mesma amostra.
