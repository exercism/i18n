# Anexo às instruções

## Processo de IO

Ao contrário de outros exercícios, o `grep` implica interagir com o «mundo exterior»: ler ficheiros, tratar erros do sistema e escrever para `stdout`.

Em Lean, a interação com o sistema faz-se normalmente na mónada [IO][io], que permite que ocorram efeitos secundários num ambiente contido sem afetar o estado puro da maioria das outras funções.

## Leitura de argumentos

O Lean permite chamar um ficheiro como script, quer diretamente como script autónomo através de `lean --run`, quer com o recurso ao `lake`.

Um projeto Lean tem um único ponto de entrada, uma função chamada `main`, que recebe uma `List String` com todos os argumentos que lhe são passados.
Para simular a execução de `Grep.lean` como executável, os argumentos são passados da mesma forma neste exercício.

## Leitura de ficheiros

O Lean oferece [funções][files] para manipular ficheiros na mónada `IO.FS`.
Por exemplo, pode usar-se `IO.FS.readFile` para ler o conteúdo de um ficheiro num determinado caminho, como uma `String`.

## Escrever a saída

Em vez de devolver um valor, este exercício exige que os resultados sejam escritos na saída padrão ou no erro padrão.
Existem [funções][console] no Lean para este efeito.

## Tratamento de erros do sistema

Ao contrário dos erros em `Except`, as exceções de `IO` são exceções de tempo de execução.
Podes usar `try`/`catch` para as tratar:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
