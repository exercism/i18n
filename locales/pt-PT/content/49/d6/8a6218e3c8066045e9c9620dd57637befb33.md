# Dicas

## Geral

- Para gerar números aleatórios, o `:rand.uniform` do Erlang ou o `Enum.random` são bons pontos de partida.
- Podes usar o `Integer.pow` para calcular a potência de um número, e o `rem` para o módulo.
- Nenhum deles funciona particularmente bem (nem rapidamente) com números inteiros muito grandes. A criptografia recorre geralmente a números maiores do que 1024 bits. O módulo `:crypto` do Erlang tem uma função útil para calcular o módulo de uma potência, sobretudo para números inteiros enormes, mas podes precisar do `:binary` para o descodificar.
