# Introdução

A tua amiga Eliud herdou uma quinta da avó Tigist.
A avó dela era inventora e tinha tendência para construir as coisas de maneira demasiado complicada.
O galinheiro tem um visor digital que mostra um número codificado, que representa as posições de todos os ovos que podem ser recolhidos.

A Eliud pede-te que escrevas um programa que mostre o número real de ovos no galinheiro.

A codificação da informação das posições calcula-se da seguinte forma:

1. Percorre os possíveis locais de postura e assinala com um `1` um ovo existente ou com um `0` um local vazio.
2. Converte o número de binário para decimal.
3. Mostra o resultado no visor.

Exemplo 1:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

Exemplo 2:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
