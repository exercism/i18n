# título a remover

## Nova abordagem ao exercício

Ignora a parte relativa a uma biblioteca FRP; não é precisa uma biblioteca de terceiros
para este exercício. Este exercício centra-se na programação orientada a eventos, com
callbacks e o ciclo de eventos do Tcl.

Tens de construir um servidor TCP e um protocolo específico de domínio. Este servidor é
iniciado com a palavra a adivinhar. O script de teste implementa o cliente que envia
comandos ao servidor.

### Protocolo específico de domínio

Os comandos do protocolo a implementar são:

- `STATUS` para devolver o estado atual do jogo. A resposta é uma lista de três elementos:
    1) o número de tentativas erradas que restam,
    2) a palavra mascarada com underscores nas letras ainda por adivinhar, e
    3) um campo de estado (um de "ongoing", "win" ou "lose")
- `GUESS x`, em que `x` é uma letra a adivinhar. O servidor responde com a lista de estado
  após cada tentativa.
- `SHUTDOWN` para desligar o servidor remotamente. Caso contrário, o servidor termina após
  uma vitória ou uma derrota.

O servidor deve conseguir tratar estes comandos sem distinguir maiúsculas de minúsculas.

### Que porta usa o servidor?

Inicia o teu servidor usando a **porta número 0**: o Tcl encontra uma porta livre, por isso
não temos de fixar um número de porta no script de teste. Todos os intérpretes a correr num
processo (incluindo as threads) partilham o mesmo ambiente, por isso o servidor pode
comunicar a sua porta ao script de teste através do array global `env`. Há um exemplo no
ficheiro hangman.tcl inicial.
