# Instruções

O Ozan está a preparar uma lista de reprodução para uma viagem de carro que se aproxima. Não quer ouvir a mesma faixa mais do que uma vez, mas a lista de reprodução ficou tão longa que está a ter dificuldade em lembrar-se de que faixas já foram adicionadas.

A API do leitor de música do Ozan só sabe trabalhar com arrays, por isso ele tenta escrever algum código que usa `Array.indexOf()` para verificar a presença de uma faixa antes de a adicionar à lista de reprodução. Infelizmente, o programa dele demora demasiado tempo a executar. Ele precisa da tua ajuda!

Ao ires em auxílio do Ozan, ficas espantado por descobrir que a lista de reprodução dele contém _meio milhão_ de faixas. Talvez conheças uma estrutura de dados diferente que te permita manipular a lista de reprodução de forma mais eficiente?

## 1. Remover faixas duplicadas

Implementa a função `removeDuplicates`, que recebe uma lista de reprodução como _parâmetro_ e _devolve_ uma nova lista de reprodução em que todas as faixas são únicas.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. Verificar se uma faixa já foi adicionada

Implementa a função `hasTrack`, que recebe uma lista de reprodução e uma faixa como _parâmetros_ e _devolve_ um boolean que indica se a lista de reprodução contém a faixa.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. Adicionar uma faixa

Implementa a função `addTrack`, que recebe uma lista de reprodução e uma faixa como _parâmetros_ e _devolve_ uma nova lista de reprodução que inclui a faixa.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. Eliminar uma faixa

Implementa a função `deleteTrack`, que recebe uma lista de reprodução e uma faixa como _parâmetros_ e _devolve_ uma nova lista de reprodução que não inclui a faixa.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. Listar os artistas distintos

Implementa a função `listArtists`, que recebe uma lista de reprodução como _parâmetro_ e _devolve_ a lista dos artistas distintos na lista de reprodução. Repara que os nomes das faixas estão formatados como `<SONG> - <ARTIST>`.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
