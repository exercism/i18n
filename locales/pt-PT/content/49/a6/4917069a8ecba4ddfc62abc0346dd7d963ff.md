# Anexo às instruções

## Registos

| Registo | Utilização           | Tipo     | Descrição                               |
| ------- | -------------------- | -------- | --------------------------------------- |
| `$a0`   | parâmetro de entrada | inteiro  | número de entrada                       |
| `$v0`   | valor devolvido      | inteiro  | número de ovos                          |
| `$t0-9` | temporário           | qualquer | usado para armazenamento temporário     |
