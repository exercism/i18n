# Introdução

O AWK é uma linguagem muito pequena e tem apenas alguns tipos de dados básicos.
Nesta lição, vamos ver números e strings.

## Números

Em AWK, os números são implementados como números de vírgula flutuante de dupla precisão.
Não há distinção entre inteiros, números de vírgula flutuante e números de precisão dupla.

O AWK reconhece constantes numéricas octais (que começam por `0`) e constantes numéricas hexadecimais (que começam por `0x` ou `0X`).

### Operações numéricas

Podes usar os operadores aritméticos habituais `+`, `-`, `*`, `/`, `%`.
O operador de exponenciação é `^`.
Existem algumas funções numéricas incorporadas, incluindo funções trigonométricas, geração de números aleatórios e `int(x)`, que trunca um número para o inteiro mais próximo entre _x_ e zero.

## Strings

As strings do AWK são sequências de carateres.
Indica uma constante de string com aspas duplas.

### Operações com strings

Só existe uma operação com strings: a concatenação.
A concatenação não tem um operador especial;
basta colocar duas strings lado a lado para as concatenar:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` é uma **instrução**, não uma função.
`print` não precisa de parênteses.
~~~~

O AWK tem uma enorme variedade de funções de manipulação de strings.
Iremos conhecê-las em profundidade à medida que avançamos pelo percurso.

## Conversão entre números e strings

Não existem operadores explícitos para converter entre números e strings.
O AWK fá-lo implicitamente com base no contexto do programa.
Isto torna muito simples trabalhar com valores dos campos de entrada: o AWK faz geralmente aquilo que queres que ele faça.

* `print x + y` converte os valores das variáveis `x` e `y` em números, graças à operação numérica `+`.
* `print x y` converte os valores das variáveis `x` e `y` em strings, graças à operação de concatenação.

Se quiseres ser explícito, `0 + x` dá a representação numérica de _x_ e `"" x` dá a representação em string de _x_.

### De strings para números

A forma como o AWK converte uma string num número pode ser confusa.
Uma maneira simples de pensar nisto é que o AWK lê «carateres numéricos» desde o início de uma string até encontrar um «caráter não numérico».
Alguns exemplos:

* `"2.5"` converte-se no número `2.5`;
* `"1e3"` converte-se no número `1000` (notação científica);
* `"456abc"` converte-se no número `456` (como `a` não é um «numeral», a conversão para aí).
* `"abc789"` converte-se no número `0` (não há números no **início** da string).
