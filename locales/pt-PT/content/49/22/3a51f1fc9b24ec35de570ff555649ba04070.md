# Instruções

Estás a desenvolver o teu próprio videojogo de interpretação de papéis. No teu jogo, existem _personagens_ e _itens_. Uma das muitas ações que podes fazer com um item é fazer com que uma personagem o coma.

Nem todos os itens são comestíveis, e nem todos os itens comestíveis têm os mesmos efeitos na personagem. Alguns itens, quando comidos, transformam-se noutro item (por exemplo, se comeres uma maçã, ficas com o caroço da maçã).

Para permitir toda essa flexibilidade, decidiste criar um protocolo `Edible` que alguns dos itens podem implementar.

## 1. Define o que é comestível

Cria o protocolo `RPG.Edible`. O protocolo tem uma função: `eat`. A função `eat` recebe um item e uma personagem e devolve um subproduto e uma personagem.

## 2. Torna os pães comestíveis

Implementa o protocolo `RPG.Edible` para o item `RPG.LoafOfBread`. Quando é comido, um pão dá à personagem 5 pontos de vida e não tem subproduto.

```elixir
RPG.Edible.eat(%RPG.LoafOfBread{}, %RPG.Character{health: 31})
# => {nil, %RPG.Character{health: 36, mana: 0}}
```

## 3. Torna as poções de mana comestíveis

Implementa o protocolo `RPG.Edible` para o item `RPG.ManaPotion`. Quando é comida, uma poção de mana dá à personagem tantos pontos de mana como a força da poção e produz um frasco vazio.

```elixir
RPG.Edible.eat(%RPG.ManaPotion{strength: 13}, %RPG.Character{mana: 50})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 100, mana: 63}}
```

## 4. Torna os venenos comestíveis

Implementa o protocolo `RPG.Edible` para o item `RPG.Poison`. Quando é comido, um veneno retira todos os pontos de vida à personagem e produz um frasco vazio.

```elixir
RPG.Edible.eat(%RPG.Poison{}, %RPG.Character{health: 3000})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 0, mana: 0}}
```
