# Sobre

O Factor concentra a aleatoriedade no vocabulário [`random`][random] em torno de uma única palavra genérica:

```
random ( obj -- elt )
```

Faz despacho com base no seu argumento:

- um **inteiro** `n` devolve um inteiro aleatório em `[0, n)`;
- uma **sequência** devolve um elemento aleatório;
- assocs, hash-sets e tuplos `uniform-distribution` também são suportados.

Dois auxiliares para sequências assentam nele:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize` modifica a sequência no local e devolve-a, por isso faz `clone` primeiro se precisares de preservar a ordem original.

## De onde vem a aleatoriedade

`random` lê o gerador guardado na variável dinâmica `random-generator`. Por predefinição, é um Mersenne Twister com semente do relógio do sistema, por isso cada processo é diferente. Podes instalar um gerador diferente durante a execução de uma quotation:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

Como `with-random` apenas liga `random-generator` durante a extensão dinâmica da quotation, uma palavra que o envolva deve ser marcada como `inline`, para que a quotation possa deixar o seu resultado na pilha para quem a chama.

Para além destes, `random` oferece `random-bits`, `random-unit`, `uniform-random` e `normal-random` para outras distribuições, além de `system-random-generator` e `secure-random-generator` para necessidades não reprodutíveis e criptográficas.

[random]: https://docs.factorcode.org/content/vocab-random.html
