# Instruções

Neste exercício vais modelar uma máquina de pesagem.

## 1. Cria um estado inicial para a máquina de pesagem

Quando é inicializada, a máquina de pesagem deve usar as suas configurações de fábrica, que são diferentes consoante o sítio onde a máquina é vendida. Além disso, a máquina deve poder ser inicializada com uma precisão e com a indicação de se usa o sistema métrico ou o imperial.

Implementa o método `WeighingMachine#initialize`, que recebe dois argumentos: `precision`, que é um `Int32`, e `metric`, que é um `Bool`. O argumento `metric`, quando é `true`, significa que a máquina deve usar o sistema métrico; caso contrário, deve usar o sistema imperial. O método initialize também deve definir a variável de instância `@weight` como `0.0`.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. Permite que a máquina de pesagem tenha uma precisão

Para responder a exigências diferentes, permitimos que cada máquina de pesagem seja personalizada com uma precisão (o número de algarismos depois do separador decimal).

Implementa o método getter `WeighingMachine#precision` para devolver a precisão da máquina de pesagem.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. Permite definir o peso na máquina de pesagem

Implementa a propriedade `WeighingMachine#weight` para permitir obter _e_ definir o peso:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. Permite alternar a máquina entre as unidades métrica e imperial

Implementa a propriedade `WeighingMachine#metric=` para permitir definir a unidade. Deve aceitar um valor do tipo Boolean.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
