# Sobre

Em Factor, os carateres são *inteiros*, ou seja, pontos de código Unicode, por isso os simples operadores numéricos `<`, `>`, `=` já te dão uma ordenação que distingue maiúsculas de minúsculas. O vocabulário [`unicode`][unicode] acrescenta, por cima disso, predicados que têm em conta o Unicode e a conversão de maiúsculas e minúsculas de um único caráter.

## Predicados

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## Conversão de maiúsculas e minúsculas

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

Os `>upper`, `>lower` e `>title` ao nível da string aplicam-nos a cada caráter de uma string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
