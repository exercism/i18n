# Integrações do Babashka com editores de texto

## nREPL

### Emacs: [CIDER](https://cider.mx/)

Este é o que deu início a tudo, e o seu ecossistema [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) alimenta muitos dos outros plug-ins.

1. Instala o [Emacs](https://www.gnu.org/software/emacs/download.html) para a tua plataforma.

2. Escolhe uma distribuição de Emacs existente ([Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/) e [Doom Emacs](https://github.com/hlissner/doom-emacs) são todas ótimas) ou acrescenta isto ao teu `init.el`:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

Resumido a partir da [documentação do CIDER](https://docs.cider.mx/cider/platforms/babashka.html):

Inicia o servidor nREPL a partir do diretório do projeto:

```bash
$ bb --nrepl-server
```

Cria ou abre qualquer ficheiro Clojure (`.clj`) com `C-x C-f` e liga-te a ele usando `C-c C-x c j` (cider-connect-clj).

Os [atalhos básicos do CIDER](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` or `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` or `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. Instala o [VSCode](https://code.visualstudio.com/).

2. Instala o [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva).

Atualmente, o Calva assume que o teu código-fonte está no contexto de uma pasta, ou seja, de um projeto Clojure. Uma boa forma de criar um é com o [clj-new](https://github.com/seancorfield/clj-new):

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. Inicia o servidor nREPL a partir do diretório do projeto:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

Abre a pasta do projeto no VSCode (Ctrl+K Ctrl+O) ou a partir de outro terminal:

```bash
$ cd bbtest
bbtest$ code .
```

4. No VSCode, executa o comando do Calva `Connect to a running REPL` (ctrl+alt+c ctrl+alt+c). Escolhe o projeto `Generic` quando te for pedido e introduz `localhost:1667`.

Comandos do REPL:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. Descarrega o IntelliJ [aqui](https://www.jetbrains.com/idea/download/index.html).
2. Instala o Cursive seguindo o [guia do utilizador](https://cursive-ide.com/userguide/) e [configura as dependências](https://cursive-ide.com/userguide/deps.html).
3. Consulta [Cursive: Working with Babashka](https://cursive-ide.com/userguide/babashka.html) para mais informações.

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. Instala o [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. Instala o pacote `chlorine`

3. Inicia o socket REPL:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Abre a paleta de comandos do Atom (ctrl+shift+p) e executa o comando `Connect Clojure Socket REPL` com `localhost` `1666`

5. Edita os atalhos no keymap.cson através do menu `Edit` -> `Keymap...`:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Para o Emacs, instala o [inf-clojure](https://github.com/clojure-emacs/inf-clojure) acrescentando isto ao teu `init.el`:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

Inicia o socket REPL como acima e, no Emacs, executa `M-x inf-clojure-connect` (C-c M-c).

Avalia as formas com C-c C-e. Para veres uma lista de todos os comandos disponíveis no inf-clojure-mode (também conhecido como o REPL) e no inf-clojure-minor-mode, podes invocar C-h f RET inf-clojure-mode e C-h f RET inf-clojure-minor-mode ou simplesmente explorar os respetivos menus.

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

Descarrega a [appimage do Neovim](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) e cria um alias para `vim`.

* Instala o [vim-plug](https://github.com/junegunn/vim-plug):

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

Cria `~/.config/nvim/init.vim`:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Abre o Neovim e executa o comando `:PlugInstall`.

Adiciona o comando `iced` ao $PATH:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* Inicia o servidor socket REPL, abre o ficheiro de código-fonte e executa `:IcedConnectSocketRepl 1666`.

Comandos predefinidos do REPL (o `<Leader>` predefinido é `\`):

- `<Leader>ei` : Avalia o elemento interior
- `<Leader>ee` : Avalia a lista exterior
- `<Leader>et` : Avalia a lista exterior do topo
