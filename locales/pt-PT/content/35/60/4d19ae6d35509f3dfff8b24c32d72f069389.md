# Introdução

Quando uma quotation precisa de *recordar* valores do ambiente que a rodeia (o que outras linguagens chamam *closure*), o Factor usa duas ferramentas: a palavra `curry` e a sintaxe *fry* `'[ ]`.

## `curry`: capturar um valor

`curry` (em [`kernel`][kernel]) recebe um valor e uma quotation e devolve uma nova quotation com esse valor já incorporado:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

Aplica `curry` duas vezes para capturar dois valores:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: juntar duas quotations

`compose` (em [`kernel`][kernel]) cola duas quotations uma à outra:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Quotations fry: capturar vários valores

Quando há mais do que uma ou duas capturas, as chamadas encadeadas a `curry` tornam-se difíceis de ler. O *fry* usa `'[ … ]` com um ou mais marcadores de posição `_`; cada `_` é substituído por um valor retirado da pilha de dados, por ordem:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

Tanto `curry` como o fry *consomem* os seus valores da pilha no momento em que o closure é construído. A linha acima não deixa nada na pilha e é um substituto direto de `[ + + ] curry curry`.

Os marcadores de posição são preenchidos da esquerda para a direita com os valores da pilha de baixo para cima: `2 3 '[ _ _ ]` é `[ 2 3 ]`, não `[ 3 2 ]`.

O fry também chega *para dentro* das quotations aninhadas, o que te permite colocar os valores capturados exatamente onde queres:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

O `_` está dentro do `[ … ]` interior, mas o fry continua a preenchê-lo.

## `call` com um efeito declarado

Quando chegares ao momento de executar uma quotation guardada, declara o efeito de pilha no `call` para que o compilador possa verificar os tipos:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## Aritmética de vetores

O vocabulário [`math.vectors`][math.vectors] combina duas sequências com o mesmo comprimento, elemento a elemento. `v+` e `v*` somam-nos ou multiplicam-nos; `vmax` e `vmin` ficam com o maior ou o menor de cada componente. Cada uma devolve um array de dois elementos:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
