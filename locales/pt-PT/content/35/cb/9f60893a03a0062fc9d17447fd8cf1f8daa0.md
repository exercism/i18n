# Operador ternário

O operador ternário fornece uma sintaxe alternativa para fazer uma comparação `if..else..` e devolver um valor.

## Sintaxe

O PHP disponibiliza uma condicional onde uma ação pode ser avaliada com base na "veracidade" de uma condição.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Em alternativa, o operador ternário pode representar a mesma operação:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

A sintaxe da comparação é curta, representada por `(condition) ? (evaluate if true) : (evaluate if false);`.
