# Dicas

## Instruções específicas do percurso

Tenta evitar a repetição de código e usa funções auxiliares privadas, se puderes.

E podes considerar usar uma única expressão `Boolean` em vez de `if-else`, para uma melhor legibilidade.
Vê [aqui](http://cs.wellesley.edu/~cs111/spring00/lectures/boolean-simplification.html) como isso pode ser feito (o link é sobre Java, mas, claro, a lógica também é válida para Scala).
