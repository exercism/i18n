# Introdução

Para partilhares código entre diferentes módulos de Elixir dentro do mesmo projeto, precisas de referir o módulo externo pelo seu nome completo. Mas e se esse nome for demasiado longo ou confuso?

A forma especial `alias` permite-te encurtar ou alterar o nome pelo qual referes um módulo externo. Quando usada sem argumentos, reduz o nome do módulo ao seu último segmento, por exemplo, `MyApp.Logger.Settings` passa a ser `Settings`. Podes especificar um nome personalizado com a opção `:as`.

Normalmente, os aliases são adicionados no início da definição do módulo.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```
