# Instruções

Neste exercício, vais escrever algum código para te ajudar a preparar-te para comprar um veículo.

Tens três tarefas: determinar se vais precisar de tirar a carta de condução; escolher entre dois veículos; e estimar o preço aceitável para um veículo usado.

## 1. Determina se vais precisar de carta de condução

Alguns tipos de veículos exigem carta de condução para os conduzir.
Assume que apenas os tipos `"car"` e `"truck"` exigem carta; tudo o resto pode ser conduzido sem carta.

Implementa a função `needs_license`, que recebe o tipo de veículo e devolve um Boolean que indica se precisas de carta para esse tipo de veículo.

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. Escolhe entre dois veículos potenciais para comprar

Já avaliaste as opções de veículos que tens disponíveis.
Conseguiste reduzi-las a duas opções, mas precisas de ajuda para tomar a decisão final.
Implementa a função `choose_vehicle`, que recebe como parâmetro de entrada um array de dois veículos e devolve uma decisão, que é a opção que vem primeiro na ordem alfabética.

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcula uma estimativa para o preço de um veículo usado

Agora que tomaste a tua decisão, queres garantir que consegues um preço justo no concessionário.
Como estás interessado em comprar um veículo usado, o preço depende da idade do veículo.
Para uma estimativa aproximada, assume que, se o veículo tiver menos de 3 anos, custa 80% do preço original que tinha quando era novo.
Se tiver mais de 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos, mas não mais de 10, custa 70% do preço original.

Implementa a função `resell_price`, que aplica esta lógica com `if`, `elif` e `else`.
Recebe um objeto com o preço original e a idade do veículo e devolve o preço estimado no concessionário.

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
