# Instruções

Trabalhas numa loja de moda online.
Tens a ideia de uma funcionalidade do site que sugere conjuntos ao utilizador.
Interessam-te os conjuntos possíveis, os respetivos preços e eliminar as opções que colidem.

~~~~exercism/note
Embora possa haver diferentes formas de resolver os problemas seguintes, todos podem ser resolvidos com uma compreensão.
~~~~

## 1. Criar uma peça de roupa


Implementa `clothingitem()` para receber dois `Tuple`, um de `categories` e outro das respetivas `qualities`.
A função deve devolver um `Dict` com as `categories` como chaves e as `qualities` como valores.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

A tua função deve conseguir lidar com qualquer número de `categories`.

## 2. Sugerir combinações

Implementa `get_combinations()` para receber um `Tuple` de partes de cima e um `Tuple` de partes de baixo.
A função deve devolver o `cartesian product` dos tuples como um array 2-D (ou seja, uma `Matrix`).
Cada entrada é uma combinação `(top, bottom)` como um `Tuple`.
As partes de cima mudam ao longo das linhas, as partes de baixo mudam ao longo das colunas.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. Somar os preços dos conjuntos

Cada peça de roupa tem um campo `price` associado, por isso pode ser útil conseguir comparar o preço total dos conjuntos.
Implementa `get_prices()`, que recebe um array de combinações de peças de roupa.
A função deve devolver um array com uma forma semelhante, com os preços dos conjuntos nas respetivas posições.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)

 50
```

## 4. Filtrar os conjuntos que colidem

Cada peça de roupa tem um campo `base_color`.
Usa este campo para remover todas as combinações em que a parte de cima e a parte de baixo têm a mesma cor base.
Implementa `filter_clashing()` para receber um array de combinações de peças de roupa.
Devolve um array 1-D (ou seja, um `Vector`) com as combinações correspondentes.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
