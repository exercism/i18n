# gofmt não utilizado

Executa o `gofmt` na tua solução, que ajuda a formatar o código em Go.

A formatação de código em Go é muito importante para a comunidade.
A maioria dos IDEs pode ser configurada para formatar o código automaticamente a cada gravação. Por exemplo:

- O Visual Studio Code tem [um excelente suporte para Go](https://code.visualstudio.com/docs/languages/go)
- O Vim também tem [uma fantástica extensão para Go](https://github.com/fatih/vim-go)
- O [Jetbrains Goland](https://www.jetbrains.com/go/) é um IDE completo para Go

Para executar o `gofmt` manualmente:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
