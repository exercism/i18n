# Instruções

Neste exercício, vais ajudar namorados do secundário a declarar o seu amor nas redes sociais.

## 1. Mostra o nome do casal separado por um coração

Implementa o método estático `HighSchoolSweethearts.DisplaySingleLine()` para receber dois nomes e mostrá-los separados por um coração.
O texto formatado deve ter 61 carateres de largura, com o coração no centro da string.

Está garantido que todos os nomes cabem bem dentro da largura da linha.

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. Mostra as iniciais do casal num coração em arte ASCII

Implementa o método estático `HighSchoolSweethearts.DisplayBanner()`, que mostra os dois conjuntos de iniciais separados por um sinal de mais.

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
```

## 3. Faz os estudantes de intercâmbio alemães sentirem-se em casa com declarações sensíveis à localidade.

Implementa o método estático `HighSchoolSweethearts.DisplayGermanExchangeStudents()` para mostrar a data de início da relação e a duração para os nossos estudantes de intercâmbio alemães.

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
