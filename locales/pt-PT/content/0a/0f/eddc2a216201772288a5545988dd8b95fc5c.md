# não uses o método main

Tenta remover o método `main` do teu código.
Os testes dos exercícios não exigem que as soluções tenham um método `main`, e ter um torna o código um pouco mais difícil de ler.

Normalmente, adiciona-se um método `main` para ajudar a depurar o código.
No entanto, uma abordagem melhor é depurar o código enquanto corres um ou mais testes unitários.
Isto tem a vantagem adicional de poderes concentrar-te em depurar um caso de teste específico.

Aqui ficam alguns links que explicam como depurar código Java ao correr testes unitários em várias IDEs:

- [Correr e depurar testes Java no Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Depurar testes no IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
