O objetivo deste exercício é melhorar o exercício Password Checker.
Como é provável que uma dada palavra-passe viole mais do que uma regra ao mesmo tempo, um verificador de palavras-passe útil deve comunicar ao utilizador todas as regras que estão a ser violadas, em vez de apenas a primeira que for descoberta.
O verificador de palavras-passe melhorado deve indicar, de uma só vez, todas as regras que uma dada palavra-passe viola.

As regras deste verificador de palavras-passe são as mesmas do exercício Password Checker anterior:

- Tem de ter 12 ou mais carateres
- Tem de ter pelo menos uma letra maiúscula
- Tem de ter pelo menos uma letra minúscula
- Tem de ter pelo menos um algarismo
- Tem de ter pelo menos um símbolo do conjunto !@#$%^&\*

## 1. Modifica a união discriminada `PasswordError` para permitir que os valores individuais sejam tratados como flags

Repara que os testes só vão compilar depois de concluíres este passo essencial.

## 2. Implementa a função `checkPassword`

A função `checkPassword` verifica a palavra-passe dada em relação às regras acima referidas.
A função deve devolver um valor `Result`, em que `Ok` é devolvido quando a palavra-passe satisfaz todas as regras, e um valor `Error` quando falha uma ou mais regras.
Se a palavra-passe dada falhar várias regras, o valor `PasswordError` deve representar todas as regras incumpridas.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. Implementa a função ``getStatusPhrases`

A função `getStatusPhrases` devolve um conjunto de strings, cada uma com uma frase legível por humanos correspondente a um dos erros do resultado devolvido por `checkPassword`.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
