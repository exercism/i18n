# Dicas

## Geral

- Podes usar `*T` para declarar variáveis que são ponteiros para um tipo `T`, por exemplo `var i *int` declara uma variável `i` que é um ponteiro para um `int`
- Podes obter um ponteiro para uma variável (o seu endereço de memória) com o operador `&`, por exemplo `mypointer := &anIntVariable`.
- Podes obter o valor guardado num ponteiro aplicando o operador `*` a esse ponteiro, por exemplo `var i int = *aPointerToInt`.
  A isto chama-se desreferenciar o ponteiro.
- Verifica se um ponteiro não é `nil` antes de o desreferenciares.
  Se tentares desreferenciar um ponteiro `nil`, vais obter um erro em tempo de execução.
- Se não tiveres a certeza de como funcionam os ponteiros, experimenta ler o [Tour of Go: Pointers][go-tour-pointers] ou o [Go by Example: Pointers][go-by-example-pointers]

## 1. Criar um contador de votos

- Tens de criar um ponteiro para um `int`, ou seja, um `*int`.
- Podes usar o operador `&` numa variável para criar um ponteiro para ela, por exemplo `&myInt`
- Podes criar um ponteiro para uma nova variável definida por ti ou podes usar a variável do argumento da função

## 2. Obter o número de votos de um contador

- Podes usar o operador `*` num ponteiro para o desreferenciar e obter o seu valor, por exemplo `*myPointer`
- Desreferenciar ponteiros `nil` dá um erro em tempo de execução.
  Certifica-te sempre de que um ponteiro não é `nil` antes de o desreferenciares.

## 3. Incrementar os votos de um contador

- Se tiveres um ponteiro `var myPointer *int`, podes atribuir a `*myPointer` para alterar o valor apontado por `myPointer`
- Para obteres o valor atual do ponteiro, tens de o desreferenciar com o operador `*`, ou chamar a função que fizeste na tarefa anterior.

## 4. Criar os resultados da eleição

- Cria um novo literal ou variável `ElectionResult` com os campos `Name` e `Votes` preenchidos com os valores dos argumentos da função.
- Podes criar um ponteiro a partir de uma variável ou literal usando o operador `&` antes do nome da variável ou do literal, por exemplo `&myVariable` ou `&ElectionResult{Name: "John", Votes: 1}`

## 5. Anunciar os resultados

- Apesar de receberes um ponteiro para um `ElectionResult`, podes aceder aos seus campos com a notação de ponto `.`, como se não fosse um ponteiro!
- Constrói a mensagem acedendo aos campos `Name` e `Value` da struct.
- Mesmo que estejas a aceder a campos a partir de um ponteiro para uma struct, não precisas de desreferenciar nada.
  O Go desreferencia o ponteiro automaticamente por ti, como neste exemplo:

```go
result := &ElectionResult{
    Name: "John",
    Votes: 32
}

result.Name // "John" - Go will automatically dereference the pointer
            //          and access the 'Name' field of the dereferenced struct 
```

## 6. Recontagem de votos

- Podes pensar nos mapas como se já fossem ponteiros.
  Isto significa que as alterações que fizeres ao mapa dentro da função serão visíveis fora da função.
- Para incrementar o valor de uma chave num `var m map[string]int`, tens várias opções: `m["mykey"] = m["mykey"] + 1`, `m["mykey"] += 1` ou `m["mykey"]++`.
