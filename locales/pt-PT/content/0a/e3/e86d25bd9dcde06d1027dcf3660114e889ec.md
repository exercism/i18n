# Instruções

Neste exercício, vais implementar a lógica da missão de um novo jogo de RPG que um amigo está a desenvolver. A personagem principal do jogo é a Annalyn, uma rapariga corajosa com um cão de estimação feroz e leal. Infelizmente, o desastre acontece: o seu melhor amigo foi raptado enquanto procurava bagas na floresta. A Annalyn vai tentar encontrar e libertar o seu melhor amigo, podendo levar o cão com ela nesta missão.

Depois de algum tempo a seguir o rasto do seu melhor amigo, encontra o acampamento onde ele está preso. Acontece que há dois sequestradores: um cavaleiro poderoso e um arqueiro astuto.

Depois de encontrar os sequestradores, a Annalyn pondera quais das seguintes ações pode realizar:

- Ataque rápido: é possível fazer um ataque rápido se o cavaleiro estiver a dormir, pois ele demora algum tempo a vestir a armadura e, por isso, fica vulnerável.
- Espionar: é possível espiar o grupo se pelo menos um deles estiver acordado. Caso contrário, espiar é uma perda de tempo.
- Sinalizar o prisioneiro: é possível sinalizar o prisioneiro com sons de aves se o prisioneiro estiver acordado e o arqueiro estiver a dormir, uma vez que os arqueiros são treinados em sinais de aves e podem intercetar a mensagem.
- _Libertar o prisioneiro_: a Annalyn pode tentar entrar furtivamente no acampamento para libertar o prisioneiro.
  É uma coisa arriscada e só pode ter sucesso de uma de duas formas:
  - Se a Annalyn tiver o seu cão de estimação com ela, pode resgatar o prisioneiro se o arqueiro estiver a dormir.
    O cavaleiro tem medo do cão e o arqueiro não terá tempo de se preparar antes de a Annalyn e o prisioneiro conseguirem escapar.
  - Se a Annalyn não tiver o cão com ela, então ela e o prisioneiro têm de ser muito furtivos!
    A Annalyn pode libertar o prisioneiro se o prisioneiro estiver acordado e o cavaleiro e o arqueiro estiverem ambos a dormir, mas se o prisioneiro estiver a dormir não pode ser resgatado: o prisioneiro ficaria assustado com o aparecimento súbito da Annalyn e acordaria o cavaleiro e o arqueiro.

Tens quatro tarefas: implementar a lógica que determina se as ações acima estão disponíveis, com base no estado das três personagens encontradas na floresta e na presença ou não do cão de estimação da Annalyn.

## 1. Verifica se a ação "Ataque rápido" é possível

Implementa uma função chamada `canExecuteFastAttack` que recebe um valor Boolean que indica se o cavaleiro está acordado. Esta função devolve `true` se a ação "Ataque rápido" estiver disponível, com base no estado da personagem. Caso contrário, devolve `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. Verifica se a ação "Espionar" é possível

Implementa uma função chamada `canSpy` que recebe três valores Boolean, indicando se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados. A função devolve `true` se a ação "Espionar" estiver disponível, com base no estado das personagens. Caso contrário, devolve `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. Verifica se a ação "Sinalizar o prisioneiro" é possível

Implementa uma função chamada `canSignalPrisoner` que recebe dois valores Boolean, indicando se o arqueiro e o prisioneiro, respetivamente, estão acordados. A função devolve `true` se a ação "Sinalizar o prisioneiro" estiver disponível, com base no estado das personagens. Caso contrário, devolve `false`:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. Verifica se a ação "Libertar o prisioneiro" é possível

Implementa uma função chamada `canFreePrisoner` que recebe quatro valores Boolean. Os três primeiros parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados. O último parâmetro indica se o cão de estimação da Annalyn está presente. A função devolve `true` se a ação "Libertar o prisioneiro" estiver disponível, com base no estado das personagens e na presença do cão de estimação da Annalyn. Caso contrário, devolve `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
