# Dicas

## 5. Substitui o treinador

- Podes usar a sintaxe de atualização de registos para criar uma cópia de um registo, mas com um ou mais campos com um novo valor.

## 6. Verifica se é a mesma equipa

- Os registos têm igualdade estrutural incorporada, o que significa que registos com os mesmos valores são iguais.

## 7. Verifica se deves torcer por uma equipa

- A melhor forma de executar lógica com base no valor da equipa é usar uma expressão case.
- Se quiseres adicionar uma condição a um padrão, podes usar uma guarda.
- A correspondência de padrões funciona para registos dentro de registos.
