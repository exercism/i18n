# Acerca de

Criar uma instância de uma _classe_ faz-se chamando o seu [_construtor_][constructors] através do [operador `new`][new].
Um construtor é um tipo especial de método cujo objetivo é inicializar uma instância recém-criada.
Os construtores são parecidos com os métodos normais, mas não têm tipo de retorno e o seu nome é igual ao da classe.

```java
class Library {
    private int books;

    public Library() {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Tal como os métodos normais, os construtores podem ter parâmetros.
Os parâmetros de um construtor são normalmente guardados como [campos][fields] (privados) para serem acedidos mais tarde, ou então usados num cálculo pontual.
Podes passar argumentos a um construtor exatamente como passas argumentos a métodos normais.

```java
class Building {
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight) {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```

Especificar um construtor é opcional.
Se não especificares nenhum construtor, o compilador gera um construtor sem parâmetros:

```java
class Elevator {
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

Se os campos tiverem um valor inicial atribuído, o compilador vai gerar código em que a atribuição é feita dentro do construtor.
As seguintes declarações de classe são, por isso, equivalentes (em termos de funcionalidade):

```java
class UsingFieldInitialization {
    private int players = 5;
}

class UsingConstructorInitialization {
    private int players;

    public UsingConstructorInitialization() {
        players = 5;
    }
}
```
