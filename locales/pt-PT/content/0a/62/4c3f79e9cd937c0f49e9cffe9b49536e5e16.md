# Dicas

## Geral

- O preço de um artigo é o segundo elemento do seu array de 2 elementos. `second` em [`sequences`][sequences] lê-o.
- Palavras de ordem superior como `filter`, `count`, `sort-by` e `map-sum` recebem todas uma *quotation* (código entre parênteses retos `[ ]`) como segundo argumento.

## 1. Ordenar o inventário por preço

- `sort-by` (em [`sorting`][sorting]) recebe uma sequência e uma *quotation* que devolve uma chave ordenável para cada elemento.

## 2. Encontrar artigos sem preço definido

- Um preço em falta é `f`. `f` é também o único valor que o Factor considera falso, por isso `[ second not ] filter` mantém os artigos cujo preço é `f`.
- `[ second ] reject` faz o mesmo ao contrário.

## 3. Contar os artigos caros

- `count` aplica o predicado a cada elemento e conta as correspondências.

## 4. Encontrar o artigo mais barato

- `minimum-by` (em [`sequences`][sequences]) devolve o elemento cuja chave extraída é a mais pequena.

## 5. Somar todos os preços

- `map-sum` (em [`sequences`][sequences]) aplica uma *quotation* a cada elemento da sequência e soma os resultados.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
