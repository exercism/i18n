# Instruções adicionais

Deves implementar este exercício recorrendo a uma gramática de cláusulas definidas (DCG).
As DCG podem ser usadas não só para analisar sequências (listas), mas também para gerar, completar e verificar essas sequências.

## Biblioteca

Os ficheiros stub da implementação incluem a seguinte linha:

```prolog
:- use_module(library(dcg/basics)).
```

Esta linha garante que podes usar a biblioteca `dcg/basics`, o que deve ser suficiente para resolveres este exercício.
