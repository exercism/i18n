# Correr os testes

Para compilar e correr os testes, basta executares o seguinte na tua pasta de exercício:
```bash
$ ponyc
$ ./exercise-name
```

(Substitui `exercise-name` pelo nome da pasta do exercício)

O binário compilado corre os testes no seu Main actor, por isso basta correr o binário e ver se os testes passaram. O Pony verifica todo o código em tempo de compilação, por isso podes descobrir que os teus testes não compilam enquanto não escreveres o código necessário. Podes comentar os testes que não compilam começando cada linha com `//`. Depois, quando estiveres pronto para trabalhar nesse teste, podes descomentá-lo.
