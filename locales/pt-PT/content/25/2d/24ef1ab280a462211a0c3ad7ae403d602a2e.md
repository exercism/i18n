# Introdução

## Variáveis de instância

Os objetos podem guardar o seu próprio estado através da definição de _variáveis de instância_.
Estas variáveis existem dentro de um objeto e são normalmente usadas para guardar algum estado interno.

As variáveis de instância começam sempre com um `@`.
Podes criar uma nova variável de instância atribuindo um valor a uma variável que comece com `@`.
Por exemplo:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

Normalmente, os objetos definem o seu estado inicial num método `initialize`, que é chamado automaticamente quando se chama `new` numa classe.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

O método `initialize` também pode receber argumentos, para que cada instância possa começar com um estado personalizado:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

É boa prática considerar que as variáveis _de instância_ são privadas, não podendo ser lidas nem alteradas do exterior.
Em vez disso, definimos métodos para obter e definir os seus valores.
Por exemplo:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] é uma palavra inglesa que significa "nada" ou "zero".
Em Ruby, `nil` é usado para expressar a _ausência_ de um objeto.
Noutras linguagens de programação, valores como `null` ou `none` podem desempenhar um papel semelhante.

```ruby
# I do not have a favorite color
favorite_color = nil
```

O Ruby atribui a qualquer variável de instância o valor predefinido `nil` quando esta é encontrada pela primeira vez, até que lhe seja atribuído outro valor.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
