# Apêndice às instruções

## Registos

| Registo  | Utilização | Tipo    | Descrição                      |
| -------- | ---------- | ------- | ------------------------------ |
| `$a0`    | entrada    | inteiro | x                              |
| `$a1`    | entrada    | inteiro | y                              |
| `$v0`    | saída      | inteiro | pontos obtidos                 |
| `$t0-9`  | temporário | qualquer| usado para armazenamento temporário |
