# Instruções

Neste exercício vais gerar relatórios meteorológicos para uma estação de notícias local.

## Gerar relatórios meteorológicos

Vais começar com algumas funções esboçadas e com o seguinte enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

Vais ter de formatar um relatório meteorológico como `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."`.
Terás de implementar a função que produz as condições meteorológicas corretas.

Por exemplo, o excerto abaixo mostra um resultado esperado para a função `get_weather_report` num dia "chuvoso".

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

E para um dia "solarengo":

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
