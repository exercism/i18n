# Instruções

Estás a trabalhar com uma equipa de desenvolvimento web para manter o site de uma equipa local de basquetebol. A equipa de desenvolvimento web conhece pouco o Elixir e pede uma função que permita extrair dados de uma série de mapas aninhados, para facilitar um desenvolvimento rápido.

## 1. Extrair dados de uma estrutura de mapas aninhados

Implementa a função `extract_from_path/2`, que recebe dois argumentos:

- `data`: uma estrutura de mapas aninhados com dados sobre a equipa de basquetebol.
- `path`: uma string composta por chaves separadas por pontos que permitem obter o valor associado à última chave.

Se o valor ou a chave não existir em nenhum ponto do caminho, deve ser devolvido `nil`.

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

Usa o _Access Behaviour_ ao implementar esta função.

Não uses nenhuma função dos módulos `Map` ou `Kernel` para trabalhar com a estrutura de mapas aninhados.

## 2. Refatorar com as funções incluídas

Um colega que está a rever o teu código fala-te de uma função do módulo `Kernel` que faz algo muito semelhante à tua implementação.

Implementa a função `get_in_path/2` para usar essa função do módulo `Kernel`.

Os argumentos esperados são os mesmos da parte 1.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
