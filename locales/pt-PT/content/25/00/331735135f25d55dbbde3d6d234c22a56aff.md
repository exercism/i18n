# Sobre

O mais importante a reter sobre as strings de C# é que são objetos imutáveis que representam texto como uma cadeia de carateres Unicode (letras, algarismos, pontuação, etc.). Usam-se aspas duplas para definir uma instância de `string`:

```csharp
string fruit = "Apple";
```

Podes manipular uma string chamando um dos seus [métodos][methods] ou [propriedades][properties]. Como os valores de string nunca podem mudar depois de serem definidos, todos os métodos de manipulação de strings devolvem uma nova string.

Uma string é delimitada por aspas duplas (`"`). Alguns carateres especiais precisam de [escape][escaping], usando o caráter de barra invertida (`\`). As strings também podem ser precedidas do símbolo arroba (`@`), o que as torna uma [string verbatim][verbatim] que ignora quaisquer carateres de escape.

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

Se só precisares de uma parte de uma string, podes usar o [método `Substring()`][substring] para extrair apenas essa parte:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

O [método `IndexOf`()][indexof] pode ser usado para encontrar o índice da primeira ocorrência de uma `string` dentro de uma `string`, devolvendo `-1` se o valor especificado não for encontrado:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

Por fim, há [várias formas de concatenar strings][concatenation]. A mais simples é usar o [operador `+`][plus-operator].

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para qualquer formatação de strings mais complexa do que uma simples concatenação, dá-se preferência à [interpolação de strings][interpolation]. Para ativar a interpolação numa string, coloca o símbolo de dólar (`$`) antes dela.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
