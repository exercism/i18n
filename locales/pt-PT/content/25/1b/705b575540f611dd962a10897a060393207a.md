# Sobre

Um [tuplo](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) é um agrupamento _imutável_ de valores sem nome, mas ordenados.
Os tuplos podem conter qualquer tipo de dados (ou vários tipos), incluindo outros tuplos.

Os tuplos definem-se como valores separados por vírgulas entre os caracteres `(` e `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Só é possível comparar tuplos com o mesmo comprimento e os mesmos tipos (na mesma ordem).
Os tuplos têm igualdade estrutural, ou seja, são iguais _apenas_ se todos os seus valores forem iguais.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Há [três formas de extrair valores de um tuplo](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values):

- As funções `fst` e `snd`
- Desconstrução de tuplos
- Correspondência de padrões

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
Tecnicamente, podes aceder ao valor de um tuplo através das suas propriedades `.Item1`, `.Item2`, ... , mas isso é desaconselhado e resulta num aviso do compilador.
~~~~

## Pontos-chave sobre tuplos

Alguns pontos-chave a saber sobre tuplos:

- Uma instância particular de um tipo de tuplo é um único objeto, semelhante a um array de dois elementos em C#, por exemplo. Quando os usas com funções, contam como um único parâmetro. A única exceção é quando chamas código que não é F# com vários parâmetros; nesse caso, passas um tuplo e os seus valores são automaticamente extraídos para o valor do parâmetro correspondente.
- Não é possível dar nomes explícitos aos tipos de tuplo. O «nome» do tipo de tuplo é determinado pela combinação dos tipos que são multiplicados entre si.
- A vírgula é o símbolo essencial que define os tuplos, e não os parênteses. Podes definir tuplos sem os parênteses, embora por vezes isso possa ser confuso. Em F#, se vires uma vírgula, provavelmente faz parte de um tuplo.
- Os tuplos podem ser usados como argumentos de funções e como valores devolvidos de funções.
