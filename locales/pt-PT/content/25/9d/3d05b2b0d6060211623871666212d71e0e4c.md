# Instruções

Estás a registar diariamente quantos pássaros visitam o teu jardim. Os dados são guardados num array de números inteiros, com **a contagem de hoje em primeiro lugar**.

## 1. A contagem de hoje

Define `today` para retirar da pilha um array de contagens diárias e devolver a contagem de hoje, ou `f` se o array estiver vazio.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Incrementar a contagem de hoje

Define `increment-day-count` para devolver um novo array com a contagem de hoje aumentada em um. Se o valor de entrada estiver vazio, devolve `{ 1 }`.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. Houve algum dia sem pássaros?

Define `has-day-without-birds?` para devolver `t` se pelo menos um dia registou zero pássaros, caso contrário `f`.

**Usa recursão** em vez de `any?` ou de outras palavras de sequência de ordem superior.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Total de pássaros desde que começaste

Define `total` para devolver a soma de todas as contagens.

**Usa recursão** em vez de `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Dias movimentados

Um dia movimentado é um dia com cinco ou mais pássaros. Define `busy-days` para devolver o número de dias movimentados.

**Usa recursão** em vez de `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
