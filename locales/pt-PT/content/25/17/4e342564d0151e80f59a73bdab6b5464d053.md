# Introdução à manipulação de bits

O Java tem operadores para manipular os bits de um `byte`, `short`, `int`, `long` ou `char`.

## Operadores de deslocamento

Usa `<<` para deslocar bits para a esquerda e `>>` para deslocar para a direita.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

O operador `<<` insere sempre zeros no lado direito.
No entanto, o `>>` insere o mesmo bit que o bit mais à esquerda (1 se o número for negativo ou 0 se for positivo).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

Usa antes o `>>>` quando for preciso inserir zeros ao deslocar para a direita.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

## Operações bit a bit

### AND bit a bit

O operador AND bit a bit (`&`) recebe dois valores e faz uma operação AND em cada bit.
Compara cada bit do primeiro valor com o bit na mesma posição do segundo valor.
Se ambos forem 1, o bit do resultado é 1.
Caso contrário, o bit do resultado é 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

### OR bit a bit

O operador OR bit a bit (`|`) recebe dois valores e faz uma operação OR em cada bit.
Compara cada bit do primeiro valor com o bit na mesma posição do segundo valor.
Se um dos bits for 1, o bit do resultado é 1.
Caso contrário, é 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

### XOR bit a bit

O operador XOR bit a bit (`^`) faz uma operação XOR bit a bit em dois valores.
Tal como os operadores AND bit a bit e OR bit a bit, compara cada bit do primeiro valor com o bit na mesma posição do segundo valor.
Se apenas um deles for 1, o bit resultante é 1.
Caso contrário, é 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

### NOT bit a bit (`~`)

Por fim, o operador NOT bit a bit (`~`) inverte cada bit.
Ao contrário dos operadores anteriores, este é um operador unário, que atua apenas sobre um valor.

```java
~0b0110_0101;
// # => 0b1001_1010
```
