# Dicas

## Geral

- Os parâmetros de entrada de `delivery_date()` são dois argumentos do tipo `String`, e a saída é uma `String`.
- Todas as strings de data estão no formato [ISO 8601][iso], a representação de string predefinida de Julia.
- A documentação útil para o módulo `Dates` inclui:
  - O [Percurso de aprendizagem][dates-times] do Exercism.
  - O [manual de Julia][Dates].
  - O [Wikibook][Wikibook].
- No mínimo, vais precisar de estar à vontade com os construtores de [DateTime][datetime] e com a adição ou subtração de [Periods][period].
- Entre as funções úteis estão [`dayofweek()`][dayofweek] e, opcionalmente, [`lastdayofmonth()`][lastdayofmonth] ou [`lastdayofquarter()`][lastdayofquarter].
- Para extrair números inteiros a partir de strings, a função [`parse()`][parse] vai ser importante.
- As funções [`tonext()`][tonext] e [`toprev()`][toprev] podem ser úteis numa abordagem que inclua funções de ordem superior.
