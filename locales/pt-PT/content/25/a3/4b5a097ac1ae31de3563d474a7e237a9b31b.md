## Executar os testes

1. Vai à raiz do diretório do teu exercício de PHP, que é `<EXERCISM_WORKSPACE>/php`.
   Para descobrires o espaço de trabalho do Exercism, executa

   ```shell
   exercism workspace
   ```

2. Instala o [PHPUnit] se ainda não o tiveres.
3. Executa os testes com:

   ```shell
   phpunit test_file.php
   ```

   Por exemplo, para executares os testes do exercício Hello World, executarias:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
