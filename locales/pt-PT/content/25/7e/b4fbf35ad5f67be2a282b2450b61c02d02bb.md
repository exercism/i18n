# Instruções

Quando os extraterrestres Lisp chegaram à Terra pela primeira vez, depararam-se com inúmeras coisas estranhas e maravilhosas, mas uma das suas descobertas favoritas foram os "animais de estimação". Sejamos honestos: que espécie de extraterrestre não se derreteria com um cachorrinho ou um gatinho?

Depois das suas férias recentes na Terra, o Ludwig decidiu que quer um animal de estimação só para si! O único problema? Demasiadas opções! Talvez possas escrever um programa para ajudar o Ludwig a encontrar e a cuidar do seu próximo amigo fofinho?

## 1. Escolher um amigo

Embora o Ludwig esteja decidido a arranjar um animal de estimação, é mais ou menos até aí que chegou no seu raciocínio. O primeiro passo, então, é decidir que tipo de animal arranjar!

O Ludwig quer encontrar um amigo com uma personalidade que complemente a sua. Podes escrever ao Ludwig uma função chamada `pal-picker` que recebe um traço de personalidade (uma palavra-chave) e devolve o tipo de animal (uma string) com esse traço?

Neste caso em particular:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

Para outras personalidades desconhecidas, a tua função deve dar como resultado: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. No seu habitat natural

Agora que o Ludwig tem um novo amigo, vai precisar de um sítio para viver! Podes ajudar o Ludwig a escolher o tamanho certo de cama / aquário / gaiola para o seu animal?

Aqui, o Ludwig precisa de uma função chamada `habitat-fitter` para selecionar o tamanho adequado do habitat (uma palavra-chave) a partir do peso do seu animal em quilogramas (um número inteiro).

Os habitats necessários para cada tamanho de animal são:

- 40kg ou mais -> `:massive`
- De 20kg a 39kg, inclusive -> `:large`
- De 10kg a 19kg, inclusive -> `:medium`
- De 1kg a 9kg, inclusive -> `:small`
- 0kg ou menos -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. E agora, vamos comer

Uma coisa que todos os animais terrestres têm em comum é a necessidade de comida! No entanto, este conceito é um pouco estranho para o Ludwig, que tem tendência a esquecer-se de reabastecer o comedouro do seu animal.

O Ludwig dava bom uso a uma função simples chamada `feeding-time` que o avisasse quando o comedouro precisa de ser reabastecido. A função receberia uma percentagem de comida (um número inteiro) e devolveria uma mensagem sob a forma de uma string.

Se o nível de comida for:

- Acima de 20% -> `"All is well."`
- 20% ou menos -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. Um código de conduta

Com o essencial resolvido, o Ludwig está ansioso por experimentar várias coisas emocionantes, como fazer "festas" e brincar ao "busca". Dito isto, nem todos os animais são adequados para estas atividades.

O Ludwig gostaria de um par de funções, `pet` e `play-fetch`, que recebem o tipo de animal (como string) e devolvem ou nada, ou uma mensagem como: `"Maybe not with this pet..."` se a ação não for adequada.

Assume que só os animais `"Dog"` brincam ao busca e que se pode fazer festas a todos os animais exceto ao `"Fish"`.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
