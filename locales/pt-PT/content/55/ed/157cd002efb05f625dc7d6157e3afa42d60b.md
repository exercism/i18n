# Instruções

O porto de Palermo é um porto movimentado, com muitos navios a chegar e a partir.
Há muito tempo que tem um sistema manual para registar os navios que estão atualmente no porto.
Este sistema é muito propício a erros, e o chefe do porto decidiu substituí-lo por um sistema informatizado.

O chefe do porto contratou-te para implementares o novo sistema.
O sistema tem de tratar identificadores de navios, mas também de destinos.

## 1. Cria o identificador dos portos

A primeira coisa que tens de fazer é criar o identificador do porto de Palermo.
O identificador é composto pelas primeiras quatro letras do nome do porto, em maiúsculas.

Define a constante `Port::IDENTIFIER` como um símbolo com o valor `:PALE`.
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. Obtém identificadores para outros portos

O programa também terá de tratar outros portos, por isso tens de criar identificadores para eles também.
O porto gostaria que o sistema fosse automatizado e, como os portos usam convenções de nomenclatura diferentes, os identificadores devem ser gerados a partir do nome do porto.
O identificador é composto pelas primeiras quatro letras do nome do porto, em maiúsculas.

Define o método `Port.get_identifier` para receber uma string como argumento e devolver o identificador desse porto como símbolo.

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. Determina em que terminal um navio deve atracar

O porto tem dois terminais e o sistema tem de determinar em que terminal um navio deve atracar.
O terminal é determinado pelo identificador do navio.

O identificador é composto por 2 partes: a primeira é formada por 3 letras maiúsculas que indicam que carga o navio transporta, e depois 3 números, que são o identificador único do navio.

Se o identificador do navio indicar **OIL** ou **GAS**, o navio deve atracar no terminal **A**.
Caso contrário, o navio deve atracar no terminal **B**. 

Define o método `Port.get_terminal` para receber como argumento um símbolo que é o identificador do navio.
O método deve devolver o terminal como símbolo.

```ruby
Port.get_terminal(:OIL123)
# => :A
```
