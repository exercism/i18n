# Arrays

Os arrays em PHP são mapas ordenados.
Um mapa é uma estrutura de dados que associa uma chave a um valor.
Os arrays são versáteis e podem ser tratados como um array linear (como em `C` ou `Java`), uma lista [vetor], uma tabela de hash, um dicionário, uma coleção, uma pilha ou uma fila.

Uma chave é opcional, mas, se for indicada, tem de ser um `int` ou uma `string`.
Quando não se indica uma chave, o PHP usa, por predefinição, chaves inteiras por ordem crescente, a começar em `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Um array pode armazenar valores de todos os tipos.
Cada valor pode ser de um tipo diferente.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## Usar arrays

Os arrays podem ser declarados como um literal (escrito no código, como acima) ou criados e manipulados por funções.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

Acede, atribui e acrescenta valores com o operador de índice:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

Percorre um array com foreach:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
