# Introdução

## Tipos aninhados

Os tipos de C# podem ser definidos dentro do âmbito de uma classe ou de uma struct. O tipo que os envolve fornece uma espécie de espaço de nomes. O acesso ao tipo faz-se através do tipo que o envolve, com a sintaxe de ponto.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Podes definir níveis de acesso para os tipos internos.

Os membros privados do tipo exterior estão no âmbito dos membros do tipo interior, mas não o contrário.
