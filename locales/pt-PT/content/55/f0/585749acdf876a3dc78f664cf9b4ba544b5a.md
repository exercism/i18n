# Cabeçalho fictício

## Instruções específicas do Bash

O objetivo deste exercício é considerar o número de argumentos que passas ao teu programa.

Repara que podes passar strings vazias como argumentos.

`./program ""`

Isto é diferente de não passar argumento nenhum.

`./program`

Se executares o teu programa com exatamente um argumento (mesmo que seja uma string vazia), trata-o como o nome de uma pessoa e imprime uma mensagem de saudação.
Se o executares sem argumentos ou com mais do que um argumento, imprime uma mensagem de erro e termina com um estado diferente de zero.
