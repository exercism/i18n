# Dicas

## Geral

- O `disposable` está em `destructors`; os genéricos do protocolo de
  streams estão em `io`; o `<string-reader>` (usado pelos testes) está
  em `io.streams.string`.
- Uma declaração `TUPLE: x < y ...` faz com que `x` herde os slots de
  `y`. O `disposable` acrescenta um sinalizador `disposed` e regista o
  tuplo no framework dos destrutores quando é construído através de
  `new-disposable`.

## 1. Define a fita

- O construtor: `tape new-disposable swap >>wire ;`. O `swap` serve
  para que o fio fique por baixo da fita acabada de construir, para o
  `>>wire` o consumir.

## 2. Junta o mixin input-stream

- Uma linha ao nível de topo, depois da declaração `TUPLE:`.

## 3. Lê um símbolo Morse

- A forma mais simples é um pequeno ciclo: lê um byte, verifica-o,
  devolve-o se for um símbolo Morse ou `f`, caso contrário lê o
  seguinte.
- Um caráter literal escreve-se `CHAR: .`. O espaço é `CHAR: \s`.
- `member?` num array pequeno funciona:
  `B{ CHAR: . CHAR: - CHAR: \s } member?`.
- A estrutura de controlo mais simples: um ciclo `while` que lê até
  encontrar um símbolo Morse ou `f`, acompanhado de um `dup` final para
  entregar o resultado ao chamador.

## 4. Delega o tipo de elemento

- Um método de uma linha: `wire>> stream-element-type`.

## 5. Limpa os recursos

- A mesma forma: `wire>> dispose`.
- Não chames `dispose*` por ti próprio. Chama `dispose` no fio.
  O trabalho do framework é garantir que o teu `dispose*` só corre
  uma vez.
