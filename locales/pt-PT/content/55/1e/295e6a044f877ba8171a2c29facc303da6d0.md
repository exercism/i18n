# Conjuntos

Um [`set`][type-set] é uma coleção _mutável_ e _não ordenada_ de objetos [_hashable_][hashable].
Os elementos de um conjunto têm de ser distintos: não são permitidos elementos duplicados.
Podem conter vários tipos de dados diferentes e até estruturas aninhadas, como um `tuple` de `tuples`, desde que todos os elementos sejam _hashable_.
Os conjuntos existem também numa variante imutável, o [`frozenset`][type-frozenset].

Os conjuntos são usados sobretudo para remover rapidamente duplicados de outras estruturas de dados ou agrupamentos de itens.
Também servem para fazer comparações eficientes quando não é preciso preservar a ordem nem controlar duplicados.

Tal como outros tipos de coleções (_dicionários, listas, tuplas_), os `sets` suportam:
- Iteração com `for item in <set>`,
- Verificação de pertença com `in` e `not in`,
- Cálculo do comprimento com `len()`, e
- Cópias superficiais com `copy()`.

`sets` não suportam:
- Indexação de qualquer tipo
- Ordenação através de uma ordenação explícita ou da ordem de inserção
- Fatiamento
- Concatenação com `+`


Verificar a pertença num `set` tem complexidade temporal constante (em média), ao contrário de verificar a pertença numa `list` ou numa `string`, em que a complexidade temporal cresce à medida que o comprimento dos dados aumenta.
Métodos como `<set>.union()`, `<set>.intersection()` ou `<set>.difference()` também têm complexidade temporal constante (em média).

[hashable]: https://docs.python.org/3.7/glossary.html#term-hashable
[type-frozenset]: https://docs.python.org/3/library/stdtypes.html#frozenset
