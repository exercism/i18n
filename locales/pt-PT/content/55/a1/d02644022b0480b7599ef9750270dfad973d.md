# Geral

O [tutorial de comparações em Python][python comparisons tutorial] e os [exemplos de comparações em Python][python comparisons examples] são uma excelente introdução que cobre o conteúdo deste exercício.

## 1. Calcular o valor de uma carta

- Podes usar o operador de comparação de igualdade `==` para determinar se uma carta é um ás: `card == 'A'`.
- Podes usar o operador de pertença `in` para determinar se uma substring está contida numa string: `'Q' in 'KJQ'`.
- Podes usar o [construtor `int`][int constructor] para converter uma `str` de um `int` num `int`: `int('13')`.

## 2. Determinar qual das cartas tem um valor mais alto

- Depois de definires a função `value_of_card`, podes chamá-la a partir de outras funções.
- Podes usar os operadores de comparação de valores `>` e `<` para determinar se cartas específicas são _maiores do que_ ou _menores do que_ um determinado valor: `3 < 12`.
- Podes usar o operador de comparação de igualdade `==` para determinar se dois valores são iguais.

## 3. Calcular o valor de um ás

- Depois de definires a função `value_of_card`, podes chamá-la a partir de outras funções.
- Podes usar o operador de comparação de ordem `>` para decidir o procedimento adequado aqui.

## 4. Determinar se é Blackjack

- Lembra-te de que podes usar a [sintaxe `if`/`elif`/`else`][if syntax] para lidar com diferentes combinações de cartas.
- Podes encadear operadores de comparação E operadores booleanos _de forma arbitrária_: `y < z < x` ou `(y or z) and (x or z)`
- Podes reutilizar a função `value_of_card` que já implementaste.

## 5. Dividir pares

- Podes reutilizar a função `value_of_card` que já implementaste.
- Podes tratar o caso do `A` (quando pelo menos uma das cartas é um ás) separadamente.

## 6. Dobrar a aposta

- Um `A` contado como 11 nunca permite dobrar a aposta se houver duas cartas na mão.
- Tendo em conta o primeiro ponto, _deves_ conseguir reutilizar a função `value_of_card` que já implementaste.
- Podes encadear operadores de comparação _de forma arbitrária_: `y < z < x`.
- Podes usar a [expressão condicional][conditional expression] (_por vezes chamada "operador ternário"_)
  para encurtar instruções `if`/`else` simples: `13 if letter == 'M' else 3`.
