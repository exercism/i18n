# Instruções

Escreve um simulador de robôs.

A instalação de testes de uma fábrica de robôs precisa de um programa para verificar os movimentos dos robôs.

Os robôs têm três movimentos possíveis:

- virar à direita
- virar à esquerda
- avançar

Os robôs são colocados numa grelha infinita hipotética, virados para uma direção específica (norte, este, sul ou oeste), num conjunto de coordenadas {x,y}, por exemplo, {3,8}, com as coordenadas a aumentar para norte e para este.

O robô recebe então uma série de instruções, altura em que a instalação de testes verifica a nova posição do robô e a direção para a qual está virado.

- A sequência de letras "RAALAL" significa:
  - Virar à direita
  - Avançar duas vezes
  - Virar à esquerda
  - Avançar uma vez
  - Virar à esquerda mais uma vez
- Imagina que um robô começa em {7, 3}, virado para norte. Se executar esta sequência de instruções, deve ficar em {9, 4}, virado para oeste.
