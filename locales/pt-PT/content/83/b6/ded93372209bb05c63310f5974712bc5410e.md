# Anexo às instruções

## Palavras

Define um tuplo `school` para guardar a lista de alunos — a forma como guardas os alunos dentro dele é contigo — e depois implementa as palavras abaixo.

- `<school> ( -- school )`: constrói uma escola vazia.
- `add-student ( school name grade -- ? )`: adiciona `name` ao `grade`. Devolve `t` em caso de sucesso, ou `f` se `name` já tiver sido adicionado (a este ou a qualquer outro ano), caso em que a lista de alunos fica inalterada.
- `roster ( school -- names )`: todos os alunos, ordenados por ano e depois alfabeticamente por nome.
- `grade ( school n -- names )`: os alunos do ano `n`, ordenados alfabeticamente por nome.
