# Introdução

Uma função é um bloco de código organizado e reutilizável que serve para realizar uma ação.
Há várias formas de definir funções em JavaScript.
Aqui vamos ver _declarações de função_ e _expressões de função_.
Outras possibilidades, como [funções arrow][concept-arrow-functions], serão abordadas noutros conceitos.

## Declaração de função

A forma padrão de definir uma função em JavaScript é uma _declaração de função_, também chamada _definição de função_ ou _instrução de função_.

É composta pela palavra-chave `function`, pelo nome da função e por uma lista de parâmetros separados por vírgulas entre parênteses.
A seguir vem o corpo da função (conjunto de instruções que define o que a função faz), entre chavetas.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

Em JavaScript, uma função é invocada (chamada) escrevendo o nome da função seguido de parênteses que contêm os argumentos.

```javascript
someName(arg1, arg2, arg3);
```

## Parâmetros

Quando trabalhas com parâmetros dentro do corpo da função, tem atenção aos possíveis efeitos secundários.

- Os valores de [tipos de dados primitivos][mdn-primitives] são _imutáveis_.
  O valor original nunca é afetado pelo que acontece ao argumento no corpo da função.
- Para todos os outros valores (objetos, arrays, funções), uma reatribuição não afeta o valor original.
  No entanto, se alterares um argumento desses (por exemplo, se acrescentares uma chave a um objeto), isso também altera o valor original que foi passado.

Por predefinição, todos os parâmetros definidos na declaração da função são opcionais em JavaScript.
Se forneceres menos argumentos do que parâmetros, os argumentos em falta serão `undefined` dentro da função; vê [Null e Undefined][concept-null-undefined].
Em muitos casos, faz sentido atribuir um valor predefinido mais adequado do que `undefined`.
Isto pode ser feito especificando parâmetros predefinidos diretamente na definição da função.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## Instrução return

Uma instrução `return` termina a execução da função e especifica um valor a devolver a quem chamou a função. Uma função pode ter várias instruções `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

O resultado de uma função que não devolve valor nenhum ou que não tem uma instrução `return` é `undefined`.
Não existem `return` implícitos em JavaScript.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

Em JavaScript, só podes devolver exatamente um valor.
Se quiseres passar mais informação, tens de a combinar primeiro numa única entidade, normalmente num [objeto][concept-objects] ou num [array][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Expressão de função

Uma declaração de função é uma instrução autónoma.
Mas, por vezes, é útil definir uma função como parte de outra expressão, por exemplo, numa atribuição, como parâmetro de função ([callback][concept-callbacks]) ou como valor num [objeto][concept-objects].
Isto pode ser feito com uma expressão de função.
Tem a mesma sintaxe que uma declaração de função, só que o nome da função pode ser omitido para criar uma _função anónima_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
