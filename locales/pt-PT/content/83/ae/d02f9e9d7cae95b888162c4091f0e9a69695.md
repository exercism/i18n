# Sobre

Os [símbolos][symbols] são identificadores nomeados que podem ser usados para fazer referência a um valor.
Os símbolos são criados através de um literal de símbolo, que consiste em colocar o caráter `:` antes de um nome, por exemplo `:foo`.
Também podem ser escritos com aspas, por exemplo `:"foo"`, o que permite, por exemplo, espaços no nome.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

Os símbolos são usados em muitos locais da linguagem, incluindo como chaves em hashes, para representar nomes de métodos e de variáveis.

## Identificador

O que distingue os símbolos das strings é que são identificadores e não representam dados nem texto.
Isto significa que dois símbolos com o mesmo nome são sempre o mesmo objeto.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## Modificar símbolos

Os símbolos são imutáveis, o que significa que não podem ser modificados.
Isto significa que, quando "modificas" um símbolo, estás na verdade a criar um novo símbolo.
Existem alguns métodos que podem ser usados para manipular símbolos; todos devolvem novos símbolos.
Todos os métodos podem ser encontrados na [API do Symbol][symbols-api].

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

A vantagem de os símbolos serem imutáveis é que são mais eficientes em termos de memória do que as strings, mas também mais seguros para usar como identificadores.

## Conversão

Os símbolos podem ser convertidos em strings e vice-versa.
Isto pode ser útil quando queres modificar um símbolo ou quando queres usar um símbolo como string.
Para apresentar uma string como símbolo, podes usar o método `String#to_sym`; para fazer o contrário, podes usar o método `Symbol#to_s`.
Como os símbolos têm um conjunto limitado de métodos, pode ser útil converter um símbolo numa string para lhe aplicar métodos de string, se precisares de um novo símbolo.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
