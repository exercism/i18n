# Apêndice às instruções

## Nota

Os testes deste exercício (e dos exercícios futuros) têm um prefixo numerado, como 'test00_'. Esta não é uma convenção normal em Pharo, mas para facilitar o estudo da linguagem é útil apresentar os testes por uma ordem determinística.

Para este exercício, estuda a categoria de métodos 'arithmetic' da classe Number, bem como a forma como os operadores Boolean também são definidos como mensagens.
Repara como "and:" e "or:" são implementados nas classes True e False.
Podes usar o item do menu de contexto "senders of..." para ver como outras partes do Pharo usam estes operadores.

Também podes achar útil experimentar... `World > Tools > Finder > Examples > 20 . 4 . true`, que está a perguntar ao Pharo que operações entre o primeiro e o segundo elementos dão como resultado o terceiro.
