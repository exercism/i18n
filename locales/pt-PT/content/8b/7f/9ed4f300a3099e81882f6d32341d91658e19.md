# Introdução

O ABAP suporta um modelo de programação orientado a objetos baseado em classes e interfaces do ABAP Objects.

## (Re)atribuição

Há algumas formas principais de atribuir valores a nomes em ABAP, recorrendo a variáveis ou a constantes. No Exercism, as variáveis escrevem-se sempre em [snake-case][wiki-snake-case]. Não existe um guia oficial a seguir, e várias empresas e organizações têm guias de estilo diferentes. _Sente-te à vontade para escreveres as variáveis como quiseres._ A vantagem de as escreveres como os exercícios estão preparados é que ficam realçadas de forma diferente na interface web e na maioria das IDEs.

Em ABAP, as variáveis podem ser definidas com as palavras-chave [`constant`][constant] ou [`data`][data].

Uma variável pode referenciar valores diferentes ao longo do seu ciclo de vida quando se usa `data`. Por exemplo, `my_first_variable` pode ser definida e redefinida várias vezes com o [operador de atribuição `=`][assignment]:

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

Ao contrário de `data`, as variáveis definidas com `constant` só podem receber uma atribuição. É assim que se definem constantes em ABAP.

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## Declarações de classes e métodos

Em ABAP, as unidades de funcionalidade estão encapsuladas em _métodos_, que normalmente se agrupam na mesma [classe][classes] quando pertencem uns aos outros. Estes métodos podem receber parâmetros (argumentos) e podem _devolver_ um valor com a palavra-chave `returning` na definição do método. Os métodos são invocados com a sintaxe `( )`.

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 Em ABAP há _muitas_ formas diferentes de declarar classes e métodos. O track tenta introduzi-las gradualmente, mas se já as conheces, sente-te à vontade para usar qualquer uma delas. Na maioria dos casos, usar uma ou outra não é melhor nem pior.
