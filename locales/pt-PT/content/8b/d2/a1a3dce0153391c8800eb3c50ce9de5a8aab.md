# Introdução

Em Elixir, para escolher um elemento aleatório de uma estrutura de dados enumerável (por exemplo, uma lista ou um intervalo), usamos `Enum.random`. Esta função escolhe um único elemento, e todos os elementos têm a mesma probabilidade de ser escolhidos.

O Elixir não tem funções próprias para escolher um número de vírgula flutuante aleatório. Para isso, temos de usar o Erlang diretamente.
