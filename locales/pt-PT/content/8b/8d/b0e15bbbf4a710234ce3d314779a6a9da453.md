# Instruções

Estás a escrever um sistema embebido para uma máquina de senhas. É um modelo muito simples. Consegue emitir números consecutivos e indicar qual foi o último número emitido.

## 1. Inicia a máquina

Implementa a função `start/0`. Deve criar um novo processo e devolver o PID desse processo. O novo processo ainda não precisa de fazer nada.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

Repara que, cada vez que executas este código, o PID pode ser diferente.

## 2. Indica o estado da máquina

Altera a máquina para que o processo recém-criado esteja pronto para receber mensagens (inicia um _ciclo de receção_) com um estado inicial de `0`. Deve conseguir receber mensagens `{:report_state, sender_pid}`. Como resposta a essas mensagens, deve enviar o seu estado atual (o número da última senha emitida) a `sender_pid` e depois aguardar mais mensagens.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. Emite números

Altera a máquina para que consiga receber mensagens `{:take_a_number, sender_pid}`. Deve aumentar o seu estado em 1, enviar o novo estado a `sender_pid` e depois aguardar mais mensagens.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. Para a máquina

Altera a máquina para que consiga receber uma mensagem `:stop`. Deve deixar de aguardar mais mensagens.

## 5. Ignora mensagens inesperadas

Altera a máquina para que, quando recebe uma mensagem inesperada, a ignore e continue a aguardar mais mensagens.
