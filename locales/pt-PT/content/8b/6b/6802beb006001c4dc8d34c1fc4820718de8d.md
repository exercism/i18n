# Instruções

A tua tarefa é criar um verificador de palavras-passe.
Um verificador de palavras-passe valida a palavra-passe proposta por um utilizador para garantir que cumpre um conjunto de requisitos definidos pela organização que controla o acesso ao recurso em questão.

Para este exercício, os requisitos da palavra-passe são:
* Tem de ter 12 ou mais carateres
* Tem de ter pelo menos uma letra maiúscula
* Tem de ter pelo menos uma letra minúscula
* Tem de ter pelo menos um algarismo
* Tem de ter pelo menos um símbolo do conjunto !@#$%^&*

A tua solução tem de usar um `Result` para encapsular o estado de sucesso ou de falha.
No caso de sucesso, o `Result` deve conter a palavra-passe validada como uma string.
No caso de falha, o `Result` deve conter a regra que foi violada.

~~~~exercism/note
Para este exercício, o verificador de palavras-passe será simplista: vai indicar apenas quando uma única regra foi violada.
Um exercício seguinte vai explorar um verificador de palavras-passe mais realista, capaz de indicar quando várias regras foram violadas ao mesmo tempo.
~~~~

## 1. Implementa a função `checkPassword`

A função `checkPassword` verifica a palavra-passe fornecida em relação às regras acima mencionadas. Em caso de falha, indica a regra que foi violada, encapsulando um dos valores de `PasswordRule` dentro do valor do resultado.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. Implementa a função ``getStatusMessage`

A função `getStatusMessage` devolve uma string com uma mensagem legível por humanos que indica o significado do resultado devolvido por `checkPassword`.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
