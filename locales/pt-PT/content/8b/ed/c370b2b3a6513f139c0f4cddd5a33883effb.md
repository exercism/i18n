# Dicas

## Geral

- A [documentação da API `Map`][map-docs] contém uma lista de métodos disponíveis na interface `Map`.

## 1. Devolve os códigos num mapa

- Vais precisar de definir um `Map` de [tal forma][declaring-members] que o possas usar nos métodos da classe.

## 2. Adiciona entradas ao dicionário

- Os mapas têm um [método][map-put-docs] para adicionar e atualizar o valor de uma chave.

## 3. Procura o país de um código de chamada

- Os mapas têm um [método][map-get-docs] para obter o valor de uma chave.

## 4. Não permitas duplicados

- Há uma forma de verificar se o mapa tem uma [chave][map-contains-key-docs] ou um [valor][map-contains-value-docs].

## 5. Encontra o código de chamada de um país

- Há uma [forma][map-entry-set-docs] de obter uma coleção iterável de entradas num mapa, o que te permite percorrer os pares chave-valor.

## 6. Atualiza o código de chamada do país

- Não te esqueças de que o código de chamada anterior do país vai estar no mapa.
- Há um [método][map-remove-docs] para remover uma entrada do mapa.
