# Depuração

Quando um teste falha, é apresentada uma mensagem que descreve o que correu mal e com que valores de entrada. Além disso, podes contar com o facto de que qualquer [saída na consola][programiz.com-basic-input-output] também será mostrada. Para escrever para a consola, usa:

```csharp
Console.WriteLine("Debug message");
```
