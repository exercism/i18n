# Representações

O [representador de Java][github-java-representer] aplica as seguintes normalizações:

- Todos os comentários são removidos
- Todas as declarações de importação são removidas
- Os identificadores são normalizados para um valor de substituição

Depois de aplicar as normalizações acima, a representação resultante é formatada segundo o [Google Java Style][google-java-style], para eliminar as diferenças de formatação de código que ainda restem.

## Antes de submeteres

Confirma os seguintes pontos:

- Não duplicas o feedback dado pelo analisador.
- Verificas o separador "examples" no diálogo de submissão e vês se o feedback faz sentido para todos os separadores.
- Verificas que não fizeste referência a espaços em branco nem a comentários.
- Verificas que não fazes referência a nomes de funções ou de variáveis tal como aparecem na solução, mas sim à correspondência fornecida (ou deixas os nomes de fora).
  Só podes fazer referência, com segurança, aos identificadores usados pelos testes do exercício, porque são sempre iguais para toda a gente.
