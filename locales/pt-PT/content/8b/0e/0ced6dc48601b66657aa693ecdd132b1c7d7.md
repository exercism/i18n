# Instruções

Estás a desenvolver o novo e muito apreciado jogo **Crystal Hunter**.
No jogo, és uma personagem que se desloca e recolhe cristais.
O jogador ganha quando apanha todos os cristais.
Se o jogador entrar em contacto com um bandido, perde todos os cristais e o jogo.
Há uma exceção a esta regra: o jogador pode ter um power-up ativo que o torna invisível para os bandidos.

O teu objetivo é escrever algumas regras que vão ser usadas no jogo.

## 1. Define se a personagem ganha pontos de bónus

No jogo, a personagem ganha pontos de bónus se tocar num bandido enquanto tem um power-up ativo.

Define o método `Rules#bonus_points?`, que recebe dois argumentos (_se a personagem tem um power-up ativo_ e _se a personagem está a tocar num bandido_) e devolve um valor Boolean que indica se a personagem vai ganhar pontos de bónus.
O método deve devolver `true` apenas se a personagem tiver um power-up ativo e estiver a tocar num bandido, e `false` caso contrário.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. Define se a personagem pontua

O jogador ganha pontos no jogo quando apanha um cristal ou um power-up.

Define o método `Rules#score?`, que recebe dois argumentos (_se a personagem está a tocar num power-up_ e _se a personagem está a tocar num cristal_) e devolve um valor Boolean que indica se a personagem pontuou ou não.
O método deve devolver `true` se a personagem tocar num power-up ou num cristal e `false` caso contrário.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. Define se a personagem perde

Define o método `Rules#lose?`, que recebe dois argumentos (_se a personagem tem um power-up ativo_ e _se a personagem está a tocar num bandido_) e devolve um valor Boolean que indica se a personagem perde ou não.
O método deve devolver `true` se a personagem tocar num bandido e não tiver um power-up ativo, e `false` caso contrário.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. Define se a personagem ganha

Define o método `Rules#win?`, que recebe três argumentos (_se a personagem apanhou todos os cristais_, _se a personagem tem um power-up ativo_ e _se a personagem está a tocar num bandido_) e devolve um valor Boolean que indica se a personagem ganha ou não.
O método deve devolver `true` se a personagem tiver reunido todos os cristais e não tiver perdido com base nos argumentos definidos na parte 3, e `false` caso contrário.

```crystal
Rules.new.win?(false, true, false)
# => false
```
