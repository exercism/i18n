# Dicas

## Geral

- Lê sobre o módulo [`Agent`][getting-started-agent] no guia de introdução.
- Lê a documentação sobre o módulo [`Agent`][elixir-doc-agent].
- Vê o [ElixirCasts: Introduction to Agents][elixircasts-agent].

## 1. Abre o jardim

- Revê a documentação do [`Agent`][elixir-doc-agent].
- A função que inicializa o estado do _processo de agente_ tem de devolver o estado inicial.

## 2. Lista os registos

- O módulo [`Agent`][elixir-doc-agent] contém muitas funções para obter o estado atual do _processo de agente_.

## 3. Regista canteiros a uma pessoa

- O módulo [`Agent`][elixir-doc-agent] contém funções para obter e atualizar o estado do _processo de agente_.
- As funções exigem geralmente uma função que transforma o estado e devolve uma forma específica.
- Para manteres o registo do id do próximo canteiro a atribuir, o estado do teu _processo de agente_ tem de guardar os canteiros e também o próximo id a usar para um canteiro.

## 4. Liberta canteiros

- O módulo [`Agent`][elixir-doc-agent] contém funções para obter e atualizar o estado do _processo de agente_.
- As funções exigem geralmente uma função que transforma o estado e devolve o estado seguinte.

## 5. Obtém um canteiro registado

- O módulo [`Agent`][elixir-doc-agent] contém funções para obter o estado do _processo de agente_.
- Obtém o canteiro e depois trata o resultado para devolver o resultado correto.
