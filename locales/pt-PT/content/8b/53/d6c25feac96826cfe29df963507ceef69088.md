# Introdução

## Enums

Um _tipo enum_ é um tipo de dados especial que permite que uma variável seja um conjunto de constantes predefinidas.
A variável tem de ser igual a um dos valores predefinidos para ela.
Exemplos comuns incluem os pontos cardeais (valores `NORTH`, `SOUTH`, `EAST` e `WEST`) e os dias da semana.

Como são constantes, os nomes dos campos de um tipo enum escrevem-se em letras maiúsculas.

### Definir um tipo enum

Na linguagem de programação Java, defines um tipo enum com a palavra-chave `enum`.
Por exemplo, um tipo enum para os dias da semana especifica-se assim:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Deves usar tipos enum sempre que precisares de representar um conjunto fixo de constantes.
Isso inclui tipos enum naturais, como os planetas do nosso sistema solar, e conjuntos de dados cujos valores possíveis conheces todos em tempo de compilação: por exemplo, as opções de um menu, as opções de linha de comandos, e assim por diante.

### Usar um tipo enum

Aqui está algum código que te mostra como usar o enum `DayOfWeek` definido acima:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### Adicionar métodos e campos

Os tipos enum da linguagem de programação Java são muito mais poderosos do que os seus equivalentes noutras linguagens.
A declaração `enum` define uma _classe_ (chamada _tipo enum_).
O corpo da classe enum pode incluir métodos e outros campos:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

Chamar o método `getNumberOfStars` num membro do tipo enum `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
