# Instruções

Dados os nomes dos alunos e o ano que frequentam, cria um registo para a
escola.

No final, deves ser capaz de:

- Adicionar o nome de um aluno ao registo de um ano
  - "Adiciona o Jim ao 2.º ano."
  - "OK."
- Obter uma lista de todos os alunos inscritos num ano
  - "Que alunos estão no 2.º ano?"
  - "Por agora, só temos o Jim."
- Obter uma lista ordenada de todos os alunos de todos os anos. Os anos devem
  ser ordenados como 1, 2, 3, etc., e os alunos dentro de cada ano devem ser
  ordenados alfabeticamente pelo nome.
  - "Quem é que está inscrito na escola neste momento?"
  - "Deixa-me pensar. Temos a
  Anna, a Barb e o Charlie no 1.º ano,
  o Alex, o Peter e a Zoe no 2.º ano
  e o Jim no 5.º ano.
  Então a resposta é: Anna, Barb, Charlie, Alex, Peter, Zoe e Jim"

Repara que todos os nossos alunos têm apenas um nome. (É uma terra pequena,
o que é que querias?)

## Para pontos extra

Conseguiste fazer passar os testes e manter o código limpo? Se quiseres, estas
são algumas coisas adicionais que podes experimentar:

- Se estás a trabalhar numa linguagem com estruturas de dados mutáveis e a tua
  implementação permite que código externo altere diretamente a base de dados
  interna da escola, vê se consegues evitar isso. Fica à vontade para
  acrescentar testes adicionais.

Depois, partilha o que pensas num comentário à submissão. Esta experiência
tornou o código melhor? Pior? Aprendeste alguma coisa com ela?
