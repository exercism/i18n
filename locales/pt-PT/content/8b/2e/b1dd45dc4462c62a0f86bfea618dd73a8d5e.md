# Introdução

Existem dois tipos diferentes de números em Gleam: inteiros e números de vírgula flutuante.

Os inteiros são números inteiros.

```gleam
let integer = 3
// -> 3
```

Também podes adicionar underscores aos inteiros para maior clareza.

```gleam
1_000_000 // One million
```

Gleam tem vários operadores que funcionam com inteiros.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
