# Instruções

Neste exercício vais implementar a lógica da missão de um novo jogo de RPG que um amigo está a desenvolver.
A personagem principal do jogo é a Annalyn, uma rapariga corajosa com um cão de estimação feroz e leal.
Infelizmente, o desastre acontece: o seu melhor amigo foi raptado enquanto procurava bagas na floresta.
A Annalyn vai tentar encontrar e libertar o seu melhor amigo, levando opcionalmente o cão com ela nesta missão.

Depois de algum tempo a seguir o rasto do seu melhor amigo, encontra o acampamento onde ele está preso.
Acontece que há dois raptores: um cavaleiro poderoso e um arqueiro astuto.

Tendo encontrado os raptores, a Annalyn pondera quais das seguintes ações pode realizar:

- _Ataque rápido_: é possível fazer um ataque rápido se o cavaleiro estiver a dormir, pois ele demora algum tempo a vestir a armadura e, por isso, fica vulnerável.
- _Espiar_: é possível espiar o grupo se pelo menos um deles estiver acordado.
  Caso contrário, espiar é uma perda de tempo.
- _Sinalizar o prisioneiro_: é possível sinalizar o prisioneiro com sons de aves se o prisioneiro estiver acordado e o arqueiro estiver a dormir, pois os arqueiros são treinados em sinalização com sons de aves e poderiam intercetar a mensagem.
- _Libertar o prisioneiro_: a Annalyn pode tentar entrar no acampamento às escondidas para libertar o prisioneiro.
  É uma ação arriscada e só pode ter sucesso de uma de duas formas:
  - Se a Annalyn tiver o cão com ela, pode resgatar o prisioneiro se o arqueiro estiver a dormir.
    O cavaleiro tem medo do cão e o arqueiro não terá tempo de se preparar antes de a Annalyn e o prisioneiro conseguirem escapar.
  - Se a Annalyn não tiver o cão, ela e o prisioneiro têm de ser muito furtivos!
    A Annalyn pode libertar o prisioneiro se este estiver acordado e o cavaleiro e o arqueiro estiverem ambos a dormir, mas se o prisioneiro estiver a dormir não pode ser resgatado: o prisioneiro ficaria assustado com o aparecimento súbito da Annalyn e acordaria o cavaleiro e o arqueiro.

Tens quatro tarefas: implementar a lógica para determinar se as ações acima estão disponíveis, com base no estado das três personagens encontradas na floresta e na presença ou não do cão da Annalyn.

## 1. Verifica se é possível fazer um ataque rápido

Define a função `can_fast_attack()`, que recebe um valor Boolean que indica se o cavaleiro está acordado.
Esta função devolve `true` se for possível fazer um ataque rápido, com base no estado do cavaleiro.
Caso contrário, devolve `false`:

```rust
let knight_awake = true;
can_fast_attack(knight_awake); // false
```

## 2. Verifica se o grupo pode ser espiado

Define a função `can_spy()`, que recebe três valores Boolean, indicando se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados.
A função devolve `true` se for possível espiar o grupo, com base no estado das três personagens.
Caso contrário, devolve `false`:

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
can_spy(knight_awake, archer_awake, prisoner_awake); // true
```

## 3. Verifica se é possível sinalizar o prisioneiro

Define a função `can_signal_prisoner()`, que recebe dois valores Boolean, indicando se o arqueiro e o prisioneiro, respetivamente, estão acordados.
A função devolve `true` se for possível sinalizar o prisioneiro, com base no estado das duas personagens.
Caso contrário, devolve `false`:

```rust
let archer_awake = false;
let prisoner_awake = true;
can_signal_prisoner(archer_awake, prisoner_awake); // true
```

## 4. Verifica se é possível libertar o prisioneiro

Define a função `can_free_prisoner()`, que recebe quatro valores Boolean.
Os primeiros três parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados.
O último parâmetro indica se o cão da Annalyn está presente.
A função devolve `true` se for possível libertar o prisioneiro, com base no estado das três personagens e na presença do cão da Annalyn.
Caso contrário, devolve `false`:

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
let dog_present = false;
can_free_prisoner(knight_awake, archer_awake, prisoner_awake, dog_present); // false
```
