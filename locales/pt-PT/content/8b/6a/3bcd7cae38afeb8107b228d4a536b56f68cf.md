# Introdução

As expressões regulares são uma forma muito versátil de _fazer correspondência de padrões_ em strings, recorrendo a uma linguagem específica de domínio (DSL) criada para esse efeito.

Tal como várias outras linguagens de programação, a Julia não tenta implementar a sua própria biblioteca de Regex. Em vez disso, usa a popular biblioteca [PCRE2][PCRE], proporcionando assim uma sintaxe de Regex idêntica à do (por exemplo) Gleam e muito semelhante à do Javascript.

A interface da Julia para expressões regulares está descrita no [manual][regex].

Uma expressão regular em Julia é simplesmente uma string precedida de `r` antes da `"` de abertura.
Toda a funcionalidade básica faz parte da biblioteca padrão.

Na verdade, muitas das funções já abordadas no Conceito [`Strings`][strings] estão concebidas, por omissão, para pesquisas com Regex, como é o caso de `occursin()`.

```julia-repl
julia> re = r"test$"
r"test$"

julia> typeof(re)
Regex

# Does a string end with "test"?
julia> occursin(re, "this is a test")
true

julia> occursin(re, "these are tests")
false
```

Podem seguir-se carateres modificadores à aspa de fecho, como o `i` para uma correspondência que não distingue maiúsculas de minúsculas.

```julia-repl
julia> occursin(r"test", "Testing")
false

julia> occursin(r"test"i, "Testing")
true
```

## Capturas

Muitas vezes queremos saber _o que_ corresponde ao padrão. Conseguimos isto incluindo grupos de captura entre parênteses dentro da regex e usando depois a função [`match()`][match].

```julia-repl
julia> m = match(r"(\d+g) .* (\d+ml)", "dissolve 25g sugar in 200ml water")
RegexMatch("25g sugar in 200ml", 1="25g", 2="200ml")

julia> m.captures
2-element Vector{Union{Nothing, SubString{String}}}:
 "25g"
 "200ml"

# how many matches?
julia> length(m.captures)
2

# what matched?
julia> m[1], m[2]
("25g", "200ml")

# Starting positions of the matches (character index)
julia> m.offsets
2-element Vector{Int64}:
 10
 23
```

Claro que as correspondências podem falhar.
O resultado será então o valor especial `Nothing` em vez de um `RegexMatch`, por isso prepara-te para testar isso.

```julia-repl
# failed match
m = match(r"(not here)", "dissolve 25g sugar in 200ml water")

julia> typeof(m)
Nothing

julia> isnothing(m)
true
```

Apesar de `match` começar, por omissão, no início da string, também podemos especificar um deslocamento `n` para ignorar os primeiros `n` carateres.

```julia-repl
# capture first match
julia> m = match(r"(\wat)", "cat, sat, mat")
RegexMatch("cat", 1="cat")

# ignore first 5 characters, then match
julia> m = match(r"(\wat)", "cat, sat, mat", 5)
RegexMatch("sat", 1="sat")
```

Em Julia, `match()` só encontra a _primeira_ correspondência dentro da string de destino: não existe um modificador global como nalgumas outras linguagens.

Em vez disso, temos [`eachmatch()`][eachmatch], que devolve um iterador de correspondências.
A avaliação é preguiçosa, por isso podes ter de o converter para o formato que quiseres.

```julia-repl
julia> matches = eachmatch(r"(\wat)", "cat, sat, mat")
Base.RegexMatchIterator{String}(r"(\wat)", "cat, sat, mat", false)

# convert to vector
julia> collect(matches)
3-element Vector{RegexMatch}:
 RegexMatch("cat", 1="cat")
 RegexMatch("sat", 1="sat")
 RegexMatch("mat", 1="mat")

# convert with comprehension
julia> [m.match for m in matches]
3-element Vector{SubString{String}}:
 "cat"
 "sat"
 "mat"

# broadcast an anonymous function
julia> (m -> m.match).(matches)
3-element Vector{SubString{String}}:
 "cat"
 "sat"
 "mat"
```

## Substituição

Uma razão comum para usar uma Regex é substituir a correspondência por uma string diferente.

A função [`replace()`][replace] foi abordada no Conceito [`Strings`][strings], usando literais de string para procurar.
A mesma função pode tirar partido de todo o poder da correspondência com Regex.

```julia-repl
julia> replace("some string", r"[aeiou]" => "*")
"s*m* str*ng"

julia> replace("first second", r"(\w+) (?<agroup>\w+)" => s"\g<agroup> \1")
"second first"
```

O segundo exemplo acima mostra como tanto grupos de captura numerados como nomeados podem ser usados na substituição, dentro de uma string `s" "`.

Consulta o [manual][regex] para mais detalhes: este é um tema que obriga constantemente a maioria dos programadores a voltar à documentação!
