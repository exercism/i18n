# Introdução

Ao contrário de muitas outras linguagens, existem em JavaScript duas entidades diferentes que representam a ausência de um valor (com significado).
São `null` e `undefined`.

## Null

O valor primitivo `null` é usado como um "valor vazio" intencional para variáveis de qualquer tipo.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Podes verificar se uma variável é null com o [operador de igualdade estrita][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Uma variável à qual não foi atribuído um valor é do tipo `undefined`.<sup>1</sup>

Isto significa que, enquanto null representa um valor vazio (mas ainda um valor), undefined representa a ausência total de um valor. 🤯

O undefined aparece em contextos diferentes.

- Se uma variável é declarada sem um valor (inicialização), é undefined.
- Se tentares aceder ao valor de uma chave inexistente num objeto, obténs undefined.
- Se uma função não devolve um valor, o resultado é undefined.
- Se um argumento não é passado a uma função, é undefined, a não ser que esse argumento tenha um valor predefinido.

```javascript
let name;
console.log(name);
// => undefined
```

Podes verificar se uma variável é undefined com o operador de igualdade estrita `===`.

```javascript
let name;

name === undefined;
// => true
```

## Encadeamento opcional

Se tentares obter um valor aninhado num objeto, mas a chave principal não existir, o JavaScript lança um erro.
Para evitar isto facilmente, o encadeamento opcional foi adicionado à especificação da linguagem em 2020.
Com o operador de encadeamento opcional `?.`, podes garantir que o JavaScript só tenta aceder à chave aninhada se a chave principal não for null nem undefined.
Caso contrário, é devolvido undefined.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Coalescência nula

Há situações em que queres aplicar um valor predefinido caso uma variável seja null ou undefined (mas só nesse caso).
Para resolver isto, o operador de coalescência nula `??` foi introduzido em 2020.
Devolve o operando do lado direito apenas quando o operando do lado esquerdo é null ou undefined.
Caso contrário, é devolvido o operando do lado esquerdo.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
