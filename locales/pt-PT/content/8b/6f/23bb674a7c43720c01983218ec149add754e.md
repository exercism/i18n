# Introdução

## Funções externas

O Gleam pode correr na máquina virtual do Erlang (BEAM) ou em ambientes de execução de JavaScript. Há muitas outras linguagens que usam estes ambientes de execução, e é frequentemente útil poder chamar, a partir do Gleam, código escrito nessas linguagens.

A funcionalidade de _funções externas_ do Gleam permite importar para o Gleam funções escritas noutras linguagens e chamá-las sem qualquer sobrecarga em tempo de execução.

Se o teu projeto Gleam correr na máquina virtual do Erlang e quiseres chamar a função `reverse` do módulo `lists` do Erlang, podes fazê-lo adicionando o atributo `@external` ao cabeçalho de uma função Gleam, assim:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Depois, podes chamá-la como uma função Gleam normal:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Se tentares compilar este código para ambientes de execução de JavaScript, a compilação falha com uma mensagem de erro, pois não existe nenhuma implementação para JavaScript. Podes especificar outra implementação para ambientes de execução de JavaScript, assim:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Também é possível escrever uma implementação em Gleam que será usada quando não existir nenhuma implementação externa para o alvo de compilação atual:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## Tipos externos

Os tipos externos permitem referir tipos de dados definidos noutras linguagens, como o Erlang ou o JavaScript.

Para definir um tipo externo, declara um tipo sem fornecer quaisquer construtores. Depois, podes usá-lo da mesma forma que qualquer outro tipo.

```gleam
pub type OrderedDictionary(element)
```
