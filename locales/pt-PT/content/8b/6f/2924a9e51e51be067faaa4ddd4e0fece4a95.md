# Introdução

## Recursão

As funções recursivas são funções que se chamam a si próprias.

Uma função recursiva tem de ter pelo menos um _caso base_ e pelo menos um _caso recursivo_.

Um _caso base_ devolve um valor sem voltar a chamar a função.
Um _caso recursivo_ volta a chamar a função, modificando o valor de entrada para que, em determinado momento, corresponda ao caso base.

Em Elm, as funções recursivas são normalmente definidas com correspondência de padrões, usando expressões `case` ou várias cláusulas de função.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### Ciclos através da recursão

Devido à imutabilidade, os ciclos em Elm escrevem-se de forma diferente das linguagens imperativas.
Por exemplo, os ciclos têm habitualmente este aspeto:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Numa linguagem funcional como Elm, não é possível modificar variáveis.
Por isso, os ciclos têm de ser implementados com recursão.

O equivalente a um ciclo `for` em Elm seria algo assim:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

Na prática, iterar sobre listas e outras estruturas de dados em Elm faz-se quase sempre com funções do módulo `List`, como `List.map`, `List.filter` e `List.foldl`.
Internamente, estas funções são implementadas com recursão.
