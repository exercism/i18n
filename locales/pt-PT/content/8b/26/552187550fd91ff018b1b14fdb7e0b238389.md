# Instruções

Após uma revisão de segurança recente, foi-te pedido que limpasses os ficheiros de registo arquivados da organização.

## 1. Identifica as linhas de registo corrompidas

Precisas de ter uma ideia de quantas linhas de registo no teu arquivo não cumprem os padrões atuais.
Acreditas que um teste simples revela se uma linha de registo é válida.
Para ser considerada válida, uma linha deve começar por uma das seguintes strings:

- `[DEBUG]`
- `[INFO]`
- `[WARNING]`
- `[ERROR]`

Implementa a função `is_valid_line` para devolver `True` se a linha de registo for válida.

```gleam
log_parser.valid_line("[ERROR] Network Failure")
// -> True

log_parser.valid_line("Network Failure")
// -> False
```

## 2. Divide a linha de registo

Pouco depois de começares o projeto de análise de registos, dás-te conta de que os registos de uma aplicação não estão divididos em linhas como os das outras.
Neste projeto, o que deviam ser linhas separadas está, em vez disso, numa única linha, ligado por setas extravagantes como `<--->` ou `<*~*~>`.

Na verdade, qualquer string que tenha `<` como primeiro caráter, `>` como último caráter e zero ou mais dos seguintes carateres `~`, `*`, `=`, e `-` entre eles pode ser usada como separador nos registos deste projeto.

Implementa a função `split_line` que recebe uma linha e devolve uma lista de strings.

```gleam
log_parser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
// -> ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Etiqueta as linhas com nomes de utilizador

Reparaste que algumas das linhas de registo incluem frases que se referem a utilizadores.
Estas frases contêm sempre a string `"User"`, seguida de um ou mais carateres de espaço em branco e, depois, um nome de utilizador.
Decidiste etiquetar essas linhas.

Implementa uma função `tag_with_user_name` que processa linhas de registo:

- As linhas que não contêm a string `"User"` permanecem inalteradas.
- Nas linhas que contêm a string `"User"`, acrescenta ao início da linha `[USER]` seguido do nome de utilizador.

```gleam
log_parser.tag_with_user_name("[INFO] User Alice created a new project")
// -> "[USER] Alice [INFO] User Alice created a new project"
```

Podes assumir que:

- Cada ocorrência da string `"User"` é seguida de um ou mais carateres de espaço em branco e do nome de utilizador.
- Existe, no máximo, uma ocorrência da string `"User"` em cada linha.
- Os nomes de utilizador são strings não vazias que não contêm espaços em branco.
