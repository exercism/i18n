## Tarefas bónus

Se tentares estas tarefas, escreve os teus próprios testes para elas no ficheiro da tua solução!

* Define uma macro de string para que `isbn"3-598-21507-X" == ISBN("3-598-21507-X")`.

* Deixa também o construtor aceitar ISBN-13. O mesmo ISBN deve ser considerado igual independentemente do formato: `ISBN("1-234-56789-X") == ISBN("978-1-234-56789-7")`.

* Define uma função ou um iterador para gerar um ISBN válido, talvez até a partir de um ISBN inicial.

 Consegues guardar o ISBN como um número inteiro em vez de uma string, e seria isso alguma vez uma boa ideia?
 Se o fizesses, continuarias a conseguir imprimir o ISBN (incluindo o algarismo de controlo) como uma string?
