# Introdução

Filtrar é o processo de criar uma sequência a partir de outra, copiando todos os elementos da sequência original exceto alguns deles.
A escolha dos itens a incluir na nova sequência pode ser feita com uma função de predicado (uma função que devolve verdadeiro ou falso) ou por igualdade com um objeto específico.

## Remover por um predicado

`remove-if` é uma função que recebe uma função de predicado e uma sequência como argumentos e devolve uma sequência só com os elementos para os quais o predicado deu falso.
Por outras palavras, "remove" todos os elementos da sequência para os quais o predicado dá verdadeiro. No entanto, repara que esta função não modifica a sequência original!
Em vez disso, devolve uma nova sequência sem os elementos em questão. Se o predicado der verdadeiro para todos os valores, é devolvida uma sequência vazia.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Remover um item específico

Se quiseres remover um item específico de uma sequência, podes usar `remove`, que recebe o item a remover e uma sequência.
São devolvidos todos os valores da sequência que não sejam iguais ao item a remover.
NOTA: por predefinição, a igualdade é verificada com o `eql`, o [predicado de igualdade genérico][concept-equality].

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
