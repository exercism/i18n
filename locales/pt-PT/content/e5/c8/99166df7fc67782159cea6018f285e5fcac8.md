# Sobre

A ligação descreve a partir de onde, no código, se pode aceder a um identificador.
Os valores com âmbito de bloco, de função ou de protótipo de função não têm ligação.
Isto significa que não se pode aceder a eles fora do seu âmbito.
Para mais informações sobre âmbito, consulta o [conceito de âmbito](../scope/introduction.md#Introduction).

## Ligação externa

Os identificadores com âmbito de ficheiro têm ligação externa por predefinição.
Pode chamar-se um identificador com ligação externa a partir de qualquer ficheiro do programa.

## Ligação interna

Pode fazer-se com que um identificador com âmbito de ficheiro tenha ligação interna através do especificador `static`.
Um identificador com ligação interna só pode ser usado dentro do seu ficheiro.

Por exemplo

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

A ligação estática não deve ser confundida com a duração de armazenamento estática.
Para mais informações sobre a duração de armazenamento estática, consulta o [conceito de duração de armazenamento](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).

Se um valor (ao contrário de uma função) for declarado num cabeçalho mas for definido no ficheiro de origem como um identificador `static` com âmbito de ficheiro e com um valor inicializado, o seu valor inicializado não será acessível a partir de fora do respetivo ficheiro de origem.
Pode compilar, ligar e executar sem erro, mas o valor será o valor zero para o identificador, mesmo que o valor seja declarado com `extern`.
(Para mais informações sobre `extern`, consulta o [conceito de `extern`](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit).)
Um identificador com âmbito de ficheiro marcado como `static` num ficheiro de origem não deve ser declarado no respetivo ficheiro de cabeçalho.
