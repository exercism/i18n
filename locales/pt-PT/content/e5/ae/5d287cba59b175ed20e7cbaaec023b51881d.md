# Introdução

## Sintaxe geral

O ciclo for é uma das instruções mais usadas para executar repetidamente alguma lógica.
Em Go, é composto pela palavra-chave `for`, por um cabeçalho e por um bloco de código que contém o corpo do ciclo, delimitado por chavetas.
O cabeçalho é composto por 3 componentes separados por pontos e vírgulas (`;`): init, condition e post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- O componente **init** é código que só corre uma vez, antes de o ciclo começar.
- O componente **condition** tem de ser uma expressão que resulte num valor Boolean e que controle quando o ciclo deve parar.
  O código dentro do ciclo será executado enquanto esta condição for verdadeira.
  Assim que esta expressão for avaliada como falsa, não haverá mais iterações do ciclo.
- O componente **post** é código que corre no final de cada iteração.

**Nota:** Ao contrário de outras linguagens, não há parênteses `()` à volta dos três componentes do cabeçalho.
Na verdade, inserir esses parênteses é um erro de compilação.
No entanto, as chavetas `{ }` à volta do corpo do ciclo são sempre obrigatórias.

## Ciclos for - um exemplo

O componente init costuma preparar uma variável contadora, o componente condition verifica se o ciclo deve continuar ou parar e o componente post costuma incrementar o contador no final de cada repetição.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Este ciclo imprime os números de `1` a `9` (incluindo o `9`).
Definir o passo faz-se frequentemente com uma instrução de incremento ou de decremento, como mostra o exemplo acima.
