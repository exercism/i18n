# Adenda às instruções

~~~~exercism/note

A descrição acima fala de [_conjuntos matemáticos_][math-sets], mas também de que um terno pitagórico {a, b, c} _**tem**_ de estar ordenado de modo que a < b < c (_ordem crescente_). 

É por isso que o [`set` do Python][python-sets] não serve para este exercício, já que é intrinsecamente _não ordenado_. 
Em vez disso, deves devolver uma [`list`][python-list] de `list`s (_por exemplo, `[[a, b, c]]`_). 
Podes gerar os próprios ternos na ordem que quiseres, uma vez que a ordem da `list` que os contém é ignorada nos testes. 

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
