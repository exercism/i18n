# Apêndice às instruções

## Registos

| Registo | Utilização       | Tipo    | Descrição                                          |
| ------- | ---------------- | ------- | -------------------------------------------------- |
| `$a0`   | valor de entrada | endereço | string terminada em null com carateres binários   |
| `$v0`   | valor de saída   | inteiro | valor decimal da string de entrada                 |
| `$t0-9` | temporário       | qualquer | usado para armazenamento temporário               |
