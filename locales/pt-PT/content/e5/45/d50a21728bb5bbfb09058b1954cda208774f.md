# Anexo às instruções

## Dicas

Para teres aqui o grau de desafio adequado, deves usar apenas a funcionalidade
disponível no Prelude. Tenta não usar Data.List, Data.Char, Data.Bits nem Numeric.

Tenta usar seq, $! ou BangPatterns de forma adequada, para garantir
que a solução é eficiente.

Não é necessário tratar entradas inválidas.

Se já fizeste o exercício Octal, talvez o devas generalizar.
