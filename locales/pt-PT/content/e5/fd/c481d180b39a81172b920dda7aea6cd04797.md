# Instruções

Neste exercício, vais implementar a lógica da missão para um novo jogo de interpretação de papéis que um amigo está a desenvolver. A personagem principal do jogo é a Annalyn, uma rapariga corajosa com um cão de estimação feroz e leal. Infelizmente, o desastre acontece: a sua melhor amiga foi raptada enquanto procurava bagas na floresta. A Annalyn vai tentar encontrar e libertar a sua melhor amiga, podendo levar o cão com ela nesta missão.

Depois de algum tempo a seguir o rasto da sua melhor amiga, encontra o acampamento onde esta está aprisionada. Acontece que há dois raptores: um cavaleiro poderoso e um arqueiro astuto.

Depois de encontrar os raptores, a Annalyn considera quais das seguintes ações pode realizar:

- Ataque rápido: pode fazer-se um ataque rápido se o cavaleiro estiver a dormir, pois ele leva tempo a vestir a armadura, ficando vulnerável.
- Espionar: o grupo pode ser espionado se pelo menos um deles estiver acordado. Caso contrário, espionar é uma perda de tempo.
- Sinalizar a prisioneira: pode sinalizar-se a prisioneira com sons de pássaros se a prisioneira estiver acordada e o arqueiro estiver a dormir, pois os arqueiros são treinados em sinalização com sons de pássaros, pelo que poderiam intercetar a mensagem.
- _Libertar a prisioneira_: a Annalyn pode tentar entrar às escondidas no acampamento para libertar a prisioneira.
  Isto é arriscado e só pode ter sucesso de uma de duas formas:
  - Se a Annalyn tiver o cão de estimação com ela, pode resgatar a prisioneira se o arqueiro estiver a dormir.
    O cavaleiro tem medo do cão e o arqueiro não terá tempo de se preparar antes de a Annalyn e a prisioneira conseguirem escapar.
  - Se a Annalyn não tiver o cão, então ela e a prisioneira têm de ser muito furtivas!
    A Annalyn pode libertar a prisioneira se esta estiver acordada e o cavaleiro e o arqueiro estiverem ambos a dormir, mas se a prisioneira estiver a dormir não pode ser resgatada: a prisioneira assustar-se-ia com o aparecimento súbito da Annalyn e acordaria o cavaleiro e o arqueiro.

Tens quatro tarefas: implementar a lógica para determinar se as ações acima estão disponíveis com base no estado das três personagens encontradas na floresta e se o cão de estimação da Annalyn está presente ou não.

## 1. Verificar se é possível fazer um ataque rápido

Implementa o método `canFastAttack()` que recebe um valor do tipo Boolean que indica se o cavaleiro está acordado. Este método devolve `true` se for possível fazer um ataque rápido com base no estado do cavaleiro. Caso contrário, devolve `false`:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. Verificar se o grupo pode ser espionado

Implementa o método `canSpy()` que recebe três valores do tipo Boolean, indicando se o cavaleiro, o arqueiro e a prisioneira estão acordados, respetivamente. O método devolve `true` se o grupo puder ser espionado, com base no estado das três personagens. Caso contrário, devolve `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Verificar se é possível sinalizar a prisioneira

Implementa o método `canSignalPrisoner()` que recebe dois valores do tipo Boolean, indicando se o arqueiro e a prisioneira estão acordados, respetivamente. O método devolve `true` se for possível sinalizar a prisioneira, com base no estado das duas personagens. Caso contrário, devolve `false`:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Verificar se a prisioneira pode ser libertada

Implementa o método `canFreePrisoner()` que recebe quatro valores do tipo Boolean. Os primeiros três parâmetros indicam se o cavaleiro, o arqueiro e a prisioneira estão acordados, respetivamente. O último parâmetro indica se o cão de estimação da Annalyn está presente. O método devolve `true` se a prisioneira puder ser libertada com base no estado das três personagens e na presença do cão de estimação da Annalyn. Caso contrário, devolve `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
