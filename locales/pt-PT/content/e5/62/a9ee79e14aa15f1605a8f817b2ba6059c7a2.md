# Introdução

Uma *expressão regular* (regex) é um pequeno padrão que descreve o
aspeto que um texto deve ter. Em vez de verificares um string caráter a
caráter, escreves a forma que queres uma única vez e deixas o Factor
fazer a correspondência. As ferramentas de regex do Factor estão no
vocabulário [`regexp`][regexp].

## Escrever um padrão

No Factor, escreves uma regex entre `R/ ` e `/`:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

A maioria dos carateres de um padrão significa apenas o próprio caráter:
`R/ cat/` corresponde ao texto `cat`. O poder vem de algumas peças
especiais que representam *tipos* de carateres ou *quantos* deles.

### Classes de carateres: um caráter de um conjunto

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

Uma classe corresponde exatamente a *um* caráter. `[A-Z]` corresponde a
`Q`, mas não a `QQ`.

### Quantificadores: quantas vezes

Coloca um destes *depois* de uma peça para indicar quantas vezes ela pode
repetir-se:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

Assim, `\d{4}` significa quatro algarismos seguidos, e `[A-Z]+` significa
uma ou mais letras maiúsculas. Juntando tudo, `R/ [A-Z]+-\d+/` descreve
«uma ou mais maiúsculas, um hífen e, depois, um ou mais algarismos»:
texto como `SALE-2024`. Aqui, o `-` é um caráter normal: fora de `[ ]`,
um hífen corresponde apenas a um hífen (dentro de uma classe, como em
`[A-Z]`, marca um intervalo).

## Corresponder a um string completo

`matches?` responde a «este string *inteiro* encaixa no padrão?»: o
padrão tem de dar conta de todos os carateres, do início ao fim:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

Mesmo que `SALE-2024` esteja dentro de `"GET SALE-2024"`, `matches?`
continua a dizer `f`: os carateres extra fazem parte do string e não
encaixam no padrão. Quando só te interessa saber se o padrão aparece
*algures*, recorre a `re-contains?`: devolve `t` exatamente onde
`matches?` devolveu `f`:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## Encontrar correspondências em textos mais longos

`re-contains?` diz-te apenas *se* o padrão está lá. As palavras seguintes
olham para dentro e indicam *o que* correspondeu:
`all-matching-subseqs` devolve todos os locais onde o padrão corresponde,
como uma sequência de strings, e `count-matches` apenas os conta:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## Substituir correspondências

`re-replace` troca cada correspondência por um texto de substituição e
devolve o novo string:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

O vocabulário `regexp` tem mais palavras que vale a pena conhecer: segue
as ligações para mais detalhes: [`first-match`][first-match] (apenas a
primeira correspondência) e [`re-split`][re-split] (divide um string
sempre que o padrão corresponde).
