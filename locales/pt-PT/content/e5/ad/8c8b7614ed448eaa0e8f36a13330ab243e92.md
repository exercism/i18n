# Testes

Executa os testes com:

```shell
npm run test
```

Também podes executar o Jest em modo "watch", que volta a executar os teus testes automaticamente quando guardas alterações no código ou no módulo de testes:

```shell
npm run watch
```

## Compreender os testes ignorados

O método skip indica à suite de testes que não execute um teste. Esta função também pode ser usada através dos seguintes nomes alternativos: `it.skip(name, fn)` ou `xit(name, fn)` ou `xtest(name, fn)`

- Porque é que são ignorados ?

Para permitir que os utilizadores se concentrem num teste de cada vez e os ativem um a um à medida que desenvolvem a solução.

- Como os ativar ?

Altera `xtest` para `test`.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
