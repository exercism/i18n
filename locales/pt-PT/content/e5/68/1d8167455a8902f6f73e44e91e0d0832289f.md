# Testes

Para cada exemplo, são necessários os seguintes passos gerais.

Primeiro, muda o diretório para o exercício que queres praticar, neste caso o `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

De seguida, corre os testes. O alvo `test` do make depende de `compile`, por isso correr `make test` garante que o teu código-fonte é compilado e avança depois para a execução dos testes.


```bash
$ make test
```

Parabéns! Tens testes a falhar!!!

Agora lê o `README.md` para descobrires o que precisas de fazer para pôr todos os teus testes a passar.


Corrige o primeiro erro indicado pelos testes e volta a correr os testes.

```bash
$ make test
```

Continua a corrigir o teste seguinte que falha no teu código-fonte e a correr os testes até todos passarem.

Quando todos os testes passarem, dá uma última vista de olhos ao teu código no diretório `src` para garantir que estás satisfeito com ele e submete-o para revisão.

Obtém feedback, revê a solução, submete, tenta o exercício seguinte e repete o processo até alcançares a iluminação do LFE.
