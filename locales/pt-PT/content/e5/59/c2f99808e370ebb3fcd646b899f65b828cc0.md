# Dicas

A menos que estejas muito à vontade com as tuas capacidades de Regex, pode ajudar-te experimentar a sintaxe num ambiente online como o [Regex101][regex101].

Lembra-te de definir o flavor para PCRE2.

Pré-definir cada expressão regular como uma `const` pode ser um estilo útil (para clareza e desempenho).

## 1. Verifica se o comando é válido

- O caráter de ancoragem para o início da string é `^`.
- Só precisas de obter verdadeiro ou falso na pesquisa da regex.
- Isto poderia ser resolvido sem usar uma Regex, mas mantém-te dentro do espírito de um exercício de conceito.

## 2. Remove os emojis encriptados

- Um simples [`replace()`][replace].

## 3. Verifica se o número de telefone é válido

- Precisa de uma Regex mais longa, mas bastante repetitiva.
- `n` ocorrências consecutivas podem ser especificadas com a sintaxe `{n}`.
- Só precisamos de um verdadeiro ou falso para a correspondência.

## 4. Obtém a ligação do site

- Lembra-te de escapar o ponto com `\.`
- Captura a parte antes do ponto num [match][match].

## 5. Cumprimenta o utilizador

- Um `replace()` com capturas nomeadas tem o formato `r"(?<name>...) " => s"\g<name>... "`
- Mais uma vez, um `split()` poderia resolver a tarefa, mas praticar uma Regex é útil.
