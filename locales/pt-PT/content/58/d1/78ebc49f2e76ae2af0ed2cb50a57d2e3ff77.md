# Introdução

Um *conjunto disjunto* (uma estrutura união-busca) mantém uma coleção de valores repartida por grupos que não se sobrepõem, e responde rapidamente a uma pergunta: estes dois valores estão no mesmo grupo? Vive no vocabulário [`disjoint-sets`][disjoint-sets].

## Construir um conjunto disjunto

`<disjoint-set>` cria uma estrutura vazia. Os valores (os *átomos*) são adicionados com `add-atom`, um a um, ou com `add-atoms`, a partir de uma sequência. Cada átomo começa num grupo só para si.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

O conjunto disjunto é *mutável*: `add-atom`, `add-atoms` e `equate` alteram-no no local em vez de devolverem um novo. O `keep` dá jeito quando queres o conjunto disjunto de volta na pilha depois de uma destas palavras o ter consumido.

## Unir grupos

O `equate` une os dois grupos que contêm os seus átomos. A união é transitiva: usa `equate` em dois átomos, depois num deles e num terceiro, e os três acabam num único grupo.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Representantes

Cada grupo tem um membro canónico, o seu *representante*. O `representative` devolve-o, e dois átomos pertencem ao mesmo grupo exatamente quando os seus representantes são iguais.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

Qual o átomo que um grupo escolhe como representante é um detalhe interno. Nunca dependas de que seja escolhido um átomo em particular, mas apenas de que dois átomos do mesmo grupo estejam de acordo.
