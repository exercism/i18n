Podes querer renderizar estes widgets em documentos Markdown, por exemplo no fim de um documento, para sugerir leituras extra ou bons exercícios com que aprendas alguma coisa.

**Nota:** também podes usar ligações normais para texto inline, às quais os tooltips serão adicionados. Vê [a documentação de ligações internas](/docs/building/markdown/internal-linking) para mais detalhes.

## Utilização

Podes usar widgets em qualquer sítio onde possas usar Markdown, como na documentação, nas abordagens e nas discussões entre estudantes e mentores.

São renderizados com o seguinte formato:

```md
[<type>:<id>]()
```

As partes `<type>` e `<id>` são variáveis e dependem do widget em questão.

A referência da ligação, ou seja, o conteúdo de `()`, é ignorada pelo site. Podes apontá-la para o que quiseres, para fins de manutenção.

## Widget de exercício

Formato da ligação: `[exercise:<track-slug>/<exercise-slug>]()`

### Exemplo

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## Widget de conceito

Formato da ligação: `[concept:<track-slug>/<concept-slug>]()`

### Exemplo

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## Widget de abordagem

Formato da ligação: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### Exemplo

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## Widget de artigo

Formato da ligação: `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### Exemplo

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
