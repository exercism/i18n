# Introdução

Em geral, não queres reinventar a roda quando se trata de programação.
Para muitos algoritmos padrão, haverá alguém que já pode ter feito o teu trabalho por ti.

## Inclusões

Para incluir o conteúdo de outros ficheiros, o C++ usa a diretiva `include`.
Estas inclusões devem ser indicadas no topo do ficheiro.
Durante a compilação, a linha com a diretiva é substituída pelo conteúdo do ficheiro respetivo.
Depois das inclusões, os namespaces ficam como estavam no ficheiro original.

## A Biblioteca Padrão

A biblioteca padrão oferece muitas funções, algoritmos e estruturas de dados comuns.
A biblioteca padrão usa o namespace `std`.

Um exemplo é a biblioteca numérica do C, `cmath`.
Fornece muitas operações matemáticas comuns.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
As bibliotecas padrão são incluídas com sinais de menor e maior `<>` em vez de aspas duplas `"`.
A diferença está no local onde o compilador procura os ficheiros respetivos.
Na versão com sinais de menor e maior, a procura no projeto atual é ignorada e começa diretamente nos diretórios de inclusão do sistema.
Se quiseres incluir ficheiros locais, usas aspas duplas: `#include "myfile"`
~~~~
