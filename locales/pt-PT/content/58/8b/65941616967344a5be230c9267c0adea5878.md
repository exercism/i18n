# Instruções

O Ozan está a preparar a mixtape perfeita: primeiro decide *que* músicas entram, depois escolhe a *ordem* em que são tocadas. Vais construir os auxiliares de combinatória por trás das suas escolhas no vocabulário `mixtape-maker`.

## 1. Contar combinações

Define `count-combinations` para devolver de quantas formas se podem escolher `k` itens de entre `n`, ignorando a ordem.

```factor
5 2 count-combinations .
! => 10
```

## 2. Contar permutações

Define `count-permutations` para devolver de quantas formas se podem escolher `k` itens de entre `n` quando a ordem importa.

```factor
5 2 count-permutations .
! => 20
```

## 3. Listar combinações

Define `list-combinations` para devolver todas as combinações de `k` elementos de uma sequência.

```factor
{ 1 2 3 } 2 list-combinations .
! => { { 1 2 } { 1 3 } { 2 3 } }
```

## 4. Listar permutações

Define `list-permutations` para devolver todas as ordenações de uma sequência.

```factor
{ 1 2 } list-permutations .
! => { { 1 2 } { 2 1 } }
```

## 5. Combinações cuja soma é um alvo

Define `combinations-summing-to` para devolver apenas as combinações de `k` elementos de uma sequência cujos elementos somam `target`.

```factor
{ 1 2 3 4 } 2 5 combinations-summing-to .
! => { { 1 4 } { 2 3 } }
```
