# Dicas

## 1. Permitir alterar o tempo esperado no forno

- Os [valores predefinidos dos parâmetros][default-parameter-values] podem ser especificados na assinatura da função.
- A especificação do valor predefinido é colocada depois da anotação de tipo do parâmetro.

## 2. Permitir números diferentes de camadas

- Os [parâmetros variádicos][variadic-parameters] podem ser especificados na assinatura da função.
- A notação do parâmetro variádico é colocada depois do nome do tipo do parâmetro.
- O parâmetro variádico de um tipo _T_ fica acessível no corpo da função como um array com elementos do tipo _T_.
  \_ Podes obter o número de elementos de um array chamado `items` acedendo à propriedade count. Ou seja, `items.count`.

## 3. Calcular as quantidades de massa e de molho

- É possível [devolver vários valores de uma função][multiple-return-values] usando um tuplo para os combinar num único valor composto.

## 4. Converter litros em onças fluidas no próprio local

- Os [parâmetros in-out][in-out-parameters] podem ser especificados colocando `inout` antes do nome do tipo do parâmetro.
- O novo valor tem de ser atribuído ao parâmetro antes de a função devolver, para poder ser copiado para a variável que foi passada.

## 5. Determinar o melhor vinho para servir

- As funções podem ser [aninhadas][nested-functions] dentro de outra função, declarando uma função como é habitual dentro de outra função.
- As funções aninhadas podem ser chamadas normalmente dentro das funções em que são definidas.
- As funções aninhadas têm acesso a todos os parâmetros, constantes e variáveis da função que as envolve. Não é preciso passá-los à função aninhada.
