# parâmetro obrigatório inesperado

O parâmetro `${'parameter.name'}` é chamado nos testes com e sem um valor, mas _não está marcado como opcional_, o que significa que os testes não passam. Podes marcar um parâmetro TypeScript como opcional de forma explícita, acrescentando um `?` a seguir ao nome:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

Ou, em alternativa, atribuindo-lhe um valor predefinido:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
