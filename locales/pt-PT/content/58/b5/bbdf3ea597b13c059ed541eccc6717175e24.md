# Dicas

## Geral

- Usa o tipo de [lista (ligada)][list] incorporado.

## 1. Define uma função que devolve uma lista vazia de linguagens

- A função tem de devolver `[]`.

## 2. Define uma função que adiciona uma linguagem à lista

- Um elemento pode ser inserido no início de uma lista com `|`.

## 3. Define uma função que remove uma linguagem da lista

- O Elixir [fornece uma função][tl] que devolve uma lista com o primeiro elemento removido.

## 4. Define uma função que devolve o primeiro elemento da lista

- O Elixir [fornece uma função][hd] para obter o primeiro elemento de uma lista.

## 5. Define uma função que devolve quantas linguagens há na lista

- O Elixir [fornece uma função][length] para contar o comprimento de uma lista.

## 6. Define uma função que determina se a lista inclui uma linguagem funcional

- A tua função deve devolver um valor Boolean que indica se `"Elixir"` é membro da lista. O Elixir [fornece uma função][in] para testar se um elemento pertence à lista.
