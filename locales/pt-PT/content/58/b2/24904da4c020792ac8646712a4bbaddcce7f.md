# Dicas

## Geral

- Há três [operadores lógicos][logical operators] para trabalhar com valores Boolean.
- É possível combinar vários operadores numa única expressão.

## 1. Verificar se é possível fazer um ataque rápido

- O operador lógico NOT (`!`) pode ser colocado antes de uma expressão para negar o seu valor.

## 2. Verificar se é possível espiar o grupo

- Os operadores lógicos são normalmente utilizados para avaliar se duas ou mais expressões são verdadeiras ou não.

## 3. Verificar se é possível sinalizar o prisioneiro

- Os operadores lógicos são executados pela ordem da sua precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Para mais detalhes, consulta a secção Precedência de Operadores na [documentação oficial do Go][operators] e a [tabela de verdade][truth table].
