# Instruções

Tens a tarefa de escrever um serviço que ingere eventos. Cada evento tem uma data associada, mas reparas que estão a ser submetidos três formatos diferentes ao endpoint do teu serviço:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

Consegues ver que existem algumas semelhanças entre si e decides escrever alguns padrões de expressões regulares que se podem compor.

## 1. Faz corresponder o dia, o mês e o ano de uma data

Implementa `day/0`, `month/0` e `year/0` para devolver um padrão de string que, quando compilado, corresponde aos componentes numéricos em `"01/01/1970"` (`dd/mm/yyyy`). O dia e o mês podem aparecer como `1` ou `01` (preenchidos à esquerda com zeros).

```elixir
"31" =~ DateParser.day() |> Regex.compile!()
# => true
"12" =~ DateParser.month() |> Regex.compile!()
# => true
"1970" =~ DateParser.year() |> Regex.compile!()
# => true
```

## 2. Faz corresponder o nome do dia da semana e o nome do mês do ano

Implementa `day_names/0` e `month_names/0` para devolver um padrão de string que, quando compilado, corresponde ao nome do dia da semana e ao nome do mês do ano, respetivamente.

```elixir
"Tuesday" =~ DateParser.day_names() |> Regex.compile!()
# => true
"June" =~ DateParser.month_names() |> Regex.compile!()
# => true
```

## 3. Captura o dia, o mês e o ano

Implementa `capture_day/0`, `capture_month/0`, `capture_year/0`, `capture_day_name/0`, `capture_month_name/0` para devolver um padrão de string que captura os respetivos componentes com os nomes: `"day"`, `"month"`, `"year"`, `"day_name"`, `"month_name"`

```elixir
DateParser.capture_month_name()
|> Regex.compile!()
|> Regex.named_captures("December")

# => %{"month_name" => "December"}
```

## 4. Combina as capturas para capturar a data completa

Implementa `capture_numeric_date/0`, `capture_month_name_date()` e `capture_day_month_name_date/0` para devolver um padrão de string que captura os componentes da parte 3 utilizando o respetivo formato de data:

- data numérica - `"01/01/1970"`
- data com nome do mês - `"January 1, 1970"`
- data com nome do dia e do mês - `"Thursday, January 1, 1970"`

```elixir
DateParser.capture_numeric_date()
|> Regex.compile!()
|> Regex.named_captures("01/01/1970")

# => %{"day" => "01", "month" => "01", "year" => "1970"}
```

## 5. Restringe a captura para corresponder apenas à data

Implementa `match_numeric_date/0`, `match_month_name_date/0` e `match_day_month_name_date/0` para devolver uma expressão regular compilada que apenas corresponde à data e que também consegue capturar os componentes.

```elixir
"Thursday, January 1, 1970 was the Unix epoch." =~ DateParser.match_day_month_name_date()
# => false
"Thursday, January 1, 1970" =~ DateParser.match_day_month_name_date()
# => true

DateParser.match_day_month_name_date()
|> Regex.named_captures("Thursday, January 1, 1970")

# => %{
#     "day" => "1",
#     "day_name" => "Thursday",
#     "month_name" => "January",
#     "year" => "1970"
#   }
```
