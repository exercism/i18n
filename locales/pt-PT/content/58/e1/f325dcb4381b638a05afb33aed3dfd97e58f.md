# Dicas

## 1. Verifica se um valor é um boolean

- Podes usar `typeof` para descobrir o tipo de um valor.
- `typeof` devolve uma string.

## 2. Verifica se um valor é um número.

- Podes usar `typeof` para descobrir o tipo de um valor.
- `typeof` devolve uma string.
- Tens de verificar `Infinity` e `NaN`.
- `NaN` nunca é igual a si próprio, mas existe uma [função incorporada][isNaN] para verificar se um valor é `NaN`.

## 3. Verifica se um valor é um objeto

- Podes usar `typeof` para descobrir o tipo de um valor.
- `typeof` devolve uma string.
- Vais ter de verificar `null`.

## 4. Verifica se uma string é numérica

- Podes usar `typeof` para descobrir o tipo de um valor.
- `typeof` devolve uma string.
- Podes iterar sobre uma string para verificar se todos os carateres são algarismos.

## 5. Verifica se um objeto é eletrónico

- Podes usar `instanceof` para verificar se um objeto é uma instância de uma classe ou de uma das suas subclasses.

## 6. Verifica se um valor é um array não vazio

- Podes usar `typeof` para descobrir o tipo de um valor.
- `typeof` devolve uma string.
- Podes verificar o comprimento de um array para descobrir quantos elementos contém.

## 7. Verifica se um valor é um array vazio

- Podes usar `typeof` para descobrir o tipo de um valor.
- `typeof` devolve uma string.
- Podes verificar o comprimento de um array para descobrir quantos elementos contém.

## 8. Verifica se um objeto tem uma propriedade ou um método `type`

- Podes usar o operador `in` para verificar se um objeto tem uma propriedade ou um método.

## 9. Lança um erro se um objeto não tiver a propriedade ou o método `id`

- Podes usar o operador `in` para verificar se um objeto tem uma propriedade ou um método.
- Se a propriedade ou o método `id` não existir, a tua função deve lançar um `Error`.

## 10. Verifica se um objeto tem uma propriedade `id`

- Para verificar se um objeto tem uma propriedade (e não um método), podes usar a função `Object.hasOwn()`.

## 11. Verifica se um objeto tem uma propriedade `type` definida

- Para verificar se um objeto tem uma propriedade (e não um método), podes usar a função `Object.hasOwn()`.
- Vais ter de aceder à propriedade `type` e verificar se está definida.

[isNaN]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/isNaN
