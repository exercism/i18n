# Sobre

As [guardas][guards] são usadas como complemento da [correspondência de padrões][exercism-pattern-matching], que vamos abordar num conceito mais à frente. As guardas permitem-nos ter diferentes implementações de uma função consoante o valor de entrada e possibilitam verificações mais complexas.

Uma instrução de guarda é definida por uma barra vertical `|` seguida de uma expressão booleana, terminando com um sinal de igual `=` e o corpo da função. Pode haver várias instruções de guarda para uma única função. As instruções de guarda são avaliadas de cima para baixo e a primeira que for avaliada como `True` é executada. Uma instrução de guarda permite uma instrução `otherwise`, que apanha qualquer valor que não corresponda às instruções de guarda anteriores.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

Também podemos definir a nossa própria função e usá-la dentro da instrução de guarda.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
