# String

O tipo de dados `String` é uma série linear de carateres codificados em UTF-8. É útil para armazenar dados textuais.

## Criar uma string

Uma string pode ser criada com as funções associadas `String::new()` ou `String::from()`. Muitos tipos têm um método `to_string` que produz uma string, por exemplo, a partir de um número.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### A macro `format!`

Como produzir uma string grande a partir de uma seleção de tipos de dados mais pequenos é uma operação comum, o Rust também tem um atalho que dispensa os detalhes de chamar `to_string`: a macro `format!`. Por exemplo, podíamos simplificar a construção da string composta acima do seguinte modo:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## Fatias de string

As strings têm uma relação estreita com as fatias de string. As fatias de string são referências imutáveis a uma região de memória de tamanho conhecido, que contém uma série linear de carateres codificados em UTF-8. Qualquer string pode ser convertida numa fatia de string ao ser emprestada com o operador de desreferenciação (`&`). Para converter uma fatia de string numa string, tanto o método `to_string()` como `String::from` são adequados.

No código Rust, uma string literal é escrita entre aspas duplas. Estas strings literais são sempre fatias de string, porque se referem a uma região imutável de memória dentro do executável do programa.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## Alterar uma string

Para concatenar um único caráter a uma string, usa o método `push`. Para concatenar uma fatia de string a uma string, usa o método `push_str` ou o operador `+`.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## Aceder a carateres numa string

Como as strings do Rust são codificadas em UTF-8, os carateres individuais não têm todos o mesmo tamanho. Por isso, o tipo de dados `String` não disponibiliza um operador de indexação (`[]`). Para aceder a todos os carateres ou a um caráter específico de uma string, podes usar o método `chars()`. Este itera sobre cada caráter da string, por ordem.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```
