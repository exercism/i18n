# Sobre

As classes são um bloco fundamental dos programas em Swift.
Permitem agrupar propriedades (dados) e métodos (funções) relacionados em unidades de funcionalidade autónomas.

### Definir classes

Para definir uma classe, usa a palavra-chave `class` seguida do nome da classe, com a definição da classe entre chavetas:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

O corpo de uma classe pode conter propriedades armazenadas, que são definidas e se comportam como constantes (`let`) ou variáveis (`var`) normais.

### Instâncias

A definição de uma classe serve de planta: define um novo tipo e descreve o aspeto dos seus valores, mas, por si só, não cria nenhuma instância.

Para criar uma *instância* de uma classe, chama o seu inicializador escrevendo o nome da classe seguido de parênteses:

```swift
let someCharacter = GameCharacter()
```

Isto cria uma nova instância cujas propriedades são inicializadas com os valores por omissão especificados na definição da classe.
Nas propriedades opcionais sem valor por omissão explícito (como `name`), o Swift atribui-lhes `nil`.

### Aceder às propriedades

Acedes às propriedades de uma instância com a *notação de ponto*: escreve o nome da instância, um ponto (`.`) e o nome da propriedade.
A notação de ponto também funciona com propriedades aninhadas.

Podes usar a notação de ponto para ler valores e, se a propriedade for mutável (`var`), atribuir novos valores:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Métodos

Além das propriedades, as classes podem definir *métodos*, ou seja, funções associadas à classe.

Define métodos dentro do corpo da classe com a sintaxe habitual de `func`.
Se um método alterar uma propriedade, essa propriedade tem de ser declarada com `var`:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Chama métodos numa instância com a notação de ponto, tal como nas propriedades:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Cada instância de uma classe tem uma propriedade implícita chamada `self`, que se refere à própria instância.
Embora seja frequentemente omitido ao referir propriedades ou métodos, o `self` costuma ser usado para distinguir nomes de propriedades de nomes de parâmetros de métodos quando são iguais.
