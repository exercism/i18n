# Instruções

O diretor de cena quer o guião de ensaio dactilografado, e várias partes dele constroem-se repetindo ou juntando coisas.

As quatro tarefas ficam na classe `REHEARSAL_SCRIPT`.

## 1. Repetir uma deixa

Dada uma deixa e um número, devolve a deixa repetida esse número de vezes, sem nada no meio.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

Repetir algo zero vezes dá a string vazia.

## 2. As iniciais do elenco

Dada a lista do elenco, devolve a primeira letra de cada nome, todas seguidas.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. Numerar as falas

Dadas as falas de uma cena, numera-as a partir de um, cada uma na sua própria linha.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

Há uma linha nova *entre* as falas e nenhuma depois da última. Uma cena sem falas dá a string vazia.

## 4. Gritar uma fala

Devolve uma fala com todas as letras em maiúscula.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
