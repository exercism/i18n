# Anexo às instruções

## Implementação

Para completares este exercício, tens de definir o tipo de dados `stopwatch` e implementar as funções:

- newStopwatch
- start
- stop
- lap
- reset
- advanceTime
- getState
- currentLap
- total
- previousLaps

Vais encontrar uma definição de tipo provisória já criada, mas cabe-te a ti definir as funções e criar um tipo de dados com significado.
