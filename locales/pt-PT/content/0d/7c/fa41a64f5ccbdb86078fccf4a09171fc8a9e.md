# Sobre

Qualquer valor pode ser um erro. `throw` (em `kernel`) sinaliza um erro: o efeito de pilha da palavra atual é abandonado e o controlo regressa ao `recover` que o envolve mais próximo.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` é uma palavra de análise que define uma classe de tuplos de erro *e* uma palavra construtora de uma só vez:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

Isso dá a cada erro personalizado uma classe única, um construtor amigável que lança o erro e um predicado de classe (`name?`) com que testar os erros capturados:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

Para uma limpeza ao estilo finally, consulta o `cleanup` em `continuations`. Para condições reiniciáveis, consulta o `condition`.
