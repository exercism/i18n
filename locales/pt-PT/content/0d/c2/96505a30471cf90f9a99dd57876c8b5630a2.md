# Instruções

Enquanto te preparavas para fazer bolachas para os teus amigos, descobriste que tens de converter algumas das medidas usadas na receita.
Como só conheces o sistema métrico, precisas de arranjar uma forma de converter as medidas de culinária mais comuns dos Estados Unidos em mililitros (mL), para te facilitar a vida.

Usa esta tabela de conversão na tua solução:

| Unidade a converter | volume | em mililitros (mL) |
| ------------------- | ------ | ------------------ |
| mL                  | 1      | 1                  |
| chávena americana   | 1      | 240                |
| onça líquida americana | 1   | 30                 |
| colher de chá americana | 1  | 5                  |
| colher de sopa americana | 1 | 15                 |

Como tens talento para a programação e estás em formação, decides usar os mililitros como unidade de transição, para facilitar a conversão de qualquer unidade da lista para qualquer outra (mesmo para ela própria).

## 1. Obter a componente numérica de um par de volume

Implementa o método `KitchenCalculator.get_volume`.
Dado um par de volume, na forma de tuplo, deve devolver apenas a componente numérica.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Converter o par de volume em mililitros

Implementa o método `KitchenCalculator.to_milliliter`.
Dado um par de volume, na forma de tuplo, deve converter o volume em mililitros, usando a tabela de conversão.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Converter o par de volume em mililitros para outra unidade

Implementa o método `KitchenCalculator.from_milliliter`.
Dado um par de volume, na forma de tuplo, e a unidade pretendida, deve converter o volume para a unidade pretendida, usando a tabela de conversão.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Converter de qualquer unidade para qualquer unidade

Implementa o método `KitchenCalculator.convert`.
Dado um par de volume, na forma de tuplo, e a unidade pretendida, deve converter o volume indicado para a unidade pretendida.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
