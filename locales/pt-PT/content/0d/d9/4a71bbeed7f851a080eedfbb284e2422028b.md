# Instruções

Foste contratado como Especialista em Expressões Regulares numa empresa que está a desenvolver um Chatbot.

Está numa fase de desenvolvimento muito básica, por isso a tua missão é usar expressões regulares para melhorar a capacidade do chatbot de compreender e gerar linguagem natural.

## Verifica se o comando é válido

Além de ser inteligente, o Chatbot é também um assistente leal.

Para pedir algo ao chatbot, o utilizador tem de dizer a palavra “**Chatbot**” na primeira posição do comando.

Não faz diferença se a palavra-chave está em MAIÚSCULAS ou minúsculas. O aspeto importante aqui é a posição da palavra.

Implementa a função `isValidCommand()` que ajuda o Chatbot a reconhecer quando o utilizador está a dar um comando.

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## Remove os emojis encriptados

O Chatbot tem dificuldade em compreender como os humanos usam os emojis para expressar as suas emoções.

Quando o chatbot recebe mensagens do utilizador, cada emoji é representado por “_emoji_” seguido do seu número _id_.

Implementa o método `removeEmoji()` para receber uma string e remover toda a encriptação dos emojis ao longo da mensagem.

As linhas que não contêm o texto do emoji devem ser devolvidas sem alterações.

Remove apenas a string do emoji. Não tentes ajustar o espaçamento.

Para este desafio em particular, usa a sintaxe de construtor para criar a expressão regular.

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## Verifica se o número de telefone é válido

Tendo em conta que as funcionalidades do chatbot são descarregadas numa aplicação móvel, espera-se que o utilizador escreva um número de telefone durante a conversa.

O problema é que o chatbot só consegue ler e validar um número com um formato específico.

Se o número for válido (corresponder à sequência de carateres especificada pela **expressão regular**), o chatbot responde com uma mensagem a agradecer ao utilizador e a confirmar o número. Se o número for inválido, a função informa o utilizador de que o número de telefone não é válido.

O formato esperado é: (+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## Obtém o link do site

O Chatbot é um software muito curioso. Apesar de conseguir pesquisar na internet sobre um determinado tema, gosta de perguntar aos utilizadores por sites fixes ou URLs onde possa encontrar informação relevante.

Exemplo de conversa:

- **Chatbot**: Olá username, gostaria de aprender a programar em JavaScript. Conheces algum site fixe onde possa aprender?
- **Utilizador**: Aprendi imenso em [exercism.org](http://exercism.org)

Implementa a função `getURL()` que consegue devolver um array apenas com o link de cada site. Escrever uma regex para reconhecer qualquer URL seria muito complicado, mas o Chatbot só precisa de ler URLs simples. Para este exercício, um URL é qualquer sequência de palavras delimitada por `"."`.

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## Cumprimenta o utilizador

Para guardar os dados de todas as pessoas com quem conversou, o chatbot consegue obter o nome completo a partir do perfil do utilizador neste formato: **“smith, john”**.

Assim, queremos que o nosso chatbot seja muito educado e cause uma boa impressão.

Escreve a função `niceToMeetYou()` que recebe uma string com o nome completo do utilizador e devolve a string **“Nice to meet you, John Smith”**

Para fins de aprendizagem, implementa a função usando um **método de substituição** das expressões regulares.

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
