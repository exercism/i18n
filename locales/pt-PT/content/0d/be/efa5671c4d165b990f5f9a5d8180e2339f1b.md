# Sobre

Os [tipos personalizados][custom-types] em Elm representam um número fixo de casos nomeados. Cada valor corresponde exatamente a um dos casos nomeados. Noutras linguagens e contextos, são conhecidos como _tipos soma_, _uniões discriminadas_, _uniões etiquetadas_ e _tipos de dados algébricos_.

Cada caso de uma união discriminada pode ter dados associados, e casos diferentes podem ter tipos de dados diferentes. Se nenhum dos casos tiver dados associados, a união discriminada é semelhante ao que outras linguagens costumam chamar de _enumeração_ (ou _enum_).

Um tipo personalizado define-se com a palavra-chave `type` e exige muito pouca sintaxe. São uma das técnicas mais importantes da programação em Elm e servem para fazer com que os valores possíveis no código correspondam exatamente aos valores válidos na vida real. Assim não sobra margem para dados inválidos e torna-se impossível representar no código [estados impossíveis][impossible-states].

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

Podes criar um valor para um caso específico referindo o seu nome (`Spring`), quando este está definido no mesmo módulo ou é importado com a sintaxe `import SeasonModule exposing (Season(..))`, ou referindo o seu nome totalmente qualificado (`Season.Spring`) quando é importado com a sintaxe `import SeasonModule exposing (Season)`.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

Os tipos personalizados, tal como tudo em Elm, têm _igualdade estrutural_, o que significa que dois valores para o mesmo caso e com os mesmos dados (opcionais) são equivalentes.

A forma preferida de trabalhar com tipos personalizados é a [correspondência de padrões][pattern-matching]:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
