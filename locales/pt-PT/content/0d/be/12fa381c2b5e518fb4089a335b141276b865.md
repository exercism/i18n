# Introdução

As funções podem declarar valores por omissão para um ou mais argumentos. Vamos ver esta função:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Quando é compilada, o Elixir cria uma definição de função para `number/0` (sem argumentos) e para `number/1` (um argumento).

Se mais do que um argumento tiver valor por omissão, os valores por omissão são aplicados à função da esquerda para a direita, para preencher os argumentos que faltam.

Se a função tiver mais do que uma cláusula, os argumentos por omissão devem ser definidos no cabeçalho de uma função (uma função sem corpo) antes das cláusulas da função:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
