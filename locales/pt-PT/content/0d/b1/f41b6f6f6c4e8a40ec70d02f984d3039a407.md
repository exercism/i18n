# Ajuda

Abaixo estão alguns recursos para obter ajuda se tiveres problemas:

- [O site principal do projeto Uiua][main] tem [documentação][docs], exemplos, tutoriais e recursos da comunidade.
- [A comunidade do Exercism no Discord][exercism-discord]
- A [comunidade Uiua no Discord][discord] é uma comunidade muito prestável e ativa.
- O [tutorial de introdução][tutorial] dá uma visão geral ampla e tem pequenos exercícios para aprender Uiua.
- O [Uiua Pad][pad] para percorrer pequenos fragmentos de código visualmente.
- [/r/apljk/][apl-reddit] é um subreddit para linguagens do tipo APL.

Além disso, o [StackOverflow][so] é um bom sítio para procurar o teu problema ou a tua pergunta e ver se já foi respondido.
Se não, podes sempre [perguntar][ask-so] ou [responder][answer-so] à pergunta de outra pessoa.
