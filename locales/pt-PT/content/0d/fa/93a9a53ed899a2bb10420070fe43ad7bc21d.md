# Introdução

## Arrays

Em C#, as estruturas de dados que podem conter zero ou mais elementos são conhecidas como _coleções_. Um **array**, ou _vetor_, é uma coleção que tem um tamanho/comprimento fixo e cujos elementos têm obrigatoriamente de ser todos do mesmo tipo. Os elementos podem ser atribuídos a um array ou obtidos a partir dele através de um índice. Os arrays de C# são de base zero, ou seja, o índice do primeiro elemento é sempre zero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Os arrays também podem ser definidos com uma notação abreviada que te permite criar o array e definir o seu valor ao mesmo tempo. Como o compilador consegue agora determinar quantos elementos o array vai ter, o comprimento pode ser omitido:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Podes manipular arrays chamando os métodos ou as propriedades de uma instância de array, ou usando os métodos estáticos definidos na classe `Array`.

## Ciclos for

Um ciclo `for` permite executar código repetidamente até que uma condição seja cumprida.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Um ciclo `for` é composto por quatro partes:

1. O inicializador: executado uma vez antes de entrar no ciclo. Normalmente serve para definir variáveis usadas dentro do ciclo.
2. A condição: executada antes de cada iteração do ciclo. O ciclo continua a executar enquanto o resultado da avaliação for `true`.
3. O iterador: executado após cada iteração do ciclo. Normalmente serve para modificar (muitas vezes, incrementar ou decrementar) as variáveis do ciclo.
4. O corpo: o código que é executado em cada iteração do ciclo.

## Ciclos foreach

O facto de um array ser também uma _coleção_ significa que, além de acederes a valores por índice, podes iterar sobre _todos_ os seus valores com um ciclo `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
