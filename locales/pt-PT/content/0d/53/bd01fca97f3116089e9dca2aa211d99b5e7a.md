# Introdução

Em Cairo, os módulos ajudam a organizar o código, agrupando funções, structs e traits relacionados em espaços de nomes separados.
A palavra-chave `use` simplifica o acesso a estes itens, ao trazê-los para o âmbito, o que reduz a repetição ao chamar funções ou usar tipos.
Esta secção aborda boas práticas para estruturar módulos, importar itens de forma eficiente e reexportar para um código mais limpo e fácil de manter.
