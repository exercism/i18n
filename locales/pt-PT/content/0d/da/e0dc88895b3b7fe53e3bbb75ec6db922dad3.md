# Introdução

## Noções básicas

Vamos assumir que estás familiarizado com a sintaxe e os tipos de dados do JSON.

O `jq` funciona passando os dados JSON de entrada por uma _expressão única_ (escrita como um _pipeline de filtros_) para obter os dados transformados que pretendes.

<!-- prettier-ignore -->
~~~~exercism/note
A linguagem `jq` é implementada pelo _programa_ `jq`.
Este programa oferece várias opções de linha de comandos úteis para controlar como os dados de entrada são consumidos e como a saída é apresentada.

Nos exemplos abaixo vais encontrar:

- `-n` ou `--null-input`

    Normalmente, o programa `jq` recebe um ficheiro para ler, ou envias-lhe dados.
    A opção `--null-input` permite-te gerar dados JSON sem quaisquer dados de entrada.

- `-c` ou `--compact-output`

    O `jq` imprime a saída formatada por omissão.
    É extremamente útil para os humanos ver os dados quando estão bem formatados.
    No entanto, isso não é necessário para as máquinas: a opção `--compact-output` remove os espaços em branco da formatação para minimizar o tamanho do JSON resultante.

- `-f filename` ou `--from-file filename`

    Lê o programa `jq` a partir de `filename` em vez de o fornecer na linha de comandos.
    Tanto o `sed` como o `awk` usam a opção `-f` para o mesmo fim.
    Vais ver isto a ser usado nos scripts de teste dos exercícios de prática.

O resto desta lição vai focar-se na _linguagem_ `jq`.
~~~~

<!-- prettier-ignore-end -->

### Filtros e pipes

Os **filtros** também são conhecidos como **expressões**.

Um _filtro_ recebe um valor de entrada e produz um valor de saída.
Tal como acontece quando trabalhas numa shell do Unix, podes encadear _filtros_ com um pipe `|` para ligar a saída de um _filtro_ aos dados de entrada de outro.

### O filtro de identidade: `.`

Este é o _filtro_ mais simples.
Limita-se a passar o valor de entrada para a saída.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

### Arrays

Esta é uma introdução rápida ao trabalho com **arrays**.
Vamos abordar este tema com mais detalhe mais adiante.

Acede-se aos elementos de um _array_ com parênteses retos, e a indexação começa em zero.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Um _filtro_ pode construir um _array_ envolvendo uma expressão em `[` e `]`

- com uma lista conhecida de elementos:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- para recolher um fluxo de elementos: por exemplo,
  o `range` é uma função que produz um fluxo de números

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Usar `[]` recolhe os resultados da expressão num array

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

### A vírgula é um operador

A _vírgula_ não é apenas sintaxe que separa elementos de um _array_.
A **vírgula** é um **operador** que junta fluxos.

Por exemplo, `[1, 2, 3]` é um _filtro_ que usa o construtor de _array_ `[]` para recolher o resultado da junção das três expressões `1`, `2` e `3`.

Reparaste nos pontos e vírgulas em `range(10; 70; 15)` acima?
Como as _vírgulas_ têm um propósito específico na linguagem `jq`, as funções que recebem vários argumentos usam pontos e vírgulas para separar os argumentos.

### Objetos

Uma introdução rápida aos **objetos**.

Tal como em muitas linguagens de programação, usa pontos para aceder às propriedades de um _objeto_

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
Também podes usar parênteses retos com _objetos_, mas nesse caso são precisas aspas para os literais de string.
Esta é uma forma de trabalhar com chaves que contêm espaços.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

Podes construir um _objeto_ com `{}` e pares `key: value`.
Não são precisas aspas à volta de _chaves_ que sejam strings "simples".

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

produz

```none
{
  "question": 54,
  "answer": 42
}
```

Para tratar a _chave_ como uma _expressão_, tens de a envolver em parênteses (o seguinte também produz o mesmo resultado que acima).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

### Pipelines

Por exemplo, dado um `file.json` que contém

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Vamos calcular o comprimento do _array_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

Estamos a _encadear_ a saída da expressão `.key2` como valor de entrada para o `length`, que, como seria de esperar, produz o número de elementos do _array_.

### Os filtros podem ignorar os dados de entrada

Neste exemplo, os dados JSON de entrada são ignorados e não têm qualquer impacto na saída:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

### Os filtros podem produzir fluxos de dados

Um _filtro_ pode produzir mais do que um valor.
Por exemplo, o _filtro_ `.[]` produz cada elemento de um _array_ como um valor separado:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Encadear um _filtro_ destes noutro executa o segundo _filtro_ **_para cada valor_**:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Isto é como uma iteração implícita.
Quando compreenderes esta técnica, vais perceber que se podem escrever _filtros_ `jq` muito poderosos de forma muito concisa.

### Parênteses

Os **parênteses** servem para agrupar subexpressões e impor a ordem das operações, tal como noutras linguagens.
No `jq`, a necessidade deles pode parecer um pouco surpreendente.

Por exemplo, imaginemos que queremos construir um _array_ com 2 elementos: a raiz quadrada de 9 e _e_ elevado à potência 1.
As duas expressões individuais são `9 | sqrt` e `1 | exp`.
Esperamos que a saída seja o _array_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Porque é que não obtivemos o que esperávamos? O `jq` interpreta isso assim:

```jq
[ ((9|sqrt), 1) | exp ]
```

O `jq` constrói um fluxo de dois elementos (`3` e `1`) que são ambos entregues ao `exp`.

Temos de garantir que o `exp` recebe apenas um número como valor de entrada.
Por outras palavras, temos de garantir que o pipe é avaliado antes da vírgula.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

### Funções e operadores

Sem entrar em grandes detalhes (as funções serão tema de outro exercício), aqui ficam algumas funções incorporadas úteis:

- `length`

  Dado um array como valor de entrada, produz o número de elementos desse array.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Este operador faz coisas diferentes consoante o tipo dos seus operandos:
  soma números,
  concatena strings,
  acrescenta arrays,
  combina objetos.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  O `add` é uma função que recebe um array e devolve um item com todos os elementos somados segundo as regras do `+`.
  `[1, 2, 3] | add` produz `6`.

- `map`

  Recebe um array como valor de entrada e um filtro como argumento, e produz um array em que o filtro é aplicado a cada elemento

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Recebe _um_ valor de entrada e um filtro como argumento:
  - se o filtro aplicado ao argumento der um valor _verdadeiro_, produz o valor de entrada sem alterações
  - caso contrário, não produz _nada_ (não o valor `null`, mesmo nada)

  Por exemplo, dados alguns números, seleciona os que são divisíveis por 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Lembra-te de que o `range` produz um _fluxo_ de números.
  O `select` é invocado uma vez por cada número.
  Só são produzidos os números que "passam" a expressão.

  Muitas vezes precisas de selecionar elementos de um array.
  Há algumas formas de o fazer.

  Com o valor de entrada `["Anne", "Bob", "Cathy", "Dave"]`, seleciona os nomes com comprimento 4.
  - usa o `map` e o `select` em conjunto

    ```jq
    map(select(length == 4))
    ```

  - expande o array em elementos, faz `select` sobre esse fluxo e recolhe os resultados

    ```jq
    [ .[] | select(length == 4) ]
    ```
