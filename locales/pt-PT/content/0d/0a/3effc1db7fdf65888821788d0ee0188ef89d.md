# Recursos

* O canal IRC [#haskell](https://web.libera.chat/?channel=#haskell) no Libera Chat tem como objetivo «encorajar a aprendizagem e a discussão de Haskell, a programação funcional e a programação em geral». Encontras mais informações sobre o canal IRC na [página do Haskell Wiki para o canal](https://wiki.haskell.org/IRC_channel).
* O [Hoogle](https://www.haskell.org/hoogle/) é um motor de busca de API de Haskell. Isto permite-te consultar o que uma função faz se só souberes o nome dela. Talvez ainda mais interessante, também permite pesquisar por assinatura de tipo: se queres saber que funções têm a assinatura de tipo [(a -> b) -> [a] -> [b]](https://www.haskell.org/hoogle/?hoogle=%28a+-%3E+b%29+-%3E+[a]+-%3E+[b]), o Hoogle ajuda-te a descobrir!
* Podes usar o [Stack Overflow](https://stackoverflow.com/questions/tagged/haskell) para procurar o teu problema e ver se já foi respondido. Também podes colocar e responder a perguntas.
* O [/r/haskell](https://www.reddit.com/r/haskell) é o subreddit de Haskell.
* A [página da comunidade de Haskell](https://www.haskell.org/community/) tem ligações para várias comunidades onde os programadores de Haskell se reúnem e interagem; a partir daqui, podes escolher o teu meio de comunicação preferido.
