# Testes

Para correres os testes, instala primeiro o pacote `z3-solver`:

```
pip install z3-solver
```

Depois, podes correr os testes com o seguinte comando, a partir do diretório do exercício:

```
python <snake_case_exercise>_test.py
```

em que substituis `<snake_case_exercise>` pelo nome do exercício.
