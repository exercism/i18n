# Sobre

A linguagem Go disponibiliza um pacote incorporado chamado `fmt` (pacote de formatação), que oferece várias funções para manipular o formato da entrada e da saída.
A função mais usada é `Sprintf`, que recorre a _verbos_ como `%s` para interpolar valores numa string e devolve essa string.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Em Go, os números de vírgula flutuante são formatados de forma conveniente com os verbos do Sprintf: `%g` (representação compacta), `%e` (expoente) ou `%f` (sem expoente).
Os três verbos permitem controlar a largura do campo e a posição numérica.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Podes encontrar a lista completa dos verbos disponíveis na [documentação do pacote de formatação][fmt-docs].

O `fmt` contém outras funções para trabalhar com strings, como o `Println`, que se limita a imprimir na consola os argumentos que recebe, e o `Printf`, que formata a entrada da mesma forma que o `Sprintf` antes de a imprimir.

[fmt-docs]: https://pkg.go.dev/fmt
