# Introdução

Os `Rational numbers` são frações com um numerador inteiro dividido por um denominador inteiro.

Por exemplo, podemos guardar `2//3` como uma fração exata em vez do valor aproximado `Float64` `0.6666...`

A vantagem é que (exceto no caso extremo de *overflow de inteiros*) um número racional permanece exato, evitando os erros de arredondamento que muitas vezes são inevitáveis com números de vírgula flutuante.

Os números racionais são um tipo numérico bastante simples e funcionam, em grande parte, como seria de esperar.
Como são um tipo padrão em Julia desde as primeiras versões, a maioria das funções aceita-os da mesma forma que aceita inteiros e números de vírgula flutuante.

## Criar números racionais

Criar um número racional é tão simples como usar `//` entre dois inteiros.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Os fatores comuns são removidos automaticamente, convertendo a fração na sua "forma irredutível": os menores inteiros que representam a fração com exatidão e com um denominador não negativo.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## Aritmética com números racionais

Os `arithmetic operators` habituais `+ - * / ^ %` funcionam com racionais, essencialmente da mesma forma que com outros tipos numéricos.

Podem incluir-se inteiros e outros `Rational`, e o resultado será um `Rational`.
Incluir um `float` na expressão dá um resultado do tipo `float`, com uma consequente (e possível) perda de precisão.

Se quiseres um `float`, basta usar a função `float()` para converter um racional.
É bastante normal usar números racionais para preservar a precisão ao longo de um cálculo extenso e, no fim, converter para um número de vírgula flutuante.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## Outras operações

Em Julia, os números racionais são apenas números.
Normalmente, o compilador converte os tipos conforme for necessário.

No entanto, tem em atenção que as comparações funcionam para frações com uma representação decimal finita:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Mas, fora desses casos, um `Rational` deve ser convertido para `Float` antes de fazer comparações:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

As funções matemáticas aceitam números racionais, mas podem dar um resultado de vírgula flutuante:

```julia-repl
julia> sqrt(9//16)
0.75
```
