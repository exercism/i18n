# Dicas

## 1. Substitui todos os espaços que encontrares por underscores

- Este [tutorial][chars-tutorial] é útil.
- Podes obter `char`s de uma string com o método [charAt][char-at].
- Deves usar um [`StringBuilder`][string-builder] para construíres a string de saída.
- Consulta a documentação de [Character][chars-docs] para encontrares um método que detete espaços em branco. Lembra-te de que é um método estático.
- Os literais `char` são escritos entre aspas simples.

## 3. Converte leetspeak em texto normal
