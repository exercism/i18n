# Introdução

## Boolean em R

Os valores verdadeiro e falso são representados pelo tipo `logical`.
Este tipo contém apenas dois valores: `TRUE` e `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Operadores Boolean

Existem cinco operadores Boolean em R, mas nesta fase do programa apenas três são relevantes.
Os outros dois serão importantes quando trabalhares com vetores, um tema abordado em vários Conceitos mais à frente.

`&&` é o operador Boolean "e".
O resultado é `TRUE` se as expressões em *ambos* os lados de `&&` forem `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` é o operador Boolean "ou".
O resultado é `TRUE` se uma expressão em *qualquer* dos lados de `||` for `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` é o operador Boolean "não".
Inverte os valores `TRUE` e `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Para expressões mais longas e complicadas, o melhor é usar parênteses para deixar clara a tua intenção.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
