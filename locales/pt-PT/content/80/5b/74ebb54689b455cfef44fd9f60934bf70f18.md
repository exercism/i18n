# Carateres

`CHAR` é um caráter, escrito entre plicas.

```sather
   c : CHAR := 'M';
```

## Carateres especiais

Alguns carateres não podem ser escritos diretamente e escrevem-se com uma barra invertida:

| Escrito | É |
| --- | --- |
| `'\n'` | uma nova linha |
| `'\t'` | uma tabulação |
| `'\''` | uma plica |
| `'\\'` | uma barra invertida |

## Perguntas

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## Maiúsculas e minúsculas

`.upper` e `.lower` mudam a caixa de uma letra e deixam tudo o resto intacto, por isso são seguros de aplicar a um caráter que ainda não verificaste.

## Números

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` e `.char` são exatamente opostos. Os factos úteis sobre a numeração são que `'a'` a `'z'` são consecutivos, `'A'` a `'Z'` são consecutivos e `'0'` a `'9'` são consecutivos, por isso:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## Dar a volta

Uma roda de cifra dá a volta depois do `z` e volta ao `a`. O `%` faz exatamente isso:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

O `%` do Sather nunca devolve um valor negativo quando o lado direito é positivo, por isso isto funciona tanto para rodar a roda para trás como para a frente.

## Carateres e strings

Uma `STR` é uma sequência de bytes, e um `CHAR` é um byte. Para texto em inglês, um byte é uma letra, por isso `"Marlowe".size` é 7 e `"Marlowe"[0]` é `'M'`. Para texto com acentos ou outro alfabeto, uma letra pode ocupar vários bytes, e nenhuma dessas duas coisas se verifica.
