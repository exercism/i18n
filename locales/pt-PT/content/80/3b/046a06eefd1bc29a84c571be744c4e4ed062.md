# Anexo às instruções

## Notas de implementação

A definição da interface Cipher está em `cipher.go`.

As tuas implementações devem respeitar a interface Cipher.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

Espera-se que `Encode` ignore todos os valores da string que não sejam A-Za-z; esses valores não serão representados na saída.
A saída será também normalizada para minúsculas.

As funções usadas para obter as cifras são:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

O argumento de `NewShift` tem de estar no intervalo de 1 a 25 ou de -1 a -25.
O zero não é permitido.
Para argumentos inválidos, `NewShift` devolve nil.

O argumento de `NewVigenere` tem de ser composto apenas por letras minúsculas de a a z.
Não são permitidos valores compostos apenas pela letra 'a'.
Para argumentos inválidos, `NewVigenere` devolve `nil`.
