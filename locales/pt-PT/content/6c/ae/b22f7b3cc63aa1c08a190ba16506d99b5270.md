# return desnecessário

As boas práticas de Scala indicam que se deve evitar a palavra-chave `return`. Em Scala, o resultado da última expressão de uma função é devolvido implicitamente. Escrever `return` explicitamente no fim de uma função pode ter efeitos secundários indesejados. [Say No To Return](https://blog.knoldus.com/scala-best-practices-say-no-to-return/).
