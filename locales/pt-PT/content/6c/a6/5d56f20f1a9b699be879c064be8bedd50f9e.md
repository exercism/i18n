# Instruções

No teu laboratório de investigação de ADN, tens vindo a explorar várias formas de comprimir os teus dados de investigação para poupar espaço de armazenamento. Um colega de equipa sugere converter os dados de ADN numa representação binária:

| Ácido nucleico | Código |
| ------------ | ------ |
| um espaço      | `0000` |
| A            | `0001` |
| C            | `0010` |
| G            | `0100` |
| T            | `1000` |

Ficas a pensar nisto, porque pode reduzir para metade os custos de armazenamento necessários, mas à custa da legibilidade para as pessoas. Decides escrever um módulo para codificar e descodificar os teus dados, para avaliar a poupança.

## 1. Codifica o ácido nucleico num valor binário

Implementa `encode_nucleotide/1` de modo a receber o ponto de código do ácido nucleico e devolver o valor inteiro do código codificado.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. Descodifica o valor binário para o ácido nucleico

Implementa `decode_nucleotide/1` de modo a receber o valor inteiro do código codificado e devolver o ponto de código do ácido nucleico.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. Codifica uma charlist de ADN

Implementa `encode/1` de modo a receber uma charlist que representa ácidos nucleicos e espaços e devolver uma bitstring com os dados codificados.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. Descodifica uma bitstring de ADN

Implementa `decode/1` de modo a receber uma bitstring que representa ácidos nucleicos e espaços e devolver os dados descodificados como uma charlist.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
