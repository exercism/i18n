# usa interpolação de strings, não string format

Uma abordagem mais comum em C# é usar [interpolação de strings](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/), em vez de usar `string.Format` para construir uma string dinamicamente.

Repara que a interpolação de strings é apenas um truque do compilador, também conhecido como açúcar sintático. Isto significa que, quando uma expressão de interpolação de strings é compilada, o compilador vai mesmo convertê-la numa chamada a `string.Format`. O benefício de usar interpolação de strings é, portanto, puramente visual.
