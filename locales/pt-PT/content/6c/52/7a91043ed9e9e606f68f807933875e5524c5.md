# Introdução

## Enums

O tipo `enum` de C# representa um conjunto fixo de constantes nomeadas (uma enumeração). O seu principal objetivo é proporcionar uma forma segura em termos de tipos de interagir com constantes numéricas, limitando os valores disponíveis a um conjunto predefinido. Um enum simples pode ser definido da seguinte forma:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Se não forem definidos explicitamente, os membros do enum recebem automaticamente valores inteiros incrementais, sendo o primeiro valor zero. Também é possível atribuir valores explicitamente:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
