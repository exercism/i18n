# Anexo às instruções

## Implementação

Os testes exigem um construtor que recebe um array. O funcionamento interno da tua implementação de conjunto personalizado pode usar outras estruturas de dados, mas podes ter de implementar um construtor exterior que receba exatamente um array para que os testes passem.

Alguns métodos têm um operador unicode equivalente. Por exemplo, `intersect(CustomSet([1, 2, 3, 4]), CustomSet([]))` é equivalente a `CustomSet([1, 2, 3, 4]) ∩ CustomSet([])`.
