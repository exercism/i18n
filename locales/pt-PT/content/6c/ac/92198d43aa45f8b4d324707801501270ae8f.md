# Instruções

Neste exercício vais escrever código para imprimir crachás com o nome dos funcionários da fábrica.

## 1. Imprime um crachá para um funcionário

Os funcionários têm um ID, um nome e o nome do departamento. Os crachás dos funcionários são formatados da seguinte forma: `"[id] - name - DEPARTMENT"`. Implementa o método (_static_) `Badge.Print()` para devolver o crachá de um funcionário:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Repara que o departamento deve ficar em maiúsculas no crachá.

## 2. Imprime um crachá para um funcionário novo

Devido a uma particularidade do sistema informático, os funcionários novos às vezes ainda não têm um ID quando começam a trabalhar na fábrica. Como os crachás são obrigatórios, recebem um crachá temporário sem o prefixo do ID. Modifica o método (_static_) `Badge.Print()` para suportar funcionários novos que ainda não têm um ID:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime um crachá para o proprietário

Até o proprietário da fábrica tem de usar um crachá em todos os momentos. No entanto, o proprietário não tem departamento. Nesse caso, o crachá deve imprimir `"OWNER"` em vez do nome do departamento. Modifica o método (_static_) `Badge.Print()` para imprimir um crachá para o proprietário:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Repara que é possível que o proprietário seja também um funcionário novo:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
