# Sobre

O Clojure usa o tipo subjacente `java.lang.Character`, que é uma quantidade de 16 bits para representar os componentes endereçáveis mais pequenos do texto.
Vários `char`s podem compor uma string como `"word"`, ou os `char`s podem ser processados independentemente. Os seus literais escrevem-se como `\a \b \c`.

Os `char`s do Clojure suportam a codificação Unicode UTF-16. Por isso, além do conjunto de carateres latinos, é possível representar praticamente todos os sistemas de escrita usados no mundo, por exemplo, a letra grega `'β'`.

Existem muitos métodos de biblioteca para inspecionar e manipular `char`s. É possível aceder-lhes através de interoperabilidade, como os métodos da classe `Character`. O Clojure também inclui uma biblioteca integrada de utilitários para strings, `clojure.string`, que oferece muitas funções poderosas para operar sobre carateres.
