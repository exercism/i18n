# Adenda às instruções

Este exercício apresenta alguns conceitos que podes ainda não ter visto:

## Espaço de nomes definido pelo utilizador

As palavras em 8th pertencem todas a um espaço de nomes; por exemplo, `a:new` refere-se à palavra `new` do espaço de nomes `a`.
Também é possível definir espaços de nomes personalizados, que é o que fazemos no início do ficheiro `circular-buffer.8th`:

```8th
ns: cb
```

Isto significa que todas as palavras desse ficheiro podem ser acedidas através de `cb:<word>`, o que é uma excelente forma de agrupar funcionalidades relacionadas.

Para mais informações, consulta a documentação sobre [espaços de nomes][namespaces].

## Exceções

Espera-se que as palavras `read` e `write` lancem uma exceção quando são chamadas num buffer circular com um estado inválido.
Para mais informações, consulta a documentação sobre [exceções e tratamento de erros][exceptions-and-error-handling].

## Objetos

Embora sejas livre de implementar o buffer circular como quiseres, podes considerar usar o [suporte para objetos][objects] do 8th.
