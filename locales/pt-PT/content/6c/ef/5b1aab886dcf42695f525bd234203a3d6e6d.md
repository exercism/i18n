# Introdução

Muitas linguagens de programação têm tipos numéricos específicos para representar diferentes tipos de números, mas o JavaScript só tem dois:

- `number`: um tipo de dados numérico no formato de vírgula flutuante de precisão dupla de 64 bits (IEEE 754).
  Exemplos: `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` e `500000`.
- `bigint`: um tipo de dados numérico que pode representar _inteiros_ no formato de precisão arbitrária.
  Exemplos: `-12n`, `0n`, `4n` e `9007199254740991n`.

Se precisares de [precisão arbitrária][ref-arbitrary-precision] ou trabalhares com números extremamente grandes, usa o tipo `bigint`.
Caso contrário, o tipo `number` é provavelmente a melhor opção.

## Arredondamento

Existe um objeto global incorporado chamado `Math` que fornece várias [funções de arredondamento][ref-math-object-rounding]. Por exemplo, podes arredondar para baixo (`floor`) ou para cima (`ceil`) números decimais para os inteiros mais próximos.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```
