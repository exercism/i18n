# Instruções

Neste exercício, vais escrever código para ajudar um freelancer a comunicar com um gestor de projeto.
A tua tarefa é fornecer alguns utilitários para calcular rapidamente tarifas diárias e mensais, opcionalmente com um desconto.

Vamos primeiro estabelecer algumas regras entre o freelancer e o gestor de projeto:

- A tarifa diária é 8 vezes a tarifa horária.
- Um mês tem 22 dias faturáveis.

Por vezes, o freelancer oferece-se para aplicar um desconto na sua tarifa diária (por exemplo, para os clientes mais fiéis ou para clientes sem fins lucrativos).

Os descontos são modelados como números fracionários que representam percentagens, por exemplo, `25.0` (25%).

~~~~exercism/note
Estes são os sufixos das instruções de vírgula flutuante:

| Sufixo | Tamanho do operando |
|--------|--------------|
| `ss`   | 32 bits      |
| `sd`   | 64 bits      |

Estas são algumas das instruções mencionadas neste conceito:

| Instrução       | Descrição                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | copia b para a                                         |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | converte o número inteiro b em vírgula flutuante a    |
| roundss/roundsd a, b, c | arredonda o valor de vírgula flutuante b de acordo com c e guarda-o em a |
| cvtss2si/cvtsd2si a, b  | converte o valor de vírgula flutuante b em número inteiro a |
| comiss/comisd a, b      | faz uma comparação entre a e b, com exceção se for `NaN` |
| ucomiss/ucomisd a, b    | faz uma comparação entre a e b, define `PF` se for `NaN` |

Estes são os números de controlo de arredondamento em `roundss` e `roundsd`:

| Número | Modo         |
|:-------|:-------------|
| 0      | Mais próximo |
| 1      | Para baixo (floor) |
| 2      | Para cima (ceil) |
| 3      | Truncar     |
~~~~

## 1. Calcular a tarifa diária a partir de uma tarifa horária

Implementa uma função chamada `daily_rate` para calcular a tarifa diária, recebendo como parâmetro uma tarifa horária, na forma de um número de vírgula flutuante de 64 bits.
O contrato define que um dia tem 8 horas faturáveis.

```c
daily_rate(60)
// => 480.0
```

A tarifa diária devolvida deve ser um número de vírgula flutuante de 64 bits.

## 2. Calcular um preço com desconto

Implementa uma função `apply_discount` para calcular o preço depois de aplicar um desconto.
Deve aceitar dois parâmetros: o preço original e a taxa de desconto em percentagem, ambos na forma de um número de vírgula flutuante de 64 bits.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

O valor devolvido deve ser sempre um número de vírgula flutuante de 64 bits.

## 3. Calcular a tarifa mensal a partir de uma tarifa horária e de um desconto

Implementa uma função `monthly_rate` para calcular a tarifa mensal com desconto.
Recebe dois parâmetros, uma tarifa horária e o desconto em percentagem, ambos na forma de um número de vírgula flutuante de 64 bits.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

A tarifa mensal devolvida deve ser arredondada por excesso (para cima) para o número inteiro de 64 bits mais próximo.

## 4. Calcular o número de dias de trabalho completos a partir de um orçamento, de uma tarifa horária e de um desconto

Implementa uma função `days_in_budget` que recebe como parâmetros:

1. Um orçamento, na forma de um número inteiro sem sinal de 64 bits.
2. Uma tarifa horária, na forma de um número de vírgula flutuante de 64 bits.
3. Um desconto em percentagem, na forma de um número de vírgula flutuante de 64 bits.

Esta função deve devolver o número de dias de trabalho completos que o orçamento cobre.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

O número de dias devolvido deve ser arredondado por defeito (para baixo) para o número inteiro de 32 bits mais próximo.
