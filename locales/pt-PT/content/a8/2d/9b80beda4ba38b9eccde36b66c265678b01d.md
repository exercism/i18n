# Introdução

## A interface como um conjunto de métodos

Na sua forma mais simples, um **tipo de interface** é um conjunto de assinaturas de métodos.
Aqui está um exemplo de uma definição de interface que inclui dois métodos, `Add` e `Value`:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Os nomes dos parâmetros, como `increment`, podem ser omitidos da definição da interface, mas muitas vezes aumentam a legibilidade.

Os nomes das interfaces em Go não contêm a palavra `Interface` nem `I`.
Em vez disso, terminam muitas vezes em `er`, por exemplo `Reader` e `Stringer`.

## Implementar uma interface

Qualquer tipo que defina os métodos da interface "implementa-a" automaticamente, de forma implícita.
Em Go não existe a palavra-chave `implements`.

O tipo seguinte implementa a interface `Counter` que vimos acima.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Para implementar a interface, não importa se o método tem um recetor de valor ou um recetor de apontador.
(Revisita os [conceitos de métodos][concept-methods] se tiveres dúvidas sobre isso.)

> Um valor de tipo de interface pode conter qualquer valor que implemente esses métodos. ((Go Tour: Interfaces)[go-tour-interfaces])

Isto significa que `Stats` pode agora ser usado em todos os locais que esperam a interface `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Como as interfaces são implementadas de forma implícita, um tipo pode implementar várias interfaces com facilidade.
Basta ter todos os métodos necessários definidos.

## Interface vazia

Há um tipo de interface muito especial em Go: o **tipo de interface vazia**, que não contém nenhum método.
A interface vazia escreve-se assim: `interface{}`.
Em Go 1.18 ou superior, também se pode usar `any`.
Foi definido como um alias.

Como a interface vazia não tem métodos, todos os tipos a implementam de forma implícita.
Isto é útil para definir uma função que pode aceitar qualquer valor de forma genérica.
Nesse caso, o parâmetro da função usa o tipo de interface vazia.
