# devolução explícita

Remove o return explícito para simplificar o método.

Em Ruby, um método devolve o resultado da última instrução avaliada. Por isso, usar explicitamente a palavra-chave `return` é desnecessário, exceto quando devolves o valor mais cedo dentro de um método.

Por exemplo, isto imprime `16`, porque o método `multiply` devolve o resultado de `a * b`, a sua última expressão.

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
