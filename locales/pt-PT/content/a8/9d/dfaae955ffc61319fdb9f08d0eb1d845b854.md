# Instruções

Estás a desenvolver o novo e muito apreciado jogo **Wings Quest**.
No jogo, és uma ave que se move e recolhe sementes.
O jogador ganha ao apanhar todas as sementes.
Se o jogador entrar em contacto com uma águia, perde todas as sementes e perde o jogo.
Há uma exceção a esta regra: o jogador pode ter um power-up ativo que o faz voar mais alto do que as outras aves.

O teu objetivo é escrever algumas regras que serão usadas no jogo.

## 1. Define se a ave ganha pontos de bónus

No jogo, a ave ganha pontos de bónus se tocar numa águia enquanto tem um power-up ativo.

Define a função `bonusPoints(powerUpActive:touchingEagle:)`, que recebe dois argumentos: `powerUpActive`, que indica se a ave tem um power-up ativo, e o argumento `touchingEagle`, que indica se a ave está a tocar numa águia.
A função deve devolver `true` apenas se a ave tiver um power-up ativo e estiver a tocar numa águia, e `false` caso contrário.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. Define se a ave marca pontos

No jogo, o jogador ganha pontos quando apanha uma semente ou um power-up.

Define a função `score(touchingPowerUp:touchingSeed:)`, que recebe dois argumentos: `touchingPowerUp`, que indica se a ave está a tocar num power-up, e o argumento `touchingSeed`, que indica se a ave está a tocar numa semente.
A função deve devolver `true` se a ave estiver a tocar num power-up ou numa semente, e devolver `false` caso contrário.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. Define se a ave perde

Define a função `lose(powerUpActive:touchingEagle:)`, que recebe dois argumentos: `powerUpActive`, que indica se a ave tem um power-up ativo, e o argumento `touchingEagle`, que indica se a ave está a tocar numa águia.
A função deve devolver `true` se a personagem estiver a tocar numa águia e não tiver um power-up ativo, e devolver `false` caso contrário.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. Define se a ave ganha

Define a função `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)`, que recebe os argumentos:

- `hasPickedUpAllSeeds` se a ave apanhou todas as sementes.
- `powerUpActive` se a ave tem um power-up ativo.
- `touchingEagle` se a ave está a tocar numa águia.

A função deve devolver `true` se a ave tiver recolhido todas as sementes e não tiver perdido, com base nos argumentos definidos na parte 3, e devolver `false` caso contrário.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
