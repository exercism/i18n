# sem rescue

Não uses exceções para controlar o fluxo do programa.
Tenta resolver este exercício sem usar `rescue`.

Se estás a usar uma função da biblioteca padrão com um nome que termina em `!` (lança erros), procura uma função equivalente sem o `!` (muitas vezes devolvem `{:ok, result}` ou `{:error, message}`).

Nota: se estás a ver este comentário automático na tua solução, é possível que outros comentários automáticos não sejam exatos.
Corrige primeiro este problema!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
