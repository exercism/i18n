## Smalltalk e strings

Quanto às strings, há alguns pequenos detalhes óbvios, como as aspas duplas para comentários, as aspas simples para strings e a sintaxe especial para carateres (por exemplo, $x para o caráter «x»), que te podem confundir à primeira leitura, já que as convenções são diferentes das usadas noutras linguagens.

Há também a noção de símbolo, que é uma string única em toda a memória; ou seja, quando é construído (normalmente em tempo de compilação), é feita uma pesquisa na memória para determinar se já existe outro igual; e só o original é usado. A razão não é apenas poupar memória, mas também um aumento significativo de velocidade ao comparar símbolos.

```smalltalk
"this is a comment"
'this is a string'
#'this is a symbol'
#thisIsASymbolToo
```

Também há muito poucas vírgulas nos programas em Smalltalk, porque não desempenham nenhum papel sintático.
É por isso que os literais de array, por exemplo, não têm vírgulas; por exemplo,
`#(1 2 3 4 5)`
No entanto, a vírgula é um operador por direito próprio e vais repará-la quando concatenas duas strings; por exemplo,
`'string1', 'string2'`

Por fim, vale a pena saber que strings e carateres são classes distintas. Uma string é uma coleção de carateres. Isto pode apanhar-te desprevenido quando iteras sobre strings, pois podes acabar por passar carateres a um método que espera strings. Repara em...
```smalltalk
(('hello' at: 2) = $e) inspect.
(('hello' at: 2) = 'e') inspect.
```

## Smalltalk e streams
As streams são úteis para leitura e escrita sequenciais. Tornam o código mais limpo ao evitar a necessidade de incrementar um índice.
As streams funcionam com qualquer coleção.
```smalltalk
stream := WriteStream on: String new.
stream nextPut: $h ; nextPutAll: 'ell' ; nextPut: $o.
stream contents inspect
```
