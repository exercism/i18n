# Introdução

Um `vector` em Clojure é uma coleção sequencial, indexada e imutável de zero ou mais valores. Isto significa que, depois de criado, um vector não pode ser modificado. As funções que operam sobre vectors devolvem um novo vector, enquanto o vector original permanece inalterado. Os valores de um vector podem ser de tipos heterogéneos. Os vectors podem ser definidos da seguinte forma:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

Os elementos podem ser obtidos a partir de um vector através de um índice. Em Clojure, os vectors são indexados a partir de zero, ou seja, o índice do primeiro elemento é sempre zero:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

O vector original permanece inalterado:

```clojure
numbers
;;=> [2 3 5]
```

Para nos lembrarmos do valor atualizado, temos de o passar adiante ou de o capturar numa var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
