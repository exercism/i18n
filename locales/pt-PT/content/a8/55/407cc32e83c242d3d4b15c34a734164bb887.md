# Acerca das constantes

As constantes são valores definidos em tempo de compilação e não podem ser reatribuídos.
Usa a palavra-chave `const` para declarar uma única constante:

```go
const greeting = "hello"
```

É possível declarar várias constantes num bloco.
Dentro de um bloco, uma constante sem valor explícito repete a expressão anterior:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

As constantes são normalmente declaradas ao nível do pacote, embora também possam ser declaradas dentro de uma função.

## Constantes com tipo e sem tipo

Quando declaras uma constante sem indicar o tipo, ela fica sem tipo definido.
Uma constante sem tipo definido não tem um tipo fixo; é o seu valor que determina com que tipos é compatível.
Desde que o valor subjacente seja compatível, o compilador converte-a para o tipo necessário em cada utilização:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

Uma constante com tipo fixa o tipo no momento da declaração:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## O que pode ser uma constante

As constantes só podem conter Boolean, números, string e runes.
Como os valores são definidos em tempo de compilação, não podes usar o resultado de uma chamada de função numa constante.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

Dentro de um bloco de constantes, `iota` representa a posição da constante no bloco:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

Cada constante a seguir à primeira herda a mesma expressão, com `iota` a incrementar uma unidade.

O `iota` também funciona em expressões.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
