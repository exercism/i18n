# Introdução

O ciclo for é uma das instruções mais usadas para executar repetidamente alguma lógica.
Em JavaScript, é composto pela palavra-chave `for`, um _cabeçalho_ entre parênteses curvos (`()`) e um bloco de código entre chavetas (`{}`) que contém o _corpo_ do ciclo.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

A inicialização normalmente cria uma variável contadora, a condição verifica se o ciclo deve continuar ou parar e o passo incrementa o contador no fim de cada repetição.
As partes individuais do cabeçalho são separadas por pontos e vírgulas.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

Definir o passo é muitas vezes feito com o operador de incremento ou decremento do JavaScript, como mostra o exemplo acima.
Estes operadores modificam uma variável no próprio local.
`++` soma uma unidade a um número, `--` subtrai uma unidade a um número.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
