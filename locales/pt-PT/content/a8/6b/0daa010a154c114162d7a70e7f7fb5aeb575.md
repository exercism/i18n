# Dicas

## Geral

- Para extrair vários argumentos nos parâmetros da função, podes agrupá-los com o operador `*arguments` para **arrays** ou com `**keyword_arguments` para argumentos de palavra-chave.
- Para agrupar ou desagrupar, usa os operadores splat (`*` ou `**`).

## 1. Cria uma lista com todos os vagões

- Vários argumentos nos parâmetros da função podem ser agrupados com o operador `*arguments`.

## 2. Corrige a lista de vagões

- Usar desagrupamento com o operador splat (`*`) permite-te extrair os dois primeiros elementos de um **array** e manter o resto intacto.
- Para adicionar outro **array** a um **array** existente, podes usar o operador splat (`*`) para "espalhar" o **array**.

## 3. Adiciona as paragens em falta

- Usar `**keyword_arguments` como argumento de um método permite passar uma quantidade arbitrária de argumentos de palavra-chave.
- Usar `**<hash>` como argumento desagrupa um `Hash` em argumentos de palavra-chave.
- Podes colocar argumentos de palavra-chave dentro de `{}`, que é outra forma de criar um `Hash`.
- Para obter os valores de um `Hash`, podes usar o método `Hash#values`.

## 4. Estende a informação de encaminhamento

- Usar `**{some_hash: value}` como argumento desagrupa o `Hash` em argumentos de palavra-chave.
