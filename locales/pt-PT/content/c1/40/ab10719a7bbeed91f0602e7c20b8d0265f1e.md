# Introdução

## Correspondência de padrões

Uma expressão `if/elif/else` pode ser usada para executar lógica de forma condicional. O F# tem ainda outra forma, mais poderosa, de executar lógica de forma condicional: a correspondência de padrões. Com a correspondência de padrões, um valor pode ser testado em relação a um ou mais _padrões_. Um exemplo desses padrões é o _padrão constante_, que compara um valor com uma constante (por exemplo, `1` ou `"hello"`).

Em F#, a correspondência de padrões faz-se através da palavra-chave `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Embora isto possa parecer as instruções `switch` de outras linguagens, a correspondência de padrões começa a brilhar quando também se usam outros padrões. Um desses padrões é o _padrão variável_, que permite capturar um valor:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

Em alguns casos, podes querer acrescentar uma condição adicional a um padrão. Isto é conhecido como uma _guarda_ (cláusula), que pode ser acrescentada com a palavra-chave `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

No exemplo acima, nem todos os valores de entrada possíveis terão um padrão correspondente. O compilador deteta isso e emite um aviso. Isto é conhecido como _verificação de exaustividade_. Para resolver o aviso, é preciso tratar de todos os casos. Para isso, pode usar-se o _padrão universal_, que é um padrão que corresponde a qualquer valor:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

A correspondência de padrões testa um valor em relação a cada padrão, de cima para baixo, até encontrar um padrão correspondente e executar a lógica associada a esse padrão. A ordem dos padrões é importante!
