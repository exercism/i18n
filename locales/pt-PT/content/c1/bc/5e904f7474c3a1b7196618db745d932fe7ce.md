# Sobre

## Tipos de função

Já vimos anteriormente como se definem as assinaturas de funções: um nome de função seguido de uma lista de etiquetas de parâmetros separadas por vírgulas, com os respetivos tipos, seguidas de `->` e do tipo dos valores devolvidos pela função.

Se retirarmos todos os nomes e etiquetas desta assinatura, ficamos com o [tipo da função][function-types].

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Repara que os tipos das duas primeiras funções são iguais, `(String, Int) -> String`, mesmo funcionando as duas funções de forma muito diferente. Ambas recebem uma `String` e um `Int` como parâmetros de entrada e devolvem uma `String`. E, como se pode ver pelo tipo da terceira função, apesar de a função parecer não devolver nada, na verdade devolve `()`, o único valor do tipo `Void`. Nota que `()` e `Void` são intercambiáveis como nomes de tipos, por isso o tipo de `printString` também pode ser escrito como `String) -> Void`.

Estes tipos podem ser usados da mesma forma que qualquer outro tipo em Swift. Por exemplo, podem ser usados na declaração de variáveis ou constantes. E, como as funções são valores em Swift, podemos atribuir funções já existentes a essas constantes ou variáveis:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

Tal como acontece com outras variáveis ou constantes, o valor que lhes atribuis tem de ser do tipo correto:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Tipos de função como tipos de parâmetros

Como os tipos de função podem ser usados em qualquer sítio onde se possam usar outros tipos, também [podem ser usados como tipos de parâmetros][functions-as-parameters], passados para outras funções e chamados de dentro dessas funções.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## Tipos de função como tipos devolvidos

De forma semelhante, [os tipos de função podem ser usados como tipos devolvidos][functions-as-returns] por funções. Por outras palavras, podemos escrever funções que criam e devolvem outras funções. Ao criar estas funções, a função devolvida pode usar os outros parâmetros passados para a função ou as variáveis locais criadas dentro da função exterior.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## Captura de valores

Como se viu com a função `makeAdder(base:)` acima, as funções aninhadas conseguem aceder aos parâmetros e às variáveis das funções que as envolvem. Além disso, conseguem manter o acesso a esses valores depois de a função que as contém terminar. Esta ação de obter e manter o acesso é conhecida como [_captura_][capturing-values].

## Funções de ordem superior

As funções que recebem funções como parâmetros e/ou devolvem funções são conhecidas como funções de ordem superior. O Swift tem muitas funções de ordem superior nas suas várias bibliotecas. Por exemplo, o método `sorted(by:)` disponível nas coleções do Swift, como `Array`, que, para um array com elementos do tipo `T`, recebe uma função de tipo `(T, T) -> Bool` que determina qual de dois valores deve vir antes do outro num array ordenado, devolvendo `true` se o valor da esquerda deve aparecer primeiro e `false` se o valor da direita deve aparecer primeiro.

Outro exemplo é o método `contains(where:)` das coleções, que, para uma coleção com elementos do tipo `T`, recebe uma função de tipo `(T) -> Bool` que devolve `true` se o elemento satisfaz uma determinada propriedade e `false` caso contrário. O `contains(where:)` devolve então `true` se algum elemento da coleção satisfizer essa propriedade.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
