# Anexo às instruções

## Formato da entrada

Cada lista de entradas é representada como uma string terminada em null, com um caráter de nova linha no final de cada entrada.

Um exemplo seria `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## Registos

| Registo | Utilização | Tipo    | Descrição                                                      |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | entrada      | endereço | string de entrada terminada em null, com uma nova linha depois de cada entrada |
| `$a1`    | entrada/saída | endereço | string de saída terminada em null                              |
| `$t0-9`  | temporário   | qualquer | para armazenamento temporário                                  |
