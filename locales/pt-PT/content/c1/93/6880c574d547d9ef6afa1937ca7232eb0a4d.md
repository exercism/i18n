# Sobre

Uma [função de ordem superior](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) é uma função que:

- Recebe uma função como argumento
- Devolve uma função

Um argumento de função é apenas um argumento normal, com a diferença de que o podes invocar.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
