# Introdução

A ligação descreve a partir de onde, no código, se pode aceder a um identificador.
Os valores com âmbito de bloco, de função ou de protótipo de função não têm ligação.
Isto significa que não se pode aceder a eles a partir de fora do seu âmbito.
Para saberes mais sobre âmbito, consulta o [conceito de âmbito](../scope/introduction.md#Introduction).

## Ligação externa

Os identificadores com âmbito de ficheiro têm, por predefinição, ligação externa.
Um identificador com ligação externa pode ser chamado a partir de qualquer ficheiro do programa.

## Ligação interna

Um identificador com âmbito de ficheiro pode passar a ter ligação interna, usando o especificador `static`.
Um identificador com ligação interna só pode ser usado dentro do seu ficheiro.

Por exemplo

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

A ligação estática não deve ser confundida com a duração de armazenamento estática.
Para saberes mais sobre a duração de armazenamento estática, consulta o [conceito de duração de armazenamento](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).
