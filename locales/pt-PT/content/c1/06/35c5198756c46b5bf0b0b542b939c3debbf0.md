# Anexo às instruções

## Pacote de ordenação

Este exercício pede que ordenes um array, mas isso não vem incluído na biblioteca padrão. Podes escrever a tua própria biblioteca de ordenação, mas uma opção melhor é usar o [pacote sorts](https://github.com/diku-dk/sorts).

Podes usar este pacote na tua solução executando o seguinte comando no diretório da solução:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

Depois, importa os [algoritmos de ordenação que quiseres](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) através de:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
