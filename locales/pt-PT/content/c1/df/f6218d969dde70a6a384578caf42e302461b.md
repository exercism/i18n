# Instruções

Neste exercício vais processar linhas de log.

Cada linha de log é uma string com o seguinte formato: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de log:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Tens três tarefas.

## 1. Analisar o nível de log

Define uma enumeração `LogLevel` com seis elementos correspondentes aos níveis de log acima.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

De seguida, implementa o método `LogLine.getLogLevel()`, que devolve o nível de log analisado de uma linha de log:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. Suportar níveis de log desconhecidos

Infelizmente, por vezes algumas linhas de log têm um nível de log desconhecido.
Para tratar estas linhas de log de forma elegante, adiciona um elemento `UNKNOWN` à enumeração `LogLevel`, que deve ser devolvido ao analisar um nível de log desconhecido:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. Converter a linha de log no formato curto

O nível de log de uma linha de log é bastante extenso.
Para reduzir o espaço em disco necessário para armazenar as linhas de log, foi criado um formato curto: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

O nível de log codificado é um mapeamento simples de um nível de log para um número:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

Implementa o método `LogLine.getOutputForShortLog()`, que consegue produzir o formato curto da linha de log:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
