# marcador de posição

## Valores ASCII

Este exercício requer converter carateres ASCII de e para o respetivo valor numérico.
A [extensão ordchr][ordchr] do GNU awk fornece esta funcionalidade. Para adicionares as
funções `ord()` e `chr()`, carrega a extensão `ordchr` adicionando uma diretiva `@load`
ao topo do teu ficheiro:

```
@load "ordchr"
```

[ordchr]: https://www.gnu.org/software/gawk/manual/gawk.html#Extension-Sample-Ord
