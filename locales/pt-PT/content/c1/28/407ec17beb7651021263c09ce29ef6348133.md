# Introdução

O tipo de união discriminada representa um número fixo de casos nomeados. Cada valor de uma união discriminada corresponde exatamente a um dos casos nomeados.

Uma união discriminada é definida com a palavra-chave `type`, com os casos separados por carateres de barra vertical (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Cada caso de uma união discriminada pode ter dados associados, opcionalmente, e casos diferentes podem ter tipos de dados diferentes. Se nenhum dos casos tiver dados associados, a união discriminada é semelhante ao que outras linguagens costumam designar por _enumeração_ (ou _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Podes criar um valor para um caso específico referindo o seu nome (por exemplo, `Success`). Como os nomes dos casos são apenas funções construtoras, podes passar os dados associados como argumento normal de uma função. Se outra união discriminada tiver definido um caso com o mesmo nome, tens de usar o nome completo do caso (por exemplo, `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

As uniões discriminadas têm _igualdade estrutural_, o que significa que dois valores para o mesmo caso e com os mesmos dados (opcionais) são equivalentes.

Embora possas usar expressões `if/elif/else` para trabalhar com uniões discriminadas, a forma recomendada de trabalhar com elas é através de correspondência de padrões, usando o _padrão de identificador_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
