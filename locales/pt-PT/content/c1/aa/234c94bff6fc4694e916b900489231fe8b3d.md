# Sobre

As [tuplas][tuples] agrupam vários valores num único valor composto.
Ao contrário dos arrays, os valores de uma tupla não precisam de ser do mesmo tipo, e o tamanho de uma tupla fica fixo a partir do momento em que é criada.

Cria uma tupla colocando valores separados por vírgulas entre parênteses:

```swift
let order = ("biscuits", 2.99, 3)
```

Também podes indicar as anotações de tipo explicitamente:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Para extrair elementos individuais de uma tupla sem nome, usa a sintaxe de índices com base em zero (`.0`, `.1`, etc.):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Tuplas nomeadas

Podes dar nomes aos elementos individuais de uma tupla quando a defines:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Dar nomes aos elementos torna o código mais legível e permite-te aceder aos elementos através da notação de ponto com os respetivos rótulos:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

Também podes incluir os nomes dos elementos na anotação de tipo:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Modificar tuplas

Se uma tupla for declarada como variável (`var`), podes atualizar os seus elementos:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Devolver vários valores

Embora as funções Swift só possam devolver um único valor, devolver uma tupla permite-te agrupar e [devolver vários valores][multiple-return-values] a partir de uma função:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Descomposição de tuplas

Podes decompor (desempacotar) os valores de uma tupla em constantes ou variáveis separadas:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

A descomposição de tuplas também funciona diretamente em ciclos `for-in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
