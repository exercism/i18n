# Instruções

O teu amigo Kojo é um grande fã de números.
Tem um pequeno site chamado 'fun-with-numbers'.
O Kojo não é muito bom a programar, por isso pediu-te ajuda.

Vais criar duas funções auxiliares para novos jogos de números no site do Kojo e uma terceira para validar os valores de entrada que o utilizador pode introduzir.

## 1. Calcular a soma dos números da máquina de slots

Um dos jogos do site do Kojo parece uma máquina de slots que mostra dois grupos de rodas com algarismos.
Cada grupo de algarismos representa um número.
Para a mecânica do jogo, o Kojo precisa de saber a soma desses dois números.

Escreve uma função `twoSum` que aceita dois arrays como parâmetros.
Cada array é composto por um ou mais números entre 0 e 9.
A função deve interpretar cada array como um número e devolver a soma desses dois números.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Determinar se um número é um palíndromo

Outro jogo do site é um pequeno questionário chamado "Lucky Numbers".
O utilizador pode introduzir um número e depois vê se esse número pertence a uma sequência ou padrão secreto.
A sequência ou padrão dos números da sorte muda todos os meses e cada utilizador só tem um número limitado de tentativas para o adivinhar.

Os números da sorte deste mês devem ser números que são palíndromos.
Um número palindrómico continua igual quando se invertem os algarismos.

Implementa a nova função `luckyNumber` que aceita um número como parâmetro.
A função deve devolver `true` se o número for um palíndromo e `false` caso contrário.
O número de entrada será sempre um inteiro positivo.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Gerar uma mensagem de erro para valores de entrada inválidos do utilizador

Em vários locais do site, há campos de entrada onde os utilizadores podem introduzir números e clicar num botão para desencadear uma ação.
O Kojo quer melhorar a experiência do utilizador do seu site.
Quer mostrar uma mensagem de erro caso o utilizador clique no botão mas o campo contenha um valor de entrada inválido.

Eis mais alguma informação sobre como é fornecido o valor de um campo de entrada.

- Se o utilizador escrever algo num campo, o valor associado é sempre uma string, mesmo que o utilizador só tenha escrito números.
- Se o utilizador escrever algo mas apagar de novo, a variável será uma string vazia.
- Antes de o utilizador começar a escrever, a variável pode ser `undefined` ou `null`.

Escreve uma função `errorMessage` que aceita os valores de entrada do utilizador como parâmetro.
Se o utilizador não fornecer nenhum valor de entrada, `errorMessage` deve devolver `'Required field'`.
Se o valor de entrada não representar um número diferente de zero (de acordo com as regras de conversão do JavaScript), deve ser devolvido `'Must be a number besides 0'`.
Em todos os outros casos, podes assumir que o valor de entrada é válido; o valor devolvido deve ser uma string vazia.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
