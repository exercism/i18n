# Instruções

Neste exercício, tens de implementar algumas regras do [Pac-Man][Pac-Man], o clássico jogo de arcada dos anos 80.

Tens quatro regras para implementar, todas relacionadas com os estados do jogo.

> _Não te preocupes com a forma como os argumentos são obtidos; concentra-te apenas em combinar os argumentos para devolver o resultado pretendido._

## 1. Define se o Pac-Man come um fantasma

Define a função `eat_ghost()` que recebe dois parâmetros (_se o Pac-Man tem uma pastilha de energia ativa_ e _se o Pac-Man está a tocar num fantasma_) e devolve um valor Boolean se o Pac-Man consegue comer um fantasma. A função só deve devolver `True` se o Pac-Man tiver uma pastilha de energia ativa e estiver a tocar num fantasma.

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Define se o Pac-Man marca pontos

Define a função `score()` que recebe dois parâmetros (_se o Pac-Man está a tocar numa pastilha de energia_ e _se o Pac-Man está a tocar num ponto_) e devolve um valor Boolean se o Pac-Man marcou pontos. A função deve devolver `True` se o Pac-Man estiver a tocar numa pastilha de energia ou num ponto.

```python
>>> score(True, True)
...
True
```

## 3. Define se o Pac-Man perde

Define a função `lose()` que recebe dois parâmetros (_se o Pac-Man tem uma pastilha de energia ativa_ e _se o Pac-Man está a tocar num fantasma_) e devolve um valor Boolean se o Pac-Man perde. A função deve devolver `True` se o Pac-Man estiver a tocar num fantasma e não tiver uma pastilha de energia ativa.

```python
>>> lose(False, True)
...
True
```

## 4. Define se o Pac-Man ganha

Define a função `win()` que recebe três parâmetros (_se o Pac-Man comeu todos os pontos_, _se o Pac-Man tem uma pastilha de energia ativa_ e _se o Pac-Man está a tocar num fantasma_) e devolve um valor Boolean se o Pac-Man ganha. A função deve devolver `True` se o Pac-Man comeu todos os pontos e não perdeu, de acordo com as regras definidas na parte 3.

```python
>>> win(False, True, False)
...
False
```
