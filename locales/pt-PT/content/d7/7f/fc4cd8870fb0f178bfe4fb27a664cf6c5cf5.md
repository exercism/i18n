# Introdução

Classes como `LocalDate` e `LocalDateTime` descrevem um _ponto_ no tempo.
O pacote `java.time` também tem duas classes que descrevem uma _quantidade_ de tempo:

- `java.time.Period` é uma quantidade de tempo em anos, meses e dias, como "2 meses e 5 dias".
- `java.time.Duration` é uma quantidade de tempo em horas, minutos, segundos, milissegundos e nanossegundos, como "1 hora e 30 minutos".

Um `Period` segue o calendário, por isso é usado com datas e datas-hora.
Uma `Duration` mede tempo exato, por isso é usada com horas e datas-hora, mas não com datas.

```exercism/note
Tal como as outras classes de `java.time`, `Period` e `Duration` são imutáveis.
Os métodos que parecem alterá-las devolvem, em vez disso, uma _nova_ instância.
```

## `Period`

Um `Period` é criado com um dos seus métodos estáticos de criação:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

O resultado de `toString()` usa a notação [ISO-8601][iso-8601-durations]: `P` (de "period") seguido do número de anos (`Y`), de meses (`M`) e de dias (`D`).

Um período pode ser adicionado a uma data ou subtraído dela:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Como os meses têm durações diferentes, adicionar meses pode calhar num dia que não existe.
Nesse caso, o resultado recua até ao último dia válido do mês:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` devolve o período de uma data (inclusive) até outra (exclusive):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## Contar unidades com `ChronoUnit`

Um `Period` mantém os anos, os meses e os dias separados.
Por isso, `getDays()` devolve apenas a _parte_ dos dias do período, e não o número total de dias.
Para contar o número total de uma única unidade entre duas datas, usa o método `between()` de [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

O resultado é negativo quando a segunda data é anterior à primeira:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

Uma `Duration` também é criada com métodos estáticos de criação:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

Na notação ISO-8601, o `T` separa a parte da data da parte da hora, e é por isso que as durações se escrevem como `PT...`.

Uma duração pode ser adicionada a uma data-hora ou subtraída dela:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` devolve a quantidade exata de tempo entre duas datas-hora:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Uma duração pode ser convertida numa única unidade com métodos como `toHours()`, `toMinutes()` e `toSeconds()`.
Estes devolvem a quantidade _total_ nessa unidade, arredondada por defeito:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Para dividir uma duração nas suas partes, como num relógio, usa antes os métodos `toXxxPart()`:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
