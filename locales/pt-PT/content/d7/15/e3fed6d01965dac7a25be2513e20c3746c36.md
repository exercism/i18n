# Instalação

O Crystal está disponível para Linux, macOS e Windows.

Convém notar que o suporte do Crystal para Windows é experimental.
Isto significa que pode haver casos-limite que não funcionam e que pode não ser ideal para casos de uso em produção.
No entanto, para o Exercism e para uma utilização básica, o Windows nativo deve ser utilizável na maior parte dos casos.

Se procuras uma experiência que não seja de pré-visualização para desenvolvimento em Windows, recomenda-se que uses o [WSL (Subsistema Windows para Linux)][wsl].
É uma funcionalidade **gratuita** do Windows 10 (1903+) e 11 que permite aos programadores correr um ambiente Linux sem precisarem de uma máquina virtual.

Usa um dos [guias de instalação][installation guides] para obteres instruções sobre como instalar o Crystal.

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
