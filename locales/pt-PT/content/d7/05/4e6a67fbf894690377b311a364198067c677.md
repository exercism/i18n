# Introdução

Um **objeto** JSON é, para usar terminologia de outras linguagens, uma "hash", um "map" ou um "dicionário".

O JSON define um _objeto_ como:

> Um objeto é um conjunto não ordenado de pares **nome**/**valor**.
> Um objeto começa com `{` chaveta de abertura e termina com `}` chaveta de fecho.
> Cada _nome_ é seguido de `:` dois pontos e os pares _nome/valor_ são separados por `,` vírgula.

O _nome_ **tem de ser uma string**.
Outra palavra para _nome_ é _chave_.

O _valor_ pode ser de qualquer tipo de JSON.
Diferentes _valores_ no mesmo objeto podem ser de tipos diferentes, como neste exemplo.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Repara que **não pode** haver uma vírgula a seguir ao _último_ par chave-valor.

## Criar objetos

Usa chavetas para reunir os pares nome/valor.
Apesar de os nomes terem de ser strings, não precisam de estar entre aspas se os nomes forem **semelhantes a identificadores** (compostos por caracteres alfanuméricos e underscores, e não começarem por um algarismo).

```jq
{name: "Jane", age: 42}
```

É válido usar chaves que não sejam _semelhantes a identificadores_.
Basta pô-las entre aspas.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Se o nome for o resultado de uma expressão, a expressão **tem de** estar entre parênteses.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## Indexação

Os valores são obtidos de um objeto com **notação de ponto**.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Se não conseguires referir-te à chave como identificador, usa **notação de parênteses retos**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## Adicionar ou alterar pares chave-valor

Para adicionar um novo par chave-valor a um array, ou para atualizar o valor de uma chave existente, usa o operador de atribuição `=`, com uma expressão de índice do lado esquerdo.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

O operador `+` _funde_ objetos.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## Remover uma chave

Usa a função `del` para remover uma chave.
Devolve o objeto atualizado.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

O parâmetro de `del` é uma **expressão de índice** (com notação de ponto ou de parênteses retos) que corresponde a uma chave no objeto.
O `jq` chama-lhe **expressão de caminho**.
Não basta dar apenas uma string.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## Pertinência

- Para testar se o objeto tem uma chave, usa a função `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Testa se uma chave está num objeto com `in`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## Listar todas as chaves

Usa a função `keys` para devolver uma lista de todas as chaves.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Repara que o `keys` _ordena_ as chaves.
Para obteres as chaves na ordem original, usa o `keys_unsorted`.

Não existe uma função equivalente para listar todos os _valores_.
No entanto, o filtro `.[]` devolve os valores do objeto como um _fluxo_, e esse fluxo pode ser capturado com o construtor de arrays `[...]`.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## Iterar

- A função `map_values(filter)` aplica o filtro a cada _valor_ do objeto.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Para iterar sobre um objeto, temos primeiro de o converter num array de objetos chave-valor.
  A função `to_entries` faz isso.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  Nesta altura, podemos usar funções de iteração de arrays, como o `map`.

- A função `from_entries` é o inverso: converte um array de objetos chave-valor num objeto.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- Para aplicar um filtro a _cada_ par chave-valor de um objeto, usa a função `with_entries(filter)`.

  Por exemplo, dado um objeto que associa um nome a uma idade, as chaves e os valores podem ser trocados da seguinte forma.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  devolve

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` é o mesmo que

  ```jq
  to_entries | map(filter) | from_entries
  ```
