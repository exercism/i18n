# Instalar o Python

Se o Python ainda não estiver disponível no teu sistema, encontras instruções detalhadas por plataforma na secção [Python Setup and Usage][using python] da documentação oficial.
O Real Python também tem um [guia útil][helpful guide] para a instalação em várias plataformas, incluindo iOS e Android.

Por fim, estes artigos do Brett Cannon, [A quick-and-dirty guide][quick-and-dirty] e [Why you should use `python -m pip`][python-m-pip], dão conselhos muito úteis sobre como gerir instalações e pacotes do Python.

**Nota para utilizadores de MacOS:**  antes do MacOS Monterey (12.3), o `Python 2.7` vinha pré-instalado com o sistema operativo.
Usar o `Python 2.7` com o Exercism ou com a maioria dos outros programas não é suportado.
Em vez disso, deves instalar o [Python 3][Python-three downloads] através de um dos métodos detalhados abaixo.
A partir do MacOS Monterey (12.3), nenhuma versão do Python vem pré-instalada com o MacOS.

Algumas ligações rápidas para a documentação, por sistema operativo:

-  [Windows][windows] Além disso, este artigo da Microsoft sobre [instalar o Python no Windows][python-on-windows] é útil.
-  [Unix & Linux Systems][unix-and-linux] (_estes métodos funcionam em grande parte para o MacOS também_)
-  [MacOS][macos]

   Também recomendamos que vejas alguns dos métodos descritos no artigo do Real Python [Installing Python][installing-python] ou nos artigos do Brett Cannon indicados acima.


Os testes e as ferramentas do Exercism suportam atualmente `3.10` - `3.13.5` (_testes_) e [`Python 3.13.5`][313-new-features] (_ferramentas_).
As exceções a este suporte são indicadas onde ocorrem.
A maioria dos exercícios funciona com `Python 3.6+`, ou até com versões anteriores.
Mas não garantimos suporte para versões que não constem em [Active Python Releases][active-python-releases].


Consulta a [documentação do Python 3.13.x][3.13 docs] para saberes o que é atualmente suportado.
