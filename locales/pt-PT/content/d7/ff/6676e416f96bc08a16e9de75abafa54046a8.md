# Testes

## Executar os testes

Para executar os testes, usa o seguinte comando:

```bash
make
```

## Resolver o exercício

Resolver um exercício significa fazer com que todos os seus testes passem. Por predefinição, quando corres os testes só um deles é executado, o primeiro. Isto é intencional, para que te possas concentrar apenas em fazer passar esse teste. Assim que ele passar, podes ativar o teste seguinte removendo a linha `TEST_IGNORE()`. Quando todos os testes estiverem ativados e a tua implementação fizer com que todos passem, tens o exercício resolvido!
