# Anexo às instruções

## Memória reservada

Os bytes 1024-1279 da memória linear estão reservados para a string de entrada.

Se quiseres, podes modificar a string de entrada no próprio local.

## Formato da entrada

Os codões são entregues como uma string, concatenados e sem preenchimento.

## Formato da saída

Produz a sequência de proteínas como uma string terminada em null, com um caráter de nova linha depois de cada proteína.

Um exemplo de saída seria `"Methionine\nPhenylalanine\nSerine\n"`

Se a string de entrada for inválida, produz uma string vazia.
