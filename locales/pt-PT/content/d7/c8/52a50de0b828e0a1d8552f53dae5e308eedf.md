# Instruções

A Sarah está a trabalhar num novo jogo de RPG e precisa da tua ajuda com a mecânica do jogador.

## 1. Define o tuplo `player`

Define uma classe de tuplo `player` com quatro fendas e valores predefinidos:

| fenda    | predefinido |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

Depois de a definires, podes construir um jogador como um literal:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. Apresenta o jogador

Define `introduce` para devolver o nome do jogador. Os jogadores furtivos escondem
o nome (`name` é `f`) e devem ser apresentados como
`"Mighty Magician"`.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. Reanima um jogador caído

Define `revive` para devolver um jogador *novo* com `health` definido como 100
e `mana` definido como 100, mas apenas se o `health` do jogador for `0`. Se
o jogador ainda estiver vivo, devolve `f`.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. Recebe dano

Define `take-damage` para devolver um jogador *novo* cujo `health` foi
reduzido na quantidade indicada, nunca ficando abaixo de `0`.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
