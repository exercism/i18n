# Apêndice às instruções

## Dicas

Este é o primeiro exercício cujos testes exigem que lances uma `Exception`.
As `Exception`s são tipicamente lançadas para indicar que um programa se deparou com dados de entrada ou um estado inesperados.

Ao longo do percurso, os testes vão verificar que as exceções que lanças são:

1. instâncias de um tipo Java especificado;
2. (opcionalmente) inicializadas com uma mensagem especificada.

[exception-docs]: https://docs.oracle.com/javase/8/docs/api/java/lang/Exception.html
