# Introdução

As conversões de tipo em Cairo permitem-te transformar dados de um tipo para outro, o que possibilita uma manipulação de dados flexível e segura.

## Noções básicas

O Cairo disponibiliza vários mecanismos de conversão de tipo:

### Conversão direta

Para tipos numéricos compatíveis, podes usar a conversão direta:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### O trait `Into`

O trait `Into` permite converter um tipo noutro:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### O trait `TryInto`

Para conversões que podem falhar, usa `TryInto`, que devolve um `Option`:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## Conversões de tipo personalizadas

Podes implementar `Into` para os teus próprios tipos:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## Considerações de segurança

- Usa `TryInto` quando a conversão pode falhar (por exemplo, de tipos grandes para tipos pequenos)
- Usa `Into` quando a conversão tem sempre sucesso
- Trata sempre os casos `Option::None` do `TryInto`
- Tem em conta o overflow e o underflow ao converter entre tipos com sinal e tipos sem sinal
