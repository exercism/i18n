# Sobre

O `awk` é uma linguagem de programação interpretada, concebida para o processamento de texto e normalmente utilizada como ferramenta de extração e apresentação de dados.
É uma característica padrão da maioria dos sistemas operativos do tipo Unix e tem uma [especificação POSIX][posix].

Pode dizer-se que o paradigma de programação do `awk` é "orientado pelos dados":
um programa `awk` lê linhas (ou outras unidades de texto) e procura correspondências de _padrões_.
Quando ocorre uma correspondência, é executada a _ação_ especificada.

Um programa `awk` tem um aspeto semelhante a este:
```awk
pattern1 {action1}
pattern2 {action2}
...
```

O _padrão_ pode ser uma expressão regular ou outra expressão qualquer que seja avaliada como verdadeira ou falsa.
O _padrão_ pode ser omitido; nesse caso, a _ação_ é executada para cada registo de texto.
A _ação_ pode ser omitida; nesse caso, a ação predefinida é imprimir o registo atual.

O `awk` é uma excelente adição à caixa de ferramentas do utilizador.
É muito bom com pequenos programas de uma só linha introduzidos na linha de comandos.
Um único programa `awk` pode substituir a maioria dos pipelines de `grep`, `sed`, `tr`, `cut`

## Implementações

O `awk` foi inventado em 1977 por Alfred Aho, Peter Weinberger e Brian Kernighan (cujos apelidos dão o nome à linguagem).
Esta implementação ficou conhecida como "old awk".
Em 1985, foi lançada uma versão melhorada, conhecida como "BWK awk", "new awk" ou "the one-true-awk".
É a versão incluída no macOS e em algumas distribuições \*BSD

Outra implementação comum é o `mawk`, que se baseia num intérprete de bytecode.
O `mawk` é muito rápido.
O `mawk` é o `/usr/bin/awk` predefinido incluído em muitas distribuições Linux.

### GNU awk

Este percurso vai usar o `gawk`, a implementação de awk da GNU.
O `gawk` pode não ter a velocidade bruta do `mawk`, mas está repleto de funcionalidades, é bem documentado e tem algumas opções de linha de comandos muito úteis.

### Shebang

Dependendo da plataforma, os scripts awk podem ser executados adicionando uma linha [shebang][shebang] no topo do ficheiro.
Na maioria dos sistemas, uma das duas linhas shebang seguintes deverá funcionar.
No entanto, como não há uma linha shebang que funcione em todos os sistemas, optámos por omitir as linhas shebang.

```bash
#!/usr/bin/env -S gawk -f
#!/usr/bin/gawk -f
```
