# Anexo às instruções

## Registos

| Registo | Utilização | Tipo     | Descrição                                                               |
| ------- | ---------- | -------- | ----------------------------------------------------------------------- |
| `$a0`   | entrada    | endereço | string de entrada terminada em nulo                                     |
| `$v0`   | saída      | Boolean  | a entrada tem parênteses correspondentes (`0` = `false`, `1` = `true`)  |
| `$t0-9` | temporário | qualquer | usado para armazenamento temporário                                     |
