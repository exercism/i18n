# Track de teste

_Antes_ de lançares a tua track (isto é, a chave `"active"` ainda é `false` no `config.json` da track), é importante testá-la.
Isto vai ajudar a encontrar erros (comuns) e a corrigi-los _antes_ de a track ser lançada, o que faz com que os estudantes nunca se deparem com eles.

## Como ativar a track para testes

Para ativar a track para testes, é preciso adicioná-la à nossa base de dados, algo que só os administradores do site podem fazer.
Abre um tópico no [fórum](https://forum.exercism.org/c/exercism/building-exercism/125) a pedir isso.

Repara que adicionar a track à base de dados _não_ a lança, mas _torna-a_ acessível no site para os utilizadores responsáveis por tracks.

## Como encontrar testadores

Os utilizadores ideais para testar a track são outros responsáveis por tracks, porque:

- Têm experiência a construir uma track (e, por isso, sabem o que deveria ter sido construído)
- Conseguem aceder a tracks que ainda não estão ativas

Para conseguires que outros responsáveis testem a tua track, abre um tópico no [fórum](https://forum.exercism.org/c/exercism/building-exercism/125) a pedir isso.
