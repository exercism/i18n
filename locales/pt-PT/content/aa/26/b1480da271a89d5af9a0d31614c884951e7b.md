# Introdução

O mapeamento consiste em aplicar uma função a cada elemento de uma sequência para produzir uma nova sequência.

Podes fazer isto facilmente numa lista com a função `mapcar`.
Vamos supor que tens uma função `double` que multiplica o seu argumento por `2`:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Repara que o primeiro argumento é uma função a chamar. O `#'` é uma sintaxe especial de citação para especificar uma função.

A função `double` foi chamada primeiro com o primeiro elemento, depois com o segundo, etc.
Os resultados foram reunidos numa lista, que é o valor da expressão.
