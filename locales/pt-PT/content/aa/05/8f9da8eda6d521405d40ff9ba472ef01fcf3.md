# Testar na linha de comandos

Corre os testes com:

```bash
$ cargo test
```

Todos os testes, exceto o primeiro, foram ignorados. Depois de fazeres o primeiro teste passar, abre o ficheiro de código-fonte dos testes, que está no diretório `tests`, remove a flag `#[ignore]` do teste seguinte e faz os testes passarem outra vez. Cada teste individual é uma função com a flag `#[test]` acima dela. Continua, até passares em todos os testes.

Se quiseres correr _apenas os testes ignorados_ sem editar o ficheiro de código-fonte dos testes, usa:

```bash
$ cargo test -- --ignored
```

Se estiveres a usar Rust 1.51 ou posterior, podes correr _todos_ os testes com

```bash
$ cargo test -- --include-ignored
```

Para correres um teste específico, por exemplo `some_test`, podes usar:

```bash
$ cargo test some_test
```

Se o teste específico estiver ignorado, usa:

```bash
$ cargo test some_test -- --ignored
```

Para saberes mais sobre os testes de Rust, consulta a [documentação dos testes][rust-tests] online.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
