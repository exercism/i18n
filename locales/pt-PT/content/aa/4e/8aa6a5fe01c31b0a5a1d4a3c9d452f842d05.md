# Introdução

Em Elixir, podemos definir atributos de módulo que podem ser usados como constantes nas nossas funções.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Quando são usados para definir constantes de módulo, os atributos podem ser qualquer expressão que possa ser avaliada em tempo de compilação. Depois da compilação, os atributos de módulo deixam de estar acessíveis, uma vez que são expandidos durante a compilação, à semelhança das macros definidas em linguagens como C.
