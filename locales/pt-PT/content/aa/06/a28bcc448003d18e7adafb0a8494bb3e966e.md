# Os testes passam localmente mas não online?

Às vezes, os teus testes passam localmente na tua máquina, mas não online.

Normalmente, há algumas razões para isto:

## Ainda não ativaste todos os testes

Muitos exercícios do Exercism vêm com alguns testes ignorados.
O objetivo é que resolvas cada teste pela ordem, ativando o seguinte à medida que avanças.
Quando chegares ao fim do exercício, todos os testes devem estar ativos e a passar, e terás uma solução totalmente funcional.
Consulta a documentação do [track em que estás a trabalhar](/docs/tracks) para saberes os pormenores de como funcionam os testes ignorados nessa linguagem.

Quando corremos os testes online, ativamos primeiro todos eles.
Por isso, se localmente deixaste alguns testes ignorados, podemos encontrar casos-limite em que não pensaste e os testes falham.

## Estamos a usar versões diferentes

Os test runners do Exercism usam uma versão específica da linguagem.
Pode não ser a versão mais recente da linguagem, porque temos de atualizar manualmente os nossos test runners sempre que são lançadas novas versões.

Se os testes falharem online, verifica o resultado (clicando na palavra "Failed") e tenta identificar o que pode estar errado.
Se concluíres que o problema se deve a uma incompatibilidade de versões, abre uma issue no repositório do test runner correspondente no GitHub.
Isso normalmente segue o padrão `https://github.com/exercism/$SLUG-test-runner` (por exemplo, `https://github.com/exercism/ruby-test-runner`).
