# Anexo às instruções

## Registos

| Registo | Utilização | Tipo    | Descrição                                        |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | valor de entrada | endereço | string de entrada terminada em null           |
| `$v0`    | valor devolvido  | boolean  | o valor de entrada é um pangrama (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário            |
