# Sobre

Os Boolean em C# são representados pelo tipo `bool`, cujos valores podem ser `true` ou `false`.

O C# suporta quatro [operadores Boolean][operators]: `!` (NOT), `&&` (AND), `||` (OR) e `^` (XOR). Os operadores `&&` e `||` usam _avaliação de curto-circuito_. Isto significa que o lado direito do operador só é avaliado quando é necessário.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

Cada um dos três operadores Boolean tem uma [_precedência de operadores_][precedence] diferente. Por isso, são avaliados por esta ordem: primeiro `not`, depois `&&`, depois `^` e, por fim, `||`. Se quiseres 'escapar' a estas regras, podes envolver uma expressão Boolean em parênteses (`()`), porque os parênteses têm uma precedência de operadores ainda maior.

```csharp
!true && false   // => false
!(true && false) // => true
```
