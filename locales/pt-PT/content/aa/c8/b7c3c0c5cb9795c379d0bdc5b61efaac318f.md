# Dicas

## Geral

- O módulo `gleam/string` tem muitas [funções de string][stdlib] úteis.

## 1. Obtém a mensagem de uma linha de registo

- O operador `<>` pode ser usado em correspondência de padrões para fazer corresponder o início de uma string.
- O módulo `gleam/string` tem uma [função][trim] para remover os espaços em branco à volta de uma string.

## 2. Obtém o nível de registo de uma linha de registo

- O módulo `gleam/string` tem uma [função][lowercase] para converter uma string em minúsculas.

## 3. Reformata uma linha de registo

- O operador `<>` pode ser usado para juntar strings.

[trim]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#trim
[lowercase]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#lowercase
