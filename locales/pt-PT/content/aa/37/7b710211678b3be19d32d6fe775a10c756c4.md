# Anexo às instruções

## Registos

| Registo | Utilização       | Tipo    | Descrição                                          |
| ------- | ---------------- | ------- | -------------------------------------------------- |
| `$a0`   | valor de entrada | inteiro | número inicial                                     |
| `$v0`   | valor de saída   | inteiro | número de passos esperado, -1 se o número for inválido |
| `$t0-9` | temporário       | qualquer | usado para armazenamento temporário               |
