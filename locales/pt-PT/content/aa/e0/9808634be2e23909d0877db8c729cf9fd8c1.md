# Anexo às instruções

## Dicas

Para completar este exercício, tens de criar o tipo de dados `Robot`
e implementar as seguintes funções:

- `bearing`
- `coordinates`
- `mkRobot`
- `move`

Vais encontrar uma declaração de dados de exemplo e assinaturas de tipos já no lugar,
mas cabe-te a ti definir as funções e criar um tipo de dados,
um newtype ou um sinónimo de tipo que faça sentido.
