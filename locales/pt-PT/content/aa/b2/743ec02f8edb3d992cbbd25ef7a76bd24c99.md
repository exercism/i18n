# Dicas

## Geral

- Usa o crate `enum-iterator` para conseguires iterar sobre enums. Consulta a [documentação](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) para saberes como.

- Usa o crate `int-enum` para conseguires converter de int para enum. Consulta a [documentação](https://docs.rs/int-enum/0.5.0/int_enum/) para mais detalhes.

- O trait `Debug` está lá porque provavelmente vais precisar dele.

- Vais precisar de alargar a lista de traits derivados com `derive` no teu enum de cores.
