# Sobre

As condicionais são instruções que executam código diferente conforme a condição seja `true` ou `false`.

Uma [condicional `if`][if_statement] executa o seu corpo apenas quando a condição é `true`.
O Go não tem o conceito de valores que possam ser avaliados como verdadeiros ou falsos, por isso a condição tem de ser do tipo `bool`.
Expressões como `if mySlice { ... }` ou `if 1 { ... }` dão erros de compilação.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Usa `else if` para verificar condições adicionais e `else` como alternativa caso nenhuma corresponda.
As condições são avaliadas de cima para baixo e só o primeiro ramo cuja condição é verdadeira é executado.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Em geral, o Go prefere devolver cedo no caso excecional e evitar o `else`.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

Uma condicional `if` também pode incluir uma instrução curta de inicialização.
Isto é habitualmente usado para verificar um erro logo a seguir a uma chamada:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

As variáveis declaradas na instrução de inicialização só existem no âmbito de toda a cadeia `if`/`else`.
É de notar que o Go não tem operador ternário, uma escolha deliberada de design para manter o código fácil de ler.

Para saberes mais, consulta [Go by Example: If/Else][go_by_example_if].
