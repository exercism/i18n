# Instruções

Dois violinistas estão a ensaiar um dueto. Cada parte é um array que guarda o
número de notas em cada compasso, e as partes nem sempre têm o mesmo comprimento.

As quatro tarefas ficam todas na classe `DUET_PRACTICE`.

## 1. Quantos compassos tocam juntos?

Tocam juntos enquanto ambas as partes ainda tiverem um compasso por tocar.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. Quantos compassos coincidem?

Conta os compassos em que ambas as partes têm o mesmo número de notas. Só os
compassos que ambos têm é que podem coincidir.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. Quem tem mais trabalho?

Conta os compassos em que a primeira parte tem mais notas do que a segunda.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. Pondera os compassos

Os compassos mais à frente são mais difíceis, por isso um compasso vale tanto
quanto a sua posição: o primeiro compasso conta uma vez, o segundo duas, o
terceiro três. Multiplica as notas de cada compasso pelo seu número e soma tudo.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

Ou seja, 1×4 + 2×4 + 3×8. Os compassos numeram-se a partir de um, não de zero.
