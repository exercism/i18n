# Testes

Antes de tentares executar os testes, certifica-te de que a pasta da tarefa está configurada corretamente, seguindo os passos de instalação, nomeadamente `corepack yarn install` e a configuração do Editor SDK.

Executa os testes com:

```bash
$ corepack yarn test
```

## Testes ignorados

Nos conjuntos de testes, todos os testes exceto o primeiro estão ignorados.

Assim que conseguires passar um teste, podes ativar o seguinte ao alterar `xit` para `it`.
Além disso, os testes podem ser agrupados com `xdescribe`.
Ativa o grupo alterando `xdescribe` para `describe`.
Por fim, alguns exercícios podem ter testes opcionais `it.skip`.
Remove `.skip` para executar o teste opcional.
