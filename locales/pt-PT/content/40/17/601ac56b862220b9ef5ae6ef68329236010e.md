# Acerca de

O tipo `Option` é um enum fornecido pela biblioteca padrão. É útil para expressar um valor que pode não existir. Apesar de poder soar a `null` ou `nil`, é bastante diferente e especial.

`Option<T>` contém outros tipos e tem duas variantes: `Some(T)` e `None`.

Por exemplo, `Option<u32>` contém o tipo `u32`.

## Utilização

### Usar o `T` dentro de `Option<T>`

Existem várias formas comuns de usar o valor que pode estar presente num `Option`:

- `if let Some(t) = optional { ... }`.

    O idiomatismo `if let` extrai o valor de um `Option<T>` e liga-o à variável `t`. Isto permite-te usá-lo diretamente no âmbito desse bloco.

- `match optional { Some(t) => {...}, None => {...}}`

    O operador `match` também te permite desempacotar e tratar os casos `None` numa única instrução ou expressão. É uma alternativa a uma cadeia de instruções if e else. Usar `match` pode aumentar a legibilidade de algumas partes do código.
- `optional.map(|t| ...)`
   `Option::map` atualiza um `Option` no próprio local, potencialmente com um novo tipo, a partir da função fornecida.

   **Nota**: atua sobre o valor contido, se este existir. A ligação passa a ser um `Option<U>`, em que a closure fornecida é `FnOnce(T) -> U`.
- `optional.unwrap()`.
   Fazer unwrap de um `Option<T>` extrai o `T`, mas entra em pânico se o `T` não estiver lá. É prático em alguns casos.

   **Importante**: fazer unwrap pode facilitar o desenvolvimento a curto prazo ou em código de teste, mas introduz a possibilidade de pânicos em tempo de execução. Deve ser evitado sempre que possível.

- `optional.expect("Unexpected None found! Aborting program.)`.
   O método `expect` em `Option<T>` é bastante semelhante a `unwrap()`, mas entra em pânico com a mensagem fornecida se o valor for `None`.

## Exemplos

Quando existe um valor num `Option<u32>`:

```rust
let has_something: Option<u32> = Some(100);
assert_eq!(has_something.unwrap(), 100);
```

Quando *não* existe um valor num `Option<u32>`:

```rust
let has_nothing: Option<u32> = None;
assert_eq!(has_nothing, None);
```
