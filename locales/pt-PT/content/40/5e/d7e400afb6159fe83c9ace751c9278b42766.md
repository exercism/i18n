# Dicas

## Geral

- Vais precisar de importar o [módulo Dict][dict-module].

## 1. Agrega os marcadores

- Provavelmente, o mais fácil é definir uma função de atualização e usar `Dict.update` em `updateGoalCountForPlayer`.

## 2. Remove os jogadores insignificantes

- O mais fácil para isto é `Dict.filter`.

## 3. Reinicia a contagem de golos do jogador

- O mais fácil para isto é `Dict.insert`.

## 4. Formata a contagem de golos de um jogador

- `Dict.get`, `Maybe.map` e `Maybe.withDefault` são úteis para isto.

## 5. Formata a contagem de golos de todos os jogadores

- `Dict.toList`, `List.map` e `String.join` são úteis para isto. Não é preciso `sort`.

## 6. Combina os jogos

- O mais fácil para isto é `Dict.merge`.

[dict-module]: https://package.elm-lang.org/packages/elm/core/latest/Dict
