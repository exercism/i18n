# Dicas

## 1. Cria o identificador dos portos

- Tens de definir uma [constante][constants] que deve conter o valor de símbolo indicado nas instruções.

## 2. Obtém os identificadores para os outros portos

- É possível [fatiar][slice] uma string para obter partes dela.
- As `Strings` têm um [método][upcase] para pôr as letras em maiúsculas.
- As `Strings` têm um [método][to_sym] para converter uma string num símbolo.

## 3. Determina em que terminal um navio deve atracar

- O Symbol tem um [método][to_s] para converter um símbolo numa string.
- É possível [fatiar][slice] uma string para obter partes dela.
- Usa a condicional [`if`][doc-if] para verificar se o navio transporta `"OIL"` ou `"GAS"`.
