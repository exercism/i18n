# Instalação

## Que versão escolher?

Recomendamos que uses uma versão estável de PHP com suporte ativo.
Atualmente, são a **PHP 8.2, 8.3 e 8.4**.
Encontras detalhes sobre as versões atuais e os respetivos calendários na [documentação oficial do PHP](https://www.php.net/supported-versions.php).

## Instalar o PHP

A maioria dos gestores de pacotes para Linux / macOS fornece pacotes pré-compilados.
Podes descarregar e compilar o PHP a partir do código-fonte, disponível em [php.net/downloads.php](https://php.net/downloads.php) ou em [windows.php.net/download](https://windows.php.net/download).

~~~~exercism/note
Não precisas de um servidor web como o nginx ou o servidor HTTP Apache para resolver os exercícios.
~~~~

### Linux

Cada distribuição tem os seus métodos.
Deves conseguir fazer

```shell
yum install php
```

ou

```shell
apt-get install php
```

consoante o teu gestor de pacotes.

Para mais instruções, consulta o manual do PHP sobre [Instalação em sistemas Unix](https://www.php.net/manual/en/install.unix.php).

### macOS

Embora o PHP venha muitas vezes incluído no macOS, está frequentemente desatualizado.
Recomendamos instalar o PHP através do [Homebrew](https://brew.sh/).
Podes instalar o Homebrew seguindo as instruções [na página inicial deles](https://brew.sh/#install).

Para confirmar a instalação, experimenta o seguinte comando; deve devolver o Homebrew `4.5.x` no momento em que isto foi escrito.

```shell
brew --version 
```

Instala o PHP através do Homebrew

```shell
brew install php@8.4
```

Isto deve mostrar a versão de PHP agora instalada, pelo menos a versão `8.2.0`.

```shell
php -v
```

Para mais instruções, consulta o manual sobre [Instalação no macOS](https://www.php.net/manual/en/install.macosx.php).

### Windows

Podes descarregar os binários oficiais do PHP para Windows em [windows.php.net/download](https://windows.php.net/download).

Existem pacotes pré-compilados que incluem o [WAMP](https://www.wampserver.com/en/) - (Windows, Apache, MySQL, PHP) e o [XAMPP](https://www.apachefriends.org/de/index.html).

Para mais instruções, consulta o manual sobre [Instalação em sistemas Windows](https://www.php.net/manual/en/install.windows.php).

### Docker

Se preferires soluções em contentores, podes descarregar a [imagem oficial do PHP do Docker Hub](https://hub.docker.com/_/php).
Vais também precisar do [Docker](https://docs.docker.com/engine/install/).

### Outros

Se quiseres usar outro sistema operativo, vê as instruções em [php.net/manual/en/install](https://www.php.net/manual/en/install.php).

## Instalar o PHPUnit

O PHPUnit 12 ainda não é suportado!
~~~~

### Através de PHP Archive (PHAR)

A forma mais fácil de usar o PHPUnit nos exercícios do Exercism é descarregar uma distribuição empacotada como PHP Archive (PHAR), que é também a forma recomendada de usar o PHPUnit.
Guarda o PHAR no mesmo local onde guardaste a CLI `exercism`, para poderes executar o PHPUnit de onde quer que estejas.

Podes descarregar uma versão dos pacotes do PHPUnit como arquivo PHP:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

Depois, torna o ficheiro descarregado executável:

```shell
chmod +x phpunit.phar
```

E move-o para o mesmo local para onde moveste a CLI `exercism`, dando o nome `phpunit` ao comando:

```shell
mv phpunit.phar ~/bin/phpunit
```

Agora podes executar o `phpunit` de onde quer que estejas, como mostrado na [documentação de testes da track de PHP](https://exercism.org/docs/tracks/php/tests):

```shell
phpunit --version
```

A saída deve ser parecida com isto:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

Também podes seguir as [instruções oficiais de instalação do PHPUnit](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) para instalar o PHPUnit.

### Através do Composer

A versão 11 do PHPUnit também pode ser instalada através do [Composer](https://getcomposer.org).

#### Instalar o Composer

Instala o [Composer](https://getcomposer.org) seguindo as [instruções de instalação](https://getcomposer.org/doc/00-intro.md) do sistema operativo do teu dispositivo. Recomendamos instalá-lo globalmente, para ser mais fácil de usar.

#### Adicionar o PHPUnit como ferramenta global

Usa o seguinte comando:

```shell
composer global require phpunit/phpunit ^11.5
```

Certifica-te de que instalas a versão 11.5 ou posterior.
