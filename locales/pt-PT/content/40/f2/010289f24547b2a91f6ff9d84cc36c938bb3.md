# Dicas

## Geral

- [Tutorial sobre números][numbers].

## 1. Calcula a taxa de produção por segundo

- Determinar a taxa de sucesso pode ser feito com uma [condicional][if-statement].
- O Java permite aplicar a multiplicação a dois tipos de números diferentes (como um `int` e um `double`). O Java devolve automaticamente o tipo de dados mais "abrangente".
- Os números podem ser comparados com os [operadores de comparação][comparison-operators] e [operadores de igualdade][comparison-operators] integrados.

## 2. Calcula o número de itens funcionais produzidos por segundo

- Enquanto um `int` pode ser convertido automaticamente num `double`, o inverso não se verifica. A razão é que um `int` tem menos precisão do que um `double`, pelo que é preciso aplicar arredondamento; além disso, o intervalo de números que um `int` pode representar é menor do que o de um `double`. Para forçar esta conversão, podes usar uma [conversão para int][cast-int].
