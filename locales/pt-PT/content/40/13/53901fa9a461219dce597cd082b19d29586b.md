# Introdução

Como todos os tipos de dados padrão do Clojure são imutáveis, ele oferece *tipos de referência*, que permitem mutação controlada. O mais simples e o mais utilizado destes chama-se Atom.

Os Atoms são criados com a função `atom`, que recebe um valor inicial:

```clojure
(def players (atom ()))
```

Para obter o valor atual do atom, usa-se `deref` ou a forma abreviada `@`:

```clojure
@players
;;=> ()
```

O valor atual do atom `players` pode ser modificado com `swap!`, que atualiza o valor aplicando uma função:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

A função `reset!` substitui o valor de um atom sem ter em conta o valor atual:

```clojure
(reset! players ())
```
