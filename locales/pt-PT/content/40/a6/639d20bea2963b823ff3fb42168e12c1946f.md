# Apêndice às instruções

## Como este exercício está estruturado no percurso de Python

Os testes deste exercício esperam que cries uma [`class`][classes] Matrix (_ver também [concept:python/classes]()_).
Isto é diferente de _usar_ um objeto Matrix de uma biblioteca de terceiros como [Numpy][numpy-matrix], que não é suportado.
 _Não te preocupes, não é tão complicado como pensas!_
 Para mais pontos de partida e detalhes sobre `classes` e estruturas de dados, dá uma vista de olhos aos recursos abaixo:


-   [**A First Look at Classes**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) da documentação do Python 3. 
-   [**How to Define a Class in Python**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) do site Real Python.  
-   [**Data Structures in Python**](https://docs.python.org/3/tutorial/datastructures.html) da documentação do Python 3.

[numpy-matrix]: https://numpy.org/doc/stable/reference/generated/numpy.matrix.html
