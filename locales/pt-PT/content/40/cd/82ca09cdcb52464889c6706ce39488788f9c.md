# Sobre

Os tipos que implementam a interface [`IEnumerable<T>`][IEnumerable] são conhecidos por serem _enumerable_.
Todos os tipos de coleção incorporados implementam esta interface.

Um tipo enumerable pode ser percorrido com um ciclo `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Para implementar `IEnumerable<T>`, um tipo tem de implementar um método: `IEnumerator<T> GetEnumerator()`.
Como se vê, um enumerable delega a iteração propriamente dita sobre uma coleção num tipo `IEnumerator<T>`.
Esta interface tem uma propriedade e três métodos para implementar:

- `public T Current { get; }`: obtém o elemento atual.
- `public bool MoveNext ();`: avança para o elemento seguinte, devolvendo `true` se a passagem para o elemento seguinte correu bem, e `false` se não (já não há mais elementos).
- `public void Reset ();`: reinicia o enumerador para o seu estado inicial (antes do primeiro elemento).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
