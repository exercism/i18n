# Introdução

Os ciclos `for` são o tipo de ciclo mais complexo em PHP. Comportam-se como os ciclos `for` em `C`, `Java` e `JavaScript`. A sua forma básica é:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

A primeira expressão (_expr1_) é avaliada antes de o ciclo começar. A segunda expressão (_expr2_) é avaliada antes de cada iteração; se for avaliada como _verdadeira_, as instruções são executadas. Depois de as instruções serem executadas, é avaliada a terceira expressão (_expr3_).
