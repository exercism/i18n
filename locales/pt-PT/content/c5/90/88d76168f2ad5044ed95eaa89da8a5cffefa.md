# Instruções

Uma escola local perto de ti tem uma associação de estudantes muito ativa.
A associação de estudantes é gerida por um presidente e, de 2 em 2 anos, realizam-se eleições para eleger um novo presidente.

Nas eleições deste ano, decidiu-se que era necessário um novo sistema digital para contar os votos.
A escola precisa da tua ajuda para construir este novo sistema.

## 1. Cria um contador de votos

Uma das primeiras coisas de que o novo sistema de votação precisa é um contador de votos.
Este contador serve para acompanhar os votos que um determinado candidato tem.

Cria uma função `NewVoteCounter` que aceita o número de votos iniciais de um candidato e devolve um apontador para um `int`, inicializado com o número de votos iniciais indicado.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. Obtém o número de votos de um contador

Já tens forma de criar novos contadores! Mas agora reparas que o novo sistema também vai precisar de uma forma de obter o número de votos de um contador.

Cria uma função `VoteCount` que recebe um contador (`*int`) como argumento e devolve o número de votos do contador.
Se o contador for `nil`, deves assumir que o contador não tem votos:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. Incrementa os votos de um contador

É finalmente a altura de contar os votos! Agora precisas de uma forma de incrementar os votos de um contador.

Cria uma função `IncrementVoteCount` que recebe um contador (`*int`) como argumento e um número de votos, e incrementa o contador com esse número de votos.
Podes assumir que o apontador recebido nunca será `nil`.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. Cria os resultados das eleições

Com todos os votos contados, é altura de preparar o anúncio dos resultados para toda a escola.
Para isso, reparas que ter apenas contadores de votos não é suficiente.
É preciso uma forma de associar o número de votos a um determinado candidato.

Cria uma função `NewElectionResult` que recebe o nome de um candidato e o seu número de votos e devolve um novo resultado eleitoral.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

A struct do resultado eleitoral já foi criada para ti e está definida assim:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. Anuncia os resultados

É altura de anunciar o novo presidente à escola!
O presidente será anunciado nos pequenos painéis de mensagens digitais que a escola tem.
A mensagem deve mostrar o nome do novo presidente e os votos que teve, no seguinte formato: `<candidate_name> (<votes>)`.
Este é um exemplo dessa mensagem: `"Peter (51)"`.

Cria uma função `DisplayResult` que recebe um `*ElectionResult` como argumento e devolve uma string com a mensagem a apresentar.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. Recontagem dos votos

Para garantir que os resultados finais estavam corretos, os votos foram recontados.
Na recontagem, descobriu-se que o número de votos de alguns candidatos estava errado por um.

Cria uma função `DecrementVotesOfCandidate` que recebe os resultados finais e o nome de um candidato cujo número de votos deves decrementar.
Os resultados finais são dados na forma de um `map[string]int`, em que as chaves são os nomes dos candidatos e os valores são o seu total de votos.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
