# Introdução

## Tuplos

Um tuplo é um contentor ordenado de valores. Tal como todos os tipos de dados de Gleam, os tuplos são imutáveis. Cada elemento de um tuplo pode ser de um tipo diferente: podem até ser outros tuplos.

Os tuplos definem-se como valores separados por vírgulas entre `#(` e `)`: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Tuplos com o mesmo comprimento e os mesmos tipos (pela mesma ordem) podem ser comparados quanto à igualdade.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Há três formas de extrair os valores contidos num tuplo:

- Indexação.
- Correspondência de padrões com `let`.
- Correspondência de padrões com `case`.

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 170

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
