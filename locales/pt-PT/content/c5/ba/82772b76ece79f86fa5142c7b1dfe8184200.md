# Sobre

Em Haxe, um **array**, ou _vetor_, é uma coleção de elementos (normalmente) do mesmo tipo. Há três formas de criar um array em Haxe: com o construtor ou com uma sintaxe de declaração. Em Haxe, o primeiro elemento de um array tem índice zero:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Para criar um array com um construtor, tens de indicar o tipo dos elementos que vão fazer parte do array:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Como o acesso a arrays em Haxe não tem limites, ou seja, é garantido que não lança uma exceção, isto merece uma explicação mais detalhada:

- Se fizeres uma leitura num índice que não existe, é devolvido um valor que depende do alvo.
- Se fizeres uma escrita com um índice positivo que está fora dos limites, é inserido `null` (ou o valor predefinido dos tipos básicos em alvos estáticos) em todas as posições entre o último índice definido e o índice que acabaste de escrever.
- Se fizeres uma escrita com um índice negativo, o resultado é indeterminado.

Se quisermos que um array contenha vários tipos de elementos, acrescentamos o tipo `Dynamic` ao indicador de tipo:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## Iteração

Podes iterar um array com um ciclo `for`:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
