# usa a captura de funções

[comment]: # (requer 2 parâmetros:)
[comment]: # (- expected: a função corrigida)
[comment]: # (- actual: a função incorreta que o aluno usou)

Quando passas uma função existente como argumento, certifica-te de que a capturas em vez de criares uma nova função anónima.

```elixir
# preferred: using capture notation

%{expected}

# discouraged: creating new anonymous functions

%{actual}
```
