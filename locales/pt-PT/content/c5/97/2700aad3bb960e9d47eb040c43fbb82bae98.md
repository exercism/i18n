# Anexo às instruções

## Mensagens de exceção

Por vezes, é necessário [levantar uma exceção][raise-an-exception]. Quando o fazes, deves incluir sempre uma **mensagem de erro significativa** que indique qual é a origem do erro. Isto torna o teu código mais legível e ajuda bastante na depuração. Nas situações em que sabes que a origem do erro será de um determinado tipo, podes optar por levantar um dos [tipos de erro incorporados][built-in-errors], mas deves incluir na mesma uma mensagem significativa.

Este exercício em particular exige que uses a [instrução raise][raise-statement] para "lançar" um `ValueError` se a pergunta passada a `answer()` estiver mal formada/inválida, ou contiver uma operação desconhecida. Os testes só passam se fizeres `raise` da `exception` e incluíres também uma mensagem.
**Atenção**: A mensagem necessária é diferente para cada cenário, mesmo que o mesmo _tipo de erro_ esteja a ser levantado.
Verifica os testes com atenção.

Para levantar um [`ValueError`][value-error] com uma mensagem, escreve a mensagem como argumento do tipo `exception`:


```python
# if the question contains an unknown operation.
raise ValueError("unknown operation")

# if the question is malformed or invalid.
raise ValueError("syntax error")
```

Para _tratar_ um erro levantado dentro de um determinado bloco de código, podes usar um [try-except][handling-exceptions].
Os blocos `try-except` "envolvem" o código que pode potencialmente causar um erro, mapeando todas as exceções para um erro, vários erros, ou outros pedaços de código que tratam do problema:


```python
while len(equation) > 1:
        try:
           # The questionable/error-prone code goes here,in an indented block
           # It can contain statements, loops, if-else blocks, or other executable code.
           x_value, operation, y_value, *rest = equation
           ...
           ...

        except:
            # Code for what to do when an error gets thrown in the code above.
            # This could be one error, or more complicated logging, error checking and messaging.
            raise ValueError("syntax error")
```
