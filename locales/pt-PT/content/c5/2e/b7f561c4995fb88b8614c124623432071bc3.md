# Instruções

Neste exercício vais gerar mensagens de registo semiestruturadas.

## Emite mensagens semiestruturadas

Vais começar com algumas funções esboçadas e com o seguinte enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

O teu objetivo é emitir uma mensagem de registo com o seguinte formato: `"[<LEVEL>]: <MESSAGE>"`.
Vais ter de implementar funções que correspondem aos níveis de registo.

Por exemplo, o excerto abaixo mostra um resultado esperado para a função `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

E para `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Diverte-te!
