# Introdução

Tal como muitas outras linguagens, o C++ tem _ponteiros_.
Já sabes que as _referências_ e os _ponteiros_ são semelhantes, mas pensa neles como estando um nível mais próximo do funcionamento interno do teu computador.
Os _ponteiros_ são variáveis que guardam endereços de objetos.
São usados para interagir diretamente com objetos, permitindo a alocação dinâmica de memória e uma manipulação eficiente de dados em C++.

Se estás a começar com os _ponteiros_, podem parecer um pouco misteriosos, mas depois de te habituares a eles são bastante simples.

São uma parte fundamental do C++, por isso dedica algum tempo a compreendê-los mesmo bem.
A versão mais básica apresentada neste conceito também é chamada de _dumb pointer_ ou _raw pointer_.
Com o C++ moderno existem também os _smart pointers_; o tipo básico não é nada inteligente e tens de fazer todo o trabalho manualmente.

Antes de entrares nos detalhes, vale a pena perceber para que servem os _ponteiros_.
Os _ponteiros_ são uma forma de partilhar o endereço de um objeto com outras partes do nosso programa, o que é útil por duas grandes razões:

1. Tal como as _referências_, os ponteiros evitam cópias e ajudam a reduzir o consumo de recursos do teu programa.
1. Ao contrário das _referências_, os ponteiros podem ser reatribuídos a objetos diferentes.
1. Os ponteiros também podem apontar para um valor nulo, para indicar que, de momento, não apontam para nenhum objeto.

## Sintaxe geral

Uma declaração de ponteiro em C++ implica especificar o tipo de dados para o qual o ponteiro aponta, seguido de um asterisco (`*`) e do nome do ponteiro.
Quando os ponteiros são declarados, não são inicializados automaticamente.
Sem uma atribuição explícita, um ponteiro guarda habitualmente um valor indeterminado, muitas vezes designado por «endereço de lixo».
Embora alguns compiladores possam inicializar os ponteiros a `nullptr`, esse comportamento não é garantido em todos os compiladores, por isso é essencial não contar com ele.
A boa prática é inicializar explicitamente os _raw pointers_ e verificar se não são nulos antes de os utilizares, para evitar potenciais problemas.

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

Para atribuir o endereço de uma variável a um ponteiro, usas o operador de endereço (`&`).
A derreferenciação de um ponteiro faz-se com o _operador de indireção_ (`*`).

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

Atenção: a derreferenciação tem de ser feita explicitamente, enquanto as _referências_ funcionavam simplesmente como um alias.

## Aritmética de ponteiros

A _aritmética de ponteiros_ permite-te efetuar operações aritméticas sobre ponteiros, o que é especialmente útil quando trabalhas com arrays.
Somar um número inteiro a um ponteiro faz com que este aponte para um elemento diferente.

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

## Acesso a variáveis membro

Em C++, o operador `->` é usado para aceder aos membros de um objeto através de um ponteiro para esse objeto.
É uma forma abreviada que simplifica o acesso aos membros de objetos apontados por ponteiros.
Por exemplo, se `ptr` for um ponteiro para um objeto com uma variável membro `x`, em vez de usares `(*ptr).x` podes usar diretamente `ptr->x`.
Este operador melhora a legibilidade do código e reduz a verbosidade quando trabalhas com ponteiros para objetos.

Eis um exemplo breve, com uma _struct_ `Superhero` que tem uma variável membro `superpower`.
A função main cria um ponteiro `dianaPrince` para um objeto `Superhero` (que representa a Mulher-Maravilha).
O operador `->` é usado para aceder à variável membro `superpower`, mostrando o icónico «Laço da Verdade» da Mulher-Maravilha.

```cpp
struct Superhero {
    std::string superpower;
};

Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";

// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;

// Memory cleanup:
delete dianaPrince;
```

## Ponteiros vs. referências

Tanto os ponteiros como as referências permitem o acesso indireto a objetos, mas diferem nas suas capacidades e nas considerações de segurança.
Os ponteiros oferecem a flexibilidade de mudar o objeto para o qual apontam e podem receber o valor nulo.
No entanto, essa flexibilidade introduz riscos, como derreferenciar ponteiros nulos ou criar ponteiros pendentes.
As referências, por outro lado, não podem ser nulas e ficam ligadas a objetos válidos no momento da criação, o que evita esses riscos.
Dada a sua natureza mais segura, deves preferir as referências aos ponteiros, a menos que as funcionalidades adicionais que os ponteiros oferecem sejam necessárias.

## Alocação dinâmica de memória e ponteiros nulos

Em C++, o `new` é usado para alocar dinamicamente memória para objetos na heap durante o tempo de execução.
Devolve um ponteiro para o endereço de memória alocado, permitindo que os objetos tenham tempos de vida que não estão dependentes de um âmbito específico.
No entanto, é importante emparelhar sempre o `new` com o `delete` para libertar corretamente a memória.
A alocação dinâmica de memória deve ser usada com cautela, para evitar problemas comuns como fugas de memória e o acesso a memória já libertada.

Os ponteiros também podem receber um valor especial chamado _ponteiro nulo_, que indica que não apontam para um endereço válido.
Os ponteiros nulos são habitualmente usados para inicializar ponteiros antes de lhes atribuir valores válidos.

```cpp
// There is a dark mark bearer, but who is it?
std::string* darkMarkBearer{nullptr};
// It is Bellatrix!
darkMarkBearer = new std::string{"Bellatrix Lestrange"};
// She has been defeated
delete darkMarkBearer;
// Reset pointer to null, symbolizing there is no more darkMarkBearer at the moment
darkMarkBearer = nullptr;
```

Um ponteiro deve conter o endereço de um objeto válido ou ser definido como `nullptr`.
Assim, só precisas de testar se os ponteiros são nulos e podes assumir que qualquer ponteiro não nulo é válido.
Quando um objeto é destruído, todos os ponteiros para o objeto destruído ficam _pendentes_ (não são automaticamente definidos como `nullptr`).
É tua responsabilidade detetar esses casos e garantir que esses ponteiros são posteriormente definidos como `nullptr`.


Em código mais antigo, podes encontrar duas alternativas ao `nullptr`.
Primeiro, o literal `0` é interpretado especificamente como um valor nulo para ponteiros, embora seja o único caso em que um literal inteiro pode ser atribuído a um ponteiro.
Segundo, a `preprocessor macro` `NULL`, herdada do C e definida no cabeçalho `<cstddef>`, é outra representação de um ponteiro nulo, embora o seu uso seja menos comum no código C++ moderno.
