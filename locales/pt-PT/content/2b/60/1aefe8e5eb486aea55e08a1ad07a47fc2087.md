# erro de cláusula de função no raise

[comment]: # (Este erro é lançado quando a submissão inclui uma chamada a `raise FunctionClauseError` em vez de deixar o Elixir falhar ao fazer corresponder a chamada à função two_fer para tipos que não são strings.)

Não chames `raise FunctionClauseError` diretamente.

> Lançar este erro é um [code smell](https://en.wikipedia.org/wiki/Code_smell) que indica que as cláusulas da função devem ser reordenadas ou que devem ser implementadas guardas para impedir a correspondência da função.

1. Quando o Elixir executa código, tenta fazer corresponder a chamada de [funções nomeadas](https://elixir-lang.org/getting-started/modules-and-functions.html#named-functions) e os seus parâmetros a cada função, de cima para baixo.
2. Se forem usadas [guardas](https://hexdocs.pm/elixir/master/guards.html), é possível impedir que as funções sejam invocadas com argumentos que não correspondem ao uso pretendido da função.
3. Se não houver correspondência para uma função nomeada, o [BEAM VM](<https://en.wikipedia.org/wiki/BEAM_(Erlang_virtual_machine)>) lança um `FunctionClauseError` em tempo de execução.
