# Instruções

Tens estado a trabalhar num projeto que permite aos utilizadores carregar ficheiros para o servidor, para serem partilhados com outros utilizadores. Foi-te pedido que escrevas uma função para verificar se um carregamento corresponde ao seu [tipo de media][mimetype]. Fazes alguma pesquisa e descobres que os primeiros bytes de um ficheiro são geralmente únicos desse tipo de ficheiro, o que lhe dá uma espécie de assinatura.

Usa a seguinte tabela como referência:

| Tipo de ficheiro | Extensão comum | Tipo de media                | «assinatura» binária                             |
| ---------------- | -------------- | ---------------------------- | ------------------------------------------------ |
| ELF              | `"exe"`        | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP              | `"bmp"`        | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG              | `"png"`        | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG              | `"jpg"`        | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF              | `"gif"`        | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. Dada uma extensão, devolve o tipo de media esperado

Implementa a função `type_from_extension/1`. Deve receber uma extensão de ficheiro (string) e devolver o tipo de media (string), ou nil se a extensão não corresponder às esperadas.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. Dado um ficheiro binário, devolve o tipo de media esperado

Implementa a função `type_from_binary/1`. Deve receber um ficheiro (binário) e devolver o tipo de media (string), ou nil se a assinatura do ficheiro não corresponder às esperadas.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

Não te preocupes em ler o ficheiro como binário. Assume que isso já foi feito por ti e que é fornecido pelos testes como argumento.

## 3. Dada uma extensão e um ficheiro binário, verifica se o ficheiro corresponde ao tipo esperado

Implementa a função `verify/2`. Deve receber um ficheiro (binário) e uma extensão (string) e devolver um tuplo `:ok` ou `:error`.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
