# Anexo às instruções

Uma possível solução para este exercício é implementares a tua própria função de exponenciação modular.
Para saberes mais sobre isto, consulta a [página seguinte](https://en.wikipedia.org/wiki/Modular_exponentiation).

## Pontos de bónus

Muitas implementações não funcionam para todo o domínio de valores de entrada.
Existem testes opcionais adicionais que ajudam a garantir que todos os valores de entrada válidos produzem resultados válidos.

Para correres os testes de bónus, remove a flag `#[ignore]` e executa os testes com a feature `big-primes`, assim:

```bash
$ cargo test --features big-primes
```
