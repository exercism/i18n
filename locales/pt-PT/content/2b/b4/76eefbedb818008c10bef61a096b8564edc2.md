# Introdução

## Arrays

Em Common Lisp, tal como noutras linguagens, um array, ou vetor, é um conjunto de elementos a que se acede através de índices inteiros.
Os tipos dos elementos podem ser heterogéneos.
O array pode ser multidimensional (não apenas unidimensional).

### Criação

`make-array` permite criar arrays.
Tem muitas opções, mas as formas mais simples permitem criar arrays de N dimensões com todos os elementos inicializados com um único valor, ou inicializar o array com os valores de outra sequência (como uma lista). 
O seu primeiro argumento é uma lista com o tamanho de cada dimensão.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Repara como os arrays N-dimensionais são impressos com o número de dimensões.)

Também é possível criar arrays com o mesmo formato em que são impressos: 

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### Acesso aos elementos

Para aceder aos elementos de um vetor usa `aref`; os índices começam em zero. 
O número de índices fornecidos tem de corresponder ao número de dimensões do array.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
