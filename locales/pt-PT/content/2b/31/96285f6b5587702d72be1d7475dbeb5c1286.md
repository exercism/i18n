# Instruções

Neste exercício vais escrever um tipo personalizado `TreasureChest` genérico (e mágico!), para guardar algum tesouro.

## 1. Define o tipo personalizado genérico TreasureChest

Define um tipo personalizado `TreasureChest` com uma única variante.

A variante deve ter um valor `String` associado, que será usado para guardar a palavra-passe do baú do tesouro.

A variante deve também ter um valor genérico associado, que será usado para guardar o tesouro.
Este valor é genérico para que o tesouro possa ser qualquer coisa.

## 2. Define o tipo UnlockResult

Define um tipo personalizado `UnlockResult` com duas variantes.

A primeira variante deve ser `Unlocked` e deve conter um valor genérico, que será usado para guardar o tesouro.

A segunda variante deve ser `WrongPassword`, que não contém nenhum valor.

## 3. Define a função get_treasure

Esta função deve receber dois parâmetros

- um tipo personalizado genérico `TreasureChest`
- uma `String` (para tentar uma palavra-passe)

Esta função deve comparar a tentativa de palavra-passe fornecida com a `String` no `TreasureChest`.

A função deve devolver um `UnlockResult`.

Se as palavras-passe coincidirem, devolve `Unlocked` com o valor genérico do `TreasureChest` (o tesouro!)

Se as palavras-passe não coincidirem, devolve `WrongPassword`.
