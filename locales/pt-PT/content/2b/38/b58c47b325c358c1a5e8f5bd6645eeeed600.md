# Dicas

## Geral

- Revê as funções disponíveis no [módulo `NaiveDateTime`][naive-date-time], no [módulo `Date`][date] e no [módulo `Time`][time].

## 1. Interpreta as datas e horas armazenadas

- Existe uma [função incorporada][naive-date-time-from-iso8601] que interpreta uma string de data e hora no formato ISO8601 e devolve uma estrutura `NaiveDateTime`.

## 2. Determina se um livro foi requisitado antes do meio-dia

- Podes definir um literal `Time` com o [sigilo `~T`][time-sigil].
- Existe uma [função incorporada][naive-date-time-to-time] que converte uma estrutura `NaiveDateTime` numa estrutura `Time`.
- Existe uma [função incorporada][time-compare] que verifica qual de duas estruturas `Time` é maior.

## 3. Calcula a data de devolução

- Um dia tem `24 * 60 * 60` segundos.
- Existe uma [função incorporada][naive-date-time-add] que adiciona um determinado número de segundos a uma estrutura `NaiveDateTime`.
- Existe uma [função incorporada][naive-date-time-to-date] que converte uma estrutura `NaiveDateTime` numa estrutura `Date`.

## 4. Determina quão atrasada foi a devolução do livro

- Existe uma [função incorporada][naive-date-time-to-date] que converte uma estrutura `NaiveDateTime` numa estrutura `Date`.
- Existe uma [função incorporada][date-diff] que calcula a diferença em dias entre duas estruturas `Date`.

## 5. Determina se o livro foi devolvido numa segunda-feira

- Existe uma [função incorporada][naive-date-time-to-date] que converte uma estrutura `NaiveDateTime` numa estrutura `Date`.
- Existe uma [função incorporada][date-day-of-week] que devolve o dia da semana de uma determinada estrutura `Date`.

## 6. Calcula a multa por atraso

- Combina todas as funções que definiste nos passos anteriores.
