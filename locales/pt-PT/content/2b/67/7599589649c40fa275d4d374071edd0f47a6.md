# Instruções

A Elena, a nova gestora de qualidade de uma fábrica de jornais, pede-te para escreveres um pequeno programa para monitorizar a sala de produção.

## 1. Define um erro personalizado

Define uma classe de tuplo de erro `machine-error` com a palavra de análise `ERROR:`. Não precisa de slots.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. Verifica a humidade

Define `check-humidity`. Recebe uma leitura de humidade da pilha e usa `throw` para lançar a string `"humidity too high"` quando a leitura for estritamente superior a `70`. Caso contrário, não devolve nada.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. Verifica a temperatura

Define `check-temperature`. Recebe uma leitura de temperatura da pilha e usa `throw` para lançar a string `"temperature too high"` quando a leitura for estritamente superior a `500`. Caso contrário, não devolve nada.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. Monitoriza a máquina

Define `monitor` para receber uma humidade e uma temperatura da pilha e executar ambas as verificações. Se alguma das verificações lançar, `monitor` deve lançar um novo `machine-error` em vez disso. Se ambas passarem, `monitor` não devolve nada.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. Monitoriza um lote de leituras

Define `monitor-batch` para receber um array de leituras `{ humidity temperature }` e devolver quantas delas iriam falhar (ou seja, quantas fariam com que `monitor` lançasse).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
