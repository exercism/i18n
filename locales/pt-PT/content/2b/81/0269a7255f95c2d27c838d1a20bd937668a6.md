# Sobre

O Lua usa duas representações para números: números inteiros de 64 bits e números de vírgula flutuante de precisão dupla.

~~~exercism/note
Antes da versão 5.3, o Lua representava todos os números com o formato de vírgula flutuante de precisão dupla.
~~~

Os números podem ser escritos com uma parte decimal opcional, mais um expoente decimal opcional.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

Um número com um ponto decimal ou um expoente é considerado um número de vírgula flutuante; um número sem esses elementos é tratado como um número inteiro, mas ambos têm o tipo 'number'.
```lua
type(1)         --> number
type(2.0)       --> number
```

Se quisermos distinguir entre números de vírgula flutuante e números inteiros, podemos usar a função `type` do módulo `math`.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## Comparação

Números inteiros e números de vírgula flutuante com o mesmo valor são considerados iguais:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## Aritmética

O Lua suporta o conjunto habitual de operadores aritméticos: adição, subtração, multiplicação, divisão e negação. Além disso, suporta a divisão com arredondamento para baixo, o módulo e a exponenciação.

### Adição, subtração, multiplicação e negação

Se ambos os operandos forem números inteiros, o resultado da operação é um número inteiro. O mesmo se aplica aos números de vírgula flutuante.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

Se um operando for um número de vírgula flutuante, os números inteiros restantes também serão convertidos em números de vírgula flutuante e a operação resulta num número de vírgula flutuante.
```lua
1.0 + 2   --> 3.0
```

### Divisão

A divisão opera sempre com números de vírgula flutuante e dá um número de vírgula flutuante como resultado.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

Dividir por zero resulta em `inf` ou `-inf`. Dividir zero por zero resulta em `-nan`.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### Divisão com arredondamento para baixo

Se for necessário um resultado inteiro, pode usar-se a divisão com arredondamento para baixo. A divisão com arredondamento para baixo arredonda sempre o quociente em direção a menos infinito, garantindo um resultado inteiro para todos os operandos.

~~~exercism/note
Antes da versão 5.3, o Lua não tinha um operador aritmético para a divisão com arredondamento para baixo.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

A divisão com arredondamento para baixo segue as mesmas regras dos operadores de adição, subtração, multiplicação e negação: se ambos os operandos forem números inteiros, o resultado da operação é um número inteiro; caso contrário, o resultado é um número de vírgula flutuante.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

Ao dividir por zero com a divisão com arredondamento para baixo, o Lua gera um erro.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### Módulo

O módulo é usado para obter o resto da divisão de dois operandos.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### Exponenciação

Tal como a divisão, a exponenciação também opera com números de vírgula flutuante e dá números de vírgula flutuante como resultado.
```lua
10 ^ 2    --> 100.0
```

## Precedência

Todas as operações são avaliadas de acordo com a [precedência dos operadores](https://www.lua.org/manual/5.4/manual.html#3.4.8). Podem usar-se parênteses para alterar a precedência de uma expressão.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## Arredondamento

O módulo `math` fornece três funções de arredondamento: `floor` arredonda "para baixo" (em direção a menos infinito), `ceil` arredonda "para cima" (em direção a mais infinito) e `modf` arredonda em direção a zero.

### `math.floor`

`floor` arredonda em direção a menos infinito.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` arredonda em direção a mais infinito.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` arredonda em direção a zero. A função devolve o valor arredondado, bem como a parte fracionária do número, que é sempre um número de vírgula flutuante.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## Conversão

Se quisermos converter um número inteiro num número de vírgula flutuante, podemos somar-lhe `0.0`.
```lua
1 + 0.0         --> 1.0
```

Se quisermos converter um número de vírgula flutuante num número inteiro, podemos fazer-lhe um OR bit a bit com zero ou usar a função `tointeger` do módulo `math`.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

Se o número não puder ser convertido num número inteiro, o operador OR gera um erro e a função `tointeger` devolve `nil`.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## Hexadecimal

Tal como muitas outras linguagens de programação, o Lua suporta números hexadecimais ao prefixá-los com `0x`, mas, ao contrário de muitas outras linguagens de programação, o Lua também suporta números hexadecimais de vírgula flutuante. Podem ter uma parte fracionária e um expoente binário, com o prefixo 'p' ou 'P'.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
