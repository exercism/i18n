# Instalação

A única coisa de que vais precisar para correr estes exercícios é teres o [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) e o [Java 8](https://java.com/en/download/) instalados. O CommandBox CLI é compatível com Mac, Linux e Windows, e o guia de instalação está aqui:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

Um exemplo de como instalar o CommandBox CLI, caso uses o Homebrew no Mac, seria:

```bash
brew install commandbox
```

Depois de teres a CLI instalada, podes brincar com o REPL:

```bash
box repl
```

Podes executar páginas .cfm diretamente:

```bash
box exec myTest.cfm
```

E até podes iniciar um servidor web em qualquer diretório do teu disco rígido:

```bash
box server start
```

O CommandBox tem uma shell interativa que podes usar, com preenchimento automático por tabulação melhorado e que corre mais depressa. Entra nela executando o binário `box` sem argumentos.

```bash
box
```
