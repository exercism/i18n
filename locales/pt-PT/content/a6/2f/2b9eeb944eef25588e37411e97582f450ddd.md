# Sobre

O Gleam pode correr na máquina virtual Erlang (BEAM) ou em ambientes de execução JavaScript. Há muitas outras linguagens que usam estes ambientes, e é muitas vezes útil poder chamar código escrito nessas linguagens a partir do Gleam.

A funcionalidade de _funções externas_ do Gleam permite importar funções de outras linguagens para o Gleam e chamá-las sem sobrecarga de execução.

Se o teu projeto Gleam corre na máquina virtual Erlang e queres chamar a função `reverse` do módulo `lists` do Erlang, podes fazê-lo adicionando o atributo `@external` a um cabeçalho de função Gleam, assim:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Esta pode depois ser chamada como uma função Gleam normal:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Se tentares compilar este código para ambientes de execução JavaScript, vai falhar com uma mensagem de erro, pois não há implementação para JavaScript. Podes especificar outra implementação para ambientes de execução JavaScript, assim:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Também é possível escrever uma implementação em Gleam que será usada quando não houver uma implementação externa para o alvo de compilação atual:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
