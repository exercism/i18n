# Iteração

Em programação, a [iteração][iteration] refere-se ao processo de repetir um bloco de código várias vezes.
Isto pode ser feito com conceitos como os ciclos while e os ciclos until.
Também pode ser feito com recursão, que é uma função que se chama a si própria.

No entanto, na maioria das vezes queres iterar sobre uma coleção de itens, como um `Array`, um `Range` ou uma `String`.
Tanto a classe `Array` como a classe `Range` do Crystal incluem o módulo [`Enumerable`][enumerable], que fornece vários métodos para iterar sobre os elementos.
Já a classe `String` tem o seu próprio conjunto de métodos para iterar sobre os carateres.

O Crystal também não tem uma instrução for como outras linguagens.
Em vez disso, tem vários métodos que podes usar para iterar.

## Iterar

A forma mais comum de iterar sobre uma coleção é usar o método [`each`][each], que passa cada elemento da coleção a um bloco.
Isto é fácil de fazer com um `Range`.
Imagina que queres fazer um ciclo entre 1 e 3; podes usar o método `each` para iterar sobre esse intervalo.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Ainda mais simples, se quiseres apenas iterar um determinado número de vezes, podes usar o método [`times`][times], que existe na classe `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Iterar sobre uma `String`

Uma `String` é uma sequência de carateres e não pertence ao módulo `Enumerable`, o que significa que tem o seu próprio conjunto de métodos para iterar sobre os carateres.
A forma mais comum de iterar sobre uma `String` é usar o método [`each_char`][each_char], que passa cada caráter da `String` a um bloco.

~~~~exercism/note
O método `each_char` passa um objeto `Char` e não um objeto `String` ao bloco.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Outra forma de iterar sobre uma `String` é usar o método [`each_line`][each_line].
Este método é usado sobretudo para ler um ficheiro linha a linha.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Iterar sobre um objeto que inclui o módulo `Enumerable`

O módulo [`Enumerable`][enumerable] fornece vários métodos para iterar sobre os elementos de uma coleção.
As coleções que incluem o módulo `Enumerable` são `Array`, `Range`, `Hash`, `Set` e outras; estas últimas serão abordadas em conceitos posteriores.

A forma mais comum de iterar sobre um `Array` é usar o método [`each`][each], que passa cada elemento do `Array` a um bloco.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

O método [`map`][map] é outra forma de iterar sobre um `Array`; devolve um novo `Array` com os resultados de aplicar o bloco a cada elemento.
É semelhante ao método `each`, mas devolve um novo `Array` com os elementos transformados.
A transformação é muito útil quando queres aplicar uma função a cada elemento da coleção, o que é uma operação comum.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Com um fluxo de controlo como o `if`, podes filtrar quais os elementos a transformar.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## Sintaxe abreviada

No Crystal, existe uma sintaxe abreviada para iterar e aplicar um método a cada elemento de uma coleção.
Isto é útil quando trabalhas com lógica simples que só precisa de ser transformada com um único método.
Faz-se usando a sintaxe `&.` seguida do nome do método.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### Com índice

Por vezes precisas de saber o índice do elemento sobre o qual estás a iterar; para isso, podes usar o método [`each_with_index`][each_with_index] ou o [`map_with_index`][map_with_index].
Passa cada elemento e o respetivo índice a um bloco; o método também aceita um argumento opcional para especificar o índice inicial.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Repara que o método [`each_char_with_index`][each_char_with_index] também está disponível para objetos `String`.

### sum

O método [`sum`][sum] devolve a soma de todos os elementos da coleção; também aceita um bloco opcional para transformar os elementos antes de os somar.
Aceita ainda um argumento opcional para especificar o valor inicial da soma.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

O [`reduce`][reduce], ou fold como é conhecido noutras linguagens, é um método que, com um método de combinação e um valor inicial, combina todos os elementos da coleção.
O método `reduce` tem um acumulador que é passado ao bloco; o acumulador é o resultado da iteração anterior.
Isto torna-se um processo recursivo que combina todos os elementos da coleção.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

O `reduce` pode parecer semelhante ao `sum`, mas é mais flexível, porque te permite especificar o valor inicial do acumulador e o método de combinação.
O `reduce` pode ser usado para implementar o `sum`, o `count` e outros métodos.
