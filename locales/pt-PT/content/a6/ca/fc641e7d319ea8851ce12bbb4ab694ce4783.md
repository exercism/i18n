# Introdução

Os símbolos em Common Lisp são valores especiais que podem apontar para outros valores ou, no caso das palavras-chave, para si mesmas.
Quando o Lisp avalia os símbolos, estes são substituídos pelos valores para que apontam:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

Repara que as palavras-chave são precedidas de dois pontos (`:`).

O _quoting_, isto é, acrescentar `'` antes de uma S-expression, diz ao Lisp para não avaliar essa expressão.
Ao usar `'foo` no nosso exemplo com `defun`, evitámos que o Lisp tentasse procurar (e não encontrasse) aquilo para que `FOO` deveria apontar e, em vez disso, devolvesse o próprio valor `FOO`.
Se `FOO` não tiver sido definido em lado nenhum do nosso programa:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

Por agora, podes considerar isto apenas como uma forma de devolver símbolos a partir de uma função, mas vamos voltar ao _quoting_ e explorar melhor as suas implicações em futuros exercícios de conceitos.
