# Dicas

Para todas estas tarefas, vais precisar do comando `print`:
```awk
{print "something", "something else"}
```

## 1. Lista os nomes de utilizador

* Usa [a variável `FS`][var-fs] para definir o separador de campos.

## 2. Imprime os números das linhas

* Usa a [variável incorporada `NR`][var-nr] para obteres o número da linha.

## 3. Imprime os registos com diretórios pessoais inválidos.

* O diretório pessoal é o 6.º campo.
* Usa a função `startsWith` fornecida.
* Usa [operadores Boolean][boolean-ops]: `&&`, `||`, `!`.

## 4. Imprime o número de utilizadores válidos que usam bash

* O shell de início de sessão é o último campo; podes usar [a variável `NF`][var-nf].
