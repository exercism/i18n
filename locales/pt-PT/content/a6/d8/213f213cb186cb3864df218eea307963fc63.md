# Introdução

Uma propriedade em Haxe é um membro de uma classe que dá acesso aos dados dessa classe. Quem chama pode definir ou obter (get) os dados. As propriedades são compostas por um acessor set e/ou um acessor get.

As propriedades têm modificadores de acesso (public, private, etc.) tal como os outros membros da classe, mas o acessor set pode ter um nível de acesso independente do acessor get, e vice-versa. Uma propriedade não tem de ter ambos os acessores, pode ter apenas um (get ou set).

O acesso de leitura e o acesso de escrita refletem-se diretamente na sintaxe, como mostra o exemplo seguinte:

```haxe
class Main {
  public var x(default, null):Int;
}
```

Tanto `default` como `null` são **identificadores de acesso** especiais. Os identificadores de acesso definem o comportamento quando o campo é lido (primeiro identificador) e quando o campo é escrito (segundo identificador). Os valores aceites são:

- `default`: Permite o acesso normal ao campo se o campo for público.
- `null`: Permite o acesso apenas de dentro da classe que o define.
- `get/set`: O acesso é gerado como uma chamada a um método acessor (`get_x()`).
- `dynamic`: Igual a `get/set`, mas não é possível verificar a existência de um método acessor.
- `never`: Não permite acesso algum.

Aqui está um exemplo completo:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
