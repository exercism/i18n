# Introdução

## Verdadeiro e falso

Em Common Lisp, todos os valores são verdadeiros, exceto `()`, que é falso.
Existem dois símbolos constantes especiais, `t` e `nil`, cujos valores são verdadeiro e falso, respetivamente.

## Condicionais

O Common Lisp disponibiliza várias expressões condicionais diferentes, sendo a principal diferença o número de ramos que suportam.

- `when` e `unless` permitem um único ramo:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

A secção após a expressão de teste pode conter mais do que uma expressão.

- `if` disponibiliza a clássica construção if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Repara que tanto a cláusula then como a cláusula else só podem ser uma única expressão.

- `cond` disponibiliza uma forma de ter vários ramos sem aninhar expressões `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Repara que não há limite para o número de expressões após a expressão de teste. 

- `case` disponibiliza uma clássica construção ao estilo 'switch': verifica um único valor contra vários ramos:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Repara que, tal como em `cond`, não há limite para o número de expressões após a expressão de teste.
