## 1. Documenta o propósito das ferramentas de formulário

- O atributo de módulo `@moduledoc` pode ser usado para escrever a documentação de um módulo.

## 2. Documenta o preenchimento de campos com valores em branco

- O atributo de módulo `@doc` pode ser usado para escrever a documentação de uma função.
- O atributo de módulo `@spec` pode ser usado para escrever um typespec de uma função.
- Coloca os atributos `@doc` e `@spec` imediatamente antes da primeira cláusula da função que esses atributos descrevem.
- Consulta a [documentação de typespecs][typespecs-types] para veres uma lista de todos os tipos disponíveis.
- O tipo correto para strings está [definido no módulo `String`][string-t].

## 3. Documenta a divisão de valores em listas de letras maiúsculas

- O atributo de módulo `@doc` pode ser usado para escrever a documentação de uma função.
- O atributo de módulo `@spec` pode ser usado para escrever um typespec de uma função.
- Coloca os atributos `@doc` e `@spec` imediatamente antes da primeira cláusula da função que esses atributos descrevem.
- Consulta a [documentação de typespecs][typespecs-types] para veres uma lista de todos os tipos disponíveis.
- O tipo correto para strings está [definido no módulo `String`][string-t].
- Uma lista é um tipo parametrizado.

## 4. Documenta a verificação se um valor cabe num campo com um comprimento máximo

- O atributo de módulo `@doc` pode ser usado para escrever a documentação de uma função.
- O atributo de módulo `@spec` pode ser usado para escrever um typespec de uma função.
- Coloca os atributos `@doc` e `@spec` imediatamente antes da primeira cláusula da função que esses atributos descrevem.
- Consulta a [documentação de typespecs][typespecs-types] para veres uma lista de todos os tipos disponíveis.
- O tipo correto para strings está [definido no módulo `String`][string-t].
- Os valores literais podem ser usados num typespec.
- A barra vertical `|` pode ser usada para representar uma união de tipos.

## 5. Documenta os diferentes formatos de morada

- O atributo de módulo `@type` pode ser usado para definir um tipo público personalizado.
- Os tipos podem ser compostos; por exemplo, ao especificar um tipo que é um mapa, também podes especificar os tipos dos valores associados a chaves específicas.
- [O operador de tipo `::`][type-operator] também pode ser usado para antepor um nome de variável a um tipo.
- Os tipos personalizados podem ser usados para definir outros tipos personalizados.
