# Sobre

**Delphi** é uma linguagem de programação baseada em Object Pascal para desenvolvimento de software para desktop, dispositivos móveis, web e consola.
Delphi foi o [nome de código](https://edn.embarcadero.com/article/20396) de um produto ainda sem nome durante o seu desenvolvimento inicial, antes da sua estreia em 1995.

Delphi foi originalmente desenvolvida pela [Borland](https://en.wikipedia.org/wiki/Borland), liderada por Anders Heilsberg como uma ferramenta [RAD](https://en.wikipedia.org/wiki/Rapid_application_development) para Windows e como sucessora do [Turbo Pascal](https://en.wikipedia.org/wiki/Turbo_Pascal).
Delphi acrescentou orientação a objetos completa à linguagem existente e, desde então, a linguagem cresceu e passou a suportar muitas outras funcionalidades modernas, incluindo:
  
- **Genéricos**  
- **Métodos anónimos (closures)**  
- **Construtores dinâmicos (atributos)**  
- **Métodos abstratos**  
- **Tipos de string integrados**  
- **Suporte nativo de COM**  
- **RTTI**  

Tal como o seu antecessor Turbo Pascal, no centro do Delphi está um compilador de código nativo.
O Turbo Pascal proporcionava um equilíbrio ideal entre a velocidade de programação e a velocidade dos programas resultantes, a clareza da sintaxe e a potência de expressão. Estes princípios continuam a ser verdadeiros hoje no Delphi.
As versões mais recentes do Delphi conseguem compilar código nativo para várias plataformas diferentes:

- **Windows (x86 e x64)**  
- **OS X (apenas 32 bits)**  
- **iOS (32 e 64 bits)**  
- **Android**  
- **Linux (apenas 64 bits)**  

Em 2006, a divisão de ferramentas de programação da Borland foi transferida da Borland para uma subsidiária integralmente detida, conhecida como [CodeGear](https://en.wikipedia.org/wiki/CodeGear), que foi vendida à [Embarcadero Technologies](https://en.wikipedia.org/wiki/Embarcadero_Technologies) em 2008.
Em 2015, a Embarcadero foi adquirida pela Idera, mas a marca Embarcadero foi mantida para a divisão de ferramentas de programação.
