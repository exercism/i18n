# Introdução

## Igualdade

O Common Lisp tem muitos predicados de igualdade diferentes.
Isto é diferente de outras linguagens de programação, que podem ter apenas um ou dois (por exemplo, `==` e `===`).
Alguns destes predicados no Common Lisp são específicos de tipos, enquanto outros são genéricos.
São estes últimos que vamos abordar aqui.

Há quatro predicados de igualdade genéricos e diferem no grau de restrição daquilo que consideram "igual".
São, por ordem do mais restritivo para o menos restritivo: `eq`, `eql`, `equal` e `equalp`.

Um conjunto rápido de definições (omitindo alguns detalhes) é o seguinte:

- `eq`: define a igualdade como significando que os dois objetos são idênticos.
  _por exemplo_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: define a igualdade como significando dois números com o mesmo tipo e o mesmo valor, dois carateres que são iguais, ou, para qualquer outra coisa, se forem `eq`.
  _por exemplo_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: define a igualdade como significando: duas listas são `equal` se cada elemento também for `equal`; duas strings são `equal` se cada elemento for `eql`; dois arrays são `equal` se forem `eq`; tudo o resto é `equal` se for `eql`.
  _por exemplo_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: define a igualdade como significando: as strings e os carateres são comparados independentemente de serem maiúsculas ou minúsculas; os números são comparados com alguma conversão de tipo; as listas e os arrays são `equalp` se todos os elementos também forem `equalp`, as estruturas se forem do mesmo tipo e todos os slots forem `equalp`, e as hash-tables se as suas chaves e valores forem `equalp`
  _por exemplo_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
