# Break, Continue

Ao usar uma estrutura de controlo de repetição ou de iteração, as palavras-chave `break` e `continue` podem ajudar-te a controlar o fluxo de um programa.
A palavra-chave `break` sai do contexto do ciclo para o âmbito exterior, terminando assim o ciclo.
A palavra-chave `continue` ignora o resto da iteração atual e reinicia o contexto do ciclo no início da iteração seguinte.
Embora seja pouco comum, podes indicar um número a seguir à palavra-chave para controlares de quantos contextos sais ou quantas iterações avanças até à seguinte.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

No exemplo anterior, o `continue` é executado cinco (5) vezes, mas na sexta (6) iteração é executado o `break`, o que faz com que o código saia do ciclo.
