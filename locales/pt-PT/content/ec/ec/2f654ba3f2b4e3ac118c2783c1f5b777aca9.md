# Sobre

## Tipos struct

Já vimos tipos struct. Para recapitular, um `struct` é uma sequência de elementos com nome chamados _campos_, cada um com um nome e um tipo.
O nome de um campo tem de ser único dentro do struct.
`Structs` podem ser comparados com a _classe_ no paradigma da Programação Orientada a Objetos.

Crias um novo struct com as palavras-chave `type` e `struct` e depois defines explicitamente o nome e o tipo dos campos, como mostra o exemplo abaixo.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Tipos que não são structs

Também é possível definir tipos que não são structs, que podes usar como alias para declarações de tipos incorporados.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Também podes definir tipos que não são structs compostos por arrays e maps.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
