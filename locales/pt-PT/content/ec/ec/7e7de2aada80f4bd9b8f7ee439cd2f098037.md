# Números de vírgula flutuante

O `INT` só guarda números inteiros, e dividir dois deles deita fora o resto:

```sather
7 / 2        -- 3, not 3.5
```

Quando a parte fracionária importa, o tipo é `FLTD`: um número **de vírgula flutuante**, que consegue guardar valores entre os inteiros.

## Escrever um

Um literal de vírgula flutuante tem um ponto decimal e um `d` no fim.

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

O `d` não é opcional. `440.0` sozinho é um tipo diferente, com menos precisão; o `d` pede o tipo que este percurso usa em todo o lado.

Escreve `2.0d`, não `2d`: também tem de haver um ponto decimal.

## Aritmética

`+`, `-`, `*` e `/` funcionam todos, e agora o `/` mantém a parte fracionária:

```sather
7.0d / 2.0d      -- 3.5
```

Os dois lados têm de ser `FLTD`. O Sather não mistura os dois tipos em silêncio, por isso `7 / 2.0d` é um erro, e não uma surpresa.

## A partir de um número inteiro

`.fltd` transforma um `INT` num `FLTD`:

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)` é `3.5`. Repara onde vai a conversão: `(7 / 2).fltd` daria `3.0`, porque a divisão já teria deitado fora a metade. Converte **antes** de dividir, não depois.

## A que distância estão?

`.abs` deita fora o sinal de menos. É assim que perguntas a que distância estão dois valores, sem te preocupares com qual deles é maior:

```sather
(440.0d - 442.0d).abs      -- 2.0
```
