# Introdução

Lembra-te de que o `jq` suporta os mesmos tipos de dados que o JSON.
O JSON descreve as **strings** como:

> Uma string é uma sequência de zero ou mais carateres Unicode, entre aspas duplas, com recurso a sequências de escape de barra invertida.

## Sequências de escape

Dentro de uma string, usa o caráter de barra invertida para introduzir carateres «especiais»:

- `\"` uma aspa literal,
- `\\` uma barra invertida literal,
- carateres de espaço em branco `\n`, `\t`, `\r`, `\f`, `\b`
- carateres Unicode `\uAAAA`, em que `A` é um algarismo hexadecimal

## Comprimento de uma string

Para saberes o número de carateres, usa a função `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## Substrings

Podes usar a notação **slice** para extrair substrings.
A sintaxe é `.[i:j]`.
A substring devolvida tem comprimento `j - i`, devolvendo carateres desde o índice `i` (inclusive) até ao índice `j` (exclusive).
Qualquer um dos índices pode ser negativo, contando nesse caso de trás para a frente a partir do fim da string.
Qualquer um dos índices pode ser omitido, referindo-se nesse caso ao início ou ao fim da string.
Os índices começam em zero.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## Concatenação

Usa `+` para juntar strings:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Usa `add` quando tens um array de strings:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## Dividir e juntar

Para dividir, usa a função `split/1` ou o operador `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

O inverso de `split/1` é `join/1`.

Converter uma string num array de carateres é algo de que precisas muitas vezes.
Há duas formas de o fazer:

1. dividir numa string vazia

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` num array de _codepoints_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` é o inverso de `explode`.

## Encontrar o índice de uma substring

Usa a função `index/1`; o índice começa em zero.

```jq
"hello" | index("el")'   # => 1
```

Se a substring não existir na string, o resultado é `null`

```jq
"hello" | index("elk")   # => null
```

## Interpolação de strings

Dentro de uma string, a sequência `\(expression)` incorpora o _resultado_ dessa expressão [na string][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## Conversão de maiúsculas e minúsculas

Usa as funções `ascii_downcase` e `ascii_upcase`.

O `jq` tem um grande suporte para expressões regulares: será o tema de uma aula mais adiante.
