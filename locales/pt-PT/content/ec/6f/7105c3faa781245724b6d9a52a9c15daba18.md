# Introdução

## Mapas

Os mapas em Elixir são a estrutura de dados para guardar informação em pares chave-valor. Noutras linguagens, também podem ser conhecidos como arrays associativos (PHP), hashes (Perl 5, Raku) ou dicionários (Python).

As chaves e os valores podem ser de qualquer tipo de dados, mas se a chave for um átomo podemos usar uma sintaxe abreviada. Os mapas não garantem a ordem das suas entradas quando são acedidos ou devolvidos.

### Formas literais

Um mapa vazio declara-se simplesmente com `%{}`. Se quisermos adicionar itens a um mapa literal, podemos usar duas formas:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Embora não exista um formato canónico, escolhe uma forma consistente de representar os pares chave-valor literais.

### Funções do módulo Map

O Elixir disponibiliza muitas funções para trabalhar com mapas no _módulo Map_. Algumas funções do _módulo Map_ exigem que lhes seja passada uma função _anónima_ para ajudar na transformação do mapa.

## Atributos de módulo como constantes

Em Elixir, podemos definir atributos de módulo que podem ser usados como constantes nas nossas funções.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Quando são usados para definir constantes de módulo, os atributos podem ser qualquer expressão que possa ser avaliada em tempo de compilação. Depois da compilação, os atributos de módulo já não estão acessíveis, uma vez que são expandidos durante a compilação, à semelhança das macros definidas em linguagens como C.
