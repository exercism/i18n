# Introdução

Um dicionário é uma coleção de elementos em que cada elemento é composto por uma chave e um valor, de tal forma que, se passares uma chave a um método do dicionário, o valor associado é devolvido. Tem o mesmo papel que os mapas ou arrays associativos têm noutras linguagens.

Podes criar um dicionário da seguinte forma:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Ou

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Repara que os tipos da chave e do valor fazem parte da definição do dicionário.

Depois de construído, podes adicionar ou remover entradas de um dicionário com os seus métodos incorporados `Add` e `Remove`.

Podes obter ou atualizar valores num dicionário ao indexares o dicionário com uma chave:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Podes testar se um valor existe no dicionário com:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Ao iterar sobre um dicionário, enumeras os seus pares chave/valor. Os dicionários também têm propriedades que te permitem enumerar as suas chaves ou os seus valores.
