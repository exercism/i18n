# Dicas

## 1. Retira uma carta de um baralho

- Os índices de `Vector` começam em `1`.
- Podes obter o `n`-ésimo valor num vetor `v` com `v[n]`.

## 2. Troca uma carta no baralho

- Os `Vector` são mutáveis, podes alterar o seu conteúdo a qualquer momento.
- O método recebe um [Pair](https://docs.julialang.org/en/v1/base/collections/#Base.Pair) como argumento.
- Podes aceder aos campos de um par `p` com `p.first` e `p.second`.

## 3. Insere uma carta no topo do baralho

- Existe um método [`push!`](https://docs.julialang.org/en/v1/base/collections/#Base.push!) em Base para adicionar um novo valor ao fim de uma coleção.

## 4. Remove uma carta do baralho

- Existe um método [`deleteat!`](https://docs.julialang.org/en/v1/base/collections/#Base.deleteat!) em Base para eliminar um elemento de um `Vector` num determinado índice.

## 5. Remove a carta do topo do baralho

- Existe um método [`pop!`](https://docs.julialang.org/en/v1/base/collections/#Base.pop!) em Base para remover um elemento no fim de uma coleção.

## 6. Insere uma carta no fundo do baralho

- Existe um método [`pushfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.pushfirst!) em Base para inserir um novo valor no início de uma coleção.

## 7. Remove uma carta do fundo do baralho

- Existe um método [`popfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.popfirst!) em Base para remover um elemento no início de uma coleção.

## 8. Verifica o tamanho do baralho

- Existe um método [`length`](https://docs.julialang.org/en/v1/base/collections/#Base.length) em Base para obter o comprimento de uma coleção.
