# Testes

Cada exercício contém um ficheiro de testes.
Corre os testes com o programa `bats`.

```bash
bats hello_world.bats
```

Se precisares de imprimir saída de depuração enquanto corres os testes localmente, consulta [Depuração local][debugging].

O `bats` tem de ser instalado.
Consulta a página [Testes no percurso de Bash][tests] para instruções sobre como instalar o `bats` no teu sistema.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Testes ignorados

Resolver um exercício significa fazer passar todos os seus testes.
Por predefinição, só um teste (o primeiro) é executado quando corres os testes.
Isto é intencional: assim, podes concentrar-te apenas em fazer passar esse único teste.
Assim que ele passar, podes ativar o teste seguinte comentando ou removendo a anotação seguinte:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Anular os skips

Para correr todos os testes, incluindo os que têm anotações `skip`, podes correr:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Pode ser cómodo usar uma função wrapper para escreveres menos:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Depois, basta correr os testes com:

```bash
bats
```
