# Sobre

Os condicionais de Factor recebem todos **quotations** como ramos: código escrito entre parênteses retos, `[ ... ]`, que é empilhado como valor em vez de ser executado, e que só corre quando o condicional o seleciona. (As próprias quotations são explicadas em detalhe num exercício mais à frente.)

Os três básicos estão em `kernel`:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

Duas variantes com asterisco tratam o Boolean como um valor que vale a pena usar quando é verdadeiro. É o par canónico «valor ou `f`»:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

Para mais de dois ramos, o `cond` (em `combinators`) percorre um array de pares `{ predicate body }` e executa o corpo do primeiro predicado que se verifica. O padrão habitual usa `dup` em cada predicado, para que o valor de entrada sobreviva, e o corpo começa com um `drop` para o descartar antes de empilhar o resultado:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

Uma entrada final sem predicado é o ramo por omissão.
