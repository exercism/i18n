# usa uma guarda ao nível da função

[comment]: # (Este erro é apresentado quando a solução usa guardas, mas não na cláusula da função)

Usa [guardas](https://hexdocs.pm/elixir/master/guards.html) na cláusula da função para impedir que `two_fer/1` execute código com valores de entrada que não sejam binários.

```elixir
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

Quando uma função é chamada com argumentos que não correspondem a nenhuma das cláusulas indicadas, é lançado um `FunctionClauseError`.

```elixir
hello(123)

# => ** (FunctionClauseError) no function clause matching in hello/1
#
#    The following arguments were given to Foo.hello/1:
#
#    # 1
#    123
```
