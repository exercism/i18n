# Sobre

Para executar lógica repetidamente, podes usar ciclos. Se o código dentro de um ciclo tiver de ser executado sempre pelo menos uma vez, podes usar um ciclo `do`/`while`:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

Usa-se com menos frequência do que um ciclo `while`, mas em alguns casos o resultado é código com um aspeto mais natural.
