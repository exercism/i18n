# Introdução

Como muitas linguagens, o Common Lisp inclui números inteiros.
São números inteiros sem parte decimal (como `-6`, `0`, `25`, `1234`, etc.).

O Common Lisp não define limites para a magnitude dos números inteiros.
Os números inteiros podem ser arbitrariamente grandes (ou pequenos, se forem negativos).

Em geral, se estiveres a trabalhar apenas com números inteiros, deves preferi-los, pois não sofrem a mesma perda de precisão que os números de vírgula flutuante ao longo de muitos cálculos.
