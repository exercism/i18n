# Sobre

O Dart combina a programação orientada a objetos e a tipagem estática com a flexibilidade de linguagens dinâmicas como o JavaScript.
Concebido para simplificar tarefas comuns de programação, o Dart ganhou rapidamente popularidade na comunidade de desenvolvimento de software, sobretudo graças à sua estreita integração com o [Flutter](https://flutter.dev), um framework amplamente utilizado para o desenvolvimento multiplataforma.

## Conceitos fundamentais do Dart

- **Simples e familiar:** O Dart é fácil de aprender para programadores que já conhecem linguagens como Java, JavaScript ou C#.
  Tem uma sintaxe limpa e consistente, o que o torna acessível.
- **Linguagem orientada a objetos moderna:** O Dart incorpora princípios modernos de orientação a objetos, oferecendo um suporte sólido para classes, herança e interfaces.
- **Tipagem forte com flexibilidade:** Embora o Dart seja uma linguagem de tipagem estática, oferece inferência de tipos flexível e funcionalidades dinâmicas, dando aos programadores o melhor dos dois mundos.
- **Programação assíncrona simplificada:** As palavras-chave `async` e `await` do Dart simplificam a concorrência.
  O modelo orientado a eventos, construído em torno de **isolates** (estruturas leves semelhantes a threads), permite uma execução assíncrona eficiente sem recorrer a threading complexo.
- **Ferramentas e bibliotecas abrangentes:** O Dart oferece bibliotecas incorporadas extensas, e o seu ecossistema é reforçado pelo [Pub.dev](https://pub.dev), um gestor de pacotes que disponibiliza uma vasta gama de bibliotecas e ferramentas de código aberto.
- **Desenvolvimento multiplataforma:** O Dart está por trás do [Flutter](https://flutter.dev), um dos frameworks mais populares para criar aplicações móveis, web e de desktop de alto desempenho e multiplataforma a partir de uma única base de código.
- **Suporte para a web:** O código Dart pode ser transpilado para JavaScript, o que o torna adequado tanto para o desenvolvimento web do lado do cliente como do lado do servidor.
  Frameworks como o [AngularDart](https://github.com/angulardart-community) (anteriormente [https://github.com/angulardart](https://github.com/angulardart)) são concebidos especificamente para aplicações web em Dart.
- **Capacidades do lado do servidor:** O Dart não serve apenas para o desenvolvimento de frontend; também pode ser usado para criar aplicações do lado do servidor escaláveis com frameworks como o [Shelf](https://pub.dev/packages/shelf).
- **Alto desempenho:** O código Dart é compilado para código de máquina nativo nas aplicações móveis e de desktop, e para JavaScript otimizado na web, proporcionando um alto desempenho em todas as plataformas.

## Versatilidade do Dart

- **Aplicações móveis:** A utilização mais destacada do Dart é no desenvolvimento de aplicações móveis através do Flutter, permitindo uma interface de utilizador e uma lógica de negócio consistentes em iOS e Android.
- **Desenvolvimento web:** O Dart pode ser compilado para JavaScript para criar aplicações web modernas, seja através de frameworks nativos do Dart, seja através do Flutter para web.
- **Desenvolvimento para desktop:** Com o Flutter, o Dart suporta agora a criação de aplicações nativas para Windows, macOS e Linux, oferecendo verdadeiras capacidades multiplataforma.
- **Serviços de back-end:** O Dart é cada vez mais utilizado em serviços de back-end graças à sua sintaxe concisa e às suas otimizações de desempenho.
  Consegue lidar com APIs RESTful, microsserviços e muito mais.
- **Integração com o Firebase e a nuvem:** O Dart tem um suporte sólido para a integração com o Firebase e outros serviços na nuvem através de bibliotecas oficiais, o que o torna uma escolha preferida para aplicações ligadas à nuvem.

## Melhorias recentes

- **Segurança contra nulos:** O Dart introduziu a **segurança contra nulos sólida**, que ajuda a eliminar erros de referência nula ao garantir que os tipos não anuláveis são usados corretamente durante o desenvolvimento.
- **Compilação mais rápida:** O Dart deu passos importantes na melhoria do seu processo de compilação, oferecendo tanto a compilação **ahead-of-time (AOT)** como a **just-in-time (JIT)**, o que garante ciclos de desenvolvimento rápidos e compilações de lançamento otimizadas.
- **Desktop e dispositivos embebidos:** A expansão do Flutter para o desktop e para plataformas embebidas tornou o Dart mais versátil do que nunca, permitindo aos programadores criar aplicações para uma vasta gama de dispositivos para além do móvel e da web.

O ecossistema em crescimento do Dart, o forte apoio aos programadores e as suas capacidades multiplataforma fazem dele uma escolha atrativa para o desenvolvimento de aplicações modernas.
