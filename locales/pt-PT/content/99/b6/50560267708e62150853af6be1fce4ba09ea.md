# Instalação

Usa o binário `full` da tua plataforma, disponível em [a página oficial de lançamentos][official-releases].
De momento, o percurso tem como alvo a versão 0.10.0 Arizona Bark do Arturo.

~~~~exercism/caution
O Homebrew é um método popular de terceiros para instalar software nas plataformas macOS e Linux.
No entanto, a sua receita para o Arturo tem como alvo a compilação `mini`, que é incompatível com este percurso.
~~~~

Se precisares de mais ajuda para instalar o Arturo, consulta o [Discord oficial do Arturo][discord].

## Executar código Arturo

A partir daí, já podes começar a escrever código Arturo!
Para acederes ao REPL do Arturo, corre `arturo` na linha de comandos.
Para executares um script do Arturo, corre `arturo <file>` na linha de comandos.
