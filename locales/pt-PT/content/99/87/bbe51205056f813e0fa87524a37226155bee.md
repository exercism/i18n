# Instalar o Kotlin

Além da CLI do Exercism e do teu editor de texto preferido, para praticar com os exercícios de Kotlin no Exercism precisas de

* o **Java Development Kit** (JDK): o Kotlin compila para bytecodes Java, por isso precisas de instalar o JDK, que inclui tanto um Java Runtime *como* ferramentas de desenvolvimento (a mais importante das quais é o compilador Java); e
* o **Gradle**: uma ferramenta de compilação especificamente para projetos baseados na JVM e que suporta Kotlin.

Escolhe o teu sistema operativo:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... ou ...
* se preferires não usar um gestor de pacotes, podes [instalar manualmente](#h-install-manually).

Opcionalmente, também podes usar uma [IDE Java](#h-java-ides).

----

## Windows

Abre uma linha de comandos com privilégios de administrador.  (Se precisares de ajuda para abrir uma linha de comandos administrativa, consulta [abrir uma linha de comandos elevada no Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (ou [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Se ainda não tens o Chocolatey instalado, instala-o agora:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Instala o JDK:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

Recomendamos que feches a linha de comandos administrativa e abras uma nova linha de comandos. Não precisas de privilégios de administrador para praticar os exercícios do Exercism.

Já estás pronto para começar com a track de Kotlin do Exercism!

Para começar, consulta "[Correr os testes](https://exercism.org/docs/tracks/kotlin/tests)".

## macOS

Em baixo estão as instruções para instalar usando o método mais comum: com o Homebrew.  Se preferires, também podes [instalar no macOS sem o Homebrew](#h-installing-on-macos-without-homebrew).

### Instalar

1. Se ainda não instalaste o [Homebrew](http://brew.sh), fá-lo agora:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Faz `tap` do [Homebrew Cask](https://caskroom.github.io/), o que nos permite instalar binários já compilados, como o JDK.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Instala o JDK:

       ```
        $ brew install --cask adoptopenjdk11
       ```

Já estás pronto para começar com a track de Kotlin do Exercism!

Para começar, consulta "[Correr os testes](https://exercism.org/docs/tracks/kotlin/tests)".

## Linux

Em baixo estão as instruções para instalar usando o gestor de pacotes da tua distribuição.  Se preferires, também podes [instalar no Linux sem um gestor de pacotes](#h-installing-on-linux-without-a-package-manager).

* [Debian](#h-debian)
* [Outras distribuições Linux](#h-other-linux-distributions)

### Debian

Se usas Debian ou uma das suas derivadas (como Ubuntu ou Linux Mint), usa o APT:

*(verificado em: Ubuntu 14, 16 e 18)*

1. Instala o JDK:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


Já estás pronto para começar com a track de Kotlin do Exercism!

Para começar, consulta "[Correr os testes](https://exercism.org/docs/tracks/kotlin/tests)".

### Outras distribuições Linux

Há muitas formas de instalar o JDK 11, mas uma das mais fáceis é usar o SDKMAN, que te permite instalar o OpenJDK 11 sem complicações. Segue estes passos:

1. Instala o SDKMAN:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (se não funcionar, dá uma vista de olhos nas instruções que encontras aqui: https://sdkman.io/install )
1. Instala o openjdk11:
    ```
    $ sdk install java 11.0.2-open
    ```

### Instalar no Windows manualmente

*NOTA: estas instruções destinam-se a utilizadores experientes do Windows.  Se ainda não sabes definir variáveis de ambiente ou não te sentes à vontade a gerir a estrutura de diretórios, recomendamos vivamente que uses a instalação com o Chocolatey, [acima](#h-windows).*

1. Instala o JDK:
   1. Descarrega o "**OpenJDK 11 (LTS)**" do [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) (escolhe **"Install JDK"**).
   -  Executa o instalador, mantendo todas as opções predefinidas.

Já estás pronto para começar com a track de Kotlin do Exercism!

Para começar, consulta "[Correr os testes](https://exercism.org/docs/tracks/kotlin/tests)".

## IDEs Java

Há muitas IDEs Java disponíveis.  As três mais populares são:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (descarrega a edição "Community")
  - criada pelos autores do Kotlin, esta IDE oferece o melhor suporte para a linguagem.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) (descarrega o pacote "Java SE")

e há [outras](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs).
