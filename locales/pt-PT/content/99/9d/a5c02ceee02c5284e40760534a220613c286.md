# Sobre

O JavaScript é uma linguagem de programação que permite tornar as páginas web dinâmicas. É uma linguagem interpretada, o que significa que não precisa de ser compilada: em vez disso, o intérprete (como um navegador web) analisa o código e transforma-o em código que a máquina consegue executar. É por isso ideal para criar sites dinâmicos que funcionam em qualquer navegador _em qualquer computador_!

O JavaScript não é usado apenas no navegador. Ambientes de execução de JavaScript, como o [Node.js][web-nodejs] e o [Deno][web-deno], permitem-te escrever, lançar e servir pedidos em servidores web.
Outros frameworks, como o [Electron][web-electron], usam JavaScript para escrever _aplicações multiplataforma_ para Windows, Linux e macOS.
O desenvolvimento de aplicações móveis também é uma possibilidade, recorrendo ao [React Native][web-react-native], ao [Ionic][web-ionic] e a vários outros, com o [Expo][web-expo] a permitir agora visar o Android, o iOS e a web, tudo de uma só vez.

O ECMAScript é a [norma][web-ecma] que define o JavaScript.

> "O ECMAScript tornou-se numa das linguagens de programação de uso geral mais amplamente utilizadas no mundo.
> É sobretudo conhecido como a linguagem incorporada nos navegadores web, mas também foi amplamente adotado em aplicações de servidor e em sistemas embebidos."
> Fonte: [ECMA International Language Specification][web-ecma-2019]

A partir da 6.ª edição (conhecida habitualmente como ES2015 ou ES6), lançada em 2015, é publicada uma nova edição da norma todos os anos.
A 6.ª edição foi uma atualização importante que trouxe muitas melhorias em relação ao ES5, incluindo, em particular, template strings, uma sintaxe expressiva de funções arrow e uma sintaxe mais limpa para definir classes.

Mas, como todos os anos chegam ao JavaScript _novas sintaxes e funcionalidades_, o suporte para estas mudanças é muitas vezes incompleto nos [navegadores atuais][web-compat-browsers] e [na versão mais recente do Node.js][web-compat-node].
Isto não quer dizer que não as possamos usar.
Ferramentas como o [Babel][web-babel] oferecem [transpilação][wiki-transpilation] para a maioria das funcionalidades, o que nos permite _escrever_ como se já estivéssemos no futuro.

**Nota**: Este track suporta a sintaxe ECMAScript mais recente através do Babel e do plugin [@babel/preset-env][web-babel-preset-env], e as novas funcionalidades experimentais são ativadas a cada atualização desse plugin, acompanhando o lançamento das especificações.
Adapta-se automaticamente à _tua instalação local de Node.js_.
Isto significa que não precisas de te preocupar com o que é e não é suportado.
