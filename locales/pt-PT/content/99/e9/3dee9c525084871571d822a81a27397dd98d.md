# Instruções

Um pirata está a traçar uma rota através de um mapa de enseadas escondidas. O mapa é uma tabela de hash indexada pelo nome da enseada; cada valor é um array das enseadas a que podes chegar diretamente a partir dessa.

## 1. Esvaziar a fila da maré

Define `tide-queue` de modo a receber um array de itens, inserir cada um numa deque nova (por ordem) e depois retirá-los todos de volta para um array que mantém a ordem original. Esta é a forma FIFO: acrescenta-se ao fim, retira-se do início.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. Enseadas alcançáveis

Define `coves-reachable` para receber uma enseada de partida e um mapa, e devolver um hash-set de todas as enseadas alcançáveis a partir de `start`, incluindo a própria `start`.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

Usa um `<dlist>` como fronteira da BFS e um `HS{ }` para o conjunto dos visitados.

## 3. Contagem de saltos

Define `hop-count` para receber uma enseada de partida, uma enseada de destino e um mapa, e devolver o número mínimo de saltos entre elas, ou `f` se não for possível alcançar o destino.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

Guarda cada enseada juntamente com a sua distância à partida na deque (um array de dois elementos serve).

## 4. Contagem de ouro

O stub declara `gold-count` com `:`. Muda-o para `MEMO:` (e não `:`) para que o resultado de cada enseada seja calculado uma só vez e fique em cache. Procura o ouro da enseada na constante `gold-distribution` que o exercício fornece. Uma enseada que não esteja na distribuição tem zero de ouro.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. Rota do tesouro

Define `treasure-route` para receber uma enseada de partida e um mapa, e devolver a enseada alcançável com mais ouro. Usa `coves-reachable` da tarefa 2 e `gold-count` da tarefa 4.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

O `gold-count` memorizado mantém gratuitas as consultas repetidas, o que é útil quando várias partes do algoritmo consultam a mesma enseada.
