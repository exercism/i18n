# Instruções

Nota: Este exercício é uma continuação do exercício `need-for-speed`.

Neste exercício vais organizar corridas entre vários tipos de carros telecomandados.
Cada carro tem as suas próprias características de velocidade e de consumo de bateria.

Os carros começam com a bateria cheia (100%).
Cada vez que conduzes o carro com o telecomando, ele percorre em metros uma distância igual à velocidade do carro e a percentagem de bateria restante diminui no valor do seu consumo de bateria.

Se a bateria de um carro estiver abaixo da percentagem do seu consumo de bateria, já não podes conduzir o carro.

O carro telecomandado tem um ecrã LED sofisticado que mostra duas informações:

- A distância total percorrida, apresentada como: `"Driven <METERS> meters"`.
- A carga restante da bateria, apresentada como: `"Battery at <PERCENTAGE>%"`.

Cada pista tem a sua própria distância.
Os carros são testados verificando se conseguem terminar a pista sem ficar sem bateria.

## 1. Conduz o carro

Implementa o método `Drive` no `Car`, que atualiza o número de metros percorridos com base na velocidade do carro e reduz a bateria de acordo com o consumo de bateria:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

Nota: Não deves tentar conduzir o carro se isso fizer com que a bateria do carro fique abaixo de 0.

## 2. Mostra a distância percorrida

Implementa um método `DisplayDistance` no `Car` para devolver a distância tal como é apresentada no ecrã LED, como `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. Mostra a percentagem da bateria

Implementa o método `DisplayBattery` no `Car` para devolver a percentagem da bateria tal como é apresentada no ecrã LED, como `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. Verifica se um carro telecomandado consegue terminar uma corrida

Para terminar uma corrida, um carro tem de conseguir percorrer a distância da corrida.
Isto significa não ficar sem bateria antes de cruzar a linha de chegada.
Implementa o método `CanFinish`, que recebe um `trackDistance int` como parâmetro e devolve `true` se o carro conseguir terminar a corrida; caso contrário, devolve `false`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
