# Resolver exercícios localmente

Resolver exercícios na tua máquina permite-te programar num ambiente que conheces bem.

## Instalar a CLI

Para resolveres um exercício na tua máquina, tens primeiro de instalar e configurar a Interface de Linha de Comandos do Exercism, seguindo [estas instruções](https://exercism.org/cli-walkthrough).

### Configuração

Tens de dizer à CLI quem és, para que possamos descarregar as coisas corretamente.
Encontras o teu token na tua [página de definições](/settings/api_cli).
Depois, podes configurar a CLI com o seguinte comando, substituindo `<your-api-token>` pelo valor da página de definições:

```
exercism configure --token=<your-api-token>
```

## Descarregar o exercício

Depois de a instalares, podes usar a CLI para descarregar o exercício para a tua máquina com o seguinte comando (substituindo `<exercise-slug>` e `<track-slug>` pelos valores correspondentes:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

Não tens de decorar esta estrutura de comando, porque a página do exercício indica o comando adequado para esse exercício.

Quando o comando de download terminar, os ficheiros do exercício ficam descarregados na tua máquina.

## Resolver o exercício

O objetivo de cada exercício é criar uma implementação que passe todos os testes.
A essa implementação chama-se _solução_.

Para te ajudar nisso, cada exercício contém os seguintes ficheiros:

- README.md: as instruções que explicam o que se espera de ti
- HELP.md: informações sobre como correr os testes e como obter ajuda quando ficares preso
- HINTS.md (opcional): dicas para te ajudar a resolver o exercício
- Ficheiro(s) de teste: contêm os testes que verificam se a tua solução está correta
- Ficheiro(s) de esboço: fornecem um ponto de partida para começares a construir a tua implementação

Consoante o percurso, pode haver outros ficheiros que as ferramentas do percurso exigem para os testes correrem.

## Submeter a tua solução

Quando a tua solução passar todos os testes, podes submetê-la com o seguinte comando:

```
exercism submit <implementation_file_paths>
```

Este comando carrega a tua solução para o site do Exercism e imprime o URL da página da solução.

Mais uma vez, não tens de decorar este comando, porque o ficheiro `HELP.md` do exercício indica o comando correto.

Podes submeter uma solução incompleta, o que te permite:

- Ver como outras pessoas resolveram o exercício
- Pedir ajuda a um mentor

## Outras funcionalidades da CLI

### Ver todos os comandos

Executa o subcomando help para obteres a lista completa dos comandos disponíveis.

```bash
exercism help
```

### Resolução de problemas

Certifica-te de que tens a versão mais recente.

Verifica que versão tens:

```bash
exercism version
```

Compara com a versão mais recente e atualiza se a tua não for a mais recente.

Depois de atualizares, confirma novamente a versão. Se a versão não mudou, certifica-te de que estás a executar o binário atualizado.

```bash
which exercism
```

Se continuares com problemas, abre uma issue no repositório exercism/cli no GitHub com o resultado do comando troubleshoot.

```bash
exercism troubleshoot
```

Podes abrir issues no [nosso repositório de issues](https://github.com/exercism/exercism/issues) e a comunidade tentará ajudar-te. **Certifica-te de que completaste o [Tutorial Interativo](https://exercism.org/cli-walkthrough) antes de abrires qualquer issue.**
