# Sobre

As bibliotecas de classes base do .NET fornecem a classe [`Regex`][regex] para processar expressões regulares.

Vê este [artigo][regex-comparison] para uma comparação do C# com outras variantes de expressões regulares.

## Grupos de captura

Um aspeto a ter em conta é o dos grupos de captura, que devolvem partes do texto que correspondem a várias partes do padrão da expressão regular. A forma de lidar com os grupos de captura exige alguma habituação. Vê esta [documentação][capture].

Repara que existe uma hierarquia em que os grupos de captura, `(?<capture-name>pattern)`, estão envolvidos:

- são devolvidas zero ou mais correspondências (uma por cada correspondência encontrada no texto).
- Cada correspondência contém um certo número de grupos de captura
- Cada grupo contém um certo número de capturas.

Além disso:

- `Match` deriva de `Group`
- `Group` deriva de `Capture`

Ressalvas:

- A abordagem mais segura é usar capturas com nome.
- Em geral, os grupos de captura aparecem na coleção `Groups` pela mesma ordem em que aparecem no texto.
- `Groups[0]` parece corresponder à correspondência completa.
- `Groups[<capture name>].Value` é quase de certeza o que te interessa. As capturas individuais (para além de `Caputures[0]`) parecem destinar-se a fins de diagnóstico, se estiverem presentes.

## Opções de Regex

Familiariza-te com [`RegexOptions`][regex-options].

Para além das habituais opções `IgnoreCase`, existem opções como `MultiLine`, útil para processar várias linhas de texto de uma só vez, e `IgnorePatternWhitespace`, que, em conjunto com strings verbatim, interpolação de strings e comentários, pode ser muito expressiva, como mostra este exemplo:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

Outra opção que vale a pena conhecer é `RegexOptions.Compiled`, para expressões regulares [compiladas][regex-compilation].
