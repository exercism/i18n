# Anexo às instruções

## Dica

Uma função com um *tipo de retorno* só pode devolver dados desse *tipo* e `null`.
No entanto, quem chama a função só está à espera de um tipo de dados.

Exemplo:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
Para deixar mais claro que esta função também pode devolver `null` ou mais tipos de dados, usa `dynamic`.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
