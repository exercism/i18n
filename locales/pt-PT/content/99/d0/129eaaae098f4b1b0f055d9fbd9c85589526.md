# Instruções

O teu amigo Linus é maquinista de comboios de mercadorias que circulam entre cidades.
Embora seja fantástico a conduzir comboios, não é tão bom a lidar com logística ou computadores.
Gostaria de contar com a tua ajuda em programação para organizar os detalhes dos comboios e corrigir erros nos dados das rotas.

~~~~exercism/note
Este exercício poderia ser facilmente resolvido com fatiamento, indexação e vários métodos de `dict`.
No entanto, gostaríamos que praticasses empacotamento, desempacotamento e atribuição múltipla ao resolveres cada uma das tarefas abaixo.
~~~~

## 1. Cria uma lista de todos os vagões

O teu amigo tem andado a registar o identificador (ID) de cada vagão, mas nunca sabe quantos vagões o sistema vai ter de processar em cada momento. Seria muito mais fácil para o resto do programa de logística ter estes dados agrupados num único `list`.

Implementa uma função `get_list_of_wagons()` que aceita um número arbitrário de IDs de vagões.
Cada ID será um número inteiro positivo.
A função deve depois `return` os IDs recebidos como uma única `list`.

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. Corrige a lista de vagões

A esta altura, já estás a começar a perceber os dados e a forma como são usados no programa de logística.
O sistema de IDs atribui sempre à locomotiva o ID **1**, e aos restantes vagões do comboio um ID escolhido aleatoriamente maior do que **1**.

O teu amigo teve de ligar dois vagões novos ao comboio e esqueceu-se de atualizar o sistema!
Agora, os dois primeiros vagões da `list` do comboio têm de ser movidos para o fim, ou tudo ficará fora de ordem.

Para complicar mais as coisas, o teu amigo acabou de descobrir uma segunda `list` que parece conter IDs de vagões em falta.
Do que se lembra é que, depois de os vagões novos serem movidos, os IDs desta segunda `list` devem ser colocados imediatamente a seguir à locomotiva designada.

O Linus ficaria muito grato se corrigisses os seus erros e consolidasses os dados.

Implementa uma função `fix_list_of_wagons()` que recebe duas `lists` com IDs de vagões.
Deve reposicionar os dois primeiros itens da primeira `list` para o fim e inserir os valores da segunda `list` atrás (_do lado direito_) do ID da locomotiva (**1**).
A função deve depois `return` uma `list` com as modificações.

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Adiciona as paragens em falta

Agora que todos os dados dos vagões estão corretos, o Linus gostaria que atualizasses as informações de encaminhamento do sistema.
Ao longo de uma rota de transporte, um comboio pode fazer paragens em algumas estações diferentes para recolher e/ou deixar carga.
Cada viagem pode ter um número diferente destes pontos de entrega intermédios.
O teu amigo gostaria que atualizasses o `dict` de encaminhamento do sistema com quaisquer informações de entrega em falta ou adicionais.

Implementa uma função `add_missing_stops()` que aceita um `dict` de encaminhamento seguido de um número variável de argumentos de palavra-chave.
Estes argumentos podem ter a forma de um `dict` com uma ou mais paragens, ou de qualquer número de pares de palavra-chave `stop_number=city`.
A tua função deve depois devolver o `dict` de encaminhamento atualizado com uma `key` adicional que contém uma `list` com todas as paragens adicionadas, por ordem.

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. Amplia as informações de encaminhamento

O Linus tem andado a trabalhar no programa de encaminhamento e reparou que faltam alguns detalhes importantes em certas rotas.
As informações iniciais da rota foram construídas como um `dict` e o teu amigo gostaria que atualizasses esse `dict` com o que estiver em falta.
Cada rota do sistema exige detalhes ligeiramente diferentes, por isso o Linus preferiria mesmo uma solução genérica.

Implementa uma função chamada `extend_route_information()` que aceita dois `dicts`.
O primeiro `dict` contém as cidades de origem e de destino entre as quais circula a rota do comboio.

O segundo `dict` contém outros detalhes de encaminhamento, como a velocidade, o comprimento ou a temperatura do comboio.
A função deve devolver um `dict` consolidado com todas as informações de encaminhamento.

~~~~exercism/note
O segundo `dict` pode conter propriedades diferentes ou mais do que as mostradas no exemplo.
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. Corrige o depósito de vagões

Quando o Linus estava a inspecionar o depósito de vagões, reparou que os vagões não estavam a ser guardados na ordem correta.
Além de um ID, cada vagão tem uma cor que corresponde ao tipo de carga que transporta.
Os vagões são guardados no depósito em grelhas, em que cada coluna da grelha tem vagões da mesma cor.

No entanto, o sistema de logística mostra que as `lists` de vagões a guardar no depósito têm as suas _linhas_ agrupadas por cor.
Mas para a grelha de armazenamento funcionar corretamente, cada _linha_ deve ter três cores diferentes, para que as _colunas_ se alinhem por cor.
O teu amigo gostaria que organizasses as `lists` do depósito de vagões, para que os vagões sejam guardados corretamente.

Implementa uma função chamada `fix_wagon_depot()` que aceita uma `list` de três itens.
Cada item da `list` é uma sublista (ou "linha") que contém três `tuples`.
Cada `tuple` é um par `(<wagon ID>, <wagon color>)`.

A tua função deve devolver uma `list` com as três `lists` de "linha" reordenadas, de modo a colocar os vagões nas posições corretas.

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
