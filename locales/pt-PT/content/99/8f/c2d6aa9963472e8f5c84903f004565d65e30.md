# Dicas

## 1. Cria um conjunto de strings úteis

- As [strings][strings-and-characters] são definidas como literais ao colocar zero ou mais carateres entre aspas duplas (`"`).

## 2. Cria um conjunto de carateres úteis

- Os [carateres][strings-and-characters] são definidos como literais ao colocar exatamente um caráter entre aspas duplas (`"`).
- Os carateres definidos como literais têm de receber explicitamente uma anotação de tipo `Character` para impedir que o compilador os interprete como strings.

## 3. Combina frases para construir mensagens

- As strings podem ser concatenadas com [o operador de string adequado][string-docs].
- Os carateres não podem ser concatenados com strings.
  Primeiro, têm de ser convertidos em strings.

## 4. Constrói um cartaz de finalista

- A [interpolação de strings][string-interpolation] faz-se colocando a expressão cujo valor queres incluir na string entre parênteses precedidos de uma barra invertida.

## 5. Calcula o custo de um cartaz

- O Swift tem [uma propriedade de string][string-count-docs] que devolve o número de carateres numa string.
