# Instruções

Os elétricos de Melbourne cobram por zona e o centro da cidade é gratuito. Estás a escrever as regras das tarifas para a máquina de bilhetes. Todas as tarifas são em cêntimos.

As quatro tarefas ficam na classe `TRAM_FARES`.

## 1. A tarifa de uma zona

A zona 0 é a Zona Gratuita de Elétricos e não custa nada. A zona 1 custa 550. A zona 2 custa 370. Qualquer outro número não é sequer uma zona de elétricos e não custa nada.

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. Que tipo de bilhete?

Os bilhetes têm uma letra. `'f'` é uma tarifa normal. Tanto `'c'` como `'s'` são tarifas reduzidas, uma para crianças e outra para estudantes. `'x'` é um passe gratuito. Qualquer outra letra é desconhecida.

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

As quatro respostas são `"Full fare"`, `"Concession"`, `"Free pass"` e `"Unknown"`.

## 3. Que tipo de dia?

`"Sat"` e `"Sun"` são fim de semana. `"Mon"` a `"Fri"` são dias de semana. Qualquer outro valor é desconhecido.

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

As três respostas são `"Weekend"`, `"Weekday"` e `"Unknown"`.

## 4. O limite diário

Independentemente de quantos elétricos apanhes, nunca pagas mais do que o limite desse dia: 1100 num dia de semana e 700 ao fim de semana. Um dia que ninguém reconhece não tem limite, ou seja, é zero.

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
