# Instruções

A namorada do Lucian está a caminho de casa e ele ainda não preparou o jantar de aniversário deles!

Neste exercício, vais escrever algum código para ajudar o Lucian a cozinhar uma lasanha requintada do seu livro de receitas preferido.

Tens quatro tarefas, todas relacionadas com o tempo gasto a cozinhar a lasanha.

## 1. Define o tempo esperado no forno em minutos

Define o método `Lasagna.ExpectedMinutesInOven()` que não recebe parâmetros e devolve quantos minutos a lasanha deve estar no forno. Segundo o livro de receitas, o tempo esperado no forno em minutos é 40:

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. Calcula o tempo restante no forno em minutos

Define o método `Lasagna.RemainingMinutesInOven()` que recebe como parâmetro os minutos reais que a lasanha já esteve no forno e devolve quantos minutos a lasanha ainda tem de permanecer no forno, com base no tempo esperado no forno em minutos da tarefa anterior.

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. Calcula o tempo de preparação em minutos

Define o método `Lasagna.PreparationTimeInMinutes()` que recebe como parâmetro o número de camadas que adicionaste à lasanha e devolve quantos minutos gastaste a preparar a lasanha, partindo do princípio de que cada camada demora 2 minutos a preparar.

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. Calcula o tempo decorrido em minutos

Define o método `Lasagna.ElapsedTimeInMinutes()` que recebe dois parâmetros: o primeiro parâmetro é o número de camadas que adicionaste à lasanha e o segundo parâmetro é o número de minutos que a lasanha esteve no forno. A função deve devolver quantos minutos trabalhaste a cozinhar a lasanha, ou seja, a soma do tempo de preparação em minutos com o tempo em minutos que a lasanha passou no forno até ao momento.

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
