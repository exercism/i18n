# Noções básicas de sintaxe de Elm 2

## Exportar funções

A exportação de funções foi abordada no primeiro conceito. Aqui fica uma revisão rápida.

Cada ficheiro em Elm é um módulo e tem de conter uma instrução `module` antes de qualquer outro código.

Os nomes dos módulos têm de corresponder ao nome do ficheiro, por isso o módulo `Calculator` tem de estar no ficheiro Calculator.elm, e o módulo `Parser.Utils` tem de estar no ficheiro Parser/Utils.elm.

Tudo o que é definido dentro de um módulo tem âmbito privado desse módulo e não pode ser acedido de fora dele, a menos que seja listado em `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Importar funções de outros módulos

O acesso a funções definidas noutros módulos faz-se através de importações.
Todas as funções desse módulo que foram expostas por ele ficam acessíveis quando importas esse módulo.
Mas a forma como são acedidas varia consoante o modo como o módulo é importado.

As importações qualificadas são o padrão, e para aceder a uma função dentro desse módulo (por exemplo, a função `map` do módulo `List`) usa-se o prefixo com o nome do módulo (`List.map`).

As importações abertas permitem aceder diretamente às funções expostas desse módulo, sem prefixo. Fazem-se com a palavra-chave `exposing`, à imagem da que é usada nas exportações. Podes expor todas as funções disponíveis (com `..`) ou apenas algumas específicas (por exemplo, `map`).

Também podes importar tipos e os respetivos construtores de outros módulos, o que é um conceito que vais ver mais à frente.

As importações qualificadas são preferíveis para maior clareza e para evitar conflitos de nomes.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Anotações de tipo

As anotações de tipo definem-se com `name : parameter types -> return type`, sendo os tipos dos parâmetros também separados por `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Os parênteses podem ser usados para definir parâmetros de função (que são eles próprios definidos com a mesma sintaxe, daí a necessidade dos parênteses).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Números

Em Elm, existem dois tipos de números, definidos pelos tipos `Int` e `Float`.
`Int` corresponde ao conjunto dos números inteiros positivos e negativos.
`Float` corresponde ao conjunto dos números reais, limitado pela precisão do computador.
As operações definidas sobre números costumam funcionar com um tipo ou com o outro, mas não com ambos misturados.
Existem funções para converter entre os dois, como `toFloat`, que converte `Int` em `Float`, e `round`, `floor`, `ceiling` ou `truncate`, que convertem um `Float` num `Int` com semânticas diferentes.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Operações com strings

Para descrever palavras e frases em código, Elm tem um tipo `String` nativo.
Os literais de string escrevem-se entre aspas duplas, como `"Hello World!"`.
Um operador de concatenação de strings `++` e um operador de igualdade `==` estão disponíveis por predefinição.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

A maioria das outras funções de string está no módulo `String`, que é preciso importar.

https://package.elm-lang.org/packages/elm/core/latest/String
