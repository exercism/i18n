# Dicas

## Geral

- O vocabulário `locals` disponibiliza `::` e `[| | ]`.
- Os locals não substituem o código da pilha. Usa-os onde acrescentam
  clareza.

## 1. Determina o estado da cozedura

- O `cond` de [`combinators`][combinators] tem a forma certa: um ramo
  verifica `dup not` (o temporizador é `f`), outro verifica
  `dup zero?`, e um ramo por omissão trata do resto. Cada ramo deve
  fazer `drop` do temporizador antes de empilhar a string.

## 2. Estima o tempo de preparação

- `:: preparation-time ( layers minutes-per-layer -- total )`
  com `layers length minutes-per-layer *`.

## 3. Calcula as massas e o molho necessários

- Os locals permitem-te referir `layers` duas vezes sem `dup`. O `count`
  com o predicado `[ "noodles" = ]` (ou `"sauce" =`) dá-te
  a contagem de cada camada.
- `1/5` é um literal racional do Factor.

## 4. Adiciona o ingrediente secreto

- O `last` (em [`sequences`][sequences]) lê o último elemento;
  o `suffix` acrescenta um ao fim.

## 5. Escala a receita

- O fator de escala é `portions / 2`. Os locals permitem-te referir
  `portions` dentro do lambda.
- O `assoc-map` de [`assocs`][assocs] recebe uma quotation `( key value -- newkey newvalue )`.
  Dentro de `[| key value | … ]`, devolve ambos os valores para manteres
  a mesma chave e produzires um novo valor.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
