# Instruções

Um amigo teu acabou de te enviar uma mensagem com um segredo importante. Para não facilitar a vida a quem a quisesse ler, a mensagem foi encriptada através de uma série de manipulações de bits. Vais ter de escrever as palavras que ajudam a desencriptar a mensagem.

## 1. Deslocar os bits para trás

O primeiro passo para desencriptar a mensagem é desfazer o deslocamento feito no processo de encriptação, deslocando os bits de volta para a direita. Os passos seguintes assumem que são inseridos zeros à esquerda.

Define `shift-back`, que recebe um valor de 32 bits e uma quantidade, e devolve o valor deslocado para a direita essa quantidade de bits, com preenchimento de zeros.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. Colocar alguns bits a 1

A seguir, há alguns bits que têm de ser colocados a 1.

Define `set-bits`, que recebe um valor e uma máscara. Todos os bits de `value` em que o bit correspondente de `mask` é 1 devem ser colocados a 1; todos os outros bits ficam inalterados.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. Inverter bits específicos

Alguns bits são invertidos durante a encriptação. Vão ter de ser invertidos de novo para desencriptar a mensagem.

Define `flip-bits`, que recebe um valor e uma máscara. Todos os bits de `value` em que o bit correspondente de `mask` é 1 devem ser invertidos; todos os outros bits ficam inalterados.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. Limpar bits específicos

Por fim, há também certos bits que são sempre desencriptados para 0.

Define `clear-bits`, que recebe um valor e uma máscara. Todos os bits de `value` em que o bit correspondente de `mask` é 1 devem ser colocados a 0; todos os outros bits ficam inalterados.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
