# Introdução

Disponível a partir do `PHP 8.0.0`, as **declarações de tipo união** aceitam valores de vários tipos diferentes, em vez de um único tipo. As definições de tipo união são feitas com a barra vertical (`|`) para separar os tipos.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

O PHP lança um `TypeError` em modo estrito se os parâmetros recebidos não forem um `float` nem um `int`. Em modo não estrito, é lançado um erro de tipo se os parâmetros recebidos não puderem ser convertidos num `float` ou num `int`.

Da mesma forma, se a função não devolver um dos tipos declarados, o PHP lança um `TypeError` em tempo de execução.
