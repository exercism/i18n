# Instruções

Neste exercício vais processar linhas de log.

Cada linha de log é uma string com o seguinte formato: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tens três tarefas, cada uma recebe uma linha de log e pede-te para fazer algo com ela.

Podes usar à vontade tanto funções legacy do R base como a biblioteca `stringr`, e ambas permitem soluções curtas e viáveis.

## 1. Obter a mensagem de uma linha de log

Implementa a função `message` para devolver a mensagem de uma linha de log:

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

Qualquer espaço em branco no início ou no fim deve ser removido:

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. Obter o nível de log de uma linha de log

Implementa a função `log_level` para devolver o nível de log de uma linha de log, que deve ser devolvido em minúsculas:

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. Reformatar uma linha de log

Implementa a função `reformat` que reformata a linha de log, colocando a mensagem primeiro e o nível de log a seguir, entre parênteses:

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
