# Boolean

Algumas perguntas têm apenas duas respostas: sim ou não. Em Sather, o tipo para uma resposta destas é `BOOL`, e as duas respostas escrevem-se `true` e `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Comparar

Comparar dois números dá um `BOOL`.

| Operador | Pergunta |
| --- | --- |
| `=` | são iguais? |
| `/=` | são diferentes? |
| `<` | o da esquerda é menor? |
| `<=` | menor, ou igual? |
| `>` | o da esquerda é maior? |
| `>=` | maior, ou igual? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Repara que `=` faz uma pergunta. Colocar um valor *dentro* de algo é `:=`, que já viste, e os dois não são a mesma coisa.

## Combinar

Há três operadores que constroem perguntas maiores a partir de outras mais pequenas.

`and` é verdadeiro quando **ambos** os lados são verdadeiros.

```sather
harness_on and rope_checked
```

`or` é verdadeiro quando **pelo menos um** dos lados é verdadeiro, ou ambos.

```sather
mat_below or net_below
```

`~` inverte uma resposta: transforma verdadeiro em falso e falso em verdadeiro.

```sather
~ready       -- true exactly when ready is false
```

`and` e `or` ficam entre duas respostas; `~` fica à frente de uma.
