# Introdução

O tipo `Result` permite que uma função devolva um único valor que indica tudo o seguinte:
- Se a operação foi bem-sucedida ou falhou
- Em caso de sucesso, o valor resultante da operação
- Em caso de falha, o motivo da falha

## Utilização

O tipo `Result` é um tipo genérico que contém dois tipos subjacentes:
- O tipo do valor resultante numa operação bem-sucedida
- O tipo de erro numa falha

O tipo `Result` é também uma [união discriminada][discriminated-union] com os seguintes casos possíveis:
* `Ok <value>` que representa um resultado bem-sucedido
* `Error <reason>` que representa uma falha

A seguinte função demonstra como criar um valor do tipo `Result`:

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

Neste exemplo, o valor `Ok` é uma string (o nome fornecido) e o valor `Error` é também uma string (a causa do erro, em formato legível para humanos).

## Ler o conteúdo de um valor do tipo `Result`

Considera a seguinte definição de tipo e assinatura de função:

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

O código que chama a função `openFile` pode usar correspondência de padrões para tratar os casos de sucesso e de falha, como no exemplo seguinte:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
