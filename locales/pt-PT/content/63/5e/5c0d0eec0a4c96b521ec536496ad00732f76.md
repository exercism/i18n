# Instruções

Estás a manter um guia de campo: um mapa que liga o nome de um animal ao habitat onde ele vive.

As cinco tarefas ficam na classe `FIELD_GUIDE`.

## 1. Está no guia?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. Onde vive?

Devolve o habitat registado para um animal. Se o guia nunca tiver ouvido falar dele, devolve `"Unknown"`.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. Adiciona uma entrada

Devolve o guia com mais um animal. Se um animal já estiver listado, o habitat dele é substituído.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

Aquilo que isto devolver é o guia a usar a partir daí. Adicionar a um guia completamente vazio funciona e dá um guia com um animal.

## 4. Quantos animais?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. Que habitats?

Devolve o conjunto de habitats que o guia menciona. Vários animais podem partilhar um habitat, e este deve aparecer uma só vez.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
