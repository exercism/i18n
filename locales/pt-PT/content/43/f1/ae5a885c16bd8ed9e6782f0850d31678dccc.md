# Instruções

Neste exercício, vais implementar uma forma de acompanhar as pontuações máximas do jogo mais popular do salão de jogos da tua zona.

Tens 7 funções para implementar, todas relacionadas com devolver e manipular um dicionário de dados de pontuações máximas.

## 1. Define um novo dicionário de pontuações máximas

Cria uma função `newScoreBoard()` que não recebe parâmetros e devolve um novo dicionário de pontuações máximas que usa valores do tipo `String` para as chaves e valores do tipo `Int` para os valores.

## 2. Adiciona jogadores ao dicionário de pontuações máximas

Para adicionares um jogador ao dicionário de pontuações máximas, define `addPlayer(_:_:_:)`, que é uma função que recebe 3 parâmetros:

- O primeiro parâmetro é o dicionário de pontuações.
    Este deve ser um parâmetro de entrada e saída.
- O segundo parâmetro é o nome de um jogador, como string.
- O terceiro parâmetro é a pontuação, como número inteiro.
    O parâmetro é opcional, por isso implementa o terceiro parâmetro com um valor predefinido de 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Remove jogadores do dicionário de pontuações

Para removeres um jogador do dicionário de pontuações máximas, define `removePlayer(_:_:)`, que recebe 2 parâmetros:

- O primeiro parâmetro é o dicionário de pontuações.
    Este deve ser um parâmetro de entrada e saída.
- O segundo parâmetro é o nome do jogador, como string.

Esta função deve remover o jogador do dicionário, se ele lá estiver, e não fazer nada caso contrário.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Reinicia a pontuação de um jogador

Para reiniciares a pontuação de um jogador, define `resetPlayer(_:_:)`, que recebe 2 parâmetros:

- O primeiro parâmetro é o dicionário de pontuações.
    Este deve ser um parâmetro de entrada e saída.
- O segundo parâmetro é o nome do jogador cuja pontuação queres reiniciar, como string.

A função coloca a pontuação do jogador a 0.
Se o jogador não estiver no dicionário, não deve acontecer nada.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Atualiza a pontuação de um jogador

Para atualizares a pontuação de um jogador somando-a à pontuação anterior, define `updateScore`, que recebe 3 parâmetros:

- O primeiro parâmetro é o dicionário de pontuações. Este deve ser um parâmetro de entrada e saída.
- O segundo parâmetro é o nome do jogador cuja pontuação queres atualizar, como string.
- O terceiro parâmetro é a pontuação que queres **somar** à pontuação máxima guardada.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Obtém uma lista de jogadores com as pontuações ordenadas pelo nome do jogador

Define a função `orderByPlayers`, que recebe 1 parâmetro:

- O primeiro parâmetro é o dicionário de pontuações.

A função devolve um array de tuplos `(String, Int)` com os jogadores e as respetivas pontuações máximas, ordenados por ordem crescente do nome do jogador.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Obtém uma lista de jogadores ordenada pela pontuação, por ordem decrescente

Para obteres uma lista de jogadores ordenada pelas pontuações por ordem decrescente, define `orderByScores`, que recebe 1 parâmetro:

- O primeiro parâmetro é o dicionário de pontuações.

A função devolve um array de tuplos `(String, Int)` com os jogadores e as respetivas pontuações máximas, ordenados por ordem decrescente da pontuação do jogador.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
