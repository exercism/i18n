# Strings

Crystal tem um tipo chamado [`String`][strings], que serve para representar texto.
As strings de Crystal são sequências de carateres Unicode.
As strings são imutáveis, ou seja, não podem ser alteradas depois de criadas.
Isto significa que é criada uma nova string sempre que modificas uma string; por isso, a string original não é alterada.

Para definir uma string, usas aspas duplas `"`.

```crystal
"Hello World"
```

## Concatenação

Para concatenar duas strings, usa o operador `+`.
O operador `+` devolve uma nova string que combina as duas strings.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Conversão entre strings e números

O método `to_i` converte uma string num número inteiro.
Em alternativa, o método `to_f` pode ser usado para devolver um número de vírgula flutuante.
Se a string não puder ser convertida num número, é lançado um `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Um número inteiro ou de vírgula flutuante pode ser convertido numa string com o método `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpolação

A interpolação é uma forma prática de combinar strings e de incorporar expressões em strings.
Para interpolar uma string, podes usar o caráter `#` seguido de chavetas `{}`, com a expressão dentro das chavetas.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal converte automaticamente o resultado da expressão numa string.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Tamanho

Quando precisas de saber o número de carateres de uma string, podes usar o método `size`, que devolve o comprimento da string como número inteiro.
O tamanho de uma string é uma propriedade armazenada da string, por isso não é preciso calculá-lo sempre que chamas o método, o que torna o método muito rápido.

```crystal
"Hello World".size
# => 11
```

## Indexação

A indexação permite-te obter um caráter específico de uma string.
Para obteres um caráter de uma `String`, podes usar a conhecida notação de parênteses retos.

~~~~exercism/note
`[]` está implementado como um método de instância de String, em que o índice é o argumento do método.
~~~~

Em Crystal, o primeiro caráter de uma string está no índice 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Para obteres um caráter do fim de uma string, podes usar o comprimento da string menos um para chegares ao índice do último caráter; para o penúltimo caráter, usas o comprimento da string menos dois, e assim sucessivamente.
Há um atalho para isto: basta usares um índice negativo, em que o último caráter está no índice -1, o penúltimo está no índice -2, e assim sucessivamente.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

## Sequências de escape

Alguns carateres não podem ser escritos diretamente numa string; para isso, tens de usar uma sequência de escape.
Por exemplo, se quiseres usar aspas duplas numa string, tens de as escapar.
Podes usar o caráter `\` para escrever uma sequência de escape seguida do caráter que queres escapar.

Estes são os carateres especiais em Crystal:

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | Alerta                        |
| `\b`     | Retrocesso                    |
| `\e`     | Escape                        |
| `\f`     | Avanço de página              |
| `\n`     | Avanço de linha ou nova linha |
| `\r`     | Retorno de carro              |
| `\t`     | Tabulação horizontal          |
| `\v`     | Tabulação vertical            |
| `\\`     | Barra invertida               |
| `\'`     | Aspas simples                 |
| `\"`     | Aspas duplas                  |
| `\377`   | Caráter ASCII octal           |
| `\xFF`   | Caráter ASCII hexadecimal     |
| `\uFFFF` | Caráter Unicode hexadecimal   |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Strings com várias linhas

Para escreveres uma string com várias linhas, usas a mesma sintaxe de uma string de uma só linha, mas mudas de linha a cada linha que queres incluir na string.

```crystal
"Hello
World"
# => "Hello\nWorld"
```
