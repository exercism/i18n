# Instalação

## Instalar o Godot Engine

O track de GDScript é construído sobre o [Godot Engine][godot-engine], que funciona em Windows, Linux, macOS e Android.
De momento, o test runner para [trabalhar localmente][working-locally] requer Linux.
Este track requer o Godot versão 4.0 ou superior.

Depois de concluíres a instalação, podes verificar se o CLI foi instalado com sucesso ao executar este comando num terminal:

```bash
godot --version
```

## Instalar o test runner do track GDScript do Exercism

Precisas de ter o [Godot instalado][installation] corretamente para usares o test runner.

Para compilar e testar scripts GDScript para o Exercism, o Godot é executado em modo "headless" a partir do CLI.
De momento, estas instruções requerem Linux e bash.

### Passo 1: Instalar a infraestrutura geral do test runner

Para preparar os testes, clona [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] e move o seu conteúdo para `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Passo 2: Descarregar o script do test runner de um único exercício

Partindo do princípio de que tens a ferramenta `exercism` configurada e que já descarregaste pelo menos um exercício de GDScript, esta deverá ter criado uma pasta `gdscript` no teu espaço de trabalho (tal como é mostrado ao executar `exercism configure`) para guardar os exercícios.
Guarda [o test runner][test-local-gdscript-solution] nesta pasta e marca o ficheiro como executável.

## Executar os testes

Com os passos de instalação concluídos, deves conseguir partir de qualquer diretório de exercício (por exemplo, `~/exercism/gdscript/two-fer`) e executar o script (que se encontra um nível acima, em `../`) para testar a tua solução local desse exercício:

```sh
../test-local-gdscript-solution.sh
```

[gdscript-test-runner]: https://github.com/exercism/gdscript-test-runner

## Usar um IDE

Para teres realce de sintaxe de GDScript num editor como o [Visual Studio Code][vscode], precisas de ter instalada uma extensão como [godot-tools][godot-tools] e um servidor de depuração em execução.
O Godot inicia este servidor de depuração automaticamente sempre que um projeto está aberto no seu próprio editor e mantém-no a correr até o projeto ou o próprio Godot serem fechados.
