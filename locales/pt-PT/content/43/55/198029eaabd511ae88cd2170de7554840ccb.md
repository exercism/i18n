# Anexo às instruções

## Registos

| Registo | Utilização | Tipo    | Descrição                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | parâmetro de entrada        | endereço | string de nome terminada em nulo   |
| `$a1`    | parâmetro de entrada        | inteiro | número                        |
| `$a2`    | parâmetro de entrada/saída | endereço | string de resultado terminada em nulo |
| `$t0-9`  | temporário    | qualquer     | para armazenamento temporário         |
