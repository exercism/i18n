## Novos conceitos de AWK

Consulta as [instruções do exercício `matrix`][ex-matrix] para revêres algumas funcionalidades interessantes da linguagem GNU awk.

### Invocação dinâmica de funções

As funções awk não são objetos de primeira classe: não podem ser passadas como valores, ao contrário do que acontece nalgumas outras linguagens.
No entanto, uma variável pode conter o _nome_ de uma função (uma string), e a função é invocada recorrendo a uma notação especial `@varname(args)`.
Um exemplo:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
Isto está descrito em [Chamadas indiretas de funções][indirect].
Isto é uma extensão do `gawk`.
