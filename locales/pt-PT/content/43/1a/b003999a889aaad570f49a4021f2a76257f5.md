# Testes

Se tiveres o binário do 8th no teu path, escreve o comando:

```bash
8th -f test.8th
```

Se o binário do 8th não estiver no PATH, no Windows escreve

```cmd
\path\to\8th -f test.8th
```

Linux ou macOS:

```bash
/path/to/8th -f test.8th
```

## Testar no REPL

Inicia o 8th, carregando test-words.8th: 

```sh
8th -f test-words.8th
```

Isto inicia uma sessão de CLI onde, depois de escreveres algum código no ficheiro da tua solução, o podes carregar no REPL.
Por exemplo, para o exercício "word-count", escreverias:

```8th
"word-count.8th" f:include
```

E podes correr os testes com 
```sh
"word-count-tests.8th" f:include
```

Ou podes copiar e colar um único teste desse ficheiro ou escrever o teu. 

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem.
Por predefinição, só um teste (o primeiro) é executado quando corres os testes.
Isto é intencional, já que te permite concentrares-te apenas em fazer esse teste passar.
Depois de passar, podes ativar o teste seguinte movendo a palavra `SKIP-REST-OF-TESTS` para depois dele.

## Anular a omissão de testes

Para correr todos os testes, incluindo os que vêm depois da palavra `SKIP-REST-OF-TESTS`, podes definir a variável de ambiente `RUN_ALL_TESTS` com o valor `true`. 
Uma forma de o definir apenas durante a execução dos testes é (macOS e Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
