# Dicas

## 1. Cria um novo quadro de pontuações máximas

- Cria um novo objeto com chavetas.
- Escreve a chave como string para que esta possa conter espaços.
- Separa a chave do valor com dois pontos.

## 2. Adiciona jogadores a um quadro de pontuações

- Usa a notação de parênteses retos para adicionar uma chave cujo nome está guardado numa variável (o argumento).
- Usa o operador de atribuição (`=`) para definir um valor para a nova chave.
- Devolve o parâmetro do quadro de pontuações depois de teres adicionado o jogador.

## 3. Remove jogadores de um quadro de pontuações

- Usa o [operador delete][mdn-delete].
- Faz referência à chave tal como fizeste na tarefa anterior (notação de parênteses retos).

## 4. Aumenta a pontuação de um jogador

- Primeiro, pensa em como expressar o novo valor que queres atribuir.
- Depois, usa o operador de atribuição como na tarefa 2 para definir esse novo valor.
- Se ainda não o fizeste, podes usar o [operador de atribuição abreviado][mdn-shorthand-assignment] `+=`.

## 5. Aplica os pontos de bónus de segunda-feira

- Usa um ciclo `for...in` para percorrer todas as chaves do objeto.
- Para cada chave, define o novo valor como fizeste na tarefa 4.
