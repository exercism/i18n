# Introdução

Os métodos de extensão permitem adicionar métodos a tipos existentes sem criar um novo tipo derivado, recompilar ou modificar de qualquer outra forma o tipo original. São definidos como métodos estáticos, mas são chamados com a sintaxe de um método de instância. O primeiro parâmetro é precedido pelo modificador `this` e especifica em que tipo o método atua, e são trazidos para o âmbito ao nível do espaço de nomes.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
