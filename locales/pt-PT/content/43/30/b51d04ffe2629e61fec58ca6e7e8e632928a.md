# Instruções

Uma escola local perto de ti tem uma associação de estudantes muito ativa.
A associação de estudantes é gerida por um presidente e, a cada 2 anos, realizam-se eleições para eleger um novo presidente.
Nas eleições deste ano, decidiu-se que era necessário um novo sistema digital para contar os votos.

A escola precisa da tua ajuda para construir este novo sistema.

## 1. Cria um contador de votos

Uma das primeiras coisas de que o novo sistema de votação precisa é de um contador de votos.
Este contador é uma forma de acompanhar os votos que um determinado candidato tem.

Cria uma função `new_vote_counter` que aceita o número de votos iniciais de um candidato e devolve um snapshot de uma struct `VoteCounter`, inicializada com o número de votos iniciais indicado.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. Obter o número de votos de um contador

Agora já tens uma forma de criar novos contadores!
Mas agora reparas que o novo sistema também vai precisar de uma forma de obter o número de votos de um contador.

Cria uma função `vote_count` que recebe um contador (`@VoteCounter`) como argumento e devolve o número de votos do contador.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. Incrementar os votos de um contador

Chegou finalmente a hora de contar os votos!
Agora precisas de uma forma de incrementar os votos de um contador.

Cria uma função `increment_vote_count` que recebe um contador (`@VoteCounter`) como argumento e um número de votos, e incrementa o contador com esse número de votos.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. Criar os resultados das eleições

Com todos os votos contados, é hora de preparar o anúncio dos resultados para toda a escola.
Para isso, reparas que ter apenas contadores para os votos é insuficiente.
É preciso haver uma forma de associar o número de votos a um determinado candidato.

Cria uma função `new_election_result` que recebe o nome de um candidato e o seu número de votos e devolve um novo resultado eleitoral.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

A struct do resultado eleitoral já está criada para ti e está definida como:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. Anunciar os resultados

É hora de anunciar o novo presidente à escola!
O presidente será anunciado nos pequenos painéis de mensagens digitais que a escola tem.

A mensagem deve mostrar o nome do novo presidente e os votos que teve, no seguinte formato: `<candidate_name> (<votes>)`.
Este é um exemplo dessa mensagem: `"Peter (51)"`.

Cria uma função `display_result` que recebe um `@ElectionResult` como argumento e devolve um `ByteArray` com a mensagem a apresentar.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. Recontagem dos votos

Para garantir que os resultados finais estavam corretos, os votos foram recontados.
Na recontagem, verificou-se que o número de votos de alguns candidatos estava errado por uma unidade.

Cria uma função `decrement_votes_of_candidate` que recebe os resultados finais e o nome de um candidato cuja contagem de votos deves decrementar.
Os resultados finais são dados sob a forma de um `Felt252Dict<u32>`, em que as chaves são os nomes dos candidatos e os valores são o total de votos de cada um.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
