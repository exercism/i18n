# Apêndice às instruções

## Comparação de desempenho

Se estás a resolver este exercício localmente, há um ficheiro incluído, `parallel_letter_frequency_benchmark_test.rb`, que compara a tua solução paralela com uma sequencial.
Podes executá-lo com `ruby parallel_letter_frequency_benchmark_test.rb`.
O resultado apresenta, em formato de tabela, os tempos de execução de cada implementação para várias quantidades de textos grandes.
Altera os casos de teste à vontade.
Talvez queiras investigar que impacto tem o comprimento do texto versus o número de textos no tempo de execução de cada implementação.

**Nota:** Com conjuntos de texto mais pequenos, a contagem sequencial _pode_ ser mais rápida devido aos custos de processamento adicionais.
