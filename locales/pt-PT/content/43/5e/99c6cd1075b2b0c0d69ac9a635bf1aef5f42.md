# Ponteiros inteligentes

Os ponteiros inteligentes em Cairo são uma ferramenta poderosa que proporciona uma gestão segura e eficiente da memória.

Um ponteiro inteligente é uma estrutura de dados que se comporta como um ponteiro normal, mas com funcionalidades de segurança adicionais para evitar problemas comuns de gestão de memória, como desreferenciar ponteiros nulos ou aceder a memória não inicializada.

## O que é um ponteiro inteligente?

Em geral, um ponteiro é uma variável que guarda um endereço de memória, normalmente a apontar para um valor guardado nesse local.

No entanto, os ponteiros brutos podem ser perigosos: se o ponteiro não apontar para memória válida ou for desreferenciado incorretamente, pode dar origem a falhas ou a um comportamento imprevisível.

Os ponteiros inteligentes resolvem este problema ao impor regras rigorosas de gestão de memória, garantindo que o acesso à memória é feito de forma segura e controlada.

Cairo, tal como muitas linguagens modernas como Rust, usa ponteiros inteligentes para evitar acessos inseguros à memória.

Um ponteiro inteligente em Cairo não só guarda um endereço de memória, como também monitoriza a propriedade e garante a segurança da memória.

## Tipos de ponteiros inteligentes em Cairo

Cairo disponibiliza vários tipos de ponteiros inteligentes, incluindo `Box<T>` e `Nullable<T>`, cada um com um propósito diferente.

Vamos ver com mais atenção como funcionam estes tipos e quando podes usá-los.

### `Box<T>`

O tipo `Box<T>` é o principal ponteiro inteligente em Cairo.

Permite-te guardar dados num segmento de memória especial chamado «boxed segment». Um `Box<T>` é um ponteiro que aponta para este segmento e, quando crias uma box, alocas espaço para os dados nesse segmento.

As boxes são ideais nas situações em que:

- Precisas de guardar um valor de um tipo cujo tamanho não pode ser determinado em tempo de compilação.
- Tens uma grande quantidade de dados e queres transferir a propriedade sem os copiar.

Ao usar uma box, consegues guardar estruturas de dados grandes de forma mais eficiente.

Quando passas um `Box<T>` a uma função, só o ponteiro é passado, evitando a necessidade de copiar todos os dados, o que melhora o desempenho, sobretudo com estruturas grandes.

### `Nullable<T>`

O tipo `Nullable<T>` é outro ponteiro inteligente importante em Cairo.

Pode apontar para um valor válido do tipo `T` ou ser `null` se não houver valor.

Este tipo é útil nos casos em que precisas de guardar valores que podem não existir sempre, como num dicionário que pode conter elementos opcionais.

Em Cairo, `Nullable<T>` é normalmente usado em dicionários para tratar casos em que não é possível aplicar um valor predefinido.

Permite-te guardar valores de forma condicional, o que facilita o tratamento seguro da ausência de dados.

## Segurança da memória com ponteiros inteligentes

Uma das principais vantagens de usar ponteiros inteligentes é que ajudam a garantir a segurança da memória.

Ao gerir a propriedade e as regras de acesso, Cairo evita problemas comuns como desreferenciar ponteiros nulos ou pendentes.

Os ponteiros inteligentes detetam quando os dados já não são necessários e podem libertar automaticamente a memória quando esta sai do âmbito, reduzindo o risco de fugas de memória.

### Exemplo: usar um `Box<T>` para tipos recursivos

Um desafio comum em muitas linguagens de programação é lidar com tipos recursivos.

Os tipos recursivos são tipos que contêm referências a si próprios.

Sem uma gestão de memória adequada, definir um tipo recursivo pode dar origem a problemas como a recursão infinita.

Em Cairo, o `Box<T>` torna possível definir tipos recursivos em segurança.

Por exemplo, podes usar `Box<T>` para implementar uma árvore binária, em que cada nó contém uma referência a outro nó.

Ao guardar referências em boxes, Cairo garante que o uso de memória é finito e o compilador consegue determinar o tamanho de memória necessário para a estrutura.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### Vantagens dos ponteiros inteligentes em termos de desempenho

Os ponteiros inteligentes também melhoram o desempenho dos teus programas.

Quando usas `Box<T>`, só o ponteiro para os dados é passado de um lado para o outro, em vez de se copiar toda a estrutura de dados.

Isto é especialmente útil quando se trabalha com grandes conjuntos de dados, pois reduz significativamente a sobrecarga das operações de memória.

No exemplo seguinte, os dados são passados por referência com um `Box<T>`, para evitar o custo de copiar toda a estrutura:

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

Neste exemplo, `pass_pointer` recebe um `Box<Cart>` em vez de um `Cart`, reduzindo a quantidade de memória copiada durante a chamada à função.
