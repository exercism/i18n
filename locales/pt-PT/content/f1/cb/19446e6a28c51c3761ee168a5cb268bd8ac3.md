# Introdução

Em contraste com muitas outras linguagens, existem duas entidades diferentes em JavaScript que representam a ausência de um valor (com significado).
Existe o `null` e o `undefined`.

## Null

O valor primitivo `null` é usado como um «valor vazio» intencional para variáveis de qualquer tipo.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Podes verificar se uma variável é `null` com o [operador de igualdade estrita][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Uma variável à qual não foi atribuído um valor é do tipo `undefined`.[^1]

Isto significa que, enquanto `null` representa um valor vazio (mas ainda um valor), `undefined` representa a ausência total de um valor. 🤯

`undefined` aparece em contextos diferentes.

- Se uma variável for declarada sem um valor (inicialização), é `undefined`.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- Se tentares aceder ao valor de uma chave que não existe num objeto, obténs `undefined`.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- Se uma função não devolver um valor, o resultado é `undefined`.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- Se um argumento não for passado a uma função, é `undefined`, a menos que esse argumento tenha um valor predefinido.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

Podes verificar se uma variável é `undefined` com o operador de igualdade estrita `===`.

```javascript
let name;

name === undefined;
// => true
```

## Encadeamento opcional

Se tentares obter um valor aninhado num objeto, mas a chave pai não existir, o JavaScript lança um erro.
Para evitar isto facilmente, o encadeamento opcional foi adicionado à especificação da linguagem em 2020.
Com o operador de encadeamento opcional `?.`, podes garantir que o JavaScript só tenta aceder à chave aninhada se a chave pai não for `null` nem `undefined`.
Caso contrário, é devolvido `undefined`.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Coalescência nula

Há situações em que queres aplicar um valor predefinido caso uma variável seja `null` ou `undefined` (mas só nesse caso).
Para resolver isto, o operador de coalescência nula `??` foi introduzido em 2020.
Devolve o operando do lado direito apenas quando o operando do lado esquerdo é `null` ou `undefined`.
Caso contrário, é devolvido o operando do lado esquerdo.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
