# Dicas

## 1. Verifica se um espectador tem direito ao desconto de sénior

- Usa [o operador ternário][doc-ternary] para verificar a idade do espectador.

## 2. Verifica se um espectador pode ver filmes assustadores

- [Compara][doc-integer-gtoe] a idade do espectador com a idade mínima permitida para ver filmes assustadores. Nesta tarefa, nem sequer precisas do operador ternário.

## 3. Verifica se um espectador tem direito a pipocas grátis

- Usa uma das condicionais [`if`][doc-if]/[`unless`][doc-unless] para verificar se um espectador tem direito a pipocas grátis.
- Usa [`raise`][doc-raise].
