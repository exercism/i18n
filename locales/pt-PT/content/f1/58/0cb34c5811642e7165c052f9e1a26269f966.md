### Introdução

Bem-vindo ao primeiro exercício do percurso de Java!

Este documento é um guia passo a passo para resolveres este exercício.
As instruções funcionam igualmente bem no Windows, no macOS e no Linux.

Mesmo que já estejas familiarizado com os básicos de Java, seguir este guia pode ser útil: ajuda-te a compreender o resultado da ferramenta Gradle, que usamos para compilar e testar o nosso código, e apresenta-te alguns dos padrões comuns a todos os exercícios deste percurso.

### Estrutura do exercício

Quando obténs um novo exercício de Java, recebes:

- __um ou mais ficheiros de teste__ (sempre).
Estes ficam no diretório `src/test/java` e definem um conjunto de testes que a nossa solução tem de satisfazer antes de podermos declarar com segurança que está a funcionar.
- __um ou mais ficheiros de partida__ (inicialmente).
Se forem fornecidos, ficam no diretório `src/main/java` e definem esqueletos das classes de que vais precisar para resolver o problema atual.

### Passo 1: Corrigir a solução

Quer trabalhes localmente, quer uses o editor online, deves encontrar o seguinte código:

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

O objetivo é modificar o código fornecido para que produza o texto `"Hello, World!"` em vez de `"Goodbye, Mars!"`.

### Passo 2: Correr os testes

Depois de fazeres as correções e implementares a tua solução, corre os testes outra vez.
Podes correr os testes no editor online ou localmente na tua máquina:

- Para correres os testes no editor online, clica no botão "Run Tests".
- Para correres os testes localmente, consulta [Testar no percurso de Java][Testing locally on the java track] Se os testes falharem, não faz mal! Vê o que diz a mensagem de erro, altera o teu código e volta a testar. Quando os testes passarem, avança para o passo seguinte.

### Passo 3: Submeter a tua primeira iteração

Com uma solução a funcionar que já revimos, está tudo pronto para a submeteres ao exercism.org.
Podes submeter a solução no editor online ou localmente, com a [CLI do Exercism][Working Locally]:

- Para submeteres o exercício localmente, começa por [instalar a CLI do Exercism][Working Locally], se ainda não o fizeste, e depois submete os ficheiros da tua solução, por exemplo:

  ```sh
  exercism submit <file location>
  ```

- Substitui `<file location>` pela localização relativa do teu ficheiro `Greeter.java`, ou seja, se estiveres a trabalhar em `C:\exercism\java\hello-world`, o comando seria

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- Se quiseres usar o editor online para submeteres a solução, basta clicares no botão "Submit"!

Para veres com mais detalhe como submeter uma solução localmente:

- [Submeter localmente][Working Locally]

### Torna-te mentor

O coração do Exercism são as conversas sobre práticas de programação.
É sem dúvida divertido praticar, mas é ao interagires com os outros, tanto nas tentativas deles como nas tuas, que recebes feedback.
Esse feedback pode ajudar-te a perceber o que estás a fazer bem e onde podes precisar de melhorar.

Algumas submissões serão quase idênticas à tua, outras serão completamente diferentes.
Ver os dois tipos pode ser instrutivo e interessante.

Os mentores revêem as soluções submetidas no percurso que escolheram mentorizar, para ajudar os utilizadores a aprender o máximo possível.

Para saberes mais sobre mentoria, vai à [documentação do Exercism][Mentoring].
