# Prefere extrair a constante para o nível superior

Considera extrair a constante para o âmbito de nível superior:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Só as funções, as classes e as constantes marcadas com `export` ficam visíveis e acessíveis do exterior.
Estas constantes podem ficar no mesmo ficheiro sem ficarem expostas a outro código.
Além disso, extrair constantes poupa memória, porque evita alocações repetidas nas funções quando essas mesmas constantes são reutilizadas.
