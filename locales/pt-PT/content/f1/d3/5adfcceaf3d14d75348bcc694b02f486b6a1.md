# Dicas

## Geral

- Uma [struct][structs] pode conter vários campos de tipos diferentes.
- O [tipo Option][option] representa um valor que pode ser `Some(value)` ou `None`.
- [A construção `match`][match]: como fazer correspondência de padrões em Cairo.

## 1. Implementa o método `revive`

- Usa [instruções condicionais][if-else] para verificar se a vida do jogador é 0.
- Podes criar uma nova instância de `Player` com a [sintaxe de inicialização de structs][structs].
- Usa [correspondência de padrões][match] ou lógica condicional para determinar o valor de mana com base no nível do jogador.
- Devolve `Option::Some(player)` para um revive bem-sucedido ou `Option::None` quando o revive falhar.

## 2. Implementa o método `cast_spell`

- Usa [correspondência de padrões][match] no tipo `Option` para tratar os casos `Some` e `None` da mana.
- Podes usar [operadores de comparação][operators] para verificar se há mana suficiente.
- Podes usar os [operadores matemáticos][operators] para fazer subtração e multiplicação, para calcular valores.
- Lembra-te de alterar o estado do jogador (vida ou mana) com referências mutáveis.
