# Instruções

O Tadhg encontrou a biblioteca Erlang perfeita para o ajudar no seu projeto. Por ser uma biblioteca Erlang mais antiga, usa o módulo `gb_trees` em vez do módulo mais recente `maps` para armazenar dados.

Ajuda o Tadgh a criar tipos externos e funções para trabalhar com `gb_trees` em Gleam.

## 1. Define o tipo externo `GbTree`

O tipo `GbTree` deve ter dois parâmetros de tipo, um tipo para a chave e um tipo para o valor. Não deve ter construtores, o que faz dele um tipo externo.

## 2. Define a função `new_gb_tree`

A função `new_gb_tree` não deve receber argumentos e deve devolver um `GbTree` vazio.

Deve usar a [função `gb_trees:empty/0`][empty] da biblioteca padrão do Erlang.

## 3. Define a função `insert`

A função `insert` deve receber um `GbTree` e uma chave e um valor para inserir na árvore. Deve devolver um novo `GbTree` com a chave e o valor inseridos.

A função deve receber três argumentos:
1. O `GbTree` onde vamos inserir.
2. A chave a inserir.
3. O valor a inserir.

Deve usar a [função `gb_trees:insert/3`][insert] da biblioteca padrão do Erlang.

## 4. Define a função `delete`

A função `delete` deve receber um `GbTree` e uma chave a eliminar da árvore. Deve devolver um novo `GbTree` com a chave e o valor eliminados.

A função deve receber dois argumentos:
1. O `GbTree` de onde vamos eliminar.
2. A chave a eliminar.

Deve usar a [função `gb_trees:delete_any/2`][delete_any] da biblioteca padrão do Erlang.

[empty]: https://www.erlang.org/doc/apps/stdlib/gb_trees.html#empty/0
[insert]: https://www.erlang.org/doc/apps/stdlib/gb_trees.html#insert/3
[delete_any]: https://www.erlang.org/doc/apps/stdlib/gb_trees.html#delete_any/2
