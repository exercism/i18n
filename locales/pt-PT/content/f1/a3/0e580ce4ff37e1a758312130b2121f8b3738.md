# Dicas

## Geral

- Um array de nomes tem o tipo `ARRAY{STR}`, e um array de números o tipo
  `ARRAY{INT}`. Tanto o argumento como, na tarefa 4, a resposta têm de indicar
  qual deles.

## 1. Quantos na fila?

- `.size`, sem parênteses a seguir.

## 2. Quem lidera?

- A primeira posição é `0`.

## 3. Quem está atrás?

- A última posição é uma menos que o tamanho, porque a contagem começa em
  zero.
- Determina-a a partir de `.size` em vez de escreveres `2`. Os testes usam
  filas de vários comprimentos diferentes.

## 4. A formação de abertura

- A resposta é um array de strings, por isso a rotina é declarada com
  `: ARRAY{STR}`.
- Devolve um array literal: os três nomes entre os sinais `|`.

## 5. Conta os passos

- Um total acumulado e um ciclo, como no exercício anterior.
- Incrementa uma variável de posição a partir de `0` e termina o ciclo com
  `until!(i >= steps.size)`.
- Começar o total em `0` é o que faz com que uma fila vazia dê zero, sem
  qualquer tratamento especial.
