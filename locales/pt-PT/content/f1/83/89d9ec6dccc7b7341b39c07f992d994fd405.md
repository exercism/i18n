# Instruções

Um banco movimentado atende os clientes em espera por *prioridade* e não pela ordem por que chegaram. Cada cliente recebe um número de prioridade quando tira uma senha, e o funcionário do balcão atende sempre a seguir o número mais baixo (`1` é o mais urgente). Uma min-heap é a fila de espera perfeita.

## 1. Abre a fila

Define `new-queue`, que não recebe nada e devolve uma fila de prioridade nova e vazia.

```factor
new-queue
! => an empty priority queue
```

## 2. Adiciona um cliente

Define `join-queue`, que recebe o nome de um cliente, um número de prioridade e uma fila. Adiciona o cliente à fila e devolve a fila, para que se possam adicionar clientes uns a seguir aos outros.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. Quem é o próximo?

Define `next-name`, que recebe uma fila e devolve o nome do cliente que deve ser atendido a seguir (o que tem o número de prioridade mais baixo), *sem* o remover.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. Atende todos

Define `serve-all`, que recebe uma fila e devolve os nomes de todos os clientes em espera, na ordem em que seriam atendidos.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
