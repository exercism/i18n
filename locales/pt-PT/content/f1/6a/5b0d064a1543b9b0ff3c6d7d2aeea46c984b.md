# Introdução

Em C++, podes comparar valores com os operadores de comparação.

| Comparação        | Operador  |
| ------------------| --------- |
| igual             | `==`      |
| diferente         | `!=`      |
| menor             | `<`       |
| menor ou igual    | `<=`      |
| maior             | `>`       |
| maior ou igual    | `>=`      |

O resultado destas comparações é sempre um valor Boolean:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Os operadores `==` e `!=` verificam, respetivamente, se um valor é igual a outro ou não.
Aqui estão alguns exemplos comuns:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Os outros operadores verificam se um valor é maior que (`>`), maior ou igual a (`>=`), menor que (`<`) ou menor ou igual a (`<=`) outro valor.
Este tipo de comparação está disponível para números e strings.
Ao comparar strings, segue-se a ordem alfabética (também conhecida como ordem lexicográfica).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
