# Dicas

## Geral

- Declara os quatro símbolos cardeais e os quatro símbolos de rumo relativo com uma única linha `SYMBOLS:`:
  `SYMBOLS: north east south west ahead starboard behind port ;`
- Cada tuplo é declarado com `TUPLE: <class> <slot1> <slot2> ;`.
- Uma linha `GENERIC:` declara a palavra; cada linha `M:` adiciona um método a uma classe. Usa `M::` se quiseres variáveis locais nomeadas no corpo do método.

## 1. `>cartesian` para direções cardeais

- Basta um `case` pequeno sobre os quatro símbolos de direção.
- `{ north [ 0 1 ] }`: o corpo apenas empilha os dois valores; o teste espera que `x` fique abaixo de `y` na pilha.

## 2. `>cartesian` para coordenadas polares

- Converte graus em radianos: `bearing pi * 180 /`.
- `sin` e `cos` estão em `math.functions`.
- Empilha `magnitude * sin(rad)` e depois `magnitude * cos(rad)`.

## 3. `>cartesian` para rumos relativos

- Declara uma variável dinâmica: `SYMBOL: heading`.
- Lê-a no teu método com `heading get`.
- Mapeia `ahead/starboard/behind/port` para um deslocamento `0/90/180/270` com um `case` e depois adiciona o rumo. A partir daí, é a mesma conversão polar da tarefa 2: considera extrair um auxiliar `: deg>cartesian ( magnitude bearing -- x y ) ... ;`.

## 4. `flip`

- `change-direction` num `cardinal` e `change-bearing` num `polar` ou `relative` constroem um novo tuplo com um campo modificado, deixando o resto intacto:
  `[ <transformation-quotation> ] change-bearing`.
- Para a rotação do `polar`: `[ 180 + 360 mod ] change-bearing`.

## 5. `add-bearings`

- Chama `>cartesian` a cada entrada e depois soma as componentes x e as componentes y. As variáveis locais tornam isto legível:
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
