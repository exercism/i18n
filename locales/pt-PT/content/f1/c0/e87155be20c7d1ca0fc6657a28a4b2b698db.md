# Sobre

O [Java](https://go.java/index.html) está entre as linguagens de programação mais populares disponíveis, graças à sua versatilidade e compatibilidade.
É amplamente utilizado no desenvolvimento de software, em aplicações móveis e na criação de sistemas maiores.

O Java nasceu em 1995 e é mantido pela [Oracle](https://www.oracle.com/index.html).
Apesar de não ser tão recente como algumas das linguagens mais novas que existem, o Java continua a ser muito popular.
Foi concebido para ser rápido, seguro, fiável, amigável para quem está a começar e altamente portátil.
Esta vantagem de portabilidade existe porque o Java é executado numa [Máquina Virtual Java (JVM)](https://en.wikipedia.org/wiki/Java_virtual_machine) compatível com várias plataformas.
As aplicações Android também são desenvolvidas com Java, uma vez que o [Sistema Operativo Android](<https://en.wikipedia.org/wiki/Android_(operating_system)>) é executado num ambiente da linguagem Java.

A comunidade do Java é enorme!
O GitHub, por exemplo, tem mais de 1,5 milhões de projetos Java.
Vale também a pena referir que o Java tem a segunda maior comunidade no [StackOverflow](https://stackoverflow.com/questions/tagged/java)!
Isto é importante porque, quanto maior for a comunidade de uma linguagem de programação, maior é a probabilidade de receberes apoio.

O Java também tem um conjunto poderoso e bem concebido de [APIs (interfaces de programação de aplicações)](https://docs.oracle.com/en/java/javase/11/docs/api/index.html) incorporadas, que podem ser usadas em várias atividades como ligação a bases de dados, redes, I/O, análise de XML, utilitários e muito mais.

Dos portáteis aos centros de dados, das consolas de jogos aos supercomputadores científicos, dos telemóveis à Internet, [o Java está em todo o lado](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
