# Instruções

Olá de novo, Agente Double-Null0111.

As forças da UMBRA estão outra vez em ação, e cabe-te a ti frustrar o seu mais recente plano.
O nosso departamento de informações informa-nos de que esses Minions estão a planear rebentar uma bomba fétida no baile do Governador.

Como os Minions são muito desastrados, muitas vezes armam acidentalmente as bombas fétidas nos seus laboratórios e escritórios.
E, como continuam a esquecer-se de como desarmar as bombas fétidas, implementaram um sistema que gera as instruções de desarmamento, que indicam a ordem em que os fios devem ser cortados a partir do número de identificação da bomba.

A tua tarefa é escrever o código que te permitirá desarmar a bomba fétida no baile antes de ela rebentar.

## 1. Escreve um closure para trocar dois fios

Cada bomba fétida tem três fios de cores diferentes.
Escreve um closure que recebe um tuplo `(String, String, String)` e devolve o tuplo com a ordem dos dois primeiros elementos trocada.
Atribui este closure ao nome `flip`.

É importante notar que o tipo tem de ser o `ChangeClosure` (ou um tipo sendable); a definição do tipo é dada no ficheiro stub.
Caso contrário, o código não compila.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Escreve um closure para rodar os fios

Escreve um closure que recebe um tuplo `(String, String, String)` e devolve o tuplo com a ordem dos fios rodada para a esquerda.
Atribui este closure ao nome `rotate`.

É importante notar que o tipo tem de ser o `ChangeClosure` (ou um tipo sendable); a definição do tipo é dada no ficheiro stub.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Implementa um gerador de baralhamento de fios

Para descobrires a ordem em que deves cortar os fios da bomba fétida, vais precisar de implementar uma função que gera a função de baralhamento adequada com base no número de identificação da bomba fétida.

Implementa a função:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

que recebe como parâmetros de entrada um closure que troca dois fios e um closure que roda os três fios, e devolve um closure.
Este closure devolvido recebe o número de identificação da bomba fétida e a ordem dos três fios, e calcula depois a ordem em que os fios devem ser cortados.
O número de identificação é composto por oito bits, e cada bit determina se os fios devem ser trocados ou rodados.

Para cada bit do número de identificação, começando pelo bit mais à direita, aplicas o closure `flipper` ao tuplo de fios se o bit for 0, e aplicas o closure `rotator` se for 1, obtendo o novo estado dos fios.
Depois de aplicares os closures adequados aos oito bits do número de identificação, o estado final dos fios é a ordem em que devem ser cortados.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
