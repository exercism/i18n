# Introdução

## Comparar números

Em JavaScript, os números podem ser comparados com os seguintes operadores relacionais e de igualdade.

| Comparação             | Operador  |
| ---------------------- | --------- |
| Maior que              | `a > b`   |
| Maior ou igual a       | `a >= b`  |
| Menor que              | `a < b`   |
| Menor ou igual a       | `a <= b`  |
| Igual (estrito)        | `a === b` |
| Diferente (estrito)    | `a !== b` |

O resultado da comparação é sempre um valor boolean, ou seja, `true` ou `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## Comparar strings

Em JavaScript, os operadores de comparação acima também podem ser usados para comparar strings.
Nesse caso, aplica-se uma ordem de dicionário (lexicográfica).
Podes encontrar uma lista com a ordem exata de todos os carateres [aqui][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Igualdade estrita

Talvez te perguntes porque é que se usam três sinais de igual para verificar a igualdade em JavaScript.
`===` representa a verificação da _igualdade estrita_, o que significa que não é feita qualquer conversão de tipo e que valores de tipos diferentes nunca são iguais.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

Usar `===` e `!==` é a forma recomendada de verificar a igualdade em JavaScript.

Também existem `==` e `!=`, que representam a verificação da _igualdade não estrita_.
Deves evitá-los, porque aplicam uma conversão de tipo implícita antes de fazer a comparação.
Nestes casos, os resultados são difíceis de prever e, por vezes, não são o que esperas.

```javascript
0 == false;
// => true
```
