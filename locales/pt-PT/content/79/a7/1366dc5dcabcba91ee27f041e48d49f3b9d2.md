# Instruções

Neste exercício vais organizar corridas entre vários tipos de carros telecomandados.
Cada carro tem as suas próprias características e corre em muitas pistas diferentes, em corridas ao longo da temporada do torneio.

~~~~exercism/note
As funções deste exercício são declaradas num ficheiro de código C com as assinaturas fornecidas.
O teu código de assembly x86-64 tem de seguir essas especificações.
~~~~

## 1. Cria um carro telecomandado

Definiste uma struct `car_t` para representar um carro telecomandado:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

Permite criar um carro telecomandado definindo uma função `new_car` em assembly x86-64.
O campo `battery` começa sempre com o valor `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Cria uma nova pista

As pistas são representadas por uma struct `track_t`:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

O `enum surface_t` guarda os diferentes tipos de superfície de uma pista:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

Permite criar uma nova pista definindo uma função `new_track` em assembly x86-64.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Cria um evento de corrida

Em cada corrida participam até 6 carros, dando um número especificado de voltas a uma pista.
As corridas são representadas por uma struct `race_t`:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Define uma função `new_race` em assembly x86-64.
No início, não há carros participantes confirmados para a corrida:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Confirma a participação de um carro na corrida

Quando o dono de um carro pede que ele participe numa corrida, a sua participação só é confirmada se a lista ainda não estiver cheia.

Define uma função `add_participant` em assembly x86-64.
Se houver espaço para mais um participante na corrida, o carro é adicionado à lista, o contador é atualizado e a sua participação fica confirmada.
Caso contrário, os organizadores da corrida têm de informar o dono do carro de que não pode participar desta vez.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Cria um torneio

Registas as corridas agendadas para a temporada numa struct `tournament_t`:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Define uma função `add_race` em assembly x86, para adicionar uma corrida ao array do torneio e atualizar também o contador.
Podes considerar que haverá sempre espaço suficiente no array `races` para a nova corrida.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
