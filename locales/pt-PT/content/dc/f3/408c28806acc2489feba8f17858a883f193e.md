## 2. Escreve um adaptador de iteradores `evens` que devolve os elementos pares de um iterador qualquer

- Basta encadear os métodos sugeridos e tudo vai funcionar
- Um número `n` é par se `n % 2 == 0`
- Uma closure é uma função com uma sintaxe abreviada: o nome (ou os nomes) dos argumentos fica entre um par de símbolos `|`, e a expressão vem a seguir. Ao contrário das funções normais, nem sempre é necessário indicar explicitamente o tipo de cada argumento, basta o nome. Por exemplo, é assim que podes construir um iterador de quadrados de números ímpares: `(0..).map(|n| 2 * n + 1).map(|n| n * n)`.

## 3. Implementa um método `manhattan` numa struct de tuplo `Position`

- Não te preocupes com a sintaxe do método; basta substituir a parte `todo` dentro do bloco `impl Position` para fazer o que é preciso.
- Tem em conta que alguns valores dentro de uma `Position` podem ser negativos, mas uma distância nunca é negativa.
- O valor absoluto é calculado por uma função [já incluída](https://doc.rust-lang.org/std/primitive.i16.html#method.abs)
