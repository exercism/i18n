# Apêndice às instruções

## Testes

Os testes vão executar algumas operações em simultâneo.
Deves esforçar-te por garantir que as operações sobre a Account a deixam num estado consistente.
Por exemplo: várias goroutines podem estar a depositar e a levantar dinheiro ao mesmo tempo, e dois levantamentos em simultâneo não devem conseguir deixar o saldo negativo.

Quando trabalhas localmente, podes testar se o teu código lida corretamente com a concorrência e não introduz condições de corrida; para isso, corre os testes com a flag `-race` ativada.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
