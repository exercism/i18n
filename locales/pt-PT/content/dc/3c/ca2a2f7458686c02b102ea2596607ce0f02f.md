# Instalação

Ao contrário de muitas outras linguagens, o Pyret não exige que instales a linguagem globalmente. Em vez disso, os programadores do Pyret disponibilizaram o seu compilador como um [pacote npm][pyret-npm]. Vais instalar o Pyret com `npm` para cada exercício: encontrarás mais detalhes na página [Testes][tests].

Precisas de instalar o Node.js, um ambiente de execução de JavaScript. Na página de [transferência do Node.js][download], certifica-te de que selecionas `npm` como gestor de pacotes.

~~~~exercism/note
De momento, o pacote pyret-npm só é compatível com Linux e MacOS.
Quem usa Windows terá de instalar o pyret-npm através do WSL ou de uma máquina virtual.
~~~~
