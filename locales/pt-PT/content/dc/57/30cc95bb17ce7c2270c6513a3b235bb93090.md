# Introdução

## Tipos genéricos

Uma definição de coleção inclui habitualmente um marcador entre sinais de menor e maior, muitas vezes `T`, por convenção. Uma coleção deste tipo é designada por tipo genérico. Isto permite a quem usa a coleção especificar que tipo de itens quer guardar nela. No exemplo de código abaixo, estamos a criar uma instância de uma lista de strings.

## Listas

As listas em C# são coleções de valores primitivos ou de instâncias de structs ou de classes. Estão implementadas na biblioteca de classes base como `List<T>`, em que `T` é o tipo do item da lista. A API expõe um conjunto rico de métodos para criar e manipular listas.

É possível adicionar e remover itens das listas. As listas crescem e encolhem conforme necessário.

```csharp
var listOfStrings = new List<string>();
```
