# Sobre

Por vezes, quando uma função recebe muitos argumentos, pode ser difícil lembrar a ordem em que devem ser fornecidos. Para facilitar a leitura, o Gleam permite rotular argumentos com um nome.

Para rotular um argumento, indica o nome do rótulo antes do nome do argumento, com um espaço entre eles.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Ao chamar uma função com argumentos rotulados, os argumentos podem ser indicados em qualquer ordem. As seguintes chamadas a `replace` são equivalentes:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Os rótulos são sempre opcionais. Mesmo que uma função tenha argumentos rotulados, pode continuar a ser chamada sem rótulos.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

Ao definir uma função com argumentos rotulados, todos os argumentos a seguir ao primeiro argumento rotulado também têm de ser rotulados.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
