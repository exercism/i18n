# Introdução

A Wikipédia descreve uma instrução `switch` como "um tipo de mecanismo de controlo de seleção que permite que o valor de uma variável ou expressão altere o fluxo de controlo do programa".

O mecanismo envolve as seguintes palavras-chave: `switch`, `case`, `break` e `default`.

Na sua forma mais simples, testam uma expressão primitiva ou uma string e tomam uma decisão com base no seu valor. Por exemplo:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

Na sua forma mais sofisticada, introduzem a conversão descendente `case <Type> <variable>:` e as guardas (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
