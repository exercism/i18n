# Dicas

## 1. Determina o número total de aves que contaste até agora

- Consulta a introdução do exercício para ver um exemplo de como usar um ciclo for para iterar sobre um slice.
- Usa uma variável auxiliar para guardar a contagem total e incrementa essa variável à medida que percorres o slice.
- Pensa no valor inicial correto para essa variável auxiliar.

## 2. Calcula o número de aves visitantes numa semana específica

- Esta tarefa é semelhante à primeira, podes copiar o teu código como ponto de partida.
- Pensa em que índices do slice precisas de ter em conta para a semana número 1 e 2, respetivamente.
- Encontra agora uma forma geral de calcular o primeiro e o último índice a considerar.
- Com isso, podes montar o ciclo for para iterar apenas sobre a secção relevante do slice.

## 3. Corrige um erro de contagem

- Mais uma vez, precisas de montar um ciclo for para iterar sobre todo o slice da contagem de aves.
- Desta vez, só precisas de visitar cada segunda entrada do slice.
- Altera o passo para que a variável contadora seja incrementada em conformidade depois de cada iteração.
- No corpo do ciclo for, podes usar o operador de incremento para alterar o valor de um elemento de um slice no próprio local.
