# Dicas

## Geral

- `<min-heap>`, `heap-push`, `heap-peek` e `heap-pop-all` estão todos em
  [`heaps`][heaps]; `values` está em [`assocs`][assocs].
- Uma heap guarda cada item como um *valor* com uma *chave*; a chave é a
  prioridade. `heap-push` recebe-os como `( value key heap -- )`.

## 1. Abre a fila

- `<min-heap>` cria uma min-heap vazia: a chave mais pequena é servida
  primeiro.

## 2. Adiciona um cliente

- O nome do cliente é o valor e a prioridade é a chave, que é
  exatamente a ordem que `heap-push` espera.
- `heap-push` consome a fila. Usa `[ heap-push ] keep` para adicionar o
  cliente e devolver a fila na mesma.

## 3. Quem é o próximo?

- `heap-peek` devolve `value key` para o item da frente sem o remover.
  Só queres o nome, por isso descarta a chave com `drop`.

## 4. Atende toda a gente

- `heap-pop-all` esvazia a heap para uma lista de associações de pares
  `{ key value }`, já por ordem de prioridade.
- `values` mantém apenas os valores, ou seja, os nomes.
