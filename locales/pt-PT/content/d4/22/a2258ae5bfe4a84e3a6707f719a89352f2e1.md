# Anexo às instruções

## Dicas

Uma [lista duplamente ligada](https://en.wikipedia.org/wiki/Doubly_linked_list) é uma estrutura de dados mutável. Como o F# é uma linguagem que dá prioridade ao paradigma funcional, geralmente dá-se preferência à imutabilidade, mas há funcionalidades da linguagem que permitem usar mutação quando é necessária.

- A palavra-chave `mutable` pode ser colocada antes de associações `let` e de campos de [registo](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records), o que te permite atribuir-lhes novos valores.

- As propriedades de [classe](https://fsharpforfunandprofit.com/posts/classes) podem tornar-se mutáveis se especificares um setter de propriedade com a palavra-chave `set`.

As associações mutáveis têm de ser reatribuídas com `<-`

```fsharp
let mutable x = "initial value"
x <- "new value"
```
