# Introdução

Em Cairo, a sobrecarga de operadores permite-te definir comportamento personalizado para operadores padrão como `+`, `-`, `==`, `<`, etc., quando trabalhas com os teus próprios tipos.

Isto é feito através da implementação de traits específicos para os teus tipos personalizados.

## Traits essenciais para operadores

### `Add` e `Sub`

Os traits `Add` e `Sub` permitem-te definir como a adição (`+`) e a subtração (`-`) funcionam com o teu tipo:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

O trait `PartialEq` permite a comparação de igualdade (`==` e `!=`) entre instâncias do teu tipo.

Isto pode, muitas vezes, ser derivado automaticamente com `#[derive(PartialEq)]`.

### `PartialOrd`

O trait `PartialOrd` permite operações de comparação (`<`, `>`, `<=`, `>=`) entre instâncias do teu tipo.

Exige que implementes pelo menos o método `lt` (menor que):

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
