# Anexo às instruções

## Implementação

As funções deste exercício aceitam um array com um ou mais números, cada um deles a representar uma "pontuação de jogo".

As pontuações do jogador podem ser lidas a partir de

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

A função `personal_top_three()` deve escrever as pontuações mais altas do jogador em

| `output`   |
|---|
| `output[0]` |
| ... |
