## 1. Identifica linhas de log corrompidas

- A [função `regexp.from_string`][from-string] pode ser usada para compilar uma expressão regular.
- A [função `regexp.check`][check] pode ser usada para testar se uma expressão regular corresponde a uma string.
- Não te esqueças de escapar os carateres que têm um significado especial nas expressões regulares.

## 2. Divide a linha de log

- A [função `regexp.split`][split] pode ser usada para dividir uma string com uma expressão regular.
- Não te esqueças de escapar os carateres que têm um significado especial nas expressões regulares.

## 3. Etiqueta linhas com nomes de utilizador

- A [função `regexp.scan`][scan] pode ser usada para capturar partes de uma string com uma expressão regular.
- Não te esqueças de escapar os carateres que têm um significado especial nas expressões regulares.
