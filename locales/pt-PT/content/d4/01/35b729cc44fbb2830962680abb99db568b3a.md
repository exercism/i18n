# Dicas

## Geral
- O [tipo][types] de uma variável depende do valor dessa variável: *10* como `Int`, *'Hello'* como `String` ou *2.0* como `double`.

## 1. Define a constante do tempo de cozedura esperado em minutos

- Tens de definir uma variável constante e atribuir-lhe um valor inteiro.
- As constantes podem ser definidas através do [cmdlet New-Variable][new variable].

## 2. Calcula o tempo de cozedura restante em minutos

- Tens de definir uma [função][defining functions] com um único parâmetro.
- Usa o [operador matemático de subtração][arithmetic] para subtrair valores.
- Esta função deve [devolver um valor][return].

## 3. Calcula o tempo de preparação em minutos

- Tens de definir uma [função][defining functions] com um único parâmetro.
- Usa o [operador matemático de multiplicação][arithmetic] para multiplicar valores.
- Podes definir uma _constante_ extra para o tempo em minutos por camada, em vez de usares um "número mágico" no teu código.
- Esta função deve [devolver um valor][return] inteiro.

## 4. Calcula o tempo total de cozedura decorrido (preparação + cozedura) em minutos

- Define uma [função][defining functions] com dois parâmetros.
- Podes _chamar_ uma função que já definiste anteriormente.
- Podes usar o [operador matemático de adição][arithmetic] para somar valores.
- Esta função deve [devolver um valor][return] inteiro.

## 5. Atualiza a receita com notas

- Define uma função sem parâmetros.
- Esta função deve devolver um valor do tipo string.
