# Adenda às instruções

## Registos

| Registo | Utilização       | Tipo    | Objetivo                   |
| -------- | --------------- | ------- | -------------------------- |
| `$a0`    | valor de entrada | inteiro | valor fornecido            |
| `$v0`    | valor devolvido  | inteiro | diferença de quadrados     |
| `$t0-9`  | temporário       | qualquer | usado para armazenamento temporário |
