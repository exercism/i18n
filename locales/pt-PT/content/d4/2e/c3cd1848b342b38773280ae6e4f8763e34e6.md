# Instruções

Bem-vindo ao mundo de *ChronoRealms*, uma terra mágica onde poderosos Guardiões do Tempo controlam o fluxo do tempo.

Neste reino, os Guardiões do Tempo gerem "TimeShards", unidades especiais que podem ser somadas, subtraídas, comparadas e até verificadas quanto à igualdade.

A tua tarefa é ajudar os Guardiões do Tempo a implementar operadores personalizados para manipular estes TimeShards.

Os Guardiões do Tempo precisam que cries uma struct personalizada `TimeShard` que suporte as seguintes operações:

1. **Somar e subtrair TimeShards**: os Guardiões do Tempo têm de conseguir somar e subtrair TimeShards para controlar a linha temporal.
2. **Comparar TimeShards**: às vezes, é preciso comparar TimeShards para ver qual deles é maior, ou se são iguais.
3. **Verificar a igualdade**: os Guardiões do Tempo têm de verificar se dois TimeShards têm o mesmo valor.

A tua missão é implementar os seguintes traits para a struct `TimeShard`:

1. **Adição (`Add`)**: permitir somar duas instâncias de `TimeShard`.
2. **Subtração (`Sub`)**: permitir subtrair uma instância de `TimeShard` a outra.
3. **Igualdade (`PartialEq`)**: permitir que os Guardiões do Tempo verifiquem se duas instâncias de `TimeShard` são iguais.
4. **Comparação (`PartialOrd`)**: permitir comparar duas instâncias de `TimeShard` para ver qual é maior ou menor.

Um `TimeShard` será representado por uma struct que guarda um valor inteiro (`i32`).

Implementa os traits necessários para facilitar o trabalho aos Guardiões do Tempo.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
