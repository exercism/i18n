# Instruções

Trabalhas num prestigiado escritório de advogados especializado em tratar pedidos testamentários únicos.

Neste exercício, vais abrir um cofre misterioso.
És o testamenteiro da herança e vais reunir os códigos secretos, guardados há muito tempo, de três famílias, para obter um número de conta e o código correspondente.

Para impedir que qualquer família abra o cofre sozinha, ele só pode ser aberto combinando o conhecimento delas com um modificador secreto que conheces do testamento.

Tens três tarefas, todas relacionadas com ajudar as famílias a abrir o cofre.

## 1. Senta-te à frente das famílias e dispõe os teus papéis

Define um namespace chamado `estate_executor`.
O código das tarefas seguintes deve ser definido no corpo do namespace `estate_executor`.

```cpp
namespace some_name {
    // The space between the curly brackets
    // is called body of the  namespace.
}
```

## 2. Encontra o número de conta secreto

Este é o teu grande momento.
Só tu tens a chave modificadora secreta para revelar o número de conta secreto.

Define a função `assemble_account_number(int secret_modifier)`, que recebe o modificador secreto como argumento e devolve o número de conta montado como um `int`.

Para obter o número correto, tens de somar a `bank_number_part` de cada uma das três famílias.

## 3. Último passo: introduz o código secreto

As instruções do testamento pedem-te que somes todos os fragmentos azuis e, depois, todos os vermelhos.
O código resultante obtém-se multiplicando as duas somas.

Define a função `assemble_code()`, que devolve o código resultante, combinando os fragmentos das três famílias num único `integer`.
A função não tem argumentos e baseia-se apenas na informação dos namespaces relevantes das famílias.
