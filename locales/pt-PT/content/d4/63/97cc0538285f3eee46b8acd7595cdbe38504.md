# Introdução

## Operadores de comparação

Os operadores de comparação em Julia são semelhantes aos de muitas outras linguagens, embora com algumas opções extra para quem gosta de matemática.

Para a igualdade, os operadores são `==` (igual) e `!=` ou `≠` (diferente).

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

Além disso, temos os vários operadores de maior e menor que.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Como acontece muitas vezes com Julia, um editor adequado torna fácil usar o símbolo matemático.
Escreve `\ne`, `\le` ou `\ge` e a seguir `TAB` para obteres `≠`, `≤` ou `≥`.

O exemplo anterior usa apenas números, mas vamos ver noutras partes do programa que vários tipos adicionais têm uma noção de ordem e podem ser comparados com os operadores de maior e menor que.

Os operadores de comparação podem ser encadeados, o que permite uma sintaxe clara e concisa:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

O exemplo anterior é sinónimo de `1 ≤ n && n ≤ 5`.

## Ramificação com `if`

Esta é a forma completa de um condicional:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

Não é preciso usar parênteses `()` nem chavetas `{}`, e a indentação serve «apenas» para melhorar a legibilidade _(mas a legibilidade é muito importante!)_.

Tanto o `elseif` como o `else` são opcionais, e pode haver vários blocos `elseif`.
No entanto, o `end` é obrigatório.

É possível aninhar condicionais, embora possas querer ajudar a legibilidade com um uso cuidado de parênteses, indentação e comentários.

A forma mais curta de um condicional seria algo assim:

```julia
if n < 0
    n = 0
end
```

Como lembrete: só as expressões que são avaliadas como `true` ou `false` podem ser usadas como condicionais.
Julia evita deliberadamente qualquer conceito de «truthiness», pelo que valores zero, strings vazias e arrays vazios _não_ são equivalentes a `false`.

## Operador ternário

Uma situação simples e comum é escolher um de dois valores com base numa condição.

Julia, como muitas linguagens, tem um operador ternário para tornar isto mais conciso.

A sintaxe é `conditional ? value_if_true : value_if_false`.

Assim, o exemplo anterior pode ser reescrito:

```julia
n = n < 0 ? 0 : n
```

O compilador não exige parênteses, mas estes podem melhorar a legibilidade.
