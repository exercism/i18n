# Instruções

Estás a construir uma pequena calculadora de Notação Polaca Inversa (NPI).
O estado da calculadora é uma *pilha de valores*, representada como um
array de Factor, e uma *operação* é uma quotation que recebe uma pilha
dessas e devolve uma nova.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. Implementa a adição

Define `add-op` para retirar os dois valores do topo da pilha, empilhar a
soma deles e devolver a nova pilha.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. Implementa a multiplicação

Define `multiply-op` da mesma forma, mas para a multiplicação.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. Aplica uma única operação

Define `apply-op` para retirar uma pilha e uma operação (uma quotation) da
pilha de dados e devolver a nova pilha da calculadora.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. Avalia um programa

Define `evaluate` para receber uma pilha inicial e um array de operações,
aplicar cada operação pela ordem e devolver a pilha final.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. Avalia por nome

Agora o programa é uma lista de *nomes de operadores* (strings), e a
calculadora procura cada nome num assoc que faz corresponder nomes a
operações.

Define `evaluate-named` para receber uma pilha inicial, um assoc de
operações com nomes e um array de nomes, e devolver a pilha final.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. Divide com segurança

Uma calculadora a sério não pode produzir lixo em silêncio quando lhe
pedem para dividir por zero. A classe de erro `zero-divisor-error` já
está definida para ti. Implementa `divide-op` de forma análoga a `add-op`
e `multiply-op`, mas que faz `throw` de um novo
`zero-divisor-error` quando o divisor no topo da pilha é `0`.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
