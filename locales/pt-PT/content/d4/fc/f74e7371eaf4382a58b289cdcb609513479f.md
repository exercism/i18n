# Dicas

## Geral

- [The Cairo Book: Smart Pointers][smart-pointers]

## 1. Constrói a ChronoChain a partir de um array de valores `u32`

- Podemos percorrer o array e construir uma cadeia ao contrário, começando no `End` e ligando cada valor com a variante `Link`.
- Considera usar `span.pop_back()` para percorrer o array pela ordem inversa; isso vai ajudar-nos a criar a cadeia do fim para o início.

## 2. Soma os valores da ChronoChain

- Usa correspondência de padrões para tratar as duas variantes de `ChronoChain`.
- Quando chegas ao `End`, a soma é 0, e quando chegas ao `Link`, somas o valor e somas recursivamente o resto da cadeia.
- Esta abordagem é semelhante a uma função recursiva que percorre a estrutura até chegar ao caso base (`End`).
