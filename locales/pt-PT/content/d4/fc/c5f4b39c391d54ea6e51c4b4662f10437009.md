# Dicas

## 1. Insere uma carta no topo da pilha

- A [função `ArrayTrait::append`][append] pode ser usada para adicionar ao fim de um array.

## 2. Remove a carta do topo da pilha

- Podes sempre converter um array num span e depois usar a [função `SpanTrait::pop_back`][pop-back] para remover do fim de um array.

## 3. Insere uma carta na base da pilha

- Não há forma de acrescentar um elemento à frente do array, mas uma forma de contornar isto é criar um novo array com um único elemento e acrescentar o antigo como um span com [`ArrayTrait::append_span`][append-span].

## 4. Remove uma carta da base da pilha

- A [função `ArrayTrait::pop_front`][pop-front] pode ser usada para remover da frente de um array.

## 5. Verifica o tamanho da pilha

- A [função `ArrayTrait::len`][len] pode ser usada para obter o comprimento de um array.
