# Sobre

Em Common Lisp, as funções globais com nome definem-se com `defun`.

Esta forma recebe, como primeiro argumento, uma lista de parâmetros da função que está a ser definida (a lista de parâmetros também se chama 'lista lambda').
A seguir, pode receber, opcionalmente, uma string para servir de documentação a essa função.
Por fim, há zero ou mais expressões que constituem o corpo da função.

Para chamar uma função, usa-se o nome da função como primeiro elemento de uma expressão, seguido dos parâmetros dessa função.

```lisp
(defun add-one (x) (1+ x))

(add-one 3) ;; => 4
```

As funções também podem receber [parâmetros opcionais][concept-optional-parameters], [parâmetros de palavra-chave][concept-keyword-parameters] e [parâmetros restantes][concept-rest-parameters].
Estes serão abordados em conceitos posteriores.

O nome da função está dentro do âmbito no corpo da função, para que seja possível fazer recursão.

```lisp
(defun countdown (x)
  (if (zerop x) (print 'BLAST-OFF)
    (progn (print x) (countdown (1- x)))))

(countdown 3) ;; will print "3","2", "1" and "BLAST-OFF" to
              ;; standard output before evalutaing to 'BLAST-OFF
```
