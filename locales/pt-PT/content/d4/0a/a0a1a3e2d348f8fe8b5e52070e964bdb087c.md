# Testes

Para testar a tua solução, abre o terminal e corre

```
mason test
```

na pasta do exercício (a que contém o ficheiro `Mason.toml` e as pastas `src/` e `test/`).

Se achares que a mensagem de erro não é suficientemente informativa, podes experimentar o seguinte para obter uma mais detalhada.

```
mason test --show
```
