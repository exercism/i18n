# Sobre

Um `bit` é o valor mais granular da computação.
A palavra `bit` significa "algarismo binário".
É uma unidade de armazenamento de dados no ambiente de execução suficientemente grande para conter um objeto que pode ter um de dois valores.
Como tal, tem um valor binário de `1` ou `0`.
Todos os outros tipos de dados são compostos por vários `bits`.
Por exemplo, um `byte` é normalmente composto por oito `bits`.

## Como escrever valores de bits

`Bits` formam um sistema numérico de base 2.
Cada múltiplo de `2` ocupa aquilo a que chamamos a casa das dezenas/centenas/milhares/etc., só que "dezenas" seria "dois", "centenas" seria "quatro", "milhares" seria "oito", e assim por diante.
Assim, o valor decimal `2` seria o valor binário `10`, `4` seria `100` e `8` seria `1000`.
Tal como nos números decimais, os valores tornam-se maiores da direita para a esquerda.
Podemos pensar no valor decimal `5` como sendo representado por `101` em binário, com um `1` na casa das unidades e um `1` na casa do `4`.
No entanto, os literais binários não fazem parte do padrão da linguagem C.
Os únicos valores binários suportados pelo padrão da linguagem C são um único `1` ou `0`.
Os literais binários _são_ suportados por algumas extensões de compilador não padrão, como o compilador gnu, colocando o prefixo `0b` antes do literal.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

É importante lembrar que esta notação não é suportada por todos os compiladores e pode ser um obstáculo à portabilidade do código entre compiladores diferentes.

Uma forma comum de escrever valores binários é usar a notação hexadecimal, que é um sistema numérico de base 16.
A notação hexadecimal da linguagem C coloca o prefixo `0x` ou `0X` antes do literal.
Como o valor decimal `16` é representado como `1` na casa das dezenas, o valor decimal `10` é representado como `0xA` em hexadecimal, `11` como `0xB`, `12` como `0xC`, `13` como `0xD`, `14` como `0xE` e `15` como `0xF`.
Assim, por exemplo, o valor decimal `42` seria escrito como `0x2A`: `2` vezes `16` (= `32`) mais `10` (= `42`).

Em binário, podemos pensar em `42` como `00101010`: `32` mais `8` mais `2`.
Diríamos que o segundo, o quarto e o sexto bits a contar da direita estão "definidos", o que significa que são `1` em vez de `0`.
O segundo bit é `2`, o quarto bit é `8` e o sexto bit é `32`.
Definir esses três bits dá origem ao valor `42`.

## Máscaras de bits

Uma máscara de bits pode ser qualquer valor usado para definir bits individuais.
Por exemplo, o alfabeto inglês tem vinte e seis letras.
Um valor com pelo menos vinte e seis bits, como um inteiro sem sinal de 32 bits, poderia ser usado como máscara de bits para definir uma condição `true` ou `false` para cada letra do alfabeto inglês.
Qualquer valor com bits suficientes para lidar com um conjunto necessário de condições `true` ou `false` pode servir de máscara de bits.
Definir e ler os bits individuais faz-se através da utilização de operadores bit a bit.

## Operadores bit a bit

Digamos que queremos acompanhar que letras ocorrem numa `string`.
Para o nosso exemplo, vamos usar apenas as vinte e seis letras do alfabeto inglês.
A nossa máscara de bits será um inteiro sem sinal de 32 bits.
Um `0` representará que a letra não ocorre.
Um `1` representará que a letra ocorre uma ou mais vezes.
No início, a representação em bits da nossa máscara será de 32 `0s` seguidos: `00000000000000000000000000000000`.
A posição mais à direita será para o `A`.
A segunda a contar da esquerda será para o `B`, e assim por diante.
Digamos que estamos a processar todas as letras da string num ciclo, por isso queremos uma única linha de código que funcione para definir qualquer letra.

### Operador de deslocamento à esquerda bit a bit: uma forma de posicionar um bit

`<<` é o operador bit a bit para deslocar à esquerda.

Se a nossa letra for `A`, não queremos deslocar à esquerda, mas se a nossa letra for `B`, queremos deslocar uma posição à esquerda, e se a nossa letra for `C`, queremos deslocar duas posições à esquerda, e assim por diante.
Embora possamos ver os `chars` como letras como `A` ou `B`, um `char` é implementado como um tipo inteiro na memória, por isso podemos fazer aritmética simples com um `char`.
Dada uma variável chamada `letter` que representa o `char` que estamos a processar, podemos deslocar à esquerda o número de posições necessário deslocando `1` para a esquerda pela diferença entre `letter` e o `char` `A`, assim: `1 << letter - 'A'`.
`A` - `A` é `0`, por isso deslocaria `0` posições à esquerda se `letter` for `A`.
`B` - `A` é `1`, por isso deslocaria `1` posição à esquerda se `letter` for `B`, e assim por diante.

### Operador OR inclusivo bit a bit: uma forma de definir um bit

Assim que sabemos _onde_ queremos definir um bit, podemos de facto defini-lo usando o operador OR inclusivo bit a bit, que é `|`.
O resultado do operador `|` será `1` em cada posição onde o operando da esquerda ou o da direita tenha um bit definido.
Assim, o resultado de `0010 | 0001` seria `0011`.
(É importante lembrar que o valor é `11` em binário, mas é `3` em decimal.)
Para atribuir o resultado a um valor, o operador `|` pode ser combinado com o operador de atribuição para definir os bits assim: `|=`.
Para simplificar, o exemplo seguinte não usa um ciclo, mas demonstra como poderíamos processar as letras `ABA` numa máscara de bits.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Definimos a parte mais à direita da nossa máscara como `0001` para o `A`, e depois definimos a máscara como `0011` para o `B`.
Definir outro `A` não altera a máscara existente.
Poderíamos ter evitado definir o bit outra vez se tivéssemos verificado se o `A` já estava definido.

### Operador AND bit a bit: uma forma de ler um bit

`&` é o operador AND bit a bit.
O resultado do operador `&` será `1` em cada posição onde tanto o operando da esquerda como o da direita tenham um bit definido.
Assim, o resultado de `0011 & 0001` seria `0001`.
Podemos ver isto em ação no exemplo seguinte.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Operador OR exclusivo bit a bit: uma forma de inverter um bit

`^` é o operador OR exclusivo bit a bit.
Um operador OR _inclusivo_ implica que existe um operador OR _exclusivo_ com um comportamento diferente.
O resultado do operador `^` será `1` em cada posição onde _apenas um_ dos operandos da esquerda ou da direita tenha um bit definido.
Assim, o resultado de `0001 ^ 0011` seria `0010`.
O bit mais à direita não será definido porque _ambos_ os operandos têm `1` na posição mais à direita.
A operação OR exclusivo é por vezes denotada por XOR.
Se o resultado de um valor que sofreu XOR sofrer XOR outra vez, devolve o valor original.
Isto pode ser usado para uma encriptação muito simples em que a mesma chave é usada tanto para encriptar como para desencriptar os dados.
Por exemplo

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### Operador de deslocamento à direita bit a bit: uma forma de reduzir um valor para metade

`>>` é o operador bit a bit para deslocar à direita.
Normalmente, por cada posição que os bits de um valor são deslocados à direita, o resultado é o valor dividido por dois.
Por exemplo

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

Se o valor do operando da direita for negativo ou for maior ou igual à largura do operando da esquerda promovido, o comportamento é indefinido.
Isso também se aplica ao operador de deslocamento à esquerda.
Quando se usa um inteiro com sinal em vez de um inteiro sem sinal, a presença de sinal também pode influenciar.
O exemplo seguinte mostra o comportamento num sistema ao deslocar demasiado para a esquerda ou para a direita com um inteiro com sinal.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

Como o comportamento é indefinido, um sistema diferente pode dar resultados diferentes.
Ao deslocar bits, é importante compreender os limites do tipo de dados utilizado.

## Campos de bits

Já vimos como os bits empacotados num tipo de dados simples podem ser endereçados pela sua posição.
Os bits empacotados numa `struct` podem ser endereçados pelo nome.
Esse tipo de dados chama-se `bit field`.
Um caso de uso para os `bit fields` pode ser quando é necessária uma coleção de indicadores ON/OFF e se pretende minimizar o uso de memória.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

A sintaxe `unsigned int variable_name : 1;` cria um campo de `1` bit dentro de um `unsigned int` colocado dentro da struct.
Em vez de um `unsigned int`, poderia usar-se um `signed int` ou, a partir do C99 ou posterior, um tipo `bool`.
Uma struct que contém campos de bits também pode conter campos de outros tipos de dados, como `number_of_lights` no exemplo acima.
