# Introdução

As funções para tratar a entrada e a saída são fornecidas pelo módulo `IO`.

## Saída

Para escrever uma string na saída padrão, usa `IO.puts`. `IO.puts` acrescenta sempre uma nova linha no fim da string. Se não quiseres esse comportamento, usa antes `IO.write`. Ambas as funções devolvem o átomo `:ok` se tiverem sucesso.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` é útil para escrever strings, mas pouco mais. Se precisares de uma ferramenta de depuração que te permita escrever qualquer valor na saída padrão, usa antes `IO.inspect`. `IO.inspect` devolve inalterado o valor que lhe foi passado, por isso pode ser inserido em qualquer ponto do teu código. Também aceita várias opções, por exemplo `:label`, que te permitem distingui-lo de outras chamadas a `IO.inspect`.

## Entrada

Para ler uma linha da entrada padrão, usa `IO.gets`. `IO.gets` aceita um argumento: uma string que imprime como mensagem a pedir a entrada. `IO.gets` não acrescenta uma nova linha depois dessa mensagem; inclui-a tu mesmo, se precisares dela.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
