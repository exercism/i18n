# Introdução

Os genéricos permitem-te escrever código que funciona com vários tipos sem duplicação.
Define tipos genéricos com sinais de menor e maior, `<T>`, em que `T` é um marcador para qualquer tipo.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

O Cairo exige limites de trait para especificar que operações o tipo genérico tem de suportar.
Podes adicionar restrições com a sintaxe `+`:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

As estruturas também podem ser genéricas:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

As traits também podem ser genéricas, o que lhes permite funcionar com tipos diferentes:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

As funções podem aceitar parâmetros genéricos com limites de trait. Assim, funcionam com qualquer tipo que implemente o trait necessário:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
