# Sobre

O Perl v5 é uma linguagem de programação de alto nível e de uso geral, criada por Larry Wall e lançada pela primeira vez em 1987.
É uma linguagem eclética, interpretada, procedural e de tipagem fraca.
O seu auge de popularidade coincidiu com a ascensão da World Wide Web, embora continue a ser amplamente utilizada em garantia de qualidade, automatização de infraestruturas de TI, processamento de texto, bioinformática e desenvolvimento de aplicações web, só para dar alguns exemplos.
É muito flexível, mas essa flexibilidade pode traduzir-se num custo de manutenção acrescido.

 O Perl tem ainda:

- suporte mínimo para objetos já incluído, mas com interessantes bibliotecas de POO de terceiros
- funções de primeira classe
- closures
- um poderoso motor de expressões regulares integrado
- a [Comprehensive Perl Archive Network (CPAN)](http://www.cpan.org), uma enorme biblioteca de módulos contribuídos pelos utilizadores

Todos os sistemas operativos Unix e do tipo Unix mais conhecidos são distribuídos com o Perl incluído.
