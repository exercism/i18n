# Criar um Representer

Antes de mais, obrigado pelo teu interesse em criar um Representer!

Estes são os passos para começar:

1. Verifica [a nossa lista de repositórios para ver se já existe um `...-representer`](https://github.com/search?q=org%3Aexercism+representer&type=repositories), para garantir que ainda não existe nenhum.
2. Explora o [conteúdo desta pasta](/docs/building/tooling/representers) para garantir que te sentes à vontade com a ideia de criar um Representer.
3. Cria um novo tópico no [fórum do Exercism][building-exercism] a dizer-nos para que linguagem gostarias de criar um Representer.
4. Depois de ser criado um repositório de Representer para ti, usa os documentos [da interface do Representer](/docs/building/tooling/representers/interface) e [Boas práticas](/docs/building/tooling/best-practices) para orientar a tua implementação.

Temos uma comunidade incrivelmente simpática e prestável, que terá todo o gosto em ajudar-te ao longo deste processo!
Se ficares bloqueado, cria um novo tópico no [fórum do Exercism][building-exercism] ou abre novas issues em [exercism/exercism][exercism-repo], conforme for necessário 🙂

[building-exercism]: https://forum.exercism.org/c/exercism/building-exercism/125
[exercism-repo]: https://github.com/exercism/exercism
