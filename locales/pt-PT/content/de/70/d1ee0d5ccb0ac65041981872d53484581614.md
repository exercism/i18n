# Dicas

## Geral

- Usa o tipo de lista [(com ligação)][list] integrado na linguagem.

## 1. Define uma função que devolve uma lista de linguagens vazia

- A função tem de devolver `[]`.

## 2. Define uma função que adiciona uma linguagem à lista

- Podes adicionar um elemento ao início de uma lista com `:`.

## 3. Define uma função que remove uma linguagem da lista

- O Haskell [tem uma função][tail] que devolve uma lista sem o primeiro elemento.

## 4. Define uma função que devolve o primeiro elemento da lista

- O Haskell [tem uma função][head] para obter o primeiro elemento de uma lista.

## 5. Define uma função que devolve quantas linguagens há na lista

- O Haskell [tem uma função][length] para calcular o comprimento de uma lista.

## 6. Define uma função que determina se a lista inclui uma linguagem funcional

- A tua função deve devolver um valor Boolean que indica se `"Haskell"` faz parte da lista.
  O Haskell [tem uma função][elem] para testar se um elemento pertence à lista.
