# Introdução

No Elixir, a documentação é um cidadão de primeira classe.

Há dois atributos de módulo usados habitualmente para documentar o teu código: o `@moduledoc`, para documentar um módulo, e o `@doc`, para documentar uma função que se segue ao atributo. O atributo `@moduledoc` aparece normalmente na primeira linha do módulo, e o atributo `@doc` aparece habitualmente mesmo antes da definição de uma função, ou do typespec da função, caso esta tenha um. A documentação é normalmente escrita numa string com várias linhas, usando a sintaxe heredoc.

A documentação do Elixir é escrita em [**Markdown**][markdown].

```elixir
defmodule String do
  @moduledoc """
  Strings in Elixir are UTF-8 encoded binaries.
  """

  @doc """
  Converts all characters in the given string to uppercase according to `mode`.

  ## Examples

      iex> String.upcase("abcd")
      "ABCD"

      iex> String.upcase("olá")
      "OLÁ"
  """
  def upcase(string, mode \\ :default)
end
```

[markdown]: https://docs.github.com/en/github/writing-on-github/basic-writing-and-formatting-syntax
