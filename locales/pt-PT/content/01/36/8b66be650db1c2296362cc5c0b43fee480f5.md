# Debug

Podes usar [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) para associar mensagens a testes que falham, assim:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

Num teste que falha, o registo associado será `secondsInOneHour: 3600`.

Há uma ressalva: as constantes de nível superior são avaliadas apenas uma vez, antes de os testes começarem a correr, por isso os testes não conseguem captar as suas mensagens de registo. Por exemplo:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

não vai registar nada durante os testes, porque a variável JavaScript associada a `secondsInOneHour` já foi avaliada para o valor 3600.
