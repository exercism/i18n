# Introdução

As condicionais são instruções que executam código diferente consoante uma condição seja `true` ou `false`.

Uma condicional `if` executa o seu corpo apenas quando a condição é `true`.
Go não tem o conceito de valores que possam ser avaliados como verdadeiros ou falsos, por isso a condição tem de ser do tipo `bool`.
Expressões como `if mySlice { ... }` ou `if 1 { ... }` são erros de compilação.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Usa `else if` para verificar condições adicionais, e `else` como alternativa se nenhuma se aplicar.
As condições são avaliadas de cima para baixo e só o primeiro ramo cuja condição seja verdadeira é executado.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Uma condicional `if` também pode incluir uma instrução curta de inicialização.
As variáveis declaradas desta forma só têm âmbito dentro da cadeia `if`/`else` completa.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
