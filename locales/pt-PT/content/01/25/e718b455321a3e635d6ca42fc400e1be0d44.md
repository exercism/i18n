# Instruções

Se queres construir algo com um Raspberry Pi, provavelmente vais usar _resistências_.
Para este exercício, precisas de saber duas coisas sobre elas:

- Cada resistência tem um valor de resistência.
- As resistências são pequenas. Tão pequenas que, se imprimisses nelas o valor de resistência, seria difícil de ler.

Para contornar este problema, os fabricantes imprimem faixas codificadas por cores nas resistências, para indicar os respetivos valores de resistência.
Cada faixa tem uma posição e um valor numérico.

As primeiras 2 faixas de uma resistência seguem um esquema de codificação simples: cada cor corresponde a um único número.

Neste exercício vais criar um programa útil para não teres de memorizar os valores das faixas.

Estas cores são codificadas da seguinte forma:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

O objetivo deste exercício é criar uma forma de:

- consultar o valor numérico associado a uma determinada faixa de cor
- listar as diferentes cores das faixas

As mnemónicas associam as cores aos números que, quando guardados num array, acabam por corresponder ao seu índice nesse array:
Better Be Right Or Your Great Big Values Go Wrong.

Podes encontrar mais informação sobre a codificação de cores das resistências no [artigo da Wikipédia sobre o código de cores eletrónico][e-color-code].

[e-color-code]: https://en.wikipedia.org/wiki/Electronic_color_code
