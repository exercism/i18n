# Instruções (apêndice)

## Formato da saída

Devolve a letra como uma string terminada em nulo.

## Registos

| Registo | Utilização   | Tipo    | Descrição                        |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada      | inteiro | verso inicial                 |
| `$a1`    | entrada      | inteiro | verso final                   |
| `$a2`    | entrada/saída | endereço | string de saída terminada em nulo |
| `$t0-9`  | temporário   | qualquer | para armazenamento temporário |
