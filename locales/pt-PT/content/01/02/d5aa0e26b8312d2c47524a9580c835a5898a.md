# Dicas

## Geral
- [Este tutorial][string-tutorial] é útil.
- [Documentação de referência][string-docs] para `String`.

## 1. Substituir espaços por underscores
- `String` disponibiliza uma função [replace][replace].

## 2. Substituir carateres de controlo pela string "[CTRL]" em maiúsculas
- Podes separar strings numa lista de strings com `String.split`
- Podes [concatenar][concat] ou [acrescentar][append] várias strings.

## 3. Converter kebab-case em camelCase
- Os literais de `char` são escritos entre plicas.
- [Char.toUpper][toUpper] converte um caráter em maiúscula.
- Considera usar funções de ordem superior para percorrer toda a string.

## 4. Omitir algarismos
- `Char` disponibiliza funções para detetar [algarismos][isDigit] e carateres [alfabéticos][isAlpha].

## 5. Omitir letras gregas minúsculas
- `Char` consegue transformar carateres [de/para os seus valores decimais Unicode][toCode].
- As [letras gregas][greek] minúsculas formam um bloco Unicode contíguo.
