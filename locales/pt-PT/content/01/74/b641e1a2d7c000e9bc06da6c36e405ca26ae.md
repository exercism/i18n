# usa recursão de cauda

O objetivo deste exercício é ensinar recursão de cauda. Resolve-o sem usares funções recursivas que não sejam de cauda.

Funções recursivas de cauda encontradas na tua solução: %{tail_call_recursive_functions}. Outras funções recursivas encontradas na tua solução: %{non_tail_call_recursive_functions}.

Lembra-te de que a recursão de cauda acontece quando a _última_ expressão avaliada pela função é uma chamada a si própria.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
