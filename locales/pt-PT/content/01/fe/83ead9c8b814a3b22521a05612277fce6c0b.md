# Funções

As funções são fundamentais em Cairo.

Por convenção, o Cairo usa **snake case** para nomes de funções e variáveis, em que as palavras são escritas em minúsculas e separadas por underscores.

Aqui tens um exemplo:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

As funções definem-se com `fn`, seguido de um nome, parênteses para os parâmetros (se existirem) e um corpo entre chavetas.

Podes chamar uma função pelo seu nome seguido de parênteses.

A ordem das funções não importa, desde que estejam no âmbito.

## Parâmetros

As funções podem receber **parâmetros**, que são variáveis definidas na assinatura da função.

Quando chamas a função, forneces **argumentos**, os valores passados a esses parâmetros.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

Aqui, `x` é um parâmetro do tipo `felt252`.

Quando é chamada com `5`, a função imprime "The value of x is: 5".

Vários parâmetros são separados por vírgulas:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

Isto imprime: `The measurement is: 5h`.

## Instruções e expressões

As funções em Cairo são compostas por **instruções** e **expressões**:

- As **instruções** executam ações, mas não devolvem valores.
Por exemplo, `let x = 3;` é uma instrução.
- As **expressões** resultam num valor.
Por exemplo, `5 + 6` dá `11`.

Os blocos entre chavetas também são expressões, e o seu valor final é devolvido:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

Aqui, `y` recebe o valor `4`.

## Valores devolvidos

As funções podem devolver valores usando a sintaxe `->` para especificar o tipo de retorno.

Por omissão, uma função devolve o valor da sua expressão final:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

Isto produz: `The value of x is: 5`.

Para casos mais complexos:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

Isto imprime: `The value of x is: 6`.

Não acrescentes um ponto e vírgula no fim da expressão final: transformaria a expressão numa instrução e a função devolveria `()` (tipo unit) em vez do valor esperado.
