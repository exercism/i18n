# Entry API

A Entry API é frequentemente a forma mais idiomática de manipular o conteúdo de uma estrutura de mapa. No entanto, ao contrário do que é habitual em Rust, não foi formalizada como uma trait: é apenas um conjunto de tipos e métodos implementados nos tipos de mapa da biblioteca padrão.

Na sua base, o método `map.entry()` fornece um `enum`:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

A utilidade vem dos restantes métodos implementados nesse enum. Por exemplo, imagina que queres obter o valor de uma determinada chave e, eventualmente, alterá-lo. Se o valor predefinido do tipo for adequado, basta fazer:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

Para aplicações como um contador, isto torna a vida muito mais fácil:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

Se o valor predefinido do tipo não for adequado à tua aplicação, podes indicar o teu próprio valor predefinido constante com `or_insert`, ou calcular um com `or_insert_with`.

Em certos casos, podes querer fazer um cálculo sobre um valor existente antes de eventuais inserções. Nesses casos, o `and_modify` permite-o. No entanto, este uso é relativamente raro. O `and_modify` é mais usado para evitar a necessidade de desreferenciar:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

Por vezes, é útil fazer match diretamente com a entry. Isto é permitido:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

Para mais informações, consulta [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) e [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html).
