# Expressões match

Uma expressão match avalia um valor e uma condição para devolver uma expressão a avaliar. Tal como um ternário, se a condição não corresponder, a expressão a devolver não é avaliada. Para corresponder a uma condição, é feita uma verificação de identidade [igualdade estrita ou `===`].

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

Para fazer uma verificação de igualdade [`==`], podes reorganizar a condição:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

Numa expressão match, se nenhuma condição corresponder, é lançado um `UnhandledMatchError`.
