## Geral

- [Documentação das listas][lists-docs]: documentação de referência para `List<T>`.

## 1. Cria uma nova lista

- As coleções genéricas são instanciadas como quaisquer outras, com o operador `new`. Lembra-te de substituir qualquer referência ao parâmetro genérico `T` pelo tipo dos itens da tua coleção.

## 2. Define uma lista existente

- Vê este [artigo][list-add] sobre como adicionar um item.

## 4. Conta as linguagens na lista

- Vê este [artigo][list-count] sobre como obter o número de itens numa lista.

## 5. Verifica se uma linguagem está na lista

- Vê este [artigo][list-contains] sobre como verificar se um item está numa lista.

## 6. Inverte a lista

- Vê este [artigo][list-reverse] sobre como inverter uma lista.

## 7. Verifica se a lista é interessante

- Vê este [artigo][list-item] sobre como obter um item pelo seu índice dentro da lista.

## 8.Remove a linguagem

- Vê este [artigo][list-remove] sobre como remover um item da lista.

## 9. Verifica se todas as linguagens da lista são únicas
