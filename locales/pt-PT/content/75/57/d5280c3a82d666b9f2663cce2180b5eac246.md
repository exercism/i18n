# Introdução

Um `Option` é um enum que serve para verificar a validade dos valores devolvidos pelas funções. É definido da seguinte forma:

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

Faz parte do pacote `haxe.ds`:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
