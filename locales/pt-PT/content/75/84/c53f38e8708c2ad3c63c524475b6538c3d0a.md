# Instruções

A Conda Airlines é a maior companhia aérea do mundo da programação, com mais de 10 000 voos por dia!

Neste momento, atribuem todos os assentos aos passageiros à mão; isto terá de ser automatizado.

Pediram-te a _ti_ que criasses um programa para automatizar a atribuição dos assentos aos passageiros.
Pedem que o teu programa seja eficiente em termos de memória e tenha um bom desempenho.

## 1. Gera as letras dos assentos

A Conda quer gerar as letras dos assentos dos seus aviões.
Um avião é composto por filas de assentos.
Cada fila tem _4 assentos_.
Os assentos de cada fila têm sempre os nomes `A`, `B`, `C` e `D`.
O primeiro assento da fila é `A`, o segundo é `B`, e assim por diante.
Depois de chegar a `D`, deve recomeçar com `A`.

Implementa uma função `generate_seat_letters(<number>)` que aceita um `int` com o número de letras de assentos a gerar.
A função deve depois devolver um _iterável_ de letras de assentos.

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. Gera assentos

A Conda quer um sistema capaz de gerar um determinado número de assentos para os seus aviões.
Cada avião tem _4 assentos_ em cada fila.
As filas são definidas por números, a começar em `1` e a aumentar.
Os assentos devem ser ordenados assim: `1A`, `1B`, `1C`, `1D`, `2A`, `2B`, `2C`, `2D`, `3A`, `3B`, `3C`, `3D`, ...

Eis um exemplo:

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|     Fila     |  5  | 21  |
| Letra do assento |  A  |  D  |
|   Resultado    | 5A  | 21D |

Muitas companhias aéreas não têm a _fila_ número 13 nos seus voos, devido à superstição dos passageiros.
A Conda Airlines também segue esta convenção, por isso certifica-te de que _não_ geras assentos para a _fila_ número 13.

Implementa uma função `generate_seats(<number>)` que aceita um `int` com o número de assentos a gerar.
A função deve depois devolver um _iterável_ com os assentos indicados.

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. Atribui assentos aos passageiros

Agora que tens uma função que gera assentos, podes usá-la para atribuir assentos aos passageiros.

Implementa uma função `assign_seats(<passengers>)` que aceita uma `list` com nomes de passageiros.
A função deve depois devolver um _dicionário_ em que `passenger` é a _chave_ e `seat_number` é o _valor_.

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. Códigos dos bilhetes

A Conda Airlines gostaria de ter um código único para cada bilhete.
Como são uma grande companhia aérea, têm muitos voos.
Isso significa que há vários voos com o mesmo número de assento.
Querem que cries um sistema que formule um bilhete único, uma string com _12_ carateres de comprimento.

Este código começa com o `assigned_seat` seguido do `flight_id`.
O resto do código é preenchido com `0s`.

Implementa uma função `generate_codes(<seat_numbers>, <flight_id>)` que aceita uma `list` de `seat_numbers` e uma `string` com o número do voo.
A função deve depois devolver um `generator` que produz um `ticket_number`.

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
