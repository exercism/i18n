# Dicas

## 1. Define um tipo Coord.

- `Coord` é uma `struct`.
- Os campos são `x` e `y`.
- Ambos têm o tipo `UInt16`

## 2. Define um tipo Plot.

- `Plot` é uma `struct` com a palavra-chave `struct`.
- Os campos são `bottom_left` e `top_right`.
- Ambos têm o tipo `Coord`.

## 3. Verifica se a tua reivindicação já foi registada.

- A reivindicação já é um elemento do `register`?
- Se for necessário, atualiza os teus conhecimentos sobre [`Sets`][sets].

## 4. Os especuladores podem reivindicar um lote, indicando as coordenadas dos seus cantos.

- Se a mesma reivindicação já tiver sido registada, devolve `false` para indicar que a tua reivindicação falhou.
- Se for permitido, adiciona a tua reivindicação ao registo. A função [`push!()][push] pode ser útil.
- Como `stake_claim!()` é uma função que altera o estado, as alterações no `register` serão visíveis para quem a chama.
- É permitido encadear a notação de ponto, como em `claim.bottom_left.x`.
- Devolve `true` para indicar sucesso.

## 5. Determina o comprimento do lado maior de um lote.

- Lembra-te da orientação destes lotes retangulares. Podes inferir as coordenadas `top_left` e `bottom_right`.
- Calcular o comprimento dos lados é aritmética simples.
- Tem atenção à diferença entre [`max()`][max] e [`maximum()`][maximum]. `max` recebe um número arbitrário de argumentos para comparar; `maximum` recebe um único iterável.

```julia-repl
julia> max(1, 2, 3)
3

julia> v = [1, 2, 3];
julia> maximum(v)
3
```

## 6. Encontra o lote reivindicado com o lado maior, para fins de investigação.

- O registo é um Set, não ordenado, mas iterável.
  - Pode ser conveniente converter o registo em algo ordenado, por exemplo com `collect()`.
  - Já escreveste uma função para calcular o lado maior de um lote, e podes aplicá-la a toda a coleção.
- Vê a tarefa 5 para uma nota sobre `max` versus `maximum`.
- Encontra um ou mais lotes com o comprimento máximo.
- Devolve os resultados como um `Set{Plot}`.
