# Dicas

## Geral

- No ['Guia de Introdução'][guide] do Elixir há uma boa revisão sobre funções nomeadas.

## 1. Cria a resposta quando o palpite coincide com o número secreto

- Podes usar uma [guarda][guard] para verificar se os números são iguais com `===/2`.

## 2. Cria a resposta quando o palpite é maior do que o número secreto

- Podes adicionar uma [cláusula de função][multiple-fn-clauses] e [guardas][guard] para verificar se o palpite é maior do que o número secreto com `>/2`.

## 3. Cria a resposta quando o palpite é menor do que o número secreto

- Podes adicionar uma [cláusula de função][multiple-fn-clauses] e [guardas][guard] para verificar se o palpite é menor do que o número secreto com `</2`.

## 4. Cria as respostas quando o palpite é um a mais ou um a menos do que o número secreto

- Podes adicionar uma [cláusula de função][multiple-fn-clauses] e [guardas][guard] para verificar se o palpite é um a menos ou um a mais do que o número secreto.
- As expressões de guarda podem usar `and/2` ou `or/2` para combinar expressões booleanas.
- Tem atenção à ordem das cláusulas de função.

## 5. Cria a resposta quando não há palpite

- Podes usar um [argumento por omissão][default-arg] para um palpite. O valor por omissão não tem de ser um número inteiro.
- Usa um cabeçalho de função antes de todas as outras cláusulas de função para definir o argumento por omissão.

[default-arg]: https://hexdocs.pm/elixir/modules-and-functions.html#default-arguments
[guard]: https://hexdocs.pm/elixir/Kernel.html#guards
[guide]: https://hexdocs.pm/elixir/modules-and-functions.html#function-definition
