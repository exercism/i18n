# Instruções

A tua tarefa é analisar coordenadas de GPS.
Cada coordenada é formatada usando a variante do [formato de graus decimais](https://en.wikipedia.org/wiki/Decimal_degrees) com hemisférios explícitos:

```text
<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>
```

Estes são os valores permitidos para cada componente individual:

- `<LATITUDE_DEGREES>`: um número de vírgula flutuante no intervalo 0..90 (inclusive)
- `<LATITUDE_HEMISPHERE>`: `N` ou `S`
- `<LONGITUDE_DEGREES>`: um número de vírgula flutuante no intervalo 0..180 (inclusive)
- `<LONGITUDE_HEMISPHERE>`: `E` ou `W`

Por exemplo, `"48.8584 N, 2.2945 E"` é analisado como:

- `<LATITUDE_DEGREES>`: 48.8584
- `<LATITUDE_HEMISPHERE>`: N
- `<LONGITUDE_DEGREES>`: 2.2945
- `<LONGITUDE_HEMISPHERE>`: E

Tens 11 tarefas, nas quais vais analisar coordenadas de GPS de forma incremental.
Vais usar o suporte do Prolog para [Gramáticas de Cláusulas Definidas](https://en.wikipedia.org/wiki/Definite_clause_grammar) (DCG), que são concebidas para analisar texto estruturado.

````exercism/note
Para te ajudar a começar, o ficheiro stub já inclui a [biblioteca `dcg/basics`](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) através de:

```prolog
:- use_module(library(dcg/basics)).
```
````

## 1. Analisar uma vírgula

Implementa a regra `comma` para analisar uma única vírgula (`","`):

```prolog
?- string_codes(",", Codes), phrase(comma, Codes).
```

## 2. Analisar um espaço

Implementa a regra `space` para analisar um único espaço (`" "`):

```prolog
?- string_codes(" ", Codes), phrase(space, Codes).
```

## 3. Suportar todos os espaços em branco (exceto novas linhas)

Modifica a regra `space` para analisar _todos_ os espaços em branco, exceto novas linhas:

```prolog
?- string_codes("\t", Codes), phrase(space, Codes).

?- string_codes("\n", Codes), phrase(space, Codes).
false.
```

## 4. Analisar o hemisfério da latitude

O hemisfério da latitude pode ser `"N"` ou `"S"`, que devem ser analisados para o átomo `north` ou `south`.
Implementa a regra `latitude_hemisphere` para analisar o hemisfério da latitude:

```prolog
?- string_codes("N", Codes), phrase(latitude_hemisphere(Hemisphere), Codes).
Hemisphere = north.
```

## 5. Analisar o hemisfério da longitude

O hemisfério da longitude pode ser `"E"` ou `"W"`, que devem ser analisados para o átomo `east` ou `west`.
Implementa a regra `longitude_hemisphere` para analisar o hemisfério da longitude:

```prolog
?- string_codes("E", Codes), phrase(longitude_hemisphere(Hemisphere), Codes).
Hemisphere = east.
```

## 6. Analisar graus

Os graus de uma longitude ou latitude são definidos como um número de vírgula flutuante.
Implementa a regra `degrees` para analisar números de vírgula flutuante:

```prolog
?- string_codes("748.012", Codes), phrase(degrees(Degrees), Codes).
Degrees = 748.012.
```

## 7. Analisar graus de latitude

Os graus de latitude não são apenas números de vírgula flutuante: são números de vírgula flutuante no intervalo 0..90 (inclusive).
Implementa a regra `latitude_degrees` para analisar graus de latitude usando o intervalo acima:

```prolog
?- string_codes("48.745", Codes), phrase(latitude_degrees(Degrees), Codes).
Degrees = 48.745.

?- string_codes("117.844", Codes), phrase(latitude_degrees(Degrees), Codes).
false.
```

## 8. Analisar graus de longitude

Os graus de longitude não são apenas números de vírgula flutuante: são números de vírgula flutuante no intervalo 0..180 (inclusive).
Implementa a regra `longitude_degrees` para analisar graus de longitude usando o intervalo acima:

```prolog
?- string_codes("178.773", Codes), phrase(longitude_degrees(Degrees), Codes).
Degrees = 178.773.

?- string_codes("-22.523", Codes), phrase(longitude_degrees(Degrees), Codes).
false.
```

## 9. Analisar a latitude

As latitudes têm duas partes: os graus e o hemisfério, que são separados por um espaço.
Implementa a regra `latitude` para analisar uma latitude:

```prolog
?- string_codes("56.101 N", Codes), phrase(latitude(Degrees, Hemisphere), Codes).
Degrees = 56.101,
Hemisphere = north.
```

## 10. Analisar a longitude

As latitudes têm duas partes: os graus e o hemisfério, que são separados por um espaço.
Implementa a regra `latitude` para analisar uma latitude:

```prolog
?- string_codes("143.889 W", Codes), phrase(longitude(Degrees, Hemisphere), Codes).
Degrees = 143.889,
Hemisphere = west.
```

## 11. Analisar a coordenada

As coordenadas têm duas partes: a latitude e a longitude, que são separadas por uma vírgula seguida de um espaço.
Implementa a regra `coordinate` para analisar tanto a latitude (graus e hemisfério):

```prolog
?- string_codes("48.8584 N, 2.2945 E", Codes), phrase(coordinate(Latitude, LatitudeHemisphere, Longitude, LongitudeHemisphere), Codes).
Latitude = 48.8584,
LatitudeHemisphere = north,
Longitude = 2.2945,
LongitudeHemisphere = east.
```
