# Instruções

Era uma vez um programador excêntrico que vivia numa casa estranha com janelas gradeadas.
Um dia, aceitou um trabalho através de um site de ofertas de emprego online para construir um robô de festas.
O robô devia cumprimentar as pessoas e ajudá-las a chegar aos seus lugares.
A primeira edição era muito técnica e revelava a falta de interação humana do programador.
Algumas dessas caraterísticas também passaram para a edição seguinte.

## 1. Dá as boas-vindas a um novo convidado da festa

Implementa a função `Welcome` para devolver uma mensagem de boas-vindas usando o nome indicado:

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. Dá as boas-vindas a um novo convidado da festa que faz anos hoje

Implementa a função `HappyBirthday` para devolver uma mensagem de aniversário usando o nome e a idade indicados da pessoa.
Infelizmente, o programador é um pouco exibicionista, por isso o robô tem de demonstrar que sabe o aniversário de todos os convidados.

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. Dá indicações

Implementa a função `AssignTable` para dar indicações.
Deve aceitar 5 parâmetros.

- O nome do novo convidado a cumprimentar (`string`)
- O número da mesa (`int`)
- O nome da pessoa que se senta ao lado (`string`)
- A direção onde encontrar a mesa (`string`)
- A distância até à mesa (`float64`)

Podes ver o formato exato do resultado no exemplo abaixo.

O robô apresenta o número da mesa num formato de 3 algarismos.
Se o número tiver menos de 3 algarismos, recebe zeros à esquerda adicionais até ficar com 3 algarismos (por exemplo, 3 torna-se 003).
O robô também menciona a distância até à mesa.
Felizmente, apenas com uma precisão limitada a 1 algarismo.

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
