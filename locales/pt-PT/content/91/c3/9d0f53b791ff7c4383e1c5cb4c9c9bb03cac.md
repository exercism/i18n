# Instruções

A Elyse, aspirante a maga, continua o seu treino.
Vão ser-lhe dados vários baralhos de cartas de que precisa para fazer os seus truques.
Para facilitar um pouco as coisas, só usa as cartas de 1 a 10.
Tem apenas uma carta de cada, não há cartas repetidas nos seus baralhos.

Neste exercício, usa métodos da biblioteca Base da Julia para analisar o conteúdo de um array.

## 1. Determina se uma carta está presente

A Elyse quer determinar se uma carta está presente no baralho, ou seja, se o baralho contém um número específico.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. Encontra a posição de uma carta

A Elyse quer saber a posição (o índice) de uma carta no baralho.
Se a carta não estiver no baralho, devolve `nothing`.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. Determina se cada carta é par

A Elyse quer saber se todas as cartas são pares, ou seja, se cada número do baralho é par.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. Verifica se o baralho contém uma carta de valor ímpar

A Elyse quer saber se há um número ímpar no baralho.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. Determina a posição da primeira carta par

A Elyse quer saber a posição da primeira carta par.
Se não houver cartas pares no baralho, devolve `nothing`.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. Obtém a primeira carta ímpar do baralho

A Elyse quer saber o valor da primeira carta ímpar.
Se não houver cartas ímpares no baralho, devolve `nothing`.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
