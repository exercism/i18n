# Acerca de

Um `SYMBOL:` não *guarda* um valor: é apenas um nome. O valor vive num espaço de nomes, e o nome funciona como chave para lá chegar.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Dois âmbitos:

- **global** — escrito/lido com `set-global`, `get-global`,
  `change-global`. Os valores persistem durante todo o tempo de vida do
  processo.
- **dinâmico** — escrito/lido com `set`, `get`, `change`.
  As ligações duram o tempo de execução de uma forma `with-variable`,
  permitindo que o código exterior "injete" um valor que o código
  interior vê, sem alterar todas as assinaturas pelo meio.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:` e `SYMBOLS:` declaram símbolos no momento em que o vocabulário
é carregado, o que os torna referências partilháveis entre ficheiros.
