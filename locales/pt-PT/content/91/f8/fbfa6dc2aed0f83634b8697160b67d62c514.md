# About

Os números de vírgula flutuante são números fracionários ou inteiros que incluem uma vírgula decimal (como `3.14`, `-1.7`, `99.99`, `2048.0`)

O tipo float em Common Lisp subdivide-se em vários subtipos, cada um com as suas próprias características e precisão: short-float, single-float, double-float e long-float.

O subtipo short-float ocupa, tipicamente, a menor quantidade de memória e oferece a precisão mais baixa dos quatro subtipos. É adequado para situações em que o uso de memória é uma preocupação, mas uma precisão menor é aceitável.

O subtipo single-float oferece um equilíbrio entre o uso de memória e a precisão. É comummente usado para cálculos de vírgula flutuante de uso geral.

O subtipo double-float oferece uma precisão superior à do single-float e é adequado para aplicações que exigem cálculos mais precisos, como cálculos científicos e simulações numéricas.

O subtipo long-float oferece a precisão mais elevada dos quatro subtipos, mas pode exigir mais memória do que os outros. É normalmente usado para aplicações especializadas que exigem cálculos extremamente precisos.

Estes subtipos permitem aos programadores de Common Lisp escolher o nível adequado de precisão e de uso de memória de acordo com os requisitos das suas aplicações específicas.

Em geral, se trabalhas apenas com números inteiros, deves dar preferência aos inteiros, uma vez que não sofrem a mesma perda de precisão que os números de vírgula flutuante sofrem ao longo de muitos cálculos.

## Reference

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
