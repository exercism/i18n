# Dicas

## Geral

- `bitor`, `bitand`, `bitxor`, `bitnot` e `shift` vivem todos em
  [`math`][math].
- `bits` está em [`math.bitwise`][bitwise].
- Uma das entradas dos testes é um valor `Int32` negativo, por isso
  certifica-te de que o teu `shift-back` produz um deslocamento para a
  direita *lógico* (preenchimento com zeros) e não aritmético.

## 1. Desloca os bits de volta

- `shift` recebe uma quantidade *com sinal*: uma quantidade negativa
  desloca para a direita.
- Para um valor positivo, `value amount neg shift` já dá o resultado
  esperado.
- Para um valor negativo, `shift` faria extensão de sinal. Usa primeiro
  `32 bits` para reinterpretar o valor como um inteiro sem sinal de
  32 bits e depois desloca: o resultado não é negativo e preenche com
  zeros naturalmente.

## 2. Ativa alguns bits

- Ativa-se um bit fazendo um OR com uma máscara. O `bitor` retira os
  dois valores da pilha e deixa o resultado.

## 3. Inverte bits específicos

- O ou-exclusivo de `value` e `mask` inverte os bits em que a máscara
  é 1 e deixa os outros como estão. A palavra é `bitxor`.

## 4. Limpa bits específicos

- O `bitand` simples mantém os bits que são 1 em ambos os operandos,
  ou seja, o oposto do que queres. Inverte primeiro a máscara com
  `bitnot` e só depois usa o `bitand`.
