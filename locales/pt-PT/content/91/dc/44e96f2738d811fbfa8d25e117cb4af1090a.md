# Instruções

Como entusiasta de xadrez, queres escrever a tua versão do jogo.
Sim, já deve haver imensas implementações de xadrez disponíveis online, mas a tua vai ser única!

Começas por implementar um sistema básico de movimento para as peças.

O jogo de xadrez vai ser jogado num tabuleiro com oito casas de largura e oito casas de comprimento.
As casas são identificadas por uma letra e um número.

## 1. Define o intervalo de linhas e colunas

O jogo vai ter de guardar as linhas do tabuleiro.
As linhas são as filas do tabuleiro e estão numeradas de 1 a 8.

O jogo também vai ter de guardar as colunas do tabuleiro.
As colunas são as filas verticais do tabuleiro e são identificadas pelas letras A a H.

Define as constantes `Chess::RANKS` e `Chess::FILES`, que guardam, respetivamente, o intervalo das linhas e das colunas.

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Verifica se a casa é válida

O jogo vai ter de verificar se uma casa é válida.
Uma casa é válida se a linha e a coluna estiverem dentro dos intervalos das linhas e das colunas.

Define o método `Chess.valid_square?`, que recebe os argumentos `rank`, que contém um int com a linha, e `file`, que contém um char com a coluna.
O método deve devolver `true` se a linha e a coluna estiverem dentro do intervalo das linhas e das colunas, e devolver `false` caso contrário.

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. Obtém a alcunha do jogador

O jogo vai ter de obter a alcunha do jogador.
A alcunha é formada pelos dois primeiros carateres do primeiro nome do jogador e pelos dois últimos carateres do apelido.
A alcunha deve ser escrita em maiúsculas.

Define o método `Chess.nickname`, que recebe os argumentos `first_name`, que contém uma string com o primeiro nome do jogador, e `last_name`, que contém uma string com o apelido do jogador.
O método deve devolver a alcunha do jogador como uma string em maiúsculas.

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Cria a mensagem de uma jogada

O jogo vai ter de criar uma mensagem para uma jogada, a indicar que jogador se moveu para que casa.
A mensagem deve usar a alcunha do jogador e a casa para onde ele se moveu.
O jogo também tem de determinar se a jogada é válida, verificando se a coluna e a linha da casa estão dentro dos intervalos das colunas e das linhas.

Se a jogada for válida, a mensagem deve ser: `"{nickname} moved to {square}"`
Se a jogada for inválida, a mensagem deve ser: `"{nickname} attempted to move to {square}, but that is not a valid square"`

Define o método `Chess.move_message`, que recebe os argumentos `first_name`, que contém uma string com o primeiro nome do jogador, `last_name`, que contém uma string com o apelido do jogador, e `square`, que contém uma string com a casa para onde o jogador se moveu.
O método deve devolver a mensagem da jogada como uma string.

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
