# Depuração

Quando um teste falha, aparece uma mensagem que descreve o que correu mal e para que valor de entrada.
Também podes usar o facto da [saída para a consola][fmt-println] também ser mostrada.
Podes escrever para a consola com:

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

Nota: quando estás a depurar com o editor no navegador, usar, por exemplo, `fmt.Print` não acrescenta uma nova linha depois da saída, o que pode provocar um bug no `go test --json` e resultar numa saída de testes confusa.
