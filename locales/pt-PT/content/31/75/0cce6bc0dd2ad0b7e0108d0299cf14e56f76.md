# Apêndice das instruções

## Valor devolvido

Devolve um dos seguintes números inteiros:

| Classificação | Devolução |
|---------------|-----------|
| não positivo  | 0         |
| deficiente    | 1         |
| perfeito      | 2         |
| abundante     | 3         |

## Endereços reservados

Não é necessária memória linear para este exercício.
