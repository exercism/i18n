# Dicas

## Geral

- Lê sobre a [recursividade, do criador do Elm][recursion].
- Usa correspondência de padrões com expressões `case`.
- Tenta dividir um problema num caso base e num caso recursivo. Por exemplo, imagina que queres contar quantos biscoitos há no pote de biscoitos com uma abordagem recursiva. O caso base é um pote vazio: tem zero biscoitos. Se o pote não estiver vazio, o número de biscoitos no pote é igual a um biscoito mais o número de biscoitos no pote depois de retirares um biscoito.

## 1. Verifica quantas aves visitaram hoje

- Esta tarefa não precisa de recursividade.
- Podes aceder ao primeiro elemento de uma lista através de correspondência de padrões com uma expressão `case`.
- Lembra-te de envolver o resultado em `Just` quando devolves um valor.

## 2. Incrementa a contagem de hoje

- Esta tarefa não precisa de recursividade.
- Podes aceder ao primeiro elemento de uma lista através de correspondência de padrões com uma expressão `case`.
- Usa o [operador `::`][list-cons] para desconstruir e reconstruir a nova lista.

## 3. Verifica se houve um dia sem aves visitantes

- Usa recursividade para iterar sobre os elementos da lista até encontrares um dia sem aves visitantes.
- Os casos base são uma lista vazia ou um dia sem aves.
- Usa correspondência de padrões para verificar se há `0` na lista.

## 4. Calcula o número total de aves visitantes

- Usa recursividade para iterar sobre cada elemento da lista.
- O caso base é uma lista vazia.
- Usa o operador `+` para somar o elemento atual ao total do resto.

## 5. Calcula o número de dias movimentados

- Usa recursividade para iterar sobre cada elemento da lista.
- O caso base é uma lista vazia.
- Usa uma expressão `if` para verificar se o dia atual é movimentado (5 aves ou mais).
- Quando encontras um dia movimentado, soma 1 à contagem de dias movimentados no resto da lista.
