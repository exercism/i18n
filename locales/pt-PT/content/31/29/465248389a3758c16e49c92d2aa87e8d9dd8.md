# Evita instruções de impressão

Tenta remover do teu código instruções como `System.out.println()`.
Os testes do exercício exigem que a solução _devolva_ valores a partir dos métodos, em vez de os imprimir.

Normalmente, instruções como estas são adicionadas para ajudar a depurar o código.
No entanto, uma abordagem melhor é depurar o código enquanto executas um ou mais testes unitários.
Isto tem a vantagem adicional de te permitir concentrares-te em depurar um caso de teste específico.

Aqui ficam alguns links que explicam como depurar código Java enquanto executas testes unitários em várias IDEs:

- [Executar e depurar testes Java no Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Depurar testes no IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
