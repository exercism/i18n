# Introdução

## Noções básicas

Para iniciar a viagem pelo C++, vamos começar com variáveis, chamadas de funções e comentários.

### Comentários

Há dois tipos de comentários: de uma linha e de várias linhas.
Tudo o que vem depois de `//` na mesma linha é ignorado pelo compilador.
Os comentários de várias linhas também são conhecidos como comentários ao estilo C.
São delimitados por `/*` e `*/`.
Tudo o que fica entre eles também é ignorado.

### Variáveis

O C++ é uma linguagem com tipos.
Todos os tipos têm de ser conhecidos em tempo de compilação e, regra geral, tens de os indicar explicitamente.
O tipo de uma variável não pode mudar.
Uma variável inteira com o nome `years` pode ser declarada assim:

```cpp
int years;
```

É boa prática inicializar as variáveis na declaração.
O C++ oferece diferentes mecanismos para o fazer.
A versão com chavetas está mais alinhada com o C++ moderno, mas a versão com o sinal de igual também é muito comum.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
O C++ permite, de facto, usar variáveis não inicializadas.
Enquanto não atribuíres um valor à variável de forma deliberada, esta fica indefinida e pode conter qualquer coisa.
Para evitares erros de utilização antes da atribuição e comportamentos indefinidos, é aconselhável **inicializar sempre**.
Um comportamento indefinido pode fazer o teu programa rebentar no pior momento possível, mesmo quando antes estava a correr bem.
Nunca é demais repetir: evita comportamentos indefinidos a todo o custo.
~~~~

### Operações aritméticas

Os operadores aritméticos como `*`, `+` ou `-` podem fazer parte de uma expressão como `3 * 2` ou `tomatoes + potatoes`.

### Atualizar variáveis

Podes reatribuir variáveis, desde que mantenham o tipo:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

### Funções

As funções têm um nome, um tipo de retorno e uma lista de parâmetros (possivelmente vazia).
Um exemplo de uma função chamada `always_fortyseven`, que devolveria sempre 47, seria assim:

```cpp
int always_fortyseven() {
    return 47;
}
```

Eis a `vip_fee`, que tem um parâmetro:

```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Ou a `total_fee`, uma função com três parâmetros e uma chamada a outra função.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

Em C++, as funções não devolvem o valor da última instrução, ao contrário do que acontece noutras linguagens.
A palavra-chave `return` é obrigatória para o código compilar.

### Espaços em branco

Os espaços em branco são usados para formatar o código-fonte e incluem espaços, tabulações e mudanças de linha.
Como o compilador ignora os espaços em branco desnecessários, podes usá-los para estruturar o teu código.
Um uso inteligente dos espaços em branco pode melhorar a legibilidade do teu código.
Existem diferentes normas de formatação, mas são todas convencionais e não são impostas pelo compilador.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
