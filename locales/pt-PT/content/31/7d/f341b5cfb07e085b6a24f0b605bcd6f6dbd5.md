# Instalação

## Instalar o Node.js

**Utilizadores de Windows e OS X**: instala o [Node.js][node] [através do gestor de pacotes][node-download].

**Utilizadores de Linux**: instala o [Node.js][node] seguindo as instruções da tua distribuição na [página de gestores de pacotes do Node.js][linstall].

## Instalar o `jasmine-node` e o `coffeescript`

Para a maioria dos utilizadores, isto resume-se a executar o seguinte comando:

```bash
$ npm install -g jasmine-node coffeescript
```

Dependendo da tua configuração, podes precisar de privilégios de superutilizador para instalar um módulo `npm` globalmente.
É o caso se tiveres usado o instalador oficial indicado acima.
Se o NPM te der um erro a dizer que não tens acesso, acrescenta `sudo` ao comando acima:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

Se usaste o instalador oficial, o teu `PATH` deve ter sido configurado automaticamente. Mas se a tua shell tiver dificuldade em encontrar os módulos que instalaste globalmente, ou se compilaste o Node.js a partir do código-fonte, atualiza o teu `PATH` para incluir os binários do `npm`, acrescentando o seguinte a `~/.bash_profile` ou a `~/.zshrc`:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
