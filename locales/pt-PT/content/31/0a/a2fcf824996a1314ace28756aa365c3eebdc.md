# converter um ponto de código diretamente numa string

A forma mais simples de converter o ponto de código de um caráter numa string com esse caráter é usar a forma especial `<<>>`. Não é preciso usar uma charlist como passo intermédio.

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
