# Instruções

A Elaine está a trabalhar num novo jogo infantil que tem animais e varinhas mágicas.
Está na altura de programar funções para lançar um dado, gerar energia aleatória para as varinhas e baralhar um slice.

## 1. Lançar um dado

Implementa uma função `RollADie`.

Será o tradicional dado de vinte faces, com os números de 1 a 20.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. Gerar energia para as varinhas

Implementa uma função `GenerateWandEnergy`.
A energia da varinha deve ser um número de vírgula flutuante aleatório igual ou superior a 0.0 e inferior a 12.0.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. Baralhar um slice

O jogo tem oito animais diferentes:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

Escreve uma função `ShuffleAnimals` que devolve um slice com os oito animais por ordem aleatória.
