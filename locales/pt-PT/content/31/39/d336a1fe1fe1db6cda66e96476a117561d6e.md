# Anexo às instruções

## Implementação

Define uma única função, SolvePuzzle, que devolve uma solução
com duas strings, cujos valores são as respostas às perguntas
do enigma da zebra: «Quem bebe água?» e «Quem é o dono da zebra?».
Cada resposta será uma das nacionalidades dos moradores:
Englishman, Spaniard, Ukrainian, Norwegian ou Japanese.

Obviamente, podias escrever uma função de uma só linha
se espreitasses o programa de testes para ver a solução esperada.
Mas o objetivo é desenvolveres um algoritmo que use
os factos e as restrições fornecidos pelo enigma
e determine as duas respostas corretas.
