# Sobre

As [classes](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) são o principal mecanismo para fazer programação orientada a objetos em F#.

Uma classe em F# é composta pelos seus campos e métodos. Os campos e métodos de uma classe são designados por _membros_.

As classes em F# definem-se com a palavra-chave `type`. Os métodos definem-se com a palavra-chave `member` e são sempre públicos. Para definir campos (privados), podes usar associações `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

As classes são modelos para criar objetos. Para criar uma instância de uma classe, invoca o nome da classe como se fosse uma função. Uma instância de uma classe também é designada por _objeto_.

Podes aceder aos membros de um objeto com a notação de ponto.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
