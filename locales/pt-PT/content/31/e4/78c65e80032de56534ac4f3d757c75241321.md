# Introdução

Em Go, uma aplicação organiza-se em pacotes.
Um pacote é um conjunto de ficheiros de código-fonte que estão na mesma pasta.
Todos os ficheiros de código-fonte de uma pasta têm de ter o mesmo nome de pacote no topo do ficheiro.
Por convenção, os pacotes têm o mesmo nome da pasta onde estão.

```go
package greeting
```

O Go disponibiliza uma vasta biblioteca padrão de pacotes, que podes usar no teu programa com a palavra-chave `import`.
Os pacotes da biblioteca padrão importam-se pelo respetivo nome.

```go
package greeting

import "fmt"
```

Depois, referes-te a um pacote importado pelo nome do pacote:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

O Go determina se um elemento pode ser chamado por código de outros pacotes pela forma como é declarado.
Para tornar uma função, um tipo, uma variável, uma constante ou um campo de struct visíveis externamente (diz-se que são _exportados_), o nome tem de começar por uma letra maiúscula.
Isto é análogo à forma como outras linguagens de programação, como o Java, usam modificadores de acesso como `public` e `private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
