# Introdução

## Filtragem de exceções

`when` é a palavra-chave para filtrar exceções. Coloca-se depois da instrução catch e pode receber uma expressão Boolean que contenha quaisquer valores que estejam no âmbito naquele momento. Se a expressão for avaliada como true, o bloco associado a essa instrução `catch` é executado; caso contrário, verifica-se a instrução `catch` seguinte, se existir.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## Exceções definidas pelo utilizador

Uma exceção definida pelo utilizador é qualquer classe definida no teu código que derive de `System.Exception`. Está sujeita a todas as regras de herança de classes, mas, além disso, o compilador e o runtime da linguagem tratam estas classes de uma forma especial, que permite que as suas instâncias sejam lançadas e capturadas fora do fluxo de controlo normal, como se explica no exercício `exceptions`.

As exceções definidas pelo utilizador são frequentemente usadas para transportar informação extra, como uma mensagem e outros dados relevantes, que fica disponível para as rotinas que as capturam.
