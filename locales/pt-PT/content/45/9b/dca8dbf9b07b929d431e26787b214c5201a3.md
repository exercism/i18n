# Testes

O percurso de Factor usa o **Factor 0.101**. Cada exercício vem com um vocabulário `exercism-tools` incluído que define as palavras de análise `STOP-HERE` e `TASK:`, além de um executor de testes. A partir do diretório do exercício, executa:

```
factor -roots=. -run=exercism-tools <exercise>
```

Por exemplo, para o exercício `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

O executor termina com um código de saída 0 quando todos os testes passam e com um código diferente de zero, acompanhado de uma saída de diagnóstico, quando algum teste falha.

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem.
Por predefinição, só é executado um teste (o primeiro) quando executas os testes.
Isto é intencional, pois permite-te concentrar-te apenas em fazer esse teste passar.

O mecanismo é a linha `STOP-HERE` no ficheiro de testes: no momento da análise, diz ao Factor para ignorar tudo o que está abaixo dela, por isso o executor só vê os testes que ficam acima. Assim que o teu primeiro teste passar, podes ativar mais testes de duas formas:

- **Apaga a linha `STOP-HERE`** para ativares de uma vez todos os testes que faltam.
- **Move a linha `STOP-HERE` mais para baixo** para ativar os testes um a um, ou uma tarefa de cada vez. Os exercícios de conceitos agrupam os testes sob marcadores `TASK:`. Mover a linha `STOP-HERE` para imediatamente antes do próximo `TASK:` é um passo natural.

Quando tiveres ativado todos os testes e a tua implementação os fizer passar todos, resolveste o exercício!
