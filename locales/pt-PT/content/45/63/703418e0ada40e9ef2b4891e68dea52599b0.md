# Sobre

Em Elixir, para escolher um elemento aleatório de uma estrutura de dados enumerável (por exemplo, listas, intervalos), usamos [`Enum.random/1`][enum-random]. Esta função escolhe um único elemento, com todos os elementos a ter a mesma probabilidade de serem escolhidos. Escolher um único valor aleatório de um intervalo é executado em tempo constante, sem percorrer o intervalo todo.

## Inteiros e letras aleatórios

- Escolher um número inteiro aleatório
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- Escolher uma letra aleatória como string
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- Escolher uma letra aleatória como charlist
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

Para escolher mais do que um elemento de uma estrutura de dados enumerável, usa [`Enum.take_random/2`][enum-take-random]. Para ordenar uma estrutura de dados enumerável por uma ordem aleatória, usa [`Enum.shuffle/1`][enum-shuffle].

## Números de vírgula flutuante aleatórios

O Elixir não tem funções próprias para escolher um número de vírgula flutuante aleatório. Para isso, temos de usar o módulo [`rand`][erl-rand] do Erlang, que, por acaso, é também o que o `Enum.random` usa nos bastidores.

- Escolher um número de vírgula flutuante aleatório (maior ou igual a 0.0 e menor do que 1.0):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- Escolher um número de vírgula flutuante aleatório (maior ou igual a `a` e menor do que `b`):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## Distribuição normal

Todas as funções mencionadas acima escolhem um valor aleatório com todos os valores possíveis a terem a mesma probabilidade de serem escolhidos. A isso chama-se uma _distribuição uniforme_. O módulo `rand` também oferece as funções [`normal/0`][erl-rand-normal-0] e [`normal/2`][erl-rand-normal-2], que escolhem um número de vírgula flutuante aleatório com uma [distribuição normal][normal-distribution].

## Semente

É importante perceber que os valores "aleatórios" são gerados por um [gerador de números _pseudo_-aleatórios][prng]. Um PRNG é um algoritmo que, dado um valor inicial chamado _semente_, gera uma sequência de números que parece aleatória, mas que não é aleatória de todo.

Este facto pode ser útil para depurar código. Podes forçar o gerador de números _pseudo_-aleatórios do Erlang (e, por consequência, o do Elixir) a produzir os mesmos valores de sequência, redefinindo a sua semente com [`:rand.seed/2`][rand-seed-2]. O primeiro argumento é um algoritmo PRNG específico, e o segundo é um tuplo de três inteiros, a semente.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## Criptografia

Os valores aleatórios devolvidos pelo `Enum.random` e pelo módulo `rand` do Erlang não são [criptograficamente seguros][cryptographically-secure-rng]. Não os uses para gerar chaves criptográficas, palavras-passe ou nonces. Para este caso de uso, existe a função [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes] do Erlang.
