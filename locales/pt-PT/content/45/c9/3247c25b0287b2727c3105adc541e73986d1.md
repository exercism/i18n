# Introdução

## Pacotes

Em Go, uma aplicação está organizada em pacotes.
Um pacote é uma coleção de ficheiros de código-fonte que estão na mesma pasta.
Todos os ficheiros de código-fonte de uma pasta têm de ter o mesmo nome de pacote no topo do ficheiro.
Por convenção, os pacotes têm o mesmo nome da pasta onde estão.

```go
package greeting
```

O Go disponibiliza uma extensa biblioteca padrão de pacotes, que podes usar no teu programa com a palavra-chave `import`.
Os pacotes da biblioteca padrão são importados pelo seu nome.

```go
package greeting

import "fmt"
```

Um pacote importado é depois referido pelo nome do pacote:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

O Go determina se um item pode ser chamado por código de outros pacotes através da forma como é declarado.
Para tornar uma função, um tipo, uma variável, uma constante ou um campo de struct visíveis externamente (o que se chama _exportado_), o nome tem de começar com uma letra maiúscula.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## Formatação de strings

O Go disponibiliza um pacote incorporado chamado `fmt` (pacote de formatação), que oferece várias funções para manipular o formato da entrada e da saída.
A função mais usada é a `Sprintf`, que usa verbos como `%s` para interpolar valores numa string e devolve essa string.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Em Go, os números de vírgula flutuante formatam-se de forma conveniente com os verbos da Sprintf: `%g` (representação compacta), `%e` (expoente) ou `%f` (sem expoente).
Os três verbos permitem controlar a largura do campo e a posição numérica.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Encontras a lista completa dos verbos disponíveis na [documentação do pacote de formatação][fmt-docs].

O `fmt` contém outras funções para trabalhar com strings, como a `Println`, que simplesmente imprime na consola os argumentos que recebe, e a `Printf`, que formata a entrada da mesma forma que a `Sprintf` antes de a imprimir.

[fmt-docs]: https://pkg.go.dev/fmt
