# Testes

## Preparação

Segue as [instruções de instalação para JavaScript][docs-exercism-javascript] para instalares as dependências necessárias.

## Requisitos

Instala as dependências do exercício:

```shell
corepack pnpm install
```

Se o `corepack` se queixar de não estar ativado, podes ativá-lo executando:

```bash
corepack enable pnpm
```

## Fazer passar o conjunto de testes

Todos os exercícios incluem um conjunto de testes que te ajuda a validar a tua solução antes de a submeteres.
Podes executar estes testes abrindo uma linha de comandos na pasta do exercício e executando:

```bash
corepack pnpm test
```

Em alguns conjuntos de testes, todos os testes, exceto o primeiro, estão ignorados.

Assim que conseguires passar num teste, podes ativar o seguinte mudando `xtest` para `test`.

## Escrever testes personalizados

Se quiseres escrever testes adicionais e personalizados, cria um ficheiro novo, `custom.spec.js`, e submete-o juntamente com a tua solução:

```shell
exercism submit numbers.js custom.spec.js
```

[docs-exercism-javascript]: https://exercism.org/docs/tracks/javascript/installation
