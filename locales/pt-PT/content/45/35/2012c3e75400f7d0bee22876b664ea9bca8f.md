# Declaração de tipos

O PHP é uma linguagem de tipos dinâmicos, o que significa que uma variável pode conter qualquer tipo de informação.
No entanto, o PHP permite uma declaração forte de tipos _opcional_ para propriedades de classes, argumentos de funções e valores devolvidos por funções.
As declarações fortes de tipos em PHP fazem asserções de tipo em tempo de execução; no entanto, o PHP tenta forçar os tipos escalares a corresponder à declaração, sempre que possível.
O comportamento de coerção pode ser desativado com a declaração `strict_types` no topo do ficheiro.

```php
<?php
declare(strict_types=1);
```

Além disso, uma função pode declarar o tipo de retorno `void`, para indicar que não devolve nenhum valor.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Uniões de tipos

Se um argumento de função, um valor devolvido ou uma propriedade de classe puder ser de mais do que um tipo, é possível declarar uma união de tipos.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Tipos mistos

Ao trabalhar com código, nem sempre é possível especificar um tipo.
A partir do PHP 8.0, existe um tipo de escape chamado `mixed`.
O `mixed` é equivalente a uma união de tipos `object|resource|array|string|float|int|bool|null`.
