# Introdução

Em Go, as funções são valores de primeira classe.
Isto significa que podes fazer com as funções as mesmas coisas que fazes com todos os outros valores: atribuir funções a variáveis, passá-las como argumentos a outras funções ou até devolver funções a partir de outras funções.

Abaixo criamos duas funções, `engGreeting` e `espGreeting`, e atribuímo-las à variável `greeting`:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Os valores de função permitem parametrizar funções não só com dados, mas também com comportamento.
No exemplo seguinte, passamos comportamento à função `dialog` através do parâmetro `greetingFunc`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

O valor de uma variável não inicializada de tipo função é `nil`.
Por isso, chamar um valor de função `nil` provoca um panic.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Os valores de função podem ser comparados com `nil`.
Isto pode ser útil para evitar panics desnecessários no programa.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Tipos de função

Usar valores de função é possível graças aos tipos de função em Go.
Um tipo de função representa o conjunto de todas as funções com a mesma sequência de tipos de parâmetros e a mesma sequência de tipos de resultado.
É possível declarar tipos definidos pelo utilizador com base em tipos de função.
Por exemplo, a função `dialog` dos exemplos anteriores pode ser atualizada da seguinte forma:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Funções anónimas

Outra ferramenta poderosa que está disponível graças ao suporte a funções de primeira classe são as funções anónimas.
As funções anónimas são definidas no ponto em que são usadas, sem um nome a seguir à palavra-chave `func`.
Estas funções têm acesso às variáveis da função que as envolve.

Por exemplo:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Uma chamada a `fib` declara as variáveis `n1` e `n2` e devolve uma função anónima que, por sua vez, altera os valores dessas variáveis sempre que a função é chamada.
A n-ésima chamada da função anónima devolve o n-ésimo número da sequência de Fibonacci, começando em 0. A função anónima interior tem acesso às variáveis locais (`n1` e `n2`) da função envolvente `fib`.
Esta é uma ótima forma de fazer com que os valores de função mantenham estado entre chamadas.
Dizemos que a função anónima é um closure das variáveis `n1` e `n2`.
Os [closures][closure] são amplamente usados em programação e podes ver outras linguagens que os suportam.
