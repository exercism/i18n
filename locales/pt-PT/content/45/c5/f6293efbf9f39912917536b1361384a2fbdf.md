# Anexo às instruções

## Instruções específicas do percurso

Implementa uma função chamada `slices` que devolve um array de strings como descrito acima.
A tua função deve lançar um `IllegalArgumentError` com uma mensagem de erro adequada, como se segue.
- Se a string fornecida estiver vazia, dá erro com a mensagem `series cannot be empty`.
- Se o comprimento da fatia for negativo, dá erro com a mensagem `slice length cannot be negative`.
- Se o comprimento da fatia for zero, dá erro com a mensagem `slice length cannot be zero`.
- Se o comprimento da fatia ultrapassar o comprimento da string, dá erro com a mensagem `slice length can not be greater than series length`.
