# Dicas

## Geral

- O alinhamento de uma struct é o alinhamento _máximo_ de qualquer um dos seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.

## 1. Criar um carro telecomandado

- O alinhamento de uma struct é o alinhamento _máximo_ de qualquer um dos seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- O alinhamento de um array é igual ao alinhamento dos seus elementos.
- Cada bloco de 8 bytes de uma struct deve ser classificado separadamente.
- Se um número inteiro e um valor de vírgula flutuante partilharem os mesmos 8 bytes, os 8 bytes inteiros são passados num General-Purpose Register (GPR).
- Um valor de vírgula flutuante não pode ser uma constante definida em tempo de assemblagem com `equ`, mas pode ser uma constante da secção .rodata.
- Para mover bytes em bruto de um registo `xmm` para um GPR, sem alterar a representação de bits, podem usar-se as instruções [movd][mov] ou [movq][mov].

## 2. Criar uma nova pista

- O alinhamento de uma struct é o alinhamento _máximo_ de qualquer um dos seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- Se campos adjacentes de uma struct não puderem ser agrupados de modo a caber no seu alinhamento, são inseridos bytes de preenchimento.

## 3. Criar um evento de corrida

- O alinhamento de uma struct é o alinhamento _máximo_ de qualquer um dos seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- Uma struct com até 16 bytes é passada em registos a uma função.
- Uma struct com mais de 16 bytes é normalmente colocada em memória.
- Quando uma função devolve uma struct em memória, o endereço de uma posição de memória onde guardar essa struct é passado como primeiro argumento implícito, em `rdi`.
- Neste caso, a função deve devolver esse endereço em `rax`.

## 4. Confirmar um carro na corrida

- O alinhamento de uma struct é o alinhamento _máximo_ de qualquer um dos seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- Um apontador ocupa 8 bytes e é passado num General-Purpose Register (GPR), independentemente do tamanho do tipo para o qual aponta.
- Tanto o array `cars` como o número de carros em corrida têm de ser atualizados em `race`.

## 5. Criar um torneio

- O alinhamento de uma struct é o alinhamento _máximo_ de qualquer um dos seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- Uma struct com mais de 16 bytes é normalmente colocada em memória.
- Quando uma função recebe como argumento uma struct em memória, essa struct é passada na pilha.
- Tanto o array `races` como o número de corridas têm de ser atualizados em `tournament`.
