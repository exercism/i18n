# Instruções

Dadas duas listas, determina se a primeira lista está contida na segunda lista, se a segunda lista está contida na primeira lista, se ambas as listas estão contidas uma na outra, ou se nenhuma destas situações é verdadeira.

Mais concretamente, uma lista A é uma sublista da lista B se, ao retirares 0 ou mais elementos do início de B e 0 ou mais elementos do fim de B, obtiveres uma lista completamente igual a A.

Exemplos:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A é uma sublista de B
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A é uma sublista de B
 * A = [3, 4], B = [1, 2, 3, 4, 5], A é uma sublista de B
 * A = [1, 2, 3], B = [1, 2, 3], A é igual a B
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A é uma superlista de B
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A não é uma superlista de B, nem uma sublista de B, nem igual a B
