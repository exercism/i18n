# Instruções

Neste exercício vais organizar corridas entre vários tipos de carros telecomandados.
Cada carro tem as suas próprias características de velocidade e de consumo de bateria.

Os carros começam com a bateria cheia (100%).
Sempre que conduzes o carro com o telecomando,
este percorre uma distância em metros igual à velocidade do carro e reduz a percentagem de bateria restante no valor do seu consumo de bateria.

Se a bateria de um carro estiver abaixo da percentagem do seu consumo de bateria, já não podes conduzir o carro.

Cada pista de corrida tem a sua própria distância.
Os carros são testados verificando se conseguem terminar a pista sem ficar sem bateria.

## 1. Cria um carro telecomandado

Define uma `struct` `Car` com os seguintes campos do tipo `int`:

- battery
- batteryDrain
- speed
- distance

Permite criar um carro telecomandado definindo uma função `NewCar` que recebe a velocidade do carro em metros
e a percentagem de consumo de bateria como os seus dois parâmetros (ambos do tipo `int`) e devolve uma instância de `Car`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. Cria uma pista de corrida

Define outro tipo de struct chamado `Track` com o campo `distance` do tipo inteiro.
Permite criar uma pista de corrida definindo uma função `NewTrack` que recebe a distância da pista em metros como o seu único parâmetro (que é do tipo `int`):

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. Conduz o carro

Implementa a função `Drive`, que atualiza o número de metros percorridos com base na velocidade do carro e reduz a bateria de acordo com o consumo de bateria.
Se não houver bateria suficiente para conduzir mais uma vez, o carro não avança:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. Verifica se um carro telecomandado consegue terminar uma corrida

Para terminar uma corrida, um carro tem de conseguir percorrer a distância da corrida.
Isso significa não esgotar a bateria antes de cruzar a linha de chegada.
Implementa a função `CanFinish`, que recebe uma instância de `Car` e uma de `Track` como parâmetros e devolve `true` se o carro conseguir terminar a corrida; caso contrário, devolve `false`.

Assume que estás na linha de partida da corrida e ligas o motor do carro para a corrida.
Tem em conta que a bateria do carro pode não estar totalmente carregada quando a corrida começa:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
