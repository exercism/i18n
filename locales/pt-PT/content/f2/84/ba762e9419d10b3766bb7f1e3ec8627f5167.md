# preferir number a parse

A família `parseXXX` é _ótima_ para converter um valor de entrada num número quando não sabes se o valor de entrada é um número, mas quando sabes, é melhor usar a função mais rigorosa [`Number(...)`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number#Convert_numeric_strings_and_null_to_numbers ).
