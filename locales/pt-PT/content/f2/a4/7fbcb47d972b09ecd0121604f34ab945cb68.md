# Instruções adicionais

## Dicas

Para completares este exercício, precisas de criar o tipo de dados `BST`,
com instâncias `Eq` e `Show`, e de implementar as funções:

- `bstLeft`
- `bstRight`
- `bstValue`
- `empty`
- `fromList`
- `insert`
- `singleton`
- `toList`

Vais encontrar uma declaração de dados de exemplo e as assinaturas de tipo já
preparadas, mas cabe-te a ti definir as funções e criar um tipo de dados,
um newtype ou um sinónimo de tipo que faça sentido.
