# Introdução

O casting e a conversão de tipos são formas diferentes de converter uma expressão de um tipo de dados para outro.

Podes fazer casting de uma expressão para outro tipo com o operador cast `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Se os tipos não forem compatíveis, é lançada uma instância de `InvalidCastException`. No caso dos números, isto indica que o tipo recetor não consegue representar o valor convertido. No caso das classes, um dos tipos tem de derivar do outro (isto também se aplica, trivialmente, às estruturas).

Uma alternativa ao casting é a conversão de tipos com o operador `is`. Isto aplica-se tipicamente a tipos de referência e a tipos anuláveis.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Se precisares de detetar o tipo exato de um objeto, o `is` pode ser demasiado permissivo, pois devolve true para uma classe e para todas as classes e interfaces das quais ela deriva, direta ou indiretamente. `typeof` e `Object.GetType()` são a solução, neste caso.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
