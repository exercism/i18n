# Instruções

Neste exercício vais implementar algumas regras do [Blackjack][blackjack], como a forma como o jogo se joga e se pontua.

**Nota**: Neste exercício, _`A`_ significa ás, _`J`_ significa valete, _`Q`_ significa dama e _`K`_ significa rei.
Os jokers são descartados.
Assume-se um [baralho padrão de 52 cartas com naipes franceses][standard_deck], mas na maioria das versões misturam-se vários baralhos para jogar.

## 1. Calcula o valor de uma carta

No Blackjack, cabe a cada jogador decidir se um ás vale 1 ou 11 pontos (_mais sobre isto mais adiante_).
As figuras (`J`, `Q`, `K`) valem 10 pontos e qualquer outra carta vale o valor do seu "pip" (_numérico_).

Define a função `value_of_card(<card>)` com o parâmetro `card`.
A função deve devolver o _valor numérico_ da string da carta recebida.
Como um ás pode assumir vários valores (1 **ou** 11), por agora esta função deve fixar o valor de um ás em 1.
Mais adiante vais implementar uma função que determina o valor de um ás, dada uma mão existente.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. Determina qual carta tem o valor mais alto

Define a função `higher_card(<card_one>, <card_two>)` com os parâmetros `card_one` e `card_two`.
Para efeitos de pontuação, o valor de `J`, `Q` ou `K` é 10.
A função deve devolver qual das cartas tem o valor mais alto para pontuação.
Se as duas cartas tiverem o mesmo valor, devolve as duas.
Podes devolver as duas cartas usando uma vírgula na instrução `return`:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

Um ás pode assumir vários valores, por isso nesta tarefa vamos fixar as cartas `A` no valor 1.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. Calcula o valor de um ás

Como já foi referido, um ás pode valer _ou_ 1 **ou** 11 pontos.
Os jogadores tentam aproximar-se o mais possível de 21 pontos, sem passar _acima_ de 21 (_"rebentar"_).

Define a função `value_of_ace(<card_one>, <card_two>)` com os parâmetros `card_one` e `card_two`, que são um par de cartas que já estão na mão _antes_ de receberes um ás.
A tua função terá de decidir se o próximo ás vai valer 1 ou 11, e devolver esse valor.
Lembra-te: o valor da mão com o ás tem de ser o mais alto possível _sem_ passar de 21.

**Dica**: se já tivermos um ás na mão, o valor do próximo ás seria 1.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. Determina uma mão "Natural" ou "Blackjack"

Se um jogador receber um ás (`A`) e uma carta de dez (10, `K`, `Q` ou `J`) como as suas duas primeiras cartas, fica com uma pontuação de 21.
Isto é conhecido como uma mão de **blackjack**.


Define a função `is_blackjack(<card_one>, <card_two>)` com os parâmetros `card_one` e `card_two`, que são um par de cartas.
Determina se a mão de duas cartas é um **blackjack** e devolve o boolean `True` se for, e `False` caso contrário.

**Nota**: O _cálculo_ da pontuação pode ser feito de várias formas.
Mas, se possível, gostaríamos que verificasses se há um ás e uma carta de dez **_na_** mão (_ou numa determinada posição_), em vez de _somar_ os valores da mão.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. Dividir pares

Se as duas primeiras cartas de uma mão tiverem o mesmo valor (_por exemplo, dois seis ou um `Q` e um `K`_), o jogador pode optar por tratá-las como duas mãos separadas.
Isto é conhecido como "dividir pares".

Define a função `can_split_pairs(<card_one>, <card_two>)` com os parâmetros `card_one` e `card_two`, que são um par de cartas.
Determina se esta mão de duas cartas pode ser dividida em dois pares.
Se a mão puder ser dividida, devolve o boolean `True`; caso contrário, devolve `False`.

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. Dobrar a aposta

Quando as duas cartas iniciais somam 9, 10 ou 11 pontos, o jogador pode fazer uma aposta adicional igual à aposta original.
Isto é conhecido como "dobrar a aposta".

Define a função `can_double_down(<card_one>, <card_two>)` com os parâmetros `card_one` e `card_two`, que são um par de cartas.
Determina se a mão de duas cartas pode ser "dobrada" e devolve o boolean `True` se puder, e `False` caso contrário.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
