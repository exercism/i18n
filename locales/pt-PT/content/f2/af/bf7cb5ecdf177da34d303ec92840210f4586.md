# Anexo às instruções

## Restrições

O Rust já disponibiliza na sua biblioteca padrão uma [função de pesquisa binária](https://doc.rust-lang.org/std/primitive.slice.html#method.binary_search).
Para este exercício, não deves usar essa função. Em vez disso, usa apenas outras ferramentas básicas.

## Para pontos bónus

Já tens os testes a passar e o código limpo? Se quiseres, há algumas coisas adicionais que podes experimentar.

- Neste momento, a tua função find provavelmente só funciona com slices de números, mas o sistema de tipos do Rust é suficientemente flexível para criar uma função find que funciona com todos os slices cujos elementos podem ser ordenados.
- Além disso, esta função find pode funcionar não só com slices, mas também, ao mesmo tempo, com um Vec ou um Array.

Para correr os testes bónus, remove a flag `#[ignore]` e executa os testes com a funcionalidade `generic`, assim:

```bash
$ cargo test --features generic
```

Depois, partilha a tua opinião num comentário à submissão. Esta experiência tornou o código melhor? Pior? Aprendeste alguma coisa com ela?
