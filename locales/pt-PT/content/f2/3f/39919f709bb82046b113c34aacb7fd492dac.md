# Sobre

Uma _string_ é o tipo de dados de JavaScript para armazenar dados de texto.
Não existe um tipo de dados separado para um caráter individual.

## Criar uma string

Crias uma [string literal][literal] envolvendo o texto em plicas ou aspas.
No Exercism, usamos plicas.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

Alguns carateres especiais do texto têm de ser precedidos de uma barra invertida `\`; vê as [sequências de escape na MDN][mdn-escape-sequences].

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

Além das plicas e das aspas, também podes criar uma string envolvendo o texto em acentos graves.
Esta sintaxe permite incluir plicas ou aspas e até mudanças de linha sem ser preciso escapá-las.
Também permite incorporar expressões; vê [Template Strings][mdn-template-strings] para mais detalhes.

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## As strings como listas de carateres

Uma string pode ser tratada como uma lista de carateres em que o primeiro caráter tem o índice `0`.
Podes aceder a um caráter individual da string com parênteses retos e o índice da letra que queres obter.
Em alternativa, também existe o método `charAt`.

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

Podes determinar o número de carateres de uma string acedendo à propriedade `length`.

```javascript
'cat'.length;
// => 3
```

## Concatenação e métodos

A forma mais simples de concatenar strings é usar o operador de adição `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

As strings fornecem muitos métodos auxiliares; vê a [documentação da MDN sobre métodos de string][mdn-string-methods] para uma lista completa.
A lista seguinte mostra alguns dos auxiliares mais usados.

- [`toUpperCase`][mdn-to-upper-case] e [`toLowerCase`][mdn-to-lower-case] - alterar as maiúsculas e minúsculas de todos os carateres
- [`trim`][mdn-trim] - remover espaços em branco no início e no fim
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] e [`endsWith`][mdn-ends-with] - determinar se outra string faz parte da string indicada
- [`slice`][mdn-slice] - extrair uma secção da string

## As strings são imutáveis

Aplicar os métodos acima nunca altera a string original. Em vez disso, é criada e devolvida uma nova string.
As strings (e outros tipos de dados primitivos) são imutáveis em JavaScript.
Isso também significa que não podes atribuir um caráter diferente a determinado índice com a sintaxe de parênteses retos mostrada acima (como farias em arrays).

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
