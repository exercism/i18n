# Sobre

As condicionais em C++ são semelhantes às condicionais de outras linguagens.
O tipo subjacente de qualquer operação condicional é o tipo `bool`, que pode ter o valor `true` ou `false`.
As condicionais são frequentemente usadas como mecanismos de controlo de fluxo para verificar várias condições.

Podes usar uma condicional `if`, que executa o seu código se a condição subjacente for `true`, da seguinte forma:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Em cenários com mais do que um caso, podes encadear várias condicionais `if` usando as instruções `else if` e `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Desde o C++17, as condicionais `if` também podem incluir uma instrução curta de inicialização que pode ser usada para inicializar uma ou mais variáveis para a condicional `if`.
Por exemplo:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Nota: não podes aceder a nenhuma variável criada na inicialização depois do fim da condicional `if`.
