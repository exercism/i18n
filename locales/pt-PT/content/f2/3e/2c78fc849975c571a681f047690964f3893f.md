# Notas para este exercício na track Python

Podes assumir o seguinte sobre os valores de entrada dos testes da função `sum_of_multiples`:

- Todos os números de entrada são **_`int`s não negativos_** (_ou seja, números naturais, incluindo o zero_).
- É obrigatório fornecer uma `list` de fatores, cujos elementos são únicos e estão ordenados por ordem crescente.
