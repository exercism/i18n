# Apêndice às instruções

## Dicas

Para completares este exercício, precisas de criar o tipo de dados `Matrix`,
com instâncias de `Eq` e `Show`, e de implementar as seguintes funções:

- `cols`
- `column`
- `flatten`
- `fromList`
- `fromString`
- `reshape`
- `row`
- `rows`
- `shape`
- `transpose`

Vais encontrar uma declaração de dados fictícia e assinaturas de tipo já presentes,
mas cabe-te a ti definir as funções e criar um tipo de dados, newtype ou sinónimo
de tipo que faça sentido.

Não é preciso validar os valores de entrada. Deixa que falhe se a matriz não for
retangular, se forem encontrados carateres inválidos, etc.

shape é (rows, cols)
