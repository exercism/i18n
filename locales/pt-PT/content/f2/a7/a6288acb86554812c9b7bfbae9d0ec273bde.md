# Introdução

Quando não se sabe de antemão quantas iterações um ciclo vai ter
(ou seja, "continua até um determinado predicado deixar de ser verdadeiro"),
o Factor usa o combinador `while` do [`kernel`][kernel]:

```
while ( pred body -- )
```

Tanto `pred` como `body` são quotations que operam sobre a pilha de dados.
`while` chama `pred`; se este deixar um valor verdadeiro no topo da pilha,
`while` executa `body` e repete; caso contrário, para. O estado que passa de
uma iteração para a seguinte vive na pilha entre chamadas (ou em locais
nomeados quando há mais do que um pedaço de estado).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` é a forma simétrica: continua *até* o predicado se tornar verdadeiro.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
