# Instruções

És um observador de aves dedicado que anda a registar quantas aves visitaram o teu jardim.
Normalmente, usas um caderno para as contar com riscos, mas, para trabalhares melhor com os teus dados, digitalizaste as contagens de aves das últimas semanas.

## 1. Determinar o número total de aves que contaste até agora

Vamos começar por analisar os dados e ter uma visão geral.
Descobre quantas aves contaste no total desde que começaste a fazer os teus registos.

Implementa uma função `totalBirdCount` que aceita um array de valores `Int` com a contagem de aves por dia.
Deve devolver o número total de aves que contaste.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. Calcular o número de aves visitantes numa semana específica

Agora que já tens uma ideia geral dos teus números de contagem de aves, queres fazer uma análise mais detalhada.

Implementa uma função `birdsInWeek` que aceita um array com a contagem de aves por dia e um número de semana.

Devolve o número total de aves que contaste nessa semana específica.
Podes assumir que as semanas são sempre registadas por completo.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. Corrigir um erro de contagem

Deste conta de que, durante todo o tempo em que andavas a tentar registar as aves, havia uma ave escondida num canto distante do jardim.

Percebeste que essa ave passava sempre dia sim, dia não no teu jardim.

Não sabes exatamente onde estava nos dias intercalares, mas de certeza que não era no teu jardim.

A tua intuição de observador de aves também te diz que a ave estava no teu jardim no primeiro dia que registaste na tua lista.

Com esta nova informação, escreve uma função `fixBirdCountLog` que recebe como argumento um array com as aves contadas por dia e devolve o array depois de corrigir o erro de contagem.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
