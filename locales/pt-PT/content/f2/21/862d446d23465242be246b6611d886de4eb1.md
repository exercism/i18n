# Introdução

O `when` do Kotlin é uma expressão condicional para escolher entre várias opções.
É semelhante ao `switch` do Java e mais flexível do que uma cadeia de `if` ... `else if` ... `else`.

Tal como o `if`, o `when` também pode ser usado como uma expressão que produz um valor.

## Correspondência com um valor

Indica ao `when`, entre parênteses, o valor com que queres fazer a correspondência.
Cada ramo compara esse valor até um deles corresponder:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Cada ramo é escrito como `pattern -> result`.
- Os ramos são testados de cima para baixo até se encontrar uma correspondência.
  Só o primeiro ramo é executado.
- Usa `else` para qualquer valor que não esteja listado acima (semelhante ao `else` final de uma cadeia de `if`).

Isto é semelhante à [correspondência de padrões][pattern-matching].
O `pattern` pode ser um valor a corresponder, ou podes usar `is` para fazer a correspondência por tipo:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

ou usar `in` para verificar se o valor está contido num intervalo, numa coleção, numa string ou em qualquer outra coisa com um método `contains`:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## Condições de guarda

Ao fazer correspondência com um valor, podes colocar condições adicionais num `if` depois do padrão.
Estas condições chamam-se condições de guarda.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

Também podes usar `else if`.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Correspondência de condições

Em alternativa, podes omitir o valor e colocar condições booleanas em cada ramo:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Mais uma vez, os ramos são verificados de cima para baixo e só é executado o primeiro ramo cuja condição seja `true`.

## Usar o `when` como expressão

Quando o `when` é usado pelo seu resultado (atribuído a uma variável, devolvido por uma função, e assim por diante), é preciso cobrir todos os casos possíveis.

- Ao fazer correspondência com um valor, adiciona `else`, a menos que todos os valores possíveis já estejam tratados (por exemplo, todos os valores de um `Boolean` ou de um `enum`).
- Ao fazer correspondência de condições, é obrigatório ter um ramo `else`, porque o compilador não consegue saber se as tuas condições cobrem todos os casos.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
