# Sobre

Os Boolean em Kotlin são representados pelo tipo `Boolean`, cujos valores podem ser `true` ou `false`.

O Kotlin suporta três [operadores booleanos][reference] incorporados: `!` (negação, ou NOT), `&&` (conjunção preguiçosa, ou AND) e `||` (disjunção preguiçosa, ou OR). Os operadores `&&` e `||` usam _avaliação de curto-circuito_, o que significa que o lado direito do operador só é avaliado quando é necessário.

```kotlin
true || false // => true
true && false // => false
```

Cada um dos três operadores booleanos tem uma [_precedência de operadores_][precedence] diferente. Como consequência, são avaliados nesta ordem: primeiro `!`, depois `&&` e, por fim, `||`. Se quiseres 'escapar' a estas regras, podes envolver uma expressão booleana entre parênteses (`()`), uma vez que os parênteses têm uma precedência de operadores ainda maior.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
