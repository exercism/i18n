# Introdução

A interpolação de string é suportada em Haxe ao envolver uma string entre aspas simples (`'`) e ao usar o sinal de dólar (`$`) para desencadear a interpolação.

Também é possível incluir expressões completas com `${expr}`, em que `expr` é qualquer expressão Haxe válida.

```haxe
var x = 10;
trace('They have $x apples, of which ${x - 4} are red.');
// They have 10 apples of which 6 are red.
```
