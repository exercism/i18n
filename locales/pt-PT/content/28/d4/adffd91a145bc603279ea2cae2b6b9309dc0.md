# Anexo às instruções

## Mensagens de exceção

Por vezes é necessário [lançar uma exceção][raising-exceptions].
Quando o fazes, deves incluir sempre uma **mensagem de erro significativa** que indique qual é a origem do erro.
Isto torna o teu código mais legível e ajuda imenso na depuração.
Em situações em que sabes que a origem do erro será de um determinado tipo, podes optar por lançar um dos [tipos de erro incorporados][error-base-classes], mas deves continuar a incluir uma mensagem significativa.


Um jogo válido de `Tic Tac Toe` termina quando um dos jogadores ganha.
Se ambos os jogadores estiverem numa situação de vitória, este exercício espera que uses a [instrução raise][raise] e que "lances" um `ValueError` na tua solução.
Espera-se também que o teu código lance um `ValueError` se se considerar que um jogador jogou duas jogadas seguidas, ou que jogou a primeira jogada quando lhe tinha sido atribuído jogar a segunda.


Para lançar um `ValueError` com uma mensagem, escreve a mensagem como argumento do tipo `exception`:

```python
# Example when player O goes before player X.
raise ValueError("Wrong turn order: O started")

# Example when player X goes twice.
raise ValueError("Wrong turn order: X went twice")

# Example when player X wins AND player O wins.
raise ValueError("Impossible board: game should have ended after the game was won")
```

Os testes verificam se a mensagem de erro corresponde exatamente, por isso lê com atenção os resultados esperados.
