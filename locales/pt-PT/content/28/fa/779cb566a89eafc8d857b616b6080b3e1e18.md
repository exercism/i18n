# Introdução

Em Ruby, os **arrays** são coleções ordenadas de qualquer objeto, indexadas por números inteiros.
A indexação de um array começa em `0`.
Um índice negativo é considerado relativo ao fim do array, ou seja, um índice `-1` indica o último elemento do array, `-2` o penúltimo, e assim sucessivamente.
Os arrays em Ruby incluem o [módulo Enumerable][enumerable-module], que acrescenta vários métodos de percurso e de pesquisa, além da possibilidade de ordenar.

## Criar um array

- Um array em Ruby pode conter objetos de tipos diferentes.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Atribuição de elementos

É possível aceder aos elementos ou alterá-los através de índices.
Também é possível aceder a subarrays indicando um índice inicial e um tamanho.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- Os índices negativos contam de trás para a frente, a partir do fim do array.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Referência de elementos

- É possível obter elementos de um array com o método #[].
- Devolve o elemento no índice indicado, ou então um subarray que começa no índice inicial e se prolonga por length elementos.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- Os índices negativos contam de trás para a frente, a partir do fim do array (-1 é o último elemento)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Obter informações sobre um array

Os arrays registam sempre o seu próprio comprimento.
Para saber quantos elementos um array contém, usa length, count ou size.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Adicionar itens a um array

Podes adicionar itens ao fim de um array com `push` ou `<<`:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Remover itens de um array

O método pop remove o último elemento de um array e devolve-o:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
