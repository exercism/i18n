# Introdução

JavaScript é uma linguagem dinâmica, que suporta estilos orientados a objetos, imperativos e declarativos (por exemplo, programação funcional).

## (Re)atribuição

Há algumas formas principais de atribuir valores a nomes em JavaScript: com variáveis ou com constantes. No Exercism, as variáveis escrevem-se sempre em [camelCase][wiki-camel-case]; as constantes escrevem-se em [SCREAMING_SNAKE_CASE][wiki-snake-case]. Não existe um guia oficial a seguir, e várias empresas e organizações têm guias de estilo diferentes. _Sente-te à vontade para escrever as variáveis como quiseres_. A vantagem de as escrever da forma como os exercícios estão preparados é que ficam destacadas de maneira diferente na interface web e na maioria das IDEs.

As variáveis em JavaScript podem ser definidas com a palavra-chave [`const`][mdn-const], [`let`][mdn-let] ou [`var`][mdn-var].

Uma variável pode referenciar valores diferentes ao longo do seu tempo de vida quando usas `let` ou `var`. Por exemplo, `myFirstVariable` pode ser definida e redefinida muitas vezes com o operador de atribuição `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

Ao contrário de `let` e `var`, as variáveis definidas com `const` só podem ser atribuídas uma vez. É assim que se definem constantes em JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 Num exercício de aprendizagem posterior, a diferença entre a atribuição / vinculação de uma _constante_ e o _valor_ de uma _constante_ é explorada e explicada.

## Declarações de funções

Em JavaScript, as unidades de funcionalidade são encapsuladas em _funções_, que normalmente se agrupam no mesmo ficheiro quando pertencem umas às outras. Estas funções podem receber parâmetros (argumentos) e podem _devolver_ um valor com a palavra-chave `return`. As funções são invocadas com a sintaxe `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 Em JavaScript há _muitas_ formas diferentes de declarar uma função. Essas outras formas são diferentes de usar a palavra-chave `function`. O percurso tenta introduzi-las gradualmente, mas, se já as conheces, usa a que preferires. Na maioria dos casos, usar uma ou outra não é melhor nem pior.

## Expor para outros ficheiros

Para tornar uma `function`, uma constante ou uma variável disponível em _outros ficheiros_, é preciso [exportá-las][mdn-export] com a palavra-chave `export`. Outro ficheiro pode depois [importá-las][mdn-import] com a palavra-chave `import`. Isto também é conhecido como sistema de módulos. Um ótimo exemplo é o funcionamento de todos os testes. Cada exercício tem pelo menos um ficheiro, por exemplo `lasagna.js`, que contém a _implementação_. Além disso, há pelo menos outro ficheiro, por exemplo `lasagna.spec.js`, que contém os _testes_. Este ficheiro _importa_ as entidades públicas (ou seja, exportadas) para testar a implementação:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
