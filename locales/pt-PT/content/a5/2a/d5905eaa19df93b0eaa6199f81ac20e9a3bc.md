# Anexo às instruções

## Implementação

Este exercício pede que cries uma estrutura de dados de lista ligada que possa ser iterada.

1. Implementa a propriedade `Count`. Não deve ser possível alterar o seu valor a partir do exterior.
2. Implementa o método `Push(T value)`, que adiciona um valor à cabeça da lista.
3. Implementa o método `Pop()`, que remove e devolve um valor da cabeça.
4. Adiciona um construtor que permita a inicialização com um único valor ou com um iterável.
5. Implementa a interface `IEnumerable<T>`. Para mais informações, consulta [ienumerable].
6. Garante que o método `Reverse()` está disponível.

[ienumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
