## 1. Define o comportamento da animação

- Usa o atributo de módulo `@callback` para definir as funções pretendidas.
- Cada callback tem de especificar o nome da função, a lista de argumentos (os seus tipos) e o valor devolvido (o seu tipo).
- Usa os tipos personalizados fornecidos `dot`, `opts`, `error` e `frame_number` nas definições dos callbacks.
- Relembra o que sabes sobre [typespecs][typespec] para te ajudar a definir callbacks.

## 2. Fornece uma implementação predefinida do callback `init/1`

- Define uma macro `__using__/1` no módulo `DancingDots.Animation`.
- Podes ignorar o argumento da macro.
- A macro tem de devolver uma [expressão citada][quote].
- Na expressão citada, usa `@behaviour` para que chamar `use DancingDots.Animation` defina `DancingDots.Animation` como o comportamento do módulo que a usa.
- Na expressão citada, implementa a função `init/1`.
- A implementação predefinida da função `init/1` deve envolver o argumento `opts` recebido num tuplo `:ok`.
- Existe [uma macro][defoverridable] que permite marcar uma função como podendo ser sobreposta.

## 3. Implementa a animação `Flicker`

- Usa a macro `__using__/1` de `DancingDots.Animation`, chamando [esta macro especial][doc-use] no módulo `DancingDots.Flicker`.
- Não precisas de implementar a função `init/1`. A implementação predefinida é suficiente.
- Precisas de implementar a função `handle_frame/3`.
- Para detetares «cada 4.º fotograma», podes verificar se o [resto][rem] da divisão do número do fotograma por 4 é igual a 0.

## 4. Implementa a animação `Zoom`

- Usa a macro `__using__/1` de `DancingDots.Animation`, chamando [esta macro especial][doc-use] no módulo `DancingDots.Zoom`.
- Precisas de implementar tanto a função `init/1` como a função `handle_frame/3`.
- Usa o módulo [`Keyword`][keyword] para trabalhar com a lista de palavras-chave de opções.
- Existe [uma guarda incorporada][is_number] para verificar se um valor é um número.
