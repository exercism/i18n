# Testes

## Instalar o executor de testes da track GDScript do Exercism

Precisas de ter o [Godot instalado][installation] corretamente para usar o executor de testes.

Para compilar e testar scripts GDScript para o Exercism, o Godot é executado em modo "headless" a partir da CLI.
De momento, estas instruções exigem Linux e bash.

### Passo 1: instalar a infraestrutura geral do executor de testes

Para preparares o ambiente de testes, clona [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] e move o conteúdo para `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Passo 2: transferir o script do executor de testes de um único exercício

Partindo do princípio de que tens a ferramenta `exercism` configurada e já descarregaste pelo menos um exercício de GDScript, deve ter criado uma pasta `exercism/gdscript` para guardar os exercícios.
Guarda [o executor de testes][test-local-gdscript-solution] nesta pasta e torna o ficheiro executável, ou cria apenas uma ligação para ele:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## Executar os testes

Depois de concluídos os passos de instalação, podes começar em qualquer diretório de exercício (por exemplo, `~/exercism/gdscript/two-fer`) e executar o script (que está um nível acima, em `../`) para testares a tua solução local desse exercício:

```sh
../test-local-gdscript-solution.sh
```
