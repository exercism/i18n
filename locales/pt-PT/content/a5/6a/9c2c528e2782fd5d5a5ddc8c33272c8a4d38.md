# Introdução

Os carateres em Factor são números inteiros (pontos de código Unicode), por isso os operadores numéricos `<`, `>`, `=` dão-te diretamente uma ordenação que distingue maiúsculas de minúsculas. O vocabulário [`unicode`][unicode] acrescenta predicados que têm em conta o Unicode e a conversão de maiúsculas e minúsculas de um único caráter.

## Predicados de carateres

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## Conversão de maiúsculas e minúsculas

`ch>upper` e `ch>lower` convertem um único caráter. As operações ao nível da string, `>upper` e `>lower`, aplicam-nas a cada caráter de uma string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` passa uma string inteira para minúsculas e depois põe o primeiro caráter em maiúscula, ou seja, a capitalização de título de uma única palavra:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## Literais de carateres

`CHAR: A` é interpretado como o ponto de código inteiro de `A`. Para carateres com nome, usa os nomes `space`, `tab`, `\n`, etc.:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## Símbolos

Quando uma palavra precisa de devolver uma etiqueta em vez de um valor, por exemplo `yes`/`no`/`maybe` em vez de um Boolean, declara cada etiqueta como um *símbolo*. Um símbolo é uma palavra que se coloca a si própria na pilha quando é chamada, e dois símbolos só são considerados iguais quando têm o mesmo nome.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` declara um; `SYMBOLS: a b c ;` declara vários.
