# Instruções adicionais

## Memória reservada

O buffer para a string de entrada usa os bytes 64-191 da memória linear.

## Formato da entrada

A entrada vem formatada como uma única string de três linhas, com uma quebra de linha no fim de cada uma. As cruzes e os círculos são sempre `X` e `O` maiúsculos.

Assim, o tabuleiro

```
X··
OXO
XOX
```
é codificado como

```
"X  \nOXO\nXOX\n"
```
