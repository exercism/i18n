# Sobre

As funções para lidar com entrada e saída são fornecidas pelo [módulo `IO`][module-io].

- [`IO.puts/2`][io-puts] escreve uma string na saída padrão, seguida de uma nova linha. Devolve `:ok`.
- [`IO.write/2`][io-write] escreve uma string na saída padrão, sem acrescentar uma nova linha. Devolve `:ok`.
- [`IO.gets/2`][io-gets] lê uma linha da entrada padrão.
- [`IO.inspect/2`][io-inspect] escreve qualquer coisa na saída padrão e aceita opções úteis como `:label`. Devolve o valor que recebeu, sem o alterar. É útil para depurar.

## Protocolo `String.Chars`

Se tentares passar ao [`IO.puts/2`][io-puts] um valor que ele não consegue imprimir, vais ver um erro `Protocol.UndefinedError`.

```elixir
IO.puts({:ok, 7})
# ** (Protocol.UndefinedError) protocol String.Chars not implemented for {:ok, 7} of type Tuple
```

Quando isto acontecer, talvez queiras usar antes o [`IO.inspect/2`][io-inspect].

## `IO.inspect/2` para depurar

O [`IO.inspect/2`][io-inspect] é perfeito para depurar, porque devolve o argumento sem o alterar, consegue imprimir qualquer coisa e oferece uma opção `:label`.

```elixir
"HELLO\n"
|> String.trim()
|> IO.inspect(label: "step 1")
|> String.downcase()
|> IO.inspect(label: "step 2")

# > step 1: "HELLO"
# > step 2: "hello"
# => "hello"
```

## Dispositivos de IO

O primeiro argumento de todas estas funções é um [dispositivo de IO][io-devices], cujo valor predefinido é `:stdio` (entrada/saída padrão). Para escrever no dispositivo de erro padrão, usa antes `:stderr`. Um dispositivo de IO também pode ser um processo, por exemplo um criado ao chamar [`File.open/2`][file-open], o que permite escrever num ficheiro.
