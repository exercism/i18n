# Instruções

Refatora um programa que imprime um livro-razão.

O exercício Livro-Razão é um exercício de refatoração.
Há código que imprime um livro-razão bem formatado, dadas uma localidade (americana ou neerlandesa) e uma moeda (dólar americano ou euro).
No entanto, o código está bastante mal escrito, embora (de forma algo surpreendente) passe sempre no conjunto de testes.

Reescreve este código.
Lembra-te de que, ao refatorar, o truque é dar pequenos passos que mantenham os testes a passar.
Assim, podes sempre voltar rapidamente a uma versão funcional.
As ferramentas de controlo de versões, como o git, também podem ajudar.

Mantém um registo das alterações que fizeste e deixa um comentário no exercício com esse registo, o que vai ajudar os revisores.
