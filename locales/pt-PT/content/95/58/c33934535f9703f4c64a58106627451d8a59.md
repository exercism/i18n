# Instruções adicionais

## Como este exercício está estruturado em Python

Este exercício resolve-se melhor com o operador `%` ([módulo][modulo]) do Python, que devolve o resto da divisão inteira de números positivos.
Tem um método equivalente, `operator.mod()`, no [módulo operator][operator-mod].


O Python também oferece outros métodos de 'resto' no [módulo math][math-module].
O [`math.fmod()`][fmod] comporta-se como o `%`, mas opera sobre números de vírgula flutuante.
O [`math.remainder()`][remainder] implementa um algoritmo de "passo mais próximo de zero" para o resto da divisão.
Embora te encorajemos a familiarizar-te com estes métodos, nenhum deles dá exatamente o mesmo resultado que o `%`, por isso não os recomendamos para este exercício.

A função incorporada [`divmod()`][divmod] também devolve um resto igual ao do `%` se for usada com dois números inteiros positivos, mas devolve um `tuple` que é preciso desempacotar.
