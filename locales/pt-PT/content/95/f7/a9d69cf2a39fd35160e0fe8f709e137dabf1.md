# Instruções

Implementa a codificação e a descodificação run-length.

A codificação run-length (RLE) é uma forma simples de compressão de dados, em que as sequências (elementos de dados consecutivos) são substituídas por um único valor e pela respetiva contagem.

Por exemplo, podemos representar os 53 carateres originais com apenas 13.

```text
"WWWWWWWWWWWWBWWWWWWWWWWWWBBBWWWWWWWWWWWWWWWWWWWWWWWWB"  ->  "12WB12W3B24WB"
```

A RLE permite reconstruir os dados originais na perfeição a partir dos dados comprimidos, o que a torna uma compressão de dados sem perdas.

```text
"AABCCCDEEEE"  ->  "2AB3CD4E"  ->  "AABCCCDEEEE"
```

Por simplificação, podes assumir que a string não codificada contém apenas as letras de A a Z (maiúsculas ou minúsculas) e espaços em branco. Assim, os dados a codificar nunca contêm números, e os números dentro dos dados a descodificar representam sempre a contagem do caráter seguinte.
