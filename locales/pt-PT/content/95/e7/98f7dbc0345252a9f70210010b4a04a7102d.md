# Dicas

## Geral

-  Este desafio é todo sobre validar, "limpar" e processar a pergunta na **_ordem correta_**.
-  Se leres as instruções e os testes com atenção, vais ver que há três condições que têm de ser cumpridas para uma pergunta ser "válida".
Se uma pergunta não for válida, tens de [lançar][raise-statement] um [ValueError][value-error] com uma mensagem (_`ValueError("unknown operation")`_).
   O melhor é despachares esta verificação em particular antes de fazeres mais alguma coisa.
-  Processar uma pergunta antes de calcular a resposta passa por usar [métodos de string][str-methods].
Alguns dos mais populares para explorares incluem `str.removeprefix`, `str.removesuffix`, `str.replace` e `str.strip`.
Outros que podes querer conhecer são `str.startswith`, `str.endswith` e `in` (_que se pode aplicar a mais do que apenas strings_).

-  É possível iterar sobre uma string.  No entanto, é **muito** mais fácil iterar sobre uma lista de _palavras_ se a string que estás a processar for uma frase ou um fragmento com espaços.  [`str.split`][split]  consegue dividir uma string e devolver uma lista de "palavras".
-  Um [`while-loop`][while-loop] é muito útil para iterar sobre a pergunta e processar os itens.
-  Para menos verificações de erros e um tratamento de erros mais limpo, recomenda-se um [`try-except`][handling-exceptions] à medida que processas a pergunta.
-  **Lembra-te**: a pergunta é processada da **_esquerda para a direita_**.  Isto significa que "1 plus 12 minus 3 multiplied by 4" é processado assim:
   -  Calcular "1 plus 12" (13),
   -  Calcular "13 minus 3" (10),
   -  Calcular "10 multiplied by 4" (40).
   -  O resultado do primeiro cálculo é _concatenado com o resto da pergunta para formar uma nova pergunta para o passo seguinte_.
       -  Esta técnica é por vezes chamada [padrão do acumulador][accumulator-pattern], ou [fold][fold] / [foldl][foldl] em linguagens de programação funcionais como [Haskell][haskell-folds] ou Lisp.
       -  O Python inclui dois métodos criados de propósito para aplicar o `accumulator-pattern` a estruturas de dados iteráveis como `lists`, `tuples` e `strings`.
               [`functools.reduce`][reduce] e [`itertools.accumulate`][accumulate] podem ser interessantes de investigar aqui.

-  Este exercício tem muitas soluções potenciais e muitos caminhos que podes seguir ao longo do percurso.
   Nenhum caminho é manifestamente "melhor" do que outro, embora um caminho em particular possa ser mais interessante ou mais adequado ao que queres aprender ou explorar neste momento.
