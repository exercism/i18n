# Recursos

Cairo é particularmente adequado para utilização numa rede sem permissão como a [Starknet](https://www.starknet.io/), onde pode oferecer uma proteção robusta contra DoS e resistência à censura. Pode ser interessante aprender sobre este aspeto da linguagem. Aprender a criar contratos inteligentes na Starknet vai melhorar o teu domínio de Cairo, uma vez que estarás a resolver problemas do mundo real com a linguagem, e também te vai apresentar ao mundo da Web3.

- [Starknet Documentation](https://docs.starknet.io/) aprende o que é a Starknet, como funciona e como desenvolver contratos inteligentes nela.
- [Starknet by Example](https://starknet-by-example.voyager.online/) uma coleção de exemplos de como usar a linguagem de programação Cairo para criar contratos inteligentes na Starknet.
- [Starknet Basecamp](https://www.youtube.com/@starknet_foundation) "O Basecamp é um bootcamp de programação gratuito concebido especificamente para ensinar programadores a criar aplicações Web3 na Starknet usando Cairo."
- [Awesome Starknet](https://github.com/keep-starknet-strange/awesome-starknet) "Uma lista selecionada de recursos, bibliotecas, ferramentas e muito mais incríveis da Starknet".
- [Starklings](https://starklings.app/) "Um tutorial interativo baseado na web para aprender Cairo e Starknet."
