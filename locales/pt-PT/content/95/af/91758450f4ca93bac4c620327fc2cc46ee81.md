# Dicas

## Geral

- Lê sobre [bitstrings][bitstring] no guia Getting Started.
- Consulta a documentação da [forma especial bitstring][bitstring-form].
- Consulta [como converter números decimais em números binários][decimal-to-binary-youtube].
- O Elixir suporta [diferentes formas de escrever números inteiros][integer-literal], incluindo a notação binária.

## 1. Calcular o tamanho em bits da paleta

- Esta tarefa não usa o tipo de dados bitstring.
- Encontra o menor número positivo `n` tal que 2 elevado a `n` seja maior ou igual ao número de cores que precisamos de representar.
- Cria uma função recursiva para isto.
- Escolhe um tamanho de bits inicial de 1. Se 2 elevado ao tamanho de bits for maior ou igual ao número de cores, encontrámos o tamanho de bits. Se não, soma 1 ao tamanho de bits e verifica outra vez (recursão).
- Usa o [operador de potência `**`][power-operator] para elevar 2 a uma dada potência.

## 2. Criar uma imagem vazia

- Usa a [forma especial bitstring][bitstring-form] para criar um novo bitstring.

## 3. Criar uma imagem de teste

- Usa a [forma especial bitstring][bitstring-form] para criar um novo bitstring.
- Usa o [operador de tipo][type-operator] para especificar o tamanho em bits de cada fragmento.

## 4. Acrescentar um pixel ao início de uma imagem

- A [forma especial bitstring][bitstring-form] pode ser usada para acrescentar um novo fragmento a um bitstring existente.
- Usa o [operador de tipo][type-operator] para especificar o tamanho em bits do novo fragmento, bem como do bitstring existente.
- Usa a função `PaintByNumber.palette_bit_size/1` implementada anteriormente para obter o tamanho em bits do novo fragmento.
- Usa o tipo especial `::bitstring` para especificar que o fragmento antigo tem tamanho desconhecido.

## 5. Obter o primeiro pixel de uma imagem

- A [forma especial bitstring][bitstring-form] pode ser usada para [fazer correspondência de padrões com bitstrings][bitstring-matching].
- Usa a função `PaintByNumber.palette_bit_size/1` implementada anteriormente para obter o tamanho em bits de um pixel.
- Usa o tipo especial `::bitstring` para especificar que o resto do bitstring tem tamanho desconhecido.

## 6. Remover o primeiro pixel de uma imagem

- A [forma especial bitstring][bitstring-form] pode ser usada para [fazer correspondência de padrões com bitstrings][bitstring-matching].
- Usa a função `PaintByNumber.palette_bit_size/1` implementada anteriormente para obter o tamanho em bits de um pixel.
- Usa o tipo especial `::bitstring` para especificar que o resto do bitstring tem tamanho desconhecido.

## 7. Concatenar duas imagens

- A [forma especial bitstring][bitstring-form] pode ser usada para concatenar dois bitstrings.
- Usa o tipo especial `::bitstring` para especificar que cada um dos fragmentos do bitstring tem tamanho desconhecido.
