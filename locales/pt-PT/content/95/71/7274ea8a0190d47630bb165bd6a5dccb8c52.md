## Apêndice

~~~~exercism/note
As instruções acima estão sincronizadas com um repositório partilhado, para garantir a consistência entre todos os percursos das várias linguagens.
Este apêndice fornece esclarecimentos adicionais ou modifica as instruções conforme necessário, para se alinhar melhor com os objetivos do percurso de Clojure.

Neste exercício, no percurso de Clojure, podes **assumir que o resultado da função `allergies` é um vetor**, como indicam os testes.
No entanto, isto não é um requisito obrigatório; podes devolver qualquer coleção sequencial.
