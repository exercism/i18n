# Introdução

## Exceções

As exceções em C# oferecem uma forma estruturada, uniforme e com segurança de tipos de tratar condições de erro que ocorrem em tempo de execução. Tratar bem as exceções e os erros é importante quando tentas evitar que a aplicação vá abaixo.

Em C#, todas as exceções têm a classe `System.Exception` como tipo base. Esta contém propriedades importantes como `Message`, que contém uma descrição legível do motivo pelo qual a exceção foi lançada.

Para sinalizar que deve haver um erro numa determinada parte do código, é preciso criar um novo objeto de exceção e depois lançá-lo, usando a palavra-chave `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Quando uma exceção é lançada, o runtime tem a tarefa de encontrar um pedaço de código responsável por tratar essa exceção. Se não for encontrado um tratador adequado, o runtime mostra a mensagem de exceção não tratada e, além disso, interrompe a execução do programa.

Para criar um tratador para uma exceção, o C# usa a instrução try-catch, que consiste num bloco `try` e numa ou mais cláusulas `catch`. O bloco `try` deve conter e proteger o código que pode fazer com que a exceção seja lançada. As cláusulas `catch` devem conter o código que trata o comportamento do programa depois de o erro ter ocorrido. É importante notar que a ordem das exceções é relevante depois do bloco `try`: quando são listadas várias exceções, é executada a primeira cláusula `catch` que corresponder.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
