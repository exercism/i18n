# Introdução

Os erros acontecem. Em Elixir, embora se diga muitas vezes "let it crash", há alturas em que precisamos de recuperar a chamada da função para um estado válido conhecido, para cumprir um contrato de software. Nalgumas linguagens, os erros são usados como método de fluxo de controlo, mas em Elixir este padrão é desaconselhado. Muitas vezes conseguimos reconhecer as funções que podem lançar um erro só pelo nome: as funções que lançam erros têm `!` no fim do nome. É o contrário das funções que devolvem `{:ok, value}` ou `:error`. Repara nestes exemplos da biblioteca:

```elixir
Map.fetch(%{a: 1}, :b)
# => :error
Map.fetch!(%{a: 1}, :b)
# => raises KeyError
```
