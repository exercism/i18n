# Sobre

Uma definição de coleção inclui normalmente um marcador de posição entre sinais de menor e maior, muitas vezes T por convenção. Uma coleção deste tipo é designada por tipo genérico. Isto permite que quem usa a coleção especifique que tipo de itens deve guardar nela. No exemplo de código acima, estamos a instanciar uma lista de strings.

Uma classe ou uma função torna-se **genérica** com o atributo `@:generic`. Isto faz com que o compilador identifique a classe ou a função como genérica:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
