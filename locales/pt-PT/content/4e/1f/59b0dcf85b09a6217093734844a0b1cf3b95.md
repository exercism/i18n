# Instruções

A tua tarefa é analisar uma string no formato Smart Game Format (SGF) e devolver uma estrutura de dados em árvore que represente o jogo.

Uma string SGF representa uma árvore de nós. A árvore inteira está envolvida em parênteses `()`.
Cada nó da árvore é indicado por um ponto e vírgula `;`, seguido de uma sequência de propriedades.
Uma propriedade é composta por um identificador em maiúsculas (por exemplo, `AB`), seguido de um ou mais valores entre parênteses retos `[]`.

Por exemplo, a string `(;FF[4]C[root])` representa uma árvore com um único nó raiz. Esse nó tem duas propriedades:
- A propriedade `FF` com o valor `4`
- A propriedade `C` com o valor `root`

**Variações (árvores e ramos)**
O SGF suporta variações de jogo através do aninhamento de árvores. Uma árvore pode ter várias árvores filhas, que também são envolvidas em parênteses.
Por exemplo, `(;A[B](;C[D])(;E[F]))` representa um nó raiz com a propriedade `A`, que tem dois ramos filhos:
1. Um nó com a propriedade `C` e o valor `D`
2. Um nó com a propriedade `E` e o valor `F`

**Formatação e escape**
Os valores dentro de parênteses retos podem conter carateres de escape. Uma barra invertida `\` seguida de qualquer caráter representa esse caráter literal (por exemplo, `\]` deve ser analisado como um `]` literal). Além disso, se uma nova linha for precedida por uma barra invertida, funciona como uma continuação de linha e deve ser removida do valor. Todas as outras novas linhas dentro de um valor devem ser preservadas.

**Tratamento de erros**
Tens de lançar um erro para strings SGF inválidas. Os exemplos seguintes são casos de SGF inválido:
- Uma árvore que não começa com parênteses `()`.
- Um nó que não começa com um ponto e vírgula `;`.
- Identificadores de propriedade que não sejam compostos apenas por letras maiúsculas.
- Parênteses retos em falta ou parênteses desemparelhados.

### Estrutura de dados

A tua função de análise deve devolver uma representação da árvore. Uma abordagem comum é representar cada árvore como um objeto com dois campos:
- `properties`: um objeto (ou Map) em que as chaves são os identificadores das propriedades (strings) e os valores são arrays de strings (uma vez que uma propriedade pode ter vários valores).
- `children`: um array que contém as árvores filhas.


Exemplo:

Entrada: `(;FF[4]C[root])`
Saída: `{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

Entrada: `(;A[B](;C[D])(;E[F]))`
Saída: `{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
