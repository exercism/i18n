# Instruções

Estás a fazer a manutenção do conjunto de ferramentas de geração de código de uma estação de sinais.
Cada macro é um *stencil*: um pequeno molde que o compilador usa para
gerar código especializado em cada ponto de chamada.

Tu escreves apenas as quatro macros. O ficheiro de testes define pequenas
palavras que servem de invólucro às tuas macros e que as *chamam* (uma macro só pode ser
observada através do código que gera); depois verifica os
resultados de execução desses invólucros. Deixa os invólucros como estão.

Em cada tarefa, o corpo recebe na pilha os valores literais
do ponto de chamada e tem de deixar **uma quotation**. As linhas "compila para"
mostram o código linear que a tua quotation deve produzir.

## 1. Duas vezes

`twice` recebe uma quotation literal e devolve uma quotation que
executa a original duas vezes seguidas.

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N repetições

`repeat-quot` recebe uma quotation literal e uma contagem literal `n`
e devolve uma quotation que executa a original `n` vezes seguidas.
`n = 0` devolve a quotation vazia `[ ]`.

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. Compor várias

`compose-many` recebe um array literal de quotations e devolve uma
única quotation que executa cada uma por sua vez. Um array vazio
devolve a quotation vazia.

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. Iteração desenrolada

`each-literal` recebe uma sequência literal e uma quotation. Devolve
uma quotation que, para cada elemento da sequência, empilha
esse elemento e depois executa a quotation. É uma iteração que acontece
em tempo de compilação, por isso o código gerado é linear.

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

Esta é a mais estrutural das quatro: tanto o comprimento da sequência
*como* os valores dos seus elementos moldam o código gerado. As
dicas acompanham a sua construção passo a passo.
