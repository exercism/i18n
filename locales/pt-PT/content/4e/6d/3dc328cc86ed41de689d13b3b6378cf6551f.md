# Introdução

## A instrução _if-then_

A instrução de fluxo de controlo mais básica em Java é a instrução _if-then_.
Esta instrução serve para executar uma secção de código apenas se uma determinada condição for `true`.
Uma instrução _if-then_ é definida com a cláusula `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

No exemplo acima, se o carro estiver sem combustível, chamar o método `Car.drive` não faz nada.

## A instrução _if-then-else_

A instrução _if-then-else_ oferece um caminho alternativo de execução para quando a condição da cláusula `if` é avaliada como `false`.
Este caminho alternativo de execução segue uma cláusula `if` e é definido com a cláusula `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

No exemplo acima, se o carro estiver sem combustível, chamar o método `Car.drive` chama outro método para parar o carro.

A instrução _if-then-else_ também permite várias condições através da cláusula `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

No exemplo acima, conduzir o carro quando o combustível é menor ou igual a `5` faz o carro andar, mas acende a luz do combustível.
Quando o combustível chega a `0`, o carro deixa de andar.
