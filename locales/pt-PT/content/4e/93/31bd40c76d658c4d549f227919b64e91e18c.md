# Apêndice às instruções

## Instruções específicas do percurso

### Formato dos dados de entrada

Os dados de entrada serão apresentados no formato de uma string.
Para que este exercício continue acessível a quem está a começar, não precisas de contar com números com vários algarismos.

Os bytes 64 a 191 da memória linear estão reservados para a string de entrada.

### Formato dos dados de saída

Espera-se que os dados de saída sejam pares de linha e coluna na forma de u8, concatenados diretamente.

Por exemplo, se houver três pontos de sela

linha: 2, coluna: 1
linha: 2, coluna: 2
linha: 2, coluna: 3

então os dados de saída esperados seriam os valores u8 `2, 1, 2, 2, 2, 3`
