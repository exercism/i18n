# Sobre

O Haxe tem suporte incorporado para expressões regulares. Podem ser usadas para verificar o formato de uma string, transformar uma string ou extrair alguns dados regulares de um texto.

Para criar uma expressão regular, escreve entre `~/` e `/`:

```haxe
var r = ~/haxe/i;
```

Outra forma de o fazer é usar a instância `EReg()`:

```haxe
var r = new EReg("haxe", "i");
```

Aqui, o `i` é uma flag que faz com que o padrão não distinga maiúsculas de minúsculas. Existem outras flags, incluindo:

- `g`: substituição global.
- `m`: correspondência em várias linhas

Entre `~/` e `/`, escreves os padrões de expressão regular. Por exemplo, queres procurar uma string que contenha letras de A a Z. Aqui podemos usar o padrão de intervalo `[A-Z]`. Existem muitos padrões de expressão, incluindo:

- `.`: qualquer caráter
- `*`: repetir zero ou mais vezes
- `+`: repetir uma ou mais vezes
- `[A-Z0-9]`: intervalos de carateres
