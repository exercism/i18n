# Recursos

- O recurso mais importante é a [documentação oficial][docs]
- Para edição online, usa o [Uiua Pad][pad]
- Explora o código-fonte no [repositório GitHub][github] do Uiua
- Mantém-te a par do [Uiua Blog][blog] oficial

O [site principal][main] também inclui uma ligação para o servidor Discord, onde podes discutir Uiua com outros entusiastas.
