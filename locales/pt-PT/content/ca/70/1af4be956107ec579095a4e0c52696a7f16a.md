# Instruções

Trabalhas num parque de diversões e foi-te entregue uma especificação para conceberes um sistema que faça a gestão da afluência e das atrações. Foi-te pedido que modeles o Attendee (a pessoa que visita o parque).

## 1. Criar novos visitantes

Implementa o método `Attendee#initialize` da classe `Attendee`; este deve receber uma altura (em centímetros) e guardá-la numa variável de instância

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. Qual é a altura do visitante

Implementa o getter `Attendee#height` da classe `Attendee`; este deve devolver a altura da instância

```ruby
Attendee.new(106).height
# => 106
```

## 3. Qual é o id do passe de atrações

Nem todos os visitantes compraram um passe de atrações, mas precisamos de saber se têm passe ou não. Implementa o getter `Attendee#pass_id` da classe `Attendee`; este deve devolver o `pass_id` da instância ou `nil` se o visitante não tiver um.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Permitir que as pessoas comprem um passe

Implementa `Attendee#issue_pass!` para alterar o estado da instância e definir a variável de instância do id do passe com o argumento. Deve devolver o id do passe.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Revogar o passe

Alguns visitantes infringem as regras com comportamentos inseguros, por isso o parque quer poder revogar passes. Implementa `Attendee#revoke_pass!` para alterar o estado da instância e definir o id do passe como `nil`

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
