# Anexo às instruções

## Trabalhar com datas em Prolog

O suporte de datas integrado no Prolog é [bastante rudimentar][built-in-dates-support].
Embora consigas resolver este exercício apenas com o que o Prolog traz integrado, há uma forma muito mais agradável de trabalhar com datas: o [pacote date_time][date-time-package].

### Instalar o pacote date_time

Se a versão do Swipl que tens instalada for relativamente recente, podes instalar o pacote executando:

```bash
swipl pack install date_time
```

Se isso não funcionar, podes executar:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Se estiveres a usar o editor online, não precisas de instalar nada manualmente.
~~~~

### Usar o pacote date_time

Adiciona o seguinte código ao topo do teu ficheiro de solução para usares o pacote `date_time`:

```prolog
:- use_module(library(date_time)).
```
