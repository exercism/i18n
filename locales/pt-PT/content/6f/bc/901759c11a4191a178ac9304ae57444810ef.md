# Dicas

## Geral

- As funções são apenas endereços de memória, e podem ser manipuladas como qualquer endereço de memória.
- Os endereços de memória são valores inteiros de 64 bits, passados e devolvidos nos registos habituais.
- É possível fazer `call` ou `jmp` para uma função guardada num registo ou na memória.

## 1. Memoriza uma transação

- As funções são apenas endereços de memória, e podem ser manipuladas como qualquer endereço de memória.
- Os endereços de memória são valores inteiros de 64 bits, passados e devolvidos nos registos habituais.
- `remember_transaction` deve guardar uma função numa localização de memória persistente.
- Em `apply_remembered`, o argumento a passar à função guardada já está armazenado no registo correto (`rdi`).

## 2. O manual do banco

- A tabela de despacho é apenas um array e pode ser indexada como qualquer array.
- Cada entrada na tabela de despacho é uma função, e as funções são valores inteiros de 64 bits (8 bytes).
- Em `select_transaction`, o argumento para a transação está originalmente em `rdx` e tem de ser movido para `rdi` antes de chamares a função.
- A chamada à transação despachada está em posição de cauda, por isso podes usar uma chamada de cauda (`jmp`).

## 3. Processa um extrato mensal

- Cada entrada no array é uma função, e as funções são valores inteiros de 64 bits (8 bytes).
- Qualquer registo preservado pelo chamador pode ser destruído por uma função externa, por isso deves guardar qualquer valor necessário antes de chamares uma função dessas.
  Os registos preservados pelo chamador são `rax`, `rcx`, `rdx`, `rdi`, `rsi`, `r8`, `r9`, `r10` e `r11`.
- Os registos preservados pela função chamada, como `rbx`, `rbp`, `r12`, `r13`, `r14` e `r15`, não são modificados por uma função chamada.
  No entanto, tens de guardar o valor original deles antes de os usares, e restaurar esse valor antes de regressares.
- A pilha deve estar alinhada a 16 bytes antes de chamares uma função externa.
  No ponto de entrada, `rsp` está 8 abaixo de um múltiplo de 16.
- Para um array vazio, não é aplicada nenhuma transação e a função deve devolver o saldo inicial sem alterações.

## 4. Processa com uma guarda

- Cada entrada no array é uma função, e as funções são valores inteiros de 64 bits (8 bytes).
- Qualquer registo preservado pelo chamador pode ser destruído por uma função externa, por isso deves guardar qualquer valor necessário antes de chamares uma função dessas.
- Os registos preservados pela função chamada, como `rbx`, `rbp`, `r12`, `r13`, `r14` e `r15`, não são modificados por uma função chamada.
  No entanto, tens de guardar o valor original deles antes de os usares, e restaurar esse valor antes de regressares.
- A pilha deve estar alinhada a 16 bytes antes de chamares uma função externa.
  No ponto de entrada, `rsp` está 8 abaixo de um múltiplo de 16.
- A função de guarda recebe como argumento o resultado de cada transação.
  Este valor tem de estar em `rdi` antes de chamares a função de guarda.
- A função de guarda devolve `0` para um resultado inválido, e um valor diferente de zero para um válido.
  Um resultado válido atualiza o saldo corrente e o número de transações aprovadas.
- A função devolve dois inteiros de 64 bits não negativos: o saldo final deve estar em `rax` e o número de transações aprovadas deve estar em `rdx`.
