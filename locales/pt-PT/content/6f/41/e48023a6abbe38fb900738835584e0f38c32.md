# Instalação

## Instalar o .NET

O percurso de F# assenta na plataforma [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), que funciona em Windows, Linux e macOS. Para criar projetos .NET, podes usar a interface de linha de comandos (CLI) do .NET. Esta CLI faz parte do SDK .NET, que podes instalar seguindo as [instruções de instalação](https://dotnet.microsoft.com/download). Nota: o percurso de F# requer a versão 8.0 ou superior do SDK.

Depois de concluíres a instalação, podes verificar se a CLI foi instalada com sucesso executando este comando num terminal:

```bash
dotnet --version
```

Se o resultado for uma versão igual ou superior a `8.0.100`, o SDK .NET foi instalado com sucesso.

## Usar um IDE

Se queres uma experiência de edição mais completa, provavelmente vais querer usar um IDE. Estes são os IDE mais populares que suportam a criação de projetos .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) com a [extensão Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Nota: como o formato dos projetos .NET é bastante diferente do das versões anteriores, os IDE mais antigos (como o Visual Studio 2015) não são suportados.
