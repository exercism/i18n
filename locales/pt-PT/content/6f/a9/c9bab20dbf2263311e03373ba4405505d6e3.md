# Recursos

Para além dos recursos de [aprendizagem][learning], aqui tens outros sítios que te podem ajudar no teu percurso com o Odin:

* [Playground do Odin][play], para experimentares no navegador.
* O repositório GitHub [odin-lang/Odin][gh].
* As ligações de [comunidade][community] do Odin (fórum, Discord, Reddit, etc.).
* [Artigos][articles] escritos por gingerBill, o criador do Odin.
  Dão-te uma ideia dos princípios de design da linguagem.
* [Guia de estilo][style].
* [Awesome Odin][awesome], uma coleção de ligações para bibliotecas e recursos do Odin.
* Uma [série de vídeos][vids] sobre o Odin e como o usar para desenvolvimento de jogos.
  Por Karl Zylinski, o autor do livro "Understanding Odin".
