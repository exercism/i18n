# Introdução

Uma definição de coleção normalmente inclui um marcador de posição entre sinais de menor e maior, muitas vezes T, por convenção. Esse tipo de coleção é chamado de tipo genérico. Isto permite ao utilizador da coleção especificar que tipo de itens guardar na coleção. No código de exemplo acima, estamos a instanciar uma lista de strings.

Uma classe ou uma função torna-se **genérica** com o atributo `@:generic`. Isto faz com que o compilador identifique a classe ou a função como genérica:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
