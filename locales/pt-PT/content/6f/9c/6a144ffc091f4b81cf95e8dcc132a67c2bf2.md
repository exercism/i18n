# Introdução

Em JavaScript, um vetor é uma estrutura semelhante a uma lista, sem comprimento fixo, que pode conter qualquer tipo de primitivos ou objetos, até tipos mistos.

Para criar um array, adiciona elementos entre parênteses retos `[]`.
Para ler a partir do array, coloca o índice entre parênteses retos `[]` depois do identificador.
Os índices de um array começam em zero.

Por exemplo:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Para obter o número de elementos que existem num array, usa a propriedade `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Para alterar um elemento do array, atribuis um valor no índice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Métodos

Alguns dos [métodos][mdn-array] disponíveis em todos os objetos Array podem ser usados para adicionar ou remover elementos do array.
Aqui ficam alguns que podes ter em conta quando trabalhas neste exercício:

### push

Um `value` pode ser _adicionado_ ao fim de um array usando `.push(value)`.
O método devolve o novo comprimento do array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

O _último_ `value` pode ser _removido_ de um array usando `.pop()`.
O método devolve o valor removido.
O comprimento do array diminui por causa desta alteração.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

O _primeiro_ `value` pode ser _removido_ de um array usando `.shift()`.
O método devolve o valor removido.
O comprimento do array diminui por causa desta alteração.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

Um `value` pode ser _adicionado_ ao início de um array usando `.unshift(value)`.
O método devolve o novo comprimento do array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

Um `value` num `index` específico pode ser _removido_ de um array usando `.splice(index, 1)`.
O método devolve o(s) elemento(s) removido(s).

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
Estes métodos são mais poderosos do que o descrito:

- Tanto `push` como `unshift` permitem adicionar vários valores de uma só vez, acrescentando mais argumentos.
  Isso não é necessário para completar este exercício.
- O Splice pode remover vários valores aumentando o segundo argumento.
  Isso não é necessário para completar este exercício.
- O Splice também pode adicionar vários valores, acrescentando-os como argumentos a seguir ao `deleteCount`.
  Isto pode ser usado para substituir valores ou inserir valores no meio de um array (por exemplo, removendo 0 elementos).
  Isso não é necessário para completar este exercício.
