# Dicas

## Geral

- Lê a documentação sobre [conjuntos][set]
- A documentação sobre [listas][lists] também pode ser útil

## 1. Começa uma coleção

- A função `Set` mais adequada é [`Set.singleton`][singleton]

## 2. Aumenta a coleção

- Usa a [função `Set.insert`][insert]
- Usa a [função `Set.member`][member]

## 3. Começa a trocar

- Usa a [função `Set.member`][member]
- Usa a [função `Set.insert`][insert]
- Usa a [função `Set.remove`][remove]

## 4. Só pode haver um de cada

- Um `Set` tem a propriedade de conter apenas valores únicos
- Usa a [função `Set.fromList`][fromList]
- Usa a [função `Set.toList`][toList]
- `Set.toList` devolve garantidamente uma lista ordenada

## 5. Cartas que não têm

- Usa a [função `Set.diff`][diff]
- Usa a [função `Set.size`][size]

## 6. Cartas que todos têm

- Usa as [funções `List.foldl` ou `List.foldr`][fold]
- Usa a correspondência de padrões na lista para distinguir listas vazias de listas não vazias
- Usa a [função `Set.intersect`][intersect]
- Usa a [função `Set.toList`][toList]
- `Set.toList` devolve garantidamente uma lista ordenada

## 7. Todas as cartas

- Usa as [funções `List.foldl` ou `List.foldr`][fold]
- Usa [`Set.empty`][empty] como acumulador
- Usa a [função `Set.union`][union]
- Usa a [função `Set.size`][size]

## 8. Shiny para ganhar

- Usa a [função `Set.partition`][partition]
- Usa a [função `String.startsWith`][startsWith]
- Usa a [função `Set.toList`][toList]
- `Set.toList` devolve garantidamente uma lista ordenada
