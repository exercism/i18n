# Dicas

## 1. Criar a tabela de pontuações máximas

- A tabela de pontuações máximas tem de ser uma tabela de dispersão.
- Podes criar uma tabela de dispersão com `make-hash-table`.

## 2. Adicionar um jogador à tabela

- Para adicionar um par chave/valor a uma tabela de dispersão, usa `(setf (gethash key table) value)`

## 3. Definir a pontuação de um jogador

- Definir a pontuação de um jogador é quase idêntico a adicionar o jogador à tabela.
- Para adicionar um par chave/valor a uma tabela de dispersão, usa `(setf (gethash key table) value)`

## 4. Obter uma pontuação da tabela

- Usa `gethash` para obter o valor associado a uma chave na tabela de dispersão.
- `gethash` tem um terceiro argumento opcional, que é o valor a usar se a chave não for encontrada.

## 5. Remover um jogador da tabela

- Usa `remhash` para remover uma chave da tabela.
