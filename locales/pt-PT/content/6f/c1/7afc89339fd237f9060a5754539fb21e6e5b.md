# Instalação

## Requisitos

* Um processador x86 de 64 bits
* Um compilador de C moderno
* A ferramenta de compilação Make
* O Netwide Assembler (NASM)

Tem em atenção que este track só suporta a convenção de chamada do System V AMD64 ABI. Quem usa Windows terá de instalar o Windows Subsystem for Linux (WSL) ou criar uma máquina virtual com Linux.

## Linux

Instala o software necessário com o gestor de pacotes do teu sistema:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Instala as Xcode Command Line Tools:

```bash
$ xcode-select --install
```

Instala o NASM com o [Homebrew](http://brew.sh/):

```bash
$ brew install nasm
```

## Windows

Para instalar o WSL, consulta https://docs.microsoft.com/en-us/windows/wsl/install-win10.
