# Introdução

Do [manual][man-types]

> O jq suporta o mesmo conjunto de tipos de dados que o JSON: números, strings, Boolean, arrays, objetos (que, no jargão do JSON, são hashes apenas com chaves do tipo string) e "null".

Vamos concentrar-nos nos **números**.

## Números e operadores numéricos

Todos os números, sejam inteiros ou não, são números de vírgula flutuante de precisão dupla IEEE754.
Isto limita-nos a 53 bits de precisão.

Os operadores habituais estão disponíveis para usar com números:

- aritmética: `+`, `-`, `*`, `/`, `%`
- comparação: `==`, `!=`, `<`, `<=`, `>=`, `>`
- [funções matemáticas][man-math] padrão

  Para funções com um parâmetro de entrada, envia o valor para a função através de um pipe

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Para funções com dois parâmetros de entrada, as funções ignoram o valor de entrada e esperam
  esses valores como parâmetros (lembra-te de que os parâmetros são separados por pontos e vírgulas)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  O ponto e vírgula é o separador dos argumentos das funções, não a vírgula.

## Outras expressões em `jq`

Para resolveres o exercício, vais precisar de conhecer as expressões condicionais.

### Expressões condicionais

O `jq` usa uma [expressão `if-then-else`][if-then-else] para as **expressões condicionais**.
Enquanto _expressão_, é colocada numa pipeline.

A sintaxe é: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

A cláusula `else` é opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

As condições adicionais usam `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
