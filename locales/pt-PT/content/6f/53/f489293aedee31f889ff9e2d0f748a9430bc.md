# Dicas

## Geral

- Não te preocupes com a forma como os argumentos são _derivados_; foca-te em combinar os argumentos para devolver o resultado pretendido.

## 0. Define um estado da máquina

- Define uma variável com o nome `PowerOn` e um valor [boolean][booleans] verdadeiro.

## 1. Define se o Pac-Man consegue comer um fantasma

- Podes usar o [operador][logical-operators] `-and` para combinar argumentos e obter um resultado.


## 2. Define se o Pac-Man marca pontos

- Podes usar o [operador][logical-operators] `-or` para combinar argumentos e obter um resultado.


## 3. Define se o Pac-Man perde

- Podes usar o [operador][logical-operators] `-not` para combinar argumentos e obter um resultado.


## 4. Define se o Pac-Man ganha

- Combina os [operadores][logical-operators] anteriores para obter o resultado.


## 5. Escreve o SYNOPSIS para a condição de vitória

- Escreve uma descrição breve no bloco de comentários da última função `Win`, usando a [palavra-chave][keywords] `SYNOPSIS`.
