# Introdução

## Booleanos

Os booleanos em Java são representados pelo tipo `boolean`, que pode assumir os valores `true` ou `false`.

O Java suporta três operadores booleanos:  

- `!` (NOT): nega o booleano  
- `&&` (AND): recebe dois booleanos e devolve `true` se ambos forem `true`
- `||` (OR): devolve `true` se um dos dois booleanos for `true`

### Exemplos

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
