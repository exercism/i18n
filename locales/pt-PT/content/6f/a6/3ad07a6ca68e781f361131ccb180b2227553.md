# Introdução

## Strings

Uma `String` em Java é um objeto que representa texto imutável como uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.).
Usam-se aspas duplas para definir uma instância de `String`:

```java
String fruit = "Apple";
```

As strings são manipuladas através da chamada dos métodos da string.
Uma vez construída uma string, o seu valor nunca pode mudar.
Quaisquer métodos que pareçam modificar uma string devolvem, na verdade, uma nova string.
A classe `String` fornece alguns métodos _static_ para transformar as strings.
