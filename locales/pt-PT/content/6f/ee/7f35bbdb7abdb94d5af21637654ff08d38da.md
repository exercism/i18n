# Introdução

Um [`Set`][set] é uma coleção de elementos com as seguintes propriedades:

- Sem ordem definida.
- As entradas são únicas, por isso as tentativas de adicionar duplicados são ignoradas silenciosamente.
- Suporta muitas das operações habituais nos conjuntos matemáticos.

Cria um `Set` com o construtor `Set()`, usando qualquer iterador como parâmetro.

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

Adiciona novos elementos com `push!()` (tal como acontece com os arrays) e remove-os com `delete!()`.

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## Operações com conjuntos

Tal como acontece com vários outros tipos de coleção, verifica se um elemento pertence ao conjunto com o operador `in` ou `∈` (usa `\in` e depois a tecla de tabulação para obter o símbolo).

```julia-repl
julia> 3 ∈ s1
true
```

São suportadas as seguintes operações sobre pares de conjuntos (os atalhos para o símbolo do operador são mostrados entre parênteses).

- `union(A, B)` ou `A ∪ B` (`\cup`): todas as entradas em A ou em B, ou em ambos.
- `intersect(A, B)` ou `A ∩ B` (`\cap`): todas as entradas comuns a A e a B.
- `setdiff(A, B)` (sem símbolo): as entradas que estão em A mas não em B.
- `symdiff(A, B)` (sem símbolo): as entradas que estão em A ou em B, mas não em ambos.
- `issubset(A, B)` ou `A ⊆ B` (`\subseteq`) ou `B ⊇ A` (`\supseteq`): `true` se todas as entradas de A também estiverem em B.
- `issetequal(A, B)` (sem símbolo): `true` se A e B contiverem exatamente as mesmas entradas.
- `isdisjoint(A, B)` (sem símbolo): `true` se A e B não tiverem entradas em comum (ou seja, se a interseção for vazia).

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

Existem também versões mutantes de muitas destas operações, com um `!` acrescentado ao nome da função.
Consulta o [manual][set] para veres a lista completa de funções.
