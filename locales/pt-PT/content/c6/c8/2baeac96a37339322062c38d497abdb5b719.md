# Dicas

## 1. Obter a primeira carta

- [Este artigo][mdn-destructuring] tem uma boa visão geral da desestruturação de arrays. Encontras um exemplo de atribuição básica de variáveis na secção 'Basic Array Destructuring'.

## 2. Obter a segunda carta

- Podes usar marcadores de posição para ignorar um ou mais valores do array.
- Encontras um exemplo [na MDN][mdn-destructuring-ignore-value].

## 3. Trocar as duas cartas

- É possível trocar dois valores numa única expressão de desestruturação.
- Encontras um exemplo [na MDN][mdn-destructuring-swapping].

## 4. Deslocar três cartas

- É possível alterar a posição de três valores numa única expressão de desestruturação.
- É o mesmo que trocar dois valores, mas com três (ou mais).

## 5. Escolher a pilha nomeada

- Os objetos podem ser desestruturados tal como os arrays.
- Encontras um exemplo [na MDN][mdn-object-destructuring-basic-assignment].

## 6. Trocar as pilhas nomeadas

- Quando uma propriedade é extraída de um objeto, pode ser renomeada com uma sintaxe específica.
- Encontras um exemplo [na MDN][mdn-object-destructuring-object-rename].
