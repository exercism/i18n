# Dicas

## 1. Inserir um cartão no topo da pilha

- A [função `queue.push_back`][push-back] pode ser usada para adicionar um elemento ao fim de uma fila.

## 2. Retirar o cartão do topo da pilha

- A [função `queue.pop_back`][pop-back] pode ser usada para remover um elemento do fim de uma fila.

## 3. Inserir um cartão na base da pilha

- A [função `queue.push_front`][push-front] pode ser usada para adicionar um elemento ao início de uma fila.

## 4. Retirar um cartão da base da pilha

- A [função `queue.pop_front`][pop-front] pode ser usada para remover um elemento do início de uma fila.
