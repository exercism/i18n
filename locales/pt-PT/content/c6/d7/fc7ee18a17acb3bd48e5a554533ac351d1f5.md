# Dicas

## 1. Estima o tempo de preparação

- Usa o [`size()`][size-func] do vector para determinar o número de camadas (o comprimento da fatia de camadas).

## 2. Calcula as quantidades de noodles e sauce necessárias

- Começa por criar um objeto `amount` para registar a quantidade de noodles e sauce.
- Usa um [ciclo for][for-loop] para percorrer as camadas.
- Se encontrares uma camada `"noodles"` ou `"sauce"` no ciclo, aumenta em conformidade a quantidade guardada no objeto `amount`.

## 3. Adiciona o ingrediente secreto

- Volta a ver os [vectors][concept-vector] para descobrires como obter um elemento de um vector e como substituir um elemento num vector.
- O índice do último elemento de um vector `a` é `a.size() - 1`, ou podes usar `a.back()` diretamente.

## 4. Escala a receita

- Primeiro, cria uma nova fatia do mesmo tamanho que a fatia de entrada.
- Usa um [ciclo for][for-loop] para percorrer a fatia de entrada e gerar a fatia de saída.

## 5. Desbloqueia o Segredo da Família

- Podes reutilizar o teu código da tarefa 3.
- Esta tarefa precisa de [sobrecarga de funções][function overloading].
