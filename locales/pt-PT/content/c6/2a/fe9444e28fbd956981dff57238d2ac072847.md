# Introdução

## Métodos de extensão

Os métodos de extensão permitem adicionar métodos a tipos já existentes sem criar um novo tipo derivado, sem recompilar e sem modificar de outra forma o tipo original. São definidos como métodos estáticos, mas são chamados com a sintaxe de um método de instância. O primeiro parâmetro é precedido do modificador `this` e especifica o tipo sobre o qual o método opera. Os métodos de extensão são trazidos para o âmbito ao nível do espaço de nomes.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
