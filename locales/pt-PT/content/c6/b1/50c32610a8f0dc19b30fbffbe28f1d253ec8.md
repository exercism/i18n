# Introdução

Em JavaScript, as _template strings_ permitem incorporar expressões em strings, o que também se designa por interpolação de strings.
Esta funcionalidade estende a do objeto global incorporado [`String`][string-reference].

Podes criar _template strings_ em JavaScript envolvendo o texto em acentos graves.
Além de permitirem que o texto inclua novas linhas e outros carateres especiais, também te deixam incorporar variáveis e outras expressões.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

No exemplo acima, os acentos graves (<code>\`\`</code>) são usados para representar uma _template string_. O `${...}` é o marcador de posição usado para a substituição.
Todos os tipos que não sejam strings são convertidos _implicitamente_ em strings.
Este tópico é abordado no conceito [conversão de tipos][type-conversion-concept].
Todos os tipos de expressões podem ser usados com _template strings_.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Quando precisas de formatar strings em várias linhas:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Com as capacidades de substituição disponíveis, também podes introduzir lógica no processo para determinar qual deve ser a string final.

Um exemplo disto é incorporar um [operador ternário][ternary-operator].
Este operador é uma forma abreviada de escrever uma instrução `if/else`.
A sintaxe é `condition ? consequent-expression : alternative-expression`.
Se a condição for verdadeira, devolve-se o operando do lado esquerdo dos dois pontos.
Caso contrário, o resultado da expressão ternária é o operando do lado direito dos dois pontos.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
