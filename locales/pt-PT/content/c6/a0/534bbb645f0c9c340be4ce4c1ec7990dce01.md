# Instruções

A empresa para a qual trabalhas está prestes a lançar o seu novo smartphone, chamado **Smarty 5**. Tem um sistema de câmara novinho em folha, um novo design e um processador revolucionário que corre um novo sistema operativo chamado **smartyOS**.

O novo processador tem potência para lidar com palavras-passe mais seguras do que nunca, e a empresa decidiu tirar partido disso.
Pediram-te para implementares um sistema de bloqueio por palavra-passe para o telefone, que permita ao utilizador definir uma palavra-passe e depois verificar se uma palavra-passe fornecida está correta.

~~~~exercism/caution
O sistema de palavras-passe praticado neste exercício não é seguro e serve apenas para fins educativos.
**NÃO** deve ser usado em nenhuma aplicação do mundo real.
~~~~

## 1. Define uma palavra-passe

O telefone permite aos utilizadores usar vários tipos diferentes de palavras-passe, desde uma simples palavra-passe de algarismos até uma palavra-passe alfanumérica mais segura e até uma palavra-passe que guarda a impressão digital.

Estes diferentes tipos de palavras-passe usam tipos diferentes: a palavra-passe de algarismos usa um `Int32`, a palavra-passe alfanumérica usa uma `String` e a palavra-passe de impressão digital usa um `Float64`.

Implementa a classe `PasswordLock` com um inicializador que recebe qualquer um dos três tipos de palavras-passe como argumento e o guarda numa variável de instância chamada `@password`.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. Encripta a palavra-passe

A empresa decidiu encriptar a palavra-passe para que esta não fique guardada em texto simples e pediu-te para implementares um método que a encripte.

Cada tipo de palavra-passe tem a sua forma única de ser encriptado:

- Palavra-passe `Int32`: a palavra-passe é dividida por dois e arredondada para o número inteiro mais próximo.
- Palavra-passe `String`: a palavra-passe é invertida.
- Palavra-passe `Float64`: a palavra-passe é multiplicada por quatro.

Implementa um método de instância chamado `encrypt` que não recebe argumentos e que modifica a variável de instância `@password`, de forma a que fique encriptada.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. Verifica se uma palavra-passe está correta

A empresa também te pediu para implementares um método que verifique se uma palavra-passe fornecida está correta.

Querem que o método devolva `nil` se a palavra-passe estiver incorreta e `"Unlocked"` se a palavra-passe estiver correta.

Implementa um método de instância chamado `unlock?` que recebe como argumento a palavra-passe a verificar.
O método deve devolver `nil` se a palavra-passe estiver incorreta e `"Unlocked"` se a palavra-passe estiver correta.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
