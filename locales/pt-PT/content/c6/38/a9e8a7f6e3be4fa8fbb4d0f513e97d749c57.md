## 1. Transformar código em dados

- Existe uma [função incorporada][doc-code-string-to-quoted] que transforma uma string com código numa AST.

## 2. Analisar um único nó da AST

- Inspeciona o resultado do [`quote`][doc-quote] para te familiarizares com o aspeto das AST em excertos de código específicos.
- As operações que definem uma função são `:def` e `:defp`.
- A operação é o primeiro elemento de um tuplo de três elementos que representa um nó da AST.
- Neste exercício, podes ignorar completamente o segundo elemento do tuplo.
- O terceiro elemento do tuplo é a lista de argumentos da operação que define a função.
- O primeiro elemento dessa lista é um tuplo com o nome e os argumentos da função, e o segundo elemento é o corpo da função.

## 3. Descodificar a parte da mensagem secreta da definição da função

- Inspeciona o resultado do [`quote`][doc-quote] para te familiarizares com o aspeto das AST em excertos de código específicos.
- O nó da AST que contém o nome da função contém também a lista de argumentos da função como terceiro elemento.
- A aridade de uma função é o comprimento da sua lista de argumentos.
- Existe uma [função incorporada no módulo `String`][string-slice] que consegue obter os primeiros `n` carateres de uma string.
- Uma função sem argumentos escrita sem parênteses não terá uma lista como argumento, mas sim um átomo.

## 4. Corrigir a descodificação para funções com guardas

- Inspeciona o resultado do [`quote`][doc-quote] para te familiarizares com o aspeto das AST em excertos de código específicos.
- Quando uma função tem uma guarda, o terceiro elemento do tuplo da operação `:def/:defp` é um pouco diferente.
- Esse terceiro elemento é uma lista com dois elementos: o primeiro é o tuplo da operação `:when` e o segundo é o corpo da função.
- Os argumentos da operação `:when` são uma lista de dois elementos, em que o primeiro argumento é o nome da função e o segundo é a expressão da guarda.

## 5. Descodificar a mensagem secreta completa

- Usa a função `to_ast/1` que implementaste na primeira tarefa para criar a AST.
- Existe uma [função incorporada][macro-prewalk] que consegue visitar cada nó de uma AST com um acumulador.
- Usa a função `decode_secret_message_part/2` que implementaste nas tarefas anteriores para percorreres a AST.
- Para inverteres o acumulador no final e o transformares numa string, relembra o que sabes sobre o [módulo `Enum`][enum].
