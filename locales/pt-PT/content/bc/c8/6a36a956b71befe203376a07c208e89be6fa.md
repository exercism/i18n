# Introdução

O Unison representa os valores true e false com o tipo `Boolean`. Há apenas dois valores: `true` e `false`.

```unison
trueVariable = true
falseVariable = false
```

Podemos avaliar expressões booleanas com os operadores e, representado por `&&`; ou, representado por `||`; e não, representado por `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

As expressões booleanas em Unison permitem avaliação de curto-circuito. Se o primeiro argumento de uma expressão com `&&` for `false`, não há razão para continuar a avaliar o segundo argumento.
Da mesma forma, se o primeiro argumento de uma expressão com `||` for `true`, a expressão devolve imediatamente `true`.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
