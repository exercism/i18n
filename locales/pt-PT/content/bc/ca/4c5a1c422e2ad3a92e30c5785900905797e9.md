# Permissões de repositório dos mantenedores

Um mantenedor de um percurso é alguém que faz parte da equipa do GitHub do percurso. Tornar-se membro da equipa de um percurso é _só por convite_.

```exercism/note
Se queres tornar-te mantenedor de um percurso, abre um tópico no [fórum](https://forum.exercism.org/c/exercism/building-exercism/125).
```

## Categoria de manutenção

Existem cinco categorias de manutenção:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

A categoria de manutenção de um percurso é determinada por três variáveis:

1. Se o percurso está ativo (ou seja, se os estudantes podem inscrever-se no percurso no site)
2. O número de mantenedores do percurso
3. O número de mantenedores do percurso que também fazem parte da equipa do GitHub `cross-track-maintainers`

Para determinar a categoria de manutenção, encontra a primeira categoria desta tabela que corresponde ao percurso:

| Categoria             | Ativo? | Número de mantenedores | Número de mantenedores cross-track |
| --------------------- | ------ | ---------------------- | ---------------------------------- |
| wip-track             | Não    | Qualquer               | Qualquer                           |
| unmaintained          | Sim    | 0                      | 0                                  |
| maintained-autonomous | Sim    | > 0                    | = Número de mantenedores           |
| maintained-solitary   | Sim    | 1                      | 0                                  |
| maintained            | Sim    | > 1                    | < Número de mantenedores           |

## Permissões de repositório

A categoria de manutenção é usada para definir as permissões do(s) repositório(s) do GitHub do percurso.

| Categoria             | Requer PR | Requer aprovação de PR | Revisões da equipa cross-track |
| --------------------- | --------- | ---------------------- | ------------------------------ |
| wip-track             | Não       | Não                    | Não                            |
| unmaintained          | Sim       | Sim                    | Sim                            |
| maintained-solitary   | Sim       | Sim                    | Sim                            |
| maintained-autonomous | Sim       | Não                    | Não                            |
| maintained            | Sim       | Não                    | Não                            |

```exercism/caution
A categoria `wip-track` é a única que permite aos mantenedores fazer push para `main`.
```

```exercism/caution
Os repositórios de ferramentas vão _sempre_ exigir aprovação de PR, uma vez que o seu conteúdo está protegido através de um [ficheiro CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners).
```
