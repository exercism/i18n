# Introdução

Uma expressão switch pode fazer corresponder um valor a um caso de um conjunto de padrões e devolver o valor associado ou executar a ação associada. A associação é indicada pelo símbolo `=>`. Além disso, cada padrão pode ter uma guarda de caso opcional, introduzida com a palavra-chave `when`. A expressão da guarda de caso tem de ser avaliada como verdadeira para que esse «braço» do switch seja selecionado. Os casos (também conhecidos como _braços do switch_) são avaliados pela ordem do texto e o processo é interrompido, devolvendo-se o valor associado, assim que se encontra uma correspondência.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
