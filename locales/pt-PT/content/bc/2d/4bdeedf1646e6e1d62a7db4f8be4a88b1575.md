# Dicas

## Geral

- Existem três operadores Boolean para trabalhar com valores Boolean: `not`, `&&` e `||`.
- Podes combinar vários operadores numa única expressão.

## 1. Define se o pac-man pode comer um fantasma

- A função tem de devolver um valor `Bool`.
- Podes usar o operador Boolean `&&` para combinar os argumentos e obteres um resultado.

## 2. Define se o pac-man marca pontos

- A função tem de devolver um valor `Bool`.
- Podes usar o operador Boolean `||` para combinar os argumentos e obteres um resultado.

## 3. Define se o pac-man perde

- A função tem de devolver um valor `Bool`.
- Podes usar os operadores Boolean `&&` e `not` para combinar os argumentos e obteres um resultado.

## 4. Define se o pac-man ganha

- A função tem de devolver um valor `Bool`.
- Podes usar os operadores Boolean `&&` e `not` para combinar os argumentos e o resultado de uma das funções implementadas anteriormente.
