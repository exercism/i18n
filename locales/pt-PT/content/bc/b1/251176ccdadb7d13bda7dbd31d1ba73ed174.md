# Instruções

Implementa um programa que traduza de inglês para Pig Latin.

O Pig Latin é uma linguagem infantil inventada, feita para ser confusa. Obedece a algumas regras simples (abaixo), mas, quando é falada depressa, torna-se muito difícil de entender para quem não é criança (e para quem não é falante nativo).

- **Regra 1**: Se uma palavra começa por um som de vogal, acrescenta um som "ay" ao fim da palavra. Repara que "xr" e "yt" no início de uma palavra produzem sons de vogal (por exemplo, "xray" -> "xrayay", "yttria" -> "yttriaay").
- **Regra 2**: Se uma palavra começa por um som consonântico, move-o para o fim da palavra e acrescenta depois um som "ay" ao fim da palavra. Os sons consonânticos podem ser formados por várias consoantes, ou seja, um grupo consonântico (por exemplo, "chair" -> "airchay").
- **Regra 3**: Se uma palavra começa por um som consonântico seguido de "qu", move-o para o fim da palavra e acrescenta depois um som "ay" ao fim da palavra (por exemplo, "square" -> "aresquay").
- **Regra 4**: Se uma palavra contém um "y" depois de um grupo consonântico ou como segunda letra de uma palavra de duas letras, produz um som de vogal (por exemplo, "rhythm" -> "ythmrhay", "my" -> "ymay").

Há mais algumas regras para casos especiais e também existem variantes regionais.

Consulta <http://en.wikipedia.org/wiki/Pig_latin> para mais detalhes.
