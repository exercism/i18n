# Sobre

[ABAP][abap] é uma linguagem de programação desenvolvida pela SAP para o desenvolvimento de aplicações de negócio com o ambiente de desenvolvimento ABAP de uma ABAP Platform.

O ABAP suporta o seguinte:

- Um modelo de programação orientada a objetos baseado em classes e interfaces do ABAP Objects.
- Um modelo de programação procedural baseado em módulos de função e sub-rotinas.

Ambos os modelos são interoperáveis, mas no Exercism o foco está exclusivamente no modelo de programação orientada a objetos.

Podes encontrar mais informações na documentação do [ABAP Track][docs].
