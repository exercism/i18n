# Strings

Uma **string** é um pedaço de texto. O tipo de Sather para uma string é `STR`, e uma string escreve-se entre aspas duplas.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## Juntar strings

`+` junta duas strings uma a seguir à outra.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

Não fica nada entre elas, por isso é preciso pedir um espaço. Se o deixares de fora, obténs `"JeanSibelius"`.

## Qual é o comprimento?

`.size` indica quantos carateres tem uma string. É um número inteiro, por isso o seu tipo é `INT`.

```sather
"Sibelius".size      -- 8
```

Não há parênteses depois de `.size`, tal como numa rotina que não recebe argumentos.

## Tirar uma parte

`.head(n)` devolve os primeiros `n` carateres. `.tail(n)` devolve os últimos `n`.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` conta a partir do início, `tail` conta a partir do fim. Ambos deixam a string original intacta e devolvem uma nova.
