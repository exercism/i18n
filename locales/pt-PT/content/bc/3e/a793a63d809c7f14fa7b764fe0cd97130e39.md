# Acerca de

Em Elixir existem dois tipos de números diferentes: os inteiros e os números de vírgula flutuante.

Os inteiros são números inteiros.

```elixir
integer = 3
# => 3
```

Encontras algumas funções úteis para trabalhar com inteiros no módulo [`Integer`][integer].

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

Os inteiros grandes (mas também os números de vírgula flutuante) costumam ser formatados separando cada 3 algarismos em grupos com um underscore.

```elixir
1_000_000
# => 1000000
```

O tamanho máximo dos números em Elixir é limitado apenas pela memória disponível no sistema, porque o Elixir usa [aritmética de precisão arbitrária][arbitrary-precision-arithmetic].

O Elixir também suporta notações abreviadas para escrever [inteiros binários, octais e hexadecimais][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Comparação

Os inteiros e os números de vírgula flutuante podem ser considerados iguais ([`==`][kernel-equal]) se tiverem o mesmo valor. No entanto, como são de tipos diferentes, nunca são estritamente iguais ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
