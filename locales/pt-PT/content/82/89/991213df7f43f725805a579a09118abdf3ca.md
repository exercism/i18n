# Anexo às instruções

## Registos

| Registo | Utilização | Tipo    | Descrição                                              |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | valor de entrada     | endereço | primeira cor como string terminada em null                  |
| `$a1`    | valor de entrada     | endereço | segunda cor como string terminada em null                 |
| `$a2`    | valor de entrada     | endereço | terceira cor como string terminada em null (possivelmente vazia) |
| `$v0`    | valor de saída    | inteiro | valor da resistência                                         |
| `$t0-9`  | temporário | qualquer   | para armazenamento temporário                                  |
