## Formatação

Embora o Common Lisp não se importe com a indentação e a disposição do código, nem com o facto de usares espaços ou tabulações, isto é um aspeto importante nas submissões ao Exercism.
O widget de código do Exercism.org não lida bem com a mistura de tabulações e espaços, por isso recomenda-se que uses apenas espaços, para tornar o código mais legível para quem o revê.
Vê as definições do teu editor para saberes como fazer isto.
Abaixo estão instruções para editores populares de Common Lisp.

### VIM

Usa os seguintes comandos para garantir que o VIM usa apenas espaços na indentação:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(ou, numa só linha, `:set tabstop=2 shiftwidth=2 expandtab`). Podes acrescentar isto ao teu ficheiro `~/.vimrc` para o usares sempre.

### Emacs

O Emacs é muito adequado para editar Common Lisp e tem muitos pacotes adicionais poderosos disponíveis. A única coisa que precisas de fazer com um Emacs de origem para que funcione bem com o exercism.org é avaliar o seguinte código:

`(setq-default indent-tabs-mode nil)`

Podes colocá-lo no teu `~/.emacs` (ou `~/.emacs.d/init.el`) para que fique definido sempre que o Emacs arranca.

Um complemento sugerido para o Emacs e o Common Lisp é o [SLIME][slime], que oferece uma integração estreita com o REPL, o que torna a escrita e os testes iterativos muito fáceis.
