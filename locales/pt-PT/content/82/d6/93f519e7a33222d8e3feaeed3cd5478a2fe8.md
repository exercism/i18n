# Apêndice às instruções

## Implementação

Pressupostos:

1. O zero é sempre representado nas saídas como [0] em vez de [].
2. Em nenhum outro caso aparecem zeros à esquerda nas saídas.
3. Aceitam-se zeros à esquerda nas entradas.
4. Uma sequência vazia de algarismos de entrada é considerada zero, e não um erro.

Trata os casos problemáticos devolvendo um erro cujo método Error() devolve uma das seguintes mensagens:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
