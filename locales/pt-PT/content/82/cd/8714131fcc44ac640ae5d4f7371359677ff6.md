# Sobre

O [C++](https://en.wikipedia.org/wiki/C%2B%2B) (pronuncia-se «cê mais mais») é uma linguagem de programação de uso geral, desenvolvida por [Bjarne Stroustrup](https://en.wikipedia.org/wiki/Bjarne_Stroustrup) a partir de 1979, nos Bell Labs. É imensamente popular, sobretudo em aplicações que exigem velocidade e/ou acesso a determinadas características de baixo nível. É considerada uma linguagem de nível intermédio, uma vez que engloba tanto características de alto nível como de baixo nível.

O C++ suporta programação [procedural](https://en.wikipedia.org/wiki/Procedural_programming), [orientada a objetos](https://en.wikipedia.org/wiki/Object-oriented_programming), [funcional](https://en.wikipedia.org/wiki/Functional_programming) e [genérica](https://en.wikipedia.org/wiki/Generic_programming). Há compiladores de C++ para praticamente todas as plataformas, incluindo Windows, Mac OS e Linux.

Principais vantagens:
- **Segurança de tipos:** encapsula as operações inseguras necessárias
- **Segurança de recursos:** gerir recursos não é só gerir memória
- **Desempenho:** é importante para algumas partes de quase todos os sistemas
- **Previsibilidade:** para sistemas de tempo real críticos e não críticos
- **Ensinabilidade:** a complexidade do código deve ser proporcional à complexidade da tarefa
- **Legibilidade:** para pessoas e máquinas («analisabilidade»)
- **Mapeamento direto para o hardware:** das instruções e dos tipos de dados fundamentais
- **Abstração de custo zero:** classes com construtores e destrutores, herança, programação genérica, técnicas de programação funcional

O padrão do C++ é mantido pela Organização Internacional de Normalização (ISO), e a versão atual do C++, em junho de 2018, é o C++17 (o nome não significa que seja a 17.ª versão do C++, mas sim que o padrão foi ratificado em 2017).

A melhor coisa do C++ é que corre em tudo, desde processadores embebidos com recursos muito limitados até ao maior supercomputador mainframe, passando por todos os computadores pessoais.
