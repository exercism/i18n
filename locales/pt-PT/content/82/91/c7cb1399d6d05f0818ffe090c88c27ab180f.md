# Sobre

As [compreensões][for] oferecem uma forma de transformar _Enumerables_ de maneira fácil e declarativa. São _açúcar sintático_ para iterar sobre enumerables em Elixir.

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

Uma compreensão tem três partes:

1. _geradores_:
   - Valores enumerados a partir de estruturas que implementam o protocolo [_Enumerable_][enumerable].
   - Expressões de correspondência de padrões para desestruturar os valores enumerados.
2. _filtros_: condições Boolean, usadas para selecionar que valores enumerados usar na criação dos novos valores.
3. _Collectables_: uma estrutura que implementa o protocolo [_Collectable_][collectable], usada para recolher os novos valores.

Há compreensões de uma só linha e compreensões de várias linhas. Quando se usa mais do que um gerador, é enumerado um [produto cartesiano][cartesian-product] dos valores gerados. Isto significa que cada valor gerado pelo primeiro gerador é emparelhado uma vez com cada valor gerado pelo segundo gerador.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

O valor que aparece no bloco do é inserido no _collectable_ **por cada valor gerado** a partir do _enumerable_.

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

A correspondência de padrões pode ocorrer na compreensão, tanto no lado esquerdo do `<-` como numa linha própria.

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
