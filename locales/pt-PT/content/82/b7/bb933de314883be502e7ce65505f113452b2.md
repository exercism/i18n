# Instruções

Neste exercício, vais processar mensagens de log com seis níveis de gravidade.

Cada linha de log é uma string formatada da seguinte forma: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de log:

| NÍVEL     | NVL   |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. Analisar o nível de log

Define um enum `LogLevel` com seis elementos correspondentes aos níveis de log definidos acima.
De seguida, define a função `parse_log_level`, que recebe a mensagem de log como parâmetro e devolve o membro do enum correspondente ao seu nível.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. Suportar um nível de log desconhecido

Infelizmente, algumas mensagens de log aparecem ocasionalmente com uma gravidade _desconhecida_. Para tratar de forma elegante estas mensagens de log "misteriosas" na função `parse_log_level`, adiciona um membro `Unknown` ao enum `LogLevel`, que é devolvido quando se analisa um nível de log desconhecido:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. Converter uma mensagem de log no formato curto

O nível de log de uma linha de log é bastante verboso. Para reduzir o espaço em disco necessário para armazenar as mensagens de log, define-se um formato curto: `"[<CODE_LEVEL>]:<MESSAGE>"`.

Os códigos de nível de log seguem um mapeamento simples:

| NÍVEL     | CÓDIGO |
| --------- | ------ |
| `Trace`   | `0`    |
| `Debug`   | `1`    |
| `Info`    | `4`    |
| `Warning` | `5`    |
| `Error`   | `6`    |
| `Fatal`   | `7`    |
| `Unknown` | `42`   |

Define a função `convert_to_short_log()`, que recebe dois parâmetros:

1. Nível de log - o nível da mensagem de log enviada, por exemplo `LogLevel.Error`.
2. Mensagem de log - a mensagem, do tipo `str`.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. Criar um alias

Parece que o utilizador criou logs para `LogLevel.Warn` em vez de `LogLevel.Warning`. Cria um `alias` para `LogLevel.Warning` e devolve o novo membro alias na função `get_warn_alias`.

Isto pode ser feito na mesma classe enum `LogLevel` já definida no topo do ficheiro. Ambos os LogLevels devem apontar para o mesmo valor: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. Todos os nomes e valores dos membros

Define a função `get_members()`.

Esta função deve devolver uma lista de tuplas `(name, value)` com todos os membros do enum `LogLevel`.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
