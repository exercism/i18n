# Introdução

Em C#, as estruturas de dados que podem conter zero ou mais elementos são conhecidas como _coleções_. Um **array**, ou _vetor_, é uma coleção que tem um tamanho/comprimento fixo e cujos elementos têm de ser todos do mesmo tipo. Os elementos podem ser atribuídos a um array ou obtidos a partir dele através de um índice. Os arrays em C# são indexados a partir de zero, o que significa que o índice do primeiro elemento é sempre zero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Também podes definir arrays com uma notação abreviada que te permite criar o array e definir o seu valor ao mesmo tempo. Como o compilador já consegue perceber quantos elementos o array terá, o comprimento pode ser omitido:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Podes manipular os arrays chamando os métodos ou as propriedades de uma instância de array, ou usando os métodos estáticos definidos na classe `Array`.
