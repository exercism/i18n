# Sobre

A Scala é uma linguagem de programação que cresce contigo: de pequenos scripts a grandes aplicações multiplataforma.

A Scala combina a programação orientada a objetos e a programação funcional numa única linguagem concisa e de alto nível. Os tipos estáticos da Scala ajudam a evitar erros em aplicações complexas, e os seus ambientes de execução JVM, JavaScript e Native permitem-te construir sistemas de alto desempenho com acesso fácil a enormes ecossistemas de bibliotecas.

* Funcionalidades
    * Interoperabilidade com a JVM: a Scala corre na JVM, por isso as pilhas Java e Scala podem ser combinadas para uma integração perfeita.
    * Interoperabilidade com JS e Native: a Scala pode correr no navegador e em dispositivos nativos, graças ao [Scala.js](https://www.scala-js.org/) e ao [Scala Native](https://github.com/scala-native/scala-native)
    * Inferência de tipos: a Scala é de tipagem estática. No entanto, fornece inferência de tipos para aliviar o peso de um sistema de tipos avançado.
    * Orientada a objetos: a Scala é uma linguagem puramente orientada a objetos, no sentido em que cada valor é um objeto. Os tipos de dados e os comportamentos dos objetos são descritos por classes e traits. As abstrações de classe são estendidas por subclasses e por um mecanismo flexível de composição baseado em mixins, para evitar os problemas da herança múltipla.
    * Funcional: a Scala é também uma linguagem funcional, no sentido em que cada função é um valor. A Scala fornece uma sintaxe leve para definir funções anónimas, suporta funções de ordem superior, permite aninhar funções e suporta currying. As case classes da Scala e o seu suporte incorporado para pattern matching modelam os tipos algébricos usados em muitas linguagens de programação funcionais. Os objetos singleton oferecem uma forma cómoda de agrupar funções que não são membros de uma classe.
    * Concorrência e distribuição: usa operações de paralelismo de dados sobre coleções, usa atores para concorrência e distribuição, ou futuros para programação assíncrona.
