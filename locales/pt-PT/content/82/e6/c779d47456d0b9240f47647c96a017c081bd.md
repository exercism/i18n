# Introdução

A correspondência de padrões é o processo de ramificar consoante um valor corresponde a padrões previamente definidos, que podem ser profundos. Em Haxe, a **correspondência de padrões** é feita com a expressão `switch` e as expressões `case` individuais.

Considera esta estrutura de dados:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Os padrões são sempre testados de cima para baixo.
- O padrão que estiver mais acima e que corresponda ao valor de entrada é o que tem a sua expressão executada.
- Um padrão `_` corresponde a qualquer coisa, por isso `case _:` é equivalente a `default:`

## Correspondência de enums

Podes fazer correspondência com enums através do seu construtor, de forma natural:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
