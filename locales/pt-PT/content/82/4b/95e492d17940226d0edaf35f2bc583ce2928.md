# Instruções

A Mika, organizadora de eventos, foi promovida no trabalho e, como parte das suas novas responsabilidades, ficou responsável pela base de dados de eventos. Reparou rapidamente que muitos dos dados estão guardados de formas que os tornam difíceis de manipular, por isso vão juntar-se para os limpar com um script que só vai ser executado uma vez.

Como o script só vai ser executado uma vez e tens confiança na estrutura dos dados, achas que é um bom sítio para usar as _let assertions_ do Gleam.

## 1. Extrair os erros

Cada evento passado tem uma lista de problemas que ocorreram durante o evento. Estes foram guardados como resultados, mas são sempre a variante `Error`.


Implementa a função `extract_error`, que recebe um resultado que se espera ser sempre um `Error` e devolve o valor de erro contido.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. Remover o prefixo de equipa

Os nomes das equipas têm o prefixo "Team ", mas isso não é necessário. Implementa a função `remove_team_prefix` para remover o prefixo de um nome de equipa.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. Separar a região e a equipa

Cada evento é executado por uma equipa e cada equipa pertence a uma região. Na base de dados, estão guardados numa única string, separados por uma vírgula.

Implementa a função `split_region_and_team` para dividir a string num tuplo de duas strings, uma para a região e outra para a equipa. O prefixo "Team " deve ser removido do nome da equipa.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
