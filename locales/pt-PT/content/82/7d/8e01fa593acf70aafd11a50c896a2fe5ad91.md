# Introdução

## Fluxos

Todas as funções do [módulo `Enum`][exercism-enum] são _ávidas_. Quando fazes várias operações sobre enumeráveis com o módulo `Enum`, cada operação gera um resultado intermédio.

O módulo `Stream` é uma alternativa _preguiçosa_ ao módulo `Enum`, que é _ávido_. Oferece muitas das mesmas funções que o `Enum`, mas, em vez de gerar resultados intermédios, constrói uma série de cálculos que só são executados quando o fluxo é passado a uma função do módulo `Enum`.

Os fluxos implementam o _[protocolo][exercism-protocols] Enumerable_ e são componíveis. Podes encadeá-los para criar funcionalidades mais complexas.

[exercism-enum]: https://exercism.org/tracks/elixir/concepts/enum
[exercism-protocols]: https://exercism.org/tracks/elixir/concepts/protocols
