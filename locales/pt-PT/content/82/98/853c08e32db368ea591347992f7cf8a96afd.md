# Instruções

Como futura mágica, a Elyse precisa de praticar algumas coisas básicas. Tem um baralho de cartas que quer manipular.

Para tornar as coisas um pouco mais simples, usa apenas as cartas de 1 a 10, por isso o seu baralho pode ser representado por um array de números. A posição de uma determinada carta corresponde ao índice no array. Ou seja, a posição 0 refere-se à primeira carta, a posição 1 à segunda, e assim por diante.

<!-- prettier-ignore-start -->
~~~~exercism/note
Todas as funções, exceto duas, devem atualizar o array de cartas e depois devolver o array modificado. É uma forma de trabalhar comum, conhecida como Builder pattern, que te permite encadear funções umas nas outras de forma elegante.

As duas exceções são `getItem`, que deve devolver a carta na posição indicada, e `checkSizeOfStack`, que deve devolver `true` se o tamanho indicado corresponder.
~~~~
<!-- prettier-ignore-end -->

## 1. Retira uma carta do baralho

Para escolher uma carta, devolve a carta no índice `position` do baralho dado.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Troca uma carta do baralho

Faz um pouco de prestidigitação e troca a carta no índice `position` pela carta de substituição fornecida.
Devolve o baralho ajustado.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Insere uma carta no topo do baralho

Faz aparecer uma carta, inserindo uma nova carta no topo do baralho.
Devolve o baralho ajustado.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Remove uma carta do baralho

Faz desaparecer uma carta, removendo do baralho a carta na `position` indicada.
Devolve o baralho ajustado.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Remove a carta do topo do baralho

Faz desaparecer uma carta, removendo a carta do topo do baralho.
Devolve o baralho ajustado.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Insere uma carta no fundo do baralho

Faz aparecer uma carta, inserindo uma nova carta no fundo do baralho.
Devolve o baralho ajustado.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Remove uma carta do fundo do baralho

Faz desaparecer uma carta, removendo a carta do fundo do baralho.
Devolve o baralho ajustado.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Verifica o tamanho do baralho

Verifica se o tamanho do baralho é igual a `stackSize` ou não.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
