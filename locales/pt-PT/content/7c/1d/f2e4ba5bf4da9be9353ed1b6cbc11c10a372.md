# Instruções

A tua tarefa é adicionar a contagem de minas às casas vazias de um tabuleiro de Campo Minado já completo.
O próprio tabuleiro é um retângulo composto por casas que estão vazias (`' '`) ou que contêm uma mina (`'*'`).

Para cada casa vazia, conta o número de minas que lhe são adjacentes (na horizontal, na vertical e na diagonal).
Se a casa vazia não tiver minas adjacentes, deixa-a vazia.
Caso contrário, substitui-a pelo número de minas adjacentes.

Por exemplo, podes receber um tabuleiro 5 x 4 como este (aqui, os espaços vazios são representados com o caráter '·' para visualização no ecrã):

```text
·*·*·
··*··
··*··
·····
```

Que o teu código deve transformar neste:

```text
1*3*1
13*31
·2*2·
·111·
```
