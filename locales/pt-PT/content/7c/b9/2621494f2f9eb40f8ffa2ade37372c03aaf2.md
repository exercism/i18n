# Instruções

A Leslie, a alienígena do Lisp, precisa de fazer umas compras. É muito importante ter uma lista de compras. É preciso acrescentar coisas à lista e tirar coisas dela.

Claro que caneta e papel não chegam para uma alienígena do Lisp. "List" é a maior parte da palavra "Lisp"! Têm de existir funções escritas para ajudar a acompanhar as compras.

Consegues ajudar a Leslie a manter a lista de compras em ordem?

## 1. Criar uma nova lista

A primeira coisa de que a Leslie precisa é de criar uma lista vazia. Uma função chamada `new-list` seria perfeita para isso.

```lisp
(new-list) ; => ()
```

Oh, não... A Leslie já tem algumas coisas em mente, por isso precisa de uma função que receba três itens (felizmente, a Leslie só cria listas de três itens. Nem mais, nem menos!) e que crie uma nova lista de compras com essas coisas. Escreve uma função, `list-of-things`, que receba três itens e devolva uma lista com eles.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Acrescentar coisas à lista.

Antes de ir à loja, a Leslie espreita a despensa para ver o que precisa. Ajuda-a escrevendo a função `add-to-list`, que acrescenta um item ao início de uma lista.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. O que vem a seguir na lista?

Enquanto faz compras, a Leslie quer saber o que procurar a seguir. Também gosta de espreitar a lista para ver o segundo, o terceiro ou até o 23.º item (o seu número da sorte).

- `first-thing` dá como resultado a primeira coisa da lista
- `second-thing` dá como resultado a segunda coisa
- `third-thing` dá como resultado a terceira coisa
- `twenty-third-thing` dá como resultado a vigésima terceira coisa

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Remover uma coisa da lista

A Leslie quer encontrar o primeiro item da lista e removê-lo da prateleira.
Ajuda-a escrevendo uma função `remove-first-item`, que dá como resultado uma lista com tudo menos o primeiro item da lista recebida.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Listas maiores a partir de listas mais pequenas

A Leslie percebeu que fez duas listas de compras sem querer, em vez de uma! Escreve uma função, `list-append`, que devolve uma lista com os elementos da primeira lista seguidos dos da segunda.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. Quanto tempo falta?

A Leslie está a ficar preocupada por esta ida às compras demorar muito tempo. Afinal, quantas coisas há nesta lista? Escreve uma função `just-how-long` que lhe diga qual é o comprimento da lista.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
