# Introdução

Embora as expressões `if/else` possam ser usadas para executar lógica condicional, o Haskell também tem uma forma mais poderosa de o fazer: [correspondência de padrões][pattern-matching].
Com a correspondência de padrões, um valor pode ser testado em relação a um ou mais _padrões_.
Um exemplo desse tipo de padrão é o _padrão constante_, que faz corresponder um valor a uma constante (por exemplo, `1` ou `"hello"`).

Ao definir funções, podes definir corpos de função separados para padrões diferentes.
Isto dá origem a código limpo, simples e legível.
Podes usar correspondência de padrões com qualquer tipo de dados: números, carateres, listas, tuplas, etc.

Por exemplo, uma função trivial que recebe um número inteiro (`Int`) e o torna _1_ mais próximo de _0_ podia ser escrita assim:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

A correspondência de padrões começa a brilhar quando é usada em conjunto com outros padrões, por exemplo o _padrão variável_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

O exemplo acima trata todos os valores de entrada diferentes de _0_ da mesma forma e produziria resultados incorretos para números negativos.
Isto pode ser resolvido com padrões condicionais, conhecidos como _guardas_, que se expressam com o símbolo `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

Nos exemplos acima, nem todos os valores de entrada possíveis têm um padrão correspondente.
O compilador deteta isso e emite um aviso.
Isto é uma funcionalidade muito útil do Haskell, que ajuda a garantir que todos os caminhos possíveis estão cobertos, para evitar erros em tempo de execução.
É conhecida como _verificação exaustiva_.
Para resolver o aviso, tens de tratar todos os casos.
Dentro das _guardas_, podes usar a expressão `otherwise` como açúcar sintático para `True`, para capturar todos os padrões restantes.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

A correspondência de padrões testa um valor em relação a cada padrão, de cima para baixo, até encontrar um padrão correspondente e executar a lógica associada a esse padrão.
**A ordem dos padrões é importante!**
