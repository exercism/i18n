# Sobre

O C é uma linguagem de uso geral, utilizada numa vasta gama de aplicações, desde computadores embebidos a clusters de computação de alto desempenho.

O C aparece frequentemente em aplicações de baixo nível, por ser uma boa alternativa às linguagens assembly mais difíceis de ler. Pode ser compilado para assembly para manter o mesmo nível de desempenho, aumentando ao mesmo tempo a legibilidade e proporcionando um pequeno nível de segurança com tipos estáticos!

O C foi criado por Dennis Ritchie nos Bell Labs e utilizado para reimplementar o sistema operativo Unix. Atualmente, é uma das linguagens de programação mais utilizadas, com muitos compiladores que suportam a maioria do hardware e das plataformas disponíveis. Há imensos recursos e apoio disponíveis para te ajudar a começar!
