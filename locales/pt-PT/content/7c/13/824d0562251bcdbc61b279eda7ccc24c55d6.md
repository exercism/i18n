# Dicas

## Geral

- Há várias funções disponíveis na biblioteca padrão para expressões booleanas. Vê-as no espaço de nomes `Boolean` no [Unison share](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/Boolean).
- A ability Each permite-te operar sobre uma lista de elementos como se fosse um só elemento, aplicando a função pretendida a cada item. Também a podes usar para criar combinações de itens, chamando Each sobre duas listas diferentes.
- Vê a [função `guard` do `Each`](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/abilities/Each). Pode ser-te útil quando queres devolver algo condicionalmente a partir da ability `Each`.
- Dado o número de combinações únicas possíveis para este problema, podes deparar-te com problemas de complexidade espacial ou temporal. Há bastantes mecanismos para otimizar a pesquisa. Vê os algoritmos de [backtracking](https://www.geeksforgeeks.org/backtracking-algorithms/) ou de [branch and bound](https://www.geeksforgeeks.org/branch-and-bound-algorithm/?ref=lbp).
