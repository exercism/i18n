# Introdução

Podes tornar um parâmetro de um método opcional atribuindo-lhe um valor predefinido. Quando chamas um método com parâmetros opcionais, não precisas de passar um valor para eles. Se não passares nenhum valor para um parâmetro opcional, será usado o seu valor predefinido.

Os parâmetros opcionais têm de estar no fim da lista de parâmetros; não podem ser seguidos de parâmetros não opcionais.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

Podes definir o parâmetro opcional como `null` usando o operador `?` antes do nome da variável:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
