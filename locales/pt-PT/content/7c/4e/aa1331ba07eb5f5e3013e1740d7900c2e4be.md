# Sobre

C# é uma linguagem de tipagem estática, o que significa que tudo tem um tipo em tempo de compilação. Escolher um nome para uma [variável][variable] é o que se chama definir uma variável. Depois de uma variável estar definida, atribuir ou atualizar um valor chama-se atribuição de variável. Uma variável pode ser definida explicitando o seu tipo ou utilizando a [palavra-chave `var`][var] para que o compilador de C# infira o seu tipo com base no valor atribuído. A utilização de `var` é conhecida como _inferência de tipos_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

O valor de uma variável pode ser atribuído e atualizado utilizando o [operador `=`][assignment]. Depois de definida, o tipo de uma variável nunca pode mudar.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# é uma linguagem orientada a objetos e exige que todas as [funções][function] sejam definidas numa _classe_, que são definidas utilizando a [palavra-chave `class`][classes]. Os objetos (ou _instâncias_) são criados utilizando a palavra-chave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Uma função dentro de uma classe é designada por _método_. Cada [método][methods] pode ter zero ou mais parâmetros. Todos os parâmetros têm de ser explicitamente tipados, não há inferência de tipos para parâmetros. Da mesma forma, o tipo devolvido também tem de ser tornado explícito. Os valores são devolvidos pelos métodos utilizando a [palavra-chave `return`][return]. Para permitir que um método seja chamado por código noutros ficheiros, é necessário adicionar o modificador de acesso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Os métodos são invocados utilizando a sintaxe de ponto (`.`) numa instância, especificando o nome do método a chamar e passando argumentos para cada um dos parâmetros do método. Os argumentos podem especificar opcionalmente o nome do parâmetro correspondente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Se o método a chamar estiver definido na mesma classe que o método que o chama, o nome da classe pode ser omitido.

Se um método não utiliza qualquer _estado_ do objeto, o método pode ser tornado _estático_ utilizando o modificador `static`. Os métodos estáticos também são invocados utilizando a sintaxe de ponto (`.`), mas são invocados na própria classe em vez de numa instância da classe.

Se uma classe só tiver métodos estáticos, também pode ser tornada estática utilizando o modificador `static`. Isto expressa a intenção da classe.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

O âmbito em C# é definido entre os caracteres `{` e `}`.

C# suporta dois tipos de [comentários][comments]. Os comentários de uma linha são precedidos por `//` e os comentários multilinha são inseridos entre `/*` e `*/`.

Os valores inteiros são definidos como um ou mais algarismos (consecutivos) e suportam os [operadores matemáticos predefinidos][operators].

Um nome de variável [tem de seguir algumas regras][identifier-names] como começar por uma letra ou um underscore, e [deve seguir a convenção de nomenclatura de C#][naming-guidelines]. Se um nome de variável colidir com uma [palavra-chave reservada de C#][csharp-keywords], tem de ser escapado utilizando `@`. A utilização dessa notação não é recomendada, mas pode ser encontrada em casos excecionais, por exemplo: `var @this`, `var @class` ou `var @var`.

Há alguns conceitos que são tão fundamentais para uma linguagem da família C como C# que ocorrem naturalmente em quase qualquer pedaço de código não trivial. Estes são a [mutação][mutation] e o [âmbito][scope]. A mutação é a ideia de que uma variável pode ter o seu valor alterado ao longo do tempo de vida de um programa. O âmbito é a ideia de que o valor associado a um nome (de um elemento de programa) só é acessível dentro da "área" de código onde é definido. As principais áreas de código em C# são _classe/struct_ e _função_ (normalmente métodos), mas também podem incluir os corpos de ciclos e de outras construções.
