# Instruções

Neste exercício, vais escrever mais algum código relacionado com a preparação e a confeção da tua fantástica lasanha, retirada do teu livro de receitas preferido.

Tens cinco tarefas.
A primeira está relacionada com a própria confeção e as outras quatro são sobre a preparação perfeita.

## 1. Determina se a lasanha está pronta

Quando tens lasanha no forno, queres saber se já a podes tirar ou não.
Para garantir que a lasanha não queima no forno, costumas programar um temporizador.
Mas às vezes esqueces-te disso.

Escreve uma função `cookingStatus` que aceita o tempo restante do temporizador, em minutos, como parâmetro.
A função tem três resultados possíveis.

- Se o temporizador mostrar `0`, deve devolver `'Lasagna is done.'`.
- Se o temporizador mostrar qualquer outro número, o resultado deve ser `'Not done, please wait.'`.
- Se a função for chamada sem um valor para o temporizador, o resultado deve ser `'You forgot to set the timer.'`.

O temporizador nunca vai mostrar um valor abaixo de 0.

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. Estima o tempo de preparação

Para a próxima lasanha que vais preparar, queres garantir que reservas tempo suficiente para poderes desfrutar da confeção.
Já fizeste um plano com todas as camadas que a tua lasanha vai ter.
Agora queres estimar quanto tempo a preparação vai levar, com base nisso.

Implementa uma função `preparationTime` que aceita um array de camadas e o tempo médio de preparação por camada, em minutos.
A função deve devolver a estimativa do tempo total de preparação, com base no número de camadas.
Se a função for chamada sem indicar o tempo médio de preparação, deve assumir-se `2` minutos.

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. Calcula as quantidades necessárias de massa e molho

Além de reservares o tempo, também queres garantir que tens molho e massa suficientes para cozinhar a lasanha dos teus sonhos.
Por cada camada de massa na tua lasanha, vais precisar de 50 gramas de massa.
Por cada camada de molho na tua lasanha, vais precisar de 0,2 litros de molho.

Define a função `quantities`, que recebe um array de camadas como parâmetro.
A função vai então determinar a quantidade de massa e de molho necessária para fazer a tua refeição.
O resultado deve ser devolvido como um objeto com as chaves `noodles` e `sauce`.

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. Adiciona o ingrediente secreto

Há algum tempo, visitaste um amigo e comeste lasanha lá.
Estava incrível e tinha algo de especial.
O amigo enviou-te a lista de ingredientes e disse-te que o último item da lista é o "ingrediente secreto" que tornou a refeição tão especial.
Agora também queres adicionar esse ingrediente secreto à tua receita.

Escreve uma função `addSecretIngredient` que aceita dois arrays de ingredientes como parâmetros.
O primeiro parâmetro é a lista que o teu amigo te enviou e o segundo é a lista de ingredientes da tua própria receita.
A função deve adicionar o último item da lista do teu amigo ao fim da tua lista.
O array que representa a tua receita deve ser modificado diretamente e a função não deve devolver nada.
No entanto, o primeiro argumento não deve ser modificado.

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. Escala a receita

As quantidades indicadas no teu livro de receitas só dão para lasanha suficiente para duas porções.
Como queres cozinhar para mais pessoas da próxima vez, queres calcular as quantidades para diferentes números de porções.

Implementa uma função `scaleRecipe` que recebe dois parâmetros.

- Um objeto de receita que contém as quantidades necessárias para 2 porções.
  O formato do objeto pode ver-se no exemplo abaixo.
- O número de porções que queres cozinhar.

A função deve devolver um objeto de receita com as quantidades necessárias para o número desejado de porções.
No entanto, queres manter a receita original.
Isto significa que, nesta tarefa, o argumento da receita não deve ser modificado.

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
