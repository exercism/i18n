# Site de uma equipa de basquetebol

## História

Estás a trabalhar num site para uma equipa de basquetebol. O site mostra muitos dados, mas, infelizmente, o que é mostrado muda com frequência. Como os dados estão guardados num único objeto, não é difícil de fazer, mas dá muito trabalho e é aborrecido. Por isso, decidiste automatizar as coisas.

## Tarefas

Estes são exemplos de tarefas que se enquadram na história de automatizar o site:

- O teu objetivo é permitir que a equipa de conteúdos escolha, por si própria, que dados mostrar. Vão fazer isso indicando um caminho para os dados a mostrar no editor de conteúdos do site. A tua tarefa é criar uma função extract que recebe um objeto e um caminho, separados por um ponto. Devolve o valor nesse caminho, ou um valor predefinido.

## Tarefas adicionais

A história pode continuar, por exemplo:

- A equipa de conteúdos está muito entusiasmada com esta nova funcionalidade e já pediu que se acrescentasse outra. Gostariam de poder mostrar dados de elementos específicos de um array.
