# Sobre

Uma extensão estática permite pseudoestender tipos existentes sem modificar o seu código-fonte. Isto consegue-se com a instrução `using`. As extensões estáticas podem ser uma ferramenta poderosa que permite acrescentar funcionalidades aos tipos sem os alterar realmente.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
