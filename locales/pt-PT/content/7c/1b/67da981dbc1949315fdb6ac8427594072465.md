# Dicas

Todas estas tarefas exigem que a linha de registo seja dividida em partes separadas.

- Consulta a função [`split()`][split] para conheceres as opções.

## 1. Obter a mensagem de uma linha de registo

- A função `split()` devolve um vetor de strings.
- Precisas de obter o elemento adequado desse vetor.
- Os espaços em branco no início e no fim podem ser removidos com [`strip()`][strip].

## 2. Obter o nível de registo a partir de uma linha de registo

- A função [`lowercase()`][lowercase] é útil aqui.
- Uma string ASCII pode ser indexada com um intervalo.
- O índice `end` refere-se ao último elemento de um vetor.
- Em alternativa, a tarefa pode ser resolvida com [`replace()`][replace] para remover os carateres indesejados.

## 3. Reformatar uma linha de registo

- A [interpolação][interpolation] de strings é talvez a abordagem mais simples aqui.
- Em alternativa, algumas pessoas (com experiência noutras linguagens) podem preferir [`@sprintf()`][sprintf].
