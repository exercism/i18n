## Instalar o Z3

### Descarregar o Python (caso ainda não esteja instalado)

Podes descarregar a versão mais recente do Python [aqui.](https://python.org)

* Ao instalar, certifica-te de que marcas a caixa que adiciona o Python ao PATH

### Descarregar o Visual Studio (caso ainda não esteja instalado)

Podes descarregar a versão mais recente do Visual Studio [aqui.](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)

* Ao instalar, seleciona a carga de trabalho **Python Development**
* Seleciona todas as caixas de verificação dos pacotes opcionais de desenvolvimento Python do lado direito

Depois de instalares, abre o Visual Studio e configura as tuas preferências iniciais.

### Instalar os comandos do Git

Encontras as instruções de instalação do Git [aqui.](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)

* Vais precisar de [adicionar o Git às tuas variáveis de sistema](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### Clonar o Z3

Vai ao [repositório do Z3 no GitHub](https://github.com/Z3Prover/z3) para ver o projeto.

Abre um terminal no teu computador e vai até à pasta onde queres clonar o repositório do Z3 (por exemplo: C:\Z3).

A partir dessa localização, executa:

```bash
git clone https://github.com/z3Prover/z3.git
```

### Compilar o Z3 no Windows com o Visual Studio Command Prompt

Abre o **Developer Command Prompt for VS 2019** através do menu Iniciar.

Vai até à pasta onde clonaste o repositório do Z3 (por exemplo: C:\Z3).

Para compilações de 32 bits, executa:

```bash
python scripts/mk_make.py
```

Para uma compilação de 64 bits, executa:

```bash
python scripts/mk_make.py -x
```

e depois executa:

```bash
cd build
pip install z3-solver
```



Agora já deves conseguir abrir o Visual Studio e executar o Z3 com o respetivo binding de Python.


Para testar, podes executar:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

As duas últimas linhas devem produzir `sat` e `[y = 4, x = 2]`.
