# Instalação

Precisas do Node Package Manager (npm) para instalar o Reason. Segue as instruções [aqui](https://www.npmjs.com/get-npm)

Depois de teres o npm, instala o Reason com:
```
npm install -g bs-platform
```

O Reason tem integração com vários editores, vê [aqui](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)

Podes encontrar algumas ferramentas de linha de comandos (incluindo um REPL que te permite avaliar expressões Reason numa shell) [aqui](https://github.com/reasonml/reason-cli)
