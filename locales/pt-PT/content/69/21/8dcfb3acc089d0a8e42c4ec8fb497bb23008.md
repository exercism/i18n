# Introdução

## Espaços de nomes

Um método importante para organizar o código é a utilização de espaços de nomes.
Duas funções podem ter uma colisão de nomes, que se pode resolver se as colocarmos em espaços de nomes diferentes.
Os espaços de nomes podem ser aninhados, o que pode ajudar a estruturar grandes bases de código.
O acesso aos espaços de nomes faz-se através do operador de resolução de âmbito `::`.

O exemplo abaixo mostra a utilização de duas funções `foo` diferentes.
São usadas em conjunto ao prefixar os respetivos espaços de nomes.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
