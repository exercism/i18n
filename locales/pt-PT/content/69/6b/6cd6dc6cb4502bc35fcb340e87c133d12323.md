# Instruções

Neste exercício vamos simular o primeiro turno de um jogo de [Blackjack](https://en.wikipedia.org/wiki/Blackjack).

Vais receber duas cartas e vais poder ver a carta do crupiê que está virada para cima.
Todas as cartas são representadas por uma string, como "ace", "king", "three", "two", etc.
Os valores de cada carta são:

| carta | valor |  carta  | valor |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | *other* |   0   |

**Nota**: Habitualmente, os aces podem valer 1 ou 11, mas, para simplificar, vamos assumir que só podem valer 11.

Consoante as tuas duas cartas e a carta do crupiê, há uma estratégia para o primeiro turno do jogo, na qual tens as seguintes opções:

- Ficar (S)
- Pedir (H)
- Dividir (P)
- Ganhar automaticamente (W)

Apesar de ainda não ser a ideal, vais seguir a estratégia que o teu amigo Alex tem vindo a desenvolver, que é a seguinte:

- Se tiveres um par de aces, tens sempre de os dividir.
- Se tiveres um Blackjack (duas cartas que somam 21) e o crupiê não tiver um ace, uma figura (Jack/Queen/King) ou um ten, ganhas automaticamente.
  Se o crupiê tiver alguma dessas cartas, tens de ficar e esperar que a outra carta seja revelada.
- Se as tuas cartas somarem um valor dentro do intervalo [17, 20], tens sempre de ficar.
- Se as tuas cartas somarem um valor dentro do intervalo [12, 16], tens sempre de ficar, a não ser que o crupiê tenha um 7 ou mais, caso em que tens sempre de pedir.
- Se as tuas cartas somarem 11 ou menos, tens sempre de pedir.

value := ParseCard("ace")

## 2. Implementa a lógica de decisão para o primeiro turno

Escreve uma função que implemente a lógica de decisão descrita acima:

```go
func FirstTurn(card1, card2, dealerCard string) string
```

Aqui ficam alguns exemplos dos resultados esperados:

```go
FirstTurn("ace", "ace", "jack") == "P"
FirstTurn("ace", "king", "ace") == "S"
FirstTurn("five", "queen", "ace") == "H"
```
