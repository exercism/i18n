# Anexo às instruções

## Implementação

Além da função _numbers_, que limpa números de telefone, tens de escrever mais duas funções, _area-code_ e _pprint_, no percurso de Emacs Lisp.

Cada uma das funções adicionais recebe o número de telefone como único parâmetro.

A primeira função _area-code_ extrai o indicativo regional do parâmetro de entrada, enquanto a segunda função _pprint_ transforma o parâmetro de entrada numa string no formato de
```
(NXX) NXX-XXXX
```
em que `N` e `X` são como descrito acima.
