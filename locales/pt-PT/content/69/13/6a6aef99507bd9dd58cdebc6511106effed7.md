# Instruções

Neste exercício vais escrever algum código para ajudar o Larry, o extraterrestre do Lisp, a analisar e a formatar strings de log. Estas strings de log chegam de vários sistemas e têm de ser processadas para que as suas mensagens possam ser apresentadas num painel de monitorização informativo.

As strings de log têm o formato `"[<level>]: <message>"`. O nível é um dos seguintes valores: `info`, `warn` ou `ohno`.

## 1. Extrai a mensagem

Define uma função `log-message` que recebe uma string de log e devolve a mensagem que contém.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. Determina a gravidade

O nível da string de log determina a sua gravidade.

- um nível `info` significa uma gravidade `:everything-ok`
- um nível `warn` significa uma gravidade `:getting-worried`
- um nível `ohno` significa uma gravidade `:run-for-cover`

Define uma função `log-severity` que recebe uma string de log e devolve a gravidade correta.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. Lidar com os caprichos da realidade

Infelizmente, às vezes as strings de log não estão formatadas corretamente. Mais concretamente, o nível de log pode não estar todo em minúsculas como indicado acima. Modifica a função `log-severity` para lidar com isto.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. Reformatar a mensagem de log de acordo com a gravidade

Consoante a gravidade, a mensagem deve ser modificada de formas diferentes:

- uma gravidade `:everything-ok` deve ter a sua mensagem alterada para tudo em minúsculas.
- uma gravidade `:getting-worried` deve ter a sua mensagem alterada para que cada palavra fique com inicial maiúscula.
- uma gravidade `:run-for-cover` deve ter a sua mensagem alterada para tudo em maiúsculas.

Define uma função `log-format` que recebe uma mensagem de log e devolve uma mensagem devidamente formatada.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
