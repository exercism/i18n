# Escrever o código

Escreve o teu código em `src/lib.rs`.
Os exercícios incluem um ficheiro esqueleto em `src/lib.rs` que te mostra as assinaturas do código que vais precisar de escrever.

Na maioria dos exercícios, o melhor é escreveres todo o teu código no ficheiro `src/lib.rs`.
Se quiseres dividir a tua solução por vários ficheiros, consulta o [capítulo sobre módulos][chapter-modules] do livro do Rust.

[chapter-modules]: https://doc.rust-lang.org/book/ch07-02-defining-modules-to-control-scope-and-privacy.html

## Correr os testes

Para correr os testes, basta executares o seguinte comando:

```bash
$ cargo test
```

Por predefinição, só o primeiro teste está ativo.
Quando estiveres pronto para passar o teste seguinte, remove a marca `ignore` desse teste (`#[ignore]`).
Se preferires, também podes remover a marca de todos os testes de uma vez.

Sente-te à vontade para escrever o mínimo de código possível para fazer os testes passar.
As falhas dos testes vão orientar-te sobre o que deves escrever a seguir.

Como o Rust verifica todo o código no tempo de compilação, pode acontecer que os teus testes não compilem enquanto não escreveres o código necessário.
Mesmo os testes com `ignore` são verificados no tempo de compilação.
Podes [comentar][comments] os testes que não compilam, começando cada linha por `//`.
Depois, quando estiveres pronto para trabalhar nesse teste, podes descomentá-lo.
O Rust tem também uma macro especial chamada `todo!()`, que podes usar em partes do código ainda por terminar para que o teu programa compile.

[comments]: https://doc.rust-lang.org/book/ch03-04-comments.html

## Usar bibliotecas

Deves conseguir resolver a maioria dos exercícios sem usar bibliotecas externas.
No entanto, podes adicionar bibliotecas (a comunidade Rust chama-lhes **crates**) correndo `cargo add crate-name` no diretório de um exercício.

Os testes automáticos do site só suportam um conjunto predefinido de crates, que podes encontrar [aqui][local-registry] na secção `[dependencies]`.
Se quiseres que seja adicionado suporte para uma crate específica, podes abrir um issue ou um pull request.

[local-registry]: https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml
