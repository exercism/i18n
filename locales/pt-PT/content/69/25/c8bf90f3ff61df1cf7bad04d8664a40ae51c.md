# Sobre

O conceito [Pares e Dicionários][pairs-dicts] abordou as bases do tipo dicionário de Julia.

Como os [`Dict`s][dict] são um tipo de coleção importante e muito utilizado, também existem muitas funções para os manipular.

## Obter entradas

A forma mais simples de obter uma entrada é pela chave (como em muitas linguagens).
No entanto, pedir uma chave inexistente provoca um `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

Podíamos testar a chave antes de tentar obtê-la (com algo como `haskey(d, 4)` ou `4 ∈ keys(d)`), mas pode ser útil obter apenas um valor predefinido para chaves em falta.

Para isso, temos a função [`get()`][get] e a sua variante mutável [`get!()`][get-bang].
A diferença está em saber se a chave "em falta" é adicionada ao `Dict`.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

Vimos no conceito anterior que `delete!()` remove uma entrada pela chave.
Isto pode ser combinado com a obtenção do valor, usando a função `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Iteração

Iterar sobre um `Dict` produz, por defeito, pares `key => value`.
Os componentes estão acessíveis com a nomenclatura habitual `.first` e `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Muitas vezes, queremos usar apenas as chaves ou apenas os valores, o que é fácil.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Combinar

Combinar dois `Dict`s pode ser útil, mas temos de ser claros quanto ao que pretendemos fazer com chaves que estão presentes em mais do que um dos dicionários fornecidos.

As funções [`merge()`][merge] e [`merge!()`][merge-bang] combinam um número arbitrário de `Dict`s fornecidos, da esquerda para a direita.

Os valores das chaves já existentes são simplesmente substituídos, pelo que o `Dict` mais à direita "ganha".

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

As funções [`mergewith()`][mergewith] e [`mergewith!()`][mergewith-bang] permitem-nos fornecer uma função como primeiro argumento, para definir como as chaves repetidas devem ser combinadas.
A adição é um exemplo simples.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Concatenar dois vetores é outra operação comum ao combinar.
Para isso, Julia usa a função [`vcat()`][vcat], por razões explicadas no conceito [`Multi Dimensional Arrays`][multidim].

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

Para vários [`Set`s][sets], a função de combinação correspondente é [`union`][union].

Repara que as funções `mergewith` são um bom exemplo de [Funções de Ordem Superior][hof] em ação.
