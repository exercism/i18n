# Fluxo de controlo

As expressões `if` e os ciclos controlam o fluxo de execução em Cairo através de:
`

- **Expressões `if`** executam código condicionalmente, consoante uma condição seja avaliada como `true`.
- **Ciclos** (como `loop`, `while` e `for`) executam código repetidamente enquanto uma condição especificada se mantiver verdadeira ou até se verificar uma condição de interrupção.

Estas construções são fundamentais para implementar lógica e iteração em Cairo.

## Expressões `if`

As expressões `if` em Cairo permitem-te controlar o fluxo de execução com base em lógica condicional.
Seguem uma estrutura em que o código é executado consoante uma condição booleana seja avaliada como `true` ou `false`.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

Este exemplo demonstra um bloco `if` simples em Cairo.
A mensagem `"It's hot outside!"` só é impressa se a condição `temperature > 25` for avaliada como `true`.
Se a condição for `false`, não é executado nenhum código e o programa continua.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

Ao executar este código, é impresso `"The number is less than 10."` na consola.

### Lidar com várias condições com `else if`

Podes usar várias condições combinando `if` e `else` numa expressão `else if`.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

Ao executar este código, é impresso `"Grade: B"` na consola.

### Usar `if` numa instrução `let`

A expressão `if` em Cairo pode ser usada no lado direito de uma instrução `let` para atribuir o resultado a uma variável.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## Ciclos

Os ciclos são uma construção fundamental que permite repetir blocos de código, possibilitando uma execução eficiente e controlada de tarefas.
Os ciclos podem iterar sobre uma sequência ou executar código repetidamente com base numa condição.
Cairo oferece três tipos principais de ciclos:

- **loop**: um ciclo básico que corre indefinidamente, a não ser que seja interrompido explicitamente com uma instrução `break`.
- **while**: continua a executar enquanto uma condição especificada se mantiver `true`.
  Termina quando a condição passa a `false`.
- **for**: itera sobre os elementos de uma coleção, como arrays, executando código para cada elemento.

### Repetir código com `loop`

A palavra-chave `loop` diz ao Cairo para executar um bloco de código vezes sem conta, para sempre, ou até lhe dizeres explicitamente para parar.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Ao executar este código, é impresso `"again!"` indefinidamente na consola, até o programa ficar sem gas ou até o pararmos manualmente.

> Nota: o Cairo impede-nos de executar um programa com ciclos infinitos através de um medidor de gas.
> O medidor de gas é um mecanismo que limita a quantidade de computação que pode ser feita num programa.
> O gas é uma unidade de medida que exprime o custo de computação de uma instrução.
> Quando o medidor de gas se esgota, o programa termina.

Para sair de um ciclo, coloca a palavra-chave `break` dentro do ciclo para indicar ao programa quando deve parar de o executar.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

A palavra-chave `continue` diz ao programa para passar à iteração seguinte do ciclo e ignorar o resto do código desta iteração.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Ao executar este programa, o valor de `i` não é impresso quando é igual a `5`.

#### Devolver valores de `loop`

Podes devolver um valor de um `loop` usando a palavra-chave `break` seguida do valor que queres devolver.
Isto permite-te sair do `loop` e passar um resultado ao resto do teu código.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### Ciclos condicionais com `while`

O `while` executa código enquanto uma condição é `true` e termina quando a condição passa a `false`.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### Percorrer uma coleção com `for`

O `for` itera sobre cada item de uma coleção, executando código para cada item.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
