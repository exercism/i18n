# Introdução

Tal como as propriedades, que guardam dados nas tuas structs e classes, também podes definir _métodos_, que guardam funções na tua struct ou classe.

Os métodos definem-se da mesma forma que uma função normal, só que dentro do corpo da struct ou da classe. Repara que, se uma função altera o valor de uma propriedade numa struct, tem de ser precedida da palavra-chave `mutating`. Além disso, se uma propriedade pode ser alterada por um método, essa propriedade tem de ser definida com `var` e não com `let`, tal como acontece com as variáveis normais.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

Estes métodos podem ser chamados com notação de ponto, tal como as propriedades.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
