# Sobre os ciclos for

O [ciclo for](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) fornece um mecanismo para executar um grupo de instruções repetidamente até que uma condição seja satisfeita.
O ciclo é composto por quatro partes:

```java
for (initialization; test; update) {
    body;
}
```

A `initialization` define um estado inicial para o ciclo e é executada exatamente uma vez, no início do ciclo.
Normalmente, declara e atribui uma variável usada na expressão de teste e na instrução de atualização.
Por exemplo:

```java
int i = 1
```

A expressão `test` verifica se o ciclo deve terminar.
Se o resultado da avaliação for true, o corpo é executado e, em seguida, a expressão de atualização.
Se o resultado for false, nem o corpo nem a instrução de atualização são executados, e a execução prossegue após o parêntese de fecho do ciclo.
Normalmente, verifica a variável atribuída no bloco de inicialização.
Por exemplo:

```java
i <= 10
```

Depois de executar o corpo do ciclo, é executada a expressão `update`.
Normalmente, incrementa ou decrementa a variável do ciclo num determinado valor.
Por exemplo:

```java
i++
```

Um ciclo for que imprime os primeiros quatro quadrados seria assim:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

Se percorreres todos os elementos de uma coleção, é preferível usar um ciclo `for-each`, mas também o podes fazer com um ciclo `for`, assim:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Um ciclo `for` tem algumas vantagens em relação a um ciclo `for-each`:

- Podes começar ou parar no índice que quiseres.
- Podes usar qualquer condição de terminação (boolean) que queiras.
- Podes saltar elementos personalizando o incremento da variável do ciclo.
- Podes processar coleções de trás para a frente, contando de forma decrescente.
- Podes usar ciclos `for` em cenários que não envolvem coleções.
