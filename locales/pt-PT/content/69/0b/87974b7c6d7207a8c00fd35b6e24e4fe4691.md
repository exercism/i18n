# Anexo às instruções

## Palavras

- `<bst> ( data-seq -- tree )`: constrói uma árvore inserindo cada
  elemento de `data-seq` pela ordem.
- `sorted-data ( tree -- seq )`: devolve os elementos da árvore por
  ordem crescente (percurso em ordem).

## Hierarquia de tuplas

Um nó de uma árvore binária de pesquisa ou está *vazio* ou *tem dados
e duas subárvores*. Modela isso como uma pequena hierarquia de
herança:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` é a classe-mãe abstrata; `leaf` é o caso da árvore vazia;
`branch` transporta um valor e dois filhos `bst` (cada um deles, por
sua vez, ou um `leaf` ou um `branch`).

## Ordenação

Compara os dados com `before=?` (de `math.order`), que funciona tanto
com strings como com números; os testes usam dados de tipo string como
`"1"`, `"2"`, `"3"`.
