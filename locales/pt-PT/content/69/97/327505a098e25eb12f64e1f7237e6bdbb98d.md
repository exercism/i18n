# Instruções

Neste exercício, vais processar linhas de um relatório de log.
Cada linha de log é uma string com o seguinte formato: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tens três tarefas e cada uma recebe uma linha de log e pede-te que faças algo com ela.

## 1. Obtém a mensagem de uma linha de log

Implementa o método `log_line::message` para devolver a mensagem de uma linha de log:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. Obtém o nível de log de uma linha de log

Implementa o método `log_line::log_level` para devolver o nível de log de uma linha de log, que deve ser devolvido em maiúsculas:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. Reformata uma linha de log

Implementa o método `log_line::reformat`, que reformata a linha de log, colocando a mensagem primeiro e o nível de log depois, entre parênteses:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
