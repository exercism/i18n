# Anexo às instruções

## Funções e testes

O código inicial que te é fornecido,
```scheme
(provide hello)

(define (hello)
  "Goodbye, Mars!")
```
define uma função chamada `hello` e torna-a disponível para executar.
O test runner recebe esta função e executa-a, comparando o valor que devolve com o valor que espera.
Usa esta definição de função inicial como base para a tua solução.
