# Testes

Para correres os testes, executa o seguinte comando:

```bash
make
```

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem.
Por predefinição, só um teste (o primeiro) é executado quando corres os testes.
Isto é intencional, pois permite que te concentres apenas em fazer esse teste passar.
Assim que passar, podes ativar o teste seguinte removendo a linha `TEST_IGNORE()`.
Quando todos os testes estiverem ativados e a tua implementação fizer com que todos passem, terás resolvido o exercício!

## Depuração

Para ajudar na depuração, há várias macros definidas num ficheiro `debug.mac`.
Podem ser chamadas com um ou mais argumentos do tamanho adequado.
Por exemplo:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

Para usares qualquer uma dessas macros, o `debug.mac` tem de ser incluído no topo do ficheiro de solução:

```x86asm
%include "debug.mac"
```
