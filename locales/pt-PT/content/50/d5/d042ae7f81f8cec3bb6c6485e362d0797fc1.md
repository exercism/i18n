# Testes

Basta escrever `make chez` se estiveres a usar ChezScheme ou `make guile` se estiveres a usar GNU Guile.

## Usar o REPL

- Introduz `test.scm` na linha de comandos do REPL.
- Desenvolve a tua solução no ficheiro `problem.scm`, recarregando à medida que avanças.
- Corre `(test)` para verificar a tua solução.
