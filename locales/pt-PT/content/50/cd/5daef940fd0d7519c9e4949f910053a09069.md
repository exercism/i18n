# Ligações internas

As ligações geradas pelo analisador de Markdown do Exercism são verificadas para ver se são internas e, caso sejam, podem ser decoradas com tooltips.

Um tooltip para um conceito pode ter este aspeto:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## Utilização

Não existe nenhuma sintaxe especial para que as ligações sejam decoradas desta forma.
Em vez disso, verificamos se o href da ligação segue uma de duas formas:

- Um URL. Por exemplo: https://exercism.org/tracks/ruby/concepts/basics
- Um caminho absoluto. Por exemplo: /tracks/ruby/concepts/basics

De momento, não suportamos URLs relativos (por exemplo, os que começam por `./` ou `../`), porque o analisador de Markdown não conhece o contexto do documento que gera, o contexto em que está a gerar, nem a estrutura de um repositório git.

## Alternativas

Em vez de usares ligações normais, podes optar por apresentar Widgets.
Normalmente, usam-se no fim de um documento para sugerir leituras adicionais ou bons exercícios para aprender algo.

Consulta [a documentação dos Widgets](/docs/building/markdown/widgets) para mais detalhes.
