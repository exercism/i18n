# Percorrer um dicionário

Usar um dicionário é uma ideia perfeitamente natural neste tipo de situação. No entanto, tem cuidado: como os dicionários são implementados como tabelas de hash, a ordem das suas chaves não é garantida. De facto, ao iterar sobre as chaves de um dicionário, estas vão aparecer numa ordem diferente e aleatória de cada vez. Vê a secção `Iteration order` do artigo [Go maps in action](https://blog.golang.org/go-maps-in-action). Se a ordem da iteração for importante, um slice é uma escolha melhor.
