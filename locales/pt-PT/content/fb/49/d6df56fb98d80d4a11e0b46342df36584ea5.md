# Sobre

A instrução `guard` em Swift é usada para retornos antecipados de funções Swift quando uma condição necessária que tem de ser satisfeita para que o processamento continue não é cumprida, por exemplo:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

Aqui, o `guard` verifica se a expressão Boolean que se segue à palavra-chave `guard` é avaliada como verdadeira. Se for, o processamento continua com o código que se segue à instrução `guard` (aqui `let root = myValue.squareRoot()`. Caso contrário, executa o código na cláusula else. Ao contrário de uma instrução `if`, uma instrução `guard` _tem_ de ter uma cláusula else e, ao contrário da cláusula else de um if-else, a cláusula else de um `guard` _tem_ de sair do âmbito da instrução `guard`. Ou seja, tem de usar uma instrução de transferência de controlo, como `return`, `continue` ou `break`, ou tem de lançar um erro ou terminar o programa.

Um exemplo da sua utilização é a função sinc, que é igual a sin(x)/x com sinc(0) definido como 1, evitando problemas com a divisão por 0. Esta função pode ser escrita em Swift, usando um `guard` da seguinte forma:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
