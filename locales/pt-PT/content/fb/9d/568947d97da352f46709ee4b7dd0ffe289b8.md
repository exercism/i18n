# Sobre

O Kotlin foi concebido e desenvolvido pela JetBrains, a empresa por trás do IntelliJ.
É uma linguagem que corre na JVM e que pode ter como alvo a versão 6 ou superior (incluindo a [plataforma Android](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/)).
A JetBrains queria usar uma linguagem com tipagem estática que eliminasse o código repetitivo do Java, oferecesse paradigmas funcionais modernos e tivesse uma interoperabilidade bidirecional perfeita com o Java no código que já tinham.
A JVM já tinha linguagens alternativas, como o Groovy e o Scala, mas nenhuma delas correspondia aos critérios que pretendiam, por isso criaram o Kotlin.

A sintaxe do Kotlin é semelhante à do Scala e à do Swift, mas vai buscar as melhores funcionalidades de outras linguagens, como o C# e o Groovy.
O Kotlin adotou uma abordagem pragmática em relação às funcionalidades incluídas na linguagem, fornecendo apenas aquilo que já tinha provado ser útil para os programadores.
Com esta decisão, implementaram um subconjunto das funcionalidades do Scala, com a intenção de proporcionar código mais fácil de manter e uma curva de aprendizagem mais suave para os programadores que procuram um «melhor Java».

A JetBrains tem uma equipa dedicada de programadores a trabalhar no Kotlin, com o código disponível no [Github](https://github.com/JetBrains/kotlin).
