# Acerca

A filtragem é o processo de criar uma sequência a partir de outra sequência, copiando todos os elementos da sequência original exceto alguns.
A escolha dos elementos a incluir na nova sequência pode ser feita através de uma função de predicado (uma função que devolve um valor Boolean) ou por igualdade com um objeto específico.

## Remover através de um predicado

`remove-if` é uma função que recebe uma função de predicado e uma sequência como argumentos e devolve uma sequência apenas com os elementos para os quais o predicado devolveu um valor falso.
Por outras palavras, "remove" todos os elementos da sequência para os quais o predicado devolve verdadeiro. No entanto, repara que esta função não modifica a sequência original! 
Em vez disso, devolve uma nova sequência sem esses elementos. Se o predicado for verdadeiro para todos os valores, é devolvida uma sequência vazia.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Manter elementos com um predicado

Existe uma função `remove-if-not` que é exatamente igual a `remove-if`, com a diferença de que *mantém* os elementos para os quais o predicado devolve verdadeiro.

Em alternativa, podes usar `complement` para transformar um predicado no seu "oposto".

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## Remover um elemento específico

Se quiseres remover um elemento específico de uma sequência, podes usar `remove`, que recebe o elemento a remover e uma sequência.
São devolvidos todos os valores da sequência que não são iguais ao elemento a remover.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

A função a usar para a igualdade pode ser especificada com o [parâmetro de palavra-chave][concept-keyword-parameters] `:test`.

Repara que `remove` poderia ser implementado com `remove-if`, escrevendo um predicado que testa a igualdade de um objeto com um elemento específico.

## Muitas opções

Cada uma destas funções também aceita muitos outros [parâmetros de palavra-chave][concept-keyword-parameters], que lhe permitem trabalhar apenas sobre subsequências, aplicar-se apenas um determinado número de vezes, entre outras coisas. Consulta a [documentação da Hyperspec][hyperspec-remove] para todos os detalhes.


## Opções destrutivas

Além de `remove`, `remove-if` e `remove-if-not`, existem `delete`, `delete-if` e `delete-if-not`, que têm o mesmo efeito, exceto que podem modificar a sequência que lhes é passada.
