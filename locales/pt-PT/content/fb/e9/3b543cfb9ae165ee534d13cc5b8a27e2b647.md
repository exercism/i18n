# Instruções

Ficaste de repente com uma vontade enorme de comer panquecas.
Como pessoa moderna com inclinação para a técnica, escreves uma lista de compras dos ingredientes das panquecas em formato JSON.
A estrutura da lista é a seguinte:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Um ingrediente é representado como um objeto JSON, assim:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Um ingrediente tem uma propriedade opcional chamada `"substitute"` que contém uma string com outro item que pode ser usado em alternativa.

Vamos ver como podemos examinar a lista de compras com `jq`

## 1. Extrair o nome da lista de compras

Escreve uma expressão que devolva o elemento "name" da lista de compras.

## 2. Contar quantos ingredientes são necessários

Conta apenas os ingredientes "required". Não incluas os ingredientes opcionais.

## 3. Quanto açúcar?

Escreve uma expressão que devolva a quantidade de açúcar.
Só é pedida a parte numérica.

## 4. Mapear os ingredientes que podem ser substituídos

Alguns dos ingredientes podem ser substituídos (se não tiveres o ingrediente X, podes usar o Y).
Devolve um objeto JSON que mapeie o ingrediente recomendado para o seu substituto.
Inclui os ingredientes opcionais no mapeamento.
