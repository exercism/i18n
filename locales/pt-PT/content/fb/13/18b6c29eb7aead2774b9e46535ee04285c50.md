# Instruções

Neste exercício vais processar linhas de log.

Cada linha de log é uma string com o seguinte formato: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tens várias tarefas, cada uma das quais recebe uma linha de log e pede-te que faças algo com ela.

## 1. Permitir obter a string a seguir a um substring específico

Ao olhares para os logs do último mês, vês que a mensagem de teste está sempre localizada a seguir a um substring específico. Como prevês ter de extrair a mensagem de teste num futuro próximo, decides criar um método auxiliar para te ajudar nisso.

Implementa o método de extensão (_static_) `LogAnalysis.SubstringAfter()`, que recebe um delimitador do tipo string e devolve o substring a seguir ao delimitador.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. Permitir obter a string entre dois substrings

Numa inspeção mais atenta, vês que o nível de log está sempre entre parênteses retos (`[` e `]`). Como também prevês ter de extrair o nível de log num futuro próximo, decides criar outro método auxiliar para te ajudar nisso.

Implementa o método de extensão (_static_) `LogAnalysis.SubstringBetween()`, que recebe dois delimitadores do tipo string e devolve o substring que está entre os dois delimitadores.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. Extrair a mensagem de um log

Implementa o método de extensão (_static_) `LogAnalysis.Message()` para devolver a mensagem contida num log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. Extrair o nível de log de um log

Implementa o método de extensão (_static_) `LogAnalysis.LogLevel()` para devolver o nível de log de um log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
