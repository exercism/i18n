# Instruções

Como entusiasta de xadrez, gostarias de escrever a tua própria versão do jogo. Sim, já deve haver por aí muitas implementações de xadrez disponíveis online, mas a tua vai ser única!

Mas antes de dares asas à imaginação, tens de tratar do básico. Vamos começar por gerar o tabuleiro.

Cada casa do tabuleiro de xadrez é identificada por um par letra-número. As colunas verticais de casas, chamadas colunas, são etiquetadas de A a H. As linhas horizontais de casas, chamadas filas, são numeradas de 1 a 8.

## 1. Define o intervalo de filas

Implementa a função `rank_range()`. Deve devolver um intervalo de inteiros, de 1 a 8.

```julia-repl
julia> rank_range()
# output omitted
```

## 2. Define o intervalo de colunas

Implementa a função `file_range()`. 
Deve devolver um intervalo de carateres, da letra A maiúscula à letra H maiúscula.

```julia-repl
julia> file_range()
# output omitted
```

## 3. Transforma o intervalo de filas num vetor de filas

Implementa a função `ranks()`. Deve devolver um vetor de inteiros, de 1 a 8. 
Não escrevas o vetor à mão, gera-o a partir do intervalo devolvido pela função `rank_range()`.

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. Transforma o intervalo de colunas num vetor de colunas

Implementa a função `files`. Deve devolver um vetor de carateres, de 'A' a 'H'. 
Não escrevas o vetor à mão, gera-o a partir do intervalo devolvido pela função `file_range()`.

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
