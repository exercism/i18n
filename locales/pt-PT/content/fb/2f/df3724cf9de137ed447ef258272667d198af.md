A interface pública de uma base de código deve ser cuidadosamente pensada, pois cada função pública aumenta os custos de manutenção a longo prazo e torna a refatoração mais difícil.

Em todos os exercícios do Exercism, a interface pública é definida pelo conjunto de testes.
Se uma função está a ser testada, tem de ser pública.
Todas as outras funções devem ser privadas, incluindo funções com o mesmo nome mas com aridades diferentes.

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
Repara que os argumentos predefinidos modificam a aridade de uma função.

Quando escreves uma biblioteca, é frequentemente necessário tornar as funções públicas para serem usadas entre módulos.
Para ocultar essas funções da documentação, os autores de bibliotecas adicionam `@doc false` antes das definições das funções ou `@moduledoc false` para ocultar o módulo inteiro.
