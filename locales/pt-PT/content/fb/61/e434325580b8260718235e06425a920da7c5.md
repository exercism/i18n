# condicionais desnecessárias

As [condicionais][conditionals] são usadas desnecessariamente nesta solução.
Usar um [argumento predefinido][default argument] em conjunto com [str.format][str.format] ou [f-strings][f-strings] (_também conhecidas como "literais de string formatados" ou "strings interpoladas"_) pode tornar o código mais claro e menos verboso.

Vê este artigo sobre [argumentos predefinidos em Python][python default arguments] para mais detalhes.
O artigo do blogue [formatação de strings em Python][string formatting in python] também pode ser um bom ponto de partida para conheceres as opções de formatação de strings do Python.
