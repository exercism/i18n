# Noções básicas de sintaxe de Elm 1

## Constantes e funções

Os programas em Elm são compostos por definições e expressões.
Em Elm, tudo é uma definição ou uma expressão.

Um valor constante define-se com `name = expression`.

```elm
five = 5

six = 3 + 3
```

As funções definem-se com `name parameters... = expression`,
ficando os parâmetros separados apenas por espaços.

```elm
add number1 number2 = number1 + number2
```

Invocar uma função também é uma expressão e faz-se
indicando o nome da função e passando argumentos para cada um dos seus parâmetros,
separados por espaços, tal como na definição de funções.

```elm
five = add 2 3
```

Podes usar parênteses para especificar a ordem de avaliação de uma expressão.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentação / espaços significativos

Elm não usa marcadores sintáticos como chavetas, parênteses ou pontos e vírgulas para delimitar o código. Usa antes espaços e indentação.

- As definições de módulo, de import e de funções de nível superior têm de começar na coluna mais à esquerda.
- Se uma expressão for dividida por várias linhas, o código que faz parte dessa expressão tem de ficar indentado sob essa expressão com, pelo menos, um espaço.
- As partes da expressão que estão agrupadas devem ser indentadas com o mesmo número de espaços.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Módulos

Cada ficheiro em Elm é um módulo e tem de conter uma instrução `module` antes de todo o resto do código.
Os nomes dos módulos têm de corresponder ao nome do ficheiro, por isso o módulo `Calculator` tem de estar no ficheiro Calculator.elm.
Tudo o que é definido dentro de um módulo tem âmbito privado
e não pode ser acedido de fora desse módulo, a menos que esteja listado em `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Comentários

Um comentário é um texto dentro do ficheiro Elm que não é interpretado como código.
Destina-se sobretudo a ser lido por ti e por outros programadores.
Há uma sintaxe leve para comentários de uma só linha, baseada em dois hífenes.
Também é possível escrever comentários de várias linhas com o par
de delimitadores de abertura e fecho `{-` e `-}`.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
