# Instruções

Refatoriza um analisador de Markdown.

O exercício de markdown é um exercício de refatorização.
Há código que analisa uma dada string com [sintaxe Markdown][markdown] e devolve o HTML associado a essa string.
Apesar de este código estar escrito de forma confusa e ser difícil de seguir, de alguma forma funciona e todos os testes passam!
O teu desafio é reescrever este código para o tornar mais fácil de ler e manter, garantindo ao mesmo tempo que todos os testes continuam a passar.

Seria útil que fosses anotando em comentários o que fizeste na tua refatorização, para que quem reveja possa vê-lo, mas não é estritamente necessário.
O mais importante é tornar o código melhor!

[markdown]: https://guides.github.com/features/mastering-markdown/
