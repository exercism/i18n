## MacOS

Primeiro, instala o Lua e o [Luarocks][2] com o [Homebrew][1]:

```shell
$ brew install lua luarocks
```

Depois, instala o framework de testes [Busted][3] para Lua:

```shell
$ luarocks install --local busted
```

Adiciona `~/.luarocks/bin` ao `$PATH` do teu sistema.

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

Repara que isto é apenas temporário.
Para o adicionar permanentemente ao teu `$PATH`, tens de o adicionar ao teu `.bashrc`, `.zshrc` ou `config.fish`, consoante o shell que estás a usar.

Depois, executa os teus testes:

```shell
$ busted
```

## Ubuntu

Primeiro, instala o Lua e o [Luarocks][2] com o [Apt][6]:

```shell
$ sudo apt-get install lua5.4 liblua5.4-dev luarocks
```

Depois, instala o framework de testes [Busted][3] para Lua:

```shell
$ luarocks install --local busted
```

Adiciona `~/.luarocks/bin` ao `$PATH` do teu sistema.

export PATH="$HOME/.luarocks/bin:$PATH"

Repara que isto é apenas temporário.
Para o adicionar permanentemente ao teu `$PATH`, tens de o adicionar ao teu `.bashrc`, `.zshrc` ou `config.fish`, consoante o shell que estás a usar.

Depois, executa os teus testes:

```shell
$ busted
```

## Windows 10: WSL

Primeiro, tens de ativar o [WSL (Subsistema Windows para Linux)][7] com o [PowerShell][8] (como Administrador):

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

Isto exige um reinício.

A seguir, instala o Ubuntu a partir da [Microsoft Store][9], **ou** descarrega-o e instala-o com o PowerShell:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

Depois, atualiza a tua lista de pacotes:

```shell
PS> wsl
$ sudo apt-get update
```

Agora já podes instalar o [LuaRocks][2] e o [Busted][3], seguindo as [instruções para Ubuntu](#ubuntu) acima.

Quando terminares, podes executar os teus testes diretamente a partir de qualquer linha de comandos do Windows:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Instalar o Gitbash

Este passo é opcional. Pode ser necessário ajustar ligeiramente os passos seguintes se preferires usar a CLI nativa do Windows ou outra CLI.

Descarrega [aqui][10].
Instruções de instalação [aqui][11].

### Instalar o Docker

Segue as instruções para instalar o [Docker for Windows][12].
Depois de terminares a instalação, podes executar o seguinte comando para garantires que foi instalado corretamente.

```shell
$ docker --version
```

_Podes encontrar um erro ao tentar executar o Docker pela primeira vez._

`cannot enable hyper-v service`

_Se isto acontecer, podes seguir estas instruções para [ativar o Hyper-V][13]. Pode ser necessário desativar a definição, reiniciar o computador e voltar a ativá-la depois do arranque._

### Instalar o Busted

Depois de teres o Gitbash e o Docker instalados, podes instalar um 'contentor' do Busted.

No Gitbash, executa o seguinte:

Descarrega este contentor Docker amplamente utilizado, executando o seguinte:

```shell
$ docker pull imega/busted
```

Cria uma função para não teres de escrever o comando completo todas as vezes.
Adiciona isto ao teu `.bashrc`:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

Agora, na tua CLI, podes navegar até ao diretório onde queres executar os testes. Executa o seguinte:

```shell
$ dbusted $PWD
```

Deves ver a saída dos teus testes do Busted.
