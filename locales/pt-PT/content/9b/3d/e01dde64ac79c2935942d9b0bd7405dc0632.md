# Anexo às instruções

## Dicas

Para completar este exercício, tens de implementar a função `wordCount`, que recebe um *texto* e devolve o número de vezes que cada *palavra* aparece.

Se é a primeira vez que resolves este exercício, é recomendável que uses a assinatura fornecida:

```haskell
wordCount :: String -> [(String, Int)]
```

Mais tarde, pode ser boa ideia revisitar este problema e experimentar outros tipos de dados e bibliotecas:

- `Text`, do pacote *text*.
- `Map`, do pacote *containers*.
- `MultiSet`, do pacote *multiset*

O conjunto de testes foi intencionalmente concebido para aceitar quase qualquer assinatura de tipo que faça sentido, por isso encorajamos-te a encontrar a que achares melhor.
