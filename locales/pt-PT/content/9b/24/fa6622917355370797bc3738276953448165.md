# Anexo às instruções

## Registos

| Registo | Utilização       | Tipo    | Descrição                            |
| -------- | --------- | ------- | ---------------------------- |
| `$a0`    | valor de entrada | endereço | string de entrada terminada em nulo |
| `$v0`    | valor de saída   | inteiro  | pontuação de Scrabble               |
| `$t0-9`  | temporário       | qualquer | para armazenamento temporário       |
