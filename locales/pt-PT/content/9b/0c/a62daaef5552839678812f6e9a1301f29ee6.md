# Introdução

O Go tem tipos numéricos básicos que conseguem representar conjuntos de valores inteiros ou de vírgula flutuante.

Este conceito vai concentrar-se em dois tipos de números:

- `int`: por exemplo, `0`, `255`, `2147483647`.
   Um inteiro com sinal que ocupa, no mínimo, 32 bits (intervalo de valores: -2147483648 a 2147483647).
   Mas isto depende da arquitetura do sistema.
   A maioria dos computadores modernos é de 64 bits, por isso `int` ocupa 64 bits (intervalo de valores: -9223372036854775808 a 9223372036854775807).

- `float64`: por exemplo, `0.0`, `3.14`.
   Contém o conjunto de todos os números de vírgula flutuante de 64 bits.

O Go suporta o conjunto padrão de operadores aritméticos: `+`, `-`, `*`, `/` e `%` (resto, não módulo).

No Go, atribuir um valor entre tipos diferentes exige uma conversão explícita.
Por exemplo, para converter um `int` num `float64`, tens de fazer o seguinte:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
