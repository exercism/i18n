# Instruções

O clube de poesia local está a começar uma nova temporada. Os poetas juntam-se ao clube e, sempre que dois deles escrevem um poema a quatro mãos, passam a fazer parte do mesmo *círculo de escrita*. O clube quer manter registo de quem partilha um círculo com quem, e pediram-te que escrevas as palavras que fazem essa gestão.

Um conjunto disjunto é a escolha perfeita: cada poeta é um átomo e cada círculo de escrita é um grupo.

## 1. Abre o clube

Define `new-club`, que recebe uma sequência de poetas e devolve um conjunto disjunto novo com todos os poetas registados. Cada poeta começa num círculo de escrita só seu.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. Regista uma colaboração

Define `collaborate`, que recebe dois poetas e um clube. Une os círculos de escrita dos dois poetas e devolve o clube, para que as colaborações possam ser registadas uma a seguir à outra.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. Encontra o círculo de um poeta

Define `circle-of`, que recebe um poeta e um clube e devolve o representante do círculo de escrita desse poeta. Dois poetas que partilham um círculo indicam sempre o mesmo representante.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. Partilham um círculo?

Define `same-circle?`, que recebe dois poetas e um clube e devolve `t` quando ambos os poetas pertencem ao mesmo círculo de escrita e `f` caso contrário. Compara os representantes dos poetas em vez de usar um teste de equivalência incorporado.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
