# Recursos

Aqui tens alguns recursos úteis que te vão ajudar a aprender mais sobre o SQLite e a melhorar as tuas competências:

- A [documentação oficial do SQLite][sqlite-docs] disponibiliza guias, tutoriais e referências abrangentes sobre o SQLite.

- [SQLite Command-Line Shell][sqlite-shell]: Documentação da interface de linha de comandos do SQLite, que te permite interagir com bases de dados SQLite através de comandos SQL.

- [SQLite FAQ][sqlite-faq]: Perguntas frequentes sobre o SQLite, que vão desde a instalação à resolução de problemas.

- [SQLite Forum][sqlite-forum]: O fórum do SQLite serve para colocares perguntas, reportares erros, sugerires melhorias, procurar orientação e discutires software relacionado com o SQLite.

- [SQLite Browser][sqlite-browser]: Uma ferramenta visual para criar, conceber e gerir bases de dados SQLite, que te permite explorar e editar ficheiros de bases de dados SQLite.

Explora estes recursos para aprofundares o teu conhecimento do SQLite e melhorares a tua proficiência na utilização deste poderoso sistema de gestão de bases de dados.

[sqlite-docs]: https://www.sqlite.org/docs.html
[sqlite-shell]: https://www.sqlite.org/cli.html
[sqlite-faq]: https://www.sqlite.org/faq.html
[sqlite-forum]: https://sqlite.org/forum/forum
[sqlite-browser]: https://sqlitebrowser.org/
