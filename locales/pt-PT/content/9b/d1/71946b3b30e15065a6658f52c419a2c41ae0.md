## Conhece o "Hello, World!"

O "Hello, World!" é provavelmente o programa mais famoso do mundo.
Praticamente todas as pessoas que aprenderam a programar já o escreveram pelo menos uma vez.
A sua simplicidade e a mensagem amigável costumam marcar o primeiro passo no maravilhoso mundo da programação.

No Exercism, recebes uma função chamada `hello` que devolve "Goodbye, Mars!".

```python
def hello():
    return 'Goodbye, Mars!'
```

A tua tarefa é alterá-la para que devolva "Hello, World!".

## A abordagem tradicional

Para começar, temos a abordagem mais simples, e aquela que o Exercism espera que implementes.
Basta uma simples alteração da string, de "Goodbye, Mars!" para "Hello, World!", e já a podemos devolver em segurança!

```python
def hello() -> str:
    return 'Hello, World'
```

## Abordagens alternativas

Vou resolver este exercício com todos os métodos diferentes de que me lembrei.

Para efeitos de narrativa, vou referir-me a esta função simples como "a máquina", uma máquina cujo único trabalho é devolver uma saudação "Hello, World!".

Vamos ver no que isto dá...!

### O join

A máquina já conhece algumas das palavras, mas parece que não as consegue... enfim, juntar numa string.

```python

    return ",".join(words)
```

### O ASCII

def hello() -> str:

### A permutação

Passou uma trovoada forte e a tua pobre máquina sem sorte foi atingida por um raio.
Continua a ligar-se, mas agora está a portar-se de forma estranha.
Todos os caracteres para montar a mensagem de saudação continuam lá, mas não estão por ordem, e os danos na placa lógica fazem com que a máquina já não consiga acertar na ordem da mensagem.
E, para tua sorte, a máquina mais pequena, incrivelmente fiável e *indestrutível*, que tinhas construído antes, afinal podia ser roubada (sim, desapareceu!).
Por isso, decides deixar o teu velho amigo experimentar todas as formas possíveis de baralhar estas letras até formar a mensagem correta.
Afinal, são só 13 caracteres e a máquina tem muita memória. Isto deve ser rápido...

```python
from itertools import permutations

def hello() -> str:
    chars = ['H', 'e', 'l', 'l', 'o', ',', ' ', 'W', 'o', 'r', 'l', 'd', '!']

    all_permutations = permutations(chars)
    for perm in all_permutations:
        if ("".join(perm) == "Hello, World!"):
            return ''.join(perm)
```

### Com classe

Decides experimentar e afinar a máquina para se comportar de forma diferente conforme o botão que é premido.
Pensaste em torná-la um pouco mais informal, começando a dizer "Hi", mas, como és uma pessoa *com classe*, decides usar sempre o método `hello` e tapar o outro.
E apercebes-te de que tens bastante tempo livre para estas coisas...

```python
class Greeting:
    location = "World"

    def __init__(self) -> None:
        pass

    def hello(self):
        return f"Hello, {self.location}!"

    def hi(self):
        return f"Hi, {self.location}!"

salutation = Greeting()
salutation.hello()
```

### A recursão

Por alguma razão, achaste que seria engraçado se a máquina ficasse um pouco lenta e só respondesse 10 segundos depois. O teu irmão volta a levantar a questão da lógica por trás desta funcionalidade, porque, segundo ele, és o único que usa a máquina.

```python
import time

def hello(n=10):
    if n == 0:
        return "Hello, World!"
    else:
        time.sleep(1)
        return hello(n-1)
```

### A aleatoriedade

De repente, um dia cansas-te de ouvir sempre a mesma saudação, por isso decides deixá-la cumprimentar-te uma última vez e reformar a máquina de vez, para nunca mais lhe tocar.
Como a máquina está contigo nos bons e maus momentos há muito tempo, decides deixar este encontro final entre "amigos" nas mãos do destino.
 Ligas a máquina uma última vez e deixas que ela gire...

```python
import random

def hello():
    chars = list("Helo,Wrld!")
    greeting = ""
    while (greeting != "Hello, World!"):
        greeting = "".join(random.choices(chars, k=13))
    return greeting
```
