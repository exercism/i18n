# Instruções

O serviço de objetos perdidos da escola guarda tudo em caixas, e o que vai para dentro de uma caixa pode ser qualquer coisa: uma camisola, um conjunto de coisas, um nome.

Escreve uma classe `LOST_BOX{T}`. O código inicial dá-te o cabeçalho da classe.

## 1. Receber algo

`create` recebe o objeto e o nome de quem o entregou, e devolve uma caixa. Uma caixa começa por não estar reclamada.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. Reclamar a caixa

`claim` marca a caixa como reclamada. Não devolve nada.

```sather
box.claim;
box.claimed
-- => true
```

## 3. Ainda está à espera?

`waiting` devolve verdadeiro se a caixa ainda não foi reclamada.

```sather
box.waiting
-- => false
```

## 4. Trocar o conteúdo

`replace` recebe um objeto novo, coloca-o na caixa e devolve o que lá estava antes. O objeto que entra e o objeto que sai são ambos `T`.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. Escrever a descrição

`describe` devolve uma linha sobre a caixa, como `"blue jumper, handed in by Mia"`.

Para colocar o objeto numa string, a classe tem de saber que um `T` pode ser convertido numa string. Restringe o parâmetro: escreve o cabeçalho da classe como `class LOST_BOX{T < $STR}`, e depois `item.str` já é permitido.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
