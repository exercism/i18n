# Introdução

Os carateres e as strings formam a base da representação de texto em Elm.
As strings podem ser vistas como listas de carateres e a maior parte das funções de `List` têm o seu equivalente no módulo `String`.

## Carateres

O tipo `Char` representa um único caráter unicode, entre plicas, por exemplo `'a'`. 
O módulo `Char` fornece funções de predicado (`Char -> Bool`) para testar qualidades de um caráter: `isUpper`, `isLower`, `isAlpha` e `isAlphaNum`.
O módulo também fornece funções para converter um caráter com `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, bem como para o seu valor numérico unicode (`Int`) e a partir dele, com `toCode` e `fromCode`.

## Strings

O tipo `String` oferece uma representação incorporada para manipular strings de forma eficiente e pode representar qualquer sequência de carateres unicode, por exemplo "this is an Elm string."
As strings com várias linhas são representadas com três aspas duplas e podem conter aspas e mudanças de linha não escapadas.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## Funções de string

O módulo `String` contém todas as funções resumidas na tabela abaixo.
Algumas das funções mais usadas incluem:

`cons : Char -> String -> String` acrescenta um caráter ao início de uma string.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` junta duas strings.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` divide uma string numa lista de strings, no separador indicado.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` concatena uma lista de strings com um separador indicado.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` substitui todas as ocorrências de uma substring indicada.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` devolve o número de carateres de uma string.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` tenta converter uma string em `Just Int` e devolve `Nothing` para strings com formato inválido.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` verifica se a segunda string contém a primeira.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` aplica uma função indicada a cada `Char` da string.
Repara que a função fornecida tem de ser um mapeamento de e para `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
