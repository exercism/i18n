# Adenda às instruções

## Adicionar métodos à classe Array

Este exercício centra-se em adicionar métodos à classe `Array` em Crystal.
Para isso, vais ter de definir uma classe com o nome `Array(T)`.
E colocar os métodos dentro dessa classe.

```crystal
class Array(T)
  # your solution here
end
```

A classe array é uma classe [genérica][generic], e é também [indexável][indexable] e [enumerável][enumerable].
O código-fonte da classe `Array` pode ser encontrado [aqui][array].

[array]: https://github.com/crystal-lang/crystal/blob/7aa5cdd86/src/array.cr#L48
[generic]: https://crystal-lang.org/docs/syntax_and_semantics/generics.html
[indexable]: https://crystal-lang.org/api/Indexable.html
[enumerable]: https://crystal-lang.org/api/Enumerable.html
