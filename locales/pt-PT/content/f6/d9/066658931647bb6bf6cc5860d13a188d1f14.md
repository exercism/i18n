# Instruções

Neste exercício, és um grande fã de desporto e acabaste de descobrir uma paixão pelo basquetebol da NBA. Como és novo no basquetebol da NBA, estás a fazer uma análise aprofundada da história da NBA, a acompanhar equipas, treinadores e as suas estatísticas de vitórias e derrotas, e a compará-las entre si.

Como ainda não tens uma equipa preferida, vais também desenvolver um algoritmo para descobrir se deves torcer por uma determinada equipa.

Tens sete tarefas para te ajudar a desenvolver o teu algoritmo proprietário de _torcer por uma equipa_.

## 1. Define o modelo

Define o registo `Coach` com os dois campos seguintes:

- `Name`: o nome do treinador, do tipo `string`.
- `FormerPlayer`: indica se o treinador era um ex-jogador, do tipo `bool`.

Define o registo `Stats` com os dois campos seguintes:

- `Wins`: o número de vitórias, do tipo `int`.
- `Losses`: o número de derrotas, do tipo `int`.

Define o registo `Team` com os três campos seguintes:

- `Name`: o nome da equipa, do tipo `string`.
- `Coach`: o treinador da equipa, do tipo `Coach`.
- `Stats`: as estatísticas da equipa, do tipo `Stats`.

## 2. Cria o treinador de uma equipa

Implementa a função `createCoach`, que recebe o nome do treinador e o seu estado de ex-jogador como parâmetros, e devolve o registo `Coach`:

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. Cria as estatísticas de uma equipa

Implementa a função `createStats`, que recebe o número de vitórias e o número de derrotas como parâmetros, e devolve o registo `Stats`:

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. Cria uma equipa

Implementa a função `createTeam`, que recebe como parâmetros o nome da equipa, o treinador e o registo, e devolve o registo `Team`:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. Substitui o treinador

Como os proprietários da NBA são impacientes, descobriste que os maus resultados da equipa levavam muitas vezes à substituição do treinador. Implementa a função `replaceCoach`, que recebe a equipa e o seu novo treinador como parâmetros, e devolve a equipa, mas com o novo treinador:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. Verifica se é a mesma equipa

Enquanto analisas as estatísticas, manténs listas de equipas e dos seus registos. Às vezes enganas-te e há entradas duplicadas na tua lista. Implementa a função `isSameTeam`, que recebe duas equipas e devolve `true` se forem a mesma equipa; caso contrário, devolve `false`:

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. Verifica se deves torcer por uma equipa

Depois de analisares muitas equipas e muitos jogos, surgiu-te um algoritmo. Se uma das seguintes condições for verdadeira, torces por essa equipa:

- O nome do treinador é "Gregg Popovich"
- O treinador é um ex-jogador
- O nome da equipa é "Chicago Bulls"
- A equipa ganhou 60 ou mais jogos
- A equipa tem mais derrotas do que vitórias

Implementa a função `rootForTeam`, que recebe uma equipa e devolve `true` se deves torcer por essa equipa; caso contrário, `return` false:

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
