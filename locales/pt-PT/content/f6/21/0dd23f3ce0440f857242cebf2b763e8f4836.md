# Sobre

Embora o Swift ofereça muitas funcionalidades na sua biblioteca padrão, podes aceder a muitas outras importando bibliotecas e frameworks externos.
Estes módulos podem vir diretamente do projeto Swift (como o [Swift Argument Parser][argument-parser]), de frameworks das plataformas da Apple (como a [Foundation][apple-foundation] e o [Network Framework][network-framework]), ou de bibliotecas de código aberto de terceiros (como o [SwiftyBeaver][swifty-beaver]).

Os módulos principais, como a Foundation, uma das bibliotecas mais utilizadas em Swift, vêm incluídos no toolchain do Swift.
As bibliotecas de terceiros têm de ser adicionadas à configuração do teu projeto (por exemplo, com o Swift Package Manager) antes de as poderes importar.

Para importar um módulo, escreve a palavra-chave `import` seguida do nome do módulo:

```swift
import Foundation
```

Importar um módulo torna os seus tipos, métodos e funções disponíveis para o teu código.
Por exemplo, importar a Foundation estende a `String` com métodos utilitários úteis como `components(separatedBy:)`.

Por convenção, as instruções `import` são colocadas no topo de um ficheiro Swift, para que as dependências fiquem imediatamente visíveis para quem lê o código.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
