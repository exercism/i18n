# Introdução

Compraste uma caixa grande de peças de computador aleatórias numa venda de garagem.
Começaste a juntar as peças para montar computadores à medida.

Queres testar o desempenho de diferentes combinações de peças e decides criar o teu próprio programa de avaliação de desempenho para ver como os teus computadores se comparam.
Escolhes o famoso algoritmo "Crivo de Eratóstenes", um algoritmo antigo, mas que deve levar os teus computadores ao limite.
