# Instruções

Cada papel na peça da escola tem um suplente: alguém que pode entrar em cena
e fazer o que o papel exige, sem que o diretor de cena saiba quem é.

As cinco tarefas ficam todas na classe `UNDERSTUDY`. As duas primeiras são
rotinas vulgares que as tarefas seguintes vão ligar.

## 1. Duas formas de dizer uma fala

Escreve `shout`, que devolve a fala em maiúsculas, e `whisper`, que a devolve
em minúsculas com `"..."` de cada lado.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. Ensaiar uma fala

`rehearse` recebe uma fala e uma forma de a dizer, e devolve o resultado. O
seu segundo argumento tem o tipo `ROUT{STR}:STR`.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. A cena toda

`run_scene` recebe um array de falas e uma forma de as dizer, e devolve-as
todas ditas assim, unidas com `" "`.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

Uma cena vazia é a string vazia.

## 4. Devolver uma forma de dizer as coisas

`understudy_for` recebe o nome de um estilo, `"shout"` ou qualquer outra
coisa, e devolve um `ROUT{STR}:STR`. `"shout"` dá a versão que grita;
qualquer outra coisa dá a versão que sussurra.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. Fixar um argumento

Escreve `repeat`, que recebe um número de vezes e uma fala e devolve a fala
repetida esse número de vezes, sem nada entre elas:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

Depois escreve `doubler`, que não recebe argumentos e devolve um
`ROUT{STR}:STR` que repete duas vezes aquilo que lhe for dado, ligando
`repeat` com o número já preenchido.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
