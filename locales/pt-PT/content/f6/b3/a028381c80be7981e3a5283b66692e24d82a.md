# Dicas

## Geral

- Os índices de `Vector` começam em `1`.
- Os baralhos de cartas não contêm cartas duplicadas.

## 1. Determinar se uma carta está presente

- Há um método [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in) na Base para determinar se uma coleção contém um valor.

## 2. Encontrar a posição de uma carta

- Há um método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) na Base para encontrar a posição do primeiro elemento de uma coleção que corresponde a um dado predicado.
- `==(x)` pode ser usado como predicado para encontrar elementos iguais a `x` em métodos que recebem funções de predicado.

## 3. Determinar se cada carta é par

- Há um método [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any}) na Base que devolve `true` se todos os elementos de uma coleção satisfizerem um dado predicado.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) é uma função de predicado.

## 4. Verificar se o baralho contém uma carta de valor ímpar

- Há um método [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any}) na Base que devolve `true` se algum elemento de uma coleção satisfizer um dado predicado.
- [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) é uma função de predicado.

## 5. Determinar a posição da primeira carta que é par

- Há um método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) na Base para encontrar a posição do primeiro elemento de uma coleção que corresponde a um dado predicado.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) é uma função de predicado.

## 6. Obter a primeira carta ímpar do baralho

- Podes obter o valor na posição `n` de um vetor `v` com `v[n]`.
- Há um método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) na Base para encontrar a posição do primeiro elemento de uma coleção que corresponde a um dado predicado.
- Se nenhum elemento da coleção dada corresponder ao predicado dado a `findfirst`, `findfirst` devolve `nothing`.
- Revê como `nothing` funciona em Julia: [concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- Revê como os condicionais funcionam em Julia: [concept:julia/conditionals](../../../../concepts/conditionals/about.md)
