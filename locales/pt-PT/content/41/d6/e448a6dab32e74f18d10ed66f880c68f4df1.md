# Sobre

A biblioteca padrão do Elixir oferece quatro módulos diferentes para trabalhar com datas e horas, cada um com a sua própria struct.

- O [módulo `Date`][date]. Uma struct `Date` pode ser criada com o [sigilo `~D`][sigil-d].
    ```elixir
    ~D[2021-01-01]
    ```

- O [módulo `Time`][time]. Uma struct `Time` pode ser criada com o [sigilo `~T`][sigil-t].
    ```elixir
    ~T[12:00:00]
    ```

- O [módulo `NaiveDateTime`][naivedatetime], para datas e horas sem fuso horário. Uma struct `NaiveDateTime` pode ser criada com o [sigilo `~N`][sigil-n].
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- O [módulo `DateTime`][datetime], para datas e horas com fuso horário. Usar este módulo com fusos horários diferentes de UTC exige uma dependência externa, uma base de dados de fusos horários. Uma struct `DateTime` pode ser representada com o [sigilo `~U`][sigil-u], mas deve ser criada com as funções do módulo `DateTime`.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## Comparações

Para comparares datas ou horas entre si, procura uma função `compare` ou `diff` no módulo correspondente. Os operadores de comparação, como `==`, `>` e `<`, _parecem_ funcionar, mas não fazem uma comparação semântica correta para estas structs.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## Deslocamento

As datas e as horas podem ser deslocadas para a frente e para trás no tempo com a função `add/2` do módulo correspondente.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## Conversões

Uma struct `NaiveDateTime` pode ser decomposta numa struct `Date` e numa struct `Time` com [`NaiveDateTime.to_date/1`][naivedatetime-to-date] e [`NaiveDateTime.to_time/1`][naivedatetime-to-time]. O inverso consegue-se com [`NaiveDateTime.new!/2`][naivedatetime-new].

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
