# Instruções

Implementa o método clássico para compor mensagens secretas chamado código quadrado.

Dado um texto em inglês, devolve a versão codificada desse texto.

Primeiro, a entrada é normalizada: os espaços e a pontuação são removidos
do texto em inglês e a mensagem passa a minúsculas.

Depois, os carateres normalizados são repartidos em linhas. Estas linhas podem
ser vistas como formando um retângulo quando impressas com quebras de linha
entre elas.

Por exemplo, a frase

```text
"If man was meant to stay on the ground, god would have given us roots."
```

é normalizada para:

```text
"ifmanwasmeanttostayonthegroundgodwouldhavegivenusroots"
```

O texto simples deve ser organizado num retângulo. O tamanho do
retângulo (`r x c`) deve ser decidido pelo comprimento da mensagem,
de forma que `c >= r` e `c - r <= 1`, em que `c` é o número de colunas
e `r` é o número de linhas.

O nosso texto normalizado tem 54 carateres, o que dita um retângulo com
`c = 8` e `r = 7`:

```text
"ifmanwas"
"meanttos"
"tayonthe"
"groundgo"
"dwouldha"
"vegivenu"
"sroots  "
```

A mensagem codificada obtém-se lendo as colunas de cima para baixo, da
esquerda para a direita.

A mensagem acima é codificada como:

```text
"imtgdvsfearwermayoogoanouuiontnnlvtwttddesaohghnsseoau"
```

Devolve o texto codificado em blocos que preenchem retângulos perfeitos `(r X c)`,
com `c` blocos de comprimento `r`, separados por espaços. Nas frases que ficam
`n` carateres aquém do retângulo perfeito, preenche cada um dos últimos `n`
blocos com um único espaço no final.

```text
"imtgdvs fearwer mayoogo anouuio ntnnlvt wttddes aohghn  sseoau "
```

Repara que, se empilhássemos estes blocos, poderíamos descodificar visualmente o
texto cifrado de volta para a mensagem original:

```text
"imtgdvs"
"fearwer"
"mayoogo"
"anouuio"
"ntnnlvt"
"wttddes"
"aohghn "
"sseoau "
```
