# Instalação

Primeiro, certifica-te de que tens o Erlang instalado, seguindo as instruções na
página de instalação do [Erlang][1], conforme for adequado.
[1]: /languages/erlang

## Homebrew para Mac OS X

Atualiza o teu Homebrew para a versão mais recente:

```bash
$ brew update
```

Instala o LFE:

```bash
$ brew install lfe
```

## Instalar a partir do código-fonte
Instala as «ferramentas de desenvolvimento» ou os «pacotes essenciais de compilação» do teu sistema, o `git`
e o `erl` do Erlang.

Por exemplo, no Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Depois, podes descarregar e compilar o LFE com os seguintes comandos:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Depois de teres o LFE compilado, podes iniciar a REPL (sessão interativa)
ao executar o binário ``lfe``:

```bash
$ ./bin/lfe
```
