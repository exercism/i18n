# Dicas

## Geral

- Lê sobre [`alias` e `import`][getting-started] no guia Getting Started.
- Lê sobre [composição de módulos][elixir-school-module-composition] em elixirschool.com.

## 1. Corrige o erro de compilação `Race.__struct__/0 is undefined`

- Podes criar um alias com a forma especial [`alias`][alias].

## 2. Corrige o erro de compilação `Car.__struct__/0 is undefined`

- Podes criar um alias com a forma especial [`alias`][alias].
- A forma especial `alias` aceita uma opção `:as`.

## 3. Corrige o erro de compilação `undefined function puts/1`

- Podes importar funções com a forma especial [`import`][import].
- A forma especial [`import`][import] aceita uma opção `:only`. O seu valor deve ser uma lista de palavras-chave em que as chaves são nomes de funções e os valores são as respetivas aridades.

## 4. Corrige o erro de compilação `undefined function default_color/0`

- Podes importar funções com a forma especial [`import`][import].
- A forma especial [`import`][import] aceita uma opção `:except`. O seu valor deve ser uma lista de palavras-chave em que as chaves são nomes de funções e os valores são as respetivas aridades.
