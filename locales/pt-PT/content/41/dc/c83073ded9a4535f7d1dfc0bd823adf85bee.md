# Apêndice

## Bónus

Dois testes opcionais estão desativados por predefinição. Para os ativares, adiciona `const TEST_BIG_INTEGERS = true` ao âmbito global do teu ficheiro de solução (ou descomenta a linha fornecida no stub).

Estes números excedem o tipo inteiro predefinido, mas os inteiros de 128 bits são suficientes para passar nos testes; não precisas de `BigInt`.
