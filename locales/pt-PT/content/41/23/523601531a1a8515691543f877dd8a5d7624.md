# Instalação

Precisas do [NodeJS LTS](https://nodejs.org/en).

> 💡 Este percurso funciona provavelmente com versões estáveis mais antigas, bem como com a versão "atual".
> No entanto, [propositadamente](https://github.com/nodejs/release#release-schedule), as versões ímpares nunca são estáveis.
> Certifica-te sempre de que instalas uma versão par do NodeJS.

Instala o [Yarn 4+](https://yarnpkg.com/getting-started/install) com o `corepack` do Node.JS:

```shell
corepack enable yarn
```

## Verificar a instalação

Em geral, tens de abrir um novo terminal para poderes usar os binários que acabaste de instalar.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_Nota: é provável que as tuas versões sejam diferentes destas._

## Instalação do exercício

**Cada exercício** precisa de algumas ferramentas para correr os testes:

Para as instalar, executa este comando dentro do diretório de cada exercício:

```bash
$ corepack yarn install
```

Dependendo do teu editor, o [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) tem de ser instalado em cada exercício, para funcionar com instalações Plug'n'Play.
No momento em que este texto foi escrito, os seguintes são suportados:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
