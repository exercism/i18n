# Sobre

O Ruby inclui uma Biblioteca Padrão (muitas vezes abreviada para "stdlib"), uma coleção de classes para trabalhar com coisas como datas, JSON e redes.
Também fornece algumas funcionalidades úteis para tornar o teu código mais fácil de trabalhar.

O `OpenStruct` faz parte da Biblioteca Padrão e permite criar facilmente um objeto a partir de um `Hash`.
Em vez de teres de aceder através das chaves de um `Hash`, o `OpenStruct` permite-te usar métodos para aceder e definir valores.

Quando usas classes da Biblioteca Padrão, ou de qualquer outra biblioteca, tens de usar o método `require` para carregar essa classe.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Uma vantagem adicional disto é que podes aproveitar um atalho quando usas a sintaxe de bloco.
Em situações em que um bloco chama um único método, podes substituir o bloco por `&:` seguido do nome do método.
Por exemplo, estas duas linhas são sinónimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
