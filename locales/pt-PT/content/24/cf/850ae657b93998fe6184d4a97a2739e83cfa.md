# Introdução

A memória dinâmica é implementada por funções de biblioteca que o programador usa para alocar e libertar memória em tempo de execução.
Como o programador controla a alocação e a libertação da memória, a memória dinâmica é tão segura quanto o programador estiver livre de erro humano.
Por essa razão, a memória dinâmica é uma das principais fontes de erros de programação e um dos principais alvos de ataques informáticos.

## malloc

`malloc` é uma função declarada em `stdlib.h` que serve para alocar memória dinâmica.
Se a alocação for bem-sucedida, é devolvido um apontador que aponta para o endereço do primeiro byte da memória alocada.
Se a alocação não for bem-sucedida, é devolvido `NULL`.
É prudente verificar se o resultado de `malloc` é `NULL` e lidar com a falha de forma controlada.
O apontador devolvido é do tipo `pointer-to-void`, que pode ser considerado, de forma aproximada, como um apontador "genérico" que pode ser convertido para o tipo específico usado pela memória.
`malloc` tem um parâmetro, que é o tamanho, em bytes, da memória pretendida.
O tamanho total para alocar um array é o tamanho do tipo de dados de cada elemento multiplicado pelo número de elementos.
O operador `sizeof` é habitualmente usado para obter o tamanho do tipo de dados de cada elemento.
O exemplo seguinte demonstra isto

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

É importante lembrar-te de que a memória recém-alocada por `malloc` não é inicializada, mas pode conter valores de lixo.
Repara que o `sizeof` do apontador `numbers` não é o número de elementos do array, nem a quantidade total de memória alocada.
O tamanho do apontador devolvido por `malloc` é o tamanho de qualquer apontador nesse sistema em particular.
O código do exemplo foi executado num sistema de 64 bits, pelo que o tamanho do apontador era 8 bytes (multiplicado por 8 bits por byte = 64 bits).
O tipo do apontador foi convertido implicitamente de pointer-to-void para pointer-to-int.
Também podia ter sido convertido explicitamente assim: `int * numbers = (int *) malloc(sizeof(int) * count);`.
Se os valores forem definitivamente escritos antes de serem lidos, usar `malloc` pode ser uma forma eficiente de alocar memória.
Mas, se houver a possibilidade de os valores serem lidos antes de serem inicializados, usar `malloc` é arriscado.
Uma forma mais segura de alocar memória é usar `calloc`, que inicializa a memória recém-alocada a zero.

Repara que, nos exemplos acima, foi usada a chamada `free(numbers)`.

## free

`free` é uma função declarada em `stdlib.h` que serve para libertar memória que foi alocada dinamicamente.
A memória alocada dinamicamente permanece ocupada até ser libertada por `free`.
Alguns sistemas operativos podem libertar automaticamente a memória alocada dinamicamente quando o programa termina, mas é boa prática não depender disso.
`free` tem um parâmetro, que é um apontador para a memória que foi alocada dinamicamente.
Um apontador que não é definido como `NULL` depois de a memória ser libertada é designado por apontador pendente.
Um apontador pendente pode referir-se a outra memória que não aquela para a qual era pretendido.
Assim, um apontador pendente pode levar à corrupção de dados e à substituição e execução de código arbitrário.
Um apontador para memória alocada que não foi limpo, definindo-o como `NULL`, pode ser usado para atacar o programa.
É boa prática definir um apontador como `NULL` depois de este ter sido passado a `free`.

## calloc

`calloc` é uma função declarada em `stdlib.h` que serve tanto para alocar memória dinâmica como para inicializar a memória recém-alocada a zero.
Se a alocação for bem-sucedida, é devolvido um apontador que aponta para o endereço do primeiro byte da memória alocada.
Se a alocação não for bem-sucedida, é devolvido `NULL`.
É prudente verificar se o resultado de `calloc` é `NULL` e lidar com a falha de forma controlada.
O apontador devolvido é do tipo `pointer-to-void`, que pode ser considerado, de forma aproximada, como um apontador "genérico" que pode ser convertido para o tipo específico usado pela memória.
`calloc` tem dois parâmetros.
O primeiro parâmetro indica quantos elementos do tipo de dados especificado devem ser alocados.
O segundo parâmetro indica o tamanho do tipo de dados especificado a alocar.

No exemplo seguinte, todas as instruções `printf` devem mostrar sempre `0`, uma vez que `calloc` garante que os valores recém-alocados ficam a zero.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` é uma função declarada em `stdlib.h` que serve para expandir ou reduzir memória já alocada.
Se a realocação for bem-sucedida, é devolvido um apontador que aponta para o endereço do primeiro byte da memória realocada.
Se a realocação não for bem-sucedida, é devolvido `NULL`.
É prudente verificar se o resultado de `realloc` é `NULL` e lidar com a falha de forma controlada.
`realloc` tem dois parâmetros.
O primeiro parâmetro é um apontador para a memória existente a realocar.
O segundo parâmetro é o tamanho, em bytes, da memória realocada.
Os valores definidos antes de a memória ser expandida são mantidos.
É importante lembrar-te de que a memória acrescentada ao expandir não é inicializada a zero e os seus valores podem ser quaisquer.
Além disso, a memória removida ao reduzir também não é inicializada e pode conservar os valores.
O exemplo seguinte demonstra como expandir e reduzir um array

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
