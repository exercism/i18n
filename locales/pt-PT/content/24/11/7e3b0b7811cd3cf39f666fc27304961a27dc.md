# Introdução

## Desestruturação de arrays

A sintaxe de desestruturação de arrays do JavaScript é uma forma concisa de extrair valores de um array e atribuí-los a variáveis distintas.

Neste exemplo, cada valor do array `numberOfMoons` é atribuído ao planeta correspondente:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

Resumindo:

- A sintaxe permite dar nome a elementos _posicionados_ num array, bem como trocar variáveis através de reatribuição.
- A sintaxe de desestruturação está disponível dentro dos parâmetros de função e em qualquer iterável.
- Deixar uma posição sem nome (não escrevendo _qualquer_ nome de variável) ignora essa posição silenciosamente.

## Desestruturação de objetos

Em JavaScript, existe também sintaxe de desestruturação para extrair propriedades de um objeto e atribuí-las a variáveis distintas.

Neste exemplo, são extraídos símbolos meteorológicos do objeto `weather`:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

Resumindo:

- A sintaxe permite tanto extrair propriedades como extraí-las e renomeá-las.
- A sintaxe de desestruturação está disponível dentro dos parâmetros de função.
