# Números

O Crystal tem um tipo, `Number`, que é o tipo base de todos os tipos numéricos.
Dentro do tipo Number existem dois subtipos principais: [`Int`][int] e [`Float`][float].

`Int` é a abreviação de *integer* e representa números inteiros.
`Int` pode ser negativo ou positivo e não tem parte decimal.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` representa números com parte decimal.
Os `Float` podem ser negativos ou positivos.

```crystal
10.5.class
# => Float64
```

## Conversão entre `Int` e `Float`

Com os métodos 'to_i' e 'to_f' podes converter entre `Int` e `Float`.
Ao converter de `Float` para `Int`, o número é arredondado para baixo.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Operadores aritméticos

Podes usar os [operadores aritméticos básicos][math] com `Int` e `Float`.
Os operadores são `+`, `-`, `*`, `/` e `%`.
Ao usares estes operadores, podes misturar `Int` e `Float` livremente.

### Adição, subtração e multiplicação

O operador `+` é usado na adição, o operador `-` na subtração e o operador `*` na multiplicação.

| Operador | Exemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Divisão

A divisão serve para dividir números.
O operador `/` é usado na divisão.
O resultado é sempre um Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Nalgumas linguagens de programação, dividir por zero dá origem a um erro.

No Crystal, ao dividir por zero, o resultado é `Infinity` ou `-Infinity`.
A única exceção é dividir zero por zero, que resulta em `NaN` (Not a Number).
`Infinity` e `NaN` são valores especiais do tipo `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## Divisão inteira

A divisão inteira serve para dividir números e obter a parte inteira do resultado.
O resultado é sempre arredondado para baixo, para um Int.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
Dividir por zero com a divisão inteira dá origem a um `DivisionByZeroError`.
Isto é diferente da divisão normal.
~~~~

### Módulo

O módulo serve para obter o resto de uma divisão.
O operador `%` é usado no módulo.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Dividir por zero com o módulo dá origem a um DivisionByZeroError.
Isto é diferente da divisão normal.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Exponenciação

A exponenciação serve para elevar um número a uma potência.
O operador `**` é usado na exponenciação.
O resultado de uma operação entre um `Float` e um `Int` é um `Float`.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## Arredondamento

O método `round` aceita um argumento opcional: o número de casas decimais para o qual arredondar.
Por omissão, o número de casas decimais é 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### Arredondar para cima e para baixo

Também podes arredondar para cima ou para baixo, para um `Int`, com os métodos `ceil` e `floor`.
O método `ceil` arredonda para cima e o método `floor` arredonda para baixo.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## Prioridade e parênteses

O Crystal permite parênteses (`()`), que podem ser usados para agrupar expressões.
Isto é útil quando queres alterar a ordem das operações.

Quando usas vários operadores aritméticos, a ordem das operações é a mesma da matemática, também conhecida como [PEMDAS][pemdas].
Segue a ordem de parênteses (`()`), expoentes (`**`), multiplicação (`*`) e divisão (`/`), e adição (`+`) e subtração (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
