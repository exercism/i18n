# Instruções

O Larry é um Lisp Alien que gosta de escrever código para jogar.
Hoje quer escrever algumas funções para o ajudar num jogo muito parecido com o jogo do galo.

Tal como o jogo do galo, este jogo é jogado num tabuleiro que é uma grelha 3x3.

## 1. Começar do zero

Primeiro, o Larry precisa de uma função para criar um tabuleiro vazio, `make-empty-board`.
Todas as células do tabuleiro devem ser `NIL`.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Começar a partir de um tabuleiro existente

De seguida, o Larry precisa de uma função para criar um tabuleiro a partir de uma lista de linhas.
Por exemplo:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. Condição de vitória

Se houver um caso em que há 3 símbolos iguais numa linha, então esse jogador ganhou.
O Larry vai precisar de uma função, `all-the-same-p`, que, dado um array de 3 itens, avalia para `T` se todos os itens forem o mesmo símbolo.
(Podes usar `eq` para determinar se dois símbolos são iguais.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. Numa linha

Agora o Larry precisa de uma forma de obter os elementos de uma linha.
A função `row` recebe um tabuleiro e um número de linha e deve devolver um array com os elementos dessa linha.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. Numa coluna

Por fim, o Larry precisa de uma forma de obter os elementos de uma coluna.
A função `column` recebe um tabuleiro e um número de coluna e deve devolver um array com os elementos dessa coluna.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
