# Introdução

Os números inteiros podem ser vistos não apenas como valores numéricos, mas também como padrões de bits. O vocabulário [`math`][math] do Factor tem as operações de baixo nível habituais sobre esses padrões de bits, e o vocabulário [`math.bitwise`][bitwise] acrescenta alguns auxiliares para trabalhar com valores de largura fixa.

## Deslocamentos de bits

`shift ( m n -- m' )` desloca os bits de `m`. Um `n` *positivo* desloca para a esquerda (multiplicando por 2 a cada passo); um `n` *negativo* desloca para a direita (dividindo por 2 a cada passo):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

Para números inteiros positivos, o deslocamento para a direita descarta bits pela extremidade inferior e preenche com zeros. Para números inteiros *negativos*, o `shift` do Factor é aritmético: preserva o bit de sinal e, conceptualmente, preenche a partir da esquerda com cópias do bit de sinal. (Os números inteiros do Factor têm precisão arbitrária, por isso «a esquerda» estende-se tanto quanto for necessário.)

## Lógica bit a bit

As quatro operações lógicas básicas são:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

O `bitnot` de `0b1011` é `-12` porque os números inteiros do Factor têm precisão arbitrária: inverter os bits de `0b1011` é, conceptualmente, «todos uns com os quatro bits de ordem inferior invertidos para `0100`», o que, lido como um bignum com sinal, dá `-12`.

## Tratar um valor como N bits

`bits ( x n -- y )`, de `math.bitwise`, aplica uma máscara a `x` para o reduzir aos seus `n` bits de ordem inferior. É a forma de, em Factor, «reinterpretar um valor como um número inteiro sem sinal de N bits»:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

O segundo exemplo é importante para este exercício. Se começares com um valor Int32 negativo em complemento para dois e quiseres deslocá-lo «logicamente» para a direita (preenchendo com zeros a partir da esquerda) em `amount`, a forma idiomática em Factor é:

```
( value -- shifted )
32 bits  amount neg  shift
```

Aplica primeiro a máscara para 32 bits, para passar à interpretação sem sinal, e só depois desloca. Como o valor resultante da máscara não é negativo, o `shift` limita-se a descartar bits pela extremidade inferior e a preencher com zeros.
