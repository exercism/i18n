# Introdução

Sendo o Clojure uma linguagem funcional, as funções são cidadãos de primeira classe. Isto significa que podem ser passadas a outras funções e geradas por elas tal como qualquer outro dado. Em particular, o Clojure traz um conjunto rico de funções de ordem superior que criam novas funções a partir de funções já existentes. Vamos explorar aqui quatro casos importantes: `partial`, `comp`, `memoize` e `juxt`. Estas funções que geram funções fazem parte de uma categoria mais ampla de funções de ordem superior, como `map`, `reduce`, `apply` ou `complement`, entre outras, que operam sobre funções já existentes.

## partial

Em geral, dada uma função já existente `my-function`, com os parâmetros `p1, p2, ..., pN`, podemos fixar alguns dos seus parâmetros `p1, p2, ..., pM` em valores constantes `v1, v2, ..., vM`. Para isso, aplicamos `partial` da seguinte forma: `(partial my-function v1 v2 ... vM)`. 

O resultado é uma nova função que aplica a função original `my-function` fixando `p1=v1, p2=v2, ..., pM=vM`. A nossa nova função recebe como parâmetros de entrada os restantes, `pM+1, pM+2, ..., pN`, cujos valores não foram indicados ao aplicar `partial`:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Como exemplo simples, vamos definir uma função `inc-by-9` que aumenta em 9, um valor fixo, independentemente do que lhe passarmos. Poderíamos implementar uma função dessas da seguinte forma:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Como segundo exemplo, temos uma função `generic-greetings` que usa o nome da pessoa a quem queremos dirigir a saudação, juntamente com uma mensagem inicial e uma mensagem final:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

E usamos `partial` para usar sempre uma mensagem de saudação específica:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

O `comp` pode ser usado para criar a composição de qualquer número de funções que queiramos compor. Em geral, compor `N` funções `f1, f2, ..., fN` significa aplicá-las por ordem sequencial, passando o resultado da anterior à seguinte. Em notação matemática, isto escreve-se assim:

```
f1 (f2 (... fN(x)))
```

No Clojure, isto equivale a fazer:
```clojure
(f1 (f2 (... (fN x))))
```

Ao usar comp, podemos criar uma nova função que faz esta composição por nós:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Como exemplo, suponhamos que queremos somar uma série de números e depois multiplicar o resultado por 6. Podemos fazê-lo assim:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

O `memoize` permite reutilizar resultados já calculados associados a um determinado valor de entrada. Dado o mesmo valor de entrada, a função *memorizada* devolve o mesmo resultado sem ter de o calcular outra vez. Aproveita o facto de as funções do `clojure` serem, por omissão, *referencialmente transparentes*: dado o mesmo valor de entrada, produzem sempre o mesmo resultado, o que permite reutilizar cálculos anteriores com facilidade. 

Para ver como isto funciona, vamos usar um caso artificial em que a função faz uma pausa de dois segundos antes de produzir o resultado, para podermos comparar facilmente o *tempo de computação* antes e depois de usar `memoize`.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

O `juxt` gera uma função que aplica, da esquerda para a direita, as funções que lhe são passadas. O resultado é um vetor cujos componentes são os resultados individuais de cada função: 

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Como exemplo simples, geramos uma função que calcula o produto de x por fatores sucessivos, de 2 a 5:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
