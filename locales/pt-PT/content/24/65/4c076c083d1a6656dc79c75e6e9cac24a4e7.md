# Instruções

Neste exercício vais documentar o código que acabaste de escrever para te ajudar a fazer uma lasanha fantástica. É pouco provável que voltes a olhar para este código relacionado com lasanha, mas documentar o código é muito útil se quiseres que qualquer projeto maior seja compreensível para os outros (ou para ti!).

Para documents o teu código, escreve uma "docstring" para cada uma das três funções. Eis como o fazer:

- Consulta a secção [Documentação][doc] do Manual de Julia.
- Começa pela assinatura da função indentada com 4 espaços.
- Inclui uma única frase de uma linha a descrever o que a função faz, pelas tuas próprias palavras.

## 1. Documenta a preptime

A primeira função que escreveste foi a `preptime`, que calcula quanto tempo demora a preparar a lasanha.

## 2. Documenta a remaining_time

A segunda função que escreveste foi a `remaining_time`, que calcula quanto tempo falta até a lasanha estar pronta.

## 3. Documenta a total_working_time

A terceira função que escreveste foi a `total_working_time`, que calcula quanto tempo demora a fazer a lasanha.
