# Aprender Visual Basic

## Websites

O Visual Basic evoluiu bastante ao longo dos anos, e muitos tutoriais de terceiros referem ferramentas ou funcionalidades desatualizadas.
A [documentação oficial do Visual Basic](https://learn.microsoft.com/en-us/dotnet/visual-basic/) é o sítio mais atual e fiável para dares os primeiros passos.

## O ecossistema .NET

O Visual Basic corre sobre o runtime .NET e partilha muita da funcionalidade central com o C# e o F#.
Por isso, perceber como o .NET funciona vai fazer de ti um programador de VB mais forte.

- [O que é o .NET?](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [O glossário do .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [O Common Type System (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
