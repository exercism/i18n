# Apêndice às instruções

## Formato da saída

Devolve uma _string_ terminada em `null`, usando uma vírgula e um espaço como separadores.

Um exemplo de saída seria `"491, 914, 142"`.

Se os valores de entrada forem inválidos, devolve uma _string_ vazia.

## Registos

| Registo  | Utilização             | Tipo    | Descrição                          |
| -------- | ---------------------- | ------- | ---------------------------------- |
| `$a0`    | parâmetro de entrada   | endereço | _string_ de série terminada em `null` |
| `$a1`    | parâmetro de entrada   | inteiro | comprimento da fatia               |
| `$a2`    | parâmetro de entrada/saída | endereço | _string_ de saída terminada em `null` |
| `$t0-9`  | temporário             | qualquer | usado para armazenamento temporário |
