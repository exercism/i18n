# Instruções

Ninguém sobe ao trapézio do circo antes de as verificações de segurança passarem.
Estás a escrever as verificações para que as mesmas regras se apliquem a todos.

As cinco tarefas ficam todas na classe `SAFETY_CHECK`.

## 1. O tapete está pronto?

O tapete só está pronto quando está no chão e limpo.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. Há algo onde aterrar?

Tem de haver um tapete por baixo, ou uma rede por baixo. Qualquer um dos dois
serve, e ter os dois também não faz mal.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. Quem ainda precisa do briefing?

Qualquer pessoa que ainda não tenha recebido o briefing precisa do briefing.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. Este artista tem idade suficiente?

O trapézio é para artistas com 13 anos ou mais.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. Junta tudo

Um artista está autorizado a subir ao trapézio quando tem idade suficiente, já
recebeu o briefing e o tapete está pronto.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

Os quatro argumentos são a idade, se já recebeu o briefing, se o tapete está no
chão e se o tapete está limpo.
