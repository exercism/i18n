# Aprendizagem

O Cairo é a primeira linguagem Turing-completa para criar programas comprováveis de computação geral. É uma linguagem de alto nível, à semelhança de Rust. Tal como Rust, destina-se a permitir que os programadores escrevam facilmente código eficiente e seguro.

Achamos que a melhor forma de aprender é brincar e praticar, seja criando os teus próprios projetos de programação, seja resolvendo pequenos problemas como os que encontras aqui no Exercism!

Aqui ficam alguns recursos que te podem ajudar a dar os primeiros passos no Cairo:

- [Cairo Programming Language](https://www.cairo-lang.org/) apresenta a linguagem Cairo e reúne muitos recursos relevantes para aprender e usar Cairo.
- [The Cairo Book](https://book.cairo-lang.org/) é um excelente recurso para aprender Cairo e também para aprofundar funcionalidades específicas do Cairo.
- [Cairo Documentation](https://docs.cairo-lang.org/) explica as construções e a semântica da linguagem.
- [Cairo by Example](https://cairo-by-example.com/) mostra exemplos das coisas mais comuns que vais escrever em Cairo.
- [Node Guardians](https://nodeguardians.io/campaigns?f=3%3D2) "Uma plataforma de aprendizagem com tema de fantasia para programadores de contratos inteligentes."
- O [Cairo Community Forum](https://community.cairo-lang.org/) responde a perguntas de todos os níveis.
