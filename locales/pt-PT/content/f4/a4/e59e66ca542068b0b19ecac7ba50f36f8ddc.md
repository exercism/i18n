# Desestruturação

A desestruturação é o processo de decompor itens nas suas partes constituintes, associando cada uma a variáveis mais pequenas.

## Desestruturar tuplos

Desestruturar tuplos é simples: basta atribuir novos nomes de variáveis a cada campo do tuplo:

```rust
let (first, second) = (1, 2);
```

## Desestruturar structs de tuplo

Desestruturar structs de tuplo é idêntico a desestruturar tuplos, mas com o nome da struct acrescentado:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## Desestruturar structs

Desestruturar structs é semelhante a desestruturar structs de tuplo. Basta usar os nomes dos campos:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## Desestruturação parcial

O operador `..` pode ser usado para ignorar alguns campos durante a desestruturação:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## Desestruturação condicional

Desestruturar structs e tuplos é infalível. No entanto, também é possível desestruturar enums, recorrendo às construções da linguagem `if let`, `while let` e `match`.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
