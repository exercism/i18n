# Ajuda

Abaixo encontras alguns recursos para obter ajuda, caso tenhas problemas:

- [A PSF](https://www.python.org) aloja as transferências do Python, a documentação e recursos da comunidade.
- Os [Fóruns da Comunidade Python](https://discuss.python.org/) servem para obter ajuda, discutir PEPs, falar com os principais contribuidores do Python e muito mais.
- [A Comunidade do Exercism no Discord](https://exercism.org/r/discord)
- [Os Fóruns de Discussão da Comunidade do Exercism](https://forum.exercsim.org)
- A [Comunidade Python no Discord](https://pythondiscord.com/) é uma comunidade muito prestável e ativa.
- O [/r/learnpython/](https://www.reddit.com/r/learnpython/) é um subreddit pensado para quem está a aprender Python.
- O [#python no Libera.chat](https://www.python.org/community/irc/) é o sítio onde os programadores responsáveis pela linguagem se juntam e põem o trabalho em dia.
- Os [Fóruns da Comunidade Free Code Camp](https://forum.freecodecamp.org/)
- O [Pythontutor](http://pythontutor.com/) para percorrer pequenos excertos de código visualmente.

Além disso, o [StackOverflow](http://stackoverflow.com/questions/tagged/python) é um bom sítio para procurar o teu problema ou a tua dúvida e ver se já foi respondida.
Se não foi, podes sempre [perguntar](https://stackoverflow.com/help/how-to-ask) ou [responder](https://stackoverflow.com/help/how-to-answer) à pergunta de outra pessoa.
