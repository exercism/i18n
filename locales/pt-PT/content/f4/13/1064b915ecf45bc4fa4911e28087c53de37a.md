# Introdução

Um *tuple* é o tipo de registo/estrutura/classe do Factor. Cada classe de tuple tem um conjunto fixo de fendas com nome, e o Factor gera automaticamente os getters e setters correspondentes.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

O `boa` ("por ordem de argumentos") preenche as fendas a partir da pilha, pela ordem de declaração. O `new` cria uma instância com cada fenda no valor declarado em `initial:` (ou `f`, caso não exista).

O getter de cada fenda é `slot>>` e o setter é `>>slot`. O setter *altera* o objeto, por isso usa `clone` primeiro se precisares de uma atualização não destrutiva:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Os valores por omissão das fendas usam `{ name initial: value }`; sem `initial:`, o valor por omissão é `f`.
