# Introdução

Os arrays associativos do Factor (tabelas de hash e afins) partilham um [protocolo][assoc-protocol] comum do [`assocs`][assocs]. O literal de tabela de hash é `H{ }`:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

Operações comuns:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

As tabelas de hash são *mutáveis*. Faz `clone` de um literal `H{ }` antes de o modificar, para que o literal não seja partilhado entre chamadas.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
