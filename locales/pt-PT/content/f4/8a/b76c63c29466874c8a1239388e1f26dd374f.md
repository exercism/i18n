# Sobre

Os blocos são pequenos agrupamentos de instruções que podem ser executados várias vezes.
Podes encará-los como closures ou funções anónimas.
Os blocos definem-se com a sintaxe `do...end` (acima), ou com `{}` (abaixo).
Os estilos são intercambiáveis e há opiniões divergentes sobre quando usar cada um.

## Sintaxe abreviada
Quando um bloco chama um único método, podes substituir o bloco por `&:` seguido do nome do método. Por exemplo, estas duas linhas são sinónimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
