# Introdução

## Mapeamento

O mapeamento é a aplicação de uma função a cada elemento de uma sequência, para produzir uma nova sequência.

Isto pode ser feito facilmente numa lista com a função `mapcar`.
Vamos supor que temos uma função `double` que multiplica o seu argumento por `2`:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Repara que o primeiro argumento é uma função a chamar. O `#'` é uma sintaxe especial de quoting para especificar uma função.

O `double` foi chamado primeiro com o primeiro elemento, depois com o segundo, e assim por diante.
Os resultados foram reunidos numa lista, que é o valor para o qual a expressão é avaliada.

## Filtragem

A filtragem é o processo de criar uma sequência a partir de outra, copiando da sequência original todos os elementos exceto alguns.
A escolha dos elementos a incluir na nova sequência pode ser feita através de uma função de predicado (uma função que é avaliada para um valor Boolean), ou por igualdade com um objeto específico.

### Remover através de um predicado

O `remove-if` é uma função que recebe, como argumentos, uma função de predicado e uma sequência, e devolve uma sequência apenas com os elementos para os quais o predicado foi avaliado como falso.
Por outras palavras, "remove" todos os elementos da sequência para os quais o predicado é verdadeiro. No entanto, repara que esta função não modifica a sequência original!
Em vez disso, devolve uma nova sequência sem os elementos em causa. Se o predicado for verdadeiro para todos os valores, é devolvida uma sequência vazia.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### Remover um item específico

Se quiseres remover um item específico de uma sequência, podes usar o `remove`, que recebe o item a remover e uma sequência.
São devolvidos todos os valores da sequência que não sejam iguais ao item a remover.
NOTA: por omissão, a igualdade é verificada com o `eql`, o [predicado genérico de igualdade][concept-equality].

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
