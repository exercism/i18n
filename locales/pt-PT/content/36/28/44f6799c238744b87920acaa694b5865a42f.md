# Dicas

## 1. Remover faixas duplicadas

- Podes ver um exemplo de como criar um set a partir de um array na [documentação da MDN][mdn-relation-to-arrays].
- Certifica-te de que convertes o teu set novamente num array antes de o devolveres.
- Volta a consultar o [conceito de desestruturação de arrays][concept-array-destructuring] para relembrares como usar o operador spread.

## 2. Verificar se uma faixa já foi adicionada

- Há um [método incorporado][mdn-set-has] para verificar se um elemento está num set.

## 3. Adicionar uma faixa

- Há um [método incorporado][mdn-set-add] para adicionar um elemento a um set.
- Certifica-te de que não estás a chamar `Set.has()` manualmente para verificar a presença do elemento antes de o adicionares; o `Set.add()` trata disso por ti!

## 4. Eliminar uma faixa

- Há um [método incorporado][mdn-set-delete] para remover um elemento de um set.
- Certifica-te de que não estás a chamar `Set.has()` manualmente para verificar a presença do elemento antes de o eliminares; o `Set.delete()` trata disso por ti!

## 5. Listar artistas únicos

- Há [algumas formas diferentes][mdn-set-iteration] de iterar sobre um set.
- Há um [método incorporado][mdn-string-split] para dividir uma string em substrings.
- Volta a consultar o [conceito de desestruturação de arrays][concept-array-destructuring] para relembrares como ignorar um elemento ao desestruturar um array.
