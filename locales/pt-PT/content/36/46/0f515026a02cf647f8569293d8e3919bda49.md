# Sobre

O ABAP tem vários tipos numéricos. Os mais comuns em pequenos exercícios introdutórios são `i` para valores inteiros e `p` para valores decimais empacotados.

Usa `i` quando um valor tem de ser um número inteiro, como uma contagem de dias. Usa um tipo decimal quando um valor pode conter casas decimais, como uma taxa horária.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

Os números empacotados são muito usados em aplicações empresariais quando é necessário um número fixo de casas decimais. O ABAP também tem números de vírgula flutuante decimais (`decfloat16` e `decfloat34`) e números de vírgula flutuante binários (`f`). Os números de vírgula flutuante binários podem ser úteis para cálculos científicos, mas não são uma boa escolha predefinida para exemplos com valores monetários, porque muitas frações decimais não podem ser representadas com exatidão.
