# Apêndice às instruções

## Formato da saída

Produz a sequência de ações como uma string terminada em null, usando uma vírgula e um espaço como separadores.

## Registos

| Registo | Utilização    | Tipo    | Descrição                         |
| -------- | ------------- | ------- | --------------------------------- |
| `$a0`    | entrada       | inteiro | número entre 1 e 31               |
| `$a1`    | entrada/saída | endereço | string de saída terminada em null |
| `$t0-9`  | temporária    | qualquer | usado para armazenamento temporário |
