# Testes

## Correr os testes

Para correr os testes, executa o seguinte comando:

```bash
call {slug}Test.bat
```

## Resolver o exercício

Resolver um exercício significa fazer com que todos os testes passem.
Quando todos os testes passarem, tens o exercício resolvido!

Para te ajudar a começar, cada exercício vem com um ficheiro de implementação stub.
Podes usar este ficheiro como ponto de partida para construir a tua solução.
Sente-te à vontade para remover ou alterar este ficheiro, se achares que é o que deves fazer.
