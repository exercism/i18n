# divisão de strings utilizada

Usa o tipo incorporado `rune` para trabalhar com carateres individuais em Go.
Uma `string` pode ser convertida num `[]rune` (uma fatia de runes) com:

```go
aRunes := []rune(a)
```

Dividir a string em muitas strings pequenas (uma para cada rune) funciona, mas é ineficiente.
