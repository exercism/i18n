# Introdução

Se os tipos dos parâmetros puderem ser inferidos, o Swift também permite que se omitam da definição do closure os nomes dos parâmetros e a palavra-chave `in`. Em vez disso, é possível referir os parâmetros através de uma sintaxe abreviada especial, em que `$0` se refere ao primeiro parâmetro, `$1` ao segundo, e assim sucessivamente.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
