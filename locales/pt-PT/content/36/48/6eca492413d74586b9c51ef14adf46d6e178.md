# Sobre

O tipo `Maybe` é a solução da linguagem Elm para valores opcionais.
Por isso, aparece nas assinaturas de tipo de muitas funções essenciais do Elm, e compreendê-lo é fundamental.

## Definição e variável de tipo

O tipo `Maybe` define-se da seguinte forma:

```elm
type Maybe a = Nothing | Just a
```

Na terminologia do Elm, isto é o que se chama uma definição de "tipo personalizado".
Os tipos personalizados são apresentados em detalhe noutro conceito deste percurso, mas não precisamos disso para compreender especificamente o `Maybe`.
O `a` em `Maybe a` e em `Just a` representa uma variável de tipo, ou seja, pode ser qualquer tipo, como `Int`, `Bool` ou `String`.
Assim, um `Maybe String` é uma variável que pode conter, ou não, uma `String`, enquanto um `Maybe Int` pode conter, ou não, um `Int`.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

A barra vertical `|` na definição do tipo `Maybe` significa "OU".
Indica que um valor deste tipo ou é `Nothing` ou é `Just` algo do tipo `a`.
Imagina agora que a pessoa não tinha preenchido o nome nem a idade; nesse caso, teríamos o seguinte.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Ler o conteúdo de um valor `Maybe`

A leitura do conteúdo de um valor `Maybe` faz-se através de "correspondência de padrões".
A correspondência de padrões também é apresentada em mais detalhe noutro conceito, por isso vamos concentrar-nos apenas em como funciona a correspondência de padrões num `Maybe`.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Sempre que usas um valor `Maybe`, o compilador do Elm verifica que o teu código trata todas as possibilidades, por isso nunca podes fazer correspondência de padrões sobre um `Maybe` tratando apenas o caso em que existe um `Just someValue`.
Ao início, isto pode parecer aborrecido, mas é uma das maiores forças da linguagem Elm.
Evita centenas de bugs e torna o refactoring guiado pelo compilador uma experiência sem medo e gratificante.

## Mais funções para manipular `Maybe`

Existem também várias funções úteis no módulo `Maybe` para manipular tipos `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
