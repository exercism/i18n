# Instruções

Neste exercício, vais implementar mecânicas de um jogo de interpretação de papéis.
A personagem de um jogador é representada pelo seguinte tipo:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

Os jogadores deste jogo têm de atingir o nível 10 antes de desbloquearem uma reserva de mana, para poderem começar a lançar feitiços.
Vais trabalhar em duas funcionalidades deste jogo: a mecânica de reviver e a mecânica de lançamento de feitiços.

## 1. Apresenta-te

Escreve o conteúdo da função `introduce`.
Repara que o campo `Name` do registo `Player` é um `Option`.
Jogadores furtivos podem querer esconder o nome deixando-o definido como `None`: esses jogadores serão apresentados como `"Mighty Magician"`.
Caso contrário, usa apenas o teu nome para te apresentares.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Implementa a mecânica de reviver

A função `revive` deve verificar se a personagem do jogador está mesmo morta (a sua saúde chegou a 0).
Se estiver, deve devolver uma nova instância de `Player` com 100 de saúde.
Caso contrário, se a personagem do jogador não estiver morta, a função `revive` devolve `None`.

Se o nível do jogador for 10 ou superior, também deve ser revivido com 100 de mana.
Se o nível do jogador for inferior a 10, a sua mana deve ser `None`.
A função `revive` deve manter o nível do jogador.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Se o método `revive` for chamado sobre um jogador cuja saúde é 1 ou superior, a função deve devolver `None`.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Implementa a mecânica de lançamento de feitiços

A função `castSpell` recebe como argumentos um `int` que indica quanta mana custa o feitiço, bem como um `Player`.
Devolve o jogador atualizado, bem como a quantidade de dano que o feitiço lançado provoca.
Um lançamento de feitiço bem-sucedido causa dano igual ao dobro do custo de mana do feitiço.
No entanto, se o jogador não tiver mana suficiente, não acontece nada: o jogador fica inalterado e não é causado qualquer dano.
Se o jogador não tiver sequer uma reserva de mana, tentar lançar o feitiço deve reduzir a sua saúde pelo custo de mana do feitiço e não causa dano.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
