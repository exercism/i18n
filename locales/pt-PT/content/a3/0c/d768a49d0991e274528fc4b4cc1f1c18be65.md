# utilização de naked returns

A comunidade Go recomenda evitar os *naked returns* (ou *bare returns*) em circunstâncias normais,
porque costumam tornar o código mais difícil de ler.
Vê o [guia oficial de revisão de código Go](https://github.com/golang/go/wiki/CodeReviewComments#naked-returns) para mais detalhes.
Há uma [proposta](https://github.com/golang/go/issues/21291) para remover os *bare returns* por completo no Go 2.
