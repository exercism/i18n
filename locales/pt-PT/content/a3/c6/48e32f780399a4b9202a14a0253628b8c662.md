# Instruções

Converte um número hexadecimal, representado como uma string (por exemplo, "10af8c"), no seu equivalente decimal, usando apenas os princípios básicos (ou seja, não, não podes usar bibliotecas incorporadas ou externas para fazer a conversão).

Na web, usamos hexadecimal para representar cores, por exemplo: verde: 008000, verde-azulado: 008080, azul-marinho: 000080).

O programa deve tratar strings hexadecimais inválidas.
