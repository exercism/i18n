# Introdução

## Strings

Em Elixir, as strings são delimitadas por aspas duplas e codificadas em UTF-8:

```elixir
"Hi!"
```

As strings podem ser concatenadas com o operador `<>/2`:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

As strings em Elixir suportam interpolação com a sintaxe `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Para colocar um caráter de nova linha numa string, usa o código de escape `\n`:

```elixir
"1\n2\n3\n"
```

Para trabalhar confortavelmente com textos com muitas novas linhas, usa antes a sintaxe heredoc com três aspas duplas:

```elixir
"""
1
2
3
"""
```

O Elixir disponibiliza muitas funções para trabalhar com strings no módulo `String`.

## Operador pipe

O operador `|>` chama-se operador pipe. Podes usá-lo para encadear chamadas de funções, de modo que o valor devolvido pela chamada anterior é passado como primeiro argumento à chamada seguinte.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
