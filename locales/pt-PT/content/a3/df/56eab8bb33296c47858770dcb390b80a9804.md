# Sobre

As [strings][getting-started-strings] em Elixir são delimitadas por aspas duplas e estão codificadas em UTF-8:

```elixir
"Hi!"
```

As strings podem ser concatenadas com o operador [`<>/2`][kernel-concat]:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

As strings em Elixir suportam [interpolação][string-interpolation] com a sintaxe `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Qualquer expressão de Elixir é válida dentro da interpolação. Se for dada uma string, esta é interpolada tal como está. Se for dado qualquer outro valor, o Elixir tenta convertê-lo numa string.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

O Elixir disponibiliza muitas funções para trabalhar com strings no módulo `String`. Se não tiveres a certeza de como processar uma string da forma que precisas, não deixes de explorar as [funções disponíveis no módulo `String`][string-module-functions] e é muito provável que encontres o que precisas.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

Ao usares algumas dessas funções, lembra-te de que o primeiro caráter numa string tem o índice `0`.

Alguns carateres precisam de ser [escapados][escape-characters] para serem colocados numa string, por exemplo, mudanças de linha, aspas duplas ou o caráter `#`:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

Para trabalhares confortavelmente com textos com muitas mudanças de linha, usa antes a [sintaxe heredoc de aspas duplas triplas][heredoc-syntax]:

```elixir
"""
1
2
3
"""
```

Vais encontrar muitas vezes esta sintaxe usada para documentar código:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
