# Funções

Em JavaScript, as funções são _objetos de primeira classe_, o que significa que podem ser atribuídas a variáveis e propriedades, passadas a outras funções e devolvidas por funções. Podem ter propriedades e métodos, tal como qualquer outro _objeto_.

## Entrada: passar argumentos

As funções em JavaScript permitem-te passar argumentos quando são chamadas. Os argumentos são sempre [passados por valor](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). Por outras palavras, se uma função reatribuir um parâmetro dentro da função, o valor não muda fora da função. Isso não significa que os objetos passados não possam ser mutados.

> [!TIP]
> Quando se passa um objeto, a referência a esse objeto é passada por valor. Isto faz com que _pareça_ que os objetos passados são tratados de forma diferente, mas não é o caso.

Um exemplo de uma função que recebe dois argumentos e os multiplica é:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Saída: valor devolvido

O JavaScript pode devolver um único valor de uma função usando a palavra-chave `return`, seguida de uma expressão. Quando uma função não devolve nada, o valor devolvido é `undefined`.

Um exemplo de uma função que devolve um valor é:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Definir funções

Existem quatro variantes de funções em JavaScript:

1. Funções normais, que podem devolver qualquer coisa e são sempre executadas até ao fim;
2. Funções assíncronas, que devolvem sempre uma `Promise` e podem ser pausadas e retomadas com o operador `await`;
3. Funções geradoras: que devolvem sempre um objeto `Generator` e podem ser pausadas e retomadas com o operador `yield`;
4. Funções geradoras assíncronas; que devolvem sempre um objeto `AsyncGenerator` e podem ser pausadas e retomadas com _ambos_ os operadores `yield` e `await`.

Para cada uma destas quatro variantes, há três formas de as definir:

1. com uma declaração
2. com uma expressão
3. com o construtor

Por fim, existe alguma sintaxe especial para definir _funções arrow e métodos_.
