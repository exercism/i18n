# Introdução

Um ciclo `for` permite iterar sobre um array e repetir o código para cada elemento:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

No exemplo acima, `fruit` é a variável que guarda o valor de um elemento individual do array `fruitList`. O compilador garante que é possível iterar sobre `fruitList`; caso contrário, interrompe a execução.

Também podes iterar sobre números com o operador de intervalo. Este operador recebe dois operandos do tipo `Int` e escreve-se `min...max`:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
