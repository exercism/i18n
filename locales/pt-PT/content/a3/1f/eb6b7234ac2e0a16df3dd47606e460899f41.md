# Representações

O [representador][representer] usa `read` para ler a submissão e `write` para escrever a representação, aplicando ainda algumas normalizações adicionais.
A cada submissão são aplicadas as seguintes normalizações:

- [Todos os comentários são removidos][remove-comments]
- [As strings de documentação são removidas][remove-doc-strings]
- [As maiúsculas e minúsculas do texto são normalizadas][normalize-case]
- [A formatação do texto é normalizada][normalize-formatting]
- [Os nomes dos símbolos são normalizados][normalize-names]
