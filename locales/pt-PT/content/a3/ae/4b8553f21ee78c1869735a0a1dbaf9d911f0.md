# Instruções adicionais

## Instruções específicas do track

Este exercício centra-se em adicionar métodos à estrutura `Int` em Swift.
A forma mais simples de o fazer é recorrer a [extensões][extensions].

```swift
extension Int {
  // 
}
```

Encontras a documentação de `Int` [aqui][int].

[int]: https://developer.apple.com/documentation/swift/int
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
