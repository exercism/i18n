# Introdução

A classe `TimeZoneInfo` fornece rotinas para lidar com as diferenças entre fusos horários. A classe `TimeZoneInfo` também contém métodos que facilitam o tratamento da hora de verão.

A classe `CultureInfo` suporta formatos de data e hora dependentes da região.

Para apoiar a programação multiplataforma, a classe `RuntimeInformation` permite detetar em que sistema operativo o teu código está a executar: Linux, Windows ou OSX.
