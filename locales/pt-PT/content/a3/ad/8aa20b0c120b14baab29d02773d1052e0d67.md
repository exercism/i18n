# Dicas

## Geral

- O Eli Bendersky escreveu [uma boa página][eli-lisp-equality] que explica as diferenças entre os predicados de igualdade genéricos em Common Lisp.
- O [Hyperspec][hyperspec] também é uma boa referência e tem páginas que definem cada um dos predicados: [`eq`][hyperspec-eq], [`eql`][hyperspec-eql], [`equal`][hyperspec-equal] e [`equalp`][hyperspec-equalp]
- Lembra-te de que os quatro predicados vão do mais restritivo ao mais permissivo, por esta ordem: `eq`, `eql`, `equal`, `equalp`.

## 1. O labirinto da igualdade de objetos

- Este labirinto precisa do predicado de igualdade mais restritivo que existir.
- [A página de referência do Hyperspec para `eq`][hyperspec-eq] pode ser útil.

## 2. O labirinto dos números

- As duas funções de que precisas para isto não vão usar necessariamente os mesmos predicados de igualdade. A primeira sala precisa de um mais restritivo do que a segunda.
- [A página de referência do Hyperspec para `eql`][hyperspec-eql] e para [`equalp`][hyperspec-equalp] pode ser útil.

## 3. O labirinto dos carateres

- As duas funções de que precisas para isto não vão usar necessariamente os mesmos predicados de igualdade. A primeira sala precisa de um mais restritivo do que a segunda.
- [A página de referência do Hyperspec para `eql`][hyperspec-eql] e para [`equalp`][hyperspec-equalp] pode voltar a ser útil.

## 4. O labirinto das strings

- As duas funções de que precisas para isto não vão usar necessariamente os mesmos predicados de igualdade. A primeira sala precisa de um mais restritivo do que a segunda.
- [A página de referência do Hyperspec para `equal`][hyperspec-equal] e para [`equalp`][hyperspec-equalp] pode ser útil.

## 5. O labirinto dos conses

- As chaves destas salas vão precisar de usar predicados de igualdade definidos para verificar o conteúdo dos conses.
- [`equal`][hyperspec-equal] é o primeiro dos predicados que verifica a igualdade dos itens _dentro_ de um cons.
- Como já aprendeste, [`equalp`][hyperspec-equalp] permite uma igualdade mais permissiva, incluindo a verificação de igualdade sem distinguir maiúsculas de minúsculas.

## 6. O labirinto dos arrays

- As chaves destas salas vão precisar de usar predicados de igualdade definidos para verificar o conteúdo dos arrays.
- [A página do Eli Bendersky sobre a igualdade em Common Lisp][eli-lisp-equality] é uma boa explicação.
- Para a primeira parte, é preciso escolher um predicado que não tenha em conta o conteúdo de um array. Tanto [`eq`][hyperspec-eq] como [`eql`][hyperspec-eql] podem ser úteis.
- [`equalp`][hyperspec-equalp] é o primeiro predicado que verifica a igualdade do conteúdo de um array.
