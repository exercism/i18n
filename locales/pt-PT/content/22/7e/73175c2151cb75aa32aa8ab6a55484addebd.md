# Instruções

Implementa a lógica do jogo da forca com programação funcional reativa.

O [jogo da forca][hangman] é um jogo simples de adivinhar palavras.

A [Programação Funcional Reativa][frp] é uma forma de escrever programas interativos.
Difere da perspetiva habitual porque, em vez de dizeres «quando o botão é premido, incrementa o contador», escreves «o valor do contador é a soma do número de vezes que o botão é premido».

Implementa a lógica básica do jogo da forca com programação funcional reativa.
Para isso, vais ter de instalar uma biblioteca de FRP; isso será descrito nos ficheiros específicos da linguagem e do track do exercício.

[hangman]: https://en.wikipedia.org/wiki/Hangman_%28game%29
[frp]: https://en.wikipedia.org/wiki/Functional_reactive_programming
