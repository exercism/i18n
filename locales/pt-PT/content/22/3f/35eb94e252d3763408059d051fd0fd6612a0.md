# Sobre
Os tipos de números incorporados em C++ podem dividir-se em inteiros e em números de vírgula flutuante.
Os inteiros são números sem parte fracionária, como `0`, `691` ou `-2`.
Os números de vírgula flutuante são números com parte fracionária, como `6.02214076`, `0.1` ou `-1.616`.

## Inteiros
O exemplo seguinte mostra a declaração e a inicialização de quatro variáveis diferentes

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Quando atribuis um valor a uma variável `int`, podes fazê-lo diretamente com um literal.
Um literal é um número fixo escrito no código, como `9241`.
Existem literais inteiros diferentes para várias bases de representação.
Os literais inteiros decimais são os mais comuns e usam os algarismos `0` a `9`.
Ao acrescentar um prefixo especial, como `0x`, é possível usar outras bases.
O exemplo acima mostra o número `9421` nas suas quatro representações e prefixos.
Todas as variáveis são inicializadas com o mesmo valor.

Para mais detalhes sobre os diferentes sistemas de representação, dá uma vista de olhos a [um pequeno tutorial][cpp_numerical_bases].

Podes usar um apóstrofo para separar algarismos e facilitar a leitura.
`9'241` é o mesmo que `0b0100'100'0001'1001` ou `92'4'1`.

## Números de vírgula flutuante

Os literais de vírgula flutuante existem em duas variantes.
Além do intuitivo `0.0024`, é possível usar a sua notação científica `2.4e-3`.
O tipo de vírgula flutuante mais comum é `double`.

## Aritmética

C++ suporta `+`, `-`, `*`, `/`, `(` e `)` e `%` para formar expressões.
O resultado da operação entre dois inteiros também é um inteiro.
`5 / 2` devolve `2`.
Quando um dos tipos envolvidos é um tipo de vírgula flutuante, o resultado também é de vírgula flutuante.
`5.0 / 2` e `5 / 2.0` devolvem `2.5`.
`%` é o operador de resto e devolve o resto de uma divisão inteira: `5%3` é `2`.

## Operador de atribuição

O operador de atribuição atribui um literal a uma variável.
Acontece sempre da direita para a esquerda e nunca ao contrário.

```cpp
int length = 5;
int width = 2;
length = width;
```

Aqui, o valor inteiro `5` é atribuído à variável `length`.
Depois, o valor inteiro `2` é atribuído à variável `width`.
Por fim, o valor de `width` é copiado para a variável `length` e o valor anterior `5` perde-se.
Repara também que só estás a atribuir o valor de `width` a `length` no momento da operação de atribuição.
Por isso, se o valor de `width` mudar mais tarde, isso não afeta o valor que `length` tem.

O operador de atribuição pode combinar-se com os outros operadores (aritméticos e bit a bit), dando origem aos operadores de `compound assignment` `+=`, `-=`, `*=`, `/=`, `%=`.
Estes operadores modificam o valor atual de uma variável realizando uma operação sobre ele.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

As variáveis `people` e `eggs` são inicializadas a `0`.
Depois, adicionamos o valor inteiro `2` ao valor existente `0` da variável `people` e atribuímos o resultado de volta a `people`.
`people` passa a valer `2`.
Mais tarde, adicionamos `3` ovos por cada pessoa, o que dá `6` ovos no total.
Agora adicionamos este `6` ao valor existente `0` da variável `eggs` e atribuímos o resultado de volta a `eggs`.
`eggs` passa a valer `6`.
A expressão equivalente seria `people = people + 2` e `eggs = eggs + (3 * people)`.

## Conversão de tipos

A conversão de tipos consiste em passar de um tipo para outro.
Se for preciso um `double`, pode usar-se um `int` no seu lugar.
O exemplo `5.0 / 2` acima é tratado por uma conversão implícita de `2` em `2.0`.
Um `double` convertido para `int` pode perder informação.
É boa prática tornar explícitas estas conversões para outro tipo T através de `static_cast<T>`.
A antiga conversão ao estilo C com `(T)` é desencorajada no C++ moderno, mas ainda assim convém conhecê-la.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## Precisão e representação

Os números em C++ não podem ser arbitrariamente grandes.
O `int`, por exemplo, é representado por 32 bits.
Isso chega para um conjunto de `2^32` números, cerca de 4 mil milhões.
Incluindo o `0`, isto faz com que os maiores e menores números `int` sejam `-2^31` e `2^31 - 1`.

Os números de vírgula flutuante são geralmente implementados com 15 casas decimais de precisão, mas a representação varia consoante o sistema anfitrião.
