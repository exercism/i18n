# Dicas

## Geral

- Todos os endereços de memória neste exercício estão alinhados a 16 bytes, por isso as variantes de movimentação alinhadas (`movaps` para números de vírgula flutuante, `movdqa` para inteiros) são as adequadas. A memória alinhada também pode ser usada diretamente como operando de origem (mas não como destino).
- As máscaras podem ser definidas na memória.

## 1. Retificar o traço

- O sinal de um número de vírgula flutuante de 32 bits é o seu bit mais alto. Limpar o bit mais elevado torna o número não negativo.
- É possível limpar o bit mais elevado fazendo um AND com um número de 32 bits em que todos os bits estão a 1 exceto o mais elevado.
- Uma máscara pode ser definida na memória com 4 números de 32 bits empacotados.
- A instrução `andps` aplica um AND a valores de vírgula flutuante.

## 2. Ler a escala de um tremor

- O campo do expoente num número de vírgula flutuante IEEE-754 de 32 bits está nos bits nas posições 23 a 30, inclusive.
- Os bits do expoente podem ser isolados fazendo um AND (`andps` ou `pand`) dos números de vírgula flutuante com uma máscara em que só os bits 23 a 30 estão a 1.
- Depois de os bits do expoente estarem isolados, podem ser deslizados para o fundo de cada via com um deslocamento lógico para a direita (`psrld`).
- O enviesamento para um número de vírgula flutuante IEEE-754 de 32 bits é 127. Pode ser removido subtraindo 127 a cada via (`psubd`).

## 3. Tornar a resolução mais grosseira

- Um deslocamento aritmético para a direita (`psrad`) de `n` posições divide por `2^n`, preservando o sinal e arredondando para menos infinito.
- As instruções de deslocamento empacotadas recebem a contagem de um imediato ou de um registo `xmm`, não de um registo de uso geral (GPR).
- A instrução `movq` pode ser usada para mover 64 bits em bruto de um GPR para um registo `xmm`.

## 4. Combinar os canais

- `por` pode ser usado para combinar todos os bits que estão a 1 em qualquer das campanhas.
- `pandn` calcula ((NOT destino) AND origem) numa única instrução. Pode ser usado para limpar todos os bits da origem que estão a 1 no destino.

## 5. Alternar os bits de calibração

- Para inverter apenas os bits desbloqueados, é preciso primeiro pôr a zero todos os bits bloqueados no valor de alternância.
- `pandn` calcula ((NOT destino) AND origem) numa única instrução. Pode ser usado para limpar todos os bits da origem que estão a 1 no destino.
- `pxor` pode ser usado para inverter os bits selecionados pelo resto do valor de alternância em cada palavra de estado.

## 6. Amplificar o traço

- O campo do expoente num número de vírgula flutuante IEEE-754 de 32 bits está nos bits nas posições 23 a 30, inclusive. Para mover o ganho `k` para a posição certa, é preciso deslocá-lo para a esquerda.
- Somar os ganhos deslocados aos bits em bruto das leituras (`paddd`) tem o efeito de multiplicar a leitura por `2^k`. O padrão de bits mantém-se válido porque os valores de entrada e os resultados são garantidamente normais.
