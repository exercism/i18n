# Fictício

## Instruções específicas do MoonScript

Este é um exercício orientado a objetos: vais implementar ComplexNumbers como uma classe.

Os testes vão comparar duas instâncias de números complexos para verificar se são iguais.
Isto significa que a tua classe vai ter de implementar o [metamétodo][metamethods] `__eq`.

Os testes também efetuam operações aritméticas com números complexos, por isso há metamétodos aritméticos a implementar.

~~~~exercism/caution
Algumas das funções de números complexos vão fazer cálculos com números de vírgula flutuante.
A tua «igualdade» vai ter de lidar com números que são _aproximadamente iguais_.
~~~~

[metamethods]: https://www.lua.org/manual/5.4/manual.html#2.4
