# Introdução

Um `vector` em Clojure é uma coleção sequencial, indexada e imutável de zero ou mais valores. Isto significa que, uma vez criado um `vector`, este não pode ser modificado. As funções que operam sobre um `vector` devolvem um novo `vector`, enquanto o `vector` original permanece inalterado. Os valores de um `vector` podem ser de tipos heterogéneos. Um `vector` pode ser definido da seguinte forma:

```clojure
(def empty [])
(def single-value [5])
```

Os elementos podem ser obtidos de um `vector` através de um índice. Os vectors de Clojure são indexados a partir do zero. Isto significa que o índice do primeiro elemento é sempre zero:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

O `vector` original permanece inalterado:

```clojure
numbers
;;=> [2 3 5]
```

Para guardar o valor atualizado, temos de o passar adiante ou capturá-lo numa var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
