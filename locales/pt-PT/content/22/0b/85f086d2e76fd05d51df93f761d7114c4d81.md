# evitar ciclos imperativos

Evita usar ciclos for neste exercício.

De acordo com a introdução, o objeto Array do JavaScript tem métodos incorporados orientados para a análise de dados.

Dá uma vista de olhos à introdução e/ou à [documentação da MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array#instance_methods) para veres que métodos tens disponíveis.
