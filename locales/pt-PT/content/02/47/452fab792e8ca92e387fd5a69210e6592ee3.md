# Introdução

Os arrays e as listas contêm uma coleção ordenada de escalares.
Fora do uso de referências (que serão abordadas num conceito separado), isto significa que os arrays e as listas são sempre planos, ou seja, não podem conter outros arrays nem outras listas.

Na maioria dos casos, as listas são delimitadas por parênteses `()` e os seus elementos são separados por vírgulas `,`.

Normalmente, uma variável do tipo array é preenchida atribuindo-lhe uma lista, por exemplo: `my @names = ('Alice', 'Bob', 'Charlie');`.

Podes aceder aos elementos de um array ou de uma lista indicando os índices através de um subscrito, por exemplo: `('Alice', 'Bob', 'Charlie')[1] # 'Bob'`.

Em Perl, os índices começam em `0`.
Os índices negativos contam a partir do fim do array ou da lista, por exemplo: `('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`.

## Funções

Há muitas funções implementadas para operar sobre arrays e listas; entre as mais úteis estão [grep][grep], para obter uma nova lista de elementos filtrados que cumprem uma condição, [map][map], para transformar elementos numa nova lista de valores, e [sort][sort], para obter uma nova lista de elementos reordenados.

As funções para manipular arrays incluem [push][push], para acrescentar elementos ao fim, [pop][pop], para remover o último elemento, [shift][shift], para remover o primeiro elemento, [unshift][unshift], para acrescentar elementos ao início, e [splice][splice], para modificações mais complexas.

Também vais encontrar com frequência a iteração sobre arrays e listas com uma instrução [for(each)][perlsynforeach].

## Variação dos sigils

Quando acedes aos elementos de um array, o sigil usado determina o resultado.
É o subscrito `[]` no fim do nome da variável que indica ao Perl que estás a aceder a um array com esse nome.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

Embora seja permitido, recomenda-se que não uses o mesmo nome para variáveis de tipos diferentes, por uma questão de legibilidade.

## Arrays vs. listas

Os arrays e as listas têm muitas semelhanças e, em muitos contextos, podem ser usados de forma intermutável, mas não são a mesma coisa.
Uma lista é uma coleção fixa e imutável de escalares.
Um array é uma coleção variável de escalares, em que o conteúdo e o tamanho do próprio array podem ser alterados.

Comportam-se de forma diferente em alguns contextos.
Um array usado em contexto escalar dá-te o tamanho do array.
Uma lista usada em contexto escalar dá-te o último elemento da lista e, possivelmente, alguns avisos sobre o resto do seu conteúdo estar a ser usado em contexto vazio.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
