# Tarifas de Freelancer

## História

Neste exercício vais escrever código para ajudar um freelancer a comunicar com um
gestor de projeto, fornecendo alguns utilitários para calcular rapidamente as
tarifas diárias e mensais, opcionalmente com um determinado desconto.

Começamos por estabelecer algumas regras entre o freelancer e o gestor de projeto:

- A tarifa diária é 8 vezes a tarifa horária;
- Um mês tem 22 dias faturáveis.

O freelancer propõe aplicar um desconto se o gestor de projeto optar por deixar o
freelancer faturar por mês, o que pode ser útil se houver um determinado orçamento
com que o gestor de projeto tenha de trabalhar.

Os descontos são modelados como números fracionários seguidos de um `%` (percentagem)
entre `0.0%` (sem desconto) e `90.0%` (desconto máximo).

## Tarefas

Estas são tarefas de exemplo que se enquadram na história do freelancer a comunicar com um gestor de projeto:

- Calcular a tarifa diária a partir de uma tarifa horária
- Calcular a tarifa mensal, a partir de uma tarifa horária e de um desconto
- Calcular o número de dias de trabalho a partir de um orçamento, de uma tarifa e de um desconto

## Terminologia

Estas são recomendações, não regras, para a terminologia recorrente nas instruções (incluindo os comentários do stub)

- A tarifa diária é 8 vezes a tarifa horária; deve ser mencionado
- A tarifa mensal é 22 vezes a tarifa diária; deve ser mencionado
- Se o desconto for fornecido como um tipo _diferente_ dos tipos numéricos, usa a terminologia **os descontos são modelados como**
