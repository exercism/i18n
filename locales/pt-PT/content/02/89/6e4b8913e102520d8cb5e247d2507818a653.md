# Dicas

## 1. Cria um vetor com todas as carruagens

- Um ciclo for/while clássico com `push!` para um `Vector` funciona.
- Caso contrário, a função [`collect()`][collect] pode ser mais concisa.
- Em alternativa, o splatting funciona dentro de um construtor de vetores:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. Corrige o vetor de carruagens

- É útil separar as carruagens da frente e a locomotiva de tudo o resto, para que possam ser reorganizadas na ordem correta.
- A atribuição múltipla com splatting pode ajudar-te (vê a introdução).

## 3. Adiciona as paragens em falta

- Lembra-te: esta função não modifica o parâmetro de entrada! Cria um novo `Dict`.
- Só é preciso o nome da paragem, não o número, por isso cada par tem de ser separado.
- Há várias formas de montar o vetor de nomes:
  -  Ciclo for/while com `push!()` para um `Vector`.
  -  Array [compreensão][comprehensions]
  -  [`map()`][map] de uma função sobre o vetor.
  -  [Broadcasting][broadcasting] de uma função [anónima][anonymous] é possível:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. Estende a informação de percurso

- Depois do slurping, `more_route_information` é uma coleção `Pairs()`.
- A função [`merge()`][merge] combina dois ou mais `Dict`, mas também aceita uma coleção `Pairs()`.
  A conversão explícita da coleção `Pairs()` para um `Dict` é possível, mas desnecessária.
