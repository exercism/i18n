# Introdução

O Gleam tem funções de primeira classe, ou seja, as funções são valores normais que podem ser atribuídos a variáveis, passados como argumentos e devolvidos por outras funções.

Uma função com nome definida num módulo pode ser referenciada pelo seu nome.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

O Gleam também tem funções anónimas, que são definidas dentro de outras funções.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

O tipo de uma função escreve-se com uma sintaxe semelhante à das funções anónimas. O tipo de uma função que recebe um `Int` e um `Float` e devolve um `Int` escreve-se assim:

```gleam
fn(Int, Float) -> Int
```

As funções anónimas podem referenciar variáveis que estavam no âmbito quando foram definidas, o que as torna _closures_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

A sintaxe de _function capture_ é uma forma abreviada e prática de criar funções anónimas que passam um único argumento a uma função. Estas duas expressões são equivalentes:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
