# Introdução

Com um ciclo while podes executar código repetidamente desde que uma determinada condição se verifique.
Escreve-se com a palavra-chave `while` seguida de uma condição entre parênteses curvos e de um bloco de código que contém o _corpo_ do ciclo entre chavetas.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

O JavaScript também tem o ciclo do-while.
Aqui, a condição é verificada depois de o corpo do ciclo ser executado.
Isto é útil quando a condição depende do resultado do código no corpo.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Dentro do corpo de um ciclo podes usar a palavra-chave `break` para parar completamente a execução do ciclo.
Em contrapartida, a palavra-chave `continue` apenas interrompe a execução da iteração atual e continua com a seguinte.
Com `continue` podes muitas vezes evitar envolver grandes partes do corpo do ciclo numa condicional.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
