# Sobre

O [Python][python docs] é uma linguagem de programação [dinâmica e fortemente][dynamic typing in python] tipada e [orientada a objetos][object oriented programming].
Usa tanto [duck typing][duck typing] como [tipagem gradual][gradual typing] (através de [type hints][type hints]).
Suporta vários paradigmas de programação, incluindo os estilos imperativo (_orientado a objetos, procedural_) e declarativo (_funcional, concorrente_).
Mas não te deixes enganar: embora programar através de vários paradigmas seja totalmente suportado, [em Python tudo é um objeto][everythings an object].


O Python foi criado por Guido van Rossum e lançado pela primeira vez em 1991.
A [Python Software Foundation][psf] gere e orienta recursos para o desenvolvimento do Python e do CPython e recebe propostas de alterações à linguagem de [membros][psf membership] da comunidade através de [Python Enhancement Proposals (PEPs)][peps].
É considerada uma linguagem sólida para programadores [que estão a dar os primeiros passos][python for beginners], com uma comunidade acolhedora e muitos recursos disponíveis para quem está a aprender, de todos os níveis e interesses.


O Python dá uma forte ênfase à legibilidade do código e (_à semelhança do Haskell_) usa [indentação significativa][significant indentation] para denotar definições de funções, métodos e classes.
O código pode ser escrito e executado a partir da linha de comandos, numa sessão interativa do intérprete, no [JupyterLab][jupyter] (Jupyter Notebooks) ou numa grande variedade de [editores de código e IDEs][editors for python].

[O Python é amplamente utilizado][python is used extensively] em computação científica, finanças, jogos, redes, desenvolvimento para a internet e na montagem de pipelines de outros programas.


O [zen de Python (PEP 20)][the zen of python] e [What is Pythonic?][what is pythonic] apresentam filosofias e perspetivas adicionais sobre a linguagem.


Os testes e as ferramentas deste percurso suportam atualmente `Python 3.10 - 3.13.7` (_testes_) e [`Python 3.13.7`][313-new-features] (_ferramentas_).
Recomenda-se vivamente que os estudantes atualizem para pelo menos `Python 3.10`, uma vez que algumas funcionalidades usadas neste percurso podem não ser suportadas em versões anteriores.
Dito isto, a maioria dos exercícios funcionará com `Python 3.6+`, ou até versões anteriores.
Mas não garantimos suporte para versões que não estejam listadas em [Versões Ativas do Python][active-python-releases].
Tentaremos indicar quando uma funcionalidade só está disponível numa determinada versão.


A documentação completa da versão do Python em uso neste percurso (`3.13.x`) pode ser encontrada em [docs.python.org][python docs].
