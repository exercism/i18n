# Manipulação de bits

O Crystal tem operadores bit a bit para manipular [`Int`][ints] ao nível dos bits.

## Operadores de deslocamento

O Crystal tem [operadores de deslocamento][shift] para deslocar bits para a esquerda (`<<`) ou para a direita (`>>`).

### Deslocamento à esquerda (`<<`)

O operador de deslocamento à esquerda (`<<`) desloca os bits para a esquerda.
O valor a deslocar indica-se do lado esquerdo e o número de posições a deslocar do lado direito.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Se o número for negativo, desloca para a direita.

```crystal
0b0010 << -1
# => 0b0001
```

### Deslocamento à direita (`>>`)

O operador de deslocamento à direita (`>>`) desloca os bits para a direita.
Tal como o operador de deslocamento à esquerda, o valor a deslocar indica-se à esquerda e o número de posições a deslocar à direita.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

E, da mesma forma, o operador desloca para a esquerda se o número for negativo.

```crystal
0b0100 >> -1
# => 0b1000
```

## Operadores binários

O Crystal tem 3 [operadores binários][binary] (`&`, `|`, `^`) e um operador `~` para efetuar operações bit a bit.

### AND bit a bit (`&`)

O operador binário AND (`&`) efetua um AND bit a bit sobre dois valores.
Compara cada bit do primeiro valor com o bit na mesma posição do segundo valor.
O bit resultante é 1 se ambos os bits forem 1.
Caso contrário, é 0.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### OR bit a bit (`|`)

O operador binário OR (`|`) efetua um OR bit a bit sobre dois valores.
Compara também cada bit do primeiro valor com o bit na mesma posição do segundo valor.
Se um dos bits for 1, o bit resultante é 1.
Caso contrário, é 0.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### XOR bit a bit (`^`)

O operador binário XOR (`^`) efetua um XOR bit a bit.
Tal como os operadores AND bit a bit e OR bit a bit, compara cada bit do primeiro valor com o bit na mesma posição do segundo valor.
Se _apenas um_ deles for 1, o bit resultante é 1.
Caso contrário, é 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### NOT bit a bit (`~`)

Por último, o operador NOT bit a bit (`~`) inverte cada um dos bits do valor.
Ao contrário dos outros operadores binários, este é um operador unário, que atua apenas sobre o valor à direita.

```crystal
~0b1110_0010
# => 0b0001_1101
```
