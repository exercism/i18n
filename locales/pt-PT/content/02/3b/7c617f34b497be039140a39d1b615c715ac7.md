# Sobre

O [TypeScript](https://www.typescriptlang.org/) (TS) é um superconjunto do JavaScript (JS), criado na Microsoft em resposta à frustração de desenvolver aplicações de grande escala em JS. Num projeto JS grande, saber que propriedades têm os teus próprios objetos e que argumentos recebem as tuas funções (e de que tipo precisam de ser) pode tornar-se difícil. Da mesma forma, como não é possível inspecionar o código JS de forma inteligente, quando incluis um pacote (por exemplo, do `npm`), tens de manter a documentação atualizada para saberes que métodos existem e que argumentos recebem. O TS resolve estes problemas. É atualmente um projeto de código aberto alojado no GitHub. Suporta ferramentas para qualquer navegador, assim como para o Node, para qualquer host, em qualquer sistema operativo. O TS compila para JavaScript legível e baseado em normas.

O TS acrescenta ao JS um sistema de tipos flexível, a par de interfaces (tipos personalizados) e da alteração da sintaxe de algumas funcionalidades do ECMAScript, como as classes. Os tipos são opcionais e flexíveis (por exemplo, podes especificar que um argumento é uma string ou um número). Os tipos permitem que as ferramentas disponíveis na maioria dos editores de código melhorem a experiência de desenvolvimento, com funcionalidades como o preenchimento automático de código e a deteção de métodos, tanto no teu próprio código como nos pacotes que usas. Suporta muitas funcionalidades futuras do ECMAScript (como async/await). Podes escrever TS em estilos orientados a objetos ou funcionais. É compatível com todos os pacotes JS existentes. O TS transpila para JS limpo e legível.

Experimenta no [playground](https://www.typescriptlang.org/play), e mantém-te a par através do [blog do TypeScript](https://devblogs.microsoft.com/typescript/) e da [conta de Twitter](https://twitter.com/typescript).
