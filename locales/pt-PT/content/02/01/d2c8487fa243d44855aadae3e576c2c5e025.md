# Instruções

Em **Chrono Realms**, os Time Keepers lidam muitas vezes não só com árvores de linhas temporais, mas também com **Chrono Chains**: sequências de **TimeNodes** ligados entre si, cada um a representar um momento específico no tempo.
Uma **Chrono Chain** é um caminho reto de momentos sequenciais, em que cada **TimeNode** se liga ao seguinte.
Estas **Chrono Chains** são úteis quando se viaja por uma série de eventos específicos, pois permitem aos Time Keepers seguir uma única linha temporal.

No entanto, para lidar com estas **Chrono Chains** potencialmente longas, os Time Keepers usam **apontadores inteligentes (Box<T>)** para gerir e percorrer com segurança estas listas de momentos, sem causar duplicação desnecessária de memória nem transbordo.
Cada **TimeNode** guarda uma referência ao nó seguinte, formando uma estrutura recursiva.

A tua tarefa, como aprendiz, é implementar uma **Chrono Chain** como uma estrutura de lista recursiva com apontadores inteligentes.

Neste exercício, vais:

1. Criar um enumerado recursivo `ChronoChain`, que representa uma lista de momentos.
2. Usar o apontador inteligente `Box<T>` para guardar os nós recursivos.
3. Implementar uma função que cria uma `ChronoChain` a partir de um array de valores `u32`.
4. Implementar uma função que percorre a `ChronoChain` e soma os valores guardados na lista.

## 1. Define o enumerado recursivo `ChronoChain`

Cria um enumerado recursivo `ChronoChain` com duas variantes:

- `End`: representa o fim da lista.
- `Link`: contém um valor `u32` e uma referência ao nó seguinte da cadeia, guardada numa `Box`.

## 2. Cria uma função para construir uma ChronoChain

Escreve uma função `ChronoChain::build` que recebe um array de valores `u32` e devolve uma `ChronoChain`, ligando os valores em sequência com apontadores inteligentes.

## 3. Implementa a função de soma

Escreve uma função `ChronoChain::sum` que percorre a `ChronoChain` recursivamente e soma os valores de todos os nós.

## Exemplo de utilização

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
