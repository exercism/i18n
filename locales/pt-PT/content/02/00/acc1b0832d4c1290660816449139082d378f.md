# Introdução

Em Elixir, um tuplo é uma estrutura de dados que organiza dados, guardando um número fixo de itens de qualquer tipo, mas sem nomes explícitos para cada elemento. Os tuplos são frequentemente usados em Elixir para operações intensivas de leitura de memória, uma vez que o acesso de leitura a um elemento é uma operação de tempo constante. Normalmente não são usados quando é preciso adicionar ou remover elementos dinamicamente, porque, em vez de modificar o tuplo existente, é criado um novo tuplo, o que exige que a memória seja alocada de antemão.

Na prática, os tuplos são criados em Elixir com chavetas. Os elementos de um tuplo podem ser acedidos individualmente com a função `elem/2`, usando indexação a partir do zero:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## Tuplos como informação agrupada

Na prática, os tuplos são frequentemente usados para representar informação agrupada.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
