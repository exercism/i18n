# Lotes de Pagamentos na Base de Dados

## Enunciado do Problema

Tens de inserir um lote de dados de pagamento na tabela `Payment`. A tua tarefa é ler os dados de pagamento a partir do ficheiro JSON de entrada fornecido e usar a operação `batchExecute` do cliente JDBC para inserir os dados de pagamento na tabela `Payment`. O ficheiro de entrada de exemplo é o `payments.json`.

O conteúdo do ficheiro JSON de entrada baseia-se no seguinte esquema JSON.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

Tens de devolver os IDs de pagamento gerados automaticamente para os dados de pagamento inseridos no lote, como saída, sem fazeres outra consulta à base de dados.

Podes assumir que os `employee_id` indicados no ficheiro `payments.json` são válidos e já existem na tabela `Employee`.

## Detalhes da Base de Dados

Usa a base de dados H2 fornecida para este problema.

> O ficheiro da base de dados de exemplo é `gofigure.mv.db` e o nome da base de dados é `gofigure`. Encontra-se dentro da pasta `db`.

As tabelas seguintes já existem na base de dados H2 de exemplo, com alguns dados de exemplo. Os nomes das colunas e os tipos de dados estão abaixo.

**Nome da tabela**: `Employee`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | inteiro, chave primária de incremento automático       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | inteiro        |

**Nome da tabela**: `Payment`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | inteiro, chave primária de incremento automático       |
| `date`            | data        |
| `amount`          | decimal        |
| `employee_id`     | inteiro        |
| `reason`          | string        |

* O ficheiro da base de dados é `gofigure.mv.db`. Usa o URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nome de utilizador: `root`
* Palavra-passe: `root`

## Restrições

* Usa o ficheiro da base de dados H2 fornecido na pasta `db` para validar as consultas e o exemplo em Ballerina
* Usa a abordagem dos parâmetros de dependência do Maven para adicionar o controlador da base de dados H2 como dependência de plataforma no teu Ballerina.toml
* Tens de encontrar os IDs de pagamento gerados automaticamente sem fazeres outra consulta à base de dados.

## Ambiente de Testes

* Podes executar os testes com `bal test`, e estes vão ser executados contra a base de dados de exemplo fornecida.

## Exemplos

### Exemplo 1

**Parâmetros de entrada:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

Dados de exemplo do ficheiro `payments.json`:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**Saída:** `[1,2,3]`

## Dicas

* Usa o módulo [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) para trabalhar com a base de dados
* Consulta a secção [Pré-requisitos](https://lib.ballerina.io/ballerinax/java.jdbc/latest) para saberes os passos necessários para adicionar o controlador JDBC como dependência
* Usa [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) para ler o ficheiro JSON de entrada
* Converte os valores JSON em tipos específicos da aplicação para trabalhares com os dados de forma segura em termos de tipos. Consulta o exemplo [Conversão para um tipo definido pelo utilizador](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)
* Usa [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) e o método remoto [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) para trabalhar com a base de dados
* Consulta o exemplo [execução em lote](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)
