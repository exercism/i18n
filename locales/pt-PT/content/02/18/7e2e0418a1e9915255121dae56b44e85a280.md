# Dicas

## Geral

- Lê a documentação de [MapSet][mapset]
- A documentação de [Enum][enum] também pode ser útil

## 1. Inicia uma coleção

- [Esta é a função `MapSet` mais adequada][new] para resolver a tarefa

## 2. Aumenta a coleção

- Usa [esta função `MapSet`][put] para adicionar cartas à tua coleção
- Usa [aquela função `MapSet`][member] para verificar se tens uma carta específica na tua coleção

## 3. Começa a trocar

- Para verificar se podes trocar uma carta, usa [esta função `MapSet`][member]
- Para atualizar a tua coleção, usa [esta função `MapSet`][delete] e [aquela][put]

## 4. Só pode haver um de cada

- Um `MapSet` tem a propriedade de só conter valores únicos
- Usa [esta função `MapSet`][new] para criar um conjunto e [aquela][to_list] para o transformar novamente numa lista
- Os `MapSet`s não têm noção de ordem, deves usar [esta função `Enum`][sort] para ordenar as cartas, mesmo que os testes passem sem isso

## 5. Cartas que eles não têm

- Usa [esta função `MapSet`][difference] para verificar diferenças entre coleções
- Usa [aquela função `MapSet`][size] para obter o número de cartas numa coleção

## 6. Cartas que todos têm

- [Esta função `Enum`][reduce] será útil para percorrer todas as coleções
- Usa pattern matching na lista para distinguir listas vazias de listas não vazias
- [Esta função `MapSet`][intersection] vai ajudar-te a manter as cartas comuns
- [Esta função `MapSet`][to_list] pode criar uma lista
- Os `MapSet`s não têm noção de ordem, deves usar [esta função `Enum`][sort] para ordenar as cartas, mesmo que os testes passem sem isso

## 7. Todas as cartas

- [Esta função `Enum`][reduce] será útil para percorrer todas as coleções
- Usa [esta função `MapSet`][new_empty] como acumulador
- [Esta função `MapSet`][union] vai ajudar-te a acumular todas as cartas
- [Esta função `MapSet`][size] vai contar quantas cartas tens

## 8. Brilhante para ganhar

- Usa [esta função `MapSet`][split_with] para separar a tua coleção
- Usa [esta função `String`][starts_with] para detetar cartas brilhantes
- [Esta função `MapSet`][to_list] pode criar uma lista
- Os `MapSet`s não têm noção de ordem, deves usar [esta função `Enum`][sort] para ordenar as cartas, mesmo que os testes passem sem isso
