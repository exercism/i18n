# Dicas

## Geral

- Podes aceder aos components individuais de um tuplo acrescentando um _.n_ ao nome do tuplo, em que _n_ é o índice do component, a começar em 0.

## 1. Obter o nome do brinquedo

- Podes aceder ao nome do brinquedo com a sintaxe `.n`.

## 2. Adicionar um brinquedo novo à base de dados

- Podes criar um tuplo novo com a sintaxe de tuplo `(name1: value1, name2: value2, ...)`.

## 3. Atualizar a quantidade de um brinquedo

- Podes usar um [ciclo for][for-loop] para iterar sobre o array de tuplos e atualizar a quantidade do brinquedo.
- Podes usar funções implementadas anteriormente para obter o nome do brinquedo.
- Podes usar uma [condicional][conditional-statement] para verificar se o nome do brinquedo corresponde ao que queres atualizar.
- Podes usar a sintaxe `.n` para atualizar a quantidade do brinquedo, por exemplo: `toys.price = 3`.

## 4. Adicionar a chave de categoria a um brinquedo

- Podes usar um [ciclo for][for-loop] para iterar sobre o array de tuplos e adicionar a chave de categoria ao brinquedo.
- Um tuplo é imutável, por isso tens de criar um tuplo novo com a chave de categoria adicionada.
  
[for-loop]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
[conditional-statement]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Conditional-Statements
