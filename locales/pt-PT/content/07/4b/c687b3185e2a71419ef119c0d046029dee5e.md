# Apêndice

## "Null" em Tcl

O Tcl não tem um valor `null` nem `nil`.
Na prática, usa-se muitas vezes a string vazia para indicar "sem valor".
Mas isso pode tornar-se complicado quando a string vazia é, na verdade, um valor válido, por exemplo numa lista que representa uma linha de dados CSV.

Neste exercício, trata a string vazia como um valor nulo que deve ser descartado.
