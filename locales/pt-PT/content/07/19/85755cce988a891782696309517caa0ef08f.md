# Dicas

## Geral

- Não há `new` numa classe imutável. O `create` começa com uma variável da
  classe, que já existe:

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)` não altera `b`. Devolve um novo rumo, e é por isso que é o
  valor devolvido.

## 1. Obter um rumo

- O `%` coloca um número dentro do intervalo, mas `-10 % 360` é `350` apenas
  porque o `%` do Sather nunca devolve um valor negativo quando o lado
  direito é positivo. Por isso, `d % 360` é suficiente por si só.

## 2. Virar

- Soma a viragem aos graus e cria um novo rumo a partir do total:
  `#BEARING(degrees + by)`.
- O `create` já traz a resposta de volta para o intervalo, por isso não há
  nada a fazer quanto a virar para lá do norte.

## 3. Comparar

- Uma linha: compara os dois `degrees`.
- O tipo do argumento é `SAME`, e lês o seu atributo da forma habitual:
  `other.degrees`.

## 4. Dar nome ao ponto

- O truque é deslocar meio segmento antes de dividir, para que cada ponto
  seja medido a partir do seu *centro*:
  `((degrees + 22) / 45) % 8` dá 0 para norte, 1 para nordeste, e assim
  por diante.
- Depois, um `case` sobre esse número, com os oito nomes. E um `else`, de que
  o `case` precisa sempre, mesmo quando os oito ramos cobrem todos os
  valores possíveis.

## 5. Escrever

- O `+` junta as peças, mas só a uma string se podem adicionar coisas. Aqui o
  número vem primeiro, por isso precisa de `degrees.str` para iniciar a
  junção. `"a" + 1` funciona; `1 + "a"` não compila.
- Chama o `point` em vez de voltares a calcular o nome.
