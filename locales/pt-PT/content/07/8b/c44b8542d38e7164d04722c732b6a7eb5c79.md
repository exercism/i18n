# Testar os exercícios

Segue os passos abaixo para desenvolver uma solução para um exercício e testá-la localmente.

## Descarregar o exercício

Abre a Command Prompt e executa o comando abaixo com o nome do exercício que preferires, para o descarregar.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Desenvolve a tua solução

1. Executa o comando abaixo para navegar até ao diretório do exercício que acabaste de descarregar.

     >**Dica:** A localização do diretório no comando abaixo depende do teu sistema operativo e do espaço de trabalho do Exercism que tens configurado. Podes descobrir a localização do teu espaço de trabalho executando o comando `exercism configure`.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Segue as instruções fornecidas e desenvolve uma solução para o exercício.

## Testa a tua solução

Alguns exercícios de Ballerina têm um único teste, enquanto outros têm vários testes. Os testes encontram-se no ficheiro de teste correspondente do diretório `/tests`, dentro do diretório raiz do exercício.

### Testar um exercício com um único teste

Executa o comando abaixo para correr o teste do exercício.

Por predefinição, só o primeiro teste está ativo. Isto é intencional, porque te permite concentrar-te apenas em fazer esse teste passar. 
     
```sh
bal test
```

### Testar um exercício com vários testes

Segue os passos abaixo para testar um exercício com vários testes.

1. Assim que o primeiro teste passar, ativa o teste seguinte removendo a propriedade `enable: false` da anotação `@test:Config`.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Executa o comando abaixo para correr o teste ativado.

   ```sh
     bal test
   ```

3. Repete os dois passos acima para ativar os restantes testes.

Concluíste o exercício com êxito ao ativar todos os testes e ao garantir que a tua implementação passa em cada um deles.
