# Instruções

Determina se um dado conjunto de três peças de dominó pode ser organizado de modo a formar uma cadeia de dominó correta (os pontos de uma metade de uma peça coincidem com os pontos da metade vizinha de uma peça adjacente) e se os pontos das metades das peças que não têm vizinha (a primeira e a última peça) coincidem entre si. Alguns casos de teste podem usar peças duplicadas numa solução de cadeia. Devolve `True` se for possível formar uma cadeia de dominó correta e `False` caso contrário. 

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
