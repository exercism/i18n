# Como escrever um bom pedido de suporte

Queres ajuda com um exercício do Exercism? Aprende a escrever um bom pedido de suporte e incentiva a nossa comunidade a apoiar-te, para aumentares as tuas hipóteses de receber uma boa resposta.

Aqui ficam algumas dicas essenciais.

## Usa blocos de code, não imagens

Quando queres partilhar code (escrito por ti ou instruções), usa um bloco de code, não uma imagem.

Enquanto programadores, lemos code muito mais depressa do que andar a ampliar uma imagem para ver as coisas. E muitos dos nossos utilizadores usam leitores de ecrã, que não conseguem ler imagens. Por isso, se queres ser um bom membro da comunidade, incentivar os nossos voluntários a ajudar-te e parecer um profissional, partilha o teu code como texto e não como imagem!

Por exemplo, podes escrever o seguinte:

````
```
for number in range(10):
  total += number;
```
````

Isto vai aparecer assim:

```
for number in range(10):
  total += number;
```

Podes até ter realce de sintaxe se adicionares a linguagem na abertura do bloco de code:

````
```python
for number in range(10):
  total += number;
```
````

o que dá isto:

```python
for number in range(10):
  total += number;
```

## Usa linguagem inclusiva

O Exercism é feito de pessoas de géneros diferentes. Se apareces no nosso Discord e dizes coisas como «Olá, rapazes», estás logo a excluir metade da nossa comunidade. Isso significa que é menos provável que te ajudem, mas também significa que o resto da comunidade te vai ajudar menos, porque valorizamos a inclusividade no Exercism.

Por isso, se queres receber ajuda e queres ser uma pessoa simpática, não uses linguagem específica de género. Experimenta «Olá, pessoal», «Olá a todos» ou sê mesmo ousado e escolhe «Olá, colegas Exercists!».

Para saber mais, lê o nosso artigo sobre [as palavras que usamos](./the-words-that-we-use).
