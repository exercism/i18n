# Dicas

## Geral

As condicionais servem para verificar determinadas condições e/ou critérios. A forma mais básica de fazer uma operação condicional é usar uma única condicional `if`.

## 1. Calcula a pontuação de uma carta qualquer.

A função `parseCard` deve receber a string `card` (por exemplo, `ace`) e transformá-la no seu valor (por exemplo, 11).

- Usa uma grande [instrução `switch`][switch-statement] sobre a variável `card`.
- King, Queen, Jack e 10 podem ser tratados com um único caso.
- O switch pode ter um caso `default`. Em qualquer caso, a função deve devolver `0` para cartas desconhecidas.

## 2. Determina se duas cartas formam um Blackjack.

`isBlackJack` verifica se 2 cartas têm o valor combinado de 21.

- Deve usar a função `parseCard` para obter o valor de cada carta.
- Deve somar os valores das 2 cartas.
- Deve devolver `true` se a soma for igual a `21`.
- Não é preciso nenhuma instrução adicional aqui. O resultado da comparação pode ser devolvido.

## 3. Implementa a lógica de decisão para pontuações de mão superiores a 20 pontos.

Como a função `largeHand` só é chamada para mãos com um valor superior a 20, só há 2 mãos possíveis: um **BlackJack** com um valor total de `21` e **2 Aces** com um valor total de `22`.

- A função deve verificar [se][if-statement] `isBlackJack` é `true` e, caso contrário, devolve "P".
- Se `isBlackJack` for `true`, é preciso verificar se o dealerScore é inferior a 10. [Se][if-statement] for inferior, devolve "W", caso contrário "S".

## 4. Implementa a lógica de decisão para pontuações de mão inferiores a 21 pontos.

A função `smallHand` só é chamada se não houver Aces na mão (`handScore` é inferior a 21).

- Implementa cada condição usando [operadores lógicos][logical-operators] se necessário:
  - [Se][if-statement] as tuas cartas somarem 17 ou mais, deves sempre _stand_.
  - [Se][if-statement] as tuas cartas somarem 11 ou menos, deves sempre _hit_.
  - [Se][if-statement] as tuas cartas somarem um valor no intervalo [12, 16], deves sempre _stand_ se o dealer tiver um 6 ou menos.
  - [Se][if-statement] as tuas cartas somarem um valor no intervalo [12, 16], deves sempre _hit_ se o dealer tiver um 7 ou mais.
- (opcional) Tenta otimizar as condições:
  - Junta as condições para _stand_ numa só.
  - Junta as condições para _hit_ numa só.
  - Remove as partes redundantes das condições (por exemplo, `A || !A && B` pode ser `A || B`).
