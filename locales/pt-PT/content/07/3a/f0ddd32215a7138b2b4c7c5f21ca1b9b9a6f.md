# Sobre

Existem basicamente dois tipos de ciclos:

1. Repetir até uma condição ser satisfeita.
2. Iterar sobre os elementos de uma coleção.

Ambos são [possíveis em R][web-loops], embora o primeiro seja provavelmente mais comum.

## `while` e `repeat`

Para problemas em aberto, em que o número de voltas ao ciclo não é conhecido à partida, R tem o ciclo [`while`][ref-control] com uma condição e o ciclo [`repeat`][ref-control] sem condição (equivalente a `while (TRUE)`).

A forma básica é bastante simples:

```R
while (condition) {
  do_something()
}
```

Neste caso, o programa continua a dar voltas ao ciclo até `condition` deixar de ser `TRUE`.

Há duas formas de sair do ciclo antecipadamente:

- Um `break` faz o ciclo terminar, continuando a execução na linha seguinte à chaveta de fecho do ciclo, `}`.
- Um `return(x)` interrompe a execução da função atual e passa o valor devolvido `x` de volta a quem a chamou.

Com estas opções disponíveis, às vezes pode ser conveniente criar um ciclo "infinito" com `repeat { ... }` e depois contar com a descoberta de uma condição de paragem dentro do corpo do ciclo para acionar um `break` ou um `return`.

Estas três variantes são equivalentes e todas terminam com `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Iterar sobre um vetor (ou outra coleção)

Muitas vezes, isto não é necessário em R.
Como foi discutido noutros conceitos, muitas funções operam sobre vetores inteiros.

No entanto, por vezes os ciclos explícitos são inevitáveis.
Isto é especialmente verdade quando:

- O corpo do ciclo tem efeitos secundários, como imprimir ou fazer entrada/saída de ficheiros.
- O ciclo continua até se atingir um determinado critério, após um número imprevisível de iterações.

A condição do ciclo tem de estar entre parênteses.
Tal como acontece com os corpos das funções, as chavetas são opcionais (mas muitas vezes incluídas) nos corpos de ciclo com uma só linha.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Se a iteração atual não satisfizer uma condição, é possível saltar imediatamente para a iteração seguinte com um `next`:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

Se precisares do índice numérico, usa [`seq_along()`][ref-seq_along].

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Usar `i in 1:length(v)` _não_ é recomendado, pois pode causar problemas quando `length(v)` é zero.
O intervalo `1:0` é equivalente a `c(1, 0)`, pelo que o corpo do ciclo é executado e provavelmente falha.
A função `seq_along()` foi concebida para tratar este caso corretamente.
