# Instruções

Dado um número n, determina qual é o n-ésimo número primo.

Ao listar os seis primeiros números primos, 2, 3, 5, 7, 11 e 13, vemos que o 6.º número primo é 13.

Se a tua linguagem de programação fornecer métodos na biblioteca padrão para lidar com números primos, finge que não existem e implementa-os tu mesmo.
