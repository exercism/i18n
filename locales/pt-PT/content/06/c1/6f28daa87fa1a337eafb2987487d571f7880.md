# Introdução

As expressões condicionais servem para executar código consoante a condição de um **if** é **verdadeira** ou **falsa**. Escrevem-se assim:

```haxe
if (condition) {
  expressions
};
```

O resultado da condição é do tipo `Bool`, por isso, quando o resultado é `true`, as expressões são executadas.

Às vezes, quando a condição é, na verdade, `false`, queremos que seja executado mais algum código. É aí que entra a expressão `else`. O `else` executa expressões quando a condição inicial é `false`. Mas e se quisermos verificar a condição para várias possibilidades? Nesse caso, usamos `else if (condition)`. Aqui está um exemplo completo:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
