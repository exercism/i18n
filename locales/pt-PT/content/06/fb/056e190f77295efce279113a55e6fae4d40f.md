# Anexo às instruções

## Como este exercício está estruturado no percurso de Python

Os testes deste exercício esperam que o teu programa seja implementado como uma [`class`][classes in python] Garden (_vê também [concept:python/classes]()_).
Se não estás familiarizado com classes em Python, este [tutorial da Real Python][how-to-make-a-class] pode ser um bom ponto de partida adicional.

A tua `class` deve implementar um [`method`][methods] chamado `plants`, que recebe o nome de um aluno como argumento e devolve a `list` dos nomes das plantas que pertencem a esse aluno.


## Construtores

Criar o jardim de exemplo:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

seria, nos testes, representado como `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`.

Para que esta representação funcione, a tua `class` terá de implementar um [`__init__()`][init] [método especial][special-methods].
Se não estás familiarizado com `__init__()` ou com [_construtores_][what-is-a-constructor], a página [objetos de classe e de instância][class vs instance objects in python] da documentação do Python dá uma explicação mais detalhada.


## Parâmetros predefinidos

Em alguns testes, é passada uma `list` de alunos como argumento a `__init__()`.
Isto deve substituir a lista de doze alunos fornecida no enunciado do problema.
Ambas estas instruções têm de funcionar com o teu método `__init__()`:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

Uma abordagem é tornar a `list` de alunos um [argumento predefinido][default argument values]; a documentação do Python descreve os `default parameters` em detalhe ao explicar [definições de funções][function definitions].
