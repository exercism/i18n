# Dicas

## 1. Define um novo dicionário de pontuações máximas

- Podes inicializar [dicionários vazios][empty-dictionary] escrevendo, a seguir ao nome do tipo, um par de parênteses vazios ou, se o tipo puder ser determinado a partir do contexto, usando o literal de dicionário vazio.

## 2. Adiciona jogadores ao dicionário de pontuações máximas

- Um dicionário tem de ser declarado como variável para lhe poderes adicionar elementos.
- Podes adicionar elementos a um dicionário com a [sintaxe de subscrito de dicionário][dictionary-subscripts].

## 3. Remove jogadores do dicionário de pontuações

- Um dicionário tem de ser declarado como variável para lhe poderes remover elementos.
- Podes remover elementos de um dicionário com o [método adequado][dictionary-docs].

## 4. Reinicia a pontuação de um jogador

- Um dicionário tem de ser declarado como variável para lhe poderes alterar os valores.
- Podes atualizar valores num dicionário com a [sintaxe de subscrito de dicionário][dictionary-subscripts].

## 5. Atualiza a pontuação de um jogador

- Um dicionário tem de ser declarado como variável para lhe poderes alterar os valores.
- Podes atualizar valores num dicionário com a [sintaxe de subscrito de dicionário][dictionary-subscripts].

## 6. Obtém uma lista de jogadores com as pontuações ordenadas por nome de jogador

- Podes ordenar os elementos de um dicionário com o [método adequado][dictionary-docs].
- Vais ter de definir uma função de ordenação do tipo `((String, Int), (String, Int)) -> Bool` para passar ao método `sorted(by:)`.
- A função de ordenação deve devolver `true` se o par chave/valor da esquerda deve aparecer _antes_ do par chave/valor da direita no resultado ordenado.

## 7. Obtém uma lista de jogadores ordenada por pontuação, por ordem decrescente

- Podes ordenar os elementos de um dicionário com o [método adequado][dictionary-docs].
- Vais ter de definir uma função de ordenação do tipo `((String, Int), (String, Int)) -> Bool` para passar ao método `sorted(by:)`.
- A função de ordenação deve devolver `true` se o par chave/valor da esquerda deve aparecer _antes_ do par chave/valor da direita no resultado ordenado.
