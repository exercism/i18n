# Introdução

Os tipos que implementam a interface `IEnumerable<T>` são conhecidos como _enumeráveis_. Todos os tipos de coleção incorporados implementam esta interface.

Um tipo enumerável pode ser iterado com um ciclo `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Para implementar `IEnumerable<T>`, um tipo tem de implementar um método: `IEnumerator<T> GetEnumerator()`. Como se pode ver, um tipo enumerável delega a iteração efetiva sobre uma coleção num tipo `IEnumerator<T>`. Esta interface tem uma propriedade e três métodos para implementar:

- `public T Current { get; }`: obtém o elemento atual.
- `public bool MoveNext ();`: avança para o elemento seguinte, devolvendo `true` se o avanço para o elemento seguinte foi bem-sucedido, e `false` se não (não há mais elementos).
- `public void Reset ();`: reinicia o enumerador para o estado inicial (antes do primeiro elemento).
