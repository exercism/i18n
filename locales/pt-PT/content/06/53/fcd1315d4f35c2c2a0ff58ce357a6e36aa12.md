Mas as coisas estão um pouco desorganizadas: as coordenadas da Azara parecem estar formatadas e ordenadas de forma diferente das do Rui, e têm de andar sempre a olhar de uma lista para a outra para perceber que tesouros correspondem a que locais.
Como fsharpies principiantes, vieram pedir-te ajuda para escreveres um pequeno programa (na verdade, um conjunto de funções) que organize melhor a informação da sua caça ao tesouro.

## 1. Extrair as coordenadas

Implementa a função `getCooordinate()` que recebe um par `(treasure, coordinate)` da lista da Azara e devolve apenas a coordenada do mapa extraída.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. Formatar as coordenadas

Implementa a função `convertCoordinate()` que recebe uma coordenada no formato "2A" e devolve um tuplo no formato `(2, 'A')`.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. Comparar as coordenadas

Implementa a função `compareRecords()` que recebe um par `(treasure, coordinate)` e um registo `(location, coordinate, quadrant)` e compara as coordenadas de cada um.
Devolve **`true`** se as coordenadas coincidirem e **`false`** se não coincidirem.
Reformata as coordenadas conforme for necessário para uma comparação exata.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. Combinar os registos coincidentes

Implementa a função `createrecord()` que recebe um par `(treasure, coordinate)` da lista da Azara e um registo `(location, coordinate, quadrant)` da lista do Rui e devolve `(coordinate, location, quadrant, treasure)` **se as coordenadas coincidirem**.
Se as coordenadas _não_ coincidirem, devolve um tuplo com a mesma forma mas preenchido com `""`.
Reformata as coordenadas conforme for necessário para uma comparação exata.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
