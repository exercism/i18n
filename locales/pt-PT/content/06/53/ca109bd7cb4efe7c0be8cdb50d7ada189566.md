# Instruções

Escreve uma função que converta números normais em [números ordinais](https://en.wikipedia.org/wiki/Ordinal_numeral). Para o zero (0), devolve apenas "0" como string.

Os números ordinais são números que descrevem a posição de algo numa lista.
É neste contexto que os números ordinais vão ser usados, com o nome do número ordinal escrito em inglês.

Os números ordinais são (pelo menos, uma das suas formas):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

Assim, ao introduzir um número normal, obtém-se o seu equivalente ordinal:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
