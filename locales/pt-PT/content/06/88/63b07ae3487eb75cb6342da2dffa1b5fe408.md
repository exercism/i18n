# Instruções

Considera uma função polinomial na forma f(x) = ax^3 + bx^2 + cx + d. Os mínimos locais são definidos como f(x) < f(x - delta) e f(x) < f(x + delta). Com esta definição, deriva uma expressão para o mínimo local e resolve também um mínimo local com os coeficientes dados (a, b, c, d). Os coeficientes vão descrever uma função com pelo menos um mínimo.
Devolve a coordenada x onde ocorre o mínimo.
