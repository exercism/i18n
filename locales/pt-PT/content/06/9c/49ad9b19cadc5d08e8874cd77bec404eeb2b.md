# Testes

Podes implementar um exercício no teu próprio sistema SAP. Segue estes passos:

1. Cria um pacote SAP para todos os exercícios do Exercism no teu sistema (nome recomendado: `$EXERCISM`)
2. Cria um pacote SAP para cada exercício como subpacote (nome recomendado: `$EXERCISM_<name-of-exercise>`, exemplo: `$EXERCISM_HELLO-WORLD`)
3. Cria uma classe ABAP correspondente ao exercício (exemplo: `ZCL_HELLO_WORLD`)
4. Copia o código modelo do Exercism para a classe
5. Mantém as classes de teste e copia o código do Exercism para a classe de teste

Agora podes completar a implementação da classe e executar o teste unitário para ver se a tua solução funciona corretamente.

Nota: Esta configuração de pacotes permite-te fazer uma cópia de segurança de todo o teu trabalho usando [abapGit](https://abapgit.org), criando um repositório para o pacote `$EXERCISM`.

Para mais detalhes, consulta a [documentação de ABAP do Exercism](https://exercism.org/docs/tracks/abap).
