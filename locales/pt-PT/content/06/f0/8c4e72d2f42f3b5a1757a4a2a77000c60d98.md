# Introdução

As **expressões regulares** (regexes) são sequências de carateres que especificam um padrão de pesquisa num texto.

Aprender a sintaxe das expressões regulares vai além do âmbito deste tópico.
Vamos concentrar-nos nas expressões que o `jq` disponibiliza para usar regexes.

## Variante de regex

Ferramentas diferentes implementam versões diferentes das expressões regulares.
O `jq` incorpora a biblioteca de regex [Oniguruma][oniguruma], que é em grande parte compatível com as expressões regulares do Perl v5.8.

A sintaxe específica usada pelo `jq` pode ser [encontrada no repositório GitHub do Oniguruma][onig-syntax].

<!-- prettier-ignore -->
~~~~exercism/caution
O `jq` não tem nenhuma sintaxe especial para expressões regulares.
São simplesmente expressas como strings.
Isto significa que todas as barras invertidas da expressão regular têm de ser escapadas na string.

Por exemplo, a classe de carateres de algarismo (`\d`) tem de ser escrita como `"\\d"`.
~~~~

<!-- prettier-ignore-end -->

## Funções de regex

As expressões regulares no `jq` estão limitadas a [um conjunto de filtros][jq-regex-funcs].

### Correspondência simples

Quando precisas de saber se uma string corresponde a um padrão, usa o filtro `test`.

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

Este filtro devolve um resultado _boolean_.

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### Informação sobre a correspondência

Quando precisas de extrair a substring que correspondeu de facto ao padrão, usa o filtro `match`.

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

Este filtro devolve:

- nada, se não houver correspondência, ou
- um objeto com várias propriedades, se houver correspondência.

Este exemplo procura duas vogais consecutivas idênticas, usando a sintaxe de retroreferência, `\1`.

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

O filtro `match` devolve um objeto para _cada_ correspondência.
Este exemplo mostra a flag `"g"` em ação para encontrar todas as vogais.

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### Substrings capturadas

Tal como o filtro `match`, o filtro `capture` devolve um objeto se houver correspondência.

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

O objeto devolvido é um mapeamento das **capturas nomeadas**.

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### Apenas as substrings

O filtro `scan` é semelhante ao `match` com a flag `"g"`.

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

O `scan` devolve um _stream_ de substrings.

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

Usa o construtor de arrays `[...]` para capturar as substrings.

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### Dividir uma string

Se sabes quais as partes da string que queres **manter**, usa o `match` ou o `scan`.
Se sabes quais as partes que queres **descartar**, usa o `split`.

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
O filtro `split` de **aridade 1** trata o seu argumento como uma **string fixa**.

Para usar uma regex com o `split`, **tens** de fornecer o segundo argumento; podes usar uma string vazia sem problema.
~~~~

<!-- prettier-ignore-end -->

Um exemplo que divide uma string por espaços em branco arbitrários.

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### Substituições

Os filtros `sub` e `gsub` podem transformar a string recebida, substituindo as partes correspondidas por uma string de substituição.

Para substituir apenas a primeira correspondência, usa o `sub`.
Para substituir todas as correspondências, usa o `gsub`.

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

O texto de substituição pode referir as substrings correspondidas; usa capturas nomeadas e [interpolação de strings][jq-interp].

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## Flags

Em todos os filtros acima, FLAGS é uma string composta por zero ou mais das flags suportadas.

- `g` - Pesquisa global (encontra todas as correspondências, não apenas a primeira)
- `i` - Pesquisa que não distingue maiúsculas de minúsculas
- `m` - Modo multilinha (o '.' corresponde a mudanças de linha)
- `n` - Ignora correspondências vazias
- `p` - Ativa os modos s e m em simultâneo
- `s` - Modo de linha única ('^' -> '\A', '$' -> '\Z')
- `l` - Encontra as correspondências mais longas possíveis
- `x` - Formato de regex extendido (ignora espaços em branco e comentários)

Por exemplo

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
