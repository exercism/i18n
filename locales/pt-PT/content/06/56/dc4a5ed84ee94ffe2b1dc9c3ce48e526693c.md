# Introdução

O PHP disponibiliza vários operadores para realizar operações aritméticas. O PHP segue a ordem habitual das operações matemáticas para os seus operadores aritméticos. Os operadores disponibilizados pelo PHP são:

* Identidade (+)
* Negação (-)
* Adição (+)
* Subtração (-)
* Multiplicação (*)
* Divisão (/)
* Módulo (%)
* Exponenciação (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
