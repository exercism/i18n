# Instruções

De repente, sentes uma onda de nostalgia e uma vontade enorme de tirar o pó às tuas velhas cartas Blorkemon™️.
As cartas Blorkemon™️ são um excelente jogo de troca de cartas à moda antiga.
Cada `Card` tem um monstro Blorkemon™️ desenhado, juntamente com um nível de poder de ataque e, se tiveres sorte, a carta pode até ser brilhante.

## 1. Compara os níveis de poder

Cada carta Blorkemon™️ parece mais poderosa do que a seguinte, mas é melhor verificares.

Implementa a função `isMorePowerful`. Deve devolver `True` se a carta no seu primeiro argumento for estritamente mais poderosa do que a outra, e `False` caso contrário.

```elm
newthree = Card "Newthree" 120 False
scientuna = Card "Scientuna" 6 True

isMorePowerful newthree scientuna
    --> True
```

## 2. Encontra o poder mais alto

Com uma mão cheia de cartas Blorkemon™️, deves ser capaz de preparar o ataque mais devastador.

Implementa a função `maxPower`, que devolve o nível de poder mais alto de duas cartas.

```elm
maxPower newthree scientuna
    --> 120
```

## 3. Ordena as cartas

Parece que te lembras de ter pelo menos uma carta de cada Blorkemon™️, mas já passou algum tempo desde a última vez que verificaste. Deves ordenar as tuas cartas para as comparares com a listagem oficial na Pulpapedia.

Implementa a função `sortByMonsterName`, que deve receber uma lista de `Cards` e devolver uma lista ordenada pelos nomes dos monstros.

```elm
sortByMonsterName [newthree, scientuna]
    --> [Card "Newthree" 120 False, Card "Scientuna" 6 True]
```

## 4. As cartas mais fixes primeiro

Os Blorkemon™️ são a coisa mais fixe de sempre.
Não estás a usar esse termo de ânimo leve, tens um método científico para o demonstrar.

Implementa a função `sortByCoolness`, que ordena uma lista de cartas colocando as mais fixes primeiro.
O quão fixe é uma carta determina-se primeiro pelo seu brilho: todas as cartas brilhantes são muito mais fixes do que as outras.
O segundo fator é o nível de poder: quanto mais alto, melhor.

```elm
sortByCoolness [newthree, scientuna]
    --> [Card "Scientuna" 6 True, Card "Newthree" 120 False]
```

## 5. Shiny Power

O brilho não é só para exibir. Numa batalha entre Blorkemon™️ com o mesmo poder, o brilhante prevalece sempre.
A isto chama-se Shiny Power.

Implementa a função `compareShinyPower`, que codifica esta propriedade.
A `Order` de duas cartas é determinada pelos níveis de poder se forem diferentes, mas se forem iguais, uma carta brilhante é maior.

```elm
compareShinyPower newthree scientuna
    --> GT
```

## 6. Faz as tuas apostas

Num jogo de cartas Blorkemon™️, tudo pode acontecer, mas há ainda uma tendência para as cartas mais poderosas ganharem.

Implementa a função `expectedWinner`, que devolve o nome do monstro com mais probabilidades de ganhar, segundo a ordenação de `compareShinyPower`.
A função deve devolver o nome do monstro do vencedor esperado, ou "too close to call" se ambos os oponentes tiverem o mesmo Shiny Power.

```elm
expectedWinner newthree scientuna
    --> "Newthree"
```
