# Anexo às instruções

## Implementação

Vais ver um ficheiro `cases_test.go` neste exercício.
Este contém os casos de teste usados no `leap_test.go`.
Na maior parte das vezes, podes ignorar este ficheiro.

No entanto, se estiveres interessado... por vezes geramos os dados de teste a partir de um [repositório interlinguístico][problem-specifications-leap].
Nesse repositório, os exercícios podem ter um [ficheiro .json][problem-specifications-leap-json] que contém dados de teste comuns.
Alguns dos nossos exercícios locais têm um [programa intermediário][local-leap-gen] que pega na especificação JSON do problema e a transforma em estruturas Go que alimentam o ficheiro `<exercise>_test.go`.
A transformação desses dados específica do Go está no ficheiro `cases_test.go`.

[problem-specifications-leap-json]: https://github.com/exercism/problem-specifications/blob/master/exercises/leap/canonical-data.json
