# Introdução

Acabaste de ser contratado como professor de matemática.
A tua primeira semana correu bem, mas há algo de estranho na segunda.
O problema é que todas as respostas dadas pelos teus alunos estão erradas!
Felizmente, os teus conhecimentos de matemática permitiram-te identificar o problema: as respostas dos alunos _estão_ corretas, mas estão todas na base 2 (binário)!
Curiosamente, verifica-se que, a cada semana, os alunos usam uma base diferente.
Para te ajudar a verificar rapidamente as respostas dos alunos, vais construir uma ferramenta que converte entre bases.
