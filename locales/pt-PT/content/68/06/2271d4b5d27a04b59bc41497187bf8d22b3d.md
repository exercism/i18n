# Dicas

## 1. Define o intervalo de fileiras e colunas

- Precisas de definir duas [constantes][constants] que devem conter um [`Range`][range] de fileiras e colunas.
- As fileiras devem ser um `range` de [`Integer`][integers] de 1 a 8.
- As colunas devem ser um `Range` de [`String`][string] de 'A' a 'H'.
- A constante tem de ser definida no [módulo][module] `Chess`.

## 2. Verifica se a casa é válida

- Precisas de verificar se um valor está dentro de um intervalo.
- Existe [um método][include] que podes usar para verificar se um valor está dentro de um intervalo.

## 3. Obtém a alcunha do jogador

- Podes obter uma fatia usando um `Range` como parâmetro de entrada.
- Existe [um método][upcase] que podes usar para converter uma string em maiúsculas.

## 4. Cria a mensagem da jogada

- Podes indexar a string da casa para obter a fileira e a coluna.
- Podes usar métodos já definidos para obter a alcunha do jogador e para verificar se a jogada é válida.
