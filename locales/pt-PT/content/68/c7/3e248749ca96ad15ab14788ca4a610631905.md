# Dicas

## 1. Cria o enum LogLevel

- Vais precisar de definir um inicializador e um método, para além dos casos do enum.

## 2. Analisa o nível de log

- O Swift tem algumas [propriedades][string-docs] e métodos para extrair partes de uma string.
- A [instrução `switch`][switch-statement] é frequentemente uma combinação natural com enums.

## 3. Converte a linha de log em formato curto

- Os métodos definem-se tal como as funções, mas apenas dentro do corpo do enum.
- É possível atribuir [valores brutos][enum-raw-values] aos casos do enum.
- A palavra-chave `self` refere-se ao valor do enum dentro do corpo de um método.
