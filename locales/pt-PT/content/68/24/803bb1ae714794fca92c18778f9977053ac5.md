# Dicas

## Geral

- O [guia de strings do rubymostas][ruby-for-beginners.rubymonstas.org-strings] tem uma boa introdução às strings do Ruby.
- O objeto `String` tem muitos [métodos incorporados][docs-string-methods] úteis.

## 1. Obter a mensagem de uma linha de registo

- Há várias formas de procurar texto numa string, que podes consultar na [documentação oficial da linguagem Ruby][docs-string-methods].
- Existem [métodos incorporados][strip-white-space] para remover espaços em branco.

## 2. Obter o nível de registo de uma linha de registo

- Os objetos `String` do Ruby têm um [método][downcase] para fazer esta operação.

## 3. Reformatar uma linha de registo

- Há várias formas de [concatenar strings][ruby-for-beginners.rubymonstas.org-strings], mas a preferida costuma ser a [interpolação de strings][ruby-for-beginners.rubymonstas.org-strings]
