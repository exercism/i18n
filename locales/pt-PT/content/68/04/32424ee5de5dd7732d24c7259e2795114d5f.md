# Apêndice às instruções

## Notas específicas de assembly x86-64

As funções deste exercício recebem um array com um ou mais números, cada um deles a representar uma «pontuação do jogo».

Em assembly x86-64, acede-se aos elementos de um array através de um deslocamento em bytes a partir de um ponteiro base.

Este ponteiro base é passado num registo, de acordo com a [convenção de chamada System V AMD64 ABI](https://www.uclibc.org/docs/psABI-x86_64.pdf).

Os primeiros 3 argumentos são passados em rdi, rsi, rdx, por esta ordem.

Como as pontuações do jogador são representadas como inteiros de 32 bits, que ocupam 4 bytes, podem ser lidas a partir de

| `rsi`   |
|---|
| `dword [rsi]` |
| `dword [rsi + 4]` |
| ... |
| `dword [rsi + 4*scores_count - 4]` |

`personal_top_three()` deve escrever as melhores pontuações do jogador num buffer, também passado num registo e acedido da mesma forma.

| `rdi`   |
|---|
| `dword [rdi]` |
| `dword [rdi + 4]` |
| ... |

Os valores inteiros, por convenção, são devolvidos no registo rax.
