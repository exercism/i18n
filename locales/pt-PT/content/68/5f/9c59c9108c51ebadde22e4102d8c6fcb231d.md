# Instruções

O teu amigo Linus é maquinista e conduz comboios de mercadorias entre cidades.
Apesar de ser fantástico a lidar com comboios, não é tão bom a lidar com logística ou computadores.
Gostaria de contar com a tua ajuda na programação para organizar os detalhes dos comboios e corrigir erros nos dados das rotas.

~~~~exercism/note
Este exercício poderia ser facilmente resolvido com slicing, indexação e vários métodos de `hash`.
No entanto, gostaríamos que praticasses empacotamento, desempacotamento e atribuição múltipla ao resolver cada uma das tarefas abaixo.
~~~~

## 1. Cria uma lista com todos os vagões

O teu amigo tem estado a registar o identificador (ID) de cada vagão, mas nunca tem a certeza de quantos vagões o sistema vai ter de processar em cada momento.
Seria muito mais fácil para o resto do programa de logística ter estes dados empacotados num único **array**.

Implementa um método `generate_list_of_wagons()` que aceita um número arbitrário de IDs de vagões.
Cada ID é um número inteiro positivo.
O método deve depois fazer `return` dos IDs recebidos como um único **array**.

```ruby
LocomotiveEngineer.generate_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
# => [1, 7, 12, 3, 14, 8, 5]
```

## 2. Corrige a lista de vagões

A esta altura, já estás a começar a perceber os dados e a forma como são usados no programa de logística.
O sistema de IDs atribui sempre à locomotiva o ID **1**, e aos restantes vagões do comboio um ID escolhido aleatoriamente maior do que **1**.

O teu amigo teve de ligar dois vagões novos ao comboio e esqueceu-se de atualizar o sistema!
Agora, os dois primeiros vagões do **array** do comboio têm de ser movidos para o fim, senão fica tudo fora de ordem.

Para complicar mais as coisas, o teu amigo acabou de descobrir um segundo **array** que parece conter IDs de vagões em falta.
Só se lembra de que, depois de mover os vagões novos, os IDs deste segundo **array** devem ser colocados imediatamente a seguir à locomotiva designada.

O Linus ficaria muito grato se corrigisses os erros dele e consolidares os dados.

Implementa um método `fix_list_of_wagons()` que recebe dois **arrays** com IDs de vagões.
Deve reposicionar os dois primeiros itens do primeiro **array** para o fim e inserir os valores do segundo **array** atrás (_do lado direito_) do ID da locomotiva (**1**).
O método deve depois `return` um **array** com as modificações.

```ruby
LocomotiveEngineer.fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
# => [1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Adiciona as paragens em falta

Agora que todos os dados dos vagões estão corretos, o Linus gostaria que atualizasses as informações de rotas do sistema.
Ao longo de uma rota de transporte, um comboio pode fazer paragens em várias estações diferentes para recolher e/ou deixar mercadorias.
Cada viagem pode ter um número diferente destes pontos de entrega intermédios.
O teu amigo gostaria que atualizasses o **hash** de rotas do sistema com qualquer informação de entrega em falta ou adicional.

Implementa um método `add_missing_stops()` que recebe um **hash** de rotas seguido de um número variável de argumentos de palavra-chave.
Estes argumentos podem ter a forma de um **hash** com uma ou mais paragens, ou de qualquer número de pares de palavra-chave `stop_<number>: "city"`.
O teu método deve depois devolver o **hash** de rotas atualizado com uma **chave** adicional que contém um **array** com todas as paragens adicionadas, pela ordem correta.

```ruby
LocomotiveEngineer.add_missing_stops({from: "New York", to: "Miami"},
                    stop_1: "Washington, DC", stop_2: "Charlotte", stop_3: "Atlanta",
                    stop_4: "Jacksonville", stop_5: "Orlando")
# => {from: "New York", to: "Miami", stops: ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

~~~~exercism/note
As paragens são sempre passadas pela ordem correta, por isso não precisas de te preocupar em ordená-las.
~~~~

## 4. Alarga a informação de rotas

O Linus tem estado a trabalhar no programa de rotas e reparou que faltam alguns detalhes importantes em certas rotas.
A informação inicial das rotas foi construída como um **hash**, e o teu amigo gostaria que atualizasses esse **hash** com tudo o que possa faltar.
Cada rota do sistema exige detalhes ligeiramente diferentes, por isso o Linus preferia mesmo uma solução genérica.

Implementa um método chamado `extend_route_information()` que recebe dois **hashes**.
O primeiro **hash** contém as cidades de origem e de destino entre as quais o comboio circula.

O segundo **hash** contém outros detalhes da rota, como a velocidade, o comprimento ou a temperatura do comboio.
O método deve devolver um **hash** consolidado com toda a informação de rotas.

~~~~exercism/note
O segundo **hash** pode conter propriedades diferentes ou mais do que as mostradas no exemplo.
~~~~

```ruby
LocomotiveEngineer.extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
# => {"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```
