# Sobre

O código Elixir corre na [máquina virtual BEAM][beam]. A BEAM faz parte do sistema de execução do [Erlang][erlang]. Por ter sido inspirado pelo Erlang e por partilhar o seu ambiente de execução, o Elixir oferece uma excelente interoperabilidade com as bibliotecas do Erlang. Isto significa que os programadores de Elixir podem usar bibliotecas do Erlang a partir do seu código Elixir. De facto, na comunidade Elixir, é desencorajado escrever bibliotecas Elixir para funcionalidades que as bibliotecas do Erlang já oferecem.

Por isso, certas funcionalidades, como operações matemáticas ou funções de temporização, só estão disponíveis no Elixir através do Erlang.

Esta relação estreita entre o Elixir e o Erlang faz com que, para te tornares um programador de Elixir proficiente, valha a pena investires algum tempo a aprender a sintaxe básica do Erlang.

## Como usar

A biblioteca padrão do Erlang está disponível para ser usada no nosso código Elixir sem ser preciso qualquer passo adicional.

As funções do Erlang podem ser chamadas da mesma forma que chamamos as funções do Elixir, com uma pequena diferença. Os nomes dos módulos do Erlang são átomos em `snake_case`. Por exemplo, para chamar a função `pi/0` do módulo `math` do Erlang, escreverias:

```elixir
:math.pi()
# => 3.141592653589793
```

## Módulos do Erlang mais usados

Os módulos do Erlang mais usados fornecem funcionalidades que a biblioteca padrão do Elixir não tem. São eles:

- O módulo `timer`, que fornece funções como [`sleep/1`][erl-timer-sleep], [`send_after/2`][erl-timer-send-after] e [`send_interval/2`][erl-timer-send-interval].
- O módulo `rand`, que fornece funções como [`uniform/0`][erl-rand-uniform], [`normal/0`][erl-rand-normal] e [`seed/2`][erl-rand-seed-2].
- [`:io_lib.format/2`][erl-io-lib-format], que fornece formatação de strings ao estilo de C (usando sequências de controlo).
- O módulo `math`, que fornece funções matemáticas como [`sin/1`][erl-math-sin], [`cos/1`][erl-math-cos], [`log2/1`][erl-math-log2], [`log10/1`][erl-math-log10], [`pow/2`][erl-math-pow] e muitas mais.
- O módulo [`queue`][erl-queue], que fornece uma estrutura de dados do tipo fila.
- O módulo [`crypto`][erl-crypto], que fornece funções criptográficas.
- O módulo [`zip`][erl-zip], que fornece funções para trabalhar com arquivos zip.
- O módulo [`calendar`][erl-calendar], que fornece funções para trabalhar com datas e horas, como [`iso_week_number/1`][erl-calendar-iso-week-number]. Para passar uma estrutura `Date`, `Time` ou `NaiveDateTime` a uma das funções do Erlang, é preciso convertê-la para o formato do Erlang com uma função `to_erl` do módulo correspondente.

Para descobrires a biblioteca padrão do Erlang, explora o [Manual de Referência da STDLIB][erl-stdlib-ref].

A interoperabilidade do Elixir com as bibliotecas do Erlang não se limita à biblioteca padrão do Erlang. Qualquer biblioteca do Erlang pode ser usada no código Elixir.
