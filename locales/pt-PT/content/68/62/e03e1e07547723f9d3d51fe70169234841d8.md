# Sobre

`call` é a primitiva universal para "executar já esta quotation".
Quando o compilador consegue ver a quotation literalmente, consegue
inferir o efeito; quando a quotation vem de uma variável, de um array
ou de um parâmetro, tens de declarar o efeito:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

A declaração `call( a b -- c )` compila para uma verificação em tempo
de execução que confirma que a quotation tem mesmo o efeito declarado.
Uma incompatibilidade passa a ser um erro claro, em vez de um estado
da pilha corrompido.

Tratar as quotations como dados (colocá-las na pilha, guardá-las em
arrays, devolvê-las a partir de words) é uma das coisas que torna o
código concatenativo tão compacto. Um "programa" pode ser uma simples
sequência, e `each` com `call` chega para o interpretar.
