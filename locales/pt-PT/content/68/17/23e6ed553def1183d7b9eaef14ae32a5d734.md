# Ajuda

Verifica se o teu código tem erros de sintaxe: cola o teu código em
[https://shellcheck.net](https://shellcheck.net) (ou [instala-o](https://github.com/koalaman/shellcheck#user-content-installing) na tua máquina).

O Stack Overflow será o teu primeiro recurso para perguntas sobre bash.

* começa pela [tag `bash`](https://stackoverflow.com/questions/tagged/bash) para procurar a tua pergunta específica: provavelmente já foi feita
* na tag bash do Stack Overflow, a ligação [Saber mais...](https://stackoverflow.com/tags/bash/info) tem _imensa_ informação boa.
    * a secção "Books and Resources" é particularmente útil.
* a [tag `bash`](https://unix.stackexchange.com/questions/tagged/bash) no Unix & Linux também é ativa

## Utilitários externos

O `bash` é uma linguagem para escrever "scripts", ou seja, programas que podem chamar
ferramentas externas, como
[`sed`](https://www.gnu.org/software/sed/),
[`awk`](https://www.gnu.org/software/gawk/),
[`date`](https://www.gnu.org/software/coreutils/manual/html_node/date-invocation.html)
e até programas escritos noutras linguagens de programação,
como o [`Python`](https://www.python.org/).
Este track não restringe a utilização destes utilitários e, desde que a tua
solução seja portátil entre sistemas e não exija a instalação de aplicações
de terceiros, podes usá-los à vontade para resolver o exercício.

Para um desafio extra, se quiseres compreender melhor a linguagem, tenta
reimplementar a solução em bash puro, sem usar ferramentas externas. Há alguns
tipos de problemas que o bash não consegue resolver, como a aritmética de
vírgula flutuante e a manipulação de datas: para esses, tens de recorrer a uma
ferramenta externa.
