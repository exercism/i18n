# Anexo às instruções

## Formato de entrada/saída

Cada conjunto de palavras é representado como uma string terminada em null, com um caráter de nova linha no fim de cada palavra.

Tens de devolver os anagramas pela mesma ordem em que aparecem nas palavras candidatas.

Um exemplo seria `"tones\nnotes\nSeton\n"`

## Registos

| Registo | Utilização   | Tipo    | Descrição                                                      |
| ------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`   | entrada      | endereço | string de destino terminada em null, sem nova linha            |
| `$a1`   | entrada      | endereço | string de candidatos terminada em null, com nova linha depois de cada palavra |
| `$a2`   | entrada/saída | endereço | string de saída terminada em null, com nova linha depois de cada palavra |
| `$t0-9` | temporário   | qualquer | para armazenamento temporário                                  |
