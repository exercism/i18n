# Anexo às instruções

## Dicas

Para completares este exercício, precisas de criar o tipo de dados `Deque`
e implementar as seguintes funções:

- `mkDeque`
- `pop`
- `push`
- `unshift`
- `shift`

Vais encontrar uma declaração de dados de exemplo e assinaturas de tipo já presentes,
mas cabe-te a ti definir as funções e criar um tipo de dados com significado,
um newtype ou um sinónimo de tipo.
