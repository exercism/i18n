# Introdução

As operações bit a bit permitem-nos manipular algarismos individuais dentro de números binários.

O Elm disponibiliza vários operadores bit a bit no seu [módulo Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

## Operações básicas

Modificar bits individuais de um número chama-se _mascaramento_.
Uma _máscara_ é um número em que bits específicos foram definidos de uma determinada forma, para manipular outro número com operadores bit a bit como `and`, `or` e `xor`.

### and

`and` combina dois números, mantendo apenas os bits que são `1` nos dois.
Isto é útil para verificar se um determinado bit está definido.
Por exemplo, para verificar se o 4.º bit de um número está definido como `1`, aplica-lhe `and` com uma máscara `01000` (`8` em decimal) e vê se o resultado é diferente de zero:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or` combina dois números, definindo cada bit como `1` se for `1` num dos números ou em ambos.
Isto é útil para definir um bit específico como `1`.
Por exemplo, para definir o 2.º bit de `10101` como `1`, aplica-lhe `or` com a máscara `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### Ou exclusivo (xor)

`xor` combina dois números, definindo cada bit como `1` se for `1` num número mas `0` no outro.
Isto é útil para inverter um bit para o seu valor oposto:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### Complemento

`complement` inverte cada bit de um número (`0` passa a `1`, `1` passa a `0`).

Repara que isto faz com que os números positivos fiquem negativos e os negativos fiquem positivos.
Isto acontece porque, em binário, os números negativos são representados com `1` na posição mais à esquerda.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### Deslocamento de bits

Os seguintes operadores deslocam bits para a esquerda ou para a direita um número especificado de posições, multiplicando ou dividindo, na prática, por potências de 2.

`shiftLeftBy` desloca os bits para a esquerda, preenchendo com `0` a partir do lado direito.
Por exemplo, para deslocar `21` três posições para a esquerda:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Isto é o mesmo que dizer `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`: desloca os bits para a direita:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Deslocar duas posições para a direita é o mesmo que uma divisão inteira por 4.

Repara que esta função duplica o valor que estiver no bit mais à esquerda.
Por isso, os números negativos continuam negativos:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Se quiseres deslocar para a direita e preencher com zeros, usa `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
