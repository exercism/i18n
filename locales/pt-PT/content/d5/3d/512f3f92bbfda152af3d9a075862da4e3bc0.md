# Testar na linha de comandos

Executa os testes com:

```bash
scarb cairo-test
```

Todos os testes, exceto o primeiro, estão ignorados. Depois de conseguires que o primeiro teste passe, abre o ficheiro de código-fonte dos testes, que está no diretório `tests`, remove o marcador `#[ignore]` do teste seguinte e faz com que os testes voltem a passar. Cada teste individual é uma função com o marcador `#[test]` acima dela. Continua até passares todos os testes.

Se quiseres executar _todos_ os testes sem editares o ficheiro de código-fonte dos testes, usa:

```bash
scarb cairo-test --include-ignored
```

Para executar um teste específico, independentemente de estar ignorado ou não, por exemplo `some_test`, podes usar:

```bash
scarb cairo-test -f some_test
```

Para saberes mais sobre os testes do Cairo, consulta a [documentação dos testes][cairo-tests] online.

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
