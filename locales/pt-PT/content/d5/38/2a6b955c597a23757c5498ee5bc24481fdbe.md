# Sobre

O C é uma linguagem de tipos estáticos, o que significa que tudo tem um tipo em tempo de compilação.
Escolher um nome para uma [variável][variable] e definir o seu tipo chama-se declarar uma variável.

Uma variável é declarada especificando explicitamente o seu tipo.
O nome de uma variável [tem de seguir algumas regras][name-rules], como começar por uma letra ou por um underscore.
Alguns nomes não podem ser usados, pois estão reservados [para palavras-chave][reserved-keywords] ou [para outros identificadores][reserved-identifiers].

Definir ou atualizar a variável faz-se por atribuição.
Definir o valor é o que define a variável.
Definir a variável também é conhecido como inicialização.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

O valor de uma variável pode ser atribuído e atualizado com o [operador de atribuição simples `=`][assignment-operator].
Uma vez definida, o tipo de uma variável nunca pode mudar.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

O C é uma linguagem [imperativa][imperative] [procedural][procedural].
Toda a computação é realizada como parte de uma série de [instruções][statements] que pertencem a uma [função][function] ou a várias funções.

Cada função pode ter zero ou mais [parâmetros][parameters].
Ao definir uma função, todos os parâmetros e o valor devolvido têm de ter tipo explícito.
Os valores são devolvidos pelas funções com a [palavra-chave `return`][return-keyword].
Por omissão, as funções têm [classe de armazenamento][storage_class] externa, o que significa que existem durante todo o tempo de vida do programa e podem ser visíveis fora do ficheiro.
Para evitar isto, pode acrescentar-se a palavra-chave `static` para especificar visibilidade interna.

```c
static int add(int x, int y) {
  return x + y;
}
```

No exemplo acima, as variáveis `x` e `y` só podem ser usadas dentro da função, ou seja, têm âmbito de função.
O [âmbito][scope] é a ideia de que o valor associado a um nome (de um elemento do programa) só é acessível dentro da "área" de código onde é definido.
As principais áreas de código em C são:

- ficheiro
- função
- bloco (como dentro de ciclos e de outras construções)

As funções são invocadas especificando o nome da função e passando argumentos para cada um dos parâmetros da função.

```c
int sum = add(1, 2);
```

O C suporta dois tipos de [comentários][comments].
Os comentários de uma linha são precedidos por `//` (desde o C99) e os comentários de várias linhas são inseridos entre `/*` e `*/`.
