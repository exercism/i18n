# Instruções

A tua tarefa é descobrir se uma frase é um pangrama.

Um pangrama é uma frase que usa todas as letras do alfabeto, pelo menos uma vez.
Esta verificação não distingue maiúsculas de minúsculas, por isso não importa se uma letra é minúscula (por exemplo, `k`) ou maiúscula (por exemplo, `K`).

Neste exercício usamos apenas as letras básicas do alfabeto inglês: de `a` a `z`.
