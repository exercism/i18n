# Dicas

## 1. Analisar uma data de marcação só com números

- O construtor vai precisar de um [DateFormat][dateformat] adequado.

## 2. Verificar se uma marcação já passou

- A comparação com o DateTime atual é sintaticamente semelhante a qualquer comparação numérica.

## 3. Verificar se a marcação é à tarde

- Pensa em que parte do DateTime é útil: _não_ é a data, e será que os minutos interessam?
- Lê as instruções para verificar a inclusão/exclusão dos limites na comparação de horas (matematicamente, trata-se de um intervalo semiaberto).

## 4. Descrever a hora e a data da marcação

- O método `Dates.format()` foi feito para isto.
- Inclui a parte `Dates.` para maior segurança (_desculpa, isto pode ser um bug na Julia_).
- Mais uma vez, vais precisar de um [DateFormat][dateformat].

## 5. Devolver a data de aniversário

- Qual é o ano atual?
- Cria um `Date` para 15 de setembro deste ano.

[dateformat]: https://docs.julialang.org/en/v1/stdlib/Dates/#Dates.DateFormat
