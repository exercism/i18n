# Instruções

Neste exercício vais trabalhar num agendador de marcações para um salão de beleza em Nova Iorque, que abriu a 15 de setembro de 2012.

Tens quatro tarefas, que envolvem todas datas de marcações. As datas e horas vão usar um dos três formatos seguintes:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
Os testes definem automaticamente a cultura como `en-US`; não precisas de definir nem especificar a cultura.
~~~~

## 1. Interpreta a data da marcação

Implementa a função `schedule` que consegue interpretar uma representação textual de uma data de marcação e convertê-la no formato `DateTime` correspondente:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Verifica se uma marcação já passou

Implementa a função `hasPassed`, que recebe uma data de marcação e verifica se a marcação já ocorreu no passado:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Verifica se a marcação é à tarde

Implementa a função `isAfternoonAppointment`, que recebe uma data de marcação e verifica se a marcação é à tarde (>= 12:00 e < 18:00):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Descreve a hora e a data da marcação

Implementa a função `description`, que recebe uma data de marcação e devolve uma descrição dessa data e hora:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Devolve a data de aniversário

Implementa a função `anniversaryDate`, que devolve a data de aniversário deste ano, que é 15 de setembro:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
