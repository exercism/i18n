# Dicas

## Geral

- Lê sobre [IO][getting-started-io] no guia Getting Started.
- Lê sobre [como depurar com `IO.inspect/2`][getting-started-debugging-io-inspect] no guia Getting Started.
- Lê sobre o módulo [`IO`][module-io] na documentação.

## 1. Dá as boas-vindas ao novo jogador

- Há uma [função incorporada][io-puts] que escreve uma string na saída padrão.

## 2. Pede o nome da personagem

- Há uma [função incorporada][io-gets] que lê uma string da saída padrão. Também pode escrever uma mensagem, por isso não precisas de usar uma função à parte para escrever a pergunta.
- Há uma [função incorporada][string-trim] no módulo `String` que consegue remover espaços em branco no início e no fim da string lida.

## 3. Pede a classe da personagem

- Há uma [função incorporada][io-gets] que lê uma string da saída padrão. Também pode escrever uma mensagem, por isso não precisas de usar uma função à parte para escrever a pergunta.
- Há uma [função incorporada][string-trim] no módulo `String` que consegue remover espaços em branco no início e no fim da string lida.

## 4. Pede o nível da personagem

- Há uma [função incorporada][io-gets] que lê uma string da saída padrão. Também pode escrever uma mensagem, por isso não precisas de usar uma função à parte para escrever a pergunta.
- Há uma [função incorporada][string-trim] no módulo `String` que consegue remover espaços em branco no início e no fim da string lida.
- Há uma [função incorporada][string-to-integer] no módulo `String` que consegue converter uma string num número inteiro.

## 5. Combina os passos anteriores num só

- Reutiliza as funções implementadas nos passos anteriores.
- Há uma [função incorporada][io-inspect], útil para depurar, que consegue escrever na saída padrão mais do que apenas strings. Essa função aceita opções, por exemplo uma string que será escrita antes do valor passado.
- A função e a opção mencionadas acima acrescentam dois pontos e um espaço a essa string por ti.
