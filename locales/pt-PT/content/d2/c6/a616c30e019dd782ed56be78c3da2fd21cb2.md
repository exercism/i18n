# Operador ternário

O operador ternário fornece uma sintaxe alternativa para efetuar uma comparação `if..else..` e devolver um valor.

## Sintaxe

O PHP disponibiliza um condicional em que uma ação pode ser avaliada com base na "veracidade" de uma condição.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Em alternativa, o operador ternário pode representar a mesma operação:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

A sintaxe da comparação é curta e representa-se por `(condition) ? (evaluate if true) : (evaluate if false);`.

## Vantagens

A vantagem óbvia de usar um operador ternário é a brevidade: escrever a expressão condicional fica mais curto do que escrever uma instrução `if..else..`. Mas há também várias outras vantagens:

- É uma expressão que pode ser usada dentro de outra expressão.
- Facilita a avaliação preguiçosa de cada ramo.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  Neste exemplo, se a resposta exata não for necessária, o cálculo dispendioso não é invocado.

## Desvantagens

Os operadores ternários têm várias desvantagens, o que torna importante ponderar a sua utilização:

- Um operador ternário pode ser mais difícil de ler, pois depende da interpretação de símbolos em vez do uso de palavras-chave.
- Um operador ternário pode conduzir inadvertidamente a bugs, porque o operador ternário em PHP é associativo à esquerda, ao contrário da maioria das linguagens contemporâneas (por exemplo, C, Java, JavaScript).
- A expressão avaliada nos ramos verdadeiro ou falso tem de devolver um valor.

## Ainda mais curta

A sintaxe do ternário pode ser reduzida ainda mais para `(condition) ?: (evaluate if falsey)`.
Uma das utilizações possíveis é fornecer um valor de recurso numa expressão:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Por vezes, também é conhecido como o _operador Elvis_ (`?:`)
