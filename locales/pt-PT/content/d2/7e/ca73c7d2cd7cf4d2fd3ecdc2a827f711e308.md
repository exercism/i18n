# Calculadora de cozinha

## História

A história facilita a exploração de [tuplas][type-tuple] numa linguagem.

A premissa básica é que os ingredientes de cozinha são frequentemente medidos de formas obscuras e exigem conversões diferentes consoante as quantidades ou as ferramentas disponíveis à mão. As tuplas são usadas para dar [duck typing][concept-duck-typing] à componente numérica da medição.

Assim, isto explora a conversão básica de valores com números de vírgula flutuante.

### Conversões

| De                 | Para    |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 cup              | 240mL   |
| 1 fluid ounce (US) | 29.57mL |
| 1 teaspoon         | 5 mL    |
| 1 tablespoon       | 15 mL   |

## Tarefas

Isto deve orientar os estudantes sobre como usar:

- Tuplas
- Tuplas como informação agrupada
- Obter valores de uma tupla através do índice do elemento
- Obter valores de uma tupla com correspondência de padrões
- Criar novas tuplas
