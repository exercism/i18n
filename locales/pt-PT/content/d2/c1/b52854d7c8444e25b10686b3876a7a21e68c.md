# Introdução

## Números inteiros

Um número inteiro é um número sem parte decimal que pertence ao conjunto `{..., -2, -1, 0, 1, 2, ...}`.
Os valores máximo e mínimo de um inteiro dependem do sistema onde o PHP corre.
Tipicamente, na maioria dos sistemas modernos, um inteiro é um valor de 64 bits, ou seja, pode representar desde `-9_223_372_036_854_775_808` até `9_223_372_036_854_775_807`, inclusive.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Podes escrever valores literais inteiros noutra base que não a base 10, usando um prefixo de base:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

## Números de vírgula flutuante

Em PHP, os números de vírgula flutuante são usados para representar um subconjunto dos números reais.
Começam por um ou mais algarismos separados por um separador decimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### Armadilhas comuns

Nem todos os números e operações aritméticas podem ser efetuados com números de vírgula flutuante.
Usar números de vírgula flutuante para representar euros e cêntimos pode dar origem a erros de arredondamento.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## Operadores aritméticos

O PHP disponibiliza vários operadores para efetuar operações aritméticas. O PHP segue a ordem de operações matemática padrão para os seus operadores aritméticos. Os operadores disponibilizados pelo PHP são:

* Identidade (+)
* Negação (-)
* Adição (+)
* Subtração (-)
* Multiplicação (*)
* Divisão (/)
* Módulo (%)
* Exponenciação (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
