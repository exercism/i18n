# Instruções

A tua tarefa é converter um número entre 1 e 31 numa sequência de ações do aperto de mão secreto.

A sequência de ações é escolhida olhando para os cinco algarismos mais à direita do número depois de o converteres para binário.
Começa no algarismo mais à direita e avança para a esquerda.

As ações para cada posição do número são:

```plaintext
00001 = wink
00010 = double blink
00100 = close your eyes
01000 = jump
10000 = Reverse the order of the operations in the secret handshake.
```

Vamos usar o número `9` como exemplo:

- O 9 em binário é `1001`.
- O algarismo mais à direita é 1, por isso a primeira ação é `wink`.
- Avançando para a esquerda, o algarismo seguinte é 0, por isso não há double blink.
- Avançando outra vez para a esquerda, o algarismo seguinte é 0, por isso deixas os olhos abertos.
- Avançando mais uma vez para a esquerda, o algarismo seguinte é 1, por isso dás um salto.

Esse era o último algarismo, por isso o código final é:

```plaintext
wink, jump
```

Dado o número 26, que é `11010` em binário, obtemos as seguintes ações:

- double blink
- jump
- reverse actions

O aperto de mão secreto para 26 é, portanto:

```plaintext
jump, double blink
```
