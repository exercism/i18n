# Dicas

## Geral

- Vê a [excelente palestra][phantom-builder-pattern] do Jeroen Engels sobre o padrão phantom builder

## 1. Fornece um marcador de posição para os baús do tesouro

- O `Chest` pode ser igual ao `TreasureChest`, uma única variante com um tipo phantom acrescentado
- O marcador de posição `Chest todo` não tem argumentos de tipo suficientes, falta-lhe o tipo phantom
- O tipo phantom deve ser um registo, para poder ser estendido
- O tipo inicial é o `Chest treasure {}` sem restrições e o tipo final é o `Chest treasure { conditions | securePassword : (), uniqueTreasure : () }` totalmente verificado
- Para passar do tipo inicial para o outro, as condições `securePassword : ()` e `uniqueTreasure : ()` são acrescentadas por `secureChest` e `uniqueTreasures` de forma independente

## 2. Seleciona os baús seguros

- Podes fazer correspondência de padrões com o `Chest` no argumento da função
- Podes usar a função [`String.length`][string-length] para validar a palavra-passe
- A condição `securePassword : ()` é acrescentada a partir da assinatura de tipo, não do corpo da função
- Não podes colocar um `Chest` sem restrições dentro de um `Just` e esperar que o tipo mude. Tens de criar um valor novo com o construtor `Chest`

## 3. Seleciona os tesouros únicos

- Não existe nenhuma função `List.unique` que possas usar, tens de criar a tua própria
- Uma abordagem possível é usar `List.filterMap` com uma função auxiliar de tipo semelhante ao `secureChest`
- A condição `uniqueTreasure : ()` é acrescentada a partir da assinatura de tipo, não do corpo da função
- Não podes colocar um `Chest` sem restrições dentro de um `Just` e esperar que o tipo mude. Tens de criar um valor novo com o construtor `Chest`

## 4. Aproveita o produto final

- O `makeTreasureChest` deve usar o construtor do tipo `TreasureChest`
