# Introdução

## Módulos

O código Gleam está organizado em módulos, e cada ficheiro é um módulo Gleam.

Até agora, temos escrito funções com a sintaxe `pub fn`, que define uma função disponível publicamente para outros módulos. As funções definidas com `fn` são privadas do módulo onde são definidas e não podem ser usadas por outros módulos.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Os módulos Gleam têm nomes, e o nome baseia-se no caminho do ficheiro dentro do diretório `src` ou `test`.

Por exemplo, um módulo definido em `src\geometry\rectangle.gleam` (no Windows) ou `src/geometry/rectangle.gleam` (em sistemas operativos do tipo UNIX) teria o nome `geometry/rectangle`.

## Importar funções de outros módulos

Acede-se a funções definidas noutros módulos através de importações.
Todas as funções desse módulo que tenham sido expostas por ele ficam acessíveis ao importar esse módulo.
Mas a forma como se acede a elas varia conforme a forma como o módulo é importado.

As importações qualificadas são a predefinição, e aceder a uma função dentro desse módulo (por exemplo, a função `map` no módulo `gleam/list`) faz-se antepondo o nome do módulo (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Por predefinição, o nome usado para se referir ao módulo é a última parte do nome do módulo, neste caso `int`, mas isto pode ser alterado usando a palavra-chave `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

As importações não qualificadas permitem aceder diretamente às funções expostas desse módulo, sem antepor o nome do módulo.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Dá-se preferência às importações qualificadas, pois tornam mais claro para quem lê de onde vem a função e ajudam a evitar conflitos de nomes.


## Biblioteca padrão

O Gleam tem uma biblioteca padrão rica e bem documentada. A documentação está disponível online em [hexdocs.pm/gleam_stdlib][docs]. Guarda este link algures, vais usá-lo imenso!

A maioria dos tipos de dados incorporados tem um módulo correspondente que oferece funções para trabalhar com esse tipo de dados, por exemplo, há o módulo `gleam/int` para inteiros, o módulo `gleam/string` para strings, o módulo `gleam/list` para listas, e assim por diante.

[docs]: https://hexdocs.pm/gleam_stdlib/
