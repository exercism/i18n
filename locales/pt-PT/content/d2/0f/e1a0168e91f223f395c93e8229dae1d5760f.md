# Introdução

Um `Iterator` em Gleam é semelhante a uma lista, na medida em que é uma coleção ordenada de valores, em que todos os valores são do mesmo tipo. Difere de uma lista porque é preguiçoso, ou seja, não guarda todos os seus valores em memória de uma só vez, mas calcula-os à medida que são necessários.

Isto é útil quando trabalhamos com sequências muito grandes ou até de tamanho infinito, pois permite-nos trabalhar com elas quando não temos memória livre suficiente para as guardar todas de uma só vez.

O módulo `gleam/iterator` define o tipo `Iterator`, bem como as funções para trabalhar com iteradores.

Muitas das funções para listas também existem para iteradores, como `map`, `filter` e `take`. Estas funções devolvem iteradores, por isso não fazem nenhum trabalho até o iterador ser consumido.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

A função `unfold` pode ser usada para criar iteradores a partir de uma função que é chamada repetidamente para produzir o valor seguinte da sequência.

Aqui, a função `unfold` é usada para criar um iterador que produz a sequência de Fibonacci:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

A sequência aqui é infinita, por isso a função `take` é usada para a tornar finita antes de recolher os valores numa lista. Se chamarmos `to_list` a um iterador infinito, o programa corre até ficar sem memória e rebenta.
