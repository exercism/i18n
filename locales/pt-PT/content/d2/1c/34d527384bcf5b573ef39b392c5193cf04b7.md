# Dicas

## Geral

- A documentação do pacote `Random` encontra-se [aqui][random-module]

## 1. Começa pelo fim

- Usa a função [`Random.constant`][random-constant]

## 2. Não se apanham moscas com vinagre

- Usa a função [`Random.uniform`][random-uniform] para gerar os tesouros
- Usa a função [`Random.map`][random-map] para envolver o tesouro

## 3. Ramificações

- Usa a função [`Random.int`][random-int] para gerar um valor entre 2 e 4
- Podes usar este valor para criar um `Branch` com a função [`Random.andThen`][random-andThen]
- Usa a função [`Random.list`][random-list] para gerar os ramos
- Usa a função [`Random.map`][random-map] para envolver os ramos

## 4. Labirintos incríveis

- Usa a função [`Random.weighted`][random-weighted] para gerar uma distribuição desigual de resultados
- Usa a função [`Random.lazy`][random-lazy] para usar um gerador de forma recursiva
- Lê mais sobre como definir estruturas de dados recursivas [aqui][bad-recursion]
- Se acabares por definir um gerador aninhado `Generator (Generator Maze)`, podes usar [`Random.andThen`][random-andThen] em conjunto com a função `identity` para o achatar

## 5. Temos de ir mais fundo

- Usa a função [`Random.uniform`][random-uniform] para gerar os becos sem saída ou as salas à profundidade `0`
- Se acabares por definir um gerador aninhado `Generator (Generator Maze)`, podes usar [`Random.andThen`][random-andThen] em conjunto com a função `identity` para o achatar
- Usa a função [`Random.lazy`][random-lazy] para usar um gerador de forma recursiva
- Lê mais sobre como definir estruturas de dados recursivas [aqui][bad-recursion]
