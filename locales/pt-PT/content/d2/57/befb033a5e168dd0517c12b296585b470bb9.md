# Instruções

Neste exercício vais escrever código para te ajudar a cozinhar uma lasanha fabulosa, seguindo o teu livro de receitas preferido.

Tens cinco tarefas, todas relacionadas com o tempo gasto a cozinhar a lasanha.

## 1. Define o tempo esperado no forno em minutos

Define a função `expected_minutes_in_oven`, que não recebe argumentos e devolve quantos minutos a lasanha deve estar no forno. Segundo o livro de receitas, o tempo esperado no forno é de 40 minutos:

```gleam
expected_minutes_in_oven()
// -> 40
```

## 2. Calcula o tempo restante no forno em minutos

Define a função `remaining_minutes_in_oven`, que recebe como argumento os minutos que a lasanha já esteve no forno e devolve quantos minutos a lasanha ainda tem de permanecer no forno, com base no tempo esperado no forno da tarefa anterior.

```gleam
remaining_minutes_in_oven(30)
// -> 10
```

## 3. Calcula o tempo de preparação em minutos

Define a função `preparation_time_in_minutes`, que recebe como argumento o número de camadas que adicionaste à lasanha e devolve quantos minutos gastaste a preparar a lasanha, partindo do princípio de que cada camada te leva 2 minutos a preparar.

```gleam
preparation_time_in_minutes(2)
// -> 4
```

## 4. Calcula o tempo total de trabalho em minutos

Define a função `total_time_in_minutes`, que recebe dois argumentos: o primeiro argumento é o número de camadas que adicionaste à lasanha e o segundo argumento é o número de minutos que a lasanha já esteve no forno. A função deve devolver o número total de minutos que dedicaste a cozinhar a lasanha, ou seja, a soma do tempo de preparação, em minutos, com o tempo, em minutos, que a lasanha esteve no forno até ao momento.

```gleam
total_time_in_minutes(3, 10)
// -> 16
```

## 5. Cria uma notificação de que a lasanha está pronta

Define a função `alarm`, que não recebe argumentos e devolve uma mensagem a indicar que a lasanha está pronta a comer.

```gleam
alarm()
// -> "Ding!"
```
