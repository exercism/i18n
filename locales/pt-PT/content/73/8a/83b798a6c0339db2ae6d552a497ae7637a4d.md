# Introdução

Existem basicamente dois tipos de ciclos:

1. Repetir até que uma condição seja satisfeita.
2. Percorrer os elementos de uma coleção.

Ambos são possíveis em R, embora o primeiro seja provavelmente mais comum.

## `while` e `repeat`

Para problemas em aberto, em que não se sabe de antemão quantas vezes o ciclo vai repetir, R tem o ciclo `while`, com uma condição, e o ciclo `repeat`, sem condição (equivalente a `while (TRUE)`).

A forma básica é bastante simples:

```R
while (condition) {
  do_something()
}
```

Neste caso, o programa continua a repetir o ciclo até que `condition` deixe de ser `TRUE`.

Há duas formas de sair do ciclo antecipadamente:

- Um `break` faz com que o ciclo termine, continuando a execução na linha seguinte à chaveta de fecho do ciclo, `}`.
- Um `return(x)` termina a execução da função atual e devolve o valor `x` a quem a chamou.

Com estas opções disponíveis, às vezes pode ser conveniente criar um ciclo "infinito" com `repeat { ... }` e depois contar com a descoberta de uma condição de paragem dentro do corpo do ciclo para acionar um `break` ou um `return`.

Estas três variantes são equivalentes e todas terminam com `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Iterar sobre um vetor

Muitas vezes isto é desnecessário em R.
Como se explica noutros conceitos, muitas funções operam sobre vetores inteiros.

No entanto, por vezes os ciclos explícitos são inevitáveis.
Isso acontece sobretudo quando:

- O corpo do ciclo tem efeitos secundários, como imprimir ou fazer entrada/saída de ficheiros.
- O ciclo continua até se atingir algum critério, depois de um número imprevisível de iterações.

A condição do ciclo tem de estar entre parênteses.
Tal como acontece nos corpos das funções, as chavetas são opcionais (mas muitas vezes incluídas) nos corpos de ciclo com uma só linha.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Se a iteração atual não satisfizer alguma condição, é possível saltar imediatamente para a iteração seguinte com um `next`:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

Se precisares do índice numérico, usa `seq_along()`.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Usar `i in 1:length(v)` _não_ é recomendado, porque pode causar problemas quando `length(v)` é zero.
O intervalo `1:0` é equivalente a `c(1, 0)`, portanto o corpo do ciclo vai executar-se e provavelmente falhar.
A função `seq_along()` foi concebida para tratar corretamente este caso.
