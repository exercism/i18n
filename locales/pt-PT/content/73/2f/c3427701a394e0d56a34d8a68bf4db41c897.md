# Sobre

[As expressões switch][switch-expressions] comportam-se de forma semelhante às [instruções switch][switch-statements] abordadas em [concept:csharp/switch-statements](). Suportam uma espécie de tabela de decisão que associa condições de entrada a ações ou valores.

No centro da expressão switch está a _correspondência de padrões_. No exercício de programação, fizemos corresponder valores a padrões `const`. Neste caso, as entradas do `switch` são uma _expressão de intervalo_, que é comparada com valores const, e os valores usados pelas _guardas de caso_.

Os casos (também conhecidos como _braços do switch_) são avaliados pela ordem em que aparecem no texto, e o processo é interrompido assim que se encontra uma correspondência, devolvendo o valor associado.

O caso `_`, que é o último da lista, é útil para garantir que a correspondência é exaustiva e para evitar possíveis erros de execução.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

Um "braço" do `switch` é selecionado quando o padrão corresponde à variável de intervalo e qualquer guarda de caso é avaliada como verdadeira.

As expressões switch também suportam [padrões de tipo][pattern-matching] e correspondência recursiva.
