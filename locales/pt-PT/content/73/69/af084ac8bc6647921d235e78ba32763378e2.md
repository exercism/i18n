# Instruções

Trabalhas como administrador de sistemas numa grande empresa em Munique, na Alemanha. Uma das tuas responsabilidades é gerir contas de email.

Tens ouvido queixas de pessoas que dizem não conseguir enviar emails ao Sr. Müller. Percebes rapidamente que a maior parte da empresa usa um cliente de email antigo que não reconhece `müller@firma.de` como um endereço de email válido, por causa do caráter não-ASCII.

Dizer às pessoas para abandonarem o seu cliente de email antigo preferido é uma batalha perdida, por isso decides criar aliases sanitizados para todas as contas de email.

## 1. Sanitiza os nomes de utilizador existentes removendo tudo exceto as letras minúsculas

Implementa a função `sanitize/1`. Deve aceitar um nome de utilizador como uma charlist e devolver o nome de utilizador sem todos os carateres que não sejam letras minúsculas.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. Permitir underscores

Estende a função `sanitize/1`. Não deve remover os underscores do nome de utilizador.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. Substituir carateres alemães

Há 4 carateres não-ASCII no alfabeto alemão, e todos eles têm substitutos ASCII amplamente reconhecidos.

| Caráter alemão | Substituto ASCII |
| -------------- | ---------------- |
| ä              | ae               |
| ö              | oe               |
| ü              | ue               |
| ß              | ss               |

Estende a função `sanitize/1`. Deve substituir os carateres alemães de acordo com a tabela. Podes assumir com segurança que todos os nomes de utilizador já estão em minúsculas.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
