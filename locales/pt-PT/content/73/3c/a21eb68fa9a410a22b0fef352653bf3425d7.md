# Testes

Podes usar o editor online do site do Exercism para resolveres os exercícios.
Ou podes descarregar os exercícios para o teu computador, resolvê-los localmente e depois submetê-los ao Exercism.
O resto deste documento fala sobre trabalhar localmente.

## CLI do Exercism

Vais precisar da ferramenta de linha de comandos `exercism` para descarregar e submeter exercícios.
Consulta [a documentação da CLI do exercism][exercism-cli] para instruções sobre como descarregá-la e configurá-la.

Para descarregares um exercício, faz assim:

```bash
exercism download --track 8th --exercise hello-world
```

E muda para o diretório do exercício:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

ou, se estiveres no Windows:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

Repara que podes obter o teu espaço de trabalho do exercism com o comando `exercism configure`.

## Testar localmente

Para correres os testes de um exercício, tens de estar no diretório correto do exercício.
Depois, lança os testes com este comando:

```bash
8th -f test.8th
```

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem.
Por predefinição, só um teste (o primeiro) é executado quando corres os testes.
Isto é intencional: assim podes concentrar-te apenas em fazer esse teste passar.
Assim que passar, podes ativar o teste seguinte movendo a linha `SKIP-REST-OF-TESTS` para baixo dele.

### Anular os testes ignorados

Para correres todos os testes, incluindo os que vêm depois da palavra `SKIP-REST-OF-TESTS`, podes definir a variável de ambiente `RUN_ALL_TESTS` com o valor `true`.
Uma forma de o definires apenas durante a execução dos testes é (macOS e Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## Submete a tua solução

Para carregares a tua solução para o site do Exercism com a ferramenta exercism:

```bash
exercism submit
```

Repara que podes carregar o teu código mesmo que não esteja a passar em todos os testes.
Isto é útil se estiveres bloqueado e precisares de ajuda de um mentor.
