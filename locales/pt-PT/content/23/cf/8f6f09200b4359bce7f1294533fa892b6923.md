# Testes

Há uma configuração inicial para cada exercício, que pode demorar alguns minutos:

```
npm install
```

Abre dois terminais e, no primeiro, inicia o processo de compilação.

```
npm start
```

No segundo, põe os testes a correr.

```
npm test
```

À medida que editas o código, os dois processos vão recompilar e voltar a correr os testes continuamente.
