# Instruções

Como aprendiz de maga, a Elyse precisa de analisar o seu baralho de várias formas diferentes.
Para simplificar, só usa cartas com valores de 1 a 10.

## 1. Determinar quantas cartas de um certo tipo há no baralho

A Elyse quer saber quantas cartas de um determinado tipo tem no seu baralho.

Escreve uma função `cardTypeCheck` que recebe dois parâmetros: um array de cartas (o baralho da Elyse) e o tipo de carta a contar.

<!--prettier-ignore -->
~~~exercism/note
A função deve usar `forEach` e devolver o número de cartas do tipo indicado que existem no baralho.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. Determinar quantas cartas ímpares ou pares há

Para outro truque, a Elyse precisa de saber quantas cartas ímpares ou pares há no seu baralho.

Implementa uma função `determineOddEvenCards` que recebe dois parâmetros: um array de cartas (o baralho da Elyse) e um boolean (true corresponde a «par» e false corresponde a «ímpar»).

Esta função deve devolver um único número: o número de cartas ímpares ou pares que há no baralho (consoante o valor do segundo argumento).

<!--prettier-ignore -->
~~~exercism/note
Para praticar, usa desta vez um ciclo `for...of` na implementação da função.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
