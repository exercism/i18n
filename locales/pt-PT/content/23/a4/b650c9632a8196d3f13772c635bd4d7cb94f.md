# Introdução

Os [tuplos][tuples] agrupam vários valores num único valor composto.
Ao contrário dos arrays, os valores de um tuplo não precisam de partilhar o mesmo tipo, e o tamanho de um tuplo é fixo depois de criado.

Cria um tuplo colocando valores separados por vírgulas entre parênteses:

```swift
let order = ("biscuits", 2.99, 3)
```

Também podes especificar anotações de tipo explicitamente:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Para extrair elementos individuais de um tuplo sem nomes, usa a sintaxe de índices a partir do zero (`.0`, `.1`, etc.):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Tuplos com nomes

Podes dar nomes a elementos individuais do tuplo ao defini-lo:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Dar nomes aos elementos torna o código mais legível e permite-te aceder aos elementos com a notação de ponto e as respetivas etiquetas:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

Também podes incluir os nomes dos elementos na anotação de tipo:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Modificar tuplos

Se um tuplo for declarado como variável (`var`), podes atualizar os seus elementos:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Devolver vários valores

Embora as funções Swift só possam devolver um único valor, devolver um tuplo permite-te agrupar e [devolver vários valores][multiple-return-values] a partir de uma função:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Decomposição de tuplos

Podes decompor (desempacotar) os valores de um tuplo em constantes ou variáveis separadas:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

A decomposição de tuplos também funciona diretamente em ciclos `for-in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
