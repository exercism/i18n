# Testes

## Linha de comandos

Podes usar o seguinte comando para correr os testes a partir da linha de comandos:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Substitui `<exercise>` pelo nome do exercício que estás a implementar.

## Modo interativo

Para correr o Prolog de forma interativa, começa por executar:

```bash
swipl
```

Depois de a consola do Prolog arrancar, carrega a tua implementação e corre os testes com:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Substitui `<exercise>` pelo nome do exercício que estás a implementar.

### Recarregar alterações

Depois de os ficheiros acima estarem carregados, podes aplicar as alterações que fizeste executando:

```
?- make.
```

## Testes ignorados

Quando começas um exercício, só o primeiro teste é que corre. Os restantes foram ignorados ao acrescentar `condition(pending)` ao objetivo `test`. Assim que o primeiro teste passar, volta a ativar o teste seguinte, mudando `pending` em `condition(pending)` para `true`. Repete para cada teste até estarem todos a correr e a passar.

### Linha de comandos

Acrescenta o argumento `-- --all` ao fim do comando para correr também os testes pendentes:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
