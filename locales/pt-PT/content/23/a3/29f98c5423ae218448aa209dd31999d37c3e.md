# Auditoria de Pagamentos na Base de Dados

## Enunciado do problema

A ABC Corp precisa que carregues todos os dados da base de dados SQL para uma [tabela Ballerina](https://ballerina.io/learn/by-example/table-syntax/) para processamento posterior. De seguida, tens de encontrar os nomes dos empregados que têm registos de pagamento superiores a um determinado valor (por exemplo, 3000.00), consultando a tabela Ballerina carregada.

**Passo 1:**

Cria uma tabela Ballerina com as seguintes colunas.

`payment_id` - integer

`amount` - decimal

`employee_name` - string

**Passo 2:**

Preenche a tabela Ballerina acima carregando o conjunto de dados completo correspondente na base de dados H2. Usa o `payment_id` como chave primária da tabela.

**Passo 3**

Consulta a tabela Ballerina com expressões de consulta Ballerina para encontrares os nomes dos empregados que têm registos de pagamento superiores ao valor indicado. Ordena o resultado pelo nome do empregado por ordem crescente. Remove os nomes duplicados do resultado antes de o devolveres.

> Nota: é obrigatório usar uma tabela Ballerina para implementar a solução.

## Detalhes da base de dados

Usa a base de dados H2 fornecida para este problema.

> O ficheiro da base de dados de exemplo é `gofigure.mv.db` e o nome da base de dados é `gofigure`. Encontra-se na pasta `db`.

As tabelas seguintes já existem na base de dados H2 de exemplo, com alguns dados de exemplo. Os nomes das colunas e os tipos de dados são indicados abaixo.

**Nome da tabela**: `Employee`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | integer, chave primária com incremento automático       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | integer       |

**Nome da tabela**: `Payment`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | integer, chave primária com incremento automático       |
| `date`            | date        |
| `amount`          | decimal        |
| `employee_id`     | integer        |
| `reason`          | string        |

* O ficheiro da base de dados é `gofigure.mv.db`. Usa o URL JDBC como `jdbc:h2:file:/path/to/db/file`
* Nome de utilizador: `root`
* Palavra-passe: `root`

## Restrições

* Usa o ficheiro da base de dados H2 fornecido na pasta `db` para validares as consultas e a amostra Ballerina
* Usa a abordagem dos parâmetros de dependência do Maven para adicionares o controlador da base de dados H2 como dependência de plataforma no teu Ballerina.toml

## Ambiente de testes

* Podes executar os testes com `bal test` e serão executados testes contra a base de dados de exemplo indicada.
