# Dicas

## 1. Criar uma peça de roupa

- Algumas funções podem ser usadas com a sintaxe de compreensão para as construir.
- `Dict` é uma dessas funções; revê as **Expressões geradoras** na introdução.
- A categoria no índice `i` corresponde à qualidade no índice `i` (o [eachindex()][index] pode ser útil)

## 2. Sugerir combinações

- Existe uma sintaxe sucinta para criar arrays multidimensionais a partir de uma compreensão.
- Revê **Várias variáveis e resultado multidimensional** na introdução
- Certifica-te de que a ordem dos teus iteradores (`tops` / `bottoms`) está correta.

## 3. Somar os preços dos conjuntos

- Vais ter de aceder ao preço de ambas as peças de roupa e somá-los.
- Certifica-te de que a forma do array de saída é igual à forma do array de entrada.
- Revê **Uma única variável** na introdução.

## 4. Filtrar os conjuntos que não combinam

- Vais ter de comparar o `base_color` de ambas as peças de roupa e descartar os conjuntos que têm o mesmo `base_color`.
- Com um `Matrix` como valor de entrada, certifica-te de que o resultado está na ordem mais eficiente (ou seja, em ordem por colunas).
- Revê **Uma única variável** na introdução.

[index]: https://docs.julialang.org/en/v1/base/arrays/#Base.eachindex
