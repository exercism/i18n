# Sobre

Um [`Attribute` de C#][attribute-concept] é uma forma de decorar uma declaração para lhe associar metadados: uma classe, um método, um enum, um campo, uma propriedade ou quaisquer [outras declarações suportadas][attribute-targets].

Podes aplicar [um atributo][attribute] a uma declaração, colocando-o entre parênteses retos `[]` antes da declaração. O exemplo seguinte usa tanto um `ClassAttribute` como um `FieldAttribute`:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

Os metadados declarativos apenas associam informação estruturada adicional ao código e não modificam o seu comportamento. No entanto, outras partes do código usam esses metadados para alterar o comportamento do seu alvo ou para adicionar, alterar, remover ou restringir algumas das suas funcionalidades.

Existem vários atributos predefinidos, como `Flags`, `Obsolete` e `Conditional`. Repara que o nome completo do [atributo `Flags`][flags-attribute] é `FlagsAttribute`, mas o sufixo «Attribute» pode ser omitido quando se usa o atributo.

Os quatro atributos predefinidos seguintes são usados regularmente:

- `[Flags]`: predefinido no namespace System. Indica que o enum suporta tanto operações bit a bit como o método `Enum.HasFlag()`; além disso, o `ToString` apresenta todas as flags: [vê o exemplo][flags-example].
- `[Obsolete]`: predefinido no namespace System. Permite adicionar uma mensagem sobre a razão pela qual o código está obsoleto; pode ser usado para apresentar avisos ou erros do compilador.
- `[Conditional]`: predefinido no namespace System.Diagnostics. Permite remover algumas chamadas de métodos em tempo de compilação com fins de depuração (diagnóstico).
- `[CallerMemberName]`: predefinido no namespace System.Runtime.CompilerServices. Permite que um método obtenha informação sobre quem o chama.
