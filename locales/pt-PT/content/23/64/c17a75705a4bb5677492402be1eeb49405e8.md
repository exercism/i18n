# Sobre

O `jq` é uma ferramenta para analisar e transformar dados JSON.
O `jq` é como o `sed` para dados JSON: podes usá-lo para cortar, filtrar, mapear e transformar dados estruturados com a mesma facilidade com que o `sed`, o `awk`, o `grep` e companhia te deixam brincar com texto.

O `jq` é uma linguagem de programação funcional com tipagem dinâmica.
Todos os valores são imutáveis.

Os programas em `jq` são compostos por pipelines de «filtros»: cada filtro recebe um único item como valor de entrada, atua sobre ele e produz zero ou mais elementos transformados.
Um «filtro» também pode ser chamado de «expressão».

As saídas de uma expressão podem ser passadas para outra usando o operador `|`.
`expressionA | expressionB` aplica `expressionA` a um valor de entrada e, em seguida, `expressionB` executa-se repetidamente para cada uma das saídas de `expressionA`.

O valor de entrada de uma expressão pode ser referido explicitamente como `.`.
Uma expressão que soma `1` ao seu valor de entrada escreve-se assim: `. + 1` (ou `1 + .`).

## `jq` (o programa) versus `jq` (a linguagem)

O `jq` é um programa que podes instalar como pacote em vários sistemas operativos ou compilar a partir do código-fonte (está escrito em C).
Tem várias [opções de linha de comandos][cli-options] úteis e é bastante rápido.

O programa `jq` também implementa uma _linguagem_ que permite manipulações arbitrariamente complexas dos dados de entrada.

Este percurso do Exercism vai focar-se na linguagem.
Vais ver utilizações do programa `jq` nos testes.

## JSON

De [json.org][json]:

> O JSON (JavaScript Object Notation) é um formato leve de intercâmbio de dados.
> É fácil de ler e escrever para humanos.
> É fácil de analisar e gerar para as máquinas.
> Baseia-se num subconjunto da norma ECMA-262, 3.ª edição, de dezembro de 1999, da Linguagem de Programação JavaScript.
> O JSON é um formato de texto completamente independente da linguagem, mas que usa convenções familiares aos programadores da família de linguagens C, incluindo C, C++, C#, Java, JavaScript, Perl, Python e muitas outras.
> Estas propriedades fazem do JSON uma linguagem ideal para o intercâmbio de dados.

Este percurso é sobre o `jq`, não sobre o JSON.
Vamos assumir que já conheces a [sintaxe e os tipos de dados do JSON][wiki-json].
