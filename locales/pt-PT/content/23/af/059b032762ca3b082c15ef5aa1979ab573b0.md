# Introdução

A herança é um conceito fundamental na POO (Programação Orientada a Objetos).
Representa uma relação é-um.
Em programação, significa literalmente o mesmo que em inglês: herdar caraterísticas do progenitor (em programação, essas caraterísticas são normalmente funções e variáveis).

Considera uma classe, `Animal`, como se mostra a seguir,

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` é uma classe mãe, porque as propriedades que esta classe tem podem ser estendidas a todos os animais em geral.

Considera um animal chamado `Lion`, com uma classe como esta,

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
A anotação `Override` serve para indicar que um método numa subclasse está a sobrepor um método da sua superclasse.
Não é estritamente necessária, mas é boa prática usá-la.
~~~~

Agora, sempre que fizermos,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Repara que estamos a inicializar a classe `Animal` com `Lion`.
A saída será parecida com isto

```java
Lion here!!
```

De acordo com a POO, existem muitos tipos de herança, mas o Java só suporta alguns deles (multinível e hierárquica).
Para saberes mais sobre isto, lê [isto][java-inheritance].
