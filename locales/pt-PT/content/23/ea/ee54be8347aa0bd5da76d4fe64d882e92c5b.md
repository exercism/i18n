# Introdução

Os [Arrays][arrays-concept] têm métodos incorporados para analisar o conteúdo do array.
A maioria destes métodos recebe como argumento uma função que devolve true ou false.
Uma função deste tipo chama-se [`predicate`][predicate_in_programming].

Estes métodos incorporados servem para serem usados _em vez de um ciclo `for`_ ou do método incorporado `forEach`:

Exemplo de análise com um ciclo for:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Exemplo de análise com um método incorporado:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Abaixo mostramos outros métodos incorporados úteis que podes usar para analisar um array. Consulta a [MDN][mdn-array-methods] para veres a lista completa dos métodos de arrays.

## `includes`

> O método includes() determina se um array inclui um determinado valor entre os seus elementos, devolvendo true ou false conforme o caso. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> O método every() testa se todos os elementos do array passam no teste implementado pela função fornecida. Devolve um valor Boolean. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> O método some() testa se pelo menos um elemento do array passa no teste implementado pela função fornecida. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> O método find() devolve o valor do primeiro elemento do array fornecido que satisfaz a função de teste fornecida. Se nenhum valor satisfizer a função de teste, é devolvido undefined. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> O método findIndex() devolve o índice do primeiro elemento do array que satisfaz a função de teste fornecida. Caso contrário, devolve -1, o que indica que nenhum elemento passou no teste. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
