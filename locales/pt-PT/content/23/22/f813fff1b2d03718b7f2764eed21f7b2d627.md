# Introdução

Esta semana, é a tua vez de tomar notas na reunião de planeamento do departamento.
Nesta reunião, o teu chefe vai definir datas de entrega para todos os itens de trabalho em aberto.
O mais irritante é que, em vez de especificar as datas de entrega _reais_, o teu chefe vai apenas _descrevê-las_ num formato abreviado.
Como muitos dos teus colegas não estão familiarizados com este jargão empresarial, vais ter de converter estas descrições de datas de entrega em datas de entrega reais.
