# Classes e propriedades readonly

As classes e propriedades readonly permitem que as classes especifiquem propriedades públicas de fácil acesso, mas impedem a modificação dessas propriedades.
Para declarar uma propriedade como readonly, é preciso acrescentar `readonly` antes da especificação do tipo.
A propriedade pode ser atribuída uma vez, mas qualquer tentativa de a reatribuir ou modificar o valor resulta num Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

As classes readonly baseiam-se neste comportamento: se forem declaradas como `readonly`, a declaração readonly aplica-se a cada propriedade.
Além disso, impede a adição de propriedades dinâmicas.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
