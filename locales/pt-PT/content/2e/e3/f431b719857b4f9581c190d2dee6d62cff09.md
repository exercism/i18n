# Apêndice às instruções

## Nota

Este tipo de problemas (em que uma resposta depende de uma anterior) é frequentemente designado por recursão.
Há diferentes formas de implementar recursão; se não estiveres familiarizado com isto, pode valer a pena pesquisar sobre o assunto.
O Pharo está bem otimizado para recursão, e este é um padrão muito utilizado.

Nota: na especificação original do problema, o grainsCalculator é chamado através de #square; no entanto, mudámos o nome deste método para #atSquare:, que é um nome mais ao estilo de Smalltalk e que descreve melhor que estás a pedir uma resposta "numa casa".
