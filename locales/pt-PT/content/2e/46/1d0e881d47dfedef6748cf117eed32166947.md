# Dicas

## Geral

- [Dicionários no The Cairo Book][book]
- [Guia rápido do Cairo][cheatsheet]

## 1. Guarda a unidade de medida no teu programa

- Para guardar as medições no teu programa, podes inseri-las uma a uma num dicionário

## 2. Cria uma nova conta

- Para criar uma nova conta, só precisas de inicializar um dicionário

## 3. Adiciona um artigo à conta do cliente

- Para verificar se a unidade de medida indicada está correta, podes testar se o teu dicionário de medições devolve um valor diferente de zero para uma chave

## 4. Remove um artigo da conta do cliente

- Para verificar se o artigo indicado está na conta do cliente, podes testar se o teu dicionário da conta devolve um valor diferente de zero para uma chave

- Para verificar se a unidade de medida indicada está correta, podes testar se o teu dicionário de medições devolve um valor diferente de zero para uma chave

## 5. Devolve o número de um artigo específico que está na conta do cliente

- Para verificar se o artigo indicado está na conta do cliente, podes simplesmente obtê-lo do dicionário
