# Instruções

Neste exercício vais escrever código para manteres o registo de uma lista de linguagens de programação que queres aprender no Exercism.

Tens seis tarefas, e todas elas envolvem lidar com listas.

## 1. Cria uma nova lista

Para manteres o registo das linguagens que queres aprender, vais precisar de criar uma nova lista. Define a função `new_list`, que devolve uma lista nova e vazia.

```gleam
new_list()
// -> []
```

## 2. Define uma lista existente

De momento, tens uma folha de papel com as linguagens que queres aprender: Gleam, Go e TypeScript. Define a função `existing_list` para devolver esta lista.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. Adiciona uma nova linguagem a uma lista

À medida que exploras o Exercism e encontras linguagens mais interessantes, queres adicioná-las à tua lista. Implementa a função `add_language` para adicionar uma nova linguagem ao início da tua lista.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. Conta as linguagens da lista

Contar as linguagens uma a uma é inconveniente. Implementa a função `count_languages` para contar o número de linguagens da tua lista.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. Inverte a lista

A dada altura, dás conta de que a tua lista está, na verdade, ao contrário! Implementa a função `reverse_list` para inverteres a tua lista.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. Verifica se a lista é entusiasmante

Embora gostes de todas as linguagens, o Gleam tem um lugar especial no teu coração. Por isso, ficas mesmo entusiasmado com uma lista de linguagens se:

- A primeira da lista for Gleam.
- O segundo item da lista for Gleam e a lista tiver duas ou três linguagens.

Implementa a função `exciting_list` para verificar se uma lista de linguagens é entusiasmante:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
