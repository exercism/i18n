# Introdução

Embora o modificador `readonly` impeça que o valor ou a referência de um campo seja sobrescrito, não oferece qualquer proteção para os membros de um tipo de referência.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Para garantir que todos os membros de um tipo de referência ficam protegidos, os campos podem ser tornados `readonly` e as propriedades automáticas podem ser definidas sem um acessador `set`.

A Biblioteca de Classes Base (BCL) fornece algumas versões só de leitura de coleções quando é necessário impedir que os membros de uma coleção sejam atualizados. Estas surgem sob a forma de wrappers:

- O `ReadOnlyDictionary<T>` expõe um `Dictionary<T>` como só de leitura.
- A `ReadOnlyCollection<T>` expõe uma `List<T>` como só de leitura.
