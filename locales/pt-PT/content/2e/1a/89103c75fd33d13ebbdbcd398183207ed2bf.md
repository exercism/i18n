# Fluxo de trabalho do configlet

O configlet usa a [ferramenta configlet](/docs/building/configlet) para verificar se os ficheiros (de configuração) de um percurso estão estruturados corretamente, tanto a nível sintático como semântico.
Faz isso executando o [`configlet lint`](/docs/building/configlet/lint).

## Ativar a verificação da formatação dos ficheiros

Os percursos podem usar o [`configlet fmt`](/docs/building/configlet/format) para formatar os vários ficheiros de configuração do percurso.
O mesmo comando também pode ser usado para verificar se todos os ficheiros de configuração estão formatados corretamente.

O fluxo de trabalho `configlet` permite verificar se os ficheiros de configuração estão formatados corretamente, mas isto é opcional e está desativado por predefinição.
Para aderir à verificação da formatação dos ficheiros de configuração, segue estes passos:

1. Cria um ficheiro `.github/org-wide-files-config.toml` com o seguinte conteúdo

```toml
[configlet]
fmt = true
```

2. Depois de este ficheiro ser integrado no ramo `main`, será aberto automaticamente um PR que modifica o fluxo de trabalho `configlet.yml` da seguinte forma:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. Assim que este PR for integrado, o fluxo de trabalho `configlet` também verificará a formatação dos ficheiros de configuração do percurso.

## Fonte

O fluxo de trabalho está definido no ficheiro `.github/workflows/configlet.yml`.
