# Dicas

## Geral

- Para trabalhar com a classe `DateTime`, é preciso _abrir_ o espaço de nomes `System`.

## 1. Analisar a data da marcação

- A classe `DateTime` tem um método para [analisar][parsing] uma `string` e obter um `DateTime`.

## 2. Verificar se uma marcação já passou

- Os objetos `DateTime` podem ser comparados com os [operadores de comparação][operators] predefinidos.
- Há uma [propriedade][properties] para obter a data e a hora atuais.

## 3. Verificar se a marcação é à tarde

- Podes aceder à parte relativa à hora de um objeto `DateTime` através de uma das suas [propriedades][properties].

## 4. Descrever a hora e a data da marcação

- Os testes correm como se estivessem numa máquina nos Estados Unidos, o que significa que converter um `DateTime` numa `string` devolve datas e horas no formato dos Estados Unidos.
- Há um [método incorporado][to-string] para converter uma instância de `DateTime` numa `string`. Se estiveres a usar `sprintf`, em vez de usares o marcador de posição `%s`, há [outro marcador de posição][object-placeholder] que chama automaticamente o método acima referido.

## 5. Devolver a data de aniversário

- Usa um dos vários [construtores][constructors] de `DateTime` para criar uma nova instância de `DateTime`.
- Podes usar uma das [propriedades][properties] da data e hora atuais para obter o ano atual.
