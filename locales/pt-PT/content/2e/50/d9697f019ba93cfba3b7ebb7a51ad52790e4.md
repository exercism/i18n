# Introdução

Em F#, atribuir um valor a um nome designa-se por _associação_. As associações são imutáveis, o que as torna semelhantes às constantes de outras linguagens. Como o F# é uma linguagem estaticamente tipada, cada associação tem um tipo em tempo de compilação.

As associações definem-se com a palavra-chave `let`. Na maioria das associações, indicar o tipo é opcional, pois a _inferência de tipos_ do F# consegue normalmente inferi-lo a partir do valor. Uma associação tem este aspeto:

```fsharp
// Automatically inferred type
let fingers = 10
```

As funções também são associações normais, mas com um ou mais parâmetros. Uma função devolve automaticamente a sua última expressão. A inferência de tipos também funciona para a maioria das funções, analisando com que valores a função é chamada e que valor devolve.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Invocar uma função consiste em indicar o nome dela e passar argumentos para cada um dos parâmetros da função.

```fsharp
let five = add 2 3
```

Se o tipo de uma associação não puder ser inferido, o compilador reporta um erro. Para resolver isto, adiciona uma anotação de tipo explícita à associação.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Em F#, só podes usar uma associação _depois_ de a teres definido. Usar uma associação antes de a definires dá origem a um erro de compilação.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

O F# usa espaços significativos para definir o âmbito. Isto significa que o âmbito é definido pela indentação do código com espaços, em relação à linha que declara a associação. A convenção predefinida é usar quatro espaços de indentação:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

As associações do F# (que incluem as funções) organizam-se normalmente em módulos. Um módulo agrupa funcionalidades relacionadas e define-se com a palavra-chave `module`. A definição do módulo tem de vir antes das suas associações:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

O F# suporta dois tipos de comentários. Os comentários de uma linha são precedidos de `//` e os comentários de várias linhas são inseridos entre `(*` e `*)`.
