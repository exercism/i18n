# Exceções

```sather
   raise "Unknown prop: " + prop;
```

```sather
   protect
      ...
   when $STR then
      #OUT + exception.str;
   end;
```

## raise

O `raise` aceita qualquer objeto. Lançar um `STR` é o caso simples e é o que
este exercício usa. Uma classe tua transporta mais informação, como que prop
e quantos eram esperados, mas obriga-te a ter um sítio onde a definir.

Uma exceção propaga-se para fora através de quem chama até que um `protect`
a capture. Se nenhum o fizer, o programa para e imprime-a.

O Sather não registra que exceções uma rotina pode lançar, nem obriga quem
chama a tratá-las. Nada no tipo de uma rotina indica que ela pode falhar.

## protect

```sather
   protect
      body
   when $STR then
      ...
   when SOME_CLASS then
      ...
   end;
```

Os ramos são testados por ordem, e executa-se o primeiro cujo tipo corresponde
ao valor lançado. `exception` é esse valor e só existe no âmbito dentro de um
ramo.

Um `protect` sem nenhum ramo correspondente não captura: a exceção continua a
propagar-se para fora como se o `protect` não estivesse lá.

## Onde capturar

Captura onde se possa fazer alguma coisa de facto. Um `protect` que engole uma
exceção e continua com um valor inventado transforma uma falha ruidosa numa
resposta errada silenciosa, o que é pior.

```sather
   -- almost always wrong
   protect
      return risky;
   when $STR then
      return 0;
   end;
```

## Exceções ou contratos?

Ambos dizem respeito a coisas que correm mal, mas servem para casos opostos.

Uma **exceção** serve para algo que pode mesmo acontecer e que quem chama pode,
com razão, não ter conseguido evitar: um prop em falta na tabela, um ficheiro
que não existe.

Um **contrato**, que é o próximo exercício, serve para algo que nunca deve
acontecer, como quem chama passar um peso negativo, e é a afirmação de que quem
chama tem um bug. Os contratos só são verificados quando é pedido, e um contrato
violado para o programa em vez de lançar algo que se possa capturar.

Resumindo: se quem chama com cuidado ainda puder deparar-se com isso, lança. Se
deparar-se com isso significa que quem chama está errado, põe-no num contrato.
