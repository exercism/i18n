# Instruções

Neste exercício vais trabalhar mais um pouco com carros de controlo remoto.

Foi desenvolvido um carro experimental e a pista de testes precisa de ser adaptada para suportar tanto os modelos de produção como os experimentais. Os dois tipos de carro já foram construídos e precisas de encontrar uma forma de lidar com ambos na pista de testes.

Além disso, os carros de produção começam a ter algum sucesso. O chefe de equipa faz questão de manter o espírito competitivo, publicando uma classificação dos carros de produção.

## 1. Permitir que os carros sejam conduzidos na mesma pista de testes

Adiciona um método à interface `IRemoteControlCar` para expor as implementações de `Drive()` dos dois tipos de carro.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. Permitir que a distância percorrida pelos diferentes modelos na pista de testes seja comparada

Adiciona uma propriedade à interface `IRemoteControlCar` para expor as implementações da propriedade `DistanceTravelled` dos dois tipos de carro.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. Permitir classificar os carros de produção

Implementa a interface `IComparable<T>` na classe `ProductionRemoteControlCar`. A ordem de ordenação predefinida dos carros deve ser a ordem crescente de vitórias.

Implementa o método estático `TestTrack.GetRankedCars()` para devolver os carros recebidos ordenados por ordem crescente do número de vitórias.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
