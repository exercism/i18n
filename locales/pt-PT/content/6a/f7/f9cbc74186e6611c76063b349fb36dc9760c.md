# Introdução

Em JavaScript, as _template strings_ permitem incorporar expressões em strings, o que também se designa por interpolação de strings.
Esta funcionalidade acrescenta capacidades ao objeto global [`String`][string-reference] incorporado.

Crias template strings em JavaScript envolvendo o texto em acentos graves.
Além de permitirem que o texto inclua novas linhas e outros carateres especiais, também podes incorporar variáveis e outras expressões.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

No exemplo acima, os acentos graves - (<code>\`\`</code>) - são usados para representar uma template string. O `${...}` é o marcador de posição usado para substituição.
Qualquer tipo que não seja uma string é convertido _implicitamente_ numa string.
Este tópico é abordado no conceito [conversão de tipos][type-conversion-concept].
Podes usar todos os tipos de expressões com template strings.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Quando precisas de formatar strings em várias linhas:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Se quiseres representar uma nova linha dentro de uma string normal em vez de usares uma template string (ou seja, sem usares acentos graves), podes usar a sequência de escape de nova linha `\n`:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

Com as capacidades de substituição disponíveis, também podes introduzir lógica no processo para determinar qual deve ser a string final.
Uma forma de tratar essa lógica é usar o [operador ternário][ternary-operator].
Isto dá a mesma funcionalidade condicional `if/else`, num formato ligeiramente diferente.

Para implementar lógica na sintaxe das template strings:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
