Para manter a quantidade de trabalho gerível, este documento contém uma pequena seleção de possibilidades. As soluções com Crossbeam têm um conjunto de conceitos semelhante ao que aqui se apresenta, e o Rayon exige apenas um subconjunto.

## Geral

- Strings: mais concretamente, o `str` é sempre um fator aqui
- Unicode: compromissos de desempenho e funcionalidades entre métodos ASCII e métodos Unicode. A medição de desempenho fica distorcida quando o benchmark usa métodos Unicode e a solução usa métodos ASCII.
- Iteradores: iterar sobre a entrada ou sobre pedaços dela.
- Coleções: iterar sobre um `HashMap` e usar `Entry`. Habitualmente, os handles são reunidos num `Vec`.
- Referências
- Números: em concreto, o trait `Add`
- Ciclo `for`: não é possível juntar threads num iterador por causa do `move`.
- **Opcional** Visibilidade: manter os detalhes de implementação não públicos
- **Opcional** slices: `.chunks()` é um método muito utilizado para dividir a entrada pelas threads de trabalho. Em alternativa, usam-se subslices.
- **Opcional** Funções de ordem superior: os HashMaps podem ser combinados por uma função de ordem superior com um iterador.
- **Opcional** Tipos: para dividir a entrada, podemos converter inteiros em valores de vírgula flutuante para aplicar arredondamento
- **Opcional** Crates

## Abordagem com a std, com ou sem canais

- Paralelismo - subtema criar/juntar threads.
- Iteradores - subtema avaliação preguiçosa: criar e juntar threads com o mesmo iterador impede o paralelismo.
- Tempos de vida - subtemas `'static lifetime` e semântica `move` explícita
- Iteradores/tempos de vida - subtema iteradores consumidores: não é possível juntar threads com um iterador.
- Tipo Option: desembrulhar os resultados das threads ou dos canais
- Funções: em concreto, as funções de ordem superior são necessárias para criar threads. As closures são uma opção aqui.

## Abordagem com a std e canais

- Paralelismo - subtema canais.
- Tuplas: `mpsc::channel()` devolve uma tupla
- Desestruturação: a tupla pode ser desestruturada na atribuição
- Tempos de vida: `drop()`

## Abordagem alternativa com variáveis partilhadas

- Contagem de referências: partilhar dados agregados entre threads com uma coleção com contagem de referências.
- **Menção honrosa**: Paralelismo - subtema mutexes. Não é necessário/útil para este exercício, mas é, ainda assim, um conceito comum. Relacionado: `RwLock`.

### Exemplo com a std e canais

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### Exemplo de crate com Arc

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
