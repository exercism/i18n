# Anexo às instruções

## Formato de entrada/saída

A função recebe uma única string de palavras, cada uma terminada por uma quebra de linha.

A primeira é a palavra da qual as restantes devem ser anagramas.

Devolve uma string com todos os anagramas válidos, cada um terminado por uma quebra de linha.


## Endereços reservados

O buffer para a string de entrada usa os bytes 64-319 da memória linear.

Podes modificar este buffer no próprio local se quiseres evitar alocações de memória adicionais.
