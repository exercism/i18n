# Instruções

Chamar APIs pode dar origem a erros quando usas texto em bruto ou JSON. Neste exercício, vais usar Ballerina Records para organizar os dados dos pedidos e garantir que a comunicação com serviços de reserva externos corre bem.

## Objetivos

- Modifica o código fornecido.
- Reserva um bilhete de avião para o utilizador através do serviço de reservas da companhia aérea. Envia um pedido POST a airlineReservationService com os dados adequados e recebe uma resposta.
- Reserva um quarto de hotel para o utilizador através do serviço de reservas de hotel. Envia um pedido POST a hotelReservationService com os dados adequados e recebe uma resposta.
- Aluga um carro para o utilizador através do serviço de aluguer de automóveis. Envia um pedido POST a carRentalService com os dados adequados e verifica a resposta.
- Se tudo correr bem, devolve um corpo com um atributo message com o valor "Congratulations! Your journey is ready!!".
