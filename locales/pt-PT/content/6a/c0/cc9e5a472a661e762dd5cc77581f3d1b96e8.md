# Dicas

## Geral

- Lê sobre as strings no [guia oficial de primeiros passos][getting-started-strings].
- Explora as [funções disponíveis no _módulo String_][string-module-functions] para descobrires que operações sobre strings a biblioteca padrão do Elixir oferece.

## 1. Obter a primeira letra do nome

- Há uma [função incorporada][string-first] para obteres o primeiro caráter de uma string.
- Há várias [funções incorporadas][string-trim] para removeres espaços em branco no início, no fim, ou no início e no fim de uma string.

## 2. Formatar a primeira letra como inicial

- Há uma [função incorporada][string-upcase] para converteres todos os carateres de uma string na sua variante maiúscula.
- Há um [operador][kernel-concat] que concatena duas strings.

## 3. Dividir o nome completo no nome próprio e no apelido

- Há uma [função incorporada][string-split] que divide uma string nos espaços em branco.
- É possível atribuir alguns dos primeiros elementos de uma lista a variáveis através de correspondência de padrões na lista.

## 4. Colocar as iniciais dentro do coração

- Existe uma sintaxe especial para [interpolar][string-interpolation] uma expressão dentro de uma string.
- Existe uma sintaxe especial para escrever [strings com várias linhas][heredoc-syntax] sem precisares de escapar carateres de nova linha.
