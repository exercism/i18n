# Dicas

## Geral

- O `movdqa` só deve ser usado quando se sabe que um operando de memória está alinhado.
  É seguro usá-lo quando ambos os operandos são registos.
- O `movdqu` funciona com qualquer alinhamento.
- Os endereços de memória são passados como valores inteiros.
  Os primeiros seis argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`, respetivamente.

## 1. Misturar duas faixas

- A adição com saturação com sinal para vias de 16 bits é `paddsw`.
- Os três endereços de memória estão alinhados a 16 bytes, por isso a variante de movimentação alinhada, `movdqa`, é a adequada.
  Também podem ser usados diretamente como operando de origem (mas não como destino).

## 2. Remover o sangramento

- A subtração com saturação com sinal para vias de 16 bits é `psubsw`.
- O `track` está alinhado, mas não há garantia de que `result` e `bleed` estejam, por isso precisam da variante de movimentação não alinhada, `movdqu`.

## 3. Combinar medidores

- A adição com saturação sem sinal para vias de 8 bits é `paddusb`.
- Os três endereços de memória estão alinhados a 16 bytes, por isso a variante de movimentação alinhada, `movdqa`, é a adequada.
  Também podem ser usados diretamente como operando de origem (mas não como destino).

## 4. Aplicar um fade

- A multiplicação que mantém os 16 bits superiores de um produto com sinal de 16 bits é `pmulhw`.
- Os três endereços de memória estão alinhados a 16 bytes, por isso o `movdqa` é o adequado.
  Também podem ser usados diretamente como operando de origem (mas não como destino).
- Tanto `track` como `gains` são lidos como valores com sinal, que é o que o `pmulhw` espera.
- As instruções de dois operandos normalmente sobrescrevem o operando de destino.
- Cada registo de 128 bits contém 8 amostras, e `n` (o quarto argumento) é sempre diferente de zero e múltiplo de `8`.
- Deves usar um ciclo para processar todas as amostras, avançando 16 bytes (8 amostras) em cada iteração.

## 5. Atenuar uma faixa

- O SIMD de inteiros não tem divisão empacotada, por isso converte para vírgula flutuante empacotada, divide e converte de volta.
- As amostras têm 16 bits e têm de ser alargadas para 32 bits antes da conversão para vírgula flutuante.
  O alargamento com sinal de vias de 16 bits para vias de 32 bits é `pmovsxwd`.
- O `pmovsxwd` pode receber um operando de memória de 64 bits, carregando e alargando 4 amostras num único passo.
- Converte os inteiros alargados para vírgula flutuante empacotada com `cvtdq2ps`.
- O divisor é um inteiro de 32 bits já fornecido em 4 cópias.
  Deve ser convertido para vírgula flutuante empacotada antes de ser usado na divisão de vírgula flutuante.
- A divisão empacotada de precisão simples é `divps`.
- Converte o quociente de volta para inteiros empacotados de 32 bits com `cvttps2dq`, que trunca sempre para zero.
- Cada bloco de resultados tem 4 inteiros de 32 bits, e `n` (o quarto argumento) é sempre diferente de zero e múltiplo de `4`.
- Deves usar um ciclo, avançando 8 bytes em `samples` (4 valores) e 16 bytes em `result` (4 valores) em cada iteração.
