# NuVoc

A [NuVoc][nuvoc-link] é a referência definitiva para o J.
É uma visão geral muito concisa e densa em informação das primitivas e da linguagem J.

# Rosetta Code

Muitas tarefas do Rosetta Code têm soluções em `J`.
É um bom recurso para encontrares programas em J que podes estudar.
[Aqui](https://rosettacode.org/wiki/Sudoku#J) tens um solucionador de sudoku da autoria de Roger Hui.
