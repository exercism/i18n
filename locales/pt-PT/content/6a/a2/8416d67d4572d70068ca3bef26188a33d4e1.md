# Anexo às instruções

## Implementação

No pacote twobucket, implementa um func em Go, Solve, com a seguinte assinatura:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve devolve quatro valores: o balde objetivo ("one" ou "two"), o número de movimentos/passos necessários para atingir a quantidade objetivo, os litros que restam no outro balde e um valor de erro.
Devolve um erro se algum parâmetro for inválido ou se não for possível encontrar uma solução.
