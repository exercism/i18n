# Criar um Test Runner

Antes de mais, obrigado pelo teu interesse em criar um Test Runner!

Estes são os passos para começar:

1. Consulta [a nossa lista de repositórios à procura de um `...-test-runner` já existente](https://github.com/search?q=org%3Aexercism+test-runner&type=repositories) para garantir que ainda não existe nenhum.
2. Explora o [conteúdo desta pasta](/docs/building/tooling/test-runners) para garantir que te sentes à vontade com a ideia de criar um Test Runner.
3. Inicia um novo tópico no [fórum do Exercism][building-exercism] a dizer-nos para que linguagem gostarias de criar um Test Runner.
4. Depois de ser criado um repositório de Test Runner para ti, usa os documentos [a interface do Test Runner](/docs/building/tooling/test-runners/interface) e [Boas práticas](/docs/building/tooling/best-practices) para orientar a tua implementação.

Temos uma comunidade incrivelmente simpática e prestável, que terá todo o gosto em ajudar-te ao longo deste processo!
Se ficares preso, inicia um novo tópico no [fórum do Exercism][building-exercism] ou cria novas issues em [exercism/exercism][exercism-repo], conforme for necessário 🙂
