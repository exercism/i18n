# Dicas

## Geral

- Em Swift, existem três tipos principais de condicionais: as instruções `if`, as instruções `switch` e as instruções `guard`.

## 1. Calcula se consegues pagar as prestações mensais de um determinado carro

- Certifica-te de que divides o preço total do carro pelo número de meses para calcular o valor da prestação mensal.
- Podes usar `+` para concatenar duas strings.

## 2. Determina o tipo de carta de condução de que vais precisar

- As instruções `switch` são boas para tratar um grande número de casos de forma clara.
- Podes tratar vários casos com um único caso de `switch` se o comportamento for o mesmo para todos eles.
- O caso `default` trata todos os casos que não estão listados explicitamente.

## 3. Calcula as taxas de registo do teu veículo novo

- A instrução `guard` usa-se em situações em que é desejável sair mais cedo, porque não é preciso continuar o processamento (ou não é possível).
- Só precisas de fazer o cálculo com a fórmula se o veículo tiver menos de 10 anos.
