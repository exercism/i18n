# Usa `Keyword.get_values`

As listas de palavras-chave podem conter mais do que um valor para uma chave, o que torna trabalhoso obter todos os valores de uma chave.
O módulo `Keyword`, além de `Keyword.get` para obter um único valor, também disponibiliza `Keyword.get_values` para obter múltiplos valores.
Usa `Keyword.get_values` para filtrar os vinhos por cor.
