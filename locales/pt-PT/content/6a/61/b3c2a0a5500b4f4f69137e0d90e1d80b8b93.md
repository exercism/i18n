Instalação
============

Para escreveres programas em YAMLScript, precisas de instalar o intérprete de
linha de comandos do YAMLScript.
É um ficheiro executável binário chamado `ys`.
Atualmente, funciona em:

* Linux / Intel
* Linux / ARM
* MacOS / Intel
* MacOS / ARM

> Nota: o suporte para Windows está planeado, mas ainda não está disponível.

As versões estão [disponíveis no GitHub](
http://github.com/yaml/yamlscript/releases).


## Instalação automática

Para resolveres os exercícios de YAMLScript do Exercism, vais modificando o teu
programa de solução e corres `make test` até todos os testes passarem.

É isso!

Da primeira vez que corres `make test`, vai tentar instalar a versão específica
do intérprete `ys` necessária para o exercício no diretório
`/path/to/exercism/yamlscript/.local/`.

Se já instalaste essa versão do `ys` algures no teu `PATH`, vai copiar o
intérprete `ys` silenciosamente para o local correto.

Caso contrário, vai pedir-te para fazeres uma instalação a partir de uma versão
binária, que normalmente demora apenas alguns segundos.

Se isso falhar (é raro, mas acontece às vezes), vai pedir-te para fazeres uma
compilação automática a partir do código-fonte, que pode demorar alguns minutos
(mas é muito fiável e não exige interação).

Só vais encontrar isto da primeira vez que correres `make test`.
Todos os exercícios configurados para usar a mesma versão do `ys` vão usar a
mesma instalação.

> Nota: também podes usar o comando `make install-ys` separadamente do `make
> test`.
> Vai fazer exatamente o mesmo processo de instalação que o `make test`, mas sem
> correr os testes depois.


Para mais informações sobre como instalar o YAMLScript, especialmente para o
usares fora do Exercism, consulta a [Documentação de Instalação do YAMLScript](
https://yamlscript.org/doc/install/).
