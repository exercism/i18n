# Introdução

A recursão é uma forma de repetir código dentro de uma função, fazendo com que a função se chame a si própria.
É outra forma de fazer ciclos ou de iterar. Tal como nos ciclos, a função deve testar uma expressão Boolean para saber quando terminar.
Ao contrário dos ciclos, uma recursão que nunca termina não fica a correr infinitamente.
Os valores usados em cada chamada de função podem ficar num frame próprio na pilha.
Se a quantidade de chamadas de função ocupar mais espaço do que a pilha tem, dá origem a um erro de stack overflow.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Isto imprime

```
The number is 1
The number is 2
After recursion
```

Pode haver situações que são mais legíveis e/ou mais fáceis de raciocinar quando expressas com recursão do que quando expressas com ciclos.
