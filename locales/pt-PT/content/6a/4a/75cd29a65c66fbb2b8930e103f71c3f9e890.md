# Ciclos

Em Rust, podes usar ciclos para executar um bloco de código repetidamente até lhe dizeres para parar ou até se cumprir uma determinada condição.

A versão mais básica de um ciclo usa a palavra-chave `loop`:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

O fragmento de código acima cria um ciclo infinito. Para sair de um ciclo, usa a palavra-chave break:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## Ciclos com `for` e `while`

Para além da palavra-chave `loop`, também podes criar ciclos com `for` e `while`.

Um ciclo `for` serve para iterar sobre os elementos de uma coleção ou de um iterador.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

Os intervalos também são iteradores, o que torna muito prático iterá-los com o ciclo `for`:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

Um ciclo while repete código até se cumprir uma condição. Podemos reescrever o exemplo anterior com um ciclo while, assim:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

Consulta [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops) no livro do Rust para mais informações sobre ciclos.
