# Anexo às instruções

## Instruções específicas do percurso

O Phix não tem ponteiros. Implementar algo como uma lista ligada, que já é, à partida, um pouco complicado, por exemplo emulando ponteiros com índices, não só seria ainda mais complicado, como seria totalmente inútil. Afinal, uma sequência padrão, a verdadeira espinha dorsal da linguagem, trata destas coisas de uma forma muito mais fácil e quase trivial.

Por isso, este exercício é muito simples: emular o comportamento de uma lista duplamente ligada (/com duas extremidades) usando uma única sequência (plana), sem quaisquer ponteiros nem nada do género.

Embora seja possível tratar várias listas com múltiplos retornos, ou usar o include stack/queue fornecido (ambos podem receber instruções para realizar uma operação na sua "outra" extremidade), para simplificar ainda mais as coisas, vamos apenas usar a única variável estática "list".
