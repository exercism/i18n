# Introdução

## Noções básicas

C# é uma linguagem de tipos estáticos, o que significa que tudo tem um tipo em tempo de compilação. Atribuir um valor a um nome chama-se definir uma variável. Uma variável pode ser definida especificando explicitamente o seu tipo ou deixando o compilador de C# inferir o tipo com base no valor atribuído (o que se chama _inferência de tipos_). Assim, as duas definições de variável que se seguem são equivalentes:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

A atualização do valor de uma variável faz-se com o operador `=`. Depois de definida, o tipo de uma variável nunca pode mudar.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# é uma [linguagem orientada a objetos][object-oriented-programming] e exige que todas as funções sejam definidas numa _classe_. A palavra-chave `class` serve para definir uma classe. Os objetos (ou _instâncias_) são criados com a palavra-chave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Uma função dentro de uma classe chama-se _método_. Cada método pode ter zero ou mais parâmetros. Todos os parâmetros têm de ter um tipo explícito; não há inferência de tipos para parâmetros. Da mesma forma, o tipo do valor devolvido também tem de ser explícito. Os valores são devolvidos pelos métodos com a palavra-chave `return`. Para permitir que código noutros ficheiros chame um método, é preciso acrescentar o modificador de acesso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Os métodos são invocados com a sintaxe de ponto (`.`) numa instância, indicando o nome do método a chamar e passando argumentos para cada um dos parâmetros do método. Os argumentos podem indicar opcionalmente o nome do parâmetro correspondente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

O âmbito em C# é definido entre os carateres `{` e `}`.

C# suporta dois tipos de comentários. Os comentários de linha única são precedidos por `//` e os comentários de várias linhas são inseridos entre `/*` e `*/`.
