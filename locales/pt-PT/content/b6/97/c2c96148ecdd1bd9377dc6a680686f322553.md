# Fluxo de trabalho de sincronização de etiquetas

O fluxo de trabalho de sincronização de etiquetas sincroniza as [etiquetas do GitHub](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) de um repositório com o conteúdo do ficheiro `.github/labels.yml`.
Sempre que o ficheiro `.github/labels.yml` mudar, o fluxo de trabalho de sincronização de etiquetas atualiza automaticamente as etiquetas do repositório.

## Personalizar as etiquetas

As etiquetas definidas em `.github/labels.yml` assumem duas formas:

- Etiquetas partilhadas: são etiquetas usadas por _todos_ os repositórios do Exercism e estão definidas no [repositório org-wide-files](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)
- Etiquetas específicas de um percurso: são definidas num ficheiro `.appends/.github/labels.yml`

Para adicionares etiquetas específicas de um percurso, tens de as acrescentar ao ficheiro `.appends/.github/labels.yml` (vê [este exemplo](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)).
Depois de fazeres o merge das alterações na `main`, é aberto automaticamente um pull request para alterar o ficheiro `.github/labels.yml`.
Após fazeres o merge desse PR, as etiquetas são atualizadas automaticamente (vê a descrição acima).

```exercism/caution
Nunca edites manualmente o ficheiro `.github/labels.yml`, porque essas alterações serão substituídas na próxima sincronização de etiquetas.
```

## Origem

O fluxo de trabalho está definido no ficheiro `.github/workflows/sync-labels.yml`.
