# Dicas

## Geral

- [Introdução aos tipos numéricos de vírgula flutuante][docs.microsoft.com-floating_point_numeric_types].

## 1. Calcula a taxa de juro

- Por omissão, qualquer número de vírgula flutuante definido em código C# é tratado como um `double`. Para usar um tipo de vírgula flutuante diferente (como `float` ou `decimal`), é preciso acrescentar o [sufixo][docs.microsoft.com-real_literals] adequado ao número.

## 2. Calcula o juro

- Ao calcular o juro, pode ser útil reparar que `InterestRate` devolve uma percentagem.

## 3. Calcula a atualização do saldo anual

- Ao calcular a atualização do saldo anual, podemos usar métodos que já definimos nos passos anteriores.

## 4. Calcula os anos necessários para atingir o saldo desejado

- Para calcular os anos, podes repetir um ciclo até atingires o saldo desejado. O C# tem várias [estruturas de repetição][docs.microsoft.com-loops].
- Existe um [operador][increment-operator] especial para incrementar valores em 1.
