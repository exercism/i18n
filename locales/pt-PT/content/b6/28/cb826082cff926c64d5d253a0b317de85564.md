# O `+` usado para concatenação

Neste caso, usar `+` é quase de certeza a escolha certa, porque é mais curto e, muitas vezes, mais rápido para concatenações simples. Se ainda não o conheces, dá uma vista de olhos ao poderoso pacote `fmt`. É o que as pessoas costumam usar para concatenações de strings mais complicadas e para outras tarefas de formatação de strings.
