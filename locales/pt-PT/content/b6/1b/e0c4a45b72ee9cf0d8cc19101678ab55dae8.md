# Dicas

## Geral

## 1. Implementa o método `new()`

- O método `new()` recebe os argumentos com que queremos instanciar uma instância de `User`. Deve devolver uma instância de `User` com o nome, a idade e o peso indicados.

- Vê [aqui](https://doc.rust-lang.org/book/ch05-01-defining-structs.html) mais exemplos sobre como definir e instanciar structs.

## 2. Implementa os métodos getter

- Os métodos `name()`, `age()` e `weight()` são getters. Por outras palavras, são responsáveis por devolver o campo correspondente de uma instância de struct.

- Repara que o método `name` devolve um `&str`, ao passo que o campo `name` da struct `User` é uma `String`. Como é que podemos fazer com que o `&str` e a `String` se deem bem um com o outro?

- Não é preciso usar uma instrução `return` em Rust, a não ser que queiras expressamente que uma função ou um método devolva mais cedo. Caso contrário, é mais idiomático usar uma devolução _implícita_, omitindo o ponto e vírgula no resultado que queremos que a função ou o método devolva. Não é _errado_ usar uma devolução explícita, mas é mais limpo aproveitar as devoluções implícitas sempre que possível.

```rust
fn foo() -> i32 {
    1
}
```

- Vê [aqui](https://doc.rust-lang.org/book/ch05-03-method-syntax.html) mais alguns exemplos de como definir métodos em structs.

## 3. Implementa os métodos setter

- Os métodos `set_age()` e `set_weight()` são setters, responsáveis por atualizar o campo correspondente de uma instância de struct com o argumento de entrada.

- Como indicam as assinaturas destes métodos, os métodos setter não devem devolver nada.
