# Apêndice às instruções

## Registos

| Registo | Utilização | Tipo | Descrição |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada      | endereço | string de algarismos com terminador nulo |
| `$a1`    | entrada      | inteiro | extensão |
| `$v0`    | saída        | inteiro | maior produto de uma série |
| `$t0-9`  | temporário   | qualquer | para armazenamento temporário |
