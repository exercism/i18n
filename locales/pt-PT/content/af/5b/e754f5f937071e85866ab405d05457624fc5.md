# `grep` ou não `grep`, eis a questão

## Ajustes do percurso AWK aos requisitos

Não és obrigado a implementar uma análise da linha de comandos completa: as flags são fornecidas numa string separada por espaços, fácil de dividir.
```sh
gawk -f grep.awk -v flags="l v" -v pattern="hello" file1.txt file2.txt
```

Tal como no grep real, o teu programa devolve um **estado de saída diferente de zero** quando _não são encontradas correspondências_.
