# Espaço reservado

## Implementar operações de List

O objetivo deste exercício é implementares tu mesmo alguns dos métodos de List.
É natural usar um objeto List no backend para guardar os dados.
Não mexas nos métodos de List (como `where`, `map`, etc.).

Há algumas operações "primitivas" de List que são inevitáveis, como:

* fatiar: `list[from..to]`
* adicionar: `list.add(item)`

## Protocolo de iterador

As operações de lista que vais implementar têm todas a ver com iterar de várias formas.
Lê sobre [o protocolo de iterador][iter].
Depois, podes fazer o seguinte:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
