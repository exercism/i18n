# Introdução

Este exercício vai ensinar-te os blocos de construção fundamentais do Ruby.
Aborda muita matéria, mas não te preocupes se parecer demasiado: vamos aprofundar tudo muito mais à medida que avançamos no percurso.

Uma das coisas fundamentais a compreender sobre o Ruby é que é uma [linguagem orientada a objetos][object-oriented-programming] e que **tudo em Ruby é um [objeto][object]**. Números, strings, arrays: são todos objetos.

## Variáveis e constantes

Costumamos usar objetos atribuindo-lhes nomes, através de variáveis ou de constantes.

As variáveis escrevem-se sempre em [snake case][snake-case].
Uma variável pode referenciar objetos diferentes ao longo do seu ciclo de vida.
Por exemplo, `my_first_variable` pode ser definida e redefinida muitas vezes com o operador `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

As constantes, por outro lado, destinam-se a ser atribuídas uma única vez.
Têm de começar com letras maiúsculas e, normalmente, escrevem-se em maiúsculas, com as palavras separadas por underscores.
Por exemplo:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## Classes

O Ruby está organizado em classes.
As classes definem-se com a palavra-chave `class`, seguida do nome da classe.
Os objetos são geralmente criados instanciando classes com o método `.new`.
Por exemplo:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## Métodos

As unidades de funcionalidade são encapsuladas em métodos, semelhantes às _funções_ de outras linguagens.

Um método pode ser definido com argumentos posicionais, com argumentos de palavra-chave (que se definem e se chamam com a sintaxe `:`) ou não ter argumentos nenhuns.

Os métodos devolvem implicitamente o resultado da última instrução avaliada ou podem devolver explicitamente um objeto através da palavra-chave `return`.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

Os métodos invocam-se com a sintaxe `.`:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
