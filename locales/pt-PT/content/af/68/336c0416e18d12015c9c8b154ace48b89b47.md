# Instalação

O [Godot Engine][godot-engine] é usado para executar código GDScript.
O Godot Engine funciona em Windows, Linux, macOS e Android.

## Instalar o Godot Engine

O Godot Engine pode ser descarregado diretamente do [site do Godot Engine][download].
O download contém uma pasta zip com dois executáveis, ambos com o nome da versão do Godot Engine.
Extrai a pasta e abre o primeiro executável.

Se precisares de um guia em vídeo, tens um [aqui][video-guide]. (Deve funcionar no Godot 4.7 ou em qualquer outra versão do Godot.)

Este track usa o Godot versão 4.7.2.

[godot-engine]: https://godotengine.org/
[download]: https://godotengine.org/download/
