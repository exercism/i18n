# Dicas

## Geral

- O [tutorial de strings do csharp.net][tutorial-csharp.net-strings] tem uma boa introdução às `string`s de C#.
- A classe `string` tem muitos [métodos incorporados][docs-string-methods] úteis.

## 1. Obter a mensagem de uma linha de registo

- As diferentes opções para procurar texto numa `string` são exploradas em [este tutorial][tutorial-docs.microsoft.com-search-text-in-string].
- Remover espaços em branco é algo [incorporado][tutorial-docs.microsoft.com-trim-white-space].

## 2. Obter o nível de registo de uma linha de registo

- Alterar as maiúsculas e minúsculas de uma `string` é explorado em [este tutorial][tutorial-docs.microsoft.com-changing-case].

## 3. Reformatar uma linha de registo

- Há várias formas de [concatenar strings][tutorial-docs.microsoft.com-concatenate-strings], mas a preferida costuma ser a [interpolação de strings][tutorial-csharp.net-string-interpolation].
