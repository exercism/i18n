# Introdução

O Haxe tem suporte nativo para expressões regulares. Podem ser usadas para verificar o formato de uma string, transformar uma string ou extrair alguns dados regulares de um determinado texto.

Para criar uma expressão regular, escreve entre `~/` e `/`:

```haxe
var r = ~/haxe/i;
```

Uma forma diferente de fazer isto é usar a instância `EReg()`:

```haxe
var r = new EReg("haxe", "i");
```

Aqui, o `i` é um sinalizador que faz com que o padrão não distinga maiúsculas de minúsculas. Existem outros sinalizadores, incluindo:

- `g`: substituição global.
- `m`: correspondência em várias linhas

Entre `~/` e `/`, escreves os padrões de expressão regular. Por exemplo, queres procurar uma string que contenha letras de A a Z. Aqui, podemos usar o padrão de intervalo `[A-Z]`. Há muitos padrões de expressão, incluindo:

- `.`: qualquer caráter
- `*`: repetir zero ou mais vezes
- `+`: repetir uma ou mais vezes
- `[A-Z0-9]`: intervalos de carateres
