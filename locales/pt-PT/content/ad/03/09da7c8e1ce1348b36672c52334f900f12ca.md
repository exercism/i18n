# Instruções

A Lilly adora cozinhar.
Quer organizar uma festa de pizza com os amigos.
Para aproveitar ao máximo os ingredientes, precisa de saber quanto de cada ingrediente vai precisar antes de começar.

Para resolver isto, a Lilly esboçou um programa para automatizar parte do planeamento, mas precisa da tua ajuda para o terminar.
Vais ajudar a Lilly a organizar a festa de pizza proporcionalmente perfeita?

## 1. Uma proporção de massa

A Lilly é fã de pizzas finas e estaladiças, com uma massa mais fina.
A massa necessária para o meio é no mínimo 200 g, mas cada pessoa servida precisa de mais 20 g de massa.

`grams = pizzas * ((persons * 20) + 200)`

A Lilly precisa de uma função que:

- Recebe o número de pizzas
- O número de pessoas que cada pizza vai servir
- E devolve a massa necessária, arredondada ao grama mais próximo.

Por exemplo, para fazer 4 pizzas que alimentam 8 pessoas:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. Um toque de molho

A Lilly é meticulosa a aplicar o molho, mas o tamanho das suas pizzas pode ser irregular.
Pela sua experiência, sabe que são precisos 125 mL de molho por pizza.
A Lilly precisa de uma função que calcule quantas latas de molho deve comprar.

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

Por exemplo, dado que a Lilly precisa de fazer 8 pizzas e cada lata tem 250 mL:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. Queijo, por favor

O queijo vem em cubos perfeitos e é vendido por tamanho.

A fórmula que a Lilly usa não é a fórmula da área da pizza, pois ela _não_ quer que o queijo cubra toda a área.
Decidiu usar a seguinte fórmula para determinar quantas pizzas de um determinado diâmetro (`diameter`) se podem fazer a partir de um cubo de queijo com um determinado comprimento de aresta (`cheese_dimension`):

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

Cria uma função que:

- Recebe a medida da aresta de um cubo de queijo
- Recebe a espessura desejada da camada de queijo
- Recebe o diâmetro da pizza
- E usa a fórmula da Lilly para devolver o número de pizzas que se podem fazer, arredondando para baixo.

Por exemplo, dado um cubo de queijo de 25x25x25 cm, uma camada de queijo de 0,5 cm de espessura e pizzas com 30 cm de diâmetro:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. Uma partilha justa

Por fim, a Lilly quer que cada pizza seja dividida em 8 fatias e distribuída igualmente pelos amigos.

Cria uma função que:

- Recebe um número de pizzas e um número de amigos
- E devolve o número de fatias que sobram se cada pessoa levar o mesmo número de fatias.

Por exemplo:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
