# Introdução

Um gerador em Python é uma _função chamável_ ou uma expressão que devolve um tipo especial de [iterador][iterator] chamado [iterador gerador][generator-iterator].
Os `Generator-iterators` são [preguiçosos][lazy iterator]: não guardam os seus `values` em memória, mas _geram_ os seus valores quando é preciso.

Uma função geradora é parecida com qualquer outra função, mas contém uma ou mais [expressões yield][yield expression].
Cada `yield` suspende a execução do código e guarda o estado de execução atual (_incluindo todas as variáveis locais e as instruções try_).
Quando a função geradora é retomada, continua a partir do ponto onde ficou suspensa, ao contrário das funções normais, que são reiniciadas a cada chamada.
