# Introdução

Quando precisas de uma sequência de `n` valores em que cada um depende do seu índice, o Factor dá-te `<iota>`, uma sequência virtual dos números inteiros `0, 1, …, n-1`, e o `map`:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

O `<iota>` não aloca os números inteiros de antemão; o `map` percorre-os por ordem, aplicando a quotation a cada um.

Se o resultado por posição for um código de caráter, o `>string` transforma o resultado numa string, a forma natural de montar uma linha de carateres a partir de decisões guiadas pelo índice:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
