# Dicas

## Geral

- Lê a documentação de [gleam/set][set]
- A documentação de [gleam/list][list] também pode ser útil

## 1. Começa uma coleção

- A função mais adequada é [`set.from_list`][from_list]

## 2. Aumenta a coleção

- Usa a [função `set.insert`][insert]
- Usa a [função `set.contains`][contains]

## 3. Começa a trocar

- Usa a [função `set.contains`][contains]
- Usa a [função `set.insert`][insert]
- Usa a [função `set.delete`][delete]

## 4. Só pode haver um de cada

- Um `Set` tem a propriedade de só conter valores únicos
- Usa a [função `set.from_list`][from_list]
- Usa a [função `set.to_list`][to_list]
- `set.to_list` não garante que devolva uma lista ordenada

## 5. Cartas que todas têm

- Usa a [função `set.intersection`][intersection]
- Usa a [função `set.to_list`][to_list]

## 6. Todas as cartas

- Usa [`set.new`][new] como acumulador
- Usa a [função `set.union`][union]
- Usa a [função `set.size`][size]

## 7. Brilhante para ganhar

- Usa a [função `set.filter`][filter]
