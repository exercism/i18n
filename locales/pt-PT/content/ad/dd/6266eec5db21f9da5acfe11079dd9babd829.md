# Introdução

## Structs

Os structs são uma extensão construída sobre os [mapas][exercism-maps] que oferece verificações em tempo de compilação e valores predefinidos. Um struct recebe o nome do módulo em que é definido. Para definir um struct, usa o construto `defstruct`. O construto aparece normalmente logo a seguir à definição do módulo. O `defstruct` aceita uma lista de átomos (para valores predefinidos `nil`) ou uma lista de palavras-chave (para valores predefinidos especificados). Os campos sem valor predefinido têm de vir antes dos campos com valores predefinidos.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### Acesso e atualização dos campos

Como os structs são construídos sobre mapas, podemos usar a maioria das funções de mapas para obter e manipular valores. O _Access Behaviour_ **não** está implementado para structs. Em vez disso, recomenda-se o uso do _operador de acesso estático_ `.` para aceder aos campos de um struct.

- obter/recuperar valores dos campos:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- atualizar valores dos campos

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### Correspondência de padrões

Os structs podem ser usados em correspondência de padrões com ou sem o nome do struct.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Ao incluir o nome do struct no padrão, garantes que tanto o lado esquerdo como o direito são structs do mesmo tipo.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### Forçar a inicialização dos valores dos campos

Podemos usar o atributo de módulo `@enforce_keys` com uma lista das chaves dos campos para garantir que os valores são inicializados quando o struct é criado. Se uma chave não estiver na lista, o seu valor será `nil`, como se vê no exemplo acima. Se uma chave forçada não for inicializada, é lançado um erro.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
