# Introdução

## Aliases de tipo

Um alias de tipo pode ser usado em Gleam para dar um nome mais cómodo a um tipo já existente que, de outra forma, seria difícil de escrever.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Quando é escrito com `pub type`, o alias pode ser usado fora do módulo em que é definido. Se `pub` for omitido, o alias é privado e não pode ser referenciado noutros módulos.
