# Introdução

Em C++, os Boolean são representados pelo tipo `bool`.
Um `bool` ou é `true` ou é `false`.

## Operadores lógicos

O C++ suporta três operadores booleanos: `!` (NOT), `&&` (AND) e `||` (OR).
Também podes usar as versões alternativas `not`, `and` e `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Precedência

Os três operadores booleanos têm cada um uma _precedência_ diferente.
Por conseguinte, são avaliados por esta ordem: `!` primeiro, `&&` a seguir e, por fim, `||`.
Se quiseres forçar uma ordem diferente, podes envolver uma expressão booleana em parênteses (ou seja, `()`), uma vez que os parênteses têm uma precedência ainda mais elevada.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Conversão

Se usares `true` ou `false` num sítio onde se espera um número, são convertidos em `1` e `0`, respetivamente.
Se usares um número numa operação booleana, tudo exceto `0` é tratado como `true`, mesmo os valores negativos.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
