# Instalação

## O que é necessário

Os elementos básicos necessários para programar em Common Lisp são:

- Uma «implementação» de Lisp, que te permite compilar e executar código, além de fornecer um REPL.
- Um editor de texto com funcionalidades para código Lisp. 
- (Opcional, mas útil) A referência mais usada para a linguagem Common Lisp, a ["Common Lisp Hyperspec"][hyperspec].

## Roswell

O [Roswell][roswell] é um comando para instalar e gerir implementações de Common Lisp, com muitas funcionalidades que facilitam o desenvolvimento e a distribuição de aplicações Lisp.
Estamos a usá-lo para simplificar os passos de instalação e de testes.

### Instalar o Roswell

Consulta o [Guia de Instalação][ros-inst] e segue as instruções para a tua plataforma.
Para a maioria dos utilizadores, o seguinte é suficiente:

* Para macOS e Linux, o [Homebrew][brew] torna isto simples:
  ```sh
  brew install roswell
  ```
* Para Windows, usa o [Scoop][scoop]:
  ```powershell
  scoop install roswell
  ```

Na primeira vez que usares o Roswell, este vai buscar e instalar o SBCL e o Quicklisp.
Basta executar isto:
```sh
ros help
```

Entra no REPL com
```sh
ros run
```

## Configura o teu editor de texto

Quem está a começar com Common Lisp, em especial quem já tem experiência com o Emacs, pode ter um início fácil e rápido instalando o [Portacle, o ambiente portátil de Common Lisp][portacle]. 
Gratuito e completo, funciona em todas as plataformas comuns e vem pré-configurado «pronto a usar». Inclui:

- Uma implementação de Lisp: SBCL, incluindo Quicklisp e ASDF.
- Um editor de texto: Emacs

... com muitos extras para escrever código Lisp: 
- SLIME, o «Superior Lisp Interaction Mode for Emacs», transforma o Emacs num IDE de Common Lisp
- ParEdit, que facilita o trabalho com parênteses. 

Vem tudo já configurado de origem. Instala o Portacle descarregando-o da [página inicial][portacle].

Nota: o Emacs (editor de texto) pode ser desorientador ao início, se não estiveres habituado a ele. Felizmente, há muitos tutoriais sobre o Emacs e o SLIME disponíveis online. 

## Início tradicional

Se preferires instalar as ferramentas necessárias separadamente, terás de instalar e configurar:

- um editor de texto com suporte para Lisp: o [Emacs][emacs] com o pacote [Slime][slime] ou [Sly][sly] é uma escolha comum, mas o [VIM][vim] com o [SLIMV][slimv], o [Atom][atom] com o [SLIMA][slima] ou o [VSCode][vscode] com um [plugin de Common Lisp][vscode-plugin] também são boas opções.
- uma implementação de Common Lisp: o [SBCL][sbcl] é uma escolha «segura», que funciona em Linux, macOS e Windows. Como a linguagem assenta num padrão, outras [implementações conformes][awesome-cl-implementations] também funcionam.
- [Quicklisp][quicklisp] para a gestão de bibliotecas. Depois de o descarregares, segue as [instruções][quicklisp-install] para garantir que fica corretamente integrado com a tua implementação de Common Lisp.
