# Introdução

## Tipos personalizados

Os tipos personalizados são a forma de definir novos tipos de dados em Gleam. Podem ter várias _variantes_, cada uma com o seu próprio nome.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Cada caso de um tipo personalizado pode, opcionalmente, conter alguns dados, e casos diferentes podem ter tipos de dados diferentes. Quando uma variante contém dados, chama-se _registo_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Podes criar um valor para um caso específico indicando o seu nome, se ele não tiver dados adicionais (`Spring`), ou chamando-o como uma função, se tiver (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

Os tipos personalizados, tal como tudo em Gleam, têm _igualdade estrutural_, o que significa que dois valores da mesma variante e com os mesmos dados são equivalentes.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Podes fazer correspondência de padrões com as variantes de um tipo personalizado usando expressões case.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
