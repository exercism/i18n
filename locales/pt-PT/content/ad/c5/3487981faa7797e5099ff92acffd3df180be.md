# Instruções

A tua tarefa é decidir o que vais dizer quando deres a bolacha extra.

Se souberes o nome da pessoa (por exemplo, se a pessoa se chamar Do-yun), vais dizer:

```text
One for Do-yun, one for me.
```

Se não souberes o nome da pessoa, dizes _you_ em vez do nome.

```text
One for you, one for me.
```

Aqui estão alguns exemplos:

| Nome   | Diálogo                    |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
