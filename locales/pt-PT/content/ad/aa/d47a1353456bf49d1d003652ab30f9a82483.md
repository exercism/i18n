# Pré-requisitos

O percurso da linguagem D requer que tenhas o seguinte software instalado no teu sistema:

* um compilador de D versão 2
* (opcional, mas recomendado) o DUB

## Pré-requisito: compilador de D versão 2

No site da linguagem D, [dlang.org](https://dlang.org), podes descarregar e instalar a versão mais recente do compilador de referência DMD (Digital Mars D) para várias plataformas.
Consulta a [página oficial de descarregamentos](https://dlang.org/download.html) para mais informações.
No Windows, uma solução alternativa é [usar o Chocolatey](https://chocolatey.org/packages/dmd).
Nos Macs com processadores Intel, uma solução alternativa é [usar o Homebrew](https://formulae.brew.sh/formula/dmd).

### Outros compiladores

Além do compilador de referência DMD, que usa o seu próprio backend, existem outros dois compiladores que podes obter através da secção de descarregamentos do dlang.org:

* [GDC](http://gdcproject.org/downloads), que usa o backend GCC
* [LDC](https://github.com/ldc-developers/ldc#installation), baseado no backend LLVM

O GDC e o LDC nem sempre estão nas versões mais recentes do frontend do DMD, mas proporcionam melhores níveis de otimização, bem como suporte para outras plataformas, como por exemplo ARM.

Consulta a wiki para [mais informações](https://wiki.dlang.org/Compilers).

### Suporte em IDEs

A linguagem D também tem suporte em várias IDEs, como por exemplo o [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html) para o Visual Studio e o [D plugin](https://plugins.jetbrains.com/plugin/7727?pr=clion) para o CLion da IntelliJ.
Consulta a wiki para [mais informações](https://wiki.dlang.org/IDEs).

### Pré-requisito: DUB

O [DUB](https://github.com/dlang/dub) é um gestor de builds para D.

Recomendamos o DUB para simplificar o processo de correr os testes, mas continua a ser possível correr sem ele, se não o conseguires ou não quiseres instalá-lo.

#### Windows

A [página de descarregamentos do site do DUB](https://code.dlang.org/download) tem um instalador para Windows.
