# Anexo às instruções

## Dicas

Para completar este exercício, tens de criar o tipo de dados `School`
e implementar as seguintes funções:

- `add`
- `empty`
- `grade`
- `sorted`

Vais encontrar uma declaração de dados de exemplo e as assinaturas de tipo já
presentes, mas cabe-te a ti definir as funções e criar um tipo de dados, um newtype
ou um sinónimo de tipo com significado.
