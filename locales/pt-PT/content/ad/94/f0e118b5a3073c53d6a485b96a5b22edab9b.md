# Adenda às instruções

## Valor máximo de um número inteiro

Segundo [a documentação do Vim][number]:

> Assumindo que são usados números de 64 bits (vê v:numbersize), um número sem sinal é truncado para 0x7fffffffffffffff ou 9223372036854775807.

Por outras palavras, o Vim script não consegue expressar nenhum número `2^63` ou superior como um número inteiro.

Alguns dos testes deste exercício exigem números inteiros de 64 bits, o que ultrapassa a limitação de tamanho dos inteiros do Vim script.
Devido a esta limitação, os resultados dos cálculos são comparados com uma string que expressa o valor inteiro, em vez de expressar a resposta como Integer.
Consegues resolver isto evitando números que sejam maiores do que a linguagem permite diretamente?

[number]: https://vimhelp.org/eval.txt.html#expr-number
