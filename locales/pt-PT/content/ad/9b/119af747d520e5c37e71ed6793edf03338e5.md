# Pede um novo percurso de linguagem

Segue as instruções abaixo para pedires um novo percurso de linguagem.

Se queres pedir um novo percurso, **tens de criar um tópico na [categoria Support do Fórum da Comunidade do Exercism][forum-support]** para falares sobre isso com a equipa.

Antes de abrires o tópico, vale a pena pensares no seguinte:

- É uma linguagem de programação?
- O Exercism já suporta a linguagem?
- Já alguém pediu esta linguagem?
- Vais estar disponível para construir e lançar o percurso de forma ativa?

## É uma linguagem de programação?

No Exercism disponibilizamos uma plataforma de aprendizagem para programadores que querem praticar uma linguagem de programação ou aprender uma nova.

Se a linguagem for uma linguagem de programação de uso geral, provavelmente teremos interesse em ter o percurso no Exercism.
Não criamos percursos para ferramentas, bibliotecas, frameworks ou tecnologias.

## O Exercism já suporta a linguagem?

Consulta a [lista de repositórios de percursos][track-repositories] para encontrares tanto percursos ativos como inativos.
Se encontrares um repositório para a tua linguagem, consulta o valor da chave `active` no ficheiro `config.json` do repositório para saberes o estado:

- `true`: o percurso está ativo e aparece na [página de percursos][exercism-tracks] do site.
- `false`: o percurso está inativo e não aparece no site.
  O percurso ainda precisa de trabalho para ficar ativo.
  Se quiseres ajudar, abre uma issue nesse repositório para dizeres olá.

## Já alguém pediu?

Pesquisa o nome da linguagem nas [issues do repositório generic-track][generic-track-repo] para veres se a linguagem já foi pedida.
Lembra-te de verificar tanto as issues abertas como as fechadas.

## Vais estar disponível para construir e lançar o percurso de forma ativa?

O Exercism é uma organização sem fins lucrativos e todos os percursos de linguagem são construídos por voluntários.
Só criamos um percurso se houver pelo menos um voluntário que se tenha oferecido para liderar a sua construção.

O mínimo para lançar um percurso é:

- 20 exercícios de prática (podem basear-se nas especificações do repositório [problem-specifications][problem-specifications].
- Integração contínua que verifica se os exercícios podem ser resolvidos.
- Um pouco de configuração e documentação.

Estamos disponíveis para te orientar ao longo do caminho e também podes obter ajuda da comunidade de pessoas que já fizeram isto para outras linguagens.

## Não existe, quero criá-lo!

Fantástico!! Cria um novo tópico no [Fórum do Exercism][forum-support] para falarmos sobre os detalhes.
