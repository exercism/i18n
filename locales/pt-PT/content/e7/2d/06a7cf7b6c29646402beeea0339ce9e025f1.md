# Export nomeado inexistente

Não foi encontrado nenhum [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) com o nome `%{export.name}`. Os testes não passam sem ele.

Certifica-te de que `%{export.name}` existe e acrescenta `export` antes dele:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
