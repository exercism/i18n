# Introdução

Uma [lista][list] é uma coleção mutável de itens em _sequência_.
 As listas podem conter referências a qualquer tipo de dados (ou a vários), incluindo outras listas ou estruturas de dados como [tuplas][tuples], [conjuntos][sets] ou [dicionários][dicts].
 O conteúdo pode ser iterado com a construção `for item in <list>`.
 Se precisares dos índices juntamente com o conteúdo, podes usar `for index, item in enumerate(<list>)`.
 Podes aceder aos elementos dentro de uma `list` através de um número de `0-based index` a partir da esquerda, ou de um número de `-1-based index` a partir da direita.
 As listas podem ser copiadas, total ou parcialmente, com _notação de fatiamento_ ou `<list>.copy()`.
 O Python disponibiliza muitos [métodos][list-methods] úteis e práticos para trabalhar com listas.
