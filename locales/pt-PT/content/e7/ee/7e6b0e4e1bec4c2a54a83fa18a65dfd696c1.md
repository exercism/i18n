# Introdução

Existem três tipos principais de condicionais usadas em Julia:

- Expressões `if`
- O operador ternário
- A avaliação de curto-circuito

## Expressões `if`

As expressões `if` em Julia são semelhantes às de outras linguagens:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

Se a expressão Boolean que se segue ao `if` for avaliada como `true`, o primeiro bloco de código é executado e o segundo bloco é ignorado.
Se a expressão Boolean que se segue ao `if` for avaliada como `false`, o primeiro bloco de código é ignorado e o segundo bloco é executado.
O programa continua a execução na primeira linha de código a seguir à palavra-chave `end`.

~~~~exercism/note
Em Julia, a palavra-chave `end` assinala o fim de todas as expressões de bloco.
Esta sintaxe não é específica das expressões `if` nem das definições de funções.
~~~~

Nos casos em que o segundo bloco de código seria apenas outra expressão `if`, o `elseif` permite-nos evitar aninhar expressões `if` dentro do bloco:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

Se uma expressão `if` só precisar de executar código para um dos casos, não é necessário escrever o ramo `else`.

## Operador ternário

As instruções `if-else` simples também podem ser escritas com o operador ternário `a ? b : c`.
Se `a` for verdadeiro, então `b` será avaliado.
Caso contrário, avalia `c`.

Por exemplo, a seguinte função

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

também pode ser escrita como

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

Isto é especialmente útil se quiseres atribuir um valor diferente a uma variável consoante uma condição.
`x = a ? b : c` atribui `b` a `x` se `a` for verdadeiro e, caso contrário, atribui `c` a `x`.
Por exemplo:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## Avaliação de curto-circuito

Se várias expressões Boolean estiverem encadeadas com os operadores `&&` e `||`, a Julia só avalia o menor número de expressões necessário para determinar o valor de toda a cadeia.

Por exemplo, considera a cadeia de expressões `n > 0 && k > 10`.
Se `n` for igual a `5`, a primeira parte da cadeia, `n > 0`, é `true`, e é necessário avaliar a segunda expressão, `k > 10`, para determinar se a expressão completa é `true`.
No entanto, se `n` for igual a `-5`, sabemos que a cadeia como um todo **não pode** ser `true`, porque a sua primeira expressão é `false`.

Se, em vez disso, considerarmos `n > 0 || k > 10`, acontece o oposto.
Se `n` for igual a `5`, a primeira parte da cadeia, `n > 0`, é `true`, e sabemos que a cadeia completa será `true`, independentemente da segunda expressão.
No entanto, se `n` for igual a `-5`, é necessário avaliar a segunda expressão.

Este comportamento pode ser usado para escrever instruções `if` muito curtas:

```julia
if a
    b
end
```

é equivalente a

```julia
a && b
```

A última expressão de uma cadeia de `&&` e `||` não precisa de ser uma expressão Boolean.
Vais encontrar muitas vezes esta funcionalidade a ser usada para erros ou devoluções antecipadas.
Por exemplo, usando a função `dessert(fruit)` definida acima:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
