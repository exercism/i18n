# Instruções

Neste exercício vais implementar um conjunto parcial de rotinas utilitárias para ajudar um programador a limpar nomes de identificadores.

Ao longo das 4 tarefas vais construir gradualmente a rotina `clean`. Um identificador válido é composto por zero ou mais letras e underscores.

Em todos os casos, é garantido que a string de entrada não é nil. Se for passada uma string vazia à função `clean`, deve ser devolvida uma string vazia.

Repara que quem chama deve evitar chamar a rotina `clean` com um identificador vazio, uma vez que esses identificadores não têm qualquer efeito.

## 1. Substitui todos os espaços que encontrares por underscores

Implementa a função `clean` para substituir todos os espaços por underscores. Isto também se aplica a espaços no início e no fim.

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. Substitui os carateres de controlo pela string em maiúsculas "CTRL"

Modifica a função `clean` para substituir os carateres de controlo pela string em maiúsculas `"CTRL"`.

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. Converte kebab-case em camelCase

Modifica a função `clean` para converter kebab-case em camelCase.

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. Omite as letras gregas minúsculas

Modifica a função `clean` para omitir todas as letras gregas no intervalo de 'α' a 'ω'.

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
