# Apêndice das instruções

## Dicas

Para passares no teste, vais precisar de criar alguns tipos com que o teu código vai trabalhar. Precisas de um objeto para `School` que guarde uma sequência do tipo `Student`, que será um tuplo de `string` e `int` para guardar o nome e a nota dos alunos.

Aqui está algum código para os tipos que te pode ajudar a começar

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
