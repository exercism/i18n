# Exercism CLI

A [Exercism CLI][cli] permite que os alunos descarreguem exercícios e submetam soluções para o site. Também suporta o comando `exercism test`, que executa o comando específico de cada track para correr os testes.

## Adicionar uma nova linguagem

Os comandos de teste específicos de cada track estão definidos num [ficheiro de configuração][test-configurations]. Podes adicionar suporte para a tua linguagem acrescentando uma entrada a esse [ficheiro de configuração][test-configurations], em que a chave é o slug do track.

### Marcadores de posição do comando de teste

Há três marcadores de posição que podes usar no comando específico de cada track:

- `{{test_files}}`: uma lista de ficheiros de teste separados por espaços (tal como aparece na chave `.files.test` do ficheiro `.meta/config.json` do exercício)
- `{{solution_files}}`: uma lista de ficheiros de solução separados por espaços (tal como aparece na chave `.files.solution` do ficheiro `.meta/config.json` do exercício)
- `{{slug}}`: o slug do exercício (tal como aparece na chave `slug` do exercício no ficheiro `config.json` da raiz do track)
