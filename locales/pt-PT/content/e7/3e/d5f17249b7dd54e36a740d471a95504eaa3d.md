# Instruções

Estás a trabalhar na implementação de um RPG.
A personagem do jogador é representada pelo seguinte:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

Neste jogo, os jogadores têm de atingir o nível 10 antes de desbloquear uma reserva de mana, que podem usar para lançar feitiços.
Antes disso, a mana do Player é `Option::None`.

Estás a trabalhar em duas funcionalidades deste jogo: o mecanismo de reviver e o mecanismo de lançar feitiços.

O método `revive` deve verificar se o Player está mesmo morto (a sua saúde chegou a 0) e, se estiver, o método deve devolver uma nova instância de Player com 100 de saúde.
O método `revive` deve preservar o nível do Player.
Se o nível do Player for 10 ou superior, deve ser revivido com 100 de mana.
Se o nível do Player for inferior a 10, a sua mana deve ser `Option::None`.

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

Se o método `revive` for chamado num Player cuja saúde seja 1 ou superior, o método deve devolver `Option::None`.

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

O método `cast_spell` recebe uma referência mutável ao Player, bem como um parâmetro `mana_cost` que indica quanta mana o feitiço custa.
Devolve a quantidade de dano causado pelo feitiço lançado.

- Se o jogador não tiver acesso a uma reserva de mana, tentar lançar o feitiço tem de diminuir a sua saúde no custo de mana do feitiço.
  O dano devolvido tem de ser 0.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- Se o jogador tiver uma reserva de mana mas mana insuficiente, o método não deve afetar a reserva.
O dano devolvido tem de ser 0.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- Caso contrário, o feitiço é lançado com sucesso.
  O `mana_cost` deve ser deduzido da reserva de mana do Player.
  O dano devolvido tem de ser o dobro do custo de mana do feitiço.

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```

Diverte-te!
