# Dicas

## Geral

Este exercício tem muitas soluções possíveis e muitos caminhos que podes seguir ao longo do percurso.
Nenhum caminho é manifestamente "melhor" do que outro, embora um caminho em particular possa ser mais interessante ou mais adequado àquilo que queres aprender ou explorar neste momento.
Alguns caminhos podem trocar velocidade por clareza, outros podem ocupar mais memória mas ser mais escaláveis ou mais fáceis de manter.
Encorajamos-te a experimentar mais do que uma estratégia para veres o que acontece.

_______
-  O Python tem um conjunto robusto de ferramentas para trabalhar com strings. [`str.split`][str.split], [`str.replace`][str.replace], [`str.lower`][str.lower] e [`str.strip`][str.strip] podem ser particularmente úteis neste desafio.
-  Os métodos de strings podem ser encadeados (_desde que o método devolva uma `str`_))
-  Enquanto `str.split()` é muito _específico_, `str.strip()` comporta-se de forma diferente e permite várias combinações.
-  O módulo [`string`][string] (ao contrário de `str`) tem algumas constantes que podem ser úteis para filtrar e comparar ao processar strings.
________

-  Os [dicionários][dict] podem ser úteis para contabilizar quando os itens (as chaves) aparecem mais do que uma vez numa string.
-  [`dict.setdefault()`][dict.setdefault] pode ajudar no processamento quando uma chave pode estar em falta num dicionário.
-  O módulo [Collections][collections] implementa alguns subtipos muito úteis do `dict` principal (o dicionário), concebidos de propósito para coisas como [contabilizar][collections.counter].
________
-  Explorar o módulo [`re`][re] e as expressões regulares pode ser divertido, mas não é de modo algum necessário para resolver este desafio.
-  O [Regex101][regex101] é muito útil para experimentar lógica de expressões regulares.
-  Tanto [`re.sub`][re.sub] como [`re.findall`][re.findall] podem ser estratégias interessantes de usar.
________
-  As [compreensões][comprehensions] podem muitas vezes "achatar" ciclos em que se acrescentam itens a uma lista ou se inserem num dicionário.
-  As [expressões geradoras][generator expressions] podem muitas vezes "substituir" uma compreensão de lista quando é preciso um iterável.
  As expressões geradoras são avaliadas de forma "preguiçosa" e ocupam menos espaço em memória do que uma compreensão de lista equivalente.
