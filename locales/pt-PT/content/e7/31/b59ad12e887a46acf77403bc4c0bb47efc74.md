# Dicas

O `i32` tem uma largura de quatro bytes.

"Uma instância de memória... contém um vetor de bytes. O comprimento do vetor é sempre um múltiplo do tamanho de página do WebAssembly, que é definido como a constante 65536"

[Especificação WebAssembly: Instâncias de memória](https://webassembly.github.io/spec/core/exec/runtime.html#page-size)

"A instrução `memory.size` devolve o tamanho atual de uma memória. A instrução `memory.grow` aumenta a memória num determinado delta e devolve o tamanho anterior, ou -1 se não for possível alocar memória suficiente. Ambas as instruções funcionam em unidades de tamanho de página."

[Especificação WebAssembly: Instruções de memória](https://webassembly.github.io/spec/core/syntax/instructions.html#syntax-instr-memory)
