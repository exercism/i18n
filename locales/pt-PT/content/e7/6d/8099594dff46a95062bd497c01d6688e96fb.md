# Introdução

## Correspondência de padrões com literais

Embora as expressões `if/else` possam ser usadas para executar lógica condicional, o Haskell também tem uma forma mais poderosa de o fazer: a [correspondência de padrões][pattern-matching].
Com a correspondência de padrões, podes testar um valor contra um ou mais _padrões_.
Um exemplo desses padrões é o _padrão constante_, que compara um valor com uma constante (por exemplo, `1` ou `"hello"`).

Ao definir funções, podes definir corpos de função distintos para padrões diferentes.
Isto dá origem a código limpo, simples e legível.
Podes fazer correspondência de padrões em qualquer tipo de dados: números, carateres, listas, tuplos, etc.

Por exemplo, uma função trivial que recebe um número inteiro (`Int`) e o torna _1_ mais próximo de _0_ pode ser escrita assim:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

A correspondência de padrões começa a revelar o seu valor quando é usada em conjunto com outros padrões, como o _padrão variável_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

O exemplo acima trata todos os valores de entrada diferentes de _0_ da mesma forma e produziria resultados incorretos para números negativos.
Isto pode resolver-se com padrões condicionais, conhecidos como _guardas_, que são expressos com o símbolo `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

Nos exemplos acima, nem todos os valores de entrada possíveis têm um padrão correspondente.
O compilador deteta isto e emite um aviso.
Esta é uma funcionalidade muito útil do Haskell, que ajuda a garantir que todos os caminhos possíveis estão cobertos, evitando erros em tempo de execução.
É conhecida como _verificação exaustiva_.
Para resolver o aviso, tens de tratar todos os casos.
Dentro das _guardas_, podes usar a expressão `otherwise` como açúcar sintático para `True` para apanhar todos os padrões restantes.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

A correspondência de padrões testa um valor contra cada padrão, de cima para baixo, até encontrar um padrão correspondente e executar a lógica associada a esse padrão.
**A ordem dos padrões é importante!**
