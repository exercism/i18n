# Instruções

Neste exercício vais escrever mais algum código para te ajudar a cozinhar a tua brilhante lasanha do teu livro de cozinha preferido.

Tens cinco tarefas, todas relacionadas com o tempo gasto a cozinhar a lasanha.

## 1. Permitir alterar o tempo esperado no forno

Queres escrever uma função `remainingMinutesInOven` melhorada que recebe como parâmetro o número de minutos decorridos que a lasanha está no forno e devolve quantos minutos a lasanha ainda tem de permanecer no forno, com base no tempo esperado no forno, em minutos, da tarefa anterior.
Antes, baseavas-te num valor constante, `expectedMinutesInOven`, que vinha de fora da função `remainingMinutesInOven`.
Isso era um pouco demasiado confuso para o teu gosto e não era suficientemente flexível, pois não te permitia alterar o tempo esperado no forno.

Para arrumar as coisas, define a função `remainingMinutesInOven` que recebe como parâmetro o número de minutos decorridos que a lasanha está no forno, bem como um parâmetro `expectedMinutesInOven` com um valor predefinido de 40.
A tua função deve devolver quantos minutos a lasanha ainda tem de permanecer no forno, com base no tempo esperado no forno, em minutos, da tarefa anterior.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. Permitir números diferentes de camadas

Tinhas escrito anteriormente uma função `preparationTimeInMinutes` que recebe como parâmetro o número de camadas que adicionaste à lasanha e devolve quantos minutos gastaste a preparar a lasanha, partindo do princípio de que cada camada demora 2 minutos a preparar.
No entanto, não estás especialmente satisfeito com esta função, porque tens de contar tu próprio o número de camadas da tua lasanha antes de poderes chamar esta função, e quem é que tem tempo para isso?

Para tornar as coisas mais fáceis para ti, escreve uma função, `preparationTimeInMinutes`, que recebe um parâmetro `String` variádico, `layers`, onde listas as diferentes camadas da tua lasanha.
A função vai depois contar o número de camadas da tua lasanha e devolver o tempo de preparação necessário.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. Calcular as quantidades de massa e de molho

Antes de começares a montar a tua lasanha, queres certificar-te de que tens molho e massa suficientes para construir a lasanha dos teus sonhos.
Para cada camada de massa da tua lasanha, vais precisar de 3 placas de massa.
Para cada camada de molho da tua lasanha, vais precisar de 0,2 litros de molho.

Define a função `quantities` que recebe um parâmetro `String` variádico, `layers`, onde listas as diferentes camadas da tua lasanha.
A função vai depois determinar a quantidade de massa e de molho necessária para preparar a tua refeição. O resultado deve ser devolvido num tuplo do tipo `(noodles: Int, sauce: Double)`.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. Converter litros em onças fluidas no local

Infelizmente, o molho que tens à mão tem o volume indicado em onças fluidas em vez de litros.
Para te ajudar a saber se tens molho suficiente à mão, escreve uma função, `toOz`, que recebe um parâmetro de tuplo in-out, `(noodles: Int, sauce: Double)`, e converte a quantidade de molho em onças fluidas.
Repara que há 33,814 onças fluidas por litro.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. Determinar o melhor vinho para servir

Por fim, queres saber que tipo de vinho servir com a tua lasanha.
Ouviste dizer que deves servir vinho branco se houver mais mozarela, ricota e béchamel na lasanha do que carne e molho, e vinho tinto caso contrário.
Escreve uma função `redWine` que recebe um parâmetro `String` variádico, `layers`, onde listas as diferentes camadas da tua lasanha.
A função vai usar cinco funções aninhadas para determinar o número de camadas de mozarela, ricota, béchamel, molho e carne na lasanha, e comparar o número de camadas para determinar se deve ser servido vinho tinto, devolvendo `true` nesse caso e `false` caso contrário.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
