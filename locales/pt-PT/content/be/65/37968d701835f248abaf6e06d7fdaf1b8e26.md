# Introdução

Em Haxe, um tipo abstrato é um tipo que é um tipo diferente em tempo de execução. É uma funcionalidade em tempo de compilação que define tipos "por cima de" tipos concretos, de modo a modificar ou ampliar o seu comportamento:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Aqui estamos a declarar o tipo `AbstractInt` com a palavra-chave `abstract`. A sua sintaxe é muito semelhante à da `class`. E tal como as classes, os tipos abstratos podem ter métodos. Também podem ser instanciados e usados tal como as classes:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
