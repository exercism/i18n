# Instruções

Neste exercício vais trabalhar com contas poupança. Todos os anos, o saldo de uma conta poupança é atualizado com base na taxa de juro. A taxa de juro que o banco oferece depende da quantidade de dinheiro na conta (o seu saldo):

- 0,5% para um saldo não negativo inferior a `1000` dólares.
- 1,621% para um saldo positivo maior ou igual a `1000` dólares e inferior a `5000` dólares.
- 2,475% para um saldo positivo maior ou igual a `5000` dólares.
- 3,213% para um saldo negativo (resulta em juro negativo).

Tens três tarefas, cada uma delas sobre o saldo e a respetiva taxa de juro.

## 1. Calcula a taxa de juro

Implementa o método `SavingsAccount.interest_rate` para calcular a taxa de juro com base no saldo indicado:

```ruby
SavingsAccount.interest_rate(200.75)
#=> 0.5
```

Repara que o valor devolvido é uma instância de `Float`.

## 2. Calcula a atualização anual do saldo

Implementa o método `SavingsAccount.annual_balance_update` para calcular a atualização anual do saldo, tendo em conta a taxa de juro:

```ruby
SavingsAccount.annual_balance_update(200.75)
#=> 201.75375
```

Repara que o valor devolvido é uma instância de `Float`.

## 3. Calcula os anos necessários para atingir o saldo pretendido

Implementa o método `SavingsAccount.years_before_desired_balance` para calcular o número mínimo de anos necessários para atingir o saldo pretendido:

```ruby
SavingsAccount.years_before_desired_balance(200.75, 214.88)
#=> 14
```

Repara que o valor devolvido é uma instância de `Integer`.
