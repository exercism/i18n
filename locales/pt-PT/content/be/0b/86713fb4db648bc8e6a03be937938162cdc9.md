# Introdução

Em Go, `for range` repete um bloco de código para os valores de uma expressão range.
A expressão range determina se cada iteração produz um valor ou dois.

## Expressões range

### Iterar uma slice com range

`range` sobre uma slice produz o índice e o valor de cada elemento, por ordem:

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### Iterar um map com range

`range` sobre um map produz cada chave e cada valor, mas a ordem de iteração não é garantida.
Go aleatoriza deliberadamente a ordem de iteração dos maps, por isso o mesmo programa pode produzir resultados diferentes em cada execução.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### Iterar uma string com range

`range` sobre uma string produz o índice do byte e cada rune (ponto de código Unicode).
No exemplo seguinte, `子` ocupa três bytes, por isso `猫` começa no índice de byte `3`, e não em `1`.

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

Se precisares dos índices das runes, converte a string numa slice de runes:

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### Iterar um número inteiro com range

`range` pode iterar diretamente sobre um número inteiro, produzindo valores desde `0` até esse número inteiro, sem o incluir.
Os valores zero e negativos são válidos, mas não produzem nenhuma iteração.

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### Iterar um iterador com range

`range` aceita um iterador do tipo `iter.Seq[V]` ou `iter.Seq2[K, V]`.
Um iterador é uma função que produz uma sequência de valores, um de cada vez.
`range` pode então percorrer esses valores.

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### Iterar um canal com range

Por fim, `range` pode receber valores enviados através de um canal até que esse canal seja fechado noutro ponto do programa.
Os canais são abordados com mais profundidade mais adiante no percurso de aprendizagem.

## Omitir o índice ou o valor

O Go não compila se declarares uma variável mas nunca a usares.

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

Se só precisares do valor, atribui o índice ou a chave a `_` para o ignorar.

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

Se só precisares do índice, omite-o por completo:

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

Se não precisares nem do índice nem do valor, podes omitir os dois:

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
