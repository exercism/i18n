# usa a interpolação de strings

Usa a [interpolação de strings](https://docs.scala-lang.org/overviews/core/string-interpolation.html) para construir uma string de forma dinâmica, em vez de recorreres à concatenação de strings ou a `StringBuilder`.

A principal vantagem é que o código com interpolação de strings costuma ser mais fácil de ler do que a concatenação de strings ou o `StringBuilder`.
