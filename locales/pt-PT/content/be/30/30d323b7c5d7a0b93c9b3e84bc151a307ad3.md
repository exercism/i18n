# Sobre

Disponível a partir do `PHP 8.0.0`, as **Declarações de tipos de união** aceitam valores de vários tipos diferentes, em vez de um único tipo. As definições de tipos de união são feitas com a barra vertical (`|`) para separar os tipos.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Nuances

- Os tipos `null` podem ser declarados como _anuláveis_, usando `?Type` ou `Type1|Type2|null`.
- os tipos declarados duplicados ou redundantes resultam num erro de compilação.
- `void` não pode ser usado como parte de uma declaração de tipo de união.
