# Dicas

## Geral

- Revê a referência sobre [Type Juggling][ref-type-juggling]

- Revê a referência sobre [Strings numéricas][ref-numeric-strings]

## 1. Calcula a soma dos números na máquina de slot

- Podes usar [`implode`][ref-implode] para combinar os dígitos.
  O `implode` converte implicitamente os dígitos do array em strings e devolve uma string.
- Para somar os números, vê o conceito de [operações aritméticas][ref-arithmetic-ops].
  Os operadores aritméticos convertem implicitamente strings em inteiros ou em números de vírgula flutuante.

## 2. Determina se um número é um palíndromo

- Podes resolver esta tarefa comparando o número dado com a sua versão invertida.
  Para isso, tens primeiro de inverter o número dado.
  Depois, devolve o resultado da comparação das duas versões.
- Podes usar [`strrev`][ref-strrev] para obter o número invertido.
  O `strrev` converte implicitamente o número numa string e devolve uma string.
- Por fim, podes [comparar][ref-comparison-ops] o número dado com a string invertida.
  Ao escrever a condição para isso, usa a [comparação][ref-comparison-ops] que faz Type Juggling.
  O PHP vai converter a string invertida num número para esta comparação.
- O resultado da comparação é um `bool`, que é o tipo a devolver.

## 3. Gera uma mensagem de erro para dados inválidos introduzidos pelo utilizador

- Podes usar [condicionais][ref-if-statement] para verificar as diferentes condições.
- Primeiro, deves tratar o caso em que o valor não contém carateres.
- A seguir, trata o caso em que o valor introduzido não é um número nem `0`.
  As regras de conversão de tipos dos [operadores de comparação][ref-comparison-ops] estão contra ti neste caso.
  Fazem com que o PHP compare strings em alguns casos, e isso dá resultados errados.
  Usa a conversão explícita para `int` que aprendeste na introdução.
  Assim podes contar com os [operadores de comparação][ref-comparison-ops] para um número maior do que `0`.
