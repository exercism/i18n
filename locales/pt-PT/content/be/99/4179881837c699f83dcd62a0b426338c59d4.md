# Instalação

Podes instalar o Cairo bastando descarregar o Scarb. O Scarb junta o compilador de Cairo e o servidor de linguagem de Cairo num único pacote fácil de instalar, para que possas começar a escrever código Cairo de imediato. O Scarb é também o gestor de pacotes do Cairo.

Para obteres as instruções de instalação recomendadas para a tua plataforma, vai ao [site oficial de Cairo](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/).

Por sistema operativo:

- Linux/MacOS
    1. Instala o [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. Instala o [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. Verifica a instalação numa nova sessão de terminal `scarb --version`
- Windows
    1. Instala o [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. Verifica a instalação numa nova sessão de terminal `scarb --version`

Ter as ferramentas instaladas não é tudo! O suporte da IDE é um enorme impulso de produtividade com que a maioria dos programadores já conta.
Se usas o Visual Studio Code, recomendamos que instales a [extensão do Cairo](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1), que oferece realce de sintaxe, conclusão de código e outras funcionalidades úteis!
