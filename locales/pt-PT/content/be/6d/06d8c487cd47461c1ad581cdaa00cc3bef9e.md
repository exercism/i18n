# https://www.php.net/manual/en/language.basic-syntax.phptags.php"Operador de resolução de âmbito

O operador de resolução de âmbito (`::`) permite-nos referenciar uma classe para aceder às suas constantes, propriedades estáticas ou métodos estáticos.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Usar `self` e `static` com o operador de resolução de âmbito

Pode ser necessário que um objeto referencie o seu próprio âmbito. Para isso, a palavra-chave `self` permite que uma classe referencie o seu próprio âmbito. Usar a palavra-chave `self` desacopla a classe do seu próprio nome, o que facilita a manutenção do código ao longo do tempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

No entanto, `self` está ligado lexicograficamente à classe onde aparece.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

Avaliar `MyOtherClass::getMyValue` continua a devolver `1` em vez de `99`. Para contornar isto, usa a palavra-chave `static` com o operador de resolução de âmbito para fazer a "ligação tardia" da referência à classe descendente atual.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Usar `parent` com o operador de resolução de âmbito

Pode ser necessário referenciar especificamente uma constante, propriedade ou método disponível a partir do âmbito da classe pai:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

Na programação orientada a objetos, o mais comum é usar `parent` para chamar o construtor da classe pai quando se instancia um objeto:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Ressalvas

### Visibilidade de constantes, propriedades e métodos

O operador de resolução de âmbito continua a seguir as regras definidas pelos modificadores de visibilidade `public`, `private` e `protected`.
