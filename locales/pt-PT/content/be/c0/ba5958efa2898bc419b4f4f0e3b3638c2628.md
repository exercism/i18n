# Sobre

Uma *expressão regular* (regex) é um pequeno padrão que descreve a forma de um texto. As ferramentas de regex do Factor encontram-se no vocabulário [`regexp`][regexp], e um padrão escreve-se como um literal entre `R/ ` e `/`.

Na sua maioria, os carateres de um padrão correspondem a si próprios. O poder expressivo vem das classes de carateres e dos quantificadores:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

Assim, `R/ [A-Z]{2}-\d{4}/` corresponde a "duas maiúsculas, um hífen, quatro algarismos".

## Corresponder à string inteira vs. procurar

`matches?` só tem sucesso quando a string *inteira* se ajusta ao padrão. As outras palavras procuram *dentro* de uma string:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## Slices

`first-match` e `re-split` devolvem objetos `slice`: vistas leves sobre a string original, em vez de strings novas. Usa `>string` para converter um slice quando precisares de uma string isolada (por exemplo, para comparar com um literal de string). `all-matching-subseqs` já devolve strings.

## Substituir

`re-replace` substitui todas as correspondências por uma string de substituição e devolve o resultado:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## Construir um padrão em tempo de execução

`R/ /` é analisado quando o ficheiro é carregado. Para construir um padrão a partir de uma string calculada em tempo de execução, usa `<regexp>`:

```
<regexp> ( string -- regexp )
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
