## Implementando operações de List

O objetivo deste exercício é implementar você mesmo alguns dos métodos de List.
É natural usar um objeto List no backend para guardar os dados.
Não mexa nos métodos de List (como `where`, `map`, etc.).

Existem algumas operações "primitivas" de List que são inevitáveis, como:

* fatiamento: `list[from..to]`
* adição: `list.add(item)`

## Protocolo de iterador

As operações de lista que você vai implementar giram em torno de iterar de várias formas.
Leia sobre [o protocolo de iterador][iter].
Aí você vai poder fazer:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
