# Introdução

Este exercício vai te ensinar os blocos de construção fundamentais do Ruby.
É bastante conteúdo, mas não se preocupe se parecer muita coisa: vamos nos aprofundar em tudo com muito mais detalhes conforme avançamos pelo track.

Uma das coisas essenciais para entender o Ruby é que ele é uma [linguagem orientada a objetos][object-oriented-programming] e que **tudo no Ruby é um [objeto][object]**. Números, strings, arrays: todos são objetos.

## Variáveis e constantes

Costumamos usar objetos dando nomes a eles, com variáveis ou constantes.

As variáveis são sempre escritas em [snake case][snake-case].
Uma variável pode referenciar objetos diferentes ao longo de sua existência.
Por exemplo, `my_first_variable` pode ser definida e redefinida várias vezes com o operador `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Já as constantes devem ser atribuídas uma única vez.
Elas precisam começar com letra maiúscula e normalmente são escritas em caixa alta, com as palavras separadas por underscores.
Por exemplo:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## Classes

O Ruby é organizado em classes.
As classes são definidas com a palavra-chave `class` seguida do nome da classe.
Os objetos geralmente são criados instanciando classes com o método `.new`.
Por exemplo:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## Métodos

Unidades de funcionalidade ficam encapsuladas em métodos, semelhantes às _funções_ de outras linguagens.

Um método pode ser definido com argumentos posicionais, argumentos nomeados (definidos e chamados com a sintaxe `:`) ou não ter nenhum argumento.

Os métodos retornam implicitamente o resultado da última instrução avaliada ou podem retornar explicitamente um objeto com a palavra-chave `return`.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

Os métodos são chamados com a sintaxe `.`:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
