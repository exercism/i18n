## Geral

* Uma lista duplamente encadeada não tem uma hierarquia de ownership clara, e é por isso que ela exige o uso de unsafe ou de abstrações para ownership compartilhado, como `Rc`. Essas abstrações trazem uma sobrecarga desnecessária para este caso.

* Consulte o [Rustonomicon](https://doc.rust-lang.org/nomicon/) para ver detalhes sobre como usar `unsafe {}` corretamente.

* Várias funções exigem um comportamento semelhante em direções diferentes (para frente ou para trás). Tente não duplicar os caminhos de código compartilhados.
