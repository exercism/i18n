# Usar `grep` ou não usar `grep`, eis a questão

## Ajustes da trilha de AWK aos requisitos

Não é obrigatório implementar uma análise da linha de comando de verdade: as flags são fornecidas em uma string separada por espaços, fácil de dividir.
```sh
gawk -f grep.awk -v flags="l v" -v pattern="hello" file1.txt file2.txt
```

Assim como o grep de verdade, seu programa vai retornar um **status de saída diferente de zero** quando _nenhuma correspondência for encontrada_.
