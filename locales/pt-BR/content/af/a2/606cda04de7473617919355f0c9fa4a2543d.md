# Dicas

## Geral

- Cada tarefa é apenas uma camada fina sobre uma palavra do vocabulário
  [`math.combinatorics`][math.combinatorics].
- As palavras de contagem recebem dois números inteiros; as palavras de
  listagem recebem uma sequência.

## 1. Contar combinações

- `nCk ( n k -- m )` retorna o número de maneiras de escolher `k` itens
  entre `n`. A pilha já está na ordem certa, é só chamá-la.

## 2. Contar permutações

- `nPk ( n k -- m )` retorna o número de maneiras ordenadas de escolher
  `k` itens entre `n`.

## 3. Listar combinações

- `all-combinations ( seq k -- combinations )` retorna todos os
  subconjuntos de `k` elementos de `seq`, em ordem lexicográfica.

## 4. Listar permutações

- `all-permutations ( seq -- permutations )` retorna todas as ordenações
  de `seq`.

## 5. Combinações que somam um valor alvo

- Comece com todas as combinações de `k` elementos que vêm de
  `all-combinations`.
- Mantenha apenas as combinações cujos elementos somam `target`. O
  `filter`, de [`sequences`][sequences], recebe uma quotation que retorna
  um Boolean; dentro dela, `sum` (de [`math`][math]) soma uma combinação
  inteira, e `=` a compara com o alvo.
- Como a tarefa precisa de `target` dentro da quotation, definir a palavra
  com `::` (de [`locals`][locals]) permite se referir a `seq`, `k` e
  `target` pelo nome.
