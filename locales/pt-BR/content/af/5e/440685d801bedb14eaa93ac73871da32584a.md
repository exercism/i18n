# Apêndice de instruções

## Mensagens de exceção

Às vezes é preciso [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você faz isso, deve sempre incluir uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda muito no debug. Em situações em que você sabe que a origem do erro será de um determinado tipo, você pode optar por lançar um dos [tipos de erro embutidos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda deve incluir uma mensagem significativa.

Este exercício específico exige que você use a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um `ValueError` quando as bases de entrada e de saída forem diferentes. Os testes só vão passar se você fizer o `raise` da `exception` e incluir uma mensagem significativa junto dela.

Para lançar um `ValueError` com uma mensagem, escreva a mensagem como argumento para o tipo `exception`:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
