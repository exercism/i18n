# Dicas

## Geral

- O tutorial [strings em csharp.net][tutorial-csharp.net-strings] traz uma boa introdução às `string`s do C#.
- A classe `string` tem muitos [métodos internos][docs-string-methods] úteis.

## 1. Obter a mensagem de uma linha de log

- [Este tutorial][tutorial-docs.microsoft.com-search-text-in-string] explora diferentes opções para procurar texto em uma string.
- Remover espaços em branco é algo [interno][tutorial-docs.microsoft.com-trim-white-space].

## 2. Obter o nível de log de uma linha de log

- [Este tutorial][tutorial-docs.microsoft.com-changing-case] mostra como alterar maiúsculas e minúsculas em uma `string`.

## 3. Reformatar uma linha de log

- Existem várias formas de [concatenar strings][tutorial-docs.microsoft.com-concatenate-strings], mas a preferida costuma ser a [interpolação de strings][tutorial-csharp.net-string-interpolation].
