# Introdução

Haxe tem suporte nativo a expressões regulares. Elas podem ser usadas para verificar o formato de uma string, transformar uma string ou extrair dados regulares de um texto.

Para criar uma expressão regular, digite entre `~/` e `/`:

```haxe
var r = ~/haxe/i;
```

Uma outra forma de fazer isso é usando a instância de `EReg()`:

```haxe
var r = new EReg("haxe", "i");
```

Aqui, o `i` é uma flag que faz o padrão não diferenciar maiúsculas de minúsculas. Existem outras flags, incluindo:

- `g`: substituição global.
- `m`: correspondência em várias linhas

Entre `~/` e `/`, você digita os padrões da expressão regular. Por exemplo, você quer procurar uma string que contenha letras de A a Z. Aqui podemos usar o padrão de intervalo `[A-Z]`. Existem muitos padrões de expressão, incluindo:

- `.`: qualquer caractere
- `*`: repetir zero ou mais vezes
- `+`: repetir uma ou mais vezes
- `[A-Z0-9]`: intervalos de caracteres
