# Acessibilidade

A missão do Exercism é ajudar o maior número possível de pessoas. Queremos que todo mundo consiga usar nossos serviços e nos esforçamos para garantir que nosso conteúdo atenda aos padrões de acessibilidade.

Criamos nosso site com os seguintes objetivos:

- O texto deve ser claro e simples de entender. Você deve conseguir aumentar o zoom em até 300% sem que o texto saia da tela
- Você deve conseguir navegar pela maior parte do site usando apenas o teclado
- Você deve conseguir navegar pela maior parte do site usando um software de reconhecimento de voz
- Você deve conseguir ouvir a maior parte do site usando um leitor de tela (incluindo a versão mais recente do JAWS, NVDA e VoiceOver)

## Quão acessível é o nosso site?

Nosso site está em conformidade com o padrão AA das Diretrizes de Acessibilidade para Conteúdo Web, versão 2.1.

## Como melhorar a acessibilidade

Estamos sempre atentos para saber se alguma parte dos nossos sites não está acessível.
Se você encontrar algo que não está bom o suficiente, abra um problema no nosso [rastreador de problemas](https://github.com/exercism/exercism/issues) explicando o que precisamos melhorar.
