# Dicas

## Geral

- Você precisa definir todos os métodos fora do `initialize` no `module`, `TicketingReservation`.
- O módulo precisa ficar acima da classe `TicketSystem`.

## 1. Crie um sistema de ingressos

- Crie uma classe chamada `TicketSystem`.
- Crie um [construtor][new-initialize] para a classe `TicketSystem`.
- Crie uma [variável de instância][instance-variable] `@tickets_available` que recebe a quantidade do primeiro argumento passado ao construtor.
- Crie uma [variável de instância][instance-variable] `@stadium` que recebe o nome do segundo argumento passado ao construtor.

## 2. Obtenha a quantidade de ingressos disponíveis

- Crie um módulo acima da classe `TicketSystem` chamado `TicketingReservation`.
- Vincule o módulo à classe usando a palavra-chave [include][include].
- Crie um método chamado `tickets_available` dentro do módulo que retorne a quantidade de ingressos disponíveis.

## 3. Faça o pedido de ingressos

- Crie um método chamado `order_ticket?` dentro do módulo.
- Use um [operador de comparação][equality-and-comparison] para verificar se há pelo menos 100 ingressos disponíveis.
- Se houver pelo menos 100 ingressos disponíveis, subtraia 1 da [variável de instância][instance-variable] `@tickets_available`.
- Retorne `true` se houver pelo menos 100 ingressos disponíveis; caso contrário, retorne `false`.

## 4. Mensagem do pedido

- Crie um método chamado `order_message` dentro do módulo.
- Você pode usar métodos já definidos para verificar se há ingressos suficientes disponíveis.
- Para formar a mensagem, você pode usar [interpolação de string][string-interpolation].
