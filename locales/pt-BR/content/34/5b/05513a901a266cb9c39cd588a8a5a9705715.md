# Dicas

## 1. Determine se você vai precisar de uma carteira de motorista

- Use o [operador de igualdade] para verificar se o seu valor de entrada é igual a uma determinada string.
- Use um dos dois [operadores Boolean] para combinar os dois requisitos.
- Você não precisa de uma condicional para resolver esta tarefa. Você pode retornar diretamente a expressão Boolean que montar.

## 2. Escolha entre dois veículos em potencial para comprar

- Você vai precisar da [expressão condicional] `if-then-else` para esta tarefa.
- Use um [operador de comparação] para determinar qual opção vem primeiro na ordem alfabética.
- Por fim, monte a frase de recomendação.
  Você pode usar a concatenação ou a interpolação de strings que aprendeu no conceito de Strings para montar a frase de recomendação.

## 3. Calcule uma estimativa do preço de um veículo usado

- Comece determinando a porcentagem com base na idade do veículo.
  Use uma expressão `if-elsif-else`.
- Para calcular o resultado, aplique a porcentagem ao preço original.
  Por exemplo, `30% of x` pode ser calculado multiplicando `x` por `30` e dividindo por `100`.
