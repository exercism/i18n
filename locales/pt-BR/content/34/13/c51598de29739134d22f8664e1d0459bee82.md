# Instruções

Neste exercício, você vai escrever código para analisar a produção de uma linha de montagem em uma fábrica de carros.
A velocidade da linha de montagem pode variar de `0` (desligada) a `10` (máxima).

Na sua velocidade mais baixa (`1`), são produzidos `221` carros por hora.
A produção aumenta linearmente com a velocidade.
Então, com a velocidade definida em `4`, ela deve produzir `4 * 221 = 884` carros por hora.
No entanto, velocidades mais altas aumentam a chance de que carros com defeito sejam produzidos, e esses carros precisam ser descartados.

Você tem três tarefas.

## 1. Calcule a taxa de sucesso

Implemente o método (_static_) `AssemblyLine.SuccessRate()` para calcular a proporção de itens criados sem erro para uma determinada velocidade.
A tabela a seguir mostra como a velocidade influencia a taxa de sucesso:

- `0`: taxa de sucesso de 0%.
- `1` a `4`: taxa de sucesso de 100%.
- `5` a `8`: taxa de sucesso de 90%.
- `9`: taxa de sucesso de 80%.
- `10`: taxa de sucesso de 77%.

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. Calcule a taxa de produção por hora

Implemente o método (_static_) `AssemblyLine.ProductionRatePerHour()` para calcular a taxa de produção por hora da linha de montagem, levando em conta a taxa de sucesso:

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

Observe que o valor retornado é um `double`.

## 3. Calcule o número de itens funcionais produzidos por minuto

Implemente o método (_static_) `AssemblyLine.WorkingItemsPerMinute()` para calcular quantos carros funcionais são produzidos por minuto:

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

Observe que o valor retornado é um `int`.
