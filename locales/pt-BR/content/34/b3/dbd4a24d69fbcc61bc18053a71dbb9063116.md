# Instruções complementares

## Notas de implementação

O objeto Tree tem dois atributos:

- rótulo `String`
- filhos `List<Tree>`

O programa de teste cria árvores aplicando repetidamente a função construtora
`Tree.of`. Por exemplo, a instrução

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

constrói a seguinte árvore:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

Você pode assumir que não haverá valores duplicados nas árvores de teste.

---

Os métodos `FromPov` e `PathTo` são a parte interessante do exercício.

O método `FromPov` recebe um argumento string `from`, que especifica um nó na
árvore pelo seu valor. Ele deve retornar uma árvore com o valor `from` na raiz.
Você pode modificar a árvore original e retorná-la, ou criar uma nova árvore e
retorná-la. Se você retornar uma nova árvore, fique à vontade para consumir ou
destruir a árvore original. Claro que o ideal é deixá-la sem modificações.

O método `PathTo` recebe dois argumentos string, `from` e `to`, que especificam
dois nós na árvore pelos seus valores. Ele deve retornar o caminho mais curto na
árvore do primeiro até o segundo nó.

## Mensagens de exceção

Às vezes é necessário [lançar uma exceção](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html).
Quando fizer isso, sempre inclua uma **mensagem de erro significativa** para indicar qual é a origem do erro.
Isso deixa seu código mais legível e ajuda muito na depuração.

Este exercício específico exige que você use a [palavra-chave throw](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)
para "lançar" várias `UnsupportedOperationException` se a classe `Tree()` receber uma árvore que não pode ser reorientada, ou se não for possível encontrar um caminho entre um `start node` e um `end node`.
Os testes só vão passar se você `throw` a `exception` e incluir uma mensagem junto com ela.

Para lançar uma `UnsupportedOperationException` com uma mensagem, escreva a mensagem como argumento do tipo `exception`:

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
