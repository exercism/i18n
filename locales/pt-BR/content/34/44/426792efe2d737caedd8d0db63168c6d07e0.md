# Introdução

## Nil

`Nil` no Gleam é um tipo com um único valor, também chamado `Nil`. É parecido com `void` em outras linguagens: é usado quando uma função não tem um valor mais adequado para retornar.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Em Gleam, os valores não são "nil-able" nem "nullable" como em algumas outras linguagens. Um valor só pode ser `Nil` se o tipo dele for `Nil`, e um valor de qualquer outro tipo nunca pode ser `Nil`.

## IO

Como a maioria das linguagens de programação, o Gleam tem "efeitos colaterais", então as funções podem ler e mudar o estado do mundo, além de retornar um valor.

O módulo `gleam/io` da biblioteca padrão do Gleam fornece funções para imprimir strings no console.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Outros pacotes podem fornecer outras funções de IO, como o `simplifile`, um pacote que fornece funções para ler e escrever arquivos.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
