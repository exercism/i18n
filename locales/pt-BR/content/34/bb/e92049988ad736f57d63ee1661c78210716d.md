# Sobre

Haxe é uma linguagem de programação e compilador de código aberto, de alto nível, fortemente tipada, multiplataforma e orientada a objetos, capaz de gerar aplicações e código-fonte para diversas plataformas de computação diferentes a partir de uma única base de código.

Há várias linguagens de destino compatíveis, que atendem a diferentes casos de uso: [Linguagens de destino compatíveis][supported-target-languages]

[Tipos][types] apresenta os sete tipos diferentes de tipos em Haxe e como eles interagem entre si. A discussão sobre tipos continua em [Sistema de tipos][type-system], onde recursos como unificação, parâmetros de tipo e inferência de tipos são explicados.

[Campos de classe][class-fields] trata inteiramente da estrutura das classes em Haxe e, entre outros tópicos, aborda propriedades, campos inline e funções genéricas.

Em [Expressões][expressions], vemos como realmente fazer os programas executarem algo usando expressões.

[Recursos da linguagem][language-features] conclui a referência da linguagem Haxe descrevendo alguns recursos em detalhe, como pattern matching, interpolação de string e eliminação de código morto.
