# Introdução

Em Java, os Booleans são representados pelo tipo `boolean`, cujos valores podem ser `true` ou `false`.

O Java oferece três operadores booleanos:  

- `!` (NÃO): nega o valor booleano  
- `&&` (E): recebe dois valores booleanos e resulta em true se os dois forem true  
- `||` (OU): resulta em true se pelo menos um dos dois valores booleanos for true  

## Exemplos

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
