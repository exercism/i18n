# Testes

## Rodando os testes

A trilha de Haxe usa o framework de testes [Buddy](https://github.com/ciscoheat/buddy).
Você pode instalá-lo assim:

```bash
haxelib install buddy
```

Para rodar os testes, execute o seguinte comando:

```bash
haxe test.hxml
```

No arquivo de testes, cada bloco describe marca uma seção de testes do exercício, e cada teste é um bloco `it` ou `xit`.
Os blocos `it` são executados quando você roda os testes, mas os blocos `xit` são testes pendentes.
Quando você enviar uma solução, o executor de testes do Exercism vai rodar todos os blocos `it` ou `xit`.
Ao trabalhar localmente, apenas o primeiro teste é rodado por padrão.
Para rodar outros testes, mude os blocos `xit` correspondentes para blocos `it` e rode `haxe test.hxml` de novo.


Além disso, alguns exercícios podem exigir a instalação de bibliotecas extras pelo haxelib.
Quando isso acontecer, haverá uma observação nas instruções do exercício.

## Resolvendo o exercício

Resolver um exercício significa fazer todos os testes passarem.
Para ajudar você a começar, cada exercício vem com um arquivo stub de implementação.
Você pode usar esse arquivo como ponto de partida para construir sua solução.
Fique à vontade para remover ou alterar esse arquivo se achar que é o certo a fazer.
Tente focar em um teste de cada vez conforme avança em direção à solução.
