## Geral

- Um laço em x86-64 é feito saltando para um rótulo anterior e pode ser encerrado saltando para um rótulo fora dele.
- Para acessar o conteúdo armazenado em um endereço na memória, você precisa desreferenciá-lo usando `[]`.
- O prefixo para acessar valores de 4 bytes na memória é `dword`.
- Um array é representado pelo seu endereço, que é um valor de 8 bytes em x86-64.
- Se uma função chamada modificar um registrador, salve qualquer valor desse registrador que você for usar depois.
