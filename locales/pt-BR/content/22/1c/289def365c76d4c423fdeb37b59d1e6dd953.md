# Dicas

## Geral

- Todos os endereços de memória neste exercício são alinhados a 16 bytes, então as variantes de movimentação alinhadas (`movaps` para números de ponto flutuante, `movdqa` para inteiros) são apropriadas.
  A memória alinhada também pode ser usada diretamente como operando de origem (mas não como destino).
- Máscaras podem ser definidas na memória.

## 1. Retifique o traço

- O sinal de um número de ponto flutuante de 32 bits é o seu bit mais alto.
  Zerar o bit mais alto torna o número não negativo.
- É possível zerar o bit mais alto fazendo um AND com um número de 32 bits em que todos os bits estão definidos, exceto o mais alto.
- Uma máscara pode ser definida na memória com 4 números de 32 bits empacotados.
- A instrução `andps` aplica o AND a valores de ponto flutuante.

## 2. Leia a escala de um tremor

- O campo do expoente em um número de ponto flutuante IEEE-754 de 32 bits está nos bits de posições 23 a 30, inclusive.
- Os bits do expoente podem ser isolados fazendo um AND (`andps` ou `pand`) entre os números de ponto flutuante e uma máscara em que só os bits 23 a 30 estão definidos.
- Depois que os bits do expoente estiverem isolados, eles podem ser deslocados para o fim de cada lane com um deslocamento lógico para a direita (`psrld`).
- O viés de um número de ponto flutuante IEEE-754 de 32 bits é 127.
  Ele pode ser removido subtraindo 127 de cada lane (`psubd`).

## 3. Torne a resolução mais grosseira

- Um deslocamento aritmético para a direita (`psrad`) em `n` divide por `2^n`, preservando o sinal e arredondando em direção ao infinito negativo.
- As instruções de deslocamento empacotadas obtêm a contagem de um imediato ou de um registrador `xmm`, não de um registrador de uso geral (GPR).
- A instrução `movq` pode ser usada para mover 64 bits brutos de um GPR para um registrador `xmm`.

## 4. Aplique gate nos canais

- `por` pode ser usada para combinar todos os bits definidos em qualquer um dos operandos.
- `pandn` calcula ((NOT destino) AND origem) em uma única instrução.
  Ela pode ser usada para zerar todos os bits da origem que estão definidos no destino.

## 5. Alterne os bits de calibração

- Para inverter apenas os bits desbloqueados, primeiro é preciso zerar no toggle todos os bits bloqueados.
- `pandn` calcula ((NOT destino) AND origem) em uma única instrução.
  Ela pode ser usada para zerar todos os bits da origem que estão definidos no destino.
- `pxor` pode ser usada para inverter os bits selecionados pelo toggle restante em cada palavra de status.

## 6. Amplifique o traço

- O campo do expoente em um número de ponto flutuante IEEE-754 de 32 bits está nos bits de posições 23 a 30, inclusive.
  Para levar o ganho `k` à posição certa, ele deve ser deslocado para a esquerda.
- Somar os ganhos deslocados aos bits brutos das leituras (`paddd`) tem o efeito de multiplicar a leitura por `2^k`.
  O padrão de bits continua válido porque é garantido que as entradas e os resultados são normais.
