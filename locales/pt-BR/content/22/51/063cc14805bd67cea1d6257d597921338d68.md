# Dicas

## 1. Calcule a taxa de juros

- Por padrão, qualquer número de ponto flutuante definido no código Go é tratado como `float64`.
  Como o tipo de retorno da função `InterestRate` é `float32`, você não precisa fazer nenhuma conversão de tipo.

## 2. Calcule os juros

- Ao calcular os juros, pode ser útil perceber que `InterestRate` retorna uma porcentagem.
- Você pode usar a função definida na tarefa anterior (`InterestRate`) para calcular os juros.
- Talvez você precise converter o resultado de `InterestRate` para `float64`.

## 3. Calcule a atualização anual do saldo

- Ao calcular a atualização anual do saldo, use as funções que foram definidas nas etapas anteriores.

## 4. Calcule os anos necessários para atingir o saldo desejado

- Para calcular os anos, você pode continuar iterando até atingir o saldo desejado, usando um [laço `for`](https://gobyexample.com/for).
- Existe um [operador](https://golang.org/ref/spec#IncDec_statements) especial para incrementar valores em 1.
