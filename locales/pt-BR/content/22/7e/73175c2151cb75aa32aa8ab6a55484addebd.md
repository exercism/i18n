# Instruções

Implemente a lógica do jogo da forca usando programação reativa funcional.

[Forca][hangman] é um jogo simples de adivinhar palavras.

[Programação reativa funcional][frp] é uma forma de escrever programas interativos.
Ela difere da perspectiva usual: em vez de dizer "quando o botão for pressionado, incremente o contador", você escreve "o valor do contador é a soma do número de vezes que o botão foi pressionado".

Implemente a lógica básica por trás do jogo da forca usando programação reativa funcional.
Você vai precisar instalar uma biblioteca de FRP para isso, e isso será descrito nos arquivos específicos da linguagem/trilha do exercício.

[hangman]: https://en.wikipedia.org/wiki/Hangman_%28game%29
[frp]: https://en.wikipedia.org/wiki/Functional_reactive_programming
