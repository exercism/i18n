# Sobre

Os tipos numéricos nativos do C++ podem ser divididos em inteiros e números de ponto flutuante.
Os inteiros são números sem parte fracionária, como `0`, `691` ou `-2`.
Os números de ponto flutuante são números com parte decimal, como `6.02214076`, `0.1` ou `-1.616`.

## Inteiros

O exemplo a seguir mostra a declaração e a inicialização de quatro variáveis diferentes.

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Quando você atribui um valor a uma variável `int`, pode fazer isso diretamente com um literal.
Um literal é um número fixo no código, como `9241`.
Existem literais inteiros diferentes para várias bases de representação.
Os literais inteiros decimais são os mais comuns e usam os dígitos de `0` a `9`.
Adicionando um prefixo especial, como `0x`, é possível usar outras bases.
O exemplo acima mostra o número `9421` em suas quatro representações e prefixos.
Todas as variáveis são inicializadas com o mesmo valor.

Para mais detalhes sobre os diferentes sistemas de representação, dê uma olhada em [um pequeno tutorial][cpp_numerical_bases].

Você pode usar um apóstrofo para separar dígitos e facilitar a leitura.
`9'241` é o mesmo que `0b0100'100'0001'1001` ou `92'4'1`.

## Números de ponto flutuante

Os literais de ponto flutuante vêm em duas formas.
Além do intuitivo `0.0024`, é possível usar sua notação científica `2.4e-3`.
O tipo de ponto flutuante mais comum é `double`.

## Aritmética

O C++ oferece suporte a `+`, `-`, `*`, `/`, `(` e `)` e `%` para formar expressões.
O resultado da operação entre dois inteiros também é um inteiro.
`5 / 2` retorna `2`.
Quando um dos tipos envolvidos é um tipo de ponto flutuante, o resultado também será um número de ponto flutuante.
`5.0 / 2` e `5 / 2.0` retornam `2.5`.
`%` é o operador de resto e retorna o resto de uma divisão inteira: `5%3` é `2`.

## Operador de atribuição

O operador de atribuição atribui um literal a uma variável.
A atribuição sempre acontece da direita para a esquerda, nunca o contrário.

```cpp
int length = 5;
int width = 2;
length = width;
```

Aqui, o valor inteiro `5` é atribuído à variável `length`.
Em seguida, o valor inteiro `2` é atribuído à variável `width`.
Por fim, o valor de `width` é copiado para a variável `length` e o valor anterior, `5`, é perdido.
Observe também que estamos apenas atribuindo o valor de `width` a `length` no momento da operação de atribuição.
Portanto, se o valor de `width` mudar depois, isso não afetará o valor que `length` recebeu.

O operador de atribuição pode ser combinado com os outros operadores (aritméticos e bit a bit), formando os operadores de `compound assignment` `+=`, `-=`, `*=`, `/=`, `%=`.
Esses operadores modificam o valor atual de uma variável realizando uma operação sobre ele.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

As variáveis `people` e `eggs` são inicializadas com `0`.
Depois, adicionamos o valor inteiro `2` ao valor existente `0` da variável `people` e atribuímos o resultado de volta a `people`.
Agora `people` passa a valer `2`.
Em seguida, adicionamos `3` ovos para cada pessoa, o que dá `6` ovos no total.
Agora adicionamos esse `6` ao valor existente `0` da variável `eggs` e atribuímos o resultado de volta a `eggs`.
`eggs` agora será `6`.
A expressão equivalente seria `people = people + 2` e `eggs = eggs + (3 * people)`.

## Conversão de tipos

A conversão de tipos transforma um valor de um tipo em outro.
Se um `double` for necessário, um `int` pode ser usado em seu lugar.
O exemplo `5.0 / 2` acima é resolvido por uma conversão implícita de `2` para `2.0`.
Um `double` convertido em `int` pode perder informação.
É boa prática tornar explícitas essas conversões para outro tipo T usando `static_cast<T>`.
A conversão no estilo C, via `(T)`, é desencorajada no C++ moderno, mas vale conhecê-la mesmo assim.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## Precisão e representação

Os números em C++ não podem ser arbitrariamente grandes.
O `int`, por exemplo, é representado por 32 bits.
Isso é suficiente para um conjunto de `2^32` números, cerca de 4 bilhões.
Incluindo o `0`, isso define o maior e o menor número `int` como `-2^31` e `2^31 - 1`.

Os números de ponto flutuante geralmente são implementados com cerca de 15 casas decimais de precisão, mas a representação varia conforme o sistema hospedeiro.
