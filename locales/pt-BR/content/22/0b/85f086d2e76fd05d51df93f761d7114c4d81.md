# deve evitar laço imperativo

Evite usar laços `for` neste exercício.

De acordo com a introdução, existem métodos embutidos no objeto Array do JavaScript voltados para análise.

Dê uma olhada na introdução e/ou na [documentação da MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array#instance_methods) para saber quais métodos estão disponíveis.
