# Sobre

Um arquivo é um fluxo com um nome no disco. O vocabulário [`io.files`][io.files] oferece duas formas de trabalhar com um: palavras de conveniência de arquivo inteiro, que leem ou escrevem tudo em uma única chamada, e abridores de fluxo (os combinadores `with-…`) para ler ou escrever de forma incremental. Os dois se apoiam no mesmo [protocolo de fluxo][stream-protocol] que os fluxos em memória do conceito `io-streams`: um `<file-reader>` e um `<string-reader>` respondem às mesmas palavras.

Toda palavra de arquivo recebe uma **codificação**, o esquema que mapeia bytes para caracteres e vice-versa. Para texto, quase sempre é o [`utf8`][utf8] de `io.encodings.utf8`; para dados binários, usa-se `latin1` ou uma codificação `<byte-array>`.

## Leitura de arquivo inteiro

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` retorna o arquivo inteiro como uma única string. `file-lines` retorna suas linhas como um array, com os terminadores de linha removidos. Isso é útil quando cada linha é um registro.

```factor
USING: io.encodings.utf8 io.files ;

"forecast.txt" utf8 file-contents   ! => "sunny\ncloudy\n"
"forecast.txt" utf8 file-lines      ! => { "sunny" "cloudy" }
```

## Escrita de arquivo inteiro

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

As duas **substituem** o arquivo, criando-o se ele não existir.
`set-file-contents` escreve uma string literalmente; `set-file-lines` escreve cada elemento de uma sequência em sua própria linha, acrescentando as quebras de linha.

```factor
{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
! forecast.txt now holds "sunny\ncloudy\n"
```

## Fluxos com escopo

Quando você quer acrescentar conteúdo a um arquivo, ou ler e escrever peça por peça, abra-o com um combinador `with-…` e use as palavras de fluxo do ambiente dentro da quotation:

```
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
with-file-appender   ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files ;

"log.txt" utf8 [ "another line" print ] with-file-appender
```

`with-file-writer` trunca o arquivo primeiro; `with-file-appender` mantém o conteúdo existente e escreve depois dele. Cada um é um escopo destrutor: o handle do arquivo é fechado quando a quotation termina, mesmo que ela lance uma exceção. É a mesma garantia que os combinadores de `boatswains-bilge` oferecem, aqui especializada para arquivos.

## Arquivo inteiro ou com escopo?

Use `file-contents` / `file-lines` / `set-file-contents` / `set-file-lines` quando o arquivo for pequeno o bastante para caber na memória e você quiser tudo de uma vez. Use os abridores `with-…` quando precisar acrescentar conteúdo, ler um arquivo grande linha a linha com `readln`, ou intercalar leituras e escritas: em qualquer situação em que manter o arquivo inteiro na memória seria um desperdício ou simplesmente errado.
