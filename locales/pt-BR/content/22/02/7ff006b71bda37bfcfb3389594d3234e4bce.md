# Sobre

Uma lista em Gleam é uma coleção imutável de zero ou mais valores. Todos os valores de uma lista precisam ter o mesmo tipo. Como as listas são imutáveis, depois que uma lista é construída, seu valor nunca pode mudar. Quaisquer funções ou operadores que pareçam modificar uma lista (como adicionar um elemento) na verdade retornam uma nova lista.

Listas podem ser definidas assim:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

A forma mais comum de adicionar um elemento a uma lista é inseri-lo no início com a sintaxe de spread:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

O módulo [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) da biblioteca padrão do Gleam tem muitas funções úteis para trabalhar com listas. Esse módulo é muito usado em código Gleam, então vale a pena conhecê-lo bem.

Em expressões case, você pode usar padrões de lista para casar com listas e atribuir os valores que elas contêm a variáveis:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Além de casar com listas de tamanho exato, a sintaxe de spread pode ser usada para casar com listas de pelo menos um certo tamanho:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

A sintaxe de spread também pode ser usada para atribuir o resto da lista a uma variável:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Expressões case devem ter um padrão para cada valor possível do tipo que está sendo casado, então um padrão de descarte final (`_`) costuma ser usado para lidar com os valores restantes.
