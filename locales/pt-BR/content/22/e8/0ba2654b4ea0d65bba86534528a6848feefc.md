# Sobre

O [Reason](https://reasonml.github.io/) é uma sintaxe e um conjunto de ferramentas voltados para programadores de Javascript, baseado na linguagem funcional [OCaml](https://ocaml.org/)

Por ter tipagem estática, tende a ser mais seguro do que o Javascript, mas conta com uma poderosa inferência de tipos, o que significa que as anotações de tipo não atrapalham você.

Os exercícios do Exercism compilam direto para JS, mas o Reason pode ser compilado pelo conjunto de ferramentas do OCaml para código nativo, IoS, Android e até [microcontroladores](http://www.algo-prog.info/ocapic/web/index.php?id=ocapic)
