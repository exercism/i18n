# fictício

## Instruções específicas do MoonScript

Este é um exercício de orientação a objetos: você vai implementar ComplexNumbers como uma classe.

Os testes vão comparar duas instâncias de números complexos para verificar a igualdade.
Isso significa que sua classe vai precisar implementar o [metamétodo][metamethods] `__eq`.

Os testes também fazem operações aritméticas com números complexos, então há metamétodos aritméticos a implementar.

~~~~exercism/caution
Algumas das funções de números complexos vão fazer contas com números de ponto flutuante.
Sua "igualdade" vai ter que lidar com números que são _aproximadamente iguais_.
~~~~

[metamethods]: https://www.lua.org/manual/5.4/manual.html#2.4
