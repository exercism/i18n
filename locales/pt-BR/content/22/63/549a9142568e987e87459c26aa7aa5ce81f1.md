# Introdução

Um `vector` em Clojure é uma coleção sequencial, indexada e imutável de zero ou mais valores. Isso significa que, depois de criado, um vetor não pode ser modificado. As funções que operam sobre vetores retornam um novo vetor, e o vetor original permanece inalterado. Os valores em um vetor podem ser de tipos heterogêneos. Vetores podem ser definidos assim:

```clojure
(def empty [])
(def single-value [5])
```

É possível recuperar elementos de um vetor usando um índice. Os vetores do Clojure são indexados a partir do zero, ou seja, o índice do primeiro elemento é sempre zero:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

O vetor original permanece inalterado:

```clojure
numbers
;;=> [2 3 5]
```

Para guardar o valor atualizado, precisamos passá-lo adiante ou capturá-lo em uma var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
