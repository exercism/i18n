# Introdução

Uma `str` em Python é uma [sequência imutável][text sequence] de [pontos de código Unicode][unicode code points].
Eles podem incluir letras, sinais diacríticos, caracteres de posicionamento, números, símbolos de moeda, emojis, pontuação, caracteres de espaço e de quebra de linha, e muito mais.

As strings implementam todas as [operações comuns de sequência][common sequence operations] e podem ser iteradas com a sintaxe `for item in <string>` ou `for index, item in enumerate(<string>)`.

As strings podem ser concatenadas com `<str> + <other str>` ou `<str>.join(<iterable>)` e divididas com `<str>.split(<separator>)`.
Elas também oferecem várias outras opções de formatação, montagem e templates.

Como é imutável, o valor de um objeto `str` na memória não muda; métodos que parecem modificar uma string retornam uma nova cópia ou uma nova instância de `str`.

Para se aprofundar no que uma string codifica (ou, _"como um computador sabe traduzir zeros e uns em letras?"_), [este post de blog é sempre muito útil][joel-on-text].
A documentação do Python também traz um [HOWTO de Unicode][unicode how-to] bem detalhado, que discute o suporte do Python à especificação Unicode nos módulos `str`, `bytes` e `re`, considerações sobre locales e alguns problemas comuns de codificação e tradução.
