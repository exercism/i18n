# Instruções

Pegue um array aninhado de qualquer profundidade e retorne um array completamente achatado.

Observe que algumas trilhas de linguagens podem incluir valores do tipo `null` no array de entrada, e a forma como esses valores são representados varia de trilha para trilha.
Esses valores devem ser excluídos do array achatado.

Além disso, a entrada pode ser de um tipo de dados diferente e conter tipos diferentes, dependendo da trilha.

Consulte a suíte de testes para mais detalhes.

## Exemplo

entrada: `[1, [2, 6, null], [[null, [4]], 5]]`

saída: `[1, 2, 6, 4, 5]`
