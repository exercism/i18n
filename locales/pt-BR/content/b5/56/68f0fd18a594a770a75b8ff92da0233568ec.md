# Introdução

Os inicializadores de objeto são uma alternativa aos construtores. A sintaxe é ilustrada abaixo. Você fornece uma lista de pares nome-valor separados por vírgula e unidos por `=` entre chaves:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Coleções também podem ser inicializadas dessa forma. Normalmente, isso é feito com listas separadas por vírgula, como mostrado aqui:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Dicionários usam a seguinte sintaxe:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```
