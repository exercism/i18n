# Dicas

## 1. Renomear uma coluna

- Lembre-se: você precisa modificar o conjunto de dados `trees`, que fica disponível quando `library(datasets)` é chamada.
- Talvez você queira (ou não) converter o `data.frame` inicial em um `tibble`.
- Veja a Introdução para saber como alterar o nome de uma coluna.

## 2. Adicionar colunas de circunferência e peso

- Veja a Introdução para saber como adicionar colunas.
- As novas colunas podem ser calculadas a partir das colunas existentes.
- Não se esqueça de arredondar para a precisão exigida.

## 3. Cópia do conjunto de dados para o pomar

- Você precisa reordenar as colunas e ordenar as linhas (veja a Introdução).

## 4. Cópia do conjunto de dados para o cliente

- Você vai precisar pegar um subconjunto de colunas.
- Apenas as árvores entre a altura mínima e a máxima *e* abaixo do peso máximo devem estar na cópia.
