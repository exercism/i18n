# Instruções

O projeto do carrinho de controle remoto que você iniciou no exercício `classes` deu certo (parabéns!) e, graças a vários acordos de patrocínio recentes, há verba no orçamento para melhorias.

Parte do orçamento está sendo usada para fornecer um pouco de telemetria.

Para agradar os patrocinadores, foi instalado no carrinho um painel que exibe os nomes dos patrocinadores enquanto ele dá voltas na pista.

Você vai notar que a introdução dessas novas tecnologias sofisticadas reduziu drasticamente a duração da bateria do carrinho.

## 1. Fazer o carrinho de controle remoto exibir os nomes dos patrocinadores

Implemente `SetSponsors()` para receber um ou mais nomes de patrocinadores e armazená-los no carrinho.

Repare que o argumento do método `SetSponsors()` é garantidamente não nulo.

Implemente `DisplaySponsor()` para exibir o patrocinador selecionado. O primeiro patrocinador passado tem `sponsorNum` 0, o segundo, 1, e assim por diante.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. Obter os dados de telemetria do carrinho

Implemente o método `RemoteControlCar.GetTelemetryData()`.

`GetTelemetryData()` deve disponibilizar a porcentagem da bateria e a distância percorrida em metros por meio de parâmetros `out`.

`GetTelemetryData()` deve retornar `false` se o argumento serialNum for menor que o valor recebido anteriormente. (Há algum problema envolvendo múltiplos nós de telemetria). Nesse caso, `serialNum` será definido como o maior `serialNum` anterior, e tanto a porcentagem da bateria quanto os metros percorridos serão definidos como `-1`. Quando a chamada é bem-sucedida, `serialNum` permanece inalterado.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. Adicionar funcionalidade para que o sistema de telemetria possa obter o consumo de bateria por metro

Implemente o método `TelemetryClient.GetBatteryUsagePerMeter()`.

Ele vai chamar `RemoteControlCar.GetTelemetryData()`. Se `GetTelemetryData()` retornar `false` ou o carrinho não tiver sido dirigido, essa rotina deve retornar "no data". Se `GetTelemetryData()` retornar `true`, deve ser retornada uma mensagem no seguinte formato: "usage-per-meter=BATTERY-USAGE-PER-METER". Em que o cálculo é (100 - porcentagem atual da bateria) dividido pela distância percorrida em metros até agora.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
