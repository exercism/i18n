# Sobre

Strings em Gleam são texto imutável entre aspas duplas. Elas aceitam caracteres unicode e podem ocupar várias linhas.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

Strings podem ser unidas com o operador `<>`:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

O módulo [`gleam/string`][stdlib] da biblioteca padrão oferece funções para trabalhar com strings.

Strings podem ser comparadas em expressões case:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Se você quiser fazer correspondência no início de uma string e atribuir o restante a uma variável, pode usar o padrão do operador `<>`:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
