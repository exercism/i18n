# Sobre

O Haxe dá suporte à reflexão de tipos e campos em tempo de execução. Para usar a reflexão corretamente, é preciso entender que tipos de operações têm suporte e quais não têm. Dada a natureza dinâmica da reflexão, nem sempre isso pode ser determinado em tempo de compilação.

A API de reflexão é composta por duas classes:

- `Reflect`: uma API leve que funciona melhor com estruturas anônimas, com suporte limitado a classes.
- `Type`: uma API mais robusta para trabalhar com classes e enums.

Os métodos disponíveis estão detalhados na API de [Reflect][reflect] e [Type][type].

No exemplo a seguir, usamos o JavaScript como alvo:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
