# Introdução

## Arrays

O JSON define um **array**, ou _vetor_, como:

> Um array é uma coleção ordenada de valores.
> Um array começa com `[` colchete esquerdo e termina com `]` colchete direito.
> Os valores são separados por `,` vírgula.

Arrays podem conter zero ou mais valores JSON de _qualquer tipo_.
Os elementos de um array não precisam ser todos do mesmo tipo.

### Criando arrays

Use colchetes para reunir elementos em um array.

```jq
[1, 2, 3]
```

Os elementos de um _stream_ podem ser capturados em um array envolvendo-o em colchetes.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### Tamanho

A função `length` retorna o número de elementos de um array.

### Indexação e fatiamento

A indexação de arrays começa em zero.

Recupere um elemento de um array com uma expressão entre colchetes:
`.[2]` obtém o terceiro elemento.

Índices negativos contam de trás para frente a partir do fim do array:
`.[-1]` obtém o último elemento; `.[-2]` é o penúltimo.

Uma **fatia** é uma subsequência do array.
`.[10:15]` retorna 5 elementos a partir do índice 10; o índice final _não é incluído_.

Existem algumas funções de conveniência:

- `first` obtém o primeiro elemento.
- `last` obtém o último elemento.
- `nth(n)` obtém o elemento no índice `n`.

### Iteração

O `jq` oferece muitas funções que cobrem a funcionalidade de iteração mais comum:

- `map(expr)` retorna um novo array em que o `expr` é aplicado a cada elemento, um por vez.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` é uma função que aplica o `expr` a um _único valor_;
  se o resultado da expressão for verdadeiro, o valor é retornado;
  se o resultado for falso, _nada_ é retornado: não `null`, literalmente nada.

  Para aplicar isso a um array, combine com `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Como alternativa, aplique `select` a um _stream_ e colete os resultados.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` e `all(condition)` retornam um valor Boolean indicando se algum ou todos os elementos do array satisfazem a condição.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
