# Instruções

Sua tarefa é receber uma lista de marcadores de um jogo e contar quantos gols cada jogador marcou.

`PlayerName` é um alias de tipo para `String`, para deixar o código mais fácil de ler e para distinguir este uso de `String` de outros usos de `String`.

## 1. Agregar os marcadores

Primeiro, implemente `updateGoalCountForPlayer` para inicializar ou incrementar a contagem de gols de um jogador.
Depois, implemente a função `aggregateScorers` para contar quantos gols cada jogador marcou, usando `updateGoalCountForPlayer`.
Essa função recebe uma `List PlayerName` (os nomes dos jogadores que marcaram os gols, que pode conter nomes de jogadores duplicados) e retorna um `Dict PlayerName Int` contendo todos os jogadores da lista junto com quantos gols eles marcaram.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. Remover jogadores insignificantes

Implemente a função `removeInsignificantPlayers` para filtrar os jogadores que marcaram menos gols do que o limite.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. Redefinir a contagem de gols de um jogador

Implemente a função `resetPlayerGoalCount` para redefinir para zero os gols marcados de um jogador.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Formatar a contagem de gols de um único jogador

Implemente a função `formatPlayer` para formatar a contagem de gols de um único jogador como uma string. Se o jogador não existir no dicionário, assuma que a contagem de gols dele é zero.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Formatar a contagem de gols de todos os jogadores

Implemente a função `formatPlayers` para formatar a contagem de gols de todos os jogadores como uma string. Os jogadores devem ser ordenados pelo nome.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Combinar jogos

Implemente a função `combineGames` para contar o número total de gols que cada jogador marcou nos dois jogos.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
