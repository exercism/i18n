# Introdução

No Common Lisp, a lista de argumentos de uma função é conhecida como uma ['lista lambda'][lambda-list].
Uma lista lambda pode ter argumentos de tipos diferentes.
Esses tipos diferentes são designados pelo uso de ['palavras-chave de lista lambda'][lambda-list-keyword], que sempre começam com `&`.
Os tipos mais usados são os argumentos opcionais, os argumentos keyword e os argumentos rest.
Todo parâmetro na lista lambda depois de uma palavra-chave de lista lambda específica será desse tipo.
Uma palavra-chave de lista lambda só pode ser usada uma vez em uma lista lambda.

As listas lambda também são usadas em outras construções que serão discutidas mais adiante, como desestruturação e macros.
