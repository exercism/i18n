# Instruções

O dia que você tanto esperou finalmente chegou, e agora você é o orgulhoso dono de uma bela fazenda nos Alpes.

Você ainda não gosta de acordar cedo demais para alimentar suas vacas. 
Como você é um excelente engenheiro, você construiu um dispensador de comida, o `FEED-M-ALL`.

A última coisa necessária para concluir seu projeto é um trecho de código que calcule a quantidade de ração que cada vaca deve receber.
É importante que cada vaca receba a mesma quantidade, você precisa evitar conflitos.
Vacas são muito sensíveis.

Felizmente, você não precisa elaborar todas as fórmulas para calcular as quantidades de ração sozinho.
Você usa uma biblioteca externa misteriosa que encontrou na internet.
Ela deveria resultar nas vacas mais felizes.
A biblioteca expõe uma classe que atende à seguinte interface.
Você vai contar com isso no código que escrever.

```crystal
class FodderCalculator
  def fodder_amount! : Number 
  end

  def fattening_factor! : Number
  end
end
```

À medida que você trabalha no seu código, vai melhorar o tratamento de erros para torná-lo mais robusto e mais fácil de depurar depois, quando você o usar no seu dia a dia na fazenda.

## 1. Divida a comida igualmente

Primeiro, você foca em escrever o código necessário para calcular a quantidade de ração por vaca.

Implemente um método `TheFarm.divide_food` que aceita como argumentos um objeto `FodderCalculator` e um número de vacas como um inteiro.
*Para esta tarefa, você assume que o número de vacas passado é sempre maior que zero.*
O método deve retornar a quantidade de comida por vaca.

Para fazer o cálculo, primeiro você precisa obter a quantidade total de ração para todas as vacas.
Isso é feito chamando o método `fodder_amount!` e passando o número de vacas.
Além disso, você precisa de um fator pelo qual essa quantidade precisa ser multiplicada.
Você obtém esse fator chamando o método `fattening_factor!`.
Com esses dois valores e o número de vacas, agora você pode calcular a quantidade de comida por vaca (como um `float64`).

Se um dos métodos que você chama retornar um erro, a execução deve parar e retornar `0`.

```crystal
fodder_calculator = FodderCalculator.new(50, 1.5)
TheFarm.divide_food(fodder_calculator, 5)
# => 15.0

fodder_calculator = FodderCalculator.new(50, nil)
TheFarm.divide_food(fodder_calculator, 5)
# => 0
```

## 2. Verifique o número de vacas

Enquanto trabalhava na primeira tarefa acima, você percebeu que a biblioteca externa que usa não é tão de alta qualidade quanto você pensava.
Por exemplo, ela não consegue lidar adequadamente com entradas inválidas.
Você quer contornar essa limitação adicionando uma verificação do valor de entrada no seu próprio código.

Escreva uma função `TheFarm.validate_input_and_divide_food` que tem a mesma assinatura que a `TheFarm.divide_food` acima.

- Se o número de vacas passado for maior que 0, a função deve chamar `TheFarm.divide_food` e retornar o resultado dessa chamada.
- Se o número de vacas for 0 ou menos, a função deve lançar um erro com a mensagem `"Number of cows must be greater than 0"`.

```crystal
TheFarm.validate_input_and_divide_food(fodderCalculator, 5)
# => 15

TheFarm.validate_input_and_divide_food(fodderCalculator, -2)
# Error: Number of cows must be greater than 0
```

## 3. Melhore o tratamento de erros

Verificar o número de vacas antes de passá-lo adiante foi uma boa jogada, mas você não está muito satisfeito com a mensagem de erro genérica.
Você decide fazer melhor criando uma classe de erro personalizada chamada `InvalidCowsError`.

O erro personalizado deve armazenar o número de vacas (`Int32`) e uma mensagem personalizada (`String`), e o método `Expection` deve serializar os dados no seguinte formato:
```txt
{number of cows} cows are invalid: {custom message}
```

Agora que você tem seu erro personalizado, implemente uma função `TheFarm.validate_number_of_cows` que aceita o número de vacas como um inteiro e retorna um erro (ou nil).

- Se o número de vacas for menor que 0, a função retorna um `InvalidCowsError` com a mensagem personalizada definida como `"there are no negative cows"`.
- Se o número de vacas for 0, a função retorna um `InvalidCowsError` com a mensagem personalizada definida como `"no cows don't need food"`.
- Caso contrário, a função retorna `nil` para indicar que a validação foi bem-sucedida.

```crystal
TheFarm.validate_number_of_cows(5)
# => nil

TheFarm.validate_number_of_cows(-5)
# => InvalidCowsError: -5 cows are invalid: there are no negative cows
```

Depois do trabalho duro de configurar essa função de validação, você percebe que já é noite e sai da sua mesa para apreciar o pôr do sol sobre as montanhas.
Você deixa para outro dia a tarefa de de fato adicionar a nova função de validação ao seu código.
