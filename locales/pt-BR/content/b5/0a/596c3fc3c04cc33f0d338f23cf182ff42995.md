# Testes

Para rodar os testes, execute o seguinte comando no diretório do exercício:

```shell
make
```

## Testes ignorados

Resolver um exercício significa fazer todos os seus testes passarem.
Por padrão, apenas um teste (o primeiro) é executado quando você roda os testes.
Isso é intencional, pois permite que você foque em fazer apenas esse teste passar.
Quando ele passar, você pode habilitar o próximo teste removendo a linha `TEST_IGNORE();`.
Quando todos os testes estiverem habilitados e sua implementação fizer todos eles passarem, você terá resolvido o exercício!
