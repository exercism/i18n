# Dicas

## Geral

- `accessors` fornece os getters `slot>>` gerados automaticamente, os setters `>>slot` e os atualizadores `change-slot`.
- Setters e `change-slot` *modificam* a tupla. Faça `clone` dela primeiro se quiser uma atualização não destrutiva.

## 1. Defina a tupla `player`

- A sintaxe de slot é `{ name initial: value }` dentro de `TUPLE: …  ;`.
- Slots sem uma cláusula `initial:` assumem `f` por padrão.

## 2. Apresente o jogador

- `name>>` lê o slot `name`.
- `unless*`, de [`kernel`][kernel], é o idioma "padrão se for `f`".

## 3. Reviva um jogador caído

- `health>>` lê o slot; `zero?`, de [`math`][math], testa se é zero.
- Construa o novo jogador com `clone` seguido de `100 >>health` e `100 >>mana`.
- No caso de ele ainda estar vivo, retorne `f`.

## 4. Receba dano

- `change-health` aceita uma quotation `( old-health -- new-health )`.
- Uma quotation fry `'[ _ - 0 max ]` (com `max`, de [`math.order`][math.order]) te dá "subtraia o dano capturado e limite a zero".
- Lembre-se de fazer `clone` antes de modificar.

[math]: https://docs.factorcode.org/content/vocab-math.html
[math.order]: https://docs.factorcode.org/content/vocab-math.order.html
