# Normalizações do representer

O [representer de JavaScript][github-javascript-representer] aplica as seguintes normalizações:

## Remover comentários

Todos os comentários são removidos.
Os exemplos a seguir são equivalentes:

### Exemplo com comentários

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### Exemplo sem comentários

```javascript
function hello() {
  return 'hi there';
}
```

## Normalizar espaços em branco

Quando o código é representado, a _ordem_ é significativa, mas sua localização física não é.
Isso significa que os espaços em branco são normalizados.
Os exemplos a seguir são equivalentes:

### Exemplo com indentação de dois espaços

```javascript
function hello() {
  return 'hello world';
}
```

### Exemplo com indentação de quatro espaços

```javascript
function hello() {
  return 'hello world';
}
```

### Exemplo com indentação interessante

```javascript
function hello() {
  return 'hello world';
}
```

## Normalizar identificadores

Os identificadores são normalizados para um valor de espaço reservado.

### Antes

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### Depois

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
