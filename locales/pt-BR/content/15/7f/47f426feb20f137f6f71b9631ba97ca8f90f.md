# Dicas

## Geral

- Para acessar e definir variáveis de instância, você escreve `@` seguido do nome da variável.

## 1. Inicialize o `TaskHandler`

- Para criar uma `Proc`, use a sintaxe `-> (args) { block }`.
- Quando uma `Proc` é definida para uma variável de instância, ela precisa ser tipada explicitamente.
  Isso pode ser feito adicionando `: Proc(<arg_type>, <return_type>)` depois do nome da variável.
  Ou com a sintaxe `-> (arg_1 : <arg_type>) : <return_type> { block }`.
- A `Proc` deve comparar se o argumento é maior ou igual a 0.

## 2. Atualize a lógica da condição da tarefa

- O método deve receber um bloco como argumento e atribuí-lo à variável de instância `@task_condition_logic`.

## 3. Execute a próxima tarefa

- Para executar uma `Proc`, você pode usar o método `call`, que aceita os argumentos da proc.
