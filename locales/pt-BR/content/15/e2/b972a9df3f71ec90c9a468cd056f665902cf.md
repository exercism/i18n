# Métodos de array

Arrays são uma estrutura de dados comum com que se trabalha.
Por isso, existe uma coleção de métodos que podem ser usados para lidar com arrays.
Isso inclui ordenar, inverter, inserir e muito mais.

Alguns desses métodos são destrutivos, o que significa que modificam o array original.
Outros são não destrutivos, ou seja, retornam um novo array e não modificam o original.

Veja a seguir alguns dos métodos mais comuns que você pode usar ao lidar com arrays:

## insert

Para inserir um elemento em um array, você pode usar o método [`insert`][insert], que recebe um índice e um elemento como argumentos.
O elemento será inserido no índice especificado, e o restante do array será deslocado para a direita.
Se o índice estiver fora dos limites, um `IndexError` será lançado.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Quando você quer excluir um elemento específico de um array, pode usar o método [`delete`][delete], que recebe um elemento como argumento.
O método retorna o elemento que foi removido.
Se o elemento não existir no array, `nil` será retornado.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Quando você quer obter o primeiro ou o último elemento de um array, pode usar os métodos [`first`][first] e [`last`][last].
Esses métodos recebem um argumento opcional que especifica quantos elementos retornar.
Isso pode melhorar a legibilidade em comparação com o uso do índice `0` ou `-1`, ou de um intervalo.
Se o array estiver vazio, um `Enumerable::EmptyError` será lançado.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Quando você quer inverter um array, pode usar o método [`reverse`][reverse], que retorna um novo array com os elementos em ordem inversa.
É importante notar que `reverse` retorna um novo array e não modifica o array original.
Se você quiser modificar o array original, adicione um `!` ao final do nome do método.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

Os métodos a seguir são úteis para operações como tornar um array unidimensional, remover elementos `nil`, remover duplicatas ou transpor um array de arrays.
Assim como `reverse`, esses métodos retornam um novo array e não modificam o array original.

| Método | Descrição | Exemplo |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | Retorna um novo array que é um achatamento unidimensional deste array (de forma recursiva). Ou seja, para cada elemento do array, extrai seus elementos para o novo array. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | Retorna uma cópia do próprio array com todos os elementos nil removidos. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | Assume que o próprio array é um array de arrays e [transpõe][transpose] as linhas e as colunas. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | Retorna um novo array removendo os valores duplicados do próprio array. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

O método de acréscimo (`<<`) é útil quando você quer adicionar objetos a um array.
No entanto, para combinar dois arrays, você pode usar o operador [`+`][concat], que retorna um novo array com os elementos dos dois arrays.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Se você anexar um array a outro array, o array será adicionado como um único elemento.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Para verificar se um array está vazio, você pode usar o método [`empty?`][empty?], que retorna `true` se o array estiver vazio e `false` caso contrário.
Isso melhora a legibilidade em comparação com verificar o tamanho do array em relação a `0`.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Quando você quer obter o índice de um elemento em um array, pode usar o método [`index`][index], que recebe um elemento como argumento.
Se o elemento não existir no array, `nil` será retornado.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Quando você quer saber o número de elementos de um array, pode usar o método [`size`][size].

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Quando você quer contar quantas vezes um elemento aparece em um array, pode usar o método [`count`][count].

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Quando você quer ordenar um array, pode usar o método [`sort`][sort], que retorna um novo array com os elementos ordenados.
Assim como `reverse`, esse método retorna um novo array e não modifica o array original.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
