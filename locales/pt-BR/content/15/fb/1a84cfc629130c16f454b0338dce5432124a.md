# Sobre

Um [`Array`][array], ou vetor, em Elm é uma coleção imutável e rápida de zero ou mais valores do mesmo tipo.
Como os arrays são imutáveis, depois que um array é construído, seu valor nunca muda.
Não existe uma sintaxe literal para arrays (como existe para as listas), então em vez dela usa-se a sintaxe Array.fromList.
Por exemplo, um `Array` com "a", "b" e "c" dentro dele geralmente aparece como `Array.fromList ["a", "b", "c"]`.
Você vai ver isso na saída do console, no depurador e em outros lugares parecidos.

Diferente de `List`, que é um [import padrão][default-imports], o módulo `Array` precisa ser importado explicitamente, com `import Array` ou algo semelhante.

As anotações de tipo para listas podem ser definidas assim:

```elm
Array String --> an array of String
Array Int --> an array of Int
```

Os arrays podem ser definidos assim:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

Os elementos são adicionados a um Array com `Array.push`:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

Arrays são concatenados com `Array.append`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

Um elemento de um Array é obtido com `Array.get`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

Um elemento de um Array é definido com `Array.set`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

Os arrays são manipulados por funções definidas no [módulo `Array`][array-module].

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

Qualquer função ou operador que pareça modificar um `Array` (como adicionar um elemento) na verdade retorna um novo `Array`.
O desempenho normalmente não é um problema, já que a implementação de `Array` evita alocações e cópias desnecessárias.
