# Dicas

## Geral

- Tudo aqui está em [`regexp`][regexp], escrito com `R/ /`.
- Um grupo é `( ... )`; `|` é "ou"; lookaround é `(?=...)`,
  `(?!...)` e `(?<=...)`.

## 1. Valide um valor

- Transforme a parte dos centavos em um grupo e marque-a como opcional: `(\.\d{2})?`.
- Escreva `\$` para um cifrão literal e depois use `matches?` para exigir
  que a string *inteira* se encaixe: `R/ \$\d+(\.\d{2})?/ matches?`.

## 2. Extraia os valores em dólares

- Um *lookbehind* só casa com dígitos quando um `$` vem antes, sem
  incluir o `$`: `R/ (?<=\$)\d+/`.
- `all-matching-subseqs` coleta todas as correspondências desse tipo.

## 3. Extraia as porcentagens

- Um *lookahead* só casa com dígitos quando um `%` vem depois:
  `R/ \d+(?=%)/`.

## 4. Sinalize uma linha

- Use `|` para as duas palavras e a opção `i` para ignorar maiúsculas e minúsculas:
  `R/ refund|chargeback/i`.
- `re-contains?` informa se há correspondência em algum ponto da linha.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
