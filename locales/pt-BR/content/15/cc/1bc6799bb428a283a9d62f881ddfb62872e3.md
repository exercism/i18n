# Instruções

Neste exercício, você vai escrever código para acompanhar códigos de discagem internacional por meio de um dicionário de códigos de discagem internacional.

O dicionário usa um número inteiro como chave (o código de discagem) e uma string (nome do país) como valor.

Você tem 9 tarefas que envolvem a classe estática `DialingCodes`.

## 1. Crie um novo dicionário

Implemente o método (estático) `DialingCodes.GetEmptyDictionary()` que retorna um dicionário vazio.

```csharp
DialingCodes.GetEmptyDictionary();
// => empty dictionary
```

## 2. Crie um dicionário pré-preenchido

Existe um dicionário pré-preenchido que contém os seguintes 3 códigos de discagem: "United States of America", com o código 1, "Brazil", com o código 55, e "India", com o código 91. Implemente o método (estático) `DialingCodes.GetExistingDictionary()` para retornar o dicionário pré-preenchido:

```csharp
DialingCodes.GetExistingDictionary();
// => 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 3. Adicione um país a um dicionário vazio

Implemente o método (estático) `DialingCodes.AddCountryToEmptyDictionary()` que cria um dicionário e adiciona a ele um código de discagem e o nome do país associado.

```csharp
DialingCodes.AddCountryToEmptyDictionary(44, "United Kingdom");
// => 44 => "United Kingdom"
```

## 4. Adicione um país a um dicionário existente

Implemente o método (estático) `DialingCodes.AddCountryToExistingDictionary()` que adiciona um código de discagem e o nome do país associado a um dicionário não vazio.

```csharp
DialingCodes.AddCountryToExistingDictionary(DialingCodes.GetExistingDictionary(),
  44, "United Kingdom");
// => 1 => "United States of America", 44 => "United Kingdom", 55 => "Brazil", 91 => "India"
```

## 5. Obtenha o nome do país correspondente a um código de discagem

Implemente o método (estático) `DialingCodes.GetCountryNameFromDictionary()` que recebe um código de discagem e retorna o nome do país correspondente. Se o código de discagem não estiver no dicionário, uma string vazia é retornada.

```csharp
DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 55);
// => "Brazil"

DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 999);
// => string.Empty
```

## 6. Verifique se um país existe no dicionário

Implemente o método (estático) `DialingCodes.CheckCodeExists()` para verificar se um código de discagem existe no dicionário.

```csharp
DialingCodes.CheckCodeExists(DialingCodes.GetExistingDictionary(), 55);
// => true
```

## 7. Atualize o nome de um país

Implemente o método (estático) `DialingCodes.UpdateDictionary()` que recebe um código de discagem e substitui o nome do país correspondente no dicionário pelo nome do país passado como parâmetro. Se o código de discagem não existir no dicionário, o dicionário permanece inalterado.

```csharp
DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 1, "Les États-Unis");
// => 1 => "Les États-Unis", 55 => "Brazil", 91 => "India"

DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 999, "Newlands");
// 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 8. Remova um país do dicionário

Implemente o método (estático) `DialingCodes.RemoveCountryFromDictionary()` que recebe um código de discagem e remove do dicionário o registro correspondente, código de discagem + nome do país.

```csharp
DialingCodes.RemoveCountryFromDictionary(
  DialingCodes.GetExistingDictionary(), 91);
// => 1 => "United States of America", 55 => "Brazil"
```

## 9. Encontre o país com o nome mais longo

Implemente o método (estático) `DialingCodes.FindLongestCountryName()` que retorna o nome do país com o nome mais longo armazenado no dicionário.

```csharp
DialingCodes.FindLongestCountryName(
  DialingCodes.GetExistingDictionary());
// => "United States of America"
```
