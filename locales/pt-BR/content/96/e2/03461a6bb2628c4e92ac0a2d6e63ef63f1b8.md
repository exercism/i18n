# Anexo das instruções

## Sobre a habilidade Stream

Um `Stream` é uma habilidade do Unison usada para emitir valores.

Você pode usar a habilidade `Stream` quando tem uma função que deve produzir valores como efeito secundário enquanto é chamada. Por exemplo, esta função retorna o último valor da lista, mas emite um total acumulado conforme cada elemento é visto:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

Podemos materializar o Stream como uma `List` junto com o valor de retorno da função que o produz, usando um manipulador de habilidade:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
