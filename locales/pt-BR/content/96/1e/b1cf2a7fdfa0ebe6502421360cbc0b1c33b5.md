# Sobre

Em C#, o [literal `null`][null-keyword] é usado para indicar a ausência de um valor. Um tipo _anulável_ é um tipo que permite valores `null`.

Antes do C# 8.0, os tipos de referência eram sempre anuláveis e os tipos de valor não eram. No entanto, é possível tornar um [tipo de valor anulável][nullable-value-types] acrescentando a ele um ponto de interrogação (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Acessar um membro de uma variável cujo valor é `null` compila sem problemas, mas resulta em uma `NullReferenceException` sendo lançada em tempo de execução:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

Para combater esse tipo comum de erro, o C# 8 permite [ativar um recurso][nullable-csharp-8] que torna os [tipos de referência não anuláveis por padrão][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Para [trabalhar com segurança com valores anuláveis][nullable-types-tutorial], é preciso verificar se eles são `null` antes de trabalhar com eles:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

O [operador `??`][null-coalescing-operator] permite retornar um valor padrão quando o valor é `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

O [operador `?.`][null-conditional-operator] permite chamar membros com segurança em um valor que pode ser `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

Se o compilador acha que um valor pode ser `null`, mas você tem certeza de que não será, o [operador `!.`][null-forgiving-operator] pode ser usado para suprimir o aviso. No entanto, use esse operador apenas como último recurso.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
