# Introdução

O tipo `Result` é a solução da linguagem Elm para reportar erros e um facilitador para a recuperação de erros. Ele é um pouco parecido com o tipo `Maybe`, mas, embora Maybe possa ser retornado por funções que podem falhar, ele não diz nada sobre o motivo da falha. O Result inclui esse contexto sobre por que algo falhou.

O tipo `Result` é definido da seguinte forma:

```elm
type Result error value
  = Ok value
  | Err error
```

Isso é conhecido como uma definição de "custom type" na terminologia do Elm.
O `error` e o `value` em `OK value` e `Error error` representam uma variável de tipo, ou seja, podem ser de qualquer tipo, como `Int`, `Bool` ou `String`.
Assim, um `Result String Int` é uma variável que se espera conter um `Int` e, se houver um erro, ele será representado como uma `String`.
Existe um [módulo Result](https://package.elm-lang.org/packages/elm/core/latest/Result) com muitas funções auxiliares úteis para o Result.
