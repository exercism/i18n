# Instruções

O contramestre faz um briefing diário de quarto no convés: uma
saudação fixa, uma chamada da tripulação de serviço e, por fim, um
encerramento. Você vai dividir o briefing em pequenas linhas
nomeadas e depois combiná-las.

Você vai editar **dois arquivos** neste exercício:

- `bosuns-briefing/helpers/helpers.factor`: pequenas peças
  reutilizáveis. Vocabulário: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`: o arquivo principal que
  combina os helpers. Vocabulário: `bosuns-briefing`.

## 1. Saudação

Em `helpers.factor`, defina `greeting` para retornar a string fixa de
abertura `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Linha da tripulação

Em `helpers.factor`, defina `crew-line` para receber uma string de nome
e retornar esse nome com o prefixo `"  - "` (dois espaços, um hífen, um
espaço).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Encerramento

Em `helpers.factor`, defina `closing` para retornar a string fixa de
encerramento `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. Escala

Em `bosuns-briefing.factor`, defina `roster` para receber um array de
nomes da tripulação e retornar uma única string de várias linhas, com
cada nome formatado por `crew-line`, unidos por quebras de linha.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Briefing

Em `bosuns-briefing.factor`, defina `briefing` para receber um array
de nomes da tripulação e retornar o briefing completo como uma única
string: a saudação na primeira linha, a escala nas linhas seguintes e
o encerramento na última linha. Use os helpers e `roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
