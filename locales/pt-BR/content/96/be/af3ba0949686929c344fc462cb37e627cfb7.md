# Adicionar uma nova trilha

O primeiríssimo passo para adicionar uma nova trilha de linguagem ao Exercism é:

- [Solicitar uma nova trilha de linguagem](/docs/building/tracks/new/request-new)

Depois de concluir esse passo, os próximos passos são:

- [Junte-se à nossa comunidade](/docs/building/tracks/new/join-our-community)
- [Selecione a variante da linguagem de programação](/docs/building/tracks/new/select-programming-language-variant) (se aplicável)
- [Selecione o framework de testes](/docs/building/tracks/new/select-testing-framework)
- [Adicione o primeiro exercício](/docs/building/tracks/new/add-first-exercise)
- [Configure a Integração Contínua](/docs/building/tracks/new/setup-continuous-integration)
- [Adicione os primeiros exercícios](/docs/building/tracks/new/add-initial-exercises)
- [Crie o executor de testes](/docs/building/tracks/new/build-test-runner)
- [Configure as ferramentas](/docs/building/tracks/new/configure-tooling)
- [Prepare-se para o lançamento](/docs/building/tracks/new/prepare-for-launch)
- [Teste a trilha](/docs/building/tracks/new/test-track)
- [Encontre mantenedores](/docs/building/tracks/new/find-maintainers)
- [Lance!](/docs/building/tracks/new/launch)
- [Ative o realce de sintaxe](/docs/building/tracks/new/syntax-highlighting)
- [Implemente ferramentas adicionais](/docs/building/tracks/new/implement-tooling)
- [Prepare-se para contribuições de código aberto de pessoas desconhecidas](/docs/building/tracks/new/prepare-for-contributions)
