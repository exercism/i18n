# Introdução

## Constantes e funções

Programas em Haskell são compostos de definições e expressões.

Um valor constante é definido com `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Funções são definidas com `name parameters... = expression`, com os parâmetros separados apenas por espaço.

```haskell
add number1 number2 = number1 + number2
```

Chamar uma função também é uma expressão e é feito especificando o nome dela e passando argumentos para cada parâmetro da função, separados por espaços, assim como nas definições de função.

```haskell
five = add 2 3
```

Parênteses podem ser usados para especificar a ordem de avaliação de uma expressão.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentação / espaços em branco significativos

Haskell usa espaços em branco e indentação para especificar os limites do código.
***O código que faz parte de alguma expressão deve ser indentado mais para dentro do que o início dessa expressão.***

- As definições de módulo, import e funções de nível superior devem começar na coluna mais à esquerda.
- Se uma expressão for dividida em várias linhas, o código que faz parte dessa expressão deve ser indentado sob essa expressão com pelo menos um espaço.
- As partes da expressão que estão agrupadas devem ser indentadas com o mesmo número de espaços.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## Módulos

Módulos exportam funções.
Isso significa que você pode usar as funções que o módulo disponibiliza em sua declaração de exportação.
Um módulo também pode definir funções apenas para uso interno.
Por padrão, funções que não são exportadas explicitamente não podem ser usadas de fora do módulo.

No início de um módulo, especificamos o nome do módulo.
Se tivermos um arquivo chamado Calculator.hs, devemos nomear nosso módulo como Calculator.
Depois, especificamos as funções que ele exporta e, após isso, podemos começar a escrever as funções.
Então, vamos começar com isto.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Comentários

Um comentário é um texto dentro do arquivo Haskell que não é interpretado como código.
Ele se destina principalmente a ser lido por você e por outros programadores.
Existe uma sintaxe leve para comentários de uma linha, baseada em hífens duplos.
Comentários de várias linhas também são possíveis com o par de delimitadores de abertura e fechamento `{-` e `-}`.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
