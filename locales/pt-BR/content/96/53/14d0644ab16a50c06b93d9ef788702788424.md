# Dicas

## Geral

- Para cada tarefa, cada função deve retornar um closure, usando os argumentos fornecidos.

## 1. Translade as coordenadas

- Os argumentos fornecidos indicam quanto transladar o par de coordenadas ao longo dos eixos _x_ e _y_.

## 2. Escale as coordenadas

- Os argumentos fornecidos indicam quanto escalar o par de coordenadas nos eixos _x_ e _y_.

## 3. Componha funções de transformação

- O resultado da primeira transformação é um array, mas as funções de transformação recebem dois argumentos numéricos. Você vai precisar pegar os valores do array.
- Lembre-se de que a ordem em que as funções são executadas faz diferença.

## 4. Salve os resultados das funções

- Para essa função, você só precisa memoizar o resultado da última transformação.
- Para retornar o resultado da última transformação, você vai precisar verificar se os argumentos de entrada são os mesmos.
