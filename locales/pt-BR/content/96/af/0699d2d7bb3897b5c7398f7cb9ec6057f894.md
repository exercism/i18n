# Sobre

Ao modelar dados que só podem assumir um conjunto específico de estados possíveis, como dias da semana, direções da bússola ou botões de um controle, tipos básicos como `Int` ou `String` têm grandes desvantagens.
Com inteiros ou strings, seu código precisa verificar o tempo todo se há valores inválidos (como um código de status `999` ou um erro de digitação como `"leftt"`), e quem lê o código não consegue identificar facilmente o que os números representam.

O Swift resolve esse problema com [_Enumerações_][enumerations] (muitas vezes abreviadas para *enums*).
Um enum define um tipo comum para um grupo de valores nomeados e relacionados. Como o compilador conhece todos os casos possíveis de antemão, ele consegue verificar se o seu código está correto e completo em tempo de compilação.
Enums também podem ter métodos, inicializadores e propriedades computadas.

## Definindo enums

Defina um enum com a palavra-chave `enum`, seguida do nome do tipo, com seus casos listados dentro de chaves.
Por convenção do Swift, o nome do tipo usa `UpperCamelCase`, enquanto cada caso usa `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

Você também pode definir vários casos em uma única linha, separados por vírgulas:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Para se referir a um caso de um enum, escreva o nome do tipo do enum, um ponto (`.`) e o nome do caso. Quando o tipo já é conhecido ou pode ser inferido pelo compilador, você pode omitir o nome do tipo e usar a sintaxe de ponto mais curta:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Enums e instruções `switch`

Enums funcionam perfeitamente com [instruções `switch`][enums-and-switches].
Como um `switch` em Swift precisa ser exaustivo, o compilador garante que você trate todos os casos possíveis:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Se você deixar de fora algum caso sem fornecer uma cláusula `default`, o compilador reporta um erro:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Muitas vezes, é preferível listar todos os casos explicitamente a usar `default`. Assim, se você adicionar um novo caso no futuro, o compilador vai avisar imediatamente para você atualizar cada instrução `switch` que trata esse enum.

## Métodos e inicializadores

Enums podem definir métodos e inicializadores personalizados, assim como classes e structs. Dentro de um método de enum, `self` se refere ao valor do caso atual:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Valores brutos

Os casos de um enum podem ser preenchidos previamente com valores padrão chamados de [_valores brutos_][raw-values].
Todos os valores brutos de um enum precisam ter o mesmo tipo (como `Int`, `String` ou `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Você pode inicializar um enum a partir de um valor bruto usando `init(rawValue:)`. Como pode ser fornecido um valor bruto inválido, esse inicializador retorna um opcional:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

O Swift pode atribuir valores brutos automaticamente para enums de `String` e de `Int`:

- Em enums de `String`, o valor bruto de cada caso é, por padrão, o nome do caso.
- Em enums de `Int`, os valores brutos começam em `0` e aumentam de 1 em 1, a menos que você especifique outra coisa.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Valores associados

Os casos de um enum também podem armazenar valores personalizados de tipos variados junto de cada caso, conhecidos como [_valores associados_][associated-values]:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Um enum pode usar valores brutos ou valores associados, mas não os dois ao mesmo tempo.

## Enumerações recursivas

Uma [enumeração recursiva][recursive-enumerations] é um enum que tem outra instância do próprio enum como valor associado de um ou mais casos.
Para permitir a recursão, marque o caso (ou o enum inteiro) com a palavra-chave `indirect`:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
