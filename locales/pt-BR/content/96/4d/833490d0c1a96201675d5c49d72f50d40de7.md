# Dicas

## Geral

- Arrays em Swift usam índices a partir do zero. O primeiro índice de um array é `0`.

## 1. Recuperar uma carta de uma pilha

- Para obter o `n`-ésimo item de uma slice, [use um subscrito][array-access].
- Um array sempre começa no índice `0`.

## 2. Trocar uma carta na pilha

- Para definir o `n`-ésimo item de um array, [use um subscrito][array-access] e atribua um novo valor a ele.
- Um array sempre começa no índice `0`.

## 3. Inserir uma carta no topo da pilha

- Existe um [método de array][array-append-docs] para adicionar um novo valor ao final do array.

## 4. Remover uma carta da pilha

- Existe um [método de array][array-removeat-docs] que pode ser usado para remover elementos em um índice específico.

## 5. Remover a carta do topo da pilha

- Existe um [método de array][array-removelast-docs] para remover o último elemento do array.

## 6. Inserir uma carta na base da pilha

- Existe um [método de array][array-insert-docs] para adicionar um novo valor em um índice específico do array.
- Um array sempre começa no índice `0`.

## 7. Remover uma carta da base da pilha

- Existe um [método de array][array-removefirst-docs] para remover o primeiro elemento do array.

## 8. Verificar o tamanho da pilha

- Arrays têm uma [propriedade][array-count-docs] para obter seu comprimento.

## 9. Contar o número de cartas pares na pilha

- Você pode percorrer os elementos de um array usando um [laço for-in][for-in-loops].
- Os tipos inteiros em Swift têm o método [`isMultiple(of:)`][int-ismultiple-docs] para testar se são múltiplos de outro inteiro.
