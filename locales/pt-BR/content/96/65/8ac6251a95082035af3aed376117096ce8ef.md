# Instruções

Neste exercício, você vai escrever um pouco de código para ajudar a se preparar para comprar um veículo.

Você tem três tarefas: uma para determinar se você precisa de uma carteira de motorista, uma para ajudar a escolher entre dois veículos e uma para estimar o preço aceitável de um veículo usado.

## 1. Descubra se você vai precisar de carteira de motorista

Alguns tipos de veículo exigem carteira de motorista para serem conduzidos.
Considere que apenas os tipos `"car"` e `"truck"` exigem carteira; todo o resto pode ser conduzido sem carteira.

Implemente a função `NeedsLicense(kind)` que recebe o tipo de veículo e retorna um booleano indicando se você precisa de carteira para aquele tipo de veículo.

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. Escolha entre dois veículos em potencial para comprar

Você avalia suas opções de veículos disponíveis.
Você consegue reduzi-las a duas opções, mas precisa de ajuda para tomar a decisão final.
Para isso, implemente a função `ChooseVehicle(option1, option2)` que recebe dois veículos como argumentos e retorna uma decisão que inclui a opção que vem primeiro em ordem lexicográfica.

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcule uma estimativa para o preço de um veículo usado

Agora que você tomou uma decisão, você quer garantir que vai pagar um preço justo na concessionária.
Como você está interessado em comprar um veículo usado, o preço depende de quantos anos o veículo tem.
Para uma estimativa aproximada, considere que, se o veículo tiver menos de 3 anos, ele custa 80% do preço original que tinha quando era novo.
Se tiver pelo menos 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos mas menos de 10 anos, custa 70% do preço original.

Implemente a função `CalculateResellPrice(originalPrice, age)` que aplica essa lógica usando `if`, `else if` e `else` (existem outras formas, se você quiser praticar).
Ela recebe o preço original e a idade do veículo como argumentos e retorna o preço estimado na concessionária.

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**Observação**: o valor de retorno é um `float64`.
