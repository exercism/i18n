# Introdução

Se for possível inferir os tipos dos parâmetros, o Swift também permite omitir os nomes dos parâmetros e a palavra-chave `in` da definição do closure. Em vez disso, dá para se referir aos parâmetros usando uma sintaxe abreviada especial, na qual `$0` se refere ao primeiro parâmetro, `$1` se refere ao segundo, e assim por diante.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
