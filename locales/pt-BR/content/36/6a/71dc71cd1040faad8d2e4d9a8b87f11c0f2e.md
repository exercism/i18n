# uso de divisão de strings

Use o tipo embutido `rune` para trabalhar com caracteres individuais em Go.
Uma `string` pode ser convertida em um `[]rune` (slice de runes) com:

```go
aRunes := []rune(a)
```

Dividir a string em várias strings pequenas (uma para cada rune) funciona, mas é ineficiente.
