# Introdução

## Mapeamento

Mapeamento se refere à aplicação de uma função a cada elemento de uma sequência para produzir uma nova sequência.

Isso pode ser feito facilmente em uma lista com a função `mapcar`.
Vamos supor que temos uma função `double` que multiplica seu argumento por `2`:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Repare que o primeiro argumento é uma função a ser chamada. O `#'` é uma sintaxe especial de citação para especificar uma função.

`double` foi chamada primeiro com o primeiro elemento, depois com o segundo, etc.
Os resultados foram reunidos em uma lista, que é o valor da expressão.

## Filtragem

Filtragem é o processo de criar uma sequência a partir de outra sequência, copiando todos os elementos da sequência original, exceto alguns.
A escolha de quais itens incluir na nova sequência pode ser feita por uma função de predicado (uma função que avalia para um valor boolean) ou por igualdade com um objeto específico.

### Remover por um predicado

`remove-if` é uma função que recebe uma função de predicado e uma sequência como argumentos e retorna uma sequência apenas com os elementos para os quais o predicado avaliou para falso.
Em outras palavras, ela "remove" todos os elementos da sequência para os quais o predicado avalia para verdadeiro. No entanto, observe que essa função não modifica a sequência original! 
Em vez disso, ela retorna uma nova sequência sem os elementos em questão. Se o predicado foi verdadeiro para todos os valores, então uma sequência vazia é retornada.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### Remover um item específico

Se você quiser remover um item específico de uma sequência, pode usar `remove`, que recebe o item a remover e uma sequência.
Todos os valores da sequência que não são iguais ao item a remover são retornados.
OBSERVAÇÃO: por padrão, a igualdade é verificada com o `eql` [predicado de igualdade genérico][concept-equality].

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
