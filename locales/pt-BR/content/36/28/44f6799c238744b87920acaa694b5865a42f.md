# Dicas

## 1. Remover faixas duplicadas

- Você pode ver um exemplo de como criar um set a partir de um array na [documentação da MDN][mdn-relation-to-arrays].
- Certifique-se de converter seu set de volta em um array antes de retorná-lo.
- Volte ao [conceito de desestruturação de array][concept-array-destructuring] para relembrar como usar o operador spread.

## 2. Verificar se uma faixa já foi adicionada

- Existe um [método integrado][mdn-set-has] para verificar se um elemento está em um set.

## 3. Adicionar uma faixa

- Existe um [método integrado][mdn-set-add] para adicionar um elemento a um set.
- Certifique-se de não chamar `Set.has()` manualmente para verificar se o elemento está presente antes de adicioná-lo; o `Set.add()` cuida disso para você!

## 4. Excluir uma faixa

- Existe um [método integrado][mdn-set-delete] para remover um elemento de um set.
- Certifique-se de não chamar `Set.has()` manualmente para verificar se o elemento está presente antes de excluí-lo; o `Set.delete()` cuida disso para você!

## 5. Listar artistas únicos

- Existem [algumas formas diferentes][mdn-set-iteration] de iterar sobre um set.
- Existe um [método integrado][mdn-string-split] para dividir uma string em substrings.
- Volte ao [conceito de desestruturação de array][concept-array-destructuring] para relembrar como pular um elemento ao desestruturar um array.
