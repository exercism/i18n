# Anexo às instruções

## Formato de saída

Produza a sequência de ações como uma string terminada em nulo, usando uma vírgula e um espaço como separadores.

## Registradores

| Registrador | Uso          | Tipo    | Descrição                        |
| ----------- | ------------ | ------- | -------------------------------- |
| `$a0`       | entrada      | inteiro | número entre 1 e 31              |
| `$a1`       | entrada/saída | endereço | string de saída terminada em nulo |
| `$t0-9`     | temporário   | qualquer | usado para armazenamento temporário |
