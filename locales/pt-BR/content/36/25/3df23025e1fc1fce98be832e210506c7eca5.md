# Instruções

Neste exercício, você está jogando um jogo de RPG chamado "Wizard and Warriors" com seus melhores amigos.
Você é o Mestre do Jogo, a pessoa encarregada de fazer o mundo do jogo ganhar vida para os jogadores.
Um aspecto fundamental disso é descrever o jogo para os jogadores: qual é o status de um personagem, como é a cidade que eles estão visitando, etc.

Você tem cinco tarefas nas quais descreve partes do jogo para os jogadores.

## 1. Descreva um personagem

Cada personagem tem uma classe, um nível e uma quantidade de pontos de vida, e é descrito assim: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`.
Implemente o método `GameMaster.describe`, que recebe um `Character` como único parâmetro e retorna sua descrição.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Descreva um destino

Cada destino tem um nome e um número de habitantes, e é descrito assim: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`.
Implemente o método `GameMaster.describe`, que recebe um `Destination` como único parâmetro e retorna sua descrição.

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Descreva o método de viagem

Os personagens podem viajar até um destino de duas formas:

- A pé, descrito assim: `"You're traveling to your destination by walking."`
- A cavalo, descrito assim: `"You're traveling to your destination on horseback."`

Implemente o método `GameMaster.describe`, que recebe um `TravelMethod` como único parâmetro e retorna sua descrição.

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. Descreva um personagem viajando até um destino

Quando um personagem está viajando até um destino, isso é descrito como uma combinação das descrições individuais: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`.
Implemente o método `GameMaster.describe`, que recebe um `Character`, um `Destination` e um `TravelMethod` como parâmetros e retorna sua descrição.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Descreva um personagem viajando até um destino sem especificar o método de viagem

Na maioria dos casos, os personagens viajam até um destino a pé.
Por conveniência, os jogadores podem omitir o método de viagem; nesse caso, assume-se que a viagem é feita a pé.
Implemente o método `GameMaster.describe`, que recebe um `Character` e um `Destination` como parâmetros e retorna sua descrição.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
