# Sobre

O ABAP tem vários tipos numéricos. Os mais comuns em pequenos exercícios introdutórios são `i` para valores inteiros e `p` para valores decimais empacotados.

Use `i` quando um valor precisar ser um número inteiro, como uma contagem de dias. Use um tipo decimal quando um valor puder conter dígitos fracionários, como um valor por hora.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

Números empacotados são usados com frequência em aplicações de negócios quando é necessário um número fixo de casas decimais. O ABAP também tem números de ponto flutuante decimais (`decfloat16` e `decfloat34`) e números de ponto flutuante binários (`f`). Números de ponto flutuante binários podem ser úteis para cálculos científicos, mas não são uma boa opção padrão para exemplos que envolvem dinheiro, porque muitas frações decimais não podem ser representadas exatamente.
