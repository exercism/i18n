# Sobre

O tipo `Maybe` é a solução na linguagem Elm para valores opcionais.
Por isso, ele está presente nas assinaturas de tipo de um grande número de funções centrais do Elm, e entendê-lo é crucial.

## Definição e variável de tipo

O tipo `Maybe` é definido da seguinte forma:

```elm
type Maybe a = Nothing | Just a
```

Isso é conhecido como uma definição de "tipo personalizado" na terminologia do Elm.
Os tipos personalizados são apresentados em detalhes em outro conceito desta trilha, mas não precisaremos disso para entender especificamente `Maybe`.
O `a` em `Maybe a` e `Just a` representa uma variável de tipo, o que significa que pode ser qualquer tipo, como `Int`, `Bool` ou `String`.
Assim, um `Maybe String` é uma variável que contém opcionalmente uma `String`, enquanto um `Maybe Int` conteria opcionalmente um `Int`.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

A barra vertical `|` na definição de tipo de `Maybe` significa "OU".
Isso indica que um valor desse tipo pode ser ou `Nothing` OU `Just` alguma coisa do tipo `a`.
Então imagine que o nome e a idade não tivessem sido preenchidos por essa pessoa; teríamos o seguinte.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Lendo o conteúdo de um valor Maybe

Ler o conteúdo de um valor `Maybe` é feito por meio de "correspondência de padrões".
A correspondência de padrões também é apresentada em mais detalhes em outro conceito, então vamos focar apenas em como funciona a correspondência de padrões em um `Maybe`.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Toda vez que você usa um valor `Maybe`, o compilador do Elm verifica se o seu código lida com todas as possibilidades, de modo que você nunca pode fazer correspondência de padrões em um `Maybe` e tratar apenas o caso em que há um `Just someValue`.
Isso pode parecer irritante no começo, mas é um dos maiores pontos fortes da linguagem Elm.
Isso evita centenas de bugs e torna a refatoração guiada pelo compilador uma experiência sem medo e gratificante.

## Mais funções para manipular `Maybe`

Também há várias funções úteis no módulo `Maybe` para manipular tipos `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
