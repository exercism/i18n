# Testes

## Rodando os testes

Para rodar os testes, execute o seguinte comando:

```bash
call {slug}Test.bat
```

## Resolvendo o exercício

Resolver um exercício significa fazer com que todos os testes passem.
Quando todos os testes passarem, você terá resolvido o exercício!

Para ajudar você a começar, cada exercício vem com um arquivo de implementação stub.
Você pode usar esse arquivo como ponto de partida para construir a sua solução.
Fique à vontade para remover ou alterar esse arquivo se você achar que é a coisa certa a fazer.
