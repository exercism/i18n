# Aprendendo PowerShell

Um ótimo lugar para começar a aprender PowerShell é escolher um recurso de aprendizado na [seção de aprendizado][learning section] do site do PowerShell.
Ela tem uma quantidade enorme de informações e links para uma ampla variedade de tópicos sobre PowerShell.

O PowerShell também conta com um sistema de ajuda autodocumentado bastante completo.
Você pode explorar boa parte do que o PowerShell oferece usando o cmdlet `Get-Help`.
De dentro do PowerShell, experimente:

```PowerShell
Get-Help about
```

Você vai ver cerca de 3 páginas de tópicos que podem ser explorados.
Mais duas funções que serão muito úteis são:

- Get-Command
- Get-Member

Quer saber o que elas fazem?
Experimente `Get-Help Get-Command` e `Get-Help Get-Member`, é claro.

## Verbos e substantivos do PowerShell

O PowerShell segue um padrão bem rígido de Verbo-Substantivo para nomear seus cmdlets.
No começo, isso pode causar um certo estranhamento em programadores experientes.
Embora você possa dar o nome que quiser às suas funções, conhecer e adotar os verbos padrão vai melhorar seu código em PowerShell.

Para ver uma lista de todos os verbos aprovados, basta rodar:

```PowerShell
Get-Verb
```
