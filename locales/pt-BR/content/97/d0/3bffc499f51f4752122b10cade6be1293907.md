# Sobre

[Dicionários][dictionaries] são um dos principais tipos de coleção do Swift.
Um dicionário armazena associações não ordenadas entre chaves únicas e os valores correspondentes.
Todas as chaves de um dicionário devem ser do mesmo tipo, e todos os valores também devem compartilhar o mesmo tipo.

Os literais de dicionário são escritos como pares `key: value` separados por vírgula e entre colchetes:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

Os tipos de dicionário podem ser escritos explicitamente de duas formas: `Dictionary<Key, Value>` ou a sintaxe abreviada `[Key: Value]`.

Para criar um dicionário vazio, especifique explicitamente os tipos de chave e valor:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## Acessando valores

Você pode acessar valores usando a notação de subscrito: coloque a chave entre colchetes depois do nome do dicionário.
Como uma chave pode não existir no dicionário, o acesso por subscrito retorna um *opcional* (`Value?`).
Se a chave estiver presente, o Swift retorna o valor encapsulado; se não estiver, retorna `nil`:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

Para não precisar lidar com opcionais, você pode fornecer um valor padrão usando o parâmetro `default`:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## Modificando dicionários

Em dicionários mutáveis, declarados com `var`, você pode adicionar ou atualizar pares de chave e valor usando atribuição por subscrito:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## Iterando sobre um dicionário

Você pode iterar sobre cada par de chave e valor de um dicionário usando um laço `for-in`.
Cada item é fornecido como uma tupla `(key, value)`:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## Ordenando dicionários

Como os dicionários não são ordenados, ordená-los produz um array de pares de chave e valor.
Você pode passar um closure para o método `sorted(by:)` que compara duas tuplas `(key, value)` e retorna `true` se a primeira tupla deve aparecer antes da segunda:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
