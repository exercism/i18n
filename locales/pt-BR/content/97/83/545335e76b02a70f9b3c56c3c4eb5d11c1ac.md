# Instruções

Neste exercício, você vai escrever um pouco de código para ajudar a se preparar para comprar um veículo.

Você tem três tarefas: uma para determinar se você precisa de carteira de habilitação, uma para ajudar a escolher entre dois veículos e uma para estimar o preço aceitável de um veículo usado.

## 1. Determine se você vai precisar de carteira de habilitação

Alguns tipos de veículo exigem carteira de habilitação para serem conduzidos.
Considere que apenas os tipos `"car"` e `"truck"` exigem habilitação, e que todos os outros podem ser conduzidos sem habilitação.

Implemente a função `needs_license(kind)` que recebe o tipo de veículo como string e retorna um boolean indicando se você precisa de habilitação para aquele tipo de veículo.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. Escolha entre dois possíveis veículos para comprar

Você avalia as opções de veículos disponíveis.
Você consegue reduzir tudo a duas opções, mas precisa de ajuda para tomar a decisão final.
Para isso, implemente a função `choose_vehicle(option1, option2)` que recebe dois veículos como argumentos e retorna uma decisão que inclui a opção que vem primeiro na ordem lexicográfica.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

A string retornada deve seguir o padrão de "<CHOSEN_VEHICLE> is clearly the better choice.", em que `<CHOSEN_VEHICLE>` é a opção escolhida entre os argumentos recebidos.

## 3. Calcule uma estimativa para o preço de um veículo usado

Agora que você tomou uma decisão, você quer garantir um preço justo na concessionária.
Como você está interessado em comprar um veículo usado, o preço depende de quantos anos o veículo tem.
Para uma estimativa aproximada, considere que, se o veículo tiver menos de 3 anos, ele custa 80% do preço original de quando era zero.
Se tiver pelo menos 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos, mas menos de 10, custa 70% do preço original.

Implemente a função `calculate_resell_price(original_price, age)` que aplica essa lógica usando `if`, `else if` e `else` (existem outras formas, se você quiser praticar).
Ela recebe o preço original e a idade do veículo como argumentos e retorna o preço estimado na concessionária.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> Observação: o valor de retorno é do tipo `double`.
