# Instruções

Neste exercício, você vai organizar corridas entre vários tipos de carros de controle remoto. Cada carro tem suas próprias características de velocidade e consumo de bateria.

Os carros começam com a bateria cheia (100%). Cada vez que você dirige o carro com o controle remoto, ele percorre a velocidade do carro em metros e diminui a porcentagem restante da bateria pelo seu consumo de bateria.

Se a bateria de um carro estiver abaixo da porcentagem do seu consumo de bateria, você não pode mais dirigir o carro.

Cada pista de corrida tem seu próprio comprimento. Os carros são testados verificando se conseguem terminar a pista sem ficar sem bateria.

## 1. Crie um carro de controle remoto

Defina uma lista `car` com os seguintes elementos:

- speed
- battery_drain
- battery
- distance_traveled

Você pode criar um carro de controle remoto definindo uma função `new_car` que recebe a velocidade do carro em metros e a porcentagem de consumo de bateria como seus dois parâmetros e retorna uma lista `car`.

Em um carro novo, a bateria está em 100% e a distância percorrida é zero.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. Crie uma pista de corrida

Defina outra lista chamada `track` com o único elemento `track_length`.
Você pode criar uma pista de corrida definindo uma função `new_track` que recebe a distância da pista em metros:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. Verifique se a bateria está descarregada

Implemente a função `battery_drained()` que indica se a bateria está descarregada.
Uma bateria é considerada descarregada se não houver energia suficiente para se mover mais uma vez.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. Dirija o carro

Implemente a função `drive` que atualiza o número de metros percorridos com base na velocidade do carro e reduz a bateria de acordo com o consumo de bateria.
Se não houver bateria suficiente para dirigir mais uma vez, o carro não se moverá.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. Verifique se um carro de controle remoto consegue terminar uma corrida

Para terminar uma corrida, um carro precisa conseguir percorrer todo o comprimento da corrida. Isso significa não esgotar a bateria antes de cruzar a linha de chegada.

Implemente a função `can_finish` que recebe um `car` e uma `track` como seus parâmetros e retorna `TRUE` se o carro conseguir terminar a corrida; caso contrário, retorne `FALSE`.

Suponha que você esteja na linha de partida da corrida e ligue o motor do carro para a corrida. Leve em conta que a bateria do carro pode não estar totalmente carregada ao começar a corrida.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. Armazene se o carro consegue terminar uma pista com a bateria cheia

Você criou várias pistas de comprimentos diferentes e precisa armazenar se o seu carro consegue completá-las quando estiver com a bateria cheia.

Implemente a função `store_track` que recebe um carro, uma pista e um nome de pista, e retorna um carro atualizado com um elemento extra.
Esse elemento deve ter o `name` da pista, e o valor deve ser uma sub-lista com o `track_length` e se o carro consegue `complete`-la.

O carro fornecido no argumento pode não estar totalmente carregado, então certifique-se de redefinir a bateria e a distância percorrida antes de usá-lo.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
