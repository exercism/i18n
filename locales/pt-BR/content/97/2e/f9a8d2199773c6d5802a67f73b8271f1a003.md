# Sobre

Para executar uma lógica repetidamente, você pode usar laços. Um dos tipos de laço mais comuns em C# é o laço `while`, que continua repetindo até que uma condição Boolean seja avaliada como `false`.

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 1;
}
```
