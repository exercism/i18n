# Anexo às instruções

## Implementação

Para completar este exercício, você precisa criar o tipo de dados `LinkedList` e implementar as seguintes funções:

- `new`
- `cons`
- `nil`
- `fromList`
- `head`
- `tail`
- `isNil`
- `reverseLinkedList`
- `toList`

Você vai encontrar uma declaração de tipo fictícia e as assinaturas de tipo já no lugar, mas cabe a você definir as funções e criar um tipo de dados que faça sentido.
