# Sobre

Todo programa que você já executou, seja um jogo, um navegador ou um aplicativo de celular, acaba virando uma longa lista de instruções minúsculas que o processador executa uma de cada vez.
A linguagem assembly é o que permite escrever essas instruções por conta própria.
Em vez de variáveis, listas e laços `for`, você trabalha com os blocos de construção do próprio processador: um pequeno conjunto de registradores, endereços de memória e saltos de uma instrução para outra.

RISC-V (pronuncia-se "risk five") é um projeto de processador que começou na Universidade da Califórnia, em Berkeley, em 2010.
Diferente da maioria dos projetos de processador, ele é um padrão aberto: ninguém precisa pagar nem pedir permissão para fabricar um chip RISC-V, e a especificação é livre para qualquer pessoa ler.
Chips RISC-V estão em microcontroladores, computadores de placa única, dispositivos de armazenamento e muito mais.

RISC-V é uma boa primeira linguagem assembly porque foi projetada para ser simples.
Suas instruções seguem um pequeno número de padrões regulares, e seus 32 registradores têm papéis claros e consistentes, então há muito menos para memorizar do que com os processadores da maioria dos notebooks.
Essa simplicidade também é o motivo pelo qual muitas universidades hoje usam RISC-V para ensinar como os computadores funcionam.

Aqui vai uma pequena amostra, uma função que soma dois números:

```riscvasm
add_numbers:
        add     a0, a0, a1      /* a0 = a0 + a1 */
        ret                     /* return to the caller, with the answer in a0 */
```

Nesta trilha, você escreve assembly RISC-V de 32 bits.
Você não precisa de nenhum hardware RISC-V: seus programas são testados em um emulador, que finge ser um processador RISC-V.
Você pode resolver os exercícios no editor online ou no seu próprio computador, usando ferramentas gratuitas.

Aprender assembly exige paciência, mas vale a pena.
Depois que você vê como um laço ou uma chamada de função aparece para o processador, toda outra linguagem de programação passa a fazer um pouco mais de sentido.
