## Ferramentas interativas para jq

Informe uma entrada e experimente vários filtros do jq para ver o resultado.

- [jq playground][jqplay], uma experiência de "experimente online".
- [ijq][ijq], ferramenta interativa de jq, como o jqplay, mas para a linha de comando.
- O [jqp][jqp] é outra ferramenta de linha de comando: ele usa o gojq como backend, que não é 100% compatível com o jq original.

## Outras ferramentas de processamento de JSON

- [gron][gron]: "achata" o JSON em uma sequência de atribuições individuais, o que possibilita usar ferramentas orientadas a linha (grep etc.) para processá-lo.
- [jo][jo]: um pequeno utilitário para criar objetos JSON a partir de variáveis do shell.
- [jello][jello]: o jello é parecido com o jq, mas usa a sintaxe padrão de dict e list do Python.
