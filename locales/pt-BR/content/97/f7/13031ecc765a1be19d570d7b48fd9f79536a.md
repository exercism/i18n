# Testes

Para rodar o teste no DrRacket, basta abrir o arquivo de teste e clicar no botão 'Run' no canto superior direito.

Para rodar o teste pela linha de comando, execute-o a partir do diretório do exercício com o seguinte comando:

```
raco test <exercise>-test.rkt
```

em que `<exercise>` deve ser substituído pelo slug do exercício.
