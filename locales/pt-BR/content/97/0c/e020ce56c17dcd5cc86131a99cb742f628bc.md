# Apêndice das instruções

## Implementação

O track de Crystal adiciona um teste opcional para verificar se as letras possíveis podem ser qualquer caractere Unicode, não apenas letras ASCII.
Esses testes não ficam disponíveis no editor web, mas são ativados por padrão quando o código é executado localmente.

Para desativar esses testes, ao chamar o executor de testes, adicione a seguinte flag: `--tag "~optional"`
