# Introdução

## Números de ponto flutuante

Um número de ponto flutuante é um número com zero ou mais dígitos depois do separador decimal. Alguns exemplos são `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

Tipos de ponto flutuante diferentes conseguem armazenar quantidades diferentes de dígitos depois do separador decimal. É isso que chamamos de precisão.

O C# tem três tipos de ponto flutuante:

- `float`: 4 bytes (~6-9 dígitos de precisão). Escrito como `2.45f`.
- `double`: 8 bytes (~15-17 dígitos de precisão). É o tipo mais comum. Escrito como `2.45` ou `2.45d`.
- `decimal`: 16 bytes (28-29 dígitos de precisão). Normalmente usado ao trabalhar com dados monetários, já que a sua precisão reduz a chance de erros de arredondamento. Escrito como `2.45m`.

Como dá para ver, cada tipo consegue armazenar uma quantidade diferente de dígitos. Por exemplo, tentar armazenar PI em um `float` vai armazenar apenas as 6 primeiras casas decimais (com o último dígito armazenado arredondado).

## Laços `while`

Neste exercício, talvez você queira usar um laço. Existem várias formas de escrever laços em C#, mas o laço `while` é o mais adequado aqui:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## Laços `do`/`while`

Se o código dentro de um laço deve ser executado sempre pelo menos uma vez, dá para usar um laço `do`/`while`:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
