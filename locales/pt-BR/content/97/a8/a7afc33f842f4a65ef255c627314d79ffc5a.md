# Anexo das instruções

## Informações específicas do Arturo

Neste exercício, espera-se que você retorne as idades usando uma [quantidade física] com uma unidade personalizada que representa a duração de um ano naquele planeta.
No Arturo, uma quantidade é formada por um valor numérico e uma [unidade de medida][unit-of-measurement] associada.

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
A unidade `yr nativa do Arturo é convertida para 31556952 segundos.
Por isso, você vai precisar definir e usar a sua própria unidade de ano em termos do número de segundos citado antes nas instruções.
~~~~

Quantidades podem ser [convertidas][convert] para outra unidade compatível.
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
Por causa das limitações de precisão dos números de ponto flutuante, às vezes o Arturo armazena o escalar como um número racional.
A [função `to`][to] pode ser usada para recuperar o valor como um número de ponto flutuante aproximado.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

O Arturo também permite [especificar][specify] nossas próprias unidades para as quantidades.

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
