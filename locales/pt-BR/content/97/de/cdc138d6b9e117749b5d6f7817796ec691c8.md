# Introdução

Além das classes de caracteres e dos quantificadores, as expressões regulares conseguem descrever *estrutura* e *contexto*. Esses recursos ficam no mesmo vocabulário [`regexp`][regexp] e no mesmo literal `R/ /`.

Os parênteses `( )` agrupam parte de um padrão para que um quantificador ou um `|` ("isto ou aquilo") se aplique ao grupo inteiro; um `?` depois do grupo o torna opcional:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

As âncoras fixam um padrão a uma posição: `^` (início), `$` (fim) e `\b` (um limite de palavra).

Um *lookaround* faz a correspondência pelo que cerca um ponto, sem consumi-lo:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

Uma letra de opção depois da `/` de fechamento muda o padrão inteiro; o `i` faz com que ele ignore maiúsculas e minúsculas:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

O Factor usa lookaround no lugar de grupos de captura: ele não faz extração de grupos de captura, nem retro-referências, nem quantificadores preguiçosos.
