# Instruções

Neste exercício, você precisa implementar algumas funções para manipular uma lista de linguagens de programação.

## 1. Defina uma função que retorna uma lista vazia de linguagens

Defina a função `new`, que não recebe argumentos e retorna uma lista vazia.

```haskell
new
-- -> []
```

## 2. Defina uma função para adicionar uma linguagem à lista

Defina a função `add/2`, que recebe 2 argumentos (uma _lista de linguagens_ e um literal de string de uma _linguagem_).
Ela deve retornar a lista resultante com a nova linguagem inserida no início da lista fornecida.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Defina uma função para remover uma linguagem da lista

Defina a função `remove`, que recebe 1 argumento (uma _lista de linguagens_).
Ela deve retornar a lista sem o primeiro item. Considere que a lista sempre terá pelo menos um item.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Defina uma função que retorna o primeiro item da lista

Defina a função `first`, que recebe 1 argumento (uma _lista de linguagens_).
Ela deve retornar a primeira linguagem da lista.
Considere que a lista sempre terá pelo menos um item.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Defina uma função que retorna quantas linguagens há na lista

Defina a função `count`, que recebe 1 argumento (uma _lista de linguagens_).
Ela deve retornar o número de linguagens na lista.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Defina uma função para determinar se a lista inclui uma linguagem funcional

Defina a função `isFunctionalList`, que recebe 1 argumento (uma _lista de linguagens_).
Ela deve retornar um valor booleano.
Ela deve retornar `True` se _"Haskell"_ for uma das linguagens da lista.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
