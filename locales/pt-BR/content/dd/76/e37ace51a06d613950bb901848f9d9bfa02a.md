# Dicas

## Geral

- `NestedValue` é uma união de tags recursiva: cada valor é `Value(number)`, `Null` ou `NestedArray(children)`.
  Use `match` para distinguir esses casos e acessar os valores que cada um carrega.

- `List.join_map` pode ser útil quando uma função mapeia cada filho para uma lista e você quer concatenar os resultados.
