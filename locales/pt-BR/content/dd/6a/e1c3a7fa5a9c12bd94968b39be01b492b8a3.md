# Anexo das instruções

## Instruções específicas da trilha

No exercício "Yacht", você vai criar um verbo que calcula a pontuação de um único lançamento de cinco dados no jogo Yacht, com base na categoria escolhida.

Para este exercício, seu verbo vai receber dois argumentos:

- **Argumento da esquerda**: uma string que representa a categoria de pontuação a ser aplicada ao lançamento dos dados.
- **Argumento da direita**: uma lista de inteiros que representa os cinco dados lançados.

Seu verbo deve ser definido para lidar com essas entradas da seguinte forma:

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
