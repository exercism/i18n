# Instalação

## Instalando o .NET

A trilha de C# é construída sobre a plataforma [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), que roda em Windows, Linux e macOS.
Para compilar projetos .NET, você pode usar a interface de linha de comando (CLI) do .NET.
Essa CLI faz parte do .NET SDK, que você pode instalar seguindo as [instruções de instalação](https://dotnet.microsoft.com/download/dotnet/8.0).
Observação: a trilha de C# exige a versão 9.0 do SDK ou superior.

Depois de concluir a instalação, você pode verificar se a CLI foi instalada com sucesso rodando este comando em um terminal:

```bash
dotnet --version
```

Se a saída for uma versão maior ou igual a `9.0.100`, o .NET SDK foi instalado com sucesso.

## Usando um IDE

Se você quer uma experiência de edição mais completa, provavelmente vai querer usar um [IDE ou ambiente de desenvolvimento integrado)](https://en.wikipedia.org/wiki/Integrated_development_environment).
Estes são os IDEs mais populares que dão suporte à criação de projetos .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) com a [extensão C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Observação: como o formato de projeto do .NET é bem diferente das versões anteriores, IDEs mais antigos (como o Visual Studio 2015) não são compatíveis.
