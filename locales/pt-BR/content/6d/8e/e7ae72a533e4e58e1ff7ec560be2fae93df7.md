# Recursos

* [The Rust Programming Language](https://doc.rust-lang.org/book/) é um ótimo recurso para começar com Rust e também para se aprofundar em funcionalidades específicas da linguagem.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) mostra exemplos das coisas mais comuns que você vai escrever em Rust.
* A [Rust API Documentation](http://doc.rust-lang.org/std/) pode ser usada para descobrir novos métodos e entender como eles funcionam.
* O [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) pode ser usado para pesquisar o seu problema e ver se ele já foi respondido. Você também pode fazer e responder perguntas.
* O [Rust User Forum](http://users.rust-lang.org) é para discussões gerais sobre Rust.
* O [/r/rust](http://www.reddit.com/r/rust/) é o subreddit oficial do Rust.
* O servidor oficial do [The Rust Programming Language](https://discord.gg/rust-lang) no [Discord](https://discordapp.com/) pode ser usado para dúvidas rápidas e discussões sobre a linguagem.
