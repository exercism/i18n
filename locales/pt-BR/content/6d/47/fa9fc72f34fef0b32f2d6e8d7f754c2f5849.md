# Instalação

As soluções desta trilha são escritas em assembly RISC-V de 32 bits e rodam sob emulação, então não é preciso ter hardware RISC-V.
Cada exercício vem com um Makefile que compila os testes e os executa.
Para usá-lo, você precisa de três ferramentas:

- [Zig][zig], que fornece o montador RISC-V, o compilador C e o linker por meio de `zig cc`.
- [Make][make], que executa a compilação.
- `qemu-riscv32`, do [QEMU][qemu], que executa o programa resultante.

## macOS

Inicie uma máquina virtual Linux com qualquer solução de virtualização adequada (por exemplo, [Lima][lima]) e siga uma das seções de distribuição Linux abaixo.

## Windows

Use o [Windows Subsystem for Linux][wsl] e siga uma das seções de distribuição Linux abaixo.
Como alternativa, monte uma máquina virtual Linux.

## Debian / Ubuntu

Instale o Make e os emuladores de modo usuário do QEMU:

```shell
sudo apt install make qemu-user
```

Depois, instale o Zig 0.15.2 ou mais recente conforme descrito em [Download direto][zig-install].

## Fedora

Instale as três ferramentas com:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

Instale as três ferramentas com:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

Instale as três ferramentas com:

```shell
sudo zypper install zig make qemu-linux-user
```

## Conferindo a instalação

Confirme que as três ferramentas estão disponíveis:

```shell
zig version
make --version
qemu-riscv32 --version
```

Depois, baixe um exercício com a CLI do Exercism e rode os testes:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
