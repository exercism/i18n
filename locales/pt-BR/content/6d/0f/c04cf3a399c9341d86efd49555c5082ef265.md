# Introdução

## IO

O módulo `IO` fornece funções para lidar com entrada e saída.

### Saída

Para escrever uma string na saída padrão, use `IO.puts`. `IO.puts` sempre adiciona uma nova linha no final da string. Se você não quiser esse comportamento, use `IO.write`. As duas funções retornam o átomo `:ok` se derem certo.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` é útil para escrever strings, mas não serve para muito mais que isso. Se você precisar de uma ferramenta de depuração que permita escrever qualquer valor na saída padrão, use `IO.inspect`. `IO.inspect` retorna o valor que recebeu sem alterações, então dá para inseri-lo em qualquer ponto do seu code. Ele também aceita muitas opções, por exemplo `:label`, que permitem distingui-lo de outras chamadas de `IO.inspect`.

### Entrada

Para ler uma linha da entrada padrão, use `IO.gets`. `IO.gets` aceita um argumento: uma string que será impressa como prompt para a entrada. `IO.gets` não adiciona uma nova linha depois do prompt. Se precisar, inclua a nova linha.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
