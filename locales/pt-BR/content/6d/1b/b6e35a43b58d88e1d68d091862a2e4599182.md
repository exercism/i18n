# não use funções de lista

Por favor, não use nenhum módulo externo (como List, Enum ou Stream) na sua
implementação. O objetivo deste exercício é que você mesmo crie essas funções
básicas. Você pode usar funções básicas do Kernel (como `Kernel.+/2` para
somar números), mas, por favor, não use funções do Kernel para listas como
`++`, `--`, `hd`, `tl`, `in`, `for` e `length`.
