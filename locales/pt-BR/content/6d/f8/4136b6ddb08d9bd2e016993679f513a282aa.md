# Aprendizado

## Começando com o Emacs

Então você instalou o Emacs. E agora?

Bem, você pode começar o tutorial pressionando `C-h t`, e esse não é um mau lugar para começar. O tutorial vai te ensinar o básico de edição, busca e navegação no Emacs.

Se você está começando agora com o Emacs, pode fazer sentido usar um kit inicial, que já vem com um conjunto de configurações e pacotes prontos.

O pacote [Emacs Prelude](http://batsov.com/prelude/) oferece um bom conjunto de padrões sensatos e pacotes.

Para instalar o Emacs Prelude, rode o seguinte em um terminal:

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

e não deixe de conferir o [guia de instalação](https://prelude.emacsredux.com/en/latest/installation/) para mais instruções.


Se você conhece o vim, pode se interessar pelo kit inicial [Doom Emacs](https://github.com/doomemacs/doomemacs), que integra a emulação do vim com o [evil-mode](https://github.com/emacs-evil/evil).

Para instalar o Doom Emacs, rode o seguinte em um terminal:

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

e não deixe de conferir o [guia de instalação](https://github.com/doomemacs/doomemacs#install) para mais instruções.

## Configurando a verificação de sintaxe e o linting

Recomendamos configurar a verificação de sintaxe e o linting com o [Flycheck](https://www.flycheck.org/en/latest/).

Se você ainda não adicionou o repositório [MELPA](https://melpa.org/) ao seu Emacs, faça isso adicionando o seguinte ao seu [arquivo de inicialização](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

A instalação e a configuração do Flycheck sem o [use-package](https://github.com/jwiegley/use-package) são feitas adicionando o seguinte ao seu [arquivo de inicialização](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

A instalação e a configuração do Flycheck com o [use-package](https://github.com/jwiegley/use-package) são feitas adicionando o seguinte ao seu [arquivo de inicialização](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

Para mais informações e solução de problemas, confira a [documentação do Flycheck](https://www.flycheck.org/en/latest/user/troubleshooting.html).

## Aprendendo Emacs Lisp

A melhor documentação sobre Emacs Lisp é... distribuída com o próprio Emacs! Para acessar a [Emacs Lisp Reference](https://www.gnu.org/software/emacs/manual/elisp.html), digite `C-h i` e procure a entrada Elisp, ou selecione Help &rarr; More Manuals &rarr; Emacs Lisp Reference. Observe que o manual pode estar faltando em algumas distribuições; nesse caso, você pode encontrá-lo [online](https://www.gnu.org/software/emacs/manual/elisp.html).

Se você nunca teve contato com Elisp, pode ler a [Introduction to Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro), que é aberta da mesma forma.

## Boas práticas e convenções do Emacs Lisp

O Manual do Emacs contém uma seção sobre [Convenções de Código](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html) do Emacs Lisp. Há também um [Guia de Estilo](https://github.com/bbatsov/emacs-lisp-style-guide) mantido pela comunidade no GitHub.
