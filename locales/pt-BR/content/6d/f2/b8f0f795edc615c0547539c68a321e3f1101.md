# Aprendizado

Lean é ao mesmo tempo uma linguagem de programação funcional de propósito geral e um assistente de provas.
Há diversos recursos disponíveis para aprender Lean, alguns com foco nos aspectos de programação da linguagem e outros no seu uso como provador de teoremas.

O livro [Functional Programming in Lean][functional-programming] é uma introdução ao paradigma da programação funcional usando Lean.
Ele é voltado a programadores que querem aprender Lean, mesmo sem nenhuma experiência anterior com linguagens de programação funcionais.

Para um estudo mais aprofundado de provas de teoremas em Lean, o livro [Theorem Proving in Lean 4][theorem-proving] é indicado como recurso oficial.

[The Lean Language Reference][lean-reference] é a fonte autoritativa para informações detalhadas sobre a linguagem.

Muitos recursos adicionais para aprender Lean são disponibilizados pela [Lean Community][community-resources].
