# Anexo de instruções

## Crie sua própria DSL

Neste exercício, você tem total liberdade para projetar a DSL de grafo dos seus sonhos.

Talvez você queira criar uma DSL baseada em listas de tags e registros, assim:

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

Ou talvez você prefira uma DSL baseada em cadeias de chamadas de funções, assim:

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

Ou talvez você tenha um plano bem diferente? Vá em frente! Os testes exigem apenas que você crie alguns grafos específicos. A forma de construí-los é totalmente com você.

Dito isso, uma DSL costuma ser melhor quando é clara, concisa e não muito surpreendente (por exemplo, a função `minus` serve para subtrair, não para criar uma aresta entre dois nós, como em `node("a") - node("b")`).

Para dobrar a diversão, você pode, opcionalmente, tentar implementar uma função `to_dot` que converte seu grafo para o formato DOT!
