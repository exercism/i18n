# Introdução

No Gleam existem dois tipos diferentes de números: inteiros e números de ponto flutuante.

Inteiros são números sem parte fracionária.

```gleam
let integer = 3
// -> 3
```

O Gleam tem vários operadores que funcionam com inteiros.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
