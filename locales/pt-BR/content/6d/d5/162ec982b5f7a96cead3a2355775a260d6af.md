# Visibilidade

Ao usar classes para organizar o código, a visibilidade de propriedades, métodos e constantes pode favorecer abstrações e responsabilidades bem definidas.
A visibilidade de propriedades, métodos e constantes é definida pelo uso das palavras-chave `public`, `private` ou `protected` no momento em que elas são declaradas.
A visibilidade sempre diz respeito ao uso externo da propriedade, do método ou da constante da classe.
Ou seja, se uma propriedade é declarada `public`, ela é observável e utilizável por chamadas externas.
Propriedades, métodos e constantes privadas não são observáveis nem utilizáveis por chamadas externas.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

Propriedades, métodos e constantes protegidas são observáveis apenas para a própria classe e para as classes filhas (por herança).

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
