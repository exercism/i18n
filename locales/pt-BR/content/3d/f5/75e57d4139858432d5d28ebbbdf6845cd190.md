# Introdução

O Haxe dá suporte a reflexão de tipos e campos em tempo de execução. Para usar a reflexão corretamente, é preciso entender que tipo de operação é suportada e qual não é. Como a reflexão é dinâmica por natureza, nem sempre dá para determinar isso em tempo de compilação.

A API de reflexão é formada por duas classes:

- `Reflect`: uma API leve, que funciona melhor com estruturas anônimas e tem suporte limitado a classes.
- `Type`: uma API mais robusta para trabalhar com classes e enums.

No exemplo a seguir, estamos usando o alvo JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
