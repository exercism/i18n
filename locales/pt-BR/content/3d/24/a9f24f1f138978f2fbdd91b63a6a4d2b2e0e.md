# Introdução

## Conceitos básicos

Em F#, atribuir um valor a um nome é chamado de _binding_. Bindings são imutáveis, o que os torna parecidos com constantes em outras linguagens. Como F# é uma linguagem com tipagem estática, cada binding tem um tipo em tempo de compilação.

Bindings são definidos com a palavra-chave `let`. Especificar o tipo de um binding é opcional na maioria dos casos, pois a _inferência de tipos_ do F# normalmente consegue inferir o tipo a partir do valor. Um binding se parece com isto:

```fsharp
// Automatically inferred type
let fingers = 10
```

Funções também são bindings comuns, mas com um ou mais parâmetros. Uma função retorna automaticamente sua última expressão. A inferência de tipos também funciona para a maioria das funções, analisando com quais valores a função é chamada e qual valor ela retorna.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Para invocar uma função, especifique o nome dela e passe argumentos para cada um dos parâmetros da função.

```fsharp
let five = add 2 3
```

Se o tipo de um binding não puder ser inferido, o compilador vai reportar um erro. Para corrigir isso, adicione uma anotação de tipo explícita ao binding.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Bindings em F# só podem ser usados _depois_ de definidos. Usar um binding antes de defini-lo resulta em um erro de compilação.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# usa espaços em branco significativos para definir escopo. Isso significa que o escopo é definido indentando o código com espaços, em relação à linha que declara o binding. A convenção padrão é usar quatro espaços de indentação:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Bindings em F# (que incluem funções) geralmente são organizados em módulos. Um módulo agrupa funcionalidades relacionadas e é definido com a palavra-chave `module`. A definição do módulo deve vir antes dos seus bindings:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# oferece suporte a dois tipos de comentários. Comentários de uma linha são precedidos por `//` e comentários de várias linhas ficam entre `(*` e `*)`.
