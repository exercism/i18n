# Instruções

O clássico exercício introdutório.
Basta dizer "Hello, World!".

["Hello, World!"][hello-world] é o tradicional primeiro programa de quem está começando a programar em uma nova linguagem ou ambiente.

Os objetivos são simples:

- Modifique o código fornecido para que ele produza a string "Hello, World!".
- Rode a suíte de testes e verifique se ela passa.
- Envie sua solução e confira no site.

Se tudo der certo, você vai estar pronto para buscar seu primeiro exercício de verdade.

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
