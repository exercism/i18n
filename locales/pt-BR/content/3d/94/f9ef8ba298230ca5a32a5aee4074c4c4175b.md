# Introdução


## Boolean

O PowerShell tem o tipo [`bool`][booleans] para representar valores verdadeiro e falso.
Nesse tipo existem apenas dois valores: `True` e `False`.
Você pode associar esses valores a variáveis com o prefixo `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Podemos usar [operadores lógicos][logical-operators] como `-and`, `-or` e `-not` para combinar e avaliar expressões booleanas.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## Ajuda baseada em comentários

A [`Comment-based help`][comment-based help] no PowerShell ajuda a fornecer informações detalhadas sobre funções e scripts escritos em comentários.
Ela usa palavras-chave especiais de comentário de ajuda para especificar os tópicos em foco, como `.SYNOPSIS`, `.EXAMPLE` ou `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

Você pode exibir as informações da ajuda baseada em comentários usando o cmdlet `Get-Help`.

```powershell
> Get-Help -Name "ExampleFunction"
```
