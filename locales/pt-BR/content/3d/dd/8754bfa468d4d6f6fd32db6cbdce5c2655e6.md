# Instruções

O caderno de um detetive vai enchendo conforme o caso avança e volta a esvaziar conforme linhas de investigação são descartadas.

Todas as cinco tarefas ficam na classe `CASE_NOTES`.

## 1. Abrir um caso

Retorne um caderno novo e vazio.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. Anotar uma pista

Adicione uma pista ao final do caderno. Isso não retorna nada: apenas altera o caderno que recebe.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. Quantas pistas?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. Descartar uma

Tire a pista de uma posição do caderno. Tudo o que vem depois dela sobe uma posição. Isso também não retorna nada.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. Relembrar o caso

Retorne todas as pistas do caderno, unidas por `"; "`. Um caderno vazio é lido como a string vazia.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
