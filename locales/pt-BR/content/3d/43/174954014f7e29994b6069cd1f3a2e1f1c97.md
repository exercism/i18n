# APRENDIZADO

O Vim já vem com uma ótima documentação embutida. A interface para a documentação é o comando `:help`.

Para uma introdução, veja `:h user-manual`.

Quase todas as instalações do Vim também vêm com um tutorial interativo:

```
$ vimtutor
```

O Vim tem décadas de existência e continua popular. Você vai encontrar muitos recursos sobre ele na web, alguns melhores que outros. Os bons estão listados [aqui](https://exercism.org/docs/tracks/vimscript/resources).
