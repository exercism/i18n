## 4. Defina a atividade

- [Esta página][define] mostra como definir uma união discriminada, tanto para casos com dados associados quanto sem.

## 5. Avalie a atividade

- A melhor forma de executar a lógica com base no valor da atividade é usar [correspondência de padrões][pattern-matching].
- O padrão para corresponder aos casos de uma união discriminada (e, opcionalmente, aos dados associados a eles) é usar [padrões de identificador][identifier-patterns].
- Se você quiser adicionar uma condição extra a um padrão, pode adicionar uma [guarda][guards].
- Se quiser capturar mais de um valor de uma vez, pode usar um [padrão curinga][wildcard-patterns].
