# Instruções

Você adora observar aves e acompanha quantos pássaros visitaram seu jardim nos últimos sete dias.

Você tem cinco tarefas, todas sobre os números de pássaros que visitaram seu jardim.

## 1. Confira quais foram as contagens da semana passada

Para fins de comparação, você sempre mantém por perto uma cópia das contagens da semana passada, que foram: 0, 2, 5, 3, 7, 8 e 4. Implemente o método `BirdCount.last_week`, que retorna as contagens da semana passada:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Verifique quantos pássaros visitaram ontem

Implemente o método `BirdCount#yesterday` para retornar quantos pássaros visitaram seu jardim ontem. As contagens de pássaros estão ordenadas por dia: o primeiro elemento é a contagem do dia mais antigo e o último é a contagem de hoje.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Calcule o número total de pássaros visitantes

Implemente o método `BirdCount#total` para retornar o número total de pássaros que visitaram seu jardim:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Calcule o número de dias movimentados

Alguns dias são mais movimentados que outros. Um dia movimentado é aquele em que cinco ou mais pássaros visitaram seu jardim.
Implemente o método `BirdCount#busy_days` para retornar o número de dias movimentados:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Verifique se houve um dia sem pássaros visitantes

Implemente o método `BirdCount#day_without_birds?`, que retorna `true` se houve um dia em que nenhum pássaro visitou o jardim; caso contrário, retorne `false`:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
