# Testes

## clojure.test

O Babashka já vem com o clojure.test incluído. Quando você estiver pronto para trabalhar em um exercício e tiver criado um arquivo para guardar sua solução (como `bob.clj`), você pode rodar os testes com `clojure.test/run-tests` [como descrito aqui](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests).


O REPL permite rodar código facilmente e receber feedback imediato, e também pode ser usado para rodar testes. Recomendamos usar o `rlwrap` para habilitar a edição de linha e o histórico de comandos com as setas para cima e para baixo. Para testar um exercício, entre no diretório dele e abra um socket REPL adicionando os diretórios `src` e `test` ao classpath:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

Primeiro, faça o `require` do namespace de teste:
``` clojure
=> (require 'bob-test)
nil
```

Depois, chame `run-tests` em `bob-test`:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

Para criar um script que roda os testes:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
