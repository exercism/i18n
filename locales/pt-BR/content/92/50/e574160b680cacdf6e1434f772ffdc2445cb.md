# Instruções

Neste exercício, você precisa traduzir algumas regras do clássico Pac-Man para funções em Gleam.

Você tem quatro regras para traduzir, todas relacionadas aos estados do jogo.

> Não se preocupe em como os argumentos são obtidos, apenas foque em combinar os argumentos para retornar o resultado esperado.

## 1. Defina se o Pac-Man come um fantasma

Defina a função `eat_ghost`, que recebe dois argumentos (_se o Pac-Man está com uma pílula de poder ativa_ e _se o Pac-Man está tocando um fantasma_) e retorna um valor Boolean se o Pac-Man consegue comer o fantasma. A função deve retornar `True` apenas se o Pac-Man estiver com uma pílula de poder ativa e estiver tocando um fantasma.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Defina se o Pac-Man marca pontos

Defina a função `score`, que recebe dois argumentos (_se o Pac-Man está tocando uma pílula de poder_ e _se o Pac-Man está tocando um ponto_) e retorna um valor Boolean se o Pac-Man marcou pontos. A função deve retornar `True` se o Pac-Man estiver tocando uma pílula de poder ou um ponto.

```gleam
score(True, True)
// -> True
```

## 3. Defina se o Pac-Man perde

Defina a função `lose`, que recebe dois argumentos (_se o Pac-Man está com uma pílula de poder ativa_ e _se o Pac-Man está tocando um fantasma_) e retorna um valor Boolean se o Pac-Man perde. A função deve retornar `True` se o Pac-Man estiver tocando um fantasma e não estiver com uma pílula de poder ativa.

```gleam
lose(False, True)
// -> True
```

## 4. Defina se o Pac-Man vence

Defina a função `win`, que recebe três argumentos (_se o Pac-Man comeu todos os pontos_, _se o Pac-Man está com uma pílula de poder ativa_ e _se o Pac-Man está tocando um fantasma_) e retorna um valor Boolean se o Pac-Man vence. A função deve retornar `True` se o Pac-Man comeu todos os pontos e não perdeu, de acordo com os argumentos definidos na parte 3.

```gleam
win(False, True, False)
// -> False
```
