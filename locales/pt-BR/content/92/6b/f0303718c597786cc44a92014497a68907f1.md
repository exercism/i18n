# Dicas

## 1. Verificar se o comando é válido

- Use a expressão [test][regex-test] para retornar um booleano.
- Lembre-se de que podemos usar o argumento [flags][flags] para recursos adicionais, como a insensibilidade a maiúsculas e minúsculas.

## 2. Remover emojis criptografados

- Graças à criptografia comum de cada emoji, podemos usar `[0-9]` para procurar qualquer dígito depois da palavra `emoji`.
- O caractere `+` corresponde a um ou mais itens consecutivos.
- Use o método [gsub][regex-gsub] para substituir cada emoji por uma string vazia.

## 3. Verificar se o número de telefone é válido

- Este [artigo][phone-validation] explica muito bem diferentes formas de validar um número de telefone.
- Use o filtro `test` para verificar se o número de telefone é válido ou não.
- Retorne a resposta final com uma expressão `if-then-else`.

## 4. Obter o link do site

- Estamos buscando palavras unidas por um ou mais pontos `.`.
- O filtro [match][regex-match] com a flag `g` pode ser usado.
- O filtro [scan][regex-scan] pode ser mais fácil de usar.

## 5. Cumprimentar o usuário

- Usar [grupos de captura nomeados][named-capture] é conveniente para reutilizar o texto correspondente.
- O filtro [capture][regex-capture] é útil para se referir ao grupo nomeado.

## 6. Análise bem simples de CSV

- Aqui, queremos usar [split][regex-split] porque conhecemos o delimitador.
- O padrão é "vírgula seguida de zero ou mais espaços em branco".
- Temos que usar o filtro `split` **de aridade 2**; não há flags que precisem ser especificadas.
