# Instruções

Um novo clube de poesia abriu na cidade, e você está pensando em ir.
Como já houve incidentes no passado, o clube tem uma política de entrada bem específica que você vai precisar dominar antes de tentar entrar.

Há duas portas no clube de poesia, e as duas têm guardas.
Para conseguir entrar, você vai precisar descobrir a senha do dia:

## 1. Divida uma string em linhas individuais

A primeira coisa que você precisa fazer é dividir o poema em linhas individuais.
O guarda vai recitar um poema, e você vai ter que dividi-lo em linhas.

Implemente a função `splitOnNewlines`, que recebe uma string e a divide em um array de strings, usando o caractere de nova linha como delimitador.
A função deve retornar um array de strings, em que cada string é uma linha do poema.

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. Porta da frente

1. O guarda vai recitar um poema
2. Você vai ter que dividir o poema em linhas individuais.
3. Você vai ter que pegar a primeira letra de cada linha.
   - Se a linha estiver vazia, você deve usar `_` no lugar.
4. Você vai ter que juntar as letras, que vão formar uma palavra.

Por exemplo, um dos escritores favoritos deles é Michael Lockwood, que escreveu o seguinte poema _acróstico_, o que significa que a primeira letra de cada frase forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recitar o poema, você vai dividi-lo em linhas individuais e responder com as primeiras letras de cada linha, ou seja, `["S", "H", "I", "R", "E"]`.

O guarda então vai te dar a palavra formada pelo array de letras que você respondeu, para você colocá-la na forma de palavra com letras maiúsculas.
Por fim, a senha que você retorna é `"SHIRE"`, e você vai conseguir entrar.

Implemente a função `frontDoorPassword`, que recebe uma string que representa o poema.
A função deve retornar a senha que você daria ao guarda.

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. Porta dos fundos

No fundo do clube você vai encontrar os poetas mais renomados, que é tipo a área VIP.
Como isso não é para todo mundo, o processo da porta dos fundos é um pouco mais complicado.

1. O guarda vai recitar um poema.
2. Você vai ter que dividir o poema em linhas.
3. Você vai ter que pegar a última letra de cada linha.
   - Às vezes a linha vai ter espaços no final, então você vai precisar removê-los.
4. Você vai ter que juntar as letras e depois adicionar `", please"` ao final da palavra formada pelas letras.

Por exemplo, o poema mencionado antes também é _telestich_, o que significa que a última letra de cada frase forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recitar o poema, você vai dividi-lo em linhas individuais, remover os espaços no final e responder com as primeiras letras de cada linha, ou seja, `["h", "o", "r", "s", "e"]`.

O guarda então vai te dar a palavra formada pelo array de letras que você respondeu, para você colocá-la na forma de palavra com letras maiúsculas e acrescentar `", please"`.
Por fim, a senha que você retorna é `"horse, please"`, e você vai conseguir entrar.

Implemente a função `backDoorPassword`, que recebe uma string que representa o poema.
A função deve retornar a senha que você daria ao guarda.

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. Sala secreta

Dentro da sala dos fundos do clube há outra porta que leva à sala secreta, onde só os poetas mais importantes podem entrar.

1. O guarda vai recitar um poema.
2. Você vai ter que dividir o poema em linhas.
3. Você vai ter que pegar a i<sup>ésima</sup> letra da i<sup>ésima</sup> linha. 
4. Você vai ter que juntar as letras e depois adicionar `"!"` ao final da palavra formada pelas letras.
5. Você vai ter que colocar a palavra em letras maiúsculas.

Por exemplo, uma versão modificada do poema mencionado antes se encaixa nesse padrão:

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

Quando o guarda recitar o poema, você vai dividi-lo em linhas individuais, remover os espaços no final e responder com as letras i<sup>ésimas</sup> de cada linha, ou seja, ["S", "u", "p", "e", "r"].

O guarda então vai te dar a palavra formada pelo array de letras que você respondeu, para você colocá-la em letras maiúsculas e acrescentar `"!"`.
Por fim, a senha que você retorna é `SUPER!`, e você vai conseguir entrar.

Implemente a função `secretRoomPassword`, que recebe uma string que representa o poema.
A função deve retornar a senha que você daria ao guarda.

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
