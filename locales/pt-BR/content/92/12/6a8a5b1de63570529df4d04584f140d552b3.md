# Instruções complementares

## O código inicial

`src/TreeBuilding.hs` já contém uma solução que funciona e passa em todos os testes.
Ela é lenta e difícil de ler; sua tarefa é melhorá-la sem quebrar os testes.

`buildTree` retorna `Nothing` quando os registros não formam uma árvore válida.

## Mudar a representação

Os testes nunca usam os construtores de `Tree` diretamente.
Em vez disso, eles constroem as árvores esperadas com a função

```haskell
node :: Int -> [Tree] -> Tree
```

em que `node i children` é o nó com id `i` e os filhos dados, em ordem crescente de id.

Isso significa que você tem liberdade para mudar como `Tree` é representada, por exemplo para

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

desde que `Tree` ainda tenha instâncias de `Eq` e `Show` e `node` mantenha o seu significado.
Se você usar uma biblioteca como `containers`, lembre-se de adicioná-la às `dependencies` do `package.yaml`.
