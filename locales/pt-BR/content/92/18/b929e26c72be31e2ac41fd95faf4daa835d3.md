# Instruções

Você está de volta ao trabalho no sistema ORM (Object Relationship Mapping) apresentado em [exercise:csharp/object-relational-mapping]().

Nossa análise de uso do ORM mostra que 95% das transações são executadas dentro de um único método que as chama, e foi decidido que seria mais adequado ter um único método do ORM que abrisse, gravasse e confirmasse uma transação.

O banco de dados tem os seguintes métodos de instância:

- `Database.BeginTransaction()` inicia uma transação no banco de dados.
- `Database.Write(string data)` grava dados no banco de dados dentro da transação. Se receber dados inválidos, uma exceção será lançada. Uma tentativa de chamar esse método sem que `BeginTransaction()` tenha sido chamado fará com que uma exceção seja lançada. Se for bem-sucedido, o estado interno do banco de dados mudará para `DataWritten`.
- `Database.EndTransaction()` confirma a transação no banco de dados. Pode lançar uma exceção se não conseguir fechar a transação ou se `Database.BeginTransaction()` não tiver sido chamado.
- Uma chamada a `Database.Dispose()` limpará o banco de dados se uma exceção for lançada durante uma transação. Isso mudará o estado do banco de dados para `Closed`.

## 1. Grave no banco de dados

Implemente o método `Orm.Write()` para iniciar uma transação no banco de dados, gravar os dados recebidos e confirmar a transação. Todas as exceções, incluindo `InvalidOperationException`, devem poder chegar até quem chamou, sem registro em log nem qualquer outra intervenção.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. Grave no banco de dados e retorne a quem chamou uma indicação de sucesso da gravação

Já se passaram alguns meses desde que `Orm.Write()` foi introduzido e há divisão na equipe. Muitos desenvolvedores gostariam que a _ORM_ tratasse os erros quando exceções são lançadas e simplesmente retornasse uma indicação de sucesso para quem chamou.

Implemente o método `Orm.WriteSafely()` para iniciar uma transação no banco de dados, gravar os dados recebidos e confirmar a transação (como acima). Ele deve retornar `true` se a _gravação_ foi bem-sucedida e `false` caso contrário. Não tente registrar a exceção em log.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
