# Instruções

Você está no posto de rádio do litoral, monitorando o falatório do canal:
as mensagens chegam pelo fio, você as registra e envia as respostas
de volta. Cinco palavrinhas dão conta do trabalho de um turno.

Os testes passam a você entradas `<string-reader>` (o tráfego de entrada)
e usam `<string-writer>` para a saída, mas cada palavra aqui
funciona da mesma forma com um `<file-reader>` real ou um socket.

## 1. Ouça tudo até o fim

Defina `hear-out` para drenar um fluxo de entrada em uma única string.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. Conte as mensagens

Defina `count-messages` para ler cada linha de um fluxo de entrada
e retornar quantas havia.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. Ecoe a última chamada

Defina `echo-back` para ler cada linha e retornar a **última
em letras maiúsculas**, a resposta padrão de rádio do tipo "você disse X".

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. Transmita uma mensagem

Defina `broadcast` para escrever uma mensagem em um writer informado e
liberar o fluxo para que ela saia imediatamente. Não retorna nada.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. Capture a saída de uma quotation

Defina `capture` para executar uma quotation com um string-writer novo
como a saída ambiente e retornar tudo o que a quotation
imprimiu. A quotation não recebe nenhum argumento: ela apenas
escreve no fluxo ambiente, como de costume.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
