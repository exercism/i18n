# O tipo Boolean

Em Cairo, o tipo Boolean é essencial para operações lógicas e instruções condicionais. Os Booleanos em Cairo ocupam o tamanho de um `felt252`, o que garante um uso eficiente de espaço e mantém a simplicidade da lógica de verdadeiro/falso.

O tipo Boolean em Cairo é especificado com a palavra-chave `bool`. Isso permite declarar e manipular variáveis booleanas na linguagem. Veja o exemplo a seguir:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

Neste exemplo, duas variáveis booleanas são declaradas. A variável `t` recebe o valor `true` e é declarada implicitamente como booleana, enquanto a variável `f` tem a anotação explícita do tipo `bool` e recebe o valor `false`.

Um detalhe importante: ao declarar uma variável booleana em Cairo, é obrigatório usar os literais `true` ou `false` como valor. Ou seja, literais inteiros, como `0` ou `1`, não podem substituir `false` ou `true`. A aplicação rígida dessa regra garante a segurança de tipos e evita possíveis erros de lógica no desenvolvimento de contratos inteligentes.

## Operadores booleanos em Cairo

- `||` (OU lógico): retorna `true` se pelo menos um dos operandos for `true`.
- `&&` (E lógico): retorna `true` se os dois operandos forem `true`.
- `!` (NÃO lógico): retorna o valor booleano oposto ao do operando.

## Código de exemplo

O trecho de código a seguir mostra como usar tipos booleanos em Cairo. Ele mostra a declaração de variáveis booleanas, a atribuição de expressões booleanas e o uso de asserções para verificar se a lógica booleana está correta:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
