# Testes

Para rodar os testes, execute o comando `v test .` de dentro do diretório do exercício.

Se você quiser ver todos os testes que foram executados, junto com estatísticas de velocidade, use `v -stats test .`

Para mais informações sobre testes em V, consulte [a documentação](https://github.com/vlang/v/blob/master/doc/docs.md#testing).
