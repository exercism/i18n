# Instruções

Neste exercício, você vai ajudar a gerenciar as operações diárias de uma pequena padaria usando as estruturas de fluxo de controle de Cairo.

## 1. Calcular o total do pedido

Implemente `calculate_total`, que calcula o custo de um pedido com base no tipo de doce e na quantidade:

- Croissant: 3 moedas cada
- Muffin: 2 moedas cada
- Cookie: 1 moeda cada

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Aplicar descontos por volume

Implemente `apply_discount`, que aplica descontos com base no total do pedido.
Aplique o desconto percentual ao total e depois arredonde para baixo até a moeda inteira mais próxima (floor).

- Pedidos ≥ 20 moedas: 10% de desconto
- Pedidos ≥ 10 moedas: 5% de desconto
- Pedidos < 10 moedas: sem desconto

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Criar o cronograma de fornadas

Implemente `baking_schedule`, que cria um plano diário de fornadas.
A padaria assa em lotes de 5 pedidos por hora:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Use as estruturas de fluxo de controle adequadas (`if`/`else`, `loop`) para resolver cada problema com eficiência.
