# Instruções

Neste exercício, você vai escrever um código para ajudar você a se preparar para comprar um veículo.

Você tem três tarefas: uma para determinar se você vai precisar de carteira de motorista, uma para ajudar você a escolher entre dois veículos e uma para estimar o preço aceitável de um veículo usado.

## 1. Determine se você vai precisar de carteira de motorista

Alguns tipos de veículo exigem carteira de motorista para serem conduzidos.
Considere que apenas os tipos `car` e `truck` exigem carteira de motorista; todo o resto pode ser conduzido sem carteira.

Implemente a função `needs_license(kind)`, que recebe o tipo de veículo e retorna um Boolean indicando se você precisa de carteira de motorista para aquele tipo de veículo.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. Escolha entre dois possíveis veículos para comprar

Você avalia as opções de veículos disponíveis.
Você consegue reduzir a duas opções, mas precisa de ajuda para tomar a decisão final.
Para isso, implemente a função `choose_vehicle(option1, option2)`, que recebe dois veículos como argumentos e retorna uma decisão que é simplesmente a opção que vem primeiro na ordem alfabética.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. Calcule uma estimativa para o preço de um veículo usado

Agora que você tomou sua decisão, você quer ter certeza de conseguir um preço justo na concessionária.
Como você está interessado em comprar um veículo usado, o preço depende da idade do veículo.
Para uma estimativa aproximada, considere que, se o veículo tiver menos de 3 anos, ele custa 80% do preço original que tinha quando era zero-quilômetro.
Se tiver mais de 10 anos, ele custa 50%.
Se o veículo tiver pelo menos 3 anos, mas não mais de 10 anos, ele custa 70% do preço original.

Implemente a função `calculate_resale_price(original_price, age)`.
Ela recebe o preço original e a idade do veículo como argumentos e retorna o preço estimado na concessionária.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
