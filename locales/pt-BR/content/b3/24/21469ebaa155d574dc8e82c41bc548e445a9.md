# Sobre

Uma **word** é o nome que o Factor dá para uma função. Você conheceu a pilha de dados e as shuffle words em `basics`; aqui você define suas próprias words, que calculam a partir de suas entradas.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

Uma definição é `:`, um stack effect, o corpo, e depois `;`. Os nomes dentro de `( … -- … )` são para quem lê; o que o compilador verifica é o *número* de entradas e saídas. Uma incompatibilidade é um erro de compilação, o que detecta uma classe de bugs que seriam erros em tempo de execução numa linguagem de tipagem dinâmica sem esse tipo de declaração.

As words de aritmética de inteiros `+`, `-` e `*` vêm do vocabulário `math`, e cada uma consome dois números do topo da pilha. O topo da pilha é o operando da direita, então `8 3 -` calcula `8 - 3`.

`CONSTANT:` define um nome para um valor fixo; chamar o nome empilha o valor, exatamente como qualquer outra word. Coloque as constantes no topo do arquivo, antes de qualquer word que as use.

O corpo de uma word pode chamar qualquer word que já esteja no escopo: definições anteriores no mesmo arquivo, words de vocabulários importados e as constantes que você declarou. Compor words pequenas, com um único propósito, é a forma normal de construir um programa.

Por convenção:

- Words e constantes usam `lowercase-kebab-case`.
- Predicados terminam em `?` e produzem um Boolean (`even?`, `empty?`).
- Words que modificam sua entrada costumam compartilhar o nome com a versão que não modifica, distinguidas apenas pelo contexto.
