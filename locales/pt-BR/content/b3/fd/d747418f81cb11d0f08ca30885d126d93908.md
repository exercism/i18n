# Apêndice das instruções

## Como este exercício está estruturado em Python

Adicionamos um descritor de semana extra (`fifth`) para o quinto dia da semana do mês, caso ele exista.  
Se não houver um quinto dia da semana em um mês, você deve lançar uma exceção.

## Personalizar e lançar exceções

Às vezes é necessário tanto [personalizar](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) quanto [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) exceções no seu código. Quando você fizer isso, sempre inclua uma **mensagem de erro significativa** que indique qual é a origem do erro. Isso deixa seu código mais legível e ajuda bastante a depurar.

Exceções personalizadas podem ser criadas por meio de novas classes de exceção (veja [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) para mais detalhes.) que normalmente são subclasses de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

Para situações em que você sabe que a origem do erro será derivada de um determinado tipo de exceção, você pode escolher herdar de um dos [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) sob a classe _Exception_. Ao lançar o erro, você ainda deve incluir uma mensagem significativa.

Este exercício em particular exige que você crie uma _exceção personalizada_ para ser [lançada](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/"disparada" quando sua função `meetup()` receber uma combinação inválida de nome de dia da semana e número. Os testes só passarão se você personalizar as exceções adequadas, lançá-las com `raise` e incluir mensagens de erro adequadas.

Para personalizar uma `built-in exception`, crie uma `class` que herde dessa exceção. Ao lançar a exceção personalizada com uma mensagem, escreva a mensagem como argumento do tipo `exception`:

```python
# subclassing the built-in ValueError to create MeetupDayException
class MeetupDayException(ValueError):
    """Exception raised when the Meetup weekday and count do not result in a valid date.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a MeetupDayException
raise MeetupDayException("That day does not exist.")
```
