# Instruções

Refatore um parser de Markdown.

O exercício Markdown é um exercício de refatoração.
Há um código que faz o parsing de uma string com [sintaxe Markdown][markdown] e retorna o HTML associado a essa string.
Mesmo que esse código esteja escrito de forma confusa e seja difícil de acompanhar, de alguma forma ele funciona e todos os testes estão passando!
Seu desafio é reescrever esse código para deixá-lo mais fácil de ler e manter, garantindo ao mesmo tempo que todos os testes continuem passando.

Seria útil se você anotasse o que fez na sua refatoração em comentários, para que quem for revisar possa ver, mas isso não é estritamente necessário.
O mais importante é deixar o código melhor!

[markdown]: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
