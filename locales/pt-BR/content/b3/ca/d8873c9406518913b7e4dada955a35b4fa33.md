# Introdução

Em Common Lisp, como em outras linguagens, um array, ou _vetor_, é um conjunto de elementos acessados por índices inteiros.
Os tipos dos elementos podem ser heterogêneos.
O array pode ser multidimensional (não apenas unidimensional).

## Criação

`make-array` permite criar arrays.
Tem muitas opções, mas suas formas mais simples permitem criar arrays N-dimensionais com todos os elementos inicializados com um único valor, ou com o array inicializado com os valores de outra sequência (como uma lista).
Seu primeiro argumento é uma lista com o tamanho de cada dimensão.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Repare que os arrays N-dimensionais são impressos com o número de dimensões.)

Arrays também podem ser criados usando o mesmo formato em que são impressos:

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## Acessando elementos

Para acessar elementos de um vetor, use `aref`; os índices começam em zero.
O número de índices fornecidos precisa ser igual ao número de dimensões do array.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
