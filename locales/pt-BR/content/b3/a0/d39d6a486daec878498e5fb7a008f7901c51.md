# Sobre

O escopo de um valor está relacionado a onde, no programa, esse valor pode ser acessado.

## Os quatro tipos de escopo: bloco; função; protótipo de função; arquivo

### Escopo de bloco

Um valor com escopo de bloco só pode ser acessado dentro do bloco onde ele é definido.
Para saber mais sobre blocos, veja o [conceito de bloco](../blocks/introduction.md#Introduction).

### Escopo de função

O escopo de função é um tipo especial de escopo que se aplica a rótulos usados com instruções `goto`.
Dois rótulos com o mesmo nome não podem ser usados na mesma função, mesmo que os rótulos sejam definidos em blocos separados dentro da função.

### Escopo de protótipo de função

O escopo de protótipo de função é outro tipo especial de escopo que se aplica apenas aos parâmetros nomeados dentro do protótipo (também chamado de declaração, lembrando que nem toda declaração é um protótipo).
O nome de um parâmetro geralmente é opcional em uma declaração de função.
O escopo de um nome só é relevante dentro da declaração.
No exemplo a seguir, o identificador `len` é definido e depois referenciado mais adiante na declaração da função.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Repare que, dentro de uma declaração, os nomes precisam corresponder quando se faz referência à mesma variável.
Se `my_func` fosse declarada como `void my_func(int len, int numbers[length]);`, seria gerado um erro de compilação mais ou menos assim

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

Uma definição de função não precisa usar o mesmo nome para um parâmetro que foi usado na declaração da função.
No exemplo acima, `len` foi usado na declaração e `length` foi usado na definição, demonstrando assim que o escopo do identificador `len` estava apenas dentro da declaração da função.

### Escopo de arquivo

Um valor com escopo de arquivo pode ser acessado de qualquer lugar do arquivo.
Todo valor desse tipo é definido fora de uma função.
