# Realce de sintaxe estático

O realce de sintaxe estático é o realce de código que você _não_ pode alterar.
Isso inclui trechos de código, iterações e muito mais.

```exercism/note
O editor online _não_ usa realce de sintaxe estático, pois você pode alterar o código na hora.
Se você quiser saber mais sobre como lidamos com realce de sintaxe no editor online, consulte a [documentação de realce de sintaxe dinâmico](/docs/building/tracks/new/syntax-highlighting/dynamic).
```

## Implementação

O realce de sintaxe estático é feito com a [biblioteca highlightjs](https://highlightjs.org/).

Ao adicionar suporte para a linguagem da sua trilha, há três opções:

1. A linguagem tem suporte _nativo_ do highlightjs (ou seja, está listada como uma [linguagem suportada](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)).
   Nesse caso, siga para a seção [Configurar a trilha](#configuring-track).
2. A linguagem tem suporte por meio de um plugin já existente do highlightjs.
   Nesse caso, siga para a seção [Usar um plugin existente](#using-an-existing-plugin).
3. A linguagem _não_ tem suporte.
   Agora há três opções:
   1. Escrever um plugin do highlightjs do zero, como descrito na seção [Criar um novo plugin](#create-a-new-plugin).
   2. A sintaxe da sua linguagem se parece (muito) com a sintaxe de outra linguagem (por exemplo, a sintaxe de Unison se parece com a de Haskell). Nesse caso, você pode considerar usar o realce de sintaxe dessa linguagem para a sua.
      Veja a seção [Configurar a trilha](#configuring-track) para mais informações.
   3. Não ter realce de sintaxe estático.

### Configurar a trilha

Para habilitar o suporte do highlightjs para a linguagem da sua trilha, você precisa modificar o [arquivo config.json](/docs/building/tracks/config-json) da trilha.
No arquivo `config.json`, adicione/defina a chave `online_editor.highlightjs_language` com o identificador de linguagem apropriado do highlightjs (que pode ser encontrado na documentação).

#### Exemplo

```json
{
  "online_editor": {
    "highlightjs_language": "csharp"
  }
}
```

### Usar um plugin existente

Para usar um plugin existente, ele precisa estar publicado no [NPM](https://www.npmjs.com/).
Se o plugin não estiver publicado no NPM, você pode:

1. Perguntar ao autor do plugin se ele quer publicá-lo no NPM.
2. Fazer um fork do repositório e publicá-lo por conta própria.
3. Pedir que nós (o Exercism) façamos um fork do repositório e o publiquemos.
   Para isso, abra um tópico [no fórum](https://forum.exercism.org/c/exercism/building-exercism/125) pedindo isso.

O próximo passo é [habilitar o plugin](#enable-plugin).

### Habilitar o plugin

Para habilitar um plugin (que precisa estar publicado no [NPM](https://www.npmjs.com/)), abra um tópico [no fórum](https://forum.exercism.org/c/exercism/building-exercism/125) pedindo que adicionemos suporte para o plugin no site.
Nós (o Exercism) então criaremos um Pull Request que adiciona o plugin ao site.
Depois que o PR for mesclado, você pode habilitar o suporte do highlightjs seguindo as instruções da seção [Configurar a trilha](#configuring-track).

### Criar um novo plugin

Se você quiser criar um plugin, há duas opções de hospedagem:

1. Criar um repositório na sua conta pessoal e publicá-lo por conta própria.
2. Pedir que nós (o Exercism) criemos um repositório e o publiquemos.
   Para isso, abra um tópico [no fórum](https://forum.exercism.org/c/exercism/building-exercism/125) pedindo isso.

Depois de ter um repositório, siga as [instruções de contribuição de linguagem](https://highlightjs.readthedocs.io/en/latest/language-contribution.html) para implementar o plugin.

Depois, você precisa publicar o plugin no [NPM](https://www.npmjs.com/).
O próximo passo é [habilitar o plugin](#enable-plugin).

### Usar uma linguagem diferente

A sintaxe da sua linguagem se parece (muito) com a sintaxe de outra linguagem. Nesse caso, você pode considerar usar o realce de sintaxe dessa linguagem para a sua.
Para isso, configure a trilha para usar o identificador de linguagem do highlightjs da outra linguagem.
Veja a seção [Configurar a trilha](#configuring-track) para mais informações.
