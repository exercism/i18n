# Sobre

Uma `List` é muito parecida com um [`Array`][array]. Mas existem diferenças importantes que você não vai querer ignorar:

1. Uma lista não pode ser indexada com colchetes, ou seja, `[0]`.
2. Uma lista não pode ser inicializada.
3. Não existem compreensões de listas.
4. Uma lista pode modificar elementos livremente enquanto itera sobre eles.

`List` é membro do pacote `haxe.ds`, então sempre que você quiser usar listas, precisa importar o pacote:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
