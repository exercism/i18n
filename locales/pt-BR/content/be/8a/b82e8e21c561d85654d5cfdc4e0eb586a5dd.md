## 1. Calcule a soma dos números na máquina caça-níqueis

- Você pode usar [`implode`][ref-implode] para combinar os dígitos.
  O `implode` vai converter implicitamente os dígitos do array em strings e retornar uma string.
- Para somar os números, veja o conceito de [operações aritméticas][ref-arithmetic-ops].
  Os operadores aritméticos vão converter implicitamente strings em inteiros ou números de ponto flutuante.

## 2. Determine se um número é um palíndromo

- Esta tarefa pode ser resolvida comparando o número dado com a sua versão invertida.
  Para isso, primeiro você precisa inverter o número dado.
  Depois, retorne o resultado da comparação entre as duas versões.
- Você pode usar [`strrev`][ref-strrev] para obter o número invertido.
  O `strrev` vai converter implicitamente o número em uma string e retornar uma string.
- Por fim, você pode [comparar][ref-comparison-ops] o número dado com a string invertida.
  Ao escrever a condição para isso, use a [comparação][ref-comparison-ops] que faz conversão de tipos.
  O PHP vai converter a string invertida em um número para essa comparação.
- O resultado da comparação é um `bool`, que é o tipo a ser retornado.

## 3. Gere uma mensagem de erro para entradas de usuário inválidas

- Você pode usar [condicionais][ref-if-statement] para verificar as diferentes condições.
- Primeiro, você deve cobrir o caso em que o valor não contém nenhum caractere.
- Em seguida, trate o caso em que a entrada não é um número nem `0`.
  As regras de conversão de tipos dos [operadores de comparação][ref-comparison-ops] jogam contra você neste caso.
  Elas fazem o PHP comparar strings em alguns casos, e isso dá resultados errados.
  Use a conversão explícita para `int` que você aprendeu na introdução.
  Assim você pode confiar nos [operadores de comparação][ref-comparison-ops] para um número maior que `0`.
