# Sobre

Disponíveis a partir do `PHP 8.0.0`, as **Declarações de Tipo União** aceitam valores de vários tipos diferentes, em vez de um único tipo. As definições de tipo união são feitas com a barra vertical (`|`) para separar os tipos.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Nuances

- Os tipos `null` podem ser declarados como _nullable_ usando `?Type` ou `Type1|Type2|null`.
- tipos duplicados ou redundantes declarados resultam em um erro em tempo de compilação.
- `void` não pode ser usado como parte de uma declaração de tipo união.
