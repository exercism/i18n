# https://www.php.net/manual/en/language.basic-syntax.phptags.php"Operador de resolução de escopo

O operador de resolução de escopo (`::`) permite referenciar uma classe para acessar suas constantes, propriedades estáticas ou métodos estáticos.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Usando `self` e `static` com o operador de resolução de escopo

Pode ser necessário que um objeto referencie o próprio escopo. Para facilitar isso, a palavra-chave `self` permite que uma classe referencie o próprio escopo. Usar a palavra-chave `self` desacopla a classe do próprio nome, o que facilita a manutenção do código ao longo do tempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

No entanto, `self` está ligado lexicograficamente à classe em que aparece.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

Avaliar `MyOtherClass::getMyValue` ainda resulta em `1`, e não em `99`. Para contornar isso, use a palavra-chave `static` com o operador de resolução de escopo para vincular tardiamente a referência à classe descendente atual.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Usando `parent` com o operador de resolução de escopo

Pode haver a necessidade de referenciar especificamente uma constante, propriedade ou método disponível no escopo da classe pai:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

Na programação orientada a objetos, o mais comum é usar `parent` para chamar o construtor da classe pai quando um objeto está sendo instanciado:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Ressalvas

### Visibilidade de constantes, propriedades e métodos

O operador de resolução de escopo ainda segue as regras definidas pelos modificadores de visibilidade `public`, `private` e `protected`.
