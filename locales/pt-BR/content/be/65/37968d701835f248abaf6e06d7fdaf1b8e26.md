# Introdução

No Haxe, um tipo abstrato é um tipo que é um tipo diferente em tempo de execução. É um recurso de tempo de compilação que define tipos "sobre" tipos concretos para modificar ou ampliar o comportamento deles:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Aqui estamos declarando o tipo `AbstractInt` com a palavra-chave `abstract`. A sintaxe dele é muito parecida com a de `class`. E, assim como as classes, os tipos abstratos podem ter métodos. Eles também podem ser instanciados e usados como as classes:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
