# Sobre

Uma *expressão regular* (regex) é um padrão pequeno que descreve o formato de um texto. As ferramentas de regex do Factor ficam no vocabulário [`regexp`][regexp], e um padrão é escrito como um literal entre `R/ ` e `/`.

A maioria dos caracteres de um padrão corresponde a si mesma. O poder expressivo vem das classes de caracteres e dos quantificadores:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

Assim, `R/ [A-Z]{2}-\d{4}/` corresponde a "duas letras maiúsculas, um hífen e quatro dígitos".

## Correspondência com a string inteira vs. busca

`matches?` só tem sucesso quando a string *inteira* se encaixa no padrão. As outras palavras buscam *dentro* de uma string:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## Slices

`first-match` e `re-split` retornam objetos `slice`, que são visões leves sobre a string original em vez de strings novas. Converta um slice com `>string` quando você precisar de uma string isolada (por exemplo, para comparar com um literal de string). `all-matching-subseqs` já retorna strings.

## Substituição

`re-replace` substitui cada ocorrência por uma string de substituição e retorna o resultado:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## Montar um padrão em tempo de execução

`R/ /` é analisado quando o arquivo é carregado. Para montar um padrão a partir de uma string calculada em tempo de execução, use `<regexp>`:

```
<regexp> ( string -- regexp )
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
