# Instalação

Cairo pode ser instalado simplesmente baixando o Scarb. O Scarb reúne o compilador Cairo e o servidor de linguagem Cairo em um único pacote fácil de instalar, para que você comece a escrever código Cairo imediatamente. O Scarb também é o gerenciador de pacotes do Cairo.

Para ver as instruções de instalação recomendadas para a sua plataforma, acesse [o site oficial do Cairo](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/).

Por sistema operacional:

- Linux/MacOS
    1. Instale o [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. Instale o [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. Verifique a instalação em uma nova sessão de terminal `scarb --version`
- Windows
    1. Instale o [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. Verifique a instalação em uma nova sessão de terminal `scarb --version`

Não basta ter a toolchain instalada! O suporte de IDE é um enorme ganho de produtividade que a maioria de quem programa já espera.
Se você usa o Visual Studio Code, recomendamos instalar a [extensão do Cairo](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1), que oferece realce de sintaxe, autocompletar de código e outros recursos úteis!
