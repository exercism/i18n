# Instruções

Neste exercício, você vai trabalhar com contas poupança. A cada ano, o saldo de uma conta poupança é atualizado com base na taxa de juros. A taxa de juros que o banco oferece depende da quantidade de dinheiro na conta (o saldo dela):

- 0,5% para um saldo não negativo menor que `1000` dólares.
- 1,621% para um saldo positivo maior ou igual a `1000` dólares e menor que `5000` dólares.
- 2,475% para um saldo positivo maior ou igual a `5000` dólares.
- 3,213% para um saldo negativo (resulta em juros negativos).

Você tem três tarefas, e cada uma delas envolve o saldo e a taxa de juros.

## 1. Calcule a taxa de juros

Implemente o método `SavingsAccount.interest_rate` para calcular a taxa de juros com base no saldo informado:

```ruby
SavingsAccount.interest_rate(200.75)
#=> 0.5
```

Repare que o valor retornado é uma instância de `Float`.

## 2. Calcule a atualização anual do saldo

Implemente o método `SavingsAccount.annual_balance_update` para calcular a atualização anual do saldo, levando em conta a taxa de juros:

```ruby
SavingsAccount.annual_balance_update(200.75)
#=> 201.75375
```

Repare que o valor retornado é uma instância de `Float`.

## 3. Calcule os anos antes de atingir o saldo desejado

Implemente o método `SavingsAccount.years_before_desired_balance` para calcular o número mínimo de anos necessários para atingir o saldo desejado:

```ruby
SavingsAccount.years_before_desired_balance(200.75, 214.88)
#=> 14
```

Repare que o valor retornado é uma instância de `Integer`.
