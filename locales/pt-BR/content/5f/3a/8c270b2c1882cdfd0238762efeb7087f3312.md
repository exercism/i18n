# About

C# tem vários operadores para fazer manipulação bit a bit:

- [`&`][and-operator]: AND bit a bit
- [`|`][or-operator]: OR bit a bit
- [`~`][complement-operator]: COMPLEMENTO bit a bit
- [`<<`][left-shift-operator]: deslocamento bit a bit para a esquerda
- [`>>`][right-shift-operator]: deslocamento bit a bit para a direita
