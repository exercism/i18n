# Sobre

[Operadores ternários][ternary-operators] permitem que condições if sejam definidas em expressões, em vez de blocos de instruções. Isso ecoa abordagens de programação funcional e muitas vezes pode deixar o código mais expressivo e menos propenso a erros.

O operador ternário combina 3 expressões: uma condição seguida de uma expressão a ser avaliada e retornada se a condição for verdadeira (a parte `if`, introduzida por `?`) e uma expressão a ser avaliada e retornada se a condição for falsa (a parte `else`, introduzida por `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
