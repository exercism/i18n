# Testes

## Escrevendo o código

Escreva seu código em `src/lib.cairo`.
Os exercícios vêm com um arquivo stub em `src/lib.cairo` que mostra as assinaturas do código que você vai precisar escrever.

Na maioria dos exercícios, o melhor é escrever todo o seu código no arquivo `src/lib.cairo`.
Se você quiser dividir a sua solução em vários arquivos, consulte o [capítulo sobre módulos][chapter-modules] do The Cairo Book.

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## Rodando os testes

Para rodar os testes, primeiro você precisa mudar o diretório de trabalho para o diretório do exercício que quer testar:

```bash
cd path/to/exercise
```

E depois rodar o seguinte comando:

```bash
scarb cairo-test
```

Por padrão, só o primeiro teste fica habilitado.
Quando chegar a hora de passar no próximo teste, remova a flag `ignore` do próximo teste (`#[ignore]`).

Para rodar todos os testes, inclusive os ignorados, você pode remover a flag `ignore` de todos os testes ou simplesmente rodar:

```bash
scarb cairo-test --include-ignored
```

Fique à vontade para escrever o mínimo de código possível para fazer os testes passarem.
As falhas nos testes vão te guiar sobre o que escrever em seguida.

Como o Cairo verifica todo o código em tempo de compilação, pode acontecer de os seus testes não compilarem até você escrever o código necessário.
Até os testes marcados como `ignore` são verificados em tempo de compilação.
Você pode [comentar][comments] os testes que não compilam começando cada linha com `//`.
Depois, quando quiser trabalhar nesse teste, é só descomentar.
O Cairo também tem uma macro especial chamada `panic!()`, que você pode usar em trechos de código inacabados para fazer o seu programa compilar.

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
