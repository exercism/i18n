# Anexo às instruções

## Implementação

Este exercício exige que você chame uma função passada como argumento.
No Uiua, você pode fazer isso com [macros](https://www.uiua.org/tutorial/macros), que é como este exercício espera que você o resolva.

```exercism/note
Você percebe imediatamente que uma associação é uma macro por causa do sufixo `!`.
```
