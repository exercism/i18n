# Introdução

## Registros

Um registro é uma coleção de campos (que podem ser de tipos diferentes) que pertencem juntos. Para definir um registro, usa-se a palavra-chave `type`. Os campos de um registro são definidos entre os caracteres `{` e `}`, e cada campo tem um nome _e_ um tipo. Para criar um registro, especifique os nomes dos campos e atribua um valor a eles entre os caracteres `{` e `}`. Todos os campos precisam receber um valor na criação de um registro. Os valores dos campos de uma instância de registro podem ser acessados com notação de ponto.

Ao definir/criar um registro, cada campo deve estar em uma linha separada ou ser separado por pontos e vírgulas (`;`) quando estiver em uma única linha.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Como registros são imutáveis, depois que um registro é construído, os valores dos seus campos nunca podem mudar. Se você quiser alterar os valores de um registro, a palavra-chave `with` permite criar uma cópia de um registro existente, mas com novos valores para um ou mais campos.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Registros têm _igualdade estrutural_, o que significa que duas instâncias do mesmo registro com valores idênticos são equivalentes.

Além de poder usar a notação de ponto para acessar os campos de um registro, os registros também podem ser _desconstruídos_ em associações e em correspondência de padrões:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
