# Dicas

## 1. Verifique se a ação 'Ataque Rápido' é possível

- O operador lógico de negação (`!`) pode ser colocado antes de uma expressão para negar seu valor.
- Confira [este documento][logical-operators] sobre operadores lógicos.

## 2. Verifique se a ação 'Espionar' é possível

- As expressões lógicas são avaliadas da esquerda para a direita e testadas quanto a possíveis 'curto-circuitos'.
- Para entender bem o mecanismo da esquerda para a direita, dê uma olhada [neste artigo][operator-precedence].

## 3. Verifique se a ação 'Sinalizar ao Prisioneiro' é possível

- Operadores lógicos na ordem de sua precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Confira [este artigo][operator-precedence] sobre precedência de operadores.

## 4. Verifique se a ação 'Libertar o Prisioneiro' é possível

- `()` é o operador de maior precedência. Use-o para agrupar expressões lógicas.
