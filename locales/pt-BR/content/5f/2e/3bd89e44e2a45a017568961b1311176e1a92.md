# Instalação

## Linux

O Bash, por ser o shell do GNU, estará presente em qualquer sistema GNU/Linux.
BSD e outros derivados de UNIX provavelmente exigem que você mesmo faça a instalação.
Se você usa BSD, AIX ou uma distribuição Linux que não vem com o bash, consulte a documentação do seu sistema operacional sobre como instalar pacotes que não fazem parte do núcleo.

Na interface gráfica de sua preferência, procure um aplicativo chamado "Terminal": ele pode estar numa seção "Administrative/System Tools".

Para verificar a versão do Bash disponível, na linha de comando ou no terminal, rode:

    echo $BASH_VERSION

Se o seu shell for o `bash`, ele deve mostrar algo assim:

    4.4.19(1)-release

Você não precisa fazer mais nada: o bash já deve estar instalado e no seu PATH, já que é o seu shell atual.

Se o seu shell não for o bash, não há motivo para trocá-lo.
Você pode escrever e rodar scripts bash sem estar num shell bash.

Para verificar a versão do bash instalada, rode:

```plain
bash --version
```

Ele vai mostrar algo assim:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

Se não mostrar, é possível que o bash não esteja instalado.
Instale-o usando o gerenciador de pacotes da sua distribuição.

## Windows

No Windows 10, você pode instalar o [WSL](https://docs.microsoft.com/en-us/windows/wsl/about).
Isso instala uma distribuição Linux completa (bem, os componentes sem interface gráfica) que roda nativamente no Windows.

Como alternativa, você pode instalar:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* uma distribuição Linux completa em [uma máquina virtual](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)

## MacOS

No Apple OSX:

* abra o Finder,
* abra a pasta Aplicativos,
* abra a pasta Utilitários,
* por fim, abra o aplicativo `Terminal`.

Repare que a versão do bash instalada no MacOS é bem antiga, a 3.2.
Isso acontece porque (i) as versões mais novas do bash têm licença GPLv3 e (ii) a Apple não quer ser obrigada a cumprir os termos dessa licença.
Além disso, a Apple sinalizou que o bash vai sair do MacOS: o shell de login padrão foi recentemente [trocado de bash para zsh](https://support.apple.com/en-us/HT208050).

Para obter um bash atualizado no seu Mac:

1. instale o [Homebrew](https://brew.sh)
1. no Terminal, digite: `brew install bash`

Isso instala um bash atualizado em (eu acredito) `/usr/local/bin/bash` (para não sobrescrever o bash padrão do sistema, já que outras ferramentas podem depender de /bin/bash).

Se você quiser que o bash do Homebrew seja iniciado quando digitar `bash`, edite o seu arquivo ~/.bash_profile (ou ~/.profile) para colocar /usr/local/bin *antes* de /bin no PATH:

    PATH=/usr/local/bin:$PATH
