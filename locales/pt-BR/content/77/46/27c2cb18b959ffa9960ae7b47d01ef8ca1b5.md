# Dicas

## Geral

- O pacote [`roc-random`](https://github.com/kili-ilo/roc-random) está disponível com o alias `random` no app de teste.
  O stub importa `random.Random`.

- Um `Random.Generator(a)` descreve como gerar um valor do tipo `a`.

- Use `Random.list` para combinar sorteios e `Random.map` para transformar os resultados.

- `Random.step(state, generator)` retorna `{ value, state }`; carregue o estado atualizado entre os grupos simulados para não repetir a mesma amostra.
