# Apêndice das instruções

## Processo de IO

Diferente de outros exercícios, o `grep` exige interagir com o "mundo externo": ler arquivos, tratar erros do sistema e imprimir em `stdout`.

Em Lean, a interação com o sistema costuma ser feita na mônada [IO][io], que permite que efeitos colaterais ocorram em um ambiente contido, sem afetar o estado puro da maioria das outras funções.

## Leitura de argumentos

O Lean permite chamar um arquivo como script, seja diretamente como um script independente por meio de `lean --run`, seja com o uso do `lake`.

Um projeto Lean tem um único ponto de entrada, uma função chamada `main`, que recebe uma `List String` com todos os argumentos passados a ela.
Para simular a execução de `Grep.lean` como um executável, os argumentos são passados da mesma forma neste exercício.

## Leitura de arquivos

O Lean oferece [funções][files] para manipular arquivos na mônada `IO.FS`.
Por exemplo, `IO.FS.readFile` pode ser usado para ler o conteúdo de um arquivo em um determinado caminho, como uma `String`.

## Escrita da saída

Em vez de retornar um valor, este exercício exige que os resultados sejam escritos na saída padrão ou no erro padrão.
Existem [funções][console] no Lean para essa finalidade.

## Tratamento de erros do sistema

Diferente dos erros em `Except`, as exceções de `IO` são de fato exceções de tempo de execução.
Você pode usar `try`/`catch` para tratá-las:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
