# Instruções

Neste exercício, você está ajudando sua irmã mais nova a revisar a redação dela para a escola. O professor está buscando pontuação e gramática corretas e uma excelente escolha de palavras.

Você tem quatro tarefas para limpar e modificar strings.

## 1. Coloque o título da redação em maiúsculas

Toda boa redação precisa de um título bem formatado.
Implemente a função `capitalize_title(<title>)`, que recebe um título `str` como parâmetro e coloca a primeira letra de cada palavra em maiúscula.
Essa função deve retornar uma `str` em formato de título.


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. Verifique se cada frase termina com um ponto final

Você quer garantir que a pontuação da redação esteja perfeita.
Implemente a função `check_sentence_ending()`, que recebe `sentence` como parâmetro. Essa função deve retornar um `bool`.


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. Limpe o espaçamento

Para deixar a redação com aparência profissional, é preciso remover os espaços desnecessários.
Implemente a função `clean_up_spacing()`, que recebe `sentence` como parâmetro.
A função deve remover os espaços em branco extras no início e no fim da frase, retornando uma nova `str` com a frase atualizada.


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. Substitua palavras por um sinônimo

Para deixar a redação _ainda melhor_, você pode substituir alguns dos adjetivos por sinônimos.
Escreva a função `replace_word_choice()`, que recebe `sentence`, `old_word` e `new_word` como parâmetros.
Essa função deve substituir todas as ocorrências de `old_word` por `new_word` e retornar uma nova `str` com a frase atualizada.


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
