# Introdução

## Funções

Em Gleam, funções são definidas usando a sintaxe `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Essa função recebe dois argumentos, ambos do tipo `Int`, e retorna um valor do tipo `Int`. Não existe a palavra-chave `return` em Gleam: o valor da última expressão de uma função é sempre retornado implicitamente.

As anotações de tipo para argumentos e o tipo de retorno são opcionais, e o Gleam sempre verifica os tipos do seu código por completo. Normalmente, programadores de Gleam atribuem anotações de tipo às suas funções para maior clareza, mas você pode omiti-las se quiser.

```gleam
pub fn add(x, y) {
  x + y
}
```

Uma função pode ser chamada usando a sintaxe `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Variáveis

Em Gleam, variáveis são definidas usando a sintaxe `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Variáveis podem ser declaradas com anotações de tipo. Assim como os argumentos de função, essas anotações são opcionais, embora a maioria dos programadores de Gleam omita anotações de tipo para variáveis por brevidade.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Strings literais

Em Gleam, strings são escritas com aspas duplas.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Comentários de código

Comentários podem ser usados para deixar notas para outros desenvolvedores que leem o código-fonte. Em Gleam, comentários são linhas únicas precedidas por `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
