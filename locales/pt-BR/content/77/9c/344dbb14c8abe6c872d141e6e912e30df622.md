# Apêndice das instruções

## Dicas

Para completar este exercício, você precisa criar o tipo de dados `ForthState`
e implementar as seguintes funções:

- `emptyState` retorna um `ForthState` vazio.
- `evalText` avalia um Text de entrada e retorna o novo estado.
- `toList` retorna a pilha atual como uma lista, com o elemento no topo
da pilha sendo o elemento mais à direita (o último).

Você vai encontrar uma declaração de dados de exemplo e assinaturas de tipo já
prontas, mas cabe a você definir as funções e criar um tipo de dados,
newtype ou sinônimo de tipo que faça sentido.
