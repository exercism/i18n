# Instruções

Sua tarefa é converter um número entre 1 e 31 em uma sequência de ações no aperto de mão secreto.

A sequência de ações é escolhida observando os cinco dígitos mais à direita do número depois de convertê-lo para binário.
Comece pelo dígito mais à direita e avance para a esquerda.

As ações para cada casa do número são:

```plaintext
00001 = wink
00010 = double blink
00100 = close your eyes
01000 = jump
10000 = Reverse the order of the operations in the secret handshake.
```

Vamos usar o número `9` como exemplo:

- 9 em binário é `1001`.
- O dígito mais à direita é 1, então a primeira ação é `wink`.
- Seguindo para a esquerda, o próximo dígito é 0, então não há double blink.
- Continuando para a esquerda, o próximo dígito é 0, então você deixa os olhos abertos.
- Mais uma vez para a esquerda, o próximo dígito é 1, então você salta.

Esse foi o último dígito, então o código final é:

```plaintext
wink, jump
```

Dado o número 26, que é `11010` em binário, obtemos as seguintes ações:

- double blink
- jump
- inverter a ordem das ações

Portanto, o aperto de mão secreto para 26 é:

```plaintext
jump, double blink
```
