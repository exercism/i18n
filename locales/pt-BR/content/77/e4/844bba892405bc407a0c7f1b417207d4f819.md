# Introdução

Constantes em Gleam são uma forma de dar nomes a valores. Elas são definidas com a palavra-chave `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Quando são definidas com a palavra-chave `pub`, as constantes de módulo podem ser acessadas de outros módulos; caso contrário, só podem ser acessadas de dentro do módulo em que foram definidas.
