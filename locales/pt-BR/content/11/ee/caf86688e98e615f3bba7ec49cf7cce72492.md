# Introdução

Em Cairo, o conceito de ownership se aplica a _variáveis_ e define as regras que determinam quem pode usar essas variáveis.
Cada variável declarada só pode ser usada uma vez, ou seja, quando uma variável é usada, ela será destruída ou movida, dependendo do tipo de uso.

_Destruição_ pode acontecer de várias formas:

- uma variável sai de escopo (com ou sem uso).
- uma struct é desestruturada.
- destruição explícita usando `destruct()`

_Mover_ um valor significa simplesmente passar esse valor para outra função.

A linguagem Cairo usa um sistema de tipos linear, que ela aproveita para garantir que todo código seja passível de prova (e de verificação), além de abstrair a memória imutável da VM do Cairo.
