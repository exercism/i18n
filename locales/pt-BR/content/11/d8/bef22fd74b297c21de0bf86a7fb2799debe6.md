# Instruções

Você é o oficial de quarto a bordo de um cúter que atravessa o Estreito de Bering. Três fontes anunciam a posição de cada banquisa e promontório à vista:

- A **mesa de cartas** fala em direções da bússola: `north`, `east`, `south`, `west`. Só um rumo, sem distância.
- O **navegador** fala em coordenadas *polares* a partir da última posição determinada do cúter: uma magnitude em milhas náuticas e uma marcação em graus, no sentido horário a partir do norte (ou seja, `0` é o norte, `90` é o leste, `180` é o sul e `270` é o oeste).
- O **vigia do mastro** fala em coordenadas *relativas*: uma distância à frente e um valor entre `ahead`, `starboard`, `behind` e `port`. As marcações relativas são medidas em relação ao *rumo atual do navio*: o capitão anuncia esse rumo na ponte de comando antes de cada quarto.

Sua tarefa é converter as três para um mesmo referencial cartesiano `(x, y)`, para que a carta possa ser traçada. As marcações são dadas em graus; `(0, 1)` é uma milha náutica ao norte e `(1, 0)` é uma milha náutica a leste.

## 1. O modelo de dados e o cartesiano para cardinal

Primeiro, defina os elementos que todo o exercício compartilha:

- Defina três tuplas: `cardinal` (uma fenda, `direction`), `polar` (as fendas `magnitude` e `bearing`) e `relative` (as fendas `distance` e `bearing`).
- Declare os símbolos de rumo com `SYMBOLS:`: `north`, `east`, `south`, `west`, `ahead`, `starboard`, `behind`, `port`.
- Declare uma variável dinâmica `heading` com `SYMBOL:` (a tarefa 3 usa essa variável).
- Declare duas palavras genéricas: `GENERIC: >cartesian ( direction -- x y )` e `GENERIC: flip ( direction -- direction' )`. Você vai adicionar os métodos delas nas próximas tarefas.

Em seguida, adicione o método `M: cardinal` de `>cartesian`, que retorna o vetor unitário para a direção informada.

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. Cartesiano para polar

Adicione um método `M: polar` a `>cartesian` que converte a forma polar para `(x, y)`:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. Cartesiano para relativo

Adicione um método `M: relative` a `>cartesian`. O detalhe é que uma marcação relativa é medida em relação ao *rumo atual* do navio, que não faz parte da tupla. Leia a variável `heading` (declarada na tarefa 1) com `heading get`, some o deslocamento da marcação (`ahead = 0`, `starboard = 90`, `behind = 180`, `port = 270`) e produza o ponto cartesiano. Quem chama a palavra define `heading` dentro de um bloco `with-variable`.

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. Flip

Adicione os métodos do genérico `flip` (declarado na tarefa 1) para que ele retorne a direção oposta.

- Para `cardinal`: north ↔ south, east ↔ west.
- Para `polar`: some 180° à marcação (módulo 360).
- Para `relative`: ahead ↔ behind, starboard ↔ port.

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. Somar marcações

Defina `add-bearings ( a b -- x y )`, que converte as duas direções para cartesiano e retorna a soma delas. Funciona com qualquer combinação de `cardinal`, `polar` e `relative`. É a recompensa de usar um genérico para `>cartesian`.

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
