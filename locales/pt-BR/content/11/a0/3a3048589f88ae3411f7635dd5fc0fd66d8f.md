# especificação incorreta

[comment]: # (Este aviso aparece quando a solução tem um typespec diferente do exemplar)

Certifique-se de que o typespec de `two_fer/1` está correto. A função aceita um argumento (uma string) e retorna um argumento (também uma string).

O tipo correto para strings é [`String.t()`](https://hexdocs.pm/elixir/String.html#t:t/0).

> Os tipos `String.t()` e `binary()` são equivalentes para ferramentas de análise. No entanto, para quem lê a documentação, `String.t()` indica que se trata de um binário codificado em UTF-8.

O [tipo `string()`](https://hexdocs.pm/elixir/typespecs.html#the-string-type) significa uma charlist, não uma string do Elixir.

> O Elixir desencoraja o uso do tipo `string()`. O tipo `string()` se refere às strings do Erlang, conhecidas como "charlists" no Elixir. Elas não se referem às strings do Elixir, que são binários codificados em UTF-8.
