# Sobre

`TUPLE:` declara uma classe com slots nomeados. O Factor gera automaticamente uma palavra construtora (com o nome da classe com o sufixo `new`), um construtor `boa` ("por ordem dos argumentos"), uma sintaxe literal `T{ class … }` e palavras acessoras por slot.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

O sistema de acessores em [`accessors`][accessors] fornece quatro variações por slot: `name>>`, `>>name`, `change-name` e o par de mutação `[ … ] change-name`. `>>name` e `change-name` mutam a tupla; use `clone` primeiro quando precisar deixar a original intacta.

As tuplas dão suporte a `=` por igualdade estrutural e são impressas exibindo os valores de slot que não são o padrão.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
