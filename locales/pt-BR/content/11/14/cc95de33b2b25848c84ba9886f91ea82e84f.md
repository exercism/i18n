# Instruções

Adicione a contagem de minas a um tabuleiro de Campo Minado completo.

Campo Minado é um jogo popular no qual o jogador precisa encontrar as minas usando dicas numéricas que indicam quantas minas estão diretamente adjacentes (na horizontal, na vertical, na diagonal) a uma casa.

Neste exercício, você precisa criar um código que conta o número de minas adjacentes a uma casa vazia e substitui essa casa pela contagem.

O tabuleiro é um retângulo composto por caracteres de espaço em branco (' '). Uma mina é representada pelo caractere asterisco ('\*').

Se um determinado espaço não tiver nenhuma mina adjacente, deixe essa casa em branco.

## Exemplos

Por exemplo, você pode receber um tabuleiro 5 x 4 como este (os espaços vazios são representados aqui com o caractere '·' para exibição na tela):

```
·*·*·
··*··
··*··
·····
```

E o seu código vai transformá-lo nisto:

```
1*3*1
13*31
·2*2·
·111·
```
