# Anexo das instruções

## Dicas

Para completar este exercício, você precisa criar o tipo de dados `Robot`, como uma variável mutável, e o tipo de dados `RunState`. Você também precisa implementar as seguintes funções:

- `initialState`
- `mkRobot`
- `resetName`
- `robotName`

Você vai encontrar uma declaração de dados fictícia e as assinaturas de tipo já prontas, mas cabe a você definir as funções e criar um tipo de dados, um newtype ou um sinônimo de tipo que faça sentido. Para modelar o estado, este exercício usa a mônada [`State`](https://en.wikibooks.org/wiki/Haskell/Understanding_monads/State). Mais especificamente, combinamos a mônada `State` com a mônada `IO` usando os [transformadores de mônada `StateT`](http://book.realworldhaskell.org/read/monad-transformers.html). Todos os testes são executados com `initialState` como o estado passado para `evalStateT`.
