# Instruções

Endpoints HTTP ficam melhores com verificação de tipos. Adicionar um tipo Record a uma requisição POST garante que os dados corretos sejam enviados todas as vezes.

## Objetivos

- Modifique o código fornecido.
- Adicione os atributos necessários a este record para aceitar dois operandos e um operador.
- Adicione uma função de recurso HTTP para aceitar uma requisição POST no caminho '/calc'
- A função deve aceitar o tipo de record Calculation como payload e retornar um objeto JSON genérico

### Aceita

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Retorna

```json
{ "expression": "4+10.2", "result": 14.2 }
```
