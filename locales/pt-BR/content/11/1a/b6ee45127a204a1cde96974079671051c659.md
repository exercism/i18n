# Testes

Para rodar os testes na linha de comando, execute o seguinte comando a partir do diretório do exercício:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## Interface gráfica

Para rodar os testes pela interface gráfica do simulador MARS, use `include` para adicionar sua implementação no final de `runner.mips`, descomentando a última linha.
