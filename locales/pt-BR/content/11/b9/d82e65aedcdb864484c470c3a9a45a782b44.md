# Instruções

Andrew, um desenvolvedor da sua empresa, acabou de construir um utilitário leve de geração de consultas SQL para uma ferramenta de migração de banco de dados.
Sua primeira implementação ingênua funcionou perfeitamente para pequenos conjuntos de dados.
Porém, durante grandes migrações em produção, a aplicação começou a consumir memória em excesso e passou a sofrer sob carga pesada.
Depois de fazer o profiling da aplicação, Andrew percebeu que a concatenação de strings tradicional dentro de laços estava forçando o Go a realocar memória o tempo todo.
Agora, ele precisa da sua ajuda para refatorar o utilitário usando `strings.Builder` do Go, para garantir que a aplicação escale bem e dê conta de grandes volumes de texto sem estourar o heap de memória.

## 1. Gerar consultas SELECT

Implemente a função `BuildSelectQuery`.
Ela recebe o nome de uma tabela (`string`) e uma slice com nomes de colunas (`[]string`).
Ela deve retornar um comando SQL `SELECT` completo, terminando com ponto e vírgula.
Se a slice de colunas estiver vazia ou for `nil`, a consulta deve recorrer ao curinga `*` para selecionar todas as colunas.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Gerar comandos INSERT em lote

Implemente a função `BuildBatchInserts`.
Ela recebe o nome de uma tabela (`string`) e uma slice bidimensional que representa as linhas do banco de dados (`[][]ColumnValue`).
Cada elemento de uma linha associa o nome de uma coluna específica ao seu valor em string.
A função deve retornar uma slice de strings SQL `INSERT` individuais.
O formato estruturado da slice garante uma ordem de saída das consultas previsível e estável.
Se a slice de linhas de entrada estiver vazia, retorne uma slice de strings vazia.
Se alguma linha individual estiver vazia, ignore-a.
Os valores em string dentro da cláusula `VALUES` devem vir entre aspas simples `'`.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
