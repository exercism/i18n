# Sobre

## Iteração sobre arrays

Um laço `for` permite iterar sobre um array e repetir o código para cada elemento:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

No exemplo acima, `fruit` é a variável que guarda o valor de um elemento individual do array `fruitList`. O compilador garante que é possível iterar sobre `fruitList`; caso contrário, ele interrompe a execução.

## Iteração sobre intervalos

Você pode iterar sobre números usando o operador de intervalo. O operador recebe dois operandos `Int` e é escrito como `min...max`. O `min` é inclusivo e o `max` é exclusivo (`min` <= i E `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## Iteração sobre pares chave-valor

É possível iterar sobre coleções de pares chave-valor. A única diferença na sintaxe é que, em vez de uma única variável, usa-se um identificador de variável de chave, seguido de `=>`, seguido do identificador de variável de valor:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
