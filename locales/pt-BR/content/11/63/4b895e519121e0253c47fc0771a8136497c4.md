# Apêndice das instruções

## Mensagens de exceção

Às vezes é necessário [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você faz isso, inclua sempre uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda bastante na depuração. Nas situações em que você sabe que a origem do erro será de um tipo específico, você pode optar por lançar um dos [tipos de erro embutidos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda assim deve incluir uma mensagem significativa.

Este exercício em particular exige que você use a [instrução `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um erro quando as regras de pontuação ou de jogo não forem seguidas. Os testes só vão passar se você fizer o `raise` da `exception` e incluir uma mensagem junto com ela.

Para lançar um `ValueError` com uma mensagem, escreva a mensagem como argumento do tipo da `exception`:

```python
# example when a bonus is attempted with an open frame
raise IndexError("cannot throw bonus with an open tenth frame")

# example when fill balls are invalid
raise ValueError("invalid fill balls")
```
