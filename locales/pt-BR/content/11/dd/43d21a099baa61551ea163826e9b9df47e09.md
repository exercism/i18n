# Instruções

Você mantém um pequeno posto meteorológico na margem do Vltava, em Praga, e a cada turno anota as leituras de temperatura num log de texto simples, uma leitura por linha. Cinco palavrinhas dão conta de toda a papelada de um turno.

Cada palavra recebe o caminho do arquivo de log.

## 1. Leia cada leitura

Defina `read-readings` para retornar todas as leituras do log como um array de strings, uma por linha.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. Encontre a leitura mais recente

Defina `latest-reading` para retornar a leitura mais recente, a última linha do log.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. Leia o log bruto

Defina `log-text` para retornar o arquivo de log inteiro como uma única string, exatamente como está armazenado.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. Registre uma leitura

Defina `record-reading` para acrescentar uma nova leitura ao final do log, em sua própria linha, sem mexer nas leituras anteriores. Não retorna nada.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. Reescreva o log

Defina `rewrite-log` para substituir o log inteiro por um novo array de leituras, uma por linha.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
