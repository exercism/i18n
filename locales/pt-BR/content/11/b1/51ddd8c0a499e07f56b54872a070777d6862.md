# Anexo de instruções

A exponenciação de números complexos requer uma função exponencial, uma função seno e uma função cosseno, e nenhuma delas está disponível no WebAssembly. Felizmente, dá para usar uma [série de Taylor](https://en.wikipedia.org/wiki/Taylor_series) para calculá-las. Você precisa de uma precisão de pelo menos `1/26!` para bater com os valores esperados.

## Função exponencial

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Função seno

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## Função cosseno

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
