# Dicas

## 1. Defina o tempo esperado no forno, em minutos

- Você precisa definir uma [var][vars] usando [def].

## 2. Calcule o tempo restante no forno, em minutos

- Você precisa definir uma [função][functions] com um único parâmetro.
- Você pode usar a var definida anteriormente e se referir a ela pelo nome.
- O resultado da avaliação da última expressão de uma função é retornado automaticamente pela função; todas as funções retornam esse valor.
- Você pode usar as funções principais para [operações com números][operators] para subtrair valores.

## 3. Calcule o tempo de preparo, em minutos

- Você precisa definir uma [função][functions] com um único parâmetro.
- Você pode usar as funções principais para [operações com números][operators] para multiplicar valores.

## 4. Calcule o tempo decorrido, em minutos

- Você precisa definir uma [função][functions] com dois parâmetros.
- Você pode [chamar][calling] uma das outras funções que você definiu anteriormente.
- Você pode usar as funções principais para [operações com números][operators] para somar valores.
