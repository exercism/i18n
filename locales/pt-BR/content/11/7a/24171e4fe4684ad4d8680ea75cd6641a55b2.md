## Instruções

Você foi contratado por um centro de reciclagem.
Por falta de espaço, todos os produtos são colocados na mesma esteira transportadora, mas isso fez com que materiais diferentes se misturassem, o que os torna inutilizáveis.
Para resolver isso, sua tarefa é criar funções que identifiquem o tipo de um produto.

### 1. Verifique se um valor é um Boolean

Implemente a função `isBoolean`, que verifica se um valor é um Boolean.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Verifique se um valor é um número.

Implemente a função `isNumber`, que verifica se um valor é um `number` ou `bigint` _finito_, ou seja, que não é `NaN` nem `Infinity`.

Às vezes, o dispositivo de leitura de IDs falha e lê um valor não numérico como `NaN` (não é um número) ou `Infinity`.
Sua função também deve conseguir lidar com isso corretamente.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Verifique se um valor é um objeto

Implemente a função `isObject`, que deve verificar se o valor é um objeto.
Na esteira, `null` é nada e não é considerado um objeto.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Verifique se uma string é numérica

Implemente a função `isNumericString`, que deve verificar se o valor é uma string composta apenas de dígitos, ou de um sinal de menos seguido de dígitos, indicando um número negativo.
Apenas números inteiros devem ser considerados; decimais não são considerados numéricos para essa verificação do robô de reciclagem.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Verifique se um objeto é eletrônico

Implemente a função `isElectronic`, que verifica se um objeto é uma instância da classe `ElectronicDevice` fornecida ou de uma de suas classes filhas.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Verifique se um valor é um array não vazio

Implemente a função `isNonEmptyArray`, que verifica se um valor é um array não vazio.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Verifique se um valor é um array vazio

Implemente a função `isEmptyArray`, que verifica se um valor é um array vazio.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Verifique se um objeto tem uma propriedade ou método `type`

Implemente a função `hasType`, que verifica se um objeto tem uma propriedade ou método `type`.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Lance um erro se um objeto não tiver uma propriedade ou método `id`

Implemente a função `assertHasId`, que lançará um `Error` se um objeto não tiver a propriedade `id`.

Se um objeto tiver a propriedade `id`, a função não deve retornar nada.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Verifique se um objeto tem uma propriedade `id`

Implemente a função `hasIdProperty`, que verifica se um objeto tem uma propriedade `id`.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Verifique se um objeto tem uma propriedade `type` definida

Implemente a função `hasDefinedType`, que verifica se um objeto tem uma propriedade `type` que não é `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
