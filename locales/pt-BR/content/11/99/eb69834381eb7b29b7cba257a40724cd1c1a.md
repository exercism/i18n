# Introdução

O tipo `enum` do C# representa um conjunto fixo de constantes nomeadas (uma enumeração). O principal objetivo dele é oferecer uma forma type-safe de interagir com constantes numéricas, limitando os valores disponíveis a um conjunto predefinido. Um enum simples pode ser definido assim:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Se os valores não forem definidos explicitamente, os membros do enum recebem automaticamente valores inteiros incrementais, começando em zero. Também é possível atribuir valores explicitamente:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
