# Instruções

Neste exercício, você vai processar linhas de um relatório de log.
Cada linha de log é uma string formatada assim: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Você tem três tarefas, e cada uma delas recebe uma linha de log e pede que você faça algo com ela.

## 1. Obter a mensagem de uma linha de log

Implemente o método `log_line::message` para retornar a mensagem de uma linha de log:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. Obter o nível de log de uma linha de log

Implemente o método `log_line::log_level` para retornar o nível de log de uma linha de log, que deve ser retornado em letras maiúsculas:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. Reformatar uma linha de log

Implemente o método `log_line::reformat`, que reformata a linha de log, colocando a mensagem primeiro e o nível de log depois dela, entre parênteses:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
