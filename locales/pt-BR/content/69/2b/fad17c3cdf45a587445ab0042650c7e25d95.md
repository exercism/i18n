# Complemento das instruções

## Paralelismo

O executor de testes tem acesso a dois núcleos a partir de 2025-07-28.
Uma abordagem exaustiva pode não se beneficiar do [hyper](https://docs.raku.org/routine/hyper) ou do [race](https://docs.raku.org/routine/race) do Raku.
Você pode verificar com:

~~~~raku
note Kernel.cpu-cores
# 2
~~~~
