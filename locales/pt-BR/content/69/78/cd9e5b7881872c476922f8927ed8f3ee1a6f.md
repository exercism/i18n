## Instalando o Z3

### Baixe o Python (caso ainda não esteja instalado)

A versão mais recente do Python pode ser baixada [aqui.](https://python.org)

* Durante a instalação, não deixe de marcar a caixa que adiciona o Python ao PATH

### Baixe o Visual Studio (caso ainda não esteja instalado)

A versão mais recente do Visual Studio pode ser baixada [aqui.](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)

* Durante a instalação, selecione a carga de trabalho **Python Development**
* Marque todas as caixas de seleção de pacotes opcionais de desenvolvimento Python no lado direito

Depois da instalação, abra o Visual Studio e configure suas preferências iniciais.

### Instale os comandos do Git

As instruções de instalação do Git estão [aqui.](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)

* Você vai precisar [adicionar o Git às suas variáveis de sistema](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### Clone o Z3

Acesse o [repositório do Z3 no GitHub](https://github.com/Z3Prover/z3) para ver o projeto.

Abra um terminal no seu computador e navegue até o local onde você quer clonar o repositório do Z3 (ex.: C:\Z3).

A partir desse local, rode:

```bash
git clone https://github.com/z3Prover/z3.git
```

### Compilando o Z3 no Windows com o Visual Studio Command Prompt

Abra o **Developer Command Prompt for VS 2019** pelo menu iniciar.

Navegue até a pasta onde você clonou o repositório do Z3 (ex.: C:\Z3).

Para compilações de 32 bits, rode:

```bash
python scripts/mk_make.py
```

Para uma compilação de 64 bits, rode:

```bash
python scripts/mk_make.py -x
```

depois, rode:

```bash
cd build
pip install z3-solver
```



Agora você já deve conseguir abrir o Visual Studio e rodar o Z3 com o binding de Python.


Para testar, você pode rodar:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

As duas últimas linhas devem produzir `sat` e `[y = 4, x = 2]`.
