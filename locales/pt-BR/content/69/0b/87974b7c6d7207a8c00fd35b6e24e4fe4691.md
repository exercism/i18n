# Apêndice de instruções

## Palavras

- `<bst> ( data-seq -- tree )`: cria uma árvore inserindo cada
  elemento de `data-seq`, na ordem dada.
- `sorted-data ( tree -- seq )`: retorna os elementos da árvore em
  ordem crescente (percurso em ordem).

## Hierarquia de tuplas

Um nó de uma árvore binária de busca é *vazio* ou *tem um dado e
duas subárvores*. Modele isso como uma pequena hierarquia de
herança:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` é o pai abstrato; `leaf` é o caso da árvore vazia;
`branch` carrega um valor e dois filhos `bst` (cada um deles,
por sua vez, um `leaf` ou um `branch`).

## Ordenação

Compare os dados com `before=?` (de `math.order`), que funciona
tanto com strings quanto com números: os testes usam dados do tipo
string como `"1"`, `"2"`, `"3"`.
