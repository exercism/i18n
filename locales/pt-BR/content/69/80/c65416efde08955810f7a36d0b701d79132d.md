# Instalação

Você vai precisar do Node Package Manager (npm) para instalar o Reason. Siga as instruções [aqui](https://www.npmjs.com/get-npm)

Depois de ter o npm, instale o Reason com:
```
npm install -g bs-platform
```

O Reason tem integração com vários editores, veja [aqui](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)

Algumas ferramentas de linha de comando (incluindo um REPL que permite avaliar expressões do Reason em um shell) podem ser encontradas [aqui](https://github.com/reasonml/reason-cli)
