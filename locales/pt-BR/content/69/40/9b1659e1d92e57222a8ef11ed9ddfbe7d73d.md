# Introdução

Assim como as propriedades, que armazenam dados nas suas structs e classes, você também pode definir _métodos_, que armazenam funções na sua struct ou classe.

Os métodos são definidos da mesma forma que uma função comum, só que dentro do corpo da struct ou da classe. Repare que, se uma função altera o valor de uma propriedade em uma struct, ela precisa ser precedida da palavra-chave `mutating`. Além disso, se uma propriedade pode ser alterada por um método, ela precisa ser definida com `var` em vez de `let`, assim como as variáveis comuns.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

Esses métodos podem ser chamados usando a notação de ponto, assim como as propriedades.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
