# Instruções

Neste exercício, você vai escrever um pouco de código para ajudar o Larry, o Alien Lisp, a processar e formatar strings de log. Essas strings de log chegam de vários sistemas e precisam ser processadas para que suas mensagens possam ser exibidas em um painel de monitoramento informativo.

As strings de log têm o formato `"[<level>]: <message>"`. O level será um dos seguintes valores: `info`, `warn` ou `ohno`.

## 1. Extraia a mensagem

Defina uma função `log-message` que recebe uma string de log e retorna a mensagem contida nela.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. Determine a gravidade

O level da string de log determina a sua gravidade.

- um level `info` significa uma gravidade `:everything-ok`
- um level `warn` significa uma gravidade `:getting-worried`
- um level `ohno` significa uma gravidade `:run-for-cover`

Defina uma função `log-severity` que recebe uma string de log e retorna a gravidade correta.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. Lidando com os caprichos da realidade

Infelizmente, às vezes as strings de log não estão sempre formatadas corretamente. Mais especificamente, o log level pode não estar todo em letras minúsculas como especificado acima. Modifique `log-severity` para lidar com isso.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. Reformatando a mensagem do log de acordo com a gravidade

Dependendo da gravidade, a mensagem deve ser modificada de maneiras diferentes:

- uma gravidade `:everything-ok` deve ter sua mensagem alterada para tudo em letras minúsculas.
- uma gravidade `:getting-worried` deve ter sua mensagem alterada para ter cada palavra com a primeira letra maiúscula.
- uma gravidade `:run-for-cover` deve ter sua mensagem alterada para tudo em letras maiúsculas.

Defina uma função `log-format` que recebe uma mensagem de log e retorna uma mensagem formatada corretamente.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
