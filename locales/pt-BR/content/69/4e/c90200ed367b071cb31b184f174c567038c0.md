Nós agora lançamos por completo a segunda parte da nossa estratégia de feedback automatizado: os Representers!
Este post dá uma visão geral rápida de como eles funcionam e por que são tão úteis.
É um pouco mais técnico que o normal, então aperte o cinto!

## O que é um Representer?

Um Representer é um software que pega a solução de um estudante e retorna uma representação normalizada dela.
Depois usamos essas representações para agilizar o feedback automatizado e a classificação.

Um exemplo ajuda a explicar os Representers da melhor forma.
Vamos supor que dois estudantes enviem duas submissões para o exercício `hello-world` em Ruby:

```ruby
# Student 1's submission
def self.hello(name = 'World')
  "Hello, #{name}!"
end
```

```ruby
# Student 2's submission
def self.hello(nom='World')
    "Hello, #{nom}!"
end
```

Embora o código dessas soluções seja diferente (indentação diferente, nomes de variáveis diferentes e sintaxe de string diferente), elas são essencialmente iguais.
Então, ao criar uma representação normalizada delas, podemos _tratá-las_ como iguais para fins de fornecer feedback.

## Por que isso é útil?

Ao criar essas representações normalizadas, conseguimos garantir que o feedback dado em uma submissão seja aplicado automaticamente a outras soluções parecidas.
Isso significa que, como estudante, você tem muito mais chance de receber um feedback instantâneo e bastante relevante.
E, como mentor, você não deve mais precisar dar o mesmo feedback duas vezes para uma solução parecida: você faz isso uma vez na interface do Automation e o resto acontece como mágica.

Também podemos usar os Representers junto com nossos Analyzers que já existem.
Os Analyzers podem comentar pontos gerais (como nomes de variáveis, linting etc.) e as representações podem focar nas mudanças mais amplas que devem ser feitas.
É um potencial enorme, e estamos apenas arranhando a superfície.

## Quem pode adicionar feedback?

A possibilidade de adicionar feedback às representações está restrita aos nossos super-mentores, cerca de 150 pessoas que já mentoraram centenas de estudantes e mantêm uma avaliação alta como mentores.

Se você é super-mentor, agora deve encontrar a aba 'Automation' desbloqueada no seu Mentoring Dashboard, que você pode usar para acessar soluções que podem receber feedback.
Leia a documentação com atenção, porque fazer isso bem tem muitas sutilezas!
