# Sobre

Os [atributos de módulo][module-attr] podem ser usados como ["constantes"][attr-as-const], que são avaliadas em tempo de compilação.

```elixir
defmodule Example do
  @number 2

  def number(), do: @number
end
```

No entanto, eles não se comportam exatamente como constantes, porque podem ser sobrescritos quando redefinidos no módulo:

```elixir
defmodule Example do
  @standard_message "Hello, World!"
  @standard_message "Overwritten!"

  def message(), do: @standard_message
end
```

[module-attr]: https://hexdocs.pm/elixir/module-attributes.html
[attr-as-const]: https://hexdocs.pm/elixir/module-attributes.html#as-constants
