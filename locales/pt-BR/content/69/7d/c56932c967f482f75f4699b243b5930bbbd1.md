# Fluxo de controle

As expressões `if` e os laços controlam o fluxo de execução em Cairo:
`

- **Expressões `if`** executam código de forma condicional, dependendo de uma condição avaliar para `true`.
- **Laços** (como `loop`, `while` e `for`) executam código repetidamente enquanto uma condição especificada continuar verdadeira ou até que uma condição de interrupção seja atingida.

Essas construções são fundamentais para implementar lógica e iteração em Cairo.

## Expressões `if`

As expressões `if` em Cairo permitem controlar o fluxo de execução com base em lógica condicional.
Elas seguem uma estrutura em que o código é executado dependendo de uma condição Boolean avaliar para `true` ou `false`.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

Este exemplo demonstra um bloco `if` simples em Cairo.
A mensagem `"It's hot outside!"` só é impressa se a condição `temperature > 25` for avaliada como `true`.
Se a condição for falsa, nenhum código é executado e o programa continua.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

Rodar este código vai imprimir `"The number is less than 10."` no console.

### Lidando com várias condições com `else if`

Você pode usar várias condições combinando `if` e `else` em uma expressão `else if`.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

Rodar este código vai imprimir `"Grade: B"` no console.

### Usando `if` em uma instrução `let`

A expressão `if` em Cairo pode ser usada no lado direito de uma instrução `let` para atribuir o resultado a uma variável.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## Laços

Os laços são uma construção fundamental que permite repetir blocos de código, viabilizando uma execução eficiente e controlada de tarefas.
Os laços podem iterar sobre uma sequência ou executar código repetidamente com base em uma condição.
Cairo oferece três tipos principais de laço:

- **loop**: Um laço básico que roda indefinidamente, a menos que seja interrompido explicitamente com uma instrução `break`.
- **while**: Continua a executar enquanto uma condição especificada permanecer `true`.
  Ele para quando a condição se tornar `false`.
- **for**: Itera sobre os elementos de uma coleção, como arrays, executando código para cada elemento.

### Repetindo código com `loop`

A palavra-chave `loop` diz a Cairo para executar um bloco de código repetidamente, para sempre, ou até você dizer explicitamente para parar.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Executar este código vai imprimir `"again!"` indefinidamente no console, até o programa ficar sem gás ou até você pará-lo manualmente.

> Nota: Cairo nos impede de rodar um programa com laços infinitos incluindo um medidor de gás.
> O medidor de gás é um mecanismo que limita a quantidade de computação que pode ser feita em um programa.
> Gás é uma unidade de medida que expressa o custo de computação de uma instrução.
> Quando o medidor de gás acaba, o programa para.

Para sair de um laço, coloque a palavra-chave `break` dentro do laço para dizer ao programa quando parar de executá-lo.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

A palavra-chave `continue` diz ao programa para ir para a próxima iteração do laço e pular o resto do código nesta iteração.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Executar este programa não vai imprimir o valor de `i` quando ele for igual a `5`.

#### Retornando valores de um `loop`

Você pode retornar um valor de um `loop` usando a palavra-chave `break` seguida do valor que você quer retornar.
Isso permite sair do `loop` e passar um resultado para o resto do seu código.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### Laços condicionais com `while`

O `while` roda código enquanto uma condição for verdadeira e sai quando a condição se tornar falsa.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### Percorrendo uma coleção com `for`

O `for` itera sobre cada item de uma coleção, executando código para cada item.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
