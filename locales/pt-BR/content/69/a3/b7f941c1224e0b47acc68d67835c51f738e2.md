# Escrevendo o código

Escreva seu código em `src/lib.rs`.
Os exercícios vêm com um arquivo stub em `src/lib.rs` que mostra as assinaturas do código que você vai precisar escrever.

Na maioria dos exercícios, o melhor é escrever todo o seu código no arquivo `src/lib.rs`.
Se você quiser dividir sua solução em vários arquivos, consulte o [capítulo sobre módulos][chapter-modules] do livro do Rust.

[chapter-modules]: https://doc.rust-lang.org/book/ch07-02-defining-modules-to-control-scope-and-privacy.html

## Rodando os testes

Para rodar os testes, basta executar o seguinte comando:

```bash
$ cargo test
```

Por padrão, só o primeiro teste vem habilitado.
Quando quiser passar no próximo teste, remova a flag `ignore` do próximo teste (`#[ignore]`).
Se preferir, você também pode remover a flag de todos os testes de uma vez.

Fique à vontade para escrever o mínimo de código possível para fazer os testes passarem.
As falhas nos testes vão te orientar sobre o que escrever em seguida.

Como o Rust verifica todo o código em tempo de compilação, pode acontecer de seus testes não compilarem até você escrever o código necessário.
Até os testes marcados com `ignore` são verificados em tempo de compilação.
Você pode [comentar][comments] os testes que não compilam começando cada linha com `//`.
Depois, quando estiver na hora de trabalhar nesse teste, é só descomentar.
O Rust também tem uma macro especial chamada `todo!()`, que você pode usar em partes do código ainda não finalizadas para fazer seu programa compilar.

[comments]: https://doc.rust-lang.org/book/ch03-04-comments.html

## Usando bibliotecas

Você deve conseguir resolver a maioria dos exercícios sem usar bibliotecas externas.
Ainda assim, você pode adicionar bibliotecas (a comunidade Rust as chama de **crates**) rodando `cargo add crate-name` no diretório de um exercício.

Os testes automáticos do site só dão suporte a um conjunto predefinido de crates, que pode ser encontrado [aqui][local-registry] na seção `[dependencies]`.
Fique à vontade para abrir uma issue ou um pull request se quiser que o suporte a um crate específico seja adicionado.

[local-registry]: https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml
