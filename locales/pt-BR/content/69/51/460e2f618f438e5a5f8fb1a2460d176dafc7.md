# Complemento das instruções

## Implementação

Além da função _numbers_, que limpa os números de telefone, você precisa escrever mais duas funções na trilha de Emacs Lisp: _area-code_ e _pprint_.

Cada uma das funções extras recebe o número de telefone como seu único parâmetro.

A primeira função, _area-code_, extrai o código de área da entrada, enquanto a segunda, _pprint_, transforma a entrada em uma string no formato
```
(NXX) NXX-XXXX
```
em que `N` e `X` são como descritos acima.
