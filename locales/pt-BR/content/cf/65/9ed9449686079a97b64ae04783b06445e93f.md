# Dicas

## Geral

- Leia sobre [charlists][getting-started-charlists], [Unicode e code points][getting-started-code-points] e [`case`][getting-started-case] no guia oficial Getting Started.
- Leia sobre [charlists][elixirschool-charlists] e [`case`][elixirschool-case] em elixirschool.com.

## 1. Sanitize os nomes de usuário existentes removendo tudo, exceto letras minúsculas

- Use recursão para iterar sobre uma charlist.
- Existe uma [função embutida][kernel-case] que permite comparar um valor com vários padrões.
- Existe uma [sintaxe especial][syntax-reference-code-points] para obter o code point de um caractere. Ela pode ser usada em guardas.
- Charlists são listas de code points, e code points, sendo números, podem ser [comparados][kernel-greater-than] entre si.
- As letras latinas minúsculas têm [code points consecutivos][unicode-character-reference], em ordem alfabética.
- Existe [uma função embutida][kernel-concat-list] que permite concatenar duas listas.

## 2. Permita underscores

- Existe uma [sintaxe especial][syntax-reference-code-points] para obter o code point de um caractere. Ela pode ser usada em guardas e também funciona para caracteres de pontuação.
- Existe [uma função embutida][kernel-concat-list] que permite concatenar duas listas.

## 3. Substitua os caracteres alemães

- Existe uma [sintaxe especial][syntax-reference-code-points] para obter o code point de um caractere. Ela pode ser usada em guardas e também funciona para letras que não são ASCII.
- Existe [uma função embutida][kernel-concat-list] que permite concatenar duas listas.
