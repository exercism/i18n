# Instruções

Você está criando um jogo online trivial em que alguém pode adivinhar um número secreto. Você quer dar algum feedback, mas sem revelar a resposta por meio de um palpite. Você precisa criar uma função que forneça respostas diferentes dependendo de como o palpite se relaciona com o número secreto.

| Condição                                                     | Resposta       |
| ------------------------------------------------------------- | -------------- |
| Quando o palpite é igual ao número secreto                    | "Correct"      |
| Quando o palpite é um a mais ou um a menos que o número secreto | "So close"     |
| Quando o palpite é maior que o número secreto                 | "Too high"     |
| Quando o palpite é menor que o número secreto                 | "Too low"      |
| Quando nenhum palpite é feito                                 | "Make a guess" |

Todos os palpites e números secretos são números inteiros.

## 1. Gere a resposta quando o palpite for igual ao número secreto

Implemente a função `compare/2`, que recebe dois argumentos, `secret_number` e `guess`, ambos números inteiros.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. Gere a resposta quando o palpite for maior que o número secreto

Modifique a função `compare` para responder a palpites maiores que o número secreto.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. Gere a resposta quando o palpite for menor que o número secreto

Modifique a função `compare` para responder a palpites menores que o número secreto.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. Gere as respostas quando o palpite for um a mais ou um a menos que o número secreto

Modifique a função `compare` para responder a palpites próximos do número secreto.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. Gere a resposta quando não houver palpite

Modifique a função `compare` para responder quando não houver palpite.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
