# Instalação

## Requisitos da trilha de PowerShell

A trilha de PowerShell do Exercism exige que estejam instalados no seu sistema:

- PowerShell ou Windows PowerShell Core
- o módulo do framework de testes e mocks Pester instalado

(PS: o suporte ao PowerShell está limitado a correções críticas. O PowerShell Core é mantido de forma contínua e tem maior suporte entre plataformas)

### Instalando o PowerShell

O PowerShell já vem pré-instalado em todos os sistemas operacionais Windows a partir do Windows 7 SP1.

Você encontra a versão mais recente do PowerShell e as instruções de instalação para todas as plataformas (Linux, macOS e Windows) [aqui][installation].

O código-fonte e a instalação manual do [PowerShell][source-code] também estão disponíveis.

### Instalando e atualizando o framework Pester

O [Pester][pester] é o framework de testes do PowerShell.
Desde a versão 4.0.9, ele é compatível com o PowerShell Core no Windows, Linux e MacOS (com algumas limitações).

Ele já vem pré-instalado no Windows 10, mas recomendamos que você o atualize executando o seguinte comando do PowerShell:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

Para atualizações seguintes, execute:

```PowerShell
Update-Module -Name Pester
```

Se necessário, há mais instruções de instalação em: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## Usando uma IDE

Se você quer uma experiência de edição mais completa, provavelmente vai querer usar uma IDE.
Estas são as IDEs mais populares que oferecem suporte à criação de projetos em PowerShell:

### Todas as plataformas

- [PowerShell ISE (Ambiente de Script Integrado)][ise], IDE gráfica integrada que vem com o PowerShell (somente Windows).
  Para iniciar o PowerShell ISE, digite `powershell_ise.exe` em um console do PowerShell.
- [Visual Studio Code][vsc] com a [extensão do PowerShell][vsc-extension].
  O Visual Studio Code também permite rodar os testes e depurar seu código.
- [Sublime Text 3][sublime] com o [pacote do PowerShell][sublime-package].
