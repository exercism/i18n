# Métodos de string

`String` tem vários métodos que podem ser usados para manipular strings.
Esses métodos são chamados na própria string e muitas vezes são encadeados para realizar várias operações em uma string.

A seguir está uma lista de alguns dos métodos mais comuns.
Veja a [documentação da API de `String`][string-api] para uma lista completa de métodos.

## String#upcase & String#downcase

O método [`upcase`][upcase] retorna uma nova string com todos os caracteres convertidos para maiúsculas.

```crystal
"hello".upcase
# => "HELLO"
```

O método [`downcase`][downcase] retorna uma nova string com todos os caracteres convertidos para minúsculas.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

Vários métodos podem fazer conversões de maiúsculas e minúsculas mais específicas.
Isso pode ser útil ao converter uma string para um formato específico.
Aqui está uma lista de alguns dos métodos mais comuns:

| Método                            | Descrição                                                                                                          | Exemplo                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | Converte a primeira letra para maiúscula e o restante para minúscula                                               | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | Converte underscore para camelcase                                                                                 | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | Igual a String#camelcase, mas deixa o primeiro caractere em minúscula                                              | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | Converte todos os caracteres para minúsculas e coloca um underscore entre uma letra minúscula e uma letra maiúscula | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | Coloca a primeira letra de cada palavra em maiúscula e o restante em minúscula                                     | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

Crystal tem métodos para substituir partes de uma string.
Eles são conhecidos como [`sub`][sub] (_substituição_) e [`gsub`][gsub] (_substituição global_).

Esses métodos podem receber uma string, um char ou uma regex como primeiro argumento e uma string ou um char como segundo argumento.
O primeiro argumento é a parte da string que será substituída, e o segundo argumento é a substituição.
`Char` e regex serão explicados em conceitos posteriores.

O método `sub` substitui a primeira ocorrência do primeiro argumento pelo segundo argumento.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

O método `gsub` funciona igual ao `sub`, mas substitui todas as ocorrências do primeiro argumento pelo segundo argumento.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Chomp e strip podem ser usados para remover caracteres indesejados de uma string.

O método [`chomp`][chomp] por padrão remove os últimos caracteres `\r`, `\n` ou `\r\n` de uma string.
Se o método for chamado com um argumento, ele removerá o valor dado do final da string,
se ele existir no final da string.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Por padrão, o método [`strip`][strip] remove todos os espaços em branco do início e do final de uma string.
Se o método for chamado com um argumento, ele removerá esse argumento do início e do final da string,
se ele existir no início ou no final da string.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

Você pode usar o método [`reverse`][reverse] para inverter uma string.
Esse método retorna uma nova string com os caracteres na ordem inversa.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

O método [`index`][index] pode ser usado para encontrar o índice de um caractere em uma string.
O método `index` recebe uma `String`, um `Char` ou uma regex como argumento.
Ele pode receber um segundo argumento opcional para especificar o índice a partir do qual buscar.
O método `index` retorna o índice da primeira ocorrência do argumento.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Você pode usar o método [`delete_at`][delete_at] para remover um caractere de uma string.
O método `delete_at` recebe um índice como argumento e remove o caractere nesse índice.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

O método [`insert`][insert] pode ser usado para inserir uma string em um índice específico.
O método `insert` recebe um índice como primeiro argumento e uma string como segundo argumento.
O método `insert` retorna uma nova string com o segundo argumento inserido no índice.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
