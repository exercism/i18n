# Introdução

Uma função permite agrupar código em uma unidade reutilizável.
Ela é composta pela palavra-chave `func`, pelo nome da função e por uma lista de zero ou mais parâmetros e tipos separados por vírgula, entre parênteses.

## Parâmetros de função

Todos os parâmetros precisam ter tipo explícito; não há inferência de tipo para parâmetros.
Não existem valores padrão para parâmetros, então todos os parâmetros de uma função são obrigatórios.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

Parâmetros do mesmo tipo podem ser declarados juntos, seguidos de uma única declaração de tipo.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Parâmetros versus argumentos

Vamos ver rapidamente dois termos que costumam ser confundidos: `parameters` e `arguments`.
Os parâmetros de uma função são os nomes definidos na assinatura da função, como `greeting` e `name` na função `PrintGreetingName` acima.
Os argumentos de uma função são os valores concretos passados aos parâmetros da função quando invocamos a função.
Por exemplo, no exemplo abaixo, `"Hello"` e `"Katrina"` são os argumentos passados aos parâmetros `greeting` e `name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## Valores de retorno

Os parâmetros da função são seguidos por zero ou mais valores de retorno, que também precisam ter tipo explícito.
Valores de retorno únicos ficam sem parênteses; múltiplos valores de retorno são envolvidos por parênteses.
Os valores são retornados ao código que fez a chamada usando a palavra-chave `return`.
Pode haver várias instruções `return` em uma função.
A execução da função termina assim que ela encontra uma dessas instruções `return`.
Se uma função precisar retornar vários valores, eles são separados por vírgula.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Como invocar funções

Para invocar uma função, você especifica o nome da função e passa argumentos para cada um dos parâmetros dela entre parênteses.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Valores de retorno nomeados e retorno 'naked'

Assim como os parâmetros, os valores de retorno podem, opcionalmente, ser nomeados.
Se valores de retorno nomeados forem usados, uma instrução `return` sem argumentos retorna esses valores.
Isso é conhecido como retorno 'naked'.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
