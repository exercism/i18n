# Introdução

## Funções com Múltiplas Cláusulas

O Elixir facilita práticas do **Princípio Aberto-Fechado** ao permitir que funções tenham múltiplas cláusulas, então em vez de uma lógica de controle extensa e codificada de forma rígida, funções focadas podem ser escritas para adicionar/remover comportamento facilmente.

O Elixir oferece _múltiplas cláusulas de função_ e _guardas_ para escrever:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

Em tempo de execução, o Elixir testará, de cima para baixo do arquivo fonte, qual cláusula de função invocar.

Variáveis que não são usadas devem ser prefixadas com um underscore.

## Guardas

As guardas são usadas para impedir que o Elixir invoque funções com base na avaliação dos argumentos por funções de guarda. As guardas começam com a palavra-chave `when`, seguida por uma expressão Boolean. Funções de guarda são funções especiais que:

- Devem ser puras e não modificar nenhum estado global.
- Devem retornar valores estritamente `true` ou `false`.

Uma lista de guardas comuns pode ser encontrada na [documentação do Elixir][kernel-guards]. Ela inclui verificações de tipo, aritmética básica, comparações e operadores estritamente Boolean.

## Argumentos Padrão

Funções podem declarar valores padrão para um ou mais argumentos. Vamos considerar esta função:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Quando compilado, o Elixir cria uma definição de função para `number/0` (sem argumentos) e `number/1` (um argumento).

Se mais de um argumento tiver valores padrão, os valores padrão serão aplicados à função da esquerda para a direita para preencher os argumentos ausentes.

Se a função tiver mais de uma cláusula, os argumentos padrão devem ser definidos em um cabeçalho de função (uma função sem corpo) antes das cláusulas da função:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
