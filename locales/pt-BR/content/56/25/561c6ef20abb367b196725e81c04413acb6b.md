# Instalação

Para obter as instruções de instalação recomendadas para a sua plataforma,
acesse [o site oficial do Rust][the official Rust website].

Não basta ter a toolchain instalada!
O suporte a IDE é um enorme ganho de produtividade que a maioria dos desenvolvedores já espera.
Se você usa o Visual Studio Code, dê uma olhada na [documentação de suporte ao Rust][vscode].
Recomendamos também, com entusiasmo, que você ative o [linting com o clippy][vscode-linting]!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
