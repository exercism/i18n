# Instalação

O Phix para as plataformas Windows ou Linux pode ser baixado do [site oficial][Download].

Após a instalação, a estrutura de diretórios deve ser a mesma mostrada na [documentação][Installation].

Para testar, rode 'p -test'.

[Download]: http://phix.x10.mx/download.php
