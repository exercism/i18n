# Introdução

Common Lisp permite que quem programa escreva "comentários" que são ignorados pelo computador.
Comentários de uma linha começam com um ou mais pontos e vírgulas (`;`) e, ocasionalmente, você pode ver o seguinte:

```lisp
(code...) ; => value
```

Quando o comentário é usado para indicar qual valor o Common Lisp retorna depois de rodar o código nessa linha.

É idiomático usar um único ponto e vírgula para um comentário curto no final de uma linha, dois para um comentário mais longo acima de uma seção de código, três para um comentário longo descrevendo algo como uma função e quatro para um comentário como um cabeçalho no topo de um arquivo-fonte.
