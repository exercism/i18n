# Instruções

Neste exercício, você vai aplicar as [regras do jogo de Go](https://matmoore.github.io/learngo/). As regras em si já estão escritas, você só precisa aplicá-las para atualizar o Game e lidar com quaisquer erros ou violações das regras.

O jogo é representado da seguinte forma:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

Há 4 regras no jogo:

- Cada ponto pode ter apenas uma pedra.
- Pedras do adversário podem ser capturadas.
- Você não pode colocar uma pedra em um ponto onde ela capturaria a si mesma.
- Você não pode usar o mesmo ponto duas vezes.

## 1. Aplicar as regras

Escreva o conteúdo da função `apply_rules`, que recebe um `Game` inicial e um conjunto de regras, e retorna o novo `Game` depois que as regras forem aplicadas.

Três das regras verificam violações das regras e podem retornar um erro, então têm o tipo de retorno `Result(Game, String)`. Se qualquer uma dessas regras falhar, o jogo original deve ser retornado, mas com o campo `error` atualizado com o erro relevante.

A outra regra não verifica violações e por isso não pode falhar (embora possa retornar um `Game` alterado), então tem o tipo de retorno `Game`.

Se todas as regras passarem, quaisquer alterações no `Game` feitas pelas regras devem ser mantidas, e o jogador deve ser trocado.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
