# Dicas

## Geral

- `matches?`, `all-matching-subseqs`, `count-matches` e `re-replace` ficam todos em [`regexp`][regexp]. Escreva cada padrão como um literal entre `R/ ` e `/`.
- Um código de crachá válido tem duas letras maiúsculas, um hífen e quatro dígitos:
  `R/ [A-Z]{2}-\d{4}/`.

## 1. Verifique um código de crachá

- `matches?` testa a string *inteira*, que é exatamente o que a pergunta "isto é um
  código de crachá válido?" precisa: `R/ [A-Z]{2}-\d{4}/ matches?`.

## 2. Extraia todos os códigos de uma linha de log

- `all-matching-subseqs` retorna cada correspondência como uma sequência de strings;
  passe a ele o mesmo padrão de código de crachá.

## 3. Conte os dígitos de um código

- `\d` corresponde a um dígito; `count-matches` conta quantas vezes o padrão
  corresponde: `R/ \d/ count-matches`.

## 4. Oculte as senhas

- `\S` significa "um caractere que não é espaço", então `R/ pass=\S+/` corresponde a
  `pass=` mais o segredo que vem depois.
- `re-replace` recebe a string, o padrão e o texto de substituição
  `"pass=****"`.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
