# Instruções

A Bellebrook Basketball League é uma liga com vários times, cada um com um elenco de jogadores.
Uma nova temporada está prestes a começar, e eles precisam criar um novo sistema de venda de ingressos para os jogos.
Na temporada passada, eles vendiam ingressos na entrada do estádio, mas a popularidade explodiu, e eles decidiram vender ingressos online nesta temporada para lidar com o aumento da demanda.

A liga entrou em contato com você e pediu que você criasse um sistema para gerenciar a venda de ingressos.

## 1. Crie um sistema de venda de ingressos

Primeiro, você precisa criar um sistema de venda de ingressos para gerenciar a venda de ingressos.
O sistema de venda de ingressos precisa informar quantos ingressos estão disponíveis para um jogo.

Uma instância de uma classe chamada `TicketSystem` deve ser criada para cada jogo.
O estado inicializado deve conter as seguintes informações:

1. Quantos ingressos estão disponíveis para o jogo.
2. Em qual estádio o jogo é disputado.

Construa um estado inicializado a partir de argumentos que indiquem o número de ingressos disponíveis e em qual estádio a partida é disputada.
O estado inicializado deve ser composto pelas variáveis de instância `@tickets_available` e `@stadium`.
Elas devem conter o primeiro e o segundo argumentos fornecidos, respectivamente.

```crystal
TicketSystem.new(100, "Bellebrook")
# => #<TicketSystem:0x10f0b8 @tickets_available=100, @stadium="Bellebrook">
```

## 2. Obtenha a quantidade de ingressos disponíveis

Primeiro, você precisa criar um método que retorne a quantidade de ingressos disponíveis para um determinado jogo.

Defina um módulo chamado `TicketingReservation` acima da classe já definida.
Esse módulo deve ser incluído na classe `TicketSystem`.

Dentro do módulo, defina um método chamado `tickets_available`.
Esse método deve retornar a quantidade de ingressos disponíveis.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.tickets_available
#=> 100
```

## 3. Faça o pedido de ingressos

Você deve criar um método que verifique se há ingressos disponíveis para um determinado jogo.
O jogo precisa ter 100 ingressos em reserva.
Isso serve para garantir que sempre haja ingressos disponíveis para as pessoas que compram na entrada do estádio.

Dentro do módulo `TicketingReservation`, defina um método chamado `order_ticket?`.
O método deve retornar `true` se houver pelo menos 100 ingressos disponíveis e `false` caso contrário.
Se houver pelo menos 100 ingressos disponíveis, o método também deve diminuir em 1 o número de ingressos disponíveis.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.order_ticket?
#=> true
```

## 4. Mensagem do pedido

O sistema de venda de ingressos precisa ter mensagens fáceis de entender para os usuários.
E as mensagens devem parecer pessoais, então devem incluir o nome do usuário.

Se a compra do ingresso foi bem-sucedida, o usuário deve receber uma mensagem informando que a compra deu certo, o número do ingresso e em qual estádio o jogo é disputado.
O número do ingresso deve ser o número de ingressos disponíveis antes do pedido.

Se a compra foi bem-sucedida, a mensagem deve ser assim: `{name}, your purchase was successful, your ticket number is #{ticket_number}, and the game is played at the {stadium_name} stadium.`.
Se a compra não foi bem-sucedida, a mensagem deve ser assim: `{name}, your purchase was unsuccessful, there are not enough tickets available.`.

Dentro do módulo `TicketingReservation,` defina um método chamado `order_message` que recebe um argumento `name` contendo o nome do comprador.
O método deve retornar uma string com a mensagem.

```crystal
ticket_system = TicketSystem.new(100, "Bellebrook")
ticket_system.order_message("John")
#=> "John, your purchase was successful, your ticket number is #100, and the game is played at the Bellebrook stadium."
```
