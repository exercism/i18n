# Instalar o `testthat`

Os testes desta trilha usam o pacote `testthat`.

Para instalar o pacote, basta abrir o R e rodar:

`install.packages("testthat")`

Você pode verificar se o pacote foi instalado com sucesso rodando:

`library(testthat)`

# Rodar os testes

Cada problema terá um script chamado `test_<exercise-name>.R` (por exemplo, `test_hello-world.R`).

Para rodar os testes de um exercício, basta executar esse script R.

No RStudio, basta abrir o script de teste e clicar em "Source", no canto superior direito do painel Source. Isso carrega o código da sua solução por meio do comando `source` na primeira linha do script de teste e depois executa a suíte de testes do `testthat` que vem em seguida.

Note, porém, que o comando `source()` na primeira linha do script de teste só funciona se o script da sua solução (`<exercise-name>.R`) estiver no seu diretório de trabalho. Se não estiver, você vai precisar de uma destas opções:
- mudar seu diretório de trabalho, por exemplo `setwd('exercism/r/hello-world/')`, ou
- atualizar a primeira linha do script de teste, por exemplo `source('exercism/r/hello-world/hello-world.R')`

Se preferir, você também pode rodar os testes pela linha de comando com `Rscript path_to_exercise_directory/test_<exercise-name>.R` (por exemplo, `Rscript hello-world/test_hello-world.R`)

Outra forma prática de rodar esses testes é usar a [função `auto_test` do testthat](https://www.rdocumentation.org/packages/testthat/topics/auto_test). Como o código e os testes do exercism ficam na mesma pasta, use esse mesmo caminho para os parâmetros `code_path` e `test_path`. Depois de rodar `auto_test()`, os testes do exercício são executados automaticamente toda vez que você atualizar ou salvar seu código R para o exercício. Isso ajuda a iterar rapidamente enquanto você trabalha na sua solução.
