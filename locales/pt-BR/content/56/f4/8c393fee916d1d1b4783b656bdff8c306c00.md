# Instruções

Neste exercício, você vai escrever código para imprimir crachás de funcionários de uma fábrica. Cada funcionário tem um ID, um nome e o nome do departamento. Os rótulos dos crachás são formatados assim: `"[id] - name - DEPARTMENT"`.

## 1. Imprima um crachá para um funcionário

Implemente a função `NameBadge.print/3`. Ela deve receber um ID, um nome e um departamento. Ela deve retornar o rótulo do crachá, com o nome do departamento em letras maiúsculas.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Imprima um crachá para um novo funcionário

Por causa de uma peculiaridade no sistema do computador, às vezes os novos funcionários ainda não têm um ID quando começam a trabalhar na fábrica. Como os crachás são obrigatórios, eles recebem um crachá temporário sem o prefixo de ID.

Estenda a função `NameBadge.print/3`. Quando o ID estiver ausente, ela deve imprimir um crachá sem ele.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Imprima um crachá para o dono

Até o dono da fábrica precisa usar um crachá o tempo todo. No entanto, o dono não tem um departamento. Nesse caso, o rótulo deve imprimir `"OWNER"` no lugar do nome do departamento.

Estenda a função `NameBadge.print/3`. Quando o departamento estiver ausente, considere que o crachá pertence ao dono da empresa.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Repare que é possível que o dono também seja um novo funcionário.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
