# Sobre

As [listas][list] são um tipo de dados básico em Haskell para guardar uma coleção de valores.
As listas são _imutáveis_, ou seja, não podem ser modificadas.
Qualquer operação que altere uma lista retorna uma lista nova.
Existem vários métodos no Prelude que permitem trabalhar com listas.

Em Haskell, as listas são implementadas como [listas encadeadas][linked-list-wiki], e não como arrays de posições contíguas de memória.
Por isso, acessar um elemento de uma lista leva tempo linear, dependendo do tamanho da lista.

As listas podem ser escritas na forma literal, na notação cabeça-cauda (que usa o operador `cons` `:`), ou em uma combinação das duas:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

A notação cabeça-cauda pode ser usada para adicionar itens ao final de uma lista.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Adicionar elementos ao final de uma lista durante uma iteração é considerado um antipadrão.
Adicionar um elemento ao final exige percorrer a lista inteira e inserir o elemento no fim. Por isso, adicionar um elemento novo a cada iteração exigiria percorrer a lista inteira em cada iteração.

Dá para chegar ao mesmo resultado adicionando um elemento ao início da lista invertida e depois invertendo o resultado. Adicionar no início é uma operação rápida e leva tempo constante.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Existem várias funções comuns do Prelude para listas:

- [`head`][head] retorna a _cabeça_ de uma lista, o _primeiro_ item dela.
- [`tail`][tail] retorna a _cauda_ da lista, ou seja, a lista _sem_ o _primeiro_ item.
- [`length`][length] retorna o número de itens da lista.
- [`elem`][elem] retorna um valor boolean que indica se o item é um elemento da lista.

Existe também o [módulo `Data.List`][list].

## Tipos de lista

Em Haskell, as listas são **homogêneas**.
Isso significa que todos os elementos de uma lista têm o mesmo tipo.
Quando você tenta colocar elementos de tipos diferentes na mesma lista, você recebe um erro de tipo.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

A anotação de tipo de uma lista é `[a]`, em que a é o tipo que a lista guarda, por exemplo `String` ou `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
