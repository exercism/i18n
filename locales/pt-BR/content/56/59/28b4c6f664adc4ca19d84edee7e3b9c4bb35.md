# Parâmetros variádicos

[_Parâmetros variádicos_][variadic-parameters] no Swift permitem que zero ou mais valores do mesmo tipo sejam passados para um único parâmetro de uma função. Isso é indicado acrescentando `...` à anotação de tipo do parâmetro.

Esses valores são agrupados automaticamente em um array cujos elementos têm o mesmo tipo do parâmetro variádico.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Repare que, ao usar parâmetros variádicos, o Swift tem uma limitação.
Se uma função tem parâmetros que vêm depois do parâmetro variádico na definição, o primeiro parâmetro após o parâmetro variádico _precisa_ ter um rótulo de argumento.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
