# Sobre

Em Haxe, as exceções são uma forma segura de lidar com erros que ocorrem ao rodar o código. Todas as exceções devem conter uma mensagem que descreve o erro. Podemos _lançar_ exceções usando a palavra-chave `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Quando uma exceção é lançada, o código procura um trecho designado para tratar o erro. Se não encontrar nenhum, exibe a mensagem de erro e também interrompe a execução do programa.

Para tratar exceções em Haxe, usamos o bloco `try-catch`. Essa instrução de bloco consiste em um bloco `try` e um ou mais blocos `catch`. O bloco `try` _tenta_ executar um trecho de código, enquanto o bloco `catch` fica aguardando caso alguma exceção seja lançada, para _capturá-la_, de modo que a execução não seja interrompida. Quando o bloco `catch` captura uma exceção, ele também executa tudo o que está dentro do bloco:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

O tipo do argumento do bloco `catch` deve ser omitido.

É importante notar que as exceções devem ser usadas em casos em que algo excepcional acontece, um erro que precisa de tratamento especial. Elas não devem ser usadas para o fluxo de controle de um programa, pois isso é considerado um design ruim, que costuma levar a problemas de desempenho e de manutenibilidade.
