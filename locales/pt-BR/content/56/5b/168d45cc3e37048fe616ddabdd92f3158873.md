# Introdução

Go é tipado estaticamente, então toda variável tem um tipo conhecido em tempo de compilação.
Depois de declarada, o tipo de uma variável não pode mudar.

## Criando uma variável

A instrução `var` pode declarar o tipo de uma nova variável, definir o valor dela, ou fazer as duas coisas ao mesmo tempo:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

Dentro de uma função, também é possível usar a instrução de atribuição curta `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

Uma variável em Go sempre tem um valor.
Se nenhum for definido na declaração, o Go fornece um [chamado valor zero][zero-values], com base no tipo da variável.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Atualizando uma variável

Dentro de uma função, o operador de atribuição `=` pode definir um novo valor para uma variável existente:

```go
count := 1
count = 2
```

O novo valor precisa ter o mesmo tipo da variável:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
