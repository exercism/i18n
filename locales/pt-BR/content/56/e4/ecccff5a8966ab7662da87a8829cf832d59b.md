# Introdução

Uma expressão Boolean é uma pergunta feita sobre um ou mais valores, que pode ser respondida com verdadeiro ou falso.
Uma expressão verdadeira retorna `1`; uma expressão falsa retorna `0`.
Além disso, os números também têm valores verdadeiro/falso. Zero é falso; qualquer valor diferente de zero é verdadeiro.

O código C antigo ou usa o tipo `int` diretamente para valores Boolean, ou o programador pode ter definido constantes como `TRUE` e `FALSE` para mapear `1` e `0` para uma representação Boolean.

Com a versão C99, foi adicionado o tipo `_Bool`.
O arquivo de cabeçalho `stdbool.h` define três novos símbolos Boolean: `bool`; `true` e `false`.
`true` mapeia para `1`; `false` mapeia para `0`; e `bool` mapeia para `_Bool`.
Então agora, em vez de usar `int`s diretamente ou criar os próprios mapeamentos Boolean, os programadores podem incluir `stdbool.h` e obter automaticamente símbolos Boolean no seu código.

## Operadores de comparação

C oferece suporte a seis operadores de comparação: `==` (igual), `!=` (diferente), `>` (maior que), `<` (menor que), `>=` (maior ou igual a), `<=` (menor ou igual a).
Esses operadores comparam as relações entre valores e as resolvem em valores Boolean.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Operadores Boolean

C oferece suporte a três operadores Boolean: `||` (ou), `&&` (e) e `!` (não).

O `!` é usado com um operando.
Ele inverte o valor Boolean do operando.
Por exemplo, `0` é falso, mas `!0` é verdadeiro.

O `||` e o `&&` são usados com dois operandos.
O operando à direita só é avaliado quando o operando à esquerda ainda não determina o resultado da expressão.
Ou seja, o `||` só avalia o operando à direita quando o operando à esquerda é avaliado como falso.
O `&&` só avalia o operando à direita quando o operando à esquerda é avaliado como verdadeiro.
