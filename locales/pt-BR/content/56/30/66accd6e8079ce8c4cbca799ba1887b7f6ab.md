# Instruções adicionais

## `Print` não coloca aspas em valores de string

Este exercício envolve manipular pontuações numéricas.
#[a: 1]` and `#[a: "1"]` não são a mesma coisa:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

Uma prática comum de depuração é usar `print` nos valores.
No entanto, a saída não adiciona aspas ao redor das strings.
Por isso, uma string numérica como `"1"`, quando impressa, aparece igual ao inteiro `1`.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
Na saída dos testes deste exercício, você pode ver um resultado como `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`.
Os dois dicionários comparados parecem iguais quando impressos.
No entanto, o primeiro dicionário tem valores de string numéricos e o segundo tem valores inteiros, então eles não são iguais. 
Ao depurar, você pode usar `inspect` para verificar o conteúdo do seu dicionário.

## `Express` coloca aspas em valores de string

`express` converte um valor em código Arturo e retorna uma string com essa representação de código.
Nesse resultado, todos os valores de string aparecem entre aspas.
Como resultado, `express "1"` retorna `"1"`, e não `1`.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
