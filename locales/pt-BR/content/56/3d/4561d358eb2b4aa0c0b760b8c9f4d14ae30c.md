# Aprendizado

Se você quiser aprender TypeScript, confira os recursos a seguir.

- [Tutorial de TS](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)

TypeScript é um superconjunto do JS.
TypeScript oferece todos os recursos do JavaScript e uma camada adicional por cima deles: o sistema de tipos do TypeScript.
