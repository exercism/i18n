# Instruções

Seu amigo acabou de enviar uma mensagem com um segredo importante.
Para não facilitar a leitura por outras pessoas, a mensagem foi criptografada com uma série de manipulações de bits.
Você vai precisar escrever as funções que ajudam a descriptografar a mensagem.

## 1. Desloque os bits de volta

O primeiro passo para descriptografar a mensagem é desfazer o deslocamento do processo de criptografia, deslocando os bits de volta para a direita.
Haverá outros passos no processo de descriptografia que presumem que `0`s são inseridos pelo lado esquerdo.

Implemente a função `shiftBack`, que recebe um número de posições a deslocar e um valor, e realiza o deslocamento.

```elm
shiftBack 2 42 --> 10
```

## 2. Defina alguns bits

Em seguida, há alguns bits que precisam ser definidos como `1`.

Implemente a função `setBits`, que recebe uma máscara e um valor e retorna o resultado de definir como `1` os bits do valor.
Um bit do valor deve ser definido como `1` onde o bit na máscara também for `1`.
Todos os outros bits devem permanecer inalterados.

```elm
setBits 66 212 --> 64
```

## 3. Inverta bits específicos

Alguns bits são invertidos durante a criptografia.
Será preciso invertê-los de volta para descriptografar a mensagem.

Implemente a função `flipBits`, que recebe uma máscara e um valor.
A máscara indica quais bits do valor devem ser invertidos.
Se o bit for `1` na máscara, o bit é invertido no valor.
Todos os outros bits permanecem inalterados.

```elm
flipBits 23 157 --> 138
```

## 4. Limpe bits específicos

Também há certos bits que sempre resultam em 0 ao serem descriptografados.

Implemente a função `clearBits`, que recebe uma máscara e um valor.
Os bits em `value` devem ser definidos como 0 onde o bit na máscara for 1.
Todos os outros bits devem permanecer inalterados.

```elm
clearBits 2 15 --> 13
```

## 5. Descriptografe uma mensagem

Agora que você já tem todas as funções de que precisa, pode decodificar a mensagem do seu amigo.
Implemente a função `decrypt`, que realiza as seguintes operações:

1. Defina os bits a partir do ano em que seu amigo nasceu (1996)
2. Inverta o resultado com o ano em que vocês se conheceram (2009)
3. Desloque os bits de volta pela quantidade de aulas que vocês têm juntos (5)
4. Limpe o primeiro e o quinto bit.

```elm
decrypt 380182 --> 11840
```

Implemente `decrypt` usando todas as funções que você implementou nas tarefas anteriores.
