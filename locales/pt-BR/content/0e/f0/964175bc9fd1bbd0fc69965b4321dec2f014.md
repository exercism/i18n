# Introdução

Uma propriedade em C# é um membro de uma classe que dá acesso aos dados dentro dessa classe. Quem chama pode definir ou recuperar (obter) esses dados. As propriedades podem ser autoimplementadas ou ter um campo de suporte. Elas são formadas por um acessador set e/ou um acessador get.
Em algumas outras linguagens, um "mutator" é mais ou menos equivalente a
um acessador set, e um "accessor" é mais ou menos equivalente a um acessador get, embora
a composição da sintaxe seja completamente diferente.

Ao definir uma propriedade, o valor de entrada pode ser validado, formatado
ou manipulado de outras formas e, na verdade, qualquer operação programática acessível ao código da
classe pode ser executada.

Do mesmo modo, ao recuperar uma propriedade, os dados podem ser calculados ou formatados e, mais uma vez,
qualquer operação programática disponível para a classe pode ser executada.

As propriedades têm modificadores de acesso (`public`, `private` etc.) da mesma forma que os outros
membros da classe, mas o acessador set pode ter um nível de acesso independente do acessador
de leitura (get), e vice-versa. Uma propriedade não precisa ter os dois acessadores: pode ter apenas um (get ou set).

A sintaxe básica para expressar propriedades pode assumir duas formas:

## Propriedades baseadas em campo/expressão:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## Propriedades autoimplementadas

```
public int MyProperty { get; private set; } = 42;
```

A inicialização é opcional.
