# Manipulação de tipos

Manipulação de tipos também pode ser conhecida como coerção de tipos.
A manipulação de tipos acontece quando dois valores de tipos diferentes são convertidos para o mesmo tipo para realizar uma operação.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Isso pode acontecer de forma implícita (veja o exemplo acima) ou explícita, com uma conversão de tipos no estilo de `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Os tipos permitidos na conversão manual de tipos são: `bool`, `int`, `float`, `string`, `array`, `object`.
Na maioria dos casos, a conversão de tipos é usada para transformar um número inteiro (`int`) em um número de ponto flutuante (`float`) ou vice-versa.
