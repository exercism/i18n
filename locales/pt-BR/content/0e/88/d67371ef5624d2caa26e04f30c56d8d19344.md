# Dicas

Usar números complexos para rotações em 2D pode deixar as coisas bem mais limpas e numericamente mais precisas.

## 1. Construir um número complexo a partir de coordenadas cartesianas

- O método [`complex(x, y)`][complex] já vem embutido e é mais eficiente do que atribuir `x + im*y`.
- Consulte a introdução para revisar.

## 2. Construir um número complexo a partir de coordenadas polares

- Existem algumas formas equivalentes de fazer isso (por exemplo, `exp`, `cis`, `cispi`).
- Consulte a introdução e as instruções para revisar melhor.

## 3. Realizar uma rotação de vetor em 2D

- A [fórmula de Euler][euler] é sua aliada aqui, e você pode usar sua função `euler`.
- Existem métodos para obter a parte [real][real] e a parte [imaginária][imaginary] de um número complexo, ou as duas de uma vez!

## 4. Realizar um deslocamento radial

- Sua função `euler` pode ser útil, ou não...
- O método [`angle`][angle] embutido pode ser usado para encontrar rapidamente um argumento a partir de um número complexo.
- O método [`abs`][abs] pode ser usado para encontrar o módulo de um número complexo.

## 5. Encontrar a música desejada

- Esta é uma boa oportunidade para compor suas funções `rotate` e `rdisplace`.
