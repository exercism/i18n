# Recursos

- [The Zig Programming Language Documentation][documentation] é uma ótima visão geral de todos os recursos da linguagem que o Zig oferece a quem a usa.
- [The Zig Standard Library][std] é uma boa referência para aprender como o código Zig é escrito e mostra muitas das funções que você pode importar para o seu próprio código.
- [Awesome Zig][awesome-zig] é uma lista curada de projetos Zig.
- [#zig][irc] no irc.freenode.net é o principal canal IRC do Zig.
- [Stack Overflow][stack-overflow] pode ser usado para descobrir trechos de código e soluções para problemas que talvez já tenham sido perguntados e até resolvidos por outras pessoas.
- [/r/Zig][reddit] é o principal subreddit do Zig.
- [The Zig Programming Language Discord][discord-zig] é o principal [Discord][discord].
  É uma ótima maneira de entrar em contato com a comunidade Zig em geral e conseguir ajuda rápida e direta para qualquer problema relacionado a Zig.
- [The Zig SHOWTIME Newsletter][newsletter] anuncia novos episódios, eventos importantes e links para projetos Zig novos e interessantes.
