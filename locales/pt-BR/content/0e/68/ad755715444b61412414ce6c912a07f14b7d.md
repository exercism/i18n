# Introdução

Os operadores ternários permitem definir condições `if` em expressões, em vez de blocos de instruções. Isso ecoa abordagens de programação funcional e muitas vezes deixa o código mais expressivo e menos propenso a erros.

O operador ternário combina 3 expressões: uma condição seguida de uma expressão que será avaliada e retornada se a condição for verdadeira (a parte do `if`, introduzida por `?`) e uma expressão que será avaliada e retornada se a condição for falsa (a parte do `else`, introduzida por `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
