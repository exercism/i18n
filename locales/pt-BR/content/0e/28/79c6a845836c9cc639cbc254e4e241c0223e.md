# Introdução

Namespaces são uma forma de agrupar código relacionado e evitar conflitos de nomes, e estão geralmente presentes em praticamente qualquer base de código, por mais simples que seja.

A sintaxe é a seguinte:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

Fora do escopo de um namespace, os tipos declarados dentro dele são referenciados prefixando o nome do tipo com a sintaxe de ponto. Como alternativa, e mais comumente, você pode colocar uma diretiva `using` no topo do arquivo (ou dentro de um namespace) e usar o tipo sem o prefixo. Dentro do mesmo namespace, não é preciso qualificar os nomes dos tipos.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

Você pode criar um alias para um namespace com a sintaxe `using MyAlias = MySpace;` e depois usar o alias em qualquer lugar onde o namespace poderia ser usado.
