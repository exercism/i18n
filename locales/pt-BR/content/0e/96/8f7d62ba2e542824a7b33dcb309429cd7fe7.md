# Testes

## Rodando os testes

Para rodar os testes, execute o seguinte comando no diretório do exercício:

```shell
make
```

Isso monta a sua solução, compila os testes, liga tudo em um programa RISC-V e o executa sob o `qemu-riscv32`.
O programa imprime uma linha para cada teste, mostrando se ele passou, falhou ou foi ignorado, e depois um resumo.

## Resolvendo o exercício

Resolver um exercício significa fazer com que todos os seus testes passem.
Por padrão, só um teste (o primeiro) é executado quando você roda os testes.
Isso é intencional: assim você pode focar em fazer apenas esse teste passar.
Quando ele passar, você pode habilitar o próximo teste removendo a linha `TEST_IGNORE();`.
Quando todos os testes estiverem habilitados e a sua implementação fizer todos eles passarem, você terá resolvido o exercício!
