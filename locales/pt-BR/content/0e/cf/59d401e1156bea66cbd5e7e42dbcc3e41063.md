# Introdução

Caracteres individuais em uma `String` podem ser acessados usando o método de subscrição usado com arrays.
No entanto, os [índices][string-indices] usados para strings _não_ são inteiros e não podem ser usados diretamente.
Em vez disso, eles precisam ser calculados a partir de algum outro índice conhecido, como `startIndex`, que aponta para a posição do primeiro caractere em uma string não vazia, usando os métodos disponíveis nas bibliotecas [`String`][string-docs] e [`NSString`][nsstring-docs] (quando o módulo `Foundation` é importado, as strings em Swift têm acesso a todas as propriedades e métodos de NSString).

Por exemplo, dada a seguinte string:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Não se pode escrever `csv[21]` para obter o "g" em "orange"; em vez disso, é preciso calcular um valor do tipo `String.Index` e fornecer esse índice.
Observe que esses índices não se destinam a ser consumidos por humanos por conta própria.
Eles são o que se chama de _índices opacos_, pois os humanos não precisam saber o que há dentro deles.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Observe, no entanto, que se o deslocamento não for um índice válido, ou seja, se ele retornar o índice antes de `startIndex` ou depois de `endIndex`, a operação vai gerar um erro, travando o programa.
Para evitar esse problema, é possível especificar um índice limitante.
Isso retorna um índice opcional e vai retornar nil para índices que de outra forma seriam inválidos.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Além disso, índices não podem ser compartilhados entre strings.
Por exemplo, usar o `index` do "g" em "orange" calculado acima para indexar a string `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, ou seja, `fam[index]`, vai travar o seu programa.

Há muitos motivos para tudo isso, mas basicamente todos se resumem a "Unicode é complicado".

De modo geral, se você precisa de acesso aleatório a caracteres individuais, provavelmente vai querer usar alguma outra estrutura de dados, como `Array<Character>`.

## Alguns métodos úteis

Swift tem os métodos `first` e `last` para obter o primeiro e o último caractere de uma string.
Esses métodos retornam um caractere opcional, então, se a string estiver vazia, eles retornam nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Você também pode usar os métodos `prefix` e `suffix` para obter uma substring de uma string.
Esses métodos recebem um número inteiro como argumento e retornam uma substring contendo os primeiros ou os últimos n caracteres da string.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
