# Sobre

Um número de ponto flutuante é um número com zero ou mais dígitos depois do separador decimal.
Exemplos são `4.0`, `0.1`, `3.14`, `-6.4`, `16.984025` e `1024.0`.
No Ruby, os números de ponto flutuante são implementados através da classe [Float][Float].

Você pode encontrar uma introdução curta sobre números de ponto flutuante em [0.30000000000000004.com][0.30000000000000004.com].

A [página do Float Toy][evanw.github.io-float-toy] tem uma explicação gráfica bacana de como os bits de um número de ponto flutuante são convertidos em um valor de ponto flutuante de verdade.

Para executar uma lógica repetidamente, pode-se usar laços.
Neste exemplo, o laço `while` é útil porque ele continua repetindo _enquanto_ uma condição for avaliada como algum valor truthy (ou seja, que não seja `false` nem `nil`).
O Ruby implementa um laço parecido com o laço `while`.
Ele se chama laço `until`, e você provavelmente já imaginou o que ele faz.
Ele continua repetindo _até_ que uma condição booleana seja avaliada como `true`.
Em algumas linguagens, para fazer um trecho de código executar um número ilimitado de vezes, usam-se construções como `while true`.
No Ruby, o laço `loop` existe para essa finalidade.
Mesmo que o laço `loop` não dependa de uma única condição, ele pode ser cancelado usando a palavra-chave `return` ou `break`.

O método `#years_before_desired_balance` do exercício anterior poderia ter sido escrito usando qualquer um dos três laços mencionados:

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

Como você provavelmente já notou, o Ruby não tem um operador de incremento (`i++`) como algumas outras linguagens têm.
Em vez disso, pode-se usar construções como `i += 1` (que é igual a `i = i + 1`).
