# Introdução

Um `Map` é usado para armazenar pares de **chave** e **valor**. Os `Maps` são inicializados da mesma forma que um array, mas usam o operador de literal de map `=>`. Também é possível definir explicitamente os tipos de chave e valor, ou deixar que os tipos sejam inferidos. As chaves precisam ser únicas, caso contrário um erro é lançado.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

É possível iterar sobre um `Map` usando um laço `for`. Você pode iterar sobre os valores ou sobre as chaves:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
