# Introdução

A classe `str` oferece [muitos métodos úteis][str methods] para trabalhar com strings e compô-las.
Entre eles estão buscar, limpar, dividir, transformar, traduzir e muitas outras técnicas.

Strings são [sequências][text sequence] de [pontos de código Unicode][unicode code points]: "caracteres" individuais, ou pontos de código (_strings de comprimento 1_), podem ser referenciados por um número de `0-based index` a partir da esquerda, ou de `-1-based index` a partir da direita.
Strings implementam todas as [operações comuns de sequência][common sequence operations].

Elas podem ser percorridas com a sintaxe `for item in <str>` ou `for index, item in enumerate(<str>)`.
Também podem ser concatenadas com `<str> + <other str>` ou `<str>.join(<iterable>)`.

Strings são _imutáveis_: o valor de um objeto `str` na memória não pode mudar.
Funções ou métodos que operam sobre uma `str` (_como os que estamos aprendendo aqui_) retornam uma nova `instance` desse objeto `str`, em vez de modificar a `str` original.

A seguir, uma pequena seleção de métodos de string do Python.
Para uma lista completa, consulte a [classe str][str methods] na documentação do Python.


[`<str>.title()`][str-title] analisa uma string e coloca em maiúscula o primeiro "caractere" de cada "palavra" encontrada.
No Python, isso depende muito do [codec de idioma][codecs] usado e de como o idioma em questão representa palavras e caracteres.
Também pode haver regras de [locale][locale] para um idioma ou conjunto de caracteres.


```python
man_in_hat_th = 'ผู้ชายใส่หมวก'
man_in_hat_ru = 'мужчина в шляпе'
man_in_hat_ko = '모자를 쓴 남자'
man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```

[`<str>.endswith(<suffix>)`][str-endswith] retorna `True` se a string termina com `<suffix>`, e `False` caso contrário.


```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.strip(<chars>)`][str-strip] retorna uma cópia da `str` com os `<chars>` iniciais e finais removidos.
Os pontos de código especificados em `<chars>` não são um prefixo nem um sufixo: **todas as combinações** dos pontos de código serão removidas a partir das **duas extremidades** da string.
Se nada for especificado para `<chars>`, todas as combinações de pontos de código de espaço em branco serão removidas.


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace] retorna uma cópia da string com todas as ocorrências de `<substring>` substituídas por `<replacement substring>`.

A citação usada abaixo é de [The Hunting of the Snark][The Hunting of the Snark], de [Lewis Carroll][Lewis Carroll].

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```
