# Apêndice de instruções

Cada lista de entradas é representada como uma string, com um caractere de nova linha no final de cada entrada.

Um exemplo seria `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

Cada linha de saída deve terminar com um caractere de nova linha `\n`.

## Memória reservada

Os bytes 128-383 da memória linear são reservados para a string de entrada.
