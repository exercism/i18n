# Sobre

A [_sobrecarga de métodos_][member-overloading] permite que vários métodos na mesma classe tenham o mesmo nome. Os métodos sobrecarregados precisam ser diferentes entre si por:

- O número de parâmetros
- O tipo dos parâmetros

Não existe sobrecarga de métodos com base no tipo de retorno.

O compilador vai inferir automaticamente qual método sobrecarregado chamar [com base no número de parâmetros e no tipo deles][overloading].

[member-overloading]: https://docs.microsoft.com/en-us/dotnet/standard/design-guidelines/member-overloading
[overloading]: https://csharpindepth.com/articles/Overloading
