# Introdução

Uma *tupla* agrupa vários valores nomeados em um único objeto, o que outras linguagens chamam de record, struct ou classe. Cada classe de tupla tem um conjunto fixo de slots nomeados, e o Factor gera automaticamente os getters e setters correspondentes.

## Definindo uma tupla

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

Cada slot é declarado como `{ name initial: default-value }`. Sem uma cláusula `initial:`, o padrão é `f`.

## Construindo uma tupla

O construtor mais simples é `new`:

```factor
point new .
! => T{ point }
```

`boa` ("por ordem de argumentos") preenche os slots na ordem de declaração, a partir da pilha de dados:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

A sintaxe literal `T{ class { slot value } … }` permite construir uma tupla com apenas um subconjunto dos slots definidos, e é impressa da mesma forma:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Quando o valor de um slot coincide com o padrão, ele é omitido na impressão.

## Lendo um slot

O Factor gera um getter `slot>>` para cada slot. Os getters ficam em [`accessors`][accessors]:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Atualizando um slot

Os setters são escritos `>>slot` e *modificam* a tupla no lugar:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Para deixar o original intacto, use `clone` primeiro:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` recebe uma quotation que mapeia o valor atual para o novo:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x` também modifica a tupla, então use `clone` antes de chamá-la se quiser preservar o original.
