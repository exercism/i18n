# Sobre

Imagine que você tem uma base de código com várias centenas de milhares de linhas. O dicionário de desenvolvedores é passado para um método que você está desenvolvendo. Talvez você tenha recebido a tarefa de imprimir os detalhes de desenvolvedores privilegiados. Você decide apagar a cor dos olhos no dicionário para proteger a privacidade dos desenvolvedores. A menos que uma [cópia profunda][so-deep-copy] do dicionário tenha sido feita no método `Authenticator.GetDevelopers()` ou, melhor ainda, que ele tenha sido colocado dentro de uma coleção somente leitura, você terá simplesmente arruinado o autenticador.

Isso segue o princípio da [cópia defensiva][defensive-copying]. Você pode garantir que a sua API formal não seja contornada evitando expor aos chamadores o estado interno que pode ser modificado.

[so-deep-copy]: https://stackoverflow.com/questions/78536/deep-cloning-objects
[defensive-copying]: https://www.informit.com/articles/article.aspx?p=31551&seqNum=2
