# Complemento das instruções

## Formato da saída

A saída deve ser uma string terminada em nulo, usando uma vírgula e um espaço como separadores.

Um exemplo de saída seria `"491, 914, 142"`

Se a entrada for inválida, a saída deve ser uma string vazia.

## Registradores

| Registrador | Uso          | Tipo    | Descrição                          |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | entrada        | endereço | string de série terminada em nulo  |
| `$a1`    | entrada        | inteiro | comprimento da fatia                   |
| `$a2`    | entrada/saída | endereço | string de saída terminada em nulo  |
| `$t0-9`  | temporário    | qualquer     | usado para armazenamento temporário     |
