# Aprendendo Visual Basic

## Sites

O Visual Basic evoluiu bastante ao longo dos anos, e muitos tutoriais de terceiros se referem a ferramentas ou recursos desatualizados.
A [documentação oficial do Visual Basic](https://learn.microsoft.com/en-us/dotnet/visual-basic/) é o lugar mais atual e confiável para começar sua jornada.

## O ecossistema .NET

O Visual Basic roda no runtime .NET, compartilhando boa parte da funcionalidade básica com C# e F#.
Portanto, entender como o .NET funciona vai fazer você programar em VB com mais segurança.

- [O que é .NET?](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [O glossário do .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [O Sistema de Tipos Comuns (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
