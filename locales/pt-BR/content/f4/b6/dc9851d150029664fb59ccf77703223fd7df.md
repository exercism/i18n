# formato do kernel

Além do método `format`, uma forma comum de criar strings em Ruby é usar [interpolação de strings](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Por exemplo:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
