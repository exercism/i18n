# Instruções

Ninguém sobe no trapézio do circo antes que as verificações de segurança passem.
Você está registrando essas verificações por escrito para que as mesmas regras valham para todo mundo.

As cinco tarefas ficam na classe `SAFETY_CHECK`.

## 1. O tapete está pronto?

O tapete está pronto somente quando está no chão e limpo.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. Há algo para amortecer a queda?

É preciso ter um tapete embaixo, ou uma rede embaixo. Qualquer um dos dois serve, e ter os dois não tem problema.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. Quem ainda precisa do briefing?

Quem ainda não recebeu o briefing precisa dele.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. Esse artista tem idade suficiente?

O trapézio é para artistas de 13 anos ou mais.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. Junte tudo

Um artista está liberado para o trapézio quando tem idade suficiente, já recebeu o briefing e o tapete está pronto.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

Os quatro argumentos são a idade, se a pessoa já recebeu o briefing, se o tapete está no chão e se o tapete está limpo.
