# Introdução

Uma tupla é um contêiner ordenado de valores. Como todos os tipos de dados do Gleam, as tuplas são imutáveis. Cada elemento de uma tupla pode ser de um tipo diferente, e podem até ser outras tuplas.

As tuplas são definidas como valores separados por vírgula entre `#(` e `)`: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Tuplas com o mesmo tamanho e os mesmos tipos (na mesma ordem) podem ser comparadas quanto à igualdade.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Há três maneiras de extrair os valores contidos em uma tupla:

- Indexação.
- Correspondência de padrões com `let`.
- Correspondência de padrões com `case`.

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
