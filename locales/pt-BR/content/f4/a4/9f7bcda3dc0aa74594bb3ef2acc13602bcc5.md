# Aprendizado

Cairo é a primeira linguagem Turing-completa para criar programas comprováveis para computação geral. É uma linguagem de alto nível, parecida com Rust. Assim como Rust, ela foi pensada para permitir que desenvolvedores escrevam com facilidade um código eficiente e seguro.

Acreditamos que a melhor forma de aprender é brincar e praticar, seja criando seus próprios projetos de programação, seja resolvendo problemas pequenos como os daqui do Exercism!

Abaixo estão alguns recursos que podem ajudar você a dar o pontapé inicial na sua jornada com Cairo:

- [Cairo Programming Language](https://www.cairo-lang.org/) apresenta a linguagem Cairo e lista muitos recursos relevantes para aprender e usar Cairo.
- [The Cairo Book](https://book.cairo-lang.org/) é um ótimo recurso para aprender Cairo e também para se aprofundar em funcionalidades específicas de Cairo.
- [Cairo Documentation](https://docs.cairo-lang.org/) explica as construções e a semântica da linguagem.
- [Cairo by Example](https://cairo-by-example.com/) mostra exemplos das coisas mais comuns que você vai escrever em Cairo.
- [Node Guardians](https://nodeguardians.io/campaigns?f=3%3D2) "Uma plataforma de aprendizado com tema de fantasia para desenvolvedores de contratos inteligentes."
- O [Cairo Community Forum](https://community.cairo-lang.org/) responde a perguntas de todos os níveis.
