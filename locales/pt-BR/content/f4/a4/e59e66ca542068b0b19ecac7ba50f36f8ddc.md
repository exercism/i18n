# Desestruturação

A desestruturação é o processo de dividir itens em suas partes componentes e associar cada uma a variáveis menores.

## Desestruturação de tuplas

Desestruturar tuplas é simples: basta atribuir novos nomes de variável a cada campo da tupla:

```rust
let (first, second) = (1, 2);
```

## Desestruturação de structs de tupla

Desestruturar structs de tupla é idêntico a desestruturar tuplas, mas com o nome da struct junto:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## Desestruturação de structs

Desestruturar structs é parecido com desestruturar structs de tupla. Basta usar os nomes dos campos:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## Desestruturação parcial

O operador `..` pode ser usado para ignorar alguns campos na hora de desestruturar:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## Desestruturação condicional

Desestruturar structs e tuplas é infalível. No entanto, enums também podem ser desestruturados, usando as construções `if let`, `while let` e `match` da linguagem.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
