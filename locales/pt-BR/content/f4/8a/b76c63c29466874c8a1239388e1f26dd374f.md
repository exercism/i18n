# Sobre

Blocos são pequenos agrupamentos de instruções que podem ser executados várias vezes. Podem ser vistos como closures ou funções anônimas. Os blocos são definidos com a sintaxe `do...end` (acima) ou `{}` (abaixo). Os estilos são intercambiáveis e existem opiniões divergentes sobre quando usar cada um.

## Sintaxe abreviada

Quando um bloco chama um único método, você pode substituir o bloco por `&:` seguido do nome do método. Por exemplo, estas duas linhas são sinônimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
