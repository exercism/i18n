# Introdução

Uma *tupla* é o tipo de registro/struct/classe do Factor. Cada classe de tupla
tem um conjunto fixo de fendas nomeadas, e o Factor gera automaticamente os
getters e setters para elas.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa` ("pela ordem dos argumentos") preenche as fendas a partir da pilha, na
ordem de declaração. `new` constrói uma instância com cada fenda no valor
`initial:` declarado (ou `f`, se não houver nenhum).

O getter de cada fenda é `slot>>` e o setter é `>>slot`. O setter *muta*, então
use `clone` primeiro se precisar de uma atualização não destrutiva:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Os valores padrão das fendas usam `{ name initial: value }`; sem `initial:`,
o padrão é `f`.
