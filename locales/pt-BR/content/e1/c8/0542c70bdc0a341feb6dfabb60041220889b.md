# Dicas

## Geral

- Leia sobre recursão no [guia de primeiros passos][getting-started-recursion] oficial.
- Leia sobre recursão no [elixirschool.com][elixir-school-recursion].
- Use funções com múltiplas cláusulas e casamento de padrões.
- Tente dividir um problema em um caso base e um caso recursivo. Por exemplo, digamos que você queira contar quantos biscoitos há no pote de biscoitos com uma abordagem recursiva. O caso base é um pote vazio: ele tem zero biscoitos. Se o pote não estiver vazio, então o número de biscoitos no pote é igual a um biscoito mais o número de biscoitos no pote depois de remover um biscoito.

## 1. Verifique quantos pássaros visitaram hoje

- Essa tarefa não precisa de recursão.
- Você pode acessar o primeiro elemento de uma lista com [casamento de padrões][getting-started-pattern-matching].

## 2. Incremente a contagem de hoje

- Essa tarefa não precisa de recursão.
- Você pode acessar o primeiro elemento de uma lista com [casamento de padrões][getting-started-pattern-matching].

## 3. Verifique se houve um dia sem pássaros visitantes

- Use recursão para iterar sobre os elementos da lista até encontrar um dia sem pássaros visitantes.
- O caso base é uma lista vazia.

## 4. Calcule o número total de pássaros visitantes

- Use recursão para iterar sobre cada elemento da lista.
- O caso base é uma lista vazia.

## 5. Calcule o número de dias movimentados

- Use recursão para iterar sobre cada elemento da lista.
- O caso base é uma lista vazia.
- Uma função pode ter mais de um caso recursivo.
- Use um [guard][kernel-equal-or-greater-than] para uma das cláusulas da função.
