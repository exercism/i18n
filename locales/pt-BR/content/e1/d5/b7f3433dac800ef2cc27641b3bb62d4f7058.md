# Introdução

Uma ferramenta importante para organizar o código são os namespaces.
Duas funções podem ter uma colisão de nomes, que pode ser resolvida colocando-as em namespaces diferentes.
Os namespaces podem ser aninhados, o que ajuda a estruturar bases de código grandes.
O acesso aos namespaces é feito pelo operador de resolução de escopo `::`.

O exemplo abaixo mostra o uso de duas funções `foo` diferentes.
Elas são usadas juntas prefixando os respectivos namespaces.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
