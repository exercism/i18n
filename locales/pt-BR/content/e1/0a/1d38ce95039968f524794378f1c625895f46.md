# Instruções

Neste exercício, você vai escrever código para ajudar uma empresa de letreiros a criar mensagens personalizadas para os seus letreiros.

## 1. Crie um letreiro de ocasião

Implemente o método `build_sign( )` que aceita uma string como parâmetro `occasion` e uma string com o nome de alguém como parâmetro `name`. Os dois parâmetros serão inseridos em um template de string para gerar a mensagem do letreiro.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Crie um letreiro de aniversário

Implemente o método `build_birthday_sign( )` que aceita uma idade e, com base nela, determina parte da mensagem do letreiro. Se a idade for 50 ou mais, o letreiro vai incluir a palavra _mature_; caso contrário, vai incluir a palavra _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Crie um letreiro de formatura

Implemente o método `graduation_for( )`, que recebe um nome como parâmetro de string e um ano como parâmetro numérico e usa templates de string para criar uma frase de letreiro que usa uma quebra de linha para separar as duas linhas da mensagem.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Calcule o custo de um letreiro

Implemente a função `cost_of( sign currency )` que recebe uma string com o conteúdo do letreiro e uma string que representa a moeda.
O letreiro tem um preço base de 20 na moeda informada. Além disso, cada letra custa 2. (Os espaços em branco entram no cálculo.)
A frase retornada inclui o custo de criação do letreiro, escrito com duas casas decimais, seguido da string da moeda.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
