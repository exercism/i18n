# Testes

Navegue até o diretório que contém o arquivo `${slug}_test.sql` correspondente, em que `${slug}` é o nome do exercício, com hífens no lugar dos espaços e tudo em minúsculas (por exemplo, `hello-world_test.sql` para o exercício `Hello World`).

```bash
sqlite3 -bail < ${slug}_test.sql
```

Você pode usar instruções `SELECT` para depurar.
A saída será encaminhada para `user_output.md` e exibida no editor web se os testes falharem.

Você encontra mais informações na [documentação do track de SQLite sobre testes](https://exercism.org/docs/tracks/sqlite/tests).
