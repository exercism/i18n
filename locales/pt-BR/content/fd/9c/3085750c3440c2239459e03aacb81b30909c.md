# Instruções

O sistema de autenticação que você viu pela última vez em [exercise:csharp/developer-privileges]() precisa de atenção. Sua tarefa é fazer uma limpeza no código. Um projeto de limpeza como esse não só vai facilitar a vida de quem for manter o código no futuro, como também vai revelar e corrigir algumas vulnerabilidades de segurança.

## 1. Definir campos e propriedades apropriados como const

Esta é uma tarefa de refatoração. Adicione o modificador `const` a qualquer membro de `Authenticator` ou `Identity` que você considere apropriado.

## 2. Definir campos apropriados como readonly

Esta é uma tarefa de refatoração. Adicione o modificador `readonly` a qualquer campo da classe `Authenticator` ou da struct `Identity` que você considere apropriado.

## 3. Garanta que a classe não possa ser alterada depois de criada

Remova o acessador `set` ou torne-o `private` em qualquer propriedade apropriada da classe `Authenticator` ou da struct `Identity`.

## 4. Garanta que não seja possível adulterar o admin

No momento, o campo de identidade do admin é retornado por uma chamada a `Admin`. Isso não é ideal, pois quem chama pode modificar o campo. Encontre uma forma de impedir que quem chama modifique os detalhes do admin no objeto `Authenticator`.

## 5. Garanta que não seja possível adulterar os desenvolvedores

No momento, o dicionário que contém as identidades privilegiadas de desenvolvedores definidas diretamente no código é retornado por uma chamada a `GetDevelopers()`. Isso não é ideal, pois quem chama pode modificar o dicionário. Encontre uma forma de impedir que quem chama modifique os detalhes dos desenvolvedores no objeto `Authenticator`.
