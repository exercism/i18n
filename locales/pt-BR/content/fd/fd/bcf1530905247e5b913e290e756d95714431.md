# Introdução

Um *heap* é uma coleção que sempre sabe qual é o seu menor item e permite removê-lo rapidamente. É a implementação natural de uma *fila de prioridade*. Os heaps ficam no vocabulário [`heaps`][heaps].

`<min-heap>` constrói um heap vazio cuja menor chave sai primeiro; `<max-heap>` é a imagem espelhada. Cada item é um *valor* guardado sob uma *chave*, e a chave é a prioridade:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Um heap é *mutável*: `heap-push` o altera no lugar. `heap-peek` retorna o valor e a chave da frente sem remover o item, `heap-pop` o remove e o retorna, e `heap-pop-all` esvazia o heap em uma lista de associações de pares `{ key value }` em ordem de prioridade:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
