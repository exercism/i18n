# Introdução

As palavras de sequência mais úteis recebem uma *quotation* como uma de suas entradas e a usam para conduzir a operação:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (também em `sequences`) mapeia uma quotation pela sequência e soma os resultados em uma única passagem. O mesmo padrão rege `sort-by` (em [`sorting`][sorting]) e `minimum-by` / `maximum-by` (em `sequences`).

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
