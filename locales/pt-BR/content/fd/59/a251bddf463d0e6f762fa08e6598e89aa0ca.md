# Instruções

Neste exercício, você vai escrever código para analisar a produção de uma linha de montagem em uma fábrica de carros. A velocidade da linha de montagem pode variar de `0` (desligada) a `10` (máxima).

Na velocidade mais baixa (`1`), são produzidos `221` carros por hora. A produção aumenta linearmente com a velocidade. Então, com a velocidade definida como `4`, ela deve produzir `4 * 221 = 884` carros por hora. No entanto, velocidades mais altas aumentam a probabilidade de que carros com defeito sejam produzidos, os quais precisam ser descartados.

Você tem três tarefas.

## 1. Calcule a taxa de sucesso

Implemente o método `success_rate()` para calcular a proporção de itens criados sem erro para uma determinada velocidade. A tabela a seguir mostra como a velocidade influencia a taxa de sucesso:

- `0`: 0% de taxa de sucesso.
- `1` a `4`: 100% de taxa de sucesso.
- `5` a `8`: 90% de taxa de sucesso.
- `9`: 80% de taxa de sucesso.
- `10`: 77% de taxa de sucesso.

```R
success_rate(10)
# => 0.77
```

## 2. Calcule a taxa de produção por hora

Implemente o método `production_rate_per_hour()` para calcular a taxa de produção por hora da linha de montagem, levando em conta sua taxa de sucesso:

```R
production_rate_per_hour(6)
# => 1193.4
```

Repare que o valor retornado é um `double`.

## 3. Calcule o número de itens funcionais produzidos por minuto

Implemente o método `working_items_per_minute()` para calcular quantos carros funcionais são produzidos por minuto:

```R
working_items_per_minute(6)
# => 19
```

Repare que o valor retornado é um número inteiro: itens incompletos não são incluídos.
