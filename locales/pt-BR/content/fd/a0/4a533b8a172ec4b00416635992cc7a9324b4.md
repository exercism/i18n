# Testes

Você pode rodar os testes abrindo um prompt de comando no diretório do exercício e, em seguida, rodando o [comando `dotnet test`](https://docs.microsoft.com/en-us/dotnet/core/tools/dotnet-test).
Como alternativa, a maioria das IDEs tem suporte integrado para rodar testes, incluindo o [Visual Studio](https://docs.microsoft.com/en-us/visualstudio/test/run-unit-tests-with-test-explorer), o [Rider](https://www.jetbrains.com/help/rider/Unit_Testing_in_Solution.html) e o [Visual Studio code](https://github.com/OmniSharp/omnisharp-vscode/wiki/How-to-run-and-debug-unit-tests).
Consulte a [página de testes](https://exercism.org/docs/tracks/csharp/tests) para mais informações.

## Testes ignorados

No começo, apenas o primeiro teste estará habilitado.
Isso é para incentivar você a resolver o exercício um passo de cada vez.
Quando você conseguir fazer o primeiro teste passar, remova a propriedade `Skip` do próximo teste e trabalhe para fazer esse teste passar.
