# Instruções

Você é um grande fã do [canal Numberphile no YouTube](https://www.youtube.com/watch?v=PeUbRXnbmms) e acabou de ver um vídeo muito legal sobre a _Sequência de Números de Lucas_. Você quer criar essa sequência usando Elixir.

Ao projetar sua função, você quer usar _avaliação preguiçosa_, assim pode gerar quantos números quiser, mas só quando precisar. Então você decide usar um stream.

## 1. Capture argumentos inválidos

Adicione uma cláusula de guarda para lançar um erro se um valor não inteiro ou um inteiro menor que 1 for usado para gerar a sequência. Fazer isso como primeiro passo evita bugs de recursão infinita nos passos seguintes.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. Gere os casos base

Você sabe que a sequência tem dois números iniciais que não seguem a mesma regra. Escreva duas cláusulas de caso base que retornem esses números:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. Crie o caso generalizado

Para qualquer sequência maior que 2, você sabe que precisa somar os dois números anteriores para obter o próximo número, e assim por diante. Escreva o caso generalizado.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
