# Introdução

O Swift tem um conjunto de instruções que podem ser usadas para alterar o fluxo de controle normal dos laços.
Essas instruções são conhecidas como instruções de transferência de controle.
Você já viu `return`; este conceito vai apresentar outras, que incluem `continue`, `break` e rótulos.
Não vamos abordar `fallthrough` neste conceito, mas você pode ler sobre ele no [livro do Swift][fallthrough].

## Continue

Às vezes é necessário pular para a próxima iteração de um laço mais cedo, sem concluir o restante das instruções da iteração atual.
A palavra-chave `continue` pode ser usada para isso.
Quando `continue` é executado, o laço salta para a próxima verificação para ver se a próxima iteração pode ser executada, ou seja, o `while` nos laços while e repeat-while, ou a verificação de se há outro elemento na sequência nos laços for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Break é usado para sair de um laço mais cedo.
Quando `break` é executado, o laço é encerrado imediatamente e o programa continua com a primeira instrução depois do laço.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Rótulos

Quando os laços estão aninhados, há momentos em que você pode querer usar `break` ou `continue` para sair ou reiniciar os laços externos que contêm o laço em que o `break` ou `continue` é usado.
Em casos como esses, rótulos podem ser usados para especificar qual laço deve ser encerrado ou reiniciado.
Um laço pode ser rotulado colocando um nome seguido de dois-pontos antes do `while`, `repeat` ou `for` que inicia o laço.

Para ver o efeito de usar rótulos desse jeito, veja o laço a seguir.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
