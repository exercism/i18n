# Testes

Para rodar os testes de dentro do diretório do exercício, execute o comando:

```sh
odin test .
```

Enquanto você testa, o Odin pode fazer um "vet" no seu código: ele consegue procurar coisas como imports e variáveis sem uso. Rode seus testes com:

```sh
odin test . -vet
```

Para mais opções, consulte `odin test -help`.
