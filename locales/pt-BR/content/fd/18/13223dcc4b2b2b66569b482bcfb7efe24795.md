# Complemento das instruções

## Personalizar e lançar exceções

Às vezes é necessário tanto [personalizar](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) quanto [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) exceções no seu código. Quando você faz isso, deve sempre incluir uma **mensagem de erro significativa** que indique qual é a origem do erro. Isso deixa o seu código mais legível e ajuda muito na depuração.

Exceções personalizadas podem ser criadas por meio de novas classes de exceção (veja [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) para mais detalhes.) que normalmente são subclasses de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

Em situações em que você sabe que a origem do erro será derivada de um certo tipo de exceção, você pode escolher herdar de um dos [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) sob a classe _Exception_. Ao lançar o erro, você ainda deve incluir uma mensagem significativa.

Este exercício em particular exige que você crie uma _exceção personalizada_ a ser [lançada](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/"disparada" quando a pilha não estiver suficientemente preenchida. Os testes só vão passar se você personalizar uma exceção adequada, fizer `raise` dessa exceção e incluir mensagens de erro adequadas.


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

Além disso, este exercício exige que você lance várias `built-in exceptions` com mensagens de erro.
Para lançar uma `built-in exception` com uma mensagem, escreva a mensagem como argumento para o tipo `exception`:

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
