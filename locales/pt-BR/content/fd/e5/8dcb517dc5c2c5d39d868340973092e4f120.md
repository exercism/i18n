# Introdução

Em Go, uma constante é um valor simples que não muda e é atribuído a um nome com a palavra-chave `const`:

```go
const myWebsite = "Exercism"
```

Essas constantes não são tipadas, mas recebem um tipo padrão com base na sintaxe delas quando um tipo é necessário, como quando são passadas para um método.
Constantes tipadas podem ser criadas adicionando um tipo explicitamente:

```go
const myWebsite string = "Exercism"
```

Go não tem enums como algumas outras linguagens, mas tem um identificador predeclarado chamado `iota` para criar constantes enumeradas.
Constantes em um bloco são repetidas implicitamente:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
