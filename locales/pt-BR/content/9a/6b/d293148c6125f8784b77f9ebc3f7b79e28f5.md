# Dicas

## Geral

- Certifique-se de ler a documentação de [decoders][decode] e [encoders][encode]
- A [documentação do GitHub][github] que inspirou este exercício contém mais informações sobre os objetos JSON
- Você pode usar [`Decode.decodeString`][decode-decodeString] para testar seus decoders com qualquer entrada

## 1. Seu ID, por favor!

Dá para resolver a tarefa com as seguintes funções:

- [`int`][decode-int]
- [`field`][decode-field]

## 2. Qual é o meu nome mesmo?

Há duas formas principais de resolver a tarefa:

- usando [`maybe`][decode-maybe]
- usando [`oneOf`][decode-oneOf] com dois decoders possíveis, um usando uma combinação de [`field`][decode-field], [`string`][decode-string] e [`map`][decode-map], e outro usando [`succeed`][decode-succeed]

## 3. Usuário? Mal te conheço!

Dá para resolver a tarefa com as seguintes funções:

- `decodeId` e `decodeName`
- `User` usado como construtor de tipo
- [`map5`][decode-map5]
- [`field`][decode-field]
- [`int`][decode-int]
- [`string`][decode-string]
- [`bool`][decode-bool]

## 4. Sou um comentário forte e independente

Dá para resolver a tarefa com as seguintes funções:

- [`field`][decode-field]
- [`int`][decode-int]
- [`nullable`][decode-nullable]

## 5. Bico

Dá para resolver a tarefa com as seguintes funções:

- [`field`][decode-field]
- [`string`][decode-string]
- [`andThen`][decode-andThen]
- uma instrução `case` que verifica o conteúdo da string que está sendo decodificada
- [`succeed`][decode-succeed]
- [`fail`][decode-fail]

## 6. O despertar dos links

Dá para resolver a tarefa com as seguintes funções:

- [`field`][decode-field]
- [`dict`][decode-dict]
- [`string`][decode-string]

## 7. Sim, comentários

É possível resolver `decodeComment` com as seguintes funções:

- `decodeId`, `decodePullRequestReviewId`, `decodeUser`, `decodeSide`, `decodeLinks`
- `Comment` usado como construtor de tipo
- [`6`][decode-6]
- [`field`][decode-field]
- [`string`][decode-string]

É possível resolver `decodeComments` com as seguintes funções:

- `decodeComment`
- [`list`][decode-list]

## 8. Tudo se encaixa

Todas as funções necessárias para esta tarefa estão definidas na [documentação dos encoders][encode], e talvez algumas do [módulo `Maybe`][maybe]
