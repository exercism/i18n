# Instruções

Você adora observar pássaros e acompanha quantos pássaros visitaram seu jardim nos últimos sete dias.

Você tem seis tarefas, todas sobre os números de pássaros que visitaram seu jardim.

## 1. Confira quais foram as contagens da semana passada

Para fins de comparação, você sempre mantém por perto uma cópia das contagens da semana passada, que foram: 0, 2, 5, 3, 7, 8 e 4. Defina o binding `lastWeek` que contém as contagens da semana passada:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Confira quantos pássaros visitaram ontem

Implemente a função `yesterday` para retornar quantos pássaros visitaram seu jardim ontem. As contagens de pássaros estão ordenadas por dia: o primeiro elemento é a contagem do dia mais antigo e o último é a contagem de hoje.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Calcule o número total de pássaros visitantes

Implemente a função `total` para retornar o número total de pássaros que visitaram seu jardim:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Verifique se houve um dia sem pássaros visitantes

Implemente a função `dayWithoutBirds` que retorna `true` se houve um dia em que zero pássaros visitaram o jardim; caso contrário, retorne `false`:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Incremente a contagem de hoje

Implemente a função `incrementTodaysCount` para incrementar a contagem de hoje e retornar as contagens atualizadas:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Verifique se a semana é incomum

Ao longo do último ano, você percebeu que algumas semanas têm os mesmos padrões incomuns:
- Em cada dia par da semana, não havia pássaros
- Em cada dia par da semana, exatamente 10 pássaros foram avistados
- Em cada dia ímpar da semana, exatamente 5 pássaros foram avistados

Implemente a função `unusualWeek` que retorna `true` se o padrão de contagem de pássaros desta semana corresponder a um dos padrões incomuns:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Repare que a paridade dos dias é indexada a partir de 1, não de 0: o primeiro elemento do array corresponde a um dia ímpar)
