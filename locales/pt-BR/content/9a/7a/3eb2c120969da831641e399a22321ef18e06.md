# Sobre

## Laços `for`

Uma instrução `for` repete um bloco de código.
A primeira linha dela controla com que frequência o bloco se repete:

```go
for init; condition; post {
    // loop body
}
```

- A instrução **init** roda uma vez antes da primeira iteração. É comum declarar e inicializar uma variável contadora usada pelo laço.
- A **condition** é uma expressão Boolean avaliada antes de cada iteração. O laço para quando ela resulta em `false`.
- A instrução **post** roda depois de cada iteração concluída. Ela pode ser usada para atualizar um contador.

Não coloque parênteses em volta de `init; condition; post`.
Porém, as chaves `{ }` em volta do corpo do laço são sempre obrigatórias.

Este laço inicia `i` em `1`, imprime o valor atual de `i`, aumenta seu valor para a próxima iteração e para quando `i` chega a `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## Outras formas de laço

### Laço apenas com condição

As instruções init e post podem ser omitidas.
Uma instrução `for` com apenas uma condição tem o mesmo propósito que um laço `while` em outras linguagens.
Go não tem a palavra-chave `while`.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Laço infinito

Uma instrução `for` pode ser escrita sem condição:

```go
for {
    // loop body
}
```

Este laço não termina sozinho.
A execução precisa sair do laço explicitamente, por exemplo com `break` ou `return`.

## Controlando laços

### Break e Continue

Neste laço, `break` sai do laço:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` pula o restante do corpo do laço atual e começa a próxima iteração:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### Break e Continue com rótulos

Com laços aninhados, um `break` ou `continue` sem rótulo se aplica ao laço mais interno.
Rotule um laço externo colocando um identificador seguido de dois-pontos na linha imediatamente acima dele.
Em seguida, escreva o rótulo do laço após `break` ou `continue` para direcionar a ação para ele:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
