# Sobre

Bash é a linguagem que você vai aprender a amar!

Muitas das suas tarefas diárias no computador podem ser feitas com os scripts concisos que ela produz. Você logo vai perceber que, embora a maioria das coisas possa ser feita por uma interface gráfica, usar essa linguagem poderosa pode ser muito mais rápido! O interpretador de comandos normalmente roda em uma janela de texto, onde o usuário digita comandos (as operações também podem vir de arquivos, conhecidos como scripts Bash).

De forma mais formal, o Bash (sigla de **B**ourne-**a**gain **sh**ell, um trocadilho com a Bourne shell e o termo "born-again") é um interpretador de comandos Unix. Oferece uma série de melhorias em relação a várias outras shells (o Bash tem funcionalidades úteis no que diz respeito a histórico de comandos, controle de jobs e edição de linha de comando).

Uma ótima forma de pensar no Bash é a seguinte:

> Embora a maioria dos usuários pense na shell como um interpretador de comandos interativo, ela é na verdade uma linguagem de programação na qual cada instrução executa um comando. Como precisa atender tanto ao aspecto interativo quanto ao de programação da execução de comandos, é uma linguagem estranha, moldada tanto pela história quanto pelo design. - Brian Kernighan e Rob Pike

_citação: Kernighan, Brian W.; Pike, Rob (1984). The UNIX Programming Environment. Englewood Cliffs: Prentice-Hall. ISBN 0-13-937699-2._

Embora tenha sido lançado há várias décadas, depois de ter sido escrito por Brian Fox, da Free Software Foundation, o Bash ainda é usado no mundo todo todos os dias! Da automação a juntar as peças de um projeto, a linguagem continua tão versátil quanto sempre foi. Outro benefício da idade da linguagem é a documentação rica que você encontra em volta dela. Se algum dia você travar e não souber exatamente como implementar um exercício, um ótimo lugar para começar é a ajuda interna, disponível com o uso de `info bash` ou `man bash`.

Esta trilha existe para ajudar você a ganhar experiência com essa maravilhosa linguagem de script.

**Happy Bash'ing**
