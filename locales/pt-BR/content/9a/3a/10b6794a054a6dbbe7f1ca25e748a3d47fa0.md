# Sobre

Por padrão, as variáveis são limitadas ao escopo em que são definidas. Se forem definidas em um arquivo fora de uma função ou classe, ficam limitadas ao escopo do arquivo. Se forem definidas em uma função ou classe, ficam limitadas ao escopo da função ou classe.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Escopo global

Usar a palavra-chave `global` antes de uma atribuição de variável cria uma variável de escopo global. Esse padrão costuma ser desencorajado, pois cria [código fortemente acoplado](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>).

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Escopo estático

Usar a palavra-chave `static` antes de uma atribuição ou declaração de variável mantém o escopo da variável, mas o valor dela é preservado entre escopos de execução.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

Neste exemplo, a variável `$count` é inicializada com 0 _apenas na primeira chamada da função_. A cada chamada posterior, o valor permanece para a próxima chamada. Assim, cada invocação da função retorna um número inteiro crescente.
