# Dicas

## Geral

- [Conjuntos][sets] são coleções mutáveis e sem ordem, sem elementos duplicados.
- Conjuntos podem conter qualquer tipo de dado.
- Conjuntos são [iteráveis][iterable].
- Conjuntos são usados com mais frequência para remover duplicatas de outras coleções rapidamente ou para testar pertencimento.
- Conjuntos também suportam operações matemáticas como `union`, `intersection`, `difference` e `symmetric difference`.

## 1. Limpe os ingredientes dos pratos

- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Vetores são iteráveis.
- Lembre-se: tuplas podem ser formadas com `(element_1, element_2)`.

## 2. Coquetéis e mocktails

- Um `Set` é _disjunto_ de outro conjunto se os dois não compartilham nenhum elemento.
- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Vetores são iteráveis.
- Strings podem ser concatenadas com o sinal `*` e a interpolação pode ser feita com `$()`.

## 3. Categorize os pratos

- Usar laços para iterar pelas categorias de refeição disponíveis pode ser útil aqui.
- Se todos os elementos de `set_1` estiverem contidos em `set_2`, então `set_1 ⊆ set_2`.
- O método equivalente a `set ⊆ iterable` é `issubset(set, iterable)`.
- Tuplas podem conter qualquer tipo de dado, inclusive outras tuplas. Tuplas podem ser formadas com `(element_1, element_2)`.
- Os elementos dentro de tuplas podem ser acessados da esquerda com um índice baseado em 1, ou da direita com um índice baseado em `end` (por exemplo, `tuple[end]`).
- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Vetores são iteráveis.
- Strings podem ser concatenadas com o sinal `*` e a interpolação pode ser feita com `$()`.

## 4. Rotule alérgenos e alimentos restritos

- Uma _intersecção_ de conjuntos são os elementos compartilhados entre `set_1` e `set_2`.
- O método de conjunto equivalente a `set ∩ iterable` é `intersect(set, iterable)` ou `∩(set, iterable)`.
- Os elementos dentro de tuplas podem ser acessados da esquerda com um índice baseado em 1, ou da direita com um índice baseado em `end` (por exemplo, `tuple[end]`).
- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Vetores são iteráveis.
- Tuplas podem ser formadas com `(element_1, element_2)`.

## 5. Monte uma "lista mestra" de ingredientes

- Uma _união_ de conjuntos é quando os elementos de `set_1` e `set_2` são combinados em um único `Set`.
- O método de conjunto equivalente a `set ∪ iterable` é `union(set, iterable)` ou `∪(set, iterable)`.
- Usar laços para iterar pelos diversos pratos pode ser útil aqui, mas usar splatting também pode funcionar.

## 6. Separe as entradas para passar em bandejas

- Uma _diferença_ de conjuntos é quando os elementos de `set_2` são removidos de `set_1`, por exemplo, `setdiff(set_1, set_2)`.
- O construtor `Set()` pode receber qualquer [iterável][iterable] como argumento. Vetores são iteráveis.
- O construtor Vector pode receber qualquer [iterável][iterable] como argumento. Conjuntos são iteráveis.

## 7. Encontre ingredientes usados em apenas uma receita

- Uma _diferença simétrica_ de conjuntos é quando elementos aparecem em `set_1` ou em `set_2`, mas não **_nos dois_**.
- Uma _diferença simétrica_ de conjuntos é o mesmo que subtrair a _intersecção_ do `Set` da _união_ do `Set`, por exemplo, `setdiff(set_1 ∪ set_2, set_1 ∩ set_2)`.
- Uma _diferença simétrica_ de mais de dois `Sets` incluirá elementos que se repetem mais de duas vezes entre os `Sets` de entrada. Para remover esses elementos repetidos entre conjuntos, é preciso subtrair da diferença simétrica as _intersecções_ entre os pares de conjuntos.
- Usar laços para iterar pelos diversos pratos pode ser útil aqui, mas splatting também pode funcionar.
