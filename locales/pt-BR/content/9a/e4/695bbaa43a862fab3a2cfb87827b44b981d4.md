# Introdução

O tipo `Option` é o mecanismo da linguagem F# para lidar com valores que podem ou não existir.
Ele oferece uma alternativa com segurança de tipos ao uso de `null`, comum em outras linguagens para lidar com esse tipo de valor.
Ele aparece em muitas funções da biblioteca padrão do F#, então entendê-lo é essencial para usar essa biblioteca de forma eficaz.

## Uso 

O tipo `Option` é um tipo genérico (que tem um tipo subjacente).  
Valores `Option` são `Some value`, que representa algum valor específico, ou `None`, que representa nenhum valor.

A função a seguir mostra como criar um valor `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` é a sintaxe pós-fixada equivalente a `Option<T>`; as duas formas de sintaxe podem ser usadas de maneira intercambiável.
No entanto, de acordo com o F# Style Guide, a notação pós-fixada é preferida para tipos Option (veja a [seção do F# Style Guide sobre formatação de tipos e anotações de tipo](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

## Lendo o conteúdo de um valor Option

A forma idiomática de ler um valor `Option` é por meio de correspondência de padrões, como mostra o exemplo a seguir:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Desempacotando Options com valores padrão

Os `Option`s podem ser "desempacotados" (convertidos para o tipo que eles contêm) fornecendo valores padrão com a função `Option.defaultValue`. 
Isso é especialmente útil quando você quer garantir que o valor não seja `None`.
Por exemplo:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
