# Sobre

Um parâmetro de método pode se tornar opcional se você atribuir a ele um valor padrão. Quando um parâmetro é opcional, quem chama o método não precisa fornecer um argumento para esse parâmetro; nesse caso, o valor padrão será usado. Os [parâmetros opcionais][optional-arguments] _devem_ ficar no final da lista de parâmetros; eles não podem ser seguidos de parâmetros não opcionais. Se um método tiver vários parâmetros opcionais, você pode especificar apenas alguns deles usando [argumentos nomeados][named-arguments].

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

O valor de um parâmetro opcional deve ser um destes:

- Uma expressão constante (por exemplo, `"hi"`, `2`, `DayOfWeek.Friday`, `null` etc.)
- Uma expressão `new` de um tipo de valor
- Uma expressão `default` de um tipo de valor
