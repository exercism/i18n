# Instruções

Você é analista de dados em uma empresa que analisa dados meteorológicos no noroeste do Pacífico.
Você vai trabalhar com um banco de dados que contém uma tabela `weather_readings` com as seguintes colunas.

* `date`: a data em que a amostra foi coletada.
* `location`: o nome da cidade em que a amostra foi coletada.
* `temperature`: a temperatura, em graus Fahrenheit.
* `wind_speed`: a velocidade do vento, em milhas por hora.

Em cada uma das tarefas a seguir, seu trabalho é recuperar o conjunto de resultados especificado usando uma instrução `SELECT`.
Repare que, em cada caso, o conjunto de resultados será armazenado em uma nova tabela (uma tabela para cada tarefa), por meio de uma instrução `CREATE TABLE` já escrita.
Por enquanto, não se preocupe com o `CREATE TABLE`; isso será abordado em outra lição.
Concentre-se apenas em adicionar a instrução `SELECT` adequada para realizar a tarefa proposta.

## 1. Recupere todos os dados

Recupere todos os dados da tabela `weather_readings`.

## 2. Recupere apenas os dados de local e temperatura

Recupere apenas os valores de local e temperatura da tabela `weather_readings`.

## 3. Recupere apenas os dados de Seattle

Recupere apenas os dados da localização Seattle.

## 4. Recupere apenas os dados com velocidade do vento em um intervalo específico

Recupere apenas os dados em que a velocidade do vento está entre 5 e 15 milhas por hora.
