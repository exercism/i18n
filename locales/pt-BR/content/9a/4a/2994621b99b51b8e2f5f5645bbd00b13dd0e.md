# Instruções

Uma escola local perto de você tem uma associação de estudantes muito ativa.
A associação de estudantes é administrada por um presidente e, a cada 2 anos,
são realizadas eleições para eleger um novo presidente.

Na eleição deste ano, foi decidido que era necessário um novo sistema digital para
contar os votos. A escola precisa da sua ajuda para construir esse novo sistema.

## 1. Obtenha o número de votos de um `ElectionResult`

O novo sistema vai precisar de uma forma de obter o número de votos de um contador.

A struct de resultado da eleição já foi criada para você e está definida assim:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

Como todos os membros da `struct` são públicos, você não precisa escrever um `constructor` para inicializar um objeto `ElectionResult`.
Você pode usar uma `initializer list` em vez disso:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

Crie uma função `vote_count` que receba uma referência a um `ElectionResult` como argumento e retorne o número de votos no `ElectionResult`.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. Incremente os votos de um `ElectionResult`

Finalmente chegou a hora de processar os votos!
Agora você precisa de uma forma de incrementar os votos em um `ElectionResult`.

Crie uma função `void` `increment_vote_count` que receba uma referência a um `ElectionResult` como argumento e um número de votos, e incremente o `ElectionResult` com esse número de votos.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. Contagem de votos e presidência

A escola entregou os votos e agora chegou a hora de verificar os resultados para saber quem venceu.

Crie uma função `determine_result` que recebe uma referência a uma contagem final e retorna uma referência ao `ElectionResult` do novo presidente.
Ela também deve mudar o nome do vencedor, adicionando o prefixo "President" a ele.
A contagem final é dada na forma de uma `reference` para `std::vector<ElectionResult>`, um vetor com os `ElectionResults` de todos os candidatos participantes.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

Para simplificar, você pode assumir o seguinte:
- O `vector` tem pelo menos um elemento.
- Não haverá empate em primeiro lugar.
