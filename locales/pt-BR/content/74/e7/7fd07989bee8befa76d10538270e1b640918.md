# A pergunta de um bilhão de dólares do HTTP

## Enunciado do problema

Você recebeu a tarefa de encontrar os `x` bilionários mais ricos, por patrimônio líquido, em um determinado conjunto de países (número de países = `N`). Para isso, você tem acesso a uma API que retorna os detalhes dos bilionários por país.

Para simplificar o acesso à API, você pode usar o conector [cliente `ims/billionairehub`](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) para se conectar à API, que retorna os detalhes dos bilionários por país.

## Restrições

* 1 <= N <= 5
* 1 <= x <= 10

## Exemplo 1

Entrada

```
Countries: ["United States"]
Limit: 3
```

Saída

```
["Elon Musk", "Jeff Bezos", "Bill Gates"]
```

## Exemplo 2

Entrada

```
Countries: ["China", "India"]
Limit: 5
```

Saída

```
["Mukesh Ambani", "Gautam Adani & family", "Zhong Shanshan", "Zhang Yiming", "Ma Huateng"]
```

## Ambiente de testes

* O Client ID e o Client Secret para se conectar à API de bilionários foram fornecidos a você no `tests/Config.toml`. Você pode usá-los para inicializar o cliente.
* Use `bal test` para rodar e testar sua implementação.

## Dicas

* O [cliente](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) do pacote `ims/billionairehub` pode ser usado para chamar a API de obter bilionários por país. Você pode usar especificamente o método remoto `getBillionaires("<country>")`.
* Você pode primeiro encontrar as pessoas mais ricas de cada país e depois combiná-las para encontrar os `x` do topo.
* As [expressões de consulta](https://ballerina.io/learn/by-example/query-expressions/) vão ser úteis para filtrar e ordenar.
