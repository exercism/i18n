# Adendo às instruções

## Registradores

| Registrador | Uso          | Tipo    | Descrição                                      |
| -------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`    | entrada      | endereço | array de palavras com as capacidades dos baldes |
| `$a1`    | entrada      | inteiro | balde inicial (1 ou 2)                          |
| `$a2`    | entrada      | inteiro | volume alvo                                     |
| `$a3`    | entrada/saída | endereço | array de palavras com o conteúdo final dos baldes |
| `$v0`    | saída        | inteiro | número de ações necessárias, -1 se não for possível |
| `$t0-9`  | temporário   | qualquer | usado para armazenamento temporário             |
