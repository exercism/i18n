# Sobre

Estruturas de dados que podem conter zero ou mais elementos são conhecidas como _coleções_. Um **array** (também chamado de _vetor_) é uma coleção que tem tamanho/comprimento fixo e cujos elementos precisam ser todos do mesmo tipo. Você pode atribuir elementos a um array ou recuperá-los dele usando um índice. Os arrays em C# são baseados em zero, o que significa que o índice do primeiro elemento é sempre zero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

Você também pode definir arrays usando uma notação abreviada que permite criar o array e definir seus valores ao mesmo tempo. Como o compilador agora consegue dizer quantos elementos o array terá, o comprimento pode ser omitido:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Você pode manipular arrays chamando os [métodos][array-methods] ou as [propriedades][array-properties] de uma instância de array, ou usando os métodos estáticos definidos na [classe `Array`][array-class].

## Iteração

Um array também é uma _coleção_, o que significa que você pode iterar sobre _todos_ os seus valores usando um [laço `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Você pode usar um [laço `for`][for-statement] para iterar sobre um array:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

No entanto, em geral um laço `foreach` é preferível a um laço `for` pelos seguintes motivos:

- Um laço `foreach` tem a garantia de iterar sobre _todos_ os valores. Com um laço `for`, é fácil deixar elementos de fora, por exemplo por causa de um erro de um a mais ou a menos.
- Um laço `foreach` é mais _declarativo_: seu código comunica _o que_ você quer que ele faça, em vez de um laço `for` que comunica _como_ você quer fazer.
- Um laço `foreach` é à prova de falhas, enquanto com laços `for` é fácil cometer um erro de um a mais ou a menos.
- Um laço `foreach` funciona com todos os tipos de coleção, inclusive aqueles que não permitem usar um indexador para acessar os elementos.

Para garantir que um laço `foreach` itere sobre _todos_ os valores, o compilador não permite alterar a coleção dentro de um laço `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Um laço `for` tem, sim, algumas vantagens sobre um laço `foreach`:

- Você pode começar ou parar no índice que quiser.
- Você pode usar qualquer condição de término (Boolean) que quiser.
- Você pode pular elementos personalizando o incremento da variável do laço.
- Você pode processar coleções de trás para frente contando de forma decrescente.
- Você pode usar laços `for` em cenários que não envolvem coleções.

Tópicos relacionados:

- Vale saber que o C# dá suporte a [arrays multidimensionais][multi-dimensional-arrays] como `int[,] arr = new int[10, 5]`, que podem ser muito úteis.
- Vale saber também que você pode instanciar objetos do tipo [`System.Array`][system-array-object] com `Array.CreateInstance`. Esses objetos têm pouca utilidade, servem principalmente para interoperar com código VB.NET. Eles não são intercambiáveis com arrays padrão (`T[]`). E podem ter um limite inferior diferente de zero.
