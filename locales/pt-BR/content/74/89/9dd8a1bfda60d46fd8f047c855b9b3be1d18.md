# Introdução

Trabalhar com texto é uma tarefa comum em programação.
O Swift, junto com o framework Foundation, oferece muitos métodos e propriedades práticos para inspecionar, transformar e manipular strings.

## Dividindo strings com `components(separatedBy:)`

Para dividir uma string em um array de substrings com base em um delimitador, use `components(separatedBy:)` (é preciso importar o Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Verificando prefixos e sufixos com `hasPrefix(_:)` e `hasSuffix(_:)`

Para verificar se uma string começa ou termina com uma sequência específica de caracteres, use `hasPrefix(_:)` e `hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## Alterando maiúsculas e minúsculas

Você pode transformar as maiúsculas e minúsculas de uma string usando estes métodos e propriedades padrão:

- `lowercased()`: Retorna uma cópia da string em letras minúsculas.
- `uppercased()`: Retorna uma cópia da string em letras maiúsculas.
- `capitalized`: Retorna uma cópia em que a primeira letra de cada palavra fica em maiúscula (do Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Substituindo substrings com `replacingOccurrences(of:with:)`

Para substituir todas as ocorrências de uma substring por outra string, use `replacingOccurrences(of:with:)` (do Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Juntando strings com `joined(separator:)`

O método `joined(separator:)` pertence a coleções de strings, como `[String]`.
Ele junta os elementos em uma única string usando um separador:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
