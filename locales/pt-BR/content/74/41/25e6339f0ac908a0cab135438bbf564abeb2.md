# Instruções

Neste exercício, você vai aplicar as [regras do jogo de Go](https://matmoore.github.io/learngo/). As regras em si já estão escritas, você só precisa aplicá-las para atualizar o `Game` e tratar quaisquer erros ou violações das regras.

O jogo é representado assim:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

Há 4 regras no jogo:

- Cada ponto pode ter apenas uma pedra (`oneStonePerPointRule`)
- Pedras adversárias podem ser capturadas! (`captureRule`)
- Você não pode colocar uma pedra onde ela capturaria a si mesma (`libertyRule`)
- Você não pode usar o mesmo ponto duas vezes (`koRule`)

## 1. Aplique as regras

Escreva o conteúdo da função `applyRules`, que recebe um `Game` inicial e um conjunto de regras, e retorna o novo `Game` depois que as regras forem aplicadas.

`oneStonePerPointRule`, `libertyRule` e `koRule` verificam violações das regras e podem retornar um erro, por isso têm o tipo de retorno `Result String Game`. Se alguma dessas regras falhar, o jogo original deve ser retornado, mas com o campo `error` atualizado com o erro relevante.

`captureRule` não verifica violações e, por isso, não pode falhar (embora possa retornar um `Game` alterado), então tem o tipo de retorno `Game`.

Se todas as regras passarem, quaisquer alterações no `Game` feitas pelas regras devem ser mantidas, e o jogador deve ser alterado. A função `changePlayer` é fornecida para fazer isso.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
