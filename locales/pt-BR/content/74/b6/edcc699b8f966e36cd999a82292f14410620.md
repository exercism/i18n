# Instruções

Você adora observar aves e acompanha quantas visitaram seu jardim. Normalmente, você anota as contagens em um caderno, mas, para trabalhar melhor com seus dados, você digitalizou as contagens de aves das últimas semanas.

## 1. Determine o número total de aves que você contou até agora

Vamos começar a analisar os dados com uma visão geral.
Descubra quantas aves você contou no total desde que começou seus registros.

Implemente uma função `TotalBirdCount` que recebe um slice de `int`s contendo a contagem de aves por dia.
Ela deve retornar o número total de aves que você contou.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Calcule o número de aves visitantes em uma semana específica

Agora que você já tem uma ideia geral dos seus números de contagem de aves, você quer fazer uma análise mais detalhada.

Implemente uma função `BirdsInWeek` que recebe um slice com as contagens de aves por dia e um número de semana.

Ela retorna o número total de aves que você contou nessa semana específica.
Você pode assumir que as semanas são sempre registradas por completo.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Corrija um erro de contagem

Você percebeu que, todo o tempo em que estava tentando acompanhar as aves, havia uma ave escondida em um canto distante do jardim.

Você descobriu que essa ave passava dia sim, dia não no seu jardim.

Você não sabe exatamente onde ela estava entre esses dias, mas com certeza não era no seu jardim.

Sua intuição de observador de aves também diz que a ave estava no seu jardim no primeiro dia registrado na sua lista.

Com essa nova informação, escreva uma função `FixBirdCountLog` que recebe como argumento um slice com as aves contadas por dia e retorna o slice depois de corrigir o erro de contagem.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
