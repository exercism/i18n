# PaySwitch - Conversor de salário

## Enunciado do problema

Uma empresa chamada **Insure Everyone** paga seus funcionários em moedas estrangeiras. Mas, por exigências legais, o salário precisa ser convertido para a moeda local. Seus funcionários estão espalhados pelo mundo.
O departamento de RH da Insure Everyone está buscando a ajuda de um desenvolvedor talentoso para criar um programa que converta o salário de cada funcionário para a moeda local correspondente. A Insure Everyone depende de taxas de câmbio fornecidas por uma API externa.

Dada a API externa de taxas de câmbio, você precisa escrever uma função que receba uma `source currency`, um `salary` (na moeda de origem) e a `local currency` do funcionário, e que retorne o salário na moeda local.

## Restrições

* 500 <= `salary` <= 10000
* `sourceCurrency` e `targetCurrency` são [códigos de moeda ISO (alfabéticos)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes). As entradas de teste podem conter códigos de moeda inválidos.
* A precisão da taxa retornada será medida com até `5` casas decimais.

## Exemplo

### Exemplo 1

#### Entrada:
* Salário: 1000
* Moeda de origem: USD
* Moeda de destino: GBP

#### Saída:

Supondo que a API externa de câmbio tenha retornado a seguinte resposta de taxas de conversão (omitida):

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

A função deve retornar `735.84000`

### Exemplo 2

#### Entrada:

        // omitted
