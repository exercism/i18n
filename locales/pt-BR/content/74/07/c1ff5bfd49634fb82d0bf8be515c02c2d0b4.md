## 1. Criar novos visitantes

- Usando as referências, complete o método initialize para salvar a altura no estado do objeto.

## 2. Qual é a altura do visitante

- Crie um getter para a altura salva no estado.

## 3. Qual é o id do passe

- Crie um getter para o id do passe.
- Não tem problema, e é até esperado, retornar `nil` antes de um passe ser emitido para o `Attendee`.

## 4. Permitir que as pessoas comprem um passe

- No método `Attendee#issue_pass!`, defina o estado da instância como o argumento.

## 5. Revogar o passe

- No método setter `Attendee#revoke_pass!`, defina o estado da instância de forma que não exista nenhum passe.
