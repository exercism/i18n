# Dicas

## 1. Imprimir um crachá para um funcionário

- Para construir as strings no R base, a função [`sprintf`][ref-sprintf] é útil.
- Para uma abordagem com o Tidyverse, você pode usar [`str_glue`][ref-str_glue] da biblioteca `stringr`.

## 2. Imprimir um crachá para um funcionário novo

- Use uma condicional com [`is.na`][ref-isna].

## 3. Imprimir um crachá para o dono

- Use uma condicional com [`is.null`][ref-isnull].

## 4. Calcular o salário total dos funcionários sem ID

- Você pode [filtrar][concept-vector-filtering] com [`is.na`][ref-isna] e depois usar [`sum`][ref-sum].
- O que é `salaries[is.na(ids)]` se não houver funcionários sem ID? Seria útil verificar isso em um console do R. Se o R não estiver instalado no seu computador, consoles online como o [rdrr.io][web-rdrr] podem ajudar.
