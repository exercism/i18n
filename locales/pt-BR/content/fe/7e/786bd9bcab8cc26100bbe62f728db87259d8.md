# Instruções

Neste exercício, você vai implementar uma forma de acompanhar os recordes do jogo mais popular do fliperama da sua região.

Você tem 6 funções para implementar, a maioria relacionada a manipular um objeto que guarda os recordes.

## 1. Criar um novo placar de recordes

Escreva uma função `create_score_board` que cria um objeto que serve como placar de recordes.
As chaves desse objeto serão os nomes dos jogadores, e os valores serão as pontuações deles.
Para fins de teste, você quer incluir diretamente uma entrada no objeto.
Essa entrada inicial deve ter `"The Best Ever"` como nome do jogador e `1000000` como pontuação.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Adicionar jogadores a um placar

Para adicionar um jogador ao placar de recordes, implemente a função `add_player`.
Ela recebe um placar como entrada e precisa de dois parâmetros: o nome do jogador e a pontuação dele.
A função retorna o objeto do placar com o novo jogador adicionado.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Se o jogador já estiver no placar, retorne o placar sem alterações.

## 3. Remover jogadores de um placar

Se os jogadores violarem as regras do fliperama, eles são removidos manualmente do placar de recordes.
Implemente `remove_player`, que recebe um placar como entrada e um parâmetro, o nome do jogador a remover.
Essa função deve remover a entrada do jogador indicado do placar e retornar o novo placar.
Se o jogador não estivesse no placar, nada deve acontecer com o placar; ele deve ser retornado como está.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Aumentar a pontuação de um jogador

Se um jogador terminar outra partida no fliperama, uma certa quantidade de pontos será adicionada à pontuação anterior no placar.
Implemente `update_score`, que recebe um placar como entrada e precisa de dois parâmetros: o nome do jogador e a quantidade de pontos a adicionar.
A função deve retornar o placar depois que a atualização for feita.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Essa função deve adicionar o jogador ao placar se ele ainda não estiver lá.

## 5. Aplicar os pontos de bônus de segunda-feira

O fliperama mantém um placar separado às segundas-feiras.
No fim do dia, cada jogador nesse placar ganha 100 pontos adicionais.

Implemente a função `apply_monday_bonus`.
A função adiciona os pontos de bônus para cada jogador listado nesse placar.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Encontrar a pontuação total

Fliperamas diferentes competem entre si para determinar quem tem os melhores jogadores.
O fliperama com a maior pontuação total ganha a honra.

Escreva uma função `total_score`.
Ela recebe um placar como entrada e retorna a soma das pontuações de todos os jogadores.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
