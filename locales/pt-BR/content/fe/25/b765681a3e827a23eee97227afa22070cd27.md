# Números de ponto flutuante

Números de ponto flutuante são usados no PHP para representar um subconjunto dos números reais.
Eles começam com um ou mais dígitos separados por um separador decimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## Armadilhas comuns

Nem todos os números e operações aritméticas podem ser realizados com números de ponto flutuante.
Usar números de ponto flutuante para representar dólares e centavos muitas vezes pode levar a erros de arredondamento.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
