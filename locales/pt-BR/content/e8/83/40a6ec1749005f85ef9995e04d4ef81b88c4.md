# Apêndice das instruções

## Registradores

| Registrador | Uso       | Tipo    | Descrição                                    |
| ----------- | --------- | ------- | -------------------------------------------- |
| `$a0`       | entrada   | endereço | string de caracteres octais terminada em null |
| `$v0`       | saída     | inteiro  | valor decimal da string de entrada            |
| `$t0-9`     | temporário | qualquer | usado para armazenamento temporário           |
