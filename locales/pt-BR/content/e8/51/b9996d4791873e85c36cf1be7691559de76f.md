# Resto

Na matemática, o **resto** é a quantidade que "sobra" depois de fazer algum cálculo.
Por exemplo, o resto de `5 / 3` é `2`.

Muitas linguagens de programação usam o sinal de porcentagem (`%`) como operador para calcular o resto.
Por exemplo:
```javascript
5 % 3 == 2
```

Muitas vezes, dá para calcular o resto tanto com números inteiros quanto com números de ponto flutuante.
Por exemplo,
```javascript
5.3 % 3 == 2.3
```

Ao trabalhar com números negativos, o resultado sempre tem o mesmo sinal do dividendo (o número do lado esquerdo, que está sendo dividido).
Por exemplo:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Algumas linguagens (como Python) usam o operador `%` para calcular o módulo, não o resto.
Isso trata os números negativos de forma diferente.
Você pode saber mais sobre isso [na Wikipédia](https://en.wikipedia.org/wiki/Modulo).
