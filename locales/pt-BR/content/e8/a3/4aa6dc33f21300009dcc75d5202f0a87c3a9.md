# Aprendizado

O Bash é um shell Unix muito poderoso e uma linguagem de script de comandos, mas tem uma curva de aprendizado bastante íngreme.

* A [página de manual](https://manpage.me/index.cgi?apropos=0&q=bash&sektion=1&manpath=Debian+7.8.0&arch=default&format=html)
  do Bash é um documento bem escrito e informativo. No entanto, é muito "denso"
  e exige ler e reler.

* Você pode encontrar guias, informações e exemplos adicionais em
    * [Greg's Wiki](http://mywiki.wooledge.org/BashGuide),
    * a [Bash Hackers Wiki](https://web.archive.org/web/20230323071638/https://wiki.bash-hackers.org/),
    * a [página de informações da tag bash](https://stackoverflow.com/tags/bash/info) no
      Stack Overflow,
    * e, expandindo a página de manual, o [GNU Bash Manual](http://gnu.org/s/bash/manual)
      é _a_ fonte de informação para o bash.

* O [shellcheck.net](https://www.shellcheck.net/) oferece uma interface web
  (e um binário para algumas distros) que verifica scripts de shell em busca de erros ou
  problemas comuns e fornece informações sobre a melhor forma de corrigi-los.
