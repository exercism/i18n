# Introdução

Às vezes, um pedaço de estado precisa ser compartilhado entre várias palavras, sem que você fique passando esse estado pelos efeitos de pilha delas toda vez. As *variáveis dinâmicas* do Factor, declaradas com `SYMBOL:`, dão a cada palavra acesso a um valor guardado em um namespace.

## `SYMBOL:` e `SYMBOLS:`

`SYMBOL: name` declara uma variável. `SYMBOLS: a b c ;` declara várias de uma vez:

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## Definir e obter

`set-global` e `get-global` (em [`namespaces`][namespaces]) operam sobre o namespace global:

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

Para estado no nível do módulo, as variantes com `-global` são o que você quer.

## Associações com escopo com `with-variable`

Uma variável dinâmica também aceita uma segunda variante, *com escopo*. `set` / `get` / `change` (sem o sufixo `-global`) leem e escrevem o escopo dinâmico *atual*, e `with-variable` (em [`namespaces`][namespaces]) cria um escopo novo enquanto uma quotation estiver em execução:

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

A variável fica associada a `value` enquanto `quot` roda; quando ele retorna, a associação desaparece. Isso permite que quem chama de fora "injete" um valor que o código interno consegue ler, sem passá-lo por todas as assinaturas de pilha.

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

Este exercício usa a variante global do início ao fim, mas reconhecer a família paralela `set`/`get`/`change` é útil quando você lê o código de outras pessoas.

## Vetores mutáveis

Como as variáveis dinâmicas guardam uma referência, você pode manter uma coleção *mutável* dentro de uma delas e atualizá-la no lugar:

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }` é um vetor literal. Sempre use `clone` em um literal `V{ }` antes de guardá-lo: os literais são compartilhados entre chamadas.

## `find`: a primeira correspondência

`find` (em [`sequences`][sequences]) retorna o primeiro elemento para o qual um predicado é verdadeiro, junto com o índice dele:

```
find ( seq quot -- index elt/f )
```

Se nada corresponder, os dois valores são `f`. Descartar o índice com `nip` e usar `unless*` é a combinação padrão de "valor padrão se faltar".

## `reject`: descarte as correspondências

`reject` (também em [`sequences`][sequences]) é o oposto de `filter`: retorna os elementos que *não passam* no predicado.
