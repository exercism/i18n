# Instruções

Você precisa identificar se existe uma cor de bala em um saco que representa a maior parte dele. 🍬 O elemento majoritário é aquele que ocupa mais da metade do espaço em uma coleção. Dada uma lista de elementos que representam as cores, retorne a cor encontrada como majoritária ou, caso não exista, indique que nenhuma maioria foi encontrada.

Para uma lista simples, `[Red, Red, Blue, Red, Green]`, o valor retornado deve ser Red, porque Red aparece 3 vezes em uma lista de 5. Mas, para uma lista `[Red, Red, Blue, Green]`, não existe maioria, apesar de Red ser o elemento mais comum, porque 2/4 não é maior que a metade dos elementos.
