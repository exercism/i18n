# Introdução

## Condicionais if

### Operadores lógicos

O Java oferece suporte aos três operadores lógicos `&&` (E), `||` (OU) e `!` (NÃO).

### A condicional if

O tipo por trás de qualquer operação condicional é o tipo `boolean`, que pode ter o valor `true` ou `false`. As condicionais costumam ser usadas como mecanismos de controle de fluxo para verificar diversas condições. Para verificar um caso específico, pode-se usar uma condicional `if`, que executa o código dela se a condição por trás for `true`, assim:

```java
int val;

if(val == 9) {
    // conditional code
}
```

Em cenários com mais de um caso, várias condicionais `if` podem ser encadeadas usando as condicionais `else if` e `else`.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### A instrução switch

O Java também oferece uma instrução `switch` para cenários com várias opções.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
