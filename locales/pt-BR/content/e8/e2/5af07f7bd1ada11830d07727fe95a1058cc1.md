# Instruções

Neste exercício, você precisa implementar algumas funções para manipular uma lista de linguagens de programação.

## 1. Defina uma função que retorna uma lista de linguagens vazia

Defina a função `new/0`, que não recebe argumentos e retorna uma lista vazia.

```elixir
LanguageList.new()
# => []
```

## 2. Defina uma função que adiciona uma linguagem à lista

Defina a função `add/2`, que recebe 2 argumentos (uma _lista de linguagens_ e um literal de string de uma _linguagem_). Ela deve retornar a lista resultante com a nova linguagem adicionada no início da lista recebida.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Defina uma função que remove uma linguagem da lista

Defina a função `remove/1`, que recebe 1 argumento (uma _lista de linguagens_). Ela deve retornar a lista sem o primeiro item. Considere que a lista sempre terá pelo menos um item.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Defina uma função que retorna o primeiro item da lista

Defina a função `first/1`, que recebe 1 argumento (uma _lista de linguagens_). Ela deve retornar a primeira linguagem da lista. Considere que a lista sempre terá pelo menos um item.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Defina uma função que retorna quantas linguagens há na lista

Defina a função `count/1`, que recebe 1 argumento (uma _lista de linguagens_). Ela deve retornar o número de linguagens na lista.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Defina uma função que determina se a lista inclui uma linguagem funcional

Defina a função `functional_list?/1`, que recebe 1 argumento (uma _lista de linguagens_). Ela deve retornar um valor Boolean. Ela deve retornar true se _"Elixir"_ for uma das linguagens da lista.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
