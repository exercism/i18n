# Sobre

Em Rust, os booleanos são representados pelo tipo `bool`, cujos valores podem ser `true` ou `false`.

Rust dá suporte a um [operador de negação Boolean][negation operators]: `!` (Não).

Rust dá suporte a seis [operadores de comparação][comparison operators]: `==` (Igual), `!=` (Diferente), `>` (Maior que), `<` (Menor que), `>=` (Maior ou igual a), `<=` (Menor ou igual a). Eles podem ser usados para avaliar a relação entre valores que não são Boolean e obter um valor Boolean.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Diferente de algumas outras linguagens, `0` não é `false` e um valor diferente de zero não é `true`.

Rust dá suporte a três [operadores binários lógicos][logical binary operators]: `&` (E lógico), `|` (Ou lógico), `^` (Ou exclusivo lógico).

Rust dá suporte a dois [operadores Boolean][lazy boolean operators]: `||` (Ou), `&&` (E). Eles diferem de `|` e `&` porque o operando do lado direito só é avaliado quando o operando do lado esquerdo não determina por si só o resultado da expressão. Ou seja, `||` só avalia seu operando do lado direito quando o operando do lado esquerdo resulta em `false`, e `&&` só o faz quando ele resulta em `true`.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
