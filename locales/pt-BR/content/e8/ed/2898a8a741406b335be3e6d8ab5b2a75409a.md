# Introdução

As condicionais do Factor escolhem entre **quotations**, trechos de código escritos entre colchetes, `[ ... ]`. Escrever `[ ... ]` coloca o código na pilha como um valor em vez de executá-lo; a condicional então decide qual quotation executar. (As quotations são tratadas por completo em um exercício mais adiante.)

`if` (em [`kernel`][kernel]) é a condicional básica do Factor. Ela recebe um boolean e duas quotations, e executa a primeira se o boolean for verdadeiro e a segunda caso contrário.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when` executa a sua quotation apenas quando o boolean for verdadeiro, e `unless` apenas quando ele for falso. Quando há mais de dois caminhos, existe o `cond` (em [`combinators`][combinators]):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
