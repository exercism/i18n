# Introdução

## Try/Rescue/Else/After

Usar `try..rescue` é uma construção poderosa para capturar erros quando eles acontecem. Capturar erros permite que as funções retornem valores definidos quando for necessário. A construção `try..rescue` também nos oferece dois recursos adicionais que podemos aproveitar:

- o bloco `else`
  - Quando o bloco `try` tem sucesso, o resultado precisa corresponder a este bloco.
- o bloco `after`
  - Independentemente de o bloco `try` ter sucesso ou gerar um erro, o código no bloco `after` sempre é executado, desde que o programa ainda esteja rodando nesse ponto.
  - O resultado do bloco `after` não é retornado para o escopo que fez a chamada.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## Despacho dinâmico

Quando o Elixir resolve a função a ser invocada, ele usa o nome do módulo para fazer uma busca. A busca pode ser feita dinamicamente se o nome do módulo estiver vinculado a uma variável.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Internamente, o nome de um módulo é um átomo. Todos os átomos de módulos do Elixir recebem automaticamente o prefixo `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
