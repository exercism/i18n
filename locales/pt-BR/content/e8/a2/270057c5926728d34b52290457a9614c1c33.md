# tem erros de compilação

O código tem um ou mais erros de compilação, o que impede os testes de rodar. Um bom primeiro passo para descobrir como corrigir os erros é examinar as mensagens de erro que aparecem quando você tenta compilar o código. Essas mensagens trazem um número e uma descrição do erro, o que ajuda a identificar exatamente qual é o problema.
