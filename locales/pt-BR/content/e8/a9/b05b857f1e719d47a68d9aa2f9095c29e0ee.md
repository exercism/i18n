# Dispositivo Secreto

## História

Esta história usa o cenário de criar um dispositivo para criptografar mensagens de forma confiável e repetida, usando [funções anônimas][concepts-anonymous_functions].

Conceitos explorados:

- [Funções anônimas][concepts-anonymous_functions]
- [Composição de funções][concepts-function_composition]
- [Funções de ordem superior][concepts-higher_order_functions]

A história também se adapta bem para [concepts-bitwise_manipulation][concepts-bitwise_manipulation], o tipo [types-bit][types-bit] e a composição de funções.
