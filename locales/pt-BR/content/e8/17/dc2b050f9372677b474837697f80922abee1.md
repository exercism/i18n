# Complemento das instruções

## Implementação

Se o último item da lista for um `object` em vez de uma `string`, ele vai conter um qualificador que modifica a última linha do provérbio.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
