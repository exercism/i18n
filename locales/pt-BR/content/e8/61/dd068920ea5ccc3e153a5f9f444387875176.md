# Sobre

Um [laço `while`][while-loops] é uma instrução de fluxo de controle que permite executar código enquanto uma determinada condição for verdadeira.
O Swift oferece dois tipos de laço `while`: os laços `while` e `repeat-while`.
A condição do laço `while` é avaliada antes de o corpo do laço ser executado; se a condição for falsa, o corpo do laço não será executado de forma alguma.
Os laços `while` no Swift têm a seguinte estrutura:

```swift
while <#condition#> {
  <#code#>
}
```

Aqui, o laço será executado enquanto `count` for maior que 0 e, com isso, imprimirá os números 2, 1 e "Liftoff!".

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Um [laço `repeat-while`][while-loops] é parecido com um laço `while`, mas a condição é avaliada depois de o corpo do laço ser executado.
Isso significa que o corpo do laço sempre será executado pelo menos uma vez, mesmo que a condição seja falsa.
Os laços `repeat-while` no Swift têm a seguinte estrutura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Aqui, o laço será executado apenas uma vez, já que a condição é falsa.
Como é um laço `repeat-while`, o corpo do laço será executado uma vez antes de a condição ser avaliada.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Laços com vinculação opcional

Uma variante comum dos laços `while` no Swift é o laço `while` com vinculação opcional.
Esses laços se repetem enquanto a chamada a alguma função que gera um valor opcional retornar um valor que não seja `nil`.
Esse valor (não opcional) é então vinculado a um nome à sua escolha e pode ser usado no corpo do laço.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
