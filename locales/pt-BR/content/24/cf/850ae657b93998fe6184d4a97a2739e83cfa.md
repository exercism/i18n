# Introdução

A memória dinâmica é implementada por funções de biblioteca que o programador usa para alocar e desalocar memória em tempo de execução.
Já que é o programador quem controla a alocação e a desalocação de memória, a segurança da memória dinâmica depende de ele não cometer erros.
Por isso, a memória dinâmica é uma das principais fontes de bugs de programação e um dos principais alvos de ataques de hackers.

## malloc

`malloc` é uma função declarada em `stdlib.h` usada para alocar memória dinâmica.
Se a alocação der certo, é retornado um ponteiro que aponta para o endereço do primeiro byte da memória alocada.
Se a alocação não der certo, é retornado `NULL`.
É prudente verificar se o resultado de `malloc` é `NULL` e tratar a falha com cuidado.
O ponteiro retornado é do tipo `pointer-to-void`, que pode ser considerado, de modo geral, um ponteiro "genérico" que pode ser convertido para o tipo específico usado pela memória.
`malloc` tem um parâmetro, que é o tamanho da memória desejada em bytes.
O tamanho total para alocar um array é o tamanho do tipo de dado de cada elemento multiplicado pelo número de elementos.
O operador `sizeof` costuma ser usado para obter o tamanho do tipo de dado de cada elemento.
O exemplo a seguir demonstra isso

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

É importante lembrar que a memória recém-alocada por `malloc` não é inicializada, mas pode conter valores lixo.
Repare que o `sizeof` do ponteiro `numbers` não é o número de elementos do array, nem a quantidade total de memória alocada.
O tamanho do ponteiro retornado por `malloc` é o tamanho de qualquer ponteiro naquele sistema específico.
O código de exemplo foi executado em um sistema de 64 bits, então o tamanho do ponteiro era 8 bytes (multiplicado por 8 bits por byte = 64 bits).
O tipo do ponteiro foi convertido implicitamente de pointer-to-void para pointer-to-int.
Ele também poderia ter sido convertido explicitamente assim: `int * numbers = (int *) malloc(sizeof(int) * count);`.
Se os valores com certeza serão gravados antes de serem lidos, usar `malloc` pode ser uma forma eficiente de alocar memória.
Mas, se houver a chance de os valores serem lidos antes de serem inicializados, usar `malloc` é arriscado.
Uma forma mais segura de alocar memória é usar `calloc`, que inicializa com zero a memória recém-alocada.

Repare nos exemplos acima que foi usado `free(numbers)`.

## free

`free` é uma função declarada em `stdlib.h` usada para desalocar memória que foi alocada dinamicamente.
A memória alocada dinamicamente permanece reservada até ser liberada por `free`.
Alguns sistemas operacionais podem liberar automaticamente a memória alocada dinamicamente quando o programa termina, mas é boa prática não depender disso.
`free` tem um parâmetro, que é um ponteiro para a memória que foi alocada dinamicamente.
Um ponteiro que não é definido como `NULL` depois de ser liberado é chamado de ponteiro pendente.
Um ponteiro pendente pode apontar para outra memória que não aquela para a qual foi planejado.
Assim, um ponteiro pendente pode levar à corrupção de dados e à substituição e execução de código arbitrário.
Um ponteiro para memória alocada que não foi limpo com a atribuição de `NULL` pode ser usado para hackear o programa.
É boa prática definir um ponteiro como `NULL` depois de passá-lo para `free`.

## calloc

`calloc` é uma função declarada em `stdlib.h` usada tanto para alocar memória dinâmica quanto para inicializar com zero a memória recém-alocada.
Se a alocação der certo, é retornado um ponteiro que aponta para o endereço do primeiro byte da memória alocada.
Se a alocação não der certo, é retornado `NULL`.
É prudente verificar se o resultado de `calloc` é `NULL` e tratar a falha com cuidado.
O ponteiro retornado é do tipo `pointer-to-void`, que pode ser considerado, de modo geral, um ponteiro "genérico" que pode ser convertido para o tipo específico usado pela memória.
`calloc` tem dois parâmetros.
O primeiro parâmetro indica quantos elementos do tipo de dado especificado serão alocados.
O segundo parâmetro é o tamanho do tipo de dado especificado a ser alocado.

No exemplo a seguir, todos os comandos `printf` devem sempre mostrar `0`, já que `calloc` garante que os valores recém-alocados sejam zerados.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` é uma função declarada em `stdlib.h` usada para expandir ou reduzir memória já alocada.
Se a realocação der certo, é retornado um ponteiro que aponta para o endereço do primeiro byte da memória realocada.
Se a realocação não der certo, é retornado `NULL`.
É prudente verificar se o resultado de `realloc` é `NULL` e tratar a falha com cuidado.
`realloc` tem dois parâmetros.
O primeiro parâmetro é um ponteiro para a memória existente que será realocada.
O segundo parâmetro é o tamanho, em bytes, da memória realocada.
Os valores definidos antes da expansão da memória são mantidos.
É importante lembrar que a memória adicionada ao expandir não é inicializada com zero e seus valores podem ser qualquer coisa.
Além disso, a memória removida ao reduzir também não é inicializada e pode conservar os valores.
O exemplo a seguir demonstra a expansão e a redução de um array

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
