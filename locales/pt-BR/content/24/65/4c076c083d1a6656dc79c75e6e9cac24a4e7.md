# Instruções

Neste exercício, você vai documentar o código que acabou de escrever para ajudar você a preparar uma lasanha incrível.
É pouco provável que você volte a olhar para esse código relacionado à lasanha, mas documentar código ajuda muito se você quiser que qualquer projeto maior seja compreensível para outras pessoas (ou para você)!

Para documentar seu código, escreva uma "docstring" para cada uma das três funções. Veja como fazer:

- Consulte a seção [Documentação][doc] no Manual da Julia.
- Comece pela assinatura da função, indentada com 4 espaços.
- Inclua uma única frase de uma linha descrevendo o que a função faz, com suas próprias palavras.

~~~~exercism/note
Você recebe a solução exemplar do [exercício anterior](https://exercism.lol/tracks/julia/exercises/lasagna).
Você também pode escolher a sua própria solução daquele exercício como ponto de partida, se preferir.
~~~~

## 1. Documente preptime

A primeira função que você escreveu foi `preptime`, que calcula quanto tempo leva para preparar a lasanha.

## 2. Documente remaining_time

A segunda função que você escreveu foi `remaining_time`, que calcula quanto tempo falta até a lasanha ficar pronta.

## 3. Documente total_working_time

A terceira função que você escreveu foi `total_working_time`, que calcula quanto tempo leva para fazer a lasanha.
