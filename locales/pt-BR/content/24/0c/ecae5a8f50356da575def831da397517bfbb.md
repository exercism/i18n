# Introdução

Os inteiros podem ser vistos não apenas como valores numéricos, mas como padrões de bits. O vocabulário [`math`][math] do Factor tem as operações de baixo nível padrão sobre esses padrões de bits, e o vocabulário [`math.bitwise`][bitwise] acrescenta alguns auxiliares para trabalhar com valores de largura fixa.

## Deslocamentos de bits

`shift ( m n -- m' )` desloca os bits de `m`. Um `n` *positivo* desloca para a esquerda (multiplicando por 2 a cada passo); um `n` *negativo* desloca para a direita (dividindo por 2 a cada passo):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

Para inteiros positivos, o deslocamento à direita descarta bits da parte de baixo e preenche com zeros. Para inteiros *negativos*, o `shift` do Factor é aritmético: ele preserva o bit de sinal, preenchendo conceitualmente a partir da esquerda com cópias do bit de sinal. (Os inteiros do Factor têm precisão arbitrária, então "a esquerda" se estende tanto quanto for necessário.)

## Lógica bit a bit

As quatro operações lógicas básicas são:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

O `bitnot` de `0b1011` é `-12` porque os inteiros do Factor têm precisão arbitrária: inverter os bits de `0b1011` é conceitualmente "todos uns com os quatro bits mais baixos trocados por `0100`", que, lido como um bignum com sinal, vale `-12`.

## Tratando um valor como N bits

`bits ( x n -- y )` do `math.bitwise` aplica uma máscara em `x` para seus `n` bits mais baixos. Essa é a forma do Factor de "reinterpretar um valor como um inteiro sem sinal de N bits":

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

Esse segundo exemplo importa para este exercício. Se você começa com um valor Int32 negativo em complemento de dois e quer deslocá-lo "logicamente" à direita (preenchendo com zeros a partir da esquerda) por `amount`, a expressão idiomática do Factor é:

```
( value -- shifted )
32 bits  amount neg  shift
```

Aplique a máscara para 32 bits primeiro para mudar para a interpretação sem sinal, depois desloque. Como o valor mascarado é não negativo, o `shift` simplesmente descarta bits da parte de baixo e preenche com zeros.
