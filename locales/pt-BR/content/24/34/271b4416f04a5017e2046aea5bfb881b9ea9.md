# Instruções

Larry é um alienígena Lisp que gosta de escrever código para jogar. Hoje ele quer escrever algumas funções para ajudá-lo em um jogo muito parecido com o jogo da velha.

Assim como o jogo da velha, este jogo é jogado em um tabuleiro que é uma grade 3x3.

## 1. Começando do zero

Primeiro, Larry precisa de uma função para criar um tabuleiro em branco, `make-empty-board`.
Todas as casas do tabuleiro devem ser `NIL`.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Começando a partir de um tabuleiro existente

Agora, Larry precisa de uma função para criar um tabuleiro a partir de uma lista de linhas.
Por exemplo:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. Condição de vitória

Se houver um caso em que existem 3 símbolos iguais em uma linha, então aquele jogador venceu.
Larry vai precisar de uma função, `all-the-same-p`, que, dado um array de 3 itens, é avaliada como `T` se todos os itens forem o mesmo símbolo.
(A função `eq` pode ser usada para determinar se dois símbolos são iguais.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. Em uma linha

Agora Larry precisa de uma forma de obter os elementos de uma linha.
A função `row` recebe um tabuleiro e um número de linha e deve retornar um array com os elementos dessa linha.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. Em uma coluna

Por fim, Larry precisa de uma forma de obter os elementos de uma coluna.
A função `column` recebe um tabuleiro e um número de coluna e deve retornar um array com os elementos dessa coluna.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
