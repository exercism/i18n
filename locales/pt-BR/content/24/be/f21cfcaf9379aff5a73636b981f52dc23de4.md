# Números

Crystal tem um tipo, `Number`, que é o tipo base para todos os tipos numéricos.
Existem dois subtipos principais dentro do tipo Number: [`Int`][int] e [`Float`][float].

`Int` é a abreviação de integer e representa números inteiros.
`Int` pode ser tanto negativo quanto positivo, e não tem ponto decimal.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` representa números com ponto decimal.
Os `Float`s podem ser tanto negativos quanto positivos.

```crystal
10.5.class
# => Float64
```

## Conversão entre `Int` e `Float`

Usando os métodos 'to_i' e 'to_f', você pode converter entre `Int` e `Float`.
O número é arredondado para baixo quando você converte de `Float` para `Int`.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Operadores aritméticos

Você pode usar os [operadores aritméticos básicos][math] com `Int` e `Float`.
Os operadores são `+`, `-`, `*`, `/` e `%`.
Ao usar esses operadores, você pode misturar `Int` e `Float`.

### Adição, subtração e multiplicação

O operador `+` é usado para a adição, o operador `-` para a subtração, e o operador `*` para a multiplicação.

| Operador | Exemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Divisão

A divisão é usada para dividir números.
O operador `/` é usado para a divisão.
O resultado será sempre um Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Em algumas linguagens de programação, ao dividir por zero, o resultado é um erro.

No Crystal, ao dividir por zero, o resultado é `Infinity` ou `-Infinity`.
A única exceção é dividir zero por zero, o que resulta em `NaN` (Not a Number).
`Infinity` e `NaN` são valores especiais no tipo `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## Divisão inteira

A divisão inteira é usada para dividir números e obter a parte inteira do resultado.
O resultado será sempre arredondado para baixo, para um Int.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
Dividir por zero ao usar a divisão inteira resulta em um `DivisionByZeroError`.
Isso é diferente da divisão normal.
~~~~

### Módulo

O módulo é usado para obter o resto de uma divisão.
O operador `%` é usado para o módulo.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Dividir por zero ao usar o módulo resulta em um DivisionByZeroError.
Isso é diferente da divisão normal.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Exponenciação

A exponenciação é usada para elevar um número a uma potência.
O operador `**` é usado para a exponenciação.
O resultado de uma operação com um `Float` e um `Int` será um `Float`.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## Arredondamento

O método `round` recebe um argumento opcional: o número de casas decimais para arredondar.
O número padrão de casas decimais é 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### Arredondar para cima e para baixo

Você também pode arredondar para cima ou para baixo, para um `Int`, usando os métodos `ceil` e `floor`.
O método `ceil` arredonda para cima, e o método `floor` arredonda para baixo.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## Precedência e parênteses

Crystal permite parênteses (`()`), que podem ser usados para agrupar expressões.
Isso é útil quando você quer mudar a ordem das operações.

Ao usar vários operadores aritméticos, a ordem das operações é a mesma da matemática, também conhecida como [PEMDAS][pemdas].
Ela segue a ordem de parênteses (`()`), expoentes (`**`), multiplicação (`*`) e divisão (`/`), e adição (`+`) e subtração (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
