# Introdução

Python tem duas construções de laço.
Laços `while` para iteração _indefinida_ (não contada) e laços `for` para iteração _definida_ (contada).
As palavras-chave `break`, `continue` e `else` ajudam a personalizar o comportamento do laço.
`range()` e `enumerate()` ajudam com a contagem e a indexação no laço.


## While

Os laços [`while`][while statement] vão continuar executando enquanto a `loop expression` ou "teste" for avaliada como `True` em um [`boolean context`][truth value testing], terminando quando for avaliada como `False`:

```python

# Lists are considered "truthy" in a boolean context if they
# contain one or more values, and "falsy" if they are empty.

>>> placeholders = ["spam", "ham", "eggs", "green_spam", "green_ham", "green_eggs"]

>>> while placeholders:
...     print(placeholders.pop(0))
...
'spam'
'ham'
'eggs'
'green_spam'
'green_ham'
'green_eggs'
```


## For

O [`for`][for statement] `loop` básico do Python é melhor descrito como um _`for each`_, que percorre os valores de qualquer [objeto iterável][iterable], terminando quando não há mais valores retornados pela chamada de [`next()`][next built-in]:

```python

>>> word_list = ["bird", "chicken", "barrel", "bongo"]

>>> for word in word_list:
...    if word.startswith("b"):
...        print(f"{word.title()} starts with a B.")
...    else:
...        print(f"{word.title()} doesn't start with a B.")
...
'Bird starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel starts with a B.'
'Bongo starts with a B.'
```


## Objeto de sequência range()

Quando não há um `iterable` específico informado, a sequência especial [`range()`][range] é usada como contador do laço.
`range()` exige um `int` onde a sequência deve `stop`, e pode opcionalmente receber os parâmetros `start` e `step`.
Se nenhum número `start` for informado, a sequência começará em 0.
Objetos `range()` são **preguiçosos** (_os valores são gerados sob demanda_), suportam todas as [operações comuns de sequência][common sequence operations] e ocupam uma quantidade fixa de memória, não importa o tamanho da sequência especificada.

```python
# Here we use range to produce some numbers, rather than creating a list of them in memory.
# The values will start with 1 and stop *before* 7

>>> for number in range(1, 7):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
'1 is odd.'
'2 is even.'
'3 is odd.'
'4 is even.'
'5 is odd.'
'6 is even.'

# range() can also take a *step* parameter.
# Here we use range to produce only the "odd" numbers, starting with 3 and stopping *before* 15.

>>> for number in range(3, 15, 2):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
...
'3 is odd.'
'5 is odd.'
'7 is odd.'
'9 is odd.'
'11 is odd.'
'13 is odd.'
```


## Valores e índices com enumerate()

Se você precisar tanto dos valores quanto dos índices, a função embutida [`enumerate(<iterable>)`][enumerate] retorna pares (`index`, `value`):

```python

>>> word_list = ["bird", "chicken", "barrel", "apple"]

# *index* and *word* are the loop variables.
# Loop variables can be any valid python name.

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    else:
...        print(f"{word.title()} (at index {index}) doesn't start with a B.")
...
'Bird (at index 0) starts with a B.'
'Chicken (at index 1) doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Apple (at index 3) doesn\'t start with a B.'


# The same method can be used as a "lookup" for pairing items between two lists.
# Of course, if the lengths or indexes don't line up, this doesn't work.

>>> word_list = ["cat", "chicken", "barrel", "apple", "spinach"]
>>> category_list = ["mammal", "bird", "thing", "fruit", "vegetable"]

>>> for index, word in enumerate(word_list):
...    print(f"{word.title()} is in category: {category_list[index]}.")
...
'Cat is in category: mammal.'
'Chicken is in category: bird.'
'Barrel is in category: thing.'
'Apple is in category: fruit.'
'Spinach is in category: vegetable.'
```


## Alterando o comportamento do laço

A palavra-chave [`continue`][continue statement] pode ser usada para avançar até a próxima iteração:

```python
word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple", "bear"]

# This will skip *bird*, at index 0
for index, word in enumerate(word_list):
    if index == 0:
        continue
    if word.startswith("b"):
        print(f"{word.title()} (at index {index}) starts with a b.")

'Barrel (at index 2) starts with a b.'
'Bongo (at index 3) starts with a b.'
'Bear (at index 6) starts with a b.'
```


A palavra-chave [`break`][break statement] (_como em muitas linguagens da família C_) pode ser usada para parar a iteração e "sair" do `loop` mais interno que a envolve:

```python
>>>  word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    elif word == "sliver":
...       break
...    else:
...       print(f"{word.title()} doesn't start with a B.")
... print("loop broken.")
...
'Bird (at index 0) starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'loop broken.'
```
