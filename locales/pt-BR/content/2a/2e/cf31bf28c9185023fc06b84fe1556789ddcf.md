# Introdução

Um número inteiro é um número sem separador decimal.

Os tipos inteiros podem armazenar apenas números positivos (sem sinal) ou armazenar números positivos e negativos (com sinal).

Alguns exemplos são -6, 0, 1, 25 e 976.

Repare que você pode usar sublinhados para melhorar a legibilidade de números mais longos: `1_000_000`.
