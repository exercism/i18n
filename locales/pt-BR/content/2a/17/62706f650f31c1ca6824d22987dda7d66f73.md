# Introdução

## Charlists

As charlists são criadas com o sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Observe que em versões mais antigas do Elixir, as charlists são representadas como `'hello'`, com aspas simples.
~~~~

Apesar de parecerem muito com strings, os dois tipos de dados são bem diferentes entre si. Uma charlist é uma lista de números inteiros. Esses números representam os valores Unicode de um determinado caractere, também conhecidos como pontos de código.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Você pode colocar um `?` antes de um caractere para obter o ponto de código dele.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Como charlists são listas, você pode trabalhar com elas como com qualquer outra lista: usando recursão e correspondência de padrões.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Você pode concatenar duas listas usando `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Quanto maior for a primeira lista, mais lenta é a concatenação, então evite adicionar repetidamente ao final de listas de tamanho arbitrário.

## Case

`case` é uma estrutura de controle de fluxo que permite comparar um determinado valor com vários padrões. As cláusulas de uma expressão `case` são avaliadas de cima para baixo, até que uma correspondência seja encontrada.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
