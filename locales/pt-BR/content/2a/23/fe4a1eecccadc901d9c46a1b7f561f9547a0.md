# Sobre

Os operadores ternários permitem definir condições `if` em expressões, em vez de blocos de instruções. Isso ecoa abordagens de programação funcional e muitas vezes pode deixar o código mais expressivo e menos propenso a erros.

O operador ternário combina 3 expressões: uma condição seguida de uma expressão que é avaliada e retornada se a condição for verdadeira (a parte `if`, introduzida por `?`) e uma expressão que é avaliada e retornada se a condição for falsa (a parte `else`, introduzida por `:`).

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
