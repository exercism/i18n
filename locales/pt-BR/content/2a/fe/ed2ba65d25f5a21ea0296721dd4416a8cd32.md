# Dicas

## 1. Converter uma representação binária em um número inteiro

- Existe um [método embutido][string-to_i] para converter uma string com representação binária em um número inteiro, dada a base.

## 2. Obter o bit menos significativo de um número inteiro

- Existe um [método embutido][integer-bit] para obter um bit de um número inteiro, dado um índice.
- O bit menos significativo é o bit mais à direita.
  Ele fica no índice 0.

## 3. Obter o valor hexadecimal de um canal de cor

- Existe um [método embutido][integer-to_s] para converter um número inteiro em uma string com representação hexadecimal, dada a base.
- O método pode receber um argumento opcional para especificar a precisão da quantidade de dígitos gerados.

## 4. Obter o valor hexadecimal de RGB

- Você pode usar os métodos já definidos para obter o valor hexadecimal de um canal de cor.
