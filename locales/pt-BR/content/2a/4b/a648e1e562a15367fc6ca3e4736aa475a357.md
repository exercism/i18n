# Testes

Há duas formas diferentes de preparar o ambiente para rodar os testes com Objective-C:

- Criar um projeto no Xcode com um target de testes que vai rodar os testes.
- Usar a gem do Ruby `objc` como utilitário para rodar os testes.

As duas são descritas com mais detalhes aqui: https://exercism.org/tracks/objective-c/tests
