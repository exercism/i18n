# Introdução

[Nil][nil-dictionary] é uma palavra do inglês que significa "nada" ou "zero".
No Ruby, `nil` é usado para expressar a _ausência_ de um objeto.
Em outras linguagens de programação, valores `null` ou `none` podem desempenhar um papel parecido.

```ruby
# I do not have a favorite color
favorite_color = nil
```

O Ruby atribui o valor padrão `nil` a qualquer variável de instância quando ela é encontrada pela primeira vez, até que seja definida de outra forma.

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
