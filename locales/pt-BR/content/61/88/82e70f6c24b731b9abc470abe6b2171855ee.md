# Instalação

A maneira mais fácil de instalar Ceylon é simplesmente **não** instalar.
Você deve conseguir resolver a maioria dos exercícios usando nossa [IDE web](http://try.ceylon-lang.org/).

Mas, se você preferir, pode instalar a distribuição de linha de comando. A maneira mais fácil de fazer isso é pelo [SDKMAN](http://sdkman.io/), então instale-o primeiro caso ainda não tenha, e depois é só digitar `sdk install ceylon` no terminal.

Quem usa OSX também pode instalar pelo [gerenciador de pacotes Homebrew](http://mxcl.github.com/homebrew/).

Instruções de instalação para outras plataformas, assim como para a Ceylon IDE, um plugin para o Eclipse, estão disponíveis no [site oficial](http://ceylon-lang.org/download/).
