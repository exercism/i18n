# Introdução

## Atributos

Um [`Attribute` do C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) oferece uma forma de decorar uma declaração para associar metadados a: uma classe, um método, um enum, um campo, uma propriedade ou qualquer [outra declaração suportada](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Você pode aplicar um atributo adicionando-o na linha anterior à declaração, usando um `ClassAttribute` e um `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Esses metadados declarativos apenas associam informações estruturadas adicionais ao código e não modificam seu comportamento, mas outras partes do código usam esses metadados para mudar como o alvo se comportaria, ou para adicionar, alterar, remover ou restringir algumas de suas funcionalidades.

Existem muitos [atributos predefinidos e reservados](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), por exemplo: `Flags`, `Obsolete`, `Conditional` e `Experimental`. Cada um tem um significado semântico específico, que pode ser consultado na documentação do C#. Repare que o nome completo de um atributo como [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) tem o formato `<Name>Attribute` (por exemplo, `FlagsAttribute`).

## Enums de flags

O [tipo `enum` do C#](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) representa um conjunto fixo de constantes nomeadas (uma enumeração).

Normalmente, um membro de um `enum` só pode se referir a exatamente uma dessas constantes nomeadas. Porém, às vezes é útil se referir a mais de uma constante. Para isso, pode-se anotar o `enum` com o [atributo `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)

Um enum de flags pode ser definido da seguinte forma (usando a notação de inteiros binários `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Uma instância de `PhoneFeatures` cujo valor é `0b00000011` tem as flags `Call` _e_ `Text` definidas.

Por padrão, o tipo `int` é usado para os valores dos membros do enum. Pode-se usar um tipo de inteiro diferente especificando o tipo na declaração do enum:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
