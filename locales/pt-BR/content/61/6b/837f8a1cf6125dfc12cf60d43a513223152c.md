# Sobre

Muitos [tipos de membros de structs e classes][expression-bodied-members] (sendo os campos a principal exceção) podem usar a sintaxe de expression-bodied member. Definir um membro com uma expressão costuma produzir código mais conciso e legível do que os blocos/instruções tradicionais.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

Os expression-bodied members não podem ter blocos com várias instruções, mas quem vem de programação funcional deve saber que tudo o que um membro tradicional faz pode ser feito com um desses membros. A "expressão" pode ser uma operação de atribuição que cria efeitos colaterais, ou uma chamada de método, o que significa que tudo é possível.

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
