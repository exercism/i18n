# Dicas

## Geral

- A contagem de pássaros por dia fica armazenada em um campo chamado `birdsPerDay`.
- A contagem de pássaros por dia é um array que contém exatamente 7 números inteiros.

## 1. Verifique quais foram as contagens da última semana

- Como guardamos a última semana, basta retornar os valores da última semana.

## 2. Verifique quantos pássaros visitaram hoje

- Lembre-se de que as contagens estão ordenadas por dia, da mais antiga para a mais recente, e o último elemento representa hoje.
- Você pode acessar o último elemento usando o índice (fixo) dele (lembre-se de começar a contar do zero) ou calculando o índice a partir do tamanho do array.

## 3. Incremente a contagem de hoje

- Defina o elemento que representa a contagem de hoje como a contagem de hoje mais 1.

## 4. Verifique se houve algum dia sem pássaros visitantes

- O array pode ser iterado com um laço `for`.
- Outra solução é usar a API de Streams do Java.

## 5. Calcule o número de pássaros visitantes nos primeiros dias

- Uma variável pode ser usada para guardar a contagem do número de pássaros visitantes.
- O array pode ser iterado com um laço `for`.
- A variável pode ser atualizada dentro do laço.
- Lembre-se: os arrays são indexados a partir de `0`.

## 6. Calcule o número de dias movimentados

- Uma variável pode ser usada para guardar o número de dias movimentados.
- O array pode ser iterado com um laço `foreach`.
- A variável pode ser atualizada dentro do laço.
- Uma condicional pode ser usada dentro do laço.
