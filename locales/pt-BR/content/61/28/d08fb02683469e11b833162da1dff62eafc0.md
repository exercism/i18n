# Instruções

Trabalhando na _Instruments of Texas_, você fica encarregado de uma calculadora experimental escrita em C#. Você está montando um harness de testes para verificar várias funções da calculadora, começando pela multiplicação. Você vai notar que há uma preocupação especial quando os dois operandos da multiplicação são negativos.

A classe `Calculator` já foi fornecida para você e não deve ser modificada.

## 1. Complete a definição da exceção definida pelo usuário `CalculationException`

Complete a definição do construtor de `CalculationException`, que precisará armazenar (encapsular) qualquer exceção lançada pela calculadora, bem como os operandos que estão sendo processados no momento em que a exceção é lançada.

## 2. Trate as condições de overflow na calculadora e forneça informações aprimoradas ao chamador

Implemente o método `CalculatorTestHarness.Multiply()`, que deve chamar o método `Calculator.Multiply()` da instância de `Calculator` passada para o construtor, passando os valores inteiros x e y. Se ocorrer um overflow no método `Calculator.Multiply()`, ele vai lançar uma `OverflowException`. Essa exceção deve ser capturada no método `CalculatorTestHarness.Multiply()` e encapsulada em uma `CalculationException`, e os valores x e y que estão sendo passados devem ser armazenados como os operandos da exceção. O objeto `CalculationException` recém-criado deve ser lançado. Você pode ignorar o valor retornado pelo método `Calculator.Multiply()` se ele for bem-sucedido.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. Teste a operação de multiplicação com entradas válidas

Implemente o método `CalculatorTestHarness.TestMultiplication()`, que recebe dois inteiros e chama o método `CalculatorTestHarness.Multiply()`. `"Multiply succeeded"` é retornado.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. Teste a operação de multiplicação com entradas negativas

Modifique o método `CalculatorTestHarness.TestMultiplication()` para que `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"` seja retornado se os dois argumentos inteiros forem negativos (menores que zero).

O espaço reservado `<INNER_EXCEPTION_MESSAGE>` deve ser substituído pela mensagem da exceção interna da `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. Teste a operação de multiplicação com entradas positivas

Modifique o método `CalculatorTestHarness.TestMultiplication()` para que `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"` seja retornado se pelo menos um dos argumentos inteiros não for negativo.

O espaço reservado `<INNER_EXCEPTION_MESSAGE>` deve ser substituído pela mensagem da exceção interna da `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
