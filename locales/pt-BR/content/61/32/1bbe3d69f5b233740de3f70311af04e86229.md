# Instruções

Mary é uma grande fã da série de TV _Star Trek: The Next Generation_.
Ela costuma jogar RPG de mesa, em que ela e seus amigos fingem ser a tripulação da _Starship Enterprise_.
A personagem de Mary é o Capitão Picard, o que significa que ela precisa manter o diário de bordo do capitão.
Ela adora a parte criativa do jogo, mas não gosta de gerar dados aleatórios na hora.

Ajude Mary criando geradores aleatórios para os dados que costumam aparecer no diário de bordo do capitão.

~~~~exercism/note
A implementação inicial deste exercício recebe uma instância de `java.util.Random` como argumento do construtor.
Isso permite que os testes do exercício passem uma instância com uma semente predefinida, o que torna os resultados dos testes previsíveis.

Por isso, espera-se que você use a instância de `java.util.Random` fornecida na sua implementação.
~~~~

## 1. Gere um planeta aleatório

A _Starship Enterprise_ encontra muitos planetas em suas viagens.
No universo de Star Trek, os planetas são divididos em categorias com base em suas propriedades.
Por exemplo, a Terra é um planeta de classe `M`.
Todas as classes planetárias possíveis são: `D`, `H`, `J`, `K`, `L`, `M`, `N`, `R`, `T` e `Y`.

Implemente o método `randomPlanetClass()`.
Ele deve retornar uma das classes planetárias de forma aleatória.

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. Gere um número de registro de nave aleatório

A Enterprise (número de registro `NCC-1701`) não é a única nave espacial voando por aí!
Quando ela se encontra com outra nave, Mary precisa anotar o número de registro dessa nave.

Os números de registro começam com o prefixo "NCC-" e depois usam um número de `1000` a `9999` (inclusive).

Implemente o método `randomShipRegistryNumber()` que retorna um número de registro de nave aleatório.

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. Gere uma data estelar aleatória

De que serve um diário se ele não inclui datas?

Uma data estelar é um número de ponto flutuante.
As aventuras da _Starship Enterprise_ na primeira temporada de _The Next Generation_ acontecem entre as datas estelares `41000.0` e `42000.0`.
O "4" representa o século XXIV e o "1", a primeira temporada.

Implemente o método `randomStardate()` que retorna um número de ponto flutuante entre `41000.0` (inclusive) e `42000.0` (exclusive).

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
