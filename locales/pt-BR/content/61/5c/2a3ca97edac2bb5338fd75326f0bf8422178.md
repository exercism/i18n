# Instruções

Neste exercício, vamos simular o primeiro turno de uma partida de [Blackjack][blackjack].

## 1. Calcule o valor de qualquer carta.

Você vai receber duas cartas e poderá ver a carta virada para cima do dealer.
Todas as cartas são representadas por uma string como "ace", "king", "three", "two", etc.
Os valores de cada carta são:

| carta | valor |  carta  | valor |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _other_ |   0   |

~~~~exercism/note
Normalmente, os ases podem valer 1 ou 11, mas, para simplificar, vamos assumir que eles só podem valer 11.
~~~~

Implemente o método `Blackjack.parse_card`, que recebe uma carta em forma de string como argumento.
O método deve retornar o valor da carta como um número inteiro.

```Crystal
Blackjack.parse_card("ace")
# => 11
```

## 2. Nomeie faixas de valores.

A pontuação do jogador precisa ser categorizada em faixas de valores.
A pontuação do jogador é calculada somando os valores das duas cartas do jogador.
As faixas usadas são:

|   faixa   |  valor   |
| :-------: | :------: |
|    low    | [4, 11]  |
|    mid    | [12, 16] |
|   high    | [17, 20] |
| blackjack |   [21]   |

Implemente o método `Blackjack.card_range`, que recebe duas cartas em forma de string como argumentos.
O método deve retornar o nome da faixa de valores em que as duas cartas se encaixam.

```Crystal
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. Implemente a lógica de decisão para o primeiro turno.

Dependendo das suas duas cartas e da carta do dealer, existe uma estratégia para o primeiro turno do jogo, na qual você tem as seguintes opções:

- Parar (S)
- Pedir carta (H)
- Dividir (P)
- Ganhar automaticamente (W)

Embora ainda não seja ideal, você vai seguir a estratégia que seu amigo Alex vem desenvolvendo, que é a seguinte:

- Se você tiver um par de ases, sempre divida.
- Se você tiver um Blackjack (duas cartas que somam um valor de 21), e o dealer não tiver um ás, uma figura ou um dez, você ganha automaticamente.
  Se o dealer tiver alguma dessas cartas, você terá que parar e esperar a revelação da outra carta.
- Se as suas cartas somarem um valor dentro da faixa [17, 20], você deve sempre parar.
- Se as suas cartas somarem um valor dentro da faixa [12, 16], você deve sempre parar, a menos que o dealer tenha um 7 ou mais, caso em que você deve sempre pedir carta.
- Se as suas cartas somarem 11 ou menos, você deve sempre pedir carta.

Implemente o método `Blackjack.first_turn`, que recebe três cartas em forma de string como argumentos.
O método deve retornar a decisão que você deve tomar como uma string.

```Crystal
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
