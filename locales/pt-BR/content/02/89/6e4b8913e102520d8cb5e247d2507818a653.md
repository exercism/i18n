# Dicas

## 1. Criar um vetor com todos os vagões

- Um laço for/while clássico com `push!` em um `Vector` funciona.
- Caso contrário, a função [`collect()`][collect] pode ser mais concisa.
- Como alternativa, o splatting funciona dentro de um construtor de vetor:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. Corrigir o vetor de vagões

- É útil separar os vagões da frente e a locomotiva de todo o resto, para depois remontá-los na ordem correta.
- A atribuição múltipla com splatting pode ajudar (veja a introdução).

## 3. Adicionar as paradas que faltam

- Lembre-se: esta função não modifica a entrada! Crie um novo `Dict`.
- Só o nome da parada é necessário, não o número da parada, então cada par precisa ser separado.
- Há várias formas de montar o vetor de nomes:
  -  Laço for/while com `push!()` em um `Vector`.
  -  Array [compreensão][comprehensions]
  -  [`map()`][map] para aplicar uma função sobre o vetor.
  -  [Broadcasting][broadcasting] de uma função [anônima][anonymous] é possível:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. Ampliar as informações de roteamento

- Depois do slurping, `more_route_information` é uma coleção `Pairs()`.
- A função [`merge()`][merge] combina dois ou mais `Dict`s, mas também aceita uma coleção `Pairs()`.
  A conversão explícita da coleção `Pairs()` para um `Dict` é possível, mas desnecessária.
