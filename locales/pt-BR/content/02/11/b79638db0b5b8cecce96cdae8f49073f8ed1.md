# Taxas de Freelancer

## História

Neste exercício, você vai escrever código para ajudar um freelancer a se comunicar com um gerente de projeto, oferecendo alguns utilitários para calcular rapidamente as taxas diária e mensal, opcionalmente com um desconto.

Primeiro, estabelecemos algumas regras entre o freelancer e o gerente de projeto:

- A taxa diária é 8 vezes a taxa horária;
- Um mês tem 22 dias faturáveis.

O freelancer se oferece para aplicar um desconto caso o gerente de projeto prefira deixar o freelancer faturar por mês. Isso pode ser útil quando há um certo orçamento com o qual o gerente de projeto precisa trabalhar.

Os descontos são modelados como números fracionários seguidos de um `%` (porcentagem) entre `0.0%` (sem desconto) e `90.0%` (desconto máximo).

## Tarefas

Estas são tarefas de exemplo que se encaixam na história do freelancer se comunicando com um gerente de projeto:

- Calcular a taxa diária a partir de uma taxa horária
- Calcular a taxa mensal, a partir de uma taxa horária e de um desconto
- Calcular o número de dias úteis a partir de um orçamento, uma taxa e um desconto

## Terminologia

Estas são recomendações, não regras, para a terminologia recorrente nas instruções (incluindo os comentários do stub):

- A taxa diária é 8 vezes a taxa horária; isso deve ser mencionado
- A taxa mensal é 22 vezes a taxa diária; isso deve ser mencionado
- Se o desconto for informado como um tipo _diferente_ dos tipos numéricos, use a terminologia **descontos são modelados como**
