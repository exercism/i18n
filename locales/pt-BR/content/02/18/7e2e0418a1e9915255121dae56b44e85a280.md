# Dicas

## Geral

- Leia a documentação de [MapSet][mapset]
- A documentação de [Enum][enum] também pode ser útil

## 1. Comece uma coleção

- [Esta é a função de `MapSet` mais apropriada][new] para resolver a tarefa

## 2. Aumente a coleção

- Use [esta função de `MapSet`][put] para adicionar cartas à sua coleção
- Use [aquela função de `MapSet`][member] para verificar se você tem uma carta específica na sua coleção

## 3. Comece a trocar

- Para verificar se você pode trocar uma carta, use [esta função de `MapSet`][member]
- Para atualizar sua coleção, use [esta função de `MapSet`][delete] e [aquela][put]

## 4. Só pode haver uma de cada

- Um `MapSet` tem a propriedade de guardar apenas valores únicos
- Use [esta função de `MapSet`][new] para criar um conjunto e [aquela][to_list] para transformá-lo de volta em uma lista
- Os `MapSet`s não têm noção de ordem, você deve usar [esta função de `Enum`][sort] para ordenar as cartas, mesmo que os testes passem sem isso

## 5. Cartas que eles não têm

- Use [esta função de `MapSet`][difference] para verificar diferenças entre coleções
- Use [aquela função de `MapSet`][size] para obter o número de cartas em uma coleção

## 6. Cartas que todos eles têm

- [Esta função de `Enum`][reduce] vai ajudar a percorrer todas as coleções
- Use casamento de padrões na lista para diferenciar listas vazias e não vazias
- [Esta função de `MapSet`][intersection] vai ajudar você a manter as cartas em comum
- [Esta função de `MapSet`][to_list] pode criar uma lista
- Os `MapSet`s não têm noção de ordem, você deve usar [esta função de `Enum`][sort] para ordenar as cartas, mesmo que os testes passem sem isso

## 7. Todas as cartas

- [Esta função de `Enum`][reduce] vai ajudar a percorrer todas as coleções
- Use [esta função de `MapSet`][new_empty] como acumulador
- [Esta função de `MapSet`][union] vai ajudar você a acumular todas as cartas
- [Esta função de `MapSet`][size] vai contar quantas cartas você tem

## 8. Brilhante para a vitória

- Use [esta função de `MapSet`][split_with] para separar sua coleção
- Use [esta função de `String`][starts_with] para detectar cartas brilhantes
- [Esta função de `MapSet`][to_list] pode criar uma lista
- Os `MapSet`s não têm noção de ordem, você deve usar [esta função de `Enum`][sort] para ordenar as cartas, mesmo que os testes passem sem isso
