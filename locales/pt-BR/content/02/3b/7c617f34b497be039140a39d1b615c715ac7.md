# Sobre

[TypeScript](https://www.typescriptlang.org/) (TS) é um superset de JavaScript (JS), criado na Microsoft em resposta à frustração de desenvolver aplicações de grande porte em JS. Em um projeto JS grande, saber quais propriedades seus próprios objetos têm, quais argumentos suas funções recebem (e de que tipo eles precisam ser) pode se tornar difícil. Da mesma forma, como não há como inspecionar o código JS de forma inteligente, quando você inclui um pacote (como um do `npm`), você precisa manter a documentação atualizada para saber quais métodos estão disponíveis e quais argumentos eles recebem. O TS resolve esses problemas. Atualmente é um projeto de código aberto hospedado no Github. Ele oferece suporte a ferramentas para qualquer navegador, assim como o Node, para qualquer host, em qualquer sistema operacional. O TS compila para JavaScript legível e baseado em padrões.

O TS adiciona um sistema de tipos flexível ao JS, além de interfaces (tipos personalizados) e da modificação da sintaxe de alguns recursos do ECMAScript, como classes. Os tipos são opcionais e flexíveis (por exemplo, você pode especificar que um argumento é uma string OU um number). Os tipos permitem ferramentas disponíveis na maioria dos editores de código que melhoram a experiência de desenvolvimento, como autocompletar código e detecção de métodos, tanto no seu próprio código quanto nos pacotes que você usa. Ele oferece suporte a muitos recursos futuros do ECMAScript (como async/await). O TS pode ser escrito nos estilos Orientado a Objetos ou Funcional. É compatível com todos os pacotes JS existentes. O TS transpila para JS limpo e legível.

Experimente no [playground](https://www.typescriptlang.org/play) e acompanhe as novidades pelo [blog do TypeScript](https://devblogs.microsoft.com/typescript/) e pela [conta no Twitter](https://twitter.com/typescript).
