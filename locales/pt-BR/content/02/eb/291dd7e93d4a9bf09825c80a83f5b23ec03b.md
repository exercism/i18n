# Conceitos de Ano bissexto

Prefiro a primeira solução de exemplo porque sua concisão segue o que já vi de Rust idiomático. Ela também evita a adição do conceito de closure que aparece na solução canônica.

## Conceitos extraídos

### Geral

- Lógica booleana
  - Boolean
- Expressões
  - As funções em Rust retornam expressões implicitamente
- Aritmética
  - módulo

### Tipos

- inteiros sem sinal - `u64`
- Boolean - `bool`

## Exercício de exemplo 1

A solução de ["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## Exercício de exemplo 2

[Canônica](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
