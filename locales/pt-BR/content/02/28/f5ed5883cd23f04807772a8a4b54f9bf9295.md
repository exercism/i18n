# Lotes de pagamentos no banco de dados

## Enunciado do problema

Você precisa inserir um lote de dados de pagamento na tabela `Payment`. Sua tarefa é ler os dados de pagamento do arquivo JSON de entrada fornecido e usar a operação `batchExecute` do cliente JDBC para inserir os dados de pagamento na tabela `Payment`. O arquivo de entrada de exemplo é fornecido como `payments.json`.

O conteúdo do arquivo JSON de entrada segue o seguinte esquema JSON.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

Você precisa retornar como saída os IDs de pagamento gerados automaticamente para os dados de pagamento inseridos no lote, sem fazer outra consulta ao banco de dados.

Você pode assumir que os `employee_id` informados no arquivo `payments.json` são válidos e já estão na tabela `Employee`.

## Detalhes do banco de dados

Use o banco de dados H2 fornecido para este problema.

> O arquivo de banco de dados de exemplo é `gofigure.mv.db`, e o nome do banco de dados é `gofigure`. Ele está dentro da pasta `db`.

As tabelas a seguir já existem no banco de dados H2 de exemplo, com alguns dados de exemplo. Os nomes das colunas e os tipos de dados estão abaixo.

**Nome da tabela** : `Employee`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | inteiro, chave primária com incremento automático       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | inteiro        |

**Nome da tabela**: `Payment`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | inteiro, chave primária com incremento automático       |
| `date`            | data        |
| `amount`          | decimal        |
| `employee_id`     | inteiro        |
| `reason`          | string        |

* O arquivo do banco de dados é `gofigure.mv.db`. Use a URL JDBC como `jdbc:h2:file:/path/to/db/file`
* Usuário: `root`
* Senha: `root`

## Restrições

* Use o arquivo de banco de dados H2 fornecido na pasta `db` para validar consultas e o exemplo em Ballerina
* Use a abordagem de parâmetros de dependência do Maven para adicionar o driver do banco de dados H2 como dependência de plataforma no seu Ballerina.toml
* Você precisa encontrar os IDs de pagamento gerados automaticamente sem fazer outra consulta ao banco de dados.

## Ambiente de teste

* Você pode rodar os testes com `bal test`, e ele vai rodar os testes com o banco de dados de exemplo fornecido.

## Exemplos

### Exemplo 1

**Entrada:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

Dados de exemplo do arquivo `payments.json`:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**Saída:** `[1,2,3]`

## Dicas

* Use o módulo [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) para trabalhar com o banco de dados
* Consulte a seção [Pré-requisito](https://lib.ballerina.io/ballerinax/java.jdbc/latest) para saber os passos de como adicionar o driver JDBC como dependência
* Use [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) para ler o arquivo JSON de entrada
* Converta os valores JSON para tipos específicos da aplicação para trabalhar com os dados de forma segura em relação a tipos. Consulte o exemplo [Conversão para um tipo definido pelo usuário](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)
* Use [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) e o método remoto [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) para trabalhar com o banco de dados
* Consulte o exemplo de [execução em lote](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)
