# Sobre

Uma [instrução switch][switch] permite comparar um valor com vários valores possíveis.
Com ela, você escreve um código mais conciso do que com várias condicionais `else-if`.
Uma instrução `switch` começa com a palavra-chave `switch`, seguida do valor a ser comparado.
Depois, use a palavra-chave `case` seguida do valor com o qual você quer comparar.
A palavra-chave `default` define o caso padrão, para quando nenhum dos casos corresponder.
Assim como as condicionais `else-if`, as instruções `switch` executam apenas o bloco de código associado ao primeiro caso que corresponde.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considere o seguinte exemplo:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Em vez disso, poderia ser escrito assim:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Vinculação e cláusulas `where`

Os valores comparados em instruções `switch` também podem ser vinculados a nomes, que podem ser usados no corpo do caso.
Eles também podem ser usados em cláusulas `where`, que são expressões Boolean adicionais que precisam ser avaliadas como `true` para que o caso corresponda.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
