# Introdução

Com um laço `while`, você pode executar código repetidamente enquanto uma determinada condição for atendida.
Ele é escrito com a palavra-chave `while` seguida de uma condição entre parênteses e de um bloco de código que contém o _corpo_ do laço entre chaves.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

O JavaScript também tem o laço do-while.
Aqui, a condição é verificada depois que o corpo do laço é executado.
Isso é útil quando a condição depende do resultado do código no corpo.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Dentro do corpo de um laço, você pode usar a palavra-chave `break` para interromper a execução do laço por completo.
Já a palavra-chave `continue` interrompe apenas a execução da iteração atual e segue para a próxima.
Com `continue`, você muitas vezes consegue evitar envolver grandes partes do corpo do laço em uma condicional.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
