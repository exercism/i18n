# Normalizações do representer

O [representer][representer] usa [`read`][cl-read] para ler a submissão e [`write`][cl-write] para escrever a representation, além de aplicar algumas normalizações adicionais.
Cada submissão passa pelas seguintes normalizações:

## Remover comentários

Como [`read`][cl-read] é usado para carregar a submissão, os comentários são removidos.

## Remover strings de documentação

Em vez de normalizar quaisquer nomes que possam estar presentes na string de documentação, a string é removida.
No entanto, a representation registra se havia ou não uma string de documentação.

## Normalizar maiúsculas e minúsculas

Como [`read`][cl-read] é usado para carregar a submissão, todos os símbolos são normalizados para maiúsculas.

## Normalizar a formatação do texto

A representation é escrita com [`write`][cl-write], então particularidades da formatação da submissão (como indentação, espaçamento e parêntese de fechamento deixado em linhas vazias) não são mantidas na representation.

## Normalizar nomes de símbolos

Símbolos como nomes de funções, variáveis e macros, além de pacotes, são mapeados para [`gensyms`][cl-gensym], que são usados na representation.
