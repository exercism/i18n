# Manipulação de bits

O Crystal tem operadores bit a bit para manipular [`Int`][ints] no nível binário.

## Operadores de deslocamento

O Crystal tem [operadores de deslocamento][shift] para deslocar bits para a esquerda (`<<`) ou para a direita (`>>`).

### Deslocamento à esquerda (`<<`)

O operador de deslocamento à esquerda (`<<`) desloca os bits para a esquerda.
O valor a deslocar é especificado do lado esquerdo e o número de posições a deslocar fica do lado direito.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Se o número for negativo, o deslocamento será para a direita.

```crystal
0b0010 << -1
# => 0b0001
```

### Deslocamento à direita (`>>`)

O operador de deslocamento à direita (`>>`) desloca os bits para a direita.
Assim como o operador de deslocamento à esquerda, o valor a deslocar é especificado à esquerda e o número de posições a deslocar fica à direita.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

E, da mesma forma, o operador deslocará para a esquerda se o número for negativo.

```crystal
0b0100 >> -1
# => 0b1000
```

## Operadores binários

O Crystal tem 3 [operadores binários][binary] (`&`, `|`, `^`) e um operador `~` para realizar operações bit a bit.

### AND bit a bit (`&`)

O operador binário AND (`&`) realiza um AND bit a bit em dois valores.
Ele compara cada bit do primeiro valor com o bit na mesma posição do segundo valor.
O bit resultante é definido como 1 se ambos os bits forem 1.
Caso contrário, ele é definido como 0.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### OR bit a bit (`|`)

O operador binário OR (`|`) realiza um OR bit a bit em dois valores.
Ele também compara cada bit do primeiro valor com o bit na mesma posição do segundo valor.
Se qualquer um dos bits for 1, o bit resultante é definido como 1.
Caso contrário, ele é definido como 0.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### XOR bit a bit (`^`)

O operador binário XOR (`^`) realiza um XOR bit a bit.
Assim como os operadores AND bit a bit e OR bit a bit, ele compara cada bit do primeiro valor com o bit na mesma posição do segundo valor.
Se _apenas um_ deles for 1, o bit resultante é 1.
Caso contrário, ele é 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### NOT bit a bit (`~`)

Por fim, o operador NOT bit a bit (`~`) inverte cada um dos bits do valor.
Diferente dos outros operadores binários, este é um operador unário, que opera apenas sobre o valor à direita.

```crystal
~0b1110_0010
# => 0b0001_1101
```
