# Instruções

Em **Chrono Realms**, os Time Keepers muitas vezes lidam não apenas com árvores de linhas do tempo, mas com **Chrono Chains**: sequências de **TimeNodes** encadeados, cada um representando um momento específico no tempo.
Uma **Chrono Chain** é um caminho reto de momentos sequenciais, em que cada **TimeNode** se conecta ao próximo.
Essas **Chrono Chains** são úteis ao viajar por uma série de eventos específicos, pois permitem que os Time Keepers sigam uma única linha do tempo.

No entanto, para lidar com essas **Chrono Chains** potencialmente longas, os Time Keepers usam **Ponteiros Inteligentes (Box<T>)** para gerenciar e percorrer com segurança essas listas de momentos sem causar duplicação desnecessária de memória nem estouro.
Cada **TimeNode** guarda uma referência para o próximo nó, formando uma estrutura recursiva.

Sua tarefa como aprendiz é implementar uma **Chrono Chain** como uma estrutura de lista recursiva usando ponteiros inteligentes.

Neste exercício, você vai:

1. Criar um enum recursivo `ChronoChain`, representando uma lista de momentos.
2. Usar o ponteiro inteligente `Box<T>` para armazenar os nós recursivos.
3. Implementar uma função para criar uma `ChronoChain` a partir de um array de valores `u32`.
4. Implementar uma função para percorrer a `ChronoChain` e somar os valores armazenados na lista.

## 1. Defina o enum recursivo `ChronoChain`

Crie um enum recursivo `ChronoChain` com duas variantes:

- `End`: representa o fim da lista.
- `Link`: contém um valor `u32` e uma referência acondicionada em `Box` para o próximo nó da cadeia.

## 2. Crie uma função para construir uma ChronoChain

Escreva uma função `ChronoChain::build` que recebe um array de valores `u32` e retorna uma `ChronoChain`, encadeando os valores em sequência com ponteiros inteligentes.

## 3. Implemente a função de soma

Escreva uma função `ChronoChain::sum` para percorrer a `ChronoChain` recursivamente e somar os valores de todos os nós.

## Exemplo de uso

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
