# Introdução

No Elixir, uma tupla é uma estrutura de dados que organiza dados, mantendo um número fixo de itens de qualquer tipo, mas sem nomes explícitos para cada elemento. As tuplas são frequentemente usadas no Elixir para operações com uso intensivo de leitura de memória, já que o acesso de leitura a um elemento é uma operação de tempo constante. Elas normalmente não são usadas quando elementos podem precisar ser adicionados/removidos dinamicamente, porque, em vez de modificar a tupla existente, uma nova tupla é criada, o que exige que memória seja alocada antecipadamente.

Na prática, as tuplas são criadas no Elixir usando chaves. Os elementos de uma tupla podem ser acessados individualmente com a função `elem/2` usando indexação baseada em 0:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## Tuplas como informações agrupadas

Na prática, as tuplas são frequentemente usadas para representar informações agrupadas.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
