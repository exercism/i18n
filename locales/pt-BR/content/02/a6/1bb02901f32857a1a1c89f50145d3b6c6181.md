# Dicas

## Geral

- É possível acessar os componentes individuais de uma tupla acrescentando um _.n_ ao nome da tupla, em que _n_ é o índice do componente, começando em 0.

## 1. Obter o nome do brinquedo

- Você pode acessar o nome do brinquedo usando a sintaxe `.n`.

## 2. Adicionar um novo brinquedo ao banco de dados

- Você pode criar uma nova tupla usando a sintaxe de tupla `(name1: value1, name2: value2, ...)`.

## 3. Atualizar a quantidade de um brinquedo

- Você pode usar um [laço `for`][for-loop] para iterar sobre o array de tuplas e atualizar a quantidade do brinquedo.
- Você pode usar funções implementadas anteriormente para obter o nome do brinquedo.
- Você pode usar uma [condicional][conditional-statement] para verificar se o nome do brinquedo corresponde ao que você quer atualizar.
- Você pode usar a sintaxe `.n` para atualizar a quantidade do brinquedo, por exemplo: `toys.price = 3`.

## 4. Adicionar a chave de categoria a um brinquedo

- Você pode usar um [laço `for`][for-loop] para iterar sobre o array de tuplas e adicionar a chave de categoria ao brinquedo.
- Uma tupla é imutável, então você precisa criar uma nova tupla com a chave de categoria adicionada.
  
[for-loop]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
[conditional-statement]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Conditional-Statements
