# Sobre

As [expressões switch][switch-expressions] funcionam de maneira semelhante às [instruções switch][switch-statements] abordadas em [concept:csharp/switch-statements](). Elas dão suporte a uma espécie de tabela de decisão que mapeia condições de entrada para ações ou valores.

No cerne da expressão `switch` está a _correspondência de padrões_. No exercício de programação, combinamos valores com padrões `const`. Aqui, as entradas do `switch` são uma _expressão de intervalo_, que é combinada com valores `const` e com os valores usados pelas _guardas de caso_.

Os casos (também conhecidos como _braços do switch_) são avaliados na ordem em que aparecem no texto, e o processo é interrompido assim que uma correspondência é encontrada, devolvendo o valor associado.

O caso `_`, que é o último da lista, é útil para garantir que a correspondência seja exaustiva e para evitar possíveis erros em tempo de execução.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

Um "braço" do `switch` é selecionado quando o padrão corresponde à variável de intervalo e alguma guarda de caso é avaliada como verdadeira.

As expressões `switch` também dão suporte a [padrões de tipo][pattern-matching] e à correspondência recursiva.
