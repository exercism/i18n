# Instruções

Você trabalha como administrador de sistemas em uma grande empresa em Munique, na Alemanha. Uma das suas responsabilidades é gerenciar contas de e-mail.

Você anda ouvindo reclamações de pessoas que dizem não conseguir escrever e-mails para o Sr. Müller. Você logo percebe que a maior parte da empresa usa um cliente de e-mail antigo que não reconhece `müller@firma.de` como um endereço de e-mail válido por causa do caractere não ASCII.

Convencer as pessoas a abandonar o cliente de e-mail antigo preferido delas é uma batalha perdida, então você decide criar aliases higienizados para todas as contas de e-mail.

## 1. Higienize os nomes de usuário existentes, removendo tudo, exceto as letras minúsculas

Implemente a função `sanitize/1`. Ela deve receber um nome de usuário como uma charlist e retornar o nome de usuário com todos os caracteres removidos, exceto as letras minúsculas.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. Permita underscores

Estenda a função `sanitize/1`. Ela não deve remover os underscores do nome de usuário.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. Substitua os caracteres alemães

Existem 4 caracteres não ASCII no alfabeto alemão, e todos eles têm substitutos ASCII amplamente reconhecidos.

| Caractere alemão | Substituto ASCII |
| ---------------- | ---------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

Estenda a função `sanitize/1`. Ela deve substituir os caracteres alemães de acordo com a tabela. Você pode assumir tranquilamente que todos os nomes de usuário já estão em minúsculas.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
