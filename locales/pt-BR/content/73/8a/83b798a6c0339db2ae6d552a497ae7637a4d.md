# Introdução

Basicamente, existem dois tipos de laço:

1. Repetir até que uma condição seja satisfeita.
2. Iterar sobre os elementos de uma coleção.

Ambos são possíveis em R, embora o primeiro possa ser mais comum.

## `while` e `repeat`

Para problemas em aberto, em que não se sabe de antemão quantas vezes o laço será executado, R tem o laço `while`, com uma condição, e o laço `repeat`, sem condição (equivalente a `while (TRUE)`).

A forma básica é bem simples:

```R
while (condition) {
  do_something()
}
```

Nesse caso, o programa continua repetindo o laço até que `condition` deixe de ser `TRUE`.

Existem duas formas de sair do laço antecipadamente:

- Um `break` faz o laço ser encerrado, e a execução continua na linha seguinte à chave de fechamento `}` do laço.
- Um `return(x)` interrompe a execução da função atual e devolve o valor de retorno `x` para quem a chamou.

Com essas opções disponíveis, às vezes é conveniente criar um laço "infinito" com `repeat { ... }` e contar com a descoberta de uma condição de parada dentro do corpo do laço para acionar um `break` ou um `return`.

Essas três variantes são equivalentes e todas terminam com `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Iterando sobre um vetor

Isso muitas vezes é desnecessário em R.
Como discutido em outros conceitos, muitas funções operam sobre vetores inteiros.

No entanto, laços explícitos às vezes são inevitáveis.
Isso vale especialmente quando:

- O corpo do laço tem efeitos colaterais, como imprimir algo ou fazer entrada/saída de arquivos.
- O laço continua até que algum critério seja atingido, após um número imprevisível de iterações.

A condição do laço precisa estar entre parênteses.
Assim como no corpo de funções, as chaves são opcionais (mas costumam ser incluídas) em corpos de laço de uma única linha.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Se a iteração atual não satisfizer alguma condição, é possível pular imediatamente para a próxima iteração com um `next`:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

Se o índice numérico for necessário, use `seq_along()`.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Usar `i in 1:length(v)` _não_ é recomendado, pois pode causar problemas quando `length(v)` é zero.
O intervalo `1:0` é equivalente a `c(1, 0)`, então o corpo do laço será executado e provavelmente falhará.
A função `seq_along()` foi feita para lidar com esse caso corretamente.
