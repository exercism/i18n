# Testes

Você pode usar o editor online no site do Exercism para resolver os exercícios.
Ou baixar os exercícios para o seu computador, resolvê-los localmente e depois enviá-los ao Exercism.
O restante deste documento fala sobre trabalhar localmente.

## CLI do Exercism

Você vai precisar da ferramenta de linha de comando `exercism` para baixar e enviar exercícios.
Veja a [documentação da CLI do exercism][exercism-cli] para instruções de como baixá-la e configurá-la.

Para baixar um exercício, faça o seguinte:

```bash
exercism download --track 8th --exercise hello-world
```

E mude para o diretório do exercício:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

ou, se você estiver no Windows:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

Repare que você pode obter seu workspace do exercism com o comando `exercism configure`.

## Testando localmente

Para rodar os testes de um exercício, você precisa estar no diretório correto do exercício.
Depois, inicie os testes com este comando:

```bash
8th -f test.8th
```

## Testes ignorados

Resolver um exercício significa fazer todos os testes passarem.
Por padrão, apenas um teste (o primeiro) é executado quando você roda os testes.
Isso é intencional, pois permite que você foque só em fazer esse único teste passar.
Quando ele passar, você pode habilitar o próximo teste movendo a linha `SKIP-REST-OF-TESTS` para baixo dele.

### Sobrescrevendo os testes ignorados

Para rodar todos os testes, incluindo os que vêm depois da palavra `SKIP-REST-OF-TESTS`, você pode definir a variável de ambiente `RUN_ALL_TESTS` com o valor `true`.
Uma forma de definir isso só durante a execução dos testes é (macOS e Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## Envie sua solução

Para enviar sua solução ao site do Exercism usando a ferramenta exercism:

```bash
exercism submit
```

Repare que você pode enviar seu código mesmo que ele não esteja passando em todos os testes.
Isso ajuda se você estiver com dificuldades e precisar da ajuda de um mentor.
