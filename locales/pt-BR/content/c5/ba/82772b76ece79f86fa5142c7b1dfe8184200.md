# Sobre

Em Haxe, um **array** (ou _vetor_) é uma coleção de elementos (normalmente) do mesmo tipo. Existem três formas de criar um array em Haxe: pelo construtor ou por uma sintaxe de declaração. Em Haxe, o primeiro elemento de um array tem índice zero:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Para criar um array usando um construtor, você precisa passar o tipo dos elementos que vão ser incluídos no array:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Como o acesso a arrays em Haxe não tem limites, ou seja, é garantido que ele não lança uma exceção, isso exige uma discussão mais detalhada:

- Se um acesso de leitura for feito em um índice inexistente, é retornado um valor que depende do alvo.
- Se um acesso de escrita for feito com um índice positivo que está fora dos limites, `null` (ou o valor padrão para tipos básicos em alvos estáticos) é inserido em todas as posições entre o último índice definido e o que acabou de ser escrito.
- Se um acesso de escrita for feito com um índice negativo, o resultado é indefinido.

Se quisermos que um array contenha vários tipos de elementos, adicionamos o tipo `Dynamic` ao indicador de tipo:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## Iteração

É possível iterar sobre arrays usando um laço `for`:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
