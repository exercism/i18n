# Introdução

## Conversão de tipos

Go exige conversão explícita entre tipos diferentes.
A conversão entre tipos (também conhecida como **type casting**) é feita por meio de uma função com o nome do tipo de destino.
Por exemplo, para converter um `int` em um `float64`, você precisa fazer o seguinte:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Conversão entre tipos primitivos e strings

Existe um pacote `strconv` para converter entre tipos primitivos (como `int`) e `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## Asserções de tipo

As interfaces em Go podem introduzir ambiguidade sobre o tipo subjacente.
Uma asserção de tipo permite extrair o valor concreto subjacente de um valor de interface usando esta sintaxe: `interfaceVariable.(concreteType)`.

Por exemplo:

```go
var input any = 12
number := input.(int)
```

OBSERVAÇÃO: isso vai causar um panic se a variável de interface não contiver um valor do tipo concreto.

Podemos testar se um valor de interface contém um tipo concreto específico usando os dois valores de retorno da asserção de tipo: o valor subjacente e um valor Boolean que informa se a asserção foi bem-sucedida.
Por exemplo:

```go
str, ok := input.(string) // no panic if input is not a string
```

Se `input` contiver uma `string`, então `str` será o valor subjacente e `ok` terá o valor true.
Se `input` não contiver uma `string`, então `str` será o valor zero do tipo `string` (ou seja, `""`, a string vazia) e `ok` terá o valor false.
Em nenhum dos casos ocorre um panic.

## Switches de tipo

Um **switch de tipo** pode realizar várias asserções de tipo em sequência.
Ele tem a mesma sintaxe de uma asserção de tipo (`interfaceVariable.(concreteType)`), mas o `concreteType` é substituído pela palavra-chave `type`.
Veja um exemplo:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
