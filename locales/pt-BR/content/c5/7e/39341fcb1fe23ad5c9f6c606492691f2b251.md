# Introdução

Os laços `for` são o tipo de laço mais complexo do PHP. Eles se comportam como os laços `for` em `C`, `Java` e `JavaScript`. A forma básica é:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

A primeira expressão (_expr1_) é avaliada antes de o laço começar. A segunda expressão (_expr2_) é avaliada antes de cada iteração; se ela for avaliada como um valor _truthy_, as instruções são executadas. Depois que as instruções são executadas, a terceira expressão (_expr3_) é avaliada.
