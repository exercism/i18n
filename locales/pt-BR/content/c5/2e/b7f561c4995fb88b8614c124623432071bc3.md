# Instruções

Neste exercício, você vai gerar mensagens de log semiestruturadas.

## Emitir mensagens semiestruturadas

Você vai começar com algumas funções já esboçadas e com o seguinte enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

Seu objetivo é emitir uma mensagem de log no seguinte formato: `"[<LEVEL>]: <MESSAGE>"`.
Você vai precisar implementar funções que correspondam aos níveis de log.

Por exemplo, o trecho abaixo demonstra uma saída esperada para a função `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

E para `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Divirta-se!
