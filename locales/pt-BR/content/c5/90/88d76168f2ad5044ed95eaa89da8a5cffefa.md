# Instruções

Uma escola perto de você tem um grêmio estudantil muito ativo.
O grêmio estudantil é administrado por um presidente e, a cada 2 anos,
são realizadas eleições para eleger um novo presidente.

Na eleição deste ano, decidiu-se que era necessário um novo sistema digital para contar os votos.
A escola precisa da sua ajuda para construir esse novo sistema.

## 1. Crie um contador de votos

Uma das primeiras coisas de que o novo sistema de votação precisa é de um contador de votos.
Esse contador é uma maneira de acompanhar os votos que um determinado candidato tem.

Crie uma função `NewVoteCounter` que aceita o número de votos iniciais de um candidato e retorna um ponteiro que se refere a um `int`, inicializado com o número de votos iniciais fornecido.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. Obtenha o número de votos de um contador

Agora você tem uma maneira de criar novos contadores! Mas você percebe que o novo sistema também precisará de uma maneira de obter o número de votos de um contador.

Crie uma função `VoteCount` que recebe um contador (`*int`) como argumento e retorna o número de votos no contador.
Se o contador for `nil`, você deve assumir que o contador não tem votos:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. Incremente os votos de um contador

Finalmente chegou a hora de contar os votos! Agora você precisa de uma maneira de incrementar os votos em um contador.

Crie uma função `IncrementVoteCount` que recebe um contador (`*int`) como argumento e um número de votos, e incrementa o contador nesse número de votos.
Você pode assumir que o ponteiro passado nunca será `nil`.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. Crie os resultados da eleição

Com todos os votos contados, é hora de preparar o anúncio do resultado para a escola inteira.
Para isso, você percebe que ter apenas contadores para os votos é insuficiente.
É preciso haver uma maneira de associar o número de votos a um candidato específico.

Crie uma função `NewElectionResult` que recebe o nome de um candidato e o número de votos dele e
retorna um novo resultado de eleição.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

A struct de resultado da eleição já foi criada para você e está definida como:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. Anuncie os resultados

É hora de anunciar o novo presidente para a escola!
O presidente será anunciado nos pequenos murais digitais de mensagens que a escola tem.
A mensagem deve mostrar o nome do novo presidente e os votos que ele recebeu, no seguinte formato: `<candidate_name> (<votes>)`.
Este é um exemplo dessa mensagem: `"Peter (51)"`.

Crie uma função `DisplayResult` que receberá um `*ElectionResult` como argumento e retornará uma string com a mensagem a ser exibida.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. Recontagem de votos

Para garantir que os resultados finais estivessem corretos, os votos foram recontados.
Na recontagem, descobriu-se que o número de votos de alguns candidatos estava com diferença de um.

Crie uma função `DecrementVotesOfCandidate` que recebe os resultados finais e o nome de um candidato cuja contagem de votos você deve decrementar.
Os resultados finais são fornecidos na forma de um `map[string]int`, em que as chaves são os nomes dos candidatos e os valores são o total de votos de cada um.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
