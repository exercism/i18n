# Adendo às instruções

## Instruções específicas da trilha

Sua tarefa é implementar um registro `circularBuffer` que tem os seguintes métodos

- `clear()`: esvazia o buffer.
- `write(item)`: adiciona o item informado ao buffer. Se o buffer estiver cheio, deve lançar `Error("Cannot write to full buffer.")`.
- `read()`: remove o elemento mais antigo do buffer e o retorna. Se o buffer estiver vazio, deve lançar `Error("Cannot read from an empty buffer.")`.
- `overwrite(item)`: Se o buffer estiver cheio, sobrescreve o elemento mais antigo com `item`. Se o buffer não estiver cheio, se comporta como `write`.
