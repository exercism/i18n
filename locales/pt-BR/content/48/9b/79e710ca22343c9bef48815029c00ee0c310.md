# Introdução

## Funções de seta

Além de declarações de função e expressões de função, o JavaScript também tem outra sintaxe bem concisa para definir uma função.
Essas funções são chamadas de _funções de seta_.

Veja uma comparação entre uma declaração de função e uma função de seta.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Se o corpo da função tiver apenas uma instrução de retorno, como no exemplo acima, podemos omitir o `{}` e a palavra-chave `return`.
Se houver apenas um parâmetro, os parênteses `()` também podem ser omitidos.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

As funções de seta são muito usadas para definir funções de callback curtas diretamente na chamada da função.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## Análise de arrays

Os [Arrays][arrays-concept] têm métodos internos para analisar o conteúdo do array.
A maioria desses métodos recebe como argumento uma função que retorna true ou false.
Uma função assim é chamada de [`predicate`][predicate_in_programming].

Esses métodos internos devem ser usados _em vez de um laço `for`_ ou do método interno `forEach`:

Exemplo de análise usando um laço `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Exemplo de análise usando um método interno:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Veja abaixo alguns outros métodos internos úteis para analisar um array.
Consulte a [MDN][mdn-array-methods] para ver a lista completa de métodos de array.

### `includes`

O método `includes(value)` determina se um array contém determinado valor.
Ele retorna `true` quando o valor está presente e `false` caso contrário.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

O método `every(predicate)` recebe uma função que é _um predicado_.
Ele verifica se todos os elementos do array retornam `true` quando passados ao predicado.
Em outras palavras: o método testa se todos os seus elementos passam no teste passado para a chamada da função.
Ele retorna `true` quando todos os elementos passam no teste do predicado e `false` caso contrário.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

O método `some(predicate)` é igual ao método `every`, mas retorna `true` se pelo menos um item do array passar no teste do _predicado_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

O método `find(predicate)` retorna o valor do primeiro elemento do array que passa no teste do `predicate`.
Onde `some()` retorna `true` quando o teste passa, `find()` retorna o valor de fato presente no array.
O método retorna `undefined` quando nenhum dos elementos do array passa no teste do _predicado_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

O `findIndex(predicate)` é igual ao método `find()`, mas retorna o _índice_ do elemento (o primeiro) que passa no teste do _predicado_, em vez do `value`.
O método retorna `-1` quando nenhum dos elementos do array passa no teste do _predicado_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
