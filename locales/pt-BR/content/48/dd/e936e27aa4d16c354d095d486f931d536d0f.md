# Instruções

Você cuida da estação de processamento de um arranjo de sismógrafos, uma rede de sensores que registram como o solo se move.

As leituras chegam em blocos de valores.
Algumas são deslocamentos do solo armazenados como números de ponto flutuante de 32 bits, outras são contagens brutas e palavras de status armazenadas como inteiros de 32 bits.
A estação processa um bloco inteiro de uma vez, aplicando a mesma operação a cada valor.

Você tem seis tarefas, cada uma operando sobre um bloco de valores mantidos na memória.
Você recebe os operandos por meio de endereços de memória e escreve sua resposta por meio de um endereço de resultado.
Todos os endereços de memória neste exercício são alinhados a 16 bytes.

~~~~exercism/note
Os cálculos neste exercício devem ser feitos usando operações bit a bit e deslocamentos SIMD, não operações escalares.
~~~~

## 1. Retifique o traço

Para a análise de magnitude, só importa o tamanho de cada deslocamento do solo, não sua direção.
A primeira etapa de processamento reduz cada leitura a um valor não negativo.

Implemente a função `rectify_trace`, que calcula o valor absoluto de cada leitura.
Um bloco contém 4 leituras, cada uma um número de ponto flutuante de 32 bits.

Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória de um buffer onde as 4 leituras retificadas são gravadas.
- `trace`: endereço de memória das leituras registradas, com 4 valores, cada um um número de ponto flutuante de 32 bits.

```c
trace  = {1.5, -2.25, 0.0, -135.75}
result = {1.5,  2.25, 0.0,  135.75}
```

Esta função não tem valor de retorno.

## 2. Leia a escala de um tremor

Os analistas classificam os tremores pela potência de dois: uma leitura próxima de `8.0` fica na escala `3`, uma leitura próxima de `0.25` fica na escala `-2`.
Essa escala já está armazenada dentro de cada número de ponto flutuante, no seu campo de expoente.

Um número de ponto flutuante de 32 bits é organizado assim: um bit de sinal no bit 31, um expoente de 8 bits nos bits 30 a 23 e uma fração de 23 bits nos bits 22 a 0.
O expoente armazenado tem um viés de 127, então o valor do número é `(-1)^sign * 1.fraction * 2^(exponent - 127)`.

Implemente a função `reading_scale`, que extrai o expoente sem viés de cada leitura como um inteiro de 32 bits com sinal.

Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória de um buffer onde as 4 escalas são gravadas, cada uma um inteiro de 32 bits com sinal.
- `trace`: endereço de memória das leituras retificadas, com 4 valores, cada um um número de ponto flutuante de 32 bits.

```c
trace  = {8.0, 0.25, 1.0, 13.5}
result = {  3,   -2,   0,   3}
```

Esta função não tem valor de retorno.
Todas as leituras são números de ponto flutuante normais e diferentes de zero.

## 3. Reduza a resolução

Para armazenamento de longo prazo, as contagens brutas de deslocamento são mantidas em uma resolução mais grosseira: cada contagem é dividida por uma potência de dois.

As contagens de deslocamento têm sinal: o solo pode se mover para os dois lados.
Dividi-las corretamente exige o deslocamento que preserva o sinal.

Implemente a função `coarsen_displacements`, que divide cada contagem com sinal por `2^shift`, arredondando em direção ao infinito negativo.

Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória de um buffer onde as 4 contagens reduzidas são gravadas, cada uma um inteiro de 32 bits com sinal.
- `counts`: endereço de memória das contagens brutas, com 4 inteiros de 32 bits com sinal.
- `shift`: a potência de dois pela qual dividir, como um inteiro sem sinal de 64 bits entre `0` e `31`.

```c
counts = {1024, -1024, 25, -25}
shift  = 3
result = { 128,  -128,  3,  -4}
```

~~~~exercism/note
A instrução `movq` pode ser usada para copiar um inteiro de 64 bits de um registrador de uso geral para um registrador `xmm` sem alterar a representação de bits subjacente.
~~~~

Esta função não tem valor de retorno.

## 4. Faça o gate dos canais

Cada estação combina duas campanhas de registro e depois silencia os canais que seu relatório de hardware marca como defeituosos.
Cada bloco contém 4 máscaras de canais, cada uma um inteiro sem sinal de 32 bits, em que cada bit representa um canal: `1` habilitado, `0` desabilitado.

Implemente a função `gate_channels`, que combina os canais habilitados em qualquer uma das campanhas e depois limpa todo canal marcado como defeituoso.

Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória de um buffer onde as 4 máscaras filtradas são gravadas, cada uma um inteiro sem sinal de 32 bits.
- `enable_a`: endereço de memória das máscaras de habilitação da primeira campanha, com 4 inteiros sem sinal de 32 bits.
- `enable_b`: endereço de memória das máscaras de habilitação da segunda campanha, com 4 inteiros sem sinal de 32 bits.
- `faulty`: endereço de memória das máscaras de canais defeituosos, com 4 inteiros sem sinal de 32 bits.

```c
enable_a = {0b1100, 0b0001, 0b1111, 0b0000}
enable_b = {0b0110, 0b0001, 0b0000, 0b0000}
faulty   = {0b0100, 0b0011, 0b1001, 0b1111}
result   = {0b1010, 0b0000, 0b0110, 0b0000}
```

Esta função não tem valor de retorno.

## 5. Alterne os bits de calibração

Uma vez por dia, a estação executa uma passagem de calibração, invertendo um conjunto escolhido de bits de configuração em cada palavra de status e deixando todos os outros bits intactos.
Mas alguns bits são travados pelo hardware e nunca podem mudar, não importa o que a passagem solicite.
Executar a mesma passagem duas vezes restaura a configuração original.

Implemente a função `toggle_calibration`, que inverte, em cada palavra de status, exatamente os bits que estão definidos na máscara de alternância correspondente e não estão definidos na máscara de trava correspondente.

Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória de um buffer onde as 4 palavras de status atualizadas são gravadas, cada uma um inteiro sem sinal de 32 bits.
- `status`: endereço de memória das palavras de status atuais, com 4 inteiros sem sinal de 32 bits.
- `toggle`: endereço de memória das máscaras de alternância, com 4 inteiros sem sinal de 32 bits.
- `locked`: endereço de memória das máscaras de trava, com 4 inteiros sem sinal de 32 bits.

```c
status = {0b1100, 0b0001, 0b1111, 0b1010}
toggle = {0b0110, 0b0011, 0b1111, 0b1010}
locked = {0b0010, 0b0001, 0b1100, 0b0000}
result = {0b1000, 0b0011, 0b1100, 0b0000}
```

Esta função não tem valor de retorno.

## 6. Amplifique o traço

Cada canal do arranjo tem seu próprio ajuste de ganho, expresso como uma potência de dois: um ganho de `3` multiplica a leitura do canal por `8`, um ganho de `-5` a divide por `32`.

A estação aplica esses ganhos sem uma única multiplicação, manipulando o campo de expoente de cada número de ponto flutuante.

Implemente a função `amplify_trace`, que multiplica cada leitura por `2` elevado ao ganho do seu canal, operando apenas sobre os bits brutos.

Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória de um buffer onde as 4 leituras amplificadas são gravadas.
- `trace`: endereço de memória das leituras, com 4 valores, cada um um número de ponto flutuante de 32 bits.
- `gains`: endereço de memória dos ganhos por canal, com 4 inteiros de 32 bits com sinal.

```c
trace  = {1.5, -2.0, 0.25, 96.0}
gains  = {  2,    1,    3,   -5}
result = {6.0, -4.0,  2.0,  3.0}
```

Esta função não tem valor de retorno.
Todas as leituras são números de ponto flutuante normais e diferentes de zero, e todo resultado amplificado também é normal.
