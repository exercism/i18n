# Instruções complementares

## Instruções específicas da trilha

Os testes deste exercício exigem que você use extensões, um mecanismo para adicionar novas funcionalidades a uma classe existente cujo código-fonte você não controla diretamente, sem precisar criar uma subclasse.
Para saber mais sobre como o Kotlin implementa extensões, confira a [documentação oficial](https://kotlinlang.org/docs/reference/extensions.html#extensions).

Os métodos `customFoldLeft` e `customFoldRight` são funções de "fold", um conceito bem conhecido no mundo da programação funcional, mas nem tanto no da orientação a objetos.
Se você quiser mais informações de contexto, confira esta página sobre [fold](https://en.wikipedia.org/wiki/Fold_(higher-order_function)).
