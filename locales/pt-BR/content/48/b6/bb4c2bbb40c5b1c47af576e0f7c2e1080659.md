# Dicas

## 1. Definir a pontuação de um jogador no hash `%Scores`

- Você quer modificar o hash `%Scores` para adicionar pontuações de novos jogadores e substituir as pontuações de jogadores que já existem.
- Hashes não podem conter chaves duplicadas: um valor mais recente em uma lista substitui um valor mais antigo.

## 2. Obter a pontuação de um jogador no hash `%Scores`

- Você quer usar o nome do jogador informado para `return` a pontuação dele no hash `%Scores`.

## 3. Aumentar a pontuação de um jogador no hash `%Scores`

- Você quer modificar o hash `%Scores` para somar as pontuações dos jogadores que já existem às novas pontuações informadas.

## 4. Ordenar os jogadores do hash `%Scores` pelo nome

- Você quer `return` os nomes dos jogadores do hash `%Scores` como uma lista ordenada alfabeticamente.


## 5. Ordenar os jogadores do hash `%Scores` pela pontuação

- Você quer `return` os nomes dos jogadores do hash `%Scores` como uma lista ordenada pela pontuação, da maior para a menor.

## 6. Remover um jogador do hash `%Scores`

- Você quer modificar o hash `%Scores` para remover o nome e a pontuação do jogador informado.
