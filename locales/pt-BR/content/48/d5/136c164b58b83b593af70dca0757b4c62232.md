# Testes

Instale as dependências.

```sh
dart pub get
```

Rode os testes.

```sh
dart test
```

Para uma saída mais detalhada por teste, use o reporter expandido.

```sh
dart test -r expanded
```

A maioria dos exercícios tem vários testes, e todos, exceto o primeiro, ficam pulados por padrão.
Para fazer os testes um de cada vez, mude `skip: true` para `skip: false` em cada teste conforme avança.

Como alternativa, rode todos os testes de uma vez sem editar o arquivo.

```sh
dart test --run-skipped
```

O executor de testes online roda todos os testes no envio, inclusive os pulados.
