# Instruções

Neste exercício, você vai ajudar namorados do ensino médio a declarar seu amor nas redes sociais, gerando uma caixa ASCII com as iniciais deles:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. Obtenha a primeira letra do nome

Implemente a função `HighSchoolSweetheart.first_letter/1`. Ela deve receber um nome e retornar sua primeira letra. Ela também deve limpar qualquer espaço em branco desnecessário do nome.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. Formate a primeira letra como uma inicial

Implemente a função `HighSchoolSweetheart.initial/1`. Ela deve receber um nome e retornar sua primeira letra, em maiúscula, seguida de um ponto. Certifique-se de reutilizar a função `HighSchoolSweetheart.first_letter/1` que você definiu no passo anterior.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. Divida o nome completo entre nome e sobrenome

Implemente a função `HighSchoolSweetheart.initials/1`. Ela deve receber um nome completo, formado por um nome e um sobrenome separados por um espaço, e retornar as iniciais. Certifique-se de reutilizar a função `HighSchoolSweetheart.initial/1` que você definiu no passo anterior.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. Coloque as iniciais dentro da caixa ASCII

Implemente a função `HighSchoolSweetheart.pair/2`. Ela deve receber dois nomes completos e retornar as iniciais dentro de uma caixa ASCII. Você não precisa desenhar a caixa sozinho: use a caixa incluída no comentário do código. Certifique-se de reutilizar a função `HighSchoolSweetheart.initials/1` que você definiu no passo anterior.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
