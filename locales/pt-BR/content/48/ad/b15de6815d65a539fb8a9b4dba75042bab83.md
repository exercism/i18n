# Dicas

## Geral

- Toda rotina fica dentro de `class STAGE_DIRECTIONS is` e do `end;` correspondente. O esqueleto já tem os dois. Escreva entre eles.
- Cada rotina termina com o próprio `end;`.

## 1. Anuncie o início

- A resposta é um texto, então a rotina é declarada `: STR`.
- O texto fica entre aspas duplas: `"like this"`.
- Retorne a resposta com `return`.

## 2. Anuncie o intervalo

- A mesma estrutura da primeira tarefa, com um texto diferente.
- Copie a linha esperada exatamente, incluindo os pontos finais.

## 3. Anuncie o fim

- De novo, a mesma estrutura.

## 4. Chame a deixa final

- Não escreva o texto uma terceira vez.
- Dentro da mesma classe, você pode usar uma rotina pelo nome, sem o nome da classe na frente e sem parênteses: `closing_line`.
- Use `return` para retornar o resultado dessa chamada.
