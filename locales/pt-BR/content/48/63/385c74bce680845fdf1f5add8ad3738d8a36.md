# Analisador de linhas de log

## História

Neste exercício, você vai processar linhas de log.

Cada linha de log é uma string formatada assim: `"[<LEVEL>]: <MESSAGE>"`.

Há três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

## Tarefas

Estas são tarefas de exemplo que se encaixam no analisador de linhas de log:

- Obter a mensagem de uma linha de log
- Obter o nível de log de uma linha de log
- Converter uma linha de log para um formato diferente
