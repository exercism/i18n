# Parser de linhas de log

## História

Neste exercício você vai processar linhas de log.

Cada linha de log é uma string formatada assim: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de log:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

## Tarefas

Estas são tarefas de exemplo que se encaixam no parser de linhas de log:

- Fazer o parse do nível de log para enum
- Aceitar níveis de log desconhecidos
- Converter uma linha de log para um formato diferente, com o nível de log convertido em um valor numérico
