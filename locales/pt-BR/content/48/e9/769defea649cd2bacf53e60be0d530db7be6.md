# Sobre

Arturo é uma linguagem de programação moderna, desenvolvida de forma independente, que segue alguns princípios muito simples e diretos:

* Code é apenas uma lista de palavras, símbolos e valores literais.

* Palavras e símbolos dentro de um bloco são interpretados, quando necessário, de acordo com o contexto.

* Nenhuma palavra reservada ou palavra-chave: por mais que você procure, não existe absolutamente nenhuma.
