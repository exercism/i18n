# Instruções

Refatore um analisador de Markdown.

O exercício markdown é um exercício de refatoração. Há um código que analisa uma determinada string com [sintaxe Markdown](https://guides.github.com/features/mastering-markdown/) e retorna o HTML associado a essa string. Apesar de esse código estar escrito de forma confusa e ser difícil de acompanhar, de alguma forma ele funciona e todos os testes estão passando! Seu desafio é reescrever esse código para deixá-lo mais fácil de ler e de manter, garantindo ao mesmo tempo que todos os testes continuem passando.

Seria útil se você anotasse em comentários o que fez na sua refatoração, para que quem revisa possa ver, mas isso não é estritamente necessário. O mais importante é deixar o código melhor!
