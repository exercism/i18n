# Sobre

`jq` é uma ferramenta para analisar e transformar dados JSON.
`jq` é como o `sed` para dados JSON: você pode usá-lo para fatiar, filtrar, mapear e transformar dados estruturados com a mesma facilidade com que `sed`, `awk`, `grep` e afins deixam você brincar com texto.

`jq` é uma linguagem de programação funcional com tipagem dinâmica.
Todos os valores são imutáveis.

Os programas em `jq` são compostos por pipelines de "filtros": cada filtro recebe um único item como entrada, age sobre ele e produz zero ou mais elementos transformados.
Um "filtro" também pode ser chamado de "expressão".

As saídas de uma expressão podem ser passadas para outra usando o operador `|`.
`expressionA | expressionB` aplica `expressionA` a alguma entrada e depois `expressionB` é executada repetidamente para cada uma das saídas de `expressionA`.

A entrada de uma expressão pode ser referida explicitamente como `.`.
Uma expressão que soma `1` à sua entrada fica assim: `. + 1` (ou `1 + .`).

## `jq` (o programa) versus `jq` (a linguagem)

`jq` é um programa que você pode instalar como pacote em diversos sistemas operacionais,
ou compilar a partir do código-fonte (ele é escrito em C).
Ele tem várias [opções de linha de comando][cli-options] úteis e é bem rápido.

O programa `jq` também implementa uma _linguagem_ que permite manipulações arbitrariamente complexas dos dados de entrada.

Esta trilha do Exercism vai focar na linguagem.
Você vai ver o uso do programa `jq` nos testes.

## JSON

Segundo o [json.org][json]:

> JSON (JavaScript Object Notation) é um formato leve de intercâmbio de dados.
> É fácil para humanos lerem e escreverem.
> É fácil para máquinas analisarem e gerarem.
> Ele é baseado em um subconjunto da Linguagem de Programação JavaScript, Padrão ECMA-262, 3ª Edição, de dezembro de 1999.
> JSON é um formato de texto completamente independente de linguagem, mas usa convenções familiares a programadores da família de linguagens C, incluindo C, C++, C#, Java, JavaScript, Perl, Python e muitas outras.
> Essas propriedades fazem do JSON uma linguagem ideal de intercâmbio de dados.

Esta trilha é sobre `jq`, não sobre JSON.
Vamos assumir que você já conhece a [sintaxe e os tipos de dados do JSON][wiki-json].
