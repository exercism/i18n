# Sobre

Um [`Attribute` do C#][attribute-concept] oferece uma forma de decorar uma declaração para associar metadados a ela: uma classe, um método, um enum, um campo, uma propriedade ou qualquer outra [declaração compatível][attribute-targets].

Você pode aplicar [um atributo][attribute] a uma declaração adicionando-o entre colchetes `[]` antes da declaração. O exemplo a seguir usa tanto um `ClassAttribute` quanto um `FieldAttribute`:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

Os metadados declarativos apenas associam informações estruturadas adicionais ao código e não modificam seu comportamento, mas esses metadados são usados por outra parte do código para mudar como o alvo se comporta, ou para adicionar, alterar, remover ou restringir algumas de suas funcionalidades.

Existem vários atributos predefinidos, como `Flags`, `Obsolete` e `Conditional`. Observe que o nome completo do [atributo `Flags`][flags-attribute] é `FlagsAttribute`, mas o sufixo "Attribute" pode ser omitido ao usá-lo.

Os quatro atributos predefinidos a seguir são usados com frequência:

- `[Flags]`: Predefinido no namespace System. Indica que o enum dá suporte tanto a operações bit a bit quanto ao método `Enum.HasFlag()`; além disso, `ToString` exibiria todas as flags: [veja um exemplo][flags-example].
- `[Obsolete]`: Predefinido no namespace System. Permite adicionar uma mensagem explicando por que o código está obsoleto; pode ser usado para exibir avisos ou erros do compilador.
- `[Conditional]`: Predefinido no namespace System.Diagnostics. Permite remover algumas chamadas de método em tempo de compilação para fins de depuração (diagnóstico).
- `[CallerMemberName]`: Predefinido no namespace System.Runtime.CompilerServices. Permite que um método obtenha informações sobre quem o chamou.
