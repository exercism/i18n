# Dicas

## 1. Criar a peça de roupa

- Algumas funções podem ser usadas com a sintaxe de compreensão para construí-las.
- `Dict` é exatamente uma dessas funções; revise **Expressões geradoras** na introdução.
- A categoria no índice `i` corresponde à qualidade no índice `i` ([eachindex()][index] pode ser útil)

## 2. Sugerir combinações

- Existe uma sintaxe sucinta para criar arrays multidimensionais a partir de uma compreensão.
- Revise **Saída com múltiplas variáveis e múltiplas dimensões** na introdução
- Certifique-se de que a ordem dos seus iteradores (`tops` / `bottoms`) está correta.

## 3. Somar os preços dos conjuntos

- Você vai precisar acessar o preço das duas peças de roupa e somá-los.
- Certifique-se de que o formato do array de saída é o mesmo do array de entrada.
- Revise **Variável única** na introdução.

## 4. Filtrar os conjuntos que não combinam

- Você vai precisar comparar o `base_color` das duas peças de roupa e descartar os conjuntos que têm o mesmo `base_color`.
- Com uma `Matrix` de entrada, certifique-se de que a saída está na ordem mais eficiente (ou seja, orientada por colunas).
- Revise **Variável única** na introdução.
