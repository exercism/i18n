# Testes

## Linha de comando

O comando a seguir pode ser usado para rodar os testes pela linha de comando:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Substitua `<exercise>` pelo nome do exercício que você está implementando.

## Interativo

Para rodar o Prolog de forma interativa, primeiro execute:

```bash
swipl
```

Depois que o console do Prolog iniciar, carregue sua implementação e rode os testes com:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Substitua `<exercise>` pelo nome do exercício que você está implementando.

### Recarregar alterações

Depois que os arquivos acima estiverem carregados, você pode aplicar as alterações que fez executando:

```
?- make.
```

## Testes ignorados

Quando você começa um exercício, apenas o primeiro teste roda. O restante foi ignorado ao adicionar `condition(pending)` à meta `test`. Assim que o primeiro teste passar, reative o próximo teste mudando `pending` em `condition(pending)` para `true`. Repita para cada teste até que todos estejam rodando e passando.

### Linha de comando

Adicione o argumento `-- --all` ao final do comando para também rodar os testes pendentes:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
