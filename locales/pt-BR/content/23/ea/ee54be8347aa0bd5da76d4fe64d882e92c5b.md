# Introdução

Os [Arrays][arrays-concept] têm métodos nativos para analisar o conteúdo do array.
A maioria desses métodos recebe como argumento uma função que retorna true ou false.
Esse tipo de função é chamada de [`predicate`][predicate_in_programming].

Os métodos nativos devem ser usados _em vez de um laço `for`_ ou do método nativo `forEach`:

Exemplo de análise usando um laço `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Exemplo de análise usando um método nativo:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Veja abaixo outros métodos nativos úteis que estão disponíveis para analisar um array. Consulte a [MDN][mdn-array-methods] para ver a lista completa de métodos de array.

## `includes`

> O método includes() determina se um array inclui determinado valor entre seus elementos, retornando true ou false conforme apropriado. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> O método every() testa se todos os elementos do array passam no teste implementado pela função fornecida. Ele retorna um valor Boolean. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> O método some() testa se pelo menos um elemento do array passa no teste implementado pela função fornecida. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> O método find() retorna o valor do primeiro elemento do array fornecido que satisfaz a função de teste fornecida. Se nenhum valor satisfizer a função de teste, undefined é retornado. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> O método findIndex() retorna o índice do primeiro elemento do array que satisfaz a função de teste fornecida. Caso contrário, retorna -1, indicando que nenhum elemento passou no teste. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
