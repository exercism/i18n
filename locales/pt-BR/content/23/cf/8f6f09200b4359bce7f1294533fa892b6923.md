# Testes

Há uma configuração inicial para cada exercício, que pode levar alguns minutos:

```
npm install
```

Abra dois terminais e, no primeiro, inicie o processo de build.

```
npm start
```

No segundo, deixe os testes rodando.

```
npm test
```

Conforme você edita o código, os dois processos refazem o build e rodam os testes continuamente.
