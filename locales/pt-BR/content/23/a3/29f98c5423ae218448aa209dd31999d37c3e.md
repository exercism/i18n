# Auditoria de pagamentos no banco de dados

## Enunciado do problema

A ABC Corp precisa que você carregue todos os dados do banco de dados SQL em uma [tabela Ballerina](https://ballerina.io/learn/by-example/table-syntax/) para processamento posterior. Depois, você precisa encontrar os nomes dos funcionários que têm registros de pagamento maiores que um valor informado (por exemplo, 3000.00), consultando a tabela Ballerina carregada.

**Passo 1:**

Crie uma tabela Ballerina com as seguintes colunas.

`payment_id` - inteiro

`amount` - decimal

`employee_name` - string

**Passo 2:**

Preencha a tabela Ballerina acima carregando o conjunto completo de dados correspondente no banco de dados H2. Use `payment_id` como chave primária da tabela.

**Passo 3**

Consulte a tabela Ballerina usando expressões de consulta do Ballerina para encontrar os nomes dos funcionários que têm registros de pagamento maiores que o valor informado. Ordene o resultado pelo nome do funcionário em ordem crescente. Remova os nomes duplicados do resultado antes de retornar.

> OBSERVAÇÃO: é obrigatório usar uma tabela Ballerina para implementar a solução.

## Detalhes do banco de dados

Use o banco de dados H2 fornecido para este problema.

> O arquivo de banco de dados de exemplo é `gofigure.mv.db`, e o nome do banco de dados é `gofigure`. Ele está dentro da pasta `db`.

As tabelas a seguir já existem no banco de dados H2 de exemplo, com alguns dados de exemplo. Os nomes das colunas e os tipos de dados estão abaixo.

**Nome da tabela**: `Employee`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | inteiro, chave primária com autoincremento       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | inteiro        |

**Nome da tabela**: `Payment`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | inteiro, chave primária com autoincremento       |
| `date`            | data        |
| `amount`          | decimal        |
| `employee_id`     | inteiro        |
| `reason`          | string        |

* O arquivo do banco de dados é `gofigure.mv.db`. Use a URL JDBC como `jdbc:h2:file:/path/to/db/file`
* Nome de usuário: `root`
* Senha: `root`

## Restrições

* Use o arquivo de banco de dados H2 fornecido na pasta `db` para validar as consultas e o exemplo em Ballerina
* Use a abordagem de parâmetros de dependência do Maven para adicionar o driver do banco de dados H2 como dependência de plataforma no seu Ballerina.toml

## Ambiente de testes

* Você pode rodar os testes com `bal test`, e eles serão executados contra o banco de dados de exemplo fornecido.
