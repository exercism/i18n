# Instruções

Como uma mágica iniciante, Elyse precisa analisar o baralho dela de várias maneiras diferentes.
Para simplificar, ela só usa cartas com valores de 1 a 10.

## 1. Determine quantas cartas de um certo tipo há no baralho

Elyse quer saber quantas cartas de um determinado tipo ela tem no baralho.

Escreva uma função `cardTypeCheck` que recebe dois parâmetros: um array de cartas (o baralho da Elyse) e o tipo de carta a contar.

<!--prettier-ignore -->
~~~exercism/note
A função deve usar `forEach` e retornar o número de cartas do tipo especificado no baralho.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. Determine quantas cartas ímpares ou pares há

Para outro truque, Elyse precisa saber quantas cartas ímpares ou pares há no baralho dela.

Implemente uma função `determineOddEvenCards` que recebe dois parâmetros: um array de cartas (o baralho da Elyse) e um boolean (true é análogo a "par", e false é análogo a "ímpar").

Essa função deve retornar um único número: a quantidade de cartas ímpares ou pares que há no baralho (dependendo do valor do segundo argumento).

<!--prettier-ignore -->
~~~exercism/note
Para praticar, desta vez use um laço `for...of` na implementação da função.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
