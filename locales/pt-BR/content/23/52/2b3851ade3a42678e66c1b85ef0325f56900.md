# Classes e propriedades readonly

Classes e propriedades readonly permitem que as classes especifiquem propriedades públicas para facilitar o acesso, mas impedem a modificação.
Para declarar uma propriedade como readonly, é preciso adicionar `readonly` antes da especificação de tipo.
A propriedade pode ser atribuída uma vez, mas qualquer tentativa de atribuir novamente ou de modificar o valor resultará em um Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

As classes readonly se baseiam nesse comportamento e, se declaradas como `readonly`, aplicam a declaração de somente leitura a cada propriedade.
Além disso, elas impedem a adição de propriedades dinâmicas.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
