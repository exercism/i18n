# Sobre listas

**Listas** são a coleção de sequências ordenadas do Java.
Diferente dos arrays, uma [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) pode crescer de tamanho para acomodar qualquer número de itens.
Uma implementação padrão é a `ArrayList`, que é sustentada por um array redimensionável.
Outra implementação padrão é a classe `LinkedList`, que é sustentada por uma lista duplamente encadeada.

As `List`s podem estar vazias ou conter qualquer número de itens (inclusive duplicatas).
As `List`s são uma **interface genérica** tipada para indicar que tipo de objetos elas podem conter.
Por exemplo:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

As `List`s têm vários métodos úteis para adicionar, remover, obter e verificar se um elemento está presente:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```

A classe [`Collections`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Collections.html) também tem alguns utilitários úteis para lidar com coleções como a `List`:

```java
List<Integer> numbers = new ArrayList<>(List.of(1, 5, 3, 2, 4));
Collections.sort(numbers); // [1, 2, 3, 4, 5]
Collections.reverse(numbers); // [5, 4, 3, 2, 1]
Collections.fill(numbers, 42); // [42, 42, 42, 42, 42]
List<Integer> fiveNines = Collections.nCopies(5, 9); // [9, 9, 9, 9, 9]
```
