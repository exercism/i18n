# Introdução

## Bools

O Gleam representa valores verdadeiro e falso com o tipo `Bool`. Existem apenas dois valores: `True` e `False`. Esses valores podem ser associados a uma variável:

```gleam
let true_variable = True
let false_variable = False
```

Os operadores `&&`, `||` e `!` podem ser usados para manipular valores Boolean:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Os operadores `&&` e `||` usam avaliação de curto-circuito. Isso significa que a expressão do lado direito do operador só é avaliada quando necessário.

Cada operador tem uma precedência diferente: `!` é avaliado antes de `&&` e `||`. As chaves podem ser usadas para avaliar uma parte da expressão antes das outras:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
