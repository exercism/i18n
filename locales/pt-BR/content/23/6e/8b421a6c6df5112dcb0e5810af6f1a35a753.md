# Sobre

[`Rational numbers`][rational] são frações com um numerador inteiro dividido por um denominador inteiro.

Por exemplo, em vez do valor aproximado `0.6666...` de um `Float64`, podemos armazenar `2//3` como uma fração exata.

A vantagem é que (exceto no caso extremo de [estouro de inteiro][integer-overflow]) um número racional permanece exato, evitando os erros de arredondamento que muitas vezes são inevitáveis com números de ponto flutuante.

Alguns detalhes adicionais estão na [página do manual][julia-rational] do Julia.

Os números racionais são um tipo numérico bastante simples e funcionam mais ou menos como você esperaria.
Como são um tipo padrão do Julia desde as primeiras versões, a maioria das funções os aceita como entrada da mesma forma que inteiros e números de ponto flutuante.

## Criando números racionais

Criar um número racional é tão simples quanto usar `//` entre dois inteiros.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Fatores comuns são removidos automaticamente, convertendo a fração para a sua ["forma irredutível"][lowest-terms]: os menores inteiros que representam a fração com exatidão e com um denominador não negativo.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Resultados infinitos são aceitos, mas [`NaN`][NaN] não.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Aritmética com números racionais

Os [`arithmetic operators`][operators] usuais `+ - * / ^ %` funcionam com racionais, essencialmente da mesma forma que com outros tipos numéricos.

Inteiros e outros `Rational`s podem ser incluídos e dão um resultado `Rational`.
Incluir um `float` na expressão resulta em uma saída `float`, com uma consequente (possível) perda de precisão.

Se você quiser um `float`, basta usar a função `float()` para converter um racional.
É bastante comum usar números racionais para preservar a precisão ao longo de um cálculo longo e só no final converter para ponto flutuante.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

Racionais e [números complexos][complex] também podem ser combinados.
Os números complexos são discutidos em um [conceito à parte][complex-concept].

## Outras operações

No Julia, números racionais são apenas números.
O compilador geralmente converte os tipos conforme necessário.

No entanto, cuidado: as comparações funcionam para frações com representação decimal finita:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Caso contrário, um `Rational` deve ser convertido para `Float` antes das comparações:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Funções matemáticas recebem racionais como entrada, mas podem dar um resultado de ponto flutuante:

```julia-repl
julia> sqrt(9//16)
0.75
```
