# Geral

[O tutorial de comparações do Python][python comparisons tutorial] e os [exemplos de comparações do Python][python comparisons examples] são uma ótima introdução que cobre o conteúdo deste exercício.

## 1. Calcule o valor de uma carta

- Você pode usar o operador de comparação de igualdade `==` para determinar se uma carta é um ás: `card == 'A'`.
- Você pode usar o operador de pertinência `in` para determinar se uma substring está contida em uma string: `'Q' in 'KJQ'`.
- Você pode usar o [construtor `int`][int constructor] para converter uma `str` de um `int` em um `int`: `int('13')`.

## 2. Determine qual carta tem o valor mais alto

- Depois de definir a função `value_of_card`, você pode chamá-la de outras funções.
- Você pode usar os operadores de comparação de valor `>` e `<` para determinar se cartas específicas são _maiores que_ ou _menores que_ um determinado valor: `3 < 12`.
- Você pode usar o operador de comparação de igualdade `==` para determinar se dois valores são iguais entre si.

## 3. Calcule o valor de um ás

- Depois de definir a função `value_of_card`, você pode chamá-la de outras funções.
- Você pode usar o operador de comparação de ordem `>` para decidir o curso de ação apropriado aqui.

## 4. Determine o Blackjack

- Lembre-se de que você pode usar a [sintaxe `if`/`elif`/`else`][if syntax] para lidar com diferentes combinações de cartas.
- Você pode encadear TANTO operadores de comparação QUANTO operadores Boolean _de forma arbitrária_: `y < z < x` ou `(y or z) and (x or z)`
- Você pode reutilizar a função `value_of_card` já implementada.

## 5. Dividir pares

- Você pode reutilizar a função `value_of_card` já implementada.
- Você pode tratar o caso do `A` (quando pelo menos uma das cartas é um ás) separadamente.

## 6. Dobrar a aposta

- Um `A` valendo 11 nunca vai permitir dobrar a aposta se houver duas cartas na mão.
- Dado o primeiro ponto, você _deve_ conseguir reutilizar a função `value_of_card` já implementada.
- Você pode encadear operadores de comparação _de forma arbitrária_: `y < z < x`.
- Você pode usar a [expressão condicional][conditional expression] (_às vezes chamada de "operador ternário"_)
  para encurtar instruções `if`/`else` simples: `13 if letter == 'M' else 3`.
