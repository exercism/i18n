# Cabeçalho fictício

## Instruções específicas do Bash

O objetivo deste exercício é considerar o número de argumentos passados para o seu programa.

Repare que você pode passar strings vazias como argumentos.

`./program ""`

Isso é diferente de não passar argumento nenhum.

`./program`

Se o seu programa for rodado com exatamente um argumento (mesmo que seja uma string vazia), trate-o como o nome de uma pessoa e imprima uma mensagem de saudação.
Se for rodado sem nenhum argumento ou com mais de um argumento, imprima uma mensagem de erro e encerre com um status diferente de zero.
