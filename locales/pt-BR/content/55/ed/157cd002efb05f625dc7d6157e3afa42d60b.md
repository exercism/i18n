# Instruções

O porto de Palermo é um movimentado ancoradouro, com muitos navios chegando e partindo.
Há muito tempo ele tem um sistema manual para acompanhar os navios que estão atualmente no porto.
Esse sistema é muito propenso a erros, e o chefe do porto decidiu substituí-lo por um sistema informatizado.

O chefe do porto contratou você para implementar o novo sistema.
O sistema precisa lidar com identificadores de navios, mas também de destinos.

## 1. Crie o identificador dos portos

A primeira coisa que você precisa fazer é criar o identificador do porto de Palermo.
O identificador são as quatro primeiras letras do nome do porto, em maiúsculas.

Defina a constante `Port::IDENTIFIER` como um símbolo com o valor `:PALE`.
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. Obtenha identificadores para outros portos

O programa também terá que lidar com outros portos, então você precisa criar identificadores para eles também.
O porto gostaria que o sistema fosse automatizado e, como os portos usam convenções de nomenclatura diferentes, os identificadores devem ser gerados a partir do nome do porto.
O identificador são as quatro primeiras letras do nome do porto, em maiúsculas.

Defina o método `Port.get_identifier` para receber uma string como argumento e retornar o identificador como símbolo para aquele porto.

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. Determine em qual terminal um navio deve atracar

O porto tem dois terminais, e o sistema precisa determinar em qual terminal um navio deve atracar.
O terminal é determinado pelo identificador do navio.

O identificador é formado por 2 partes: a primeira é composta por 3 letras maiúsculas que indicam qual carga o navio está transportando, e depois 3 números, que são o identificador único do navio.

Se o identificador do navio indicar que ele carrega **OIL** ou **GAS**, o navio deve atracar no terminal **A**.
Caso contrário, o navio deve atracar no terminal **B**. 

Defina o método `Port.get_terminal` para receber como argumento um símbolo que é o identificador do navio.
O método deve retornar o terminal como um símbolo.

```ruby
Port.get_terminal(:OIL123)
# => :A
```
