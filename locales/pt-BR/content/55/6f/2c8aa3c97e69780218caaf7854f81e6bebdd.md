# Arrays

Arrays (vetores) em PHP são mapas ordenados.
Um mapa é uma estrutura de dados que associa uma chave a um valor.
Arrays são versáteis e podem ser tratados como um array linear (como em `C` ou `Java`), lista [vetor], tabela hash, dicionário, coleção, pilha ou fila.

Uma chave é opcional, mas, se especificada, deve ser um `int` ou uma `string`.
Quando uma chave não é fornecida, o PHP usa, por padrão, chaves inteiras em ordem crescente, começando em `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Um array pode armazenar valores de todos os tipos.
Cada valor pode ter um tipo diferente.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## Usando arrays

Arrays podem ser declarados como um literal (escrito no código, como feito acima) ou criados e manipulados por funções.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

Acesse, atribua e anexe valores usando o operador de índice:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

Itere sobre um array usando `foreach`:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
