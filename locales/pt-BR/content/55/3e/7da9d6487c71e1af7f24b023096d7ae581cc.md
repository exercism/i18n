# Dicas

## Geral

- [Tutorial sobre como trabalhar com enums][docs.microsoft.com-enumeration-types].

## 1. Analisar o nível de log

- Existe um [método para obter uma parte de uma string][docs.microsoft.com_system_string_substring].
- Você pode usar uma [instrução `switch`][docs.microsoft.com_keyword_switch] para tratar os vários níveis de log de forma elegante.

## 2. Suportar nível de log desconhecido

- Existe um [caso especial do `switch`][docs.microsoft.com_keyword_switch_default] que pode ser usado para capturar casos não especificados.

## 3. Converter a linha de log para o formato curto

- É possível [atribuir valores específicos aos membros de um enum][docs.microsoft.com_creating-an-enumeration-type].
- Converter um enum em número pode ser feito por meio de [casting][docs.microsoft.com_enumeration-types-casting] ou usando uma [string de formato][docs.microsoft.com_system.enum.tostring].
