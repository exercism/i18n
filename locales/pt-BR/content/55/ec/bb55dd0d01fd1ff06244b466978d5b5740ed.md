# Dicas

## Geral

- `disposable` está em `destructors`; os genéricos do protocolo de stream estão em `io`; `<string-reader>` (usado pelos testes) está em `io.streams.string`.
- Uma declaração `TUPLE: x < y ...` faz `x` herdar os slots de `y`. `disposable` adiciona uma flag `disposed` e registra a tupla no framework de destrutores quando construída via `new-disposable`.

## 1. Defina a fita

- O construtor: `tape new-disposable swap >>wire ;`. O `swap` serve para que o wire fique abaixo da fita recém-construída para o `>>wire` consumir.

## 2. Inclua o mixin input-stream

- Uma linha no nível superior, depois da declaração `TUPLE:`.

## 3. Leia um símbolo Morse

- A forma mais simples é um laço pequeno: leia um byte, verifique-o, retorne-o se for um símbolo Morse ou `f`; caso contrário, leia o próximo.
- Um literal de caractere é escrito `CHAR: .`. Espaço é `CHAR: \s`.
- `member?` em um array pequeno funciona: `B{ CHAR: . CHAR: - CHAR: \s } member?`.
- A estrutura de controle mais simples: um laço `while` que lê até obter um símbolo Morse ou `f`, combinado com um `dup` final para entregar o resultado a quem chamou.

## 4. Delegue o tipo do elemento

- Um método de uma linha: `wire>> stream-element-type`.

## 5. Limpe

- A mesma forma: `wire>> dispose`.
- Não chame `dispose*` por conta própria. Chame `dispose` no wire. O trabalho do framework é garantir que seu `dispose*` rode apenas uma vez.
