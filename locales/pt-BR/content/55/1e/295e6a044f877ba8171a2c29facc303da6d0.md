# Sets

Um [`set`][type-set] é uma coleção _mutável_ e _não ordenada_ de objetos [_hashable_][hashable].
Os membros de um set precisam ser distintos: itens duplicados não são permitidos.
Eles podem conter vários tipos de dados diferentes e até estruturas aninhadas, como uma `tuple` de `tuples`, desde que todos os elementos possam receber um hash.
Os sets também vêm em uma versão imutável, o [`frozenset`][type-frozenset].

Os sets são usados com mais frequência para remover rapidamente duplicatas de outras estruturas de dados ou de agrupamentos de itens.
Eles também servem para comparações eficientes quando sequenciamento e rastreamento de duplicatas não são necessários.

Assim como outros tipos de coleção (_dicionários, listas, tuplas_), os `sets` suportam:
- Iteração via `for item in <set>`,
- Verificação de pertencimento via `in` e `not in`,
- Cálculo de comprimento via `len()`, e
- Cópias superficiais via `copy()`.

Os `sets` não suportam:
- Indexação de qualquer tipo
- Ordenação por classificação ou por ordem de inserção
- Fatiamento
- Concatenação via `+`


Verificar se um item pertence a um `set` tem complexidade de tempo constante (em média), ao contrário de verificar se um item pertence a uma `list` ou a uma `string`, em que a complexidade cresce conforme o tamanho dos dados aumenta.
Métodos como `<set>.union()`, `<set>.intersection()` ou `<set>.difference()` também têm complexidade de tempo constante (em média).

[hashable]: https://docs.python.org/3.7/glossary.html#term-hashable
[type-frozenset]: https://docs.python.org/3/library/stdtypes.html#frozenset
