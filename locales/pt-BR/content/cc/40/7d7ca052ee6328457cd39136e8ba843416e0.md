# Introdução

Trabalhar com dados binários pode ser complicado, por isso o Gleam oferece um tipo `BitArray` e uma sintaxe própria para construir e fazer casamento de padrões com dados binários.

Os literais de bit array são definidos com a sintaxe `<<>>`. Ao definir um literal de bit array, ele é definido em segmentos. Cada segmento tem um valor e uma anotação, separados por `:`. A anotação especifica quantos bits serão usados para codificar o valor e pode ser omitida por completo, o que faz com que o padrão seja um valor inteiro de 8 bits.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Especificar o tipo como `:1` é uma forma abreviada de escrever `:size(1)`. Você precisa usar a sintaxe mais longa se o tamanho em bits vier de uma variável.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## Binário

Ao escrever literais inteiros binários, podemos escrevê-los diretamente na notação de base 2, prefixando o literal com `0b`. Note que eles serão exibidos como números decimais quando impressos nos testes ou no seu programa.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## Truncamento

Se o valor do segmento exceder a capacidade do tipo do segmento, ele será truncado pela esquerda.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## Adicionar no início e no fim

Você pode adicionar tanto no início quanto no fim de um bit array existente usando a sintaxe de bit array. A anotação `:bits` deve ser usada para o bit array existente.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## Concatenação

Podemos concatenar bit arrays guardados em variáveis usando a sintaxe. A anotação `:bits` deve ser usada ao concatenar dois bit arrays de tamanhos variáveis.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## Casamento de padrões

Também é possível fazer casamento de padrões para obter valores do bit array. Você precisa saber o número de bits de cada fragmento que quer capturar, com uma exceção: a anotação `:bits` pode ser usada para fazer casamento de padrões em um bit array de tamanho desconhecido, mas isso só pode ser usado no último fragmento.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## Inspecionar bit arrays

~~~~exercism/note
Os bit arrays podem ser impressos em um formato diferente do formato usado para criá-los. Isso costuma causar confusão quando se está aprendendo bit arrays.
~~~~

Por padrão, os bit arrays são exibidos em fragmentos de 8 bits (um byte), mesmo que você os tenha criado com fragmentos de tamanho diferente.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Se você criar um bit array que representa uma string codificada em UTF-8 imprimível, ele pode ser exibido como uma string por funções como `io.debug`. Isso acontece por causa de um detalhe de implementação de como o Gleam representa strings internamente.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
