# Sobre

[Guards][guards] são usados como complemento ao [pattern matching][exercism-pattern-matching]. Permitem verificações mais complexas. Podem ser usados em [algumas situações, mas não todas][where-guards-can-be-used] em que o pattern matching pode ser usado, por exemplo em cláusulas de função ou cláusulas de case.

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- Os guards começam com a palavra-chave `when`, seguida de uma expressão booleana.
- As expressões de guard são funções especiais que:
  - Devem ser [puras][pure-function] e não alterar nenhum estado global.
  - Devem retornar valores estritamente `true` ou `false`.
- Uma lista dos guards mais comuns está na [documentação do Elixir][kernel-guards]. Ela inclui:
  - Verificações de tipo: [`is_integer/1`][guard-is-integer], [`is_list/1`][guard-is-list], [`is_nil/1`][guard-is-nil] etc.
  - Operadores aritméticos: [`+/2`][guard-plus], [`-/2`][guard-minus] etc.
  - Comparações: [`==/2`][guard-equals], [`>/2`][guard-greater], [`</2`][guard-less] etc.
  - Operadores booleanos: [`and/2`][guard-and], [`or/2`][guard-or], [`not/1`][guard-not]
  - Operador de pertencimento: [`in/2`][guard-in]
- Você pode definir seus próprios guards com [`defguard`][defguard].

  - De acordo com a [convenção de nomenclatura][naming] do Elixir, os nomes de guards devem começar com `is_`.

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
