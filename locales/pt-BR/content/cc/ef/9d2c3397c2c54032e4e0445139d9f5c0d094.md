# Introdução

O PowerShell é uma linguagem de script da Microsoft, com tipagem dinâmica implícita (e também suporte a variáveis fortemente tipadas), voltada principalmente para automação de tarefas e gerenciamento de configuração.

O PowerShell dá suporte a programação imperativa, funcional, orientada a objetos e até ao estilo de pipeline.

O PowerShell foi construído sobre a plataforma .NET e lançado pela primeira vez em 2006.
Ele vem incluído por padrão em todos os sistemas Windows modernos e pode ser instalado no Mac e no Linux.


## Variáveis

Há duas formas comuns de definir uma variável no PowerShell.

O nome de uma variável no PowerShell precisa começar com `$`, e usamos o operador de atribuição `=` para associar o nome da variável a um valor.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Você também pode especificar explicitamente o tipo de uma variável, caso queira impor um [tipo][strong typed] específico.
O PowerShell faz o possível para converter o valor de um tipo em outro, quando isso é possível.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Constantes

As constantes no PowerShell são variáveis somente leitura que não podem ser **removidas** depois de definidas.
Isso nos leva à segunda forma de definir variáveis, usando o cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Para uma forma mais detalhada e avançada de criar uma nova variável com várias opções, consulte o cmdlet [New-Variable][New-Variable].


## Funções

As [funções][functions] no PowerShell são definidas com a palavra-chave `function`.
Cada função pode ter zero ou mais [parâmetros][parameters] formais entre parênteses `()`, seguidos do próprio [escopo][scope], que começa com `{` e termina com `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

As funções no PowerShell podem retornar valores explicitamente com a palavra-chave `return`, depois de serem chamadas com a sintaxe `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Uma análise mais avançada de como escrever uma definição detalhada de função, e de como as funções podem retornar valores de forma implícita, será abordada no módulo do conceito `Functions`.


## Comentários

Um comentário de uma linha no PowerShell começa com `#` e termina no fim da linha.
Um bloco de comentário no PowerShell começa com `<#` e termina com `#>`.
Uma demonstração avançada de bloco de comentário para criar o Comment-Based Help será abordada no módulo do conceito `Functions`.

```powershell
function Main() {
    #This is a comment
}
```
