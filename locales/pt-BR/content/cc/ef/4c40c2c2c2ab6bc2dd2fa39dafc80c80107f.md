# Conceitos de números de Armstrong

> Um [número de Armstrong](https://en.wikipedia.org/wiki/Narcissistic_number) é um número que é a soma dos próprios dígitos, cada um elevado à potência da quantidade de dígitos.

## Exemplo de solução

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## Conceitos

- funções: essenciais para verificar a solução e definir a lógica
- suítes de testes: necessárias para verificar a solução
- inteiros: `u32` para o argumento e para as asserções de identidade
- `&str`: necessário para contar o comprimento do número, já que Rust tem tipagem forte
- `Option<T>`: necessário para acessar o valor real de `char::to_digit`
- conversão de tipos: necessária para aplicar operações aritméticas
- recursos de iteradores:
  - turbofish para permitir uma solução com uma única expressão
  - `map` e `sum` para reduzir convenientemente a expressão ao que precisamos verificar
