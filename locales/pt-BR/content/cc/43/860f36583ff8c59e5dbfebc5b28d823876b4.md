# Introdução

## Arrays

Um `array` (ou _vetor_) em F# é uma coleção mutável de zero ou mais valores com comprimento fixo. Isso significa que, depois que um array é criado, seu tamanho não pode mudar, mas seus valores podem. Todos os valores de um array precisam ter o mesmo tipo. Os arrays podem ser definidos assim:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Os elementos podem ser atribuídos a um array ou recuperados dele usando um índice. Os arrays em F# são indexados a partir do zero, o que significa que o índice do primeiro elemento é sempre zero:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Os arrays são manipulados por funções e operadores definidos no módulo `Array`, ou manualmente com correspondência de padrões usando o padrão _array_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Você também pode _descartar_ um valor na correspondência de padrões; quando você _não_ se importa com um valor em um caso específico (ou seja, você não vai _usar_ um valor), você pode usar um sublinhado (`'_'`) para indicar isso:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

O `'_'` sozinho deve sempre vir por _último_ na correspondência de padrões; todo valor que _não_ corresponder a nenhum dos outros casos será tratado por esse caso.
