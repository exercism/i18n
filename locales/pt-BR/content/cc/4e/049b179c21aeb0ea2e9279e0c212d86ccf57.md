# Instruções

Neste exercício, você vai trabalhar com contas poupança.
A cada ano, o saldo da sua conta poupança é atualizado com base na taxa de juros dela.
A taxa de juros que o seu banco oferece depende da quantidade de dinheiro na sua conta (o saldo):

- 3,213% para um saldo negativo (o saldo fica ainda mais negativo).
- 0,5% para um saldo positivo menor que `1000` dólares.
- 1,621% para um saldo positivo maior ou igual a `1000` dólares e menor que `5000` dólares.
- 2,475% para um saldo positivo maior ou igual a `5000` dólares.

Você tem quatro tarefas, e cada uma delas vai lidar com o seu saldo e a sua taxa de juros.

## 1. Calcule a taxa de juros

Implemente o método `SavingsAccount.interest_rate()`, que recebe um saldo como argumento.
O método deve retornar a taxa de juros para o saldo informado.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. Calcule os juros

Implemente o método `SavingsAccount.interest()`, que recebe um saldo como argumento.
O método deve retornar os juros para o saldo informado.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. Calcule a atualização anual do saldo

Implemente o método `SavingsAccount.annual_balance_update()`, que recebe um saldo como argumento.
O método deve retornar o saldo depois de um ano.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. Calcule quantos anos faltam para atingir o saldo desejado

Implemente o método `SavingsAccount.years_before_desired_balance()`, que recebe um saldo e um saldo alvo como argumentos.
O método deve retornar o número de anos necessários para atingir o saldo alvo.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
Ao aplicar juros simples a um saldo principal, o saldo é multiplicado pela taxa de juros e o produto dos dois é o valor dos juros.

Os juros compostos, por outro lado, são aplicados de forma recorrente.
A cada aplicação, o valor dos juros é calculado e somado ao saldo principal, de modo que os cálculos de juros seguintes incidem sobre um saldo principal maior.
~~~~
