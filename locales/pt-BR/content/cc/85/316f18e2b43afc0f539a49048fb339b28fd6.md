# Sobre

Os Boolean em C++ são representados pelo tipo `bool`.
Um `bool` é `true` ou `false`.

## Operadores lógicos

C++ oferece três operadores Boolean: `!` (NÃO), `&&` (E) e `||` (OU).
Você também pode usar as versões alternativas `not`, `and` e `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Precedência

Os três operadores Boolean têm _precedência de operador_ diferente entre si.
Por isso, eles são avaliados nesta ordem: `!` primeiro, `&&` em segundo e, por fim, `||`.
Se você quiser forçar uma ordem diferente, pode colocar uma expressão Boolean entre parênteses (ou seja, `()`), já que os parênteses têm precedência de operador ainda maior.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Conversão

Se você usar `true` ou `false` em um lugar onde se espera um número, eles serão convertidos em `1` e `0`, respectivamente.
Se você usar um número em uma operação Boolean, tudo o que não for `0` é tratado como `true`, inclusive valores negativos.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
