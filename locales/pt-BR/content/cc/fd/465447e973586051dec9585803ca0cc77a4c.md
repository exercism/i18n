# Apêndice de instruções

## Palavras

Defina uma tupla `game` e um construtor `<game> ( -- game )` que retorna um novo jogo sem arremessos.

Forneça estas palavras que operam sobre um jogo:

- `roll ( pins game -- )`: registra que `pins` pinos foram derrubados. Lance um erro quando o arremesso for inválido:
  - `"Negative roll is invalid"` para um número negativo de pinos.
  - `"Cannot roll after game is over"` depois que todos os dez frames (e quaisquer bolas de preenchimento) tiverem sido arremessados.
  - `"Pin count exceeds pins on the lane"` quando mais pinos forem derrubados do que estão de pé.
- `score ( game -- n )`: a pontuação total do jogo. Lance `"Score cannot be taken until the end of the game"` quando o jogo ainda não estiver completo.

Repare que `roll` sombreia a palavra `roll` de embaralhamento do vocabulário `kernel`.

A suíte de testes desfaz a ambiguidade com `FROM: bowling => roll ;`.
