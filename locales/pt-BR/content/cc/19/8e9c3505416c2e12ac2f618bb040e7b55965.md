# Instruções

Neste exercício, você vai trabalhar com algumas funções para gerenciar compromissos.
O sistema guarda tudo em strings formatadas conforme a ISO 8601, mas não é assim que as pessoas usam o calendário.
Várias funções são necessárias para converter entre os diversos formatos.

## 1. Crie um compromisso

Crie um compromisso daqui a `n` dias, no horário atual.
A função recebe `n` dias e retorna o horário do compromisso daqui a `n` dias.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

Se o segundo parâmetro `now` não for usado, o horário atual deve ser usado em vez dele.

## 2. Converta uma data em um timestamp

Várias ferramentas só funcionam com o formato ISO 8601, padronizado internacionalmente.
Escreva a função `getAppointmentTimestamp` para receber uma data e retornar uma string nesse formato.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. Obtenha os detalhes de um compromisso

Timestamps são difíceis de ler; uma função para obter os detalhes do compromisso deve ajudar com isso.
A função `getAppointmentDetails` recebe um timestamp no formato ISO 8601 e retorna o ano, o mês, o dia, a hora e o minuto.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. Atualize um compromisso com as opções fornecidas

A função receberá como primeiro argumento o horário do compromisso e como segundo argumento um objeto com algumas opções.
Você deve atualizar o compromisso de acordo com as opções no objeto e retornar a nova data do compromisso.
O objeto de opções pode ter várias opções.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. Obtenha o tempo disponível entre dois compromissos

A função receberá dois compromissos (timestamps) como argumentos.
Você deve retornar a diferença entre esses dois horários em segundos.

Como meio segundo é quase insignificante, arredonde o número antes de retorná-lo.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. Verifique se um compromisso é válido ou não

Por fim, quando o compromisso é marcado, o sistema precisa verificar se ele é válido.
Em outras palavras, o compromisso deve estar no futuro, e não no passado.

Escreva a função `isValid`, que recebe dois argumentos, um timestamp de compromisso (string) e o horário atual como timestamp (string), e retorna `true` se o compromisso estiver no futuro, dado o horário atual.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
