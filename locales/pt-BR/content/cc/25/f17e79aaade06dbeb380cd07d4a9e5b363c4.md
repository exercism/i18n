# Instruções

Aquele carrinho de controle remoto que você comprou recentemente virou um hobby totalmente novo. Você tem organizado corridas de carrinhos de controle remoto.

Você estava quase terminando de escrever um programa que permitiria rodar simulações de corrida quando seu gato pulou em cima do seu teclado e apagou algumas linhas de código. Agora seu programa não compila mais...

## 1. Corrija o erro de compilação `Race.__struct__/0 is undefined`

Adicione um alias para que o módulo `NeedForSpeed.Race` possa ser referenciado pelo nome mais curto `Race`.

## 2. Corrija o erro de compilação `Car.__struct__/0 is undefined`

Adicione um alias para que o módulo `NeedForSpeed.RemoteControlCar` possa ser referenciado pelo nome mais curto `Car`.

## 3. Corrija o erro de compilação `undefined function puts/1`

A função `puts/1` vem do módulo `IO`. Importe-a para poder usá-la sem referenciar o módulo.

## 4. Corrija o erro de compilação `undefined function default_color/0`

As funções `default_color/0`, `red/0`, `cyan/0` e `green/0` vêm todas do módulo `IO.ANSI`. Você está planejando adicionar suporte a outras cores de carro, então quer importar o módulo inteiro. Infelizmente, a função `color/1` do módulo `IO.ANSI` entra em conflito com uma das suas funções locais. Importe todo o módulo `IO.ANSI`, exceto essa função.
