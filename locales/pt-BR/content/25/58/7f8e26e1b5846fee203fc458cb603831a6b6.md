# Instruções

Você faz parte de uma equipe de desenvolvimento web que mantém o site de um time de basquete local. A equipe conhece pouco de Elixir e está pedindo uma função capaz de extrair dados de uma série de mapas aninhados para facilitar o desenvolvimento rápido.

## 1. Extrair dados de uma estrutura de mapas aninhados

Implemente a função `extract_from_path/2` para receber dois argumentos:

- `data`: uma estrutura de mapas aninhados com dados sobre o time de basquete.
- `path`: uma string composta de chaves separadas por pontos, para obter o valor associado à última chave.

Caso o valor ou a chave não exista em nenhum ponto do caminho, a função deve retornar `nil`.

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

Use o _Access Behaviour_ ao implementar essa função.

Não use nenhuma função dos módulos `Map` ou `Kernel` para trabalhar com a estrutura de mapas aninhados.

## 2. Refatore usando funções incluídas

Um colega que revisa seu código comenta sobre uma função do módulo `Kernel` que faz algo muito parecido com a sua implementação.

Implemente `get_in_path/2` usando essa função do módulo `Kernel`.

Os argumentos esperados são os mesmos da parte 1.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
