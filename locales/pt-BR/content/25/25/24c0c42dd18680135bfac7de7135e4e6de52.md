# Executando os testes

Para compilar e rodar os testes, basta executar o seguinte no diretório do seu exercício:
```bash
$ ponyc
$ ./exercise-name
```

(Substitua `exercise-name` pelo nome do diretório do exercício)

O binário compilado roda os testes no seu ator Main, então basta rodar o binário e ver se os seus testes passaram. O Pony verifica todo o código em tempo de compilação, então pode acontecer de seus testes não compilarem até você escrever o código necessário. Você pode comentar os testes que não compilam começando cada linha com `//`. Depois, quando quiser trabalhar nesse teste, basta descomentá-lo.
