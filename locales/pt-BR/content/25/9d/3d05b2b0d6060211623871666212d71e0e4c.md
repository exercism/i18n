# Instruções

Você está anotando a contagem diária de quantos pássaros visitam seu jardim. Os dados ficam guardados em um array de inteiros, com **a contagem de hoje em primeiro lugar**.

## 1. A contagem de hoje

Defina `today` para pegar um array de contagens diárias da pilha e retornar a contagem de hoje, ou `f` se o array estiver vazio.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Incrementar a contagem de hoje

Defina `increment-day-count` para retornar um novo array com a contagem de hoje aumentada em um. Se a entrada estiver vazia, retorne `{ 1 }`.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. Houve algum dia sem pássaros?

Defina `has-day-without-birds?` para retornar `t` se pelo menos um dia registrou zero pássaros, e `f` caso contrário.

**Use recursão** em vez de `any?` ou de outras palavras de ordem superior para sequências.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Total de pássaros desde o início

Defina `total` para retornar a soma de todas as contagens.

**Use recursão** em vez de `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Dias movimentados

Um dia movimentado é aquele com cinco pássaros ou mais. Defina `busy-days` para retornar o número de dias movimentados.

**Use recursão** em vez de `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
