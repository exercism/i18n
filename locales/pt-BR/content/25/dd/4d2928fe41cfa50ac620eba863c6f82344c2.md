# Instruções

Implemente vários tipos de tratamento de erros e de gerenciamento de recursos.

Um ponto importante da programação é saber como tratar erros e fechar recursos mesmo quando ocorrem erros.

Este exercício pede que você trate vários erros.
Como o tratamento de erros é bastante específico de cada linguagem de programação, você vai precisar consultar os testes da sua trilha para ver exatamente o que é necessário.
