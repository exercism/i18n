# Introdução

## Variáveis de instância

Objetos podem guardar o próprio estado definindo _variáveis de instância_.
Essas variáveis vivem dentro de um objeto e normalmente são usadas para armazenar algum estado interno.

Variáveis de instância sempre começam com um `@`.
Você pode criar uma nova variável de instância definindo uma variável que comece com `@`.
Por exemplo:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

Objetos geralmente definem seu estado inicial em um método `initialize`, que é chamado automaticamente quando você chama `new` em uma classe.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

O método `initialize` também pode receber argumentos, para que cada instância possa começar com um estado personalizado:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

É uma boa prática considerar as variáveis de _instância_ como privadas, tanto para leitura quanto para escrita externas.
Em vez disso, definimos métodos para obter e definir seus valores.
Por exemplo:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] é uma palavra em inglês que significa "nada" ou "zero".
Em Ruby, `nil` é usado para expressar a _ausência_ de um objeto.
Em outras linguagens de programação, valores `null` ou `none` podem desempenhar um papel parecido.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby dá a qualquer variável de instância o valor padrão `nil` quando ela é encontrada pela primeira vez, até que receba outro valor.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
