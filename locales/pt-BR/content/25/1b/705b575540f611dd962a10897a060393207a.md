# Sobre

Uma [tupla](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) é um agrupamento _imutável_ de valores sem nome, mas ordenados.
As tuplas podem conter qualquer tipo de dado (ou vários), inclusive outras tuplas.

As tuplas são definidas como valores separados por vírgula entre os caracteres `(` e `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Só é possível comparar tuplas com o mesmo comprimento e os mesmos tipos (na mesma ordem).
As tuplas têm igualdade estrutural, ou seja, elas são iguais _apenas_ quando todos os seus valores são iguais.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Existem [três formas de extrair valores de uma tupla](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values):

- As funções `fst` e `snd`
- Desconstrução de tuplas
- Correspondência de padrões

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
Tecnicamente, você pode acessar o valor de uma tupla usando as propriedades `.Item1`, `.Item2`, ..., mas isso não é recomendado e gera um aviso do compilador.
~~~~

## Pontos principais sobre tuplas

Alguns pontos importantes que você precisa saber sobre tuplas:

- Uma instância específica de um tipo tupla é um único objeto, parecido, por exemplo, com um array de dois elementos em C#. Ao usá-las com funções, elas contam como um único parâmetro. A única exceção é ao chamar código que não é F# com vários parâmetros, caso em que você passa uma tupla e os valores dela são extraídos automaticamente para os valores dos parâmetros correspondentes.
- Não é possível dar nomes explícitos a tipos tupla. O “nome” do tipo tupla é determinado pela combinação dos tipos que são multiplicados entre si.
- A vírgula é o símbolo crucial que define as tuplas, e não os parênteses. Você pode definir tuplas sem os parênteses, embora isso às vezes possa ser confuso. Em F#, se você vir uma vírgula, provavelmente ela faz parte de uma tupla.
- As tuplas podem ser usadas como argumentos de função e como valor de retorno de função.
