# Instruções

Você faz parte do helpdesk de TI e quer melhorar o sistema de tickets para que ele seja mais eficiente e para fornecer estatísticas à sua gerente.

Um ticket tem um status (new, in progress...), uma pessoa criadora (identificada por um nome de usuário e um ID de funcionário), pode ser atribuído a um funcionário de TI e contém um histórico de comentários.

Aqui estão quatro tarefas que vão melhorar seu sistema de tickets atual.

## 1. Detectar comentários vazios

Comentários vazios poluem a interface e não trazem nenhuma informação, então você quer filtrá-los.

Defina uma função auxiliar `emptyComment` que recebe um par usuário/comentário e retorna `True` para comentários vazios.

Use desestruturação para extrair o usuário e o comentário diretamente no argumento da função. Ignore o usuário, já que você não precisa dessa informação.

```elm
emptyComment ( User "Alice", "" )
-- => True
```

## 2. Contar o número de comentários de quem criou o ticket

Sua gerente quer ter estatísticas sobre o envolvimento das pessoas no processo de tickets.
Ela pede que você verifique quantos comentários foram adicionados por quem criou o ticket.

Defina `numberOfCreatorComments`, que recebe um ticket e retorna o número de comentários adicionados por quem criou o ticket.

Use desestruturação no argumento da função para extrair o record do tipo `Ticket`, ao mesmo tempo que os campos de que você precisa do record.
Depois, desestruture o `createdBy` em uma ligação `let` para poder contar os comentários relevantes.
Use funções do módulo `List` para fazer a contagem e use desestruturação no argumento de uma função anônima para separar o par usuário/comentário.

```elm
numberOfCreatorComments
numberOfCreatorComments
    (Ticket
        { status = Closed
        , createdBy = ( User "Chiaki", 1 )
        , assignedTo = Nothing
        , comments = [ ( User "Chiaki", "Never mind, fixed it." ) ]
        }
    )
-- => 1
```

## 3. Detectar tickets atribuídos ao Time de Desenvolvimento

Alguns tickets precisam ser escalados para Alice, Bob ou Charlie, do Time de Desenvolvimento.
É importante ficar de olho neles para garantir que estejam avançando.

Defina uma função auxiliar `assignedToDevTeam` que verifica se um ticket está atribuído a um dos membros do Time de Desenvolvimento.

Use desestruturação no argumento da função para extrair o record do tipo `Ticket`, bem como o campo de que você precisa.
Depois, use um único `case` para verificar se o ticket está atribuído a Alice, Bob ou Charlie, usando pattern matching recursivo para extrair os nomes de usuário e pattern matching literal para compará-los.

```elm
assignedToDevTeam
    (Ticket
        { status = InProgress
        , createdBy = ( User "Bill", 2 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Bill", "What's an 'undefined'?" ) ]
        }
    )
-- => True
```

## 4. Atribuir tickets a funcionários de TI

Às vezes, vários tickets precisam ser reatribuídos a outros funcionários de TI.

Defina uma função `assignTicketTo` para ajudar você a fazer isso. A função recebe dois argumentos: um usuário para quem atribuir o ticket e um ticket.
Se o status do ticket for `New`, atribua-o ao novo usuário e mude o status para `InProgress`.
Para os outros status, apenas reatribua o ticket ao novo usuário, exceto os tickets com o status `Archived`, que não devem ser modificados de forma alguma.

Use desestruturação no argumento da função para extrair o record do tipo `Ticket`, bem como o campo de que você precisa, e use também a palavra-chave `as` para capturar o record inteiro como ele está.
Use um único `case` para fazer pattern matching do status e retornar o ticket apropriado, criado a partir da modificação do record original que você capturou com a palavra-chave `as`.

```elm
assignTicketTo (User "Danny")
    (Ticket
        { status = New
        , createdBy = ( User "Jesse", 3 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
        }
    )
-- => Ticket
--        { status = InProgress
--        , createdBy = ( User "Jesse", 3 )
--        , assignedTo = Just (User "Danny")
--        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
--        }
```
