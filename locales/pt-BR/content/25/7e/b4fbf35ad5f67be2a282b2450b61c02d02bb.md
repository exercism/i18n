# Instruções

Quando os aliens de Lisp chegaram à Terra pela primeira vez, encontraram incontáveis coisas estranhas e maravilhosas, mas uma de suas descobertas favoritas foi a dos "animais de estimação". Vamos ser sinceros: que tipo de alien não se derreteria por um filhote de cachorro ou de gato?

Ludwig, depois de sua recente viagem à Terra, decidiu que quer um animal de estimação só para si! O único problema? Opções demais! Talvez você possa escrever um programa para ajudar Ludwig a encontrar e cuidar de seu próximo amigo fofinho?

## 1. Escolhendo um amigo

Embora Ludwig esteja decidido a adotar um animal de estimação, o planejamento parou por aí. O primeiro passo, então, é decidir que tipo de animal escolher!

Ludwig quer encontrar um companheiro com uma personalidade que complemente a sua. Você poderia escrever para Ludwig uma função chamada `pal-picker` que recebe um traço de personalidade (uma palavra-chave) e retorna o tipo de animal (uma string) com o traço dado?

Neste caso específico:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

Para outras personalidades desconhecidas, sua função deve resultar em: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. Em seu habitat natural

Agora que Ludwig tem um novo amigo, vai precisar de um lugar para morar! Você pode ajudar Ludwig a escolher o tamanho certo de cama, aquário ou gaiola para o animal?

Aqui, Ludwig precisa de uma função chamada `habitat-fitter` para selecionar o tamanho adequado do habitat (uma palavra-chave) a partir do peso do animal em quilogramas (um número inteiro).

Os habitats necessários para cada tamanho de animal são:

- 40kg ou mais -> `:massive`
- de 20kg a 39kg, inclusive -> `:large`
- de 10kg a 19kg, inclusive -> `:medium`
- de 1kg a 9kg, inclusive -> `:small`
- 0kg ou menos -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. E agora, a refeição

Uma coisa que todos os animais terrestres têm em comum é a necessidade de comida! Esse conceito, porém, é meio alienígena para Ludwig, que costuma esquecer de reabastecer o pote de comida do animal.

Ludwig poderia usar uma função simples chamada `feeding-time` para avisar quando o pote precisar ser reabastecido. A função receberia um percentual de preenchimento (um número inteiro) e retornaria uma mensagem na forma de uma string.

Se o nível de comida estiver:

- Acima de 20% -> `"All is well."`
- 20% ou menos -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. Um código de conduta

Com o básico resolvido, Ludwig está ansioso para experimentar várias coisas empolgantes, como fazer carinho e brincar de buscar. Dito isso, nem todo animal é adequado para essas atividades.

Ludwig gostaria de um par de funções, `pet` e `play-fetch`, que recebem o tipo de animal (como uma string) e retornam ou nada, ou uma mensagem como: `"Maybe not with this pet..."` se a ação não for adequada.

Considere que apenas os `"Dog"`s brincam de buscar e que todos os animais, exceto `"Fish"`, podem receber carinho.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
