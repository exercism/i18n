# Sobre

O mais importante a lembrar sobre strings em C# é que elas são objetos imutáveis que representam texto como uma sequência de caracteres Unicode (letras, dígitos, pontuação etc.). Usamos aspas duplas para definir uma instância de `string`:

```csharp
string fruit = "Apple";
```

Para manipular uma string, você pode chamar um dos seus [métodos][methods] ou [propriedades][properties]. Como os valores de string nunca mudam depois de definidos, todos os métodos de manipulação de string retornam uma nova string.

Uma string é delimitada por caracteres de aspas duplas (`"`). Alguns caracteres especiais precisam ser [escapados][escaping] com o caractere barra invertida (`\`). Uma string também pode ser prefixada com o símbolo arroba (`@`), o que a transforma em uma [string verbatim][verbatim] que ignora qualquer caractere escapado.

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

Se você só precisa de uma parte de uma string, pode usar o [método `Substring()`][substring] para extrair apenas essa parte:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

O [método `IndexOf`()][indexof] pode ser usado para encontrar o índice da primeira ocorrência de uma `string` dentro de outra `string`, retornando `-1` se o valor especificado não for encontrado:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

Por fim, existem [várias formas de concatenar uma string][concatenation]. A mais simples é usar o [operador `+`][plus-operator].

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para qualquer formatação de string mais complexa que a concatenação simples, a [interpolação de strings][interpolation] é preferível. Para habilitar a interpolação em uma string, coloque o símbolo de cifrão (`$`) antes dela.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
