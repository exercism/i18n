## Executando os testes

1. Vá até a raiz do diretório do seu exercício de PHP, que é `<EXERCISM_WORKSPACE>/php`.
   Para descobrir o workspace do Exercism, rode

   ```shell
   exercism workspace
   ```

2. Instale o [PHPUnit] se você ainda não tiver.
3. Execute os testes com:

   ```shell
   phpunit test_file.php
   ```

   Por exemplo, para rodar os testes do exercício Hello World, você rodaria:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
