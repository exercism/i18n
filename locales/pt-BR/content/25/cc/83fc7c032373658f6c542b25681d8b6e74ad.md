# Complemento das instruções

## Literais de data de nascimento com `from_quote`

A função `DateOfBirth.from_quote` interpreta uma string formatada como `"YYYY-MM-DD"` e a transforma em um `DateOfBirth`.
Isso permite escrever um código como este:

```roc
birthdate : DateOfBirth
birthdate = "2019-01-20"
```

Esse código chama `DateOfBirth.from_quote("2019-01-20")` implicitamente em tempo de compilação.
Rodar código em tempo de compilação com essa abordagem (ou com outros métodos descritos abaixo) pode deixar o programa mais rápido, já que não é preciso fazer o parsing nem a validação de dados em tempo de execução.
Além disso, garante que dados inválidos (como um formato de data incorreto) sejam rejeitados em tempo de compilação, em vez de em tempo de execução, o que deixa sua aplicação mais robusta.
Por fim, o código fica mais limpo e legível.
Por exemplo, veja um dos testes deste exercício:

```roc
# multiple birthdates with one shared birthday
expect {
	shared_birthday(["1966-07-29", "1977-02-12", "2001-07-29", "1980-11-10"])
}
```

No entanto, quem lê esse código pode supor que a função `shared_birthday` recebe uma `List(Str)`, quando na verdade ela recebe uma `List(DateOfBirth)`.
Isso pode causar confusão e erros.
Por isso, você pode preferir o formato um pouco mais longo, mas mais explícito: `"2019-01-20".DateOfBirth`, que também chama `from_quote` em tempo de compilação.

Nos seus próprios programas, você pode preferir oferecer um construtor conveniente, como este:

```roc
DateOfBirth := { year : I64, month : U8, day : U8 }.{
    from_ymd : I64, U8, U8 -> Try(DateOfBirth, [InvalidMonth, InvalidDay])
    from_ymd = |year, month, day| ...
}
```

Você também pode chamar esse construtor em tempo de compilação, assim:

```roc
Ok(birthdate) = DateOfBirth.from_ymd(2019, 1, 20)
```

Observação: colocar essa definição no nível superior faz com que ela rode em tempo de compilação (já que a função é pura e as entradas são conhecidas em tempo de compilação).
Dentro de uma função, você pode usar o mesmo construtor em tempo de execução.
