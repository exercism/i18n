# Instruções

Neste exercício você vai gerar relatórios meteorológicos para uma emissora de notícias local.

## Gerar relatórios meteorológicos

Você vai começar com algumas funções esboçadas e com o seguinte enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

Você vai precisar formatar um relatório meteorológico como `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."`.
Você vai precisar implementar a função que retorna as condições meteorológicas corretas.

Por exemplo, o trecho abaixo mostra uma saída esperada para a função `get_weather_report` em um dia chuvoso.

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

E para um dia ensolarado:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
