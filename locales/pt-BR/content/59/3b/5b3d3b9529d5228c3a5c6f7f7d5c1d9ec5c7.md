# Dicas

## 1. Dobre cada uma das cartas

- Existe um método embutido ótimo para [transformações simples][map_method_docs] como esta.

## 2. Crie várias cópias de cada 3 encontrado no baralho

- Existe um método embutido perfeito para transformações personalizadas ou [acumulações][reduce_method_docs] (como somar um array, etc.)

## 3. Encontre duas cartas bem no meio do baralho

- Existe um método embutido para [fatiar e picar][slice_method_docs] arrays em segmentos menores.

## 4. As duas cartas de fora vão reaparecer no meio do baralho

- Existe um método embutido para [inserir ou remover][splice_method_docs] itens do meio de um array.
- O array também tem métodos embutidos para remover o primeiro e o último elemento, veja a [documentação de Array da MDN][array_docs].

## 5. Toda carta que não for 2 desaparece

- Existe um método embutido para [filtrar][filter_method_docs] ou excluir itens em um array.

## 6. Converta um baralho embaralhado em um baralho perfeitamente ordenado

- Existe um método embutido para [ordenar][sort_method_docs].

## 7. Reordene o baralho

- Existe um método embutido para [inverter][reverse_method_docs] um array.
