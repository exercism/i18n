# Anexo às instruções

## Observações

A intenção deste exercício é investigar alguns dos paralelos entre uma instância de um módulo WebAssembly e uma instância de uma classe em linguagens orientadas a objetos.

Na sua solução, uma instância WebAssembly deve ser considerada uma instância de uma conta bancária, e globais mutáveis do WebAssembly devem ser usados para modelar estados privados como em uma classe.

Nenhuma memória linear deve ser necessária!
