# Dicas

## Geral

- Lembre-se de consultar a tabela nas instruções.

## 1. Dada uma extensão, retorne o tipo de mídia esperado

- Use [pattern matching][pattern-matching] para retornar o tipo de mídia correto.
- Você pode usar [múltiplas cláusulas de função][mfc].

## 2. Dado um arquivo binário, retorne o tipo de mídia esperado

- Use a [forma especial de binário][special-forms] disponível para escrever um binário literal.
- Use [pattern matching][binary-matching] para comparar os primeiros bytes do binário do arquivo.

## 3. Dada uma extensão e um arquivo binário, verifique se o arquivo corresponde ao tipo esperado

- Reutilize as funções que você criou nas partes 1 e 2.
- Compare o valor de retorno de cada função e depois retorne o valor adequado.
  - Você pode usar o [macro condicional `if`][if] para condições binárias.
