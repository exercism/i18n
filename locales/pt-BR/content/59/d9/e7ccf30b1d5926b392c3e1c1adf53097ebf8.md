# Instruções

Neste exercício, você joga um jogo de RPG chamado "Wizard and Warriors", no qual pode jogar como um Wizard ou um Warrior.

Existem regras diferentes para Warriors e Wizards que determinam quantos pontos de dano eles causam.

Para um Warrior, as regras são:

- Causar 6 pontos de dano se o personagem que está sendo atacado não for vulnerável
- Causar 10 pontos de dano se o personagem que está sendo atacado for vulnerável

Para um Wizard, as regras são:

- Causar 12 pontos de dano se o Wizard preparar uma magia com antecedência
- Causar 3 pontos de dano se o Wizard não preparar uma magia com antecedência

Em geral, os personagens nunca são vulneráveis. No entanto, os Wizards _são_ vulneráveis se não tiverem preparado uma magia.

Você tem seis tarefas que trabalham com personagens Warrior e Wizard.

## 1. Descreva um personagem

Sobrescreva o método `ToString()` da classe `Character` para retornar uma descrição do personagem, formatada como `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. Deixe os personagens não vulneráveis por padrão

Garanta que o método `Character.Vulnerable()` sempre retorne `false`.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Permita que os Wizards preparem uma magia

Implemente o método `Wizard.PrepareSpell()` para permitir que um Wizard prepare uma magia com antecedência.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. Faça os Wizards ficarem vulneráveis quando não tiverem preparado uma magia

Garanta que o método `Vulnerable()` retorne `true` se o wizard não tiver preparado uma magia; caso contrário, retorne `false`.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Calcule os pontos de dano de um Wizard

Implemente o método `Wizard.DamagePoints()` para retornar os pontos de dano causados: 12 pontos de dano quando uma magia tiver sido preparada, 3 pontos de dano quando não.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Calcule os pontos de dano de um Warrior

Implemente o método `Warrior.DamagePoints()` para retornar os pontos de dano causados: 10 pontos de dano quando o alvo for vulnerável, 6 pontos de dano quando não.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
