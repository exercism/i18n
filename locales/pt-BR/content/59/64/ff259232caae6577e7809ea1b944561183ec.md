# Introdução

## Datas e horas

A biblioteca padrão do Elixir oferece 4 módulos diferentes para trabalhar com datas e horas, cada um com seu próprio struct.

- O módulo `Date`. Um struct `Date` pode ser criado com o sigilo `~D`.

  ```elixir
  ~D[2021-01-01]
  ```

- O módulo `Time`. Um struct `Time` pode ser criado com o sigilo `~T`.

  ```elixir
  ~T[12:00:00]
  ```

- O módulo `NaiveDateTime` para datas e horas sem fuso horário. Um struct `NaiveDateTime` pode ser criado com o sigilo `~N`.

  ```elixir
  ~N[2021-01-01 12:00:00]
  ```

- O módulo `DateTime` para datas e horas com fuso horário. Usar esse módulo para fusos horários diferentes de UTC exige uma dependência externa, um banco de dados de fusos horários.

### Comparações

Para comparar datas ou horas entre si, procure uma função `compare` ou `diff` no módulo correspondente. Operadores de comparação como `==`, `>` e `<` _parecem_ funcionar, mas não fazem uma comparação semântica correta para esses structs.
