# Dicas

## Geral

- Instâncias de struct são criadas declarando o nome da struct seguido dos valores dos campos entre chaves.
- `@T` pode ser usado para declarar snapshots de algum tipo `T`, por exemplo `let i: @u32 = @1;` declara uma variável `i` que é um snapshot do valor `1` do tipo `u32`;
- Você pode extrair um valor de um snapshot usando o operador `*` (desnap), por exemplo `let int = *an_int_snapshot;`.
- Você pode declarar um valor como mutável usando a palavra-chave `mut`, como em `let mut i = 1;`.

## 1. Criar um contador de votos

- Você precisa criar um ponteiro para uma struct `VoteCounter`, ou seja, um `@VoteCounter`.
- Você pode atribuir o parâmetro `value` diretamente ao criar uma instância da struct.

## 2. Obter o número de votos de um contador

- Você pode usar o operador `*` em um snapshot para fazer o desnap e obter o valor dele, por exemplo `*my_snapshot`

## 3. Incrementar os votos de um contador

- Em vez de modificar o snapshot `@VoteCounter`, você precisa retornar uma nova instância de `VoteCounter` com os votos incrementados.
- Você pode fazer o desnap do valor subjacente do contador de votos usando o operador `*`, ou chamar a função que você criou na tarefa anterior.

## 4. Criar os resultados da eleição

- Crie uma nova struct `ElectionResult` ou uma variável com os campos `name` e `vote_counter` preenchidos com os valores dos argumentos da função.
- Você pode criar um snapshot de `VoteCounter` usando o operador `@` antes do nome da variável ou da declaração da struct, ou chamar a função `new_vote_counter` que você fez em uma das tarefas anteriores.

## 5. Anunciar os resultados

- Embora você esteja recebendo um snapshot de um `ElectionResult`, você pode acessar os campos dele com a notação de ponto `.`, como se não fosse um snapshot!
- Monte a mensagem acessando os campos `name` e `vote_counter` da struct.
- Ao fazer o desnap de um snapshot aninhado, você precisa aplicar tantos operadores `*` quantos forem os snapshots a desfazer:

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. Recontagem de votos

- Por causa da [forma como os dicionários são implementados][dictionaries underneath], é necessário que eles sejam mutáveis tanto para modificá-los quanto para ler seus valores, o que significa que as alterações que você fizer no dicionário dentro da função serão visíveis fora dela.
- Para incrementar o valor de uma chave em um `let mut m: Felt252Dict<u32>`, você deve combinar as funções `get` e `insert`: `m.insert('mykey', m.get('mykey') + 1);`

[dictionaries underneath]: https://book.cairo-lang.org/ch03-02-dictionaries.html#dictionaries-underneath
