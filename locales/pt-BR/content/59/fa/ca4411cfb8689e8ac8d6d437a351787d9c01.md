# Laços

```sather
   loop
      ...
   end;
```

Sather tem exatamente uma instrução de laço. Não existe `while` nem `for`;
os dois são construídos a partir de `loop` e de algo que o encerra.

## Variáveis

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=` declara e pega o tipo do valor informado. Quando uma variável precisa
existir antes de haver um valor para ela, declare-a com um tipo:

```sather
   total : INT;
   total := 0;
```

Uma variável declarada sem valor começa como zero para `INT`, `false` para
`BOOL` e void para uma string ou um objeto.

## Encerrando um laço

| Escrito | Encerra o laço |
| --- | --- |
| `until!(q)` | quando `q` for verdadeira |
| `while!(q)` | quando `q` for falsa |
| `break!` | imediatamente |

Os três podem aparecer em qualquer lugar do corpo, e um laço pode usar mais de um.

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## O ponto de exclamação

`until!`, `while!` e `break!` terminam em `!` porque são **iteradores**:
coisas que só podem aparecer dentro de um laço, e que podem encerrá-lo.
Escrever um deles fora de um laço é um erro, e não um aviso. Exercícios
mais adiante usam os outros iteradores da biblioteca e, por fim, escrevem
novos.

## Laços infinitos

Um laço sem nada para encerrá-lo roda para sempre. Às vezes é isso mesmo que
se quer, mas com muito mais frequência significa que o valor sobre o qual a
condição pergunta nunca muda. Se um programa travar, a primeira coisa a
verificar é se algo dentro do laço o aproxima de parar.
