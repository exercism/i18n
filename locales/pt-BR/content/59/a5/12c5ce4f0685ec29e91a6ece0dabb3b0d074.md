# Introdução

Um [condicional switch][switch] compara um valor com vários padrões de correspondência possíveis.
Ele é uma alternativa mais limpa e legível do que encadear vários condicionais `if-else`.

Um condicional `switch` começa com a palavra-chave `switch`, seguida do valor a ser testado.
Cada correspondência possível é introduzida com a palavra-chave `case`.
A palavra-chave `default` define um caso padrão, executado quando nenhum dos casos explícitos corresponder.
Assim como as cadeias de `if-else`, um condicional `switch` executa apenas o bloco de código associado ao primeiro caso que corresponder.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considere a seguinte cadeia de `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Isso pode ser escrito de forma mais clara com um condicional `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
