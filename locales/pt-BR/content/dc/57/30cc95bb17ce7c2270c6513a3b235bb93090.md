# Introdução

## Tipos genéricos

A definição de uma coleção costuma incluir um espaço reservado entre sinais de maior e menor, geralmente `T` por convenção. Uma coleção assim é chamada de tipo genérico. Isso permite que quem usa a coleção especifique que tipo de item será armazenado nela. No exemplo de código abaixo, estamos instanciando uma lista de strings.

## Listas

As listas em C# são coleções de valores primitivos ou de instâncias de structs ou classes. Elas são implementadas na biblioteca de classes base como `List<T>`, em que `T` é o tipo do item da lista. A API expõe um conjunto rico de métodos para criar e manipular listas.

É possível adicionar e remover itens das listas. Elas crescem e diminuem conforme a necessidade.

```csharp
var listOfStrings = new List<string>();
```
