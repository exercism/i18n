# Dicas

## 1. Determine o número total de pássaros que você contou até agora

- Consulte a introdução do exercício para ver um exemplo de como usar um laço `for` para iterar sobre um slice.
- Use uma variável auxiliar para armazenar a contagem total e aumente essa variável conforme percorre o slice.
- Pense no valor inicial correto para essa variável auxiliar.

## 2. Calcule o número de pássaros visitantes em uma semana específica

- Esta tarefa é parecida com a primeira, você pode copiar seu código como ponto de partida.
- Pense em quais índices do slice você precisaria levar em conta para a semana número 1 e 2, respectivamente.
- Agora encontre uma forma geral de calcular o primeiro e o último índice que devem ser considerados.
- Com isso, você pode montar o laço `for` para iterar apenas sobre a seção relevante do slice.

## 3. Corrija um erro de contagem

- Novamente, você precisa montar um laço `for` para iterar sobre todo o slice de contagem de pássaros.
- Desta vez, você só precisa visitar um elemento a cada dois no slice.
- Altere o passo para que a variável contadora seja incrementada da forma adequada após cada iteração.
- No corpo do laço `for`, você pode usar o operador de incremento para alterar o valor de um elemento do slice no próprio lugar.
