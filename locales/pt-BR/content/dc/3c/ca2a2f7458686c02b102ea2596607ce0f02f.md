# Instalação

Diferente de muitas outras linguagens, o Pyret não exige que você instale a linguagem globalmente.
Em vez disso, os desenvolvedores do Pyret disponibilizaram o compilador como um [pacote npm][pyret-npm].
Você vai instalar o Pyret usando `npm` a cada exercício:
haverá mais detalhes na página de [Testes][tests].

Você precisa instalar o Node.js, um ambiente de execução de JavaScript.
Na página de [download do Node.js][download], certifique-se de selecionar `npm` como gerenciador de pacotes.

~~~~exercism/note
No momento, o pacote pyret-npm só é compatível com Linux e MacOS.
Quem usa Windows vai precisar instalar o pyret-npm usando o WSL ou uma máquina virtual.
~~~~
