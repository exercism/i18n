# Apêndice das instruções

## Testes

Os testes vão executar algumas operações ao mesmo tempo.
Procure garantir que as operações no Account o deixem em um estado consistente.
Por exemplo: várias goroutines podem estar depositando e sacando dinheiro simultaneamente, e dois saques acontecendo ao mesmo tempo não devem conseguir deixar o saldo negativo.

Ao trabalhar localmente, para testar se o seu código lida corretamente com concorrência e não introduz corridas de dados, rode os testes com a flag `-race` ativada.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
