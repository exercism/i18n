# Introdução

O JSON define um **array** como:

> Um array é uma coleção ordenada de valores.
> Um array começa com `[` colchete de abertura e termina com `]` colchete de fechamento.
> Os valores são separados por `,` vírgula.

Arrays podem conter zero ou mais valores de _qualquer tipo_ do JSON.
Os elementos de um array não precisam ser todos do mesmo tipo.

## Criando arrays

Use colchetes para reunir elementos em um array.

```jq
[1, 2, 3]
```

Os elementos de um _stream_ podem ser capturados em um array envolvendo-o em colchetes.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## Tamanho

A função `length` retorna o número de elementos de um array.

## Indexação e fatiamento

Os índices de um array começam em zero.

Para obter um elemento de um array, use uma expressão entre colchetes:
`.[2]` obtém o terceiro elemento.

Índices negativos contam de trás para frente, a partir do fim do array:
`.[-1]` obtém o último elemento; `.[-2]` é o penúltimo.

Uma **fatia** é uma subsequência do array.
`.[10:15]` retorna 5 elementos a partir do índice 10; o índice final _não é incluído_.

Existem também algumas funções para facilitar:

- `first` obtém o primeiro elemento.
- `last` obtém o último elemento.
- `nth(n)` obtém o elemento no índice `n`.

## Iteração

O `jq` oferece muitas funções para cobrir as necessidades de iteração mais comuns:

- `map(expr)` retorna um novo array em que a `expr` é aplicada a cada elemento, um de cada vez.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` é uma função que aplica a `expr` a um _único valor_;
  se o resultado da expressão for verdadeiro, o valor é retornado;
  se o resultado for falso, _nada_ é retornado. Nem `null`: literalmente nada.

  Para aplicar isso a um array, combine com o `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Como alternativa, aplique o `select` a um _stream_ e colete os resultados.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` e `all(condition)` retornam um valor Boolean que indica se algum dos elementos do array satisfaz a condição ou se todos eles a satisfazem.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
