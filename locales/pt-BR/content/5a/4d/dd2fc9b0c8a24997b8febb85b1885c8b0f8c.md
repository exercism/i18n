# Introdução

Um bloco é um conjunto de instruções e declarações agrupadas em uma única unidade sintática.
Os blocos costumam ser definidos entre chaves, mas nem sempre.
Blocos podem ser aninhados dentro de funções e dentro de outros blocos.

Uma função se comporta de certa forma como um bloco.
Um identificador de uma variável definida em uma função não pode ser visto fora da função, assim como um identificador de uma variável definida em um bloco não pode ser visto fora do bloco.
Duas variáveis em duas funções podem ter o mesmo nome, já que as duas funções não enxergam uma dentro da outra, assim como duas variáveis em dois blocos podem ter o mesmo nome, já que os dois blocos não enxergam um dentro do outro.
Mas funções e blocos não são idênticos.
Uma função não pode ser aninhada dentro de outra função, mas um bloco pode ser aninhado dentro de outro bloco.

No exemplo a seguir, `number` é definida dentro da função `main`.
`flag` é definida dentro do bloco `if`, que está aninhado dentro da função `main`.
Variáveis definidas dentro de um bloco só são válidas dentro desse bloco.
Por isso, ao tentar compilar o código, você recebe um erro de compilação.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

A mensagem de erro pode ser confusa, já que `flag` _é_ usada antes na função.
No entanto, `flag` é definida dentro de um bloco dentro da função.
O bloco interno consegue "ver" a variável `number` na função externa, mas a função externa não consegue "ver" a variável `flag` definida dentro do seu bloco interno.
Assim que a execução sai do bloco, a variável `flag` é destruída automaticamente e deixa de estar disponível para o programa.
A própria função `main` vê o identificador `flag` pela primeira vez na última instrução `printf`.
Se a última instrução `printf` for removida, o programa vai compilar e imprimir `1` quando for executado.
Isso acontece porque a variável `flag` é válida no bloco que contém a primeira instrução `printf`.

A partir do `C99`, instruções `if`, `for`, `while` e `do` de uma única linha também são consideradas blocos.
No exemplo a seguir, embora `i` não seja definida entre chaves, ela existe apenas no bloco definido pela instrução `for` e não é visível para a função `main` externa.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

Se a última instrução `printf` for removida, o programa vai compilar e imprimir `0 2 4 6 8 10 ` quando for executado.
Algumas linguagens, como Go e Rust, deixam explícito que condicionais e laços de uma única linha constituem um bloco.
Elas exigem que essas instruções de uma única linha continuem entre chaves.
