# Clone a Trilha de ABAP

## Pré-requisitos

1. Sistema ABAP versão 7.4 ou superior
2. abapGit v1.115.0 ou superior
3. Autorizações para implementar pacotes, programas e classes ABAP

## Instalando o abapGit

A trilha de ABAP com todos os exercícios é implementada como um repositório abapGit. Para clonar a trilha no seu próprio sistema, primeiro você precisa instalar o abapGit.

1. Acesse [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)
2. Baixe o arquivo `zabapgit_standalone.prog.abap`
3. Crie o programa `zabapgit_standalone` no seu próprio sistema
4. Envie o código-fonte de `zabapgit_standalone.prog.abap` para o programa `zabapgit_standalone`
5. Ative o programa

## Instalando a Trilha de ABAP do Exercism

### Repositório Online

Use este método se o seu sistema estiver conectado à Internet e tiver acesso ao GitHub.com (abordagem recomendada).

1. Execute o abapGit

![Repositório online do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. Na "Repository Overview", selecione "New Online"
3. Informe os seguintes valores
- URL: `https://github.com/exercism/abap`
- Package: `$exer`
- Display Name: `Exercism - ABAP Track`

Observação: se o nome do pacote for muito longo, como `$exercism`, você receberá um erro ao tentar importar o repositório. Mantenha o nome curto, como mencionado acima.

![Repositório online do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. Selecione "Create Online Repository". Você deve ver uma lista de objetos com o status "A":

![Repositório online do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. Selecione "Pull" para clonar todos os objetos no seu sistema. Quando terminar, você deve ver todos os objetos com o status em branco

![Repositório online do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### Repositório Offline

Use este método se o seu sistema *não* estiver conectado à Internet.

1. Acesse [https://github.com/exercism/abap](https://github.com/exercism/abap)
2. Baixe o arquivo ZIP do repositório

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. Execute o abapGit
4. Na "Repository Overview", selecione "New Offline"
5. Informe os seguintes valores
- Repository Name: `Exercism - ABAP Track`
- Package: `$exer`

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. Selecione "Create Offline Repository"

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. Selecione "Import ZIP" e escolha o arquivo ZIP baixado. Você deve ver uma lista de objetos com o status "A":

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. Selecione "Pull ZIP" para clonar todos os objetos no seu sistema. Quando terminar, você deve ver todos os objetos com o status em branco

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## Desinstalando a Trilha de ABAP do Exercism

Você pode remover todos os objetos do seu sistema da seguinte forma:

1. Execute o abapGit
2. Acesse o repositório `Execism - ABAP Track`
3. Selecione "Advanced > Uninstall"
4. Confirme a exclusão de todos os objetos e do repositório

## Solução de problemas

- Em caso de problemas de conexão, consulte a [Configuração de SSL](https://docs.abapgit.org/user-guide/setup/ssl-setup.html)
- Em caso do erro `Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit`, use um nome de pacote mais curto, como `$exer`.
- Alguns arquivos vão mostrar diferenças depois que você fizer o Pull para o seu sistema ABAP. Diferenças relacionadas a caracteres de fim de arquivo ou a marcas de ordem de bytes podem ser ignoradas.
