# Introdução

O Elixir oferece muitas funções para trabalhar com bits no _módulo Bitwise_.

- `band/2`: AND bit a bit
- `bsl/2`: deslocamento para a esquerda bit a bit
- `bsr/2`: deslocamento para a direita bit a bit
- `bxor/2`: XOR bit a bit
- `bor/2`: OR bit a bit
- `bnot/1`: NOT bit a bit

Veja um exemplo de como usar uma função bit a bit:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Todas as funções bit a bit funcionam apenas com números inteiros.

Se você estiver usando a versão 1.9 do Elixir ou anterior, vai precisar chamar `require Bitwise` no início da definição do módulo para poder usar o _módulo Bitwise_.
