## Geral

- Para definir uma string você pode usar aspas duplas `"`.
- Para concatenar strings você pode usar o operador `+`.
- Você pode usar `#{}` para interpolar uma string.

## 1. Dê as boas-vindas a um novo convidado da festa

- Uma string pode ser concatenada com outra string usando o operador `+`.

## 2. Dê as boas-vindas a um novo convidado que faz aniversário hoje

- Para converter um número em uma string você pode usar o método `to_s`.

## 3. Dê direções

- Para arredondar um número, você pode usar o método `round`.
- Para obter um caractere em uma string você pode usar o método `[]`, que recebe um número inteiro que é um índice.
