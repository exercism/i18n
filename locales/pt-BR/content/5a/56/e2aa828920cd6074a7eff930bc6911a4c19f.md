# Instruções

A Mary é uma grande fã da série de TV _Star Trek: The Next Generation_. Ela costuma jogar RPG de mesa, em que ela e seus amigos fingem ser a tripulação da _Starship Enterprise_. A personagem da Mary é o Capitão Picard, o que significa que ela precisa manter o diário do capitão. Ela adora a parte criativa do jogo, mas não gosta de gerar dados aleatórios na hora.

Ajude a Mary criando geradores aleatórios para os dados que aparecem com frequência no diário do capitão.

## 1. Gere um planeta aleatório

A _Starship Enterprise_ encontra muitos planetas em suas viagens. No universo de Star Trek, os planetas são divididos em categorias com base em suas propriedades. Por exemplo, a Terra é um planeta de classe M. Todas as classes planetárias possíveis são: D, H, J, K, L, M, N, R, T e Y.

Implemente a função `random_planet_class/0`. Ela deve retornar uma das classes planetárias aleatoriamente.

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. Gere um número de registro de nave espacial aleatório

A Enterprise (número de registro NCC-1701) não é a única nave espacial voando por aí! Quando ela se encontra com outra nave espacial, a Mary precisa anotar no diário o número de registro dessa nave.

Os números de registro começam com o prefixo "NCC-" e depois usam um número de 1000 a 9999 (inclusive).

Implemente a função `random_ship_registry_number/0`, que retorna um número de registro de nave espacial aleatório.

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. Gere uma data estelar aleatória

De que serve um diário se ele não inclui datas?

Uma data estelar é um número de ponto flutuante. As aventuras da _Starship Enterprise_ na primeira temporada de _The Next Generation_ acontecem entre as datas estelares 41000.0 e 42000.0. O "4" representa o século 24, e o "1" representa a primeira temporada.

Implemente a função `random_stardate/0`, que retorna um número de ponto flutuante entre 41000.0 (inclusive) e 42000.0 (exclusive).

A implementação deve usar uma função do Erlang.

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. Formate a data estelar

No diário do capitão, as datas estelares geralmente são arredondadas para uma casa decimal.

Implemente a função `format_stardate/1`, que recebe um número de ponto flutuante e retorna uma string com o número arredondado para uma casa decimal.

A implementação deve usar uma função do Erlang.

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
