# Introdução

## Booleans em R

Valores verdadeiros ou falsos são representados pelo tipo `logical`.
Ele contém apenas dois valores: `TRUE` e `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Operadores Boolean

Existem cinco operadores Boolean em R, mas apenas três são relevantes nesta etapa do syllabus.
Os outros dois serão importantes quando você trabalhar com vetores, que serão abordados em vários Conceitos mais adiante.

`&&` é o operador Boolean "e".
Ele é avaliado como `TRUE` se as expressões dos *dois* lados de `&&` forem `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` é o operador Boolean "ou".
Ele é avaliado como `TRUE` se uma expressão de *qualquer* um dos lados de `||` for `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` é o operador Boolean "não".
Ele troca os valores `TRUE` e `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Para expressões mais longas e mais complicadas, é melhor usar parênteses para deixar sua intenção clara.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
