# Char

`Char` é um tipo de dado em Crystal que representa um ponto de código [Unicode][unicode] de 32 bits.
O tamanho deles os torna eficientes em memória e lhes dá propriedades específicas que as Strings não têm.
Eles são criados usando aspas simples (`'`) e permitem que apenas um ponto de código Unicode seja colocado dentro.

```crystal
'a' # => 'a'
'a'.class # => Char
```

É bastante comum trabalhar com Chars quando se trabalha com Strings em Crystal, já que vários métodos da classe String retornam Chars ou recebem Chars como argumentos.
Por exemplo, o método [`String#[]`][index] retorna um Char, ou o método [`String#chars`][chars] retorna uma coleção de Chars.

## Incremento / Decremento

Como um char é um ponto Unicode de 32 bits, ele suporta incremento e decremento, o que faz com que, se você tiver `'a'`, possa obter `'b'` somando um.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Existe também um método chamado [`Char#succ`][succ], que retorna o próximo char na tabela Unicode, e [`Char#pred`][pred], que retorna o char anterior na tabela Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concatenação

Como Chars servem apenas para representar um ponto Unicode de 32 bits, dois chars não podem ser concatenados.
Portanto, Chars só podem ser concatenados com Strings.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Métodos de propriedades

Crystal tem alguns métodos para obter informações sobre um caractere, como se ele é um número ou uma letra, ou se está em maiúscula ou minúscula.
Aqui está uma lista de alguns desses métodos; para uma lista completa, consulte a [API do Char][char-api]:

| Método                           | Descrição                                            |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Retorna `true` se o Char é um número                 |
| [`Char#letter?`][letter]         | Retorna `true` se o Char é uma letra                 |
| [`Char#lowercase?`][lowercase]   | Retorna `true` se o Char está em minúscula           |
| [`Char#uppercase?`][uppercase]   | Retorna `true` se o Char está em maiúscula           |
| [`Char#ascii?`][ascii]           | Retorna `true` se o Char é um caractere ASCII        |
| [`Char#whitespace?`][whitespace] | Retorna `true` se o Char é um caractere de espaço em branco |

## Conversão

### Convertendo entre pontos de código e Chars

Como Chars são pontos Unicode de 32 bits, você pode converter entre Chars e pontos de código (Int).
Isso pode ser feito usando o método [`Char#ord`][ord], que retorna o ponto de código do Char, ou o método [`Int#chr`][chr], que retorna o Char do ponto de código.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Convertendo entre tipos

Como acontece com outros tipos de dados, chars têm alguns métodos para converter entre tipos.
O mais comum é o método `Char#to_s`, que converte o Char em uma String. No entanto, também existe o método `Char#to_i`, que converte o Char em um Int, e o método `Char#to_f`, que converte o Char em um Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Escapes

Assim como acontece com Strings, existem certos caracteres que não podem ser escritos diretamente e, para escrevê-los, você precisa escapá-los.
Você pode usar o caractere `\` para escrever uma sequência de escape seguida do caractere que você quer escapar.

Estes são os caracteres especiais em Crystal:

| Valor    | Descrição                     |
| -------- | ----------------------------- |
| `\a`     | Alerta                        |
| `\b`     | Backspace                     |
| `\e`     | Escape                        |
| `\f`     | Form feed                     |
| `\n`     | Line feed ou nova linha       |
| `\r`     | Retorno de carro              |
| `\t`     | Tabulação horizontal          |
| `\v`     | Tabulação vertical            |
| `\\`     | Barra invertida               |
| `\'`     | Aspas simples                 |
| `\"`     | Aspas duplas                  |
| `\377`   | Caractere ASCII octal         |
| `\xFF`   | Caractere ASCII hexadecimal   |
| `\uFFFF` | Caractere Unicode hexadecimal |
