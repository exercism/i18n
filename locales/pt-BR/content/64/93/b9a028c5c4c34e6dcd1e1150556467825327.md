# Arquivos legados

```exercism/note
Se você está vendo isto no Elixir ou no Elm depois de começar a usar a v3, provavelmente é porque essas trilhas mudaram a estrutura de arquivos delas.
Veja as seções no final deste documento para saber como lidar com essa mudança.
```

## O que são arquivos legados?

Se você usa o editor online do Exercism, às vezes pode encontrar um aviso sobre arquivos legados.
Há dois motivos pelos quais você pode ver isso.

### Arquivos enviados incorretamente pela CLI

Quando você usa a CLI, pode enviar os arquivos que quiser.
No entanto, o editor online só permite que você edite os arquivos que ele conhece.
Então, se você enviar um arquivo que o editor não conhece, ele não vai deixar você editá-lo e vai mostrar um aviso, caso você queira excluí-lo.

### Arquivos por causa de mudanças nos exercícios

Às vezes a estrutura dos exercícios muda.
Arquivos podem ser renomeados, ou estruturas inteiras de exercícios podem mudar.
Embora a gente tente evitar isso, às vezes é pragmaticamente a decisão certa.
Por exemplo, uma trilha pode mudar seu sistema de build, como o Elixir fez ao passar de arquivos `exs` para arquivos `ex`.
Ou a estrutura normal de diretórios dentro de uma linguagem pode mudar, como aconteceu com o Elm, quando moveram tudo para subdiretórios.

Nessas situações, não conseguimos mover os arquivos automaticamente para você, então há um pouco de trabalho manual a fazer.
No editor, você vai ver o(s) arquivo(s) de solução antigos (com um banner de legado) e o stub do novo arquivo de solução.
Copie seu trabalho do arquivo antigo para o novo e ajuste qualquer código que precise mudar.
Quando os testes passarem, você pode excluir seu arquivo de solução antigo e esquecer que tudo isso um dia aconteceu 🙂

## Excluir arquivos legados

Quando você exclui um arquivo legado, isso **não** afeta iterações anteriores.
Esse arquivo continuará existindo nessas iterações.
Excluir um arquivo simplesmente o remove da **próxima** iteração que você enviar pelo editor.

## Mudanças nas estruturas das trilhas

### Elixir

Em julho de 2019, o Elixir mudou a estrutura dos seus exercícios, passando de scripts Elixir (arquivos `*.exs`) para um [projeto Mix](https://elixir-lang.org/getting-started/mix-otp/introduction-to-mix.html) completo para cada exercício.
Para usar os recursos da v3, copie sua solução para o arquivo stub que fica em `lib/<exercise_stub>.ex`.
Você não precisa mover o arquivo de teste, a versão atualizada já estará no lugar certo.
