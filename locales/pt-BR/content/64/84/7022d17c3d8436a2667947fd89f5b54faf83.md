# Classes abstratas

Um espetáculo de circo é uma lista de números. Malabarismo, trapézio e acrobacia são coisas diferentes, com interiores diferentes, mas quem monta a ordem de apresentação só precisa de duas coisas de cada número: o nome e quanto tempo ele dura.

Uma **classe abstrata** descreve exatamente isso, e nada mais.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

O nome dela começa com `$`. Ela lista rotinas sem corpo: só assinaturas, cada uma terminando no ponto e vírgula. Não dá para criar nada a partir dela: não existe `create` nem `new`.

## Conformidade

Uma classe de verdade promete ser um `$ACT` ao nomear essa classe depois do `<`:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` se lê "é um". A classe precisa fornecer todas as rotinas que a classe abstrata lista, com os mesmos argumentos e o mesmo tipo de retorno. Deixar uma de fora é um erro de compilação, não uma surpresa em tempo de execução.

Uma classe pode acrescentar o que mais quiser. `TRAPEZE` pode ter uma altura que nenhum outro número tem; a classe abstrata nem sabe nem se importa.

## Usando o tipo

`$ACT` é um tipo, então qualquer coisa pode ser declarada com ele:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

Esse array contém objetos de três classes diferentes ao mesmo tempo, o que um `ARRAY{JUGGLING}` não poderia.

## Despacho

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` é um `$ACT`. Qual `minutes` roda é decidido quando a linha roda, pelo que o objeto realmente é: `JUGGLING::minutes` para o malabarismo, `TRAPEZE::minutes` para o trapézio. Essa escolha se chama **despacho**.

A rotina que faz a soma nunca pergunta que tipo de número ela tem. Acrescentar um quarto tipo de número significa escrever uma nova classe e não mexer em mais nada, e é por isso que vale a pena fazer desse jeito.
