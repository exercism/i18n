# Introdução

## Aleatoriedade

No Elixir, para escolher um elemento aleatório de uma estrutura de dados enumerável (por exemplo, uma lista ou um intervalo), usamos `Enum.random`. Essa função escolhe um único elemento, e todos os elementos têm a mesma probabilidade de serem escolhidos.

O Elixir não tem funções próprias para escolher um número de ponto flutuante aleatório. Para isso, precisamos usar o Erlang diretamente.

## Bibliotecas do Erlang

O código Elixir roda na máquina virtual BEAM. A BEAM faz parte do Erlang Run-Time System. Inspirado no Erlang e compartilhando seu ambiente de execução, o Elixir oferece uma ótima interoperabilidade com as bibliotecas do Erlang. Isso significa que quem desenvolve em Elixir pode usar bibliotecas do Erlang dentro do seu código Elixir. Na verdade, a comunidade Elixir desencoraja escrever bibliotecas Elixir para funcionalidades que as bibliotecas do Erlang já oferecem.

Por isso, certas funcionalidades, como operações matemáticas ou funções de temporização, só estão disponíveis no Elixir por meio do Erlang.

A biblioteca padrão do Erlang pode ser usada no nosso código Elixir sem nenhum passo extra.

As funções do Erlang podem ser chamadas do mesmo jeito que chamamos as funções do Elixir, com uma pequena diferença. Os nomes dos módulos do Erlang são átomos em `snake_case`. Por exemplo, para chamar a função `pi/0` do Erlang, do módulo `math`, você escreveria:

```elixir
:math.pi()
# => 3.141592653589793
```

As funções do Erlang mais usadas que não têm equivalente no Elixir são:

- `:timer.sleep/1`, que suspende um processo pela quantidade de milissegundos informada.
- `:rand.uniform/0`, que gera um número de ponto flutuante aleatório `x`, em que `0.0 <= x < 1.0`.
- `:io_lib.format/2`, que oferece formatação de string no estilo C (usando sequências de controle). Com essa função, poderíamos, por exemplo, imprimir um número inteiro em qualquer base entre 2 e 36 ou formatar um número de ponto flutuante com a precisão desejada. Repare que essa função, como muitas funções do Erlang, retorna uma charlist.
- O módulo `math`, que oferece funções matemáticas como `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` e outras.

Para conhecer a biblioteca padrão do Erlang, explore o [STDLIB Reference Manual][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
