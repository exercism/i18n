# Sobre

O Swift é uma linguagem de programação moderna e de código aberto que roda no macOS, no Linux e no Windows.

O Swift foi desenvolvido inicialmente pela Apple para interoperar com seus principais frameworks, Cocoa e CocoaTouch, ambos implementados majoritariamente em Objective-C.

O Swift sofre influência de um grande número de linguagens de programação já existentes e incorpora conceitos de uma ampla variedade de métodos de programação. De scripting à programação orientada a objetos e funcional.

A Apple se refere ao Swift como uma "linguagem de programação orientada a protocolos" e declarou o objetivo de, algum dia, tornar o Swift útil para tudo, de scripts a um sistema operacional.
