# Apêndice das instruções

## Implementação

Defina uma única função em Go, Cost, que calcula o custo de uma determinada lista de livros com base nos descontos definidos.

Use a seguinte assinatura para a função Cost:

```go
func Cost(books []int) int
```

Cost retorna o custo total (após os descontos) em centavos.
Por exemplo, para um único livro, o custo é 800 centavos, o que equivale a US$ 8,00.
Este exercício exige apenas cálculos com números inteiros.
