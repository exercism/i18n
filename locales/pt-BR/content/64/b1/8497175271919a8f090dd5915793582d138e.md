# Introdução

## Tempo

O conceito de _tempo_ é tratado no .NET usando a estrutura `DateTime`. Há rotinas para converter entre o horário local e UTC. A aritmética pode ser feita com o auxílio de `TimeSpan`.

## Fuso horário

A classe `TimeZoneInfo` fornece rotinas para lidar com as diferenças entre fusos horários. A classe `TimeZoneInfo` também contém métodos que facilitam lidar com o horário de verão.

A classe `CultureInfo` dá suporte a formatos de data e hora dependentes da localidade.

Para dar suporte à programação multiplataforma, a classe `RuntimeInformation` permite detectar em qual sistema operacional seu código está sendo executado, Linux, Windows ou OSX.
