# Anexo às instruções

## Formato de saída

Produza a sequência de proteínas como uma string terminada em null, com um caractere de nova linha depois de cada proteína.

Um exemplo de saída seria `"Methionine\nPhenylalanine\nSerine\n"`

Se a entrada for inválida, produza uma string vazia.

## Registradores

| Registrador | Uso           | Tipo     | Descrição                           |
| ----------- | ------------- | -------- | ----------------------------------- |
| `$a0`       | entrada       | endereço | string de entrada terminada em null |
| `$a1`       | entrada/saída | endereço | string de saída terminada em null   |
| `$t0-9`     | temporário    | qualquer | usado para armazenamento temporário |
