# Instruções

A ESA (Exercism Space Agency) está a todo vapor planejando uma nova missão para [Phobos][phobos], uma lua de Marte.
O objetivo da missão é pousar uma sonda na superfície de Phobos e enviar de volta dados sobre a superfície.
A ESA pediu sua ajuda para construir o computador de navegação da sonda.
O computador de navegação tem memória limitada, então precisamos manter o uso de memória o mais baixo possível.
Por isso, precisamos usar os tipos de dados adequados.

## 1. Constantes de navegação

O computador de navegação precisa saber a distância entre alguns objetos no espaço para fazer os cálculos corretos. A distância é medida em km.

Defina as seguintes constantes:

- `NEPTUNE_DISTANCE` com o valor `4_400_000_000`, que deve ser armazenado como um `Int64`
- `MARS_DISTANCE` com o valor `227_940_000`, que deve ser armazenado como um `Int32`
- `ATMOSPHERE_DISTANCE` com o valor `10_000`, que deve ser armazenado como um `Int16`

## 2. Análise correta de área

O computador de navegação precisa saber a área de alguns objetos no espaço para fazer os cálculos corretos.
Uma área **NÃO** pode ser negativa.
Os engenheiros planejaram o programa para gerar um erro de overflow quando a área fosse negativa.
No entanto, os engenheiros esqueceram de trocar o inteiro com sinal por um inteiro sem sinal.

Por isso, os engenheiros gostariam de um programa que converta um inteiro com sinal em um inteiro sem sinal.

Implemente o método `Navigation#correct_area_analysis`, que recebe uma `measurement` como argumento e retorna a área como um inteiro sem sinal de 32 bits.

~~~~exercism/note
A área dada sempre caberá como um inteiro sem sinal de 32 bits.
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. Calcular a velocidade

O computador de navegação precisa saber a velocidade da sonda.
A velocidade é medida em m/s.

Para calcular a velocidade, precisamos saber a distância percorrida e o tempo que levou para percorrer essa distância.
Depois, pegue a distância e divida pelo tempo.

A velocidade pode não ser exata e nunca será um número considerável.
Portanto, podemos usar um `Float32`.

Implemente o método `Navigation#calculate_velocity`, que recebe `distance` e `time` como argumentos e retorna a velocidade como um `Float` de 32 bits.

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
