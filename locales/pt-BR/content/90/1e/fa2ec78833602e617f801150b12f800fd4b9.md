# Introdução

Um `array` (vetor) em F# é uma coleção mutável de zero ou mais valores com comprimento fixo. Isso significa que, uma vez criado um array, seu tamanho não pode mudar, mas seus valores podem mudar. Os valores em um array precisam ter todos o mesmo tipo. Arrays podem ser definidos da seguinte forma:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Elementos podem ser atribuídos a um array ou recuperados dele usando um índice. Os arrays do F# começam no índice zero, o que significa que o índice do primeiro elemento é sempre zero:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Arrays são manipulados por funções e operadores definidos no módulo `Array`, ou manualmente usando correspondência de padrões com o padrão _array_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Você também pode _descartar_ um valor ao fazer correspondência de padrões; quando você _não_ se importa com um valor em um caso específico (ou seja, você não vai _usar_ um valor), pode usar um sublinhado (`'_'`) para indicar isso:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

O `'_'` sozinho deve vir sempre _por último_ na correspondência de padrões; todo valor que _não_ corresponder a nenhum dos outros casos será tratado por esse caso.
