# Instruções

Implemente um avaliador para um subconjunto bem simples de Forth.

[Forth][forth]
é uma linguagem de programação baseada em pilha.
Implemente um avaliador bem básico para um pequeno subconjunto de Forth.

Seu avaliador precisa dar suporte às seguintes palavras:

- `+`, `-`, `*`, `/` (aritmética de inteiros)
- `DUP`, `DROP`, `SWAP`, `OVER` (manipulação de pilha)

Você pode usar uma tupla como pilha, assim você evita fift e os opcodes de asm relacionados à pilha.

Para simplificar, o único tipo de dado com que você precisa trabalhar são inteiros com sinal de pelo menos 16 bits.

Use as seguintes regras para a sintaxe: um número é uma sequência de um ou mais dígitos (ASCII), e uma palavra é uma sequência de uma ou mais letras, dígitos, símbolos ou pontuação que não seja um número.
(O Forth provavelmente usa regras um pouco diferentes, mas isso é bem próximo.)
