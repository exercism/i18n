- O ponto central deste exercício é o uso de `unique_ptr` e `shared_ptr`.
  Que tipo de ponteiro inteligente deve ser usado para cada uma das variáveis `human`?
- Os `artifacts` não são compartilhados, mas os `powers` são necessários para acompanhar as pessoas influenciadas.
- o ponteiro `possession` deve ser único, e os ponteiros de poder devem ser compartilhados.
