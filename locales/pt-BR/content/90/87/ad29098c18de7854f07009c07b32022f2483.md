# Introdução

## Operadores ternários

O _operador ternário_ é uma alternativa leve e compacta para condicionais _if/else_ simples.
Normalmente usado em (mas não restrito a) instruções de retorno, precisa de apenas uma única linha para tomar a decisão, retornando o valor da esquerda se a expressão for `true` e o da direita se for `false`, assim:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Muitas expressões _if/else_ simples podem ser simplificadas usando _operadores ternários_.
