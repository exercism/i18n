# Sobre

Um [record][records] é uma coleção de campos (que podem ser de tipos diferentes) que andam juntos. Para [definir um record][define], usa-se a palavra-chave `type`. Os campos de um record são definidos entre os caracteres `{` e `}`, e cada campo tem um nome _e_ um tipo.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

Para [criar um record][create], especifique os nomes dos campos e atribua um valor a eles entre os caracteres `{` e `}`. Todos os campos de um record precisam receber um valor no momento da criação. Os campos podem ser especificados em qualquer ordem, não precisam seguir a ordem da definição do tipo do record. Para acessar os valores dos campos de uma instância de record, usa-se a notação de ponto.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

Ao definir ou criar um record, cada campo deve ficar em uma linha separada ou, quando estiver na mesma linha, ser separado por ponto e vírgula (`;`):

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

Se os nomes dos campos de um record forem únicos, as anotações de tipo são opcionais, pois o compilador conseguirá inferir o tipo automaticamente. Se a combinação de nomes de campos _não_ for única, você pode ajudar o compilador a escolher o record correto usando um tipo explícito na associação do record ou prefixando um ou mais campos com o tipo do record:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

Como os records são imutáveis, depois que um record é construído, os valores de seus campos nunca podem mudar. Se você quiser mudar os valores de um record, a palavra-chave `with` permite [criar uma cópia de um record existente, mas com novos valores para um ou mais campos][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Os records têm [_igualdade estrutural_][equality], o que significa que duas instâncias do mesmo record com valores idênticos são equivalentes:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

Além de poder usar a notação de ponto para acessar os campos de um record, os records também podem ser _desconstruídos_ em associações e em correspondência de padrões usando o [padrão de record][record-patterns]:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
