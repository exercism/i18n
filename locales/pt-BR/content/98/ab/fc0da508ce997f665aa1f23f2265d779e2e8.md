# Anexo às instruções

## Except

O valor de retorno da função `guess` é do tipo `Except String Result`.

Um [`Except ε α`][except] representa uma computação que pode resultar em um erro do tipo `ε` ou produzir um valor de sucesso do tipo `α`. 
Ele é uma mônada, o que permite compor essas computações.

## Programação reativa

Por razões práticas, este exercício não exige uma abordagem de programação reativa.
Em vez disso, considere implementar uma [máquina de estados finitos][finite-state-machine].
