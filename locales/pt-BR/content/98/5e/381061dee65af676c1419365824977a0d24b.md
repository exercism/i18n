# Instruções

Neste exercício, você vai trabalhar em um agendador de compromissos para um salão de beleza em Nova York que abriu em 15 de setembro de 2012.

## 1. Converter a data de um compromisso

Implemente o método `AppointmentScheduler.schedule()` para converter uma representação textual de uma data de compromisso no `LocalDateTime` correspondente:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. Verificar se um compromisso já passou

Implemente o método `AppointmentScheduler.hasPassed()`, que recebe uma data de compromisso e verifica se o compromisso ficou em algum momento no passado:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. Verificar se o compromisso é à tarde

Implemente o método `AppointmentScheduler.isAfternoonAppointment()`, que recebe uma data de compromisso e verifica se o compromisso é à tarde (>= 12:00 e < 18:00):

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Descrever a data e o horário do compromisso

Implemente o método `AppointmentScheduler.getDescription()`, que recebe uma data de compromisso e retorna uma descrição dessa data e desse horário:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. Retornar a data de aniversário

Implemente o método `AppointmentScheduler.getAnniversaryDate()`, que retorna a data de aniversário deste ano, que é 15 de setembro:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
