# Dicas

## 1. Determine se você vai precisar de uma carteira de motorista

- Use o [operador de igualdade][equality-operator] para verificar se a sua entrada é igual a uma string específica.
- Use um dos dois [operadores lógicos][logical-operators] que você aprendeu no conceito de Boolean para combinar os dois requisitos.
- Você **não** precisa de uma condicional para resolver esta tarefa. Você pode retornar diretamente a expressão booleana que montar.

## 2. Escolha entre dois veículos possíveis para comprar

- Use um [operador de comparação][comparison-operators] para determinar qual opção vem primeiro na ordem lexicográfica.
- Use um [template de string][string-templates] para criar a frase de recomendação.

## 3. Calcule uma estimativa para o preço de um veículo usado

- Use uma [condicional if-else if-else][if-statement] para determinar a porcentagem.
- Nas duas condições if, use [operadores de comparação][comparison-operators] para comparar a idade do carro com os valores limite.
- Para calcular o resultado, aplique a porcentagem ao preço original. Por exemplo, `30% of x` pode ser calculado dividindo `30` por `100` e multiplicando por `x`.
