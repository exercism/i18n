# Dicas

## 1. Defina a aprovação

- Tipos personalizados podem ser definidos com a sintaxe `pub type Name { Variant1 }`.

## 4. Defina a atividade

- Tipos personalizados que contêm dados podem ser definidos com a sintaxe `pub type Name { Variant1(SomeType) }`.

## 5. Avalie a atividade

- É possível fazer pattern matching nas variantes de um tipo personalizado usando expressões case.
- Se você quiser adicionar uma condição extra a um padrão, pode adicionar uma guarda ao padrão usando a palavra-chave `if`.
