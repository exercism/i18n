# Apêndice de instruções

## Palavras

Defina uma tupla `custom-set` e declare-a uma instância do mixin `set`
com `INSTANCE: custom-set set`.

- `<custom-set> ( -- set )`: constrói um conjunto vazio.
- `>custom-set ( seq -- set )`: monta um conjunto a partir de uma sequência,
  descartando duplicatas silenciosamente.

Depois, forneça métodos `M:` (de `sets`) para `members`, `in?`,
`adjoin` e `set-like` do `custom-set`. Com a declaração `INSTANCE:`
e esses quatro métodos no lugar, `null?`, `union`,
`intersect`, `diff`, `subset?`, `set=` e `intersects?` do
vocabulário `sets` funcionam todos no seu conjunto por meio das
implementações padrão do protocolo. Os testes chamam essas palavras
diretamente.

`adjoin ( elt set -- )` é mutante: adiciona `elt` a `set` no
próprio lugar, caso ainda não esteja presente.
