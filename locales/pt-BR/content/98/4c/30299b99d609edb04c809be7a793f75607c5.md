# Use `[item | list]` para adicionar itens ao início das listas

Usar `[item] ++ list` em vez de `[item | list]` é mais longo e revela menos a intenção: adicionar um item ao início de uma lista acaba parecendo uma concatenação de listas.
Use a sintaxe `[item | list]` para adicionar itens ao início de listas.
