# Introdução

As hashes são um tipo de dado em Perl que contém uma coleção não ordenada de chaves string associadas a valores escalares.

Uma variável hash normalmente é preenchida atribuindo uma lista a ela, por exemplo, `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

As listas normalmente são separadas por vírgulas, mas você vai ver com frequência o que se chama de "vírgula gorda" `=>` para separar chaves e valores em uma lista.
O comportamento dela é quase idêntico ao de uma vírgula, mas ela tem o benefício extra de interpretar o elemento do lado esquerdo como uma string.

As hashes também podem ser preenchidas atribuindo valores a chaves individuais, por exemplo, `$scores{Alice} = 10;`.

Os valores de uma hash podem ser acessados especificando as chaves por meio de um subscrito, por exemplo, `$scores{Bob} # 15`.

As chaves em uma hash são únicas.
Se uma chave for informada várias vezes, apenas o último valor informado será mantido.

## Funções

Entre as funções para trabalhar com hashes estão [keys][keys] e [values][values], que recuperam essas respectivas partes de uma hash como uma lista.
As listas retornadas pelas funções [keys][keys] e [values][values] podem ser úteis para funções de lista como [grep][grep], [map][map] e [sort][sort], além de laços [for][for].

Outras funções de hash incluem [exists][exists], para verificar se uma chave existe em uma hash (mesmo que o valor dela seja `undef`), e [delete][delete], para remover uma chave de uma hash.

## Variação de sigilo

Ao obter valores de uma hash, o sigilo usado determina o resultado.
É o subscrito `{}` no final do nome da variável que diz ao Perl que você está acessando uma hash com aquele nome.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Embora isso seja permitido, é recomendável que tipos diferentes de variáveis não compartilhem o mesmo nome, por questões de legibilidade.
