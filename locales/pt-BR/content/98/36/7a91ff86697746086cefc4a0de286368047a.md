# Dicas

Este exercício gira em torno de um tipo composto com palavra-chave e uniões de tipos.

## 1. Defina uniões de tipos

- Veja o exemplo na introdução em que um tipo foi nomeado.

## 2. Implemente o tipo composto Player

- Todos os campos devem ser *anotados com tipos*, e dois deles com uniões de tipos.
- Veja o exemplo de `Node` na introdução para um exemplo concreto de campos anotados com tipos.
- Todos os campos devem ter os valores padrão listados nas instruções.

## 3. Apresente-se

- Você pode usar um [operador ternário][control-flow] para uma solução de uma linha.
- A função `ismissing` é útil aqui.

## 4. Implemente os métodos increment

- Os argumentos dos métodos precisam ser anotados com os tipos corretos para `name` e `mana`.
- Veja mais exemplos de assinaturas de funções / anotação de argumentos na introdução.
- [Operadores ternários][control-flow] também podem ser usados aqui para soluções de uma linha.
- Pode ser útil estudar/revisar o conceito de `Multiple Dispatch`, se precisar.

## 5. Implemente a função title

- Use a sua função `increment`.
- Você pode usar um [operador ternário][control-flow] para uma solução de uma linha.

## 6. Implemente a função revive

- Use a sua função `increment`.
- Retorne um jogador modificado se ele estava morto, ou um jogador não modificado se ele estava vivo.


[control-flow]: https://docs.julialang.org/en/v1/manual/control-flow/#man-conditional-evaluation
