# Construtores de strings

Uma `STR` nunca muda. Então `+` não consegue adicionar a uma `STR`: é preciso criar uma string totalmente nova com o conteúdo das duas.

Isso funciona uma vez. Em um laço, não:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

A cada iteração, tudo o que foi construído até então é copiado para uma nova string, e a antiga é descartada. Dez linhas significam dez cópias, cada uma maior que a anterior. Cem linhas significam cem. O trabalho cresce com o *quadrado* do número de linhas, e um laço que parece inofensivo se torna a parte lenta do programa.

## FSTR

`FSTR` é uma string que *pode* ser alterada: um **construtor de strings**. Adicionar a um `FSTR` geralmente só escreve no espaço que ele já tem, então um laço sobre cem linhas faz mais ou menos o trabalho de cem linhas, em vez de cem cópias.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

Três coisas para reparar.

**`#FSTR` cria um `FSTR` vazio.** `#FSTR(100)` cria um com espaço para cem caracteres já reservado, o que vale a pena fazer quando o tamanho é conhecido.

**Você precisa atribuir o resultado de volta.** `script := script + ...`, nunca `script + ...` sozinho. Normalmente a resposta é o mesmo construtor que entrou, mas quando ele fica sem espaço, é um novo, maior. Descartar a resposta deixaria você escrevendo no antigo.

**`.str` no final.** Uma rotina que promete `: STR` precisa retornar uma `STR`, e `.str` cria uma a partir do construtor.

## O que pode ser adicionado

`+` em um `FSTR` aceita uma string, um caractere, um número inteiro ou um Boolean, então normalmente não é preciso converter antes:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## Novas linhas

`"\n"` dentro de uma string é uma nova linha: um caractere, escrito com dois.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
