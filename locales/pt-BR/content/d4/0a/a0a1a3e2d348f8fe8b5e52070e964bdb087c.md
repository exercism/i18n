# Testes

Para testar a sua solução, abra o terminal e rode

```
mason test
```

na pasta do exercício (a que contém o arquivo `Mason.toml` e as pastas `src/` e `test/`).

Se você achar que a mensagem de erro não é informativa o suficiente, experimente o comando abaixo para obter uma mensagem mais detalhada.

```
mason test --show
```
