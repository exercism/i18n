# Dicas

## Geral

- `<min-heap>`, `heap-push`, `heap-peek` e `heap-pop-all` ficam todos em [`heaps`][heaps]; `values` fica em [`assocs`][assocs].
- Um heap armazena cada item como um *valor* com uma *chave*; a chave é a prioridade. `heap-push` recebe-os como `( value key heap -- )`.

## 1. Abra a fila

- `<min-heap>` cria um min-heap vazio; a menor chave é atendida primeiro.

## 2. Adicione um cliente

- O nome do cliente é o valor e a prioridade é a chave, que é exatamente a ordem que o `heap-push` espera.
- `heap-push` consome a fila. Use `[ heap-push ] keep` para adicionar o cliente e ainda retornar a fila.

## 3. Quem vem a seguir?

- `heap-peek` retorna `value key` do item da frente sem removê-lo. Você só quer o nome, então use `drop` na chave.

## 4. Atenda todo mundo

- `heap-pop-all` esvazia o heap em uma lista de associação de pares `{ key value }`, já em ordem de prioridade.
- `values` mantém apenas os valores: os nomes.
