# Instruções

Bem-vindo ao mundo de *ChronoRealms*, uma terra mágica onde poderosos Timekeepers controlam o fluxo do tempo.

Neste reino, os Timekeepers administram os "TimeShards", unidades especiais que podem ser somadas, subtraídas, comparadas e até verificadas quanto à igualdade.

Sua tarefa é ajudar os Timekeepers implementando operadores personalizados para manipular esses TimeShards.

Os Timekeepers precisam que você crie uma struct personalizada `TimeShard` que dê suporte às seguintes operações:

1. **Somando e subtraindo TimeShards**: os Timekeepers precisam conseguir somar e subtrair TimeShards para controlar a linha do tempo.
2. **Comparando TimeShards**: às vezes, é preciso comparar TimeShards para ver qual deles é maior, ou se são iguais.
3. **Verificando a igualdade**: os Timekeepers precisam verificar se dois TimeShards têm o mesmo valor.

Sua missão é implementar as seguintes traits para a struct `TimeShard`:

1. **Adição (`Add`)**: permitir somar duas instâncias de `TimeShard`.
2. **Subtração (`Sub`)**: permitir subtrair um `TimeShard` de outro.
3. **Igualdade (`PartialEq`)**: permitir que os Timekeepers verifiquem se duas instâncias de `TimeShard` são iguais.
4. **Comparação (`PartialOrd`)**: permitir comparar duas instâncias de `TimeShard` para ver qual é maior ou menor.

Um `TimeShard` será representado por uma struct que guarda um valor inteiro (`i32`).

Implemente as traits necessárias para facilitar o trabalho dos Timekeepers.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
