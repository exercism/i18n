# Instruções

Você está construindo uma pequena calculadora de Notação Polonesa Reversa (RPN).
O estado da calculadora é uma *pilha de valores*, representada como um
array de Factor, e uma *operação* é uma quotation que recebe essa
pilha e retorna uma nova.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. Implemente a adição

Defina `add-op` para remover os dois valores do topo da pilha, empilhar a
soma deles e retornar a nova pilha.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. Implemente a multiplicação

Defina `multiply-op` da mesma forma, mas para multiplicação.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. Aplique uma única operação

Defina `apply-op` para tirar da pilha de dados uma pilha e uma operação
(uma quotation) e retornar a nova pilha da calculadora.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. Avalie um programa

Defina `evaluate` para receber uma pilha inicial e um array de operações,
aplicar cada operação em sequência e retornar a pilha final.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. Avalie por nome

Agora o programa é uma lista de *nomes de operadores* (strings), e a
calculadora procura cada nome em um assoc que mapeia nomes para
operações.

Defina `evaluate-named` para receber uma pilha inicial, um assoc de
operações nomeadas e um array de nomes, e retornar a pilha final.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. Divida com segurança

Uma calculadora de verdade não pode produzir lixo silenciosamente quando
pedem para dividir por zero. A classe de erro `zero-divisor-error` já está
definida para você. Implemente `divide-op` de forma análoga a `add-op` e
`multiply-op`, exceto que ela `throw`s um novo
`zero-divisor-error` quando o divisor no topo da pilha é `0`.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
