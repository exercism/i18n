# Anexo às instruções

## Registradores

| Registrador | Uso       | Tipo    | Finalidade                        |
| ----------- | --------- | ------- | --------------------------------- |
| `$a0`       | entrada   | inteiro | valor fornecido                   |
| `$v0`       | saída     | inteiro | diferença de quadrados            |
| `$t0-9`     | temporário | qualquer | usado para armazenamento temporário |
