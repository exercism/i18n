# Sobre

Em Common Lisp, funções globais nomeadas são definidas com `defun`.

Essa forma recebe como primeiro argumento uma lista de parâmetros da função que está sendo definida (a lista de parâmetros também é chamada de "lambda list").
Depois disso, ela pode, opcionalmente, receber uma string para servir de documentação dessa função.
Por fim, vêm zero ou mais expressões que formam o corpo da função.

Para chamar uma função, usamos o nome dela como primeiro elemento de uma expressão, seguido dos parâmetros dessa função.

```lisp
(defun add-one (x) (1+ x))

(add-one 3) ;; => 4
```

Funções também podem receber [parâmetros opcionais][concept-optional-parameters], [parâmetros keyword][concept-keyword-parameters] e [parâmetros rest][concept-rest-parameters].
Vamos falar sobre eles em conceitos posteriores.

O nome da função está no escopo do corpo da função, o que permite fazer recursão.

```lisp
(defun countdown (x)
  (if (zerop x) (print 'BLAST-OFF)
    (progn (print x) (countdown (1- x)))))

(countdown 3) ;; will print "3","2", "1" and "BLAST-OFF" to
              ;; standard output before evalutaing to 'BLAST-OFF
```
