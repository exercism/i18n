# Apêndice das instruções

## Dicas

Uma [lista duplamente encadeada](https://en.wikipedia.org/wiki/Doubly_linked_list) é uma estrutura de dados mutável. Como F# é uma linguagem funcional em primeiro lugar, a imutabilidade costuma ser preferida, mas a linguagem tem recursos que permitem usar mutação quando ela é necessária.

- A palavra-chave `mutable` pode ser colocada antes de associações `let` e de campos de [record](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records), o que permite atribuir novos valores a eles.

- As propriedades de uma [classe](https://fsharpforfunandprofit.com/posts/classes) podem se tornar mutáveis ao especificar um setter de propriedade com a palavra-chave `set`.

Associações mutáveis precisam ser reatribuídas com `<-`

```fsharp
let mutable x = "initial value"
x <- "new value"
```
