# Anexo às instruções

## Implementação

As funções deste exercício aceitam um array com um ou mais números, cada um representando uma "pontuação de jogo".

As pontuações do jogador podem ser lidas em

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

`personal_top_three()` deve gravar as melhores pontuações do jogador em

| `output`   |
|---|
| `output[0]` |
| ... |
