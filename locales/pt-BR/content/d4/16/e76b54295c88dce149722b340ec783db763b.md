## 1. Identifique linhas de log corrompidas

- A função [`regexp.from_string`][from-string] pode ser usada para compilar uma expressão regular.
- A função [`regexp.check`][check] pode ser usada para testar se uma expressão regular corresponde a uma string.
- Não se esqueça de escapar os caracteres que têm significado especial em expressões regulares.

## 2. Divida a linha de log

- A função [`regexp.split`][split] pode ser usada para dividir uma string usando uma expressão regular.
- Não se esqueça de escapar os caracteres que têm significado especial em expressões regulares.

## 3. Marque as linhas com nomes de usuário

- A função [`regexp.scan`][scan] pode ser usada para capturar partes de uma string usando uma expressão regular.
- Não se esqueça de escapar os caracteres que têm significado especial em expressões regulares.
