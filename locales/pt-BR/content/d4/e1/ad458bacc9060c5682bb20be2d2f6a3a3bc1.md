# Introdução

Em Cairo, a sobrecarga de operadores permite definir comportamentos personalizados para operadores padrão como `+`, `-`, `==`, `<`, etc., ao trabalhar com os seus próprios tipos.

Isso é feito implementando traits específicas para os seus tipos personalizados.

## Traits principais para operadores

### `Add` e `Sub`

As traits `Add` e `Sub` permitem definir como a adição (`+`) e a subtração (`-`) funcionam com o seu tipo:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

A trait `PartialEq` permite a comparação de igualdade (`==` e `!=`) entre instâncias do seu tipo.

Muitas vezes, isso pode ser derivado automaticamente com `#[derive(PartialEq)]`.

### `PartialOrd`

A trait `PartialOrd` permite operações de comparação (`<`, `>`, `<=`, `>=`) entre instâncias do seu tipo.

Ela exige que você implemente pelo menos o método `lt` (menor que):

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
