# Dicas

## 1. Insira uma carta no topo da pilha

- A [função `ArrayTrait::append`][append] pode ser usada para adicionar ao final de um array.

## 2. Remova a carta do topo da pilha

- É sempre possível converter um array em um span e depois usar a [função `SpanTrait::pop_back`][pop-back] para remover do final de um array.

## 3. Insira uma carta na base da pilha

- Não há como adicionar um item ao início do array, mas uma forma de contornar isso é criar um novo array com um item e adicionar o antigo como span com [`ArrayTrait::append_span`][append-span].

## 4. Remova uma carta da base da pilha

- A [função `ArrayTrait::pop_front`][pop-front] pode ser usada para remover do início de um array.

## 5. Verifique o tamanho da pilha

- A [função `ArrayTrait::len`][len] pode ser usada para obter o comprimento de um array.
