## Geral

- [The Cairo Book: Smart Pointers][smart-pointers]

## 1. Construa a ChronoChain a partir de um array de valores `u32`

- Podemos iterar sobre o array e construir uma cadeia de trás para frente, começando pelo `End` e ligando cada valor com a variante `Link`.
- Considere usar `span.pop_back()` para iterar sobre o array em ordem inversa: isso ajuda a criar a cadeia do fim para o começo.

## 2. Some os valores da ChronoChain

- Use correspondência de padrões para lidar com as duas variantes de `ChronoChain`.
- Quando você chega ao `End`, a soma é 0. Quando chega ao `Link`, você soma o valor e soma recursivamente o resto da cadeia.
- Essa abordagem é parecida com uma função recursiva que percorre a estrutura até chegar ao caso base (`End`).
