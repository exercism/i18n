# Introdução

## Operadores de comparação

Os operadores de comparação em Julia são parecidos com os de muitas outras linguagens, mas com algumas opções extras para quem gosta de matemática.

Para igualdade, os operadores são `==` (igual) e `!=` ou `≠` (diferente).

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

Além disso, temos os vários operadores de maior/menor que.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Como costuma acontecer com Julia, um editor adequado facilita usar o símbolo matemático. Digite `\ne`, `\le` ou `\ge` e depois `TAB` para obter `≠`, `≤` ou `≥`.

O exemplo anterior usa apenas números, mas veremos em outras partes do currículo que vários tipos adicionais têm uma noção de ordenação e podem ser testados quanto a maior/menor que.

Os operadores de comparação podem ser encadeados, o que permite uma sintaxe clara e concisa:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

O exemplo anterior é sinônimo de `1 ≤ n && n ≤ 5`.

## Ramificação com `if`

Esta é a forma completa de uma condicional `if`:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

Não é preciso usar parênteses `()` nem chaves `{}`, e a indentação serve "só" para melhorar a legibilidade _(mas legibilidade é muito importante!)_.

Tanto `elseif` quanto `else` são opcionais, e pode haver vários blocos `elseif`.
Porém, o `end` é obrigatório.

É possível aninhar condicionais `if`, mas talvez você queira ajudar a legibilidade com o uso cuidadoso de parênteses, indentação e comentários.

A forma mais curta de uma condicional seria algo assim:

```julia
if n < 0
    n = 0
end
```

Como lembrete: só é possível usar como condicionais expressões que avaliam para `true` ou `false`.
Julia evita de propósito qualquer conceito de "truthiness", então valores zero, strings vazias e arrays vazios _não_ são equivalentes a `false`.

## Operador ternário

Uma situação simples e comum é escolher um entre dois valores com base em uma condicional.

Julia, como muitas linguagens, tem um operador ternário para deixar isso mais conciso.

A sintaxe é `conditional ? value_if_true : value_if_false`.

Então o exemplo anterior poderia ser reescrito:

```julia
n = n < 0 ? 0 : n
```

Os parênteses não são exigidos pelo compilador, mas podem melhorar a legibilidade.
