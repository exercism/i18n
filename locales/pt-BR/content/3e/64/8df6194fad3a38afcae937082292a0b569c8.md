# Complemento das instruções

## Dicas

Este exercício é sobre [refatoração de código](https://en.wikipedia.org/wiki/Refactoring), então fornecemos para você uma solução que já passa nos testes.

O desafio é reescrevê-la até você se orgulhar dela e aprender algo no processo.

Se você não sabe por onde começar, aqui vão algumas ideias:

- Tente reduzir a repetição ao mínimo.
- Tente deixar o código legível.

Sem pressa.

Mude uma coisa de cada vez e verifique se a sua solução ainda passa nos testes.

Divirta-se!
