# Instruções

Elyse, aspirante a maga, continua seu treinamento. Ela vai receber vários montes de cartas com os quais precisa realizar seus truques.
Para facilitar um pouco as coisas, ela usa apenas as cartas de 1 a 10.

Neste exercício, use métodos nativos para analisar o conteúdo de um array.

## 1. Encontre a posição de uma carta

Elyse quer saber a posição (índice) de uma carta no monte.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. Determine se uma carta está presente

Elyse quer determinar se uma carta está presente no monte, ou seja, se o monte contém um `number` específico.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. Determine se cada carta é par

Elyse quer saber se cada carta é par, ou seja, se cada número no monte é um `number` par.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. Verifique se o monte contém uma carta de valor ímpar

Elyse quer saber se há um número ímpar no monte.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. Obtenha a primeira carta ímpar do monte

Elyse quer saber o valor da primeira carta que é ímpar.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. Determine a posição da primeira carta par

Elyse quer saber a posição da primeira carta que é par.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
