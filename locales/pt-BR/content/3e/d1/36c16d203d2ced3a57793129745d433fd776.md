# Instruções

Neste exercício, você vai trabalhar em um sistema de agendamento para um salão de beleza.

Você tem três tarefas, e todas elas envolvem datas de agendamento.

## 1. Verifique se um agendamento já passou

Implemente a sub-rotina `appointment_has_passed`, que recebe uma string de data e verifica se o agendamento aconteceu em algum momento no passado:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

As strings de data serão passadas no formato de data e hora ISO 8601: `YYYY-mm-ddTHH:MM:SS`

Você vai precisar implementar a sub-rotina privada `_parse_datetime`.
Alguns módulos são sugeridos para você:

- [Time::Piece][time-piece] é um módulo do núcleo do Perl.
- [DateTime::Tiny][datetime-tiny] está disponível no CPAN.

## 2. Verifique se o agendamento é à tarde

Implemente a função `is_afternoon_appointment`, que recebe uma string de data e verifica se o agendamento é à tarde (>= 12:00 e < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. Descreva a hora e a data do agendamento

Implemente a função `describe_appointment`, que recebe uma string de data e retorna uma descrição dessa data e hora:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

Repare que a hora está no intervalo de 0 a 12 e não tem zero à esquerda nem espaço.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
