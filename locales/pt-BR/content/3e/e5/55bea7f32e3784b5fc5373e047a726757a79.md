# Instruções

Você tem várias pizzarias que vendem pizza em fatias na sua cidade e quer escrever um webapp que permita comparar duas configurações diferentes de pizza para saber quem vai te dar a fatia maior.

## 1. Escreva uma função que calcule o tamanho das fatias e retorne nil para entradas inválidas.

Implemente a função `sliceSize(diameter: Double?, slices: Int?) -> Double?`, que, dado o diâmetro de uma pizza e o número de fatias por pizza, retorna a área de uma fatia.
Para diâmetros negativos e para um número de fatias menor que 1, retorne `nil`, já que não existe pizza com diâmetro negativo e não há como cortar uma pizza em menos de 1 fatia.
Se qualquer um dos parâmetros for `nil`, retorne `nil` também

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Processe a entrada da sua aplicação web para determinar a fatia maior.

Sua aplicação web vai passar quatro strings para a sua função `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`.
A primeira e a segunda strings são o diâmetro e o número de fatias da primeira pizza, respectivamente, e a terceira e a quarta são o diâmetro e o número de fatias da segunda pizza, respectivamente.

Implemente `biggestSlice` de forma que ele tente converter o diâmetro e o número de fatias de cada pizza em um `Double` e um `Int`, respectivamente.
Se esses dois valores puderem ser obtidos a partir das strings, use sua primeira função para tentar calcular a área; caso contrário, a área dessa fatia é `nil`.
Depois de obter as áreas das duas fatias, compare as duas áreas usando as seguintes regras:

1. Se a área da fatia A for um `Double` e a da fatia B for `nil`, retorne "Slice A is bigger". Se o inverso for verdadeiro, retorne "Slice B is bigger".
2. Se as duas áreas forem `Double`s, retorne "Slice A is bigger" ou "Slice B is bigger", dependendo de qual fatia tem a área maior.
3. Se as duas áreas forem `nil`, ou se as duas forem `Double`s e forem iguais, retorne "Neither slice is bigger".

~~~~exercism/note
Mesmo que a entrada resulte em uma área de fatia igual a 0, a fatia ainda é considerada válida e deve ser vista como maior que uma fatia com área `nil`.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
