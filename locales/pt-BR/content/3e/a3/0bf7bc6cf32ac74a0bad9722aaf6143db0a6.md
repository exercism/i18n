# Introdução a arrays

O Bash tem dois tipos de parâmetros: valores "escalares" e arrays.
Um valor escalar pode ser uma string ou um número; ele representa uma única "coisa".

Na maior parte do tempo, valores escalares bastam para guardar seus dados.
Mas às vezes você precisa armazenar uma lista de valores escalares.
Nesse caso, você vai usar um _array_.

Existem dois tipos de arrays:

* Arrays indexados numericamente mapeiam uma chave inteira para um valor string.
  (Em outras linguagens, isso pode ser chamado de "lista" ou "sequência".)
* Arrays associativos mapeiam uma chave string para um valor string.
  (Em outras linguagens, isso pode ser chamado de "mapa" ou "dicionário".)

As primeiras seções deste documento tratam dos arrays indexados numericamente (daqui em diante, simplesmente "arrays").
Os detalhes sobre arrays associativos aparecem no final.

~~~~exercism/caution
Os arrays do Bash _só_ podem armazenar valores escalares.
Não há como criar um array bidimensional (array de arrays).
~~~~

## Declarando e inicializando uma variável de array

Você pode inicializar um array atribuindo a uma variável uma lista de elementos entre parênteses (possivelmente vazia).

```bash
myarray=("one" "two" "three")
```

Como em toda atribuição de variável, não pode haver espaços em volta do sinal de igual.

Repare que não há vírgulas separando os elementos; é uma lista de strings separadas por espaços em branco.

Na verdade, a quantidade de espaços em branco dentro dos parênteses é completamente livre.
Quebras de linha são permitidas; use quantas quiser para melhorar a legibilidade.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

Atribuir uma lista de strings a uma variável de array dessa forma armazena a primeira string no índice zero, a próxima string no índice um, a seguinte no índice dois, e assim por diante.

É possível inicializar um "array esparso" especificando os índices de que você precisa.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
Para reforçar: os índices de array começam em zero.
Este trecho produz "true":

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

Você pode usar o comando `declare` (ou `local` dentro de uma função) para especificar que uma variável vai conter um array.

```bash
declare -a myarray
```

É mais idiomático simplesmente atribuir uma lista entre parênteses (talvez vazia) para inicializar a variável.

## Acessando elementos de um array

Como você viu na nota acima, a sintaxe para acessar um elemento de array é `${myarray[$index]}`.
O índice é informado entre colchetes.
As chaves são obrigatórias.

~~~~exercism/note
Para arrays indexados numericamente, o índice é uma expressão aritmética.
O manual do Bash [afirma][arithmetic]:

> Dentro de uma expressão aritmética, variáveis do shell também podem ser referenciadas pelo nome sem usar a sintaxe de expansão de parâmetro.

Isso significa que o `$` não é necessário para a expansão "simples" de variáveis.
Você pode acessar elementos assim, o que é um pouco mais fácil de ler:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

Se o índice informado não existir no array, o resultado da expansão é uma string vazia.

## Atribuindo a um array

Para atribuir a uma entrada específica do array, use esta sintaxe:

```bash
myarray[10]="hello"
```

Para _acrescentar_ a um array, use o operador de atribuição por concatenação `+=` e use parênteses:

```bash
myarray+=("new element 1" "new element 2")
```

## Iterando sobre um array

Normalmente você vai precisar iterar sobre os _valores_ de um array.
Use um laço `for` (que você viu no conceito de [Laços][looping]):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

Repare na sintaxe especial para expandir o array: `"${myarray[@]}"`
Essa forma de expansão de parâmetro substitui os valores do array como palavras separadas.
É mais ou menos equivalente a:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

A forma `"${myarray[@]}"` funciona com arrays esparsos, expandindo apenas os valores definidos.

Essa expansão especial, em que o índice é um ampersand (`@`), só é especial dentro de aspas duplas.

#### Outras expansões de parâmetro especiais

Aqui estão mais alguns detalhes de sintaxe especial de que precisamos para iterar sobre um array.
Eles estão descritos no manual em [Expansão de Parâmetro do Shell][man-expn].

Para descobrir o _comprimento_ de um array, use `${#myarray[@]}`, com um `#` antes do nome.
O "comprimento" de um array é o número de elementos que ele contém.

Para extrair a lista de _índices_ de um array, use `"${!myarray[@]}"`, com um `!` antes do nome e a expansão entre aspas duplas.
Para arrays indexados numericamente, os índices são expandidos em ordem numérica.

### Iterando sobre os índices de um array

Às vezes você precisa do índice além do valor.
Existem algumas formas de fazer isso.

1. Quando você sabe que os índices formam uma sequência ininterrupta, pode usar um laço `for` _aritmético_.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   Repare na sintaxe `${#myarray[@]}`, com o caractere `#` na frente do nome do array.
   Como os arrays usam indexação baseada em zero, o último índice do array é uma unidade menor que o comprimento do array.

2. Quando o array é esparso, você pode usar esta forma:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   Repare na sintaxe `${!myarray[@]}`, com o caractere `!` na frente do nome do array.

## Inspecionando um array

Se você quiser ver o conteúdo de um array, use o comando `declare` com a opção `-p`:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

Isso imprime o conteúdo com as aspas canônicas do shell.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## Arrays associativos

Para reforçar, arrays associativos usam strings como índices, não números.
Tudo o que foi escrito acima vale para arrays associativos, mas com pequenas diferenças.
Em geral, usamos o termo "chave" em vez de "índice": arrays associativos mapeiam chaves para valores.

### Declarando um array associativo

Diferente dos arrays, os arrays associativos **precisam** ser declarados.
Use a opção `-A` de `declare` (ou `local` dentro de uma função):

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### Inicializando um array associativo

Os pares chave-valor são especificados dentro da lista entre parênteses:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

Isso produz:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
Lembre-se de que arrays associativos **não têm ordem definida**.
~~~~

A declaração e a inicialização podem acontecer em uma única linha.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

Em versões recentes do Bash, a inicialização pode usar uma lista `(key value key value ...)`.

```bash
declare -A mymap=(first foo second bar third baz)
```

### Acessando valores

A mesma sintaxe de antes é usada para acessar elementos: `${mymap[$key]}`.

As chaves de arrays associativos não são avaliadas em um contexto aritmético.
É preciso usar a sintaxe usual de expansão de parâmetro.

### Atribuindo a um array associativo

A atribuição usa a mesma sintaxe de antes:

```bash
mymap[$key]="$value"
```

### Iterando

Você pode usar um laço `for value in "${mymap[@]}"` para iterar.
Porém, normalmente você também quer a chave junto com o valor.

Use a sintaxe `"${!mymap[@]}"` que vimos acima.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

Isso produz

```
second -> bar
first -> foo
third -> baz
```

Para reforçar, as chaves não têm ordem alguma.
