# Introdução

Uma `string` em C# é um objeto que representa texto imutável, na forma de uma sequência de caracteres Unicode (letras, dígitos, pontuação etc.). Usamos aspas duplas para definir uma instância de `string`:

```csharp
string fruit = "Apple";
```

Manipulamos uma string chamando os métodos dela. Depois que uma string é construída, seu valor nunca pode mudar. Qualquer método que pareça modificar uma string, na verdade, retorna uma nova string.

Podemos concatenar (somar) várias strings. A forma mais simples de fazer isso é usar o operador `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para qualquer formatação de string mais complexa do que uma concatenação simples, prefira a interpolação de strings. Para usar interpolação em uma string, coloque o símbolo de dólar (`$`) na frente dela. Depois, você pode usar chaves (`{}`) para acessar quaisquer variáveis dentro da sua string.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
