# Testes

Se você baixou um exercício com a ferramenta CLI, você deve ver um arquivo Uiua com o nome do exercício e um arquivo `tests.ua`.
Esse arquivo contém todos os casos de teste, que correspondem aos que o executor de testes roda quando você envia sua solução.
Fique à vontade para adicionar casos de teste extras e fazer experimentos.
Mas modificar os testes não afeta o processo do executor de testes online.

## Testes locais

Para rodar os testes de um exercício, abra um terminal no diretório do exercício e rode o comando `uiua test tests.ua`.

Por exemplo, a saída de um exercício `hello-world` sem edições pode ser assim:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

A linha `Error` mostra a saída real do seu código.
O número da linha indica a localização do resultado esperado em `tests.ua`.
Uma solução correta produz:

```bash
$ uiua test tests.ua
Test passed
```
