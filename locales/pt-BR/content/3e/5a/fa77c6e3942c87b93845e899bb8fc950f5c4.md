# Instruções

Converta um número hexadecimal, representado como uma string (por exemplo, "10af8c"), para o seu equivalente decimal partindo dos princípios básicos (ou seja, não, você não pode usar bibliotecas internas ou externas para fazer a conversão).

Na web, usamos hexadecimal para representar cores, por exemplo, verde: 008000, turquesa: 008080, azul-marinho: 000080).

O programa deve tratar strings hexadecimais inválidas.
