# Introdução

Uma interface pode ser entendida como a assinatura de uma classe, porque descreve os campos públicos de uma classe. Uma classe _implementa_ uma `interface` com a palavra-chave `implments`.

A sintaxe dela é muito parecida com a de uma classe, exceto que os métodos aparecem como assinaturas sem corpo:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

Os campos implementados a partir de uma interface **devem** sempre usar o mesmo modificador de visibilidade. Por exemplo, se a variável `a` é `public` em uma interface, sua implementação também precisa ser `public`.
