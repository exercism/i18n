# Anexo das instruções

## Registradores

| Registrador | Uso | Tipo | Descrição |
| -------- | --------- | ------- | ---------------------------------------------------------------------------------- |
| `$a0`    | entrada     | inteiro | lado a                                                                             |
| `$a1`    | entrada     | inteiro | lado b                                                                             |
| `$a2`    | entrada     | inteiro | lado c                                                                             |
| `$v0`    | saída    | inteiro | tipo de triângulo (`0` = escaleno, `1` = isósceles, `2` = equilátero, `3` = inválido) |
| `$t0-9`  | temporário | qualquer     | usado para armazenamento temporário                                                         |
