# Placar de Recordes

## História

Este exercício usa o cenário de manter um placar de recordes de um fliperama para ensinar o conceito de [coleções][collection] de chave-valor ([mapas][types-map], [hashes][types-hash_map], arrays associativos, [dicionários][dict], etc.). O nome de um jogador é a chave, e a pontuação é o valor.

## Tarefas

Em seguida, o estudante é guiado por algumas operações:

- Criar uma nova coleção vazia.
- Adicionar um jogador à coleção.
- Colocar na coleção valores associados a jogadores existentes.
- Atualizar os valores na coleção.
- Retornar uma lista ordenada por chave a partir da coleção.
- Retornar uma lista ordenada por valor a partir da coleção.
