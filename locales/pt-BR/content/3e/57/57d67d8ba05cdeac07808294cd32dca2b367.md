# Introdução

Uma **palavra** é o nome que o Factor dá para uma função. Partindo da pilha de dados de `basics`, este conceito é sobre definir suas próprias palavras: fazer aritmética, dar nome a valores fixos e compor palavras a partir de outras palavras.

Uma definição começa com `:`, informa um efeito de pilha, depois vem o corpo e então `;`. O compilador verifica se o corpo corresponde ao efeito declarado:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

As palavras de aritmética de inteiros `+`, `-`, `*` desempilham dois números cada uma e empilham o resultado. Elas ficam no vocabulário `math`, então um arquivo que as usa precisa de `math` na sua linha `USING:`. O topo da pilha é o operando da direita:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:` nomeia um valor fixo. Uma constante também é uma palavra: chamá-la empilha o valor:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

O corpo de uma palavra pode chamar qualquer palavra que já esteja no escopo, inclusive as que você definiu antes no mesmo arquivo:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

Um `?` no final das saídas é a convenção para indicar um Boolean, e tanto palavras quanto constantes usam `lowercase-kebab-case`.
