# Dicas

## Geral

- A documentação do pacote `Random` está [aqui][random-module]

## 1. Comece pelo fim

- Use a função [`Random.constant`][random-constant]

## 2. Não se pega mosca com vinagre

- Use a função [`Random.uniform`][random-uniform] para gerar os tesouros
- Use a função [`Random.map`][random-map] para envolver o tesouro

## 3. Ramificações

- Use a função [`Random.int`][random-int] para gerar um valor entre 2 e 4
- Você pode acessar esse valor para criar um `Branch` com a função [`Random.andThen`][random-andThen]
- Use a função [`Random.list`][random-list] para gerar as ramificações
- Use a função [`Random.map`][random-map] para envolver as ramificações

## 4. Labirintos incríveis

- Use a função [`Random.weighted`][random-weighted] para gerar uma distribuição desigual de resultados
- Use a função [`Random.lazy`][random-lazy] para usar um gerador de forma recursiva
- Leia mais sobre como definir estruturas de dados recursivas [aqui][bad-recursion]
- Se você acabar definindo um gerador aninhado `Generator (Generator Maze)`, pode usar [`Random.andThen`][random-andThen] junto com a função `identity` para achatá-lo

## 5. Precisamos ir mais fundo

- Use a função [`Random.uniform`][random-uniform] para gerar os becos sem saída ou salas na profundidade `0`
- Se você acabar definindo um gerador aninhado `Generator (Generator Maze)`, pode usar [`Random.andThen`][random-andThen] junto com a função `identity` para achatá-lo
- Use a função [`Random.lazy`][random-lazy] para usar um gerador de forma recursiva
- Leia mais sobre como definir estruturas de dados recursivas [aqui][bad-recursion]
