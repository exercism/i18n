# Introdução

## Números inteiros

Números inteiros são números que pertencem ao conjunto `{..., -2, -1, 0, 1, 2, ...}`.
Os valores máximo e mínimo de um número inteiro são determinados pelo sistema em que o PHP roda.
Normalmente, na maioria dos sistemas modernos, o número inteiro é um valor de 64 bits, o que significa que ele pode representar de `-9_223_372_036_854_775_808` a `9_223_372_036_854_775_807`, inclusive.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Você pode escrever valores literais inteiros em bases diferentes de 10 usando um prefixo de base:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

## Números de ponto flutuante

Os números de ponto flutuante são usados no PHP para representar um subconjunto dos números reais.
Eles começam com um ou mais dígitos separados por um separador decimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### Armadilhas comuns

Nem todos os números e operações aritméticas podem ser realizados com números de ponto flutuante.
Usar números de ponto flutuante para representar dólares e centavos pode levar a erros de arredondamento.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## Operadores aritméticos

O PHP oferece vários operadores para realizar operações aritméticas. O PHP segue a ordem de operações matemática padrão para seus operadores aritméticos. Os operadores que o PHP oferece são:

* Identidade (+)
* Negação (-)
* Adição (+)
* Subtração (-)
* Multiplicação (*)
* Divisão (/)
* Módulo (%)
* Exponenciação (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
