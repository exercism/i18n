# Operador ternário

O operador ternário oferece uma sintaxe alternativa para fazer uma comparação `if..else..` e retornar um valor.

## Sintaxe

O PHP oferece uma condicional em que uma ação pode ser definida com base na "veracidade" de uma condição.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Como alternativa, o operador ternário pode representar a mesma operação:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

A sintaxe da comparação é curta, representada por `(condition) ? (evaluate if true) : (evaluate if false);`.

## Vantagens

A vantagem mais óbvia de usar um operador ternário é a brevidade: escrever a expressão condicional é mais curto do que escrever uma condicional `if..else..`. Mas há várias outras vantagens também:

- É uma expressão que pode ser usada dentro de outra expressão.
- Facilita a avaliação preguiçosa de cada bloco.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  Neste exemplo, se a resposta exata não for necessária, o cálculo custoso não é executado.

## Desvantagens

Os operadores ternários têm várias desvantagens, o que torna importante pensar bem antes de usá-los:

- Um operador ternário pode ser mais difícil de ler, porque depende de interpretar símbolos em vez do uso de palavras-chave.
- Um operador ternário pode causar bugs sem querer, porque em PHP o operador ternário é associativo à esquerda, ao contrário da maioria das linguagens contemporâneas (por exemplo, C, Java e JavaScript).
- A expressão avaliada nos blocos verdadeiro e falso precisa retornar um valor.

## Ainda mais curto

A sintaxe do ternário pode ser encurtada ainda mais para `(condition) ?: (evaluate if falsey)`.
Um uso possível é fornecer um valor alternativo em uma expressão:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Às vezes, isso também é conhecido como _Elvis operator_ (`?:`).
