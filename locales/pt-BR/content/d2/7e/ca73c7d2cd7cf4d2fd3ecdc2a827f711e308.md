# Calculadora de Cozinha

## História

A história facilita a exploração de [tuplas][type-tuple] em uma linguagem.

A premissa básica é que, muitas vezes, ingredientes de cozinha são medidos de formas obscuras e exigem conversões diferentes dependendo das quantidades ou das ferramentas disponíveis à mão. As tuplas são usadas para fornecer [duck typing][concept-duck-typing] ao componente numérico da medição.

Assim, isto explora a conversão básica de valores usando números de ponto flutuante.

### Conversões

| De                 | Para    |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 xícara           | 240mL   |
| 1 onça fluida (EUA) | 29.57mL |
| 1 colher de chá    | 5 mL    |
| 1 colher de sopa   | 15 mL   |

## Tarefas

Isto deve orientar os estudantes sobre como usar:

- Tuplas
- Tuplas como informação agrupada
- Obter valores de uma tupla usando o índice do elemento
- Obter valores de uma tupla usando pattern matching
- Criar novas tuplas
