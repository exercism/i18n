# Sobre

O Gleam tem funções de primeira classe, ou seja, as funções são valores comuns que podem ser atribuídos a variáveis, passados como argumentos e retornados de outras funções.

Uma função nomeada definida em um módulo pode ser referenciada pelo seu nome.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

O Gleam também tem funções anônimas, que são definidas dentro de outras funções.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

O tipo de uma função é escrito com uma sintaxe parecida com a das funções anônimas. O tipo de uma função que recebe um `Int` e um `Float` e retorna um `Int` é escrito assim:

```gleam
fn(Int, Float) -> Int
```

Funções anônimas podem referenciar variáveis que estavam no escopo quando foram definidas, o que as torna _closures_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

A sintaxe de _function capture_ oferece um atalho conveniente para criar funções anônimas que passam um único argumento para uma função. Estas duas expressões são equivalentes:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
