# Introdução

## Módulos

O código Gleam é organizado em módulos, e cada arquivo é um módulo Gleam.

Até agora escrevemos funções com a sintaxe `pub fn`, que define uma função disponível publicamente para outros módulos. Funções definidas com `fn` são privadas do módulo em que são definidas e não podem ser usadas por outros módulos.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Os módulos Gleam têm nomes, e o nome é baseado no caminho do arquivo dentro do diretório `src` ou `test`.

Por exemplo, um módulo definido em `src\geometry\rectangle.gleam` (no Windows) ou em `src/geometry/rectangle.gleam` (em sistemas operacionais do tipo UNIX) se chamaria `geometry/rectangle`.

## Importando funções de outros módulos

O acesso a funções definidas em outros módulos é feito por meio de importações.
Todas as funções desse módulo que foram expostas por ele ficam acessíveis ao importar esse módulo.
Mas a forma de acessá-las varia conforme a maneira como o módulo é importado.

Importações qualificadas são o padrão, e acessar uma função desse módulo (por exemplo, a função `map` do módulo `gleam/list`) é feito prefixando o nome do módulo (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Por padrão, o nome usado para se referir ao módulo é a última parte do nome do módulo, neste caso `int`, mas isso pode ser alterado usando a palavra-chave `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Importações não qualificadas permitem acesso direto às funções expostas desse módulo, sem prefixo.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Prefere-se importações qualificadas, pois deixam mais claro para quem lê de onde vem uma função, além de evitarem conflitos de nomes.


## Biblioteca padrão

Gleam tem uma biblioteca padrão rica e bem documentada. A documentação está disponível online em [hexdocs.pm/gleam_stdlib][docs]. Salve este link em algum lugar: você vai usá-lo muito!

A maioria dos tipos de dados embutidos tem um módulo correspondente que oferece funções para trabalhar com aquele tipo de dado, por exemplo, existe o módulo `gleam/int` para ints, o módulo `gleam/string` para strings, o módulo `gleam/list` para listas e assim por diante.

[docs]: https://hexdocs.pm/gleam_stdlib/
