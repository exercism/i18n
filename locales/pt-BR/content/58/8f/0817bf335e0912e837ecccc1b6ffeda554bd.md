# Sobre

A [D](https://dlang.org) é uma linguagem de programação de sistemas, com
sintaxe parecida com a de C e tipagem estática. Ela combina eficiência, controle e poder de
modelagem com segurança e produtividade para quem programa. A linguagem foi desenvolvida
originalmente por [Walter Bright](https://en.wikipedia.org/wiki/Walter_Bright) e [Andrei
Alexandrescu](https://en.wikipedia.org/wiki/Andrei_Alexandrescu) a partir da versão 2 da D.

A D é o resultado de décadas de experiência implementando compiladores para as mais diversas
linguagens e tem um grande número de [recursos únicos](http://dlang.org/overview.html):

- construções de alto nível para um grande poder de modelagem
- linguagem compilada de alto desempenho
- tipagem estática
- evolução do C++ (sem os erros)
- interface direta com as APIs do sistema operacional e com o hardware
- tempos de compilação extremamente rápidos
- permite programação segura em relação à memória (SafeD)
- código fácil de manter e de entender.
- curva de aprendizado curta (sintaxe parecida com a de C, semelhante a Java e outras linguagens)
- compatível com a interface binária de aplicações do C
- multiparadigma (imperativo, estruturado, orientado a objetos, genérico, pureza de programação funcional e até assembly)
- prevenção de erros embutida (contratos, testes de unidade)

A [D Language Foundation](https://dlang.org/foundation.html) é a organização dedicada a desenvolver e
promover a linguagem D.
