# Introdução

Um *conjunto disjunto* (uma estrutura union-find) mantém uma coleção de valores particionada em grupos que não se sobrepõem, e responde rapidamente a uma pergunta: esses dois valores estão no mesmo grupo? Ele fica no vocabulário [`disjoint-sets`][disjoint-sets].

## Montando um conjunto disjunto

`<disjoint-set>` cria uma estrutura vazia. Os valores, ou *átomos*, são adicionados com `add-atom`, um de cada vez, ou com `add-atoms`, a partir de uma sequência. Cada átomo começa em um grupo só para si.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

O conjunto disjunto é *mutável*: `add-atom`, `add-atoms` e `equate` o alteram no lugar em vez de retornar um novo. `keep` é útil quando você quer o conjunto disjunto de volta na pilha depois que uma dessas palavras o consumiu.

## Unindo grupos

`equate` une os dois grupos que contêm seus átomos. A união é transitiva: use `equate` entre dois átomos, depois entre um deles e um terceiro, e os três acabam no mesmo grupo.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Representantes

Todo grupo tem um membro canônico, o seu *representante*. `representative` o retorna, e dois átomos pertencem ao mesmo grupo exatamente quando seus representantes são iguais.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

Qual átomo um grupo escolhe como representante é um detalhe interno. Nunca dependa de um átomo específico ser escolhido, apenas de que dois átomos no mesmo grupo estejam de acordo.
