# Sobre

[Guardas][guards] são usadas como complemento do [casamento de padrões][exercism-pattern-matching], que vamos abordar em um conceito mais adiante.
As guardas permitem que uma função tenha implementações diferentes dependendo do valor da entrada.
Elas também permitem verificações mais complexas.

Uma instrução de guarda é definida por uma barra vertical `|` seguida de uma expressão booleana, e termina com um sinal de igual `=` e o corpo da função.
Pode haver várias instruções de guarda para uma única função.
As instruções de guarda são avaliadas de cima para baixo, e a primeira que resultar em `True` será executada.
Uma instrução de guarda pode incluir uma instrução `otherwise`, que funciona como um caso geral para qualquer valor que não corresponda às instruções de guarda anteriores.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

Também podemos definir nossa própria função e usá-la dentro da instrução de guarda.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
