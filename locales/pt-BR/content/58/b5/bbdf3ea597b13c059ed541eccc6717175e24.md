# Dicas

## Geral

- Use o tipo de [lista (encadeada)][list] que já vem embutido.

## 1. Defina uma função para retornar uma lista de linguagens vazia

- A função precisa retornar `[]`.

## 2. Defina uma função para adicionar uma linguagem à lista

- Um elemento pode ser adicionado ao início de uma lista usando `|`.

## 3. Defina uma função para remover uma linguagem da lista

- O Elixir [fornece uma função][tl] para retornar uma lista sem o primeiro item.

## 4. Defina uma função para retornar o primeiro item da lista

- O Elixir [fornece uma função][hd] para obter o primeiro item de uma lista.

## 5. Defina uma função para retornar quantas linguagens há na lista

- O Elixir [fornece uma função][length] para contar o comprimento de uma lista.

## 6. Defina uma função para determinar se a lista inclui uma linguagem funcional

- Sua função deve retornar um valor Boolean indicando se `"Elixir"` é um membro da lista. O Elixir [fornece uma função][in] para testar se um item pertence à lista.

[length]: https://hexdocs.pm/elixir/Kernel.html#length/1
[in]: https://hexdocs.pm/elixir/Kernel.html#in/2
