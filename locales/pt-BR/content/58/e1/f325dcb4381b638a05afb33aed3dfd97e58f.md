# Dicas

## 1. Verifique se um valor é um Boolean

- Você pode usar `typeof` para descobrir o tipo de um valor.
- `typeof` retorna uma string.

## 2. Verifique se um valor é um número

- Você pode usar `typeof` para descobrir o tipo de um valor.
- `typeof` retorna uma string.
- Você precisa verificar se o valor é `Infinity` ou `NaN`.
- `NaN` nunca é igual a si mesmo, mas existe uma [função nativa][isNaN] para verificar se um valor é `NaN`.

## 3. Verifique se um valor é um objeto

- Você pode usar `typeof` para descobrir o tipo de um valor.
- `typeof` retorna uma string.
- Você vai precisar verificar se o valor é `null`.

## 4. Verifique se uma string é numérica

- Você pode usar `typeof` para descobrir o tipo de um valor.
- `typeof` retorna uma string.
- Você pode iterar sobre uma string para verificar se todos os caracteres são dígitos.

## 5. Verifique se um objeto é eletrônico

- Você pode usar `instanceof` para verificar se um objeto é uma instância de uma classe ou de uma de suas subclasses.

## 6. Verifique se um valor é um array não vazio

- Você pode usar `typeof` para descobrir o tipo de um valor.
- `typeof` retorna uma string.
- Você pode verificar o tamanho de um array para descobrir quantos elementos ele contém.

## 7. Verifique se um valor é um array vazio

- Você pode usar `typeof` para descobrir o tipo de um valor.
- `typeof` retorna uma string.
- Você pode verificar o tamanho de um array para descobrir quantos elementos ele contém.

## 8. Verifique se um objeto tem uma propriedade ou método `type`

- Você pode usar o operador `in` para verificar se um objeto tem uma propriedade ou método.

## 9. Lance um erro se um objeto não tiver a propriedade ou o método `id`

- Você pode usar o operador `in` para verificar se um objeto tem uma propriedade ou método.
- Se a propriedade ou o método `id` não existir, sua função deve lançar um `Error`.

## 10. Verifique se um objeto tem uma propriedade `id`

- Para verificar se um objeto tem uma propriedade (e não um método), você pode usar a função `Object.hasOwn()`.

## 11. Verifique se um objeto tem uma propriedade `type` definida

- Para verificar se um objeto tem uma propriedade (e não um método), você pode usar a função `Object.hasOwn()`.
- Você vai precisar acessar a propriedade `type` e verificar se ela está definida.
