<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

Talvez você queira renderizar esses widgets em seus documentos Markdown, por exemplo no fim de um documento, para sugerir leituras extras ou bons exercícios para aprender algo.

**Nota:** Você também pode usar links normais no meio do texto, que receberão os tooltips. Veja a [documentação sobre Links Internos](/docs/building/markdown/internal-linking) para mais detalhes.

## Uso

Você pode usar widgets em qualquer lugar onde dá para usar Markdown, como na documentação, nas abordagens e nas discussões entre estudantes e mentores.

Eles são renderizados usando o seguinte formato:

```md
[<type>:<id>]()
```

As partes `<type>` e `<id>` são variáveis e dependem do widget que está sendo usado.

A referência do link, ou seja, o conteúdo dos `()`, é ignorada pelo site. Você pode apontá-los para o que quiser, por questões de manutenção.

## Widget de exercício

Formato do link: `[exercise:<track-slug>/<exercise-slug>]()`

### Exemplo

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## Widget de conceito

Formato do link: `[concept:<track-slug>/<concept-slug>]()`

### Exemplo

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## Widget de abordagem

Formato do link: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### Exemplo

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## Widget de artigo

Formato do link: `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### Exemplo

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
