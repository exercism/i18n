# Instruções

Ozan está montando a mixtape perfeita: primeiro ele decide *quais* músicas entram, depois define a *ordem* em que elas tocam. Você vai construir os auxiliares de combinatória por trás das escolhas dele no vocabulário `mixtape-maker`.

## 1. Contar combinações

Defina `count-combinations` para retornar de quantas maneiras `k` itens podem ser escolhidos entre `n`, ignorando a ordem.

```factor
5 2 count-combinations .
! => 10
```

## 2. Contar permutações

Defina `count-permutations` para retornar de quantas maneiras `k` itens podem ser escolhidos entre `n` quando a ordem importa.

```factor
5 2 count-permutations .
! => 20
```

## 3. Listar combinações

Defina `list-combinations` para retornar cada combinação de `k` elementos de uma sequência.

```factor
{ 1 2 3 } 2 list-combinations .
! => { { 1 2 } { 1 3 } { 2 3 } }
```

## 4. Listar permutações

Defina `list-permutations` para retornar todas as ordenações de uma sequência.

```factor
{ 1 2 } list-permutations .
! => { { 1 2 } { 2 1 } }
```

## 5. Combinações que somam um alvo

Defina `combinations-summing-to` para retornar apenas as combinações de `k` elementos de uma sequência cujos elementos somam `target`.

```factor
{ 1 2 3 4 } 2 5 combinations-summing-to .
! => { { 1 4 } { 2 3 } }
```
