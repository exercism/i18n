# parâmetro obrigatório inesperado

O parâmetro \`${'parameter.name'}\` é chamado com e sem um valor nos testes, mas _não está marcado como opcional_, e por isso os testes não vão passar. Um parâmetro do TypeScript pode ser marcado explicitamente como opcional usando um `?` no final:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

Ou, como alternativa, atribuindo um valor padrão:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
