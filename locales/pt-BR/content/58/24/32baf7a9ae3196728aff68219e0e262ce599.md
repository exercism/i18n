# String

O tipo de dados `String` é uma série linear de caracteres codificados em UTF-8. É útil para armazenar dados textuais.

## Criando uma String

Uma String pode ser criada usando as funções associadas `String::new()` ou `String::from()`. Muitos tipos têm um método `to_string` para produzir uma string, por exemplo, a partir de um número.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### O macro `format!`

Produzir uma string grande a partir de uma seleção de tipos de dados menores é uma operação comum. Por isso, o Rust também tem um atalho que omite os detalhes de chamar `to_string`: o macro `format!`. Por exemplo, podemos simplificar a construção da string composta acima assim:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## String slices

As strings têm uma relação próxima com os string slices. Um string slice é uma referência imutável a uma região de memória de tamanho conhecido, que contém uma série linear de caracteres codificados em UTF-8. Qualquer string pode ser convertida em um string slice por coerção, emprestando-a com o operador de desreferência (`&`). Para converter um string slice em uma string, tanto o método `to_string()` quanto `String::from` são adequados.

No código Rust, uma string literal fica entre aspas duplas. Essas strings literais são sempre string slices, porque se referem a uma região imutável de memória dentro do executável do programa.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## Modificando uma String

Para concatenar um único caractere a uma string, use o método `push`. Para concatenar um string slice a uma string, use o método `push_str` ou o operador `+`.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## Acessando caracteres em uma String

Como as strings do Rust são codificadas em UTF-8, nem todos os caracteres individuais têm o mesmo tamanho. Por isso, o tipo de dados `String` não oferece um operador de indexação (`[]`). Para acessar todos os caracteres ou um caractere específico de uma string, pode-se usar o método `chars()`. Esse método itera sobre cada caractere da string, em sequência.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```
