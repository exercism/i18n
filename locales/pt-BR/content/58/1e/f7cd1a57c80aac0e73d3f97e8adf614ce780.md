# Introdução

Em geral, você não quer reinventar a roda quando o assunto é programação. Para muitos algoritmos padrão, é bem possível que alguém já tenha feito o trabalho por você.

## Inclusões

Para incluir o conteúdo de outros arquivos, o C++ usa a diretiva `include`. Essas inclusões devem ficar no topo do arquivo. Durante a compilação, a linha com a diretiva é substituída pelo conteúdo do arquivo correspondente. Depois das inclusões, os namespaces são mantidos como estão no arquivo original.

## A biblioteca padrão

A biblioteca padrão oferece muitas funções, algoritmos e estruturas de dados comuns. A biblioteca padrão usa o namespace `std`.

Um exemplo é a biblioteca numérica do C, `cmath`. Ela oferece muitas operações matemáticas comuns.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
As bibliotecas padrão são incluídas com sinais de maior e menor `<>` em vez de aspas duplas `"`. A diferença está no local onde o compilador procura os arquivos correspondentes. Na versão com sinais de maior e menor, a busca no projeto atual é ignorada, e a busca começa direto nos diretórios de inclusão do sistema. Se você quiser incluir arquivos locais, use aspas duplas: `#include "myfile"`
~~~~
