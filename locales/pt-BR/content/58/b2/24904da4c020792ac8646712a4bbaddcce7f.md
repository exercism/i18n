# Dicas

## Geral

- Existem três [operadores Boolean][logical operators] para trabalhar com valores Boolean.
- É possível combinar vários operadores em uma única expressão.

## 1. Verifique se é possível fazer um ataque rápido

- O operador lógico de negação (`!`) pode ser colocado antes de uma expressão para negar o valor dela.

## 2. Verifique se é possível espionar o grupo

- Os operadores lógicos são normalmente usados para avaliar se duas ou mais expressões são verdadeiras ou não.

## 3. Verifique se é possível sinalizar o prisioneiro

- Os operadores lógicos são executados na ordem de sua precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Para mais detalhes, consulte a seção de Precedência de Operadores na [documentação oficial do Go][operators] e a [tabela verdade][truth table].
