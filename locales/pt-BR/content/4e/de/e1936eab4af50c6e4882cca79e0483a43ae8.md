# Sobre

Os booleanos em Java são representados pelo tipo `boolean`, cujos valores podem ser `true` ou `false`.

Java dá suporte a três [operadores booleanos][operators]:

- `!` (NOT): nega o booleano
- `&&` (AND): recebe dois booleanos e resulta em true se os dois forem verdadeiros
- `||` (OR): resulta em true se qualquer um dos dois booleanos for verdadeiro

Os operadores `&&` e `||` usam _avaliação de curto-circuito_. Isso significa que o lado direito do operador só é avaliado quando necessário.

Eles também são conhecidos como operadores condicionais ou lógicos.
Na documentação, `!` às vezes é classificado como uma operação bit a bit, mas tem a semântica convencional de _NOT_.

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

Cada um dos três operadores booleanos tem uma [_precedência de operadores_][precedence] diferente. Por isso, eles são avaliados nesta ordem: `not` primeiro, `&&` em segundo e, por fim, `||`.
Se você quiser 'escapar' dessas regras, pode colocar uma expressão booleana entre parênteses (`()`), pois os parênteses têm uma precedência de operador ainda maior.

```java
!true && false   // => false
!(true && false) // => true
```
