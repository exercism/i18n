# Instruções

Você cuida do kit de geração de código de uma estação de sinais.
Cada macro é um *estêncil*: um pequeno molde que o compilador usa
para carimbar código especializado em cada ponto de chamada.

Você escreve apenas as quatro macros. O arquivo de testes define
pequenas palavras wrapper que *chamam* suas macros (uma macro só
pode ser observada por meio do código que ela gera) e depois
verifica os resultados em tempo de execução dos wrappers. Deixe os
wrappers como estão.

Para cada tarefa, o corpo recebe as entradas literais do ponto de
chamada na pilha e deve deixar **uma quotation**. As linhas
"compila para" mostram o código linear que sua quotation deve
produzir.

## 1. Duas vezes

`twice` recebe uma quotation literal e retorna uma quotation que
executa a original duas vezes seguidas.

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N repetições

`repeat-quot` recebe uma quotation literal e uma contagem literal
`n`, e retorna uma quotation que executa a original `n` vezes
seguidas. `n = 0` retorna a quotation vazia `[ ]`.

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. Compor várias

`compose-many` recebe um array literal de quotations e retorna uma
única quotation que executa cada uma delas em sequência. Um array
vazio retorna a quotation vazia.

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. Iteração desenrolada

`each-literal` recebe uma sequência literal e uma quotation. Ela
retorna uma quotation que, para cada elemento da sequência, empilha
esse elemento e depois executa a quotation: iteração que acontece em
tempo de compilação, então o código gerado é linear.

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

Esta é a mais estrutural das quatro: tanto o comprimento da
sequência *quanto* os valores de seus elementos moldam o código
gerado. As dicas mostram como construí-la passo a passo.
