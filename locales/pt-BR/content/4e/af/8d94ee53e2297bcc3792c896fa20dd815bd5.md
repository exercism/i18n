# Introdução

## Interfaces

Uma interface é um tipo que contém membros que definem um grupo de funcionalidades relacionadas. Ela separa os usos de uma classe da implementação, o que permite várias implementações diferentes ou o suporte a algum comportamento genérico, como formatação, comparação ou conversão.

A sintaxe de uma interface é parecida com a de uma classe ou struct, exceto que os métodos e as propriedades aparecem apenas como assinatura, sem corpo.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Todas as operações definidas pela interface precisam ser implementadas.

As interfaces podem conter métodos de instância e propriedades, entre outros membros.

## Ordenação

Para permitir que um objeto seja comparado a outro objeto, ele precisa implementar a interface `IComparable<T>`.
Essa interface tem um único método que precisa ser implementado: `int CompareTo(T other)`.

Há três valores de retorno possíveis para o método `CompareTo`:

- Valor menor que zero: o objeto atual é menor que o outro objeto.
- Valor maior que zero: o objeto atual é maior que o outro objeto.
- Valor igual a zero: o objeto atual é igual ao outro objeto.
