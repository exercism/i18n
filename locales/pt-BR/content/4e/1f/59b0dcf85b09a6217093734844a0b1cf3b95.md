# Instruções

Sua tarefa é fazer o parsing de uma string no formato Smart Game Format (SGF) e retornar uma estrutura de dados em árvore que represente o jogo.

Uma string SGF representa uma árvore de nós. A árvore inteira fica entre parênteses `()`.
Cada nó da árvore é indicado por um ponto e vírgula `;`, seguido de uma sequência de propriedades.
Uma propriedade consiste em um identificador em letras maiúsculas (por exemplo, `AB`), seguido de um ou mais valores entre colchetes `[]`.

Por exemplo, a string `(;FF[4]C[root])` representa uma árvore com um único nó raiz. Esse nó tem duas propriedades:
- A propriedade `FF` com o valor `4`
- A propriedade `C` com o valor `root`

**Variações (árvores e ramificações)**
O SGF permite variações do jogo por meio de árvores aninhadas. Uma árvore pode ter várias árvores filhas, que também ficam entre parênteses.
Por exemplo, `(;A[B](;C[D])(;E[F]))` representa um nó raiz com a propriedade `A`, que tem dois ramos filhos:
1. Um nó com a propriedade `C` e o valor `D`
2. Um nó com a propriedade `E` e o valor `F`

**Formatação e escape**
Os valores entre colchetes podem conter caracteres escapados. Uma barra invertida `\` seguida de qualquer caractere representa esse caractere literal (por exemplo, `\]` deve ser interpretado como um `]` literal). Além disso, se uma quebra de linha for precedida por uma barra invertida, ela funciona como continuação de linha e deve ser removida do valor. Todas as outras quebras de linha dentro de um valor devem ser preservadas.

**Tratamento de erros**
Você deve lançar um erro para strings SGF inválidas. Os exemplos a seguir são SGF inválidos:
- Uma árvore que não começa com parênteses `()`.
- Um nó que não começa com um ponto e vírgula `;`.
- Identificadores de propriedade que não são compostos apenas por letras maiúsculas.
- Colchetes ausentes ou parênteses desemparelhados.

### Estrutura de dados

Sua função de parsing deve retornar uma representação da árvore. Uma abordagem comum é representar cada árvore como um objeto com dois campos:
- `properties`: um objeto (ou Map) em que as chaves são os identificadores de propriedade (strings) e os valores são arrays de strings (já que uma propriedade pode ter vários valores).
- `children`: um array que contém as árvores filhas.


Exemplo:

Entrada: `(;FF[4]C[root])`
Saída: `{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

Entrada: `(;A[B](;C[D])(;E[F]))`
Saída: `{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
