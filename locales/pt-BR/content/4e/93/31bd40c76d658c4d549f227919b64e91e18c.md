# Anexo às instruções

## Instruções específicas da trilha

### Formato de entrada

A entrada estará no formato de uma string.
Para manter este exercício amigável para quem está começando, não é preciso esperar números com mais de um dígito.

Os bytes 64-191 da memória linear são reservados para a string de entrada.

### Formato de saída

A saída é esperada em pares de linha e coluna como u8, concatenados diretamente.

Por exemplo, se houver três pontos de sela

linha: 2, coluna: 1
linha: 2, coluna: 2
linha: 2, coluna: 3

então os valores u8 esperados na saída seriam `2, 1, 2, 2, 2, 3`
