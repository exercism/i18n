# Sobre

Existem três tipos de ponto flutuante em C#: `double`, `float` e `decimal`. O tipo mais usado é `double`, enquanto `decimal` normalmente é usado ao trabalhar com dados monetários. Um `double` é escrito como `2.45` ou `2.45d`, um `float` como `2.45f` e um decimal como `2.45m`.

Cada tipo de ponto flutuante tem sua própria [precisão, faixa aproximada e tamanho][docs-microsoft.com-characteristics-of-the-floating-point-types].

Algumas conversões entre tipos de ponto flutuante são [automáticas (implícitas)][docs-microsoft.com-implicit-numeric-conversion], mas outras são [manuais (explícitas)][docs-microsoft.com-explicit-numeric-conversion].

```csharp
decimal account = 125m * (decimal)1.2f;
```

Tenha sempre cuidado ao verificar a igualdade entre valores de tipos de ponto flutuante, pois valores que parecem representar o mesmo número podem na verdade ser diferentes. Veja [este artigo][docs.microsoft.com_precision-in-comparisons] para mais informações.

Você encontra uma breve introdução aos números de ponto flutuante em [0.30000000000000004.com][0.30000000000000004.com]. A página [Float Toy][evanw.github.io-float-toy] traz uma explicação gráfica bacana de como os bits de um número de ponto flutuante são convertidos em um valor de ponto flutuante de verdade.
