# Dicas

## Geral

- Leia sobre aritmética básica no [guia oficial de primeiros passos][getting-started-basic-arithmetic].
- Explore os módulos [`Float`][float-functions] e [`Kernel`][kernel-arithmetic-operators] para conhecer as funções e os operadores que funcionam com números de ponto flutuante.

## 1. Calcule o valor diário a partir de um valor por hora

- As [operações aritméticas básicas][kernel-arithmetic-operators] em que um argumento é um número inteiro e o outro é um número de ponto flutuante retornam um número de ponto flutuante.

## 2. Calcule um preço com desconto

- As [operações aritméticas básicas][kernel-arithmetic-operators] em que um argumento é um número inteiro e o outro é um número de ponto flutuante retornam um número de ponto flutuante.

## 3. Calcule o valor mensal a partir de um valor por hora e de um desconto

- Existe uma [função embutida][kernel-trunc] para converter números de ponto flutuante em inteiros.
- Existe uma [função embutida][float-ceil] para arredondar números de ponto flutuante para cima.

## 4. Calcule o número de dias úteis a partir de um orçamento, um valor por hora e um desconto

- Existe uma [função embutida][float-floor] para arredondar números de ponto flutuante para baixo com a precisão desejada.
