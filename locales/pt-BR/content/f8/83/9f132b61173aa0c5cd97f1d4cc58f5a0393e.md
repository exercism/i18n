# Introdução

## Argumentos rotulados

Às vezes, quando uma função recebe muitos argumentos, pode ser difícil lembrar a ordem em que eles devem ser passados. Para facilitar a leitura, o Gleam permite rotular os argumentos com um nome.

Para rotular um argumento, escreva o nome do rótulo antes do nome do argumento, separados por um espaço.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Ao chamar uma função com argumentos rotulados, os argumentos podem ser passados em qualquer ordem. Todas estas chamadas a `replace` são equivalentes:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Os rótulos são sempre opcionais. Mesmo que uma função tenha argumentos rotulados, ela ainda pode ser chamada sem rótulos.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
