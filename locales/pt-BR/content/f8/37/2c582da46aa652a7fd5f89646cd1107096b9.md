# Conceitos de Luhn

Luhn é um algoritmo de validação que combina verificações textuais e numéricas. Soluções em Rust favorecem abordagens funcionais.

## Geral

### primitivos

- `&str` e `char`
  - os estudantes precisam entender a distinção entre um `char` individual e uma `&str` para excluir ou incluir corretamente partes da entrada fornecida
- inteiro
  - entender inteiros é importante para fazer a validação numérica necessária
- booleans
  - fundamentais para verificações de identidade e comparações finais

### recursos de iteradores

- encadeamento
  - é importante entender cadeias de iteradores aqui para resolver o problema de forma ordenada.
- `map`, `filter`, turbofish, possivelmente `fold`
  - combinar map e filter fornece um padrão de projeto fundamental para problemas de validação como este. Soluções com `fold` também são mais breves.
  - o turbofish é necessário em algumas soluções para dizer ao Rust que tipo você está criando a partir de uma expressão encadeada

## Solução de exemplo 1

a [solução](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d) de york

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## Solução de exemplo 2

Canônica

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
