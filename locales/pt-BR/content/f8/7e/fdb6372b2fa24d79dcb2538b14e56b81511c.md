# Sobre

## Funções

No Gleam, as funções são definidas com a sintaxe `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Essa função recebe dois argumentos, ambos do tipo `Int`, e retorna um valor do tipo `Int`. No Gleam não existe a palavra-chave `return`: o valor da última expressão de uma função é sempre _retornado implicitamente_.

As anotações de tipo dos argumentos e o tipo de retorno são opcionais, e o Gleam sempre verifica os tipos do seu código por completo. Normalmente, quem programa em Gleam adiciona anotações de tipo às funções para deixar tudo mais claro, mas você pode omiti-las se quiser.

```gleam
pub fn add(x, y) {
  x + y
}
```

Uma função pode ser chamada com a sintaxe `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Variáveis

No Gleam, as variáveis são definidas com a sintaxe `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

As variáveis podem ser declaradas com anotações de tipo. Assim como nos argumentos de função, elas são opcionais, embora a maioria de quem programa em Gleam prefira omitir as anotações de tipo das variáveis.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Literais de string

No Gleam, as strings são escritas entre aspas duplas.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Comentários de código

Você pode usar comentários para deixar anotações para outras pessoas que forem ler o código-fonte. No Gleam, os comentários são linhas únicas precedidas por `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
