# Instruções

Sua amiga Li Mei tem um bar de sucos onde vende deliciosos sucos mistos de frutas.
Você é cliente frequente da loja dela e percebeu que poderia facilitar a vida da sua amiga.
Você decide usar suas habilidades de programação para ajudar Li Mei no trabalho dela.

## 1. Determine quanto tempo leva para preparar um suco

Li Mei gosta de avisar os clientes com antecedência quanto tempo eles vão esperar por um suco do cardápio que pediram.
Ela tem dificuldade para lembrar os números exatos, porque o tempo de preparo dos sucos varia:

| ID  | Bebida              | Tempo |
| --- | ------------------- | ----- |
| 1   | Pura Alegria de Morango | 1 |
| 2   | Energético          | 3     |
| 3   | Jardim Verde        | 3     |
| 4   | Ilha Tropical       | 4     |
| 5   | Tudo ou Nada        | 5     |
| 6   | Bem-Estar           | 4     |
| 7   | Especial do Dia     | 7     |
| 8   | Escolha do Cliente  | 10    |

Escreva uma função `time_to_make_juice` que recebe o ID de um suco, como um número de 32 bits, e retorna o tempo que leva para preparar o suco, também como um número de 32 bits.

```c
time_to_make_juice(2);
// => 3
```

## 2. Determine quanto tempo leva para preparar todos os sucos pedidos

Li Mei precisa reabastecer os suprimentos de tempos em tempos, então precisa saber com antecedência quanto tempo vai levar para preparar todos os pedidos disponíveis no momento.

Para ajudar sua amiga, escreva uma função `time_to_prepare` que recebe um array de IDs, um para cada suco pedido, e o número de sucos no array.
Essa função deve retornar o tempo total necessário para preparar todas as bebidas do array.

Você pode considerar que cada ID, o número de IDs no array e o valor de retorno são todos números de 32 bits.
O resultado sempre cabe em um número de 32 bits.

```c
time_to_prepare({2, 3, 8}, 3);
// => 16
```

## 3. Reabasteça o estoque de gomos de limão

Muitas das criações de Li Mei levam gomos de limão, seja como ingrediente, seja como parte da decoração.
Por isso, quando ela começa o turno de manhã, precisa garantir que o recipiente de gomos de limão esteja cheio para o resto do dia.

Implemente a função `limes_to_cut`, que recebe o número de gomos de limão que Li Mei precisa cortar, um array que representa o estoque de limões inteiros que ela tem à mão e o número de limões no array.

Cada limão é representado no array por um caractere com o seu tamanho.
Tamanhos diferentes de limão podem dar a Li Mei um número diferente de gomos:

| Tamanho | Gomos |
| ------- | ----- |
| 'S'     | 6     |
| 'M'     | 8     |
| 'L'     | 10    |

~~~~exercism/note
Um caractere é um número de 8 bits que pode ser usado como qualquer número de 8 bits:

| Caractere | Valor |
|-----------|-------|
| 'S'       | 83    |
| 'M'       | 77    |
| 'L'       | 76    |

Ele também pode ser usado diretamente nas instruções, equivalendo ao seu valor:

```x86asm
mov dl, 'S'
cmp cl, 'M'
```
~~~~

Li Mei sempre corta os limões na ordem em que eles aparecem no array, começando pelo primeiro item.
Ela continua até atingir o número de gomos de que precisa ou até os limões acabarem.

Li Mei gostaria de saber com antecedência quantos limões ela precisa cortar.

Você pode considerar que o número de gomos necessários, o número de limões no array e o valor de retorno são todos números de 32 bits.
O resultado sempre cabe em um número de 32 bits.

```c
limes_to_cut(25, {'S', 'S', 'L', 'M', 'S'}, 5);
// => 4
```

## 4. Termine o turno

Li Mei sempre trabalha até as 15h.
Depois, seu funcionário Dmitry assume.
Muitas vezes há bebidas que foram pedidas, mas ainda não foram preparadas quando o turno de Li Mei termina.
Então Dmitry prepara os sucos restantes.

Para facilitar a passagem do turno, implemente uma função `remaining_orders` que recebe:

- O número de minutos restantes no turno de Li Mei.
- Um array de IDs, um para cada suco que foi pedido mas ainda não foi preparado.

A função deve retornar o número de pedidos que Li Mei preparou antes do fim do seu turno.

O tempo restante no turno será sempre maior que 0.
O array de sucos a preparar nunca estará vazio e o turno sempre termina antes de chegar ao fim do array.
Além disso, os pedidos são preparados na ordem em que aparecem no array.
Se Li Mei começa a preparar um determinado suco, ela sempre o termina, mesmo que precise trabalhar um pouco mais.

Você pode considerar que o número de minutos restantes, cada ID no array e o valor de retorno são todos números de 32 bits.
O resultado sempre cabe em um número de 32 bits.

```c
remaining_orders(5, {5, 5, 3});
// => 1
```
