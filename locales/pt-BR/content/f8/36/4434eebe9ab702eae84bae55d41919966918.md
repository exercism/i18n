# Instruções

Como aspirante a mágica, Elyse precisa praticar alguns fundamentos. Ela tem uma pilha de cartas que quer manipular.

Para facilitar um pouco, ela usa apenas as cartas de 1 a 10, então a pilha de cartas pode ser representada por um vetor de números. A posição de uma carta corresponde ao índice no vetor.

## 1. Pegar uma carta da pilha

Para pegar uma carta, retorne a carta no índice `position` da pilha fornecida.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. Trocar uma carta na pilha

Com um passe de mágica, troque a carta no índice `position` pela carta de substituição fornecida.
Retorne a pilha ajustada.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. Inserir uma carta no topo da pilha

Faça uma carta aparecer inserindo uma nova carta no topo da pilha.
Retorne a pilha ajustada.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. Remover uma carta da pilha

Faça uma carta desaparecer removendo da pilha a carta na `position` indicada.
Retorne a pilha ajustada.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. Verificar o tamanho da pilha

Verifique se o tamanho da pilha é igual a `stack_size` ou não.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. Remover a carta do topo da pilha

Faça uma carta desaparecer removendo a carta do topo da pilha.
Retorne a pilha ajustada.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. Inserir uma carta na base da pilha

Faça uma carta aparecer inserindo uma nova carta na base da pilha.
Retorne a pilha ajustada.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. Remover uma carta da base da pilha

Faça uma carta desaparecer removendo a carta da base da pilha.
Retorne a pilha ajustada.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
