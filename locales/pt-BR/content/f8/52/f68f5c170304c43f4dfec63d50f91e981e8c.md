# Introdução

JavaScript é uma linguagem dinâmica, que dá suporte a estilos orientados a objetos, imperativos e declarativos (por exemplo, programação funcional).

## Variáveis

Existem algumas formas principais de atribuir valores a nomes em JavaScript: usando variáveis ou constantes.
No Exercism, as variáveis são sempre escritas em [camelCase][wiki-camel-case]; as constantes são escritas em [SCREAMING_SNAKE_CASE][wiki-snake-case].
Não há um guia oficial a seguir, e empresas e organizações diferentes têm guias de estilo diferentes.
_Fique à vontade para escrever as variáveis como quiser_.
A vantagem de escrevê-las do jeito que os exercícios são preparados é que elas vão aparecer destacadas de forma diferente na interface web e na maioria das IDEs.

Em JavaScript, as variáveis podem ser definidas com a palavra-chave [`const`][mdn-const], [`let`][mdn-let] ou [`var`][mdn-var].

Uma variável pode referenciar valores diferentes ao longo da sua existência quando se usa `let` ou `var`.
Por exemplo, `myFirstVariable` pode ser definida e redefinida várias vezes usando o operador de atribuição `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

Ao contrário de `let` e `var`, as variáveis definidas com `const` só podem receber uma atribuição uma única vez.
É assim que se definem constantes em JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## Declarações de funções

Em JavaScript, as unidades de funcionalidade são encapsuladas em _funções_, geralmente agrupando no mesmo arquivo as funções que pertencem umas às outras.
Essas funções têm parâmetros (para que possam receber argumentos) e podem _retornar_ um valor usando a palavra-chave `return`.
As funções são invocadas com a sintaxe `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

Neste exemplo, o nome da função é `add`.
Ela tem dois parâmetros, `num1` e `num2`.
Ela retorna um valor: o resultado da expressão `num1 + num2`

Em seguida, a função `add` é _chamada_ com dois argumentos: `1` e `3`.
O resultado da função, o valor retornado, é `4`.

```exercism/note
💡 Em JavaScript existem _muitas_ maneiras diferentes de declarar uma função.
Algumas dessas outras maneiras são diferentes do uso da palavra-chave `function`.
A trilha tenta apresentá-las aos poucos, mas se você já as conhece, fique à vontade para usar qualquer uma delas.
Na maioria dos casos, usar uma ou outra não é melhor nem pior.
```

## Expondo para outros arquivos

Para tornar uma `function`, uma constante ou uma variável disponível em _outros arquivos_, é preciso [exportá-las][mdn-export] usando a palavra-chave `export`.
Outro arquivo pode então [importá-las][mdn-import] usando a palavra-chave `import`.
Isso também é conhecido como sistema de módulos.

Um ótimo exemplo é como todos os testes funcionam.
Cada exercício tem pelo menos um arquivo, por exemplo `lasagna.js`, que contém a _implementação_.
A _implementação_ é marcada com `export` no arquivo, o que a deixa disponível para importação em outro arquivo.
Além disso, há pelo menos um outro arquivo, por exemplo `lasagna.spec.js`, que contém os _testes_.
Esse arquivo importa (com `import`) as entidades públicas (ou seja, as que foram exportadas) para poder testar a implementação:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
