# Introdução

## Noções básicas

Para informações mais detalhadas sobre esses tópicos, visite a [página do conceito][exercism-concept].

### Sintaxe geral

A tag de abertura do PHP `<?php` marca o início do código PHP.
Todas as instruções devem terminar com um `;` para separá-las.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

Para facilitar a leitura, todos os exemplos de código omitem a tag de abertura do PHP `<?php`.

### Comentários

Comentários de uma linha começam com `//`.

```php
// Single line comment
```

### Valores e variáveis

Com o operador de atribuição `=`, você pode atribuir um valor a uma variável.
Os nomes de variáveis devem começar com o cifrão `$` e seguir as [convenções de nomenclatura][exercism-concept-naming-conventions].

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

### Funções e métodos

Valores e variáveis podem ser passados para funções.
Os argumentos de uma função se tornam novas variáveis para armazenar os valores passados.
Funções podem retornar qualquer valor usando a palavra-chave `return`.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

Funções dentro de classes e suas instâncias são chamadas de métodos.
Para chamar um método, o nome é precedido pela instância e por `->`.
Métodos têm acesso à variável especial `$this`, que se refere à instância atual.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
