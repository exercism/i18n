# Instruções

Como uma mágica em formação, Elyse precisa praticar alguns fundamentos. Ela tem um baralho de cartas que quer manipular.

Para facilitar um pouco as coisas, ela usa apenas as cartas de 1 a 10.

## 1. Retire uma carta do baralho

Implemente a função `getCard` que retorna a carta na posição `index` do baralho fornecido. Se o índice não existir no baralho, retorne Nothing.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. Troque uma carta no baralho

Implemente a função `setCard` que retorna um baralho com a carta na posição `index` trocada pela nova carta fornecida.
Se o `index` não existir no baralho, retorne o baralho original.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. Adicione uma carta ao baralho

Implemente a função `addCard` que retorna um baralho com a nova carta adicionada.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. Remova uma carta do baralho

Implemente a função `removeCard` que retorna um baralho com a carta na posição `index` removida.
Se o `index` fornecido não for um índice válido no baralho, retorne o baralho original.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. Conte o número de cartas pares no baralho

Implemente a função `evenCardCount` que conta o número de cartas pares no baralho.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
