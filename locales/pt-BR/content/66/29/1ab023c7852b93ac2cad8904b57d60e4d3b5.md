# Sobre

As classes principais de `java.time`, como `LocalDate` e `LocalDateTime`, oferecem métodos básicos para somar ou subtrair unidades de tempo. Já os ajustes de data mais complexos costumam exigir uma lógica mais sofisticada (por exemplo, encontrar a "segunda terça-feira do mês" ou o "último dia do ano").

O pacote `java.time.temporal` oferece a interface funcional [`TemporalAdjuster`][temporaladjuster-docs] para essa finalidade.
Ela representa uma estratégia para ajustar um objeto temporal (como um `LocalDate`).
A classe utilitária [`TemporalAdjusters`][temporaladjusters-docs] (repare no "s" do plural) contém métodos de fábrica estáticos que fornecem muitas implementações de ajustadores comuns e predefinidos.

## Usando TemporalAdjusters

Objetos temporais como `LocalDate` e `LocalDateTime` têm um método `with()` que aceita um `TemporalAdjuster`.
Esse método retorna um *novo* objeto temporal com o ajuste aplicado.

```exercism/note
Usar `with(TemporalAdjuster)` retorna uma instância _nova_ e não atualiza a instância existente, pois todas as classes temporais de `java.time` são imutáveis.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## Ajustadores predefinidos comuns

A classe `TemporalAdjusters` oferece muitos métodos estáticos úteis.
Veja alguns exemplos comuns:

### Encontrar o enésimo dia da semana no mês

O ajustador `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` encontra a enésima ocorrência de um dia da semana específico dentro do mês.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### Encontrar o primeiro ou o último dia da semana no mês

Os ajustadores `firstInMonth(DayOfWeek dayOfWeek)` e `lastInMonth(DayOfWeek dayOfWeek)` encontram a primeira ou a última ocorrência de um dia da semana dentro do mês.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Encontrar o primeiro ou o último dia do mês ou do ano

Ajustadores mais simples encontram o primeiro ou o último dia do mês ou do ano atual.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### Ajustes relativos (próximo/anterior)

Ajustadores como `next()`, `previous()`, `nextOrSame()` e `previousOrSame()` encontram a próxima ocorrência, ou a ocorrência anterior, de um determinado dia da semana em relação à data atual.

- `next()`/`previous()`: excluem a data atual se ela corresponder.
- `nextOrSame()`/`previousOrSame()`: incluem a data atual se ela corresponder.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Ajustadores personalizados

Como `TemporalAdjuster` é uma [`@FunctionalInterface`][functionalinterface-docs], você pode criar seus próprios ajustadores personalizados com expressões lambda para lógicas que os métodos predefinidos não cobrem.
A interface exige a implementação de um único método: `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

Ajustadores personalizados são poderosos, mas os ajustadores predefinidos da classe `TemporalAdjusters` cobrem uma grande variedade de casos de uso comuns.
