# Instruções

Você está cuidando do placar em uma partida de netball. Diferente de tudo até agora, um placar precisa se lembrar do que aconteceu.

A classe `SCOREBOARD` precisa do seguinte. O código inicial já traz a classe e as duas declarações de atributos dela; adicione o resto.

## 1. Monte o placar

`create` recebe o nome do time da casa e o nome do time visitante e devolve um placar com as duas pontuações em zero.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. Marque um gol

`home_goal` soma um à pontuação da casa, e `away_goal` soma um à pontuação dos visitantes. Nenhum dos dois retorna nada.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. Leia o placar

`summary` retorna o placar como ele seria escrito: o time da casa, sua pontuação, um traço, a pontuação dos visitantes e, por fim, o time visitante.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

Os espaços são exatamente como mostrado, e o traço é um único `-`.

## 4. Quem está ganhando?

`leader` retorna o nome do time que está na frente, ou `"Draw"` quando as pontuações estão empatadas.

```sather
board.leader
-- => "Vixens"
```

## 5. Por quantos gols de diferença?

`margin` retorna quantos gols separam os times. Ele nunca é negativo, não importa quem esteja na frente.

```sather
board.margin
-- => 1
```
