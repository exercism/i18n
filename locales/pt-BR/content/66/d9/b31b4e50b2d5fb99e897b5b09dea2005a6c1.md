# Sobre

Z3 é uma linguagem de Satisfatibilidade Módulo Teorias (SMT), usada para ver se equações ou fórmulas são satisfatíveis, ou têm uma solução possível.

Z3 é mais comumente encontrada em verificação de software, resolução de restrições, problemas geométricos, segurança e outras aplicações que se beneficiam de computação matemática rápida.

Z3 foi criada pelo grupo Research in Software Engineering (RiSE) da Microsoft Research e, a partir de 2015, tornou-se uma linguagem de código aberto. O repositório de código aberto do Z3 no GitHub pode ser encontrado em https://github.com/Z3Prover/z3.
