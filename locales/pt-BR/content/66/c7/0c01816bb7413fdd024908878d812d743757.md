# Testes

Execute os testes com:

```bash
$ gradlew test
```

> Use `gradlew.bat` se você estiver no Windows

## Testes desativados

Nas suítes de teste, todos os testes, exceto o primeiro, foram desativados.

Assim que você conseguir fazer um teste passar, você pode ativar o próximo removendo a anotação `@Ignore`.
