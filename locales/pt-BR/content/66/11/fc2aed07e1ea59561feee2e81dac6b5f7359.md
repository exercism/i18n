## 1. Inicie uma verificação de confiabilidade para uma única entrada

- Você não precisa de uma tarefa para este passo; um processo vinculado comum já basta.
- Existe uma [função nativa][spawn-link] que executa uma determinada função anônima em um novo processo e o vincula ao processo atual.

## 2. Interprete os resultados de uma verificação de confiabilidade

- Para receber uma única mensagem, chame [`receive`][receive] uma vez. Ela vai ler a primeira mensagem que corresponder a qualquer um dos padrões informados, deixando as outras mensagens na caixa de entrada do processo.
- Você pode usar uma guarda ou [o operador de pin][pin-operator] para garantir que só sejam recebidas mensagens de um processo cujo PID corresponda ao PID passado como argumento para `await_reliability_check_result/2`.
- [`receive`][receive] aceita uma cláusula `after` para tratar timeouts.

## 3. Execute uma verificação de confiabilidade concorrente para muitas entradas

- O processo atual precisa começar a capturar saídas antes que qualquer novo processo vinculado seja criado.
- Para capturar saídas em um processo, define-se uma flag nesse processo.
- Existe uma [função nativa][process-flag] que define uma flag em um processo e retorna o valor anterior dessa flag.
- A flag para capturar saídas se chama `:trap_exit` e aceita um valor booleano.
- Use as funções do `Enum` para primeiro iniciar um processo para cada entrada e depois aguardar as mensagens de cada processo. Use as funções implementadas nos dois passos anteriores. Repare que o mapa retornado por `start_reliability_check/2` corresponde ao mapa que `await_reliability_check_result/2` espera como primeiro argumento.

## 4. Execute uma verificação de correção concorrente para muitas entradas

- Use uma tarefa assíncrona para este passo.
- Existe uma [função nativa][task-async] que inicia uma tarefa assíncrona.
- Existe uma [função nativa][task-await] que espera uma tarefa assíncrona terminar de executar e retorna o resultado dela. Ela aceita um timeout como segundo argumento.
- Use as funções do `Enum` para primeiro iniciar uma tarefa para cada entrada e depois esperar por cada tarefa.
