# Testes

Você pode rodar os testes fornecidos pelo DrRacket, ou pela linha de comando.

Para rodar o teste pelo DrRacket, basta abrir o arquivo de teste e clicar no botão 'Run' no canto superior direito.

Para rodar o teste pela linha de comando, basta rodar o teste a partir do diretório do exercício. Por exemplo, se a suíte de testes se chama `hello-world-test.rkt`, você pode rodar o seguinte comando:

```
raco test hello-world-test.rkt
```

que vai mostrar o seguinte:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
