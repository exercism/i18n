# Sobre

`assocs` é um [protocolo][assoc-protocol], não um único tipo de dado. Tabelas hash (`H{ }`), listas de associação (sequências de pares `{ key value }`) e mapas de árvore todos implementam esse protocolo, e a maioria dos words de assocs é intercambiável entre eles.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

A superfície completa é ampla, com iteração ordenada, mapeamento e filtragem, mas a maior parte do trabalho nos exercícios envolve um conjunto pequeno de words:

| word        | efeito                                        |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` distingue o valor f de uma chave ausente |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )` altera o assoc       |
| `change-at` | `( key assoc quot -- )` `quot` é `( old -- new )` |
| `inc-at`    | `( key assoc -- )` `+1`, inserindo `1` se a chave não existir |
| `delete-at` | `( key assoc -- )` altera o assoc             |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` e `sort-values` (em `sorting`) ordenam uma alist pelo campo escolhido.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
