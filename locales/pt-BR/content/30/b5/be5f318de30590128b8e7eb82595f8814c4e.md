# Anexo de instruções

## Implementação

Existem muitas formas de fazer este exercício, mas preparamos alguns stubs adicionais para quem quiser praticar a escrita dos próprios [manipuladores de habilidades][ability-handler-docs].

A assinatura da função auxiliar `checkBalance` fornecida para este exercício usa um requisito de habilidade, `{Stack}`.
A habilidade `Stack` já está definida para você, mas o manipulador, `Stack.run`, não!
Se você quiser, pode implementar as funções `Stack.run`, `checkBalance` e `isPaired`.
Os testes vão rodar mesmo se você optar por não implementar este exercício com habilidades.

[ability-handler-docs]: https://www.unison-lang.org/learn/fundamentals/abilities/writing-abilities/
