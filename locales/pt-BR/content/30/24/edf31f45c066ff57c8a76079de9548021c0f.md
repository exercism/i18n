# Instruções

Neste exercício, você vai escrever um `SecureTreasureChest` genérico (e mágico!) para guardar um tesouro.
Quem prestou atenção deve ter notado que o `TreasureChest` anterior não era tão seguro assim!
Se você usasse a função `getTreasure`, precisava informar a senha, mas ainda podia simplesmente desestruturar o tipo `TreasureChest` para pegar o tesouro, sem precisar saber a senha.
Pior ainda: você conseguia até recuperar a senha do mesmo jeito!
Vamos resolver isso usando um Tipo Opaco.

## 1. Defina o tipo opaco `Password`, usando o padrão "Parse, don't validate"

Defina um tipo customizado `Password` com uma única variante.

A variante deve ter um valor `String` associado, para a senha.

Você deve expor o tipo `Password`, mas não a variante.
Isso torna `Password` um Tipo Opaco e significa que você não pode mais usar desestruturação para pegar a senha.
Não é possível testar se um tipo é opaco ou não; em código de produção, você usaria o [elm-review][elm-review] (uma ferramenta de análise estática) para garantir isso.

Defina e exponha uma função `createPassword`, com uma definição de tipo, que recebe uma `String` e retorna um `Maybe Password`.

A Owasp recomenda que [as senhas tenham pelo menos 8 caracteres][owasp-password-length], então vamos usar o padrão [Parse, don't validate][parse-dont-validate] para garantir essa invariante.

Se a senha tiver menos de 8 caracteres, `createPassword` deve retornar `Nothing`; caso contrário, deve retornar `Just Password`.

## 2. Exponha `SecureTreasureChest`, mas não a sua variante

Você deve expor o tipo `SecureTreasureChest`, mas não a variante.
Isso torna `SecureTreasureChest` um Tipo Opaco e significa que você não pode mais usar desestruturação para pegar a senha ou o tesouro.

## 3. Defina a função `createTreasure`

Essa função deve receber dois parâmetros e ter uma definição de tipo.

- um tipo genérico (para o tesouro)
- uma `Password` (para a senha)

A função deve retornar um `SecureTreasureChest`.

Exponha essa função para que outros módulos possam criar instâncias de `SecureTreasureChest`.

## 4. Defina a função `getTreasure`

Essa função deve receber dois parâmetros e ter uma definição de tipo.

- uma `String` (para a senha)
- um tipo customizado genérico `SecureTreasureChest`

Essa função deve conferir a tentativa de senha fornecida com a `Password` do `SecureTreasureChest`.

A função deve retornar um `Maybe`.

Se as senhas coincidirem, retorne `Just` com o valor genérico do `SecureTreasureChest` (o tesouro!)

Se as senhas não coincidirem, retorne `Nothing`.

Exponha essa função para que outros módulos possam pegar o tesouro de um `SecureTreasureChest`, desde que informem a senha correta.
