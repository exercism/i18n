# Sobre

Inicializadores de objeto são uma alternativa aos construtores. A sintaxe é uma lista de pares campo=valor separados por vírgula, ilustrada abaixo:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Coleções também podem ser inicializadas dessa forma. Normalmente, isso é feito com listas separadas por vírgula, como mostrado aqui:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Essa abordagem (e essa sintaxe) pode ser usada com qualquer classe que implemente `IEnumerable` e tenha um método `Add()`.

Os campos podem ser listados em qualquer ordem ou omitidos por completo.

Dicionários usam a seguinte sintaxe:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

Os campos inicializados precisam ser acessíveis a quem faz a chamada. Normalmente, isso significa que eles precisam ser `public` ou `internal`.

Há uma forte tendência de promover a imutabilidade entre os projetistas da linguagem e os principais profissionais da área, então a mutabilidade dos objetos inicializados dessa forma é vista como uma desvantagem. Existem propostas de introduzir uma cláusula `init` na próxima versão da linguagem, o C# 9, o que pode resolver essa questão.

- A documentação de [inicializador de objeto][object-initializers] descreve como usar inicializadores.
- A documentação de [inicializador de coleção][collection-initializers] dá uma prévia de como os inicializadores podem ser usados com coleções como dicionários e listas.
