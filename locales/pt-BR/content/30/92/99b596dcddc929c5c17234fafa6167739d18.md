# Instruções

Neste exercício você vai trabalhar em um agendador de compromissos para um salão de beleza em Nova York que abriu em 15 de setembro de 2012.

Você tem cinco tarefas, e todas elas envolvem datas de compromissos.
Os horários estão no formato de 24 horas (sem AM/PM).

## 1. Analisar a data do compromisso em formato numérico

Implemente a função `schedule_appointment()` para converter uma representação textual de uma data de compromisso no formato `DateTime` correspondente.

Repare que a entrada está no formato americano mês/dia/ano.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Verificar se um compromisso já passou

Implemente a função `has_passed()` que recebe uma data de compromisso e verifica se o compromisso já ficou no passado:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Verificar se o compromisso é à tarde

Implemente a função `is_afternoon_appointment()` que recebe uma data de compromisso e verifica se o compromisso é à tarde (>= 12:00 e < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Descrever o horário e a data do compromisso

Implemente a função `description()` que recebe uma data de compromisso e retorna uma descrição dessa data e desse horário:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. Retornar a data de aniversário

Implemente a função `anniversary_date()` que retorna a data de aniversário deste ano, que é 15 de setembro:

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
