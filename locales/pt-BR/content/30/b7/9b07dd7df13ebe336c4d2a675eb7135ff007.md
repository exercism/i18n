# Dicas

## 1. Substitua todos os espaços encontrados por sublinhados

A biblioteca `clojure.string` embutida contém uma função [`replace`][str-replace].

## 2. Substitua caracteres de controle pela string "CTRL" em maiúsculas

Você pode usar o método [`isISOControl`][java-ctrl] da classe `Character` do Java.

## 3. Converta kebab-case para camelCase

Tente separar a string nos hifens com [`split`][str-split].
Se ela não contiver hifens, retorne-a como está. Você pode verificar isso usando [`includes?`][str-includes]. Use [`upper-case`][str-upper-case] para criar as "corcovas" do camelo. Por fim, concatene-as com [`join`][str-join].

## 4. Omita caracteres que não são letras

Você pode filtrar caracteres usando [`Character/isLetter`][java-isletter] como predicado.

## 5. Omita letras gregas minúsculas

As letras gregas minúsculas são os pontos Unicode `\u03B1` a `\u03C9`, ou os valores inteiros de 945 a 969.
