# Introdução

## Tipos de função

Se removermos todos os nomes e rótulos de uma assinatura de função em Swift, o que sobra é o tipo da função.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Repare que os tipos das duas primeiras funções são iguais, `(String, Int) -> String`, mesmo que as duas assinaturas sejam diferentes e as duas funções funcionem de maneiras bem distintas. As duas recebem uma `String` e um `Int` como entrada e retornam uma `String`. E, como dá para ver pelo tipo da terceira função, mesmo que o corpo da função não pareça retornar nada, na verdade ele retorna `()` implicitamente, o único valor do tipo `Void`.

Esses tipos de função podem ser usados da mesma forma que qualquer outro tipo em Swift. Por exemplo, podem ser usados na declaração de variáveis ou constantes. E, como funções são valores em Swift, funções que já existem podem ser atribuídas a essas constantes/variáveis:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Como acontece com outras variáveis/constantes, o valor que você atribui precisa ser do tipo correto:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

### Tipos de função como tipos de parâmetro

Como os tipos de função podem ser usados em qualquer lugar onde outros tipos podem ser usados, eles também podem ser usados como tipos de parâmetro, passados para outras funções e chamados de dentro delas.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Tipos de função como tipos de retorno

Da mesma forma, os tipos de função podem ser usados como tipos de retorno de funções. Em outras palavras, você pode escrever funções que criam e retornam outras funções. Ao criar essas funções, a função retornada pode usar os outros parâmetros passados para a função ou as variáveis locais criadas dentro da função pai.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
