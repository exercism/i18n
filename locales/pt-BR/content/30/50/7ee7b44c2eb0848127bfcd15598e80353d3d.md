# Anexo às instruções

## Dicas

Para completar este exercício, você precisa implementar a função `score`, que recebe uma sequência de *arremessos* de boliche e retorna a pontuação final ou o erro apropriado:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Você vai encontrar essas definições já prontas, mas definir a função é com você.

Lembre-se de que a suíte de testes espera que os arremessos sejam numerados a partir de zero.
