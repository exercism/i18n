# Anexo às instruções

## Formato do campo minado

O campo minado é representado como uma string terminada em nulo, com um caractere de quebra de linha no final de cada linha.

Um exemplo seria `"   \n * \n   \n"`

## Registradores

| Registrador | Uso          | Tipo    | Descrição                     |
| ----------- | ------------ | ------- | ----------------------------- |
| `$a0`       | entrada      | endereço | string de entrada terminada em nulo  |
| `$a1`       | entrada/saída | endereço | string de saída terminada em nulo |
| `$t0-9`     | temporário   | qualquer | para armazenamento temporário |
