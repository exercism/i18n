# Instruções complementares

## Implementação

As strings do código-fonte em Go (e as strings dos testes unitários) são UTF-8.
Uma string contém bytes que representam runes.
Na maioria dos casos em Go, uma "unidade de código" é um `byte` e um "ponto de código" é um `rune`.

Veja [Strings, bytes, runes and characters in Go][strings] para mais detalhes.

[strings]: https://go.dev/blog/strings
