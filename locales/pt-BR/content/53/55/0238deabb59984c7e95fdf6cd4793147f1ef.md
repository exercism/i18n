# Módulo

Comparações com módulo são perfeitamente válidas no Crystal, mas uma forma mais legível de comparar o resto de uma divisão é com o método [`divisible_by?`][divisible_by].
Ou, melhor ainda, se você quer verificar se um número é ímpar ou par, use os métodos [`odd?`][odd?] e [`even?`][even?].

Por exemplo:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```
