# Instalação

## Instale o .NET 10

A trilha de Visual Basic usa o .NET 10.
Para compilar e testar os exercícios localmente, instale [o SDK do .NET 10 para o seu sistema operacional][install-sdk]:
instale o SDK, não apenas o runtime.

## Verifique a instalação

Abra um novo terminal e execute:

```bash
dotnet --version
```

O comando deve exibir `10.0.0` ou uma versão posterior.

## Suporte a editores

O SDK do .NET e um editor de texto simples são tudo o que você precisa para completar os exercícios.
Para recursos mais avançados, como preenchimento automático de código e debug, considere um destes editores:

- [Visual Studio 2026][visual-studio] no Windows
- [Visual Studio Code][visual-studio-code] no Windows, no Linux ou no macOS
- [JetBrains Rider][rider] no Windows, no Linux ou no macOS

[install-sdk]: https://learn.microsoft.com/en-us/dotnet/core/install
[rider]: https://www.jetbrains.com/rider/
[visual-studio]: https://visualstudio.microsoft.com/downloads/
