# Ranges

[Ranges][range] representam um intervalo entre dois valores.
Os tipos mais comuns que suportam ranges são `Integer` e `String`.
Eles podem ser usados para muitas coisas, como criar uma coleção rapidamente, fatiar strings, verificar se um valor está em um range e iterar.
Eles são criados com o operador de range `..` ou `...` (inclusivo e exclusivo, respectivamente).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

O motivo de existirem dois operadores de range é permitir criar ranges que incluem ou excluem o valor final, o que pode ser útil, por exemplo, ao trabalhar com índices que começam em zero.

Ranges também podem ser criados com o inicializador `Range`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Ao criar um range em Ruby com os operadores de range `..` ou `...` e querer chamar um método nesse range, você precisa envolver o range entre parênteses.
Isso acontece porque, caso contrário, o método será chamado no segundo argumento do operador de range.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Obtendo substrings

Quando você quer fatiar uma string, pode usar o operador de range para obter uma substring.
Ou seja, criando um range com o índice inicial e o índice final da substring.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Você também pode usar índices negativos para obter a substring a partir do fim da string.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Métodos de range

Ranges têm sim um conjunto de métodos que podem ser usados para trabalhar com eles.
Por exemplo, esses métodos podem ser usados para obter a soma de todos os valores do range ou verificar se o range inclui um valor.

| Método                  | Descrição                                                               | Exemplo                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Retorna a soma de todos os valores do range                             | `(1..5).sum # => 15`            |
| [`size`][size]          | Retorna o tamanho do range                                              | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Retorna `true` se o range inclui o valor dado, caso contrário `false`   | `(1..5).include?(3) # => true` |

## Ranges sem fim e sem início

Um range pode ser sem fim e sem início.
O range sem fim ou sem início tem seu valor inicial ou final igual a `nil`, mas, ao definir o range, o `nil` pode ser omitido.

Usar ranges sem início e sem fim é útil quando você quer, por exemplo, fatiar uma string desde o começo ou até o fim.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Se não for usado em uma coleção, o range sem fim pode causar uma sequência sem fim, caso não seja usado com cuidado.
~~~~

## Ranges de string

Strings também podem ser usadas em ranges e permitem obter um intervalo de strings entre duas strings.
O comportamento pode ser um pouco inesperado com certas strings, então use com cuidado.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
