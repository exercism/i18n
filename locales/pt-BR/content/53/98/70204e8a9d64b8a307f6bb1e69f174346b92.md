# Sobre

Você pode usar [tipos de enumeração][enumeration types] sempre que tiver um conjunto fixo de valores constantes. Usar um `enum` oferece uma forma segura em termos de tipos de interagir com valores constantes. Definir um enum é feito com a palavra-chave `enum`. Para se referir a um membro do enum, coloca-se antes dele o nome do enum e um ponto (por exemplo, `Status.Active`).

Cada membro do enum é uma associação entre um nome e um valor `int`. Se o primeiro membro não tiver um valor explícito, seu valor é definido como `0`. Se nenhum valor for definido explicitamente para um membro do enum, seu valor é atribuído automaticamente ao valor do membro anterior mais `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

Enums são muito declarativos. Compare as duas chamadas de método a seguir:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

Para quem lê o código, a segunda versão (com enum) será mais fácil de entender.

## Enums com tipo numérico

Embora o tipo numérico padrão dos valores seja `int`, ele pode ser alterado especificando explicitamente qualquer outro tipo [numérico integral][integral numeric].

O enum a seguir usa o tipo numérico `byte` para seus valores:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## Conversão para um membro de enum

Você deve sempre considerar usar um enum sempre que quiser modelar algo como um Boolean. Além dos benefícios de legibilidade mencionados, os enums têm outra vantagem sobre os Booleans: novos valores sempre podem ser adicionados a um enum, enquanto um valor Boolean só pode ser `true` ou `false`. Assim, usar um enum é mais à prova de futuro.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Observe que, embora _seja possível_ converter valores inteiros em um enum, fazer isso pode levar a resultados inesperados quando o valor inteiro não corresponde a nenhum valor do enum:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Fazendo o parsing de um enum

Às vezes é útil converter uma string em um membro de enum com base no nome dele usando [`Enum.Parse`][enum parse]:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Para verificar se um nome ou um valor existe no enum, você pode usar [`Enum.TryParse`][enum tryparse] ou [`Enum.IsDefined`][enum isdefined]; ambos retornam um Boolean que indica se o membro do enum existe:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
