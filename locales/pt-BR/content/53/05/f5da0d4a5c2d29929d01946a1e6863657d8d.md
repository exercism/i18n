# Testes

Para testar sua solução, basta rodar:

```bash
make test
```

Isso vai rodar o arquivo de teste `<exercise-name>-test.ys`, que contém todos os
testes que você precisará passar para que sua solução esteja correta.
Estude o arquivo de teste para entender exatamente o que sua solução precisa
fazer.

> Observação: na primeira vez que você rodar `make test`, ele também vai garantir
> que a versão correta do intérprete `ys` do YAMLScript esteja instalada no
> lugar certo.

Se você rodar `make test` antes de mudar qualquer arquivo, todos os testes vão falhar.
Esse é o comportamento correto e esperado.
O processo normal de desenvolvimento do exercício é melhorar sua solução
iterativamente, rodando `make test` depois de cada mudança, até que todos os testes passem.

Se você quiser rodar apenas um teste específico (enquanto se concentra naquela
parte da solução), adicione este par chave/valor a esse teste:

```yaml
  ONLY: true
```

Se você quiser pular testes específicos (enquanto trabalha em outras partes da
solução), adicione este par chave/valor a esses testes:

```yaml
  SKIP: true
```


## Pré-requisitos para os testes

No momento, o YAMLScript roda no MacOS e no Linux.

Seu computador vai precisar ter os seguintes comandos bem comuns instalados:

* `bash` - Você pode rodar os testes em qualquer shell, mas o `bash` precisa estar disponível.
* `make` - Você precisa usar o `make` do GNU para rodar os testes.
  Em alguns ambientes, ele pode ter um nome diferente de `make`.
  Talvez `gmake`.
* `prove` - Este programa faz parte de qualquer instalação normal do Perl.
* `curl` - Usado para instalar o ys se ele ainda não estiver instalado.

É muito provável que você já tenha todos esses programas instalados.
