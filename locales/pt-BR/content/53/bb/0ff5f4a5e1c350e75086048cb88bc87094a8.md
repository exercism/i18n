# Introdução

## Variáveis e atribuição

R é uma linguagem de tipagem dinâmica, então em geral não é necessário especificar o tipo de uma variável. O operador de atribuição preferido é `<-`

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

Usar `=` em vez de `<-` muitas vezes funciona, mas nem sempre, e é desaconselhado por ser um estilo ruim.
Se você estiver trabalhando no RStudio, dá para digitá-lo com o atalho de teclado `Alt-minus`.

Os operadores são em sua maioria convencionais, mas repare em `%/%` e `%%`:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

Em R, `#` inicia um comentário de uma linha só.
Não existe uma sintaxe separada para comentários de várias linhas.

## Funções

Para definir uma função:

```R
squareit <- function(x) {
    x * x
}
```

As funções podem ter zero ou mais argumentos, separados por vírgulas.
Os parênteses `()` são necessários com `function()`, mesmo que não haja parâmetros.

É possível especificar valores padrão para os argumentos de uma função, mas eles precisam vir depois de qualquer argumento sem valor padrão, e usamos `=` e não `<-` para atribuir o valor padrão.
Como um exemplo meio sem propósito:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

As chaves `{ }` não são estritamente necessárias para corpos de função de uma linha só, mas incluí-las é considerado um bom estilo.

O R retorna automaticamente o valor final de uma função, como nos exemplos acima.

`return()` pode ser usado em qualquer lugar dentro do corpo da função para deixar um valor de retorno explícito.

Chamar uma função é igual a muitas outras linguagens:

```R
squareit(3)
#> [1] 9
```
