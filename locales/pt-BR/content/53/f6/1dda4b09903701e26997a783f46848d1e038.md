# Testes

Para rodar os testes, execute o comando `sbt test` no diretório do exercício.
Veja a [página de testes](https://exercism.org/docs/tracks/scala/tests) para mais informações.

## Testes ignorados

No início, apenas o primeiro teste estará habilitado.
Isso é para incentivar você a resolver o exercício um passo de cada vez.
Quando você conseguir fazer o primeiro teste passar, remova a palavra-chave `pending` do início do próximo teste e trabalhe para fazer esse teste passar.
