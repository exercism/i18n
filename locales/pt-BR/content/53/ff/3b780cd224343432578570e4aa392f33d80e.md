# Sobre

Assim como a maioria das linguagens de programação, o Gleam tem "efeitos colaterais", então as funções podem ler e alterar o estado do mundo, além de retornar um valor.

O módulo `gleam/io` da biblioteca padrão do Gleam fornece funções para imprimir strings no console.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Outros pacotes podem fornecer outras funções de entrada e saída, como o `simplifile`, um pacote que fornece funções para ler e escrever arquivos.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
