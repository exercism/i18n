# Sobre

Ao percorrer uma sequência, às vezes o elemento sozinho não basta: você também precisa da posição. As palavras de iteração *indexada* do Factor fornecem tanto o elemento quanto o índice à quotation por elemento, com o índice no topo da pilha. `times` é a palavra relacionada para iteração com contagem sem uma sequência subjacente.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| palavra      | efeito                                                               |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, mas veja abaixo                             |

Uma sutileza sobre `times`: embora sua quotation esteja documentada como
`( -- )`, a palavra é `inline`, então uma quotation balanceada em efeito
como `( str -- str )` funciona bem e propaga a pilha entre as
iterações. Isso fornece um acumulador com contagem, sem nenhum
estado mutável:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

O mesmo truque funciona para `each-index` e `map-index`: o
efeito declarado por elemento é um *mínimo*, não um máximo.
