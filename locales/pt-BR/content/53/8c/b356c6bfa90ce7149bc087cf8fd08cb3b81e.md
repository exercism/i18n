# Instalação

## Instalando a Clojure CLI

O Clojure fornece ferramentas de linha de comando para: executar um REPL interativo (Read-Eval-Print Loop), executar programas Clojure e avaliar expressões Clojure.
Recomendamos que você use a Clojure CLI com os exercícios. Para instalar a [Clojure CLI](https://clojure.org/guides/deps_and_cli):

### Windows
Para instruções de instalação no Windows, veja: [Instalação da Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_windows).

### Linux
Para instruções de instalação na maioria das plataformas, veja: [Instalação da Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_linux).

### Homebrew para Mac OS X
Atualize o Homebrew:

``` bash
$ brew update
```

Instale a Clojure CLI:
``` bash
$ brew install node clojure/tools/clojure
```

O `Node` é necessário para o ambiente Node.

## Testando a instalação

Para testar se a instalação está correta, execute `clojure --help`; se tudo der certo, ele mostra a versão.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
