# Testes

Para rodar os testes desta trilha, você vai precisar instalar o DUnitX. Veja as instruções de [instalação](http://www.exercism.org/docs/tracks/delphi/installation) para mais informações.

### Carregando exercícios no Delphi

Se o Delphi estiver instalado corretamente e os arquivos `*.dpr` estiverem associados ao Delphi, um duplo clique no arquivo `*.dpr` fornecido abrirá o Delphi e carregará o exercício/projeto. `control + F9` é o atalho de teclado para compilar o projeto, ou pressionar `F9` compila e roda o projeto.

Como alternativa, você pode abrir o Delphi e carregar seu projeto pelo menu suspenso `File`.
