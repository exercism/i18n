# Anexo das instruções

## Registradores

| Registrador | Uso          | Tipo    | Descrição                            |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | entrada        | inteiro | número natural a ser fatorado     |
| `$a1`    | entrada/saída | endereço | array de destino para os fatores primos |
| `$v0`    | saída       | inteiro | número de fatores                   |
| `$t0-9`  | temporário    | qualquer     | usado para armazenamento temporário          |
