# Dicas

## General

- Todo laço aqui é controlado por um iterador, então nenhum deles precisa de uma variável contadora nem de um `until!`.
- A resposta sempre fica numa variável declarada antes do laço, porque qualquer coisa declarada dentro dele desaparece quando o laço termina.

## 1. O total

- `counts.elt!` dá uma contagem a cada iteração.
- Comece o total em `0`, o que também dá a resposta certa para uma pesquisa sem nenhum dia.

## 2. O melhor dia

- Guarde o melhor visto até agora numa variável, começando em `0`.
- A cada iteração, compare e substitua se este dia for melhor. `.max` faz a comparação numa única etapa: `best := best.max(counts.elt!)`.

## 3. Os dias movimentados

- Conte em vez de somar: `if counts.elt! > n then found := found + 1; end;`
- Pergunte ao iterador uma vez só, dentro da condição do `if`. Escrever `counts.elt!` duas vezes no mesmo corpo percorre o array duas vezes.

## 4. Esconderijos para verificar

- Aqui nada está sendo percorrido, então `elt!` não serve para nada. `1.upto!(days)` faz a contagem para você.
- `1.upto!(0)` não dá nada, que é a resposta certa para zero dias.

## 5. O primeiro dia movimentado

- A resposta é uma posição, não um valor, então percorra as posições: `i ::= 0.upto!(counts.size - 1)`.
- Comece a resposta em `-1`. Se nada for encontrado, é isso que já deve ser retornado.
- Assim que encontrar um dia, saia com `break!`. Caso contrário, um dia movimentado mais adiante sobrescreveria o primeiro.
