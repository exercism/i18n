# Instruções

Você faz parte de uma organização de bombeiros formada por voluntários internacionais.
Por causa da natureza internacional da equipe, um tempo valioso foi perdido nas últimas ocorrências convertendo entre Fahrenheit e Celsius enquanto estimavam a temperatura dentro dos prédios em chamas.
Para poupar tempo, e pessoas, você decide criar um programa que converta automaticamente entre Fahrenheit e Celsius para a sua equipe internacional.

## 1. Converta Fahrenheit para Celsius

Implemente a função `tempToC` para converter uma temperatura `Integer` em Fahrenheit para o `Float` equivalente em Celsius, arredondado para o centésimo mais próximo.
A temperatura em graus Celsius é definida como: T(°C) = (T(°F) - 32) / 1.8.

```haskell
> tempToC 32
0.00
```

## 2. Converta Celsius para Fahrenheit

Implemente a função `tempToF` para converter uma temperatura `Float` em Celsius para o equivalente em Fahrenheit.
Por questões de segurança, **arredonde para cima** o resultado para o `Integer` **imediatamente superior**.
A temperatura em graus Fahrenheit é definida como: T(°F) = T(°C) × 1.8 + 32.

```Haskell
> tempToF 4
40
```
