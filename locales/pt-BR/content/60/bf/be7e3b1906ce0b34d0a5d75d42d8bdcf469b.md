# Introdução

Um **Map** é uma estrutura de dados para armazenar pares de chave e valor.
Ele é parecido com os dicionários de outras linguagens de programação.
A interface [Map][map-javadoc] define as operações sobre um map.

O Java tem várias implementações diferentes de Map.
O [HashMap][hashmap-javadoc] é uma das mais usadas.

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

Adicione entradas ao map com [put][map-put-javadoc].

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

Cada chave só pode estar associada a um valor.
Chamar `put` com a mesma chave atualiza o valor daquela chave.

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

Use [get][map-get-javadoc] para obter o valor de uma chave.

```java
fruitPrices.get("apple"); // => 100
```

Use [containsKey][map-containskey-javadoc] para verificar se o map contém determinada chave.

```java
fruitPrices.containsKey("apple");   // => true
fruitPrices.containsKey("orange");  // => false
```

Remova entradas com [remove][map-remove-javadoc].

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

O método [size][map-size-javadoc] retorna o número de entradas.

```java
fruitPrices.size();  // Returns 2
```

Você pode usar os métodos [keySet][map-keyset-javadoc] ou [values][map-values-javadoc] para obter as chaves ou os valores de um Map como um Set ou uma coleção, respectivamente.

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
