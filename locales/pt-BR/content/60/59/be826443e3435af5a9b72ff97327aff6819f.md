# Testes

Se você tiver o binário do phix no PATH, digite o comando:

```bash
p test 
```
Isso vai rodar o arquivo de teste (test.exw).

Se o binário do phix não estiver no PATH, no Windows digite

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem.
Por padrão, todos os testes do arquivo test.exw são executados.
Para ignorar um teste, coloque dois traços (o marcador de comentário padrão do Phix) no início da linha.

Observe que os testes não respeitam nenhuma flag `include=false` no `tests.toml`; é responsabilidade
de quem escreve o test.exw mantê-las manualmente nesse arquivo para refletir a realidade em benefício
do site do Exercism (por exemplo, para coletar estatísticas da track), mas nada na própria track faz
uso delas, incluindo especificamente o gerador de testes e o executor de testes.
