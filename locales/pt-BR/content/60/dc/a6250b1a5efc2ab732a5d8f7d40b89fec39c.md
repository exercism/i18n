# Sobre

O Batch scripting é uma linguagem de script usada principalmente para executar comandos no Prompt de Comando do Windows (cmd.exe).
Ela permite automatizar tarefas, gerenciar arquivos e controlar o ambiente do sistema por meio de uma série de instruções de linha de comando.

Embora o Batch scripting seja simples, ele consegue dar conta de uma ampla variedade de tarefas, de operações simples com arquivos a processos de automação mais complexos.

Os arquivos Batch têm extensão `.bat` ou `.cmd` e podem ser executados diretamente pelo interpretador de comandos do Windows.

A flexibilidade do Batch scripting faz dele uma ferramenta poderosa para administradores de sistemas, desenvolvedores e usuários avançados que precisam automatizar tarefas rotineiras ou criar ferramentas de linha de comando personalizadas.
