# Dicas

## General

- Leia sobre [erros][errors] no guia Getting Started.
- Leia sobre [`try`][docs-try] na documentação.

## 1. Warn the team

- Deixe a função de operação lançar o próprio erro.
- Para invocar uma função guardada em uma variável, use o operador `.`.

## 2. Wrap the error

- Use try .. rescue para retornar o resultado esperado.

## 3. Pass on the message

- Use try .. rescue para retornar o resultado esperado.
- O bloco rescue permite fazer pattern matching com o nome do módulo do erro e também vincular o erro a uma variável.
