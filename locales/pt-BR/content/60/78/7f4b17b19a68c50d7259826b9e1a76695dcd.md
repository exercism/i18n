# Dicas

## Geral

- Leia a documentação oficial sobre [intervalos][range].

## 1. Defina o intervalo das fileiras

- Existe um [operador especial][range-creation-operator] para criar intervalos.

## 2. Defina o intervalo das colunas

- Existe um [operador especial][range-creation-operator] para criar intervalos.
- Existe uma [sintaxe especial][unicode-code-points] para escrever o ponto de código de um caractere sem saber explicitamente o valor dele.

## 3. Transforme o intervalo das fileiras em uma lista de fileiras

- Os intervalos implementam o protocolo `Enumerable`.
- Existe uma [função integrada][enum-to-list] para transformar uma estrutura de dados enumerável em uma lista.

## 4. Transforme o intervalo das colunas em uma lista de colunas

- Os intervalos implementam o protocolo `Enumerable`.
- Existe uma [função integrada][enum-map] para transformar uma estrutura de dados enumerável em uma lista enquanto modifica os elementos dela.
- A [forma especial de bitstring][bitstring-special-form] pode ser usada para transformar um ponto de código em uma string.
