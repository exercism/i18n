# Dicas

## Geral

- As palavras de leitura ficam em [`io`][io]; os construtores de stream de
  string e `with-string-writer` ficam em
  [`io.streams.string`][io.streams.string].
- Para a tarefa de esvaziar o writer, as variáveis locais (`::` e `:>`) mantêm
  o corpo legível quando você precisa mexer no mesmo stream duas vezes.

## 1. Ouça tudo

- Uma palavra: `stream-contents`.

## 2. Conte as mensagens

- `stream-lines` divide o stream em um array de linhas;
  `length` retorna a contagem.

## 3. Repita a última chamada

- O mesmo `stream-lines` de antes, depois `last`, depois `>upper` (de
  `ascii`).

## 4. Transmita uma mensagem

- `stream-write` escreve a mensagem e `stream-flush` a envia para
  fora. O writer é usado duas vezes, então recorra às variáveis locais `::`:
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. Capture a saída de uma quotation

- Uma palavra: `with-string-writer`. Adicione `inline` depois do `;`
  de fechamento para que o compilador consiga enxergar através do
  argumento de quotation:
  `: capture ( quot -- captured ) with-string-writer ; inline`.
