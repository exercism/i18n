# Instruções

Neste exercício, você vai escrever código para ajudar um freelancer a se comunicar com os clientes sobre os preços de determinados projetos. Você vai escrever algumas funções utilitárias para calcular rapidamente os custos dos clientes.

## 1. Calcule o valor diário a partir do valor por hora

Um cliente entra em contato com o freelancer para perguntar sobre seus valores.
O freelancer explica que **_trabalha 8 horas por dia._**
No entanto, o freelancer conhece apenas o valor por hora do projeto.
Ajude o freelancer a estimar o valor diário a partir do valor por hora.

Implemente a função `dailyRateFrom(hourlyRate:)`, que recebe o argumento `hourlyRate`, que contém o valor por hora do freelancer.  
A função deve retornar o valor diário com base no valor por hora.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

O valor diário retornado deve ser um `Double`.

## 2. Calcule o valor mensal a partir do valor por hora e de um desconto

Às vezes, um cliente tem interesse em contratar o freelancer por um período mais longo.
O freelancer está disposto a dar um desconto ao cliente, mas apenas se o cliente o contratar por pelo menos um mês.
No total, são **_22 dias úteis_**.
Ajude o freelancer a calcular o valor mensal a partir do valor por hora e da porcentagem de desconto sobre o valor fixo que ele está disposto a oferecer, arredondado para o número inteiro mais próximo.

Implemente a função `monthlyRateFrom(hourlyRate:withDiscount:)`, que recebe os argumentos `hourlyRate`, que contém o valor por hora do freelancer, e `withDiscount`, que contém o desconto que o freelancer está disposto a dar ao cliente.
A função deve retornar o valor mensal arredondado para o número inteiro mais próximo.

```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

## 3. Calcule o número de dias úteis a partir de um orçamento, do valor por hora e de um desconto

Em outro dia, um gerente de projetos oferece ao freelancer a oportunidade de trabalhar em um projeto com orçamento fixo.
Dados o orçamento fixo e o valor por hora do freelancer, ajude o freelancer a calcular o número de dias que trabalharia até o orçamento acabar.
Leve em conta que, nesse cenário, o freelancer sempre está disposto a dar o desconto, independentemente do número de dias contratados.
O resultado _deve_ ser **arredondado para baixo** para o número inteiro mais próximo.

Implemente a função `workdaysIn(budget:hourlyRate:withDiscount:)`, que recebe os argumentos:
- `budget`, que contém o orçamento do projeto.
- `hourlyRate`, que contém o valor por hora do freelancer.
- `withDiscount`, que contém o desconto que o freelancer está disposto a dar ao cliente.

A função deve retornar o número de dias úteis que o freelancer vai trabalhar no projeto, arredondado para baixo.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
