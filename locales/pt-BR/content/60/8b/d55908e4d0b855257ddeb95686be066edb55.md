# Introdução

Um [`Attribute` do C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) oferece uma forma de decorar uma declaração para associar metadados a: uma classe, um método, um enum, um campo, uma propriedade ou qualquer [outra declaração compatível](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Você pode aplicar um atributo adicionando-o na linha anterior à declaração, usando um `ClassAttribute` e um `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Esses metadados declarativos apenas associam informações estruturadas adicionais ao código e não modificam seu comportamento. No entanto, outras partes do código usam esses metadados para mudar como o alvo se comporta, ou para adicionar, alterar, remover ou restringir algumas de suas funcionalidades.

Existem muitos [atributos predefinidos e reservados](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), por exemplo: `Flags`, `Obsolete`, `Conditional`, e cada um tem uma finalidade específica que pode ser consultada na documentação do C#. Repare que o nome completo de um atributo como [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) é `FlagsAttribute`, por convenção, mas o sufixo _Attribute_ pode ser omitido quando ele é aplicado a uma declaração.
