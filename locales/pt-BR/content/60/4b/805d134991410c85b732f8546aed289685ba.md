# Sobre

Enumeração é o ato de percorrer uma coleção (`Array`, `Hash`, etc.) e realizar alguma ação em cada objeto.

A enumeração é um conceito fundamental no Ruby e é usada para ordenar (`sort_by`), agrupar (`group_by`), mapear (`map`), reduzir (`reduce`) e muito mais.
Você vai encontrar a enumeração com mais frequência como a maneira idiomática de iterar sobre coleções, em vez de usar laços.

Uma enumeração simples para imprimir cada palavra de um array ficaria assim:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

Neste exemplo, chamamos o método `Array#each` e passamos um _bloco_, que recebe um parâmetro (`word`) e o imprime.

Também podemos encadear métodos enumeráveis.
Por exemplo, podemos encadear `.with_index` em `each` para imprimir o índice de um objeto, além do seu valor:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

Enumerar objetos `Hash` é exatamente o mesmo que enumerar objetos `Array`, exceto que o bloco recebe dois argumentos: a chave e o valor:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

Os métodos descritos acima fazem parte do [módulo `Enumerable`][enumerable-module], que está incluído em `Array`, `Hash` e outras classes que precisam da capacidade de enumerar.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
