# Palavras-chave estáticas de classe

Uma classe é uma unidade de organização de código em PHP, e muitas vezes representa uma instância de uma coisa, um serviço ou um procedimento.
Com as palavras-chave `static` e `self`, propriedades e métodos podem existir em referência à classe para todas as instâncias (ou para nenhuma).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limitação

Métodos estáticos de classe só podem chamar outras propriedades estáticas ou métodos estáticos da própria classe.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
