# Dicas

## Geral

- O preço de um item é o segundo elemento do seu array de dois elementos.
  `second`, em [`sequences`][sequences], lê esse elemento.
- Palavras de ordem superior como `filter`, `count`, `sort-by` e `map-sum`
  recebem uma *quotation* (código entre colchetes `[ ]`) como segundo
  argumento.

## 1. Ordene o inventário por preço

- `sort-by` (em [`sorting`][sorting]) recebe uma sequência e uma quotation
  que retorna uma chave ordenável para cada elemento.

## 2. Encontre os itens sem preço definido

- Um preço ausente é `f`. `f` também é o único valor falso de Factor, então
  `[ second not ] filter` mantém os itens cujo preço é `f`.
- `[ second ] reject` faz o mesmo de forma inversa.

## 3. Conte os itens caros

- `count` executa o predicado em cada elemento e conta quantos correspondem.

## 4. Encontre o item mais barato

- `minimum-by` (em [`sequences`][sequences]) retorna o elemento cuja chave
  extraída é a menor.

## 5. Some todos os preços

- `map-sum` (em [`sequences`][sequences]) aplica uma quotation a cada
  elemento da sequência e soma os resultados.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
