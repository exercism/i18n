# Apêndice das instruções

Você deve implementar este exercício usando uma gramática de cláusulas definidas (DCG).
As DCGs podem ser usadas não só para analisar sequências (listas), mas também para gerar, completar e verificar essas sequências.

## Biblioteca

Os arquivos stub de implementação incluem a seguinte linha:

```prolog
:- use_module(library(dcg/basics)).
```

Isso garante que a biblioteca `dcg/basics` possa ser usada, o que deve ser suficiente para resolver este exercício.
