# Ordem das anotações de função

Por convenção, as anotações de função `@doc` devem vir antes das anotações de função `@spec`, e as anotações de função `@spec` devem vir imediatamente antes da função. Se a função tiver várias cláusulas, as anotações de função devem vir antes da primeira cláusula.

Exemplo:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
