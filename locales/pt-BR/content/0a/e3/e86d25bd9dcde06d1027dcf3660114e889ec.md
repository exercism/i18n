# Instruções

Neste exercício, você vai implementar a lógica de missão de um novo jogo de RPG que um amigo está desenvolvendo. A personagem principal do jogo é Annalyn, uma garota corajosa com um cachorro de estimação fiel e feroz. Infelizmente, o desastre acontece: seu melhor amigo foi sequestrado enquanto procurava frutas silvestres na floresta. Annalyn vai tentar encontrar e libertar seu melhor amigo, podendo levar o cachorro com ela nessa missão.

Depois de um tempo seguindo o rastro de seu melhor amigo, ela encontra o acampamento onde ele está preso. Acontece que há dois sequestradores: um cavaleiro poderoso e um arqueiro astuto.

Tendo encontrado os sequestradores, Annalyn considera quais das ações a seguir ela pode realizar:

- Ataque rápido: um ataque rápido pode ser feito se o cavaleiro estiver dormindo, pois ele leva tempo para vestir a armadura e ficará vulnerável.
- Espionar: o grupo pode ser espionado se pelo menos um deles estiver acordado. Caso contrário, espionar é perda de tempo.
- Sinalizar para o prisioneiro: pode-se sinalizar para o prisioneiro usando sons de pássaros se o prisioneiro estiver acordado e o arqueiro estiver dormindo, pois arqueiros são treinados em sinais com pássaros e poderiam interceptar a mensagem.
- _Libertar o prisioneiro_: Annalyn pode tentar se esgueirar até o acampamento para libertar o prisioneiro.
  Isso é arriscado e só pode dar certo de uma de duas formas:
  - Se Annalyn estiver com o cachorro, ela pode resgatar o prisioneiro se o arqueiro estiver dormindo.
    O cavaleiro tem medo do cachorro e o arqueiro não terá tempo de se preparar antes que Annalyn e o prisioneiro consigam escapar.
  - Se Annalyn não estiver com o cachorro, ela e o prisioneiro precisarão ser muito furtivos!
    Annalyn pode libertar o prisioneiro se o prisioneiro estiver acordado e o cavaleiro e o arqueiro estiverem dormindo, mas se o prisioneiro estiver dormindo não dá para resgatá-lo: o prisioneiro se assustaria com o aparecimento repentino de Annalyn e acordaria o cavaleiro e o arqueiro.

Você tem quatro tarefas: implementar a lógica para determinar se as ações acima estão disponíveis com base no estado dos três personagens encontrados na floresta e na presença ou não do cachorro de Annalyn.

## 1. Verificar se a ação 'Ataque rápido' é possível

Implemente uma função chamada `canExecuteFastAttack` que recebe um valor Boolean que indica se o cavaleiro está acordado. Essa função retorna `true` se a ação 'Ataque rápido' estiver disponível com base no estado do personagem. Caso contrário, retorna `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. Verificar se a ação 'Espionar' é possível

Implemente uma função chamada `canSpy` que recebe três valores Boolean, indicando se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados. A função retorna `true` se a ação 'Espionar' estiver disponível com base no estado dos personagens. Caso contrário, retorna `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. Verificar se a ação 'Sinalizar para o prisioneiro' é possível

Implemente uma função chamada `canSignalPrisoner` que recebe dois valores Boolean, indicando se o arqueiro e o prisioneiro, respectivamente, estão acordados. A função retorna `true` se a ação 'Sinalizar para o prisioneiro' estiver disponível com base no estado dos personagens. Caso contrário, retorna `false`:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. Verificar se a ação 'Libertar o prisioneiro' é possível

Implemente uma função chamada `canFreePrisoner` que recebe quatro valores Boolean. Os três primeiros parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados. O último parâmetro indica se o cachorro de Annalyn está presente. A função retorna `true` se a ação 'Libertar o prisioneiro' estiver disponível com base no estado dos personagens e na presença do cachorro de Annalyn. Caso contrário, retorna `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
