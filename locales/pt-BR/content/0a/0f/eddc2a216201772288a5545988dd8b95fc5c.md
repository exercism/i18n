# não use o método `main`

Experimente remover o método `main` do seu código.
Os testes do exercício não exigem que as soluções tenham um método `main`, e ter um deixa o código um pouco mais difícil de ler.

Normalmente, um método `main` é adicionado para ajudar a fazer debug do código.
No entanto, uma abordagem melhor é fazer debug do código enquanto roda um ou mais testes unitários.
Isso tem a vantagem adicional de permitir focar no debug de um caso de teste específico.

Aqui estão alguns links que explicam como fazer debug de código Java enquanto roda testes unitários em várias IDEs:

- [Rodando e fazendo debug de testes Java no Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Fazendo debug de testes no IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
