# Instruções

Determine se um triângulo é equilátero, isósceles ou escaleno.

Um triângulo _equilátero_ tem os três lados com o mesmo comprimento.

Um triângulo _isósceles_ tem pelo menos dois lados com o mesmo comprimento. (Às vezes
define-se que ele tem exatamente dois lados com o mesmo comprimento, mas, para os fins
deste exercício, vamos dizer pelo menos dois.)

Um triângulo _escaleno_ tem todos os lados com comprimentos diferentes.

## Observação

Para que uma forma seja um triângulo, todos os lados precisam ter comprimento > 0, e
a soma dos comprimentos de dois lados quaisquer deve ser maior ou igual ao
comprimento do terceiro lado. Veja [Desigualdade triangular](https://en.wikipedia.org/wiki/Triangle_inequality).

## Aprofunde-se

O caso em que a soma dos comprimentos de dois lados é _igual_ à do
terceiro é conhecido como triângulo _degenerado_: ele tem área zero e parece
uma única linha. Sinta-se à vontade para adicionar seu próprio código/testes para verificar triângulos degenerados.
