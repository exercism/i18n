# Introdução

Um tipo é um _tipo genérico_ quando pode conter valores de qualquer tipo usando um _parâmetro de tipo_.

Por exemplo, este tipo `Box` tem o parâmetro de tipo `a` (escrito com letras minúsculas).

```gleam
pub type Box(a) {
  Box(a)
}
```

O parâmetro de tipo `a` é um espaço reservado para qualquer tipo, então `Box` pode ser usado com strings, inteiros ou qualquer outro tipo.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

Um tipo pode ter vários parâmetros de tipo, separando-os com vírgulas.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## Funções genéricas

Parâmetros de tipo também podem ser usados nos argumentos de funções.

Esta função recebe um valor do tipo `a` e chama duas vezes uma função que recebe um `a` e retorna um `b`.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
