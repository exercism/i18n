# Introdução

O tipo booleano em Lua tem os dois valores tradicionais: `true` e `false`. Esses valores podem ser atribuídos a uma variável, combinados com operadores lógicos (`and`, `or`, `not`) e usados em testes condicionais (por exemplo, em estruturas de controle).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

Testes condicionais e os operadores lógicos consideram tanto o valor Boolean `false` quanto `nil` como falso, e qualquer outra coisa como verdadeiro.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Tanto `and` quanto `or` usam *avaliação de curto-circuito*, ou seja, avaliam o segundo operando apenas quando necessário. Todas as operações são avaliadas de acordo com a [precedência de operadores](https://www.lua.org/manual/5.4/manual.html#3.4.8), em que `not` é avaliado antes de `and` e `or`.
