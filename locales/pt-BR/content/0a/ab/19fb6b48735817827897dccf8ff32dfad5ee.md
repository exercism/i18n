# Dicas

## Geral

- `*T` pode ser usado para declarar variáveis que são ponteiros para algum tipo `T`, por exemplo `var i *int` declara uma variável `i` que é um ponteiro para um `int`
- Você pode obter um ponteiro para uma variável (seu endereço de memória) usando o operador `&`, por exemplo `mypointer := &anIntVariable`.
- Você pode obter o valor armazenado em um ponteiro usando o operador `*` em um ponteiro, por exemplo `var i int = *aPointerToInt`.
  Isso se chama desreferenciar o ponteiro.
- Verifique se um ponteiro não é `nil` antes de desreferenciá-lo.
  Tentar desreferenciar um ponteiro `nil` vai gerar um erro em tempo de execução.
- Se você não tem certeza de como ponteiros funcionam, tente ler [Tour of Go: Pointers][go-tour-pointers] ou [Go by Example: Pointers][go-by-example-pointers]

## 1. Crie um contador de votos

- Você precisa criar um ponteiro para um `int`, em outras palavras, um `*int`.
- Você pode usar o operador `&` em uma variável para criar um ponteiro para ela, por exemplo `&myInt`
- Você pode criar um ponteiro para uma nova variável definida por você ou pode usar a variável do argumento da função

## 2. Obtenha o número de votos de um contador

- Você pode usar o operador `*` em um ponteiro para desreferenciá-lo e obter seu valor, por exemplo `*myPointer`
- Desreferenciar ponteiros `nil` vai gerar um erro em tempo de execução.
  Sempre verifique se um ponteiro não é `nil` antes de desreferenciá-lo.

## 3. Incremente os votos de um contador

- Se você tem um ponteiro `var myPointer *int`, pode atribuir a `*myPointer` para mudar o valor apontado por `myPointer`
- Para obter o valor atual do ponteiro, você precisa desreferenciá-lo usando o operador `*`, ou chamar a função que você fez na tarefa anterior.

## 4. Crie os resultados da eleição

- Crie um literal ou uma variável `ElectionResult` nova com os campos `Name` e `Votes` preenchidos com os valores nos argumentos da função.
- Você pode criar um ponteiro a partir de uma variável ou de um literal usando o operador `&` antes do nome da variável/do literal, por exemplo `&myVariable` ou `&ElectionResult{Name: "John", Votes: 1}`

## 5. Anuncie os resultados

- Embora você esteja recebendo um ponteiro para um `ElectionResult`, você pode acessar seus campos com a notação de ponto `.`, como se ele não fosse um ponteiro!
- Construa a mensagem acessando os campos `Name` e `Value` na struct.
- Mesmo que você esteja acessando campos de um ponteiro para uma struct, você não precisa fazer nenhuma desreferência.
  O Go vai desreferenciar o ponteiro automaticamente para você, como neste exemplo:

```go
result := &ElectionResult{
    Name: "John",
    Votes: 32
}

result.Name // "John" - Go will automatically dereference the pointer
            //          and access the 'Name' field of the dereferenced struct 
```

## 6. Recontagem de votos

- Você pode pensar em mapas como se já fossem ponteiros.
  Isso significa que as mudanças que você faz no mapa dentro da função serão visíveis fora da função.
- Para incrementar o valor de uma chave em um `var m map[string]int`, você tem várias opções: `m["mykey"] = m["mykey"] + 1`, `m["mykey"] += 1` ou `m["mykey"]++`.
