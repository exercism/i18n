O objetivo deste exercício é melhorar o exercício Verificador de Senhas.
Como é provável que uma senha viole mais de uma regra ao mesmo tempo, um verificador de senhas útil deve informar todas as regras que foram violadas, e não apenas a primeira que for encontrada.
O verificador de senhas melhorado deve indicar de uma só vez todas as regras violadas por uma senha.

As regras deste verificador de senhas são as mesmas do exercício Verificador de Senhas anterior:

- Deve ter 12 caracteres ou mais
- Deve ter pelo menos uma letra maiúscula
- Deve ter pelo menos uma letra minúscula
- Deve ter pelo menos um dígito
- Deve ter pelo menos um símbolo do conjunto !@#$%^&\*

## 1. Modifique a união discriminada `PasswordError` para permitir que os valores individuais sejam tratados como flags

Observe que os testes não vão compilar enquanto este passo essencial não estiver completo.

## 2. Implemente a função `checkPassword`

A função `checkPassword` verifica a senha fornecida em relação às regras mencionadas acima.
A função deve retornar um valor `Result`, em que `Ok` é retornado quando a senha satisfaz todas as regras, e um valor `Error` quando ela falha em uma ou mais regras.
Se a senha falhar em várias regras, o valor `PasswordError` deve representar todas as regras que falharam.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. Implemente a função ``getStatusPhrases`

A função `getStatusPhrases` retorna um conjunto de strings, cada uma contendo uma frase legível para humanos correspondente a um dos erros no resultado retornado por `checkPassword`.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
