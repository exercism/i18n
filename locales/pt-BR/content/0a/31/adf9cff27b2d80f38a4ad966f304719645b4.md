# Dicas

## 5. Substitua o treinador

- A sintaxe de atualização de registro pode ser usada para criar uma cópia de um registro, mas com um ou mais campos com um novo valor.

## 6. Verifique se é o mesmo time

- Os registros têm igualdade estrutural embutida: registros com os mesmos valores são iguais.

## 7. Verifique se você deve torcer por um time

- A melhor forma de executar uma lógica com base no valor do time é usar uma expressão `case`.
- Se você quiser adicionar uma condição a um padrão, pode usar uma guarda.
- A correspondência de padrões funciona com registros dentro de registros.
