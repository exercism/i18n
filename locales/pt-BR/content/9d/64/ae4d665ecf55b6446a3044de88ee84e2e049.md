# Anexo às instruções

## Implementação

Para completar este exercício, você precisa implementar a struct definindo o tipo de dados `school` e implementando as funções:

- newSchool
- add
- roster
- grade

O capítulo 3 de [Notes on Programming SML/NJ][notes] discute o uso de assinaturas e structs.
