# Aprendizado

- [The Zig Programming Language Documentation][documentation] é uma ótima visão geral de todos os recursos da linguagem que o Zig oferece para quem a usa.
- [Awesome Zig][awesome-zig] é uma boa coleção de projetos Zig feitos por várias pessoas.
  A coleção reúne projetos com código Zig bem desenvolvido.
- [Zighelp][zighelp] é um excelente guia introdutório que explica os recursos da linguagem que o Zig tem a oferecer.
- [Ziglings][ziglings] é altamente recomendado.
  Aprenda Zig corrigindo pequenos programas quebrados.
- [Zig SHOWTIME][zig-showtime] é um programa transmitido ao vivo, no qual membros da comunidade Zig compartilham código e ideias.

[awesome-zig]: https://github.com/catdevnull/awesome-zig
[documentation]: https://ziglang.org/documentation/master/
[zighelp]: https://zighelp.org/
[zig-showtime]: https://zig.show/
[ziglings]: https://codeberg.org/ziglings/exercises
