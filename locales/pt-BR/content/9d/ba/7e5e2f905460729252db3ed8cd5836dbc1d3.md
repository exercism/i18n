# Apêndice das instruções

## Definindo um tipo indutivo

Este exercício espera que o valor de retorno seja um [tipo indutivo][inductive] `Classification` que você deve definir.

Esse tipo deve ter uma instância de [BEq][beq], ou seja, ele admite um teste de igualdade Boolean, e uma instância de [Repr][repr], ou seja, valores do tipo podem ser formatados para exibição.

Você pode consultar [esta página][instance] sobre declarações de instância.
O Lean pode [gerar instâncias][deriving] automaticamente para muitas classes.

## Subtipos

O argumento da função `classify` é um [subtipo][subtype] chamado `Positive`:

```
def Positive := { x : Nat // x > 0 }
```

Subtipos representam elementos de um determinado tipo que satisfazem um predicado.
`Positive` representa elementos de `Nat` que são maiores que `0`.

Qualquer elemento de um subtipo pode ser visto como um par formado por um valor do tipo subjacente e uma prova, no sentido matemático, de que esse valor satisfaz o predicado correspondente.

Subtipos impõem invariantes no nível do tipo, garantindo que valores mal formados não possam ser construídos.
