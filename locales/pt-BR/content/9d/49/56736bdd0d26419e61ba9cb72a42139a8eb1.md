# Dicas

## 1. Recupere uma carta de uma pilha

- Os índices de `Vector` começam em `1`.
- Você pode recuperar o valor de índice `n` de um vetor `v` com `v[n]`.

## 2. Troque uma carta na pilha

- Os `Vector`s são mutáveis: você pode alterar o conteúdo deles a qualquer momento atribuindo um novo valor.

## 3. Insira uma carta no topo da pilha

- Existe um método [`push!`][push] em Base para adicionar um novo valor ao final de uma coleção.

## 4. Remova uma carta da pilha

- Existe um método [`deleteat!`][deleteat] em Base para excluir um elemento de um `Vector` em um determinado índice.

## 5. Remova a carta do topo da pilha

- Existe um método [`pop!`][pop] em Base para remover um elemento no final de uma coleção.

## 6. Insira uma carta no fundo da pilha

- Existe um método [`pushfirst!`][pushfirst] em Base para inserir um novo valor no início de uma coleção.

## 7. Remova uma carta do fundo da pilha

- Existe um método [`popfirst!`][popfirst] em Base para remover um elemento no início de uma coleção.

## 8. Verifique o tamanho da pilha

- Existe um método [`length`][length] em Base para obter o comprimento de uma coleção.
