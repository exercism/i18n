# Introdução

## Casting

Casting e conversão de tipos são formas diferentes de transformar uma expressão de um tipo de dado em outro.

Uma expressão pode receber um cast para outro tipo com o operador de cast `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Se os tipos não forem compatíveis, uma instância de `InvalidCastException` é lançada. No caso de números, isso indica que o tipo de destino não consegue representar o valor convertido. No caso de classes, um dos tipos precisa derivar do outro (o que também vale, trivialmente, para structs).

Uma alternativa ao _casting_ é a _conversão de tipos_, usando o operador `is`. Normalmente ela é aplicada a tipos de referência e a tipos anuláveis.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Se você precisar detectar o tipo exato de um objeto, o `is` pode ser um pouco permissivo demais, porque ele retornará true para uma classe e para quaisquer classes e interfaces das quais ela derive direta ou indiretamente. Nesse caso, `typeof` e `Object.GetType()` são a solução.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
