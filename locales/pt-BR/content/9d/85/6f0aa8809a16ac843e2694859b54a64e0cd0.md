# Instruções

Neste exercício, você vai escrever código para ajudar uma empresa de placas a criar mensagens personalizadas para suas placas.

## 1. Crie um conjunto de strings úteis

Defina as seguintes strings constantes que serão usadas para criar placas:

- `birthday`: guarda o valor "Birthday"
- `valentine`: guarda o valor "Valentine's Day"
- `anniversary`: guarda a string "Anniversary"

## 2. Crie um conjunto de caracteres úteis

Defina os seguintes caracteres constantes que serão usados para criar placas:

- `space`: guarda o valor " " (um único espaço)
- `exclamation`: guarda o valor "!"

## 3. Combine frases para montar mensagens

Implemente a função `buildSign(for:name:)`, que recebe o argumento `for`, que guarda uma das três strings definidas na primeira tarefa, e o argumento `name`, que é uma string que guarda o nome da pessoa para quem a placa é destinada.
Você deve usar concatenação para montar a mensagem da placa e lembre-se de reutilizar as constantes já definidas.
A função deve retornar a mensagem da placa como uma string.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Crie uma placa de formatura

Implemente a função `graduationFor(name:year:)`, que recebe o argumento `name`, que é uma string que guarda o nome da pessoa para quem a placa é destinada, e o argumento `year`, que é um inteiro que guarda o ano em que a pessoa se forma.
Você deve usar template strings para montar a mensagem da placa.
A função deve retornar a mensagem da placa como uma string.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Calcule o custo de uma placa

Implemente a função `costOf(sign:)`, que recebe o argumento `sign`, que é uma string que guarda a mensagem da placa.
A placa tem um preço base de 20 na moeda em questão. Além disso, cada letra custa 2 (os espaços em branco entram no cálculo).
A função deve retornar o custo da placa como um inteiro.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
