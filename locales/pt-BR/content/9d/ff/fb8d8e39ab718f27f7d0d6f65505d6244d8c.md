# Apêndice de instruções

A saída deve estar organizada em [ordem row-major](https://en.wikipedia.org/wiki/Row-_and_column-major_order): todas as palavras da primeira linha, depois as palavras da segunda linha, e assim por diante.

## Registradores

| Registrador | Uso          | Tipo    | Descrição                           |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | entrada        | inteiro | tamanho                             |
| `$a1`    | entrada/saída | endereço | matriz de palavras, em ordem row-major |
| `$v0`    | saída       | inteiro | número de palavras na matriz        |
| `$t0-9`  | temporário    | qualquer | para armazenamento temporário       |
