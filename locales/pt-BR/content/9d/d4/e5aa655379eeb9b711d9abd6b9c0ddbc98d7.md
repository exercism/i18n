# Instruções

Neste exercício, você vai implementar uma forma de acompanhar as melhores pontuações do jogo mais popular do fliperama da sua região.

## 1. Adicionar jogadores ao placar de recordes

Para adicionar um jogador ao placar de recordes, defina dois métodos `add_player!` que recebem os seguintes argumentos:

- O primeiro argumento é o dicionário de pontuações.
- O segundo argumento é o nome de um jogador, como uma string.
- O terceiro argumento é a pontuação, como um número inteiro.
  Esse argumento é opcional. Quando nenhum valor for informado, a pontuação deve ser definida como 0.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Remover jogadores do placar

Para remover um jogador do placar de recordes, defina `remove_player!`, que recebe 2 argumentos:

- O primeiro argumento é o dicionário de pontuações.
- O segundo argumento é o nome do jogador, como uma string.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Atualizar a pontuação de um jogador

Para atualizar a pontuação de um jogador substituindo a pontuação anterior, defina `update_score!`, que recebe 3 argumentos:

- O primeiro argumento é o dicionário de pontuações.
- O segundo argumento é o nome do jogador, como uma string, cuja pontuação você deseja atualizar.
- O terceiro argumento é a pontuação que você deseja definir como a pontuação armazenada.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Redefinir a pontuação de um jogador

Para redefinir a pontuação de um jogador, defina `reset_score!`, que recebe 2 argumentos:

- O primeiro argumento é o dicionário de pontuações.
- O segundo argumento é o nome do jogador, como uma string, cuja pontuação você deseja redefinir.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. Obter uma lista de jogadores

Para obter uma lista de jogadores, defina `players`, que recebe 1 argumento:

- O primeiro argumento é o dicionário de pontuações.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
