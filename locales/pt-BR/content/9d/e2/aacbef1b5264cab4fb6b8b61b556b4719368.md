# Testes

Um REPL de Clojurescript permite rodar código com facilidade e receber feedback imediato, e também pode ser usado para rodar testes.

## Leiningen
Para abrir um REPL usando a CLI do Clojure, vá até o diretório que contém o exercício e rode:
``` bash
$ clojure -m cljs.main -re node
```

Repare que o Node precisa estar instalado no seu sistema.

Quando você estiver pronto para trabalhar em um exercício e tiver criado um arquivo para guardar sua solução (como `bob.cljs`), você pode rodar os testes no seu terminal com `$ clojure -A:test`.

Primeiro, faça o `require` do namespace de teste:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Mude o ns para o namespace de teste:
```clojure
=> (ns bob-test)
nil
```

Depois, chame `run-tests` em `bob-test`:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Para rodar os testes de um exercício com a CLI do Clojure, basta chamar:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
