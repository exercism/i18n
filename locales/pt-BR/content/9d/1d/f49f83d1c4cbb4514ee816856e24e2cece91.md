# sem alias de tipo para Stopwatch

Neste exercício, a ideia é que você defina `Stopwatch` como um tipo opaco.
Usar `type alias Stopwatch` define `Stopwatch` como um alias de tipo, o que expõe a estrutura interna.
Em vez disso, use `type Stopwatch` para esconder a estrutura interna e impedir que outros módulos desconstruam ou atualizem diretamente valores de `Stopwatch`.
