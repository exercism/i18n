# Introdução

Às vezes você precisa enxergar uma sequência como uma série de *partes*, e não elemento por elemento. Os vocabulários [`grouping`][grouping], [`splitting`][splitting] e [`splitting.monotonic`][splitting.monotonic] dão quatro maneiras de fazer isso.

## `group`: blocos disjuntos de tamanho *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

Se o comprimento da sequência não for múltiplo de *n*, o último bloco fica menor que *n*.

## `clump`: janela deslizante sobreposta de tamanho *n*

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

Se a sequência for menor que *n*, o resultado é vazio.

## `split-when`: quebra onde um predicado dispara

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

Cada elemento recebe sua própria chamada do predicado; os elementos verdadeiros são os *pontos de quebra* e não são mantidos no resultado.

## `monotonic-split`: quebra trechos onde a verificação de pares adjacentes falha

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

O predicado roda sobre *pares adjacentes*. Enquanto ele retorna verdadeiro, o trecho continua; quando retorna `f`, um novo trecho começa. Com `[ = ]` você obtém trechos de elementos iguais; com `[ <= ]`, trechos não decrescentes; e assim por diante.

## Quando recorrer a cada um

- **`group`/`clump`**: você sabe o *tamanho* que quer.
- **`split-when`**: você sabe como é um *elemento de quebra*.
- **`monotonic-split`**: você sabe o que faz dois elementos adjacentes *continuarem juntos*.
