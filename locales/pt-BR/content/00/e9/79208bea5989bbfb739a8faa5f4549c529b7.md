# Dicas

Seu código deve conter uma função frequency :: Int -> [Text] -> Map Char Int que recebe um número de workers para usar em paralelo e uma lista de textos, e retorna a frequência total de cada letra no texto.

## Benchmark

Veja como mudar o número de workers afeta o desempenho da sua solução rodando o benchmark. Use `stack bench` para rodá-lo. Fique à vontade para modificar `bench/Benchmark.hs` e explorar o desempenho da sua solução com entradas diferentes.
