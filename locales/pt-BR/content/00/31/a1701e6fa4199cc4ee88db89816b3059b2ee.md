# Introdução

Uma `string` em Go é uma sequência imutável de bytes, que não precisa necessariamente representar caracteres.

Um literal de string é definido entre aspas duplas:

```go
const name = "Jane"
```

Strings podem ser concatenadas com o operador `+`:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Alguns caracteres especiais precisam ser escapados com uma barra invertida no início, como `\t` para uma tabulação e `\n` para uma nova linha em strings.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

O pacote `strings` contém muitas funções úteis para trabalhar com strings.
Para mais informações sobre funções de string, confira a [documentação do pacote `strings`](https://pkg.go.dev/strings).
Aqui estão alguns exemplos:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
