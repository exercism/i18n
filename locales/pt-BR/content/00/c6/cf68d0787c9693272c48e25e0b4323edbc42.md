# Introdução

Tuplas são uma forma leve de agrupar um conjunto fixo de dados de tipos arbitrários. Uma tupla não tem um nome específico; dar nome a uma estrutura de dados a transforma em uma `struct`. Os campos de uma tupla não têm nomes; eles são acessados por meio de desestruturação ou por posição.

## Sintaxe

### Criação

Tuplas são sempre criadas com uma expressão de tupla:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Tuplas podem ter um número arbitrário de elementos.

### Acesso por desestruturação

É possível acessar os elementos de uma tupla por desestruturação. Isso significa apenas atribuir nomes de variáveis aos elementos individuais da tupla, consumindo-a.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Acesso por posição

Também é possível acessar os elementos de uma tupla por índice posicional numérico. A indexação, como sempre, começa em 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Structs de tupla

Você também vai trabalhar com structs de tupla. Assim como structs normais, elas são tipos nomeados; diferente de structs normais, elas têm campos anônimos. A sintaxe delas é muito parecida com a sintaxe normal de tupla. É legal usar tanto desestruturação quanto acesso posicional.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### Visibilidade dos campos

Todos os campos de tuplas anônimas são sempre públicos. No entanto, os campos de structs de tupla têm visibilidade individual, que por padrão é privada, assim como os campos de structs padrão. Você pode tornar os campos públicos com o modificador `pub`, assim como em uma struct padrão.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
