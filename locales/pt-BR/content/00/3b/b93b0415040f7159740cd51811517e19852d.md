# Testes

Você vai precisar do [Godot instalado][installation] corretamente para usar o executor de testes.

## Rodando os testes

O [executor de testes][test runner] é usado para carregar e testar soluções.
Para rodar o executor de testes, baixe-o localmente e depois use o `godot` para executá-lo.
No futuro, o executor de testes será baixado automaticamente junto com os exercícios ao usar `exercism download`.

### Baixando o executor de testes

O trecho de shell a seguir pode ser usado para baixar o executor de testes.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### Rodando o executor de testes

O executor de testes roda com o `godot` em modo headless (sem IDE).
`-s` ou `--script` diz ao Godot para rodar o script do executor de testes.
O executor de testes espera dois argumentos: o slug e o caminho para o diretório da solução.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

Por exemplo,

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
