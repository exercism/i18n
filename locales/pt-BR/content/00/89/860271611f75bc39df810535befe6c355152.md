# substituir os comentários de stub

Substitua os comentários de stub por uma descrição breve, mas útil, do pacote, e uma ou duas frases explicando o que a função faz, quais parâmetros ela recebe e o que ela retorna.
Comentários precisos e úteis sobre como usar o código são muito importantes para os desenvolvedores Go.
Este é um ótimo guia para escrever bons comentários: [Effective Go: Commentary](https://golang.org/doc/effective_go.html#commentary).
A ferramenta `godoc` gera automaticamente a documentação a partir dos comentários do código, quando executada.
Veja [godoc.org](https://godoc.org) para exemplos de como isso fica.
