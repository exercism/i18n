# Introdução

Uma *expressão regular* (regex) é um padrão pequeno que descreve a forma que um texto deve ter. As ferramentas de regex do Factor ficam no vocabulário [`regexp`][regexp], e um padrão é escrito entre `R/ ` e `/`.

Na maioria dos casos, os caracteres em um padrão representam a si mesmos. Alguns elementos especiais representam *tipos* de caractere ou *quantos* esperar:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

Então `R/ [A-Z]{2}-\d{4}/` significa "duas letras maiúsculas, um hífen, quatro dígitos".

`matches?` testa se uma string *inteira* se encaixa no padrão:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

Outras palavras olham *dentro* de uma string: `all-matching-subseqs` retorna todas as correspondências, `count-matches` as conta, `re-contains?` informa se existe alguma correspondência, e `re-replace` troca cada correspondência por um novo texto:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
