# Instruções

Enquanto trabalha na _Instruments of Texas_, você é encarregado de trabalhar em uma calculadora experimental de Notação Polonesa Reversa [RPN] escrita em Elixir. Sua equipe está com um problema: algumas operações geram erros e travam o processo. Você foi encarregado de escrever uma função que encapsula a função de operação para que os erros possam ser tratados de forma mais elegante com código Elixir idiomático.

## 1. Avise a equipe

Implemente a função `calculate!/2` para chamar a função de operação com a pilha como único argumento. A função de operação está definida em outro lugar, mas você sabe que ela pode ser concluída com sucesso ou gerar um erro.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> Nomes de funções que terminam em `!` são um aviso aos programadores de que essa função pode gerar um erro

## 2. Envolva o erro

Ao pesquisar mais, você percebe que muitas funções usam átomos e tuplas para indicar sucesso ou falha. Implemente `calculate/2` usando essa estratégia.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. Repasse a mensagem

Alguns dos erros contêm informações importantes que seus colegas de trabalho precisam ter para garantir o funcionamento correto do sistema. Implemente `calculate_verbose/2` para repassar a mensagem de erro. O erro é uma struct que tem um campo `:message`.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
