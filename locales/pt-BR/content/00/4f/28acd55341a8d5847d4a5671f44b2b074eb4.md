# Instruções

Busque em arquivos as linhas que correspondem a uma string de busca e retorne todas as linhas correspondentes.

O comando [`grep`][grep] do Unix busca, nos arquivos, as linhas que correspondem a uma expressão regular.
Sua tarefa é implementar um comando `grep` simplificado, que permite buscar por strings fixas.

O comando `grep` recebe três argumentos:

1. A string a ser buscada.
2. Zero ou mais flags para personalizar o comportamento do comando.
3. Um ou mais arquivos nos quais buscar.

Em seguida, lê o conteúdo dos arquivos especificados (na ordem especificada), encontra as linhas que contêm a string de busca e, por fim, retorna essas linhas na ordem em que foram encontradas.
Ao buscar em vários arquivos, cada linha correspondente é precedida pelo nome do arquivo e dois-pontos (':').

## Flags

O comando `grep` aceita as seguintes flags:

- `-n` Adiciona o número da linha e dois-pontos (':') no início de cada linha da saída, colocando o número depois do nome do arquivo (se houver).
- `-l` Exibe apenas os nomes dos arquivos que contêm pelo menos uma linha correspondente.
- `-i` Faz a correspondência usando uma comparação que ignora maiúsculas e minúsculas.
- `-v` Inverte o programa: coleta todas as linhas que não correspondem.
- `-x` Busca apenas as linhas em que a string de busca corresponde à linha inteira.

[grep]: https://pubs.opengroup.org/onlinepubs/9699919799/utilities/grep.html
