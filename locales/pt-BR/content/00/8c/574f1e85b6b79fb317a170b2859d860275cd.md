# Básico

Um programa em Sather é feito de **classes**. Uma classe é uma caixa com nome que guarda rotinas. Uma **rotina** é um pedaço de trabalho com nome que produz uma resposta.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

Lendo isso de cima para baixo:

- `class GREETER is` abre a caixa e dá um nome a ela. Nomes de classe são escritos em letras maiúsculas.
- `hello : STR is` inicia uma rotina chamada `hello` que produz um `STR`, um pedaço de texto chamado *string*. O `: STR` é uma promessa sobre o tipo de resposta que volta.
- `return "Hello!";` devolve a resposta. Textos são escritos entre aspas duplas.
- `end;` fecha a rotina, e o segundo `end;` fecha a classe.

Tudo o que vem depois de `--` em uma linha é um **comentário**. O Sather o ignora; ele está ali para as pessoas.

```sather
-- This line is for the reader, not the computer.
```

Para usar uma rotina de outro lugar, escreva o nome da classe, dois dois-pontos e o nome da rotina:

```sather
GREETER::hello        -- this is "Hello!"
```

Dentro da mesma classe, você pode deixar o nome da classe de fora:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

Uma rotina que não recebe argumentos é chamada sem parênteses: `hello`, e não `hello()`.
