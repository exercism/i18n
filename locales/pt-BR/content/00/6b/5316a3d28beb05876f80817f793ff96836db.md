# Sobre

As funções em Elixir podem ser despachadas dinamicamente.

Todos os nomes de módulos são átomos. Todos os nomes de módulos em Elixir recebem automaticamente o prefixo `Elixir.` quando são compilados.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

O Elixir consegue resolver uma função a ser invocada em tempo de execução, usando o nome do módulo para fazer uma busca. A busca pode ser feita dinamicamente se o nome do módulo estiver vinculado a uma variável.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
