# Introdução

Common Lisp tem um conceito de The Printer que inclui todas as funções para escrever representações textuais de dados Lisp. Uma dessas funções é `format`, que permite a quem programa formatar os dados como quiser.

As capacidades de `format` e do The Printer em geral são um tópico amplo; aqui serão descritos os fundamentos do uso de `format`.

## A função FORMAT

A função `format` recebe pelo menos dois argumentos: um stream para imprimir e uma string de controle que define o que e como deve ser impresso.

Streams são um conceito à parte e serão descritos em outro lugar. Mas, por enquanto, tudo o que você precisa saber é que a impressão é feita no stream e que há dois valores especiais para esse argumento: `t` e `nil`. `t` significa imprimir na saída padrão (na verdade, o stream ao qual a variável `*standard-output*` está vinculada), e `nil` significa criar uma string e retorná-la.

Repare que `format` sempre avalia para `nil`, exceto nesse último caso, em que `nil` é especificado como o stream. É uma forma comum de fazer interpolação ou construção de strings de maneira simples.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## Diretivas de formato

A string de controle pode conter "diretivas de formato" que dão instruções a `format` sobre o que imprimir e como interpretar quaisquer outros parâmetros passados a `format`. De certo modo, a string de controle é um programa que `format` vai interpretar e executar. Todas as diretivas começam com `~` e são seguidas por um caractere (por exemplo, `~A`, `~D`, `~&`). Não importa se o caractere está em maiúscula ou minúscula.

A maioria das diretivas de formato simplesmente interpola um argumento de `format` na saída. Diz-se que isso "consome" o argumento. Algumas diretivas não consomem argumentos, ou consomem mais de um. Uma diretiva permite até que você salte pela lista de argumentos ou pule argumentos.

## Formatação básica

Uma diretiva de formato bastante versátil é `~A`. Ela imprime uma versão 'legível para humanos' dos dados.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

Outra diretiva de formato útil é `~S`. Ela imprime uma versão 'legível por máquina' dos dados. Isso pode ser muito útil se você quiser conseguir interpretar a saída gerada como dados Lisp. Para muitas coisas, ela parecerá igual a `~A`, mas repare que, para strings, por exemplo, a saída incluirá as aspas (escapadas quando incluídas em outra string), para que o valor possa ser lido de volta como o parâmetro string.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

Mais duas diretivas muito úteis são `~%` e `~&`. A primeira gera um caractere de nova linha, enquanto a última gera uma 'linha nova'. A diferença é que `~%` sempre gera uma nova linha, enquanto `~&` gerará uma se não estiver atualmente no início de uma linha. Nenhuma delas consome um argumento.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

Por fim, `~~` é uma diretiva simples que gera um `~` literal.
