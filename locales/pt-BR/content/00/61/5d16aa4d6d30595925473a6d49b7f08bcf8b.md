# Instruções

Todo arnês do circo tem uma carga nominal em quilogramas, e ninguém sobe antes de os números serem conferidos.

A classe `SAFETY_HARNESS` precisa do seguinte. O stub já traz a classe e o atributo dela; acrescente o resto. Cada rotina abaixo carrega um contrato, e as dicas dizem qual.

## 1. Monte um arnês

`create` recebe a carga nominal do arnês e retorna um arnês. Uma carga nominal de zero ou menos não é um arnês de jeito nenhum, então isso é um `pre`.

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. Quanto ainda sobra?

`spare_capacity` recebe a carga sobre o arnês e retorna quanto mais ele poderia suportar. A carga não pode ser negativa nem passar do limite: as duas condições são `pre`. A resposta nunca é negativa, o que é um `post`.

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. O quanto ele está cheio?

`percent_used` recebe a carga e a retorna como uma porcentagem do limite, arredondada para baixo. A carga não pode ser negativa, e a resposta nunca é negativa.

```sather
harness.percent_used(60)
-- => 50
```

## 4. É seguro?

`is_safe` recebe a carga e responde se ela está dentro do limite. Pode-se perguntar sobre qualquer carga, inclusive uma absurda, então não há `pre` na carga. Mas escreva um `post` dizendo que a resposta é true exatamente quando a carga está dentro do limite.

```sather
harness.is_safe(200)
-- => false
```
