# Anexo de instruções

## Implementação

Você vai escrever uma implementação de uma lista duplamente encadeada genérica.
Implemente um `Node` para guardar um valor e ponteiros para os nós seguinte e anterior.
Depois, implemente uma `List` que guarda referências para o primeiro e o último nó e oferece funções para adicionar e remover itens.

Usar um genérico `comparable` permite que a lista guarde qualquer tipo de dado comparável.

Seu `Node` deve ter os seguintes campos e métodos:

- `Value`: o valor do nó.
- `Next() *Node`: ponteiro para o próximo nó.
- `Prev() *Node`: ponteiro para o nó anterior.

Você deve ter uma função `NewList()` que cria e retorna uma `List`:

- `NewList[T comparable](args ...any) *List[T]`: cria uma nova lista encadeada preservando a ordem dos valores.

Sua `List[T]` deve ter os seguintes métodos:

- `First() *Node[T]`: retorna um ponteiro para o primeiro nó (cabeça).
- `Last() *Node[T]`: retorna um ponteiro para o último nó (cauda).
- `Push(v T)`: insere um valor no fim da lista.
- `Pop() (T, error)`: remove um valor do fim da lista.
- `Unshift(v T)`: insere um valor no início da lista.
- `Shift() (T, error)`: remove um valor do início da lista.
- `Reverse()`: inverte a lista encadeada.
