# Sobre

O casamento de padrões é o processo de ramificar conforme um valor corresponde a padrões dados, possivelmente profundos. Em Haxe, o **casamento de padrões** é feito usando a expressão `switch` e expressões `case` individuais.

Considere esta estrutura de dados:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Os padrões são sempre testados de cima para baixo.
- O primeiro padrão que corresponder ao valor de entrada tem sua expressão executada.
- Um padrão `_` corresponde a qualquer coisa, então `case _:` é equivalente a `default:`.

## Casamento com enums

Podemos casar enums pelo seu construtor naturalmente:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
