# Instalando o Emacs

Como Emacs Lisp (elisp) é a linguagem de extensão do Emacs, você precisa instalar o [GNU Emacs](http://www.gnu.org/software/emacs/) primeiro.

Recomendamos usar a versão mais recente do Emacs, mas a 28.1 ou superior deve ser considerada a implementação alvo dos exercícios.
Se você já tem o Emacs instalado, pode verificar a versão com `M-x emacs-version RET`.

## No OS X
A forma mais fácil é acessar o [Emacs For Mac OS X](http://emacsformacosx.com/) e baixar o dmg, que
instala o GNU Emacs como um aplicativo empacotado do OS X.

Existem alternativas, como o Aquamacs (não recomendado) ou instalar pelo
[Homebrew](https://formulae.brew.sh/formula/emacs), se você preferir.

## No Linux
Em algumas distribuições, o Emacs já vem instalado, já que faz parte do GNU.

### Ubuntu
A forma atualmente recomendada de instalar o Emacs mais recente é pelo [snap](https://snapcraft.io/emacs):

```
sudo snap install emacs --classic
```

Se você não quiser usar o snap, também pode instalar o Emacs pelo snap, mas a versão disponível nos repositórios do Ubuntu costuma estar desatualizada.
Se quiser instalar uma versão mais recente do Emacs pelo apt, você precisa usar um [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) ou [compilar a partir do código-fonte](https://www.emacswiki.org/emacs/BuildingEmacs).

Se você não faz questão da versão mais recente, deve ser tão simples quanto

```
sudo apt-get install emacs
```

### Arch
O Arch costuma vir com a versão mais recente do Emacs, então é só rodar:

```
sudo pacman -S emacs
```

e pronto.

### Outras distribuições
Confira na sua distribuição qual é a versão atual e use o gerenciador de pacotes
ou compile a partir do código-fonte, conforme o caso.

### Windows
Para instalar o Emacs no Windows, acesse o
[espelho de arquivo FTP](https://ftpmirror.gnu.org/emacs/windows) mais próximo, baixe o instalador (=emacs-XX.X-installer.exe=) e execute-o.
Se você quiser usar o Emacs sem instalá-lo, baixe o arquivo com o padrão =emacs-XX.x.zip=, descompacte-o e execute `bin\runemacs.exe`.

Se você usa o [MSYS2](https://www.msys2.org/), pode instalar a versão de 64 bits do Emacs com

```
pacman -S mingw-w64-x86_64-emacs
```

ou a versão de 32 bits com

```
pacman -S mingw-w64-i686-emacs
```
