# Dicas

## 1. Obter as permissões padrão de um tipo de conta

- Defina o enum `Permission` com valores para os seguintes tipos de permissão: `None`, `Read`, `Write` e `Delete`.
- Usar as flags do enum permitiria usar operações bit a bit de forma nativa com o enum `Permission`, [veja `enum` `Flags`][docs-enum-flags].
- O membro `All` do enum pode ser definido como uma combinação dos membros `Read`, `Write` e `Delete`.
- Defina o enum `AccountType` com valores para os seguintes tipos de conta: `Guest`, `User` e `Moderator`.
- Para lidar com cada tipo de conta, seria possível usar uma condicional `if`, mas a [instrução `switch`][docs.microsoft.com-switch-keyword] é uma ótima alternativa.
- Combinar flags significa definir um bit específico como `1` usando um dos [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 2. Conceder uma permissão

- Combinar flags significa definir um bit específico como `1` usando um dos [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 3. Revogar uma permissão

- Remover uma flag significa definir um bit específico como `0` usando uma combinação de dois [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 4. Verificar uma permissão

- Verificar uma permissão pode ser feito conferindo o resultado da aplicação de um dos [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].
