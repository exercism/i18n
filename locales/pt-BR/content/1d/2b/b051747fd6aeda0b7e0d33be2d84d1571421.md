# Apêndice das instruções

## Formato da saída

Retorne a letra como uma string terminada em nulo.

## Registradores

| Registrador | Uso          | Tipo    | Descrição                          |
| ----------- | ------------ | ------- | ---------------------------------- |
| `$a0`       | entrada      | inteiro | garrafas iniciais                  |
| `$a1`       | entrada      | inteiro | quantidade a derrubar              |
| `$a2`       | entrada/saída | endereço | string de saída terminada em nulo |
| `$t0-9`     | temporário   | qualquer | para armazenamento temporário      |
