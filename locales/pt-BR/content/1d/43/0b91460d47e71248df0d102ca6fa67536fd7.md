# Dicas

## Geral

- Leia sobre composição de funções no [manual][function-composition-manual].
- Explore os [métodos disponíveis para _Strings_][string-methods].

## 1. Limpe o nome

- Existe um [método embutido][string-replace] para substituir todas as ocorrências de uma substring em uma string.
- Existe um [método embutido][string-strip] para remover espaços em branco no início e no fim de uma string.

## 2. Obtenha a primeira letra do nome

- Para obter um caractere específico de uma string, você pode usar [indexação][string-indexing].
- A maneira mais limpa de escrever isso é usando o operador de composição `∘`.

## 3. Formate a primeira letra como uma inicial

- Existe um [método embutido][string-uppercase] para converter todos os caracteres de uma string na versão maiúscula deles.

## 4. Coloque as iniciais dentro do coração

- Você pode usar caracteres unicode em strings assim: `'\u<id>'`, em que, no caso do emoji de coração, o id é `2764`.
- Isso pode ser feito com [concatenação][string-concatenation] ou [interpolação][string-interpolation].
