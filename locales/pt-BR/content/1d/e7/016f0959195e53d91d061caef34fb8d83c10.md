# Instruções

A kata do diamante recebe uma letra como entrada e a exibe em formato de diamante. Dada uma letra, ela imprime um diamante começando com 'A', com a letra fornecida no ponto mais largo.

## Requisitos

* A primeira linha contém um 'A'.
* A última linha contém um 'A'.
* Todas as linhas, exceto a primeira e a última, têm exatamente duas letras idênticas.
* Todas as linhas têm tantos espaços no final quantos no início. (Pode ser 0.)
* O diamante é simétrico na horizontal.
* O diamante é simétrico na vertical.
* O diamante tem formato quadrado (a largura é igual à altura).
* As letras formam um formato de diamante.
* A metade superior tem as letras em ordem crescente.
* A metade inferior tem as letras em ordem decrescente.
* Os quatro cantos (que contêm os espaços) são triângulos.

## Exemplos

Nos exemplos a seguir, os espaços são indicados pelo caractere `·`.

Diamante para a letra 'A':

```text
A
```

Diamante para a letra 'C':

```text
··A··
·B·B·
C···C
·B·B·
··A··
```

Diamante para a letra 'E':

```text
····A····
···B·B···
··C···C··
·D·····D·
E·······E
·D·····D·
··C···C··
···B·B···
····A····
```
