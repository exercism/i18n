# Sobre

## Condicionais

Condicionais são instruções de tomada de decisão que podem executar efeitos colaterais ou controlar o fluxo de execução de um programa.
As condicionais incluem as instruções `if`, `if/else`, `switch` e `ternary`.

As condicionais servem para fazer perguntas sobre um valor ou sobre uma relação entre valores.
A pergunta resulta em uma resposta Boolean, mas a própria instrução `if` pode retornar qualquer valor ou simplesmente executar um efeito colateral.

## Instruções if

A condicional `if` mais simples avalia uma expressão e executa uma linha.
A expressão testada fica sempre entre parênteses.

Ela pode executar um efeito colateral

```c
if (count > 10)
    printf("count is greater than 10");
```

ou pode mudar o fluxo de execução


```c
if (count > 10)
    return sum;
```

Se uma condicional `if` executar mais de uma linha, ela precisa colocar as linhas entre chaves

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Algumas equipes de programação podem padronizar que as condicionais `if` sempre usem chaves, mesmo para uma única linha.


## If Else

Uma condicional `if` pode ser combinada com um `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## If Else If


O `else` pode ser combinado com outro `if` para criar o que se chama de `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Switch


Às vezes, um `if-else-if ladder` pode ser melhor representado por um `switch`.
Assim como o `if`, a expressão testada fica sempre entre parênteses.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

O caso `default` executa se o valor testado não corresponder a nenhum dos casos anteriores.

Se um caso do `switch` não retorna, geralmente um `break` é inserido para encerrar cada caso; caso contrário, a lógica "passa" para o próximo caso.
Às vezes o fallthrough é usado de propósito

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Quando o fallthrough acontece sem querer, é um bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Um switch pode ser vantajoso quando se testa valores específicos em vez de um intervalo de valores.
Ele pode ser mais rápido que um `if-else-if ladder` porque o compilador pode conseguir otimizar a instrução `switch` de formas que não consegue com uma escada.
Um switch às vezes pode parecer mais legível que uma escada.

## Operador ternário (também chamado de condicional)

O operador ternário é uma condicional de três partes, frequentemente usada para definir um valor.
A expressão a ser testada vem antes do ponto de interrogação e não precisa estar entre parênteses.
O valor retornado se a condição for verdadeira fica antes dos dois-pontos; o valor retornado se a condição for falsa fica depois dos dois-pontos.
Pode ser retornado tanto um literal quanto uma variável.

```c
int i = j > 5 ? 5: j;
```

Operadores ternários podem ser aninhados para reduzir o excesso de sintaxe.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## Comparações condicionais com números de ponto flutuante

Por causa de como os números de ponto flutuante são implementados, uma operação matemática simples pode gerar um erro de arredondamento, o que pode fazer com que um teste de igualdade não retorne o resultado esperado.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

Um valor de tolerância, chamado de `epsilon`, pode ser usado para determinar um intervalo no qual um valor pode estar e ainda ser considerado igual quando comparado a outro valor.
Algumas plataformas têm constantes embutidas para os epsilons de `float` e `double`.
Consulte a documentação do seu compilador para saber mais.
Calcular o epsilon pode ser algo sofisticado e pode variar entre plataformas: até entre máquinas individuais.
Veja um programa de exemplo que usa uma comparação simples.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

Cuidado ao comparar `float`s ou `double`s para verificar igualdade!
