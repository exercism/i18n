# Anexo às instruções

## Saída

Neste exercício, você vai implementar um verbo que gera o Triângulo de Pascal até um determinado número de linhas. A saída do seu verbo pode ser formatada de duas maneiras:

  1. Como um array de listas encaixotadas, em que cada lista representa uma linha do Triângulo de Pascal.
  1. Como uma tabela, em que os números são alinhados à direita e zeros preenchem os espaços vazios à esquerda.

### Exemplo de saída

Veja duas saídas válidas para `pascal 3`:

  - Como um array de listas encaixotadas:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - Como uma tabela com preenchimento:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
