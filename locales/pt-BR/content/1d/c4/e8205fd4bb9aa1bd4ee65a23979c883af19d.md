# Sobre

O principal a lembrar sobre strings em Java é que elas são objetos imutáveis que representam texto como uma sequência de caracteres Unicode (letras, dígitos, pontuação etc.).
Aspas duplas são usadas para definir uma instância de `String`:

```java
String fruit = "Apple";
```

A manipulação de uma string pode ser feita usando métodos da classe [`String`][string-class].
Como os valores de string nunca mudam depois de definidos, todos os métodos de manipulação de string retornam uma nova string.

Uma string é delimitada por caracteres de aspas duplas (`"`).
Alguns caracteres especiais precisam de escape usando a barra invertida (`\`).
Caracteres que precisam de escape em Java:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Por fim, existem muitas formas de concatenar uma string.
A mais simples é o operador `+`:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para qualquer formatação de string mais complexa que uma simples concatenação, prefira o método `String.format`.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

Outras possibilidades são:

- usar a [classe `StringBuilder`][string-builder]
- usar o [método `String.concat`][string-concat]
