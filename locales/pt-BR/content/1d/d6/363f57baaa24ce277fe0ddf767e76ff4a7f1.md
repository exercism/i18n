# Dicas

## 1. Ler endereços de e-mail de um arquivo

- A [função `simplifile.read`][file-read] pode ser usada para ler o conteúdo de um arquivo.

## 2. Criar um arquivo de log para escrita

- A [função `simplifile.create_file`][file-create] pode ser usada para criar um arquivo vazio.

## 3. Registrar um e-mail enviado

- A [função `simplifile.append`][file-append] pode ser usada para acrescentar texto a um arquivo.

## 5. Enviar a newsletter

- Todas as operações necessárias em arquivos já foram implementadas nos passos anteriores.
- A [função `result.try`][result-try] e a [função `list.try_each`][list-try-each] podem ser usadas para trabalhar com o tipo `Result`.
