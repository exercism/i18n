# Introdução

Uma `list` em R é uma coleção ordenada de itens, que difere dos `vectors` de algumas formas:

- Os itens podem ser de tipos diferentes (por exemplo, misturar `numeric` com `character`).
- Os itens podem ser estruturas complexas (por exemplo, vetores, outras listas etc.).
- Há uma sintaxe um pouco diferente para acessar os elementos.

As analogias com outras linguagens são imprecisas.
Uma `list` em R é um pouco parecida com um dicionário do Python, mas a `list` é ordenada e pode ser acessada por um índice numérico.
É um pouco parecida com um `struct` de C, exceto que a `list` pode ser facilmente estendida em tempo de execução.

## Criando listas

Dar nomes (muitas vezes chamados de "tags") aos elementos é mais comum em listas do que em vetores:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

No entanto, as tags são opcionais, e então o R apenas usa números de índice:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Acessando os elementos de uma lista

Há três formas de fazer isso, cada uma útil em contextos diferentes.

### 1. Com a notação `$tag`

Muito comum quando os nomes das tags são conhecidos de antemão.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Com a notação `[[tag]]`

Isso tem a vantagem de que o nome da tag pode ser escolhido em tempo de execução.
Repare nos colchetes duplos.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Com índice de posição

Isso funciona com ou sem tags na lista.
Mais uma vez, os colchetes são duplos.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Adicionando e removendo elementos

Simples: atribuir a um elemento vai modificá-lo caso ele exista ou inseri-lo caso seja novo.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Para excluir, atribua `NULL` ao elemento indesejado.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
