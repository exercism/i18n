# Números

`INT` é o tipo de Sather para números inteiros: `0`, `7`, `-3`. Uma rotina que responde com um número inteiro diz isso depois dos dois-pontos, do mesmo jeito que uma rotina que responde com texto diz `STR`.

```sather
   goals : INT is
      return 42;
   end;
```

As rotinas podem receber **argumentos**: valores passados quando a rotina é chamada. Cada argumento tem um nome e um tipo, entre parênteses depois do nome da rotina:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Quando dois argumentos têm o mesmo tipo, você pode nomeá-los juntos:

```sather
   total(first, second : INT) : INT is
```

Para chamá-la, coloque os valores entre parênteses:

```sather
SCORES::total(3, 4)     -- this is 7
```

Os cinco operadores aritméticos são `+`, `-`, `*`, `/` e `%`.

`/` entre dois `INT`s é **divisão inteira**: ela descarta qualquer resto em vez de dar uma fração.

```sather
7 / 2      -- 3, not 3.5
```

`%` dá o que sobra dessa divisão.

```sather
7 % 2      -- 1
```

Os dois andam juntos: `7` é `3` vezes `2` com `1` sobrando.
