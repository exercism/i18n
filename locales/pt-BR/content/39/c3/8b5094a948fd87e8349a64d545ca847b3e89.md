# Instruções

Encontre a diferença entre o quadrado da soma e a soma dos quadrados dos primeiros N números naturais.

O quadrado da soma dos dez primeiros números naturais é
(1 + 2 + ... + 10)² = 55² = 3025.

A soma dos quadrados dos dez primeiros números naturais é
1² + 2² + ... + 10² = 385.

Logo, a diferença entre o quadrado da soma e a soma dos quadrados dos dez primeiros números naturais é 3025 - 385 = 2640.

Você não precisa descobrir por conta própria uma solução eficiente partindo dos princípios fundamentais; pesquisar é permitido e, mais que isso, incentivado.
Encontrar o melhor algoritmo para o problema é uma habilidade essencial na engenharia de software.
