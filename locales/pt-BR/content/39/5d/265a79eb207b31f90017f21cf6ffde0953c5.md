# Introdução

Uma lista em Gleam é uma coleção imutável de zero ou mais valores. Todos os valores de uma lista precisam ter o mesmo tipo. Como as listas são imutáveis, depois que uma lista é construída, seu valor nunca pode mudar. Qualquer função ou operador que pareça modificar uma lista (como adicionar um elemento) na verdade retorna uma nova lista.

As listas podem ser definidas assim:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

A forma mais comum de adicionar um elemento a uma lista é com a sintaxe de espalhamento:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

O módulo [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) da biblioteca padrão do Gleam tem muitas funções úteis para trabalhar com listas. Esse módulo é muito usado em código Gleam, por isso é bom conhecê-lo bem.

Padrões de lista podem ser usados em expressões case para corresponder a listas e atribuir os valores contidos a variáveis:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Além de corresponder a listas de comprimento exato, a sintaxe de espalhamento pode ser usada para corresponder a listas com pelo menos um certo comprimento:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

A sintaxe de espalhamento também pode ser usada para atribuir o restante da lista a uma variável:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

As expressões case devem ter um padrão para cada valor possível do tipo com que se está fazendo correspondência, por isso um padrão de descarte final (`_`) costuma ser usado para tratar quaisquer valores restantes.
