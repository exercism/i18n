# Introdução

`Enum` é um módulo muito útil que fornece um conjunto de algoritmos para trabalhar com enumerables. Ele oferece ordenação, filtragem, agrupamento, contagem, busca, descoberta de valores mínimos e máximos, e muito mais.

De modo geral, um _enumerable_ é qualquer dado sobre o qual se pode iterar, ou seja, uma coleção. No Elixir, um enumerable é qualquer tipo de dado que implementa o [protocolo][exercism-protocols] `Enumerable`. Os mais comuns são as [listas][exercism-lists] e os [mapas][exercism-maps].

Muitas funções de `Enum` aceitam uma função como argumento.

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

As funções de `Enum` mais comuns são `map` e `reduce`.

## `map/2`

`Enum.map/2` permite substituir cada elemento de um enumerable por outro elemento. O segundo argumento de `Enum.map/2` é uma função que aceita o elemento original e retorna o seu substituto.

## `reduce/3`

`Enum.reduce/3` permite _reduzir_ todo o enumerable a um único valor. Para isso, usa-se uma variável especial chamada _acumulador_. O acumulador carrega o estado intermediário da redução entre as iterações.

O segundo argumento de `Enum.reduce/3` é o valor inicial do acumulador. O terceiro argumento é uma função que aceita um elemento e um acumulador e retorna o novo valor do acumulador.

## Trabalhando com mapas

Ao usar mapas com funções de `Enum`, o mapa é convertido automaticamente em uma lista de 2 tuplas `{key, value}`.

Para transformá-lo de volta em um mapa, use `Enum.into/2`. `Enum.into/2` é uma função que transforma um enumerable em um coletável: qualquer estrutura de dados que implemente o protocolo `Collectable`. Ela pode ser pensada como o oposto de `Enum.reduce/3`.

`Enum` também tem `Enum.into/3`. `Enum.into/3` é uma variação de `Enum.into/2` que aceita uma função de transformação a ser aplicada enquanto o enumerable é transformado em um coletável.

### Mapeando mapas

Em vez de usar `Enum.into/3` ou `Enum.map/2` mais `Enum.into/2` para aplicar uma transformação (mapeamento) a um mapa, também podemos usar uma função dedicada, `Map.new/2`. Ela funciona exatamente como `Enum.into/3`, no sentido de que aceita um enumerable e uma função de transformação, mas sempre retorna um novo mapa, em vez de nos deixar escolher o coletável.
