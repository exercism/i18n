# Introdução

## Alias

Para compartilhar código entre diferentes módulos Elixir dentro do mesmo projeto, você precisa se referir ao módulo externo pelo nome completo. Mas e se esse nome for longo ou confuso demais?

A forma especial `alias` permite encurtar ou alterar o nome pelo qual você se refere a um módulo externo. Quando usada sem argumentos, ela reduz o nome do módulo ao seu último segmento, por exemplo, `MyApp.Logger.Settings` se torna `Settings`. Um nome personalizado pode ser especificado com a opção `:as`.

Normalmente, os aliases são adicionados no início da definição do módulo.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

A forma especial `import` permite usar funções de um módulo externo sem usar o nome do módulo.

Importar um módulo externo inteiro pode criar conflitos com funções locais existentes. Para evitar isso, há duas opções disponíveis: `:except` e `:only`. Ambas esperam uma keyword list, em que a chave é o nome da função e o valor é a aridade da função.

Normalmente, os imports são adicionados no início da definição do módulo.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
