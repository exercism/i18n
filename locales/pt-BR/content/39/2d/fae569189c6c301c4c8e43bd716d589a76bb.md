# Instruções

Um amigo seu tem uma loja de atacado antiga chamada **Gross Store**.

O nome vem da quantidade do item que a loja vende: é tudo em [unidade de grosa][gross-unit].

Seu amigo pediu para você implementar um sistema de ponto de venda (PDV) para a loja dele.

**Primeiro, você quer construir um protótipo dele.**

**No seu protótipo, o sistema vai apenas registrar a quantidade.**

Seu amigo te deu uma lista de medidas para ajudar:

| Unidade            | Valor |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Armazene a unidade de medida no seu programa

Para usar a medida, você precisa armazená-la no seu programa.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Crie uma nova conta de cliente

Você precisa implementar uma função que cria uma nova conta (vazia) para o cliente.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Adicione um item à conta do cliente

Para implementar isso, você vai precisar:

- Retornar `false` se a `unit` fornecida não estiver no mapa `units`.
- Caso contrário, adicionar o item à `bill` do cliente, indexado pelo nome do item, e então retornar `true`.
- Se o item já estiver na conta, aumentar a quantidade dele pelo valor que corresponde à `unit` fornecida.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> Repare que o valor retornado é do tipo `bool`.

## 4. Remova um item da conta do cliente

Para implementar isso, você vai precisar:

- Retornar `false` se o item fornecido **não** estiver na conta.
Um item é considerado fora da conta se a quantidade dele for 0.
- Retornar `false` se a `unit` fornecida não estiver no mapa `units`.
- Retornar `false` se a nova quantidade for menor que 0.
- Se a nova quantidade for 0, o item é considerado removido da `bill`, então você pode retornar `true`.
- Caso contrário, reduzir a quantidade do item e retornar `true`.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> Repare que o valor retornado é do tipo `bool`.

## 5. Retorne a quantidade de um item específico que está na conta do cliente

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> Repare que o valor retornado é do tipo `u32`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
