# Sobre

O PHP tem várias estruturas de controle de laços embutidas, como o `while`. A forma básica de uma instrução `while` é:

```php
while (expr) {
  // statements
}
```

Enquanto a expressão (_expr_) for avaliada como um valor _truthy_, o laço vai iterar sobre as instruções dentro dele. Se a expressão (_expr_) for avaliada como falsa antes da primeira iteração, as instruções nunca serão executadas.

Como alternativa, você pode usar um laço `do-while`, que executa as instruções do laço uma vez antes de avaliar a expressão (_expr_).

```php
do {
  // statements
} while (expr);
```
