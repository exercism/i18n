# Luhn: usando a trait From

Antes de fazer este exercício, você provavelmente deveria fazer o exercício Luhn original. Se você ainda não completou o Luhn, pode obtê-lo rodando o comando:

```shell
exercism download --exercise=luhn --track=rust
```

No exercício Luhn original você só validava strings, mas o algoritmo de Luhn também pode ser aplicado a números inteiros.

Neste exercício você vai implementar a [trait From](https://doc.rust-lang.org/std/convert/trait.From.html) para converter strings, strs e inteiros sem sinal em uma Struct que faz a validação.
