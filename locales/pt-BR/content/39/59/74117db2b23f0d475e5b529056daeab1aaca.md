# Instruções

O treino de netball começa com voltas. O treinador faz cada volta um pouco mais longa que a anterior: a primeira tem 100 metros, a segunda 110, a terceira 120, e assim por diante, dez metros a mais a cada vez.

As três tarefas ficam na classe `WARM_UP_LAPS`.

## 1. Qual é a distância total?

Dado um número de voltas, calcule a distância total.

```sather
WARM_UP_LAPS::distance_run(3)
-- => 330
```

Ou seja, 100 + 110 + 120. Zero voltas dá zero metros.

## 2. Quantas voltas para cobrir uma distância?

Dada uma distância em metros, quantas voltas são necessárias até o total chegar a pelo menos essa distância?

```sather
WARM_UP_LAPS::laps_to_reach(330)
-- => 3
WARM_UP_LAPS::laps_to_reach(331)
-- => 4
```

Zero metros não precisa de volta nenhuma.

## 3. Qual volta fica longa primeiro?

Dada uma distância em metros, qual é a primeira volta que, *por si só*, é mais longa que essa distância? A volta 1 tem 100 metros, a volta 2 tem 110, e assim por diante.

```sather
WARM_UP_LAPS::first_long_lap(115)
-- => 3
```

A volta 3 tem 120 metros, que é a primeira acima de 115.
