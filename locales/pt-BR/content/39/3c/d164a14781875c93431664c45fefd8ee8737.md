# Tuplas

Em Elm, as tuplas podem conter dois ou três valores, e cada valor pode ter qualquer tipo.
Em Elm, as tuplas são usadas principalmente para tipos transitórios simples.
Por isso, as tuplas têm no máximo 3 valores e, como incentivo extra, só existem funções de conveniência para 2 valores.
Para dados mais complexos, é melhor usar registros.
Um uso comum é quando você precisa retornar mais de um valor de uma função.
Os campos de uma tupla não têm nome: você os acessa por desestruturação ou por posição.

Você pode ler uma [introdução concisa às tuplas][tuples-concise].
Também há uma [introdução mais aprofundada][tuples-in-depth], e a [documentação da API do módulo Tuple][tuple-core] traz exemplos de código e documentação detalhada.

## Declaração

Os tipos de tupla são criados com parênteses, e os tipos de seus elementos são separados por vírgulas.

```elm
type alias IntStringTuple = (Int, String)
```

### Criação

As tuplas são criadas com parênteses, e seus elementos são separados por vírgulas.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

Você também pode usar `Tuple.pair` para criar uma tupla com dois valores.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### Acesso

Também há funções para acessar os valores de uma tupla por posição: `Tuple.first` e `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

As tuplas podem ser _desestruturadas_ em vinculações usando casamento de padrões de tupla.
A desestruturação pode ser feita em expressões let, declarações de função e instruções case.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

O casamento de padrões em uma instrução case também permite fazer correspondência com o conteúdo dos valores:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
