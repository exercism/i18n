# Anexo às instruções

## Funções e testes

Você recebe uma definição inicial para a função `SayHi`.

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

O executor de testes pega essa função e a executa, comparando o valor que ela [retorna][returns] com o valor esperado.
Use essa definição inicial como base para a sua solução.

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
