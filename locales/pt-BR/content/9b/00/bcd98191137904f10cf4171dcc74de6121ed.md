# Instruções

O clube de poesia local está começando uma nova temporada. Os poetas entram no clube e, sempre que dois deles escrevem um poema juntos, eles passam a fazer parte do mesmo *círculo de escrita*. O clube quer acompanhar quem compartilha um círculo com quem, e pediram que você escrevesse as palavras que cuidam disso.

Um conjunto disjunto é perfeito para isso: cada poeta é um átomo e um círculo de escrita é um grupo.

## 1. Abra o clube

Defina `new-club`, que recebe uma sequência de poetas e retorna um novo conjunto disjunto com todos os poetas registrados. Cada poeta começa em um círculo de escrita só seu.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. Registre uma colaboração

Defina `collaborate`, que recebe dois poetas e um clube. Ela une os círculos de escrita dos dois poetas e retorna o clube, para que as colaborações possam ser registradas uma após a outra.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. Encontre o círculo de um poeta

Defina `circle-of`, que recebe um poeta e um clube e retorna o representante do círculo de escrita desse poeta. Dois poetas que compartilham um círculo sempre informam o mesmo representante.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. Compartilham um círculo?

Defina `same-circle?`, que recebe dois poetas e um clube e retorna `t` quando os dois poetas pertencem ao mesmo círculo de escrita e `f` caso contrário. Compare os representantes dos poetas em vez de usar um teste de equivalência embutido.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
