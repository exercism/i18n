# Recursos

Aqui estão alguns recursos úteis para ajudar você a aprender mais sobre SQLite e aprimorar suas habilidades:

- A [documentação oficial do SQLite][sqlite-docs] traz guias completos, tutoriais e referências sobre SQLite.

- [SQLite Command-Line Shell][sqlite-shell]: documentação do shell de linha de comando do SQLite, que permite interagir com bancos de dados SQLite usando comandos SQL.

- [SQLite FAQ][sqlite-faq]: perguntas frequentes sobre SQLite, cobrindo tópicos que vão da instalação à solução de problemas.

- [SQLite Forum][sqlite-forum]: o fórum do SQLite serve para fazer perguntas, relatar bugs, sugerir melhorias, buscar orientação e discutir softwares relacionados ao SQLite.

- [SQLite Browser][sqlite-browser]: uma ferramenta visual para criar, projetar e gerenciar bancos de dados SQLite, permitindo navegar e editar arquivos de banco de dados SQLite.

Explore estes recursos para aprofundar seu conhecimento sobre SQLite e melhorar sua proficiência no uso desse poderoso sistema de gerenciamento de banco de dados.

[sqlite-docs]: https://www.sqlite.org/docs.html
[sqlite-shell]: https://www.sqlite.org/cli.html
[sqlite-faq]: https://www.sqlite.org/faq.html
[sqlite-forum]: https://sqlite.org/forum/forum
[sqlite-browser]: https://sqlitebrowser.org/
