# Instruções

O setor de achados e perdidos da escola guarda tudo em caixas, e o que vai dentro de uma caixa pode ser qualquer coisa: um suéter, várias coisas, um nome.

Escreva uma classe `LOST_BOX{T}`. O código inicial já traz o cabeçalho da classe.

## 1. Receba algo

`create` recebe o item e o nome de quem o entregou, e retorna uma caixa. Uma caixa começa como não retirada.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. Marque como retirada

`claim` marca a caixa como retirada. Não retorna nada.

```sather
box.claim;
box.claimed
-- => true
```

## 3. Ainda está esperando?

`waiting` responde se a caixa ainda não foi retirada.

```sather
box.waiting
-- => false
```

## 4. Troque o conteúdo

`replace` recebe um novo item, coloca-o na caixa e retorna o que estava lá antes. O item que entra e o item que sai são ambos `T`.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. Descreva a caixa

`describe` retorna uma linha sobre a caixa, como
`"blue jumper, handed in by Mia"`.

Para colocar o item em uma string, a classe precisa saber que um `T` pode virar uma. Restrinja o parâmetro: escreva o cabeçalho da classe como
`class LOST_BOX{T < $STR}`, e assim `item.str` é permitido.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
