## Conheça o "Hello, World!"

"Hello, World!" é provavelmente o programa mais famoso do mundo.
Praticamente qualquer pessoa que aprendeu a programar já o escreveu pelo menos uma vez.
A sua simplicidade e a mensagem amigável costumam representar o primeiro passo no maravilhoso mundo da programação.

No Exercism, você recebe uma função chamada `hello` que retorna "Goodbye, Mars!".

```python
def hello():
    return 'Goodbye, Mars!'
```

Sua tarefa é alterá-la para que retorne "Hello, World!".

## A abordagem tradicional

Começando pela abordagem mais simples, aquela que o Exercism espera que você implemente.
Com uma simples mudança da string de "Goodbye, Mars!" para "Hello, World!", já podemos retorná-la com segurança!

```python
def hello() -> str:
    return 'Hello, World'
```

## Abordagens alternativas

Vou resolver este exercício usando todos os métodos diferentes que eu conseguir imaginar.

Para fins narrativos, vou me referir a essa função simples como a "máquina", uma máquina cujo único trabalho é retornar uma saudação "Hello, World!".

Vamos ver no que isso vai dar...!

### A junção

A máquina já conhece algumas das palavras, mas parece que ela não consegue, hã, digamos, bem, juntá-las.

```python
def hello() -> str:
    words = ["Hello", " world!"]
    return ",".join(words)
```

### O título

A bateria da máquina está meio fraca hoje, porque todas as palavras estão sem energia e não estão sendo capitalizadas corretamente.

```python
def hello() -> str:

    return words.title()
```

### O curry

Opa, opa, algumas partes da máquina estão em modo de manutenção.
Ela esqueceu a mensagem de saudação e agora só consegue aceitá-la parte por parte.

```python
def hello(greet: str):
    def world(location: str) -> str:
        return f"{greet}, {location}!"
    return world

hello("World")
```

### O ASCII

Você derramou um pouco de limonada na máquina sem querer e agora ela só mostra esses números estranhos em vez dos caracteres de sempre na mensagem.

```python
def hello() -> str:
    ascii = [72, 101, 108, 108, 111, 44, 32, 87, 111, 114, 108, 100, 33]
    return ''.join(chr(value) for value in ascii)
```

def hello(morse) -> str:

### A permutação

Uma forte tempestade passou por aqui e sua pobre máquina azarada foi atingida por um raio.
Ela ainda liga, mas agora está se comportando de forma estranha.
Todos os caracteres para montar a mensagem de saudação ainda estão lá, mas fora de ordem, e o dano na placa lógica faz com que a máquina não consiga mais acertar a ordem da mensagem.
E, para a sua sorte, a máquina menor incrivelmente confiável e *indestrutível* que você construiu antes, na verdade, podia ser roubada (sim, ela sumiu!).
Por isso, você decide simplesmente deixar seu velho amigo tentar todas as formas possíveis de embaralhar essas letras até formar a mensagem correta.
Afinal, são só 13 caracteres e a máquina tem bastante memória. Isso deve ser rápido...

```python
from itertools import permutations

def hello() -> str:
    chars = ['H', 'e', 'l', 'l', 'o', ',', ' ', 'W', 'o', 'r', 'l', 'd', '!']

    all_permutations = permutations(chars)
    for perm in all_permutations:
        if ("".join(perm) == "Hello, World!"):
            return ''.join(perm)
```

### Com classe

Você decide fazer experimentos e ajustar a máquina para se comportar de maneira diferente conforme o botão que for pressionado.
Você pensou em deixá-la um pouco mais informal, começando a dizer "Oi", mas, sendo uma pessoa *de classe*, você decide usar sempre o método `hello` e cobrir o outro com fita adesiva.
Você percebe que tem bastante tempo livre para essas coisas...

```python
class Greeting:
    location = "World"

    def __init__(self) -> None:
        pass

    def hello(self):
        return f"Hello, {self.location}!"

    def hi(self):
        return f"Hi, {self.location}!"

salutation = Greeting()
salutation.hello()
```

### A recursão

Por algum motivo, você decidiu que seria engraçado se a máquina tivesse um pouco de atraso e só respondesse 10 segundos depois. Seu irmão mais uma vez levanta a questão da lógica por trás desse recurso, porque, segundo ele, você é a única pessoa que usa a máquina.

```python
import time

def hello(n=10):
    if n == 0:
        return "Hello, World!"
    else:
        time.sleep(1)
        return hello(n-1)
```

### A aleatoriedade

De repente, um dia você simplesmente se cansa da mesma saudação repetidas vezes e decide deixá-la te cumprimentar uma última vez e aposentar a máquina de vez, sem nunca mais tocar nela.
Como a máquina esteve com você nos bons e maus momentos por muito tempo, você decide deixar esse encontro final entre "amigos" nas mãos do destino.
 Você a liga uma última vez e simplesmente a deixa girar...

```python
import random

def hello():
    chars = list("Helo,Wrld!")
    greeting = ""
    while (greeting != "Hello, World!"):
        greeting = "".join(random.choices(chars, k=13))
    return greeting
```
