# Apêndice das instruções

## Dicas

Para completar este exercício, você precisa implementar a função `wordCount`, que recebe um *texto* e retorna quantas vezes cada *palavra* aparece.

Se for a sua primeira vez resolvendo este exercício, é recomendável que você fique com a assinatura fornecida:

```haskell
wordCount :: String -> [(String, Int)]
```

Mais tarde, pode ser uma boa ideia voltar a este problema e brincar com outros tipos de dados e bibliotecas:

- `Text`, do pacote *text*.
- `Map`, do pacote *containers*.
- `MultiSet`, do pacote *multiset*

A suíte de testes foi projetada de propósito para aceitar quase qualquer assinatura de tipo que faça sentido, então fique à vontade para encontrar a que você achar melhor.
