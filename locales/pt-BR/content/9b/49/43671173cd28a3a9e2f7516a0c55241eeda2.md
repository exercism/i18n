# Dicas

## Geral

- Use funções anônimas.
- Funções anônimas podem referenciar variáveis que estavam no escopo quando elas foram definidas.

## 1. Crie um somador

- Retorne uma função anônima que soma o argumento da função anônima ao argumento passado para `secret_add`.

## 2. Crie um subtrator

- Retorne uma função anônima que subtrai o argumento passado para `secret_subtract` do argumento da função anônima.

## 3. Crie um multiplicador

- Retorne uma função anônima que multiplica o argumento da função anônima pelo argumento passado para `secret_multiply`.

## 4. Crie um divisor

- Retorne uma função anônima que divide o argumento da função anônima pelo argumento passado para `secret_divide`.

## 5. Crie um combinador de funções

- Retorne uma função anônima que combina cada uma das funções passadas para `secret_combine`.
