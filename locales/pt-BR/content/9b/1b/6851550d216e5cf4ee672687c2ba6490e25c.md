# Introdução

Os tipos de C# podem ser definidos dentro do escopo de uma classe ou struct. O tipo externo funciona como uma espécie de namespace. O acesso ao tipo é feito por meio do tipo externo, com a sintaxe de ponto.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Você pode definir níveis de acesso para os tipos internos.

Os membros privados do tipo externo estão no escopo dos membros do tipo interno, mas não o contrário.
