# Instruções

Refatore um analisador de Markdown.

O exercício de markdown é um exercício de refatoração.
Existe um código que analisa uma string qualquer com [sintaxe Markdown][markdown] e retorna o HTML correspondente a essa string.
Mesmo que esse código esteja escrito de forma confusa e seja difícil de acompanhar, de alguma forma ele funciona e todos os testes estão passando!
Seu desafio é reescrever esse código para deixá-lo mais fácil de ler e de manter, garantindo ao mesmo tempo que todos os testes continuem passando.

Seria útil se você anotasse em comentários o que fez na sua refatoração, para que quem revisar consiga ver, mas isso não é estritamente necessário.
O mais importante é deixar o código melhor!

[markdown]: https://guides.github.com/features/mastering-markdown/
