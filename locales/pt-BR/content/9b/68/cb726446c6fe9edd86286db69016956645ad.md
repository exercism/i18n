## MacOS

Primeiro, instale o Lua e o [Luarocks][2] usando o [Homebrew][1]:

```shell
$ brew install lua luarocks
```

Depois, instale o framework de testes [Busted][3] para Lua:

```shell
$ luarocks install --local busted
```

Adicione `~/.luarocks/bin` ao `$PATH` do seu sistema

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

Repare que isso é só temporário.
Para adicionar de forma permanente ao seu `$PATH`, você
vai precisar adicioná-lo ao seu `.bashrc`, `.zshrc` ou `config.fish`, dependendo
do shell que você usa.

Depois, rode seus testes:

```shell
$ busted
```

## Ubuntu

Depois, rode seus testes:


## Windows 10: WSL

Primeiro, você precisa habilitar o [WSL (Windows Subsystem for Linux)][7] usando o [PowerShell][8] (Administrador):

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

Isso exige reiniciar o computador.

Em seguida, instale o Ubuntu pela [Microsoft Store][9], **ou** baixe e instale usando o PowerShell:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

Depois, atualize sua lista de pacotes:

```shell
PS> wsl
$ sudo apt-get update
```

Agora você está pronto para instalar o [LuaRocks][2] e o [Busted][3] seguindo as [instruções do Ubuntu](#ubuntu) acima.

Depois disso, você pode rodar seus testes direto de qualquer linha de comando do Windows:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Instalar o Gitbash

Esta etapa é opcional. Talvez você precise ajustar um pouco os passos a seguir se preferir usar a CLI nativa do Windows ou outra CLI.

Baixe [aqui][10].
Instruções de instalação [aqui][11].

### Instalar o Docker

Siga as instruções para instalar o [Docker for Windows][12].
Quando terminar a instalação, rode o comando a seguir para garantir que tudo foi instalado corretamente.

```shell
$ docker --version
```

_Talvez você encontre um erro ao tentar rodar o Docker pela primeira vez._

`cannot enable hyper-v service`

_Se isso acontecer, você pode seguir estas instruções para [habilitar o Hyper V][13]. Talvez você precise desativar a configuração, reiniciar o computador e reativá-la depois de iniciar._

### Instalar o busted

Depois de instalar o Gitbash e o Docker, você vai conseguir instalar um 'contêiner' do busted.

No Gitbash, rode o seguinte:

Baixe este contêiner Docker muito usado rodando o seguinte:

```shell
$ docker pull imega/busted
```

Crie uma função para não precisar digitar o comando inteiro toda vez.
Adicione isto ao seu `.bashrc`:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

Agora, na sua CLI, você pode navegar até o diretório em que quer rodar seus testes. Rode o seguinte:

```shell
$ dbusted $PWD
```

Você deve ver a saída dos seus testes do busted.
