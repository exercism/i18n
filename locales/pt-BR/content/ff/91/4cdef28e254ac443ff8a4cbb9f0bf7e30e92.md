# Aprendizado

* [The Rust Programming Language](https://doc.rust-lang.org/book/) é um ótimo recurso para começar com Rust e também para se aprofundar em aspectos específicos da linguagem.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) mostra exemplos das coisas mais comuns que você vai escrever em Rust.
* [Into_rust()](http://intorust.com/) "Screencasts para aprender Rust."
* [Rustlings](https://github.com/carols10cents/rustlings) "Pequenos exercícios para você se acostumar a ler e escrever código Rust."
* O [Rust User Forum](http://users.rust-lang.org) tira dúvidas de todos os níveis.
