# Introdução

## Nil

[Nil][nil-dictionary] é uma palavra do inglês que significa "nada" ou "zero". No Elixir, `nil` é um valor especial que significa uma _ausência_ de valor.

```elixir
# I do not have a favorite color
favorite_color = nil
```

Em outras linguagens de programação, valores `null` ou `none` podem desempenhar um papel parecido.

## If

Além de `cond`, o Elixir também fornece a macro [`if/2`][getting-started-if], que é útil quando você precisa verificar apenas uma condição.

[`if/2`][kernel-if] aceita uma condição e duas opções. Ela retorna a primeira opção se a condição for _truthy_ e a segunda opção se a condição for _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Também é possível escrever uma expressão `if` em uma única linha. Repare na vírgula depois da condição.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Essa sintaxe é útil para expressões muito curtas, mas deve ser evitada se a expressão não couber em uma única linha.

### _Truthy_ e _falsy_

No Elixir, todos os tipos de dados são avaliados como um valor _truthy_ ou _falsy_ quando aparecem em um contexto booleano (como uma expressão `if`). Todos os dados são considerados _truthy_, **exceto** `false` e `nil`. Em particular, strings vazias, o número inteiro `0` e listas vazias são todos considerados _truthy_ no Elixir.
