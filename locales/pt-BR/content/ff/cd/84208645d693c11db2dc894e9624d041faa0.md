# Sobre

Um `Map` é usado para armazenar pares de **chave** e **valor**. Os `Maps` são inicializados assim como um array, mas usam o operador de literal de map `=>`. Eles também podem ter seus tipos de chave-valor definidos explicitamente, ou então os tipos podem ser inferidos. As chaves precisam ser únicas, caso contrário um erro é lançado.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

É possível iterar sobre um `Map` usando um laço `for`. Você pode iterar sobre os valores ou sobre as chaves:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

Por baixo dos panos, um `Map` é um tipo abstrato. Em tempo de compilação, ele é convertido para um de vários tipos especializados, dependendo do tipo da chave:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

O tipo `Map` não existe em tempo de execução e foi substituído por um dos objetos acima.
