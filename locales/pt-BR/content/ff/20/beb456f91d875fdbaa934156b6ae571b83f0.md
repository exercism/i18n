# Introdução

## Condicionais `switch`

Assim como uma condicional _if/else_, a condicional `switch` permite mudar o fluxo do programa executando código de forma condicional.
A diferença é que a condicional `switch` só consegue comparar o valor de uma expressão primitiva ou de uma string com valores constantes predefinidos.

Algumas palavras-chave são úteis ao usar uma condicional `switch`.

- `switch`: essa palavra-chave permite declarar a estrutura da condicional.
  Ela é seguida pela expressão ou pela variável que vai mudar o resultado.
- `case`: você vai usar essa palavra-chave para declarar as diferentes possibilidades de resultado.
- `break`: a palavra-chave `break` é muito útil para interromper a execução da condicional no fim do fluxo desejado.
  Se você esquecer dela, o programa continua e pode dar resultados inesperados.
- `default`: como o próprio nome diz, use-a como resultado padrão quando nenhum outro `case` corresponder ao resultado da sua expressão.

Na forma mais simples, elas testam uma expressão primitiva ou uma string e tomam uma decisão com base no valor dela.
Por exemplo:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
