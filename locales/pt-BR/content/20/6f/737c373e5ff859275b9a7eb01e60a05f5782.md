# Instruções

A trupe de dança se alinha em fileiras, e você está acompanhando quem fica
onde.

As cinco tarefas ficam na classe `DANCE_FORMATION`.

## 1. Quantos na fileira?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. Quem lidera?

O líder é quem fica em primeiro.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. Quem fica atrás?

Quem fica atrás é quem está por último, por mais longa que seja a fileira.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. A formação de abertura

A trupe sempre abre na mesma ordem: Mia, Ana, Ben. Retorne essa fileira.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

Esta rotina não recebe argumentos.

## 5. Conte os passos

Cada dançarino tem um número de passos a fazer. Some todos.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

Uma fileira vazia é zero passos.
