# Promoção de propriedades do construtor

Em classes que declaram muitas propriedades, declarar a classe, as propriedades e um construtor para definir essas propriedades separadamente exige repetição.
Com a promoção de propriedades do construtor, podemos reduzir essa repetição.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
