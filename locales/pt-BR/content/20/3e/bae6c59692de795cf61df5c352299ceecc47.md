# Dicas

## 1. Implemente o método calculate para dar suporte a algumas operações básicas

- Use uma [instrução `switch`][switch-statement-docs] para corresponder às diferentes operações.

## 2. Trate operações ilegais

- Você não pode verificar `null` dentro de uma instrução `switch`.
- Use um caso `default` para qualquer outra coisa no final do `switch`.

## 3. Trate a exceção lançada ao dividir por zero

- Use um [bloco `try-catch`][exception-handling-docs] para capturar a `ArithmeticException` lançada ao dividir por zero.
- A classe `IllegalOperationException` tem um construtor que recebe uma mensagem e uma causa como parâmetros.

[switch-statement-docs]: https://docs.oracle.com/javase/tutorial/java/nutsandbolts/switch.html
[exception-handling-docs]: https://docs.oracle.com/javase/tutorial/essential/exceptions/handling.html
