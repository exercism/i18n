# Anexo das instruções

## Dicas

Para este exercício, os seguintes recursos do F# são úteis:
- [(..) start finish](https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-operators.html#(..)) permite criar um intervalo de valores de forma sucinta.
- [List.sumBy](https://fsharp.github.io/fsharp-core-docs/reference/fsharp-collections-listmodule.html#sumBy) é um formato condensado para aplicar uma função a uma lista e depois somar os resultados.
