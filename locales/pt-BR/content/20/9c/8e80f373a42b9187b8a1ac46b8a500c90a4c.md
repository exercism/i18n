# Instruções

Neste exercício, você vai processar entradas de log.

Cada linha de log é uma string formatada da seguinte forma: `"[<LEVEL>]: <MESSAGE>"`.

Há três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Você tem três tarefas, e cada uma delas vai receber uma linha de log e pedir que você faça algo com ela.
Há muitas maneiras de resolver essas tarefas. Escolha suas técnicas favoritas nos exemplos acima e veja o que você consegue fazer.

## 1. Obtenha a mensagem de uma linha de log

Implemente a função `message` para retornar a mensagem de uma linha de log:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

Qualquer espaço em branco no início ou no final deve ser removido:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. Obtenha o nível de log de uma linha de log

Implemente a função `log_level` para retornar o nível de log de uma linha de log, que deve ser retornado em minúsculas:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. Reformate uma linha de log

Implemente a função `reformat` que reformata a linha de log, colocando a mensagem primeiro e o nível de log depois dela entre parênteses:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
