# Introdução

O PHP permite declarar funções dentro de outras funções. Essas funções não precisam ter um nome, mas podem ser atribuídas a variáveis ou até passadas diretamente para outra função que espera um parâmetro de função.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
