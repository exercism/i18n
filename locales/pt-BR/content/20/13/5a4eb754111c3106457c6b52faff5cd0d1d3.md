# Introdução

Quando você tem vários valores discretos possíveis e precisa escolher entre eles, `case` (em [`combinators`][combinators]) é uma opção mais limpa do que uma cadeia de `if`s.

## `case`

```
case ( obj assoc -- )
```

`case` retira o valor do topo da pilha e um *assoc* de cláusulas. Cada cláusula é `{ value [ body ] }`. A primeira cláusula cujo valor `=` o valor de entrada vence; o corpo dela roda com o valor de entrada *já consumido*. Uma entrada final que é só `[ body ]` é o padrão: o valor de entrada ainda está na pilha quando ela roda.

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

A igualdade é feita com `=`, então qualquer coisa que compare como igual funciona como chave: números, strings e símbolos também.

## `cond` para ramificações com guarda

Quando a escolha depende de um *predicado* em vez de uma igualdade (por exemplo, `x > 11`), `cond` é a ferramenta certa. Você conheceu `cond` em [Carros, montem!][cars-assemble].

## Símbolos

Um `SYMBOL:` declara uma palavra que empurra a si mesma para a pilha: um valor de tag que se autoavalia. `SYMBOLS:` declara vários de uma vez:

```factor
SYMBOLS: yes no maybe ;
```

Agora `yes` é um valor, comparável com `=`, que você pode usar como chave em um `case`:

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
