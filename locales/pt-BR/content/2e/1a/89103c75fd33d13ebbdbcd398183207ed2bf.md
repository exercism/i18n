# Fluxo de trabalho do configlet

O configlet usa a [ferramenta configlet](/docs/building/configlet) para verificar se os arquivos (de configuração) de uma trilha estão estruturados corretamente, tanto sintática quanto semanticamente.
Para isso, ele executa o comando [`configlet lint`](/docs/building/configlet/lint).

## Ativar a verificação da formatação dos arquivos

As trilhas podem usar o [`configlet fmt`](/docs/building/configlet/format) para formatar os vários arquivos de configuração da trilha.
O mesmo comando também pode ser usado para verificar se todos os arquivos de configuração estão formatados corretamente.

O fluxo de trabalho do `configlet` permite verificar se os arquivos de configuração estão formatados corretamente, mas isso é opcional e vem desativado por padrão.
Para optar por verificar a formatação dos arquivos de configuração, siga estes passos:

1. Crie um arquivo `.github/org-wide-files-config.toml` com o seguinte conteúdo

```toml
[configlet]
fmt = true
```

2. Depois que este arquivo for mesclado na `main`, um PR será aberto automaticamente, modificando o fluxo de trabalho `configlet.yml` da seguinte forma:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. Depois que esse PR for mesclado, o fluxo de trabalho do `configlet` também vai verificar a formatação dos arquivos de configuração da trilha.

## Fonte

O fluxo de trabalho é definido no arquivo `.github/workflows/configlet.yml`.
