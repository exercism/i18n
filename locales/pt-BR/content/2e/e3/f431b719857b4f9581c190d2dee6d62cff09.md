# Apêndice das instruções

## Observação

Esse tipo de problema (em que uma resposta depende de uma anterior) costuma ser chamado de recursão. Existem diferentes formas de programar com recursão, e pode valer a pena pesquisar sobre o assunto caso você ainda não o conheça. O Pharo é bem otimizado para recursão, e esse é um padrão bastante usado.

Observação: na especificação original do problema, o grainsCalculator é chamado por #square, mas renomeamos esse método para #atSquare:, que é um nome mais no estilo Smalltalk e descreve melhor que você está pedindo uma resposta "em uma casa".
