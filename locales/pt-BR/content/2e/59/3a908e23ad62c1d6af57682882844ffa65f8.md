# Introdução

Embora o modificador `readonly` impeça que o valor ou a referência de um campo seja sobrescrito, ele não oferece nenhuma proteção para os membros de um tipo de referência.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Para garantir que todos os membros de um tipo de referência estejam protegidos, os campos podem ser marcados como `readonly` e propriedades automáticas podem ser definidas sem um acessador `set`.

A Biblioteca de Classes Base (BCL) oferece algumas versões somente leitura de coleções quando há a necessidade de impedir que os membros de uma coleção sejam atualizados. Elas vêm na forma de wrappers:

- `ReadOnlyDictionary<T>` expõe um `Dictionary<T>` como somente leitura.
- `ReadOnlyCollection<T>` expõe um `List<T>` como somente leitura.
