# Sobre

[Emacs Lisp](https://www.gnu.org/software/emacs/manual/) é a linguagem no coração do Emacs, o icônico editor de texto que está lá no início do movimento do Software Livre.
O Emacs é feito de mais de um milhão de linhas de Emacs Lisp, e todos os programas que rodam dentro do Emacs (IDEs para diversas linguagens de programação, jogos, planejadores, etc.) são escritos em Emacs Lisp.
As preferências do usuário também são listas de expressões em Emacs Lisp.

Conhecer Emacs Lisp é o primeiro passo para o Lisp, a segunda linguagem de programação mais antiga ainda em uso (acabou de completar 60 anos em 2018) e também uma linguagem que ainda influencia tantas outras linguagens de programação.

[Citando o criador do Emacs](https://www.gnu.org/gnu/rms-lisp.html):
"O Multics Emacs se provou um grande sucesso: programar novos comandos de edição era tão conveniente que até as secretárias do escritório dele começaram a aprender a usá-lo. Elas usavam um manual que alguém tinha escrito e que mostrava como estender o Emacs, mas não dizia que aquilo era programação. Então as secretárias, que achavam que não conseguiriam programar, não se assustaram. Elas leram o manual, descobriram que conseguiam fazer coisas úteis e aprenderam a programar."
