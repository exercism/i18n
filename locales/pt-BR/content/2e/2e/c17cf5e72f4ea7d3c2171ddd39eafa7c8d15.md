# Introdução

O uso de correspondência de padrões é dominante em código Elixir idiomático e assertivo. Você deve se lembrar de que `=/2` é descrito como um operador de correspondência, e não como um operador de atribuição. Ao usar o operador de correspondência, se o padrão à esquerda corresponder ao da direita, as variáveis à esquerda são vinculadas e o valor do lado direito é retornado. Um `MatchError` é lançado se não houver correspondência.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

Lembre-se: as correspondências ocorrem do lado direito para o lado esquerdo.

No último exemplo, se não precisarmos de uma variável em uma correspondência de padrões, podemos descartá-la usando `_`. Qualquer variável que comece com um `_` não é rastreada em tempo de execução.

## Correspondência de padrões em funções nomeadas

A correspondência de padrões também é uma ferramenta útil ao criar várias cláusulas de função. Ela pode ser usada nos argumentos das funções, o que determina qual cláusula de função será chamada. A busca começa no topo do arquivo e desce até a primeira correspondência. As variáveis podem ser vinculadas no cabeçalho da função e usadas no corpo dela.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
