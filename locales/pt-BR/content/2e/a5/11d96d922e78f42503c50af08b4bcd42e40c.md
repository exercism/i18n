# Instruções

Neste exercício, você vai escrever código para acompanhar uma lista de linguagens de programação que você quer aprender no Exercism.

São seis tarefas, e todas elas envolvem lidar com listas.

## 1. Crie uma nova lista

Para acompanhar as linguagens que você quer aprender, você vai precisar criar uma nova lista. Defina a função `new_list`, que retorna uma nova lista vazia.

```gleam
new_list()
// -> []
```

## 2. Defina uma lista existente

No momento, você tem um papel com as linguagens que quer aprender: Gleam, Go e TypeScript. Defina a função `existing_list` para retornar essa lista.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. Adicione uma nova linguagem a uma lista

Conforme você explora o Exercism e encontra linguagens mais interessantes, você vai querer adicioná-las à sua lista. Implemente a função `add_language` para adicionar uma nova linguagem ao início da sua lista.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. Conte as linguagens da lista

Contar as linguagens uma a uma é inconveniente. Implemente a função `count_languages` para contar quantas linguagens há na sua lista.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. Inverta a lista

Em algum momento, você percebe que sua lista está na verdade na ordem inversa! Implemente a função `reverse_list` para inverter sua lista.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. Verifique se a lista é empolgante

Embora você ame todas as linguagens, Gleam tem um lugar especial no seu coração. Por isso, você fica muito empolgado com uma lista de linguagens se:

- A primeira da lista é Gleam.
- O segundo item da lista é Gleam e a lista contém duas ou três linguagens.

Implemente a função `exciting_list` para verificar se uma lista de linguagens é empolgante:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
