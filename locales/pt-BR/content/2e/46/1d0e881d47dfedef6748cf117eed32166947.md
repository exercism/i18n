# Dicas

## Geral

- [Dicionários no The Cairo Book][book]
- [Guia rápido do Cairo][cheatsheet]

## 1. Armazene a unidade de medida no seu programa

- Para armazenar as medidas no seu programa, você pode inseri-las uma a uma em um dicionário

## 2. Crie uma nova conta

- Para criar uma nova conta, basta inicializar um dicionário

## 3. Adicione um item à conta do cliente

- Para verificar se a unidade de medida informada está correta, você pode testar se o seu dicionário de medidas retorna um valor diferente de zero para uma chave

## 4. Remova um item da conta do cliente

- Para verificar se o item informado está na conta do cliente, você pode testar se o seu dicionário da conta retorna um valor diferente de zero para uma chave

- Para verificar se a unidade de medida informada está correta, você pode testar se o seu dicionário de medidas retorna um valor diferente de zero para uma chave

## 5. Retorne a quantidade de um item específico que está na conta do cliente

- Para verificar se o item informado está na conta do cliente, você pode simplesmente recuperá-lo do dicionário
