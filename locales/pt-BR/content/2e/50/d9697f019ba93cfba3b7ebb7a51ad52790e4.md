# Introdução

No F#, atribuir um valor a um nome é chamado de _binding_. Bindings são imutáveis, o que faz com que se pareçam com constantes de outras linguagens. Como o F# é uma linguagem de tipagem estática, cada binding tem um tipo em tempo de compilação.

Os bindings são definidos com a palavra-chave `let`. Especificar o tipo de um binding é opcional na maioria dos casos, já que a _inferência de tipos_ do F# geralmente consegue inferir o tipo com base no valor. Um binding se parece com isto:

```fsharp
// Automatically inferred type
let fingers = 10
```

Funções também são bindings comuns, mas com um ou mais parâmetros. Uma função retorna automaticamente sua última expressão. A inferência de tipos também funciona para a maioria das funções, analisando com quais valores a função é chamada e qual valor ela retorna.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Para invocar uma função, você especifica o nome dela e passa argumentos para cada um dos parâmetros da função.

```fsharp
let five = add 2 3
```

Se o tipo de um binding não puder ser inferido, o compilador vai reportar um erro. Para corrigir isso, adicione uma anotação de tipo explícita ao binding.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Os bindings no F# só podem ser usados _depois_ de serem definidos. Usar um binding antes de defini-lo resulta em um erro de compilação.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

O F# usa espaços em branco significativos para definir escopo. Isso significa que o escopo é definido pela indentação do código com espaços, em relação à linha que declara o binding. A convenção padrão é usar quatro espaços para a indentação:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Os bindings do F# (que incluem funções) geralmente são organizados em módulos. Um módulo agrupa funcionalidades relacionadas e é definido com a palavra-chave `module`. A definição do módulo deve vir antes dos seus bindings:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

O F# dá suporte a dois tipos de comentários. Comentários de uma linha são precedidos por `//` e comentários de várias linhas são inseridos entre `(*` e `*)`.
