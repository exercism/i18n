# Exceções

```sather
   raise "Unknown prop: " + prop;
```

```sather
   protect
      ...
   when $STR then
      #OUT + exception.str;
   end;
```

## raise

`raise` aceita qualquer objeto. Lançar uma `STR` é o caso simples, e é o que
este exercício usa. Uma classe sua carrega mais informação, como qual prop e
quantos eram necessários, mas tem o custo de precisar de um lugar para
defini-la.

Uma exceção percorre para fora, por quem chama, até que um `protect` a capture.
Se nenhum capturar, o programa para e a imprime.

Sather não registra quais exceções uma rotina pode lançar, e não obriga quem
chama a tratá-las. Nada no tipo de uma rotina diz que ela pode falhar.

## protect

```sather
   protect
      body
   when $STR then
      ...
   when SOME_CLASS then
      ...
   end;
```

Os ramos são testados em ordem, e o primeiro cujo tipo corresponde ao valor
lançado é executado. `exception` é esse valor, e só está no escopo dentro de um
ramo.

Um `protect` sem nenhum ramo correspondente não captura: a exceção segue para
fora como se o `protect` não estivesse ali.

## Onde capturar

Capture onde algo realmente pode ser feito. Um `protect` que engole uma exceção
e segue em frente com um valor inventado transforma uma falha barulhenta em uma
resposta errada silenciosa, o que é pior.

```sather
   -- almost always wrong
   protect
      return risky;
   when $STR then
      return 0;
   end;
```

## Exceções ou contratos?

Os dois tratam de coisas que dão errado, e servem para casos opostos.

Uma **exceção** serve para algo que pode genuinamente acontecer e que quem chama
pode, razoavelmente, não ter conseguido evitar: um prop que falta na tabela, um
arquivo que não está lá.

Um **contrato**, que é o próximo exercício, serve para algo que nunca deve
acontecer, como quem chama passar um peso negativo, e é uma afirmação de que
quem chama tem um bug. Os contratos são verificados só quando pedidos, e um
contrato violado para o programa em vez de lançar algo que dê para capturar.

Resumindo: se quem chama, por mais cuidadoso que seja, ainda pode esbarrar
nisso, lance. Se esbarrar nisso significa que quem chama está errado, coloque
isso num contrato.
