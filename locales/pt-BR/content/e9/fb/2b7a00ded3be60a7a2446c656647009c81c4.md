# Apêndice das instruções

## Devo usar `random` ou `secrets` aqui?

A partir do Python 3.6, existem dois módulos diferentes para produzir números "aleatórios":

O módulo chamado [`random`][random] é [_pseudoaleatório_][pseudo-random], ou seja, **não** gera
aleatoriedade de verdade, mas segue um algoritmo que _simula_ aleatoriedade.
Como esses "números aleatórios" são gerados por um algoritmo conhecido, eles não são realmente aleatórios.
Por isso, o módulo `random` não é adequado para criptografia e não deve ser usado,
justamente porque é pseudoaleatório.


O módulo chamado [`secrets`][secrets] gera
números "aleatórios" [criptograficamente fortes][crypto-strong], que oferecem a segurança maior exigida pela criptografia.
Eles ainda são pseudoaleatórios no sentido mais estrito, mas têm garantias de que os números que produzem são absolutamente imprevisíveis.


Como este é apenas um exercício de prática, usar o módulo `random` não tem problema, mas note que **seria
muito inseguro se fosse realmente usado para criptografia.**

[crypto-strong]: https://cryptobook.nakov.com/secure-random-generators/secure-random-generators-csprng
[pseudo-random]: https://en.wikipedia.org/wiki/Pseudorandomness
[random]: https://docs.python.org/3/library/random.html
[secrets]: https://docs.python.org/3/library/secrets.html
