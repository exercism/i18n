# Instruções

Você é o radiotelegrafista de um cargueiro. O sinal chega por
uma linha ruidosa, com o barulho das máquinas do navio, estática
do tempo e conversas estrangeiras ocasionais, tudo intercalado
com o Morse que você está tentando ouvir. Para captar a
mensagem, você passa o fio por um dispositivo de *fita* que
remove tudo, exceto os símbolos Morse válidos (`.`, `-` e o
espaço que separa as letras).

Seu trabalho é construir a fita como um fluxo de entrada
personalizado do Factor.

## 1. Defina a fita

Defina uma tupla `tape` que estende `disposable` e contém um
slot, `wire`, para o fluxo de entrada subjacente.

```factor
TUPLE: tape < disposable wire ;
```

Depois escreva o construtor `<tape> ( wire -- tape )`. Use
`new-disposable` (e não `new`) para que o framework do destrutor
registre a fita, e guarde o fluxo subjacente no slot `wire`.

## 2. Adira ao mixin input-stream

Declare que `tape` é um `input-stream`:

```factor
INSTANCE: tape input-stream
```

Assim, os combinadores padrão do protocolo despacham para a sua
classe.

## 3. Leia um símbolo Morse

Implemente `M: tape stream-read1 ( tape -- elt/f )`. Leia bytes
do fio subjacente até encontrar um de `CHAR: .`, `CHAR: -` ou
`CHAR: \s` (espaço). Retorne esse byte. Se o fio retornar `f`
(fim de fluxo), retorne `f` também: a fita acabou.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. Delegue o tipo de elemento

Implemente `M: tape stream-element-type ( tape -- type )`
delegando ao fio: a fita não muda o tipo de elementos que estão
sendo lidos.

## 5. Faça a limpeza

Implemente `M: tape dispose* ( tape -- )`. O framework chama o
seu método exatamente uma vez por `dispose`; basta descartar o
fio subjacente.

Com essas cinco peças no lugar, a fita funciona como um fluxo de
entrada comum: `with-input-stream`, `stream-read` e as demais
palavras do protocolo despacham automaticamente para os seus
métodos.
