# Sobre

O conceito básico de `try .. rescue` pode ser estendido para suportar as cláusulas `else` e `after`:

- O bloco `else`:
  - Onde ocorre uma correspondência de padrão com o resultado de sucesso do bloco `try`.
- O bloco `after`:
  - Onde funções são invocadas, seja o bloco `try` bem-sucedido ou resgatado, desde que o programa esteja rodando.
  - O resultado do bloco `after` não é retornado ao escopo de chamada.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
