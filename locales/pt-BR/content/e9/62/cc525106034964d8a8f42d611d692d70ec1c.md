# Rodando os testes do Ceylon

Antes de rodar os testes, seu código precisa ser compilado com [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html).

Rodamos os testes com o comando [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html).

O comando `ceylon test` espera o nome de um módulo para rodar os testes.
Na trilha de Ceylon, cada exercício tem apenas um módulo.

Por isso, você pode rodar os testes com:

```bash
ceylon compile && ceylon test $(basename source/*)
```
