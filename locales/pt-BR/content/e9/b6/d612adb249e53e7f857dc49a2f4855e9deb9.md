# Threads

Este exercício introduz threads para testar o quanto a sua conta bancária é robusta em operações concorrentes. Um pouco de material de leitura sobre threads no Tcl:

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf),
  um capítulo de _Practical Programming in Tcl and Tk, 4th Ed._,
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * Observação: este capítulo afirma que "a maioria das distribuições binárias do Tcl não tem suporte a threads". Isso não é mais verdade: hoje as distribuições do Tcl são compiladas com suporte a threads (consulte a [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) da documentação do Tcl.

## Instalação

Algumas distribuições do Tcl não trazem o pacote Thread por padrão: pode ser preciso instalá-lo separadamente.
Verifique com
```bash
$ echo 'package require Thread' | tclsh
```
Se isso não gerar _nenhuma saída_, o pacote Thread já está instalado.

Execute `apt install tcl-thread` (ou `dnf install tcl-thread`) conforme necessário.
