# Complemento das instruções

## Registradores

| Registrador | Uso        | Tipo     | Descrição                     |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | entrada    | inteiro | índice do primo            |
| `$v0`    | saída      | inteiro | valor do enésimo primo     |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário |
