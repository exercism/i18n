# Testes

Para rodar os testes fornecidos, você vai precisar da gem Minitest. Abra uma janela do terminal e rode o seguinte comando para instalar o minitest:

```
gem install minitest
```


Rode os testes a partir do diretório do exercício com o seguinte comando:

```
ruby <snake-case-exercise>_test.rb
```

Substitua `<snake-case-exercise>` pelo nome do seu exercício em snake_case.

## Saída colorida

Você pode usar `require 'minitest/pride'` ou rodar o seguinte comando para ter uma saída colorida:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
