# Introdução

Para aprender o básico sobre argumentos de função, veja o [conceito de função][function concept].

## Nomes de parâmetros

Os [nomes de parâmetros][parameters], assim como os nomes de variáveis, precisam começar com uma letra ou um sublinhado e podem conter letras, sublinhados ou números.
Os nomes de parâmetros não devem conter espaços nem pontuação.


## Argumentos posicionais

Argumentos posicionais são valores passados a uma função na mesma ordem dos parâmetros aos quais eles se vinculam.
Opcionalmente, eles podem ser passados usando o nome do parâmetro:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

A primeira chamada de concat passa os argumentos por posição.
A segunda chamada de concat passa os argumentos por _nome_, permitindo que suas posições sejam alteradas.

Repare que argumentos posicionais não podem vir depois de argumentos passados por nome (_também chamados de [argumentos nomeados][keyword-arguments]. **Não** devem ser confundidos com parâmetros var-posicionais ou [**kwargs][kwargs]_).

Este conjunto de argumentos:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

vai resultar neste erro:

```
SyntaxError: positional argument follows keyword argument
```

## Valores padrão para argumentos

[Valores padrão][default arguments] para um ou mais argumentos podem ser fornecidos na lista de parâmetros.
Isso permite chamar a função com _menos_ argumentos, se necessário.
Os valores padrão podem ser substituídos chamando a função com novos argumentos no lugar dos padrões:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## Argumentos nomeados

Os argumentos nomeados usam o nome do parâmetro ao passar argumentos para uma função.
Opcionalmente, eles podem ser referenciados por posição:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
