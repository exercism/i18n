# Sobre

- O tipo [binary][binary] é uma especialização do tipo [bitstring][bitstring].
- Binários são compostos de [bytes][wiki-byte].
  - Bytes são 8 [bits][wiki-bit].
  - Bytes podem representar números de `0` a `255`
  - Valores inteiros [hexadecimais][wiki-hexadecimal] são comuns quando se trabalha com bytes: `0x00` a `0xFF`.
- Literais binários são definidos usando a [forma especial `<<>>`][special-form].
  - Se você usar um inteiro maior que `255` para um byte, apenas os últimos 8 bits são usados, a menos que você especifique a [unidade e/ou o tamanho a usar][bin-size] com o operador [`::`][type-operator].
- [`<>/2`][bin-concat] pode ser usado para concatenar bitstrings/binários/strings.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

Um _byte nulo_ é outro nome para `<<0>>`.

## Strings são dados binários codificados

- Strings são dados binários codificados no formato [UTF-8][wiki-utf8].
  - Elas são codificadas em blocos de 8 bits (um byte), usando até 4 bytes para representar mais de 255 caracteres.
  - O [comprimento de uma string][string-length] pode não ser igual ao seu [tamanho em bytes][byte-size].

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## Correspondência de padrões em dados binários

- É possível fazer correspondência de padrões com binários como um todo ou usar a forma especial para corresponder a apenas uma parte.
  - Apenas a última parte em uma correspondência de padrões pode ter tamanho variável.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

Isso também pode ser feito para strings:

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
