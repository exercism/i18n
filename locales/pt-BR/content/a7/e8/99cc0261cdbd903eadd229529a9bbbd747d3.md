# Introdução

## Herança

Herança é um conceito central na POO (Programação Orientada a Objetos).
Ela representa uma relação É-UM.
Na programação, significa literalmente o mesmo que em inglês: herdar características da classe pai (na programação, essas características geralmente são funções e variáveis).

Considere uma classe `Animal`, como mostrado a seguir:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` é uma classe pai, porque as propriedades dessa classe podem ser estendidas a todos os animais em geral.

Considere um animal chamado `Lion`, com uma classe como esta:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
A anotação `Override` é usada para indicar que um método em uma subclasse está sobrescrevendo um método da sua superclasse.
Ela não é estritamente necessária, mas usá-la é uma boa prática.
~~~~

Agora, sempre que fizermos:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Repare: estamos inicializando a classe `Animal` com `Lion`.
A saída será assim:

```java
Lion here!!
```

De acordo com a POO, existem muitos tipos de herança, mas o Java suporta apenas alguns deles (multinível e hierárquica).
Para saber mais, leia [este artigo][java-inheritance].
