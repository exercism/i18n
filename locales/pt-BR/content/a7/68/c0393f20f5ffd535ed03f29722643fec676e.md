# Instalação para hackers de Linux (somente para uso avançado no Linux)

Ainda estamos definindo as melhores instruções aqui, mas sabemos (e agradecemos) que muitos desenvolvedores de Linux são bastante exigentes quanto ao que instalam e onde as coisas devem ficar.

_Se você prefere uma instalação padrão, é só voltar e seguir [a configuração normal](https://exercism.io/tracks/pharo-smalltalk/installation)._

As instruções a seguir estão muito em construção (WIP) e são baseadas no ArchLinux, mas podem servir para a sua distro (e, se não servirem, ajude-nos a encontrar melhorias, e possivelmente a enviar pedidos ao próprio Pharo). _Observação: ainda não está claro se estas instruções funcionam de forma confiável, então agradecemos qualquer ajuda para melhorá-las._

- Instale uma VM do Pharo no local que você preferir. Talvez você consiga usar uma do AUR ou equivalente, se o Pharo 7 estiver listado lá. Ou, como alternativa, baixe uma em: [https://files.pharo.org/vm/pharo-spur64/linux/] (e escolha uma vm stable-timer)
- Em seguida, você precisa extrair um arquivo Pharo.image para colocar no seu diretório do exercism. Você pode obtê-lo em: [https://files.pharo.org/image/70/] e escolher o arquivo zip de 64 bits mais recente.
- Agora tente um teste simples na linha de comando para verificar se a VM e a imagem estão funcionando: `pharo Pharo.image eval "100 factorial"`. Se estiver tudo certo, você deve receber uma resposta.
- Agora tente o "load script" descrito na seção do OSX. Talvez você receba um erro mencionando `libgit2`; se for o caso, instale essa biblioteca também e tente de novo. Também recebemos relatos de que instalar `libcurl-gnutls` pode ajudar (mas isso ainda não foi comprovado)
- Também recebemos relatos de que, para algumas falhas do libgit2, existe uma alteração interna em loadModule que talvez possamos trazer do Pharo em desenvolvimento. Nesse caso, você precisa substituir o método `unixModuleName` na classe `LGitLibrary` da seguinte forma:
  1. Abra um Pharo com interface gráfica (headfull) digitando `pharo-ui Pharo.image`
  1. Pressione Ctrl-Space e digite `unixModuleName`
  1. Selecione a entrada `LGitLibrary >> unixModuleName` e pressione enter
  1. No navegador que abrir, substitua o código-fonte do método `unixModuleName` pelo seguinte (copie e cole), pressione salvar (ctrl-s) e, por fim, salve e saia do Pharo.
```
LGitLibrary >> unixModuleName
	| pluginDir |
	pluginDir := Smalltalk vm binary parent.
	#('libgit2.so' 'libgit2.so.0')
		detect: [ :each | (pluginDir / each) exists ] 
		ifFound: [ :libName | ^ (pluginDir / libName) fullName ].

	self error: 'Module not found.' 
 ```

Agora tente de novo o "load script" do exercism para OSX que mencionamos acima. Se estiver tudo funcionando corretamente, você verá barras de progresso de carregamento piscando pela tela e, depois, uma janela do System Browser vai aparecer. Se não, visite o Discord do Pharo (conforme explicado acima).

Agora é só voltar e seguir o restante das [Instruções de primeiros passos](https://exercism.io/tracks/pharo-smalltalk/installation).
