# Sobre

O JavaScript tem um operador de incremento e um operador de decremento.
Eles modificam uma variável no próprio lugar.
`++` acrescenta um a um número e `--` subtrai um de um número.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

O exemplo acima mostra o operador de incremento/decremento pós-fixado.
Nesse caso, o operador fica depois da variável e o valor de retorno da expressão é o valor da variável _antes_ do incremento/decremento.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

Existe também a variante prefixada, em que o operador fica antes da variável.
Aí o valor de retorno é o valor da variável _depois_ do incremento/decremento.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
