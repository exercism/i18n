# Instruções

Lucy, a alienígena do Lisp, gosta de Números, e acha que alguns deles são "magníficos".

Ela pede que você a ajude a escrever funções para deixar os números mais magníficos.

O que Lucy considera magnífico em um número pode mudar, então as funções precisam ser flexíveis.

## 1. Torne magnífico

Para transformar uma lista de números em uma lista de números mais magníficos, você vai precisar escrever uma função `make-magnificent-maybe` que recebe uma função para aplicar aos números e uma lista de números.
Ela deve resultar em uma lista de números mais magníficos (de acordo com a função fornecida)

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. Só os melhores

Depois de (esperançosamente) deixar os números mais magníficos, Lucy quer ver apenas os números que são realmente magníficos.

Ela sabe com certeza que 1 *nunca* é magnífico, então você só precisa remover esse.

Mas fora isso, Lucy às vezes muda de ideia, então mais uma vez ela vai te dar uma função que diz se um número é magnífico ou não.

Você vai precisar escrever uma função `only-the-best` que recebe uma função e uma lista de números e retorna apenas os melhores números (nem o `1` e nem os números para os quais a função resulta em verdadeiro).

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
