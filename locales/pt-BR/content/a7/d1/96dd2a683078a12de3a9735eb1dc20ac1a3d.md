# Dicas

## 1. Determinar quanto tempo leva para misturar um suco

- Reveja o conceito [Switch][concept-switch] para ter ideias de como abordar isso.

## 2. Reabastecer o estoque de gomos de limão

- Faça um laço até que uma das condições das instruções seja satisfeita.
- Pode ser útil, embora não seja obrigatório, ter uma pequena função auxiliar que relacione os tamanhos das limas ao número de gomos que elas rendem.
- Novamente, o conceito [Switch][concept-switch] pode sugerir abordagens convenientes.
- Retorne quantas limas foram realmente cortadas.

## 3. Listar os tempos para misturar cada pedido da fila

- Nesta etapa do programa de estudos, a abordagem mais fácil usa um laço `for` sobre `orders`, mas também dá para fazer com `seq_along`.
- Uma tarefa anterior pode fornecer uma função útil.
- Use [`print()`][print-function] para mostrar os tempos em ordem (veja um exemplo na introdução).
- Você não deve retornar nada neste exercício.

## 4. Terminar o turno

- Faça um laço enquanto houver pedidos e ainda sobrar tempo.
- Retorne um vetor com os pedidos que não foram iniciados.
