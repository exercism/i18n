# Dicas

## Geral

- `case` (em [`combinators`][combinators]) é a ferramenta certa para encontrar correspondência com valores iguais; `cond` é a ferramenta certa para predicados com guarda.
- Os símbolos (`yes`, `no`, `maybe`, `korean`, …) já estão declarados via `SYMBOLS:` no arquivo do exercício.

## 1. Avalie a culinária

- Um `case` de duas cláusulas, mapeando `korean` e `turkish` para os seus valores de aprovação.

## 2. Avalie o gênero do filme

- Faça a correspondência com `romance` e coloque um padrão `[ drop no ]` para o resto.
  Lembre-se de que o bloco padrão vê o valor original no topo: dê `drop` nele antes de empilhar o resultado.

## 3. Avalie a caminhada

- Use `cond` (também em `combinators`): cada guarda é `[ dup N > ]`.
  O corpo precisa dar `drop` nos quilômetros antes de empilhar a aprovação.

## 4. Avalie a atividade

- A atividade é `{ tag value }`. Use `first2` para empilhar os dois na pilha e depois `swap`, para deixar a tag no topo: é contra isso que o `case` faz a correspondência.
- Os blocos de `board-game` e `chill` veem o valor (`f`) ainda na pilha; dê `drop` nele antes de empilhar a aprovação.
- Os blocos de `movie`, `restaurant` e `walk` veem o valor relevante ainda na pilha, então você pode chamar diretamente a sua palavra da tarefa 2/1/3.
