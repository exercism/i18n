# Sobre

Tipos de C# podem ser definidos dentro do escopo de uma classe ou struct. O tipo externo funciona como uma espécie de namespace. O acesso ao tipo é feito por meio do tipo externo, com sintaxe de ponto.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Níveis de acesso

Os níveis de acesso podem ser aplicados aos tipos internos. Por exemplo, se uma classe for `private`, ela não pode ser vista fora do escopo do tipo externo e, claro, instâncias dela também não podem ser vistas ou usadas fora desse escopo.

Os membros privados da classe externa estão no escopo de todos os membros da classe interna, mas apenas os membros não privados da classe interna estão no escopo dos membros da classe externa. Para acessar os membros da classe externa, a classe interna precisa receber uma instância da classe externa.

Veja isso no exemplo a seguir:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Evitar a instanciação independente

Existe um padrão para impedir que um tipo instanciável seja criado fora do tipo externo. Você expõe uma interface pública, mas mantém a classe que a implementa privada.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Nota para desenvolvedores Java

As classes aninhadas do C# são um meio-termo entre as classes aninhadas estáticas e as classes internas do Java. No C#, os membros privados da classe externa estão no escopo dos membros da classe aninhada, mas não existe uma sintaxe especial para instanciá-los e vinculá-los a uma instância da classe externa. Você precisa usar alguma variação do padrão ilustrado nos exemplos acima.

O C# tem, sim, classes aninhadas estáticas, mas elas são apenas classes que ficam dentro de outra, com comportamento estático.
