# use argumento padrão

[comment]: # (Este erro é exibido quando a solução não usa argumentos padrão)

Use um [argumento padrão](https://elixir-lang.org/getting-started/modules-and-functions.html#default-arguments) nesta solução.

- [Argumentos padrão](https://elixir-lang.org/getting-started/modules-and-functions.html#default-arguments) eliminam a necessidade de escrever cláusulas de função duplicadas para funções com [aridades](https://en.wikipedia.org/wiki/Arity) diferentes.

```elixir
# Consider this function:
def foo(bar \\ "baz") do
  IO.puts(bar)
end
```

- Essa função agora define tanto `foo/0` quanto `foo/1`
- se `foo()` for chamada, `"baz"` é escrito para o application group leader, que por sua vez escreve em `stdout`
- se `foo("bar")` for chamada, `"bar"` é escrito para o application group leader, que por sua vez escreve em `stdout`

> Quando o Elixir é compilado e executado, a [BEAM VM](<https://en.wikipedia.org/wiki/BEAM_(Erlang_virtual_machine)>) inicia um processo conhecido como `group leader`, que representa a entrada e a saída padrão; esse processo é compartilhado com todos os outros processos para abstrair as operações de entrada e saída
