# Sobre

É hora de chegar a um dos paradigmas centrais do C++: a programação orientada a objetos (POO).
A POO gira em torno de `classes`: tipos de dados definidos pelo usuário, com o seu próprio conjunto de funções relacionadas.
Vamos começar pelo básico e, mais adiante na árvore do currículo, vamos cobrir tópicos mais avançados.

## Membros

As classes podem ter **variáveis de membro** e **funções de membro**.
Elas são acessadas pelo operador de **seleção de membro** `.`.
Assim como as variáveis fora de `classes`, é recomendável inicializar as variáveis de membro com um valor na declaração.
Esse valor passa a ser o padrão para os objetos criados a partir dessa classe.

## Encapsulamento e ocultação de informação

As classes oferecem a opção de restringir o acesso aos seus membros.
Os dois casos básicos são `private` e `public`.
Os membros `private` não são acessíveis de fora da classe.
Os membros `public` podem ser chamados livremente.
Por padrão, todos os membros são `private` e precisam ser marcados explicitamente para serem usados fora da classe.

## Exemplo básico

A definição de uma nova `class` pode ser vista no exemplo a seguir.
Repare no `;` depois da definição.

```cpp
class Wizzard {
  public:               // from here on all members are accessible publicly
    int cast_spell() {  // defines the public member function cast_spell
      return damage;
    }
    std::string name{}; // defines the public member variable `name`
  private:              // from here on all members are private
    int damage{5};      // defines the private member variable `damage`
};

```

Você pode acessar todas as variáveis de dentro da classe.
Dê uma olhada em `damage` dentro da função `cast_spell`.
Você não pode ler nem alterar membros `private` fora da classe:

```cpp
Wizzard silverhand{};
// calling the `cast_spell` function is okay, it is public:
silverhand.cast_spell();
// => 5

// name is public and can be changed:
silverhand.name = "Laeral";

// damage is private:
silverhand.damage = 500;
 // => Compilation error
```

## Construtores

Os construtores oferecem a possibilidade de atribuir valores às variáveis de membro no momento da criação do objeto.
Eles têm o mesmo nome da `class` e não têm tipo de retorno.
Uma classe pode ter vários construtores.
Isso é útil quando você nem sempre precisa definir todas as variáveis.

```cpp
class Wizzard {
  public:
    Wizzard(std::string new_name) {
      name = new_name;
    }
    Wizzard(std::string new_name, int new_damage) {
      name = new_name;
      damage = new_damage;
    }
    int cast_spell() {
      return damage;
    }
    std::string name{};
  private:
    int damage{5};
};

Wizzard el{"Eleven"};       // deals  5 damage
Wizzard vecna{"Vecna", 50}; // deals 50 damage
```

Construtores são um tópico extenso e têm muitas nuances.
Se você não definir explicitamente um `constructor` para a sua `class`, então, e só então, o compilador fará esse trabalho para você.
Foi o que aconteceu no primeiro exemplo acima.
O objeto _silverhand_ é criado chamando o construtor padrão, sem nenhum argumento passado.
Todas as variáveis recebem o valor declarado na definição da classe.
Se você não tivesse dado nenhum valor nessa definição, as variáveis poderiam ficar sem inicialização, o que pode ter consequências indesejadas.

## Structs

As structs vêm das origens da linguagem no C e são tão antigas quanto o próprio C++.
Elas são efetivamente a mesma coisa que as `classes`, com uma exceção importante.
Por padrão, tudo em uma `class` é `private`.
As structs, por outro lado, são `public` até que se defina o contrário.
Por convenção, a palavra-chave `struct` costuma ser usada para **estruturas que contêm apenas dados**.
Já a palavra-chave `class` é preferida para objetos que precisam garantir certas propriedades.
Um desses invariantes poderia ser que o `damage` da sua `class` `Wizzard` não pode ficar negativo.
A variável `damage` é privada, e qualquer função que altere o damage garantiria que o invariante fosse preservado.
