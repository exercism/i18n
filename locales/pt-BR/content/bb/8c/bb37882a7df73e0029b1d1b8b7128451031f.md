# Dicas

## Geral

- Pode ser útil ter uma lista de todas as [operações aritméticas][arithmetic-operations] em PHP.

## 1. Uma proporção de massa

- Você pode resolver essa tarefa usando os operadores aritméticos básicos de adição e multiplicação.

## 2. Um toque de molho

- Para garantir um número inteiro de latas, você vai precisar arredondar para cima.
- O PHP oferece [funções numéricas][numeric-functions] que podem ajudar.

## 3. Um pouco de queijo, por favor

- Você pode elevar um número ao cubo usando o [operador de exponenciação][arithmetic-operations].
- Para garantir um número inteiro de pizzas, você vai precisar arredondar para baixo.
- O PHP oferece [funções numéricas][numeric-functions] que podem ajudar.
- O PHP tem uma [constante embutida][pi-constant] para o pi (π).

## 4. Uma divisão justa

- Use o [operador de módulo][arithmetic-operations] (`%`) para obter o resto da divisão.

[arithmetic-operations]: https://www.php.net/manual/en/language.operators.arithmetic.php
[pi-constant]: https://www.php.net/manual/en/function.pi.php
[numeric-functions]: https://www.php.net/manual/en/ref.math.php
