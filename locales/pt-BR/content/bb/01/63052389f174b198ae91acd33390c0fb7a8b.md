# Introdução

## Expressões case

No Gleam, uma expressão `case` pode ser usada para executar código condicionalmente. Com uma expressão `case`, um valor pode ser testado contra um ou mais _padrões_. Um exemplo desse tipo de padrão é o _padrão literal_, que compara um valor com um valor literal (por exemplo, `1` ou `"hello"`).

As expressões `case` são escritas com a palavra-chave `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Embora isso possa parecer com as instruções `switch` de outras linguagens, a correspondência de padrões começa a brilhar quando você também usa outros padrões. Um deles é o _padrão de variável_, que permite atribuir um valor a uma variável. Neste exemplo, a variável `i` receberá o valor de `number` se ele não for `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Em alguns casos, você pode querer adicionar uma condição extra a um padrão. Isso é conhecido como uma _guarda_ (cláusula), que pode ser adicionada com a palavra-chave `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Por questões de desempenho, apenas operadores matemáticos e booleanos básicos são permitidos em guardas; outras funções não podem ser usadas nelas.

No exemplo acima, nem toda entrada possível terá um padrão correspondente. O compilador vai detectar isso e emitir um erro. Isso é conhecido como _verificação de exaustividade_. Para resolver o aviso, é preciso tratar todos os casos. Para isso, pode-se usar o _padrão de descarte_, que é um padrão que corresponde a qualquer valor:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

É possível corresponder a vários padrões em uma única cláusula, usando `|` para separar cada padrão. Só é possível adicionar uma guarda por cláusula:

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

As expressões `case` testam um valor contra cada padrão, de cima para baixo, até encontrar um padrão correspondente e executar a lógica associada a ele. A ordem dos padrões importa!
