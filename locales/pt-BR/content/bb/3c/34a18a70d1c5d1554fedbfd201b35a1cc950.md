# Dicas

## Geral

- O vocabulário [`sequences`][sequences] cobre quase tudo,
  incluindo `sum`.

## 1. A contagem de hoje

- `last` retorna o último elemento de uma sequência.

## 2. Incrementar a contagem de hoje

- `unclip-last` retira o último elemento para que você possa transformá-lo,
  e `suffix` acrescenta um elemento a uma sequência. Juntas, elas dão
  a você um padrão não destrutivo de "modificar o último elemento".

## 3. Houve algum dia sem pássaros?

- `any?` recebe uma sequência e uma quotation de predicado e retorna `t`
  se o predicado foi verdadeiro para pelo menos um elemento.
- A quotation de predicado para "este número é zero?" é `[ zero? ]`.

## 4. Somar os primeiros dias

- `head` recebe uma sequência e uma contagem `n` e retorna os primeiros `n`
  elementos.
- Depois, some o resultado.

## 5. Contar os dias movimentados

- `count` recebe uma sequência e um predicado, como `any?` faz, mas
  retorna *quantos* elementos corresponderam.

## 6. Preencher os dias que faltam

- `pad-tail` recebe uma sequência, um comprimento alvo e um elemento de
  preenchimento, e estende a sequência até esse comprimento acrescentando
  cópias do elemento. Se a sequência já for longa o bastante, ela é
  retornada sem alterações.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
