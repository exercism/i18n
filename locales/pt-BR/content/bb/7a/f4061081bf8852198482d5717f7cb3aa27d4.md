# Instruções

Sua equipe de design está migrando de transformações CSS para Factor em parte do
trabalho de layout. Para manter o resto da equipe feliz, você vai construir
transformações pequenas e reutilizáveis como quotations que recebem um ponto 2D
e retornam um ponto 2D.

Um ponto é um array de 2 elementos `{ x y }`.

## 1. Transladar as coordenadas

Defina `translate-2d` para receber dois valores `dx` e `dy` da pilha
e retornar uma quotation que translada um ponto em `(dx, dy)`.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. Escalar as coordenadas

Defina `scale-2d` da mesma forma, retornando uma quotation que escala um
ponto em `(sx, sy)`.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. Compor duas transformações

Defina `compose-transformations` para receber duas quotations de
transformação `f` e `g` e retornar uma única quotation que aplica
`f` primeiro e depois `g`.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. Aplicar uma transformação

Defina `apply-transformation` para receber um ponto e uma quotation de
transformação da pilha e retornar o ponto transformado.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. Transformar vários pontos de uma vez

Defina `transform-points` para receber um array de pontos e uma
quotation de transformação, e retornar o array de pontos transformados.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
