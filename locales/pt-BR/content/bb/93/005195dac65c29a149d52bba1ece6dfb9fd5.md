# Classes com estado

Toda classe até agora foi uma caixa de rotinas. Cada uma recebia seus argumentos,
calculava uma resposta e esquecia tudo.

Uma classe pode, em vez disso, **lembrar** de coisas. Um placar precisa fazer
isso: a pontuação agora depende de cada gol desde que o jogo começou.

## Atributos

`attr` dá a uma classe algo para lembrar.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

Cada `attr` vira uma rotina que lê o valor e outra que o altera:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

Atributos do mesmo tipo podem compartilhar uma declaração, assim como os
argumentos:

```sather
   attr home_score, away_score : INT;
```

## Objetos

Uma classe com atributos é um molde para criar **objetos**. Cada objeto tem suas
próprias cópias dos atributos, então dois placares guardam duas pontuações.

`new` cria um objeto. Ele fica dentro de uma rotina chamada `create`, que então
preenche o objeto e o devolve:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` significa "esta classe". Escrever `SCOREBOARD` ali diria a mesma coisa,
mas `SAME` continua funcionando se a classe for renomeada.

## Criando um objeto

`#` chama `create`:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

Você já vem usando `#` desde `rehearsal-script`: `#FSTR` é exatamente isso.

## Rotinas que alteram o objeto

Dentro da classe, um atributo é usado pelo nome, sem nenhum objeto na frente. Ele
se refere ao objeto em que a rotina foi chamada.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal` não declara tipo de retorno, porque não devolve nada: em vez disso,
ela altera o objeto. Chame-a como uma instrução:

```sather
   board.home_goal;
```

## Atributos começam vazios

Um atributo que ninguém definiu guarda zero para um `INT`, `false` para um `BOOL`
e void para uma string ou um objeto. Então um placar novo mostra 0 a 0 sem que
nada precise dizer isso.
