# Instruções

Este exercício aborda a análise de arquivos de log.

Após uma recente revisão de segurança, pediram para você limpar os arquivos de log arquivados da organização.

Todas as strings passadas aos métodos são garantidamente não nulas e sem espaços no início nem no fim.

## 1. Identificar linhas de log corrompidas

Você precisa ter alguma ideia de quantas linhas de log no seu arquivo não estão em conformidade com os padrões atuais. Você acredita que um teste simples revela se uma linha de log é válida. Para ser considerada válida, uma linha deve começar com uma das seguintes strings:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

Implemente o método `LogParser.IsValidLine()` para retornar `false` se uma string não for válida; caso contrário, `true`.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. Dividir a linha de log

Uma nova equipe entrou na organização, e você descobre que os arquivos de log dela usam um separador estranho para "campos". Em vez de algo sensato como dois-pontos ":", eles usam uma string como "<--->" ou "<=>" (porque é mais bonito); na verdade, qualquer string que tenha "<" como primeiro caractere e ">" como último caractere, e qualquer combinação dos seguintes caracteres no meio: "^", "\*", "=" e "-".

Implemente o método `LogParser.SplitLogLine()` que recebe uma linha e retorna um array de strings, cada uma contendo um campo.

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. Contar o número de linhas que contêm uma senha entre aspas

A equipe precisa saber sobre senhas que aparecem em texto entre aspas para que possam ser examinadas manualmente.

Implemente o método `LogParser.CountQuotedPasswords()` para fornecer uma indicação da provável escala do trabalho manual.

Identifique linhas de log em que a string literal "password", que pode estar em qualquer combinação de maiúsculas e minúsculas, está cercada por aspas.
Considere a possibilidade de haver conteúdo adicional entre as aspas, antes e depois de "password".

As linhas passadas para a rotina podem ser válidas ou não, conforme definido na tarefa 1. Nós as processamos da mesma forma, sejam válidas ou não.

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. Remover artefatos do log

Você descobriu que algum processamento anterior dos logs vem espalhando o texto "end-of-line" seguido de um número de linha (sem espaço entre eles) por todos os logs.

Implemente o método `LogParser.RemoveEndOfLineText()` para receber uma string, remover o texto end-of-line e retornar uma string "limpa".

Linhas que não contêm o texto end-of-line devem ser retornadas sem modificação.

Apenas remova a string end-of-line. Não tente ajustar os espaços em branco.

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. Listar linhas com senhas extremamente fracas para que os culpados possam ser punidos

Antes de expurgar as senhas do arquivo, precisamos listar quaisquer casos em que as senhas começam com o texto "password".

Implemente o método `LogParser.ListLinesWithPasswords()` para imprimir a senha infratora seguida da linha completa.

Linhas com senhas entre aspas já foram removidas, e você processa as linhas independentemente de serem válidas (conforme a tarefa 1).

Linhas que contêm uma senha infratora devem ser retornadas com o prefixo "<password>: ".

Linhas que não contêm uma senha infratora devem ser retornadas com o prefixo "--------: ".

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
