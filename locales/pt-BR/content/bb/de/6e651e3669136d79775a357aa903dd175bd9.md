## Representações do PHP

O [representer do PHP][github-php-representer] aplica as seguintes normalizações:

- Todos os comentários são removidos
- Todos os espaços em branco são normalizados
- Identificadores (classes, funções e variáveis) são normalizados para um valor de espaço reservado
  - Identificadores que não diferenciam maiúsculas de minúsculas são normalizados para o mesmo valor de espaço reservado
  - Funções com alias são normalizadas (https://www.php.net/manual/en/aliases.php)
- Strings (com aspas simples, com aspas duplas, heredoc e nowdoc) são todas convertidas para aspas simples (https://www.php.net/manual/en/language.types.string.php)
  - Strings interpoladas são normalizadas para concatenação: `"this is $a variable"` => `'this is ' . $a . ' variable'`
  - As concatenações são simplificadas: `'testA' . 'testB' . 'testC'` => `'testAtestBtestC'`
- Arrays são normalizados para a sintaxe curta: `array('a', 'b')` => `['a', 'b']`
- Casts `(float)` e `(real)` são normalizados para `(double)`

[github-php-representer]: https://github.com/exercism/php-representer

Verifique os seguintes itens:

1. Verifique a aba "exemplos" na janela de envio e veja se o feedback faz sentido para _todas_ as abas.
2. Verifique se você não mencionou espaços em branco ou comentários
3. Verifique se você não menciona nomes de funções ou de variáveis como aparecem na solução, mas sim o mapeamento fornecido (ou deixe os nomes de fora).
   Apenas os nomes exigidos pelos testes podem ser mencionados com segurança, porque são sempre os mesmos para todo mundo.
