# Instruções

Você mantém a biblioteca de macros sobre a qual o motor de composição de uma revista é construído.
O motor em si, as funções que dispõem cada página, é fixo e você não o escreve.
O que você escreve é a maquinaria de tempo de montagem a partir da qual ele é construído.

Este exercício não exige que você escreva nenhuma função, apenas macros.
Essas macros são então incluídas e chamadas em funções já predefinidas em outro arquivo.

Você tem quatro tarefas.

~~~~exercism/caution
Cada macro é chamada pelo nome exato e pela ordem de argumentos que a tarefa indica, então escreva-as exatamente assim.
Caso contrário, o arquivo não será montado.
~~~~

## 1. Nomeie as constantes de formato

O formato da revista é um punhado de números fixos, e o resto do layout se refere a eles apenas pelo nome.
Você deve dar a cada um um nome legível em tempo de montagem:

- `COLUMN_COUNT` é `4`
- `COLUMN_STRIDE` é `18`
- `SPACE` é `0x20`, o byte em branco
- `RULE` é `0x3D`, o byte `=`
- `RULE_WIDTH` é `4`
- `PLAIN` é `0x2E`, o byte `.`
- `RULED` é `0x2D`, o byte `-`
- `BOXED` é `0x23`, o byte `#`

O motor reporta esses valores na ordem acima.

```c
out = {4, 18, 32, 61, 4, 46, 45, 35} // the eight named values, in order
```

## 2. Escreva a macro `fill_run`

O motor esvazia uma galé e traça filetes de cabeçalho estampando uma sequência de um único byte.
Capture essa etapa como uma macro de várias linhas que o motor possa chamar sempre que uma sequência precisar ser preenchida.

Primeiro, defina um nome legível `COUNTER` para o registrador `rcx`.
Em seguida, defina a macro `fill_run`, que deve preencher um array com N cópias de um byte.
Ela recebe três argumentos nesta ordem:

1. o endereço de destino, passado em um registrador de uso geral de 64 bits.
2. a contagem de bytes (N) a escrever, passada em um registrador de uso geral de 64 bits ou como um valor imediato.
3. o byte a escrever, passado como um valor imediato.

```x86asm
fill_run rdi, rax, SPACE
fill_run rdx, RULE_WIDTH, RULE
```

A macro `fill_run` pode sobrescrever `COUNTER` livremente, mas nenhum outro registrador.

Repare que a contagem de bytes pode ser passada em um registrador de uso geral de 64 bits, como `rax` ou `rsi`, ou como um valor imediato, como `10` ou `4`.
Você pode considerar que essa contagem nunca é negativa.

Esta macro é chamada três vezes, em duas funções diferentes.

```c
length = 8
page   = {32, 32, 32, 32, 32, 32, 32, 32}

width  = 8
page   = {61, 61, 61, 61, 32, 32, 32, 32} // '====' then spaces
```

## 3. Escreva a macro `lay_columns`

A grade é fixa para o formato, então os inícios das colunas podem ser calculados em tempo de montagem.

Defina a macro `lay_columns`, que escreve `COLUMN_COUNT` deslocamentos, cada um um inteiro de 64 bits.
Ela recebe dois argumentos nesta ordem:

1. o endereço de destino, passado em um registrador de uso geral de 64 bits
2. a margem esquerda, passada em um registrador de uso geral de 64 bits

```x86asm
lay_columns rsi, rax
```

O número de deslocamentos a serem escritos no endereço de destino é fixo e igual a `COLUMN_COUNT`.

Cada deslocamento é um valor de 64 bits calculado com `offset[i] = margin + i * COLUMN_STRIDE`, onde `i` é o índice do deslocamento começando em `0`, e `margin` é o segundo argumento.

Esta macro pode sobrescrever seus dois argumentos de registrador, mas nenhum outro.
Ela é chamada uma vez.

```c
margin = 3
out    = {3, 21, 39, 57}
```

## 4. Escreva a macro `set_header`

Cada uma das três seções fixas tem um estilo de cabeçalho fixado pelo formato, então o byte é conhecido em tempo de montagem.

Defina `set_header`, que recebe dois argumentos nesta ordem:

1. o endereço de destino.
2. um id de estilo literal passado como um valor imediato, onde `0` é simples, `1` é com filete e `2` é com moldura.

O endereço de destino é a expressão de um endereço de memória efetivo.
Ela usa um registrador de base que pode ser somado a um registrador de índice escalado por `1`, `2`, `4` ou `8`, e um valor imediato:

```x86asm
set_header rdx+8*rcx+2, 1
```

Selecione o byte de cabeçalho (`PLAIN`, `RULED` ou `BOXED`) com montagem condicional (`%if` / `%elif` / `%else`) em vez de um desvio em tempo de execução.

Esta macro não deve sobrescrever nenhum registrador.
Ela é chamada três vezes na mesma função.

```c
pitch = 4
out   = {46, 0, 0, 0, 45, 0, 0, 0, 35} // '.', '-', '#'
```
