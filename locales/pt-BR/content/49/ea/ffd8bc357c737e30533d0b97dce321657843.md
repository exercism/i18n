# Introdução

Sua amiga Eliud herdou uma fazenda da avó, Tigist.
A avó dela era inventora e tinha a tendência de construir as coisas de um jeito complicado demais.
O galinheiro tem um visor digital que mostra um número codificado representando as posições de todos os ovos que podem ser coletados.

Eliud está pedindo que você escreva um programa que mostre o número real de ovos no galinheiro.

A codificação das informações de posição é calculada assim:

1. Percorra os possíveis locais de postura e anote um `1` para um ovo existente ou um `0` para um lugar vazio.
2. Converta o número de binário para decimal.
3. Mostre o resultado no visor.

Exemplo 1:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

Exemplo 2:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
