# Instruções

Neste exercício, você vai modelar uma balança.

## 1. Crie um estado inicial para a balança

Quando inicializada, a balança deve usar as configurações de fábrica, que são diferentes conforme o local onde a máquina é vendida.
Por isso, a máquina deve poder ser inicializada com uma precisão e com a indicação de se ela é métrica ou imperial.

Implemente o método `WeighingMachine#initialize`, que recebe dois argumentos: `precision`, que é um `Int32`, e `metric`, que é um `Bool`.
O argumento `metric`, quando é `true`, significa que a máquina deve usar o sistema métrico; caso contrário, ela deve usar o sistema imperial.
O método `initialize` também deve definir a variável de instância `@weight` como `0.0`.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. Permita que a balança tenha uma precisão

Para atender a demandas diferentes, permitimos que cada balança seja personalizada com uma precisão (o número de dígitos depois do separador decimal).

Implemente o método getter `WeighingMachine#precision` para retornar a precisão da balança.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. Permita que o peso seja definido na balança

Implemente a propriedade `WeighingMachine#weight` para permitir que o peso seja lido _e_ definido:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. Permita que a máquina alterne entre unidades métricas e imperiais

Implemente a propriedade `WeighingMachine#metric=` para permitir que a unidade seja definida.
Ela deve aceitar um valor Boolean.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
