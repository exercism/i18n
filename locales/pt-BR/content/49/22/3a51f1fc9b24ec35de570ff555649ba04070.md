# Instruções

Você está desenvolvendo seu próprio videogame de RPG. No seu jogo, existem _personagens_ e _itens_. Uma das muitas ações que você pode fazer com um item é fazer um personagem comê-lo.

Nem todos os itens são comestíveis, e nem todos os itens comestíveis têm os mesmos efeitos sobre o personagem. Alguns itens, quando comidos, se transformam em um item diferente (por exemplo, se você comer uma maçã, sobra o caroço).

Para permitir toda essa flexibilidade, você decidiu criar um protocolo `Edible` que alguns dos itens podem implementar.

## 1. Defina a comestibilidade

Crie o protocolo `RPG.Edible`. O protocolo tem uma função: `eat`. A função `eat` aceita um item e um personagem e retorna um subproduto e um personagem.

## 2. Faça os pães serem comestíveis

Implemente o protocolo `RPG.Edible` para o item `RPG.LoafOfBread`. Quando comido, um pão dá ao personagem 5 pontos de vida e não produz subproduto.

```elixir
RPG.Edible.eat(%RPG.LoafOfBread{}, %RPG.Character{health: 31})
# => {nil, %RPG.Character{health: 36, mana: 0}}
```

## 3. Faça as poções de mana serem comestíveis

Implemente o protocolo `RPG.Edible` para o item `RPG.ManaPotion`. Quando ingerida, uma poção de mana dá ao personagem tantos pontos de mana quanto a força da poção, e produz uma garrafa vazia.

```elixir
RPG.Edible.eat(%RPG.ManaPotion{strength: 13}, %RPG.Character{mana: 50})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 100, mana: 63}}
```

## 4. Faça os venenos serem comestíveis

Implemente o protocolo `RPG.Edible` para o item `RPG.Poison`. Quando ingerido, um veneno tira todos os pontos de vida do personagem e produz uma garrafa vazia.

```elixir
RPG.Edible.eat(%RPG.Poison{}, %RPG.Character{health: 3000})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 0, mana: 0}}
```
