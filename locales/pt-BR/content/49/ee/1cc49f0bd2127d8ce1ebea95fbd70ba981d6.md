# Introdução

AWK é uma linguagem muito pequena e tem apenas alguns tipos de dados básicos.
Nesta lição, vamos ver números e strings.

## Números

Os números em AWK são implementados como números de ponto flutuante de precisão dupla.
Não há distinção entre inteiros e números de ponto flutuante de precisão simples ou dupla.

AWK entende constantes numéricas octais (que começam com `0`) e constantes numéricas hexadecimais (que começam com `0x` ou `0X`).

### Operações numéricas

Você pode usar os operadores aritméticos padrão `+`, `-`, `*`, `/`, `%`.
O operador de exponenciação é `^`.
Existem algumas funções numéricas embutidas, incluindo funções trigonométricas, geração de números aleatórios e `int(x)` para truncar um número até o inteiro mais próximo entre _x_ e zero.

## Strings

Strings em AWK são sequências de caracteres.
Especifique uma constante de string usando aspas duplas.

### Operações com strings

Existe apenas uma operação com strings: a concatenação.
A concatenação não tem um operador especial;
basta colocar duas strings lado a lado para concatená-las:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` é uma **instrução**, não uma função.
`print` não exige parênteses.
~~~~

AWK tem uma grande variedade de funções de manipulação de strings.
Vamos conhecê-las em profundidade conforme avançarmos pela trilha.

## Convertendo entre números e strings

Não existem operadores explícitos para converter entre números e strings.
O AWK faz isso implicitamente, com base no contexto do programa.
Isso torna muito simples trabalhar com os valores dos campos de entrada: o AWK geralmente só faz o que você quer que ele faça.

* `print x + y` vai converter os valores das variáveis `x` e `y` em números, graças à operação numérica `+`.
* `print x y` vai converter os valores das variáveis `x` e `y` em strings, graças à operação de concatenação.

Se você quiser ser explícito, `0 + x` dá a representação numérica de _x_ e `"" x` dá a representação em string de _x_.

### De strings para números

A forma como o AWK converte uma string em número pode ser confusa.
Uma maneira simples de pensar nisso é que o AWK lê os "caracteres numéricos" desde o início da string até encontrar um caractere que não seja um número.
Alguns exemplos:

* `"2.5"` é convertida no número `2.5`;
* `"1e3"` é convertida no número `1000` (notação científica);
* `"456abc"` é convertida no número `456` (como `a` não é um "numeral", a conversão para por aí).
* `"abc789"` é convertida no número `0` (não há números no **início** da string).
