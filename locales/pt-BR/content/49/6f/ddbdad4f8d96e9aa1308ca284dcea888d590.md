# Sobre

O Factor concentra a aleatoriedade no vocabulário [`random`][random] em torno de uma única palavra genérica:

```
random ( obj -- elt )
```

Ela despacha com base no argumento:

- um **inteiro** `n` gera um inteiro aleatório em `[0, n)`;
- uma **sequência** gera um elemento aleatório;
- assocs, hash-sets e tuplas `uniform-distribution` também são aceitos.

Dois auxiliares de sequência se baseiam nela:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize` modifica e retorna a sequência, então faça `clone` primeiro se precisar manter a ordem original.

## De onde vem a aleatoriedade

`random` lê o gerador contido na variável dinâmica `random-generator`. Por padrão, é um Mersenne Twister inicializado a partir do relógio do sistema, então cada processo é diferente. Você pode instalar um gerador diferente durante a execução de uma quotation:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

Como `with-random` simplesmente vincula `random-generator` durante a extensão dinâmica da quotation, uma palavra que envolve `with-random` deve ser marcada como `inline` para que a quotation possa deixar seu resultado na pilha para o chamador.

Além dessas, `random` oferece `random-bits`, `random-unit`, `uniform-random` e `normal-random` para outras distribuições, além de `system-random-generator` e `secure-random-generator` para necessidades não reprodutíveis e criptográficas.

[random]: https://docs.factorcode.org/content/vocab-random.html
