# Dicas

## Geral

- Para gerar números aleatórios, `:rand.uniform` do Erlang ou `Enum.random` são bons pontos de partida.
- `Integer.pow` pode ser usado para calcular a potência de um número, e `rem` para o módulo.
- Nenhum dos dois funciona particularmente bem (nem rapidamente) com números inteiros muito grandes. A criptografia geralmente usa números maiores que 1024 bits. O módulo `:crypto` do Erlang tem uma função útil para calcular o módulo de uma potência, especialmente para números inteiros enormes, mas talvez você precise do `:binary` para decodificá-lo.
