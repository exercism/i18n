# Instruções

Neste exercício, você está jogando um jogo de adivinhação de números com um amigo. As regras são simples: você escolhe um número em segredo entre `1` e `100`, e seu amigo tenta adivinhar qual número você escolheu. Para ajudar seu amigo, você responde de forma diferente dependendo de quão perto o palpite chegou do número que você escolheu (`42`). Estas são as regras para as diferentes respostas:

- Se o palpite for `42`: "Correct"
- Se o palpite for `41` ou `43`: "So close"
- Se o palpite for menor que `41`: "Too low"
- Se o palpite for maior que `43`: "Too high"

Você tem quatro tarefas para codificar as respostas aos palpites.

## 1. Responda a um palpite correto

Implemente a função `reply` para responder a um palpite correto:

```gleam
reply(42)
// -> "Correct"
```

## 2. Responda a um palpite próximo

Modifique a função `reply` para responder a palpites próximos:

```gleam
reply(41)
// -> "So close"
```

## 3. Responda a palpites muito baixos

Modifique a função `reply` para responder a palpites muito baixos:

```gleam
reply(25)
// -> "Too low"
```

## 4. Responda a palpites muito altos

Modifique a função `reply` para responder a palpites muito altos:

```gleam
reply(88)
// -> "Too high"
```
