# Instruções

Ozan está montando uma playlist para uma viagem de carro que vai fazer em breve. Ele não quer ouvir a mesma faixa mais de uma vez, mas a playlist ficou tão longa que ele está com dificuldade para lembrar quais faixas já foram adicionadas.

A API do tocador de música do Ozan só sabe trabalhar com arrays, então ele tenta escrever um código que usa `Array.indexOf()` para verificar se uma faixa já está na playlist antes de adicioná-la. Infelizmente, o programa dele demora demais para executar. Ele precisa da sua ajuda!

Ao socorrer Ozan, você se espanta ao descobrir que a playlist dele tem _meio milhão_ de faixas. Talvez você conheça uma estrutura de dados diferente que permita manipular a playlist com mais eficiência?

## 1. Remover faixas duplicadas

Implemente a função `removeDuplicates`, que recebe uma playlist como _parâmetro_ e _retorna_ uma nova playlist em que todas as faixas são únicas.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. Verificar se uma faixa já foi adicionada

Implemente a função `hasTrack`, que recebe uma playlist e uma faixa como _parâmetros_ e _retorna_ um boolean que indica se a playlist contém a faixa.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. Adicionar uma faixa

Implemente a função `addTrack`, que recebe uma playlist e uma faixa como _parâmetros_ e _retorna_ uma nova playlist que inclui a faixa.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. Excluir uma faixa

Implemente a função `deleteTrack`, que recebe uma playlist e uma faixa como _parâmetros_ e _retorna_ uma nova playlist que não inclui a faixa.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. Listar artistas únicos

Implemente a função `listArtists`, que recebe uma playlist como _parâmetro_ e _retorna_ a lista de artistas únicos da playlist. Repare que os nomes das faixas seguem o formato `<SONG> - <ARTIST>`.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
