# Instruções

Neste exercício, você vai implementar um conjunto parcial de rotinas utilitárias para ajudar uma pessoa desenvolvedora a limpar nomes de identificadores.
Nas 5 tarefas, você vai construir aos poucos a rotina `Clean`.
Um identificador válido é composto por zero ou mais letras e sublinhados.
Em todos os casos, a string de entrada tem garantia de não ser nula.
Se uma string vazia for passada para a função `Clean`, uma string vazia deve ser retornada.
Repare que quem chama a rotina `Clean` deve evitar passar um identificador vazio, já que esses identificadores não têm efeito.

## 1. Substitua qualquer espaço encontrado por sublinhados

Implemente o método (_static_) `Identifier.Clean()` para substituir qualquer espaço por sublinhados.
Isso também vale para espaços no início e no fim.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. Substitua caracteres de controle pela string "CTRL" em maiúsculas

Modifique o método (_static_) `Identifier.Clean()` para substituir caracteres de controle pela string `"CTRL"` em maiúsculas.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Converta kebab-case em camelCase

Modifique o método (_static_) `Identifier.Clean()` para converter kebab-case em camelCase.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Omita caracteres que não são letras

Modifique o método (_static_) `Identifier.Clean()` para omitir qualquer caractere que não seja letra.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Omita letras gregas minúsculas

Modifique o método (_static_) `Identifier.Clean()` para omitir qualquer letra grega no intervalo de 'α' a 'ω'.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
