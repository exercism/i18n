# Dicas

## 1. Desloque os bits de volta

- Existem dois operadores para deslocar para a direita, mas só um deles sempre insere um 0.

## 2. Defina alguns bits

- Um dos operadores bit a bit sempre define um bit como 1 onde os bits nos dois valores são 1.

## 3. Inverta bits específicos

- Existe uma operação bit a bit que inverte um bit onde a máscara é 1.

## 4. Limpe bits específicos

- Uma das operações bit a bit limpa bits onde o bit na máscara é 0.
- Mas talvez você precise combiná-la com outro operador para limpar bits onde a máscara é 1.
