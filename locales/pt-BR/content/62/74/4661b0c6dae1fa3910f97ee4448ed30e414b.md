# PowerShell

Automatize tudo!
Escreva scripts em qualquer sistema operacional para gerenciar arquivos, processos, um data center ou serviços de nuvem.
Explore interativamente dados estruturados como JSON, XML e CSV; trabalhe com qualquer interface de gerenciamento, de APIs web e CIM a aplicativos de linha de comando.

# Sobre o PowerShell

Uma linguagem de script .NET de código aberto e multiplataforma, um shell e um framework de gerenciamento de configuração, o PowerShell ajuda profissionais de TI e usuários avançados a controlar e automatizar praticamente qualquer coisa.

O PowerShell é construído sobre o .NET Framework e transforma o conceito clássico de pipe do Unix, estendendo-o de apenas passar texto ou fluxos binários para suportar a passagem de instâncias de objetos que incluem informações de tipo (por exemplo, datas e horas) e estado complexo com seus dados estruturados.
Em um shell tradicional, você poderia usar processamento de texto para extrair informações específicas da saída de um comando; no PowerShell, você tem acesso a propriedades e métodos (incluindo formas de inspecionar objetos para determinar quais propriedades e métodos estão disponíveis).
Você pode trabalhar com arquivos CSV, converter JSON em hashtables, navegar em documentos XML e muito mais, tornando muitas tarefas facilmente componíveis, o que seria difícil ou impraticável com análise de texto.

O PowerShell é extensível.
Não apenas por meio de ferramentas de linha de comando independentes, como outros shells são extensíveis, mas por meio de scripts, funções e cmdlets distribuídos em módulos que realmente se integram totalmente ao sistema de ajuda do PowerShell, ao editor de linha de comando com realce de sintaxe, à descoberta automática de parâmetros e ao autocompletar com Tab.
Você pode até estender a sintaxe simples e explorável de propriedade + conteúdo do sistema de arquivos para repositórios de dados como o registro do Windows e o repositório de certificados, o SQL Server e até o Azure!

O PowerShell inclui muitos recursos adicionais:

- "Cmdlets" integrados para tarefas comuns de administração de sistemas, como gerenciar arquivos, serviços, processos e até o registro, logs de eventos e o Common Information Model (CIM), requisições web e muito mais.
- Compatibilidade com scripts e ferramentas de linha de comando existentes.
- Interfaces extensíveis e módulos e comandos facilmente descobríveis.
- Acesso total ao .NET Framework e extensibilidade por meio de assemblies .NET do NuGet.
- Um rico histórico de comandos com informações sobre o sucesso e a duração da execução de um comando.
- Poderosas capacidades de manipulação de objetos. Os objetos podem ser manipulados diretamente, serializados e até enviados para outras ferramentas ou bancos de dados.

Documentação detalhada sobre o PowerShell, a linguagem, seus conceitos principais e recursos pode ser encontrada com os instaladores em https://docs.microsoft.com/en-us/powershell.
