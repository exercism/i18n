# Introdução

## With

A [forma especial with][with] oferece uma maneira de focar no "caminho feliz" de uma série de etapas que podem falhar e lidar com as falhas depois.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

Em cada etapa, se uma cláusula casar, a cadeia continua até o bloco `do` ser executado. Se um casamento falhar, a cadeia para e a cláusula que não casou é retornada. Você tem a opção de usar um bloco `else` para capturar casamentos que falharam e modificar o valor de retorno.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
