# Introdução

## Aleatoriedade

Uma instância da classe `java.util.Random` pode ser usada para gerar números aleatórios em Java.

### Números inteiros aleatórios

Um número inteiro aleatório pode ser gerado usando o método `nextInt()`.
Isso vai gerar um valor no intervalo de `Integer.MIN_VALUE` a `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Para limitar o intervalo dos valores gerados, use `nextInt(int)`.
Isso vai gerar um valor no intervalo de `0` (inclusive) até o limite superior informado (exclusivo).

Por exemplo, isso vai gerar um número aleatório de `0` a `9`.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

E isso vai gerar um número aleatório de `10` a `19`.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### Números de ponto flutuante aleatórios

Um número de ponto flutuante aleatório pode ser gerado usando o método `nextDouble()`.
Isso vai gerar um valor no intervalo de `0.0` a `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

E isso vai gerar um número aleatório de `100.0` a `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
