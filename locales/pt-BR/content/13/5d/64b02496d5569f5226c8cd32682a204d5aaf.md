# Anexo das instruções

## Registradores

| Registrador | Uso       | Tipo    | Descrição                            |
| ----------- | --------- | ------- | ------------------------------------ |
| `$a0`       | entrada   | endereço | array de palavras de fatores        |
| `$a1`       | entrada   | inteiro | número de fatores                    |
| `$a2`       | entrada   | inteiro | limite                               |
| `$v0`       | saída     | inteiro | soma dos múltiplos dentro do limite  |
| `$t0-9`     | temporário | qualquer | usado para armazenamento temporário  |
