# Instruções

Antes de ativar o arranjo de lasers, você precisa prever a ordem exata em que os cristais serão atingidos, identificados pelos seus IDs de amostra.

## Exemplo de caso de teste

Considere esta configuração de arranjo de cristais:

```json
{
  "start": { "x": 0, "y": 0, "angle": 0 },
  "prisms": [
    { "id": 1, "x": 10, "y": 10, "angle": -90 },
    { "id": 2, "x": 10, "y": 0, "angle": 90 },
    { "id": 3, "x": 30, "y": 10, "angle": 45 },
    { "id": 4, "x": 20, "y": 0, "angle": 0 }
  ]
}
```

## O que está acontecendo

O laser começa na origem `(0, 0)` e dispara na horizontal para a direita, em um ângulo de 0°.
Veja o caminho do feixe, passo a passo:

**Passo 1**: O feixe percorre o eixo x (y = 0) e encontra primeiro o **Cristal #2**, na posição `(10, 0)`.
Esse cristal tem um ângulo de refração de 90°, o que faz o feixe virar na perpendicular em relação ao seu caminho atual.
O feixe, que viajava a 0°, agora é redirecionado para 90° (direto para cima).

**Passo 2**: O feixe agora segue na vertical, para cima, a partir da posição `(10, 0)`, e atinge o **Cristal #1**, na posição `(10, 10)`.
Esse cristal tem um ângulo de refração de -90°, desviando o feixe em -90° em relação à sua direção atual.
O feixe viajava a 90°, então, após a refração, ele fica a 0° (90° + (-90°) = 0°), seguindo na horizontal para a direita de novo.

**Passo 3**: A partir da posição `(10, 10)`, o feixe segue na horizontal e encontra o **Cristal #3**, na posição `(30, 10)`.
Esse cristal refrata o feixe em 45°, mudando sua direção para 45°.
O feixe segue para o espaço vazio, além do arranjo.
