# Extrator de snippets

O [Extrator de snippets][snippet-extractor] recebe a submissão de um estudante e extrai dela as primeiras dez linhas de código "interessantes".
O snippet extraído é exibido em várias páginas do site.

Por padrão, são exibidas as primeiras dez linhas, ignorando linhas vazias no início.
Essas primeiras dez linhas _podem_ incluir coisas como comentários, que normalmente não são ideais para aparecer em um snippet.

## Personalizando a extração de snippets

Recomendamos que cada trilha [personalize a extração de snippets][snippet-extractor-customize] para, no mínimo, remover os comentários do código-fonte.
Para personalizar a extração de snippets, você precisa:

1. Adicionar um arquivo `lib/languages/<track_slug>.txt` que configura a extração de snippets.
   Esse arquivo pode usar o [modo básico][basic-mode] ou o [modo estendido][extended-mode].
   A maioria das trilhas usa o modo estendido, que dá mais flexibilidade.
2. Adicionar um ou mais casos de teste em um diretório `tests/<track_slug>/<test_slug>`.
   Cada diretório de teste precisa de dois arquivos:

   1. `tests/<track_slug>/<test_slug>/code.<track_extension>`: o código no qual o extrator de snippets será executado
   2. `tests/<track_slug>/<test_slug>/expected_snippet.<track_extension>`: o snippet esperado

Veja [este pull request de exemplo][example-pr] que personaliza a extração de snippets para a linguagem Arturo.
