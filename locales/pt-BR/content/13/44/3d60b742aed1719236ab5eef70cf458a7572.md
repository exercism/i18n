# Instruções

Continuando o tema do jogo wizards and warriors, agora é hora de adicionar um método de rolagem de dado para uso geral. Este será o tradicional dado de 18 lados, com números de 1 a 18. Os jogadores também geram uma força de feitiço.

## 1. Permita que um jogador de _wizards and warriors_ role um dado.

Implemente um método `RollDie()` na classe `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Os jogadores precisam da própria força. Ofereça uma forma de gerar a força de feitiço

Implemente um método `GenerateSpellStrength()` na classe do jogador. A força de feitiço fica entre 0.0 e 100.0, sem incluir o 100.0.

Repare que a força de feitiço precisa ser um número real (não um número inteiro) para reduzir a possibilidade de empate quando as forças de dois adversários forem comparadas.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
