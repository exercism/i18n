# Introdução

## Tabelas hash

Tabelas hash em Common Lisp são estruturas de dados para armazenar dados associativos.
Elas mapeiam chaves (que podem ser qualquer objeto) para valores (que também podem ser qualquer objeto).
Outras linguagens podem se referir a esse conceito como mapas, dicionários ou hashes.

### Criando tabelas hash

Tabelas hash podem ser criadas com a função `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Repare que a apresentação impressa de uma tabela hash depende da implementação, então ela pode aparecer de forma diferente no seu REPL.)

### Recuperando valores por chave

Para obter um valor a partir de uma chave na tabela hash, você usa a função `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` retorna [múltiplos valores][concept-multiple-values], o que será explicado em outro conceito.

### Inserindo valores

Para inserir um valor em uma tabela hash, você usa `setf` com `gethash` assim:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Isso modifica o valor da chave `:foo` na tabela hash `*hash-table*` para `:bar`.
Isso retorna o valor.

O uso de `setf` será explicado em outro conceito.
