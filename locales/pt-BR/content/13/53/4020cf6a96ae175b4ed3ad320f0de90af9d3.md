# Introdução a Variáveis

## Variáveis

_Variáveis_ são um lugar para armazenar dados.
O Bash tem dois tipos de dados: strings e arrays.
Vamos falar sobre arrays mais adiante.

Você atribui uma variável assim
```bash
name="value"
```

~~~~exercism/note
**Importante**: não pode haver _espaços_ ao redor do sinal de igual!

Quando houver espaços, como neste exemplo,

```bash
x = 10
```

o bash vai chamar o **comando** `x` com os **dois argumentos** `=` e `10`!
~~~~

As variáveis também podem ser chamadas de _parâmetros_.
Os dois termos serão usados de forma intercambiável neste documento.

Alguns parâmetros importantes usados ou definidos pelo bash incluem:

* `PATH`: uma lista de diretórios separados por dois pontos, usada para encontrar comandos externos.
* `IFS`: o "separador interno de campos".
   Vamos ver como ele é usado abaixo.
* `PWD`: seu diretório de trabalho atual.
   Terá o mesmo valor que a saída do comando `pwd`.
* `RANDOM`: um inteiro pseudoaleatório entre 0 e 32767.
* `BASH_VERSION`: a string de versão da instância em execução do bash.

## Nomes de Variáveis

Um nome de variável é composto por _letras maiúsculas, letras minúsculas, números e underscore_.
Ele não pode começar com um número.

~~~~exercism/caution
É uma boa prática **evitar usar nomes de variáveis em CAIXA ALTA**.
O shell usa essa convenção para seus parâmetros, e você não quer sobrescrever acidentalmente parâmetros do shell que têm significado especial.

## Expansão de Parâmetros

Você obtém o valor de um parâmetro com a sintaxe `$varname`.

```bash
x=10
echo "The value of x is $x"
```

Para evitar que o nome da variável se confunda com o texto ao redor, você pode colocar o nome da variável entre chaves.
Por exemplo, para imprimir a string `10x10`

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

Alguns [guias de estilo][google-style-guide] recomendam usar chaves na maioria dos casos para legibilidade e/ou consistência.

## Parâmetros Posicionais

Como discutimos na lição [Comandos e Argumentos][cmds-args], comandos podem receber argumentos.
Os scripts Bash não são exceção.
Os argumentos para a instância atual do bash são chamados de _parâmetros posicionais_.
Eles podem ser recuperados com estes parâmetros especiais:

* `$1`: o primeiro parâmetro posicional
* `$2` ... `$9`: parâmetros subsequentes
* `${10}` ...: dois dígitos exigem chaves.
* `$0`: o nome do script atual.

Argumentos para uma função do shell também são parâmetros posicionais, tratados exatamente assim.
Veremos mais sobre funções em uma lição mais adiante.

### Parâmetros Posicionais Especiais

Existem alguns _parâmetros especiais_ que ajudam você a trabalhar com os parâmetros posicionais.

* `$#` expande para o _número_ de parâmetros posicionais.
* `"$@"` expande para a lista de todos os parâmetros posicionais, cada um como uma palavra separada.
* `"$*"` expande para uma única string de todos os parâmetros posicionais unidos por um caractere.
  * O caractere de junção é _o primeiro caractere_ da variável `$IFS`, que por padrão é um espaço.

O `"$@"` é a maneira mais segura de passar parâmetros posicionais para outro comando mantendo-os devidamente entre aspas.
Também é o que você usará para iterar sobre os parâmetros posicionais:

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

Na prática, `"$@"` é usado com mais frequência do que `"$*"`.

## Substituição de Comandos

Uma operação muito frequente que você fará em scripts bash é capturar a saída de um comando e armazená-la em uma variável.
Para fazer isso, você usará _substituição de comandos_.

```bash
var=$(command)
```

Por exemplo, para converter uma string para maiúsculas, você pode fazer isso:

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## Mais sobre Expansão de Parâmetros

O Bash tem muitos recursos internos para manipular variáveis e strings, para que você não precise chamar comandos externos.

* Converter texto para maiúsculas.
  Na seção anterior, mostrei como usar `tr` para converter algum texto para maiúsculas.
  Para fazer isso no bash:

  ```bash
  echo "${text^^}"
  ```

  Da mesma forma, `${text,,}` converte o valor para minúsculas.

* Fornecer um valor padrão se a variável estiver vazia.

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* Pesquisar e substituir.

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

Existem muitas outras expansões de parâmetros interessantes: extrair uma substring, obter o comprimento da string, _atribuir_ um valor padrão, remover texto do início ou do fim do valor, e mais.
Leia sobre elas [no manual][param-exp].
