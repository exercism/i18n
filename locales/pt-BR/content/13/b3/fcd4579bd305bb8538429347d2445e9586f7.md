# Sobre

Uma string no Factor é uma sequência de caracteres e compartilha todo o protocolo [`sequences`][sequence-protocol], com `length`, `nth`, `head`, `tail`, `map`, `filter` e por aí vai, além dos seus vocabulários dedicados.

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

As palavras específicas de strings ficam principalmente em [`splitting`][splitting], [`ascii`][ascii] e [`unicode`][unicode]:

| palavra      | vocabulário   | o que faz                             |
|--------------|---------------|---------------------------------------|
| `split1`     | [`splitting`][splitting]   | corta na primeira ocorrência          |
| `split`      | [`splitting`][splitting]   | corta em qualquer caractere de um conjunto |
| `harvest`    | [`sequences`][sequences]   | descarta as partes vazias de um resultado de divisão |
| `replace`    | [`splitting`][splitting]   | substitui uma substring               |
| `surround`   | [`sequences`][sequences]   | envolve com um prefixo e um sufixo    |
| `glue`       | [`sequences`][sequences]   | junta duas strings com um separador   |
| `join`       | [`sequences`][sequences]   | junta um array de strings com um separador |
| `>lower`     | [`ascii`][ascii]       | converte para minúsculas (ASCII)      |
| `>upper`     | [`ascii`][ascii]       | converte para maiúsculas (ASCII)      |
| `[ blank? ] trim` | [`sequences`][sequences] | remove os espaços em branco do início e do fim |
| `first`, `second`, `third`, `fourth` | [`sequences`][sequences] | a posição inicial |
| `first2`, `first3`         | [`sequences`][sequences]   | separa duas ou três posições iniciais |
| `>string`    | [`strings`][strings]     | transforma uma sequência de caracteres em uma string |
| `1string`    | [`strings`][strings]     | envolve um único caractere em uma string de um caractere |
| `CHAR: x`    | parser        | um literal de um único caractere (por exemplo, `CHAR: A` → `65`) |

Para converter entre números e strings nos dois sentidos, [`math.parser`][math.parser] oferece `number>string` e `string>number`. Para saída com string de formato, [`formatting`][formatting] oferece `sprintf` e afins.

Para conversão de maiúsculas e minúsculas ou classificação de caracteres que leva o Unicode em conta, use as palavras correspondentes em [`unicode`][unicode].
