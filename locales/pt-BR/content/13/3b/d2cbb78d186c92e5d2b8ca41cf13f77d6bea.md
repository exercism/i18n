# Instruções

Converta uma frase na sigla dela.

Quem é do mundo tech adora suas TLAs (siglas de três letras)!

Ajude a gerar um pouco de jargão escrevendo um programa que converte um nome longo como Portable Network Graphics na sua sigla (PNG).

A pontuação é tratada assim: hífens são separadores de palavras (como espaços em branco); todo o resto da pontuação pode ser removido da entrada.

Por exemplo:

| Entrada                   | Saída |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
