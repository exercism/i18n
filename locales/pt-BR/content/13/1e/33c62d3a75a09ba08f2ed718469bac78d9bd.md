# Instalação

A trilha de C exige que você tenha os seguintes programas instalados no seu sistema:

* Um compilador C moderno
* A ferramenta de build Make

O Xcode, IDE da Apple, reúne o compilador e o sistema de build nativo em uma única IDE (ambiente de desenvolvimento integrado).
Ambientes Linux normalmente expõem o compilador e o sistema de build nativo como ferramentas de linha de comando separadas.

## Linux

Usuários de Linux vão precisar do gcc ou do clang como compilador, e do `make` para o build nativo.
O Make já vem instalado na maioria dos sistemas unix, mas muito provavelmente está disponível no seu gerenciador de pacotes.
Em distribuições baseadas em Debian e Ubuntu, tudo o que você precisa pode ser instalado com `sudo apt-get install build-essential`, caso ainda não esteja presente.

## MacOS

Usuários de MacOS podem instalar o gcc ou o clang com o [Homebrew][] através de `brew install gcc` ou `brew install llvm`.

## Windows

Para quem usa o Windows 10, a recomendação é usar o [Windows Subsystem for Linux][] e seguir as instruções para Linux acima.

Se você estiver usando uma versão anterior do Windows ou se o WSL Bash não estiver disponível para você, pode usar o [MSYS][] ou o [mingw-w64][].

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
