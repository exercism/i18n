# Dicas

## Geral

- Este [artigo][time-overview] é uma visão geral de datas, horas e fusos horários no .NET.
- A struct `DateTime` está documentada [aqui][date-time].

## 1. Forneça aos administradores equivalentes em horário local dos agendamentos em UTC (Tempo Universal Coordenado)

Procure um membro adequado de `DateTime` que converta de UTC para o horário local.

## 2. Agende compromissos em Nova York, Londres e Paris

Use a classe [`TimeZoneInfo`][time-zone-info] e selecione os IDs de fuso horário apropriados nas instruções da tarefa. Lembre-se de que o Windows e o OSX/Linux têm IDs diferentes.

O método [`RuntimeInformation.IsOSPlatform()`] é essencial para ter caminhos de código voltados a sistemas operacionais diferentes.

## 3. Envie alertas aos clientes em intervalos antes do agendamento

Uma abordagem é usar [`TimeSpan`][time-span] para fazer aritmética com horários.

## 4. Se o horário de verão mudou recentemente, enviamos uma mensagem aos clientes para lembrá-los.

`TimeZoneInfo` tem métodos apropriados para isso.

## 5. Use o formato de data e hora local para inserir agendamentos

Dê uma olhada em `DateTime.Parse()` e [`CultureInfo`][culture-info].
