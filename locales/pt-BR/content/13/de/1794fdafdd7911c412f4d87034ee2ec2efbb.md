# Dicas

## Geral

- Tente dividir um problema em um caso base e um caso recursivo
  Por exemplo, digamos que você queira contar quantos cookies há no pote de cookies com uma abordagem recursiva
  Um caso base é um pote vazio: ele tem zero cookies.
  Se o pote não estiver vazio, então o número de cookies no pote é igual a um cookie mais o número de cookies no pote depois de remover um cookie.

## 1. Implemente uma função para somar os números de um array

- A recursão consiste em iterar sobre os elementos do array, somando cada um a um acumulador.
- O caso base é um array vazio, cuja soma é igual a zero.
- O caso recursivo soma o primeiro elemento à soma do restante do array.
- Lembre-se da indexação e do fatiamento de arrays em [o conceito de Arrays][arrays-concept] para separar o primeiro elemento do array do restante dos elementos.

## 2. Inverta um array

- A recursão consiste em iterar sobre os elementos do array, adicionando cada um a outro array em ordem inversa.
- O caso base é um array vazio.
- Lembre-se de que o [operador `+`][manual-addition] concatena quando aplicado a arrays.

## 3. Mapeie um array

- A recursão consiste em iterar sobre os elementos do array, adicionando a um array acumulador o resultado de aplicar o filtro ao elemento.
- Para aplicar o parâmetro de filtro a um elemento, use a sintaxe de pipe usual: `.element | filter`.
- O caso base é um array vazio.
