# Instruções

Seu clube de netball precisa que a tabela de classificação seja calculada depois de cada rodada.

As quatro tarefas ficam na classe `NETBALL_LADDER`.

## 1. Pontos na tabela

Uma vitória vale 4 pontos e um empate, 2. As derrotas não valem nada.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. Saldo de gols

Gols marcados menos gols sofridos. Pode ser negativo.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. Quartos inteiros jogados

Um quarto tem 15 minutos. Dado um número de minutos, quantos quartos inteiros isso dá?

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. Minutos dentro do quarto

Dado o mesmo número de minutos, quantos minutos já se passaram no quarto atual?

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
