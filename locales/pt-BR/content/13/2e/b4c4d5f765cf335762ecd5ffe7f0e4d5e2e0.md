# Ajuda

## Rodando os testes

A trilha de Factor usa o **Factor 0.101**. Depois de
[instalá-lo](https://exercism.org/docs/tracks/factor/installation),
rode a partir do diretório deste exercício:

```
factor -roots=. -run=exercism-tools <exercise>
```

Por exemplo, para o `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Cada exercício inclui um pequeno vocabulário `exercism-tools`
embutido, que comanda a execução dos testes. O executor termina
com status 0 quando todos os testes passam, e com status
diferente de zero mais uma saída de diagnóstico se algum teste
falhar.

### Testes ignorados

Por padrão, só o primeiro teste roda. O mecanismo é a linha
`STOP-HERE` no arquivo de teste: no momento da análise, ela diz
ao lexer do Factor para ignorar tudo o que vem abaixo, de modo
que o executor só enxerga os testes acima. Quando seu primeiro
teste passar, você pode ativar mais testes de duas maneiras:

- **Apague a linha `STOP-HERE`** para ativar de uma vez todos os
  testes restantes.
- **Mova a linha `STOP-HERE` mais para baixo** para ativar os
  testes um de cada vez, ou uma tarefa por vez. Os exercícios de
  conceito agrupam seus testes sob marcadores `TASK:`; mover o
  `STOP-HERE` para logo antes do próximo `TASK:` é um passo
  natural.

Quando todos os testes passarem, você resolveu o exercício.

## Enviando sua solução

A partir do diretório do exercício:

```
exercism submit <exercise>/<exercise>.factor
```

Por exemplo:

```
exercism submit hello-world/hello-world.factor
```

Se o `.meta/config.json` do exercício listar mais de um
arquivo de solução (alguns exercícios de conceito dividem uma
solução em um subvocabulário auxiliar), passe para o
`exercism submit` todos os arquivos que você editou.

## Enviando soluções incompletas

Você pode enviar uma solução mesmo com testes falhando. Isso
permite ver como outras pessoas abordaram o exercício e pedir
feedback de mentores sobre o que você já tem até agora.

## Como conseguir mais ajuda

- A [categoria Factor no fórum do Exercism](https://forum.exercism.org/c/programming/factor/)
  é o melhor lugar para dúvidas e feedback específicos da trilha.
- O [Discord do Exercism](https://exercism.org/r/discord) tem
  canais tanto para ajuda geral quanto para trilhas individuais.
- A documentação oficial do Factor é pesquisável e completa. Dois bons pontos de entrada:
  - [The Factor handbook](https://docs.factorcode.org/content/article-handbook.html):
    em formato de referência, organizado por vocabulário.
  - [The Factor cookbook](https://docs.factorcode.org/content/article-cookbook.html):
    exemplos curtos e idiomáticos por tópico.
- O [Factor tutorial](https://andreaferretti.github.io/factor-tutorial/)
  de Andrea Ferretti é uma introdução rápida e amigável à
  linguagem e ao ambiente de desenvolvimento.
