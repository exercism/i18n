# Bools

Haskell tem um tipo conhecido como [`Bool`][bools].
É uma enumeração de `True` e `False`.

## Operadores lógicos

Haskell tem três operadores lógicos (`not`, `||`, `&&`), que combinam Bools e montam expressões que produzem valores diferentes.

### And(`&&`)

O operador [_and_][and] em Haskell é representado por `&&` e retorna `True` se os dois valores forem `True`; caso contrário, retorna `False`.
Ao usar o operador _and_, um Bool fica à direita do `&&` e o outro à esquerda.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### Or(`||`)

O operador [_or_][or] em Haskell é representado por `||` e retorna `True` se **pelo menos um** dos valores dados for `True`. 
Se ambos os valores forem `False`, retorna `False`.
Ao usar o operador _or_, um Bool deve ficar à direita do `||` e o outro à esquerda.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Not(`not`)

O operador _not_ em Haskell é representado por `not` e retorna `True` se o Bool dado for `False`, e retorna `False` se receber `True`.
Ao usar o operador _not_, um Bool deve ficar depois do operador (`not`).

```haskell
not True
-- -> False

not False
-- -> True
```

## Usando parênteses(`()`)

Ao trabalhar com booleanos, você pode usar parênteses para decidir quais Bools avaliar primeiro.
O resultado pode ser diferente dependendo de como os parênteses são usados.
Em Haskell, o que está entre parênteses é avaliado primeiro.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Como o que está entre parênteses é avaliado primeiro, no exemplo a seguir o operador _not_ vai se aplicar à expressão dentro dos parênteses.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
Use parênteses apenas quando eles afetarem o resultado; caso contrário, omita-os.
~~~~
