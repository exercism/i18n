# Instruções

Há uma loja de eletrodomésticos chamada "Tech Palace" aqui perto.
O dono da loja instalou recentemente um grande painel para usar em mensagens de marketing e para mostrar uma saudação especial quando os clientes passam o cartão de fidelidade na entrada.
O painel é formado por muitas luzes de LED pequenas e pode mostrar várias linhas de texto.

O dono da loja precisa da sua ajuda com o código usado para gerar o texto do novo painel.

## 1. Crie a mensagem de boas-vindas

<!-- markdownlint-disable-next-line MD038 -->
Para a maioria dos clientes que passam o cartão de fidelidade, o dono da loja quer ver `Welcome to the Tech Palace, ` seguido do nome do cliente em letras maiúsculas no painel.

Implemente a função `welcome_message` que aceita o nome do cliente como argumento de string curta (`felt252`) e retorna a mensagem desejada como um `ByteArray`.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. Adicione uma borda chique

Para os clientes fiéis que compram bastante na loja, o dono quer deixar o painel de boas-vindas mais chique, adicionando uma linha de estrelas antes e depois da mensagem de boas-vindas.
Ele ainda não decidiu quantas estrelas deve haver nas linhas, então quer que essa quantidade seja configurável.

Escreva uma função `add_border` que aceita uma mensagem de boas-vindas (um `ByteArray`) e o número de estrelas por linha (do tipo `u32`) como argumentos.
Ela deve retornar um `ByteArray` com 3 linhas: uma linha com o número desejado de estrelas, depois a mensagem de boas-vindas como foi passada e, por fim, outra linha de estrelas.

```rust
add_border("Welcome!", 10)
```

Deve retornar o seguinte:

```bash
**********
Welcome!
**********
```

## 3. Limpe mensagens de marketing antigas

Antes de instalar esse novo painel, a loja tinha um painel parecido que só mostrava linhas estáticas e não configuráveis.
O dono gostaria de reaproveitar algumas das mensagens de marketing antigas no novo painel.
Porém, os dados já incluem uma borda de estrelas e alguns espaços em branco indesejados.
Sua tarefa é limpar as mensagens para que possam ser reaproveitadas.

Implemente uma função `clean_up_message` que aceita a mensagem de marketing antiga como um `ByteArray`.
A função deve primeiro remover todas as estrelas do texto e, depois, remover os espaços em branco do início e do fim do texto restante.
Em seguida, a função deve retornar a mensagem limpa.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
