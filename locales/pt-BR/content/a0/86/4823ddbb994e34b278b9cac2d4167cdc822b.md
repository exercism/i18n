# Anexo às instruções

## Trabalhando com datas em Prolog

O suporte nativo do Prolog para datas é [bastante rudimentar][built-in-dates-support].
Uma forma bem mais agradável de trabalhar com datas é usar o [pacote date_time][date_time-package].

### Instalando o pacote date_time

Se a versão do Swipl que você instalou estiver razoavelmente atualizada, você pode instalar o pacote rodando:

```bash
swipl pack install date_time
```

Se isso não funcionar, você pode rodar:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Se você estiver usando o editor online, não precisa instalar nada manualmente.
~~~~

### Usando o pacote date_time

Adicione o seguinte código no topo do arquivo da sua solução para usar o pacote `date_time`:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Dica: o [código-fonte do pacote date_time][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] é bem documentado e pode ser de grande ajuda!
~~~~
