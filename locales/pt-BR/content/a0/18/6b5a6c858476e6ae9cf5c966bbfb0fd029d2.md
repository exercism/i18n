# Recursos

Existem muitos recursos online gratuitos e ótimos para Lua, incluindo:

1.  [lua.org][8]
2.  Uma introdução detalhada e autoritativa, altamente recomendada, a todos os aspectos da programação em Lua, escrita pelo arquiteto-chefe de Lua: [Programming in Lua, by Roberto Ierusalimschy][6]
3.  Para uma definição oficial da linguagem Lua, consulte o [Lua 5.4 Reference Manual][7], de R. Ierusalimschy, L. H. de Figueiredo, W. Celes.
4.  [Lua Style Guide][4]
5.  [Learn Lua in 15 minutes][5]
6.  Embora não seja bonito de se ver, o wiki do [lua-users.org][14] contém muitas informações e conhecimentos úteis
7.  Algumas opções para linting
    -   [luacheck][12]
    -   [Detecting Undefined Variables][13]
8.  Implementações do Language Server Protocol para Lua
    -   [Lua Language Server][9]
    -   [EmmyLua-LanguageServer][10]
