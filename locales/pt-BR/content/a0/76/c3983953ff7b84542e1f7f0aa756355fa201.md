# Sobre

`when` é a palavra-chave para filtrar exceções. Ele é colocado depois da instrução catch e pode receber uma expressão Boolean que contenha quaisquer valores no escopo naquele momento. Esses valores não precisam ser apenas membros da própria exceção. Se o tipo da exceção corresponder e a expressão resultar em true, o bloco associado a essa instrução `catch` é executado; caso contrário, a próxima instrução `catch`, se houver, é verificada.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- Este artigo [Filtros de exceção][exception-filters] mostra como filtrar exceções.
