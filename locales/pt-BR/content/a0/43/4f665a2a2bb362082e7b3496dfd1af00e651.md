# Introdução

Em Haxe, um **array** (_vetor_) é uma coleção de elementos (normalmente) do mesmo tipo. Há três formas de criar um array em Haxe: com um construtor ou com uma sintaxe de declaração. Em Haxe, o primeiro elemento de um array tem índice zero:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Para criar um array usando um construtor, você precisa passar o tipo dos elementos que vão ser incluídos no array:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Se quisermos que um array contenha vários tipos de elementos, adicionamos o tipo `Dynamic` ao indicador de tipo:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
