# Dicas

## 1. Divida uma string em linhas individuais

- O Swift tem um [método][nsstring-components-docs] para dividir uma string em um array de strings usando um delimitador fornecido.

## 2. Porta da frente

- O guarda vai recitar um poema, e você vai ter que dividir o poema em linhas individuais; você pode usar uma função já existente para isso.
- Você pode usar um laço `for` para iterar sobre as linhas do poema.
- Você pode usar a propriedade `first` de uma string para obter o primeiro caractere de uma string.
- Para armazenar o primeiro caractere de cada linha, você pode usar um array de caracteres ou uma string.

## 3. Porta dos fundos

- O guarda vai recitar um poema, e você vai ter que dividir o poema em linhas individuais; você pode usar uma função já existente para isso.
- Você pode usar um laço `for` para iterar sobre as linhas do poema.
- Você pode usar a propriedade `last` de uma string para obter o último caractere de uma string.
- Para armazenar o último caractere de cada linha, você pode usar um array de caracteres ou uma string.

## 4. Sala secreta

- O guarda vai recitar um poema, e você vai ter que dividir o poema em linhas individuais; você pode usar uma função já existente para isso.
- Você pode usar um laço `for` que itera sobre o comprimento das linhas do poema.
- O Swift tem um [método][indexing] para obter o caractere em um índice específico de uma string.
- O Swift tem um [método][uppercased] para converter uma string para maiúsculas.
