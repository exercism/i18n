# Aprendizado

## Recursos de aprendizado recomendados

O Exercism oferece exercícios e feedback, mas pode ser difícil começar com ML para quem está aprendendo SML pela primeira vez.
Estes recursos podem ajudar você a dar os primeiros passos:

### Nunca programei antes

Provavelmente ML não é a melhor linguagem para quem está começando a programar.
Provavelmente é melhor você começar com uma linguagem como Ruby ou Python, mas, se estiver se sentindo especialmente ousado, talvez queira ler [Programming in Standard ML '97: An On-line Tutorial][tutorial].
Sugiro pular a introdução e ir direto para [Simple applicative programming][node13], porque a introdução é bem técnica.

O Coursera oferece um curso sobre [linguagens de programação][coursera].
O curso é voltado para programadores com alguma experiência, mas é difícil encontrar uma introdução melhor à linguagem ML.


### Já ouvi falar de programação funcional

Uma boa leitura é [Programming in Standard ML '97: An On-line Tutorial][tutorial].

Outra é [A Gentle Introduction to ML][gentle].

O Coursera oferece um curso sobre [linguagens de programação][coursera].
É difícil encontrar uma introdução melhor à linguagem ML.

O [site do SML/NJ][smlnj] lista vários livros.
A maioria é bem antiga e provavelmente difícil de encontrar.
A linguagem não mudou muito, então, se você conseguir encontrá-los, não pense que estão tão desatualizados.
Dê uma olhada também nas Four Lectures on Standard ML listadas na página.


## Sou um programador confiante

Se você é um programador confiante e conhece muito bem linguagens funcionais, pode ter uma boa visão geral da sintaxe em [Learn X in Y minutes][learnxy].

As [Four Lectures on Standard ML][four-lectures] são uma boa introdução.
