# Instruções

Você é um observador de aves dedicado que acompanha quantas aves visitaram o seu jardim.
Normalmente, você usa uma marcação em um caderno para contar as aves, mas você quer
trabalhar melhor com os seus dados. Você já digitalizou as contagens de aves por dia das
últimas semanas que guardou no caderno.

Agora você quer determinar o número total de aves que contou, calcular a contagem de aves
de uma semana específica e corrigir um erro de contagem.

<!-- prettier-ignore -->
~~~~exercism/note
Para praticar, use um laço `for` para resolver cada uma das tarefas abaixo.
~~~~

## 1. Determine o número total de aves que você contou até agora

Vamos começar analisando os dados com uma visão geral.
Descubra quantas aves você contou no total desde que começou os seus registros.

Implemente uma função `totalBirdCount` que aceita um objeto do tipo array que contém a
contagem de aves por dia.
Ela deve retornar o número total de aves que você contou.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. Calcule o número de aves visitantes em uma semana específica

Agora que você tem uma noção geral dos seus números de contagem de aves, você quer fazer
uma análise mais detalhada.

Implemente uma função `birdsInWeek` que aceita um objeto do tipo array de contagens de aves
por dia e um número de semana.
Ela retorna o número total de aves que você contou nessa semana específica.
Você pode assumir que as semanas são sempre registradas por completo.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. Corrija um erro de contagem

Você percebeu que, todo o tempo em que tentava acompanhar as aves, havia uma se escondendo
em um canto distante do jardim.
Você descobriu que essa ave sempre passava dia sim, dia não no seu jardim.
Você não sabe exatamente onde ela estava entre esses dias, mas com certeza não estava no
seu jardim.
Sua intuição de observador de aves também diz que a ave estava no seu jardim no primeiro
dia que você registrou na sua lista.

Com essa nova informação, escreva uma função `fixBirdCountLog` que recebe um objeto do tipo
array de aves contadas por dia como argumento. Ela deve corrigir o erro de contagem
modificando o array fornecido.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
