# Introdução

Existem dois tipos diferentes de números em C#:

- Inteiros: números sem nenhum dígito depois do separador decimal (números inteiros). São exemplos `-6`, `0`, `1`, `25`, `976` e `500000`.
- Números de ponto flutuante: números com zero ou mais dígitos depois do separador decimal. São exemplos `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

Os dois tipos numéricos mais comuns em C# são `int` e `double`. Um `int` é um inteiro de 32 bits e um `double` é um número de ponto flutuante de 64 bits.

A aritmética é feita com os operadores aritméticos padrão. Os números podem ser comparados com os operadores de comparação numérica padrão e com os operadores de igualdade (`==`) e desigualdade (`!=`).

O C# tem dois tipos de conversão numérica:

1. Conversões implícitas: nenhum dado é perdido e nenhuma sintaxe adicional é necessária.
2. Conversões explícitas: dados podem ser perdidos e é necessária uma sintaxe adicional na forma de um _cast_.

Como um `int` tem menos precisão que um `double`, converter de `int` para `double` é seguro e, portanto, é uma conversão implícita. Já converter de `double` para `int` pode significar perda de dados, então isso exige uma conversão explícita.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
