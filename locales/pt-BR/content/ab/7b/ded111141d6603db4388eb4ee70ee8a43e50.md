# Instruções

É o turno da noite no cais de Hull. O cargueiro *Olwen* está
atracado ao lado, e uma equipe de estivadores trabalha o
manifesto em paralelo. Todo caixote precisa ser pesado antes de
subir a bordo, e o capitão do porto mantém uma única **contagem
de tonelagem** corrente que cada içamento atualiza. O detalhe:
só existe um guindaste no cais, então a contagem não pode ser
corrompida por dois estivadores atualizando-a ao mesmo tempo.

Cada caixote é um array de pesos de itens. O peso do caixote é a
soma desses itens.

## 1. Pesar um caixote

Defina `weigh-crate` para receber um caixote e retornar seu peso
total. É trabalho sequencial simples: entra um caixote, sai um
número.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. Pesar o manifesto inteiro em paralelo

Defina `weigh-all` para receber um array de caixotes e retornar o
array com seus pesos, na mesma ordem. Use `parallel-map` para que
o trabalho por caixote aconteça em paralelo.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. Construir um guindaste novo

Defina `<crane>` para construir um novo guindaste: uma tupla com
um `<lock>` novo e uma tonelagem de `0`. O guindaste é o recurso
compartilhado que as tarefas seguintes vão proteger.

```factor
<crane> tonnage>> .
! => 0
```

## 4. Içar um caixote para a contagem em andamento

Defina `hoist-crate` para receber um `weight` e um `crane` e somar
o peso à tonelagem do guindaste **sob o lock do guindaste**, para
que a leitura, a soma e a escrita sejam atômicas em relação a
outros estivadores que estejam içando ao mesmo tempo.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. Ler a tonelagem em andamento

Defina `crane-tonnage` para retornar a tonelagem atual do
guindaste, também sob o lock, para que a leitura não veja um
valor corrompido no meio de um içamento.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. Carregar a carga

Defina `load-cargo` para receber um array de caixotes e um
guindaste e, **para cada caixote, criar uma thread de estivador**
que pesa o caixote e iça o peso para o guindaste. A palavra só
retorna depois que todos os estivadores terminam. Use `<promise>`
e `?promise` para coordenar a junção.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
