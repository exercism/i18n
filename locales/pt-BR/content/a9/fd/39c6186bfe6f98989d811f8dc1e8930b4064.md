# Dicas

## Geral

- [Structs e classes][structs-and-classes] compartilham uma sintaxe de definição semelhante.

## 1. Defina uma struct Size

- As propriedades devem ser definidas como `var`s se puderem ser alteradas.
- As propriedades height e width devem receber os valores padrão 80 e 60, respectivamente.
- Os métodos de uma struct precisam ser marcados como `mutating` se alterarem propriedades da struct.

## 2. Defina uma struct Position

- As propriedades devem ser definidas como `var`s se puderem ser alteradas.
- As propriedades x e y devem receber o valor padrão 0.
- Os métodos de uma struct precisam ser marcados como `mutating` se alterarem propriedades da struct.

## 3. Defina uma classe Window

- Structs podem ser inicializadas com valores de propriedades diferentes usando [inicializadores membro a membro][memberwise-initializers].
- Propriedades constantes devem ser definidas usando `let`.
- A propriedade `contents` deve ser opcional, pois pode não ter valor.
- Você precisa definir um inicializador vazio para a classe (`init() {}`).

## 4. Adicione um método para redimensionar janelas

- O método deve receber um parâmetro `to` do tipo `Size`.
- É possível extrair width e height do parâmetro `to` usando a notação de ponto.

## 5. Adicione um método para mover janelas

- O método deve receber um parâmetro `to` do tipo `Position`.
- É possível extrair x e y do parâmetro `to` usando a notação de ponto.

## 6. Adicione um método para definir o conteúdo de uma janela

- É possível ter dois métodos com o mesmo nome, mas com parâmetros diferentes em Swift.
- Defina um método com o parâmetro `title` que define a propriedade `title`.
- Defina um método com o parâmetro `text` que define a propriedade `contents`.
- Defina um método de exibição que imprime o título e o conteúdo da janela.

## 7. Crie um inicializador para a classe Window

- A classe deve ter dois inicializadores: um que não recebe nenhum parâmetro e outro que recebe parâmetros.
- O novo inicializador deve ter os parâmetros `title` e `contents`, e também deve permitir os parâmetros opcionais `size` e `position`
    Se nenhum parâmetro for informado, os valores padrão devem ser usados.
- Parâmetros opcionais podem ser obtidos usando [valores padrão de parâmetros][default-parameters-vales].
