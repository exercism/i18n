# Introdução

[Structs e classes][structs-and-classes] são os principais blocos de construção para criar tipos personalizados em Swift.
Ambos permitem agrupar propriedades (dados) e métodos (comportamento) relacionados em unidades reutilizáveis.
A maioria dos tipos fundamentais do Swift, incluindo `Int`, `Double`, `String` e tipos de coleção como `Array` e `Dictionary`, é implementada como structs.

Para guias detalhados sobre cada tipo, veja:

- [concept:swift/structs]()
- [concept:swift/classes]()

## Escolhendo entre structs e classes

Embora structs e classes permitam definir tipos personalizados, eles diferem fundamentalmente na forma como são passados na memória:

- **Structs são tipos de valor**: quando você atribui ou passa uma struct, o Swift faz uma cópia independente dos seus dados.
Alterações feitas em uma cópia não afetam as outras cópias.
- **Classes são tipos de referência**: quando você atribui ou passa uma instância de classe, o Swift compartilha uma referência para a instância existente.
Alterações feitas por meio de uma referência afetam imediatamente todas as outras referências que apontam para a mesma instância.

O Swift prioriza a segurança e o comportamento previsível, o que faz das structs a recomendação padrão para a maioria dos tipos personalizados.
Usar tipos de valor garante que alterar dados em uma parte do programa não produza efeitos colaterais inesperados em outro lugar.

Em geral:

- **Use uma struct** ao modelar dados que representam valores independentes (como coordenadas, formas, dimensões geométricas ou registros formatados).
- **Use uma classe** ao modelar entidades que têm identidades distintas ou requisitos de ciclo de vida compartilhado (como controles de interface, conexões com banco de dados ou manipuladores de arquivo).
