# Sobre
Um laço é uma forma de chamar repetidamente uma ou mais instruções em conjunto.
Cada execução de um conjunto de instruções é chamada de iteração.

## Laço `while`

Um laço `while` executa um conjunto de instruções enquanto uma expressão Boolean no topo do laço for verdadeira.
Quando a expressão Boolean for falsa, o laço para de rodar e a execução segue para a próxima linha de código depois do laço.

Se a expressão Boolean for falsa desde o começo, o laço `while` não rodará nenhuma vez e a execução seguirá para a próxima linha de código depois do laço.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

É importante que exista uma condição para encerrar o laço; caso contrário, ele é um laço infinito, que vai travar todo o progresso do código.
Se o código acima tivesse o `++` removido do `i`, seria um laço infinito.

## Laço `do`

Um laço `do` tem sua expressão Boolean testada na parte de baixo do laço.
Um laço `do` sempre rodará pelo menos uma vez, como no exemplo a seguir

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Com um laço `while`, isso ficaria mais verboso

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Laço `for`

Muitas vezes um laço atualiza uma variável e termina quando a variável atinge um determinado valor.
Um laço `for` é uma forma de inicializar, atualizar e testar uma ou mais variáveis em uma única linha, dentro de parênteses.
A primeira seção serve para inicializar a variável, a segunda para testar a variável e a terceira para atualizar o valor da variável.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Isso é menos verboso que o laço `while` equivalente e, ainda assim, continua legível.

As seções de inicialização e atualização do laço `for` podem lidar com mais de uma variável usando o operador vírgula para separar expressões dentro das condições.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Isso vai imprimir

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

Nenhuma das seções do `for` precisa ser definida.
Uma expressão de teste vazia é avaliada como verdadeira, então um laço `for` poderia ser usado para definir um laço infinito assim

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

Isso é parecido com o laço `while`, no sentido de que `i` é inicializado antes do laço e incrementado dentro do laço.
Além disso, `i` é testado dentro do laço e o laço termina com a instrução `break`.

## Instrução `break`

Às vezes um laço pode precisar terminar por uma condição especial que não é testada em sua expressão Boolean.
A instrução `break` encerra o laço e a execução segue para a próxima linha de código depois do laço.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Isso vai imprimir

```
i is 0
j is 5
After the loop
```

## Instrução `continue`

Às vezes um laço pode precisar iniciar sua próxima iteração sem concluir a iteração atual.
A instrução `continue` interrompe a execução da iteração atual e continua a execução no início da próxima iteração.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Isso vai imprimir

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

Ela não imprime os valores de `i` e `j` quando ambos são `2`.
