# Sobre

Em Haxe, os iteradores servem para iterar sobre um valor usando um laço `for`. Existem dois tipos de iteradores:

- `Iterator`, que itera sobre um valor.
- dados `Iterable`, que tornam possível iterar sobre um tipo de dados.

Os dois conceitos são representados por `Iterator<T>` e `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Qualquer classe que unifique com um desses tipos pode ser iterada com um laço `for`. Se uma classe define os métodos `hasNext` e `next`, ela é considerada um iterador; caso contrário, se define um método `iterator`, é considerada um tipo iterável:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

No exemplo acima, a classe `MyStringIterator` é considerada um iterador, já que implementa os métodos `hasNext` e `next`, o que a torna compatível com `Iterator<String>`.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

Aqui, a classe `MyArrayWrap` é considerada um tipo de dados iterável, já que é compatível com `Iterable<Array<T>>`.
