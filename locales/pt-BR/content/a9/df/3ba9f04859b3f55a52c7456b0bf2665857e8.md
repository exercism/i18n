# Instruções

Enquanto você continua seu trabalho na _Instruments of Texas_, a implementação em Elixir da calculadora RPN está avançando. Sua equipe gostaria de conseguir lançar erros mais específicos do que os erros genéricos fornecidos pela biblioteca padrão. Você está fazendo algumas pesquisas, mas decidiu implementar dois novos erros que implementam o _Exception Behaviour_.

## 1. Erro para divisão por zero

Dividir um número por zero produz um resultado indefinido, e a equipe decide que o melhor é representá-lo por meio de um erro.

Implemente o módulo `DivisionByZeroError` com a mensagem de erro: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Erro ao encontrar underflow da pilha

As calculadoras RPN usam uma _pilha_ para acompanhar os números antes de serem somados. A equipe representa essa _pilha_ com uma lista de números (inteiros e de ponto flutuante), por exemplo: `[3, 4.0]`. Cada operação precisa de uma quantidade específica de números na pilha para realizar seu cálculo. Quando não há números suficientes na pilha, isso é chamado de erro de underflow da pilha. Implemente a exceção `StackUnderflowError`, que fornece uma mensagem padrão e um contexto extra opcional

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Escreva uma função de divisão

Implemente a função `divide/1`, que recebe uma pilha _(uma lista de dois números)_ e:

- lança um _underflow da pilha_ quando a pilha não contém números suficientes
- lança uma _divisão por zero_ quando o divisor é 0 (repare que a pilha de números é armazenada na ordem inversa)
- realiza a divisão quando nenhum erro é lançado

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> Repare que a ordem da lista está invertida!
