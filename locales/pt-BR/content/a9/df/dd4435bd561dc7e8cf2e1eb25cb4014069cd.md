# Introdução

Os dicts em Gleam são a estrutura de dados para armazenar informações em pares de chave-valor. Em outras linguagens, eles também podem ser conhecidos como arrays associativos, hashes ou dicionários.

Qualquer tipo pode ser usado para as chaves e os valores em um dict, e os dicts não garantem a ordem das suas entradas quando acessadas ou retornadas.

## Trabalhando com dicts

Os dicts são criados e manipulados usando funções do módulo `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
