# Introdução

Uma string em Factor é uma sequência de caracteres. A maioria das palavras do vocabulário [`sequences`][sequences] funciona com strings, além das palavras dedicadas ao tratamento de strings em [`splitting`][splitting], [`ascii`][ascii] e afins.

## Literais de string

As strings são escritas entre aspas duplas. As sequências de escape usuais são aceitas: `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Comprimento e indexação

Como uma string é uma sequência, as palavras `length` e `nth` do vocabulário [`sequences`][sequences] funcionam diretamente nela.

`length` retorna o número de caracteres:

```factor
"hello" length .    ! => 5
```

`nth` recebe um índice com base em zero e a sequência, e retorna o elemento naquela posição. No caso de uma string, o elemento é um *caractere*, um ponto de código (um número inteiro), e não uma substring de um caractere:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## De um caractere de volta para uma string

Para transformar um único ponto de código em uma string de um caractere, use `1string ( char -- str )` do vocabulário [`strings`][strings]. `CHAR:` é a forma que o parser aceita para um ponto de código literal:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## Separação

O vocabulário [`splitting`][splitting] corta uma string em pedaços.

`split1` corta na *primeira* ocorrência de um separador e retorna as duas metades:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` corta em *qualquer* um dos caracteres de um conjunto de separadores, podendo produzir pedaços vazios:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` (em [`sequences`][sequences]) descarta os pedaços vazios:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Selecionando um pedaço

Depois que uma string é dividida em um array de pedaços, `first`, `second`, `third` e `fourth` (em [`sequences`][sequences]) retornam o pedaço naquela posição:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Quando você quer todos os primeiros pedaços na pilha de uma vez, `first2` e `first3` desempacotam dois ou três deles em um único passo:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

Em uma string, `first` retorna o primeiro **caractere**, um ponto de código, e não uma substring:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Remoção de espaços em branco

`[ blank? ] trim` (de [`sequences`][sequences], com `blank?` do vocabulário [`ascii`][ascii]) remove espaços em branco no início e no fim:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Conversão de maiúsculas e minúsculas

`>lower` e `>upper` (de [`ascii`][ascii]) retornam uma nova string com as maiúsculas e minúsculas alteradas:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Junção

Duas palavras de [`sequences`][sequences] montam strings:

`surround` envolve uma string com um prefixo e um sufixo:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` une duas strings com um separador entre elas:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
