# Sobre

Elm é uma linguagem encantadora para criar aplicações web confiáveis.
Tem mensagens de erro amigáveis, ótima performance, assets pequenos e nenhuma exceção em tempo de execução.

Provavelmente a parte mais famosa e mais copiada do Elm é o The Elm Architecture, que é um padrão simples para estruturar aplicações web e é como todas as aplicações web em Elm são escritas.

A ideia central é que o seu código é construído em torno de um `Model` do estado da sua aplicação, de uma forma de `update` do seu modelo e de uma forma de `view` do seu modelo.

O `Model` contém o estado da aplicação: todos os dados de que a aplicação precisa.
Se você imaginar uma aplicação simples com uma caixa de texto e um texto mostrando o inverso desse texto, o modelo ficaria assim.
Você também pode ver este exemplo no [Elm Guide][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` é uma função chamada com uma `Msg` quando há uma mudança (como o usuário clicar em um botão).
Recebe a `Msg` e o `Model` atual e retorna um novo `Model`.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` é uma função que retorna HTML para mostrar ao usuário no navegador.
Recebe o `Model` atual e retorna um `Html Msg` (o tipo que o Elm usa para representar HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```
