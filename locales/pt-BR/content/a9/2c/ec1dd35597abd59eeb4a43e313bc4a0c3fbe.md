# Instalação

O [Godot Engine][godot-engine] é usado para rodar código GDScript.
O Godot Engine roda no Windows, Linux, macOS e Android.



## Instalando o Godot Engine

O Godot Engine pode ser baixado diretamente do [site do Godot Engine][godot-engine].
O download contém um único executável, cujo nome inclui a versão do Godot Engine.
Esse arquivo precisa ser renomeado para `godot` e colocado em um dos diretórios do `$PATH`.
Depois de concluir a instalação, você pode verificar se a CLI foi instalada com sucesso rodando este comando em um terminal:

```bash
godot --version
```

Esta trilha usa a versão 4.7.2 do Godot.
