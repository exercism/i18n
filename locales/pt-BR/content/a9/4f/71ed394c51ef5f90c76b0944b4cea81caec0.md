# Introdução

A função `switch()` pode ser uma substituta concisa para uma longa série de testes `if` ... `else if`.
A variável sobre a qual se faz o switch geralmente é uma string e, nesse caso, as aspas podem ser omitidas do seletor.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Repare que as opções só passam para a seguinte se o valor for deixado em branco, como acontece com `M` no exemplo acima.
Não é preciso incluir instruções `break`, como acontece em algumas outras linguagens.

Ao fazer o switch sobre tipos `character`, o valor final é um valor padrão, como aqui.
Com tipos inteiros, não é possível informar um padrão.

## Funções no `dplyr`

O `switch` do R base é bem limitado: ele só faz uma correspondência exata com uma única entrada.
Isso parecia razoável quando o R foi lançado, em 1993, mas precisa de melhorias para o uso moderno.

~~~~exercism/note
Como mencionado no Conceito [`Conditionals`][concept-conditionals], a coleção de pacotes `tidyverse` foi projetada para complementar (e às vezes substituir) a funcionalidade do R base sem afetar a compatibilidade retroativa.

O pacote `dplyr` pode ser trazido para o escopo adicionando `library(dplyr)` (para o pacote individual) ou `library(tidyverse)` (para a coleção inteira) ao topo do seu código.

[concept-conditionals]: https://exercism.org/tracks/r/concepts/conditionals

A biblioteca `dplyr` fornece duas funções extras relacionadas ao `switch`.

### As funções `recode_values` e `replace_values`

Essas duas funções relacionadas permitem um mapeamento vetorizado, semelhante ao switch, de valores antigos para valores novos.

A principal diferença entre elas é que `recode_values()` cria um vetor totalmente novo, enquanto `replace_values()` permite atualizações parciais de um vetor existente.

A correspondência ainda é exata, mas:

- As opções à esquerda podem ser vetores, e a entrada corresponde se qualquer elemento corresponder.
- As opções à esquerda e os resultados à direita são ligados com um til `~` em vez de `=`.
- Um valor padrão pode ser especificado em todos os casos.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### A função `case_when`

`case_when` leva a sintaxe de `case_match` um passo adiante, permitindo qualquer expressão lógica à esquerda do `~`.

O vetor de entrada (`x` no exemplo abaixo) não é fornecido como argumento; ele só precisa já estar definido.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

A função `between()` também faz parte do `dplyr`.
