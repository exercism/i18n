# Sobre

[Estruturas][structs-and-classes] (geralmente chamadas de *structs*) são um dos principais blocos de construção dos programas em Swift.
As structs permitem criar tipos personalizados que agrupam, em um só lugar, propriedades (dados) e métodos (comportamento) relacionados.
Na verdade, os tipos padrão da Swift, incluindo `Int`, `Double`, `Bool`, `String`, `Array` e `Dictionary`, são todos implementados como structs.

## Definindo structs

Defina uma struct com a palavra-chave `struct`, seguida do nome do tipo e de chaves que contêm sua definição.
Por convenção da Swift, os nomes de structs usam `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Criando instâncias

A definição de uma struct é um molde.
Para criar uma *instância* de uma struct, chame o inicializador dela escrevendo o nome do tipo seguido de parênteses:

```swift
var someStats = CharacterStats()
```

Isso cria uma instância preenchida com os valores padrão das propriedades definidas na struct.

A Swift também gera automaticamente um **inicializador membro a membro** para structs, que permite inicializar propriedades pelo nome:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Acessando e modificando propriedades

Você acessa e modifica as propriedades de uma instância usando a *notação de ponto*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Como structs são tipos de valor, para modificar as propriedades de uma instância é preciso que a própria instância seja declarada com `var`.
Se a instância for declarada com `let`, todas as suas propriedades se tornam imutáveis.
