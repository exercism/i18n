# Anexo às instruções

## Estrutura do projeto

Os exercícios de Clojure no exercism usam o [leiningen](http://leiningen.org/) para configurar e rodar seu código e seguem a [estrutura de diretórios padrão do leiningen](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout).

Você vai encontrar um arquivo de teste chamado `hello_world_test.clj` dentro do diretório `test`.
Escreva seu código em `src/hello_world.clj`. Ele deve usar o namespace `hello-world` para que os testes o reconheçam.

## Rodando os testes

Rode os testes com o comando `lein test` e faça com que passem:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Depois, envie o exercício usando:

```
$ exercism submit src/hello_world.clj
```

Para instruções mais detalhadas e recursos de aprendizado, consulte a [página da linguagem Clojure do exercism](http://exercism.io/languages/clojure).
