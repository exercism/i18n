# Introdução

## Arrays

Em Ruby, **arrays** (ou _vetores_) são coleções ordenadas de qualquer objeto, indexadas por números inteiros.
A indexação de arrays começa em `0`.
Um índice negativo é considerado relativo ao fim do array, por exemplo: um índice `-1` indica o último elemento do array, `-2` é o penúltimo elemento, e assim por diante.

### Criando arrays

Normalmente, os arrays são criados usando a notação `[]`.
Eles podem conter objetos de tipos diferentes.

```ruby
array = [1, "two", 3.0]
```

### Referência a elementos

Os elementos de um array podem ser recuperados por seus índices usando o método `#[]`.
Isso retorna o elemento no índice, ou retorna um subarray começando no índice inicial e continuando por um comprimento especificado.
Índices negativos contam de trás para frente a partir do fim do array.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### Métodos auxiliares

Há vários métodos auxiliares úteis em arrays.
Aqui estão alguns dos mais comuns:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## Enumeração

Em vez de usar laços para iterar sobre coleções, em Ruby usamos enumeração.

A enumeração é o ato de percorrer uma coleção (neste caso, um array) e executar alguma ação em cada objeto. A enumeração é um conceito-chave em Ruby e é usada para coisas como ordenação, agrupamento, mapeamento, redução e muito mais.

Uma enumeração para imprimir cada palavra de um array seria assim:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

Neste exemplo, chamamos o método `.each` no nosso array e passamos um _bloco_ que recebe um parâmetro (`word`) e o imprime.

Vamos ver _blocos_ com muito mais profundidade mais adiante na trilha, mas por enquanto pense neles como funções anônimas que podem receber zero ou mais argumentos.
Eles podem ser definidos usando a sintaxe `do...end` (acima), ou a sintaxe `{}` (abaixo).

Aqui estão alguns outros exemplos de métodos de array que usam blocos:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
