# Sobre

A macro `use` permite estender rapidamente nosso módulo com a funcionalidade fornecida por outro módulo. Quando usamos `use` em um módulo, esse módulo pode injetar código no módulo que o usa: por exemplo, ele pode definir funções, fazer `import` ou `alias` de outros módulos, ou definir atributos do módulo.

Se você já olhou os arquivos de teste de alguns dos exercícios de Elixir aqui no Exercism, provavelmente reparou que todos eles começam com `use ExUnit.Case`. É essa única linha de código que deixa as macros `test` e `assert` disponíveis no módulo de teste.

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## A macro `__using__/1`

O que acontece exatamente quando você usa `use` em um módulo é ditado pela macro `__using__/1` desse módulo. Ela recebe um argumento, uma lista de palavras-chave com opções, e retorna uma [expressão citada][concept-ast]. O código dessa expressão citada é inserido no nosso módulo na chamada de `use`.

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

As opções podem ser passadas como segundo argumento ao chamar `use`, por exemplo `use ExUnit.Case, async: true`. Quando não são passadas explicitamente, o padrão é uma lista vazia.

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
