# use interpolação de strings

[comment]: # (Este aviso é exibido quando a solução não usa interpolação de strings)

Use [interpolação de strings](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20) para inserir o parâmetro `name` na string de saída.

- Quando possível, a trilha de Elixir do Exercism recomenda usar interpolação de strings em vez de concatenação de strings, pela legibilidade.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [Qualquer expressão em Elixir](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30) pode aparecer na sintaxe de interpolação de strings

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
