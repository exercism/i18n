# Apêndice das instruções

## Registradores

| Registrador | Uso          | Tipo    | Descrição                    |
| ----------- | ------------ | ------- | ----------------------------- |
| `$a0`       | entrada      | inteiro | N, soma dos lados do triângulo |
| `$a1`       | entrada/saída | endereço | valores de a                  |
| `$a2`       | entrada/saída | endereço | valores de b                  |
| `$a3`       | entrada/saída | endereço | valores de c                  |
| `$v0`       | saída        | inteiro | número de trios               |
| `$t0-9`     | temporário   | qualquer | para armazenamento temporário |
