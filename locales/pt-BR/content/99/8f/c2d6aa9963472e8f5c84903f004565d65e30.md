# Dicas

## 1. Crie um conjunto de strings úteis

- [Strings][strings-and-characters] são definidas como literais quando você coloca zero ou mais caracteres entre aspas duplas (`"`).

## 2. Crie um conjunto de caracteres úteis

- [Caracteres][strings-and-characters] são definidos como literais quando você coloca exatamente um caractere entre aspas duplas (`"`).
- Caracteres definidos como literais precisam receber explicitamente uma anotação de tipo `Character` para impedir que o compilador os interprete como Strings.

## 3. Combine frases para montar mensagens

- Strings podem ser concatenadas com [o operador de string apropriado][string-docs].
- Caracteres não podem ser concatenados com Strings.
  Primeiro, eles precisam ser convertidos em Strings.

## 4. Monte uma placa de formatura

- [A interpolação de string][string-interpolation] é feita colocando a expressão cujo valor você quer inserir na string dentro de um par de parênteses precedidos por uma barra invertida.

## 5. Calcule o custo de uma placa

- O Swift tem [uma propriedade de string][string-count-docs] que retorna o número de caracteres em uma string.
