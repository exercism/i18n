# Recursos recomendados

## Documentação

* [Documentação da linguagem Groovy](http://docs.groovy-lang.org/docs/latest/html/documentation/)
* [Documentação da API Groovy JDK](http://groovy-lang.org/gdk.html)
* A [documentação do Groovy](http://www.groovy-lang.org/documentation.html) da Apache, incluindo a excelente seção [Aprenda Groovy](http://www.groovy-lang.org/learn.html)

## Ferramentas

* [SDKman](http://sdkman.io/)
* [Groovy Eclipse](https://github.com/groovy/groovy-eclipse/wiki)
* [IntelliJ Idea](https://www.jetbrains.com/idea/download/)

## Tecnologias

* [Gradle](https://gradle.org/), uma ferramenta de build para dominar todas
* [Spock](http://spockframework.org/), a nova geração de testes de linguagens da JVM
* [Ratpack](https://ratpack.io/), microsserviços minúsculos com martinis
* [Grails](https://grails.org/), "Você precisa escolher, mas escolha com sabedoria."

## Colaboração
