# Instruções

Observação: este exercício é uma continuação do exercício `need-for-speed`.

Neste exercício, você vai organizar corridas entre vários tipos de carros de controle remoto.
Cada carro tem suas próprias características de velocidade e de consumo de bateria.

Os carros começam com a bateria cheia (100%).
Cada vez que você dirige o carro com o controle remoto, ele percorre em metros a velocidade do carro e diminui a porcentagem restante da bateria pelo seu consumo de bateria.

Se a bateria de um carro estiver abaixo da porcentagem do seu consumo de bateria, você não pode mais dirigir o carro.

O carro de controle remoto tem um display de LED bacana que mostra duas informações:

- A distância total percorrida, exibida como: `"Driven <METERS> meters"`.
- A carga restante da bateria, exibida como: `"Battery at <PERCENTAGE>%"`.

Cada pista de corrida tem sua própria distância.
Os carros são testados verificando se conseguem terminar a pista sem ficar sem bateria.

## 1. Dirija o carro

Implemente o método `Drive` em `Car`, que atualiza o número de metros percorridos com base na velocidade do carro e reduz a bateria de acordo com o consumo de bateria:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

Observação: você não deve tentar dirigir o carro se isso fizer a bateria dele ficar abaixo de 0.

## 2. Exiba a distância percorrida

Implemente um método `DisplayDistance` em `Car` que retorne a distância exibida no display de LED como uma `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. Exiba a porcentagem da bateria

Implemente o método `DisplayBattery` em `Car` que retorne a porcentagem da bateria exibida no display de LED como uma `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. Verifique se um carro de controle remoto consegue terminar uma corrida

Para terminar uma corrida, o carro precisa conseguir percorrer a distância da corrida.
Isso significa não descarregar a bateria antes de cruzar a linha de chegada.
Implemente o método `CanFinish`, que recebe um `trackDistance int` como parâmetro e retorna `true` se o carro conseguir terminar a corrida; caso contrário, retorne `false`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
