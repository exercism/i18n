# Instruções

Seu amigo Linus é maquinista e conduz trens de carga entre cidades.
Apesar de ser incrível no comando dos trens, ele não é tão bom assim com logística ou computadores.
Ele gostaria de contar com a sua ajuda em programação para organizar os detalhes dos trens e corrigir erros nos dados das rotas.

~~~~exercism/note
Este exercício poderia ser resolvido facilmente usando fatiamento, indexação e vários métodos de `dict`.
No entanto, queremos que você pratique empacotamento, desempacotamento e atribuição múltipla ao resolver cada uma das tarefas abaixo.
~~~~

## 1. Crie uma lista de todos os vagões

Seu amigo vem acompanhando o identificador (ID) de cada vagão, mas nunca tem certeza de quantos vagões o sistema vai precisar processar em um dado momento. Seria muito mais fácil para o restante do programa de logística ter esses dados empacotados em uma única `list`.

Implemente uma função `get_list_of_wagons()` que aceita um número arbitrário de IDs de vagões.
Cada ID será um número inteiro positivo.
A função deve então `return` os IDs fornecidos como uma única `list`.

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. Corrija a lista de vagões

Neste ponto, você já está começando a entender os dados e como eles são usados no programa de logística.
O sistema de IDs sempre atribui à locomotiva o ID **1**, e os demais vagões do trem recebem um ID escolhido aleatoriamente maior que **1**.

Seu amigo teve que conectar dois vagões novos ao trem e esqueceu de atualizar o sistema!
Agora, os dois primeiros vagões da `list` do trem precisam ser movidos para o final, ou tudo vai ficar fora de ordem.

Para complicar ainda mais, seu amigo acabou de encontrar uma segunda `list` que parece conter IDs de vagões que estavam faltando.
Tudo o que ele lembra é que, depois que os novos vagões forem movidos, os IDs dessa segunda `list` devem ser colocados logo depois da locomotiva indicada.

Linus ficaria muito grato se você corrigisse os erros dele e consolidasse os dados.

Implemente uma função `fix_list_of_wagons()` que recebe duas `lists` contendo IDs de vagões.
Ela deve reposicionar os dois primeiros itens da primeira `list` para o final e inserir os valores da segunda `list` atrás (_à direita_) do ID da locomotiva (**1**).
A função deve então `return` uma `list` com as modificações.

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Adicione as paradas que faltam

Agora que todos os dados dos vagões estão corretos, Linus gostaria que você atualizasse as informações de roteamento do sistema.
Ao longo de uma rota de transporte, um trem pode fazer paradas em algumas estações diferentes para pegar e/ou deixar carga.
Cada viagem pode ter um número diferente desses pontos de entrega intermediários.
Seu amigo gostaria que você atualizasse o `dict` de roteamento do sistema com qualquer informação de entrega que esteja faltando ou que seja adicional.

Implemente uma função `add_missing_stops()` que aceita um `dict` de roteamento seguido de um número variável de argumentos nomeados.
Esses argumentos podem estar na forma de um `dict` contendo uma ou mais paradas, ou de qualquer número de pares nomeados `stop_number=city`.
Sua função deve então retornar o `dict` de roteamento atualizado com uma `key` adicional que contém uma `list` de todas as paradas adicionadas, na ordem.

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. Amplie as informações de roteamento

Linus vem trabalhando no programa de roteamento e percebeu que certas rotas estão sem alguns detalhes importantes.
As informações iniciais da rota foram montadas como um `dict` e seu amigo gostaria que você atualizasse esse `dict` com o que estiver faltando.
Cada rota do sistema exige detalhes um pouco diferentes, então Linus preferiria muito uma solução genérica.

Implemente uma função chamada `extend_route_information()` que aceita dois `dicts`.
O primeiro `dict` contém as cidades de origem e destino entre as quais o trem circula.

O segundo `dict` contém outros detalhes de roteamento, como velocidade, comprimento ou temperatura do trem.
A função deve retornar um `dict` consolidado com todas as informações de roteamento.

~~~~exercism/note
O segundo `dict` pode conter propriedades diferentes ou em maior número do que as mostradas no exemplo.
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. Corrija o depósito de vagões

Quando Linus estava inspecionando o depósito de vagões, ele notou que os vagões não estavam sendo armazenados na ordem correta.
Além de um ID, cada vagão tem uma cor que corresponde ao tipo de carga que transporta.
Os vagões são armazenados no depósito em grades, onde cada coluna da grade tem vagões da mesma cor.

No entanto, o sistema de logística mostra que as `lists` de vagões a serem armazenados no depósito têm as suas _linhas_ agrupadas por cor.
Mas, para que a grade de armazenamento funcione corretamente, cada _linha_ deve ter três cores diferentes, para que as _colunas_ se alinhem por cor.
Seu amigo gostaria que você organizasse as `lists` do depósito de vagões, para que os vagões sejam armazenados corretamente.

Implemente uma função chamada `fix_wagon_depot()` que aceita uma `list` de três itens.
Cada item da `list` é uma sublista (ou "linha") que contém três `tuples`.
Cada `tuple` é um par `(<wagon ID>, <wagon color>)`.

Sua função deve retornar uma `list` com as três `lists` "linha" reordenadas para que os vagões sejam colocados nas posições corretas.

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
