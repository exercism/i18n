# Resolvendo exercícios localmente

Resolver exercícios na sua máquina local permite que você escreva todo o código em um ambiente que já conhece.

## Instalando a CLI

Para resolver um exercício na sua máquina local, primeiro você precisa instalar e configurar a interface de linha de comando do Exercism seguindo [estas instruções](https://exercism.org/cli-walkthrough).

### Configuração

Você precisa informar à CLI quem você é para que possamos baixar as coisas corretamente.
Você encontra seu token na sua [página de configurações](/settings/api_cli).
Depois, você pode configurar a CLI com o comando a seguir, substituindo `<your-api-token>` pelo valor da página de configurações:

```
exercism configure --token=<your-api-token>
```

## Baixando o exercício

Depois de instalada, você pode usar a CLI para baixar o exercício para a sua máquina local com o comando a seguir (substituindo `<exercise-slug>` e `<track-slug>` pelos valores correspondentes:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

Você não precisa decorar essa estrutura de comando, pois a página do exercício lista o comando apropriado para ele.

Quando o comando de download terminar, os arquivos do exercício serão baixados para a sua máquina local.

## Resolvendo o exercício

O objetivo de cada exercício é criar uma implementação que passe em todos os testes.
Essa implementação é chamada de _solução_.

Para ajudar você nisso, cada exercício contém os seguintes arquivos:

- README.md: as instruções que explicam o que se espera de você
- HELP.md: informações sobre como rodar os testes e como conseguir ajuda quando você travar
- HINTS.md (opcional): dicas para ajudar a resolver o exercício
- Arquivo(s) de teste: contêm os testes que verificam se a sua solução está correta
- Arquivo(s) stub: fornecem um ponto de partida para ajudar você a começar a construir a sua implementação

Dependendo da trilha, pode haver outros arquivos que as ferramentas da trilha exigem para que os testes rodem.

## Enviando sua solução

Quando a sua solução passar em todos os testes, você pode enviá-la com o comando a seguir:

```
exercism submit <implementation_file_paths>
```

Esse comando envia a sua solução para o site do Exercism e imprime a URL da página da solução.

Mais uma vez, você não precisa decorar esse comando, pois o arquivo `HELP.md` do exercício lista o comando correto.

É possível enviar uma solução incompleta, o que permite que você:

- Veja como outras pessoas resolveram o exercício
- Peça ajuda a um mentor

## Outras funcionalidades da CLI

### Vendo todos os comandos

Rode o subcomando help para ver a lista completa de comandos disponíveis.

```bash
exercism help
```

### Solução de problemas

Verifique se você está na versão mais recente.

Confira qual versão você está usando:

```bash
exercism version
```

Verifique se há uma versão mais recente e atualize caso a sua não seja a mais nova.

Depois de atualizar, confira a versão novamente. Se a versão não mudou, verifique se você está executando o binário atualizado.

```bash
which exercism
```

Se você ainda estiver com problemas, abra uma issue em exercism/cli no GitHub com a saída do comando troubleshoot.

```bash
exercism troubleshoot
```

Você pode abrir issues no [nosso rastreador de issues](https://github.com/exercism/exercism/issues) e a comunidade vai tentar ajudar você. **Certifique-se de ter feito o [Passo a Passo Interativo](https://exercism.org/cli-walkthrough) antes de abrir qualquer issue.**
