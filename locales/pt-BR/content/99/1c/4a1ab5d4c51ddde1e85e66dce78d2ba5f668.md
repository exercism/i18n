# Sobre

As bibliotecas de classes base do .NET fornecem a classe [`Regex`][regex] para processar expressões regulares.

Veja este [artigo][regex-comparison] para uma comparação do C# com outros sabores de expressões regulares.

## Grupos de captura

Um aspecto a considerar é o dos grupos de captura, que retornam partes do texto que correspondem a várias partes do padrão da expressão regular. A abordagem dos grupos de captura exige um tempo para se acostumar. Veja esta [documentação][capture].

Repare que existe uma hierarquia quando grupos de captura, `(?<capture-name>pattern)`, estão envolvidos:

- um conjunto de zero ou mais correspondências é retornado (uma para cada correspondência encontrada no texto).
- Cada correspondência contém um número de grupos de captura
- Cada grupo contém um número de capturas.

Além disso:

- `Match` deriva de `Group`
- `Group` deriva de `Capture`

Ressalvas:

- A abordagem mais segura é usar capturas nomeadas.
- Os grupos de captura geralmente aparecem na coleção `Groups` na mesma ordem em que aparecem no texto.
- `Groups[0]` parece se referir à correspondência inteira.
- `Groups[<capture name>].Value` é quase certamente o que você procura. As capturas individuais (exceto `Caputures[0]`) parecem destinadas a fins de diagnóstico, quando existem.

## Opções de regex

Familiarize-se com [`RegexOptions`][regex-options].

Além das opções `IgnoreCase` de sempre, existem as de `MultiLine`, útil para processar várias linhas de texto de uma vez, e `IgnorePatternWhitespace` que, combinada com strings verbatim, interpolação de strings e comentários, pode ser muito expressiva, como mostra este exemplo:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

Outra opção interessante é `RegexOptions.Compiled` para regexes [compiladas][regex-compilation].
