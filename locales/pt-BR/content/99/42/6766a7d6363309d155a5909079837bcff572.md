# Complemento das instruções

## Dica

Uma função com um *tipo de retorno* só pode retornar dados desse *tipo* e `null`. No entanto, quem chama a função espera apenas um tipo de dados.

Exemplo:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
Para deixar mais claro que essa função também pode retornar `null` ou mais tipos de dados, use `dynamic`.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
