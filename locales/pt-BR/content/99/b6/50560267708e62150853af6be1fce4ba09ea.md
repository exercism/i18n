# Instalação

Use o binário `full` da sua plataforma, disponível na [página oficial de releases][official-releases].
No momento, a trilha é voltada para a versão Arturo 0.10.0, Arizona Bark.

~~~~exercism/caution
O Homebrew é um método popular de terceiros para instalar programas no macOS e no Linux.
No entanto, a receita dele para o Arturo usa a build `mini`, que é incompatível com esta trilha.
~~~~

Se precisar de mais ajuda para instalar o Arturo, consulte o [Discord oficial do Arturo][discord].

## Executando código Arturo

Com isso, você já pode começar a escrever código Arturo!
Para acessar o REPL do Arturo, rode `arturo` na linha de comando.
Para executar um script Arturo, rode `arturo <file>` na linha de comando.

[official-releases]: https://arturo-lang.io/#download
