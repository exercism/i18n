# Sobre

O JavaScript é uma linguagem de programação que permite que as páginas web sejam dinâmicas. É uma linguagem interpretada, o que significa que não precisa ser compilada: em vez disso, o intérprete (como um navegador web) analisa o código e o transforma em código que a máquina consegue rodar. Isso é ideal para criar sites dinâmicos que funcionam em qualquer navegador _em qualquer computador_!

O JavaScript não é usado apenas no navegador. Ambientes de execução de JavaScript, como o [Node.js][web-nodejs] e o [Deno][web-deno], permitem que você escreva, inicie e atenda requisições em servidores web.
Outros frameworks, como o [Electron][web-electron], usam JavaScript para escrever _aplicativos multiplataforma_ para Windows, Linux e macOS.
O desenvolvimento de aplicativos móveis também é uma possibilidade, usando [React Native][web-react-native], [Ionic][web-ionic] e vários outros, com o [Expo][web-expo] agora permitindo atingir Android, iOS e a web, tudo de uma vez.

O ECMAScript é o [padrão][web-ecma] que define o JavaScript.

> "O ECMAScript se tornou uma das linguagens de programação de uso geral mais amplamente utilizadas do mundo.
> Ela é mais conhecida como a linguagem embutida nos navegadores web, mas também foi amplamente adotada para aplicações de servidor e embarcadas."
> [Especificação da Linguagem da ECMA International][web-ecma-2019]

A partir da 6ª edição (conhecida como ES2015 ou ES6), em 2015, uma nova edição do padrão passou a ser lançada a cada ano.
A 6ª edição foi uma atualização importante que trouxe muitas melhorias em relação ao ES5, incluindo, notavelmente, template strings, uma sintaxe expressiva de arrow functions e uma sintaxe mais limpa para definir classes.

Mas como novas sintaxes e recursos chegam ao JavaScript _a cada ano_, o suporte a essas mudanças costuma ser incompleto nos [navegadores atuais][web-compat-browsers] e no [Node.js mais recente][web-compat-node].
Isso não significa que não podemos usá-los.
Ferramentas como o [Babel][web-babel] oferecem [transpilação][wiki-transpilation] para a maioria dos recursos, permitindo que a gente _escreva_ como se já estivéssemos no futuro.

**Nota**: Esta trilha oferece suporte à sintaxe ECMAScript mais recente por meio do Babel e do plugin [@babel/preset-env][web-babel-preset-env], e novos recursos experimentais são habilitados a cada atualização desse plugin, acompanhando o lançamento das especificações.
Ele se adapta automaticamente à instalação do Node.js _da sua máquina_.
Isso significa que você não precisa se preocupar com o que tem e o que não tem suporte.
