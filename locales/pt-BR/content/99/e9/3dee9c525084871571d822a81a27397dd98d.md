# Instruções

Um pirata está traçando uma rota por um mapa de enseadas escondidas.
O mapa é uma tabela hash com chave no nome da enseada; cada valor é um
array das enseadas que você consegue alcançar diretamente a partir daquela.

## 1. Esvazie a fila da maré

Defina `tide-queue` para receber um array de itens, inserir cada um em um
deque novo (na ordem) e depois remover todos, de volta para um array
que preserva a ordem original. Essa é a forma FIFO:
insira no fim, remova do começo.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. Enseadas alcançáveis

Defina `coves-reachable` para receber uma enseada inicial e um mapa,
e retornar um hash-set de todas as enseadas alcançáveis a partir de `start`,
incluindo o próprio `start`.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

Use uma `<dlist>` como fronteira da BFS e um `HS{ }` para o
conjunto de visitados.

## 3. Contagem de saltos

Defina `hop-count` para receber uma enseada inicial, uma enseada de
destino e um mapa, e retornar o número mínimo de saltos entre elas, ou
`f` se o destino não for alcançável.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

Carregue cada enseada junto com sua distância desde o início no
deque (um array de 2 elementos funciona).

## 4. Contagem de ouro

O stub declara `gold-count` com `:`. Mude para `MEMO:`
(não `:`) para que o resultado de cada enseada seja calculado uma vez e
armazenado em cache. Procure o ouro da enseada na constante
`gold-distribution` que o exercício fornece.
Uma enseada que não está na distribuição tem zero de ouro.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. Rota do tesouro

Defina `treasure-route` para receber uma enseada inicial e um mapa, e
retornar a enseada alcançável com mais ouro. Use
`coves-reachable` da tarefa 2 e `gold-count` da tarefa 4.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

O `gold-count` memoizado mantém as consultas repetidas gratuitas, o que é
útil quando várias partes do algoritmo consultam a mesma enseada.
