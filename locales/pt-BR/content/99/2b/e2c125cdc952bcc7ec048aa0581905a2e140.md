# Introdução

**Closures** são um padrão de programação [no Clojure][clojure-guide-closures] que permite usar variáveis de um [escopo léxico][wiki-lexical-scope] externo dentro de uma função. O Clojure dá suporte a closures de forma transparente, e eles costumam ser usados sem que se saiba o que são.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Closures para guardar estado e passar valores adiante

Usar um atom permite preservar um pouco de estado:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Cada chamada sucessiva a `increment` incrementa o contador:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
