# Instalando o Kotlin

Além da CLI do Exercism e do seu editor de texto favorito, praticar os exercícios de Kotlin do Exercism exige:

* o **Java Development Kit** (JDK): o Kotlin compila para bytecodes Java, então você precisa instalar o JDK, que inclui tanto um Java Runtime *quanto* ferramentas de desenvolvimento (principalmente o compilador Java); e
* o **Gradle**: uma ferramenta de build específica para projetos baseados na JVM, com suporte a Kotlin.

Escolha o seu sistema operacional:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... ou ...
* se você preferir não usar um gerenciador de pacotes, você pode [instalar manualmente](#h-install-manually).

Opcionalmente, você também pode usar uma [IDE Java](#h-java-ides).

----

## Windows

Abra um prompt de comando como administrador.  (Se precisar de ajuda para abrir um prompt administrativo, veja [abrir um prompt elevado no Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (ou [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Se você ainda não instalou o Chocolatey, faça isso agora:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Instale o JDK:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

Recomendamos fechar o prompt de comando administrativo e abrir um novo prompt de comando. Você não precisa de privilégios de administrador para praticar os exercícios do Exercism.

Agora você já pode começar com a trilha de Kotlin do Exercism!

Para começar, veja "[Executando os testes](https://exercism.org/docs/tracks/kotlin/tests)".

## macOS

Abaixo estão as instruções para instalar usando o método mais comum, com o Homebrew.  Se você preferir, também pode [instalar no macOS sem o Homebrew](#h-installing-on-macos-without-homebrew).

### Instalação

1. Se você ainda não instalou o [Homebrew](http://brew.sh), faça isso agora:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Faça o tap do [Homebrew Cask](https://caskroom.github.io/): isso permite instalar binários pré-compilados, como o JDK.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Instale o JDK:

       ```
        $ brew install --cask adoptopenjdk11
       ```

Agora você já pode começar com a trilha de Kotlin do Exercism!

Para começar, veja "[Executando os testes](https://exercism.org/docs/tracks/kotlin/tests)".

## Linux

Abaixo estão as instruções para instalar usando o gerenciador de pacotes da sua distribuição.  Se você preferir, também pode [instalar no Linux sem um gerenciador de pacotes](#h-installing-on-linux-without-a-package-manager).

* [Debian](#h-debian)
* [Outras distribuições Linux](#h-other-linux-distributions)

### Debian

Se você usa Debian ou derivados (como Ubuntu ou Linux Mint), use o APT:

*(verificado em: Ubuntu 14, 16 e 18)*

1. Instale o JDK:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


Agora você já pode começar com a trilha de Kotlin do Exercism!

Para começar, veja "[Executando os testes](https://exercism.org/docs/tracks/kotlin/tests)".

### Outras distribuições Linux

Existem muitas formas de instalar o JDK 11, mas uma das mais fáceis é usar o SDKMAN, 
que permite instalar o OpenJDK 11 sem complicação. Siga os passos abaixo:

1. Instale o SDKMAN:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (se isso não funcionar, dê uma olhada nas instruções que estão aqui: https://sdkman.io/install )
1. Instale o openjdk11:
    ```
    $ sdk install java 11.0.2-open
    ``` 

Agora você já pode começar com a trilha de Kotlin do Exercism!

Para começar, veja "[Executando os testes](https://exercism.org/docs/tracks/kotlin/tests)".

### Instalar no Windows manualmente

*OBSERVAÇÃO: estas instruções são destinadas a usuários experientes do Windows.  Se você ainda não sabe como definir variáveis de ambiente ou não se sente à vontade para gerenciar a estrutura de diretórios, recomendamos fortemente que use a instalação baseada no Chocolatey, [acima](#h-windows).*

1. Instale o JDK:
   1. Baixe o "**OpenJDK 11 (LTS)**" em [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) (escolha **"Install JDK"**).
   -  Execute o instalador, aceitando todos os padrões.

Agora você já pode começar com a trilha de Kotlin do Exercism!

Para começar, veja "[Executando os testes](https://exercism.org/docs/tracks/kotlin/tests)".

## IDEs Java

Existem muitas IDEs Java disponíveis.  As três mais populares são:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (baixe a edição "Community")
  - feita pelos autores do Kotlin, esta IDE oferece o melhor suporte para a linguagem.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) (baixe o pacote "Java SE")

e existem [outras](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs).
