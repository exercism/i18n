# Introdução

Inicializadores são métodos especiais usados para criar um valor do enum. A definição deles se parece muito com a de um método, só que não há a palavra-chave `func`, não há tipo de retorno, o nome precisa ser `init` e o inicializador _precisa_ atribuir um valor do enum a `self`. Os inicializadores são chamados pela notação de ponto ou passando os parâmetros do inicializador para o nome do enum.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```
