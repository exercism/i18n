# Introdução

A interpolação de strings é suportada no Haxe ao envolver uma string com aspas simples (`'`) e usar o cifrão (`$`) para acionar a interpolação.

Também é possível incluir expressões inteiras usando `${expr}`, em que `expr` é qualquer expressão válida do Haxe.

```haxe
var x = 10;
trace('They have $x apples, of which ${x - 4} are red.');
// They have 10 apples of which 6 are red.
```
