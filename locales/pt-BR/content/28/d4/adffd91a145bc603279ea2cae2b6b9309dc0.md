# Apêndice das instruções

## Mensagens de exceção

Às vezes é necessário [lançar exceções][raising-exceptions].
Quando você faz isso, deve sempre incluir uma **mensagem de erro significativa** para indicar qual é a origem do erro.
Isso deixa seu código mais legível e ajuda bastante na depuração.
Nas situações em que você sabe que a origem do erro é de um determinado tipo, você pode optar por lançar um dos [tipos de erro embutidos][error-base-classes], mas ainda deve incluir uma mensagem significativa.


Uma partida válida de `Tic Tac Toe` termina quando um dos jogadores vence.
Se os dois jogadores estiverem em estado de vitória, este exercício espera que você use a [instrução raise][raise] e "lance" um `ValueError` na sua solução.
Espera-se também que seu código lance um `ValueError` se for identificado que um jogador jogou duas vezes seguidas, ou se jogou a primeira jogada quando deveria jogar a segunda.


Para lançar um `ValueError` com uma mensagem, escreva a mensagem como argumento do tipo `exception`:

```python
# Example when player O goes before player X.
raise ValueError("Wrong turn order: O started")

# Example when player X goes twice.
raise ValueError("Wrong turn order: X went twice")

# Example when player X wins AND player O wins.
raise ValueError("Impossible board: game should have ended after the game was won")
```

Os testes vão verificar uma correspondência exata da mensagem de erro, então leia os resultados esperados com atenção.
