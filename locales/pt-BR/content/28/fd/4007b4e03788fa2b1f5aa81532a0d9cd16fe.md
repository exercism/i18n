# Instruções

Neste exercício, você está jogando um jogo de interpretação de papéis chamado "Wizards and Warriors". Para jogar, você precisa de um método de rolagem de dado para uso geral, que determine vários resultados. Este será o tradicional dado de 18 lados, com números de 1 a 18. Os jogadores também vão precisar gerar uma força de feitiço aleatória.

## 1. Permita que um jogador de _Wizards and Warriors_ role um dado

Implemente um método `RollDie()` na classe `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Os jogadores precisam da própria força. Ofereça uma forma de gerar a força de feitiço

Implemente um método `GenerateSpellStrength()` na classe do jogador.
A força de feitiço fica entre 0.0 e 100.0, sem incluir o 100.0.

Repare que a força de feitiço precisa ser um número de ponto flutuante (não um número inteiro) para reduzir a possibilidade de empate quando as forças de dois adversários forem comparadas.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
