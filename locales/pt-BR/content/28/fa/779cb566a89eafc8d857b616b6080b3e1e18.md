# Introdução

No Ruby, os **arrays** são coleções ordenadas, indexadas por inteiros, de qualquer objeto.
A indexação de arrays começa em `0`.
Um índice negativo é considerado relativo ao fim do array (ou seja, um índice `-1` indica o último elemento do array, `-2` é o penúltimo elemento do array, e assim por diante).
Os arrays do Ruby incorporam o [módulo Enumerable][enumerable-module], que adiciona vários métodos de travessia e busca, além da capacidade de ordenar.

## Criar um array

- Um array em Ruby pode conter objetos de tipos diferentes.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Atribuição de elementos

É possível acessar ou alterar elementos usando índices.
Também é possível acessar subarrays especificando um índice inicial e um tamanho.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- Índices negativos contam de trás para frente a partir do fim do array.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Referência a elementos

- É possível recuperar elementos de um array com o método `#[]`.
- Ele retorna o elemento no índice indicado ou um subarray que começa no índice inicial e segue por um número de elementos.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- Índices negativos contam de trás para frente a partir do fim do array (-1 é o último elemento)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Obter informações sobre um array

Os arrays acompanham o próprio tamanho o tempo todo.
Para consultar quantos elementos um array contém, use length, count ou size.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Adicionar itens a um array

É possível adicionar itens ao fim de um array usando `push` ou `<<`:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Remover itens de um array

O método pop remove o último elemento de um array e o retorna:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
