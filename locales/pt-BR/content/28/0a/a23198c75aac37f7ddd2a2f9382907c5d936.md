# Depuração

Ao contrário de muitas linguagens, o código WebAssembly não tem acesso automático a recursos globais como o console. Esse tipo de funcionalidade precisa ser fornecida por meio de importações.

Para oferecer uma funcionalidade parecida com `console.log` e algumas outras facilidades, a trilha WebAssembly do Exercism disponibiliza uma biblioteca padrão de funções em todos os exercícios.

Essas funções precisam ser importadas no topo do seu módulo WebAssembly e depois podem ser chamadas de dentro do seu código WebAssembly.

As funções `log_mem_*` precisam conseguir acessar a memória linear do seu módulo WebAssembly. Por padrão, esse é um estado privado, então, para deixá-la acessível, você precisa exportar sua memória linear com o nome de exportação `mem`. Isso é feito assim:

```wasm
(memory (export "mem") 1)
```

# Registrar variáveis locais e globais

Fornecemos funções de registro para cada um dos tipos primitivos do WebAssembly. Isso é útil para registrar variáveis globais e locais.

## log_i32_s - Registra um inteiro de 32 bits com sinal no console

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```

# Registrar a partir da memória linear

A Memória Linear do WebAssembly é um array de valores endereçável por byte. Ela funciona como o equivalente da memória virtual para programas WebAssembly

Fornecemos funções de registro para interpretar um intervalo de endereços dentro da memória linear como arrays estáticos de determinados tipos. Isso funciona de forma parecida com os TypedArrays do JavaScript. Os parâmetros de comprimento não são medidos em bytes. Eles são medidos no número de elementos consecutivos do tipo associado à função.

**Para que essas funções funcionem, seu módulo WebAssembly precisa declarar e exportar sua memória linear usando a exportação nomeada "mem"**

```wasm
(memory (export "mem") 1)
```

## log_mem_as_utf8 - Registra uma sequência de caracteres UTF8 no console

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

## log_mem_as_i8 - Registra uma sequência de inteiros de 8 bits com sinal no console

```wasm
(module
  (import "console" "log_mem_as_i8" (func $log_mem_as_i8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (func $main
    (memory.fill (i32.const 128) (i32.const -42) (i32.const 10))
    ;; Logs an array of 10x -42 to console
    (call $log_mem_as_u8 (i32.const 128) (i32.const 10))
  )
)
```
