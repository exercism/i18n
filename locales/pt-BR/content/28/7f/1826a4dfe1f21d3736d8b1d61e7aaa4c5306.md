# Sobre

Em Kotlin, os Boolean são representados pelo tipo `Boolean`, cujos valores podem ser `true` ou `false`.

Kotlin tem três [operadores booleanos][reference] embutidos: `!` (negação, também conhecida como NOT), `&&` (conjunção preguiçosa, também conhecida como AND) e `||` (disjunção preguiçosa, também conhecida como OR). Os operadores `&&` e `||` usam _avaliação de curto-circuito_, o que significa que o lado direito do operador só é avaliado quando necessário.

```kotlin
true || false // => true
true && false // => false
```

Cada um dos três operadores booleanos tem uma [_precedência de operadores_][precedence] diferente. Por isso, eles são avaliados nesta ordem: `!` primeiro, `&&` depois e, por fim, `||`. Se você quiser "escapar" dessas regras, pode colocar uma expressão booleana entre parênteses (`()`), já que os parênteses têm uma precedência ainda maior.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
