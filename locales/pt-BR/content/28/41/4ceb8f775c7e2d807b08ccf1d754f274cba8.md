# Apêndice das instruções

## Mensagens de exceção

Às vezes é necessário [levantar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você fizer isso, inclua sempre uma **mensagem de erro significativa** que indique qual é a origem do erro. Isso deixa o seu código mais legível e ajuda muito na depuração. Em situações em que você sabe que a origem do erro será de um determinado tipo, você pode optar por levantar um dos [tipos de erro embutidos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda assim deve incluir uma mensagem significativa.

Este exercício em particular exige que você use a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um `ValueError`. Os testes só vão passar se você usar `raise` na `exception` e incluir uma mensagem junto com ela.

Para levantar um `ValueError` com uma mensagem, escreva a mensagem como argumento do tipo `exception`:

```python
raise ValueError("A meaningful error message here.")
```
