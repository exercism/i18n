# Anexo às instruções

## Registradores

| Registrador | Uso       | Tipo    | Descrição                          |
| ----------- | --------- | ------- | ---------------------------------- |
| `$a0`       | entrada   | endereço | cor como string terminada em nulo |
| `$v0`       | saída     | inteiro | valor do resistor                  |
| `$t0-9`     | temporário | qualquer | para armazenamento temporário      |
