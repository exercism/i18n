# Sobre

PureScript é uma linguagem de programação puramente funcional e com tipagem estática, com inferência de tipos global.

**Funcional** significa que as funções são valores de primeira classe.
As funções são uma ferramenta importante e poderosa de abstração.
Em PureScript, a computação é modelada como a avaliação de expressões formadas por aplicações de funções, e não como a execução de uma sequência de instruções.

**Puramente funcional** significa que é possível dizer se uma computação tem efeitos colaterais ou não. Ou seja, se uma computação altera uma variável global, lê uma entrada, escreve em um socket etc., isso vai se refletir no tipo da computação.

**Com tipagem estática** significa que toda computação tem um tipo conhecido antes da execução do programa.

**Inferência de tipos global** significa que o compilador consegue descobrir o tipo das computações do programa inteiro sem que o programador precise especificar o tipo.
