# Introdução

## O operador ternário

Uma condicional ternária é uma forma mais curta de escrever instruções `if/else` simples.
Se uma instrução `if/else` contiver apenas dois blocos, um para quando a condição for verdadeira e outro para quando for falsa, ela pode ser reescrita como uma condicional ternária.

As ternárias usam uma combinação dos símbolos `?` e `:` para dividir uma condicional:

```ruby
condition ? true_branch : false_branch
```

O código do lado esquerdo do `?` é a condição, e o código do lado direito contém os dois blocos possíveis, separados pelo `:`.
Se a condição for _verdadeira_, o código do lado _esquerdo_ do `:` é executado.
Se a condição for _falsa_, o código à _direita_ do `:` é executado.

Por exemplo:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

pode ser reescrito como:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
