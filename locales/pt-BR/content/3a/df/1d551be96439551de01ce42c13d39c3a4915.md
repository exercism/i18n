# Instruções

Sua tarefa é criar um programa que implemente o algoritmo do Crivo de Eratóstenes para encontrar números primos.

Um número primo é um número que só é divisível por 1 e por ele mesmo.
Por exemplo, 2, 3, 5, 7, 11 e 13 são números primos.

O Crivo de Eratóstenes é um algoritmo antigo que funciona assim: pegamos uma lista de números e riscamos todos os números que não são primos.

Um número que **não** é primo é chamado de "número composto".

Para usar o Crivo de Eratóstenes, primeiro você cria uma lista de todos os números entre 2 e o número escolhido.
Depois, você repete os seguintes passos:

1. Encontre o próximo número não marcado da sua lista. Esse número é primo.
2. Marque todos os múltiplos desse número primo como compostos (não primos).

Você continua repetindo esses passos até percorrer todos os números da sua lista.
No final, todos os números não marcados são primos.
