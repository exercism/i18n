# Mestre de jogo de um RPG

## História

Neste exercício, você está jogando um RPG chamado "Magos e Guerreiros" com seus melhores amigos. Você é o mestre de jogo, a pessoa responsável por dar vida ao mundo do jogo para os outros jogadores. Um aspecto fundamental disso é descrever o jogo para os jogadores: qual é o status de um personagem, como é a cidade que eles estão visitando, etc.

## Tarefas

Estas são tarefas de exemplo que se encaixam no exercício de mestre de jogo:

- Descrever um personagem
- Descrever um destino
- Descrever um método de viagem
- Descrever uma combinação de personagem/destino/método de viagem
- Descrever uma combinação de personagem/destino com um método
