# Introdução

Bombas, válvulas, mangueiras: tudo que ocupa um recurso do sistema operacional (um arquivo aberto, uma conexão de rede) precisa ser *liberado* quando você termina de usá-lo. O vocabulário [`destructors`][destructors] do Factor envolve tudo isso num framework que garante a limpeza, mesmo quando um erro interrompe seu código no meio.

## A classe e o genérico

Uma classe entra no framework estendendo `disposable` e implementando o genérico `dispose*`:

```factor
USING: accessors destructors kernel ;

TUPLE: pump < disposable opened ;

: <pump> ( -- pump )
    pump new-disposable t >>opened ;

M: pump dispose* f >>opened drop ;
```

`new-disposable ( class -- obj )` aloca a tupla *e* a registra no framework: uma exceção entre a alocação e o próximo ponto seguro não pode vazar o recurso. O framework garante que `dispose*` roda **no máximo uma vez** por objeto, então chamadas repetidas de `dispose` não têm efeito.

## Quem chama de fora usa `dispose`

```
dispose          ( obj -- )                ! release; safe to call twice
with-disposal    ( disposable quot -- )    ! scope one resource
with-destructors ( quot -- )               ! open a registry scope
&dispose         ( obj -- obj )            ! dispose on normal *or* failure exit
|dispose         ( obj -- obj )            ! dispose only if the scope unwinds
```

`with-disposal` é a forma para um único recurso: ela empilha o disposable para a quotation interna e o libera na saída.

```factor
USING: destructors io ;

<pump> [
    "pumping" print
] with-disposal
! pump released on the way out — even if `print` had thrown
```

Para mais de um recurso, abra um escopo `with-destructors` e registre cada aquisição. `&dispose` (e comercial) quer dizer "sempre libere na saída, com sucesso ou com falha". `|dispose` (barra vertical) quer dizer "libere **apenas** em caso de falha", o que é útil quando o caminho de sucesso passa o recurso para quem chamou e vai assumir a posse dele.

```factor
[
    <pump> &dispose
    <pump> &dispose
    ! ... use the pumps ...
] with-destructors
! both pumps released
```

Para um try/finally puro, sem registro, [`cleanup`][cleanup] (em `continuations`) é a primitiva de nível mais baixo, mas o `with-destructors` é a forma idiomática e moderna no Factor.
