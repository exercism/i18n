# Dicas

## Geral

- Não se preocupe em como os argumentos são obtidos; concentre-se apenas em combiná-los para retornar o resultado esperado.

## 1. Defina se o pac-man pode comer um fantasma

- A função deve retornar um valor [bool][bool].
- Você pode usar o operador [bool][bool] `&&` para combinar os argumentos e obter um resultado.

## 2. Defina se o pac-man pontua

- A função deve retornar um valor [bool][bool].
- Você pode usar o operador [bool][bool] `||` para combinar os argumentos e obter um resultado.

## 3. Defina se o pac-man perde

- A função deve retornar um valor [bool][bool].
- Você pode usar os operadores [bool][bool] `&&` e `!` para combinar os argumentos e obter um resultado.

## 4. Defina se o pac-man vence

- A função deve retornar um valor [bool][bool].
- Você pode usar os operadores [bool][bool] `&&` e `!` para combinar os argumentos e os resultados de uma das funções implementadas anteriormente.

[bool]: https://gleam.run/book/tour/bools.html
