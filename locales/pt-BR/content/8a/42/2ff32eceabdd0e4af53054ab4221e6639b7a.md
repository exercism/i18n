# Testes

Cada exercício contém um arquivo de teste.
Execute os testes usando o programa `bats`.

```bash
bats hello_world.bats
```

Se você precisar imprimir saída de depuração ao rodar os testes localmente, veja [Depuração local][debugging].

O `bats` precisará ser instalado.
Veja a página [Testes na trilha do Bash][tests] para instruções de como instalar o `bats` no seu sistema.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Testes ignorados

Resolver um exercício significa fazer todos os seus testes passarem.
Por padrão, apenas um teste (o primeiro) é executado quando você roda os testes.
Isso é intencional, pois permite que você se concentre apenas em fazer esse único teste passar.
Quando ele passar, você pode habilitar o próximo teste comentando ou removendo a próxima anotação:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Sobrescrevendo skips

Para rodar todos os testes, incluindo aqueles com anotações `skip`, você pode executar:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Pode ser conveniente usar uma função wrapper para economizar digitação:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Depois, é só rodar os testes com:

```bash
bats
```
