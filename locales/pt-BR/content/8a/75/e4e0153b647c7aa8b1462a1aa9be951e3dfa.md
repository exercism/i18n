# Sobre

As condicionais de Factor recebem todas **quotations** como blocos: código escrito entre colchetes, `[ ... ]`, que é empilhado como um valor em vez de ser executado até que a condicional o selecione. (As quotations em si são abordadas por completo em um exercício mais adiante.)

As três básicas estão em `kernel`:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

Duas variantes com asterisco tratam o Boolean como um valor que vale a pena usar quando ele é truthy: o par canônico "valor-ou-`f`":

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

Para mais de dois blocos, `cond` (em `combinators`) percorre um array de pares `{ predicate body }` e executa o corpo do primeiro predicado que disparar. O padrão convencional usa `dup` em cada predicado para que o valor de entrada sobreviva, e o corpo começa com um `drop` para descartá-lo antes de empilhar o resultado:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

Uma entrada final sem predicado é o bloco padrão.
