# Sobre

O Dart combina programação orientada a objetos e tipagem estática com a flexibilidade de linguagens dinâmicas como JavaScript.
Criado para simplificar tarefas comuns de programação, o Dart ganhou popularidade rapidamente na comunidade de desenvolvimento de software, principalmente pela sua integração estreita com o [Flutter](https://flutter.dev), um framework amplamente usado para desenvolvimento multiplataforma.

## Conceitos-chave do Dart

- **Simples e familiar:** o Dart é fácil de aprender para quem já conhece linguagens como Java, JavaScript ou C#.
  Ele tem uma sintaxe limpa e consistente, o que o torna acessível.
- **Linguagem orientada a objetos moderna:** o Dart incorpora princípios modernos de orientação a objetos e oferece suporte robusto a classes, herança e interfaces.
- **Tipagem forte com flexibilidade:** embora seja uma linguagem de tipagem estática, o Dart oferece inferência de tipos flexível e recursos dinâmicos, o que dá aos desenvolvedores o melhor dos dois mundos.
- **Programação assíncrona sem complicação:** as palavras-chave `async` e `await` do Dart simplificam a concorrência.
  O modelo orientado a eventos, construído em torno de **isolates** (estruturas leves semelhantes a threads), permite uma execução assíncrona eficiente sem a complexidade do trabalho com threads.
- **Ferramentas e bibliotecas abrangentes:** o Dart oferece bibliotecas integradas completas, e seu ecossistema é reforçado pelo [Pub.dev](https://pub.dev), um gerenciador de pacotes que disponibiliza uma ampla variedade de bibliotecas e ferramentas de código aberto.
- **Desenvolvimento multiplataforma:** o Dart é a base do [Flutter](https://flutter.dev), um dos frameworks mais populares para criar aplicativos multiplataforma de alto desempenho para celular, web e desktop a partir de um único código-fonte.
- **Suporte para web:** o código Dart pode ser transpilado para JavaScript, o que o torna adequado tanto para o desenvolvimento web do lado do cliente quanto do lado do servidor.
  Frameworks como o [AngularDart](https://github.com/angulardart-community) (anteriormente [https://github.com/angulardart](https://github.com/angulardart)) são feitos especificamente para aplicativos web em Dart.
- **Recursos do lado do servidor:** o Dart não serve apenas para o desenvolvimento frontend; também pode ser usado para criar aplicações escaláveis do lado do servidor com frameworks como o [Shelf](https://pub.dev/packages/shelf).
- **Alto desempenho:** o código Dart é compilado para código de máquina nativo em aplicativos para celular e desktop e para JavaScript otimizado na web, entregando alto desempenho em todas as plataformas.

## Versatilidade do Dart

- **Aplicativos para celular:** o uso mais destacado do Dart está no desenvolvimento de aplicativos para celular por meio do Flutter, o que permite uma interface de usuário consistente e a mesma lógica de negócios no iOS e no Android.
- **Desenvolvimento web:** o Dart pode ser compilado para JavaScript para criar aplicações web modernas, seja por meio de frameworks nativos do Dart, seja pelo Flutter para web.
- **Desenvolvimento para desktop:** com o Flutter, o Dart agora permite criar aplicações nativas para Windows, macOS e Linux, oferecendo capacidades realmente multiplataforma.
- **Serviços de back-end:** o Dart é cada vez mais usado em serviços de back-end graças à sua sintaxe concisa e às suas otimizações de desempenho.
  Ele consegue lidar com APIs RESTful, microsserviços e muito mais.
- **Integração com o Firebase e a nuvem:** o Dart tem suporte robusto para integração com o Firebase e outros serviços de nuvem por meio de bibliotecas oficiais, o que o torna uma escolha preferida para aplicativos conectados à nuvem.

## Melhorias recentes

- **Segurança contra nulos:** o Dart introduziu a **sound null safety**, que ajuda a eliminar erros de referência nula ao garantir que os tipos não anuláveis sejam usados corretamente durante o desenvolvimento.
- **Compilação mais rápida:** o Dart avançou bastante na melhoria do seu pipeline de compilação, oferecendo compilação **ahead-of-time (AOT)** e **just-in-time (JIT)**, o que garante ciclos de desenvolvimento rápidos e builds de lançamento otimizados.
- **Desktop e dispositivos embarcados:** a expansão do Flutter para plataformas desktop e embarcadas tornou o Dart mais versátil do que nunca, permitindo que os desenvolvedores criem aplicações para uma ampla variedade de dispositivos além de celular e web.

O ecossistema crescente do Dart, o forte apoio da comunidade de desenvolvedores e as capacidades multiplataforma fazem dele uma escolha atraente para o desenvolvimento de aplicativos modernos.
