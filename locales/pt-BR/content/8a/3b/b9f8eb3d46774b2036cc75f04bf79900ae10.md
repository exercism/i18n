# Tuplas

Uma [tupla][tuple] é uma lista ordenada e finita de elementos, que é imutável.
As tuplas exigem que todas as posições tenham um tipo fixo.
Isso, por sua vez, significa que o compilador sabe qual tipo está em cada posição.
Os tipos usados em uma tupla podem ser diferentes em cada posição, mas os tipos precisam ser conhecidos em tempo de compilação.

## Criando uma tupla

Dependendo de se os tipos dos valores da tupla podem ser interpretados em tempo de compilação, a tupla pode ser criada de maneiras diferentes.
Se os valores forem conhecidos em tempo de compilação, a tupla pode ser criada usando a sintaxe literal de tupla; caso contrário, eles precisam ser declarados explicitamente.
Também é importante que os tipos dos valores correspondam aos tipos especificados na tupla e que o número de valores corresponda ao número de tipos especificados.
Veja um exemplo de definição por meio da sintaxe literal de tupla:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

Também há a possibilidade de criar uma tupla usando a classe `Tuple`.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

Como alternativa, você pode especificar explicitamente o tipo da variável atribuída à tupla.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

Especificar explicitamente o tipo da tupla pode ser útil, pois permite definir que uma posição deve conter um tipo de união.
Isso significa que uma posição pode conter vários tipos.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## Conversão

### Criando uma tupla a partir de um array

Você pode criar uma tupla a partir de um array usando o método `from` da classe `Tuple`.
Isso exige que o tipo da tupla seja especificado.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### Conversão para array

Você pode converter uma tupla em um array usando o método `to_a`.
O tipo dos elementos do array resultante é a união do tipo de cada campo da tupla.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

## Acessando elementos

Assim como os arrays, as tuplas são indexadas a partir de zero, ou seja, o primeiro elemento está no índice 0.
No entanto, diferentemente dos arrays, o tipo de cada elemento é fixo e conhecido em tempo de compilação; portanto, ao indexar uma tupla, o tipo do elemento é específico da posição.
Para acessar um elemento em uma tupla, você pode usar o operador `[]`.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

Outra diferença na hora de acessar elementos de arrays é que, se o índice for especificado, o compilador verificará se o índice está dentro dos limites da tupla.
Isso significa que você receberá um erro em tempo de compilação em vez de um erro em tempo de execução.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

Porém, se o índice estiver armazenado em uma variável, o compilador não conseguirá verificar em tempo de compilação se o índice está dentro dos limites da tupla e, em vez disso, dará um erro em tempo de execução.

## Subtupla

Você pode obter uma subtupla de uma tupla usando o operador `[]` com um intervalo.
O que é retornado é uma nova tupla com os elementos do intervalo especificado.
O intervalo precisa ser fornecido em tempo de compilação; caso contrário, o compilador não conseguirá saber os tipos dos elementos da subtupla.
Isso significa que o intervalo precisa ser um literal de intervalo e não pode ser atribuído a uma variável.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## Quando usar uma tupla

As tuplas são úteis quando você quer agrupar um número fixo de valores cujos tipos são conhecidos em tempo de compilação.
Isso porque as tuplas exigem menos memória e são mais rápidas que os arrays, devido à imutabilidade das tuplas.
Outro caso de uso é retornar vários valores de um método.
Isso é especialmente útil se os valores tiverem tipos diferentes, já que cada posição da tupla pode ter um tipo diferente.

As tuplas não devem ser usadas quando é necessária uma estrutura de dados que possa crescer ou diminuir de tamanho ou que precise ser modificada com frequência.

# Sobre

Os [símbolos][symbols] são identificadores nomeados que podem ser usados para se referir a um valor.
Os símbolos são criados por meio de um literal de símbolo, que consiste em prefixar um nome com o caractere `:`, por exemplo `:foo`.
Eles também podem ser escritos com aspas, por exemplo `:"foo"`, o que permite, por exemplo, espaços no nome.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

Os símbolos são usados em muitos lugares da linguagem, inclusive como chaves em namedtuples e para representar nomes de métodos e variáveis.

## Símbolos em Crystal

Os símbolos em Crystal são bem diferentes dos do Ruby.
Em Crystal, um símbolo é um tipo de constante e, portanto, é atribuído em tempo de compilação.
Isso significa que os símbolos não podem ser criados dinamicamente, o que é possível no Ruby.

Os símbolos em Crystal são representados como `Int32`s, o que os torna muito eficientes.

## Conversão

Os símbolos podem ser convertidos em strings, mas não o contrário.
Isso porque os símbolos são criados em tempo de compilação e as strings em tempo de execução.

```crystal
:foo.to_s # => "foo"
```
