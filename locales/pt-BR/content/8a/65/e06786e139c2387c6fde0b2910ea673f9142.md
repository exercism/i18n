# Sobre

Para executar uma lógica repetidamente, pode-se usar laços. Se o código dentro de um laço precisar ser executado pelo menos uma vez, é possível usar um laço `do`/`while`:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

Esse laço é usado com menos frequência que um laço `while`, mas em alguns casos resulta em um código que parece mais natural.
