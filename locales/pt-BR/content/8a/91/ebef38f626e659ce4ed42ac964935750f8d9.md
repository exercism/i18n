# Introdução

Este exercício se baseia na aritmética de números inteiros de
[Lasanha Deliciosa da Leah][lasagna]. Aqui você vai trabalhar com números de
ponto flutuante e escolher a palavra de divisão certa para cada situação.

## Números inteiros e de ponto flutuante

O Factor distingue números inteiros (`1`, `42`, `1_000_000`) de números de
ponto flutuante (`1.0`, `3.14`, `6.02e23`). Se você misturar um inteiro e um
número de ponto flutuante em um mesmo cálculo, o resultado sai como ponto
flutuante:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

Você pode colocar underscores dentro de um número para agrupar os dígitos,
como em `1_000_000`, e o Factor simplesmente os ignora.

## Palavras de divisão

O Factor tem palavras de divisão separadas. Todas elas ficam no vocabulário
[`math`][math].

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` produz um `ratio` (o tipo racional exato do Factor) para dois inteiros,
ou um `float` se qualquer uma das entradas for um ponto flutuante. `/f` força
um resultado de ponto flutuante mesmo para dois inteiros. `/i` sempre trunca
em direção a zero.

## Verificação

Predicados numéricos de [`math`][math], [`math.functions`][math.functions]
e [`math.primes`][math.primes]:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## De ponto flutuante para inteiro

`floor`, `ceiling` e `round`, do vocabulário
[`math.functions`][math.functions], retornam todos um ponto flutuante
(`3.0`, não `3`). Para obter um inteiro de verdade, encadeie `>integer`:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## Potências e valor absoluto

`sq`, `^` e `abs` (em [`math.functions`][math.functions]) calculam quadrados,
potências arbitrárias e valores absolutos:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## Mínimo e máximo

`min ( x y -- z )` e `max ( x y -- z )` (em
[`math.order`][math.order]) retornam o menor ou o maior de dois números:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

O uso mais comum é o *clamping*: fixar um valor a um piso com `max` (por
exemplo, `0 max` mantém um valor não negativo) ou a um teto com `min`.

## Predicados de ordenação

`math.order` também fornece `before?`, `after?`, `before=?` e
`after=?` para predicados de comparação que funcionam com qualquer
tipo ordenável: números, strings, caracteres:

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

Use esses em vez de `<`/`<=` quando os valores puderem ser strings,
pois os operadores aritméticos não fazem despacho sobre strings.
