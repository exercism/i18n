# Testes

## Executando os testes

Execute a especificação de testes com:

```bash
$ gradle test
```

## Habilitando mais testes

Quando seu código passar em todos os testes ativos, habilite outro teste removendo o `@Ignore` que precede o próximo teste que lhe interessar. Faça isso removendo a linha `@Ignore` ou comentando-a, adicionando duas barras no início da linha.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
