# Introdução

A biblioteca padrão do Gleam implementa um tipo `Queue` no módulo `gleam/queue`. Ele é semelhante ao tipo `List`, mas com algumas diferenças importantes:

- O tipo `Queue` não tem uma sintaxe literal que possa ser usada para construir filas ou fazer pattern matching nelas.
- Elementos podem ser adicionados e removidos de forma eficiente tanto da frente quanto do final do tipo `Queue`, enquanto o tipo `List` só consegue adicionar e remover elementos de forma eficiente da frente.

Na maioria das vezes, você vai querer usar o tipo `List`, mas quando precisar adicionar e remover do final de uma coleção, o tipo `Queue` é uma boa escolha.

Filas podem ser criadas usando as funções `queue.new` e `queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Elementos podem ser adicionados à fila usando as funções `queue.push_front` e `queue.push_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Elementos podem ser removidos da fila usando as funções `queue.pop_front` e `queue.pop_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Uma fila pode ser convertida em uma lista usando a função `queue.to_list`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## Igualdade de filas

Devido à forma como as filas são implementadas, duas filas com os mesmos elementos na mesma ordem podem não ser iguais de acordo com o operador `==`, que compara valores estruturalmente. Por exemplo:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Se você precisar comparar duas filas para verificar se são iguais, pode usar a função `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
