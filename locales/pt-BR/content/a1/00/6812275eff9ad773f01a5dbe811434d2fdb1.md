# Complemento das instruções

## Memória reservada

O buffer da string de entrada usa os bytes 64 a 319 da memória linear.

## Resultados

O resultado deve ser retornado como uma tupla de quatro elementos: `(i32 i32 i32 i32)`. Cada número representa a contagem das letras `A`, `C`, `G` e `T`, nessa ordem.
