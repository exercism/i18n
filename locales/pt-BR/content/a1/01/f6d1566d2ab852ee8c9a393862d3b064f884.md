# Dicas

## Geral

Este exercício vai fazer você escrever filtros `jq` para quatro tarefas.
Como um programa `jq` é uma _única expressão_, esses quatro filtros precisam ser unidos com vírgulas.
Use parênteses em volta das subexpressões para controlar a ordem das operações.

## 1. Extraia o nome da lista de compras

- O conteúdo do arquivo pode ser acessado com o filtro `.`.
- Uma propriedade de objeto pode ser acessada com notação de ponto ou notação de colchetes.

## 2. Conte quantos ingredientes são necessários

- Você precisa produzir o comprimento de um array.

## 3. Quanto de açúcar?

- Você precisa selecionar o ingrediente chamado "sugar".
- Você precisa acessar uma das propriedades dele.

## 4. Mapeie os ingredientes que podem ser substituídos

- Você precisa concatenar dois arrays.
- Você precisa selecionar elementos específicos do array resultante.
- Você precisa gerar um objeto chave:valor para cada um desses elementos.
- Você precisa mesclar esses objetos em um único objeto.
