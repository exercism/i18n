# Apêndice de instruções

## Exemplo de entrada

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

Isso significa que suas entradas são:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## Lidando com entradas inválidas

Se qualquer um dos valores de entrada for inválido, seu verbo deve retornar um `empty` (por exemplo, `0$0` ou `''`).

### Exemplos

- Se a _base de entrada_ for menor que 2:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- Se a _base de saída_ for menor que 2:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- Se _dígitos_ contiver valores maiores ou iguais à base de entrada:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
