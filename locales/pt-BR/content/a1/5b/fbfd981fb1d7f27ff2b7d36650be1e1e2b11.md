# Testes

## Rodando os testes

Com os [passos de instalação][test-installation-steps] concluídos, você pode partir de qualquer diretório de exercício (por exemplo, `~/exercism/gdscript/two-fer`) e rodar o script (que fica um nível acima, em `../`) para testar sua solução local desse exercício:

```sh
../test-local-gdscript-solution.sh
```

## Resolvendo um exercício

Resolver um exercício significa fazer todos os seus testes passarem.

Para ajudar você a começar, cada exercício vem com um arquivo GDScript com o nome do exercício (por exemplo, `exercism/gdscript/two-fer/two_fer.gd`).
Você pode usar esse arquivo como ponto de partida para montar sua solução.
Fique à vontade para alterá-lo conforme necessário, mas os testes esperam que os nomes das funções sejam os fornecidos originalmente.

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
