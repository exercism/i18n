# Instruções

Você está executando um sistema composto por algumas aplicações que produzem muitos logs. Você quer escrever um pequeno programa que agregue esses logs e lhes dê rótulos de acordo com seu nível de gravidade. Todas as aplicações do seu sistema usam os mesmos códigos de log, mas algumas aplicações legadas não suportam todos os códigos.

| Código do log         | Rótulo do log | Suportado em aplicações legadas? |
|-----------------------| ------------- | -------------------------------- |
| 0                     | trace         | não                              |
| 1                     | debug         | sim                              |
| 2                     | info          | sim                              |
| 3                     | warning       | sim                              |
| 4                     | error         | sim                              |
| 5                     | fatal         | não                              |
| outro / não suportado | unknown       | -                                |

## 1. Determine o rótulo do log

Implemente a função `LogLevel.to_label/2`. Ela deve receber um código inteiro e um sinalizador Boolean que indica se o log vem de uma aplicação legada, e retornar o rótulo de uma linha de log como um átomo.

Códigos de log não especificados na tabela devem retornar o rótulo _unknown_. Códigos de log especificados na tabela como não suportados em aplicações legadas também devem retornar o rótulo _unknown_ se o log vier de uma aplicação legada.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Envie um alerta

Alguém precisa ser notificado quando coisas inesperadas acontecem.

Implemente a função `LogLevel.alert_recipient/2` para determinar para quem o alerta precisa ser enviado. A função deve receber um código inteiro e um sinalizador Boolean que indica se o log vem de uma aplicação legada, e retornar o nome do destinatário como um átomo.

Use a função `LogLevel.to_label/2` da tarefa anterior. Se o rótulo do log for _error_ ou _fatal_, envie o alerta para a equipe _ops_. Se você receber um log com o rótulo _unknown_ de um sistema legado, envie o alerta para a equipe _dev1_; outros rótulos unknown devem ser enviados para a equipe _dev2_. Todos os outros rótulos de log podem ser ignorados com segurança retornando _false_.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
