# Introdução

Uma *deque* (fila de duas pontas) dá suporte a push e pop nas duas
pontas em O(1). A implementação padrão do Factor é `<dlist>` (uma
lista duplamente encadeada) em [`dlists`][dlists]; as operações
ficam em [`deques`][deques].

## A API de deque

```
<dlist>       ( -- dlist )
push-front    ( elt deque -- )
push-back     ( elt deque -- )
pop-front     ( deque -- elt )
pop-back      ( deque -- elt )
deque-empty?  ( deque -- ? )
dlist-length  ( dlist -- n )
clear-deque   ( deque -- )
```

`clear-deque` esvazia a deque no local: útil para reutilizar
sem realocar.

Fazer push e pop na mesma ponta dá uma pilha LIFO. Fazer push em
uma ponta e pop na outra dá uma fila FIFO:

```factor
USING: deques dlists ;

<dlist>
"alpha" over push-back
"bravo" over push-back
"charlie" over push-back
dup pop-front .   ! => "alpha"   (FIFO — oldest first)
dup pop-front .   ! => "bravo"
pop-front .       ! => "charlie"
```

Para LIFO, você recorreria a um vetor (`V{ }`) com `push`/`pop`,
que tem menos sobrecarga por operação. Recorra ao `<dlist>` quando
precisar de O(1) nas *duas* pontas, quase sempre para uma fila FIFO.

## Busca em largura

É o uso FIFO que faz das deques a fronteira certa para a *BFS*.
Você começa com um único nó, faz push dos vizinhos para o fim, faz
pop dos candidatos da frente e remove as duplicatas com um hash-set:

```factor
! DOCTEST: SKIP
USING: deques dlists hash-sets sets ;

! ... visited adjoin and frontier push-back ...
[ frontier deque-empty? ] [
    frontier pop-front ! ... look up neighbours, push unseen ones ...
] until
```

Candidatos mais antigos são visitados antes dos mais novos, então a
busca se espalha em camadas a partir do início. É isso que dá à BFS
a sua propriedade de caminho mais curto: a primeira vez que você
chega a um nó de destino é por um caminho com o mínimo de saltos.

## `MEMO:`: cache automático

Às vezes, a consulta por nó que a BFS faz é cara. O vocabulário
[`memoize`][memoize] do Factor oferece `MEMO:`, um substituto
direto para `:` que guarda em cache o resultado da palavra,
indexado pelas suas entradas:

```factor
USING: memoize ;

MEMO: gold-count ( cove -- n )
    ! ... slow lookup ...
    ;
```

Uma palavra com `MEMO:` executa o corpo na primeira vez que cada
entrada é vista e retorna o resultado guardado em cache a partir
daí: mesma interface, nenhuma chamada extra no ponto de chamada,
apenas mais rápida nas repetições.
