# Introdução

## Definindo variáveis

Definir uma variável significa atribuir um valor a um nome. Em Scala, existem dois tipos de variáveis: vals e vars.

Um `val` é imutável, então seu valor não pode mais ser alterado depois da primeira atribuição:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

Já um `var` pode ser reatribuído a um novo valor do mesmo tipo:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala é uma linguagem de tipagem estática, o que significa que tudo tem um tipo em tempo de compilação. Uma variável pode ser definida especificando explicitamente seu tipo ou deixando o compilador do Scala inferir o tipo com base no valor atribuído (o que se chama de inferência de tipos). Portanto, as duas definições de variável a seguir são equivalentes:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

Uma vez definido, o tipo de uma variável nunca pode mudar.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## Definindo métodos dentro de classes

Scala é uma _linguagem orientada a objetos_ e exige que todos os métodos sejam definidos em uma _classe_. A palavra-chave `class` é usada para definir uma classe.

```scala
class Calculator {
  // ...
}
```

Dentro de uma classe, os métodos podem ser definidos começando com a palavra-chave `def`, seguida de um nome. Cada método pode ter zero ou mais parâmetros, que são listados separados por vírgula entre parênteses. Todos os parâmetros devem ser tipados explicitamente; não há inferência de tipos para parâmetros. Depois da lista de parâmetros, o tipo de retorno do método é definido, separado por mais dois-pontos.

A definição do método é seguida por um sinal de `=` para iniciar o corpo do método. No exemplo a seguir, o corpo do método consiste em duas instruções, que estão envolvidas por chaves.

O método retornará o valor da última expressão; neste caso, o método `add` retorna o valor da variável `sum`:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

Há algumas melhorias que podem ser feitas para encurtar esse método e melhorar a legibilidade:

- como a variável `sum` é acessada apenas uma vez para retornar o valor, ela pode ser omitida
- métodos que consistem em apenas uma instrução não precisam de chaves
- o tipo de retorno do método pode ser inferido da mesma forma que os tipos das variáveis

Isso leva ao seguinte método de uma linha, com a mesma funcionalidade:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## Instanciando classes e chamando métodos

Para invocar um método, primeiro você cria uma instância de uma classe e depois chama o método nessa instância, passando argumentos:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Comentários

Scala suporta dois tipos de comentários: comentários de uma linha e comentários de várias linhas:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
