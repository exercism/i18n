# Apêndice das instruções

Sobrescreva a string de número de telefone fornecida.
Se o número de telefone for inválido, substitua-o por uma string vazia.

## Registradores

| Registrador | Uso           | Tipo    | Descrição                                  |
| ----------- | ------------- | ------- | ------------------------------------------ |
| `$a0`       | entrada/saída | endereço | número de telefone como string terminada em nulo |
| `$t0-9`     | temporário    | qualquer | usado para armazenamento temporário        |
