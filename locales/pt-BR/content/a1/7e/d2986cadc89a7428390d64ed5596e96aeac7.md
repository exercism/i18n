# Testes

Usamos o [PonyTest](https://stdlib.ponylang.io/pony_test--index/) da biblioteca padrão para escrever os testes que verificam a sua solução. Para testar a sua solução, compile e rode o seu código.

Por exemplo, a sua sessão do "Hello World" pode ficar assim:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
