# Introdução

## Protocolos

Protocolos são um mecanismo para alcançar polimorfismo em Elixir quando você quer que o comportamento varie de acordo com o tipo de dado.

Protocolos são definidos com `defprotocol` e contêm uma ou mais assinaturas de função.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

Protocolos podem ser implementados com `defimpl`.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

Um protocolo pode ser implementado para qualquer tipo de dado existente do Elixir ou para um struct.

Quando uma função de protocolo é chamada, a implementação apropriada é escolhida automaticamente com base no tipo do primeiro argumento.
