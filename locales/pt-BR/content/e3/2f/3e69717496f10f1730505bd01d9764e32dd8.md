# Dicas

As três primeiras tarefas chamam a mesma função `print_name_badge()`.
A implementação pode ser construída aos poucos, acrescentando a lógica das tarefas 2 e 3 conforme você avança.

## 1. Criar um crachá para um funcionário

- Este é o caso padrão: basta juntar os 3 argumentos em uma string adequada.
- A [interpolação de strings][interpolation] provavelmente é a abordagem mais fácil.

## 2. Criar um crachá para um novo funcionário

- Agora o ID é `missing,`, então o formato da string de destino é diferente.
- [`ismissing()][ismissing] é útil aqui.
- Julia tem um [operador ternário][ternary] com sintaxe concisa.

## 3. Criar um crachá para o proprietário

- Agora o departamento é `nothing`.
- Existe uma função [`isnothing()`][isnothing].

## 4. Calcular o salário total dos funcionários sem ID

- Falta [algum][any] ID? Se não, o valor de retorno é zero.
- Para extrair as entradas com ID ausente, pode ajudar começar fazendo o [zip][zip] dos vetores `ids` e `salaries`.
- Há várias formas de iterar sobre o vetor de tuplas resultante, sem escrever um laço explícito.
  - De forma pythônica, com uma [comprehension][comprehension] de vetor.
  - De forma funcional, com [`map()`][map] e uma [função anônima][anonymous].
  - De forma vetorial, com [broadcasting][broadcasting] de uma [função anônima][anonymous].
- No final, haverá uma [`sum()`][sum] sobre um vetor de salários modificado.
   - Os salários dos funcionários com ID podem ser omitidos ou definidos como zero.
