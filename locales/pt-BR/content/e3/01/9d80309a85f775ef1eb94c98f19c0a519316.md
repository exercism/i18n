# Aprendendo

O Exercism oferece exercícios e feedback, mas pode ser difícil dar os primeiros passos para quem está aprendendo Common Lisp pela primeira vez.
Estes recursos podem ajudar você a começar:

* [A Road to Common Lisp][road-to-cl], um post de blog que explica a trajetória de uma pessoa com Common Lisp e as opiniões dela sobre como começar
* [Practical Common Lisp][practical-cl], um livro completo para aprender Common Lisp, disponível de graça online (e também impresso)
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  por vários colaboradores
* [Awesome Common Lisp Learning][awesome-cl]

Veja também, nesta trilha de Common Lisp do Exercism: [Recursos importantes][track-resources].
