# Sobre

Cada processo do Elixir tem seu próprio identificador único: um _PID_ (identificador de processo).

- Os PIDs são um tipo de dado próprio.
  - Você pode verificar se uma variável é um PID com [`is_pid/1`][kernel-is-pid]
- Você pode obter o PID do processo atual com `self()`.
- Os PIDs funcionam como _endereços de caixa de correio_: se você tem o PID de um processo, pode enviar uma mensagem para esse processo.
- Os PIDs geralmente são criados indiretamente, como valor de retorno de funções que criam novos processos, como `spawn`.
  - Os PIDs não devem ser criados diretamente pelo programador. Se fosse necessário, o Erlang tem uma função [`list_to_pid/1`][erlang-list-to-pid].

[kernel-is-pid]: https://hexdocs.pm/elixir/Kernel.html#is_pid/1
[erlang-list-to-pid]: https://www.erlang.org/doc/man/erlang.html#list_to_pid-1
