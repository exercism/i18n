# Introdução

Em Kotlin, as classes podem ser usadas para encapsular dados e comportamento.
Uma classe é declarada com a palavra-chave `class`.
Por exemplo:

```kotlin
class Car
```

Crie uma instância da classe chamando-a.

```kotlin
val instance = Car()
```

## Propriedades

Nos exemplos acima, a classe `Car` foi declarada sem nenhuma propriedade.
As propriedades da classe podem ser declaradas no corpo, entre `{}`, usando `var` para propriedades mutáveis e `val` para as imutáveis.
Por exemplo:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

Outra opção é definir as propriedades em um construtor que as recebe.

## Construtores

Kotlin tem dois tipos de construtores: primários e secundários.
O construtor primário é declarado na mesma linha da declaração da classe.
Por exemplo:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

A palavra-chave `constructor` pode ser omitida quando não há anotações nem modificadores de visibilidade:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Kotlin permite definir a classe com um corpo quando ela contém apenas propriedades, sem precisar das chaves `{}`:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

Uma classe pode ter apenas um construtor primário.
Os construtores secundários são construtores adicionais, que podem ser acrescentados declarando-os no corpo da classe com a palavra-chave `constructor`.
Por exemplo:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

Os construtores secundários precisam invocar o construtor primário chamando `this`.

## Blocos de inicialização

O construtor primário define as propriedades da classe.
Se for preciso fazer mais alguma coisa durante a criação do objeto, é possível usar blocos `init` para executar ações adicionais.

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## Funções

Funções podem ser definidas no corpo da classe.
Por exemplo:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## Visibilidade

Propriedades e funções podem ser `private`, `public`, `internal` ou `protected`.

- `private` pode ser acessado apenas dentro da classe
- `protected` pode ser acessado por elementos da própria classe e por quaisquer subclasses
- `internal` pode ser acessado por elementos do mesmo módulo
- `public` pode ser acessado por outros componentes que usam a classe

Por exemplo:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
