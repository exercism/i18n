# Apêndice das instruções

## Instruções específicas da trilha

```exercism/note
Soluções ingênuas podem demorar muito para passar nos testes que envolvem fatores de quatro dígitos, provavelmente mais do que o limite de tempo reservado ao executor de testes online.
Talvez você precise trabalhar no exercício localmente para analisar o desempenho da sua solução.
Existem soluções eficientes para este exercício, mas elas são desafiadoras.
```
