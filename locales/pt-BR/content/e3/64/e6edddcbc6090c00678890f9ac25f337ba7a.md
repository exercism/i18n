# Dicas

## Geral

- O [tipo atom é descrito aqui][atom].

## 1. Determine o rótulo do log

- Você pode usar a [forma especial `cond/1`][cond] para lidar com os diversos códigos de log de forma elegante.
- Você pode usar os [operadores de igualdade][equality] para comparar inteiros quanto à igualdade estrita de tipo.
- Existe uma [maneira de especificar um bloco padrão][cond] em uma expressão cond que pode ser usada para capturar casos não especificados.

## 2. Envie um alerta

- Você pode usar a [forma especial `cond/1`][cond] para decidir se um alerta deve ser enviado.
- Você pode usar os [operadores de igualdade][equality] para comparar atoms quanto à igualdade.

[equality]: https://hexdocs.pm/elixir/Kernel.html#==/2
[atom]: https://hexdocs.pm/elixir/basic-types.html#atoms
[cond]: https://hexdocs.pm/elixir/case-cond-and-if.html#cond
