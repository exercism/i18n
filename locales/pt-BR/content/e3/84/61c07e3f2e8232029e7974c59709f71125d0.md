# Introdução

Java é uma linguagem de tipagem estática, o que significa que o tipo de uma variável é conhecido em tempo de compilação.
Atribuir um valor a um nome é o que chamamos de definir uma variável.
Uma variável é definida especificando explicitamente o seu tipo.

```java
int explicitVar = 10;
```

A atualização do valor de uma variável é feita com o operador `=`.
Aqui, o `=` não representa igualdade matemática.
Ele simplesmente atribui um valor a uma variável.
Depois de definida, o tipo de uma variável nunca muda.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java é uma [linguagem orientada a objetos][object-oriented-programming] e exige que todas as funções sejam definidas dentro de uma _classe_.
A palavra-chave `class` é usada para definir uma classe.

```java
class Calculator {
    // ...
}
```

Uma função dentro de uma classe é chamada de _método_.
Cada método pode ter zero ou mais parâmetros.
Todos os parâmetros precisam ter o tipo explícito; não há inferência de tipos para parâmetros.
Da mesma forma, o tipo de retorno também precisa ser explícito.
Os valores são retornados dos métodos com a palavra-chave `return`.
Para permitir que outras classes chamem um método, é preciso adicionar o modificador de acesso `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Para invocar/chamar um método, especifica-se a classe e o nome do método e passam-se argumentos para cada um dos parâmetros do método.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

O escopo em Java é definido entre os caracteres `{` e `}`.

Java suporta dois tipos de comentários.
Comentários de linha única são precedidos por `//` e comentários de várias linhas ficam entre `/*` e `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
