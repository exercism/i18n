# Dicas

## Geral

- Leia sobre o uso de bibliotecas Erlang no [guia oficial de primeiros passos][getting-started-erlang-libraries] e, em particular, sobre [formatação de strings][getting-started-formatted-text-output].

## 1. Gere um planeta aleatório

- Use o atributo de módulo fornecido com uma lista de letras que representam as classes planetárias.
- Existe uma [função embutida][enum-random] para escolher um elemento de uma lista aleatoriamente.

## 2. Gere um número de registro de nave estelar aleatório

- Existe uma [função embutida][enum-random] para escolher um elemento de um intervalo aleatoriamente.

## 3. Gere uma data estelar aleatória

- Não existe uma função do Elixir que retorne um número de ponto flutuante aleatório.
- Existe uma [função embutida do Erlang][erl-rand-uniform] que retorna um número de ponto flutuante aleatório x onde `0.0 <= x < 1.0`.
- Se `x` pertence a um intervalo `0.0 <= x < 1.0`, mas você precisa de um número de um intervalo diferente `a <= x < b`, você pode deslocar o intervalo de x multiplicando-o pela largura do intervalo (`b - a`) e somando o início do intervalo (`a`). Ou seja: `x * (b - a) + a`.

## 4. Formate a data estelar

- Não existe uma função do Elixir capaz de, em uma única etapa, formatar um número de ponto flutuante como string com uma precisão específica.
- Existe uma [função embutida do Erlang][erl-io-lib-format] que recebe uma string de formato e uma lista de dados e retorna um charlist.
- Existe uma [função embutida][to-string] que converte um charlist em uma string.
- A string de formato dessa função contém sequências de controle.
- Uma sequência de controle começa com `~` e tem o padrão `~F.P.PadModC`, onde `F` representa a largura da saída, `P` representa a precisão, `Pad` representa o caractere de preenchimento, `Mod` representa o modificador da sequência de controle e `C` é o tipo da sequência de controle.
- Para formatar um número de ponto flutuante com a precisão desejada, basta uma sequência de controle com o padrão `~.PC`.
- O tipo da sequência de controle para números de ponto flutuante é `f`.
- A string de formato exata que você precisa é `~.1f`.
