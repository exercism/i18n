# Introdução

*Combinatória* é a matemática de contar e listar as maneiras pelas quais uma coleção de itens pode ser escolhida ou organizada. O vocabulário [`math.combinatorics`][math.combinatorics] do Factor aborda as duas perguntas básicas:

- **Combinações**: seleções em que a ordem *não* importa.
- **Permutações**: arranjos em que a ordem *importa*.

Cada pergunta tem uma palavra de *contagem* que retorna um número e uma palavra de *listagem* que retorna as seleções em si. Há ainda uma variante `each-` em fluxo, que chama uma quotation com cada uma delas:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
