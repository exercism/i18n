# Instalação

## Versão alvo

Os testes desta trilha usam a imagem Docker `alpine:3.24.1` que, em setembro de 2026, traz o `sqlite3 version 3.53.4`.
Buscamos garantir que as ferramentas oferecidas por esta trilha funcionem na versão LTS mais recente do Ubuntu.
Talvez você tenha versões mais novas instaladas, mas é bom saber que alguns recursos podem não funcionar com o nosso executor de testes.
Você pode comparar os recursos no [histórico de versões do SQLite][version-history].

## Windows

Para instalar o SQLite no Windows, siga estes passos:

1. Baixe os binários pré-compilados para Windows na [página oficial de download][sqlite-download].
2. Extraia o arquivo ZIP baixado para um diretório de sua escolha.
   Por exemplo, `C:\Program Files\sqlite3`.
3. Adicione o diretório que contém `sqlite3.exe` à variável de ambiente PATH do sistema.
   O processo é um pouco diferente em cada versão do Windows, mas a informação é fácil de encontrar na busca.
   Por exemplo, [instruções para o Windows 11][windows-11-install] e [Windows 10][windows-10-install].

## macOS

No macOS, o SQLite já vem instalado.
Mas, se você precisar de uma versão mais recente, pode usar o [Homebrew][homebrew]:

```bash
brew install sqlite
```

## Ubuntu / Debian

Em sistemas Ubuntu e baseados em Debian, você pode instalar o SQLite usando o apt:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

Em sistemas CentOS, Fedora e baseados em Red Hat, você pode instalar o SQLite usando yum ou dnf:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

No Arch Linux, você pode instalar o SQLite usando o pacman:

```bash
sudo pacman -S sqlite
```

## Outras formas de instalação e versões antigas

Consulte a [página de download do SQLite][sqlite-download] para mais informações e formas alternativas de instalação.
A seção `Build Product Names and Info` traz o modelo de nomenclatura das diferentes versões do SQLite, então você deve conseguir buscar a versão que quiser com o seu mecanismo de busca preferido.
