# Sobre operadores aritméticos

## Operadores

Go suporta os seguintes operadores aritméticos:

| Operador | Exemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

Na divisão inteira, o resto é descartado (por exemplo, `5 / 2 == 2`).

O operador `+` também concatena strings: `"foo" + "bar" == "foobar"`.

## Aritmética com tipos mistos

Go não permite operações aritméticas entre tipos numéricos diferentes:

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

Os operandos precisam ser do mesmo tipo, o que às vezes exige uma conversão explícita:

```go
x := float64(42)
n := 2.0
value := n * x 
```

## Atribuições abreviadas

Cada operador tem uma forma de atribuição abreviada que atualiza a variável no lugar:

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## Incremento e decremento

Quando colocadas depois de uma variável, as instruções de incremento (`++`) e decremento (`--`) aumentam ou diminuem em 1 o valor numérico armazenado nela.
Colocá-las antes de uma variável é um erro de sintaxe.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

Como são instruções, elas não retornam um valor.
