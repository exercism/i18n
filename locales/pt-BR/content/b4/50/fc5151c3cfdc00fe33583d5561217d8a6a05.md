# Números em Phix

Existem dois tipos de dados em Phix para armazenar números: integer e atom.
Os integers têm sinal e são um bit menores que a palavra da máquina e, portanto (alerta de spoiler), são inadequados para esta tarefa, mesmo em 64 bits.
Os atoms conseguem guardar inteiros de precisão mais alta, o suficiente pelo menos em 64 bits, que é o que você certamente está usando ao rodar online no site exercism.org, e provavelmente na CLI, desde que seja essa a versão que você instalou: basta rodar 'p' em um console de terminal e ele vai mostrar para você.

## Máquinas de 32 bits

No entanto, mesmo os atoms em 32 bits ainda não são precisos nem grandes o bastante para concluir este exercício. Para contornar isso, você pode, em vez disso, retornar uma string, que deve/pode ser exata, sem vírgulas nem underscores, mas você não é obrigado a fazer isso em 64 bits.
Você pode construir essas strings manualmente ou usar uma biblioteca de precisão arbitrária, como a [mpfr][mpfr].

Uma versão de 32 bits do Phix continua essencial para testes adequados no desktop/Phix antes de usar o p2js, já que o JavaScript é inerentemente de 32 bits (ou, talvez mais precisamente, de 53 bits), mesmo em um navegador de 64 bits rodando em uma máquina de 64 bits.

Os limites exatos do que os integers e atoms do Phix conseguem guardar estão, é claro, detalhados com mais profundidade no [manual][manual].

[mpfr]: http://phix.x10.mx/docs/html/mpfr.htm
[manual]: http://phix.x10.mx/docs/html/atoms.htm
