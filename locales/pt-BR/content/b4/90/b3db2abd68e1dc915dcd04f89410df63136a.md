# Introdução

## Propriedades

Uma propriedade em C# é um membro de uma classe que dá acesso aos dados dessa classe. Quem chama pode definir ou recuperar (obter) os dados. As propriedades podem ser autoimplementadas ou ter um campo de apoio. Elas compreendem um acessador set e/ou um acessador get.
Em algumas outras linguagens, um "mutator" equivale mais ou menos a um acessador set, e um "accessor" equivale mais ou menos a um acessador get, embora a composição da sintaxe seja completamente diferente.

Ao definir uma propriedade, o valor de entrada pode ser validado, formatado ou manipulado de outra forma; na verdade, qualquer operação programática acessível ao código da classe pode ser executada.

Da mesma forma, ao recuperar uma propriedade, os dados podem ser calculados ou formatados e, de novo, qualquer operação programática disponível para a classe pode ser executada.

Propriedades têm modificadores de acesso (`public`, `private` etc.) da mesma forma que outros membros da classe, mas o acessador set pode ter um nível de acesso independente do acessador de leitura (get), e vice-versa. Uma propriedade não precisa ter os dois acessadores: pode ter apenas um (get ou set).

A sintaxe básica para expressar propriedades pode assumir duas formas:

### Propriedades com campo de apoio ou expressão:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### Propriedades autoimplementadas

```
public int MyProperty { get; private set; } = 42;
```

A inicialização é opcional.
