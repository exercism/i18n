## Variáveis

Variáveis são nomes simbólicos que se referem a valores ou a contêineres.
Nomes de variáveis podem começar com ou sem um caractere especial chamado [sigil][sigils], seguido de um identificador.
Um sigil também pode ser seguido de um [twigil][twigils].

Variáveis com sigils diferentes guardam tipos diferentes de estruturas de dados.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

Os twigils que você verá com mais frequência são `^` e `:`, que funcionam como atalhos para assinaturas de bloco de código.
O `^` é para parâmetros posicionais.
O `:` é para parâmetros nomeados.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## Contêineres

Os contêineres são o que permite que uma variável seja modificada.

Variáveis declaradas com `constant` e variáveis sem sigil (declaradas com um `\` antes do identificador) não têm contêineres e se referem diretamente a valores.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## Tipos

Variáveis podem ser declaradas com uma restrição de tipo.
Restrições de tipo também podem ter coerções, passando um tipo aceito como argumento para o tipo desejado.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

Usar restrições de tipo é uma forma de aproveitar rotinas de despacho múltiplo.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

Os tipos em Raku são apenas mais um tipo de objeto.
Declarar uma `class`, um `role` ou um `enum` é uma forma de criar seus próprios objetos de tipo.
Por exemplo, o tipo nativo `Bool` é criado com um enum: `enum Bool <False True>`.

Você também pode criar restrições de tipo simples com base em outros tipos usando a palavra-chave `subset`.
Você pode restringir ainda mais esse novo tipo usando uma cláusula `where`.
Uma cláusula `where` também pode ser usada em uma assinatura.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
