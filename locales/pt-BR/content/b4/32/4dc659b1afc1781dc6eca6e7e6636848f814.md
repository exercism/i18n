# Instruções

Sua amiga bibliotecária pediu que você estendesse o software da biblioteca dela para calcular automaticamente as taxas de atraso.
O sistema atual dela armazena a data e a hora exatas da retirada de um livro como uma string de data e hora [ISO8601](https://en.wikipedia.org/wiki/ISO_8601).
Ela administra uma biblioteca local em uma cidade pequena de Gana, que usa o fuso horário GMT (UTC +0), não adota horário de verão e não precisa se preocupar com outros fusos horários.

## 1. Fazer o parse das datas armazenadas

Implemente a função `LibraryFees.datetime_from_string/1`. Ela deve receber uma string de data e hora ISO8601 como argumento e retornar uma struct `NaiveDateTime`.

```elixir
LibraryFees.datetime_from_string("2021-01-01T13:30:45Z")
# => ~N[2021-01-01 13:30:45]
```

## 2. Determinar se um livro foi retirado antes do meio-dia

Se um livro foi retirado antes do meio-dia, o leitor tem 28 dias para devolvê-lo. Se foi retirado ao meio-dia ou depois, são 29 dias.

Implemente a função `LibraryFees.before_noon?/1`. Ela deve receber uma struct `NaiveDateTime` e retornar um valor booleano.

```elixir
LibraryFees.before_noon?(~N[2021-01-12 08:23:03])
# => true
```

## 3. Calcular a data de devolução

Com base na data e hora da retirada, calcule a data de devolução.

Implemente a função `LibraryFees.return_date/1`. Ela deve receber uma struct `NaiveDateTime` e retornar uma struct `Date`, 28 ou 29 dias depois.

```elixir
LibraryFees.return_date(~N[2020-11-28 15:55:33])
# => ~D[2020-12-27]
```

## 4. Determinar o atraso na devolução do livro

A biblioteca cobra uma taxa fixa por devoluções atrasadas. Para calcular a taxa, precisamos saber quantos dias após a data de devolução o livro foi realmente devolvido.

Implemente a função `LibraryFees.days_late/2`. Ela deve receber uma struct `Date` (a data de devolução planejada) e uma struct `NaiveDateTime` (a data e hora da devolução real).

Se a data de devolução real for em um dia anterior ou no mesmo dia que a data e hora da devolução planejada, a função deve retornar 0. Caso contrário, ela deve retornar a diferença entre essas duas datas em dias.

A biblioteca registra tanto a data quanto a hora da devolução real do livro para fins estatísticos, mas não usa a hora no cálculo da taxa de atraso.

```elixir
LibraryFees.days_late(~D[2020-12-27], ~N[2021-01-03 09:23:36])
# => 7
```

## 5. Determinar se o livro foi devolvido em uma segunda-feira

A biblioteca tem uma oferta especial para devoluções de livros às segundas-feiras.

Implemente a função `LibraryFees.monday?/1`. Ela deve receber uma struct `NaiveDateTime` e retornar um valor booleano.

```elixir
LibraryFees.monday?(~N[2021-01-03 13:30:45Z])
# => false
```

## 6. Calcular a taxa de atraso

Implemente a função `LibraryFees.calculate_late_fee/3`. Ela deve receber três argumentos: duas strings de data e hora ISO8601 (a data e hora da retirada e a data e hora da devolução real) e a taxa de atraso de um dia. Ela deve retornar a taxa de atraso total de acordo com o atraso da devolução real do livro.

Inclua a oferta especial de segunda-feira. Se você devolver o livro em uma segunda-feira, sua taxa de atraso tem 50% de desconto, arredondado para baixo.

```elixir
# Sunday, 7 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-03T13:30:45Z", 100)
# => 700

# one day later, Monday, 8 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-04T09:02:11Z", 100)
# => 400
```
