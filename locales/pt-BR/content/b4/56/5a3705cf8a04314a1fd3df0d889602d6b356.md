# Ajuda

Para conseguir ajuda quando você tiver dificuldades, use um destes recursos:

- [tag `c++-faq` no StackOverflow](https://stackoverflow.com/tags/c%2b%2b-faq/info)
- [FAQ de C++ do isocpp.com](https://isocpp.org/faq)
- [CppReference](http://en.cppreference.com/) é uma referência em formato de wiki para a linguagem C++ e a biblioteca padrão
- [C traps and pitfalls](http://www.slideshare.net/LegalizeAdulthood/c-traps-and-pitfalls-for-c-programmers) é útil se você está começando com C++, mas já programou em C
