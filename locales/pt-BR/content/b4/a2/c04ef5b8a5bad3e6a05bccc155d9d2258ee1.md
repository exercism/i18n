# Instruções

Você é o comissário do navio, responsável pelo estoque da despensa. O
inventário é uma hashtable em que cada chave é o nome de um item e o
valor é a quantidade em estoque.

## 1. Monte um inventário a partir de uma lista

Defina `create-inventory` para receber uma sequência de nomes de itens e
retornar uma hashtable que associa cada nome único à sua contagem.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Adicione mais itens

Defina `add-items` para receber um inventário e uma sequência de itens e
retornar um novo inventário com as contagens incrementadas para cada
item listado. O inventário original não deve ser modificado.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Decremente as contagens

Defina `decrement-items` para receber um inventário e uma sequência de
itens e retornar um novo inventário com as contagens diminuídas em uma
unidade para cada item listado. As contagens nunca podem ficar abaixo de
zero, e itens que ainda não estão no inventário devem ser deixados de
fora (nenhuma entrada negativa é inserida).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Remova um item por completo

Defina `remove-item` para receber um inventário e um item e retornar um
novo inventário com esse item removido. Se o item não estiver presente,
retorne uma cópia inalterada.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Liste os itens disponíveis

Defina `list-inventory` para receber um inventário e retornar um array de
pares `{ name quantity }` contendo apenas os itens cuja quantidade é
maior que zero, ordenados alfabeticamente por nome.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
