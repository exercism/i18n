# Dicas

## Geral

- Não se preocupe com a forma como os argumentos são obtidos, foque apenas em combinar os argumentos para retornar o resultado esperado.

## 1. Defina se o pac-man pode comer um fantasma

- A função deve retornar um valor boolean.
- Você pode usar o operador [boolean][boolean] [`and/2`][boolean-and] para combinar os argumentos e obter um resultado.

## 2. Defina se o pac-man pontua

- A função deve retornar um valor boolean.
- Você pode usar o operador [boolean][boolean] [`or/2`][boolean-or] para combinar os argumentos e obter um resultado.

## 3. Defina se o pac-man perde

- A função deve retornar um valor boolean.
- Você pode usar os operadores [boolean][boolean] [`and/2`][boolean-and] e [`not/1`][boolean-not] para combinar os argumentos e obter um resultado.

## 4. Defina se o pac-man vence

- A função deve retornar um valor boolean.
- Você pode usar os operadores [boolean][boolean] [`and/2`][boolean-and] e [`not/1`][boolean-not] para combinar os argumentos e os resultados de uma das funções implementadas anteriormente.

[boolean]: https://hexdocs.pm/elixir/basic-types.html#booleans-and-nil
[boolean-and]: https://hexdocs.pm/elixir/Kernel.html#and/2
[boolean-or]: https://hexdocs.pm/elixir/Kernel.html#or/2
[boolean-not]: https://hexdocs.pm/elixir/Kernel.html#not/1
