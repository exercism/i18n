# Introdução

Números de ponto flutuante são números com um ou mais dígitos depois do separador decimal.

```gleam
let float = 3.45
// -> 3.45
```

Números de ponto flutuante também têm seu próprio conjunto de operadores.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```
