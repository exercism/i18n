# Introdução

AWK é uma linguagem muito pequena e tem apenas alguns tipos de dados básicos.
Nesta lição, vamos ver números e strings.

## Números

Em AWK, os números são implementados como números de ponto flutuante de precisão dupla.
Não há distinção entre inteiros, floats e doubles.

AWK entende constantes numéricas octais (que começam com `0`) e constantes numéricas hexadecimais (que começam com `0x` ou `0X`).

### Operações numéricas

Você pode usar os [operadores aritméticos padrão][ops-arith] `+`, `-`, `*`, `/`, `%`.
O operador de exponenciação é `^` (especificado pelo POSIX), embora `**` também possa ser usado.
Existem algumas [funções numéricas internas][funcs-numeric], incluindo funções trigonométricas, geração de números aleatórios e `int(x)` para truncar um número até o inteiro mais próximo entre _x_ e zero.

Não existem _operadores_ bit a bit.
O gawk os implementa como funções.
Os argumentos precisam ser números não negativos.

| função              | operação                                       |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | AND bit a bit dos argumentos                   |
| `or(a, b [, ...])`  | OR bit a bit dos argumentos                    |
| `xor(a, b [, ...])` | XOR bit a bit dos argumentos                   |
| `lshift(v, count)`  | o valor de _v_ deslocado _count_ bits à esquerda |
| `rshift(v, count)`  | o valor de _v_ deslocado _count_ bits à direita  |
| `compl(v, count)`   | complemento bit a bit de _v_                   |

## Strings

As strings em AWK são sequências de caracteres.
Para especificar uma constante string, use aspas duplas.

~~~~exercism/caution
O GNU awk permite caracteres Unicode em strings: outras implementações de awk talvez não.
Compare o `gawk` com o `mawk`, outro AWK bastante popular:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### Operações com strings

Existe apenas uma operação com strings: a concatenação.
A concatenação não tem um operador especial;
basta colocar duas strings lado a lado para concatená-las:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` é uma **instrução**, não uma função.
`print` não exige parênteses.
~~~~

AWK tem uma porção de [funções de manipulação de strings][funcs-string].
Vamos conhecê-las a fundo conforme avançamos pela trilha.

## Conversão entre números e strings

Não existem operadores explícitos para converter entre números e strings.
O AWK faz isso de forma implícita, com base no contexto do programa.
Isso torna muito simples trabalhar com os valores dos campos de entrada: em geral, o AWK simplesmente faz o que você quer que ele faça.

* `print x + y` converte os valores das variáveis `x` e `y` em números, graças à operação numérica `+`.
* `print x y` converte os valores das variáveis `x` e `y` em strings, graças à operação de concatenação.

Se você quiser ser explícito, `0 + x` dá a representação numérica de _x_ e `"" x` dá a representação como string de _x_.

### De strings para números

A forma como o AWK converte uma string em número pode ser confusa.
Uma maneira simples de pensar nisso é que o AWK lê os "caracteres numéricos" do início da string até encontrar um caractere que não seja um número.
Alguns exemplos:

* `"2.5"` é convertido no número `2.5`;
* `"1e3"` é convertido no número `1000` (notação científica);
* `"456abc"` é convertido no número `456` (como `a` não é um "numeral", a conversão para ali).
* `"abc789"` é convertido no número `0` (não há números no **início** da string).

Os detalhes completos estão [no manual][str-to-num].

## Descobrindo o tipo de uma variável

A [função `typeof(var)`][func-typeof] retorna o tipo como uma string.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
produz a saída
```none
42 string
43 number
```
