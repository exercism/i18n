# Aprendizado

Odin é uma linguagem de programação de sistemas.
Assim como em C, quem programa precisa gerenciar a memória manualmente.
Ainda assim, é uma linguagem bastante simples.

Os recursos a seguir estão disponíveis para ajudar você a aprender Odin:

Tenha um primeiro contato com a linguagem:

* Assista ao [Introduction to Odin][video], apresentado pelo criador do Odin.
* Leia o artigo [Introduction to Odin][intro], escrito pelo autor de ["Understanding the Odin Programming Language"][book].
* Estude o [Demo File][demo], que mostra, em código, conceitos do Odin.

Aprofunde-se com:

* [Visão geral da linguagem Odin][overview].
* A documentação dos [pacotes oficiais][packages].
* O livro ["Understanding the Odin Programming Language"][book] (pago).
* O conjunto oficial de ["Odin Examples"][examples].
