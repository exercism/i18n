# Testes

A maioria dos testes verifica que, ao atribuir a [result] ou ao passar um valor para [exit], você retorna o valor esperado.

Alguns testes verificam que você [raise] a exceção esperada.

## Rodando os testes

O utilitário `make` é uma dependência para rodar os testes.

De dentro do diretório do exercício, digite em um console/terminal:

```sh
make
```

Se você ainda não mexeu no arquivo de solução do exercício, vai ver uma mensagem como:

```
Please implement your solution.
```

Então remova essa linha antes de começar a escrever sua solução.

Por padrão, só o primeiro teste é executado.

```text
TAP version 14
1..10
ok 1 - ...
```

Para rodar todos os testes, digite:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

Quando todos os testes passarem, você terminou o exercício e pode enviar a solução.

É possível escolher um único teste para rodar passando o número correspondente, por exemplo:

```sh
make test=2
```

executaria apenas o segundo teste.
