# Introdução

Vamos nos referir à _linguagem_ como **AWK** e ao _executável_ que interpreta programas AWK como **`awk`** ou **`gawk`**.

## Padrões e ações

Um programa AWK é composto por **pares padrão-ação**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

Um **padrão** pode ser uma expressão regular para comparar com a entrada.
Também pode ser qualquer expressão que resulte em um valor verdadeiro/falso.

Uma **ação** é um ou mais comandos AWK.
As chaves ao redor são obrigatórias.

Se o resultado do padrão for _verdadeiro_, a ação correspondente é avaliada.

## Registros e campos

O AWK analisa a entrada como uma série de **registros**.
Cada registro é dividido em zero ou mais **campos**.

O comportamento padrão é:

- dividir a entrada em registros usando a quebra de linha como "separador de registros", então cada _linha_ é um registro.
- dividir o registro em campos usando espaço em branco como "separador de campos", então cada _palavra_ é um campo.

## Padrões e ações, continuação

O padrão pode ser omitido; nesse caso, a ação é avaliada _para cada registro de entrada_.

A ação pode ser omitida; nesse caso, a ação padrão é imprimir o registro atual.

### Padrões especiais

Existem dois padrões especiais usados com frequência.

- `BEGIN` avalia a ação associada antes de consumir qualquer entrada.
- `END` avalia a ação associada depois de consumir toda a entrada.

## Variáveis de campo

Você se refere aos campos como `$1`, `$2`, `$3`, etc.

O registro atual é `$0`.

Veja algumas outras variáveis internas usadas com frequência.

### Variáveis internas que controlam a análise da entrada

- `RS` é o separador de registros da entrada.
  Como mencionado, seu valor padrão é a quebra de linha.
- `FS` é o separador de campos da entrada.

Essas variáveis costumam ser definidas no bloco de ação `BEGIN`.

### Variáveis internas que trazem informações

Essas variáveis são definidas automaticamente pelo AWK durante a execução do programa.

- `NF` guarda o número de campos do registro atual.
  - Para obter o valor do último campo, use `$NF`.
- `NR` guarda o número do registro atual.
  - Quando vários arquivos de entrada estão sendo processados, `NR` contém o número total de registros processados até agora.
- `FNR` guarda o número do registro atual no arquivo de entrada atual.
  - Para ilustrar a diferença entre NR e FNR, veja um idioma comum do AWK.
    ```awk
    NR == FNR {action}
    ```
    Isso significa "se o número acumulado de registros for igual ao número de registros do arquivo atual."
    Isso só pode ser verdadeiro para registros do _primeiro arquivo de entrada_.

## Veracidade

O AWK usa o mesmo conceito de veracidade que o C.

- O número `0` é falso.
- Qualquer outro número é verdadeiro.

Como o AWK é uma linguagem de processamento de texto, os valores de verdade se estendem às strings.

- Uma string vazia `""` é falsa.
- Qualquer string não vazia é verdadeira.

## Comentários

Os comentários começam com o caractere `#` e vão até o fim da linha.

## Exemplos

Em sistemas do tipo Unix, `/etc/passwd` contém informações sobre os usuários.
Cada usuário é descrito em uma linha separada, com os campos separados por dois-pontos.

Para listar os nomes de usuário:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Repare que a ação `{print $1}` não tem padrão, então ela é executada para cada registro.

Se quisermos limitar a saída apenas aos usuários que usam o bash como shell de login, podemos fazer:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
