# Anexo às instruções

## Restrições

Não se subestime usando a biblioteca padrão de ferramentas de coleção. Você pode e deve completar este exercício sem ferramentas como `Array.tryFindIndex`.

## Dicas

Para este exercício, os seguintes recursos do F# são úteis:

- [Recursão de cauda](https://blogs.msdn.microsoft.com/fsharpteam/2011/07/08/tail-calls-in-f/) Evite estouros de pilha com entradas grandes usando recursão de cauda. Embora não existam casos de teste que verifiquem isso explicitamente, usar recursão de cauda leva a uma solução com melhor desempenho. Outro bom recurso sobre recursão de cauda é [este post de blog](http://blog.ploeh.dk/2015/12/22/tail-recurse/).
- [Pattern matching](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/pattern-matching) é extremamente poderoso e ajuda a simplificar lógica condicional com vários ramos.
