# Arrays

`ARRAY{T}` é uma sequência fixa de valores do tipo `T`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## As chaves

`ARRAY{STR}` se lê "array de `STR`". As chaves contêm um **parâmetro de tipo**:
`ARRAY` sozinho não é um tipo, porque um array precisa ser um array de alguma
coisa. Boa parte da biblioteca do Sather é construída assim, e escrever uma
classe dessas por conta própria fica para depois.

## Posições

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

As posições vão de `0` a `.size - 1`. Um array conhece o próprio tamanho e nunca
o altera: não há como acrescentar elementos a um `ARRAY`.

## Criar um sem usar um literal

`#ARRAY{INT}(n)` cria um array com `n` valores, todos iguais a zero:

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

Atribuir a uma posição usa os mesmos colchetes à esquerda do `:=`.

## Fora do intervalo

Ler ou escrever uma posição que não existe não é verificado numa compilação
normal. Isso não vai parar o programa com uma mensagem útil; vai ler ou escrever
o que quer que esteja logo depois na memória. Dois hábitos evitam isso: use
`.size - 1` em vez de um número contado a olho, e termine os laços com
`until!(i >= a.size)` em vez de um literal.

## Imprimir um

`.str` mostra o conteúdo entre chaves, o que é útil enquanto você está
resolvendo alguma coisa:

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
