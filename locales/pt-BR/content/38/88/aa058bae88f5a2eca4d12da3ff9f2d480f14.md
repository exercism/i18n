# Sobre

Swift fornece um tipo embutido chamado [`Bool`][bools] para representar valores de verdade: `true` e `false`.

## Operadores lógicos

Swift fornece três [operadores lógicos][logical-operators] (`!`, `&&` e `||`) para combinar e avaliar expressões Boolean.

### AND lógico (`&&`)

O [operador _and_][and] (`&&`) retorna `true` somente se ambos os operandos forem `true`.
Se qualquer um dos operandos for `false`, ele retorna `false`.
Coloque uma expressão ou um valor Boolean em cada lado do símbolo `&&`:

```swift
true && true  // true
true && false // false
```

### OR lógico (`||`)

O [operador _or_][or] (`||`) retorna `true` se **pelo menos um** dos operandos for `true`.
Ele retorna `false` apenas quando ambos os operandos forem `false`.
Coloque uma expressão ou um valor Boolean em cada lado do símbolo `||`:

```swift
true || true   // true
true || false  // true
false || false // false
```

### NOT lógico (`!`)

O [operador _not_][not] (`!`) inverte um valor Boolean.
Ele retorna `true` se o valor for `false`, e `false` se o valor for `true`.
Coloque o operador `!` imediatamente antes do valor ou da expressão:

```swift
!true  // false
!false // true
```

## Usando parênteses (`()`)

Você pode usar [parênteses][explicit-parentheses] para agrupar expressões e controlar a ordem de avaliação.
Em Swift, as expressões dentro dos parênteses são avaliadas primeiro:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Agrupar com parênteses também determina como o operador NOT se aplica a expressões complexas:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Use parênteses quando precisar deixar clara a ordem de avaliação ou tornar condições complexas mais fáceis de ler.
Evite adicionar parênteses desnecessários quando a precedência padrão já está clara.
~~~~
