# Ajuda

- [The Zig Programming Language Documentation][documentation] é uma ótima visão geral de todos os recursos da linguagem que o Zig oferece para quem o usa.
- [Zig Guide][zig-guide] é uma excelente introdução que explica os recursos da linguagem que o Zig tem a oferecer.
- [Ziglings][ziglings] é altamente recomendado.
  Aprenda Zig corrigindo pequenos programas quebrados.
- [The Zig Programming Language Discord][discord-zig] é o principal [Discord][discord].
  Ele oferece uma ótima forma de entrar em contato com a comunidade Zig como um todo e de conseguir ajuda rápida e direta para qualquer problema relacionado ao Zig.
- [#zig][irc] no irc.freenode.net é o principal canal IRC do Zig.
- [/r/Zig][reddit] é o principal subreddit do Zig.
- [Stack Overflow][stack-overflow] pode ser usado para descobrir trechos de código e soluções para problemas que outras pessoas já podem ter perguntado e talvez resolvido.
