# Introdução

## Erros

Os erros são úteis para avisar quando algo está errado ou inesperado em um programa ou em um trecho de código.

Eles são objetos do JavaScript.

A principal propriedade desse objeto é `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Com a sintaxe `throw`, você pode lançar um erro.

```javascript
throw new Error('Oops');
```

Quando um erro é lançado, a execução atual é interrompida e continua no primeiro bloco catch da pilha de chamadas.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## Herança

Herança é uma forma de criar relações pai-filho entre classes.
A classe filha (às vezes chamada de _subclasse_) tem acesso ao comportamento e aos dados definidos pela classe pai (às vezes chamada de _superclasse_).

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

A palavra-chave `extends` na declaração da classe filha estabelece uma relação com a classe pai por meio da [cadeia de protótipos][prototype-chain].

Os objetos criados pelo construtor da classe filha terão o protótipo da classe pai em sua cadeia de protótipos, o que dá acesso a quaisquer métodos ou dados definidos pela classe pai.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

Assim como qualquer classe em JavaScript, as subclasses podem herdar de `Error` para criar erros personalizados usando a palavra-chave `extends`.
A sintaxe `instanceof` verifica se o erro capturado é uma instância de uma subclasse específica de `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
