# Complemento das instruções

## Dados mutáveis em Prolog

Por padrão, os valores em Prolog são _imutáveis_, ou seja, os valores nunca mudam (você vai precisar introduzir uma nova variável para cada novo valor).
Embora isso seja ótimo para a grande maioria dos casos de uso, este exercício _exige_ a mutação de valores.
Para mutar dados em Prolog, você pode usar o predicado [setarg].

[setarg]: https://www.swi-prolog.org/pldoc/doc_for?object=setarg/3
