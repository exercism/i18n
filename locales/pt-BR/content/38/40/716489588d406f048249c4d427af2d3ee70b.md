# Lista de linguagens

## História

Esta história facilita a exploração de [listas][types-list] em uma linguagem.

A premissa básica é que uma pessoa quer manter uma [lista][types-list] de linguagens que deseja aprender no site do Exercism.

## Tarefas

O exercício geralmente orienta os estudantes sobre como:

- Criar uma lista.
- Adicionar a uma lista.
- Remover de uma lista.
- Contar o comprimento de uma lista.
- Obter o primeiro item de uma lista.
- Verificar se um item pertence a uma lista.
