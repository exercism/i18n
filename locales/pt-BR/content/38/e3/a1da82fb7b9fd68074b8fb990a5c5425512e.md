# Dicas

## Geral

- Há três [operadores Boolean][operators] para trabalhar com valores Boolean.
- É possível combinar vários operadores em uma única expressão.

## 1. Verifique se é possível fazer um ataque rápido

- Os [operadores Boolean][operators] também podem ser aplicados a parâmetros Boolean.
- Ao contrário de muitas outras linguagens, a negação de valores Boolean _não_ é feita com o operador `!`.

[operators]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/boolean-operators
