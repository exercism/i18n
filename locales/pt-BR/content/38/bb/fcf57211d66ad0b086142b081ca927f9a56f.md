# Introdução

## Sobrecarga de métodos

Em Java, a sobrecarga de métodos é um recurso que permite que uma classe tenha mais de um método com o mesmo nome, desde que as listas de parâmetros sejam diferentes.
Ela está relacionada ao polimorfismo em tempo de compilação (ou estático).
Esse conceito é essencial para
criar métodos que realizam tarefas parecidas, mas com entradas diferentes.

### Por que sobrecarregar métodos?

A sobrecarga de métodos aumenta a legibilidade do programa.
Métodos diferentes podem receber o mesmo nome, mas com
parâmetros diferentes.
Dependendo da quantidade de parâmetros ou do tipo dos parâmetros, o método correspondente é chamado.

### Como sobrecarregar métodos?

A chave para a sobrecarga de métodos é a assinatura do método.
Dois métodos são considerados diferentes se tiverem assinaturas diferentes.
Há duas formas de sobrecarregar um método:

1. **Quantidade diferente de parâmetros**: os métodos podem ter o mesmo nome, mas uma quantidade diferente de parâmetros.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Tipos de parâmetros diferentes**: os métodos podem ter o mesmo nome e a mesma quantidade de parâmetros, mas com
   tipos diferentes.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### Pontos para lembrar

- Métodos sobrecarregados precisam alterar a lista de argumentos.
- Métodos sobrecarregados também podem alterar o tipo de retorno, mas apenas alterar o tipo de retorno não constitui
  sobrecarga de métodos.
- Métodos podem ser sobrecarregados na mesma classe ou em uma subclasse.

Neste conceito, vamos explorar vários exemplos e nuances da sobrecarga de métodos em Java.
