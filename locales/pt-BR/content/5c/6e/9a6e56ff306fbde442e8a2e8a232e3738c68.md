# Introdução

O fato de um array também ser uma _coleção_ significa que, além de acessar valores por índice, você pode iterar sobre _todos_ os seus valores usando um laço `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
