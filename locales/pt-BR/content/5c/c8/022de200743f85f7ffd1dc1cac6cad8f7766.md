# Instruções

Neste exercício você vai implementar o tratamento de erros de uma calculadora simples de números inteiros.
Para simplificar, os métodos para calcular adição, multiplicação e divisão já são fornecidos.

O objetivo é ter uma calculadora que funcione e que retorne uma String com o seguinte padrão: `16 + 51 = 67`, quando ela receber os argumentos `16`, `51` e `+`.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. Implemente o método calculate para dar suporte a algumas operações básicas

O método principal a ser implementado nesta tarefa será o método `CalculatorConundrum.calculate()`.
Ele recebe três argumentos.
Os dois primeiros argumentos, `operand1` e `operand2`, são números inteiros sobre os quais uma operação vai atuar.
O terceiro argumento, `operation`, é do tipo String e, para este exercício, é necessário implementar as seguintes operações:

- adição usando a String `+`
- multiplicação usando a String `*`
- divisão usando a String `/`

## 2. Trate operações ilegais

Atualize o método `CalculatorConundrum.calculate()` para tratar operações ilegais:

- Quando o argumento `operation` for `null`, deve ser lançada uma `IllegalArgumentException` com a mensagem `Operation cannot be null`.
- Quando o argumento `operation` for `""`, deve ser lançada uma `IllegalArgumentException` com a mensagem `Operation cannot be empty`.
- Quando o argumento `operation` for qualquer operação diferente de `+`, `*` ou `/`, deve ser lançada uma `IllegalOperationException` com a mensagem `Operation '{operation}' does not exist`.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. Trate a exceção lançada ao dividir por zero

Em Java, tentar dividir por zero lança uma `ArithmeticException`.
Atualize o método `CalculatorConundrum.calculate()` para capturar essa exceção e, em seguida, lançar uma `IllegalOperationException` com a mensagem `Division by zero is not allowed` e a `ArithmeticException` capturada como sua causa.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
