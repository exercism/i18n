# Introdução

## Result

O tipo `Result` é a solução da linguagem Elm para relatar erros e possibilita a recuperação de erros. É um tanto semelhante ao tipo `Maybe`, mas, embora o Maybe possa ser retornado por funções que podem falhar, ele não diz nada sobre por que a falha ocorreu. O Result inclui esse contexto sobre por que algo falhou.

O tipo `Result` é definido da seguinte forma:

```elm
type Result error value
  = Ok value
  | Err error
```

Isso é conhecido como uma definição de "tipo personalizado" na terminologia do Elm.
O `error` e o `value` em `OK value` e `Error error` representam uma variável de tipo, ou seja, ela pode ser de qualquer tipo, como `Int`, `Bool` ou `String`.
Assim, um `Result String Int` é uma variável que deve conter um `Int` e, se houver um erro, ele será representado como uma `String`.
Há um [módulo Result](https://package.elm-lang.org/packages/elm/core/latest/Result) com muitas funções auxiliares úteis para o Result.
