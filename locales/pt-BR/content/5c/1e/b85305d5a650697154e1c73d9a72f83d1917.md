# Instruções

Neste exercício, você vai brincar com um carro de controle remoto, para o qual finalmente juntou dinheiro suficiente para comprar.

Os carros começam com a bateria cheia (100%).
Cada vez que você dirige o carro usando o controle remoto, ele percorre 20 metros e gasta um por cento da bateria.
O apelido do carro só é conhecido quando ele é criado.

O carro de controle remoto tem um display de LED sofisticado que mostra duas informações:

- A distância total percorrida, exibida como: `"<METERS> meters"`.
- A carga restante da bateria, exibida como: `"Battery at <PERCENTAGE>%"`.

Se a bateria estiver em 0%, você não pode mais dirigir o carro e o display da bateria vai mostrar `"Battery empty"`.

## 1. Crie um carro de controle remoto novinho em folha

Implemente a função `new_remote_control_car/0` para retornar um objeto de carro de controle remoto novinho em folha:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Crie um carro de controle remoto novinho em folha com um apelido

Implemente a função `new_remote_control_car/1` para retornar um objeto de carro de controle remoto novinho em folha com um apelido fornecido:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Exiba a distância

Implemente a função `display_distance/0` que recebe um objeto de carro como entrada e retorna a string de distância exibida no display de LED:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Exiba a porcentagem da bateria

Implemente a função `display_battery/0` que recebe um objeto de carro como entrada e retorna a string da porcentagem da bateria exibida no display de LED:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Se a bateria estiver em 0%, o display da bateria vai mostrar "Battery empty".

## 5. Dirigir altera a bateria e a distância percorrida

Implemente a função `drive/0` que:

- recebe um objeto de carro como entrada
- aumenta em 20 o número de metros percorridos
- gasta 1% da bateria
- retorna o objeto de carro modificado

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Lide com a direção com a bateria descarregada

Atualize a função `drive/0` para não aumentar a distância percorrida nem diminuir a porcentagem da bateria quando a bateria estiver descarregada (em 0%):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
