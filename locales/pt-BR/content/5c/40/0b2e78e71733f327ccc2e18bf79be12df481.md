# Introdução

## Erros

Erros acontecem. No Elixir, embora muitas pessoas costumem dizer "let it crash", há momentos em que precisamos resgatar a chamada da função para um estado bom conhecido, a fim de cumprir um contrato de software. Em algumas linguagens, os erros são usados como forma de controle de fluxo, mas no Elixir esse padrão é desencorajado. Muitas vezes conseguimos reconhecer funções que podem lançar um erro só pelo nome: funções que lançam erros têm `!` no final do nome. Isso em comparação com funções que retornam `{:ok, value}` ou `:error`. Veja estes exemplos da biblioteca:

```elixir
Map.fetch(%{a: 1}, :b)
# => :error
Map.fetch!(%{a: 1}, :b)
# => raises KeyError
```

## Try/Rescue

O Elixir oferece uma construção para resgatar erros usando `try .. rescue`

```elixir
try do
  raise RuntimeError, "error"
rescue
  e in RuntimeError -> :error
end
```

Vamos examinar essa construção:

- **Linha 1**, o bloco é declarado com `try`.
- **Linha 2**, a chamada de função que pode dar erro fica aqui; neste caso, estamos chamando `raise/2`.
- **Linha 4**, na seção `rescue`, fazemos pattern matching no nome do _Módulo_ do erro lançado
  - no lado esquerdo de `->`:
    - `e` corresponde à struct de erro.
    - `in` é uma palavra-chave.
    - `RuntimeError` é o erro que queremos resgatar.
      - Se quiséssemos resgatar de todos os erros, poderíamos usar `_` no lugar do nome do módulo ou omitir completamente a palavra-chave `in`.
  - no lado direito:
    - as instruções a serem executadas se o erro corresponder.

### Structs de erro

Os erros (às vezes também chamados de "exceções") que você resgata dessa forma são structs.
Resgatar erros no Elixir é algo muito raro.
Normalmente, o erro resgatado é registrado em log ou enviado a um serviço externo de monitoramento e, em seguida, lançado novamente.
Isso significa que geralmente não nos importamos com a estrutura interna da struct de erro específica.

No [conceito de Exceptions][exercism-exceptions], você vai aprender mais sobre structs de erro, incluindo como definir seu próprio erro personalizado.
