# Dicas

## Geral

- A [documentação da API `Map`][map-docs] contém uma lista dos métodos disponíveis na interface `Map`.

## 1. Retornar os códigos em um map

- Você vai precisar definir um `Map` [de tal forma][declaring-members] que consiga usá-lo nos métodos da classe.

## 2. Adicionar entradas ao dicionário

- Os maps têm um [método][map-put-docs] para adicionar e atualizar o valor de uma chave.

## 3. Consultar o país de um código de discagem

- Os maps têm um [método][map-get-docs] para obter o valor de uma chave.

## 4. Não permitir duplicatas

- Existe uma forma de verificar se o map tem uma [chave][map-contains-key-docs] ou um [valor][map-contains-value-docs].

## 5. Encontrar o código de discagem de um país

- Existe uma [forma][map-entry-set-docs] de obter uma coleção iterável das entradas de um map, o que permite percorrer os pares de chave e valor.

## 6. Atualizar o código de discagem do país

- Não se esqueça de que o código de discagem anterior do país ainda vai estar no map.
- Existe um [método][map-remove-docs] para remover uma entrada do map.
