# Dicas

## Geral

- Leia sobre o [módulo `Agent`][getting-started-agent] no guia de Introdução.
- Leia a documentação sobre o [módulo `Agent`][elixir-doc-agent].
- Assista a [ElixirCasts: Introduction to Agents][elixircasts-agent].

## 1. Abra o jardim

- Revise a documentação do [`Agent`][elixir-doc-agent].
- A função que inicializa o estado do _processo de agent_ precisa retornar o estado inicial.

## 2. Liste os registros

- O módulo [`Agent`][elixir-doc-agent] tem muitas funções para obter o estado atual do _processo de agent_.

## 3. Registre canteiros para uma pessoa

- O módulo [`Agent`][elixir-doc-agent] tem funções para obter e atualizar o estado do _processo de agent_.
- As funções geralmente exigem uma função que transforma o estado e retorna uma forma específica.
- Para acompanhar o id do próximo canteiro a atribuir, o estado do seu _processo de agent_ precisa acompanhar os canteiros e também o próximo id a usar para um canteiro.

## 4. Libere canteiros

- O módulo [`Agent`][elixir-doc-agent] tem funções para obter e atualizar o estado do _processo de agent_.
- As funções geralmente exigem uma função que transforma o estado e retorna o próximo estado.

## 5. Obtenha um canteiro registrado

- O módulo [`Agent`][elixir-doc-agent] tem funções para obter o estado do _processo de agent_.
- Obtenha o canteiro e depois trate o resultado para retornar o resultado correto.
