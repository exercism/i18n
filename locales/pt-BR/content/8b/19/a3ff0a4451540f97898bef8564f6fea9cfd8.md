# Dicas

## 1. Obter a mensagem de uma linha de log

- Extraia o texto que vem depois do _primeiro_ dois-pontos.
  - Você pode usar `index/1` e a notação de slice.
  - Ou explore o uso de funções de expressão regular.
- Use a função `trim` fornecida.

## 2. Obter o nível de log de uma linha de log

- Extraia o texto dentro do primeiro conjunto de colchetes.
- Exiba o resultado em letras minúsculas.

## 3. Reformular uma linha de log

- Reutilize as funções existentes.
- Duas abordagens são usar interpolação de string ou concatenação.
