# Introdução

## Iteradores

Um `Iterator` em Gleam é parecido com uma lista por ser uma coleção ordenada de valores, em que todos os valores são do mesmo tipo. Ele difere de uma lista por ser preguiçoso: não armazena todos os seus valores na memória de uma vez, mas os calcula conforme são necessários.

Isso é útil ao trabalhar com sequências muito grandes ou até infinitas, pois permite trabalhar com elas mesmo quando não há memória livre suficiente para armazená-las todas de uma vez.

O módulo `gleam/iterator` define o tipo `Iterator`, além de funções para trabalhar com iteradores.

Muitas das funções para listas também existem para iteradores, como `map`, `filter` e `take`. Essas funções retornam iteradores, então elas não realizam nenhum trabalho de fato até que o iterador seja consumido.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

A função `unfold` pode ser usada para criar iteradores a partir de uma função chamada repetidamente para produzir o próximo valor da sequência.

Aqui, a função `unfold` é usada para criar um iterador que produz a sequência de Fibonacci:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

A sequência aqui é infinita, então a função `take` é usada para torná-la finita antes de coletar os valores em uma lista. Se `to_list` for chamada em um iterador infinito, o programa vai rodar até ficar sem memória e travar.
