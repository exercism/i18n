# Debug

Quando um teste falha, uma mensagem é exibida descrevendo o que deu errado e para qual entrada. Você também pode contar com o fato de que qualquer [saída no console][programiz.com-basic-input-output] também será mostrada. Você pode escrever no console usando:

```csharp
Console.WriteLine("Debug message");
```
