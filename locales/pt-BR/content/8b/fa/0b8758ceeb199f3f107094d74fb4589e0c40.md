# Representações

O [representador do Java][github-java-representer] aplica as seguintes normalizações:

- Todos os comentários são removidos
- Todas as declarações de import são removidas
- Os identificadores são normalizados para um valor de espaço reservado

Depois de aplicar as normalizações acima, a representação resultante é formatada de acordo com o [Google Java Style][google-java-style], para eliminar quaisquer diferenças restantes na formatação do código.

## Antes de enviar

Verifique os seguintes pontos:

- Você não duplica o feedback dado pelo analisador.
- Você confere a aba "examples" na caixa de diálogo de envio e vê se o feedback faz sentido para todas as abas.
- Você confere que não fez referência a espaços em branco ou a comentários.
- Você confere que não se refere a nomes de funções nem a nomes de variáveis como eles aparecem na solução, mas usa o mapeamento fornecido (ou omite os nomes).
  Só os identificadores usados pelos testes do exercício podem ser citados com segurança, porque eles são sempre os mesmos para todo mundo.
