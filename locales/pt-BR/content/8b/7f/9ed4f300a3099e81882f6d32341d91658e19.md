# Introdução

O ABAP dá suporte a um modelo de programação orientado a objetos baseado em classes e interfaces do ABAP Objects.

## Atribuição (e reatribuição)

Existem algumas formas principais de atribuir valores a nomes em ABAP: usando variáveis ou constantes. No Exercism, as variáveis são sempre escritas em [snake-case][wiki-snake-case]. Não existe um guia oficial a seguir, e várias empresas e organizações têm guias de estilo variados. _Fique à vontade para escrever variáveis como quiser_. A vantagem de escrevê-las do jeito que os exercícios são preparados é que elas serão destacadas de forma diferente na interface web e na maioria das IDEs.

Variáveis em ABAP podem ser definidas usando as palavras-chave [`constant`][constant] ou [`data`][data].

Uma variável pode referenciar valores diferentes ao longo de sua existência quando se usa `data`. Por exemplo, `my_first_variable` pode ser definida e redefinida muitas vezes usando o [operador de atribuição `=`][assignment]:

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

Em contraste com `data`, variáveis definidas com `constant` só podem receber atribuição uma vez. Isso é usado para definir constantes em ABAP.

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## Declarações de classes e métodos

Em ABAP, unidades de funcionalidade são encapsuladas em _métodos_, geralmente agrupando métodos na mesma [classe][classes] quando eles devem ficar juntos. Esses métodos podem receber parâmetros (argumentos) e podem _retornar_ um valor usando a palavra-chave `returning` na definição do método. Os métodos são chamados usando a sintaxe `( )`.

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 Em ABAP há _muitas_ maneiras diferentes de declarar classes e métodos. A trilha tenta apresentá-las gradualmente, mas se você já as conhece, fique à vontade para usar qualquer uma delas. Na maioria dos casos, usar uma ou outra não é melhor nem pior.
