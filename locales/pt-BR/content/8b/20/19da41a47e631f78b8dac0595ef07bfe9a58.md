# Instruções específicas do SQLite

A coluna **result** deve conter um objeto JSON de objetos, com cada palavra como chave e a contagem como número inteiro.

Por exemplo, considere a frase acima: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
O **result** para essa entrada deve ser:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## Esquema da tabela

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
