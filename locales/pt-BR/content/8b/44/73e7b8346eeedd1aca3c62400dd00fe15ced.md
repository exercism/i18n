# Anexo às instruções

## Tarefas bônus

Se você tentar essas tarefas, escreva os seus próprios testes para elas no seu arquivo de solução!

* Defina uma macro de string para que `isbn"3-598-21507-X" == ISBN("3-598-21507-X")`.

* Faça o construtor aceitar também ISBN-13. O mesmo ISBN deve ser considerado igual independentemente do formato: `ISBN("1-234-56789-X") == ISBN("978-1-234-56789-7")`.

* Defina uma função ou um iterador para gerar um ISBN válido, talvez até a partir de um ISBN inicial.

 Você consegue armazenar o ISBN como um número inteiro em vez de uma string, e isso seria alguma vez uma boa ideia?
 Se conseguisse, você ainda poderia imprimir o ISBN (incluindo o dígito verificador) como uma string?
