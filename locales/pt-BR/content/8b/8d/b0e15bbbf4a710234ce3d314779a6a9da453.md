# Instruções

Você está escrevendo um sistema embarcado para uma máquina de tirar senha. É um modelo bem simples. Ela consegue entregar números consecutivos e informar qual foi o último número entregue.

## 1. Inicie a máquina

Implemente a função `start/0`. Ela deve criar um novo processo e retornar o PID do processo. O novo processo ainda não precisa fazer nada.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

Repare que o PID pode ser diferente a cada vez que você rodar este código.

## 2. Reporte o estado da máquina

Modifique a máquina para que o processo recém-criado esteja pronto para receber mensagens (inicie um _laço de receive_) com um estado inicial de `0`. Ela deve ser capaz de receber mensagens `{:report_state, sender_pid}`. Como resposta a essas mensagens, ela deve enviar seu estado atual (o último número de senha entregue) para `sender_pid` e depois aguardar mais mensagens.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. Entregue números

Modifique a máquina para que ela possa receber mensagens `{:take_a_number, sender_pid}`. Ela deve aumentar seu estado em 1, enviar o novo estado para `sender_pid` e depois aguardar mais mensagens.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. Pare a máquina

Modifique a máquina para que ela possa receber uma mensagem `:stop`. Ela deve parar de aguardar mais mensagens.

## 5. Ignore mensagens inesperadas

Modifique a máquina para que, ao receber uma mensagem inesperada, ela a ignore e continue aguardando mais mensagens.
