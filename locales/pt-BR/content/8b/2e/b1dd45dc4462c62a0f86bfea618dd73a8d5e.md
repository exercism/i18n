# Introdução

Existem dois tipos diferentes de números no Gleam: inteiros e números de ponto flutuante.

Os inteiros são números inteiros.

Você também pode adicionar underscores aos inteiros para deixar tudo mais claro.

```gleam
let integer = 3
// -> 3
```

```gleam
1_000_000 // One million
```

O Gleam tem vários operadores que funcionam com inteiros.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
