# Instruções

Depois de uma revisão de segurança recente, pediram para você limpar os arquivos de log arquivados da organização.

## 1. Identificar linhas de log corrompidas

Você precisa ter uma ideia de quantas linhas de log do seu arquivo não estão de acordo com os padrões atuais.
Você acredita que um teste simples revela se uma linha de log é válida.
Para ser considerada válida, uma linha deve começar com uma das seguintes strings:

- `[DEBUG]`
- `[INFO]`
- `[WARNING]`
- `[ERROR]`

Implemente a função `is_valid_line` para retornar `True` se a linha de log for válida.

```gleam
log_parser.valid_line("[ERROR] Network Failure")
// -> True

log_parser.valid_line("Network Failure")
// -> False
```

## 2. Dividir a linha de log

Pouco depois de começar o projeto de análise de logs, você percebe que os logs de uma aplicação não estão divididos em linhas como os das outras. Neste projeto, o que deveria ser linhas separadas está em uma única linha, conectado por setas rebuscadas como `<--->` ou `<*~*~>`.

Na verdade, qualquer string que tenha `<` como primeiro caractere, `>` como último caractere e zero ou mais dos seguintes caracteres `~`, `*`, `=` e `-` entre eles pode ser usada como separador nos logs deste projeto.

Implemente a função `split_line` que recebe uma linha e retorna uma lista de strings.

```gleam
log_parser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
// -> ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Marcar linhas com nomes de usuário

Você notou que algumas linhas de log incluem frases que se referem a usuários.
Essas frases sempre contêm a string `"User"`, seguida de um ou mais caracteres de espaço em branco e, em seguida, um nome de usuário.
Você decide marcar essas linhas.

Implemente uma função `tag_with_user_name` que processa linhas de log:

- As linhas que não contêm a string `"User"` permanecem inalteradas.
- Para as linhas que contêm a string `"User"`, coloque como prefixo da linha `[USER]` seguido do nome de usuário.

```gleam
log_parser.tag_with_user_name("[INFO] User Alice created a new project")
// -> "[USER] Alice [INFO] User Alice created a new project"
```

Você pode assumir que:

- Cada ocorrência da string `"User"` é seguida de um ou mais caracteres de espaço em branco e do nome de usuário.
- Há no máximo uma ocorrência da string `"User"` em cada linha.
- Os nomes de usuário são strings não vazias que não contêm espaços em branco.
