# Fluxo de trabalho de publicação

O fluxo de trabalho de publicação serve para publicar as [ferramentas da track](/docs/building/tooling) em:

1. [Docker Hub](https://hub.docker.com/): usado em scripts ou para testes locais.
   Disponível publicamente.
2. [ECR](https://aws.amazon.com/ecr/): usado no ambiente de produção para testar as soluções enviadas.
   Privado.

## Fonte

O fluxo de trabalho está definido no arquivo `.github/workflows/deploy.yml`.
