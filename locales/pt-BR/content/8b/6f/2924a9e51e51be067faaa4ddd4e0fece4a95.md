# Introdução

## Recursão

Funções recursivas são funções que chamam a si mesmas.

Uma função recursiva precisa ter pelo menos um _caso base_ e pelo menos um _caso recursivo_.

Um _caso base_ retorna um valor sem chamar a função de novo.
Um _caso recursivo_ chama a função de novo, modificando a entrada para que ela, em algum momento, corresponda ao caso base.

Em Elm, funções recursivas costumam ser definidas usando pattern matching com expressões `case` ou várias cláusulas de função.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### Laços por meio de recursão

Por causa da imutabilidade, os laços em Elm são escritos de forma diferente das linguagens imperativas.
Por exemplo, um laço normalmente se parece com isto:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Em uma linguagem funcional como Elm, não é possível alterar variáveis.
Por isso, os laços precisam ser implementados com recursão.

O equivalente a um laço `for` em Elm ficaria assim:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

Na prática, iterar sobre listas e outras estruturas de dados em Elm geralmente é feito com funções do módulo `List`, como `List.map`, `List.filter` e `List.foldl`.
Por baixo dos panos, essas funções são implementadas com recursão.
