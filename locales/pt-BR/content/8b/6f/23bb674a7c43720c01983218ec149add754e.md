# Introdução

## Funções externas

O Gleam pode rodar na máquina virtual do Erlang (BEAM) ou em ambientes de execução JavaScript. Existem muitas outras linguagens que usam esses ambientes de execução, e muitas vezes é útil poder chamar, a partir do Gleam, código escrito nessas linguagens.

O recurso de _funções externas_ do Gleam permite que funções escritas em outras linguagens sejam importadas para o Gleam e chamadas sem nenhum custo adicional em tempo de execução.

Se o seu projeto Gleam roda na máquina virtual do Erlang e você quer chamar a função `reverse` do módulo `lists` do Erlang, você pode fazer isso adicionando o atributo `@external` ao cabeçalho de uma função Gleam, assim:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Depois disso, ela pode ser chamada como qualquer função Gleam normal:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Se você tentar compilar esse código para ambientes de execução JavaScript, vai receber uma mensagem de erro, porque não existe implementação para JavaScript. Você pode especificar outra implementação para ambientes de execução JavaScript assim:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Também é possível escrever uma implementação em Gleam que será usada quando não houver implementação externa para o alvo de compilação atual:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## Tipos externos

Tipos externos podem ser usados para se referir a tipos de dados definidos em outras linguagens, como Erlang ou JavaScript.

Para definir um tipo externo, declare um tipo sem fornecer nenhum construtor. Depois disso, ele pode ser usado da mesma forma que qualquer outro tipo.

```gleam
pub type OrderedDictionary(element)
```
