# Introdução

Filtragem é o processo de criar uma sequência a partir de outra sequência, copiando todos os elementos da sequência original, exceto alguns deles.
A escolha de quais itens incluir na nova sequência pode ser feita por uma função de predicado (uma função que resulta em um valor Boolean) ou por igualdade com um objeto específico.

## Removendo por um predicado

`remove-if` é uma função que recebe como argumentos uma função de predicado e uma sequência, e retorna uma sequência apenas com os elementos para os quais o predicado resultou em um valor falso.
Em outras palavras, ela "remove" todos os elementos da sequência para os quais o predicado resulta em verdadeiro. No entanto, repare que essa função não modifica a sequência original! 
Em vez disso, ela retorna uma nova sequência sem os elementos em questão. Se o predicado foi verdadeiro para todos os valores, o resultado é uma sequência vazia.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Removendo um item específico

Se você quiser remover um item específico de uma sequência, pode usar `remove`, que recebe o item a remover e uma sequência.
São retornados todos os valores da sequência que não são iguais ao item a remover.
OBSERVAÇÃO: por padrão, a igualdade é verificada com o [predicado de igualdade genérico][concept-equality] `eql`.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
