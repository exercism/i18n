# Instruções

Sua tarefa é criar um verificador de senha.
Um verificador de senha valida a senha proposta por um usuário. Ele garante que ela atenda a um conjunto de requisitos definidos pela organização que controla o acesso ao recurso em questão.

Para este exercício, os requisitos da senha são:
* Deve ter 12 caracteres ou mais
* Deve ter pelo menos uma letra maiúscula
* Deve ter pelo menos uma letra minúscula
* Deve ter pelo menos um dígito
* Deve ter pelo menos um símbolo do conjunto !@#$%^&*

Sua solução deve usar um `Result` para encapsular o status de sucesso ou de falha.
No caso de sucesso, o `Result` deve transmitir a senha validada como string.
No caso de falha, o `Result` deve transmitir a regra que foi violada.

~~~~exercism/note
Para este exercício, o verificador de senha será simplista: ele vai indicar apenas quando uma única regra foi violada.
Um exercício posterior vai explorar um verificador de senha mais realista, capaz de indicar quando várias regras foram violadas ao mesmo tempo.
~~~~

## 1. Implemente a função `checkPassword`

A função `checkPassword` verifica a senha fornecida de acordo com as regras mencionadas acima. Em caso de falha, ela indica a regra que foi violada, encapsulando um dos valores de `PasswordRule` dentro do valor de resultado.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. Implemente a função ``getStatusMessage`

A função `getStatusMessage` retorna uma string contendo uma mensagem legível por humanos que indica o significado do resultado retornado por `checkPassword`.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
