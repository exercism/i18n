# Introdução

No Elixir, para escolher um elemento aleatório de uma estrutura de dados enumerável (por exemplo, uma lista ou um intervalo), usamos `Enum.random`. Essa função escolhe um único elemento, e todos os elementos têm a mesma probabilidade de serem escolhidos.

O Elixir não tem funções próprias para escolher um número de ponto flutuante aleatório. Para isso, precisamos usar o Erlang diretamente.
