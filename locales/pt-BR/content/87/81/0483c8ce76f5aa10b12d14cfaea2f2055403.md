# Apêndice das instruções

## Palavras

`find-fewest-coins ( coins target -- result )` retorna um array
de denominações de moedas cuja soma é `target`. `coins` é um hash
set (por exemplo, `HS{ 1 5 10 25 }`); use as palavras do vocabulário
`sets` (`members`, `in?`, …) para trabalhar com ele.

Quando nenhuma combinação de `coins` consegue formar `target`, lance um
erro `cannot-make-change`.
