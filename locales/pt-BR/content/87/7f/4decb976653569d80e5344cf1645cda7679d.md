# Dicas

## Geral

- Uma função pode ser definida para receber vários argumentos empacotados juntos usando o parâmetro `*args` para argumentos do tipo `list` e `tuple`, ou o parâmetro `**kwargs` para argumentos de dicionário/palavra-chave.
- Para empacotar ou desempacotar, use o operador `*` ou `**`.

## 1. Crie uma lista de todos os vagões

- Vários argumentos nos parâmetros da função podem ser empacotados com o operador `*args`.

## 2. Conserte a lista de vagões

- Usar desempacotamento com o operador `*` permite extrair os dois primeiros elementos de uma `list` mantendo o restante intacto.
- Para adicionar outra `list` a uma `list` existente, você pode usar o operador `*` para "espalhar" a `list`.

## 3. Adicione paradas que faltam

- Usar `**kwargs` como parâmetro de função permite que um número arbitrário de argumentos de palavra-chave seja passado.
- Usar `**<dict>` como argumento irá desempacotar um dicionário em argumentos de palavra-chave.
- Você pode colocar argumentos de palavra-chave em um `{}` ou `dict()`.
- Para obter os valores de um dicionário, você pode usar o método `<dict>.values()`.

## 4. Estenda as informações de roteamento

- Usar `**<dict>` como argumento irá desempacotar um dicionário em argumentos de palavra-chave.
- Você pode colocar argumentos de palavra-chave em um `{}` ou `dict()`.

## 5. Conserte o depósito de vagões

- `zip(*iterators)` pode ser usado para transpor uma `list` aninhada.
- Para extrair dados de iteradores zipados, você pode usar um laço `for`.
- Você também pode desempacotar iteradores zipados usando `*`.
  `[*content] = zip(iterator_1, iterator_2)` irá descompactar a `tuple` produzida por `zip()` em uma `list`.
