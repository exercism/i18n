# Introdução

A desestruturação é uma forma de separar valores compostos em Rust. Ela costuma ser usada para extrair campos de tuplas ou structs.

Por exemplo, o trecho abaixo extrai dois valores de uma tupla:

```rust
let (first, second) = (1, 2);
```

O valor `1` é vinculado à variável `first`.
O valor `2` é vinculado à variável `second`.
