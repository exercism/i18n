# Sobre strings

Uma [`string`][ref-string] em Kotlin é uma sequência imutável de caracteres Unicode.

[`Immutable`][wiki-immutable] significa que qualquer operação em uma string precisa retornar uma nova string: a string original nunca pode mudar.

[`Unicode`][wiki-unicode] significa que a maioria dos sistemas de escrita do mundo pode ser representada, mas (ao contrário de linguagens mais antigas, como C) não existe uma correspondência 1:1 entre caracteres e bytes.
Isso será discutido mais adiante no Conceito [`Chars`][concept-chars].

Uma string fica entre aspas duplas `" "`.

Alguns caracteres precisam de escape: `\\`, além dos habituais caracteres não imprimíveis, como `\t` (tabulação) e `\n` (nova linha).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Strings de várias linhas ficam entre 3 aspas duplas e podem conter qualquer texto (sem necessidade de escape).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Use [trimIndent][trimIndent-doc] para remover a indentação comum das linhas.
Isso é útil para formatar a string:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Como alternativa, [trimMargin][trimMargin-doc] permite especificar um delimitador.
Cada linha na `String` então começa depois do delimitador.
O delimitador padrão é `|`, mas você pode especificar um delimitador diferente como parâmetro.
Por exemplo:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Strings podem ser concatenadas com `+`, mas é melhor limitar isso a casos curtos e simples.
Existem outras opções, muitas vezes melhores.

## Templates de string

[`Templates`][ref-templates] se refere ao que outras linguagens chamam de "interpolação".

Se uma string contém um cifrão `$` seguido de um identificador, ou contém chaves (`{expression}`) em volta de uma expressão, esses elementos são substituídos, respectivamente, pelo valor ou pelo resultado da expressão.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## Formatação de string

Na plataforma JVM (somente), `String.format()` permite uma formatação mais precisa do que os templates de string, com uma [sintaxe][web-formats] semelhante à das funções [`printf`][wiki-printf] (_muito antigas!_).

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## Funções de string

Kotlin oferece _muitas_ [`functions`][ref-string-functions] para manipular strings.

Na maioria, são [`extensions functions`][ref-extensions] e não membros da classe `String`, embora isso tenha pouca influência na forma como as usamos.

~~~~exercism/note
As páginas de [documentação][ref-string-functions] do Kotlin, bastante complexas, escondem as funções de extensão na visualização padrão.
No momento em que isto foi escrito, o conteúdo mais valioso estava escondido em uma aba chamada `Members & Extensions`.
Clique nela para expandir essa seção e ver todos os membros e as extensões disponíveis na classe `String`.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

O exemplo a seguir mostra apenas uma pequena seleção do que está disponível:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## Construindo uma string

Às vezes, uma string longa precisa ser construída em etapas, por exemplo, dentro de um laço.

Concatenar strings com `+` logo deixa de ser elegante ou performático: a imutabilidade significa que há _muita_ cópia envolvida.

Kotlin tem várias maneiras mais eficientes de combinar várias strings:

- Templates de string, descritos acima.
- [`joinToString()][ref-jointostring], que será abordado no Conceito [Listas][concept-lists].
- O [`StringBuilder`][ref-stringbuilder] do Java, que não é considerado particularmente idiomático em Kotlin.
- O [`buildString()`][ref-buildstring] do Kotlin, que envolve o `StringBuilder` em uma sintaxe mais concisa e idiomática.
Ele recebe a lógica de construção da string como argumento lambda, o que será discutido em um Conceito mais adiante.

Em essência, um `StringBuilder` é uma estrutura semelhante a uma lista, com muitos métodos convenientes.
Esta é uma pequena seleção:

- [`append()`][ref-sb-append] para adicionar ao final.
- [`insert()`][ref-sb-insert] para adicionar em uma posição especificada.
- [`deleteAt()`][ref-sb-deleteat] e [`deleteRange()`][ref-sb-deleterange] para remover de posição(ões) especificada(s).
- `toString()` para converter em uma string normal no final: concatenando tudo em uma única operação performática.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Um exemplo com `buildString()`, usando a sintaxe de Conceitos posteriores:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
