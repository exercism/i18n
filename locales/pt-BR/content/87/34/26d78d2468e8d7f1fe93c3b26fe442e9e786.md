# Configure as ferramentas

Há três ferramentas que você pode ajustar na sua trilha:

- O **[Contador de linhas de código](/docs/building/tooling/lines-of-code-counter)**: essa ferramenta conta as linhas de código de cada iteração enviada.
- O **[Extrator de snippets](/docs/building/tooling/snippet-extractor)**: essa ferramenta extrai um snippet de cada iteração. Esse snippet aparece no site.
- A **[Exercism CLI](/docs/building/tooling/cli)**: essa ferramenta é usada pelos estudantes para trabalhar em uma trilha localmente, na própria máquina.

```exercism/note
Ajustar essas ferramentas é opcional, mas deixa a integração da sua trilha com o site _muito_ melhor.
Por isso, recomendamos fortemente que você ajuste as três.
```
