# Dicas

## 1. Defina o tipo externo `GbTree`

- Tipos externos podem ser definidos com a sintaxe `pub type TypeName(a, b, c)`.

## 2. Defina a função `new_gb_tree`

- Funções externas podem ser definidas com a sintaxe `@external(erlang, "module", "function")`.
- A função deve usar `gb_trees:empty/0`.

## 3. Defina a função `insert`

- Consulte a documentação de `gb_trees:insert/3` para confirmar a ordem correta dos argumentos.
- A função externa pode ser uma função privada chamada pela função `insert` para mudar a ordem dos argumentos.
- A função deve usar `gb_trees:insert/3`.

## 4. Defina a função `delete`

- Consulte a documentação de `gb_trees:delete_any/2` para confirmar a ordem correta dos argumentos.
- A função externa pode ser uma função privada chamada pela função `delete` para mudar a ordem dos argumentos.
- A função deve usar `gb_trees:delete_any/2`.
- A função `gb_trees:delete/2` quebra se a chave não for encontrada, então ela não deve ser usada.
