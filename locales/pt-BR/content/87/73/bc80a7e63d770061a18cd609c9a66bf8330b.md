# Anexo de instruções

## Palavras

Defina uma tupla `rat` com os slots `numerator` e `denominator`.
`<rat>` deve reduzir seus argumentos à forma irredutível, com o
sinal no numerador (assim, o denominador é sempre positivo).

- `<rat> ( numerator denominator -- rat )`: constrói um racional reduzido.
- `>rat ( pair -- rat )`: constrói um `rat` a partir de `{ numerator denominator }`.
- `rat>pair ( rat -- pair )`: retorna `{ numerator denominator }`.
- `r+ ( a b -- c )`, `r- ( a b -- c )`, `r* ( a b -- c )`,
  `r/ ( a b -- c )`: operações aritméticas entre dois racionais.
- `r-abs ( a -- |a| )`: valor absoluto.
- `r^ ( a n -- a^n )`: eleva um racional a uma potência inteira
  (expoentes negativos permitidos).
- `real^r ( x a -- y )`: eleva um número real a um expoente racional
  e retorna um número de ponto flutuante.

Os genéricos `MATH:` do Factor (`+`, `-`, `*`, `/`) só fazem dispatch sobre
a hierarquia matemática embutida, então este exercício usa nomes de palavras
dedicados em vez de métodos nesses genéricos.
