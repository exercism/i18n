# Anexo das instruções

Existem muitas formas de resolver este exercício, mas preparamos este exercício para quem quer praticar a escrita dos próprios [manipuladores de ability][ability-handler-docs].

Escreva uma ability `Zipper` que permite navegar por uma estrutura de dados de árvore binária.

A ability `Zipper` em si já está definida para você, mas você vai precisar implementar o manipulador que permite que ela navegue pela estrutura de dados de árvore binária designada.

Dada a seguinte árvore binária, se chamarmos `Zipper.right`, `Zipper.right`, `Zipper.up` e depois `Zipper.left`, devemos parar no nó com valor `5`.

```
     1
   /   \
  2     4
 /     /  \
3     5    7
```

Para os fins deste exercício, se você chamar `left` ou `right` em uma árvore binária que não tem um ramo esquerdo ou direito, pode retornar o valor do nó atual.
