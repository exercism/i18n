# Instruções

É mais uma noite movimentada no pátio de manobras de Antuérpia. Você é o
despachante de plantão: os vagões de carga que chegam precisam ser
reagrupados em trens de saída, os engates inspecionados, as rotas divididas
nas junções, e as cargas idênticas reunidas para a fatura.

Cada *vagão* é uma string que diz o que ele está transportando:
`"coal"`, `"timber"`, `"crates"` etc.

## 1. Engate os vagões em trens

Defina `couple` para receber um array de vagões e um comprimento `n`, e
retornar trens que não se sobrepõem, com `n` vagões cada. O último trem
pode ficar menor se a quantidade não dividir por igual.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Dê uma espiada nos engates

Defina `peek-couplings` para receber um array de vagões e retornar todos os
pares adjacentes, para que o inspetor possa examinar cada engate.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Divida a corrente nas junções

Defina `split-at-junctions` para receber um array de vagões e um
array de `junctions` (vagões que marcam um ponto de divisão), e retornar
os trechos entre os vagões de junção. Os próprios vagões de junção não são
mantidos.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Reúna as cargas idênticas

Defina `coalesce-cargo` para receber um array de vagões e agrupar em
sequências os vagões *consecutivos* que carregam a mesma carga.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
