# Introdução

Este é potencialmente um assunto _grande_!
É possível escrever um livro longo sobre ele, e várias pessoas já o fizeram (procure "unicode book" na Amazon para ver alguns exemplos).

## Uma breve história

Lidar com caracteres em computadores era muito mais simples em décadas passadas, quando os programadores presumiam que o inglês era a única língua importante.
Então: 26 letras, maiúsculas e minúsculas, 10 dígitos, vários sinais de pontuação, mais um código (0x07) para tocar um sino, e tudo cabia em 7 bits: o conjunto de caracteres [ASCII][wiki-ascii].

Naturalmente, as pessoas começaram a perguntar e o que dizer de à, ä e Ł, depois outras pessoas começaram a perguntar sobre ऄ, ஹ e ญ, e os jovens queriam emojis 😱.
O que fazer?

Para encurtar uma longa história, muitas pessoas inteligentes e pacientes tiveram que participar de comitês por anos, definindo os detalhes do conjunto de caracteres [Unicode][web-unicode] e de codificações como [UTF-8][wiki-utf-8], e muito software precisou de uma reescrita _muito_ complicada.
Além disso, muitos bugs novos foram introduzidos.

Para evitar que _tudo_ quebrasse, o design do Unicode/UTF-8 garante que os primeiros 127 códigos sejam idênticos ao ASCII _(até o sino)_.

## Caracteres em Kotlin

Linguagens criadas depois de aproximadamente 2005 têm a enorme vantagem de que já existia um padrão Unicode razoavelmente estável.

Kotlin (lançada pela primeira vez em 2011) pôde presumir que os usuários usariam uma variedade de línguas (humanas) e precisariam do Unicode para expressá-las.

Literais de caractere são escritos entre aspas simples e são distintos de strings escritas entre aspas duplas.
Isso provavelmente é óbvio para quem vem do mundo C/C++, mas pode ser confuso para programadores de Python e JavaScript.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

Converter entre `Char` e `Int` é simples:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

O compilador permite _algumas_ formas de aritmética de inteiros com `Char`s:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Algumas funções para `Char`

Como sempre, há [muitas funções][ref-char-lib] demais para discutir aqui, então esta é apenas uma seleção.

- Para alfabetos apropriados, altere maiúsculas e minúsculas com [`uppercase()`][ref-uppercase] e [`lowercase()`][ref-lowercase].
- Teste maiúsculas e minúsculas com [`isUpperCase()`][ref-isuppercase] e [`isLowerCase()`][ref-islowercase].
- Teste o tipo do caractere com:
    - [`isLetter()`][ref-isletter], cobre muitos alfabetos
    - [`isDigit()`][ref-isdigit], no intervalo 0..9
    - `isLetterOrDigit()`, combina as duas anteriores
    - [`isWhitespace()`][ref-iswhitespace], qualquer caractere de espaço em branco

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Conversões entre lista de Char e String

Para converter de String para lista de Char, podemos usar `toList()`.

Para converter de lista de Char para String, existe a função [`joinToString()`][ref-jointostring], que recebe um separador (muitas vezes a string vazia) como argumento.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Observe que `joinToString()` opera sobre uma List ou Array.
Para _converter_ um único `Char` em uma string de 1 caractere, use `toString()`.

```kotlin
'a'.toString() // => "a"
```

Para verificar se um caractere está presente em uma `String`, ou em uma lista ou array de `Char`, temos `in`, que corresponde à função [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
