# Introdução

Os `Integer` guardam qualquer número, por maior que seja, até o limite da memória da sua máquina, enquanto o `Int` corresponde ao conjunto dos números inteiros positivos e negativos que podem ser expressos em 32 ou 64 bits (com garantia de pelo menos -2^29 a 2^29).

O `Float` corresponde ao conjunto dos números reais, limitado pela precisão do computador.
As operações definidas sobre números geralmente funcionam com um tipo ou com o outro, mas não com os dois.

As funções para converter entre `Float` e `Integer` incluem, entre outras, `toFloat`, que converte `Int`/`Integer` para `Float`, e `ceiling`, que converte um `Float` para um `Int`.

A conversão de um tipo inteiro (`Int` ou `Integer`) para qualquer outro tipo numérico é feita com a função `fromIntegral`.
O tipo de destino é inferido automaticamente.
Por exemplo:

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
