# Introdução

Uma `List` é muito semelhante a um `Array`. No entanto, há diferenças importantes que você não vai querer pular:

1. Uma lista não pode ser indexada usando colchetes, ou seja, `[0]`.
2. Uma lista não pode ser inicializada.
3. Não existem compreensões de lista.
4. Uma lista permite modificar elementos livremente durante a iteração sobre eles.

`List` é um membro do pacote `haxe.ds`, então, sempre que você quiser usar listas, precisa importar o pacote:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
