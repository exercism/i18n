# Instruções

Neste exercício, você vai processar linhas de log.

Cada linha de log é uma string formatada assim: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Você tem três tarefas, e cada uma delas recebe uma linha de log e pede que você faça algo com ela.

## 1. Obtenha a mensagem de uma linha de log

Implemente o método (_static_) `LogLine.Message()` para retornar a mensagem de uma linha de log:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Qualquer espaço em branco no início ou no final deve ser removido:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Obtenha o nível de log de uma linha de log

Implemente o método (_static_) `LogLine.LogLevel()` para retornar o nível de log de uma linha de log, que deve ser retornado em minúsculas:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Reformate uma linha de log

Implemente o método (_static_) `LogLine.Reformat()` que reformata a linha de log, colocando a mensagem primeiro e o nível de log depois dela entre parênteses:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
