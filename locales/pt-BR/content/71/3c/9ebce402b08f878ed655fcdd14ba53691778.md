Você tem a tarefa de escrever um serviço que ingere eventos. Cada evento tem uma data associada, mas você percebe que 3 formatos diferentes estão sendo enviados para o endpoint do seu serviço:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

Você percebe que existem algumas semelhanças entre eles e decide escrever alguns padrões de expressão regular que podem ser compostos.

## 1. Encontre o dia, o mês e o ano de uma data

Implemente `day`, `month` e `year` para retornar um padrão de string que, quando executado, corresponde aos componentes numéricos em `"01/01/1970"` (`dd/mm/yyyy`). O dia e o mês podem aparecer como `1` ou `01` (com zero à esquerda).

Não se preocupe com a verificação de erros. Considere que você sempre receberá um componente numérico válido.

```clojure
(day "31")
;;=> "31"
(month "12")
;;=> "12"
(year "1970")
;;=> "1970"
```

## 2. Encontre o dia da semana e o mês do ano

Implemente `day-name` e `month-name` para retornar um padrão de string que, quando executado, corresponde a qualquer dia da semana nomeado e ao mês nomeado do ano, respectivamente.

```clojure
(day-name "Tuesday")
;;=> "Tuesday"
(month-name "June")
;;=> "June"
```

## 3. Capture o dia, o mês e o ano

Implemente `capture-day`, `capture-month`, `capture-year`, `capture-day-name` e `capture-month-name` para retornar um mapa que associa os respectivos componentes aos nomes: `"day"`, `"month"`, `"year"`, `"day-name"`, `"month-name"`

```clojure
(capture-month-name "December")
;;=> {:month-name "December"}
```

## 4. Combine as capturas para capturar a data inteira

Implemente `capture-numeric-date`, `capture-month-name-date` e `capture-day-month-name-date` para retornar um mapa com os componentes da parte 3, usando o respectivo formato de data.

```clojure
(capture-numeric-date "01/01/1970")
;;=> {:day "01", :month "01", :year "1970"}
```
