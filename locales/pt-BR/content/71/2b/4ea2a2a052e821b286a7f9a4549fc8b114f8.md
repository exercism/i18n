# Instruções

Neste exercício, você vai implementar as mecânicas de um jogo de RPG.
O personagem de um jogador é representado pelo seguinte tipo:

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

Os jogadores deste jogo precisam alcançar o nível 10 antes de desbloquear um reservatório de mana, para só então começarem a lançar feitiços.
Você vai trabalhar em duas funcionalidades deste jogo: a mecânica de reviver e a mecânica de lançar feitiços.

## 1. Apresente-se

Escreva o conteúdo da função `introduce`.
Jogadores furtivos podem estar escondendo o nome e serão apresentados como `"Mighty Magician"`.
Caso contrário, use apenas o seu nome para se apresentar.

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. Implemente a mecânica de reviver

A função `revive` deve verificar se o personagem do jogador está de fato morto (a saúde dele chegou a 0).
Se estiver, ela deve retornar uma nova instância de `Player` com 100 de saúde.
Caso contrário, se o personagem do jogador não estiver morto, a função `revive` retorna `Nothing`.

Se o nível do jogador for 10 ou mais, ele também deve ser revivido com 100 de mana.
Se o nível do jogador for menor que 10, a mana dele deve ser `Nothing`.
A função `revive` deve preservar o nível do jogador.

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

Se o método `revive` for chamado em um jogador cuja saúde é 1 ou mais, então a função deve retornar `Nothing`.

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. Implemente a mecânica de lançar feitiços

A função `castSpell` recebe como argumentos um `Int` indicando quanta mana o feitiço custa, além de um `Player`.
Ela retorna o jogador atualizado, bem como a quantidade de dano que o feitiço lançado causa.
Um feitiço lançado com sucesso causa dano igual a duas vezes o custo de mana do feitiço.
No entanto, se o jogador não tiver mana suficiente, nada acontece: o jogador permanece igual e nenhum dano é causado.
Se o jogador nem sequer tiver um reservatório de mana, tentar lançar o feitiço deve diminuir a saúde dele no valor do custo de mana do feitiço e não causa dano.

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
