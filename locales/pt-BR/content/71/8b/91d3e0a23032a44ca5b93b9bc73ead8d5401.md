# Instruções

Neste exercício, você vai gerenciar um sistema de inventário.

O inventário deve ser organizado pelo nome do item e deve manter o controle da quantidade de itens disponíveis.

Você vai precisar lidar com a adição de itens a um inventário.
Cada vez que um item aparecer em uma determinada lista, a quantidade desse item no inventário deve aumentar em `1`.
Você também vai precisar lidar com a remoção de itens de um inventário, diminuindo as quantidades em `1` quando solicitado.

Por fim, você vai precisar implementar uma função que retorne todos os pares chave-valor de um determinado inventário como uma `list` de `tuples`.


## 1. Crie um inventário a partir de uma lista

Implemente a função `create_inventory(<input list>)`, que cria um "inventário" a partir de uma lista de itens de entrada.
Ela deve retornar um `dict` contendo cada nome de item junto com sua respectiva quantidade.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Adicione itens de uma lista a um dicionário existente

Implemente a função `add_items(<inventory dict>, <item list>)`, que adiciona uma lista de itens ao inventário passado:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Decremente itens do inventário

Implemente a função `decrement_items(<inventory dict>, <items list>)`, que recebe uma `list` de itens.
Sua função deve remover `1` da contagem de um item para cada vez que esse item aparecer na `list`:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

As contagens de itens no inventário não podem ficar abaixo de 0.
 Se o número de vezes que um item aparece na `list` de entrada exceder a contagem disponível, a quantidade registrada para esse item deve permanecer em 0.
 As solicitações adicionais para remover contagens devem ser ignoradas depois que a contagem chegar a zero.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Remova uma entrada por completo do inventário

Implemente a função `remove_item(<inventory dict>, <item>)`, que remove um item e sua contagem por completo de um inventário:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Se o item não for encontrado no inventário, a função deve retornar o inventário original sem alterações.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. Retorne todo o conteúdo do inventário

Implemente a função `list_inventory(<inventory dict>)`, que recebe um inventário e retorna uma lista de `tuples` no formato `(item, quantity)`.
A lista deve incluir apenas os itens _disponíveis_ (_com quantidade maior que zero_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
