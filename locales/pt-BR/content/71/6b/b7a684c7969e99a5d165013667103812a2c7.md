# Anexo das instruções

## Dicas

Para completar este exercício, você precisa criar o tipo de dados `Allergen`, com instâncias de `Eq` e `Show`, e implementar as seguintes funções:

- `allergies`
- `isAllergicTo`

Você vai encontrar uma declaração de dados de exemplo e assinaturas de tipo já prontas, mas definir as funções e criar um tipo de dados, um newtype ou um sinônimo de tipo que faça sentido é com você.
