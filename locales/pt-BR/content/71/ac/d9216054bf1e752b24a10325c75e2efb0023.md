# Introdução

A maioria das palavras de sequência do Factor retorna *novas* sequências e não mexe nos valores de entrada. Mas arrays e vectors também oferecem **mutação no local** quando você quer registrar um estado que evolui ao longo do tempo.

`set-nth` e `change-nth` alteram uma posição no local e funcionam tanto com um array quanto com um vector. `<array>` cria um array mutável de comprimento fixo; os literais `V{ }`, `<vector>`, `push` e `pop` formam o conjunto exclusivo dos vectors, já que arrays não podem mudar de comprimento. `clone` duplica a sequência para que mutações posteriores não vazem para a original.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```
