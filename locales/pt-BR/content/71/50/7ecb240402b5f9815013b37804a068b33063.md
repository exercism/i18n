# Testes

## Executando os testes

Quando você estiver no diretório de um exercício, você deve ver dois subdiretórios:

* `Sources/<Exercise>` contém a sua solução para o exercício
* `Tests/<Exercise>Tests` contém os testes a serem executados para o exercício

Se você estiver no diretório certo (ou seja, o que contém `Sources` e `Tests`), você pode rodar os testes desse exercício executando `swift test`:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Quando você conseguir fazer um teste passar, remova `.enabled(if: RUNALL)` na instrução `@Test` para habilitar o próximo teste. Como alternativa, você pode rodar todos os testes com a variável de ambiente `RUNALL` definida como `true` no Linux ou no macOS:

```bash
$ export RUNALL=true
```

Ou, se você estiver usando o PowerShell no Windows:

```powershell
set RUNALL=true
```

## Enviando sua solução

Para enviar uma solução ao Exercism, você precisa estar no diretório que contém os diretórios `Sources` e `Tests`.

```bash
$ exercism submit 
```
