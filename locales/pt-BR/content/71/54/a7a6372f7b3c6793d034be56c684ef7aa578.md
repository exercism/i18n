# Instruções

Como aspirante a mágica, Elyse precisa praticar alguns fundamentos.
Ela tem uma pilha de cartas que quer manipular.

Para facilitar um pouco as coisas, ela usa apenas as cartas de 1 a 10.

## 1. Crie um slice com determinadas cartas

Ao praticar com suas cartas, Elyse gosta de começar com suas três cartas favoritas do baralho: 2, 6 e 9.
Escreva uma função `FavoriteCards` que retorna um slice com essas cartas nessa ordem.

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. Recupere uma carta de uma pilha

Retorne a carta na posição `index` da pilha fornecida.

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

Se o índice estiver fora dos limites (ou seja, se for negativo ou depois do fim da pilha), queremos retornar `-1`:

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
Por convenção em Go, retorna-se um erro em vez de retornar um valor "fora dos limites".
Aqui, o valor "fora dos limites" é `-1` quando se espera um inteiro positivo.
Ao retornar um erro, é considerado idiomático retornar o [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/) junto com o erro.
Retornar um erro com o valor de retorno adequado será abordado em um exercício futuro.
~~~~

## 3. Troque uma carta na pilha

Troque a carta na posição `index` pela nova carta fornecida e retorne a pilha ajustada.
Observe que isso vai modificar o slice de entrada, o que é o comportamento esperado.

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

Se o índice estiver fora dos limites (ou seja, se for negativo ou depois do fim da pilha), queremos acrescentar a nova carta ao fim da pilha:

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. Adicione cartas ao topo da pilha

Adicione a(s) carta(s) especificada(s) no parâmetro `value` ao topo da pilha.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

Se nenhum argumento for passado para o parâmetro `value`, o resultado será igual ao slice original.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. Remova uma carta da pilha

Remova a carta na posição `index` da pilha e retorne a pilha.
Observe que isso pode modificar o slice de entrada, o que é aceitável.

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

Se o índice estiver fora dos limites (ou seja, se for negativo ou depois do fim da pilha), queremos deixar a pilha inalterada:

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
