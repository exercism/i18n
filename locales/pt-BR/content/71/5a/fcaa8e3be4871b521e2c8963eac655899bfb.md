# Dicas

## Geral

- `<dlist>` está em [`dlists`][dlists]; as palavras push/pop estão em
  [`deques`][deques].
- `MEMO:` está em [`memoize`][memoize].
- Variáveis locais (`::` e `:>`) mantêm o corpo da BFS legível; o
  predicado vê as mesmas variáveis locais que o corpo.

## 1. Esvazie a fila da maré

- Comece com `<dlist>`, `[ push-back ] each` para preenchê-lo, depois
  esvazie-o com um laço `until` (`[ deque-empty? ]` como predicado):
  retire o elemento da frente para um `V{ } clone`, convertendo para um array no
  final com `>array`.

## 2. Enseadas alcançáveis

- Padrão: `HS{ } clone` para `visited`, `<dlist>` para
  `frontier`, marque `start` como visitado e empurre-o para a
  fronteira, depois faça um laço até a fronteira ficar vazia: retire o
  elemento da frente, consulte seus vizinhos na carta com `at`, e para
  cada vizinho ainda não visto adicione a `visited` e faça push-back para
  a fronteira.

## 3. Contagem de saltos

- Mesma forma da tarefa 2, mas o deque carrega pares `{ cove distance }`.
  Quando você retirar um par cuja enseada é igual ao objetivo, registre
  a distância como resposta e pare. Use uma variável local mutável
  (`f :> answer!`) e condicione o laço `until` a
  `frontier deque-empty? answer or`.

## 4. Contagem de ouro

- Uma declaração: `MEMO: gold-count ( cove -- n ) gold-distribution at 0 or ;`.
  `MEMO:` substitui o `:` inicial; todo o resto é uma definição de palavra
  normal. `at` retorna `f` quando a chave está ausente; `0 or` substitui por zero.

## 5. Rota do tesouro

- `coves-reachable` retorna um hash-set; `members` (em `sets`)
  o transforma em uma sequência. Monte um array de pares `{ gold cove }`
  com `[ [ gold-count ] keep 2array ] map`, depois ordene o array com `sort`
  (que ordena os pares pelo primeiro elemento), e `last second` escolhe a
  enseada do par com mais ouro.
