# Introdução

Uma `list` em F# é uma coleção imutável de zero ou mais valores. Todos os valores de uma lista precisam ter o mesmo tipo. Como as listas são imutáveis, depois que uma lista é construída, o valor dela nunca muda. Qualquer função ou operador que pareça modificar uma lista (como adicionar um elemento) na verdade retorna uma nova lista.

Listas podem ser definidas assim:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

A forma mais comum de adicionar um elemento a uma lista é com o operador `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Uma lista em F# tem uma _cabeça_ (o primeiro elemento) e uma _cauda_ (tudo que vem depois do primeiro elemento). A cauda de uma lista também é uma lista.

As listas são manipuladas por funções e operadores definidos no módulo `List`, ou manualmente com correspondência de padrões usando os padrões _list_ e _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Você também pode _descartar_ um valor na correspondência de padrões; quando você _não_ se importa com um valor em um caso específico (ou seja, você não vai _usar_ um valor), pode usar um sublinhado (`'_'`) para indicar isso:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

O `'_'` sozinho deve vir sempre _por último_ na correspondência de padrões, pois todo valor que _não_ corresponder a nenhum dos outros casos será tratado por este caso.
