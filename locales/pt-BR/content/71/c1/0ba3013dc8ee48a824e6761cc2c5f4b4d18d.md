# Sincronize com o GitHub

Olá, pessoal!

Passamos os últimos meses trabalhando duro nos nossos cursos [Coding Fundamentals](https://exercism.org/courses/coding-fundamentals) e [Front-End Fundamentals Bootcamp](https://exercism.org/courses/front-end-fundamentals), que foram experiências incríveis para nós. Agora que eles estão prontos, estamos dedicando um pouco do nosso tempo a adicionar novos recursos ao site principal do Exercism!

Hoje estamos lançando **dois novos recursos** no Exercism:
1. Sincronize suas soluções com o GitHub.
2. Salve e explore seus Favoritos.

## Sincronize suas soluções com o GitHub

Ter um backup público das suas próprias soluções é algo que as pessoas pedem há muito tempo.
Muita gente sincroniza as soluções manualmente com o GitHub ou até escreveu os próprios scripts para fazer isso, mas agora essa função **está integrada ao Exercism!**

Assim que você ativar o recurso, suas soluções começarão a ser copiadas automaticamente para o GitHub. Você pode configurar se o backup funciona via Pull Requests ou commits, e fazer um envio em massa de todas as suas soluções!

Fizemos um lançamento discreto para os Insiders há um mês e agora já copiamos dezenas de milhares de soluções para o GitHub. Quanto mais pessoas usam, mais elas gostam. Como disse um Insider:

> Eu não tinha uma opinião forte sobre esse recurso quando ele foi proposto pela primeira vez, mas agora que ele está aqui, fico muito feliz que vocês tenham seguido em frente! Já não consigo imaginar o Exercism sem ele.
> 
> \- W8CYE no Discord

Para começar, basta acessar a nova [página de configurações do GitHub Syncer](https://exercism.org/settings/github_syncer) e conectar um repositório!

## Favoritos

Hoje também estamos lançando os [Favoritos do Exercism](https://exercism.org/favorites), um lugar para guardar e explorar as melhores soluções que você encontra no Exercism.

Pensados para você guardar tudo o que achar interessante, inspirador ou impressionante, os favoritos permitem que você favorite soluções conforme navega pelo site e volte a elas sempre que quiser se aprofundar.

Para adicionar um favorito, basta clicar no botão "Favoritar" em qualquer solução da comunidade. Você vai ver o texto mudar para "Favoritado" e a estrela ficar dourada!
Se quiser remover um favorito, é só clicar de novo.

<img src="https://assets.exercism.org/images/community/favorites-button.png" alt="Uma captura de tela da página de solução da comunidade mostrando o botão Favoritar" style="width:100%; max-width:600px;" width="2182" height="980" />

Todas as soluções que você já favoritou foram migradas automaticamente para os seus favoritos. Você pode acessar os Favoritos pelo menu Aprender, ou diretamente por [este link](https://exercism.org/favorites).
