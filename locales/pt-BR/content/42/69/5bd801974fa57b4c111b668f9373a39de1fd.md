# Testes

Cada exercício fornece os testes de unidade e uma receita de build do Make.
Você fornece a implementação.

Cada arquivo de teste deve ser vinculado à sua implementação para gerar um executável de console que roda os testes.
Rodar o executável de teste imprime mensagens para cada teste que falha e informa um status de saída diferente de zero quando os testes falham.

Para fazer um exercício:
* Crie o build inicial com o Make
* Para cada teste de unidade:
  * Remova a linha `TEST_IGNORE()`.
  * Resolva os erros de compilação para fazer o teste falhar.
  * Implemente apenas o suficiente para fazer o teste passar.
  * Refatore sua implementação para melhorar a legibilidade, reduzir a duplicação etc.
