# Introdução

## Valores padrão de parâmetros

[Valores padrão de parâmetros][default-parameter-values] podem ser fornecidos para qualquer um dos parâmetros de uma função atribuindo um valor ao parâmetro na lista de parâmetros, logo após a anotação de tipo do parâmetro. Quando um valor padrão de parâmetro é especificado, quem chama a função pode omitir esse parâmetro na chamada, e o valor padrão será usado no lugar.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Parâmetros variádicos

[Parâmetros variádicos][variadic-parameters] permitem que uma função aceite zero ou mais valores de um tipo especificado para um único parâmetro.
Você define um parâmetro variádico acrescentando três pontos (`...`) à anotação de tipo do parâmetro.

Dentro do corpo da função, o Swift disponibiliza esses valores como um array do tipo especificado:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Se uma função incluir parâmetros adicionais depois de um parâmetro variádico, o primeiro parâmetro seguinte ao parâmetro variádico **precisa** ter um rótulo de argumento explícito, para que o Swift saiba onde termina a lista de argumentos variádicos.
~~~~


## Parâmetros in-out

Dentro do corpo de uma função, os parâmetros são tratados como constantes, não como variáveis; tentar modificar o valor de um parâmetro gera um erro de compilação.
Se uma função quiser modificar o valor de um parâmetro, ela precisa usar um [_parâmetro in-out_][in-out-parameters] para tornar essa mutabilidade explícita.

Para usar parâmetros in-out, quem programa precisa ter certeza de três coisas:

1. A definição da função precisa marcar explicitamente os parâmetros in-out escrevendo a palavra-chave `inout` entre os `:` e o nome do tipo na anotação de tipo do parâmetro.
2. O valor passado para o parâmetro in-out precisa ser declarado como uma variável, não como uma constante. Da mesma forma, ele não pode ser um literal.
3. O nome da variável precisa ser precedido por um `&` na chamada da função, marcando-o explicitamente como modificável.

Quando isso é feito, a função cria uma cópia interna do parâmetro in-out, modifica essa cópia conforme indicado no corpo da função e, quando a função retorna, copia o valor modificado de volta para a variável que foi passada.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Existem algumas regras extras que você deve conhecer a respeito de parâmetros in-out.

1. Dentro de uma função com parâmetros in-out, você não pode referenciar a variável que foi passada como parâmetro in-out.
2. A mesma variável não pode ser passada como vários parâmetros in-out na mesma função.
   Por exemplo, `inoutFunc(&mutVar, &mutVar)` gera um erro do compilador.
~~~~

## Funções aninhadas

No Swift, você pode definir [funções dentro de outras funções][nested-functions].
Essas são conhecidas como **funções aninhadas**.

Funções aninhadas costumam ser usadas como auxiliares privadas que realizam tarefas específicas para a função que as contém, sem poluir o escopo externo:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Funções aninhadas se comportam como funções normais, mas sua visibilidade fica restrita ao corpo da função que as contém.
