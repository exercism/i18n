# Debug

Quando um teste falha, é exibida uma mensagem descrevendo o que deu errado.
Se você quiser uma saída adicional, pode usar a sub-rotina `::YYY()` em volta do código que você quer inspecionar.
(`::` é um atalho para `main::`).
Essa sub-rotina faz parte do módulo [XXX][XXX].

Você também pode simplesmente imprimir uma mensagem usando a função `say`, por exemplo, `say 'Hello, World!';`.

O executor de testes online usa o [Test Anything Protocol][TAP].
Devido à natureza do TAP, o uso de `print` no executor de testes online é fortemente desaconselhado.

[TAP]: https://testanything.org/
