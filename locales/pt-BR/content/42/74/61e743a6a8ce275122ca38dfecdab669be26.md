# Apêndice das instruções

## Dicas

Para completar este exercício, você precisa implementar as seguintes funções:

- `territories` retorna as coordenadas (a contagem começa em 1, o canto superior esquerdo é (1,1)) dos pontos em cada território, junto com quem "possui" o território.

- `territoriesFor` retorna o território que contém a coordenada, junto com o dono do território. Se a coordenada não aponta para um local vazio, retorna *Nothing*.

Um território pertence a um dos jogadores se as pedras desse jogador forem as únicas pedras adjacentes ao território.

As assinaturas de tipo já estão prontas, mas cabe a você definir as funções.
