# Sobre

Literais são valores fixos usados diretamente no código.
Não precisam de nenhum cálculo durante a execução.
Existem em várias formas para representar tipos diferentes de dados com eficiência.
Os literais mais frequentes são de natureza numérica, mas também existem operadores literais para tipos de data, hora e string.
Um conceito posterior mostrará como operadores literais definidos pelo usuário podem ser usados.

## Literais numéricos

Literais numéricos incluem as representações decimal, octal, hexadecimal e binária.
Esses conceitos básicos já foram abordados no [conceito de números][numbers-concept].

Todas as representações como `23`, `0x50f7ba11` e `0xba5eba11` são entendidas pelo compilador como `int`.
O tipo `int` comum tem sinal e ([dependendo do compilador e do sistema][in-depth-integers]) costuma ter um intervalo de `-2'147'483'648` a `2'147'483'647`.
Isso é suficiente na maioria das vezes, e você não precisa se preocupar com o tipo específico.

Alguns casos de uso exigem intervalos maiores ou um uso de memória muito pequeno nos programas.
Para deixar isso explícito, é possível declarar tipos inteiros específicos diretamente com o literal numérico.

Quando números negativos não são necessários, mas o intervalo maior é desejado, usa-se o sufixo `u` ou `U` para inteiros _unsigned_.
Para intervalos ainda maiores, `L` ou até `LL` podem ser usados para os tipos long e long long.

~~~~exercism/caution
O uso de `l` minúsculo é permitido, mas é facilmente confundido com o número `1` e, por isso, desencorajado.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

Números de ponto flutuante geralmente resultam em `double` durante a compilação.
Esse é um bom padrão, e casos de uso com o tipo `float`, mais restrito, são menos frequentes que o exemplo com _unsigned_ acima.

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## Literais de caractere e de string

Outros conceitos já usaram literais de caractere com aspas simples, como `'}'` ou `'@'`.

Em C++, `char` é limitado aos primeiros 128 [códigos de caractere ASCII][ascii-code].
Para usar vários caracteres ASCII ou caracteres ASCII estendidos como `‰`, ou até caracteres unicode como `麗` e `ẞ`, outros tipos são necessários.
Em um conceito anterior, os literais de string foram apresentados com _aspas duplas_: `"一体どういう意味ですか。C++です"`.
O tipo real dessa frase em japonês é `const char (&)[46]`, uma string no estilo C.

O uso de literais de string não é ativado por padrão.
Para usar o literal _string_ `""s` ou o literal _string-view_ `""sv`, é preciso indicar isso usando o namespace relacionado:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

Uma _string_view_ pode ser vista como uma referência a uma string const.
