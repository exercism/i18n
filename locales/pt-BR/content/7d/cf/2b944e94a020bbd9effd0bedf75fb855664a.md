# Sobre

Uma quotation, escrita em `[ ]`, é o equivalente, no Factor, de uma função anônima ou de um bloco de código. É um valor de primeira classe que você pode empilhar, guardar ou passar adiante, e que só roda quando algo a *chama*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

Quotations são sequências de palavras, e o Factor as usa em todo lugar onde um comportamento precisa ser adiado ou parametrizado:

- os blocos de `if` / `when` / `unless` / `cond`
- o predicado de `filter`, `count`, `any?`, `all?`
- a transformação de `map`, `each`, `reduce`
- o corpo de `times`, `while`, `loop`

O efeito de pilha de uma quotation normalmente pode ser inferido. Quando não dá (em geral porque ela é guardada e chamada mais tarde com `call`), declare o efeito explicitamente: `call( a b -- c )`.

## Combinando quotations

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` concatena duas quotations de ponta a ponta em uma nova quotation que roda a primeira e depois a segunda. `curry` antepõe um valor fixo e retorna uma quotation que empilha esse valor antes de invocar a original. As duas produzem quotations comuns, que você pode chamar com `call`, guardar ou passar para combinadores.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
