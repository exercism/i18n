# Instruções

Neste exercício, você precisa implementar alguns métodos para manipular um array de linguagens de programação.

## 1. Defina um método para retornar um array de linguagens vazio

Defina o método `LanguageList.list`, que não recebe argumentos e retorna um array vazio do tipo `Array(String)`.

```crystal
LanguageList.list()
# => []
```

## 2. Defina um método para adicionar uma linguagem ao array

Defina o método `LanguageList.add`, que recebe 2 argumentos (um _array de linguagens_ e um literal de string de uma _linguagem_).
O método deve retornar o array com a nova linguagem adicionada ao final.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. Defina um método para remover uma linguagem do array

Defina o método `LanguageList.remove`, que recebe 1 argumento (um _array de linguagens_).
O método deve retornar o array sem o último item.
Considere que o array sempre terá pelo menos um item.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. Defina um método para retornar o enésimo item do array

Defina a função `LanguageList.at`, que recebe 2 argumentos (um _array de linguagens_ e um índice).
O método deve retornar a linguagem no índice n do array.
Considere que sempre haverá uma linguagem no índice.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. Defina um método para fazer o parse de uma string de linguagens

Defina o método `LanguageList.parse`, que recebe 1 argumento (um literal de string de linguagens separadas por vírgula).
O método deve retornar um array de linguagens.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
