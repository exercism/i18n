# Instruções

Traduza sequências de RNA em proteínas.

O RNA pode ser dividido em sequências de três nucleotídeos chamadas códons e, em seguida, traduzido para um polipeptídeo assim:

RNA: `"AUGUUUUCU"` => traduz para

Códons: `"AUG", "UUU", "UCU"`
=> que se tornam um polipeptídeo com a seguinte sequência =>

Proteína: `"Methionine", "Phenylalanine", "Serine"`

Existem 64 códons que, por sua vez, correspondem a 20 aminoácidos. No entanto, nem todas as sequências de códons e os aminoácidos resultantes são importantes neste exercício.
Se funcionar para um códon, o programa deve funcionar para todos eles.
Porém, fique à vontade para ampliar a lista na suíte de testes e incluir todos eles.

Existem também três códons de terminação (também conhecidos como códons 'STOP'); se algum desses códons for encontrado (pelo ribossomo), toda a tradução termina e a proteína é encerrada.

Todos os códons seguintes são ignorados, assim:

RNA: `"AUGUUUUCUUAAAUG"` =>

Códons: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Proteína: `"Methionine", "Phenylalanine", "Serine"`

Repare que o códon de parada `"UAA"` encerra a tradução e a metionina final não é traduzida para a sequência de proteína.

Abaixo estão os códons e os aminoácidos resultantes necessários para o exercício.

| Códon              | Proteína      |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |
