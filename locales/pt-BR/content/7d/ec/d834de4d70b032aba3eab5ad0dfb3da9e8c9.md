# função não otimizada

Parece que a função `%{function}` não é ótima.
Este analisador é um trabalho em andamento e não consegue dizer exatamente por que acha que algo não é ótimo.
Fique à vontade para ignorar este feedback.
Se você quiser tentar resolver isso, a recomendação é a seguinte: espera-se que esta função seja o mais simples possível, sem declarar nenhuma variável extra.
