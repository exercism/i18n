# Dicas

## 1. Verifique quais foram as contagens na semana passada

- Os [vetores][vectors] são representados em Clojure usando colchetes (`[ ]`)

## 2. Verifique quantos pássaros visitaram hoje

- A função [`peek`][peek] pode ser usada para retornar o último item de um vetor.

## 3. Incremente a contagem de hoje

- A função [`update`][update] pode ser usada para retornar um novo vetor com um elemento diferente em um determinado índice.

- A função [`count`][count] pode ser usada para descobrir o comprimento do vetor.

- As funções [`inc`][inc] e [`dec`][dec] podem ser usadas para incrementar e decrementar valores inteiros.

## 4. Verifique se houve um dia sem pássaros visitantes

- A função [`every?`][every?] pode ser usada para verificar se todos os itens de uma coleção satisfazem um determinado predicado.

- O predicado [`pos?`][pos?] retorna `true` se um número for maior que zero.

- A função [`not`][not] retorna `true` se uma expressão for avaliada como falsa.

## 5. Calcule o número de pássaros visitantes nos primeiros dias

- A função [`take`][take] pode ser usada para retornar uma sequência dos n primeiros itens de uma coleção.

- A função [`reduce`][reduce] pode ser usada para somar uma coleção de valores.

## 6. Calcule o número de dias movimentados

- A função de ordem superior [`filter`][filter] pode ser usada para retornar uma sequência de itens de uma coleção que satisfazem um determinado predicado.

## 7.  Verifique se a semana é ímpar

- A função [`=`][equality] pode ser usada para testar igualdade.
