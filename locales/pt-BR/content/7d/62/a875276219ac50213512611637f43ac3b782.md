# Introdução

Você receberá uma solução exemplar para cada exercício que resolver no Exercism.
Na trilha de Julia, essas soluções geralmente contêm [docstrings](https://en.wikipedia.org/wiki/Docstring).
Depois de resolver este exercício, você saberá como as docstrings são estruturadas, como escrevê-las e como acessar docstrings pelo REPL.

~~~~exercism/note
Não é necessário escrever docstrings para suas funções enquanto resolve exercícios na trilha de Julia, se não quiser.
~~~~

## Sintaxe

Qualquer string imediatamente antes de qualquer tipo de objeto Julia, por exemplo, uma função ou tipo, será interpretada como uma docstring que documenta o objeto.
Por exemplo:

```julia
"Tell a joke."
joke() = ...
```

Docstrings em Julia são formatadas usando [Markdown](https://en.wikipedia.org/wiki/Markdown).
Isso permite usar recursos como indentação, blocos de código ou texto em negrito em docstrings.

~~~~exercism/note
Você pode encontrar uma lista dos recursos Markdown suportados na [documentação da biblioteca padrão Markdown](https://docs.julialang.org/en/v1/stdlib/Markdown/).
~~~~

Uma docstring mais complexa pode ser assim:

````julia
"""
    mean(x, y)

Compute the mean value of `x` and `y`.
"""
mean(x, y) = (x + y) / 2
````

O Manual do Julia contém algumas convenções que devem ser seguidas:

> - Sempre mostre a assinatura de uma função no topo da documentação, com recuo de quatro espaços para que seja impressa como código Julia.
> - Inclua uma única frase de uma linha descrevendo o que a função faz ou o que o objeto representa após o bloco simplificado de assinatura.
>    Se necessário, forneça mais detalhes em um segundo parágrafo, após uma linha em branco.
>    A frase de uma linha deve usar a forma imperativa ("Faça isso", "Retorne aquilo") em vez da terceira pessoa (não escreva "Retorna o comprimento...") ao documentar funções.
>    Deve terminar com um ponto final.
> - Não se repita.
>    Como o nome da função é dado pela assinatura, não há necessidade de começar a documentação com "A função `mean`...": vá direto ao ponto.
> - Use crases para identificar código e equações.
> - Coloque os caracteres `"""` de início e fim em linhas separadas.

~~~~exercism/note
A lista acima cobre apenas convenções que você pode precisar ou encontrar no contexto do Exercism.
Você pode encontrar uma lista completa e não abreviada no [Manual do Julia](https://docs.julialang.org/en/v1/manual/documentation/).
Convenções adicionais para documentar conceitos mais avançados de Julia serão introduzidas junto com o conceito em exercícios posteriores.
~~~~

## Acessando docstrings

Você pode pesquisar docstrings no REPL digitando `?` seguido do nome da função ou objeto, por exemplo.

```julia-repl
help?> println
search: println printstyled print sprint isprint

  println([io::IO], xs...)


  Print (using print) xs followed by a newline. If io is not supplied, prints to stdout.

  Examples
  ==========

  julia> println("Hello, world")
  Hello, world

  julia> io = IOBuffer();

  julia> println(io, "Hello, world")

  julia> String(take!(io))
  "Hello, world\n"
```

Isso também pode ser usado como uma pesquisa básica, por exemplo, se você não tiver certeza sobre a grafia exata de uma função:

```julia-repl
help?> printline
search:

Couldn't find printline
Perhaps you meant println, pipeline, @inline or print
  No documentation found.

  Binding printline does not exist.
```
