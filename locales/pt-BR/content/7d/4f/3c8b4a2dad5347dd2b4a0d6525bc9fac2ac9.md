# Introdução

As exceções são uma forma de tratamento de erros.
Elas são chamadas de exceções porque normalmente aparecem quando lidamos com algum evento inesperado.

Em qualquer ponto do nosso código, podemos lançar uma exceção.
Fazemos isso com o método `raise`, passando um objeto, normalmente um objeto Exception, embora também possamos usar strings simples.
Por exemplo, você vai ver nos stubs dos exercícios que usamos o `RuntimeError` embutido para avisar ao Ruby que um método não foi implementado.
Você também pode usar a sintaxe abreviada `raise(ExceptionObject, params)`.
Se a classe da exceção for omitida, `RuntimeError` é usado por padrão.
Por exemplo:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Quando o Ruby vê isso, ele propaga o erro até o topo do programa e então encerra.
Por exemplo, se você tentar dividir algo por zero, vai ver algo assim:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
