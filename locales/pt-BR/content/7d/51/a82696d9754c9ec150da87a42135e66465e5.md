# Introdução

Por padrão, as variáveis ficam limitadas ao escopo em que são definidas. Se forem definidas em um arquivo fora de uma função ou classe, ficam limitadas ao escopo do arquivo. Se forem definidas dentro de uma função ou classe, ficam limitadas ao escopo da função ou da classe.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

As variáveis também podem ser declaradas especificamente com escopo `global` ou `static`.
