# Artigos

Cada exercício pode ter artigos associados, que exploram algum aspecto interessante do exercício.

## Tópicos

Possíveis tópicos que um artigo pode explorar:

- Comparar o desempenho de diferentes abordagens
- Qualquer coisa interessante que você conseguir imaginar!

## Considerações gerais

- Se o seu artigo for baseado em algum código que você escreveu, considere incluir esse código (dentro do diretório do artigo)
  - Um exemplo é um artigo sobre desempenho, para o qual foi escrito um código de benchmarking

## Para quais exercícios escrever artigos?

Qualquer exercício, desde que haja algo interessante a explorar.

## Arquivos

Cada artigo deve adicionar os dois arquivos a seguir:

- `.articles/<article-slug>/content.md`: descrição do artigo (veja [a documentação](/docs/building/tracks/practice-exercises#file-articles-article-slug-content-md))
- `.articles/<article-slug>/snippet.md`: trecho que apresenta o artigo (veja [a documentação](/docs/building/tracks/practice-exercises#file-articles-article-slug-snippet-txt))

Depois, você precisará adicionar ou atualizar:

- `.articles/config.json`: metadados dos artigos (veja [a documentação](/docs/building/tracks/practice-exercises#file-article-config-json))
