# Introdução

## Sobrecarga de operadores

Os principais operadores aritméticos e de comparação podem ser adaptados para uso nas suas próprias classes e structs. Isso é conhecido como _sobrecarga de operadores_.

A maioria dos operadores tem a forma:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

Os operadores de conversão têm a forma:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Os operadores se comportam da mesma forma que métodos estáticos. O símbolo do operador ocupa o lugar do identificador do método, e os operadores têm parâmetros e um tipo de retorno. As regras de tipo para os parâmetros e para o tipo de retorno seguem a sua intuição, e você pode contar com o compilador para dar orientações detalhadas.
