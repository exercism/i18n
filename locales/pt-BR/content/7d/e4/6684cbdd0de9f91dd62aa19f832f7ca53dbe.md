# Introdução

## Números

Do [manual][man-types]

> O jq dá suporte ao mesmo conjunto de tipos de dados que o JSON: números, strings, Boolean, arrays, objetos (que, no jargão do JSON, são hashes com apenas chaves do tipo string) e "null".

Vamos nos concentrar nos **números**.

### Números e operadores numéricos

Todos os números, sejam inteiros ou não, são números de ponto flutuante de precisão dupla IEEE754.
Isso nos limita a 53 bits de precisão.

Os operadores usuais estão disponíveis para usar com números:

- aritmética: `+`, `-`, `*`, `/`, `%`
- comparação: `==`, `!=`, `<`, `<=`, `>=`, `>`
- [funções matemáticas][man-math] padrão

  Para funções de uma entrada, use um pipe para passar o valor para a função

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Para funções de duas entradas, elas ignoram a entrada e esperam as entradas
  como parâmetros (lembre-se de que os parâmetros são separados por ponto e vírgula)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  O ponto e vírgula é o separador de argumentos de função, não a vírgula.

### Outras expressões `jq`

Para resolver o exercício, você vai precisar conhecer as expressões condicionais.

#### Expressões condicionais

O `jq` usa uma [expressão `if-then-else`][if-then-else] para **expressões condicionais**.
Como é uma _expressão_, ela é colocada em um pipeline.

A sintaxe é: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

A cláusula `else` é opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Condições adicionais usam `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
