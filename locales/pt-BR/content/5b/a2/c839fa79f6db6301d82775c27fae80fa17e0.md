# Apêndice das instruções

## Dicas

Neste exercício, fornecemos a definição do
[tipo de dados algébrico](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses)
chamado `Planet`.
Você precisa implementar a função `ageOn`, que calcula quantos
anos alguém teria em um `Planet`, dada uma idade em segundos.

Você pode usar a assinatura fornecida se estiver na dúvida sobre os tipos, mas
não deixe que ela restrinja sua criatividade:

```haskell
ageOn :: Planet -> Float -> Float
```
