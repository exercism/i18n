# Introdução

O Factor modela datas e horários com o vocabulário [`calendar`][calendar]. Um ponto no tempo é um `timestamp`; um intervalo de tempo é um `duration`.

## Construindo uma data

`<date>` (em [`calendar`][calendar]) constrói um `timestamp` à meia-noite do dia informado:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` divide um timestamp de volta em suas partes:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## Inspecionando uma data

`day-of-week` retorna o dia da semana como um número inteiro, `0` para domingo até `6` para sábado. `day-names` (em [`calendar.english`][english]) é a lista correspondente de nomes, então `day-names nth` transforma o número em uma palavra:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` aceita um ano (ou um timestamp) e `days-in-month` retorna o número de dias do mês de um timestamp, já levando em conta anos bissextos:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## Aritmética de datas

Palavras como `days`, `weeks` e `hours` constroem um `duration`, e `time+` desloca um timestamp em uma `duration`:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

A aritmética lida corretamente com a passagem entre meses e anos, e dois timestamps que indicam o mesmo instante são iguais com `=`.

## Horários do dia

`<timestamp>` constrói um timestamp completo, com precisão de segundos. Seu último argumento é o deslocamento em relação ao UTC; `instant` (um `duration` zero) mantém o timestamp no UTC:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` é o correspondente de `>date<` e divide um timestamp em hora, minuto e segundo:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` e `minutes` constroem um `duration` assim como `days`, `weeks` e `hours`, então qualquer uma delas pode ser passada para `time+`:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

Os campos individuais de um timestamp são lidos com os acessadores `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` e `second>>`:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
