# Instruções

Neste exercício, você vai escrever um TreasureChest genérico (e mágico!), para guardar alguns tesouros.

## 1. Defina o tipo customizado genérico TreasureChest

Defina um tipo customizado `TreasureChest` com uma única variante.

A variante deve ter um valor `String` associado, que será usado para armazenar a senha do baú do tesouro.

A variante também deve ter um valor genérico associado, que será usado para armazenar o tesouro.
Esse valor é genérico para que o tesouro possa ser qualquer coisa.

## 2. Defina a função getTreasure

Essa função deve receber dois parâmetros

- uma `String` (para tentar uma senha)
- um tipo customizado genérico `TreasureChest`

Essa função deve comparar a tentativa de senha fornecida com a `String` no `TreasureChest`.

A função deve retornar um `Maybe`.

Se as senhas coincidirem, retorne `Just` com o valor genérico do `TreasureChest` (o tesouro!)

Se as senhas não coincidirem, retorne `Nothing`.

## 3. Defina a função multiplyTreasure

Essa função (de ordem superior) deve receber dois parâmetros

- uma função multiplicadora que recebe um parâmetro genérico e retorna uma lista do mesmo tipo genérico
- um tipo customizado genérico `TreasureChest`, também com o mesmo tipo genérico

Essa função deve chamar a função multiplicadora com o tesouro no baú.

A função deve retornar um novo TreasureChest, com a mesma senha do original e com o tesouro multiplicado (o retorno)
