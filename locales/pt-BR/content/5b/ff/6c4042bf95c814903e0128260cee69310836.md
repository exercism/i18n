# Introdução

## Constantes e funções

Um valor constante é definido com `name = expression` e, em Elm, tudo o que não é uma definição é uma expressão.

```elm
five = 5

six = 3 + 3
```

Funções são definidas com `name parameters... = expression`, com os parâmetros separados apenas por espaço.

```elm
add number1 number2 = number1 + number2
```

Chamar uma função também é uma expressão, e isso é feito especificando o nome dela e passando argumentos para cada um dos parâmetros da função, separados por espaço, assim como na definição de função.

```elm
five = add 2 3
```

Parênteses podem ser usados para especificar a ordem de avaliação de uma expressão.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentação / espaços em branco significativos

Elm não usa marcadores sintáticos como chaves, parênteses ou ponto e vírgula para delimitar o código. Em vez disso, usa espaços em branco e indentação.

- Definições de módulo, de import e de funções de nível superior devem começar na coluna mais à esquerda.
- Se uma expressão for dividida em várias linhas, o código que faz parte dessa expressão deve ser indentado sob ela com pelo menos um espaço.
- As partes da expressão que estão agrupadas devem ser indentadas com o mesmo número de espaços.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Módulos

Cada arquivo em Elm é um módulo e deve conter uma instrução `module` antes de todo o resto do código.
Os nomes dos módulos devem corresponder ao nome do arquivo, então o módulo `Calculator` deve estar no arquivo Calculator.elm.
Tudo o que é definido dentro de um módulo tem escopo privado a ele e não pode ser acessado de fora desse módulo, a menos que esteja listado em `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Comentários

Um comentário é um texto dentro do arquivo Elm que não é interpretado como código.
Ele serve principalmente para você mesmo e outros programadores lerem.
Existe uma sintaxe leve para comentários de uma linha, baseada em dois hífens.
Comentários de várias linhas também são possíveis com o par `{-` e `-}` de delimitadores de abertura e fechamento.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
