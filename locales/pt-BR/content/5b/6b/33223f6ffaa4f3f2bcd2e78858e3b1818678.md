# Introdução

O PowerShell é uma linguagem de script dinâmica e de tipagem implícita (_mas que também dá suporte a [variáveis fortemente tipadas][strong typed]_) da Microsoft, focada principalmente em automação de tarefas e gerenciamento de configuração.

O PowerShell dá suporte a programação imperativa, funcional, orientada a objetos e até mesmo no estilo de pipeline.

O PowerShell foi construído sobre a plataforma .NET e lançado pela primeira vez em 2006.
Ele vem incluído por padrão em todos os sistemas operacionais Windows modernos e também pode ser instalado no Mac e no Linux.


## Variáveis

Existem duas formas comuns de definir uma variável no PowerShell.

Os nomes de variáveis no PowerShell precisam começar com um `$` e usam o operador de atribuição `=` para vincular o nome da variável a um valor.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Você também pode especificar o tipo de uma variável explicitamente, se quiser forçar/exigir que o valor seja de um determinado tipo.
O PowerShell fará o possível para converter o valor de um tipo para outro, se possível.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Constantes

As constantes no PowerShell são variáveis que não podem ser **alteradas** nem **removidas** depois de definidas.
Isso nos leva à segunda forma de definir variáveis: usar o cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Para formas mais detalhadas e avançadas de criar uma nova variável, leia [New-Variable][New-Variable].


## Funções

As [funções][functions] no PowerShell são definidas com a palavra-chave `function`.
Cada função pode ter zero ou mais parâmetros formais entre parênteses `()`, seguidos pelo escopo da função, que começa com `{` e termina com `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

As funções no PowerShell podem retornar valores explicitamente por meio da palavra-chave `return`, depois de serem chamadas com a sintaxe `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Uma visão avançada de como escrever uma definição de função detalhada e de como as funções podem retornar valores implicitamente será abordada no módulo do conceito `Functions`.


## Comentários

Comentários de linha única no PowerShell começam com `#` e terminam no fim da linha.
Blocos de comentário no PowerShell começam com `<#` e terminam com `#>`.
Uma demonstração avançada de bloco de comentário para criar ajuda baseada em comentários será abordada no módulo do conceito `Functions`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
