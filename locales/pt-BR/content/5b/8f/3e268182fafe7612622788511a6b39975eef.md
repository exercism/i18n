# Instruções

Neste exercício, você vai simular um sistema de computador baseado em janelas.
Você vai criar algumas janelas que podem ser movidas e redimensionadas.
A imagem a seguir representa os valores com que você vai trabalhar abaixo.

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. Defina as propriedades da janela do programa

Usando a estrutura de classe fornecida, defina as propriedades para os valores de `y`, `x`, `height` e `width`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. Defina os valores iniciais da janela do programa

Defina uma função construtora para `ProgramWindow`.
Ela não deve receber nenhum argumento, mas durante a execução do construtor defina os valores padrão de suas propriedades.
Ela deve definir os valores iniciais de `y` e `x` como `0`.
Ela deve definir `height` e `width` iniciais para um tamanho de tela de `600x800`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. Defina uma função para redimensionar a janela

Defina uma nova classe em `Size.php` para uma classe Size.
Ela deve receber argumentos de construtor para definir as propriedades `height` e `width`.
Além disso, `ProgramWindow` precisa de uma função de redimensionamento, que recebe a instância do objeto `Size` e atualiza suas próprias propriedades.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. Defina uma função para mover a janela

Defina uma nova classe em `Position.php` para uma classe Position.
Ela deve receber argumentos de construtor para definir as propriedades `y` e `x`.
Além disso, `ProgramWindow` precisa de uma função de movimento, que recebe a instância do objeto `Position` e atualiza suas próprias propriedades.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
