# Dicas

## Geral

- Leia sobre [pattern matching][pattern-matching] no guia oficial.
- Dê uma olhada neste cheat sheet sobre [desestruturação][destructuring].
- O pattern matching para registros é [explicado aqui][records-pattern-matching] com mais detalhes.

## 1. Detectar comentários vazios

- Você pode usar `(a, b)` diretamente no argumento da função se o argumento for um par.
- Você pode substituir valores que recebe mas não usa pelo curinga `_`.
- Para verificar se uma string está vazia, consulte a [documentação de `String`][string-docs].

## 2. Contar o número de comentários do criador

- Você pode desestruturar um tipo personalizado com uma única variante `type Box = Box AB` diretamente em um argumento de função assim: `(Box ab)`.
- Você pode fazer pattern matching no campo `a` de um registro `{a : A, b : B}` usando: `{ a }`.
- Você pode usar as duas técnicas acima ao mesmo tempo em tipos personalizados que guardam um registro.
- Você não pode fazer pattern matching diretamente no par `ab` de um registro `{ ab : (A, B) }`. Você precisa fazer pattern matching em `{ ab }` primeiro, e depois usar `( a, b) = ab` em uma vinculação `let`.
- Para encontrar o número de elementos que satisfazem uma condição em uma lista, use as [funções de `List`][list-docs].
- Você pode desestruturar pares diretamente nos argumentos de funções anônimas.

## 3. Detectar tickets atribuídos ao Dev Team

- Como na Tarefa 2, você pode fazer pattern matching nos campos relevantes de um registro "encaixotado" no argumento da função.
- Você pode usar pattern matching recursivamente para casar um valor aninhado como `Just (Box "42")`.
- Você pode usar o curinga `_` para casar qualquer coisa em uma instrução `case`.

## 4. Atribuir tickets a funcionários de TI

- Como nas Tarefas 2 e 3, você pode fazer pattern matching nos campos relevantes de um registro "encaixotado" no argumento da função.
- Além disso, você pode usar a palavra-chave `as` para fazer pattern matching em um campo e também vincular o registro inteiro: `(Box ({ a } as ab))`.
- Você pode fazer pattern matching nos valores de um tipo personalizado com a instrução `case`.
- Use o construtor de tipo `Ticket` para retornar um ticket.
- Use a [sintaxe de atualização de registros][record-update] para modificar registros.
