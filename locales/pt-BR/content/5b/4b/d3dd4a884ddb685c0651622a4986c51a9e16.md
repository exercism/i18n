# Dicas

## Geral

- Você consegue realizar todas essas tarefas sem usar uma condicional `if`.

## 1. Determine se você vai precisar de uma carteira de motorista

- Use o [operador de igualdade][cmp] para verificar se o primeiro campo é igual a uma determinada string.
- Use uma expressão regular para verificar se o segundo campo contém as substrings necessárias.
- Use um dos dois [operadores Boolean][bool] para combinar os dois requisitos.

## 2.Calcular uma estimativa para o preço de um veículo usado

- Use os [operadores de comparação][cmp] para determinar qual desconto usar.

[cmp]: https://www.gnu.org/software/gawk/manual/html_node/Comparison-Operators.html
[bool]: https://www.gnu.org/software/gawk/manual/html_node/Boolean-Ops.html
