# Introdução

Factor é uma linguagem *concatenativa*: cada palavra lê suas entradas de uma **pilha de dados** compartilhada e coloca suas saídas de volta no topo dela. Não existe outra forma de passar valores de um lado para o outro.

Escrever um literal o empilha no topo da pilha; o código é lido da esquerda para a direita:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

Uma declaração de *efeito de pilha* documenta o contrato de uma palavra:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` diz que a palavra desempilha dois valores e deixa dois para trás na ordem inversa. Os nomes são documentação (só o *número* de entradas e saídas é verificado pelo compilador), e o topo da pilha é o nome da direita.

As **palavras de embaralhamento** do `kernel`, usadas no dia a dia, reorganizam o topo da pilha:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

As palavras são definidas com `:` e terminam com `;`; o compilador recusa uma definição cujo corpo não corresponde ao efeito declarado.
