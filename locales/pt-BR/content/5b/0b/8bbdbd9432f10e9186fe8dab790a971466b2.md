# Instruções

O novo aeroporto de Berlim contratou desenvolvedores para o laboratório de robôs deles, e você está começando a trabalhar lá.
Eles têm robôs desajeitados, meio humanoides, que estão tentando usar para melhorar o atendimento ao cliente.

Sua primeira tarefa no trabalho é escrever um programa para que o robô possa cumprimentar as pessoas no idioma nativo delas depois que elas escanearem os passaportes no balcão de autoatendimento.

O robô tem orgulho de suas habilidades, então ele sempre vai dizer primeiro qual idioma ele sabe falar e depois cumprimentar a pessoa.
Por exemplo, se alguém escanear um passaporte alemão, o robô diria:

```txt
I can speak German: Hallo Dietrich!
```

## 1. Crie a funcionalidade abstrata de saudação

Você não vai escrever o código dos diferentes idiomas, então precisa estruturar o código do robô de forma que outros desenvolvedores possam adicionar mais idiomas facilmente depois.

Como primeiro passo, defina uma interface `Greeter` com dois métodos.

- `LanguageName`, que retorna o nome do idioma (uma `string`) no qual o robô deve cumprimentar o visitante.
- `Greet`, que aceita o nome de um visitante (uma `string`) e retorna uma `string` com a mensagem de saudação em um idioma específico.

Em seguida, implemente uma função `SayHello` que aceita o nome do visitante e qualquer coisa que implemente a interface `Greeter` como argumentos e retorna a string de saudação desejada.
Por exemplo, imagine uma implementação alemã de `Greeter` em que `LanguageName` retorna `"German"` e `Greet` retorna `"Hallo {name}!"`:

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Implemente o italiano

Agora sua tarefa é fazer o robô funcionar para as pessoas que escaneiam passaportes italianos.

Para isso, crie uma struct `Italian` e implemente os dois métodos necessários para que a struct cumpra a interface `Greeter` que você definiu na tarefa 1.
Você pode cumprimentar alguém em italiano com `"Ciao {name}!"`.

## 3. Implemente o português

Antes de encerrar o expediente, você também deve terminar a funcionalidade de cumprimentar as pessoas em português.

Para isso, crie uma struct `Portuguese` e implemente os dois métodos necessários para que a struct cumpra a interface `Greeter` aqui também.
Você pode cumprimentar alguém em português com `"Olá {name}!"`.
