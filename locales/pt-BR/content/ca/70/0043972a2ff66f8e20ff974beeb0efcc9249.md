# Anexo às instruções

## Trabalhando com datas no Prolog

O suporte nativo do Prolog para datas é [bastante rudimentar][built-in-dates-support].
Embora você consiga resolver este exercício só com o que o Prolog já traz, uma forma bem mais agradável de trabalhar com datas é usar o [pacote date_time][date-time-package].

### Instalando o pacote date_time

Se a versão do Swipl que você tem instalada estiver razoavelmente atualizada, você pode instalar o pacote rodando:

```bash
swipl pack install date_time
```

Se isso não funcionar, você pode rodar:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Se você estiver usando o editor online, não precisa instalar nada manualmente.
~~~~

### Usando o pacote date_time

Adicione o seguinte código no topo do seu arquivo de solução para usar o pacote `date_time`:

```prolog
:- use_module(library(date_time)).
```
