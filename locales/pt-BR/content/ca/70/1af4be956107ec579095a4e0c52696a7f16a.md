# Instruções

Trabalhando em um parque de diversões, você recebeu uma especificação para projetar um sistema que controle a entrada de visitantes e os brinquedos. Você ficou responsável por modelar o Attendee (a pessoa que visita o parque).

## 1. Criar novos visitantes

Implemente o método `Attendee#initialize` da classe `Attendee`. Ele deve receber uma altura (em centímetros) e armazená-la como uma variável de instância.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. Qual é a altura do visitante?

Implemente o getter `Attendee#height` da classe `Attendee`. Ele deve retornar a altura da instância.

```ruby
Attendee.new(106).height
# => 106
```

## 3. Qual é o id do passe de brinquedos?

Nem todos os visitantes compraram um passe de brinquedos, mas precisamos saber se eles têm um passe ou não. Implemente o getter `Attendee#pass_id` da classe `Attendee`. Ele deve retornar o pass_id da instância ou `nil` se o visitante não tiver um.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Permitir que as pessoas comprem um passe

Implemente `Attendee#issue_pass!` para alterar o estado da instância e definir a variável de instância pass_id com o argumento. Ele deve retornar o id do passe.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Revogar o passe

Alguns visitantes desrespeitam as regras com comportamento inseguro, por isso o parque quer poder revogar passes. Implemente `Attendee#revoke_pass!` para alterar o estado da instância e definir o id do passe como `nil`.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
