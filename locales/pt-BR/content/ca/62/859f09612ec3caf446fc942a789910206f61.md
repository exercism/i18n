# Rodando os testes

O SWI Prolog pode ser rodado de forma interativa ou executado diretamente na linha de comando.

## Linha de comando

Você pode usar o comando a seguir para rodar os testes na linha de comando:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Substitua `<exercise>` pelo nome do exercício que você está implementando.

## Modo interativo

Para rodar o Prolog de forma interativa, primeiro execute:

```bash
swipl
```

Depois que o console do Prolog iniciar, carregue sua implementação e rode os testes com:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Substitua `<exercise>` pelo nome do exercício que você está implementando.

### Recarregando alterações

Depois que os arquivos acima estiverem carregados, você pode aplicar qualquer alteração que tiver feito rodando:

```
?- make.
```

## Testes ignorados

Quando você começa um exercício, só o primeiro teste roda. Os demais foram ignorados ao adicionar `condition(pending)` ao objetivo `test`.
Quando o primeiro teste passar, reative o próximo teste trocando `pending` por `true` em `condition(pending)`.
Repita para cada teste até que todos estejam rodando e passando.

### Linha de comando

Adicione o argumento `-- --all` ao final do comando para rodar também os testes pendentes:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
