# Sobre

O Haxe tem suporte nativo a expressões regulares. Elas podem ser usadas para verificar o formato de uma string, transformar uma string ou extrair dados regulares de um texto.

Para criar uma expressão regular, escreva entre `~/` e `/`:

```haxe
var r = ~/haxe/i;
```

Uma outra forma de fazer isso é usar a instância `EReg()`:

```haxe
var r = new EReg("haxe", "i");
```

Aqui, o `i` é uma flag que faz o padrão ignorar maiúsculas e minúsculas. Existem outras flags, entre elas:

- `g`: substituição global.
- `m`: correspondência multilinha

Entre `~/` e `/`, você escreve os padrões da expressão regular. Por exemplo, você quer procurar uma string que contenha letras de A a Z. Aqui, podemos usar o padrão de intervalo `[A-Z]`. Existem muitos padrões de expressão, entre eles:

- `.`: qualquer caractere
- `*`: repetir zero ou mais vezes
- `+`: repetir uma ou mais vezes
- `[A-Z0-9]`: intervalos de caracteres
