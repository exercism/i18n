# Introdução

## Arrays e vectors

O C++ oferece diferentes contêineres para armazenar elementos do mesmo tipo de forma ordenada.
Existe o `std::array` para contêineres de tamanho fixo e o `std::vector`, que vem com recursos de redimensionamento dinâmico.

### Construção

Quando você declara um array ou um vector, precisa especificar o tipo dos elementos que esse contêiner vai armazenar.
Arrays também precisam de um tamanho.
Veja estes exemplos para ver a inicialização dos dois tipos de contêiner:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

Vectors geralmente precisam de mais espaço, já que alocam memória para crescimento futuro.
Você não precisa especificar um tamanho:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> Nota: você ainda não precisa conhecer a mecânica exata por trás do conceito de template, ele terá seu próprio conceito mais adiante na árvore do syllabus.

### Acesso aos elementos

Vectors e arrays compartilham as mesmas funções para acessar seus elementos.
Você pode usar as funções membro `front` e `back` para obter o primeiro e o último elemento do contêiner.
Também existem `at` e o operador `[]` para acessar elementos específicos.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> Nota: se você escolher uma posição que não está no intervalo do seu contêiner, o `[]` pode levar a um comportamento indefinido.
> A função `at` lançaria uma exceção, o que pode facilitar sua vida a longo prazo.

### Modificadores de vector

Como o `vector` não tem tamanho fixo, é possível adicionar ou remover elementos.
Duas funções comuns para isso são `emplace_back` e `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### Capacidade

Você pode verificar se os contêineres estão vazios com a função membro `empty`.
Se quiser saber o número de elementos, pode usar `size`.
