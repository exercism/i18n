# Introdução

## Enumerações

Até agora, lidamos principalmente com números e strings.
Para modelar o mundo real, podemos querer um número limitado de valores que uma variável pode assumir.
Talvez você queira um tipo dedicado, com alguns valores distintos e nomes distintos.
Por exemplo, numa fábrica de skates, ter o material do shape como uma escolha entre apenas maple, bamboo ou plastic.

Você poderia usar inteiros para codificar esses valores, mas teria que usar código extra para verificar se o sistema está enviando um valor inválido para o material.
O significado desses [_números mágicos_][magic numbers] é difícil de rastrear ao longo do código-fonte, e eles são propensos a confusões.
`enumerations` podem ser usadas para incentivar um código expressivo e para restringir comparações acidentais.

## Exemplo de uso

O termo específico para esse tipo de enumeração é `scoped enumeration`.
O trecho abaixo mostra como escrever um `enumeration` `DeckMaterial`.
Repare na palavra-chave `enum class` e no `;` no final da definição:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```
Agora, veja uma função de preços na loja de skates e repare no operador de resolução de escopo (`::`) especificando um `enumerator` do `enumeration`:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## Escopo

Imagine que você tem um segundo `enumeration` para o material da roda:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```
Embora as rodas e o shape possam ser feitos de _plastic_, os dois não podem ser confundidos.
Eles são _tipos_ diferentes:  `DeckMaterial` plastic e `WheelMaterial` plastic.
Cada `enumeration` terá seus `enumerators` em seu próprio escopo: o próprio `namespace`.
É por isso que eles são chamados de `scoped enumerations`.

## Enumerações sem escopo
Você pode estar pensando que, com um nome como `scoped`, também existiriam enumerações _`unscoped`_, e você está certo.
As `Unscoped enumerations` estão se tornando menos populares porque todas compartilham o mesmo namespace global.
Por causa desse compartilhamento, você não poderia ter duas `unscoped enumerations` com os mesmos `enumerators`, como _plastic_ no exemplo acima.

Além disso, `unscoped enumerations` são convertidas implicitamente para inteiros.
Veja o exemplo abaixo, com um resultado surpreendente:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

Se você quiser converter `scoped enumerations` para inteiros, pode usar `static_cast<int>`.

## Instruções `switch`

Assim como outras linguagens, C++ também oferece uma instrução `switch`.
As instruções `switch` são uma maneira mais curta de escrever longas instruções `if ... else if`.
Para criar um switch, começamos usando a palavra-chave `switch` seguida de um inteiro.
Depois, declaramos cada uma das condições com a palavra-chave `case`.
Também podemos declarar um caso `default`, que será executado quando nenhuma das condições `case` anteriores corresponder.
Cada caso deve terminar com uma instrução `break` (ou `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Continuação da execução

Um ponto importante sobre a construção switch é que o código continua a ser executado até ser interrompido por uma instrução `break` (ou `return`).
Isso pode levar a um comportamento inesperado.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

O principal uso desse recurso de execução continuada é uma instrução com vários rótulos.
Vários resultados de um switch podem apontar para o mesmo trecho de código a ser executado.
Assim, num aplicativo de reservas, por exemplo, a função chamada para grupos de tamanho 2 e 3 pode ser a mesma:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
