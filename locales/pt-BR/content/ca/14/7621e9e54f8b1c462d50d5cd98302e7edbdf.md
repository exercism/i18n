# Introdução

## Booleanos

Elixir representa os valores verdadeiro e falso com o tipo booleano. Existem apenas dois valores: `true` e `false`. Esses valores podem ser atribuídos a uma variável:

```elixir
true_variable = true
false_variable = false
```

Podemos avaliar expressões booleanas estritas usando os operadores `and/2`, `or/2` e `not/1`.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Quando você escreve uma função que retorna um valor booleano, é idiomático terminar o nome da função com um `?`. A mesma convenção pode ser usada em variáveis que guardam valores booleanos.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
