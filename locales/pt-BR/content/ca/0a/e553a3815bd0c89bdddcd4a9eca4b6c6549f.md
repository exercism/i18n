# Introdução

Funções e métodos em Go podem retornar vários valores:

```go
func GetCard() (Card, error) { ... }
```

Todo valor de retorno precisa ser atribuído em ordem e separado por vírgulas:

```go
card, err := GetCard()
```

Cada posição na atribuição declara uma variável.
O Go não compila se alguma variável declarada nunca for usada.
O identificador em branco `_` ocupa o lugar de um nome de variável para ignorar aquele valor de retorno:

```go
card, _ := GetCard()
```

`error` é uma interface embutida.
Um `error` `nil` significa que nenhum erro ocorreu; qualquer valor diferente de `nil` significa que algo deu errado.
Por convenção, funções que podem falhar devem retornar um `error` como último valor.
Quem chama a função precisa verificá-lo antes de usar qualquer outro valor de retorno:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
