# Sobre

Expressões condicionais são usadas para executar código com base em **se** uma condição é **verdadeira** ou **falsa**. Essas expressões são escritas assim:

```haxe
if (condition) {
  expressions
};
```

A saída da condição é do tipo `Bool`, então quando a saída é `true` as expressões são executadas.

Às vezes, quando a condição na verdade é `false`, queremos que outro trecho de código seja executado. É aí que entra a expressão `else`. O `else` executa expressões quando a condição inicial é `false`. Mas e se quisermos verificar a condição para várias possibilidades? Aí usamos `else if (condition)`. Veja um exemplo completo:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
