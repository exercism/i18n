# Introdução

No Haxe, as exceções são uma forma segura de lidar com erros que acontecem durante a execução do código. Toda exceção deve conter uma mensagem que descreva o erro. Podemos _lançar_ exceções com a palavra-chave `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Quando uma exceção é lançada, o código procura um trecho encarregado de tratar o erro. Se não encontrar nenhum, ele exibe a mensagem de erro e também interrompe a execução do programa.

Para tratar exceções no Haxe, usamos o bloco `try-catch`. Essa instrução de bloco é formada por um bloco `try` e um ou mais blocos `catch`. O bloco `try` _tenta_ executar um trecho de código, enquanto o bloco `catch` fica esperando caso alguma exceção seja lançada para _capturá-la_, de modo que a execução não seja interrompida. Quando o bloco `catch` captura uma exceção, ele também executa tudo o que está dentro do bloco:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

O tipo do argumento do bloco `catch` deve ser omitido.
