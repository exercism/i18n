# Impressão

A impressão em Cairo permite exibir mensagens e valores no console, o que facilita depurar programas ou comunicar informações durante a execução.

O sistema de impressão é versátil e direto ao mesmo tempo, e oferece ferramentas para formatar e exibir dados de vários tipos.

## Noções básicas de impressão

O Cairo oferece duas macros principais para imprimir texto no console:

- **`println!`**: imprime a saída em uma nova linha.
- **`print!`**: imprime a saída na mesma linha, sem adicionar uma nova linha.

As duas macros recebem um `ByteArray` como argumento principal, que pode ser uma string simples ou uma string formatada com espaços reservados para valores.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

No exemplo acima:

- Os espaços reservados `{}` são substituídos pelos valores de `x` e `y`.
- `println!` garante que a saída termine com uma nova linha.

## Formatando strings

Às vezes, você pode precisar criar uma string formatada sem imprimi-la imediatamente.

A macro `format!` permite fazer isso.

Ela funciona de forma parecida com `println!`, mas retorna um `ByteArray` em vez de enviar a saída para o console.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

Neste exemplo:

- `format!` combina `s1`, `s2` e `s3` em uma única string, separando-as com hífens (`-`).
- A string resultante pode ser reutilizada ou impressa depois.

## Imprimindo tipos de dados personalizados

Por padrão, o Cairo só consegue imprimir tipos básicos, como inteiros e strings.

Se você tentar imprimir um tipo personalizado, como uma struct, vai encontrar um erro, a menos que o tipo implemente as traits `Display` ou `Debug`.

### Usando `Display` para formatação personalizada

A trait `Display` permite definir como um tipo personalizado deve ser impresso.

Veja um exemplo:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

Neste exemplo:

- A função `fmt` define como a struct `Point` é convertida em uma string imprimível.
- A macro `write!` acrescenta a string formatada ao `Formatter`.

### Depurando com `Debug`

Para fins de depuração, o Cairo oferece a trait `Debug`.

Você pode derivá-la automaticamente para a maioria dos tipos, o que torna rápido e fácil imprimir os detalhes internos das suas structs.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

Neste exemplo:

- `#[derive(Debug)]` gera automaticamente a implementação da trait `Debug`.
- O espaço reservado `{:?}` diz ao `println!` para usar a trait `Debug` na formatação.

## Impressão em hexadecimal

O Cairo permite imprimir inteiros em formato hexadecimal usando o espaço reservado `{:x}`.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

Isso é especialmente útil ao trabalhar com representações de dados de baixo nível.
