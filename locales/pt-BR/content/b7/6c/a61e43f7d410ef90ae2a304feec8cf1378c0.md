# Apêndice
## Bônus

Preserve os agrupamentos de grafemas, ou seja,

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

Você provavelmente vai achar a biblioteca padrão `Unicode` útil para esta tarefa bônus.

Para habilitar o teste de grafemas, adicione `const TEST_GRAPHEMES = true` ao escopo global do seu arquivo.
