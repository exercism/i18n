# Introdução

O Swift oferece uma variação da sua sintaxe ao lidar com closures, conhecida como trailing closure. Um trailing closure surge quando o último parâmetro da lista de parâmetros de uma função tem tipo de função. Nesse caso, se você estiver passando um closure, ele pode ser escrito _depois_ do parêntese de fechamento, e o rótulo do argumento é omitido. Repare que, se a função tiver apenas um parâmetro, os parênteses podem ser omitidos por completo.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
