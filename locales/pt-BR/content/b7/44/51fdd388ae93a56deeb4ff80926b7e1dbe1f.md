# Dicas

## 1. `empty-log`

- `HS{ }` é o literal vazio, mas ele é *compartilhado*: clone-o.

## 2. `sight`

- Uma palavra de `sets`: a inserção destrutiva.

## 3. `seen?`

- `in?` é o teste de pertencimento do protocolo de conjuntos. É a busca por hash em O(1), diferente da varredura linear de `member?` sobre uma sequência.

## 4. `forget-sighting`

- Uma palavra de `sets`: a remoção destrutiva.

## 5. `unique-count`

- `cardinality` retorna o tamanho de um conjunto.

## 6. `reachable`

- Esta é uma busca em largura clássica.
- Mantenha duas estruturas mutáveis: um `HS{ }` para os faróis visitados (para não processar ninguém duas vezes) e um `V{ }` que funciona como uma fila de fronteira (`push` para enfileirar, `pop` para desenfileirar).
- Inicialize os dois com `start`. Depois, `while` a fronteira não estiver vazia, desenfileire um farol, procure os vizinhos dele em `relay-map` (usando `at`) e, para cada vizinho que ainda não estiver em `visited`, `adjoin` ele a `visited` e `push` ele na fronteira.
- Retorne `visited`.
- Variáveis locais (`::` e `:>`) mantêm isso legível; use-as para `visited`, `frontier` e a consulta de vizinhos a cada iteração.
