# Introdução

## Números e strings

O AWK é uma linguagem muito pequena e tem apenas alguns tipos de dados básicos.
Nesta lição, vamos ver números e strings.

### Números

Os números no AWK são implementados como números de ponto flutuante de precisão dupla.
Não há distinção entre inteiros, números de ponto flutuante e números de precisão dupla.

O AWK entende constantes numéricas octais (começando com `0`) e constantes numéricas hexadecimais (começando com `0x` ou `0X`).

#### Operações numéricas

Você pode usar os operadores aritméticos padrão `+`, `-`, `*`, `/`, `%`.
O operador de exponenciação é `^`.
Existem algumas funções numéricas internas, incluindo funções trigonométricas, geração de números aleatórios e `int(x)` para truncar um número para o inteiro mais próximo entre _x_ e zero.

### Strings

Strings no AWK são sequências de caracteres.
Especifique uma constante do tipo string usando aspas duplas.

#### Operações com strings

Existe apenas uma operação com strings: a concatenação.
A concatenação não tem um operador especial;
basta colocar duas strings lado a lado para concatená-las:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` é uma **instrução**, não uma função.
`print` não exige parênteses.
~~~~

O AWK tem uma grande variedade de funções de manipulação de strings.
Vamos conhecê-las em profundidade conforme avançarmos pela trilha.

### Convertendo entre números e strings

Não há operadores explícitos para converter entre números e strings.
O AWK faz isso implicitamente, com base no contexto do programa.
Isso torna muito simples trabalhar com os valores dos campos de entrada: em geral, o AWK faz exatamente o que você quer.

* `print x + y` converte os valores das variáveis `x` e `y` para números, graças à operação numérica `+`.
* `print x y` converte os valores das variáveis `x` e `y` para strings, graças à operação de concatenação.

Se você quiser ser explícito, `0 + x` dá a representação numérica de _x_ e `"" x` dá a representação de _x_ como string.

#### De strings para números

A forma como o AWK converte uma string em número pode ser confusa.
Uma forma simples de pensar nisso é que o AWK lê os "caracteres de número" desde o início da string até encontrar um caractere que não seja número.
Alguns exemplos:

* `"2.5"` é convertido para o número `2.5`;
* `"1e3"` é convertido para o número `1000` (notação científica);
* `"456abc"` é convertido para o número `456` (como `a` não é um "numeral", a conversão para por aí).
* `"abc789"` é convertido para o número `0` (não há números no **início** da string).
