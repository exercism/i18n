# Instruções

Você administra uma boutique de moda online. Sua grande liquidação anual está chegando, então você precisa fazer um levantamento do inventário para garantir que está tudo pronto.

Cada item do inventário é representado por um mapa, e o inventário inteiro é uma lista desses mapas.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Ordene os itens por preço

Implemente a função `sort_by_price/1`. Ela deve receber o inventário e retorná-lo ordenado pelo preço do item, em ordem crescente.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Encontre todos os itens sem preço

Depois de ordenar seu inventário por preço, você percebeu que deve ter cometido um erro ao fazer o levantamento e esqueceu de preencher o preço de alguns itens.

Implemente a função `with_missing_price/1`. Ela deve receber o inventário e retornar uma lista dos itens que não têm preço.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Atualize os nomes dos itens

Você percebeu que alguns nomes de itens têm uma palavra que você não gosta mais de usar. Agora você precisa atualizar todos os nomes de itens que contêm essa palavra.

Implemente a função `update_names/3`. Ela deve receber o inventário, a palavra antiga que você quer remover e uma palavra nova que você quer usar no lugar. Ela deve retornar uma lista de itens com os nomes atualizados.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Aumente a quantidade do item

Alguns itens estavam vendendo especialmente bem, então você encomendou mais, em todos os tamanhos.

Implemente a função `increase_quantity/2`. Ela deve receber um único item e um número `n` e retornar esse item com a quantidade de cada tamanho aumentada em `n`.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Calcule a quantidade total do item

Para saber de quanto espaço você precisa no seu depósito, você precisa saber quantas unidades de cada item você tem no total.

Implemente a função `total_quantity/1`. Ela deve receber um único item e retornar quantas peças você tem no total, em qualquer tamanho.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
