# Getters e setters

Getters e setters são métodos que permitem ler e escrever o valor de uma propriedade de um objeto.
O Crystal tem macros, o que facilita definir getters e setters para uma propriedade.
Macros são uma forma de gerar código em tempo de compilação, o que será abordado mais adiante no conceito de macros.

No Ruby, esses métodos são definidos com os métodos `attr_reader`, `attr_writer` e `attr_accessor` e, na superfície, são muito parecidos com a implementação do Crystal.
O Crystal definiu isso como as macros `getter`, `setter` e `property`.

## Getters

Getter é uma macro que define um método que retorna o valor de uma variável de instância.
Isso significa que você não precisa mais escrever `@` na frente da variável de instância quando quiser acessá-la (em métodos, exceto no initialize); em vez disso, você pode chamar o método que a macro getter definiu.

A macro getter aceita várias variáveis de instância, basta separá-las com vírgulas.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Como você pode ver, usar getter reduz a quantidade de código que você escreve e facilita a leitura.
Além disso, Ruby e Crystal diferem no fato de que o Crystal aceita tanto o nome da variável quanto o símbolo como argumentos para a macro getter.
Símbolos serão abordados mais adiante no conceito de símbolos.

## Setters

Setter é uma macro que define um método que atribui um valor a uma variável de instância.
Essa macro não é tão comum assim; em geral, usa-se a macro `property` em vez dela.
Os métodos criados terão a forma `name_of_method=`; é o `=` que permite definir a propriedade.

Essa definição de método é um pouco especial, já que o argumento que o método recebe fica depois do sinal `=`.
Vários outros métodos especiais no Crystal usam essa sintaxe, como o método `+`.

Assim como na macro getter, quando você quiser atualizar o valor de uma variável de instância depois de definir um setter, pode chamar o método que a macro setter definiu.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

Property é uma macro que define tanto um getter quanto um setter para uma variável de instância.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
