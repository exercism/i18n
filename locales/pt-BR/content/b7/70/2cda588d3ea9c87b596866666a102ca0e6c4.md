# Tipos numéricos

O Crystal tem uma variedade de tipos numéricos diferentes para várias finalidades.
Por exemplo, alguns tipos são mais rápidos, mas têm um intervalo menor de valores possíveis do que outros.
Alguns têm um intervalo maior de valores possíveis, mas são mais lentos.

No Crystal, existem tipos inteiros com sinal e sem sinal.
Os tipos inteiros com sinal podem ser positivos ou negativos.
Os tipos inteiros sem sinal só podem ser positivos.

## Tipos inteiros com sinal

Estes são os [tipos inteiros com sinal][int] no Crystal:

| Tipo     | Tamanho (bits) | Intervalo                                                                                                   |
| -------- | -------------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8              | -128 a 127                                                                                                  |
| `Int16`  | 16             | -32_768 a 32_767                                                                                            |
| `Int32`  | 32             | -2_147_483_648 a 2_147_483_647                                                                              |
| `Int64`  | 64             | -9_223_372_036_854_775_808 a 9_223_372_036_854_775_807                                                     |
| `Int128` | 128            | -170_141_183_460_469_231_731_687_303_715_884_105_728 a 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Os tipos menores usam menos memória e são mais rápidos que os tipos maiores, mas têm um intervalo menor de valores possíveis.

Quando você sabe que os valores estarão dentro de um certo intervalo, o melhor é usar o menor tipo possível para economizar memória e melhorar o desempenho.

O tipo inteiro padrão é `Int32`.
Para declarar um inteiro com um tipo específico, você pode usar o nome do tipo como sufixo, adicionando `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

Você pode usar o método `to_i<bit>` para converter entre tipos inteiros diferentes.
O método `to_i` converte para o tipo inteiro padrão, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Tipos inteiros sem sinal

Estes são os [tipos inteiros sem sinal][uint] no Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

A única diferença entre inteiros com sinal e sem sinal é que os inteiros sem sinal só podem ser positivos.
Para declarar um inteiro sem sinal com um tipo específico, você pode usar o nome do tipo como sufixo, adicionando `<number>_u<bit>`.
Você pode usar o método `to_u<bit>` para converter entre tipos inteiros sem sinal diferentes.
O método `to_u` converte para o tipo inteiro sem sinal padrão, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Tipos de ponto flutuante

Estes são os tipos de ponto flutuante no Crystal:

| Tipo      | Tamanho (bits) | Intervalo            |
| --------- | -------------- | -------------------- |
| `Float32` | 32             | 1.2E-38 a 3.4E+38    |
| `Float64` | 64             | 2.3E-308 a 1.7E+308  |

Existem dois [tipos de ponto flutuante][float] diferentes, um é mais preciso que o outro.

O tipo de ponto flutuante padrão é `Float64`.

Você pode usar o método `to_f<bit>` para converter entre tipos de ponto flutuante diferentes.
O método `to_f` converte para o tipo de ponto flutuante padrão, `Float64`.

## Tipo após uma operação

Quando você executa uma operação entre dois números, o resultado será do tipo do número com a maior precisão.
O ponto flutuante é mais preciso que um inteiro, e um inteiro é mais preciso que um inteiro sem sinal.
Depois, `Float64` é mais preciso que Float32, e assim por diante.

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## Dig Deeper: inteiros sem sinal vs. inteiros com sinal

~~~~exercism/advanced
Por baixo dos panos, o que diferencia inteiros sem sinal de inteiros com sinal é que os inteiros com sinal usam o primeiro bit para armazenar o sinal.
O sinal é positivo ou negativo.
Para inteiros sem sinal, o primeiro bit é usado para armazenar o valor.
Assim, para um inteiro com sinal de 32 bits, o valor máximo é 2^31 - 1.
Para um inteiro sem sinal de 32 bits, o valor máximo é 2^32 - 1.

Se você quiser aprender mais sobre signedness, você pode ler mais sobre isso na [Wikipédia](https://en.wikipedia.org/wiki/Signedness).
