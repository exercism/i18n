# Testes

Há um script Perl com a extensão `.t` contido no diretório `t/`, que será usado para testar sua solução.
Você pode rodar os testes usando o comando:

```bash
`prove`
```

A documentação sobre as asserções usadas nos arquivos de teste pode ser encontrada em [Test2::Manual::Testing::Introduction][test2-manual].

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
