# API do Exercism

## Descrição

A maioria das trilhas de linguagem do Exercism usa a ferramenta de linha de comando `exercism` para buscar e enviar exercícios, que interage com o `exercism.io` por meio de uma API REST. A trilha de linguagem Pharo Smalltalk, por sua vez, usa a mesma API REST para levar exercícios para dentro e para fora da imagem do Pharo, sem precisar de nenhuma ferramenta intermediária. Este documento detalha a API do Exercism, com foco em como ela é usada pela trilha de linguagem Pharo Smalltalk. Ele é destinado a mantenedores das ferramentas do Pharo Smalltalk.

## Cabeçalhos

Todos os endpoints exigem que os cabeçalhos da requisição sejam definidos com os seguintes valores:

```
Authorization: Bearer <token>
```

O valor `<token>` é o token de autenticação da CLI do usuário, disponível em `https://exercism.io/my/settings`.

## Buscando exercícios

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

Na URL acima, `<slug>` é o nome do exercício, por exemplo `hello-world`, e `<language>` é a trilha de linguagem, por exemplo `pharo-smalltalk`.

### Resposta

#### 200

Uma requisição bem-sucedida envia uma resposta contendo um payload JSON. Dentro do JSON estarão informações sobre o exercício e uma URL para baixar os arquivos do exercício.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

O nome da trilha de linguagem é ambíguo, ou os arquivos de exercício enviados não mudaram.

#### 403

A solução não está desbloqueada para o usuário, ou o usuário não ingressou na trilha de linguagem.

#### 404

Não foi possível encontrar a trilha de linguagem ou o exercício.

## Enviando exercícios

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### Resposta

#### 201

Um envio bem-sucedido.

#### 400

Um arquivo enviado é grande demais (mais de um megabyte), ou a solução é duplicada.

#### 403

A solução não está acessível ao usuário. O ID de usuário da solução e o ID do usuário atual não coincidem.

#### 404

O ID da solução não foi encontrado.
