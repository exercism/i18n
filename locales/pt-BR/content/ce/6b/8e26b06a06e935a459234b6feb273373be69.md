# Sobre

Um dos aspectos essenciais de trabalhar com números no Ruby é a distinção entre números inteiros (números sem dígitos depois do separador decimal) e números de ponto flutuante (números com zero ou mais dígitos depois do separador decimal).
Eles são implementados por meio das classes [`Integer`][integer-ruby] e [`Float`][float-ruby].

```ruby
a = 1
b = 1.0
a.class
#=> Integer
b.class
#=> Float
```

- A aritmética é feita com os [operadores aritméticos][arithmetic-operators] básicos (`+`, `-`, `*`, `/`).
  Os números podem ser comparados com os [operadores de comparação][comparison-operators] padrão.
- As operações aritméticas básicas entre instâncias de `Integer` sempre resultam em uma instância de `Integer`.
- As operações aritméticas básicas entre instâncias de `Float` resultam em outras instâncias de `Float`.
- As operações aritméticas básicas entre instâncias de `Integer` e instâncias de `Float` resultam em instâncias de `Float`.
- As classes `Float` e `Integer` têm métodos que convertem valores de um tipo para o outro.
  Os números `Integer` são exatos em unidades inteiras, enquanto o `Float` tem precisão fracionária em relação a um número inteiro.
  Isso significa que converter um float em um inteiro pode causar perda de precisão.

```ruby
4.9.to_i
#=> 4

5.to_f
#=> 5.0

7 - 3.0
#=> 4.0

2 == 4
#=> false

1.0 == 1
#=> true
```

Uma condicional `if` permite executar código apenas quando uma condição for satisfeita:

```ruby
x = 5

if x == 5
  # Execute logic if x equals 5
elsif x > 7
  # Execute logic if x greater than 7
else
  # Execute logic in all other cases
end
```

Às vezes você quer executar uma instrução (ou várias) quando uma condição _não_ for verdadeira. Para situações como essa, o Ruby tem a palavra-chave `unless`:

```ruby
x = 4
unless x == 5
  # Execute logic if x does not equal 5
else
  # Execute logic if x == 5
end
```

Se você quiser executar um código diferente dependendo do valor de uma variável, a instrução `case` do Ruby pode ser útil:

```ruby
y = 5
case y
when 3
  # Execute logic if y equals 3
when 5
  # Execute logic if y equals 5
else
  # Execute logic in all other cases
end
```

O mesmo problema às vezes pode ser resolvido com tipos diferentes de condicionais, e às vezes uma delas é mais adequada ao problema do que a outra.
É uma boa ideia parar um momento e também considerar as outras duas opções ao usar qualquer uma das três condicionais.
