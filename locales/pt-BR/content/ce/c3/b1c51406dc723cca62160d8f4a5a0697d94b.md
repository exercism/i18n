# Ordem dos problemas da trilha Rust

A verdadeira fonte de referência para a ordem dos problemas e os tópicos é o [config.json](config.json), mas este arquivo documenta o raciocínio por trás da ordem dos problemas nele.

## Nossa abordagem

Ordenamos os problemas pensando em quem está aprendendo Rust. Com esse público em mente, seguimos duas regras ao adicionar novos problemas.

- Um exercício deve introduzir um único conceito novo
- Os exercícios devem progredir do básico de Rust até conceitos avançados

### Um conceito novo

Se a solução de um problema exige que os estudantes usem tanto `Result` quanto `HashMap`, pelo menos um desses conceitos deve ter sido introduzido por um problema anterior.

Se a trilha tem vários problemas que dependem de um mesmo conceito, agrupe-os para reforçar o aprendizado.

### Progredir pelo Rust

#### Problemas iniciais

Os problemas iniciais devem focar a sintaxe e os conceitos de Rust que aparecem em muitas linguagens de programação: condicionais, laços e funções de ordem superior.

#### Problemas intermediários

Os problemas do meio da trilha devem introduzir conceitos menos comuns, como `Result`, `Option` e traits. Ou sintaxes como `while let`.

Ao longo da seção intermediária da trilha, os estudantes devem se familiarizar com uma ampla variedade de conceitos de Rust.

#### Problemas finais

Os problemas no fim da trilha devem fazer uma de duas coisas:

1. Introduzir conceitos avançados: lifetimes, concorrência, unsafety
2. Exigir uma solução complexa que sintetize todo o conhecimento que os estudantes acumularam até aqui
