# Dicas

## 1. Converter a data do agendamento

- A classe `LocalDateTime` tem um método para [converter][localdatetime-parse] uma `String` em um `LocalDateTime`.
- Use um [`DateTimeFormatter`][datetimeformatter-docs] com um padrão personalizado para converter um formato de data e hora não padrão.

## 2. Verificar se um agendamento já passou

- Instâncias de `LocalDateTime` têm [métodos][localdatetime-methods] para compará-las com outros `LocalDateTime`.
- Há um [método][localdatetime-methods] para obter a data e a hora atuais.

## 3. Verificar se o agendamento é à tarde

- É possível acessar a parte de hora de uma instância de `LocalDateTime` por meio de um de seus [métodos][localdatetime-methods].

## 4. Descrever a hora e a data do agendamento

- Use um [`DateTimeFormatter`][datetimeformatter-docs] com um padrão personalizado para formatar o `LocalDateTime`.
- Os testes rodam como se estivessem em uma máquina nos Estados Unidos, então verifique se o formatador [usa o locale correto][datetimeformatter-ofpattern-with-locale].

## 5. Retornar a data do aniversário

- A classe `LocalDate` tem um [método][localdate-methods] para obter a data atual.
- É possível acessar o ano de uma instância de `LocalDate` por meio de um de seus [métodos][localdate-methods].
