# Anexo às instruções

## Notas específicas do exercício em Rust

Esta versão em Rust é um pouco diferente das versões em outras linguagens deste exercício. Em vez de exigir que você retorne erros para valores fora do intervalo, usamos o sistema de tipos forte do Rust para limitar a entrada. É muito mais fácil fazer uma função lidar com todas as entradas válidas do que exigir que quem usa o seu módulo trate os erros.

### Extensão

Adicione a capacidade de converter até o valor máximo de u64: `18_446_744_073_709_551_615`.

Para ter uma ideia da saída que isso deve produzir, veja o último caso de teste.
