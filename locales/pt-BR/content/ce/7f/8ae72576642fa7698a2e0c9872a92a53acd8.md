# Dicas

## Geral

- Lembre-se de que a sobrecarga de operadores é implementada por meio de traits no Cairo
- O atributo `#[derive(PartialEq)]` implementa automaticamente a comparação de igualdade
- Ao implementar `PartialOrd`, você só precisa implementar o método `lt`; os outros operadores de comparação são derivados dele

## 1. Implementando `Add`

- O método `add` deve combinar os campos `value` dos dois TimeShards
- Lembre-se de que os TimeShards contêm valores `i32`, que já têm a adição definida

## 2. Implementando `Sub`

- Parecido com a adição, mas usa o operador de subtração entre os campos `value`
- A ordem dos operandos faz diferença na subtração

## 3. Implementando `PartialOrd`

- O método `lt` deve comparar os campos `value` dos TimeShards
- Assim que `lt` estiver implementado, os outros operadores de comparação (`>`, `<=`, `>=`) funcionarão automaticamente
- Lembre-se de que `PartialEq` já é derivado, então você não precisa implementá-lo manualmente
