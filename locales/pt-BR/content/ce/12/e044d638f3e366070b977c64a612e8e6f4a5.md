# Dicas

## 1. Hora de misturar um suco

- `cond` (em [`combinators`][combinators]) é a forma mais limpa de
  escolher um valor com base em uma cadeia de testes de igualdade.

## 2. Reabastecer o estoque de gomos de limão

- Um laço `while` com dois estados, os gomos ainda necessários
  e os limões ainda disponíveis, é a escolha natural. Declarar
  esses estados com `::` e `:> name!` mantém o corpo do laço legível.
- `unclip ( seq -- rest first )` retira o primeiro limão, pronto
  para alimentar `wedges-from-lime`.

## 3. Listar os horários de misturar cada pedido na fila

- Uma única palavra de [`sequences`][sequences] faz o trabalho inteiro.

## 4. Terminar o turno

- O formato é o mesmo da Tarefa 2: um laço `while` controlado por
  dois estados, os minutos restantes do turno e os pedidos ainda
  esperando. Pare assim que um dos dois acabar.

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
