# Descrição

Um terno pitagórico é um conjunto de três números naturais, {a, b, c}, para os quais,

```text
a² + b² = c²
```

e tal que,

```text
a < b < c
```

Por exemplo,

```text
3² + 4² = 5².
```

Dado um número inteiro N de entrada, encontre todos os ternos pitagóricos para os quais `a + b + c = N`.

Por exemplo, com N = 1000, existe exatamente um terno pitagórico para o qual `a + b + c = 1000`: `{200, 375, 425}`.
