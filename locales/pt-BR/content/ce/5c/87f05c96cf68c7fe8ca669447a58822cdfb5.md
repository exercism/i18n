# Introdução

O sistema de erros de Factor tem três peças: `throw` (em
[`kernel`][kernel]) lança um erro, `recover` (em
[`continuations`][continuations]) captura um erro, e `ERROR:` define
uma classe de erro do tipo tupla.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` executa a quotation *try*; se ela
lançar um erro, o erro é empilhado e a quotation *recovery* é executada.

`ERROR:` declara tanto a classe *quanto* uma palavra construtora que
lança uma instância nova:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
