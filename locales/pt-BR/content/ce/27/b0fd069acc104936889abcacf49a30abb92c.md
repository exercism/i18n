# Dicas

## 1. Descreva um personagem

- Modifique os [construtores][constructor-syntax] das classes `Wizard` e `Warrior` para passar o tipo de personagem delas ao [construtor da classe base][instance-constructors].
- Armazene o tipo de personagem como um [campo][fields] na classe `Character`.
- A classe `Character` herda implicitamente da classe `object`, cujo [método `ToString()` você pode sobrescrever][override-tostring].

## 2. Faça com que os personagens não sejam vulneráveis por padrão

- Implemente o método `Vulnerable()` na classe `Character` para sempre retornar `false`.

## 3. Permita que os Magos preparem um feitiço

- Adicione um campo à classe `Wizard` para armazenar se um feitiço foi preparado e atualize isso no método `PrepareSpell()`.
- O feitiço deve começar como não preparado.

## 4. Faça com que os Magos fiquem vulneráveis quando não tiverem preparado um feitiço

- Sobrescreva o método `Vulnerable()` na classe `Wizard` para tornar os Magos vulneráveis se eles não tiverem preparado um feitiço.

## 5. Calcule os pontos de dano de um Mago

- Use uma [condicional][if-else] para retornar os pontos de dano, levando em conta o valor do campo de preparação do feitiço.

## 6. Calcule os pontos de dano de um Guerreiro

- Você pode chamar um método na instância de `Character` recebida para determinar a vulnerabilidade dela.
- Use uma [condicional][if-else] para retornar os pontos de dano, levando em conta a vulnerabilidade do alvo.
