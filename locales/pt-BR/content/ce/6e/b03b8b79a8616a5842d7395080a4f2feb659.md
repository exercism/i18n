# Apêndice das instruções

## Algumas observações adicionais para a implementação em C++

Este exercício usa o [`unordered_set`][set].
Provavelmente você vai precisar da função [`emplace`][emplace] para adicionar elementos ao conjunto.

Você pode esbarrar em [`const`][const], porque ele ainda não apareceu no syllabus.
Quando vem antes de uma variável, funciona como uma proteção.
Variáveis `const` não podem ser alteradas.
Este exercício também apresenta a palavra-chave [`unsigned`][unsigned].
Ela dobra o intervalo do inteiro ao qual é prefixada, mas não deixa que ele fique negativo.
