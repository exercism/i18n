# Introdução

Fazer malabarismo com a pilha funciona bem para palavras curtas. Quando uma palavra tem várias entradas e você precisa se referir a elas pelo nome, o Factor oferece *locals*: ligações nomeadas introduzidas com `::` (para definições de palavras) ou `[| | ]` (para lambdas inline), os dois vêm de [`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Dentro de uma quotation, `[| inputs | body ]` é uma lambda com entradas nomeadas:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
