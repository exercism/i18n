# Use guardas

[comment]: # (Este erro é gerado quando a solução não usa guardas de forma alguma)

Use [guardas](https://hexdocs.pm/elixir/master/guards.html) para impedir que `two_fer/1` execute código com entradas não binárias.

> Lembre-se, [strings](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) são consideradas [dados binários](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) em Elixir.

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> Esta guarda pode ser testada no `iex`

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
