# Introdução

Uma `String` em Haxe é um objeto que representa texto imutável como uma sequência de caracteres Unicode (letras, dígitos, pontuação etc.). Usamos aspas duplas para definir uma instância de `String`:

```haxe
var fruit:String = "Apple";
```

As strings são manipuladas chamando os métodos da string. Depois que uma string é construída, seu valor nunca pode mudar. Quaisquer métodos que pareçam modificar uma string, na verdade, retornam uma nova string.

É possível concatenar (somar) várias strings entre si. A maneira mais simples de fazer isso é usar o operador `+`.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Para qualquer formatação de string mais complexa do que uma concatenação simples, prefira a interpolação de string. Para usar interpolação em uma string, coloque-a entre aspas simples (`'`). Depois, você pode usar o cifrão (`$`) para acionar a interpolação:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
