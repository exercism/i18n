# Algoritmo para torcer para um time da NBA

## História

Neste exercício, você é um grande fã de esportes e acabou de descobrir uma paixão pelo basquete da NBA. Como está começando agora no basquete da NBA, você está fazendo uma imersão na história da NBA, acompanhando times, técnicos, suas estatísticas de vitórias e derrotas e comparando uns com os outros.

Como você ainda não tem um time favorito, também vai desenvolver um algoritmo para descobrir se deve torcer para um determinado time.

## Tarefas

Estas são tarefas de exemplo que se encaixam no exercício do algoritmo para torcer para um time da NBA:

- Definir registros para um time da NBA, seu técnico e suas estatísticas
- Criar o técnico de um time
- Criar as estatísticas de um time
- Criar um time
- Substituir o técnico
- Verificar se há duplicatas
- Verificar se você deve torcer para um time
