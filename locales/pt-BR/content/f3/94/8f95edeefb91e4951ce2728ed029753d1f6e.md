# Introdução

## Listas

Como o nome da linguagem que estamos usando, Lisp, vem de _LIST Processing_ (processamento de listas), dá para supor que ela tenha recursos para lidar com listas de itens. E você tem razão!

Embora o Common Lisp tenha outras estruturas de dados além das listas, as listas ainda são muito usadas.

Uma lista em Common Lisp é uma sequência de itens. Ela também é chamada de **cons** (na maioria das vezes, por razões históricas).
Os próprios itens não precisam ser do mesmo tipo.
Por exemplo, você pode ter uma lista com `1`, `two`, `"III"`.

### Criando listas

Você pode simplesmente digitar uma lista com aspas assim: `'(1 two "III")`, e isso fará com que uma lista seja criada e avaliada (ela é avaliada como `(1 two "III")`).

Também há duas funções principais usadas para criar listas: `list` e `cons`.

`list` recebe zero ou mais argumentos e é avaliada como uma lista criada com esses valores:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons` recebe dois itens e cria uma lista que tem o primeiro item como seu `car` (a cabeça da lista) e o segundo item como seu `cdr` (o resto da lista):

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

As funções `car` e `cdr` podem ser usadas para acessar o `car` e o `cdr` de uma lista.

(`first` e `rest` são sinônimos de `car` e `cdr` e funcionam exatamente do mesmo jeito.)

### Comprimento e acesso aleatório

O comprimento de uma lista pode ser determinado com o uso de `length`.
Uma lista vazia tem comprimento zero.

Um item qualquer pode ser acessado com `nth` (repare que as listas têm índice começando em zero).

Não é um erro pedir um índice maior do que o comprimento da lista.
Em vez disso, ela é avaliada como `nil`:

```lisp
(nth 23 '(short list)) ; => nil
```

Também existem vários métodos auxiliares para acessar os primeiros itens de uma lista: `first`, `second`, `third`, e assim por diante até `tenth`. Legal, né?

### Combinando listas

Duas ou mais listas podem ser combinadas com `append`:

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

Cada argumento passado para `append` precisa ser uma lista.
