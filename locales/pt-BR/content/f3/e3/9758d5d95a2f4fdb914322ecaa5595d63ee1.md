# Palavras-chave estáticas de classe

Uma classe é uma unidade de organização de código em PHP, muitas vezes representando uma instância de uma coisa, um serviço ou um procedimento.
Usando as palavras-chave `static` e `self`, propriedades e métodos podem existir em referência à classe para todas as instâncias (ou nenhuma).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limitação

Métodos estáticos de classe só podem chamar outras propriedades estáticas ou métodos de classe da própria classe.
