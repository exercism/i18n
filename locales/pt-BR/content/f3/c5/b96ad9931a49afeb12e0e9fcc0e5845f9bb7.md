# Instruções

Neste exercício, você tem a tarefa de escrever o software de um dispositivo de criptografia que funciona realizando transformações nos dados. Você precisa de uma forma de criar funções complicadas de maneira flexível, combinando funções mais simples.

Para cada tarefa, retorne uma função anônima que possa ser invocada a partir do escopo de chamada.

## 1. Crie um somador

Implemente `secret_add`. Ela deve retornar uma função que recebe um argumento e soma a ele o argumento passado para `secret_add`.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. Crie um subtrator

Implemente `secret_subtract`. Ela deve retornar uma função que recebe um argumento e subtrai desse argumento o segredo passado para `secret_subtract`.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. Crie um multiplicador

Implemente `secret_multiply`. Ela deve retornar uma função que recebe um argumento e o multiplica pelo segredo passado para `secret_multiply`.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. Crie um divisor

Implemente `secret_divide`. Ela deve retornar uma função que recebe um argumento e o divide pelo segredo passado para `secret_divide`.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. Crie um combinador de funções

Implemente `secret_combine`. Ela deve retornar uma função que recebe um argumento e aplica a ele, em ordem, as duas funções passadas para `secret_combine`.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
