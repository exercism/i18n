# Dicas

## 1. Criar uma lista vazia

Criar uma lista vazia é igual a criar uma lista com itens. Você pode fazer isso usando `list` ou usando `quote` em uma lista vazia.

## 2. Adicionar uma nova linguagem à lista

O Clojure tem uma função do core que consegue [adicionar um item ao início de uma lista](https://clojuredocs.org/clojure.core/cons).

## 3. Verificar a última linguagem adicionada

Assim como as outras Lisps, o Clojure tem uma função que [retorna o primeiro item de uma lista](https://clojuredocs.org/clojure.core/first).

## 4. Remover a primeira linguagem da lista

Da mesma forma, o Clojure também tem uma função para [retornar uma lista sem o primeiro item](https://clojuredocs.org/clojure.core/rest).

## 5. Contar as linguagens da lista

O [número de itens](https://clojuredocs.org/clojure.core/count) de uma lista pode ser retornado facilmente com uma função do core do Clojure.

## 6. Juntar tudo

Lembre-se de que chamadas de função podem ser aninhadas.
