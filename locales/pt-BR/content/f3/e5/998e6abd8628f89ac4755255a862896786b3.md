# Introdução

## Binários

O Elixir oferece uma sintaxe elegante para trabalhar com dados binários, como já vimos com a forma especial `<<>>` usada para trabalhar com [bitstrings][exercism-bitstrings].

O tipo binário é uma especialização do tipo bitstring. Enquanto bitstrings podem ter qualquer comprimento (qualquer quantidade de [bits][wiki-bit]), binários têm um número de bits divisível por 8. Ou seja, ao trabalhar com binários, costumamos pensar em termos de [bytes][wiki-byte] (8 bits). Um byte pode representar números inteiros de `0` a `255`. É comum trabalhar com valores de byte em [hexadecimal][wiki-hexadecimal], `0x00 - 0xFF`.

Literais binários são definidos usando a forma especial de bitstring `<<>>`. Ao definir um literal binário, podemos usar literais inteiros e strings. Valores inteiros maiores que 255 sofrem overflow e apenas os últimos 8 bits do inteiro são usados. Por padrão, o modificador `::binary` é aplicado ao valor. Podemos concatenar binários com o operador `<>/2`.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

Um _byte nulo_ é outro nome para `<<0>>`.

### Casamento de padrões em dados binários

O [casamento de padrões][exercism-pattern-matching] é estendido até mesmo a binários, e podemos fazer casamento de padrões sobre uma parte dos dados binários, assim como faríamos com uma lista.

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

Assim como em outros tipos de casamento de padrões, podemos usar isso em assinaturas de função para fazer a correspondência ao selecionar entre várias cláusulas de função.
