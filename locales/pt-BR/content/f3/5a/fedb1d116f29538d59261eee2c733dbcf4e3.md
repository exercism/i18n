# Sobre

Rust implementa o tipo [char][char type] para representar um único caractere. Um literal `char` fica entre aspas simples, como `'a'`.
Cada `char` ocupa quatro bytes e representa um único [valor escalar Unicode][unicode scalar].

No entanto, um [`char`][character type] nem sempre é o que pensamos ser uma letra. Existem algumas línguas, como o híndi, que usam [diacríticos][diacritics],
que são símbolos especiais que modificam o caractere ao qual estão ligados. Embora, em Rust, o diacrítico seja um `char` separado, o que costumamos
considerar uma letra é o diacrítico junto com o caractere que ele modifica.

O termo para um caractere e seu diacrítico é [aglomerado de grafemas][grapheme cluster]. Existem crates externos que podem ser usados para processar
aglomerados de grafemas, como o [unicode-segmentation][unicode-segmentation].

Exemplo

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

imprime

```rust
2
'u'
'\u{308}'
```

'\u{308}' é outra forma de escrever um literal `char`. O `\u` indica que é um `char` Unicode, e `{308}` é o número Unicode único daquele caractere
ou diacrítico.
