# Instruções

Neste exercício, você vai construir o tratamento de erros de uma calculadora simples de números inteiros.
A calculadora deve dar suporte às operações de adição, multiplicação e divisão, retornando o resultado como uma string formatada.
Você também vai implementar o tratamento de erros para lidar com operações ilegais e com a divisão por zero.

O objetivo é ter uma calculadora funcionando que retorna uma string no seguinte formato:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Implemente as operações da calculadora

A função principal desta tarefa será `SimpleCalculator::calculate`, que recebe três argumentos: dois números inteiros e um `ByteArray` que representa a operação.
Implemente as seguintes operações:

- **Adição** com o símbolo `+`
- **Multiplicação** com o símbolo `*`
- **Divisão** com o símbolo `/`

## 2. Trate operações ilegais

Se o símbolo da operação for qualquer coisa diferente de `+`, `*` ou `/`, a calculadora deve entrar em pânico ou retornar um erro:

- Se a operação for uma string vazia, entre em pânico com uma mensagem de erro `ByteArray` `"Operation cannot be an empty string"`.
- Para qualquer outra operação inválida, retorne `Result::Err("Operation is out of range")`.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. Trate os erros ao dividir por zero

Ao tentar dividir por `0`, a calculadora deve entrar em pânico com uma mensagem de erro indicando que a divisão por zero não é permitida.
O resultado retornado deve ser um valor `felt252` igual a `'Division by zero is not allowed'`.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
