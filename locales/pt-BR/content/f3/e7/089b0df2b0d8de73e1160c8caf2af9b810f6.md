# Instruções

Seu amigo acabou de te enviar uma mensagem com um segredo importante.
Como não queria que outras pessoas conseguissem lê-la com facilidade, a mensagem foi criptografada por meio de uma série de manipulações de bits.
Você vai precisar escrever os métodos que ajudam a descriptografar a mensagem.

## 1. Desloque os bits de volta

O primeiro passo para descriptografar a mensagem é desfazer o deslocamento feito na criptografia, deslocando os bits de volta para a direita.
Haverá outros passos no processo de descriptografia que assumem que 0s são inseridos pelo lado esquerdo.

Implemente o método `Secrets.shiftBack`, que recebe um valor e o número de posições a deslocar e realiza o deslocamento.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Defina alguns bits

Em seguida, há alguns bits que precisam ser definidos como 1.

Implemente o método `Secrets.setBits`, que recebe um valor e uma máscara e retorna o resultado de definir como 1 os bits do valor.
Um bit do valor deve ser definido como 1 quando o bit correspondente na máscara também for 1.
Todos os outros bits devem permanecer inalterados.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Inverta bits específicos

Alguns bits são invertidos durante a criptografia.
Eles precisarão ser invertidos de volta para descriptografar a mensagem.

Implemente o método `Secrets.flipBits`, que recebe um valor e a máscara.
A máscara indica quais bits do valor devem ser invertidos.
Se o bit for 1 na máscara, o bit é invertido no valor.
Todos os outros bits permanecem inalterados.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Zere bits específicos

Por fim, também há certos bits que sempre descriptografam para 0.

Implemente o método `Secrets.clearBits`, que recebe um valor e uma máscara.
Os bits em `value` devem ser definidos como 0 quando o bit na máscara for 1.
Todos os outros bits devem permanecer inalterados.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
