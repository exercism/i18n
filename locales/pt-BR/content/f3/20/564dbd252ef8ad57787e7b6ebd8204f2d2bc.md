# Instruções

Neste exercício, você vai processar linhas de log.

Cada linha de log é uma string formatada da seguinte forma: "[<LEVEL>]: <MESSAGE>*".

## 1. Obter a mensagem de uma linha de log

Implemente a função `LogLevels.message()` para retornar a mensagem de uma linha de log, com os espaços em branco do início e do fim removidos.

## 2. Obter o nível de log de uma linha de log

Implemente a função `LogLevels.logLevel()` para retornar o nível de log de uma linha de log em letras minúsculas.

## 3. Reformatar uma linha de log

Implemente o método `LogLevels.reformat()`, que recebe uma linha de log e uma string de localização e reformata tudo em uma mensagem contendo duas linhas.
A primeira linha é formatada como `<LEVEL>@<LOCATIOON>:`, em que:

* `<LEVEL>` é o nível de log em letras minúsculas (como em 2. Obter o nível de log de uma linha de log).
* `<LOCATION>` é a localização dada como segundo parâmetro.

A segunda linha contém exatamente dois espaços, seguidos da mensagem de log (como em 1. Obter a mensagem de uma linha de log):

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
