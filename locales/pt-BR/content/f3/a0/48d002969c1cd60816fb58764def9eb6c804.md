# Instruções

Karl quer acompanhar uma lista de linguagens de programação para aprender no site do Exercism.
Karl precisa conseguir adicionar novas linguagens, remover as antigas e verificar se certas linguagens estão na lista.
Seria muito empolgante se Karl quiser aprender Java ou Kotlin!

## 1. Defina uma função para verificar se a lista de linguagens está vazia

Karl precisa saber se a lista de linguagens dele fica vazia em algum momento, para poder procurar mais linguagens para aprender!
Defina um método chamado `isEmpty` que retorna `true` se não houver linguagens na lista.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Defina uma função para adicionar uma linguagem à lista

Karl está ansioso para aprender Kotlin e Python!
Ajude Karl a começar definindo um método chamado `addLanguage`, que recebe a linguagem que ele quer aprender e a adiciona à lista.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Defina uma função para remover uma linguagem da lista

Karl decidiu que não quer aprender Scala agora.
Ajude Karl a removê-la da lista definindo um método chamado `removeLanguage`, que recebe a linguagem que ele está removendo e a remove da lista.

```java
languageList.removeLanguage("Scala");
```

## 4. Defina uma função para retornar o primeiro item da lista

Karl quer lembrar a primeira linguagem que ele adicionou à lista (que ainda está na lista).
Defina um método chamado `firstLanguage` que retorna a primeira linguagem da lista.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Defina uma função para retornar quantas linguagens estão na lista

Karl precisa saber quantas linguagens ele está tentando aprender.
Ajude Karl a encontrar a resposta definindo um método chamado `count`, que retorna o número de linguagens na lista.

```java
int two = languageList.count(); // 2
```

## 6. Defina uma função para determinar se uma linguagem está na lista

Karl está tentando lembrar se queria aprender Python ou Ruby.
Defina um método chamado `containsLanguage`, que recebe a linguagem sobre a qual ele está perguntando, para que Karl descubra!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Defina uma função para determinar se a lista é empolgante

Se Karl quiser aprender Java ou Kotlin, isso é muito empolgante!
Defina um método chamado `isExciting` que retorna true se Karl quiser aprender Java ou Kotlin.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
