# Sobre

`reduce` é o fold geral do Factor: ele percorre uma sequência,
passando um acumulador por uma quotation binária que recebe
o acumulador corrente e o próximo elemento e produz o novo
acumulador.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

Um valor inicial personalizado permite que `reduce` expresse folds
que `sum` ou `product` não conseguem. Por exemplo, o maior valor
de uma sequência com um padrão caso todos os elementos percam:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

O valor inicial `0` participa da comparação, então uma sequência
totalmente negativa ainda produz `0` em vez do seu menor valor.

## `produce`: o unfold

O dual de `reduce` é `produce` (em [`sequences`][sequences]):
onde `reduce` *consome* uma sequência, `produce` *gera* uma.
Uma quotation de predicado testa o estado corrente; enquanto ela
retorna um valor verdadeiro, uma quotation de corpo produz o
próximo elemento.

```
produce ( pred quot -- seq )
```

Usados juntos, `reduce` e `produce` formam o par fold/unfold do
Factor.

## Reduções cumulativas

A família cumulativa em [`math.statistics`][math.statistics]
retorna uma sequência do mesmo comprimento que a entrada, em que
cada elemento é a redução sobre o prefixo até aquela posição,
inclusive:

| palavra       | operação acumulada |
|---------------|--------------------|
| `cum-sum`     | total acumulado    |
| `cum-product` | produto acumulado  |
| `cum-min`     | mínimo acumulado   |
| `cum-max`     | máximo acumulado   |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

As reduções cumulativas são úteis quando você quer inspecionar
*como* uma quantidade evoluiu ao longo da sequência, não apenas o
seu valor final. Encadeá-las também é útil: a saída de uma
cumulativa é ela própria uma sequência, pronta para alimentar
outra.
