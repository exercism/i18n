# Sobre

A [forma especial with][with] oferece uma maneira de focar no "caminho feliz" de uma série de passos que podem falhar e de lidar com as falhas depois.

Digamos que você queira validar um nome de usuário com várias verificações. Você pode recorrer ao `case`:

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

Pode até estar legível agora, mas se você adicionar mais verificações aninhadas, vai ficar bem mais bagunçado. Nessa situação, use o `with`:


```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

A cada passo, se uma cláusula corresponder, a cadeia continua até o bloco `do` ser executado. Se uma correspondência falhar, a cadeia para e a cláusula que não correspondeu é retornada.

Você pode usar guardas na cadeia, assim como o operador `=` para correspondências comuns.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

Por fim, você tem a opção de usar um bloco `else` para capturar correspondências que falharam e modificar o valor de retorno.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

O `else` é como uma condicional `case` para qualquer valor da cláusula `with` que não corresponda. O primeiro valor que corresponder será usado.
