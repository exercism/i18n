# Dicas

## 1. Implemente a interface `Stringer` para o tipo `TemperatureUnit`

- O tipo `TemperatureUnit` já foi criado para você e representa uma unidade de temperatura
- Repare que já existem 2 constantes criadas para você desse tipo: `Celsius` e `Fahrenheit`, que representam uma temperatura em Celsius e Fahrenheit, respectivamente
- Adicione um método `String()` ao tipo `TemperatureUnit` para que ele satisfaça a interface `Stringer`.
  Esse método deve retornar a string `"°C"` se a unidade de temperatura for Celsius ou `"°F"` se a unidade de temperatura for Fahrenheit

## 2. Implemente a interface `Stringer` para o tipo `Temperature`

- Adicione um método `String()` ao tipo `Temperature` para que ele satisfaça a interface `Stringer`
- O método `String()` deve retornar uma string com o valor numérico da temperatura e a unidade de temperatura separados por um espaço (`<temperature> <unit>`)
- A struct `Temperature` contém uma `TemperatureUnit` e um `int`.
  Você pode usar [fmt.Sprintf][sprintf] para ajudar a formatar essa string
- Como `TemperatureUnit` já implementa a interface `Stringer` (da tarefa 1), as funções do pacote `fmt` como [fmt.Sprintf][sprintf] vão saber como formatá-la quando você usar os [verbos de formatação][fmt] `%v` ou `%s`

## 3. Implemente a interface `Stringer` para o tipo `SpeedUnit`

- O tipo `SpeedUnit` já foi criado para você e representa uma unidade de temperatura
- Repare que já existem 2 constantes criadas para você desse tipo: `KmPerHour` e `MilesPerHour`, que representam uma velocidade em quilômetros por hora e milhas por hora, respectivamente
- Adicione um método `String()` ao tipo `SpeedUnit` para que ele satisfaça a interface `Stringer`.
  Esse método deve retornar a string `"km/h"` se a unidade de velocidade for quilômetros por hora ou `"mph"` se a unidade de velocidade for milhas por hora.

## 4. Implemente a interface `Stringer` para `Speed`

- Adicione um método `String()` ao tipo `Speed` para que ele satisfaça a interface `Stringer`
- O método `String()` deve retornar uma string com o valor numérico da velocidade e a unidade de velocidade separados por um espaço (`<speed> <unit>`)
- A `Speed` contém uma `SpeedUnit` e um `int`.
  Você pode usar [fmt.Sprintf][sprintf] para ajudar a formatar essa string
- Como a struct `TemperatureUnit` já implementa a interface `Stringer` (da tarefa 3), as funções do pacote `fmt` como [fmt.Sprintf][sprintf] vão saber como formatá-la quando você usar os [verbos de formatação][fmt] `%v` ou `%s`
- Para inserir um `%` na string final ao usar [fmt.Sprintf][sprintf], use `%%` na string de formatação.

## 5. Implemente a interface `Stringer` para o tipo `MeteorologyData`

- A `Speed` contém os campos `Temperature` e `Speed`, entre outros campos.
  Você pode usar [fmt.Sprintf][sprintf] para ajudar a formatar essa string
- O método `String` deve retornar os dados meteorológicos no seguinte formato: `"<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity"`
- Como os tipos `Temperature` e `Speed` já implementam a interface `Stringer` (das tarefas 2 e 4), as funções do pacote `fmt` como [fmt.Sprintf][sprintf] vão saber como formatá-lo quando você usar os [verbos de formatação][fmt] `%v` ou `%s`

[fmt]: https://pkg.go.dev/fmt
