# Introdução

Se você quer construir algo usando um Raspberry Pi, provavelmente vai usar _resistores_.
Assim como nos exercícios anteriores `Resistor Color Duo` e `Resistor Color Trio`, você vai traduzir as faixas de cores dos resistores para rótulos legíveis para humanos.

- Cada resistor tem um valor de resistência.
- Resistores são pequenos, tão pequenos que, se você imprimisse o valor da resistência neles, seria difícil de ler.
  Para contornar esse problema, os fabricantes imprimem faixas codificadas por cores nos resistores para indicar seus valores de resistência.
- Cada faixa funciona como um dígito de um número.
  Por exemplo, se imprimissem uma faixa brown (valor 1) seguida de uma faixa green (valor 5), isso corresponderia ao número 15.

## Instruções

Neste exercício, você vai criar um programa útil para não precisar memorizar os valores das faixas.
O programa recebe 1, 4 ou 5 cores como entrada e retorna o valor correto, em ohms.
As faixas de cores são codificadas da seguinte forma:

- Black: 0
- Brown: 1
- Red: 2
- Orange: 3
- Yellow: 4
- Green: 5
- Blue: 6
- Violet: 7
- Grey: 8
- White: 9

Em `resistor-color trio` você decodificou as três primeiras cores.
Por exemplo: orange-orange-brown corresponde ao valor principal `330`.
Neste exercício, você vai precisar adicionar _tolerância_ à mistura.
A tolerância é a quantidade máxima que um valor pode ficar acima ou abaixo do valor principal.
Por exemplo, se a última faixa for green, a tolerância máxima será ±0.5%.

A faixa de tolerância terá um destes valores:

- Grey - 0.05%
- Violet - 0.1%
- Blue - 0.25%
- Green - 0.5%
- Brown - 1%
- Red - 2%
- Gold - 5%
- Silver - 10%

O resistor de quatro faixas é montado assim:

| Faixa_1 | Faixa_2 | Faixa_3     | faixa_4   |
| ------- | ------- | ----------- | --------- |
| Valor_1 | Valor_2 | Multiplicador | Tolerância |

Ou seja

- orange-orange-brown-green seria 330 ohms com tolerância de ±0.5%.
- orange-orange-red-grey seria 3300 ohms com tolerância de ±0.05%.

A diferença entre um resistor de quatro e um de cinco faixas é que o de cinco faixas tem uma faixa extra para indicar um valor mais preciso.

| Faixa_1 | Faixa_2 | Faixa_3 | Faixa_4     | faixa_5   |
| ------- | ------- | ------- | ----------- | --------- |
| Valor_1 | Valor_2 | Valor_3 | Multiplicador | Tolerância |

Ou seja

- orange-orange-orange-black-green seria 333 ohms com tolerância de ±0.5%.
- orange-red-orange-blue-violet seria 323M ohms com tolerância de ±0.10.

Também existem resistores de uma faixa.
Resistores de uma faixa têm apenas a cor black com valor 0.

Este exercício é sobre traduzir as cores das faixas dos resistores para um rótulo:

"... ohms ...%"

Então, uma entrada de "orange", "orange", "black", "green" deve retornar:

"33 ohms ±0.5%"

Quando há mais de mil ohms, dizemos "kiloohms".
Isso é parecido com dizer "quilômetro" para 1000 metros e "quilograma" para 1000 gramas.

Então, uma entrada de "orange", "orange", "orange", "grey" deve retornar:

"33 kiloohms ±0.05%"

Quando há mais de um milhão de ohms, dizemos "megaohms".

Então, uma entrada de "orange", "orange", "blue", "red" deve retornar:

"33 megaohms ±2%"
