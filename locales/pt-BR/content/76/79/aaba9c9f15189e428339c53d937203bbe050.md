# Introdução

JavaScript é uma linguagem dinâmica, que dá suporte a estilos orientados a objetos, imperativos e declarativos (por exemplo, programação funcional).

## (Re)Atribuição

Existem algumas formas principais de atribuir valores a nomes em JavaScript: usando variáveis ou constantes. No Exercism, as variáveis são sempre escritas em [camelCase][wiki-camel-case]; as constantes são escritas em [SCREAMING_SNAKE_CASE][wiki-snake-case]. Não existe um guia oficial a seguir, e várias empresas e organizações têm guias de estilo diferentes. _Fique à vontade para escrever as variáveis do jeito que quiser_. A vantagem de escrevê-las do jeito que os exercícios são preparados é que elas serão destacadas de forma diferente na interface web e na maioria das IDEs.

Variáveis em JavaScript podem ser definidas usando a palavra-chave [`const`][mdn-const], [`let`][mdn-let] ou [`var`][mdn-var].

Uma variável pode referenciar valores diferentes ao longo de sua existência quando se usa `let` ou `var`. Por exemplo, `myFirstVariable` pode ser definida e redefinida várias vezes usando o operador de atribuição `=`:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

Em contraste com `let` e `var`, variáveis definidas com `const` só podem receber atribuição uma vez. É assim que se definem constantes em JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 Em um Exercício de Conceito mais adiante, a diferença entre a atribuição / vinculação de uma _constante_ e o valor de uma _constante_ é explorada e explicada.

## Declarações de funções

Em JavaScript, unidades de funcionalidade são encapsuladas em _funções_, geralmente agrupando funções no mesmo arquivo quando elas pertencem umas às outras. Essas funções podem receber parâmetros (argumentos) e podem _retornar_ um valor usando a palavra-chave `return`. As funções são invocadas usando a sintaxe `()`.

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 Em JavaScript existem _muitas_ formas diferentes de declarar uma função. Essas outras formas são diferentes do uso da palavra-chave `function`. A trilha tenta apresentá-las aos poucos, mas se você já as conhece, fique à vontade para usar qualquer uma delas. Na maioria dos casos, usar uma ou outra não é melhor nem pior.

## Expondo para outros arquivos

Para disponibilizar uma `function`, uma constante ou uma variável em _outros arquivos_, elas precisam ser [exportadas][mdn-export] usando a palavra-chave `export`. Outro arquivo pode então [importá-las][mdn-import] usando a palavra-chave `import`. Isso também é conhecido como sistema de módulos. Um ótimo exemplo é como todos os testes funcionam. Cada exercício tem pelo menos um arquivo, por exemplo `lasagna.js`, que contém a _implementação_. Além disso, há pelo menos um outro arquivo, por exemplo `lasagna.spec.js`, que contém os _testes_. Esse arquivo _importa_ as entidades públicas (ou seja, exportadas) para testar a implementação:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
