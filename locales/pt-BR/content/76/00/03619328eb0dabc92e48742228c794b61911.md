# Introdução

Em Common Lisp, strings são [vetores][concept-vectors] de [caracteres][concept-characters].
Uma string é escrita como caracteres entre aspas duplas (por exemplo, "Hello World!").

O predicado `stringp` retorna verdadeiro apenas se o valor dado for uma string.

É possível dividir strings em sub-strings com a função `subseq`, que recebe a string, um índice inicial e, opcionalmente, um índice final.
A indexação começa em zero.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

É possível comparar strings quanto à igualdade com `string=`.
Se maiúsculas e minúsculas devem ser ignoradas, você pode usar `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Operações como converter strings para maiúsculas, para minúsculas e capitalizá-las podem ser feitas com `string-upcase`, `string-downcase` e `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
