# Instruções

Você trabalha em uma loja de moda online.
Você tem a ideia de criar um recurso no site em que looks são sugeridos ao usuário.
Interessam os looks possíveis, seus preços e a eliminação das opções que não combinam.

~~~~exercism/note
Embora possa haver diferentes formas de resolver os problemas a seguir, todos podem ser resolvidos com uma compreensão de lista.
~~~~

## 1. Crie uma peça de roupa


Implemente `clothingitem()` para receber dois `Tuple`s, um de `categories` e outro das respectivas `qualities`.
A função deve retornar um `Dict` com as `categories` como chaves e as `qualities` como valores.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

Sua função deve ser capaz de lidar com qualquer número de `categories`.

## 2. Sugira combinações

Implemente `get_combinations()` para receber um `Tuple` de peças de cima e um `Tuple` de peças de baixo.
A função deve retornar o `cartesian product` dos tuples como um array 2-D (ou seja, uma `Matrix`).
Cada entrada é uma combinação `(top, bottom)` como um `Tuple`.
As peças de cima variam ao longo das linhas, as peças de baixo variam ao longo das colunas.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. Some os preços dos looks

Cada peça de roupa tem um campo `price` associado a ela, então pode ser útil conseguir comparar o preço total dos looks.
Implemente `get_prices()`, que recebe um array de combinações de roupas.
A função deve retornar um array com formato semelhante, com os preços dos looks em suas respectivas posições.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. Filtre os looks que não combinam

Cada peça de roupa tem um campo `base_color`.
Use esse campo para remover todas as combinações em que a peça de cima e a peça de baixo têm a mesma cor base.
Implemente `filter_clashing()` para receber um array de combinações de roupas.
Retorne um array 1-D (ou seja, um `Vector`) das combinações resultantes.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
