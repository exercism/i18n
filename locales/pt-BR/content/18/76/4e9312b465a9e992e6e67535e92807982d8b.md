# Apêndice de instruções

## Notas de implementação

Defina uma função recognizeDigit como descrito no Passo 1 das instruções, mas faça com que ela reconheça todos os dez dígitos, de 0 a 9.
Escolha o que você quiser para os parâmetros e os valores de retorno, mas faça com que ela seja útil como sub-rotina para o passo 2.

Para o Passo 2, defina

func Recognize(string) []string

e implemente-a usando recognizeDigit.

As strings de entrada testadas aqui têm um \n no início de cada linha e nenhum \n no final da última linha. (Isso deixa os literais de string brutos mais legíveis.)

Para ganhar pontos extras, trate os dados mal formatados com elegância.
O que você deve fazer com uma casa incompleta?
Descartar?
Preencher com espaços?
Sinalizar com o caractere `"?"`?
O que você deve fazer se o primeiro caractere não for `\n`?
