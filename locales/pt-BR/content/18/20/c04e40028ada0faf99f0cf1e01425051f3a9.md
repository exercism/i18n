# Dicas

## Geral

- Cada tarefa é uma única palavra cujo corpo é composto por palavras de embaralhamento do vocabulário `kernel`. Nenhuma aritmética é necessária.
- Use `.s` no listener para imprimir a pilha inteira enquanto você experimenta.

## 1. Troque as duas caixas de cima

- Uma única palavra de embaralhamento inverte os dois valores do topo: `swap`.

## 2. Remova a caixa derramada

- `drop` remove o valor do topo; as duas caixas de baixo ficam intactas.

## 3. Guarde uma cópia da caixa de baixo

- `over` copia o penúltimo valor para o topo.

## 4. Organize o convés

- Traga a caixa de baixo para o topo com `rot`, jogue-a fora com `drop`, duplique o novo topo com `dup` e depois use `rot` novamente para colocar as peças em ordem. Acompanhe a pilha palavra por palavra: `x y z` → `y z x` → `y z` → `y z z` → `z z y`.
