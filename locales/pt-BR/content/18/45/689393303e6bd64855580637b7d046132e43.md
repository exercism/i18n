# Depurando localmente

Quando você roda os testes da trilha de Bash com [Bats](https://github.com/bats-core/bats-core), o Bats captura tanto STDOUT quanto STDERR para asserções de saída.

```exercism/caution
Isso funciona localmente com o `bats`, mas **não** no editor online do Exercism.
```

Se você quiser imprimir saída de depuração sem afetar o resultado do teste, escreva-a no descritor de arquivo (fd) 3.

```bash
echo 'debug message' >&3
```

O Bats mostra a saída escrita no fd 3 durante a execução dos testes, mas não inclui essa saída em asserções como `assert_output`.

Exemplo de execução:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

Isso é útil quando você está rodando os testes localmente.
