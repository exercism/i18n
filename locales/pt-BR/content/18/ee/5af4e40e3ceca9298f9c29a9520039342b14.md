# Introdução

Uma exceção definida pelo usuário é qualquer classe definida no seu código que deriva de `System.Exception`. Ela está sujeita a todas as regras da herança de classes, mas, além disso, o compilador e o runtime da linguagem tratam essas classes de um jeito especial: suas instâncias podem ser lançadas e capturadas fora do fluxo normal de controle, como vimos no exercício `exceptions`.

As exceções definidas pelo usuário costumam servir para carregar informações extras, como uma mensagem e outros dados relevantes, e deixá-las disponíveis para as rotinas de captura.
