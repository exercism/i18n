# Sobre

## Tipos de função

Já vimos antes como as assinaturas de função são definidas usando o nome da função seguido de uma lista de rótulos de parâmetros separados por vírgula, junto com seus tipos, seguida de `->` e do tipo dos valores retornados pela função.

Se removermos todos os nomes e rótulos dessa assinatura, sobra o [tipo da função][function-types].

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Repare que os tipos das duas primeiras funções são iguais, `(String, Int) -> String`, mesmo que as duas funções funcionem de maneiras bem diferentes. Ambas recebem uma `String` e um `Int` como entrada e retornam uma `String`. E, como dá para ver pelo tipo da terceira função, mesmo que a função não pareça retornar nada, na verdade ela retorna `()`, o único valor do tipo `Void`. Repare que `()` e `Void` são intercambiáveis como nomes de tipo, então o tipo de `printString` também poderia ser escrito como `String) -> Void`.

Esses tipos podem ser usados da mesma forma que qualquer outro tipo em Swift, por exemplo, podem ser usados na declaração de variáveis ou constantes. E, como funções são valores em Swift, funções já existentes podem ser atribuídas a essas constantes/variáveis:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

Como acontece com outras variáveis/constantes, o valor que você atribui a ela precisa ser do tipo correto:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Tipos de função como tipos de parâmetro

Como tipos de função podem ser usados em qualquer lugar onde outros tipos podem ser usados, segue que [eles podem ser usados como tipos de parâmetro][functions-as-parameters] e passados para outras funções, sendo chamados de dentro delas.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## Tipos de função como tipos de retorno

Da mesma forma, [tipos de função podem ser usados como tipos de retorno][functions-as-returns] de funções. Em outras palavras, dá para escrever funções que criam e retornam outras funções. Ao criar essas funções, a função retornada pode usar os outros parâmetros passados para a função ou as variáveis locais criadas dentro da função pai.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## Captura de valores

Como vimos com a função `makeAdder(base:)` acima, funções aninhadas conseguem acessar os parâmetros e as variáveis das funções que as envolvem. Além disso, elas conseguem manter o acesso a esses valores depois que a função que as contém termina. Essa ação de obter e manter o acesso é conhecida como [_captura_][capturing-values].

## Funções de ordem superior

Funções que recebem funções como parâmetros e/ou retornam funções são conhecidas como funções de ordem superior. O Swift tem muitas funções de ordem superior em suas várias bibliotecas. Por exemplo, o método `sorted(by:)`, disponível nas coleções do Swift como o `Array`, que, para um array com elementos do tipo `T`, recebe uma função do tipo `(T, T) -> Bool` que determina qual de dois valores deve vir antes do outro em um Array ordenado, retornando `true` se o valor da esquerda deve aparecer primeiro e `false` se o valor da direita deve aparecer primeiro.

Outro exemplo é o método `contains(where:)` das coleções, que, para uma coleção com elementos do tipo `T`, recebe uma função do tipo `(T) -> Bool` que retorna `true` se o elemento satisfaz alguma propriedade e `false` caso contrário. O `contains(where:)` então retorna `true` se algum elemento da coleção satisfizer essa propriedade.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
