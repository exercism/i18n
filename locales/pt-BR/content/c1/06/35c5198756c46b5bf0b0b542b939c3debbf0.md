# Anexo às instruções

## Pacote de ordenação

Este exercício exige que você ordene um array, mas isso não vem embutido na biblioteca padrão.
Você poderia escrever sua própria biblioteca de ordenação, mas uma opção melhor é usar o [pacote sorts](https://github.com/diku-dk/sorts).

Você pode usar esse pacote na sua solução rodando o seguinte comando no diretório da solução:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

Depois, importe os [algoritmos de ordenação que você quiser](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) com:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
