# Introdução

## Correspondência de padrões

Uma expressão `if/elif/else` pode ser usada para executar lógica de forma condicional. O F# também tem outra forma mais poderosa de fazer isso: a correspondência de padrões. Com a correspondência de padrões, um valor pode ser testado em relação a um ou mais _padrões_. Um exemplo desses padrões é o _padrão constante_, que compara um valor com uma constante (por exemplo, `1` ou `"hello"`).

No F#, a correspondência de padrões é feita com a palavra-chave `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Embora isso possa parecer com instruções `switch` de outras linguagens, a correspondência de padrões começa a se destacar quando você também usa outros padrões. Um deles é o _padrão de variável_, que permite capturar um valor:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

Em alguns casos, você pode querer adicionar uma condição extra a um padrão. Isso é conhecido como _guarda_ (cláusula), que pode ser adicionada com a palavra-chave `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

No exemplo acima, nem toda entrada possível terá um padrão correspondente. O compilador detecta isso e emite um aviso. Isso é conhecido como _verificação de exaustividade_. Para resolver o aviso, é preciso tratar todos os casos. Para isso, pode-se usar o _padrão curinga_, que é um padrão que corresponde a qualquer valor:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

A correspondência de padrões testa um valor em relação a cada padrão, de cima para baixo, até encontrar um padrão correspondente e executar a lógica associada a esse padrão. A ordem dos padrões faz diferença!
