# Sobre

As [tuplas][tuples] agrupam vários valores em um único valor composto.
Diferente dos arrays, os valores de uma tupla não precisam ser do mesmo tipo, e o tamanho de uma tupla é fixo depois de criada.

Crie uma tupla colocando valores separados por vírgula entre parênteses:

```swift
let order = ("biscuits", 2.99, 3)
```

Você também pode declarar as anotações de tipo explicitamente:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Para extrair elementos individuais de uma tupla sem nome, use a sintaxe de índice começando em zero (`.0`, `.1` etc.):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Tuplas nomeadas

Você pode dar nomes aos elementos de uma tupla no momento em que a define:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Dar nome aos elementos deixa o código mais legível e permite acessar os elementos com a notação de ponto usando os rótulos:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

Você também pode incluir os nomes dos elementos na anotação de tipo:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Modificar tuplas

Se uma tupla for declarada como variável (`var`), você pode atualizar seus elementos:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Retornar vários valores

Embora as funções em Swift só possam retornar um único valor, retornar uma tupla permite empacotar e [retornar vários valores][multiple-return-values] de uma função:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Decomposição de tuplas

Você pode decompor (desempacotar) os valores de uma tupla em constantes ou variáveis separadas:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

A decomposição de tuplas também funciona diretamente em laços `for-in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
