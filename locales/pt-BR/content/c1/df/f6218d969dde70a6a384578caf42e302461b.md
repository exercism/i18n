# Instruções

Neste exercício, você vai processar linhas de log.

Cada linha de log é uma string formatada da seguinte forma: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de log:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Você tem três tarefas.

## 1. Analisar o nível de log

Defina um enum `LogLevel` que tem seis elementos correspondentes aos níveis de log acima.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

Em seguida, implemente o método `LogLine.getLogLevel()` que retorna o nível de log analisado de uma linha de log:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. Lidar com nível de log desconhecido

Infelizmente, de vez em quando algumas linhas de log têm um nível de log desconhecido.
Para lidar com essas linhas de log de forma elegante, adicione um elemento `UNKNOWN` ao enum `LogLevel`, que deve ser retornado ao analisar um nível de log desconhecido:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. Converter linha de log para formato curto

O nível de log de uma linha de log é bastante verboso.
Para reduzir o espaço em disco necessário para armazenar as linhas de log, foi desenvolvido um formato curto: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

O nível de log codificado é um mapeamento simples de um nível de log para um número:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

Implemente o método `LogLine.getOutputForShortLog()` que consegue gerar o formato encurtado de linha de log:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
