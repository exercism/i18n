# Anexo das instruções

## Dicas

Para completar este exercício, você precisa criar o tipo de dados `CustomSet`, com instâncias de `Eq` e `Show`, e implementar as seguintes funções:

- `delete`
- `difference`
- `empty`
- `fromList`
- `insert`
- `intersection`
- `isDisjointFrom`
- `isSubsetOf`
- `member`
- `null`
- `size`
- `toList`
- `union`

Você vai encontrar uma declaração de dados e assinaturas de tipo fictícias já prontas, mas cabe a você definir as funções e criar um tipo de dados, um newtype ou um sinônimo de tipo que faça sentido.

Se você tiver interesse em escrever uma implementação eficiente, mas não souber bem por onde começar, o melhor material introdutório que conheço é "Purely Functional Data Structures", de Chris Okasaki, e você pode ler uma versão dele aqui:
https://www.cs.cmu.edu/~rwh/theses/okasaki.pdf
