# Dicas

## 1. Calcule o valor de qualquer carta

- Um [`switch`][ref-switch] de estilo antigo funciona bem aqui, já que ele só precisa lidar com uma única carta a cada chamada.
- Usar [`case_match`][ref-case_match] é outra opção, mas as aspas em torno das strings não podem ser omitidas nesse caso.

## 2. Implemente a lógica de decisão da primeira rodada

- O [`case_when`][ref-case_when] ajuda bastante nesta tarefa.
- Dá para resolver a tarefa no R base usando uma série de condicionais, mas de um jeito menos elegante.

[ref-case_match]: https://dplyr.tidyverse.org/reference/case_match.html
[ref-case_when]: https://dplyr.tidyverse.org/reference/case_when.html
