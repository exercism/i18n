# Introdução

Um método é uma função com um argumento especial, o _receptor_.
O receptor aparece em sua própria lista de argumentos, entre a palavra-chave `func` e o nome do método.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

Você só pode definir um método com um receptor cujo tipo esteja definido no mesmo pacote que o método.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

O método da struct pode ser chamado com notação de ponto.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

Repare como chamamos o método `Greetings()` na instância `p` de `Person`.
É exatamente como você chama métodos em uma linguagem de programação orientada a objetos.

Lembre-se: um método é só uma função com um argumento receptor.
Os métodos ajudam a evitar conflitos de nomes. Como um método está ligado a um tipo de receptor específico, você pode ter o mesmo nome de método em tipos diferentes.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

Existem dois tipos de receptores: receptores de valor e receptores de ponteiro.

Todos os métodos que vimos até agora têm um receptor de valor. Isso significa que eles recebem uma cópia do valor passado ao método. Assim, qualquer alteração feita ao receptor dentro do método não é visível para quem chamou.

Você pode declarar métodos com receptores de ponteiro para modificar o valor para o qual o receptor aponta.
Isso é feito colocando um `*` antes do nome do tipo.
Por exemplo, com o tipo `rect`, um receptor de ponteiro seria declarado como `*rect`.
Essas modificações também são visíveis para quem chama o método.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
