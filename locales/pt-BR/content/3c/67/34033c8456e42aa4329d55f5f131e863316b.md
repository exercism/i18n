# Sobre

Um buffer de string é uma forma eficiente de construir uma string grande acrescentando pequenos elementos. Ao contrário de String, uma instância de StringBuf não é imutável, no sentido de que pode ser passada como argumento para funções que a modificam acrescentando mais valores.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
