# Dicas

## Geral

- Leia sobre processos no [guia oficial Getting Started][getting-started-processes].
- Leia [este post do blog][mullen-processes] sobre processos do Elixir.

## 1. Inicie a máquina

- A máquina deve rodar em um novo processo. Existe [uma função embutida que inicia um novo processo][kernel-spawn-1].
- Use uma função anônima de aridade 0 ao iniciar um novo processo. Essa função ainda não precisa fazer nada.

## 2. Reporte o estado da máquina

- Você vai precisar de uma nova função nomeada. Você pode nomeá-la, por exemplo, `loop`.
- Essa nova função deve aceitar um argumento, o estado.
- A função anônima de aridade 0 da etapa anterior pode chamar a nova função nomeada, passando o estado inicial.
- A nova função nomeada precisa responder a mensagens.
- Existe [uma função embutida que espera uma mensagem chegar na caixa de entrada do processo][kernel-receive].
- Existe [uma função embutida que envia uma mensagem para outro processo][kernel-send].
- Use recursão para esperar por mais de uma mensagem.

## 3. Distribua números

- Essa etapa é conceitualmente igual à anterior. A única diferença é a necessidade de atualizar o estado da máquina.

## 4. Pare a máquina

- Essa etapa não exige enviar nenhuma mensagem como resposta.
- Um processo encerra se não tiver mais código para executar.
- Quando você precisar criar um bloco de código "vazio" em Elixir, pode usar `nil` como a única expressão desse bloco de código.
- Esse é um caso base da função recursiva.

## 5. Ignore mensagens inesperadas

- Essa etapa não exige enviar nenhuma mensagem como resposta.
- Você pode usar `_` para casar com todas as mensagens que não corresponderam aos padrões anteriores.
