# Introdução

Objetos podem manter seu próprio estado ao definir _variáveis de instância_, que são criadas ao colocar `@` antes de um nome de variável.

```ruby
@name = 2
```

Objetos geralmente definem seu estado inicial em um método `initialize`, que é chamado automaticamente ao chamar `new` em uma classe.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

O método `initialize` também pode receber argumentos, para que cada instância possa começar com um estado personalizado:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Considere as variáveis _de instância_ como privadas em relação a leituras e escritas externas. Métodos _de instância_ devem ser usados para obter e definir variáveis de instância:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
