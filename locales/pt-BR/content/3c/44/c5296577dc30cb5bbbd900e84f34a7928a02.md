# Dicas

## Geral

- A sintaxe `0b00` pode ser usada para especificar um int em sintaxe binária em vez
  de sintaxe decimal.

## 1. Codificar ácido nucleico em valor binário

- É possível fazer pattern matching no tipo de nucleotídeo com uma expressão case.

## 2. Decodificar o valor binário para o ácido nucleico

- A sintaxe de int binário pode ser usada em padrões.
- Retorne `Error(Nil)` se o int não for um nucleotídeo válido.

## 3. Codificar uma lista de DNA

- A função `encode_nucleotide` pode ser usada para codificar um único nucleotídeo.

## 4. Decodificar um bit array de DNA

- A sintaxe de int binário pode ser usada dentro de um padrão de bit array.
- Retorne `Error(Nil)` se o bit array restante não for longo o suficiente para conter
  um nucleotídeo.
