# Introdução

O Hashmap é uma coleção usada para armazenar pares chave-valor. Ele permite que tipos arbitrários sejam usados como chaves e valores. O Hashmap tem inserção e recuperação rápidas e é muito útil, por exemplo, para fazer contagens de frequência, armazenar relacionamentos etc. O Hashmap também oferece a poderosa API `entry`, que torna o uso dele ergonômico.
