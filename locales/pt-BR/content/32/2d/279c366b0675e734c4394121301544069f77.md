# Introdução

Às vezes você não precisa do custo extra de criar um objeto com estado.
Nesses casos, dá para usar um `module`.

Um módulo é muito parecido com uma classe (na verdade, `Module` é um ancestral de `Class` na hierarquia de objetos). A principal diferença é que, em vez de usarmos métodos de instância, usamos métodos de classe.
Os métodos de classe começam com `self.` e são chamados diretamente em um módulo.

Por exemplo:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
