# Instruções

Enquanto planejam uma noite de jogos com os amigos, o grupo decide revisitar os favoritos da infância. Seu amigo alemão sugere _Mensch ärgere Dich nicht_ (_Man, Don't Get Angry_), um clássico em muitos países europeus (parecido com o _Ludo_ inglês ou o _Parcheesi_ norte-americano).

Para se preparar para o jogo, você decide implementar a função de rolagem de dados em Elixir.

Em _Mensch ärgere Dich nicht_, os jogadores rolam um dado de 6 lados para determinar o próximo movimento. Se tiverem sorte e tirarem 6, podem rolar e jogar de novo.

## 1. Faça uma rolagem de um dado de 6 lados

Implemente a função `d6/0`, que vai escolher aleatoriamente um número inteiro entre 1 e 6 a cada chamada.

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. Continue rolando enquanto tirar seis

Implemente a função `roll/0`. Ela deve retornar um stream de rolagens de dado. As rolagens devem seguir as regras do jogo. Se eu tirar um seis, posso rolar de novo. Caso contrário, pare de rolar. Use a função `d6/0` definida no passo anterior.

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. Permita usar um dado viciado

Para facilitar o teste do seu código, permita usar um dado viciado.

Estenda a função `roll/0`. Ela deve aceitar um argumento opcional: uma função. Se o argumento for passado, use-o para fazer a rolagem do dado. Caso contrário, recorra a `MenschAergereDichNicht.d6/0`.

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
