# Sobre

As tuplas são usadas comumente para agrupar informações de forma informal. Um padrão comum em Elixir é agrupar valores de retorno de funções junto com um status.

```elixir
File.read("hello.txt")
# => {:ok, "World"}

File.read("invalid.txt")
# => {:error, :enoent}
```

- Literais de tupla são delimitados por chaves, `{}`.
- As tuplas podem conter qualquer tipo de dado em memória contígua, alocada no momento em que a tupla é criada.
- As tuplas permitem acesso de leitura em tempo constante.
- Ao manipular uma tupla, em vez de modificar a tupla existente, uma nova é criada.
- As características de desempenho das tuplas as tornam ideais para armazenar informações relacionadas juntas, mas não para armazenar coleções de itens que exigem iteração ou que podem crescer ou diminuir. Neste último caso, [uma lista é mais apropriada][getting-started-lists-or-tuples].
- Os módulos [`Kernel`][kernel-module] e [`Tuple`][tuple-module] têm funções úteis para trabalhar com tuplas.
