## 1. Sugira uma combinação

- Na compreensão de listas, use dois _geradores_ para criar o produto cartesiano.

## 2. Filtre combinações que não combinam

- Você pode usar _pattern matching_ para desconstruir no _gerador_ e vincular os campos a uma variável.
- Use uma expressão de _filtro_ para retornar false quando as cores base coincidirem.

## 3. Filtre pelo preço da combinação

- Há várias [funções para listas de palavras-chave][kw-module] disponíveis para recuperar opções de uma lista de palavras-chave.
- Use uma expressão de _filtro_ para retornar false quando o preço combinado for maior que o preço máximo.
