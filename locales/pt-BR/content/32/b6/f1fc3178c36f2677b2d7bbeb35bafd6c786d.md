# Introdução

Você trabalha em uma empresa que vende fontes pelo site dela.
Eles querem mostrar uma frase diferente cada vez que alguém visualiza uma fonte no site.
Para dar uma noção completa da fonte, as frases aleatórias devem usar **todas** as letras do alfabeto inglês.

Eles estão promovendo uma competição para receber sugestões de frases que possam usar.
Você é responsável por verificar os envios para ver se são válidos.

~~~~exercism/note
Pangram vem do grego, παν γράμμα, pan gramma, que significa "todas as letras".

O pangrama em inglês mais conhecido é:

> The quick brown fox jumps over the lazy dog.
~~~~
