# Instruções

Daphne vem trabalhando em um sistema para rodar e registrar os resultados de seus experimentos. Parte do código ficou um pouco verbosa e repetitiva, então ela pediu que você escrevesse algumas expressões `use` para ajudar a limpá-lo.

## 1. Defina a função `with_retry`

Às vezes um experimento pode falhar por causa de um erro isolado, então, se um experimento falhar, Daphne quer tentar de novo para ver se funciona na segunda vez.

Defina a função `with_retry`, que recebe como argumento uma função que retorna um resultado.

Se a função retornar um valor `Ok`, `with_retry` deve retornar esse valor.

Se a função retornar um valor `Error`, `with_retry` deve chamar a função de novo e retornar o resultado dessa chamada.

Daphne vai usar a função assim:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. Defina a função `record_timing`

Daphne registra quanto tempo cada experimento leva para rodar, chamando uma função de registro de tempo antes e depois de cada experimento.

Defina a função `record_timing`, que recebe dois argumentos:
- Uma função de registro de tempo, que não recebe argumentos e retorna `Nil`.
- Uma função de experimento, que não recebe argumentos e retorna um resultado.

`record_timing` deve chamar a função de registro de tempo, depois chamar a função de experimento, depois chamar a função de registro de tempo de novo e, por fim, retornar o resultado da função de experimento.

Daphne vai usar a função assim:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. Defina a função `run_experiment`

Um experimento é composto de três fases: a preparação, a ação e o registro. As três fases retornam resultados, e cada fase precisa do resultado bem-sucedido da fase anterior para rodar.

Defina a função `run_experiment`, que recebe quatro argumentos:
- O nome do experimento como uma `String`.
- Uma função de preparação, que não recebe argumentos e retorna um resultado.
- Uma função de ação, que recebe como argumento o valor `Ok` da função de preparação e retorna um resultado.
- Uma função de registro, que recebe como argumentos o valor `Ok` das funções de preparação e de ação e retorna um resultado.

Se as três funções tiverem sucesso, `run_experiment` deve retornar `Ok(#(experiment_name, recording_data))`.

Se alguma das funções retornar um valor `Error`, `run_experiment` deve retornar esse valor.

Daphne vai usar a função assim:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
