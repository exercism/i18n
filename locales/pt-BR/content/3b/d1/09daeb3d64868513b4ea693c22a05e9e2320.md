# Sobre

Um dos aspectos principais de trabalhar com números em C# é a distinção entre inteiros (números sem dígitos depois do separador decimal) e números de ponto flutuante (números com zero ou mais dígitos depois do separador decimal).

Os dois tipos numéricos mais usados em C# são `int` (um inteiro de 32 bits) e `double` (um número de ponto flutuante de 64 bits).

```csharp
int i = 123;
double d = 54.29;
```

Tanto inteiros quanto números de ponto flutuante podem usar o caractere `_` como _separador de dígitos_, o que ajuda na hora de definir números grandes:

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

A aritmética é feita usando os [operadores aritméticos][arithmetic-operators] padrão (`+`, `-`, `*`, etc.). Os números podem ser comparados usando os [operadores de comparação][comparison-operators] padrão (`<`, `>=`, etc.) e os operadores de [igualdade][equality-operators] (`==`) e [desigualdade][equality-operators] (`!=`).

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

Ao converter entre tipos numéricos, existem dois tipos de conversão numérica:

1. Conversões implícitas: nenhum dado é perdido e nenhuma sintaxe adicional é necessária.
2. Conversões explícitas: dados podem ser perdidos e é preciso usar sintaxe adicional na forma de um _cast_.

Como um `int` tem menos precisão que um `double`, converter de um `int` para um `double` é seguro e, portanto, é uma conversão implícita. Já converter de um `double` para um `int` pode significar perder dados, então isso exige uma conversão explícita.

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
