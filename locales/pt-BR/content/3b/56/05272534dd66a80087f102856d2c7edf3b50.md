# Mutabilidade

O Cairo, com seu design voltado para blockchain, implementa por padrão um modelo de memória imutável.
Isso significa que, depois que um valor é escrito na memória, ele não pode ser sobrescrito, apenas lido.
No entanto, o Cairo oferece um mecanismo para criar variáveis mutáveis usando a palavra-chave `mut`.
Quando uma variável é declarada como mutável e o valor é alterado, o novo valor é escrito em uma nova célula de memória, e a variável é atualizada para apontar para a nova célula.
Esse mecanismo traz flexibilidade sem abrir mão dos benefícios da imutabilidade.

No exemplo abaixo, a variável `x` é declarada como imutável.
Se o valor de `x` for alterado, o compilador vai gerar um erro.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

Podemos declarar `x` como uma variável mutável usando a palavra-chave `mut`.
Assim, o valor de `x` pode ser alterado depois de declarado.

```rust
let mut x = 5;
x = 10;
```

No fim das contas, decidir se usar mutabilidade ou não é com você, e depende do que você achar mais claro naquela situação específica.

## Constantes

Assim como as variáveis imutáveis, as constantes são valores associados a um nome que não podem mudar, mas há algumas diferenças entre constantes e variáveis:

- As constantes são declaradas com a palavra-chave `const`
- Não é permitido usar `mut` com constantes
- O tipo do valor sempre precisa ser declarado explicitamente
- As constantes só podem ser declaradas no escopo global
- As constantes só podem receber expressões constantes, não o resultado de um valor calculado em tempo de execução

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

É possível usar a macro `consteval_int!` para criar uma variável `const` que é o resultado de algum cálculo.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## Sombreamento

É possível, e muitas vezes idiomático, reutilizar um nome de variável conforme um valor específico vai sendo transformado, redeclarando-o com várias invocações de `let`.
Isso é conhecido como _sombreamento_.
Na prática, a segunda variável passa a valer no lugar da primeira: todo uso do nome da variável se refere a ela até que ela mesma seja sombreada ou o escopo termine.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

Usando sombreamento, podemos até mudar o tipo da variável, reutilizando o mesmo nome de variável.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
