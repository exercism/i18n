# Dicas

## Geral

- Existem três [operadores Boolean][boolean-operators] para trabalhar com valores Boolean.
- É possível combinar vários operadores em uma única expressão.

## 1. Verifique se é possível fazer um ataque rápido

- O operador lógico de negação (`!`) pode ser colocado antes de uma expressão para negar o valor dela.

## 2. Verifique se o grupo pode ser espionado

- Operadores Boolean costumam ser usados para avaliar se duas ou mais expressões são verdadeiras ou não.

## 3. Verifique se o prisioneiro pode ser sinalizado

- Os operadores Boolean são executados na ordem de precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Em geral, o uso de parênteses é recomendado para deixar sua intenção mais clara.
- Para mais detalhes, confira a seção de precedência de operadores na [documentação oficial do Julia][operator-precedence].

## 4. Verifique se a opção 'Free Prisoner' deve ser exibida

- Os operadores Boolean são executados na ordem de precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Em geral, o uso de parênteses é recomendado para deixar sua intenção mais clara.
