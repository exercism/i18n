# Instruções

Seu amigo acabou de te enviar uma mensagem com um segredo importante.
Como ele não queria facilitar a leitura por outras pessoas, a mensagem foi criptografada por meio de uma série de manipulações de bits.
Você vai precisar escrever as funções que ajudam a descriptografar a mensagem.

## 1. Desloque os bits de volta

O primeiro passo para descriptografar a mensagem é desfazer o deslocamento do processo de criptografia, deslocando os bits de volta para a direita.
Haverá outros passos no processo de descriptografia que assumem que 0s são inseridos pelo lado esquerdo.

Implemente a função `shift_back()`, que recebe um valor e o número de posições a deslocar, e realiza o deslocamento.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Defina alguns bits

Agora, há alguns bits que precisam ser definidos como 1.

Implemente a função `set_bits()`, que recebe um valor e uma máscara e retorna o resultado de definir como 1 os bits do valor.
Um bit de `value` deve ser definido como 1 onde o bit em `mask` também for 1.
Todos os outros bits devem permanecer inalterados.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Inverta bits específicos

Alguns bits são invertidos durante a criptografia.
Eles precisarão ser invertidos de volta para descriptografar a mensagem.

Implemente a função `flip_bits()`, que recebe um valor e a máscara.
A máscara indica quais bits do valor devem ser invertidos.
Se o bit for 1 em `mask`, o bit é invertido em `value`.
Todos os outros bits permanecem inalterados.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Limpe bits específicos

Por último, também há certos bits que sempre descriptografam para 0.

Implemente a função `clear_bits()`, que recebe um valor e uma máscara.
Os bits de `value` devem ser definidos como 0 onde o bit na máscara for 1.
Todos os outros bits devem permanecer inalterados.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
