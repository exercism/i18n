# Instruções

Como aprendiz de mágica, Elyse precisa praticar o básico.

Ela tem uma pilha de cartas que quer manipular.

Para facilitar um pouco as coisas, ela usa apenas as cartas de 1 a 10.

A pilha de cartas é representada por um `Array`, com a base da pilha na frente do array e o topo da pilha no final.

## 1. Inserir uma carta no topo da pilha

Implemente a função `insert_top` que retorna uma cópia da pilha com a nova carta informada adicionada ao topo da pilha.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. Remover a carta do topo da pilha

Implemente a função `remove_top_card` que retorna uma cópia da pilha com a carta do topo removida.

Se a pilha informada estiver vazia, a pilha original deve ser retornada, sem alterações.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. Inserir uma carta na base da pilha

Implemente a função `insert_bottom` que retorna uma cópia da pilha com a nova carta informada adicionada à base da pilha.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. Remover uma carta da base da pilha

Implemente a função `remove_bottom_card` que retorna uma cópia da pilha com a carta da base removida.

Se a pilha informada estiver vazia, a pilha original deve ser retornada, sem alterações.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. Verificar o tamanho da pilha

Implemente a função `check_size_of_stack` que verifica se o tamanho da pilha é igual a um `stack_size` informado ou não.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
