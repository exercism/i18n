# Recursos de aprendizagem recomendados

O Exercism oferece exercícios e feedback, mas pode ser difícil dar os primeiros passos para quem está aprendendo ABAP pela primeira vez. Estes recursos gratuitos podem ajudar você a começar:

* SAP Learning Journey [Learning the Basics of ABAP Programming](https://learning.sap.com/courses/learn-the-basics-of-abap-programming-on-sap-btp)
* [ABAP for Newbies Community](https://pages.community.sap.com/topics/abap/abap-for-newbies)
* [ABAP Language Documentation](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm)
* [ABAP Starter](https://github.com/Keller-Michael/ABAP_starter)
* [ABAP Cheat Sheets](https://github.com/SAP-samples/abap-cheat-sheets)

Se você está começando com ABAP, recomendamos completar as seguintes unidades da SAP Learning Journey:

- Getting Started
- ABAP Language Basics
- Local Classes

Depois disso, você já pode resolver exercícios de ABAP no Exercism.

Se você chegar a exercícios mais complexos, sugerimos percorrer também as seguintes unidades:

- Structures
- Complex Internal Tables

Esses tópicos podem ajudar a resolver exercícios mais difíceis no Exercism.
