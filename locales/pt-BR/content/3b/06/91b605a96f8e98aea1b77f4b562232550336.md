# Condicionais `case`

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## Como a comparação funciona

O valor depois de `case` é comparado com cada valor de `when` usando `=`, de cima para baixo. A primeira correspondência é executada, e só ela. As demais partes `when` são ignoradas, e a execução continua depois do `end`.

Qualquer tipo que aceite `=` pode ser usado: `INT`, `CHAR`, `STR`, `BOOL`.

## O `else`

Um `case` sem correspondência e sem `else` gera um erro fatal em tempo de execução. Escreva sempre um. Quando os casos restantes realmente não deveriam acontecer, diga isso ali em vez de omitir o `else`:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

O `raise` vem mais adiante; até lá, retornar um padrão razoável funciona bem.

## Quando preferir `if`

O `case` compara um valor com constantes. Qualquer outra coisa pede um `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

Tentar forçar um intervalo dentro de um `case` produz algo mais longo e pior do que o `if` que ele substitui.

## O `case` como expressão

O `case` é uma instrução, não uma expressão, então isto não é Sather:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

Retorne de dentro de cada bloco, ou atribua a uma variável dentro de cada bloco.
