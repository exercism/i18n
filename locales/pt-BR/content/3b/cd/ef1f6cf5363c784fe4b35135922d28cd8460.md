# Anexo de instruções

## Implementação

Você vai escrever uma implementação de uma lista duplamente encadeada.
Implemente um `Node` para guardar um valor e ponteiros para os nós seguinte e anterior.
Depois, implemente uma `List` que guarda referências para o primeiro e o último nó e oferece funções para adicionar e remover itens.

Seu `Node` deve ter os seguintes campos e métodos:

- `Value`: o valor do nó (vamos usar `any`).
- `Next() *Node`: ponteiro para o próximo nó.
- `Prev() *Node`: ponteiro para o nó anterior.

Você deve ter uma função `NewList()` que cria e retorna uma `List`:

- `NewList(args ...any) *List`: cria uma nova lista encadeada preservando a ordem dos valores.

Sua `List` deve ter os seguintes métodos:

- `First() *Node`: retorna um ponteiro para o primeiro nó (cabeça).
- `Last() *Node`: retorna um ponteiro para o último nó (cauda).
- `Push(v any)`: insere um valor no fim da lista.
- `Pop() (any, error)`: remove um valor do fim da lista.
- `Unshift(v any)`: insere um valor no início da lista.
- `Shift() (any, error)`: remove um valor do início da lista.
- `Reverse()`: inverte a lista encadeada.
