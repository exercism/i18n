# Dicas

## Geral

Os valores de retorno das funções são de um tipo específico, então preste atenção.

## 1. Defina um vetor nomeado

- As informações necessárias para os nomes e os valores estão nas instruções.
- A forma de construir um vetor nomeado é abordada em detalhe na introdução.

## 2. Retorne o valor associado a uma faixa

- Você pode usar seu vetor nomeado `resistor_bands` para fazer isso facilmente.
- Você precisa retornar apenas um valor numérico.

## 3. Retorne o valor associado a duas faixas

- Sua função `band_value` pode ser útil aqui.
- Dicas de indexação para vetores nomeados estão na introdução.
- Há várias formas de construir o número, mais comumente por meio de manipulação de strings ou numericamente.
- O número retornado deve ser apenas um valor numérico.

## 4. Retorne os ohms associados às três faixas

- Tanto `band_value` quanto `two_band_value` são úteis aqui.
- Os dois primeiros valores no vetor são para o valor de duas faixas, enquanto o terceiro é o multiplicador.
- Novamente, é possível obter o número por meio de manipulação de strings ou de meios numéricos.
- O número retornado deve ser apenas um valor numérico.
