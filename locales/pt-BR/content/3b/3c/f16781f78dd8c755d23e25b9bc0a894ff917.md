# Instruções

Neste exercício, vamos simular o primeiro turno de um jogo de [Blackjack](https://en.wikipedia.org/wiki/Blackjack).

Você vai receber duas cartas e poderá ver a carta virada para cima do dealer. Todas as cartas são representadas por uma string como "ace", "king", "three", "two", etc. Os valores de cada carta são:

| carta | valor | carta | valor |
| :---: | :---: | :---: | :---: |
|  ace  |  11   | eight |   8   |
|  two  |   2   | nine  |   9   |
| three |   3   |  ten  |  10   |
| four  |   4   | jack  |  10   |
| five  |   5   | queen |  10   |
|  six  |   6   | king  |  10   |
| seven |   7   | other |   0   |

**Nota**: Normalmente, os ases podem valer 1 ou 11, mas, por simplicidade, vamos supor que só podem valer 11.

Dependendo das suas duas cartas e da carta do dealer, existe uma estratégia para o primeiro turno do jogo, na qual você tem as seguintes opções:

    - Stand (S)
    - Hit (H)
    - Split (P)
    - Automatically win (W)

Embora ainda não seja a ideal, você vai seguir a estratégia que seu amigo Alex vem desenvolvendo, que é a seguinte:

Categoria: Mão Grande

- Se você tiver um par de ases, deve sempre dividi-lo.
- Se você tiver um Blackjack (duas cartas que somam 21) e o dealer não tiver um ás, uma figura ou um dez, você vence automaticamente. Se o dealer tiver alguma dessas cartas, você terá que parar e esperar a revelação da outra carta.

Categoria: Mão Pequena

- Se as suas cartas somarem 17 ou mais, você deve sempre parar.
- Se as suas cartas somarem 11 ou menos, você deve sempre pedir carta.
- Se as suas cartas somarem um valor dentro do intervalo [12, 16], você deve sempre parar, a menos que o dealer tenha 7 ou mais, caso em que você deve sempre pedir carta.

A lógica geral já foi implementada. Você tem quatro tarefas:

## 1. Calcule a pontuação de qualquer carta.

Implemente uma função que calcule o valor numérico de uma carta a partir do seu nome, usando condicionais.

```java
parseCard("ace")
// returns 11
```

## 2. Determine se duas cartas formam um Blackjack.

Implemente uma função que retorne `true` se duas cartas formarem um Blackjack e `false` caso contrário.

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. Implemente a lógica de decisão para pontuações de mão maiores que 20 pontos.

Implemente uma função que retorne a representação em string de uma decisão, dadas as suas cartas. Essa função só é chamada se o `handScore` for maior que 20. Ela vai receber 2 argumentos: `isBlackJack` e `dealerScore`. Ela deve implementar os pontos da categoria "Mão Grande" acima.

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. Implemente a lógica de decisão para pontuações de mão com menos de 21 pontos.

Implemente uma função que retorne a representação em string de uma decisão, dadas as suas cartas. Essa função só é chamada se o `handScore` for menor que 21. Ela vai receber 2 argumentos: `handScore` e `dealerScore`. Ela deve implementar os pontos da categoria "Mão Pequena" acima.

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
