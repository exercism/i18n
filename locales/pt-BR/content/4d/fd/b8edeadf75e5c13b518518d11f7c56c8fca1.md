# Sobre

Ruby é uma linguagem de programação dinâmica e de código aberto, com foco na simplicidade e na produtividade.
Ela tem uma sintaxe elegante, natural de ler e fácil de escrever.

Ruby foi criada como uma linguagem de equilíbrio cuidadoso.
Seu criador, [Yukihiro “Matz” Matsumoto](https://en.wikipedia.org/wiki/Yukihiro_Matsumoto), misturou partes de suas linguagens favoritas (Perl, Smalltalk, Eiffel, Ada e Lisp) para formar uma nova linguagem que equilibrava a programação funcional com a programação imperativa.

Ele costuma dizer que está "tentando tornar o Ruby natural, não simples", de um jeito que espelha a vida.

Partindo disso, ele acrescenta: "Ruby é simples na aparência, mas é muito complexa por dentro, assim como o nosso corpo humano."

Você pode ler mais sobre a linguagem Ruby [no site dela](https://www.ruby-lang.org/en/about/).
