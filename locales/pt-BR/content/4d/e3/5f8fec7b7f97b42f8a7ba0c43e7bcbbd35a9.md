# Dicas

## 1. Obter a primeira letra do título

- Existe [um método][index] que retorna um `Char` de uma `String` em um determinado índice.

## 2. Obter as iniciais dos autores

- Você pode usar métodos já implementados para obter a primeira letra de uma `String`.
- Para combinar valores em uma `String`, você pode usar [interpolação de string][string-interpolation].

## 3. Decifrar a letra

- Existe [um método][uppercase] para verificar se um `Char` é maiúsculo.
- Existe [um método][ord] para obter o ponto de código de um `Char`.

## 4. Decifrar o texto

- Você pode usar [laços][while] para rodar o código várias vezes.
