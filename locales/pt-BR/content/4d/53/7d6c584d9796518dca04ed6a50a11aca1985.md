# Instalação

## Ubuntu (e a maioria das outras distribuições baseadas em Debian)

Para compilar o código localmente, você vai precisar de gcc e make, que podem ser instalados usando

```shell
sudo apt install gcc make
```

Se você não estiver rodando em hardware ARM64, instale o emulador [QEMU][] e a toolchain de compilação cruzada do GCC para ARM64 usando

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Use o [Windows Subsystem for Linux][] com uma distribuição baseada em Debian e siga as instruções do Ubuntu acima.
Como alternativa, configure uma máquina virtual Linux.

## macOS

Uma máquina virtual Linux pode ser iniciada com qualquer solução de virtualização adequada (por exemplo, [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
