# Dicas

## Geral

- Leia sobre [erros][getting-started-errors] no guia Getting Started.
- Leia sobre [`defexception`][defexception] na documentação.
- Leia sobre o [comportamento `Exception`][exception-behaviour] na documentação.
- Leia os trechos de código da introdução.

## 1. Erro de divisão por zero

- Implemente o módulo, especificando a mensagem com uma [macro interna especial para definir exceções][defexception].
- Módulos podem ser aninhados dentro de outros módulos.

## 2. Erro ao encontrar underflow de pilha

- Implemente o módulo, especificando a mensagem com uma [macro interna especial para definir exceções][defexception].
- Você pode usar um dos callbacks do comportamento `Exception` para definir uma exceção cuja mensagem muda conforme os argumentos passados para `raise/2`.
- Módulos podem ser aninhados dentro de outros módulos.

## 3. Escreva uma função de divisão

- Escreva uma função com múltiplas cláusulas usando guardas para controlar o fluxo.
- Você pode fazer pattern matching na lista de argumentos da função para vincular os valores da pilha a variáveis.
