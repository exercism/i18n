# Dicas

## 1. Encontre a posição de uma carta

- Os índices de array começam em `0`.
- Existe um método [nativo][indexof_method_docs] para obter o índice de um determinado valor.

## 2. Determine se uma carta está presente

- Existe um método [nativo][includes_method_docs] para verificar se o valor está presente no array

## 3. Determine se cada carta é par

- Existe um método [nativo][every_method_docs] para verificar se cada valor passa em um predicado

## 4. Verifique se a pilha contém uma carta de valor ímpar

- Existe um método [nativo][some_method_docs] para verificar se pelo menos um valor passa em um predicado

## 5. Obtenha a primeira carta ímpar da pilha

- Existe um método [nativo][find_method_docs] para obter o primeiro item que passa em um predicado

## 6. Determine a posição da primeira carta que é par

- Existe um método [nativo][findindex_method_docs] para obter o primeiro índice no array em que o valor
