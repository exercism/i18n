# Introdução

## Funções de callback

Funções de callback são funções passadas como argumentos.
Esse padrão de programação cria uma sequência de chamadas de função tanto na programação síncrona quanto na assíncrona.
Escrever uma função de callback não é diferente de escrever uma função; no entanto, a função de callback precisa corresponder à assinatura definida pela função chamadora.

```javascript
const squareLength = 5;

// Caller function takes a callback function
function applyToSquare(callback) {
  return callback(squareLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(number) {
  return number * number;
}

applyToSquare(areaOfSquare); // => 25
```

Você também pode escrever callbacks como uma expressão de função, uma expressão de função anônima ou uma expressão de arrow function:

```javascript
applyToSquare(function squarePerimeter(side) {
  return side * 4;
});

applyToSquare(function (side) {
  return side * 4;
});

applyToSquare((side) => {
  return side * 4;
});
```
