# Introdução

Uma tupla é um contêiner ordenado de valores. Assim como todos os tipos de dados do Gleam, as tuplas são imutáveis.
Cada elemento de uma tupla pode ser de um tipo diferente; podem até ser outras tuplas.

As tuplas são definidas como valores separados por vírgula entre `#(` e `)`: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Tuplas com o mesmo comprimento e os mesmos tipos (na mesma ordem) podem ser comparadas quanto à igualdade.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Existem três maneiras de obter os valores contidos em uma tupla:

- Indexação.
- Casamento de padrões com `let`.
- Casamento de padrões com `case`.

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

A indexação de tuplas pode ser usada em guardas de expressão case.

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
