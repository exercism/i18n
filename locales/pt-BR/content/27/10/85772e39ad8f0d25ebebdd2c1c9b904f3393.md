# chamada diferente do esperado

Encontramos `%{unexpected}`, mas o esperado era `%{expected}`.

Ainda não há orientação específica escrita para essa transformação. Se você acha
que ela deveria ser adicionada, abra uma issue [aqui](https://github.com/exercism/javascript-analyzer/issues/new).

⚡ **Aviso:** Não podemos garantir que o analisador funcionou corretamente neste ponto.
Confira se ele cometeu algum erro e, se cometeu, abra uma issue
[aqui](https://github.com/exercism/javascript-analyzer/issues/new?assignees=&labels=%%3Abug%%3A+bug&template=incorrect-analysis.md&title=Incorrect+Analysis%%3A+) para que o analisador seja atualizado.
