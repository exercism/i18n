# Instruções

Neste exercício, você vai processar linhas de log.

Cada linha de log é uma string formatada da seguinte forma: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de log:

- `TRC` (rastreamento)
- `DBG` (depuração)
- `INF` (informação)
- `WRN` (aviso)
- `ERR` (erro)
- `FTL` (fatal)

Você tem três tarefas.

## 1. Analisar o nível de log

Defina um `enum` `LogLevel` que tenha seis elementos correspondentes aos níveis de log acima.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

Em seguida, implemente o método (_estático_) `LogLine.ParseLogLevel()` para analisar o nível de log de uma linha de log:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. Lidar com nível de log desconhecido

Infelizmente, de vez em quando algumas linhas de log têm um nível de log desconhecido. Para lidar com essas linhas de log sem quebrar o programa, adicione um elemento `Unknown` ao `enum` `LogLevel`, que deve ser retornado ao analisar um nível de log desconhecido:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. Converter a linha de log para o formato curto

O nível de log de uma linha de log é bastante extenso. Para reduzir o espaço em disco necessário para armazenar as linhas de log, foi criado um formato curto: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

O nível de log codificado é um mapeamento simples de um nível de log para um número:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

Implemente o método (_estático_) `LogLine.OutputForShortLog()` que consegue gerar o formato curto da linha de log:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
