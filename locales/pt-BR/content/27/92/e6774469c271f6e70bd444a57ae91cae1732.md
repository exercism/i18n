# Introdução

Os mapas em Elixir são a estrutura de dados para armazenar informações em pares chave-valor. Em outras linguagens, eles também podem ser conhecidos como arrays associativos (PHP), hashes (Perl 5, Raku) ou dicionários (Python).

As chaves e os valores podem ser de qualquer tipo de dado, mas se a chave for um atom, podemos usar uma sintaxe abreviada. Os mapas não garantem a ordem de suas entradas quando elas são acessadas ou retornadas.

## Formas literais

Um mapa vazio é simplesmente declarado com `%{}`. Se quisermos adicionar itens a um mapa literal, podemos usar duas formas:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Embora não exista um formato canônico, escolha uma forma consistente de representar os pares literais de chave-valor.

## Funções do módulo Map

Elixir oferece muitas funções para trabalhar com mapas no _módulo Map_. Algumas funções do _módulo Map_ exigem que uma função _anônima_ seja passada para elas, para ajudar na transformação do mapa.
