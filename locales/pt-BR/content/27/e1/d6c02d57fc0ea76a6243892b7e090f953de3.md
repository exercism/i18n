# Introdução

Uma `string` em F# é um objeto que representa texto imutável como uma sequência de caracteres Unicode (letras, dígitos, pontuação etc.) e é definida assim:

```fsharp
let fruit = "Apple"
```

As strings são manipuladas chamando os métodos da string ou usando as funções do módulo `String`. Depois que uma string é construída, seu valor nunca pode mudar. Quaisquer métodos ou funções que pareçam modificar uma string na verdade retornam uma nova string.

As strings podem ser concatenadas ou formatadas de algumas maneiras diferentes.
* Você pode usar o operador `+` para concatenar:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Você pode usar a função `sprintf` para formatar texto, em que você tem marcadores de posição no texto de formato (`%s` para uma `string`) e fornece os valores como argumentos:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
