# Apêndice das instruções

## API do Roc

Use um valor `React` imutável.
Cada operação retorna um reator atualizado; guarde esse valor para as operações seguintes.
As células são identificadas por `cell_id`; os callbacks, por `callback_id`.
Ambos os identificadores são strings fornecidas no momento do registro.
O registro e a remoção de callbacks recebem ambos os identificadores para especificar a célula e seu callback.

Uma função de computação recebe uma lista de valores de células na mesma ordem que sua lista `inputs` de identificadores de células.
Ela retorna `Ok(value)` em caso de sucesso ou `Err(message)` com uma string que descreve uma falha, como uma quantidade incorreta de entradas ou uma divisão por zero.
Suas dependências já devem existir quando a célula de computação é adicionada.
Tanto `add_compute` quanto `set_value` reportam erros de computação como `ComputeFailed({ cell_id, message })`.
Se uma computação falhar durante uma atualização, nenhum reator atualizado é retornado e nenhum callback é executado; o reator original continua utilizável.

Os callbacks são funções puras do tipo `React.CellValue, React.CallbackLog -> React.CallbackLog`.
Cada callback recebe o novo valor da célula e o log atual e então retorna um log atualizado.
`set_value` recebe um registro contendo `cell_id`, `value` e o `log` inicial, e retorna tanto o reator atualizado quanto o log final.
Passe o log retornado por cada callback para o próximo callback; a ordem dos callbacks não é especificada.

`React.CallbackLog` é um alias para `Dict(Str, List(I64))`: ele registra os valores recebidos por cada identificador de callback.
Os testes passam um log vazio para cada atualização de entrada para verificar se os callbacks foram executados exatamente uma vez ou nunca foram executados.

Registrar um callback não o chama.
Remover o mesmo callback mais de uma vez é permitido e não deve afetar outros callbacks.
Todos os callbacks de uma atualização devem observar os valores finais e estáveis das células.

## Dicas

<details>
<summary>Mostrar dicas</summary>

Você pode guardar funções em registros junto com seus identificadores de célula ou de callback.
Para chamar uma função guardada em um campo de registro, use parênteses, como em `(cell.compute)(values)` ou `(registration.callback)(value, log)`.
Sem esses parênteses, Roc trata a chamada como um método no tipo do registro.
`List.map_try` e `List.fold_try` podem ajudar a encadear computações que podem falhar.
