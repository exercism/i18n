# Instruções complementares

## Dicas

Para completar este exercício, você precisa implementar as seguintes funções:

- `boardString`
- `canAttack`

Você encontrará as assinaturas de tipo já no lugar, mas cabe a você
definir as funções.

As posições são especificadas como duplas:

- O primeiro elemento é a linha (fileira em termos de xadrez).
- O segundo elemento é a coluna (file, em termos de xadrez).
- (0, 0) é o canto superior esquerdo do tabuleiro, (0, 7) é o canto superior direito,
- (7, 0) é o canto inferior esquerdo, e (7, 7) é o canto inferior direito.
