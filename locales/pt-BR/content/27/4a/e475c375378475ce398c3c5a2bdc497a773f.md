# Introdução

Em Go, `map` é um tipo de dados embutido que mapeia chaves para valores.
Em outras linguagens de programação, você pode conhecer o conceito de `map` como dicionário, tabela hash, armazenamento de chave/valor ou array associativo.

Sintaticamente, `map` tem esta forma:

```go
map[KeyType]ElementType
```

Também é importante saber que cada chave é única, ou seja, atribuir a mesma chave duas vezes vai sobrescrever o valor da chave correspondente.

Para criar um map, você pode fazer:

```go
  // With map literal
  foo := map[string]int{}
```

ou

```go
  // or with make function
  foo := make(map[string]int)
```

Aqui estão algumas operações que você pode fazer com um map

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

Se você tentar recuperar o valor de uma chave que não existe no map, ele vai retornar o valor zero do tipo do valor.
Isso pode confundir você, principalmente se o valor padrão do seu `ElementType` (por exemplo, 0 para um int) for um valor válido.
Para verificar se uma chave existe no seu map, você pode usar

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
