# Introdução

A capacidade de algo ser definido em termos de si mesmo se chama recursão. Em F#, a recursão aparece mais comumente em funções recursivas, que são funções que chamam a si mesmas.

Uma função recursiva precisa ter pelo menos um _caso base_ e pelo menos um _caso recursivo_. Um _caso base_ retorna um valor sem chamar a função de novo. Um _caso recursivo_ chama a função de novo, modificando a entrada para que em algum momento ela corresponda ao caso base.

Funções recursivas são definidas como funções comuns, mas com o modificador `rec`. Sem esse modificador, uma função _não_ vai conseguir chamar a si mesma, e qualquer tentativa de fazer isso resultará em um erro de compilação. Portanto, é preciso optar explicitamente pela recursão.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# também oferece suporte a tipos recursivos por meio de tipos de união discriminada. Um tipo de união discriminada recursivo tem um ou mais de seus casos se referindo ao próprio tipo de união discriminada em seus dados. Assim como as funções recursivas, os tipos recursivos precisam ter um caso base. Diferente das funções recursivas, os tipos recursivos não usam a palavra-chave `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
