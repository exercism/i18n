# Introdução

O tipo `atom` do Elixir representa uma constante fixa. O valor de um átomo é simplesmente o seu próprio nome. Isso nos dá uma maneira de interagir com os dados com segurança de tipos. Os átomos podem ser definidos assim:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

_Átomos_ são representados internamente por um número inteiro em uma tabela de consulta, atribuído automaticamente. Não é possível alterar esse valor interno.
