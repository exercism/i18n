# Apêndice das instruções

## Memória reservada

O buffer para a string de entrada usa os bytes 64 a 191 da memória linear.

## Formato da entrada

A entrada vem formatada como uma única string de três linhas, com uma quebra de linha no final de cada uma. Os X e os O serão sempre maiúsculos: `X` e `O`.

Assim, o tabuleiro

```
X··
OXO
XOX
```

será codificado como

```
"X  \nOXO\nXOX\n"
```
