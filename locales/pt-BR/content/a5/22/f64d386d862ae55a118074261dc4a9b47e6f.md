# Testes

## Instalando o executor de testes da trilha GDScript do Exercism

Você vai precisar do [Godot instalado][installation] corretamente para usar o executor de testes.

Para compilar e testar scripts GDScript no Exercism, o Godot será executado em modo "headless" pela CLI.
Estas instruções atualmente exigem Linux e bash.

### Passo 1: Instalando a infraestrutura geral do executor de testes

Para preparar o ambiente de teste, clone [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] e mova o conteúdo para `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Passo 2: Baixando o script do executor de testes de um único exercício

Considerando que você já configurou a ferramenta `exercism` e baixou pelo menos um exercício de GDScript, ela deve ter criado uma pasta `exercism/gdscript` para guardar os exercícios.
Salve [o executor de testes][test-local-gdscript-solution] nessa pasta e marque o arquivo como executável, ou apenas crie um link para ele:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## Rodando os testes

Com os passos de instalação concluídos, você já pode partir de qualquer diretório de exercício (por exemplo, `~/exercism/gdscript/two-fer`) e rodar o script (que fica um nível acima, em `../`) para testar sua solução local desse exercício:

```sh
../test-local-gdscript-solution.sh
```
