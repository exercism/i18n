# Introdução

Em Factor, os caracteres são números inteiros, isto é, pontos de código Unicode. Por isso, as comparações numéricas `<`, `>`, `=` já oferecem uma ordenação sensível a maiúsculas e minúsculas. O vocabulário [`unicode`][unicode] acrescenta predicados que reconhecem Unicode e a conversão de maiúsculas e minúsculas de um único caractere.

## Predicados de caracteres

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## Conversão de maiúsculas e minúsculas

`ch>upper` e `ch>lower` invertem um único caractere. Já `>upper` e `>lower`, no nível de string, aplicam essa conversão a todos os caracteres de uma string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` deixa uma string inteira em minúsculas e depois coloca seu primeiro caractere em maiúscula, o que dá o formato de título de uma única palavra:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## Literais de caractere

`CHAR: A` é interpretado como o ponto de código inteiro de `A`. Para caracteres com nome, use os nomes `space`, `tab`, `\n`, etc.:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## Símbolos

Quando uma palavra precisa retornar uma tag em vez de um valor, digamos `yes`/`no`/`maybe` no lugar de um Boolean, declare cada tag como um *símbolo*. Um símbolo é uma palavra que empilha a si mesma quando é chamada, e dois símbolos só são iguais quando têm o mesmo nome.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` declara um; `SYMBOLS: a b c ;` declara vários.
