# Anexo das instruções

## Implementação

Este exercício pede que você crie uma estrutura de dados de lista encadeada pela qual seja possível iterar.

1. Implemente a propriedade `Count`, cujo valor não deve poder ser alterado de fora
2. Implemente o método `Push(T value)`, que adiciona um valor no início da lista.
3. Implemente o método `Pop()`, que remove e retorna um valor do início da lista.
4. Adicione um construtor que permita a inicialização com um único valor, ou com um iterável
5. Implemente a interface `IEnumerable<T>`. Para mais informações, veja [ienumerable].
6. Certifique-se de que o método `Reverse()` esteja disponível.

[ienumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
