## 1. Defina o behaviour de animação

- Use o atributo de módulo `@callback` para definir as funções desejadas.
- Cada callback deve especificar o nome da função, a lista de argumentos (seus tipos) e o valor de retorno (seu tipo).
- Use os tipos personalizados fornecidos `dot`, `opts`, `error` e `frame_number` nas definições dos callbacks.
- Relembre seus conhecimentos sobre [typespecs][typespec] para ajudar a definir callbacks.

## 2. Forneça uma implementação padrão do callback `init/1`

- Defina uma macro `__using__/1` no módulo `DancingDots.Animation`.
- O argumento da macro pode ser ignorado.
- A macro deve retornar uma [expressão quoted][quote].
- Na expressão quoted, use `@behaviour` para que chamar `use DancingDots.Animation` defina `DancingDots.Animation` como o behaviour do módulo que faz o `use`.
- Na expressão quoted, implemente a função `init/1`.
- A implementação padrão da função `init/1` deve envolver o argumento `opts` fornecido em uma tupla `:ok`.
- Existe [uma macro][defoverridable] que pode marcar uma função como sobrescrevível.

## 3. Implemente a animação `Flicker`

- Use a macro `__using__/1` de `DancingDots.Animation` chamando [esta macro especial][doc-use] no módulo `DancingDots.Flicker`.
- Você não precisa implementar a função `init/1`. A implementação padrão dela já basta.
- Você precisa implementar a função `handle_frame/3`.
- Para detectar "a cada 4 quadros", você pode verificar se o [resto][rem] da divisão por 4 é igual a 0.

## 4. Implemente a animação `Zoom`

- Use a macro `__using__/1` de `DancingDots.Animation` chamando [esta macro especial][doc-use] no módulo `DancingDots.Zoom`.
- Você precisa implementar tanto a função `init/1` quanto a função `handle_frame/3`.
- Use o módulo [`Keyword`][keyword] para trabalhar com a lista de palavras-chave das opções.
- Existe [uma guarda embutida][is_number] para verificar se um valor é um número.
