# Sobre conversão de tipos

Go exige conversão explícita entre tipos diferentes.
Por exemplo, isto causa um erro de compilação:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

A conversão entre tipos (também conhecida como **type casting**) é feita por meio de uma função com o nome do tipo de destino.
Um valor `v` é convertido para o tipo `T` usando `T(v)`.
Por exemplo, para converter um `int` em um `float64`, você precisa fazer o seguinte:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

O mesmo vale para qualquer tipo personalizado:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## Conversão entre tipos primitivos e strings

Existe um pacote `strconv` para converter entre tipos primitivos (como `int`) e `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

AVISO: usar o método de conversão padrão não produz esse comportamento.
Por exemplo:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

Veja alguns dos outros métodos de conversão mais comuns:

| Método      | Finalidade                          |
| ----------- | ----------------------------------- |
| ParseBool   | Converter `string` em `bool`        |
| FormatBool  | Converter `bool` em `string`        |
| ParseFloat  | Converter `string` em `float`       |
| FormatFloat | Converter `float` em `string`       |
| ParseInt    | Converter `string` em `int`         |
| FormatInt   | Converter `int` em `string`         |
