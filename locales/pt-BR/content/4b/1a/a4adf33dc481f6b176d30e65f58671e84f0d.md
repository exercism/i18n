# Instruções complementares

## Adicionando um método à struct `Int`

Este exercício é focado em adicionar métodos à struct `Int` do Crystal.
Para isso, você vai precisar definir uma struct com o nome `Int`.
E colocar o método dentro dessa struct.

```crystal
struct Int
  # your solution here
end
```

O código-fonte da classe `Int` pode ser encontrado [aqui][int].
