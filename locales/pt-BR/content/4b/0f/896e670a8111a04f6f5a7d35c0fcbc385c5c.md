## Mensagens de exceção

Às vezes é necessário [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você faz isso, deve sempre incluir uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda bastante na depuração. Em situações em que você sabe que a origem do erro será de um determinado tipo, você pode escolher lançar um dos [tipos de erro embutidos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda assim deve incluir uma mensagem significativa.

Este exercício em particular exige que você use a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um `ValueError` quando o jogo tiver terminado mas o jogador tentar continuar jogando. Os testes só vão passar se você `raise` a `exception` e incluir uma mensagem junto com ela.

Para lançar um `ValueError` com uma mensagem, escreva a mensagem como argumento do tipo `exception`:

```python
# when player tries to play, but the game is already over.
raise ValueError("The game has already ended.")
```
