# Sobre

O PHP oferece vários operadores para realizar operações aritméticas. O PHP segue a ordem matemática padrão das operações para seus operadores aritméticos. Os operadores que o PHP oferece são:

* Identidade (+)
* Negação (-)
* Adição (+)
* Subtração (-)
* Multiplicação (*)
* Divisão (/)
* Módulo (%)
* Exponenciação (**)

Vamos ver cada um deles e como podem ser usados:

## Identidade (+)

O operador de identidade (+) atua sobre um único valor (operador unário). Ele vai resultar no valor `float` ou `int` da variável.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## Negação (-)

O operador de negação atua sobre um único valor (operador unário) e retorna o oposto do valor numérico.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## Adição (+) e Subtração (-)

O operador de adição soma os dois valores que estão de cada lado dele, enquanto o operador de subtração subtrai o valor da direita do valor da esquerda.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## Divisão (/)

O operador de divisão dá o resultado da divisão do valor da esquerda pelo valor da direita. Se o valor da direita for 0, isso causa um erro `DivisionByZeroError`.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## Multiplicação (*)

O operador de multiplicação retorna o resultado da multiplicação dos valores da esquerda e da direita entre si.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## Módulo (%)

O operador de módulo retorna o resto quando o valor da esquerda é dividido pelo valor da direita. Esse operador é muito útil para determinar se um número divide outro exatamente, para saber se um valor é par ou ímpar e muito mais.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## Exponenciação (**)

O operador de exponenciação é usado para elevar o valor da esquerda à potência do valor da direita. Antes do PHP 5.6, você precisaria usar a função `pow` para fazer a mesma coisa.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

O operador de exponenciação aceita inteiros e números de ponto flutuante nos dois lados, então você pode usá-lo para calcular raízes quadradas (ou outras raízes) ou valores exponenciais mais complexos.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## Ordem das operações

O PHP segue a ordem de operações padrão da matemática. Isso significa que, em vez de realizar as operações da esquerda para a direita, cada operador tem uma precedência e as operações são resolvidas de acordo com essa precedência. A ordem das operações é:

* parênteses
* exponenciação
* multiplicação, divisão
* adição, subtração

Multiplicação e divisão têm o mesmo nível de precedência entre si. Da mesma forma, adição e subtração têm o mesmo nível de precedência.

Isso significa que o valor abaixo seria 17 em vez de 10, já que a multiplicação tem precedência maior que a adição:

```php
$value = 2 + 3 * 5;
```

O PHP também oferece vários operadores de atribuição úteis que combinam operadores aritméticos com atribuição quando você realiza uma operação em uma variável e atribui o resultado de volta a ela mesma. Eles serão abordados no conceito `Assignment Operators`.
