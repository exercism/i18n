# Instalação

## Usuários do Windows

Instale o [Subsistema do Windows para Linux][wsl-link] e veja a próxima seção.

## Usuários de Linux/Mac

### Instalando com o brew

Esta é a maneira mais fácil de instalar o Chapel.
Isso vai te dar uma instalação básica e funcional, adequada para percorrer a trilha do Exercism.
Usuários mais avançados podem querer compilar o Chapel a partir do código-fonte (próxima seção).

0. Se ainda não fez isso, instale o gerenciador de pacotes [brew][brew-link].
1. Primeiro, verifique se o brew está atualizado rodando `brew update`
2. Instale o Chapel rodando `brew install chapel`
3. Verifique se a instalação deu certo rodando `chpl --version`

Isso vai instalar o compilador do Chapel (`chpl`), o gerenciador de pacotes `mason`, que vamos usar para rodar os testes, e a ferramenta de geração de documentação `chpldoc`. Esta não é necessária para o Exercism, mas é bom tê-la se (quando :) ) você quiser desenvolver suas próprias bibliotecas em Chapel.

### Compilando o Chapel a partir do código-fonte

Usuários mais avançados podem querer compilar o Chapel a partir do código-fonte por conta própria. Para isso,

1. Instale os [pré-requisitos][prereqs-link]
2. [Baixe][download-link] o arquivo da versão mais recente do Chapel e extraia-o.
3. Primeiro, você precisa preparar a instalação e configurar onde você quer instalar o Chapel.
Isso pode ser feito rodando o script `configure` fornecido.
Basta rodar

```
./configure
```

para instalar binários, bibliotecas e arquivos compartilhados em `/usr/local/`. Você pode mudar isso usando a opção `--prefix`.
Por exemplo, se você quiser instalar o Chapel em `~/.chapel`, você pode fazer

```
./configure --prefix=~/.chapel
```

4. Para instalar o compilador e as ferramentas, rode 

```
make
make mason
make chpldoc
make install
```

5. Verifique se a pasta `/dir/for/install/bin` está na sua variável `PATH`. 

Para mais informações sobre as diferentes formas de instalar o Chapel e trabalhar a partir do código-fonte, veja a página [Building Chapel][building-link] na documentação.
