# Sobre

Estruturas de dados que podem conter zero ou mais elementos são conhecidas como _coleções_.
Um **array** em Ruby, também chamado de _vetor_, é uma coleção que mantém a ordem em que seus objetos são adicionados.
Arrays podem conter qualquer objeto.
Objetos podem ser adicionados a um array ou recuperados dele usando um índice.
A indexação de arrays em Ruby começa em zero, ou seja, o índice do primeiro elemento é sempre zero:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

Em Ruby, existem várias formas de criar um array:

- Usando o construtor literal `[]` _(mais comum)_
- Chamando `Array.new` explicitamente
- Chamando o método `Array()` do Kernel

O método `Array.new` aceita dois argumentos opcionais: o tamanho inicial do array e um objeto padrão.

Quando um tamanho e um padrão são fornecidos, o array é preenchido com `size` cópias do objeto padrão.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

Como todos os elementos do array guardam o mesmo hash, alterar um deles afeta todos os outros.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

Se o que você quer são cópias diferentes, use a versão com bloco, que usa o resultado desse bloco cada vez que um elemento do array precisa ser inicializado:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Outra característica dos arrays em Ruby é que eles incluem o módulo [Enumerable][enumerable-module], que adiciona vários métodos úteis para iterar, buscar, ordenar e filtrar os elementos de um array.
