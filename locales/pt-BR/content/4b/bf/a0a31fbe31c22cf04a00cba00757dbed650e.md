# Anexo às instruções

## Implementação

Implemente os métodos `waterDrinker` e `zebraOwner` da classe `ZebraPuzzle`.
Cada um deles deve retornar uma string, cujo valor é a resposta para as perguntas do quebra-cabeça da zebra "Quem bebe água?" e "Quem tem a Zebra?".
Cada resposta será uma das nacionalidades dos moradores: Englishman, Spaniard, Ukrainian, Norwegian ou Japanese.

Obviamente, você poderia simplesmente escrever duas funções de uma única instrução se espiar o programa de testes para ver a solução esperada.
Mas o objetivo é desenvolver um algoritmo que use os fatos e as restrições dados do quebra-cabeça e determine as duas respostas corretas.
