# Pausar as contribuições da comunidade

Alguns repositórios não têm recursos para fazer a triagem ou revisar issues e pull requests de pessoas que não são mantenedoras.
A pausa das contribuições da comunidade
Se um repositório habilitou este fluxo de trabalho, ele vai comentar automaticamente em uma issue ou pull request recém-aberta quando quem a criou _não_ for membro da organização do Exercism no GitHub.
O comentário vai sugerir que a pessoa abra primeiro um tópico no fórum do Exercism.

## Habilitar o fluxo de trabalho

Adicione o [arquivo .github/workflows/pause-community-contributions.yml](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml) ao seu repositório.

## Desabilitar o fluxo de trabalho

Remova o arquivo do fluxo de trabalho do seu repositório.

## Fonte

O fluxo de trabalho é definido no arquivo `.github/workflows/pause-community-contributions.yml`.
