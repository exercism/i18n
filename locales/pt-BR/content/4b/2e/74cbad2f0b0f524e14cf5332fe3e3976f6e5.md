# Sobre

A `generator` é uma função ou expressão que retorna um tipo especial de [iterador][iterator] chamado [iterador gerador][generator-iterator].
`Generator-iterators` são [preguiçosos][lazy iterator]: não armazenam seus `values` na memória, mas _geram_ seus valores quando necessário.

Uma função geradora se parece com qualquer outra função, mas contém uma ou mais [expressões yield][yield expression].
Cada `yield` suspende a execução do código, salvando o estado atual de execução (_incluindo todas as variáveis locais e as instruções try_).
Quando o gerador é retomado, ele recupera o estado de onde foi suspenso, ao contrário das funções normais, que reiniciam a cada chamada.


## Como construir um gerador

Os geradores são construídos de forma parecida com outras funções de laço ou recursivas, mas exigem uma [expressão `yield`](#the-yield-expression), que vamos explorar em detalhes um pouco mais adiante.

Um exemplo é uma função que retorna os _quadrados_ de uma determinada lista de números.  
Do jeito que está escrita, toda a entrada precisa ser processada antes que qualquer valor possa ser retornado:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Você pode converter essa função em um gerador assim:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

A lógica por trás disso é que você usa um gerador quando não precisa de todos os valores _de uma vez_.

Isso economiza memória e poder de processamento, já que só o valor no qual você está _trabalhando no momento_ é calculado.


## Como usar um gerador

Geradores (_tecnicamente, [`generator-iterator`s][generator-iterator]: veja a nota abaixo._) são um tipo de `iterator` e podem ser usados em qualquer lugar do Python onde se espera um `iterator` ou um `iterable`.
Isso inclui _funções_ ou _objetos_ que exigem um `iterable`/`iterator` como argumento.
Para se aprofundar, veja [Como criar um iterador em Python][how-to-iterator].


~~~~exercism/note

Os iteradores geradores são um subconjunto especial dos [iteradores][iterator].
Os `Iterators` são o mecanismo/protocolo que permite iterar sobre _iteráveis_.
Os iteradores geradores e os iteradores retornados pelos [`iterables`][iterables] comuns do Python agem de forma muito parecida, mas há algumas diferenças importantes a observar:

- Eles são _[avaliados de forma preguiçosa][lazy evaluation]_; a iteração é _unidirecional_ e não há como "voltar" a um valor anterior.
- Eles são _consumidos_ ao iterar sobre os valores retornados; não há como reiniciar nem salvar na memória.
- Eles não podem ser ordenados nem revertidos.
- Eles não são tipos de sequência e _não_ têm `indexes`. 
  Você não pode referenciar um valor anterior ou futuro usando adição ou subtração, e não pode usar notação de colchetes (`[]`) nem fatiamento.
- Eles não podem ser usados com a função `len()`, pois não têm comprimento.
- Eles podem ser _finitos_ ou _infinitos_. Cuidado ao coletar todos os valores de um `generator-iterator` _infinito_!

Para usar o gerador `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

Os valores dentro de um gerador também podem ser produzidos/acessados por meio da função `next()`.
`next()` chama o método `__next__()` de um objeto gerador, "avançando" ou avaliando o código do gerador até sua expressão `yield`, que então "produz" ou retorna o valor.

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Quando um `generator` é totalmente consumido e não tem mais valores a retornar, ele lança um erro `StopIteration`.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```

### Diferença entre iteráveis e geradores

Os geradores são um subconjunto especial dos _iteradores_.
Os `Iterators` são o mecanismo/protocolo que permite iterar sobre _iteráveis_.
Os geradores e os iteradores retornados pelos [`iterables`][iterables] comuns do Python agem de forma muito parecida, mas há algumas diferenças importantes a observar:

- Os geradores são _unidirecionais_; não há como "voltar" a um valor anterior.

- Iterar sobre geradores consome os valores retornados; não há como reiniciar.

- Os geradores (_por serem avaliados de forma preguiçosa_) não podem ser ordenados nem revertidos.

- Os geradores _não_ têm `indexes`, então você não pode referenciar um valor anterior ou futuro usando adição ou subtração.

- Os geradores não podem ser usados com a função `len()`.

- Os geradores podem ser _finitos_ ou _infinitos_; cuidado ao coletar todos os valores de um gerador _infinito_.

## A expressão yield

A [expressão yield][yield expression] é muito parecida com a expressão `return`.

_Ao contrário_ da expressão `return`, o `yield` entrega valores ao chamador em um _ponto específico_, suspendendo a avaliação/retorno de quaisquer valores adicionais até que sejam solicitados.

Quando o `yield` é avaliado, ele pausa a execução da função que o contém e retorna quaisquer valores da função _naquele momento_.

A função então _permanece no escopo_, e quando `__next__()` é chamado, a execução continua até que o `yield` seja encontrado novamente.

~~~~exercism/note
O uso de expressões `yield` é proibido fora de funções.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```

## Por que usar geradores?

Os geradores são úteis em muitas aplicações.

Ao trabalhar com uma coleção grande, você pode não querer colocar todos os seus valores na `memory`.
Um gerador pode ser usado para trabalhar com dados maiores peça por peça, economizando memória e melhorando o desempenho.

Os geradores também são muito úteis quando um processo ou cálculo é _complexo_, _caro_ ou _infinito_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Agora, sempre que `__next__()` for chamado no objeto `infinite_sequence`, ele retornará o _número anterior_ + 1.
