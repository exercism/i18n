# Introdução

## Boolean em Julia

Valores verdadeiros ou falsos são representados pelo tipo `Bool`.
Ele contém apenas dois valores: `true` e `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Operadores Boolean

Existem três operadores Boolean em Julia.

`&&` é o "e" Boolean.
Ele resulta em `true` se as expressões em *ambos* os lados de `&&` forem `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` é o "ou" Boolean.
Ele resulta em `true` se uma expressão em *qualquer um dos* lados de `||` for `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` é o "não" Boolean.
Ele troca os valores `true` e `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Para expressões mais longas e mais complicadas, é melhor usar parênteses para deixar clara a sua intenção.

```julia-repl
julia> (true || false) && (false && true)
false
```
