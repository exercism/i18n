# Complemento das instruções

## Mensagens de exceção

Às vezes é preciso [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você faz isso, deve sempre incluir uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda bastante na depuração. Em situações em que você sabe que a origem do erro vai ser de um certo tipo, você pode escolher lançar um dos [tipos de erro internos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda deve incluir uma mensagem significativa.

Este exercício em particular pede que você refatore como/onde a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) é usada para "lançar" um `ValueError` para uma entrada de árvore inválida. Os testes só vão passar se o código tanto fizer `raise`s na `exception` apropriada quanto incluir uma mensagem apropriada junto com ela.
