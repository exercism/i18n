# Parâmetros variádicos

Os [_parâmetros variádicos_][variadic-parameters] em Swift permitem que zero ou mais valores do mesmo tipo sejam passados para um único parâmetro de uma função.
Isso é indicado acrescentando `...` à anotação de tipo do parâmetro.

Esses valores são agrupados automaticamente em um array com elementos do mesmo tipo que o do parâmetro variádico.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

Ao usar parâmetros variádicos, o Swift tem duas limitações:

1. O Swift só permite que uma função tenha um parâmetro variádico. Foi decidido que essa restrição será removida em uma versão futura do Swift, mas por enquanto ela continua valendo.
2. Se uma função tem parâmetros que vêm depois do parâmetro variádico na definição, o primeiro parâmetro depois do parâmetro variádico _precisa_ ter um rótulo de argumento.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
