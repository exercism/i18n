# Introdução

Os números em Clojure incluem:

- Inteiros: números sem dígitos depois do separador decimal (números inteiros). Exemplos são `-6`, `0`, `1`, `25`, `976` e `500000`.
- Números de ponto flutuante: números com zero ou mais dígitos depois do separador decimal. Exemplos são `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

Dois tipos numéricos comuns são `int` e `float`. Um `int` é um inteiro de 32 bits e um `float` é um número de ponto flutuante de 64 bits.

A aritmética é feita usando os operadores aritméticos padrão. Os números podem ser comparados usando os operadores de comparação numérica padrão (`>`, `<`, `<=`, `>=`), o operador de igualdade (`=`) e o operador de desigualdade (`not=`).

Neste exercício, você precisa executar lógica condicionalmente. Uma forma comum de fazer isso em Clojure é usar `cond`:

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```

## Nota
O operador `==` pode ser preferível ao `=` em alguns casos em que números precisam ser comparados independentemente do tipo exato. Por exemplo,
```clojure
(== 5.0 5) ;; true as both numbers are equal when type is ignored
(= 5.0 5) ;; false as the types of numbers are also taken into account here i.e. float is different from int
```
