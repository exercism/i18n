# Instruções

Você vai inicializar buffers vazios e listar os cinco primeiros números, ou elementos, da sequência de Fibonacci.

A sequência de Fibonacci é um conjunto de números em que o próximo elemento é a soma dos dois anteriores. A sequência começa no um. Assim, os dois primeiros elementos são 1 e 1.

## 1. Crie um buffer de `count` zeros.

Crie uma função que cria um buffer de `count` zeros.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Liste os cinco primeiros elementos da sequência de Fibonacci

Crie uma função que retorna os cinco primeiros números da sequência de Fibonacci.
Seus cinco primeiros elementos são `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
