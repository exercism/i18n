# Null

Null é um tipo de valor primitivo com apenas um valor: `null`.
Null costuma ser usado para representar o nada.
Ele é considerado "falsey", mas é diferente de `false` e de outros valores "falsey".

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Trabalhando com valores null

Em PHP, valores null podem ser uma causa comum de erro, porque muitas vezes são retornados no lugar de um estado de erro ou para representar o nada.
Evitar que erros aconteçam muitas vezes exige verificar se o valor não é null antes de operar sobre ele.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

Verificar a presença de null repetidamente pode ser propenso a erros, então o PHP oferece dois operadores para trabalhar com valores null: o operador `?->`, de acesso seguro a null, e o operador `??`, de coalescência de null.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
