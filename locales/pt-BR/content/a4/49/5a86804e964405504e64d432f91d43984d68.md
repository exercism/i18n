# Dicas

## Geral

- Existem três operadores lógicos '!`(logical NOT), '||` (logical OR), e `&&` (logical AND) ao trabalhar com valores Boolean.
- Vários operadores podem ser combinados em uma única expressão.

## 1. Verifique se um ataque rápido pode ser feito

- O operador lógico NOT (`!`) pode ser colocado antes de uma expressão para negar o valor dela.

## 2. Verifique se é possível espionar o grupo

- Operadores lógicos costumam ser usados para avaliar se duas ou mais expressões são verdadeiras ou não.

## 3. Verifique se é possível sinalizar para o prisioneiro

- Os operadores lógicos são executados na ordem de precedência deles (da mais alta para a mais baixa): `!`, `&&`, `||`.
