# Introdução

Em Clojure, vincular um valor a um nome é chamado de _var_. Vars de nível superior (globais) são parecidas com constantes em outras linguagens, mas costumam ser redefinidas para facilitar o desenvolvimento dinâmico.

Vars de nível superior são definidas usando `def`:

```clojure
(def fingers 10)
```

A macro `defn` pode ser usada para definir uma função que recebe zero ou mais argumentos. Uma função sempre retorna o resultado da última expressão do seu corpo.

```clojure
(defn add [x y]
  (+ x y))
```

Para invocar uma função, especifique o nome dela e passe argumentos para cada um dos parâmetros da função.

```clojure
(def five (add 2 3))
```

Funções e valores em Clojure só podem ser usados _depois_ de serem definidos. Usá-los antes de serem definidos resulta em um erro de compilação.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Em Clojure, os espaços em branco não têm significado além da formatação.

As funções e vars de Clojure são organizadas em namespaces. Um namespace agrupa funcionalidades relacionadas e é definido usando a macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure dá suporte a dois tipos de comentários. Comentários de uma linha são precedidos por `;` e a forma `comment` é usada para impedir a avaliação de tudo que estiver entre `(comment` e `)`.
