# Enums

Enums são um tipo de dados do Cairo usado para definir um conjunto de variantes predefinidas com o objetivo de tornar o código mais legível e seguro.
No Cairo, as variantes de um `enum` podem ser declaradas para conter diferentes tipos de dados (números inteiros, structs, tuplas, outros enums, etc.).

O trecho de código abaixo mostra como os enums poderiam ser definidos:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

O enum `Direction` declarado acima é um enum simples com quatro variantes: `North`, `East`, `South` e `West`.
A convenção de nomenclatura é usar PascalCase para as variantes do enum.
Cada variante representa um valor distinto do tipo `Direction`.
Cada variante neste exemplo específico de enum não tem valor associado e pode ser instanciada usando esta sintaxe:

```rust
let direction = Direction::North;
```

Abaixo está o mesmo enum `Direction`, mas com variantes que têm valores associados, que armazenam o grau exato da direção:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

Fica evidente neste exemplo que cada variante do enum `Direction` tem um valor associado do tipo `u128`.
Esse tipo de enum pode ser instanciado assim:

```rust
let direction = Direction::North(10);
```

## Exemplo de enum complexo com tipos personalizados

Um enum pode ser declarado com uma combinação de diferentes tipos de dados como suas variantes.
No exemplo abaixo, `Action` é um enum complexo que tem uma coleção de `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` e `ProfileState` como variantes.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## Implementações de traits para enums

No Cairo, traits podem ser definidos e implementados em enums personalizados.
Isso permite que você defina métodos e atributos associados a um enum.
Abaixo está um exemplo disso, no qual definimos um enum `Message` e implementamos um trait `Processing` para ele:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

Veja como o trait poderia ser usado para processar uma mensagem `Quit`:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

Em muitas situações, os enums são úteis, especialmente quando usados com o fluxo `match`, como no exemplo de implementação de traits acima.
Leia mais sobre o fluxo `match` em [The Cairo Book][match].
