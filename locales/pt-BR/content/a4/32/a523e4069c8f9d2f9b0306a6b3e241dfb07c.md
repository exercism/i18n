# Sobre

## Alias de tipo

Um alias de tipo pode ser usado em Gleam para dar um nome conveniente a um tipo existente que, de outra forma, seria trabalhoso de escrever.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Quando escrito com `pub type`, o alias pode ser usado fora do módulo em que foi definido. Se `pub` for omitido, o alias é privado e não pode ser referenciado em outros módulos.
