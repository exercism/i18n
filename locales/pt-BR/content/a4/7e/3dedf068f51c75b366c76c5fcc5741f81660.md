# Sobre

A [sobrecarga de métodos][method-overloading] é um conceito-chave em Java: permite que uma classe tenha mais de um método com o mesmo nome, desde que cada método tenha uma lista de parâmetros diferente.
Esse recurso é um aspecto fundamental da programação orientada a objetos em Java e oferece uma forma de realizar operações parecidas com tipos ou quantidades diferentes de entradas.
A sobrecarga de métodos melhora a legibilidade e a organização do código, ao permitir que métodos que fazem coisas parecidas compartilhem o mesmo nome.
É importante notar que a sobrecarga é determinada pela assinatura do método, que inclui o nome do método e a lista de parâmetros.

## Pontos-chave

- **A assinatura importa**: o tipo de retorno não faz parte da assinatura do método, então só mudar o tipo de retorno de um método não configura sobrecarga.
- **Diferenças nos parâmetros**: os métodos sobrecarregados precisam diferir no número ou no tipo de parâmetros.
- **Uso**: a sobrecarga costuma ser usada para oferecer formas mais intuitivas de usar um método com tipos diferentes de entradas.

## Exemplos de sobrecarga de métodos

Considere uma classe `Calculator` que soma números.
A sobrecarga permite diferentes tipos de operações de adição:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## Boas práticas

- **Clareza**: os métodos sobrecarregados devem ser usados de forma que tornem o código mais intuitivo.
  - O comportamento dos métodos sobrecarregados deve ser relacionado e consistente.
- **Evite ambiguidade**: garanta que cada método sobrecarregado tenha um propósito claro e que as diferenças nas listas de parâmetros sejam significativas o bastante para evitar confusão.
- **Documentação**: documente adequadamente cada versão dos métodos sobrecarregados.
  - Uma documentação clara ajuda outras pessoas desenvolvedoras a entender o propósito e o uso de cada variante do método.
- **Tipos de retorno consistentes**: embora os tipos de retorno possam variar em métodos sobrecarregados, em geral é uma boa prática mantê-los consistentes sempre que possível, para evitar confusão.
- **Limite a sobrecarga**: evite usar sobrecarga de métodos em excesso.
  - Sobrecarga em excesso pode deixar o código mais difícil de ler e de manter.

## Conclusão

A sobrecarga de métodos é um recurso poderoso em Java que, quando usado corretamente, pode melhorar muito a legibilidade e a flexibilidade do seu código.
Ela permite que os métodos sejam mais versáteis e se adaptem a contextos diferentes, tornando seus programas Java mais modulares e fáceis de manter.
