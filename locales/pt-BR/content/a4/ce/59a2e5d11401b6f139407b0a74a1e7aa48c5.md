# camelCase

[comment]: # "Este erro é gerado quando uma variável/tipo não usa camelCase/PascalCase"
[comment]: # "exige 2 parâmetros:"
[comment]: # "- wrong: nome na capitalização errada"
[comment]: # "- correct: nome na capitalização correta"

A comunidade Elm tem uma forte preferência por usar camelCase para nomes de variáveis e PascalCase para tipos.

Encontramos o nome `%{wrong}`, que deve ser substituído por `%{correct}`.
