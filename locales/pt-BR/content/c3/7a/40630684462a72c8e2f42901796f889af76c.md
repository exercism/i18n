# Instruções

Você vai escrever um código para gerenciar uma lista de linguagens de programação para aprender. A lista vai ficar em um array chamado `@LanguageList::Languages`.

## 1. Adicione uma linguagem ao array @Languages

Modifique a sub-rotina `LanguageList::add_language`, que recebe um nome de linguagem como argumento, para adicionar a linguagem ao final do array `@LanguageList::Languages`.

## 2. Remova uma linguagem do array @Languages

Modifique a sub-rotina `LanguageList::remove_language` para remover a última linguagem do array `@LanguageList::Languages`.

## 3. Obtenha a primeira linguagem do array @Languages

Modifique a sub-rotina `LanguageList::first_language` para retornar a primeira linguagem do array `@LanguageList::Languages`.

## 4. Obtenha a última linguagem do array @Languages

Modifique a sub-rotina `LanguageList::last_language` para retornar a última linguagem do array `@LanguageList::Languages`.

## 5. Obtenha uma fatia de linguagens do array @Languages

Modifique a sub-rotina `LanguageList::get_languages`, que recebe uma lista de números com os elementos desejados, para retornar uma fatia do array `@LanguageList::Languages`.

## 6. Verifique se uma linguagem existe no array @Languages

Modifique a sub-rotina `LanguageList::has_language`, que recebe um nome de linguagem como argumento, para retornar um valor verdadeiro ou falso que indica se a linguagem existe no array `@LanguageList::Languages`.
