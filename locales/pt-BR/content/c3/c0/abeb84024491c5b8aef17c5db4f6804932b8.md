# Instruções

Use o Crivo de Eratóstenes para encontrar todos os primos de 2 até um número dado.

O Crivo de Eratóstenes é um algoritmo simples e antigo para encontrar todos os números primos até qualquer limite dado.
Ele faz isso marcando iterativamente como compostos (ou seja, não primos) os múltiplos de cada primo, começando pelos múltiplos de 2.
Ele não usa nenhuma operação de divisão ou de resto.

Crie o seu intervalo, começando em dois e indo até o limite dado, inclusive.
(ou seja, [2, limite])

O algoritmo consiste em repetir o seguinte várias vezes:

- pegue o próximo número não marcado disponível na sua lista (ele é primo)
- marque todos os múltiplos desse número (eles não são primos)

Repita até ter processado cada número do seu intervalo.

Quando o algoritmo termina, todos os números da lista que não foram
marcados são primos.

[Este artigo da Wikipédia][eratosthenes] tem uma imagem útil que explica o algoritmo.

Repare que este é um algoritmo bem específico, e os testes não verificam se você implementou o algoritmo, apenas se você chegou à lista correta de primos.
Um bom primeiro teste é verificar que você não usa operações de divisão ou de resto (div, /, mod ou % dependendo da linguagem).

[eratosthenes]: https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes
