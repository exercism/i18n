# Introdução

Na maior parte do tempo, o Factor lida com iteração por meio de combinadores como
`each`, `map` e `count`. Às vezes, porém, a forma mais limpa de expressar um
cálculo é a **recursão**: uma palavra que chama a si mesma.

## Definindo uma palavra recursiva

Uma definição com `:` pode chamar a si mesma diretamente:

```factor
: count-down ( n -- )
    dup 0 = [ drop ] [ dup . 1 - count-down ] if ;

5 count-down
! prints 5 4 3 2 1
```

## Ramificação entre vazio e não vazio

`if-empty` (em [`sequences`][sequences]) é o caso base natural da recursão:

```
if-empty ( seq emptyquot nonemptyquot -- )
```

```factor
{ 4 0 9 } [ "empty" ] [ "got data" ] if-empty .
! => "got data"
```

O `emptyquot` roda com a sequência (vazia) já consumida;
o `nonemptyquot` roda com a sequência ainda na pilha.

## `cond`: uma cadeia de ramificações com guardas

Quando a sua recursão tem mais de dois casos, `cond` (em
[`combinators`][combinators]) mantém o código legível:

```factor
: classify ( n -- label )
    {
        { [ dup 0 < ] [ drop "negative" ] }
        { [ dup 0 = ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

## Referências antecipadas com `DEFER:`

Uma definição com `:` pode chamar a si mesma diretamente, mas quando duas
palavras chamam *uma à outra*, o parser vê a primeira antes de a segunda
existir. O `DEFER:` reserva um nome para que a primeira definição consiga
compilar:

```factor
DEFER: even?

: odd? ( n -- ? ) dup 0 = [ drop f ] [ 1 - even? ] if ;
: even? ( n -- ? ) dup 0 = [ drop t ] [ 1 - odd? ] if ;
```

O `DEFER:` também é útil quando uma palavra auxiliar é lida mais naturalmente
*depois* da palavra que a usa.
