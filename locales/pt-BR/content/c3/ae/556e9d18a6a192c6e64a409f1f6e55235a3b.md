# Instruções

Um único fabricante pode produzir dois tipos diferentes de motores; a partir daqui, os motores serão chamados de motor A e motor B. Ambos os motores têm 3 componentes necessários para a produção: fiação, perfuração e montagem. Cada motor exige uma quantidade diferente de tempo para cada uma dessas etapas de produção. Em geral, uma única unidade do motor A exige t_a_1 horas para fiação, t_a_2 horas para perfuração e t_a_3 horas para montagem. Por outro lado, uma única unidade do motor B exige t_b_1 horas para fiação, t_b_2 horas para perfuração e t_b_3 horas para montagem. Implemente uma função que, dados o total de horas alocado para cada etapa de produção (t_1 horas para fiação, t_2 horas para perfuração e t_3 horas para montagem) e os preços de cada tipo de motor (p_a, p_b), calcule as quantidades ótimas do motor A e do motor B que maximizam o lucro.

A função terá 4 parâmetros de entrada no total. Eles são descritos abaixo:
1. a_hours: tupla de três elementos (t_a_1, t_a_2, t_a_3) em horas
2. b_hours: tupla de três elementos (t_b_1, t_b_2, t_b_3) em horas
3. total_hours: tupla de três elementos (t_1, t_2, t_3) em horas
4. prices: tupla de dois elementos (p_a, p_b) em dólares

A saída deve ser uma única tupla de três elementos composta por (q_a, q_b, profit), em que:
1. q_a: quantidade ótima do motor A a produzir
2. q_b: quantidade ótima do motor B a produzir
3. profit: valor do lucro máximo em dólares

Outros pontos importantes a observar:
q_a e q_b não podem ser números de ponto flutuante, porque não é possível produzir uma fração de motor.
Os resultados do modelo Z3 para as variáveis precisarão ser convertidos para int antes de comporem a saída. Se o resultado do modelo Z3 for do tipo `IntNumRef`, o método de classe `as_long()` pode ser usado para converter para um número inteiro.
Se o problema for insatisfatível devido a entradas inválidas, lance uma exceção embutida do Python `ArithmeticError()`.
