# Introdução

A classe Lambda é uma coleção de métodos funcionais para usar programação no estilo funcional com Haxe. Ela permite operar sobre um Iterable inteiro de uma vez. Isso costuma ser preferível a rotinas de laço, já que é menos propenso a erros e mais fácil de ler. Por conveniência, as classes Array e List contêm alguns dos métodos mais usados da classe Lambda.

Algumas das funções da classe `Lambda` incluem:

- `Lambda.array`, `Lambda.list` Convertem um Iterable em Array ou List. Sempre retornam uma nova instância.
- `Lambda.count` Conta o número de elementos. Se o Iterable for um Array ou uma List, é mais rápido usar a propriedade length dele.
- `Lambda.has` Determina se o elemento especificado está no Iterable.
- `Lambda.indexOf` Descobre o índice do elemento especificado.
- `Lambda.find` Encontra o primeiro elemento de acordo com a função de busca fornecida.
- `Lambda.concat` Combina dois Iterables, retornando uma nova List.
- `Lambda.filter` Encontra os elementos que satisfazem a um critério, retornando uma nova List.

Um exemplo demonstrando algumas funções:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
