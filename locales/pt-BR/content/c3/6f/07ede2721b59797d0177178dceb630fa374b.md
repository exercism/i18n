# Instalação

## Instalando a CLI do Clojure
O Clojure oferece ferramentas de linha de comando que podem ser usadas para iniciar um REPL do Clojure, usar bibliotecas Clojure e Java e iniciar programas Clojure.

Se você precisar instalar o Java, recomendamos o [Adoptium Temurin 17](https://adoptium.net/).

### Linux
Verifique se as seguintes dependências estão instaladas: `bash`, `curl`, `rlwrap` e `Java`. 
Você pode instalar o Clojure de uma destas 2 formas:

1. LinuxBrew - requer o [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. Instalador por script

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew no Mac OS X
Instale as ferramentas de linha de comando com o brew a partir do tap [clojure/tools](https://github.com/clojure/homebrew-tools):

```bash
brew install clojure/tools/clojure
```

#### Java

Qualquer distribuição de Java funciona. Se precisar, você pode instalar o Temurin usando o brew:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

O Clojure no Windows melhorou bastante recentemente. Costumávamos recomendar o WSL2, que funciona muito bem,
mas agora existe um instalador para PowerShell. O Clojure no Windows está atualmente em fase alpha; veja [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues) para problemas conhecidos.

Verifique se o Java está instalado e se a variável de ambiente `JAVA_HOME` está definida, e execute:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Outra forma de instalar o Clojure no Windows é com o gerenciador de pacotes [Scoop](https://scoop.sh/). Para instalar o Scoop, abra o PowerShell e execute estes 2 comandos, um após o outro:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Para instalar o Clojure com o Scoop, você precisa primeiro adicionar dois buckets importantes:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

Agora é só instalar o Java e o Clojure com os seguintes comandos:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

Depois de executar os passos acima com sucesso, você vai conseguir rodar o Clojure com o seguinte comando:

```sh
clj
```

## Instalar o Leiningen (opcional)

Embora não seja mais necessário, ainda damos suporte à ferramenta completa de gerenciamento de projetos [Leiningen](https://leiningen.org/).
Ela oferece uma grande variedade de tarefas úteis, como testes práticos, builds e um REPL melhor.

1. Baixe o [script lein](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) ou o [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) (Windows)
2. Coloque-o em seu `$PATH`, onde o seu shell consiga encontrá-lo (por exemplo, `/usr/local/bin/`)
3. Torne-o executável (`sudo chmod a+x /usr/local/bin/lein`)
4. Execute `lein`.
