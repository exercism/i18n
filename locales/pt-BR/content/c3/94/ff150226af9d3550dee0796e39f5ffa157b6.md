# Dicas

## Geral

- Existem três [operadores Boolean][boolean-operators] para trabalhar com valores Boolean escalares.
- Vários operadores podem ser combinados em uma única expressão.

## 1. Verificar se um ataque rápido pode ser feito

- O operador lógico NOT (`!`) pode ser colocado antes de uma expressão para negar o valor dela.

## 2. Verificar se o grupo pode ser espionado

- Os operadores Boolean normalmente são usados para avaliar se duas ou mais expressões são `TRUE` ou não`!`

## 3. Verificar se o prisioneiro pode ser sinalizado

- Os operadores Boolean são executados na ordem de precedência deles (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Em geral, o uso de parênteses é incentivado para deixar sua intenção mais clara.

## 4. Verificar se o prisioneiro pode ser libertado

- Os operadores Boolean são executados na ordem de precedência deles (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Em geral, o uso de parênteses é incentivado para deixar sua intenção mais clara.
