## Dicas de `jq`

Este exercício é sobre pegar um objeto de entrada e transformá-lo em um novo objeto.
Algumas funções integradas que podem ajudar:

- [`to_entries`][x_entries]
  - essa função recebe um objeto como entrada
  - ela produz um _array_, e cada elemento do array é um objeto `{"key": "K", "value": V}`
    - cada `K` é uma chave do objeto de entrada
    - cada `V` é o valor correspondente a `K`.
- [`from_entries`][x_entries]
  - a operação inversa
  - recebe um array de objetos `{"key": K, "value": V}` e constrói um objeto

Um exemplo:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

produz:

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
