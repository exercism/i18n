# Instruções

Encontre a diferença entre o quadrado da soma e a soma dos quadrados dos N primeiros números naturais.

O quadrado da soma dos dez primeiros números naturais é
(1 + 2 + ... + 10)² = 55² = 3025.

A soma dos quadrados dos dez primeiros números naturais é
1² + 2² + ... + 10² = 385.

Portanto, a diferença entre o quadrado da soma dos dez primeiros
números naturais e a soma dos quadrados dos dez primeiros
números naturais é 3025 - 385 = 2640.

Não se espera que você descubra sozinho uma solução eficiente para isso
partindo dos princípios básicos; pesquisar é permitido e, aliás, incentivado.
Encontrar o melhor algoritmo para o problema é uma habilidade essencial
na engenharia de software.
