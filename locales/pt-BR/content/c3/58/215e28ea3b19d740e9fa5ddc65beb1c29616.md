# Testes

## Rodando os testes

1. Baixe um exercício:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Entre no diretório do exercício:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Rode os testes:

    ```bash
    $ ./gradlew test
    ```

Na maioria dos exercícios, apenas o primeiro teste roda por padrão.  
Os outros testes estão anotados com `@Ignore` para serem pulados.  
Conforme você resolve cada teste, remova o `@Ignore` do próximo para avançar.

Essa é uma prática comum no desenvolvimento orientado a testes (ou TDD, para encurtar).
Ela serve para garantir que você esteja trabalhando em um problema de cada vez.
