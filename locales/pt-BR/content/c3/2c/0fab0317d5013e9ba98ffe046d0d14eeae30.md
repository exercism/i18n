# Introdução

O tipo `char` do F# é um valor de 16 bits que representa os menores componentes endereçáveis de texto, imutável por padrão.

Os `char`s podem ser definidos como literais com aspas simples:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Strings são uma sequência de chars.

Um `char` individual pode ser obtido de uma string com indexação (a partir do zero):

```fsharp
"Exercism"[4] //  =>  'c'
```

Iterar sobre uma string retorna um `char` a cada passo.

O próximo exemplo usa uma função de ordem superior e uma função anônima, por conveniência.
Elas serão abordadas direito mais adiante no programa de estudos, mas por enquanto são, na prática, uma forma concisa de escrever um laço sobre os caracteres de uma string.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Como mostrado acima, um `char` pode ser convertido para seu valor `int`.
Isso também funciona (*pelo menos algumas vezes*) para outros sistemas de escrita:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

O Int16 subjacente é usado ao comparar caracteres:

```fsharp
'A' < 'D'  // =>  true
```

Além disso, um `int` pode ser convertido para `char`:

```fsharp
char 77  // => 'M'
```

A biblioteca `System.Char` contém o conjunto completo de métodos esperados para uma linguagem .NET, como conversões para maiúsculas/minúsculas:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
