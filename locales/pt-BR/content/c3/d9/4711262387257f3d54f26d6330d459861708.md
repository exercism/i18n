# Arrays

Um **array**, ou _vetor_, guarda uma fileira de valores do mesmo tipo, em ordem.

O tipo é escrito `ARRAY{T}`, em que `T` é o que ele guarda. Um array de strings é
`ARRAY{STR}`; um array de números inteiros é `ARRAY{INT}`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

Os valores entre as duas marcas `|` são o **literal de array**. O Sather
descobre o tamanho a partir de quantos são.

## Como obter um valor

Os colchetes guardam a posição:

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

A contagem começa em **zero**, não em um. Então o primeiro valor está em `0`, e o
último, numa fileira de três, está em `2`.

## Quantos?

`.size` é quantos valores o array guarda.

```sather
row.size    -- 3
```

Como a contagem começa em zero, a última posição é sempre `.size - 1`:

```sather
row[row.size - 1]     -- "Ben"
```

Pedir uma posição que não existe, como `row[3]` ou `row[-1]`, é um erro que o
Sather não vai pegar para você. Por isso, vale mais escrever `.size - 1` do que
contar os valores de cabeça.

## Percorrendo um array

Um array e um laço andam juntos. Faça uma variável subir pelas posições e use-a
para alcançar cada valor:

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
