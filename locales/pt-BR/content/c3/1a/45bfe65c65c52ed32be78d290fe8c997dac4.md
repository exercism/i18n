# Dicas

## Geral

- O namespace `clojure.string` tem muitas [funções úteis de manipulação de string][string-ns].

## 1. Obter a mensagem de uma linha de log

- A função [`split`][split] pode ser usada para dividir uma string com base em uma expressão regular.
- A função [`trim`][trim] pode ser usada para remover espaços em branco das extremidades de uma string.

## 2. Obter o nível de log de uma linha de log

- Uma `string` pode ser convertida para minúsculas usando [`lower-case`][lower-case].

## 3. Reformatar uma linha de log

- A função [`str`][str] pode ser usada para concatenar strings.
