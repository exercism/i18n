# Testes

## Resumo rápido

- Vá até o diretório do problema (por exemplo, `~/Exercism/hello-world`).
- Inicie uma sessão do `jconsole` em um terminal.
- Carregue o arquivo da sua solução (por exemplo, `load 'hello-world.ijs'`).
- Carregue o framework de testes unitários digitando `load  'general/unittest'`.
- Teste sua solução digitando `unittest 'test.ijs'`.
<br></br>
- Como alternativa, é possível rodar os testes em uma única linha assim: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Sessão do Jconsole

A ideia é que a configuração dos testes da trilha seja o mais simples possível.
Se você está fazendo um exercício, digamos `hamming.ijs`, veja como o trabalho deve fluir.
Edite `hamming.ijs` escrevendo sua solução.
Construa a solução interativamente começando por digitar:

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

Depois, de dentro do console do J, recarregue digitando

```j
load 'hamming.ijs'
```

O próximo passo é carregar o framework de testes unitários digitando

```j
load 'general/unittest'
```

Para rodar os testes, depois de carregar sua solução, digite

```j
unittest 'test.ijs'
```

E então observe os resultados.

## Linha de comando

Você pode rodar os testes com um único comando no terminal usando a flag -js:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
onde cada argumento representa um comando que será executado em sequência.
