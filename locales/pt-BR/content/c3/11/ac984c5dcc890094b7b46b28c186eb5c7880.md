# Instruções

Sua amiga Leticia trabalha no setor de Achados e Perdidos de uma estação de metrô.

Cada objeto encontrado é adicionado como uma nova entrada em uma lista de itens do dia.
No fim do mês, todo item que não for retirado é movido para um depósito, em uma caixa etiquetada com a data em que foi encontrado.
Tudo isso é feito no papel, então as coisas às vezes ficam complicadas!

Leticia pediu sua ajuda para automatizar algumas dessas tarefas.

~~~~exercism/note
Estas são as instruções mencionadas neste conceito:

| Instrução     | Descrição                                                     |
|---------------|---------------------------------------------------------------|
| push a        | empilha a na pilha, reduzindo `rsp` pelo tamanho de a         |
| pop a         | desempilha a da pilha, aumentando `rsp` pelo tamanho de a     |

## 1. Crie uma entrada para cada item

A primeira coisa que você precisa fazer é organizar todos os itens, para que possam ser consultados de forma mais fácil.
Cada item é identificado no armazenamento pelo seu ID, por uma descrição, pela data em que foi encontrado e por um número variável de categorias.

Defina uma função `create_item_entry` que não tem valor de retorno e insere uma nova entrada para um item em um local da memória.
Essa função pode receber qualquer número de parâmetros, dos quais os seis primeiros são sempre:

1. O endereço de um local na memória onde a entrada deve ser armazenada.
2. O ID do item, como um inteiro sem sinal de 64 bits.
3. O endereço de uma string com a descrição do item.
4. O dia em que o item foi encontrado, como um inteiro sem sinal de 64 bits.
5. O mês em que o item foi encontrado, como um inteiro sem sinal de 64 bits.
6. O número de categorias do item, como um inteiro sem sinal de 64 bits.

Cada parâmetro seguinte é o endereço de uma string com uma das categorias.

Os valores devem ser armazenados no local de memória fornecido na mesma ordem dos argumentos: ID, descrição, dia, mês, número de categorias e cada categoria em ordem.

## 2. Reserve espaço para uma lista mensal de itens

É trabalhoso procurar itens em tantas listas diferentes.
Então você decide organizar tudo em uma única lista para cada mês.
Essa lista é implementada como um array.

Defina a função `create_monthly_list`, que aloca espaço na memória para um array e retorna o endereço desse local na memória.
Ela recebe como parâmetros:

1. A capacidade do array em bytes, como um inteiro sem sinal de 64 bits.
2. Uma função alocadora.

A função alocadora recebe como parâmetro um inteiro sem sinal de 64 bits correspondente ao tamanho em memória a ser alocado, em bytes, e retorna o endereço do espaço alocado.

Repare que o espaço alocado tem valor _indefinido_, então todos os bytes desse espaço devem ser limpos, ou seja, seu valor deve ser definido como `0`.

## 3. Insira um item na lista mensal

A cada dia, todo item encontrado deve ser inserido na lista mensal.

Defina a função `insert_found_item`, que não tem valor de retorno e recebe como parâmetros:

1. O endereço de um espaço na memória onde a lista mensal está localizada.
2. O número atual de entradas já armazenadas na lista, como um inteiro sem sinal de 64 bits.
3. Uma nova entrada a ser adicionada à lista.

Você pode considerar que a nova entrada sempre cabe na lista e que cada entrada da lista ocupa 120 bytes de espaço.

## 4. Imprima um item

Procurar uma entrada específica seria muito mais fácil se Leticia pudesse vê-la impressa na tela.

Defina a função `print_item`, que recebe como parâmetros:

1. O endereço de um buffer onde pode ser armazenada uma string introdutória ASCII terminada em NUL.
2. O endereço de um espaço na memória onde a lista mensal está localizada.
3. O índice da entrada no array correspondente ao item que deve ser impresso, como um inteiro sem sinal de 64 bits.
4. Uma função de impressão.

Essa função não tem valor de retorno e deve chamar a função de impressão com os seguintes argumentos:

1. O endereço de um local na memória onde a string introdutória está armazenada; ou `0` (como um inteiro de 64 bits) se nenhuma string for passada.
2. O índice da entrada no array correspondente ao item que deve ser impresso, como um inteiro sem sinal de 64 bits.
3. O ID do item, como um inteiro sem sinal de 64 bits.
4. O endereço de uma string com a descrição do item.
5. O dia em que o item foi encontrado, como um inteiro sem sinal de 64 bits.
6. O mês em que o item foi encontrado, como um inteiro sem sinal de 64 bits.
7. O número de categorias do item, como um inteiro sem sinal de 64 bits.
8. O endereço da primeira string de categoria.

A string introdutória é opcional.
Se ela for usada na função de impressão, essa string deve terminar em NUL (terminando em `0`) e ter no máximo 50 caracteres, já considerando o terminador NUL.
Caso contrário, o valor `0` deve ser passado à função de impressão.

Você pode considerar que cada item da lista ocupa 120 bytes de espaço.
