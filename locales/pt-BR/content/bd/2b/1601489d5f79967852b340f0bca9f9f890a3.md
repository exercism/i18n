# Introdução

O tipo `Result` permite que uma função retorne um único valor que indica todas estas coisas:

- Se a operação teve sucesso ou falhou
- Em caso de sucesso, o valor resultante da operação
- Em caso de falha, o motivo da falha

## Uso

`Result` é um tipo genérico que contém dois tipos subjacentes:

- O tipo do valor resultante em uma operação bem-sucedida
- O tipo que representa o motivo da falha em caso de falha

O tipo `Result` também é uma [união discriminada][discriminated-union] com os seguintes casos possíveis:

- `Ok <value>` representa um resultado bem-sucedido
- `Error <reason>` representa uma falha

A função a seguir mostra como criar um valor `Result`:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

Nesse exemplo, o valor `Ok` é uma string (o nome fornecido), e o valor `Error` também é uma string (a causa do erro, em formato legível para humanos).

## Lendo o conteúdo de um valor `Result`

Considere a seguinte definição de tipo e assinatura de função:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

O código que chama a função `openFile` pode usar correspondência de padrões para tratar os casos de sucesso e de falha, como no exemplo a seguir:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
