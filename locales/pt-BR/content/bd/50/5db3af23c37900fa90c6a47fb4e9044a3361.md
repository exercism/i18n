# Anexo de instruções

## Crie sua própria DSL

Neste exercício, você tem total liberdade para projetar a DSL de grafo dos seus sonhos.

Os testes exigem apenas que você crie alguns grafos específicos. A forma de construí-los é totalmente com você.

Para dobrar a diversão, você pode, opcionalmente, tentar implementar uma função `to_dot` que converte seu grafo para o formato DOT!

## Representação do grafo

Defina sua DSL em `Graph.roc` e depois use-a para construir os grafos pedidos pelo stub.
Os dois IDs de nó em cada `EdgeId` devem estar em ordem alfabética.

| Definição | Grafo a construir |
| --- | --- |
| `empty_graph` | Um grafo vazio |
| `graph_with_one_node` | Um nó |
| `graph_with_one_node_with_attribute` | Um nó com um atributo |
| `graph_with_one_edge` | Uma aresta |
| `graph_with_one_attribute` | Um atributo do grafo |
| `graph_with_nodes_edges_and_attributes` | Nós, arestas e atributos |
| `multiple_edges_on_one_line` | Várias arestas expressas em uma linha |
| `only_1_edge_between_nodes` | Apenas uma aresta entre cada par de nós |
