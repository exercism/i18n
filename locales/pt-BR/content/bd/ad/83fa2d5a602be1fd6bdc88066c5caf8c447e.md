# Introdução

## Ciclo de vida de recursos

[concept:csharp/resource-cleanup]() usa a interface `IDispose` para sinalizar que o recurso de algum objeto, ou outro estado do programa, precisava ser liberado ou redefinido quando o objeto não era mais necessário (e que depender do coletor de lixo não alcançaria isso nem ofereceria o nível de controle necessário) e que o método `IDisposable.Dispose()` era o lugar natural para essas operações de limpeza.

Existe outra construção, o bloco `using`, que permite, do ponto de vista de quem chama, reunir todo o gerenciamento do ciclo de vida dos recursos em uma única instrução.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

No exemplo acima, os recursos do sistema de arquivos associados a `file` serão liberados de volta para o sistema operacional quando o bloco `using` for encerrado.

Para que o padrão funcione, a variável na instrução `using` precisa ser um tipo de referência que implemente a interface `IDisposable` e precisa liberar recursos/redefinir o estado do programa em seu método `Dispose()`.

O C# 8 introduz um refinamento desse padrão. Uma instrução `using` pode ser colocada no início de um bloco.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Quem programa em Java pode reconhecer isso como um análogo do mecanismo de _gerenciamento automático de recursos_ introduzido no Java 7.
