# Introdução

## Primeiros passos

### Variáveis

Você pode armazenar e nomear valores definindo uma [variável][constants-variables].
Depois de definir uma variável, você pode usar o nome dela para se referir a esse valor em todo o seu código.
As variáveis são _mutáveis_, o que significa que os valores delas podem mudar depois de definidos.

Defina uma variável com a palavra-chave `var`:

```swift
var variableName = 10
```

Swift é uma linguagem com tipagem estática, o que significa que todo valor tem um tipo conhecido em tempo de compilação.
Você pode declarar um tipo explicitamente com uma [anotação de tipo][type annotations], ou pode deixar o compilador do Swift [inferir o tipo][type-inferring] a partir do valor atribuído:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Você pode atualizar o valor de uma variável usando o operador de atribuição (`=`):

~~~~exercism/note
O tipo de uma variável não pode mudar depois que ela for declarada.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Você pode declarar uma variável sem um valor inicial especificando o tipo dela, mas precisa atribuir um valor antes de usá-la:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Constantes

As [constantes][constants-variables] também associam um nome a um valor, mas os valores delas não podem ser alterados depois da atribuição.
Elas são _imutáveis_.
Defina uma constante com a palavra-chave `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Operadores aritméticos

O Swift oferece os [operadores aritméticos][arithmetical-operators] padrão para a matemática básica:

- Adição: `+`
- Subtração: `-`
- Multiplicação: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Funções

No Swift, as [funções][functions] são blocos de código independentes que executam uma tarefa específica.
As funções podem receber entradas, retornar um valor e ser passadas como valores para outras funções.
Defina uma função com a palavra-chave `func`, seguida do nome da função, de uma lista de parâmetros entre parênteses e de um tipo de retorno opcional:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

As funções do Swift usam [rótulos de argumento][argument-labels], que fazem o código ser lido como frases naturais:

- O **rótulo de argumento** é usado na chamada da função.
- O **nome do parâmetro** é usado dentro do corpo da função para acessar o valor.

Se você especificar apenas um nome, o Swift o usa como rótulo de argumento e como nome de parâmetro ao mesmo tempo:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Se você não quiser um rótulo de argumento na chamada da função, escreva um sublinhado (`_`) antes do nome do parâmetro:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Todos os parâmetros de uma função são constantes (`let`) por padrão, ou seja, os valores deles não podem ser modificados dentro do corpo da função.

Para retornar um valor de uma função, especifique o tipo de retorno depois de `->` e use a palavra-chave `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Quando uma função não retorna um valor, o tipo de retorno dela é `Void` (equivalente a uma tupla vazia, `()`).
Nessas funções, você pode omitir tanto o tipo de retorno `-> Void` quanto a instrução `return`.

### Comentários

O Swift dá suporte a duas formas de [comentários][comments]:

- **Comentários de uma linha** começam com `//` e vão até o fim da linha.
- **Comentários de várias linhas** ficam entre `/*` e `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
