# Introdução

Uma _string_ é o tipo de dado do JavaScript para armazenar dados de texto.

## Criando uma string

Você cria uma string envolvendo o texto em aspas simples ou aspas duplas.
No Exercism, usamos aspas simples.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## Strings como listas de caracteres

Uma string pode ser tratada como uma lista de caracteres, em que o primeiro caractere tem índice `0`.
Você pode acessar um caractere individual da string usando colchetes e o índice da letra que quer obter.

```javascript
'cat'[1];
// => 'a'
```

Você pode descobrir o número de caracteres de uma string acessando a propriedade `length`.

```javascript
'cat'.length;
// => 3
```

## Concatenação e métodos

A forma mais simples de concatenar strings é usar o operador de adição `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

As strings oferecem muitos métodos auxiliares; consulte a [documentação da MDN sobre métodos de string][mdn-string-methods] para ver a lista completa.
A lista a seguir mostra alguns auxiliares usados com frequência.

- [`toUpperCase`][mdn-to-upper-case] e [`toLowerCase`][mdn-to-lower-case] - mudam todos os caracteres para maiúsculas ou minúsculas
- [`trim`][mdn-trim] - removem espaços em branco no início e no fim
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] e [`endsWith`][mdn-ends-with] - verificam se outra string faz parte da string em questão
- [`slice`][mdn-slice] - extraem uma parte da string

As strings são imutáveis em JavaScript. Por isso, uma "modificação", por exemplo com alguns dos métodos acima, sempre cria uma nova string.
