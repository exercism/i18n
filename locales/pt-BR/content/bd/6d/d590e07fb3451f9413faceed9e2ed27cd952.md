# Sobre

## Herança

Java dá suporte à herança como parte central de seu funcionamento e, com ela, é possível implementar vários princípios de POO, como a abstração.

Uma classe pode estender outra classe usando a palavra-chave `extends` e pode herdar de uma interface usando a palavra-chave `implements`.

## Modificadores de acesso

Os modificadores de acesso definem regras sobre o acesso às variáveis de membro e aos métodos de uma classe a partir de outras classes (ou de qualquer lugar do código).

Existem quatro modificadores de acesso:

- `private`
- `public`
- `protected`
- padrão (nenhuma palavra-chave necessária)

Você pode ler mais sobre eles [neste artigo][access-modifiers]

## Herança vs composição

Esses conceitos são muito parecidos e muitas vezes são confundidos.

- Herança significa que a classe filha tem uma relação É-UM com a classe mãe.

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

Aqui, `Dog` É-UM `Animal`

- Composição representa uma relação TEM-UM.

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

Aqui, `Car` TEM-UM `Engine`
