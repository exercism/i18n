# Instruções

`Two-fer` ou `2-fer` é a abreviação de two for one.
Um para você e um para mim.

Dado um nome, retorne uma string com a mensagem:

```text
One for name, one for me.
```

Onde "name" é o nome fornecido.

No entanto, se o nome estiver faltando, retorne a string:

```text
One for you, one for me.
```

Aqui estão alguns exemplos:

|Nome    |String a retornar
|:-------|:------------------
|Alice   |One for Alice, one for me.
|Bob     |One for Bob, one for me.
|        |One for you, one for me.
|Zaphod  |One for Zaphod, one for me.
