# variável extra criada para o nome

Criar uma variável extra para guardar o nome é desnecessário, já que Go não passa variáveis por referência.
Reatribuir `name` não vai alterar o valor fora do escopo da função `ShareWith`.
Como Go não oferece uma forma de definir valores padrão para os parâmetros de uma função,
é uma convenção comum em Go reatribuir o valor para definir um padrão.
