# Debug

Quando um teste falha, uma mensagem é exibida descrevendo o que deu errado e com qual entrada.
Você pode inspecionar valores arbitrários do seu programa passando-os para o método `debug` (disponível em `exercism/test_runner`).
Isso captura os valores e mostra a saída para você.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
