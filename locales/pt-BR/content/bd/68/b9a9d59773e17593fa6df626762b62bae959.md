# Introdução

A [lista][list] é uma coleção mutável de itens em _sequência_.
 Elas são uma estrutura de dados extremamente flexível e útil que muitos métodos e operações `built-in` do Python produzem como saída.
 As listas podem guardar referência a qualquer tipo de dado (ou a vários), incluindo outras listas ou estruturas de dados como [tuplas][tuples], [conjuntos][sets] ou [dicionários][dicts].
 Você pode iterar sobre o conteúdo usando a construção `for item in <list>`.
 Se precisar dos índices junto com o conteúdo, você pode usar `for index, item in enumerate(<list>)`.
 Elementos dentro de uma `list` podem ser acessados por um número `0-based index` a partir da esquerda, ou por um número `-1-based index` a partir da direita.
 Listas podem ser copiadas por inteiro ou em parte usando  _notação de fatia_ ou `<list>.copy()`.
