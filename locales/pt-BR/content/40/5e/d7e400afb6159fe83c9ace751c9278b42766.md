# Dicas

## Geral

- Você vai precisar importar o [módulo Dict][dict-module].

## 1. Agregue os marcadores de gols

- Provavelmente é mais fácil definir uma função de atualização e usar `Dict.update` em `updateGoalCountForPlayer`.

## 2. Remova os jogadores insignificantes

- O `Dict.filter` é o mais fácil para isso.

## 3. Zere a contagem de gols de um jogador

- O `Dict.insert` é o mais fácil para isso.

## 4. Formate a contagem de gols de um único jogador

- `Dict.get`, `Maybe.map` e `Maybe.withDefault` são úteis para isso.

## 5. Formate a contagem de gols de todos os jogadores

- `Dict.toList`, `List.map` e `String.join` são úteis para isso. `sort` não é necessário.

## 6. Combine as partidas

- O `Dict.merge` é o mais fácil para isso.

[dict-module]: https://package.elm-lang.org/packages/elm/core/latest/Dict
