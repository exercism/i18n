# Instalação

## Qual versão escolher?

Recomendamos usar uma versão estável do PHP com suporte ativo.
Atualmente, são o **PHP 8.2, 8.3 e 8.4**.
Detalhes sobre as versões atuais e seus cronogramas podem ser encontrados na [documentação oficial do PHP](https://www.php.net/supported-versions.php).

## Instalar o PHP

A maioria dos gerenciadores de pacotes para Linux / macOS fornece pacotes prontos.
O PHP pode ser baixado e compilado a partir do código-fonte, disponível em [php.net/downloads.php](https://php.net/downloads.php) ou [windows.php.net/download](https://windows.php.net/download).

~~~~exercism/note
Não é necessário um servidor web como o nginx ou o Apache HTTP server para completar os exercícios.
~~~~

### Linux

Distribuições diferentes têm métodos diferentes.
Você deve conseguir rodar

```shell
yum install php
```

ou

```shell
apt-get install php
```

dependendo do seu gerenciador de pacotes.

Para mais instruções, leia o manual do PHP sobre [Instalação em sistemas Unix](https://www.php.net/manual/en/install.unix.php).

### macOS

Embora o PHP muitas vezes já venha incluído no macOS, ele costuma estar desatualizado.
Recomendamos instalar o PHP pelo [Homebrew](https://brew.sh/).
Você pode instalar o Homebrew seguindo as instruções [na página inicial dele](https://brew.sh/#install).

Para confirmar a instalação, experimente o comando a seguir; no momento em que escrevemos, ele deve exibir o Homebrew `4.5.x`.

```shell
brew --version 
```

Instale o PHP pelo Homebrew

```shell
brew install php@8.4
```

Isso deve exibir a versão do PHP agora instalada, no mínimo a versão `8.2.0`.

```shell
php -v
```

Para mais instruções, leia o manual sobre [Instalação no macOS](https://www.php.net/manual/en/install.macosx.php).

### Windows

Os binários oficiais do PHP para Windows podem ser baixados em [windows.php.net/download](https://windows.php.net/download).

Existem pacotes prontos, incluindo [WAMP](https://www.wampserver.com/en/) - (Windows, Apache, MySQL, PHP) e [XAMPP](https://www.apachefriends.org/de/index.html).

Para mais instruções, leia o manual sobre [Instalação em sistemas Windows](https://www.php.net/manual/en/install.windows.php).

### Docker

Se você preferir soluções em contêiner, pode baixar a [imagem oficial do PHP no Docker Hub](https://hub.docker.com/_/php).
Você também vai precisar do [Docker](https://docs.docker.com/engine/install/).

### Outros

Se você quiser usar outro sistema operacional, veja as instruções em [php.net/manual/en/install](https://www.php.net/manual/en/install.php).

## Instalar o PHPUnit

~~~~exercism/note
O PHPUnit 12 ainda não é suportado!
~~~~

### Via PHP Archive (PHAR)

A maneira mais fácil de usar o PHPUnit nos exercícios do Exercism é baixar uma distribuição empacotada como PHP Archive (PHAR), que também é a forma recomendada de usar o PHPUnit.
Guarde o PHAR onde você guardou a CLI `exercism`, para rodar o PHPUnit de qualquer lugar.

Você pode baixar uma versão dos pacotes do PHPUnit como um PHP archive:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

Depois, torne o arquivo baixado executável:

```shell
chmod +x phpunit.phar
```

E mova-o para o mesmo local para onde você moveu a CLI `exercism`, dando ao comando o nome `phpunit`:

```shell
mv phpunit.phar ~/bin/phpunit
```

Agora você pode rodar o `phpunit` de qualquer lugar, como mostrado na [documentação de testes da trilha de PHP](https://exercism.org/docs/tracks/php/tests):

```shell
phpunit --version
```

A saída deve ser parecida com isto:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

Você também pode seguir as [instruções oficiais de instalação do PHPUnit](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) para instalar o PHPUnit.

### Via Composer

A versão 11 do PHPUnit também pode ser instalada via [Composer](https://getcomposer.org).

#### Instalar o Composer

Instale o [Composer](https://getcomposer.org) seguindo as [instruções de instalação](https://getcomposer.org/doc/00-intro.md) do sistema operacional do seu dispositivo. Recomendamos instalá-lo globalmente para facilitar o uso.

#### Adicionar o PHPUnit como ferramenta global

Usando o comando a seguir:

```shell
composer global require phpunit/phpunit ^11.5
```

Certifique-se de instalar a versão 11.5 ou mais recente.
