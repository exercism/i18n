# Apêndice das instruções

## Como este exercício está estruturado na trilha de Python

Os testes deste exercício esperam que você crie uma [`class`][classes] Matrix (_veja também [concept:python/classes]()_).
Isso é diferente de _usar_ um objeto Matrix de uma biblioteca de terceiros como [Numpy][numpy-matrix], o que não é suportado.
 _Não se preocupe, não é tão complicado quanto você imagina!_
 Para mais pontos de partida e detalhes sobre `classes` e estruturas de dados, dê uma olhada nos recursos abaixo:


-   [**Um primeiro contato com classes**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) da documentação do Python 3. 
-   [**Como definir uma classe em Python**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) do site Real Python.  
-   [**Estruturas de dados em Python**](https://docs.python.org/3/tutorial/datastructures.html) da documentação do Python 3.

[numpy-matrix]: https://numpy.org/doc/stable/reference/generated/numpy.matrix.html
