# Testes

Antes de tentar executar os testes, verifique se a pasta do exercício está configurada corretamente seguindo os passos de instalação, ou seja, `corepack yarn install` e a configuração do Editor SDK.

Execute os testes com:

```bash
$ corepack yarn test
```

## Testes ignorados

Nas suítes de teste, todos os testes, exceto o primeiro, são ignorados.

Assim que você conseguir fazer um teste passar, pode habilitar o próximo trocando `xit` por `it`.
Além disso, os testes podem ser agrupados com `xdescribe`.
Para habilitar o grupo, troque isso por `describe`.
Por fim, alguns exercícios podem ter testes opcionais, `it.skip`.
Remova o `.skip` para executar o teste opcional.
