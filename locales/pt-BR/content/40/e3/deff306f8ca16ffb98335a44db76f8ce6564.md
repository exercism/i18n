# Introdução

A maior parte dos dados em Factor vive em *sequências*. Arrays (`{ … }`),
vetores (`V{ … }`) e strings compartilham o mesmo
[protocolo][sequence-protocol] de [`sequences`][sequences].

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

As agregações (`sum`, `count`, `any?`, `all?`) e os predicados como
`empty?` e `member?` funcionam de forma uniforme em todos os tipos de
sequência. Dá para construir novas sequências sem mutação: `prefix`,
`suffix`, `append`, `unclip`, `unclip-last`.

`>array`, `>vector` e `>string` (em
[`arrays`][arrays] e nos vocabulários correspondentes) fazem a conversão
entre tipos de sequência quando você precisa recuperar um tipo concreto
específico a partir de uma operação genérica.

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
