# Sobre

Os tipos que implementam a interface [`IEnumerable<T>`][IEnumerable] são conhecidos como _enumerable_.
Todos os tipos de coleção nativos implementam essa interface.

É possível iterar sobre um tipo enumerable usando um laço `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Para implementar `IEnumerable<T>`, um tipo precisa implementar um único método: `IEnumerator<T> GetEnumerator()`.
Como vimos, um tipo enumerable delega a iteração de fato sobre uma coleção a um tipo `IEnumerator<T>`.
Essa interface tem uma propriedade e três métodos a implementar:

- `public T Current { get; }`: obtém o elemento atual.
- `public bool MoveNext ();`: avança para o próximo elemento, retornando `true` se a mudança para o próximo elemento tiver sido bem-sucedida, e `false` se não (não há mais elementos).
- `public void Reset ();`: redefine o enumerador para o estado inicial (antes do primeiro elemento).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
