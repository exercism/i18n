# Instruções

Dois violinistas estão ensaiando um dueto. Cada parte é um array que contém o número de notas de cada compasso, e as partes nem sempre têm o mesmo tamanho.

As quatro tarefas ficam na classe `DUET_PRACTICE`.

## 1. Quantos compassos eles tocam juntos?

Eles tocam juntos enquanto as duas partes ainda tiverem um compasso.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. Quantos compassos coincidem?

Conte os compassos em que as duas partes têm o mesmo número de notas. Só podem coincidir os compassos que ambas têm.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. Quem tem mais trabalho?

Conte os compassos em que a primeira parte tem mais notas que a segunda.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. Dê peso aos compassos

Os compassos mais adiante são mais difíceis, então cada compasso conta tanto quanto a sua posição: o primeiro conta uma vez, o segundo duas vezes, o terceiro três vezes. Multiplique as notas de cada compasso pelo seu número e some tudo.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

Isso dá 1×4 + 2×4 + 3×8. Os compassos são numerados a partir de um, não de zero.
