# Dicas

## 1. Crie o identificador de portas

- Você precisa definir uma [constante][constants] que deve conter o valor de símbolo especificado nas instruções.

## 2. Obtenha identificadores para outras portas

- É possível usar [slice][slice] em uma string para obter partes dela.
- As `Strings` têm um [método][upcase] para colocar as letras em maiúsculas.
- As `Strings` têm um [método][to_sym] para converter uma string em um símbolo.

## 3. Determine em qual terminal um navio deve atracar

- Um símbolo tem um [método][to_s] para converter um símbolo em uma string.
- É possível usar [slice][slice] em uma string para obter partes dela.
- Use o condicional [`if`][doc-if] para verificar se o navio está transportando `"OIL"` ou `"GAS"`.
