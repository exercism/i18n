# Introdução

Como todos os tipos de dados padrão do Clojure são imutáveis, a linguagem oferece *tipos de referência*, que permitem mutação controlada. Os mais simples e mais usados deles são os Atoms.

Os atoms são criados com a função `atom`, que recebe um valor inicial:

```clojure
(def players (atom ()))
```

O valor atual do atom é obtido com `deref` ou com o atalho `@`:

```clojure
@players
;;=> ()
```

O valor atual do atom `players` pode ser modificado com `swap!`, que atualiza o valor aplicando uma função:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

A função `reset!` substitui o valor de um atom sem levar em conta o valor atual:

```clojure
(reset! players ())
```
