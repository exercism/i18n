# Aprendizado

A linguagem de programação Pascal tem uma longa história, e boa parte da documentação online é voltada para iniciantes. A maioria desses tutoriais trata de programas de console, nos quais você imprime informações na tela e/ou lê a entrada do usuário. Por exemplo, um dos tutoriais para iniciantes mais comuns é um programa que imprime 'Hello World' na tela:

```pascal
program HelloWorld;
begin
  writeln('Hello World!');
end.
```

Quando executado, a partir de um console/terminal, esse programa imprime 'Hello World' na tela.

Aqui no Exercism, usamos testes automatizados para garantir que suas soluções estão corretas e, por isso, precisamos usar uma **unit** em vez de um **program**. A principal diferença é que você vai precisar retornar um valor de uma função em vez de imprimir algo no terminal:

```pascal
writeln('Hello World!');
```

virou

```pascal
result := 'Hello World!'
```

Os comandos write/writeln ainda são úteis para exibir informações ou obter uma representação textual da saída de um comando, de uma operação matemática etc.
