# Dicas

## Geral

- Em Python, `None` é usado com frequência como placeholder para representar a **ausência de um valor** de uma variável, de um objeto ou de um argumento.

## 1. Crie um novo mapa de assentos

Lembre-se: primeiro você precisa criar um dicionário vazio. Depois, preencha as _chaves_ do dicionário com quantos assentos estiverem disponíveis e defina os _valores_ delas como um **placeholder**, para indicar que estão disponíveis, mas ainda sem atribuição.

## 2. Organize as reservas

- Se não houver uma lista de convidados, você vai querer retornar um `new_seating_chart()` preenchido com placeholders. Um `default argument` para a sua função pode ajudar aqui. Se houver uma lista de convidados, você pode começar com um `new_seating_chart()` e depois fazer um laço de 1 até o número de convidados, atribuindo cada um deles a um assento na ordem.

## 3. Encontre todos os assentos disponíveis

- Você pode percorrer todos os pares (chave, valor) de um dicionário chamando `dict.items()`. Você pode verificar se uma variável ou um valor é None com um `if statement`: `if var is None` retorna True se o valor for `None`. Você pode adicionar coisas a uma `list` chamando `list.append()`

## 4. Capacidade atual de assentos

- Você pode percorrer todos os valores do objeto dicionário chamando `dict.values()`. Os assentos estão disponíveis quando o valor deles é `None`.

## 5. Acomode os convidados que estão esperando

- Você precisa descobrir o número atual de assentos vazios e verificar se ele é maior ou igual ao número de convidados que estão esperando. Se for possível acomodar os convidados, você vai precisar chamar `find_all_available_seats()` para obter uma lista dos números de assentos aos quais pode atribuir convidados. Lembre-se de que `range()` aceita qualquer tipo de número como argumento... **inclusive** o número retornado pela chamada de `len()` em uma lista. Lembre-se também de que usar `list[index_number]` retorna o **valor** que está no **número do índice** dentro dos colchetes.

## 6. Esvazie os assentos

- Dado o `dict` do mapa de assentos e uma `list` de números de assentos, você vai querer indicar que o assento agora está disponível para outro convidado, substituindo o nome dele por um placeholder. Percorrer a lista de números de assentos e procurar esses assentos no dicionário pode ajudar aqui.
