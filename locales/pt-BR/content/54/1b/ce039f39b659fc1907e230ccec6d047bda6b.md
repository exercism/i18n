# Sobre

Números de ponto flutuante são números com um ou mais dígitos depois do separador decimal.

```gleam
let float = 3.45
// -> 3.45
```

Os números de ponto flutuante também têm seu próprio conjunto de operadores.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

Também é possível adicionar sublinhados aos números de ponto flutuante para facilitar a leitura.

```gleam
1_000_000.0 // One million
```

Também é possível usar notação científica com números de ponto flutuante:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
