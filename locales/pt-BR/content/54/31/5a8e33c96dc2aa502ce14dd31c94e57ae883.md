# Sobre

Embora o modificador `readonly` impeça que o valor ou a referência em um campo sejam sobrescritos, ele não oferece nenhuma proteção para os membros de um tipo de referência.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Para garantir que todos os membros de um tipo de referência sejam protegidos, os campos podem ser marcados como `readonly` e as propriedades automáticas podem ser definidas sem um acessador `set`.

A Biblioteca de Classes Base (BCL) fornece algumas versões somente leitura de coleções quando há a necessidade de impedir que os membros de uma coleção sejam atualizados. Elas vêm na forma de wrappers:

- [`ReadOnlyDictionary<T>`][ReadOnlyDictionary]
- [`ReadOnlyCollection<T>`][ReadOnlyCollection]

[ReadOnlyDictionary]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlydictionary-2
[ReadOnlyCollection]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlycollection-1
