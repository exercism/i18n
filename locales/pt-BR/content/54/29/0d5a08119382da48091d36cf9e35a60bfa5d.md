# Introdução

## Operadores de comparação

Os operadores de comparação são parecidos com os de várias outras linguagens.

Para igualdade, os operadores são `==` (igual) e `!=` (diferente).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Os operadores de maior/menor também são os convencionais.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Ramificação com `if`

Esta é a forma completa de uma expressão `if`:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Os parênteses `()` em volta de cada condicional são obrigatórios.
- Uma condicional precisa avaliar para um Boolean `true` ou `false`.
  Kotlin não tem o conceito de "truthy" e "falsy" que existe em algumas linguagens.
- As chaves `{}` são opcionais, se houver apenas uma única expressão.
- Tanto `else if` quanto `else` são opcionais, e pode haver vários blocos `else if`.

A expressão `if` também pode ser usada para "escolher" um valor:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Alternativas?

Por uma escolha deliberada, Kotlin _não_ tem o operador ternário `? :` que existe em Java. Uma forma concisa de `if ... else` é preferida:

```Kotlin
return if (isOK) goodValue else badValue
```
