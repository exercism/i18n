# Introdução

Uma `String` em Julia é uma sequência imutável e finita de caracteres [Unicode](https://en.wikipedia.org/wiki/Unicode), na codificação [UTF-8](https://en.wikipedia.org/wiki/UTF-8).

Um literal `String` é uma sequência de caracteres entre aspas duplas:

```julia-repl
julia> "Christopher"
"Christopher"
```

Strings podem ser concatenadas com o operador `*`:

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
Se você tem curiosidade de saber por que Julia usa `*` em vez de `+` para concatenar strings, dê uma olhada no [Julia Manual](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation).
~~~~

Alguns caracteres especiais precisam ser escapados com uma barra invertida no início:

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Por padrão, o Julia inclui muitas funções úteis para trabalhar com strings:

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
