# Introdução

Um dicionário é uma coleção de elementos em que cada elemento é composto por uma chave e um valor, de modo que, se uma chave for passada a um método do dicionário, o valor associado a ela é retornado. Ele tem o mesmo papel que os mapas ou arrays associativos têm em outras linguagens.

Um dicionário pode ser criado assim:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Ou

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Repare que os tipos da chave e do valor fazem parte da definição do dicionário.

Depois de construído, é possível adicionar ou remover entradas de um dicionário usando seus métodos internos `Add` e `Remove`.

Para recuperar ou atualizar valores em um dicionário, você indexa o dicionário usando uma chave:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Você pode testar se um valor existe no dicionário com:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Iterar sobre um dicionário significa iterar sobre seus pares de chave/valor. Os dicionários também têm propriedades que permitem iterar sobre suas chaves ou seus valores.
