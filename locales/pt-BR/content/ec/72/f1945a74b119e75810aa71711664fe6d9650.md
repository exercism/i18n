# Sobre

**Delphi** é uma linguagem de programação baseada em Object Pascal para o desenvolvimento de software para desktop, mobile, web e console.
Delphi foi o [nome de código](https://edn.embarcadero.com/article/20396) de um produto ainda sem nome durante seu desenvolvimento inicial, antes de sua estreia em 1995.

O Delphi foi originalmente desenvolvido pela [Borland](https://en.wikipedia.org/wiki/Borland), liderado por Anders Heilsberg como uma ferramenta [RAD](https://en.wikipedia.org/wiki/Rapid_application_development) para Windows, sucessora do [Turbo Pascal](https://en.wikipedia.org/wiki/Turbo_Pascal).
O Delphi adicionou orientação a objetos completa à linguagem existente e, desde então, a linguagem cresceu e passou a dar suporte a muitos outros recursos modernos, incluindo:
  
- **Genéricos**  
- **Métodos anônimos (closures)**  
- **Construções dinâmicas (atributos)**  
- **Métodos abstratos**  
- **Tipos string integrados**  
- **Suporte nativo a COM**  
- **RTTI**  

Assim como seu antecessor Turbo Pascal, o Delphi tem no seu núcleo um compilador de código nativo.
O Turbo Pascal oferecia um equilíbrio ideal entre a velocidade de programação e a velocidade dos programas resultantes, a clareza da sintaxe e o poder de expressão. Esses princípios continuam válidos hoje no Delphi.
Versões mais recentes do Delphi conseguem compilar código nativo para diversas plataformas diferentes:

- **Windows (x86 e x64)**  
- **OS X (apenas 32 bits)**  
- **iOS (32 e 64 bits)**  
- **Android**  
- **Linux (apenas 64 bits)**  

Em 2006, a divisão de ferramentas de desenvolvimento da Borland foi transferida da Borland para uma subsidiária integral chamada [CodeGear](https://en.wikipedia.org/wiki/CodeGear), que foi vendida para a [Embarcadero Technologies](https://en.wikipedia.org/wiki/Embarcadero_Technologies) em 2008.
Em 2015, a Embarcadero foi comprada pela Idera, mas a marca Embarcadero foi mantida para a divisão de ferramentas de desenvolvimento.
