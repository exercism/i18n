# Introdução

## Igualdade

Common Lisp tem muitos predicados de igualdade diferentes.
Isso é diferente de outras linguagens de programação, que podem ter apenas um ou dois (talvez `==` e `===`, por exemplo).
Alguns desses predicados em Common Lisp são específicos de tipos, enquanto outros são genéricos.
São estes últimos que vamos abordar aqui.

Existem quatro predicados de igualdade genéricos, e eles diferem no quão restritivos são em relação ao que consideram "igual".
Eles são, em ordem do mais restritivo ao menos restritivo: `eq`, `eql`, `equal` e `equalp`.

Um conjunto rápido de definições (deixando de fora alguns detalhes) é o seguinte:

- `eq`: define a igualdade como significando que os dois objetos são idênticos.
  _por exemplo_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: define a igualdade como significando dois números com o mesmo tipo e valor, dois caracteres iguais, ou, para qualquer outra coisa, se forem `eq`.
  _por exemplo_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: define a igualdade da seguinte forma: duas listas são `equal` se cada elemento também for `equal`; duas strings são `equal` se cada elemento for `eql`; dois arrays são `equal` se forem `eq`; todo o resto é `equal` se for `eql`.
  _por exemplo_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: define a igualdade da seguinte forma: strings e caracteres são comparados sem diferenciar maiúsculas de minúsculas; números são comparados com alguma conversão de tipo; listas e arrays são `equalp` se todo elemento também for `equalp`; estruturas, se forem do mesmo tipo e todos os slots forem `equalp`; e tabelas hash, se suas chaves e valores forem `equalp`
  _por exemplo_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
