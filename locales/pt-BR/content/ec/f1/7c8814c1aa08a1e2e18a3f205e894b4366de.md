# Break, Continue

Ao usar uma estrutura de controle de laço ou de iteração, as palavras-chave `break` e `continue` podem ajudar a controlar o fluxo de um programa.
A palavra-chave `break` sai do contexto do laço e vai para o escopo externo, encerrando o laço.
A palavra-chave `continue` pula o restante da iteração atual e reinicia o contexto do laço no começo da próxima iteração.
Embora seja incomum, é possível passar um número junto com a palavra-chave para controlar de quantos contextos sair ou quantas iterações pular.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

No exemplo anterior, o `continue` é executado cinco (5) vezes, mas na sexta (6) iteração o `break` é executado, fazendo o código sair do laço.
