# Dicas

## 1. Recuperar uma carta do baralho

- Os índices de `Vector` começam em `1`.
- Você pode recuperar o `n`-ésimo valor de um vetor `v` com `v[n]`.

## 2. Trocar uma carta no baralho

- Os `Vector`s são mutáveis, você pode mudar o conteúdo deles a qualquer momento.
- O método recebe um [Pair](https://docs.julialang.org/en/v1/base/collections/#Base.Pair) como argumento.
- Você pode acessar os campos de um par `p` usando `p.first` e `p.second`.

## 3. Inserir uma carta no topo do baralho

- Existe um método [`push!`](https://docs.julialang.org/en/v1/base/collections/#Base.push!) em Base para adicionar um novo valor ao final de uma coleção.

## 4. Remover uma carta do baralho

- Existe um método [`deleteat!`](https://docs.julialang.org/en/v1/base/collections/#Base.deleteat!) em Base para excluir um elemento de um `Vector` em um determinado índice.

## 5. Remover a carta do topo do baralho

- Existe um método [`pop!`](https://docs.julialang.org/en/v1/base/collections/#Base.pop!) em Base para remover um elemento no final de uma coleção.

## 6. Inserir uma carta no fundo do baralho

- Existe um método [`pushfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.pushfirst!) em Base para inserir um novo valor no início de uma coleção.

## 7. Remover uma carta do fundo do baralho

- Existe um método [`popfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.popfirst!) em Base para remover um elemento no início de uma coleção.

## 8. Verificar o tamanho do baralho

- Existe um método [`length`](https://docs.julialang.org/en/v1/base/collections/#Base.length) em Base para obter o comprimento de uma coleção.
