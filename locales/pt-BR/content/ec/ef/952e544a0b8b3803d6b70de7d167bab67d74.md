# Apêndice das instruções

## Formato de saída

Informe a idade em centésimos de ano.

Por exemplo, 100 × 1.000.000.000 ÷ 31.557.600 ≈ 3.169, então alguém com 1.000.000.000 segundos de idade tem `3169` centésimos de ano terrestre.

## Registradores

| Registrador | Uso       | Tipo     | Descrição                     |
| ----------- | --------- | -------- | ----------------------------- |
| `$a0`       | entrada   | inteiro  | planeta (`0` = Mercúrio, `1` = Vênus, `2` = Terra, `3` = Marte, `4` = Júpiter, `5` = Saturno, `6` = Urano, `7` = Netuno) |
| `$a1`       | entrada   | inteiro  | segundos                      |
| `$v0`       | saída     | inteiro  | idade em centésimos de ano    |
| `$t0-9`     | temporário | qualquer | usado para armazenamento temporário |
