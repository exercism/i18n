# Sobre

## Tipos struct

Já vimos tipos struct; para recapitular, um `struct` é uma sequência de elementos nomeados chamados _campos_, e cada campo tem um nome e um tipo.
O nome de um campo precisa ser único dentro do struct.
Os `Structs` podem ser comparados com a _classe_ no paradigma de Programação Orientada a Objetos.

Você cria um novo struct usando as palavras-chave `type` e `struct`, e depois define explicitamente o nome e o tipo dos campos, como mostra o exemplo abaixo.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Tipos que não são struct

Também é possível definir tipos que não são struct e usá-los como alias para declarações de tipos embutidos.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Você também pode definir tipos que não são struct compostos de arrays e maps.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
