# Números de ponto flutuante

`INT` guarda apenas números inteiros, e dividir dois deles descarta o resto:

```sather
7 / 2        -- 3, not 3.5
```

Quando a fração importa, o tipo é `FLTD`, um número de **ponto flutuante**, que consegue guardar valores entre os inteiros.

## Como escrever um

Um literal de ponto flutuante tem um ponto decimal e um `d` no final.

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

O `d` não é opcional. `440.0` sozinho é outro tipo, de menor precisão; o `d` pede o tipo que esta trilha usa em todo lugar.

Escreva `2.0d`, não `2d`: também é preciso ter um ponto decimal.

## Aritmética

`+`, `-`, `*` e `/` funcionam, e agora o `/` mantém a fração:

```sather
7.0d / 2.0d      -- 3.5
```

Os dois lados têm que ser `FLTD`. Sather não mistura os dois tipos em silêncio, então `7 / 2.0d` é um erro, e não uma surpresa.

## A partir de um número inteiro

`.fltd` transforma um `INT` em um `FLTD`:

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)` é `3.5`. Repare onde fica a conversão: `(7 / 2).fltd` daria `3.0`, porque a divisão já teria descartado a metade. Converta **antes** de dividir, não depois.

## Qual é a distância?

`.abs` descarta o sinal de menos, e é assim que você pergunta qual a distância entre dois valores sem se importar com qual deles é maior:

```sather
(440.0d - 442.0d).abs      -- 2.0
```
