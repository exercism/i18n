# Introdução

## Mapas

Os mapas em Elixir são a estrutura de dados para armazenar informações em pares chave-valor. Em outras linguagens, eles também podem ser conhecidos como arrays associativos (PHP), hashes (Perl 5, Raku) ou dicionários (Python).

As chaves e os valores podem ser de qualquer tipo de dados, mas se a chave for um átomo podemos usar uma sintaxe abreviada. Os mapas não garantem a ordem das suas entradas quando acessadas ou retornadas.

### Formas literais

Um mapa vazio é simplesmente declarado com `%{}`. Se quisermos adicionar itens a um mapa literal, podemos usar duas formas:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Embora não haja um formato canônico, escolha uma forma consistente de representar os pares chave-valor literais.

### Funções do módulo Map

O Elixir oferece muitas funções para trabalhar com mapas no _módulo Map_. Algumas funções do _módulo Map_ exigem que uma função _anônima_ seja passada para ajudar na transformação do mapa.

## Atributos de módulo como constantes

Em Elixir, podemos definir atributos de módulo que podem ser usados como constantes nas nossas funções.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Quando usados para definir constantes de módulo, os atributos podem ser qualquer expressão que possa ser avaliada em tempo de compilação. Depois da compilação, os atributos de módulo não são acessíveis, já que são expandidos durante a compilação, de forma semelhante às macros definidas em linguagens como C.
