# Representações

O [representer do Python][representer] processa e normaliza as soluções dos estudantes para uma forma mais "genérica":

- O código é convertido em uma AST usando o [módulo AST do Python][python-ast].
- A árvore AST final é convertida em uma string sem espaços em branco nem indentação e gravada em `representation.txt`.
- Para fins de diagnóstico, `representation.out` inclui a AST inicial, a AST editada e uma representação do código com as normalizações aplicadas.

- Remoções:
    - type hints (_incluindo type hints em dataclasses, veja Normalizações abaixo_)
    - instruções `print()`
    - blocos `if __name__ == __main__`
    -  comentários
    -  docstrings

-  Substituições:
    - nomes definidos pelo usuário são substituídos por placeholders (_incluindo nomes de funções, parâmetros e variáveis em lambdas_)

- Normalizações:
  - as aspas `'` são trocadas por `"` (_aspas duplas_), a menos que escapes sejam necessários, caso em que permanecem inalteradas.
  - literais numéricos têm os underscores removidos e a notação científica é calculada por posição:
    - **66_777_888_433** --> 66777888433
    - **1_999_878_473.66** --> 1999878473.66
    - **77_555_998_125.445_779** --> 77555998125.44579
    - **44_573_123.445_312+123_674.889_12j** --> 44573123.445312 + 123674.88912j
    - **1e6** --> 1000000.0 #1000000
    -  **1e2+.23** --> 100.0 + 0.23 #100.23
    - **1e2+1_23e0+4.4e-1** --> 100.0 + 123.0 + 0.44 #223.44
    - **7e6+7e5+5e4+9.98e2+4.45_779e-1** -->7000000.0 + 700000.0 + 50000.0 + 998.0 + 0.445779 #7750998.445779
    - **(7e6+7e5+5e4+9.98e1+4.457_79e-1)+(1e2+1.23e1+4.444_23e-1)*1*j** --> (7000000.0 + 700000.0 + 50000.0 + 99.8 + 0.445779 + (100.0 + 12.3 + 0.444423) * 1j)  #7750100.245779+112.744423j
  - funções e classes que ficam com corpos vazios depois da remoção das docstrings recebem `pass` no corpo.
  - dataclasses que têm membros de dados com type hint mas sem valor atribuído recebem `None` como valor nesses membros. Veja a docstring que começa na linha 153 de normalizer.py para mais detalhes.
