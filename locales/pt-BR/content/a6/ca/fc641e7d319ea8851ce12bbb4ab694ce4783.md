# Introdução

Os símbolos em Common Lisp são valores especiais que podem apontar para outros valores ou, no caso das _keywords_, para si mesmos.
Quando o Lisp avalia os símbolos, eles são substituídos pelos valores para os quais apontam:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

Note que as _keywords_ são indicadas por dois-pontos no início (`:`).

A citação, ou seja, adicionar `'` antes de uma S-expression, diz ao Lisp para não avaliar essa expressão.
Ao citar `'foo` no nosso exemplo com `defun`, evitamos que o Lisp tentasse buscar (e não encontrasse) aquilo para o que `FOO` deveria apontar, retornando em vez disso o próprio valor `FOO`.
Se `FOO` não tiver sido definido em nenhum lugar do nosso programa:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

Por enquanto, você pode encarar isso apenas como uma forma de retornar símbolos de uma função, mas vamos voltar à citação e explorar melhor suas implicações em exercícios de conceito futuros.
