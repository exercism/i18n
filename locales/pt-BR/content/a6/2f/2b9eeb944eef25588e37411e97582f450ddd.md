# Sobre

O Gleam pode rodar na máquina virtual do Erlang (BEAM) ou em runtimes JavaScript. Existem muitas outras linguagens que usam esses runtimes, e muitas vezes é útil poder chamar código escrito nessas linguagens a partir do Gleam.

O recurso de _funções externas_ do Gleam permite importar funções de outras linguagens para o Gleam e chamá-las sem nenhuma sobrecarga de runtime.

Se o seu projeto Gleam roda na máquina virtual do Erlang e você quer chamar a função `reverse` do módulo `lists` do Erlang, você pode fazer isso adicionando o atributo `@external` a um cabeçalho de função Gleam, assim:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Aí você pode chamá-la como uma função Gleam normal:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Se você tentar compilar esse código para runtimes JavaScript, vai dar erro com uma mensagem de falha, porque não existe implementação para JavaScript. Você pode especificar outra implementação para runtimes JavaScript, assim:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Também é possível escrever uma implementação em Gleam que será usada quando não houver implementação externa para o alvo de compilação atual:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
