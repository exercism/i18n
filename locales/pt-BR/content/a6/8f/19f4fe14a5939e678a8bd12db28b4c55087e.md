## 1. Documente o propósito das ferramentas de formulário

- O atributo de módulo `@moduledoc` pode ser usado para escrever a documentação de um módulo.

## 2. Documente o preenchimento de campos com valores em branco

- O atributo de módulo `@doc` pode ser usado para escrever a documentação de uma função.
- O atributo de módulo `@spec` pode ser usado para escrever um typespec de uma função.
- Coloque os atributos `@doc` e `@spec` logo antes da primeira cláusula da função que esses atributos descrevem.
- Consulte a [documentação de typespecs][typespecs-types] para ver a lista de todos os tipos disponíveis.
- O tipo correto para strings é [definido no módulo `String`][string-t].

## 3. Documente a divisão de valores em listas de letras maiúsculas

- O atributo de módulo `@doc` pode ser usado para escrever a documentação de uma função.
- O atributo de módulo `@spec` pode ser usado para escrever um typespec de uma função.
- Coloque os atributos `@doc` e `@spec` logo antes da primeira cláusula da função que esses atributos descrevem.
- Consulte a [documentação de typespecs][typespecs-types] para ver a lista de todos os tipos disponíveis.
- O tipo correto para strings é [definido no módulo `String`][string-t].
- Uma lista é um tipo parametrizado.

## 4. Documente a verificação se um valor cabe em um campo com comprimento máximo

- O atributo de módulo `@doc` pode ser usado para escrever a documentação de uma função.
- O atributo de módulo `@spec` pode ser usado para escrever um typespec de uma função.
- Coloque os atributos `@doc` e `@spec` logo antes da primeira cláusula da função que esses atributos descrevem.
- Consulte a [documentação de typespecs][typespecs-types] para ver a lista de todos os tipos disponíveis.
- O tipo correto para strings é [definido no módulo `String`][string-t].
- Valores literais podem ser usados em um typespec.
- O pipe `|` pode ser usado para representar uma união de tipos.

## 5. Documente diferentes formatos de endereço

- O atributo de módulo `@type` pode ser usado para definir um tipo público personalizado.
- Os tipos podem ser compostos, por exemplo, ao especificar um tipo que é um mapa, você também pode especificar os tipos dos valores sob chaves específicas.
- [O operador de tipo `::`][type-operator] também pode ser usado para prefixar um tipo com um nome de variável.
- Tipos personalizados podem ser usados para definir outros tipos personalizados.

## 6. Documente a formatação do endereço

- O atributo de módulo `@doc` pode ser usado para escrever a documentação de uma função.
- O atributo de módulo `@spec` pode ser usado para escrever um typespec de uma função.
- Coloque os atributos `@doc` e `@spec` logo antes da primeira cláusula da função que esses atributos descrevem.

- Tipos personalizados podem ser usados em um typespec.
