# Dicas

Para todas essas tarefas, você vai precisar do comando `print`:
```awk
{print "something", "something else"}
```

## 1. Liste os nomes de usuário

* Use [a variável `FS`][var-fs] para definir o separador de campos.

## 2. Imprima os números das linhas

* Use a [variável embutida `NR`][var-nr] para obter o número da linha.

## 3. Imprima os registros com diretórios home inválidos.

* O diretório home é o 6º campo.
* Use a função `startsWith` fornecida.
* Use [operadores Boolean][boolean-ops]: `&&`, `||`, `!`.

## 4. Imprima o número de usuários válidos que usam bash

* O shell de login é o último campo; você pode usar [a variável `NF`][var-nf].
