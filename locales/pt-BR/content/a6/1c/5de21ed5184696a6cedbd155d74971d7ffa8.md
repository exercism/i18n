# Introdução

## Campos rotulados

Quando uma variante de um tipo personalizado contém dados, ela é chamada de registro, e cada valor contido fica em um _campo_.

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

Para facilitar a leitura, o Gleam permite rotular os campos com um nome.

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

Os rótulos podem ser usados para passar os argumentos em qualquer ordem ao construtor de um registro.

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

Quando um tipo personalizado tem apenas uma variante, a sintaxe de acesso `.label` pode ser usada para obter os campos de um registro.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

A sintaxe de atualização de registro pode ser usada quando um tipo personalizado tem uma única variante, para criar um novo registro a partir de um existente, mas com alguns dos campos substituídos por novos valores.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

Os rótulos também podem ser usados no casamento de padrões para extrair valores de registros.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h >. 20.0 -> True
    _ -> False
  }
}
```

Se quisermos casar apenas com alguns dos campos, podemos usar o operador de espalhamento `..` para ignorar os campos restantes.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
