# Introdução

## Verdadeiro e falso

Em Common Lisp, todos os valores são "verdadeiro", exceto `()`, que é "falso".
Existem dois símbolos constantes especiais, `t` e `nil`, cujos valores são verdadeiro e falso, respectivamente.

## Condicionais

Common Lisp oferece várias expressões condicionais diferentes, sendo a principal diferença o número de bifurcações que elas suportam.

- `when` e `unless` permitem apenas uma bifurcação:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

A parte depois da expressão de teste pode conter mais de uma expressão.

- `if` oferece a clássica construção if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Repare que tanto a cláusula then quanto a cláusula else podem conter apenas uma única expressão.

- `cond` oferece uma forma de ter várias bifurcações sem aninhar expressões `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Repare que não há limite para o número de expressões depois da expressão de teste.

- `case` oferece uma construção clássica no estilo 'switch': ela verifica um único valor contra várias bifurcações:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Repare que, assim como em `cond`, não há limite para o número de expressões depois da expressão de teste.
