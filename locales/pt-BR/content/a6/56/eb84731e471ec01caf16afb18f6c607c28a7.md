# Anexo às instruções

## Implementação

Foi adicionado um teste opcional que verifica se as possíveis letras podem ser qualquer caractere unicode, e não apenas caracteres alfabéticos ASCII.
Ele não fica acessível pelo editor web, mas é executado por padrão quando você roda os testes localmente.

Para desativar esses testes, ao chamar o comando de teste (`crystal spec`), adicione a seguinte flag: `--tag "~optional"`
