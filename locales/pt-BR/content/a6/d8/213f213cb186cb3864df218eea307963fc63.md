# Introdução

Uma propriedade em Haxe é um membro de uma classe que fornece acesso a dados dentro dessa classe. Quem chama pode definir ou recuperar (get) os dados. Elas compreendem um acessador de escrita e/ou um acessador de leitura.

As propriedades têm modificadores de acesso (public, private etc.) da mesma forma que outros membros da classe, mas o acessador de escrita pode ter um nível de acesso independente do acessador de leitura (get) e vice-versa. Uma propriedade não precisa ter os dois acessadores, pode ter apenas um (get ou set).

O acesso de leitura e o acesso de escrita se refletem diretamente na sintaxe, como mostra o exemplo a seguir:

```haxe
class Main {
  public var x(default, null):Int;
}
```

Tanto `default` quanto `null` são **identificadores de acesso** especiais. Os identificadores de acesso definem o comportamento para quando o campo é lido (primeiro identificador) e para quando o campo é escrito (segundo identificador). Os valores aceitos são:

- `default`: Permite acesso normal ao campo se o campo for public.
- `null`: Permite acesso apenas de dentro da classe que o define.
- `get/set`: O acesso é gerado como uma chamada a um método acessador (`get_x()`).
- `dynamic`: O mesmo que `get/set`, mas a existência de um método acessador não pode ser verificada.
- `never`: Não permite acesso algum.

Veja um exemplo completo:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
