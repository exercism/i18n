# Instruções

Neste exercício, você vai implementar a lógica da missão de um novo jogo de RPG que um amigo está desenvolvendo.
A personagem principal do jogo é Annalyn, uma garota corajosa com um cachorro de estimação feroz e leal.
Infelizmente, o desastre acontece: seu melhor amigo foi sequestrado enquanto procurava frutas na floresta.
Annalyn vai tentar encontrar e libertar seu melhor amigo, podendo levar o cachorro com ela nessa missão.

Depois de passar um tempo seguindo o rastro de seu melhor amigo, ela encontra o acampamento onde ele está preso.
Acontece que há dois sequestradores: um cavaleiro poderoso e um arqueiro astuto.

Depois de encontrar os sequestradores, Annalyn considera quais das seguintes ações ela pode realizar:

- _Ataque Rápido_: um ataque rápido pode ser feito se o **cavaleiro** estiver **_dormindo_**, já que ele demora para vestir a armadura e ficará vulnerável.
- _Espionar_: o grupo pode ser espionado se **pelo menos um** deles estiver **_acordado_**. Caso contrário, espionar é perda de tempo.
- _Sinalizar para o prisioneiro_: o prisioneiro pode receber um sinal usando sons de pássaros se o **prisioneiro** estiver **_acordado_** e o **arqueiro** estiver **_dormindo_**, já que arqueiros são treinados em sinais com pássaros e poderiam interceptar a mensagem.
- _Libertar o prisioneiro_: Annalyn pode tentar entrar escondida no acampamento para libertar o prisioneiro.
  É uma coisa arriscada e só pode dar certo de duas maneiras:
  - Se Annalyn estiver com o cachorro, ela pode resgatar o prisioneiro se o **arqueiro** estiver **_dormindo_**.
    O cavaleiro tem medo do cachorro e o arqueiro não terá tempo de se preparar antes que Annalyn e o prisioneiro escapem.
  - Se Annalyn não estiver com o cachorro, ela e o prisioneiro precisam ser muito furtivos!
    Annalyn pode libertar o prisioneiro se o **prisioneiro** estiver **_acordado_** e o **cavaleiro** e o **arqueiro** estiverem ambos **_dormindo_**, mas se o **prisioneiro** estiver **_dormindo_** ele não pode ser resgatado: o prisioneiro se assustaria com a aparição repentina de Annalyn e acordaria o cavaleiro e o arqueiro.

Você tem quatro tarefas: implementar a lógica para determinar se as ações acima estão disponíveis com base no estado dos três personagens encontrados na floresta e se o cachorro de estimação de Annalyn está presente ou não.

## 1. Verifique se a ação 'Ataque Rápido' é possível

Implemente uma função chamada `canExecuteFastAttack` que recebe um valor Boolean que indica se o cavaleiro está acordado.
Essa função retorna `true` se a ação 'Ataque Rápido' estiver disponível com base no estado do personagem.
Caso contrário, retorna `false`:

```javascript
const knightIsAwake = true;
canExecuteFastAttack(knightIsAwake);
// => false
```

## 2. Verifique se a ação 'Espionar' é possível

Implemente uma função chamada `canSpy` que recebe três valores Boolean, indicando se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados.
A função retorna `true` se a ação 'Espionar' estiver disponível com base no estado dos personagens.
Caso contrário, retorna `false`:

```javascript
const knightIsAwake = false;
const archerIsAwake = true;
const prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Verifique se a ação 'Sinalizar para o prisioneiro' é possível

Implemente uma função chamada `canSignalPrisoner` que recebe dois valores Boolean, indicando se o arqueiro e o prisioneiro, respectivamente, estão acordados.
A função retorna `true` se a ação 'Sinalizar para o prisioneiro' estiver disponível com base no estado dos personagens.
Caso contrário, retorna `false`:

```javascript
const archerIsAwake = false;
const prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Verifique se a ação 'Libertar o prisioneiro' é possível

Implemente uma função chamada `canFreePrisoner` que recebe quatro valores Boolean.
Os três primeiros parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados.
O último parâmetro indica se o cachorro de estimação de Annalyn está presente.
A função retorna `true` se a ação 'Libertar o prisioneiro' estiver disponível com base no estado dos personagens e na presença do cachorro de estimação de Annalyn.
Caso contrário, ela retorna `false`:

```javascript
const knightIsAwake = false;
const archerIsAwake = true;
const prisonerIsAwake = false;
const petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
