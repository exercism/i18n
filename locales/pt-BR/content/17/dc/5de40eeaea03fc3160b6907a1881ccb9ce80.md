# Instruções

Neste exercício, você trabalha em uma pizzaria que entrega para os clientes.

Você oferece três tipos de pizza:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

Os clientes também podem escolher duas opções adicionais por uma pequena taxa extra:

1. Molho extra: \$1
1. Coberturas extras: \$2

Quando os clientes fazem um pedido, uma taxa adicional é cobrada se pedirem apenas uma ou duas pizzas:

- 1 pizza: \$3
- 2 pizzas: \$2

Você tem três tarefas, e cada uma delas vai trabalhar com pizzas e seus preços.

## 1. Defina os tipos de pizza e as opções

Defina o tipo personalizado `Pizza` para representar os diferentes tipos de pizza e de opções:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

`ExtraSauce` e `ExtraToppings` devem envolver o tipo `Pizza`.

## 2. Calcule o preço da pizza

Implemente a função `pizza_price` para calcular o preço de uma pizza:

```gleam
pizza_price(Caprese)
// -> 9
```

## 3. Calcule o preço de um pedido

Implemente a função `order_price` para calcular o preço de um pedido de pizza:

```gleam
order_price([Margherita, Formaggio])
// -> 19
```
