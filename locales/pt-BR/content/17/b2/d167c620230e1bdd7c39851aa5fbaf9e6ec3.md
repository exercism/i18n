# Instruções

Você é o sinaleiro de uma embarcação de patrulha costeira. A bolsa de hoje
precisa de cinco palavrinhas prontas antes de o turno da manhã começar.

## 1. Represente um valor em sua forma de origem

O diário de bordo registra cada observação na *forma de origem do Factor*,
o mesmo texto que o analisador vai ler de volta. Defina `quote-value` para
transformar qualquer valor na string correspondente em sua forma de origem.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. Remova o enquadramento da bandeira

As bandeiras de sinal que chegam vêm emolduradas com um caractere marcador
em cada ponta. Defina `flag-body` para retornar tudo o que está *entre* os
dois marcadores: descarte o primeiro caractere e descarte o último caractere.

Retorne uma fatia (uma visão) em vez de copiar.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. Divida uma bandeira

Cada bandeira carrega um pequeno código de prefixo seguido da carga útil.
Defina `split-flag` para receber uma bandeira e um comprimento de cabeçalho, e
retornar *tanto* a fatia do cabeçalho quanto a fatia do corpo.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. Triangule a partir de duas leituras

Duas leituras de sinal consecutivas dão três medidas derivadas:
a *diferença* `a - b`, o *ponto médio* `(a + b) / 2`
e a *razão* `a / b`. Cada medida usa as duas leituras.

Defina `triangulate` para retornar as três a partir de um par de leituras.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. Resuma três leituras

Três leituras consecutivas são resumidas em sua **soma**,
seu **produto** e seu **máximo**. Cada estatística usa as três
leituras.

Defina `triangle-stats` para retornar as três.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
