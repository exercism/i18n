# é preciso otimizar o método auxiliar

O método auxiliar `%{method.name}` não é o ideal. Muito provavelmente, ele pode ser igual à solução de `resistor-color`.

⚡ **Aviso:** não podemos garantir que o analisador funcionou corretamente neste ponto. Confira se ele cometeu algum erro e, caso tenha cometido, abra uma issue [aqui](https://github.com/exercism/javascript-analyzer/issues/new?assignees=&labels=%%3Abug%%3A+bug&template=incorrect-analysis.md&title=Incorrect+Analysis%%3A+) para que o analisador possa ser atualizado.
