# Instruções

Sua empresa foi contratada para gerar registros CSV a partir da entrada do usuário.

Precisamos de um construtor de registro CSV conforme o padrão definido na [RFC 4180](https://tools.ietf.org/html/rfc4180).

Embora exista uma especificação formal, sua empresa só precisa implementar a seguinte funcionalidade:
- criar um novo construtor de registro
- adicionar um campo individual ao registro
- serializar o registro com escape básico

Escape básico significa:

- Campos que contêm quebras de linha, aspas duplas e vírgulas devem ser envolvidos em aspas duplas.

- Se aspas duplas forem usadas para envolver campos, uma aspa dupla que apareça dentro de um campo deve ser escapada precedendo-a com outra aspa dupla.


## 1. Crie um novo construtor

Você vai precisar implementar o método `new` para criar um novo construtor.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. Adicione campos individuais ao registro

Você vai precisar implementar o método `add` para acrescentar campos ao seu construtor de registro.
`add` recebe fatias de string imutáveis, `&str`, como argumento.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. Serialize o registro com escape básico

Você vai precisar implementar o método `build`.
`build` consome o construtor e retorna um registro CSV.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
