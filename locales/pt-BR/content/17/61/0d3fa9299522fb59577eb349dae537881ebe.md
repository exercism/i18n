# Instruções específicas do SQLite

As colunas **list_one** e **list_two** contêm uma lista de inteiros codificada em JSON.

Exemplo:

```json
[1, 2, 3]
```

## Esquema da tabela

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
