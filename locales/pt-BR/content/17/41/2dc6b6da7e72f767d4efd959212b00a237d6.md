# Instruções

Você está trabalhando na implementação de um sistema de monitoramento de saúde. Como parte disso, você precisa acompanhar as estatísticas de saúde dos usuários.

Você vai começar com algumas funções esboçadas em um bloco `impl`, além da seguinte definição de struct:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

Seu objetivo é implementar os métodos esboçados do `User` `struct` definido no bloco `impl`.

Por exemplo, o método `new` deve retornar uma instância do struct `User` com os valores de nome, idade e peso especificados.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

O método `weight` deve retornar o peso do `User`.

```rust
bob.weight();
// Returns: 155.2
```

O método `set_age` deve definir a idade do `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

Divirta-se!
