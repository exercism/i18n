# Apêndice das instruções

## Implementação

É permitido usar recursos nativos da linguagem para construir e desconstruir arrays por meio de desestruturação, assim como o literal de array `[]`, mas nenhuma função de `Array.prototype` deve ser usada.

Para conseguir testar sua solução, certifique-se de que `forEach` esteja implementado.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
