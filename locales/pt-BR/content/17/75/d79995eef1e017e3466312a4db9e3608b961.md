# Introdução

A recursão é uma forma de repetir código em uma função fazendo com que a própria função chame a si mesma.
Ela pode ser vista como outra forma de fazer laços ou iterar. 
Assim como nos laços, uma expressão Boolean ou um teste `True`/`False` é usado para determinar quando parar a execução recursiva.
_Diferente_ dos laços, a recursão sem terminação em Python não pode rodar infinitamente.
Os valores usados em cada chamada de função ficam no próprio [frame][stack-frame] da [pilha do intérprete][what-is-the-call-stack] do Python.
Se o número total de chamadas de função ocupar mais espaço do que a pilha tem disponível, isso vai resultar em um erro.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

Isso vai imprimir

```
The step is 1
The step is 2
After recursion
```

Pode haver situações que ficam mais legíveis e/ou mais fáceis de entender quando expressas com recursão do que com laços.
