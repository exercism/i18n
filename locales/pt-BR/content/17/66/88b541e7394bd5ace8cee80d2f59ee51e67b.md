# Sobre

Os métodos podem ter um parâmetro varargs, que permite que quem chama especifique zero ou mais argumentos como se fossem parâmetros comuns. O método recebe esses argumentos em um único array.

Para transformar um parâmetro em um parâmetro varargs, adicione a [palavra-chave `params`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params) à declaração do parâmetro:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
