# Instruções

Contrataram você como Especialista em Expressões Regulares em uma empresa que está desenvolvendo um Chatbot.

Ela está em uma fase muito básica de desenvolvimento.
Sua missão é usar Expressões Regulares para melhorar a capacidade do Chatbot de entender e gerar linguagem natural.

## 1. Verifique se o comando é válido

Além de inteligente, o Chatbot também é um assistente leal.
Para perguntar algo ao Chatbot, o usuário deve dizer a palavra "**Chatbot**" na primeira posição do comando.
Não importa se a palavra-chave está em MAIÚSCULAS ou minúsculas.
O importante é a posição da palavra.

Implemente a função `is_valid_command` que ajuda o Chatbot a reconhecer quando o usuário está dando um comando.

```jq
"Chatbot, play a song from the 80's." | is_valid_command
# => true
"Hey Chatbot, where is the closest pharmacy?" | is_valid_command
# => false
"CHATBOT, do you have a solution for this challenge?" | is_valid_command
# => true
```

## 2. Remova os emojis criptografados

O Chatbot tem dificuldade para entender como as pessoas usam emojis para expressar suas emoções.
Quando o Chatbot recebe mensagens de usuários, cada emoji é representado pela string "emoji" seguida de um _número de id_.

Implemente o método `remove_emoji`, que recebe uma string e remove todos os emojis da mensagem.

Linhas que não contêm emojis devem ser retornadas sem modificações.
Basta remover a string do emoji.
Não ajuste os espaços em branco.

```jq
"I love playing videogames emoji3465 it's one of my hobbies" | remove_emoji
# => "I love playing videogames  it's one of my hobbies"
```

## 3. Verifique se o número de telefone é válido

Em algum momento da interação com o Chatbot, o usuário vai fornecer um número de telefone.
O Chatbot só consegue ligar para um número com um formato específico.

Implemente a função `check_phone_number`.

Se o número for válido, o Chatbot responde com uma mensagem agradecendo ao usuário e confirmando o número.
Se o número for inválido, o Chatbot informa ao usuário que o número de telefone não é válido.

O formato esperado é `(+NN) NNN-NNN-NNN`, em que N é um dígito.

```jq
"chatbot my phone number is (+34) 659-771-594" | check_phone_number
# => "Thanks! Your phone number is OK."
"chatbot, call me at 659-771-594" | check_phone_number
# => "Oops, it seems like I can't reach out to 659-771-594."
```

## 4. Obtenha o link do site

O Chatbot é um software muito curioso.
Apesar de conseguir pesquisar na internet sobre um assunto específico, ele gosta de perguntar aos usuários sobre sites legais para visitar e encontrar informações relevantes.

Exemplo de conversa:

> **Chatbot**: Ei, Usuário, eu gostaria de aprender a programar em JavaScript. Você conhece algum site legal onde eu poderia aprender?
>
> **Usuário**: Eu aprendi muito no exercism.org, tem muita coisa boa lá.

Implemente a função `get_domains`, que retorna um array de domínios de sites.

```jq
"I learned a lot from exercism.org and google.com" | get_domains
# => ["exercism.org", "google.com"]
```

## 5. Cumprimente o usuário

Um Chatbot educado fala com os usuários pelo nome.
Quando um usuário se apresenta, nosso Chatbot detecta o nome e responde com uma saudação amigável.

Escreva a função `nice_to_meet_you`.

Se a string de entrada contiver "My name is Someone.", capture o nome e retorne a string "Nice to meet you, Someone.".

```jq
"My name is Jean-Luc" | nice_to_meet_you
# => "Nice to meet you, Jean-Luc"
```

## 6. Análise de CSV bem simples

Cedendo à mania de adicionar cada vez mais funcionalidades, vamos adicionar uma função de análise de CSV ao Chatbot.

Implemente a função `parse_csv`, que recebe uma string e retorna um array com os campos resultantes.
O separador de campos deve ser "vírgula mais espaço em branco opcional".

Não vamos nos preocupar com os casos limite do formato CSV (como campos que contêm vírgulas).

```jq
"first, second,third,   fourth" | parse_csv
# => ["first", "second", "third", "fourth"]
```
