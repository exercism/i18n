# Aprendizado

O Exercism oferece exercícios e feedback, mas pode ser difícil dar os primeiros passos para quem está aprendendo Pascal pela primeira vez. Estes recursos podem ajudar você a começar:

* O [Pascal Tutorial](https://www.tutorialspoint.com/pascal/index.htm) parece um bom lugar para se familiarizar com Pascal se você não tem nenhuma experiência com essa linguagem. Você não precisa do Delphi para completar os exercícios abordados neste tutorial. Pode ser um bom lugar para praticar um pouco antes de encarar os exercícios daqui, que exigem o Delphi para serem concluídos.
* O [Pascal-Programming.info](http://www.pascal-programming.info/index.php) também parece ter um bom tutorial para quem está começando na linguagem.
* Existem muitas outras fontes online para aprender Pascal, tantas que não dá para listar todas aqui.
