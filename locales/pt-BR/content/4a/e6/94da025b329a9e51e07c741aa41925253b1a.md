# Instruções

Se você quer construir algo com um Raspberry Pi, provavelmente vai usar _resistores_.
Para este exercício, você precisa saber duas coisas sobre eles:

- Cada resistor tem um valor de resistência.
- Resistores são pequenos, tão pequenos que, se você imprimisse o valor da resistência neles, seria difícil de ler.

Para contornar esse problema, os fabricantes imprimem faixas com código de cores nos resistores para indicar seus valores de resistência.
Cada faixa tem uma posição e um valor numérico.

As duas primeiras faixas de um resistor seguem um esquema de codificação simples: cada cor corresponde a um único número.
Por exemplo, se imprimissem uma faixa brown (valor 1) seguida de uma faixa green (valor 5), isso corresponderia ao número 15.

Neste exercício, você vai criar um programa útil para não precisar memorizar os valores das faixas.
O programa vai receber nomes de cores como entrada e retornar um número de dois dígitos, mesmo que a entrada tenha mais de duas cores!

As cores das faixas são codificadas assim:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

A partir do exemplo acima:
brown-green deve retornar 15, e
brown-green-violet também deve retornar 15, ignorando a terceira cor.
