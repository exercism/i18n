# Dicas

## Geral

- Leia sobre o módulo `Enum` no [guia oficial de primeiros passos][getting-started-enum] ou no [elixirschool.com][elixir-school-enum].
- Dê uma olhada na documentação para ver a [lista completa de funções do módulo `Enum`][enum-functions].

## 1. Ordene os itens por preço

- Existe uma [função integrada][enum-sort-by] para ordenar enumeráveis usando uma função de ordenação.

## 2. Encontre todos os itens com preços ausentes

- Existe uma [função integrada][enum-filter] para filtrar enumeráveis.

## 3. Atualize os nomes dos itens

- Existe uma [função integrada][enum-map] para transformar cada elemento de um enumerável.
- Existe uma [função integrada][string-replace] que substitui todas as ocorrências de uma string por outra.

## 4. Incremente a quantidade do item

- Os mapas implementam o protocolo enumerável.
- As funções do `Enum` convertem mapas em uma lista de tuplas `{key, value}`.
- Existem duas funções diferentes que podem transformar uma lista de tuplas `{key, value}` de volta em um mapa usando uma função de transformação. [Uma delas sempre retorna um novo mapa][map-new], enquanto [a outra permite escolher um coletável][enum-into].

## 5. Calcule a quantidade total do item

- Os mapas implementam o protocolo enumerável.
- As funções do `Enum` convertem mapas em uma lista de tuplas `{key, value}`.
- Existe uma [função integrada][enum-reduce] para reduzir um enumerável a um único valor.
