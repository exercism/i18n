# Introdução

Em Kotlin, as funções são cidadãs de primeira classe.
Isso significa que elas podem ser guardadas em variáveis, passadas como argumentos e até retornadas por outras funções.
Por exemplo, atribuindo uma função à variável `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Uma função também pode retornar outra função:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

Depois de atribuída, a função pode ser chamada através da variável como se fosse apenas mais uma função:
```kotlin
addOne(3)
// => 4
```

## Declarando tipos de função

É possível declarar o tipo de uma variável ou de um parâmetro usando a sintaxe `(parameter types) -> return type`.
Por exemplo, declarando uma variável:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

E para um parâmetro de função:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Expressões lambda

Uma expressão lambda é uma forma mais curta de definir uma função.
Elas são escritas na forma `{ parameters -> body }`.
A expressão retorna o último valor da última instrução do corpo.
Por exemplo:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Kotlin consegue inferir os tipos quando há informação suficiente.
Por exemplo, os exemplos acima também podem ser escritos assim:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` para lambdas de um único parâmetro

Quando a expressão tem apenas um parâmetro, o parâmetro pode ser omitido.
Kotlin então disponibiliza no corpo um parâmetro chamado `it`.
Por exemplo:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Passando lambdas ao final

Quando o último argumento de uma função é uma lambda, a expressão lambda é escrita diretamente _depois_ dos parênteses.
Por exemplo:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
