# Introdução

## Uniões discriminadas

O tipo união discriminada representa um número fixo de casos nomeados. Cada valor de uma união discriminada corresponde a exatamente um dos casos nomeados.

Uma união discriminada é definida com a palavra-chave `type`, com os casos separados por caracteres de barra vertical (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Cada caso de uma união discriminada pode ou não ter dados associados, e casos diferentes podem ter tipos de dados diferentes. Se nenhum dos casos tiver dados associados, a união discriminada é parecida com o que outras linguagens costumam chamar de _enumeração_ (ou _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Você cria um valor para um caso específico referindo-se ao seu nome (por exemplo, `Success`). Como os nomes dos casos são apenas funções construtoras, os dados associados podem ser passados como um argumento comum de função. Se outra união discriminada já definiu um caso com o mesmo nome, você vai precisar usar o nome completo (por exemplo, `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

As uniões discriminadas têm _igualdade estrutural_, o que significa que dois valores do mesmo caso e com os mesmos dados (opcionais) são equivalentes.

Embora você possa usar expressões `if/elif/else` para trabalhar com uniões discriminadas, a forma recomendada é a correspondência de padrões, usando o _padrão de identificador_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
