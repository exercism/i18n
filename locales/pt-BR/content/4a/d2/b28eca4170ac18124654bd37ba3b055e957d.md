# Introdução

## Igualdade

Tipos simples (strings e primitivos) normalmente são testados quanto à igualdade com `==` e `!=`.

Tipos de referência (instâncias de classes) são comparados usando o método `Equals()` herdado de `Object`. Se o seu objetivo com o teste de igualdade é garantir que dois objetos sejam exatamente a mesma instância, então confiar na implementação de `Object` já basta. Caso contrário, você precisa sobrescrever `object.Equals()`.

Se você sabe que todas as instâncias da sua classe são criadas em um único lugar, como personagens de algum jogo ou simulação, a igualdade de referência é suficiente. No entanto, é provável que várias instâncias da mesma entidade do mundo real sejam criadas (a partir de um banco de dados, por entrada do usuário, por meio de uma requisição web). Nesse caso, os valores que identificam a entidade de forma única precisam ser testados quanto à igualdade. Por isso, `Equals()` precisa ser sobrescrito e os membros de dados apropriados da sua classe são testados quanto à igualdade.

Um método `Equals()` sobrescrito vai conter testes de igualdade nos membros de tipos simples usando `==` e nos de tipos de referência com chamadas recursivas a `Equals()`.

A classe `Object` fornece métodos apropriados para comparar dois objetos e detectar se eles são uma única e mesma instância.

### `Object.GetHashCode()`

O método `Object.GetHashCode()` retorna um código hash na forma de um número inteiro de 32 bits. O código hash é usado por classes _dicionário_ e _conjunto_, como `Dictionary<T>` e `HashSet<T>`, para armazenar e recuperar objetos de maneira eficiente.

A relação entre código hash e igualdade é a seguinte: se dois objetos são iguais (`Equal()` retorna true), então `GetHashCode()` dos dois objetos precisa retornar o mesmo valor. Isso não vale na direção inversa. Não é simétrico. Só porque dois objetos têm o mesmo código hash, eles não precisam ser iguais. Imagine uma função de busca que primeiro vai para um "bucket" com base no código hash e depois seleciona o item específico usando o teste de igualdade.

A documentação da API da biblioteca HashCode discute a melhor forma de gerar um código hash.

Os valores usados no teste de igualdade precisam ser estáveis enquanto a coleção com hash estiver em uso. Se você adiciona um objeto à coleção com um conjunto de valores e depois altera esses valores, o código hash não vai mais apontar para o "bucket" correto. Na prática, isso significa que o objeto deve ser imutável. Outras abordagens correm o risco de criar armadilhas para os mantenedores.

## Conjuntos

Um conjunto é uma coleção de valores únicos. A implementação padrão de conjunto do .NET é a classe `HashSet<T>`, que é uma coleção que contém apenas valores únicos.
