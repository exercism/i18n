# Anexo das instruções

## Registradores

| Registrador | Uso       | Tipo    | Descrição                                |
| -------- | --------- | ------- | ---------------------------------------- |
| `$a0`    | entrada   | endereço | string de entrada terminada em nulo     |
| `$v0`    | saída     | boolean | isbn válido (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário     |
