# Sobre

Muitos operadores também podem ser usados como [atribuições compostas][compound-assignment], uma notação abreviada em que `x = op y` pode ser escrito como `x op= y`:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
