# Apêndice das instruções

## Dicas

Os testes deste exercício são diferentes dos testes comuns. Normalmente, um teste verifica se, para uma determinada entrada, a saída corresponde ao valor esperado. Isso se chama _teste baseado em valores_. No entanto, este exercício usa _teste baseado em propriedades_, em que os testes verificam se, para uma série de entradas, a saída tem uma propriedade específica. As duas principais diferenças que distinguem o teste baseado em propriedades do teste baseado em valores são:

1. Um teste baseado em propriedades não trabalha com um único valor de entrada, mas com muitos.
1. Um teste baseado em propriedades verifica propriedades, não valores concretos.

Neste exercício, todos os testes verificam uma propriedade do formato de diamante que seu código deve produzir. Além disso, todos os testes verificam se a propriedade testada vale para todas as letras de entrada válidas ('A' a 'Z').

Para facilitar o teste baseado em propriedades, os testes deste exercício utilizam os pacotes [FsCheck](https://www.nuget.org/packages/FsCheck) e [FsCheck.Xunit](https://packages.nuget.org/packages/FsCheck.Xunit/2.2.0). Para saber mais sobre o FsCheck, a documentação do framework está disponível [aqui](https://fscheck.github.io/FsCheck/).

Se você quiser mais informações sobre teste baseado em propriedades, veja [este artigo](http://www.erikschierboom.com/2016/02/22/property-based-testing/).
