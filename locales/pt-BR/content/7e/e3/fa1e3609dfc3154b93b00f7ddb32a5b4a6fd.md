# Instruções

Elyse, aspirante a mágica, continua seu treinamento. Ela vai receber várias pilhas de cartas com as quais precisa realizar seus truques.
Para facilitar um pouco as coisas, ela usa apenas as cartas de 1 a 10.

Neste exercício, use métodos internos para analisar o conteúdo de um vetor.

## 1. Determine se uma carta está presente

Elyse quer determinar se uma carta está presente na pilha, ou seja, se a pilha contém um número específico.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. Encontre a posição de uma carta

Elyse quer saber a posição (índice) de uma carta na pilha. 
Se a carta não estiver na pilha, retorne `-1`.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. Determine se cada carta é par

Elyse quer saber se todas as cartas são pares, ou seja, se cada número na pilha é um número par.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. Verifique se a pilha contém uma carta de valor ímpar

Elyse quer saber se há um número ímpar na pilha.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. Obtenha a primeira carta ímpar da pilha

Elyse quer saber o valor da primeira carta que é ímpar.  
Se não houver carta ímpar na pilha, retorne `-1`.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. Determine a posição da primeira carta par

Elyse quer saber a posição da primeira carta que é par.
Se não houver carta par na pilha, retorne `-1`.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
