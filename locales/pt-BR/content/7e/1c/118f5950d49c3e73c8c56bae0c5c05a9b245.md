# Instruções

Neste exercício, você vai processar linhas de log.

Cada linha de log é uma string formatada como `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de log: `INFO`, `WARNING` e `ERROR`.

Você tem três tarefas. Cada uma recebe uma única linha de log da pilha.

## 1. Obtenha a mensagem de uma linha de log

Defina `message` para retornar a mensagem da linha de log. Espaços em branco no início ou no final devem ser removidos.

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. Obtenha o nível de log de uma linha de log

Defina `log-level` para retornar o nível da linha de log, em minúsculas.

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. Reformate uma linha de log

Defina `reformat` para colocar a mensagem primeiro e o nível de log em minúsculas entre parênteses depois dela.

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***Observação:*** Todas as strings deste exercício são ASCII. Exercícios posteriores vão abordar o tratamento de strings com suporte a Unicode.
