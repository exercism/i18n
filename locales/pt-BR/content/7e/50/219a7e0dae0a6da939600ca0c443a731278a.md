# Instruções

Você adora observar pássaros e acompanha quantos visitaram seu jardim nos últimos sete dias.

Você tem seis tarefas, todas lidando com os números de pássaros que visitaram seu jardim.

## 1. Confira quantos pássaros visitaram hoje

Implemente a função `today()` para retornar quantos pássaros visitaram seu jardim hoje. As contagens de pássaros estão ordenadas por dia, com o primeiro elemento sendo a contagem do dia mais antigo e o último elemento sendo a contagem de hoje.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Incremente a contagem de hoje

Implemente a função `increment_todays_count()` para incrementar a contagem de hoje:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Verifique se houve um dia sem pássaros visitantes

Implemente a função `has_day_without_birds()` que retorna `TRUE` se houve um dia em que zero pássaros visitaram o jardim; caso contrário, retorne `FALSE`:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Calcule o número de pássaros visitantes nos primeiros dias

Implemente a função `count_for_first_days()` que retorna o número de pássaros que visitaram seu jardim desde o início da semana, mas limita a contagem ao número especificado de dias a partir do início da semana.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Calcule o número de dias movimentados

Alguns dias são mais movimentados que outros. Um dia movimentado é aquele em que cinco ou mais pássaros visitaram seu jardim.
Implemente a função `busy_days()` para retornar o número de dias movimentados:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. Calcule o total acumulado de visitas de pássaros na última semana

Você quer saber quantos pássaros no total visitaram até agora nesta semana.
Calcule os totais acumulados para cada dia.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. Ordene os nomes dos dias de acordo com o movimento

Você suspeita que as visitas dos pássaros são afetadas por padrões do trânsito nas proximidades, sendo diferentes nos fins de semana e nos dias úteis.

Ordene as abreviações dos dias em ordem _decrescente_ de quantos pássaros visitaram.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
