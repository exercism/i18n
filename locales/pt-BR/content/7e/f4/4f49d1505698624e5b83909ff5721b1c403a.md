# Introdução

O Ruby vem com uma biblioteca padrão (em inglês, "Standard Library"), uma coleção de classes para trabalhar com coisas como datas, json e redes.
Ela também traz alguns recursos úteis para facilitar o trabalho com o seu código.

O `OpenStruct` faz parte da biblioteca padrão e permite que você crie facilmente um objeto a partir de um `Hash`.
Em vez de precisar acessar pelos(as) chaves do `Hash`, o `OpenStruct` permite usar métodos para acessar e definir valores.

Ao usar classes da biblioteca padrão, ou de qualquer outra biblioteca, você precisa carregar essa classe usando o método `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Uma vantagem extra disso é que você pode aproveitar um atalho ao usar a sintaxe de bloco.
Quando um bloco chama um único método, você pode substituir o bloco por `&:` seguido do nome do método.
Por exemplo, estas duas linhas são equivalentes:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
