Projete uma suíte de testes para uma ferramenta de contagem de linhas, letras e caracteres.

Este é um exercício especial.
Em vez de criar código que funciona com uma suíte de testes existente, você é quem define a suíte de testes.
Para ajudar você, várias variações do código em teste foram fornecidas; sua suíte de testes deve ser capaz de detectar ao menos os problemas (ou a ausência deles) nelas.

O sistema em teste deve ser um sistema que conta o número de linhas, letras e o total de caracteres nas strings fornecidas.
A ideia é que você execute a operação "add string" várias vezes, passando strings, e depois chame as funções "lines", "letters" e "characters" para obter os totais.
