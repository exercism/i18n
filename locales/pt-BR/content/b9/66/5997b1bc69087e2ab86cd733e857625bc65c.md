# Testes

## Configuração

Siga as [instruções de instalação do WebAssembly][docs-exercism-wasm] para instalar as dependências necessárias.

## Requisitos

Instale as dependências do exercício:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## Como fazer a suíte de testes passar

Todos os exercícios vêm com uma suíte de testes para ajudar você a validar sua solução antes de enviar.
Você pode executar esses testes abrindo um prompt de comando no diretório do exercício e rodando:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

Em algumas suítes de testes, todos os testes, exceto o primeiro, são ignorados.

Assim que você conseguir fazer um teste passar, é possível ativar o próximo trocando `xtest` por `test`.

## Escrevendo testes personalizados

Se você quiser escrever testes adicionais e personalizados, crie um novo arquivo `custom.spec.js` e envie-o junto com sua solução:

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
