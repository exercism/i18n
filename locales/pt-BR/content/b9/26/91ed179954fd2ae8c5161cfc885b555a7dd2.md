# Introdução

Os comentários permitem que você deixe anotações no código sem afetar a forma como ele roda.
Comentários de uma linha começam com `//`, e comentários de várias linhas ficam entre `/*` e `*/`:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

Os comentários têm propósitos diferentes dependendo de onde aparecem.

## Comentários de código

Comentários de código explicam por que algo é feito, não o que é feito.
Use-os quando o motivo por trás de uma decisão não estiver óbvio a partir do código:

```go
results = results[1:] // skipping the header row
```

## Comentários de documentação

Comentários de documentação ficam diretamente antes de uma declaração, sem nenhuma linha em branco separando o comentário da declaração.
O [`godoc`][godoc] os analisa para gerar a documentação do pacote.
Um comentário de documentação deve ser uma frase completa, começando com o nome do identificador e terminando com um ponto final.

Comentários de pacote começam com o nome do pacote:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

Comentários de função começam com o nome da função:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
