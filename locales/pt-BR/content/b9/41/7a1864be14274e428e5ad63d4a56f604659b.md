# Introdução

O Common Lisp usa os operadores aritméticos padrão para a maioria das operações, mas tem a particularidade de usar uma "notação de prefixo" em vez da mais familiar "notação infixa".

De forma mais visual:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Embora a notação de prefixo transforme algumas operações como `2 + 2` na forma um pouco incomum `(+ 2 2)`, ela torna muito mais fácil operar com mais de um número de uma vez.

## Matemática básica

O Common Lisp tem todas as funções típicas: `+`, `-`, `*` e `/` para adição, subtração, multiplicação e divisão.

Ao trabalhar com divisão, você pode querer saber o resto de uma divisão. Isso é feito pela função `mod` (de módulo), que recebe um número e um divisor como argumentos:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## Comparando números

Por fim, pode ser útil comparar números diferentes usando funções como `=` (igual), `/=` (diferente de) e `>=` (maior ou igual a).
Quando essas comparações são verdadeiras (como em `(= 1 1)`), elas retornam `T`, e quando não são (como em `(> 0 1)`), retornam `NIL`.
