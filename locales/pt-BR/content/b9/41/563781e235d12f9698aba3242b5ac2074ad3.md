# Testes

## Rodando os testes

Quando você estiver no diretório de um exercício, deve ver dois subdiretórios:

* `src` contém a sua solução para o exercício
* `spec` contém os testes a serem rodados no exercício

Se você estiver no diretório certo (ou seja, o que contém `src` e `spec`), pode rodar os testes desse exercício com `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Isso vai rodar todos os arquivos de teste do diretório `spec`.

Em cada arquivo de teste, todos os testes, exceto o primeiro, foram ignorados.

Assim que conseguir fazer um teste passar, você pode ativar o próximo trocando `pending` por `it`.

## Formatação do Crystal

Antes de enviar, é recomendável rodar `crystal tool format` na sua solução.

Você pode formatar tudo no seu diretório atual com:

```bash
$ crystal tool format ./
```

Ou você pode formatar arquivos específicos com:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## Enviando sua solução

Ao enviar sua solução, certifique-se de enviar o arquivo-fonte que está no diretório `src`:

```bash
$ exercism submit src/<exercise>.cr
```
