Mas as coisas estão um pouco desorganizadas: as coordenadas da Azara parecem estar formatadas e ordenadas de forma diferente das do Rui, e eles precisam ficar olhando de uma lista para a outra para descobrir quais tesouros combinam com quais locais.
Como aspirantes a pythonistas, eles procuraram você para ajudar a escrever um pequeno programa (um conjunto de funções, na verdade) para organizar melhor as informações da caçada.


## 1. Extrair coordenadas

Implemente a função `get_coordinate()` que recebe um par `(treasure, coordinate)` da lista da Azara e retorna apenas a coordenada de mapa extraída.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. Formatar coordenadas

Implemente a função `convert_coordinate()` que recebe uma coordenada no formato "2A" e retorna uma tupla no formato `("2", "A")`.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. Comparar coordenadas

Implemente a função `compare_records()` que recebe um par `(treasure, coordinate)` e um registro `(location, coordinate, quadrant)` e compara as coordenadas de cada um.
Retorne **`True`** se as coordenadas "combinarem", e retorne **`False`** se não combinarem.
Reformate as coordenadas conforme necessário para uma comparação precisa.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. Combinar registros correspondentes

Implemente a função `create_record()` que recebe um par `(treasure, coordinate)` da lista da Azara e um registro `(location, coordinate, quadrant)` da lista do Rui e retorna `(treasure, coordinate, location, coordinate, quadrant)` **se as coordenadas combinarem**.
Se as coordenadas _não_ combinarem, retorne a string **"not a match"**.
Reformate a coordenada conforme necessário para uma comparação precisa.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
