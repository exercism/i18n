# Strings

`STR` armazena texto. Uma string é escrita entre aspas duplas.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

Uma `STR` nunca muda depois de criada. Tudo o que vem abaixo devolve uma string *nova*, em vez de alterar aquela sobre a qual se perguntou.

## Concatenação

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

O `+` também junta um número a uma string, e é assim que um número entra numa frase:

```sather
"Opus " + 27           -- "Opus 27"
```

## Comprimento

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` conta caracteres, e a resposta é um `INT`.

## Pedaços

| Chamada | Resposta |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

Pedir mais do que existe devolve o que existe, em vez de falhar.

## Comparação

O `=` pergunta se duas strings são o mesmo texto, e o `/=` se elas são diferentes.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

Maiúsculas e minúsculas fazem diferença. `.upper` e `.lower` devolvem uma cópia em caixa alta ou caixa baixa, que é a forma usual de comparar sem se importar com isso:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## Uma palavra sobre tamanho

Uma `STR` é uma sequência de bytes, e `.size` conta bytes. Para texto em inglês, isso é o mesmo que contar letras. Para texto com acentos ou outros alfabetos, não é, porque essas letras ocupam mais de um byte cada uma.
