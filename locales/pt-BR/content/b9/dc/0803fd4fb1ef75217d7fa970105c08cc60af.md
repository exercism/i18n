# Sobre

Um valor Boolean representa se uma condição é `true` ou `false`.
Em Go, o tipo `bool` só pode ser um desses dois valores.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## Operadores lógicos

Os operadores lógicos atuam sobre um ou dois valores Boolean e produzem um resultado Boolean.

| Operador | Nome | Comportamento                                              |
| -------- | ---- | ---------------------------------------------------------- |
| `!`      | NÃO  | Retorna o oposto de um único valor Boolean                 |
| `&&`     | E    | Retorna `true` apenas quando os dois lados são `true`      |
| `\|\|`   | OU   | Retorna `true` se qualquer um dos lados for `true`         |

Use `!` (NÃO) quando precisar do oposto de um valor Boolean:

```go
!isDoorLocked // false
```

Use `&&` (E) quando as duas condições precisarem ser `true`:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

Use `||` (OU) quando pelo menos uma condição precisar ser `true`:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

Os operadores lógicos são avaliados nesta ordem: primeiro `!`, depois `&&` e, por fim, `||`.
Use parênteses para agrupar o código e controlar quais operações acontecem primeiro:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
