# Anexo das instruções

## Como este exercício está estruturado para a trilha de Python

Os testes deste exercício esperam que sua solução seja implementada como uma `class` RelativeDistance em Python.
Se você ainda não conhece `class`es em Python, [concept:python/classes]() e [`classes` na documentação oficial do Python][classes in python] são bons pontos de partida.


`RelativeDistance` deve ser inicializado (_veja [`__init__()`][init] para mais informações_) usando `family_tree`, um dicionário em que as `keys` são indivíduos e os `values` são `list`s dos filhos desse indivíduo.
Você também vai precisar implementar um [método][methods] `degree_of_separation`, que retorna o grau de separação entre `person_a` e `person_b`, que são indivíduos na árvore genealógica passada.


Você recebe uma implementação esboçada do [método especial][special-methods] `__init__` usado para criar uma instância da classe `RelativeDistance`, bem como um esboço do método `degree_of_separation`.
Primeiro, você vai precisar personalizar o `__init__` com um atributo apropriado em `self` (_a instância_) para representar os dados de `family_tree`.
Depois, você pode adicionar sua lógica ao método `degree_of_separation` para calcular o grau de separação entre `person_a` e `person_b`.


## Mensagens de exceção

Às vezes, é necessário [lançar uma exceção][raising-exceptions].
Quando fizer isso, sempre inclua uma **mensagem de erro significativa** para indicar qual é a origem do erro.
Isso deixa seu código mais legível e ajuda bastante na depuração.
Para situações em que você sabe que a origem do erro será de um determinado tipo, você pode optar por lançar um dos [tipos de erro integrados][base-error-classes], mas ainda assim deve incluir uma mensagem significativa.

Este exercício em particular exige que você use a [instrução raise][raise-statement] para "lançar" vários `ValueError`s.
No primeiro cenário, você vai precisar lançar um `ValueError` quando uma ou ambas as pessoas passadas ao método `RelativeDistance.degree_of_separation` não estiverem presentes na árvore genealógica.

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

Se as duas pessoas estiverem presentes na árvore genealógica, você vai precisar lançar um `ValueError` quando não houver nenhuma conexão válida entre elas, conforme definido pelas regras.

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

Os testes só vão passar se você `raise` o tipo de `exception` esperado e incluir também a mensagem esperada.
Confira os testes e os resultados esperados com atenção, porque estas instruções não são exaustivas.
