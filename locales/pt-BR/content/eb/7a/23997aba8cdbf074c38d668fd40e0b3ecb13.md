# Dicas

## 1. Monitorar o nível de umidade do ambiente

- Se a umidade estiver muito alta, basta [parar][ref-stopifnot]; nenhuma mensagem é necessária.
- Se as condições estiverem boas, você precisa emitir uma [mensagem][ref-message].

## 2. Detectar superaquecimento

- Há várias condições para testar.
- Se você precisar [parar][ref-stop], a mensagem de erro é importante.
- Uma condição preocupante, mas ainda não fatal, pede um [aviso][ref-warning].
- Um bom resultado pede uma [mensagem][ref-message] tranquilizadora.
- Lembre-se do valor de retorno Boolean.

## 3. Monitorar a máquina

- As tarefas 1 e 2 têm valores de retorno Boolean que você pode testar.
