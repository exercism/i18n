# Introdução

Quando o Elixir resolve a função a ser invocada, ele usa o nome do módulo para fazer uma busca. A busca pode ser feita dinamicamente se o nome do módulo estiver vinculado a uma variável.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Internamente, o nome de um módulo é um átomo. Todos os átomos de módulo do Elixir recebem automaticamente o prefixo `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
