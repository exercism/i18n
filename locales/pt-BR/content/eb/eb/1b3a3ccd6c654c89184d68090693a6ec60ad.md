# Sobre

O pacote `java.time`, introduzido no Java 8, contém várias classes para trabalhar com datas e horas.

## `LocalDate`

A classe [`java.time.LocalDate`][localdate-docs] representa uma data sem fuso horário no [sistema de calendário ISO-8601][iso-8601], como `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

Datas podem ser comparadas com outras datas:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

Uma instância de `LocalDate` tem getters para recuperar partes da data:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getYear();
// => 2007

date.getMonthValue();
// => 12

date.getDayOfMonth();
// => 3
```

Uma instância de `LocalDate` tem métodos para adicionar unidades de tempo a ela.

```exercism/note
Esses métodos retornam uma _nova_ instância de `LocalDate` e não atualizam a instância existente, já que a classe `LocalDate` é imutável.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06

date.plusMonths(1);
// => 2008-01-03

date.plusYears(1);
// => 2008-12-03
```

## `LocalDateTime`

A classe [`java.time.LocalDateTime`][localdatetime-docs] representa uma data e hora sem fuso horário no [sistema de calendário ISO-8601][iso-8601], como `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);

datetime.getYear();
// => 2007

datetime.getMonthValue();
// => 12

datetime.getDayOfMonth();
// => 3

datetime.getHours();
// => 10

datetime.getMinutes();
// => 15

datetime.getSeconds();
// => 30
```

Assim como a classe `LocalDate`, uma instância de `LocalDateTime` tem os mesmos métodos para comparar com outros `LocalDateTime`s e para adicionar unidades de tempo a ela.

Também é possível converter uma instância de `LocalDate` em um `LocalDateTime`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## Formatação de datas e horas

Tanto `LocalDate` quanto `LocalDateTime` usam a notação padrão [ISO-8601][iso-8601] ao converter de e para uma `String`.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

Não é possível fazer o parse de um `LocalDate` ou `LocalDateTime` a partir de uma `String` como essa usando um formato diferente.
Em vez disso, para formatar datas usando um formato personalizado, você deve usar o [`java.time.format.DateTimeFormatter`][datetimeformatter-docs]:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", formatter);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

Também é possível especificar um [locale][locale] ao criar o formato personalizado, para formatar e fazer o parse em regiões diferentes:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```
