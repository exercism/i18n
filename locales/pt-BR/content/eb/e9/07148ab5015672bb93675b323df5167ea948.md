# Testes

Para testar a solução, é só **rodar o script de teste**. Você pode fazer isso pelo Red Console usando a função `do` junto com o caminho do script de teste, assim:

```red
do %exercism/red/hello-world/hello-world-test.red
```

Ou simplesmente adicionando-o como argumento ao binário do Red no terminal do seu sistema:

```shell
red exercism/red/hello-world/hello-world-test.red
```

No começo, apenas o primeiro teste do arquivo de teste estará habilitado. Isso é para incentivar você a resolver os exercícios um de cada vez. Quando você conseguir fazer o primeiro teste passar, mude o segundo *argumento* da função `test-init` no início do arquivo de teste e rode de novo. Esse valor é a contagem de testes habilitados, então mudá-lo de `1` para `2` vai habilitar o segundo teste. Você também pode remover o refinamento `\limit` da função `test-init` e o segundo argumento, para rodar todos os testes sem pular nenhum.
