# Sobre

A maior parte da iteração em Factor é expressa com combinadores (`each`, `map`, `reduce`), mas a recursão explícita ainda tem seu lugar: quando a recursão não tem formato de lista, quando o caso base não é trivial ou quando você mesmo está implementando um combinador.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Algumas coisas que vale a pena saber:

- Definições comuns com `:` podem ser recursivas sem nenhuma sintaxe especial. O compilador infere os efeitos de pilha ao longo da chamada recursiva.
- `loop ( quot -- )` permite iterar uma quotation que retorna um Boolean: continue enquanto o valor for verdadeiro.
- Chamadas de cauda são compiladas como saltos, então palavras profundamente recursivas não estouram a pilha.

O par `unclip` / `if-empty` é a forma padrão de recursão em sequências; `cond` é a forma padrão de despacho para múltiplos casos.
