# Apêndice das instruções

## Registradores

| Registrador | Uso           | Tipo     | Descrição                                               |
| ----------- | ------------- | -------- | ------------------------------------------------------- |
| `$a0`       | entrada       | inteiro  | número de moedas de entrada                             |
| `$a1`       | entrada       | inteiro  | alvo                                                    |
| `$a2`       | entrada/saída | endereço | array sobrescrevível de palavras de moedas              |
| `$v0`       | saída         | inteiro  | número de moedas de saída, -1 se a entrada for inválida |
| `$t0-9`     | temporário    | qualquer | usado para armazenamento temporário                     |
