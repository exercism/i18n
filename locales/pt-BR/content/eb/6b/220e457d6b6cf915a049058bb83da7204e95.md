# Tratamento de erros

Neste exercício, você vai implementar uma função chamada `processString` que processa uma string de entrada fornecida com o tratamento de erros adequado.

Você vai aprender a:

- Verificar tipos de entrada e lançar erros para entradas inválidas.
- Lançar erros para casos específicos (por exemplo, strings vazias).
- Retornar a versão em maiúsculas da string se ela for válida.
- Tratar e capturar erros usando um bloco try..catch


Implemente a função processString usando um bloco `try…catch`.

Dentro do bloco `try`:
- Se a entrada não for uma string, lance um `TypeError`.
- Se a entrada for uma string vazia, retorne `null`.
- Se o comprimento da entrada for maior que 100, ou menor que 10, lance um `RangeError`.
- Se a entrada contiver uma mistura de letras e números, lance um `SyntaxError`.
- Caso contrário, retorne a entrada em `uppercase`.

*Não se esqueça de anexar mensagens de erro apropriadas quando você lançar! Uma mensagem de erro informativa e bem estruturada pode economizar horas de depuração.*

Dentro do bloco `catch`:
- Registre a mensagem do erro usando `console.log`
- `throw` o `error` para que o tipo dele possa ser testado.
