# Dicas

## 1. Gere um planeta aleatório

- Isso se parece com uma [amostragem][ref-sample] de um vetor de entrada.
- É possível haver duplicatas, então faça a amostragem com reposição.

## 2. Gere um número de registro de nave estelar aleatório

- A parte numérica é uma amostragem de um intervalo.
- Há várias formas de construir a string, incluindo [`sprintf()`][ref-sprintf] e [`str_glue()`][ref-str_glue].

## 3. Embaralhe uma frota de naves estelares

- A Introdução fala sobre embaralhamento.

## 4. Gere uma data estelar aleatória

- Queremos um número de ponto flutuante com [distribuição uniforme][ref-runif] entre limites inferior e superior.
- Nuanças sobre limites inclusivos ou exclusivos podem ser ignoradas nesta tarefa.
