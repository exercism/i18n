# Instalação

Vamos usar o *PolyML* como nossa implementação de Standard ML.

Se você usa Windows, pode baixar um instalador em [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases).
Instruções gerais para Linux/OS X/Free BSD estão em [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme).

Se você quiser instalar a partir do código-fonte, o processo é bem simples:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

Se você quiser instalar em um local personalizado, por exemplo `$HOME/.local`:

```sh
$ ./configure --prefix=$HOME/.local
```

Último passo:

```sh
$ make compiler
$ make install
```

Verifique se a instalação deu certo:

```sh
$ poly
```

Se você vir o intérprete, está tudo pronto!
Se não, provavelmente você vai precisar adicionar `$HOME/.local/bin` (ou `<you prefix>/bin`) ao seu `$PATH`.
