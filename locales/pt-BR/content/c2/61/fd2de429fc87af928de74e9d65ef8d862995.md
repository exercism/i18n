# Testes

Faça o primeiro teste compilar, linkar e passar seguindo as [três regras do desenvolvimento orientado a testes][3-tdd-rules].

O makefile incluído pode ser usado para criar e rodar os testes usando a tarefa `test`.

```console
$ make test
```

Crie apenas as funções necessárias para resolver os erros do compilador e fazer o teste falhar.
Depois, escreva só o código suficiente para fazer o teste passar.
Quando terminar, passe para o próximo teste.

Conforme você avança pelos testes, reserve um tempo para refatorar sua implementação em busca de legibilidade e expressividade e depois siga para o próximo teste.

Procure usar os recursos padrão do C99 em vez de escrever à mão seus próprios algoritmos ou recursos de baixo nível.

## Como verificar vazamentos de memória

O makefile também vem com uma build que verifica alguns erros comuns relacionados a vazamentos de memória e acesso fora dos limites de arrays.
Para rodar essas verificações, use o seguinte na linha de comando:

```console
$ make memcheck
```
