# Introdução

Felt é um dos tipos escalares de Cairo, assim como os números inteiros e os valores Boolean, e é representado pela palavra-chave `felt252`.
`felt252` é um tipo de dados fundamental em Cairo, do qual todos os outros tipos de dados derivam.
`felt252` também pode ser usado para armazenar [representações de string curtas][felts] com comprimento máximo de 31 caracteres.

Por exemplo:

```rust
    let felt: felt252 = 100;
    let felt_as_str: felt252 = 'Hello Starknet!';

    let _felt = felt + felt_as_str;
```

[felts]: https://starknet-by-example.voyager.online/getting-started/basics/bytearrays-strings.html#short-strings
