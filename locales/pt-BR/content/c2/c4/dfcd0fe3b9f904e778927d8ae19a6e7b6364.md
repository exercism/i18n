# Introdução

Uma [`string`][ref-string] em Kotlin é uma sequência imutável de caracteres Unicode.

[`Immutable`][wiki-immutable] significa que qualquer operação em uma string precisa retornar uma nova string: a string original nunca pode mudar.

[`Unicode`][wiki-unicode] significa que a maioria dos sistemas de escrita do mundo pode ser representada, mas (ao contrário de linguagens mais antigas, como C) não existe uma correspondência 1:1 entre caracteres e bytes.

Uma string geralmente fica entre aspas duplas `" "`.

Alguns caracteres precisam de escape: `\'`, `\\`, além dos habituais caracteres não imprimíveis, como `\t` (tabulação) e `\n` (nova linha).

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

Strings de várias linhas ficam entre 3 aspas duplas e podem conter texto arbitrário (sem precisar de escape).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Use [trimIndent][trimIndent-doc] para remover a indentação comum das linhas.
Isso é útil para formatar a string:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Como alternativa, [trimMargin][trimMargin-doc] permite especificar um delimitador.
Nesse caso, cada linha da `String` começa depois do delimitador.
O delimitador padrão é `|`, mas você pode especificar um delimitador diferente como parâmetro.
Por exemplo:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Strings podem ser concatenadas com `+`, mas é melhor limitar isso a casos curtos e simples.
Existem outras opções, muitas vezes melhores.

## Templates de string

Isso se refere ao que algumas outras linguagens chamam de "interpolação".

Se uma string contém um cifrão `$` seguido de um identificador, ou contém chaves (`{expression}`) envolvendo uma expressão, esses elementos são substituídos, respectivamente, pelo valor ou pelo resultado da expressão.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

As chaves `{ }` são necessárias ao redor de expressões quando a análise seria ambígua de outra forma.

Em geral, usar templates de string é uma forma mais eficiente e idiomática de combinar strings do que usar `+`.

## Funções de string

Kotlin oferece _muitas_ [`functions`][ref-string-functions] para manipular strings.

Na maioria das vezes, são [`extensions functions`][ref-extensions] em vez de membros da classe `String`, embora isso tenha pouco efeito na forma como as usamos.

~~~~exercism/note
As páginas de [documentação][ref-string-functions] do Kotlin são bem complexas e escondem as extension functions na visualização padrão.
Certifique-se de clicar em `Members & Extensions` para expandir esta seção.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Os exemplos a seguir mostram apenas uma pequena seleção do que está disponível:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
