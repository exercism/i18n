# Instruções

Implemente a operação `accumulate`, que, dada uma coleção e uma operação a ser aplicada em cada elemento da coleção, retorna uma nova coleção contendo o resultado da aplicação dessa operação a cada elemento da coleção de entrada.

Dada a coleção de números:

- 1, 2, 3, 4, 5

E a operação:

- elevar um número ao quadrado (`x => x * x`)

Seu código deve ser capaz de produzir a coleção de quadrados:

- 1, 4, 9, 16, 25

Dê uma olhada no conjunto de testes para ver a assinatura de função esperada.

## Restrições

Não use essa funcionalidade de collect/map/fmap/seja lá o que for que a sua biblioteca padrão oferece!
Resolva este exercício por conta própria usando outras ferramentas básicas.
