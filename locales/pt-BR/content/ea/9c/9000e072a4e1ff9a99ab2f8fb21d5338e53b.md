# Introdução

Em Python, [um enum](https://docs.python.org/3/library/enum.html) é um conjunto de nomes associados a valores `literal` ou `constant` únicos. Um enum é definido herdando uma classe `Enum`. Tipos de enum integrados estão disponíveis no módulo `enum`, e a classe `Enum` pode ser importada com `from enum import Enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

Repare que os valores dos membros do enum podem ser quaisquer tipos de dados, como str, tuple, float etc.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Quando você atribui o mesmo valor a dois membros de um enum, o membro atribuído por último será um alias do primeiro. Não é permitido usar o mesmo nome para dois membros de um enum.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

É possível iterar sobre os membros do enum com a sintaxe padrão `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Os membros de um enum podem ser comparados usando [`is` (_operador de identidade_)](https://www.w3schools.com/python/ref_keyword_is.asp) ou `is not`. Os operadores `==` ou `!=` (_operadores de igualdade_) funcionam da mesma forma.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Para acessar um membro do enum a partir de um determinado valor, pode-se usar `EnumName(value)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
