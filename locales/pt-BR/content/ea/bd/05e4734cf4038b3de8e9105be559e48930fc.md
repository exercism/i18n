# Dicas

## Geral

- O [Tutorial sobre strings][python-str-doc] da documentação do Python traz uma visão geral do tipo `str` do Python.
- Os métodos de string [`str.join()`][str-join] e [`str.split()`][str-split] são muito úteis na hora de processar strings.
- A documentação do Python sobre [tipos de sequência][common sequence operations] traz um resumo das operações comuns a todas as sequências, incluindo `strings`, `lists`, `tuples` e `ranges`.

São quatro atividades no exercício, cada uma com um conjunto de textos ou palavras para trabalhar.

## 1. Adicionar um prefixo a uma palavra

- Strings pequenas podem ser concatenadas com o operador `+`.

## 2. Adicionar prefixos a grupos de palavras

- Acredite ou não, [`str.join()`][str-join] é tudo o que você precisa aqui. **Um laço não é necessário**.
- Os testes vão passar uma `list` para a sua função. Não vai ser preciso alterar essa `list` se você conseguir descobrir uma boa string delimitadora.
- Lembre-se de que as strings delimitadoras ficam entre os elementos e os "colam" uns aos outros, formando uma única string. Os delimitadores são inseridos _sem_ espaço, embora você possa incluir espaços dentro deles.
- Assim como [`str.split()`][str-split], o `str.join()` pode processar uma string de comprimento arbitrário, formada por quaisquer pontos de código unicode. _Diferente_ de `str.split()`, ele também pode processar iteráveis de comprimento arbitrário, como `list`, `tuple` e `set`.

## 3. Remover um sufixo de uma palavra

- Strings podem ser indexadas ou fatiadas tanto pela esquerda (começando em 0) quanto pela direita (começando em -1).
- Se você quiser o último ponto de código de uma string de comprimento arbitrário, pode usar `[-1]`.
- As três últimas letras de uma string podem ser "cortadas" com um índice negativo. Por exemplo, `beautiful'[:-3] == 'beauti`

## 4. Extrair e transformar uma palavra

- Usar [`str.split()`][str-split] retorna uma `list` de strings quebradas nos espaços em branco.
- `lists` são sequências e podem ser indexadas.
- [`str.split()`][str-split] pode ser indexado diretamente: `'Exercism rocks!'.split()[0] == 'Exercism'`
- Cuidado com a pontuação! Pontos finais podem ser removidos com um fatiamento: `'dark.'[:-1] == 'dark'`
