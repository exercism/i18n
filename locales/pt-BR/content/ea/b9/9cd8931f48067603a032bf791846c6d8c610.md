# Apêndice das instruções

## Desenvolvimento orientado a testes

 Certifique-se de conferir os comentários no topo do arquivo de testes.
 Eles vão ajudar a entender a saída esperada da sua função.

Este desafio _poderia_ ser resolvido com um mínimo de código e muito texto fixo no código, duplicado entre os versos.
No entanto, esta música é um tipo de [canção cumulativa][cumulative song], em que cada novo verso se constrói sobre o verso anterior.
Para um desafio de programação maior, considere montar cada verso a partir de suas partes.
Por exemplo, em cada verso, o dia muda e o presente muda, e o resto do verso é praticamente igual.
Qual poderia ser uma boa estratégia para evitar repetição?
