# Introdução

## Condicionais

As condicionais são instruções de tomada de decisão que podem tanto executar efeitos colaterais quanto controlar o fluxo de execução de um programa.
As condicionais incluem `if`, `if/else`, `switch` e `ternary`.

As condicionais servem para fazer perguntas sobre um valor ou sobre a relação entre valores.
A pergunta resulta em uma resposta Boolean, mas a própria condicional `if` pode retornar qualquer valor ou simplesmente executar um efeito colateral.

## Condicionais `if`

A condicional `if` mais simples avalia uma expressão e executa uma linha.
A expressão testada fica sempre entre parênteses.

Ela pode executar um efeito colateral

```c
if (count > 10)
    printf("count is greater than 10");
```

ou pode mudar o fluxo de execução


```c
if (count > 10)
    return sum;
```

Se uma condicional `if` executa mais de uma linha, as linhas precisam ficar entre chaves

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Algumas equipes de programação podem padronizar que as condicionais `if` sempre usem chaves, mesmo para uma única linha.


## If Else

Uma condicional `if` pode ser combinada com um `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## If Else If


O `else` pode ser combinado com outro `if` para criar o que se chama de `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Switch


Às vezes, uma `if-else-if ladder` pode ser melhor representada por um `switch`.
Assim como no `if`, a expressão testada fica sempre entre parênteses.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

O caso `default` é executado se o valor testado não corresponder a nenhum dos casos anteriores.

Se um caso do `switch` não faz um retorno, normalmente se insere um `break` para encerrar cada caso; caso contrário, a lógica "passa direto" para o próximo caso.
Às vezes, essa passagem direta é intencional

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Quando a passagem direta acontece sem querer, é um bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Um `switch` pode ser vantajoso quando se testam valores específicos em vez de um intervalo de valores.
Ele pode ser mais rápido que uma `if-else-if ladder`, porque o compilador pode conseguir otimizar o `switch` de formas que não consegue com uma escada.
Às vezes, um `switch` pode parecer mais legível que uma escada.

## Operador ternário (também chamado de condicional)

O operador ternário é uma condicional de três partes, muito usada para definir um valor.
A expressão a ser testada vem antes do ponto de interrogação e não precisa ficar entre parênteses.
O valor retornado quando a condição for verdadeira vem antes dos dois-pontos; o valor retornado quando ela for falsa vem depois.
Pode ser retornado tanto um literal quanto uma variável.

```c
int i = j > 5 ? 5: j;
```

Operadores ternários podem ser aninhados para reduzir a poluição sintática.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
