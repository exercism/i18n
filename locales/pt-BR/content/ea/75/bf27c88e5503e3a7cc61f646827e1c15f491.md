# Butique de Moda

## História

Você tem uma butique de moda online. A Black Friday está chegando, então você precisa fazer um balanço do seu estoque para garantir que está tudo pronto.

Cada item do estoque é representado por um mapa/dicionário, e o estoque inteiro é uma lista/array desses mapas/dicionários.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## Tarefas

- Ordenar os itens por preço
- Encontrar todos os itens sem preço
- Incrementar a quantidade do item
- Calcular a quantidade total do item
