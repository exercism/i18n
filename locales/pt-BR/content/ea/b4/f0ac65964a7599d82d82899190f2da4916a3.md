# Apêndice das instruções

## Como este exercício está estruturado em Python


O Python oferece uma grande variedade de funções matemáticas na forma do [módulo math][math-module] e de funções embutidas como o operador de exponenciação `**`, [`pow()`][pow] e [`sum()`][sum].
No entanto, queremos que você encare o desafio de resolver este exercício sem essas funções embutidas e sem esses módulos.

Embora exista uma fórmula matemática que encontra a raiz quadrada de _qualquer_ número, optamos pelo caminho de ter apenas [números naturais][nautral-number] (inteiros positivos) como soluções.  
É possível calcular a raiz quadrada de qualquer número natural usando apenas números naturais no cálculo.
