# Instruções

Neste exercício, você vai escrever código para imprimir crachás com nomes de funcionários de uma fábrica.

## 1. Imprima um crachá para um funcionário

Funcionários têm um ID, um nome e o nome do departamento. Os rótulos dos crachás dos funcionários seguem o seguinte formato: `"[id] - name - DEPARTMENT"`.
Implemente o método `Badge.print()` para retornar o rótulo do crachá de um funcionário:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Repare que o departamento deve aparecer em maiúsculas no rótulo.

## 2. Imprima um crachá para um funcionário novo

Por causa de uma peculiaridade do sistema do computador, às vezes os funcionários novos ainda não têm um ID quando começam a trabalhar na fábrica.
Como os crachás são obrigatórios, eles recebem um crachá temporário sem o prefixo do ID. Modifique o método `Badge.print()` para aceitar funcionários novos que ainda não têm um ID:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprima um crachá para o dono

Até o dono da fábrica precisa usar um crachá o tempo todo.
No entanto, o dono não tem um departamento. Nesse caso, o rótulo deve imprimir `"OWNER"` no lugar do nome do departamento.
Modifique o método `Badge.print()` para imprimir um rótulo para o dono:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

Repare que é possível que o dono também seja um funcionário novo:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
