# Dicas

## 1. Verifique o nível de umidade da sala

- Lógica simples de if...else.
- Um operador ternário já dá conta.
- Esta tarefa usa uma função `error()`, e não `throw()`.
- A macro `@info` também é necessária.
- Leia a seção Logging da introdução para ver como gerar mensagens de log.

## 2. Verifique se há superaquecimento

- Há duas condições de falha a testar.
- Cada uma precisa de um `throw()` se falhar.
- A macro `@info` é necessária em caso de sucesso.

## 3. Defina um erro personalizado

- Veja a introdução para um exemplo de como definir um erro personalizado.
- Campos e mensagens de impressão personalizadas são possíveis, mas não obrigatórios.

## 4. Monitore a máquina

- Você pode usar as funções `humiditycheck` e `temperaturecheck`, mas isso não é estritamente necessário.
- Se você usá-las, deve conseguir verificar de forma independente se as duas funções lançam erros e adicionar os logs apropriados.
- Uma variável definida fora de um bloco `try...catch` pode ser atualizada de dentro do bloco, se necessário.
- Lembrete: se uma verificação falhar, ou as duas, você só precisa lançar um `MachineError` depois que os logs forem adicionados.
