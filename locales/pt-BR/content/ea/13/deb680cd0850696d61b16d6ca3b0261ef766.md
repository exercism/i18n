# Introdução

[Go](https://golang.org) é uma linguagem de programação compilada e de tipagem estática.
Este exercício apresenta três recursos importantes da linguagem: pacotes, funções e variáveis.

## Pacotes

Aplicações Go são organizadas em pacotes.
Um pacote é uma coleção de arquivos-fonte localizados no mesmo diretório.
Todos os arquivos-fonte em um diretório devem compartilhar o mesmo nome de pacote.
Quando um pacote é importado, apenas entidades (funções, tipos, variáveis, constantes) cujos nomes começam com letra maiúscula podem ser usadas / acessadas.
O estilo recomendado de nomenclatura em Go é que os identificadores sejam nomeados usando `camelCase`, exceto aqueles que devem ser acessíveis entre pacotes, que devem usar `PascalCase`.

```go
package lasagna
```

## Variáveis

Go tem tipagem estática, o que significa que todas as variáveis [devem ter um tipo definido](https://en.wikipedia.org/wiki/Type_system) em tempo de compilação.

Variáveis podem ser definidas especificando explicitamente um tipo:

```go
var explicit int // Explicitly typed
```

Você também pode usar um inicializador, e o compilador atribuirá à variável o tipo que corresponde ao tipo do inicializador.

```go
implicit := 10   // Implicitly typed as an int
```

Uma vez declaradas, as variáveis podem receber valores usando o operador `=`.
Uma vez declarada, o tipo de uma variável nunca pode mudar.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

Constantes guardam um dado, assim como as variáveis, mas seu valor não pode mudar durante a execução do programa.

Constantes são definidas usando a palavra-chave `const` e podem ser números, caracteres, strings ou valores Boolean:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funções

As funções Go aceitam zero ou mais parâmetros.
Os parâmetros devem ser tipados explicitamente, não há inferência de tipo.

Os valores são retornados de funções usando a palavra-chave `return`.

Uma função é invocada especificando o nome da função e passando argumentos para cada um dos parâmetros da função.

Repare que Go suporta dois tipos de comentários.
Comentários de uma única linha são precedidos por `//` e comentários de várias linhas são inseridos entre `/*` e `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
