# Instruções

Você! Isso mesmo, você, corajoso lisper! [Lenny, o alienígena do Lisp][alien], precisa da sua ajuda! Lenny quer sair para curtir com todos os outros alienígenas do Lisp, mas os pais avisaram que não vai a lugar nenhum enquanto o quarto não estiver limpo.

O problema é que Lenny quase não consegue ver o chão! Lenny não consegue distinguir os átomos dos conses, os símbolos das palavras-chave, os `car`s dos `cdr`s!

Você pode ajudar Lenny a organizar essa bagunça? Não se esqueça [dos seus parênteses][xkcd], você vai precisar deles!

## 1. Relembre Lenny sobre os símbolos

Antes de começar, Lenny precisa relembrar como são os símbolos e as palavras-chave: já faz um tempo desde a última arrumação... Ajude Lenny definindo duas funções: `lennys-favorite-food`, que é avaliada para algum símbolo, e `lennys-secret-keyword`, que é avaliada para alguma palavra-chave. Por exemplo:

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

Observe que você pode retornar qualquer símbolo ou palavra-chave que quiser (se você não é fã de lasanha ou não acredita em alienígenas).

## 2. Ajude Lenny a distinguir entre átomos e conses

Agora que Lenny já relembrou símbolos e palavras-chave, é hora de limpar! Para organizar todas as S-Expressions espalhadas pelo quarto, Lenny precisa de ajuda para descobrir o que é um cons e o que é um átomo. Você pode ajudar implementando duas funções, `is-an-atom-p` e `is-a-cons-p`:

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

Nesta seção, existem várias funções internas do Lisp que podem ser úteis. Além disso, por enquanto, você pode simplesmente considerar `T` como verdadeiro e `NIL` como falso.

## 3. Ajude Lenny a dividir os conses

Por fim, os conses de Lenny são volumosos demais para guardar direitinho, então é preciso dividi-los em partes menores. Você pode ajudar definindo mais duas funções para separar os conses (`first-thing` e `rest-of-it`)?

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

De novo, algumas funções internas do Common Lisp podem ser úteis aqui.
