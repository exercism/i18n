# Anexo às instruções

## Estrutura do projeto

Os exercícios de Clojure no Exercism têm suporte às duas ferramentas mais comuns para gerenciamento de dependências e testes, o [leiningen][leiningen] e a [Clojure CLI][clojure-cli].

Você vai encontrar um arquivo de teste chamado `hello_world_test.clj` dentro do diretório `test`.
Escreva seu código em `src/hello_world.clj`. Ele deve usar o namespace `hello-world` para que os testes o reconheçam.

### Rodando os testes com a Clojure CLI

```
$ clj -X:test
```

### Rodando os testes com o Leiningen

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Depois, envie o exercício usando:

```
$ exercism submit src/hello_world.clj
```

Para instruções mais detalhadas e recursos de aprendizado, consulte a [página da linguagem Clojure do Exercism][exercism-clojure].

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
