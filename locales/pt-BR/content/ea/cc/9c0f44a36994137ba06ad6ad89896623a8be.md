# Instruções

A Mecha Munch™, uma empresa de automação de compras de supermercado, acaba de contratar você para trabalhar no aplicativo de pedidos deles.
Sua equipe ficou encarregada de construir um MVP (_[produto mínimo viável][mvp]_) que gerencia todas as atividades básicas do carrinho de compras, permitindo que os usuários adicionem, removam e ordenem seus pedidos de supermercado.
Felizmente, outra equipe cuida de todas as funções de pagamento e finalização da compra!

## 1. Adicione item(ns) ao carrinho de compras do usuário

O MVP deve permitir que o usuário adicione itens ao carrinho de compras.
Pode ser um único item ou vários itens de uma vez.
Como este é um MVP, a quantidade de itens é indicada por _repetições_.
Se um usuário quiser adicionar 2 Oranges, 'Oranges' aparecerá duas vezes no iterável de entrada.
Se o usuário já tiver o item no carrinho, a quantidade no carrinho deve ser aumentada em 1.
Se o item for _novo_ no carrinho, ele deve ser adicionado com quantidade 1.

Crie a função `add_items!(<cart>, <items>)` que recebe como argumentos um dicionário de carrinho e um iterável de itens a adicionar.
Ela deve retornar o dicionário do carrinho de compras atualizado para o usuário.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. Atualize a seção de "ideias" de receitas

O gerente de projeto pediu que você criasse uma forma de editar essas receitas de "ideias", já que a equipe de conteúdo vive mudando ingredientes e quantidades.

Crie a função `update_recipes!(<ideas>, <updates>)` que recebe como argumentos um dicionário de "ideias" e um dicionário de atualizações de receitas.

## 3. Envie o carrinho de compras do usuário para a loja para separação

O aplicativo precisa enviar o carrinho de um determinado usuário para a loja para separação.
No entanto, os separadores da loja precisam saber onde o item pode ser encontrado, usando um código de corredor único.
O "carrinho de separação" precisa ser ordenado pela ordem dos códigos de corredor dos itens, para ajudar os separadores a serem mais eficientes.

Crie a função `send_to_store(<cart>, <aislecodes>)` que recebe um carrinho de compras do usuário e um dicionário com os números de corredor da loja.
A função deve retornar um "carrinho de separação" combinado, com um par `aislecode => quantity` para cada item que o cliente está pedindo.
Os itens devem aparecer na ordem dos seus códigos de corredor.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. Atualize o estoque da loja para refletir o que o usuário pediu.

O aplicativo não pode simplesmente fazer pedidos de clientes sem parar.
Em algum momento, a loja vai ficar sem vários produtos.
Por isso, o MVP do seu aplicativo precisa atualizar o estoque da loja toda vez que um usuário enviar o pedido para a loja.
Caso contrário, os clientes vão pedir produtos que não estão realmente disponíveis.

Crie a função `update_store_inventory!(<inventory>, <cart>)` que recebe um `cart` e um `inventory`.
A função deve reduzir as quantidades do estoque da loja pelo número "pedido" no "cart" e então retornar um dicionário com os itens que estão fora de estoque (ou seja, que chegaram a `0`).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Faça um novo pedido dos itens fora de estoque.

Além de atualizar o estoque, o seu aplicativo pode ajudar a repô-lo.
O seu MVP deve ser capaz de preparar um mini-pedido de qualquer item que esteja fora de estoque após o pedido de um cliente.
Isso vai ajudar a tornar mais simples o disparo de um pedido maior.
Além disso, às vezes há itens promocionais por tempo limitado que não estão na lista de estoque.
Se eles esgotarem antes do fim do período promocional, é sinal de que fizeram sucesso e podem ser adicionados à lista de estoque.

Crie a função `reorder!(<outofstock>, <stock>)` que recebe `outofstock` e `stock`.
O dicionário `stock` contém itens de estoque padrão e suas quantidades de reposição.
O dicionário `outofstock` é o resultado de `update_store_inventory!`, ou seja, um dicionário de itens com quantidade zero.
As quantidades em `outofstock` devem ser atualizadas para refletir as de `stock` e retornadas.
Além disso, qualquer item em `outofstock` que não esteja presente em `stock` deve ser adicionado a `stock` com uma quantidade padrão de `100`.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
