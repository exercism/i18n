# Introdução

## Comparações

Em C++, você pode comparar valores usando os operadores de comparação.

| Comparação        | Operador  |
| ------------------| --------- |
| igual             | `==`      |
| diferente         | `!=`      |
| menor             | `<`       |
| menor ou igual    | `<=`      |
| maior             | `>`       |
| maior ou igual    | `>=`      |

O resultado dessas comparações é sempre um valor Boolean:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Os operadores `==` e `!=` verificam se um valor é igual a outro ou não, respectivamente.
Veja alguns exemplos comuns:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Os outros operadores verificam se um valor é maior que (`>`), maior ou igual a (`>=`), menor que (`<`) ou menor ou igual a (`<=`) outro valor.
Esse tipo de comparação está disponível para números e strings.
Ao comparar strings, a ordem de dicionário (também conhecida como ordem lexicográfica) é seguida.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## Condicionais

As condicionais em C++ são parecidas com as condicionais de outras linguagens.
O tipo por trás de qualquer operação condicional é o tipo `bool`, que pode ter o valor `true` ou `false`.
As condicionais costumam ser usadas como mecanismos de controle de fluxo para verificar várias condições.

Você pode usar uma condicional `if`, que executa o código dela se a condição por trás for `true`, assim:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Em cenários com mais de um caso, várias condicionais `if` podem ser encadeadas usando as condicionais `else if` e `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Desde o C++17, as condicionais `if` também podem incluir uma instrução de inicialização curta, que pode ser usada para inicializar uma ou mais variáveis para a condicional `if`.
Por exemplo:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Observação: as variáveis criadas na inicialização não podem ser acessadas depois do fim da condicional `if`.
