# Debug

Como o test runner atual usa o [PonyTest](https://stdlib.ponylang.io/pony_test--index/), o actor Main fica em test.pony e não deve ser editado como parte da sua solução.

Como é boa prática em aplicações Pony, não damos acesso a `Env` a menos que seja necessário. Isso significa que, em quase todos os casos, você não consegue usar depuração no estilo printf com `env.out.print()`.

Porém, o Pony tem um módulo [debug](https://stdlib.ponylang.io/debug--index/) que permite que programas compilados com a flag `-d` tenham acesso especial a STDOUT e STDERR sem acesso a `Env`.

Se você precisar de depuração no estilo printf, use essa funcionalidade.

Exemplo de debug:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
