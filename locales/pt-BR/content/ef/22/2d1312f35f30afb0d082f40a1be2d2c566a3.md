# Dicas

## Geral

- Use `?` para trabalhar com os [pontos de código][codepoint] dos caracteres.
- `\s` pode ser usado para representar um espaço.
- Use a notação abreviada de [literal inteiro binário][integer-literal] para trabalhar com os códigos.
- Tente usar a estratégia de recursão de cauda.

## 1. Codifique o ácido nucleico em valor binário

- Essa função precisa mapear um inteiro para outro.
- Essa função não precisa de recursão.
- Usar funções com múltiplas cláusulas pode facilitar, dividindo o problema em partes.

## 2. Decodifique o valor binário para o ácido nucleico

- Essa função é o oposto da função da parte 1.
- Essa função não precisa de recursão.
- Usar funções com múltiplas cláusulas pode facilitar, dividindo o problema em partes.

## 3. Codifique uma charlist de DNA

- Crie uma função recursiva de cauda que pega um ponto de código da charlist e constrói recursivamente o resultado em bitstring.
- Funções recursivas de cauda precisam de um acumulador.
- Lembre-se: uma [charlist][charlist] é uma lista de [pontos de código inteiros][codepoint].
- Você pode obter o primeiro item e os restantes de uma lista usando uma função embutida do [módulo `Kernel`][kernel].
- Você também pode fazer pattern matching em uma lista usando a notação [`[head | tail]`][list].
- Use funções com múltiplas cláusulas para separar o caso base dos casos recursivos.
- Não esqueça de especificar os tipos dos segmentos de bitstring usando o operador `::`.

## 4. Decodifique uma bitstring de DNA

- Crie uma função recursiva de cauda que [faz pattern matching dos primeiros 4 bits][bitstring-matching] da [bitstring][bitstring] e constrói recursivamente o resultado em [charlist][charlist].
- Funções recursivas de cauda precisam de um acumulador.
- Lembre-se de que a [forma especial de bitstring][bitstring-form] pode ser usada para fazer pattern matching em bitstrings.
- Não esqueça de especificar os tipos dos segmentos de bitstring usando o operador `::`.
- Você vai precisar inverter o acumulador no final. Escreva uma função `reverse` privada e recursiva de cauda para fazer isso e use-a no caso base da função `decode`.
