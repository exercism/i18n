# Introdução

O Swift oferece um tipo embutido chamado [`Bool`][bools] para representar valores de verdade: `true` e `false`.

## Operadores lógicos

O Swift oferece três [operadores lógicos][logical-operators] (`!`, `&&` e `||`) para combinar e avaliar expressões Boolean.

### E lógico (`&&`)

O [operador _e_][and] (`&&`) retorna `true` somente se os dois operandos forem `true`.
Se um dos operandos for `false`, ele retorna `false`.
Coloque uma expressão ou um valor Boolean de cada lado do símbolo `&&`:

```swift
true && true  // true
true && false // false
```

### OU lógico (`||`)

O [operador _ou_][or] (`||`) retorna `true` se **pelo menos um** dos operandos for `true`.
Retorna `false` apenas quando os dois operandos são `false`.
Coloque uma expressão ou um valor Boolean de cada lado do símbolo `||`:

```swift
true || true   // true
true || false  // true
false || false // false
```

### NÃO lógico (`!`)

O [operador _não_][not] (`!`) inverte um valor Boolean.
Ele retorna `true` se o valor for `false`, e `false` se o valor for `true`.
Coloque o operador `!` imediatamente antes do valor ou da expressão:

```swift
!true  // false
!false // true
```

## Usando parênteses (`()`)

Você pode usar [parênteses][explicit-parentheses] para agrupar expressões e controlar a ordem de avaliação.
No Swift, as expressões dentro dos parênteses são avaliadas primeiro:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Agrupar com parênteses também determina como o operador NÃO se aplica a expressões complexas:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Use parênteses quando precisar deixar a ordem de avaliação mais clara ou tornar condições complexas mais fáceis de ler.
Evite adicionar parênteses desnecessários quando a precedência padrão já estiver clara.
~~~~
