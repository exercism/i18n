# Bools

Crystal tem um tipo conhecido como [`Bool`][bools].
Ele representa os valores `true` e `false`.

## Operadores lógicos

Crystal tem três operadores lógicos (`!`, `||`, `&&`), que combinam Bools e formam expressões que produzem valores diferentes.

### And(`&&`)

O [operador _and_][and] no Crystal é representado por `&&` e retorna `true` se os dois valores forem `true`; caso contrário, retorna `false`.
Ao usar o operador _and_, um Bool fica do lado direito do `&&` e o outro do lado esquerdo.

```crystal
true && true
# => true

true && false
# => false
```

### Or(`||`)

O [operador _or_][or] no Crystal é representado por `||` e retorna `true` se **pelo menos um** dos valores dados for `true`.
Se os dois valores forem `false`, ele retorna `false`.
Ao usar o operador _or_, um Bool deve ficar do lado direito do `||` e o outro do lado esquerdo.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not(`!`)

O operador _not_ no Crystal é representado por `!` e retorna `true` se o Bool dado for `false`, e retorna `false` se for fornecido `true`.
Ao usar o operador _not_, um Bool deve ficar depois do operador (`!`).

```crystal
!true
# => false

!false
# => true
```

## Usando parênteses(`()`)

Ao trabalhar com booleanos, você pode usar parênteses para decidir quais Bools avaliar primeiro.
O resultado pode variar dependendo de como os parênteses são usados.
No Crystal, o que está entre parênteses é avaliado primeiro.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Como o que está entre parênteses é avaliado primeiro, no exemplo a seguir o operador _not_ vai se aplicar à expressão dentro dos parênteses.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Use parênteses apenas quando eles afetarem o resultado; caso contrário, eles devem ser omitidos.
~~~~

## Truthy e falsey

No Crystal, os valores "falsey" são: `false`, `nil` e ponteiros nulos; **todo o resto** é "truthy".
Esses valores podem ser usados com os operadores lógicos mencionados acima.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## Convenções de nomenclatura de métodos com booleanos

No Crystal, é comum nomear com um ponto de interrogação (`?`) um método que retorna um valor truthy ou falsey.
Na maioria dos casos, esse método vai retornar um valor Bool, mas não precisa ser assim.
Isso significa que o método pode ser usado em lugares onde se espera um valor truthy ou falsey, por exemplo, como condição de um `if`:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

Métodos com um ponto de interrogação no fim do nome que não retornam um valor Bool geralmente retornam `nil` em vez disso. O `nil` é _parecido com `None` ou `null` de outras linguagens_.
