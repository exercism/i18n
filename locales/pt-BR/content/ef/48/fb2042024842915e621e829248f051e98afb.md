### Terminology

`Vector{T}` is an alias for arrays unidimensionais `Array{T, 1}`.

## Pairs

Um `Pair` é uma estrutura de dados que contém exatamente dois elementos, acessíveis pelos campos `first` e `second`.

Eles podem ser construídos usando `x => y`:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

Os elementos de um `Pair` podem ser de tipos diferentes:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

Os `Pair`s têm dois usos comuns em Julia: dicionários e substituições.

### Replacements

Muitos métodos de substituição recebem um `Pair` como argumento para deixar claro qual elemento está sendo substituído.
Isso permite uma sintaxe como

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

em que cada `4` da coleção é substituído por `0`, em vez da sintaxe menos clara

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
