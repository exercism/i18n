# Introdução

As exceções em C# oferecem uma forma estruturada, uniforme e com segurança de tipos de tratar condições de erro que acontecem em tempo de execução. Tratar exceções e erros da forma correta é importante na hora de tentar evitar que a aplicação trave.

Em C#, todas as exceções têm a classe `System.Exception` como tipo base. Ela contém propriedades importantes, como `Message`, que traz uma descrição legível por humanos do motivo pelo qual a exceção foi lançada.

Para sinalizar que deve haver um erro em uma determinada parte do código, é preciso criar um novo objeto de exceção e então lançá-lo, usando a palavra-chave `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Quando uma exceção é lançada, o tempo de execução tem a tarefa de encontrar um trecho de código responsável por tratar essa exceção. Se nenhum tratador adequado for encontrado, o tempo de execução exibe a mensagem de exceção não tratada e também interrompe a execução do programa.

Para criar um tratador para uma exceção, o C# usa a instrução try-catch, que consiste em um bloco `try` e uma ou mais cláusulas `catch`. O bloco `try` deve conter e proteger o código que pode fazer com que a exceção seja lançada. As cláusulas `catch` devem conter o código que trata o comportamento do programa depois que o erro aconteceu. É importante observar que a ordem das exceções importa depois do bloco `try`, pois, quando várias exceções estão listadas, a primeira cláusula `catch` correspondente é executada.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
