# Apêndice de instruções

## Instruções específicas da trilha

Historicamente, o Elm usava programação reativa funcional, até se especializar no uso da Elm Architecture.

Resolva este exercício como se você estivesse escrevendo um aplicativo web usando a Elm Architecture.
A saída do programa deve ser HTML com a seguinte estrutura

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

em que `<dl>` é o elemento de lista de descrição, `<dt>` é o elemento de termo de descrição e `<dd>` é o elemento de detalhes de descrição, todos elementos HTML padrão.

Se houver um erro, a saída deve ter a seguinte estrutura

```html
<div>
  <p>error message</p>
</div>
```
