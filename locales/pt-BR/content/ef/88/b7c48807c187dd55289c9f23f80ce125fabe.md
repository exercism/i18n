# Instruções complementares

## Dicas

Para completar este exercício, você precisa criar o tipo de dados `LinkedList`
e implementar as seguintes funções:

- `datum`
- `fromList`
- `isNil`
- `new`
- `next`
- `nil`
- `reverseLinkedList`
- `toList`

Você vai encontrar uma declaração de dados fictícia e as assinaturas de tipo já prontas,
mas cabe a você definir as funções e criar um tipo de dados, um newtype ou um sinônimo de tipo que faça sentido.
