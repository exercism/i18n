# Introdução

## `Base.@kwdef`

A macro `Base.@kwdef` pode ser usada para definir automaticamente construtores que recebem argumentos nomeados para a definição de uma [struct][struct].
Ela também permite definir valores padrão para os campos.

Por exemplo, a seguinte definição

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

define três construtores de uma só vez

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

incluindo um construtor baseado em argumentos nomeados

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

já a definição padrão

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

define apenas os dois construtores a seguir

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

e exigiria que você definisse manualmente um construtor baseado em argumentos nomeados.

### Quando usar `Base.@kwdef`?

Construtores baseados em argumentos nomeados são especialmente úteis para construir structs que recebem um grande número de argumentos, principalmente quando o tipo ou o valor dos argumentos não se relaciona diretamente com o significado deles.

Considere a seguinte definição:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

Não fica claro o que cada valor significa sem conhecer a definição do tipo.
E mesmo que você conheça a definição, provavelmente teria que consultar a ordem repetidas vezes.

Já ao usar um construtor baseado em argumentos nomeados, o significado deles fica imediatamente óbvio:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
`Base.@kwdef` não é exportada nem documentada no manual e, portanto, não faz parte da [API pública do Julia][public-api].
Isso significa que sua interface, tecnicamente, não tem garantia de estabilidade e pode mudar entre atualizações menores do Julia.

No entanto, a macro é amplamente usada em todo o ecossistema, e é improvável que ela mude de uma forma que quebre compatibilidade.

Para mais informações, veja:

- ["O que `@kwdef` faz?"][discourse-kwdef]
- [Issue #32659 do Julia para adicionar `@kwdef` ao Manual][add-kwdef-to-manual]
- [Issue #33192 do Julia para exportar `@kwdef`][export-kwdef]

~~~~
