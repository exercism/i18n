# Sobre

Tudo em Common Lisp é uma expressão.
Uma expressão é ou uma coisa única (chamada de átomo) ou uma lista de coisas (delimitada por parênteses: `()`).

## Citação

Todas as S-Expressions, como os símbolos, podem ser citadas:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Essa citação impede a avaliação de uma S-Expression e, em vez disso, a trata como dado.
Aqui está uma excelente [resposta do Stack Overflow][so-quoting] que discute a citação com um pouco mais de detalhe.
