# Dicas

## 1. Desloque os bits de volta
- O Crystal tem um [operador][shifts] para deslocar bits à esquerda.

## 2. Aplique uma máscara de bits
- O Crystal tem um operador [AND bit a bit][binary].

## 3. Ative alguns bits
- O Crystal tem um operador [OR bit a bit][binary].

## 4. Reverta o XOR
- Um XOR pode ser revertido aplicando um XOR sobre o mesmo valor.
- O Crystal tem operadores para [NOT bit a bit][not] e [XOR][xor] bit a bit.

[binary]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#binary
[not]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#other-unary-operators
[xor]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#binary
