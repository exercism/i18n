# Introdução

Os laços permitem repetir blocos de código. No Rust existem três tipos de laço: o laço `for`, que permite iterar sobre os elementos de um iterador ou de uma coleção (tecnicamente, os valores de qualquer tipo que implemente a trait `IntoIterator`); o laço `while`, que repete um bloco de código enquanto uma condição for satisfeita; e o laço `loop`, que repete o código indefinidamente até que um `break` seja invocado explicitamente.
