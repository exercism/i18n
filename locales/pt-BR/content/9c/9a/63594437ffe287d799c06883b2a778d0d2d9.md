# Instruções

A estação meteorológica de Wellington vai substituir seu sistema manual de registro de temperatura por um novo sistema digital.
No sistema antigo, os cálculos eram feitos manualmente.
No sistema novo, eles serão automatizados.
Entre os cálculos estão converter a temperatura de Celsius para Fahrenheit e encontrar a temperatura média.
O novo sistema tem sensores para registrar os dados de temperatura em Celsius.

A estação meteorológica de Wellington quer a sua ajuda com o sistema novo.

## 1. Converter a temperatura de Celsius para Kelvin

A estação meteorológica tem uma seção em seu site destinada aos pesquisadores.
Os pesquisadores se interessam pela temperatura em Kelvin.

Kelvin é uma unidade usada para medir temperatura.
Ela está na mesma escala que Celsius, mas com um ponto de partida diferente.
Seu ponto de partida é o zero absoluto, que é 0K (Kelvin) ou -273.15°C (Celsius).

Veja uma tabela que mostra a conversão entre Celsius e Kelvin:

| Celsius(°C) | Kelvin(K) |
| ----------- | --------- |
| -273.15     | 0         |
| -100        | 173.15    |
| 0           | 273.15    |
| 100         | 373.15    |

A estação meteorológica quer que você implemente um método que converta uma temperatura de Celsius para Kelvin.

Implemente o método `Temperature#to_kelvin`, que recebe um argumento `celsius` e retorna a temperatura em Kelvin somando 273.15 ao valor informado em `celsius`.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. Arredondar a temperatura

O sensor de temperatura da estação meteorológica é exato.
Ele consegue medir a temperatura com precisão de até 0.0001°C.
A estação meteorológica só quer exibir a temperatura arredondada para 1 casa decimal, já que a maioria dos usuários não se interessa por esse nível de precisão.

A estação meteorológica quer que você implemente um método que arredonde a temperatura para 1 casa decimal.

Implemente o método `Temperature#round`, que recebe um argumento `celsius` e retorna a temperatura arredondada para 1 casa decimal.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. Converter a temperatura de Celsius para Fahrenheit

A estação meteorológica tem uma seção em seu site destinada aos turistas.
Os turistas se interessam pela temperatura em Fahrenheit.

Fahrenheit é uma unidade de medida de temperatura.
Ela tem uma escala diferente da de Celsius.
0°C é 32°F, e 1 grau Celsius equivale a 1.8 graus Fahrenheit.

Veja uma tabela que mostra a conversão entre Celsius e Fahrenheit:

| Celsius(°C) | Fahrenheit(°F) |
| ----------- | -------------- |
| -273.15     | -459.8         |
| -100        | -148            |
| 0           | 32             |
| 100         | 212            |

A estação meteorológica quer que você implemente um método que converta temperaturas de Celsius para Fahrenheit.

Implemente o método `Temperature#to_fahrenheit`, que recebe um argumento `celsius` e retorna a temperatura em Fahrenheit como um número inteiro.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. Obter o número de sensores que faltam

Durante a instalação dos sensores de temperatura, os funcionários da manutenção perceberam que alguns sensores estavam faltando.
Cada unidade de medição de temperatura precisa de quatro sensores de temperatura.
A equipe de manutenção contou quantos sensores tinha, mas precisava saber quantos estavam faltando.
Eles gostariam de ajuda para contar quantos sensores precisam comprar para montar outra unidade completa de medição de temperatura.

Implemente o método `Temperature#number_missing_sensors`, que recebe um argumento `number_of_sensors` e retorna o número de sensores que faltam.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
