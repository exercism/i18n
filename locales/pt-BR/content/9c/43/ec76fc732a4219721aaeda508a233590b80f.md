# Introdução

Os arrays, ou vetores, são o principal tipo de sequência de comprimento fixo do Factor, escritos com `{ … }`: você pode mudar os elementos, mas não o comprimento. Os vocabulários `arrays` e `sequences` juntos oferecem a você pequenos construtores que retiram valores da pilha, além de operações do dia a dia para juntar, inverter e buscar elementos.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```
