# use o @moduledoc

[comment]: # (Este erro é gerado quando a solução não tem @moduledoc no módulo)

Recomendamos que você tenha um atributo [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) para descrever a intenção do módulo.

- No Elixir, a documentação é um [cidadão de primeira classe](https://hexdocs.pm/elixir/writing-documentation.html). A documentação do Elixir foi pensada para ser fácil de ler e de escrever.
- A sintaxe Markdown é aceita dentro dos atributos de documentação `@moduledoc` e `@doc`
