# Introdução

Em Go, toda variável tem um valor.
Quando você declara uma variável sem atribuir um valor, ela recebe o valor zero do seu tipo.

Os tipos básicos, incluindo `bool`, os tipos numéricos e `string`, têm cada um um valor zero fixo:

| Tipo                   | Valor zero |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64, etc. | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

Ponteiros, funções, interfaces, slices, canais e mapas têm como valor zero o `nil`.

Arrays e structs nunca são `nil`, porque guardam os dados diretamente, e não uma referência a eles.
Cada elemento de um array e cada campo de uma struct é inicializado com o valor zero do seu próprio tipo.
Por exemplo, `var a [3]int` cria o array `[0, 0, 0]`.

## Declarando valores zero

Use `var` para uma declaração:

```go
var myBool bool   // false
var mySlice []int // nil
```

Use um literal composto `T{}` para structs:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
