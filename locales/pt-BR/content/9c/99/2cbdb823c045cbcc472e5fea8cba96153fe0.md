# evite literais de caractere

Verifique se as letras são diferentes, independentemente de quais sejam.
Esta solução usa literais de caractere (por exemplo, `'T'`), mas eles não são necessários para este exercício.
Embora a descrição mencione o caso de uso dos nucleotídeos de DNA, você pode calcular a distância de Hamming para quaisquer duas strings de mesmo comprimento.
