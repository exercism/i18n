# Anexo às instruções

## Implementação

Neste exercício, você vai implementar um procedimento que deve alocar a string que retorna. Desalocar a string é responsabilidade de quem chama o procedimento.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
