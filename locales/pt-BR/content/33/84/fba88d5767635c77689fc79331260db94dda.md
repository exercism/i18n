# Instruções

É a final da temporada no clube local. Você está cuidando do
placar na linha de chegada: os corredores cruzam em ordem, as
raias precisam de rótulos, e o registro oficial tem que ser
anotado antes da próxima bateria.

Os nomes dos corredores chegam em um array, na ordem de
chegada: o nome de índice 0 é o vencedor, o de índice 1 é o
segundo colocado, e assim por diante.

## 1. Atribua os números de peito

Defina `assign-bibs` para receber um array de nomes de corredores
e retornar um array de pares `{ position name }`, com a posição
primeiro.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Rótulos das raias

Defina `lane-labels` para receber um array de nomes de corredores
e retornar strings como `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. Marque os corredores

Defina `tag-racers` para receber um array de nomes de corredores
*e* uma string de etiqueta, retornando rótulos no formato
`"<tag>/<index>: <name>"`. A mesma etiqueta fica embutida em
todos os rótulos.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. Registre as chegadas

Defina `record-finishes` para receber um array de nomes de
corredores e um registro (um vetor). Para cada corredor,
acrescente ao registro, no próprio local, uma string no formato
`"<index>: <name>"`. Não retorna nada.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Sinos de volta

Defina `lap-bells` para receber um número `laps` e retornar uma
string feita de `"ding "` repetido `laps` vezes.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
