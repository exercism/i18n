# Sobre

Jai é uma linguagem de sistemas projetada e construída pelo lendário desenvolvedor de jogos Jonathan Blow. Ela surgiu da frustração com a sobrecarga e a complexidade das linguagens existentes.

Os principais objetivos de design de Jai são velocidade e produtividade. O compilador é incrivelmente rápido e os binários gerados são bem enxutos, com um runtime mínimo.

Um dos recursos de destaque de Jai é o suporte a metaprogramação. Você tem acesso a todos os dados que o compilador usa internamente e pode manipulá-los como quiser. Jai vai até um passo além: ele permite que você rode código Jai arbitrário em _tempo de compilação_!

Como o próprio sistema de build é inteiramente escrito em Jai, não há necessidade de aprender uma ferramenta de build separada: você só escreve código Jai para acessar o sistema de build.

Jai foi desenvolvida para ajudar a construir o jogo Order of the Sinking Star; por isso, você vai perceber que Jai é ideal para criar jogos.
