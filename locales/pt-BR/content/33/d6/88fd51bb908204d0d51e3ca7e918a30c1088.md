# Introdução

O Zebra Puzzle é um famoso quebra-cabeça de lógica com cinco casas, cada uma pintada de uma cor diferente.
As casas têm moradores diferentes, que têm nacionalidades diferentes, criam animais de estimação diferentes, bebem bebidas diferentes e fumam marcas diferentes de cigarros.

Para ajudar você a resolver o quebra-cabeça, são dadas 15 afirmações que descrevem a solução.
No entanto, só combinando as informações de _todas_ as afirmações você conseguirá encontrar a solução do quebra-cabeça.

~~~~exercism/note
O Zebra Puzzle é um [problema de satisfação de restrições (CSP)][constraint-satisfaction-problem].
Nesse tipo de problema, você tem um conjunto de valores possíveis e um conjunto de restrições que limitam quais valores são válidos.
Outro CSP bastante conhecido é o Sudoku.

[constraint-satisfaction-problem]: https://en.wikipedia.org/wiki/Constraint_satisfaction_problem
~~~~
