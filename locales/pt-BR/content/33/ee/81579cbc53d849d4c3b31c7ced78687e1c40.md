# Instruções

Neste exercício, você vai escrever código para acompanhar uma lista de linguagens de programação que quer aprender no Exercism.

Você tem nove tarefas, e todas elas envolvem lidar com listas.

## 1. Criar uma nova lista

Para acompanhar as linguagens que você quer aprender, você vai precisar criar uma nova lista.

Implemente o método estático `Languages.NewList()` que retorna uma nova lista vazia.

```csharp
Languages.NewList()
// => empty list
```

## 2. Definir uma lista existente

No momento, você tem um pedaço de papel listando as linguagens que quer aprender: C#, Clojure e Elm.

Implemente o método estático `Languages.GetExistingLanguages()` para retornar a lista.

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. Adicionar uma nova linguagem a uma lista

Conforme você explora o Exercism e encontra linguagens mais interessantes, você quer adicioná-las à sua lista.

Implemente a função estática `Languages.AddLanguage()` para adicionar uma nova linguagem ao final da sua lista.

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. Contar as linguagens na lista

Contar as linguagens uma a uma é inconveniente.

Implemente o método estático `Languages.CountLanguages()` para contar quantas linguagens há na sua lista.

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. Verificar se uma linguagem está na lista

Implemente o método estático `Languages.HasLanguage()` para verificar se uma linguagem está presente.

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. Inverter a lista

Em algum momento, você percebe que sua lista na verdade está em ordem inversa!

Implemente o método estático `Languages.ReverseList()` para inverter a sua lista.

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. Verificar se a lista é empolgante

Embora você ame todas as linguagens, C# tem um lugar especial no seu coração. Por isso, você fica realmente empolgado com uma lista de linguagens se uma das seguintes condições for verdadeira:

- O primeiro item da lista é C#.
- O segundo item da lista é C# e a lista contém duas ou três linguagens.

Implemente o método estático `Languages.IsExciting()` para verificar se uma lista de linguagens é empolgante:

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.Remover linguagem

Implemente o método estático `Languages.RemoveLanguage()` para remover uma linguagem específica da lista.

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. Verificar se todas as linguagens da lista são únicas

Implemente o método estático `Languages.IsUnique()` para verificar se alguma das linguagens se repete na lista.

A lista de linguagens (ou seja, o parâmetro) tem garantia de não estar vazia quando esse método é chamado, e não importa se a lista for modificada.

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
