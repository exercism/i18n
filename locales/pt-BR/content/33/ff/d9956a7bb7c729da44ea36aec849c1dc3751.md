# Testes

Para baixar um exercício, por exemplo `hello-world`, abra um terminal e rode:

```bash
exercism download --track roc --exercise hello-world
```

Depois vá até o diretório do exercício e edite o código para resolver o exercício. Por exemplo:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

Cada exercício vem com uma suíte de testes. Você pode rodar os testes com o comando `roc test`, por exemplo:

```
roc test hello-world-test.roc
```

Se você resolveu o exercício, deve ver 0 testes com falha, por exemplo:

```
All (5) tests passed in 123.4 ms.
```

Mas se o seu código tiver algum erro, ele vai aparecer assim:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

Isso deve ajudar você a corrigir o código. Quando o seu código funcionar, você pode enviá-lo com o comando `exercism submit` (veja o `HELP.md` no diretório do exercício para mais detalhes).
