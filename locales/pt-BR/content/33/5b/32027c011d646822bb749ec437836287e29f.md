# Import

A [forma especial `import`][import] permite usar funções e macros de um módulo externo sem usar o nome do módulo.

Importar um módulo externo inteiro pode criar conflitos com as funções locais que já existem. Para evitar isso, há duas opções: `:except` e `:only`. As duas esperam uma lista de palavras-chave, em que a chave é o nome da função e o valor é a aridade da função.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

Normalmente, os imports são adicionados no começo da definição do módulo, mas podem ser adicionados em qualquer lugar. Eles têm escopo lexical. Isso significa que um import adicionado dentro da definição de uma função não ficará disponível em outra função.

Imports não utilizados geram avisos do compilador.

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
