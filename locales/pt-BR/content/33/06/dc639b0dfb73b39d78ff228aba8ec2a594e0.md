# Sobre

Uma [`list`][lists] em F# é uma coleção imutável de zero ou mais valores. Todos os valores de uma lista precisam ter o mesmo tipo. Como as listas são imutáveis, depois que uma lista é construída, seu valor nunca pode mudar. Uma lista em F# tem uma _cabeça_ (o primeiro elemento) e uma _cauda_ (tudo o que vem depois do primeiro elemento). A cauda de uma lista é ela mesma uma lista.

As listas podem ser definidas assim:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

A forma mais comum de adicionar um elemento a uma lista é com o operador `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

É possível concatenar listas com o operador `@` ou com `List.append`:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

As listas são manipuladas por funções e operadores definidos no [módulo `List`][list-module]. Algumas dessas funções também estão disponíveis como [propriedades][list-properties] de uma instância de `list`:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

Não existe opção certa ou errada aqui. Em geral, as funções do módulo `List` se dão melhor com inferência de tipos, enquanto as propriedades permitem um código mais conciso.

Qualquer função ou operador que pareça modificar uma lista (como adicionar um elemento) na verdade retorna uma nova lista. O desempenho geralmente não é um problema, porque a implementação das listas evita alocações e cópias desnecessárias.

Como as listas são implementadas como listas simplesmente encadeadas, adicionar um elemento no início (com o operador `::`) é muito rápido, enquanto acessar um elemento por índice pode ser relativamente lento.

Também é possível processar listas com correspondência de padrões, usando os padrões [_list_][list-pattern] e [_cons_][cons-pattern]:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Você também pode _descartar_ um valor durante a correspondência de padrões; quando você _não_ se importa com um valor em um caso específico (ou seja, você não vai _usar_ o valor), você pode usar um sublinhado (`'_'`) para indicar isso:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

O `'_'` sozinho deve sempre vir _por último_ na correspondência de padrões, pois todo valor que _não_ corresponder a nenhum dos outros casos será tratado por esse caso.
