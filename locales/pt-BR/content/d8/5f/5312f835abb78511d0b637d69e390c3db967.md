# Título de nível superior fictício

## Números em Euphoria

Em Euphoria, um `atom` pode guardar qualquer tipo de número, e o subtipo `integer` é reservado para números inteiros.

Em linguagens de estilo C, é possível resolver este exercício retornando um número inteiro sem sinal de 64 bits.

No entanto, os inteiros em Euphoria têm sinal e são _um bit menores que a palavra da máquina_, o que os torna pequenos demais para este exercício, enquanto os atoms conseguem guardar inteiros maiores, com os 64 bits de precisão necessários.

### 32 bits

Existe uma versão de 32 bits do Euphoria, que continua existindo para que aplicações legadas possam continuar usando dll/so de 32 bits pré-compiladas quando não há uma versão de 64 bits disponível, ou quando o wrapper para elas está cheio de deslocamentos de 32 bits fixos no código.
Essa versão é totalmente inadequada para resolver esta tarefa, já que esses atoms têm apenas 53 bits de precisão.
Se você estiver com dificuldade para resolver este exercício localmente, verifique se está usando uma versão de 64 bits do Euphoria.
