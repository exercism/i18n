# Instruções

Você recebeu a tarefa de trabalhar mais um pouco no sistema de autenticação de rede.

Além de a identidade do admin estar fixa no código do sistema durante o desenvolvimento, quem manda também quer que os desenvolvedores sênior recebam o mesmo tratamento.

## 1. Guarde os dados do admin do sistema fixos no código e deixe-os disponíveis para quem chama.

Os dados do admin são os seguintes:

| Email        | Cor dos olhos | Largura do filtro labial | Nome     | Endereço 1 | Endereço 2 |
| ------------ | ------------- | ------------------------ | -------- | ---------- | ---------- |
| admin@ex.ism | green     | 0.9            | Chanakya | Mumbai    | India     |

Implemente a propriedade `Authenticator.Admin` para retornar os dados de identidade do admin do sistema. O nome e cada parte do endereço devem ficar em um elemento separado da lista `NameAndAddress`.

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. Guarde os dados dos desenvolvedores fixos no código do sistema e deixe-os disponíveis na forma de um dicionário

Os dados dos desenvolvedores são os seguintes:

| Email         | Cor dos olhos | Largura do filtro labial | Nome     | Endereço 1 | Endereço 2 |
| ------------- | ------------- | ------------------------ | -------- | ---------- | ---------- |
| bert@ex.ism   | blue      | 0.8            | Bertrand | Paris     | France    |
| anders@ex.ism | brown     | 0.85           | Anders   | Redmond   | USA       |

Implemente a propriedade `Authenticator.Developers` para retornar os dados de identidade dos desenvolvedores. A chave do dicionário é o nome do desenvolvedor.

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
