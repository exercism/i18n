# Introdução

Common Lisp oferece várias expressões condicionais diferentes; a principal diferença entre elas é o número de bifurcações que aceitam.

- `when` e `unless` permitem uma única bifurcação:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

A seção depois da expressão de teste pode ter mais de uma expressão.

- `if` fornece a clássica construção if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Repare que tanto a cláusula `then` quanto a `else` só podem ser uma única expressão.

- `cond` permite ter várias bifurcações sem aninhar expressões `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Repare que não há limite para o número de expressões depois da expressão de teste.

- `case` fornece uma construção clássica no estilo "switch": ela compara um único valor com várias bifurcações:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Repare que, assim como em `cond`, não há limite para o número de expressões depois da expressão de teste.
