# Dicas

## Geral

- Endereços x86-64 na memória são números de 64 bits (8 bytes).
- Você deve usar `rel` para formar endereços relativos válidos na memória.

## 1. Obter o valor RGB de uma cor

- Endereços x86-64 na memória são números de 64 bits (8 bytes).
- Você deve usar `rel` para formar endereços relativos válidos na memória.
- Para acessar o conteúdo armazenado em um endereço na memória, você precisa desreferenciá-lo usando `[]`.
- Inteiros de 32 bits (4 bytes) são retornados em `eax`.

## 2. Adicionar a cor base

- Endereços x86-64 na memória são números de 64 bits (8 bytes).
- Você deve usar `rel` para formar endereços relativos válidos na memória.
- Variáveis inicializadas são definidas em _section .data_.
- Uma variável precisa ser declarada `global` para ser visível a outros arquivos-fonte.
- Você pode reutilizar a função `get_color_value` já implementada.

## 3. Definir constantes para as cores primárias

- Endereços x86-64 na memória são números de 64 bits (8 bytes).
- Você deve usar `rel` para formar endereços relativos válidos na memória.
- Constantes inicializadas são definidas em _section .rodata_.
- Uma constante precisa ser declarada `global` para ser visível a outros arquivos-fonte.

## 4. Combinar cores

- Endereços x86-64 na memória são números de 64 bits (8 bytes).
- Você deve usar `rel` para formar endereços relativos válidos na memória.
- Para acessar o conteúdo armazenado em um endereço na memória, você precisa desreferenciá-lo usando `[]`.
- Uma função ou um dado externo precisa ser declarado `extern` na seção correspondente.
- Uma função externa pode modificar qualquer um dos registradores usuais que você esteja usando, então você precisa salvar as variáveis na memória antes de chamá-la.
- `combining_function` recebe o valor de 32 bits (não o endereço) da cor base em `rdi` e o valor de 32 bits (não o endereço) da cor secundária em `rsi`.
