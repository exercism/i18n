# Instruções

Você vai escrever um código para gerenciar o placar de um jogo.
O placar será um hash chamado `%HighScoreBoard::Scores`.
As chaves do hash serão os nomes dos jogadores, e os valores serão as pontuações deles.

## 1. Definir a pontuação de um jogador no hash %Scores

Modifique a sub-rotina `HighScoreBoard::set_player_scores`, que recebe nomes de jogadores e pontuações como argumentos, para definir as pontuações dos jogadores no hash `%HighScoreBoard::Scores`.

## 2. Obter a pontuação de um jogador no hash %Scores

Modifique a sub-rotina `HighScoreBoard::get_player_score`, que recebe um nome de jogador como argumento, para retornar a pontuação do jogador no hash `%HighScoreBoard::Scores`.

## 3. Aumentar a pontuação de um jogador no hash %Scores

Modifique a sub-rotina `HighScoreBoard::increase_player_scores`, que recebe nomes de jogadores e pontuações como argumentos, para aumentar as pontuações dos jogadores no hash `%HighScoreBoard::Scores` pela pontuação informada.

## 4. Ordenar os jogadores no hash %Scores pelo nome

Modifique a sub-rotina `HighScoreBoard::sort_players_by_name` para retornar os nomes dos jogadores no hash `%HighScoreBoard::Scores` ordenados pelo nome.

## 5. Ordenar os jogadores no hash %Scores pela pontuação

Modifique a sub-rotina `HighScoreBoard::sort_players_by_score` para retornar os nomes dos jogadores no hash `%HighScoreBoard::Scores` ordenados pela pontuação.

## 6. Excluir um jogador do hash %Scores

Modifique a sub-rotina `HighScoreBoard::delete_player`, que recebe um nome de jogador como argumento, para excluir o jogador do hash `%HighScoreBoard::Scores`.
