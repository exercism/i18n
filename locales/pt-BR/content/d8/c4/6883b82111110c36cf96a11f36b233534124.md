# Apêndice de instruções

## Formato da saída

Exiba as plantas do estudante como uma string, usando uma vírgula e um espaço como separadores.

## Memória reservada

O buffer da string do diagrama usa os bytes 1024-2047 da memória linear.
O buffer da string do estudante usa os bytes 2048-3071 da memória linear.

As strings de entrada podem ser modificadas no próprio lugar, se você quiser.
