# Instruções

Você está fazendo trilha na Nova Zelândia e tomando marcações com uma bússola. Uma marcação é um número inteiro de graus e é um valor: girar 20 graus não muda a marcação que você tomou, apenas dá outra.

Escreva uma `immutable class BEARING`. O código inicial já traz o cabeçalho da classe e o atributo dela.

## 1. Tomar uma marcação

`create` recebe um número de graus e retorna uma marcação. Os graus vão de 0 a 359, então qualquer valor fora disso dá a volta: 370 é 10, e -10 é 350.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. Girar

`turned` recebe um número de graus para girar e responde com a nova marcação. Girar com um número negativo gira para o outro lado. A marcação sobre a qual o método foi chamado não muda.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. Comparar

`is_eq` recebe outra marcação e responde se as duas são iguais. Depois que ele existe, o `=` funciona com marcações.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. Nomear o ponto

`point` responde o ponto cardeal mais próximo da marcação, como um destes: `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"`.

Cada ponto cobre 45 graus, centrado na marcação exata dele: o norte vai de 337,5 passando por 0 até 22,5, o nordeste vai de 22,5 a 67,5, e assim por diante. Como as marcações aqui são números inteiros, uma marcação de 22 é `"N"` e 23 é `"NE"`.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. Anotar

`str` responde os graus e o ponto, assim: `"90 degrees (E)"`.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
