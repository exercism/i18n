# Instruções

Neste exercício, você está jogando um jogo de RPG em que diferentes tipos de lutadores podem combater uns aos outros.
O jogo tem regras diferentes para cada tipo de lutador.
Vamos nos concentrar em dois tipos específicos: Magos e Guerreiros.

Para um Guerreiro, as regras são estas:

- Um Guerreiro nunca é vulnerável.
- Um Guerreiro causa `6` pontos de dano se o lutador que ele está atacando não for vulnerável.
- Um Guerreiro causa `10` pontos de dano se o lutador que ele está atacando for vulnerável.

Para um Mago, as regras são estas:

- Um Mago pode preparar uma magia com antecedência.
- Um Mago é vulnerável a menos que tenha preparado uma magia com antecedência.
- Um Mago causa `12` pontos de dano se tiver preparado uma magia com antecedência.
- Um Mago causa `3` pontos de dano se não tiver preparado uma magia com antecedência.

## 1. Crie a classe Warrior

Crie uma nova classe chamada `Warrior`.
Essa classe deve herdar da classe `Fighter` existente.

## 2. Descreva um Guerreiro

Atualize a classe `Warrior` para que seu método `toString()` descreva que tipo de lutador ele é.
O método deve retornar a string `"Fighter is a Warrior"`.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Torne os Guerreiros invulneráveis

Atualize a classe `Warrior` para que seu método `isVulnerable()` sempre retorne `false`.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Calcule os pontos de dano de um Guerreiro

Atualize a classe `Warrior` para que seu método `getDamagePoints(Fighter)` calcule o dano causado por um Guerreiro de acordo com as regras acima.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Crie a classe Wizard

Crie outra nova classe chamada `Wizard`.
Essa classe também deve herdar da classe `Fighter` existente.

## 6. Descreva um Mago

Atualize a classe `Wizard` para que seu método `toString()` descreva que tipo de lutador ele é.
O método deve retornar a string `"Fighter is a Wizard"`.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Permita que os Magos preparem uma magia e os torne vulneráveis quando não tiverem preparado uma magia

Atualize a classe `Wizard` para adicionar um método chamado `prepareSpell()`.
A classe deve se lembrar de quando esse método é chamado e garantir que seu método `isVulnerable()` retorne `false` apenas quando uma magia estiver preparada.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Calcule os pontos de dano de um Mago

Atualize a classe `Wizard` para que seu método `getDamagePoints(Fighter)` calcule o dano causado por um Mago de acordo com as regras acima.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
