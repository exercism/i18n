# Introdução

A classe `TimeZoneInfo` fornece rotinas para lidar com as diferenças entre fusos horários. A classe `TimeZoneInfo` também contém métodos que facilitam lidar com o horário de verão.

A classe `CultureInfo` dá suporte a formatos de data e hora que dependem da localidade.

Para dar suporte à programação multiplataforma, a classe `RuntimeInformation` permite detectar em qual sistema operacional o seu código está rodando: Linux, Windows ou OSX.
