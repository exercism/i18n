# Instruções

Converta um número hexadecimal, representado como uma string (por exemplo, "10af8c"), para o seu equivalente decimal usando os princípios fundamentais (ou seja, não, você não pode usar bibliotecas nativas ou externas para fazer a conversão).

Na web, usamos hexadecimal para representar cores, por exemplo, verde: 008000, verde-azulado: 008080, azul-marinho: 000080).

O programa deve saber lidar com strings hexadecimais inválidas.
