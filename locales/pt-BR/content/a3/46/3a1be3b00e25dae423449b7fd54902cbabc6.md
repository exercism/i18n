## Geral

- [Tutorial sobre como trabalhar com enums][java-tutorial-enum-types].

## 1. Interpretar o nível de log

- Existe um [método para obter uma parte de uma string][java-docs-substring].
- Você pode usar uma [instrução `switch`][java-tutorial-switch-statement] para lidar com os diversos níveis de log de forma elegante.

## 2. Dar suporte a um nível de log desconhecido

- Existe um caso especial do `switch`, chamado `default`, que pode ser usado para capturar casos não especificados.

## 3. Converter a linha de log para o formato curto

- Você pode adicionar campos e métodos a um tipo enum; veja o [tutorial sobre como trabalhar com enums][java-tutorial-enum-types].
