# Instruções

Neste exercício, você vai implementar mecânicas de um jogo de RPG.
A personagem de um jogador é representada pelo seguinte tipo:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

Os jogadores deste jogo precisam alcançar o nível 10 antes de desbloquear uma reserva de mana para poderem começar a conjurar feitiços.
Você vai trabalhar em duas funcionalidades deste jogo: a mecânica de reviver e a mecânica de conjuração de feitiços.

## 1. Apresente-se

Escreva o conteúdo da função `introduce`.
Repare que o campo `Name` do registro `Player` é uma `Option`.
Os jogadores mais furtivos podem querer esconder o nome deixando-o definido como `None`; esses jogadores serão apresentados como `"Mighty Magician"`.
Caso contrário, use apenas o seu nome para se apresentar.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Implemente a mecânica de reviver

A função `revive` deve verificar que a personagem do jogador está de fato morta (a vida dela chegou a 0).
Se estiver, ela deve retornar uma nova instância de `Player` com 100 de vida.
Caso contrário, se a personagem do jogador não estiver morta, a função `revive` retorna `None`.

Se o nível do jogador for 10 ou mais, ele também deve ser revivido com 100 de mana.
Se o nível do jogador for inferior a 10, sua mana deve ser `None`.
A função `revive` deve preservar o nível do jogador.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Se o método `revive` for chamado para um jogador cuja vida é 1 ou mais, a função deve retornar `None`.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Implemente a mecânica de conjuração de feitiços

A função `castSpell` recebe como argumentos um `int` indicando quanta mana o feitiço custa, além de um `Player`.
Ela retorna o jogador atualizado, bem como a quantidade de dano que o feitiço conjurado causa.
Uma conjuração de feitiço bem-sucedida causa dano igual a duas vezes o custo de mana do feitiço.
No entanto, se o jogador tiver mana insuficiente, nada acontece: o jogador permanece inalterado e nenhum dano é causado.
Se o jogador não tiver nem uma reserva de mana, a tentativa de conjurar o feitiço deve diminuir sua vida no valor do custo de mana do feitiço e não causa dano.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
