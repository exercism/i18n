# Sobre

As [strings][getting-started-strings] no Elixir são delimitadas por aspas duplas e codificadas em UTF-8:

```elixir
"Hi!"
```

As strings podem ser concatenadas com o operador [`<>/2`][kernel-concat]:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

As strings no Elixir aceitam [interpolação][string-interpolation] com a sintaxe `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Qualquer expressão do Elixir é válida dentro da interpolação. Se o valor for uma string, ela é interpolada como está. Se for qualquer outro valor, o Elixir tenta convertê-lo em string.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

O Elixir traz muitas funções para trabalhar com strings no módulo `String`. Se você não sabe como processar uma string do jeito que precisa, não deixe de explorar as [funções disponíveis no módulo `String`][string-module-functions] e é bem provável que você encontre o que procura.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

Ao usar algumas dessas funções, lembre-se de que o primeiro caractere de uma string tem o índice `0`.

Alguns caracteres precisam ser [escapados][escape-characters] para entrar em uma string, como quebras de linha, aspas duplas ou o caractere `#`:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

Para trabalhar com tranquilidade com textos que têm muitas quebras de linha, use a [sintaxe de heredoc com três aspas duplas][heredoc-syntax]:

```elixir
"""
1
2
3
"""
```

Você vai encontrar essa sintaxe com muita frequência na documentação de código:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
