# Introdução

## Strings

As strings em Elixir são delimitadas por aspas duplas e codificadas em UTF-8:

```elixir
"Hi!"
```

As strings podem ser concatenadas com o operador `<>/2`:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

As strings em Elixir aceitam interpolação com a sintaxe `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Para colocar um caractere de nova linha em uma string, use o código de escape `\n`:

```elixir
"1\n2\n3\n"
```

Para trabalhar confortavelmente com textos que têm muitas quebras de linha, use a sintaxe heredoc de aspas triplas duplas:

```elixir
"""
1
2
3
"""
```

O Elixir oferece muitas funções para trabalhar com strings no módulo `String`.

## Operador pipe

O operador `|>` é chamado de operador pipe. Ele pode ser usado para encadear chamadas de função de modo que o valor retornado pela chamada anterior seja passado como primeiro argumento para a próxima chamada.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
