# Introdução

## Importação

A biblioteca padrão do Swift oferece muitos recursos, mas você pode acessar funcionalidades adicionais importando bibliotecas e frameworks externos.
Esses módulos podem vir diretamente do projeto Swift (como o [Swift Argument Parser][argument-parser]), de frameworks da plataforma Apple (como o [Foundation][apple-foundation] e o [Network Framework][network-framework]) ou de bibliotecas de código aberto de terceiros (como o [SwiftyBeaver][swifty-beaver]).

Módulos principais como o Foundation, uma das bibliotecas mais usadas do Swift, já vêm com o conjunto de ferramentas do Swift.
Bibliotecas de terceiros precisam ser adicionadas à configuração do seu projeto (por exemplo, usando o Swift Package Manager) antes de poderem ser importadas.

A importação de módulos é feita escrevendo a palavra-chave `import` seguida do nome do módulo.
Assim, dá para importar o Foundation adicionando o seguinte ao seu programa.

```swift
import Foundation
```

Importar um módulo deixa os tipos, métodos e funções dele disponíveis para o seu código.
Por exemplo, importar o Foundation estende o `String` com métodos utilitários úteis, como `components(separatedBy:)`.

Por convenção, as instruções `import` ficam no topo do arquivo Swift, para que as dependências sejam visíveis de imediato para quem lê o código.

## Indexação de strings

Você pode acessar caracteres individuais de uma `String` usando o método de subscrito que se usa com arrays.
No entanto, os [índices][string-indices] usados para strings _não_ são inteiros e não podem ser usados diretamente.
Em vez disso, eles precisam ser calculados a partir de algum outro índice conhecido, como `startIndex`, que aponta para a posição do primeiro caractere em uma string não vazia, usando os métodos disponíveis nas bibliotecas [`String`][string-docs] e [`NSString`][nsstring-docs] (quando o módulo `Foundation` é importado, as strings em Swift têm acesso a todas as propriedades e métodos do NSString).

Por exemplo, dada a seguinte string:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Não dá para escrever `csv[21]` para obter o "g" de "orange"; em vez disso, é preciso calcular um valor do tipo `String.Index` e passar esse índice.
Repare que esses índices não foram feitos para serem consumidos por humanos diretamente.
Eles são o que se chama de _índices opacos_, já que os humanos não precisam saber o que há dentro deles.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Repare, porém, que se o deslocamento não for um índice válido, ou seja, se ele retornar o índice antes de `startIndex` ou depois de `endIndex`, a operação vai gerar um erro e derrubar o programa.
Para evitar esse problema, dá para especificar um índice limite.
Isso retorna um índice opcional e devolverá nil para índices que de outra forma seriam inválidos.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Além disso, índices não podem ser compartilhados entre strings.
Por exemplo, usar o `index` do "g" em "orange" calculado acima para indexar a string `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, ou seja, `fam[index]`, vai derrubar o programa.

Há muitos motivos para tudo isso, mas basicamente todos se resumem a "Unicode é complicado".

De modo geral, se você precisa de acesso aleatório a caracteres individuais, provavelmente é melhor usar outra estrutura de dados, como `Array<Character>`.

### Alguns métodos úteis

O Swift tem os métodos `first` e `last` para obter o primeiro e o último caractere de uma string.
Esses métodos retornam um caractere opcional, então, se a string estiver vazia, eles retornam nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Você também pode usar os métodos `prefix` e `suffix` para obter uma substring de uma string.
Esses métodos recebem um inteiro como argumento e retornam uma substring com os primeiros ou os últimos n caracteres da string.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Métodos de string

Trabalhar com texto é uma tarefa comum em programação.
O Swift, junto com o framework Foundation, oferece muitos métodos e propriedades convenientes para inspecionar, transformar e manipular strings.

## Dividindo strings com `components(separatedBy:)`

Para dividir uma string em um array de substrings com base em um delimitador, use `components(separatedBy:)` (é preciso importar o Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Verificando prefixos e sufixos com `hasPrefix(_:)` e `hasSuffix(_:)`

Para verificar se uma string começa ou termina com uma sequência específica de caracteres, use `hasPrefix(_:)` e `hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## Alterando maiúsculas e minúsculas

Você pode alterar as maiúsculas e minúsculas de uma string usando estes métodos e propriedades padrão:

- `lowercased()`: retorna uma cópia da string em minúsculas.
- `uppercased()`: retorna uma cópia da string em maiúsculas.
- `capitalized`: retorna uma cópia em que a primeira letra de cada palavra fica maiúscula (do Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Substituindo substrings com `replacingOccurrences(of:with:)`

Para substituir todas as ocorrências de uma substring alvo por outra string, use `replacingOccurrences(of:with:)` (do Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Juntando strings com `joined(separator:)`

O método `joined(separator:)` pertence a coleções de strings, como `[String]`.
Ele junta os elementos em uma única string usando um separador:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
