# uso de retornos nus

A comunidade Go recomenda evitar *retornos nus* (ou *retornos vazios*) em circunstâncias normais, pois eles costumam tornar o código mais difícil de ler.
Consulte o [guia oficial de revisão de código do Go](https://github.com/golang/go/wiki/CodeReviewComments#naked-returns) para mais detalhes.
Existe uma [proposta](https://github.com/golang/go/issues/21291) para remover os retornos vazios de vez no Go 2.
