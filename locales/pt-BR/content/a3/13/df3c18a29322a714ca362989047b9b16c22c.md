# Funções

Em JavaScript, funções são _objetos de primeira classe_, o que significa que podem ser atribuídas a variáveis e propriedades, passadas para outras funções e retornadas de funções. Elas podem ter propriedades e métodos, assim como qualquer outro _objeto_.

## Entrada: passando argumentos

As funções em JavaScript permitem que você passe argumentos quando elas são chamadas. Os argumentos são sempre [passados por valor](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). Em outras palavras, se uma função reatribuir um parâmetro dentro dela, o valor não muda fora da função. Isso não significa que os objetos passados não possam ser alterados.

> [!TIP]
> Quando um objeto é passado, a referência a esse objeto é passada por valor. Isso faz _parecer_ que passar objetos é tratado de forma diferente, mas não é o caso.

Um exemplo de função que recebe dois argumentos e os multiplica é:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Saída: valor de retorno

Em JavaScript, você pode retornar um único valor de uma função usando a palavra-chave `return`, seguida de uma expressão. Quando nada é retornado de uma função, o valor retornado é `undefined`.

Um exemplo de função que retorna um valor é:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Definindo funções

Existem quatro tipos de funções em JavaScript:

1. Funções regulares, que podem retornar qualquer coisa e sempre rodam até o fim;
2. Funções assíncronas, que sempre retornam uma `Promise` e podem ser pausadas e retomadas com o operador `await`;
3. Funções geradoras: que sempre retornam um objeto `Generator` e podem ser pausadas e retomadas com o operador `yield`;
4. Funções geradoras assíncronas: que sempre retornam um objeto `AsyncGenerator` e podem ser pausadas e retomadas com _ambos_ os operadores `yield` e `await`.

Para cada um desses quatro tipos, existem três formas de defini-las:

1. usando uma declaração
2. usando uma expressão
3. usando o construtor

Por fim, existe uma sintaxe especial para definir _arrow functions e métodos_.
