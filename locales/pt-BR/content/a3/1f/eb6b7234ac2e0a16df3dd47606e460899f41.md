# Representações

O [representer][representer] usa [`read`][cl-read] para ler a submissão e [`write`][cl-write] para escrever a representação, além de aplicar algumas normalizações adicionais.
Cada submissão passa pelas seguintes normalizações:

- [Todos os comentários são removidos][remove-comments]
- [As strings de documentação são removidas][remove-doc-strings]
- [O uso de maiúsculas e minúsculas no texto é normalizado][normalize-case]
- [A formatação do texto é normalizada][normalize-formatting]
- [Os nomes dos símbolos são normalizados][normalize-names]
