# Introdução

Um laço `for` permite iterar sobre um array e repetir o código para cada elemento:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

No exemplo acima, `fruit` é a variável que guarda o valor de um elemento individual do array `fruitList`. O compilador garante que dá para iterar sobre `fruitList`; caso contrário, ele interrompe a execução.

Você pode iterar sobre números usando o operador de intervalo. O operador recebe dois operandos `Int` e é escrito como `min...max`:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
