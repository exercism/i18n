# Testes na trilha de MoonScript

Testar na trilha de MoonScript é exatamente igual a [testar na trilha de Lua][lua-tests].
Em um diretório de exercício, digite:

```console
$ busted
```

## Testes pendentes

Esta trilha segue a metodologia de [Desenvolvimento Guiado por Testes][tdd] do Exercism.
Você recebe uma suíte de testes completa, mas só o primeiro teste está "ativo".

Para habilitar os testes, mude o comando de um teste de `pending` para `it`.

Se você gosta de rodar todos os testes o tempo todo, pode usar uma ferramenta de linha de comando para mudá-los todos de uma vez.
Veja um exemplo usando perl (que está instalado em quase todo lugar):

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

Quando você está trabalhando no editor online, o executor de testes roda todos os testes automaticamente.

## Usando o LuaRocks

Lua, por si só, é uma linguagem muito pequena.
O [LuaRocks][luarocks] é o gerenciador de pacotes de módulos Lua.

Você pode usar qualquer módulo nas suas soluções, mas nem todos estarão disponíveis no executor de testes online.
O executor de testes oferece estes:

**Já disponíveis como dependências do `busted`**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**Já disponíveis como dependências do MoonScript**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**Data e hora**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
