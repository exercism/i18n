# Sobre

[`fold`][fold] é um [adaptador de iterador consumidor][consuming iterator adaptor] que aplica uma função a cada elemento da iteração, acumulando o resultado em um novo valor.

Cada iteração de `fold` recebe dois argumentos. O primeiro é um valor inicial para o acumulador. O segundo é uma closure que também recebe dois argumentos: o acumulador e um item. O valor de retorno da closure é o valor seguinte do acumulador. Quando o iterador se esgota, o valor final do acumulador é retornado.

Você pode usar `fold` quando quiser transformar uma coleção em um único valor. Por exemplo, se você quiser a soma de todos os números pares

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

Imprime `30`.

O que dá para fazer com `fold` muitas vezes dá para fazer com outra função, ou com várias. Para o exemplo acima, usar [`filter`][filter] em `(1..=10)` e depois [`sum`][sum] seria menos verboso e daria o mesmo resultado, assim

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

Outras funções mais usadas do que `fold` incluem [`product`][product] e [`collect`][collect].

Um acumulador pode ser usado para valores que não são numéricos. Por exemplo

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

Imprime `FeeFiFoFum`
