# Instruções

Você foi contratado como Engenheiro de Produção Assistente em uma empresa que produz colchas para tartarugas.

Os pedidos chegam ao longo do dia na forma de um nome ou número de cliente e uma quantidade pedida.
Eles são então processados de manhã, antes de a produção do dia começar.

Você pode ir para casa com o pagamento integral assim que todos os pedidos do dia forem atendidos, então há um incentivo para encurtar o dia de trabalho o máximo possível.
Como cada pedido é processado por uma única máquina, agendar primeiro os maiores permite empurrar o custo de iniciar um trabalho para os pedidos menores, encurtando o tempo total de produção.
Por isso, você decidiu criar algumas funções de ordenação para ajudar a acelerar esse agendamento, para poder chegar em casa e tricotar um suéter para sua tartaruga.

## 1. Ordene a quantidade!

Como observado, o array de quantidades precisará ser ordenado do maior para o menor.
Como esses arrays podem ser muito grandes, eles devem ser ordenados *in-place*.
Para acompanhar tudo corretamente, você também vai precisar ordenar o array de clientes de acordo com as quantidades, então será necessária uma permutação de ordenação das quantidades.

Escreva uma função `sortquantity!(qty)` que recebe um `Vector` de quantidades `Integer`.
Essa função ordena a entrada `qty` in-place em ordem decrescente e retorna uma permutação de ordenação dessa ordem.

```julia-repl
julia> qty = [8, 9, 5, 6]
4-element Vector{Int64}:
 8
 9
 5
 6

julia> sortquantity!(qty)
4-element Vector{Int64}:
 2
 1
 4
 3

julia> qty # original vector is sorted in-place
4-element Vector{Int64}:
 9
 8
 6
 5
```

## 2. Ordene o cliente

Como dito acima, você precisa acompanhar os clientes em uma ordem definida.

Escreva uma função `sortcustomer(cust, srtperm)` que recebe um `Vector` de clientes `cust` e um `Vector` de permutação de ordenação `srtperm`.
Essa função retorna um novo array com os clientes na ordem indicada pela permutação de ordenação.

```julia-repl
julia> cust = ["a", "b", "c"]
3-element Vector{String}:
 "a"
 "b"
 "c"

julia> sortcustomer(cust, [2, 3, 1])
3-element Vector{String}:
 "b"
 "c"
 "a"

julia> cust # original vector remains unsorted
3-element Vector{String}:
 "a"
 "b"
 "c"
```

## 3. Cronograma de produção!

Agora você pode juntar tudo para ajudar a manter essas tartarugas aquecidas!
Agora você consegue ordenar as quantidades e os clientes corretamente, mas precisa conseguir recuperar a ordem original para o envio.
Isso pode ser feito com uma permutação de ordenação inversa.

Escreva uma função `production_schedule!(cust, qty)` que recebe um `Vector` de clientes e um `Vector` de quantidades.
Essa função ordena as quantidades in-place em ordem decrescente.
Ela retorna um novo `Vector` de clientes ordenados na mesma ordem que as quantidades e uma permutação de ordenação *inversa*, que pode ser usada para restaurar os vetores ordenados à sua ordem original.

```julia-repl
julia> cust, qty = ["a", "b", "c"], [2, 3, 1]
(["a", "b", "c"], [2, 3, 1])

julia> orderedcust, invperm = production_schedule!(cust, qty)
(["b", "a", "c"], [2, 1, 3])

julia> qty # has been sorted in-place
3-element Vector{Int64}:
 3
 2
 1

julia> orderedcust[invperm], qty[invperm] # inverse permutation gives original ordering
(["a", "b", "c"], [2, 3, 1])
```
