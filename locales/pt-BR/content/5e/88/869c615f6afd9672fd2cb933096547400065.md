# Instruções

Você adora observar pássaros e anota todos os dias quantos visitam seu jardim. As contagens ficam guardadas em um array, do dia mais antigo para o mais recente.

## 1. A contagem de hoje

Defina `today` para pegar o array de contagens diárias da pilha e retornar a contagem de hoje.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Incrementar a contagem de hoje

Defina `increment-todays-count` para retornar um novo array com a contagem de hoje aumentada em um. O array original não deve ser modificado.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. Houve algum dia sem pássaros?

Defina `has-day-without-birds?` para retornar `t` se pelo menos um dia registrou zero pássaros, e `f` caso contrário.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Somar os primeiros dias

Defina `count-for-first-days` para receber um array de contagens e um número `n`, e retornar a soma das primeiras `n` contagens.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Contar os dias movimentados

Um dia movimentado é aquele com cinco pássaros ou mais. Defina `busy-days` para retornar o número de dias movimentados no array.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Preencher os dias faltantes

Se você não observou todos os dias de um período de `n` dias, preencha com `0` os dias finais que faltam. Defina `pad-missing-days` para receber um array de contagens e um comprimento alvo `n`, e retornar um array de comprimento pelo menos `n`, cujas posições extras sejam `0`. As contagens existentes devem ser preservadas sem alteração; se a entrada já tiver pelo menos `n` de comprimento, retorne-a sem alterações.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
