# Introdução

`when` é a palavra-chave para filtrar exceções. Ela é colocada depois da instrução `catch` e pode receber uma expressão Boolean que contenha quaisquer valores que estejam no escopo naquele momento. Se a expressão for verdadeira, o bloco associado a essa instrução `catch` é executado; caso contrário, a próxima instrução `catch`, se houver, é verificada.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
