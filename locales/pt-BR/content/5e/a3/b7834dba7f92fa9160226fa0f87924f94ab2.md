# Dicas

## Geral

- Reveja a [Referência da Linguagem sobre Array][ref-arrays]
- Reveja a [Referência de Funções de Array][ref-array-functions]

## 1. Defina uma função que retorne uma lista de linguagens vazia

- Reveja a [referência da linguagem][ref-arrays]
- Você pode retornar um array vazio

## 2. Modifique a função para criar uma lista a partir de qualquer número de linguagens

- Consulte a referência de funções sobre [argumentos de comprimento variável][variable-arguments]

## 3. Defina uma função que adicione uma linguagem à lista

- Crie uma nova função para realizar a operação
- Reutilize uma [função existente][ref-array-functions] ou use a [sintaxe de inserção][square-bracket-syntax]

## 4. Defina uma função que remova um item da lista de linguagens

- Crie uma nova função para realizar a operação
- Reutilize uma [função existente][ref-array-functions] para realizar a operação

## 5. Defina uma função que obtenha o primeiro item da lista

- Crie uma nova função para realizar a operação
- Use a [sintaxe de índice][index-syntax] para obter o primeiro elemento

## 6. Defina uma função que retorne quantas linguagens há na lista

- Crie uma nova função para realizar a operação
- Reutilize uma [função existente][ref-array-functions] para realizar a operação
