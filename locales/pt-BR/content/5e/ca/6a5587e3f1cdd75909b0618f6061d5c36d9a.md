# Executando os testes

Escolha seu sistema operacional:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Abra um Command Prompt.
2. Baixe o primeiro exercício:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Mude para o diretório do exercício:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Rode os testes:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Não se preocupe se os testes falharem no começo: é assim que você começa cada exercício.)_

5. Resolva o exercício. Encontre e siga o guia `instructions.append.md` ([ver no GitHub][hello-world-tutorial]).

Boa sorte! Divirta-se!

## macOS

1. Na janela do terminal, baixe o primeiro exercício:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Mude para o diretório do exercício:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. Rode os testes:

   ```sh
   ./gradlew test
   ```

   _(Não se preocupe se os testes falharem no começo: é assim que você começa cada exercício.)_

4. Resolva o exercício. Encontre e siga o guia `instructions.append.md` ([ver no GitHub][hello-world-tutorial]).

Boa sorte! Divirta-se!

## Linux

1. Na janela do terminal, baixe o primeiro exercício:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Mude para o diretório do exercício:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. Rode os testes:

   ```sh
   ./gradlew test
   ```

   _(Não se preocupe se os testes falharem no começo: é assim que você começa cada exercício.)_

   Se você receber o seguinte erro:

   ```sh
   ./gradlew: Permission denied
   ```

   Então o arquivo não tem permissão de execução. Para corrigir isso, rode:

   ```sh
   chmod +x ./gradlew
   ```

   E agora você deve conseguir rodar o comando anterior.

4. Resolva o exercício. Encontre e siga o guia `instructions.append.md` ([ver no GitHub][hello-world-tutorial]).

Boa sorte! Divirta-se!
