# Referência de Rust

## Conceitos

Os exercícios de conceito de Rust ensinam conceitos que vão dos fundamentos ao domínio da linguagem. Eles estão classificados e listados abaixo.

Os conceitos do Exercism existem para servir quem aprende de formas práticas, por isso diferem das ideias abstratas. Este documento define o que esses conceitos significam em Rust. Adicionamos um agrupamento visual abaixo para ajudar os mantenedores da track a criar um documento de referência eficaz. Esses agrupamentos _não_ constituem divisões pedagógicas. Por isso, por favor, não os use como referência ao ensinar.

As caixas de seleção indicam se os conceitos já são ensinados na lista de mapeamento dos exercícios.

## Mapeamento dos exercícios de conceito

Embora o ideal seja ter um único exercício de conceito para cada um dos conceitos listados acima, que ensine exatamente um conceito e exija apenas os seus pré-requisitos, fazer isso não é totalmente prático. Por exemplo, seria difícil criar um exercício que ensinasse o que são funções sem exigir nenhum conhecimento de primitivos; da mesma forma, seria difícil ensinar primitivos, com uma suíte de testes, sem nenhum conhecimento de funções.

Os exercícios desta tabela devem formar um DAG que, com o tempo, vai cobrir todos os conceitos listados acima.
