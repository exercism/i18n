# Sobre

Uma [instrução switch][switch] compara um valor com vários padrões de correspondência possíveis.
Ela oferece uma alternativa mais limpa e mais legível do que encadear várias condicionais `if-else`.

Uma instrução `switch` começa com a palavra-chave `switch`, seguida do valor a ser testado.
Cada correspondência possível é introduzida pela palavra-chave `case`.
A palavra-chave `default` define um caso padrão, executado quando nenhum dos casos explícitos corresponder.
Assim como as cadeias de `if-else`, uma instrução `switch` executa apenas o bloco de código associado ao primeiro caso que corresponde.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considere a seguinte cadeia de `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Isso pode ser escrito com mais clareza usando uma instrução `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Vinculação de valores e cláusulas `where`

Um caso de `switch` pode vincular os valores correspondentes a constantes ou variáveis temporárias, que você pode usar no corpo desse caso.
Os casos também podem incluir uma cláusula `where` para verificar condições Boolean adicionais antes de fazer a correspondência:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
