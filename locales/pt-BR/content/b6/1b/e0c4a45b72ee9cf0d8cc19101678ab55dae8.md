# Dicas

## Geral

## 1. Implemente o método `new()`

- O método `new()` recebe os argumentos com os quais queremos instanciar uma instância de `User`. Deve retornar uma instância de `User` com o nome, a idade e o peso especificados.

- Veja [aqui](https://doc.rust-lang.org/book/ch05-01-defining-structs.html) mais exemplos de como definir e instanciar structs.

## 2. Implemente os métodos getter

- Os métodos `name()`, `age()` e `weight()` são getters. Em outras palavras, são responsáveis por retornar o campo correspondente de uma instância de struct.

- Repare que o método `name` retorna um `&str`, mas o campo `name` da struct `User` é uma `String`. Como fazer `&str` e `String` conviverem bem um com o outro?

- Não há necessidade de usar uma instrução `return` em Rust, a menos que você queira expressamente que uma função ou método retorne antecipadamente. Caso contrário, é mais idiomático usar um retorno _implícito_, omitindo o ponto e vírgula do resultado que queremos que a função ou método retorne. Não é _errado_ usar um retorno explícito, mas é mais limpo aproveitar os retornos implícitos quando possível.

```rust
fn foo() -> i32 {
    1
}
```

- Veja [aqui](https://doc.rust-lang.org/book/ch05-03-method-syntax.html) mais alguns exemplos de como definir métodos em structs.

## 3. Implemente os métodos setter

- Os métodos `set_age()` e `set_weight()` são setters, responsáveis por atualizar o campo correspondente de uma instância de struct com o argumento de entrada.

- Como as assinaturas desses métodos especificam, os métodos setter não devem retornar nada.
