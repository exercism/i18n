# Anexo às instruções

## Registradores

| Registrador | Uso | Tipo | Descrição |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada        | endereço | string de dígitos terminada em nulo |
| `$a1`    | entrada        | inteiro | extensão                          |
| `$v0`    | saída       | inteiro | maior produto de série        |
| `$t0-9`  | temporário    | qualquer     | para armazenamento temporário         |
