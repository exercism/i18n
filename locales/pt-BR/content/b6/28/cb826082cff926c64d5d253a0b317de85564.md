# sinal de mais usado para concatenação

Neste caso, usar `+` é quase certamente a escolha certa, porque é mais curto e, muitas vezes, mais rápido para concatenações simples. Se você ainda não conhece, dê uma olhada no poderoso pacote `fmt`. É o que as pessoas costumam usar para concatenações de strings mais complicadas e para outras tarefas de formatação de strings.
