# Instruções

Um novo clube de poesia abriu na cidade, e você está pensando em frequentá-lo.
Como já houve incidentes no passado, o clube tem uma política de entrada bem específica que você precisa dominar antes de tentar entrar.

O clube de poesia tem duas portas, uma da frente e uma dos fundos, e as duas são vigiadas.
Para entrar, você vai precisar descobrir a senha do dia.

A senha é sempre baseada em um poema e pode ser obtida em um processo de duas etapas.

1. O guarda recita o poema, uma linha de cada vez, e você precisa responder com a letra correspondente dessa linha.
2. Em seguida, o guarda diz de uma vez todas as letras que você respondeu, e você precisa anotá-las em um papel em um formato específico.

Os detalhes do processo dependem de qual porta você está tentando entrar.

## 1. Obtenha a primeira letra de uma frase

Para descobrir as letras da senha da porta da frente, você precisa responder com a primeira letra da linha do poema que o guarda recita para você.

Para chegar a uma senha bonita, os membros do clube de poesia gostam de usar poemas _acrósticos_.
Isso significa que a primeira letra de cada frase forma uma palavra.
Veja um exemplo de um dos escritores favoritos deles, Michael Lockwood.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Então, quando o guarda recitar **Stands so high**, você responde **S**, e quando o guarda recitar **Huge hooves too**, você responde **H**.

Implemente a função `frontDoorResponse` que recebe uma linha do poema como argumento e retorna a primeira letra dessa linha.

```javascript
frontDoorResponse('Stands so high');
// => "S"
```

## 2. Deixe uma palavra com a inicial maiúscula

Agora que você tem todas as letras corretas, tudo o que precisa fazer para obter a senha da porta da frente é colocar a palavra com a inicial maiúscula corretamente.

Implemente a função `frontDoorPassword` que aceita uma string (as letras combinadas que você encontrou na tarefa 1) e a retorna com a inicial maiúscula correta.

```javascript
frontDoorPassword('SHIRE');
// => "Shire"

frontDoorPassword('shire');
// => "Shire"
```

## 3. Obtenha a última letra de uma frase

Para descobrir as letras da senha da porta dos fundos, você precisa responder com a última letra da linha do poema que o guarda recita para você.

Os membros do clube de poesia são muito espertos.
O poema mencionado antes também é um _telestíquio_, o que significa que a última letra de cada frase também forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recitar **Stands so high**, você responde **h**, e quando o guarda recitar **Huge hooves too**, você responde **o**.

Repare que às vezes o guarda faz pausas estilísticas (na forma de espaços em branco) no começo ou no fim da linha.
Você vai precisar ignorar essas pausas para chegar à letra correta.

Implemente a função `backDoorResponse` que recebe uma linha do poema como argumento e retorna a última letra dessa linha que não seja um caractere de espaço em branco.

```javascript
backDoorResponse('Stands so high');
// => "h"

backDoorResponse('Stands so high   ');
// => "h"
```

## 4. Seja educado

Para entrar no clube de poesia pela porta dos fundos, você precisa ser muito educado.
Então, para obter a senha, desta vez você precisa colocar a palavra com a inicial maiúscula corretamente e adicionar `', please'` no final.

Implemente a função `backDoorPassword` que aceita uma string (as letras combinadas que você encontrou na tarefa 3) e retorna a versão educada da senha com a inicial maiúscula.

```javascript
backDoorPassword('horse');
// => "Horse, please"
```
