# Fluxo de trabalho de sincronização de labels

O fluxo de trabalho de sincronização de labels sincroniza as [labels do GitHub](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) de um repositório com o conteúdo do arquivo `.github/labels.yml`.
Sempre que o arquivo `.github/labels.yml` mudar, o fluxo de trabalho de sincronização de labels atualizará automaticamente as labels do repositório.

## Personalizando labels

As labels definidas em `.github/labels.yml` existem em duas formas:

- Labels compartilhadas: são labels usadas por _todos_ os repositórios do Exercism, e são definidas no [repositório org-wide-files](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)
- Labels específicas de um track: são definidas em um arquivo `.appends/.github/labels.yml`

Para adicionar labels específicas de um track, você precisa adicioná-las ao arquivo `.appends/.github/labels.yml` (veja [este exemplo](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)).
Depois de mesclar as mudanças na `main`, um pull request será aberto automaticamente para alterar o arquivo `.github/labels.yml`.
Depois de mesclar esse PR, as labels serão atualizadas automaticamente (veja a descrição acima).

```exercism/caution
Nunca edite o arquivo `.github/labels.yml` manualmente, pois essas mudanças serão sobrescritas na próxima vez que as labels forem sincronizadas.
```

## Fonte

O fluxo de trabalho é definido no arquivo `.github/workflows/sync-labels.yml`.
