# Introdução

## Interface como um conjunto de métodos

Na sua forma mais simples, um **tipo de interface** é um conjunto de assinaturas de métodos.
Aqui está um exemplo de definição de interface que inclui dois métodos `Add` e `Value`:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Os nomes dos parâmetros como `increment` podem ser omitidos da definição da interface, mas costumam aumentar a legibilidade.

Nomes de interface em Go não contêm a palavra `Interface` ou `I`.
Em vez disso, muitas vezes terminam com `er`, por exemplo `Reader`, `Stringer`.

## Implementando uma interface

Qualquer tipo que define os métodos da interface a implementa automaticamente e de forma implícita.
Não existe a palavra-chave `implements` em Go.

O tipo a seguir implementa a interface `Counter` que vimos acima.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Para implementar a interface, não importa se o método tem um receptor de valor ou de ponteiro.
(Reveja os [conceitos de métodos][concept-methods] caso tenha dúvidas sobre eles.)

> Um valor de tipo de interface pode conter qualquer valor que implemente esses métodos. [^1]

Isso significa que `Stats` agora pode ser usado em todos os lugares que esperam a interface `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Como as interfaces são implementadas de forma implícita, um tipo pode facilmente implementar várias interfaces.
Ele só precisa ter todos os métodos necessários definidos.

## Interface vazia

Existe um tipo de interface muito especial em Go, o tipo **interface vazia**, que contém zero métodos.
A interface vazia é escrita assim: `interface{}`.
`any` é um alias para `interface{}`, e é usado com mais frequência.

Como a interface vazia não tem métodos, todo tipo a implementa implicitamente.
Isso é útil para definir uma função que pode aceitar qualquer valor de forma genérica.
Nesse caso, o parâmetro da função usa o tipo interface vazia.
