# Dicas

## Geral

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).

## 1. Crie uma entrada para cada item

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).
- Todos os argumentos inteiros depois do sexto são passados na pilha, sendo o primeiro em `rsp + 8`.
- O número de argumentos extras é igual ao número de categorias, que é passado em `r9`.
- Você pode fazer um laço para adicionar os argumentos extras um a um, ou pode usar [movsq][movs] combinado com [rep][rep].

## 2. Reserve espaço para uma lista mensal de itens

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).
- Você precisa saber o tamanho do array para limpar os bytes dele depois de chamar a função de alocação.
- Quando você chama uma função externa, ela pode modificar o valor em qualquer _registrador salvo pelo chamador_.
- Você pode preservar o valor de um registrador na pilha usando [push][push] ou manipulando `rsp` diretamente.
- Qualquer modificação em `rsp`, inclusive com `push`, deve ser revertida antes de a função retornar, seja com [pop][pop], seja alterando `rsp` diretamente.

## 3. Insira um item na lista mensal

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).
- Um valor que não cabe em um registrador é passado para uma função na pilha.
- Cada entrada de um item ocupa 120 bytes de espaço, muito mais do que o tamanho máximo de um registrador (8 bytes).
- Os argumentos passados na pilha podem ser encontrados em endereços a partir de `rsp + 8`.
- Você pode fazer um laço para adicionar os valores ao endereço de memória de destino, ou pode usar [movsb][movs] combinado com [rep][rep].

## 4. Imprima um item

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).
- A string introdutória é opcional; em vez dela, você pode chamar a função de impressão com `0`.
- Se a string introdutória for passada para a função de impressão, ela deve ter no máximo 50 caracteres ASCII, já incluindo o terminador NUL (valor `0`).
- Sempre que você chamar uma função, precisa reservar espaço na pilha para qualquer argumento depois do sexto.
- A ABI System V determina que a pilha deve estar alinhada em 16 bytes antes de chamar uma função, o que é especialmente importante para funções externas.
- Cada entrada de um item na lista ocupa 120 bytes de espaço.
