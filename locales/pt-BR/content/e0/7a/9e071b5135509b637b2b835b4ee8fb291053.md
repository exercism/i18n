# Instruções

Neste exercício, você vai verificar as permissões de contas de usuário em um fórum online. O fórum oferece três permissões diferentes:

- Read
- Write
- Delete

Existem três tipos de conta, cada um com permissões padrão diferentes:

- Convidados: podem ler posts.
- Usuários: podem ler e escrever posts.
- Moderadores: podem ler, escrever e excluir posts, eles têm todas as permissões.

Às vezes, permissões individuais podem ser modificadas. Por exemplo, é possível dar a uma conta de convidado a permissão de também escrever posts, ou revogar todas as permissões de uma conta, o que deixaria ela sem nenhuma permissão.

## 1. Obter as permissões padrão de um tipo de conta

Primeiro, defina um enum `AccountType` para representar os três tipos de conta: `Guest`, `User` e `Moderator`.

Em seguida, defina um enum `Permission` para representar os três tipos de permissão: `Read`, `Write`, `Delete`, e mais dois: `All` para ter todas as permissões e `None` para não ter nenhuma permissão.

Depois, implemente o método (_static_) `Permissions.Default()` para retornar as permissões padrão de um tipo de conta específico:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Conceder uma permissão

Implemente o método (_static_) `Permissions.Grant()`, que concede (adiciona) uma permissão:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Revogar uma permissão

Implemente o método (_static_) `Permissions.Revoke()`, que revoga (remove) uma permissão:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Verificar uma permissão

Implemente o método (_static_) `Permissions.Check()`, que recebe as permissões atuais da conta e verifica se a conta está autorizada para uma determinada permissão:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
