## 1. Verifique a criticidade

- Operadores de comparação ([comparisons][comparisons review]) e operações Boolean ([concept:python/bools]()) podem ser combinados e usados com condicionais.
- Expressões condicionais devem resultar em `True` ou `False`.
- `else` pode ser usado para um bloco de código que será executado quando todos os testes condicionais retornarem `False`.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. Determine a faixa de potência de saída

- Operadores de comparação podem ser combinados e usados com condicionais.
- Qualquer número de instruções `elif` pode ser usado como "blocos" de decisão.
- Cada "bloco" pode ter um `return` separado, embora isso possa ser considerado "má prática" pelas ferramentas de lint.
- Se o linter reclamar, considere atribuir a saída de um bloco a uma variável comum e depois fazer `return` dessa variável.
