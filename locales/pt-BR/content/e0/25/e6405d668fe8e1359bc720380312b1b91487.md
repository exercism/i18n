# Introdução

O tipo `Bool` é um dos blocos de construção da linguagem. Ele serve para descrever se algo é verdadeiro ou falso, com os respectivos valores `True` e `False`.

Booleanos podem ser combinados com os operadores `&&` ("E") e `||` ("OU"), e negados com a função `not`.

Booleanos também são extremamente úteis para criar blocos no seu código que só são executados se certas condições forem atendidas. No Elm, isso é feito com uma expressão `if-then-else`, usada da seguinte forma.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
