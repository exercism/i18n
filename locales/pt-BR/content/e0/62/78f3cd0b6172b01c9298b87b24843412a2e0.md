# não use divisão nem módulo

Como as instruções mencionam, o objetivo deste exercício é construir o Crivo de Eratóstenes sem usar operações como divisão ou módulo.
Consulte o [link da Wikipédia](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes) para ver uma descrição do algoritmo.

Construir o Crivo de Eratóstenes em uma linguagem imutável como Elm pode parecer um pouco estranho, mas é um algoritmo bonito, inventado há mais de dois milênios, que vale a pena aprender e implementar corretamente.
