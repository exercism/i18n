# Introdução

Um laço `for` permite executar um trecho de código repetidamente até que uma condição seja satisfeita.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Um laço `for` é composto de quatro partes:

1. O inicializador: executado uma vez antes de entrar no laço. Normalmente usado para definir as variáveis usadas dentro do laço.
2. A condição: executada antes de cada iteração do laço. O laço continua a ser executado enquanto isso for avaliado como `true`.
3. O iterador: executado depois de cada iteração do laço. Normalmente usado para modificar (muitas vezes: incrementar ou decrementar) as variáveis do laço.
4. O corpo: o código que é executado a cada iteração do laço.
