# Exemplo

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

Linhas que começam com um ponto são _diretivas_: instruções para o montador, e não para o processador.
`.equ` dá o nome `FRAME_SIZE` ao número 16.
`.text` diz que o que vem a seguir é código.
`.global` torna o rótulo `is_triple` visível fora deste arquivo, para que outro código possa chamá-lo.
Você também pode encontrar `.globl`, que significa a mesma coisa.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` verifica se `a² + b² = c²`, retornando 1 se for o caso e 0 caso contrário.
Por exemplo, `(6, 8, 10)` dá 1, porque `36 + 64 = 100`.
O rótulo `is_triple` marca onde a função começa.
Ela é chamada com `a`, `b` e `c` nos registradores `a0`, `a1` e `a2`.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

O registrador `ra` guarda o _endereço de retorno_, o ponto no chamador para onde voltar quando terminarmos.
Cada `call` sobrescreve `ra`, então primeiro salvamos ele na _pilha_.
A pilha cresce para baixo, em direção a endereços menores, então subtrair 16 do ponteiro de pilha `sp` reserva 16 bytes para nós.
(`sp` deve ser sempre um múltiplo de 16.)
Também salvamos `b` e `c`, porque uma função que chamamos pode alterar os registradores `a`.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` já está em `a0`, onde `square` espera sua entrada.
`call` define `ra` para a próxima instrução e salta para `square`, que retorna seu resultado em `a0`.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

Carregamos `b` de volta da pilha, elevamos ao quadrado e somamos o resultado a `a * a`.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

A diferença é zero exatamente quando `a² + b² = c²`.
`seqz` ("set if equal to zero") transforma isso em 1 ou 0.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

Restauramos `ra` e devolvemos os 16 bytes da pilha.
`ret` então salta para o endereço em `ra`, de volta ao chamador.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` não chama nenhuma outra função, então `ra` permanece intacto e não há nada para salvar.
Ela não está marcada como `.global`, porque só `is_triple` a usa.
