# Sobre

A principal construção orientada a objetos em Java é a _classe_, que combina dados ([_campos_][fields]), também conhecidos como variáveis de instância, e comportamento ([_métodos_][methods]).
Os campos e os métodos de uma classe são conhecidos como seus _membros_.

O acesso aos membros pode ser controlado por meio de modificadores de acesso, sendo os dois mais comuns:

- [`public`][public]: o membro pode ser acessado por qualquer código (sem restrições).
- [`private`][private]: o membro só pode ser acessado por código da mesma classe.

Em Java, se nenhum modificador de acesso for especificado, o padrão é a _visibilidade de pacote_.
Nesse caso, o membro fica visível para todas as classes definidas no mesmo pacote.

Esse agrupamento de dados e comportamentos relacionados, somado à restrição de acesso aos membros, é conhecido como [_encapsulamento_][encapsulation], um dos conceitos centrais da orientação a objetos.

Você pode pensar em uma classe como um molde para criar instâncias dessa classe.
Para [criar uma instância de uma classe][creating-objects] (também chamada de _objeto_), usa-se a palavra-chave [`new`][new]:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Os [campos][fields] têm um tipo e um nome (grafados em [camelCase][camel-case]) e podem ser definidos em qualquer lugar de uma classe (grafada em [PascalCase][pascal-case]).

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

É possível atribuir um valor inicial a um campo, de forma opcional.
Se um campo _não_ especificar um valor inicial, ele receberá o [valor padrão][default-values] do seu tipo.
Os valores dos campos de uma instância podem ser acessados e atualizados usando a notação de ponto.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Campos privados costumam ser atualizados como efeito colateral da chamada de um método.
Esses métodos geralmente não retornam nenhum valor e, nesse caso, o tipo de retorno deve ser [`void`][void]:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field
        carsImported = carsImported + numberOfCars;
    }
}
```

Repare que não é comum usar campos públicos em classes Java.
Normalmente usam-se campos privados, acessados por meio de [_getters_ e _setters_][so-getters-setters].

Dentro de uma classe, a palavra-chave [`this`][this] se refere à classe atual.
Isso é especialmente útil quando um parâmetro tem o mesmo nome de um campo:

```java
class CarImporter {
    private int carsImported;

    public void setImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```
