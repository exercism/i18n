# Introdução

## Boolean em Julia

Valores verdadeiro ou falso são representados pelo tipo `Bool`.
Esse tipo contém apenas dois valores: `true` e `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Operadores booleanos

Existem três operadores booleanos em Julia.

`&&` é o "e" booleano.
O resultado é `true` se as expressões em *ambos* os lados de `&&` forem `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` é o "ou" booleano.
O resultado é `true` se *pelo menos uma* das expressões dos dois lados de `||` for `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` é o "não" booleano.
Ele inverte os valores `true` e `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Para expressões mais longas e complicadas, é melhor usar parênteses para deixar sua intenção clara.

```julia-repl
julia> (true || false) && (false && true)
false
```
