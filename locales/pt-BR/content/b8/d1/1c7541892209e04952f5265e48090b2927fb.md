# Apêndice de instruções

## Dicas

O módulo Sgf deve exportar um módulo `parseSgf` com a seguinte assinatura:

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

Talvez seja útil copiar as seguintes definições de SgfTree e SgfNode:

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```
