# Sobre

[Intervalos][range] representam um intervalo entre dois valores.
Intervalos são comumente usados com tipos como `Int`, `String` e `Character` para iterar sobre sequências, fatiar coleções ou verificar se um valor está dentro dos limites.

O Swift oferece dois operadores de intervalo principais:

- **Operador de intervalo fechado (`...`)**: inclui tanto o valor inicial quanto o final (`1...5` inclui 1, 2, 3, 4 e 5).
- **Operador de intervalo semiaberto (`..<`)**: inclui o valor inicial, mas exclui o valor final (`1..<5` inclui 1, 2, 3 e 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Ao chamar um método diretamente em um literal de intervalo, coloque a expressão de intervalo entre parênteses para que o compilador avalie o intervalo primeiro:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Convertendo um intervalo em um array

Você pode converter um intervalo de números em um `Array` usando o inicializador `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Fatiando um array com intervalos

Você pode usar intervalos para fatiar partes de um array:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Propriedades e métodos de intervalos

As operações mais comuns com intervalos incluem:

| Membro                  | Descrição                                                  | Exemplo                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Retorna o número de elementos no intervalo                 | `(1...5).count` retorna `5`          |
| [`contains(_:)`][contains] | Retorna `true` se o intervalo inclui o valor especificado | `(1...5).contains(3)` retorna `true` |

## Intervalos unilaterais

O Swift também oferece suporte a intervalos unilaterais (parciais), em que você omite o valor inicial ou o final:

- `array[2...]`: do índice 2 até o final da coleção.
- `array[...2]`: do início da coleção até o índice 2, inclusive.
- `array[..<2]`: do início da coleção até o índice 2 (sem incluí-lo).

## Intervalos de string e caractere

Também é possível criar intervalos entre caracteres ou strings que estão em conformidade com `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
