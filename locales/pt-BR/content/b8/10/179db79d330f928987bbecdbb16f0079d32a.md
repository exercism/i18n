# Introdução

Uma `string` em Clojure é uma string do Java: um objeto que representa texto imutável como uma sequência de caracteres Unicode (letras, dígitos, pontuação etc.) e é definida assim:

```clojure
(def fruit "Apple")
```

A biblioteca `clojure.string` oferece muitas funções padrão de manipulação e processamento de strings. Além disso, todos os métodos Java usuais para operar com strings ficam disponíveis por meio da interoperabilidade com o Java.
