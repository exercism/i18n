# Classes com estado

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| Escrito | Lido de fora | Alterado de fora |
| --- | --- | --- |
| `attr x : INT` | sim | sim |
| `readonly attr x : INT` | sim | não |
| `private attr x : INT` | não | não |

`readonly` é o que você deve usar por padrão. Ele deixa qualquer pessoa ver o placar e exige que qualquer mudança passe por `home_goal`, que é onde ficam as regras de pontuação.

## create e new

`new` produz um objeto desta classe com todos os atributos vazios. Ele só pode ser usado dentro da classe.

`create` é uma rotina comum com um nome combinado: `#C(args)` é exatamente `C::create(args)`. Uma classe pode ter várias, distinguidas pelos argumentos, e uma classe sem nenhuma simplesmente não pode ser criada com `#`.

## SAME

`SAME` representa a classe em que é escrito. Em `create`, ele é o tipo de retorno; também aparece em um argumento, e é o que faz uma rotina herdada se referir à classe que herda, e não àquela de onde veio.

## Rotinas sem tipo de retorno

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Sem `:` e sem tipo. Essa rotina é chamada como uma instrução e não pode aparecer em uma expressão. É o sinal de que o objetivo da chamada é a mudança que ela provoca.

## self

Dentro de uma rotina, `self` é o objeto no qual ela foi chamada. Raramente é escrito, porque um atributo ou uma rotina citados sozinhos já significam os de `self`. Ele é necessário quando o objeto precisa ser repassado ou retornado:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` e `out` são todas palavras que o Sather reservou, e nenhuma delas pode ser usada como um nome seu.

## Referência, não valor

Um objeto é acessado por meio de uma referência. Dois nomes para o mesmo placar veem a mesma pontuação:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class`, mais adiante, é como obter o outro comportamento.
