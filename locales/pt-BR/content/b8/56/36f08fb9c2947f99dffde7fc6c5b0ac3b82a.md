# Introdução

C#, como muitas linguagens de tipagem estática, oferece vários tipos que representam números inteiros, cada um com seu próprio intervalo de valores. No extremo inferior, o tipo `sbyte` tem valor mínimo de -128 e valor máximo de 127. Como em todos os tipos inteiros, esses valores estão disponíveis como `<type>.MinValue` e `<type>.MaxValue`. No extremo superior, o tipo `long` tem valor mínimo de -9,223,372,036,854,775,808 e valor máximo de 9,223,372,036,854,775,807. Entre eles ficam os tipos `short` e `int`.

Os intervalos são determinados pela largura de armazenamento do tipo, conforme alocada pelo sistema. Por exemplo, um `byte` usa 8 bits e um `long` usa 64 bits.

Cada um dos tipos acima vem acompanhado de um equivalente sem sinal: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint` e `long`/`ulong`. Em todos os casos, o intervalo de valores vai de 0 até o máximo negativo com sinal multiplicado por 2 mais 1.

| Tipo   | Largura | Mínimo                     | Máximo                      |
| ------ | ------- | -------------------------- | --------------------------- |
| sbyte  | 8 bit   | -128                       | +127                        |
| short  | 16 bit  | -32_768                    | +32_767                     |
| int    | 32 bit  | -2_147_483_648             | +2_147_483_647              |
| long   | 64 bit  | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 bit   | 0                          | +255                        |
| ushort | 16 bit  | 0                          | +65_535                     |
| uint   | 32 bit  | 0                          | +4_294_967_295              |
| ulong  | 64 bit  | 0                          | +18_446_744_073_709_551_615 |

Uma variável (ou expressão) de um tipo pode ser convertida facilmente em outra. Por exemplo, em uma operação de atribuição, se o tipo do valor que está sendo atribuído (lhs) garantir que o valor estará dentro do intervalo do tipo que recebe a atribuição (rhs), então a atribuição é simples:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

Por outro lado, se o intervalo do tipo de origem não for um subconjunto do intervalo de valores do tipo de destino, então é necessário um cast, uma operação `()`, mesmo que o valor em questão esteja dentro do intervalo do destino:

```csharp
short s = 42;
uint ui = (uint)s;
```
