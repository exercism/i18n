# Roadmap

Este documento traz uma visão geral dos principais tópicos nos quais contribuidores e mantenedores provavelmente vão focar nos próximos meses.

## Visão geral dos tópicos

- Melhorar os exercícios de conceito existentes (veja a [issue de acompanhamento](https://github.com/exercism/javascript/issues/1415))
- Criar mais exercícios de conceito (veja a visão geral do programa de estudos abaixo)
- Definir as listas `prerequisites` e `practices` para todos os exercícios de prática (veja a [issue de acompanhamento](https://github.com/exercism/javascript/issues/960))
- Melhorar o [test runner](https://github.com/exercism/javascript-test-runner/)
  - Corrigir bugs
  - Uma saída mais agradável quando variáveis são definidas fora do caso de teste
  - Conectar os testes às tarefas
- Adicionar comentários do [analyzer](https://github.com/exercism/javascript-analyzer/) para todos os exercícios de conceito existentes
- Melhorar/atualizar/revisar a documentação (diretrizes de contribuição, como implementar um exercício de conceito, docs, exercises/shared, pasta de referência)

## Visão geral do programa de estudos

- `strings` (incl. métodos de string)
- `numbers`
- `booleans`
- `conditionals` (if/else) e `comparison`
- `for-loops` e `increment-decrement`
- `while-loops`
- `conditionals-switch`
- `objects` (como coleções de chave-valor)
- `null-undefined`
- `functions`
- `type-conversion` (incl. truthy/falsy)
- `template-strings`
- `conditionals-ternary`
- `callbacks`
- `arrow-functions`
- `classes` e `prototypes`
- `inheritance`
- `errors`
- `arrays` (incl. manipulação de arrays com push, pop etc.)
- `array-loops`
- `array-analysis`
- `array-transformation`
- `array-destructering`
- `rest-and-spread`
- `promises`
- `recursion`
- `closures`
- `sets`
- `randomness`
- `regular-expressions`
- `dates`
- `async-await`
- `type-checking`

### Possíveis conceitos futuros

- `math`
- getters/setters, flags, descritores
- `proxy`
- `variables` (aprofundamento em const/let/var)
- `immutability` (incl. freeze, poderia ser combinado com o conceito de variáveis)
- `object-helpers` (por exemplo, Object.assign)
- caracteres e pontos de código
- this e escopo (incl. call/bind)
- iteradores e "enumeradores"
- geradores/yield
- geradores e iteradores assíncronos
- operadores bit a bit
- módulos, imports, exports, imports dinâmicos
- duck typing
- API de internacionalização
- `bigint`
- `symbol`
- comentários JSDoc
- assincronicidade, laço de eventos
- setTimeout/setInterval
- eventos
- "tudo é um objeto" às vezes (relação de funções, arrays e primitivos com objetos, por exemplo, boxed types)
