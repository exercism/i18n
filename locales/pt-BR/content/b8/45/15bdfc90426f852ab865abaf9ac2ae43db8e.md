# Introdução

## Números

Existem dois tipos diferentes de números em F#:

- Inteiros: números sem dígitos depois do separador decimal (números inteiros). Exemplos são `-6`, `0`, `1`, `25`, `976` e `500000`.
- Números de ponto flutuante: números com zero ou mais dígitos depois do separador decimal. Exemplos são `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

Os dois tipos numéricos mais comuns em F# são `int` e `float`. Um `int` é um inteiro de 32 bits e um `float` é um número de ponto flutuante de 64 bits.

As operações aritméticas são feitas com os operadores aritméticos padrão. Números podem ser comparados com os operadores de comparação numérica padrão e com os operadores de igualdade (`=`) e desigualdade (`<>`).

A conversão entre tipos numéricos é feita por meio de operadores de conversão internos. Esses operadores de conversão têm o nome do tipo para o qual vão converter. O F# _não_ oferece conversão automática entre tipos numéricos.

## Condicionais

A forma mais comum de executar código condicionalmente em F# é usar uma expressão `if/elif/else`:

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

As condições usadas em uma expressão `if/elif/else` devem ser do tipo `bool`. O F# não tem o conceito de valores _truthy_.
