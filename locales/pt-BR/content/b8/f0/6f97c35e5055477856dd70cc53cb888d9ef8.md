# Dicas

## Geral

- `n <iota>` produz uma sequência virtual dos inteiros
  `0, 1, …, n-1`.
- `map` (em [`sequences`][sequences]) roda a sua quotation em cada
  elemento e coleta os resultados.
- `>string` (em [`strings`][strings]) transforma uma sequência de
  códigos de caractere em uma string.

## 1. Bandeirinhas do alfabeto

- `CHAR: a` é interpretado como o inteiro `97`. Somar o índice `i`
  dá o código da `i`-ésima letra minúscula.

## 2. Bandeirinhas de contagem

- `mod` (em [`math`][math]) retorna o resto da divisão
  inteira.
- Os códigos de caractere dos dígitos são consecutivos (`CHAR: 0`,
  `CHAR: 1`, …), então `CHAR: 0 +` converte um inteiro em `0..9` no
  caractere de dígito correspondente.

## 3. Bandeirinhas de listras

- `even?` (em [`math`][math]) é `t` para inteiros pares e `f`
  caso contrário.
- Dentro da quotation do `map`, o `if` escolhe um entre dois literais
  de caractere com base no teste.

## 4. Bandeirinhas de marcadores

- `5 mod zero?` é `t` exatamente nas posições `0`, `5`, `10`, … .

## 5. Bandeirinhas de vale

- `-5 5 [a..b)` (em [`ranges`][ranges]) é o intervalo
  semiaberto `-5, -4, …, 4`.
- `abs` (em [`math`][math]) converte um inteiro negativo em seu
  correspondente positivo, deixando os inteiros não negativos intactos.
