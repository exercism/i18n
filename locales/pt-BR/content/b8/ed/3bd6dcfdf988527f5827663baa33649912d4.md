# Sobre

Às vezes, você não precisa da sobrecarga de criar um objeto com estado.
Nesses casos, dá para usar um `module`.

Um `module` é muito semelhante a uma classe (na verdade, `Module` é o pai de `Classes` na hierarquia de objetos). A principal diferença é que, em vez de usar métodos de instância, usamos métodos de classe.
Os métodos de classe começam com `self.` e são chamados diretamente em um módulo.

Por exemplo:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
