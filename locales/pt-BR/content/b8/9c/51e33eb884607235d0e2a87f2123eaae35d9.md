# Dicas

- A função `format` será necessária neste exercício.

## 1. Formatar valores trimestrais

- `format` sempre retorna `nil`, a menos que o parâmetro stream seja `nil`.
- `~A` pode ser usado para formatar um valor.

## 2. O relatório dos dois trimestres

- Sua função anterior é perfeita para criar as duas linhas necessárias.
- `~%` e `~&` podem ser usados para criar quebras de linha.

## 3. Legível para humanos vs. para o Lisp Alien

- Sua função de formatação de trimestres anterior é perfeita para criar as strings necessárias.
- `~S` pode ser usado para formatar valores de forma legível.
