# Dicas

## 1. Encontrar uma carta no baralho

- Existe um [método nativo][index] que encontra o primeiro elemento da coleção que atende à condição especificada no bloco e retorna o índice dele, ou `nil` se nenhum elemento for encontrado.

## 2. Deixar todos os caracteres em maiúscula

- Existe um [método nativo][map] para transformar todos os elementos da coleção.
- Existe um [método nativo][capitalize] para colocar palavras em maiúscula em uma `String`.

## 3. Calcular o nível de poder de todas as cartas

- Você pode usar o [método `sum`] para calcular o nível de poder total de todas as cartas.
- O método `sum` também pode aceitar um bloco para transformar os elementos antes de somá-los.

## 4. Decodificar uma carta

- Existe um [método nativo][each_char_with_index] para iterar sobre os caracteres de uma `String` com um índice.
