# Apêndice das instruções

## Registradores

| Registrador | Uso       | Tipo    | Descrição                   |
| -------- | --------- | ------- | --------------------------- |
| `$a0`    | entrada   | endereço | array de palavras de livros |
| `$a1`    | entrada   | inteiro | número de livros            |
| `$v0`    | saída     | inteiro | preço, em centavos          |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário |
