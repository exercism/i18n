# Instruções

Boris é um grande entusiasta de trens de modelismo e decidiu compartilhar essa paixão com o mundo lançando uma newsletter. A ideia é começar enviando a primeira edição para amigos e conhecidos que compartilham o hobby; os endereços de e-mail deles estão guardados em um arquivo de texto.

Dica: use o módulo [simplifile](https://hexdocs.pm/simplifile/simplifile.html) para as operações com arquivos.

## 1. Ler endereços de e-mail de um arquivo

Implemente a função `read_emails`. Ela recebe uma string com o caminho de um arquivo de texto que contém endereços de e-mail separados por quebras de linha e retorna uma lista com os endereços de e-mail do arquivo.

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. Criar um arquivo de log para escrita

Enviar um e-mail é uma tarefa que pode falhar por muitos motivos imprevisíveis, como um erro de digitação no endereço de e-mail ou problemas temporários de rede. Para garantir que você possa tentar reenviar os e-mails a todos os seus amigos sem enviar duplicatas, é preciso registrar os endereços de e-mail que já receberam a mensagem. Para isso, você vai precisar de um arquivo de log.

Implemente a função `create_log_file`. Ela recebe um caminho de arquivo e cria um novo arquivo vazio nesse local.

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. Registrar um e-mail enviado

Implemente a função `log_sent_email`. Ela recebe o caminho de um arquivo de log e uma string com o endereço de e-mail. Ela escreve o endereço de e-mail no arquivo, seguido de uma quebra de linha.

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. Enviar a newsletter

Agora que você tem todas as peças do processo de envio de e-mails, precisa juntá-las em uma única função.

Implemente a função `send_newsletter`. Ela recebe o caminho do arquivo com os endereços de e-mail, o caminho de um arquivo de log e uma função anônima que envia um e-mail para um determinado endereço de e-mail.

Ela deve ler todos os endereços de e-mail do arquivo fornecido e tentar enviar um e-mail para cada um deles. Se a função anônima que envia o e-mail retornar um valor `Ok`, escreva o endereço de e-mail no arquivo de log. Certifique-se de fazer isso assim que o e-mail for enviado.

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
