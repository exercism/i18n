# Introdução

## Enum

`Enum` é um módulo muito útil que fornece um conjunto de algoritmos para trabalhar com enumeráveis. Ele oferece ordenação, filtragem, agrupamento, contagem, busca, encontrar valores mínimos e máximos, e muito mais.

Em geral, um _enumerável_ é qualquer dado sobre o qual se pode iterar, uma coleção. Em Elixir, um enumerável é qualquer tipo de dados que implemente o [protocolo][exercism-protocols] `Enumerable`. Os mais comuns são as [listas][exercism-lists] e os [mapas][exercism-maps].

Muitas funções do `Enum` aceitam uma função como argumento.

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

As funções mais comuns do `Enum` são `map` e `reduce`.

### `map/2`

O `Enum.map/2` permite substituir cada elemento de um enumerável por outro elemento. O segundo argumento do `Enum.map/2` é uma função que aceita o elemento original e retorna seu substituto.

### `reduce/3`

O `Enum.reduce/3` permite _reduzir_ todo o enumerável a um único valor. Para isso, usa-se uma variável especial chamada _acumulador_. O acumulador carrega o estado intermediário da redução entre as iterações.

O segundo argumento do `Enum.reduce/3` é o valor inicial do acumulador. O terceiro argumento é uma função que aceita um elemento e um acumulador, e retorna o novo valor do acumulador.

### Trabalhando com mapas

Quando usamos mapas com funções do `Enum`, o mapa é automaticamente convertido em uma lista de 2 tuplas `{key, value}`.

Para transformá-lo de volta em um mapa, use `Enum.into/2`. O `Enum.into/2` é uma função que transforma um enumerável em um coletável, ou seja, qualquer estrutura de dados que implemente o protocolo `Collectable`. Pode ser pensado como o oposto de `Enum.reduce/3`.

O `Enum` também tem `Enum.into/3`. O `Enum.into/3` é uma variação do `Enum.into/2` que aceita uma função de transformação a ser aplicada enquanto o enumerável é transformado em um coletável.

#### Mapeando mapas

Em vez de usar `Enum.into/3` ou `Enum.map/2` mais `Enum.into/2` para aplicar uma transformação (mapeamento) a um mapa, também podemos usar uma função dedicada, `Map.new/2`. Ela funciona exatamente como o `Enum.into/3`, no sentido de que aceita um enumerável e uma função de transformação, mas sempre retorna um novo mapa, em vez de nos deixar escolher o coletável.
