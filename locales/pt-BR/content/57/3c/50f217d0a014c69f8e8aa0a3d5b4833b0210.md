# Dicas

## 1. Calcule o valor da diária a partir do valor por hora

- Use os operadores aritméticos como mencionado na introdução deste exercício.

## 2. Calcule o número de dias úteis a partir de um orçamento

- Primeiro determine o valor da diária, depois calcule o número de dias e, por fim, arredonde esse número para baixo.

## 3. Calcule o valor com desconto para projetos grandes

- Arredonde o resultado da divisão para baixo para obter o número de meses completos.
- `100% - discount` é igual à porcentagem cobrada depois de aplicar o desconto.
- Use `MOD`, o operador de resto, para calcular o número de dias que excedem os meses completos.
- Some os valores dos meses com desconto e os valores das diárias cheias e arredonde o resultado para cima.
