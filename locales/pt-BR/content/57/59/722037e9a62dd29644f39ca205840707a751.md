# Mapas e conjuntos

Um array guarda valores em posições numeradas. Às vezes o rótulo útil não é um número.

## Mapas

Um **mapa** associa cada **chave** a um **alvo**. Procure algo pela chave e o mapa te dá o que foi arquivado sob ela.

`FMAP{K,T}` é um mapa de chaves do tipo `K` para alvos do tipo `T`. Um guia que associa o nome de um animal ao lugar onde ele vive é `FMAP{STR,STR}`.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## Sempre atribua a resposta de volta

Repare de novo naquela linha do meio. O `insert` responde com o mapa que tem o par extra dentro dele, e a resposta precisa ser guardada:

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

Essa é a mesma regra de `FSTR`, e pelo mesmo motivo. A resposta costuma ser o próprio mapa que entrou, alterado no lugar; de vez em quando, quando o mapa fica sem espaço, é um mapa maior. Como você não tem como saber qual dos dois, **use a resposta e pare de usar o nome antigo.** Um nome que sobrou de antes de um `insert` pode estar desatualizado ou pode não descrever um mapa utilizável de jeito nenhum.

Isso também significa que um mapa entregue a uma rotina não está a salvo dela. Se o original precisar sobreviver, veja `copy` na página do conceito.

## Ele está lá?

`has_ind` pergunta se uma chave está no mapa. O nome é a abreviação de "has index", e "index" é o que esses mapas chamam de chave.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

Pedir uma chave que não está lá **não** reclama de nada. O `get` devolve o valor vazio do tipo: zero para um `INT` e void para um `STR`, o que vai dar errado mais tarde, em outro lugar. Então verifique antes de buscar:

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## Conjuntos

Um **conjunto** guarda valores sem repetições e sem ordem. `FSET{T}` é um conjunto de valores do tipo `T`.

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

Inserir algo duas vezes deixa uma só cópia. É para isso que um conjunto serve: colecionar coisas esquecendo com que frequência cada uma apareceu.

O `insert` em um conjunto responde com o conjunto a ser usado daí em diante, exatamente como faz em um mapa, então atribua a resposta de volta todas as vezes.

## Quantos

`.size` funciona nos dois: quantos pares um mapa guarda e quantos valores há em um conjunto.
