# Introdução

Em Rust, qualquer tipo que implemente o trait [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) pode ser tratado como um iterador.
As [`collections`](https://doc.rust-lang.org/std/collections/index.html) embutidas do Rust podem ser convertidas em iteradores por meio dos métodos `iter`, `iter_mut` e `into_iter`.
Os iteradores têm uma ampla variedade de [métodos poderosos](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods), como `collect`, `map`, `filter` e `fold`, para você realizar operações nos seus dados.

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
