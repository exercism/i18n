# Complemento das instruções

## Registradores

| Registrador | Uso        | Tipo     | Descrição                                             |
| ----------- | ---------- | -------- | ----------------------------------------------------- |
| `$a0`       | entrada    | endereço | string de entrada terminada em null                   |
| `$v0`       | saída      | Boolean  | a entrada é um isograma (`0` = `false`, `1` = `true`) |
| `$t0-9`     | temporário | qualquer | usados para armazenamento temporário                  |
