# Instalando o Java

Além da CLI do Exercism e do seu editor de texto favorito, praticar com os exercícios de Java do Exercism exige o **Java Development Kit** (JDK). O JDK inclui tanto um Java Runtime _quanto_ ferramentas de desenvolvimento (principalmente o compilador Java).

Hoje em dia existem muitas versões do JDK, e algumas delas são de código aberto. Aqui no Exercism recomendamos o [Eclipse Temurin do Adoptium][adoptium].

## Versões de Java compatíveis

A trilha de Java do Exercism é compatível com o Java 25 LTS e versões anteriores.

## Instalando o Eclipse Temurin

Para instalar o Eclipse Temurin no seu sistema, dê uma olhada nas excelentes [instruções de instalação][adoptium-installation-guide] deles. Lá você vai encontrar instruções sobre como instalar o JDK usando o gerenciador de pacotes que preferir, além de links para instaladores de todos os principais sistemas operacionais.

## IDEs Java

Existem muitas IDEs gratuitas para Java. Aqui estão algumas opções populares:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code com a extensão Java][vscode-java]
