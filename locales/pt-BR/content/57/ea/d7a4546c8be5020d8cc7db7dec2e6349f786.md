# Introdução

O `OpenStruct` permite criar um objeto a partir de um `Hash` com facilidade.
Em vez de precisar acessar usando as chaves do `Hash`, o `OpenStruct` permite usar métodos para acessar e definir valores.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Um bônus dessa abordagem é que podemos aproveitar um atalho ao usar a sintaxe de bloco.
Quando um bloco chama um único método, você pode substituir o bloco por `&:` seguido do nome do método.
Por exemplo, estas duas linhas são sinônimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Biblioteca padrão

Todas as classes que você viu nos exercícios anteriores faziam parte da Core Library do Ruby.

O OpenStruct faz parte da biblioteca padrão do Ruby (muitas vezes abreviada como "stdlib"), uma coleção de classes para trabalhar com coisas como datas, json e redes.
Ela também oferece algumas funcionalidades úteis para deixar seu código mais fácil de trabalhar.

Ao usar classes que não vêm da Core Library (seu próprio código em outros arquivos, classes da biblioteca padrão ou dependências externas), precisamos importá-las com o método `require` antes de usá-las.
Por exemplo:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
