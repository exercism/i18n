# Apêndice das instruções

## Formato da saída

Produza o losango como uma string terminada em null, com um caractere de nova linha no final de cada linha.

Um exemplo de saída seria `"  A  \n B B \nC   C\n B B \n  A  \n"`

## Registros

| Registro | Uso          | Tipo    | Descrição                          |
| -------- | ------------ | ------- | ---------------------------------- |
| `$a0`    | entrada      | byte    | letra                              |
| `$a1`    | entrada/saída | endereço | string de resultado terminada em null |
| `$t0-9`  | temporário   | qualquer | para armazenamento temporário      |
