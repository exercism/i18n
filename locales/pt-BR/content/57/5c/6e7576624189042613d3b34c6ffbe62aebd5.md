# Dicas

## Geral

- [Sobrecarga de métodos em C#][member-overloading].
- [Interpolação de strings][string-interpolation] pode ser usada para formatar strings de descrição.

## 3. Descreva o método de viagem

- Uma [condicional simples][if-statement] pode ser usada para a lógica condicional.

## 4. Descreva um personagem viajando para um destino

- Você pode reutilizar a funcionalidade de descrição existente.
- Você pode usar [expressões em strings interpoladas][string-interpolation-expressions], o que significa que você pode chamar métodos diretamente nas partes interpoladas de uma string interpolada.

## 5. Descreva um personagem viajando para um destino sem especificar o método de viagem

- Você pode reutilizar a funcionalidade existente que usa um método de viagem explícito.
- Você pode usar [parâmetros opcionais][optional-arguments] para simplificar a quantidade de código que você precisa.
