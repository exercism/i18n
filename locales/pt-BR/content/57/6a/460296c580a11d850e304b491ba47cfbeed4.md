# Instruções

Neste exercício, você vai trabalhar com contas poupança.
A cada ano, o saldo da sua conta poupança é atualizado com base na sua taxa de juros.
A taxa de juros que o seu banco oferece depende da quantia de dinheiro na sua conta (o saldo):

- 3.213% para um saldo menor que `0` dólares (o saldo fica ainda mais negativo).
- 0.5% para um saldo maior ou igual a `0` dólares e menor que `1000` dólares.
- 1.621% para um saldo maior ou igual a `1000` dólares e menor que `5000` dólares.
- 2.475% para um saldo maior ou igual a `5000` dólares.

Você tem quatro tarefas, e cada uma delas lida com o saldo e a sua taxa de juros.

## 1. Calcule a taxa de juros

Implemente a função `interest_rate` para calcular a taxa de juros com base no saldo especificado:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. Calcule os juros

Implemente a função `yearly_interest` para calcular os juros com base no saldo especificado:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. Calcule a atualização anual do saldo

Implemente a função `annual_balance_update` para calcular a atualização anual do saldo, levando em conta a taxa de juros:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. Calcule os anos necessários para atingir o saldo desejado

Implemente a função `years_until_desired_balance` para calcular o número mínimo de anos necessários para atingir o saldo desejado, levando em conta que, a cada ano, os juros são adicionados ao saldo.
Isso significa que o saldo depois de um ano é: saldo inicial + juros sobre o saldo inicial.
O saldo depois do segundo ano é o saldo depois de um ano + juros sobre o saldo depois de um ano.
E assim por diante, até que o saldo do ano atual seja maior ou igual ao saldo desejado.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

Repare que o valor retornado é um `int`.
