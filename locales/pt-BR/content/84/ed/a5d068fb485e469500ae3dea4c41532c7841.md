# Apêndice das instruções

## Formato da entrada

Cada dominó é armazenado em um único byte, com a metade esquerda no [nibble] alto e a metade direita no [nibble] baixo. Por exemplo, as pedras `[2|1]`, `[2|3]` e `[1|3]` são representadas pelos bytes `0x21 0x23 0x13`.

## Registradores

| Registrador | Uso       | Tipo    | Descrição                                          |
| ----------- | --------- | ------- | -------------------------------------------------- |
| `$a0`       | entrada   | endereço | array de bytes das pedras                          |
| `$a1`       | entrada   | inteiro | número de pedras                                   |
| `$v0`       | saída     | boolean | os dominós podem formar uma cadeia (`0` = `false`, `1` = `true`) |
| `$t0-9`     | temporário | qualquer | usados para armazenamento temporário               |


[nibble]: https://en.wikipedia.org/wiki/Nibble
