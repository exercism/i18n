# Dicas

## Geral

- Cada tarefa compara um valor com uma lista fixa, que é exatamente para isso
  que o `case` existe.
- Todo `case` precisa de um `else`, mesmo quando os ramos acima parecem
  completos. Sem ele, um valor que não corresponde a nada faz o programa parar.

## 1. A tarifa de uma zona

- Três ramos `when` e um `else`. O `else` cobre todo número que não é uma
  zona.
- Tanto a zona 0 quanto uma zona desconhecida não custam nada, mas são casos
  diferentes; escrevê-las como ramos separados deixa claro o que se pretende.

## 2. Que tipo de bilhete?

- `'c'` e `'s'` dão a mesma resposta, então compartilham um ramo:
  `when 'c', 's' then`.
- Aspas simples: o argumento é um `CHAR`, não um `STR`.

## 3. Que tipo de dia?

- Dois ramos, um listando dois dias e outro listando cinco.
- Strings se comparam com `=` do mesmo jeito que os números, então funcionam
  num `case` sem nenhuma mudança.

## 4. O limite diário

- Você já tem uma rotina que transforma um dia num tipo de dia. Chame-a e
  depois faça um `case` sobre a resposta.
- Fazer assim significa que a lista de dias é escrita uma vez só. Repeti-la
  aqui é o erro que esta tarefa foi feita para pegar.
