# Sobre

Um dos aspectos principais de trabalhar com números em Java é a distinção entre inteiros (números sem dígitos depois do separador decimal) e números de ponto flutuante (números com zero ou mais dígitos depois do separador decimal).

O Java tem outros [tipos de dados][numeric-datatypes] além de `int` e `double`:

```java
// 8-Bit Integer
byte   a = 127;

// 16-Bit Integer
short  b = 262143;

// 64-Bit Integer
long   d = 18446744073709551999L;

// 32-bit Single-Precision Floating-Point
float  e = 5409.29f;
```

Tanto inteiros quanto números de ponto flutuante podem usar o caractere `_` como _separador de dígitos_, o que ajuda na hora de definir números grandes:

```java
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

A aritmética é feita com os [operadores aritméticos][arithmetic-operators] padrão (`+`, `-`, `*`, etc.).
Números podem ser comparados com os [operadores de comparação][comparison-operators] padrão (`<`, `>=`, etc.), junto com o operador de igualdade (`==`) e o operador de desigualdade (`!=`).

```java
5 * 6
// => 30

1.2 > 0.8
// => true

120 == 100
// => false

2 != 4
// => true
```

Ao converter entre tipos numéricos, existem dois tipos de conversão numérica:

1. Conversões implícitas: nenhum dado é perdido e nenhuma sintaxe adicional é necessária.
2. Conversões explícitas: dados podem ser perdidos e é necessária uma sintaxe adicional na forma de um _cast_.

Como um `int` tem menos precisão que um `double`, converter de `int` para `double` é seguro e, por isso, é uma [conversão implícita][type-casting].
Já converter de `double` para `int` pode significar perda de dados, então isso exige uma [conversão explícita][type-casting].

```java
int i = 9;
double d = 2.72;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
