# Dicas

## Geral

- As palavras de string que você vai precisar estão em [`splitting`][splitting] e
  [`sequences`][sequences]; `blank?` está em `ascii`. Atualize sua
  linha `USING:` conforme avança.

## 1. Limpe o nome

- `replace ( seq old new -- new-seq )` faz substituição de substring.
- `[ blank? ] trim` remove espaços em branco no início e no fim.

## 2. Obtenha a primeira letra do nome

- Depois de `cleanupname`, pegue o primeiro caractere com `first` e depois
  envolva-o em uma string de um único caractere com `1string`.

## 3. Formate a primeira letra como uma inicial

- Use `>upper` (em `ascii`) para deixar a letra maiúscula e depois use `append`
  para adicionar um `"."` no final.

## 4. Coloque as iniciais dentro do coração

- `bi@ ( x y quot -- ... )` é a forma natural de aplicar `initial` aos
  dois nomes com uma única chamada de combinador: `[ initial ] bi@`.
- Depois do `bi@`, você tem as duas iniciais na pilha. Junte-as com um
  separador usando `glue` e envolva o resultado com o prefixo e o
  sufixo do coração usando `surround`.
- O caractere do coração é `\u{2764}` dentro de um literal de string do Factor.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
