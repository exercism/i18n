# Instruções

Neste exercício, você vai ajudar namorados do ensino médio a declarar seu amor nas redes sociais gerando um coração em ASCII com a inicial deles:

```
❤ J.  +  M. ❤
```

## 1. Limpe o nome

Implemente o método `HighSchoolSweetheart.clean_up_name`.
Ele deve receber um nome, remover todos os caracteres `-` e substituí-los por um espaço.
Ele também deve remover qualquer espaço em branco do início e do fim do nome.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. Obtenha a primeira letra do nome

Implemente o método `HighSchoolSweetheart.first_letter`.
Ele deve receber um nome e retornar sua primeira letra.
Certifique-se de reutilizar o método `HighSchoolSweetheart.clean_up_name` que você definiu na etapa anterior.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. Formate a primeira letra como uma inicial

Implemente o método `HighSchoolSweetheart.initial`.
Ele deve receber um nome e retornar sua primeira letra, em maiúscula, seguida de um ponto.
Certifique-se de reutilizar o método `HighSchoolSweetheart.first_letter` que você definiu na etapa anterior.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. Coloque as iniciais dentro do coração

Implemente o método `HighSchoolSweetheart.pair`.
Ele deve receber dois nomes e retornar as iniciais com corações em emoji ao redor.
Certifique-se de reutilizar o método `HighSchoolSweetheart.initial` que você definiu na etapa anterior.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
