# Dicas

## 1. Faça algo magnífico

- O mapeamento é o processo correto para aplicar uma função a cada elemento de uma sequência.
- `mapcar` é uma boa função para aplicar uma função a cada item de uma lista.

## 2. Apenas o melhor

- A filtragem é o processo correto para remover um ou mais itens de uma sequência, gerando uma nova sequência.
- `remove` pode remover de uma sequência os valores iguais a um item específico.
- `remove-if` pode remover os valores para os quais uma função de predicado resulta em um valor verdadeiro.
