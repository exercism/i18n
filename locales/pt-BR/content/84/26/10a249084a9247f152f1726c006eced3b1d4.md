# Testes

Você pode usar o editor online no site do Exercism para resolver os exercícios.
Ou baixe os exercícios para o seu computador, resolva-os localmente e depois envie-os para o Exercism.

Se você quiser trabalhar localmente, vai precisar do programa [`bats`][bats].
Consulte a página [Testar na trilha Bash][test-bash] para ver as instruções de instalação.

Seu código será testado no test runner jq do Exercism usando o [`jq` versão **1.8**][jq].

[bats]: https://github.com/bats-core/bats-core
[test-bash]: https://exercism.org/docs/tracks/bash/tests
[jq]: https://jqlang.org/manual/
