# Instructions

De repente, você sente um acesso de nostalgia e uma forte vontade de tirar o pó das suas velhas cartas de Blorkemon™️.
Blorkemon™️ cards é um ótimo jogo de troca de cartas à moda antiga.
Cada `Card` tem um monstro Blorkemon™️ desenhado, junto com um nível de poder de ataque e, se você tiver sorte, a carta pode até ser brilhante.

## 1. Compare os níveis de poder

Cada carta de Blorkemon™️ parece mais poderosa que a anterior, mas é melhor você conferir.

Implemente a função `isMorePowerful`. Ela deve retornar `True` se a carta do primeiro argumento for estritamente mais poderosa que a outra, e `False` caso contrário.

```elm
newthree = Card "Newthree" 120 False
scientuna = Card "Scientuna" 6 True

isMorePowerful newthree scientuna
    --> True
```

## 2. Encontre o maior poder

Com uma mão cheia de cartas de Blorkemon™️, você deve conseguir preparar o ataque mais devastador.

Implemente a função `maxPower`, que retorna o maior nível de poder entre duas cartas.

```elm
maxPower newthree scientuna
    --> 120
```

## 3. Ordene as cartas

Parece que você se lembra de ter pelo menos uma carta de cada Blorkemon™️, mas já faz um tempo desde a última vez que você conferiu. Você deve ordenar suas cartas para compará-las com a lista oficial na Pulpapedia.

Implemente a função `sortByMonsterName`, que deve receber uma lista de `Cards` e retornar uma lista ordenada pelos nomes dos monstros.

```elm
sortByMonsterName [newthree, scientuna]
    --> [Card "Newthree" 120 False, Card "Scientuna" 6 True]
```

## 4. As cartas mais legais primeiro

Os Blorkemon™️ são a coisa mais legal que existe.
Você não está usando esse termo à toa. Você tem um método científico para comprovar isso.

Implemente a função `sortByCoolness`, que ordena uma lista de cartas colocando as mais legais primeiro.
O quão legal uma carta é, em primeiro lugar, é determinado pelo seu brilho: todas as cartas brilhantes são muito mais legais que as outras.
O segundo fator é o nível de poder, quanto maior, melhor.

```elm
sortByCoolness [newthree, scientuna]
    --> [Card "Scientuna" 6 True, Card "Newthree" 120 False]
```

## 5. Poder Brilhante

O brilho não é só enfeite: em uma batalha entre Blorkemon™️ com o mesmo poder, o brilhante sempre leva a melhor.
Isso se chama Poder Brilhante.

Implemente a função `compareShinyPower`, que codifica essa propriedade.
A `Order` de duas cartas é determinada pelos níveis de poder, se forem diferentes, mas, se forem iguais, uma carta brilhante será maior.

```elm
compareShinyPower newthree scientuna
    --> GT
```

## 6. Faça suas apostas

Em um jogo de cartas Blorkemon™️, tudo pode acontecer, mas ainda há uma tendência de as cartas mais poderosas vencerem.

Implemente a função `expectedWinner`, que retorna o nome do monstro com maior expectativa de vitória, de acordo com a ordenação de `compareShinyPower`.
A função deve retornar o nome do monstro do provável vencedor, ou "too close to call" se os dois oponentes tiverem o mesmo Poder Brilhante.

```elm
expectedWinner newthree scientuna
    --> "Newthree"
```
