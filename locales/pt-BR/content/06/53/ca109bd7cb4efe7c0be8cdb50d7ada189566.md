# Instruções

Escreva uma função que converta números normais em [números ordinais](https://en.wikipedia.org/wiki/Ordinal_numeral). Para o zero (0), basta retornar "0" como string.

Números ordinais são números que descrevem a posição de algo em uma lista. É nesse contexto que os números ordinais serão usados, com o nome de um número ordinal grafado em inglês.

Os números ordinais são (pelo menos, uma forma deles):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

Então, ao inserir um número normal, o resultado é o seu equivalente ordinal:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
