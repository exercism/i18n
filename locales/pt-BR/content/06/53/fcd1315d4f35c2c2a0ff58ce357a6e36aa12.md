Mas as coisas estão um pouco desorganizadas: as coordenadas de Azara parecem estar formatadas e ordenadas de maneira diferente das de Rui, e eles precisam ficar alternando entre uma lista e outra para descobrir quais tesouros combinam com quais locais.
Como aspirantes a programadores de F#, eles vieram pedir sua ajuda para escrever um pequeno programa (na verdade, um conjunto de funções) para organizar melhor as informações da caça.

## 1. Extrair coordenadas

Implemente a função `getCooordinate()` que recebe um par `(treasure, coordinate)` da lista de Azara e retorna apenas a coordenada do mapa extraída.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. Formatar coordenadas

Implemente a função `convertCoordinate()` que recebe uma coordenada no formato "2A" e retorna uma tupla no formato `(2, 'A')`.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. Comparar coordenadas

Implemente a função `compareRecords()` que recebe um par `(treasure, coordinate)` e um registro `(location, coordinate, quadrant)` e compara as coordenadas de cada um.
Retorne **`true`** se as coordenadas "combinarem", e retorne **`false`** se não combinarem.
Reformate as coordenadas conforme necessário para uma comparação precisa.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. Combinar registros correspondentes

Implemente a função `createrecord()` que recebe um par `(treasure, coordinate)` da lista de Azara e um registro `(location, coordinate, quadrant)` da lista de Rui e retorna `(coordinate, location, quadrant, treasure)` **se as coordenadas combinarem**.
Se as coordenadas _não_ combinarem, retorne uma tupla com o mesmo formato, mas preenchida com `""`.
Reformate as coordenadas conforme necessário para uma comparação precisa.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
