# Introdução

Jogos de azar precisam de uma fonte de aleatoriedade. O vocabulário [`random`][random] do Factor fornece uma palavra genérica, `random`, que se adapta a tudo o que você passar para ela, além de auxiliares para embaralhar e coletar amostras, e uma forma de tornar a aleatoriedade *reproduzível* para os testes.

## Marcar uma palavra como `inline`

Algumas tarefas deste exercício definem uma palavra que recebe uma *quotation* (um bloco `[ … ]`) como argumento e a executa. O Factor tem uma regra firme sobre isso: **uma palavra que faz `call` numa quotation que recebeu como argumento precisa ser declarada `inline`**, o que se escreve colocando `inline` logo depois do `;` de fechamento.

`inline` diz ao compilador para inserir o corpo da palavra em cada ponto de chamada em vez de compilá-lo uma única vez, isoladamente.

- A quotation de quem chama é costurada diretamente, então **tudo o que a quotation deixa na pilha flui de volta para quem chamou**, mesmo que o próprio efeito de pilha da palavra não declare nenhuma saída.

Veja uma palavra pequena que empilha `10` e depois executa a quotation que recebeu:

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

O efeito de pilha dela, `( quot -- )`, não nomeia nenhuma saída, mas chamá-la com duas quotations de efeitos *diferentes* produz resultados diferentes, todos fluindo de volta para quem chamou:

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random`: um elemento

`random` (de [`random`][random]) é genérica em relação ao seu argumento:

```
random ( obj -- elt )
```

- Dado um **inteiro** `n`, ela retorna um inteiro aleatório em `[0, n)`:

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- Dada uma **sequência**, ela retorna um elemento aleatório:

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

Para rolar um dado comum, você desloca o intervalo em uma unidade: `random` com `6` dá de 0 a 5, então `6 random 1 +` dá de 1 a 6.

## Sortear vários valores

Para coletar um número fixo de sorteios aleatórios, repita uma quotation com `replicate` (de [`sequences`][sequences]):

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize`: embaralhar no lugar

`randomize` (de [`random`][random]) retorna a sequência com os elementos em ordem aleatória:

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

Ela embaralha **no lugar** e retorna a mesma sequência, então use `clone` antes se precisar manter a ordem original.

## `sample`: vários elementos distintos

`sample` (de [`random`][random]) sorteia `n` elementos *distintos* de uma sequência, como distribuir uma mão de cartas, nunca a mesma carta duas vezes:

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

Pedir mais elementos do que a sequência tem é um erro.

## Aleatoriedade reproduzível

Por padrão, `random` sorteia de um gerador global cuja semente vem do relógio do sistema, então cada execução é diferente. Para testes, ou sempre que você quiser um jogo que possa *repetir*, associe um gerador a uma **semente** fixa.

`<mersenne-twister>` (de [`random.mersenne-twister`][mt]) constrói um gerador a partir de uma semente inteira, e `with-random` (de [`random`][random]) executa uma quotation com esse gerador instalado:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

Tudo dentro da quotation (`random`, `randomize`, `sample`) sorteia do gerador com semente, então a mesma semente sempre reproduz o mesmo resultado.

Uma palavra que recebe uma quotation como argumento e a executa por meio de `with-random` cai na regra de [Marcar uma palavra como `inline`](#marking-a-word-inline): `with-random` acaba fazendo `call` nessa quotation, então esse tipo de wrapper precisa ser marcado como `inline`.
