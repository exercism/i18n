# Dicas

## 1. Defina um novo dicionário de recordes

- [Dicionários vazios][empty-dictionary] podem ser inicializados escrevendo o nome do tipo seguido de um par de parênteses vazios ou, se o tipo puder ser determinado pelo contexto, usando o literal de dicionário vazio.

## 2. Adicione jogadores ao dicionário de recordes

- Um dicionário precisa ser declarado como uma variável para que você possa adicionar elementos a ele.
- Elementos podem ser adicionados a um dicionário usando a [sintaxe de subscrito de dicionário][dictionary-subscripts].

## 3. Remova jogadores do dicionário de recordes

- Um dicionário precisa ser declarado como uma variável para que você possa remover elementos dele.
- Elementos podem ser removidos de um dicionário usando o [método apropriado][dictionary-docs].

## 4. Redefina a pontuação de um jogador

- Um dicionário precisa ser declarado como uma variável para que você possa alterar valores nele.
- Valores podem ser atualizados em um dicionário usando a [sintaxe de subscrito de dicionário][dictionary-subscripts].

## 5. Atualize a pontuação de um jogador

- Um dicionário precisa ser declarado como uma variável para que você possa alterar valores nele.
- Valores podem ser atualizados em um dicionário usando a [sintaxe de subscrito de dicionário][dictionary-subscripts].

## 6. Obtenha uma lista de jogadores com suas pontuações, ordenada pelo nome do jogador

- Os elementos do dicionário podem ser ordenados usando o [método apropriado][dictionary-docs].
- Você precisará definir uma função de ordenação do tipo `((String, Int), (String, Int)) -> Bool` para passar ao método `sorted(by:)`.
- A função de ordenação deve retornar `true` se o par chave/valor da esquerda deve aparecer _antes_ do par chave/valor da direita na saída ordenada.

## 7. Obtenha uma lista de jogadores ordenada pela pontuação do jogador, em ordem decrescente

- Os elementos do dicionário podem ser ordenados usando o [método apropriado][dictionary-docs].
- Você precisará definir uma função de ordenação do tipo `((String, Int), (String, Int)) -> Bool` para passar ao método `sorted(by:)`.
- A função de ordenação deve retornar `true` se o par chave/valor da esquerda deve aparecer _antes_ do par chave/valor da direita na saída ordenada.
