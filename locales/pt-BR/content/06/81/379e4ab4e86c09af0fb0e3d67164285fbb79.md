# Apêndice das instruções

## Implementação

Você vai ver um arquivo `cases_test.go` neste exercício.
Ele contém os casos de teste usados no `leap_test.go`.
Você pode basicamente ignorar esse arquivo.

Mas, se você tiver curiosidade... às vezes geramos os dados de teste a partir de um [repositório multilinguagem][problem-specifications-leap].
Nesse repositório, os exercícios podem ter um [arquivo .json][problem-specifications-leap-json] que contém dados de teste comuns.
Alguns dos nossos exercícios locais têm um [programa intermediário][local-leap-gen] que pega o JSON da especificação do problema e o transforma em structs Go que alimentam o arquivo `<exercise>_test.go`.
A transformação específica de Go desses dados fica no arquivo `cases_test.go`.

[problem-specifications-leap]: https://github.com/exercism/problem-specifications/tree/master/exercises/leap
[problem-specifications-leap-json]: https://github.com/exercism/problem-specifications/blob/master/exercises/leap/canonical-data.json
[local-leap-gen]: https://github.com/exercism/go/blob/main/exercises/practice/leap/.meta/gen.go
