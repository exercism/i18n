# Testes

Você pode implementar um exercício no seu próprio sistema SAP. Siga estes passos:

1. Crie um pacote SAP para todos os exercícios do Exercism no seu sistema (nome recomendado: `$EXERCISM`)
2. Crie um pacote SAP para cada exercício como um subpacote (nome recomendado: `$EXERCISM_<name-of-exercise>`, exemplo: `$EXERCISM_HELLO-WORLD`)
3. Crie uma classe ABAP correspondente ao exercício (exemplo: `ZCL_HELLO_WORLD`)
4. Copie o código modelo do Exercism para a classe
5. Mantenha as classes de teste e copie o código do Exercism para a classe de teste

Agora você pode concluir a implementação da classe e rodar o teste de unidade para ver se a sua solução funciona corretamente.

Observação: essa configuração de pacotes permite que você faça backup de todo o seu trabalho usando o [abapGit](https://abapgit.org), criando um repositório para o pacote `$EXERCISM`.

Para mais detalhes, consulte a [documentação de ABAP do Exercism](https://exercism.org/docs/tracks/abap).
