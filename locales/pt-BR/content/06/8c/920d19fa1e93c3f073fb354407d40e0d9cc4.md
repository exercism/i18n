# Introdução

Os tipos que implementam a interface `IEnumerable<T>` são conhecidos como _enumeráveis_. Todos os tipos de coleção nativos implementam essa interface.

Um tipo enumerável pode ser iterado com um laço `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Para implementar `IEnumerable<T>`, um tipo precisa implementar um método: `IEnumerator<T> GetEnumerator()`. Como visto, um enumerável delega a iteração de fato sobre uma coleção a um tipo `IEnumerator<T>`. Essa interface tem uma propriedade e três métodos para implementar:

- `public T Current { get; }`: obtém o elemento atual.
- `public bool MoveNext ();`: avança para o próximo elemento, retornando `true` se a passagem para o próximo elemento deu certo, e `false` se não (não há mais elementos).
- `public void Reset ();`: reinicia o enumerador ao seu estado inicial (antes do primeiro elemento).
