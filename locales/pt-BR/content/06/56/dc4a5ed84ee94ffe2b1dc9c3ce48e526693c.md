# Introdução

O PHP fornece diversos operadores para realizar operações aritméticas. O PHP segue a ordem padrão das operações matemáticas para seus operadores aritméticos. Os operadores fornecidos pelo PHP são:

* Identidade (+)
* Negação (-)
* Adição (+)
* Subtração (-)
* Multiplicação (*)
* Divisão (/)
* Módulo (%)
* Exponenciação (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
