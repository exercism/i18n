# If, Elseif, Else

As condicionais que usam `if`, `elseif` e `else` são uma parte fundamental do fluxo de controle do programa.
A condicional `if` avalia uma expressão e, se ela for `true`, executa o bloco de código.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Se a expressão não for um valor Boolean, a avaliação determina a "veracidade" ou a "não falsidade" desse valor.
Em PHP, os seguintes valores são considerados iguais a false:

- Boolean `false`
- inteiro `0`
- número de ponto flutuante `0.0` e `-0.0`
- um array vazio `[]`
- uma string vazia `""` ou uma string numérica `"0"`
- `null`

Todos os outros valores são considerados true.

## Respondendo a várias condições

Depois de uma condicional `if`, você pode encadear várias condições usando `elseif` e `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Apenas uma condicional avaliada como verdadeira será executada.
Então, se várias condições puderem ser verdadeiras, a ordem em que elas são escritas é importante.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
