# Anexo às instruções

## Como este exercício está estruturado na trilha Python

Os testes deste exercício esperam que seu programa seja implementado como uma [`class`][classes in python] Garden (_veja também [concept:python/classes]()_).
Se você ainda não conhece classes em Python, este [tutorial do Real Python][how-to-make-a-class] pode ser um bom ponto de partida adicional.

Sua `class` deve implementar um [`method`][methods] chamado `plants`, que recebe o nome de um estudante como argumento e retorna a `list` de nomes de plantas pertencentes a esse estudante.


## Construtores

Criar o jardim de exemplo:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

seria, nos testes, representado como `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`.

Para que essa representação funcione, sua `class` precisará implementar um [`__init__()`][init] [método especial][special-methods].
Se você não conhece `__init__()` nem [_construtores_][what-is-a-constructor], [objetos de classe e de instância][class vs instance objects in python] da documentação do Python traz uma explicação mais detalhada.


## Parâmetros padrão

Em alguns testes, uma `list` de estudantes é passada como argumento para `__init__()`.
Isso deve substituir a lista de doze estudantes fornecida no enunciado do problema.
As duas instruções a seguir precisam funcionar com seu método `__init__()`:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

Uma abordagem é transformar a `list` de estudantes em um [argumento padrão][default argument values]; a documentação do Python descreve `default parameters` em detalhe ao explicar [definições de função][function definitions].
