# Introdução

**Expressões regulares** (regex) são sequências de caracteres que especificam um padrão de busca em um texto.

Aprender a sintaxe de expressões regulares está além do escopo deste tópico.
Vamos focar nas expressões que o `jq` oferece para usar regexes.

## Variante de regex

Ferramentas diferentes implementam versões diferentes de expressões regulares.
O `jq` incorpora a biblioteca de regex [Oniguruma][oniguruma], que é bastante compatível com as regexes do Perl v5.8.

A sintaxe específica usada pelo `jq` pode ser [encontrada no repositório do Oniguruma no GitHub][onig-syntax].

<!-- prettier-ignore -->
~~~~exercism/caution
O `jq` não tem nenhuma sintaxe especial para expressões regulares.
Elas são simplesmente escritas como strings.
Isso significa que qualquer barra invertida na expressão regular precisa ser escapada na string.

Por exemplo, a classe de caracteres de dígitos (`\d`) precisa ser escrita como `"\\d"`.
~~~~

<!-- prettier-ignore-end -->

## Funções de regex

As expressões regulares no `jq` se limitam a [um conjunto de filtros][jq-regex-funcs].

### Correspondência simples

Quando você precisa saber se uma string corresponde a um padrão, use o filtro `test`.

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

Esse filtro gera um resultado _boolean_.

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### Informações sobre a correspondência

Quando você precisa extrair a substring que de fato correspondeu ao padrão, use o filtro `match`.

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

Esse filtro gera:

- nada, se não houver correspondência, ou
- um objeto com várias propriedades, se houver correspondência.

Este exemplo procura duas vogais idênticas consecutivas usando a sintaxe de referência inversa, `\1`.

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

O filtro `match` retorna um objeto para _cada_ correspondência.
Este exemplo mostra a flag `"g"` em ação para encontrar todas as vogais.

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### Substrings capturadas

Assim como o filtro `match`, o filtro `capture` retorna um objeto quando há correspondência.

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

O objeto retornado é um mapeamento das **capturas nomeadas**.

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### Apenas as substrings

O filtro `scan` é parecido com o `match` com a flag `"g"`.

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

O `scan` gera um _fluxo_ de substrings.

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

Use o construtor de array `[...]` para capturar as substrings.

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### Dividindo uma string

Se você sabe quais partes da string quer **manter**, use `match` ou `scan`.
Se você sabe quais partes quer **descartar**, use `split`.

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
O filtro `split` de **aridade 1** trata seu argumento como uma **string fixa**.

Para usar uma regex com o `split`, você **precisa** fornecer o segundo argumento; pode usar uma string vazia.
~~~~

<!-- prettier-ignore-end -->

Um exemplo que divide uma string em espaços em branco arbitrários.

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### Substituições

Os filtros `sub` e `gsub` podem transformar a string de entrada, substituindo as partes correspondentes pela string de substituição.

Para substituir apenas a primeira correspondência, use `sub`.
Para substituir todas as correspondências, use `gsub`.

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

O texto de substituição pode se referir às substrings correspondentes; use capturas nomeadas e [interpolação de string][jq-interp].

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## Flags

Em todos os filtros acima, FLAGS é uma string formada por zero ou mais das flags suportadas.

- `g` - Busca global (encontra todas as correspondências, não apenas a primeira)
- `i` - Busca sem diferenciar maiúsculas e minúsculas
- `m` - Modo multilinha ('.' corresponde a quebras de linha)
- `n` - Ignora correspondências vazias
- `p` - Os modos s e m ficam ativados
- `s` - Modo de linha única ('^' -> '\A', '$' -> '\Z')
- `l` - Encontra as correspondências mais longas possíveis
- `x` - Formato estendido de regex (ignora espaços em branco e comentários)

Por exemplo

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
