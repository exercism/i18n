# Instruções

Considere uma função polinomial na forma f(x) = ax^3 + bx^2 + cx + d. Mínimos locais são definidos como f(x) < f(x - delta) e f(x) < f(x + delta). Usando essa definição, deduza uma expressão para o mínimo local e também determine um mínimo local com os coeficientes dados (a, b, c, d). Os coeficientes vão descrever uma função com pelo menos um mínimo.
Retorne a coordenada x onde o mínimo ocorre.
