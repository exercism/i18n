# Instruções

Você está ajudando em um levantamento de aves. A cada dia, alguém se senta em um observatório e conta o que passa voando, e as contagens do dia chegam como um array.

As cinco tarefas ficam na classe `BIRD_SURVEY`.

## 1. O total

Some a contagem de cada dia.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

Um levantamento sem nenhum dia conta zero aves.

## 2. O melhor dia

Retorne a maior contagem. Se não houve nenhum dia, a resposta é zero.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. Os dias movimentados

Quantos dias tiveram uma contagem acima de algum número?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

Acima é acima: uma contagem de exatamente 2 não conta.

## 4. Observatórios a verificar

No primeiro dia do levantamento, você verifica um observatório; no segundo dia, dois; e assim por diante. Quantas verificações de observatório são no total?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

Ou seja, 1 + 2 + 3 + 4.

## 5. O primeiro dia movimentado

Qual foi o primeiro dia com uma contagem acima de algum número? Os dias são numerados a partir de zero, assim como as posições de um array. Se nenhum dia foi tão movimentado, a resposta é `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
