# Sobre

O Swift fornece instruções de transferência de controle para alterar o fluxo de execução de laços e instruções switch.
Além do `return`, o Swift inclui `continue`, `break`, rótulos de laço e `fallthrough`.

## Continue

A instrução `continue` diz a um laço para parar de executar a iteração atual e começar imediatamente a próxima iteração.
Em um laço `while` ou `repeat-while`, ela salta direto para a verificação da condição.
Em um laço `for-in`, ela avança para o próximo elemento da sequência.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

A instrução `break` encerra imediatamente um laço ou uma instrução switch por completo.
A execução continua na primeira linha de código após o laço ou a instrução switch.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Instruções com rótulo

Em laços aninhados, você pode querer que `break` ou `continue` afetem um laço externo em vez do laço mais interno.
Você pode rotular um laço colocando um nome e dois-pontos antes dele (`labelName:`).
Depois, você pode passar esse rótulo para `break` ou `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

Em Swift, instruções `switch` não continuam para o próximo case por padrão; a execução para automaticamente no fim do case correspondente.
Se você quiser explicitamente que a execução continue para o próximo case sem avaliar o padrão dele, use a palavra-chave `fallthrough`:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
