# Introdução

## Fundamentos

Vamos nos referir à _linguagem_ como **AWK** e ao _executável_ que interpreta programas AWK como **`awk`** ou **`gawk`**.

### Padrões e ações

Um programa AWK é composto de **pares padrão-ação**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

Um **padrão** pode ser uma expressão regular para corresponder à entrada.
Também pode ser qualquer expressão que resulte em um valor verdadeiro ou falso.

Uma **ação** é um ou mais comandos AWK.
As chaves ao redor são obrigatórias.

Se o resultado do padrão for _verdadeiro_, a ação correspondente é executada.

### Registros e campos

O AWK analisa a entrada como uma série de **registros**.
Cada registro é dividido em zero ou mais **campos**.

O comportamento padrão é:

- dividir a entrada em registros usando a quebra de linha como "separador de registros", de modo que cada _linha_ seja um registro.
- dividir o registro em campos usando espaços em branco como "separador de campos", de modo que cada _palavra_ seja um campo.

### Padrões e ações, continuação

O padrão pode ser omitido, e nesse caso a ação é executada _para cada registro de entrada_.

A ação pode ser omitida, e nesse caso a ação padrão é imprimir o registro atual.

#### Padrões especiais

Há dois padrões especiais que são usados com frequência.

- `BEGIN` executa a ação associada antes que qualquer entrada seja consumida.
- `END` executa a ação associada depois que toda a entrada for consumida.

### Variáveis de campo

Você se refere aos campos como `$1`, `$2`, `$3` etc.

O registro atual é `$0`.

Aqui estão algumas outras variáveis internas usadas com frequência.

#### Variáveis internas que controlam a análise da entrada

- `RS` é o separador de registros da entrada.
  Como mencionado, seu valor padrão é uma quebra de linha.
- `FS` é o separador de campos da entrada.

Essas variáveis geralmente são definidas no bloco de ação `BEGIN`.

#### Variáveis internas que trazem informações

Essas variáveis são definidas automaticamente pelo AWK durante a execução do programa.

- `NF` armazena o número de campos no registro atual.
  - Para obter o valor do último campo, use `$NF`.
- `NR` armazena o número do registro atual.
  - Quando vários arquivos de entrada estão sendo processados, `NR` contém o número total de registros processados até o momento.
- `FNR` armazena o número do registro atual no arquivo de entrada atual.
  - Para ilustrar a diferença entre NR e FNR, aqui está uma expressão idiomática comum do AWK.
    ```awk
    NR == FNR {action}
    ```
    Isso significa "se o número acumulado de registros for igual ao número de registros do arquivo atual".
    Isso só pode ser verdadeiro para registros do _primeiro arquivo de entrada_.

### Veracidade

O AWK usa o mesmo conceito de veracidade que o C.

- O número `0` é falso.
- Qualquer outro número é verdadeiro.

Como o AWK é uma linguagem de processamento de texto, os valores de verdade se estendem às strings.

- Uma string vazia `""` é falsa.
- Qualquer string não vazia é verdadeira.

### Comentários

Os comentários começam com o caractere `#` e vão até o fim da linha.

### Exemplos

Em sistemas do tipo Unix, `/etc/passwd` contém informações sobre usuários.
Cada usuário é descrito em uma linha separada, com os campos separados por dois-pontos.

Para listar os nomes de usuário:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Repare que a ação `{print $1}` não tem padrão, então ela é executada para cada registro.

Se quisermos limitar a saída apenas aos usuários que usam o bash como shell de login, podemos fazer:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
