# sem export nomeado

Não encontramos [`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export).
Os testes não vão passar sem isso.

Verifique se `%{export.name}` existe e adicione `export` na frente:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
