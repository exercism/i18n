# Apêndice de instruções

## Implementação

Defina
`type Classification`
para conter os valores de classificação dos números naturais.
Você pode escolher qualquer representação para esse tipo.

Defina três constantes Classification com os nomes

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

Implemente uma função chamada Classify que aceita
uma entrada int64 e retorna uma Classification e um valor de erro.

Crie um erro chamado ErrOnlyPositive,
que é retornado quando a entrada não é um número inteiro positivo.
