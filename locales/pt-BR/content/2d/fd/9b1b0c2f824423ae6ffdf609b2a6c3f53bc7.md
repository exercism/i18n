# Instruções

Você está trabalhando em um jogo voltado para um sistema embarcado de baixo consumo e precisa escrever várias funções utilitárias que serão usadas por outras partes do jogo.

## 1. Calcule o quociente e o resto de uma divisão

O quociente é o resultado de uma divisão.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

Exemplo:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. Escolha itens em posições pares de um iterador

Isso vai ajudar a viabilizar uma otimização do buffer da tela, promete seu chefe.

Iteradores são itens que expõem os métodos definidos pela [trait `Iterator`](https://doc.rust-lang.org/std/iter/trait.Iterator.html). Essa documentação é bastante extensa, porque oferecem muitos métodos; aqui estão as propriedades mais relevantes:

- Um iterador é um fluxo de itens de tamanho arbitrário
- Eles têm um [método `enumerate`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate) que retorna uma tupla `(i, val)` para cada valor
- Eles têm um [método `filter`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter) que usa uma closure para determinar se deve produzir um elemento do iterador
- Eles têm um [método `map`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map) que usa uma closure para modificar elementos do iterador

Como sua função pode rodar em qualquer tipo de iterador, ela usa `impl` para indicar que se trata de uma instância de trait e não de um item simples. Do mesmo modo, a sintaxe `<Item=T>` significa apenas que não importa que tipo de item o iterador produz; sua função pode produzir os elementos pares de qualquer iterador.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

Exemplos:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. Calcule a distância de Manhattan de uma posição até a origem

Para facilitar o mapeamento, você tem uma struct de tupla `Position`:

```rust
struct Position(i16, i16);
```

Você precisa implementar um método `manhattan` em `Position` que retorna a [distância de Manhattan](https://en.wikipedia.org/wiki/Taxicab_geometry) dessa posição até a origem (`Position(0, 0)`).

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

Exemplo:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
