# Introdução

Cairo não tem um tipo nativo para strings, mas oferece duas formas de lidar com elas: strings curtas usando aspas simples e `ByteArray` usando aspas duplas.

Uma string curta é uma string ASCII em que cada caractere é codificado em um byte.

O tipo que o Cairo usa para strings curtas por padrão é `felt252`, o que faz com que o comprimento máximo seja de apenas 31 caracteres.

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

Tecnicamente, qualquer tipo inteiro menor que `felt252` pode ser representado usando o formato de string curta.

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

Para strings com mais de 31 caracteres, o Cairo oferece o `ByteArray`, que tem comprimento ilimitado.

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

ByteArrays podem ser concatenados com o operador `+`:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Alguns caracteres especiais precisam ser escapados com uma barra invertida no início, como `\t` para uma tabulação e `\n` para uma quebra de linha em strings.

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Você pode até acessar bytes individuais dentro de um ByteArray usando o índice dele.

Mas atenção: o tipo do byte retornado é `u8`, e não `ByteArray`!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

A biblioteca principal oferece muitos métodos e operadores úteis para trabalhar com ByteArrays.

Para mais informações sobre os métodos de ByteArray, confira a [documentação do ByteArrayTrait][docs].

Veja alguns exemplos:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
