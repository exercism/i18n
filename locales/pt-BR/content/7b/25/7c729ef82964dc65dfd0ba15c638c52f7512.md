# Introdução

Tipos personalizados são a forma como novos tipos de dados são definidos em Gleam. Eles podem ter várias _variantes_, cada uma com seu próprio nome.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Cada variante de um tipo personalizado pode, opcionalmente, guardar algum dado, e variantes diferentes podem ter tipos de dados diferentes. Quando uma variante guarda dados, ela é chamada de _registro_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Para criar um valor de uma variante específica, você pode se referir ao nome dela, caso ela não contenha dados adicionais (`Spring`), ou chamá-la como uma função, caso contenha (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Tipos personalizados, assim como tudo em Gleam, têm _igualdade estrutural_, o que significa que dois valores da mesma variante e com os mesmos dados são equivalentes.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Você pode fazer correspondência de padrões nas variantes de um tipo personalizado usando expressões case.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
