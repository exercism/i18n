O Elixir tem convenções de nomenclatura específicas, que incluem como nomear [funções que retornam um booleano](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo):

> Funções que retornam um booleano recebem um ponto de interrogação no final do nome.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

Repare que guards, algumas funções embutidas e macros que retornam booleanos e são válidas em guards seguem outra convenção e são nomeadas com o prefixo `is_` (`def is_integer`, `defguard is_foo`, `defmacro is_foo`). As duas convenções não podem se misturar.
