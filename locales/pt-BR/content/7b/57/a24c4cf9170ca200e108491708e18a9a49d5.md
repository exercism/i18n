# Instruções

Vossa majestade está dando um jantar na capital da [União de Kalmar][kalmar_union], Copenhague.
É a maior festa do ano e todos os nobres estão convidados.
Mas estão se espalhando rumores pelo país de que há um plano para envenenar Vossa Majestade.

Vossa majestade pediu a você, responsável por encontrar venenos na corte, que descubra se alguma comida ou bebida está envenenada.
Vossa majestade planeja servir apenas **Mushroom pasties** como comida, mas, para beber, há uma variedade de bebidas.

## 1. Verifique se a comida está correta

Há uma grande chance de a comida estar envenenada se não for o que Vossa majestade pediu.
Se a comida não for o que Vossa majestade pediu, ela deve ser descartada.

Implemente o método `check_food?`, que recebe o argumento `food`, que contém o nome da comida como uma `String`.
O método deve retornar a comida se ela for `Mushroom pasties`; caso contrário, deve retornar `nil`.

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. Verifique se a bebida está envenenada

É possível que a bebida esteja envenenada, mas é um pouco mais difícil dizer se está.
A bebida está envenenada se ela **não** incluir a letra `i` no nome, não importa se a letra está em maiúscula ou minúscula.
A bebida deve ser descartada se estiver envenenada.

Implemente o método `check_drink?`, que recebe o argumento `drink`, que contém o nome da bebida como uma `String`.
O método deve retornar a bebida se ela não estiver envenenada; caso contrário, deve retornar `nil`.

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. Substitua a bebida

Vossa majestade não ia querer deixar os convidados preocupados com veneno na comida.
Portanto, se a bebida estiver envenenada, ela deve ser trocada por uma nova bebida, especificamente **Apple juice**.

Implemente o método `replace_drink`, que recebe o argumento `drink`, que contém o nome da bebida como uma `String`.
O método deve retornar a bebida se ela não estiver envenenada; caso contrário, deve retornar `"Apple juice"`.

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
