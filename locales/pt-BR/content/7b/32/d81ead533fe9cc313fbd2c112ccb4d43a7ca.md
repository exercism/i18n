# Política de entrada do clube de poesia

## História

Um novo clube de poesia abriu na cidade e você está pensando em participar. Como
já houve incidentes no passado, o clube tem uma política de entrada bem
específica que você vai precisar dominar antes de tentar entrar.

São duas portas no clube de poesia, e as duas têm guarda. Para conseguir
entrar, você vai precisar descobrir a senha do dia:

### Porta da frente

1. O guarda vai recitar um poema, uma linha de cada vez;
   - Você vai precisar responder com a letra adequada.
2. O guarda vai dizer de uma vez todas as letras com que você respondeu;
   - Você precisa formatar as letras como uma palavra com inicial maiúscula.

Por exemplo, um dos escritores favoritos deles é Michael Lockwood, que escreveu
o seguinte poema _acróstico_, o que significa que a primeira letra de cada
frase forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recitar **Stands so high**, você responde **S**; quando o guarda
recitar **Huge hooves too**, você responde **H**.

No fim, a senha que você anota é `Shire`, e você entra.

### Porta dos fundos

No fundo do clube ficam os poetas mais renomados, algo como a área VIP. Como
isso não é para todo mundo, o processo da porta dos fundos é um pouco mais
complicado.

1. O guarda vai recitar um poema, uma linha de cada vez;
   - Você vai precisar responder com a letra adequada.
2. O guarda vai dizer de uma vez todas as letras com que você respondeu, _mas
   às vezes há espaços depois de cada frase_:
   - Você precisa formatar as letras como uma palavra com inicial maiúscula
   - e pedir com educação, acrescentando `, please`

Por exemplo, o poema mencionado antes também é _telestíquio_, o que significa
que a última letra de cada frase forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recitar **Stands so high**, você responde **h**; quando o guarda
recitar **Huge hooves too**, você responde **o**.

No fim, a senha que você anota é `Horse, please`, e você pode curtir a festa
com os poetas renomados.
