# Apêndice de instruções

## Dicas

Você precisa implementar a função `recite`, que gera a letra de 'The Twelve Days of Christmas'. Você pode usar a assinatura fornecida se não tiver certeza sobre os tipos, mas não deixe que ela limite sua criatividade.

Este exercício trabalha com dados textuais. Por razões históricas, o tipo `String` de Haskell é sinônimo de `[Char]`, uma lista de caracteres. Para lidar com dados textuais de forma mais eficiente, é possível usar o tipo `Text`.

Como uma extensão opcional deste exercício, você pode

- ler sobre [tipos de string](https://haskell-lang.org/tutorial/string-types) em
  Haskell.
- adicionar `- text` à sua lista de dependências em package.yaml.
- importar `Data.Text` [da seguinte
  forma](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- escrever, por exemplo, `recite :: Int -> Int -> [Text]` e se referir aos
  combinadores de `Data.Text` como, por exemplo, `T.pack`.
- consultar a documentação de
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- substituir todas as ocorrências de `String` por `Text` em TwelveDays.hs, ou seja:

```haskell
recite :: Int -> Int -> [Text]
```

Esta parte é totalmente opcional.
