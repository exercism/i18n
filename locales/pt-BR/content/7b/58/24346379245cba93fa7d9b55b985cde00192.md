# Introdução

[Laços repeat-while][repeat-loops] são parecidos com os laços `while`, mas com uma diferença fundamental: a condição é verificada *depois* que o corpo do laço executa, e não antes.
Por isso, um laço `repeat-while` tem a garantia de executar seu bloco de código pelo menos uma vez.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
