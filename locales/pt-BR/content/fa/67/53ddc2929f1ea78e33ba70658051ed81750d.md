# Syllabus - O primeiro exercício

O primeiro exercício deve cobrir o conceito `basics` e não deve ter pré-requisitos.
Ele deve fornecer apenas a informação suficiente para permitir que o estudante resolva o exercício em questão.

Muitas trilhas já implementaram um exercício que cobre `basics`.
Para se familiarizar com o que costuma ser ensinado em um exercício assim, recomendamos que você se inscreva em algumas trilhas diferentes que tenham o Modo de Aprendizagem e resolva o primeiro exercício de conceito.

Cada linguagem é diferente, e você pode descobrir que precisa introduzir mais do que outras trilhas, ou menos.
Por exemplo, se for preciso compilar um programa para que ele funcione, isso é algo que você vai querer mencionar na introdução do exercício.

Outras coisas que costumam ser abordadas no exercício `basics` são:

- definir funções ou métodos
- chamar funções
- passar argumentos para funções
- atribuir um valor a um nome (variáveis e/ou constantes)

Use o mínimo possível de tipos de dados.
Se você conseguir, use apenas números inteiros, já que a notação deles é a mesma na maioria das linguagens e será bem conhecida por praticamente todo mundo.

Se existir uma trilha para uma linguagem parecida com a sua, verifique se você pode fazer um fork do exercício dela e usá-lo como ponto de partida.

Procure ser conciso; você não quer sobrecarregar os estudantes com informação.
A introdução deve explicar _só o suficiente_ para que o estudante consiga olhar o código e identificar quais são as diferentes partes.
Eles não precisam entender nada disso a fundo, mas também não devem ficar se perguntando o que é cada coisa.

O estudante deve precisar _usar_ ativamente apenas um ou dois conceitos.
