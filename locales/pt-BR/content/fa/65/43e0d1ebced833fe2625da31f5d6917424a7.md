# Para mantenedores

## Script auxiliar para criar testes em Fortran: create_fortran_test.py

Uma forma fácil de criar o teste de um exercício é usar o script
`bin/create\_fortran\_test.py`

Use este script para criar um arquivo inicial <exercise>\_test.f90 que pode servir de modelo para o seu teste.
Normalmente, você vai precisar substituir a função 'response' no arquivo gerado pela chamada de função correta.

Repare também que o Fortran tem problemas com caracteres especiais como `\n` e `\t`, então tome cuidado especial ao lidar com eles.

### Pré-requisitos

- CMake e compilador Fortran funcionando
- Python 3.x (talvez funcione com Python 2, mas eu não me dei ao trabalho
  de torná-lo compatível com versões anteriores)
- versão mais recente de https://github.com/exercism/problem-specifications.git
- git

### Fluxo de trabalho para criar um novo teste

- baixe as últimas mudanças de `exercism/problem-specifications`, por exemplo git clone git@github.com:exercism/problem-specifications.git
- crie um novo branch para criar um novo exercício, por exemplo git checkout -b exercise-bob
- rode este script para o exemplo que você quer criar
- copie `config/CMakeLists.txt` para o diretório do exercício (você pode usar `bin/update-cmake-files` para isso)
- implemente um exercício que funcione
- corrija os testes que podem dar problema (veja, por exemplo, exercise/bob "Test 20" e "Test 24")
- verifique se o comando `ctest` valida sem erros
- copie sua solução para .meta/example.f90 e remova a implementação de fato do arquivo do exercício, por exemplo bob.f90
- atualize os diretórios .docs e .meta
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - substitua "# Description" por "# Instructions"
  - preencha .meta/tests.toml manualmente (até que exista uma forma automatizada)
  - preencha .meta/config.json manualmente (até que exista uma forma automatizada)
    - use ../problem-specifications/exercises/bob/metadata.yml
- abra um pull request com suas mudanças

Para o exemplo do bob:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### Alterando `CMakeLists.txt`

Ao alterar o arquivo do cmake, atualize a cópia principal em `config/` e use `bin/update-cmake-files` para copiá-la para todos os diretórios de exercícios.

## Solução

Quando você tiver uma solução, copie essa solução para o diretório ".meta" como "example.f90".

Talvez você queira deixar uma implementação esqueleto da função ou sub-rotina que ajude o estudante, e deixar o arquivo com o nome do exercício no diretório do exercício.
