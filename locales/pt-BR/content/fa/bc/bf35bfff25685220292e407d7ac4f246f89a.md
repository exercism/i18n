# Apêndice de instruções

Este é um bom exercício para experimentar com literais de string não padrão e metaprogramação.

Uma breve introdução aos literais de string não padrão pode ser encontrada neste [post de blog](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html). Um guia detalhado de metaprogramação pode ser encontrado no [manual](https://docs.julialang.org/en/v1/manual/metaprogramming/).

Você pode ampliar sua solução adicionando a funcionalidade descrita abaixo.

O bônus A exige apenas o básico, como descrito no post de blog. O bônus B exige bem mais conhecimento de metaprogramação em Julia.

## Bônus A
Implemente um literal de string que aplica `ROT13` à string:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## Bônus B
Implemente os literais de string `R<i>`, `i = 0, ..., 26`, que deslocam a string em `i` valores:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
