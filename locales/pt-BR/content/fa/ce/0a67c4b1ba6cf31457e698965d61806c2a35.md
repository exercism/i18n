# Instruções

O problema das Oito Rainhas é uma pergunta clássica de entrevista de programação. Felizmente, o Z3 facilita bastante a resolução.
O problema é o seguinte: posicione 8 rainhas em um tabuleiro de xadrez de modo que nenhuma rainha possa capturar outra. No xadrez, as rainhas podem se mover qualquer número de casas em uma única direção (para frente, para trás, para a esquerda, para a direita, na diagonal). Escreva uma função que retorne uma lista de tuplas do Python com as posições das 8 rainhas.
