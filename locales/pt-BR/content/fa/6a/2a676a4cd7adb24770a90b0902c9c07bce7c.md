# Instalação

A forma mais simples de instalar o PureScript é pelo Node.js com o NPM.

Se você ainda não tem o Node.js instalado no seu computador, pode baixá-lo no
[site do Node.js](https://nodejs.org/). Depois que o Node.js estiver funcionando,
digite este comando no terminal para instalar o compilador do PureScript e a
ferramenta de build Spago:

    npm install --global purescript spago

Você encontra mais informações no [repositório do PureScript](https://github.com/purescript/purescript/blob/master/INSTALL.md).
