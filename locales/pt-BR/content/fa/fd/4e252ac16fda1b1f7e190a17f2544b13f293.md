# Instruções

"Outros" desenvolvedores andam trabalhando no projeto do carrinho de controle remoto [exercise:csharp/remote-control-competition](). Chamaram você para limpar o código.

## 1. Separe as responsabilidades entre o próprio carrinho e o sistema de telemetria

Refatore a classe `RemoteControlCar` para separar os métodos e as propriedades de telemetria, acessados por meio de uma propriedade `Telemetry`.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. Evite que outro código assuma dependências demais do tipo Telemetry

Garanta que a instância de `Telemetry` não possa ser criada fora do escopo do carrinho.

## 3. Evite que outro código assuma dependências da struct Speed

Garanta que a struct `Speed` não possa ser usada fora do escopo da classe `RemoteControlCar`.

## 4. Evite que outro código assuma dependências do enum SpeedUnits

Garanta que o enum `SpeedUnits` não possa ser usado fora do escopo da classe `RemoteControlCar`.
