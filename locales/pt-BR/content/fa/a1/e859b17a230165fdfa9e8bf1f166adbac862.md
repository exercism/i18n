# Dicas

## Geral

- Toda tarefa monta texto em um laço, então todas começam com `#FSTR` e
  terminam com `.str`.
- Atribua o resultado de cada `+` de volta ao acumulador:
  `script := script + ...`.

## 1. Repita uma deixa

- `1.upto!(times)` roda o laço a quantidade certa de vezes. O valor que ele
  gera não é necessário, então pode ir direto para uma variável que nunca é
  usada, ou use `times.times!`, que não gera nada.
- Zero repetições não exige tratamento especial: o laço simplesmente não roda.

## 2. As iniciais do elenco

- `names.elt!` dá cada nome; `[0]` pega o primeiro caractere.
- Um `FSTR` aceita um `CHAR` diretamente, então não é preciso transformá-lo em
  uma string primeiro.

## 3. Numere as linhas

- Dois iteradores em um mesmo laço, como no último exercício: `1.up!` para o
  número e `lines.elt!` para o texto.
- A nova linha entra *antes* de cada linha, exceto a primeira. Testar o número
  é o jeito mais fácil: `if number > 1 then ... end`.
- Um `FSTR` aceita o número diretamente, então `script + number + ". "` funciona
  sem converter.

## 4. Grite uma linha

- `line.elt!` percorre uma string caractere por caractere.
- `.upper` deixa intacto tudo o que não é letra, então o espaço não precisa de
  tratamento especial.
