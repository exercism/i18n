# Anexo às instruções

## Use UTC

Para resolver este problema, você vai precisar converter um valor `time_t` em um valor `struct tm`.
A biblioteca [`time.h`][time.h] oferece duas funções para fazer isso.
Certifique-se de usar a que resulta em um tempo de calendário expresso em **UTC**.

[time.h]: https://en.cppreference.com/w/c/chrono
