# Introdução

## Strings

Em Common Lisp, strings são [vetores][concept-vectors] de [caracteres][concept-characters]. Elas são escritas como caracteres entre aspas duplas (_por exemplo_ "Hello World!").

O predicado `stringp` retornará verdadeiro apenas se o valor fornecido for uma string.

Strings podem ser divididas em substrings com a função `subseq`, que recebe a string, um índice inicial e, opcionalmente, um índice final. A indexação começa em zero.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Strings podem ser comparadas para verificar igualdade com `string=`. Se maiúsculas e minúsculas não importarem, use `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Operações como colocar strings em maiúsculas, em minúsculas e capitalizá-las podem ser feitas com `string-upcase`, `string-downcase` e `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
