[Boolean][booleans] em Haxe são representados pelo tipo `Bool`, cujos valores podem ser `true` ou `false`.

O Haxe oferece suporte a três operadores Boolean: `!` (NOT unário), `&&` (AND binário) e `||` (OR binário).

Expressões Boolean compostas (`&&` e `||`) usam avaliação de _curto-circuito_, em que as expressões são avaliadas da esquerda para a direita, mas só até onde for necessário. Isso é importante em casos como o seguinte:

```haxe
object != null && object.field == x
```

A primeira verificação Boolean garante que `object.field` só seja acessado se `object` não for `null`, o que protege contra um erro em tempo de execução.

Os três operadores Boolean têm [precedência][precedence] diferente e são avaliados nesta ordem: `!` -> `&&` -> `||`.

Colocar expressões entre parênteses `()` permite sobrescrever essas regras de precedência, já que os parênteses têm precedência maior.

```haxe
!true && false   // => false
!(true && false) // => true
```
