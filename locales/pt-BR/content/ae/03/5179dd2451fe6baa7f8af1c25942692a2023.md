# Introdução

Em Haxe, os iteradores servem para iterar sobre um valor usando um laço `for`. Existem dois tipos de iteradores:

- `Iterator`, que itera sobre um valor.
- Dados `Iterable`, que tornam possível iterar sobre um tipo de dados.

Os dois conceitos são representados por `Iterator<T>` e `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Qualquer classe que unifique com um desses tipos pode ser iterada usando um laço `for`. Se uma classe define os métodos `hasNext` e `next`, ela é considerada um iterador; caso contrário, se ela define um método `iterator`, ela é considerada um tipo iterável.
