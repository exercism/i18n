# Apêndice das instruções

## Observação

Se você estiver editando este arquivo em um editor de texto e não no Pharo, consulte a seção [Primeiros passos](https://www.exercism.org/tracks/pharo/installation).

Você até pode usar um editor de texto, mas a IDE do Pharo é parte do que torna a linguagem tão especial.

No Pharo, você pode rodar código (inclusive testes) com métodos quebrados e classes ausentes.
Quando a máquina virtual encontra código quebrado, ela aciona um depurador, que permite explorar o problema um pouco melhor.

Aí você tem a opção de apertar o botão Create para adicionar uma classe ou um método que está faltando, e também corrigir qualquer código que cause erro.
Ao fazer isso, o depurador volta atrás e deixa você retomar a execução com as suas novas mudanças.

Experimente fazer isso com o seu exemplo HelloWorld, simplesmente rodando qualquer um dos métodos de teste de unidade.
