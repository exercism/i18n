# sem condicionais

Operadores condicionais não são necessários. Eles só adicionam ruído desnecessário. Use [valores padrão de parâmetro](https://docs.scala-lang.org/tour/default-parameter-values.html) e [interpolação de strings](https://docs.scala-lang.org/overviews/core/string-interpolation.html) para montar a string de retorno dinamicamente.
