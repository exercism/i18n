# Dicas

## Geral

- O [pacote strings][strings-package] contém muitas funções `string` úteis.
- O pacote `strings` precisa ser importado antes de ser usado.
- Para chamar funções do pacote `strings`, prefixe-as com `strings.`.

## 1. Crie a mensagem de boas-vindas

- Strings podem ser concatenadas com o operador `+`.
- Existe uma função para [converter uma `string` para letras maiúsculas][to-upper].

## 2. Adicione uma borda decorativa

- Existe uma função para [criar uma `string` com um caractere específico repetido um certo número de vezes][repeat].
- Uma quebra de linha é um [caractere de escape][escape-characters] especial.

## 3. Limpe as mensagens de marketing antigas

- Existe uma função para [substituir strings dentro de uma `string`][replace-all].
- Existe uma função para [remover espaços no início e no fim de uma `string`][trim-space].
