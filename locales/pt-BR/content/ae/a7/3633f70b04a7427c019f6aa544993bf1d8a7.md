# Instalação

## Pré-requisitos

A trilha de C++ exige que você tenha os seguintes softwares instalados no seu sistema:
* um compilador moderno de C++14
* o sistema de build multiplataforma CMake

Usamos o [Catch2](https://github.com/catchorg/Catch2) para os testes, uma biblioteca somente de cabeçalhos que vem junto com os exercícios.

Esse conjunto de dependências é muito comum em projetos de C++, então, se você tiver algum problema para configurá-lo, vai encontrar muitos recursos úteis na internet.

Muitas IDEs, incluindo o Visual Studio da Microsoft, o Xcode da Apple e o CLion da JetBrains, já vêm com um compilador e o CMake juntos, então você provavelmente só precisa instalar a IDE.

### Um compilador moderno de C++14

Esta trilha exige um compilador com suporte a [C++14](http://en.wikipedia.org/wiki/C%2B%2B14), lançado em 2014. Todos os principais compiladores lançados nos últimos anos devem ser compatíveis, então, desde que você esteja em uma versão razoavelmente recente, não deve ter problemas. Especificamente, GCC versão 7 ou superior, Clang versão 6 ou superior, ou Visual Studio 2017 ou superior.

### CMake

O CMake é um sistema de build multiplataforma de código aberto que gera scripts de build para o seu sistema de build nativo (`make`, Visual Studio, Xcode etc.). A trilha de C++ do Exercism usa o CMake para oferecer a você um build pronto que:

* compila os testes
* compila a sua solução
* linka o executável dos testes
* roda os testes automaticamente a cada build
* aborta o build se qualquer teste falhar

Usar o CMake permite que o Exercism ofereça um script de build multiplataforma capaz de gerar arquivos de projeto para ambientes de desenvolvimento integrados como o Visual Studio e o Xcode. Assim, você pode focar no problema e não se preocupar em montar um build para cada exercício.

Conseguir um build portável não é fácil e exige acesso a muitos tipos de sistemas. Se você encontrar qualquer problema com a receita de CMake fornecida, [relate o problema](https://github.com/exercism/cpp/issues) para que possamos melhorar o suporte ao CMake.

É necessário o [CMake 3.5.1 ou superior](http://www.cmake.org/) para usar a receita de build fornecida.

## Windows

Usuários de Windows podem baixar o [Visual Studio Community](https://www.visualstudio.com/vs/community/), um download gratuito que traz a IDE do Visual Studio e a versão mais recente do compilador Microsoft Visual C++.

1. Seguir [as instruções aqui](https://docs.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio) para configurar o CMake.
1. Baixar o exercício usando a ferramenta [CLI do Exercism](https://exercism.io/cli-walkthrough).
1. Abrir o Visual Studio 2017 ou superior (com as ferramentas do Visual C++ para CMake instaladas, como descrito no link acima).
1. Abrir a pasta do exercício no VS.
1. Executar "Build->Build the solution". Os testes rodarão junto com o build, e a saída vai para a janela de build. Como os testes rodam durante o build, o VS vai indicar falha de build se um dos testes falhar, e as mensagens de falha dos testes aparecerão na janela de saída do build.

Você também deve conseguir usar outras IDEs integradas, como o CLion da JetBrains, de forma parecida.

### Instalando o Boost no Windows

Os exercícios `meetup` e `gigasecond` dependem das bibliotecas [Boost][boost-website]. Os passos a seguir descrevem como configurar isso.

1. Baixar as [bibliotecas pré-compiladas para Windows][sourceforge-boost-binaries] do Boost.
   - Os exercícios exigem a versão mínima 1.58 do Boost.
   - Você pode descobrir a versão do MSVC clicando em "Modify" no Instalador do Visual Studio.
1. Extrair as bibliotecas para uma pasta local.
1. Definir a variável de ambiente `BOOST_ROOT` como a pasta onde você instalou as bibliotecas do Boost.
1. Se você estava com o Visual Studio aberto enquanto fazia isso, feche-o para garantir que o valor de `BOOST_ROOT` seja reconhecido.
1. Iniciar o Visual Studio e abrir a pasta que contém o exercício `gigasecond` ou `meetup`.
1. O "Startup Item" deve ser `gigasecond.exe` ou `meetup.exe`, e você deve receber erros de build em `gigasecond_test.cpp` ou `meetup_test.cpp` dizendo para implementar os itens que faltam, como nos outros exercícios.

## Linux

Todas as versões recentes de distribuições Linux têm compiladores compatíveis com C++14, e você deve conseguir instalá-los usando o gerenciador de pacotes da sua distribuição. As versões que suportamos são as versões padrão instaladas no Ubuntu LTS 18.04.

Por exemplo, no Ubuntu você usaria o seguinte comando para instalar o gcc.

```bash
$ sudo apt-get install gcc
$ gcc --version
```

Se você estiver em uma distribuição mais antiga, pode não ter um compilador com suporte a C++14. Nesse caso, você vai precisar consultar a sua distribuição para descobrir como instalar a versão mínima do compilador.

## MacOS

Usuários de macOS podem instalar o GCC com o [Homebrew](http://brew.sh/) usando `brew install gcc`.
