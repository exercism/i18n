# Instruções

Neste exercício, você vai gerenciar um sistema de inventário.

O inventário deve ser organizado pelo nome do item e deve manter o controle da quantidade de itens disponíveis.

Você vai precisar lidar com a adição de itens a um inventário.
Cada vez que um item aparece em um determinado vetor, a quantidade desse item deve aumentar em `1` no inventário.
Você também vai precisar lidar com a remoção de itens de um inventário, diminuindo as quantidades em `1` quando solicitado.

Por fim, você vai precisar implementar uma função que retorna todos os pares chave-valor de um determinado inventário como um `vector` de `pair`s.

~~~~exercism/note
Os testes deste exercício não se importam com mutação, mas os nomes das funções indicam que elas não devem mutar.
Se você quiser usar funções da introdução sem mutar a entrada, a função `copy()` vai ajudar.
~~~~

## 1. Crie um inventário a partir de um vetor

Implemente a função `create_inventory(<input vector>)` que cria um "inventário" a partir de um vetor de itens de entrada.
Ela deve retornar um `dict` que contém cada nome de item emparelhado com a respectiva quantidade.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Adicione itens de um vetor a um dicionário existente

Implemente a função `add_items(<inventory dict>, <item vector>)` que adiciona um vetor de itens ao inventário passado:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Decremente itens do inventário

Implemente a função `decrement_items(<inventory dict>, <items vector>)` que recebe um `vector` de itens.
Sua função deve subtrair `1` da contagem de um item a cada vez que esse item aparece no `vector`:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

As contagens de itens no inventário não podem ficar abaixo de 0.
Se o número de vezes que um item aparece no `vector` de entrada exceder a quantidade disponível, a quantidade listada para esse item deve permanecer em 0.
Pedidos adicionais de remoção de contagem devem ser ignorados assim que a contagem chega a zero.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Remova uma entrada por completo do inventário

Implemente a função `remove_item(<inventory dict>, <item>)` que remove um item e sua contagem por completo de um inventário:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Se o item não for encontrado no inventário, a função deve retornar o inventário original sem alterações.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. Retorne todo o conteúdo do inventário

Implemente a função `list_inventory(<inventory dict>)` que recebe um inventário e retorna um vetor de pares `(item, quantity)`.

O vetor deve incluir apenas os itens _disponíveis_ (_com quantidade maior que zero_) e deve estar ordenado em ordem alfabética dos itens:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
