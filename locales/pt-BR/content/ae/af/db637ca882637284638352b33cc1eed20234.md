# Dicas

## Geral

- [Use os métodos do pacote time.][time]

## 1. Interpretar a data do agendamento

- Existe um [método][time.parse] para interpretar uma `string` como um `Time`.
- Você encontra mais informações sobre como formatar partes de uma data na seção de constantes da [documentação do pacote time][time-package-constants].

## 2. Verificar se um agendamento já passou

- Existem [métodos][before] para [comparar][after] `Times` e [obter][now] a data e a hora atuais.

## 3. Verificar se o agendamento é à tarde

- Existe um [método][hour] para obter a hora de um `Time`.

## 4. Descrever a hora e a data do agendamento

- Converta a string fornecida em um `Time` e depois formate a string de resposta de acordo, usando os [métodos][time] adequados para extrair os componentes necessários.

## 5. Retornar a data de aniversário da abertura do salão

- Crie um `Time` com a data de aniversário da abertura do salão para o ano atual.
