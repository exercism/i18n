# Dicas

Este exercício testa estado mutável que pode ser acessado com segurança a partir de várias threads. Scala oferece uma variedade de maneiras de proteger estado mutável. Para quem já conhece concorrência Java, Scala pode utilizar o suporte de concorrência do Java, como o bloco synchronized do Java.

## Armadilhas comuns

Em Scala, há duas maneiras de se obter estado mutável: usar uma "var" ou um objeto mutável.
Dois erros comuns aqui são:
- Não use uma "var" que também seja um objeto mutável. Um já basta, mas não os dois juntos.
- Não exponha a "var" ou o objeto mutável para o mundo exterior. Então torne-os "private" e transforme o objeto mutável em imutável antes de retorná-lo como um valor.
