# Apêndice das instruções

## Implementação

Os testes deste exercício esperam que o seu relógio seja implementado usando uma `data declaration` no Pyret.
Se você não conhece declarações de dados, [a documentação oficial][data-declaration] é um bom lugar para começar.

Como parte do exercício, você vai comparar valores construídos por uma variante de dados `Clock`.
Como as horas e os minutos de um relógio podem dar a volta em qualquer direção, as seguintes combinações são iguais em um relógio: 1 hora e 1 minuto, 0 horas e 61 minutos, 25 horas e 1 minuto, e 2 horas e -59 minutos.
O operador de teste `is` do Pyret usa igualdade estrutural, o que faz com que, por padrão, nenhuma dessas combinações seja considerada igual.
Para isso, você vai precisar definir o seu próprio método de igualdade para comparar o horário entre valores de uma variante de dados Clock.
Se você não estiver familiarizado com a forma como o Pyret lida com igualdade, confira a documentação oficial sobre [igualdade][equality].
