# Testes

Para executar os testes, monte e execute o arquivo do test runner para um determinado exercício, seja pela interface gráfica do simulador MARS, seja pela linha de comando. Para executar na linha de comando, especifique primeiro o arquivo do runner e depois a sua implementação, assim:

    java -jar /path/to/mars.jar nc runner.mips impl.mips

Para executar pela interface gráfica, use `include` para adicionar a sua implementação no final de "runner.mips", descomentando a última linha.

O test runner vai concluir com uma mensagem “success” ou vai parar em um teste que falha, com uma mensagem que especifica qual entrada fez aquele teste falhar.
