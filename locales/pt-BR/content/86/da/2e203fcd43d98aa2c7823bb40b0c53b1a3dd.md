# Dicas

## Geral

- Use o [tipo array][array] embutido.

## 1. Defina um método para retornar um array de linguagens vazio

- A função precisa retornar um array vazio com o tipo `Array(String)`.
- A sintaxe para criar um array vazio é `[]`.
  O tipo pode ser especificado com `of String`.

## 2. Defina um método para adicionar uma linguagem ao array

- Um elemento pode ser adicionado ao final de um array com `<<`.

## 3. Defina um método para remover uma linguagem do array

- O Crystal [fornece um método][pop] para remover o último item de um array.

## 4. Defina um método para retornar o n-ésimo item do array

- O Crystal [fornece um método][index] para obter o item em um índice específico de um array.

## 5. Defina um método para converter uma string de linguagens

- O Crystal [fornece um método][split] para converter uma string em um array usando um delimitador.
