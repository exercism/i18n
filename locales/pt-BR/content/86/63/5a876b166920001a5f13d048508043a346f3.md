# Apêndice das instruções

## Instruções específicas do Odin

Para resolver este exercício, você vai precisar manter o controle dos nomes dos robôs que criar. A estrutura de dados `Robot_Storage` é fornecida justamente para isso.

Como os nomes dos robôs são `string` em Odin e precisam ser alocados manualmente conforme você cria os robôs, é sua responsabilidade liberar a memória associada no procedimento `delete_storage()`.
