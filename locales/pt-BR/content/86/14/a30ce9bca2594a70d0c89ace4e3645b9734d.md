# Apêndice de instruções

## Dicas

Você precisa implementar a função `rotate`, que recebe um `Int` e uma `String` e então as codifica usando uma cifra rotacional.
Você pode usar a assinatura fornecida se estiver em dúvida sobre os tipos, mas não deixe que ela restrinja sua criatividade.

Este exercício trabalha com dados textuais. Por razões históricas, o tipo `String` de Haskell é sinônimo de `[Char]`, uma lista de caracteres. Para um tratamento mais eficiente de dados textuais, pode-se usar o tipo `Text`.

Como extensão opcional deste exercício, você pode

- ler sobre [tipos de string](https://haskell-lang.org/tutorial/string-types) em Haskell.
- adicionar `- text` à sua lista de dependências em package.yaml.
- importar `Data.Text` [da seguinte forma](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- usar o tipo `Text`, por exemplo `rotate :: Int -> Text -> Text`, e se referir aos combinadores de `Data.Text` como, por exemplo, `T.pack`.
- consultar a documentação de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- substituir todas as ocorrências de `String` por `Text` em RotationalCipher.hs, ou seja:

```haskell
rotate :: Int -> Text -> Text
```

Esta parte é totalmente opcional.
