# Introdução

## Operadores de Comparação

[Operadores de comparação][comparison-operators] comparam dois valores do mesmo tipo e retornam um valor `Bool` (`true` ou `false`).
Se você tentar comparar valores de tipos diferentes, o compilador gera um erro.

Os operadores de comparação padrão em Swift são:

| Operador | Descrição                | Exemplo         |
| -------- | ------------------------ | --------------- |
| `==`     | Igual a                  | `1 == 1` (true) |
| `!=`     | Diferente de             | `1 != 2` (true) |
| `<`      | Menor que                | `4 < 5`  (true) |
| `<=`     | Menor ou igual a         | `4 <= 4` (true) |
| `>`      | Maior que                | `3 > 1`  (true) |
| `>=`     | Maior ou igual a         | `2 >= 2` (true) |

## Instruções If e Else

Uma [instrução condicional][conditional-statement] executa código com base em se uma condição é avaliada como `true` ou `false`.
A mais comum é a [condicional][if], que executa um bloco de código somente quando sua condição é `true`.
Escreva uma condicional usando a palavra-chave `if`, seguida da condição e do bloco de código entre chaves:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Você pode combinar um `if` com uma cláusula `else` para executar um código alternativo quando a condição for `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Para testar múltiplas condições em sequência, encadeie instruções usando `else if`.
Uma condicional não exige um bloco `else`, mas você pode incluir um para lidar com casos em que nenhuma das condições corresponde:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Expressões if

No Swift moderno, condicionais também podem ser usadas como expressões que produzem um valor.
Cada bloco é avaliado como um valor, facilitando a atribuição condicional de resultados:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## Operador ternário

O [operador condicional ternário][ternary-operator] é uma forma concisa de escrever uma expressão `if-else`.
Ele avalia uma condição e retorna um de dois valores dependendo se essa condição é `true` ou `false`.

O operador usa três partes: `condition ? trueExpression : falseExpression`.
Se `condition` for avaliada como `true`, `trueExpression` é avaliada e retornada; caso contrário, `falseExpression` é avaliada e retornada.

O operador ternário é ideal para escolhas simples, de uma linha:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

O exemplo acima é um equivalente compacto de:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
