# Instruções

Neste exercício, você vai trabalhar em um agendador de compromissos para um salão de beleza em Nova York que abriu em 15 de setembro de 2012.

Você tem quatro tarefas, e todas elas envolvem datas de compromissos. As datas e os horários vão usar um dos três formatos a seguir:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

Os testes vão definir a cultura automaticamente como `en-US`. Você não precisa definir nem especificar a cultura.

## 1. Converter a data do compromisso

Implemente o método (_static_) `Appointment.Schedule()` para converter uma representação textual de uma data de compromisso no formato `DateTime` correspondente:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Verificar se um compromisso já passou

Implemente o método (_static_) `Appointment.HasPassed()`, que recebe uma data de compromisso e verifica se o compromisso já ficou no passado:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Verificar se o compromisso é à tarde

Implemente o método (_static_) `Appointment.IsAfternoonAppointment()`, que recebe uma data de compromisso e verifica se o compromisso é à tarde (>= 12:00 e < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Descrever a hora e a data do compromisso

Implemente o método (_static_) `Appointment.Description()`, que recebe uma data de compromisso e retorna uma descrição dessa data e desse horário:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Retornar a data de aniversário

Implemente o método (_static_) `Appointment.AnniversaryDate()`, que retorna a data de aniversário deste ano, que é 15 de setembro:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
