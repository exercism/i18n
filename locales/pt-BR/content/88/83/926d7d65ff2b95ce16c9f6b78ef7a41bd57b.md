# Números

O Crystal tem um tipo, `Number`, que é o tipo base de todos os tipos numéricos.
Dentro do tipo Number existem dois subtipos principais: [`Int`][int] e [`Float`][float].

`Int` é a abreviação de integer e representa números inteiros.
`Int` pode ser negativo ou positivo, sem ponto decimal.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` representa números com ponto decimal.
Um `Float` pode ser negativo ou positivo.

```crystal
10.5.class
# => Float64
```

## Conversão entre `Int` e `Float`

Usando os métodos 'to_i' e 'to_f', você pode converter entre `Int` e `Float`.
Ao converter de `Float` para `Int`, o número é arredondado para baixo.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Operadores aritméticos

Você pode usar os [operadores aritméticos básicos][math] com `Int` e `Float`.
Os operadores são `+`, `-`, `*`, `/` e `%`.
Ao usar esses operadores, você pode misturar `Int` e `Float`.

### Adição, subtração e multiplicação

O operador `+` é usado para adição, o operador `-` é usado para subtração e o operador `*` é usado para multiplicação.

| Operador | Exemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Divisão

A divisão é usada para dividir números.
O operador `/` é usado para divisão.
O resultado será sempre um Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Em algumas linguagens de programação, ao dividir por zero, o resultado é um erro.

No Crystal, ao dividir por zero, o resultado é `Infinity` ou `-Infinity`.
A única exceção é dividir zero por zero, o que resulta em `NaN` (Not a Number).
`Infinity` e `NaN` são valores especiais do tipo `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### Módulo

O módulo é usado para obter o resto de uma divisão.
O operador `%` é usado para o módulo.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Dividir por zero ao usar o módulo resulta em um DivisionByZeroError.
Isso é diferente da divisão normal.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Arredondamento

O método `round` aceita um argumento opcional: o número de casas decimais para arredondar.
O número padrão de casas decimais é 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## Precedência e parênteses

O Crystal permite parênteses (`()`), que podem ser usados para agrupar expressões.
Isso é útil quando você quer mudar a ordem das operações.

Ao usar vários operadores aritméticos, a ordem das operações é a mesma da matemática, também conhecida como [PEMDAS][pemdas].
Ela segue a ordem de parênteses (`()`), expoentes (`**`), multiplicação (`*`) e divisão (`/`), e adição (`+`) e subtração (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
