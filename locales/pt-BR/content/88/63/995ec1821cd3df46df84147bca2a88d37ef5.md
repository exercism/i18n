# Introdução

A principal construção orientada a objetos em C# é a _classe_, que combina dados (_campos_) e comportamento (_métodos_). Os campos e métodos de uma classe são conhecidos como seus _membros_.

O acesso aos membros pode ser restrito por meio de modificadores de acesso; os dois mais comuns são:

- `public`: o membro pode ser acessado por qualquer código (sem restrições).
- `private`: o membro só pode ser acessado por código da mesma classe.

Você pode pensar em uma classe como um modelo para criar instâncias dela. Para criar uma instância de uma classe (também conhecida como _objeto_), usa-se a palavra-chave `new`:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Os campos têm um tipo e podem ser definidos em qualquer lugar de uma classe.
Campos públicos são definidos em PascalCase e campos privados em camelCase, prefixados com um sublinhado `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

É possível atribuir um valor inicial a um campo, se quiser. Se um campo _não_ especificar um valor inicial, ele receberá o valor padrão do seu tipo. Os valores dos campos de uma instância podem ser acessados e atualizados usando a notação de ponto.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Campos privados geralmente são atualizados como efeito colateral da chamada de um método. Esses métodos geralmente não retornam nenhum valor; nesse caso, o tipo de retorno deve ser `void`:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
