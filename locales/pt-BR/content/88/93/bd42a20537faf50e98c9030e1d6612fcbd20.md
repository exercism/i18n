# Instruções

Neste exercício, você vai trabalhar com contas de poupança. A cada ano, o saldo da sua conta de poupança é atualizado com base na sua taxa de juros. A taxa de juros que o seu banco oferece depende da quantidade de dinheiro na sua conta (o saldo):

- 3.213% para um saldo negativo (o que resulta em juros negativos).
- 0.5% para um saldo positivo menor que `1000` dólares.
- 1.621% para um saldo positivo maior ou igual a `1000` dólares e menor que `5000` dólares.
- 2.475% para um saldo positivo maior ou igual a `5000` dólares.

A cada ano, o governo permite que você doe uma porcentagem do seu dinheiro para instituições de caridade, sem pagar impostos. Como você é uma pessoa gentil, se o seu saldo ficar positivo no fim do ano, você pega a porcentagem isenta de impostos e dobra, arredondando para baixo até o dólar inteiro mais próximo. Você não se importa em pagar imposto sobre a segunda metade da doação.

Você tem três tarefas, e cada uma delas lida com o seu saldo e a sua taxa de juros.

## 1. Calcular a taxa de juros

Implemente a função `interestRate` para calcular a taxa de juros com base no saldo informado:

```fsharp
interestRate 200.75m
// => 0.5f
```

Repare que o valor retornado é um `single`.

## 2. Calcular os juros

Implemente o método `interest` para calcular os juros com base no saldo informado:

```fsharp
interest 200.75m
// => 1.00375m
```

Repare que o valor retornado é um `decimal`.

## 3. Calcular a atualização anual do saldo

Implemente a função `annualBalanceUpdate` para calcular a atualização anual do saldo, levando em conta a taxa de juros:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

Repare que o valor retornado é um `decimal`.

## 4. Calcular quanto dinheiro doar

Implemente a função `amountToDonate` para calcular quanto dinheiro doar para instituições de caridade, com base no saldo e na porcentagem isenta de impostos que o governo permite:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

Repare que o valor retornado é um `int`.
