# Introdução

Em Factor, os caracteres são inteiros, ou seja, code points Unicode, então os operadores numéricos `<`, `>`, `=` já dão a você uma ordenação que diferencia maiúsculas de minúsculas. O vocabulário [`unicode`][unicode] adiciona predicados que reconhecem Unicode e conversão de maiúsculas e minúsculas de um único caractere.

## Predicados de caracteres

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Conversão de maiúsculas e minúsculas

`ch>upper` e `ch>lower` invertem um único caractere. Os `>upper` e `>lower`, no nível da string, os aplicam a cada caractere de uma string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
