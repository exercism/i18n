# Ordenação

Colocar as coisas em ordem é tão comum que a biblioteca faz isso por você.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort` funciona com qualquer coisa que já saiba se comparar: números e strings conseguem, porque têm um `is_lt`.

## Ordenação com sua própria regra

A maioria das ordens não é a que já vem pronta. A tabela de classificação do netball não é alfabética nem por tamanho do nome: é por pontos e, depois, por saldo de gols para as equipes empatadas em pontos. Não há como o `ARRAY` adivinhar isso.

Então você passa a ordem, como uma rotina vinculada:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by` recebe um `ROUT{T,T}:BOOL`, uma rotina que recebe dois dos elementos sendo ordenados e responde se o primeiro vem antes do segundo. Ela chama essa rotina quantas vezes precisar e coloca o array na ordem que as respostas indicam.

Era para isso que servia o `understudy`. A biblioteca sabe ordenar e não sabe nada sobre a sua ideia de ordem; é na rotina vinculada que as duas se encontram.

## Escrevendo a comparação

A rotina responde **true quando o primeiro argumento vem primeiro**.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

Para uma regra com mais de uma parte, trate as partes em ordem de importância:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

O primeiro `if` resolve sempre que os pontos são diferentes. Só quando eles são iguais é que a segunda linha entra em ação. Escrever o critério de desempate primeiro faria com que os pontos nunca importassem.

## A ordenação altera o array

`insertion_sort_by` coloca o próprio array em ordem e não responde nada:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

Se a ordem original importar, ordene uma cópia:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
