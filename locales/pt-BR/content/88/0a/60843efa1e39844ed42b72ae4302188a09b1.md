# Introdução

Os ponteiros inteligentes em Cairo são estruturas de dados avançadas que garantem um gerenciamento de memória seguro e eficiente ao adicionar recursos de segurança aos ponteiros comuns, evitando problemas comuns como desreferenciar ponteiros nulos ou acessar memória não inicializada.

## O que é um ponteiro inteligente?

Um ponteiro inteligente se comporta como um ponteiro comum, mas rastreia a propriedade dos dados e garante um acesso seguro à memória, evitando problemas como desreferenciar ponteiros nulos ou pendentes.

## Tipos de ponteiros inteligentes

Cairo oferece vários tipos de ponteiro inteligente, como `Box<T>` e `Nullable<T>`:

- **`Box<T>`**: Armazena dados em um segmento de memória especial, ideal para dados grandes ou de tamanho dinâmico.
                Permite transferir a propriedade sem copiar os dados.
- **`Nullable<T>`**: Aponta para um valor válido do tipo `T` ou para `null`, útil para lidar com valores opcionais.

## Segurança de memória

Os ponteiros inteligentes ajudam a evitar acessos inseguros à memória. A memória é desalocada automaticamente quando não é mais necessária, o que reduz o risco de vazamentos de memória.

### Exemplo: usar `Box<T>` para tipos recursivos

Ponteiros inteligentes como `Box<T>` permitem lidar com tipos recursivos com segurança, como em uma árvore binária, alocando memória de forma eficiente e evitando recursão infinita.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## Benefícios de desempenho

Os ponteiros inteligentes melhoram o desempenho passando referências aos dados em vez de copiar estruturas grandes, o que reduz a sobrecarga de memória.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
