# Dicas

## 1. Obter a primeira carta

- [Este guia][destructuring_resource] tem uma boa visão geral da desestruturação sequencial. Você pode encontrar um exemplo de vinculação de nomes a valores.

## 2. Obter a segunda carta

- Você pode usar placeholders para ignorar um ou mais valores na vinculação.

## 3. Trocar as duas primeiras cartas

- É possível usar `&` para combinar os elementos restantes em uma sequência.

## 4. Descartar a carta do topo

- Você pode usar `:as all` para vincular o vetor inteiro ao símbolo `all`.

## 5. Inserir as cartas de figura

- Você pode encontrar mais informações sobre onde desestruturar [aqui][where-to-destructure].

[where-to-destructure]: https://clojure.org/guides/destructuring#_where_to_destructure
