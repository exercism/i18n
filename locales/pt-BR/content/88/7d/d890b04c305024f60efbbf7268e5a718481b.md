# Instruções

Seu amigo, um aspirante a artista, entrou em contato com você com uma ideia de projeto. Vamos combinar a criatividade visual dele com o seu conhecimento técnico. É hora de se aventurar na [arte generativa][generative-art]!

Restrições ajudam a criatividade e encurtam os prazos dos projetos, então vocês dois concordaram em limitar sua obra-prima a uma única forma: o círculo. Mas vão ser muitos círculos. E eles podem se movimentar! Você vai chamar isso de... pontos dançantes.

Seu amigo com certeza vai querer criar novos movimentos elaborados para os pontos, então você vai começar a programar criando uma arquitetura que permita definir novas animações com facilidade mais tarde.

## 1. Defina o comportamento da animação

Cada módulo de animação precisa implementar dois callbacks: `init/1` e `handle_frame/3`. Defina-os no módulo `Animation`.

Defina o callback `init/1`. Ele deve receber um argumento do tipo `opts` e retornar uma tupla `{:ok, opts}` ou uma tupla `{:error, error}`. As implementações desse callback vão verificar se as opções fornecidas são válidas para esse tipo específico de animação.

Defina o callback `handle_frame/3`. Ele deve receber três argumentos: o ponto, um número de quadro e as opções. Ele deve sempre retornar um ponto. As implementações desse callback vão modificar os atributos do ponto com base no número do quadro atual e nas opções da animação.

## 2. Forneça uma implementação padrão do callback `init/1`

O comportamento `Animation` deve ser fácil de incorporar em outros módulos chamando `use DancingDots.Animation`.

Para que isso aconteça, implemente a macro `__using__` no módulo `Animation` de forma que ele defina o módulo `Animation` como o comportamento do outro módulo. Ele também deve fornecer uma implementação padrão do callback `init/1`. A implementação padrão de `init/1` deve retornar as opções fornecidas sem alterações.

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. Implemente a animação `Flicker`

Use o comportamento `Animation` para implementar uma animação cintilante.

Ela deve usar o callback `init/1` padrão porque não recebe nenhuma opção.

Implemente o callback `handle_frame/3`, que lida com um único quadro. Se o número do quadro for múltiplo de quatro, a função deve retornar o ponto com metade da sua opacidade original. Nos outros quadros, ela deve retornar o ponto sem alterações.

Os quadros são contados a partir de `1`. O ponto passado para `handle_frame/3` é sempre o ponto em seu estado original, não no estado do quadro anterior.

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. Implemente a animação `Zoom`

Use o comportamento `Animation` para implementar uma animação de zoom.

Essa animação recebe uma opção: a velocidade. A velocidade pode ser qualquer número. Se for negativa, o ponto sofre zoom out em vez de zoom in.

Implemente o callback `init/1`. Ele deve validar que as opções passadas são uma keyword list com uma chave `:velocity`. O valor da velocidade deve ser um número. Se não for um número, retorne o erro `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`.

Implemente o callback `handle_frame/3`. Ele deve retornar o ponto com seu raio aumentado pelo número do quadro atual, menos um, vezes a velocidade.

Os quadros são contados a partir de `1`. O ponto passado para `handle_frame/3` é sempre o ponto em seu estado original, não no estado do quadro anterior.

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
