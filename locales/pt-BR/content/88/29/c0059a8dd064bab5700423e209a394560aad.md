# Testes

Os testes exigem que o pacote `{testthat}` esteja instalado no R.
Para rodar os testes de um exercício, basta executar o script `test_<exercise_name>.R` de dentro do diretório do exercício.

Isso pode ser feito de forma prática com a [função `auto_test` do testthat](https://testthat.r-lib.org/reference/auto_test.html). Como o código e os testes do Exercism ficam na mesma pasta, use esse mesmo caminho para os parâmetros `code_path` e `test_path`. Na linha de comando, você também pode rodar `Rscript test_<exercise_name>.R`.

Veja a [página de testes](https://exercism.org/docs/tracks/r/tests) para mais informações.
