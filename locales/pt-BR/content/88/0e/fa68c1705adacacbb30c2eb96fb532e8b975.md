# Introdução

## Expressões regulares

As expressões regulares em Gleam seguem a especificação **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), de forma semelhante a outras linguagens populares como Java, JavaScript ou Ruby.

O módulo `gleam/regexp` do pacote `gleam_regexp` oferece funções para trabalhar com expressões regulares.

~~~~exercism/note
Este exercício pressupõe que você já conhece a sintaxe de expressões regulares, incluindo classes de caracteres, quantificadores, grupos e capturas.

Se você precisar relembrar seus conhecimentos sobre expressões regulares, confira uma destas fontes: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

A forma mais comum de criar expressões regulares é usando a função `regexp.from_string`.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

As funções de criação de expressões regulares retornam um erro se a sintaxe da expressão regular for inválida, então uma let-assertion foi usada aqui para garantir que a expressão regular seja válida.

A função `regexp.check` pode ser usada para verificar se uma expressão regular corresponde a uma string.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### Capturas

Se você quiser capturar substrings usando uma expressão regular, a função `regexp.scan` pode ser usada para retornar uma lista de correspondências.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### Modificadores

O comportamento de uma expressão regular pode ser modificado criando-a com a função `regexp.compile` e passando opções.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
