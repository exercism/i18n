# Recursos

## Aprendizado

- [Nim basics](https://narimiran.github.io/nim-basics/) - para quem está começando a programar.
- [Nim tutorial, part 1](https://nim-lang.org/docs/tut1.html) - para quem já tem alguma experiência em programação.
- [Learn X in Y minutes for Nim](https://learnxinyminutes.com/docs/nim/) - uma visão geral da sintaxe.
- [Nim for Python programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-Python-Programmers)
- [Nim for C programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-C-programmers)
- [Nim in Action](https://www.manning.com/books/nim-in-action) - disponível como livro impresso ou eBook.

Veja a página oficial [Learn Nim](https://nim-lang.org/learn.html) para saber mais.
