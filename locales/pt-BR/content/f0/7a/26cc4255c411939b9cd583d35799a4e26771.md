# Retorno

Em Crystal, a última expressão de um método retorna seu valor.
Porém, às vezes você precisa retornar um valor antes da última expressão.
Para isso, você pode usar a palavra-chave `return`, que retorna o valor da expressão seguinte.
O código escrito depois de uma palavra-chave `return` não será executado.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
A palavra-chave `return` deve ser omitida quando a última expressão de um método for o valor que deve ser retornado.
~~~~
