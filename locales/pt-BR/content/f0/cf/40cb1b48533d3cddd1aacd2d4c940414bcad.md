# Geral

A documentação da [instrução `switch`][switch-statement] traz uma introdução às instruções `switch`.

## 1. Exiba as descrições dos jogadores com base no número da camisa

- A instrução [`break`][break] é útil.

## 2. Lide com números de camisa desconhecidos

- A instrução [`default`][default] é útil.

## 3. Estenda a cobertura para incluir atividades fora de campo

- A [correspondência de padrões por tipo][switch-pattern-matching] é a chave para esta tarefa.
- Use a instrução [`default`][default] para corresponder a qualquer outro tipo.

## 5. Faça um relatório sobre os técnicos dos clubes

- Veja esta [documentação][switch-when] sobre a palavra-chave `when`.
