# Dicas

## Geral

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.

## 1. Acompanhe as diferentes moedas

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- Você pode manter as strings relevantes na seção `.rodata` ou na seção `.data` e encaminhá-las conforme o valor do enum.
- Um enum é convertido implicitamente em um número inteiro, normalmente de 32 bits.

## 2. Verifique a taxa de câmbio

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- O valor de cada elemento do enum é o índice no array em C referenciado por `value_in_US_dollars`.
- Em C, os índices começam no deslocamento 0 e são para elementos, independentemente do tamanho deles em bytes. Por exemplo, o índice `2` sempre se refere ao terceiro elemento.
- Cada `double` ocupa 8 bytes de espaço.
- A taxa de câmbio pode ser calculada dividindo o valor em dólares americanos da moeda estrangeira pelo valor em dólares americanos da moeda local.

## 3. Calcule o valor das cédulas

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- O valor das cédulas pode ser calculado multiplicando `denomination` por `number_of_bills`.
- Um `unsigned long long` é um número inteiro sem sinal de 64 bits.
- Um `unsigned short` é um número inteiro sem sinal de 16 bits.
- Um `uint64_t` é um número inteiro sem sinal de 64 bits.

## 4. Calcule o número de cédulas

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- Você precisa arredondar `amount` para baixo antes de convertê-lo em um número inteiro.
- Um `float` é um número de ponto flutuante de 32 bits.
- Você pode usar [roundss][round] com `1` como terceiro operando para arredondar para baixo um valor de ponto flutuante de 32 bits.
- Um `unsigned int` é um número inteiro sem sinal de 32 bits.

## 5. Calcule o valor após o câmbio

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- Você precisa converter `spread` em um valor de ponto flutuante antes de dividi-lo por `100` para obter uma porcentagem.
- Depois de obter a porcentagem, você deve multiplicá-la por `exchange_rate` para obter a _comissão_ do spread.
- A _taxa efetiva_ é a soma da taxa de câmbio com a comissão do spread.
- Você deve dividir o orçamento pela taxa efetiva para obter o máximo de dinheiro trocado.
- Você pode reutilizar a função `get_number_of_bills` implementada anteriormente para obter o número de cédulas que vai usar.
- Um `uint32_t` é um número inteiro sem sinal de 32 bits.

[round]: https://www.felixcloutier.com/x86/roundss
