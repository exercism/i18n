# Analisadores

Os analisadores do Exercism avaliam automaticamente as submissões dos estudantes e oferecem comentários no estilo de um mentor.

## Como contribuir com os analisadores

Cada linguagem tem o seu próprio analisador, escrito nessa linguagem.
O site funciona como orquestrador entre os analisadores e as submissões dos estudantes.

Cada analisador fica na organização do Exercism no GitHub, em um repositório chamado `<track_slug>-analyzer` (por exemplo, [`exercism/ruby-analyzer`](https://github.com/exercism/ruby-analyzer)).
Você pode ver os analisadores que já existem [aqui](https://github.com/search?q=topic%3Aexercism-analyzer&type=repositories).

Se você quiser ajudar em um analisador que já existe, abra uma issue no repositório dele perguntando se há algum lugar em que você possa ajudar.
Se você quiser criar um analisador para uma linguagem que ainda não tem um, siga as instruções de [criar um analisador](/docs/building/tooling/analyzers/creating-from-scratch).
