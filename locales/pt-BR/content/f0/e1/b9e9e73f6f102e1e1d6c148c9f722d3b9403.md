# Instruções

Enquanto se preparava para assar biscoitos para os seus amigos, você descobriu que precisa converter algumas das medidas usadas na receita.
Como você só conhece o sistema métrico, precisa encontrar uma forma de converter medidas comuns de confeitaria dos Estados Unidos para mililitros (mL) para facilitar a sua vida.

Use esta tabela de conversão para a sua solução:

| Unidade a converter | volume | em mililitros (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| xícara americana          | 1      | 240                 |
| onça fluida americana  | 1      | 30                  |
| colher de chá americana     | 1      | 5                   |
| colher de sopa americana   | 1      | 15                  |

Como você é um programador talentoso em formação, decide usar mililitros como unidade de transição para facilitar a conversão de qualquer unidade da lista para qualquer outra (até para ela mesma).

## 1. Obtenha o componente numérico de uma tupla de volume

Implemente a função `getVolume`. Dada uma tupla de volume, ela deve retornar apenas o componente numérico.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. Converta a tupla de volume para mililitros

Implemente a função `toMilliliter`. Dada uma tupla de volume, ela deve converter o volume para mililitros usando a tabela de conversão.

Use múltiplas cláusulas de função e casamento de padrões para criar as funções de cada unidade. Os átomos usados para denotar cada unidade são: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.
Retorne o resultado da conversão envolvido em uma tupla.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. Converta a tupla de volume em mililitros para outra unidade

Implemente a função `fromMilliliter`. Dada uma tupla de volume e a unidade desejada, ela deve converter o volume para a unidade desejada usando a tabela de conversão.

Use múltiplas cláusulas de função e casamento de padrões para criar as funções de cada unidade. Os átomos usados para denotar cada unidade são: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. Converta de qualquer unidade para qualquer unidade

Implemente a função `convert`. Dada uma tupla de volume e a unidade desejada, ela deve converter o volume dado para a unidade desejada.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
