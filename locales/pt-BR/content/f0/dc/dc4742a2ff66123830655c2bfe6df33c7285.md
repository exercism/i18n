# Introdução

No Factor, você define uma nova palavra com `: name ( stack-effect ) body ;`.
O corpo é uma sequência de palavras; quando você chama a sua nova palavra,
elas são executadas em ordem.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Quando uma rotina fica grande, você pode (e deve) *fatorá-la*: agrupar
conjuntos de palavras em palavras menores e nomeadas, cada uma com uma única
tarefa. É por isso que a linguagem tem esse nome.

## Vocabulários

Cada arquivo `.factor` declara um vocabulário com `IN:`. Palavras de um
vocabulário podem chamar palavras de outro listando o outro vocabulário no
`USING:`.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

A estrutura de diretórios segue o nome pontuado do vocabulário: o vocabulário
`my-vocab` fica em `my-vocab/my-vocab.factor`; o vocabulário `my-vocab.helpers`
fica em `my-vocab/helpers/helpers.factor`. O carregador do Factor segue as
declarações `USING:` de forma transitiva, carregando cada vocabulário sob
demanda.
