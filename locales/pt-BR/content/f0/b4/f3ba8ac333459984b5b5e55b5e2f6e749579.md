# Sobre

Se os tipos dos parâmetros puderem ser inferidos, o Swift também permite omitir os nomes dos parâmetros e a palavra-chave `in` da definição do closure. Em vez disso, é possível se referir aos parâmetros usando uma [sintaxe abreviada especial][shorthand-argument-names], em que `$0` se refere ao primeiro parâmetro, `$1` ao segundo, e assim por diante.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

Esse estilo é usado com mais frequência quando passamos closures para funções de ordem superior e a brevidade é valorizada.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
