# Condicionais

Um **condicional** escolhe entre dois caminhos possíveis, dependendo de se algo é verdadeiro.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Lendo isso: `if`, depois uma pergunta cuja resposta é `true` ou `false`, depois `then`. As linhas depois de `then` rodam quando a resposta é verdadeira, e as linhas depois de `else` rodam quando é falsa. `end;` fecha tudo.

## Mais de duas alternativas

`elsif` adiciona outra pergunta, feita só quando as anteriores deram falso.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

A ordem importa. Uma pontuação de `9` é pega pela primeira pergunta e nunca chega à segunda, mesmo que `9 >= 5` também seja verdade. Escrever os testes na ordem errada é o jeito mais comum de errar isso.

A grafia é `elsif`, não `elseif`, nem `else if`.

## Omitir o else

O `else` pode ser omitido quando não há nada a fazer nesse caso.

```sather
   if late then
      apologise;
   end;
```

Uma rotina que precisa retornar algo exige que todos os caminhos retornem, então neste exercício todo `if` mantém seu `else`.
