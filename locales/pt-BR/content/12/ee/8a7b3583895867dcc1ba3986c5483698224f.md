# Dicas

## Geral

- [Tuplas][tuple-module] são estruturas de dados organizadas em memória contígua e que podem guardar qualquer tipo de dado.
- Átomos podem ser usados para indicar estados finitos, já que este exercício usa `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter` para indicar as unidades utilizadas.
- Você pode usar funções de [`Kernel`][elem] ou de [`Tuple`][tuple-module], ou pattern matching, para manipular as tuplas.

## 1. Obtenha o componente numérico de um par de volume

- Considere usar [uma função do módulo `Kernel`][elem] para retornar o componente numérico do par de volume.

## 2. Converta o par de volume para mililitros

- Use [funções com múltiplas cláusulas][multi-clause] e [pattern matching][pattern-matching] para reduzir a lógica de fluxo de controle condicional.
- Implemente a função de todas as unidades para mililitros, incluindo de mililitros para mililitros.

## 3. Converta o par de volume em mililitros para outra unidade

- Use [funções com múltiplas cláusulas][multi-clause] e [pattern matching][pattern-matching] para reduzir a lógica de fluxo de controle condicional.
- Implemente a função de mililitros para todas as unidades, incluindo de mililitros para mililitros.
