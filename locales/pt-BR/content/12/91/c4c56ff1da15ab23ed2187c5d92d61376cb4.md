# Sobre

No Common Lisp, uma lista de parâmetros (como a de uma definição de função) também é conhecida como [lista lambda][lambda-list].
Listas lambda também são usadas para definir macros e para fazer desestruturação.

As listas lambda podem conter [palavras-chave de lista lambda][lambda-list-keyword], como `&rest`, `&optional`, `&key` e outras.

Embora seja possível combinar vários tipos de parâmetros com outros tipos de parâmetros (parâmetros opcionais e de palavra-chave), isso pode ser problemático e deve ser feito com cuidado.
Veja a seção ["Misturando tipos diferentes de parâmetros"][pcl-function] em Practical Common Lisp.
