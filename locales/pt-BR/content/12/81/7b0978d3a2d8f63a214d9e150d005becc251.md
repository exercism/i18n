# Use `||` em vez de if-else

Quando você quiser mudar um valor caso ele seja `nil` ou qualquer outro valor avaliado como falso, use o operador `||` em vez de uma instrução if-else.
Isso é mais idiomático, mais conciso e também tem melhor desempenho.

O operador `||` retorna o valor à esquerda do operador se ele for verdadeiro; caso contrário, retorna o valor à direita do operador.

Por exemplo:

```crystal
# Rather than:
value.nil? ? "default" : value

# Consider:
value || "default"
```
