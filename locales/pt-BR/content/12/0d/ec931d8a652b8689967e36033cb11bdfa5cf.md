# Introdução

Vamos supor que você já conhece a sintaxe e os tipos de dados do JSON.

O jq funciona passando os dados JSON de entrada por uma _única expressão_ (escrita como um _pipeline de filtros_) para chegar aos dados transformados que você quer.

<!-- prettier-ignore -->
~~~~exercism/note
A linguagem `jq` é implementada pelo _programa_ `jq`.
Esse programa oferece várias opções de linha de comando úteis para controlar como a entrada é consumida e como a saída é apresentada.

Nos exemplos abaixo você vai encontrar:

- `-n` ou `--null-input`

    Normalmente o programa `jq` recebe um arquivo para ler, ou você envia dados para a entrada dele.
    A opção `--null-input` permite gerar dados JSON sem nenhuma entrada.

- `-c` ou `--compact-output`

    Por padrão, o `jq` imprime a saída de forma indentada e legível.
    É extremamente útil para os humanos ver os dados quando eles estão bem formatados.
    Mas isso não é necessário para as máquinas: a opção `--compact-output` remove os espaços em branco da formatação para minimizar o tamanho do JSON resultante.

- `-f filename` ou `--from-file filename`

    Lê o programa `jq` a partir de `filename` em vez de fornecê-lo na linha de comando.
    Tanto o `sed` quanto o `awk` usam a opção `-f` para a mesma finalidade.
    Você vai ver isso nos scripts de teste dos exercícios de prática.

O resto desta lição vai focar na _linguagem_ `jq`.
~~~~

<!-- prettier-ignore-end -->

## Filtros e pipes

**Filtros** também são conhecidos como **expressões**.

Um _filtro_ recebe uma entrada e produz uma saída.
Assim como você faz em um shell do Unix, você pode unir _filtros_ com um pipe `|` para conectar a saída de um _filtro_ à entrada de outro.

## O filtro de identidade: `.`

Este é o _filtro_ mais simples.
Ele apenas passa a entrada para a saída.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## Arrays

Esta será uma introdução rápida ao trabalho com **arrays**.
Vamos cobrir esse assunto com mais detalhes depois.

Os elementos de um _array_ são acessados com colchetes, e a indexação começa no zero.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Um _filtro_ pode construir um _array_ envolvendo uma expressão em `[` e `]`

- com uma lista conhecida de elementos:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- para coletar um fluxo de elementos: por exemplo,
  `range` é uma função que gera um fluxo de números

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Usar `[]` coleta os resultados da expressão em um array

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## A vírgula é um operador

A _vírgula_ não é só sintaxe que separa elementos de um _array_.
**A vírgula** é um **operador** que une fluxos.

Por exemplo, `[1, 2, 3]` é um _filtro_ que usa o construtor de _array_ `[]` para coletar o resultado da união das três expressões `1`, `2` e `3`.

Você reparou nos pontos e vírgulas em `range(10; 70; 15)` acima?
Como as _vírgulas_ têm um propósito específico na linguagem `jq`, as funções que recebem vários argumentos usam pontos e vírgulas para separar os argumentos.

## Objetos

Uma introdução rápida aos **objetos**.

Como em muitas linguagens de programação, use pontos para acessar as propriedades de um _objeto_

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
Colchetes também podem ser usados para _objetos_, mas aí as aspas são necessárias para literais de string.
Essa é uma das formas de trabalhar com chaves que contêm espaços.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

Você pode construir um _objeto_ com `{}` e pares `key: value`.
As aspas não são necessárias em torno de _chaves_ que são strings "simples".

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

produz

```none
{
  "question": 54,
  "answer": 42
}
```

Para tratar a _chave_ como uma _expressão_, você precisa envolvê-la em parênteses (o exemplo a seguir também produz o mesmo resultado acima).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## Pipelines

Por exemplo, dado um `file.json` com o conteúdo

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Vamos calcular o comprimento do _array_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

Estamos _passando por um pipe_ a saída da expressão `.key2` como entrada para `length`, que, como era de se esperar, gera o número de elementos do _array_.

## Filtros podem ignorar a entrada

Neste exemplo, os dados JSON de entrada são ignorados e não têm nenhum efeito na saída:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## Filtros podem gerar fluxos de dados

Um _filtro_ pode gerar mais de um valor.
Por exemplo, o _filtro_ `.[]` gera cada elemento de um _array_ como um valor separado:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Passar um _filtro_ desses por um pipe para outro vai executar o segundo _filtro_ **_para cada valor_**:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Isso é como uma iteração implícita.
Quando você entender essa técnica, vai perceber que _filtros_ `jq` muito poderosos podem ser bem concisos.

## Parênteses

**Parênteses** são usados para agrupar subexpressões e garantir a ordem das operações, como em outras linguagens.
No `jq`, a necessidade deles pode parecer um tanto surpreendente.

Por exemplo, digamos que queremos construir um _array_ com 2 elementos: a raiz quadrada de 9; e _e_ elevado à potência 1.
As duas expressões individuais são `9 | sqrt` e `1 | exp`.
Esperamos que a saída seja o _array_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Por que não obtivemos o que esperávamos? O `jq` interpreta isso assim:

```jq
[ ((9|sqrt), 1) | exp ]
```

O `jq` monta um fluxo de dois elementos (`3` e `1`), que são passados individualmente para `exp`.

Precisamos garantir que `exp` receba apenas um número como entrada.
Em outras palavras, precisamos garantir que o pipe seja avaliado antes da vírgula.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## Funções e operadores

Sem entrar em muitos detalhes (funções serão tema de outro exercício), aqui estão algumas funções internas úteis:

- `length`

  Dado um array como entrada, gera o número de elementos do array.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Esse operador faz coisas diferentes dependendo do tipo dos operandos:
  soma números,
  concatena strings,
  acrescenta arrays,
  mescla objetos.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add` é uma função que recebe um array e retorna um item com todos os elementos somados de acordo com as regras do `+`.
  `[1, 2, 3] | add` gera `6`.

- `map`

  Dado um array como entrada e um filtro como argumento, gera um array em que o filtro é aplicado a cada elemento

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Dado _algum_ dado de entrada e um filtro como argumento:
  - se o filtro aplicado ao argumento resultar em um valor _verdadeiro_, gera a entrada sem alterações
  - caso contrário, não gera _nada_ (não o valor `null`, mas realmente nenhuma saída)

  Por exemplo, dados alguns números, selecione os que são divisíveis por 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Lembre-se de que `range` gera um _fluxo_ de números.
  O `select` é invocado uma vez para cada número.
  Só os números que "passam" pela expressão são gerados.

  Muitas vezes você precisa selecionar elementos de um array.
  Há algumas maneiras de fazer isso.

  Com a entrada `["Anne", "Bob", "Cathy", "Dave"]`, selecione os nomes que têm comprimento 4.
  - use `map` e `select` juntos

    ```jq
    map(select(length == 4))
    ```

  - expanda o array em elementos, aplique `select` nesse fluxo e colete os resultados

    ```jq
    [ .[] | select(length == 4) ]
    ```
