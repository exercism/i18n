# O tipo tupla

Uma tupla é um tipo de dado composto versátil e eficiente em Cairo, que permite agrupar vários valores de tipos diferentes em uma única entidade.
As tuplas têm comprimento fixo, ou seja, depois de declaradas, seu tamanho não pode mudar.

## Criando tuplas

Para criar uma tupla, você escreve uma lista de valores separados por vírgulas dentro de parênteses.
Cada posição da tupla tem um tipo específico, e esses tipos podem ser diferentes entre si.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

Uma tupla pode conter vários valores de tipos de dados diferentes, incluindo outras tuplas.
Por exemplo:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

Aqui, a variável `nested_tup` é uma tupla que contém duas tuplas, o que mostra que tuplas podem ter outras tuplas como elementos.

## Desestruturando tuplas

Para acessar cada valor individual dentro de uma tupla, você pode usar correspondência de padrões para desestruturar a tupla.
Isso divide a tupla em suas partes constituintes.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## Declarando e desestruturando ao mesmo tempo

Você também pode declarar e desestruturar uma tupla ao mesmo tempo.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## O tipo unit `()`

O tipo unit é um tipo especial em Cairo que tem um único valor: `()`.
É representado por uma tupla sem elementos.
O tamanho do tipo unit é sempre zero, e é garantido que não exista no código compilado.

Em Cairo, toda expressão retorna um valor, e quando uma expressão não retorna nada, ela retorna `()` implicitamente.
Isso pode ser útil para funções que precisam retornar um valor, mas não têm um valor significativo para retornar.

## Declarando um tipo de tupla nomeada

Uma tupla nomeada permite criar um alias de tipo mais descritivo para uma tupla, melhorando a legibilidade do código.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

Neste exemplo, `Point` é um tipo de tupla nomeada que representa um par de inteiros sem sinal de 32 bits, deixando o código mais expressivo.
