# Apêndice das instruções

## Registradores

| Registrador | Uso          | Tipo    | Descrição                              |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | entrada      | inteiro | limite                              |
| `$a1`    | entrada/saída | endereço | array de destino para os números primos |
| `$v0`    | saída        | inteiro | número de primos                    |
| `$t0-9`  | temporário   | qualquer | usado para armazenamento temporário |
