# Introdução

Perl é uma linguagem de programação criada por Larry Wall e lançada pela primeira vez em 1987.

## Pacotes e módulos

Um pacote é uma coleção de código, muitas vezes contida em um arquivo de módulo de mesmo nome com a extensão `.pm`.
O módulo pode então ser importado em outro arquivo, normalmente com a palavra-chave `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Variáveis

Existem variáveis escalares (`$foo`), array (`@bar`) e hash (`%baz`).
Para simplificar, aqui vamos usar apenas variáveis escalares.
Um valor escalar pode ser uma string, um número, um Boolean ou uma [referência][perlreftut] a alguma coisa.
A ausência de um valor é `undef`.


As palavras-chave `my` e `our` declaram uma variável no escopo léxico, por exemplo `my $foo;`.
Com `our`, a variável também recebe um alias para uma variável de pacote de mesmo nome.
Existem outras formas de declarar variáveis que não serão abordadas aqui.

Você pode atribuir um valor a uma variável com o operador `=`, por exemplo `$foo = 1;`, e isso pode ser feito ao mesmo tempo que a declaração da variável, por exemplo `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Sub-rotinas

A palavra-chave `sub` declara uma [sub-rotina][perlsub].
A palavra-chave `return` encerra a sub-rotina, retornando os valores especificados ou uma lista vazia, caso nada seja informado.
Sem um `return` explícito, o valor retornado será determinado pelo contexto em que a sub-rotina é usada (escalar, de lista ou vazio) e pela sua última instrução.

```perl
sub hello () {
    return 'Hello, World!';
}
```

Versões recentes do Perl permitem que você especifique parâmetros formais em uma [assinatura][perlsubsig].
A lista de parâmetros pode conter variáveis escalares, array ou hash.
Uma lista de parâmetros vazia significa que a sub-rotina não aceita nenhum argumento.
Versões mais antigas do Perl exigiam obter os argumentos a partir da variável especial `@_`, o que não será abordado aqui.

## Comentários

Os comentários em Perl começam com um `#` que não faz parte de uma string e terminam no fim da linha.
