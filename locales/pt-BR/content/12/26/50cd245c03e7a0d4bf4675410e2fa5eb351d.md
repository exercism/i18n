# concatenação de strings

A concatenação de strings é perfeitamente válida em Ruby, mas uma forma mais comum de compor uma string é com [interpolação de strings](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Por exemplo:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
