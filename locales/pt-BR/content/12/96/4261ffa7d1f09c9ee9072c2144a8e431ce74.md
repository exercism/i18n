# Dicas

## 1. Calcule a soma dos números do caça-níqueis

- Você pode usar [join][mdn-join] para combinar os dígitos.
  Ela também converte os números em strings implicitamente.
- Reveja a seção de introdução para descobrir como converter uma string em número.
- Some os números depois de convertê-los.

## 2. Determine se um número é um palíndromo

- Esta tarefa pode ser resolvida tratando o número como uma string e verificando se a string é igual à sua versão invertida.
- Para isso, primeiro você precisa converter o número em uma string.
  Reveja a seção de introdução para descobrir como fazer isso.
- Para inverter a string, use `split` para dividi-la em um array, `reverse` no array e `join` para juntá-la de novo.
- Por fim, você pode [comparar][concept-comparison] a string original com a string invertida.

## 3. Gere uma mensagem de erro para entradas inválidas do usuário

- Você pode usar [condicionais][mdn-if-statement] para verificar as diferentes condições.
- Primeiro, você deve cobrir o caso em que o valor não contém nenhum caractere.
  Ao escrever a condição para isso, aproveite a conversão implícita para boolean e o fato de que `null`, `undefined` e a string vazia são todos falsy.
- Em seguida, trate o caso em que a entrada não é um número nem `0`.
  Use a conversão explícita para `Number` que você aprendeu na introdução.
  Depois, você pode mais uma vez contar com a conversão implícita para boolean e o fato de que `NaN` e `0` são falsy.
- O [operador lógico de negação][mdn-not] `!` pode ajudar a formular as condições.
