# Sobre

No Elixir, para escolher um elemento aleatório de uma estrutura de dados enumerável (por exemplo, uma lista ou um intervalo), usamos [`Enum.random/1`][enum-random]. Essa função escolhe um único elemento, e todos os elementos têm a mesma probabilidade de serem escolhidos. Escolher um único valor aleatório de um intervalo é feito em tempo constante, sem percorrer o intervalo inteiro.

## Números inteiros e letras aleatórios

- Escolhendo um número inteiro aleatório
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- Escolhendo uma letra aleatória como string
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- Escolhendo uma letra aleatória como charlist
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

Para escolher mais de um elemento de uma estrutura de dados enumerável, use [`Enum.take_random/2`][enum-take-random]. Para ordenar uma estrutura de dados enumerável em ordem aleatória, use [`Enum.shuffle/1`][enum-shuffle].

## Números de ponto flutuante aleatórios

O Elixir não tem funções próprias para escolher um número de ponto flutuante aleatório. Para isso, precisamos usar o módulo [`rand`][erl-rand] do Erlang, que, por sinal, é o que o `Enum.random` usa por baixo dos panos.

- Escolhendo um número de ponto flutuante aleatório (maior ou igual a 0.0 e menor que 1.0):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- Escolhendo um número de ponto flutuante aleatório (maior ou igual a `a` e menor que `b`):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## Distribuição normal

Todas as funções mencionadas acima escolhem um valor aleatório de modo que todo valor possível tem a mesma probabilidade de ser escolhido. Isso se chama _distribuição uniforme_. O módulo `rand` também oferece as funções [`normal/0`][erl-rand-normal-0] e [`normal/2`][erl-rand-normal-2], que escolhem um número de ponto flutuante aleatório com uma [distribuição normal][normal-distribution].

## Semente

É importante entender que os valores "aleatórios" são gerados por um [gerador de números _pseudoaleatórios_][prng]. Um PRNG é um algoritmo que, dado um valor inicial chamado de _semente_, gera uma sequência de números que parece aleatória, mas não é nada aleatória.

Esse detalhe pode ser útil para depuração. Você pode forçar o gerador de números pseudoaleatórios do Erlang (e, portanto, do Elixir) a produzir a mesma sequência de valores redefinindo a semente com [`:rand.seed/2`][rand-seed-2]. O primeiro argumento é um algoritmo de PRNG específico, e o segundo é uma tupla de três números inteiros: a semente.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## Criptografia

Os valores aleatórios retornados por `Enum.random` e pelo módulo `rand` do Erlang não são [criptograficamente seguros][cryptographically-secure-rng]. Não os use para gerar chaves criptográficas, senhas ou nonces. Para esse caso de uso, existe o [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes] do Erlang.
