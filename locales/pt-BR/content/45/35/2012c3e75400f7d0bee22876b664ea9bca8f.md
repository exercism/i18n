# Declaração de tipos

PHP é uma linguagem de _tipagem dinâmica_, o que significa que uma variável pode conter qualquer tipo de informação.
O PHP permite a declaração forte de tipos _opcional_ para propriedades de classe, argumentos de função e valores de retorno de função.
As declarações fortes de tipo no PHP fornecem asserções de tipo em tempo de execução; no entanto, o PHP tentará converter tipos escalares para corresponder à declaração, se possível.
O comportamento de conversão pode ser desativado usando a declaração `strict_types` no topo do arquivo.

```php
<?php
declare(strict_types=1);
```

Além disso, as funções podem ter o tipo de retorno `void` para indicar que nenhum valor deve ser retornado pela função.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Uniões de tipos

Se um argumento de função, valor de retorno ou propriedade de classe puder ser mais de um tipo, pode-se declarar uma união de tipos.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Tipos mistos

Ao trabalhar com código, nem sempre conseguimos especificar um tipo.
A partir do PHP 8.0, é fornecido um tipo de escape chamado `mixed`.
`mixed` é equivalente a uma união de tipos de `object|resource|array|string|float|int|bool|null`.
