# Anexo às instruções

## Instruções específicas da trilha

Implemente uma função chamada `slices` que retorna um array de strings, como descrito acima.
Sua função deve lançar um `IllegalArgumentError` com uma mensagem de erro apropriada, como a seguir.
- Se a string fornecida estiver vazia, gere um erro com a mensagem `series cannot be empty`.
- Se o comprimento da fatia for negativo, gere um erro com a mensagem `slice length cannot be negative`.
- Se o comprimento da fatia for zero, gere um erro com a mensagem `slice length cannot be zero`.
- Se o comprimento da fatia exceder o comprimento da string, gere um erro com a mensagem `slice length can not be greater than series length`.
