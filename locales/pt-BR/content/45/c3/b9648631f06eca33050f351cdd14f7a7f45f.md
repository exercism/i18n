# Instruções

Dadas duas listas, determine se a primeira lista está contida na segunda lista, se a segunda lista está contida na primeira lista, se ambas estão contidas uma na outra ou se nenhum desses casos é verdadeiro.

Especificamente, uma lista A é uma sublista da lista B se, ao remover 0 ou mais elementos do início de B e 0 ou mais elementos do fim de B, você obtiver uma lista completamente igual a A.

Exemplos:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A é uma sublista de B
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A é uma sublista de B
 * A = [3, 4], B = [1, 2, 3, 4, 5], A é uma sublista de B
 * A = [1, 2, 3], B = [1, 2, 3], A é igual a B
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A é uma superlista de B
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A não é uma superlista de B, nem uma sublista de B, nem igual a B
