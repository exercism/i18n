# Testes

A track de Factor usa **Factor 0.101**. Cada exercício vem com um vocabulário `exercism-tools` que define as palavras de parsing `STOP-HERE` e `TASK:` e um executor de testes. No diretório do exercício, rode:

```
factor -roots=. -run=exercism-tools <exercise>
```

Por exemplo, para o exercício `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

O executor sai com status 0 quando todos os testes passam, e com um status diferente de zero e uma saída de diagnóstico quando algum teste falha.

## Testes ignorados

Resolver um exercício significa fazer todos os testes passarem.
Por padrão, apenas um teste (o primeiro) é executado quando você roda os testes.
Isso é intencional, pois permite que você foque só em fazer esse único teste passar.

O mecanismo é a linha `STOP-HERE` no arquivo de teste: no momento do parsing, ela diz ao Factor para ignorar tudo abaixo dela, então o executor só vê os testes acima. Assim que seu primeiro teste passar, você pode habilitar mais testes de duas formas:

- **Apague a linha `STOP-HERE`** para habilitar todos os testes restantes de uma vez.
- **Mova a linha `STOP-HERE` mais para baixo** para habilitar os testes um de cada vez, ou uma tarefa de cada vez. Os exercícios de conceito agrupam os testes sob marcadores `TASK:`; mover o `STOP-HERE` para logo antes do próximo `TASK:` é um passo natural.

Quando todos os testes estiverem habilitados e sua implementação fizer todos passarem, você terá resolvido o exercício!
