# Testes

## Configuração

Siga as [instruções de instalação para JavaScript][docs-exercism-javascript] para instalar as dependências necessárias.

## Requisitos

Instale as dependências do exercício:

```shell
corepack pnpm install
```

Se o `corepack` reclamar que não está habilitado, você pode habilitá-lo rodando:

```bash
corepack enable pnpm
```

## Como fazer a suíte de testes passar

Todos os exercícios vêm com uma suíte de testes para ajudar você a validar sua solução antes de enviar.
Você pode executar esses testes abrindo um prompt de comando no diretório do exercício e rodando:

```bash
corepack pnpm test
```

Em algumas suítes de testes, todos os testes menos o primeiro ficam desativados.

Assim que um teste passar, você pode habilitar o próximo trocando `xtest` por `test`.

## Escrevendo testes personalizados

Se você quiser escrever testes adicionais e personalizados, crie um novo arquivo `custom.spec.js` e envie-o junto com sua solução:

```shell
exercism submit numbers.js custom.spec.js
```

[docs-exercism-javascript]: https://exercism.org/docs/tracks/javascript/installation
