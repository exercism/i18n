# Dicas

## Geral

- O alinhamento de uma struct é o alinhamento _máximo_ entre todos os seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.

## 1. Crie um carro de controle remoto

- O alinhamento de uma struct é o alinhamento _máximo_ entre todos os seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- O alinhamento de um array é igual ao alinhamento dos seus elementos.
- Cada bloco de 8 bytes de uma struct deve ser classificado separadamente.
- Se um inteiro e um valor de ponto flutuante compartilham os mesmos 8 bytes, todos os 8 bytes são passados em um Registrador de Propósito Geral (GPR).
- Um valor de ponto flutuante não pode ser uma constante de tempo de montagem definida com `equ`, mas pode ser uma constante na seção .rodata.
- Para mover bytes brutos de um registrador `xmm` para um GPR, sem alterar a representação em bits, podem ser usadas as instruções [movd][mov] ou [movq][mov].

## 2. Crie uma nova pista

- O alinhamento de uma struct é o alinhamento _máximo_ entre todos os seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- Se campos adjacentes em uma struct não puderem ser agrupados para caber no alinhamento dela, bytes de preenchimento são inseridos.

## 3. Crie um evento de corrida

- O alinhamento de uma struct é o alinhamento _máximo_ entre todos os seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- Uma struct de até 16 bytes é passada em registradores para uma função.
- Uma struct com mais de 16 bytes geralmente é colocada na memória.
- Quando uma função retorna uma struct na memória, o endereço de um local de memória para armazenar essa struct é passado como primeiro argumento implícito, em `rdi`.
- Nesse caso, a função deve retornar esse endereço em `rax`.

## 4. Confirme um carro na corrida

- O alinhamento de uma struct é o alinhamento _máximo_ entre todos os seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- Um ponteiro ocupa 8 bytes e é passado em um Registrador de Propósito Geral (GPR), independentemente do tamanho do tipo para o qual aponta.
- Tanto o array `cars` quanto o número de carros correndo devem ser atualizados em `race`.

## 5. Crie um torneio

- O alinhamento de uma struct é o alinhamento _máximo_ entre todos os seus campos.
- O tamanho de uma struct é um múltiplo do seu alinhamento.
- Uma struct com mais de 16 bytes geralmente é colocada na memória.
- Quando uma função recebe como argumento uma struct na memória, essa struct é passada na pilha.
- Tanto o array `races` quanto o número de corridas devem ser atualizados em `tournament`.
