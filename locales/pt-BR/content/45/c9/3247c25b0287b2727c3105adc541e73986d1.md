# Introdução

## Pacotes

Em Go, uma aplicação é organizada em pacotes.
Um pacote é uma coleção de arquivos-fonte que ficam na mesma pasta.
Todos os arquivos-fonte de uma pasta precisam ter o mesmo nome de pacote no topo do arquivo.
Por convenção, os pacotes recebem o mesmo nome da pasta em que estão.

```go
package greeting
```

Go oferece uma biblioteca padrão extensa de pacotes, que você pode usar no seu programa com a palavra-chave `import`.
Os pacotes da biblioteca padrão são importados pelo próprio nome.

```go
package greeting

import "fmt"
```

Um pacote importado é acessado pelo nome do pacote:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go determina se um item pode ser chamado por código de outros pacotes pela forma como ele é declarado.
Para tornar uma função, um tipo, uma variável, uma constante ou um campo de struct visível externamente (o que se chama de _exported_), o nome precisa começar com letra maiúscula.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## Formatação de strings

Go oferece um pacote embutido chamado `fmt` (pacote de formatação), que traz diversas funções para manipular o formato da entrada e da saída.
A função mais usada é `Sprintf`, que utiliza verbos como `%s` para interpolar valores em uma string e retorna essa string.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Em Go, valores de ponto flutuante são formatados de maneira prática com os verbos do Sprintf: `%g` (representação compacta), `%e` (expoente) ou `%f` (sem expoente).
Todos os três verbos permitem controlar a largura do campo e a posição numérica.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Você encontra a lista completa dos verbos disponíveis na [documentação do pacote de formatação][fmt-docs].

O `fmt` contém outras funções para trabalhar com strings, como `Println`, que simplesmente imprime no console os argumentos que recebe, e `Printf`, que formata a entrada do mesmo jeito que o `Sprintf` antes de imprimi-la.

[fmt-docs]: https://pkg.go.dev/fmt
