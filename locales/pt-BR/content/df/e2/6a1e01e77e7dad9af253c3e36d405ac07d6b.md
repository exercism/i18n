# Sobre

[Structs e classes][structs-and-classes] são os principais blocos de construção para criar tipos personalizados no Swift.
Ambos permitem agrupar propriedades (dados) e métodos (comportamento) relacionados em unidades reutilizáveis.
A maioria dos tipos principais do Swift, incluindo `Int`, `Double`, `String` e tipos de coleção como `Array` e `Dictionary`, é implementada como struct.

Para guias detalhados sobre cada tipo, veja:

- [concept:swift/structs]()
- [concept:swift/classes]()

## Como escolher entre structs e classes

Structs e classes permitem definir tipos personalizados, mas diferem de forma fundamental na maneira como são passadas na memória:

- **Structs são tipos de valor**: quando você atribui ou passa uma struct, o Swift faz uma cópia independente dos dados dela.
Alterações feitas em uma cópia não afetam as outras cópias.
- **Classes são tipos de referência**: quando você atribui ou passa uma instância de classe, o Swift compartilha uma referência para a instância existente.
Alterações feitas por meio de uma referência afetam imediatamente todas as outras referências que apontam para a mesma instância.

O Swift dá ênfase à segurança e ao comportamento previsível, o que torna as structs a recomendação padrão para a maioria dos tipos personalizados.
Usar tipos de valor garante que alterar dados em uma parte do seu programa não produza efeitos colaterais inesperados em outras partes.

Em geral:

- **Use uma struct** ao modelar dados que representam valores independentes (como coordenadas, formas, dimensões geométricas ou registros formatados).
- **Use uma classe** ao modelar entidades que têm identidades distintas ou requisitos de ciclo de vida compartilhados (como controles de interface, conexões com banco de dados ou handles de arquivo).
