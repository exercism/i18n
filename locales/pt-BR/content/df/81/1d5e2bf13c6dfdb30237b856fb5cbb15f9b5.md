# Sobre

O Printer do Common Lisp é o recurso para enviar dados a streams. Uma função comum desse recurso é `format`.

`format` recebe dois parâmetros obrigatórios: um stream para onde escrever e uma string de controle. O conteúdo da string de controle determina como os demais argumentos são usados.

O primeiro parâmetro tem dois valores especiais: `t` e `nil`. `t` indica que deve ser usado o stream ligado a `*standard-output*`, e `nil` indica que uma string deve ser criada e retornada. `format` resulta em `nil`, a menos que o parâmetro de stream seja `nil`.

A string de controle pode conter diretivas de formatação, indicadas por um `~` seguido de um caractere (maiúsculo ou minúsculo, não importa). A diretiva de formatação define se algum argumento é consumido e como ele é formatado no stream.

As diretivas de formatação básicas mais importantes são:

* `~A` - formata de maneira _estética_, "legível por humanos".
* `~S` - formata no formato _padrão_, para ser "legível por máquina".
* `~%` - emite uma nova linha
* `~&` - emite uma nova linha, a menos que já esteja no início de uma linha.
* `~~` - emite um til.

Exemplos:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
