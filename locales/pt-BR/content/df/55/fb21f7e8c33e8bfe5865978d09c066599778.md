# Sobre

Os combinadores transformam padrões de embaralhamento da pilha em palavras nomeadas e componíveis. Depois de escrever bastante Factor, você para de pensar "preciso dar `dup`, depois rodar F, depois manter o original" e simplesmente escreve `[ F ] keep`.

| pattern                            | shuffles                      | combinator      |
|------------------------------------|-------------------------------|-----------------|
| aplica F, preserva a entrada       | `dup F swap`                  | `[ F ] keep`    |
| duas funções de uma entrada        | `dup F swap G`                | `[ F ] [ G ] bi`|
| três funções de uma entrada        | complicado                     | `[ F ] [ G ] [ H ] tri` |
| muitas funções de uma entrada      | bem complicado                 | `{ Fs … } cleave`|
| opera sobre valores *abaixo* do topo | `swap F swap`                 | `[ F ] dip`     |
| mesma operação em dois valores     | `swap F swap F`               | `[ F ] bi@`     |
| operações diferentes em dois valores | `swap F swap G`               | `[ F ] [ G ] bi*`|

A família com prefixo `2` (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`,
`2nip`, `2swap`) faz o mesmo quando cada operação precisa de *duas*
entradas; `3dup` e `4dup` estendem o idioma de duplicação para três
ou quatro valores do topo da pilha.

Além da família cleave/dip/bi, o [`kernel`][kernel] também oferece
variantes de fluxo de controle que propagam `f` de forma limpa:

| word        | effect                                              |
|-------------|-----------------------------------------------------|
| `if*`       | o bloco verdadeiro vê o valor; o bloco falso, não    |
| `?last`     | último elemento de uma sequência, ou `f` se ela estiver vazia |
| `pop*`      | variante de `pop` que descarta o valor (modifica um vetor) |
| `dupd`      | duplica o *segundo* a partir do topo                 |
| `pick`      | copia o *terceiro* a partir do topo para o topo      |
| `swapd`     | troca o segundo e o terceiro a partir do topo        |
| `rotd`      | rotaciona os três de baixo de uma pilha com quatro níveis |
| `tuck`      | copia o topo para debaixo do segundo a partir do topo |
| `with`      | embute um valor fixo em uma quotation para HOS       |
| `while`     | repete enquanto um predicado for verdadeiro          |
| `until`     | repete até que um predicado seja verdadeiro          |

Escolher o combinador certo é uma habilidade por si só. A regra
geral: quando o corpo de uma definição tem mais de uma palavra de
embaralhamento em sequência, geralmente existe um combinador que
captura melhor a intenção.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
