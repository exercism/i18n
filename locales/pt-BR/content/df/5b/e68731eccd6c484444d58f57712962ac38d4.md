# Prepare-se para o lançamento

Antes de lançar sua trilha, verifique se as tarefas a seguir foram concluídas.

## Solicite o ícone da trilha

Para criar um ícone para o site, abra uma nova issue no repositório [exercism/website-icons](https://github.com/exercism/website-icons/issues), respondendo às seguintes perguntas:

- A linguagem tem um logo oficial? Se sim
  - inclua um link para um exemplo
  - liste os requisitos de atribuição e os direitos concedidos para o uso desse logo
- A linguagem tem um logo não oficial? Se sim
  - explique de que formas as pessoas usam o logo não oficial
  - inclua um link para um exemplo
  - liste os requisitos de atribuição desse logo

## Adicione os documentos da trilha

Adicione os seguintes documentos da trilha:

- `docs/ABOUT.md`: uma breve introdução à linguagem.
- `docs/INSTALLATION.md`: descreva o que o estudante precisa instalar para conseguir trabalhar na trilha no próprio sistema usando a CLI.
- `docs/LEARNING.md`: links para recursos de aprendizado.
- `docs/RESOURCES.md`: links para recursos úteis.
- `docs/TESTS.md`: descreva tudo relacionado a rodar os testes na trilha.

Esses documentos ajudam o estudante a dar os primeiros passos na trilha e a aprender sobre ela e sobre a sua linguagem.
Consulte a [documentação sobre docs](/docs/building/tracks/docs) para mais informações.

## Adicione os documentos dos exercícios

Adicione os seguintes documentos dos exercícios:

- `exercises/shared/.docs/help.md`: contém instruções específicas da trilha sobre como conseguir ajuda
- `exercises/shared/.docs/tests.md`: contém instruções específicas da trilha sobre como rodar os testes

## Adicione um trecho de código

Adicione um trecho de código ao arquivo `docs/SNIPPET.txt`.
Esse trecho dá uma impressão visual de como é a sintaxe da linguagem.
Consulte a [documentação sobre docs](/docs/building/tracks/docs) para mais informações.

## Atualize os metadados

Os metadados da trilha são definidos no [arquivo config.json](/docs/building/tracks/config-json).
As seguintes propriedades devem ser atualizadas:

- `language`: a linguagem da trilha (por exemplo, `"C#"`). Seu comprimento deve ser <= 255
- `slug`: a linguagem da trilha como uma string em minúsculas e em kebab-case (por exemplo, `"csharp"`). Seu comprimento deve ser <= 255
- `blurb`: uma breve descrição da linguagem. Seu comprimento deve ser <= 400
- `online_editor`: um objeto que descreve as configurações usadas no editor online:
  - `indent_style`: `"space"` ou `"tab"`
  - `indent_size`: o tamanho da indentação como um número inteiro (por exemplo, `4`)
  - `highlightjs_language`: o identificador da linguagem para o Highlight.js (veja a [lista completa de identificadores](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)). Se não houver suporte ao Highlight.js, esse campo pode ser omitido.
- `key_features`: os principais recursos da linguagem, que descrevem de forma sucinta as suas características mais importantes. Para mais informações, consulte a [documentação sobre os principais recursos](/docs/building/tracks/config-json#h-key-features).
- `tags`: define as tags que se aplicam a esta trilha, o que permite que ela seja encontrada no site. Para mais informações e a lista de tags aceitas, consulte a [documentação sobre tags](/docs/building/tracks/config-json#h-tags).
