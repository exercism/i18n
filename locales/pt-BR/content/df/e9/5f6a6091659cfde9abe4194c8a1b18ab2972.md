# Introdução

Caracteres e strings formam a base da representação de texto em Elm.
Podemos pensar em strings como listas de caracteres, e a maioria das funções de `List` tem equivalente no módulo `String`.

## Caracteres

O tipo `Char` representa um único caractere unicode entre aspas simples, por exemplo `'a'`. 
O módulo `Char` fornece funções de predicado (`Char -> Bool`) para testar qualidades de um caractere: `isUpper`, `isLower`, `isAlpha` e `isAlphaNum`.
O módulo também fornece funções para converter um caractere com `toUpper`, `toLower`, `toLocaleUpper` e `toLocaleLower`, além de converter de e para seu valor numérico unicode (`Int`) com `toCode` e `fromCode`.

## Strings

O tipo `String` oferece uma representação embutida para manipulação eficiente de strings e pode representar qualquer sequência de caracteres unicode.
Strings são representadas com aspas duplas: `"this is a string"`.
Strings de várias linhas são representadas com três aspas duplas e podem conter aspas e quebras de linha sem escape.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## Manipulação de strings

`reverse : String -> String` inverte a string.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` repete uma string n vezes.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` substitui todas as ocorrências de uma substring.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` anexa duas strings.
O operador `++` também pode ser usado para isso.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` concatena uma lista de strings em uma única string.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` divide uma string em uma lista de strings no separador informado.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` concatena uma lista de strings usando um separador informado.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` quebra uma string em várias strings, dividindo em trechos de espaços em branco.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` quebra uma string em linhas, dividindo nas quebras de linha.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` adiciona um caractere ao início de uma string.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` divide uma string não vazia em cabeça e cauda.
Isso permite fazer correspondência de padrões em strings exatamente como você faria com listas.
Strings vazias retornam `Nothing`.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## Obtendo substrings

`slice : Int -> Int -> String -> String` extrai uma substring a partir de um índice inicial e um índice final.
Índices negativos são contados a partir do fim da lista.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` e `right : Int -> String -> String` pegam n caracteres do lado esquerdo ou do lado direito da string, respectivamente.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` e `dropRight : Int -> String -> String` descartam n caracteres do lado esquerdo ou do lado direito de uma string, respectivamente.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## Verificando qualidades de strings

`length : String -> Int` retorna o número de caracteres em uma string.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` determina se uma string está vazia. 
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` verifica se a segunda string contém a primeira.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` e `endsWith : String -> String -> Bool` verificam se a segunda string começa/termina com uma substring informada.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` obtém uma lista com todos os índices iniciais de uma substring em outra string.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## Convertendo strings
`toInt : String -> Maybe Int` tenta converter uma string em `Just Int` e retorna `Nothing` para strings com formato inválido.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` converte um número inteiro em uma string.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` tenta converter uma string em um número de ponto flutuante, falhando em strings com formato inválido.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` converte um número de ponto flutuante em uma string.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` e `fromList : List Char -> String` convertem uma string de e para uma lista de caracteres, respectivamente.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` converte um caractere em uma string.
```elm
fromChar 'a' 
    --> "a"
```

## Formatando strings

`toUpper : String -> String` e `toLower : String -> String` convertem strings para tudo maiúsculo ou tudo minúsculo, respectivamente.
Útil para comparações que não diferenciam maiúsculas de minúsculas.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` preenche uma string dos dois lados com o `Char` informado até ela atingir o comprimento indicado.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
De forma semelhante, `padLeft` e `padRight` preenchem uma string de um dos lados até ela atingir um comprimento indicado.

`trim : String -> String` remove os espaços em branco dos dois lados de uma string.
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` e `trimRight` removem espaços em branco de um dos lados de uma string.

## Funções de alta ordem

`map : (Char -> Char) -> String -> String` transforma cada caractere de uma string com a função informada.
Repare que a função fornecida precisa mapear de e para `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` mantém apenas os caracteres que passam no teste.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` reduz uma string começando pela esquerda.
A função é aplicada com o primeiro caractere como primeiro parâmetro e um valor inicial informado como segundo parâmetro.
O resultado da função precisa ser do mesmo tipo que o valor inicial informado e é aplicado a cada caractere em sequência.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` faz o mesmo, mas começando pelo lado direito da string.

`any : (Char -> Bool) -> String -> Bool` determina se algum caractere retorna `True` para o predicado informado.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` determina se todos os caracteres de uma string retornam `True` para o predicado informado.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
