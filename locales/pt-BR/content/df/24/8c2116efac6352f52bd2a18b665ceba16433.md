# Introdução

Em Toyland, os trens estão sempre ocupados entregando tesouros pela cidade, de bolinhas de gude brilhantes a blocos de montar raros.
Os trilhos por onde eles passam são feitos de peças coloridas em forma de dominó, cada uma marcada com dois números.
Para que os trens se movam, as peças de dominó precisam formar uma corrente perfeita, em que os números combinem.

Hoje, uma entrega urgente de brinquedos raros está parada.
Você recebeu um conjunto de peças de trilho para inspecionar.
Se elas conseguirem formar uma corrente contínua, o trem seguirá viagem, levando sorrisos por toda a Toyland.
Se não conseguirem, o conjunto será descartado e outro será testado.

Os brinquedos contam com você para resolver este quebra-cabeça.
Será que as peças de dominó vão conectar os trilhos e fazer o trem partir, ou o conjunto vai ficar para trás?
