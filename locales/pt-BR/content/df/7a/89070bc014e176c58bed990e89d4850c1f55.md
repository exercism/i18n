# Instruções

Você dá aulas.
No fim do ano, você gerou uma nota numérica para cada um dos seus alunos.
Agora você precisa transformar cada nota em uma letra e contar quantos alunos tiraram cada letra

## 1. Converta uma nota numérica em uma letra

A função `letter_grade` recebe uma nota numérica como entrada e retorna a letra.
Use estes intervalos:

| Letra |      Nota |
| :----: | --------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

Exemplo:

```jq
75 | letter_grade   # => "C"
```

## 2. Conte o número de alunos para cada letra

A função `count_letter_grades` recebe um objeto que mapeia nomes de alunos às suas notas.
A saída será um objeto que mapeia cada letra ao número de alunos com aquela nota.

Exemplo:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Existem algumas formas diferentes de resolver isso.
Use o filtro `reduce` para praticar.
