# Introdução

Em Common Lisp, uma função pode ter alguns argumentos opcionais.
Eles são designados na lista lambda pela palavra-chave de lista lambda `&optional`.
Um parâmetro será associado ao valor `nil` se não for especificado.
Se houver vários parâmetros opcionais, eles são associados na ordem.
É possível especificar valores padrão para parâmetros opcionais.
Por fim, um símbolo pode ser especificado para cada parâmetro opcional, que será associado a verdadeiro ou falso dependendo de o parâmetro ter sido fornecido ou não por quem chama a função (isso é chamado de "parâmetro supplied-p").

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
