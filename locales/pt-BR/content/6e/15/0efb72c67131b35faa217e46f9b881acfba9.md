# Introdução

Em JavaScript, os valores podem ser de tipos diferentes. Mudar o tipo de uma variável pode ser feito com uma _conversão de tipo_ explícita.
Além disso, o JavaScript também realiza uma _coerção de tipo_ (conversão de tipo implícita) quando o contexto exige.

## Conversão de tipo

O JavaScript não tem um construto para converter um valor em um tipo (diferente), como acontece em muitas outras linguagens, mas alguns auxiliares internos podem ser usados no lugar.
Os exemplos mais notáveis são `Boolean`, `Number` e `String`, que podem ser usados como funções para converter um valor no tipo correspondente.

### Convertendo para Boolean (valores truthy/falsy)

Com `Boolean(value)`, você pode converter qualquer valor em um Boolean.
Existe um conjunto fixo de valores, os chamados valores _falsy_, que se convertem em `false`.
O mais importante: `false`, `0`, string vazia, `null`, `undefined` e `NaN` são falsy.

Para todos os outros valores, `Boolean` retorna `true`.
Esses valores são chamados de _truthy_.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

Repare que, por causa das regras descritas, `'0'`, `'false'`, `[]` e `{}` são **truthy** em JavaScript.

### Convertendo para número

`Number(value)` pode ser usado para converter um valor em um número.
Espaços em branco no início e no fim de uma string são ignorados, e uma string vazia é convertida em `0`.
Se você tentar converter um valor não primitivo ou uma string que não representa um número, o resultado é `NaN` ([Not-A-Number][mdn-nan]).

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### Convertendo para string

Com `String(value)`, você pode converter um valor em uma string.
Para valores primitivos, o resultado é o que você esperaria.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

No caso de arrays, a função `String` aplica a conversão para string em cada elemento e junta os resultados com uma vírgula.
Você também pode aplicar o próprio [método `join`][mdn-join], por exemplo, para personalizar o separador.
Repare que, nesses casos, `null` e `undefined` são convertidos em uma string vazia.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

No caso de objetos, por padrão `String` retorna um texto pouco útil.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## Coerção de tipo

Em certos contextos, o JavaScript converte automaticamente um valor em outro tipo de dado antes de avaliar uma instrução.
Essa conversão implícita é chamada de _coerção de tipo_.

### Contexto Boolean

Quando um valor que não é Boolean é usado em um contexto Boolean, o JavaScript aplica as mesmas regras da função `Boolean` para converter o valor implicitamente.

A coerção para Boolean costuma acontecer em:

- a condição de uma [condicional][concept-conditionals]
- o primeiro operando do [operador ternário][mdn-ternary] `?`
- o operando do operador lógico de negação `!`
- os operandos dos operadores lógicos AND `&&` e OR `||` (o resultado da expressão é um dos operandos, não necessariamente um Boolean)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### Contexto de string

Se o operador de adição `+` for usado com valores primitivos e um dos operandos for uma string, o outro também será convertido em string.
A lógica de conversão é a mesma da função `String`.
Depois disso, as duas strings são concatenadas.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### Contexto numérico

Muitos operadores convertem os operandos em números (se necessário) seguindo a lógica da função `Number` explicada acima.

- Operadores aritméticos: `+` (se não houver string envolvida), `-`, `*`, `/`, `%`, `**`
- Operadores unários de mais e de negação: `+`, `-`
- Operadores relacionais (para operandos que não são string): `>`, `>=`, `<`, `<=`
- Operadores bit a bit: `|`, `&`, `^`, `~`

Consulte a [lista de operadores da MDN][mdn-operators] para mais detalhes sobre qualquer um desses operadores.

Para evitar erros, é uma boa prática sempre chamar `Number` explicitamente antes de aplicar esses operadores.
