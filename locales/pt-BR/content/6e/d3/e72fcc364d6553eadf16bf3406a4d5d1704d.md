# Anexo às instruções

## Mensagens de exceção

Às vezes é necessário [levantar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você faz isso, deve sempre incluir uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda bastante na depuração. Em situações em que você sabe que a origem do erro será de um certo tipo, você pode optar por levantar um dos [tipos de erro internos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda deve incluir uma mensagem significativa.

Este exercício em particular exige que você use a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um `ValueError` se a função `classify()` receber um número que não seja um _inteiro positivo_. Os testes só vão passar se você fizer `raise` da `exception` e também incluir uma mensagem com ela.

Para levantar um `ValueError` com uma mensagem, escreva a mensagem como argumento do tipo `exception`:

```python
# if a number to be classified is less than 1.
raise ValueError("Classification is only possible for positive integers.")
```
