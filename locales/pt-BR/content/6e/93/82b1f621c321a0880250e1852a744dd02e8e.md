# Instruções

Neste exercício, você vai implementar uma forma de acompanhar os recordes do jogo mais popular do seu fliperama local.

Você tem 5 funções para implementar, a maioria relacionada a manipular um objeto que guarda recordes.

## 1. Crie um novo placar de recordes

Crie uma função `create_score_board` que retorna um dict que serve como placar de recordes.
As chaves desse objeto serão os nomes dos jogadores, e os valores, as pontuações deles.
Para fins de teste, você quer incluir diretamente uma entrada no objeto.
Essa entrada inicial deve ter `"The Best Ever"` como nome de jogador e `1_000_000` como pontuação.

```gleam
create_score_board()
// returns an object with one initial entry
```

## 2. Adicione jogadores a um placar de recordes

Para adicionar um jogador ao placar de recordes, defina a função `add_player`.
Ela aceita 3 parâmetros:

- O primeiro parâmetro é um dict existente de placar de recordes.
- O segundo parâmetro é o nome de um jogador como string.
- O terceiro parâmetro é a pontuação como um int.

A função retorna um dict com o novo jogador e a nova pontuação adicionados.

## 3. Remova jogadores de um placar de recordes

Se os jogadores violarem as regras do fliperama, eles são removidos manualmente do placar de recordes.
Defina `remove_player`, que recebe 2 parâmetros:

- O primeiro parâmetro é um dict existente de placar de recordes.
- O segundo parâmetro é o nome do jogador como string.

Essa função deve retornar o dict sem o jogador que foi removido.

Se o jogador não estava no placar, nada deve acontecer com o placar: ele deve ser retornado como está.

## 4. Aumente a pontuação de um jogador

Se um jogador terminar outro jogo no fliperama, uma certa quantidade de pontos será adicionada à pontuação anterior no placar.
Implemente `update_score`, que recebe 3 parâmetros:

- O primeiro parâmetro é um dict existente de placar de recordes.
- O segundo parâmetro é o nome do jogador cuja pontuação deve ser aumentada.
- O terceiro parâmetro é a pontuação que você deseja **adicionar** ao recorde armazenado.

A função deve retornar um dict com a pontuação atualizada.

Se o jogador não estava no placar, nada deve acontecer com o placar: ele deve ser retornado como está.

## 5. Aplique os pontos de bônus de segunda-feira

O fliperama mantém um placar separado às segundas-feiras.
No fim do dia, cada jogador nesse placar ganha 100 pontos adicionais.

Implemente a função `apply_monday_bonus`, que aceita um placar.
A função retorna um dict com os pontos de bônus adicionados para cada jogador listado nesse placar.
