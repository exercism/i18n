# Instruções

Implemente uma função que, dados dois pontos no plano de coordenadas 2D, produza um terceiro ponto de modo que a ligação entre esses pontos resulte em um triângulo equilátero. A função retorna dois pontos porque, dados os dois pontos iniciais, há duas possibilidades de "terceiro" ponto que formam um triângulo equilátero. Vale notar que um triângulo equilátero é definido como uma forma de três lados em que todos os três lados têm o mesmo comprimento.

A função recebe como entrada duas tuplas do Python, cada uma especificando as coordenadas x e y de cada ponto, como números de ponto flutuante. Por exemplo, (0.0, 0.0) e (1.0, 1.0) poderiam ser as entradas.

A função deve retornar uma tupla composta de duas tuplas, cada uma especificando as coordenadas x e y de cada ponto, como números de ponto flutuante. Por exemplo, ((0.0, 0.0), (1.0, 1.0)) poderia ser uma saída possível.

A função deve lançar a exceção nativa do Python `ArithmeticError` se o solver Z3 produzir um resultado que não seja satisfatível. Uma `ArithmeticError` também deve ser lançada se os dois pontos de entrada forem iguais.

A função não deve usar a função "set_option()" da biblioteca z3 para definir parâmetros globais. Isso é feito dentro dos casos de teste para garantir que os números de ponto flutuante tenham a precisão esperada (número de casas decimais).

Como a interpretação de modelo de uma variável Real do Z3 é uma instância de AlgebraicNumRef, IntNumRef ou RatNumRef, é fornecida uma função para converter essa instância em um número de ponto flutuante.
