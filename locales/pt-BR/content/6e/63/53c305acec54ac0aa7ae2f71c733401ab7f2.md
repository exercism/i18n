# Instruções

Neste exercício, você vai implementar um conjunto parcial de rotinas utilitárias para ajudar quem desenvolve a limpar nomes de identificadores.

Nas 6 tarefas, você vai construir aos poucos as funções `transform`, para converter caracteres individuais, e `clean`, para converter strings.

Um identificador válido é composto por zero ou mais letras, sublinhados, hífens, pontos de interrogação e emojis.

Se uma string vazia for passada para a função `clean`, uma string vazia deve ser retornada.

## 1. Substitua todos os hífens por sublinhados

Implemente a função `transform` para substituir todos os hífens por sublinhados.

```fsharp
transform '-'  // => "_"
```

## 2. Remova todos os espaços em branco

Remova todos os caracteres de espaço em branco.
Isso inclui espaços em branco no início e no fim.

```fsharp
transform ' '  // => ""
```

## 3. Converta camelCase para kebab-case

Modifique a função `transform` para converter camelCase em kebab-case

```fsharp
transform 'D'  // => "-d"
```

## 4. Omita caracteres que são dígitos

Modifique a função `transform` para omitir qualquer caractere que seja numérico.

```fsharp
transform '7'  // => ""
```

## 5. Substitua letras gregas minúsculas por pontos de interrogação

Modifique a função `transform` para substituir qualquer letra grega no intervalo de 'α' a 'ω'.

```fsharp
transform 'β' // => "?"
```

## 6. Combine essas operações para atuar sobre uma string

Implemente a função `clean` para aplicar essas operações a uma string inteira.

Caracteres que ficam fora das regras devem passar sem alteração.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## Montando uma string a partir de caracteres

Este tópico será abordado em detalhes mais adiante no programa de estudos.

Por enquanto, pode ser útil saber que existe uma [função de ordem superior][higher-order-function] chamada [`String.collect`][string-collect] que converte uma coleção de `char`s em uma string, usando uma função que você fornece.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
