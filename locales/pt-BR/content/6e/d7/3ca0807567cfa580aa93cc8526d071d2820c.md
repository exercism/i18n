# Apêndice das instruções

## Implementação

Defina uma função, `cost`, que calcula o custo de uma determinada lista de livros com base nos descontos definidos.

`cost` retorna o custo total (depois dos descontos) em centavos.
Por exemplo, para um único livro, o custo é 800 centavos, o que equivale a $8.00.
Para este exercício, só são necessários cálculos com números inteiros.
