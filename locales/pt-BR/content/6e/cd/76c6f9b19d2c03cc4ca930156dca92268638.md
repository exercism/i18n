# Introdução

Muitas vezes, queremos escrever código que pode seguir caminhos diferentes com base em uma condição. Embora existam muitas maneiras de fazer isso no Elixir, uma das mais simples é usar `cond/1`.

Na sua forma mais simples, o `cond` segue o primeiro caminho que for avaliado como `true` com um ou mais blocos:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Se nenhum caminho for avaliado como `true`, o runtime lança um erro.
