# Introdução

Em JavaScript, as _template strings_ permitem embutir expressões em strings, recurso também chamado de interpolação de strings.
Esse recurso amplia a funcionalidade do objeto global [`String`][string-reference] nativo da linguagem.

Você pode criar template strings em JavaScript envolvendo o texto entre crases.
Elas não só permitem que o texto inclua novas linhas e outros caracteres especiais, como também permitem embutir variáveis e outras expressões.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

No exemplo acima, usamos crases (<code>\`\`</code>) para representar uma template string. O `${...}` é o placeholder usado para substituição.
Qualquer tipo que não seja string é convertido _implicitamente_ para string.
Esse assunto é abordado no conceito de [conversão de tipos][type-conversion-concept].
Todos os tipos de expressão podem ser usados com template strings.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Quando você precisa formatar strings em várias linhas:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Com os recursos de substituição disponíveis, você também pode introduzir lógica no processo para determinar qual deve ser a string de saída.

Um exemplo disso é embutir um [operador ternário][ternary-operator].
Esse operador é uma forma curta de escrever uma instrução `if/else`.
A sintaxe é `condition ? consequent-expression : alternative-expression`.
Se a condição for verdadeira, o operando do lado esquerdo dos dois-pontos será retornado.
Caso contrário, o resultado da expressão ternária é o operando do lado direito dos dois-pontos.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
