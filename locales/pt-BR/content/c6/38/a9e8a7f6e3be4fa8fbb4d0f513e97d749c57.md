## 1. Transforme código em dados

- Existe uma [função embutida][doc-code-string-to-quoted] que transforma uma string com código em um AST.

## 2. Faça o parse de um único nó de AST

- Inspecione a saída de [`quote`][doc-quote] para se familiarizar com a aparência dos ASTs em trechos de código específicos.
- As operações que definem uma função são `:def` e `:defp`.
- A operação é o primeiro elemento de uma tupla de três elementos de um nó de AST.
- Você pode ignorar completamente o segundo elemento da tupla neste exercício.
- O terceiro elemento da tupla é a lista de argumentos da operação que define a função.
- O primeiro elemento dessa lista é uma tupla com o nome e os argumentos da função, e o segundo elemento é o corpo da função.

## 3. Decodifique a parte da mensagem secreta da definição da função

- Inspecione a saída de [`quote`][doc-quote] para se familiarizar com a aparência dos ASTs em trechos de código específicos.
- O nó de AST que contém o nome da função também contém a lista de argumentos da função como terceiro elemento.
- A aridade de uma função é o comprimento da sua lista de argumentos.
- Existe uma [função embutida no módulo `String`][string-slice] que consegue obter os primeiros `n` caracteres de uma string.
- Uma função sem argumentos escrita sem parênteses não terá uma lista como argumento, mas um átomo.

## 4. Corrija a decodificação para funções com guards

- Inspecione a saída de [`quote`][doc-quote] para se familiarizar com a aparência dos ASTs em trechos de código específicos.
- Quando uma função tem um guard, o terceiro elemento da tupla da operação `:def/:defp` é um pouco diferente.
- Esse terceiro elemento é uma lista com dois elementos: o primeiro é a tupla da operação `:when`, e o segundo é o corpo da função.
- Os argumentos da operação `:when` são uma lista de dois elementos, em que o primeiro argumento é o nome da função e o segundo é a expressão de guard.

## 5. Decodifique a mensagem secreta completa

- Use a função `to_ast/1` que você implementou na primeira tarefa para criar o AST.
- Existe uma [função embutida][macro-prewalk] que consegue visitar cada nó de um AST com um acumulador.
- Use a função `decode_secret_message_part/2` que você implementou nas tarefas anteriores para fazer o prewalk do AST.
- Para inverter o acumulador no final e transformá-lo em uma string, relembre seus conhecimentos sobre o [módulo `Enum`][enum].
