# Dicas

## 1. Estime o tempo de preparo

- Use o [`size()`][size-func] do vector para determinar o número de camadas (o comprimento da fatia de camadas).

## 2. Calcule as quantidades de massa e molho necessárias

- Primeiro, crie um objeto `amount` para acompanhar a quantidade de massa e molho.
- Use um [laço `for`][for-loop] para iterar sobre as camadas.
- Se você encontrar uma camada `"noodles"` ou `"sauce"` no laço, aumente a quantidade armazenada no objeto `amount` de acordo.

## 3. Adicione o ingrediente secreto

- Reveja os [vectors][concept-vector] para descobrir como recuperar um elemento de um vector e como substituir um elemento em um vector.
- O índice do último elemento de um vector `a` é `a.size() - 1`, ou você pode usar `a.back()` diretamente.

## 4. Multiplique a receita

- Primeiro, crie uma nova fatia do mesmo tamanho da fatia de entrada.
- Use um [laço `for`][for-loop] para iterar sobre a fatia de entrada e gerar a fatia de saída.

## 5. Desbloqueie o segredo da família

- Você pode reutilizar o código da tarefa 3.
- Esta tarefa precisa de [sobrecarga de funções][function overloading].
