# Introdução

Embora o Swift ofereça muitos recursos em sua biblioteca padrão, você pode acessar recursos adicionais importando bibliotecas e frameworks externos.
Esses módulos podem vir diretamente do projeto Swift (como o [Swift Argument Parser][argument-parser]), de frameworks das plataformas da Apple (como o [Foundation][apple-foundation] e o [Network Framework][network-framework]) ou de bibliotecas de código aberto de terceiros (como o [SwiftyBeaver][swifty-beaver]).

Módulos centrais como o Foundation, uma das bibliotecas mais usadas no Swift, já vêm com o toolchain do Swift.
Bibliotecas de terceiros precisam ser adicionadas à configuração do seu projeto (por exemplo, usando o Swift Package Manager) antes de poderem ser importadas.

Para importar um módulo, escreva a palavra-chave `import` seguida do nome do módulo:

```swift
import Foundation
```

Importar um módulo deixa seus tipos, métodos e funções disponíveis para o seu código.
Por exemplo, importar o Foundation estende o `String` com métodos utilitários, como `components(separatedBy:)`.

Por convenção, as instruções `import` ficam no topo de um arquivo Swift, para que as dependências fiquem visíveis de imediato para quem lê o código.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
