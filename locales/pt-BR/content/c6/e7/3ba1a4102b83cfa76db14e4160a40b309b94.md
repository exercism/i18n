# Dicas

## 1. Insira uma carta no topo da pilha

- A [função `queue.push_back`][push-back] pode ser usada para adicionar ao final de uma fila.

## 2. Remova a carta do topo da pilha

- A [função `queue.pop_back`][pop-back] pode ser usada para remover do final de uma fila.

## 3. Insira uma carta na base da pilha

- A [função `queue.push_front`][push-front] pode ser usada para adicionar ao início de uma fila.

## 4. Remova uma carta da base da pilha

- A [função `queue.pop_front`][pop-front] pode ser usada para remover do início de uma fila.

## 5. Verifique o tamanho da pilha
