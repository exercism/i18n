# Dicas

## 1. Pegar a primeira carta

- [Este artigo][mdn-destructuring] traz uma boa visão geral da desestruturação de arrays. Você encontra um exemplo de atribuição básica de variáveis na seção 'Basic Array Destructuring'.

## 2. Pegar a segunda carta

- Você pode usar placeholders para ignorar um ou mais valores do array.
- Você encontra um exemplo [no MDN][mdn-destructuring-ignore-value].

## 3. Trocar as duas cartas

- É possível trocar dois valores em uma única expressão de desestruturação.
- Você encontra um exemplo [no MDN][mdn-destructuring-swapping].

## 4. Deslocar três cartas

- É possível mudar a posição de três valores em uma única expressão de desestruturação.
- Isso é o mesmo que trocar dois valores, só que com três (ou mais).

## 5. Pegar a pilha nomeada

- Objetos podem ser desestruturados assim como os arrays.
- Você encontra um exemplo [no MDN][mdn-object-destructuring-basic-assignment].

## 6. Trocar as pilhas nomeadas

- Quando uma propriedade é extraída de um objeto, ela pode ser renomeada com uma sintaxe específica.
- Você encontra um exemplo [no MDN][mdn-object-destructuring-object-rename].
