# Tipos de string

Cairo não tem um tipo de dado nativo para strings.
No entanto, há duas formas de representar um tipo string: strings curtas usando um único `felt252` e strings de comprimento arbitrário usando `ByteArray`.

## Strings curtas

Uma string curta é formada com aspas simples, em que cada caractere que compõe a string é codificado em um byte seguindo o [padrão ASCII][ascii-table].

Como string ASCII, por exemplo, `'abc'` será:

- `'a'` equivale a `0x61`
- `'b'` equivale a `0x62`
- `'c'` equivale a `0x63`
- `'abc'` equivale a `0x616263`

O tipo de dado `felt252` é o que armazena strings curtas em Cairo.
Como `felt252` contém 251 bits, uma string curta fica limitada a 31 caracteres (31 \* 8 = 248 bits, que é o maior múltiplo de 8 que cabe em 251 bits).

Exemplos de declarações de strings curtas:

```rust
    let my_first_char = 'D';
    let my_first_char_in_hex = 0x44;

    let my_first_string = 'Hello world';
    let my_first_string_in_hex = 0x48656C6C6F20776F726C64;
```

### ByteArray

A struct ByteArray foi introduzida no Cairo 2.4.0.
As strings `ByteArray` são escritas entre aspas duplas, assim:

```rust
    let long_string: ByteArray = "this is a string which has more than 31 characters";
```

Tecnicamente, a atualização também introduziu o tipo `bytes31`, que armazena 31 bytes e cabe em um felt.
Na prática, a struct `ByteArray` representa uma string longa usando um array de `bytes31` que guardam as "palavras completas" (ou seja, palavras que preenchem todo o felt) e um único campo felt que guarda uma "palavra incompleta" (o número de bytes que ela contém é especificado em um campo de comprimento à parte).

```rust
#[derive(Drop, Clone, PartialEq, Serde, Default)]
struct ByteArray {
    data: Array<bytes31>,
    pending_word: felt252,
    pending_word_len: usize,
}
```
