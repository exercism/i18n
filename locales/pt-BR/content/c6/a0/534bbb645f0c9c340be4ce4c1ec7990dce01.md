# Instruções

A empresa em que você trabalha está prestes a lançar seu smartphone novinho em folha, o **Smarty 5**. Ele traz um sistema de câmera totalmente novo, um design novo e um processador revolucionário que roda um novo sistema operacional chamado **smartyOS**.

O novo processador tem potência para lidar com senhas mais seguras do que nunca, e a empresa decidiu usar isso a seu favor.
Eles pediram que você implemente um sistema de bloqueio por senha para o telefone, que permita ao usuário definir uma senha e depois verificar se uma senha informada está correta.

~~~~exercism/caution
O sistema de senhas usado neste exercício não é seguro e serve apenas para fins educacionais.
Ele **NÃO** deve ser usado em aplicações do mundo real.
~~~~

## 1. Defina uma senha

O telefone permite que os usuários usem vários tipos diferentes de senha, de uma senha simples de dígitos a uma senha alfanumérica mais segura, e até uma senha que armazena a impressão digital.

Esses diferentes tipos de senha usam tipos diferentes: a senha de dígitos usa um `Int32`, a senha alfanumérica usa uma `String`, e a senha de impressão digital usa um `Float64`.

Implemente a classe `PasswordLock` com um inicializador que recebe qualquer um dos três tipos de senha como argumento e o armazena em uma variável de instância chamada `@password`.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. Criptografe a senha

A empresa decidiu criptografar a senha para que ela não seja armazenada em texto simples e pediu que você implemente um método para criptografá-la.

Cada tipo de senha tem uma forma única de criptografia:

- Senha `Int32`: a senha é dividida por dois e arredondada para o número inteiro mais próximo.
- Senha `String`: a senha é invertida.
- Senha `Float64`: a senha é multiplicada por quatro.

Implemente um método de instância chamado `encrypt` que não recebe argumentos e modifica a variável de instância `@password` para que ela fique criptografada.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. Verifique se uma senha está correta

A empresa também pediu que você implemente um método que verifica se uma senha informada está correta.

Eles querem que o método retorne `nil` se a senha estiver incorreta e `"Unlocked"` se a senha estiver correta.

Implemente um método de instância chamado `unlock?` que recebe como argumento a senha a ser verificada.
O método deve retornar `nil` se a senha estiver incorreta e `"Unlocked"` se a senha estiver correta.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
