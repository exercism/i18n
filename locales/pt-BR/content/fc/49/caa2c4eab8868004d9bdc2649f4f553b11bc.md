# Dicas

## Geral

- Cada arquivo começa com uma linha `USING:` que lista os vocabulários dos quais ele toma emprestado, e uma linha `IN:` que declara o próprio vocabulário. O nome depois de `IN:` precisa corresponder ao caminho do arquivo sob a raiz do exercício: `bosuns-briefing.helpers` para `helpers/helpers.factor`, `bosuns-briefing` para o arquivo principal.
- Sempre que você chamar uma palavra de outro vocabulário, adicione esse vocabulário à linha `USING:`.

## 1. `greeting`

- `greeting` não recebe nada e retorna uma string literal. O corpo é apenas essa string literal.

## 2. `crew-line`

- `prepend` (em `sequences`) recebe `( seq1 seq2 -- newseq )` e retorna `seq2` seguido de `seq1`. Então `"Lopez" "  - " prepend` produz `"  - Lopez"`.

## 3. `closing`

- Mesmo formato de `greeting`.

## 4. `roster`

- `[ crew-line ] map` (de `sequences`) aplica `crew-line` a cada elemento do array de entrada, retornando um array de strings formatadas.
- `"\n" join` (de `splitting`) concatena um array de strings, inserindo `"\n"` entre cada par.

## 5. `briefing`

- O resultado são três strings unidas por `"\n"`: a saudação, o roster dos nomes de entrada e o fechamento.
- `3array` (de `arrays`) empacota os três valores em um único array, pronto para `"\n" join`.
- Use `[ greeting ] dip` para empurrar a saudação *abaixo* dos nomes que já estão na pilha, depois rode `roster` sobre os nomes e `closing` em seguida, deixando três strings prontas para `3array`.
