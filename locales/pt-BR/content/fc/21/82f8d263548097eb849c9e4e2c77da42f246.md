# Instruções

Estamos abrindo um clube do queijo, que vai usar aprendizado de máquina (ML) para selecionar novos queijos a serem oferecidos aos nossos clientes amantes de queijo, com base no histórico e nos gostos de cada um.

Os novos membros precisam responder a um questionário inicial para que possamos reunir alguns dados básicos para começar.
Com isso, descobrimos que existe um subconjunto de clientes enfáticos que não têm nuance nas críticas.
Como isso pode acabar enviesando de forma irreversível um algoritmo mais sutil, há um algoritmo separado para atender às necessidades deles.
Pedimos que você forneça algumas funções auxiliares para lidar com os dados deles.

~~~~exercism/note
Embora possa haver maneiras diferentes de resolver as tarefas a seguir, cada uma pode ser resolvida com no máximo duas funções de ordem superior.
~~~~

## 1. Classifique os clientes

O sistema de avaliação tem base de cinco estrelas, que consiste simplesmente nos números inteiros `1:5`.
Os clientes enfáticos só dão avaliações de `1` ou `5`, e queremos saber se um cliente apresenta esse comportamento.

Implemente `all_15()`, que recebe um vetor de avaliações e retorna `true` se todas as avaliações forem `1` ou `5`, e false caso contrário.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. Nomeie os clientes

Precisamos associar o nome (ou ID) do cliente às suas avaliações.

Implemente `name_customers()`, que recebe um vetor de nomes e uma lista de avaliações e os "emparelha" em uma lista de listas.

Os elementos das listas internas devem ter os nomes `name` e `rating`.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. Separe os clientes enfáticos

Precisamos separar os clientes mais enfáticos dos demais.

Implemente `emphatics()`, que recebe clientes e avaliações.
Retorna uma lista restrita àqueles que só dão avaliações de `1` ou `5` estrelas.`

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. Mude as avaliações para binário

Como os clientes enfáticos só usam avaliações `1` e `5`, será mais conveniente do ponto de vista computacional mudá-las para `0` e `1`.

Implemente `to_binary()`, que recebe um vetor de avaliações enfáticas.
Retorna avaliações binárias, em que `1` foi mudado para `0` e `5` foi mudado para `1`.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. Calcule a média das avaliações ao longo do tempo

Você quer continuar melhorando as recomendações para cada cliente individual (não só para os enfáticos) com o tempo, à medida que entende melhor o gosto deles.

Implemente `satisfactions()`, que recebe um vetor de avaliações.
Retorna um vetor de médias acumuladas até esse ponto.
Arredonde os resultados para 2 casas decimais.

Tomara que os números continuem crescendo, para clientes felizes!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
