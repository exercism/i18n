# Introdução

A instrução `guard` do Swift serve para fazer retornos antecipados de funções Swift quando uma condição necessária para que o processamento continue não é satisfeita, por exemplo:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Aqui, o `guard` verifica se a expressão Boolean que vem depois da palavra-chave `guard` é avaliada como verdadeira. Se for, o processamento continua com o código que vem depois da instrução `guard` (aqui `let root = myValue.squareRoot()`. Caso contrário, ele executa o código da cláusula `else`. Ao contrário de uma condicional `if`, uma instrução `guard` _precisa_ ter uma cláusula `else` e, ao contrário da cláusula `else` de um if-else, a cláusula `else` de um `guard` _precisa_ sair do escopo da instrução `guard`. Ou seja, ela precisa usar uma instrução de transferência de controle, como `return`, `continue`, `break`, ou então lançar um erro ou encerrar o programa.
