# Dicas

**Lembre-se**: os testes deste exercício são agnósticos em relação a mutações, mas os nomes das funções indicam que elas não devem mutar nada.
Se você quiser usar funções da introdução sem mutar a entrada, a função `copy()` vai ajudar.

## 1. Crie um inventário a partir de um vetor

- Pode ajudar dar uma olhada na Tarefa 2 antes de começar esta.

## 2. Adicione itens de um vetor a um dicionário existente

- A abordagem mais simples é percorrer o vetor de entrada, um item por vez.
- A função [`haskey(dict, key)`][haskey] vai ser útil.

## 3. Decremente itens do inventário

- O código é bem parecido com o da Tarefa 2, com uma mudança de sinal.
- Lembre-se de não deixar a contagem de itens cair abaixo de zero.
- A lógica `if...else` funciona, mas a função [`max()`][max] permite um código conciso e idiomático.

## 4. Remova por completo uma entrada do inventário

- Julia tem uma função que faz exatamente isso: leia a Introdução.

## 5. Retorne todo o conteúdo do inventário

- Lembre-se de remover os itens com contagem zero.
- Para quem está começando, pode ser mais fácil fazer um laço sobre os itens e usar [`push!()`][push] quando for o caso.
- Uma compreensão de lista no estilo Python é bem mais concisa, e é permitido adicionar uma cláusula `if` no final.
- Apesar de exigir conhecimento de Conceitos posteriores, quem já está familiarizado com programação funcional pode querer investigar a função [`filter()`][filter].
- É preciso retornar uma lista ordenada, e o [`sort()`][sort] por padrão ordena pela primeira parte de um par.
