# Dicas

## Geral

- Para extrair vários argumentos nos parâmetros da função, você pode empacotá-los com `...<args>`.
- Para usar rest e spread, use o operador `...`.

## 1. Crie uma lista com todos os vagões

- É possível empacotar vários argumentos nos parâmetros da função com a [sintaxe `...<args>` (spread)][spread-syntax].

## 2. Mova os dois primeiros elementos para o final do array

- Você pode desempacotar uma série de parâmetros usando [uma atribuição por desestruturação (`...`)][destructuring-assignment].
  Isso permite extrair os dois primeiros elementos de um `array` mantendo o restante intacto.
- Para adicionar outro `array` a um `array` existente, você pode usar o operador `...` para "espalhar" o `array`.

## 3. Adicione os valores que faltam

- Usando o desempacotamento com o operador rest (`...`), você pode extrair o primeiro elemento de um `array` mantendo o restante intacto.
- Para adicionar outro `array` a um `array` existente, você pode usar o operador `...` para "espalhar" o `array`.

## 4. Amplie as informações de rota

- Para adicionar outro `object` a um `object` existente, você pode usar o operador `...` para "espalhar" o `object`.

## 5. Separe o horário de chegada das informações de rota

- Para extrair um valor de um `object` mantendo o restante intacto, você pode usar o operador rest (`...`).
