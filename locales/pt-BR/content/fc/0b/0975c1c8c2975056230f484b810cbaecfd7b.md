# Number guessing game

## História

Neste exercício, você joga um jogo de adivinhação de números com um amigo. As regras são simples: você escolhe secretamente um número entre `1` e `100` e seu amigo tenta adivinhar qual número você escolheu. Para ajudar seu amigo, você responde de um jeito diferente conforme a proximidade do palpite com o número que você escolheu (`42`). Estas são as regras para as diferentes respostas:

- Se o palpite for `42`: "Correct"
- Se o palpite for `41` ou `43`: "So close"
- Se o palpite for menor que `41`: "Too low"
- Se o palpite for maior que `43`: "Too high"

## Tarefas

Estas são tarefas de exemplo que se encaixam no exercício de adivinhação de números:

- Responder a um palpite correto
- Responder a um palpite próximo
- Responder a palpites muito baixos
- Responder a palpites muito altos
