# Encontre mantenedores

Para uma track ter sucesso, é importante contar com algumas pessoas que vão cuidar da manutenção dela.
Essas pessoas são (sem surpresa) conhecidas como os _mantenedores da track_.
As tarefas desses mantenedores vão desde revisar PRs até corrigir bugs e adicionar novos exercícios.

Ter alguns mantenedores de track é especialmente importante depois que a track é lançada, já que os estudantes vão se inscrever e trabalhar nos exercícios.

Adicionar mantenedores é uma tarefa manual.
Você pode pedir para adicionar um mantenedor abrindo uma issue e marcando `@exercism/staff`.
