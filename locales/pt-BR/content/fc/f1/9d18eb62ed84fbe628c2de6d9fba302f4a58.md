# Instruções

Toda rotina que a trupe de dança apresenta parte do mesmo aquecimento e, depois, segue o próprio caminho.

O stub já traz `WARM_UP`. Escreva mais três classes abaixo dela.

## 1. A rotina de jazz

`JAZZ_ROUTINE` pega tudo de `WARM_UP` sem mudanças e não acrescenta nada.

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. A rotina de sapateado

`TAP_ROUTINE` pega `counts` de `WARM_UP`, mas se descreve do seu próprio jeito. Deixe `describe` de fora do include e escreva uma nova versão.

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. O finale

`FINALE` pega `counts` de `WARM_UP` sob o nome `warm_up_counts` e deixa `describe` de fora. Depois, tem o próprio `counts`, que é o dobro do aquecimento, e o próprio `describe`.

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

Repare no que isso mostra: `FINALE::counts` não é `WARM_UP::counts`, e os dois estão disponíveis sob nomes diferentes na mesma classe.
