# Instruções adicionais

## Observação

Construa este exercício peça por peça, e não tenha medo de extrair os conceitos úteis para uma nova classe.
Os exercícios anteriores devem dar a base para uma solução elegante.

Também pode ser útil revisar capítulos sobre pensamento orientado a objetos, por exemplo [Inside Smalltalk - Capítulo 1](http://sdmeta.gforge.inria.fr/FreeBooks/InsideST/InsideSmalltalk.pdf) ou [Smalltalk by Example - Capítulo 9](http://sdmeta.gforge.inria.fr/FreeBooks/ByExample/11%20-%20Chapter%209%20-%20Object-Oriente.pdf)
