# Char

`Char` é um tipo de dados em Crystal que representa um code point [Unicode][unicode] de 32 bits.
O tamanho deles os torna eficientes em memória e lhes dá propriedades específicas que as strings não têm.
Eles são criados com aspas simples (`'`) e permitem colocar apenas um code point Unicode dentro.

```crystal
'a' # => 'a'
'a'.class # => Char
```

É bem comum trabalhar com Chars ao lidar com strings em Crystal, já que vários métodos da classe String retornam Chars ou recebem Chars como argumentos.
Por exemplo, o método [`String#[]`][index] retorna um Char, e o método [`String#chars`][chars] retorna uma coleção de Chars.

## Incremento / decremento

Como um Char é um code point Unicode de 32 bits, ele permite incremento e decremento. Isso faz com que, se você tem `'a'`, possa obter `'b'` somando um.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Existe também um método chamado [`Char#succ`][succ], que retorna o próximo char na tabela Unicode, e o [`Char#pred`][pred], que retorna o char anterior na tabela Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concatenação

Como um Char só serve para representar um code point Unicode de 32 bits, dois chars não podem ser concatenados.
Por isso, só dá para concatenar Chars com strings.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Métodos de propriedades

O Crystal tem alguns métodos para obter informações sobre um caractere, como saber se ele é um número ou uma letra, ou se é maiúsculo ou minúsculo.
Veja uma lista de alguns desses métodos; para a lista completa, consulte a [API do Char][char-api]:

| Método                           | Descrição                                            |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Retorna `true` se o Char for um número               |
| [`Char#letter?`][letter]         | Retorna `true` se o Char for uma letra               |
| [`Char#lowercase?`][lowercase]   | Retorna `true` se o Char for minúsculo               |
| [`Char#uppercase?`][uppercase]   | Retorna `true` se o Char for maiúsculo               |
| [`Char#ascii?`][ascii]           | Retorna `true` se o Char for um caractere ASCII      |
| [`Char#whitespace?`][whitespace] | Retorna `true` se o Char for um caractere de espaço em branco |

## Conversão

### Conversão entre code points e Chars

Como um Char é um code point Unicode de 32 bits, é possível converter entre Chars e code points (Int).
Isso pode ser feito com o método [`Char#ord`][ord], que retorna o code point do Char, ou com o método [`Int#chr`][chr], que retorna o Char do code point.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Conversão entre tipos

Assim como os outros tipos de dados, os chars têm alguns métodos para converter entre tipos.
O mais comum é o método `Char#to_s`, que converte o Char em uma string. No entanto, também existem o método `Char#to_i`, que converte o Char em um Int, e o método `Char#to_f`, que converte o Char em um Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
