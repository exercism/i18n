# Debug

Quando um teste falha, é exibida uma mensagem descrevendo o que deu errado e para qual entrada.

Imprimir valores e conteúdos de variáveis também pode ajudar a entender o que acontece.
O PHP pode imprimir valores usando:

- `echo 'Debug message';` para exibir uma string de sua escolha
- `var_dump($variable);` para entender melhor um valor, por exemplo, o tipo que o PHP vê
