# Caracteres

Um **caractere** é uma única letra, dígito, espaço ou sinal. O tipo de Sather
para um deles é `CHAR`, e um caractere é escrito entre aspas simples.

```sather
   initial : CHAR is
      return 'M';
   end;
```

Aspas simples para um caractere, aspas duplas para uma string. `'M'` e
`"M"` são tipos diferentes e não podem ser trocados.

## Caracteres a partir de uma string

Uma string é uma sequência de caracteres, e os colchetes alcançam um deles
pela posição, contando do zero, do mesmo jeito que um array.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## Perguntando sobre um caractere

| Chamada | Responde |
| --- | --- |
| `c.is_alpha` | é uma letra? |
| `c.is_digit` | é um dos `0`–`9`? |
| `c.is_upper` | é uma letra maiúscula? |
| `c.is_lower` | é uma letra minúscula? |

Cada uma responde `true` ou `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## Mudando entre maiúsculas e minúsculas

O `.upper` retorna a letra maiúscula de um caractere, e o `.lower` a
minúscula. Qualquer coisa que não seja uma letra é retornada sem alteração.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## Caracteres como números

Todo caractere tem um número. O `.int` o retorna, e o `.char` transforma um
número de volta em um caractere.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

Os números exatos raramente importam. O que importa é que as letras de `a`
a `z` estejam em ordem e uma ao lado da outra, então `'c'.int - 'a'.int` é
2, ou seja, o quão longe o `c` está no alfabeto. É isso que faz uma roda de
cifra funcionar.
