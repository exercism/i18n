# Introdução

## Caracteres

O tipo `char` do C# é uma quantidade de 16 bits que representa os menores componentes endereçáveis do texto.
Vários `char`s podem compor uma string como `"word"`, ou `char`s podem ser
processados individualmente. Seus literais usam aspas simples, por exemplo, `'A'`.

Os `char`s do C# têm suporte à codificação Unicode UTF-16, então, além do conjunto
de caracteres latinos, praticamente todos os sistemas de escrita usados no mundo podem ser representados,
por exemplo, a letra grega `'β'`.

Existem muitos métodos na biblioteca padrão para inspecionar e manipular `char`s. Eles
estão disponíveis como métodos estáticos da classe `System.Char`.

## StringBuilder

Às vezes, `char`s são usados em conjunto com um objeto `StringBuilder`.
Esse objeto tem métodos que permitem construir uma string
caractere por caractere e manipulá-la. No fim do processo,
é possível chamar `ToString` nele para gerar uma string completa.
