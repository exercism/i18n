# Sobre

[Groovy](http://www.groovy-lang.org/) é a linguagem dinâmica, poderosa e com tipagem opcional da Apache Foundation, que também traz recursos de tipagem estática e de compilação estática.

Groovy tem como objetivo melhorar a produtividade de quem desenvolve, graças a uma sintaxe concisa e fácil de aprender. Ela facilita a criação de scripts, a escrita de linguagens específicas de domínio, a metaprogramação em tempo de execução e em tempo de compilação, além da programação funcional.

Ela dá acesso a todo o ecossistema de bibliotecas Java e se integra perfeitamente com aplicações Java.

Pode ser usada como uma linguagem de script simples ou adicionada a frameworks Java complexos. 
Ela está por trás de tecnologias como: 
* Gradle, 
* Spock, 
* Ratpack, 
* Grails, 
* e scripting no Jenkins.

E também é divertida.
