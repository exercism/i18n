# Instruções

Neste exercício, você vai trabalhar em um agendador de compromissos para um salão de beleza que abriu em 15 de setembro de 2012.

Você tem cinco tarefas, e todas elas envolvem datas de agendamento.

## 1. Interpretar a data de um agendamento

Implemente a função `Schedule` para interpretar uma representação textual de uma data de agendamento no formato `time.Time` correspondente:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. Verificar se um agendamento já passou

Implemente a função `HasPassed`, que recebe uma data de agendamento e verifica se o agendamento ficou em algum momento no passado:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. Verificar se o agendamento é à tarde

Implemente a função `IsAfternoonAppointment`, que recebe uma data de agendamento e verifica se o agendamento é à tarde (>= 12:00 e < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. Descrever a data e o horário do agendamento

Implemente a função `Description`, que recebe uma data de agendamento e retorna uma descrição dessa data e desse horário:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. Retornar a data de aniversário da abertura do salão

Implemente a função `AnniversaryDate`, que retorna a data de aniversário da abertura do salão no ano atual em UTC.

Considerando que o ano atual é 2020:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**Observação:** o valor de retorno é um `time.Time` e o horário do dia não importa.
