# Dicas

## 1. Obtenha todos os vinhos de uma determinada cor

- Argumentos nomeados são especificados escrevendo um nome antes do nome do argumento, separados por um espaço.
- A função [`list.filter`][list-filter] pode ser usada para selecionar de uma lista os elementos que atendem a um determinado predicado.

## 2. Obtenha todos os vinhos de uma determinada cor engarrafados em um determinado ano

- Argumentos nomeados são especificados escrevendo um nome antes do nome do argumento, separados por um espaço.
- A função [`list.filter`][list-filter] pode ser usada para selecionar de uma lista os elementos que atendem a um determinado predicado.

## 3. Obtenha todos os vinhos de uma determinada cor engarrafados em um determinado país

- Esta função pode ser implementada chamando `wines_from_country` e depois `wines_of_color` no resultado.
