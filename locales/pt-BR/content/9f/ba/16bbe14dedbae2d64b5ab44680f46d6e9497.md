# Sobre

A biblioteca de sequências do Factor se apoia fortemente em *quotations* (código entre
colchetes `[ ]`) para parametrizar a iteração. A forma é sempre a mesma: passe uma sequência
e uma quotation, e a palavra de ordem superior executa a quotation sobre cada elemento.

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

As palavras mais comuns, na íntegra:

| palavra      | forma                                      |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

Quando a *sua* palavra repassa uma quotation de runtime para um desses combinadores,
declare a sua palavra com `; inline` para que a inferência de efeitos do combinador
consiga enxergar a forma da quotation no local da chamada. Palavras construídas apenas com
quotations literais não precisam disso.

Além das operações centrais de sequência:

| vocabulário              | fornece                                      |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

Os combinadores de pares (`bi`, `tri`) e os "n-ários" (`2map`, `2each`, `zip`) estendem o
mesmo padrão quando a quotation precisa de mais de uma entrada.
