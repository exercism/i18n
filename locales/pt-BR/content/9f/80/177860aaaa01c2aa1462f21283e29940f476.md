# Instruções

Você está ajudando um amigo a gerar um relatório a partir de leituras que ele fez em diferentes cantos do jardim dele.
Infelizmente, seu amigo guardou os dados em um formato estranho.
Cada leitura é um conjunto de campos separados por vírgula.
No entanto, ele distribuiu números de dois dígitos em duas colunas.

| número do campo | significado |
| --- | --- |
| 1 | número de ID |
| 2 | localização |
| 3 | primeira leitura, valor das dezenas |
| 4 | primeira leitura, valor das unidades |
| 5 | segunda leitura, valor das dezenas |
| 6 | segunda leitura, valor das unidades |

Para uma linha de entrada como `101,house,4,2,5,4`
- a primeira leitura é `42`,
- a segunda leitura é `54`.

## Tarefa 1: Gerar o relatório

Sua tarefa é encontrar a média das duas leituras e produzir a saída de cada linha no seguinte formato

```none
#<id>, <label> = <average>
```

Como a média de 42 e 54 é 48, a saída para a linha de exemplo deve ser:

```none
#101, house = 48
```
