# Sobre

O [F#](https://try.fsharp.org/) é uma linguagem funcional e fortemente tipada, que faz parte da pilha de linguagens .NET da Microsoft.

Embora o F# seja ótimo para problemas de ciência de dados, ele consegue lidar com elegância com praticamente qualquer problema que você apresente a ele.

Como o F# roda no runtime do .NET, você tem acesso a todo o ecossistema .NET, incluindo todos os pacotes do [nuget.org](https://www.nuget.org/).

A integração com código .NET existente fica ainda mais simples, porque o F# também permite que você escreva código orientado a objetos.

A página oficial do F# é [fsharp.org](http://fsharp.org/), e uma ótima introdução ao F# está no site [F# for fun and profit](http://fsharpforfunandprofit.com/).
