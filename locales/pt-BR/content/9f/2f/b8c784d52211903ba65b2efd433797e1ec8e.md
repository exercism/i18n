# Introdução

A entrada e saída (I/O) do Factor é construída sobre *streams*: objetos dos quais você lê bytes ou caracteres, ou nos quais você os escreve. O vocabulário [`io`][io] oferece duas visões do mesmo [protocol][stream-protocol].

## As duas visões

As palavras de **stream explícito** recebem o stream como argumento. Todas começam com `stream-`:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

As palavras de **stream ambiente** leem de ou escrevem para o stream que estiver *vinculado no momento*: a variável dinâmica de todo o programa `input-stream` ou `output-stream`. Elas têm nomes curtos:

```
read1 read readln write write1 print flush
```

A forma ambiente é a que a maior parte do código do dia a dia usa. A forma explícita é a que você busca quando tem um stream específico em mãos e não quer trocar o ambiente.

## Streams em memória

Para o exercício, você vai trabalhar com streams baseados em string do [`io.streams.string`][io.streams.string]:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

Um `<string-reader>` lê de uma string literal como se fosse um arquivo; um `<string-writer>` coleta tudo o que for escrito nele para que você possa lê-lo de volta depois. Os dois implementam o mesmo protocolo que os streams de arquivo, então as lições se aplicam diretamente a `<file-reader>` / `<file-writer>`.

## Definindo o escopo com `with-…`

Para vincular um stream explícito como o ambiente de uma quotation e descartá-lo depois, use um combinador `with-…`:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer] é a forma prática para "coletar o que esta quotation imprime": ela cria o writer, executa a quotation com esse writer como a saída ambiente e retorna a string capturada:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

Todos os combinadores `with-…` são combinadores destrutores (da mesma família que `with-disposal` e `with-destructors` de [`boatswains-bilge`][boatswains-bilge]): o stream é descartado na saída, mesmo que a quotation lance uma exceção.
