# Structs

Structs são tipos de dados personalizados que permitem nomear e agrupar vários valores relacionados.
Elas são parecidas com tuplas, mas mais flexíveis, e permitem nomear cada dado, o que deixa o seu código mais claro.
Em Cairo, as structs têm estas propriedades:

- Toda struct tem um nome próprio.
- Cada membro de uma struct é chamado de **campo**.
- Cada campo de uma struct tem um nome próprio.
- A visibilidade é controlada no nível do campo: cada campo pode ser público ou privado de forma independente.

## Definindo e instanciando structs

Para definir uma struct, use a palavra-chave `struct` seguida de um nome e de chaves contendo os campos com seus nomes e tipos:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Para criar uma instância de uma `struct`, especifique o nome da `struct` e use chaves com pares chave-valor para os campos.
Repare que você pode listar os campos em qualquer ordem ao criar uma instância:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Interagindo com uma instância de struct

Use a notação de ponto para acessar ou modificar os campos de uma instância de `struct`.
Repare que, para modificar um campo, a instância precisa ser mutável:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Como em qualquer expressão, podemos construir uma nova instância da `struct` como a última expressão do corpo da função para retornar essa nova instância implicitamente:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Sintaxe abreviada de inicialização de campos

No último exemplo, fazia sentido dar aos parâmetros `email` e `username` da função os mesmos nomes dos campos da `struct`, mas ter que repeti-los ao atribuí-los aos campos da struct é um pouco trabalhoso.
Felizmente, existe uma abreviação conveniente para inicializar campos de struct a partir de variáveis com os mesmos nomes:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Criando instâncias a partir de outras instâncias com a sintaxe de atualização de struct

Use a sintaxe de atualização de struct para criar uma nova instância a partir de uma existente, mudando alguns campos e mantendo os demais iguais.
Isso é feito com o operador `..`.

Sem a sintaxe de atualização:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Com a sintaxe de atualização:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

A sintaxe `..user1` copia os campos restantes de `user1` para `user2`.
Repare que isso move os dados de `user1` para `user2`, então `user1` não pode ser usado depois se contiver tipos que não podem ser copiados.
