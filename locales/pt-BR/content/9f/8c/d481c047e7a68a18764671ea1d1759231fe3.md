# Instruções

Continuando seu trabalho no parque de diversões, sua tarefa é escrever alguns métodos utilitários para facilitar a verificação de se um visitante pode usar um brinquedo.

## 1. Verifique se um visitante tem um passe de brinquedo

Implemente o método `Attendee#has_pass?` para retornar um valor Boolean (`true`/`false`) com base na presença de um passe de brinquedo.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Verifique se um visitante tem altura para um brinquedo

Implemente o método `Attendee#fits_ride?` para ver se um visitante tem altura suficiente para um brinquedo.
A altura mínima exigida pelo brinquedo é fornecida como argumento.
O visitante precisa ter altura maior ou igual à altura mínima exigida pelo brinquedo.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Verifique se um visitante pode andar no brinquedo

Implemente o método `Attendee#allowed_to_ride?` para ver se um visitante pode andar em um brinquedo. A altura mínima exigida pelo brinquedo é fornecida como argumento. O visitante precisa ter um passe de brinquedo e ter altura suficiente para o brinquedo.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
