# Sobre

O `<iota>` do Factor produz uma sequência *virtual* dos inteiros `0, 1, …, n-1`. Percorrê-la com `map` gera uma sequência tabulada em que cada elemento é uma função da sua posição:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Duas peças permitem transformar uma sequência de códigos inteiros em uma string:

| palavra   | papel                                                        |
|-----------|--------------------------------------------------------------|
| `CHAR:`   | literal resolvido em tempo de leitura que empilha o ponto de código de um caractere |
| `>string` | converte uma sequência de pontos de código em uma string     |

Combinadas, elas formam a expressão padrão para montar uma linha de caracteres indexada pela posição:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Escolher o caractere com `if` (ou `?`) dentro da quotation mantém a decisão de cada posição perto do índice do qual ela depende.
