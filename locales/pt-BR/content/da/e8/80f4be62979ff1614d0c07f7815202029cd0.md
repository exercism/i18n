# Introdução

Constantes são valores definidos em tempo de compilação e não podem ser reatribuídas.
Use a palavra-chave `const` para declarar uma única constante:

```go
const greeting = "hello"
```

É possível declarar várias constantes em um bloco.
Dentro de um bloco, uma constante sem um valor explícito repete a expressão anterior:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

Em geral, as constantes são declaradas no nível do pacote, mas também podem ser declaradas dentro de uma função.

## Constantes com tipo e sem tipo

Declarar uma constante sem especificar um tipo faz com que ela fique sem tipo.
Uma constante sem tipo não tem um tipo fixo; é o valor dela que determina com quais tipos ela é compatível.
Desde que o valor subjacente seja compatível, o compilador o converte para o tipo necessário a cada uso:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

Uma constante com tipo fixa o tipo já na declaração:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## O que pode ser uma constante

Constantes só podem conter Boolean, números, strings e runes.
Como os valores são definidos em tempo de compilação, o resultado de uma chamada de função não pode ser usado em uma constante.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

Dentro de um bloco de constantes, `iota` representa a posição da constante dentro do bloco:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

Cada constante depois da primeira herda a mesma expressão, com `iota` incrementando de um em um.

`iota` também funciona em expressões.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
