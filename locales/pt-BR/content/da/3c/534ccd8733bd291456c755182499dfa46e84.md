# Introdução

Uma função em Cairo permite agrupar código em uma unidade reutilizável, deixando seus programas mais modulares e mais fáceis de entender.
As funções em Cairo são compostas pela palavra-chave `fn`, seguida do nome da função, de uma lista de parâmetros entre parênteses e de um bloco de código que define o que a função faz.

## Parâmetros de função

Em Cairo, todos os parâmetros de função precisam ter o tipo declarado explicitamente.
Diferente de algumas linguagens, Cairo não infere tipos e não existe valor padrão para parâmetros, então todos os parâmetros são obrigatórios.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## Parâmetros vs. argumentos

É importante distinguir entre `parameters` e `arguments`:

- **Os parâmetros** são os nomes de variáveis usados na definição da função, como `greeting` e `name` na função `print_greeting_name`.
- **Os argumentos** são os valores de fato passados para a função quando ela é chamada.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## Instruções e expressões

Os corpos de função são formados por uma série de instruções que podem terminar, opcionalmente, em uma expressão.

- As instruções executam alguma ação e não retornam nenhum valor.
- As expressões são avaliadas e resultam em um valor.

Criar uma variável e atribuir um valor a ela com a palavra-chave `let` é uma instrução.

```rust
let y = 6;
```

Mas o `6` na instrução acima é uma expressão que resulta no valor `6`.

Chamar uma função é uma expressão, já que sempre resulta em um valor: o valor de retorno explícito da função, se houver, ou o tipo 'unit' `()` caso contrário.

## Valores de retorno

As funções em Cairo podem retornar valores para o código que as chama.
Os valores de retorno são listados depois dos parâmetros, separados por uma seta `->`.
Em Cairo, o valor de retorno da função é sinônimo do valor da última expressão no bloco do corpo da função.
Você pode retornar antecipadamente de uma função usando a palavra-chave `return` e especificando um valor.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## Chamar funções

Para chamar uma função em Cairo, basta usar o nome da função seguido dos argumentos entre parênteses.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
