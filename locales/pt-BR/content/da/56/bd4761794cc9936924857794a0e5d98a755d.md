# Instalação

Você vai precisar de acesso a um Oracle DB montado. Se você ainda não tem um instalado, aqui vão algumas opções:
* obtenha um espaço de trabalho gratuito em https://apex.oracle.com
* baixe o VirtualBox da Oracle e rode uma das imagens disponíveis gratuitamente; na época em que este texto foi escrito, a mais fácil para começar talvez fosse a _Database App Development VM_. A imagem é bem grande...
* baixe e instale uma versão do próprio Oracle DB. As licenças de desenvolvedor são gratuitas.
