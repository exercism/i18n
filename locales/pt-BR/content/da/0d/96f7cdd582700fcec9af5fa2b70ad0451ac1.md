# Introdução

A [forma especial with][with] oferece uma forma de focar no "happy path" de uma série de etapas que podem falhar e lidar com as falhas depois.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

A cada etapa, se uma cláusula corresponder, a cadeia continua até que o bloco `do` seja executado. Se uma correspondência falhar, a cadeia para e a cláusula que não corresponder é retornada. Você tem a opção de usar um bloco `else` para capturar correspondências que falharam e modificar o valor de retorno.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
