# Instruções

A máquina básica Take-A-Number estava vendendo muito bem, mas alguns usuários reclamavam da falta de recursos avançados em comparação com outros modelos disponíveis no mercado.

O fabricante ouviu o feedback dos usuários e decidiu lançar um modelo deluxe com mais recursos, e mais uma vez você ficou responsável por escrever o software dessa máquina.

Os novos recursos adicionados ao modelo deluxe incluem:
- Manter o controle dos números que estão na fila no momento.
- Definir o número mínimo e o número máximo. Isso permite usar várias máquinas Take-A-Number deluxe para enfileirar clientes de departamentos diferentes de uma mesma instalação, e distinguir os departamentos pela faixa de números.
- Permitir que certos números furem a fila, para oferecer atendimento prioritário a gestantes e idosos.
- Desligamento automático, para evitar deixar a máquina ligada sem querer durante todo o fim de semana e desperdiçar energia.

A lógica de negócios da máquina já foi implementada pelo seu colega e pode ser encontrada no módulo `TakeANumberDeluxe.State`. Agora sua tarefa é envolvê-la em um `GenServer`.

## 1. Iniciar a máquina

Use o behaviour `GenServer` no módulo `TakeANumberDeluxe`.

Implemente a função `start_link/1` e o callback `GenServer` necessário.

O argumento passado para `start_link/1` é uma keyword list. Ela contém as chaves `:min_number` e `:max_number`. Os valores sob essas chaves precisam ser passados para a função `TakeANumberDeluxe.State.new/2`.

Se `TakeANumberDeluxe.State.new/2` retornar uma tupla `{:ok, state}`, a máquina deve iniciar, usando o estado retornado como seu estado. Se ela retornar uma tupla `{:error, error}`, a máquina deve parar, usando o erro retornado como motivo da parada.

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

Você deve ter notado que a função `TakeANumberDeluxe.State.new/2` também aceita um terceiro argumento opcional, `auto_shutdown_timeout`. Vamos usá-lo no último passo deste exercício.

## 2. Relatar o estado da máquina

Implemente a função `report_state/1` e o callback `GenServer` necessário. A máquina deve responder ao chamador com seu estado atual.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. Enfileirar novos números

Implemente a função `queue_new_number/1` e o callback `GenServer` necessário.

Ela deve chamar a função `TakeANumberDeluxe.State.queue_new_number/1` com o estado atual da máquina.

Se `TakeANumberDeluxe.State.queue_new_number/1` retornar uma tupla `{:ok, new_number, new_state}`, a máquina deve responder ao chamador com o novo número e definir o novo estado como seu estado. Se ela retornar uma tupla `{:error, error}`, a máquina deve responder ao chamador com o erro e não alterar seu estado.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. Atender o próximo número da fila

Implemente a função `serve_next_queued_number/2` e o callback `GenServer` necessário.

Ela deve chamar a função `TakeANumberDeluxe.State.serve_next_queued_number/2` com o estado atual da máquina e seu segundo argumento opcional, `priority_number`.

Se `TakeANumberDeluxe.State.serve_next_queued_number/2` retornar uma tupla `{:ok, next_number, new_state}`, a máquina deve responder ao chamador com o próximo número e definir o novo estado como seu estado. Se ela retornar uma tupla `{:error, error}`, a máquina deve responder ao chamador com o erro e não alterar seu estado.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. Redefinir o estado

Implemente a função `reset_state/1` e o callback `GenServer` necessário.

Ela deve chamar a função `TakeANumberDeluxe.State.new/2` para criar um novo estado usando o `min_number` e o `max_number` do estado atual. A máquina deve definir o novo estado como seu estado. Ela não deve responder ao chamador.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. Implementar o desligamento automático

Modifique a inicialização da máquina. Ela deve ler o valor sob a chave `:auto_shutdown_timeout` na keyword list passada como `init_arg` e passá-lo como terceiro argumento para `TakeANumberDeluxe.State.new/3`. Use o valor padrão `:infinity` se `:auto_shutdown_timeout` não tiver sido informado.

Modifique a redefinição do estado da máquina para também passar `auto_shutdown_timeout` para `TakeANumberDeluxe.State.new/3`.

Modifique os valores de retorno de todos os callbacks implementados (`init/1` e todos os callbacks `handle_*`) para definir um timeout. Use o valor sob a chave `:auto_shutdown_timeout` no estado atual da máquina. Não adicione o timeout ao valor de retorno `{:stop, reason}` de `init/1`: timeouts só se aplicam depois que o servidor iniciou seu loop de recebimento.

Implemente um callback `GenServer` para tratar a mensagem `:timeout` que será enviada à máquina se ela não receber nenhuma outra mensagem dentro do timeout informado. Ela deve encerrar o processo com o motivo `:normal`.

Certifique-se de também tratar quaisquer mensagens inesperadas, ignorando-as.

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
