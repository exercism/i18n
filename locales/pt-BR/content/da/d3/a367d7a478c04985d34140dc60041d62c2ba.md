# Instruções

Neste exercício, você vai escrever mais um pouco de código relacionado ao preparo e ao cozimento da sua lasanha maravilhosa, tirada do seu livro de receitas favorito.

Você tem quatro tarefas.
A primeira tem a ver com o cozimento em si, e as outras três com a preparação perfeita.

## 1. Estime o tempo de preparo

Para a próxima lasanha que você preparar, você quer ter certeza de que reservou tempo suficiente para aproveitar o cozimento.
Você já planejou quais camadas a sua lasanha vai ter.
Agora você quer estimar quanto tempo o preparo vai levar com base nisso.

Implemente uma função `PreparationTime` que aceita uma slice de camadas como `[]string` e o tempo médio de preparo por camada em minutos como um `int`.
A função deve retornar a estimativa do tempo total de preparo com base no número de camadas, como um `int`.
Go não tem valores padrão para funções.
Se o tempo médio de preparo for passado como `0` (o valor inicial padrão de um `int`), então o valor padrão `2` deve ser usado.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. Calcule as quantidades de macarrão e molho necessárias

Além de reservar o tempo, você também quer ter certeza de que tem molho e macarrão suficientes para cozinhar a lasanha dos seus sonhos.
Para cada camada de macarrão na sua lasanha, você vai precisar de 50 gramas de macarrão.
Para cada camada de molho na sua lasanha, você vai precisar de 0,2 litro de molho.

Defina a função `Quantities` que recebe uma slice de camadas como parâmetro, do tipo `[]string`.
A função vai então determinar a quantidade de macarrão e molho necessária para preparar sua refeição.
O resultado deve ser retornado como dois valores: `noodles` como um `int` e `sauce` como um `float64`.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. Adicione o ingrediente secreto

Um tempo atrás, você visitou um amigo e comeu lasanha na casa dele.
Estava incrível e tinha algo especial.
O amigo te mandou a lista de ingredientes e disse que o último item da lista é o "ingrediente secreto" que deixou a refeição tão especial.
Agora você também quer adicionar esse ingrediente secreto à sua receita.

Escreva uma função `AddSecretIngredient` que aceita duas slices de ingredientes do tipo `[]string` como parâmetros.
O primeiro parâmetro é a lista que seu amigo te mandou, o segundo é a lista de ingredientes da sua própria receita.
O último elemento da sua lista de ingredientes é sempre `"?"`.
A função deve substituí-lo pelo último item da lista do seu amigo.
**Observação:** `AddSecretIngredient` não retorna nada. Você deve modificar diretamente a lista dos seus ingredientes.
A lista com os ingredientes do seu amigo **não** deve ser modificada.
Além disso, como a `slice` é passada para uma função como ponteiro, as alterações feitas nos dois argumentos `[]string` passados para `AddSecretIngredient` acontecem diretamente.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Escale a receita

As quantidades listadas no seu livro de receitas só rendem lasanha suficiente para duas porções.
Como você quer cozinhar para mais pessoas da próxima vez, você quer calcular as quantidades para diferentes números de porções.

Implemente uma função `ScaleRecipe` que recebe dois parâmetros.

- Uma slice de valores `float64` necessários para 2 porções.
- O número de porções que você quer preparar.

A função deve retornar uma slice de `float64` com as quantidades necessárias para o número de porções desejado.
Mas você quer manter a receita original.
Isso significa que o argumento `quantities` não deve ser modificado nesta função.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
