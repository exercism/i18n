Concatenar strings manualmente no Haxe é possível, mas o Haxe oferece a [interpolação de strings][string-interpolation], que traz uma sintaxe mais curta e mais conveniente:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

Como mostrado acima, strings interpoladas são delimitadas por aspas simples (`'`), ao contrário das [strings][strings] comuns, e podem conter identificadores especiais denotados pelo cifrão (`$`), que disparam a interpolação.

Também é possível incluir expressões inteiras usando `${expr}`, em que `expr` é qualquer expressão válida do Haxe:

```haxe
trace('the next number is ${x + 1}');
```

Para suprimir a interpolação quando você quer um cifrão de verdade, use `$$`:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

Por último, vale notar que a interpolação de strings é um recurso de tempo de compilação que não afeta o desempenho em tempo de execução. Internamente, o compilador do Haxe gera o código equivalente ao da concatenação manual.

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
