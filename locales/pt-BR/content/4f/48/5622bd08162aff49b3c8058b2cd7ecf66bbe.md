# Introdução

## Resultados

Gleam não usa exceções para tratar erros. Em vez disso, funções que podem dar certo ou falhar retornam o tipo genérico `Result`.

O tipo `Result` já vem embutido na linguagem, então você não precisa defini-lo nem importá-lo. Mas, se você fosse defini-lo, ficaria assim:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

A variante `Ok` é retornada quando uma função dá certo, e a variante `Error` é retornada quando uma função falha.

Os resultados são muito comuns em Gleam, e quem programa em Gleam costuma usar o [módulo `gleam/result`](https://hexdocs.pm/gleam_stdlib/gleam/result.html) para facilitar o trabalho com eles.

A função `result.map` pode ser usada para chamar uma função sobre o valor dentro de um resultado, caso ele seja um `Ok`, ou para deixar passar um `Error` sem alterações.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

A função `result.try` é parecida, mas espera-se que a função de callback retorne um resultado. Isso é útil para encadear várias funções que retornam resultados.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
