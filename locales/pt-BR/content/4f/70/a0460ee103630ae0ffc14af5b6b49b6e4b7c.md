## 1. Defina o tipo `Fiberator`

- `n` é a quantidade de números a gerar.
- Mantenha tudo simples: nenhuma outra informação é necessária.

## 2. Implemente o(s) método(s) `iterate`

- Veja a Introdução para detalhes importantes de implementação.
- O argumento `state` não precisa ser um número inteiro. Pode ser de qualquer tipo.
- Considere quais valores você precisa para calcular o próximo elemento. Uma tupla desses valores deve ser o argumento `state`.
- O método `iterate` retorna uma `Tuple` com dois valores `(item, state)`. `item` é o número de Fibonacci, ou seja, o `item` em `for item in Fiberator(10)`.
- Se o seu `state` incluir vários valores, considere usar uma tupla nomeada para esclarecer o significado de cada valor.
  - Isso é útil para desempacotar, mas não é obrigatório.
