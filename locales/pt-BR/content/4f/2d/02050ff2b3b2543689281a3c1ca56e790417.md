# Dicas

## 1. As três atrações

- O cabeçalho da classe nomeia a classe abstrata depois do `<`:
  `class JUGGLING < $ACT is`.
- Cada uma precisa definir `name` e `minutes`, exatamente como a classe abstrata os declara. Se faltar um dos dois, dá um erro de compilação que aponta o nome da rotina.
- Cada uma também precisa de um `create`, senão o `#JUGGLING` não tem o que chamar. Para duas delas, `create : SAME is return new; end;` já é o suficiente.
- `TRAPEZE` precisa de um atributo para a altura e de um `create` que receba essa altura.
- O `+` junta um número a uma string, então `"Trapeze at " + height + "m"` não precisa de nenhuma conversão.

## 2. O espetáculo

- O tipo do argumento é `ARRAY{$ACT}`. É isso que permite que um único array guarde os três tipos.
- `acts.elt!` devolve um `$ACT`. Chamar `.minutes` nele executa a versão certa sozinho: isso é o despacho, e é justamente o ponto do exercício. Não há nada para verificar nem `typecase` para escrever.
- `billing` monta uma string em um laço, então `FSTR`, e o `", "` vem antes de cada nome, exceto o primeiro.
- `longest` mantém a melhor atração até o momento. Começar os minutos da melhor atração em `-1` faz com que a primeira atração sempre a supere, o que resolve o espetáculo vazio sem um caso especial: o nome continua sendo `""`.
