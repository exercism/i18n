# Introdução

O Python tem duas construções de laço.
Laços `while` para iteração _indefinida_ (não contada) e laços `for` para iteração _definida_ (contada).
As palavras-chave `break`, `continue` e `else` ajudam a personalizar o comportamento do laço.
As funções `range(<length of sequence>)` e `enumerate(<iterable>)` ajudam na contagem e na indexação do laço.


Os laços `while` não têm um número de repetições a executar especificado e continuam enquanto a expressão do `loop`, ou o "teste", for avaliada como `True`.
O laço termina quando a expressão do laço for avaliada como `False`.

```python
while expression:
    set_of_statements
```

Os laços `for` percorrem os valores de qualquer sequência e terminam quando não há mais valores a retornar.
A função `range(<length of sequence>)` fornece um contador de `loop` ou uma sequência quando não há uma estrutura de dados ou outro iterável sobre o qual iterar.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
