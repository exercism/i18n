# Rodando os testes

No terminal, vá até o diretório base do exercício e execute os testes com:

```bash
$ gleam test
```

Isso vai executar o arquivo de teste que está na subpasta `test`, um arquivo que termina em `_test.gleam`

## Funções de teste

Os testes usam um [framework de teste personalizado](https://github.com/exercism/gleam-test-runner/tree/main/runner).
Qualquer função pública no diretório `test` cujo nome termine em `_test` será considerada um teste pelo framework.

Por exemplo:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
