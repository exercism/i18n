# Dicas

## Geral

- Talvez você queira criar uma DSL baseada em listas de tags e registros, como esta:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- Ou talvez você prefira uma DSL baseada em cadeias de chamadas de função, como esta:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  Ou quem sabe você tenha um plano bem diferente?
  Vá em frente!

- Dito isso, uma DSL costuma ser melhor quando é clara, concisa e não muito surpreendente (por exemplo, a função `minus` serve para subtrair, não para criar uma aresta entre dois nós, como em `node("a") - node("b")`).
