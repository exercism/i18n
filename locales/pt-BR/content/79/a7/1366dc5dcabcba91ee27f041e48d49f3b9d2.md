# Instruções

Neste exercício, você vai organizar corridas entre vários tipos de carros de controle remoto.
Cada carro tem suas próprias características e corre em muitas pistas diferentes, em corridas ao longo da temporada do torneio.

~~~~exercism/note
As funções deste exercício são declaradas em um arquivo fonte em C com as assinaturas fornecidas.
O seu código em x86-64 assembly precisa seguir essas especificações.
~~~~

## 1. Crie um carro de controle remoto

Você definiu uma struct `car_t` para representar um carro de controle remoto:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

Permita criar um carro de controle remoto definindo uma função `new_car` em x86-64 assembly.
O campo `battery` sempre começa com o valor `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Crie uma nova pista

As pistas são representadas por uma struct `track_t`:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

O `enum surface_t` guarda os diferentes tipos de superfície de uma pista:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

Permita criar uma nova pista definindo uma função `new_track` em x86-64 assembly.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Crie um evento de corrida

Até 6 carros participam de cada corrida, dando um número determinado de voltas em uma pista.
As corridas são representadas por uma struct `race_t`:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Defina uma função `new_race` em x86-64 assembly.
No início, não há carros com participação confirmada na corrida:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Confirme um carro na corrida

Quando o dono de um carro pede que ele participe de uma corrida, a participação só é confirmada se a lista ainda não estiver cheia.

Defina uma função `add_participant` em x86-64 assembly.
Se houver espaço para mais um participante na corrida, o carro é adicionado à lista, o contador é atualizado e a participação dele é confirmada.
Caso contrário, os organizadores da corrida precisam informar ao dono do carro que ele não pode participar desta vez.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Crie um torneio

Você acompanha as corridas agendadas para a temporada em uma struct `tournament_t`:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Defina uma função `add_race` em x86-assembly, para adicionar uma corrida ao array do torneio e também atualizar o contador.
Você pode considerar que sempre haverá espaço suficiente no array `races` para a nova corrida.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
