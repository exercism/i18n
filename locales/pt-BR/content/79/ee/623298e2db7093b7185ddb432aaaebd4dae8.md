# Anexo de instruções

## Formatos de saída

A função `treeFromTraversals` deve retornar um objeto com 3 propriedades:

- `value` O valor do nó atual
- `left`  Um objeto que contém o filho à esquerda do nó
- `right`  Um objeto que contém o filho à direita do nó

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

Se a árvore estiver vazia, deve ser retornado um objeto vazio.
