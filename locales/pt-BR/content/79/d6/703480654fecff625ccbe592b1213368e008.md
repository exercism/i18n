# Instruções

Olá de novo, Agente Double-Null0111.

As forças da UMBRA estão de novo em ação, e cabe a você frustrar o mais recente plano delas.
Nossa divisão de inteligência nos informa que aqueles Minions estão planejando detonar uma bomba fétida no baile do Governador.

Como os Minions são muito desastrados, muitas vezes eles armam as bombas fétidas sem querer em seus laboratórios e escritórios.
E como eles vivem esquecendo como desarmar suas bombas fétidas, eles implementaram um sistema que gera as instruções de desarme, que listam a ordem em que os fios devem ser cortados a partir do número de ID da bomba.

Seu trabalho é escrever o código que vai permitir que você desarme a bomba fétida no baile antes que ela exploda.

## 1. Escreva um closure para trocar dois fios

Há três fios de cores diferentes em cada bomba fétida.
Escreva um closure que recebe uma tupla `(String, String, String)` e retorna a tupla com a ordem dos dois primeiros elementos invertida.
Atribua esse closure ao nome `flip`.

É importante notar que o tipo precisa ser o `ChangeClosure` (ou um sendable type), a definição do tipo está no arquivo stub.
Caso contrário, o código não vai compilar.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Escreva um closure para girar os fios

Escreva um closure que recebe uma tupla `(String, String, String)` e retorna a tupla com a ordem dos fios girada para a esquerda.
Atribua esse closure ao nome `rotate`.

É importante notar que o tipo precisa ser o `ChangeClosure` (ou um sendable type), a definição do tipo está no arquivo stub.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Implemente um gerador de embaralhamento de fios

Para descobrir a ordem em que os fios da bomba fétida devem ser cortados, você vai precisar implementar uma função que gera a função de embaralhamento adequada com base no número de ID da bomba fétida.

Implemente a função:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

que recebe como entrada um closure que troca dois fios e um closure que gira os três fios, e retorna um closure.
Esse closure retornado recebe o número de ID da bomba fétida e a ordem dos três fios, e então calcula a ordem em que os fios precisam ser cortados.
O número de ID é formado por oito bits, e cada bit vai determinar se os fios devem ser trocados ou girados.

Para cada bit do número de ID, começando pelo bit mais à direita, você vai aplicar o closure `flipper` à tupla de fios se o bit for 0, e vai aplicar o closure `rotator` se for 1, obtendo o novo estado dos fios.
Depois que os closures apropriados tiverem sido aplicados para todos os oito bits do ID, o estado final dos fios é a ordem em que eles precisam ser cortados.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
