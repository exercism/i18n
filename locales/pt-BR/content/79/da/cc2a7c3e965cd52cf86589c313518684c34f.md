# Introdução

Em C#, o literal `null` é usado para denotar a ausência de um valor. Um tipo _anulável_ é um tipo que permite valores `null`.

Antes do C# 8.0, os tipos de referência eram sempre anuláveis e os tipos de valor não eram. Um tipo de valor, porém, pode se tornar anulável acrescentando a ele um ponto de interrogação (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Acessar um membro de uma variável cujo valor é `null` compila sem problemas, mas faz com que uma `NullReferenceException` seja lançada em tempo de execução:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

Para combater esse tipo comum de erro, o C# 8 permite optar por um recurso que torna os tipos de referência não anuláveis por padrão:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Para trabalhar com segurança com valores anuláveis, deve-se verificar se eles são `null` antes de usá-los:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

O operador `??` permite retornar um valor padrão quando o valor é `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

O operador `?.` permite chamar membros com segurança em um valor que pode ser `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
