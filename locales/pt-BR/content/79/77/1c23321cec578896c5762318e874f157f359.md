# Introdução

## Comparando números

Em JavaScript, números podem ser comparados usando os seguintes operadores relacionais e de igualdade.

| Comparação             | Operador  |
| ---------------------- | --------- |
| Maior que              | `a > b`   |
| Maior ou igual a       | `a >= b`  |
| Menor que              | `a < b`   |
| Menor ou igual a       | `a <= b`  |
| Igual (estrito)        | `a === b` |
| Diferente (estrito)    | `a !== b` |

O resultado da comparação é sempre um valor Boolean, ou seja, `true` ou `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## Comparando strings

Em JavaScript, os operadores de comparação acima também podem ser usados para comparar strings.
Nesse caso, aplica-se uma ordem de dicionário (lexicográfica).
Você encontra uma lista com a ordem exata de todos os caracteres [aqui][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Igualdade estrita

Você pode se perguntar por que a verificação de igualdade em JavaScript usa três sinais de igual.
O `===` representa a verificação de _igualdade estrita_, o que significa que nenhuma conversão de tipo é realizada e valores de tipos diferentes nunca são iguais.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

Usar `===` e `!==` é a forma recomendada de verificar igualdade em JavaScript.

Também existem `==` e `!=`, que representam a verificação de _igualdade solta_.
Você deve evitá-los, porque eles aplicam uma conversão de tipo implícita antes de fazer a comparação.
Os resultados nesses casos são difíceis de prever e às vezes não são o que você espera.

```javascript
0 == false;
// => true
```
