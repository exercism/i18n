# Sobre

Em Common Lisp, valores falsos são representados pela lista vazia (`()`) ou pelo símbolo `nil`.
Esses valores podem ser citados ou não.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Todos os outros valores em Lisp são considerados verdadeiros.
Existe também o símbolo constante especial `t`, que é sempre igual a `t` (e, portanto, é sempre verdadeiro).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
