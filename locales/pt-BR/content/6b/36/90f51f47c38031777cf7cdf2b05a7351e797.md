# Sobre

Em F#, os valores Boolean são representados pelo tipo `bool`, cujos valores podem ser `true` ou `false`.

O F# oferece três [operadores Boolean][operators]: `not` (NOT), `&&` (AND) e `||` (OR). Os operadores `&&` e `||` usam a _avaliação de curto-circuito_, o que significa que o lado direito do operador só é avaliado quando necessário.

```fsharp
true || false // => true
true && false // => false
```

Os três operadores Boolean têm cada um uma [_precedência de operadores_][precedence] diferente. Como consequência, eles são avaliados nesta ordem: primeiro o `not`, depois o `&&` e, por fim, o `||`. Se você quiser "escapar" dessas regras, pode colocar uma expressão Boolean entre parênteses (`()`), já que os parênteses têm uma precedência de operadores ainda maior.

```fsharp
not true && false   // => false
not (true && false) // => true
```
