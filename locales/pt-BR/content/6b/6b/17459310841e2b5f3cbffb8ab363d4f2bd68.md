# Instruções

O trabalho está indo bem na _Instruments of Texas_ com a Calculadora RPN. Sua equipe agora quer conseguir escrever uma versão em string da equação em um recurso de _IO_.

## 1. Abra um arquivo

Sua equipe ainda não decidiu para que tipo de dispositivo escrever a equação, então você sugere usar uma abordagem de _despacho dinâmico_ para poder injetar o recurso na função em vez de deixá-lo fixo no código. Implemente a função `write/3` para abrir um _dispositivo de IO_ usando o recurso e o nome do arquivo.

Você pode assumir que `resource` será sempre um átomo que representa um módulo com uma função `open/1` que retorna `{:ok, io_device}`.

Quando a função tiver sucesso, retorne uma tupla ok com a equação.

```elixir
RPNCalculator.Output.write(resource, "file_to_be_written", "1 4 +")
# {:ok, "1 4 +"}
```

## 2. Tente escrever no dispositivo de IO

Agora que você abriu o dispositivo de IO, tente escrever nele usando `IO.write/2`.

Estenda a função `write/3` para realizar essa ação. A tentativa de escrita pode lançar um erro; resgate o erro e retorne uma tupla de erro:

```elixir
RPNCalculator.Output.write(resource, "bad_file", "1 4 +")
# {:error, "Unable to write to resource"}
```

## 3. Feche o dispositivo de IO

É uma boa prática sempre tentar liberar os recursos que você abriu, mesmo que a função que usa o recurso lance um erro. Estenda a função `write/3` para chamar a função de fechamento do recurso e fechar o _dispositivo de IO_.

Você pode assumir que `resource` será sempre um átomo que representa um módulo com uma função `close/1` que recebe um _dispositivo de IO_.
