# Sobre

Os enums do Rust também são chamados de [tipos de dados algébricos](https://en.wikipedia.org/wiki/Algebraic_data_type), ou [uniões marcadas](https://en.wikipedia.org/wiki/Tagged_union). Por que isso importa? Enumerações são um conceito popular e cada linguagem de programação as implementa de um jeito diferente. A programação funcional influenciou o design do Rust, e a implementação de `enum` é prova disso.

- [introdução aos enums no livro do Rust](https://doc.rust-lang.org/book/ch06-01-defining-an-enum.html)
