# Instruções

Neste exercício você vai escrever código para ajudar uma pessoa freelancer a se comunicar com um gerente de projeto, fornecendo alguns utilitários para calcular rapidamente os valores diário e mensal, opcionalmente com um desconto.

Primeiro, vamos estabelecer algumas regras entre a pessoa freelancer e o gerente de projeto:

- O valor da diária é 8 vezes o valor por hora.
- Um mês tem 22 dias faturáveis.

Às vezes, a pessoa freelancer oferece aplicar um desconto sobre o valor da diária (por exemplo, para os clientes mais fiéis ou para clientes sem fins lucrativos).

Os descontos são modelados como números fracionários que representam porcentagem, por exemplo `25.0` (25%).

## 1. Calcular o valor da diária a partir de um valor por hora

Implemente uma função para calcular o valor da diária a partir de um valor por hora:

```haskell
dailyRate 60
-- -> 480.0
```

O valor da diária retornado deve ser um double.

## 2. Calcular um preço com desconto

Implemente uma função para calcular o preço depois de um desconto.

```haskell
applyDiscount 150 10
-- -> 135.0
```

O valor retornado deve ser sempre um double, sem nenhum arredondamento.

## 3. Calcular o valor mensal a partir de um valor por hora e um desconto

Implemente uma função para calcular o valor mensal e aplicar um desconto:

```haskell
monthlyRate 77 10.5
-- -> 12130
```

O valor mensal retornado deve ser arredondado para cima (usando o teto) até o inteiro mais próximo.

## 4. Calcular o número de dias de trabalho a partir de um orçamento, um valor por hora e um desconto

Implemente uma função que recebe um orçamento, um valor por hora e um desconto, e calcula quantos dias de trabalho isso cobre.

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

O número de dias retornado deve ser arredondado para baixo (usando o piso) com uma casa decimal.
