# Sobre

Tcl, pronunciado "tickle" e abreviação de Tool Command Language, é uma linguagem de programação dinâmica e de código aberto.

Ela foi criada com o objetivo de ser muito simples, mas poderosa.
É tão simples que toda a sua sintaxe é descrita por completo em [apenas 12 regras][rules].
Mesmo assim, é uma linguagem de programação completa.

O Tcl transforma tudo em *comandos*, até mesmo atribuições de variáveis, definições de procedimentos e fluxo de controle.
Por isso, lembra tanto scripts de shell quanto Lisp.

O Tcl oferece suporte a vários paradigmas de programação, incluindo o orientado a objetos, o imperativo e o funcional.
Os usos mais comuns do Tcl são como ambiente de execução de scripts embarcado em aplicações C e para prototipagem de GUIs com o toolkit Tk.
