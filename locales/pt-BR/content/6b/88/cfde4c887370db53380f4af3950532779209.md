# Introdução

O Unison representa os valores true e false com o tipo `Boolean`. Existem apenas dois valores: `true` e `false`.

```unison
trueVariable = true
falseVariable = false
```

Podemos avaliar expressões booleanas usando os operadores e, representado por `&&`; ou, representado por `||`; e não, representado por `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
