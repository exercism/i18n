# Dicas

## Geral

- Não se preocupe com a forma como os argumentos são obtidos, apenas foque em combinar os argumentos para retornar o resultado esperado.

## 1. Defina se o pac-man pode comer um fantasma

- A função deve retornar um valor Boolean.
- Você pode usar o operador lógico e ([`&&`][logical operators]) para combinar os argumentos e chegar a um resultado.

## 2. Defina se o pac-man marca pontos

- A função deve retornar um valor Boolean.
- Você pode usar o operador lógico ou ([`||`][logical operators]) para combinar os argumentos e chegar a um resultado.

## 3. Defina se o pac-man perde

- A função deve retornar um valor Boolean.
- Você pode usar os operadores Boolean [`&&`][logical operators] e [`!`][logical operators] para combinar os argumentos e chegar a um resultado.

## 4. Defina se o pac-man vence

- A função deve retornar um valor Boolean.
- Você pode usar os operadores Boolean [`&&`][logical operators] e [`!`][logical operators] para combinar os argumentos e os resultados de uma das funções implementadas anteriormente.

[logical operators]: https://en.cppreference.com/w/cpp/language/operator_logical
