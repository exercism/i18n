# Instruções

Neste exercício, você vai implementar um conjunto parcial de rotinas utilitárias para ajudar quem desenvolve a limpar nomes SqueakyClean.

Nas 4 tarefas, você vai montar aos poucos o método `clean`.
Um nome SqueakyClean válido é composto de zero ou mais letras e sublinhados.

Em todos os casos, é garantido que a string de entrada não será nula. Repare que o método `clean` deve tratar uma string vazia como válida.

## 1. Substitua os espaços encontrados por sublinhados

Implemente o método (_static_) `SqueakyClean.clean()` para substituir os espaços por sublinhados. Isso também vale para espaços no início e no fim.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Converta kebab-case em camelCase

Modifique o método (_static_) `SqueakyClean.clean()` para converter kebab-case em camelCase.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Converta leetspeak em texto normal

Modifique o método (_static_) `SqueakyClean.clean()` para converter [leetspeak][leet-speak] em texto normal.

Para simplificar, vamos substituir apenas `4`, `3`, `0`, `1` e `7` por `a`, `e`, `o`, `l` e `t`, respectivamente.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Remova os caracteres que não são letras

Modifique o método (_static_) `SqueakyClean.clean()` para remover os caracteres que não são letras.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
