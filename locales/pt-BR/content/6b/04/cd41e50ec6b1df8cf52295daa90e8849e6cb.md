# Complemento das instruções

## Dicas

- Para analisar o texto, você pode tentar usar a biblioteca [Sprache](https://github.com/sprache/Sprache/blob/develop/README.md). Você também pode encontrar um bom tutorial [aqui](https://www.thomaslevesque.com/2017/02/23/easy-text-parsing-in-c-with-sprache/).
- Você pode resolver este exercício com um algoritmo de força bruta, mas o desempenho em tempo de execução provavelmente será ruim.
  Tente encontrar uma solução mais sofisticada.
- Dica: você pode tentar o algoritmo de adição coluna por coluna que costuma ser ensinado na escola.
