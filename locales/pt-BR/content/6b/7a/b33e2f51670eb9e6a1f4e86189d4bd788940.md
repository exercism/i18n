# Testes

Se você baixou um exercício com a ferramenta CLI, você vai ver um arquivo Futhark com o nome do exercício e um arquivo `test.fut`.
Esse arquivo contém todos os casos de teste, que correspondem aos que o test runner executa quando você envia sua solução.
Fique à vontade para adicionar mais casos de teste para experimentar.
No entanto, modificar os testes não afeta o processo do test runner online.

## Testes locais

Para rodar os testes de um exercício, abra um terminal no diretório do exercício e rode o comando `futhark test test.fut` (ou `exercism test`).

## Recursos adicionais

Para saber mais sobre testes com Futhark, consulte a documentação do [`futhark test`][test-command].
