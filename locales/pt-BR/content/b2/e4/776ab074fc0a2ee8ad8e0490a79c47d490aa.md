# Introdução

O _operador ternário_ é uma alternativa leve e compacta para condicionais simples do tipo _if/else_.
Normalmente é usado em instruções de retorno (mas não apenas nelas), e precisa de uma única linha para tomar a decisão, retornando o valor da esquerda se a expressão for `true` e o valor da direita se for `false`, da seguinte forma:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Muitas expressões _if/else_ simples podem ser simplificadas com o uso de _operadores ternários_.
