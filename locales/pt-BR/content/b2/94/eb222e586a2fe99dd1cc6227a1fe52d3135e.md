# Instruções

Um grande pomar de cerejeiras geralmente tem um pequeno estoque de árvores excedentes que gostaria de oferecer como madeira.
Isso ajuda a manter o pomar saudável e, ao mesmo tempo, gera uma receita extra.
Eles pediram sua ajuda para programar algumas funcionalidades que auxiliem no processo de seleção de árvores quando um possível cliente liga.

~~~~exercism/note
A biblioteca [`datasets`][ref-datasets] embutida tem muitos conjuntos de dados de exemplo, e este exercício usa o conjunto de dados `trees`.
Para chamar o conjunto de dados, basta usar o nome `trees`.
```R
library(datasets) # loading is optional

trees |> head(3)
#>    A data.frame: 3 × 3 	
#>   Girth	Height	Volume
#>	 <dbl>	 <dbl>	 <dbl>
#> 1   8.3	    70	  10.3  
#> 2   8.6	    65	  10.3
#> 3   8.8	    63	  10.2
```
Repare nas três colunas: `Girth`, `Height` e `Volume`

O conjunto de dados inicialmente está na forma de um `data.frame`, mas você pode querer trabalhar com ele como um `tibble`.

[ref-datasets]: https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/00Index.html
~~~~

## 1. Renomeie uma coluna

Infelizmente houve um erro administrativo que nunca foi corrigido, e uma coluna do conjunto de dados se chama `Girth`, mas na verdade ela é o `Diameter`.

Defina um data.frame/tibble chamado `tree_data` que corrija o nome da coluna `Girth` em `trees` para `Diameter`.

```R
head(tree_data, 3)
#>     A tibble: 3 × 3 
#> Diameter	 Height	Volume
#>    <dbl>	  <dbl>	 <dbl>
#>      8.3	     70	  10.3
#>      8.6	     65	  10.3
#>      8.8	     63	  10.2
```

## 2. Adicione as colunas de circunferência e peso

A circunferência ainda é uma medida útil, assim como o peso da madeira.
A circunferência é facilmente calculada por `πD`, onde `D` é o diâmetro.
O peso de toda a madeira pode ser calculado por `ρV`, onde `ρ = 35` é a densidade da madeira de cerejeira e `V` é o volume da madeira.

Defina a função `girth_n_weight(data, rnd_digits)`, que recebe um dataframe e argumentos numéricos.
A função deve retornar um novo dataframe com as duas colunas adicionais: `Girth` e `Weight`, arredondadas para o número apropriado de dígitos dado por `rnd_digits`.

```R
girth_n_weight(tree_data, 1) |> head(3)
#>           A tibble: 3 × 5 
#> Diameter  Height	 Volume	 Girth	Weight
#>    <dbl>	  <dbl>	  <dbl>	 <dbl>	 <dbl>
#>      8.3	     70	   10.3	  26.1	 360.5
#>      8.6	     65	   10.3	  27.0	 360.5
#>      8.8	     63	   10.2	  27.6	 357.0
```

## 3. Cópia do conjunto de dados do pomar

Para cada possível cliente, o pomar mantém uma cópia especial do conjunto de dados para ajudar na venda.
Esse conjunto de dados tem as colunas mais relevantes, `Weight` e `Height`, movidas para a frente, e fica ordenado por `Weight`.

Defina a função `orchard_copy(data, important_cols)`, que recebe um dataframe como entrada.
Ela deve retornar um novo dataframe com `Weight` e `Height` movidas para a frente e as linhas ordenadas por `Weight`.

```R
tree_data |> girth_n_weight() |> orchard_copy() |> head(3)
#>            A tibble: 3 × 5 
#> Weight	Height	Diameter	Volume	Girth
#>  <dbl>	 <dbl>	   <dbl>	 <dbl>	<dbl>
#>    357	    63	       9	    10	   28
#>    360	    70	       8	    10	   26
#>    360	    65	       9	    10	   27
```

## 4. Cópia do conjunto de dados do cliente

Cada possível cliente receberá uma versão pessoal do conjunto de dados com base em suas preferências.
Para isso, o cliente pode especificar: a altura mínima, a altura máxima e o peso máximo de uma única árvore.

Defina a função `customer_copy(data, min_height, max_height, max_weight)`.
Retorne uma cópia do dataframe para o cliente, com as colunas `Height`, `Weight`, `Diameter` e `Girth`, contendo as linhas que estão dentro dos limites.

```R
tree_data |> 
    girth_n_weight(1) |> 
    orchard_copy() |>
    customer_copy(65, 75, 1500) |> 
    head(3)
#>        A tibble: 3 × 4 
#> Height	Weight	Diameter	Girth
#>  <dbl>	 <dbl>	   <dbl>	<dbl>
#>     70	 360.5	     8.3	 26.1
#>     65	 360.5	     8.6	 27.0
#>     66	 546.0	    11.0	 34.6
```
