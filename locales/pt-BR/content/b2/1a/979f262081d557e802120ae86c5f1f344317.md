# Instruções


Você é o maître de um restaurante de hotel.
Sua tarefa é organizar os lugares do salão de acordo com o número de assentos disponíveis hoje, o número de reservas e os convidados que chegaram sem reserva e estão esperando por um lugar.
Para os fins deste exercício, os lugares são atribuídos ao primeiro assento vazio disponível.


Para este exercício, você tem 6 desafios diferentes de organização do salão para completar.


## 1. Monte o mapa de assentos de hoje

Defina a função `new_seating_chart(<size=22>)`, que recebe um argumento `size` representando o número de assentos que serão montados no salão hoje.
Se nenhum `size` for informado, a função deve retornar um mapa de assentos com 22 lugares.
Os valores dos assentos devem ter `None` como placeholder para indicar que estão disponíveis para atribuir a um convidado.


## 2. Organize as reservas

Defina a função `arrange_reservations(<guest_names>)` com 1 parâmetro, uma lista de nomes de convidados.
Isso representa o número de pessoas que têm lugares reservados no salão hoje.


Essa função deve retornar um mapa de assentos `dict` com o tamanho padrão (22 lugares), com os convidados atribuídos aos assentos na ordem em que aparecem na lista de reservas.
Todos os assentos não atribuídos devem ser definidos como `None`.
Se não houver convidados, deve ser retornado um mapa de assentos "vazio", com todos os placeholders `None`.


```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```


## 3. Encontre todos os assentos "vazios"

Defina a função `find_all_available_seats(<seats>)`, que recebe 1 parâmetro (_um dicionário com o mapa de assentos_) e retorna uma `list` de números de assentos disponíveis para os convidados que estão esperando no momento.
Se um assento estiver vazio, ele terá o valor `None` no dicionário. Os assentos ocupados terão o nome do convidado.


```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. Capacidade atual de assentos vazios

Defina a função `current_empty_seat_capacity(<seats>)`, que recebe 1 parâmetro: o `dict` das reservas de assentos existentes.
A função deve retornar o número total de assentos vazios.

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```


## 5. Devemos esperar?

Defina a função `accommodate_waiting_guests(<seats>, <guests>)`, que recebe dois parâmetros.
O primeiro parâmetro será um `dict` do mapa de assentos.
O segundo parâmetro será uma `list` de convidados que chegaram sem reserva de última hora.
Primeiro, você precisa descobrir quantos assentos estão disponíveis e se dá para acomodar os convidados inesperados neste momento.

Se não houver assentos suficientes, retorne o `dict` do mapa de assentos sem alterações.

Se _houver_ assentos disponíveis, atribua lugares aos convidados no mapa de assentos e retorne o mapa atualizado.
**Dica:** você pode usar as funções definidas anteriormente para fazer os cálculos para você.


```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. Assentos vazios

Defina a função `empty_seats(<seats>, <seat_numbers>)`, que recebe dois parâmetros.
O primeiro parâmetro será um dicionário de mapa de assentos.
O segundo parâmetro é uma lista de números de assentos que você precisa "liberar" ou esvaziar, ou seja, você precisa atribuir o valor `None` a esses números de assento.

Retorne o `dict` de assentos depois de atualizar os valores dos assentos "a esvaziar".

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
