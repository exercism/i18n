# Instruções

Neste exercício, você vai analisar números de telefone.

Você deve implementar 2 funcionalidades.

Os números de telefone passados para as rotinas têm a garantia de estar no formato
NNN-NNN-NNNN, por exemplo 212-515-9876, e não são nulos.

## 1. Analise um número de telefone

Sua análise deve retornar 3 dados:

1. Uma indicação de se o número tem um código de discagem de Nova York, ou seja, 212 como os 3 primeiros dígitos
2. Uma indicação de se o número é falso, tendo 555 como código de prefixo nas posições 5 a 7 (contando a partir de 1)
3. Os últimos 4 dígitos do número.

Implemente o método (estático) `PhoneNumber.Analyze()` para produzir as informações do número de telefone.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. Detecte se um número de telefone tem um código de prefixo falso (555)

Implemente o método (estático) `PhoneNumber.IsFake()` para detectar se o número de telefone é falso usando as informações do número de telefone produzidas na tarefa 1.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
