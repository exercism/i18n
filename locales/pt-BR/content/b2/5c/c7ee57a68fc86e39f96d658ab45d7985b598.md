# Testes

Todos os exercícios usam o framework [Pester][pester] para criar mocks e fazer testes.
Todos os testes ficam em um arquivo chamado `[Exercise].tests.ps1`, como é o padrão do framework Pester.
Se você estiver no diretório correto (ou seja, aquele que contém `[Exercise].ps1` e `[Exercise].tests.ps1`).
Você pode rodar os testes pelo PowerShell chamando:

``` PowerShell
Invoke-Pester
```

Isso vai rodar todos os arquivos `.tests.ps1` que encontrar no diretório.

Se você estiver usando outro shell que não o PowerShell, pode rodar os testes chamando:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Rodando os testes no Visual Studio Code

Você precisa garantir que tem [a extensão do PowerShell][extension] instalada no Visual Studio Code.

Você pode rodar os testes no Visual Studio Code de algumas formas:

- Rodando o script `.Tests.ps1` pelo menu Debug. Os atalhos de teclado são: `F5` ou `Shift + F5`
- De dentro do editor, clicando no link "Run Tests" acima da palavra-chave `Describe` no próprio código do teste
- Configurando uma Task para rodar o framework Pester

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
