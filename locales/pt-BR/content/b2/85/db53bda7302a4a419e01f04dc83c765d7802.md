# Instruções

Neste exercício, vamos simular o primeiro turno de uma partida de [Blackjack][blackjack].

## 1. Calcule o valor de uma carta qualquer.

Você vai receber duas cartas e vai poder ver a carta virada para cima do dealer.
Todas as cartas são representadas por uma string como "ace", "king", "three", "two" etc. Os valores de cada carta são:

| carta | valor |  carta  | valor |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _other_ |   0   |

~~~~exercism/note
Normalmente, os ases podem valer 1 ou 11, mas, por simplicidade, vamos assumir que só podem valer 11.
~~~~

Implemente o método `Blackjack.parse_card`, que recebe como argumento uma carta na forma de string.
O método deve retornar o valor da carta como um número inteiro.

```ruby
Blackjack.parse_card("ace")
# => 11
```

## 2. Dê nomes a faixas de valores.

A pontuação do jogador precisa ser categorizada em faixas de valores.
A pontuação do jogador é calculada somando os valores das duas cartas do jogador.
As faixas usadas são:

|   faixa   |  valor   |
| :-------: | :------: |
|    low    | [4, 11]  |
|    mid    | [12, 16] |
|   high    | [17, 20] |
| blackjack |   [21]   |

Implemente o método `Blackjack.card_range`, que recebe como argumentos duas cartas na forma de strings.
O método deve retornar o nome da faixa de valores em que as duas cartas se encaixam.

```ruby
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. Implemente a lógica de decisão para o primeiro turno.

Dependendo das suas duas cartas e da carta do dealer, existe uma estratégia para o primeiro turno do jogo, na qual você tem as seguintes opções:

- Parar (S)
- Pedir carta (H)
- Dividir (P)
- Vitória automática (W)

Apesar de ainda não ser ideal, você vai seguir a estratégia que seu amigo Alex vem desenvolvendo, que é assim:

- Se você tiver um par de ases, deve sempre dividi-los.
- Se você tiver um Blackjack (duas cartas que somam 21), e o dealer não tiver um ás, uma figura ou um dez, você ganha automaticamente.
  Se o dealer tiver alguma dessas cartas, você vai ter que parar e esperar que a outra carta seja revelada.
- Se suas cartas somarem um valor dentro da faixa [17, 20], você deve sempre parar.
- Se suas cartas somarem um valor dentro da faixa [12, 16], você deve sempre parar, a menos que o dealer tenha um 7 ou mais, caso em que você deve sempre pedir carta.
- Se suas cartas somarem 11 ou menos, você deve sempre pedir carta.

Implemente o método `Blackjack.first_turn`, que recebe como argumentos três cartas na forma de strings.
O método deve retornar, como string, a decisão que você deve tomar.

```ruby
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
