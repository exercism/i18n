# Sobre

Em Swift, você não pode acessar uma string usando um número inteiro (como `string[3]`).
Como as strings do Swift são compostas de caracteres Unicode de tamanho variável, encontrar um caractere exige percorrer os caracteres anteriores.

Para acessar um caractere em uma posição específica, você precisa calcular um índice do tipo `String.Index`.
Esses índices são chamados de *índices opacos* porque sua estrutura interna é gerenciada pelo Swift em vez de ser manipulada diretamente como números inteiros brutos:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
