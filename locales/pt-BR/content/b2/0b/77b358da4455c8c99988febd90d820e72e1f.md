# Sobre

Em Java, o [`null` literal][null-keyword] é usado para indicar a ausência de um valor.

Os [tipos de dados primitivos][primitive-data-types] em Java têm todos um valor padrão e, por isso, nunca podem ser `null`.
Por convenção, começam com uma letra minúscula, por exemplo `int`.

Os [tipos de referência][reference-data-types] contêm o endereço de memória de um objeto e podem ter o valor `null`.
Em geral, começam com uma letra maiúscula, por exemplo `String`.

Tentar atribuir o valor `null` a uma variável primitiva resulta em um erro de compilação, já que a variável sempre guarda um valor padrão do tipo atribuído.

```java
// Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Atribuir o valor `null` a uma variável de referência não resulta em erro de compilação, porque variáveis de referência podem ser nulas.

```java
//No error will occur as the String variable str is nullable
String str = null;
```

Acessar uma variável de referência que tem o valor `null` compila sem problemas, mas faz com que uma `NullPointerException` seja lançada em tempo de execução.

```java
int[] arr = null;

// Throws NullPointerException at runtime
arr.length;
```

Uma [`NullPointerException` é lançada][null-pointer-exception] ao tentar acessar uma variável de referência que é nula, mas que exige um objeto.

Para trabalhar com segurança com valores que podem ser nulos, verifique se eles são `null` antes de usá-los, o que pode ser feito com os [operadores de igualdade][equality-operators], como `==` ou `!=`:

```java
int[] arr = null;

if(arr != null) {
    System.out.println(arr.length);
} else {
    //Perform an alternate action when arr is null
}
```
