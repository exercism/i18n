# Apêndice das instruções

Cada linha da grade é representada como uma palavra.

Por exemplo,

```
    0 1 0
    1 0 0
    1 1 0
```

é representada como

```
0x2
0x4
0x6
```

A grade tem no máximo 32 colunas.

## Registradores

| Registrador | Uso          | Tipo    | Descrição                   |
| ----------- | ------------ | ------- | --------------------------- |
| `$a0`       | entrada      | inteiro | número de linhas            |
| `$a1`       | entrada      | inteiro | número de colunas           |
| `$a2`       | entrada      | endereço | grade da geração atual     |
| `$a3`       | entrada/saída | endereço | grade da próxima geração  |
| `$t0-9`     | temporário   | qualquer | usado para armazenamento temporário |
