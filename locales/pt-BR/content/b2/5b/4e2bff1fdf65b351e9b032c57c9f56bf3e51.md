# Dicas

## 1. Crie um novo visitante

- Reveja o [conceito "Objetos"][concept-objects] para descobrir como criar um objeto com determinadas chaves e valores.

## 2. Revogue o ingresso

- Use o operador de atribuição `=` para definir a propriedade `ticketId` do objeto visitante como `null`.
- Depois, retorne o objeto visitante.

## 3. Determine o status do ingresso

- Reveja o [conceito "Condicionais"][concept-conditionals] para descobrir como retornar valores diferentes da função de forma condicional.
- Use a notação de colchetes para acessar o valor do `ticketId` informado no objeto.
- Use o operador de igualdade estrita `===` para verificar se o valor é `null` ou `undefined`.

## 4. Melhore a resposta do status do ingresso

- Recupere o valor de um determinado `ticketId` com a notação de colchetes, como na tarefa anterior.
- Não é preciso usar uma condicional para resolver esta tarefa.
- Em vez disso, use o [operador de coalescência nula][mdn-nullish-coalescing] `??`.

## 5. Determine a versão dos termos e condições

- Reveja o [conceito "Objetos"][concept-objects] para saber como acessar valores aninhados e comece escrevendo a expressão para obter a versão.
- Depois, use o operador de [encadeamento opcional][mdn-optional-chaining] para tratar o caso do objeto gtc ausente.
- Não é preciso usar uma condicional para resolver esta tarefa.
