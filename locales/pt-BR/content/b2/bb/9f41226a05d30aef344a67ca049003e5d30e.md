# Ajuda

Se você estiver com dificuldades, pode usar um destes recursos para conseguir ajuda:

- [/r/javascript](https://www.reddit.com/r/javascript) é o subreddit de JavaScript.
- O [StackOverflow](https://stackoverflow.com/questions/tagged/javascript+exercism) pode ser usado para pesquisar o seu problema e ver se ele já foi respondido. Você também pode fazer e responder perguntas.
- O [Github issue tracker](https://github.com/exercism/javascript/issues) é onde acompanhamos o desenvolvimento e a manutenção dos exercícios de JavaScript no Exercism. Mas, se nenhum dos links acima ajudar, fique à vontade para abrir uma issue aqui.
