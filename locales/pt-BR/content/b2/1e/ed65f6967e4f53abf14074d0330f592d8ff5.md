# Dicas

## Geral

- Embora você esteja recebendo uma `reference` para um `ElectionResult`, você pode acessar os membros dele com a notação de ponto `.`, como se não fosse uma `reference`!
- Você pode obter uma `reference` para uma variável usando o operador `&`, por exemplo `int&`.
- Se você não tem certeza de como as `references` funcionam, experimente ler [Learn C++: References][learncpp-references].
