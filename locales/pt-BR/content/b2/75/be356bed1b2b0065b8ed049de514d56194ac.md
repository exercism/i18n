# Anexo das instruções

## Formato de saída

Produza as plantas do estudante como uma string terminada em nulo, usando uma vírgula e um espaço como separadores.

## Registradores

| Registrador | Uso          | Tipo    | Descrição                             |
| ----------- | ------------ | ------- | ------------------------------------- |
| `$a0`       | entrada      | endereço | diagrama do jardim                   |
| `$a1`       | entrada      | endereço | nome do estudante                    |
| `$a2`       | entrada/saída | endereço | string de saída terminada em nulo    |
| `$t0-9`     | temporário   | qualquer | usados para armazenamento temporário |
