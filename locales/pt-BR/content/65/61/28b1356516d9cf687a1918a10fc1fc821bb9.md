# converter campo para const

Considere converter o campo `%{name}` para `const`, já que a intenção é que o valor nunca mude. Usar constantes não é apenas mais comum: também existem algumas diferenças sutis entre um `const` e um `field`, explicadas [neste post do StackOverflow](https://stackoverflow.com/questions/755685/static-readonly-vs-const#755693).
