# Sobre

Pode ser difícil encontrar uma linguagem de programação mais expressiva. [Raku](https://raku.org/) é uma linguagem moderna e multiparadigma. Raku oferece metodologias [procedurais](https://docs.raku.org/language/functions), [orientadas a objetos](https://docs.raku.org/language/objects) e de [programação funcional](https://docs.raku.org/language/functions#Functions_are_first-class_objects).

[Curioso?](https://raku.org/) Aprofunde-se na [documentação](https://docs.raku.org/) ou no [repositório](https://raku.land/) de módulos (como o pypi ou o CPAN).

É uma linguagem extremamente [flexível](https://docs.raku.org/language/operators), que se [adapta](https://docs.raku.org/language/glossary#gradual_typing) ao seu estilo de programação, seja ele [programas de uma linha](https://docs.raku.org/language/create-cli) rápidos para administradores de sistemas, scripts para gerenciar a importação de um banco de dados, ou a pilha completa de módulos necessária para construir um [site inteiro](https://cro.services/).

Raku aprende com outras linguagens:

* Ele amplia o apelo duradouro do Perl com um sistema de objetos adequado, incluindo [roles](https://docs.raku.org/language/typesystem#role), [threading](https://docs.raku.org/language/concurrency) e despacho [multimétodo](https://docs.raku.org/language/glossary#Multi-dispatch).
* Ele traz o threading do Java, [simplificado](https://docs.raku.org/language/concurrency) para um punhado de métodos.
* Usar interfaces de [funções estrangeiras](https://docs.raku.org/language/nativecall) do Lisp torna o acesso a bibliotecas tão simples quanto uma linha de código.
* As [expressões regulares](https://docs.raku.org/language/regexes) agora chegaram ao 11, com a introdução das [gramáticas](https://docs.raku.org/language/grammars) de Expressão de Parser, que permitem encarar tarefas enormes de análise.
* Strictures e avisos agora são automáticos, eliminando uma enorme quantidade de erros em potencial.
* ... e ele sabe fazer [matemática](https://docs.raku.org/language/math): ```1/10 * 3 == 0.3 ```. Tente isso na sua linguagem favorita!

Os lemas do Raku:
* "Raku foi projetada para tornar as tarefas fáceis fáceis, sem tornar as tarefas difíceis impossíveis."
* "Há mais de uma maneira de fazer isso, agora com ainda mais -Ofun (otimizado para diversão) acrescentado."
