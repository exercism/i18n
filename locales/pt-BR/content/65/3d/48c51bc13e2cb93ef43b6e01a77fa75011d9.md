# Aprendizado

Quer começar com Groovy, ou aprender mais enquanto faz os exercícios?

Experimente o Groovy com

* [um navegador usando um interpretador online](https://www.jdoodle.com/execute-groovy-online)
* [o Groovy Console](http://groovy-lang.org/groovyconsole.html) digitando `groovyConsole` na linha de comando
* [o Groovy Shell](http://groovy-lang.org/groovyconsole.html) digitando `groovysh` na linha de comando

Faça um tour rápido pelo Groovy com

* o [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) do Tim Rows, que é igualmente bom para quem não desenvolve em Java
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* o [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html) da SmartThings
* alguns [Groovy Koans](http://www.groovy-koans.org/) online da JDriven

Aprofunde-se com

* a [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), _o livro_ sobre Groovy
* o [Making Java Groovy](https://www.manning.com/books/making-java-groovy) do Ken Kousen
