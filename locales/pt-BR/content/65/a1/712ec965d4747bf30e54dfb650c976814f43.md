# Classes e propriedades somente leitura

As classes e propriedades somente leitura permitem que as classes especifiquem propriedades públicas de fácil acesso, mas impedem a modificação.
Para declarar uma propriedade como somente leitura, é preciso adicionar `readonly` antes da especificação de tipo.
A propriedade pode ser atribuída uma vez, mas qualquer tentativa de reatribuir ou modificar o valor resulta em um Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

As classes somente leitura ampliam esse comportamento: se declaradas como `readonly`, aplicam a declaração de somente leitura a cada propriedade.
Além disso, impedem a adição de propriedades dinâmicas.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
