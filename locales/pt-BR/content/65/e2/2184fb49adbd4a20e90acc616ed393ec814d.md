# Dicas

## Geral

- Use vários [operadores aritméticos][arithmeticoperators] para realizar operações matemáticas.
- Consulte a documentação de [`Int`][int] e [`Double`][double] para aprender sobre as funções e os operadores que funcionam com `Int`s e `Double`s.

## 1. Calcule o valor diário a partir de um valor por hora

- Você vai precisar converter explicitamente entre `Int` e `Double`.

## 2. Calcule o valor mensal, a partir de um valor por hora e um desconto

- Existe um [método disponível][rounded] para arredondar `Double`s.

## 3. Calcule o número de dias úteis a partir de um orçamento, um valor por hora e um desconto

- Existe um [método disponível][rounded] para arredondar `Double`s no qual você pode informar a regra de arredondamento a usar.
