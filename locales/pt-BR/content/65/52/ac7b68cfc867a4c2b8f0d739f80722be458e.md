# Ajuda

Para conseguir ajuda se estiver com dificuldades, você pode usar um destes recursos:

- [The Definition of Standard ML](https://github.com/SMLFamily/The-Definition-of-Standard-ML-Revised)
- [/r/sml](https://www.reddit.com/r/sml) é o subreddit do Standard ML.
- Você pode usar o [StackOverflow](http://stackoverflow.com/questions/tagged/sml) para pesquisar seu problema e ver se ele já foi respondido. Também pode fazer e responder perguntas.
