# Anexo de instruções

## Palavras

Defina uma tupla `triangle` com os campos `a`, `b` e `c`.

- `<triangle> ( a b c -- triangle )`: constrói um triângulo a partir de
  três comprimentos de lado.
- `equilateral? ( triangle -- ? )`
- `isosceles? ( triangle -- ? )`
- `scalene? ( triangle -- ? )`

Cada predicado retorna `f` para triângulos que violam a desigualdade triangular ou têm um lado não positivo.
