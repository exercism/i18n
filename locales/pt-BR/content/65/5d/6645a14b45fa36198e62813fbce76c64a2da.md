# About

Um [método][methods] é uma função com um argumento especial, o _receptor_.
O receptor aparece na própria lista de argumentos, entre a palavra-chave `func` e o nome do método.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

Você só pode definir um método com um receptor cujo tipo esteja definido no mesmo pacote do método.

```go
type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!

```

Existem dois tipos de receptor: receptores de valor e receptores de ponteiro.

Métodos com receptor de valor operam sobre uma cópia do valor que recebem. Isso significa que qualquer modificação feita ao receptor dentro do método não é visível para quem o chamou.

Você pode declarar métodos com receptores de ponteiro para modificar o valor para o qual o receptor aponta.
Essas modificações também são visíveis para quem chama o método.

```go
type rect struct {
	width, height int
}

func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```

Lembre-se: um método é apenas uma função com um argumento receptor.
