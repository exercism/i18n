# Sobre

Uma definição de tipo cria um novo tipo nomeado, distinto de todos os outros tipos, mesmo daqueles com o mesmo tipo subjacente.

## Definindo tipos

Uma definição de tipo começa com a palavra-chave `type`, seguida do nome do novo tipo e do seu tipo subjacente:

```go
type File []bool
```

Aqui, `File` se refere a uma única coluna vertical de um tabuleiro de xadrez, normalmente identificada de A a H.
Cada casa dessa coluna é representada por um valor Boolean que indica se ela está ocupada ou não.
Agora que `File` está definido, podemos usá-lo dentro de outras definições:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` mapeia identificadores de colunas para valores `File`.
Cada `File` é um slice de valores Boolean que representa as casas de uma coluna do tabuleiro.
Sem essas definições de tipo, `board` seria um `map[string][]bool`, o que tornaria mais difícil entender o que estamos representando.

## Tipos definidos são distintos

Embora `Score` e `int` guardem valores inteiros, converter de um para o outro exige uma conversão explícita:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` é uma constante sem tipo, então pode ser atribuída diretamente a uma variável `Score`.

Tipos definidos também podem ter métodos, que são abordados no conceito Métodos.

## Tipos struct

As definições de struct usam a mesma palavra-chave `type`:

```go
type Player struct {
    Name  string
    Score Score
}
```

Os tipos struct são abordados no conceito Structs.

## Aliases de tipo

Um alias de tipo cria outro nome para um tipo existente, em vez de criar um novo tipo.
Como um alias e o tipo original são idênticos, seus valores podem ser usados de forma intercambiável.
Aliases são declarados usando a palavra-chave `type`, o nome do alias, o sinal de igual (`=`) e o tipo existente.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
