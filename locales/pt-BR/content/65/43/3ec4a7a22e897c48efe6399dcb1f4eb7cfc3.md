# Instruções

Neste exercício, você vai usar um `HashMap`, junto com os métodos da API `entry`, para resolver um problema simples de algoritmo.

Dados `&[&str]` representando as palavras de um artigo de revista, e `&[&str]` representando as palavras de um bilhete que você gostaria de enviar, você consegue montar seu bilhete recortando palavras da revista e colando-as numa carta?

Observações:

- Isso implica recortar e colar de verdade; a revista precisa conter pelo menos tantas cópias de cada palavra quantas o bilhete exigir.
- O uso de maiúsculas e minúsculas importa; só porque você está montando um bilhete com palavras recortadas de uma revista, não significa que você aceite escrever com erros de gramática.

Você vai começar com a seguinte assinatura de função já esboçada:

```rust
pub fn can_construct_note(magazine: &[&str], note: &[&str]) -> bool {
    todo!()
}
```

Dada a seguinte entrada

```rust
let magazine = "two times three is not four".split_whitespace().collect::<Vec<&str>>();
let note = "two times two is four".split_whitespace().collect::<Vec<&str>>();
assert!(!can_construct_note(&magazine, &note));
```

A função retorna `false`, já que a revista contém apenas uma ocorrência de `"two"` quando o bilhete exige duas delas.

A seguinte entrada vai funcionar:

```rust
let magazine = "Astronomer Amy Mainzer spent hours chatting with Leonardo DiCaprio for Netflix's 'Don't Look Up'".split_whitespace().collect::<Vec<&str>>();
let note = "Amy Mainzer chatting with Leonardo DiCaprio"
    .split_whitespace()
    .collect::<Vec<&str>>();
assert!(can_construct_note(&magazine, &note));
```

A função retorna `true`, pois a revista contém todas as palavras que o bilhete exige.
