# Contribuindo pelo GitHub

As contribuições para a base de código do Exercism são feitas pelo [GitHub][github].

Como o próprio nome indica, o GitHub usa o [git][git] como sistema de controle de versão.
Se você não conhece o Git, o melhor recurso online é o [Pro Git][pro-git].

Caso você não conheça o GitHub e o fluxo de trabalho de contribuição, aqui estão alguns recursos que podem ajudar você a começar:

- [Introdução ao GitHub - Curso interativo][github-course]
- [Como criar um pull request no GitHub - Tutorial][pr-tutorial]
- [Como fazer um PR simples no GitHub - Vídeo de anthonywritescode][anthonywritescode]

## Guias

Você pode ler mais sobre como garantir que sua contribuição seja bem-vinda no guia [Como fazer um ótimo pull request][great-pr].

Também temos vários guias de pull request específicos do Exercism:

- [Como fazer um ótimo pull request][how-to-make-a-great-pr]
- [O guia dos contribuidores para pull requests][contributors-pr-guide]
- [O guia dos mantenedores para pull requests][maintainers-pr-guide]
- [Permissões de repositório dos mantenedores][maintainers-repo-permissions]
