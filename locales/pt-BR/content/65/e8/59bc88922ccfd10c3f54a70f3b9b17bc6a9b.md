# Introdução

As classes são a principal estrutura para fazer programação orientada a objetos em F#.

Uma classe em F# é composta por seus campos e métodos. Os campos e métodos de uma classe são conhecidos como seus _membros_.

As classes em F# são definidas com a palavra-chave `type`. Os métodos são definidos com a palavra-chave `member` e são sempre públicos. Para definir campos (privados), pode-se usar associações `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

As classes são modelos para criar objetos. Para criar uma instância de uma classe, chame o nome da classe como se fosse uma função. Uma instância de uma classe também é conhecida como um _objeto_.

É possível acessar os membros de um objeto usando a notação de ponto.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
