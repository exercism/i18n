# Introdução

Uma definição `:` pode chamar a si mesma diretamente. O compilador do Factor infere o efeito de pilha de palavras recursivas como faria com qualquer outra: nenhuma declaração especial é necessária para recursão simples.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

As duas metades são o *caso base* da recursão (aqui, a sequência vazia soma `0`) e o *passo recursivo* (retire um elemento, faça a recursão sobre o restante e combine os resultados).

`if-empty` e `unclip` são os companheiros canônicos da recursão em sequências. `if-empty ( seq emptyquot nonemptyquot -- )` roda um dos dois quotations, dependendo da sequência; `unclip` retira o primeiro elemento para que o passo recursivo tenha algo mais simples.
