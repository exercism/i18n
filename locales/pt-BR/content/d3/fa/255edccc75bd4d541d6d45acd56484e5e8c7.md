# Instalação

## Windows (Recomendado)

Você usa um sistema operacional Windows?

Pressione `Windows Key`, digite `cmd` e pressione `enter`.

> O Batch já vem instalado no seu sistema se o seu sistema operacional for Windows.

Se você usa outro sistema operacional, pode instalar o Batch seguindo as instruções abaixo.

## Mac OS

1. O Gatekeeper não pode estar configurado para bloquear pacotes sem assinatura.
2. Abra o aplicativo Terminal.
3. Rode o seguinte comando para instalar o Batch:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. Se o seu sistema for 64 bits, habilite a arquitetura de 32 bits (caso ainda não tenha feito isso):

```bash
sudo dpkg --add-architecture i386
```

2. Adicione o repositório do WineHQ:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. Instale o WineHQ:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. Habilite o repositório do Wine:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. Instale o WineHQ:

```bash
dnf install winehq-stable
```
