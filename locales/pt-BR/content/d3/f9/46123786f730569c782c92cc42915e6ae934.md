# Instruções

Enquanto se prepara para assar cookies para os seus amigos, você percebeu que precisa converter algumas das medidas usadas na receita. Como você só conhece o sistema métrico, precisa dar um jeito de converter medidas comuns de confeitaria dos EUA para mililitros (mL), para facilitar a sua vida.

Use esta tabela de conversão na sua solução:

| Unidade a converter | volume | em mililitros (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| xícara americana | 1      | 240                 |
| onça líquida americana | 1      | 30                  |
| colher de chá americana | 1      | 5                   |
| colher de sopa americana | 1      | 15                  |

Como você tem talento para programação e está em treinamento, decide usar mililitros como unidade de transição para facilitar a conversão de qualquer unidade da lista para qualquer outra (até para ela mesma).

## 1. Obtenha o componente numérico de um par de volume

Implemente a função `KitchenCalculator.get_volume/1`. Dada uma tupla de par de volume, ela deve retornar apenas o componente numérico.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Converta o par de volume para mililitros

Implemente a função `KitchenCalculator.to_milliliter/1`. Dada uma tupla de par de volume, ela deve converter o volume para mililitros usando a tabela de conversão.

Use várias cláusulas de função e pattern matching para criar as funções de cada unidade. Os átomos usados para denotar cada unidade são: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. Retorne o resultado da conversão em uma tupla.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Converta o par de volume em mililitros para outra unidade

Implemente a função `KitchenCalculator.from_milliliter/2`. Dada uma tupla de par de volume e a unidade desejada, ela deve converter o volume para a unidade desejada usando a tabela de conversão.

Use várias cláusulas de função e pattern matching para criar as funções de cada unidade. Os átomos usados para denotar cada unidade são: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Converta de qualquer unidade para qualquer unidade

Implemente a função `KitchenCalculator.convert/2`. Dada uma tupla de par de volume e a unidade desejada, ela deve converter o volume dado para a unidade desejada.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
