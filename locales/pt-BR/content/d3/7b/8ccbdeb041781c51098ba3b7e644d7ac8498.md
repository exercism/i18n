# Dicas

## 1. Acompanhando as rodadas de pôquer

- A função [`list`][list] retorna uma lista formada pelos argumentos que recebe.

## 2. Mantendo todas as rodadas no mesmo lugar

- A função [`concat`][concat] pode ser usada para concatenar duas listas.

## 3. Encontrando rodadas anteriores

- A função [`some`][some] retorna o primeiro valor logicamente verdadeiro de uma coleção.
- A função [`boolean`][boolean] é útil quando uma função retorna um valor, mas os testes esperam um Boolean.

## 4. Calculando a média dos valores das cartas

- Lembre-se dos operadores aritméticos básicos, como [`/`][division] e [`+`][addition].
- Uma coleção de números pode ser somada com [`apply`][apply] ou [`reduce`][reduce].
- A função [`count`][count] retorna o número de itens de uma coleção.
- A função [`/`][division] retorna um tipo ratio quando opera com inteiros. Você pode usar [`double`][double] para converter um ratio em um decimal.

## 5. Médias alternativas

- Existem funções de sequência para retornar o [`first`][first] ou o [`last`][last] elemento de uma coleção sequencial.
- Para encontrar a carta do meio, você pode dividir o número de cartas por 2, arredondar para o menor inteiro com [`int`][int] e pegar a carta nesse índice com [`nth`][nth].
- Use [`or`][or] para determinar se qualquer uma das condições for verdadeira.

## 6. Mais técnicas de média

- Uma forma de pegar as cartas em índices pares/ímpares seria usar [`map`][map] com uma função que usa [`nth`][nth] sobre um [`range`][range], que aceita um argumento `step` opcional.

## 7. Regras da rodada bônus

- Lembre-se de como usar [`if`][if] no exercício sobre condicionais.
- Você pode retornar todos os itens de uma coleção, exceto o último, usando [`butlast`][butlast].
