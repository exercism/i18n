# Sobre

ColdFusion (CFML) é uma linguagem de script da JVM cuja sintaxe é semelhante a C ou JavaScript. 
Ela compila JIT para bytecode que roda na JVM, mas é dinâmica e fracamente tipada, o que torna o desenvolvimento rápido e fácil. 
CF é uma linguagem multiparadigma, com suporte a orientação a objetos clássica e programação funcional.

CFML também tem uma linguagem de template baseada em tags, integrada, que o torna ideal para aplicações web. 
Roda em um contêiner J2EE com muitas bibliotecas inclusas que deixam o desenvolvimento muito produtivo, sem a necessidade de instalar muitos pacotes. 
CFML tem suporte nativo a arquivos zip, geração de PDF e Excel, e-mails, FTP, HTTP, sistemas de arquivos S3, bibliotecas de segurança ESAPI, drivers JDBC, JSON e APIs REST.  

CFML também pode aproveitar qualquer projeto Java colocando os jars no projeto e instanciando objetos Java diretamente no seu código. 
Você pode aprender mais sobre sintaxe básica e tipos de dados de primeira classe neste guia: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
