# Introdução

Pyret tem duas primitivas Boolean distintas, `true` e `false`.
Esses dois valores representam se uma afirmação ou condição é válida ou não.

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret fornece os operadores `and` e `or`, que podem combinar valores Boolean.

O operador and retorna true se ambos os lados forem true e false para todas as outras combinações.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

O operador or retorna true se pelo menos um dos lados for true e false se ambos os lados forem false.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` é uma função embutida que inverte true para false ou false para true.

```pyret
not(true) # false
not(false) # true
```
