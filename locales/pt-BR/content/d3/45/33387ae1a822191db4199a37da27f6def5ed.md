# Instruções

Implemente operações básicas de listas.

Em linguagens funcionais, operações de lista como `length`, `map` e `reduce` são muito comuns.
Implemente uma série de operações básicas de listas, sem usar funções existentes.

A quantidade e os nomes exatos das operações a implementar dependem da trilha, para evitar conflitos com nomes já existentes, mas as operações gerais que você vai implementar incluem:

- `append` (*dadas duas listas, adicione todos os itens da segunda lista ao final da primeira lista*);
- `concatenate` (*dada uma série de listas, combine todos os itens de todas as listas em uma única lista achatada*);
- `filter` (*dados um predicado e uma lista, retorne a lista de todos os itens para os quais `predicate(item)` é verdadeiro*);
- `length` (*dada uma lista, retorne o número total de itens dentro dela*);
- `map` (*dadas uma função e uma lista, retorne a lista dos resultados de aplicar `function(item)` a todos os itens*);
- `foldl` (*dadas uma função, uma lista e um acumulador inicial, acumule (reduza) cada item no acumulador da esquerda para a direita usando `function(accumulator, item)`*);
- `foldr` (*dadas uma função, uma lista e um acumulador inicial, acumule (reduza) cada item no acumulador da direita para a esquerda usando `function(item, accumulator)`*);
- `reverse` (*dada uma lista, retorne uma lista com todos os itens originais, mas em ordem invertida*);
