# use interpolação de string, não concatenação de string

Use [interpolação de string](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/) para montar uma string dinamicamente, em vez de usar concatenação de string. O principal benefício é menos "ruído": enquanto a concatenação de string exige `+` entre cada string, a interpolação de string não tem essa limitação. Por isso, o código com interpolação de string costuma ser um pouco mais fácil de ler.
