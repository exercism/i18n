# Introdução

Você trabalha em uma empresa que vende fontes pelo site dela.
A empresa gostaria de mostrar uma frase diferente cada vez que alguém visualiza uma fonte no site.
Para dar uma noção abrangente da fonte, as frases aleatórias devem usar **todas** as letras do alfabeto inglês.

Ela está promovendo uma competição para receber sugestões de frases que possa usar.
Você é responsável por verificar as submissões para ver se elas são válidas.

```exercism/note
Pangram vem do grego, παν γράμμα, pan gramma, que significa "todas as letras".

O pangrama inglês mais conhecido é:

> The quick brown fox jumps over the lazy dog.
```
