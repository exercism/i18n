# Apêndice das instruções

## Instruções específicas da trilha

Certifique-se de que sua solução seja geral o suficiente para ser facilmente escalável para nomes mais longos, com mais letras e dígitos.
Isso geralmente também resulta em uma qualidade de código melhor.

Sugestão (isso não é testado explicitamente):
Para garantir que você sempre tenha um nome único, você pode implementar seu próprio cache ou usar um `Stream` com o cache integrado.
