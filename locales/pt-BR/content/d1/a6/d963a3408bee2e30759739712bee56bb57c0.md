# Executando os testes

Com o `sbt` instalado, os testes podem ser executados pela linha de comando com:

```bash
$ sbt test
```

Repare que executar `sbt test` toda vez será lento, pois o `sbt` é reinicializado a cada chamada.

O `sbt` funciona como um shell: depois de iniciado, você pode rodar comandos dentro dele. 

Por exemplo, você pode usar o `sbt` para rodar seus testes de novo sempre que os arquivos-fonte mudarem:
```bash
$ sbt
>~ test
```

Repare que todos os testes foram desativados, exceto o primeiro, para você trabalhar nele. 
Para continuar, basta remover a palavra-chave `pending` do início de cada caso de teste.

Acesse [este link](https://www.scala-sbt.org/) para saber mais sobre o `sbt`.


Os testes também podem ser executados nestas IDEs:

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA com o plugin Scala](https://www.jetbrains.com/idea/)
