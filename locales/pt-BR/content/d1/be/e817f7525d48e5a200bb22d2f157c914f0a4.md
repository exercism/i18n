# Introdução

Ao trabalhar com objetos `java.time` como o `LocalDate`, muitas vezes você precisa fazer ajustes de data mais complexos, como encontrar a "segunda terça-feira do mês".
Em vez de calcular isso manualmente, você pode usar os **`TemporalAdjusters`**.

A classe utilitária `java.time.temporal.TemporalAdjusters` (repare no "s" do plural) fornece métodos estáticos para muitos ajustes de data comuns.
Você aplica esses ajustes com o método `.with()` em um objeto temporal (como o `LocalDate`).

```exercism/note
Usar `with(TemporalAdjuster)` retorna uma instância _nova_ e não atualiza a instância existente, porque os objetos `java.time` são imutáveis.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Aqui estão alguns ajustadores importantes que ajudam nos cálculos de agendamento:

## Encontrar o enésimo dia da semana

Use `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` para encontrar a enésima ocorrência de um dia da semana.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

## Encontrar o primeiro/último dia da semana no mês

Use `firstInMonth(DayOfWeek dayOfWeek)` ou `lastInMonth(DayOfWeek dayOfWeek)`.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

## Ajustes relativos (próximo/anterior)

Ajustadores como `next()`, `previous()`, `nextOrSame()` e `previousOrSame()` encontram a próxima ocorrência ou a ocorrência anterior de um dia da semana, em relação à data atual.

- `next()`/`previous()`: excluem a data atual se ela corresponder.
- `nextOrSame()`/`previousOrSame()`: incluem a data atual se ela corresponder.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Ajustadores personalizados

`TemporalAdjuster` é uma interface funcional, então você pode escrever um ajustador seu como uma lambda que recebe o temporal a ser ajustado e retorna o temporal já ajustado.
Ele é aplicado com `.with()` assim como os ajustadores predefinidos, e pode usá-los internamente.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

Usar esses ajustadores da classe `TemporalAdjusters` pode simplificar bastante as tarefas de manipulação de datas.
