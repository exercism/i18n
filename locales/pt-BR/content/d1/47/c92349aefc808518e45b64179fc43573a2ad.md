# Aprendizado

## Aprendendo D

Em geral, o Exercism parte do princípio de que você já conhece a sintaxe e os mecanismos de uma linguagem em uma trilha específica. No entanto, conhecer a sintaxe de uma linguagem é apenas o primeiro passo para se tornar especialista nela. O Exercism permite que você pratique a resolução de problemas e troque ideias com outros programadores que resolveram o mesmo problema. É a partir dessas discussões compartilhadas que ganhamos experiência e compreensão para nos tornarmos programadores melhores.

Aqui estão alguns recursos para você começar:

* [Aprender D como iniciante](http://ddili.org/ders/d.en/index.html), o excelente livro de Ali Cehreli
* [Aprender D para programadores experientes](http://wiki.dlang.org/Coming_From), para quem vem de outras linguagens
* [Tutoriais de D](https://wiki.dlang.org/Tutorials)
* [Visão geral dos recursos exclusivos de D](http://dlang.org/overview.html)
* [Perguntas frequentes sobre D](http://dlang.org/faq.html)
* Apresentações e vídeos do [DConf](http://dconf.org/2016/index.html) no YouTube

Para obter mais ajuda:

* Tire suas dúvidas no canal IRC [#d](irc://irc.freenode.net/d) no freenode ([interface web](https://kiwiirc.com/client/irc.freenode.net/d))
* Peça ajuda no [D.learn](http://forum.dlang.org/group/learn)
* Abra uma issue no [rastreador de bugs do D](https://issues.dlang.org/)

## Desenvolvimento orientado a testes

O Exercism parte do princípio de que você já conhece o conceito de desenvolvimento orientado a testes. Cada exercício vem com uma série de testes já escritos para você. Você avança pelo exercício um teste de cada vez, escrevendo a implementação aos poucos até satisfazer os testes.
