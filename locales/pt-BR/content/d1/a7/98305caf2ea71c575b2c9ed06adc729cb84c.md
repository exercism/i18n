# Introdução

As listas são nativas da linguagem Elixir. Elas são consideradas um tipo básico, representado por colchetes. As listas podem estar vazias ou conter qualquer número de itens de qualquer tipo. Por exemplo:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

O Elixir implementa as listas como uma lista encadeada, em que cada nó armazena dois valores: o primeiro item e outra lista com todos os itens restantes. O primeiro item da lista é chamado de _cabeça_ e a lista restante de itens é chamada de _cauda_. Podemos usar essa notação no código:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

Podemos usar a notação _`[head | tail]`_ para adicionar elementos ao início de uma lista:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Existem várias funções no módulo `Kernel` para trabalhar com listas, além do módulo `List` inteiro.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
