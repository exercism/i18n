# Dicas

## Geral

- Uma rotina que responde com texto é declarada `: STR`. Uma que responde
  com um número inteiro é declarada `: INT`.
- Dois argumentos do mesmo tipo podem compartilhar uma declaração:
  `full_title(piece, composer : STR) : STR`.

## 1. Nomeie a peça e quem a escreveu

- Três pedaços de texto unidos com `+`: a peça, depois `" by "`, depois o
  compositor.
- Os espaços estão dentro das aspas. O `+` não acrescenta nada por conta
  própria.

## 2. Meça uma linha

- `.size`, sem parênteses depois.

## 3. As primeiras letras

- `.head` recebe o número entre parênteses: `title.head(count)`.

## 4. As últimas letras

- `.tail` é o `.head` contando a partir da outra ponta.

## 5. Encurte um título longo

- Seis letras do começo, depois `"..."` unidos com `+`.
- O número de letras é sempre seis, então dá para escrevê-lo direto na
  chamada em vez de passá-lo como argumento.
