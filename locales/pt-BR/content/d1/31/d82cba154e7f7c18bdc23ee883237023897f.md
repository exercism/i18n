# Como contribuir com o Exercism

Esta seção da documentação mostra como contribuir com o Exercism.
Ela contém informações e especificações para as diversas áreas do Exercism, além de guias sobre coisas como se tornar um mantenedor e escolher uma história para um exercício.

Para ter uma ideia de onde você pode ajudar, dê uma olhada na nossa [lista de tarefas][tasks].

As contribuições para a base de código são feitas pelo [GitHub][github].

[tasks]: https://exercism.org/contributing/tasks
[github]: /docs/building/github
