# Sobre

O módulo `gleam/order` da biblioteca padrão do Gleam contém o tipo `Order`, usado para comparar valores.

A definição de `Order` é esta:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

O tipo tem três variantes, cada uma usada para representar a relação entre um valor e outro valor:

- `Gt`: o valor é _maior_ que o outro valor.
- `Eq`: o valor é _igual_ ao outro valor.
- `Lt`: o valor é _menor_ que o outro valor.

Se um tipo de dados pode ser comparado por tamanho, é comum que o módulo defina uma função `compare` que retorna um valor do tipo `Order`. Por exemplo, `gleam/float` e `gleam/int` definem funções `compare` que operam sobre números de ponto flutuante e inteiros, respectivamente.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Funções de ordenação como `list.sort` costumam receber uma função que retorna um valor do tipo `Order`, o que permite que quem faz a chamada defina como a lista deve ser ordenada.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
