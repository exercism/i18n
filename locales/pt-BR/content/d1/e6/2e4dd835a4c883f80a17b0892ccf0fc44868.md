# Case

[`case`][case] (muitas vezes chamado de switch em outras linguagens) é uma forma de expressão de controle, como o if-else.
O `case` permite encadear várias instruções if-else-if, pode ser mais legível e permite construções poderosas.

Um `case` é definido pela palavra-chave `case` seguida de uma expressão opcional.
Depois, para cada caso, usa-se a palavra-chave `when` seguida de uma expressão que é comparada à expressão do `case`.
A palavra-chave `when` não deve ser indentada em relação à palavra-chave `case`.
Depois da palavra-chave `when` vem o código que deve ser executado se a expressão do `case` corresponder à expressão do `when`.
O `case` permite uma cláusula `else` opcional, que é executada se nenhum outro caso corresponder.

A expressão do `case` é avaliada e depois comparada com cada expressão do `when`.
A comparação é feita com o [operador de subsunção do `case` (`===`)][case-subsumption].

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## Operador de subsunção do `case` (`===`)

O operador de subsunção do `case` (`===`) é um pouco diferente do operador de igualdade (`==`).
O operador verifica se o lado direito é um membro do conjunto descrito pelo lado esquerdo.
Isso significa que a posição de cada operando faz diferença.
Como isso funciona depende do tipo do lado esquerdo. Por exemplo, um `Range` verificaria se o lado direito está no intervalo, ou um `Object` verificaria se o lado direito é uma instância de `Object`.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## `case` com várias expressões

O `case` permite corresponder várias expressões em um único caso, com cada valor possível separado por vírgula.
O código será executado se qualquer uma das expressões corresponder.
Isso pode ser útil para um único caso com vários valores possíveis.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## `case` com intervalos

O `case` também pode verificar se um valor está em um intervalo.
Isso é feito usando um intervalo como expressão do `when`.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## `case` sem expressão do `case`

Quando não há necessidade de uma expressão do `case`, é possível omiti-la.
Ao fazer isso, cada expressão do `case` é avaliada quanto à veracidade.
E faz com que se comportem como instruções if-else-if.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## `when` em uma única linha

O Crystal permite instruções `case` de uma única linha.
Isso pode ser usado quando você tem uma instrução simples de uma única linha.
A instrução `when` de uma única linha é escrita como `when <expression> then <statement>.`
E quando usada na cláusula `else`, ela é escrita como `else <statement>`.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## `case` com tipos

O `case` permite fazer correspondência com tipos.
A comparação usa o operador `is_a?` para verificar o tipo da variável.
Por exemplo, isso permite um bloco para cada tipo em uma união de tipos.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## Objeto implícito

O `case` permite o uso de um objeto implícito.
Isso permite, por exemplo, que uma expressão do `when` seja uma chamada de método na expressão do `case`.
Dependendo de o método retornar um valor verdadeiro ou falso, o `case` corresponderá ou não.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
