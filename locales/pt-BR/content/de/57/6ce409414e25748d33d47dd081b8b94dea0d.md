# Introdução

Genéricos permitem escrever código que funciona com vários tipos sem duplicação.
Defina tipos genéricos usando sinais de maior e menor `<T>`, em que `T` é um espaço reservado para qualquer tipo.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo exige limites de trait para especificar quais operações o tipo genérico precisa suportar.
Você pode adicionar restrições usando a sintaxe `+`:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

Structs também podem ser genéricas:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

Traits também podem ser genéricas, o que permite que funcionem com tipos diferentes:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

Funções podem aceitar parâmetros genéricos com limites de trait, o que as faz funcionar com qualquer tipo que implemente o trait necessário:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
