# Dicas

## Geral

- Use o [tipo de lista (encadeada)][list] que já vem embutido na linguagem.

## 1. Defina uma função para retornar uma lista de linguagens vazia

- A função precisa retornar `[]`.

## 2. Defina uma função para adicionar uma linguagem à lista

- É possível adicionar um elemento ao início de uma lista usando `:`.

## 3. Defina uma função para remover uma linguagem da lista

- O Haskell [fornece uma função][tail] para retornar uma lista sem o primeiro item.

## 4. Defina uma função para retornar o primeiro item da lista

- O Haskell [fornece uma função][head] para obter o primeiro item de uma lista.

## 5. Defina uma função para retornar quantas linguagens há na lista

- O Haskell [fornece uma função][length] para contar o comprimento de uma lista.

## 6. Defina uma função para determinar se a lista inclui uma linguagem funcional

- Sua função deve retornar um valor Boolean que indica se `"Haskell"` é um membro da lista.
  O Haskell [fornece uma função][elem] para testar se um item pertence à lista.
