# Introdução

As funções para lidar com entrada e saída são fornecidas pelo módulo `IO`.

## Saída

Para escrever uma string na saída padrão, use o `IO.puts`. O `IO.puts` sempre adiciona uma nova linha no final da string. Se você não quiser esse comportamento, use o `IO.write`. As duas funções retornam o átomo `:ok` se derem certo.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

O `IO.puts` é útil para escrever strings, mas não muito além disso. Se você precisar de uma ferramenta de depuração que permita escrever qualquer valor na saída padrão, use o `IO.inspect`. O `IO.inspect` retorna o valor que recebeu, sem alterá-lo, então você pode inseri-lo em qualquer ponto do seu código. Ele também aceita várias opções, como `:label`, que permitem diferenciá-lo de outras chamadas de `IO.inspect`.

## Entrada

Para ler uma linha da entrada padrão, use o `IO.gets`. O `IO.gets` aceita um argumento: uma string que ele imprime como mensagem para pedir a entrada. O `IO.gets` não adiciona uma nova linha depois da mensagem; se precisar, inclua a nova linha você mesmo.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
