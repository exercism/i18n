# Sobre

Um `bit` é o valor mais granular da computação.
A palavra `bit` significa "dígito binário".
É uma unidade de armazenamento de dados no ambiente de execução grande o suficiente para conter um objeto que pode ter um de dois valores.
Como tal, tem um valor binário de `1` ou `0`.
Todos os outros tipos de dados consistem em múltiplos `bits`.
Por exemplo, um `byte` normalmente consiste em oito `bits`.

## Como escrever valores de bits

`Bits` formam um sistema numérico de base 2.
Cada múltiplo de `2` é colocado no que pensamos como a casa das dezenas/centenas/milhares/etc., exceto que "dezenas" seria "dois", "centenas" seria "quatro", "milhares" seria "oito", e assim por diante.
Assim, o valor decimal `2` seria o valor binário `10`, `4` seria `100`, e `8` seria `1000`.
Como nos números decimais, os valores aumentam da direita para a esquerda.
Podemos pensar no valor decimal `5` sendo representado por `101` em binário, com um `1` na casa das "unidades" e um `1` na casa do "quatro".
No entanto, literais binários não fazem parte do padrão da linguagem C.
Os únicos valores binários suportados pelo padrão da linguagem C são um único `1` ou `0`.
Literais binários _são_ suportados por algumas extensões de compilador não padronizadas, como o compilador GNU, ao prefixar o literal com `0b`.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

É importante lembrar que essa notação não é suportada por todos os compiladores e pode ser uma barreira para a portabilidade do código entre compiladores diferentes.

Uma forma comum de codificar valores binários é usar a notação hexadecimal, que é um sistema numérico de base 16.
A notação hexadecimal da linguagem C prefixa o literal com `0x` ou `0X`.
Como o valor decimal `16` é representado como `1` na casa das dezenas, o valor decimal `10` é representado como `0xA` em hexadecimal, `11` como `0xB`, `12` como `0xC`, `13` como `0xD`, `14` como `0xE` e `15` como `0xF`.
Então, por exemplo, o valor decimal `42` seria escrito como `0x2A`: `2` vezes `16` (= `32`) mais `10` (= `42`).

Em binário, podemos pensar em `42` como `00101010`: `32` mais `8` mais `2`.
Diríamos que o segundo, o quarto e o sexto bits da direita estão "definidos", ou seja, são `1` em vez de `0`.
O segundo bit é `2`, o quarto bit é `8`, e o sexto bit é `32`.
Definir esses três bits define um valor de `42`.

## Máscaras de bits

Uma máscara de bits pode ser qualquer valor usado para definir bits individuais.
Por exemplo, há vinte e seis letras no alfabeto inglês.
Um valor de pelo menos vinte e seis bits, como um inteiro sem sinal de 32 bits, poderia ser usado como uma máscara de bits para definir uma condição `true` ou `false` para cada letra do alfabeto inglês.
Qualquer valor com bits suficientes para lidar com um conjunto necessário de condições `true` ou `false` pode servir como uma máscara de bits.
Definir e ler os bits individuais é feito por meio do uso de operadores bit a bit.

## Operadores bit a bit

Digamos que queremos acompanhar quais letras ocorrem em uma `string`.
Para nosso exemplo, usaremos apenas as vinte e seis letras do alfabeto inglês.
Nossa máscara de bits será um inteiro sem sinal de 32 bits.
Um `0` representará que a letra não ocorre.
Um `1` representará que a letra ocorre uma ou mais vezes.
No início, a representação em bits da nossa máscara de bits será 32 `0s` em sequência: `00000000000000000000000000000000`.
A posição mais à direita será para `A`.
A segunda a partir da esquerda será para `B`, e assim por diante.
Digamos que estamos processando todas as letras da string em um laço, então queremos uma linha de código que funcione para definir qualquer letra.

### Operador bit a bit de deslocamento à esquerda: uma forma de posicionar um bit

`<<` é o operador bit a bit para deslocar à esquerda.

Se nossa letra for `A` não queremos deslocar à esquerda, mas se nossa letra for `B` queremos deslocar à esquerda uma posição, e se nossa letra for `C` queremos deslocar à esquerda duas posições, e assim por diante.
Embora possamos perceber `chars` como letras como `A` ou `B`, um `char` é implementado como um tipo inteiro na memória, então podemos fazer matemática simples com um `char`.
Dada uma variável chamada `letter` que representa o `char` que estamos processando, podemos deslocar à esquerda o número necessário de posições deslocando `1` para a esquerda pela diferença entre `letter` e o `char` `A`, assim: `1 << letter - 'A'`.
`A` - `A` é `0`, então deslocaria à esquerda `0` posições se `letter` fosse `A`.
`B` - `A` é `1`, então deslocaria à esquerda `1` posição se `letter` fosse `B`, e assim por diante.

### Operador OR inclusivo bit a bit: uma forma de definir um bit

Quando sabemos _onde_ queremos definir um bit, podemos de fato defini-lo usando o operador OR inclusivo bit a bit, que é `|`.
O resultado do operador `|` será `1` em cada posição onde o operando esquerdo ou o direito tiver um bit definido.
Então, o resultado de `0010 | 0001` seria `0011`.
(É importante lembrar que o valor é `11` em binário, mas é `3` em decimal.)
Para atribuir o resultado a um valor, o operador `|` pode ser combinado com o operador de atribuição para definir os bits assim: `|=`.
Para simplificar, o exemplo a seguir não usa um laço, mas demonstra como poderíamos processar as letras `ABA` em uma máscara de bits.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Definimos a parte mais à direita da nossa máscara como `0001` para `A`, e então definimos a máscara como `0011` para `B`.
Definir outro `A` não resulta em mudança na máscara existente.
Poderíamos ter evitado definir o bit novamente verificando se `A` já havia sido definido.

### Operador AND bit a bit: uma forma de ler um bit

`&` é o operador AND bit a bit.
O resultado do operador `&` será `1` em cada posição onde tanto o operando esquerdo quanto o direito tiverem um bit definido.
Então, o resultado de `0011 & 0001` seria `0001`.
Podemos ver isso em ação no exemplo a seguir.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Operador OR exclusivo bit a bit: uma forma de inverter um bit

`^` é o operador OR exclusivo bit a bit.
Um operador OR _inclusivo_ implica que existe um operador OR _exclusivo_ com comportamento diferente.
O resultado do operador `^` será `1` em cada posição onde _apenas um_ dos operandos esquerdo ou direito tiver um bit definido.
Então, o resultado de `0001 ^ 0011` seria `0010`.
O bit mais à direita não será definido porque _ambos_ os operandos têm `1` na posição mais à direita.
A operação OR exclusivo às vezes é denotada como XOR.
Se o resultado de um valor que sofreu XOR for ele mesmo submetido a XOR, ele retornará o valor original.
Isso pode ser usado para uma criptografia bem simples, em que a mesma chave é usada tanto para criptografar quanto para descriptografar os dados.
Por exemplo

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### Operador bit a bit de deslocamento à direita: uma forma de dividir um valor pela metade

`>>` é o operador bit a bit para deslocar à direita.
Normalmente, para cada posição em que os bits de um valor são deslocados à direita, o resultado é o valor dividido por dois.
Por exemplo

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

Se o valor do operando direito for negativo ou for maior ou igual à largura do operando esquerdo promovido, o comportamento será indefinido.
Isso também se aplica ao operador de deslocamento à esquerda.
Quando um inteiro com sinal é usado em vez de um inteiro sem sinal, a presença de sinal também pode influenciar.
O exemplo a seguir mostra o comportamento em um sistema ao deslocar demais para a esquerda ou para a direita com um inteiro com sinal.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

Como o comportamento é indefinido, um sistema diferente pode produzir resultados diferentes.
Ao deslocar bits, é importante entender os limites do tipo de dados usado.

## Campos de bits

Já vimos como bits empacotados em um tipo de dados simples podem ser endereçados por sua posição.
Bits empacotados em um `struct` podem ser endereçados por nome.
Esse tipo de dados é chamado de `bit field`.
Um caso de uso para `bit fields` pode ser quando uma coleção de flags ON/OFF é necessária e deseja-se minimizar o uso de memória.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

A sintaxe de `unsigned int variable_name : 1;` cria um campo de `1` bit dentro de um `unsigned int` colocado dentro da struct.
Em vez de um `unsigned int`, poderia ser usado um `signed int`, ou, a partir do C99 ou posterior, um tipo `bool`.
Uma struct contendo campos de bits também pode conter campos de outros tipos de dados, como `number_of_lights` no exemplo acima.
