# Instruções complementares

## Definindo a sintaxe

Neste exercício, você deve definir uma sintaxe para as cores usando o prefixo `c*`, por exemplo, `c*black`.
Essa sintaxe deve expandir, em tempo de compilação, para o valor correspondente de cada cor como um `Fin 10`, de acordo com as instruções.
Da mesma forma, você deve definir uma sintaxe para um array com todos os valores de cor usando `c*all`.

É provável que esta tarefa exija que você use notações ou macros.
Talvez você queira dar uma olhada em uma [referência][macro-reference].

Como a sintaxe nova é expandida em tempo de compilação, qualquer teste falharia na compilação a menos que toda a sintaxe necessária esteja definida.
Por esse motivo, em vez de depender de testes tradicionais em tempo de execução, verificamos todos os valores usando teoremas.
Se um teorema passar na verificação de tipos, você pode considerá-lo um teste aprovado.

Se você trabalhar localmente ou no [playground online][playground] do Lean, receberá feedback instantâneo, pelo Lean InfoView, sobre se cada teorema é bem-sucedido ou falha, e por que falha.

[macro-reference]: https://lean-lang.org/doc/reference/latest/Notations-and-Macros/#language-extension
[playground]: https://live.lean-lang.org/
