# Dicas

## 1. Retirar uma carta de uma pilha

- Os índices de um array começam em `0`.
- [Esta página][access_array_elements_resource] tem mais informações sobre como acessar elementos de um array.

## 2. Trocar uma carta da pilha

- O array é uma estrutura mutável, você pode alterar seu conteúdo a qualquer momento.
- Você pode encontrar um exemplo [aqui][change_array_elements_resource], dentro da seção 'Changing an Array Element'.

## 3. Inserir uma carta no topo da pilha

- Existe um método [nativo][push_method_docs] para adicionar um novo valor ao final do array.

## 4. Remover uma carta da pilha

- Existe um método [nativo][splice_method_docs] que, entre outros casos de uso, pode ser usado para remover elementos a partir de uma determinada posição.

## 5. Remover a carta do topo da pilha

- Existe um método [nativo][pop_method_docs] para remover o último elemento do array.

## 6. Inserir uma carta na base da pilha

- Existe um método [nativo][unshift_method_docs] para adicionar um novo valor ao início do array.

## 7. Remover uma carta da base da pilha

- Existe um método [nativo][shift_method_docs] para remover o primeiro elemento do array.

## 8. Verificar o tamanho da pilha

- Os arrays têm uma [propriedade][length_property_docs] para obter seu comprimento.
