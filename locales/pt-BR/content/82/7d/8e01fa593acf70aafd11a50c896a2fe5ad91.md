# Introdução

## Streams

Todas as funções no [módulo `Enum`][exercism-enum] são _eager_. Ao realizar várias operações em enumeráveis com o módulo `Enum`, cada operação vai gerar um resultado intermediário.

O módulo `Stream` é uma alternativa _lazy_ ao módulo `Enum`, que é _eager_. Oferece muitas das mesmas funções que o `Enum`, mas, em vez de gerar resultados intermediários, constrói uma série de computações que só são executadas quando o stream é passado para uma função do módulo `Enum`.

Streams implementam o _[protocolo][exercism-protocols] Enumerable_ e são componíveis: você pode encadeá-los para criar funcionalidades mais complexas.

[exercism-enum]: https://exercism.org/tracks/elixir/concepts/enum
[exercism-protocols]: https://exercism.org/tracks/elixir/concepts/protocols
