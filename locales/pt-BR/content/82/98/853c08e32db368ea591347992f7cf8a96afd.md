# Instruções

Como aspirante a mágica, Elyse precisa praticar alguns fundamentos. Ela tem uma pilha de cartas que quer manipular.

Para facilitar um pouco as coisas, ela usa apenas as cartas de 1 a 10, então a pilha de cartas dela pode ser representada por um array de números. A posição de uma carta corresponde ao índice no array. Isso significa que a posição 0 se refere à primeira carta, a posição 1 à segunda carta, e assim por diante.

<!-- prettier-ignore-start -->
~~~~exercism/note
Todas as funções, exceto duas, devem atualizar o array de cartas e depois retornar o array modificado. Essa é uma forma comum de trabalhar conhecida como padrão Builder, que permite encadear funções uma na outra de forma elegante.

As duas exceções são `getItem`, que deve retornar a carta na posição dada, e `checkSizeOfStack`, que deve retornar `true` se o tamanho dado corresponder.
~~~~
<!-- prettier-ignore-end -->

## 1. Recuperar uma carta de uma pilha

Para pegar uma carta, retorne a carta no índice `position` da pilha dada.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Trocar uma carta na pilha

Faça um pouco de prestidigitação e troque a carta no índice `position` pela carta de substituição fornecida.
Retorne a pilha ajustada.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Inserir uma carta no topo da pilha

Faça uma carta aparecer inserindo uma nova carta no topo da pilha.
Retorne a pilha ajustada.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Remover uma carta da pilha

Faça uma carta desaparecer removendo a carta na `position` dada da pilha.
Retorne a pilha ajustada.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Remover a carta do topo da pilha

Faça uma carta desaparecer removendo a carta do topo da pilha.
Retorne a pilha ajustada.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Inserir uma carta na base da pilha

Faça uma carta aparecer inserindo uma nova carta na base da pilha.
Retorne a pilha ajustada.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Remover uma carta da base da pilha

Faça uma carta desaparecer removendo a carta da base da pilha.
Retorne a pilha ajustada.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Verificar o tamanho da pilha

Verifique se o tamanho da pilha é igual a `stackSize` ou não.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
