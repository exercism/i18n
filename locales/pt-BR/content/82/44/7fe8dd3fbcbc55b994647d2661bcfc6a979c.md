# Sobre

Scala é uma linguagem de programação que cresce com você: de pequenos scripts a grandes aplicações multiplataforma.

Scala combina a programação orientada a objetos e a programação funcional em uma única linguagem concisa e de alto nível. Os tipos estáticos de Scala ajudam a evitar bugs em aplicações complexas, e seus runtimes JVM, JavaScript e Native permitem que você construa sistemas de alto desempenho, com acesso fácil a enormes ecossistemas de bibliotecas.

* Recursos
    * Interoperabilidade com a JVM - Scala roda na JVM, então stacks Java e Scala podem ser misturadas para uma integração perfeita.
    * Interoperabilidade com JS e Native - Scala pode rodar no navegador e em dispositivos nativos, graças ao [Scala.js](https://www.scala-js.org/) e ao [Scala Native](https://github.com/scala-native/scala-native)
    * Inferência de tipos - Scala é tipada estaticamente. No entanto, Scala oferece inferência de tipos para aliviar o peso de um sistema de tipos avançado.
    * Orientada a objetos - Scala é uma linguagem puramente orientada a objetos, no sentido de que todo valor é um objeto. Os tipos de dados e os comportamentos dos objetos são descritos por classes e traits. As abstrações de classe são estendidas por meio de subclasses e de um mecanismo flexível de composição baseado em mixins, para evitar os problemas da herança múltipla.
    * Funcional - Scala também é uma linguagem funcional, no sentido de que toda função é um valor. Scala oferece uma sintaxe leve para definir funções anônimas, oferece suporte a funções de ordem superior, permite que funções sejam aninhadas e oferece suporte a currying. As case classes de Scala e seu suporte integrado a correspondência de padrões modelam os tipos algébricos usados em muitas linguagens de programação funcionais. Objetos singleton oferecem uma maneira prática de agrupar funções que não são membros de uma classe.
    * Concorrência e distribuição - Use operações paralelas sobre os dados em coleções, use atores para concorrência e distribuição, ou futures para programação assíncrona.
