# Apêndice das instruções

## Implementação

Premissas:

1. O zero é sempre representado nas saídas como [0] em vez de [].
2. Em nenhuma outra situação as saídas têm zeros à esquerda.
3. Zeros à esquerda são aceitos nas entradas.
4. Uma sequência vazia de dígitos de entrada é considerada zero, e não um erro.

Trate os casos problemáticos retornando um erro cujo método Error() retorna uma das seguintes mensagens:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
