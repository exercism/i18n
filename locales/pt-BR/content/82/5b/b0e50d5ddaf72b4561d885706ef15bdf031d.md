# Introdução

Em C#, as estruturas de dados que podem conter zero ou mais elementos são conhecidas como _coleções_. Um **array** é uma coleção que tem tamanho/comprimento fixo e cujos elementos precisam ser todos do mesmo tipo. Você pode atribuir elementos a um array ou recuperá-los dele usando um índice. Os arrays em C# começam no zero, o que significa que o índice do primeiro elemento é sempre zero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Você também pode definir arrays com uma notação abreviada que permite criar o array e definir seu valor ao mesmo tempo. Como o compilador agora consegue saber quantos elementos o array vai ter, o comprimento pode ser omitido:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Você pode manipular arrays chamando os métodos ou as propriedades de uma instância de array, ou usando os métodos estáticos definidos na classe `Array`.
