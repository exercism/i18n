# Anexo às instruções

## Registradores

| Registrador | Uso       | Tipo    | Descrição                                          |
| ----------- | --------- | ------- | -------------------------------------------------- |
| `$a0`       | entrada   | endereço | primeira cor como string terminada em nulo         |
| `$a1`       | entrada   | endereço | segunda cor como string terminada em nulo          |
| `$a2`       | entrada   | endereço | terceira cor como string terminada em nulo (possivelmente vazia) |
| `$v0`       | saída     | inteiro | valor do resistor                                  |
| `$t0-9`     | temporário | qualquer | para armazenamento temporário                      |
