# Instruções

Neste exercício, você vai processar mensagens de log com seis níveis de severidade.

Cada linha de log é uma string formatada assim: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de log:

| NÍVEL     | LVL   |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. Analisar o nível de log

Defina um enum `LogLevel` com seis elementos correspondentes aos níveis de log definidos acima.
Em seguida, defina a função `parse_log_level`, que recebe a mensagem de log como parâmetro e retorna o membro do enum correspondente ao seu nível.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. Dar suporte a nível de log desconhecido

Infelizmente, algumas mensagens de log aparecem de vez em quando com uma severidade _desconhecida_. Para tratar essas mensagens de log "misteriosas" de forma elegante na função `parse_log_level`, adicione um membro `Unknown` ao enum `LogLevel`, que será retornado ao analisar um nível de log desconhecido:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. Converter uma mensagem de log para o formato curto

O nível de log de uma linha de log é bastante verboso. Para reduzir o espaço em disco necessário para armazenar as mensagens de log, define-se um formato curto: `"[<CODE_LEVEL>]:<MESSAGE>"`.

Os códigos dos níveis de log seguem um mapeamento direto:

| NÍVEL     | CÓDIGO |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

Defina a função `convert_to_short_log()`, que recebe dois parâmetros:

1. Nível de log - O nível de log do log enviado. ex: `LogLevel.Error`.
2. Mensagem de log - A mensagem do tipo `str`.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. Criar um alias

Parece que o usuário criou logs para `LogLevel.Warn` em vez de `LogLevel.Warning`. Crie um `alias` para `LogLevel.Warning` e retorne o novo membro alias na função `get_warn_alias`.

Isso pode ser feito na mesma classe enum `LogLevel` já definida no topo do arquivo. Os dois LogLevels devem apontar para o mesmo valor: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. Todos os nomes e valores dos membros

Defina a função `get_members()`.

Essa função deve retornar uma lista de tuplas `(name, value)` contendo todos os membros do enum `LogLevel`.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
