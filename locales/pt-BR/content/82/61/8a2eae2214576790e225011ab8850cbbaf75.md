# Vetores como uma pilha

Uma pilha é uma estrutura de dados linear otimizada para o acesso a partir de uma das extremidades. Uma boa metáfora é uma pilha de folhas de papel num espeto: novas folhas são sempre adicionadas na mesma extremidade, e as folhas são removidas na ordem inversa à que foram adicionadas. As folhas adicionadas primeiro são removidas por último, e as adicionadas por último são removidas primeiro.

A estrutura de dados `Vec` do Rust é adequada para uso como pilha. O [`push` method](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) adiciona itens ao final do vetor. O [`pop` method](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) remove o último item do vetor. Tanto `push` quanto `pop` exigem apenas tempo amortizado `O(1)`.

## Exemplo

Neste exemplo, usamos um vetor como pilha para uma calculadora [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation) simples. O código-fonte completo está no [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736).

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
