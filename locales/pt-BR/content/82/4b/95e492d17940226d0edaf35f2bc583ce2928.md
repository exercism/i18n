# Instruções

Mika, a organizadora de eventos, foi promovida no trabalho e, como parte de suas novas responsabilidades, agora é ela quem cuida do banco de dados de eventos. Ela logo percebeu que muitos dos dados estão armazenados de formas que dificultam o trabalho, então vocês vão se juntar para limpá-los com um script de uso único.

Como o script vai rodar só uma vez e você conhece bem a estrutura dos dados, este é um bom lugar para usar as _let assertions_ do Gleam.

## 1. Extrair os erros

Cada evento passado tem uma lista de problemas que ocorreram durante o evento. Eles foram armazenados como results, mas são sempre a variante `Error`.


Implemente a função `extract_error`, que recebe um result que deve ser sempre um `Error` e retorna o valor de erro contido nele.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. Remover o prefixo de equipe

Os nomes das equipes foram prefixados com a palavra "Team ", mas isso não é necessário. Implemente a função `remove_team_prefix` para remover o prefixo do nome de uma equipe.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. Separar região e equipe

Cada evento é organizado por uma equipe, e cada equipe pertence a uma região. No banco de dados, eles ficam armazenados em uma única string, separados por uma vírgula.

Implemente a função `split_region_and_team` para dividir a string em uma tupla de duas strings, uma para a região e outra para a equipe. O prefixo "Team " deve ser removido do nome da equipe.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
