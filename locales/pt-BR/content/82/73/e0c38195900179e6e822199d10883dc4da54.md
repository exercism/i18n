## Formatação

Embora o Common Lisp não se importe com a indentação e o layout do código, nem com o uso de espaços ou tabulações, isso é uma consideração importante ao enviar soluções para o Exercism.
O widget de código do Exercism.org não lida bem com a mistura de tabulações e espaços, então recomendamos usar apenas espaços para deixar o código mais legível para os revisores humanos.
Consulte as configurações do seu editor para saber como fazer isso.
Abaixo estão as instruções para editores populares de Common Lisp.

### VIM

Use os seguintes comandos para garantir que o VIM use apenas espaços na indentação:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(ou em uma só linha, `:set tabstop=2 shiftwidth=2 expandtab`). Você pode adicionar isso ao seu arquivo `~/.vimrc` para usar sempre.

### Emacs

O Emacs é muito adequado para editar Common Lisp e tem muitos pacotes extras poderosos disponíveis. A única coisa que você precisa fazer com um Emacs padrão para que ele funcione bem com o exercism.org é avaliar o seguinte código:

`(setq-default indent-tabs-mode nil)`

Você pode colocar isso no seu `~/.emacs` (ou `~/.emacs.d/init.el`) para que a configuração seja aplicada sempre que o Emacs for iniciado.

Um complemento sugerido para Emacs e Common Lisp é o [SLIME][slime], que oferece uma integração estreita com o REPL, tornando a codificação e os testes iterativos muito fáceis.
