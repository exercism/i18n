# Sobre

O [C++](https://en.wikipedia.org/wiki/C%2B%2B) (pronuncia-se cê mais mais) é uma linguagem de programação de uso geral desenvolvida por [Bjarne Stroustrup](https://en.wikipedia.org/wiki/Bjarne_Stroustrup) a partir de 1979 nos Bell Labs. É imensamente popular, principalmente para aplicações que exigem velocidade e/ou acesso a alguns recursos de baixo nível. É considerada uma linguagem de nível intermediário, pois encapsula recursos de linguagens tanto de alto quanto de baixo nível.

O C++ dá suporte a programação [procedural](https://en.wikipedia.org/wiki/Procedural_programming), [orientada a objetos](https://en.wikipedia.org/wiki/Object-oriented_programming), [funcional](https://en.wikipedia.org/wiki/Functional_programming) e [genérica](https://en.wikipedia.org/wiki/Generic_programming). Existem compiladores de C++ para praticamente todas as plataformas, incluindo Windows, Mac OS e Linux.

Principais vantagens:
- **Segurança de tipos:** Encapsule as operações inseguras necessárias
- **Segurança de recursos:** Nem todo gerenciamento de recursos é gerenciamento de memória
- **Desempenho:** Para algumas partes de quase todos os sistemas, ele é importante
- **Previsibilidade:** Para sistemas de tempo real críticos e não críticos
- **Capacidade de ensino:** A complexidade do código deve ser proporcional à complexidade da tarefa
- **Legibilidade:** Pessoas e máquinas ("analisabilidade")
- **Mapeamento direto para o hardware:** de instruções e tipos de dados fundamentais
- **Abstração com custo zero:** Classes com construtores e destrutores, herança, programação genérica, técnicas de programação funcional

O padrão do C++ é mantido pela International Organization for Standardization (ISO), e a versão atual do C++ em junho de 2018 é o C++17 (nomeado não como a 17ª versão do C++, mas sim indicando que o padrão foi ratificado em 2017).

A melhor coisa do C++ é que ele roda em tudo, de processadores embarcados com recursos muito limitados ao maior supercomputador mainframe, passando por todos os computadores pessoais entre eles.
