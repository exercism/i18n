Mas as coisas estão um pouco desorganizadas: as coordenadas de Aazra parecem estar formatadas e ordenadas de um jeito diferente das de Rui, e eles precisam ficar olhando de uma lista para a outra para descobrir quais tesouros combinam com quais lugares. Como são Gleamlins iniciantes, eles vieram até você pedir ajuda para escrever um pequeno programa (na verdade, um conjunto de funções) que organize melhor as informações da caçada.

## 1. Converter localizações

Implemente a função `place_location_to_treasure_location`, que recebe uma localização de lugar (como `#("C", 1)`) e a converte em uma localização de tesouro (como `#(1, "C")`).

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. Comparar localizações de tesouro e de lugar

Implemente a função `treasure_location_matches_place_location`, que recebe uma localização de lugar (como `#("C", 1)`) e retorna `True` se ela corresponder a uma localização de tesouro (como `#(1, "C")`).

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. Contar localizações de tesouros

Implemente a função `count_place_treasures`, que recebe um lugar (como `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) e a lista de tesouros, e retorna quantos tesouros podem ser encontrados ali.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. Lugares especiais

Implemente a função `special_case_swap_possible`, que recebe um tesouro (como `#("Amethyst Octopus", #(1, "F"))`), um lugar (como `#("Seaside Cottages", #("C", 1))`) e um tesouro desejado (como `#("Crystal Crab", #(6, "A"))`), e retorna `True` para as seguintes combinações:

- O Brass Spyglass pode ser trocado por qualquer outro tesouro no Abandoned Lighthouse.
- O Amethyst Octopus pode ser trocado pelo Crystal Crab ou pela Glass Starfish no Stormy Breakwater.
- O Vintage Pirate Hat pode ser trocado pelo Model Ship in Large Bottle ou pelo Antique Glass Fishnet Float no Harbor Managers Office.
