# Dicas

## Geral

- Para que um nome possa ter vários tipos diferentes, você precisa usar um [tipo de união][union-type].
- Para que uma variável de instância seja usada em uma expressão de controle [`if var.is_a?(Type)`][if-is-a], primeiro ela precisa ser atribuída a uma variável local.

## 1. Definir uma senha

- Você precisa definir uma classe com o nome `PasswordLock`.
- Você precisa definir um método initialize que recebe um `String`, `Int32` ou `Float64` como argumento.
- Você precisa definir uma [variável de instância][instance-variable] `@password` que recebe o argumento passado ao construtor.

## 2. Criptografar a senha

- Defina um método de instância chamado `encrypt`.
- O método deve modificar a [variável de instância][instance-variable] `@password` para que ela fique criptografada.
- Para que um bloco específico só possa ser executado se a variável for de um tipo específico, você precisa usar o método [`is_a?`][is-a] em uma expressão de controle.

## 3. Verificar se uma senha está correta

- Você pode usar os métodos já definidos para criptografar a tentativa de senha fornecida.
