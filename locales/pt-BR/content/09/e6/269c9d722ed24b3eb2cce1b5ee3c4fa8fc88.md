# Introdução

## Pacotes e módulos

### Importação

Um módulo normalmente é carregado com a palavra-chave `use`.
Isso carrega o módulo e chama o método `import` dele, importando todos os símbolos exportados.

Os símbolos no array `@EXPORT` do pacote são importados por padrão.
Já os símbolos no array `@EXPORT_OK` do pacote precisam ser importados explicitamente.

### Exportação

Para que um símbolo seja importado, ele precisa primeiro ser exportado.
O módulo [Exporter][Exporter] vem incluído no Perl e é uma das opções mais práticas para exportar.

Definindo o módulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Usando o módulo:
```perl
use Foo ('bar');

bar();
```

### Módulos principais

Além do [Exporter][Exporter], o Perl tem uma grande variedade de [módulos principais][perl-core-modules] disponíveis para uso.
Alguns exemplos úteis para os exercícios que você pode encontrar por aqui são [List::Util][List::Util], [Time::Piece][Time::Piece] e [Math::BigRat][Math::BigRat].

### CPAN

Além dos módulos principais, o [CPAN][metacpan] tem milhares de módulos adicionais criados pela comunidade Perl disponíveis para instalação.
A track de Perl usa um [cpanfile][test-runner-cpanfile] para instalar uma seleção de módulos que podem ser usados com o test runner de Perl do Exercism.
