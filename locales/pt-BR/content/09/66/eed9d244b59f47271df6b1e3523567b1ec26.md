# Dicas

## Geral

- A tupla `plot`, os símbolos `registrations` e `next-id`, e o símbolo
  `not-found` já estão declarados no arquivo do exercício.
- Para estado no nível do módulo, use `set-global`, `get-global` e
  `change-global`.

## 1. Abra o jardim e liste seus registros

- `V{ } clone` é o valor inicial certo para `registrations`
  (sempre `clone`, para que o literal não seja compartilhado entre chamadas).
- `1 next-id set-global` define o contador.
- Para `list-registrations`, um único `registrations get-global` já basta.

## 2. Registre um canteiro

- Leia `next-id` primeiro, depois `plot boa` para construir o canteiro a partir de
  `id` e `name`.
- Incremente o contador com `next-id [ 1 + ] change-global`.
- `push` (em [`sequences`][sequences]) acrescenta a um vetor no próprio local,
  perfeito para `registrations get-global`.

## 3. Libere um canteiro

- Um `:: release ( id -- )` deixa `id` disponível dentro do predicado
  do filtro.
- `[ id>> id = ] reject` mantém todo canteiro cujo slot `id` *não*
  corresponde ao `id` local. Use isso como o corpo de um `change-global`.

## 4. Obtenha um canteiro registrado

- `find` retorna `( index elt/f )`. `nip` descarta o índice.
- `[ not-found ] unless*` substitui o símbolo quando nada foi
  encontrado.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
