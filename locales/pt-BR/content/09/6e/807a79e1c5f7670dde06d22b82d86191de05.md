# não escreva no console

Remova a(s) função(ões) que escrevem no console, pois os testes não precisam delas e elas deixam o código um pouco mais difícil de ler.

Normalmente, essas instruções são adicionadas para ajudar a depurar o código. No entanto, uma abordagem melhor é depurar o código enquanto você roda um ou mais testes unitários. Isso tem a vantagem extra de permitir focar na depuração de um caso de teste específico. Aqui estão alguns links que explicam como depurar código Scala enquanto você roda testes unitários em várias IDEs:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
