# Introdução

O vocabulário [`random`][random] do Factor fornece uma única palavra genérica, `random`, que se adapta ao argumento dela, além de auxiliares para embaralhar e amostrar sequências.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

`random` aplicado a um número inteiro `n` retorna um valor em `[0, n)`; aplicado a uma sequência, retorna um elemento aleatório. `randomize` embaralha a sequência no local, e `sample` sorteia elementos distintos.

Por padrão, essas palavras usam um gerador global inicializado a partir do relógio do sistema. Para tornar os resultados reproduzíveis, instale um gerador com semente usando `<mersenne-twister>` (de [`random.mersenne-twister`][mt]) e `with-random`:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
