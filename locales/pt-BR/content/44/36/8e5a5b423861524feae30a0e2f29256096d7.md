# Instruções

Neste exercício, você vai trabalhar em um agendador de compromissos para um salão de beleza em Nova York que abriu em 15 de setembro de 2012.

Você tem cinco tarefas, e todas elas envolvem datas de compromissos.
Os horários estão no formato de 24 horas (sem AM/PM).
Para manter as questões de fuso horário o mais simples possível, considere que tudo usa UTC.

## 1. Converta uma data de compromisso totalmente numérica

Implemente a função `schedule_appointment()` para converter uma representação textual de uma data de compromisso no formato `DateTime` correspondente.

Repare que a entrada está no formato mês/dia/ano, ao estilo dos Estados Unidos.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Verifique se um compromisso já passou

Implemente a função `has_passed()`, que recebe uma data de compromisso e verifica se o compromisso ficou em algum momento no passado:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Verifique se o compromisso é à tarde

Implemente a função `is_afternoon_appointment()`, que recebe uma data de compromisso e verifica se o compromisso é à tarde (>= 12:00 e < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Verifique o dia da semana de um compromisso

Implemente a função `day_of_week()`, que retorna o dia da semana em formato _numérico_.
O salão fecha aos domingos, então segunda-feira é o dia 1 e sábado é o dia 6.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. Remarque um compromisso

Quando um cliente precisa remarcar um compromisso, isso é feito automaticamente para a próxima sexta-feira, no mesmo horário do dia (já que é o dia mais tranquilo da semana).

Implemente a função `reschedule()`, que recebe o compromisso original (como uma string de texto no formato mês/dia/ano) e retorna um compromisso remarcado.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

Se o compromisso original era de segunda a quinta-feira, remarque para a sexta-feira desta semana.
Para compromissos de sexta ou sábado, remarque para a sexta-feira da próxima semana.
