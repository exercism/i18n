# Sobre

O Elixir usa [_comportamentos_][behaviours] para oferecer interfaces genéricas comuns e, ao mesmo tempo, facilitar implementações específicas para cada módulo que implementa o comportamento. Um desses comportamentos é o _Access Behaviour_.

O _Access Behaviour_ oferece uma interface comum para recuperar dados baseados em chaves de uma estrutura de dados. Está implementado para mapas e listas de palavras-chave.

O módulo [`Access`][access] define os callbacks exigidos pela interface. Já os módulos [`Map`][map] e [`Keyword`][keyword] implementam os callbacks exigidos [`fetch/2`][map-fetch], [`get_and_update/3`][map-get-and-update] e [`pop/2`][map-pop]

Para usar o comportamento, você pode colocar _colchetes_ logo depois de uma variável associada e, em seguida, usar a chave para recuperar o valor associado a ela. Os mapas aceitam chaves de qualquer tipo, enquanto as listas de palavras-chave aceitam apenas chaves do tipo átomo.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

Se a chave não existir na estrutura de dados, `nil` é retornado. Isso pode ser fonte de comportamento indesejado, porque não lança um erro.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

Repare que o próprio `nil` implementa o Access Behaviour e sempre retorna `nil` para qualquer chave.

```elixir
nil[:key]
# => nil
```

Structs não implementam o Access Behaviour.
