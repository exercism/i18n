# Sobre

Uma `string` em Clojure é uma string Java, ou seja, um objeto que representa texto imutável como uma cadeia de caracteres Unicode (letras, dígitos, pontuação etc.) e é definida assim:

```clojure
(def fruit "Apple")
```

A biblioteca `clojure.string` oferece muitas funções padrão de manipulação e processamento de strings. Além disso, todos os métodos Java usuais para operar com strings estão disponíveis via interop.
