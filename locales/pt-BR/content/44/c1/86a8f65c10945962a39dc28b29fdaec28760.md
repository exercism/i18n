# Introdução

Em Go, os Boolean são representados pelo tipo booleano predeclarado `bool`, cujos valores podem ser `true` ou `false`.
É um tipo definido.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go oferece três operadores lógicos que podem reduzir expressões a valores Boolean, retornando `true` ou `false`.

| Operador    | O que significa                                          |
| ----------- | -------------------------------------------------------- |
| `&&` (and)  | É verdadeiro se as duas afirmações forem verdadeiras.     |
| `\|\|` (or) | É verdadeiro se pelo menos uma afirmação for verdadeira.  |
| `!` (not)   | É verdadeiro apenas se a afirmação for falsa.             |
