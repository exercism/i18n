# Instalação

Consulte [System/Installation][install-link] para instruções de como configurar tudo no seu sistema.

~~~exercism/caution
Se você tiver o Java Development Kit (JDK) instalado, o executável `jconsole` pode entrar em conflito com o Java Console, que usa o mesmo nome.

Algumas soluções possíveis:

- Renomeie o executável `jconsole` da linguagem de programação J para algo único (por exemplo, `jconsole-jlang`).

- Ajuste as variáveis de ambiente ou o PATH do seu sistema para priorizar o `jconsole` da linguagem de programação J.

- **Para usuários de Linux**, há um script bash em `bin/install.sh` que cria um **link simbólico** chamado `ijconsole` no diretório `/usr/`. Você pode usar esse link digitando `ijconsole` no seu terminal.
~~~

Depois que o J estiver instalado, abra um console do J no seu terminal e digite os seguintes comandos para instalar o framework de testes unitários:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
