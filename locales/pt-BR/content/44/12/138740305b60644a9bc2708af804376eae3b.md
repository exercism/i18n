# Introdução

Criar uma instância de uma classe é feito chamando seu [_construtor_][constructor] por meio do operador `new`. Um construtor é um método especial dentro de uma classe cujo objetivo é inicializar a classe. Em Haxe, o método construtor tem o nome de `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Assim como métodos normais, construtores podem ter parâmetros. Esses parâmetros são (geralmente) armazenados em campos privados e acessados depois.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

Você **não pode** criar uma nova instância de uma classe se ela não tiver um construtor. Assim, usar um construtor vazio é a única forma.

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
