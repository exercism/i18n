# Sobre

Em Clojure, associar um valor a um nome é chamado de [_var_][vars]. Vars de nível superior (globais) são semelhantes a constantes em outras linguagens, mas costumam ser redefinidas para facilitar o desenvolvimento dinâmico.

Vars de nível superior são definidas com [`def`][def]:

```clojure
(def fingers 10)
```

Você pode usar as funções principais para [operações com números][operators] para fazer aritmética com valores.

A macro `defn` pode ser usada para definir uma [função][functions] que recebe zero ou mais argumentos. Uma função sempre retorna o resultado da última expressão do seu corpo.

```clojure
(defn add [x y]
  (+ x y))
```

Para chamar uma função, você especifica o nome dela e passa argumentos para cada um dos parâmetros da função.

```clojure
(def five (add 2 3))
```

Funções e valores em Clojure só podem ser usados _depois_ de definidos. Usá-los antes de serem definidos resulta em um erro de compilação.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Em Clojure, os espaços em branco não têm nenhum significado além da formatação.

As funções e vars de Clojure são organizadas em namespaces. Um namespace agrupa funcionalidades relacionadas e é definido com a macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure oferece suporte a dois tipos de comentários. Comentários de uma linha são precedidos por `;` e a forma `comment` é usada para impedir a avaliação de tudo entre `(comment` e `)`.
