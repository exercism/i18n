# Anexo às instruções

## Dica de desempenho

Todas as entradas e saídas estão em ASCII.
As `String`s e `&str` do Rust são utf8, então, embora a gente possa esperar que `"Hello".chars()` seja simples, na verdade ele precisa verificar cada caractere para ver se ocupa 1, 2, 3 ou 4 `u8`s.
Se sabemos que uma `&str` é ASCII, podemos chamar `.as_bytes()` e nos referir aos dados subjacentes como um `&[u8]` (uma fatia de bytes).
Iterar sobre uma fatia de bytes ASCII é muito mais rápido, já que não há pontos de código envolvidos: cada byte ASCII ocupa um `u8`.
