# Instruções

Neste exercício você vai brincar com um carro de controle remoto, que você finalmente juntou dinheiro suficiente para comprar.

Os carros começam com a bateria cheia (100%). Cada vez que você dirige o carro com o controle remoto, ele percorre 20 metros e gasta um por cento da bateria.

O carro de controle remoto tem um display de LED chique que mostra duas informações:

- A distância total percorrida, exibida como: `"Driven <METERS> meters"`.
- A carga restante da bateria, exibida como: `"Battery at <PERCENTAGE>%"`.

Se a bateria estiver em 0%, você não pode mais dirigir o carro e o display da bateria vai mostrar `"Battery empty"`.

Você tem seis tarefas, e cada uma delas vai trabalhar com instâncias de carro de controle remoto.

## 1. Compre um carro de controle remoto novinho em folha

Implemente o método (_static_) `RemoteControlCar.Buy()` para retornar uma instância novinha em folha de carro de controle remoto:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. Exiba a distância percorrida

Implemente o método `RemoteControlCar.DistanceDisplay()` para retornar a distância como ela é exibida no display de LED:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. Exiba a porcentagem da bateria

Implemente o método `RemoteControlCar.BatteryDisplay()` para retornar a porcentagem da bateria como ela é exibida no display de LED:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. Atualize o número de metros percorridos ao dirigir

Implemente o método `RemoteControlCar.Drive()` que atualiza o número de metros percorridos:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. Atualize a porcentagem da bateria ao dirigir

Atualize o método `RemoteControlCar.Drive()` para atualizar a porcentagem da bateria:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. Impeça de dirigir quando a bateria acabar

Atualize o método `RemoteControlCar.Drive()` para não aumentar a distância percorrida nem diminuir a porcentagem da bateria quando a bateria acabar (em 0%):

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
