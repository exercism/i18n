# Dicas

## Geral

- Use o [tipo de lista (encadeada)][list] nativo da linguagem.
- Use as funções nativas do módulo [`Stream`][stream] para criar um stream

## 1. Detectar argumentos inválidos

- Use um [guard][guards] para detectar os casos em que um número inteiro não é passado como argumento para `generate/1`.

## 2. Gerar os casos base

- Você pode usar várias [cláusulas de função][multiple-fn-clauses] e [pattern matching][pattern-matching] para criar as funções de caso base.

## 3. Criar o caso generalizado

- Use a função [`Stream.iterate/2`][stream-iterate] para gerar uma sequência de números, em que cada próximo é criado a partir do anterior.
- Os números iniciais são `2` e depois `1`, que você pode passar juntos usando uma tupla para formar um par `{2, 1}`
- Certifique-se de que o próximo número seja a soma dos dois números anteriores a ele.
- Para converter o stream em uma lista, use uma função do módulo [`Enum`][enum].
