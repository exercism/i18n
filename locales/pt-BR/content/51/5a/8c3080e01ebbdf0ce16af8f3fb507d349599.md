# Introdução

O módulo `Agent` fornece uma abstração para criar [processos e o laço _receive-send_][exercism-processes]. Daqui em diante, vamos chamar de _'processos de agente'_ os processos iniciados com o módulo `Agent`. Um _processo de agente_ pode ser escolhido para representar um estado compartilhado central.

Para iniciar um _processo de agente_, `Agent` fornece a função `start/2`. A função fornecida ao iniciar o _processo de agente_ com `start` retorna o estado inicial do processo:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Assim como `Map` ou `List`, `Agent` fornece muitas funções para trabalhar com _processos de agente_.

É comum organizar e encapsular toda a funcionalidade relacionada a `Agent` em um módulo para o domínio que está sendo modelado.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
