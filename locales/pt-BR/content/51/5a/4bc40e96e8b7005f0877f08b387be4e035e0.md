# Instruções

Neste exercício, você vai escrever código para imprimir crachás de funcionários de uma fábrica.

## 1. Imprima um crachá para um funcionário

Os funcionários têm um ID, um nome e o nome do departamento.
Os rótulos dos crachás dos funcionários são formatados assim: `"[id] - name - DEPARTMENT"`.
Implemente o método `printBadge()` para retornar o rótulo do crachá de um funcionário:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Repare que o departamento deve ficar em maiúsculas no rótulo.
~~~~

## 2. Imprima um crachá para um funcionário novo

Por causa de uma peculiaridade no sistema do computador, os funcionários novos às vezes ainda não têm um ID quando começam a trabalhar na fábrica.
Como os crachás são obrigatórios, eles vão receber um crachá temporário sem o prefixo de ID.
Modifique o método `printBadge()` para dar suporte a funcionários novos que ainda não têm um ID:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprima um crachá para o dono

Até o dono da fábrica precisa usar um crachá o tempo todo.
No entanto, o dono não tem um departamento.
Nesse caso, o rótulo deve imprimir `"OWNER"` no lugar do nome do departamento.
Modifique o método `printBadge()` para imprimir um rótulo para o dono:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Repare que é possível que o dono também seja um funcionário novo:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
