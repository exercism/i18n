# Dicas

## Geral

- O tipo fornecido é recursivo: `Nil` representa uma lista vazia, e `Cons(value, rest)` contém um elemento e outra lista.
  Use essas mesmas formas em um `match` para inspecionar uma lista ou em uma expressão para construir uma.

- As operações retornam listas atualizadas em vez de modificar seus argumentos.
