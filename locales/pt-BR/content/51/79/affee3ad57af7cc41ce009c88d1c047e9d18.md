# Dicas

## Geral

- Use `Bitwise` (ou div/rem).
- Se você usar `Bitwise`, uma forma fácil de ver se um bit específico está definido é comparar o E binário (`&&&`) de um conjunto de bits com o padrão de bits específico que você quer verificar, e determinar se o resultado é igual ao padrão que você está verificando.
