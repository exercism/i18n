# Sobre

As sequências em Factor vêm em duas formas quando você precisa *modificá-las*:

- **Arrays** (`{ … }`) têm comprimento fixo. Você pode mudar o que está
  *em* cada posição com `set-nth` / `change-nth`, mas não dá para
  aumentar nem diminuir o comprimento deles.
- **Vectors** (`V{ … }`) têm comprimento variável. `push` adiciona ao
  final, `pop` remove e retorna o último elemento.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| palavra         | efeito                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`: array de `n` cópias de `elt` |
| `<vector>`      | `( n -- vector )`: vector vazio com capacidade `n` |
| `V{ }`          | literal de vector vazio                        |
| `set-nth`       | `( elt n seq -- )`: atribui o elemento no índice `n` |
| `change-nth`    | `( i seq quot -- )`: aplica `quot` ao elemento em `i` |
| `push`          | `( elt seq -- )`: acrescenta a um vector       |
| `suffix!`       | `( seq elt -- seq )`: acrescenta no lugar e retorna o vector |
| `pop`           | `( seq -- elt )`: remove e retorna o último    |
| `pop*`          | `( seq -- )`: remove o último e descarta       |
| `clone`         | `( obj -- copy )`: cópia nova e independente   |
| `new-sequence`  | `( n exemplar -- newseq )`: sequência nova da mesma classe que `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )`: variante redimensionável nova |

Quando você modifica uma sequência que o chamador passou, a mudança
fica visível para o chamador, já que é o mesmo objeto. Se não é isso
que você quer, use `clone` primeiro para obter uma cópia independente.
