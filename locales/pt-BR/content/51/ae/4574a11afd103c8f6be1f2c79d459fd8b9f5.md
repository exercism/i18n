# Introdução

## Anulabilidade

Em Java, o literal `null` é usado para denotar a ausência de um valor.

Os tipos de dados primitivos em Java têm todos um valor padrão e, por isso, nunca podem ser `null`.
Por convenção, eles começam com uma letra minúscula, por exemplo `int`.

Os tipos de referência contêm o endereço de memória de um objeto e podem ter o valor `null`.
Em geral, eles começam com uma letra maiúscula, por exemplo `String`.

Tentar atribuir a uma variável primitiva um valor `null` resultará em um erro em tempo de compilação, pois a variável sempre contém um valor primitivo do tipo atribuído.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Atribuir a uma variável de referência um valor `null` não resultará em um erro em tempo de compilação, pois variáveis de referência são anuláveis.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
