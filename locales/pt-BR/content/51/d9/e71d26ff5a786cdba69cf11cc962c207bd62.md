# Instrução

Sua tarefa é resolver um quebra-cabeça binário.
Todo quebra-cabeça binário tem exatamente _uma_ solução, que pode ser encontrada aplicando estas regras:

1. Cada casa deve conter zero ou um.
2. Não pode haver mais de dois dígitos iguais adjacentes. Assim, se duas casas adjacentes contêm o mesmo dígito, as casas ao lado dos dígitos devem conter o outro dígito.
3. Cada linha e cada coluna devem conter a mesma quantidade de zeros e uns.
4. Cada linha e cada coluna é única.

Você vai receber um quebra-cabeça incompleto na forma de linhas de zeros e uns, com placeholders (`_`) para os valores desconhecidos.
O objetivo é definir as regras do quebra-cabeça binário, que permitirão que os testes descubram os valores dos placeholders (isso não é tarefa sua).
Sua implementação deve usar a [Programação em Lógica com Restrições sobre Domínios Finitos (CLP(FD))](https://www.swi-prolog.org/man/clpfd.html) do Prolog, que é perfeita para esse tipo de tarefa.
