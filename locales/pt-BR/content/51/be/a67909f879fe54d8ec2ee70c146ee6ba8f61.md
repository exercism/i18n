# Instruções

Receba uma lista aninhada e retorne uma única lista achatada com todos os valores, exceto nil/null.

O desafio é escrever uma função que aceite uma estrutura aninhada em forma de lista, com profundidade arbitrária, e retorne uma estrutura achatada sem nenhum valor nil/null.

Por exemplo:

entrada: [1,[2,3,null,4],[null],5]

saída: [1,2,3,4,5]
