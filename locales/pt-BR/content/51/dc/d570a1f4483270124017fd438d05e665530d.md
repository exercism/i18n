# Introdução

Charlists são criadas usando o sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Note que em versões mais antigas do Elixir, charlists são representadas como `'hello'` com aspas simples.
~~~~

Embora pareçam muito com strings, os dois tipos de dados são bem diferentes entre si. Uma charlist é uma lista de inteiros. Os inteiros representam os valores Unicode de um determinado caractere, também conhecidos como pontos de código.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Você pode colocar `?` antes de um caractere para obter o ponto de código dele.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Como charlists são listas, você pode trabalhar com elas exatamente como com qualquer outra lista, usando recursão e correspondência de padrões.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Você pode concatenar duas listas usando `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Quanto mais longa for a primeira lista, mais lenta será a concatenação, então evite ficar acrescentando a listas de comprimento arbitrário.
