# Sobre

Para que um objeto possa ser comparado a outro objeto, ele precisa implementar a interface `IComparable<T>`.
Essa interface tem um único método que precisa ser implementado: `int CompareTo(T other)`.

O método `CompareTo` tem três valores de retorno possíveis:

- Valor menor que zero: o objeto atual é menor que o outro objeto.
- Valor maior que zero: o objeto atual é maior que o outro objeto.
- Valor igual a zero: o objeto atual é igual ao outro objeto.

```csharp
public class Book : IComparable<Book>
{
    public int PageCount { get; set; }

    public int CompareTo(Book other)
    {
        // If other is not a valid object reference, this instance is greater.
        if (other == null) return 1;

        // Compare books using their number of pages
        return PageCount.CompareTo(other.PageCount);
    }
}

var smallBook = new Book { PageCount = 99 };
var largeBook = new Book { PageCount = 3333 };

smallBook.CompareTo(largeBook);
// => -1
```
