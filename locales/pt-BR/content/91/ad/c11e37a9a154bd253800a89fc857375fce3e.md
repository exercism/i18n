# Sobre

Um `SYMBOL:` não *guarda* um valor: é só um nome. O valor fica em um namespace, e o nome funciona como chave para acessá-lo.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Dois escopos:

- **global**: escrito e lido com `set-global`, `get-global` e `change-global`. Os valores persistem enquanto o processo estiver rodando.
- **dinâmico**: escrito e lido com `set`, `get` e `change`. As vinculações duram o tempo de uma forma `with-variable`, o que permite que o código externo "injete" um valor visto pelo código interno sem mudar todas as assinaturas no meio do caminho.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:` e `SYMBOLS:` declaram símbolos no momento em que o vocabulário é carregado, o que os torna referências compartilháveis entre arquivos.
