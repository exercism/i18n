# Instruções

Implemente um avaliador para um subconjunto muito simples de Forth.

[Forth][forth]
é uma linguagem de programação baseada em pilha.
Implemente um avaliador bem básico para um pequeno subconjunto de Forth.

Seu avaliador precisa dar suporte às seguintes palavras:

- `+`, `-`, `*`, `/` (aritmética de inteiros)
- `DUP`, `DROP`, `SWAP`, `OVER` (manipulação de pilha)

Seu avaliador também precisa dar suporte à definição de novas palavras usando a sintaxe habitual: `: word-name definition ;`.

Para simplificar, o único tipo de dado que você precisa dar suporte é inteiros com sinal de pelo menos 16 bits.

Use as seguintes regras para a sintaxe: um número é uma sequência de um ou mais dígitos (ASCII), e uma palavra é uma sequência de uma ou mais letras, dígitos, símbolos ou sinais de pontuação que não seja um número.
(O Forth provavelmente usa regras um pouco diferentes, mas isso é o suficientemente próximo.)

As palavras não diferenciam maiúsculas de minúsculas.

[forth]: https://en.wikipedia.org/wiki/Forth_%28programming_language%29
