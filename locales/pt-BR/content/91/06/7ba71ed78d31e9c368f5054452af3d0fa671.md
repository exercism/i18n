# Instruções

Era uma vez um programador excêntrico que morava numa casa estranha com janelas com grades.
Um dia ele aceitou um trabalho de um site de vagas para construir um robô de festa.
O robô deveria cumprimentar as pessoas e ajudá-las a chegar aos seus lugares.
A primeira edição era muito técnica e deixava evidente a falta de interação humana do programador.
Parte disso também foi parar na edição seguinte.

## 1. Dê as boas-vindas a um novo convidado na festa

Implemente a função `Welcome` para retornar uma mensagem de boas-vindas usando o nome fornecido:

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. Dê as boas-vindas a um novo convidado que faz aniversário hoje

Implemente a função `HappyBirthday` para retornar uma mensagem de aniversário usando o nome e a idade da pessoa.
Infelizmente o programador é um pouco exibido, então o robô precisa demonstrar que sabe o aniversário de cada convidado.

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. Dê as direções

Implemente a função `AssignTable` para dar as direções.
Ela deve aceitar 5 parâmetros.

- O nome do novo convidado a cumprimentar (`string`)
- O número da mesa (`int`)
- O nome de quem senta ao lado (`string`)
- A direção onde encontrar a mesa (`string`)
- A distância até a mesa (`float64`)

O formato exato do resultado pode ser visto no exemplo abaixo.

O robô informa o número da mesa em um formato de 3 dígitos.
Se o número tiver menos de 3 dígitos, ele recebe zeros à esquerda até ficar com 3 dígitos (por exemplo, 3 vira 003).
O robô também menciona a distância da mesa.
Felizmente, só com uma precisão limitada a 1 dígito.

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
