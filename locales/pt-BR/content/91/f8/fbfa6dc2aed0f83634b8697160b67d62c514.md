# Sobre

Números de ponto flutuante são números fracionários ou inteiros que incluem um ponto decimal (como `3.14`, `-1.7`, `99.99`, `2048.0`)

O tipo float em Common Lisp é subdividido em vários subtipos, cada um com suas próprias características e precisão: short-float, single-float, double-float e long-float.

O subtipo short-float normalmente ocupa a menor quantidade de memória e oferece a menor precisão entre os quatro subtipos. Ele é adequado para situações em que o uso de memória é uma preocupação, mas uma precisão menor é aceitável.

O subtipo single-float oferece um equilíbrio entre uso de memória e precisão. Ele é usado com frequência em cálculos de ponto flutuante de propósito geral.

O subtipo double-float oferece uma precisão maior em comparação com o single-float e é adequado para aplicações que exigem cálculos mais precisos, como computação científica e simulações numéricas.

O subtipo long-float oferece a maior precisão entre os quatro subtipos, mas pode exigir mais memória do que os outros. Ele costuma ser usado em aplicações especializadas que demandam cálculos extremamente precisos.

Esses subtipos permitem que quem programa em Common Lisp escolha o nível adequado de precisão e de uso de memória de acordo com as necessidades de cada aplicação.

Em geral, se você estiver trabalhando apenas com números inteiros, prefira usar inteiros, porque eles não sofrem a mesma perda de precisão que os números de ponto flutuante sofrem ao longo de muitos cálculos.

## Referência

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
