# Debug

Quando um teste falha, uma mensagem é exibida descrevendo o que deu errado e com qual entrada. Além disso, você pode aproveitar o fato de que a [saída do console][fmt-println] também é exibida.

Você pode escrever no console usando:

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

Observação: ao depurar com o editor do navegador, usar, por exemplo, `fmt.Print` não adiciona uma quebra de linha depois da saída, o que pode provocar um bug no `go test --json` e deixar a saída dos testes bagunçada.
