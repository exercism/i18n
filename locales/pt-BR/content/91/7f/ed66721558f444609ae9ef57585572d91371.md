# Dicas

## Geral

- No ['Guia de primeiros passos'][guide] do Elixir há uma boa revisão sobre funções nomeadas.

## 1. Crie a resposta quando o palpite for igual ao número secreto

- Você pode usar um [guard][guard] para verificar se os números são iguais com `===/2`.

## 2. Crie a resposta quando o palpite for maior que o número secreto

- Você pode adicionar uma [cláusula de função][multiple-fn-clauses] e [guards][guard] para verificar se o palpite é maior `>/2` que o número secreto.

## 3. Crie a resposta quando o palpite for menor que o número secreto

- Você pode adicionar uma [cláusula de função][multiple-fn-clauses] e [guards][guard] para verificar se o palpite é menor `</2` que o número secreto.

## 4. Crie as respostas quando o palpite for um a mais ou um a menos que o número secreto

- Você pode adicionar uma [cláusula de função][multiple-fn-clauses] e [guards][guard] para verificar se o palpite é um a menos ou um a mais que o número secreto.
- As expressões de guard podem usar `and/2` ou `or/2` para combinar expressões booleanas.
- Preste atenção na ordem das cláusulas de função.

## 5. Crie a resposta quando não houver palpite

- Você pode usar um [argumento padrão][default-arg] para o palpite. O valor padrão não precisa ser um número inteiro.
- Use um cabeçalho de função antes de todas as outras cláusulas de função para definir o argumento padrão.

[default-arg]: https://hexdocs.pm/elixir/modules-and-functions.html#default-arguments
[guard]: https://hexdocs.pm/elixir/Kernel.html#guards
[guide]: https://hexdocs.pm/elixir/modules-and-functions.html#function-definition
[multiple-fn-clauses]: https://hexdocs.pm/elixir/modules-and-functions.html#function-definition
