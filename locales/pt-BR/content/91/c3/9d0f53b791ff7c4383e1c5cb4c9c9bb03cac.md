# Instruções

Elyse, aspirante a mágica, continua seu treinamento.
Ela vai receber vários baralhos de cartas com os quais precisa realizar seus truques.
Para facilitar um pouco as coisas, ela usa apenas as cartas de 1 a 10.
Ela tem apenas uma carta de cada, não há duplicatas em seus baralhos.

Neste exercício, use métodos da biblioteca Base do Julia para analisar o conteúdo de um array.

## 1. Determinar se uma carta está presente

Elyse quer determinar se uma carta está presente no baralho, ou seja, se o baralho contém um número específico.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. Encontrar a posição de uma carta

Elyse quer saber a posição (índice) de uma carta no baralho.
Se a carta não estiver no baralho, retorne `nothing`.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. Determinar se cada carta é par

Elyse quer saber se todas as cartas são pares, ou seja, se cada número do baralho é par.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. Verificar se o baralho contém uma carta de valor ímpar

Elyse quer saber se há um número ímpar no baralho.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. Determinar a posição da primeira carta que é par

Elyse quer saber a posição da primeira carta que é par.
Se não houver cartas pares no baralho, retorne `nothing`.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. Obter a primeira carta ímpar do baralho

Elyse quer saber o valor da primeira carta que é ímpar.
Se não houver cartas ímpares no baralho, retorne `nothing`.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
