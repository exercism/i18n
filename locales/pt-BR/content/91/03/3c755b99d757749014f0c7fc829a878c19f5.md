# Adendo às instruções

## Implementação

Este problema pode ser resolvido facilmente usando a [função `sqrt` integrada do Roc](sqrt).

No entanto, gostaríamos que você considerasse o desafio de resolver este exercício sem usar funções integradas nem módulos.

Embora exista uma fórmula matemática que encontra a raiz quadrada de _qualquer_ número, optamos por ter apenas [números naturais][natural-number] (inteiros positivos) como soluções.

[sqrt]: https://www.roc-lang.org/docs/main/Num/#F64.sqrt
[natural-number]: https://en.wikipedia.org/wiki/Natural_number
