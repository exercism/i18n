# Instruções

Como entusiasta de xadrez, você quer escrever a sua versão do jogo.
Sim, pode já haver várias implementações de xadrez disponíveis online, mas a sua vai ser única!

Você começa implementando um sistema básico de movimento para as peças.

O jogo de xadrez será disputado em um tabuleiro de oito casas de largura por oito casas de comprimento.
As casas são identificadas por uma letra e um número.

## 1. Defina os intervalos de fileiras e colunas

O jogo vai precisar armazenar as fileiras do tabuleiro.
As fileiras são as linhas do tabuleiro e são numeradas de 1 a 8.

O jogo também vai precisar armazenar as colunas do tabuleiro.
As colunas são identificadas pelas letras de A a H.

Defina as constantes `Chess::RANKS` e `Chess::FILES`, que armazenam o intervalo de fileiras e de colunas, respectivamente.

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Verifique se uma casa é válida

O jogo vai precisar verificar se uma casa é válida.
Uma casa é válida se a fileira e a coluna estiverem dentro dos intervalos das fileiras e das colunas.

Defina o método `Chess.valid_square?`, que recebe os argumentos `rank`, que contém um int da fileira, e `file`, que contém um char da coluna.
O método deve retornar `true` se a fileira e a coluna estiverem dentro do intervalo das fileiras e das colunas, e retornar `false` caso contrário.

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. Obtenha o apelido do jogador

O jogo vai precisar obter o apelido do jogador.
O apelido é formado pelos dois primeiros caracteres do primeiro nome do jogador e pelos dois últimos caracteres do sobrenome.
O apelido deve ser escrito em maiúsculas.

Defina o método `Chess.nickname`, que recebe os argumentos `first_name`, que contém uma string com o primeiro nome do jogador, e `last_name`, que contém uma string com o sobrenome do jogador.
O método deve retornar o apelido do jogador como uma string em maiúsculas.

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Crie a mensagem de movimento

O jogo vai precisar criar uma mensagem para um movimento, dizendo qual jogador se moveu para qual casa.
A mensagem deve usar o apelido do jogador e a casa para onde ele se moveu.
O jogo também deve determinar se o movimento é válido, verificando se a coluna e a fileira da casa estão dentro dos intervalos das colunas e das fileiras.

Se o movimento for válido, a mensagem deve ser: `"{nickname} moved to {square}"`
Se o movimento for inválido, a mensagem deve ser: `"{nickname} attempted to move to {square}, but that is not a valid square"`

Defina o método `Chess.move_message`, que recebe os argumentos `first_name`, que contém uma string com o primeiro nome do jogador, `last_name`, que contém uma string com o sobrenome do jogador, e `square`, que contém uma string com a casa para onde o jogador se moveu.
O método deve retornar a mensagem do movimento como uma string.

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
