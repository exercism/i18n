# Dicas

## Geral

- `bitor`, `bitand`, `bitxor`, `bitnot` e `shift` ficam todos em
  [`math`][math].
- `bits` está em [`math.bitwise`][bitwise].
- Uma das entradas de teste é um valor `Int32` negativo, então certifique-se
  de que seu `shift-back` produza um deslocamento à direita *lógico*
  (preenchimento com zeros), não aritmético.

## 1. Desloque os bits de volta

- `shift` recebe uma quantidade *com sinal*: uma quantidade negativa desloca
  para a direita.
- Para um valor positivo, `value amount neg shift` já dá o resultado
  esperado.
- Para um valor negativo, `shift` faria extensão de sinal. Use `32 bits`
  primeiro para reinterpretar o valor como um inteiro sem sinal de 32 bits, e
  só então desloque: o resultado fica não negativo e preenche com zeros
  naturalmente.

## 2. Defina alguns bits

- Um bit é definido ao fazer OR com uma máscara. `bitor` retira os dois
  valores da pilha e deixa o resultado.

## 3. Inverta bits específicos

- O ou-exclusivo de `value` e `mask` inverte os bits onde a máscara é 1 e
  deixa os outros como estão. `bitxor` é a palavra.

## 4. Limpe bits específicos

- O `bitand` sozinho mantém os bits que são 1 nos dois operandos, o oposto
  do que você quer. Inverta a máscara primeiro com `bitnot` e depois use
  `bitand`.
