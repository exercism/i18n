# Introdução

## Operações bit a bit

As operações bit a bit permitem manipular dígitos individuais dentro de números binários.

O Elm fornece vários operadores bit a bit em seu [módulo Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

### Operações básicas

Modificar bits individuais de um número é chamado de _mascaramento_.
Uma _máscara_ é um número em que bits específicos foram definidos de uma maneira específica para manipular outro número usando operadores bit a bit como `and`, `or` e `xor`.

#### and

`and` combina dois números mantendo apenas os bits que são `1` nos dois.
Isso é útil para verificar se um bit individual está definido.
Por exemplo, para verificar se o quarto bit de um número está definido como `1`, aplique `and` nele com uma máscara `01000` (`8` em decimal) e veja se o resultado é diferente de zero:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

#### or

`or` combina dois números definindo cada bit como `1` se ele for `1` em um dos números ou em ambos.
Isso é útil para definir um bit específico como `1`.
Por exemplo, para definir o segundo bit em `10101`, aplique `or` nele com a máscara `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

#### Ou exclusivo (xor)

`xor` combina dois números definindo cada bit como `1` se ele for `1` em um número, mas `0` no outro.
Isso é útil para inverter um bit para seu valor oposto:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

#### Complemento

`complement` inverte cada bit de um número (`0` se torna `1`, `1` se torna `0`).

Observe que isso fará com que números positivos se tornem negativos e números negativos se tornem positivos.
Isso acontece porque números negativos em binário são representados com `1` na posição mais à esquerda.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

#### Deslocamento de bits

Os operadores a seguir movem bits para a esquerda ou para a direita em um número especificado de posições, multiplicando ou dividindo efetivamente por potências de 2.

`shiftLeftBy` move bits para a esquerda, preenchendo com `0` do lado direito.
Por exemplo, para deslocar `21` três posições para a esquerda:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Isso é o mesmo que dizer `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`: move bits para a direita:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Deslocar duas posições para a direita é o mesmo que divisão inteira por 4.

Observe que essa função duplica qualquer valor que esteja no bit mais à esquerda.
Assim, números negativos continuarão negativos:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Se você quiser deslocar para a direita e preencher com zeros, use `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
