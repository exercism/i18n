# Sobre

[Strings][strings] em Haxe são objetos imutáveis que representam texto como uma sequência de caracteres Unicode (letras, dígitos, pontuação etc.). Aspas duplas são usadas para definir uma instância de `string`:

```haxe
var fruit:String = "Apple";
```

É possível manipular uma string chamando um de seus [métodos ou propriedades][string-api]. Como valores de string nunca podem mudar depois de serem definidos, todos os métodos de manipulação de string retornam uma nova string.

Uma string é delimitada por aspas duplas (`"`). Alguns caracteres especiais precisam de [escape][escaping] usando o caractere barra invertida (`\`). Além disso, strings em Haxe são multilinha e permitem construir literais de string longos facilmente:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

A maneira mais simples de concatenar strings é usando o [operador `+`][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Para formatação de string mais complexa, prefira a [interpolação de string][interpolation]. Isso é feito envolvendo a string em aspas simples (`'`) e usando o cifrão (`$`) para acionar a interpolação de variáveis. Também é possível avaliar expressões completas usando `${expr}`, onde `expr` é qualquer expressão Haxe válida:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
