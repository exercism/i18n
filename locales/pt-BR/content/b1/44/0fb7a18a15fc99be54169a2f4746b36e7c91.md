# Dicas

## Geral

- Não se preocupe em como os argumentos são obtidos, concentre-se apenas em combinar os argumentos para retornar o resultado esperado.
- Unison tem [regras específicas de precedência de operadores][operator-precedence], lembre-se de usar parênteses se precisar ordenar a aplicação de funções de outra forma

## 1. Defina se o Pac-Man pode comer um fantasma

- Você precisa definir uma função com 2 argumentos. O primeiro argumento é um valor [boolean][boolean], que indica se o pac-man tem uma pílula de poder ativa. O segundo argumento é um valor [boolean][boolean], que indica se o pac-man está tocando um fantasma.
- A função deve retornar um valor [boolean][boolean].
- Você pode usar o operador [boolean][boolean] `&&` para combinar os argumentos e obter um resultado.

## 2. Defina se o Pac-Man marca pontos

- Você precisa definir uma função com 2 argumentos. O primeiro argumento é um valor [boolean][boolean], que indica se o pac-man está tocando uma pílula de poder. O segundo argumento é um valor [boolean][boolean], que indica se o pac-man está tocando um ponto.
- A função deve retornar um valor [boolean][boolean].
- Você pode usar o operador [boolean][boolean] `||` para combinar os argumentos e obter um resultado.

## 3. Defina se o Pac-Man perde

- Você precisa definir uma função com 2 argumentos. O primeiro argumento é um valor [boolean][boolean], que indica se o pac-man tem uma pílula de poder ativa. O segundo argumento é um valor [boolean][boolean], que indica se o pac-man está tocando um fantasma.
- A função deve retornar um valor [boolean][boolean].
- Você pode usar os operadores [boolean][boolean] `&&` e `not` para combinar os argumentos e obter um resultado.

## 4. Defina se o Pac-Man vence

- Você precisa definir uma função com 3 argumentos. O segundo argumento é um valor [boolean][boolean], que indica se o pac-man comeu todos os pontos. O primeiro argumento é um valor [boolean][boolean], que indica se o pac-man tem uma pílula de poder ativa. O segundo argumento é um valor [boolean][boolean], que indica se o pac-man está tocando um fantasma.
- A função deve retornar um valor [boolean][boolean].
- Você pode usar os operadores [boolean][boolean] `&&` e `not` para combinar os argumentos e os resultados das funções invocadas.

[boolean]: https://elixir-lang.org/getting-started/basic-types.html#booleans
