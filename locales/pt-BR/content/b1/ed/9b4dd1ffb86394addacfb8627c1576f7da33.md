# Instruções

Neste exercício, você vai implementar um `TranslationService` que oferece serviços básicos de tradução para membros gratuitos e tradução avançada para membros premium, com garantias de qualidade.

**A API**

Você encontrou uma API de tradução do espaço sideral que atende qualquer `request` de tradução em um tempo razoável.
Você quer tirar proveito disso.
Os tradutores espaciais são extremamente volúveis e odeiam redundância, então eles também oferecem satélites de _armazenamento da API_, onde você pode usar `fetch` para obter traduções anteriores sem incomodá-los.

**_Buscando uma tradução_**

`api.fetch(text)` busca uma tradução de `text` no _armazenamento da API_ e retorna uma `promise` que fornece dois valores:

- `translation`: a tradução em si
- `quality`: a qualidade expressa como um número

Se uma tradução não for encontrada no _armazenamento da API_, a API lança um erro `NotAvailable`.
É possível adicionar traduções usando o método `api.request`.
Se o 'text' não puder ser traduzido, a API lança um erro `Untranslatable`.

```javascript
api.fetch('jIyaj');
// => Promise({ resolved: 'I understand' })
```

**_Solicitando uma tradução_**

Algumas traduções certamente existem, mas ainda não foram adicionadas ao _armazenamento da API_. É essa a diferença entre `NotAvailable` ( não está no armazenamento, mas pode ser solicitada ) e `Untranslatable` ( não pode ser traduzida ).

`api.request(text, callback)` solicita que uma tradução de `text` seja feita e adicionada ao _armazenamento da API_.
Ao terminar, a função `callback` é chamada.

- Em caso de sucesso, `undefined` é passado para o `callback`: isso indica que a tradução foi bem-sucedida e pode ser acessada usando o método `api.fetch`.
- Em caso de falha, um `error` é passado para o `callback`: isso indica que algo deu errado.
  A API do espaço sideral é _instável_, o que significa que a API falha com frequência.
  Se isso acontecer, tudo bem chamar `api.request` de novo.

```javascript
api.request('majQa’', callback);
// => undefined
//
// later: the passed callback is called with undefined
//        because it was successful.
```

**⚠ Atenção! ⚠**

<!-- prettier-ignore-start -->
~~~~exercism/caution
A API faz sua mágica teleportando os vários tradutores quando chega um `request`.
Essa é uma ação muito custosa, então ela não deveria ser chamada quando uma tradução *está* disponível.
Infelizmente, nem todo mundo lê o manual, então existe um sistema para expulsar quem age de má-fé.

Se um `api.request` for chamado para um `text` que está disponível, a API lança um `AbusiveClientError` para essa chamada, **e para todas as chamadas seguintes**.
Garanta que você *nunca* solicite uma tradução se algo já foi traduzido.
~~~~

## 1. Busque uma tradução, ignorando a qualidade

O serviço gratuito só fornece traduções que já estão no _armazenamento da API_.

Implemente um método `free(text)` que oferece aos membros gratuitos as traduções que já existem no _armazenamento da API_.
Ignore a qualidade e repasse qualquer erro lançado pela API.

- Retorna a tradução se ela puder ser obtida, independentemente da qualidade
- Repassa qualquer erro da API de tradução
- Usa o método `api.fetch` (`api.fetch` retorna uma `promise`)

```javascript
service.free('jIyaj');
// => Promise<...> resolves "I understand."

service.free("jIyajbe'");
// => Promise<...> rejects Error("Not yet translated")
```

## 2. Busque um lote de traduções, tudo ou nada

Implemente um método `batch([text, text, ...])` para membros gratuitos que traduz um array de textos usando o serviço gratuito, retornando todas as traduções ou um único erro.

- Resolve com todas as traduções (na mesma ordem), se todas estiverem disponíveis
- Rejeita com o primeiro erro encontrado
- Rejeita com um erro `BatchIsEmpty` se nenhum texto for passado

```javascript
service.batch(['jIyaj', "majQa'"]);
// => Promise<...> resolves ["I understand.", "Well done!"]

service.batch(['jIyaj', "jIyajbe'"]);
// => Promise<...> rejects new Error("Not yet translated")

service.batch([]);
// => Promise<...> rejects BatchIsEmpty()
```

## 3. Solicite uma tradução, tentando novamente no máximo 2 vezes

Implemente um método `request(text)` para usuários premium que _solicita_ que uma tradução seja adicionada ao _armazenamento da API_.
A solicitação deve tentar novamente de forma automática se ocorrer uma falha.
Ela não deve fazer mais de **3 chamadas** para a mesma solicitação (_não irrite os tradutores espaciais!!!_).

- Se `api.request` não retornar um erro, resolva com `undefined`
- Se `api.request` retornar um erro, tente novamente no máximo duas vezes
- Se as tentativas acabarem, rejeite com o último erro recebido

```javascript
service.request("jIyajbe'");
// => Promise<...> resolves (with nothing), can now be retrieved using the fetch API
```

## 4. Busque uma tradução, inspecione a qualidade ou solicite-a

Implemente um método `premium(text, quality)` para usuários premium que busca uma tradução.
Se a tradução for `NotAvailable`, solicite-a e busque-a depois que ela tiver sido adicionada ao _armazenamento da API_.
O método só deve retornar a tradução se ela atingir um determinado limite de `quality`.

- Se `api.fetch` resolver, verifique a qualidade antes de resolver
- Se `api.fetch` rejeitar, _solicite_ a tradução
- Se `api.request` rejeitar, repasse o erro

```javascript
service.premium("jIyajbe'", 100);
// => Promise<...> resolves "I don't understand."

service.premium("'arlogh Qoylu'pu'?", 100);
// => Promise<...> rejects QualityThresholdNotMet()

service.premium("'arlogh Qoylu'pu'?", 40);
// => Promise<...> resolves "What time is it?"
```

**Obs.**

<!-- prettier-ignore-start -->
~~~~exercism/note
The correct translation of `'arlogh Qoylu'pu'?` is **How many times has it been heard?**.
~~~~
