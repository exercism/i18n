# Dicas

## Geral

- Todas as palavras de leitura e escrita ficam em [`io.files`][io.files]; a codificação `utf8` que todas elas recebem vem de [`io.encodings.utf8`][utf8].

## 1. Leia cada leitura

- `file-lines` retorna um array de linhas com as quebras de linha removidas.

## 2. Encontre a leitura mais recente

- Leia as linhas com `file-lines` e depois pegue a última com a palavra `last` (de `sequences`).

## 3. Leia o log bruto

- `file-contents` retorna o arquivo como uma única string, com as quebras de linha e tudo.

## 4. Registre uma leitura

- Abra o arquivo para anexar e use `print` na leitura dentro da quotation:
  `with-file-appender ( path encoding quot -- )`. A leitura é usada dentro
  da quotation, enquanto o caminho é consumido antes dela, então os locais `::`
  mantêm o corpo legível:
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`.

## 5. Reescreva o log

- `set-file-lines` escreve cada elemento de uma sequência em sua própria linha, adicionando as quebras de linha para você.
