# Introdução

Trabalhar com dados binários é um conceito importante em qualquer linguagem, e o Elixir oferece uma sintaxe elegante para escrever, fazer pattern matching e construir dados binários.

Em Elixir, dados binários são chamados de bitstring. O _tipo_ de dado binário (que não deve ser confundido com dados binários em geral) é uma forma específica de bitstring, que vamos discutir em um exercício mais adiante.

Literais de bitstring são definidos com a forma especial de bitstring `<<>>`. Ao definir um literal de bitstring, você o define em segmentos. Cada segmento tem um valor e um tipo, separados pelo operador `::`. O tipo especifica quantos bits serão usados para codificar o valor. O tipo pode ser omitido por completo, e nesse caso o padrão é um valor inteiro de 8 bits.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

Especificar o tipo como `::1` é uma forma abreviada de escrever `::size(1)`. Você precisa usar a sintaxe mais longa se o tamanho em bits vier de uma variável.

## Binário

Ao escrever literais inteiros binários, podemos escrevê-los diretamente em notação de base 2 prefixando o literal com `0b`. Repare que eles serão de qualquer forma exibidos como números decimais quando impressos nos resultados dos testes ou ao usar o iex.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## Truncamento

Se o valor do segmento ultrapassar a capacidade do tipo do segmento, ele será truncado pela esquerda.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## Adicionar no início e no fim

Você pode tanto adicionar no início quanto no fim de uma bitstring existente usando a forma especial. O tipo `::bitstring` deve ser usado na bitstring existente se ela tiver tamanho desconhecido.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## Concatenação

Podemos concatenar bitstrings guardadas em variáveis usando a forma especial. O tipo `::bitstring` deve ser usado ao concatenar duas bitstrings de tamanhos desconhecidos.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## Pattern matching

Também é possível fazer pattern matching para obter valores da forma especial. Você precisa saber o número de bits de cada fragmento que quer capturar, com uma exceção: o tipo `::bitstring` pode ser usado para fazer pattern matching em uma bitstring de tamanho desconhecido, mas isso só pode ser usado no último fragmento.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## Inspecionar bitstrings

~~~~exercism/note
As bitstrings podem ser impressas (pelo test runner ou no iex) em um
formato diferente do formato que foi usado para criá-las. Isso costuma
causar confusão quando se está aprendendo bitstrings.
~~~~

Por padrão, as bitstrings são exibidas em fragmentos de 8 bits (um byte), mesmo que você as tenha criado com fragmentos de tamanho diferente.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

Se você criar uma bitstring que representa uma string imprimível codificada em UTF-8, ela é exibida como uma string.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
