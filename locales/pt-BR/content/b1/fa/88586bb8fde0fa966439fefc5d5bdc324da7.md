# concatenação de strings

A concatenação de strings é perfeitamente válida no Crystal, mas uma forma mais comum de compor uma string é com [interpolação de strings][interpolation].
Por exemplo:

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
