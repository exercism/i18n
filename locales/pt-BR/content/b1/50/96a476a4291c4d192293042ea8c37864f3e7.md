# Instruções

Neste exercício, você vai escrever código para analisar uma linha de montagem em uma fábrica de carros.

## 1. Calcule o número de carros funcionais produzidos por hora

Implemente uma função que recebe o número de carros produzidos por hora e a taxa de sucesso e calcula o número de carros produzidos com sucesso por hora. A taxa de sucesso é dada como uma porcentagem, de `0` a `100`:

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**Observação:** o valor de retorno deve ser um número de ponto flutuante.

## 2. Calcule o número de carros funcionais produzidos por minuto

Implemente uma função que recebe o número de carros produzidos por hora e a taxa de sucesso e calcula quantos carros são produzidos com sucesso a cada minuto:

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**Observação:** o valor de retorno deve ser um número inteiro.

## 3. Calcule o custo de produção

Cada carro normalmente custa $10.000 para ser produzido individualmente, independentemente de ser bem-sucedido ou não. Mas com um pouco de planejamento, 10 carros podem ser produzidos juntos por $95.000. Por exemplo, 37 carros podem ser produzidos da seguinte forma:
37 = 3 x grupos de dez + 7 carros individuais

Então o custo para 37 carros é:
3 \* 95,.000 + 7 \* 10.000 = 355.000

Implemente uma função que calcula o custo de produzir um número de carros, independentemente de serem bem-sucedidos ou não:

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**Observação:** o valor de retorno deve ser um número inteiro.
