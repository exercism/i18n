# Apêndice das instruções

## Registradores

| Registrador | Uso       | Tipo    | Descrição                                   |
| -------- | --------- | ------- | ------------------------------------------- |
| `$a0`    | entrada   | endereço | string de caracteres hexadecimais terminada em nulo |
| `$v0`    | saída     | inteiro | valor decimal da string de entrada          |
| `$t0-9`  | temporário | qualquer | usados para armazenamento temporário        |
