# Introdução

## Recursão

Chamamos de recursão a capacidade de algo ser definido em termos de si mesmo. Em F#, a recursão aparece com mais frequência em funções recursivas, ou seja, funções que chamam a si mesmas.

Uma função recursiva precisa ter pelo menos um _caso base_ e pelo menos um _caso recursivo_. Um _caso base_ retorna um valor sem chamar a função de novo. Um _caso recursivo_ chama a função de novo, modificando a entrada para que, em algum momento, ela corresponda ao caso base.

Funções recursivas são definidas como funções normais, mas com o modificador `rec`. Sem esse modificador, uma função _não_ consegue chamar a si mesma, e qualquer tentativa de fazer isso resulta em um erro de compilação. Por isso, a recursão precisa ser habilitada explicitamente.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

O F# também dá suporte a tipos recursivos por meio de uniões discriminadas. Em uma união discriminada recursiva, um ou mais casos fazem referência à própria união discriminada nos seus dados. Assim como as funções recursivas, os tipos recursivos precisam ter um caso base. Diferentemente das funções recursivas, os tipos recursivos não usam a palavra-chave `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
