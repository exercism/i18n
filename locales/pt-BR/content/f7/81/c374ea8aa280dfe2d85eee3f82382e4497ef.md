# Dicas

## Geral

- Leia sobre enumeráveis e streams no [guia oficial Getting Started][getting-started-streams].
- Leia a documentação oficial sobre [streams][stream].

## 1. Faça uma rolagem de dado de 6 lados

- Os ranges implementam o _protocolo Enumerable_.
- Existe uma [função embutida][enum-random] para escolher um valor aleatório de um enumerável.

## 2. Continue rolando enquanto tirar seis

- Existe uma [função embutida][stream-repeatedly] que cria um stream gerado pela chamada repetida de uma função.
- Existe uma [função embutida para streams][stream-transform] que funciona de modo semelhante a `Enum.reduce/3`.

## 3. Permita usar um dado viciado

- Use o [operador de captura][special-forms-capture] para capturar a função `roll/0`.
