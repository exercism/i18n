# Introdução

Às vezes, um estado precisa ser compartilhado entre várias palavras
sem precisar passá-lo pelos efeitos de pilha delas a cada vez.
As *variáveis dinâmicas* do Factor, declaradas com `SYMBOL:`, dão a cada
palavra acesso a um valor armazenado em um namespace.

```factor
USING: namespaces ;

SYMBOL: counter

0 counter set-global
counter [ 1 + ] change-global
counter get-global .       ! => 1
```

`set-global` e `get-global` operam no namespace global.
`set` e `get` operam no escopo dinâmico *atual* e são
normalmente usados dentro de um bloco `with-variable` quando você quer
uma associação com escopo em vez de uma que vale para todo o processo.

`SYMBOLS: a b c ;` declara vários símbolos de uma vez.
