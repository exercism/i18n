# Instruções

Você é um assistente de ensino corrigindo provas de estudantes.
Acompanhar os resultados manualmente está ficando tedioso e sujeito a erros.
Você decide tornar as coisas um pouco mais interessantes montando algumas funções para contar e calcular os resultados da turma.

## 1. Arredondar as notas

Você pode dar "crédito parcial" nas questões da prova, mas as notas gerais precisam ser `int`s.
Então, antes de fazer qualquer outra coisa com as notas da turma, você precisa percorrer as notas e transformar qualquer nota `float` em `int`. Para sua sorte, o Python tem a função embutida [`round()`][round] que você pode usar.

Crie a função `round_scores(student_scores)` que recebe uma `list` de `student_scores`.
Essa função deve _consumir_ a `list` de entrada e `return` uma nova lista com todas as notas convertidas para `int`s.
A ordem das notas na `list` resultante não é importante.

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. Estudantes que não passaram

Enquanto você corrigia a prova, percebeu que alguns estudantes não tiveram um desempenho tão bom quanto você esperava.
Mas você se distraiu e esqueceu de anotar exatamente _quantos_ estudantes.

Crie a função `count_failed_students(student_scores)` que recebe uma `list` de `student_scores`.
Essa função deve contar o número de estudantes que não têm notas suficientes para passar e retornar essa contagem como um número inteiro.
Um estudante precisa de uma nota maior que **40** para atingir a média de aprovação na prova.

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. O "melhor"

O professor que você está auxiliando quer encontrar o grupo de estudantes que tiveram "o melhor" desempenho nesta prova.
O que qualifica como "o melhor" varia, então você precisa encontrar as notas dos estudantes que são **maiores ou iguais** ao limite atual.

Crie a função `above_threshold(student_scores, threshold)` recebendo `student_scores` (uma `list` de notas) e `threshold` (o limite de "nota mais alta") como parâmetros.
Essa função deve retornar uma `list` com todas as notas que são `>=` a `threshold`.

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. Calculando conceitos por letra

O professor que você está auxiliando gosta de atribuir conceitos por letra além das notas numéricas.
Como os estudantes raramente tiram 100 em uma prova, os limites inferiores do "conceito por letra" são calculados com base na maior nota alcançada e aumentam de forma uniforme entre a maior nota e o limite de reprovação de **<= 40**.

Crie a função `letter_grades(highest)` que recebe a maior nota ("highest") da prova como argumento e retorna uma `list` de limites inferiores de nota para cada intervalo de conceito "no estilo americano": `["D", "C", "B", "A"]`.


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. Associar nomes às notas

Você tem uma lista de notas de prova em ordem decrescente, e outra lista de nomes de estudantes também ordenada de forma decrescente pelas notas da prova.
Você gostaria de associar cada nome de estudante à sua nota da prova e imprimir um ranking geral da turma.

Crie a função `student_ranking(student_scores, student_names)` com os parâmetros `student_scores` e `student_names`.
Associe cada nome de estudante na `list` student_names à sua nota da `list` student_scores.
Você pode assumir que cada `list` de argumento estará ordenada da maior nota para a menor nota.
A função deve retornar uma `list` de strings com o formato `<rank>. <student name>: <student score>`.

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. Uma nota "perfeita"

Embora uma nota "perfeita" de 100 seja rara em uma prova, é interessante saber se pelo menos um estudante conseguiu alcançá-la.

Crie a função `perfect_score(student_info)` com o parâmetro `student_info`.
`student_info` é uma `list` de listas contendo o nome e a nota de cada estudante: `[["Charles", 90], ["Tony", 80]]`.
A função deve `return` _o primeiro_ par `[<name>, <score>]` do estudante que tirou 100 na prova.

Se nenhuma nota 100 for encontrada em `student_info`, deve ser retornada uma lista vazia `[]`.

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```
