# Testes

Para executar os testes, siga estes passos:

- Vá até o diretório do problema (por exemplo, `~/Exercism/hello-world`).
- Inicie uma sessão do `jconsole` (por exemplo, digitando `jconsole` ou `ijconsole`) em um terminal.
- Carregue o arquivo da sua solução (por exemplo, `load 'hello-world.ijs'`)
- Carregue o framework de testes de unidade digitando `load  'general/unittest'`
- Teste sua solução digitando `unittest 'test.ijs'`.
<br></br>
- Como alternativa, é possível executar os testes em uma única linha, assim: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Testes ignorados

No início, apenas o teste inicial estará habilitado.
essa abordagem incentiva você a resolver o exercício passo a passo.
Cada teste inclui um substantivo acima da sua definição, com um nome terminando em _'\_ignore'_.
Para executar o teste, mude o valor dele para 0.

### Exemplo:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
