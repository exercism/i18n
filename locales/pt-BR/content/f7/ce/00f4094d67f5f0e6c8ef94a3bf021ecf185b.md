# Instruções complementares

## Instruções específicas da trilha

Você vai precisar implementar seu próprio operador de igualdade para o objeto `ComplexNumber`.
Isso traz o desafio de comparar dois números de ponto flutuante.
Pode ser útil usar o método `isApproximatelyEqual(to:absoluteTolerance:)`, que está na biblioteca [Numerics][swift-numberics].
Por questões de desempenho, você só terá acesso à parte `RealModule`.
Para importá-la, basta escrever: `import RealModule` no topo do arquivo.
Uma tolerância de `0.00001` deve ser suficiente para passar nos testes.
A biblioteca já está no projeto, então basta importá-la no seu arquivo.

Você também pode implementar seu próprio método para comparar os dois números complexos.

[swift-numberics]: https://github.com/apple/swift-numerics
