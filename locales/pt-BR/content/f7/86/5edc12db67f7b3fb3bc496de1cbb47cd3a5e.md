# Dicas

## Geral

- Não se preocupe com tipos específicos de número; use `Int32` e `Float64` por enquanto.
- Int32 e Float64 são os tipos de número padrão em Crystal, então você não precisa especificá-los.

## 1. Converta a temperatura de Celsius para Kelvin

- Você pode usar o operador aritmético (`+`) para somar números.

## 2. Arredonde a temperatura

- Você pode usar o método `round` para arredondar um número para um número específico de casas decimais.
- O método `round` recebe um argumento `places` que especifica para quantas casas decimais arredondar.

## 3. Converta a temperatura de Celsius para Fahrenheit

- Você pode usar o operador aritmético (`*`) para multiplicar números.
- Você pode usar parênteses (`()`) para agrupar operações.

## 4. Obtenha o número de sensores ausentes

- Você pode usar o operador aritmético (`-`) para subtrair números.
- Você pode usar o operador aritmético (`%`) para obter o resto de uma divisão.
