# Dicas

## 1. Defina se o Pac-Man pode comer um fantasma

* A função deve retornar um valor Boolean.
* Você pode usar o operador lógico `and` para combinar os argumentos e obter um resultado.

## 2. Defina se o Pac-Man pontua

* A função deve retornar um valor Boolean.
* Você pode usar o operador Boolean `or` para combinar os argumentos e obter um resultado.

## 3. Defina se o Pac-Man perde

* A função deve retornar um valor Boolean.
* Você pode usar os operadores Boolean `and` e `not` para combinar os argumentos e obter um resultado.

## 4. Defina se o Pac-Man vence

* A função deve retornar um valor Boolean.
* Você pode usar os operadores Boolean `and` e `not` para combinar os argumentos e os resultados de uma das funções implementadas anteriormente.
