# Instruções

Você tem uma boutique de moda online. Cada item do seu inventário é um array de 2 elementos `{ name price }`, e o inventário inteiro é um array de itens.

Um preço ausente é registrado como `f`.

## 1. Ordene o inventário por preço

Defina `sort-by-price` para retornar um novo array com os itens ordenados por preço, em ordem crescente.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. Encontre itens sem preço definido

Defina `with-missing-price` para retornar um array apenas com os itens cujo preço é `f`.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. Conte os itens caros

Defina `expensive-items` para receber um inventário e um limite de preço, e retornar quantos itens custam estritamente mais que o limite.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. Encontre o item mais barato

Defina `cheapest-item` para retornar o item com o menor preço. Itens sem preço (`f`) não aparecerão na entrada.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. Some todos os preços

Defina `total-price` para retornar a soma de todos os preços. Itens sem preço (`f`) não aparecerão na entrada.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. Formate um item como etiqueta de preço

Defina `format-price-tag` para retornar uma string no formato `"name: $price"` para um item. Itens sem preço (`f`) não aparecerão aqui.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
