# Dicas

## Geral

- Um [mapa][maps] é uma estrutura de dados associativa de pares chave-valor.
- O Elixir oferece [muitas funções úteis do módulo Map na biblioteca padrão][map-module].

## 1. Defina um novo mapa de recordes

- Deve retornar um [mapa][maps] vazio.
- Funções do [módulo Map][map-module] ou formas literais podem ser úteis.

## 2. Adicione jogadores ao mapa de recordes

- O mapa resultante deve ser retornado.
- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-put] coloca um valor em um mapa sob uma determinada chave.

## 3. Remova jogadores do mapa de pontuações

- O mapa resultante deve ser retornado.
- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-delete] exclui uma chave de um mapa.

## 4. Redefina a pontuação de um jogador

- O mapa resultante deve ser retornado com a pontuação do jogador redefinida para um valor inicial.
- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-put] coloca um valor em um mapa sob uma determinada chave.

## 5. Atualize a pontuação de um jogador

- O mapa resultante deve ser retornado com a pontuação atualizada do jogador.
- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-update] atualiza um valor em um mapa sob uma determinada chave.

## 6. Obtenha uma lista de jogadores

- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-keys] retorna uma lista com todas as chaves de um mapa.
