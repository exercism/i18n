# Instruções

Implemente um programa que traduz do inglês para o Pig Latin.

O Pig Latin é uma língua infantil inventada, feita de propósito para confundir.
Ela segue algumas regras simples (abaixo), mas quando é falada rápido fica muito difícil para quem não é criança (e para quem não é falante nativo) entender.

- **Regra 1**: Se uma palavra começa com um som de vogal, adicione o som "ay" ao final da palavra.
  Observe que "xr" e "yt" no início de uma palavra produzem sons de vogal (por exemplo, "xray" -> "xrayay", "yttria" -> "yttriaay").
- **Regra 2**: Se uma palavra começa com um som de consoante, mova esse som para o final da palavra e depois adicione o som "ay" ao final da palavra.
  Sons de consoante podem ser formados por várias consoantes, ou seja, um encontro consonantal (por exemplo, "chair" -> "airchay").
- **Regra 3**: Se uma palavra começa com um som de consoante seguido de "qu", mova esse som para o final da palavra e depois adicione o som "ay" ao final da palavra (por exemplo, "square" -> "aresquay").
- **Regra 4**: Se uma palavra contém um "y" depois de um encontro consonantal ou como a segunda letra de uma palavra de duas letras, ele produz um som de vogal (por exemplo, "rhythm" -> "ythmrhay", "my" -> "ymay").

Existem mais algumas regras para casos extremos, e também há variações regionais.
