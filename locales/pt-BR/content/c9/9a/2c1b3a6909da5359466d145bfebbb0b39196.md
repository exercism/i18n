# Introdução

## Let

A expressão `let` é usada para criar um escopo local e é útil em algumas situações:

- Para simplificar expressões
- Para nomear os resultados de expressões intermediárias
- Dividir uma expressão em partes menores quando ela está ficando grande

Você pode fazer quase tudo dentro de uma expressão `let`, incluindo desestruturação (mais detalhes sobre isso em exercícios posteriores), mas não é possível definir um novo Custom Type ou Type Alias.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
