# Listas

`LIST{T}` é uma coleção ordenada e que pode crescer, sustentada por um array que é substituído por um maior quando ele fica cheio.

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes[0]                     -- "muddy boots"
   notes[0] := "clean boots";
   notes.size
   notes.is_empty
   notes.has("clean boots")
   notes.remove_index(0);
```

## Array ou lista?

| | `ARRAY{T}` | `LIST{T}` |
| --- | --- | --- |
| tamanho | fixo na criação | muda |
| acrescentar | não | sim |
| remover | não | sim |
| indexação | `a[i]` | `l[i]` |
| custo extra | nenhum | um tamanho e espaço de sobra |

Use um `ARRAY` quando o tamanho é conhecido e definitivo: uma fila de dançarinos, uma semana de contagens. Use um `LIST` quando as coisas chegam ou vão embora.

## Modifica no lugar, não é funcional

`append`, `remove_index` e `[i] :=` alteram a própria lista. Não é preciso atribuir nada de volta, e uma lista entregue a uma rotina não fica a salvo disso.

Isso é o oposto de `FMAP` e `FSET`, e vale a pena deixar claro qual dos dois você tem em mãos. A regra geral: o `F` no início do nome indica funcional, e todo o resto altera no lugar.

Para entregar uma lista que ninguém possa estragar, entregue uma cópia:

```sather
   return notes.copy;
```

## O custo de acrescentar

Acrescentar é barato em média. Quando o array de apoio fica cheio, um novo, com o dobro do tamanho, é alocado e tudo é copiado. Então a maioria dos acréscimos não custa quase nada, e alguns poucos custam uma cópia. Ao longo de muitos acréscimos, isso dá uma média constante para cada um, e é por isso que se dobra o tamanho em vez de crescer um de cada vez.

`remove_index` não é barato: tudo depois da posição removida desloca uma casa para cima. Remover repetidamente do início de uma lista longa é lento de um jeito fácil de passar despercebido.

## Rotinas úteis

| Chamada | Faz |
| --- | --- |
| `l.append(x)` | adiciona ao final |
| `l.insert_before(i, x)` | adiciona em uma posição |
| `l.remove_index(i)` | retira uma posição |
| `l.has(x)` | está aí dentro? |
| `l.copy` | uma cópia independente |
| `l.str` | o conteúdo, entre chaves |
| `l.elt!`, `l.ind!` | percorre os valores, ou as posições |
