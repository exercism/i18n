# Introdução

Embora o Swift tenha muitos tipos diferentes, cada um deles se encaixa em uma de duas classificações: _tipos de valor_ e _tipos de referência_. No Swift, structs são tipos de valor, enquanto classes são tipos de referência.

A principal diferença entre tipos de valor e tipos de referência é que, quando um tipo de valor é atribuído a uma variável ou constante, ou passado para uma função, o que é atribuído ou passado é na verdade uma cópia do valor, e não aquele valor em si. Modificar uma cópia de um struct não afeta as outras cópias. Já com os tipos de referência, o que é atribuído ou passado é uma referência àquele valor, então dois nomes diferentes podem se referir à mesma instância de uma classe. Isso pode acabar modificando a instância original quando ela é acessada por outro nome.
