# JSON de transformação de combustível

## Enunciado do problema

Todo funcionário da ABC Corp recebe um auxílio combustível ilimitado. Os funcionários precisam enviar um registro toda vez que abastecem seus veículos. Esses registros são acrescentados ao mesmo arquivo JSON e processados no fim do mês.

Como membro da equipe de operações digitais, sua tarefa é ler esse arquivo JSON e escrever os resultados em outro arquivo JSON. O arquivo de saída deve conter uma entrada para cada funcionário com os seguintes detalhes:

- Número do funcionário
- Número de abastecimentos
- Custo total com combustível
- Total de galões
- Total de milhas acumuladas

Você recebe dois argumentos do tipo `string`.

1. Caminho do arquivo JSON de entrada.
1. Caminho do arquivo JSON de saída.

O arquivo JSON de entrada contém um array de objetos JSON. Cada objeto JSON tem o seguinte formato.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

Sua tarefa é transformar a entrada JSON no formato JSON a seguir e escrever o conteúdo no caminho informado. O arquivo de saída deve conter uma entrada para cada funcionário, ordenada de forma crescente pelo `employeeId`.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## Restrições

- Número de registros de abastecimento `n` no arquivo JSON de entrada:  0 <= n <= 1000
- Número de funcionários na empresa: 97
- O preço da gasolina é por galão
- Nenhum registro de abastecimento está faltando

## Dicas

- Use o [módulo `ballerina/io`](https://lib.ballerina.io/ballerina/io/latest) para ler e escrever arquivos JSON.
- Converta os valores JSON em tipos específicos da aplicação para trabalhar com os dados de forma segura em termos de tipos. Consulte o [exemplo de conversão para um tipo definido pelo usuário](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) em Ballerina By Examples (BBE) para mais informações.

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- [Desestruturar registros](https://ballerina.io/learn/by-example/destructure-records-using-query) pode ser útil para reduzir a verbosidade do código.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- Use funções com corpo de expressão para funções com uma única expressão. Por exemplo, funções que têm apenas a instrução de retorno.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
