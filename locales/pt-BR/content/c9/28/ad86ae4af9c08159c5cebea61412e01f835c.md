## Importação

Um módulo geralmente é carregado com a palavra-chave `use`.
Isso carrega o módulo e chama o método `import` dele, importando todos os símbolos exportados.

Os símbolos no array `@EXPORT` do pacote são importados por padrão.
Já os símbolos no array `@EXPORT_OK` do pacote precisam ser importados explicitamente.

Antes do Perl `v5.37`, um módulo precisava terminar com um valor verdadeiro (normalmente `1`) para indicar que tinha sido carregado com sucesso.
Isso não é necessário ao usar o recurso [`module_true`][module_true].

## Exportação

Para que um símbolo seja importado, ele primeiro precisa ser exportado.
O módulo [Exporter][Exporter] vem incluído no Perl e é uma das opções mais práticas para exportar.

Definindo o módulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Usando o módulo:
```perl
use Foo ('bar');

bar();
```

## Pragma

Um pragma é um módulo que influencia algum aspecto do comportamento do Perl.

Os pragmas [`strict`][strict] e [`warnings`][warnings] são bastante recomendados: o primeiro restringe construções inseguras e o segundo sinaliza possíveis problemas.
O pragma `strict` é ativado junto com `use v5.12` ou superior.
O pragma `warnings` é ativado junto com `use v5.35` ou superior.

O pragma [`feature`][feature] permite ativar recursos novos e experimentais do Perl.
Quando a palavra-chave `use` recebe uma versão específica do Perl, ela ativa o conjunto de recursos daquela versão.

## Módulos principais

Além do [Exporter][Exporter], o Perl tem uma grande variedade de [módulos principais][perl-core-modules] disponíveis para uso.
Alguns exemplos úteis para os exercícios que você pode encontrar aqui incluem [List::Util][List::Util], [Time::Piece][Time::Piece] e [Math::BigRat][Math::BigRat].

## CPAN

Além dos módulos principais, o [CPAN][metacpan] tem milhares de módulos adicionais criados pela comunidade Perl disponíveis para instalação.
A trilha de Perl usa um [cpanfile][test-runner-cpanfile] para instalar uma seleção de módulos que podem ser usados com o test runner de Perl do Exercism.
