# Recursos de aprendizagem recomendados

Bem-vindo ao aprendizado de ColdFusion (CFML)! O CFML é uma linguagem de script para a JVM, dinâmica e fracamente tipada. Ela tem dois tipos de arquivo diferentes. Os arquivos `.cfm` (ColdFusion markup)_ são puramente procedurais e usam a sintaxe baseada em tags para gerar HTML. Você usaria esses arquivos para as views se estivesse construindo um site:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

O outro tipo de arquivo é o `.cfc` (ColdFusion Component), e é assim que você declara uma classe. Os componentes são usados para lógica de negócio, modelos e controladores. Eles geralmente usam a sintaxe de script, que é parecida com JavaScript.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
