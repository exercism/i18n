# Introdução

O laço `for` é uma das instruções mais usadas para executar alguma lógica repetidamente.
Em JavaScript, ele é formado pela palavra-chave `for`, um _cabeçalho_ entre parênteses e um bloco de código que contém o _corpo_ do laço entre chaves.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

A inicialização normalmente cria uma variável contadora, a condição verifica se o laço deve continuar ou parar e o passo incrementa o contador ao final de cada repetição.
As partes individuais do cabeçalho são separadas por pontos e vírgulas.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
