# Testes

## Executando os testes

Para executar os testes, execute o comando a seguir:

```bash
dotnet test
```

Para executar os testes automaticamente sempre que um arquivo-fonte for alterado, execute o comando a seguir:

```bash
dotnet watch test
```

## Resolvendo o exercício

Resolver um exercício significa fazer com que todos os testes dele passem. Por padrão, apenas um teste (o primeiro) é executado quando você roda os testes. Isso é intencional, pois permite que você se concentre apenas em fazer esse único teste passar. Depois que ele passar, você pode habilitar o próximo teste removendo `Skip = "Remove this Skip property to run this test"` do atributo `[Fact]` ou `[Theory]` do teste. Quando todos os testes estiverem habilitados e a sua implementação fizer todos eles passarem, você terá resolvido o exercício!

Para ajudar você a começar, cada exercício vem com um arquivo de implementação stub. Você pode usar esse arquivo como ponto de partida para construir a sua solução. Fique à vontade para remover ou alterar esse arquivo se você achar que é a coisa certa a fazer.

## Usando pacotes

Você deve conseguir resolver a maioria dos exercícios sem usar nenhum pacote externo. No entanto, nos exercícios em que você quiser usar um pacote externo, você pode adicioná-lo ao seu projeto executando o comando a seguir:

```bash
dotnet add package [package-name]
```
