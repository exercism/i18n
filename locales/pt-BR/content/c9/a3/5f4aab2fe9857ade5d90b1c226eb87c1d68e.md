# Dicas

## 1. Verifique se a ação 'Ataque Rápido' é possível

- O operador lógico de negação (`!`) pode ser colocado antes de uma expressão para inverter seu valor.
- Dê uma olhada [neste artigo da MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_Operators#Logical_NOT_!) sobre operadores lógicos.

## 2. Verifique se a ação 'Espiã' é possível

- As expressões lógicas são avaliadas da esquerda para a direita e passam por possíveis 'curto-circuitos'.
- Para entender bem como funciona essa avaliação da esquerda para a direita, dê uma olhada [neste artigo](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence)!

## 3. Verifique se a ação 'Sinalizar o Prisioneiro' é possível

- Os operadores lógicos na ordem de precedência (da maior para a menor): `!`, `&&`, `||`.
- Dê uma olhada [neste artigo da MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#Precedence_And_Associativity) sobre precedência de operadores.

## 4. Verifique se a ação 'Libertar o Prisioneiro' é possível

- `()` é o operador com a maior precedência. Use-o para agrupar expressões lógicas.
