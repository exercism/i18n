# Sobre

Common Lisp usa os operadores aritméticos padrão para a maioria das operações, mas é um pouco peculiar por usar uma "notação de prefixo" em vez da "notação infixa" mais familiar.

Mais visualmente:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Embora a notação de prefixo transforme algumas operações como `2 + 2` na forma um pouco menos familiar `(+ 2 2)`, ela facilita muito operar com mais de um número ao mesmo tempo.

## Operadores aritméticos com um único argumento

Como uma pequena particularidade, os operadores `-` e `/` têm um significado especial quando aplicados a apenas um número:

```lisp
;; A single number passed to `-` is simply negated
(- 4)   ; => -4
(- -32) ; => 32
;; A single number passed to `/` returns the reciprocal
(/ 8)   ; => 1/8
(/ 0.1) ; => 10.0
```

## Comparando números

Por fim, pode ser útil comparar números diferentes com funções como `=` (igual), `/=` (diferente de) e `>=` (maior ou igual a).
Quando essas comparações são verdadeiras (como em `(= 1 1)`), elas retornam `T`, e quando não são (como em `(> 0 1)`), retornam `NIL`.

## Predicados numéricos

A linguagem também inclui alguns predicados úteis, como `zerop`, `evenp` e `oddp`, que verificam as condições óbvias.

## Referência

```lisp
;; Addition
(+ 1 2 3 4 5) ; => 15

;; Subtraction
(- 15 3 2)    ; => 10
(- 42)        ; => -42

;; Multiplication
(* 4 3 2 1)   ; => 24

;; Division
(/ 64 16 2)   ; => 2
(/ 5)         ; => 1/5

;; Exponentiation
(expt 2 8)    ; => 256

;; Square Root
(sqrt 25)     ; => 25

;; Modulo (Similar to remainder)
(mod 10 3)    ; => 1

;; Equality
(= 2 2)       ; => T
(= 3 5)       ; => NIL
```
