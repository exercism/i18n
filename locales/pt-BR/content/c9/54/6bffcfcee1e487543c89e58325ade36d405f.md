# Instalação

Siga as instruções para o seu sistema na página de instalação em [golang.org](http://golang.org/doc/install).

## Versão do Go

Esta trilha usa o Go 1.26.

Dá para usar uma versão anterior do Go modificando o arquivo `go.mod` de cada exercício e alterando a linha `go 1.26`. Só que os testes usam recursos introduzidos no Go 1.22 e não vão funcionar sem modificações com uma versão anterior.
