# Introdução

Uma *palavra genérica* declara uma operação que pode ter implementações diferentes conforme a classe do seu argumento. Os métodos são adicionados com `M:`.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` declara a palavra e seu efeito de pilha. `M:` define um método em uma classe específica, e o Factor despacha com base na classe do argumento que está no topo da pilha, em tempo de execução.

Você pode perguntar à palavra genérica para quais classes ela tem métodos, e adicionar ou remover métodos depois de definida. Não existe uma sintaxe especial de herança: qualquer classe de tupla já pode receber definições de métodos automaticamente.
