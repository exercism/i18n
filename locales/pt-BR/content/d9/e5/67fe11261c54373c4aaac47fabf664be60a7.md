# Noções básicas

## Sintaxe geral

O PHP é uma linguagem interpretada, o que significa que ele executa diretamente o código que você escreve.
Os arquivos de código PHP são arquivos de texto que contêm uma tag de abertura do PHP `<?php` para marcar o início do código PHP.
Se o arquivo contiver apenas código PHP, é possível omitir a tag de fechamento `?>` que marca o fim do código PHP.
Consulte a [documentação da tag do PHP][php-tag] para saber mais sobre a tag do PHP.

```php
<?php

// All PHP code goes here

// No closing tag required at the end
```

Para facilitar a leitura, todos os exemplos de código omitem a tag de abertura do PHP `<?php`.
Mas ela está presente em todos os exercícios de PHP, então você não precisa adicioná-la.

Todas as instruções, como atribuições ou chamadas de função, precisam terminar com um `;` para a separação de instruções.
Omitir o `;` (como no JavaScript) não é permitido e resulta em erros de sintaxe.
Saiba mais sobre a [separação de instruções][php-semicolon] na documentação do PHP.

```php
$message = "Success!"; // Statement correctly ends with `;`
$message = "I know JavaScript." // PHP Parse error: syntax error, [...]
```

## Valores e variáveis

O PHP é uma linguagem de programação de tipagem dinâmica.
Os tipos de valor só são verificados enquanto o programa está rodando.
Com o operador de atribuição `=`, você pode atribuir qualquer tipo de valor a qualquer nome de variável.
Os nomes de variáveis precisam começar com um cifrão `$`.
Para se aprofundar em variáveis, consulte a [documentação de variáveis do PHP][php-variables].

```php
$count = 1; // Assign an integer value of 1
$count = 2; // Re-assign a new value to the variable

$count = false; // You may assign any value type

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## Funções e métodos

Valores literais e valores armazenados em variáveis podem ser passados para funções.
Novas variáveis são criadas ao definir os argumentos de uma função, para guardar os valores passados.

```php
// Declare the window_width function
function window_width($width)
{
    echo $width; // Access the value passed into the function as $width
    // ...
}

window_width(100); // Call the function with the literal value 100

$newWidth = 100;
window_width($newWidth); // Call the function with the value stored in $newWidth
```

As funções podem retornar valores usando a palavra-chave `return`.
Os valores a retornar podem ser literais, estar armazenados em variáveis ou ser o resultado de uma instrução.

```php
function window_height()
{
    $heightOffset = 10;

    return 100 + $heightOffset;
}
```

As funções dentro de classes e de suas instâncias são chamadas de métodos.
Para chamar um método, o nome é precedido pela instância e por `->`.
Uma instância de classe é criada pela operação `new`.
Os métodos têm acesso à variável especial `$this`, que se refere à instância atual.

```php
<?php
// Calculator.php

class Calculator {
    // ...

    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```

Vamos nos aprofundar em funções e classes nos próximos exercícios.

## Depuração simples

Como uma forma básica de depuração, imprimir valores e o conteúdo das variáveis ajuda a entender o que acontece.
O PHP pode imprimir valores usando:

- `echo $variable;` para exibir uma representação em string do valor
- `print $variable;`, que é o mesmo que `echo $variable;`
- `var_dump($variable);` para obter mais detalhes sobre o valor, por exemplo, o tipo que o PHP enxerga

Ao usar `echo` ou `print`: strings vazias, `false` e `null` não aparecem.
E classes e instâncias farão com que eles gerem erro.
Use `var_dump()` para vê-los.

No editor online, a saída que você produz é exibida junto com os resultados dos testes.
Quando você usa a CLI, a saída aparece misturada com o indicador de progresso, antes do resumo dos testes.

## Organização do código

Os arquivos são as unidades básicas de organização do código em PHP e em muitas outras linguagens.
Para mostrar o nome do arquivo a ser consultado em um bloco de código, usamos um comentário.
Você nunca precisa adicionar comentários assim aos seus arquivos:

```php
<?php
// NameOfPhpFile.php

[...]
```

Código, funções e classes podem estar todos presentes em um único arquivo.
Mas, normalmente, esses tipos de unidades de código ficam em arquivos separados.

É prática comum ter uma classe por arquivo, com um nome de arquivo que corresponde à classe.

```php
<?php
// Calculator.php

class Calculator {
    // ...

    function add($x, $y)
    {
        return $x + $y;
    }
}
```

As funções costumam ser agrupadas em arquivos que descrevem o tema em comum entre elas.

```php
<?php
// window_handling.php

function window_paint()
{
    // ...
}

function window_size($width, $height)
{
    // ...
}

function window_move($x, $y)
{
    // ...
}
```

E muitas vezes há arquivos que contêm instruções para execução direta, como um `index.php`, comumente usado como ponto de entrada de uma aplicação web.

```php
<?php
// index.php

$sum = add(1, 2);
// ...
```

## Convenções de nomenclatura

Os nomes de classes devem estar todos em `PascalCase`.
Dependendo do padrão de estilo, os nomes de variáveis, funções e métodos podem estar em `camelCase` ou `snake_case`.
Os nomes podem conter letras `a-zA-Z`, números `0-9` e sublinhados `_`, mas não podem começar com um número.

## Comentários

Comentários de uma linha começam com `//`, e um bloco de texto pode ser envolvido por `/*` e `*/` para se tornar um comentário de várias linhas.

```php
// Single-line comment

/*
  Multi-line comment
*/
```
