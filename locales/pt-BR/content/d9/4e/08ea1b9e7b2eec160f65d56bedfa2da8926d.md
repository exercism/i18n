# Introdução

Um vetor é um array unidimensional.
Ele pode conter elementos de tipos diferentes.

## Criando vetores

Vetores podem ser criados com a função `vector` ou usando sua forma de leitura `#()`:

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

Como são arrays, também podem ser criados com `make-array`:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## Predicado de vetor

Para verificar se um objeto é um vetor, basta usar o predicado `vectorp`.

## Acessando elementos

Para acessar elementos de um vetor, use `aref`; os índices começam em zero:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
