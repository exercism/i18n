# Instalação

Você precisa do [Vim](http://www.vim.org) para fazer os exercícios:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [Código-fonte](#source)

## macOS

O sistema já vem com o Vim por padrão, mas é uma versão completamente desatualizada.

Provavelmente você usa o [MacPorts](https://www.macports.org) ou o
[Homebrew](https://brew.sh) para instalar programas.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

Se você quiser uma interface gráfica, dê uma olhada no [MacVim](https://macvim-dev.github.io/macvim).

## Ubuntu / Debian

Instale um Vim completo, com suporte a interface gráfica (`gvim`):

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

Usando o [Chocolatey](https://chocolatey.org):

```
C:\> choco install vim
```

Ou baixe e instale diretamente [daqui](http://www.vim.org/download.php#pc).

## Código-fonte

Se você quiser compilar o Vim mais recente por conta própria, dê uma olhada no
[repositório oficial no GitHub](https://github.com/vim/vim).
