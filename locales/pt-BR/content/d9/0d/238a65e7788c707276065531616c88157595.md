# remova a função `main` e corrija o nome do pacote

Remova a função `main`, renomeie o pacote de volta para `twofer` e rode os testes.

Uma função `main` é usada como ponto de entrada de um programa. O Exercism usa TDD ([desenvolvimento guiado por testes](http://testfirst.org/about#tdd)).
Isso significa que o código é executado ao rodar os testes, para fazê-los passar. Para rodar os testes, use `go test` no terminal.
Os testes vão passar se a funcionalidade estiver implementada corretamente.
