# Dicas

## 1. Determine o número total de aves que você contou até agora

- Consulte a introdução do exercício para ver um exemplo de como usar um laço `for` para iterar sobre um array.
- Use uma variável auxiliar para guardar a contagem total e aumente essa variável conforme percorre o array.
- Pense no valor inicial correto para essa variável auxiliar.
- Volte ao [conceito de array][concept-arrays] para relembrar como obter valores de um array.

## 2. Calcule o número de aves visitantes em uma semana específica

- Esta tarefa é parecida com a primeira.
  Você pode copiar seu código como ponto de partida.
- Pense em quais índices do array você precisaria levar em conta para a semana 1 e a semana 2, respectivamente.
- Agora, encontre uma forma geral de calcular o primeiro e o último índice que devem ser considerados.
- Com isso, você pode montar o laço `for` para iterar apenas sobre a parte relevante do array.

## 3. Corrija um erro de contagem

- De novo, você precisa montar um laço `for` para iterar sobre todo o array de contagem de aves.
- Desta vez, você só precisa visitar cada segunda entrada do array.
- Mude o passo para que a variável contadora seja incrementada na medida certa após cada iteração.
- No corpo do laço `for`, você pode usar o operador de incremento para mudar o valor de um elemento de um array no próprio lugar.
