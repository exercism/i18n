# Instruções

Lucy tem uma loja de adesivos online, onde vende adesivos fofos com as linguagens de programação favoritas de todo mundo. Pessoas do mundo todo compram os adesivos dela, e ela está tendo dificuldade para lidar com todas as moedas diferentes.

Crie um programa que Lucy possa usar para calcular preços, garantindo que ela esteja sempre usando a moeda correta.

## 1. Defina os tipos `Usd`, `Eur` e `Jpy`

Esses tipos são usados para representar as diferentes moedas que os clientes de Lucy usam para comprar os adesivos dela.

Eles devem ser usados como tipos fantasma e não precisam ter construtores.

## 2. Defina o tipo `Money`.

O tipo `Money` deve ter um campo `Int` para a quantidade de dinheiro, um parâmetro de tipo fantasma para a moeda, e deve ser um tipo opaco.

## 3. Defina as funções `dollar`, `euro` e `yen`

Defina as funções `dollar`, `euro` e `yen`, que recebem um argumento `Int` e retornam um valor `Money` com a moeda correta.

## 4. Defina a função `total`

Defina a função `total`, que recebe uma lista de valores `Money` e retorna o valor total de dinheiro na lista.

```gleam
total([euro(120), euro(200), euro(145)])
// -> euro(465)
```
