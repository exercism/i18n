# Instruções

Você é um mixologista especialista, preparando bebidas gostosas para o público aproveitar nas suas noites de balada.
Mas você percebeu que poderia facilitar a sua vida escrevendo um pouco de código para ajudar no seu trabalho.

## 1. Determine quanto tempo leva para preparar um pedido

Bebidas diferentes levam quantidades diferentes de tempo para preparar:

- `"beer"`, `"soda"` e `"water"` levam 0,5 minuto cada.
- `"shot"`s levam 1,0 minuto, `"mixed drink"`s levam 1,5 minutos,
- `"fancy drink"`s levam 2,5 minutos,
- `"frozen drink"`s levam 3,0 minutos.

Implemente a função `timeToPrepare(drinks:)`, que recebe o argumento `drinks`, que contém um array de strings representando as bebidas que precisam ser preparadas.
A função deve retornar o tempo total que levará para preparar todas as bebidas do array.

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. Reponha seu estoque de gomos de limão

Uma das primeiras coisas que você precisa fazer quando começa o seu turno é garantir que o seu potinho de gomos de limão esteja cheio para o turno que vem pela frente.
Você vai ter limões de tamanhos diferentes, que rendem quantidades diferentes de gomos: dá para tirar 6 gomos de um limão "small", 8 gomos de um limão "medium" e 10 de um limão "large".

Enquanto você ainda precisar de mais gomos e ainda tiver mais limões para cortar, pegue o primeiro limão do array e subtraia a quantidade adequada de gomos da quantidade de que você precisa.
Continue assim até não precisar de mais gomos ou até os limões acabarem.

Implemente a função `makeWedges(needed:limes:)`, que recebe os argumentos `needed`, que contém o número de gomos que você precisa cortar, e `limes`, que contém um array de strings representando os tamanhos dos limões que você tem disponíveis para cortar.
A função deve retornar o número de limões que você cortou.

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. Termine o seu turno

Parabéns! Seu longo dia de trabalho está quase no fim e logo você vai para casa trabalhar no seu novo app.
Mas você ainda tem uma série de pedidos de bebidas para fazer antes de passar os pedidos para o próximo turno e ir embora.

Enquanto ainda houver tempo no seu turno, você deve fazer o primeiro pedido do array e depois remover esse pedido do array.
Depois, você pode subtrair o tempo que levou para preparar esse pedido, de acordo com a sua função `timeToPrepare(drinks:)`, do tempo que resta no seu turno.

Implemente a função `finishShift(minutesLeft:remainingOrders:)`, que recebe o número de minutos restantes no seu turno (garantidamente maior que 0) e um array não vazio de pedidos de bebidas.
A função deve retornar o array de pedidos que você ainda não conseguiu fazer antes do fim do seu turno.

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. Acompanhe determinados pedidos

Para garantir que a beer e a soda fiquem frescas, você precisa acompanhar os pedidos delas junto com os horários em que esses pedidos foram feitos.

Implemente a função `orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)` que, quando recebe uma lista de pedidos e horários, retorna um par de tuplas opcionais contendo os horários do primeiro e do último pedido de beer e de soda, junto com o número total de pedidos de cada uma, e `nil` se nenhum pedido dessas bebidas foi feito. Você não precisa acompanhar nenhuma outra bebida.

Implemente a função `orderTracker(orders:)`, que recebe um array de tuplas, em que cada tupla contém a bebida pedida e o horário em que o pedido foi feito.
A função deve retornar uma tupla contendo o primeiro e o último horário em que a beer foi pedida, o número total de pedidos de beer, o primeiro e o último horário em que a soda foi pedida, e o número total de pedidos de soda.
Ela deve ser retornada como uma tupla no formato: `(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`.

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
