# Dicas

## 1. Classifique os clientes

- Usar [`every()`][ref-every] com uma função anônima pode ser conveniente.

## 2. Nomeie os clientes

- Processar duas entradas em paralelo: pense em [`map2()`][ref-map2] como uma abordagem possível.

## 3. Separe os clientes enfáticos

- As tarefas anteriores vão te ajudar.
- Quais clientes você quer [`keep`][ref-keep] na lista de saída?

## 4. Converta as avaliações para binário

- Há várias formas de resolver isso, mas [`if_else()`][ref-if_else] da biblioteca `dplyr` pode ser a mais simples. Isso foi discutido no [Conceito Switch][concept-switch].
- Dentro do `purrr`, outra possibilidade é [`map_int()`][ref-map_int].

## 5. Média das avaliações ao longo do tempo

- É uma média cumulativa, o que te dá uma pista sobre o nome de uma função útil.
- Uma média é uma soma dividida por um comprimento, então poderíamos implementar isso usando funções do `purrr`.
  - Vimos na Introdução como acumular uma soma.
  - Poderíamos usar [`map2_dbl()`][ref-map2] para dividir somas por comprimentos.
