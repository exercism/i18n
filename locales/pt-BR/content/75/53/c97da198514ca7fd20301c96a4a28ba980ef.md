# Apêndice das instruções

## Apêndice

~~~~exercism/note
As instruções acima são sincronizadas com um repositório compartilhado para garantir consistência entre todas as trilhas de linguagens.
Este apêndice traz esclarecimentos adicionais ou modifica as instruções conforme necessário, para alinhá-las melhor com os objetivos da trilha de Clojure.

Neste exercício da trilha de Clojure, **considere que tanto a entrada quanto a saída são vetores**, como indicam os testes.
Como objetivo extra, pense em como implementar uma abordagem que não use listas nas etapas intermediárias.

É importante não reaproveitar funções nativas do Clojure com funcionalidade parecida, pois isso reduziria o valor de aprendizado pretendido pelo exercício.
As principais funções do namespace `clojure.core` que você deve evitar incluem `into`, `concat`, `cat`, `lazy-cat`, `mapcat`, `flatten`, `filter`, `filterv`, `remove`, `count`, `map`, `mapv`, `reduce`, `transduce`, `reverse` e `rseq`.

### Objetivos opcionais

O objetivo opcional é para quem quer um desafio extra e foi pensado supondo que você já concluiu o objetivo principal.

Tente passar nos testes elaborando uma abordagem que parte do princípio de que:

* Tanto a entrada quanto a saída são listas em vez de vetores.
  Repare que, como sempre, não é preciso modificar os testes.
* Não é possível usar vetores nas etapas intermediárias.

Se você decidir publicar, não deixe de incluir um comentário indicando que a solução atende ao objetivo opcional de usar listas.
Não esqueça de atualizar as docstrings!
