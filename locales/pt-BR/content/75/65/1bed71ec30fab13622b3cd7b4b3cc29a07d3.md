# API Entry

A API Entry costuma ser a forma mais idiomática de manipular o conteúdo de uma estrutura de mapa. Porém, de modo incomum para Rust, ela não foi formalizada como uma trait; é apenas um conjunto de tipos e métodos implementados nos tipos de mapa da biblioteca padrão.

No fundo, o método `map.entry()` fornece um `enum`:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

A utilidade vem de outros métodos implementados nesse enum. Por exemplo, se você quer obter e, possivelmente, alterar o valor de uma chave específica, e o valor padrão do tipo do valor for adequado, basta fazer:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

Para aplicações como um contador, isso facilita muito a vida:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

Caso o valor padrão do tipo não sirva para a sua aplicação, você pode fornecer o seu próprio valor padrão constante com `or_insert`, ou calcular um com `or_insert_with`.

Em certos casos, você pode querer fazer um cálculo sobre um valor que já existe antes de qualquer inserção em potencial. Nesses casos, `and_modify` permite isso. No entanto, esse uso é um tanto raro. `and_modify` é mais usado para evitar a necessidade de desreferenciar:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

De vez em quando, é interessante fazer um `match` diretamente com a entry. Isso é permitido:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

Para mais informações, veja [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) e [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html).
