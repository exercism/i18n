O projeto está em uma fase bem básica de desenvolvimento, por isso sua missão é usar Expressões Regulares para melhorar a capacidade do chatbot de entender e gerar linguagem natural.

## 1. Verifique se o comando é válido

Além de inteligente, o Chatbot também é um assistente leal.

Para pedir algo ao chatbot, o usuário precisa dizer a palavra “**Chatbot**” na primeira posição do comando.

Não importa se a palavra-chave está em MAIÚSCULAS ou minúsculas.
O que importa aqui é a posição da palavra.

Implemente a função `is_valid_command()` que ajuda o Chatbot a reconhecer quando o usuário está dando um comando.

```R
is_valid_command("Chatbot, play a song from the 80's.")
[1] TRUE
> is_valid_command("Hey Chatbot, where is the closest pharmacy?")
[1] FALSE
> is_valid_command("CHATBOT, do you have a solution for this challenge?")
[1] TRUE
```

## 2. Remova os emojis criptografados

O Chatbot tem dificuldade para entender como as pessoas usam emojis para expressar suas emoções.

Quando o chatbot recebe mensagens do usuário, cada emoji é representado como “_emoji_” seguido do seu número de _id_.

Implemente o método `remove_emoji()` que recebe uma string e remove toda a criptografia dos emojis ao longo da mensagem.

As linhas que não contêm texto de emoji devem ser retornadas sem modificação.

Apenas remova a string do emoji. Não tente ajustar os espaços em branco.

```R
remove_emoji("I love playing videogames emoji3465 it's one of my hobbies")
[1] "I love playing videogames  it's one of my hobbies"
```

## 3. Verifique se o número de telefone é válido

Como os recursos do chatbot podem ser baixados em um aplicativo de celular, espera-se que o usuário escreva um número de telefone durante a conversa.

O problema é que o chatbot só consegue ler e validar um número com um formato específico.

Se o número for válido (corresponder à sequência de caracteres especificada pela **expressão regular**), o chatbot responde com uma mensagem agradecendo ao usuário e confirmando o número. Se o número for inválido, a função informa ao usuário que o número de telefone não é válido.

O formato esperado é: (+##) ###-###-###

```R
check_phone_number("(+34) 659-771-594")
[1] "Thanks! You can now download me to your phone."
> check_phone_number("659-771-594")
[1] "Oops, it seems like I can't reach out to 659-771-594"
```

## 4. Cumprimente o usuário

Para armazenar os dados de todas as pessoas que já conversaram com ele, o chatbot consegue obter o Nome Completo do perfil do usuário neste formato: **“Smith, John”**.

Assim, queremos que o nosso chatbot seja bem educado e cause uma boa impressão.

Escreva a função `nice_to_meet_you()` que recebe uma string com o nome completo do usuário e retorna a string **“Nice to meet you, John Smith”**

```R
nice_to_meet_you("Smith, John")
#> Nice to meet you, John Smith
```

## 5. Obtenha o link do site

O Chatbot é um software muito curioso. Apesar de conseguir pesquisar na internet sobre um assunto específico, ele gosta de perguntar aos usuários sobre sites legais ou URLs onde encontrar informações relevantes.

Exemplo de conversa:

- **Chatbot**: Ei nome de usuário, eu gostaria de aprender a programar em JavaScript, você conhece algum site legal onde eu poderia aprender?
- **Usuário**: Aprendi muito no [exercism.org](http://exercism.org)

Implemente a função `get_URL()` que consegue retornar um array com apenas o link de cada site.

```R
get_URL("I learned a lot from exercism.org")
[1] "exercism.org"
```
