# Anexo de instruções

## Instruções específicas da trilha

Sua tarefa é escrever uma função `nucleotideCounts` que recebe como entrada uma string e retorna como saída um array associativo contando quantas vezes cada nucleotídeo está presente.
Se a string for uma sequência inválida, a função deve lançar um `IllegalArgumentError` com a mensagem `Invalid nucleotide in strand`.
