# Instalação

Os [binários pré-compilados do Uiua][releases] estão disponíveis, então não é preciso compilar.
Consulte o [guia de instalação oficial][install-guide] para as instruções mais recentes, incluindo integração com IDE e fontes.

```exercism/note
No momento, nosso test runner online usa a versão `0.18.1`.
Com o ritmo acelerado de desenvolvimento do Uiua, isso pode mudar, então tenha isso em mente se você não conseguir reproduzir os resultados dos testes do site.
```

Depois de baixar o Uiua para o local desejado, você precisa adicioná-lo ao PATH do seu sistema.

- **macOS:** Use o Finder para abrir `Applications > Utilities > Terminal`. Digite `export PATH="/path/to/uiua:$PATH"` para rodar o Uiua de qualquer lugar.

- **Windows:** Abra "Edit Environment Variables" no menu Iniciar. Em "Path", adicione sua pasta do Uiua.

- **Linux:** Abra o Terminal e adicione `export PATH="/path/to/uiua:$PATH"` a `~/.bashrc` ou `~/.profile` para facilitar o acesso.

[releases]: https://github.com/uiua-lang/uiua/releases
[install-guide]: https://www.uiua.org/docs/install#basic
