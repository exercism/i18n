# Sobre

Executar código de forma condicional pode ser feito com [expressões `if/elif/else`][conditional-expression]. As condições usadas em uma expressão `if/elif/else` precisam ser do tipo `bool`. O F# não tem o conceito de valores _truthy_.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

Como `if/elif/else` é uma expressão, ela pode ser atribuída a um nome ou retornada por uma função.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

Todos os blocos precisam retornar o mesmo tipo. Se isso não acontecer, o resultado é um erro de compilação:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

Os blocos `else` e `elif` são opcionais, mas apenas se o tipo da expressão retornada for [`unit`][unit-type].

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

Uma expressão `if/else` também pode ser escrita em uma única linha. Isso só deve ser usado para expressões `if` simples.

```fsharp
let y = if x > 5 then 10 else 20
```
