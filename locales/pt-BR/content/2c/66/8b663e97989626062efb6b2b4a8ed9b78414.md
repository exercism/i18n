# Instruções

Você está desenvolvendo um sistema para ajudar a equipe do site de um clube de futebol a fazer reportagens sobre as partidas.
Os dados são recebidos de várias fontes e canalizados para um único fluxo depois de serem limpos.

## 1. Gere as descrições dos jogadores com base no número da camisa

O time só joga no esquema 4-3-3 e nunca concordou com a mudança de 1965 nas regras que permitiu as substituições, muito menos com elencos ampliados.

As descrições dos jogadores são as seguintes:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Implemente o método estático `FootballMatchReports.onField()` para gerar a descrição de um jogador com base no número da camisa dele.

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. Retorne "invalid" se o número da camisa não fizer parte da lista oficial

Modifique o método `FootballMatchReports.onField()` para retornar 'invalid' quando for processado um número de camisa fora do intervalo de 1 a 11.

```java
FootballMatchReports.onField(13);
// => "invalid"
```
