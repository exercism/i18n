# Sobre

## Booleans

O PowerShell tem o tipo [`bool`][booleans] para representar valores verdadeiros e falsos.
Nesse tipo existem apenas dois valores: `True` e `False`.
Você pode vincular esses valores a variáveis com o prefixo `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Podemos usar [operadores lógicos][logical-operators] como `-and`, `-or` e `-not` para combinar e avaliar expressões Boolean.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## Conversão e veracidade

O PowerShell pode tratar qualquer tipo como Boolean implicitamente.
No entanto, você também pode usar o acelerador de tipo Boolean `[bool]` para uma conversão explícita.

Aqui estão algumas regras gerais que o PowerShell usa para converter outros tipos em valores Boolean:

$false:
- Strings vazias como `''` ou `""`
- Valores nulos como `$null`
- Tipo numérico com o valor zero (0)

$true:
- Strings não vazias
- Instâncias de qualquer outro tipo que não seja coleção

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

Para regras detalhadas sobre a conversão de valores Boolean a partir de tipos de coleção, leia [aqui][collection-conversion].
