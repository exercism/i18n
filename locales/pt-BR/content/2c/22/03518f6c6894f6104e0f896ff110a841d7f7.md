# Dicas

## 1. Gerar as letras dos assentos

- O valor de retorno deve ser do _tipo_ `generator`.
- Você pode ter uma sequência de letras de `A` a `D` e percorrer esse ciclo.
- Use `yield` para retornar a próxima letra.

## 2. Gerar os assentos

- O valor de retorno deve ser do _tipo_ `generator`.
- A fileira `13` deve ser pulada, então vá de `12` a `14`.
- Lembre-se de que os valores de retorno devem estar em ordem crescente. `1A, 1B, 2A, ...`
- Aqui pode ser uma boa ideia reutilizar ou chamar funções que você já definiu.

## 3. Atribuir assentos aos passageiros

- Verifique se os números dos assentos não têm espaços.
- Aqui pode ser uma boa ideia reutilizar ou chamar funções que você já definiu.

## 4. Códigos das passagens

- Você pode usar `len()` para obter o comprimento de uma string.
- Você pode usar `"<string>" * <int>` para repetir uma string.
