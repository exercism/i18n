# Instruções

Neste exercício, você vai escrever código para processar uma lista de linguagens de programação que pretende praticar na plataforma Exercism.

Você tem seis tarefas.

## 1. Crie uma nova lista

Antes de adicionar linguagens, você precisa começar criando uma nova lista. Defina uma função que retorna uma lista vazia.

```clojure
(new-list)
;; => ()
```

## 2. Adicione uma nova linguagem à lista

Conforme você explora o Exercism e encontra linguagens que quer aprender, vai precisar adicioná-las à sua lista. Defina uma função para adicionar uma nova linguagem ao início da sua lista.

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. Confira a última linguagem adicionada

Você vai querer conferir rapidamente qual linguagem acabou de adicionar. Defina uma função que retorna a primeira linguagem da sua lista.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Remova a primeira linguagem da lista

Às vezes você muda de ideia sobre uma linguagem que acabou de adicionar. Defina uma função para remover a primeira linguagem da sua lista.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Conte as linguagens da lista

Contar as linguagens uma a uma é inconveniente. Defina uma função para contar quantas linguagens há na sua lista.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Junte tudo

Defina uma função `learning-list`, dentro da qual você vai usar algumas das funções que definiu acima.

- Crie uma lista vazia
- Adicione 2 novas linguagens de programação à lista.

  - "Clojure"
  - "Lisp"

- Remova "Lisp" da lista, já que talvez você não tenha tempo suficiente no ano, e ela é bastante parecida com Clojure.
- Adicione mais 2 linguagens de programação à lista.

  - "Java"
  - "JavaScript"

- Retorne o número total de linguagens. Dica: deve ser 3.

```clojure
(learning-list)
;; => 3
```
