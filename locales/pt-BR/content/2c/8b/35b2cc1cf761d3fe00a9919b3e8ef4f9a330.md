# Dicas

## Geral

Lembre-se: este é um [MVP][mvp].
Isso significa que você não precisa complicar demais o tratamento de erros nem se preocupar com diferentes cenários de "casos extremos".
Não tem problema ser simples e direto nas funções que você escrever.

A seção sobre dicionários do [tutorial oficial][dicts-docs] e a [referência oficial da biblioteca][mapping-types-dict] para o tipo de mapeamento são ótimos lugares para buscar mais ajuda com todos esses métodos.


## 1. Adicione item(ns) ao carrinho de compras do usuário

- Você vai precisar iterar sobre cada item em `items_to_add`.
- Você pode evitar um `KeyError` quando falta uma chave usando um [método][set-default] de `dict` que recebe um _valor padrão_ como um dos argumentos.
- Também é possível fazer a mesma coisa manualmente no `loop`, usando algumas verificações e tratamento de erros, mas o método de `dict` é mais fácil.

## 2. Leia os itens listados no app de notas do usuário

- Lembre-se: o Python tem um método para _tudo_. Esse aqui é um _classmethod_ que é uma forma fácil de [preencher um `dict`][fromkeys] com chaves.
- Esse método de `dict` retorna um _novo dicionário_, preenchido com valores padrão. Se nenhum valor for informado, o valor padrão será `None`

## 3. Atualize a seção de "Ideias" da receita

- Não pense demais nisso! Dá para resolver com **uma** única chamada de método de `dict`.
- A palavra-chave aqui é .... [_update_][update].

## 4. Ordene os itens no carrinho do usuário

- Que método você chamaria para obter uma [visão iterável dos itens][items] do dicionário?
- Se você tivesse uma `list` ou uma `tuple`, que função [`built-in`][builtins] você poderia usar para ordená-las?
- A função built-in que você quer é a que retorna uma _cópia_ e não modifica o original.

## 5. Envie o carrinho de compras do usuário para a loja fazer a separação

- Ter um dicionário novo e vazio aqui como `fulfillment_cart` pode ser útil para adicionar itens.
- Um `Looping` pelos membros do carrinho pode ser a forma mais direta de acessar as coisas aqui.
- Que método você chamaria para obter uma [visão iterável apenas das chaves][keys] do dicionário?
- Lembre-se de que você pode obter o `value` de uma determinada chave usando a sintaxe `<dict name>[<key_name>]`.
- Se você tivesse uma `list` ou uma `tuple`, que função [`built-in`][builtins] você poderia usar para ordená-las?
- Lembre-se de que a função `built-in` pode receber um argumento opcional `reverse=True`.

## 6. Atualize o estoque da loja para refletir o que o usuário pediu.

- Existe um método que dá a você uma visão iterável dos pares (`key`, `value`) do dicionário.
- Você pode acessar um item em uma _tupla aninhada_ usando a _notação de colchetes_: `<tuple>[<nested_tuple>][<index_of_value>]`
- Não esqueça de verificar se a contagem de um item do estoque chega a zero: você vai precisar adicionar a mensagem "Out of Stock".
