# Tarefas

As tarefas são issues do GitHub com as quais gostaríamos que as pessoas ajudassem, desde revisar textos até construir Concept Exercises.
Elas aparecem no site e levam para as issues correspondentes no GitHub.
Cada tarefa recebe uma ou mais propriedades, que são preenchidas a partir das labels da issue.
Aí a pessoa pode filtrar as tarefas com base nessas propriedades.

## Tags

Para que uma issue seja considerada uma tarefa, ela precisa ter uma ou mais labels específicas de tarefa.
Assim, os maintainers podem escolher que só algumas issues apareçam como tarefas.

Cada label de tarefa é definida como: `x:<type>/<value>` e há suporte a cinco tipos de tarefa:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### Tag de ação

As labels `x:action/<value>` descrevem que tipo de trabalho a pessoa vai fazer ao trabalhar na issue.

| Tag                  | Descrição                              |
| -------------------- | -------------------------------------- |
| `x:action/create`    | Trabalhar em algo do zero              |
| `x:action/fix`       | Corrigir uma issue                     |
| `x:action/improve`   | Melhorar funcionalidade/conteúdo existente |
| `x:action/proofread` | Revisar textos                         |
| `x:action/sync`      | Sincronizar o conteúdo com a versão mais recente |

### Tag de conhecimento

As labels `x:knowledge/<value>` descrevem quanto conhecimento do Exercism a pessoa precisa ter.

| Tag                        | Descrição                                   |
| -------------------------- | ------------------------------------------- |
| `x:knowledge/none`         | Não exige nenhum conhecimento do Exercism   |
| `x:knowledge/elementary`   | Exige pouco conhecimento do Exercism        |
| `x:knowledge/intermediate` | Exige bastante conhecimento do Exercism     |
| `x:knowledge/advanced`     | Exige conhecimento amplo do Exercism        |

### Tag de módulo

As labels `x:module/<value>` indicam em que parte do Exercism a pessoa vai trabalhar.

| Tag                          | Descrição                    |
| ---------------------------- | ---------------------------- |
| `x:module/analyzer`          | Trabalhar nos Analyzers      |
| `x:module/concept`           | Trabalhar nos Concepts       |
| `x:module/concept-exercise`  | Trabalhar nos Concept Exercises |
| `x:module/generator`         | Trabalhar nos geradores de exercícios |
| `x:module/practice-exercise` | Trabalhar nos Practice Exercises |
| `x:module/representer`       | Trabalhar nos Representers   |
| `x:module/test-runner`       | Trabalhar nos Test Runners   |

### Tag de tamanho

As labels `x:size/<value>` descrevem a quantidade de trabalho esperada de quem contribui.

| Tag              | Descrição                     |
| ---------------- | ----------------------------- |
| `x:size/tiny`    | Uma quantidade mínima de trabalho |
| `x:size/small`   | Pouco trabalho                |
| `x:size/medium`  | Uma quantidade média de trabalho |
| `x:size/large`   | Muito trabalho                |
| `x:size/massive` | Uma quantidade enorme de trabalho |

### Tag de tipo

As labels `x:type/<value>` descrevem o tipo de trabalho em que a pessoa vai se envolver.

| Tag              | Descrição                                                                                                                                                                                                      |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | Trabalhar em Integração Contínua (por exemplo, fluxos de trabalho do GitHub Actions)                                                                                                                           |
| `x:type/coding`  | Escrever código que não faz parte do conteúdo voltado para estudantes. Normalmente são tarefas ligadas a ferramentas de produção (por exemplo, test runners), ferramentas internas (geradores) ou bibliotecas que o Exercism mantém. |
| `x:type/content` | Trabalhar em conteúdo (por exemplo, exercícios, concepts)                                                                                                                                                      |
| `x:type/docker`  | Trabalhar em Dockerfiles                                                                                                                                                                                       |
| `x:type/docs`    | Trabalhar em documentação                                                                                                                                                                                      |

## Tags claimed e unclaimed

Para esconder uma tarefa pelo fato de alguém já estar trabalhando nela, a issue pode receber a label `x:status/claimed`.
