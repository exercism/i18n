# Instruções

Neste exercício, você vai implementar algumas regras do clássico jogo Pac-Man.

São quatro regras para implementar, todas relacionadas aos estados do jogo.

## 1. Defina se o Pac-Man come um fantasma

Implemente uma função que recebe como entradas se o Pac-Man tem uma pílula de poder ativa e se o Pac-Man está encostando em um fantasma, e retorna um valor Boolean indicando se o Pac-Man consegue comer o fantasma. A função só deve retornar `true` se o Pac-Man tiver uma pílula de poder ativa e estiver encostando em um fantasma.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Defina se o Pac-Man pontua

Implemente uma função que recebe como entradas se o Pac-Man está encostando em uma pílula de poder e se o Pac-Man está encostando em uma pastilha, e retorna um valor Boolean indicando se o Pac-Man pontuou. A função deve retornar `true` se o Pac-Man estiver encostando em uma pílula de poder ou em uma pastilha.

```lua
rules.score(true, true)
-- => true
```

## 3. Defina se o Pac-Man perde

Implemente uma função que recebe como entradas se o Pac-Man tem uma pílula de poder ativa e se o Pac-Man está encostando em um fantasma, e retorna um valor Boolean indicando se o Pac-Man perde. A função deve retornar `true` se o Pac-Man estiver encostando em um fantasma e não tiver uma pílula de poder ativa.

```lua
rules.lose(false, true)
-- => true
```

## 4. Defina se o Pac-Man vence

Implemente uma função que recebe como entradas se o Pac-Man comeu todas as pastilhas, se o Pac-Man tem uma pílula de poder ativa e se o Pac-Man está encostando em um fantasma, e retorna um valor Boolean indicando se o Pac-Man vence. A função deve retornar `true` se o Pac-Man comeu todas as pastilhas e não perdeu, de acordo com os argumentos definidos na parte 3.

```lua
rules.win(false, true, false)
-- => false
```
