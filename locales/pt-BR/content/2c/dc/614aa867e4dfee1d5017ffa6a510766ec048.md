# Recursos

## Geral

* [A documentação da linguagem Unison](https://www.unison-lang.org/learn/fundamentals/values-and-functions/terms/) é um ótimo lugar para aprender os conceitos centrais do Unison
* [Unison Share](https://share.unison-lang.org/) é o repositório onde hospedamos bibliotecas públicas e código
* Você pode tirar dúvidas a qualquer momento no [Discord do Unison](https://unison-lang.org/discord)
* [The Unison Blog](https://www.unison-lang.org/blog/) traz novidades da linguagem e tópicos especiais
* Um artigo sobre como usar a [Remote ability do Unison para implementar uma biblioteca no estilo do Spark](https://www.unison-lang.org/articles/distributed-datasets/)
