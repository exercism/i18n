# Dicas

## Geral

- As [tuplas](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) são agrupamentos imutáveis de valores sem nome, mas ordenados, possivelmente de tipos diferentes.
- Os elementos dentro de tuplas podem ser [obtidos](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values) por meio de correspondência de padrões, desestruturação de tuplas ou funções auxiliares.

## 1. Extrair as coordenadas

- Lembre-se: as tuplas permitem o acesso por meio de funções auxiliares ou de desestruturação.
- Confira o [parsing](https://docs.microsoft.com/en-us/dotnet/api/system.int32.parse?view=net-5.0) para obter um número a partir de uma string.

## 2. Formatar as coordenadas

- Confira os [exemplos](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#examples) para mais detalhes sobre a criação de tuplas.
- Confira o [fatiamento de strings](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/strings#string-indexing-and-slicing) para mais detalhes sobre strings.
