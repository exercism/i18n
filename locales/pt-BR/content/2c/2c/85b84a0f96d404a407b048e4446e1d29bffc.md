# Complemento das instruções

## Dicas

Para que o desafio tenha o nível de dificuldade adequado, use apenas a funcionalidade presente no Prelude. Tente não usar Data.List, Data.Char, Data.Bits nem Numeric.

Tente usar seq, $! ou BangPatterns de forma adequada para garantir que a solução seja eficiente.

Não é necessário tratar entradas inválidas.
