# Instruções case

Quando um valor é comparado com uma lista de possibilidades, uma cadeia de
`elsif`s diz a mesma coisa repetidas vezes:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

O `case` diz isso uma vez só:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

O valor vem depois do `case`. Cada `when` dá um valor para comparar com ele,
e o primeiro que corresponder é executado.

## Vários valores em um único when

Um `when` pode listar valores, separados por vírgulas:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

Isso funciona com números inteiros, caracteres e strings: qualquer coisa que
possa ser comparada com `=`.

## O else não é opcional

**Um `case` que não corresponde a nada e não tem `else` é um erro que
interrompe o programa quando isso acontece.**

Isso é diferente do `if`, em que omitir o `else` simplesmente significa que
nada acontece. Também é diferente da maioria das linguagens, em que um `case`
sem correspondência silenciosamente não faz nada.

Então todo `case` precisa de um `else`, mesmo quando você tem certeza de que
as partes `when` já cobrem todos os valores. Uma quarta zona é adicionada
mais tarde, o `case` não é atualizado para acompanhar, e o programa trava no
primeiro passageiro que usar essa zona.

## Apenas um when roda

Quando um `when` corresponde, as instruções depois do `then` rodam e o `case`
termina: o programa continua depois do `end`. As partes `when` abaixo dele nem
chegam a ser avaliadas, então você não precisa escrever nada para impedir que
a próxima também rode.
