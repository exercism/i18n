# Introdução

Uma string representa dados textuais.
Em Swift, uma [`String`][strings-and-characters] é uma coleção ordenada de valores `Character`, em que cada caractere representa um caractere Unicode.

Você cria uma string usando um literal de string, que é uma sequência de caracteres cercada por aspas duplas (`"`).
Para strings de várias linhas, use três aspas duplas (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

As strings do Swift se conectam de forma transparente com a classe [`NSString`][nsstring-docs] do framework Foundation, dando acesso a amplos recursos de processamento de texto.

## Caracteres

Um `Character` representa um único cluster de grafemas estendido, um caractere legível por humanos composto de um ou mais [valores escalares Unicode][unicode-scalar-values].
Um valor escalar Unicode é um ponto de código de 21 bits no intervalo de `U+0000` a `U+D7FF`, inclusive, ou de `U+E000` a `U+10FFFF`, inclusive.

```swift
let aChar: Character = "A"
```

## Inferência de tipos

Quando você escreve um literal de string, o Swift infere automaticamente que o tipo dele é `String`.
Para armazenar um único caractere como `Character`, você precisa fornecer uma anotação de tipo explícita:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Concatenação

Você pode juntar strings usando o operador de adição (`+`):

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Você não pode concatenar um `Character` diretamente a uma `String` usando `+` sem antes converter o caractere em uma string.
No entanto, você pode usar o método [`append(_:)`][append] para acrescentar uma string ou um caractere diretamente a uma string mutável:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## Interpolação de strings

A [interpolação de strings][string-interpolation] permite construir uma string embutindo constantes, variáveis, literais e expressões dentro de literais de string.
Coloque cada expressão entre parênteses precedidos por uma barra invertida (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Propriedades de strings e caracteres

Strings e caracteres oferecem várias propriedades para inspecionar seu conteúdo.

### Propriedades de strings

As propriedades de string mais comuns incluem:

| Propriedade | Descrição                                            | Exemplo                              |
| ----------- | ---------------------------------------------------- | ------------------------------------ |
| `isEmpty`   | Retorna `true` se a string não tiver caracteres      | `"Hello".isEmpty` resulta em `false` |
| `count`     | Retorna o número de caracteres na string             | `"Hello".count` resulta em `5`       |

Para uma lista completa de propriedades, consulte a [documentação de String da Apple][string-docs].

### Propriedades de caracteres

As propriedades de caractere mais comuns incluem:

| Propriedade    | Descrição                                        | Exemplo                                |
| -------------- | ------------------------------------------------ | -------------------------------------- |
| `isLowercase`  | Retorna `true` se o caractere for minúsculo      | `"a".isLowercase` resulta em `true`    |
| `isUppercase`  | Retorna `true` se o caractere for maiúsculo      | `"A".isUppercase` resulta em `true`    |
| `isNumber`     | Retorna `true` se o caractere for um dígito      | `"1".isNumber` resulta em `true`       |
| `isWhitespace` | Retorna `true` se o caractere for um espaço em branco | `" ".isWhitespace` resulta em `true` |

Para uma lista completa de propriedades, consulte a [documentação de Character da Apple][character-docs].

## Conversão de tipos

Você pode converter outros tipos em strings usando o inicializador `String(_:)`, que dá suporte a tipos padrão como `Int`, `Double` e `Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Caracteres especiais

Literais de string do Swift dão suporte a várias [sequências de escape][special-characters] para caracteres especiais:

| Sequência  | Descrição                              |
| ---------- | -------------------------------------- |
| `\0`       | Caractere nulo                         |
| `\\`       | Barra invertida                        |
| `\t`       | Tabulação horizontal                   |
| `\n`       | Avanço de linha (nova linha)           |
| `\r`       | Retorno de carro                       |
| `\'`       | Aspas simples                          |
| `\"`       | Aspas duplas                           |
| `\u{n}`    | Escalar Unicode arbitrário (hexadecimal) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
