# Anexo às instruções

## Palavras

Defina uma tupla `school` para guardar a lista de alunos (como você guarda os alunos dentro dela é decisão sua) e, depois, implemente as palavras abaixo.

- `<school> ( -- school )`: constrói uma escola vazia.
- `add-student ( school name grade -- ? )`: adiciona `name` a `grade`. Retorne `t` em caso de sucesso, ou `f` se `name` já tiver sido adicionado (a esta série ou a qualquer outra); nesse caso, a lista de alunos permanece inalterada.
- `roster ( school -- names )`: todos os alunos, ordenados por série e depois em ordem alfabética pelo nome.
- `grade ( school n -- names )`: os alunos da série `n`, em ordem alfabética pelo nome.
