# Sobre

[Símbolos][symbols] são identificadores nomeados que podem ser usados para se referir a um valor.
Os símbolos são criados por meio de um literal de símbolo, que consiste em prefixar um nome com o caractere `:`, por exemplo, `:foo`.
Eles também podem ser escritos com aspas, por exemplo, `:"foo"`, o que permite, por exemplo, espaços no nome.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

Os símbolos são usados em muitos lugares da linguagem, inclusive como chaves em hashes, para representar nomes de métodos e nomes de variáveis.

## Identificador

O que diferencia os símbolos das strings é que eles são identificadores e não representam dados nem texto.
Isso significa que dois símbolos com o mesmo nome são sempre o mesmo objeto.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## Modificando símbolos

Os símbolos são imutáveis, o que significa que não podem ser modificados.
Isso significa que, quando você "modifica" um símbolo, na verdade está criando um novo símbolo.
Existem alguns métodos que podem ser usados para manipular símbolos. Todos eles retornam novos símbolos.
Todos os métodos podem ser encontrados na [API do Symbol][symbols-api].

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

A vantagem de os símbolos serem imutáveis é que eles são mais eficientes em termos de memória do que as strings, além de serem mais seguros para usar como identificadores.

## Conversão

Os símbolos podem ser convertidos em strings e vice-versa.
Isso pode ser útil quando você quer modificar um símbolo ou quando quer usar um símbolo como string.
Para apresentar uma string como um símbolo, você pode usar o método `String#to_sym` e, para fazer o contrário, o método `Symbol#to_s`.
Como os símbolos têm um conjunto limitado de métodos, pode ser útil converter um símbolo em string para usar métodos de string nele, caso você precise de um novo símbolo.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
