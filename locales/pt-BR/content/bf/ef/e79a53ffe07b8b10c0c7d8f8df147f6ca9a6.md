# Instruções

Neste exercício, você vai escrever código para ajudar uma pessoa freelancer a se comunicar com um gerente de projetos, fornecendo alguns utilitários para calcular rapidamente valores diários e mensais, opcionalmente com um desconto dado.

Primeiro, estabelecemos algumas regras entre quem é freelancer e o gerente de projetos:

- O valor diário é 8 vezes o valor por hora.
- Um mês tem 22 dias faturáveis.

Às vezes, o freelancer oferece um desconto sobre o valor diário (por exemplo, para os clientes mais fiéis ou para clientes sem fins lucrativos).

Os descontos são modelados como números fracionários que representam porcentagens, por exemplo `25.0` (25%).

## 1. Calcule o valor diário a partir de um valor por hora

Implemente uma função que calcule o valor diário a partir de um valor por hora:

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

O valor diário retornado deve ser um número de ponto flutuante.

## 2. Calcule um preço com desconto

Implemente uma função que calcule o preço depois de aplicar um desconto.

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

O valor retornado deve ser sempre um número de ponto flutuante, sem arredondamento de nenhum tipo.

## 3. Calcule o valor mensal a partir de um valor por hora e de um desconto

Implemente uma função que calcule o valor mensal e aplique um desconto:

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

O valor mensal retornado deve ser arredondado para cima (teto) para o número inteiro mais próximo.

## 4. Calcule o número de dias de trabalho a partir de um orçamento, de um valor por hora e de um desconto

Implemente uma função que recebe um orçamento, um valor por hora e um desconto, e calcula quantos dias de trabalho isso cobre.

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

O número de dias retornado deve ser arredondado para baixo (piso) até uma casa decimal.
