# Instruções

Como futura mágica, Elyse precisa praticar alguns fundamentos. Ela tem uma pilha de cartas que quer manipular.

Para deixar as coisas um pouco mais fáceis, ela usa apenas as cartas de 1 a 10.

A pilha de cartas é representada por um `queue`, com a base da pilha na frente da fila e o topo da pilha no fim dela.

## 1. Insira uma carta no topo da pilha

Implemente a função `insert_top`, que retorna uma cópia da pilha com a nova carta fornecida adicionada ao topo da pilha.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. Remova a carta do topo da pilha

Implemente a função `remove_top_card`, que retorna uma cópia da pilha sem a sua carta do topo. Se a pilha dada estiver vazia, a pilha original deve ser retornada, sem alterações.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. Insira uma carta na base da pilha

Implemente a função `insert_bottom`, que retorna uma cópia da pilha com a nova carta fornecida adicionada à base da pilha.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. Remova uma carta da base da pilha

Implemente a função `remove_bottom_card`, que retorna uma cópia da pilha sem a sua carta da base. Se a pilha dada estiver vazia, a pilha original deve ser retornada, sem alterações.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. Verifique o tamanho da pilha

Implemente a função `check_size_of_stack`, que verifica se o tamanho da pilha é igual a um `stack_size` dado ou não.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
