# Introdução

Até agora, vimos que os argumentos passados para um método são associados aos parâmetros declarados do método com base na posição. Uma abordagem alternativa, especialmente quando uma rotina recebe um grande número de argumentos, é quem chama associar os argumentos especificando o identificador do parâmetro declarado.

O código a seguir ilustra a sintaxe:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
