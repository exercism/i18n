# Executando os testes

Os exercícios obtidos com o [cliente de linha de comando do Exercism](https://exercism.io/cli) são entregues com no mínimo três arquivos: um arquivo `readme.md`, um arquivo `.dpr` e um arquivo `.pas`. O arquivo `.dpr` é o arquivo de projeto do Delphi, e o arquivo `.pas` é o executor de testes. Carregue o projeto Delphi clicando duas vezes no arquivo `.dpr` ou abrindo o projeto dentro do Delphi. Você será responsável por criar um novo arquivo `.pas` que conterá o código da sua solução, contra o qual os testes serão executados. Consulte o arquivo `readme.md` para saber como compilar e executar seu código.

Todos os testes foram ignorados, exceto o primeiro, para você trabalhar nele. Para continuar, basta comentar o atributo `[Ignore]` do teste para começar a trabalhar nele.

Certifique-se de que o [DUnitX](https://github.com/VSoftTechnologies/DUnitX) esteja instalado, caso ainda não tenha sido instalado na configuração acima.
