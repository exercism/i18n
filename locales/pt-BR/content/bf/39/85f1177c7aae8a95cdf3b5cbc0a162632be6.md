# CLI

## Configuração

A maneira mais simples de instalar o Purescript é pelo Node.js e o NPM.

Se você ainda não tem o Node.js instalado no seu computador, pode baixá-lo no [site do Node.js][nodejs-website]. Depois que o Node.js estiver funcionando, digite este comando no terminal para instalar o compilador do PureScript e o Spago, o gerenciador de pacotes e ferramenta de build.

```shell
npm install -g purescript spago
```

Você encontra mais informações no [repositório do PureScript][purescript-repository].

## Requisitos

Instale as dependências do exercício:

```shell
spago install
spago build
```

## Fazendo a suíte de testes passar

Execute os testes com:

```shell
spago test
```

Na suíte de testes, todos os testes, exceto o primeiro, estão ignorados. Isso serve para incentivar você a resolver o exercício um passo de cada vez.

Quando você conseguir fazer um teste passar, pode ativar o próximo trocando `xit` por `it`.

## Enviando a solução

Quando nenhum teste estiver ignorado e todos estiverem passando, você pode enviar sua solução com:

```shell
exercism submit src/<NAME>.purs
```

## Escrevendo testes personalizados

Se você quiser escrever testes adicionais e personalizados, crie um novo arquivo `test/Custom.purs` e envie-o junto com sua solução:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
