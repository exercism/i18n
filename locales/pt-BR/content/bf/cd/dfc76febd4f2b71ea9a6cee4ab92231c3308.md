# Como aprender MoonScript

Leia [An Overview of MoonScript][leafo], de Leafo, o criador do MoonScript.
É um ótimo ponto de partida se você está começando agora tanto com MoonScript quanto com Lua, pois explica conceitos fundamentais.

O principal lugar para encontrar os Learning Resources é [o site do MoonScript][learn].
Ele pressupõe que você já conheça Lua.

[leafo]: https://leafo.net/posts/moonscript_overview.html
[learn]: https://moonscript.org/#learning
