# Dicas

## Geral

- Revise as funções disponíveis no [módulo `NaiveDateTime`][naive-date-time], no [módulo `Date`][date] e no [módulo `Time`][time].

## 1. Analise as datas e horas armazenadas

- Existe uma [função nativa][naive-date-time-from-iso8601] que analisa uma string de data e hora no formato ISO8601 e retorna uma struct `NaiveDateTime`.

## 2. Determine se um livro foi retirado antes do meio-dia

- Você pode definir um literal `Time` usando o [sigilo `~T`][time-sigil].
- Existe uma [função nativa][naive-date-time-to-time] que converte uma struct `NaiveDateTime` em uma struct `Time`.
- Existe uma [função nativa][time-compare] que verifica qual de duas structs `Time` é maior.

## 3. Calcule a data de devolução

- Um dia tem `24 * 60 * 60` segundos.
- Existe uma [função nativa][naive-date-time-add] que adiciona um determinado número de segundos a uma struct `NaiveDateTime`.
- Existe uma [função nativa][naive-date-time-to-date] que converte uma struct `NaiveDateTime` em uma struct `Date`.

## 4. Determine o atraso na devolução do livro

- Existe uma [função nativa][naive-date-time-to-date] que converte uma struct `NaiveDateTime` em uma struct `Date`.
- Existe uma [função nativa][date-diff] que calcula a diferença em dias entre duas structs `Date`.

## 5. Determine se o livro foi devolvido em uma segunda-feira

- Existe uma [função nativa][naive-date-time-to-date] que converte uma struct `NaiveDateTime` em uma struct `Date`.
- Existe uma [função nativa][date-day-of-week] que retorna o dia da semana de uma struct `Date`.

## 6. Calcule a multa por atraso

- Combine todas as funções que você definiu nos passos anteriores.
