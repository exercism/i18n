# Instruções

Neste exercício, você vai escrever código para imprimir crachás de identificação para os funcionários de uma fábrica.
Cada funcionário tem um ID, um nome e o nome do departamento.
A etiqueta do crachá de cada funcionário segue este formato: `"[id] - name - DEPARTMENT"`.

## 1. Imprima um crachá para um funcionário

Implemente a função `print_name_badge`. Ela deve receber um ID, um nome e um departamento.
Ela deve retornar a etiqueta do crachá, com o nome do departamento em maiúsculas.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Imprima um crachá para um novo funcionário

Por causa de uma peculiaridade no sistema do computador, às vezes os novos funcionários ainda não têm um ID quando começam a trabalhar na fábrica.
Como os crachás são obrigatórios, eles vão receber um crachá temporário, sem o prefixo do ID.

Estenda a função `print_name_badge`. Quando o id estiver ausente, ela deve imprimir um crachá sem ele.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Imprima um crachá para o dono

Até o dono da fábrica precisa usar um crachá o tempo todo.
No entanto, o dono não tem um departamento e nunca vai ter: ele está acima de todos os departamentos.
Nesse caso, a etiqueta deve imprimir `"OWNER"` em vez do nome do departamento.

Estenda a função `print_name_badge`. Quando o departamento for `NULL`, considere que o crachá pertence ao dono da empresa.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

Repare que é possível que o dono também seja um novo funcionário.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. Calcule o salário total dos funcionários sem ID

Como uma métrica aproximada de quão bem os IDs estão sendo emitidos, você quer ver a soma dos salários dos funcionários sem ID.
Um valor alto significa que há muita gente esperando, ou que o problema está afetando funcionários mais antigos: as duas coisas são ruins.

Implemente a função `salaries_no_id`, que recebe um vetor de IDs e um vetor correspondente de salários e retorna a soma dos salários das pessoas que ainda não têm ID.
Os dois vetores têm o mesmo comprimento.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_Como um aprendizado extra que não é testado:_ se não há funcionários sem ID, qual é o "vetor vazio" que você está somando?
