# Instruções

Você tem trabalhado em um projeto que permite que usuários enviem arquivos para o servidor para serem compartilhados com outros usuários. Você recebeu a tarefa de escrever uma função para verificar se um arquivo enviado corresponde ao seu [tipo de mídia][mimetype]. Você faz uma pesquisa e descobre que os primeiros bytes de um arquivo geralmente são únicos para aquele tipo de arquivo, o que lhe dá uma espécie de assinatura.

Use a tabela a seguir como referência:

| Tipo de arquivo | Extensão comum | Tipo de mídia                | assinatura binária                               |
| --------------- | -------------- | ---------------------------- | ------------------------------------------------ |
| ELF             | `"exe"`        | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP             | `"bmp"`        | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG             | `"png"`        | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG             | `"jpg"`        | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF             | `"gif"`        | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. Dada uma extensão, retorne o tipo de mídia esperado

Implemente a função `type_from_extension/1`. Ela deve receber uma extensão de arquivo (string) e retornar o tipo de mídia (string) ou nil se a extensão não corresponder às esperadas.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. Dado um arquivo binário, retorne o tipo de mídia esperado

Implemente a função `type_from_binary/1`. Ela deve receber um arquivo (binário) e retornar o tipo de mídia (string) ou nil se a assinatura do arquivo não corresponder às esperadas.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

Não se preocupe em ler o arquivo como binário. Considere que isso já foi feito para você e que é fornecido pelos testes como argumento.

## 3. Dada uma extensão e um arquivo binário, verifique se o arquivo corresponde ao tipo esperado

Implemente a função `verify/2`. Ela deve receber um arquivo (binário) e uma extensão (string) e retornar uma tupla `:ok` ou `:error`.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
