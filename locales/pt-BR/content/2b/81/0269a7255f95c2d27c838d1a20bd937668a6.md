# Sobre

Lua usa duas representações para números: números inteiros de 64 bits e números de ponto flutuante de precisão dupla.

~~~exercism/note
Antes da versão 5.3, Lua representava todos os números usando o formato de ponto flutuante de precisão dupla.
~~~

Números podem ser escritos com uma parte decimal opcional e um expoente decimal opcional.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

Um número com ponto decimal ou um expoente é considerado um número de ponto flutuante, e sem eles é tratado como inteiro, mas ambos têm o tipo 'number'.
```lua
type(1)         --> number
type(2.0)       --> number
```

Se quisermos distinguir entre números de ponto flutuante e inteiros, podemos usar a função `type` do módulo `math`.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## Comparação

Inteiros e números de ponto flutuante com o mesmo valor são considerados iguais:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## Aritmética

Lua suporta o conjunto usual de operadores aritméticos: adição, subtração, multiplicação, divisão e negação. Além disso, suporta divisão inteira, módulo e exponenciação.

### Adição, Subtração, Multiplicação e Negação

Se ambos os operandos forem inteiros, o resultado da operação é um inteiro. O mesmo se aplica a números de ponto flutuante.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

Se um operando for um número de ponto flutuante, os inteiros restantes também serão convertidos para números de ponto flutuante e a operação resultará em um número de ponto flutuante.
```lua
1.0 + 2   --> 3.0
```

### Divisão

A divisão sempre opera sobre números de ponto flutuante e dá um número de ponto flutuante como resultado.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

Dividir por zero resultará em `inf` ou `-inf`. Dividir zero por zero resultará em `-nan`.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### Divisão inteira

Se um resultado inteiro for necessário, pode-se usar a divisão inteira. A divisão inteira sempre arredonda o quociente em direção ao infinito negativo, garantindo um resultado inteiro para todos os operandos.

~~~exercism/note
Antes da versão 5.3, Lua não tinha operador aritmético para divisão inteira.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

A divisão inteira segue as mesmas regras dos operadores de adição, subtração, multiplicação e negação: se ambos os operandos forem inteiros, o resultado da operação é um inteiro; caso contrário, o resultado é um número de ponto flutuante.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

Ao dividir por zero usando divisão inteira, Lua gerará um erro.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### Módulo

O módulo é usado para obter o resto da divisão de dois operandos.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### Exponenciação

Assim como a divisão, a exponenciação também opera sobre números de ponto flutuante e dá números de ponto flutuante como resultado.
```lua
10 ^ 2    --> 100.0
```

## Precedência

Todas as operações são avaliadas de acordo com a [precedência de operadores](https://www.lua.org/manual/5.4/manual.html#3.4.8). Parênteses podem ser usados para mudar a precedência de uma expressão.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## Arredondamento

O módulo `math` fornece três funções de arredondamento: `floor` arredonda "para baixo" (em direção ao infinito negativo), `ceil` arredonda "para cima" (em direção ao infinito positivo) e `modf` arredonda em direção a zero.

### `math.floor`

`floor` arredonda em direção ao infinito negativo.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` arredonda em direção ao infinito positivo.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` arredonda em direção a zero. A função retorna o valor arredondado e também a parte fracionária do número, que é sempre um número de ponto flutuante.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## Conversão

Se quisermos converter um inteiro em um número de ponto flutuante, podemos somar `0.0` a ele.
```lua
1 + 0.0         --> 1.0
```

Se quisermos converter um número de ponto flutuante em um inteiro, podemos fazer um OU bit a bit com zero ou usar a função `tointeger` do módulo `math`.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

Se o número não puder ser convertido em um inteiro, o operador OU gerará um erro e a função `tointeger` retornará `nil`.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## Hexadecimal

Assim como muitas outras linguagens de programação, Lua suporta números hexadecimais ao prefixá-los com `0x`, mas, diferentemente de muitas outras linguagens de programação, Lua também suporta números hexadecimais de ponto flutuante. Eles podem ter uma parte fracionária e um expoente binário, prefixado por 'p' ou 'P'.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
