# Instruções

Elena, a nova gerente de qualidade de uma fábrica de jornais, pede que você
escreva um pequeno programa para monitorar a sala de produção.

## 1. Defina um erro personalizado

Defina uma classe de tupla de erro `machine-error` usando a palavra de
parsing `ERROR:`. Ela não precisa de slots.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. Verifique a umidade

Defina `check-humidity`. Ela pega uma leitura de umidade da pilha
e usa `throw` para lançar a string `"humidity too high"` quando a leitura
for estritamente maior que `70`. Caso contrário, ela não retorna nada.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. Verifique a temperatura

Defina `check-temperature`. Ela pega uma leitura de temperatura e
usa `throw` para lançar a string `"temperature too high"` quando a leitura
for estritamente maior que `500`. Caso contrário, ela não retorna nada.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. Monitore a máquina

Defina `monitor` para pegar uma umidade e uma temperatura da pilha e
rodar as duas verificações. Se qualquer uma das verificações lançar uma
exceção, `monitor` deve lançar um `machine-error` novo em vez disso. Se
as duas passarem, `monitor` não retorna nada.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. Monitore um lote de leituras

Defina `monitor-batch` para pegar um array de leituras
`{ humidity temperature }` e retornar quantas delas falhariam (ou seja,
quantas fariam `monitor` lançar uma exceção).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
