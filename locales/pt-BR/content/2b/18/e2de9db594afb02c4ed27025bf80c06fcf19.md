# Instalação

A única coisa de que você vai precisar para rodar estes exercícios é o [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) e o [Java 8](https://java.com/en/download/) instalados.  O CommandBox CLI tem suporte a Mac, Linux e Windows, e o guia de instalação está aqui:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

Um exemplo de como configurar o CommandBox CLI, se você usa Homebrew no Mac, seria:

```bash
brew install commandbox
```

Depois de instalar o CLI, você pode brincar com o REPL:

```bash
box repl
```

Você pode executar páginas .cfm diretamente:

```bash
box exec myTest.cfm
```

E você pode até iniciar um servidor web em qualquer pasta do seu disco rígido:

```bash
box server start
```

O CommandBox tem um shell interativo que você pode usar, com autocompletar com Tab aprimorado e que roda mais rápido.  Para entrar nele, basta rodar o binário `box` sem nenhum argumento.

```bash
box
```
