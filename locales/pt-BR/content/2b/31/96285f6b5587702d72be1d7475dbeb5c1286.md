# Instruções

Neste exercício, você vai escrever um TreasureChest genérico (e mágico!), para armazenar alguns tesouros.

## 1. Defina o tipo personalizado genérico TreasureChest

Defina um tipo personalizado `TreasureChest` com uma única variante.

A variante deve ter um valor `String` associado, que será usado para armazenar a senha do baú de tesouro.

A variante também deve ter um valor genérico associado, que será usado para armazenar o tesouro.
Esse valor é genérico para que o tesouro possa ser qualquer coisa.

## 2. Defina o tipo UnlockResult

Defina um tipo personalizado `UnlockResult` com duas variantes.

A primeira variante deve ser `Unlocked` e deve guardar um valor genérico, que será usado para armazenar o tesouro.

A segunda variante deve ser `WrongPassword`, que não guarda nenhum valor.

## 3. Defina a função get_treasure

Essa função deve receber dois parâmetros

- um tipo personalizado genérico `TreasureChest`
- uma `String` (para tentar uma senha)

Essa função deve conferir a tentativa de senha fornecida com a `String` dentro do `TreasureChest`.

A função deve retornar um `UnlockResult`.

Se as senhas coincidirem, retorne `Unlocked` com o valor genérico do `TreasureChest` (o tesouro!).

Se as senhas não coincidirem, retorne `WrongPassword`.
