# Introdução

## Arrays

Em Common Lisp, assim como em outras linguagens, um array é um conjunto de elementos acessados por índices inteiros. Em português, ele também é chamado de vetor.
Os tipos dos elementos podem ser heterogêneos.
O array pode ser multidimensional (não apenas unidimensional).

### Criando arrays

`make-array` permite criar arrays.
Ela tem muitas opções, mas suas formas mais simples permitem criar arrays de N dimensões com todos os elementos inicializados com um único valor, ou com o array inicializado com os valores de outra sequência (como uma lista). 
Seu primeiro argumento é uma lista com o tamanho de cada dimensão.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Repare que os arrays de N dimensões são impressos com o número de dimensões.)

Também é possível criar arrays usando o mesmo formato em que eles são impressos: 

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### Acessando elementos

Para acessar elementos de um vetor, use `aref`. Os índices começam em zero. 
O número de índices fornecidos deve corresponder ao número de dimensões do array.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
