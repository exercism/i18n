# Anexo das instruções

Uma solução possível para este exercício é implementar sua própria função de exponenciação modular.
Para saber mais a respeito, consulte a [página a seguir](https://en.wikipedia.org/wiki/Modular_exponentiation).

## Para ganhar pontos extras

Muitas implementações não funcionam para todo o domínio de entradas.
Existem testes opcionais adicionais definidos que ajudam a garantir que todas as entradas válidas produzam resultados válidos.

Para rodar os testes de bônus, remova a flag `#[ignore]` e rode os testes com o recurso `big-primes`, assim:

```bash
$ cargo test --features big-primes
```
