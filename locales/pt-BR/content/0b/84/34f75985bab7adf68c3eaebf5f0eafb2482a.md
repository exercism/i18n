# Anexo das instruções

## Implementação

Neste exercício, você vai instanciar uma classe e adicionar alguns métodos de instância. Para saber como fazer isso, consulte [Escrevendo classes em Ruby][writing-classes].

Uma classe HighScore recebe um array com um ou mais números, cada um representando uma "pontuação de jogo".
A classe Array pode servir de inspiração para trabalhar com arrays; veja a [documentação do Ruby][ruby-docs-array].

[ruby-docs-array]: https://docs.ruby-lang.org/en/master/Array.html
