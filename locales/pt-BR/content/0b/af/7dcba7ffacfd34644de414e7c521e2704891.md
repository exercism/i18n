# Dicas

## 1. Verifique se o comando é válido

- Use o método [test()][mdn-regex-test] para retornar um Boolean.
- Lembre-se de que podemos usar [flags][mdn-flags] no final da expressão regular para recursos adicionais, como a insensibilidade a maiúsculas e minúsculas.

## 2. Remova os emojis criptografados

- Neste caso, devemos usar o construtor [RegExp][mdn-regular-expressions] para montar nossa expressão regular.
- Graças à criptografia comum de cada emoji, podemos usar `[0-9]` para procurar qualquer dígito depois da palavra `emoji`.
- O caractere `+` corresponde a um ou mais itens consecutivos.
- Use o método [split()][mdn-regex-split] junto com a regex de cada emoji para se livrar de toda a criptografia.
- Por fim, retorne esse array dividido como uma string usando o método [join()][mdn-join].

## 3. Verifique se o número de telefone é válido

- Neste exercício, estamos brincando com `groups and ranges`. Leia esta [documentação][mdn-groups] para aprender mais sobre isso.
- Este [artigo][phone-validation] explica muito bem diferentes formas de validação de números.
- Você também pode querer usar esta [referência rápida][mdn-regex-cheatsheet] para ter uma visão ampla dos recursos disponíveis nas expressões regulares.
- Use o método `test()` para verificar se o número de telefone é válido ou não.
- Retorne a resposta final com um simples `if statement`.

## 4. Obtenha o link do site

- Estamos buscando palavras unidas por um ou mais `.(dots)`.
- Lembre-se de colocar a flag `g` no final para que possamos pegar todos os domínios em qualquer frase.
- Use o método [match()][mdn-regex-match] para retornar um array com todas as correspondências anteriores.

## 5. Cumprimente o usuário

- Primeiro, use o método [replace()][mdn-regex-replace] diretamente na string fornecida.
- Use [Grupos de captura nomeados][mdn-groups] para armazenar o `name` e o `surname` em valores diferentes.
- Passe uma desestruturação `(...match)` para a função de substituição para conseguir o nome e o sobrenome dentro do objeto nos grupos correspondentes.
- Use o método `pop()` para armazenar o objeto correspondente com `name` e `surname`.
- Por fim, implemente uma `template String` para obter os valores do objeto da expressão regular. Veja [este][mdn-capturing-groups] exemplo para saber como match() armazena objetos.
