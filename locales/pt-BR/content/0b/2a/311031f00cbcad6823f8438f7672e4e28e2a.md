# Apêndice de instruções

## Instruções específicas da trilha

Para este exercício, você precisa definir um **locale** chamado `robot` que define os **substantivos** `position` e `direction` e um **verbo** `move`.

- O verbo `create` de `robot` recebe a posição e a direção iniciais como um array de caixas.
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move` atualiza os valores de `position` e `direction` na **instância** criada.
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
