# Dicas

## Geral

- Talvez dê uma olhada em [Interfaces no Tour of Go][interfaces-tour-of-go] para ver mais exemplos, caso tenha dificuldade com o exercício.

## 1. Crie a funcionalidade abstrata de saudação

- Volte ao exemplo `Counter` da introdução para descobrir como definir uma interface.
- Releia os [conceitos de funções][concept-functions] para relembrar como escrever assinaturas de função em Go.
- O tipo abstrato `Greeter` pode ser usado em uma assinatura de função da mesma forma que um tipo concreto comum, como `string`.
- Para implementar `SayHello`, chame os métodos no argumento do tipo `Greeter`.
  Depois, use formatação de string ou concatenação de strings para montar o resultado final.

## 2. Implemente o italiano

- Releia o [conceito de structs][concept-structs] para ver como definir um tipo struct.
- Para resolver a tarefa, a struct não precisa de nenhum campo.
- Depois de definir a struct, você vai querer adicionar a ela os métodos `LanguageName` e `Greet`.
  Releia o [conceito de métodos][concept-methods] para descobrir como adicionar um método a um tipo.
