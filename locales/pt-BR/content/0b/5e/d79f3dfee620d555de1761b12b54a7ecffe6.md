# Complemento das instruções

## Mensagens de exceção

Às vezes é necessário [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você faz isso, deve sempre incluir uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda bastante na depuração. Quando você sabe que a origem do erro é de um tipo específico, pode optar por lançar um dos [tipos de erro internos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda assim deve incluir uma mensagem significativa.

Este exercício em particular pede que você use a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um `ValueError` quando não for possível fazer o troco com as moedas dadas. Os testes só vão passar se você fizer `raise` da `exception` e incluir uma mensagem junto.

Para lançar um `ValueError` com uma mensagem, escreva a mensagem como argumento para o tipo `exception`:

```python
# example when change cannot be made with the coins passed in
raise ValueError("can't make target with given coins")
```
