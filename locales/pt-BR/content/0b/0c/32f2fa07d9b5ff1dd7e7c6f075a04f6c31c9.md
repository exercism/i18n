# Números inteiros

Números inteiros são números sem parte fracionária que pertencem ao conjunto `{..., -2, -1, 0, 1, 2, ...}`.
Os valores máximo e mínimo de um número inteiro dependem do sistema em que o PHP roda.
Normalmente, na maioria dos sistemas modernos, o número inteiro é um valor de 64 bits, ou seja, ele pode representar de `-9_223_372_036_854_775_808` a `9_223_372_036_854_775_807`, inclusive.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Você pode escrever valores literais inteiros em bases diferentes de 10 usando um prefixo de base:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
