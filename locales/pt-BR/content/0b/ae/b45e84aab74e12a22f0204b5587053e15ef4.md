# Sobre

`Nil` em Gleam é um tipo com um único valor, também chamado `Nil`. Ele é parecido com `void` em outras linguagens, no sentido de que é usado quando uma função não tem nenhum valor mais adequado para retornar.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Em Gleam, os valores não são anuláveis como em algumas outras linguagens. Um valor só pode ser `Nil` se o tipo dele for `Nil`, e um valor de qualquer outro tipo nunca pode ser `Nil`.
