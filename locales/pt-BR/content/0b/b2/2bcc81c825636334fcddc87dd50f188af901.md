# Apêndice da introdução

## Implementação

Existem várias formas de resolver o **ano bissexto**. Este exercício foca em não usar o método `Time.leap_year?` embutido.
Isso porque o objetivo deste exercício é aprender a lidar com comparações e lógica booleana.
Mas, para qualquer outra finalidade, recomenda-se usar o método embutido.
