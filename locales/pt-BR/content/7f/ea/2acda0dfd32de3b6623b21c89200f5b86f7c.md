# Instruções

Neste exercício, você vai implementar uma forma de acompanhar os recordes do jogo mais popular do fliperama da sua região.

Você tem 5 funções para implementar, a maioria relacionada à manipulação de um objeto que guarda os recordes.

## 1. Criar um novo placar de recordes

Crie uma função `createScoreBoard` que cria um objeto que serve como placar de recordes.
As chaves desse objeto serão os nomes dos jogadores e os valores serão as pontuações deles.
Para fins de teste, você quer incluir uma entrada diretamente no objeto.
Essa entrada inicial deve conter `The Best Ever` como nome de jogador e `1000000` como pontuação.

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. Adicionar jogadores a um placar de recordes

Para adicionar um jogador ao placar de recordes, defina a função `addPlayer`.
Ela aceita 3 parâmetros:

- O primeiro parâmetro é um objeto de placar de recordes existente.
- O segundo parâmetro é o nome de um jogador como uma string.
- O terceiro parâmetro é a pontuação como um número.

A função retorna o mesmo objeto de placar que foi passado, depois de adicionar o novo jogador.

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. Remover jogadores de um placar de recordes

Se os jogadores violarem as regras do fliperama, eles são removidos manualmente do placar de recordes.
Defina `removePlayer`, que recebe 2 parâmetros:

- O primeiro parâmetro é um objeto de placar de recordes existente.
- O segundo parâmetro é o nome do jogador como uma string.

Essa função deve remover a entrada do jogador em questão do placar e retornar o placar em seguida.
Se o jogador não estava no placar desde o início, nada deve acontecer com o placar.
Ele deve ser retornado como está.

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. Aumentar a pontuação de um jogador

Se um jogador termina outro jogo no fliperama, uma certa quantidade de pontos será adicionada à pontuação anterior no placar.
Implemente `updateScore`, que recebe 3 parâmetros:

- O primeiro parâmetro é um objeto de placar de recordes existente.
- O segundo parâmetro é o nome do jogador cuja pontuação deve ser aumentada.
- O terceiro parâmetro é a pontuação que você deseja **adicionar** ao recorde armazenado.

A função deve retornar o placar depois que a atualização for feita.

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. Aplicar os pontos de bônus de segunda-feira

O fliperama mantém um placar separado às segundas-feiras.
No fim do dia, cada jogador nesse placar ganha 100 pontos adicionais.

Implemente a função `applyMondayBonus`, que aceita um placar.
A função adiciona os pontos de bônus para cada jogador listado nesse placar.
Depois, o placar é retornado.

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
