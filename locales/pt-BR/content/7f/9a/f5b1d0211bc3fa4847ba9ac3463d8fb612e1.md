# Instruções

Um espetáculo de circo é uma ordem de apresentação de números. Números
diferentes são completamente diferentes por dentro, e quem monta o espetáculo
precisa das mesmas duas coisas de cada um deles.

Este é o primeiro exercício em que você escreve várias classes em um único
arquivo. O esqueleto traz a classe abstrata; escreva o restante abaixo dela.

## 1. Os três números

Escreva três classes, cada uma um `$ACT`.

| Classe | `name` | `minutes` |
| --- | --- | --- |
| `JUGGLING` | `"Juggling"` | 5 |
| `TUMBLING` | `"Tumbling"` | 3 |
| `TRAPEZE` | `"Trapeze at "` depois a altura e depois `"m"` | 8 |

`JUGGLING` e `TUMBLING` são criadas sem argumentos. `TRAPEZE` é criada com a
altura em metros:

```sather
#JUGGLING
#TRAPEZE(4)
```

então `#TRAPEZE(4).name` é `"Trapeze at 4m"`.

## 2. O espetáculo

Escreva uma classe `CIRCUS_ACTS` com três rotinas, cada uma recebendo a ordem
de apresentação como um `ARRAY{$ACT}`.

**`total_minutes`**: quanto tempo o espetáculo inteiro dura.

```sather
CIRCUS_ACTS::total_minutes(|#JUGGLING, #TUMBLING|)
-- => 8
```

**`billing`**: os nomes dos números, unidos com `", "`.

```sather
CIRCUS_ACTS::billing(|#JUGGLING, #TUMBLING|)
-- => "Juggling, Tumbling"
```

**`longest`**: o nome do número que leva mais tempo. Quando dois empatam, o que
vem antes vence. Um espetáculo vazio não tem número mais longo, então a resposta
é `""`.

```sather
CIRCUS_ACTS::longest(|#JUGGLING, #TUMBLING|)
-- => "Juggling"
```

Nenhuma das três pode perguntar que tipo de número é.
