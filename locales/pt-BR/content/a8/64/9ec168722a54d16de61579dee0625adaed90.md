# Dicas

## Geral

- Você pode ler sobre [Eliminação de chamada de cauda][tail-call-elimination] com o criador do Elm
- Em funções recursivas de cauda, a _última_ operação em um bloco chama a si mesma em uma aplicação simples de função
- Você vai precisar definir funções auxiliares recursivas de cauda

## 1. Fatorial

- Você vai precisar definir uma função auxiliar recursiva de cauda
- O fatorial de 0 é 1
- Use recursão para reduzir `n` até seu caso base, mantendo o controle do produto

## 2. Fatorial duplo

- Você vai precisar definir uma função auxiliar recursiva de cauda
- O fatorial duplo de 0 é 1
- O fatorial duplo de 1 é 1
- Use recursão para reduzir `n`, de dois em dois, até seu caso base, mantendo o controle do produto

## 3. Transformação de convergência de Newton/Euler

- Você vai precisar definir uma função auxiliar recursiva de cauda
- Usar `factorial` e `doubleFactorial` diretamente não é recomendado, pois não é a forma mais eficiente de criar os termos da soma
- Você pode passar quantos argumentos quiser para a função auxiliar
