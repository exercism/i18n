# Introdução

## Interface como um conjunto de métodos

Na sua forma mais simples, um **tipo de interface** é um conjunto de assinaturas de métodos.
Veja um exemplo de definição de interface que inclui dois métodos, `Add` e `Value`:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Os nomes de parâmetros como `increment` podem ser omitidos da definição da interface, mas muitas vezes aumentam a legibilidade.

Os nomes de interfaces em Go não contêm a palavra `Interface` nem `I`.
Em vez disso, costumam terminar com `er`, por exemplo `Reader`, `Stringer`.

## Implementando uma interface

Qualquer tipo que defina os métodos da interface automaticamente "implementa" a interface, de forma implícita.
Não existe a palavra-chave `implements` em Go.

O tipo a seguir implementa a interface `Counter` que vimos acima.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Para implementar a interface, não importa se o método tem receptor de valor ou de ponteiro.
(Reveja os [conceitos de métodos][concept-methods] se tiver dúvidas sobre isso.)

> Um valor de tipo interface pode conter qualquer valor que implemente esses métodos. ((Go Tour: Interfaces)[go-tour-interfaces])

Isso significa que `Stats` agora pode ser usado em todos os lugares que esperam a interface `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Como as interfaces são implementadas de forma implícita, um tipo pode implementar várias interfaces facilmente.
Ele só precisa ter todos os métodos necessários definidos.

## Interface vazia

Existe um tipo de interface muito especial em Go, o **tipo interface vazia**, que contém zero métodos.
A interface vazia é escrita assim: `interface{}`.
No Go 1.18 ou superior, `any` também pode ser usado.
Ele foi definido como um alias.

Como a interface vazia não tem métodos, todo tipo a implementa de forma implícita.
Isso é útil para definir uma função que possa aceitar qualquer valor de forma genérica.
Nesse caso, o parâmetro da função usa o tipo interface vazia.
