# Instruções

Neste exercício, você vai escrever código para ajudar uma pessoa freelancer a se comunicar com um gerente de projeto.
Sua tarefa é fornecer alguns utilitários para calcular rapidamente as taxas diária e mensal, opcionalmente com um desconto dado.

Primeiro, estabelecemos algumas regras entre a pessoa freelancer e o gerente de projeto:

- A taxa diária é 8 vezes a taxa horária.
- Um mês tem 22 dias faturáveis.

Às vezes, a pessoa freelancer oferece aplicar um desconto sobre sua taxa diária (por exemplo, para clientes mais fiéis ou clientes sem fins lucrativos).

Os descontos são modelados como números fracionários que representam porcentagens, por exemplo, `25.0` (25%).

~~~~exercism/note
Estes são os sufixos das instruções de ponto flutuante:

| Sufixo | Tamanho do operando |
|--------|--------------|
| `ss`   | 32 bits      |
| `sd`   | 64 bits      |

Estas são algumas das instruções mencionadas neste conceito:

| Instrução       | Descrição                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | copia b para a                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | converte o inteiro b para ponto flutuante a            |
| roundss/roundsd a, b, c | arredonda o ponto flutuante b de acordo com c e armazena em a |
| cvtss2si/cvtsd2si a, b  | converte o ponto flutuante b para o inteiro a          |
| comiss/comisd a, b      | faz uma comparação entre a e b, exceção se `NaN`       |
| ucomiss/ucomisd a, b    | faz uma comparação entre a e b, define `PF` se `NaN`   |

Estes são os números de controle de arredondamento em `roundss` e `roundsd`:

| Número | Modo            |
|:-------|:----------------|
| 0      | Mais próximo    |
| 1      | Para baixo      |
| 2      | Para cima       |
| 3      | Truncar         |
~~~~

## 1. Calcule a taxa diária a partir de uma taxa horária

Implemente uma função chamada `daily_rate` para calcular a taxa diária a partir de uma taxa horária recebida como parâmetro, como um número de ponto flutuante de 64 bits.
O contrato define que um dia tem 8 horas faturáveis.

```c
daily_rate(60)
// => 480.0
```

A taxa diária retornada deve ser um número de ponto flutuante de 64 bits.

## 2. Calcule um preço com desconto

Implemente uma função `apply_discount` para calcular o preço após um desconto.
Ela deve aceitar dois parâmetros: o preço original e a taxa de desconto em porcentagem, ambos como um número de ponto flutuante de 64 bits.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

O valor retornado deve ser sempre um número de ponto flutuante de 64 bits.

## 3. Calcule a taxa mensal, a partir de uma taxa horária e de um desconto

Implemente uma função `monthly_rate` para calcular a taxa mensal com desconto.
Ela recebe dois parâmetros: uma taxa horária e o desconto em porcentagem, ambos como um número de ponto flutuante de 64 bits.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

A taxa mensal retornada deve ser arredondada para cima (teto) para o inteiro de 64 bits mais próximo.

## 4. Calcule o número de dias úteis completos a partir de um orçamento, uma taxa horária e um desconto

Implemente uma função `days_in_budget` que recebe como parâmetros:

1. Um orçamento, como um inteiro sem sinal de 64 bits.
2. Uma taxa horária, como um número de ponto flutuante de 64 bits.
3. Um desconto em porcentagem, como um número de ponto flutuante de 64 bits.

Essa função deve retornar o número de dias completos de trabalho que o orçamento cobre.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

O número de dias retornado deve ser arredondado para baixo (piso) para o inteiro de 32 bits mais próximo.
