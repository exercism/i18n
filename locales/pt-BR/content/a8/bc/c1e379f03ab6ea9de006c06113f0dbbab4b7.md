# sem rescue

Não use exceções para controle de fluxo.
Tente resolver este exercício sem usar `rescue`.

Se você estiver usando uma função da biblioteca padrão com um nome terminando em `!` (que levanta erros), procure uma função equivalente sem o `!` (muitas vezes elas retornam `{:ok, result}` ou `{:error, message}`).

Observação: se você está vendo este comentário automático na sua solução, outros comentários automáticos podem não estar corretos.
Corrija este problema primeiro!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
