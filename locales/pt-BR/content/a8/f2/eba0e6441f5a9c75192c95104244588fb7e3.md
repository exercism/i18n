# Introdução

Um `vector` em Clojure é uma coleção sequencial, indexada e imutável de zero ou mais valores. Ou seja, depois que um vector é criado, ele não pode ser modificado. As funções que operam sobre vectors retornam um novo vector, e o vector original permanece inalterado. Os valores em um vector podem ser de tipos heterogêneos. Vectors podem ser definidos assim:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

É possível obter elementos de um vector usando um índice. Os vectors do Clojure têm base zero, o que significa que o índice do primeiro elemento é sempre zero:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

O vector original permanece inalterado:

```clojure
numbers
;;=> [2 3 5]
```

Para guardar o valor atualizado, precisamos passá-lo adiante ou capturá-lo em uma var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
