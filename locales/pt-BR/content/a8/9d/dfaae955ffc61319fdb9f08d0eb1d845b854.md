# Instruções

Você está desenvolvendo o novo e muito elogiado jogo **Wings Quest**.
No jogo, você é um pássaro que se move e coleta sementes.
O jogador vence ao coletar todas as sementes.
Se o jogador entrar em contato com uma águia, perde todas as suas sementes e perde o jogo.
Há uma exceção a essa regra: o jogador pode ter um power-up ativo que permite voar mais alto que os outros pássaros.

Seu objetivo é escrever algumas regras que serão usadas no jogo.

## 1. Defina se o pássaro ganha pontos de bônus

No jogo, o pássaro ganha pontos de bônus se tocar uma águia enquanto tem um power-up.

Defina a função `bonusPoints(powerUpActive:touchingEagle:)` que recebe dois argumentos: `powerUpActive`, que indica se o pássaro tem um power-up ativo, e o argumento `touchingEagle`, que indica se o pássaro está tocando uma águia.
A função deve retornar `true` apenas se o pássaro tiver um power-up ativo e estiver tocando uma águia, e `false` caso contrário.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. Defina se o pássaro marca pontos

No jogo, o jogador ganha pontos ao pegar uma semente ou um power-up.

Defina a função `score(touchingPowerUp:touchingSeed:)` que recebe dois argumentos: `touchingPowerUp`, que indica se o pássaro está tocando um power-up, e o argumento `touchingSeed`, que indica se o pássaro está tocando uma semente.
A função deve retornar `true` se o pássaro estiver tocando um power-up ou uma semente, e retornar `false` caso contrário.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. Defina se o pássaro perde

Defina a função `lose(powerUpActive:touchingEagle:)` que recebe dois argumentos: `powerUpActive`, que indica se o pássaro tem um power-up ativo, e o argumento `touchingEagle`, que indica se o pássaro está tocando uma águia.
A função deve retornar `true` se o pássaro estiver tocando uma águia e não tiver um power-up ativo, e retornar `false` caso contrário.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. Defina se o pássaro vence

Defina a função `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)` que recebe os argumentos:

- `hasPickedUpAllSeeds` se o pássaro pegou todas as sementes.
- `powerUpActive` se o pássaro tem um power-up ativo.
- `touchingEagle` se o pássaro está tocando uma águia.

A função deve retornar `true` se o pássaro pegou todas as sementes e não perdeu, com base nos argumentos definidos na parte 3, e retornar `false` caso contrário.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
