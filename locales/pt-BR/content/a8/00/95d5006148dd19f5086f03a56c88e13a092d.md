# retorno explícito

Remova o `return` explícito para simplificar o método.

Em Ruby, um método retorna o resultado da última instrução avaliada. Usar a palavra-chave `return` de forma explícita é, portanto, desnecessário, exceto quando você quer retornar antes do fim do método.

Por exemplo, este código imprime `16`, já que o método `multiply` retorna o resultado de `a * b`, sua última expressão.

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
