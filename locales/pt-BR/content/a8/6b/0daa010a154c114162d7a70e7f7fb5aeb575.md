# Dicas

## Geral

- Para extrair vários argumentos nos parâmetros da função, você pode empacotá-los com o operador `*arguments` para **array** ou `**keyword_arguments` para argumentos de palavra-chave.
- Para empacotar ou desempacotar, use os operadores splat (`*` ou `**`).

## 1. Crie uma lista com todos os vagões

- Vários argumentos nos parâmetros da função podem ser empacotados com o operador `*arguments`.

## 2. Conserte a lista de vagões

- Usar desempacotamento com o operador splat (`*`) permite extrair os dois primeiros elementos de um **array** mantendo o restante intacto.
- Para adicionar outro **array** a um **array** existente, você pode usar o operador splat (`*`) para "espalhar" o **array**.

## 3. Adicione as paradas que faltam

- Usar `**keyword_arguments` como argumento de um método permite passar uma quantidade arbitrária de argumentos de palavra-chave.
- Usar `**<hash>` como argumento desempacota um `Hash` em argumentos de palavra-chave.
- Você pode colocar argumentos de palavra-chave em um `{}`, que é outra forma de criar um `Hash`.
- Para obter os valores de um `Hash`, você pode usar o método `Hash#values`.

## 4. Estenda as informações de rota

- Usar `**{some_hash: value}` como argumento desempacota o `Hash` em argumentos de palavra-chave.
