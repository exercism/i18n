# Dicas

## Geral

- Existem três operadores Boolean para trabalhar com valores Boolean: `not`, `&&` e `||`.
- É possível combinar vários operadores em uma única expressão.

## 1. Defina se o pac-man pode comer um fantasma

- A função deve retornar um valor `Bool`.
- Você pode usar o operador Boolean `&&` para combinar os argumentos e obter um resultado.

## 2. Defina se o pac-man marca pontos

- A função deve retornar um valor `Bool`.
- Você pode usar o operador Boolean `||` para combinar os argumentos e obter um resultado.

## 3. Defina se o pac-man perde

- A função deve retornar um valor `Bool`.
- Você pode usar os operadores Boolean `&&` e `not` para combinar os argumentos e obter um resultado.

## 4. Defina se o pac-man vence

- A função deve retornar um valor `Bool`.
- Você pode usar os operadores Boolean `&&` e `not` para combinar os argumentos e o resultado de uma das funções implementadas anteriormente.
