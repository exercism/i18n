# Strings

Uma **string** é uma cadeia de caracteres. O tipo de uma string em Sather é `STR`, e uma string é escrita entre aspas duplas.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## Juntando strings

O `+` junta duas strings de ponta a ponta.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

Nada é colocado entre elas, por isso é preciso incluir o espaço explicitamente. Se você deixar o espaço de fora, o resultado é `"JeanSibelius"`.

## Qual é o tamanho?

`.size` indica quantos caracteres uma string contém. Isso é um número inteiro, então seu tipo é `INT`.

```sather
"Sibelius".size      -- 8
```

Não há parênteses depois de `.size`, assim como em uma rotina que não recebe argumentos.

## Extraindo uma parte

`.head(n)` retorna os primeiros `n` caracteres. `.tail(n)` retorna os últimos `n`.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` conta a partir do início, `tail` conta a partir do fim. Ambos deixam a string original intacta e retornam uma nova.
