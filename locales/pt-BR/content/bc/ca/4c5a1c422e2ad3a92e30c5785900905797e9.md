# Permissões de repositório dos mantenedores

Um mantenedor de trilha é alguém que faz parte da equipe do GitHub da trilha.
Tornar-se membro da equipe de uma trilha é _somente por convite_.

```exercism/note
Se você quiser se tornar mantenedor de uma trilha, abra um tópico no [fórum](https://forum.exercism.org/c/exercism/building-exercism/125).
```

## Categoria de manutenção

Existem cinco categorias de manutenção:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

A categoria de manutenção de uma trilha é determinada por três variáveis:

1. Se a trilha está ativa (ou seja, se os estudantes podem entrar na trilha no site)
2. O número de mantenedores da trilha
3. O número de mantenedores da trilha que também estão na equipe `cross-track-maintainers` do GitHub

Para determinar a categoria de manutenção, encontre a primeira categoria que corresponde à trilha nesta tabela:

| Categoria             | Ativa? | Número de mantenedores | Número de mantenedores cross-track |
| --------------------- | ------ | ---------------------- | ---------------------------------- |
| wip-track             | Não    | Qualquer               | Qualquer                           |
| unmaintained          | Sim    | 0                      | 0                                  |
| maintained-autonomous | Sim    | > 0                    | = Número de mantenedores           |
| maintained-solitary   | Sim    | 1                      | 0                                  |
| maintained            | Sim    | > 1                    | < Número de mantenedores           |

## Permissões de repositório

A categoria de manutenção é usada para definir as permissões do(s) repositório(s) do GitHub da trilha.

| Categoria             | Exige PR | Exige aprovação de PR | Revisões da equipe cross-track |
| --------------------- | -------- | --------------------- | ------------------------------ |
| wip-track             | Não      | Não                   | Não                            |
| unmaintained          | Sim      | Sim                   | Sim                            |
| maintained-solitary   | Sim      | Sim                   | Sim                            |
| maintained-autonomous | Sim      | Não                   | Não                            |
| maintained            | Sim      | Não                   | Não                            |

```exercism/caution
A categoria `wip-track` é a única que permite que os mantenedores façam push para a `main`.
```

```exercism/caution
Os repositórios de ferramentas _sempre_ vão exigir aprovação de PR, pois seu conteúdo é protegido por um [arquivo CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners).
```
