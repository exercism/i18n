# Ajuda

Para conseguir ajuda se estiver com dificuldades, você pode usar um destes recursos:

- [TypeScript QuickStart](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)
- [ECMAScript 2015 Language Specification](https://www.ecma-international.org/wp-content/uploads/ECMA-262_6th_edition_june_2015.pdf) (pdf)
- [Mozilla JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference)
- [/r/typescript](https://www.reddit.com/r/typescript) é o subreddit do TypeScript.
- O [StackOverflow](https://stackoverflow.com/questions/tagged/typescript) pode ser usado para pesquisar seu problema e ver se ele já foi respondido. Você também pode fazer e responder perguntas.
