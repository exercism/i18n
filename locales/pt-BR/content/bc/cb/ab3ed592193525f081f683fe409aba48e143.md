# Introdução

Uma expressão switch pode fazer um valor corresponder a um dos casos de um conjunto de padrões e retornar o valor associado ou executar a ação associada. Essa correspondência é indicada pelo símbolo `=>`. Além disso, cada padrão pode ter uma guarda de caso opcional, introduzida com a palavra-chave `when`. A expressão da guarda de caso precisa ser avaliada como verdadeira para que aquele "braço" do switch seja selecionado. Os casos (também conhecidos como _braços do switch_) são avaliados na ordem em que aparecem no texto e, assim que uma correspondência é encontrada, o processo é interrompido e o valor associado é retornado.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
