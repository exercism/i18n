# Sobre

Existem dois tipos diferentes de números em Elixir: inteiros e números de ponto flutuante.

Inteiros são números sem parte fracionária.

```elixir
integer = 3
# => 3
```

Você encontra algumas funções úteis para trabalhar com inteiros no módulo [`Integer`][integer].

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

Números inteiros grandes (e também os números de ponto flutuante) costumam ser formatados separando cada 3 dígitos em grupos com um sublinhado.

```elixir
1_000_000
# => 1000000
```

O tamanho máximo dos números em Elixir é limitado apenas pela memória disponível no sistema, porque o Elixir usa [aritmética de precisão arbitrária][arbitrary-precision-arithmetic].

O Elixir também oferece notações abreviadas para escrever [inteiros binários, octais e hexadecimais][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Comparação

Inteiros e números de ponto flutuante podem ser considerados iguais ([`==`][kernel-equal]) se tiverem o mesmo valor. No entanto, como são tipos diferentes, nunca são estritamente iguais ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
