# Introdução

Uma tupla é um agrupamento _imutável_ de valores sem nome, mas ordenados.
Tuplas podem conter qualquer tipo de dado (ou vários tipos), incluindo outras tuplas.

As tuplas são definidas como valores separados por vírgula entre os caracteres `(` e `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Só é possível comparar tuplas com o mesmo tamanho e os mesmos tipos (na mesma ordem).
As tuplas têm igualdade estrutural, o que significa que elas são iguais _apenas_ se todos os seus valores forem iguais.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Existem três formas de extrair valores de uma tupla:

- As funções `fst` e `snd`
- Desconstrução da tupla
- Correspondência de padrões

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
