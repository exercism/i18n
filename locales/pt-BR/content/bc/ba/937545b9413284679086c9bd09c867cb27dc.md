# Sobre

[ABAP][abap] é uma linguagem de programação desenvolvida pela SAP para o desenvolvimento de aplicações de negócio com o ambiente de desenvolvimento ABAP de uma ABAP Platform.

O ABAP oferece suporte a:

- Um modelo de programação orientado a objetos, baseado em classes e interfaces do ABAP Objects.
- Um modelo de programação procedural, baseado em módulos de função e sub-rotinas.

Os dois modelos são interoperáveis. No Exercism, porém, o foco está apenas no modelo de programação orientado a objetos.

Você encontra mais informações na documentação do [ABAP Track][docs].
