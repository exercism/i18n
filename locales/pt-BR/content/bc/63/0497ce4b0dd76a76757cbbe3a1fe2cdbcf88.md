# Instruções adicionais

## Implementação

Sua lista também deve implementar a seguinte interface:

- `delete` (excluir a primeira ocorrência de um valor especificado)
- `count` (contar o número de itens da lista)

**NOTA**: _Não_ use uma biblioteca para implementar este exercício. _Não_ use um array subjacente para implementar este exercício.
