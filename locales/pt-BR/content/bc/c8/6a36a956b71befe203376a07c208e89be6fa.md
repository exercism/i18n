# Introdução

O Unison representa valores true e false com o tipo `Boolean`. Há apenas dois valores: `true` e `false`.

```unison
trueVariable = true
falseVariable = false
```

Podemos avaliar expressões booleanas com os operadores e (representado por `&&`), ou (representado por `||`) e não (representado por `not`).

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

As expressões booleanas de Unison permitem curto-circuito: se o primeiro argumento de uma expressão `&&` for `false`, não há motivo para continuar avaliando o segundo argumento.
Da mesma forma, se o primeiro argumento de uma expressão `||` for `true`, a expressão retornará `true` imediatamente.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
