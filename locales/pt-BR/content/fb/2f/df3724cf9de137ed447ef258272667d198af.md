Vale a pena pensar com cuidado na interface pública de uma base de código, já que cada função pública aumenta os custos de manutenção a longo prazo e torna a refatoração mais difícil.

Em todo exercício do Exercism, a interface pública é definida pelo conjunto de testes.
Se uma função está sendo testada, ela precisa ser pública.
Todas as outras funções devem ser privadas, incluindo funções com o mesmo nome, mas com aridades diferentes.

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
Repare que argumentos padrão alteram a aridade de uma função.

Ao escrever uma biblioteca, muitas vezes é necessário tornar funções públicas para uso entre módulos.
Para esconder essas funções da documentação, quem escreve a biblioteca adiciona `@doc false` antes das definições das funções, ou `@moduledoc false` para esconder o módulo inteiro.
