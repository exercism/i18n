# Sobre

Filtragem é o processo de criar uma sequência a partir de outra sequência, copiando todos os elementos da sequência original, exceto alguns. A escolha de quais itens incluir na nova sequência pode ser feita por uma função de predicado (uma função que resulta em um valor Boolean) ou por igualdade com um objeto específico.

## Removendo com um predicado

`remove-if` é uma função que recebe uma função de predicado e uma sequência como argumentos e retorna uma sequência apenas com os elementos para os quais o predicado resultou em falso. Em outras palavras, ela "remove" todos os elementos da sequência para os quais o predicado resulta em verdadeiro. No entanto, repare que essa função não modifica a sequência original!
Em vez disso, ela retorna uma nova sequência sem os elementos em questão. Se o predicado for verdadeiro para todos os valores, uma sequência vazia é retornada.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Mantendo elementos com um predicado

Existe uma função `remove-if-not` que é igual a `remove-if`, exceto que ela *mantém* o elemento para o qual o predicado resulta em verdadeiro.

Como alternativa, dá para usar `complement` para transformar um predicado no seu "oposto".

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## Removendo um item específico

Se você quiser remover um item específico de uma sequência, pode usar `remove`, que recebe o item a remover e uma sequência.
Todos os valores da sequência que não forem iguais ao item a remover são retornados.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

A função usada para a igualdade pode ser especificada com o [parâmetro de palavra-chave][concept-keyword-parameters] `:test`.

Repare que `remove` poderia ser implementada com `remove-if`, escrevendo um predicado que testa a igualdade de um objeto com um item específico.

## Muitas opções

Cada uma dessas funções também aceita muitos outros [parâmetros de palavra-chave][concept-keyword-parameters], que permitem que elas atuem apenas sobre subsequências, que sejam aplicadas apenas um certo número de vezes, entre outras coisas. Consulte a [documentação da Hyperspec][hyperspec-remove] para todos os detalhes.


## Opções destrutivas

Além de `remove`, `remove-if` e `remove-if-not`, existem `delete`, `delete-if` e `delete-if-not`, que têm o mesmo efeito, exceto que podem modificar a sequência passada para elas.
