# Sobre

O Kotlin foi projetado e desenvolvido pela JetBrains, a empresa por trás do IntelliJ. 
É uma linguagem que roda na JVM e pode ter como alvo as versões 6+ (incluindo a [plataforma Android](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/)).
A JetBrains queria usar uma linguagem de tipagem estática que eliminasse o código boilerplate do Java, oferecesse paradigmas funcionais modernos e tivesse interoperabilidade bidirecional perfeita com a base de código Java que já existia. 
A JVM já tinha linguagens alternativas como Groovy e Scala, mas nenhuma delas atendia aos critérios desejados, então criaram o Kotlin.

A sintaxe do Kotlin é parecida com a de Scala e Swift, mas traz os melhores recursos de outras linguagens, como 
C# e Groovy. 
O Kotlin adotou uma abordagem pragmática quanto aos recursos incluídos na linguagem, oferecendo apenas funcionalidades que já 
se mostraram úteis para quem desenvolve. 
Com essa decisão, implementaram um subconjunto dos recursos do Scala, com a intenção de oferecer um código mais fácil de manter e uma curva de aprendizado mais suave para quem procura um "Java melhor".

A JetBrains tem uma equipe dedicada de desenvolvedores trabalhando no Kotlin, com a base de código disponível no [Github](https://github.com/JetBrains/kotlin).
