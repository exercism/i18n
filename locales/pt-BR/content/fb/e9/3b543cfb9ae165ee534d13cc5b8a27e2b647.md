# Instruções

Você está com uma vontade súbita de comer panquecas.
Como uma pessoa moderna e ligada em tecnologia, você escreve uma lista de compras dos ingredientes da panqueca em formato JSON.
A estrutura da lista é:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Um ingrediente é representado por um objeto JSON, assim:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Um ingrediente tem uma propriedade opcional chamada `"substitute"` que guarda uma string com outro item que pode ser usado no lugar.

Vamos ver como podemos examinar a lista de compras com `jq`.

## 1. Extraia o nome da lista de compras

Escreva uma expressão que imprime o elemento "name" da lista de compras.

## 2. Conte quantos ingredientes são necessários

Conte apenas os ingredientes "obrigatórios". Não inclua os ingredientes opcionais.

## 3. Quanto de açúcar?

Escreva uma expressão que imprime a quantidade de açúcar.
Só a parte numérica interessa.

## 4. Mapeie os ingredientes que podem ser substituídos

Alguns dos ingredientes podem ser substituídos (se você não tem o ingrediente X, pode usar o Y).
Imprima um objeto JSON que mapeia o ingrediente recomendado à sua substituição.
Inclua os ingredientes opcionais no mapeamento.
