# Sobre

A instrução `guard` do Swift é usada para fazer retornos antecipados em funções Swift quando uma condição necessária para que o processamento continue não é atendida, por exemplo:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

Aqui, o `guard` verifica se a expressão Boolean que vem depois da palavra-chave `guard` é avaliada como verdadeira. Se for, o processamento continua com o código que vem depois da instrução `guard` (aqui `let root = myValue.squareRoot()`. Caso contrário, ele executa o código da cláusula `else`. Diferente de uma condicional `if`, uma instrução `guard` _precisa_ ter uma cláusula `else` e, diferente da cláusula `else` de um if-else, a cláusula `else` de um `guard` _precisa_ sair do escopo da instrução `guard`. Ou seja, ela precisa usar uma instrução de transferência de controle como `return`, `continue` ou `break`, ou então lançar um erro ou encerrar o programa.

Um exemplo de uso é a função sinc, que é igual a sin(x)/x com sinc(0) definido como 1, evitando problemas com divisão por 0. Essa função pode ser escrita em Swift, usando um `guard`, assim:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
