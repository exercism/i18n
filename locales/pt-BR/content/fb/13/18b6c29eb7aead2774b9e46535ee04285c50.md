# Instruções

Neste exercício, você vai processar linhas de log.

Cada linha de log é uma string formatada assim: `"[<LEVEL>]: <MESSAGE>"`.

Há três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Você tem várias tarefas, e cada uma vai receber uma linha de log e pedir que você faça algo com ela.

## 1. Permitir recuperar a string depois de uma substring específica

Olhando os logs do último mês, você vê que a mensagem de teste sempre está depois de uma substring específica. Como você prevê que vai precisar extrair a mensagem de teste em algum momento próximo, decide criar um método auxiliar para ajudar nisso.

Implemente o método de extensão (_static_) `LogAnalysis.SubstringAfter()`, que recebe um delimitador do tipo string e retorna a substring depois do delimitador.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. Permitir recuperar a string entre duas substrings

Olhando com mais atenção, você vê que o nível de log sempre está entre colchetes (`[` e `]`). Como você também prevê que vai precisar extrair o nível de log em algum momento próximo, decide criar outro método auxiliar para ajudar nisso.

Implemente o método de extensão (_static_) `LogAnalysis.SubstringBetween()`, que recebe dois delimitadores do tipo string e retorna a substring que fica entre os dois delimitadores.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. Extrair a mensagem de um log

Implemente o método de extensão (_static_) `LogAnalysis.Message()` para retornar a mensagem contida em um log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. Extrair o nível de log de um log

Implemente o método de extensão (_static_) `LogAnalysis.LogLevel()` para retornar o nível de log de um log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
