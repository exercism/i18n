# condicionais desnecessárias

As [condicionais][conditionals] são usadas sem necessidade nesta solução.
Usar um [argumento padrão][default argument] junto com [str.format][str.format] ou [f-strings][f-strings] (_também conhecidas como "literais de string formatados" ou "strings interpoladas"_) pode deixar o código mais claro e menos verboso.

Veja este post sobre [argumentos padrão do Python][python default arguments] para mais detalhes.
O post do blog [formatação de strings em Python][string formatting in python] também pode ser um bom ponto de partida para aprender sobre as opções de formatação de strings do Python.
