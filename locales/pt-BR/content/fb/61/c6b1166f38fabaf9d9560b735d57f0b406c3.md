# Noções básicas de sintaxe do Elm 1

## Constantes e funções

Os programas em Elm são compostos de definições e expressões.
Tudo em Elm é uma definição ou uma expressão.

Um valor constante é definido com `name = expression`.

```elm
five = 5

six = 3 + 3
```

As funções são definidas com `name parameters... = expression`,
e os parâmetros são separados apenas por espaço.

```elm
add number1 number2 = number1 + number2
```

Chamar uma função também é uma expressão e é feito
especificando o nome dela e passando argumentos para cada um dos parâmetros da função,
separados por espaço, assim como na definição de uma função.

```elm
five = add 2 3
```

Você pode usar parênteses para especificar a ordem de avaliação de uma expressão.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentação / espaços em branco significativos

Elm não usa marcadores sintáticos como chaves, parênteses ou pontos e vírgulas para delimitar o código. Em vez disso, usa espaços em branco e indentação.

- Definições de módulo, de import e de funções de nível superior devem começar na coluna mais à esquerda.
- Se uma expressão for dividida em várias linhas, o código que faz parte dessa expressão deve ser indentado abaixo dela com pelo menos um espaço.
- As partes da expressão que estão agrupadas devem ser indentadas com o mesmo número de espaços.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Módulos

Cada arquivo em Elm é um módulo e deve conter uma instrução `module` antes de qualquer outro código.
Os nomes dos módulos devem corresponder ao nome do arquivo, então o módulo `Calculator` deve estar no arquivo Calculator.elm.
Tudo o que é definido dentro de um módulo tem escopo privado nele
e não pode ser acessado de fora desse módulo, a menos que esteja listado em `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Comentários

Um comentário é um texto dentro do arquivo Elm que não é interpretado como código.
Ele serve principalmente para que você e outras pessoas que programam possam lê-lo.
Existe uma sintaxe leve para comentários de uma linha, baseada em dois hífens.
Também é possível usar comentários de várias linhas com o par `{-` e `-}`
de delimitadores de abertura e fechamento.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
