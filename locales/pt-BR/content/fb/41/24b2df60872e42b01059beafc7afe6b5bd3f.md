# Introdução

Assim como é possível criar um ponteiro para um `int` ou outro tipo de dado básico, também é possível criar um ponteiro para uma função.
Um ponteiro para função pode ser usado para passar uma função para outra função.
Uma função que é passada como valor de parâmetro para outra função é chamada de função de primeira classe.
Uma função que recebe uma ou mais funções como parâmetro, ou que retorna uma função, é chamada de função de ordem superior.

No exemplo a seguir, `is_even` e `is_odd` são funções de primeira classe.
A função de ordem superior é `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
A assinatura de função `bool (*func) (int)` do primeiro argumento de `test_number` corresponde à assinatura das funções passadas.
Tanto `is_even` quanto `is_odd` recebem um parâmetro `int` e retornam um `bool`.
Em `(*func)`, `func` representa o nome da função a ser usada.
Se `(*fn)` fosse usado, a chamada teria sido feita assim: `printf(text, number, fn(number)? "true": "false");`.
Para satisfazer o parâmetro do ponteiro para função, passamos o nome de uma função com a assinatura esperada ao chamar `test_number`.
Assim, vemos que o nome de uma função aponta para o endereço dessa função nomeada.
