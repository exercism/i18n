# Edição Padrão

A Edição Padrão do Exercism foi feita para uso individual, no aprendizado pessoal, com as pessoas se ajudando por meio dos nossos sistemas de comunidade.

Ela não foi criada nem pensada para que organizações treinem suas equipes ou para servir de base para bootcamps.
Veja a [Edição para Equipes](/docs/editions/teams) para saber como alcançar esses objetivos.
