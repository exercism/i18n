# Testes

Você pode rodar os testes executando o seguinte comando no diretório do exercício:

```bash
dub test
```

## Como passar nos testes

Faça o primeiro teste compilar, linkar e passar seguindo as [três regras do desenvolvimento orientado a testes](http://butunclebob.com/ArticleS.UncleBob.TheThreeRulesOfTdd). Crie apenas a estrutura suficiente declarando namespaces, funções, classes etc., para resolver os erros de compilação e fazer o teste falhar. Depois, escreva apenas o código suficiente para fazer o teste passar. Quando terminar, descomente o próximo teste movendo a linha a seguir para depois do próximo teste.

```D
static if (all_tests_enabled)
```

Isso pode gerar erros de compilação, já que podem aparecer novas construções que você ainda não declarou ou definiu. Mais uma vez, corrija os erros de compilação o mínimo necessário para chegar a um teste que falha, depois altere o código o mínimo necessário para que o teste passe, refatore sua implementação pensando em legibilidade e expressividade e só então siga para o próximo teste.

Procure usar os recursos padrão de D em vez de escrever seus próprios algoritmos ou recursos de baixo nível à mão.
