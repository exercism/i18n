# Sobre

Sendo uma linguagem funcional, em Clojure as funções são cidadãs de primeira classe. Isso significa que elas podem ser passadas para outras funções e geradas por elas, exatamente como acontece com dados. Clojure, em particular, vem com um rico conjunto de funções de ordem superior que derivam novas funções a partir de outras já existentes. Vamos explorar aqui quatro casos importantes: `partial`, `comp`, `memoize` e `juxt`. Essas funções que geram funções fazem parte de uma categoria mais ampla de funções de ordem superior, como `map`, `reduce`, `apply` e `complement`, entre outras, que operam sobre funções já existentes.

## partial

Em geral, dada uma função `my-function` já existente, com parâmetros `p1, p2, ..., pN`, podemos fixar alguns de seus parâmetros `p1, p2, ..., pM` com valores constantes `v1, v2, ..., vM`. Fazemos isso aplicando `partial` da seguinte forma: `(partial my-function v1 v2 ... vM)`.

O resultado é uma nova função que aplica a função original `my-function` fixando `p1=v1, p2=v2, ..., pM=vM`. Nossa nova função recebe como entrada os parâmetros restantes `pM+1, pM+2, ..., pN`, cujos valores não foram indicados ao aplicar `partial`:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Como um exemplo simples, vamos definir uma função `inc-by-9` que aumenta em 9, uma quantidade fixa, qualquer valor que passarmos. Poderíamos implementar essa função assim:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Como segundo exemplo, temos uma função `generic-greetings` que usa o nome da pessoa que queremos cumprimentar junto com mensagens de texto inicial e final:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

E usamos `partial` para sempre usar uma mensagem de cumprimento específica:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp` pode ser usada para criar uma composição de quantas funções quisermos compor. Em geral, compor `N` funções `f1, f2, ..., fN` significa aplicar essas funções em ordem sequencial, passando a saída da função anterior para a próxima. Em notação matemática, isso se expressa assim:

```
f1 (f2 (... fN(x)))
```

Em Clojure, isso equivale a fazer:
```clojure
(f1 (f2 (... (fN x))))
```

Usando comp, podemos criar uma nova função que realiza essa composição para nós:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Como exemplo, digamos que queremos somar uma série de números e depois multiplicar o resultado por 6. Podemos fazer assim:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` permite reutilizar resultados já calculados associados a um determinado valor de entrada. Dado o mesmo valor de entrada, a função *memoizada* retorna o mesmo resultado sem precisar calculá-lo de novo. Ela aproveita o fato de que as funções de `clojure` são, por padrão, *referencialmente transparentes*: dado o mesmo valor de entrada, elas sempre produzem a mesma saída, o que torna possível reutilizar cálculos anteriores com facilidade.

Para ver como isso funciona, vamos usar um caso sintético em que a função dorme por dois segundos antes de produzir a saída, para que possamos comparar facilmente o *tempo de computação* antes e depois de usar `memoize`.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` gera uma função que aplica, da esquerda para a direita, as funções passadas para ela. O resultado é um vetor com os resultados individuais de cada função como componentes do vetor:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Como exemplo simples, geramos uma função que calcula o produto de x por fatores sucessivos, de 2 a 5:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
