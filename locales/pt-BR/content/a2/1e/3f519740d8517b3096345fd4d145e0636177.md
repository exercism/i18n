# Introdução

Tuplas são uma forma leve de agrupar um conjunto fixo de dados de tipos arbitrários.
Uma tupla não tem um nome específico; dar um nome a uma estrutura de dados a transforma em uma `struct`.
Os campos de uma tupla não têm nomes; acessa-se a eles por meio de desestruturação ou pela posição.

## Criação

Tuplas são sempre criadas com uma expressão de tupla:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Tuplas podem ter um número arbitrário de elementos.

## Acesso por desestruturação

É possível acessar os elementos de uma tupla por desestruturação.
Isso significa apenas atribuir nomes de variáveis aos elementos individuais da tupla, consumindo-a.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
