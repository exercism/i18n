# Aprendizado

## Aprender C do zero

Em geral, o Exercism assume que você já conhece a sintaxe e os mecanismos de uma linguagem em uma trilha específica.
No entanto, conhecer a sintaxe de uma linguagem é apenas o primeiro passo para se tornar especialista nela.
O Exercism permite que você pratique a resolução de problemas e troque ideias com outros programadores que resolveram o mesmo problema.
É dessa troca de ideias que tiramos experiência e percepção para nos tornarmos programadores melhores.

Se você está começando agora na linguagem C, vale a pena dedicar um tempo primeiro para aprender o básico da linguagem.
Aqui estão alguns recursos que podem ajudar você a começar:

* [Learn C][]
* [CS50x][]

O [CodeChef][] é uma interface simples de formulário web para um compilador de C, que permite testar pequenos programas.
Às vezes, essa pode ser uma forma mais fácil de fazer um teste rápido do que montar algo localmente em um ambiente de desenvolvimento integrado.

## Desenvolvimento orientado a testes em C

O Exercism assume que você já conhece o conceito de desenvolvimento orientado a testes.
Cada exercício vem com uma série de testes já escritos para você.
Você avança pelo exercício um teste de cada vez, escrevendo a implementação aos poucos até satisfazer os testes.

Se você é novo no desenvolvimento orientado a testes, é altamente recomendável começar por uma [visão geral rápida de alguns frameworks de teste para C][test-frameworks] ou ler o livro [Test-Driven Development for Embedded C][tdd], de James Grenning.
Esses recursos abordam o [Unity][] e o [CppUTest][]; esta trilha usa o Unity.
