# Dicas

## 1. Criando uma nova lista

- Common Lisp tem uma [função com um nome bem descritivo][hyper-list] para criar uma _LIST_.

## 2. Adicionar coisas à lista.

- Para adicionar algo ao início de uma lista, o idiomático é *CONS*truir uma nova lista com o item como `car` e a lista como `cdr`. No Hyperspec há uma [página][hyper-cons] que descreve essa função.

## 3. Qual é o próximo item (ou itens) da lista?

- Common Lisp tem uma função de propósito geral para obter um item [de qualquer índice de uma lista][hyper-nth].
- Ela também tem [vários auxiliares][hyper-first-tenth] para acessar índices abaixo de 11
- Os índices de lista começam em zero.

## 4. Removendo um item da lista

- Uma forma idiomática de remover o primeiro item de uma lista é usar uma função que consegue separar o `cdr` da lista do `car` da lista. No Hyperspec você encontra uma [página][hyper-rest] que descreve uma das funções que fazem isso.

## 5. Listas maiores a partir de listas menores

- Common Lisp tem uma função [especificamente para adicionar uma lista na frente de outra][hyper-append]

## 6. Quanto mais longa?

- Common Lisp tem uma função [de nome óbvio][hyper-length] para obter o comprimento de uma lista.
