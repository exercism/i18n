# Instruções

Você está chamando as deixas da peça da sua escola. O diretor de palco quer as falas padrão anotadas para que qualquer pessoa consiga operar a mesa.

Você tem quatro tarefas, todas na classe `STAGE_DIRECTIONS`.

## 1. Anuncie o início

Retorne a fala que abre o espetáculo.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. Anuncie o intervalo

Retorne a fala chamada no intervalo.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. Anuncie o fim

Retorne a fala que encerra o espetáculo.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. Chame a deixa final

A deixa final é a mesma fala que encerra o espetáculo. Em vez de escrever o texto uma segunda vez, chame a rotina que você já escreveu.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
