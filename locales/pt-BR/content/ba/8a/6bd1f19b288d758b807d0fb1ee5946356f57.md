# Instalação

O Exercism permite que você programe e teste seu código ABAP diretamente no navegador. Não é preciso instalar nada. Mas, se você preferir programar e testar no seu próprio sistema, pode obter um sistema de teste do ABAP.

É claro que o seu empregador pode usar SAP. Verifique com o departamento de TI se e como você pode conseguir acesso a um sandbox de desenvolvimento ABAP.

## Qual versão escolher?

Recomendamos usar uma versão atual da plataforma ABAP com suporte ativo. Atualmente, isso significa **ABAP 7.5 ou superior**. Detalhes sobre as versões atuais e seus cronogramas podem ser encontrados no [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise).

## O que instalar?

Recomendamos usar a versão mais recente do [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial). Ele é baseado no ABAP 7.58. Você pode instalar o sistema SAP ABAP como uma imagem Docker ou hospedado na SAP Cloud Appliance Library. Além disso, você precisa instalar o SAP GUI para Windows ou para Java, dependendo do seu sistema operacional. Você pode baixar o SAP GUI [aqui](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui).

Para mais detalhes, veja este blog da [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183).
