# Introdução

## Operador pipe

O operador `|>` é chamado de operador pipe. Ele pode ser usado para encadear chamadas de função de modo que o valor retornado pela chamada de função anterior seja passado para a próxima chamada de função.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

O código acima é equivalente ao seguinte:

```gleam
string.append(string.uppercase("hello"), "?!")
```

O operador pipe passa o valor como primeiro argumento para a chamada de função, ou como único argumento para uma nova chamada, escolhendo a opção que tiver o tipo correto.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Às vezes, queremos passar o valor para outra posição. Nesse caso, o placeholder `_` pode ser usado para indicar onde o valor deve ser inserido.

```gleam
100
|> some_function(1, _, 2)
```
