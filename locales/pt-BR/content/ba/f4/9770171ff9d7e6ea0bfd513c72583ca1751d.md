# Dicas

## 1. Imprimir um crachá para um funcionário

- A [interpolação de strings][string-interpolation] pode ser usada para formatar o crachá de forma concisa.
- Existe um [método nativo para converter uma string em maiúsculas][toupper].

## 2. Imprimir um crachá para um novo funcionário

- Verifique se o ID é `null` antes de usá-lo.
- [Este tutorial explica em detalhes como trabalhar com tipos de valor anuláveis][nullable-types-tutorial].

## 3. Imprimir um crachá para o proprietário

- Verifique se o departamento é `null` antes de usá-lo.
- [Este tutorial explica em detalhes como trabalhar com tipos de referência anuláveis][nullable-reference-types-tutorial].
- O [operador condicional nulo][null-conditional-operator] pode ser usado para simplificar a chamada de um membro em um valor anulável.
- O [operador de coalescência nulo][null-coalescing-operator] pode ser usado para simplificar o retorno de um valor diferente quando um valor anulável é `null`.
