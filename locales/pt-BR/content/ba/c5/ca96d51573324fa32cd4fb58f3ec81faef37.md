# Introdução

## Formato - Noções básicas

O Common Lisp tem um conceito chamado Impressora, que inclui todas as funções para escrever representações textuais de dados Lisp. Uma dessas funções é `format`, que permite ao programador formatar os dados como quiser.

As capacidades de `format` e da Impressora do Lisp em geral são um assunto amplo; aqui vamos descrever o básico do uso de `format`.

### A função FORMAT

A função `format` recebe pelo menos dois argumentos: um fluxo no qual imprimir e uma string de controle que define o que será impresso e como.

Os fluxos são um conceito à parte e serão descritos em outro lugar. Por enquanto, basta saber que a impressão é feita no fluxo, e que existem dois valores especiais para esse argumento: `t` e `nil`. O `t` significa imprimir na saída padrão (na verdade, o fluxo ao qual a variável `*standard-output*` está associada). E `nil` significa criar uma string e retorná-la.

Repare que `format` sempre avalia para `nil`, exceto nesse último caso, em que `nil` é especificado como o fluxo. Essa é uma forma comum de fazer simplesmente interpolação ou construção de strings.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

### Diretivas de formato

A string de controle pode conter "diretivas de formato", que dão instruções ao `format` sobre o que imprimir e como interpretar os demais parâmetros passados a ele. De certo modo, a string de controle é um programa que o `format` interpreta e executa. Todas as diretivas começam com `~` e são seguidas de um caractere (_por exemplo_, `~A`, `~D`, `~&`). Não importa se o caractere está em maiúscula ou minúscula.

A maioria das diretivas de formato simplesmente interpola na saída um argumento passado ao `format`. Diz-se que elas "consomem" o argumento. Algumas diretivas não consomem argumentos, ou consomem mais de um. Há até uma diretiva que permite pular de um ponto a outro da lista de argumentos ou ignorar argumentos.

### Formatação básica

Uma diretiva de formato bastante versátil é `~A`. Ela imprime uma versão "legível para humanos" dos dados.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

Outra diretiva de formato útil é `~S`. Ela imprime uma versão "legível para máquinas" dos dados. Isso pode ser muito útil se você quiser conseguir interpretar a saída gerada como dados Lisp. Para muitas coisas ela vai parecer igual à `~A`, mas repare que, no caso de strings, por exemplo, a saída vai incluir as aspas (escapadas quando incluídas em outra string) para que o valor possa ser lido de volta como o parâmetro de string.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

Mais duas diretivas muito úteis são `~%` e `~&`. A primeira gera um caractere de nova linha, enquanto a segunda gera uma "linha nova". A diferença é que `~%` sempre gera uma nova linha, enquanto `~&` só gera uma se o cursor não estiver no início de uma linha. Nenhuma delas consome um argumento.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

Por fim, `~~` é uma diretiva simples que gera um `~` literal.
