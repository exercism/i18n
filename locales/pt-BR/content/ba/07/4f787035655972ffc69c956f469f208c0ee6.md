# Introdução

Lembre-se de que um programa `jq` é um _pipeline de expressões_.
**A atribuição de variável** segue esta regra: uma _atribuição de variável_ é uma expressão com esta forma:

```jq
... | expr as $varname | ...
```

## A saída do filtro é a entrada

Assim como a _expressão de identidade_ `.`, a saída da _atribuição de variável_ é a mesma que a sua entrada.
Definir o valor da variável é um efeito colateral.

Exemplo, mostrando que `.` depois da atribuição é igual à entrada inicial:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Escopo da variável

O escopo da variável é "lexical": a variável estará no escopo pelo restante do pipeline.
Variáveis definidas em funções (veremos funções mais adiante) são "locais" à função.

## Nomes de variáveis

A variável precisa começar com `$`.
O restante do nome da variável é um **identificador**: começa com uma letra ou um underscore, seguido de letras, números ou underscores.

## Atribuição por desestruturação

Do manual:

> É possível declarar várias variáveis com uma única expressão `as`, fornecendo um padrão que _corresponde à estrutura da entrada_ (isso é conhecido como "desestruturação").

Exemplos:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Fazer o nome da variável coincidir com a _chave do objeto_ oferece um atalho:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Constantes

Como mostrado no exemplo acima, as variáveis são úteis para armazenar constantes.
É melhor dar um nome às constantes do que ter "números mágicos" aparecendo no código.

## Muitas vezes as variáveis não são necessárias

Muitas vezes, omitir as variáveis deixa o código mais legível.

Considere calcular a média de uma lista de números

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

em comparação com

```jq
[2, 4, 8, 7] | add / length
```

Isso destaca um dos aspectos mais poderosos do `jq`: a entrada de um filtro é fornecida a _todas_ as subexpressões:

- o array de entrada `[2,4,8,7]` é passado para `add` (que soma os números aplicando o operador `+` a todos os elementos)
- _em paralelo_, `[2,4,8,7]` também é passado para `length`
- quando essas subexpressões terminam, seus resultados são então divididos, retornando o valor médio dos números no array de entrada.

## Operadores do `jq` que você vai precisar para o exercício de aprendizagem

### Operador alternativo: `//`

A expressão `a // b` produz `b` se `a` for false ou null; caso contrário, produz `a`.
No contexto de definir uma variável, isso é muito útil para fornecer um valor padrão:

```jq
(.input.theAnswer // 42) as $answer | ...
```

### Operadores aritméticos

- `+`, `-` e `*` são os operadores usuais de adição, subtração e multiplicação de números.
