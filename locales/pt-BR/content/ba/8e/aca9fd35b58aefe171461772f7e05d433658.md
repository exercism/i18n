# Rodando os testes

Para rodar os testes de um determinado exercício, entre na pasta com `cd` e execute o seguinte:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

Os testes usam uma biblioteca chamada TestBox, que suporta os estilos de teste xUnit e BDD. Todas as suítes de teste são escritas no [estilo BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html), que usa closures para definir as especificações de teste. Você não precisa se preocupar em instalar o TestBox. O executor de testes da CLI cuida disso para você. Você só precisa estar conectado à internet na primeira vez que rodar os testes. Você pode ler mais sobre isso aqui:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
