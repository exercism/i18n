# Introdução

Muitas linguagens têm uma forma, como `null` ou `none`, de indicar um valor inexistente.
Como R foi projetado para lidar com grandes volumes de dados (muitas vezes bagunçados), a linguagem tem várias formas de nada.

O objetivo geral é sinalizar valores ausentes ou suspeitos conforme eles aparecem e depois continuar, sem lançar uma exceção.

## NULL

Se um valor realmente não existe, ele é representado por `NULL`. Provavelmente é o que mais se aproxima do que C ou Python fariam.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

Em muitos contextos, valores `NULL` são simplesmente ignorados:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Para situações em que um valor existe, mas não sabemos qual é, usa-se `NA`. Por exemplo, ao contar veículos que trafegam em uma estrada, observadores humanos podem ficar doentes ou sensores automáticos podem quebrar, mas o trânsito continua fluindo.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Assim, `NA` é um marcador que avisa às pessoas que elas precisam decidir como lidar com isso.

## Vetores vazios

Talvez para a nossa surpresa, R não tem uma forma padrão de verificar se um vetor está vazio, embora alguns pacotes de terceiros implementem suas próprias funções, como `is.empty()`.

Até mesmo gerar um vetor vazio não é totalmente óbvio.
Vimos em uma seção anterior que `c()` sem argumentos retorna `NULL`, e não um vetor.

```R
is.vector(c())
#> [1] FALSE
```

Funções como `logical()` ou `integer()` recebem um argumento que especifica o comprimento desejado, que pode ser zero.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Também podemos gerar um vetor e depois remover todos os elementos, como descrito no [conceito de vetores][concept-vectors].
Isso resulta em um vetor de comprimento 0 de um tipo apropriado.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
