# Sobre

Embora o Swift traga muitos recursos na sua biblioteca padrão, você pode acessar muito mais importando bibliotecas e frameworks externos.
Esses módulos podem vir do próprio projeto Swift (como o [Swift Argument Parser][argument-parser]), de frameworks das plataformas da Apple (como o [Foundation][apple-foundation] e o [Network Framework][network-framework]) ou de bibliotecas de código aberto de terceiros (como o [SwiftyBeaver][swifty-beaver]).

Módulos centrais como o Foundation, uma das bibliotecas mais usadas do Swift, já vêm junto com o toolchain do Swift.
Já as bibliotecas de terceiros precisam ser adicionadas à configuração do seu projeto (por exemplo, com o Swift Package Manager) antes de poderem ser importadas.

Para importar um módulo, escreva a palavra-chave `import` seguida do nome do módulo:

```swift
import Foundation
```

Importar um módulo deixa os tipos, métodos e funções dele disponíveis no seu código.
Por exemplo, importar o Foundation estende o `String` com métodos utilitários úteis, como `components(separatedBy:)`.

Por convenção, as instruções `import` ficam no topo do arquivo Swift, para que quem lê o código veja as dependências de imediato.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
