# Dicas

## Geral

- Os índices de um `Vector` começam em `1`.
- Os baralhos de cartas não contêm cartas duplicadas.

## 1. Determinar se uma carta está presente

- Existe um método [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in) no módulo Base para determinar se uma coleção contém um valor.

## 2. Encontrar a posição de uma carta

- Existe um método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) no módulo Base para encontrar a posição do primeiro elemento de uma coleção que corresponde a um determinado predicado.
- `==(x)` pode ser usado como predicado para encontrar elementos iguais a `x` em métodos que recebem funções de predicado.

## 3. Determinar se cada carta é par

- Existe um método [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any}) no módulo Base que retorna `true` se todos os elementos de uma coleção satisfazem um determinado predicado.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) é uma função de predicado.

## 4. Verificar se o baralho contém uma carta de valor ímpar

- Existe um método [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any}) no módulo Base que retorna `true` se algum elemento de uma coleção satisfaz um determinado predicado.
- [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) é uma função de predicado.

## 5. Determinar a posição da primeira carta que é par

- Existe um método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) no módulo Base para encontrar a posição do primeiro elemento de uma coleção que corresponde a um determinado predicado.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) é uma função de predicado.

## 6. Obter a primeira carta ímpar do baralho

- Você pode obter o `n`-ésimo valor de um vetor `v` com `v[n]`.
- Existe um método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) no módulo Base para encontrar a posição do primeiro elemento de uma coleção que corresponde a um determinado predicado.
- Se nenhum elemento da coleção dada corresponder ao predicado passado para `findfirst`, `findfirst` retorna `nothing`.
- Revise como `nothing` funciona em Julia: [concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- Revise como os condicionais funcionam em Julia: [concept:julia/conditionals](../../../../concepts/conditionals/about.md)
