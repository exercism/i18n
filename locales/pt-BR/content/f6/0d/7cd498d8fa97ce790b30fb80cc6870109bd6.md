# Descrição

Implemente a operação `accumulate`, que, dada uma coleção e uma operação a
executar em cada elemento da coleção, retorna uma nova coleção com o resultado
de aplicar essa operação a cada elemento da coleção de entrada.

Dada a coleção de números:

- 1, 2, 3, 4, 5

E um trecho de código que faz:

- elevar um número ao quadrado (`[ sq ]`)

Seu código deve ser capaz de produzir a coleção de quadrados:

- 1, 4, 9, 16, 25

## Restrições

Não encoste nessa funcionalidade de collect/map/fmap/sei-lá-o-quê que a sua
biblioteca padrão oferece!

Resolva este exercício por conta própria, usando outras ferramentas básicas.
