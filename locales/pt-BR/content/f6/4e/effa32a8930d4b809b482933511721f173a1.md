# Introdução

Caracteres e strings formam a base para a representação de texto em Elm.
Podemos pensar em strings como listas de caracteres, e a maioria das funções de `List` tem sua equivalente no módulo `String`.

## Caracteres

O tipo `Char` representa um único caractere unicode com aspas simples, por exemplo, `'a'`. 
O módulo `Char` fornece funções de predicado (`Char -> Bool`) para testar qualidades de um caractere: `isUpper`, `isLower`, `isAlpha` e `isAlphaNum`
O módulo também fornece funções para converter um caractere com `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, bem como de e para seu valor numérico unicode (`Int`) com `toCode` e `fromCode`.

## Strings

O tipo `String` fornece uma representação nativa para manipulação eficiente de strings e consegue representar qualquer sequência de caracteres unicode, por exemplo, "this is an Elm string."
Strings multilinha são representadas com três aspas duplas e podem conter aspas e quebras de linha não escapadas.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## Funções de string

O módulo `String` contém todas as funções resumidas na tabela abaixo.
Algumas das funções mais usadas incluem:

`cons : Char -> String -> String` adiciona um caractere ao início de uma string.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` concatena duas strings.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` divide uma string em uma lista de strings no separador dado.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` concatena uma lista de strings usando um separador dado.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` substitui todas as ocorrências de uma substring dada.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` retorna o número de caracteres em uma string.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` tenta converter uma string em `Just Int` e retorna `Nothing` para strings com formato inválido.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` verifica se a segunda string contém a primeira.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` aplica uma função dada a cada `Char` da string.
Repare que a função fornecida deve ser um mapeamento de e para `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
