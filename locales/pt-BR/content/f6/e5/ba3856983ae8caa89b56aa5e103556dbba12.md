# Apêndice das instruções

## BufSet

Sugerimos que `detectAnagrams` retorne um `BufSet`.

Um `BufSet` é um conjunto de strings, igual a `StringHashMap(void)`, só que você não precisa copiar uma chave antes de inserir.
O próprio `BufSet` faz isso.

Para mais detalhes sobre hash maps em Zig, veja:

- [Hexops - Zig hashmaps explained][zig-hashmaps-explained]
- [Zighelp - Hash Maps][zighelp]
- [Zig Standard Library - `buf_set.zig`][buf-set]
