# Introdução

## Números

Muitas linguagens de programação têm tipos numéricos específicos para representar diferentes tipos de números, mas o JavaScript tem apenas dois:

- `number`: um tipo de dado numérico no formato de ponto flutuante de precisão dupla de 64 bits (IEEE 754).
  Alguns exemplos são `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` e `500000`.
- `bigint`: um tipo de dado numérico que pode representar _inteiros_ no formato de precisão arbitrária.
  Alguns exemplos são `-12n`, `0n`, `4n` e `9007199254740991n`.

Se você precisar de precisão arbitrária ou trabalhar com números extremamente grandes, use o tipo `bigint`.
Caso contrário, o tipo `number` provavelmente é a melhor opção.

### Arredondamento

Existe um objeto global embutido chamado `Math` que oferece várias [funções de arredondamento][ref-math-object-rounding].
Por exemplo, você pode arredondar para baixo (`floor`) ou para cima (`ceil`) números decimais para os números inteiros mais próximos.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## Operadores aritméticos

O JavaScript oferece 6 operadores diferentes para realizar operações aritméticas básicas com números.

- `+`: O operador de adição é usado para encontrar a soma de números.
- `-`: O operador de subtração é usado para encontrar a diferença entre dois números
- `*`: O operador de multiplicação é usado para encontrar o produto de dois números.
- `/`: O operador de divisão é usado para dividir dois números.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: O operador de resto é usado para encontrar o resto de uma divisão.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: O operador de exponenciação é usado para elevar um número a uma potência.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### Ordem das operações

Ao usar vários operadores na mesma linha, o JavaScript segue uma ordem de precedência, como mostra [esta tabela de precedência][mdn-operator-precedence].
Para simplificar isso ao nosso contexto, o JavaScript usa a regra PEDMAS (Parênteses, Expoentes, Divisão/Multiplicação, Adição/Subtração) que aprendemos nas aulas de matemática do ensino fundamental.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### Operadores de atribuição abreviados

Os operadores de atribuição abreviados são uma forma mais curta de escrever código que realiza operações aritméticas em uma variável e atribui o novo valor à mesma variável.
Por exemplo, considere duas variáveis `x` e `y`.
Então, `x += y` é o mesmo que `x = x + y`.
Muitas vezes, isso é usado com um número em vez de uma variável `y`.
As outras 5 operações também podem ser feitas de forma parecida.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
