# Anexo de instruções

A direção para a qual o robô está virado será expressa como um dos seguintes números:

- Norte = 0
- Leste = 1
- Sul = 2
- Oeste = 3

Quando a entrada for inválida, retorne uma direção de -1 (os outros valores serão ignorados).

## Memória reservada

O buffer para a string de entrada usa os bytes 64-319 da memória linear.

A string de entrada pode ser modificada, se você quiser.
