# Apêndice das instruções

## Palavras

Defina uma tupla `cmplx` com os campos `real` e `imaginary`. Os acessadores de campo `real>>` e `imaginary>>` vêm de graça com a definição da tupla e são o que os testes usam para ler os componentes.

- `<cmplx> ( real imag -- cmplx )`: constrói um número complexo.
- `>cmplx ( pair -- cmplx )`: constrói um `cmplx` a partir de `{ real imaginary }`.
- `cmplx>pair ( cmplx -- pair )`: retorna `{ real imaginary }`.
- `c+ ( a b -- c )`, `c- ( a b -- c )`, `c* ( a b -- c )`, `c/ ( a b -- c )`: aritmética entre dois números complexos.
- `c-abs ( a -- |a| )`: valor absoluto (um número real).
- `c-conj ( a -- a* )`: conjugado complexo.
- `c-exp ( z -- e^z )`: exponencial complexa.

Os genéricos `MATH:` de Factor (`+`, `-`, `*`, `/`) só fazem dispatch sobre a hierarquia matemática embutida. Por isso, este exercício usa nomes de palavras dedicados em vez de métodos nesses genéricos.

Os testes de aritmética que mistura números reais com números complexos ficam de fora: toda operação aqui é entre dois valores `cmplx`.
