# Introdução

[Estruturas][structs-and-classes] (comumente chamadas de *structs*) são um dos principais blocos de construção dos programas em Swift.
Structs permitem que você crie tipos personalizados que agrupam propriedades (dados) e métodos (comportamento) relacionados.
De fato, os tipos padrão do Swift, incluindo `Int`, `Double`, `Bool`, `String`, `Array` e `Dictionary`, são todos implementados como structs.

## Definindo structs

Defina uma struct usando a palavra-chave `struct`, seguida pelo nome do tipo e por chaves que contêm a definição.
Por convenção do Swift, nomes de structs usam `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Criando instâncias

Uma definição de struct é um molde.
Para criar uma *instância* de uma struct, chame o inicializador escrevendo o nome do tipo seguido de parênteses:

```swift
var someStats = CharacterStats()
```

Isso cria uma instância preenchida com os valores padrão das propriedades definidos no molde.

O Swift também gera automaticamente um **inicializador por membros** para structs, o que permite inicializar propriedades pelo nome:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Acessando e modificando propriedades

Você acessa e modifica as propriedades de uma instância usando *notação de ponto*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Como structs são tipos de valor, modificar as propriedades de uma instância exige que a própria instância seja declarada com `var`.
Se a instância for declarada com `let`, todas as suas propriedades se tornam imutáveis.
