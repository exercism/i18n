# Introdução

## Malabarismo de tipos

O malabarismo de tipos também pode ser conhecido como coerção de tipos.
O malabarismo de tipos acontece quando dois valores de tipos diferentes são coagidos a assumir o mesmo tipo para realizar uma operação.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Isso pode ser feito de forma implícita (veja o exemplo acima), ou de forma explícita com conversão de tipos no estilo `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Os tipos permitidos para conversão manual de tipos são: `bool`, `int`, `float`, `string`, `array`, `object`.
Na maioria das vezes, a conversão de tipos é usada para transformar um inteiro (`int`) em um número de ponto flutuante (`float`) ou vice-versa.
