# Instruções

Neste exercício, você é um grande fã de esportes e acabou de descobrir uma paixão pelo basquete da NBA.
Como você é novo no basquete da NBA, está mergulhando fundo na história da NBA, acompanhando times, treinadores, suas estatísticas de vitórias e derrotas, e comparando uns com os outros.

Como você ainda não tem um time favorito, também vai desenvolver um algoritmo para descobrir se deve torcer por um determinado time.
Você tem sete tarefas para ajudar a desenvolver seu algoritmo proprietário de _torcer por um time_.

## 1. Defina o modelo

Defina o alias de tipo `Coach` para um record com os dois campos a seguir, nesta ordem:

- `name`: o nome do treinador, do tipo `String`.
- `formerPlayer`: indica se o treinador já foi jogador, do tipo `Bool`.

Defina o alias de tipo `Stats` para um record com os dois campos a seguir, nesta ordem:

- `wins`: o número de vitórias, do tipo `Int`.
- `losses`: o número de derrotas, do tipo `Int`.

Defina o alias de tipo `Team` para um record com os três campos a seguir, nesta ordem:

- `name`: o nome do time, do tipo `String`.
- `coach`: o treinador do time, do tipo `Coach`.
- `stats`: as estatísticas do time, do tipo `Stats`.

## 2. Crie um time

Você quer integrar com um código de terceiros que tem o conceito de time, mas que chama o seu código com os parâmetros em uma ordem diferente. Adicione uma função `createTeam` com a seguinte assinatura `String -> Stats -> Coach -> Team`.

## 3. Substitua o treinador

Como os donos de times da NBA são impacientes, você percebeu que maus resultados do time muitas vezes levavam à substituição do treinador.
Implemente a função `replaceCoach`, que recebe o novo treinador e o time como parâmetros e retorna o time, mas com o novo treinador:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Verifique se você deve torcer por um time

No futuro, você planeja criar um algoritmo complicado para decidir se deve torcer por um time ou não, mas, nesta primeira tentativa, você decidiu que deve torcer por qualquer time que tenha mais vitórias do que derrotas.

Você quer que essa função seja reutilizável em outros contextos, então use um record extensível na assinatura de tipo para aceitar qualquer record que tenha os campos relevantes.
Para manter a função o mais concisa possível, você quer usar pattern matching para obter o `stats` do parâmetro da função.
Implemente a função `rootForTeam`, que recebe um time e retorna `True` se você deve torcer por esse time; caso contrário, retorne `False`.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
