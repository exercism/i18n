# Sobre

Hashes são um tipo de dados em Perl que contêm uma coleção não ordenada de chaves de string emparelhadas com valores escalares.

Uma variável de hash geralmente é preenchida atribuindo uma lista a ela, por exemplo, `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Listas geralmente são separadas por vírgulas, mas você verá com frequência a chamada "vírgula gorda" `=>` para separar chaves e valores em uma lista.
O comportamento dela é quase idêntico ao de uma vírgula, mas tem o benefício adicional de interpretar o elemento do lado esquerdo como uma string.

Um hash também pode ser preenchido atribuindo valores a chaves individuais, por exemplo, `$scores{Alice} = 10;`.

Os valores de um hash podem ser acessados especificando chaves por meio de um subscrito, por exemplo, `$scores{Bob} # 15`.

As chaves em um hash são únicas.
Se uma chave for fornecida várias vezes, apenas o último valor fornecido será mantido.

## Funções

As funções para trabalhar com hashes incluem [keys][keys] e [values][values], para recuperar essas respectivas partes de um hash como uma lista.
As listas retornadas pelas funções [keys][keys] e [values][values] podem ser úteis para funções de lista como [grep][grep], [map][map] e [sort][sort], bem como para laços [for][for].

Outras funções de hash incluem [exists][exists], para verificar se uma chave existe em um hash (mesmo que seu valor seja `undef`), e [delete][delete], para remover uma chave de um hash.

## Variação de sigilo

Ao obter valores de um hash, o sigilo usado determina o resultado.
O subscrito `{}` no final do nome da variável é o que diz ao Perl que você está acessando um hash com esse nome.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Embora seja permitido, recomenda-se não usar o mesmo nome para variáveis de tipos diferentes, para facilitar a leitura.
