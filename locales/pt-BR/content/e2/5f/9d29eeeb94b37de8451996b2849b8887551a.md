# Debug

Todo o resultado do seu script Red fica visível no console ao rodar cada teste. Você pode usar `print` para o que quiser, por exemplo os valores das palavras:

```red
print ["x =" x]
```

Além disso, a função `probe` é muito útil. Quando avaliada, ela avalia sua entrada, imprime o resultado de um jeito que reflete o tipo dele e o retorna. Por isso, na maioria dos casos, ela é "transparente", e você pode inseri-la dentro de expressões:

```red
x: 10
y: probe x + 5
```

Às vezes, a função chamada `type?` (sim, ela tem um ponto de interrogação no nome!) pode ser útil para verificar o tipo de um valor:

```red
print ["x type:" type? x]
```

Há também algumas técnicas de depuração mais avançadas [listadas na Wiki do Red](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
