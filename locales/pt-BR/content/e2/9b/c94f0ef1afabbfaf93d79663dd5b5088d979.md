# Ingestão de eventos

## História

Nesta história, você tem um programa que precisa ingerir eventos, mas as mensagens usam 3 formatos de data diferentes:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

A tarefa é escrever regex para corresponder e capturar de cada tipo.

Aborda:

- correspondência de caracteres literais
- quantificadores
- alternâncias
- classes de caracteres
- âncoras

## Tarefas

- Crie padrões para corresponder a componentes pequenos
- Amplie e crie padrões que capturam os componentes pequenos
- Amplie e crie padrões que capturam a partir dos formatos de data fornecidos
- Amplie e crie regex que corresponda e capture apenas aquele formato de data
