# Dicas

## Geral

- Slices em Go são baseados em zero.
  O primeiro índice de um slice é `0`.
- A função embutida [`append`][append-builtin] é [`variadic`][variadic-gobyexample]
- Você pode acrescentar os elementos de um slice a outro slice usando a notação de três pontos:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. Criar um slice com determinadas cartas

- Para criar um slice já preenchido com alguns dados, use a notação de literal de slice: `s := []T{x1, x2, ..., xn}`.

## 2. Recuperar uma carta de uma pilha

- Para obter o `n`-ésimo item de um slice, [use um índice][go-slices].
- Para verificar se um item existe em um slice, use uma condicional e compare o índice com o [comprimento do slice][len-builtin].

## 3. Trocar uma carta na pilha

- Para definir o `n`-ésimo item de um slice, [use um índice][go-slices] e atribua um novo valor a ele.
- Para adicionar um novo item ao final de um slice, use a função `append`.

## 4. Adicionar cartas ao topo da pilha

- Adicionar itens ao início de um slice pode ser feito acrescentando os elementos do slice original ao slice do argumento `value`.

## 5. Remover uma carta da pilha

- Remover um item de um slice pode ser feito acrescentando a parte depois de `index` à parte antes de index.
