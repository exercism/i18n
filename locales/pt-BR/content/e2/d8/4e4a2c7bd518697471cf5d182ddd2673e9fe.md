# Apêndice das instruções

## Formato da saída

Cada nacionalidade é indicada por uma única letra. (`E` = `Englishman`, `J` = `Japanese`, `N` = `Norwegian`, `S` = `Spaniard`, `U` = `Ukrainian`)

## Registradores

| Registrador | Uso        | Tipo     | Descrição                       |
| ----------- | ---------- | -------- | ------------------------------- |
| `$v0`       | saída      | byte     | nacionalidade de quem bebe água |
| `$v1`       | saída      | byte     | nacionalidade do dono da zebra  |
| `$t0-9`     | temporário | qualquer | para armazenamento temporário   |
