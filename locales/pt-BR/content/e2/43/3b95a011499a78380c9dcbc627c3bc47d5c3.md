# Nil

O Crystal tem um tipo chamado [`Nil`][nil], que só pode ter um valor: `nil`.
Ele é usado para representar a ausência de um valor e é parecido com `null` ou `None` em outras linguagens.

Valores nil podem ser retornados por vários métodos, por exemplo [`String#[]?`][string-index], que retorna `nil` se o índice estiver fora dos limites.

```crystal
"foo"[10]? # => nil
```

O Crystal tem o que se conhece como **verificações de referência nula**, o que significa que, por padrão, nenhum tipo pode ser nil.
Isso quer dizer que você não pode atribuir `nil` a uma variável, a menos que a declare explicitamente como um tipo `Nil`.
Por sua vez, isso significa que o compilador vai verificar automaticamente as referências nulas.

## Valor falso

Existem algumas abordagens para lidar com valores nil.
`nil` é um valor [falso][truthy-falsey], assim como `false`.
Isso significa que, em instruções e em outros lugares onde se espera um valor falso ou verdadeiro, ele será tratado da mesma forma que `false`.

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

Isso significa que, se uma variável que pode ser nil tiver o valor `nil`, o bloco do caso verdadeiro não será executado.

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## Verificar se é nil

O Crystal tem um método que pode ser usado para verificar se um valor é `nil`.
Ele se chama [`nil?`][nil?] e está disponível em todos os objetos.

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

Isso é um pouco diferente de simplesmente usar o valor em uma condicional, já que nos últimos exemplos tanto false quanto nil seriam tratados como falso.
Aqui, só `nil` é tratado como falso, pois, se fosse false, não seria nil e, com isso, seria verdadeiro.

## Operador ou

A maneira mais fácil de lidar com valores nil é garantir que eles nunca se tornem `nil` desde o início.
O operador ou ([`||`][or]) costuma ser usado para lidar com `Bools`, mas, se bem compreendido, também pode ser usado para lidar com valores nil.
O operador ou verifica se o primeiro valor é verdadeiro; se não for, o segundo valor é usado.
Isso pode ser usado para que, se o valor for `nil`, ele seja falso e, com isso, o segundo valor seja usado.

```crystal
"foo"[10]? || "bar" # => "bar"
```
