# Introdução

Todas as funções do [módulo `Enum`][exercism-enum] são _imediatas_. Ao realizar várias operações sobre enumeráveis com o módulo `Enum`, cada operação vai gerar um resultado intermediário.

O módulo `Stream` é uma alternativa _preguiçosa_ ao módulo `Enum`. Ele oferece muitas das mesmas funções que o `Enum`, mas em vez de gerar resultados intermediários, constrói uma série de cálculos que só são executados quando o stream é passado para uma função do módulo `Enum`.

Os streams implementam o _Enumerable [protocolo][exercism-protocols]_ e podem ser compostos: você pode encadeá-los para criar funcionalidades mais complexas.

[exercism-enum]: https://exercism.org/tracks/elixir/concepts/enum
[exercism-protocols]: https://exercism.org/tracks/elixir/concepts/protocols
