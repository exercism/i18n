# Instruções

Você é um observador de aves dedicado e acompanha quantos pássaros visitaram seu jardim a cada dia.

Você decidiu levar a observação de aves a um novo patamar e implementar algumas ferramentas que vão ajudar a acompanhar e processar os dados.

Você escolheu armazenar os dados como uma lista de números inteiros.
O primeiro número da lista é a quantidade de pássaros que visitaram seu jardim hoje, o segundo ontem, e assim por diante.

```exercism/note
Em aplicações do mundo real, você deve sempre usar os módulos principais quando for o caso; mas, para aprender sobre recursão, não use nenhuma das funções de `List` neste exercício.
```

## 1. Verifique quantos pássaros visitaram hoje

Implemente a função `today`.
Ela deve receber uma lista com as contagens diárias de pássaros e retornar a contagem de hoje.
Se a lista estiver vazia, ela deve retornar `Nothing`; caso contrário, a contagem vem dentro de um `Just`.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Incremente a contagem de hoje

Implemente a função `incrementDayCount`.
Ela deve receber uma lista com as contagens diárias de pássaros e incrementar a contagem de hoje em 1.
Se a lista estiver vazia, retorne `[1]`.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Verifique se houve um dia sem pássaros visitantes

Implemente a função `hasDayWithoutBirds`.
Ela deve receber uma lista com as contagens diárias de pássaros.
Ela deve retornar `True` se houve pelo menos um dia em que nenhum pássaro visitou o jardim, e `False` caso contrário.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Calcule o número total de pássaros visitantes

Implemente a função `total`.
Ela deve receber uma lista com as contagens diárias de pássaros e retornar o número total que visitou seu jardim desde que você começou a coletar os dados.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Calcule o número de dias movimentados

Alguns dias são mais movimentados que outros.
Um dia movimentado é aquele em que cinco ou mais pássaros visitaram seu jardim.

Implemente a função `busyDays`.
Ela deve receber uma lista com as contagens diárias de pássaros e retornar o número de dias movimentados.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
