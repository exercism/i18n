# Instruções

Seu amigo Linus é maquinista e conduz trens de carga entre cidades.
Apesar de ser incrível no comando dos trens, ele não é incrível com logística ou computadores.
Ele gostaria de contar com sua ajuda na programação para organizar os detalhes dos trens e corrigir erros nos dados de rota.

~~~~exercism/note
Este exercício poderia facilmente ser resolvido com slicing, indexação e vários métodos de `Dict`.
No entanto, queremos que você pratique empacotamento (ou seja, slurping), desempacotamento (ou seja, splatting) e atribuição múltipla ao resolver cada uma das tarefas abaixo.
~~~~

## 1. Crie um vetor com todos os vagões

Seu amigo vem anotando o identificador (ID) de cada vagão, mas nunca tem certeza de quantos vagões o sistema vai precisar processar em um dado momento.
Seria muito mais fácil para o resto do programa de logística ter esses dados empacotados em um único `Vector`.

Implemente uma função `get_vector_of_wagons(args...)` que aceita um número arbitrário de IDs de vagões.
Cada ID será um número inteiro positivo.
A função deve então `return` os IDs recebidos como um único `Vector`.

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. Corrija o vetor de vagões

Neste ponto, você já está começando a pegar o jeito dos dados e de como eles são usados no programa de logística.
O sistema de IDs sempre atribui à locomotiva o ID **1**, e os demais vagões do trem recebem um ID escolhido aleatoriamente, maior que **1**.

Seu amigo precisou conectar dois vagões novos ao trem e esqueceu de atualizar o sistema!
Agora, os dois primeiros vagões do `Vector` do trem precisam ser movidos para o final, senão tudo vai ficar fora de ordem.

Para complicar ainda mais, seu amigo acabou de encontrar um segundo `Vector` que parece conter IDs de vagões que estavam faltando.
Ele só lembra que, depois de mover os vagões novos, os IDs desse segundo `Vector` devem ser colocados logo depois da locomotiva designada.

Linus ficaria muito grato se você corrigisse os erros dele e consolidasse os dados.

Implemente uma função `fix_vector_of_wagons(each_wagons_id, missing_wagons)` que recebe dois `Vectors` contendo IDs de vagões.
Ela deve reposicionar os dois primeiros itens do primeiro `Vector` para o final e inserir os valores do segundo `Vector` atrás (_à direita_) do ID da locomotiva (**1**).
A função deve então `return` um `Vector` com as modificações.

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. Adicione as paradas que faltam

Agora que todos os dados dos vagões estão corretos, Linus gostaria que você atualizasse as informações de rota do sistema.
Ao longo de uma rota de transporte, um trem pode parar em algumas estações diferentes para pegar e/ou deixar carga.
Cada viagem pode ter um número diferente desses pontos intermediários de entrega.
Seu amigo gostaria que você atualizasse o `Dict` de rotas do sistema com as informações de entrega que estiverem faltando ou que precisem ser adicionadas.

Implemente uma função `add_missing_stops(route, stops...)` que aceita um `Dict` de rotas seguido de um número variável de Pairs `stop_number => city`.
Sua função deve então retornar o `Dict` de rotas atualizado com uma `key` adicional que contém um `Vector` com todas as paradas adicionadas, na ordem.

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. Estenda as informações de rota

Linus vem trabalhando no programa de rotas e notou que certas rotas estão sem alguns detalhes importantes.
As informações iniciais de rota foram construídas como um `Dict` e seu amigo gostaria que você atualizasse esse `Dict` com tudo o que estiver faltando.
Cada rota do sistema exige detalhes um pouco diferentes, então Linus preferiria muito uma solução genérica.

Implemente uma função chamada `extend_route_information(route; more_route_information...)` que aceita um `Dict` contendo as cidades de origem e destino entre as quais a rota do trem passa, além de um número variável de argumentos nomeados com detalhes de rota, como velocidade, comprimento ou temperatura do trem.
A função deve retornar um `Dict` consolidado com todas as informações de rota.

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
