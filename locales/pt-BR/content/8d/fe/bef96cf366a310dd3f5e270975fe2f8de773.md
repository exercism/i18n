# Ajuda

Abaixo estão alguns recursos para conseguir ajuda se você tiver problemas:

- [O site principal do projeto Futhark][main] reúne [documentação][docs], [exemplos][examples], uma [referência da linguagem][language-reference] e muito mais.
- [Parallel Programming in Futhark][book] é um livro pensado como uma introdução à linguagem.
- [A comunidade do Exercism no Discord][exercism-discord]
- O canal `#futhark` na [Libera][libera]
- O [canal do futhark no Gitter][gitter]
- O [/r/futhark/][reddit] é um subreddit para linguagens do tipo APL.

Além disso, o [StackOverflow][so] é um bom lugar para pesquisar seu problema ou sua dúvida e ver se ela já foi respondida.
Se não foi, você sempre pode [perguntar][ask-so] ou [responder][answer-so] à pergunta de outra pessoa.
