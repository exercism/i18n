## 2. Validar as informações do morador

- O valor zero de uma string é `""`.
- O valor zero de um map é `nil`.
- Reveja o [conceito de maps](/tracks/go/concepts/maps) para saber como determinar se uma chave de map existe.

## 3. Excluir as informações do morador

- Um morador é considerado excluído quando todos os seus campos estão definidos com o valor zero.
- Reveja o [conceito de valores zero](/tracks/go/concepts/zero-values) para saber o valor zero de cada tipo em Go.
