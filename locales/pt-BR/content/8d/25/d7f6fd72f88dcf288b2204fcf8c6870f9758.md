# Instruções

Neste exercício, você vai brincar com um carro de controle remoto, aquele que você finalmente juntou dinheiro suficiente para comprar.

Os carros começam com a bateria cheia (100%). Cada vez que você dirige o carro com o controle remoto, ele percorre 20 metros e consome um por cento da bateria. O apelido do carro não é conhecido até que ele seja criado.

O carro de controle remoto tem um display de LED sofisticado que mostra duas informações:

- A distância total percorrida, exibida como: `"<METERS> meters"`.
- A carga restante da bateria, exibida como: `"Battery at <PERCENTAGE>%"`.

Se a bateria estiver em 0%, você não pode mais dirigir o carro e o display da bateria vai mostrar `"Battery empty"`.

## 1. Crie um carro de controle remoto novinho em folha

Implemente a função `RemoteControlCar.new/0` para retornar uma struct de carro de controle remoto novinho em folha:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

O apelido é exigido pela struct. Certifique-se de que um valor seja inicializado na função `new`, mas não na struct.

## 2. Crie um carro de controle remoto novinho em folha com um apelido

Implemente a função `RemoteControlCar.new/1` para retornar uma struct de carro de controle remoto novinho em folha com um apelido fornecido:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. Exiba a distância

Implemente a função `RemoteControlCar.display_distance/1` para retornar a distância conforme exibida no display de LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

Certifique-se de que a função aceite apenas uma struct `RemoteControlCar` como argumento.

## 4. Exiba a porcentagem da bateria

Implemente a função `RemoteControlCar.display_battery/1` para retornar a porcentagem da bateria conforme exibida no display de LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

Certifique-se de que a função aceite apenas uma struct `RemoteControlCar` como argumento. Se a bateria estiver em 0%, o display da bateria vai mostrar "Battery empty".

## 5. Dirigir altera a bateria e a distância percorrida

Implemente a função `RemoteControlCar.drive/1` que:

- aumenta em 20 o número de metros percorridos
- consome 1% da bateria

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

Certifique-se de que a função aceite apenas uma struct `RemoteControlCar` como argumento.

## 6. Leve em conta dirigir com a bateria descarregada

Atualize a função `RemoteControlCar.drive/1` para não aumentar a distância percorrida nem diminuir a porcentagem da bateria quando a bateria estiver descarregada (em 0%):

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
