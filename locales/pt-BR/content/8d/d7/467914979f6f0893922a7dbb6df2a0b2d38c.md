# Sobre

O Haxe é fortemente tipado, mas o sistema de tipos pode ser subvertido quando necessário. Atribuir um valor a um nome é o que chamamos de definir uma variável. Uma variável pode ser definida especificando explicitamente o tipo dela ou deixando o compilador do Haxe inferir o tipo usando a [palavra-chave `var`](var). Portanto, as duas definições de variável a seguir são equivalentes:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Você pode atualizar uma variável usando o operador `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

O compilador vai gerar um erro quando você tentar atribuir um valor de tipo diferente do da variável:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

No Haxe, o código normalmente é escrito dentro de uma _função_, também chamada de [_método_](method). Essas funções podem receber parâmetros (argumentos) e retornar valores usando a palavra-chave `return`. As funções são invocadas com a sintaxe `()`. Todas as funções precisam ter um tipo de retorno.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

No Haxe, o escopo é definido entre os caracteres `{` e `}`.

O Haxe suporta dois tipos de comentários. Os de uma linha são precedidos por `//` e os de várias linhas são inseridos entre `/*` e `*/`.
