# Introdução

Se uma classe implementa a interface `IDisposable`, o método `Dispose()` dela precisa ser chamado sempre que uma instância não for mais necessária. Isso normalmente é feito a partir de uma cláusula `catch` ou `finally` ou da rotina `Dispose()` de algum chamador. `Dispose()` oferece uma oportunidade para que recursos não gerenciados, como objetos do sistema operacional (que não são gerenciados pelo runtime do .NET), sejam liberados, e para que o estado interno dos recursos gerenciados seja redefinido.
