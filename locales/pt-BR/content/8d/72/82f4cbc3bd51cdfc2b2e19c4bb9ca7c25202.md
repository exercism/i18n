# Instruções

Você está trabalhando em um sistema para simplificar o processo de login na rede da sua organização. As tarefas tratam da parte de autenticação. O sistema usa reconhecimento facial para comprovar a identidade.

Em todos os casos, o parâmetro de cor dos olhos tem garantia de não ser nulo.

## 1. Garanta que as características faciais coincidam

Implemente `Authenticator.AreSameFace()` para verificar se dois rostos coincidem.

Adicione rotinas de igualdade para a classe `FacialFeatures`.

```csharp
Authenticator.AreSameFace(new FacialFeatures("green", 0.9m), new FacialFeatures("green", 0.9m);
// => true
Authenticator.AreSameFace(new FacialFeatures("blue", 0.9m), new FacialFeatures("green", 0.9m);
// => false
```

## 2. Autentique o administrador do sistema

Apesar dos seus protestos, o administrador do sistema insiste em ter uma identidade embutida durante os testes de aceitação, para que ele possa sempre ser autenticado.

O e-mail do administrador é admin@exerc.ism. Ele tem olhos verdes e um filtrum com largura de 0.9.

Adicione rotinas de igualdade para a classe `Identity`.

Implemente o método `Authenticator.IsAdmin()` para verificar se a identidade passada corresponde à do administrador.

```csharp
var authenticator = new Authenticator();
authenticator.IsAdmin(new Identity("admin@exerc.ism", new FacialFeatures("green", 0.9m)));
// => true
authenticator.IsAdmin(new Identity("admin@thecompetition.com", new FacialFeatures("green", 0.9m)));
// => false
```

## 3. Registre novas identidades

Implemente o método `Authenticator.Register()`, que armazena uma identidade no próprio autenticador, de modo que chamadas a `IsRegistered()` retornem `true` para essa identidade; caso contrário, `IsRegistered()` retorna `false`.

Para detectar tentativas duplicadas de registrar uma identidade, se a identidade já tiver sido registrada, `Authenticator.Register()` retorna `false`; caso contrário, retorna `true`.

```csharp
var authenticator = new Authenticator();
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.IsRegistered(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => false
```

## 4. Impeça que identidades inválidas sejam autenticadas

Implemente o método `Authenticator.IsRegistered()` e garanta que ele retorne false quando nenhuma identidade tiver sido registrada.

```csharp
var authenticator = new Authenticator();
authenticator.IsRegistered(new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.8m)));
// => false
```

## 5. Adicione diagnósticos para detectar várias tentativas de autenticação

Foi relatado um bug em que o método `Authenticator.IsRegistered()` é chamado várias vezes em rápida sucessão para a mesma identidade. Você acredita que há algum tipo de problema de "bounce", em que o mesmo registro exato é enviado várias vezes. Sua tarefa é adicionar uma rotina de diagnóstico, `Authenticator.AreSameObject()`, para dar suporte a qualquer teste que seja realizado. A rotina compara dois objetos e retorna `true` se eles forem exatamente a mesma instância; caso contrário, retorna `false`.

```csharp
var identityA = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityB = identityA;
Authenticator.AreSameObject(identityA, identityB);
// => true

var identityC = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityD = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
Authenticator.AreSameObject(identityC, identityD);
// => false
```
