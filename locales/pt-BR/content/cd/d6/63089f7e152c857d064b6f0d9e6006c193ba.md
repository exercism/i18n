# Depuração

Quando um teste falha, é exibida uma mensagem descrevendo o que deu errado e para qual entrada.
Você também pode contar com o fato de que tudo o que for impresso na "saída padrão" também será mostrado.
Você pode escrever na saída padrão usando `println!`:

```rust
println!("Debug message");
```

Use chaves `{}` para imprimir o valor de uma variável ou de uma expressão:

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

Repare que nem todos os tipos podem ser impressos desse jeito, apenas aqueles que podem ser apresentados aos usuários sem ambiguidade.
Por exemplo, vetores (listas) não podem ser impressos assim, porque não está claro como um vetor deveria ser exibido aos usuários!
Para esses outros tipos, você pode pedir para a macro `println!` usar a _formatação de depuração_ com: `{:?}`.
Essa representação é feita para ser vista apenas por quem desenvolve.
Um exemplo:

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

Existe até a prática macro `dbg!`, que pode ser usada para depurar expressões grandes ali mesmo, no meio do código, sem precisar dividi-las em declarações de variáveis separadas.

Suponha que tenhamos a seguinte expressão:

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

Agora queremos ver o que a chamada a `collect` retorna.
Poderíamos fazer o seguinte:

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

Mas isso é trabalhoso!
Não queremos reescrever nossas belas expressões só para conseguir depurá-las.
E agora, com vocês: `dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

O espaço em branco é só para deixar mais claro.
Você pode envolver qualquer expressão em `dbg!()`, que vai imprimir esse valor (com formatação de depuração).
Depois, você pode continuar usando o valor em uma expressão maior, como se o `dbg!` nem estivesse ali.

Boa depuração!
