## 1. Capture as informações necessárias para gerar os cards usando regex

- `\p{L}` corresponde a qualquer tipo de letra de qualquer idioma.
- Você pode usar a seguinte expressão para capturar as informações:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
