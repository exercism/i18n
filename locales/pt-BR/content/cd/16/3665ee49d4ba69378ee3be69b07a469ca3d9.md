# Getters e setters

Getters e setters são métodos que permitem ler e escrever o valor de uma propriedade de um objeto.
O Crystal tem macros, o que facilita definir getters e setters para uma propriedade.
Macros são uma forma de gerar código em tempo de compilação, o que será abordado mais adiante no conceito de macros.

No Ruby, esses métodos são definidos com os métodos `attr_reader`, `attr_writer` e `attr_accessor` e, na superfície, são muito parecidos com a implementação do Crystal.
O Crystal os definiu como as macros `getter`, `setter` e `property`.

## Getters

Getter é uma macro que define um método que retorna o valor de uma variável de instância.
Isso significa que você não precisa mais escrever `@` na frente da variável de instância quando quiser acessá-la (em métodos, exceto em initialize); em vez disso, você pode chamar o método que a macro getter definiu.

A macro getter pode receber várias variáveis de instância, separando-as por vírgulas.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Como você pode ver, usar o getter reduz a quantidade de código que você escreve e facilita a leitura.
Além disso, Ruby e Crystal diferem em um ponto: o Crystal aceita tanto o nome da variável quanto um símbolo como argumentos para a macro getter.
Símbolos serão abordados mais adiante no conceito de símbolos.

## Setters

Setter é uma macro que define um método que atribui o valor de uma variável de instância.
Essa macro não é tão comum; normalmente usa-se a macro `property` em seu lugar.
Os métodos criados terão o formato `name_of_method=`; é o `=` que faz com que a propriedade possa ser atribuída.

Essa definição de método é um pouco especial, porque o argumento que o método recebe vem depois do sinal `=`.
Vários outros métodos especiais do Crystal usam essa sintaxe, como o método `+`.

Assim como na macro getter, quando você quiser atualizar o valor de uma variável de instância depois de definir um setter, você pode chamar o método que a macro setter definiu.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

A macro property define tanto um getter quanto um setter para uma variável de instância.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
