# Instruções

Neste exercício, você precisa implementar algumas regras do [Pac-Man][Pac-Man], o clássico jogo de fliperama da década de 1980.

São seis tarefas no total, e quatro delas são regras relacionadas aos estados do jogo.

> _Não se preocupe com a forma como os argumentos são obtidos nas funções; concentre-se apenas em combinar os argumentos para retornar o resultado esperado._


## 0. Defina um estado de energia

Defina uma variável chamada `PowerOn` com um valor que represente que a energia está de fato ligada.

```powershell
> $PowerOn
True
```

## 1. Defina se o Pac-Man come um fantasma

Defina a função `EatGhost` que recebe dois parâmetros (_se o Pac-Man tem uma pastilha de energia ativa_ e _se o Pac-Man está tocando um fantasma_) e retorna um valor Boolean se o Pac-Man consegue comer o fantasma.
A função deve retornar `True` somente se o Pac-Man tiver uma pastilha de energia ativa e estiver tocando um fantasma.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Defina se o Pac-Man pontua

Defina a função `Score` que recebe dois parâmetros (_se o Pac-Man está tocando uma pastilha de energia_ e _se o Pac-Man está tocando um ponto_) e retorna um valor Boolean se o Pac-Man pontuou.
A função deve retornar `True` se o Pac-Man estiver tocando uma pastilha de energia ou um ponto.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Defina se o Pac-Man perde

Defina a função `Lose` que recebe dois parâmetros (_se o Pac-Man tem uma pastilha de energia ativa_ e _se o Pac-Man está tocando um fantasma_) e retorna um valor Boolean se o Pac-Man perde.
A função deve retornar `True` se o Pac-Man estiver tocando um fantasma e não tiver uma pastilha de energia ativa.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Defina se o Pac-Man vence

Defina a função `Win` que recebe três parâmetros (_se o Pac-Man comeu todos os pontos_, _se o Pac-Man tem uma pastilha de energia ativa_ e _se o Pac-Man está tocando um fantasma_) e retorna um valor Boolean se o Pac-Man vence.
A função deve retornar `True` se o Pac-Man comeu todos os pontos e não perdeu de acordo com os parâmetros definidos na parte 3.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. Escreva uma Sinopse para a condição de vitória

Volte à última função e adicione uma seção `Synopsis` ao bloco de comentários como uma descrição curta de como vencer o jogo.
A descrição deve ter no mínimo dez caracteres.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
