# Espaço reservado

## Geral

- A [função numérica][rand-func] `rand` pode gerar números aleatórios.
- A [função numérica][srand-func] `srand` vai ajudar a definir a semente de `rand`.

## Geração do labirinto

Você pode usar qualquer algoritmo para gerar um labirinto perfeito. O [backtracking recursivo][recursive-backtracker] é uma boa escolha.

## Caracteres de desenho de caixa

| Caractere | Nome                                                  | Unicode |
|:---------:|:------------------------------------------------------|:--------|
|     ┌     | desenho de caixa leve para baixo e para a direita     |  U+250C |
|     ─     | desenho de caixa leve horizontal                      |  U+2500 |
|     ┬     | desenho de caixa leve para baixo e horizontal         |  U+252C |
|     ┐     | desenho de caixa leve para baixo e para a esquerda    |  U+2510 |
|     │     | desenho de caixa leve vertical                        |  U+2502 |
|     └     | desenho de caixa leve para cima e para a direita      |  U+2514 |
|     ┴     | desenho de caixa leve para cima e horizontal          |  U+2534 |
|     ┘     | desenho de caixa leve para cima e para a esquerda     |  U+2518 |
|     ├     | desenho de caixa leve vertical e para a direita       |  U+2520 |
|     ⇨     | seta branca para a direita                            |  U+21E8 |
