# Dicas

## Geral

- Fique atento à sintaxe de ponteiros.
  Você vai usar `*` (operador de desreferência) e `->` (acesso a membro por meio de ponteiro).
- Certifique-se de verificar ponteiros nulos (`nullptr`) quando necessário, para evitar acessar memória inválida.
- Você pode rodar os testes mesmo se o seu código não estiver completo; uma estrutura básica já basta para ver os resultados.
- Todas as funções usadas pelos testes precisam ser declaradas no arquivo de cabeçalho.
- Se o seu programa travar ou se comportar de forma inesperada, muitas vezes a causa é a desreferência de um ponteiro nulo.
  Verifique de novo se você trata `nullptr` corretamente.
- Ao usar aritmética de ponteiros, garanta que você permaneça dentro dos limites do array de sensores.
  Ir além da capacidade do array pode causar problemas de memória.

## 1. Verifique a conexão do sensor (`connection_check`)

- A tarefa consiste basicamente em verificar se um ponteiro é nulo ou não.
- Use o operador de comparação `!=` para verificar se um ponteiro é válido.
- Se você não tiver certeza de que está verificando o ponteiro corretamente, pense no que `nullptr` representa (a ausência de um endereço de memória válido).


## 2. Conte a atividade dos sensores (`activity_counter`)

- Você precisa iterar sobre o array de sensores.
  Um array em C++ pode ser tratado como um ponteiro para o seu primeiro elemento.
- Use aritmética de ponteiros (`sensor_array + i`) para acessar o sensor no índice `i`.
- O operador `->` é usado para acessar um membro da struct por meio de um ponteiro.

### Exemplo

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

## 3. Controle do alarme (`alarm_control`)

- Primeiro, verifique se o ponteiro é nulo antes de acessar o sensor.
- Use o operador `->` para acessar o membro `activity` da struct `pillar_men_sensor`.
- Pense com cuidado sobre o que deve acontecer se o nível de atividade do sensor for `0`.
  O alarme deve disparar?

## 4. Verificação dos dados em busca de anomalias com a função `uv_alarm`

- Use o operador `&` para passar um ponteiro para o array de dados do sensor à função `uv_light_heuristic`.
- Garanta que você verifique corretamente se há um ponteiro nulo antes de acessar os dados do sensor.
- Compare o resultado de `uv_light_heuristic` com o valor `activity` do sensor para determinar se o alarme deve disparar.
