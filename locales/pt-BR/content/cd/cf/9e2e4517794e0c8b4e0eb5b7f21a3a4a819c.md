# Introdução

As expressões regulares em Gleam seguem a especificação **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), de forma parecida com outras linguagens populares, como Java, JavaScript ou Ruby.

O módulo `gleam/regex` oferece funções para trabalhar com expressões regulares.

~~~~exercism/note
Este exercício pressupõe que você já conhece a sintaxe de expressões regulares, incluindo classes de caracteres, quantificadores, grupos e capturas.

Se você precisar relembrar seus conhecimentos de expressões regulares, dê uma olhada em uma destas fontes: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

A forma mais comum de criar expressões regulares é usando a função `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

A função `regex.from_string` retorna um `Error` se a sintaxe da expressão regular for inválida, então uma let-assertion foi usada aqui para garantir que a expressão regular é válida.

A função `regex.check` pode ser usada para verificar se uma expressão regular corresponde a uma string.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Capturas

Se você quiser capturar substrings usando uma expressão regular, a função `regex.scan` pode ser usada para retornar uma lista de correspondências.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Modificadores

É possível modificar o comportamento de uma expressão regular criando-a com a função `regex.compile` e passando opções.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
