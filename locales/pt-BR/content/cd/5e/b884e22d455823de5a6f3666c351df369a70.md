# Conceitos de Paasio

PaaS I/O explora a extensão das traits `Read` e `Write` padrão para fornecer estatísticas adicionais por meio de um tipo wrapper. Uma boa forma de aprender sobre traits em Rust e seus melhores recursos.

Este exercício pode ser implementado com um único tipo ou com dois tipos (um para `Read` e um para `Write`), com os trait bounds adequados.

## Conceitos extraídos

- **Primitivos**
  - `usize`
  - `u8`
- **Imutabilidade/mutabilidade explícita**
- **Structs**
- **Funções**
  - **Métodos**
- **Slices**
- **Aliases de tipo**
- **Referências**
  - Desreferenciamento
- **Traits**
  - Métodos de trait
  - `self` e mutabilidade
  - Trait bounds
- **Blocos `impl`**

## Exemplo usando uma única struct wrapper

Retirado de ["sophie-cyborg"](https://exercism.org/tracks/rust/exercises/paasio/solutions/a2255eb1cc73491184cf88edd982a8d0)

```rust
use std::io::{Read, Result, Write};

pub type ReadStats<T> = IoStats<T>;
pub type WriteStats<T> = IoStats<T>;

pub struct IoStats<T> {
    wrapped: T,
    bytes_through: usize,
    writes: usize,
    reads: usize,
}

impl<T> IoStats<T> {
    pub fn new(wrapped: T) -> IoStats<T> {
        IoStats {
            wrapped,
            bytes_through: 0,
            writes: 0,
            reads: 0,
        }
    }

    pub fn get_ref(&self) -> &T {
        &self.wrapped
    }

    pub fn bytes_through(&self) -> usize {
        self.bytes_through
    }
}

impl<T: Read> IoStats<T> {
    pub fn reads(&self) -> usize {
        self.reads
    }
}

impl<T: Write> IoStats<T> {
    pub fn writes(&self) -> usize {
        self.writes
    }
}

impl<T: Read> Read for IoStats<T> {
    fn read(&mut self, buf: &mut [u8]) -> Result<usize> {
        self.reads += 1;
        self.wrapped.read(buf).map(|bytes| {
            self.bytes_through += bytes;
            bytes
        })
    }
}

impl<T: Write> Write for IoStats<T> {
    fn write(&mut self, buf: &[u8]) -> Result<usize> {
        self.writes += 1;
        self.wrapped.write(buf).map(|bytes| {
            self.bytes_through += bytes;
            bytes
        })
    }

    fn flush(&mut self) -> Result<()> {
        self.wrapped.flush()
    }
}
```

## Exemplo usando duas structs separadas

Retirado de ["fdumontmd"](https://exercism.org/tracks/rust/exercises/paasio/solutions/95344f0ee9ec43a0b152ca2d56c44519)

```rust
use std::io::{Read, Result, Write};

pub struct ReadStats<R> {
    wrapped: R,
    bytes_through: usize,
    reads: usize,
}

impl<R: Read> ReadStats<R> {
    pub fn new(wrapped: R) -> ReadStats<R> {
        ReadStats {
            wrapped,
            bytes_through: 0,
            reads: 0,
        }
    }

    pub fn get_ref(&self) -> &R {
        &self.wrapped
    }

    pub fn bytes_through(&self) -> usize {
        self.bytes_through
    }

    pub fn reads(&self) -> usize {
        self.reads
    }
}

impl<R: Read> Read for ReadStats<R> {
    fn read(&mut self, buf: &mut [u8]) -> Result<usize> {
        self.reads += 1;
        self.wrapped.read(buf)
            .map(|bt| { self.bytes_through += bt; bt })
    }
}

pub struct WriteStats<W> {
    wrapped: W,
    bytes_through: usize,
    writes: usize,
}

impl<W: Write> WriteStats<W> {
    pub fn new(wrapped: W) -> WriteStats<W> {
        WriteStats {
            wrapped,
            bytes_through: 0,
            writes: 0,
        }
    }

    pub fn get_ref(&self) -> &W {
        &self.wrapped
    }

    pub fn bytes_through(&self) -> usize {
        self.bytes_through
    }

    pub fn writes(&self) -> usize {
        self.writes
    }
}

impl<W: Write> Write for WriteStats<W> {
    fn write(&mut self, buf: &[u8]) -> Result<usize> {
        self.writes += 1;
        self.wrapped.write(buf)
            .map(|bt| { self.bytes_through += bt; bt })
    }

    fn flush(&mut self) -> Result<()> {
        self.wrapped.flush()
    }
}
```
