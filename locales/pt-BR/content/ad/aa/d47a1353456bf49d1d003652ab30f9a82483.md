# Pré-requisitos

A trilha da linguagem D exige que você tenha os seguintes programas instalados no seu sistema:

* um compilador D versão 2
* (opcional, mas recomendado) o DUB

## Pré-requisito: compilador D versão 2

No site da linguagem D, [dlang.org](https://dlang.org), é possível baixar e instalar a versão mais recente do compilador de referência DMD (Digital Mars D) para várias plataformas.
Consulte a [página oficial de downloads](https://dlang.org/download.html) para mais informações.
No Windows, uma alternativa é [usar o Chocolatey](https://chocolatey.org/packages/dmd).
Em Macs com processador Intel, uma alternativa é [usar o Homebrew](https://formulae.brew.sh/formula/dmd).

### Outros compiladores
Além do compilador de referência DMD, que usa seu próprio backend, há outros dois compiladores que podem ser obtidos na seção de downloads do dlang.org:

* [GDC](http://gdcproject.org/downloads), que usa o backend do GCC
* [LDC](https://github.com/ldc-developers/ldc#installation), baseado no backend do LLVM

O GDC e o LDC nem sempre acompanham as versões mais recentes do frontend do DMD, mas oferecem níveis melhores de otimização, além de suporte a outras plataformas, como, por exemplo, ARM.

Consulte o wiki para [mais informações](https://wiki.dlang.org/Compilers).

### Suporte em IDEs

A linguagem D também tem suporte em várias IDEs, como o [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html) para o Visual Studio e o [plugin D](https://plugins.jetbrains.com/plugin/7727?pr=clion) para o CLion da IntelliJ.
Consulte o wiki para [mais informações](https://wiki.dlang.org/IDEs).

### Pré-requisito: DUB

O [DUB](https://github.com/dlang/dub) é um gerenciador de build para D.

Recomendamos usá-lo para simplificar o processo de rodar os testes, mas ainda é possível rodar sem o DUB se você não puder ou não quiser instalá-lo.

#### Windows

A [página de downloads do site do DUB](https://code.dlang.org/download) tem um instalador para Windows.
