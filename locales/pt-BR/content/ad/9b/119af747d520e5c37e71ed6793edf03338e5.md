# Solicitar uma nova trilha de linguagem

Siga as instruções abaixo para solicitar uma nova trilha de linguagem.

Se você quiser solicitar uma nova trilha, **você precisa postar na [categoria Support do Fórum da Comunidade do Exercism][forum-support]** para discutir isso com a equipe.

Antes de abrir o post, vale a pena considerar:

- É uma linguagem de programação?
- O Exercism já oferece suporte a essa linguagem?
- Alguém já pediu por ela?
- Você terá disponibilidade para construir e lançar a trilha de forma ativa?

## É uma linguagem de programação?

No Exercism, oferecemos uma plataforma de aprendizado para desenvolvedores que querem praticar uma linguagem de programação ou aprender uma nova.

Se a linguagem for uma linguagem de programação de uso geral, provavelmente vamos nos interessar por ter a trilha no Exercism.
Não criamos trilhas para ferramentas, bibliotecas, frameworks ou tecnologias.

## O Exercism já oferece suporte a essa linguagem?

Confira a [lista de repositórios de trilhas][track-repositories] para encontrar tanto trilhas ativas quanto inativas.
Se você encontrar um repositório para a sua linguagem, confira o valor da chave `active` no arquivo `config.json` do repositório para saber o status dela:

- `true`: a trilha está ativa e aparece na [página de trilhas][exercism-tracks] do site.
- `false`: a trilha está inativa e não aparece no site.
  A trilha ainda precisa de trabalho para se tornar ativa.
  Se você quiser ajudar, abra uma issue nesse repositório para se apresentar.

## Alguém já pediu por ela?

Faça uma busca nas [issues do repositório generic-track][generic-track-repo] pelo nome da linguagem para ver se ela já foi solicitada.
Lembre-se de conferir tanto as issues abertas quanto as fechadas.

## Você terá disponibilidade para construir e lançar a trilha de forma ativa?

O Exercism é uma organização sem fins lucrativos, e todas as trilhas de linguagem são construídas por voluntários.
Só criamos uma trilha se houver pelo menos uma pessoa voluntária que se ofereça para liderar a construção dela.

O mínimo para lançar uma trilha é:

- 20 exercícios de prática (eles podem se basear nas especificações do repositório [problem-specifications][problem-specifications]).
- Integração contínua que verifica se os exercícios podem ser resolvidos.
- Um pouco de configuração e documentação.

Estamos disponíveis para orientar você ao longo do caminho, e você também pode contar com a ajuda da comunidade de pessoas que já fez isso para outras linguagens.

## Ela não existe, eu quero criá-la!

Que ótimo!! Crie um novo post no [Fórum do Exercism][forum-support] para discutirmos os detalhes.
