# Dicas

## Geral

- Leia a documentação de [gleam/set][set]
- A documentação de [gleam/list][list] também pode ser útil

## 1. Inicie uma coleção

- A função mais adequada é [`set.from_list`][from_list]

## 2. Aumente a coleção

- Use a [função `set.insert`][insert]
- Use a [função `set.contains`][contains]

## 3. Comece a trocar

- Use a [função `set.contains`][contains]
- Use a [função `set.insert`][insert]
- Use a [função `set.delete`][delete]

## 4. Só pode haver um de cada

- Um `Set` tem a propriedade de guardar apenas valores únicos
- Use a [função `set.from_list`][from_list]
- Use a [função `set.to_list`][to_list]
- Não há garantia de que `set.to_list` retorne uma lista ordenada

## 5. As cartas que todos têm

- Use a [função `set.intersection`][intersection]
- Use a [função `set.to_list`][to_list]

## 6. Todas as cartas

- Use [`set.new`][new] como acumulador
- Use a [função `set.union`][union]
- Use a [função `set.size`][size]

## 7. Shiny para vencer

- Use a [função `set.filter`][filter]
