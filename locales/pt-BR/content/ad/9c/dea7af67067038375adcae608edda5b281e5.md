# Introdução

Quando você precisa de uma sequência de `n` valores em que cada um depende
do próprio índice, o Factor oferece `<iota>` (uma sequência virtual dos
inteiros `0, 1, …, n-1`) e `map`:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

O `<iota>` não aloca os inteiros de antemão; o `map` percorre esses
inteiros em ordem, aplicando a quotation a cada um.

Se o resultado por posição for um código de caractere, `>string` transforma
o resultado em uma string: a forma natural de montar uma linha de
caracteres a partir de decisões guiadas pelo índice:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
