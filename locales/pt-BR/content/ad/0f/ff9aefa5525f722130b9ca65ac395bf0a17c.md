# Instalação

## O que você precisa

Os itens básicos para desenvolver em Common Lisp são:

- Uma "implementação" de Lisp, que permite compilar e executar código, além de fornecer um REPL.
- Um editor de texto com recursos para código Lisp.
- (Bom ter) A referência mais usada para a linguagem Common Lisp, a ["Common Lisp Hyperspec"][hyperspec].

## Roswell

[Roswell][roswell] é um comando para instalar e gerenciar implementações de Common Lisp, com muitos recursos para facilitar o desenvolvimento e a distribuição de aplicações Lisp.
Usamos ele para simplificar as etapas de instalação e de testes.

### Instalar o Roswell

Consulte o [guia de instalação][ros-inst] e siga as instruções para a sua plataforma.
Para a maioria das pessoas, o seguinte é suficiente:

* No MacOS e no Linux, o [Homebrew][brew] deixa isso simples:
  ```sh
  brew install roswell
  ```
* No Windows, use o [Scoop][scoop]:
  ```powershell
  scoop install roswell
  ```

Na primeira vez que você usar o Roswell, ele baixa e instala o SBCL e o Quicklisp.
Basta rodar isto:
```sh
ros help
```

Entre no REPL com
```sh
ros run
```

## Configure seu editor de texto

Quem está começando com Common Lisp, especialmente quem já tem experiência com o Emacs, pode ter um início rápido e fácil instalando o [Portacle, o Portable Common Lisp Environment][portacle].
Gratuito e cheio de recursos, funciona em todas as plataformas comuns e já vem pré-configurado, pronto para usar. Ele fornece:

- Uma implementação de Lisp: SBCL, incluindo Quicklisp e ASDF.
- Um editor de texto: Emacs

... com vários complementos para escrever código em Lisp:
- SLIME, o "Superior Lisp Interaction Mode for Emacs", transforma o Emacs em uma IDE de Common Lisp
- ParEdit, que facilita trabalhar com parênteses.

Tudo já vem configurado, pronto para usar. Instale o Portacle baixando da [página inicial][portacle].

Observação: o Emacs (editor de texto) pode ser desorientador no começo, se você não estiver acostumado com ele. Felizmente, há muitos tutoriais sobre Emacs e SLIME disponíveis online.

## Instalação tradicional

Se você preferir instalar as ferramentas necessárias separadamente, vai precisar instalar e configurar:

- um editor de texto com suporte a Lisp: o [Emacs][emacs] com o pacote [Slime][slime] ou [Sly][sly] é uma escolha comum, mas [VIM][vim] com [SLIMV][slimv], [Atom][atom] com [SLIMA][slima] ou [VSCode][vscode] com um [plugin de Common Lisp][vscode-plugin] também são boas opções.
- uma implementação de Common Lisp: o [SBCL][sbcl] é uma escolha "segura", que funciona no Linux, no MacOS e no Windows. Como a linguagem se baseia em um padrão, outras [implementações em conformidade][awesome-cl-implementations] também funcionam.
- [Quicklisp][quicklisp] para gerenciar bibliotecas. Depois de baixá-lo, siga as [instruções][quicklisp-install] para garantir que ele esteja bem integrado com a sua implementação de Common Lisp.
