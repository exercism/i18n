# Introdução

Em C++, os valores Boolean são representados pelo tipo `bool`.
Um `bool` é `true` ou `false`.

## Operadores lógicos

O C++ suporta três operadores Boolean: `!` (NOT), `&&` (AND) e `||` (OR).
Você também pode usar as versões alternativas `not`, `and` e `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Precedência

Cada um dos três operadores Boolean tem uma _precedência de operadores_ diferente.
Por isso, eles são avaliados nesta ordem: `!` primeiro, `&&` depois e, por fim, `||`.
Se você quiser forçar uma ordem diferente, pode envolver uma expressão Boolean entre parênteses (ou seja, `()`), já que os parênteses têm uma precedência ainda maior.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Conversão

Se você usar `true` ou `false` em um lugar onde se espera um número, eles serão convertidos em `1` e `0`, respectivamente.
Se você usar um número em uma operação Boolean, tudo, exceto `0`, é tratado como `true`, mesmo valores negativos.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
