# Introdução

## Tipos personalizados

Os tipos personalizados são a forma como novos tipos de dados são definidos em Gleam. Eles podem ter várias _variantes_, cada uma com seu próprio nome.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Cada caso de um tipo personalizado pode, opcionalmente, carregar algum dado, e casos diferentes podem ter tipos de dados diferentes. Quando uma variante carrega dados, ela é chamada de _registro_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

É possível criar um valor para um caso específico referindo-se ao seu nome, se ele não tiver dados adicionais (`Spring`), ou chamando-o como uma função, se tiver (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

Os tipos personalizados, assim como tudo em Gleam, têm _igualdade estrutural_, o que significa que dois valores da mesma variante e com os mesmos dados são equivalentes.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

É possível fazer pattern matching nas variantes de um tipo personalizado usando expressões case.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
