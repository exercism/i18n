# Apêndice das instruções

## Dicas

Para completar este exercício, você precisa criar o tipo de dado `School`
e implementar as seguintes funções:

- `add`
- `empty`
- `grade`
- `sorted`

Você vai encontrar uma declaração de dados fictícia e assinaturas de tipo já
prontas, mas cabe a você definir as funções e criar um tipo de dado, um
newtype ou um sinônimo de tipo que faça sentido.
