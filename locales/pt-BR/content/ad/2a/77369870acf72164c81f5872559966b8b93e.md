# Introdução

## Aliases de tipo

Você pode usar um alias de tipo em Gleam para dar um nome conveniente a um tipo existente que, de outra forma, seria trabalhoso de escrever.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Quando o alias é escrito com `pub type`, ele pode ser usado fora do módulo em que foi definido. Se `pub` for omitido, o alias fica privado e não pode ser referenciado em outros módulos.
