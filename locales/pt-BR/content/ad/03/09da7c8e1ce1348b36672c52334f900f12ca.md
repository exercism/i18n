# Instruções

Lilly adora cozinhar.
Ela quer fazer uma festa de pizza com os amigos.
Para aproveitar ao máximo os ingredientes, ela precisa saber quanto de cada ingrediente vai precisar antes de começar.

Para resolver isso, Lilly esboçou um programa para automatizar parte do planejamento, mas precisa da sua ajuda para terminá-lo.
Você vai ajudar a Lilly a fazer a festa de pizza perfeitamente proporcional?

## 1. Uma proporção de massa

Lilly é fã de pizzas finas e crocantes, com uma borda mais fina.
A massa necessária para o meio é de no mínimo 200 g, mas cada pessoa que ela serve exige mais 20 g de massa.

`grams = pizzas * ((persons * 20) + 200)`

Lilly precisa de uma função que:

- Receba o número de pizzas
- O número de pessoas que cada pizza vai servir
- E retorne a massa necessária arredondada para o grama mais próximo.

Por exemplo, para fazer 4 pizzas que alimentam 8 pessoas:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. Um toque de molho

Lilly é meticulosa ao aplicar o molho, mas o tamanho das suas pizzas pode variar.
Pela sua experiência, ela sabe que são necessários 125 mL de molho por pizza.
Lilly precisa de uma função que calcule quantas latas de molho comprar.

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

Por exemplo, considerando que Lilly precisa fazer 8 pizzas e cada lata tem 250 mL:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. Um pouco de queijo, por favor

O queijo vem em cubos perfeitos e é vendido por tamanho.

A fórmula que Lily usa não é a fórmula da área da pizza, já que ela _não_ quer que o queijo cubra toda a área.
Ela decidiu usar a seguinte fórmula para determinar quantas pizzas de um certo diâmetro (`diameter`) podem ser feitas a partir de um cubo de queijo com um certo comprimento de aresta (`cheese_dimension`):

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

Crie uma função que:

- Receba a medida da aresta de um cubo de queijo
- Receba a espessura desejada da camada de queijo
- Receba o diâmetro da pizza
- E use a fórmula de Lilly para retornar o número de pizzas que podem ser feitas, arredondando para baixo.

Por exemplo, considerando um cubo de queijo de 25x25x25 cm, uma camada de queijo de 0,5 cm de espessura e pizzas de 30 cm de diâmetro:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. Uma divisão justa

Por fim, Lilly quer que suas pizzas sejam divididas em 8 fatias cada e distribuídas igualmente entre os amigos.

Crie uma função que:

- Receba um número de pizzas e um número de amigos
- e retorne o número de fatias que vão sobrar se cada pessoa pegar a mesma quantidade de fatias.

Por exemplo:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
