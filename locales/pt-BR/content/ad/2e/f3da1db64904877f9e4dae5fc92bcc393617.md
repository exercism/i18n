# Introdução

## Funções matemáticas

Raízes quadradas, ângulos e curvas de crescimento são difíceis de calcular só com `+`,
`-`, `*` e `/`. O vocabulário [`math.functions`][math.functions] tem palavras que
fazem essas contas para você, e [`math.constants`][math.constants] tem o π. Como
qualquer outra palavra, cada uma pega suas entradas da pilha e deixa a resposta lá.

## Raízes quadradas

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

Uma escada de 5 metros de comprimento, com o pé a 3 metros da parede, alcança
4 metros de altura nela:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## Pi

`pi` (de `math.constants`) empilha π, o número de vezes que o diâmetro de um círculo
cabe ao longo da circunferência:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## Ângulos em radianos

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`, `cos` e `tan` recebem um ângulo, mas não em graus. Elas usam
**radianos**, em que meia volta é π em vez de 180. Passar graus para elas não é um
erro: só dá a resposta errada, sem avisar.

`deg>rad` converte graus em radianos, e `rad>deg` converte de volta.
É o mesmo que multiplicar por π e dividir por 180, ou o contrário:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

Converta graus em radianos antes de chamar `sin`:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

Uma rampa de 10 metros a 30 graus sobe 5 metros. A resposta aparece como
`4.999999999999999` porque as funções matemáticas dão o número de ponto flutuante
mais próximo, não o valor exato. Sem a conversão, `30 sin` trata 30 como
radianos (quase cinco voltas completas) e a rampa "subiria"
`-9.88` metros.

## Encontrando um ângulo

`fatan2` faz o caminho inverso: dado o quanto para cima e o quanto na horizontal,
ela responde o ângulo em radianos. Ela fica em [`math.libm`][math.libm].
A distância *para cima* vai na pilha primeiro, depois a distância
*na horizontal*:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

O ângulo é medido a partir da direção *horizontal* positiva. `fatan2`
olha para os sinais das duas distâncias, então pode responder em qualquer ponto de
−180 a 180 graus.

## Potências de dez: 10^ e log10

`10^` eleva 10 a uma potência:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` faz o caminho inverso. Ela responde à pergunta "10 elevado a que
potência dá este número?" Essa resposta é o **logaritmo** do número:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ e log

`e^` e `log` são o mesmo par, com *e* (aproximadamente 2,718) no lugar de
10. `e^` eleva *e* a uma potência, e `log` responde "*e* elevado a que potência
dá este número?"

```
e^  ( x -- y )
log ( x -- y )
```

Os matemáticos usam *e* para qualquer coisa que cresça ou diminua na mesma
fração a cada passo. Dinheiro rendendo juros é um exemplo, e uma xícara
de chá esfriando é outro:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log` desfaz `e^`. Isso responde à pergunta ao contrário: em quantos
minutos a diferença cai para 40 graus?

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
