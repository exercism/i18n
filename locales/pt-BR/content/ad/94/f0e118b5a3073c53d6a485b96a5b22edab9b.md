# Apêndice das instruções

## Valor inteiro máximo

De acordo com [a documentação do Vim][number]:

> Supondo que números de 64 bits sejam usados (veja v:numbersize), um número sem sinal é truncado para 0x7fffffffffffffff ou 9223372036854775807.

Em outras palavras, o Vim script não consegue expressar nenhum número `2^63` ou maior como um inteiro.

Alguns dos testes deste exercício exigem inteiros de 64 bits, o que ultrapassa a limitação de tamanho de inteiros do Vim script.
Por causa dessa limitação, os resultados dos cálculos são testados em comparação com uma string que expressa o valor inteiro, em vez de expressar a resposta como Integer.
Você consegue resolver isso evitando diretamente números maiores do que a linguagem permite?

[number]: https://vimhelp.org/eval.txt.html#expr-number
