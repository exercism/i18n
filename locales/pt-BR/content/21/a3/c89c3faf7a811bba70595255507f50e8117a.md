# Dicionários

Os dicionários em Cairo são armazenamentos de chave-valor parecidos com mapas ou tabelas hash de outras linguagens.

No entanto, eles têm algumas características únicas por causa do modelo de memória imutável do Cairo.

## Conceito principal

O tipo `Felt252Dict<T>` oferece a funcionalidade de dicionário em Cairo, com `felt252` como tipo de chave e qualquer tipo `T` compatível como tipo de valor.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## Características importantes

Diferentemente dos dicionários de outras linguagens, os dicionários do Cairo têm algumas propriedades especiais:

1. As chaves precisam ser valores `felt252`.
2. Todas as chaves começam implicitamente com o valor zero.
3. Não é possível excluir entradas: você só pode atualizar valores.
4. Os valores precisam implementar a trait `Felt252DictValue`.

## Nota sobre desempenho

Por causa do modelo de memória imutável do Cairo, as operações de dicionário têm complexidade $O(n)$, em que $n$ é o número de operações realizadas no dicionário.

Cada operação cria uma nova entrada que registra a mudança.

## Trabalhando com tipos complexos

Para tipos que não implementam `Felt252DictValue` (como arrays ou structs), você pode envolvê-los em `Nullable<T>`:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## Gerenciamento de memória

Os dicionários implementam a trait `Destruct`, o que significa que eles são automaticamente "squashed" (validados e otimizados) quando saem de escopo.

Isso faz parte do sistema de provas do Cairo e acontece nos bastidores.

Lembre-se: embora os dicionários possam parecer menos eficientes do que em outras linguagens, eles foram projetados assim para funcionar com o modelo de memória único do Cairo e com os requisitos do seu sistema de provas.
