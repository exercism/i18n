Como futura mágica, Elyse precisa praticar alguns fundamentos.
Ela tem um baralho de cartas que quer manipular.

Para facilitar um pouco as coisas, ela usa apenas as cartas de 1 a 10.

## 1. Recuperar uma carta de um baralho

Retorne a carta na posição `idx` do baralho fornecido.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. Trocar uma carta no baralho

Troque a carta na posição `idx` pela nova carta fornecida e retorne o baralho ajustado.
Observe que isso vai modificar (alterar) o vetor de entrada, e não tem problema.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. Inserir uma carta no topo do baralho

Insira uma nova carta no topo do baralho e retorne o baralho.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. Remover uma carta do baralho

Remova a carta na posição `idx` do baralho e retorne o baralho.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. Remover a carta do topo do baralho

Remova a carta do topo do baralho e retorne o baralho.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. Inserir uma carta na base do baralho

Insira uma nova carta na base do baralho e retorne o baralho.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. Remover uma carta da base do baralho

Remova a carta da base do baralho e retorne o baralho.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. Verificar o tamanho do baralho

Verifique se o tamanho do baralho é igual ao `deck_size` fornecido.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
