# Apêndice das instruções

## Palavras

`convert ( rows -- str )` recebe a grade como um array de strings,
uma string por linha, e retorna os dígitos reconhecidos como uma única
string. Várias linhas de casas são unidas na saída com
vírgulas (`,`).

## Erros

Lance uma dessas strings (exatamente como estão) para entrada malformada:

- `"Number of input lines is not a multiple of four"`
- `"Number of input columns is not a multiple of three"`
