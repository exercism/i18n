# Complemento das instruções

## Instruções específicas da trilha

O compilador Phix normalmente conhece todos os pacotes padrão distribuídos com ele e os incorpora automaticamente para você quando necessário. No entanto, nem sempre é o caso, assim como não seria com componentes que você criou como parte de uma aplicação.
Este exercício (simplérrimo) não envolve nada além de localizar o pacote padrão de números complexos distribuído com o Phix e deixá-lo disponível para os testes rodarem. 

Você pode usar a [online][[online] cópia da documentação, embora, se você tiver instalado uma cópia localmente, talvez descubra que ela tem recursos de busca melhores, especialmente a versão chm, normalmente localizada em `C:\Program Files[ (x86)]\Phix\docs\phix\`.

Se você quiser aprender como a aritmética de números complexos é implementada, não há nada melhor do que examinar o código-fonte desse componente padrão, pelo menos de modo geral. Não vou negar que possa haver algoritmos um pouco melhores por aí para uma ou duas coisas, que poderiam ser mais rápidos, mais precisos, ou ambos.

[online]:(http://phix.x10.mx/docs/html/phix.htm)
