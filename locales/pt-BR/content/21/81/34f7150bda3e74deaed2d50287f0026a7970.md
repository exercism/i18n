# Dicas

## 1. Determine quanto tempo leva para misturar um suco

- Prepare uma [condicional `switch`][mdn-switch] para a variável `name`.
- Os diferentes casos devem representar os diferentes nomes de suco.
- Use o caso `default` para cobrir todos os outros nomes.
- Lembre-se de que os casos [passam para o seguinte por padrão][mdn-fallthrough], então certifique-se de fazer algo para evitar esse comportamento.

## 2. Reabasteça o estoque de gomos de limão

- Use um [laço `while`][mdn-while] para cortar um limão depois do outro.
- Reveja o [conceito de arrays][concept-arrays] para encontrar uma forma de remover os limões da lista na ordem correta.
- Prepare uma [condicional `switch`][mdn-switch] para obter o número de gomos de um determinado tamanho de limão.
- Você precisa acompanhar duas coisas: quantos limões já foram cortados e quantos gomos ainda faltam.
- Você pode combinar duas condições para o laço usando [operadores lógicos][concept-booleans].

## 3. Termine o turno

- Use um [laço `do-while`][mdn-do-while] para atender um pedido depois do outro.
- Reveja o [conceito de arrays][concept-arrays] para encontrar uma forma de remover as bebidas da lista na ordem correta.
- Você já tem uma função que determina o tempo que leva para preparar uma bebida. Use-a para reduzir o tempo restante de acordo.
- Você pode combinar duas condições para o laço usando [operadores lógicos][concept-booleans].
