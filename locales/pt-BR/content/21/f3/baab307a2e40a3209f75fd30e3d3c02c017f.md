# Introdução

O Gleam pode rodar na máquina virtual do Erlang (BEAM) ou em runtimes de JavaScript. Existem muitas outras linguagens que usam esses runtimes, e muitas vezes é útil conseguir chamar, a partir do Gleam, código escrito nessas linguagens.

O recurso de _funções externas_ do Gleam permite importar funções de outras linguagens para o Gleam e chamá-las sem sobrecarga em tempo de execução.

Se o seu projeto Gleam roda na máquina virtual do Erlang e você quer chamar a função `reverse` do módulo `lists` do Erlang, você pode fazer isso adicionando o atributo `@external` a um cabeçalho de função do Gleam, assim:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Depois, você pode chamá-la como uma função normal do Gleam:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Se você tentar compilar esse código para runtimes de JavaScript, vai dar erro com uma mensagem, porque não há implementação para JavaScript. Você pode especificar outra implementação para runtimes de JavaScript assim:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Também é possível escrever uma implementação em Gleam que será usada quando não houver implementação externa para o alvo de compilação atual:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
