# Instruções

Você está de volta à cozinha, refinando a receita de lasanha do exercício
[Lasanha Suculenta da Leah][lasagna]. As tarefas aqui pedem que você lide
com várias entradas ao mesmo tempo, e é exatamente aí que os *locals*, as
vinculações nomeadas do Factor, se justificam.

## 1. Determine o status de cozimento

Defina `cooking-status` para pegar uma leitura do timer da pilha e
retornar uma string de status.

- `0` → `"Lasagna is done."`
- `f` (o timer nunca foi definido) → `"You forgot to set the timer."`
- qualquer outro número → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Estime o tempo de preparo

Defina `preparation-time` para receber um array de nomes de camadas e uma
média de minutos por camada, e retornar o tempo total de preparo.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Calcule o macarrão e o molho necessários

Defina `quantities` para receber um array de nomes de camadas e retornar
*dois* valores: quantos gramas de macarrão são necessários (50 g por
camada de macarrão) e quantos litros de molho são necessários (`1/5` de
litro por camada de molho).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Adicione o ingrediente secreto

Alguém te manda uma lista de ingredientes; o *último* item é o segredo
dessa pessoa. Defina `add-secret-ingredient` para receber a lista dela e
a sua e retornar a sua lista com o segredo acrescentado.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Ajuste a escala da receita

A receita do livro rende duas porções. Defina `scale-recipe` para receber
uma receita (um hashtable que mapeia o nome do ingrediente para a
quantidade) e um número desejado de porções, e retornar uma nova receita
ajustada na proporção certa.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
