# Anexo às instruções

## Apêndice

~~~~exercism/note
As instruções acima são sincronizadas com um repositório compartilhado para garantir consistência entre todas as trilhas de linguagens.
Este apêndice traz esclarecimentos adicionais ou modifica as instruções conforme necessário para se alinhar melhor aos objetivos da trilha de Clojure.
~~~~

É importante não usar funções nativas já existentes com funcionalidade parecida com a da função que você está implementando, pois isso reduziria o valor de aprendizado pretendido do exercício.
Em Clojure, não existe uma função nativa para contar o número de bits em um número, então você pode usar qualquer função de Clojure na sua implementação.
No entanto, o Java inclui uma função para essa finalidade: `bitCount`.
