# Dicas

## Geral

- Os arrays com as contagens de pássaros sempre contêm exatamente 7 números inteiros.

## 1. Verifique quais eram as contagens na semana passada

- Existem [várias formas de definir um array][creating-arrays].

## 2. Verifique quantos pássaros visitaram ontem

- Lembre-se de que as contagens estão ordenadas por dia, da mais antiga para a mais recente, e o último elemento representa hoje.
- Você pode acessar o penúltimo elemento de duas formas: usando o índice dele (que é fixo, e a contagem começa do zero) ou calculando esse índice a partir do comprimento do array, seja com uma [função do módulo `Array`][length-function], seja acessando uma das [propriedades][length-property] do array.

## 3. Calcule o total de pássaros visitantes

- O módulo `Array` tem uma [função para somar os valores de um array][sum-function].

## 4. Verifique se houve algum dia sem pássaros visitantes

- O módulo `Array` tem uma [função para verificar se um array contém um valor específico][contains-function].

## 5. Incremente a contagem de hoje

- Há duas formas de atualizar um valor em um array:
  - O operador `<-` permite atualizar um valor em um array.
  - O módulo `Array` tem uma [função para atualizar um valor em um array][set-function].
- A função acima, que atualiza um valor em um array, não retorna valor. Por isso, você deve retornar manualmente o array atualizado depois de definir o valor dele.

## 6. Verifique se a semana foi incomum

- Em vez de verificar todos os valores individualmente, use [pattern matching][pattern-matching-array].
