# Dicas

## Geral

- Uma árvore é uma estrutura de dados recursiva que tem dois casos:
  - `nil`: um nó folha, que não tem um valor
  - `node(Left, Value, Right)`: um nó normal, que tem um valor e um nó à esquerda e outro à direita
- Tanto para o percurso pré-ordem quanto para o em-ordem, você vai precisar definir regras que lidem com os dois casos de árvores
