# Instalação

Para trabalhar nos exercícios, você vai precisar destes programas:

1. [`OPAM`, o gerenciador de pacotes do OCaml](https://opam.ocaml.org/)

   Consulte [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)
   para saber como instalar e configurar o `OPAM` no seu sistema operacional.

2. O compilador OCaml

   Veja uma lista das versões disponíveis:

   ```bash
   opam switch
   ```

   Se você já tem um switch para OCaml 5.1, carregue-o rodando `opam switch <switch-name>` ou crie um novo switch rodando:

   ```bash
   opam switch create exercism 5.4.0
   ```

   O nome `exercism` aqui é opcional, mas dar nome aos seus switches é uma boa prática.

3. Instale bibliotecas padrão estendidas e bibliotecas de teste

   Rode o seguinte para instalar as dependências exigidas por esta trilha:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   Alguns exercícios usam apenas a biblioteca padrão do OCaml, e outros usam as bibliotecas estendidas da Jane Street chamadas Base e Core_kernel.
   A biblioteca de testes se chama OUnit, e alguns exercícios também usam a biblioteca QCheck para testes baseados em propriedades.
   Rodar o comando acima instala essas bibliotecas.

4. Instale e use um shell interativo (opcional)

   Um resumo de [Configurando e usando o `utop`](https://dev.realworldocaml.org/install.html):

   ```bash
   opam install utop
   ```

   Crie um novo arquivo chamado `.ocamlinit` no seu diretório home e adicione as seguintes linhas a ele:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. Instale ferramentas no VS Code (opcional)

   Se você usa o VS Code:
   - Instale o servidor de linguagem OCaml [daqui](https://github.com/ocaml/ocaml-lsp).
   - Instale a extensão OCaml para VS Code [daqui](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform) ou procure por `OCaml Platform`, da Ocaml Labs.
