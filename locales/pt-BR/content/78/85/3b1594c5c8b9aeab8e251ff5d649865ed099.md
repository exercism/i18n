## Callable

Em PHP, existe o conceito de [callable](https://www.php.net/manual/en/language.types.callable.php).

Eles podem assumir várias formas, mas vamos focar nas [funções anônimas](https://www.php.net/manual/en/functions.anonymous.php).

É possível criar uma função anônima em uma variável e chamá-la com parâmetros:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
