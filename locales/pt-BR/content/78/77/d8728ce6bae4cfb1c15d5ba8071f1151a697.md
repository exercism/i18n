# Instruções

Neste exercício, você vai escrever código para acompanhar uma lista de linguagens de programação que você quer aprender no Exercism.

São seis tarefas, e todas envolvem lidar com listas.

## 1. Criar uma nova lista

Para acompanhar as linguagens que você quer aprender, você vai precisar criar uma nova lista. Defina o binding `newList`, que contém uma nova lista vazia.

```fsharp
newList
// => []
```

## 2. Definir uma lista existente

No momento, você tem um pedaço de papel com as linguagens que quer aprender: F#, Clojure e Haskell. Defina o binding `existingList` para representar essa lista.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Adicionar uma nova linguagem à lista

Conforme você explora o Exercism e encontra linguagens mais interessantes, você vai querer adicioná-las à sua lista. Implemente a função `addLanguage` para adicionar uma nova linguagem ao início da sua lista.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Contar as linguagens da lista

Contar as linguagens uma a uma é inconveniente. Implemente a função `countLanguages` para contar quantas linguagens há na sua lista.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Inverter a lista

Em algum momento, você percebe que sua lista está na verdade ordenada ao contrário! Implemente a função `reverseList` para inverter a sua lista.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Verificar se a lista é empolgante

Embora você ame todas as linguagens, o F# ocupa um lugar especial no seu coração. Por isso, uma lista de linguagens te empolga muito quando:

- O primeiro item da lista é o F#.
- O segundo item da lista é o F# e a lista contém duas ou três linguagens.

Implemente a função `excitingList` para verificar se uma lista de linguagens é empolgante:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
