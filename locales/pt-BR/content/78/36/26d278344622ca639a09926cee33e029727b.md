# Introdução

O ABAP tem vários tipos numéricos. Neste exercício, você vai usar dois deles:

- `i` para valores inteiros, como um número de dias.
- `p` para valores decimais empacotados, como um valor por hora ou um desconto.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Os números empacotados definem o comprimento máximo e o número de casas decimais. Literais decimais são geralmente escritos como valores de texto e convertidos para o tipo decimal de destino pelo compilador ou com `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

O ABAP oferece funções numéricas integradas para arredondamento. A função `floor` arredonda para baixo até o número inteiro mais próximo, e `ceil` arredonda para cima até o número inteiro mais próximo.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
