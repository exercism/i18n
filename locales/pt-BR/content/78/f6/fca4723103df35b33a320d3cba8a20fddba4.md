## Geral

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Para acessar menos de 64 bits de um registrador, consulte o [Manual da AMD][manual] para saber o nome adequado.

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.

## 3. Defina `items_to_be_moved`

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Para acessar menos de 64 bits de um registrador, consulte o [Manual da AMD][manual] para saber o nome adequado.
- Você pode retornar mais cedo para verificar cada etapa.
- A subtração funciona da mesma forma para números com e sem sinal.

## 4. Defina `calculate_payment`

- Os seis primeiros argumentos inteiros são passados para uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Para acessar menos de 64 bits de um registrador, consulte o [Manual da AMD][manual] para saber o nome adequado.
- Você pode retornar mais cedo para verificar cada etapa.
- Se você receber respostas muito grandes quando esperava um número negativo, provavelmente o sinal de um dos números está incorreto.
- Existe uma [instrução][cqo] para estender o sinal de valores de `rax` para `rdx`.
- Existe uma [instrução][idiv] para divisão com sinal.
- O pagamento é dividido entre você e um certo número de trabalhadores, e você também fica com o resto.
- O resto de uma divisão é armazenado em `rdx`.
