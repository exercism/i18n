# Introdução

Uma forma comum de usar o tipo união discriminada em F# é representar um conjunto fixo de constantes nomeadas, uma estrutura chamada de "enum" em outras linguagens.

Normalmente, em uma união discriminada assim, cada caso só pode se referir a exatamente uma dessas constantes nomeadas.
Porém, às vezes é útil se referir a mais de uma constante.
Para isso, você pode anotar a união discriminada com o atributo Flags.

Uma união discriminada com o atributo Flags pode ser definida assim (usando a notação de inteiro binário 0b):

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 0b00000001
| Text = 0b00000010
```

Uma instância de `PhoneFeatures` com o valor `0b00000011` tem as flags `Call` e `Text` definidas.
