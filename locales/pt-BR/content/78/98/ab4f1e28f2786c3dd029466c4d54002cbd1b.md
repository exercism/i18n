# Introdução

Muitos programas precisam de valores (pseudo)aleatórios para simular acontecimentos do mundo real.

Exemplos comuns e familiares incluem:

- O lançamento de uma moeda: um valor aleatório dentre ('H', 'T').
- O lançamento de um dado: um número inteiro aleatório de 1 a 6.
- Embaralhar um baralho de cartas: uma ordenação aleatória de uma lista de cartas.
- A criação de árvores e arbustos em uma simulação gráfica 3-D.

Gerar valores verdadeiramente aleatórios com um computador é um [desafio técnico surpreendentemente difícil][why-randomness-is-hard], e é por isso que também existem geradores "pseudoaleatórios".

A [especificação da linguagem][spec] para JavaScript não obriga uma implementação específica para a geração de números aleatórios.

## Gerando números aleatórios

Em JavaScript, você pode gerar números pseudoaleatórios usando a função [`Math.random()`][Math.random].
Ela retorna um número de ponto flutuante pseudoaleatório entre 0 (inclusive) e 1 (exclusive).

Para obter um número aleatório entre _min_ (inclusive) e _max_ (exclusive), você pode usar uma função mais ou menos assim:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

A maioria das técnicas simples de retornar um intervalo de números com base no número gerado aleatoriamente [introduz viés][bias].
Isso significa que alguns números terão mais chance de sair do que outros.
Usar a técnica da multiplicação espalha o viés por todo o intervalo, então ele fica menos óbvio e, na maioria dos casos, não é um grande problema, mas você deve estar ciente disso.

## Gerando números inteiros aleatórios

Para gerar um número inteiro aleatório, você pode usar `Math.floor()` ou `Math.ceil()` para transformar um número gerado aleatoriamente em um número inteiro.
