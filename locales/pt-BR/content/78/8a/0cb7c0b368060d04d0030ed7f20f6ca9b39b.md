# Anexo às instruções

## Implementação

Os itens são representados por [records](https://lfe.gitbooks.io/reference-guide/content/16.html), definidos em `item.lfe`.
Use `item-weight` para obter o peso e `item-value` para obter o valor.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
