# Apêndice das instruções

## Registros

| Registro | Uso           | Tipo     | Descrição                              |
| -------- | ------------- | -------- | -------------------------------------- |
| `$a0`    | entrada       | endereço | string de entrada terminada em nulo    |
| `$a1`    | entrada/saída | endereço | string de saída terminada em nulo      |
| `$t0-9`  | temporário    | qualquer | usados para armazenamento temporário   |
