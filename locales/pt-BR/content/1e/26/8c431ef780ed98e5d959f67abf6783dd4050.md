# Dicas

## Geral

- Você precisa tornar as funções [visíveis para outros arquivos][global].
- A [documentação do NASM][interfacing] descreve como os argumentos das funções são passados e como os valores de retorno são obtidos.

## 1. Defina o tempo esperado no forno, em minutos

- Você precisa tornar as funções [visíveis para outros arquivos][global].
- A [documentação do NASM][interfacing] descreve como os argumentos das funções são passados e como os valores de retorno são obtidos.
- Existe uma [instrução][mov] para armazenar um valor em um registrador.
- Você pode definir constantes em tempo de montagem usando `equ`.

## 2. Calcule o tempo restante no forno, em minutos

- Você precisa tornar as funções [visíveis para outros arquivos][global].
- A [documentação do NASM][interfacing] descreve como os argumentos das funções são passados e como os valores de retorno são obtidos.
- Você pode [chamar][call] uma das outras funções que você definiu antes.
- Existe uma [instrução][sub] para subtrair valores.

## 3. Calcule o tempo de preparo, em minutos

- Você precisa tornar as funções [visíveis para outros arquivos][global].
- A [documentação do NASM][interfacing] descreve como os argumentos das funções são passados e como os valores de retorno são obtidos.
- Existe uma [instrução][imul] para multiplicar valores.

## 4. Calcule o tempo decorrido, em minutos

- Você precisa tornar as funções [visíveis para outros arquivos][global].
- A [documentação do NASM][interfacing] descreve como os argumentos das funções são passados e como os valores de retorno são obtidos.
- Você pode [chamar][call] uma das outras funções que você definiu antes.
- Existe uma [instrução][add] para somar valores.
