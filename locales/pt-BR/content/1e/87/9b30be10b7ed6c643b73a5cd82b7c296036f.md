# Instruções

Neste exercício, você vai organizar corridas entre vários tipos de carros de controle remoto. Cada carro tem sua própria velocidade e suas próprias características de consumo de bateria.

Os carros começam com a bateria cheia (100%). Cada vez que você dirige o carro com o controle remoto, ele percorre a velocidade do carro em metros e diminui a porcentagem restante de bateria pelo seu consumo de bateria.

Se a bateria de um carro estiver abaixo da porcentagem de consumo de bateria dele, você não pode mais dirigir o carro.

Cada pista de corrida tem sua própria distância. Os carros são testados verificando se conseguem terminar a pista sem ficar sem bateria.

Você tem seis tarefas, e cada uma delas vai trabalhar com instâncias de carros de controle remoto.

## 1. Criando um carro de controle remoto

Permita criar um carro de controle remoto definindo um construtor para a classe `RemoteControlCar` que recebe a velocidade do carro em metros e a porcentagem de consumo de bateria como seus dois parâmetros (ambos do tipo `int`):

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. Criando uma pista de corrida

Permita criar uma pista de corrida definindo um construtor para a classe `RaceTrack` que recebe a distância da pista em metros como seu único parâmetro (que é do tipo `int`):

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Dirija o carro

Implemente o método `RemoteControlCar.Drive()` que atualiza o número de metros percorridos com base na velocidade do carro. Implemente também o método `RemoteControlCar.DistanceDriven()` para retornar o número de metros percorridos pelo carro:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. Verifique se a bateria acabou

Atualize o método `RemoteControlCar.Drive()` para drenar a bateria com base no consumo de bateria do carro. Implemente também o método `RemoteControlCar.BatteryDrained()` que indica se a bateria acabou:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. Crie o carro de controle remoto Nitro

O carro de controle remoto mais vendido é o Nitro, que tem uma velocidade máxima impressionante de 50 metros com um consumo de bateria de 4%. Implemente o método (estático) `RemoteControlCar.Nitro()` para retornar esse tipo de carro:

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. Verifique se um carro de controle remoto consegue terminar uma corrida

Para terminar uma pista de corrida, o carro precisa conseguir percorrer a distância da pista. Isso significa não drenar a bateria antes de cruzar a linha de chegada. Implemente o método `RaceTrack.TryFinishTrack()` que recebe uma instância de `RemoteControlCar` como parâmetro e retorna `true` se o carro conseguir terminar a pista de corrida; caso contrário, retorna `false`:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
