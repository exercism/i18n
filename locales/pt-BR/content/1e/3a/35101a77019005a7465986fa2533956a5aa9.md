# Complemento das instruções

## Traits do Rust para `.to_string()`

Você também vai precisar implementar `.to_string()` para a struct `Clock`.
Vamos usar isso para exibir o estado do Clock.
Você pode fazer isso implementando diretamente ou usando o [trait Display][display-trait].

Se for esse o caso, experimente implementar o [trait Display][display-trait] para `Clock`.

Os traits permitem uma forma comum de implementar funcionalidade para vários tipos.

Para aprender mais, pense em como você poderia implementar `String::from` para o tipo `Clock`.
Você não precisa implementar isso de fato (é redundante com `Display`, que em geral é a melhor
escolha quando o tipo de destino é `String`), mas é útil ter alguns traits de conversão de
tipos no seu kit de ferramentas.

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
