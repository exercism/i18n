# Sobre

Escreva código que se lê como inglês simples.

O Visual Basic roda no mesmo runtime .NET que o C# e o F#.
Você tem LINQ, generics e async/await, mas a sintaxe foi feita para ser lida, não decifrada.

Se você já conhece C# ou F#, o runtime e as bibliotecas do .NET vão ser familiares.
Se você conhece VB6, VBA ou VBScript, essa sintaxe familiar agora é sustentada pelo runtime .NET, que já provou seu valor.

Sem chaves para equilibrar, sem pontos e vírgulas para caçar.
