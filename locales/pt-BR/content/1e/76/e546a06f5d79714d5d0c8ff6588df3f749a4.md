# Anexo de instruções

## Mensagens de exceção

Às vezes é necessário [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você fizer isso, inclua sempre uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda muito na depuração. Em situações em que você sabe que a origem do erro será de um determinado tipo, você pode escolher lançar um dos [tipos de erro embutidos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda assim deve incluir uma mensagem significativa.

Este exercício em particular exige que você use a [instrução `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um `ValueError` se os parâmetros series e/ou length passados para a função `slice()` estiverem vazios ou fora do intervalo. Os testes só serão aprovados se você usar `raise` na `exception` e incluir uma mensagem junto com ela.

Para lançar um `ValueError` com uma mensagem, escreva a mensagem como um argumento do tipo `exception`:

```python
# if the slice length is zero.
raise ValueError("slice length cannot be zero")

# if the slice length is negative.
raise ValueError("slice length cannot be negative")

# if the series provided is empty.
raise ValueError("series cannot be empty")

# if the slice length is longer than the series.
raise ValueError("slice length cannot be greater than series length")
```
