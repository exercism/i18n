# Instruções

Crie uma implementação da cifra Atbash, um antigo sistema de criptografia criado no Oriente Médio.

A cifra Atbash é uma cifra de substituição simples que se baseia em inverter todas as letras do alfabeto, de modo que o alfabeto resultante fique de trás para frente.
A primeira letra é substituída pela última, a segunda pela penúltima, e assim por diante.

Uma cifra Atbash para o alfabeto latino seria assim:

```text
Plain:  abcdefghijklmnopqrstuvwxyz
Cipher: zyxwvutsrqponmlkjihgfedcba
```

É uma cifra muito fraca, porque tem apenas uma chave possível e é uma cifra de substituição monoalfabética simples.
No entanto, isso pode não ter sido um problema na época da cifra.

O texto cifrado é escrito em grupos de comprimento fixo, sendo o tamanho tradicional do grupo 5 letras, deixando os números inalterados, e a pontuação é excluída.
Isso serve para dificultar a adivinhação com base nos limites das palavras.
Todo o texto será codificado em letras minúsculas.

## Exemplos

- Codificar `test` dá `gvhg`
- Codificar `x123 yes` dá `c123b vh`
- Decodificar `gvhg` dá `test`
- Decodificar `gsvjf rxpyi ldmul cqfnk hlevi gsvoz abwlt` dá `thequickbrownfoxjumpsoverthelazydog`
