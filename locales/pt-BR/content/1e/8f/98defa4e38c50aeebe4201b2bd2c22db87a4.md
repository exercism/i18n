# Instruções

O departamento de reivindicações da Isaac's Asteroid Exploration Co. pediu que você melhore o desempenho do sistema de reivindicação de terras deles.

Sempre que um asteroide está pronto para exploração, especuladores são convidados a registrar sua reivindicação de um lote de terra.
A terra do asteroide é dividida em lotes retangulares que não se sobrepõem.
As dimensões variam, mas todos têm lados paralelos aos eixos coordenados.
Os especuladores reivindicam um dos lotes informando suas coordenadas.

Seu objetivo é desenvolver um sistema de alto desempenho para lidar com a corrida pelas terras que, no passado, derrubou o site.

A unidade de medida é 100 metros, mas pode ser ignorada nestas tarefas.

## 1. Defina um ponto

Defina uma `struct` para guardar as coordenadas `x` e `y`.
Elas são inteiros não negativos bem pequenos, então use o tipo `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Defina um Plot

Como todos os lotes devem ser retangulares, com lados horizontais e verticais, só são necessários dois cantos opostos para defini-los.

Implemente a struct `Plot`, recebendo dois structs `Coord` no construtor.

`Plot` deve ser uma struct com argumentos nomeados, contendo os campos `bottom_left` e `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Verifique se a sua reivindicação já foi registrada

Há concorrência por essas reivindicações, então, antes de a sua ser aceita, ela será verificada em relação às reivindicações existentes no registro.

Implemente a função `is_claim_staked()` para determinar se uma reivindicação já foi registrada.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. Especuladores podem registrar sua reivindicação informando um lote identificado pelas coordenadas de um de seus cantos

Implemente a função mutável `stake_claim!()` para permitir que uma reivindicação seja registrada.

Se a mesma reivindicação já tiver sido registrada, retorne `false`.

Se uma nova reivindicação for possível, adicione-a ao registro e retorne `true`.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Encontre o comprimento do lado mais longo de um lote.

Implemente a função `get_longest_side()` para obter o lado mais longo (horizontal ou vertical) de uma reivindicação.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Encontre o lote reivindicado que tem o lado mais longo, para fins de pesquisa

Implemente a função `get_claim_with_longest_side()` para examinar todas as reivindicações registradas e retornar a(s) reivindicação(ões) com o lado mais longo.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Retorne o(s) `Plot`(s) como um `Set`, com um elemento se houver um único lote mais longo, ou vários em caso de empate.
