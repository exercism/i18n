# Dicas

## Geral

- Todas as palavras de limpeza ficam em [`destructors`][destructors].
- `:>` e `::` (locals) mantêm legíveis os corpos com várias bombas. Adicione `locals` ao `USING:` se você recorrer a eles.

## 1. Esvaziar o porão

- Uma palavra: `dispose`.

## 2. Rotina de bombeamento

- Uma palavra: `with-disposal`. Adicione `inline` depois do `;` de fechamento
  para que o compilador consiga enxergar através do argumento de citação:
  `: pump-out ( pump quot -- ) with-disposal ; inline`.

## 3. Rotina do turno inteiro

- Abra o escopo com `with-destructors`. Dentro dele, registre cada
  bomba com `&dispose` e depois use `call` na citação. Com locals:
  `[ pump-a &dispose pump-b &dispose quot call ] with-destructors`.

## 4. Bombeamento arriscado

- Mesma forma da tarefa 3, mas com `|dispose` (somente em caso de falha) em uma
  única bomba.

## 5. Um disposable personalizado: a válvula

- `TUPLE: valve < disposable is-open ;`. O `<` estende `disposable`,
  então a maquinaria do framework é herdada.
- `<valve>` usa `new-disposable` (e não o `new` simples) para que a nova
  válvula seja registrada no framework.
- `M: valve dispose*` é o seu gancho de limpeza. Retornar nada na
  pilha faz diferença: `>>is-open` deixa a tupla no topo, então
  termine com `drop`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
