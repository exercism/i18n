# Referências e Snapshots

Quando você passa uma variável para uma função, o ownership dela geralmente é transferido, o que torna a variável original inutilizável. Isso pode ser um pouco incômodo quando você precisa acessar um estado mais de uma vez.
O Cairo tem dois recursos para passar um valor sem destruí-lo ou movê-lo, chamados `references` e `snapshots`.

## Snapshots

Snapshots oferecem uma visão imutável de um valor em um determinado momento, permitindo que você mantenha o ownership de uma variável enquanto acessa o estado dela.
Qualquer modificação na variável cria uma nova célula de memória e deixa a visão do snapshot inalterada.

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## Operador desnap

Para converter um snapshot de volta em uma variável comum, você pode usar o operador desnap `*`, que funciona como o oposto do operador `@`.
Só é possível aplicar o desnap em tipos que implementam o trait `Copy`.

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## Referências mutáveis

As referências mutáveis permitem passar valores mutáveis para uma função e tê-los retornados implicitamente, mantendo o ownership no contexto de chamada.
Isso pode ser feito com o modificador `ref`, desde que a variável seja declarada como mutável com a palavra-chave `mut`.

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
