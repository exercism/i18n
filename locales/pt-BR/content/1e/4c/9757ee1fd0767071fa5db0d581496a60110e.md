# About

O Swift oferece três construções de laço principais:

- **laços `while`**: Repetem um bloco de código enquanto uma condição especificada continuar `true`. A condição é avaliada antes de rodar o corpo do laço.
- **laços `repeat-while`**: Semelhantes aos laços `while`, mas a condição é avaliada depois de rodar o corpo do laço. Isso garante que o corpo seja executado pelo menos uma vez.
- **laços `for-in`**: Executam um bloco de código uma vez para cada elemento de uma sequência ou coleção (como um intervalo, array ou string).
