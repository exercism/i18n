# Introdução

R não tem um tipo [conjunto][wiki-set] separado; em vez disso, usa uma variedade de funções para realizar operações parecidas com vetores.

O operador [`%in%`][ref-match] testa a pertinência a um conjunto.
Esse operador infixo é sinônimo da função `is.element()`.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Entre as funções relevantes, estão:

- [`unique()`][ref-unique] para remover duplicatas.
- [`union()`][ref-sets] para combinar conjuntos (matematicamente, `A ∪ B`).
- [`intersect()`][ref-sets] para encontrar os elementos comuns aos dois conjuntos (`A ∩ B`).
- [`setdiff()`][ref-sets] para subtrair um conjunto de outro (`A - B`).
- [`setequal`][ref-sets] para testar a igualdade entre conjuntos, ignorando duplicatas e a ordem.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

Em cada caso, a função retorna uma cópia e deixa os argumentos inalterados.

## Tabelas hash

As operações com vetores descritas acima fazem parte do R base.
Elas são úteis para problemas pequenos, mas ficam lentas para conjuntos grandes.

Vários pacotes de terceiros implementam [tabelas hash][wiki-hash] para melhorar o desempenho em alguns contextos.

Por exemplo, o pacote [`hashtable`][ref-hashtable] traz implementações de `hashmap` e `hashset`, que escalam melhor.
Como a maioria dos pacotes externos, ele não está disponível no Exercism, mas vale a pena conhecê-lo para problemas do mundo real.
