`String` e `&str` são duas formas fundamentais de trabalhar com dados textuais em Rust.

`String` tem ownership, é um vetor de bytes `u8` e é mutável.
`&str` é uma referência emprestada a uma fatia de string e, portanto, imutável.

Você também pode criar e modificar `String`s usando um dos seus muitos métodos, como `push`.
```rust
let mut a_string = String::from("hello");
a_string.push('!');
```

Você também pode criar uma `String` convertendo um `&str`:
```rust
let a_string = "hello".to_string();
```
