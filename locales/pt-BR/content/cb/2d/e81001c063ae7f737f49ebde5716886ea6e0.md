# Anexo às instruções

## Implementando suas próprias operações de lista

Rust tem um rico sistema de iteradores, e usá-los para resolver este exercício é trivial.
Tente resolver o exercício sem recorrer a métodos de iterador como 
`map()`, `flatten()`, `filter()`, `count()`, `fold()`, `chain()`, `rev()` e similares.
Os métodos `next()` e `next_back()` não contam.

## Evitando alocações

Dá para resolver o exercício sem introduzir nenhuma alocação de memória adicional na solução.
Veja se você consegue criar o seu próprio tipo de iterador em vez de criar um iterador a partir de uma coleção.
