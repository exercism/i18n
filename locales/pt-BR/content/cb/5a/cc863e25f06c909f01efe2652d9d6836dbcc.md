# Instruções

Como entusiasta de xadrez, você quer escrever a sua própria versão do jogo.
Sim, talvez já existam muitas implementações de xadrez disponíveis online, mas a sua será única!

Você começa implementando um tabuleiro de xadrez.

A partida de xadrez será disputada em um tabuleiro de oito casas de largura por oito casas de comprimento.
As casas são identificadas por uma letra e um número.

## 1. Defina o intervalo de fileiras e colunas

O jogo terá que armazenar as fileiras do tabuleiro.
As fileiras são as linhas do tabuleiro e são numeradas de 1 a 8.

O jogo também terá que armazenar as colunas do tabuleiro.
Essas colunas são identificadas pelas letras de A a H.

Defina as constantes `ranks` e `files` que armazenam o intervalo de fileiras e colunas, respectivamente.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. Verifique se a casa é válida

O jogo terá que verificar se uma casa é válida.
Uma casa é válida se a fileira e a coluna estiverem dentro dos intervalos das fileiras e das colunas.

Defina o método `isValidSquare(rank:file:)` que recebe os argumentos `rank`, que contém um `Int` da fileira, e `file`, que contém uma `String` da coluna.
O método deve retornar `true` se a fileira e a coluna estiverem dentro do intervalo de fileiras e colunas, e `false` caso contrário.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. Obter a linha

O jogo armazenará todas as casas do tabuleiro em um array unidimensional.
As casas são formadas por uma string da fileira e da coluna, por exemplo, "1A", "8B", "4G", etc.
Para obter a linha de uma casa, o jogo terá que calcular o índice da primeira casa da linha.

Defina o método `getRow(rank:)` que recebe o argumento `rank`, que contém um `Int` da fileira.
O método deve retornar um array de strings que representam as casas da linha.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
