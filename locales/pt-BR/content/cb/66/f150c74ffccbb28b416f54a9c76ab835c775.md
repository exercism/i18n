# Instruções

Neste exercício, você vai criar algumas constantes para usar no funcionamento de um banco.

Você tem cinco tarefas:

## 1. Represente a taxa de juros fixa de um empréstimo

Crie a constante numérica sem tipo `FixedInterestRate` para armazenar o valor de 5% (5/100) e depois implemente a função `GetFixedInterestRate` para retorná-lo:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Represente o número de dias em um ano

Crie a constante `DaysPerYear` do tipo `int` para armazenar o valor 365 e depois implemente a função `GetDaysPerYear` para retorná-lo:

```go
GetDaysPerYear()
// => 365
```

## 3. Represente os meses do ano

Em um bloco, use o enumerador do Go para criar doze constantes numéricas sem tipo com os valores de 1 a 12 para os meses do ano.
Nomeie-as `Jan`, `Feb`, `Mar` etc. e depois implemente a função `GetMonth` para retornar o valor de um determinado mês:

```go
GetMonth(Jan)
// => 1
```

## 4. Represente um número de conta

Crie a constante de string sem tipo `AccountNo` para armazenar o valor XF348IJ e depois implemente a função `GetAccountNumber` para retorná-lo:

```go
GetAccountNumber()
// => "XF348IJ"
```
