# Luhn: usando uma trait personalizada

Antes de fazer este exercício, você provavelmente deveria fazer o exercício Luhn original e o seu sucessor, "Luhn: usando a trait From"

Para obter o exercício Luhn original, rode

```shell
exercism download --exercise=luhn --track=rust
```

Para obter o exercício "Luhn: usando a trait From", rode

```shell
exercism download --exercise=luhn-from --track=rust
```

No exercício Luhn original você só validava strings, mas o algoritmo de Luhn também pode ser aplicado a números inteiros.

Em "Luhn: usando a trait From" você implementou uma trait From, o que também exigiu que você criasse uma struct Luhn.

Em vez de criar uma struct só para fazer a validação, que tal validar os próprios tipos primitivos (ou seja, String, u8, etc.)?

Neste exercício, você vai criar e implementar uma [trait](https://doc.rust-lang.org/book/ch10-02-traits.html) personalizada que faz a validação.
