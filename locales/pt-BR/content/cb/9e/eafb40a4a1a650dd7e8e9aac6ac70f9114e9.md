# Instruções

Quem prestou atenção deve ter notado que o tipo `TreasureChest` do exercício anterior não era tão seguro assim!

Se você usou a função `get_treasure`, precisava fornecer a senha, mas ainda podia desestruturar o tipo `TreasureChest` para obter o tesouro sem precisar saber a senha.

Vamos corrigir isso usando um tipo opaco.

## 1. Defina o tipo opaco `TreasureChest`.

O `TreasureChest` contém dois campos:
- Uma senha, que é uma `String`.
- Um tesouro, que é um tipo genérico.

O tipo `TreasureChest` deve ser opaco.

## 2. Defina a função `create`.

Essa função recebe dois argumentos:
- Uma senha `String`.
- Um valor de tesouro de qualquer tipo.

A função retorna um `TreasureChest` contendo a senha e o valor.

Se a senha tiver menos de 8 caracteres, a função deve retornar um erro dizendo `Password must be at least 8 characters long`.

## 3. Defina a função `open`.

Essa função recebe dois argumentos:

- Um `TreasureChest`.
- Uma senha `String`.

Se a senha corresponder à senha do `TreasureChest`, a função deve retornar o tesouro; caso contrário, deve retornar um erro dizendo `Incorrect password`.
