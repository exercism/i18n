# use o operador de coalescência nula, não IsNullOrEmpty

Em vez de usar `string.IsNullOrEmpty` para determinar se o nome padrão deve ser usado, experimente o [operador de coalescência nula](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/null-coalescing-operator) para simplificar o código. Repare também na diferença de comportamento.
