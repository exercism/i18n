# Instruções

Neste exercício, você vai brincar com um carro de controle remoto, que você finalmente juntou dinheiro suficiente para comprar.

Os carros começam com a bateria cheia (100%). Cada vez que você dirige o carro com o controle remoto, ele percorre 20 metros e consome um por cento da bateria.

O carro de controle remoto tem um display de LED sofisticado que mostra duas informações:

- A distância total percorrida, exibida como: `"Driven <METERS> meters"`.
- A carga restante da bateria, exibida como: `"Battery at <PERCENTAGE>%"`.

Se a bateria estiver em 0%, você não pode mais dirigir o carro e o display da bateria vai mostrar `"Battery empty"`.

Você tem seis tarefas, e cada uma delas vai trabalhar com instâncias de carro de controle remoto.

## 1. Compre um carro de controle remoto novinho em folha

Implemente o método (_estático_) `JedliksToyCar.buy()` para retornar uma instância novinha em folha de carro de controle remoto:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Exiba a distância percorrida

Implemente o método `JedliksToyCar.distanceDisplay()` para retornar a distância como ela aparece no display de LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Exiba a porcentagem da bateria

Implemente o método `JedliksToyCar.batteryDisplay()` para retornar a porcentagem da bateria como ela aparece no display de LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Atualize o número de metros percorridos ao dirigir

Implemente o método `JedliksToyCar.drive()` que atualiza o número de metros percorridos:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Atualize a porcentagem da bateria ao dirigir

Atualize o método `JedliksToyCar.drive()` para atualizar a porcentagem da bateria:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Impeça que o carro ande quando a bateria acabar

Atualize o método `JedliksToyCar.drive()` para não aumentar a distância percorrida nem diminuir a porcentagem da bateria quando a bateria estiver descarregada (em 0%):

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
