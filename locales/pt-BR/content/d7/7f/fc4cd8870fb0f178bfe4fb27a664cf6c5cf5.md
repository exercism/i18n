# Introdução

Classes como `LocalDate` e `LocalDateTime` descrevem um _ponto_ no tempo.
O pacote `java.time` também tem duas classes que descrevem uma _quantidade_ de tempo:

- `java.time.Period` é uma quantidade de tempo em anos, meses e dias, como "2 meses e 5 dias".
- `java.time.Duration` é uma quantidade de tempo em horas, minutos, segundos, milissegundos e nanossegundos, como "1 hora e 30 minutos".

Um `Period` segue o calendário, então é usado com datas e com valores de data e hora.
Um `Duration` mede tempo exato, então é usado com horários e com valores de data e hora, mas não com datas.

```exercism/note
Assim como as outras classes de `java.time`, `Period` e `Duration` são imutáveis.
Métodos que parecem alterá-las retornam uma instância _nova_.
```

## `Period`

Um `Period` é criado com um dos seus métodos de fábrica estáticos:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

O resultado de `toString()` usa a [notação ISO-8601][iso-8601-durations]: `P` (de "period") seguido do número de anos (`Y`), meses (`M`) e dias (`D`).

Um período pode ser somado a uma data ou subtraído dela:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Como os meses têm durações diferentes, somar meses pode cair em um dia que não existe.
Nesse caso, o resultado é movido para o último dia válido do mês:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` retorna o período de uma data (incluída) até outra (não incluída):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## Contando unidades com `ChronoUnit`

Um `Period` mantém anos, meses e dias separados.
Por isso, `getDays()` retorna apenas a _parte_ de dias do período, e não o número total de dias.
Para contar o número total de uma única unidade entre duas datas, use o método `between()` de [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

O resultado é negativo quando a segunda data é anterior à primeira:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

Um `Duration` também é criado com métodos de fábrica estáticos:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

Na notação ISO-8601, o `T` separa a parte da data da parte da hora, e é por isso que as durações são escritas como `PT...`.

Uma duração pode ser somada a um valor de data e hora ou subtraída dele:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` retorna a quantidade exata de tempo entre dois valores de data e hora:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Uma duração pode ser convertida para uma única unidade com métodos como `toHours()`, `toMinutes()` e `toSeconds()`.
Eles retornam a quantidade _total_ naquela unidade, arredondada para baixo:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Para dividir uma duração em suas partes, como em um relógio, use os métodos `toXxxPart()`:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
