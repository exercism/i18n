# Instalação

Crystal está disponível no Linux, macOS e Windows.

Vale notar que o suporte do Crystal ao Windows é experimental.
Isso significa que pode haver alguns casos extremos que não funcionam e que pode não ser ideal para casos de uso em produção.
No entanto, para o Exercism e para uso básico, o Windows nativo deve ser amplamente utilizável.

Se você procura uma experiência que não seja de preview para o desenvolvimento no Windows, recomenda-se usar o [WSL (Subsistema do Windows para Linux)][wsl].
É um recurso **gratuito** do Windows 10 (1903+) e 11 que permite ao desenvolvedor rodar um ambiente Linux sem precisar de uma máquina virtual.

Use um dos [guias de instalação][installation guides] para obter instruções sobre como instalar o Crystal.

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
