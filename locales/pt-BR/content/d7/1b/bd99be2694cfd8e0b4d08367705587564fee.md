# Instruções

Seu amigo Kojo é um grande fã de números.
Ele tem um pequeno site chamado 'fun-with-numbers'.
Kojo não é muito bom em programação, então pediu sua ajuda.

Você vai criar duas funções auxiliares para novos jogos de números no site do Kojo e uma terceira para validar uma entrada que o usuário pode digitar.

## 1. Calcule a soma dos números no caça-níqueis

Um dos jogos no site do Kojo parece um caça-níqueis que mostra dois grupos de roletas com dígitos.
Cada grupo de dígitos representa um número.
Para a mecânica do jogo, Kojo precisa saber a soma desses dois números.

Escreva uma função `twoSum` que aceita dois arrays como parâmetros.
Cada array consiste em um ou mais números entre 0 e 9.
A função deve interpretar cada array como um número e retornar a soma desses dois números.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Determine se um número é um palíndromo

Outro jogo no site é um pequeno quiz chamado "Lucky Numbers".
Um usuário pode digitar um número e então vê se o número pertence a alguma sequência ou padrão secreto.
A sequência ou o padrão dos "lucky numbers" muda a cada mês, e cada usuário tem apenas um número limitado de tentativas para adivinhar.

Os lucky numbers deste mês devem ser números que são palíndromos.
Números palindrômicos permanecem iguais quando os dígitos são invertidos.

Implemente a nova função `luckyNumber` que aceita um número como parâmetro.
A função deve retornar `true` se o número for um palíndromo e `false` caso contrário.
O número de entrada será sempre um inteiro positivo.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Gere uma mensagem de erro para entrada de usuário inválida

Em vários lugares do site, há campos de entrada onde os usuários podem digitar números e clicar em um botão para acionar alguma ação.
Kojo quer melhorar a experiência do usuário no site dele.
Ele quer mostrar uma mensagem de erro caso o usuário clique no botão, mas o campo contenha um valor de entrada inválido.

Aqui estão mais algumas informações sobre como o valor de um campo de entrada é fornecido.

- Se o usuário digitar algo em um campo, o valor associado será sempre uma string, mesmo que o usuário tenha digitado apenas números.
- Se o usuário digitar algo, mas apagar de novo, a variável será uma string vazia.
- Antes mesmo de o usuário começar a digitar, a variável pode ser `undefined` ou `null`.

Escreva uma função `errorMessage` que aceita a entrada do usuário como parâmetro.
Se o usuário não forneceu nenhuma entrada, `errorMessage` deve retornar `'Required field'`.
Se a entrada não representa um número diferente de zero (de acordo com as regras de conversão do JavaScript), `'Must be a number besides 0'` deve ser retornado.
Em todos os outros casos, você pode assumir que a entrada é válida, o valor de retorno deve ser uma string vazia.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
