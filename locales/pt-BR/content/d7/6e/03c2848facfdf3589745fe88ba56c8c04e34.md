# Anexo às instruções

## Dicas

Este é o primeiro exercício com testes que exigem que você lance uma [`Exception`][exception-docs].
Normalmente, uma `Exception` é lançada para indicar que um programa encontrou uma entrada ou um estado inesperado.

Os testes ao longo da trilha vão verificar que as exceções que você lança são:

1. instâncias de um tipo Java especificado;
2. (opcionalmente) inicializadas com uma mensagem especificada.

[exception-docs]: https://docs.oracle.com/javase/8/docs/api/java/lang/Exception.html
