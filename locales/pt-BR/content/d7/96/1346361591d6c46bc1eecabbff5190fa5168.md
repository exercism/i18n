# Introdução

## Exportando funções

Exportar funções foi abordado no primeiro conceito. Aqui vai uma revisão rápida.

Cada arquivo em Elm é um módulo e precisa conter uma instrução `module` antes de qualquer outro código.

Os nomes dos módulos precisam corresponder ao nome do arquivo; assim, o módulo `Calculator` precisa estar no arquivo Calculator.elm, e o módulo `Parser.Utils` precisa estar no arquivo Parser/Utils.elm.

Tudo que é definido dentro de um módulo tem escopo privado e não pode ser acessado de fora desse módulo, a menos que esteja listado em `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Importando funções de outros módulos

Acessar funções definidas em outros módulos é feito por meio de importações.
Todas as funções desse módulo que foram expostas por ele ficam acessíveis quando você importa esse módulo.
Mas a forma de acessá-las varia conforme o modo como o módulo é importado.

As importações qualificadas são o padrão, e acessar uma função dentro de um módulo assim (por exemplo, a função `map` no módulo `List`) é feito prefixando o nome do módulo (`List.map`).

As importações abertas permitem acessar diretamente as funções expostas desse módulo, sem prefixo. Elas são feitas com a palavra-chave `exposing`, como um espelho da usada nas exportações. Você pode expor todas as funções disponíveis (com `..`), ou apenas algumas específicas (por exemplo, `map`).

Você também pode importar tipos e seus construtores de outros módulos, o que será visto em um conceito posterior.

As importações qualificadas são preferidas por deixarem o código mais claro e evitarem conflitos de nomes.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Anotações de tipo

As anotações de tipo são definidas com `name : parameter types -> return type`, sendo que os tipos dos parâmetros também são separados por `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Parênteses podem ser usados para definir parâmetros de função (que são eles mesmos definidos com a mesma sintaxe, daí a necessidade de usar parênteses).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Números

Existem dois tipos de números disponíveis em Elm, definidos pelos tipos `Int` e `Float`.
`Int` corresponde ao conjunto dos números inteiros positivos e negativos.
`Float` corresponde ao conjunto dos números reais, limitado pela precisão do computador.
As operações definidas sobre números geralmente funcionam com um tipo ou com o outro, mas não misturando os dois.
Existem funções para converter entre os dois, como `toFloat`, que converte `Int` em `Float`, e `round`, `floor`, `ceiling` ou `truncate`, que convertem um `Float` em um `Int` com semânticas diferentes.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Operações com strings

Para descrever palavras e frases no código, Elm tem um tipo `String` nativo.
Os literais de string são escritos entre aspas duplas, como `"Hello World!"`.
Um operador de concatenação de strings `++` e um operador de igualdade `==` estão disponíveis por padrão.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

A maioria das outras funções de string está no módulo `String`, que precisa ser importado.

https://package.elm-lang.org/packages/elm/core/latest/String
