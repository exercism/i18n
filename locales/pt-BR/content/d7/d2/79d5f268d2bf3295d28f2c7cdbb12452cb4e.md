# Introdução

## Formatação de strings

Existem dois mecanismos principais para formatar strings em C#/.NET. O uso de `String.Format()` e a interpolação de strings.

### Formatação composta

`String.Format()` recebe uma string (chamada na documentação de _formato composto_) composta por texto fixo e espaços reservados (conhecidos na documentação como itens de formato), além de um número variável de argumentos. O valor de retorno resolve cada item de formato usando o argumento correspondente e combina os valores resolvidos com o texto fixo.

```csharp
string.Format("I had {0} bitcoins on {1}, the day I forgot my password.", 55.5, new DateTime(2010, 2, 25));
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

Esse mecanismo é tecnicamente conhecido como _formatação composta_.

### Interpolação de strings

Strings interpoladas são prefixadas com um `$` e incluem expressões de tempo de execução entre chaves. O item de formato tem a seguinte sintaxe: `$"{<interpolationExpression>}"`. Elas dispensam a necessidade de uma lista separada de argumentos. O resultado é funcionalmente equivalente ao mecanismo `String.Format()`.

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf} bitcoins on {thatDay}, the day I forgot my password."
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

### Itens de formato

O texto entre chaves, espaços reservados no caso do formato composto e expressões interpoladas no caso da interpolação de strings, é conhecido como _item de formato_.

Um item de formato pode ser composto por até 3 partes. A primeira é a expressão obrigatória ou o espaço reservado de argumento, como visto no código de exemplo acima. Além disso, há um alinhamento opcional (introduzido por uma vírgula, ",") e uma _string de formato_ opcional (introduzida por dois-pontos, ":").

`{<interpolationExpression>[,<alignment>][:<formatString>]}`

O _alinhamento_ especifica o comprimento do "campo" no qual o texto é colocado, preenchido à esquerda com espaços se o alinhamento for positivo ou à direita se for negativo.

A _string de formato_ especifica a forma da saída de texto, como se separadores de milhar devem ser incluídos em um número ou se apenas a parte de data de um objeto `DateTime` deve ser gerada.

O código a seguir ilustra a exibição da parte de data de um objeto `DateTime` e de um número de ponto flutuante em forma exponencial.

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf:E} bitcoins on {thatDay:d}, the day I forgot my password."
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings

string.Format(
    "I had {0:E} bitcoins on {1:d}, the day I forgot my password.",
    loadsOf, thatDay)
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings
```

Há formatação padrão e personalizada tanto para números quanto para datas. Não há diferença vital entre _personalizada_ e _padrão_, exceto que você tem a chance de compor strings de formato personalizadas a partir de letras de formato.

### Cultura

Cada thread tem uma cultura padrão `Thread.CurrentThread.CurrentCulture` encapsulada em uma instância de `CultureInfo`. A cultura da thread determina como datas e números são formatados em relação a variações regionais, como a diferença no formato de data convencional entre o Reino Unido _DD/MM/YYYY_ e os EUA _MM/DD/YYYY_.

`CultureInfo` implementa a interface `IFormatProvider`, que pode ser passada para certas sobrecargas de `String.Format()`. Isso pode ser usado para substituir a cultura da thread.

## Strings verbatim

Strings verbatim permitem strings com várias linhas. Elas são introduzidas com um @.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```
