# Testes

## Rodando os testes

Para rodar os testes, execute o seguinte comando:

```bash
make
```

## Resolvendo o exercício

Resolver um exercício significa fazer com que todos os seus testes passem. Por padrão, apenas um teste (o primeiro) é executado quando você roda os testes. Isso é intencional, pois permite que você foque apenas em fazer esse único teste passar. Assim que ele passar, você pode habilitar o próximo teste removendo a linha `TEST_IGNORE()`. Quando todos os testes estiverem habilitados e sua implementação fizer todos eles passarem, você terá resolvido o exercício!
