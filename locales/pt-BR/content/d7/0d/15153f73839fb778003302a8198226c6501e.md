# Instalando o Python

Se o Python ainda não estiver disponível no seu sistema, você encontra instruções detalhadas por plataforma na seção [Python Setup and Usage][using python] da documentação oficial.
O Real Python também oferece um [guia bem legal][helpful guide] para instalação em várias plataformas, incluindo iOS e Android.

Por fim, estes posts do Brett Cannon, [A quick-and-dirty guide][quick-and-dirty] e [Why you should use `python -m pip`][python-m-pip], trazem dicas muito úteis sobre como gerenciar instalações e pacotes do Python.

**Nota para quem usa MacOS:**  antes do MacOS Monterey (12.3), o `Python 2.7` já vinha pré-instalado com o sistema operacional.
Usar o `Python 2.7` com o Exercism ou com a maioria dos outros programas não é suportado.
Em vez disso, instale o [Python 3][Python-three downloads] usando um dos métodos detalhados abaixo.
A partir do MacOS Monterey (12.3), nenhuma versão do Python vem pré-instalada no MacOS.

Alguns links rápidos para a documentação, por sistema operacional:

-  [Windows][windows] Além disso, este artigo da Microsoft sobre [instalar o Python no Windows][python-on-windows] é útil.
-  [Sistemas Unix e Linux][unix-and-linux] (_a maioria também funciona no MacOS_)
-  [MacOS][macos]

   Também recomendamos dar uma olhada em alguns dos métodos descritos no artigo do Real Python [Installing Python][installing-python] ou nos artigos do Brett Cannon linkados acima.


Os testes e as ferramentas do Exercism atualmente dão suporte a `3.10` - `3.13.5` (_testes_) e ao [`Python 3.13.5`][313-new-features] (_ferramentas_).
Exceções a esse suporte são anotadas onde ocorrem.
A maioria dos exercícios funcionará com `Python 3.6+`, ou até com versões anteriores.
Mas não garantimos suporte para versões que não estejam listadas em [Active Python Releases][active-python-releases].


Consulte a [documentação do Python 3.13.x][3.13 docs] para saber o que é atualmente suportado.
