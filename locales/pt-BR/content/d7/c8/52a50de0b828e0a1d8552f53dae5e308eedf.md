# Instruções

Sarah está trabalhando em um novo jogo de RPG e precisa da sua ajuda com
a mecânica do jogador.

## 1. Defina a tupla `player`

Defina uma classe tupla `player` com quatro slots e valores padrão:

| `slot`   | `default` |
| -------- | --------- |
| `name`   | `f`       |
| `level`  | `0`       |
| `health` | `100`     |
| `mana`   | `f`       |

Depois de definida, você pode criar um jogador como um literal:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. Apresente o jogador

Defina `introduce` para retornar o nome do jogador. Jogadores furtivos
escondem o nome (`name` é `f`) e devem ser apresentados como
`"Mighty Magician"`.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. Reviva um jogador caído

Defina `revive` para retornar um jogador *novo* com `health` definido como 100
e `mana` definido como 100, mas apenas se o `health` do jogador for `0`. Se
o jogador ainda estiver vivo, retorne `f`.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. Receba dano

Defina `take-damage` para retornar um jogador *novo* cujo `health` foi
reduzido pela quantidade informada, nunca ficando abaixo de `0`.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
