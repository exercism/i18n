# Apêndice às instruções

## Memória reservada

Os bytes 1024-1279 da memória linear são reservados para a string de entrada.

A string de entrada pode ser modificada no próprio local, se você quiser.

## Formato de entrada

Os códons são entregues concatenados, sem preenchimento, como uma string.

## Formato de saída

Produza a sequência de proteínas como uma string terminada em null, com um caractere de nova linha depois de cada proteína.

Um exemplo de saída seria `"Methionine\nPhenylalanine\nSerine\n"`

Se a entrada for inválida, produza uma string vazia.
