# Sobre

O Elixir representa os valores true e false com o tipo Boolean. Existem apenas dois valores: `true` e `false`. Esses valores podem ser combinados com operadores Boolean ([`and/2`][strict-and], [`or/2`][strict-or], [`not/1`][strict-not]):

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Os operadores [`and/2`][strict-and], [`or/2`][strict-or] e [`not/1`][strict-not] são estritamente Boolean, ou seja, exigem que o _primeiro_ argumento seja Boolean. Existem também operadores Boolean equivalentes que funcionam com qualquer tipo de argumento: [`&&/2`][and], [`||/2`][or] e [`!/1`][not].

Os operadores Boolean usam _avaliação de curto-circuito_, o que significa que a expressão do lado direito do operador só é avaliada se for necessário.

Cada um dos operadores tem uma precedência diferente, e `not/1` é avaliado antes de `and/2` e `or/2`. É possível usar parênteses para avaliar uma parte da expressão antes das outras:

```elixir
not true and false
# => false

not (true and false)
# => true
```

Ao escrever uma função que retorna um valor Boolean, é [idiomático terminar o nome da função][naming] com um `?`. A mesma convenção pode ser usada para variáveis que armazenam valores Boolean.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
