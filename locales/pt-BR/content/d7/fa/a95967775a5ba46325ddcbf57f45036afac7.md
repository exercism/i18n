# Introdução

As conversões de tipo em Cairo permitem transformar dados de um tipo em outro, o que possibilita uma manipulação de dados flexível e segura.

## Noções básicas

Cairo oferece vários mecanismos para conversão de tipos:

### Conversão direta

Para tipos numéricos compatíveis, você pode usar a conversão direta:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### O trait `Into`

O trait `Into` permite a conversão de um tipo para outro:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### O trait `TryInto`

Para conversões que podem falhar, use `TryInto`, que retorna um `Option`:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## Conversões de tipos personalizadas

Você pode implementar `Into` para os seus próprios tipos:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## Considerações de segurança

- Use `TryInto` quando a conversão puder falhar (por exemplo, de tipos grandes para tipos pequenos)
- Use `Into` quando a conversão sempre der certo
- Sempre trate os casos `Option::None` vindos de `TryInto`
- Considere overflow e underflow ao converter entre tipos com sinal e sem sinal
