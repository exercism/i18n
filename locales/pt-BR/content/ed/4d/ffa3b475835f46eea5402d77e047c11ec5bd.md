# Instruções

Seu grupo de strings vai fazer um recital, e alguém precisa escrever o
programa.

As cinco tarefas ficam na classe `PROGRAMME_NOTES`.

## 1. Nomeie a peça e quem a escreveu

Coloque a peça primeiro, depois ` by `, e depois o compositor.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. Meça uma linha

A gráfica precisa saber o comprimento de uma linha.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. As primeiras letras

Dado um título e um número, retorne essa quantidade de letras do começo.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. As últimas letras

O mesmo, contando a partir do fim.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. Encurte um título longo

Os títulos que não couberem são cortados nas suas seis primeiras letras,
seguidas de três pontos.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
