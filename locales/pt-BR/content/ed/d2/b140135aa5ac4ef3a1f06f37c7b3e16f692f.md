# Sobre

Um [condicional switch][switch] permite comparar um valor com vários valores possíveis de correspondência.
Ele permite escrever um código mais conciso do que usar vários condicionais `else-if`.
Um condicional switch começa com a palavra-chave `switch`, seguida do valor a ser comparado.
Depois, você define os casos com a palavra-chave `case`, seguida do valor com o qual eles serão comparados.
A palavra-chave `default` define o caso padrão, usado quando nenhum dos casos corresponde.
Assim como as condicionais `else-if`, as condicionais `switch` executam apenas o bloco de código associado ao primeiro caso que corresponder.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considere o seguinte exemplo:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Isso poderia, em vez disso, ser escrito assim:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
