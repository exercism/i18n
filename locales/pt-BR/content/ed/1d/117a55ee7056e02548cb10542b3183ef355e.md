# Introdução

Em Elixir, as funções são tratadas como cidadãs de primeira classe. Isso significa que:

- Funções nomeadas e anônimas podem ser atribuídas a variáveis.
- Funções nomeadas e anônimas podem ser passadas por aí como dados, na forma de argumentos e valores de retorno.
- Funções anônimas podem ser criadas dinamicamente.

As funções anônimas, ao contrário das funções nomeadas, não têm uma referência estática à disposição: elas só existem se forem atribuídas a uma variável ou invocadas imediatamente.

Podemos usar funções anônimas para:

- Esconder dados usando escopo lexical (também conhecido como closure).
- Criar funções dinamicamente em tempo de execução.

As funções anônimas começam com a palavra reservada `fn`, os argumentos são separados do corpo da função pelo token `->`, e elas terminam com um `end`. Assim como acontece com as funções nomeadas, a última expressão da função é _retornada implicitamente_ para a função que a chamou.

Para invocar uma referência de função, você precisa usar um `.` entre a variável de referência e a lista de argumentos:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Você pode até usar a notação de captura abreviada para deixar isso mais conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
