# Instruções

Neste exercício você vai escrever um TreasureChest genérico (e mágico!), para guardar algum tesouro.

## 1. Defina o tipo TreasureChest

Defina um tipo paramétrico `TreasureChest{T}` com dois campos.

- Um campo `password` do tipo `String`, que será usado para armazenar a senha do baú do tesouro.
- Um campo `treasure` do tipo `T`, que será usado para armazenar o tesouro.
Esse valor é genérico, então o tesouro pode ser qualquer coisa.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. Defina a função get_treasure()

Essa função deve receber dois argumentos.

- Uma `String` (para tentar uma senha)
- Um tipo `TreasureChest`

A função deve comparar a tentativa de senha fornecida com o `password` do `TreasureChest`.

- Se as senhas coincidirem, retorne o tesouro.
- Se as senhas não coincidirem, retorne `nothing`.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. Defina a função multiply_treasure()

Essa função deve receber dois argumentos.

- Um multiplicador inteiro `n`.
- Um tipo `TreasureChest{T}`.

A função deve retornar um novo `TreasureChest{Vector{T}}`, com 
- A mesma senha do original
- O tesouro multiplicado como um `Vector{T}` de comprimento `n`, e o tesouro original repetido `n` vezes.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
