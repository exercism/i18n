# sugerir remover o extern crate

Considere remover o `extern crate`, pois [não é mais necessário](https://doc.rust-lang.org/stable/edition-guide/rust-2018/module-system/path-clarity.html#no-more-extern-crate) na edição 2018 do Rust, que é a edição que os exercícios da trilha de Rust estão configurados para usar.
