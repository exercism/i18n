# Introdução

Todo o código Common Lisp é feito de S-Expressions (expressões simbólicas). São chamadas de sexprs, para abreviar. Toda sexpr é um átomo ou um cons. Quando S-Expressions são avaliadas, elas retornam automaticamente algum valor que toma o lugar da expressão. Ao escrever suas próprias funções (usando `defun`), o último valor dentro do corpo do `defun` é retornado automaticamente:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
