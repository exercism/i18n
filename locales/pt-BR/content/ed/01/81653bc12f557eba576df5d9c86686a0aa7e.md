# Instruções

Você está demarcando uma trilha de caminhada pelo mato. Tanto as distâncias quanto os
avistamentos vêm em forma de sequências, então ambos são iteradores.

Os quatro vão na classe `BUSH_WALK`. Todos eles são iteradores, então todo nome
termina com `!`.

## 1. Os marcadores

`markers!` recebe um espaçamento em metros e uma quantidade, e fornece a distância de
cada marcador a partir do início.

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

Uma quantidade de zero não fornece nada.

## 2. Até o fim da trilha

`until_end!` recebe os avistamentos ao longo da trilha e os fornece um de cada vez,
parando quando encontra `"end"`. O próprio `"end"` não é fornecido.

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

Se não houver um `"end"`, fornece tudo.

## 3. Só as aves

`birds!` recebe os avistamentos e fornece apenas os que começam com letra maiúscula,
que é como este levantamento registra as aves.

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. Numerados

`numbered!` recebe os avistamentos e fornece cada um com a posição na frente,
contando a partir de um.

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
