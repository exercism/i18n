# Sobre

[Clojure](http://clojure.org) é uma linguagem de programação dinâmica destinada à Máquina Virtual Java (JVM).
Projetado como uma linguagem de propósito geral, o Clojure combina a acessibilidade de uma linguagem de script com uma infraestrutura robusta para programação com múltiplas threads.

O Clojure é predominantemente uma linguagem de programação funcional e traz um rico conjunto de [estruturas de dados](http://clojure.org/data_structures) imutáveis e persistentes.

O Clojure é de código aberto, e há informações sobre como contribuir com a linguagem [aqui](http://clojure.org/contributing).

Rich Hickey, o criador do Clojure, queria uma Lisp moderna para programação funcional, simbiótica com a já estabelecida plataforma Java e projetada para concorrência. Foi assim que o Clojure nasceu.

Aqui estão duas citações que exemplificam os objetivos do Clojure:

* _Um bom design não se trata de fazer grandes planos, e sim de desmontar as coisas._
* _Programar não é sobre digitar... é sobre pensar._
