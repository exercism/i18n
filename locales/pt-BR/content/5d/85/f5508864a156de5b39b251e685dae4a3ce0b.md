# Introdução

Um parâmetro de método pode se tornar opcional quando você atribui a ele um valor padrão. Ao chamar um método com parâmetros opcionais, não é obrigatório passar um valor para eles. Se nenhum valor for passado para um parâmetro opcional, o valor padrão dele será usado.

Parâmetros opcionais _precisam_ ficar no final da lista de parâmetros; eles não podem ser seguidos por parâmetros não opcionais.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
