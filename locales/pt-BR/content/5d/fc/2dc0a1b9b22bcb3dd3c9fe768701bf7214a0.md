# Aprendizado

- [A documentação oficial](https://idris2.readthedocs.io/en/latest/)

Este tutorial é uma breve introdução à linguagem e é voltado para quem já conhece uma linguagem funcional como Haskell ou OCaml. Em particular, pressupõe-se certa familiaridade com a sintaxe de Haskell, embora a maioria dos conceitos seja explicada, ainda que brevemente. Também se espera que você tenha algum interesse em usar tipos dependentes para escrever e verificar software de sistemas.
