# Introdução

O Ruby é uma [linguagem orientada a objetos][object-oriented-programming] dinâmica.
Tudo no Ruby é um [objeto][object].

Existem duas formas principais de atribuir objetos a nomes no Ruby: usando variáveis ou constantes.
As variáveis são sempre escritas em [snake case][snake-case].
Uma variável pode referenciar objetos diferentes ao longo de sua existência.
Por exemplo, `my_first_variable` pode ser definida e redefinida várias vezes usando o operador `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

As constantes, porém, devem ser atribuídas uma única vez.
Elas precisam começar com uma letra maiúscula e, normalmente, são escritas totalmente em maiúsculas, com as palavras separadas por underscores.

Por exemplo:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

O Ruby é organizado em classes.
As classes são definidas usando a palavra-chave `class`, seguida do nome da classe.
Os objetos geralmente são criados instanciando classes com o método `.new`.

Por exemplo:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

As unidades de funcionalidade são encapsuladas em métodos, semelhantes às _funções_ de outras linguagens.
Um método pode, opcionalmente, ser definido com argumentos posicionais e/ou argumentos nomeados, que são definidos e chamados usando a sintaxe `:`.
Os métodos retornam implicitamente o resultado da última instrução avaliada ou podem retornar explicitamente um objeto por meio da palavra-chave `return`.
Os métodos são invocados usando a sintaxe `.`.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
