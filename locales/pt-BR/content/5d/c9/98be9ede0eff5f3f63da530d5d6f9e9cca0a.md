# Aprendizado

O Tcl foi projetado com o objetivo de ser muito simples, mas poderoso.
Por isso, aprender [a sintaxe básica do Tcl][syntax] é bem fácil.

Para um tutorial prático, veja [Learn X in Y minutes: Tcl][X-in-Y].

Para um tutorial mais completo, em várias partes:
 - [The Tcl tutorial][tutorial] cobre o Tcl versão 8.5 (a versão estável atual é a 9.0)
 - O suporte a programação orientada a objetos foi adicionado ao núcleo do Tcl na versão 8.6.
   O Magicsplat tem um [tutorial de OO][oo-tutorial] completo que cobre isso.
