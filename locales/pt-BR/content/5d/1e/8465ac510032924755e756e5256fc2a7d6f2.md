# Introdução

Os conceitos de covariância e contravariância em PHP são importantes, já que o PHP exige que essas regras sejam seguidas ao estender classes ou interfaces.

A covariância preserva a relação entre dois tipos, enquanto a contravariância inverte essa relação. Em resumo, isso significa que, ao estender classes e sobrescrever funções, você pode permitir tipos mais ou menos específicos nos parâmetros do seu método, e pode retornar tipos menos ou mais específicos a partir do método.

## Exemplos

Considere a seguinte classe:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

Se estendermos a classe, podemos permitir mais tipos de parâmetros do que os declarados originalmente, mas não podemos retornar nada além dos tipos de retorno originais.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

A classe estendida a seguir não é válida, porque não é permitido retornar tipos adicionais ou mais amplos:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
