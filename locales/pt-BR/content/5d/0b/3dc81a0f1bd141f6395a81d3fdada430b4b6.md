# Dicas

## Geral

- A classe `string` tem muitos [métodos nativos][methods] úteis.

## 1. Obter a mensagem de uma linha de log

- Existem [vários métodos][index-of] para encontrar o índice em que um texto aparece em uma `string`.
- Remover espaços em branco é um recurso [nativo][trim].

## 2. Obter o nível de log de uma linha de log

- Uma `string` pode ser convertida para minúsculas usando um [método nativo][to-lower].

## 3. Reformatar uma linha de log

- Existe um [operador nativo][plus-operator] para concatenar strings.
