# Introdução

A sintaxe de desestruturação de array do JavaScript é uma forma concisa de extrair valores de um array e atribuí-los a variáveis distintas.

Neste exemplo, cada valor do array `numberOfMoons` é atribuído ao seu planeta correspondente:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```
