# Testes

## Clojure CLI

Os exercícios de Clojure no Exercism vêm com um arquivo `deps.edn` com um alias `:test` para invocar o [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

Isso vai procurar no diretório `test` do seu projeto todos os testes definidos com `clojure.test` e executá-los.

## Leiningen

Para executar os testes de um exercício com o Leiningen, basta chamar:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
