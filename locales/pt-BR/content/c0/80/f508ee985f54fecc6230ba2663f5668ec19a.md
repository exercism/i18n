# Dicas

## Geral

- Dê uma olhada na [documentação do `elm/parser`][elm-parser]
- A introdução apresenta todos os conceitos necessários para resolver o exercício

## 1. Fazer o parsing do preço da pizza

- O [parser `int`][int] é dedicado a fazer o parsing de números inteiros
- Mais de um parser consegue lidar com €, mas o [`symbol`][symbol] é o mais adequado
- O [operador `(|.)`][(|.)] consegue fazer o parsing de duas coisas, mas mantém apenas uma

## 2. Fazer o parsing do indicador vegetariano

- O [parser `oneOf`][oneOf] consegue tentar possibilidades diferentes
- Há mais de uma forma de fazer o parsing de uma string específica; neste caso, [`keyword`][keyword] ou [`symbol`][symbol] são adequados
- Há mais de uma forma de retornar `True` quando um parser tem sucesso; uma boa é usar o [`succeed`][succeed]

## 3. Fazer o parsing dos nomes de pizzas e ingredientes

- O [parser `chompWhile`][chompWhile] é dedicado a fazer o parsing de caracteres arbitrários
- A [função `isAlpha`][isAlpha] consegue validar caracteres ASCII maiúsculos e minúsculos
- A [função `map`][map] pode ser usada para modificar o conteúdo de um parser
- A [função `String.toLower`][toLower] consegue deixar uma string em minúsculas

## 4. Fazer o parsing de uma lista de ingredientes

- O [parser `sequence`][sequence] é dedicado a fazer o parsing de listas de itens
- Use todas as funções adequadas que você definiu até agora

## 5. Fazer o parsing de uma pizza completa

- Com o [operador `(|=)`][(|=)], é bem simples manter mais de uma coisa em um pipeline
- Use `Pizza` como construtor de tipo com o [`succeed`][succeed]
- Mais de um parser consegue lidar com ":" e "-", mas o [`symbol`][symbol] é o mais adequado
- O [parser `spaces`][spaces] é útil para se livrar de espaços extras
- Use todas as funções adequadas que você definiu até agora

## 6. Fazer o parsing do menu completo

- O [parser `sequence`][sequence] é dedicado a fazer o parsing de listas de itens
- Lembre-se de que o `spaces` também consome caracteres de nova linha, e isso pode interferir no seu separador
- O [parser `end`][end] é dedicado a verificar se você chegou ao fim de uma string
- O [operador `(|.)`][(|.)] consegue fazer o parsing de duas coisas, mas mantém apenas uma
- Use todas as funções adequadas que você definiu até agora

## 7. Fazer o parsing de nomes de ingredientes com várias palavras

- O [parser `chompWhile`][chompWhile] é dedicado a fazer o parsing de caracteres arbitrários
- A [função `isAlpha`][isAlpha] consegue validar caracteres ASCII maiúsculos e minúsculos
- A [função `andThen`][andThen] pode ser usada para inspecionar o conteúdo de um parser
- A [função `problem`][problem] retorna um parser que chegou a um beco sem saída
- A [função `String.toLower`][toLower] consegue deixar uma string em minúsculas
- A [função `String.trim`][trim] consegue se livrar de espaços em branco nas extremidades de uma string
