# Dicas

## Geral

- [Tuplas][tuple] são estruturas de dados imutáveis, têm tamanho fixo e podem conter qualquer tipo de dado.
- Símbolos podem ser usados para denotar estados finitos: este exercício usa `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter` para denotar as unidades usadas.

## 1. Obtenha o componente numérico de um par de volume

- Considere indexar a tupla para retornar o componente numérico do par de volume.

## 2. Converta o par de volume para mililitros

- Use a lógica de controle de fluxo para determinar qual lógica aplicar, com base na unidade.
- Implemente o método de todas as unidades para mililitros, incluindo de mililitros para mililitros.

## 3. Converta o par de volume em mililitros para outra unidade

- Use a lógica de controle de fluxo para determinar qual lógica aplicar, com base na unidade.
- Implemente o método de mililitros para todas as unidades, incluindo de mililitros para mililitros.

## 4. Converta de qualquer unidade para qualquer unidade

- Reutilize os métodos já criados para fazer a conversão no método `KitchenCalculator.convert`.
