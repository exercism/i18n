# Introdução

Um arquivo é só um fluxo com um nome no disco. O vocabulário [`io.files`][io.files] dá a você duas formas de trabalhar com ele: palavras de conveniência para o arquivo inteiro, que leem ou escrevem tudo em uma única chamada, e abridores de fluxo para quando você quer ler ou escrever de forma incremental.

Toda palavra que mexe com um arquivo recebe uma **codificação**, o esquema que transforma bytes em caracteres e vice-versa. Para texto, quase sempre é [`utf8`][utf8], de `io.encodings.utf8`.

## Lendo um arquivo inteiro

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` retorna o arquivo inteiro como uma única string; `file-lines` retorna um array com as linhas do arquivo, sem as quebras de linha.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Escrevendo um arquivo inteiro

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

As duas **substituem** o conteúdo do arquivo (criando-o se necessário). `set-file-contents` escreve uma string exatamente como está; `set-file-lines` escreve cada elemento de uma sequência em sua própria linha, adicionando as quebras de linha para você.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## Acrescentando a um arquivo

Para adicionar conteúdo a um arquivo sem apagar o que já está lá, abra-o com um combinador `with-…` e escreva no fluxo ambiente dentro da quotation:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Como todo combinador `with-…`, esses são escopos de destruição: o handle do arquivo é fechado quando a quotation termina, mesmo que ela lance um erro.
