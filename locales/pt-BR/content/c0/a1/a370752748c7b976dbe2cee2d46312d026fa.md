# Sobre

Ceylon é uma linguagem de programação de propósito geral, com uma sintaxe parecida com a de Java e C#. Ela é imperativa, estaticamente tipada, estruturada em blocos, orientada a objetos e de ordem superior. Quando dizemos que ela é _estaticamente tipada_, queremos dizer que o compilador faz uma verificação de tipos bastante ampla, com a ajuda das anotações de tipo que aparecem no código. Quando dizemos que ela é _orientada a objetos_, queremos dizer que a linguagem dá suporte a tipos definidos pelo usuário e conta com um sistema de tipos nominativo, no qual um tipo é um conjunto de atributos e operações nomeados, além de dar suporte a herança e polimorfismo de subtipos. Quando dizemos que ela é _de ordem superior_, queremos dizer que todo elemento do programa que pode ser referenciado (todo atributo, toda operação e todo tipo) também é um valor. Quando dizemos que ela é _estruturada em blocos_, queremos dizer que a linguagem tem escopo léxico e uma sintaxe recursiva extremamente regular para declarações e instruções.

Ceylon aprimora a linguagem e o sistema de tipos de Java para reduzir a verbosidade e aumentar a segurança de tipos em comparação com Java e C#. Ceylon incentiva um estilo de programação mais funcional e um pouco menos imperativo, o que resulta em código mais fácil de entender e de refatorar.
