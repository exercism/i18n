# Apêndice das instruções

## Tratamento de erros

Para este exercício você deve adicionar um conjunto de erros `ComputationError` que contém o erro `IllegalArgument`.
Lembre-se de torná-lo público!
A função `steps` deve retornar `ComputationError.IllegalArgument` quando a entrada dela for igual a zero.

Exercícios mais adiante geralmente vão omitir instruções explícitas como esta.
Em geral, o Exercism espera que você leia o arquivo de testes ao implementar sua solução.
