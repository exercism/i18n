# Instruções

O trabalho no projeto do carro de controle remoto continua. A largura de banda no sistema de telemetria é preciosa, e pediram que você implemente um protocolo de mensagens para comunicar os dados de telemetria.

Os dados são transmitidos em um buffer (array de bytes). Quando inteiros são enviados, o tamanho do buffer é reduzido com o protocolo descrito abaixo.

Cada valor deve ser representado no menor tipo inteiro possível (os tipos `byte` e `sbyte` não estão incluídos, pois a economia seria trivial):

| De                         | Até                       | Tipo     |
| -------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

O valor deve ser convertido para o número apropriado de bytes do tipo atribuído a ele. O buffer completo é composto por um byte que indica a quantidade de bytes adicionais no buffer (_byte de prefixo_) seguido pelos bytes que contêm o inteiro (_bytes de payload_).

Alguns dos tipos usam um número idêntico de bytes (por exemplo, os tipos `uint` e `int`). Normalmente, eles teriam o mesmo _byte de prefixo_, mas isso tornaria a decodificação problemática. Para contornar isso, o protocolo introduz um pequeno truque: para tipos com sinal, o valor do _byte de prefixo_ é `256` menos o número de bytes adicionais no buffer.

Apenas o byte de prefixo e o número de bytes seguintes indicados pelo prefixo serão enviados na comunicação. Internamente, um buffer de 9 bytes é usado (com zeros à direita, conforme necessário) tanto pelas rotinas de envio quanto pelas de recebimento.

## 1. Codifique um valor inteiro pronto para enviar

Implemente o método estático `TelemetryBuffer.ToBuffer()` para codificar um buffer a partir do parâmetro passado para o método.

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. Decodifique um buffer recebido

Implemente o método estático `TelemetryBuffer.FromBuffer()` para decodificar o buffer recebido e retornar o valor na forma de um `long`.

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

Se o byte de prefixo tiver um valor inesperado, `0` deve ser retornado.
