# Introdução

Cairo fornece dicionários como parte de suas bibliotecas principais, representados pelo tipo `Felt252Dict<T>`.

O tipo da chave de um dicionário em Cairo é restrito a `felt252`, o que é diferente de outras linguagens, nas quais é possível definir o tipo da chave.

Para criar um dicionário, você pode usar o método `default` do trait `Default`, assim:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

As operações básicas mais usadas são:

1. `insert(felt252, T) -> ()` para escrever valores em uma instância de dicionário e
2. `get(felt252) -> T` para ler valores dela.

E veja como você usaria essas operações:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

Se você tentar recuperar o valor de uma chave que não existe no dicionário, ele vai retornar o valor zero do tipo de valor.

Isso pode confundir você, principalmente se o valor padrão do seu tipo de valor (por exemplo, 0 para um número inteiro) for um valor válido.

Isso também significa que não há como excluir dados de um dicionário.

Algo a se levar em conta ao incorporar essa estrutura no seu código.
