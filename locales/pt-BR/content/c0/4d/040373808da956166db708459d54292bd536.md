# Introdução

Além da condicional `if`, também existe a instrução `switch` para executar lógica de forma condicional. Ela é usada quando é preciso comparar uma única variável com vários valores possíveis. Para uma variável x qualquer, a instrução switch em Haxe tem a seguinte sintaxe.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

O caso `default` é executado quando nenhum outro caso corresponde.
