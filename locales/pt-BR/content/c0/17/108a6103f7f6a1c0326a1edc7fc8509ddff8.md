# Dicas

## Geral

- Este desafio é sobre criar uma [_pilha_][Baeldung: The Stack Data Structure] usando uma [lista encadeada simples][singly linked list].
- Diferente de pilhas construídas com `lists`, `collections.deque` ou `queue.LifoQueue`, pedimos que você crie [`classes`][classes tutorial] `Node` e `LinkedList` personalizadas para armazenar e encadear elementos.

Um círculo com borda tracejada chamado New_Node está bem à esquerda, com duas linhas de seta pontilhadas apontando para a direita. New_Node mostra "(becomes head) - New_Node - next = node_6". A linha de seta pontilhada de cima está rotulada como "push" e aponta para Node_6, acima e à direita. Node_6 mostra "(current) head - Node_6 - next = node_5". Node_1 tem uma seta pontilhada apontando para a direita, em direção a um nó que diz "None".](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- [Real Python: Linked Lists][Real Python Linked Lists], [Towards Data Science: Demystifying the Linked List][towards data science demystifying the linked list] e [ADS Stack in Python][Koder Dojo Coding an ADS Stack in Python] podem ajudar a revisar os detalhes de implementação.
- Sua `LinkedList` deve aceitar um argumento `list` em seu _construtor_, mas não deve usar uma `list` para armazenar nós ou elementos.
- `len()` é uma função embutida para a maioria dos objetos Python.
Para que _objetos personalizados_ suportem `len()`, é preciso definir o método especial [`__len__`][__len__].
- Em Python, a iteração é suportada para a maioria dos objetos do tipo sequência, contêiner ou coleção.
Para que um objeto _personalizado_ suporte repetição ou reordenação, é preciso definir o método especial `__iter__`.
[Implementar um iterador para uma classe][implementing iterators] pode ajudar a mostrar como fazer.
