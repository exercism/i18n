# Introdução

Toda instância de uma estrutura ou classe tem uma propriedade implícita chamada `self`, que se refere à própria instância.
O uso mais comum de `self` é distinguir entre uma propriedade de instância e um parâmetro que tem o mesmo nome:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Os tipos em Swift também oferecem uma palavra-chave `Self` com inicial maiúscula, que se refere ao *tipo* da instância, e não à própria instância.
