# Introdução

Em Cairo, os Booleanos são representados pelo tipo Boolean predeclarado `bool`, cujos valores podem ser `true` ou `false`.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo dá suporte a três operadores lógicos que avaliam expressões e resultam em valores Booleanos, retornando `true` ou `false`.

| Operador    | O que significa                                 |
| ----------- | --------------------------------------------- |
| `&&` (e)  | É verdadeiro se as duas afirmações forem verdadeiras.       |
| `\|\|` (ou) | É verdadeiro se pelo menos uma afirmação for verdadeira. |
| `!` (não)   | É verdadeiro apenas se a afirmação for falsa.    |
