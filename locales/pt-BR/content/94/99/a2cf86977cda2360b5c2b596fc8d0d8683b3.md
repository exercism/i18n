# indentação

[comment]: # (Este comentário é retornado quando a solução usou pelo menos uma tabulação para indentar)

O código Elixir deve ser indentado com 2 espaços. Certifique-se de não usar tabulações para indentar.

Se você está resolvendo exercícios de Elixir no seu próprio computador, considere rodar `mix format` no diretório do exercício. Ele vai formatar seu código automaticamente de acordo com os padrões da comunidade, incluindo corrigir todos os problemas de indentação.
