# Dicas

## 1. Determine se você vai precisar de carteira de motorista

- Use o [operador de comparação de igualdade][comparison-operators] para verificar se a sua entrada é igual a uma determinada string.
- Use um dos dois [operadores lógicos][logical-operators] que você aprendeu no conceito de Boolean para combinar os dois requisitos.
- Você **não** precisa de uma condicional para resolver esta tarefa. Você pode retornar direto a expressão Boolean que montar.

## 2. Escolha entre dois possíveis veículos para comprar

- Use um [operador de comparação][comparison-operators] para determinar qual opção vem primeiro na ordem lexicográfica.
- Depois, defina o valor de uma variável auxiliar de acordo com o resultado dessa comparação, com a ajuda de uma [condicional if-else][if-statement].
- Por fim, monte a frase de recomendação.
  Para isso, você pode usar o operador `+` para concatenar as duas strings.

## 3. Calcule uma estimativa do preço de um veículo usado

- Comece determinando a porcentagem do preço original com base na idade do veículo.
  Salve isso em uma variável auxiliar. Use uma [condicional if-else if-else][if-statement] como mencionado nas instruções.
- Nas duas condições if, use [operadores de comparação][comparison-operators] para comparar a idade do carro com os valores limite.
- Para calcular o resultado, aplique a porcentagem ao preço original. Por exemplo, `30% of x` pode ser calculado dividindo `30` por `100` e multiplicando por `x`.

[comparison-operators]: https://golang.org/ref/spec#Comparison_operators
[logical-operators]: https://golang.org/ref/spec#Logical_operators
[if-statement]: https://golang.org/ref/spec#If_statements
