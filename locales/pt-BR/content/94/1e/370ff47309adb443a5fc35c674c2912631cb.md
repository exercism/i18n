# Grandes despesas no banco de dados

## Enunciado do problema

A ABC Corp precisa que você encontre o nome e o departamento dos funcionários com lançamentos de pagamento maiores que um determinado valor (por exemplo, `3000.00`).

Crie um record chamado `HighPayment` para retornar os dados necessários. A definição do record é a seguinte.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

Use a operação `query` do cliente JDBC para obter os dados necessários do banco de dados.

> OBSERVAÇÃO: Ordene o resultado por `payment_id` em ordem crescente.

## Detalhes do banco de dados

Use o banco de dados H2 fornecido para este problema.

> O arquivo do banco de dados de exemplo é `gofigure.mv.db`, e o nome do banco de dados é `gofigure`. Ele está dentro da pasta `db`.

As tabelas a seguir já estão no banco de dados H2 de exemplo com alguns dados de exemplo. Os nomes das colunas e os tipos de dados estão abaixo.

**Nome da tabela** : `Employee`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | inteiro, chave primária com auto-incremento       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | inteiro        |

**Nome da tabela**: `Payment`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | inteiro, chave primária com auto-incremento       |
| `date`            | data        |
| `amount`          | decimal        |
| `employee_id`     | inteiro        |
| `reason`          | string        |

* O arquivo do banco de dados é `gofigure.mv.db`. Use a URL JDBC como `jdbc:h2:file:/path/to/db/file`
* Nome de usuário: `root`
* Senha: `root`

## Restrições

* Use o arquivo do banco de dados H2 fornecido na pasta `db` para validar as consultas e o exemplo em Ballerina
* Use a abordagem de parâmetros de dependência do Maven para adicionar o driver do banco de dados H2 como dependência de plataforma no seu Ballerina.toml

## Ambiente de teste

* Você pode rodar os testes com `bal test`, que serão executados contra o banco de dados de exemplo fornecido.

## Dicas

* Use o módulo [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) para trabalhar com o banco de dados
* Consulte a seção [Pré-requisito](https://lib.ballerina.io/ballerinax/java.jdbc/latest) para ver os passos de como adicionar o driver JDBC como dependência
* Use o método remoto [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) para consultar dados do banco de dados
* Consulte o exemplo [Consulta simples](https://ballerina.io/learn/by-example/mysql-query-operation)
