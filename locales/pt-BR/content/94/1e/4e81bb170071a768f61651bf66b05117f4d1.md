# Introdução

Uma `str` em Python é uma [sequência imutável][text sequence] de [pontos de código Unicode][unicode code points].
Ela pode incluir letras, sinais diacríticos, caracteres de posicionamento, números, símbolos de moeda, emoji, pontuação, vários tipos de espaço, quebras de linha e muito mais.

As strings implementam todas as [operações comuns de sequência][common sequence operations] e podem ser iteradas com a sintaxe `for item in <str>` ou `for index, item in enumerate(<str>)`.
Elas podem ser concatenadas com `<str> + <other str>` ou `<str>.join(<iterable>)`, divididas com `<str>.split(<separator>)` e oferecem várias opções de formatação e montagem.

Para trabalhar ainda mais com strings, o Python oferece um rico conjunto de [métodos de string][str-methods] que ajudam a buscar, limpar, transformar, traduzir e fazer muitas outras operações.

Por ser _imutável_, o valor de um objeto `str` na memória não muda; os métodos que parecem modificar uma string retornam uma nova cópia ou instância desse objeto `str`.
