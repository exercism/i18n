# Instruções

Neste exercício, você vai implementar a lógica de missão de um novo jogo de RPG que um amigo está desenvolvendo.

A personagem principal do jogo é Annalyn, uma garota corajosa que tem um cachorro de estimação feroz e leal. Infelizmente, o desastre acontece: seu melhor amigo foi sequestrado enquanto procurava frutinhas na floresta.

Annalyn vai tentar encontrar e libertar seu melhor amigo, podendo levar o cachorro com ela nessa missão.

Depois de passar um tempo seguindo a trilha de seu melhor amigo, ela encontra o acampamento onde ele está preso. Acontece que há dois sequestradores: um cavaleiro poderoso e um arqueiro astuto.

Depois de encontrar os sequestradores, Annalyn considera quais das ações a seguir ela pode realizar:

- _Ataque rápido_: um ataque rápido pode ser feito se o cavaleiro estiver dormindo, pois ele leva tempo para vestir a armadura, então ficará vulnerável.
- _Espionar_: pode-se espionar o grupo se pelo menos um deles estiver acordado. Caso contrário, espionar é perda de tempo.
- _Sinalizar para o prisioneiro_: pode-se sinalizar para o prisioneiro usando sons de pássaros se o prisioneiro estiver acordado e o arqueiro estiver dormindo, pois os arqueiros são treinados em sinais com pássaros, então poderiam interceptar a mensagem.
- _Libertar o prisioneiro_: Annalyn pode tentar se esgueirar até o acampamento para libertar o prisioneiro.
  É uma coisa arriscada de se fazer e só pode dar certo de uma entre duas maneiras:
  - Se Annalyn estiver com seu cachorro de estimação, ela pode resgatar o prisioneiro se o arqueiro estiver dormindo.
    O cavaleiro tem medo do cachorro e o arqueiro não terá tempo de se preparar antes que Annalyn e o prisioneiro consigam escapar.
  - Se Annalyn não estiver com o cachorro, ela e o prisioneiro precisam ser muito sorrateiros!
    Annalyn pode libertar o prisioneiro se o prisioneiro estiver acordado e o cavaleiro e o arqueiro estiverem ambos dormindo, mas se o prisioneiro estiver dormindo não dá para resgatá-lo: o prisioneiro se assustaria com o aparecimento repentino de Annalyn e acordaria o cavaleiro e o arqueiro.

Você tem quatro tarefas: implementar a lógica para determinar se as ações acima estão disponíveis, com base no estado dos três personagens encontrados na floresta e na presença ou não do cachorro de estimação de Annalyn.

## 1. Verifique se é possível fazer um ataque rápido

Implemente o método `canFastAttack()` que recebe um valor booleano que indica se o cavaleiro está acordado. Esse método retorna `true` se um ataque rápido puder ser feito com base no estado do cavaleiro. Caso contrário, retorna `false`:

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. Verifique se é possível espionar o grupo

Implemente o método `canSpy()` que recebe três valores booleanos, indicando se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados. O método retorna `true` se for possível espionar o grupo, com base no estado dos três personagens. Caso contrário, retorna `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Verifique se é possível sinalizar para o prisioneiro

Implemente o método `canSignalPrisoner()` que recebe dois valores booleanos, indicando se o arqueiro e o prisioneiro, respectivamente, estão acordados. O método retorna `true` se for possível sinalizar para o prisioneiro, com base no estado dos dois personagens. Caso contrário, retorna `false`:

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Verifique se é possível libertar o prisioneiro

Implemente o método `canFreePrisoner()` que recebe quatro valores booleanos. Os três primeiros parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados. O último parâmetro indica se o cachorro de estimação de Annalyn está presente. O método retorna `true` se for possível libertar o prisioneiro, com base no estado dos três personagens e na presença do cachorro de estimação de Annalyn. Caso contrário, retorna `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
