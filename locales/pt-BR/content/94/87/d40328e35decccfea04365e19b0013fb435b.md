# Números exatos

Dois dos tipos numéricos que você conheceu abrem mão de alguma coisa.

`INT` tem exatamente 32 bits, então guarda números de cerca de menos dois
bilhões a dois bilhões, e nada além disso. Passe disso e ele dá a volta
silenciosamente: nenhum erro, só uma resposta errada.

`FLTD` guarda frações, mas só de forma aproximada. `0.1d + 0.2d` fica bem
perto de `0.3`, mas não é exatamente `0.3`.

Para trabalhos em que isso importa, a biblioteca tem um tipo para cada um.

## INTI: números inteiros de qualquer tamanho

`INTI` guarda um número inteiro sem limite além da memória.

```sather
   #INTI(2).pow(100)
   -- 1267650600228229401496703205376
```

Um `INT` não consegue guardar isso. Um `FLTD` conseguiria guardar algo
próximo, e perderia os vinte últimos dígitos.

Crie um a partir de um `INT`, ou a partir de uma string quando o número for
grande demais para ser escrito como um `INT` desde o início:

```sather
   #INTI(42)
   #INTI("123456789012345678901234567890")
```

Depois, `+`, `-`, `*`, `/` e comparação funcionam como sempre, e `.str` dá
todos os dígitos.

Contar as maneiras como um grupo pode formar fila é o motivo clássico para
querer isso. Doze dançarinos têm 479001600 maneiras, e um `INT` guarda isso;
treze têm 6227020800, e ele não guarda.

```sather
   #INTI(20).factorial
   -- 2432902008176640000
```

## RAT: frações exatas

`RAT` guarda um número inteiro sobre outro, e os mantém assim.

```sather
   #RAT(1, 3)          -- 1/3, exactly
   #RAT(1, 2) + #RAT(1, 3)
   -- 5/6
```

Não acontece nenhum arredondamento, porque nada é convertido para decimal.

```sather
   #RAT(1, 10) + #RAT(2, 10) = #RAT(3, 10)      -- true
   0.1d + 0.2d = 0.3d                            -- not to be relied on
```

Um `RAT` se simplifica: `#RAT(2, 4)` é `1/2`, e imprime como `1/2`. Um que
resulta em inteiro imprime como número inteiro: `#RAT(6, 3)` imprime `2`.

## O custo

Os dois são mais lentos que os tipos embutidos, e os dois alocam memória.
`INT` e `FLTD` são instruções de máquina únicas; `INTI` e `RAT` são objetos
fazendo aritmética em software.

Use-os onde a exatidão é o ponto, e os tipos comuns em todo o resto.
