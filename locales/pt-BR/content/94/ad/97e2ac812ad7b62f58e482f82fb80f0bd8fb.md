# Introdução

No Conceito `Types`, aprendemos que:

- Os tipos em Julia formam uma hierarquia.
- Cada tipo tem um supertipo.
- `Any` está no topo da hierarquia e é seu próprio supertipo.
- Os tipos _podem_ ter subtipos, e os que têm são chamados de `abstract types`.
- Tipos sem subtipos (nós folha da árvore) são chamados de `concrete types`.
- Tipos indivisíveis, como `Char` ou `Int64`, são chamados de `primitive types`.

Apenas tipos `primitive` seguem o padrão abstrato versus concreto em sua forma simples.
`Vector` é uma coleção, separável em elementos com tipo próprio.

```julia-repl
julia> isprimitivetype(Int)
true

julia> isprimitivetype(Vector)
false
```

_Uma coleção de quê?_

Cada vetor (ou conjunto) é uma coleção de elementos com algum tipo uniforme, que pode ser especificado com um _parâmetro_ entre chaves `{ }`, ou omitido para que a inferência de tipos determine.

```julia-repl
julia> v = [1, 2, 3]
3-element Vector{Int64}:
 1
 2
 3

julia> v8 = Vector{Int8}([2, 4, 6])
3-element Vector{Int8}:
 2
 4
 6
```

Esses `parametric types` são uma forma de `generic programming`, e muitas linguagens modernas têm algo amplamente equivalente, embora com muitas diferenças nos detalhes.

## Tipos Compostos Paramétricos

Às vezes queremos criar um tipo composto flexível (genérico) o suficiente para lidar com diferentes tipos de campo.

Isso pode ser feito com um tipo fictício na definição, geralmente chamado de `T`.

```julia-repl
julia> struct Point{T}
               x::T
               y::T
       end

# high definition version

julia> real_point = Point(7.3, 4.2)
Point{Float64}(7.3, 4.2)

julia> typeof(real_point)
Point{Float64}

# low definition version

julia> int8point = Point{Int8}(17, 23)
Point{Int8}(17, 23)

julia> typeof(int8point)
Point{Int8}

julia> Point(Int8(17), Int8(23))
Point{Int8}(17, 23)
```

Naturalmente, essa abordagem também funciona com coleções nos campos:

```julia-repl
julia> struct Record{T}
           data::Vector{T}
           comment::String
       end

julia> rec = Record{Float64}([1.3, 5.2], "some data")
Record{Float64}([1.3, 5.2], "some data")

julia> rec.data
2-element Vector{Float64}:
 1.3
 5.2

julia> rec2 = Record{Int32}([3, 5], "more data")
Record{Int32}(Int32[3, 5], "more data")

julia> rec2.data
2-element Vector{Int32}:
 3
 5
```
