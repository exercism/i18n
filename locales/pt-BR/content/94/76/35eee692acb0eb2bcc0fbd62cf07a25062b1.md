# Instruções

Você é um elfo que trabalha na divisão de logística do Papai Noel e recebeu duas tarefas do chefe para atualizar o software do sistema.

## 1. Obter o nome do brinquedo

O sistema precisa conseguir obter o nome de um brinquedo do banco de dados.
O banco de dados é composto de tuplas do tipo `(name: String, quantity: Int)`.

Implemente a função `getName(_:)`, que recebe um argumento que contém uma tupla do tipo `(name: String, quantity: Int)`.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. Adicionar um novo brinquedo ao banco de dados

O mercado de brinquedos é um mercado rápido e em constante mudança: o que é popular muda muito rapidamente.
Por isso, é necessária uma função que crie um novo brinquedo.

Implemente a função `createToy(name:amount:)`, que recebe um argumento `name` que contém o nome do brinquedo, e `amount` que contém a quantidade do brinquedo.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. Atualizar a quantidade de um brinquedo

Os elfos na oficina do Papai Noel estão constantemente fazendo mais brinquedos, e o Papai Noel precisa acompanhar a quantidade de cada brinquedo.
Para isso, o sistema precisa conseguir atualizar a quantidade de um brinquedo no banco de dados.

Implemente a função `updateQuantity(_:toy:Amount:)`, que recebe os argumentos:
- `toys` que contém um array de tuplas do tipo `(name: String, quantity: Int)`.
- `toy` que contém o nome do brinquedo a atualizar.
- `amount` que contém a nova quantidade do brinquedo.

Você pode assumir que o brinquedo já está no banco de dados e não precisa verificar isso.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. Adicionar uma chave de categoria a um brinquedo

O Papai Noel quer conseguir categorizar os brinquedos no banco de dados.
Isso permite que ele encontre os brinquedos facilmente quando precisar fazer uma entrega e consiga ordená-los no banco de dados.

No entanto, quando o sistema foi implementado pela primeira vez, a chave de categoria foi esquecida.
Agora, o sistema precisa conseguir adicionar uma chave de categoria a um brinquedo no banco de dados.

Implemente a função `addCategory(_:category:)`, que recebe os argumentos:
- `toys` que contém um array de tuplas do tipo `(name: String, quantity: Int)`.
- `category` que contém a chave de categoria a adicionar aos brinquedos.

Você pode assumir que o brinquedo já está no banco de dados e não precisa verificar isso.
Você também pode assumir que ainda não há uma chave de categoria no brinquedo.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
