# Introdução

## Laços `for`

Uma instrução `for` repete um bloco de código.
A primeira linha dela controla com que frequência o bloco se repete:

```go
for init; condition; post {
    // loop body
}
```

- A instrução **init** roda uma única vez, antes da primeira iteração. É comum declarar e inicializar uma variável contadora usada pelo laço.
- A **condition** é uma expressão Boolean avaliada antes de cada iteração. O laço para quando essa expressão resulta em `false`.
- A instrução **post** roda depois de cada iteração concluída. Ela pode ser usada para atualizar um contador.

Não coloque parênteses em volta de `init; condition; post`.
No entanto, as chaves em volta do corpo do laço são sempre obrigatórias.

Esse laço começa `i` em `1`, imprime o valor atual de `i`, aumenta `i` para a próxima iteração e para quando `i` chega a `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
