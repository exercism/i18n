# Instruções

Elena é a nova gerente de qualidade de uma fábrica de jornais.
Como acabou de chegar à empresa, decidiu revisar alguns dos processos da fábrica para ver o que poderia ser melhorado.

Ela descobriu que os técnicos fazem muitos controles de qualidade à mão.

Ela vê uma boa oportunidade para automação e pede a você, desenvolvedor freelancer, que desenvolva um software para monitorar algumas das máquinas.

## 1. Monitore o nível de umidade da sala

Sua primeira missão é escrever um software para monitorar o nível de umidade da sala de produção.
Já existe um sensor conectado ao software da empresa que retorna periodicamente a porcentagem de umidade da sala.

Você precisa implementar uma função no software que lance um erro se a porcentagem de umidade estiver muito alta.
A função deve se chamar `check_humidity_level` e receber a porcentagem de umidade como parâmetro.

Você deve parar com um erro (a mensagem não é importante) se a porcentagem passar de 70%. 
Caso contrário, emita uma mensagem que inclua "humidity test passed" e retorne `TRUE` para confirmar que a medição está boa.

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. Detecte o superaquecimento

Elena ficou muito satisfeita com sua primeira tarefa e pede que você cuide do monitoramento da temperatura das máquinas.
Enquanto conversa com um técnico, Greg, você fica sabendo que, se a temperatura de uma máquina passar de 500°C, os técnicos começam a se preocupar com superaquecimento.

A máquina é equipada com um sensor que mede sua temperatura interna.
Você deve saber que o sensor é muito sensível e costuma quebrar.
Nesse caso, os técnicos precisarão trocá-lo.

Sua tarefa é implementar uma função `report_overheating` que recebe a temperatura como parâmetro e lança um erro se o sensor estiver quebrado ou se a máquina começar a superaquecer.

Sabendo que mais tarde você precisará reagir de forma diferente dependendo do erro, você precisa de um mecanismo para diferenciar os dois tipos de erro.

- Se o sensor estiver quebrado, a temperatura será `NULL`.
  Nesse caso, você deve parar com uma mensagem de erro que inclua "Sensor Broken" como parte da string.
- Quando o sensor estiver funcionando, se a temperatura passar de 600°C, você deve parar com uma mensagem que inclua a temperatura.
- Se a temperatura passar de 500°C, mas não de 600°C, você deve emitir um aviso que inclua a temperatura e retornar `FALSE`.
- Caso contrário, está tudo bem, então emita a mensagem `"temperature check passed: t °C"`, em que `t` é a temperatura, e retorne `TRUE`.

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. Monitore a máquina

Agora que sua máquina consegue detectar erros e você tem um erro de máquina personalizado, você adiciona uma função wrapper que consegue relatar como tudo está funcionando.
Além de retornar os logs das funções anteriores, esse wrapper também precisará adicionar logs dependendo dos tipos de falha que ocorrerem.

- Verifique a umidade e a temperatura.
- Se houver problemas, deixe `check_humidity_level()` e `report_overheating()` simplesmente emitirem seus logs.
- Se estiver tudo bem, adicione uma mensagem que inclua "All OK".

Implemente uma função `monitor_the_machine()` que recebe umidade e temperatura como argumentos.

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
