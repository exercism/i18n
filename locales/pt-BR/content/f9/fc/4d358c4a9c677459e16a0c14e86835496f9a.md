# Instruções

Neste exercício, você vai escrever um código para ajudar a preparar uma lasanha incrível do seu livro de receitas favorito.

Você tem cinco tarefas, todas relacionadas ao tempo gasto preparando a lasanha.

## 1. Defina o tempo esperado no forno em minutos

Implemente a função `expectedCookTime` na classe `Lasagna`, que não recebe nenhum argumento e retorna quantos minutos a lasanha deve ficar no forno.
De acordo com o livro de receitas, o tempo esperado no forno, em minutos, é 40:

```php
<?php
$timer = new Lasagna();
$timer->expectedCookTime()
// => 40
```

## 2. Calcule o tempo restante no forno em minutos

Implemente a função `remainingCookTime` na classe `Lasagna`, que recebe como argumento o número real de minutos que a lasanha já passou no forno e retorna quantos minutos a lasanha ainda precisa ficar no forno, com base no tempo esperado no forno, em minutos, da tarefa anterior.

```php
<?php
$timer = new Lasagna();
$timer->remainingCookTime(30)
// => 10
```

## 3. Calcule o tempo de preparo em minutos

Implemente a função `totalPreparationTime` na classe `Lasagna`, que recebe como argumento o número de camadas que você adicionou à lasanha e retorna quantos minutos você passou preparando a lasanha, considerando que cada camada leva 2 minutos para preparar.

```php
<?php
$timer = new Lasagna();
$timer->totalPreparationTime(3)
// => 6
```

## 4. Calcule o tempo total de trabalho em minutos

Implemente a função `totalElapsedTime` na classe `Lasagna`, que recebe dois argumentos: o primeiro argumento é o número de camadas que você adicionou à lasanha, e o segundo argumento é o número de minutos que a lasanha passou no forno.
A função deve retornar quantos minutos, no total, você trabalhou preparando a lasanha. Esse total é a soma do tempo de preparo em minutos com o tempo, em minutos, que a lasanha passou no forno até o momento.

```php
<?php
$timer = new Lasagna();
$timer->totalElapsedTime(3, 20)
// => 26
```

## 5. Crie uma notificação de que a lasanha está pronta

Implemente a função `alarm` na classe `Lasagna`, que não recebe nenhum argumento e retorna uma mensagem indicando que a lasanha está pronta para comer.

```php
<?php
$timer = new Lasagna();
$timer->alarm()
// => "Ding!"
```
