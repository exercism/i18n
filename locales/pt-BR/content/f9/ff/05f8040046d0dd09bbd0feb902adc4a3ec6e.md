# Sobre

Uma expressão Boolean é uma pergunta feita a um ou mais valores que pode ser respondida com `true` ou `false`.
Uma expressão verdadeira retorna `1`; uma expressão falsa retorna `0`.
Além disso, os números têm valores de verdadeiro/falso. Zero é `false`; diferente de zero é `true`.

Código C antigo ou usa o tipo `int` diretamente para valores Boolean, ou o programador pode ter definido constantes como `TRUE` e `FALSE` para mapear `1` e `0` para uma representação Boolean.

Com a versão C99, o tipo `_Bool` foi adicionado.
O arquivo de cabeçalho `stdbool.h` define três novos símbolos Boolean: `bool`; `true` e `false`.
`true` mapeia para `1`; `false` mapeia para `0`; e `bool` mapeia para `_Bool`.
Então agora, em vez de usar `int`s diretamente ou criar seus próprios mapeamentos Boolean, os programadores podem incluir `stdbool.h` e obter automaticamente símbolos Boolean no seu código.

## Operadores de comparação

C suporta seis operadores de comparação: `==` (Igual a), `!=` (Diferente de), `>` (Maior que), `<` (Menor que), `>=` (Maior ou igual a), `<=` (Menor ou igual a).
Esses operadores comparam as relações entre valores e as resolvem em valores Boolean.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Operadores Boolean

C suporta três operadores Boolean: `||` (Ou), `&&` (E), e `!` (Não).

`!` é usado com um operando.
Ele inverte o valor Boolean do operando.
Por exemplo, `0` é `false`, mas `!0` é `true`.

`||` e `&&` são usados com dois operandos.
O operando à direita só é avaliado quando o operando à esquerda ainda não determina o resultado da expressão.
Ou seja, `||` só avalia seu operando à direita quando seu operando à esquerda é avaliado como `false`.
`&&` só avalia seu operando à direita quando seu operando à esquerda é avaliado como `true`.

## Curto-circuito

Não avaliar todos os operandos é conhecido como "curto-circuito".
O curto-circuito é uma forma sucinta e poderosa de lidar com certas situações.
Por exemplo, uma prática comum é verificar se um ponteiro não é `NULL` e (&&), se ele não for `NULL`, então desreferenciá-lo, evitando assim desreferenciar um ponteiro `NULL`.
Mas o curto-circuito também pode levar a bugs.
Às vezes, um programador esquece que o operando à direita de `||` ou `&&` pode não ser sempre avaliado.
Se o operando à direita for uma expressão com um efeito colateral que se espera que sempre aconteça, então será um bug dependendo do valor Boolean do operando à esquerda.

## Retornar uma expressão Boolean

O resultado de uma expressão Boolean pode ser retornado diretamente.
Por exemplo, esta condicional `if`

```c
if (count > 0)
    return true;
else
    return false;
end
```

poderia ser substituída por

```c
return count > 0;
```
