# About

Em Go, strings são imutáveis.
Concatenar strings com `+` em um laço causa alocações frequentes e copia os dados várias vezes.
O pacote [`strings`](https://pkg.go.dev/strings) fornece o [`Builder`](https://pkg.go.dev/strings#Builder) para minimizar a sobrecarga de memória ao montar strings de forma eficiente.

## Construindo strings

O valor zero de um `strings.Builder` já está pronto para uso, sem nenhuma inicialização nem alocação explícita.
Você pode inserir novos dados no builder usando métodos de escrita específicos.
Cada método de escrita retorna um valor de erro para satisfazer as interfaces padrão de Go, mas é garantido que ele sempre será `nil` e costuma ser ignorado no código do dia a dia.

Os métodos mais usados são:

- `WriteString(s string) (int, error)`: Acrescenta uma string ao buffer.
- `WriteRune(r rune) (int, error)`: Acrescenta a codificação UTF-8 de uma rune.
- `WriteByte(c byte) error`: Acrescenta um único byte.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Obtendo e redefinindo

Quando terminar de montar seu texto, você pode extrair o conteúdo acumulado como uma string padrão de Go chamando o método `String()`.
Chamar `String()` é uma operação muito barata, porque retorna o slice de bytes subjacente como uma string diretamente, sem copiar os dados acumulados.

Se precisar reutilizar a mesma instância de builder para montar uma nova string (por exemplo, dentro de um laço), você pode chamar o método `Reset()`.
Isso esvazia o buffer interno e permite começar do zero e montar a próxima string, preservando a capacidade de memória já alocada por baixo dos panos.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
