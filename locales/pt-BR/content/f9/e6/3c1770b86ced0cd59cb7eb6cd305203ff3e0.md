# Instruções

O dia que você esperou por tanto tempo finalmente chegou, e agora você é o orgulhoso dono de uma bela fazenda nos Alpes.

Você ainda não gosta de acordar cedo demais para alimentar suas vacas.
Como você é um excelente engenheiro, você constrói um distribuidor de comida, o `FEED-M-ALL`.

A última coisa necessária para terminar seu projeto é um trecho de código que calcula a quantidade de forragem que cada vaca deve receber.
É importante que cada vaca receba a mesma quantidade, você precisa evitar conflitos.
Vacas são muito sensíveis.

Felizmente, você não precisa calcular todas as fórmulas de forragem por conta própria.
Você usa uma biblioteca externa misteriosa que encontrou na internet.
Ela deveria resultar nas vacas mais felizes.
A biblioteca expõe um tipo que cumpre a seguinte interface.
Você vai contar com isso no código que escrever.

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

À medida que você trabalha no seu código, vai melhorar o tratamento de erros para torná-lo mais robusto e mais fácil de depurar depois, quando usá-lo na sua vida diária na fazenda.

## 1. Divida a comida igualmente

Em primeiro lugar, você foca em escrever o código necessário para calcular a quantidade de forragem por vaca.

Implemente uma função `DivideFood` que aceita um `FodderCalculator` e um número de vacas como inteiro como argumentos.
*Para esta tarefa, você assume que o número de vacas passado é sempre maior que zero.*
A função deve retornar a quantidade de comida por vaca como um `float64` ou um erro, se ocorrer algum.

Para fazer o cálculo, você primeiro precisa obter a quantidade total de forragem para todas as vacas.
Isso é feito chamando o método `FodderAmount` e passando o número de vacas.
Além disso, você precisa de um fator pelo qual essa quantidade precisa ser multiplicada.
Você obtém esse fator chamando o método `FatteningFactor`.
Com esses dois valores e o número de vacas, você pode agora calcular a quantidade de comida por vaca (como um `float64`).
É isso que deve ser retornado da função `DivideFood`.

Se um dos métodos que você chama retornar um erro, a execução deve parar e esse erro deve ser retornado (como está) da função `DivideFood`.

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. Verifique o número de vacas

Enquanto trabalhava na primeira tarefa acima, você percebeu que a biblioteca externa que usa não tem a qualidade que você imaginava.
Por exemplo, ela não consegue lidar corretamente com entradas inválidas.
Você quer contornar essa limitação adicionando uma verificação para o valor de entrada no seu próprio código.

Escreva uma função `ValidateInputAndDivideFood` que tem a mesma assinatura que `DivideFood` acima.

- Se o número de vacas passado for maior que 0, a função deve chamar `DivideFood` e retornar os resultados dessa chamada.
- Se o número de vacas for 0 ou menos, a função deve retornar um erro com a mensagem `"invalid number of cows"`.

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. Melhore o tratamento de erros

Verificar o número de vacas antes de passá-lo adiante foi uma boa ideia, mas você não está muito satisfeito com a mensagem de erro pouco específica.
Você decide fazer melhor criando um tipo de erro personalizado chamado `InvalidCowsError`.

O erro personalizado deve armazenar o número de vacas (`int`) e uma mensagem personalizada (`string`), e o método `Error` deve serializar os dados no seguinte formato:

```txt
{number of cows} cows are invalid: {custom message}
```

De posse do seu erro personalizado, implemente uma função `ValidateNumberOfCows` que aceita o número de vacas como um inteiro e retorna um erro (ou nil).

- Se o número de vacas for menor que 0, a função retorna um `InvalidCowsError` com a mensagem personalizada definida como `"there are no negative cows"`.
- Se o número de vacas for 0, a função retorna um `InvalidCowsError` com a mensagem personalizada definida como `"no cows don't need food"`.
- Caso contrário, a função retorna `nil` para indicar que a validação foi bem-sucedida.

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

Depois do trabalho duro de montar essa função de validação, você percebe que já é noite e sai da sua mesa para curtir o pôr do sol sobre as montanhas.
Você deixa para outro dia a tarefa de de fato adicionar a nova função de validação ao seu código.
