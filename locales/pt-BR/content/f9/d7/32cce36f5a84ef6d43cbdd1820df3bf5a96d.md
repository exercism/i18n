# Dicas

## 1. Defina o intervalo de fileiras e colunas

- Você precisa definir duas [constantes][constants] que devem conter um [intervalo][range] de fileiras e colunas.
- As fileiras devem ser um intervalo de [números inteiros][integers] de 1 a 8.
- As colunas devem ser um intervalo de [caracteres][characters] de 'A' a 'H'.
- A constante precisa ser definida no [módulo][module] `Chess`.

## 2. Verifique se a casa é válida

- Você precisa verificar se um valor está dentro de um intervalo.
- Existe [um método][include] que pode ser usado para verificar se um valor está dentro de um intervalo.

## 3. Obtenha o apelido do jogador

- Você pode obter uma substring usando o [operador de intervalo][range-operator] como índice.
- Existe [um método][upcase] que pode ser usado para transformar uma string em maiúsculas.

## 4. Crie a mensagem do movimento

- Você pode indexar a string da casa para obter a fileira e a coluna.
- Você pode usar os métodos já definidos para obter o apelido do jogador e para verificar se o movimento é válido.
