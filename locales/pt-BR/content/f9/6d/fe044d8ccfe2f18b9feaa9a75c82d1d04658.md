# Sobre

O [SQLite][sqlite] é um sistema de gerenciamento de [banco de dados relacional][relational-database] de código aberto, leve, sem servidor e autossuficiente.
Ele é conhecido pela simplicidade, pela facilidade de uso e por não exigir nenhuma configuração.
O SQLite pode ser incorporado a aplicações, o que o torna uma escolha ideal para apps, sistemas embarcados e projetos de pequeno e médio porte.

Criado por [D. Richard Hipp][hipp], o SQLite segue as propriedades [ACID][acid], pensadas para facilitar transações confiáveis.
Ele é amplamente usado em diversos setores por ocupar pouco espaço e ter um desempenho eficiente.

O SQLite usa uma sintaxe direta baseada em SQL para definir bancos de dados e interagir com eles.
Tabelas, índices e consultas são criados com instruções SQL padrão, o que dá às pessoas desenvolvedoras uma forma familiar e expressiva de gerenciar bancos de dados.
O mecanismo do banco de dados é autossuficiente, o que elimina a necessidade de um processo de servidor separado.
Essa simplicidade, combinada com seus recursos poderosos, faz do SQLite uma excelente escolha para projetos em que facilidade de uso e eficiência são prioridade.

Para informações detalhadas e documentação, consulte a [documentação oficial do SQLite][sqlite docs].
Além disso, a comunidade oferece recursos como tutoriais, perguntas frequentes e muito mais para apoiar pessoas usuárias de todos os níveis.
