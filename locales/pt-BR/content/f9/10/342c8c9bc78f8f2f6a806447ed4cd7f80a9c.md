# Introdução

Uma *quotation* é um trecho de código entre colchetes `[ ]`. É um valor: você pode colocá-la na pilha, passá-la para outra palavra ou guardá-la em um array.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

A maioria das palavras de ordem superior recebe uma *quotation* como segundo argumento:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

O corpo de uma *quotation* é só código Factor comum: os mesmos operadores e os mesmos efeitos de pilha que você usa em qualquer outro lugar.

Quando você monta código a partir de dados (concatenando fragmentos, mapeando tokens para operações), o resultado é uma sequência; passe-a por `>quotation` para torná-la chamável:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
