# Dicas

## 1. Calcule o preço de uma pizza

- Monte uma função recursiva que retorna o preço de uma cobertura extra somado ao preço da pizza sem essa cobertura.
- Se aparecer o erro `Maximum call stack size exceeded`, verifique se você não deixou de fora o caso base.
- Se você estiver recebendo um `Memory Allocation Error`, verifique se está duplicando o array de coberturas de entrada em vez de modificá-lo.

## 2. Calcule o preço total de um pedido

- Usando `pizzaPrice`, calcule o preço de cada pizza do array e some os valores.
- Se aparecer o erro `Maximum call stack size exceeded` e mais de um teste estiver falhando, verifique se você não deixou de fora o caso base. Se apenas um teste estiver falhando, tente implementar isso com um laço!
- Se você estiver recebendo um `Memory Allocation Error`, verifique se está duplicando o array de entrada em vez de modificá-lo.
