# Apêndice das instruções

## Implementação

Defina uma única func do Go, MakeChain, que aceita uma slice de dominós e tenta construir uma cadeia válida de dominós.

MakeChain deve ter a seguinte assinatura:

```go
type Domino [2]int

func MakeChain(input []Domino) (chain []Domino, ok bool)
```

O resultado bool `ok` indica se a lista de dominós de entrada pode ser organizada em uma cadeia válida.
Uma lista de entrada vazia é considerada válida, e um único dominó cujos lados são iguais também é considerado válido.

O resultado 'chain' é uma slice de zero ou mais dominós organizados em uma ordem que mostra a cadeia válida.
É aceitável (e esperado) que os dominós em 'input' precisem ser rotacionados para que cada lado corresponda ao dominó adjacente na cadeia.
Os dominós no início e no fim da cadeia também devem corresponder ao seu lado externo.

Se a slice de dominós de entrada não puder ser organizada em uma cadeia válida,
MakeChain pode retornar nil para o resultado da cadeia, mas deve retornar false para o resultado ok.

Como pode haver mais de uma cadeia válida para uma determinada lista de entrada, quando `ok` for `true`, o programa de teste verificará apenas a validade da cadeia.
