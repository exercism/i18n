# Introdução

Casting e conversão de tipos são maneiras diferentes de mudar uma expressão de um tipo de dados para outro.

Uma expressão pode sofrer casting para outro tipo com o operador de cast `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Se os tipos não forem compatíveis, uma instância de `InvalidCastException` é lançada. No caso de números, isso indica que o tipo de destino não consegue representar o valor convertido. No caso de classes, um dos tipos precisa ser derivado do outro (isso também vale, trivialmente, para structs).

Uma alternativa ao _casting_ é a _conversão de tipos_ usando o operador `is`. Isso normalmente se aplica a tipos de referência e tipos anuláveis.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Se você precisar detectar o tipo exato de um objeto, o `is` pode ser permissivo demais, porque ele retorna true para uma classe e para qualquer uma das classes e interfaces das quais ela deriva, direta ou indiretamente. `typeof` e `Object.GetType()` são a solução nesse caso.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
