# Anexo das instruções

## Restrições

A biblioteca padrão do Rust já traz uma
[função de busca binária](https://doc.rust-lang.org/std/primitive.slice.html#method.binary_search).
Neste exercício, você não deve usar essa função, e sim outras ferramentas básicas.

## Para ganhar pontos extras

Você conseguiu fazer os testes passarem e deixar o código limpo? Se quiser, há
algumas coisas extras que você pode tentar.

- No momento, sua função find provavelmente só funciona com slices de números,
  mas o sistema de tipos do Rust é flexível o bastante para criar uma função
  find que funcione com todos os slices cujos elementos possam ser ordenados.
- Além disso, essa função find pode funcionar não só com slices, mas ao mesmo
  tempo também com um Vec ou um Array.

Para rodar os testes de bônus, remova a flag `#[ignore]` e execute os testes com
a feature `generic`, assim:

```bash
$ cargo test --features generic
```

Depois, compartilhe o que você achou em um comentário na solução enviada. Essa
experiência deixou o código melhor? Pior? Você aprendeu alguma coisa com ela?
