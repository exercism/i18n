# Instruções

Neste exercício, você vai organizar corridas entre vários tipos de carros de controle remoto.
Cada carro tem sua própria velocidade e suas próprias características de consumo de bateria.

Os carros começam com a bateria cheia (100%).
Cada vez que você dirige o carro com o controle remoto,
ele percorre em metros a velocidade do carro e reduz a porcentagem restante de bateria de acordo com o consumo dela.

Se a bateria de um carro estiver abaixo da porcentagem de consumo da bateria, você não pode mais dirigi-lo.

Cada pista de corrida tem sua própria distância.
Os carros são testados verificando se conseguem terminar a pista sem ficar sem bateria.

## 1. Crie um carro de controle remoto

Defina uma struct `Car` com os seguintes campos do tipo `int`:

- battery
- batteryDrain
- speed
- distance

Permita criar um carro de controle remoto definindo uma função `NewCar` que recebe a velocidade do carro em metros
e a porcentagem de consumo da bateria como seus dois parâmetros (ambos do tipo `int`) e retorna uma instância de `Car`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. Crie uma pista de corrida

Defina outro tipo struct chamado `Track` com o campo `distance` do tipo inteiro.
Permita criar uma pista de corrida definindo uma função `NewTrack` que recebe a distância da pista em metros como seu único parâmetro (que é do tipo `int`):

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. Dirija o carro

Implemente a função `Drive` que atualiza o número de metros percorridos com base na velocidade do carro e reduz a bateria de acordo com o consumo dela.
Se não houver bateria suficiente para dirigir mais uma vez, o carro não se move:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. Verifique se um carro de controle remoto consegue terminar uma corrida

Para terminar uma corrida, um carro precisa ser capaz de percorrer a distância da corrida.
Isso significa não esgotar a bateria antes de cruzar a linha de chegada.
Implemente a função `CanFinish` que recebe uma instância de `Car` e uma instância de `Track` como seus parâmetros e retorna `true` se o carro conseguir terminar a corrida; caso contrário, retorne `false`.

Considere que você está na linha de partida da corrida e liga o motor do carro para a corrida.
Leve em conta que a bateria do carro pode não estar necessariamente cheia ao começar a corrida:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
