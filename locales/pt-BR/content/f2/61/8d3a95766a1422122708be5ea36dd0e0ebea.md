## Propriedades e campos em Groovy

Neste exercício, você deve ter notado que o stub define getters, como `getX()`, mas os testes acessam o valor diretamente como `.x`. Isso se deve à forma como o Groovy define propriedades. Vamos por partes:

- Um **campo** é um membro de uma classe, interface ou trait usado para **armazenar dados**.
- Uma **propriedade** é um recurso **visível externamente** de uma classe.

Pontos-chave sobre as propriedades do Groovy:
- O Groovy gera getters e setters automaticamente para campos não privados (ou apenas um getter, se o campo estiver marcado como `final`).
- As propriedades podem ser acessadas pelo nome (como no teste deste exercício) e vão chamar o getter ou o setter de forma transparente.
- Por convenção, o Groovy reconhece propriedades mesmo quando não existe um campo de apoio, desde que haja getters ou setters.

Neste exercício, especificamos apenas os getters necessários (e, portanto, as propriedades conforme descrito acima) para exigir uma implementação adequada. Você tem liberdade para decidir quais campos (e seus tipos) são mais adequados para a sua solução.

Se você quiser explorar mais o tema de campos e propriedades, consulte o [Capítulo 3.3. Campos e propriedades](https://www.groovy-lang.org/objectorientation.html#_fields_and_properties) na documentação do Groovy.
