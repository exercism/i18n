# Introdução

Quando o número de iterações de um laço não é conhecido de antemão ("continue até que algum predicado deixe de ser verdadeiro"), o Factor usa o combinador `while` do [`kernel`][kernel]:

```
while ( pred body -- )
```

Tanto `pred` quanto `body` são quotations que operam sobre a pilha de dados. O `while` chama `pred`; se ela deixar um valor verdadeiro no topo, o `while` executa `body` e repete; caso contrário, ele para. O estado que flui de uma iteração para a seguinte fica na pilha entre as chamadas (ou em locais nomeados quando há mais de um pedaço de estado).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` é a forma simétrica: ele continua *até* que o predicado se torne verdadeiro.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
