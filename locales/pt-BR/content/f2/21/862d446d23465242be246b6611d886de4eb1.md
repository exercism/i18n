# Introdução

O `when` do Kotlin é uma expressão condicional para escolher entre várias opções. Ele é parecido com o `switch` do Java e mais flexível que uma cadeia de `if` ... `else if` ... `else`.

Assim como o `if`, o `when` também pode ser usado como uma expressão que produz um valor.

## Correspondência com um valor

Passe para o `when`, entre parênteses, um valor a ser comparado. Cada bloco compara esse valor até que um deles corresponda:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Cada bloco é escrito como `pattern -> result`.
- Os blocos são testados de cima para baixo até que uma correspondência seja encontrada. Apenas o primeiro bloco roda.
- Use `else` para qualquer valor que não esteja listado acima (parecido com o `else` final em uma cadeia de `if`).

Isso é semelhante à [correspondência de padrões][pattern-matching]. O `pattern` pode ser um valor a comparar, ou você pode usar `is` para comparar por tipo:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

ou usar `in` para verificar se o valor está contido em um intervalo, uma coleção, uma string ou qualquer outra coisa que tenha um método `contains`:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## Condições de guarda

Ao fazer correspondência com um valor, você pode colocar condições adicionais em um `if` depois do padrão. Essas condições são chamadas de condições de guarda.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

Você pode até usar `else if`.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Correspondência com condições

Como alternativa, você pode omitir o valor e colocar condições booleanas em cada bloco:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Novamente, os blocos são verificados de cima para baixo e apenas o primeiro bloco cuja condição é `true` roda.

## Usando `when` como expressão

Quando o `when` é usado pelo seu resultado (atribuído a uma variável, retornado de uma função e assim por diante), todos os casos possíveis precisam estar cobertos.

- Ao fazer correspondência com um valor, adicione `else`, a menos que todos os valores possíveis já estejam tratados (por exemplo, todos os valores de um `Boolean` ou de um `enum`).
- Ao fazer correspondência com condições, um bloco `else` é obrigatório, porque o compilador não tem como saber que as suas condições cobrem todos os casos.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
