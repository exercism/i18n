# Instruções

Você adora observar pássaros e acompanha quantos visitaram seu jardim.
Normalmente você usa um registro num caderno para contar os pássaros, mas para trabalhar melhor com seus dados, você digitalizou as contagens das últimas semanas.

## 1. Determine o total de pássaros que você contou até agora

Vamos começar analisando os dados com uma visão geral.
Descubra quantos pássaros você contou no total desde que começou seus registros.

Implemente uma função `totalBirdCount` que aceita um array de `Int`s que contém a contagem de pássaros por dia.
Ela deve retornar o total de pássaros que você contou.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. Calcule o número de pássaros visitantes em uma semana específica

Agora que você tem uma noção geral dos números da sua contagem de pássaros, você quer fazer uma análise mais detalhada.

Implemente uma função `birdsInWeek` que aceita um array de contagens de pássaros por dia e um número de semana.

Ela retorna o total de pássaros que você contou naquela semana específica.
Você pode assumir que as semanas são sempre registradas por completo.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. Corrija um erro de contagem

Você percebeu que, todo o tempo em que tentava acompanhar os pássaros, havia um pássaro escondido num canto distante do jardim.

Você descobriu que esse pássaro sempre passava dia sim, dia não, no seu jardim.

Você não sabe exatamente onde ele estava entre esses dias, mas com certeza não era no seu jardim.

Sua intuição de observador de pássaros também diz que o pássaro estava no seu jardim no primeiro dia que você registrou na sua lista.

Com essa nova informação, escreva uma função `fixBirdCountLog` que recebe um array de pássaros contados por dia como argumento e retorna o array depois de corrigir o erro de contagem.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
