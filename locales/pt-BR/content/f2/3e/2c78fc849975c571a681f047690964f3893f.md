# Notas para este exercício na trilha Python

Você pode fazer as seguintes suposições sobre as entradas de teste da função `sum_of_multiples`:

- Todos os números de entrada são **_`int`s não negativos_** (_ou seja, números naturais incluindo o zero_).
- Uma `list` de fatores sempre será fornecida, e seus elementos são únicos e estão ordenados em ordem crescente.
