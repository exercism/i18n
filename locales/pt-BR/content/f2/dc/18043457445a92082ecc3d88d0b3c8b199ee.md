# Apêndice de instruções

## Dicas

Para completar este exercício, você precisa criar o tipo de dados `Matrix`,
com instâncias de `Eq` e `Show`, e implementar as seguintes funções:

- `cols`
- `column`
- `flatten`
- `fromList`
- `fromString`
- `reshape`
- `row`
- `rows`
- `shape`
- `transpose`

Você vai encontrar uma declaração de dados fictícia e as assinaturas de tipo já
prontas, mas cabe a você definir as funções e criar um tipo de dados significativo,
um newtype ou um sinônimo de tipo.

Nenhuma validação da entrada é necessária. Deixe falhar se a matriz não for
retangular, se caracteres inválidos aparecerem etc.

shape é (rows, cols)
