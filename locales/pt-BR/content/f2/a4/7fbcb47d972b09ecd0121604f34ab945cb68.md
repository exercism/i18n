# Complemento das instruções

## Dicas

Para completar este exercício, você precisa criar o tipo de dados `BST`, com instâncias de `Eq` e `Show`, e implementar as funções:

- `bstLeft`
- `bstRight`
- `bstValue`
- `empty`
- `fromList`
- `insert`
- `singleton`
- `toList`

Você vai encontrar uma declaração de dados fictícia e as assinaturas de tipo já prontas, mas cabe a você definir as funções e criar um tipo de dados, um newtype ou um sinônimo de tipo que façam sentido.
