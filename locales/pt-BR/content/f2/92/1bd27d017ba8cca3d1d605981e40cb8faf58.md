# Sobre

As condicionais em C++ são parecidas com as condicionais de outras linguagens.
O tipo subjacente de qualquer operação condicional é o tipo `bool`, que pode ter o valor `true` ou `false`.
As condicionais costumam ser usadas como mecanismos de controle de fluxo para verificar várias condições.

Você pode usar uma condicional `if`, que executa o código dela se a condição subjacente for `true`, assim:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Em cenários com mais de um caso, várias condicionais podem ser encadeadas usando as cláusulas `else if` e `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Desde o C++17, as condicionais também podem incluir uma instrução curta de inicialização, que pode ser usada para inicializar uma ou mais variáveis da condicional.
Por exemplo:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Observação: quaisquer variáveis criadas na inicialização não podem ser acessadas depois do fim da condicional.
