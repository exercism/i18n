# NuVoc

O [NuVoc][nuvoc-link] é a referência definitiva de J.
É uma visão geral muito concisa e densa em informações sobre as primitivas e a linguagem J.

# Rosetta Code

Muitas tarefas do Rosetta têm soluções em `J`.
É um bom recurso para encontrar programas em J para estudar.
[Aqui](https://rosettacode.org/wiki/Sudoku#J) está um solucionador de sudoku de Roger Hui.
