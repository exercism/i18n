# Laços

Em Rust, os laços podem ser usados para executar um bloco de código repetidamente até que você diga para parar ou até que uma certa condição seja atendida.

A versão mais básica de um laço usa a palavra-chave `loop`:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

O trecho de código acima cria um laço infinito. Para sair de um laço, use a palavra-chave break:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## Laços com `for` e `while`

Além da palavra-chave `loop`, você também pode criar laços com `for` e `while`.

Um laço `for` é usado para iterar sobre os elementos de uma coleção ou de um iterador.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

Intervalos também são iteradores, o que torna muito conveniente iterar sobre eles com o laço `for`:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

Um laço while fica repetindo o código até que uma condição seja atendida. Poderíamos reescrever o exemplo anterior usando um laço while assim:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

Veja [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetição com laços) no livro do Rust para mais informações sobre laços.
