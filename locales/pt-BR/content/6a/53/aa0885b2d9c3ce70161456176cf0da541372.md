Este exercício oferece uma grande variedade de soluções possíveis em combinação com a ajuda de crates externas. Para manter a quantidade de trabalho gerenciável, este documento traz uma pequena seleção de possibilidades. As soluções com Crossbeam têm um conjunto de conceitos semelhante ao listado aqui, e o Rayon exige apenas um subconjunto.

## Geral

- Strings: especificamente, o `str` é sempre um fator aqui
- Unicode: concessões de desempenho/recursos dos métodos ASCII vs Unicode. Os resultados de benchmark ficam distorcidos quando o benchmark usa métodos Unicode e a solução usa métodos ASCII.
- Iteradores: iterar sobre a entrada ou sobre pedaços dela.
- Coleções: iterar sobre um `HashMap` e usar `Entry`. Geralmente, os handles são coletados em um `Vec`.
- Referências
- Números: especificamente o trait `Add`
- Laço `for`: não dá para juntar threads em um Iterator por causa do move.
- **Opt** Visibilidade: mantenha os detalhes de implementação não públicos
- **Opt** slices: `.chunks()` é um método muito usado para dividir a entrada para as threads de trabalho. Como alternativa, usam-se subslices.
- **Opt** Funções de ordem superior: os HashMaps podem ser combinados por uma função de ordem superior com um Iterator.
- **Opt** Tipos: para dividir a entrada, podemos converter inteiros em valores de ponto flutuante para aplicar arredondamento
- **Opt** Crates

## Abordagem com std, com ou sem canais

- Paralelismo - subtópico criar/juntar threads.
- Iteradores - subtópico avaliação preguiçosa: criar e juntar threads com o mesmo Iterator impede o paralelismo.
- Tempos de vida - subtópicos `'static lifetime` e semântica explícita de `move`
- Iteradores/tempos de vida - subtópico iteradores consumidores: não dá para juntar threads usando Iterator.
- Tipo Option: desempacotar resultados de thread ou canal
- Funções: especificamente, funções de ordem superior são necessárias para criar threads. Closures são uma opção aqui.

## Abordagem com std e canais

- Paralelismo - subtópico canais.
- Tuplas: `mpsc::channel()` retorna uma tupla
- Desestruturação: a tupla pode ser desestruturada na atribuição
- Tempos de vida: `drop()`

## Abordagem alternativa com variáveis compartilhadas

- Contagem de referências: compartilhar dados agregados entre threads com uma coleção com contagem de referências.
- **Menção honrosa**: Paralelismo - subtópico Mutexes. Não é necessário/útil para este exercício, mas é um conceito comum mesmo assim. Relacionado: `RwLock`.

### Exemplo com std e canais

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### Exemplo com crate e Arc

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
