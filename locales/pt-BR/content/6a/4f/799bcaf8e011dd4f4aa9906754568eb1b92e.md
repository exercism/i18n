# Dicas

## Geral

- Use `movdqa` apenas quando se sabe que um operando de memória está alinhado.
  É seguro usá-lo quando os dois operandos são registradores.
- `movdqu` funciona com qualquer alinhamento.
- Os endereços de memória são passados como valores inteiros.
  Os seis primeiros argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`, respectivamente.

## 1. Misture duas faixas

- A adição com sinal e saturação para lanes de 16 bits é `paddsw`.
- Os três endereços de memória estão alinhados em 16 bytes, então a variante de movimentação alinhada, `movdqa`, é a adequada.
  Eles também podem ser usados diretamente como operando de origem (mas não como destino).

## 2. Remova o bleed

- A subtração com sinal e saturação para lanes de 16 bits é `psubsw`.
- `track` está alinhado, mas não há garantia de que `result` e `bleed` estejam, então eles precisam da variante de movimentação não alinhada, `movdqu`.

## 3. Combine os medidores

- A adição sem sinal e saturação para lanes de 8 bits é `paddusb`.
- Os três endereços de memória estão alinhados em 16 bytes, então a variante de movimentação alinhada, `movdqa`, é a adequada.
  Eles também podem ser usados diretamente como operando de origem (mas não como destino).

## 4. Aplique um fade

- A multiplicação que mantém os 16 bits altos de um produto de 16 bits com sinal é `pmulhw`.
- Os três endereços de memória estão alinhados em 16 bytes, então `movdqa` é a adequada.
  Eles também podem ser usados diretamente como operando de origem (mas não como destino).
- Tanto `track` quanto `gains` são lidos como valores com sinal, que é o que `pmulhw` espera.
- Instruções de dois operandos geralmente sobrescrevem o operando de destino.
- Cada registrador de 128 bits contém 8 amostras, e `n` (o quarto argumento) é sempre diferente de zero e múltiplo de `8`.
- Use um laço para processar todas as amostras, avançando 16 bytes (8 amostras) a cada iteração.

## 5. Atenue uma faixa

- O SIMD de inteiros não tem divisão empacotada, então converta para ponto flutuante empacotado, divida e depois converta de volta.
- As amostras têm 16 bits e precisam ser expandidas para 32 bits antes da conversão para ponto flutuante.
  A expansão com sinal de lanes de 16 bits para lanes de 32 bits é `pmovsxwd`.
- `pmovsxwd` pode receber um operando de memória de 64 bits, carregando e expandindo 4 amostras em uma única etapa.
- Converta os inteiros expandidos para números de ponto flutuante empacotados com `cvtdq2ps`.
- O divisor é um inteiro de 32 bits já fornecido em 4 cópias.
  Ele deve ser convertido para ponto flutuante empacotado antes de ser usado na divisão de ponto flutuante.
- A divisão empacotada de precisão simples é `divps`.
- Converta o quociente de volta para inteiros empacotados de 32 bits com `cvttps2dq`, que sempre trunca em direção a zero.
- Cada bloco de resultado tem 4 inteiros de 32 bits, e `n` (o quarto argumento) é sempre diferente de zero e múltiplo de `4`.
- Use um laço, avançando 8 bytes em `samples` (4 valores) e 16 bytes em `result` (4 valores) a cada iteração.
