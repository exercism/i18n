# Dicas

## Geral

- Leia sobre strings no [guia oficial de primeiros passos][getting-started-strings].
- Explore as [funções disponíveis no _módulo String_][string-module-functions] para descobrir quais operações com strings a biblioteca padrão do Elixir oferece.

## 1. Obter a primeira letra do nome

- Existe uma [função integrada][string-first] para obter o primeiro caractere de uma string.
- Existem várias [funções integradas][string-trim] para remover espaços em branco do início, do fim, ou do início e do fim de uma string.

## 2. Formatar a primeira letra como inicial

- Existe uma [função integrada][string-upcase] para converter todos os caracteres de uma string para a versão maiúscula.
- Existe um [operador][kernel-concat] que concatena duas strings.

## 3. Dividir o nome completo em primeiro nome e sobrenome

- Existe uma [função integrada][string-split] que divide uma string por caracteres de espaço em branco.
- Alguns dos primeiros elementos de uma lista podem ser atribuídos a variáveis por meio de casamento de padrões na lista.

## 4. Colocar as iniciais dentro do coração

- Existe uma sintaxe especial para [interpolar][string-interpolation] uma expressão dentro de uma string.
- Existe uma sintaxe especial para escrever [strings multilinha][heredoc-syntax] sem precisar escapar quebras de linha.
