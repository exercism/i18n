# Use `Keyword.get_values`

Listas de palavras-chave podem conter mais de um valor para uma mesma chave, o que torna trabalhoso recuperar todos os valores de uma chave.
Além de `Keyword.get`, que obtém um único valor, o módulo `Keyword` também oferece `Keyword.get_values`, que obtém vários valores.
Use `Keyword.get_values` para filtrar vinhos por cor.
