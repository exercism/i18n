# Instruções

Neste exercício, você vai trabalhar mais um pouco com carros de controle remoto.

Um carro experimental foi desenvolvido e a pista de testes precisa ser adaptada para lidar com os modelos de produção e experimental. Os dois tipos de carro já foram construídos e você precisa encontrar uma forma de lidar com ambos na pista de testes.

Além disso, os carros de produção estão começando a ter sucesso. O chefe da equipe quer manter o espírito competitivo publicando um ranking dos carros de produção.

## 1. Permita que os carros sejam dirigidos na mesma pista de testes

Adicione um método à interface `IRemoteControlCar` para expor as implementações de `Drive()` dos dois tipos de carro.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. Permita comparar a distância percorrida por modelos diferentes na pista de testes

Adicione uma propriedade à interface `IRemoteControlCar` para expor as implementações da propriedade `DistanceTravelled` dos dois tipos de carro.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. Permita que os carros de produção sejam classificados

Implemente a interface `IComparable<T>` na classe `ProductionRemoteControlCar`. A ordem de classificação padrão dos carros deve ser a ordem crescente de vitórias.

Implemente o método estático `TestTrack.GetRankedCars()` para retornar os carros recebidos ordenados em ordem crescente de número de vitórias.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
