# Apêndice das instruções

## Implementação

No pacote twobucket, implemente uma função Go, Solve, com a seguinte assinatura:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve retorna quatro valores: o bucket objetivo resultante ("one" ou "two"), o número de movimentos/passos para alcançar a quantidade objetivo, os litros que sobraram no outro bucket e um valor de erro.
Retorne um erro para qualquer parâmetro inválido ou quando não houver solução possível.
