# Introdução

## Expressões regulares

As expressões regulares em Elixir seguem a especificação **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), de forma semelhante a outras linguagens populares como Java, JavaScript ou Ruby.

O módulo `Regex` oferece funções para trabalhar com expressões regulares. Algumas funções do módulo `String` também aceitam expressões regulares como argumentos.

~~~~exercism/note
Este exercício pressupõe que você já conheça a sintaxe de expressões regulares, incluindo classes de caracteres, quantificadores, grupos e capturas.

Se você precisar relembrar seus conhecimentos de expressões regulares, dê uma olhada em uma destas fontes: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).

### Sigils

A forma mais comum de criar expressões regulares é usando o sigil `~r`.

```elixir
~r/test/
```

Repare que todos os sigils do Elixir suportam [diferentes tipos de delimitadores][sigils], não apenas `/`.

### Correspondência

O operador `=~/2` pode ser usado para realizar uma correspondência de regex que retorna um resultado `boolean`. Como alternativa, existem também as funções `match?/2` no módulo `Regex`, assim como no módulo `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### Capturas

Se uma simples verificação booleana não for suficiente, use a função `Regex.run/3` para obter uma lista com todas as capturas (ou `nil` se não houver correspondência). O primeiro elemento da lista retornada é sempre uma correspondência de toda a expressão regular, e os elementos seguintes são os grupos correspondidos.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### Modificadores

O comportamento de uma expressão regular pode ser modificado acrescentando flags especiais. Ao usar um sigil para criar uma expressão regular, adicione os modificadores depois do segundo delimitador.

Os modificadores mais comuns são:
- `i` - torna a correspondência insensível a maiúsculas e minúsculas.
- `u` - habilita padrões específicos do Unicode, como `\p`, e faz com que classes de caracteres como `\w`, `\s` etc. também correspondam a caracteres Unicode.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
