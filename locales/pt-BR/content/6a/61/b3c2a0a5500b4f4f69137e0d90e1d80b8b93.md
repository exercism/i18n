Instalação
==========

Para escrever programas em YAMLScript, você precisa instalar o intérprete de
linha de comando do YAMLScript.
É um arquivo executável binário chamado `ys`.
No momento, ele funciona em:

* Linux / Intel
* Linux / ARM
* MacOS / Intel
* MacOS / ARM

> Observação: o suporte ao Windows está planejado, mas ainda não está disponível.

As versões estão [disponíveis no GitHub](
http://github.com/yaml/yamlscript/releases).


## Instalação automática

Para resolver os exercícios de YAMLScript do Exercism, você modifica o programa
da sua solução repetidamente e roda `make test` até que todos os testes passem.

É isso!

Na primeira vez que você rodar `make test`, ele vai tentar instalar a versão
específica do intérprete `ys` exigida pelo exercício no diretório
`/path/to/exercism/yamlscript/.local/`.

Se você já instalou essa versão do `ys` em algum lugar do seu `PATH`, ele vai
copiar o intérprete `ys` silenciosamente para o lugar certo.

Se não, ele vai pedir para você fazer uma instalação de um release binário, o
que geralmente leva só alguns segundos.

Se isso falhar (raro, mas às vezes acontece), ele vai pedir uma compilação
automática a partir do código-fonte, que pode levar alguns minutos (mas é muito
confiável e não exige nenhuma interação).

Você só vai encontrar isso na primeira vez que rodar `make test`.
Todos os exercícios configurados para usar a mesma versão do `ys` vão usar a
mesma instalação.

> Observação: você também pode usar o comando `make install-ys` separadamente do `make
> test`.
> Ele faz exatamente o mesmo processo de instalação do `make test`, mas sem
> rodar os testes depois.


Para mais informações sobre como instalar o YAMLScript, especialmente para usá-lo
fora do Exercism, veja a [Documentação de instalação do YAMLScript](
https://yamlscript.org/doc/install/).
