# Criando um Test Runner

Antes de tudo, agradecemos o seu interesse em criar um Test Runner!

Estes são os passos para começar:

1. Verifique [nossa lista de repositórios para um `...-test-runner` já existente](https://github.com/search?q=org%3Aexercism+test-runner&type=repositories) para se certificar de que ele ainda não existe.
2. Dê uma olhada no [conteúdo deste diretório](/docs/building/tooling/test-runners) para se sentir à vontade com a ideia de criar um Test Runner.
3. Abra um novo tópico no [fórum do Exercism][building-exercism] dizendo para qual linguagem você gostaria de criar um Test Runner.
4. Quando um repositório de Test Runner for criado para você, use os documentos [interface do Test Runner](/docs/building/tooling/test-runners/interface) e [Boas práticas](/docs/building/tooling/best-practices) para ajudar a orientar sua implementação.

Temos uma comunidade incrivelmente amigável e prestativa, que terá prazer em ajudar você ao longo do processo!
Se você travar em algum ponto, abra um novo tópico no [fórum do Exercism][building-exercism] ou crie novas issues em [exercism/exercism][exercism-repo] conforme a necessidade 🙂

[building-exercism]: https://forum.exercism.org/c/exercism/building-exercism/125
