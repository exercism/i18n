# Noções básicas de match

O operador `match` compara um valor com uma série de padrões e então executa código com base em qual padrão corresponde.

## Correspondência com literais

Em sua forma mais fundamental, `match` compara um valor com vários padrões possíveis e escolhe o primeiro braço que corresponder. Apenas um braço é escolhido, e o controle nunca "passa adiante" para outro braço. `match` é uma expressão que pode resultar em um valor.

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## Exaustividade

A correspondência é sempre exaustiva: o Rust não compila um programa se for possível que um valor passe despercebido. Para ajudar nisso, `_` é um curinga que corresponde a qualquer coisa.

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## Correspondência como fluxo de controle

Embora `match` possa ser usado como uma expressão para produzir um valor, ele também pode ser usado como uma instrução apenas para fins de fluxo de controle.

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## Correspondência com intervalos

Os braços de um `match` não precisam ser especificados como valores únicos; eles também podem ser intervalos.

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## Padrões alternativos

Um braço de `match` pode corresponder a uma entre várias opções possíveis usando o token `|` como separador.

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## Correspondência estrutural e vinculação

A correspondência pode produzir uma vinculação válida dentro de um braço específico de `match`. Isso é especialmente útil para desempacotar enums que carregam dados em suas variantes.

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```

Mais sobre este tópico no conceito `match-advanced`.
