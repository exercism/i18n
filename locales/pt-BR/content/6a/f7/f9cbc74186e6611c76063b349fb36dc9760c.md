# Introdução

Em JavaScript, as _template strings_ permitem embutir expressões em strings, o que também é chamado de interpolação de strings.
Esse recurso amplia a funcionalidade do objeto global integrado [`String`][string-reference].

Você pode criar template strings em JavaScript envolvendo o texto em crases.
Elas não apenas permitem que o texto inclua novas linhas e outros caracteres especiais, como também permitem embutir variáveis e outras expressões.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

No exemplo acima, as crases - (<code>\`\`</code>) - são usadas para representar uma template string. O `${...}` é o placeholder usado para a substituição.
Quaisquer tipos que não sejam string são convertidos _implicitamente_ para string.
Esse assunto é abordado no conceito de [conversão de tipos][type-conversion-concept].
Todos os tipos de expressões podem ser usados com template strings.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Quando você precisa que as strings sejam formatadas em várias linhas:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Se você quiser representar uma nova linha dentro de uma string comum em vez de usar uma template string (ou seja, sem usar crases), pode usar a sequência de escape de nova linha `\n`:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

Com os recursos de substituição disponíveis, você também pode introduzir lógica no processo para determinar qual deve ser a string de saída.
Uma forma de lidar com essa lógica é usar o [operador ternário][ternary-operator].
Ele oferece a mesma funcionalidade condicional de `if/else`, em um formato um pouco diferente.

Para implementar lógica na sintaxe de template string:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
