# Introdução

Recursão é uma forma de repetir código em uma função fazendo com que a função chame a si mesma.
É outra forma de fazer um laço ou iterar. Assim como em um laço, a função deve testar uma expressão Boolean para saber quando terminar.
Diferentemente de um laço, uma recursão que nunca termina não roda infinitamente.
Os valores usados em cada chamada da função podem ser colocados em um quadro próprio na pilha.
Se a quantidade de chamadas de função ocupar mais espaço do que a pilha tem, isso vai resultar em um erro de estouro de pilha.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Isso vai imprimir

```
The number is 1
The number is 2
After recursion
```

Pode haver situações que ficam mais legíveis e/ou mais fáceis de raciocinar sobre quando expressas com recursão do que com laços.
