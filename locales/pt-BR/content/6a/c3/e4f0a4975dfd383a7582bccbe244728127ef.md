# Instruções

Chamar APIs pode dar erro quando usamos texto bruto ou JSON. Neste exercício, você vai usar Records do Ballerina para organizar os payloads das requisições e garantir uma comunicação bem-sucedida com endpoints externos de reserva.

## Objetivos

- Modifique o código fornecido.
- Reserve uma passagem aérea para o usuário chamando o serviço de reservas da Airline. Envie uma requisição POST para airlineReservationService com o payload adequado e receba uma resposta
- Reserve um quarto de hotel para o usuário chamando o serviço de reservas do Hotel. Envie uma requisição POST para hotelReservationService com o payload adequado e receba uma resposta
- Alugue um carro para o usuário chamando o serviço de aluguel de carros. Envie uma requisição POST para carRentalService com o payload adequado e verifique a resposta
- Se tudo der certo, retorne um corpo com um atributo message de "Congratulations! Your journey is ready!!"
