# Apêndice de instruções

## Formato de entrada/saída

A função recebe uma única string de palavras, cada uma terminada com uma quebra de linha.

A primeira é a palavra da qual as demais devem ser anagramas.

Retorne uma string com todos os anagramas válidos, cada um terminado com uma quebra de linha.


## Endereços reservados

O buffer da string de entrada usa os bytes 64-319 da memória linear.

Você pode modificar esse buffer no próprio lugar, caso queira evitar alocações de memória adicionais.
