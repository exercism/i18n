# Debug

Você pode usar [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) para anexar mensagens a testes que falham, assim:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

Em um teste que falha, o log anexado será `secondsInOneHour: 3600`.

Há uma ressalva: constantes de nível superior são avaliadas apenas uma vez, antes de os testes começarem a rodar, então os testes não conseguem capturar as mensagens de log delas. Por exemplo:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

não vai registrar nada durante os testes, porque a variável JavaScript associada a `secondsInOneHour` já foi avaliada com o valor 3600.
