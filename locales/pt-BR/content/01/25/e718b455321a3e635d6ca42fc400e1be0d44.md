# Instruções

Se você quiser construir algo usando um Raspberry Pi, provavelmente vai usar _resistores_.
Para este exercício, você precisa saber duas coisas sobre eles:

- Cada resistor tem um valor de resistência.
- Resistores são pequenos. Tão pequenos que, se você imprimisse o valor da resistência neles, seria difícil de ler.

Para contornar esse problema, os fabricantes imprimem faixas codificadas por cores nos resistores para indicar seus valores de resistência.
Cada faixa tem uma posição e um valor numérico.

As duas primeiras faixas de um resistor seguem um esquema de codificação simples: cada cor corresponde a um único número.

Neste exercício, você vai criar um programa útil para não precisar decorar os valores das faixas.

Essas cores são codificadas assim:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

O objetivo deste exercício é criar uma forma de:

- consultar o valor numérico associado a uma faixa de cor específica
- listar as diferentes cores de faixa

Os mnemônicos associam as cores aos números que, quando armazenados como um array, acabam correspondendo ao índice de cada uma no array:
Better Be Right Or Your Great Big Values Go Wrong.

Mais informações sobre a codificação de cores dos resistores podem ser encontradas no [artigo da Wikipédia sobre código de cores eletrônico][e-color-code].
