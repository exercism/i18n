# Dicas

## Geral
- [Este tutorial][string-tutorial] é útil.
- [Documentação de referência][string-docs] de `String`.

## 1. Substitua espaços por sublinhados
- `String` fornece uma função [replace][replace].

## 2. Substitua caracteres de controle pela string "[CTRL]" em maiúsculas
- Você pode separar strings em uma lista de strings com `String.split`
- Você pode [concatenar][concat] ou [acrescentar][append] várias strings.

## 3. Converta kebab-case em camelCase
- Literais de `char` ficam entre aspas simples.
- [Char.toUpper][toUpper] converte um caractere para letra maiúscula.
- Considere usar funções de ordem superior para percorrer a string inteira.

## 4. Omita dígitos
- `Char` fornece funções para detectar [dígitos][isDigit] e caracteres [alfabéticos][isAlpha].

## 5. Omita letras gregas minúsculas
- `Char` pode transformar caracteres [de/para seus valores decimais unicode][toCode].
- As [letras gregas][greek] minúsculas formam um bloco Unicode contíguo.
