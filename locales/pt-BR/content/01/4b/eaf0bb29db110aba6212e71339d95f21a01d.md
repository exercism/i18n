# Instalação

Siga as instruções para o seu sistema na página de instalação em [golang.org][go-install].


## Versão do Go

Esta trilha usa o Go 1.27.

Dá para usar uma versão anterior do Go modificando o arquivo `go.mod` de cada exercício e alterando a linha `go 1.27`. Só que os testes usam recursos introduzidos no Go 1.22 e não vão funcionar sem modificações com uma versão anterior.

[go-install]: https://go.dev/doc/install
