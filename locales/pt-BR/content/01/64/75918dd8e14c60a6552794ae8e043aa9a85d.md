# Introdução

## Caracteres

### Caracteres

O tipo primitivo `char` do Java é uma representação de 16 bits de um único caractere.
Vários `char`s podem compor uma string, como `"word"`, ou os `char`s podem ser processados de forma independente.
Um literal `char` é cercado por aspas simples (por exemplo, `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

### Obtendo os `char`s de uma `String`

O método `String.toCharArray` retorna os caracteres de uma String como um array.
Como mencionado em arrays, você pode usar um laço `for` para iterar sobre o array.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### A classe Character

Existem muitos métodos integrados da biblioteca para inspecionar e manipular `char`s.
Eles podem ser encontrados como métodos estáticos da classe `java.lang.Character`.
Aqui estão alguns exemplos:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### Adicionando um `char` a uma `String`

O operador `+` pode ser usado para adicionar um `char` a uma `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Cuidado para _não_ usar o `+` para juntar dois `char`s e formar uma `String`!
Somar dois `char`s dessa forma resulta em um `int`, _não_ em uma `String`!
Por exemplo:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Isso acontece porque o Java promove o `char` para um `int` (veja [4.2 Primitive Types and Values ][jls-primitives] da [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

No entanto, quando há muitos caracteres para adicionar, pode ser mais eficiente usar um `StringBuilder`:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
