# Funções

Funções são fundamentais em Cairo.

Por convenção, Cairo usa **snake case** para nomes de funções e variáveis, em que as palavras ficam em minúsculas e separadas por underscores.

Veja um exemplo:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

As funções são definidas com `fn`, seguidas de um nome, parênteses para os parâmetros (se houver) e um corpo entre chaves.

Você chama uma função pelo nome dela seguido de parênteses.

A ordem das funções não importa, desde que estejam no escopo.

## Parâmetros

As funções podem receber **parâmetros**, que são variáveis definidas na assinatura da função.

Ao chamar a função, você fornece **argumentos**, os valores passados para esses parâmetros.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

Aqui, `x` é um parâmetro do tipo `felt252`.

Quando chamada com `5`, a função imprime "The value of x is: 5".

Vários parâmetros são separados por vírgulas:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

Isso imprime: `The measurement is: 5h`.

## Instruções e expressões

As funções em Cairo são compostas por **instruções** e **expressões**:

- **Instruções** executam ações, mas não retornam valores.
Por exemplo, `let x = 3;` é uma instrução.
- **Expressões** resultam em um valor.
Por exemplo, `5 + 6` resulta em `11`.

Blocos entre chaves também são expressões, e o valor final deles é retornado:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

Aqui, `y` recebe o valor `4`.

## Valores de retorno

As funções podem retornar valores usando a sintaxe `->` para especificar o tipo de retorno.

Por padrão, uma função retorna o valor da sua expressão final:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

Isso imprime: `The value of x is: 5`.

Para casos mais complexos:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

Isso imprime: `The value of x is: 6`.

Cuidado para não adicionar um ponto e vírgula no fim da expressão final, pois isso transformaria a expressão em uma instrução, fazendo a função retornar `()` (tipo unit) em vez do valor esperado.
