# Introdução

Condicionais são instruções que executam um código diferente dependendo de a condição ser `true` ou `false`.

Uma condicional `if` executa seu corpo somente quando a condição for `true`.
Go não tem o conceito de valores truthy ou falsy, então a condição precisa ser do tipo `bool`.
Expressões como `if mySlice { ... }` ou `if 1 { ... }` são erros de compilação.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Use `else if` para verificar condições adicionais e `else` como alternativa quando nenhuma delas for atendida.
As condições são avaliadas de cima para baixo, e apenas o primeiro bloco cuja condição for verdadeira é executado.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Uma condicional `if` também pode incluir uma instrução curta de inicialização.
As variáveis declaradas dessa forma só existem no escopo de toda a cadeia `if`/`else`.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
