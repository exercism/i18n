# Introdução

Muitos tipos de membros de struct e de classe (sendo os campos a principal exceção) podem usar a sintaxe de membro com corpo de expressão. Definir um membro com uma expressão costuma produzir um código mais conciso e legível do que blocos/instruções tradicionais.

Métodos e propriedades somente leitura estão entre os membros que podem ser definidos com corpo de expressão.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
