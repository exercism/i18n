# Introdução

Um dicionário (`dict`) em Python é uma estrutura de dados que associa _chaves_ [hashable][term-hashable] a _valores_ e é conhecido em outras linguagens de programação como uma [tabela hash][hashtable-wikipedia] redimensionável, hashmap ou [array associativo][associative-array].
Os dicionários são o único [tipo de mapeamento][mapping-types-dict] nativo do Python.


As `keys` precisam ser hashable e únicas em todo o dicionário.
Os tipos de chave podem incluir `number`, `str` ou `tuple` (de valores _imutáveis_).
Eles não podem conter estruturas de dados _mutáveis_, como `list`, `dict` ou `set`.
A partir do Python 3.7, a ordem das chaves de um `dict` é garantida como a ordem em que as entradas são inseridas.

Os `values` podem ser de qualquer tipo ou estrutura de dados.
Os valores também podem ser aninhados _de forma arbitrária_, então podem incluir listas de listas, subdicionários e outras estruturas de dados personalizadas ou compostas.

Dada uma `key`, os dicionários conseguem recuperar um `value` em tempo constante (em média), _independentemente do número de entradas_.
Em comparação com a busca de um valor dentro de uma `list` ou `array` (_sem saber a posição do `index`_), um `dict` usa muito mais memória, mas tem uma recuperação muito rápida.

Os dicionários são especialmente úteis em cenários em que a coleção de itens é grande e precisa ser acessada e atualizada com frequência.
