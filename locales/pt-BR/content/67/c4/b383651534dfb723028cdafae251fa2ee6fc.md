# Instruções

Aprenda o básico sobre tabelas internas em ABAP.

Sua classe tem uma tabela interna chamada `initial_data`. Ela tem três colunas: `GROUP`, `NUMBER` e `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## Passo 1

Sua primeira tarefa é completar o método `fill_itab` e colocar 6 registros nessa tabela com os seguintes valores:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## Passo 2

Em seguida, implemente o método `add_to_itab` para adicionar um registro ao final da tabela interna com o seguinte valor:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## Passo 3

Agora ordene a tabela interna no método `sort_itab`, com a coluna `GROUP` em ordem alfabética e a coluna `NUMBER` em ordem decrescente.

## Passo 4

No método `search_itab`, procure na tabela ordenada e retorne o índice do registro que tem o valor 6 na coluna `NUMBER`.
