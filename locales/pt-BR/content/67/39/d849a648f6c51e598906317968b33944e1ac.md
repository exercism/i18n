# Dicas

## 1. Determinar quanto tempo leva para preparar um pedido

- Um [laço for-in][for-in-loops] pode ser usado para olhar uma bebida de cada vez.
- Você pode usar uma instrução `switch` para retornar o tempo que leva para preparar cada tipo de bebida.

## 2. Repor seu estoque de gomos de limão

- [Arrays têm um método][array-docs] para remover o primeiro elemento de um array e retorná-lo a você.
- Você precisa fazer uma cópia em uma variável dos parâmetros da função se quiser modificá-los.

## 3. Terminar seu turno

- Se sabemos que ainda temos tempo no nosso turno, sabemos que teremos que preparar pelo menos um pedido.
    Isso é um bom indício de que um [laço repeat-while][repeat-loops] seria uma boa escolha.
- [Arrays têm um método][array-docs] para remover o primeiro elemento de um array e retorná-lo a você.

## 4. Acompanhar certos pedidos

- Um [laço for-in][for-in-loops] pode ser usado para trabalhar em cada pedido de cada vez.
- A decomposição de tuplas pode ser usada para nomear os elementos individuais da tupla no laço for-in.
- Você pode usar [instruções de transferência de controle][control-transfer] para pular para a próxima iteração do laço nas bebidas com as quais não nos importamos.
