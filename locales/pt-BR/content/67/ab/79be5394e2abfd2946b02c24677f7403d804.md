# Sobre

Elm é uma linguagem puramente funcional, então não há instruções, só expressões, e as funções são sempre uma única expressão.

Isso incentiva funções pequenas e simples e, em geral, é uma coisa boa, mas às vezes as funções são inevitavelmente mais complexas, e precisamos de uma forma de garantir que elas possam ser escritas de maneira elegante.

É aí que entram as expressões `let`. Elas têm duas partes: uma seção `let`, onde você pode criar quantas definições precisar, e uma seção `in`, que é uma única expressão que pode usar essas definições.

Em termos de computação, o `let` cria um escopo que é local à expressão dentro do `in`.

A expressão `let` é útil em algumas situações:

- Para simplificar expressões
- Para dar nome aos resultados de expressões intermediárias
- Para dividir uma expressão em partes menores quando ela começa a ficar grande

Você pode fazer a maioria das coisas dentro de uma expressão `let`, inclusive desestruturação; no entanto, o seguinte não é permitido:

- Tipos personalizados
- Alias de tipo
- Sombreamento de nomes (você não pode redefinir nem reutilizar um nome que já está no escopo)

## Simplificando expressões

Esta expressão soma os cubos de 3 números, mas é difícil de ler, e seria fácil o cálculo sair diferente para os diferentes números.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

Podemos definir uma função `cube` em uma expressão `let` para deixar o cálculo mais simples, mais expressivo e mais seguro. Essa função poderia ter uma anotação de tipo, mas em código Elm idiomático isso é relativamente raro.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Dando nome aos resultados de expressões intermediárias

Este código define sideArea e topArea para deixar o cálculo mais simples e mais expressivo.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Dividindo uma expressão grande

Este código cria um padrão inicial para o [Jogo da Vida](https://playgameoflife.com/) (um exercício de exemplo comum de programação).

Não é importante entender exatamente como ele funciona, mas é de se esperar que fique claro que ele seria muito grande se fosse escrito como uma única expressão, sem o `let`.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
