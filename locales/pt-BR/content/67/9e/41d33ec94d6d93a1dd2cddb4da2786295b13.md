# Sobre

Em Haxe, é possível definir uma hierarquia de classes usando _herança_, que permite que uma classe derivada (`Car`) herde o comportamento e os dados da sua classe pai (`Vehicle`).

Na classe pai, você pode:

- Métodos que podem ser sobrescritos
- Métodos abstratos que precisam ser implementados pelas classes derivadas

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Se a classe pai tiver um construtor, usamos `super()` para chamá-lo:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
