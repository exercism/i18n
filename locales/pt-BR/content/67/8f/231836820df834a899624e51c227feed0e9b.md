# Como usar Markdown na mentoria

Você pode usar Markdown nos seus comentários de mentoria no GitHub.
Isso permite incorporar trechos de código, adicionar títulos, negrito, itálico, listas etc., além de citar frases anteriores.

Também permitimos alguns elementos do "GitHub-flavoured Markdown" no Exercism, mais especificamente realce de sintaxe, tabelas e tachado.

Se você ainda não conhece o Markdown nem os extras do GitHub, recomendamos ler o [guia de Markdown do GitHub](https://guides.github.com/features/mastering-markdown/).
