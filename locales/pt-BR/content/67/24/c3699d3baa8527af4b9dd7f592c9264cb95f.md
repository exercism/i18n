# Sobre

Crystal é uma linguagem de programação compilada e orientada a objetos.
Estes são alguns dos objetivos da linguagem:

- Sintaxe inspirada no Ruby.

- Verificação estática de tipos, mas sem precisar especificar o tipo de variáveis ou argumentos de métodos.

- Poder chamar código C escrevendo bindings para ele em Crystal.

- Ter avaliação e geração de código em tempo de compilação, para evitar código boilerplate.

- Compilar para código nativo eficiente.
