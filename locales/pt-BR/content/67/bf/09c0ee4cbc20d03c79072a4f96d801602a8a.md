# Testes

## Rodar todos os testes

Existe um script Raku com a extensão `.rakutest`, que será usado para testar sua solução.
Você pode rodar os testes com o comando:

`prove6`

Antes de você começar o exercício, a saída provavelmente será parecida com isto:

```
# Failed test 'Say Hi!'
# at t/hello-world.rakutest line 6
# expected: "Hello, World!"
#  matcher: 'infix:<eq>'
#      got: "Goodbye, Mars!"
# You failed 1 test of 1
t/hello-world.rakutest ... Dubious, test returned 1
Failed 1/1 subtests
```

Você vai precisar modificar o módulo com a extensão `.rakumod`, que fica no diretório `lib/`, e escrever uma solução que passe nos testes.
Quando os testes passarem, a saída do comando acima provavelmente será parecida com isto:

```
t/hello-world.rakutest ... ok
All tests successful.
```

## Parar após a primeira falha

Se você definir a variável de ambiente `RAKU_TEST_DIE_ON_FAIL`, o executor de testes vai parar após a primeira falha. Por exemplo:

No Linux / OS X:

```bash
export RAKU_TEST_DIE_ON_FAIL=1
# now all the follow up runs will stop at the first failure
prove6
# until we do
unset RAKU_TEST_DIE_ON_FAIL
# or you can use it for one run like this:
RAKU_TEST_DIE_ON_FAIL=1 prove6
```

Ou no Windows:

```
SET RAKU_TEST_DIE_ON_FAIL=1
REM now all the follow up runs will stop at the first failure
prove6
REM until we do
set RAKU_TEST_DIE_ON_FAIL=
```

Para mais informações, veja o
[capítulo sobre testes da documentação do Raku](https://docs.raku.org/language/testing.html).

## Solução de problemas

```
===SORRY!===
Could not find JSON::Fast
```

Todos os módulos usados na trilha de Raku vêm incluídos com o Rakudo Star.
Se você receber uma mensagem de erro como a acima ao tentar rodar um teste, vai precisar garantir que tem a distribuição mais recente do Rakudo Star ou instalar o módulo você mesmo usando um gerenciador de pacotes.
Veja a [documentação do Raku sobre módulos](https://docs.raku.org/language/modules#Looking_for_and_installing_modules.) para saber como instalar módulos.
