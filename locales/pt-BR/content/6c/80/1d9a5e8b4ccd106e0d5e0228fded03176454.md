# Sobre

Clojure usa o tipo subjacente `java.lang.Character`, que é uma quantidade de 16 bits para representar os menores componentes endereçáveis de um texto.
Vários `char`s podem compor uma string como `"word"`, ou os `char`s podem ser
processados de forma independente. Seus literais são escritos assim: `\a \b \c`.

Os `char`s do Clojure suportam a codificação UTF-16 Unicode, então, além do conjunto de caracteres latinos,
praticamente todos os sistemas de escrita em uso no mundo podem ser representados,
por exemplo, a letra grega `'β'`.

Existem muitos métodos de biblioteca para inspecionar e manipular `char`s. Eles
podem ser acessados por interop como os métodos da classe `Character`. O Clojure também inclui uma biblioteca de utilitários de string integrada, `clojure.string`, que oferece muitas funções poderosas para operar sobre caracteres.
