# use interpolação de string em vez de string format

Uma abordagem mais comum em C# é usar [interpolação de string](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/), em vez de usar `string.Format` para montar uma string dinamicamente.

Repare que a interpolação de string é apenas um truque do compilador, também conhecido como açúcar sintático. Isso significa que, quando uma expressão de interpolação de string é compilada, o compilador na verdade a converte em uma chamada a `string.Format`. O benefício de usar interpolação de string é, portanto, puramente visual.
