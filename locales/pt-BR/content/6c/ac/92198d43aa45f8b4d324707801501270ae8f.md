# Instruções

Neste exercício, você vai escrever código para imprimir crachás de identificação para funcionários de uma fábrica.

## 1. Imprimir um crachá para um funcionário

Os funcionários têm um ID, um nome e o nome do departamento. O rótulo do crachá de um funcionário tem o seguinte formato: `"[id] - name - DEPARTMENT"`. Implemente o método (_static_) `Badge.Print()` para retornar o rótulo do crachá de um funcionário:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Repare que o departamento deve aparecer em maiúsculas no rótulo.

## 2. Imprimir um crachá para um funcionário novo

Por causa de uma peculiaridade do sistema, às vezes os funcionários novos ainda não têm um ID quando começam a trabalhar na fábrica. Como o crachá é obrigatório, eles recebem um crachá temporário sem o prefixo do ID. Modifique o método (_static_) `Badge.Print()` para aceitar funcionários novos que ainda não têm um ID:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprimir um crachá para o dono

Até o dono da fábrica precisa usar um crachá o tempo todo. No entanto, o dono não tem um departamento. Nesse caso, o rótulo deve imprimir `"OWNER"` no lugar do nome do departamento. Modifique o método (_static_) `Badge.Print()` para imprimir o rótulo do dono:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Repare que é possível que o dono também seja um funcionário novo:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
