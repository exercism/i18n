# Intervalos

[Intervalos][range] representam um intervalo entre dois valores.
Os tipos mais comuns que dão suporte a intervalos são `Integer` e `String`.
Eles podem ser usados para muitas coisas, como criar uma coleção rapidamente, fatiar strings, verificar se um valor está em um intervalo e iterar.
Eles são criados com o operador de intervalo `..` ou `...` (inclusivo e exclusivo, respectivamente).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

O motivo de existirem dois operadores de intervalo é permitir criar intervalos que incluem ou excluem o valor final, o que pode ser útil, por exemplo, ao trabalhar com índices que começam em zero.

Também é possível criar intervalos usando o construtor `Range`, `new`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Quando você cria um intervalo em Ruby com os operadores `..` ou `...` e quer chamar um método nele, precisa envolver o intervalo entre parênteses.
Isso acontece porque, caso contrário, o método será chamado no segundo argumento do operador de intervalo.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Obtendo substrings

Quando você quer fatiar uma string, pode usar o operador de intervalo para obter uma substring.
Ou seja, criando um intervalo com o índice inicial e o final da substring.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Você também pode usar índices negativos para pegar a substring a partir do fim da string.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Métodos de intervalo

Os intervalos têm, sim, um conjunto de métodos que podem ser usados para trabalhar com eles.
Por exemplo, esses métodos podem ser usados para obter a soma de todos os valores do intervalo ou verificar se o intervalo inclui um valor.

| Método                  | Descrição                                                               | Exemplo                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Retorna a soma de todos os valores do intervalo                         | `(1..5).sum # => 15`            |
| [`size`][size]          | Retorna o tamanho do intervalo                                          | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Retorna `true` se o intervalo inclui o valor dado; caso contrário, `false` | `(1..5).include?(3) # => true` |

## Intervalos sem fim e sem início

Um intervalo pode ser sem fim e sem início.
Um intervalo sem fim ou sem início tem o valor inicial ou final igual a `nil`, mas, ao definir o intervalo, o `nil` pode ser omitido.

Usar intervalos sem início e sem fim é útil quando você quer, por exemplo, fatiar uma string desde o início ou até o fim.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
Se não for usado em uma coleção, o intervalo sem fim pode gerar uma sequência sem fim, caso não seja usado com cuidado.
~~~~

## Intervalos com strings

Strings também podem ser usadas em intervalos e permitem obter um intervalo de strings entre duas strings.
O comportamento pode ser um pouco inesperado com certas strings, então use com cuidado.

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
