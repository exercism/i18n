# Anexo das instruções

## Implementação

Os testes exigem um construtor que recebe um array. A implementação interna do seu conjunto personalizado pode usar outras estruturas de dados, mas talvez você precise implementar um construtor externo que receba exatamente um array para que os testes passem.

Alguns métodos têm um operador unicode equivalente. Por exemplo, `intersect(CustomSet([1, 2, 3, 4]), CustomSet([]))` é equivalente a `CustomSet([1, 2, 3, 4]) ∩ CustomSet([])`.
