# Introdução

Muitas linguagens de programação têm tipos numéricos específicos para representar diferentes tipos de números, mas o JavaScript tem apenas dois:

- `number`: um tipo de dado numérico no formato de ponto flutuante de 64 bits com precisão dupla (IEEE 754).
  Alguns exemplos são `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` e `500000`.
- `bigint`: um tipo de dado numérico que consegue representar _inteiros_ no formato de precisão arbitrária.
  Alguns exemplos são `-12n`, `0n`, `4n` e `9007199254740991n`.

Se você precisar de [precisão arbitrária][ref-arbitrary-precision] ou trabalhar com números extremamente grandes, use o tipo `bigint`.
Caso contrário, o tipo `number` provavelmente é a melhor opção.

## Arredondamento

Existe um objeto global embutido chamado `Math` que oferece várias [funções de arredondamento][ref-math-object-rounding]. Por exemplo, você pode arredondar números decimais para baixo (`floor`) ou para cima (`ceil`) até o número inteiro mais próximo.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```
