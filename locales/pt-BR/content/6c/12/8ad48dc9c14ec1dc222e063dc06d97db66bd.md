# Complemento das instruções

Este exercício apresenta alguns conceitos que você talvez ainda não tenha visto:

## Namespace definido pelo usuário

Todas as palavras em 8th pertencem a um namespace, por exemplo, `a:new` se refere à palavra `new` no namespace `a`.
Também é possível definir namespaces personalizados, que é o que fazemos no topo do arquivo `circular-buffer.8th`:

```8th
ns: cb
```

Isso significa que todas as palavras dentro desse arquivo podem ser acessadas via `cb:<word>`, o que é uma ótima forma de agrupar funcionalidades relacionadas.

Para mais informações, confira a documentação de [namespaces][namespaces].

## Exceções

Espera-se que as palavras `read` e `write` lancem uma exceção quando forem chamadas em um buffer circular com um estado inválido.
Para mais informações, confira a documentação de [exceções e tratamento de erros][exceptions-and-error-handling].

## Objetos

Embora você seja livre para implementar o buffer circular como quiser, você pode considerar usar o [suporte a objetos][objects] do 8th.
