# Instruções

No seu laboratório de pesquisa de DNA, você vem trabalhando em várias formas de comprimir seus dados de pesquisa para economizar espaço de armazenamento. Uma pessoa da equipe sugere converter os dados de DNA para uma representação binária:

| Ácido nucleico | Código |
| -------------- | ------ |
| um espaço      | `0000` |
| A              | `0001` |
| C              | `0010` |
| G              | `0100` |
| T              | `1000` |

Você reflete sobre isso, já que pode reduzir pela metade o custo de armazenamento necessário, mas às custas da legibilidade para humanos. Você decide escrever um módulo para codificar e decodificar seus dados e medir a economia.

## 1. Codifique o ácido nucleico em valor binário

Implemente `encode_nucleotide/1` para receber o code point do ácido nucleico e retornar o valor inteiro do código codificado.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. Decodifique o valor binário para o ácido nucleico

Implemente `decode_nucleotide/1` para receber o valor inteiro do código codificado e retornar o code point do ácido nucleico.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. Codifique uma charlist de DNA

Implemente `encode/1` para receber uma charlist que representa ácidos nucleicos e lacunas e retornar uma bitstring com os dados codificados.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. Decodifique uma bitstring de DNA

Implemente `decode/1` para receber uma bitstring que representa ácidos nucleicos e lacunas e retornar os dados decodificados como uma charlist.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
