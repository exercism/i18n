# Anexo às instruções

## Dicas

Os testes unitários fornecem exemplos de palavras. Tente agrupar as consoantes independentemente das combinações específicas de consoantes usadas nos testes unitários.

Este exercício trabalha com dados textuais. Por razões históricas, o tipo `String` do Haskell é sinônimo de `[Char]`, uma lista de caracteres. Para lidar com dados textuais de forma mais eficiente, dá para usar o tipo `Text`.

Como extensão opcional deste exercício, você pode

- Ler sobre [tipos de string](https://haskell-lang.org/tutorial/string-types) em Haskell.
- Adicionar `- text` à sua lista de dependências em package.yaml.
- Importar `Data.Text` [da seguinte forma](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

      import qualified Data.Text as T
      import           Data.Text (Text)

- Agora você pode escrever, por exemplo, `translate :: Text -> Text` e se referir aos combinadores de `Data.Text` como, por exemplo, `T.isSuffixOf`.
- Consultar a documentação de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),

Esta parte é totalmente opcional.
