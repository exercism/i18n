# Testes

## Executando os testes

Para rodar os testes, execute o seguinte comando:

```bash
dotnet test
```

## Resolvendo o exercício

Resolver um exercício significa fazer com que todos os seus testes passem. Por padrão, apenas um teste (o primeiro) é executado quando você roda os testes. Isso é intencional, pois permite que você foque em fazer só esse teste passar. Depois que ele passar, você pode habilitar o próximo teste removendo `Skip = "Remove this Skip property to run this test"` do atributo `[<Fact>]` ou `[<Theory>]` do teste. Quando todos os testes estiverem habilitados e sua implementação fizer todos eles passarem, você terá resolvido o exercício!

Para ajudar você a começar, cada exercício vem com um arquivo de implementação stub. Você pode usar esse arquivo como ponto de partida para construir sua solução. Fique à vontade para remover ou alterar esse arquivo se achar que é a coisa certa a fazer.

## Usando pacotes

Você deve conseguir resolver a maioria dos exercícios sem usar nenhum pacote externo. No entanto, nos exercícios em que você quiser usar um pacote externo, você pode adicioná-lo ao seu projeto rodando o seguinte comando:

```bash
dotnet add package [package-name]
```
