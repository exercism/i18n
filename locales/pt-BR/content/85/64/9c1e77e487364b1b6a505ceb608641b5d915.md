# Instruções

Neste exercício, você vai escrever código para ajudar um freelancer a se comunicar com os clientes sobre os preços de determinados projetos.
Você vai escrever algumas funções utilitárias para calcular rapidamente os custos para os clientes.

```exercism/note
A variável `ratePerHour` e a função `dayRate` têm a ver com dinheiro.
As unidades de medida são dinheiro por unidade de tempo: horas e dias, respectivamente.
```

## 1. Calcule o valor diário a partir de um valor por hora

Um cliente entra em contato com o freelancer para saber seus valores.
O freelancer explica que **_trabalha 8 horas por dia._**
No entanto, ele só conhece o valor por hora do projeto.
Ajude a estimar o valor diário a partir de um valor por hora.

```javascript
dayRate(89);
// => 712
```

O valor diário não precisa ser arredondado nem convertido para uma precisão "fixa".

## 2. Calcule o número de dias de trabalho a partir de um orçamento fixo

Certo dia, um gerente de projeto convida o freelancer para trabalhar em um projeto com orçamento fixo.
Com o orçamento fixo e o valor por hora do freelancer, ajude a calcular quantos dias de trabalho o orçamento cobre antes de acabar.
O resultado _deve_ ser **arredondado para baixo** para o número inteiro mais próximo.

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. Calcule o valor com desconto para projetos grandes

Muitas vezes, o freelancer é contratado por clientes para projetos que duram vários meses.
Nesses casos, ele decide oferecer um desconto para cada mês completo, e os dias restantes são cobrados pelo valor diário.
Seu excelente equilíbrio entre vida pessoal e trabalho faz com que você trabalhe apenas 22 dias em cada mês, então **_cada mês tem 22 dias faturáveis._**
Ajude a estimar o custo desse tipo de projeto, dado um valor por hora, o número de dias faturáveis que o projeto tem e uma taxa de desconto mensal.
O desconto é sempre passado como um número, em que `42%` vira `0.42`. O resultado _deve_ ser **arredondado para cima** para o número inteiro mais próximo.

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
