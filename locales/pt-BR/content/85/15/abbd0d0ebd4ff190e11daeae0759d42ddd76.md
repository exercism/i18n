# Anexo às instruções

## Registradores

| Registrador | Uso          | Tipo    | Descrição                              |
| ----------- | ------------ | ------- | -------------------------------------- |
| `$a0`       | entrada      | endereço | primeira cor como string terminada em nulo  |
| `$a1`       | entrada      | endereço | segunda cor como string terminada em nulo |
| `$a2`       | entrada      | endereço | terceira cor como string terminada em nulo  |
| `$a3`       | entrada/saída | endereço | string de saída terminada em nulo          |
| `$t0-9`     | temporário   | qualquer | usado para armazenamento temporário             |
