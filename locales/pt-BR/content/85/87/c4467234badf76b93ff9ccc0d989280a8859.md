# Introdução

Um *disposable* é qualquer coisa que mantém um recurso do sistema operacional (um arquivo aberto, um socket, um lock apoiado em tabela hash) e que precisa ser liberado quando você terminar de usá-lo. O vocab [`destructors`][destructors] do Factor envolve esses recursos em um pequeno framework, para que a limpeza aconteça mesmo quando uma exceção desenrola a pilha.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` executa a quotation com o recurso e o libera na saída. Para mais de um recurso, abra um escopo com `with-destructors` e registre cada um com `&dispose` (libera na saída normal *e* em caso de erro) ou `|dispose` (libera apenas em caso de erro).

Uma classe entra no framework estendendo `disposable` e implementando a palavra genérica `dispose*`. O framework a chama uma vez, e só uma vez, por objeto. A palavra pública usada por quem chama é `dispose`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
