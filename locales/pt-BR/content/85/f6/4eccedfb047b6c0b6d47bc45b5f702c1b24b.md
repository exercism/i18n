# Anexo das instruções

## Implementação

Defina uma única func Go, Solve, que recebe uma string de quebra-cabeça que pode ter zero ou mais operadores + e um operador ==; Solve deve tentar resolver o quebra-cabeça de alfamética e retornar um map com todas as substituições de letras, tanto para o quebra-cabeça quanto para a solução da adição.

Use a seguinte assinatura para a func Solve:

```go
func Solve(puzzle string) (map[string]int, error) {
```

Solve deve retornar um erro se não houver solução para o quebra-cabeça dado.

Um exemplo de quebra-cabeça e a solução retornada:

```go
Solve("SEND + MORE == MONEY")
```

retornaria

```go
map[string]int{"M":1, "O":0, "N":6, "E":5, "Y":2, "S":9, "D":7, "R":8}, nil
```

```text
  S E N D
  M O R E +
-----------
M O N E Y
```

Substituindo essas letras por números válidos, temos:

```text
  9 5 6 7
  1 0 8 5 +
-----------
1 0 6 5 2
```
