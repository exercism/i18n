# Rodando os testes

Para rodar a suíte de testes, execute o seguinte comando:

```bash
stack test
```

#### Se você receber uma mensagem de erro como esta...

```
No .cabal file found in directory
```

ou

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

Você provavelmente está rodando uma versão antiga do Stack e precisa atualizá-la. Tente rodar:

```bash
stack upgrade
```

Ou veja outras opções para atualizar na [documentação do Stack](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade).

#### Caso contrário, se você receber uma mensagem de erro como esta...

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

Basta fazer o que ela diz, e ele vai baixar e instalar a versão correta do compilador:

```bash
stack setup
```

# Rodando o *GHCi*

Se você quiser brincar com a sua solução no GHCi, é só rodar o comando:

```bash
stack ghci
```
