# Instruções

Você trabalha no posto de segurança de uma estação de pesquisa. Os
funcionários usam *crachás* cujos códigos seguem um formato rígido, o
registro de acesso está cheio desses códigos misturados a texto comum,
e o registro precisa ser limpo antes de poder ser compartilhado.
Expressões regulares são a ferramenta certa para cada uma dessas
tarefas.

Um código de crachá válido é **duas letras maiúsculas, um hífen e, em
seguida, quatro dígitos**, por exemplo `NS-1024`.

## 1. Verifique um código de crachá

Defina `valid-badge?`, que recebe uma string de crachá e retorna `t`
quando a string *inteira* é um código de crachá válido e `f` caso
contrário.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. Extraia todos os códigos de uma linha do registro

Defina `badge-codes`, que recebe uma linha do registro de acesso e
retorna uma sequência com todos os códigos de crachá que aparecem nela,
na ordem.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. Conte os dígitos de um código

Defina `digit-count`, que recebe uma string e retorna quantos dígitos
ela contém.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. Oculte as senhas

Às vezes, as linhas do registro gravam uma senha como `pass=` seguido
do segredo (qualquer sequência de caracteres que não sejam espaços).
Defina `redact`, que recebe uma linha e a retorna com cada senha desse
tipo substituída por `pass=****`.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
