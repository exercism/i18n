# Sobre

Recursão é uma forma de repetir código em uma função fazendo com que a função chame a si mesma.
É outra forma de fazer laços ou iterar. Assim como nos laços, a função precisa testar uma expressão Boolean para saber quando parar.
Diferente dos laços, uma recursão que nunca termina não roda infinitamente.
Os valores usados em cada chamada da função podem ficar no próprio frame dela na pilha.
Se a quantidade de chamadas de função ocupar mais espaço do que a pilha tem, isso resulta em um erro de estouro de pilha.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Isso vai imprimir

```
The number is 1
The number is 2
After recursion
```

Existem situações que ficam mais legíveis e/ou mais fáceis de entender quando expressas com recursão do que com laços.


## Chamada de cauda

Uma chamada de cauda acontece quando a última instrução de uma função apenas chama a própria função e nada mais.

A chamada de cauda é uma forma específica de recursão que pode permitir ao compilador otimizar a recursão para um laço no código compilado.
Isso dá o melhor dos dois mundos: a legibilidade da recursão com o desempenho de um laço.
A compilação da recursão em um laço é chamada de `tail call elimination` ou `tail call optimization.`

Quando uma chamada de cauda é compilada para um laço, um novo frame de pilha não é criado a cada chamada da função.
O endereço da função, da chamada original, recebe os valores atualizados, economizando espaço na pilha e melhorando o desempenho.

Este exemplo não é uma chamada de cauda, pois a função soma 1 ao resultado da chamada a si mesma

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

Isso vai imprimir

```
The number is 1
The number is 2
j is 3 after recursion
```

Para refatorar isso em uma chamada de cauda, transforme `j` em um parâmetro de `printIncrement`

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

Você pode achar que uma chamada de cauda é mais fácil de entender do que uma chamada recursiva que não é uma chamada de cauda.
No entanto, os compiladores geralmente não garantem que todas as chamadas de cauda serão otimizadas.
Ao usar recursão, é sempre importante saber que não haverá tantas iterações a ponto de a pilha estourar.
