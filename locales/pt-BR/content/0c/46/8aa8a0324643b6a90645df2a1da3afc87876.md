# Instruções

Você administra um cinema exclusivo.
Para assistir a um filme, as pessoas precisam comprar passes anuais e depois podem assistir aos filmes de graça.

Seu cinema mantém um registro de entradas.
Você quer usar esse registro para acompanhar quais membros usaram o passe anual neste mês.
Você também quer obter dados demográficos de idade dos seus clientes.
Você percebe que pode usar conjuntos para atingir esses objetivos.

## Conjuntos

Um conjunto é o tipo de dado perfeito para armazenar esse tipo de informação.

Um conjunto é um tipo de dado usado para armazenar valores distintos e únicos, sem uma ordem específica.
Distintos e únicos significa que um elemento está no conjunto ou não está; diferente de um array, ele não pode estar no conjunto mais de uma vez.
Conjuntos normalmente não têm ordem; se você listar os elementos de um conjunto, a ordem obtida pode ser diferente da ordem em que eles foram adicionados, ou até diferente da ordem que você obteve na listagem anterior!

Uma propriedade fundamental dos conjuntos é a verificação de pertinência: a capacidade de verificar se um conjunto contém um elemento.
As verificações de pertinência são essenciais para quase todos os usos de um conjunto.

Go não oferece um tipo de conjunto embutido.
É comum usar um `map[<type>]struct{}` ou um `map[<type>]bool` no lugar de um conjunto; assim como um conjunto, um `map` permite adicionar elementos distintos e únicos e oferece suporte a verificações de pertinência.

## 1. Um lugar para armazenar informações dos participantes

Para acompanhar a frequência e os dados demográficos de idade, você quer usar um conjunto.
Você não quer escrever conjuntos separados para nomes e idades; em vez disso, pode usar um conjunto genérico para os dois.
Defina um tipo `Set` como um `map[T comparable]struct{}` para armazenar os participantes.
Escreva uma função `NewSet[T comparable]()` que retorna um `Set[T]` vazio.

```go
names := NewSet[string]()
```

## 2. Acompanhando os participantes

Agora é hora de registrar as informações dos participantes.

Escreva um método `Add[T]()` que adiciona um elemento ao conjunto.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. Verificando os participantes

Agora que você tem um conjunto de participantes, pode verificar se determinados membros e dados demográficos de idade apareceram.
Escreva um método `Contains[T](element)` que retorna se um membro ou um dado demográfico de idade está no `Set`.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. Comparando os participantes

Outro mês passou e você tem um novo `Set` de dados demográficos de idade.
Seu gerente de marketing quer saber se os lançamentos deste mês mudaram quais dados demográficos de idade estão aparecendo.
Escreva um método `Equals[T](other)` que determina se dois conjuntos têm os mesmos elementos.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
