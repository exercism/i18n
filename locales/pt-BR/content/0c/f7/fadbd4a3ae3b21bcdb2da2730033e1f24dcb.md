# Letreiros personalizados

## História

Neste exercício, você vai escrever código para ajudar uma empresa de letreiros a criar mensagens personalizadas para as suas placas.

## Tarefas

Estas são tarefas de exemplo que se encaixam na história de uma pessoa projetando um letreiro personalizado:

- Criar um conjunto de strings úteis
- Criar um conjunto de caracteres úteis
- Combinar frases para montar mensagens
- Montar um letreiro de formatura
- Calcular o custo de um letreiro
