# Anexo de instruções

## Instruções específicas da trilha

### Memória reservada

Os bytes de 64 a 447 da memória linear são reservados para a string de entrada.

A string de entrada pode ser modificada no lugar, se você quiser.

### Formato de entrada

Cada linha contém o nome do primeiro time, depois um ponto e vírgula `;`, depois o nome do segundo time, outro ponto e vírgula `;`, o resultado da partida (`"win"`, `"draw"`, `"loss"`) e, por fim, uma quebra de linha `\n`.
