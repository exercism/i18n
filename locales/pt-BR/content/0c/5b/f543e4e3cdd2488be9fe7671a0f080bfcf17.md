# Sobre

ClojureScript é um compilador para Clojure que tem o JavaScript como alvo. Ele emite código JavaScript compatível com o modo de compilação avançado do compilador otimizador Google Closure.

## Por que Clojure?

Clojure é uma linguagem de programação dinâmica e de propósito geral que dá suporte ao desenvolvimento interativo. Clojure é uma linguagem de programação funcional com um rico conjunto de estruturas de dados imutáveis e persistentes. Como um dialeto de Lisp, tem uma filosofia de código como dados e um poderoso sistema de macros.

## Por que JavaScript?

A disseminação do navegador e dos aplicativos web deu ao JavaScript um alcance exclusivo, sem igual em qualquer outra linguagem. Por causa dessa importância, os motores JavaScript também vêm recebendo muita pesquisa e otimização, o que permite ao JavaScript competir em desempenho com plataformas muito mais consolidadas, como a JVM.

## Por que Google Closure?

O Google, que fornece alguns dos aplicativos web cliente-servidor mais complicados em uso hoje, investiu pesadamente na criação da biblioteca Closure e do compilador Closure. Os dois trabalham juntos para tornar possível a otimização de todo o programa, gerando programas com tempos de carregamento mínimos mesmo ao usar muitas bibliotecas.

## Oportunidade

O ClojureScript combina o alcance da plataforma JavaScript, a flexibilidade e o desenvolvimento interativo do Clojure e a otimização de todo o programa do Google Closure para oferecer a linguagem mais poderosa para programar para a web.
