# Introdução

Em Go, uma `struct` é uma sequência de elementos nomeados chamados _campos_; cada campo tem um nome e um tipo.
O nome de um campo deve ser único dentro da `struct`.
As structs podem ser comparadas com _classes_ no paradigma de Programação Orientada a Objetos.

## Definindo uma struct

Você cria uma nova struct usando as palavras-chave `type` e `struct` e define explicitamente o nome e o tipo dos campos.
Por exemplo, aqui definimos a struct `Shape`, que guarda o nome de uma forma e o seu tamanho:

```go
type Shape struct {
    name string
    size int
}
```

Os nomes de campos em structs seguem a convenção do Go: campos cujo nome começa com letra minúscula só são visíveis para código no mesmo pacote, enquanto os que começam com letra maiúscula são visíveis em outros pacotes.

## Criando instâncias de uma struct

Depois de definir a `struct`, você precisa criar uma nova instância definindo os campos pelo nome do campo, em qualquer ordem:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Para ler ou modificar os campos de uma instância, use a notação `.`:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Os campos que não tiverem um valor inicial atribuído terão o valor zero.
Por exemplo:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Você pode criar uma instância de uma `struct` sem usar os nomes dos campos, desde que defina os campos _na ordem_:

```go
s := Shape {
	"Oval",
	20,
}
```

No entanto, essa sintaxe é considerada _código frágil_, pois pode quebrar quando um campo é adicionado, especialmente se o novo campo for de um tipo diferente.
No exemplo a seguir, adicionamos um campo extra à `Shape`:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## Funções `New`

Às vezes é bom ter funções que nos ajudam a criar instâncias de struct.
Por convenção, essas funções geralmente se chamam `New` ou têm nomes que começam com `New`, mas, como são apenas funções comuns, você pode dar a elas qualquer nome que quiser.
Elas podem lembrar construtores de outras linguagens, mas em Go são apenas funções comuns.

No exemplo a seguir, uma dessas funções `New` é usada para criar uma nova instância de `Shape` e definir automaticamente um valor padrão para o `size` da forma:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Usar funções `New` pode trazer as seguintes vantagens:

* validação dos valores fornecidos
* tratamento de valores padrão
* como as funções `New` geralmente são declaradas no mesmo pacote das structs que inicializam, elas podem inicializar até campos privados da struct

Para se aprofundar nesse tipo, você pode consultar estes recursos: [Go by Example: Structs][go-by-example-structs], [A Tour of Go: Structs][tour-of-go-structs] ou [Structures in Go (structs)][medium-structures-in-go]

## O `new` embutido

Outra forma de criar uma nova instância de uma struct é usar o `new` embutido:

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

Neste exemplo, `new` cria uma instância da struct `Shape` com todos os valores inicializados com o valor zero do seu tipo e retorna um ponteiro para ela.

~~~~exercism/note
Na maioria das vezes, você não verá novas instâncias de structs criadas com o `new` embutido.
Prefira sempre usar um literal de struct, uma função `New` personalizada ou qualquer outra função fornecida pelo pacote que possa ajudar você a construir uma struct.
Use o `new` embutido para criar novas instâncias de structs apenas em último caso.
~~~~
