# Introdução

Criar uma instância de uma classe é feito chamando seu _construtor_ pelo operador `new`. Um construtor é um método especial dentro de uma classe cujo objetivo é inicializar a classe. No Haxe, o método construtor tem o nome de `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Assim como os métodos normais, os construtores podem ter parâmetros. Esses parâmetros são (normalmente) armazenados em campos privados e acessados depois.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```
