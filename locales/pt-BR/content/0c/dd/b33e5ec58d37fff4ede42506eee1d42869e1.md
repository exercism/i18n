# não altere as assinaturas fornecidas

Como as instruções mencionam, você não deve modificar as assinaturas de `makeChest` e `makeTreasureChest`.
Elas devem permanecer exatamente assim:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
