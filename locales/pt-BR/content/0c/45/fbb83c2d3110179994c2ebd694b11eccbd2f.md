# Introdução

O Swift oferece instruções de transferência de controle para alterar o fluxo de execução de laços e de instruções switch.
Além de `return`, o Swift inclui `continue`, `break`, rótulos de laço e `fallthrough`.

## Continue

A instrução `continue` diz a um laço para parar de executar a iteração atual e começar a próxima iteração imediatamente.
Em um laço `while` ou `repeat-while`, ela salta direto para a verificação da condição.
Em um laço `for-in`, avança para o próximo elemento da sequência.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

A instrução `break` encerra imediatamente todo um laço ou uma instrução switch.
A execução recomeça na primeira linha de código depois do laço ou do switch.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Instruções rotuladas

Em laços aninhados, pode ser que você queira que `break` ou `continue` afetem um laço externo, e não o laço mais interno.
Você pode rotular um laço colocando um nome e dois-pontos antes dele (`labelName:`).
Depois, é só passar esse rótulo para `break` ou `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
