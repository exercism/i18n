Raku é uma linguagem de programação incrivelmente rica, flexível e poderosa.
Sua flexibilidade permite que quem programa escreva código expressivo, que combina com o próprio estilo.

Raku é uma linguagem grande, com muita profundidade para aprender, explorar e experimentar.
Este programa de estudos tem como objetivo cobrir os fundamentos para você começar.

A programação orientada a objetos está no coração do Raku, mas ele não impõe práticas de programação orientada a objetos.
Por causa de sua natureza orientada a objetos, este programa de estudos vai fazer referências frequentes a [objetos, classes e métodos][object-orientation].

## Variáveis

Para manter as coisas simples, no básico vamos usar apenas [variáveis][variables] escalares.

Variáveis escalares são [identificadores][identifiers] prefixados com o sigil `$`.

Variáveis escalares podem conter praticamente qualquer coisa e têm tipo padrão [`Any`][Any].

A maioria das variáveis que você usar vai precisar de uma [declaração][variable-declarator].
Por enquanto, fique com [`my`][my] e [`constant`][constant].

```raku
my $foo;
constant $BAR;
```

## Sub-rotinas

Uma sub-rotina é declarada com o declarador [`sub`][sub-declarator].

Uma declaração `sub` é seguida por um [identificador][identifiers] opcional, depois por uma [assinatura][signatures] opcional e depois por um [bloco][blocks].

As sub-rotinas podem ser exportadas (entre outras coisas) adicionando o trait [`is export`][exporting].

Uma sub-rotina pode ser chamada com um operador [pós-circunfixo `( )`][postcircumfix-()] no identificador.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## Operadores

Raku tem uma grande variedade de [operadores][operators].
Vamos usar alguns operadores matemáticos básicos do Raku, como `+` e `-`, nos exercícios do conceito básico.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

Você pode definir os seus próprios operadores no Raku facilmente, se quiser.
A maioria dos operadores embutidos também está disponível como sub-rotinas.

## Pacotes e módulos

Existem vários tipos de [pacotes][package-declarator] no Raku. No básico, vamos usar apenas `module`.

Para declarar um arquivo inteiro como um `module`, a declaração do módulo recebe o prefixo `unit`.

```raku
unit module Foo;

sub bar () { ... }
```

## Comentários

Raku tem comentários [de uma linha][single-line-comments] e [de várias linhas/embutidos][multi-line-comments].

Comentários de uma linha começam com `#` e seguem até o fim da linha.

Comentários de várias linhas/embutidos começam com uma cerquilha seguida por um backtick e um caractere Unicode de pontuação de abertura.
Eles terminam com um caractere de fechamento correspondente.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## Convenções de estilo

Os [identificadores][identifiers] de variáveis e sub-rotinas no Raku seguem o estilo `kebab-case`.
Constantes seguem o estilo `ALL-CAPS`.
Nomes de pacotes seguem o estilo `PascalCase`.
