# Cabeçalho fictício

## Usar `grep` ou não usar `grep`, eis a questão

Embora este exercício possa ser resolvido de forma trivial simplesmente passando os
argumentos para o `grep`, implemente este exercício usando apenas o bash. O objetivo
desta trilha do Exercism é aprender a usar os comandos internos do bash para resolver
problemas.

Para resolver este exercício, você vai precisar:

* analisar os argumentos da linha de comando: [`getopts`](https://stackoverflow.com/tags/getopts/info) é útil para isso.
* iterar sobre as linhas de um arquivo: é a [bash FAQ #1](https://mywiki.wooledge.org/BashFAQ/001)
* usar correspondência de expressões regulares: o bash consegue fazer isso com o operador `=~`
  dentro de [`[[ ... ]]`](https://www.gnu.org/software/bash/manual/bash.html#index-_005b_005b)
