# Instruções

Se você quer construir algo usando um Raspberry Pi, provavelmente vai usar _resistores_.
Para este exercício, você precisa saber duas coisas sobre eles:

- Cada resistor tem um valor de resistência.
- Resistores são pequenos, tão pequenos que, se você imprimisse o valor da resistência neles, seria difícil de ler.

Para contornar esse problema, os fabricantes imprimem faixas com código de cores nos resistores para indicar seus valores de resistência.
Cada faixa tem uma posição e um valor numérico.

As 2 primeiras faixas de um resistor têm um esquema de codificação simples: cada cor corresponde a um único número.

A terceira faixa é um multiplicador.

Neste exercício, você vai criar um programa útil para não precisar memorizar os valores das faixas.

Você encontra mais informações sobre a codificação de cores dos resistores no [artigo da Wikipédia sobre código de cores eletrônico][e-color-code].

## 1. Defina um vetor nomeado

As cores são codificadas da seguinte forma:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

Crie o vetor nomeado `resistor_bands`, que deve ter as cores como nomes e os números como valores.

## 2. Retorne o valor associado a uma faixa

Primeiro, você vai querer conseguir encontrar o valor único de qualquer faixa colorida.

Defina uma função `band_value(band)` que recebe uma `string` com a cor de uma faixa.
A função retorna o valor associado a essa cor.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. Retorne o valor associado a duas faixas

As duas primeiras faixas de um resistor se combinam para formar um único número.
Se as duas primeiras faixas tiverem números respectivos `m` e `n`, elas se combinam para formar o número único `mn`.

Defina uma função `two_band_value(bands)` que recebe um `vector` de `string`s com duas cores de faixa.
A função retorna o valor associado à combinação dessas duas cores.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. Retorne os ohms associados às três faixas

Por fim, você vai precisar encontrar a resistência total em ohms usando as duas primeiras faixas em conjunto com a terceira.
Para isso, você vai precisar encontrar o valor das duas faixas e um multiplicador.
O multiplicador pode ser pensado como quantos zeros são acrescentados ao valor das duas faixas.

Defina uma função `ohms(bands)` que recebe um `vector` de `string`s com três cores de faixa.
A função retorna a resistência em ohms associada à combinação das três cores.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
