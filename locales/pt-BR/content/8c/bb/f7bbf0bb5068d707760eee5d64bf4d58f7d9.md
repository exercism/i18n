# Instalação

## Instale o ambiente de execução do R
Acesse a [página inicial do CRAN](https://cran.r-project.org/). Lá você vai encontrar os links de download para Linux, Mac OSX e Windows. Baixe e execute o instalador do seu sistema operacional.

## Instale a IDE RStudio (recomendado)
O RStudio é um ambiente de desenvolvimento integrado (IDE) multiplataforma popular para programar em R (e também dá suporte a outras linguagens, como Python, JavaScript e Markdown). Usar o RStudio vai facilitar a escrita das suas soluções de código e a execução dos testes.

Baixe e instale a [versão estável atual do RStudio](https://www.rstudio.com/products/rstudio/download/). Ou, se preferir, pegue a [versão preview](https://www.rstudio.com/products/rstudio/download/preview/) de um lançamento que ainda está por vir.

## Instale a extensão do R para o Visual Studio Code (alternativa)
A extensão do R para o Visual Studio Code dá suporte a realce de sintaxe estendido, preenchimento automático de código, linting, formatação, interação com terminais do R, visualização de dados, gráficos, variáveis do workspace e páginas de ajuda, além de gerenciamento de pacotes e trabalho com documentos R Markdown.

Baixe e instale a [versão atual da extensão do R](https://code.visualstudio.com/docs/languages/r)

## Instale os pacotes R para executar os testes
O executor de testes das especificações é a biblioteca [`testthat`](https://github.com/hadley/testthat) do Hadley Wickham, uma escolha popular entre quem escreve pacotes R.

Para instalar essa biblioteca, digite o seguinte no console do RStudio (ou onde quer que você esteja usando o R).

```{R}
install.packages("testthat")
```

Embora seja pouco provável que você _precise_ instalar pacotes para resolver os problemas do Exercism, talvez você queira trazer um pacote utilitário de uso geral, como o [`tidyverse`](https://github.com/tidyverse/tidyverse), que combine com o seu estilo de programação. Para instalar e carregar um pacote como o `tidyverse`:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
