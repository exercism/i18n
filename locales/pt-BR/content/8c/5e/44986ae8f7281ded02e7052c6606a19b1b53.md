# Introdução

## Números

Haskell tem um tipo, `Num`, que é o tipo base para todos os tipos numéricos.
Existem quatro subtipos principais dentro do tipo Number: [`Int`][int], [`Integer`][integer], [`Double`][double] e [`Float`][float].

Existem dois tipos de inteiros em Haskell, que representam números inteiros.
`Int` é um inteiro de tamanho fixo, enquanto `Integer` é um inteiro de precisão arbitrária.
Um `Integer` armazena qualquer número, não importa o tamanho, até o limite da memória da sua máquina, enquanto um `Int` corresponde ao conjunto dos inteiros positivos e negativos que podem ser expressos em 32 ou 64 bits (garantido pelo menos de -2^29 a 2^29 - 1).

Repare que, ao escrever números negativos, você deve usar parênteses para evitar ambiguidade.

```haskell
1

(-1)
```

`Float` corresponde ao conjunto dos números reais, limitado pela precisão do computador.
As operações definidas sobre números geralmente funcionam com um tipo ou com o outro, mas não com os dois.
`Double` é um número de ponto flutuante com precisão dupla.

```haskell
10.5
```

### Convertendo entre inteiros e floats

Usar a função `toFloat` permite converter um `Int` ou um `Integer` em um `Float`.

```haskell
toFloat 1
-- -> 1.0
```

Também existe `fromIntegral`, que converte qualquer tipo numérico para o tipo numérico inferido que for necessário.

```haskell
fromIntegral 1
-- -> 1.0
```

Para converter um `Float` em um `Int`, você pode usar as funções [`round`][round], [`floor`][floor] ou [`ceiling`][ceiling].
A função `round` arredonda para o inteiro mais próximo, `floor` arredonda para baixo e `ceiling` arredonda para cima.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

### Operadores aritméticos

Você pode usar os [operadores aritméticos básicos][math] com os tipos numéricos.
Os operadores são `+`, `-`, `*`, `/` e `%`.
Ao usar esses operadores, os tipos dos números precisam ser iguais.
A função `fromIntegral` faz a conversão para que os tipos sejam iguais.

#### Adição, subtração e multiplicação

O operador `+` é usado para adição, o operador `-` é usado para subtração e o operador `*` é usado para multiplicação.

| Operador | Exemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

#### Divisão

A divisão é usada para dividir números.
O operador `/` é usado para divisão.
O resultado será sempre um número de ponto flutuante.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
Em algumas linguagens de programação, ao dividir por zero, o resultado é um erro.

Em Haskell, ao dividir por zero, o resultado é `Infinity` ou `-Infinity`.
A única exceção é dividir zero por zero, que resulta em `NaN` (Not a Number).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

### Divisão inteira

A divisão inteira é usada para dividir números inteiros e obter a parte inteira do resultado.
Haskell tem duas funções de divisão inteira, que diferem na forma de arredondar quando o resultado é negativo:

- `div` arredonda para baixo, na direção do infinito negativo.
- `quot` arredonda na direção do zero.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Dividir por zero na divisão inteira resulta em uma exceção.
Isso é diferente da divisão normal.
~~~~

#### Resto

O resto de uma divisão inteira pode ser obtido com `mod` ou `rem`.
Eles diferem no sinal do resultado quando um dos números é negativo:

- `mod` anda junto com `div`, e seu resultado tem o mesmo sinal do divisor.
- `rem` anda junto com `quot`, e seu resultado tem o mesmo sinal do dividendo.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Para quaisquer `x` e `y` (com `y` diferente de zero), valem estas leis:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Quando os dois números são positivos, `div` e `quot` dão o mesmo resultado, assim como `mod` e `rem`.
Nesse caso, `quot` e `rem` podem ser um pouco mais eficientes, já que `div` e `mod` precisam de passos extras para lidar com números negativos.
~~~~

~~~~exercism/caution
Dividir por zero com `mod` ou `rem` resulta em uma exceção.
Isso é diferente da divisão normal.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

### Exponenciação

Haskell tem três operadores de "elevar à potência" que funcionam de forma diferente e recebem tipos de argumento diferentes.

- `**` recebe dois **números de ponto flutuante** e usa logaritmos para calcular a potência.
- `^^` recebe um **ponto flutuante** e o eleva a uma potência **inteira** positiva ou negativa.
- `^` recebe **qualquer tipo numérico** e o eleva a uma potência **inteira positiva**.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

### Prioridade e parênteses

Haskell permite parênteses (`()`), que podem ser usados para agrupar expressões.
Isso é útil quando você quer mudar a ordem das operações.

Ao usar vários operadores aritméticos, a ordem das operações é a mesma da matemática, também conhecida como [PEMDAS][pemdas].
Ela segue a ordem de parênteses (`()`), expoentes (`**`), multiplicação (`*`) e divisão (`/`), e adição (`+`) e subtração (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
