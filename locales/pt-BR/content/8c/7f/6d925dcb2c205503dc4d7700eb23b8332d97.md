# Introdução

`call` (no [`kernel`][kernel]) executa uma quotation. Quando
o efeito de pilha da quotation não pode ser inferido, normalmente porque
ela veio de outro lugar, declare o efeito em
`call` explicitamente:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Como quotations são valores, um array pode conter uma mistura de números
e quotations, o que faz de "um programa" apenas mais uma sequência:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
