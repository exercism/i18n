# Introdução

## Aliases de tipo

### Aliases de tipo

Um alias de tipo pode ser usado em Gleam para dar um nome conveniente a um tipo existente que de outra forma seria complicado de escrever.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Quando escrito com `pub type`, o alias pode ser usado fora do módulo onde foi definido. Se `pub` for omitido, o alias é privado e não pode ser referenciado em outros módulos.

## Dicionários

Os dicionários em Gleam são a estrutura de dados para armazenar informações em pares chave-valor. Em outras linguagens, eles também podem ser conhecidos como arrays associativos, hashes ou dicionários.

Qualquer tipo pode ser usado para as chaves e os valores em um dicionário, e eles não garantem a ordem das suas entradas quando acessadas ou retornadas.

### Trabalhando com dicionários

Os dicionários são criados e manipulados usando funções do módulo `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
