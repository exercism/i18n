# Dicas

## Geral

- Leia sobre [erros][getting-started-errors] no guia Getting Started.
- Leia sobre [IO][getting-started-io] no guia Getting Started.

## 1. Abra um arquivo

- Use _dispatch dinâmico_ para invocar a função de abrir. Reveja o trecho de código da introdução.

## 2. Tente escrever no arquivo

- Use a construção try-rescue.
- Existe uma [função][io-write] no módulo `IO` que permite escrever em um dispositivo de IO.
- Você pode usar o bloco `rescue` para fazer pattern matching com o erro e retornar a tupla de erro.
- Você pode usar o bloco `else` para fazer pattern matching com o retorno de uma escrita bem-sucedida.

## 3. Feche o arquivo

- Você pode usar o bloco `after` para executar uma função, independentemente de o bloco `try` ter sucesso ou ser resgatado.
