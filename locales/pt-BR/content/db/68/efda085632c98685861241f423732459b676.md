# Aprendizado

## Aprender C++ do zero

C++ é uma linguagem com uma sintaxe ampla e expressiva, que dá suporte a vários estilos de programação diferentes: procedural, orientado a objetos, funcional e genérico, além de combinações de todos eles no mesmo programa. Esta trilha da linguagem tenta apresentar problemas com dificuldade crescente e gradual. No entanto, alguns elementos da sintaxe da linguagem funcionam melhor se apresentados de outra forma, e não como uma série de exercícios.

Em geral, o Exercism parte do princípio de que você já conhece a sintaxe e os mecanismos da linguagem de uma trilha específica. No entanto, conhecer a sintaxe de uma linguagem é apenas o primeiro passo para se tornar especialista nela. O Exercism permite que você pratique a resolução de problemas e participe de discussões com outros programadores que resolveram o mesmo problema. É a partir das discussões compartilhadas que ganhamos experiência e percepção para nos tornarmos programadores melhores.

Se você está começando agora na linguagem C++, vale a pena dedicar um tempo a aprender o básico da linguagem primeiro. Aqui estão alguns recursos que podem ajudar você a começar:

* [Learn C++](http://www.learncpp.com/)
* [C++ Koans](https://github.com/torbjoernk/CppKoans)

O [Coliru](http://coliru.stacked-crooked.com/) é uma interface web simples, em forma de formulário, para um compilador de C++, que permite experimentar pequenos programas. Às vezes, essa pode ser uma maneira mais fácil de fazer um teste rápido do que compilar algo localmente em um ambiente de desenvolvimento integrado.

## Desenvolvimento guiado por testes em C++

O Exercism parte do princípio de que você já conhece o conceito de desenvolvimento guiado por testes. Cada exercício vem com uma série de testes já escritos para você. Você avança pelo exercício um teste de cada vez, escrevendo a implementação de forma incremental para satisfazer os testes.

Se você é novo em desenvolvimento guiado por testes, é altamente recomendável que você primeiro faça o workshop [Test-Driven Development in C++](https://github.com/boostcon/cppnow_presentations_2014/tree/master/files/test_driven), do [C++ Now! 2014](http://cppnow.org/). As mesmas ferramentas usadas nesse workshop são usadas na trilha de C++ do Exercism.
