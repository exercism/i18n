# Instruções

Neste exercício, você tem a tarefa de escrever o software de um dispositivo de criptografia que funciona realizando transformações nos dados. Você precisa de uma forma de criar funções complicadas de maneira flexível, combinando funções mais simples.

Para cada tarefa, retorne uma função anônima que possa ser invocada a partir do escopo que a chama.

Todas as funções devem esperar argumentos inteiros. Números inteiros também são adequados para realizar operações bit a bit em Elixir.

## 1. Crie um somador

Implemente `Secrets.secret_add/1`. Ela deve retornar uma função que recebe um argumento e soma a ele o argumento passado para `secret_add`.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. Crie um subtrator

Implemente `Secrets.secret_subtract/1`. Ela deve retornar uma função que recebe um argumento e subtrai desse argumento o segredo passado para `secret_subtract`.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. Crie um multiplicador

Implemente `Secrets.secret_multiply/1`. Ela deve retornar uma função que recebe um argumento e o multiplica pelo segredo passado para `secret_multiply`.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. Crie um divisor

Implemente `Secrets.secret_divide/1`. Ela deve retornar uma função que recebe um argumento e o divide pelo segredo passado para `secret_divide`.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

Use a divisão inteira para que a saída seja compatível com a entrada esperada pelas outras funções.

## 5. Crie um operador "and"

Implemente `Secrets.secret_and/1`. Ela deve retornar uma função que recebe um argumento e realiza uma operação _and_ bit a bit entre ele e o segredo passado para `secret_and`.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. Crie um operador "xor"

Implemente `Secrets.secret_xor/1`. Ela deve retornar uma função que recebe um argumento e realiza uma operação _xor_ bit a bit entre ele e o segredo passado para `secret_xor`.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. Crie um combinador de funções

Implemente `Secrets.secret_combine/2`. Ela deve retornar uma função que recebe um argumento e aplica a ele, na ordem, as duas funções passadas para `secret_combine`.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
