# Instruções

Convenceram você a voltar para Hyperia (com a inflação alta) com uma diária exorbitante.

O Banco Central está pensando em introduzir o dólar americano como uma segunda moeda, então todos os sistemas de contabilidade precisam ser adaptados para lidar com múltiplas moedas.

Pediram para você implementar o objeto de quantia em moeda.

## 1. Permitir que a quantia em moeda seja testada quanto à igualdade

Modifique a struct `CurrencyAmount` para tratar igualdade. Se as duas structs de quantia em moeda não tiverem a mesma moeda ("USD" ou "HD"), uma instância de `ArgumentException` deve ser lançada.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Comparar quantias em moeda

Modifique a struct `CurrencyAmount` para tratar comparações (`>` e `<`, apenas). Se as duas structs de quantia em moeda não tiverem a mesma moeda ("USD" ou "HD"), uma instância de `ArgumentException` deve ser lançada.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Somar e subtrair quantias em moeda

Modifique a struct `CurrencyAmount` para tratar adição e subtração aritméticas (`+` e `-`, apenas). Se as duas structs de quantia em moeda não tiverem a mesma moeda ("USD" ou "HD"), uma instância de `ArgumentException` deve ser lançada.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Multiplicar e dividir quantias em moeda

Modifique a struct `CurrencyAmount` para tratar multiplicação e divisão aritméticas (`*` e `/`, apenas).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Converter a quantia em moeda para um double

Modifique a struct `CurrencyAmount` para que uma instância possa ser convertida explicitamente para `double`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Converter a quantia em moeda para um decimal

Modifique a struct `CurrencyAmount` para que uma instância possa ser convertida implicitamente para `decimal`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
