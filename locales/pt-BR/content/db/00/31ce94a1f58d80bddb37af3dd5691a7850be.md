# Introdução

Em Rust, valores Boolean são representados pelo tipo `bool` e podem ser `true` ou `false`.

Rust tem seis operadores de comparação: `==` (igual), `!=` (diferente), `>` (maior que), `<` (menor que), `>=` (maior ou igual a), `<=` (menor ou igual a). Eles podem ser usados para avaliar a relação entre valores não Boolean e obter um valor Boolean.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Ao contrário de algumas outras linguagens, `0` não é `false` e um valor diferente de zero não é `true`.

Rust tem dois operadores Boolean: `||` (ou), `&&` (e). Eles só são avaliados quando o operando da esquerda ainda não determina o resultado da expressão. Ou seja, `||` só avalia o operando da direita quando o operando da esquerda for avaliado como `false`, e `&&` só quando ele for avaliado como `true`.
