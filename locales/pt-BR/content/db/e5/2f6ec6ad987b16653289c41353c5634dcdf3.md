# Dicas

## 1. Apresente-se

A função `introduce` precisa "desembrulhar" o valor contido em `player.Name`. Considere usar a [função `Options.defaultValue`][defaultvalue] para converter `player.Name` no valor que ele guarda quando for `Some`, ou no valor padrão necessário quando for `None`.

## 2. Implemente a mecânica de reviver

A função `revive` precisa retornar `Some <player>` ou `None`, em que `<player>` é um registro `Player` possivelmente com alguns campos modificados.

## 3. Implemente a mecânica de lançar feitiços

Considere usar uma expressão match para cobrir tanto o caso `Some` quanto o caso `None`, como no exemplo a seguir:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
