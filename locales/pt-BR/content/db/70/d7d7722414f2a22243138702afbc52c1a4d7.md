# Instruções

Neste exercício, você vai modelar uma balança usando Quilogramas como unidade.

Você tem 6 tarefas, e cada uma exige que você implemente uma ou mais propriedades:

## 1. Permita que a balança tenha uma precisão

Para atender a demandas diferentes, permitimos que cada balança seja personalizada com uma precisão (o número de dígitos depois do separador decimal).
Implemente a classe `WeighingMachine` com uma propriedade `Precision` somente de leitura, definida a partir do argumento `precision` do construtor:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. Permita definir o peso na balança

Implemente a propriedade `WeighingMachine.Weight` para permitir ler _e_ definir o peso:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. Garanta que um peso de entrada negativo seja rejeitado

Claramente, ninguém pode ter um peso negativo.
Adicione validação à propriedade `WeighingMachine.Weight` para lançar uma `ArgumentOutOfRangeException` ao tentar defini-la com um peso negativo:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. Permita aplicar um ajuste de tara à balança

O ajuste de tara pode ser qualquer valor (até negativo, ou um valor que deixe o peso exibido negativo)
Implemente a propriedade `WeighingMachine.TareAdjustment` para permitir definir o ajuste de tara:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. Garanta que a balança tenha um ajuste de tara padrão

Depois de alguns testes minuciosos, parece que, por um problema de fabricação, todas as balanças têm uma tendência a superestimar o peso em `5`.
Altere a propriedade `WeighingMachine.TareAdjustment` para que seu valor padrão seja `5`.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. Permita obter o peso

Implemente a propriedade `WeighingMachine.DisplayWeight`, que deve retornar uma string mostrando o peso depois do ajuste de tara, com a precisão correta aplicada e a unidade adicionada.
Repare que:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
