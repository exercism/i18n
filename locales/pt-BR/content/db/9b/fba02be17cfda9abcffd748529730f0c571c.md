# Apêndice das instruções

## Palavras

Defina uma tupla `stopwatch` e um construtor `<stopwatch> ( -- stopwatch )`
que retorna um novo cronômetro no estado `"ready"`, sem tempo decorrido e
sem voltas anteriores.

Forneça estas palavras que operam sobre um cronômetro:

- `state ( stopwatch -- str )`: `"ready"`, `"running"` ou `"stopped"`.
- `current-lap ( stopwatch -- str )`: o tempo decorrido da volta atual como
  uma string `"HH:MM:SS"`.
- `total ( stopwatch -- str )`: o tempo decorrido combinado da volta atual
  e de todas as voltas anteriores, como uma string `"HH:MM:SS"`.
- `previous-laps ( stopwatch -- seq )`: um array das voltas registradas
  anteriormente, cada uma como uma string `"HH:MM:SS"`.
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )`
  e `lap ( stopwatch -- )`: os quatro comandos da tabela acima. Chamar um
  deles a partir de um estado que não o permite deve `throw` um erro.

O tempo avança com:

- `advance-time ( str stopwatch -- )`: adiciona a duração `"HH:MM:SS"` à
  volta atual. Isso só tem efeito enquanto o cronômetro está rodando.
