# Introdução

## Arrays

A biblioteca padrão do Cairo implementa um tipo `Array`.

Ele é parecido com os tipos de array comuns em outras linguagens de programação, mas com algumas diferenças importantes:

- Os elementos só podem ser adicionados com eficiência no final do tipo `Array`, e só podem ser removidos com eficiência do início.
- É impossível definir um item manualmente usando o índice do array.

Arrays podem ser criados com a função `ArrayTrait::new` e também com a macro `array!`:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

Elementos podem ser adicionados ao array com a função `ArrayTrait::append`:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

Elementos podem ser removidos do array com a função `ArrayTrait::pop_front`:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

O Cairo também introduz um tipo `Span`, que funciona como um "snapshot" do `Array`.

Todo `Array` pode ser convertido em um `Span` com a função `ToSpanTrait::span`:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Converter um array em um `Span` é muito eficiente, porque `Span` é apenas uma estrutura de dados que permite ao Cairo "ver" uma seção do array. Ele não modifica o array de forma alguma.

Ao converter um array em um `Span`, o Cairo permite realizar mais operações do que seria permitido diretamente em `Array`, como remover um item do início do span.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Repare que tivemos que tornar `one_to_four_span` mutável com a palavra-chave `mut` para chamar `pop_back`, que modifica o span encurtando a seção do array que o span está "vendo".
