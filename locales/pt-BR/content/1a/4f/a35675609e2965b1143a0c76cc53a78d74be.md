# Introdução
## Switch

Uma [instrução switch][switch] permite comparar um valor com vários valores possíveis.
Ela permite escrever um código mais conciso do que usar várias condicionais `else-if`.
Uma instrução switch começa com a palavra-chave `switch` seguida do valor a ser comparado.
Depois, você pode definir os casos com a palavra-chave `case` seguida do valor com o qual comparar.
A palavra-chave `default` define o caso padrão quando nenhum dos casos corresponde.
Assim como as condicionais `else-if`, as instruções `switch` só executam o bloco de código associado ao primeiro caso que corresponder.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considere o seguinte exemplo:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Em vez disso, isso poderia ser escrito assim:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Laços while

Um [laço while][while-loops] é uma instrução de fluxo de controle que permite executar código enquanto uma determinada condição for verdadeira.
O Swift oferece dois tipos de laços while: os laços while e repeat-while.
A condição do laço while é avaliada antes de o corpo do laço ser executado; se a condição for falsa, o corpo do laço não será executado nenhuma vez.
Os laços while no Swift têm a seguinte estrutura:

```swift
while <#condition#> {
  <#code#>
}
```

Aqui, o laço será executado enquanto o count for maior que 0 e, com isso, imprimirá os números 2, 1 e "Liftoff!".

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Um [laço repeat-while][while-loops] é semelhante a um laço while, mas a condição é avaliada depois de o corpo do laço ser executado.
Isso significa que o corpo do laço sempre será executado pelo menos uma vez, mesmo que a condição seja falsa.
Os laços repeat-while no Swift têm a seguinte estrutura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Aqui, o laço será executado apenas uma vez, já que a condição é falsa.
Como é um laço repeat-while, o corpo do laço será executado uma vez antes de a condição ser avaliada.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Transferência de controle

O Swift tem um conjunto de instruções que podem ser usadas para alterar o fluxo normal de controle dos laços.
Elas são conhecidas como instruções de transferência de controle.
Você já viu o `return`; este conceito vai apresentar outras, que incluem `continue`, `break` e rótulos.
Não vamos abordar o `fallthrough` neste conceito, mas você pode ler sobre ele no [livro do Swift][fallthrough].

### Continue

Às vezes é preciso pular para a próxima iteração de um laço mais cedo, sem concluir o restante das instruções da iteração atual.
A palavra-chave `continue` pode ser usada para isso.
Quando o `continue` é executado, o laço salta para a próxima verificação para ver se a próxima iteração pode rodar, ou seja, o `while` nos laços while e repeat-while ou a verificação de que há outro elemento na sequência nos laços for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

Break é usado para sair de um laço mais cedo.
Quando o `break` é executado, o laço é encerrado imediatamente e o programa continua com a primeira instrução depois do laço.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Rótulos

Quando os laços estão aninhados, há momentos em que se pode querer usar `break` ou `continue` para sair ou reiniciar os laços externos que contêm o laço em que o `break` ou `continue` são usados.
Em casos como esses, rótulos podem ser usados para especificar o laço a ser encerrado ou reiniciado.
Um laço pode ser rotulado colocando um nome seguido de dois-pontos antes do `while`, `repeat` ou `for` que inicia o laço.

Para ver o efeito de usar rótulos dessa forma, considere o seguinte laço.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
