# não compare valores Boolean com true ou false

Comparar valores Boolean com true ou false é redundante.
Usar `==` gera um valor Boolean, então não é preciso compará-lo com outro valor Boolean fixo no código.
Se quiser inverter o valor Boolean, use o operador `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
