# Dicas

## Geral

- Um número de ponto flutuante é retornado em `xmm0`.
- Os 8 primeiros argumentos de ponto flutuante são passados em `xmm0` a `xmm7`.

## 1. Calcule a taxa diária a partir de uma taxa horária

- Um número de ponto flutuante é retornado em `xmm0`.
- Os 8 primeiros argumentos de ponto flutuante são passados em `xmm0` a `xmm7`.
- Um inteiro de 64 bits pode ser convertido em um número de ponto flutuante de precisão dupla usando `cvtsi2sd`.
- Um imediato (um número constante) precisa ser armazenado em um registrador de uso geral antes de ser convertido em um número de ponto flutuante.
- Dois números de ponto flutuante de precisão dupla podem ser multiplicados com `mulsd`.

## 2. Calcule um preço com desconto

- Um número de ponto flutuante é retornado em `xmm0`.
- Os 8 primeiros argumentos de ponto flutuante são passados em `xmm0` a `xmm7`.
- Dois números de ponto flutuante de precisão dupla podem ser divididos com `divsd`.
- Um número de ponto flutuante de precisão dupla pode ser subtraído de outro com `subsd`.

## 3. Calcule a taxa mensal, dada uma taxa horária e um desconto

- Um número de ponto flutuante é retornado em `xmm0`.
- Os 8 primeiros argumentos de ponto flutuante são passados em `xmm0` a `xmm7`.
- Você pode usar `roundsd` para arredondar um número de ponto flutuante de precisão dupla, usando um terceiro operando para indicar o modo de arredondamento.
- O número para arredondar para cima (teto) é `2`.
- Você pode usar `cvtsd2si` para converter um número de ponto flutuante de precisão dupla em um inteiro de 64 bits.

## 4. Calcule o número de dias úteis dados um orçamento, uma taxa horária e um desconto

- Um número de ponto flutuante é retornado em `xmm0`.
- Os 8 primeiros argumentos de ponto flutuante são passados em `xmm0` a `xmm7`.
- Você pode usar `roundsd` para arredondar um número de ponto flutuante de precisão dupla, usando um terceiro operando para indicar o modo de arredondamento.
- O número para arredondar para baixo (piso) é `1`.
- Você pode usar `cvtsd2si` para converter um número de ponto flutuante de precisão dupla em um inteiro de 32 bits.
