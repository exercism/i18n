# Introdução

O Factor tem dois valores booleanos: `t` (verdadeiro) e `f` (falso). Sempre que precisar de uma resposta de "sim/não", as palavras colocam um deles na pilha.

Os operadores booleanos ficam em [`kernel`][kernel]:

```
and ( a b -- ? )
or  ( a b -- ? )
not ( a -- ? )
```

```factor
t f and .   ! => f
t f or .    ! => t
f not .     ! => t
```

`f` também é o único valor *falsy* do Factor. Todos os outros valores (strings vazias, zero, arrays vazios) são tratados como truthy.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
