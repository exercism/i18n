# Sobre

Você cria uma instância de uma _classe_ chamando o seu [_construtor_][constructors] por meio do [operador `new`][new]. Um construtor é um tipo especial de método cujo objetivo é inicializar uma instância recém-criada. [Os construtores se parecem com métodos normais][constructor-syntax], mas sem tipo de retorno e com um nome que é igual ao nome da classe.

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Assim como os métodos normais, os construtores podem ter parâmetros. Os parâmetros de um construtor geralmente são guardados como [campos][fields] (privados) para serem acessados depois, ou então usados em algum cálculo pontual. Argumentos podem ser passados para construtores da mesma forma que se passam argumentos para métodos normais.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

Especificar um construtor é opcional. Se nenhum construtor for especificado, o compilador gera um [construtor sem parâmetros][parameterless-constructors]:

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

Se os campos tiverem um valor inicial atribuído a eles, o compilador vai gerar um código no qual a atribuição é feita, na verdade, dentro do construtor. As declarações de classe a seguir são, portanto, equivalentes (em termos de funcionalidade):

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
