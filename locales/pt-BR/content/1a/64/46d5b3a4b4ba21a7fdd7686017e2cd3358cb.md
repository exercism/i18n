# Depuração

Para ajudar na depuração, você pode usar o fato de que toda a saída do console será capturada e mostrada na janela de resultados dos testes.
Você pode exibir qualquer valor passando-o para `@show`.

`@show` mostra uma expressão e o resultado dela, e ainda retorna esse resultado.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

Você também pode usar [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) ou qualquer outro método que escreva a saída em [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)).
