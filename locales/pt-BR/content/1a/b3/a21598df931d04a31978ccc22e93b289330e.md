# Testes

  ## Resumo rápido

  1. Faça suas alterações no arquivo `<myFileName>.u`
  2. Salve o arquivo `<myFileName>.u`
  3. Se o arquivo passar na verificação de tipos, rode os comandos `add` ou `update` do UCM
    * Se o arquivo não passar na verificação de tipos, faça alterações no código do seu arquivo `<myFileName>.u` até que ele compile. Lembre-se de rodar `update` nas suas funções depois das alterações!
  4. Rode o comando `load <myFileName>.test.u` na CLI do UCM para trazer os testes para o escopo e executá-los

  ## Passo a passo

  Se você estiver resolvendo um problema do Exercism pela linha de comando, o mais provável é que implemente sua solução no diretório com o nome do exercício em questão. Por exemplo, se o exercício for `hello-world`, você deve abrir o `ucm` pela linha de comando depois de entrar em `~/exercism/unison/hello-world` com `cd`. Faça as alterações da sua implementação no arquivo `hello.u` e, quando sua implementação estiver pronta, digite o comando `add` ou `update` na CLI do gerenciador de codebase do Unison (UCM) para adicionar à codebase o trabalho feito no arquivo.

  O arquivo que contém os testes de cada exercício tem o sufixo `.test.u`. Você vai querer usar o comando `load` do UCM para trazer os testes para o escopo e executá-los. O comando `load` recebe um caminho de arquivo como argumento. No exercício hello world, isso seria mais ou menos assim:

  ```
  .> load hello.test.u
  ```

  Você deve ver uma mensagem do UCM sobre os termos que foram trazidos para o escopo e, o mais importante, o resultado da execução do teste:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  Digamos que seus testes não passaram na primeira vez. Volte a editar o arquivo `myExercise.u` e, ao salvar, você pode rodar `update`

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  Agora podemos recarregar nossos testes para ver se algo mudou!

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
