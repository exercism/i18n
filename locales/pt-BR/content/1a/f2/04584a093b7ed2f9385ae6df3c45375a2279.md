# Instruções

Neste exercício, você vai escrever código para acompanhar uma lista de linguagens de programação que você quer aprender no Exercism.
São seis tarefas, e todas elas envolvem lidar com listas.

## 1. Criar uma nova lista

Para acompanhar as linguagens que você quer aprender, você vai precisar criar uma nova lista.
Defina a constante `newList` que contém uma lista nova e vazia.

```elm
newList
    --> []
```

## 2. Definir uma lista existente

No momento, você tem um pedaço de papel com uma lista das linguagens que quer aprender: Elm, Clojure e Haskell.
Defina a constante `existingList` para representar essa lista.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. Adicionar uma nova linguagem a uma lista

Conforme você explora o Exercism e encontra linguagens mais interessantes, você quer adicioná-las à sua lista.
Implemente a função `addLanguage` para adicionar uma nova linguagem ao início da sua lista.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. Contar as linguagens da lista

Contar as linguagens manualmente é inconveniente.
Implemente a função `countLanguages` para contar o número de linguagens da sua lista.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. Inverter a lista

Em algum momento, você percebe que sua lista está na verdade em ordem inversa!
Implemente a função `reverseList` para inverter sua lista.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. Verificar se a lista é empolgante

Embora você ame todas as linguagens, Elm tem um lugar especial no seu coração.
Por isso, você fica muito empolgado com uma lista de linguagens quando:

- O primeiro item da lista é Elm.
- Ou o segundo item da lista é Elm e a lista contém três linguagens ou menos.

Implemente a função `excitingList` para verificar se uma lista de linguagens é empolgante:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
