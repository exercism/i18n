# Anexo de instruções

## Notas específicas para WebAssembly

A assinatura da função para a exportação WebAssembly `total` é a seguinte:

```wasm
(func (export "total")
    (param $basketOffset i32)
    (param $basketLength i32)
    (result i32)
)
```

Os dois parâmetros `$basketOffset` e `$basketLength` expressam o deslocamento base e o comprimento de um array de inteiros de 32 bits. O parâmetro de comprimento é medido em número de elementos do array, não em bytes. Antes de chamar essa função, o chamador grava esse array na memória linear do WebAssembly a partir do deslocamento `$basketOffset`. A memória linear do WebAssembly é sempre expressa em little-endian.

Por exemplo, o chamador codificaria a cesta `[1,2]` como a seguinte sequência de oito bytes.

```
| 64 | 65 | 66 | 67 | 68 | 69 | 70 | 71 |
| --- basket[0] --- | --- basket[1] --- |
,0x01,0x00,0x00,0x00,0x02,0x00,0x00,0x00,
```
