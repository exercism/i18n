# Dicas

## Geral

- `MACRO:` está em [`macros`][macros]. Os blocos de construção ficam em
  `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`,
  `<repetition>`, `map`) e `quotations` (`>quotation`).
- Um corpo de macro precisa deixar **uma quotation** na pilha. Se o seu
  corpo produz um array de código, termine com `>quotation`.
- Para conferir seu raciocínio, rode as palavras do corpo sobre um literal no
  listener e veja a quotation que você recebe de volta. Ela deve ser
  o código sequencial da linha "compila para" da tarefa.

## 1. Duas vezes

- Você recebe `[ A ]` e quer `[ A A ]`. Faça uma cópia e junte as duas:
  `dup append`.

## 2. N repetições

- Você recebe `[ A ] n` e quer `n` cópias juntas.
- `<repetition>` constrói as cópias, mas o efeito dela é
  `( length elt -- repetition )`. A contagem precisa estar no topo, então
  use `swap` primeiro.
- Depois achate e converta: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Componha várias

- Você já recebe o array de quotations; só precisa achatá-lo em uma
  só. `concat >quotation` é o corpo inteiro.

## 4. Iteração desenrolada

Você recebe uma sequência e uma quotation, por exemplo `{ 10 20 30 } [ + ]`,
e quer `[ 10 + 20 + 30 + ]`. Monte isso em três passos.

**Um elemento.** Embutir um elemento na quotation é exatamente
o que `curry` faz:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Cada elemento.** Você quer fazer `map` disso sobre a sequência, mas
`map` só passa uma entrada para a quotation de mapeamento (o elemento),
enquanto você também precisa ter `[ + ]` à mão a cada vez. Então embuta
`[ + ]` na quotation de mapeamento primeiro, de novo com `curry`:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` quer dizer "empurre a pequena quotation `[ curry ]`,
depois embuta `[ + ]` nela com curry", o que dá `[ [ + ] curry ]`. Fazer
`map` disso sobre um elemento `e` roda `e [ + ] curry`, que é `[ e + ]`.

**Junte-as.** Mesmo final das outras tarefas:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- O corpo inteiro: `[ curry ] curry map concat >quotation`.
