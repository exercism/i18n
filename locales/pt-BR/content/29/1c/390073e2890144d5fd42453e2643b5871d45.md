# Dicas

## Geral

A linguagem SGF tem uma definição recursiva:

```none
GameTree = "(" Sequence { GameTree } ")"
```

Ou seja, uma GameTree é um trecho de texto que começa com um `(`, seguido de um texto chamado "Sequence" (uma lista de nós do jogo), _seguido de **zero ou mais** GameTrees filhos_, e termina com um `)`.

Talvez você queira usar expressões regulares para fazer o parse de um texto SGF.
No entanto, como as árvores do jogo podem ficar aninhadas dentro de outras árvores do jogo a qualquer profundidade, as expressões regulares comuns não dão conta de acompanhar os níveis de aninhamento.

Existem algumas abordagens para resolver este exercício:

### Máquina de estados

Você pode percorrer a string de entrada caractere por caractere, mantendo uma variável com a sua posição atual.
Você pode acompanhar o estado atual do texto analisado com base no caractere da posição atual.
O "estado atual" pode ser algo como "lendo um nome de propriedade" ou "dentro de um valor de propriedade".
Com essa abordagem, são muitos os valores que você precisa acompanhar.

### Parser

Um [parser baseado em PEG][PEG-parser] é uma ótima forma de fazer o parse de uma linguagem que tem uma gramática definida.
O [LPeg][LPeg] é um parser PEG e uma das dependências obrigatórias do MoonScript, então você já tem acesso a ele.
Um parser permite escrever regras que dizem como o texto deve ser.
Por exemplo, "um nome de propriedade é formado só por letras maiúsculas" ou "um valor de propriedade fica entre colchetes".
O parser então faz o trabalho pesado de comparar o texto de entrada com as suas regras.
