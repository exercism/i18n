# Testes

## Rodando os testes

Para rodar os testes, execute o seguinte comando:

```bash
bats test-<exercise-slug>.bats
```

### O bats é implementado em bash

O arquivo bats é um script bash, com algumas funções especiais reconhecidas pelo comando `bats`.
Você vai ver alguns testes parecidos com

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

Essa sintaxe `<<<` é uma *Here String* do bash.
Ela envia a string do lado direito para a entrada padrão do programa do lado esquerdo.
É mais ou menos o mesmo que

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## Testes ignorados

Resolver um exercício significa fazer todos os seus testes passarem.
Por padrão, apenas um teste (o primeiro) é executado quando você roda os testes.
Isso é intencional, pois permite que você foque apenas em fazer esse único teste passar.
Depois que ele passar, você pode ativar o próximo teste comentando ou removendo as

    [[ $BATS_RUN_SKIPPED == true ]] || skip

anotações que antecedem os outros testes.

## Sobrescrevendo os skips

Para rodar todos os testes, inclusive os que têm anotações `skip`, você pode rodar:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

ou você pode comentar ou apagar a linha:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

do arquivo de teste.
