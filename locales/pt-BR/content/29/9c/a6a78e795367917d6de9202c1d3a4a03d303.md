# Introdução

## Explicação

Além dos tipos de dados primitivos como `number` e `string`, existe outro tipo de dados importante em JavaScript chamado `object`.
Objetos são coleções de pares de chave-valor.
Assim, eles podem ser usados da mesma forma que o que costuma ser chamado de mapas ou dicionários em outras linguagens.

Em outras linguagens, todos os valores de um mapa geralmente precisam ter o mesmo tipo de dados.
Em JavaScript, apenas o tipo da chave é restrito: ela precisa ser uma `string`.
Os valores dentro de um objeto podem ter tipos diferentes.
Eles podem ser tipos primitivos como números, mas também arrays, outros objetos ou até funções.
Isso torna os objetos muito versáteis, de modo que também são entidades centrais para a [programação orientada a objetos][oop] (POO) em JavaScript.

A seguir, vamos nos concentrar em objetos como coleções ou mapas.
Outros casos de uso de objetos serão abordados em outros conceitos; veja, por exemplo, [Classes][concept-classes].

## Criando um objeto

Você cria um objeto usando chaves.
Você também pode incluir algumas entradas diretamente.
Para isso, informe a chave primeiro, seguida de dois-pontos e do valor.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

A vírgula final após a última entrada é opcional em JavaScript.

Você pode se perguntar por que as chaves não estão envolvidas por aspas, embora devessem ser strings.
Essa é uma notação abreviada.
Se a chave seguir as regras de nomenclatura de um [identificador][mdn-identifier] JavaScript, você pode omitir as aspas.
Para chaves com caracteres especiais no nome, você precisa usar a notação de string usual.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Obtendo um valor

Há duas maneiras de obter o valor de uma determinada chave: notação de ponto e notação de colchetes.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

Usar a notação de ponto como forma abreviada tem a mesma restrição que omitir as aspas.
Ela só funciona se a chave seguir as regras de nomenclatura de identificadores.

## Adicionando ou alterando um valor

Você pode adicionar ou alterar um valor usando o operador de atribuição `=`.
Novamente, há notações de ponto e de colchetes disponíveis.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Excluindo uma entrada

Você pode excluir um par chave-valor de um objeto usando a palavra-chave `delete`.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Verificando se uma chave existe

Você pode verificar se uma determinada chave existe em um objeto com o método `hasOwnProperty`.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Iterando sobre um objeto

Há um laço `for...in` especial para iterar sobre todas as chaves de um objeto.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

Para evitar erros sutis, você deve sempre assumir que o laço `for...in` visita as chaves em uma ordem arbitrária.
Além disso, lembre-se de que o `for...in` inclui [chaves herdadas][concept-inheritance] em sua iteração.
