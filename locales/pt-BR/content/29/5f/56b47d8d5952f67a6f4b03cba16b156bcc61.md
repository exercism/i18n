# Sobre

As strings do F# são objetos imutáveis que representam texto como uma sequência de caracteres Unicode (letras, dígitos, pontuação, etc.). Aspas duplas são usadas para definir uma instância de `string`:

```fsharp
let fruit = "Apple"
```

Você pode manipular uma string chamando um dos seus [métodos][methods] ou [propriedades][properties], ou usando uma das funções do [módulo `String`][string-module]. Como os valores de string nunca mudam depois de definidos, todos os métodos e funções de manipulação de string retornam uma nova string.

Uma string é delimitada por caracteres de aspas duplas (`"`). Alguns caracteres especiais precisam de [escape][escaping] usando o caractere barra invertida (`\`). As strings também podem ser prefixadas com o símbolo arroba (`@`), o que as transforma em uma [string verbatim][verbatim] que ignora qualquer caractere escapado.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

Como alternativa, as strings podem ser definidas usando [aspas triplas][triple-quoted] (`"""`), o que permite usar aspas duplas dentro da string sem escapá-las.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

Por fim, a concatenação de strings pode ser feita com o [operador `+`][plus-operator]:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
