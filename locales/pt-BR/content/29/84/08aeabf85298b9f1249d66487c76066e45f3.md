# Instruções

Neste exercício, você vai organizar corridas entre vários tipos de carros de controle remoto. Cada carro tem suas próprias características de velocidade e de consumo de bateria.

Os carros começam com a bateria cheia (100%). Cada vez que você dirige o carro usando o controle remoto, ele percorre, em metros, uma distância igual à velocidade do carro e diminui a porcentagem restante da bateria pelo seu consumo de bateria.

Se a bateria de um carro estiver abaixo da porcentagem do seu consumo de bateria, você não pode mais dirigir o carro.

Cada pista de corrida tem sua própria distância. Os carros são testados verificando se conseguem terminar a pista sem ficar sem bateria.

Você tem seis tarefas, e cada uma delas vai trabalhar com instâncias de carros de controle remoto.

## 1. Criar um carro de controle remoto

Permita criar um carro de controle remoto definindo um construtor para a classe `NeedForSpeed` que recebe a velocidade do carro em metros e a porcentagem de consumo de bateria como seus dois parâmetros (ambos do tipo `int`):

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
```

## 2. Criar uma pista de corrida

Permita criar uma pista de corrida definindo um construtor para a classe `RaceTrack` que recebe a distância da pista em metros como seu único parâmetro (que é do tipo `int`):

```java
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Dirigir o carro

Implemente o método `NeedForSpeed.drive()` que atualiza o número de metros percorridos com base na velocidade do carro. Além disso, implemente o método `NeedForSpeed.distanceDriven()` para retornar o número de metros percorridos pelo carro:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.distanceDriven();
// => 5
```

## 4. Verificar se a bateria está descarregada

Atualize o método `NeedForSpeed.drive()` para consumir a bateria com base no consumo de bateria do carro. Além disso, implemente o método `NeedForSpeed.batteryDrained()` que indica se a bateria está descarregada demais para dirigir:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.batteryDrained();
// => false
```

## 5. Criar o carro de controle remoto Nitro

O carro de controle remoto mais vendido é o Nitro, que tem uma velocidade máxima impressionante de 50 metros com um consumo de bateria de 4%. Implemente o método (estático) `NeedForSpeed.nitro()` para retornar esse tipo de carro:

```java
var car = NeedForSpeed.nitro();
car.drive();
car.distanceDriven();
// => 50
```

## 6. Verificar se um carro de controle remoto consegue terminar uma corrida

Para terminar uma corrida, um carro precisa conseguir percorrer a distância da corrida. Isso significa não consumir sua bateria antes de cruzar a linha de chegada. Implemente o método `RaceTrack.canFinishRace()` que recebe uma instância de `NeedForSpeed` como seu parâmetro e retorna `true` se o carro conseguir terminar a corrida; caso contrário, retorne `false`:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);

int distance1 = 100;
var race1 = new RaceTrack(distance1);

int distance2 = 300;
var race2 = new RaceTrack(distance2);

race1.canFinishRace(car);
// => true

race2.canFinishRace(car);
// => false
```
