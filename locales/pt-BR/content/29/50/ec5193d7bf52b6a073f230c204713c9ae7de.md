# Rotinas vinculadas

Até agora, tudo passou *valores* adiante: números, strings, objetos. Uma
**rotina vinculada** permite passar adiante a própria rotina: algo que será
chamado depois, por um código que não sabe o que ela é.

Um substituto é exatamente essa ideia: o diretor de palco guarda uma forma de
representar o papel, sem saber quem é nem o que vai fazer.

## Criando uma

`bind` recebe uma chamada com buracos, escritos como `_`:

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

`part` agora é um valor como qualquer outro. A chamada acontece depois:

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## O tipo

O tipo de uma rotina vinculada é `ROUT`, com os tipos dos argumentos entre
chaves e o tipo de retorno depois dos dois-pontos:

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

Leia `ROUT{STR}:STR` como "uma rotina que recebe um `STR` e responde com um `STR`".

| Escrito | Significa |
| --- | --- |
| `ROUT{STR}:STR` | recebe um `STR`, responde com um `STR` |
| `ROUT{INT,INT}:BOOL` | recebe dois `INT`, responde com um `BOOL` |
| `ROUT{STR}` | recebe um `STR`, não responde nada |
| `ROUT:INT` | não recebe nada, responde com um `INT` |

Como é um tipo, pode ser um argumento:

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse` não faz ideia do que `part` faz. É essa a ideia: ela pode receber
`shout`, ou `whisper`, ou qualquer outra coisa com esse formato.

## Preenchendo alguns dos argumentos

Nem todo argumento precisa ser um buraco. O que estiver escrito fica fixo
quando o bind acontece:

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice` recebe apenas a linha, porque o `2` já está decidido. O valor é
calculado no momento da vinculação e guardado, então mudar depois a variável
de onde ele veio não faz diferença.

É assim que uma rotina genérica se transforma em muitas rotinas específicas.

## Vinculando o objeto também

No caso de uma rotina de um objeto, o objeto é a primeira coisa na chamada e
pode ser fixado ou deixado como buraco:

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
