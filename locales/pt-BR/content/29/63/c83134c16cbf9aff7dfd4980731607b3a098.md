# Introdução

Assim como outras linguagens, o C++ também oferece uma instrução `switch`.
As instruções `switch` são uma forma mais curta de escrever condicionais longas com `if ... else if`.
Para criar um `switch`, começamos usando a palavra-chave `switch` seguida de um número inteiro.
Em seguida, declaramos cada uma das condições com a palavra-chave `case`.
Também podemos declarar um `default`, que executa quando nenhuma das condições `case` anteriores corresponde.
Cada caso deve terminar com uma instrução `break` (ou `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Passagem entre casos

Um ponto importante sobre a construção `switch` é que o código continua sendo executado até ser interrompido por uma instrução `break` (ou `return`).
Isso pode levar a comportamentos inesperados.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

O principal caso de uso dessa execução continuada é uma instrução com vários rótulos.
Vários resultados do `switch` podem apontar para o mesmo trecho de código a ser executado.
Dessa forma, em um app de reservas, por exemplo, a função chamada para grupos de tamanho 2 e 3 pode ser a mesma:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
