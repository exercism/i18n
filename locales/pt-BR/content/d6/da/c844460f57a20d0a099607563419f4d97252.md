# Introdução

Uma *quotation* (código entre colchetes `[ ]`) é, em si, um valor no Factor, assim como um número ou uma string. Você pode guardar uma em uma variável, colocar uma em um array, passar uma para outro word e *chamá-la* depois.

## `call`

`call` (no [`kernel`][kernel]) roda uma quotation:

```factor
3 4 [ + ] call .
! => 7
```

Quando você usa `call` em uma quotation num contexto em que o Factor não consegue inferir o efeito de pilha dela, você precisa declarar o efeito explicitamente:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

Isso compila uma verificação em tempo de execução de que a quotation realmente tem o efeito declarado.

## Quotations em sequências

Como quotations são valores, um array pode conter uma mistura de números e quotations:

```factor
{ 3 4 [ + ] }
```

Isso faz de "um programa" uma sequência comum, e o `each` se torna uma maneira natural de rodar um:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## Fatiamento do fim de uma sequência

`head*` retorna tudo, exceto os últimos `n` elementos; `last2` retorna os dois últimos:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

Junto com `suffix`, isso é tudo que você precisa para escrever uma operação de pilha que "consome os dois do topo e empilha um resultado".
