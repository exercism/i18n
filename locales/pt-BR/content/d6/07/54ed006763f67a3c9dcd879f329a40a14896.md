# Bools

Crystal tem um tipo conhecido como [`Bool`][bools].
Representa os valores `true` e `false`.

## Operadores lógicos

Crystal tem três operadores lógicos (`!`, `||`, `&&`), que combinam Bools e criam expressões que produzem valores diferentes.

### And(`&&`)

O operador [_and_][and] em Crystal é representado por `&&` e retorna `true` se os dois valores forem `true`; caso contrário, retorna `false`.
Ao usar o operador _and_, um Bool fica do lado direito do `&&` e o outro do lado esquerdo.

```crystal
true && true
# => true

true && false
# => false
```

### Or(`||`)

O operador [_or_][or] em Crystal é representado por `||` e retorna `true` se **pelo menos um** dos valores fornecidos for `true`. 
Se os dois valores forem `false`, ele retorna `false`.
Ao usar o operador _or_, um Bool deve ficar do lado direito do `||` e o outro do lado esquerdo.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not(`!`)

O operador _not_ em Crystal é representado por `!` e retorna `true` se o Bool fornecido for `false` e retorna `false` se `true` for fornecido.
Ao usar o operador _not_, um Bool deve ficar depois do operador (`!`).

```crystal
!true
# => false

!false
# => true
```

## Usando parênteses (`()`)

Ao trabalhar com Bools, você pode usar parênteses para decidir quais Bools avaliar primeiro.
O resultado pode variar dependendo de como os parênteses são usados.
Em Crystal, o que está entre parênteses é avaliado primeiro.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Como o que está entre parênteses é avaliado primeiro, no exemplo a seguir o operador _not_ será aplicado à expressão dentro dos parênteses.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Você só deve usar parênteses quando eles afetarem o resultado; caso contrário, devem ser omitidos.
~~~~
