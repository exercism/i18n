# Instruções

Neste exercício, você vai escrever código para ajudar um freelancer a se comunicar com um gerente de projeto.
Sua tarefa é fornecer alguns utilitários para calcular rapidamente as taxas diária e mensal, opcionalmente com um desconto.

Primeiro, estabelecemos algumas regras entre o freelancer e o gerente de projeto:

- A taxa diária é 8 vezes a taxa horária.
- Um mês tem 22 dias faturáveis.

Às vezes, o freelancer oferece aplicar um desconto sobre sua taxa diária (por exemplo, para seus clientes mais fiéis ou clientes sem fins lucrativos).

Os descontos são modelados como números fracionários que representam porcentagens, por exemplo, `25.0` (25%).

## 1. Calcule a taxa diária a partir de uma taxa horária

Implemente uma função chamada `daily_rate` para calcular a taxa diária a partir de uma taxa horária como parâmetro.
O contrato define que um dia tem 8 horas faturáveis.

```cpp
daily_rate(60)
// => 480.0
```

A taxa diária retornada deve ser do tipo `double`.

## 2. Calcule um preço com desconto

Implemente uma função `apply_discount` para calcular o preço após um desconto.
Ela deve aceitar dois parâmetros: o preço original e a taxa de desconto em porcentagem.

```cpp
apply_discount(150, 10)
// => 135.0
```

O valor retornado deve sempre ser do tipo `double`, sem nenhum arredondamento.

## 3. Calcule a taxa mensal, a partir de uma taxa horária e um desconto

Implemente uma função `monthly_rate` para calcular a taxa mensal com desconto.
Ela deve ter dois parâmetros: uma taxa horária e o desconto em porcentagem.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

A taxa mensal retornada deve ser arredondada para cima (teto) para o inteiro mais próximo.

## 4. Calcule o número de dias úteis completos com um orçamento, uma taxa horária e um desconto

Implemente uma função `days_in_budget` que recebe um orçamento, uma taxa horária e um desconto, e calcula quantos dias completos de trabalho isso cobre.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

O número de dias retornado deve ser arredondado para baixo (piso) para o inteiro mais próximo.
