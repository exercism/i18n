# Testes

Antes de tentar executar os testes, verifique se a pasta do exercício está configurada corretamente seguindo os passos de instalação, ou seja, `corepack yarn install` e a configuração do Editor SDK.

Execute os testes com:

```bash
$ corepack yarn test
```

Certifique-se de que seu código segue as boas práticas, assim como o de outros usuários, com o eslint, uma ferramenta que faz análise estática do seu código.
Ferramentas como essa economizam tempo na hora de detectar erros de digitação ou erros bobos no seu código:

```bash
$ corepack yarn lint
```

Ou faça os dois ao mesmo tempo:

```bash
$ corepack yarn test && corepack yarn lint
```

A trilha de TypeScript no Exercism não impõe um _estilo_ de código, então você é livre para escolher entre ponto e vírgula, tabulações ou espaços, e tudo mais.

## Criando seu primeiro módulo

Normalmente, os testes desta trilha carregam sua implementação importando-a como um módulo: `import Bob from './bob';`.
Para que isso funcione, você precisa exportar sua implementação no arquivo em que os testes procuram seu módulo, `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

Nós fornecemos stubs em cada exercício e já colocamos esse `export` lá para você.
