# Instruções adicionais

## Palavras

Defina uma tupla `linked-list-node`.

Defina uma tupla `linked-list` e forneça um método `M: linked-list length` (de `sequences`) para que os testes possam chamar `length` diretamente na sua lista.

- `<linked-list> ( -- linked-list )`: constrói uma lista vazia.
- `>linked-list ( seq -- linked-list )`: insere cada elemento de `seq` em uma lista nova, na ordem.
- `linked-list>array ( linked-list -- array )`: retorna os valores, começando pelo topo da lista.
- `list-push ( linked-list value -- linked-list )`: insere um valor no topo.
- `list-pop ( linked-list -- linked-list value )`: remove e retorna o valor do topo.
- `list-peek ( linked-list -- value )`: retorna o valor do topo sem removê-lo.
- `list-reverse ( linked-list -- linked-list )`: retorna uma lista com os elementos em ordem inversa.

Lance uma classe de erro `list-empty` a partir de `list-pop` e `list-peek` quando a lista estiver vazia.
