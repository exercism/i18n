# Instruções

Sua tarefa é escrever o código que calcula os pontos de energia concedidos aos jogadores quando eles completam uma fase.

Os pontos concedidos dependem de duas coisas:

- A fase (um número) que o jogador completou.
- O valor base de cada item mágico coletado pelo jogador durante essa fase.

Os pontos de energia são concedidos de acordo com as seguintes regras:

1. Para cada item mágico, pegue o valor base e encontre todos os múltiplos desse valor que sejam menores que o número da fase.
2. Combine os conjuntos de números.
3. Remova as duplicatas.
4. Calcule a soma de todos os números que restarem.

Vamos ver um exemplo:

**O jogador completou a fase 20 e encontrou dois itens mágicos com valores base de 3 e 5.**

Para calcular os pontos de energia ganhos pelo jogador, precisamos encontrar todos os múltiplos únicos desses valores base que sejam menores que a fase 20.

- Múltiplos de 3 menores que 20: `{3, 6, 9, 12, 15, 18}`
- Múltiplos de 5 menores que 20: `{5, 10, 15}`
- Combine os conjuntos e remova as duplicatas: `{3, 5, 6, 9, 10, 12, 15, 18}`
- Some os múltiplos únicos: `3 + 5 + 6 + 9 + 10 + 12 + 15 + 18 = 78`
- Portanto, o jogador ganha **78** pontos de energia por completar a fase 20 e encontrar os dois itens mágicos com valores base de 3 e 5.
