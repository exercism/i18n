# Sobre funções anônimas e closures

O PHP permite declarar funções dentro de outras funções. Essas funções não precisam ter um nome, mas podem ser atribuídas a variáveis ou até passadas diretamente para outra função que exige um parâmetro do tipo função.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

A função definida e passada para array_filter acima é uma função anônima. A função `array_filter` usa isso para determinar se um determinado valor de um array será retornado no resultado de `array_filter`. Se a função retornar `true` para um valor, esse valor será incluído no array de resultado.

Funções anônimas também podem ser usadas para referenciar, de dentro da função, variáveis que estão no escopo externo à função. Isso é conhecido como o escopo da função "se fechando" sobre a variável usada na função, daí o nome "closure". Em algumas linguagens, todas as variáveis no escopo podem ser usadas automaticamente dentro do closure. No PHP, o `$this`, que se refere ao objeto atual, é permitido automaticamente dentro do closure. Todas as outras variáveis precisam ser referenciadas explicitamente usando a palavra-chave `use`.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

Na função `makeAdderFunction` acima, o valor de `$number` passado é "fechado" dentro da função anônima definida internamente, que então é retornada. Assim, sempre que essa função é executada, ela sabe qual é o valor de `$number` que foi passado. Se você chamar essa função de novo com outro número, isso retornará uma função completamente diferente. Isso não mudaria os valores nem o comportamento retornados pela primeira chamada da função.
Se você precisar fechar sobre mais de uma variável, elas podem ser adicionadas na palavra-chave `use`, separadas por vírgula.

O PHP também tem uma sintaxe de função mais curta, chamada `arrow functions`. Elas precisam ser razoavelmente simples. A forma básica delas é:

```php
fn(arguments) => expression
```

Nesse estilo de função, você não precisa usar `use`. Ela fecha e captura automaticamente qualquer valor do escopo pai. A expressão nessas arrow functions é retornada automaticamente, sem precisar usar a palavra-chave `return`. Isso permite reescrever a função `onlyOdds` acima assim:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

A `makeAdderFunction` acima poderia ser reescrita assim:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Nota:** Se a função não puder ser escrita como uma expressão, a sintaxe mais curta de arrow function não pode ser usada.

As variáveis são passadas e usadas dentro de funções anônimas e closures por valor. Isso significa que, se você mudar o valor da variável dentro da função, isso não afetará o valor da variável fora da função. Se você precisar que o valor seja modificado, pode passá-lo por referência.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

No exemplo acima, `array_walk` itera sobre cada elemento do array, enviando cada valor para a função declarada na chamada. Ele mantém um total acumulado em `$total`, em que cada valor somado é o valor absoluto do número. Ele também mantém o controle de quantos números havia. Os dois valores são usados no closure por referência, indicado pelo `&` na frente de cada variável na seção `use`. Isso significa que as mudanças feitas nas variáveis ainda estarão valendo quando o `array_walk` terminar, para que a função possa retornar a média dos valores absolutos dos números no array.

Funções anônimas e closures podem ser uma forma prática de definir uma função que talvez só seja necessária em um único contexto, ou de definir uma função que retorna uma função dinâmica com base em um conjunto de parâmetros conhecidos em um momento diferente daquele em que a função é realmente usada.
