# Introdução

Uma [`function`][function] é uma forma de compartimentar o código para que ela possa ser chamada pelo nome a partir de um ou mais pontos do programa.
As funções servem para realizar tarefas específicas e repetitivas.

De forma mais formal: uma função é qualquer objeto Python ao qual a operação de [`function call`][calls] pode ser aplicada.
Uma função pode ser usada para [`return`][return] um ou mais valores como resultado de uma ou mais operações, ou pode ser usada para um ou mais [`side effects`][side effects].
Se uma função não especificar um valor de retorno, ela ainda assim retorna `None`.

A seguir, um exemplo de uma função com um efeito colateral:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

No exemplo acima, a palavra-chave [`def`][def] sinaliza o início da definição da função.
`hello` é o nome da função.
Os parênteses vazios indicam que nenhum valor está sendo passado para a função.
O corpo da função é a única instrução `print("Hello")`.
`print` também é uma função.
O `"Hello"` entre os parênteses da função `print` é conhecido como um [`argument`][arguments].
O argumento é usado pela função `print` para saber o que imprimir.
Repare que o corpo da função está indentado.
A indentação é importante porque o Python depende dela para saber onde aquele bloco de código termina.
O corpo da função termina no fim do programa ou logo antes da próxima linha de código que _não_ está indentada.
Como `hello()` não especifica um valor de `return`, ela executa seu efeito colateral, que é chamar `print()`, e depois retorna `None`.
Por fim, chamamos a função usando o nome dela e os parênteses, o que sinaliza ao intérprete do Python que esse é um nome _chamável_.

A seguir, um exemplo de uma função com um valor de retorno:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

O corpo dessa função mudou: em vez de _chamar_ `print`, agora ele _retorna_ a `string` "Hello".
No fim, o código ainda imprime `"Hello"`, mas o efeito colateral acontece no _código que chama_, e não na função `hello`.
Se os parênteses forem omitidos ao chamar a função `hello` (por exemplo, `print(hello)`), o `print` exibirá algo como

```
<function hello at 0x0000026E18E93E20>
```

É importante lembrar que, mesmo que uma função não aceite argumentos (ou seja, não tenha parâmetros), os parênteses vazios precisam ser usados para _chamá-la_ corretamente.
Isso é diferente de uma linguagem como Ruby, que não exige parênteses vazios para chamar uma função sem argumentos.

Uma função pode definir zero ou mais [`parameters`][parameters]. Um parâmetro define quais argumentos a função aceita.

A seguir, um exemplo de uma função que aceita um argumento:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

O parâmetro é definido como `name`.
`"Bob"` é o argumento que o programa passa para a função `hello`.
A função _retorna_ a `string` "Hello, Bob".

E se alguém chamar `hello` sem passar um argumento?
O programa lança um erro:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Se não quisermos que o programa dê erro quando não há argumento (mas ainda quisermos permitir que o código que chama não informe nenhum), podemos definir um [argumento padrão][default arguments].
Um argumento padrão define qual valor usar se o argumento estiver faltando quando a função for chamada.

A seguir, um exemplo de uma função com um argumento padrão:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

O parâmetro `name` recebe o argumento padrão `"you"`, então o programa exibe `Hello, you` quando nenhum argumento `name` é passado.

Para saber mais sobre argumentos de função, veja o conceito de [argumentos de função][function arguments].
