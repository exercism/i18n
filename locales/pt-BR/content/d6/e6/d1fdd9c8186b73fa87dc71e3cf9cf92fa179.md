# Instruções

Você está escrevendo o núcleo digital de uma pequena mesa de mixagem em um estúdio de gravação.

O som chega como um fluxo de amostras.
Cada amostra é um número que descreve a posição do cone de um alto-falante em um instante.
Uma mesa processa um bloco inteiro de amostras de uma vez, aplicando a mesma operação a cada uma.

Você tem cinco tarefas, cada uma operando sobre um bloco de amostras mantido na memória.
Você recebe os operandos por meio de endereços de memória e escreve sua resposta por meio de um endereço de resultado.

~~~~exercism/note
Os cálculos deste exercício devem ser feitos com instruções SIMD, e não com operações escalares.
~~~~

## 1. Misturar duas faixas

Às vezes, o estúdio grava instrumentos em faixas diferentes.
Para reproduzi-los nos mesmos alto-falantes, você soma as duas faixas em uma só.

Implemente a função `mix_tracks`, que soma duas faixas, amostra por amostra.
Cada faixa é um bloco de 8 amostras de 16 bits com sinal.
Uma soma que estoura o intervalo de 16 bits com sinal deve saturar em vez de dar a volta.

Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória alinhado a 16 bytes para um buffer onde as 8 amostras mixadas são escritas.
- `track_a`: endereço de memória alinhado a 16 bytes da primeira faixa, com 8 amostras de 16 bits com sinal.
- `track_b`: endereço de memória alinhado a 16 bytes da segunda faixa, com 8 amostras de 16 bits com sinal.

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

Esta função não tem valor de retorno.

## 2. Remover o vazamento

Quando dois microfones gravam ao mesmo tempo, cada um capta uma cópia fraca da fonte do outro.
Essa cópia indesejada é chamada de _vazamento_.
Depois que esse vazamento é medido, ele precisa ser subtraído de volta para limpar a faixa.

Implemente a função `remove_bleed`, que subtrai o bloco de vazamento do bloco da faixa, amostra por amostra.
Cada bloco tem 8 amostras de 16 bits com sinal, e a subtração deve saturar.

Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória onde as 8 amostras limpas são escritas (alinhamento não garantido).
- `track`: endereço de memória alinhado a 16 bytes da faixa gravada, 8 amostras de 16 bits com sinal.
- `bleed`: endereço de memória do vazamento a remover, 8 amostras de 16 bits com sinal (alinhamento não garantido).

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

Esta função não tem valor de retorno.

## 3. Combinar os medidores

Acima de cada canal fica um medidor de nível, uma barrinha cujo brilho mostra o quão alto está aquele canal.
O painel frontal tem um medidor principal que deve brilhar tanto quanto os dois canais combinados.
Você soma os dois blocos de medidores para acioná-lo.

Repare que um medidor brilhante permanece no brilho máximo em vez de voltar para o escuro, então a soma satura.

Implemente a função `combine_meters`, que soma dois blocos de medidores amostra por amostra.
Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória alinhado a 16 bytes onde os 16 valores combinados são escritos.
- `meter_a`: endereço de memória alinhado a 16 bytes do bloco de medidores do primeiro canal, com 16 valores de 8 bits sem sinal empacotados.
- `meter_b`: endereço de memória alinhado a 16 bytes do bloco de medidores do segundo canal, com 16 valores de 8 bits sem sinal empacotados.

Cada bloco tem 16 valores de 8 bits sem sinal.
Eles devem ser somados, saturando para o intervalo sem sinal.

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

Esta função não tem valor de retorno.

## 4. Aplicar um fade

A música não deve parar de repente, mas fazer um fade out no final.
Você tem um bloco de _coeficientes de ganho_, um por amostra, que vão ficando cada vez mais baixos.

Cada coeficiente é uma fração expressa sobre `65536`.
Por exemplo, se uma amostra tem valor `16384`, ela na verdade expressa `16384 / 65536`, que é `1 / 4`.
O maior valor utilizável, `32767`, é pouco menos que a metade.

Como `65536` é `2^16`, multiplicar uma amostra pelo seu coeficiente e manter a _metade alta_ do produto dá `sample * gain / 65536`.

Implemente a função `apply_fade`, que escala cada amostra pelo seu coeficiente.
Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória alinhado a 16 bytes onde todas as amostras escaladas são escritas.
- `track`: endereço de memória alinhado a 16 bytes da faixa, com `n` amostras de 16 bits com sinal.
- `gains`: endereço de memória alinhado a 16 bytes dos coeficientes de ganho, com `n` valores de 16 bits com sinal, cada um no intervalo de `0` a `32767`.
- `n`: o número de amostras, que é sempre diferente de zero e múltiplo de `8`, como um inteiro de 64 bits sem sinal.

Repare que `track` é um array que contém `n` amostras de 16 bits com sinal, em que `n` nunca é zero e é sempre múltiplo de `8`.
Para cada amostra, o resultado escalado são os 16 bits _altos_ do produto com sinal: `sample * gain`.

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
Manter a metade alta arredonda em direção ao infinito negativo.
É por isso que `20000 * 32767` escala para `9999`, enquanto `-20000 * 32767` escala para `-10000` em vez de `-9999`.
~~~~

Esta função não tem valor de retorno.

## 5. Atenuar uma faixa

O baterista foi gravado alto demais.
Para baixar a faixa inteira, você divide cada amostra por uma constante.

Implemente a função `attenuate_track`.
Esta função recebe como argumentos, nesta ordem:

- `result`: endereço de memória alinhado a 16 bytes onde os resultados são escritos, como inteiros de 32 bits com sinal.
- `samples`: endereço de memória alinhado a 16 bytes das amostras, `n` valores de 16 bits com sinal.
- `divisor`: endereço de memória alinhado a 16 bytes de 4 cópias idênticas do divisor, como inteiros de 32 bits.
- `n` é o número de amostras, que é sempre diferente de zero e múltiplo de `4`, como um inteiro de 64 bits sem sinal.

Repare que `samples` é um array que contém `n` amostras de 16 bits com sinal, em que `n` nunca é zero e é sempre múltiplo de `4`.

O divisor é fornecido como `4` cópias do mesmo inteiro de 32 bits, já replicadas para preencher as quatro vias de uma vez.

O SIMD de inteiros não tem divisão empacotada, então o trabalho é feito em ponto flutuante empacotado e depois convertido de volta para inteiros de 32 bits empacotados, para serem armazenados em `result`.
Converta de volta truncando em direção ao zero, então um quociente de `2.3` vira `2` e `-2.3` vira `-2`.

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

Esta função não tem valor de retorno.
