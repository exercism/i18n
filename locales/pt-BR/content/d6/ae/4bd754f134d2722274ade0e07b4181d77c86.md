# Sobre

O tipo primitivo `char` do Java é uma representação de 16 bits de um único caractere Unicode.

~~~~exercism/note
O tipo `char` é baseado na [especificação original do Unicode][unicode-specification], que usava 16 bits para representar caracteres.
Isso é suficiente para cobrir a maioria das letras comuns e abrange os caracteres no intervalo de 0x0000 a 0xFFFF.
Desde então, a especificação ampliou o intervalo de caracteres possíveis até 0x01FFFF.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

Vários `char`s podem compor uma string, como `"word"`, ou os `char`s podem ser processados individualmente.
Um literal `char` é cercado por aspas simples (por exemplo, `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Obtendo os `char`s de uma `String`

O método `String.toCharArray` retorna os chars de uma String como um array.
Como mencionado em [arrays][concept-arrays], você pode usar um laço `for` para iterar sobre o array.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## A classe [Character][docs-character]

Há muitos métodos integrados da biblioteca para inspecionar e manipular `char`s.
Eles podem ser encontrados como métodos estáticos da classe [`java.lang.Character`][docs-character].
Aqui estão alguns exemplos:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Alguns métodos da classe Character têm uma sobrecarga para que possam receber um `char` ou um `int`.
Por exemplo, `isDigit` tem uma que aceita um [`char`][is-digit-char] e outra que aceita um [`int`][is-digit-int].
Como mencionado antes, o tipo `char` só pode representar os caracteres no intervalo de 0x0000 a 0xFFFF.
O `int`, porém, pode representar todos os caracteres, daí as sobrecargas de `int`.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## Adicionando um `char` a uma `String`

O operador `+` pode ser usado para adicionar um `char` a uma `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Cuidado para _não_ usar `+` para juntar dois `char`s e formar uma `String`!
Somar dois `char`s dessa forma resulta em um `int`, _não_ em uma `String`!
Por exemplo:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Isso acontece porque o Java promove o `char` para `int` (veja [4.2 Primitive Types and Values ][jls-primitives] da [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

No entanto, quando há muitos caracteres a serem adicionados, pode ser mais eficiente usar um [`StringBuilder`][docs-stringBuilder]:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
