# Introdução

Na programação, é essencial tratar os erros com cuidado para garantir que situações inesperadas não façam um programa travar ou se comportar de forma imprevisível.
O Cairo oferece dois mecanismos principais para o tratamento de erros:

1. **Erros irrecuperáveis** com `panic`, que param o programa imediatamente.
2. **Erros recuperáveis** com `Result`, que permitem que o programa trate os erros e responda a eles.

## Erros irrecuperáveis com `panic`

Às vezes, um programa encontra um erro tão grave que não consegue continuar.
Nesses casos, o Cairo usa a função `panic` para interromper a execução imediatamente.
Isso ajuda quando um erro, como tentar acessar um índice fora dos limites, torna impossível que o programa continue de forma sensata.
A função `panic` aceita uma mensagem do tipo `ByteArray` que descreve o motivo do erro.

Por exemplo, no Cairo:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

Este exemplo demonstra um panic forçado, que interrompe o programa imediatamente com uma mensagem.

### A macro `assert!`

A macro `assert!` é uma ferramenta útil para impor condições específicas no seu código.
Se a condição em `assert!` for avaliada como `false`, o programa entrará em panic com uma mensagem de erro do tipo `ByteArray`.
Isso é usado com frequência para verificar suposições durante o desenvolvimento e garantir que os valores atendam a certos critérios.

Por exemplo:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

Se `x` não for maior que zero, o programa entrará em panic com a mensagem `"x must be greater than zero"`. A macro `assert!` ajuda a verificar invariantes e pré-condições sem escrever manualmente código de tratamento de erros.

## Erros recuperáveis com `Result`

Nem todos os erros precisam interromper o programa.
Alguns podem ser tratados com cuidado para que o programa continue.
O enum `Result` do Cairo representa esses erros recuperáveis e tem duas variantes:

- `Result::Ok` indica sucesso.
- `Result::Err` representa um erro.

Com `Result`, uma função pode retornar um valor de sucesso ou um erro, permitindo que a função que a chamou decida o que fazer em seguida.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

Neste exemplo, se `b` for zero, um erro é retornado; caso contrário, o resultado da divisão é retornado.
