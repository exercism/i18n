# Instruções adicionais

Se a entrada for inválida, retorne um comprimento vazio.

## Endereços reservados

O buffer da primeira string usa os bytes 1024-2047 da memória linear.
O buffer da segunda string usa os bytes 2048-3071 da memória linear.
O buffer da terceira string usa os bytes 3072-4095 da memória linear.

O primeiro segmento dos bytes 0-1023 da memória linear está livre para uso.
