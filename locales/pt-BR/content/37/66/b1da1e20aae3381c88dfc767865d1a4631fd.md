# Apêndice de instruções

## Instruções específicas da trilha

As funções devem retornar o produto, além do deslocamento e do comprimento do array de fatores.
Os fatores são apenas escritos como pares de i32 na memória:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

Para o maior produto palíndromo de um dígito, ficaria assim:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
