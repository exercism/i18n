# Dicas

## 1. Verifique se a ação 'Ataque rápido' é possível

- O operador lógico de negação (`not`) pode ser colocado antes de uma expressão para negar seu valor.

## 2. Verifique se a ação 'Aproximar e espiar' é possível

- As expressões lógicas são avaliadas da esquerda para a direita e testadas quanto a possíveis 'curtos-circuitos'.

## 3. Verifique se a ação 'Sinalizar para o prisioneiro' é possível

- Os operadores lógicos na ordem de precedência (da maior para a menor): `not`, `&&`, `||`.
