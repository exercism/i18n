# Instruções

Olá, Agente Double-Null0111.

Sua missão, caso decida aceitá-la, é escrever um par de ferramentas para ajudar você a se infiltrar no quartel-general da UMBRA (Lacaios Unidos Sendo Realmente Terríveis) e recuperar os planos do mais recente esquema realmente terrível deles. 
Há três ferramentas de que você vai precisar para cumprir esta missão.

## 1. Gere um número de identificação

Cada lacaio tem um identificador único que muda a cada dia e depende do número de segredos que ele guarda e do número de horas que dorme.
Você vai precisar escrever uma função que recebe o dia (como um `Int`) e cria uma função geradora de identificador para o dia.
A função geradora de identificador recebe dois parâmetros:

1. o número de segredos guardados
2. o número de horas que o lacaio dorme

O identificador é calculado assim:

1. multiplique o número de segredos guardados pelo número de horas que ele dorme
2. some o dia (representado como um `Int`) ao resultado

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. Proteja os planos secretos recuperados com uma senha secreta

Depois de ter os planos secretos, você vai precisar protegê-los para que só quem souber a senha possa recuperá-los.
Para fazer isso, você vai precisar implementar a função `protectSecret(secret: String, password: String) : (String) -> String`.
Essa função retorna outra função que recebe possíveis strings de senha como entrada.
Se a senha digitada estiver correta, a nova função retorna o segredo escondido; mas, se a senha estiver incorreta, a função retorna "Sorry. No hidden secrets here."

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. Encontre a senha secreta

A base da UMBRA tem várias salas guardadas por um segurança que vai pedir a você a senha secreta.
A senha secreta depende do número da sala.
Infelizmente, conhecemos apenas metade do algoritmo para descobrir a senha.
A outra metade pode ser descoberta perguntando a um dos lacaios.

Implemente a função `getPassword` que recebe o seguinte e retorna a senha:

1. o número da sala
2. a função do lacaio e retorna a senha secreta

A senha secreta é obtida chamando a função do lacaio com outra função que representa o algoritmo conhecido por nós.
Nossa parte do algoritmo:

1. recebe dois números e os soma
2. multiplica o resultado pelo id da sala

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
