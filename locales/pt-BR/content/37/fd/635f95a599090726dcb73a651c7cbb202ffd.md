# Apêndice das instruções

## Imprimir a árvore

Este exercício tem alguns métodos de classe predefinidos que ajudam a imprimir a árvore em um formato agradável.
O objetivo principal é ajudar na depuração e deixar tudo mais claro.
Se você implementar o resto da classe corretamente, ela deve imprimir a árvore para você.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
