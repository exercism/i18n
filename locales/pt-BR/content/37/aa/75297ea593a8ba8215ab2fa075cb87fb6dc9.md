# Instruções

Sua tarefa é determinar o que você vai dizer ao entregar o biscoito extra.

Se sua amiga gosta de biscoitos e se chama Do-yun, você vai dizer:

```text
One for Do-yun, one for me.
```

Se ela não gosta de biscoitos, você dá o biscoito para a próxima pessoa da fila na confeitaria.
Como você não sabe o nome dela, você vai dizer _you_ em vez disso.

```text
One for you, one for me.
```

Veja alguns exemplos:

| Nome   | Fala                        |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
