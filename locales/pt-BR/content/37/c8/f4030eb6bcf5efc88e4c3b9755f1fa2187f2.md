- Revise os padrões de expressão regular da introdução. Lembre-se: ao criar o padrão a partir de uma string, você precisa escapar alguns caracteres.
- Leia sobre o módulo [`Regex`][regex-docs] na documentação.
- Leia sobre o [sigil de expressão regular][sigils-regex] no guia de primeiros passos.

## 1. Identificar linhas de log corrompidas

- Use o sigil [`r`][sigil-r] para criar uma expressão regular.
- Existe [um operador][match-operator] que pode ser usado para comparar uma string com uma expressão regular. Também há uma [função do `Regex`][regex-match] e uma [função do `String`][string-match] que fazem o mesmo.
- Não se esqueça de escapar os caracteres que têm significado especial em expressões regulares.

## 2. Dividir a linha de log

- Existe uma [função do `Regex`][regex-split], assim como uma [função do `String`][string-split], que consegue dividir uma string em uma lista de strings com base em uma expressão regular.
- Não se esqueça de escapar os caracteres que têm significado especial em expressões regulares.

## 3. Remover artefatos do log

- Existe uma [função do `Regex`][regex-replace], assim como uma [função do `String`][string-replace], que consegue trocar por outra string uma parte de uma string que corresponde a uma determinada expressão regular.
- Existe um [modificador][regex-modifiers] que pode deixar toda a expressão regular insensível a maiúsculas e minúsculas.

## 4. Marcar linhas com nomes de usuário

- Existe uma [função do `Regex`][regex-run] que executa uma expressão regular em uma string e retorna todas as capturas.
