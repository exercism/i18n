# Sobre

[Tuplas][tuple] são usadas comumente para agrupar informações. Elas diferem das listas por terem tamanho fixo e poderem guardar tipos de dados diferentes.
Tuplas são criadas usando chaves, `()`, e costumam ser usadas para retornar vários valores de uma função.

```haskell
tuple = (1, "abc", False)
```

Isso pode ser útil quando você quer, por exemplo, armazenar uma coordenada em um espaço 2D: aí você sabe que a tupla sempre terá dois elementos, as coordenadas x e y.

```haskell
coordinate = (3, 4)
```

## Acessando elementos

Muitas vezes você trabalha com tuplas curtas, e pode acessar os elementos com as funções `fst` e `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
