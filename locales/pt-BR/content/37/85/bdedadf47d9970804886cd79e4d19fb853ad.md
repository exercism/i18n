# Realce de sintaxe

Existem dois tipos de realce de sintaxe no site:

1. Realce de código _estático_ (trechos de código, iterações e afins).
   Consulte a [documentação de realce de sintaxe estático](/docs/building/tracks/new/syntax-highlighting/static) para saber mais.
2. Realce de código _dinâmico_ (o editor online).
   Consulte a [documentação de realce de sintaxe dinâmico](/docs/building/tracks/new/syntax-highlighting/dynamic) para saber mais.

```exercism/note
Os requisitos para o realce de sintaxe estático e dinâmico são _muito_ diferentes, e é por isso que usam bibliotecas diferentes.
```
