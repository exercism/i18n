# Introdução

Go não tem o conceito de vazio, nulo ou indefinido para valores de variáveis.
Variáveis declaradas sem um valor inicial explícito recebem, por padrão, o valor zero do seu respectivo tipo.

O valor zero para tipos primitivos, como boolean, tipos numéricos e string, é `false`, `0` e `""`, respectivamente.

O identificador `nil`, que significa zero, é o valor zero para tipos mais complexos, como ponteiros, funções, interfaces, slices, canais e mapas.

A tabela a seguir detalha o valor zero dos tipos de Go.

| Tipo      | Valor zero |
| --------- | ---------- |
| boolean   | `false`    |
| numérico  | `0`        |
| string    | `""`       |
| ponteiro  | `nil`      |
| função    | `nil`      |
| interface | `nil`      |
| slice     | `nil`      |
| canal     | `nil`      |
| mapa      | `nil`      |

Você deve ter notado que os tipos struct não aparecem na tabela acima.
Isso acontece porque o valor zero de um tipo struct depende dos seus campos.
Um struct assume seu valor zero quando todos os seus campos assumem seus respectivos valores zero.
