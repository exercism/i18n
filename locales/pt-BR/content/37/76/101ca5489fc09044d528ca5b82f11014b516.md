# Introdução

Em Cairo, não existe um tipo nativo para strings.
Em vez disso, você pode usar um único `felt252` para armazenar uma string curta de até 31 caracteres, ou um `ByteArray` para strings de comprimento arbitrário.
Strings curtas usam aspas simples e o `ByteArray` usa aspas duplas.
Todos os caracteres devem seguir o padrão ASCII.
