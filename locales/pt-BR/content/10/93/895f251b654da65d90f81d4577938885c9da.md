# Instruções

Ellen está criando um jogo em que a pessoa que joga precisa lutar contra aliens.
Ela acabou de aprender sobre Programação Orientada a Objetos (POO) e está ansiosa para aproveitar o que o uso de `classes` pode oferecer ao programa dela.

Para a alegria de Ellen, você se ofereceu para ajudar e ela lhe deu a tarefa de programar os aliens que a pessoa que joga precisa enfrentar.


## 1. Crie a classe Alien

Defina a classe Alien com um construtor que aceita dois parâmetros, `<x_coordinate>` e `<y_coordinate>`, e os coloca nas variáveis de instância `x_coordinate` e `y_coordinate`.
Todo alien também começa com um nível de vida de 3, então a variável `health` também deve ser inicializada.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

Agora, cada alien deve ser capaz de rastrear internamente a própria posição e a própria vida.

## 2. O método `hit`

Ellen gostaria que a `class` Alien tivesse um método `hit` que diminui a vida de um objeto alien em 1 quando chamado.
Assim, ela pode simplesmente chamar `<alien>.hit()` em vez de ter que alterar manualmente a vida de um alien.
Fica a seu critério se `hit()` leva os pontos de vida _para_ ou _abaixo_ de zero.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. O método `is_alive`

Você percebe que, se a vida continuar diminuindo, em algum momento ela provavelmente chegará a 0 (_ou até menos!_).
Seria uma boa ideia adicionar um método `is_alive` que Ellen possa chamar rapidamente para verificar se o alien está... bem... vivo. 😉
`<alien>.is_alive()` deve retornar um Boolean.

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. O método `teleport`

No jogo da Ellen, os aliens têm a habilidade de se teletransportar!
Você vai precisar escrever um método `teleport` que recebe novos valores de `x_coordinate` e `y_coordinate` e muda as coordenadas do alien de acordo.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. O método `collision_detection`

Obviamente, se os aliens podem ser atingidos por algo, eles precisam ser capazes de detectar quando essa colisão acontece.
No entanto, algoritmos de detecção de colisão podem ser complicados, e você ainda não sabe como implementar um.
Ellen disse que vai fazer isso mais tarde, mas ela ainda gostaria que o método `collision_detection` aparecesse na classe como um lembrete para construir essa funcionalidade.
Ele vai precisar receber uma variável de algum tipo (provavelmente outro objeto), mas isso é realmente tudo o que você sabe.
Você vai precisar garantir que colocar a definição do método na classe não cause nenhum erro quando ele for chamado:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. Contador de aliens

Ellen voltou com um novo pedido para você.
Ela quer acompanhar quantos aliens foram criados ao longo do tempo de vida do jogo.
Ela diz que isso tem a ver com o sistema de pontuação.

Por exemplo:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. Criando uma lista de aliens

Ellen adorou o que você fez até agora, mas ela tem mais um favor a pedir.
Ela gostaria de uma função independente (_fora da classe `Alien()`_) que cria uma `list` de objetos `Alien()`, dada uma lista de posições (como `tuples`).

Por exemplo:

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)

```
