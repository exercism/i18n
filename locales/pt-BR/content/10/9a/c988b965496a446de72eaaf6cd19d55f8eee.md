# Introdução

A biblioteca padrão do Elixir oferece 4 módulos diferentes para trabalhar com datas e horários, cada um com sua própria struct.

- O módulo `Date`. Uma struct `Date` pode ser criada com o sigil `~D`.

  ```elixir
  ~D[2021-01-01]
  ```

- O módulo `Time`. Uma struct `Time` pode ser criada com o sigil `~T`.

  ```elixir
  ~T[12:00:00]
  ```

- O módulo `NaiveDateTime` para datas e horas sem fuso horário. Uma struct `NaiveDateTime` pode ser criada com o sigil `~N`.

  ```elixir
  ~N[2021-01-01 12:00:00]
  ```

- O módulo `DateTime` para datas e horas com fuso horário. Usar esse módulo para fusos horários diferentes de UTC exige uma dependência externa, um banco de dados de fusos horários.

## Comparações

Para comparar datas ou horários entre si, procure a função `compare` ou `diff` no módulo correspondente. Operadores de comparação como `==`, `>` e `<` _parecem_ funcionar, mas não fazem uma comparação semântica correta para essas structs.
