# Instalação

Existem muitas formas de instalar o Zig, e o número de formas de instalar o Zig cresce constantemente conforme a linguagem amadurece.
Felizmente, todos os métodos de instalação populares estão listados na [página de instalação do Zig][install-zig].

## Versão do Zig

Atualmente, o Exercism oferece suporte apenas ao Zig 0.16.0 (lançado em 14 de abril de 2026).

Um exercício pode ser compatível com uma versão diferente do Zig, mas isso não é garantido.
O Zig ainda não chegou à versão 1.0, e mudanças que quebram a compatibilidade são comuns.

## Utilitários adicionais

### Zig fmt - Gerando código bem formatado

Ao resolver qualquer exercício, você pode usar todo tipo de estilo de código nas suas soluções.
Porém, fora da resolução de exercícios, como ao criar aplicações ou bibliotecas, normalmente é uma boa ideia manter o código consistente e legível.
Essas premissas são especialmente importantes quando outras pessoas que queiram ajudar nos seus projetos tiverem que ler o seu código.

Para resolver esse problema, o compilador do Zig vem com um [linter][linters] leve integrado, que formata o seu código de forma conveniente.
Este formatador de código busca seguir o [guia de estilo][style-guide] já estabelecido pela [documentação do Zig][documentation].

Para conhecer os recursos do formatador nativo do Zig, use o seguinte comando:

```bash
zig fmt --help
```

### Zig Zen - Regras para programar

Às vezes, uma orientação ajuda bastante ao realizar qualquer tarefa, até mesmo ao escrever código.
Felizmente, temos um comando divertido integrado ao compilador do Zig para nos lembrar de alguns dos objetivos que envolvem escrever um bom código em Zig.

Para conferir essas palavras de sabedoria, use o seguinte comando:

```bash
zig zen
```

### O Zig Language Server - Suporte de editor completo para o Zig

Este software de terceiros oferece autocompletar no editor e recursos aprimorados de navegação pelo código Zig, que podem ajudar você a aprender a linguagem mais rápido.

Consulte o [Guia de instalação do ZLS][install-zls] para as instruções mais recentes.
