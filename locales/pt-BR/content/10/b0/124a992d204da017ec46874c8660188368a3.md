# Introdução

Em Go, strings são imutáveis.
Concatenar strings com `+` dentro de um laço provoca alocações frequentes e copia os dados várias vezes.
O pacote [`strings`](https://pkg.go.dev/strings) fornece o [`Builder`](https://pkg.go.dev/strings#Builder) para minimizar o consumo de memória, montando strings de forma eficiente.

## Construindo strings

O valor zero de um `strings.Builder` já está pronto para uso imediato, sem nenhuma inicialização ou alocação explícita.
Você pode adicionar novos dados ao builder usando métodos de escrita específicos.
Cada método de escrita retorna um valor de erro para satisfazer as interfaces padrão de Go, mas é garantido que ele será sempre `nil` e, no código do dia a dia, costuma ser ignorado.

Os métodos mais usados são:

- `WriteString(s string) (int, error)`: adiciona uma string ao buffer.
- `WriteRune(r rune) (int, error)`: adiciona a codificação UTF-8 de uma rune.
- `WriteByte(c byte) error`: adiciona um único byte.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Recuperando e redefinindo

Quando você terminar de montar seu texto, pode extrair o conteúdo acumulado como uma string padrão de Go chamando o método `String()`.
Chamar `String()` é uma operação muito barata, porque retorna a slice de bytes subjacente como string diretamente, sem copiar os dados acumulados.

Se você precisar reutilizar a mesma instância de builder para montar uma nova string (por exemplo, dentro de um laço), pode chamar o método `Reset()`.
Isso esvazia o buffer interno e permite começar do zero e montar a próxima string, mantendo por baixo dos panos a capacidade de memória já alocada.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
