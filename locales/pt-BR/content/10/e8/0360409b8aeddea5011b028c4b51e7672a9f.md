# Dicas

## Geral

- Leia sobre strings no [guia de strings][string-guide] oficial.
- Explore os [métodos disponíveis para _Strings_][string-methods].

## 1. Limpe o nome

- Existe um [método embutido][string-replace] para substituir todas as ocorrências de uma substring em uma string.
- Existe um [método embutido][string-strip] para remover espaços em branco no início e no fim de uma string.

## 2. Obtenha a primeira letra do nome

- Para obter um caractere específico de uma string, você pode usar o [operador de indexação][string-indexing].

## 3. Formate a primeira letra como inicial

- Existe um [método embutido][string-upcase] para converter todos os caracteres de uma string na sua versão em maiúsculas.

## 4. Coloque as iniciais dentro do coração

- Existe uma sintaxe especial para [interpolar][string-interpolation] uma expressão dentro de uma string.
- Você pode colocar um emoji de coração em uma string usando escape: `\u<id>`, o id do emoji de coração é `2764`.
