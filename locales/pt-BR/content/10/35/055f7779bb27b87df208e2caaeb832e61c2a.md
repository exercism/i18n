# Instruções

Um naturalista está catalogando os dragões que vivem ao redor da
caldeira. Eles compartilham características entre si: todo dragão tem
um nome, uma cor e uma idade, mas cada um se especializa de maneiras
distintas. Você vai construir uma pequena árvore de herança de classes
de dragão e uma única palavra que envelhece qualquer descendente.

## 1. A família dos dragões

Defina toda a árvore de herança de classes de tuplas desde o início (os
construtores vêm nas tarefas a seguir):

- `dragon`, com os campos `name`, `color`, `age`.
- `fire-dragon`, uma subclasse de `dragon`, que adiciona um campo `flame-temp`.
- `ice-dragon`, outra subclasse de `dragon`, que adiciona um campo `chill-temp`.
- `volcano-dragon`, uma subclasse de `fire-dragon`, que adiciona um
  campo `lava-volume`.

Depois, dê a `dragon` um construtor `<dragon>`.

```factor
"Falkor" "white" 100 <dragon> name>> .   ! => "Falkor"
```

## 2. Os cuspidores de fogo

Dê a `fire-dragon` um construtor `<fire-dragon>`.

```factor
"Smaug" "red" 500 1200 <fire-dragon> flame-temp>> .   ! => 1200
"Smaug" "red" 500 1200 <fire-dragon> dragon? .        ! => t
```

## 3. Os cuspidores de gelo

Dê a `ice-dragon` um construtor `<ice-dragon>`.

```factor
"Frosty" "blue" 200 -40 <ice-dragon> chill-temp>> .   ! => -40
"Frosty" "blue" 200 -40 <ice-dragon> fire-dragon? .   ! => f   (siblings)
```

## 4. Os moradores dos vulcões

Dê a `volcano-dragon` um construtor `<volcano-dragon>`.

```factor
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> dragon? .       ! => t
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> fire-dragon? .  ! => t
```

## 5. Envelhecer qualquer dragão

Defina `age-dragon` para incrementar em uma unidade o campo `age` de
qualquer dragão (ou descendente). Não retorna nada.

```factor
"Falkor" "white" 100 <dragon> dup age-dragon age>> .   ! => 101
```

A mesma palavra deve funcionar em qualquer descendente. É exatamente
esse o ponto do acessador compartilhado.
