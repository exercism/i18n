# Introdução

C# é uma linguagem de tipagem estática, o que significa que tudo tem um tipo em tempo de compilação. Atribuir um valor a um nome é o que chamamos de definir uma variável. Uma variável pode ser definida especificando explicitamente o tipo dela, ou deixando o compilador do C# inferir o tipo com base no valor atribuído (o que chamamos de _inferência de tipo_). Portanto, as duas definições de variável a seguir são equivalentes:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Para atualizar o valor de uma variável, usamos o operador `=`. Depois de definida, o tipo de uma variável nunca pode mudar.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# é uma [linguagem orientada a objetos][object-oriented-programming] e exige que todas as funções sejam definidas dentro de uma _classe_. A palavra-chave `class` é usada para definir uma classe. Os objetos (ou _instâncias_) são criados com a palavra-chave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Uma função dentro de uma classe é chamada de _método_. Cada método pode ter zero ou mais parâmetros. Todos os parâmetros precisam ter o tipo especificado explicitamente: não há inferência de tipo para parâmetros. Do mesmo modo, o tipo de retorno também precisa ser explícito. Os valores são retornados dos métodos com a palavra-chave `return`. Para que um método possa ser chamado por código em outros arquivos, é preciso adicionar o modificador de acesso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Os métodos são invocados com a sintaxe de ponto (`.`) em uma instância, especificando o nome do método a chamar e passando argumentos para cada parâmetro dele. Os argumentos podem, opcionalmente, especificar o nome do parâmetro correspondente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

O escopo em C# é definido entre os caracteres `{` e `}`.

C# tem dois tipos de comentários. Comentários de uma linha são precedidos por `//`, e comentários de várias linhas ficam entre `/*` e `*/`.
