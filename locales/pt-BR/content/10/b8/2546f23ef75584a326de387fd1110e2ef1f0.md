# Instruções

Neste exercício, você vai escrever código para gerenciar um dicionário de códigos de discagem internacionais usando um `Map`.

O dicionário permite procurar o nome de um país (o valor do mapa, como uma `String`) pelo código de discagem internacional (a chave do mapa, como um `Integer`).

## 1. Retorne os códigos em um mapa

Implemente o método `getCodes`, que não recebe parâmetros e retorna um mapa dos códigos de discagem para os países que estão atualmente no dicionário.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. Adicione entradas ao dicionário

O dicionário precisa ser populado.
Implemente o método `setDialingCode`, que recebe um código de discagem e o país correspondente e adiciona o código de discagem e o país.
Se o código de discagem já estiver no mapa, atualize o mapa com o código e o país fornecidos.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. Descubra o país de um código de discagem

Implemente o método `getCountry`, que recebe um código de discagem e retorna o nome do país com esse código de discagem.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. Não permita duplicatas

Ao adicionar um código de discagem, é preciso cuidado para evitar que um código ou um país seja adicionado duas vezes.
Nas situações em que isso acontece, pode-se assumir que a primeira entrada é a entrada correta.
Implemente o método `addNewDialingCode`, que adiciona uma entrada para o código de discagem e o país fornecidos.
No entanto, diferentemente de `setDialingCode`, ele não faz nada se o código de discagem ou o país já estiver no mapa.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. Encontre o código de discagem de um país

É raro, mas erros podem acontecer.
Para corrigir o erro, vamos precisar saber a qual código de discagem o país está mapeado no momento.
Para descobrir qual código de discagem precisa ser corrigido, implemente o método `findDialingCode`, que recebe um país e retorna o código de discagem desse país.
Retorne `null` se o país _não_ estiver no mapa.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. Atualize o código de discagem do país

Agora que sabemos qual código de discagem precisa ser corrigido, vamos atualizar o código.
Implemente o método `updateCountryDialingCode`, que recebe o novo código de discagem do país e o nome do país e atualiza de acordo.
Não faça nada se o país _não_ estiver no mapa (já que este método serve apenas para ajudar a corrigir erros).

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
