# Dicas

## 1. Imprima um crachá para um funcionário

- Você pode usar um [template de string][string-template] para criar strings de descrição.
- Existe um [método integrado para converter uma string em maiúsculas][to-upper-case].

## 2. Imprima um crachá para um novo funcionário

- Você deve verificar se o ID é `null` antes de usá-lo.
- Você pode usar um [operador de igualdade][kotlin-operators] para verificar se um valor é `null`.

## 3. Imprima um crachá para o dono

- Você pode usar o [operador Elvis][elvis-operator] para usar um valor alternativo quando uma variável for `null`.
