# Anexo às instruções

## Implementação

Sua função vai receber um array de strings.
Cada string representa uma mão composta de 5 cartas separadas por espaços.
Uma carta é representada por um número e seu naipe.

Você deve retornar um array contendo a melhor mão ou, em caso de empate, as melhores mãos.
Cada mão deve ser uma string no mesmo formato em que foi dada a você inicialmente como entrada.
