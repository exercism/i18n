# Introdução

Structs são uma extensão construída sobre [mapas][exercism-maps] e oferecem verificações em tempo de compilação e valores padrão. Um struct recebe o nome do módulo em que é definido. Para definir um struct, use a construção `defstruct`. A construção geralmente vem logo após a definição do módulo. `defstruct` aceita uma lista de átomos (para valores padrão `nil`) ou uma lista de palavras-chave (para valores padrão especificados). Os campos sem valores padrão devem vir antes dos campos com valores padrão.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Acessar e atualizar campos

Como structs são construídos sobre mapas, podemos usar a maioria das funções de mapas para obter e manipular valores. O _Access Behaviour_ **não** é implementado para structs. Em vez disso, recomenda-se usar o _operador de acesso estático_ `.` para acessar os campos de um struct.

- obter/buscar valores de campos:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- atualizar valores de campos

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Correspondência de padrões

Structs podem ser usados em correspondência de padrões com ou sem o nome do struct.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Ao incluir o nome do struct no padrão, você pode garantir que tanto o lado esquerdo quanto o direito sejam structs do mesmo tipo.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## Exigindo a inicialização de valores de campos

Podemos usar o atributo de módulo `@enforce_keys` com uma lista das chaves dos campos para garantir que os valores sejam inicializados quando o struct é criado. Se uma chave não for listada, seu valor será `nil`, como visto no exemplo acima. Se uma chave exigida não for inicializada, um erro é lançado.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
