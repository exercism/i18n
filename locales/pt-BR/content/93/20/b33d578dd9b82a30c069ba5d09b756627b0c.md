# Instalação

Para instalar o Julia no seu sistema, siga as instruções na [página de downloads da linguagem Julia](https://julialang.org/downloads/).

~~~~exercism/caution
Não é recomendado instalar o Julia pelo gerenciador de pacotes do seu sistema operacional.
Esses pacotes não são mantidos oficialmente e podem causar problemas.
~~~~

Para uma instalação local, existem plugins disponíveis para um grande número de editores/IDEs.
A [extensão do VS Code](https://github.com/julia-vscode/julia-vscode) é a mais popular.
Você pode encontrar integrações para outros editores na organização [JuliaEditorSupport](https://github.com/JuliaEditorSupport) no GitHub.

Se você preferir um ambiente mais interativo, pode usar notebooks Jupyter com o [IJulia](https://github.com/JuliaLang/IJulia.jl), ou usar o [Pluto.jl](https://github.com/fonsp/Pluto.jl) para notebooks reativos simples em Julia.

Uma forma simples de começar com o Julia sem precisar de uma instalação local é o [Nextjournal](https://nextjournal.com/), uma IDE online baseada em notebooks.
Você acessa pelo navegador, faz login e já começa a resolver exercícios.
Se você quiser apenas um REPL online, pode usar o [Repl.it](https://repl.it/languages/julia).
