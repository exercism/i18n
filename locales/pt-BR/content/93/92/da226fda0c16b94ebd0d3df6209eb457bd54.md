# Sobre

As listas em C# são coleções de valores primitivos ou instâncias de structs ou classes. Elas são implementadas na biblioteca de classes base como [`List<T>`][lists-docs], em que `T` é o tipo do item da lista. A API expõe um conjunto rico de métodos para criar e manipular listas.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

Uma definição de coleção normalmente inclui um marcador entre sinais de maior e menor, muitas vezes `T` por convenção. Isso permite que quem usa a coleção especifique que tipo de item armazenar nela.

Diferentemente de [concept:csharp/arrays](), as listas podem redimensionar o próprio tamanho dinamicamente.

## LINQ

Embora a API integrada de `List<T>` seja rica (com mapeamentos e filtros como `ConvertAll`, `FindAll` e `Foreach`) e sua [sintaxe de laço][for-each] seja bem clara, e você com certeza precise conhecer essa API, a Language Integrated Query ([LINQ][linq]) está disponível para muitas tarefas. Ela é ainda mais poderosa e amplamente usada, e tem a vantagem de oferecer uma interface consistente entre coleções de bibliotecas, coleções de terceiros e suas próprias classes.
