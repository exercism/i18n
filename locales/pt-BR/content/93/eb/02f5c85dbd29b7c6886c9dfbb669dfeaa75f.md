# Anexo às instruções

## Implementação

Às vezes você precisa lidar com problemas inesperados que surgem durante a execução do código.
No Dart, você pode usar exceções para lidar com essas situações.

Para lançar uma exceção no Dart, use a palavra-chave `throw` seguida de uma instância da exceção específica que você quer lançar.
Por exemplo, `throw Exception()` lança uma instância do tipo base Exception.

Neste exercício, você precisa definir uma exceção personalizada chamada `InvalidNucleotideException`.
Essa exceção deve ser lançada quando um nucleotídeo inválido for encontrado.
A suíte de testes verifica apenas que uma instância de `InvalidNucleotideException` é lançada, então você tem liberdade para implementá-la como quiser, desde que ela seja lançada corretamente.

Para mais informações sobre exceções no Dart, consulte a [documentação de exceções](https://dart.dev/language/error-handling).
Exceções personalizadas podem ser criadas [implementando a interface Exception](https://dart.dev/language#interfaces-and-abstract-classes).
