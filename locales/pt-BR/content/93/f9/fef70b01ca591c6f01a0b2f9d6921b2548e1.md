# Aprendizado

O COBOL tem uma variedade de recursos para ajudar tanto programadores experientes quanto iniciantes, embora alguns possam ser obscuros. Felizmente, aqui está uma compilação de algumas fontes populares.

## Livros

- [Beginning COBOL for Programmers][Coughlan Book]  
Este livro de Michael Coughlan cobre desde o básico da escrita em COBOL até o padrão de 2002. Ele também inclui exercícios para praticar programação, que foram concluídos e reunidos neste [Repositório do GitHub][Book Exercises].

- [Ebooks de COBOL gratuitos][Free Books]

## Documentação

- [GnuCOBOL's Programmer's Guide][Gnu Guide]  
Este recurso cobre os elementos do compilador GnuCOBOL e é atualizado regularmente conforme o próprio compilador muda.

## Cursos

- [Open Mainframe Project COBOL Course][Open Mainframe]  
Este curso cobre o dialeto IBM no ambiente VSCode fornecido.
