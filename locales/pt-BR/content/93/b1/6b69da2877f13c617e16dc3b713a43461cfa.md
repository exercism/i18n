# Introdução

## Funções de callback

Funções de callback são funções passadas como argumentos. Esse padrão de programação cria uma sequência de chamadas de função tanto na programação síncrona quanto na assíncrona. Escrever uma função de callback não é diferente de escrever uma função; no entanto, a função de callback precisa corresponder à assinatura definida pela função que a chama.

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

Você também pode escrever callbacks como uma expressão de função:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
