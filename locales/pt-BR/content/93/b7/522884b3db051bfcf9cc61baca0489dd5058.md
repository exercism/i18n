# Instruções

Você vai escrever um pouco de código para gerenciar uma lista de linguagens de programação para aprender.

## 1. Adicionar uma linguagem a uma lista

Modifique a sub-rotina `add-language`, que recebe uma lista de linguagens e um nome de linguagem como argumentos, para retornar uma lista com a nova linguagem adicionada ao final.

## 2. Remover uma linguagem de uma lista

Modifique a sub-rotina `remove-language` para remover a última linguagem de uma lista fornecida.

## 3. Buscar a primeira linguagem de uma lista

Modifique a sub-rotina `first-language` para retornar a primeira linguagem de uma lista fornecida.

## 4. Buscar a última linguagem de uma lista

Modifique a sub-rotina `last-language` para retornar a última linguagem de uma lista fornecida.

## 5. Buscar uma fatia de linguagens de uma lista

Modifique a sub-rotina `get-languages`, que recebe uma lista de linguagens e uma lista de números para os elementos desejados, para retornar uma fatia da lista fornecida.

## 6. Verificar se uma linguagem existe em uma lista

Modifique a sub-rotina `has-language`, que recebe uma lista de linguagens e um nome de linguagem como argumentos, para retornar `True` ou `False`, indicando se a linguagem existe na lista fornecida.
