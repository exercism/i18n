# Classes imutáveis

Um `SCOREBOARD` é uma coisa que muda. Dois nomes para um mesmo placar veem a
mesma pontuação, porque só existe um placar e os dois nomes apontam para ele.

Um rumo não funciona assim. `350 degrees` não se transforma em outra coisa:
ele simplesmente *é*. Os números funcionam assim, e as strings também. E as
suas próprias classes também podem.

## immutable

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

Duas palavras mudam tudo. Um objeto de uma classe imutável é um **valor**, e
não algo para o qual se aponta:

- ele é copiado quando atribuído ou passado adiante, então ninguém mais pode
  mudar o seu;
- ele nunca pode ser void;
- e não se pode atribuir aos seus atributos.

## Mudar um criando outro

Como `degrees := 90` não é permitido, o `attr` oferece outra coisa: uma rotina
que recebe o novo valor e responde com **um novo objeto** já com ele alterado.

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

O original fica intocado. É essa a ideia toda, e é assim que `create` é
escrito:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

Não existe `new` aqui. Um objeto imutável sempre existe, então `b : SAME` já é
um, com todos os atributos no seu valor vazio.

Uma rotina que "muda" um rumo, portanto, retorna um novo rumo:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## Comparar

Valores são comparados pelo que contêm, e não por qual objeto são. Mas você
precisa dizer como. Escreva `is_eq`, e o `=` vai usá-lo:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

Sem isso, o `=` entre dois rumos não compila.

## Qual escolher

Use uma classe imutável quando a coisa não tem identidade e nada nela pode
mudar de forma sensata: um rumo, um ponto, uma data, um comprimento. Use uma
classe comum quando a coisa é um objeto específico a que as coisas acontecem:
um placar, um harness, um arquivo.

O teste é se "o mesmo" significa "igual" ou "exatamente o mesmo objeto".
