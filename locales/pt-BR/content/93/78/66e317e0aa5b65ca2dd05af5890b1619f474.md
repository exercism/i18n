# Módulo

Comparações com módulo são perfeitamente válidas em Crystal, mas uma forma mais legível de comparar o resto de uma divisão é com o método [`divisible_by?`][divisible_by].
Por exemplo:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
