# Apêndice

## Comportamento do Zipper

O Zipper oferece uma forma funcional de navegar por uma árvore de `Node`.

Todas as chamadas do Zipper devem retornar um objeto Zipper _novo_.
Se o Zipper não alterar valores (ou seja, nenhum método `Set*` foi chamado), ele deve usar a mesma árvore subjacente.
Quando um método `Set*` é chamado, o novo Zipper deve ter uma nova árvore, deixando a árvore original inalterada.

Chamadas do Zipper que mudam o foco para um `Node` inválido devem retornar um erro.
