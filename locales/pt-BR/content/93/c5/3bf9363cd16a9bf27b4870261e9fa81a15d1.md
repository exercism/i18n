# Manipulação de tipos

A manipulação de tipos também é conhecida como coerção de tipos.
A manipulação de tipos acontece quando dois valores de tipos diferentes são coagidos ao mesmo tipo para que uma operação possa ser realizada.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

Quando a expressão é avaliada, o valor do tipo string é convertido implicitamente para um `int` para atender ao que o operador `*` espera.
A decisão de qual tipo usar na coerção é do PHP, de acordo com as regras da operação, e essas regras variam bastante.

A coerção de tipos também acontece ao chamar funções e métodos:

```php
strlen(12321);
# => 5
```

## Conversão de tipos

Em vez de depender da coerção implícita, podemos forçar explicitamente que um valor seja avaliado como um determinado tipo usando a conversão de tipos no estilo de `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Isso converte o valor para o tipo especificado entre os parênteses `(...)`.
Todos os tipos primitivos podem ser usados como tipo de destino: `bool`, `int`, `float`, `string`, `array`, `object`.

## Conversão apenas temporária

A manipulação de tipos ou a conversão **não altera** o tipo do valor armazenado em uma variável.
Apenas o valor de entrada da operação é convertido.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## Perda de informação

Quando um valor é coagido para outro tipo, pode haver perda de informação no processo:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

Depender da conversão, seja explícita ou implícita, pode gerar erros em um sistema maior.

## Conversão explícita para `array` e `object`

Valores também podem ser convertidos para os tipos `array` e `object`.
Se um valor que não é um array nem um object for convertido para `array`, ele vira um único item dentro de um array:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

Quando convertido para `object`, o valor é atribuído a uma propriedade pública chamada `scalar`:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` é o tipo de uma classe anônima embutida no PHP.
