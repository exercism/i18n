# Testes

Para rodar os testes, execute o comando `bal test --offline` dentro do diretório do exercício.

## Testes ignorados

Inicialmente, apenas o primeiro teste estará habilitado.
A ideia é incentivar você a resolver o exercício um passo de cada vez.
Quando você conseguir fazer o primeiro teste passar, remova a propriedade `enable: false` do próximo teste e trabalhe para fazer esse teste passar também.
