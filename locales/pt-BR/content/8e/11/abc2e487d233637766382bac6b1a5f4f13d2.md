# Introdução

O Swift tem um conjunto de instruções que podem ser usadas para alterar o fluxo de controle normal dos laços. Elas são conhecidas como instruções de transferência de controle.
Você já viu o `return`; este conceito vai apresentar outras, entre elas `continue`, `break` e rótulos.

## Continue

Às vezes é necessário pular para a próxima iteração de um laço mais cedo, sem completar o restante das instruções da iteração atual do laço.
A palavra-chave `continue` pode ser usada para isso.
Quando o `continue` é executado, o laço salta para a próxima verificação para saber se a iteração seguinte pode rodar, ou seja, o `while` nos laços while e repeat-while, ou a verificação de se há outro elemento na sequência nos laços for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

O break é usado para sair de um laço mais cedo.
Quando o `break` é executado, o laço é encerrado imediatamente e o programa continua a partir da primeira instrução depois do laço.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Rótulos

Quando os laços estão aninhados, há momentos em que você pode querer usar `break` ou `continue` para sair ou reiniciar os laços externos que contêm o laço no qual o `break` ou o `continue` são usados.
Em casos como esses, rótulos podem ser usados para especificar qual laço deve ser encerrado ou reiniciado.
Um laço pode receber um rótulo colocando um nome seguido de dois-pontos antes do `while`, do `repeat` ou do `for` que inicia o laço.

Para ver o efeito de usar rótulos dessa forma, observe o laço a seguir.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

A palavra-chave `fallthrough` é usada para seguir adiante para o próximo case de uma instrução switch.
Isso significa que o código dentro do próximo case será executado sem verificar as suas condições.
Isso faz a instrução switch se comportar como em outras linguagens de programação, nas quais a instrução `break` não é necessária para sair da instrução switch depois que um case encontra correspondência.
Você pode ler mais sobre o `fallthrough` no [livro do Swift][fallthrough].

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
