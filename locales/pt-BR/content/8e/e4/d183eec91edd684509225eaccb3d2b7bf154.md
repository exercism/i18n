# Dicas

## Geral

- Leia sobre listas de palavras-chave no [Guia de primeiros passos][getting-started-keyword-lists] oficial.
- Leia sobre listas de palavras-chave no [elixirschool.com][elixir-school-keyword-lists].
- Dê uma olhada na [documentação do módulo `Keyword`][keyword].

## 1. Explique as cores dos vinhos

- Você precisa escrever as informações da tabela como uma lista de palavras-chave.
- Dê uma olhada em alguns [exemplos][keyword-examples] de como definir uma lista de palavras-chave.

## 2. Obtenha todos os vinhos de uma determinada cor

- Existe uma [função interna][keyword-get-values] para obter a lista de todos os valores de uma determinada chave.

## 3. Obtenha todos os vinhos de uma determinada cor engarrafados em um determinado ano

- Existe uma [função interna][keyword-get] para obter um único valor de uma determinada chave.
- Você não precisa implementar a filtragem das garrafas sozinho. Você só precisa usar condicionalmente a função `filter_by_year/2`, que já está implementada.

## 4. Obtenha todos os vinhos de uma determinada cor engarrafados em um determinado país

- Existe uma [função interna][keyword-get] para obter um único valor de uma determinada chave.
- Você não precisa implementar a filtragem das garrafas sozinho. Você só precisa usar condicionalmente a função `filter_by_country/2`, que já está implementada.
