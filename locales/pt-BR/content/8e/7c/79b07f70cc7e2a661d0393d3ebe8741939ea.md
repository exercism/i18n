# Introdução

Haxe é uma linguagem fortemente tipada, mas o sistema de tipos pode ser subvertido quando necessário. Atribuir um valor a um nome é o que chamamos de definir uma variável. Você pode definir uma variável especificando explicitamente o tipo dela ou deixando o compilador do Haxe inferir o tipo. Por isso, as duas definições de variável a seguir são equivalentes:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Para atualizar uma variável, use o operador `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

O compilador lança um erro quando você tenta atribuir um valor cujo tipo é diferente do da variável:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Uma função que está dentro de uma classe é chamada de _método_. Métodos podem ter zero ou mais parâmetros. Todos os parâmetros precisam ter o tipo declarado explicitamente. Assim como os parâmetros, o tipo de retorno de um método não pode ser inferido e precisa ser declarado. Os valores são retornados dos métodos com a palavra-chave `return`:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Para chamar um método, você especifica o nome da classe e do método e passa os argumentos:

```haxe
var sum = add(1, 2) // sum = 3
```

O escopo em Haxe é definido entre os caracteres `{` e `}`.

Haxe tem dois tipos de comentários. Os de uma linha são precedidos por `//` e os de várias linhas ficam entre `/*` e `*/`.
