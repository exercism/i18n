# Sobrecarga de operadores

A sobrecarga de operadores é um recurso de algumas linguagens de programação que permite redefinir operadores padrão, como adição (`+`), subtração (`-`), multiplicação (`*`) e divisão (`/`), para que funcionem com tipos definidos pelo usuário.

Isso pode deixar a sintaxe do código mais intuitiva, pois permite expressar operações com tipos definidos pelo usuário do mesmo jeito que operações com tipos primitivos.

No Cairo, a sobrecarga de operadores é obtida por meio da implementação de traits específicas.

Cada operador tem uma trait associada, e sobrecarregar esse operador envolve fornecer uma implementação dessa trait para um tipo personalizado.
No entanto, é essencial usar a sobrecarga de operadores com bom senso.

O uso indevido pode causar confusão e deixar o código mais difícil de manter, por exemplo quando o operador sobrecarregado não tem significado semântico.

Considere um exemplo em que duas `Potions` precisam ser combinadas.

As `Potions` têm dois campos de dados, mana e health.

Combinar duas `Potions` deve somar os respectivos campos.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

No código acima, estamos implementando a trait `Add` para o tipo `Potion`.

A função add recebe dois argumentos: `lhs` e `rhs` (lado esquerdo e lado direito).

O corpo da função retorna uma nova instância de `Potion`, com os valores dos campos sendo uma combinação de `lhs` e `rhs`.

Como o exemplo ilustra, sobrecarregar um operador exige especificar o tipo concreto que está sendo sobrecarregado.

A trait genérica sobrecarregada é `Add<T>`, e definimos uma implementação concreta para o tipo `Potion` com `Add<Potion>`.
