# Instruções

Conte os retângulos em um diagrama ASCII como o que está abaixo.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

O diagrama acima contém estes 6 retângulos:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

Você pode assumir que a entrada é sempre um retângulo bem formado (ou seja, o comprimento de cada linha é igual ao comprimento da primeira linha).
