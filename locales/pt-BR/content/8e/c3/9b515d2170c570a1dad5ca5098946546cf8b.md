# Apêndice das instruções

## Notas de implementação

`Range` deve retornar uma lista de todos os trios pitagóricos com lados no intervalo de `min` a `max`, inclusive.

`Sum` deve retornar uma lista de todos os trios pitagóricos em que a soma `a+b+c` (o perímetro) seja igual a `p`.
Os três elementos de cada trio retornado devem estar em ordem, `t[0] <= t[1] <= t[2]`, e a lista de trios deve estar em ordem lexicográfica.
