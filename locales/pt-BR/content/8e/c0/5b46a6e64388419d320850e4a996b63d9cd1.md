# Apêndice das instruções

## Implementação

É possível ficar sem nomes de robô: quando todos os nomes possíveis já tiverem sido atribuídos, um erro deve ser retornado.

## Teste bônus

Quando você conseguir fazer o `go test` passar, vai encontrar na suíte de testes um teste chamado `TestCollisions`, que é ignorado por padrão porque pode demorar bastante.
Esse teste cria novos robôs até que não seja mais possível atribuir nomes novos ao robô.

Para fazer o teste rodar, remova esta linha:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

Para fazer esse teste passar, você vai precisar garantir que o nome de um robô não tenha sido usado antes e que os nomes possam ser atribuídos de forma eficiente.
