# Instruções

Neste exercício você vai escrever código para ajudar uma pessoa freelancer a se comunicar com seus clientes sobre os preços de determinados projetos.
Você vai escrever alguns métodos utilitários para calcular rapidamente os custos para os clientes.

```exercism/note
O parâmetro `rate_per_hour` e o método `day_rate` estão relacionados a dinheiro.
As unidades de medida são dinheiro por unidade de tempo: horas e dias, respectivamente.
```

## 1. Calcule o valor diário a partir de um valor por hora

Um cliente entra em contato com a pessoa freelancer para perguntar sobre seus valores.
A pessoa freelancer explica que **_trabalha 8 horas por dia._**
No entanto, ela conhece apenas seu valor por hora do projeto.
Ajude-a a estimar um valor diário a partir de um valor por hora.

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

O valor diário não precisa ser arredondado nem ajustado para uma precisão "fixa".

## 2. Calcule o número de dias de trabalho a partir de um orçamento fixo

Em outro dia, um gerente de projeto oferece à pessoa freelancer a chance de trabalhar em um projeto com um orçamento fixo.
Dado o orçamento fixo e o valor por hora da pessoa freelancer, ajude-a a calcular quantos dias ela trabalharia até o orçamento acabar.
O resultado _deve_ ser **arredondado para baixo** para o número inteiro mais próximo.

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. Calcule o valor com desconto para projetos grandes

Muitas vezes, os clientes da pessoa freelancer a contratam para projetos que duram vários meses.
Nesses casos, ela decide oferecer um desconto para cada mês completo, e os dias restantes são cobrados pelo valor diário.
O seu excelente equilíbrio entre vida pessoal e trabalho significa que você trabalha apenas 22 dias em cada mês do calendário, então **_todo mês tem 22 dias faturáveis._**
Ajude-a a estimar o custo desses projetos, dado um valor por hora, o número de dias faturáveis que o projeto tem e uma taxa de desconto mensal.
O desconto é sempre passado como um número, em que `42%` vira `0.42`. O resultado _deve_ ser **arredondado para cima** para o número inteiro mais próximo.

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
