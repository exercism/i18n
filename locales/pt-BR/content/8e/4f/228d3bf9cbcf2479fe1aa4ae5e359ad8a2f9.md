# Dicas

Alguns (não todos) dos testes assumem que o valor é `Int32`, então evite forçá-lo a ser outra coisa.

## 1. Desloque os bits de volta

- Isto é um deslocamento à direita.
- Repare que a instrução pede que os resultados sejam preenchidos com zeros à esquerda.

## 2. Defina alguns bits

- Os bits são definidos com um OR bit a bit com uma máscara. Isso é extremamente comum.

## 3. Inverta bits específicos

- Existe uma piada antiga entre programadores de que os criptógrafos descobriram o XOR e esqueceram de ler o resto do manual.
