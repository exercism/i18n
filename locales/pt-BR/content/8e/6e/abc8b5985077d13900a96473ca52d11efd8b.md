# Testes

## Clojure CLI

Os exercícios de Clojure no Exercism vêm com um arquivo `deps.edn` com um alias `:test` para invocar o [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

## Leiningen

Você também pode usar o Leiningen para rodar os testes do exercício com o seguinte comando, a partir do diretório do exercício:

```bash
lein test
```

## REPL

Para usar o REPL e rodar os testes do exercício, execute o seguinte comando a partir do diretório do exercício:

```bash
$ clj
```

-ou-

```bash
$ lein repl
```

Depois, use `require` no namespace de testes do exercício e no namespace de testes do Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

Depois, chame `run-tests` em `<exercise>-test`:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
