# Introdução

## Genéricos

### Introdução

Genéricos são um recurso da linguagem que permite reutilizar código.
Por exemplo, não deveria importar qual tipo uma lista contém para calcular o seu comprimento.
É por isso que a função `length` usa um parâmetro de tipo genérico `a` na sua assinatura de tipo.

```elm
length : List a -> Int
```

### Parâmetros em tipos

Quando um tipo é genérico sobre outro tipo, usamos um nome em minúsculas para esse outro tipo e o chamamos de parâmetro de tipo.
Exemplos comuns são os tipos personalizados `List`, `Maybe` e `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Uma observação importante sobre os nomes dos parâmetros de tipo é que eles podem ter vários caracteres.
A única restrição é que devem ser nomes em minúsculas.
Por isso, quando é útil, costumamos dar a eles nomes descritivos.

Um tipo pode ser genérico sobre vários outros tipos e, portanto, ter vários parâmetros de tipo.
Nesse caso, cada tipo independente recebe um nome diferente em minúsculas.
Serem independentes não impede que se tornem o mesmo tipo, apenas permite que sejam diferentes.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Aliases de tipo de registro também podem ter parâmetros de tipo, embora seja menos comum.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### Parâmetros de tipo em funções

Como os tipos podem ser genéricos, as funções também podem.
Funções que lidam com tipos genéricos podem ser escritas, como a `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Funções que recebem outras funções como parâmetros são chamadas de funções de ordem superior, e elas também podem ser genéricas.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
