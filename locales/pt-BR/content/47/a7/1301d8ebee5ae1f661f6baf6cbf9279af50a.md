# Dicas

## 1. Defina o intervalo de fileiras e colunas

- Há um [operador][swift-range-docs] para criar um intervalo, que pode ser usado tanto para strings quanto para inteiros.

## 2. Verifique se a casa é válida

- Há um [método][contains-docs] para verificar se um valor está dentro de um intervalo.

## 3. Obtenha a fileira

- Cada fileira deve ter 8 de comprimento.
- Para cada fileira, começando em 1, você terá que deslocar o início e o fim em 8.
- Você pode usar um intervalo para obter um subarray do array.
