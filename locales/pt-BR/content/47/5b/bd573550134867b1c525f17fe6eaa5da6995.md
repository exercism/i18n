# Apêndice das instruções

## Dicas

Você precisa implementar a função

```haskell
value :: (Color, Color) -> Int
```

que aceita apenas duas cores e produz o componente numérico do valor da resistência do resistor.

**Bônus - Testes de propriedades:**

Este exercício é uma boa oportunidade para escrever alguns [testes de propriedade](https://en.wikipedia.org/wiki/Property_testing). Se você nunca escreveu nenhum antes, aqui estão alguns recursos:

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

Fornecemos um exemplo de teste de propriedade com QuickCheck no arquivo de teste.

Exemplos de propriedades que podem ser testadas:

- `value (x, y) >= 10` para todo `(x, y)` em que `x` não é `Black`

- Chamar `show` em `value (x, y)` produz a String com `reverse` aplicado à chamada de `show` em `value (y, x)`.

- Todas as cores têm nomes únicos. (Para quaisquer duas cores, se as cores forem diferentes, seus nomes também serão.)
