# Tuplas

Tuplas são uma forma leve de agrupar um conjunto fixo de dados de tipos arbitrários. Uma tupla não tem
um nome próprio; dar nome a uma estrutura de dados a transforma em uma `struct`. Os campos de uma tupla
não têm nomes; o acesso a eles é feito por desestruturação ou por posição.

## Sintaxe

Tuplas são uma lista de campos entre parênteses:

- `()` é o `unit type`, que é um [caso especial](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _expressão_ **,)** é uma expressão de tupla de um único elemento
- **(** _Tipo_ **,)** é um tipo de tupla de um único elemento
- **(** _expressão_ **,** ... **)** é uma expressão de tupla geral
- **(** _Tipo_ **,** ... **)** é um tipo de tupla geral

### Criação

As tuplas são sempre criadas com uma expressão de tupla:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

As tuplas podem ter um número arbitrário de elementos.

### Acesso por desestruturação

É possível acessar os elementos de uma tupla por desestruturação. Isso significa simplesmente atribuir
nomes de variáveis aos elementos individuais da tupla, consumindo-a.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Acesso por posição

Também é possível acessar os elementos de uma tupla por um índice numérico posicional. A indexação,
como sempre, começa em 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Structs de tupla

Você também vai trabalhar com structs de tupla. Assim como as structs normais, elas são tipos nomeados;
diferente das structs normais, elas têm campos anônimos. A sintaxe delas é muito parecida com a sintaxe
normal de tuplas. É permitido usar tanto a desestruturação quanto o acesso posicional.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### Visibilidade dos campos

Todos os campos de tuplas anônimas são sempre públicos. Já os campos de structs de tupla têm
visibilidade individual, que por padrão é privada, assim como os campos de structs normais. Você pode
tornar os campos públicos com o modificador `pub`, exatamente como em uma struct normal.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
