# Ajuda

## Instalação do Rust

Consulte a [página de ajuda do Exercism][help-page] para saber como instalar o Rust e para recursos de aprendizado.

## Como enviar a solução

Em geral, você deve enviar todos os arquivos em que implementou sua solução (`src/lib.rs` na maioria dos casos). Se estiver usando crates externos, considere enviar o arquivo `Cargo.toml`. Isso deixa o processo de revisão mais rápido e mais claro.

## Feedback, problemas e pull requests

Acesse [o fórum](https://forum.exercism.org/c/programming/rust/) e crie um post para dar feedback sobre um exercício ou se quiser ajudar a implementar novos exercícios.
Os membros da equipe da trilha de Rust terão prazer em ajudar!

O [repositório da trilha][github] no GitHub é a casa de todos os exercícios de Rust.

Se quiser saber mais sobre o Exercism, dê uma olhada no [guia de contribuição][contribution guide].

## Como enviar soluções incompletas
É possível enviar uma solução incompleta para ver como outras pessoas resolveram o exercício.
