## Geral

## 1. Calcular o valor de uma carta

- As instruções [cmp][cmp] e [test][test] são úteis para definir flags de acordo com algumas condições testadas.

- Você pode usar `cmp` para comparar duas cartas, definindo as flags apropriadas.
- Você pode usar `je` ou `jz` para desviar se um número for igual ao outro.
- Você pode usar `jl` para desviar se um número for menor que o outro.

- Você pode usar `jg` para desviar se um número for maior que o outro, e `jl` para desviar se for menor.
