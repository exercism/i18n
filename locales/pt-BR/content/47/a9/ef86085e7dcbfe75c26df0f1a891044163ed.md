# Introdução

O operador `|>` é chamado de operador pipe. Ele pode ser usado para encadear chamadas de função, de modo que o valor retornado pela chamada de função anterior seja passado como o primeiro argumento da próxima chamada de função.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
