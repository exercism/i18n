# Instalação

A versão atual do elm é a 0.19.1.
As instruções de instalação mudam conforme a linguagem evolui.
Para instruções de instalação atualizadas, acesse as
[instruções de instalação do guia do elm][elm-install].

[elm-install]: https://guide.elm-lang.org/install/elm.html

## Ferramentas adicionais

**elm-test**

A ferramenta usada para rodar os testes pela linha de comando se chama elm-test.
No momento, o elm-test exige Node.js e npm, então, se você ainda não tem,
[instale primeiro o Node.js e o npm][npm-install].
Depois de instalar o npm, você pode instalar o elm-test com:

```shell
npm install --global elm-test@latest-0.19.1
```

Mais informações na [página do elm-test no npm][elm-test].

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

A maioria dos programadores de elm usa o elm-format para formatar o código elm.
É uma ferramenta de formatação de código sem configuração.
No começo pode parecer um pouco frustrante se você não está acostumado
com ferramentas de formatação automática, mas depois que se acostuma,
você começa a se perguntar como conseguia programar sem ela antes.
Ela também pode ser instalada com o npm:

```shell
npm install --global elm-format@latest-0.19.1
```

Mais informações na [página do elm-format no GitHub][elm-format].

[elm-format]: https://github.com/avh4/elm-format

**Editor de texto**

O suporte a Elm é bom pelo menos no [IntelliJ][intellij],
e em editores de texto compatíveis com o [servidor de linguagem do elm][els],
como VS Code, Sublime Text ou Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## Erros de permissão com o npm

Talvez você esteja vendo um erro de permissões EACCESS com o npm
ao instalar o elm-test ou o elm-format.
Se for o caso, siga as instruções no site do npm.
[Como resolver erros de permissão EACCES ao instalar pacotes globalmente][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
