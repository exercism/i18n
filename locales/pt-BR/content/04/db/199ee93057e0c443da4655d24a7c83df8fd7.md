# Sobre

## Igualdade

Os tipos de Elm podem ser verificados quanto a "serem iguais" com o [operador de igualdade][equality-operator] `(==)`.
O operador de desigualdade é `(/=)` (*não* `!=` como em muitas linguagens).

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

Os dois valores comparados precisam ser do mesmo tipo.
O operador de igualdade funciona com literais, tuplas, registros e tipos personalizados.
O operador verifica a igualdade estrutural. Isso significa que valores iguais têm o mesmo conteúdo e a mesma estrutura profunda, independentemente de anotação de tipo ou de posição na memória.

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Repare que você *nunca deve* comparar funções, pois isso fará o programa travar em tempo de execução.
Mais informações sobre essa limitação [aqui][equality-operator].

## Comparações

Os [operadores de comparação][comparison-operators] `(<)`, `(<=)`, `(>)`, `(>=)` e as funções `min`, `max` e `compare` funcionam com tipos `comparable`.
O tipo `comparable` é um tipo especial que agrupa todos os tipos internos que podem ser comparados: números, caracteres, strings, listas de coisas comparáveis e tuplas de coisas comparáveis.
Os caracteres são comparados a partir de seus [pontos de código Unicode][unicode-codepoint].

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

Tipos que se comportam como sequências (strings, listas e tuplas) são comparados em [ordem lexicográfica][lexicographic-order].
Em resumo, os elementos da sequência são comparados aos pares, em ordem, até que um elemento seja menor ou uma sequência termine.

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

Valores de outros tipos, como registros ou tipos personalizados, não podem ser comparados diretamente.

Alguns tipos internos exigem que seu conteúdo seja `comparable`, como as chaves de `Set` ou `Dict`, já que sua estrutura depende de uma ordenação interna.
Isso implica que tipos personalizados não podem ser armazenados em um `Set`, embora existam alternativas da comunidade: [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] e outras.

Listas de valores `comparable` podem ser ordenadas com `List.sort`, e listas de valores que podem ser mapeados para valores comparáveis podem ser ordenadas com `List.sortBy`.
Se você precisar de uma ordenação hierárquica (ordenar por uma propriedade e desempatar com outra), tuplas ou listas podem ser usadas com `List.sortBy` (entre outras [alternativas][sort-by]), já que tuplas e listas são ordenadas em ordem lexicográfica.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

A função `compare` recebe dois valores `comparable` e retorna um `Order`.
Um `Order` é um tipo que verifica, em uma única operação, se um valor é maior (`GT`), igual (`EQ`) ou menor (`LT`) que outro.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

Funções de comparação podem ser construídas para tipos arbitrários e usadas, por exemplo, para ordenar com `List.sortWith`:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
