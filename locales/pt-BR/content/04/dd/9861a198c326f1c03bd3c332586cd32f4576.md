# Números

`INT` guarda um número inteiro. Neste Sather ele tem exatamente 32 bits, então
conta de -2147483648 a 2147483647.

```sather
   goals : INT is
      return 42;
   end;
```

## Argumentos

Uma rotina recebe argumentos entre parênteses, cada um com um tipo:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Argumentos que compartilham um tipo podem compartilhar a declaração, que é o
estilo usual:

```sather
   total(first, second : INT) : INT is
```

## Aritmética

| Operador | Significado |
| --- | --- |
| `+` | adicionar |
| `-` | subtrair e negar |
| `*` | multiplicar |
| `/` | dividir, descartando o resto |
| `%` | o resto dessa divisão |

`/` entre dois `INT`s nunca produz uma fração:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

Se você quiser uma fração, vai precisar de `FLTD`, que aparece mais adiante.

A multiplicação e a divisão têm precedência sobre a adição e a subtração, como
na aritmética comum. Os parênteses agrupam quando você precisa de outra coisa:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## Rotinas úteis em INT

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

`.str` é como um número passa a fazer parte de uma frase, depois que você
conhecer as strings.
