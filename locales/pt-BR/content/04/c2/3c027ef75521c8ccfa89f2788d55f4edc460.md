# Introdução

## Operadores de comparação

R tem um conjunto de operadores igual ao de muitas outras linguagens:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Ramificação

A forma básica de um if-else é:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

Nesse caso, tanto os parênteses `()` em volta do Boolean quanto as chaves `{}` em volta do corpo são obrigatórios.

Uma condicional `if` simples pode ser encurtada:

```R
if (x == 0) return("success")
```
