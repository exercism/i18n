# Ignore isto

## Entrada

Seu script receberá o quebra-cabeça alfanumérico como uma única string via
entrada padrão (stdin). A string do quebra-cabeça segue o formato
`WORD1 + WORD2 + ... == RESULT`.

Por exemplo:

```text
SEND + MORE == MONEY
```

## Saída

Se o quebra-cabeça tiver solução, imprima uma única linha composta de pares
`LETTER=DIGIT` separados por espaço, ordenados alfabeticamente pela letra.

Para o exemplo acima, a saída deve ser:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

Se o quebra-cabeça tiver várias soluções válidas, imprimir qualquer uma delas
é aceitável.

Se o quebra-cabeça não tiver solução, não imprima nada (uma linha vazia).
