# Instruções

Converta um número binário, representado como uma string (por exemplo, '101010'), para o seu equivalente decimal usando os princípios básicos.

Implemente a conversão de binário para decimal.
Dada uma string de entrada binária, seu programa deve produzir uma saída decimal.
O programa deve lidar com entradas inválidas.

## Observação

- Implemente a conversão por conta própria.
  Não use outra coisa para fazer a conversão no seu lugar.

## Sobre binário (base 2)

O decimal é um sistema de base 10.

Um número 23 na notação de base 10 pode ser entendido como uma combinação linear de potências de 10:

- O dígito mais à direita é multiplicado por 10^0 = 1
- O próximo número é multiplicado por 10^1 = 10
- ...
- O *n*-ésimo número é multiplicado por 10^*(n-1)*.
- Todos esses valores são somados.

Então: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

O binário é parecido, mas usa potências de 2 em vez de potências de 10.

Então: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
