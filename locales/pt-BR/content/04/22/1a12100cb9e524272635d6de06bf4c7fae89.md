# Instruções

Você é o contramestre de um cargueiro costeiro. A sentina, o compartimento mais baixo do casco, acumula águas residuais, e a cada turno o equipamento da sentina precisa ser aberto, acionado e guardado. Aconteça o que acontecer no meio do bombeamento, o equipamento *precisa* terminar de volta ao seu estado guardado.

Os testes fornecem `<test-pump>` para você obter bombas novas. Cada bomba tem um slot `opened>>` que lê `t` enquanto está aberta e `f` depois que ela é descartada.

## 1. Drenar a sentina

Defina `drain-bilge` para liberar uma única bomba. Chamar `drain-bilge` na mesma bomba duas vezes deve ser inofensivo: o framework cuida disso para você.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. Rotina de bombeamento

Defina `pump-out` para receber uma bomba e uma quotation, empurrar a bomba para a pilha para a quotation usar, e liberar a bomba em seguida, *mesmo que a quotation lance uma exceção*.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. Rotina de turno completo

Defina `shift-routine` para receber duas bombas e uma quotation. Abra um escopo de destrutor, registre *as duas* bombas para liberação incondicional e depois chame a quotation. As duas bombas acabam liberadas, quer a quotation termine normalmente, quer lance uma exceção.

A quotation recebe as duas bombas na pilha como entradas.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. Bombeamento arriscado

Às vezes uma bomba está emprestada: você só quer descartá-la se algo der errado; caso contrário, o próximo turno precisa que ela fique aberta. Defina `risky-pump-out` para receber uma bomba e uma quotation, registrar a bomba para liberação **apenas em caso de falha** e chamar a quotation com a bomba na pilha.

Se a quotation terminar com sucesso, a bomba fica aberta. Se a quotation lançar uma exceção, a bomba é liberada e a exceção se propaga.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. Um disposable personalizado: a válvula

Complete o conjunto de ferramentas com um disposable novinho em folha: uma `valve`. A tupla já está declarada para você:

```factor
TUPLE: valve < disposable is-open ;
```

- Defina `<valve> ( -- valve )` para construir uma válvula nova via `new-disposable`, com `is-open` definido como `t`.
- Implemente `M: valve dispose*` para mudar `is-open` para `f`.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
