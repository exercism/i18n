# Instruções

Neste exercício, você vai implementar uma forma de acompanhar as pontuações mais altas do jogo mais popular do fliperama da sua região.

## 1. Defina um novo mapa de pontuações

Para criar um novo mapa de pontuações, defina a função `HighScore.new/0`, que não recebe nenhum argumento e retorna um mapa de pontuações novo e vazio.

```elixir
HighScore.new()
# => %{}
```

## 2. Adicione jogadores ao mapa de pontuações

Para adicionar um jogador ao mapa de pontuações, defina `HighScore.add_player/3`, uma função que recebe 3 argumentos:

- O primeiro argumento é o mapa de pontuações.
- O segundo argumento é o nome de um jogador, como uma string.
- O terceiro argumento é a pontuação, como um número inteiro. O argumento é opcional: implemente o terceiro argumento com um valor padrão de 0.

Guarde a pontuação inicial padrão em um atributo de módulo. Ela vai ser necessária de novo.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. Remova jogadores do mapa de pontuações

Para remover um jogador do mapa de pontuações, defina `HighScore.remove_player/2`, que recebe 2 argumentos:

- O primeiro argumento é o mapa de pontuações.
- O segundo argumento é o nome do jogador, como uma string.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. Redefina a pontuação de um jogador

Para redefinir a pontuação de um jogador, defina `HighScore.reset_score/2`, que recebe 2 argumentos:

- O primeiro argumento é o mapa de pontuações.
- O segundo argumento é o nome do jogador, como uma string, cuja pontuação você quer redefinir.

A função também deve funcionar se o jogador não tiver uma pontuação.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. Atualize a pontuação de um jogador

Para atualizar a pontuação de um jogador somando à pontuação anterior, defina `HighScore.update_score/3`, que recebe 3 argumentos:

- O primeiro argumento é o mapa de pontuações.
- O segundo argumento é o nome do jogador, como uma string, cuja pontuação você quer atualizar.
- O terceiro argumento é a pontuação que você quer **somar** à pontuação armazenada.

A função também deve funcionar se o jogador não tiver uma pontuação anterior: considere que a pontuação anterior é 0.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. Obtenha uma lista de jogadores

Para obter uma lista de jogadores, defina `HighScore.get_players/1`, que recebe 1 argumento:

- O primeiro argumento é o mapa de pontuações.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
