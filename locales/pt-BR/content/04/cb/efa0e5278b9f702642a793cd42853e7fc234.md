# Instruções complementares

## Personalizando e lançando exceções

Às vezes é necessário tanto [personalizar](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) quanto usar [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) em exceções no seu código. Quando você faz isso, deve sempre incluir uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda muito no debug.

Exceções personalizadas podem ser criadas por meio de novas classes de exceção (consulte [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) para mais detalhes) que normalmente são subclasses de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

Em situações em que você sabe que a origem do erro será uma derivada de um certo tipo de exceção, você pode escolher herdar de um dos [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) sob a classe _Exception_. Ao lançar o erro, você ainda deve incluir uma mensagem significativa.

Este exercício em particular exige que você crie duas _exceções personalizadas_. Uma exceção a ser [lançada](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/"disparada" quando seu buffer circular estiver **cheio**, e outra para quando ele estiver **vazio**. Os testes só passarão se você personalizar as exceções adequadas, lançá-las com `raise` e incluir mensagens de erro adequadas.

Para personalizar uma `built-in exception`, crie uma `class` que herde dessa exceção. Ao lançar a exceção personalizada com uma mensagem, escreva a mensagem como argumento para o tipo `exception`:

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
