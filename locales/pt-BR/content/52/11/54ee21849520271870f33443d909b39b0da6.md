# Introdução

Laços são usados para executar alguma lógica repetidas vezes.
Os dois tipos mais comuns são o `while loop` (repetição indefinida) e o `for loop` (repetição definida, ou contada).
Existe também o laço `for each`, que vai aparecer em um conceito mais adiante.


## Sintaxe geral

O `for loop` é composto por um cabeçalho e um bloco de código que contém o corpo do laço entre chaves.
O cabeçalho é composto por 3 componentes separados por ponto e vírgula `;`: instrução de inicialização, condição e uma outra expressão.
Cada um deles pode ficar vazio.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- O componente **init** é um código que roda apenas uma vez, antes de o laço começar.
- O componente **condition** precisa ser uma expressão que resulte em um Boolean e que controle quando o laço deve parar.
O código dentro do laço vai rodar enquanto essa condição for verdadeira.
Assim que essa expressão for falsa, nenhuma outra iteração do laço vai rodar.
- O componente **expression** é um código que roda no final de cada iteração.


O `while loop` executa o seu corpo enquanto a verificação da condição for verdadeira.
O trecho de código abaixo mostra como transformar um laço `for` em um laço `while`.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## Interlúdio: incrementos e decrementos

Ao trabalhar com laços, muitas vezes é preciso somar 1 ou subtrair 1 de uma variável contadora.
Isso é tão comum que a operação tem operadores especiais: `++` e `--`.

Eles existem em uma forma prefixa e uma forma posfixa.
A forma prefixa muda a variável antes do uso na instrução, e a forma posfixa muda depois.
Na maioria das vezes, você provavelmente vai querer a versão prefixa.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## Laços `for` - um exemplo

O componente init normalmente prepara uma variável contadora, a condição verifica se o laço deve continuar ou parar e o componente post normalmente incrementa o contador no fim de cada repetição.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Esse laço vai somar os números de `1` a `9` (incluindo `9`).

## Break e continue

Dentro do corpo de um laço, você pode usar a palavra-chave `break` para interromper a execução do laço por completo:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Já a palavra-chave `continue` interrompe apenas a execução da iteração atual e segue para a próxima:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> Observação: normalmente é mais fácil entender a lógica do laço quando o uso de `break` e `continue` é minimizado ou totalmente evitado.
