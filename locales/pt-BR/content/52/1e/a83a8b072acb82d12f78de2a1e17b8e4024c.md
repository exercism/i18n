# Testes

Rode os testes com `exercism test` ou `eutest`. Por padrão, todos os testes são executados.

## Como pular testes

Uma boa forma de começar é comentar todos os testes, exceto o primeiro, em `t_<exercise>.e`.

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

Resolva um de cada vez e descomente o próximo teste assim que o atual passar. Quando todos os testes passarem, você concluiu o exercício.
