# Condicionais

O Ruby tem o que são conhecidas como expressões de controle de fluxo. Elas são usadas para controlar a forma como o programa será executado e recebem um valor verdadeiro ou falso.
Existem operadores que podem ser usados para criar valores verdadeiros ou falsos, conhecidos como [operadores de comparação][comparison-operators].

Existem duas expressões de controle principais que definem qual código será executado e qual não será.
Ou seja, qual bloco será executado.

Essas duas são: `if` e a expressão `unless`.

## Operadores de comparação

Os [operadores de comparação][comparison-operators] são usados para comparar valores e retornar um valor `true` ou `false`.
Os operadores a seguir exigem dois valores do mesmo tipo para serem comparados.
Se os valores não forem do mesmo tipo, o compilador lançará um erro.
Veja uma lista dos operadores e um exemplo de quando eles resultam em `true`:

| Método | Descrição           | Exemplo |
| ------ | --------------------- | ------- |
| <      | menor que             | 4 < 5   |
| <=     | menor ou igual a      | 4 <= 4  |
| >      | maior que             | 3 > 1   |
| >=     | maior ou igual a      | 2 >= 2  |

Os operadores de igualdade e desigualdade podem ser usados para comparar qualquer tipo de valor, ao contrário dos operadores já mencionados.
O operador `==` é usado para verificar se dois valores são iguais, e isso inclui verificar o tipo do valor.
O `!=` funciona do mesmo jeito, mas retorna `true` se os valores forem diferentes e `false` se forem iguais.
Veja uma lista dos operadores de igualdade e desigualdade e um exemplo de quando eles resultam em `true`:

| Método | Descrição  | Exemplo |
| ------ | ------------ | ------- |
| ==     | igual a      | 4 == 4  |
| !=     | diferente de | 5 != 4  |

## Condicional if

A condicional [`if`][if] serve para verificar se uma determinada condição é "verdadeira" ou "falsa".
Se a condição for verdadeira, o código dentro da condicional if será executado.
Uma condicional `if` termina com a palavra-chave `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Condicional unless

A condicional `unless` funciona de forma muito parecida com a condicional `if`, mas executa o código dentro da condicional `unless` se a condição for falsa.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Condicional else

A condicional `else` pode ser usada em conjunto com a condicional `if`.
A condicional `else` será executada se o bloco do `if` não for executado.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Condicionais em cascata

A condicional `elsif` pode ser usada em conjunto com a condicional if.
A condicional `elsif` será executada se o bloco do if não for executado e a condição da condicional elsif for verdadeira.
As condicionais elsif podem ser encadeadas, e a primeira condição verdadeira será executada.
Também pode haver uma condicional else no final da condicional if, que será executada se nenhuma das condicionais anteriores tiver sido verdadeira.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
