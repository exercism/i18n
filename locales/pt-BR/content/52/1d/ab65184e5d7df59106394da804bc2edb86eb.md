# Instruções

Neste exercício, você vai escrever código para ajudar um freelancer a se comunicar com um gerente de projetos.
Sua tarefa é fornecer alguns utilitários para calcular rapidamente os valores diários e mensais, opcionalmente com um desconto informado.

Primeiro, estabelecemos algumas regras entre o freelancer e o gerente de projetos:

- O valor diário é 8 vezes o valor por hora.
- Um mês tem 22 dias faturáveis.

Às vezes, o freelancer se oferece para aplicar um desconto sobre o valor diário (por exemplo, para os clientes mais fiéis ou para clientes sem fins lucrativos).

Os descontos são modelados como números fracionários que representam porcentagens, por exemplo, `25.0` (25%).

## 1. Calcule o valor diário a partir do valor por hora

Implemente uma função chamada `dailyRateFrom` para calcular o valor diário a partir de um valor por hora como parâmetro.
O contrato define que um dia tem 8 horas faturáveis.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

O valor diário retornado deve ser um `Double`.

## 2. Calcule o valor mensal a partir do valor por hora e de um desconto

Implemente uma função `monthlyRateFrom` para calcular o valor mensal com desconto.
Ela recebe dois parâmetros: um valor por hora e o desconto em porcentagem.


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

O valor mensal retornado deve ser arredondado para cima (usando o teto) para o número inteiro mais próximo.

## 3. Calcule o número de dias úteis completos a partir de um orçamento, do valor por hora e de um desconto

Implemente uma função `workdaysIn` que recebe um orçamento, um valor por hora e um desconto, e calcula quantos dias completos de trabalho isso cobre.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
O número de dias retornado deve ser arredondado para baixo (usando o piso) para o próximo número inteiro.
