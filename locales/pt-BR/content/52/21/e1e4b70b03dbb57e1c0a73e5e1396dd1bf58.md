# Sobre

O tipo `Option` é o mecanismo da linguagem F# para lidar com valores que podem ou não existir.
Ele oferece uma alternativa segura em termos de tipos ao uso de `null`, comum em outras linguagens para lidar com esses valores.
Ele é usado em muitas funções da biblioteca padrão do F#, então entender esse tipo é essencial para usar a biblioteca padrão do F# de forma eficaz.

## Vantagens de usar o tipo `Option`

* __Segurança em tempo de compilação__: ao tornar explícita no sistema de tipos a presença ou a ausência de um valor, o compilador consegue garantir que você trate o caso de "nenhum valor", evitando uma grande categoria de bugs que poderiam ocorrer com o uso de `null`.

* __Segurança em tempo de execução__: em vez de usar `null`, o F# usa `None` para representar a ausência de um valor, o que torna impossível a ocorrência de uma `NullReferenceException`.

* __Força um tratamento explícito__: o sistema de tipos exige que o código trate explicitamente tanto o caso `Some value` quanto o caso `None`, deixando seu código mais robusto e previsível.

* __Funciona com correspondência de padrões__: os valores `Option` funcionam perfeitamente com o recurso de correspondência de padrões do F#, oferecendo uma forma limpa e segura de desestruturar e tratar o valor, se ele existir, ou de executar uma ação diferente, se não existir.

## Uso 

O tipo `Option` é um tipo genérico (que tem um tipo subjacente).  
Os valores `Option` são `Some value`, que representa um valor específico, ou `None`, que representa a ausência de valor.

A função a seguir mostra como criar um valor `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` é a sintaxe pós-fixada equivalente a `Option<T>`; as duas formas de sintaxe podem ser usadas de maneira intercambiável.
No entanto, segundo o Guia de Estilo do F#, a notação pós-fixada é preferida para tipos Option (veja a [seção do Guia de Estilo do F# sobre formatação de tipos e anotações de tipo](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

Um caso de uso típico de `Option` são as funções de busca. 
Por exemplo, a função `List.tryFind` retorna `Some index` quando o item está na lista (em que `index` é a posição do valor procurado na lista), ou `None` quando o item não está na lista.

## Lendo o conteúdo de um valor Option

A forma idiomática de ler um valor `Option` é por meio da correspondência de padrões, como mostra o exemplo a seguir:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Desempacotando Options com valores padrão

Os valores `Option` podem ser "desempacotados" (convertidos para o tipo que eles contêm) ao fornecer valores padrão com a função `Option.defaultValue`. 
Isso é especialmente útil quando você quer garantir que o valor não seja `None`.
Por exemplo:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## Mais funções no módulo `Option`

O módulo `Option` também inclui funções que correspondem às funções disponíveis para listas, arrays, sequências e outros tipos de coleção, como `Option.map`, `Option.iter`, `Option.forall` e `Option.count`. 
Essas funções permitem tratar os valores `Option` como uma coleção de zero ou um elemento.
