## Como usar

### Compilar

`npx blueprint build` ou `yarn blueprint build`

### Testar

`npx blueprint test` ou `yarn blueprint test`

### Publicar ou rodar outro script

`npx blueprint run` ou `yarn blueprint run`

### Adicionar um novo contrato

`npx blueprint create ContractName` ou `yarn blueprint create ContractName`
