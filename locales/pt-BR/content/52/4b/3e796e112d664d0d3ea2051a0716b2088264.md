# Apêndice de instruções

# Entrada

As entradas deste exercício são:

- `target`: uma string (por exemplo, `'stone'`) será o _argumento esquerdo_.
- `candidates`: uma lista de strings em caixas (por exemplo, `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) será o _argumento direito_.

Seu verbo será chamado assim:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## Saída

Seu verbo deve retornar uma _lista_ de caixas contendo as strings que são anagramas do target. Se não houver anagramas, o resultado deve ser `empty`.
