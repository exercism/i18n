# Instruções

Você faz trabalho voluntário no centro de artes comunitário, onde um longo
mosaico de ladrilhos cerâmicos está sendo montado sobre a entrada principal. A
equipe de design organizou o trabalho **fileira por fileira**: cada fileira é um
array de cores de ladrilho, e o mosaico inteiro é um array de fileiras.

Enquanto os voluntários cortam, posicionam e reorganizam ladrilhos, você está
escrevendo pequenas palavras reutilizáveis para montar, combinar e consultar
partes do design.

## 1. Uma fileira de um só ladrilho

Defina `tile-strip` para receber uma cor e retornar uma fileira de 1 elemento
contendo apenas essa cor.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. Uma fileira de três ladrilhos

Defina `row-of-three` para pegar três cores da pilha e retornar uma fileira de 3
elementos.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. Combine as fileiras em uma lista plana de ladrilhos

A equipe de design precisa conferir os totais de cores em todas as fileiras do
mosaico. Defina `combine-rows` para receber um array de fileiras e retornar uma
única sequência com todos os ladrilhos em ordem.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. Espelhe uma fileira

Para painéis simétricos, a equipe espelha uma fileira antes de colocar a cópia
no lado oposto. Defina `mirror-row` para retornar uma fileira na ordem inversa.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. Onde está essa cor na fileira?

Defina `tile-position` para receber uma fileira e uma cor e retornar o índice
(começando em 0) do primeiro ladrilho com essa cor na fileira. Se a cor não
estiver presente, retorne `f`.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. Essa fileira contém a cor?

Defina `has-colour?` para receber uma fileira e uma cor e retornar `t` se a cor
aparecer em qualquer lugar da fileira, caso contrário `f`.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
