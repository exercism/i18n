# Sobre

C# é uma linguagem de programação multiparadigma e de tipagem estática, com recursos orientados a objetos, declarativos, funcionais, genéricos, preguiçosos, de consulta integrada e de inferência de tipos.

**Tipagem estática** significa que os identificadores têm um [tipo](https://en.wikipedia.org/wiki/Type_system#Static_type_checking) definido em tempo de compilação, como os de Java, C++ ou Haskell, em vez de conter dados de qualquer tipo como os de Python, Ruby ou JavaScript.

**Orientada a objetos** significa que C# oferece [objetos imperativos baseados em classes](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming) com recursos como herança simples, interfaces e encapsulamento.

**Declarativa** significa programar [o que deve ser feito](https://stackoverflow.com/questions/1784664/what-is-the-difference-between-declarative-and-imperative-programming), em oposição a como é feito (também conhecido como programação imperativa) (que é um detalhe de implementação que pode desviar a atenção do domínio ou da lógica de negócio).

**Funcional** significa que [funções são tipos de dados de primeira classe](https://livebook.manning.com/#!/book/functional-programming-in-c-sharp/chapter-1) que podem ser passadas como argumentos para outras funções e retornadas por elas.

**Genérica** significa que os algoritmos são escritos em termos de tipos [a serem especificados depois](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/generics/generic-type-parameters) que, em seguida, são instanciados, quando necessário, para os tipos específicos fornecidos como parâmetros.

**Preguiçosa** [(também conhecida como "execução adiada")](https://blogs.msdn.microsoft.com/pedram/2007/06/02/lazy-evaluation-in-c/) significa que o compilador adia a avaliação de um item até que ele seja necessário. Isso permite fazer com segurança coisas estranhas, como operar sobre uma lista infinita: a linguagem só vai criar a lista até o último valor necessário.

**Consulta integrada** significa o recurso da linguagem chamado [LINQ "Language-Integrated Query"](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/linq/), que permite consultas preguiçosas diretamente dentro da linguagem, não apenas sobre seus próprios objetos, mas também sobre fontes de dados externas por meio de formatos como XML, JSON, SQL, bancos NoSQL e fluxos de eventos.

**Inferência de tipos** significa que o compilador muitas vezes descobre o tipo de um identificador sozinho, para que você não precise especificá-lo. Scala e F# fazem isso também.

**Sintaxe** é semelhante à de outras linguagens no estilo C, como C, C++ e Java.

**.NET** é o ambiente gerenciado no qual o C# é executado, então você tem acesso a todo o ecossistema .NET, incluindo todos os pacotes em [nuget.org](http://www.nuget.org). O .NET costumava funcionar apenas no Windows, mas com o lançamento do [.NET Core](https://www.microsoft.com/net/core), assim como do [Mono](http://www.mono-project.com/), você também pode usar C# em Mac, Linux ou sistemas baseados em Unix e em plataformas móveis também.

C# também tem recursos, entre outros, para facilitar a programação com múltiplas threads/processadores, paralelização, assincronia, código não gerenciado em um ambiente gerenciado e interoperabilidade entre linguagens. Ela é desenvolvida e mantida pela Microsoft, que fornece a [documentação](https://docs.microsoft.com/en-us/dotnet/csharp/) oficial.
