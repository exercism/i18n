# Introdução

## Laços

Laços servem para executar alguma lógica repetidamente.
Os dois tipos mais comuns são o `while loop` (repetição indefinida) e o `for loop` (repetição definida, ou contada).
Existe também o laço `for each`, que vai aparecer em um conceito mais adiante.

### Sintaxe geral

O `for loop` é formado por um cabeçalho e um bloco de código que contém o corpo do laço entre chaves.
O cabeçalho é composto por 3 componentes separados por ponto e vírgula `;`: instrução de inicialização, condição e outra expressão.
Qualquer um deles pode ficar vazio.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- O componente **instrução de inicialização** é o código que roda só uma vez, antes de o laço começar.
- O componente **condição** precisa ser uma expressão que resulte em um `boolean` e que controla quando o laço deve parar.
  O código dentro do laço roda enquanto essa condição for `true`.
  Assim que essa expressão for `false`, o laço não roda mais nenhuma iteração.
- O componente **expressão** é um código que roda no fim de cada iteração.

O `while loop` executa o seu corpo enquanto a verificação da **condição** for `true`.
O trecho de código abaixo mostra como transformar um `for` em um `while loop`.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### Interlúdio: incrementos e decrementos

Ao trabalhar com laços, muitas vezes é preciso somar 1 ou subtrair 1 de uma variável contadora que acompanha as iterações.
Isso é tão comum que as ações de incremento e de decremento têm operadores especiais: `++` e `--`.

Eles existem na forma **prefixada** e na forma **pós-fixada**.
A versão prefixada altera a variável antes do uso na instrução; a pós-fixada, depois.
Na maioria das vezes, você provavelmente vai querer a versão prefixada.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### Laços `for`: um exemplo

O _componente de inicialização_ geralmente cria uma variável contadora, a _condição_ verifica se o laço deve continuar ou parar, e o _componente final_ geralmente incrementa o contador no fim de cada repetição.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Esse laço soma os números de `1` a `9` (incluindo o `9`).

### `break` e `continue`

Dentro do corpo de um laço, você pode usar a palavra-chave `break` para interromper a execução do laço por completo:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Já a palavra-chave `continue` interrompe apenas a execução da iteração atual e segue para a próxima:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
Normalmente é mais fácil entender a lógica do laço quando o uso de `break` e `continue` é reduzido ao mínimo ou evitado por completo.
As duas palavras-chave pulam certas partes do código e, muitas vezes, dificultam acompanhar o que acontece.
~~~~
