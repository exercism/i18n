# Instruções

Era uma vez uma cidade movimentada chamada Cyberspace.
Cyberspace era uma metrópole digital, com milhões de habitantes entrando e saindo todos os dias.
Para acompanhar todos esses usuários, Cyberspace tinha um arquivo especial chamado /etc/passwd.

O arquivo /etc/passwd era como uma lista telefônica da cidade.
Ele listava todos os usuários que tinham uma conta no sistema, junto com algumas informações importantes sobre cada usuário:

| n   | campo |
| --- | --- |
| 1   | nome de usuário |
| 2   | senha ("x" indica que a senha de verdade é armazenada em outro lugar, por segurança) |
| 3   | UID, um ID numérico único de usuário |
| 4   | GID, um ID numérico único de grupo (normalmente o mesmo que o UID) |
| 5   | informações do usuário (normalmente o nome completo da pessoa, mas pode incluir outras informações) |
| 6   | diretório home |
| 7   | shell de login |

Os campos são separados por dois-pontos.
Esta é uma entrada típica:

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

O arquivo era gerenciado por uma equipe de administradores de sistemas, responsáveis por criar novas contas, atualizar contas existentes e remover contas antigas.
Os administradores de sistemas eram os guardiões do Cyberspace, garantindo que apenas usuários autorizados pudessem acessar o sistema.

Um dia, Alex, um novo administrador de sistemas, foi contratado para se juntar à equipe.
Alex ficou empolgado com o trabalho e logo aprendeu todos os detalhes do arquivo /etc/passwd.
Aprendeu a adicionar novos usuários ao sistema, a atualizar informações de usuários e a remover usuários antigos.

Enquanto trabalhava no arquivo /etc/passwd, Alex percebeu algo estranho.
Alguns usuários tinham diretórios home estranhos ou incomuns.
Alguns tinham o diretório home definido como /dev/null, enquanto outros tinham o diretório home definido como caminhos estranhos que nem existiam.

Alex percebeu que esses usuários não eram pessoas de verdade, mas contas falsas que tinham sido criadas por hackers.
Os hackers tinham encontrado uma forma de explorar uma vulnerabilidade no sistema e criado essas contas falsas para conseguir acesso ao Cyberspace.

Alex sabia que precisava agir.
Usou o awk para analisar o arquivo /etc/passwd e escreveu um script para identificar todas as contas falsas.
Depois, trabalhou com o restante da equipe para remover essas contas e corrigir a vulnerabilidade que tinha permitido que os hackers as criassem.

Graças ao uso do awk por Alex, a equipe conseguiu identificar e remover as contas falsas e tornar o Cyberspace um lugar mais seguro para todo mundo.
Os administradores de sistemas continuaram gerenciando o arquivo /etc/passwd, mantendo-o atualizado e seguro e garantindo que apenas usuários autorizados pudessem acessar o sistema.

Agora é a sua vez de ser um administrador de sistemas como Alex.

## 1. Liste os nomes de usuário

Escreva um programa awk que imprima o primeiro campo separado por dois-pontos de cada linha do arquivo passwd.

## 2. Imprima os números das linhas

Escreva um comando awk que imprima o número da linha de cada registro no arquivo de entrada.
Imprima apenas o número da linha, e nenhuma outra informação.

## 3. Imprima os registros com diretórios home inválidos.

No Cyberspace, um diretório home "válido" começa com `/home` ou `/root`.
Imprima os registros do arquivo de entrada com diretórios home **inválidos**.

## 4. Imprima os usuários válidos que usam bash

Imprima os registros em que o diretório home é válido **e** o shell de login é `bash`.
