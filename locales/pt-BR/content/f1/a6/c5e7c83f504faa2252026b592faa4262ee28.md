# Dicas

## 1. Verifique se um espectador tem direito ao desconto para idosos

- Use [o operador ternário][doc-ternary] para verificar a idade do espectador.

## 2. Verifique se um espectador pode ver filmes de terror

- [Compare][doc-integer-gtoe] a idade do espectador com a idade mínima permitida para ver filmes de terror. Nesta tarefa, você nem precisa do operador ternário.

## 3. Verifique se um espectador tem direito a pipoca grátis

- Use uma das condicionais [`if`][doc-if]/[`unless`][doc-unless] para verificar se um espectador tem direito a pipoca grátis.
- Use [`raise`][doc-raise].
