# Dicas

## Geral

- Uma [struct][structs] pode conter vários campos de tipos diferentes.
- O [tipo Option][option] representa um valor que pode ser `Some(value)` ou `None`.
- A [construção `match`][match]: como fazer correspondência de padrões em Cairo.

## 1. Implemente o método `revive`

- Use [instruções condicionais][if-else] para verificar se a vida do jogador é 0.
- Você pode criar uma nova instância de `Player` usando [sintaxe de inicialização de struct][structs].
- Use [correspondência de padrões][match] ou lógica condicional para determinar o valor de mana com base no nível do jogador.
- Retorne `Option::Some(player)` quando o jogador for revivido com sucesso ou `Option::None` quando não for possível revivê-lo.

## 2. Implemente o método `cast_spell`

- Use [correspondência de padrões][match] no tipo `Option` para tratar os casos `Some` e `None` de mana.
- Você pode usar [operadores de comparação][operators] para verificar se há mana suficiente.
- Você pode usar os [operadores matemáticos][operators] para subtração e multiplicação a fim de calcular valores.
- Lembre-se de modificar o estado do jogador (vida ou mana) usando referências mutáveis.
