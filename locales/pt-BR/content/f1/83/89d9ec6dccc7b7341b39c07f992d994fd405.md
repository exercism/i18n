# Instruções

Um banco movimentado atende os clientes que esperam por *prioridade*, e não na ordem em que chegaram. Cada cliente recebe um número de prioridade ao pegar uma senha, e o caixa sempre atende o menor número em seguida (`1` é o mais urgente). Um heap mínimo é a fila de espera perfeita.

## 1. Abra a fila

Defina `new-queue`, que não recebe nada e retorna uma fila de prioridade nova e vazia.

```factor
new-queue
! => an empty priority queue
```

## 2. Adicione um cliente

Defina `join-queue`, que recebe o nome de um cliente, um número de prioridade e uma fila. Ela adiciona o cliente à fila e retorna a fila, para que os clientes possam ser adicionados um depois do outro.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. Quem é o próximo?

Defina `next-name`, que recebe uma fila e retorna o nome do cliente que deve ser atendido em seguida, aquele com o menor número de prioridade, *sem* removê-lo.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. Atenda todo mundo

Defina `serve-all`, que recebe uma fila e retorna os nomes de todos os clientes que estão esperando, na ordem em que seriam atendidos.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
