### Introdução

Bem-vindo ao primeiro exercício da trilha Java!

Este documento é um guia passo a passo para resolver este exercício.
As instruções devem funcionar igualmente bem no Windows, no macOS e no Linux.

Mesmo que você já conheça o básico de Java, percorrer este guia pode ser útil. Ele vai ajudar você a entender a saída da ferramenta Gradle, que usamos para compilar e testar nosso código, além de apresentar alguns dos padrões comuns a todos os exercícios desta trilha.

### Estrutura do exercício

Quando você baixa um novo exercício de Java, recebe:

- __um ou mais arquivos de teste__ (sempre).
Eles ficam no diretório `src/test/java` e definem um conjunto de testes que nossa solução precisa passar antes que possamos declarar com segurança que ela funciona.
- __um ou mais arquivos iniciais__ (no começo).
Se forem fornecidos, eles ficam no diretório `src/main/java` e definem esqueletos das classes de que você vai precisar para resolver o problema atual.

### Passo 1: Corrigir a solução

Trabalhando localmente ou usando o editor online, você vai encontrar o seguinte código:

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

O objetivo é modificar o código fornecido para que ele produza o texto `"Hello, World!"` em vez de `"Goodbye, Mars!"`.

### Passo 2: Rodar os testes

Depois de fazer as correções e implementar sua solução, rode os testes de novo.
Você pode rodar os testes usando o editor online ou localmente na sua máquina:

- Para rodar os testes no editor online, clique no botão "Rodar testes".
- Para rodar os testes localmente, confira [Testando localmente na trilha Java][Testing locally on the java track]. Se os testes falharem, tudo bem! Veja o que a mensagem de erro está dizendo, mude seu código e teste de novo. Quando seus testes passarem, siga para o próximo passo.

### Passo 3: Enviar sua primeira iteração

Com uma solução que funciona e que revisamos, é hora de enviá-la para o exercism.org.
Você pode enviar a solução usando o editor online ou localmente, com a [CLI do Exercism][Working Locally]:

- Para enviar o exercício localmente, primeiro [instale a CLI do Exercism][Working Locally] se ainda não a tiver instalado e depois envie os arquivos da sua solução, por exemplo:

  ```sh
  exercism submit <file location>
  ```

- Substitua `<file location>` pelo caminho relativo do seu arquivo `Greeter.java`. Assim, se você está trabalhando em `C:\exercism\java\hello-world`, o comando seria

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- Se você quiser usar o editor online para enviar sua solução, basta clicar no botão "Enviar"!

Para saber mais sobre como enviar uma solução localmente:

- [Enviando localmente][Working Locally]

### Torne-se um mentor

O coração do Exercism são as conversas sobre práticas de programação.
Praticar é divertido, mas é interagindo com outras pessoas, tanto nas tentativas delas quanto nas suas, que você recebe feedback.
Esse feedback pode ajudar a mostrar o que você está fazendo bem e onde você pode melhorar.

Algumas submissões serão quase idênticas à sua, outras completamente diferentes.
Ver os dois tipos pode ser instrutivo e interessante.

Os mentores revisam as soluções enviadas na trilha que escolheram mentorar para ajudar as pessoas a aprender o máximo possível.

Para saber mais sobre mentoria, acesse a [documentação do Exercism][Mentoring].

### Contribua com o Exercism

O Exercism é inteiramente de código aberto e é um trabalho de amor de mais de 100 mantenedores e muitos outros colaboradores.

Um ponto de partida para começar e se tornar um colaborador está no [guia de contribuição do Exercism][Contributing].
