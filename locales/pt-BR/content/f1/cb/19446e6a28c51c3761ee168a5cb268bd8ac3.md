# Introdução

Ao contrário de muitas outras linguagens, existem duas entidades diferentes em JavaScript que representam a ausência de um valor (significativo).
Existem `null` e `undefined`.

## Null

O valor primitivo `null` é usado como um "valor vazio" intencional para variáveis de qualquer tipo.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Você pode verificar se uma variável é null usando o [operador de igualdade estrita][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Uma variável à qual não foi atribuído um valor é do tipo `undefined`.[^1]

Isso significa que, enquanto `null` representa um valor vazio (mas ainda um valor), `undefined` representa a ausência total de um valor. 🤯

`undefined` aparece em contextos diferentes.

- Se uma variável é declarada sem um valor (inicialização), ela é `undefined`.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- Se você tentar acessar o valor de uma chave que não existe em um objeto, você recebe `undefined`.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- Se uma função não retorna um valor, o resultado é `undefined`.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- Se um argumento não é passado para uma função, ele é `undefined`, a menos que esse argumento tenha um valor padrão.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

Você pode verificar se uma variável é undefined usando o operador de igualdade estrita `===`.

```javascript
let name;

name === undefined;
// => true
```

## Encadeamento opcional

Se você tentar recuperar um valor aninhado em um objeto, mas a chave pai não existir, o JavaScript vai lançar um erro.
Para evitar isso facilmente, o encadeamento opcional foi adicionado à especificação da linguagem em 2020.
Com o operador de encadeamento opcional `?.`, você pode garantir que o JavaScript só tente acessar a chave aninhada se o pai não for `null` nem `undefined`.
Caso contrário, `undefined` é retornado.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Coalescência nula

Existem situações em que você quer aplicar um valor padrão caso uma variável seja null ou undefined (mas só nesse caso).
Para resolver isso, o operador de coalescência nula `??` foi introduzido em 2020.
Ele retorna o operando do lado direito apenas quando o operando do lado esquerdo é `null` ou `undefined`.
Caso contrário, o operando do lado esquerdo é retornado.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
