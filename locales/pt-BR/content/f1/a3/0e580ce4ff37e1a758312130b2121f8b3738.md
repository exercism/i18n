# Dicas

## Geral

- Um array de nomes tem o tipo `ARRAY{STR}`, e um array de números, `ARRAY{INT}`. Tanto o argumento quanto, na tarefa 4, a resposta precisam indicar qual dos dois.

## 1. Quantos na fileira?

- `.size`, sem parênteses depois.

## 2. Quem lidera?

- A primeira posição é `0`.

## 3. Quem está no fim?

- A última posição é uma a menos que o tamanho, porque a contagem começa em zero.
- Calcule a partir de `.size` em vez de escrever `2`. Os testes usam fileiras de vários tamanhos diferentes.

## 4. A formação de abertura

- A resposta é um array de strings, então a rotina é declarada `: ARRAY{STR}`.
- Retorne um array literal: os três nomes entre as marcas `|`.

## 5. Conte os passos

- Um total acumulado e um laço, como no exercício anterior.
- Conte uma variável de posição a partir de `0` e para cima, e termine o laço com `until!(i >= steps.size)`.
- Começar o total em `0` é o que faz a fileira vazia responder zero sem nenhum tratamento especial.
