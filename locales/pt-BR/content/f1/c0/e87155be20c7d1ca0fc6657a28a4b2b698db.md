# Sobre

[Java](https://go.java/index.html) está entre as linguagens de programação mais populares, graças à sua versatilidade e compatibilidade.
É muito usada no desenvolvimento de software, de aplicativos móveis e de sistemas maiores.

O Java nasceu em 1995 e é mantido pela [Oracle](https://www.oracle.com/index.html).
Apesar de não ser tão jovem quanto algumas das linguagens mais recentes por aí, o Java continua muito popular.
Ele foi projetado para ser rápido, seguro, confiável, amigável para quem está começando e altamente portátil.
Essa vantagem de portabilidade existe porque o Java é executado em uma [Java Virtual Machine - JVM](https://en.wikipedia.org/wiki/Java_virtual_machine) compatível entre plataformas.
Aplicativos Android também são desenvolvidos com Java, já que o [Sistema Operacional Android](<https://en.wikipedia.org/wiki/Android_(operating_system)>) roda em um ambiente da linguagem Java.

A comunidade Java é enorme!
O GitHub, por exemplo, tem mais de 1,5 milhão de projetos Java.
Vale também mencionar que o Java tem a segunda maior comunidade no [StackOverflow](https://stackoverflow.com/questions/tagged/java)!
Isso é importante porque, quanto maior for a comunidade de uma linguagem de programação, mais apoio você provavelmente vai receber.

O Java também tem um conjunto poderoso e bem projetado de [APIs - Interfaces de Programação de Aplicações](https://docs.oracle.com/en/java/javase/11/docs/api/index.html) embutidas, que podem ser usadas em várias atividades, como conexão com banco de dados, redes, I/O, análise de XML, utilitários e muito mais.

De notebooks a data centers, de consoles de videogame a supercomputadores científicos, de celulares à Internet, [o Java está em todo lugar](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
