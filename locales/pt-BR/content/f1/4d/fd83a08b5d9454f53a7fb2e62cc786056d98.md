# Dicas

## Geral

- Declare os quatro símbolos cardeais e os quatro símbolos de direção relativa com uma linha `SYMBOLS:`: `SYMBOLS: north east south west ahead starboard behind port ;`
- Cada tupla é declarada com `TUPLE: <class> <slot1> <slot2> ;`.
- Uma linha `GENERIC:` declara a palavra; cada linha `M:` adiciona um método para uma classe. Use `M::` se você quiser variáveis locais nomeadas no corpo do método.

## 1. `>cartesian` para cardinal

- Um `case` pequeno sobre os quatro símbolos de direção já basta.
- `{ north [ 0 1 ] }`: o corpo só empilha os dois valores; o teste espera `x` abaixo de `y` na pilha.

## 2. `>cartesian` para polar

- Converta graus para radianos: `bearing pi * 180 /`.
- `sin` e `cos` estão em `math.functions`.
- Empilhe `magnitude * sin(rad)` e depois `magnitude * cos(rad)`.

## 3. `>cartesian` para relative

- Declare uma variável dinâmica: `SYMBOL: heading`.
- Leia-a no seu método com `heading get`.
- Mapeie `ahead/starboard/behind/port` para um deslocamento `0/90/180/270` com um `case` e depois some o heading. A partir daí, é a mesma conversão polar da tarefa 2. Considere extrair uma palavra auxiliar `: deg>cartesian ( magnitude bearing -- x y ) ... ;`.

## 4. `flip`

- `change-direction` em um `cardinal` e `change-bearing` em um `polar` ou `relative` constroem uma nova tupla com um slot modificado, deixando o resto intacto: `[ <transformation-quotation> ] change-bearing`.
- Para a rotação de `polar`: `[ 180 + 360 mod ] change-bearing`.

## 5. `add-bearings`

- Chame `>cartesian` em cada entrada e depois some os componentes x e y. Variáveis locais deixam isso legível:
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
