# Introdução

## Comparar

### Comparando números

No `jq`, números podem ser comparados com os seguintes operadores relacionais e de igualdade.

| Comparação             | Operador |
| ---------------------- | -------- |
| Maior que              | `a > b`  |
| Maior ou igual a       | `a >= b` |
| Menor que              | `a < b`  |
| Menor ou igual a       | `a <= b` |
| Igual a                | `a == b` |
| Diferente de           | `a != b` |

O resultado da comparação é sempre um valor Boolean, ou seja, `true` ou `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### Comparando strings

Os operadores de comparação acima também podem ser usados para comparar strings.
Nesse caso, é aplicada uma ordem de dicionário (lexicográfica).
A ordenação é _pelo valor do codepoint Unicode_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Você precisa tomar cuidado ao comparar duas variáveis que parecem conter valores numéricos, mas são do tipo string.
Por causa da ordem de dicionário, o resultado não será o mesmo de comparar valores do tipo number.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### Igualdade "estrita"

O operador `==` do `jq` é como o `===` do JavaScript, no sentido de que coisas que "parecem" iguais, mas são de tipos diferentes, não são iguais.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### Comparando arrays

Dois arrays são iguais se todos os elementos correspondentes forem iguais.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### Comparando objetos

Dois objetos são iguais se tiverem os mesmos pares chave-valor.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## Condicionais

### Expressão if

A **expressão condicional** do `jq` é `if A then B else C end`.

O `if-then-else` é um filtro como todos os builtins do `jq`: ele recebe uma entrada e produz uma saída.

Se a expressão `A` produzir um valor "truthy", o filtro `if` avalia `B`.
Caso contrário, avalia `C`.
A entrada do filtro `if` será passada para `B` ou `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
A cláusula `else` é **opcional**; as duas instruções a seguir são equivalentes.

```jq
if A then B else . end
if A then B end
```
~~~~

### Condicionais aninhados

Você pode adicionar mais condições com `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Use quantas cláusulas `elif` você precisar.

### Veracidade

Os únicos valores "falsos" no `jq` são: `false` e `null`.
Todo o resto é "verdadeiro", até o número zero, a string vazia, o array vazio e o objeto vazio.

### Operadores Boolean

Os **operadores Boolean** `and` e `or` podem ser usados para construir consultas complexas.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Para negar, use `not`. Isso é um **filtro**, não um operador.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### Operador alternativo

O **operador alternativo** permite especificar um valor "padrão" caso uma expressão seja false ou null.

```jq
A // B

# This is identical to
if A then A else B end
```

Para demonstrar

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
