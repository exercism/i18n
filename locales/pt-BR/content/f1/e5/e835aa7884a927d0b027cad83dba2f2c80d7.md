# prefira extrair a constante para o escopo de nível superior

Considere extrair a constante para o escopo de nível superior:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Só funções, classes e constantes que são `export`ed ficam visíveis e acessíveis de fora.
Essas constantes podem viver no mesmo arquivo sem ficarem expostas a outro código.
Extrair constantes também economiza memória, pois evita alocações repetidas dentro de funções quando essas mesmas constantes são reutilizadas.
