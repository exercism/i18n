# Dicas

## 1. Descreva números simples

- use `fmt.Sprintf` para formatar

## 2. Descreva uma caixa de números

- pegue o resultado do método `Number()`
- use `fmt.Sprintf` para formatar

## 3. Implemente um método que extrai o número de uma caixa de números sofisticada

- use uma asserção de tipo para verificar se isto é um `FancyNumber`
- pegue a `string` do método `Value()`
- use `strconv.Atoi` para converter a `string` em um `int` (podemos descartar o erro, já que queremos 0 se não for possível convertê-la em um `int`)

## 4. Descreva uma caixa de números sofisticada

- use `ExtractFancyNumber` para obter o valor `int`
- converta o `int` para um `float64`
- use `fmt.Sprintf` para formatar

## 5. Implemente `DescribeAnything`, que usa todos eles

- use asserções de tipo (por exemplo, `i.(someType)`) ou um switch de tipo (`switch v := i.(type)`)
- lembre-se de converter `int` para `float64`
