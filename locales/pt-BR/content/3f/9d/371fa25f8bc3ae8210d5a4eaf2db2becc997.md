# Instruções

Dada uma string de dígitos, produza todas as substrings contíguas de comprimento `n` nessa string, na ordem em que aparecem.

Por exemplo, a string "49142" tem as seguintes séries de 3 dígitos:

- "491"
- "914"
- "142"

E as seguintes séries de 4 dígitos:

- "4914"
- "9142"

E se você pedir uma série de 6 dígitos a partir de uma string de 5 dígitos, você merece o que receber.

Repare que essas séries só precisam ocupar *posições adjacentes* na entrada; os dígitos não precisam ser *numericamente consecutivos*.
