# Instruções

A dona da pizzaria do seu bairro pediu sua ajuda para calcular os tempos de preparo de diferentes pizzas. Neste exercício, você vai escrever algumas funções para fazer esses cálculos.

Você tem três tarefas.

## 1. Calcular o tempo restante no forno em minutos

Defina e implemente a função `remainingMinutesInOven()` que vai contar quantos minutos mais você precisa manter a pizza no forno.

A função deve aceitar um parâmetro **opcional** (com valor padrão) para a quantidade de minutos que passaram desde que você começou a assar a pizza. Se o parâmetro não for informado, considere que você acabou de colocar a pizza no forno e que já passaram **0 (zero)** minutos.

Para simplificar, vamos supor que todos os tipos de pizza precisam de exatamente 40 minutos no forno para ficarem prontas.

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. Calcular o tempo de preparo em minutos

Antes de assar a pizza, você precisa preparar a massa, abri-la e colocar as coberturas por cima.

Defina e implemente a função `preparationTimeInMinutes()` que vai contar quantos minutos serão necessários para preparar a pizza antes de colocá-la no forno.

A função deve aceitar um parâmetro **obrigatório** (`numberOfIngredientTypes`) para o número de tipos de cobertura que serão usados.

Considere que você precisa de 5 minutos para fazer e abrir a massa e 2 minutos para usar **cada** tipo de cobertura.

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. Calcular o tempo decorrido em minutos

Defina e implemente a função `elapsedCookingTimeInMinutes()` que vai contar quantos minutos serão necessários para preparar, assar e servir a pizza. Use as funções dos passos anteriores ao fazer os cálculos.

A função deve aceitar dois parâmetros. O primeiro é **obrigatório** e é o número de tipos de cobertura. O segundo é **opcional** e é o tempo de servir em minutos (considere que é 0 se não for informado).

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
