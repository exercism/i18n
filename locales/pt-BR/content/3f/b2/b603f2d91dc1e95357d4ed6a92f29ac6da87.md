# Anexo às instruções

## Dicas

Para completar este exercício, você precisa implementar a função `slices`,
que recebe um *texto* e retorna as subsequências de dígitos com um
tamanho especificado:

Se esta for a primeira vez que você resolve este exercício, é recomendável
usar a assinatura fornecida:

```haskell
slices :: Int -> String -> [[Int]]
```

Mais tarde, pode ser uma boa ideia voltar a este problema e brincar com outros
tipos de dados e bibliotecas:

- `ByteString`, do pacote *bytestring*.
- `Sequence`, do pacote *containers*.
- `Text`, do pacote *text*.
- `Vector`, do pacote *vector*.

A suíte de testes foi projetada de propósito para aceitar quase qualquer
assinatura de tipo que faça sentido, então vale a pena você procurar a que
considerar melhor.
