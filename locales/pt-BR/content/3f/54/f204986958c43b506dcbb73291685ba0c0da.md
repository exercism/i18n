# Introdução

## Parâmetros

Este exercício discute alguns detalhes dos parâmetros de métodos e seu uso em C#.

Os parâmetros transmitem informações de um método chamador para um método chamado.

- O comportamento dos parâmetros pode ser modificado pelo uso de modificadores como `ref` e `out`.

- Um parâmetro com o modificador `out` transmite um valor de volta do método chamado para o chamador. O parâmetro pode ser passado ao método chamado sem ser inicializado e, de qualquer forma, é tratado dentro do método chamado como se, na entrada, não tivesse sido inicializado. A compreensão do comportamento e das regras sobre modificadores de parâmetros pode ser obtida mais facilmente por meio de exemplos (veja abaixo) e mensagens do compilador.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Os parâmetros `out` precisam ser atribuídos dentro do método chamado.

- Um parâmetro com o modificador `ref` passa um valor para dentro do método chamado. Quando o método retorna, o chamador encontrará nesse parâmetro quaisquer atualizações feitas pelo método chamado.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Os parâmetros `ref` precisam ser variáveis, pois o método chamado operará diretamente sobre o parâmetro como visto pelo chamador.
- Os modificadores `out` e `ref` são exigidos tanto na assinatura do método chamado quanto no local da chamada.
