# Introdução

## Funções anônimas

As funções são tratadas como cidadãs de primeira classe no Elixir. Isso significa que:

- Funções nomeadas e anônimas podem ser atribuídas a variáveis.
- Funções nomeadas e anônimas podem ser passadas como dados, tanto como argumentos quanto como valores de retorno.
- Funções anônimas podem ser criadas dinamicamente.

Funções anônimas, ao contrário das funções nomeadas, não têm uma referência estática disponível; elas só ficam disponíveis se forem atribuídas a uma variável ou invocadas imediatamente.

Podemos usar funções anônimas para:

- Esconder dados usando escopo léxico (também conhecido como closure).
- Criar funções dinamicamente em tempo de execução.

Funções anônimas começam com a palavra reservada `fn`, os argumentos são separados do corpo da função pelo token `->`, e são finalizadas com um `end`. Assim como nas funções nomeadas, a última expressão da função é _retornada implicitamente_ para a função que a chamou.

Para invocar uma referência de função, você deve usar um `.` entre a variável de referência e a lista de argumentos:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Você pode até usar a notação de captura abreviada para deixar isso mais conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## Manipulação de bits

O Elixir oferece muitas funções para trabalhar com bits, encontradas no _módulo Bitwise_.

- `band/2`: AND bit a bit
- `bsl/2`: deslocamento à esquerda bit a bit
- `bsr/2`: deslocamento à direita bit a bit
- `bxor/2`: XOR bit a bit
- `bor/2`: OR bit a bit
- `bnot/1`: NOT bit a bit

Veja um exemplo de como usar uma função bit a bit:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Todas as funções bit a bit só funcionam com números inteiros.

Se você estiver rodando o Elixir na versão 1.9 ou inferior, vai precisar chamar `require Bitwise` no início da definição do módulo para conseguir usar o módulo _Bitwise_.
