# Instruções

Determine se um número é perfeito, abundante ou deficiente, com base no esquema de classificação de Nicômaco (60 - 120 d.C.) para números inteiros positivos.

O matemático grego [Nicômaco][nicomachus] criou um esquema de classificação para números inteiros positivos, identificando cada um como pertencendo exclusivamente a uma das categorias **perfect**, **abundant** ou **deficient**, com base na sua [soma dos divisores próprios][aliquot-sum].
A soma dos divisores próprios é definida como a soma dos fatores de um número, sem incluir o próprio número.
Por exemplo, a soma dos divisores próprios de 15 é (1 + 3 + 5) = 9

- **Perfect**: soma dos divisores próprios = número
  - 6 é um número perfeito porque (1 + 2 + 3) = 6
  - 28 é um número perfeito porque (1 + 2 + 4 + 7 + 14) = 28
- **Abundant**: soma dos divisores próprios > número
  - 12 é um número abundante porque (1 + 2 + 3 + 4 + 6) = 16
  - 24 é um número abundante porque (1 + 2 + 3 + 4 + 6 + 8 + 12) = 36
- **Deficient**: soma dos divisores próprios < número
  - 8 é um número deficiente porque (1 + 2 + 4) = 7
  - Números primos são deficientes

Implemente uma forma de determinar se um número é **perfect**.
Dependendo da sua trilha de linguagem, talvez você também precise implementar uma forma de determinar se um número é **abundant** ou **deficient**.
