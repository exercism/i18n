# Sobre

Qualquer valor pode ser um erro. `throw` (em `kernel`) sinaliza; o
efeito de pilha da palavra atual é abandonado e o controle se desenrola
até o `recover` envolvente mais próximo.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` é uma palavra de parsing que define uma classe de tupla de
erro *e* uma palavra construtora de uma vez só:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

Isso dá a cada erro personalizado uma classe única, um construtor
amigável para lançar o erro e um predicado de classe (`name?`) para
testar os erros capturados:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

Para uma limpeza no estilo `finally`, veja `cleanup` em
`continuations`. Para condições que podem ser reiniciadas, veja
`condition`.
