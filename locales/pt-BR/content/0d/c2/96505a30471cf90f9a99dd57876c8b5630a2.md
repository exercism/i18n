# Instruções

Enquanto se preparava para assar cookies para seus amigos, você descobriu que precisa converter algumas das medidas usadas na receita.
Como só conhece o sistema métrico, você precisa dar um jeito de converter as medidas comuns de culinária dos Estados Unidos para mililitros (mL) para facilitar a sua vida.

Use esta tabela de conversão na sua solução:

| Unidade a converter | volume | em mililitros (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| xícara americana          | 1      | 240                 |
| onça líquida americana  | 1      | 30                  |
| colher de chá americana     | 1      | 5                   |
| colher de sopa americana   | 1      | 15                  |

Como um programador talentoso em formação, você decide usar mililitros como unidade de transição para facilitar a conversão de qualquer unidade da lista para qualquer outra (até para ela mesma).

## 1. Obtenha o componente numérico de um par de volume

Implemente o método `KitchenCalculator.get_volume`.
Dada uma tupla de par de volume, ele deve retornar apenas o componente numérico.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Converta o par de volume para mililitros

Implemente o método `KitchenCalculator.to_milliliter`.
Dada uma tupla de par de volume, ele deve converter o volume para mililitros usando a tabela de conversão.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Converta o par de volume em mililitros para outra unidade

Implemente o método `KitchenCalculator.from_milliliter`. 
Dada uma tupla de par de volume e a unidade desejada, ele deve converter o volume para a unidade desejada usando a tabela de conversão.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Converta de qualquer unidade para qualquer unidade

Implemente o método `KitchenCalculator.convert`.
Dada uma tupla de par de volume e a unidade desejada, ele deve converter o volume dado para a unidade desejada.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
