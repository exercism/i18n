# Apêndice das instruções

## Implementação

Para completar este exercício, você precisa definir o tipo de dados `stopwatch` e implementar as funções:

- newStopwatch
- start
- stop
- lap
- reset
- advanceTime
- getState
- currentLap
- total
- previousLaps

Você vai encontrar uma definição de tipo provisória já pronta no código, mas cabe a você definir as funções e criar um tipo de dados que faça sentido.
