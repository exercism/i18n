# Introdução

## Básico

Vamos assumir que você já conhece a sintaxe e os tipos de dados do JSON.

O jq funciona passando os dados JSON de entrada por uma _única expressão_ (escrita como um _pipeline de filtros_) para obter os dados transformados desejados.

<!-- prettier-ignore -->
~~~~exercism/note
A linguagem `jq` é implementada pelo _programa_ `jq`.
Esse programa oferece várias opções de linha de comando úteis para controlar como a entrada é consumida e como a saída é apresentada.

Nos exemplos abaixo você encontrará:

- `-n` ou `--null-input`

    Normalmente, o programa `jq` recebe um arquivo para ler, ou você envia dados para a entrada dele.
    A opção `--null-input` permite gerar dados JSON sem nenhuma entrada.

- `-c` ou `--compact-output`

    O `jq` formata a saída de forma legível por padrão.
    É extremamente útil para humanos visualizar os dados quando estão bem formatados.
    No entanto, isso não é necessário para máquinas: a opção `--compact-output` remove os espaços em branco da formatação para minimizar o tamanho do JSON resultante.

- `-f filename` ou `--from-file filename`

    Lê o programa `jq` de `filename` em vez de fornecê-lo na linha de comando.
    Tanto `sed` quanto `awk` usam a opção `-f` para o mesmo propósito.
    Você verá isso sendo usado nos scripts de teste para os exercícios de prática.

O restante desta lição vai focar na _linguagem_ `jq`.
~~~~

<!-- prettier-ignore-end -->

### Filtros e Pipes

**Filtros** também são conhecidos como **Expressões**.

Um _filtro_ recebe uma entrada e produz uma saída.
Assim como você trabalha em um shell Unix, você pode unir _filtros_ com um pipe `|` para conectar a saída de um _filtro_ à entrada de outro.

### O Filtro de Identidade: `.`

Este é o _filtro_ mais simples.
Ele simplesmente passa sua entrada para sua saída.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

### Arrays

Esta será uma introdução rápida ao trabalho com **arrays**.
Vamos abordar este tópico em mais detalhes depois.

Elementos de _array_ são acessados com colchetes, e são indexados a partir de zero.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Um _filtro_ pode construir um _array_ envolvendo uma expressão em `[` e `]`

- com uma lista conhecida de elementos:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- para coletar um stream de elementos: por exemplo,
  `range` é uma função que gera um stream de números

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Usar `[]` coleta os resultados da expressão em um array

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

### Vírgula é um operador

A _vírgula_ não é apenas sintaxe que separa elementos de _array_.
**Vírgula** é um **operador** que une streams.

Por exemplo, `[1, 2, 3]` é um _filtro_ que usa o construtor de _array_ `[]` para coletar o resultado da união das três expressões `1`, `2` e `3`.

Você notou os pontos e vírgulas em `range(10; 70; 15)` acima?
Como as _vírgulas_ têm um propósito específico na linguagem `jq`, funções que recebem múltiplos argumentos usam pontos e vírgulas para separar os argumentos.

### Objetos

Uma introdução rápida a **objetos**.

Semelhante a muitas linguagens de programação, use pontos para acessar propriedades de _objeto_

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
Colchetes também podem ser usados para _objetos_, mas então aspas são necessárias para strings literais.
Este é um método para trabalhar com chaves contendo espaços.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

Você pode construir um _objeto_ com `{}` e pares `key: value`.
Aspas não são necessárias ao redor de _chaves_ que são strings "simples".

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

produz

```none
{
  "question": 54,
  "answer": 42
}
```

Para tratar a _chave_ como uma _expressão_, você deve envolvê-la em parênteses (o seguinte também produz o mesmo que acima).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

### Pipelines

Por exemplo, dado `file.json` contendo

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Vamos calcular o comprimento do _array_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

Estamos _passando_ a saída da expressão `.key2` como entrada para `length`, que sem surpresa produz o número de elementos no _array_.

### Filtros podem ignorar sua entrada

Neste exemplo, os dados JSON de entrada são ignorados e não têm impacto na saída:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

### Filtros podem gerar streams de dados

Um _filtro_ pode gerar mais de um valor.
Por exemplo, o _filtro_ `.[]` gera cada elemento de um _array_ como um valor separado:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Passar esse _filtro_ para outro executará o segundo _filtro_ **_para cada valor_**:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Isso é como iteração implícita.
Depois que você entender esta técnica, vai perceber que _filtros_ `jq` muito poderosos podem ser bem concisos.

### Parênteses

**Parênteses** são usados para agrupar subexpressões e impor a ordem das operações, assim como em outras linguagens.
No `jq`, a necessidade deles pode parecer um pouco surpreendente.

Por exemplo, digamos que queremos construir um _array_ com 2 elementos: a raiz quadrada de 9; e _e_ elevado à potência 1.
As duas expressões individuais são `9 | sqrt` e `1 | exp`.
Esperamos que a saída seja o _array_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Por que não obtivemos o que esperávamos? O `jq` interpreta isso assim:

```jq
[ ((9|sqrt), 1) | exp ]
```

O `jq` constrói um stream de dois elementos (`3` e `1`) que são cada um passados para `exp`.

Precisamos garantir que `exp` receba apenas um número como entrada.
Em outras palavras, precisamos impor que o pipe seja avaliado antes da vírgula.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

### Funções e Operadores

Sem entrar em grandes detalhes (funções serão um tópico para outro exercício), aqui estão algumas funções internas úteis:

- `length`

  Dado um array como entrada, produz o número de elementos no array.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Este operador faz coisas diferentes dependendo do tipo de seus operandos:
  soma números,
  concatena strings,
  anexa arrays,
  mescla objetos.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add` é uma função que recebe um array e retorna um item com todos os elementos somados usando as regras do `+`.
  `[1, 2, 3] | add` produz `6`.

- `map`

  Dado um array como entrada e um filtro como argumento, produz um array onde o filtro é aplicado a cada elemento

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Dada _alguma_ entrada e um filtro como argumento:
  - se o filtro aplicado ao argumento resultar em um valor _verdadeiro_, produz a entrada inalterada
  - caso contrário, não produz _nada_ (não o valor `null`, realmente nenhuma saída)

  Por exemplo, dados alguns números, selecione os divisíveis por 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Lembre-se de que `range` produz um _stream_ de números.
  `select` será invocado uma vez para cada número.
  Apenas os números que "passam" na expressão são produzidos.

  Frequentemente você precisa selecionar elementos de um array.
  Há algumas maneiras de fazer isso.

  Com a entrada `["Anne", "Bob", "Cathy", "Dave"]`, selecione os nomes com comprimento 4.
  - use `map` e `select` juntos

    ```jq
    map(select(length == 4))
    ```

  - exploda o array em elementos, aplique `select` nesse stream, e colete os resultados

    ```jq
    [ .[] | select(length == 4) ]
    ```
