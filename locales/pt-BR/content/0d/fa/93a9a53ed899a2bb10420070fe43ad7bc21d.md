# Introdução

## Arrays

Em C#, as estruturas de dados que podem conter zero ou mais elementos são conhecidas como _coleções_. Um **array** (ou _vetor_) é uma coleção de tamanho e comprimento fixos, cujos elementos precisam ser todos do mesmo tipo. Os elementos podem ser atribuídos a um array ou recuperados dele por meio de um índice. Os arrays em C# são indexados a partir de zero, o que significa que o índice do primeiro elemento é sempre zero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Também é possível definir arrays usando uma notação abreviada que permite criar o array e definir seus valores ao mesmo tempo. Como o compilador agora consegue saber quantos elementos o array terá, o comprimento pode ser omitido:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Os arrays podem ser manipulados chamando os métodos ou as propriedades de uma instância de array, ou usando os métodos estáticos definidos na classe `Array`.

## Laços `for`

Um laço `for` permite executar código repetidamente até que uma condição seja satisfeita.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Um laço `for` é composto de quatro partes:

1. O inicializador: executado uma vez antes de entrar no laço. Normalmente usado para definir as variáveis usadas dentro do laço.
2. A condição: executada antes de cada iteração do laço. O laço continua a rodar enquanto isso for avaliado como `true`.
3. O iterador: executado após cada iteração do laço. Normalmente usado para modificar (muitas vezes: incrementar/decrementar) a(s) variável(is) do laço.
4. O corpo: o código que é executado a cada iteração do laço.

## Laços `foreach`

O fato de um array também ser uma _coleção_ significa que, além de acessar valores por índice, você pode iterar sobre _todos_ os valores dele usando um laço `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
