# Introdução

No Cairo, os módulos ajudam a organizar o código agrupando funções, structs e traits relacionados em namespaces separados.
A palavra-chave `use` simplifica o acesso a esses itens ao trazê-los para o escopo, o que reduz a repetição na hora de chamar funções ou usar tipos.
Esta seção aborda boas práticas para estruturar módulos, importar itens com eficiência e reexportar itens para um código mais limpo e fácil de manter.
