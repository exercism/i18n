# Instruções

Você acaba de entrar para uma empresa que está desenvolvendo um Chatbot, no cargo de Especialista em Expressões Regulares.

O projeto está em uma fase bem básica de desenvolvimento, então sua missão é usar Expressões Regulares para melhorar a capacidade do chatbot de entender e gerar linguagem natural.

## Verificar comando válido

Além de ser inteligente, o Chatbot também é um assistente leal.

Para pedir algo ao chatbot, é preciso dizer a palavra “**Chatbot**” na primeira posição do comando.

Não importa se a palavra-chave está em MAIÚSCULAS ou minúsculas. O que importa aqui é a posição da palavra.

Implemente a função `isValidCommand()` que ajuda o Chatbot a reconhecer quando o usuário está dando um comando.

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## Remover emojis criptografados

O Chatbot tem dificuldade para entender como as pessoas usam emojis para expressar suas emoções.

Quando o chatbot recebe mensagens do usuário, cada emoji é representado como “_emoji_” seguido do seu número de _id_.

Implemente o método `removeEmoji()` para receber uma string e remover toda a criptografia de emoji da mensagem.

Linhas que não contêm texto de emoji devem ser retornadas sem modificação.

Remova apenas a string do emoji. Não tente ajustar os espaços em branco.

Para este desafio em particular, use a sintaxe de construtor para criar a expressão regular.

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## Verificar número de telefone válido

Com os recursos do chatbot disponíveis em um aplicativo de celular, espera-se que o usuário escreva um número de telefone durante a conversa.

O problema é que o chatbot só consegue ler e validar um número com um formato específico.

Se o número for válido (corresponder à sequência de caracteres especificada pela **expressão regular**), o chatbot responde com uma mensagem agradecendo e confirmando o número. Se o número for inválido, a função informa ao usuário que o número de telefone não é válido.

O formato esperado é: (+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## Obter o link do site

O Chatbot é um software bastante curioso. Mesmo conseguindo pesquisar na internet sobre um assunto específico, ele gosta de perguntar ao usuário sobre sites legais ou URLs para encontrar informações relevantes.

Exemplo de conversa:

- **Chatbot**: Olá, usuário, eu gostaria de aprender a programar em JavaScript, você conhece algum site legal onde eu poderia aprender?
- **Usuário**: Eu aprendi muito com o [exercism.org](http://exercism.org)

Implemente a função `getURL()`, capaz de retornar um array apenas com o link de cada site. Escrever uma regex para reconhecer qualquer URL seria muito complicado, mas o Chatbot só precisa ler URLs simples. Neste exercício, uma URL é qualquer sequência de palavras delimitada por `"."`.

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## Cumprimentar o usuário

Para armazenar dados de todas as pessoas que já conversaram com ele, o chatbot consegue obter o Nome Completo a partir do perfil do usuário, neste formato: **“smith, john”**.

Assim, queremos que nosso chatbot seja bem educado e cause uma boa impressão.

Escreva a função `niceToMeetYou()` que recebe uma string com o nome completo do usuário e retorna a string **“Nice to meet you, John Smith”**

Para fins de aprendizado, implemente a função usando um **método de substituição** das Expressões Regulares.

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
