# Ajuda

Veja abaixo alguns recursos para conseguir ajuda se você encontrar problemas:

- [O site principal do projeto Uiua][main] reúne [documentação][docs], exemplos, tutoriais e recursos da comunidade.
- [A comunidade do Exercism no Discord][exercism-discord]
- [A comunidade Uiua no Discord][discord] é uma comunidade muito prestativa e ativa.
- O [tutorial de introdução][tutorial] oferece uma visão geral ampla e tem pequenos exercícios para aprender Uiua.
- O [Uiua Pad][pad] para acompanhar pequenos trechos de código visualmente.
- [/r/apljk/][apl-reddit] é um subreddit para linguagens do tipo APL.

Além disso, o [StackOverflow][so] é um bom lugar para pesquisar seu problema ou sua dúvida e ver se já responderam.
Se não encontrarem, você sempre pode [perguntar][ask-so] ou [responder][answer-so] à pergunta de outra pessoa.
