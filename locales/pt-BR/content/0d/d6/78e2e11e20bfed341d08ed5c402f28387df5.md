# Instruções

A direção de cena quer o roteiro de ensaio digitado, e várias partes dele são construídas repetindo ou juntando coisas.

As quatro tarefas ficam na classe `REHEARSAL_SCRIPT`.

## 1. Repita uma deixa

Dada uma deixa e um número, retorne a deixa repetida essa quantidade de vezes, sem nada entre elas.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

Repetir algo zero vezes produz a string vazia.

## 2. As iniciais do elenco

Dada a lista do elenco, retorne a primeira letra de cada nome, todas juntas.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. Numere as linhas

Dadas as linhas de uma cena, numere-as a partir de um, cada uma em sua própria linha.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

Há uma quebra de linha *entre* as linhas e nenhuma depois da última. Uma cena sem linhas é a string vazia.

## 4. Grite uma linha

Retorne uma linha com cada letra transformada em maiúscula.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
