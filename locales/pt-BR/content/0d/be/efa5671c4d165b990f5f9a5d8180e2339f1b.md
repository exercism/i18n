# Sobre

Os [Custom Types][custom-types] em Elm representam um número fixo de casos nomeados. Cada valor corresponde a exatamente um dos casos nomeados. Em outras linguagens / contextos, eles são conhecidos como _tipos soma_, _uniões discriminadas_, _uniões etiquetadas_ e _tipos de dados algébricos_.

Cada caso de uma união discriminada pode ter dados associados a ele, e casos diferentes podem ter tipos diferentes de dados. Se nenhum dos casos tiver dados associados, a união discriminada é parecida com o que outras linguagens costumam chamar de _enumeração_ (ou _enum_).

Os Custom Types são definidos com a palavra-chave `type` e exigem muito pouca sintaxe. São uma das técnicas mais importantes da programação em Elm e servem para fazer com que os valores possíveis no código correspondam exatamente aos valores válidos da vida real, o que não deixa espaço para dados inválidos e torna [impossível representar estados impossíveis no código][impossible-states].

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

Para criar um valor de um caso específico, você pode se referir ao seu nome (`Spring`), quando ele é definido no mesmo módulo ou é importado com a sintaxe `import SeasonModule exposing (Season(..))`, ou se referir ao seu nome totalmente qualificado (`Season.Spring`) quando ele é importado com a sintaxe `import SeasonModule exposing (Season)`.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

Os Custom Types, assim como tudo em Elm, têm _igualdade estrutural_, o que significa que dois valores do mesmo caso e com os mesmos dados (opcionais) são equivalentes.

A forma preferida de trabalhar com Custom Types é com [correspondência de padrões][pattern-matching]:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
