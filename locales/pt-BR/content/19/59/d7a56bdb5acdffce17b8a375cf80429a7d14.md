# Introdução

O modificador `const` pode ser aplicado (e em geral deve ser) a qualquer campo cujo valor seja conhecido em tempo de compilação e não mude durante o tempo de vida do programa.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

O modificador `readonly` pode ser aplicado (e em geral deve ser) a qualquer campo que não possa ser declarado `const`, cujo valor não mude durante o tempo de vida do programa e que seja definido por um inicializador inline ou durante a instanciação (pelo construtor ou por um método chamado pelo construtor).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
