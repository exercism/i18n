# Dicas

## 1. `assign-bibs`

- Use `map-index`. A quotation tem `index` no topo da pilha, com `name` logo abaixo. Para produzir um par `{ position name }`, você vai querer os dois na ordem inversa antes de chamar `2array`.

## 2. `lane-labels`

- Use `map-index`.
- `sprintf` lê seus argumentos de baixo para cima: o placeholder `%` mais à esquerda pega o argumento mais de baixo, e o mais à direita pega o de cima.
- Para `"Lane %d: %s"`, você quer que `index` (um número) alimente `%d` e que `name` (uma string) alimente `%s`. Reordene a pilha dentro da quotation de acordo.

## 3. `tag-racers`

- O argumento `tag` precisa estar disponível para cada chamada por elemento. `curry` (ou `fry`) já o embute.
- Dentro da quotation, você vai ter três valores para alimentar `sprintf`: a tag, o índice e o nome. `spin` inverte os três valores do topo da pilha, que é exatamente o movimento que você quer.

## 4. `record-finishes`

- O ledger precisa estar disponível para cada chamada por elemento. `fry` (`'[ … _ … ]`) é o caminho natural: o `_` se torna o ledger.
- Monte a string de cada corredor com `sprintf` e depois use `push` para colocá-la no ledger.
- `each-index` não retorna nada; a mutação *é* o resultado.

## 5. `lap-bells`

- `times` é `inline`, então a quotation dele pode ter um efeito diferente de `( -- )`. Use uma quotation de efeito `( str -- str )` para encadear uma string acumulada ao longo das iterações.
- Comece com a string vazia `""` na pilha.
