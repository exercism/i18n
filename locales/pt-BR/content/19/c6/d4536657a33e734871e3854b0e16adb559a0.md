# Anexo de instruções

## Instruções específicas da trilha

Para algo um pouco diferente, você também pode tentar uma solução com uma função `unfold`.

Você provavelmente já conhece `foldLeft/Right`: "mapear" uma coleção inteira em outra coisa (normalmente uma não-coleção).

`unfoldLeft/Right` são as operações "inversas": "mapear" algo (normalmente uma não-coleção) em uma coleção.

Então fazer `unfold` é uma adição lógica e parte do repertório padrão de programação funcional.

Este exercício pode ser visto como um caso para usar `unfold`: "mapear" um `Int` em uma `String` (que é, é claro, implicitamente um `Seq[Char]`).

Infelizmente, a biblioteca de coleções do Scala não inclui `unfoldLeft/Right`.

Mas você pode pegar a implementação [aqui][unfold].

[unfold]: http://daily-scala.blogspot.de/2009/09/unfoldleft-and-right.html
