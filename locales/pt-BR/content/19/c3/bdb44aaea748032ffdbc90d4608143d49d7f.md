# Sobre

Em Swift, uma `String` é uma coleção ordenada de valores `Character` que representam texto legível por humanos. As strings do Swift suportam totalmente caracteres Unicode e emoji.

Você cria uma string usando um literal de string, colocando o texto entre aspas duplas (`"`).
Caracteres especiais usam sequências de escape: por exemplo, `\n` representa uma nova linha e `\"` representa uma aspa dupla escapada dentro de um literal de string.

Uma string vazia é escrita como um par de aspas duplas sem nenhum conteúdo entre elas (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
