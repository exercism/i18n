# Dicas

## Geral

- Um [valor int][ints] pode ser definido como um ou mais dígitos consecutivos.
- Literais [String][string] são uma sequência de caracteres entre aspas duplas.

## 1. Defina o tempo esperado de forno em minutos

- Você precisa definir uma [função][functions] sem argumentos.
- Você precisa retornar um [int][ints].

## 2. Calcule o tempo restante de forno em minutos

- Você precisa definir uma [função][functions] com um único argumento.
- Você precisa retornar um int de uma função.
- O argumento da função é um [int][ints].
- Você pode usar o [operador matemático de subtração][ints] para subtrair valores.

## 3. Calcule o tempo de preparo em minutos

- Você precisa definir uma [função][functions] com um único argumento.
- Você precisa retornar um int de uma função.
- O argumento da função é um [int][ints].
- Você pode usar o [operador matemático de multiplicação][ints] para multiplicar valores.

## 4. Calcule o tempo total de trabalho em minutos

- Você precisa definir uma [função][functions] com dois argumentos.
- Você precisa retornar um int de uma função.
- O argumento da função é um [int][ints].
- Você pode invocar uma das outras funções que definiu anteriormente.
- Você pode usar o [operador matemático de adição][ints] para somar valores.

## 5. Crie uma notificação de que a lasanha está pronta

- Você precisa definir uma [função][functions] sem argumentos.
- Você precisa retornar uma [string][string].

[functions]: https://gleam.run/book/tour/functions.html
[ints]: https://gleam.run/book/tour/ints-and-floats.html
[string]: https://gleam.run/book/tour/strings.html
