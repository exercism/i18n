# Apêndice de instruções

## Registradores

| Registrador | Uso       | Tipo     | Descrição                         |
| ----------- | --------- | -------- | --------------------------------- |
| `$a0`       | entrada   | endereço | primeira string terminada em nulo |
| `$a1`       | entrada   | endereço | segunda string terminada em nulo  |
| `$v0`       | saída     | inteiro  | distância de Hamming              |
| `$t0-9`     | temporário | qualquer | para armazenamento temporário     |
