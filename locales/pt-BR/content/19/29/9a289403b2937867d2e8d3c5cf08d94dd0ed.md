# Introdução

O [Zen do Python][zen-of-python] afirma que deve haver "uma forma _óbvia_ de fazer algo em Python".
Para o Python 3.6+, a [**interpolação literal de strings**][string-interpolation] ([**`f-string`s**][f-string]) costuma ser a forma óbvia e preferida de formatar strings:

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

No entanto, dada a longa história do Python e os diferentes casos de uso, talvez não seja surpresa que existam **três** outras formas comuns de fazer formatação de strings em Python:

1. [`str.format()`][str-format] é versátil, muito poderoso e compatível tanto com o [`gnu gettext`][gettext] quanto com a maioria das versões do Python.
2. Se você precisa de simplicidade, segurança e/ou muita internacionalização, dá para usar [`string.Template()`][string-template] para reduzir riscos quando entradas precisam ser tratadas e para envolver strings de tradução.
3. O operador `%` é geralmente considerado obsoleto para código novo, embora ainda funcione no Python moderno.
  Ele deve ser usado principalmente para compatibilidade com bases de código mais antigas.
  A formatação com `%` pode causar problemas ao exibir caracteres não ASCII e Unicode, além de ter mais erros e menos funcionalidade que os outros métodos.
  Se você pretende usá-lo, verifique os detalhes de suporte na sua distribuição específica do Python.

Se você quiser ir mais longe, [tudo sobre formatação][all-about-formatting] e [Boas práticas de formatação de strings em Python][formatting-best-practices] são bons pontos de partida.
