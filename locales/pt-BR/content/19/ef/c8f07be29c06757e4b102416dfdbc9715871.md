# Instruções

Neste exercício, você vai processar linhas de log.

Cada linha de log é uma string formatada assim: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Você tem três tarefas, e cada uma delas recebe uma linha de log e pede que você faça algo com ela.
Existem muitas formas de resolver essas tarefas: escolha os seus métodos favoritos entre os exemplos acima e veja o que você consegue criar.

## 1. Obter a mensagem de uma linha de log

Implemente o método `LogLineParser#message` para retornar a mensagem de uma linha de log:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

Qualquer espaço em branco no início ou no fim deve ser removido:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Obter o nível de log de uma linha de log

Implemente o método `LogLineParser#log_level` para retornar o nível de log de uma linha de log, que deve ser retornado em minúsculas:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Reformular uma linha de log

Implemente o método `LogLineParser#reformat`, que reformula a linha de log, colocando a mensagem primeiro e o nível de log depois dela entre parênteses:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
