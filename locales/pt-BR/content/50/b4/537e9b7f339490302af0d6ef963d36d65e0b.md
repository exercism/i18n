# iterar sobre um map

Usar um map é uma ideia perfeitamente natural nesse tipo de situação. No entanto, tome cuidado: como os maps são implementados como tabelas hash, a ordem das chaves não é garantida. Na verdade, quando você itera sobre as chaves de um map, elas aparecem em uma ordem diferente e aleatória a cada vez. Veja a seção `Iteration order` de [Go maps in action](https://blog.golang.org/go-maps-in-action). Se a ordem de iteração importar, um slice é uma escolha melhor.
