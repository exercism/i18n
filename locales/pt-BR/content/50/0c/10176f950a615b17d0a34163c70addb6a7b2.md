# About

Assim como outras linguagens, o C++ também oferece uma instrução `switch`.
As instruções switch são uma forma mais curta de escrever instruções `if ... else if` longas.
Para criar um switch, começamos usando a palavra-chave `switch` seguida de um número inteiro.
Em seguida, declaramos cada uma das condições com a palavra-chave `case`.
Também podemos declarar um caso `default`, que será executado quando nenhuma das condições `case` anteriores corresponder.
Cada caso deve terminar com uma instrução `break` (ou `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Passagem entre casos

Um ponto importante sobre a construção switch é que o código continua sendo executado até ser interrompido por uma instrução `break` (ou `return`).
Isso pode causar um comportamento inesperado.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

O principal caso de uso desse recurso de execução contínua é uma instrução com vários rótulos.
Vários resultados do switch podem apontar para o mesmo trecho de código a ser executado.
Assim, em um aplicativo de reservas, por exemplo, a função chamada para grupos de tamanho 2 e 3 pode ser a mesma:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
Como você viu, a instrução switch do C++ é muito limitada quando comparada a outras linguagens.
Muitas linguagens conseguem fazer switches com base em expressões booleanas ou até mesmo em expressões regulares.
Você pode pensar na versão do C++ como uma construção estendida de goto/switch.
Só a instrução switch consegue saltar para um rótulo.
Depois disso, todos os outros rótulos são ignorados e você precisa usar a instrução `break` para sair do bloco de código.
~~~~
