# Sobre

Variáveis declaradas com a palavra-chave `final` em vez de `var` só podem receber um valor uma vez.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

É importante notar que `final` pode não ter o efeito esperado com tipos que não são imutáveis, como arrays ou objetos:

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
