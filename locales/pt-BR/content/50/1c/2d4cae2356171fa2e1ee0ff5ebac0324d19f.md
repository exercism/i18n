# Apêndice das instruções

## Funções e testes

O código inicial que você recebe,
```scheme
(provide hello)

(define (hello)
  "Goodbye, Mars!")
```
define uma função chamada `hello` e a deixa disponível para rodar.
O executor de testes pega essa função e a executa, comparando o valor que ela retorna com o valor que ele espera.
Use essa definição de função inicial como base para a sua solução.
