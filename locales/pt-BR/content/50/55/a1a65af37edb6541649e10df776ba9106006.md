# Testes

Para rodar os testes, execute o seguinte comando:

```bash
make
```

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem.
Por padrão, só um teste (o primeiro) é executado quando você roda os testes.
Isso é intencional, pois permite que você foque apenas em fazer esse único teste passar.
Quando ele passar, você pode habilitar o próximo teste removendo a linha `TEST_IGNORE()`.
Quando todos os testes estiverem habilitados e sua implementação fizer todos eles passarem, você terá resolvido o exercício!

## Depuração

Para ajudar na depuração, existem várias macros definidas em um arquivo `debug.mac`.
Elas podem ser chamadas com um ou mais argumentos do tamanho adequado.
Por exemplo:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

Para usar qualquer uma dessas macros, o `debug.mac` precisa ser incluído no topo do arquivo de solução:

```x86asm
%include "debug.mac"
```
