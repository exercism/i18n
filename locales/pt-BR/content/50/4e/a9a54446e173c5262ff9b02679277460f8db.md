# Instruções

Neste exercício, você está jogando um jogo de RPG chamado "Wizard and Warriors" com seus melhores amigos. Você é o Mestre do Jogo, a pessoa encarregada de fazer o mundo do jogo ganhar vida para os jogadores. Um aspecto fundamental disso é descrever o jogo para os jogadores: qual é o status de um personagem, como é a cidade que eles estão visitando, etc.

Você tem cinco tarefas que pedem que você descreva partes do jogo para os jogadores.

## 1. Descreva um personagem

Cada personagem tem uma classe, um nível e um número de pontos de vida, e é descrito como: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. Implemente o método (estático) `GameMaster.Describe`, que recebe um `Character` como seu único parâmetro e retorna a descrição dele.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Descreva um destino

Cada destino tem um nome e um número de habitantes, e é descrito como: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. Implemente o método (estático) `GameMaster.Describe`, que recebe um `Destination` como seu único parâmetro e retorna a descrição dele.

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Descreva o meio de viagem

Os personagens podem viajar para um destino usando uma de duas opções:

- A pé, descrito como: `"You're traveling to your destination by walking."`
- A cavalo, descrito como: `"You're traveling to your destination on horseback."`

Implemente o método (estático) `GameMaster.Describe`, que recebe um `TravelMethod` como seu único parâmetro e retorna a descrição dele.

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. Descreva um personagem viajando para um destino

Quando um personagem está viajando para um destino, isso é descrito como uma combinação das descrições individuais: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. Implemente o método (estático) `GameMaster.Describe`, que recebe um `Character`, um `Destination` e um `TravelMethod` como parâmetros e retorna a descrição.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Descreva um personagem viajando para um destino sem especificar o meio de viagem

Na maioria dos casos, os personagens viajam para um destino a pé. Por conveniência, os jogadores podem omitir a menção ao meio de viagem; nesse caso, considera-se que o meio de viagem é a pé. Implemente o método (estático) `GameMaster.Describe`, que recebe um `Character` e um `Destination` como parâmetros e retorna a descrição.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
