# Links internos

Os links renderizados pelo parser de Markdown do Exercism são verificados para saber se são internos e, se forem, podem ser decorados com tooltips.

Um tooltip de um conceito pode ser parecido com isto:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## Uso

Não existe uma sintaxe especial para que os links sejam decorados desse jeito.
Em vez disso, verificamos se o href do link segue uma de duas formas:

- Uma URL. Por exemplo, https://exercism.org/tracks/ruby/concepts/basics
- Um caminho absoluto. Por exemplo, /tracks/ruby/concepts/basics

No momento, não damos suporte a URLs relativas (por exemplo, as que começam com `./` ou `../`), porque o parser de Markdown não conhece o contexto do documento que renderiza, o contexto em que está renderizando nem a estrutura de um repositório git.

## Alternativas

Em vez de usar links normais, você pode querer renderizar Widgets.
Eles geralmente são usados no fim de um documento para sugerir leituras extras ou bons exercícios para aprender alguma coisa.

Consulte [a documentação dos Widgets](/docs/building/markdown/widgets) para mais detalhes.
