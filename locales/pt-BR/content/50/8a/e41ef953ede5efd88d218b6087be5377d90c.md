# Sobre

Java é uma linguagem de tipagem estática, o que significa que tudo tem um tipo em tempo de compilação.
Atribuir um valor a um nome é o que chamamos de definir uma variável.

```java
int explicitVar = 10; // Explicitly typed
```

O valor de uma variável pode ser atribuído e atualizado com o [operador `=`][assignment].
Depois de definida, o tipo de uma variável nunca pode mudar.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Java é uma linguagem orientada a objetos e exige que todas as funções sejam definidas em uma _classe_, que são definidas com a [palavra-chave `class`][classes].
Uma função dentro de uma classe é chamada de _método_.
Cada [método][methods] pode ter zero ou mais parâmetros.
Todos os parâmetros precisam ter o tipo explícito, não existe inferência de tipo para parâmetros.
Da mesma forma, o tipo de retorno também precisa ser explícito.
Os valores são retornados das funções com a [palavra-chave `return`][return].
Para permitir que outras classes chamem um método, é preciso adicionar o modificador de acesso `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Para chamar um método, especifique o nome da classe e do método e passe argumentos para cada um dos parâmetros dele.

```java
int sum = new Calculator().add(1, 2);
```

Se um método não usa nenhum _estado_ da classe (como é o caso neste exercício), ele pode se tornar _static_ com o modificador `static`.
Da mesma forma, se uma classe só tem métodos estáticos, ela também pode se tornar _static_ com o modificador `static`.

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

O escopo em Java é definido entre os caracteres `{` e `}`.

Java tem dois tipos de [comentários][comments].
Comentários de uma linha são precedidos por `//` e comentários de várias linhas ficam entre `/*` e `*/`.

Valores inteiros são definidos como um ou mais dígitos (consecutivos) e aceitam os [operadores matemáticos padrão][operators].
