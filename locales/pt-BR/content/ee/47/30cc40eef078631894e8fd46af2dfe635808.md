# Dicas

## 1. Gere um número de registro aleatório da nave estelar

- Para gerar um número aleatório no intervalo de _min_ (inclusive) a _max_ (exclusive), você pode usar o trecho `min + Math.random()*(max - min)`.
- Existe uma [função nativa][floor] para transformar um número de ponto flutuante em um número inteiro.

## 2.Gere uma data estelar aleatória

- Para gerar um número aleatório no intervalo de _min_ (inclusive) a _max_ (exclusive), você pode usar o trecho `min + Math.random()*(max - min)`.

## 3. Gere um planeta aleatório

- Você pode usar um número inteiro gerado aleatoriamente como índice de um array.
