# Dicas

## Geral

Ao lidar com árvores, a [recursão][recursion] costuma ser sua amiga.

- A chave aqui é encontrar uma forma de dividir o problema em problemas menores com a mesma estrutura.
- Há uma dica nas instruções que aponta onde isso pode ser feito.
- Os dois percursos são necessários para o problema.
- Qual é a relação entre os dois percursos? A posição da `root` pode dar uma pista.
- Qual é o caso base? O primeiro teste aponta para uma boa resposta.

[recursion]: https://en.wikipedia.org/wiki/Recursion
