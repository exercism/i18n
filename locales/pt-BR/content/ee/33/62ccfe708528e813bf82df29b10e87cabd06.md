# Dicas

## Geral

- Para criar os métodos getter e setter, use as macros `getter`, `setter` e `property`.

## 1. Criar um estado inicial para a balança

- Para inicializar a balança, use o método `initialize`.
- O método deve receber dois argumentos, `precision` e `metric`, que devem ser um `Int32` e um `Bool`, respectivamente.
  Eles devem ser usados para definir as variáveis de instância `@precision` e `@metric`.
- A variável de instância `@weight` deve ser definida como `0.0`.

## 2. Permitir que a balança tenha uma precisão

- A macro `getter` permite definir um método que retorna o valor de uma variável de instância.

## 3. Permitir que o peso seja definido na balança

- A macro `property` permite definir um método que obtém e define o valor de uma variável de instância.

## 4. Permitir que a máquina alterne entre unidades métricas e imperiais

- A macro `setter` permite definir um método que define o valor de uma variável de instância.
