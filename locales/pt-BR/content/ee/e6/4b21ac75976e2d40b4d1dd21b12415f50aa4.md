# Dicas

## Geral

- Laços [`while`][while-loops] são usados para iteração _indefinida_ (não contada).
- Laços [`for`][for-loops] são usados para iteração _definida_ (contada).
- As palavras-chave [`break` e `continue`][control flow] ajudam a personalizar o comportamento do laço.
- [`range(<start>, <stop>, <step>)`][range] pode ser usado para gerar uma sequência para um contador de laço.
- A função embutida [`enumerate()`][enumerate] retorna pares (`<value>`, `<index>`) para você iterar sobre eles.

Também ajuda, para completar as tarefas, estar familiarizado com o seguinte:

- [`lists`][list]: indexação, listas aninhadas, [`<list>.append()`][append and pop], [`<list>.pop()`][append and pop].
- [`str`][str]: construtor `str()`, uso do `+` para concatenar strings e, opcionalmente, [`f-strings`][f-strings].

## 1. Arredondando as notas

- Laços `While` continuam rodando até que a condição de teste deles seja avaliada como `False`.
- `<list>.pop()` remove e retorna o último item de uma `list`.
- Listas vazias são avaliadas como `False` (a maioria dos objetos vazios em Python é "Falsy")

## 2. Estudantes que não passaram

- Não é preciso declarar contadores de `loop` nem de `index` ao iterar sobre um objeto com um laço `for`.
- Já um contador de resultados precisa ser criado e _incrementado_. Quando o laço terminar, você vai querer usar `return` para retornar a quantidade de estudantes que não passaram.

## 3. A "melhor"

- Não é preciso declarar contadores de `loop` nem de `index` ao iterar sobre um objeto com um laço `for`.
- Ajuda ter uma `list` vazia para adicionar as notas "melhores" aqui.
- `<list>.append()` pode ajudar a adicionar coisas à `list` de resultados.

## 4. Calculando os conceitos

- Esses são _limiares inferiores_. O _limiar inferior_ para um "D" é uma nota **41**, já que um "F" é **<= 40**.
- [`range()`][range] pode ajudar aqui a gerar uma sequência com os incrementos corretos de "F" -> "A".
- [`round()`][round] sem parâmetros deve arredondar os incrementos direitinho.
- Assim como na tarefa "melhor", `<list>.append()` pode ser útil aqui para acrescentar itens de `range()` a uma `list` de resultados.

## 5. Relacionando nomes às notas

- [`enumerate()`][enumerate] pode ajudar aqui.
- Se as duas listas tiverem o mesmo tamanho e estiverem ordenadas da mesma forma, você poderia usar o `index` de uma para obter um `value` da outra?

## 6. Uma nota "perfeita"

- Pode haver ou não um estudante com nota 100, e você não pode retornar `[]` sem verificar **todas** as notas.
- As instruções [`control flow`][control flow] `continue` e `break` podem ser úteis aqui para pular valores indesejados.
