# Introdução

O Elixir usa _Behaviours_ para fornecer interfaces genéricas comuns e, ao mesmo tempo, facilitar implementações específicas para cada módulo que as implementa. Um exemplo comum disso é o _Access Behaviour_.

O _Access Behaviour_ fornece uma interface comum para obter dados de uma estrutura de dados baseada em chaves. O _Access Behaviour_ é implementado para mapas e listas de palavras-chave, mas vamos ver como ele é usado com mapas para você sentir como funciona. O _Access Behaviour_ determina que, quando você tem um mapa, pode escrever _colchetes_ logo depois dele e então usar a chave para obter o valor associado a essa chave.

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

Se a chave não existir na estrutura de dados, é retornado `nil`. Isso pode ser fonte de comportamento indesejado, porque não lança um erro. Repare que o próprio `nil` implementa o Access Behaviour e sempre retorna `nil` para qualquer chave.
