# Laços `for`

Laços são um conceito fundamental da programação: eles permitem executar um bloco de código várias vezes.
Em Swift, existem dois tipos de laços: [laços `for-in`][for-loops] e laços `while`. 
Neste capítulo, você vai aprender sobre laços `for-in`.

Laços `for` permitem iterar sobre uma sequência de valores, pegando cada elemento por vez e vinculando-o a uma variável da sua escolha.
O Swift permite iterar sobre uma variedade de sequências, como intervalos, arrays e strings (e outros tipos que veremos mais adiante).
Quando todos os elementos da sequência tiverem sido iterados, o laço termina.

Laços `for` são declarados com a palavra-chave `for`, seguida de um nome de variável, da palavra-chave `in` e de uma sequência de valores sobre a qual iterar.
A variável declarada no laço `for-in` é imutável, ou seja, você não pode alterar o valor dela dentro do laço.
Veja um exemplo de laço `for-in` que itera sobre um array de números:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
A variável `number` é declarada no laço `for-in` e só existe dentro do escopo do laço.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Iterando sobre um intervalo

Você também pode iterar sobre um intervalo de números usando um laço `for-in`.
Isso permite executar um bloco de código um número específico de vezes. Por exemplo, o intervalo `1...5` itera sobre os números 1, 2, 3, 4 e 5, então o laço será executado 5 vezes.
Às vezes você pode querer iterar sobre índices em uma estrutura de dados como um array; nesse caso, pode usar um intervalo `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Iterando sobre uma string

Você também pode iterar sobre uma string usando um laço `for-in`.
Isso permite iterar sobre cada caractere da string, e repare que o tipo da variável do laço é `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## Variáveis não utilizadas

Se você não precisa do valor da variável no laço, pode usar um sublinhado `_` para ignorá-lo.

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## `stride`

O Swift também oferece uma função `stride`, que permite criar uma sequência sobre um intervalo com um passo específico e depois iterar sobre ela com um laço `for-in`.
A função `stride` é definida como [`stride(from:to:by:)`][stride-to] ou [`stride(from:through:by:)`][stride-through]; a primeira é exclusiva e a segunda é inclusiva.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Repare que o parâmetro `to` é exclusivo, então o laço itera até o número anterior ao parâmetro `to`; já o parâmetro `through` é inclusivo e, nesse caso, também incluiria o `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
