# Dicas

## 1. Adicionar uma linguagem ao array @Languages

- Você quer modificar o array `@Languages` para adicionar uma nova linguagem ao final.

## 2. Remover uma linguagem do array @Languages

- Você quer modificar o array `@Languages` para remover a última linguagem.

## 3. Buscar a primeira linguagem do array @Languages

- Você quer usar `return` para obter o primeiro elemento do array `@Languages`.

## 4. Buscar a última linguagem do array @Languages

- Você quer usar `return` para obter o último elemento do array `@Languages`.

## 5. Buscar uma fatia de linguagens do array @Languages

- Você quer uma fatia do array `@Languages`.
- Lembre-se de que os índices começam em 0. O elemento `1` é o índice `0`.

## 6. Verificar se uma linguagem existe no array @Languages

- Você quer retornar um valor verdadeiro, por exemplo, `1`, ou falso, por exemplo, `0`, se a linguagem informada puder ser encontrada no array `@Languages`.
