# Apêndice das instruções

## Implementação

Neste exercício você pratica a iteração sobre um array, ou seja: executar uma operação em cada elemento de um array.
O Ruby tem muitos métodos internos úteis para iterações.
Dê uma olhada [neste artigo][how-to-iterate].

A maioria dos métodos listados no artigo não é específica de Array, mas vem de [Enumerable][Enumerable].
O artigo não lista a iteração sobre _elementos consecutivos_.
O primeiro desafio é encontrar um método que faça isso.

[Enumerable]: https://docs.ruby-lang.org/en/master/Enumerable.html
[how-to-iterate]: http://jeromedalbert.com/ruby-how-to-iterate-the-right-way/
