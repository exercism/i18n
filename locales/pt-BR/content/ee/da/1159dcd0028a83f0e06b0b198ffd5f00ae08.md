# Aprendizado

Se você está começando com SQLite e quer aprender o básico da sintaxe SQL e do gerenciamento de bancos de dados, aqui estão alguns ótimos recursos pensados para quem está iniciando:

- **Introdução ao SQL no YouTube**: dê uma olhada no [What is SQL?][sql-youtube], um vídeo de 4 minutos para iniciantes feito por Danielle Thé.

- **Tutoriais de SQLite**: os [SQLite Tutorials][sqlite-tutorial] trazem uma introdução amigável ao SQLite para iniciantes, cobrindo conceitos fundamentais como criação de banco de dados, consultas e manipulação de dados.

- **SQLZoo**: pratique suas habilidades em SQL com exercícios interativos e tutoriais no [SQLZoo][sqlzoo], incluindo conteúdo específico de SQLite adequado para iniciantes.

Esses recursos oferecem uma base para aprender SQLite e a sintaxe SQL, ajudando quem está começando a entender conceitos de banco de dados e a ganhar experiência prática com bancos SQLite.

[sqlite-tutorial]: https://www.sqlitetutorial.net/
[sql-youtube]: https://www.youtube.com/watch?v=27axs9dO7AE
[sqlzoo]: https://sqlzoo.net/
