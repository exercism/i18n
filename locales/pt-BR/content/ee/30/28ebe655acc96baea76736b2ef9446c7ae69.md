## 1. Dê a razão entre sucessos e tentativas

- Crie números `Rational` usando os sucessos como numerador e as tentativas como denominador.
- Você pode usar laços, compreensões ou operações com vetores para criar o novo array.

## 2. Encontre as probabilidades reais associadas à razão entre sucessos e tentativas

- Crie números `Float` usando os sucessos como numerador e as tentativas como denominador.
- Você pode usar laços, compreensões ou operações com vetores para criar o novo array.

## 3. Verifique a média das probabilidades

- A média é obtida somando os dados e dividindo pelo número de eventos.
- Use suas funções `rationalize` e `probabilities`.
- Se houver discrepância entre usar ponto flutuante e racionais, retorne o número racional.
- A função `float()` pode ser necessária na comparação (veja a introdução).
- Você pode usar laços ou operações com vetores.
