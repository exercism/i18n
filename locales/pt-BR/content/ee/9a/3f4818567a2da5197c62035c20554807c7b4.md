# Instalação

Esta trilha depende do [Node.js][web-nodejs] para fornecer um ambiente de execução para JavaScript.
Isso significa que assumimos que toda execução de JavaScript no seu computador vai acontecer usando o [Node.js][web-nodejs].

## Requisitos da trilha

Muitas máquinas já vêm com o [Node.js][web-nodejs] pré-instalado, ou ele pode ter sido instalado antes, ou como uma dependência.
Então, antes de fazer qualquer coisa, vamos verificar se ele já está instalado:

1. Abra um _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. `node -v`

Se o [Node.js][web-nodejs] estiver instalado, uma versão será exibida.
Anote essa versão.
Se o [Node.js][web-nodejs] _não_ estiver instalado, um erro será exibido.
Normalmente, algo como `'node' is not recognised`.

## Node.js

### Se o Node.js já vem instalado

Acesse [o site do Node.js][web-nodejs].
Ele vai mostrar _duas_ versões (se detectar o seu sistema operacional. Caso contrário, selecione o seu sistema operacional primeiro).
Se a versão do seu `node -v` corresponder a uma delas, tudo certo.
Se não corresponder, recomendamos usar o Node.js LTS.
Se você tem receio de que a atualização quebre algo no seu sistema, você pode seguir como se estivesse tudo bem;
talvez não consigamos oferecer suporte se algo inesperado acontecer.

### Se o Node.js não estiver instalado

Há algumas formas de instalar o [Node.js][web-nodejs]:

- com um [Instalador ou Binário][web-nodejs-download]
- com um [gerenciador de pacotes][web-nodejs-package]

As duas opções funcionam no Windows, no macOS e no Linux. Se você não sabe o que fazer, usar um instalador é o mais fácil.

- Recomendamos usar a versão **LTS**. Ela também aparece indicada como _recomendada_ no site do [Node.js][web-nodejs] "for most users".
- Siga as instruções na página e/ou durante a instalação e instale o [Node.js][web-nodejs].

## Testando a instalação

Depois que o instalador terminar, ou o gerenciador de pacotes concluir, ou o binário tiver sido copiado e as instruções tiverem sido seguidas, é bom testar se está tudo certo.

1. Abra um _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. `node -v`

A versão deve ser a mesma que aparece no site.

> [!NOTE]
> É importante abrir uma janela de terminal _nova_.
> As janelas de terminal que já estão abertas podem não ter sido atualizadas depois que a instalação terminou.
> Isso significa que os terminais abertos não sabem que um novo programa foi instalado.

> [!IMPORTANT] > _**Ajuda**_: `'node' is not recognised`
>
> Se você usou o instalador oficial, seu `PATH` deve ter sido configurado automaticamente, mas se o seu shell tiver dificuldade para localizar os módulos instalados globalmente, ou se você compilar o Node.js a partir do código-fonte, atualize seu `PATH` para incluir os binários do `npm`.
>
> No macOS e no Linux, você pode fazer isso adicionando o seguinte a `~/.bash_profile` ou `~/.zshrc`:
>
> ```shell
> export PATH=/usr/local/share/npm/bin:$PATH
> ```
>
> No Windows, abra o menu Iniciar e pesquise por "environment variables".
> Você precisará editar a entrada `PATH` e _adicionar_ aqui o caminho para os binários do `npm`.
> Normalmente, eles ficam em `C:\Program Files\nodejs`.
> Se você navegar até lá com o `File Explorer`, vai encontrar `node.exe`, `npm.bat` e `npx.bat`.
>
> Feche todos os terminais abertos e abra um novo.

## Habilitando o corepack

Para usar um gerenciador de pacotes versionado e compatível com esta trilha, é preciso habilitar o `corepack` uma vez:

```shell
corepack enable pnpm
```

## Requisitos dos exercícios

Siga [estas instruções][cli-walkthrough] para baixar a CLI do Exercism para o seu sistema operacional.

Depois que a CLI estiver instalada e configurada, baixe o primeiro exercício, o `hello-world`:

```shell
exercism download --exercise=hello-world --track=javascript
```

Cada exercício precisa de algumas ferramentas para rodar os testes.
Você pode instalá-las rodando este comando dentro do diretório de cada exercício:

```shell
corepack pnpm install
```

Como esta trilha passou a usar o pnpm, você não precisa se preocupar com espaço em disco.
Dê uma olhada no [pnpm](https://pnpm.io/), que garante que apenas uma cópia de cada versão de pacote seja instalada no disco.

> **Mas o que é o corepack e por que isso funciona?**
>
> Você não precisa dessas informações para completar a trilha de JavaScript, mas se você está curioso para entender o que acabou de acontecer, os parágrafos a seguir são para você:
>
> Isso funciona porque o `corepack` é uma ferramenta que vem junto com o Node.js, que foi instalado conforme os passos acima.
> Ela consegue instalar o gerenciador de pacotes `pnpm`. Ela configura o sistema
> O comando `corepack` procura um arquivo `package.json`, que existe em _cada_ pasta de exercício.
> Em seguida, ele verifica o `packageManager`, que corresponde ao `pnpm`, então pode continuar. Se for necessário, ele primeiro atualiza o `pnpm`.
> Esse arquivo também lista as `"dependencies"` acima, que então são baixadas pelo `pnpm` e colocadas em um cache local.
>
> Os scripts no `package.json` usam os binários do cache local, e são esses scripts que rodam os testes, conforme listado na descrição de `exercise`.
