# Dicas

## Geral

- [Ruby para iniciantes: o nada e a verdade][rfb-nothingness-and-truth]

## 1. Verificar se um visitante tem um passe de brinquedo

- Converta o pass_id em um objeto Boolean.
- Dê uma olhada na classe [`BasicObject`][basicobject-class]: ela contém métodos que a maioria das classes herda.

## 2. Verificar se um visitante tem altura suficiente para um brinquedo

- Compare a altura mínima do brinquedo com a altura do visitante.
- Dê uma olhada no módulo [`Comparable`][comparable-module]: ele contém métodos para comparar objetos que podem ser usados quando ele é incluído.
  - A classe [Integer][integer-class] inclui o módulo [`Comparable`][comparable-module].

## 3. Verificar se um visitante tem permissão para andar no brinquedo

- Combine os métodos de instância que você criou usando um [operador booleano][pr-boolean-operator] para retornar o resultado.
