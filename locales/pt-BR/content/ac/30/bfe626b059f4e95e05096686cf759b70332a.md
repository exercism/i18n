# prefira concatenação de strings

Embora `String.format` e `String.formatted()` sejam métodos maravilhosos e poderosos, eles são mais lentos quando o problema exige apenas uma concatenação simples de `String` com o operador `+`.

Para saber mais sobre o desempenho de `String.format` e `String.formatted()`, confira [Java String Concatenation: Which Way Is Best?](https://redfin.engineering/java-string-concatenation-which-way-is-best-8f590a7d22a8).
