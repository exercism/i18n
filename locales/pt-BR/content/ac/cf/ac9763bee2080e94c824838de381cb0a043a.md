# Introdução

Entender referências é fundamental para usar Perl de forma eficaz.
Como referências são scalars, e arrays e hashes só podem conter scalars, as referências são essenciais para aninhar essas estruturas de dados.

Você pode criar referências para variáveis e sub-rotinas existentes usando o operador de barra invertida `\`:

* `\$scalar` para criar uma referência de scalar (pode ser qualquer scalar, por exemplo, `\1`, não apenas uma variável).
* `\@array` para criar uma referência de array.
* `\%hash` para criar uma referência de hash.
* `\&sub` para criar uma referência de código.

Você também pode criar o que se chama de referência anônima para arrays, hashes e sub-rotinas:

* `['Alice', 'Bob', 'Charlie']` para criar uma referência anônima de array.
* `{foo => 'a', bar => 'b', baz => 'c'}` para criar uma referência anônima de hash.
* `sub { return 1 }` para criar uma referência anônima de código.

AVISO: as chaves em Perl podem ser ambíguas em certos contextos. Se você não estiver obtendo a referência de hash que espera, adicione um sinal de mais no início para desfazer a ambiguidade, por exemplo, `+{}`. Veja [Chaves][perlrefcurlybrackets] para mais informações.

É possível acessar referências usando o operador seta `->`:

* `$ref->[0]` para acessar um elemento dentro de uma referência de array.
* `$ref->{foo}` para acessar um valor dentro de uma referência de hash.
* `$ref->($arg)` para chamar uma sub-rotina por meio de uma referência de código.

Dados dentro de estruturas de dados complexas, como arrays multidimensionais e hashes aninhados, podem ser acessados encadeando subscritos, por exemplo, `$ref->{foo}[0]{bar}` (o mesmo que `$ref->{foo}->[0]->{bar}`).

Se você quiser desreferenciar um array ou hash inteiro, pode usar o operador seta seguido de `@*` ou `%*`, respectivamente, por exemplo, `$ref->@*` ou `$ref->%*`.
Você também pode obter fatias de uma referência de array ou hash substituindo o `*` por um subscrito, por exemplo, `$ref->@[0..2]` ou `$ref->@{'Foo', 'Bar'}`.
Para fatias, a variação de sigil se aplica aqui da mesma forma que acontece com variáveis de array e hash.

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
