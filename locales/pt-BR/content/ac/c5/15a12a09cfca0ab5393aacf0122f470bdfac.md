# Apêndice das instruções

## Registradores

| Registrador | Uso           | Tipo    | Descrição                        |
| ----------- | ------------- | ------- | -------------------------------- |
| `$a0`       | entrada       | inteiro | número fornecido                 |
| `$a1`       | entrada/saída | endereço | string de resultado terminada em nulo |
| `$t0-9`     | temporário    | qualquer | para armazenamento temporário    |
