# Instruções

Bob é um consultor financeiro e ajuda as pessoas a gerenciar suas despesas.
Os clientes de Bob enviam registros de despesas para ele analisar.
Bob tem registros dos períodos anteriores, então consegue ver mudanças nos gastos.
Bob não gosta de calendários e usa a *Bob epoch* em vez de datas.
A Bob epoch é o número de dias decorridos desde que o cliente de Bob começou sua atividade.

Neste exercício, você vai construir um programa para ajudar Bob a gerenciar e analisar as despesas dos clientes dele.

Bob trabalha com `Record`s e `DaysPeriod`s.

Um `Record` representa um registro de despesa que contém o dia em que a despesa foi feita, o dinheiro gasto e a categoria da despesa.

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

Um `DaysPeriod` representa um intervalo de dias e inclui todos os dias desde o dia `From` até o dia `To`.
As duas extremidades estão incluídas no intervalo.

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. Implemente um filtro geral de registros

Bob lida com muitos registros todos os dias, mas nem todos são interessantes, dependendo da análise que Bob está fazendo.
Vamos ajudar Bob a fazer uma filtragem básica dos registros.

Implemente a função genérica `Filter` para filtrar registros de acordo com um critério dado por uma função.
Essa função de filtro recebe uma coleção de registros e uma função de predicado e retorna apenas os registros da coleção que satisfazem o predicado.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. Filtre registros dentro de um período de tempo

Bob frequentemente precisa filtrar registros que estão em um determinado período de tempo.

Implemente a função `ByDaysPeriod`, que vai ajudar Bob a criar esses filtros.
Essa função recebe um `DaysPeriod` e retorna uma função que recebe um registro e diz se o registro está no período de tempo especificado pelo `DaysPeriod` dado como argumento.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. Filtre registros por categoria

Além de filtrar registros por um período de tempo, Bob também precisa filtrar registros pela categoria deles.

Implemente a função `ByCategory`, que vai ajudar Bob a criar esses filtros.
Essa função recebe uma categoria e retorna uma função que recebe um registro e diz se a categoria desse registro é a mesma que a categoria dada como argumento.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. Calcule o valor total das despesas em um período

Bob também quer saber o valor total das despesas em um período de tempo.

Implemente a função `TotalByPeriod` para retornar a soma das despesas no período de dias.

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. Calcule as despesas totais dos registros de uma categoria em um período

Para os relatórios mais complexos que Bob faz para seus clientes, Bob precisa filtrar registros por categoria e período de tempo ao mesmo tempo.
Ou seja, Bob quer saber as despesas totais dos registros de uma categoria em um determinado período de tempo.

Implemente a função `CategoryExpenses`, que retorna o valor total das despesas de uma categoria em um determinado período de dias.
A função também deve diferenciar o caso em que a categoria dada não está presente nos registros de despesas do caso em que não há despesas da categoria no período fornecido.
Quando a categoria não é categoria de nenhum dos registros (independentemente do período de tempo), a função deve retornar um erro.

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
