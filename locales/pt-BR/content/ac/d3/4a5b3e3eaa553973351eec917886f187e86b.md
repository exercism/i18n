# Instruções

Neste exercício, você vai processar linhas de log.

Cada linha de log é uma string formatada da seguinte forma: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de log:

- `TRC` (rastreamento)
- `DBG` (depuração)
- `INF` (informação)
- `WRN` (aviso)
- `ERR` (erro)
- `FTL` (fatal)

Você tem três tarefas, e cada uma delas precisa ser concluída para fornecer a funcionalidade necessária.

## 1. Criar o enum LogLevel

Defina um enum `LogLevel` com seis casos correspondentes aos níveis de log acima, além de um caso desconhecido para níveis ausentes ou fora do padrão.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. Analisar o nível de log

Em seguida, implemente o inicializador de `LogLevel` para analisar o nível de log de uma linha de log:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. Converter a linha de log para o formato curto

O nível de log de uma linha de log é bastante verboso.
Para reduzir o espaço em disco necessário para armazenar as linhas de log, foi criado um formato curto: `"<ENCODED_LEVEL>:<MESSAGE>"`.

O nível de log codificado é um mapeamento simples de um nível de log para um número:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

Implemente o método `shortFormat(message: String) -> String`, que gera o formato reduzido da linha de log como uma `String`:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
