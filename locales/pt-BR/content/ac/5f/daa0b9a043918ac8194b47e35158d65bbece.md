# Dicas

## Geral

- `H{ } clone` é a forma certa de começar uma tabela hash nova e mutável: os literais `H{ }` podem ser compartilhados entre chamadas.
- `inc-at` de [`assocs`][assocs] soma 1 ao valor de uma chave (ou insere a chave valendo 1, se ela ainda não existir).

## 1. Monte um inventário a partir de uma lista

- Comece com `H{ } clone` e `inc-at` para cada elemento. Uma fry quotation `'[ _ inc-at ]` captura a tabela hash para você poder passá-la por `each`.
- Envolva a iteração em `[ … ] keep` para que a tabela hash seja o valor deixado na pilha.

## 2. Adicione mais itens

- A forma é a mesma da tarefa 1, só que você parte de um `clone` do inventário de entrada em vez de um inventário vazio.

## 3. Decremente as contagens

- Use `key?` primeiro; só os itens que já estão no inventário são alterados.
- `change-at` aceita uma quotation `( old -- new )`; combine-a com `[ 1 - 0 max ]` (com `max` de [`math.order`][math.order]) para que a contagem nunca fique negativa.

## 4. Remova um item por completo

- `delete-at` modifica a tabela hash e não retorna nada: faça `clone` primeiro, depois `delete-at`, e então deixe o clone na pilha.

## 5. Liste os itens disponíveis

- `>alist` converte a tabela hash em uma sequência de pares.
- `[ second 0 > ] filter` mantém apenas os itens em estoque.
- `sort-keys` (em [`sorting`][sorting]) ordena uma alist pela chave.

[math.order]: https://docs.factorcode.org/content/vocab-math.order.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
