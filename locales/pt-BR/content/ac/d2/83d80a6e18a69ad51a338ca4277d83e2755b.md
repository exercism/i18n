# Dicas

## Geral

- Há muitas formas de resolver este exercício, e planejar sua estratégia é parte fundamental do desafio.
- Como nas outras trilhas, a entrada é um `Vector{String}`.
- Como Julia tem um tipo nativo [`Matrix`][matrix] na linguagem base, pode ser mais fácil para você converter o tabuleiro para algum tipo de `Matrix` (`String`, `Char`, `Int`...).
- Fique atento aos casos extremos, que elevam a dificuldade do exercício de Fácil para Médio.
  - É possível fazer uma jogada que vence em 2 dimensões ao mesmo tempo.
  - Quais combinações de dimensões são possíveis e válidas?

## Para quem gosta de matemática

- O módulo [`LinearAlgebra`][linearalgebra] está disponível no test runner.
- Ele pode conter funções úteis, como [`diag()`][diag].
- Isso é só uma opção para quem tiver essa inclinação. Usar álgebra linear não é essencial de forma alguma.

[matrix]: https://docs.julialang.org/en/v1/base/arrays/#Base.Matrix
