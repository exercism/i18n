# Dicas

## Geral

- Leia sobre [structs][getting-started-structs] no guia Getting Started.
- Leia sobre [`defstruct`][docs-defstruct] na documentação.
- Assista [Elixir Casts - #106: Intro to Structs][elixir-casts].

## 1. Criar um carrinho de controle remoto novinho em folha

- O atributo de módulo `@enforce_keys` pode ser usado para especificar valores obrigatórios. Ele precisa ser definido antes de chamar `defstruct`.
- O campo `nickname` não deve ter um valor padrão especificado.
- A função `new/0` deve inicializar o `nickname` com o valor `"none"`.

## 2. Criar um carrinho de controle remoto novinho em folha com um apelido

- Use [`multiple-function-clauses`][multiple-fn-clauses] para reutilizar o nome da função, mas aceitar argumentos diferentes.
- Considere um [`default-argument`][default-arg] para a função.

## 3. Exibir a distância

- Para funções que aceitam apenas um tipo específico de struct, certifique-se de fazer um pattern matching para verificar o argumento.
- Use o _operador de acesso estático_ para obter os valores dos campos.

## 4. Exibir a porcentagem da bateria

- Para funções que aceitam apenas um tipo específico de struct, certifique-se de fazer um pattern matching para verificar o argumento.
- Use o _operador de acesso estático_ para obter os valores dos campos.

## 5. Dirigir altera a bateria e a distância percorrida

- Para funções que aceitam apenas um tipo específico de struct, certifique-se de fazer um pattern matching para verificar o argumento.
- Use o _operador de acesso estático_ para obter os valores dos campos.
- Revise a introdução sobre como atualizar structs.

## 6. Considerar dirigir com a bateria descarregada

- Se a bateria estiver descarregada, a função deve retornar a struct sem alterações.
