# Instruções

Seu amigo acabou de lhe enviar uma mensagem com um segredo importante.
Para não facilitar a leitura por outras pessoas, a mensagem foi criptografada usando uma série de manipulações de bits.
Você vai precisar escrever um programa para ajudar a descriptografar a mensagem.

## 1. Desloque os bits de volta

O primeiro passo para descriptografar a mensagem é desfazer o deslocamento do processo de criptografia, movendo os bits de volta para a esquerda.
O número de posições a deslocar pode variar entre mensagens.

Implemente o método `Secrets.shift_back`, que recebe um valor e o número de posições a deslocar para a esquerda.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Aplique uma máscara de bits

O próximo passo é aplicar uma máscara de bits para extrair o valor de determinados bits.
A máscara é aplicada fazendo um AND bit a bit entre o valor e a máscara.

Implemente o método `Secrets.apply_mask`, que recebe um valor e aplica uma máscara.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Defina alguns bits

Deslocar bits para a esquerda adicionou alguns novos bits 0.
Alguns desses novos bits precisam ser definidos como 1.
O OR bit a bit é útil para definir certos bits como 1 e preservar os demais.

Implemente o método `Secrets.set_bits`, que recebe dois valores e realiza um OR bit a bit.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. Reverta o XOR

Parte do processo de criptografia aplica um XOR com um valor combinado.
Para voltar ao valor original, basta fazer XOR novamente entre o valor criptografado e o valor combinado.
No entanto, devido a um mal-entendido, seu amigo inverteu os bits do valor combinado (ou seja, aplicou um NOT bit a bit ao valor combinado) antes de aplicar o XOR. 

Implemente o método `Secrets.reverse_xor`, que recebe os valores criptografado e combinado e calcula o valor original.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
