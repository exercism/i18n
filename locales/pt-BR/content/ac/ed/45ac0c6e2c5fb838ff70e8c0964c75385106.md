# Resolvendo exercícios

A principal forma pela qual o Exercism ajuda você a aprender é resolvendo exercícios.

Há duas formas de resolver exercícios no Exercism:

1. [Online, pelo editor no navegador do site](/docs/using/solving-exercises/using-the-online-editor)
2. [Na sua máquina, pela CLI](/docs/using/solving-exercises/working-locally)

## Qual opção devo escolher?

Usar o editor online ou a CLI envolve trocas diferentes:

|            | Editor online                            | CLI                                             |
| ---------- | ---------------------------------------- | ----------------------------------------------- |
| Instalação | Não                                      | Sim (por exemplo, SDK)                          |
| Edição     | Navegador                                | Seu editor preferido                            |
| Testes     | Rodar os testes no site                  | Rodar os testes localmente                      |
| Depuração  | Suporte limitado (só para algumas trilhas) | Suporte completo (dependendo do seu ambiente) |

De modo geral, o editor online é ideal para começar trilhas novas, enquanto a abordagem com a CLI é ótima se você quiser usar seu próprio ambiente de programação personalizado.
