# Introdução

A capacidade de algo ser definido em termos de si mesmo é chamada de recursão. Em Gleam, a recursão aparece mais comumente em funções recursivas, que são funções que chamam a si mesmas.

Uma função recursiva precisa ter pelo menos um _caso base_ e pelo menos um _caso recursivo_. Um _caso base_ retorna um valor sem chamar a função de novo. Um _caso recursivo_ chama a função de novo, modificando a entrada para que em algum momento ela corresponda ao caso base.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam não tem sintaxe especial para laços, então todos os laços são feitos com recursão.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam também dá suporte a tipos personalizados recursivos. Um tipo personalizado recursivo tem uma ou mais variantes que fazem referência a si mesmo nos dados que contêm.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
