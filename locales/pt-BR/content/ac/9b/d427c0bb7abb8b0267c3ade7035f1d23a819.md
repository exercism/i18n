O Elixir tem convenções de nomenclatura específicas, que incluem como nomear [funções que retornam Boolean](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) e [verificações que retornam Boolean e são válidas em cláusulas de guarda](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> Funções que retornam um Boolean são nomeadas com um ponto de interrogação no final.

> Verificações de tipo e outras verificações de Boolean permitidas em cláusulas de guarda são nomeadas com o prefixo `is_`.

As macros podem ser usadas nos dois contextos, então a notação depende do caso, mas as duas convenções de nomenclatura não podem se misturar.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
