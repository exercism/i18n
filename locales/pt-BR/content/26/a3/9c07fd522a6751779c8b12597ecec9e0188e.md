# Instruções

Como quase todo mundo que tem um trabalho, Layla, a alienígena de Lisp, às vezes precisa fazer relatórios para informar outras pessoas. Ela pede se você poderia ajudá-la a formatar os dados que tem para esses relatórios.

## 1. Formatando valores trimestrais

A primeira coisa de que Layla precisa é de uma função: `format-quarter-value`, que recebe dois parâmetros: o trimestre e o valor, e os formata para um relatório. Ela deve resultar em uma string.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. O relatório de dois trimestres

Layla agradece pela função `format-quarter-value` e diz que ela vai ser muito útil na *próxima* função de que precisamos.

O próximo relatório precisa mostrar o trimestre e o valor de 2 trimestres, impressos em duas linhas.

Além disso, a saída precisa ir para o stream fornecido como primeiro argumento.

Por exemplo: `(format-two-quarters t "last" 3.14 "this" 0)` vai produzir o seguinte na saída padrão:

```

The value last quarter: 3.14
The value this quarter: 0

```

Repare nas linhas em branco em volta.

## 3. Legível para humanos vs. alienígenas de Lisp

Layla esqueceu de contar que os alienígenas de Lisp gostam de ver os valores de um jeito que seja legível como dados de Lisp. Então ela precisa de uma nova função que possa ser lida como dados de lisp (de novo, para o stream especificado):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
