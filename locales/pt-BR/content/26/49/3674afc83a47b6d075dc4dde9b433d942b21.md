# Instalação

Esta trilha depende do [Wren Console][wren-console] o tempo todo para fornecer um runtime local para Wren. Isso significa que presumimos que toda execução de Wren no seu computador vai acontecer usando o [Wren Console][wren-console]. Por favor, não confunda isso com a <abbr title="Command Line Interface">CLI</abbr> oficial do Wren. Em um mundo perfeito, você poderia usar aquele runtime, mas no momento ele [tem](https://github.com/wren-lang/wren-cli/pull/74) [vários](https://github.com/wren-lang/wren/pull/1006) [problemas](https://github.com/wren-lang/wren-cli/issues/108) [diferentes](https://github.com/wren-lang/wren-cli/pull/105) que o tornam uma escolha pouco ideal para aprender Wren no Exercism.

O Wren Console é um fork do Wren CLI, resolve esses problemas e adiciona recursos para deixar sua experiência de aprendizado mais tranquila. Não se preocupe: o conhecimento da linguagem Wren e os conceitos que você vai aprender aqui devem valer onde quer que você queira usar Wren no futuro.

## Visão geral da instalação

- Instale o Git para ter o comando `git`
- Instale o [Wren Console][wren-console] para ter o comando `wrenc`

### Instalar o Git

Você vai precisar do binário `git` instalado e no seu PATH. É assim que o Wren Package instala pacotes (como a suíte de testes de que você vai precisar para testar seus exercícios etc.).

- **Windows**: o [download oficial do Git](https://git-scm.com/download/win) é um bom ponto de partida.
-  **Linux**: seu gerenciador de pacotes favorito deve dar conta do recado.
- **Mac**: todas as versões recentes do Mac OS já vêm com o `git` incluído.

Você pode confirmar que o Git está instalado com `git --version`:

```
$ git --version
git version 2.31.1
```

Não se preocupe se a versão exata não for a mesma, isso normalmente não é tão crítico.


### Instalar o Wren Console

#### Windows

Você muito provavelmente vai querer [baixar a versão mais recente][releases] do GitHub. Depois disso, você vai precisar descompactar o arquivo e copiar o executável `wrenc` para o seu PATH.

Também é possível [compilar a partir do código-fonte][build-from-source] usando o Visual Studio.

#### Linux

Você pode [baixar a versão mais recente][releases] do GitHub ou [compilar a partir do código-fonte][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

E garanta que ele esteja disponível no seu `PATH`.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

A instalação mais fácil é usar o tap e a fórmula do [Homebrew][homebrew] do Exercism:

```
brew tap exercism/wren
brew install wren-console
```

Como alternativa, você pode [baixar a versão mais recente][releases] do Github e instalá-la manualmente, conforme mostrado nas instruções para Linux. Compilar a partir do código-fonte também é bem simples, se você estiver familiarizado com esse tipo de coisa.

### Testando a instalação

Depois de achar que você instalou o binário corretamente, é bom testar se tudo está funcionando.

1. Abra um _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. Rode `wrenc -v`

Você deve ver as versões do `wrenc` e do Wren listadas:

```
wrenc v0.3.1 (wren v0.4.0)
```

**Observação**: é importante que você abra uma janela _nova_ de terminal. Janelas de terminal que já estavam abertas podem não ter sido atualizadas depois que a instalação terminou. Isso significa que os terminais abertos não sabem que um novo programa foi instalado.

> _**Ajuda**_: `'wrenc' is not recognised`
>
> Provavelmente você não colocou o `wrenc` no seu PATH... No MacOS e no Linux, você pode alterar seu path adicionando o seguinte ao
> `~/.bash_profile` ou ao `~/.zshrc`:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **Não faço ideia se algo disso está correto.**
> No Windows, abra o menu iniciar e procure por "environment variables". Você vai
> precisar editar a entrada `PATH` e _adicionar_ aqui o caminho para os binários do `wrenc`.
> Normalmente eles ficam em `C:\Program Files\nodejs`. Se você navegar até lá com
> o seu `File Explorer`, você deve encontrar `node.exe`, `npm.bat` e `npx.bat`.
>
> Feche todos os terminais abertos e abra um novo.

## Requisitos do exercício

Siga [estas instruções][cli-walkthrough] para baixar a CLI `exercism` para o seu sistema operacional.

Depois que a CLI estiver toda configurada, baixe o primeiro exercício, `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

Cada exercício precisa então de alguns pacotes do Wren para rodar os testes. Eles podem ser instalados
rodando este comando dentro do diretório do exercício:

```bash
$ wrenc package.wren install
```
