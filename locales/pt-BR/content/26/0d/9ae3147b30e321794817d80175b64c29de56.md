# Sobre

As características do [Red](https://www.red-lang.org) vêm em grande parte do fato de que a base da sua criação foi o [Rebol](http://www.rebol.com), e o desenvolvimento do Red começou como uma alternativa de comunidade de código aberto. Nesse meio tempo, o desenvolvimento do Rebol parou, e o Red está em constante evolução.

## Legado do Rebol

Assim como o Rebol, o Red é uma linguagem de programação **de propósito geral**. Você pode usá-la para criar qualquer aplicação que quiser. Para ser o mais familiar possível para quem desenvolve, **vários paradigmas** são implementados: *imperativo*, *funcional*, *de objetos*, *simbólico* e *reativo*. Apesar de toda a sua cadeia de ferramentas caber em um download de 1,5 MB, ele tem implementações de **Interface Gráfica do Usuário** para todos os principais sistemas operacionais (Windows, Linux, macOS) e nenhuma dependência de bibliotecas externas.

O Red se esforça para ser **o mais simples possível**. Ele é projetado a partir das concessões mais práticas e de padrões sensatos, para que você consiga concluir qualquer tarefa sem se perder em um monte de escolhas. O foco é a **legibilidade** humana, então o açúcar sintático é reduzido ao mínimo e os programas tentam se parecer com frases de linguagem natural. Como resultado, o Red e o Rebol são [altamente expressivos](https://redmonk.com/dberkholz/2013/03/25/programming-languages-ranked-by-expressiveness/).

Um valor incomum do Red é a sua **homoiconicidade**, então um programa Red pode ser manipulado como qualquer estrutura de dados do Red. Portanto, o Red e o Rebol também são formatos de dados. Um fato curioso é que o [JSON foi inspirado no Rebol](http://www.rebol.com/article/0522.html).

## Red

Em comparação com o Rebol, o Red foi bastante aprimorado. Ele pode ser **compilado** para um único executável para cada plataforma compatível, usando qualquer uma delas. Assim, você pode compilar programas para Windows no Linux ou programas para macOS no Windows. Há também um **console REPL** disponível, tanto em linha de comando quanto gráfico, que permite manipular dados instantaneamente com comandos do Red, digitando-os um a um.

O que também diferencia o Red é o seu dialeto, o Red/System, que faz do Red uma linguagem **full stack**, permitindo o desenvolvimento de código de baixo nível como em C.

## Missão

* Trazer a **diversão** de volta para a programação
* Combater a complexidade do software

## Desenvolvimento

O Red é de código aberto. Seu desenvolvimento fica no [repositório do GitHub](https://github.com/red/red). No momento, o projeto está em **estágio alpha**, então espere que as coisas mudem e quebrem.
