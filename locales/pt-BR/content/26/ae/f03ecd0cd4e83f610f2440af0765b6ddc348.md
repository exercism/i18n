# Anexo às instruções

## Palavras

Implemente:

- `grep ( pattern flags files -- lines )`

`pattern` é a string de busca, `flags` é um array de zero ou mais das strings de flag `"-n"`, `"-l"`, `"-i"`, `"-v"` e `"-x"`, e `files` é um array de um ou mais nomes de arquivo. Retorne as linhas correspondentes (com os prefixos de nome de arquivo e de número de linha solicitados) como um array de strings.

Quando a flag `-l` for fornecida, retorne um array com os nomes dos arquivos que contêm pelo menos uma correspondência.

## Ler arquivos

Leia as linhas de um arquivo com `file-lines`, passando uma codificação:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

Os três arquivos de exemplo (`iliad.txt`, `midsummer-night.txt` e `paradise-lost.txt`) acompanham o exercício no diretório de trabalho, então ler pelo nome funciona sem problema.
