# Sobre

É possível tornar um parâmetro de método opcional atribuindo a ele um valor padrão. Ao chamar um método com parâmetros opcionais, não é obrigatório passar um valor para eles. Se nenhum valor for passado para um parâmetro opcional, o valor padrão dele será usado.

Parâmetros opcionais precisam ficar no final da lista de parâmetros; eles não podem ser seguidos por parâmetros não opcionais.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

O parâmetro opcional pode ser definido como `null` usando o operador `?` antes do nome da variável:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
