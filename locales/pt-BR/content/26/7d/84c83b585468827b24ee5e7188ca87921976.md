# Instruções

Um violino é afinado de ouvido em relação a uma nota de referência. As cordas ficam muito distantes em altura, e os números envolvidos não são inteiros.

As cinco tarefas ficam na classe `TUNING_THE_STRINGS`.

## 1. Subir uma oitava

Uma nota uma oitava acima tem o dobro da frequência.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. Descer uma oitava

Uma oitava abaixo é a metade.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. Exatamente no meio

Dadas duas frequências, retorne a que fica exatamente entre elas.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. Quão desafinado?

Quando duas notas estão próximas mas não são iguais, você ouve um batimento uma vez por segundo para cada ciclo de diferença entre elas. Retorne a distância entre as frequências. A resposta nunca é negativa, seja qual for a nota mais aguda.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. Dividindo o tempo de prática

Dados um número de minutos e um número de músicos, quantos minutos cada um recebe? Os minutos e os músicos são números inteiros, mas a resposta pode não ser inteira.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
