# Instruções

Um anagrama é um rearranjo das letras para formar uma nova palavra.
Dada uma palavra e uma lista de candidatos, selecione a sublista formada pelos anagramas dessa palavra.

Dada a palavra `"listen"` e uma lista de candidatos como `"enlists" "google"
"inlets" "banana"`, o programa deve retornar uma lista contendo
`"inlets"`.
