# Sobre

Criar um processo é fácil, mas gerenciar seu estado e seu comportamento pode ficar bem complicado. O módulo [`Agent`][agent-module] é uma abstração que facilita o gerenciamento de um estado compartilhado em um processo Elixir.

Ao usar as funções do módulo `Agent`, é comum encapsular as funções relacionadas a agentes em um único módulo.

```elixir
# A simple use of agent processes to represent a counter
defmodule Counter do
  def start_link(initial_value) do
    Agent.start(fn -> initial_value end)
  end

  def value(pid) do
    Agent.get(pid, & &1)
  end

  def increment(pid) do
    Agent.update(pid, &(&1 + 1))
  end
end
```

A escolha de usar o módulo `Agent`, ou de usar vários processos, depende da relação que você quer modelar com os dados. Os _processos de agente_ são úteis quando vários processos precisam usar um mesmo estado compartilhado.

Muitas vezes, a melhor escolha é evitar um processo separado e guardar o estado em uma variável dentro do próprio processo, dentro de uma função. Também é preciso tomar cuidado para não tratá-los às cegas como uma variável global, já que outros processos podem manipulá-los, criando condições de corrida ou erros difíceis de rastrear.

Se você optar por usar um _processo de agente_, o objetivo deve ser manter um estado simples, encapsulando as chamadas ao _processo de agente_ em um módulo para organizá-las.

Se um trabalho custoso precisar ser feito em outro processo, vale considerar um _processo de tarefa_ (usando [`Task`][task-module]). Se for necessário que um processo guarde estado e execute comportamentos, vale considerar um _processo GenServer_ (usando [`GenServer`][genserver-module]).

[genserver-module]: https://hexdocs.pm/elixir/GenServer.html
