# Dicas

## 1. Estime o tempo de preparo

- Use a [função embutida `len()`][len-builtin] para determinar o número de camadas (o comprimento da slice de camadas).

## 2. Calcule as quantidades de macarrão e de molho necessárias

- Primeiro, crie duas variáveis para acompanhar a quantidade de macarrão e de molho.
- Use um laço `for` para iterar sobre as camadas.
- Se você encontrar uma camada `'noodles'` ou `'sauce'` no seu laço, aumente de acordo a quantidade armazenada na variável correspondente.

## 3. Adicione o ingrediente secreto

- Volte a [slices][concept-slices] para descobrir como recuperar um elemento de uma slice e como substituir um elemento em uma slice.
- O índice do último elemento de uma slice `a` é `len(a) - 1`.

## 4. Ajuste a receita

- Primeiro, crie uma nova slice do mesmo tamanho que a slice de entrada
- Use um [laço `for`][for-loop] para iterar sobre a slice de entrada e gerar a slice de saída
