# Convenção do Ameba

**Linha %{line_number}** :  o Ameba reportou %{message}.

Isso quer dizer que este código não segue as convenções gerais de [estilo de código][code style].
Embora esse tipo de problema geralmente não afete a forma como o código _é executado_, ele pode
prejudicar a legibilidade ou o desempenho de ferramentas automatizadas, como geradores de
documentação ou executores de testes.

[code style]: https://crystal-lang.org/reference/latest/conventions/coding_style.html
