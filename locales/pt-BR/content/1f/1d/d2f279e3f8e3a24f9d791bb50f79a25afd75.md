# Sobre

O PHP é uma linguagem do lado do servidor voltada ao desenvolvimento web. A sigla é recursiva: significa _PHP: Hypertext Preprocessor_.

Bem mais versátil que a criação de scripts CGI, o PHP costuma ser usado para adicionar interatividade a HTML puro e reforçar frameworks web.

A linguagem pode ser usada em qualquer sistema operacional. O PHP é suportado pela maioria dos servidores web comuns e muitas vezes é processado por meio de um módulo intérprete. Isso combina código web estático com inclusões dinâmicas.

O PHP não é só um framework de servidor web. Ele também é útil para criar scripts de linha de comando (análise headless) e desenvolver GUIs.

Você deveria aprender PHP porque:

- é uma linguagem de código aberto
- é bem documentada e tem bom suporte
- é compatível com a maioria dos servidores web comuns
- é fácil de aprender e começar
- é altamente escalável e extensível
