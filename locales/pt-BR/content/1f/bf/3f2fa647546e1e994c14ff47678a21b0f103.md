# Anexo às instruções

## Mensagens de exceção

Às vezes, é necessário [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você faz isso, deve sempre incluir uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda muito na depuração. Em situações em que você sabe que a origem do erro será de um tipo específico, você pode escolher lançar um dos [tipos de erro embutidos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda deve incluir uma mensagem significativa.

Este exercício em particular exige que você use a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um `ValueError` quando o valor fornecido não for encontrado no array. Os testes só vão passar se você usar `raise` na `exception` e incluir uma mensagem junto.

Para lançar um `ValueError` com uma mensagem, escreva a mensagem como argumento para o tipo `exception`:

```python
# example when value is not found in the array.
raise ValueError("value not in array")
```
