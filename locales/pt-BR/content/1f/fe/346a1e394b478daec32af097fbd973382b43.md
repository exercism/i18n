# Dicas

## Geral

- Explore as [funções disponíveis no _módulo de string_][string-module-functions] para descobrir quais operações com strings a biblioteca padrão do Gleam oferece.

## 1. Obtenha a primeira letra do nome

- Existe uma [função][string-first] para obter o primeiro caractere de uma string.
- Existem várias [funções][string-trim] para remover espaços em branco do início, do fim, ou do início e do fim de uma string.

## 2. Formate a primeira letra como uma inicial

- Existe uma [função][string-upcase] para converter todos os caracteres de uma string para a versão maiúscula.
- O operador `<>` pode ser usado para concatenar strings.

## 3. Divida o nome completo em primeiro nome e sobrenome

- Existe uma [função][string-split] que divide uma string nos caracteres de espaço em branco.
- É possível atribuir alguns dos primeiros elementos de uma lista a variáveis fazendo pattern matching na lista.

## 4. Coloque as iniciais dentro do coração

- O operador `<>` pode ser usado para concatenar strings.
