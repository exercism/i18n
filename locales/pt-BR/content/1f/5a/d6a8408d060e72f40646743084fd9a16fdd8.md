# Null

Null é um tipo de valor primitivo com um único valor: `null`.
Null costuma ser usado para representar o nada.
É considerado "falsey", mas é diferente de `false` e de outros valores "falsey".

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Trabalhando com valores null

Em PHP, valores null são uma causa comum de erro, já que muitas vezes são retornados no lugar de um estado de erro ou para representar o nada.
Evitar que esses erros aconteçam muitas vezes exige uma "checagem de null" para garantir que o valor não é null antes de operar com ele.

Fazer essa checagem repetidamente pode ser propenso a erros, então o PHP fornece dois operadores para trabalhar com valores null: o operador de acesso seguro a null `?->` e o operador de coalescência de null `??`.
