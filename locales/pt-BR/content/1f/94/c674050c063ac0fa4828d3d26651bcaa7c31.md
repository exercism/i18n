# Instruções

Chamar APIs é uma parte importante de escrever código na internet. Neste exercício, você vai precisar buscar dados de um endpoint e garantir que eles foram recuperados com sucesso.

## Objetivos

- Modifique o código fornecido.
- Invoque o cliente HTTP e tente obter uma citação. Esse resultado deve ser um tipo união composto por `string` e `error`.
- Se a citação for recebida, imprima-a no console (usando `io:println()`).
- Se ocorrer um `error`, imprima a mensagem de erro no console.
