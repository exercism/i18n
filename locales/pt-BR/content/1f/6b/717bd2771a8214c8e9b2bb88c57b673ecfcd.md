# Instruções

A biblioteca de Luton é uma grande biblioteca com uma vasta coleção de literatura, que vai de livros a arte.
A biblioteca tem uma seção onde se estuda literatura e se adicionam livros ao sistema do computador.

Algumas partes pretendem ser automatizadas e pediram sua ajuda.
Isso inclui ajudar desde a automação dos formulários do processo de inscrição até ajudar a descriptografar textos.

## 1. Obter a primeira letra do título

Os livros de uma biblioteca devem ser fáceis de encontrar, então são ordenados pela primeira letra do título.

Implemente o método `Library.first_letter`, que recebe um argumento `title`, que contém o título do livro.
O método deve retornar a primeira letra do título.

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. Obter as iniciais do autor

A biblioteca tem muitos livros escritos por autores diferentes.
Muitas vezes os autores são chamados pelas iniciais, então a biblioteca pediu um sistema que forneça as iniciais do autor a partir do primeiro nome e do sobrenome informados.
As iniciais devem ser formatadas assim: `{first_letter_of_first_name}.{first_letter_of_last_name}`

Implemente o método `Library.initials`, que recebe dois argumentos, `first_name` e `last_name`, que contêm o primeiro nome e o sobrenome do autor.
O método deve retornar as iniciais do autor.

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. Descriptografar uma letra

Parte da literatura está criptografada e a biblioteca tem muitos textos criptografados.
A biblioteca gostaria de um novo sistema de descriptografia para uma criptografia especial.

A criptografia funciona pegando a letra e substituindo pela letra que vem antes dela no alfabeto.
Por exemplo, `a` vira `z`, `b` vira `a`, `c` vira `b`, e assim por diante.

A biblioteca gostaria que fosse possível descriptografar tanto letras maiúsculas quanto minúsculas, mantendo o mesmo caso da letra original.

Implemente o método `Library.decrypt_character`, que recebe um argumento `character`, que contém a letra a descriptografar.
O método deve retornar a letra descriptografada.

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. Descriptografar um texto

A biblioteca também gostaria de descriptografar um texto inteiro, com a criptografia que usa a letra anterior no alfabeto.

O descriptografador deve descriptografar apenas letras e deixar todos os outros caracteres como estão.

Implemente o método `Library.decrypt_text`, que recebe um argumento `text`, que contém o texto a descriptografar.
O método deve retornar o texto descriptografado.

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
