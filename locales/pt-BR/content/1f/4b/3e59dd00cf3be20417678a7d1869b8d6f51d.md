# Introdução

## Átomos

O tipo `atom` do Elixir representa uma constante fixa. O valor de um átomo é simplesmente o próprio nome. Isso nos dá uma forma de interagir com dados com segurança de tipos. Os átomos podem ser definidos da seguinte forma:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

_Átomos_ são representados internamente por um número inteiro em uma tabela de consulta, que são definidos automaticamente. Não é possível alterar esse valor interno.

## Cond

Muitas vezes, queremos escrever código que pode ramificar com base em uma condição. Embora existam muitas formas de fazer isso no Elixir, uma das mais simples é usar `cond/1`.

Na sua forma mais simples, `cond` segue o primeiro caminho que avalia para `true`, com um ou mais blocos:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Se nenhum caminho avaliar para `true`, o runtime gera um erro.
