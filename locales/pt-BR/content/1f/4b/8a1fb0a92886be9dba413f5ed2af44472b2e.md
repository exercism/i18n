# Introdução

Você é um grande fã de [geocaching](https://en.wikipedia.org/wiki/Geocaching), que combina seu amor pela natureza com o amor por resolver quebra-cabeças. O site local de geocaching lista as coordenadas de GPS de todos os caches, mas _não_ oferece suporte para criar uma rota eficiente para coletá-los. Acontece que você tem um software de busca de caminhos instalado na sua máquina, só que ele usa um formato de GPS diferente do site de geocaching. Para alimentar o software com os dados, você vai precisar interpretar os graus e o hemisfério tanto da latitude quanto da longitude de cada coordenada de GPS no site.
