# Recursos

## Criando seu primeiro módulo CoffeeScript

Para criar um módulo que pode ser carregado com `Bob = require './bob'`, coloque este código em `bob.coffee`:

```coffeescript
class Bob

module.exports = Bob
```

Você pode encontrar mais informações sobre módulos na [documentação do Node](http://nodejs.org/api/modules.html#modules_module_exports).

## Visual Studio no Windows

Se você tem uma versão paga do Visual Studio, pode baixar uma solução do Visual Studio que já está configurada para funcionar com CoffeeScript e com as outras linguagens que o Visual Studio oferece.

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. Baixe o [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) no GitHub clicando no botão Download Zip na página.
2. Descompacte o template no seu diretório de exercícios, por exemplo `C:\src\exercises`
2. Instale a [Exercism CLI](http://exercism.io/cli)
3. Abra um prompt de comando no seu diretório de exercícios
4. Adicione sua chave de API ao exercism `exercism configure --key=YOUR_API_KEY`
5. Configure seu diretório de origem no exercism `exercism configure --dir=C:\src\exercises`
6. [Busque seu primeiro exercício](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. Abra a solução do Exercism no Visual Studio
8. Expanda o projeto Exercism.coffeescript
9. Clique em **Show All Files** no Solution Explorer (veja abaixo)
10. O exercício que você acabou de buscar vai aparecer esmaecido. Clique com o botão direito na pasta e **Include In Project**
11. Agora é só programar...

![Adicionar arquivos](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Para trabalhar com CoffeeScript no Visual Studio, você deve instalar a extensão [Web Essentials](http://vswebessentials.com/). Ela também vai facilitar muito o trabalho com Javascript.

Você pode rodar os testes de unidade em uma linha de comando do node.js usando o arquivo em lote do projeto.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

Se você não vir nenhuma saída ao rodar os testes, provavelmente não está em um prompt de comando do Node.js.
