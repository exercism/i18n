# Introdução

## Dicionários

Um dicionário é uma coleção de elementos em que cada elemento é composto por uma chave e um valor, de modo que, se uma chave for passada a um método do dicionário, o valor associado a ela é retornado. Ele tem o mesmo papel que mapas ou arrays associativos têm em outras linguagens.

Um dicionário pode ser criado da seguinte forma:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Ou

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Repare que os tipos de chave e valor fazem parte da definição do dicionário.

Depois de construído, entradas podem ser adicionadas ou removidas de um dicionário usando seus métodos internos `Add` e `Remove`.

A recuperação ou atualização de valores em um dicionário é feita indexando o dicionário com uma chave:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Você pode testar se uma chave existe no dicionário com:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Iterar sobre um dicionário itera sobre seus pares de chave/valor. Os dicionários também têm propriedades que permitem iterar sobre as chaves ou os valores.
