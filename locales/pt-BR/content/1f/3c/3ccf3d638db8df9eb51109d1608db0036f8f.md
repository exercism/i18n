# Introdução

No Python, `None` é frequentemente usado para representar a ausência de um valor: um espaço reservado para definir uma variável, um objeto ou um argumento `null` (vazio).

Se você já ouviu falar ou já usou um tipo `NULL` ou `nil` em outra linguagem de programação, este uso de `None` no Python vai ser familiar para você.
O `None` ajuda você a declarar variáveis ou argumentos de função para os quais ainda não tem valores.
Depois, conforme a necessidade, você pode atribuir valores específicos a eles:


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

O `None` é avaliado como `False` quando usado em uma verificação condicional, então ele é útil para validar a "presença" ou a "ausência" de um valor, _qualquer_ valor, um padrão usado com frequência quando uma função ou um processo pode devolver um `error`, um `object` ou uma mensagem.

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
