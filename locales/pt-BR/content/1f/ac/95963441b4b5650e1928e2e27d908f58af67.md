# formatação com porcentagem ou "estilo antigo"

Esta solução usa `%%-formatting` ou [formatação no estilo antigo][old-style formatting] para strings.

Embora `%%-formatting` seja uma abordagem totalmente válida, ela pode criar problemas de representação ou de legibilidade.
Usar o método [str.format()][str.format()] ou as [f-strings][f-strings] (_também conhecidas como "formatted string literals" ou "interpolated strings"_) pode oferecer opções que melhoram a legibilidade e deixam mais clara a substituição de variáveis dentro de strings.

O post de blog [String Formatting in Python][string formatting in python] é um bom ponto de partida para entender todas as opções de formatação de strings do Python, e [Newer Python String Format Techniques][newer python string format techniques] também traz boas dicas e truques para usar `str.format()` e as `f-strings`.
