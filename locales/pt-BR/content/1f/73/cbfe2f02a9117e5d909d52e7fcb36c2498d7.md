# Sobre

`while` e `until` (em [`kernel`][kernel]) são combinadores de laço guiados por quotations, para o caso em que você não sabe de antemão quantas iterações serão necessárias:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while` continua enquanto `pred` deixar um valor verdadeiro; `until` continua enquanto `pred` deixar `f`. Ambos param e retornam quando o predicado se inverte.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

Quando um único valor passando pela pilha não é estado suficiente (digamos, uma lista restante, um total acumulado e um contador, tudo ao mesmo tempo), o padrão mais limpo é usar *locals* nomeados para maior clareza. Os *locals* são apresentados com mais profundidade mais adiante no currículo; aqui basta saber que `:: word ( a b -- c )` declara as entradas como locals nomeados, e que `:> name!` adiciona um local mutável que o corpo pode atualizar com `value name!`.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
