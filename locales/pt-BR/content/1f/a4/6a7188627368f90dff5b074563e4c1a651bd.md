# Noções básicas da sintaxe de Haskell

## Constantes e funções

Os programas em Haskell são compostos de definições e expressões.

Um valor constante é definido com `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Funções são definidas com `name parameters... = expression`, e os parâmetros são separados apenas por espaço.

```haskell
add number1 number2 = number1 + number2
```

Chamar uma função também é uma expressão, e é feito especificando o nome dela e passando argumentos para cada um dos parâmetros da função, separados por espaços, assim como nas definições de funções.

```haskell
five = add 2 3
```

Os parênteses podem ser usados para especificar a ordem de avaliação de uma expressão.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentação / espaços em branco significativos

O Haskell usa espaços em branco e indentação para delimitar o código.
***O código que faz parte de alguma expressão deve estar indentado mais para dentro do que o início dessa expressão.***

- Definições de módulo, de importação e de funções de nível superior devem começar na coluna mais à esquerda.
- Se uma expressão é dividida em várias linhas, o código que faz parte dessa expressão deve estar indentado sob essa expressão com pelo menos um espaço.
- As partes da expressão que estão agrupadas devem ser indentadas com a mesma quantidade de espaços.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## Módulos

Os módulos exportam funções.
Isso significa que você pode usar as funções que o módulo disponibiliza em sua declaração de exportação.
Um módulo também pode definir funções apenas para uso interno.
Por padrão, funções que não são exportadas explicitamente não podem ser usadas de fora do módulo.

No início de um módulo, especificamos o nome do módulo.
Se temos um arquivo chamado Calculator.hs, devemos nomear nosso módulo como Calculator.
Em seguida, especificamos as funções que ele exporta e, depois disso, podemos começar a escrever as funções.
Então vamos começar com isto.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Comentários

Um comentário é um texto dentro do arquivo Haskell que não é interpretado como código.
Ele se destina principalmente a ser lido por você e por outros programadores.
Existe uma sintaxe simples para comentários de uma linha, baseada em traços duplos.
Comentários de várias linhas também são possíveis com o par de delimitadores de abertura e fechamento `{-` e `-}`.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
