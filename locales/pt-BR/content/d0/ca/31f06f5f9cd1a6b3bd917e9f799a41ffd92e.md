# Apêndice das instruções

## Registradores

| Registrador | Uso       | Tipo    | Descrição                        |
| ----------- | --------- | ------- | -------------------------------- |
| `$a0`       | entrada   | inteiro | número da casa no intervalo 1..64 |
| `$v0`       | saída     | inteiro | 32 bits menos significativos da saída |
| `$v1`       | saída     | inteiro | 32 bits mais significativos da saída |
| `$t0-9`     | temporário | qualquer | para armazenamento temporário    |
