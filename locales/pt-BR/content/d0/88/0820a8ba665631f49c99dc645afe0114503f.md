# Instruções

Neste exercício, você vai escrever código para ajudar freelancers a se comunicar com gerentes de projeto, fornecendo alguns utilitários para calcular rapidamente as taxas diária e mensal, opcionalmente com um desconto informado.

Primeiro, vamos estabelecer algumas regras entre freelancer e gerente de projeto:

A taxa diária é 8 vezes a taxa horária.
Um mês tem 22 dias faturáveis.
Há a possibilidade de aplicar um desconto caso o gerente de projeto opte pelo faturamento mensal, o que pode ser útil quando existe um determinado orçamento com o qual o gerente precisa trabalhar.

Os descontos são modelados como números fracionários que representam porcentagem, por exemplo 25.0 (25%).

## 1. Calcule a taxa diária a partir de uma taxa horária

Implemente uma função para calcular a taxa diária a partir de uma taxa horária:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

A taxa diária retornada deve ser um número de ponto flutuante.

## 2. Calcule um preço com desconto

Implemente uma função para calcular o preço após um desconto.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

O valor retornado deve ser sempre um número de ponto flutuante, sem nenhum tipo de arredondamento.

## 3. Calcule a taxa mensal a partir de uma taxa horária e um desconto

Implemente uma função para calcular a taxa mensal e aplicar um desconto:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

A taxa mensal retornada deve ser arredondada para cima (teto) até o inteiro mais próximo.

## 4. Calcule o número de dias de trabalho a partir de um orçamento, uma taxa horária e um desconto

Implemente uma função que recebe um orçamento, uma taxa horária e um desconto, e calcula quantos dias de trabalho isso cobre.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

O número de dias retornado deve ser arredondado para baixo (piso) até uma casa decimal.
