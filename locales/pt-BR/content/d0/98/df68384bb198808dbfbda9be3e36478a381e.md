## 1. Convertendo valores com sinal em valores sem sinal

- Verifique se o valor com sinal é negativo. Se for, retorne `Option::None`
- Verifique se o valor com sinal ultrapassa `u16::MAX` (65535). Se ultrapassar, retorne `Option::None`
- Para valores válidos, converta usando `.try_into()` ou uma conversão direta
- Lembre que `u16` pode armazenar valores de 0 a 65535

## 2. Convertendo valores sem sinal em valores com sinal

- Como `u16::MAX` (65535) cabe tranquilamente em `i32`, essa conversão sempre funciona
- Use `.into()` para converter de `u16` para `i32` com segurança

## 3. Conversão de tipo personalizado

- Implemente o trait `Into` com a sintaxe: `impl IntoImplName of Into<SourceType, TargetType>`
- No método `into`, crie uma nova instância do tipo de destino
- Mapeie o campo `potency` de `Essence` para o campo `strength` de `Elixir`
- Depois de implementar o trait, você pode usar `.into()` em instâncias de `Essence`

## 4. Usando o trait Into

- Depois de implementar o trait `Into`, chame `.into()` no parâmetro `Essence`
- O compilador vai usar automaticamente a sua implementação do trait
- A anotação do tipo de retorno ajuda o Cairo a saber qual conversão usar
