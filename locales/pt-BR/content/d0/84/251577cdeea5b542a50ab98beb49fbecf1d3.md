# Sobre

## Múltiplos valores de retorno

Em Swift, as funções podem [retornar múltiplos valores][multiple-return-values] retornando uma tupla:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    return (reverse: String(str.reversed()), length: str.count)
}

let result = reverseAndLength("Hello")
print(result.reverse) // Prints "olleH"
print(result.length)  // Prints 5
```

## Omitir a palavra-chave `return`

Quando o corpo de uma função é uma única expressão, você pode [omitir a palavra-chave `return`][implicit-returns]:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    (reverse: String(str.reversed()), length: str.count)
}
```

Essa sintaxe de retorno implícito vale para todas as funções que retornam um valor, não só para as que retornam tuplas.
