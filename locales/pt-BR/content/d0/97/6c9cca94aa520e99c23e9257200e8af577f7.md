# Testes

Para rodar os testes, execute o comando `go test` de dentro do diretório do exercício.

Se a suíte de testes tiver benchmarks, você pode rodá-los com as flags `--bench` e `--benchmem`:

    go test -v --bench . --benchmem

Lembre-se de que cada revisor vai rodar os benchmarks em uma máquina diferente, com especificações diferentes, então os resultados desses testes de benchmark podem variar.
