# Introdução

`Nil` em Gleam é um tipo com um único valor, também chamado `Nil`. É semelhante a `void` em outras linguagens, no sentido de que é usado quando uma função não tem um valor mais adequado para retornar.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Os valores em Gleam não são "nulos" ou "anuláveis" como em algumas outras linguagens. Um valor só pode ser `Nil` se seu tipo for `Nil`, e um valor de qualquer outro tipo nunca pode ser `Nil`.
