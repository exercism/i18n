# Instalação

## Mac

Instale usando o homebrew com `brew install swi-prolog`.
Como alternativa, baixe o código-fonte para a sua máquina no [site do SWI Prolog](http://www.swi-prolog.org/download/devel).

## Windows

Baixe o código-fonte para a sua máquina no [site do SWI Prolog](http://www.swi-prolog.org/download/devel).

## Linux

Siga as instruções para a sua distro [aqui](http://www.swi-prolog.org/build/unix.html).
