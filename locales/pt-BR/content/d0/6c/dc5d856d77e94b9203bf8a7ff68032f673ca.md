## Como resolver com bash

O `bash` não tem nenhuma forma nativa de **interpretar** strings de data e hora.
Este exercício exige que você chame um utilitário externo.

* A opção `-d` do comando `date` do GNU consegue interpretar [uma grande variedade de formatos][gnu-date].
* Para quem usa Mac, veja o [comando `date` do BSD][bsd-date] e a opção `-f` dele.
* O Perl está amplamente disponível, e o [módulo `Time::Piece`][time-piece] dele pode ser usado para interpretar timestamps.

O bash consegue **formatar** datas sem nenhuma ferramenta externa.
Dado um valor de tempo inteiro (segundos desde a epoch), [o formatador `%()T` do `printf`][bash-printf] consegue aplicar uma formatação no estilo "strftime".

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```
