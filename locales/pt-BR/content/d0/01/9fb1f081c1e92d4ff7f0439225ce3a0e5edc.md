# Dicas

## Geral

- Você precisa usar diferentes formas de [controle de fluxo][control-flow] para resolver este exercício.

## 1. Verifique a criticidade

- Você precisa usar condicionais [`if`][if] ou [`unless`][unless] para resolver este exercício.
- Você precisa usar [operadores de comparação][equality-and-comparison] para resolver este exercício.
- Para combinar várias condições, você pode usar [`&&`][and] e [`||`][or].

## 2. Determine a faixa de potência de saída

- Você pode criar vários blocos usando `if` e `elsif`.

## 3. Mecanismo à prova de falhas

- Você pode usar `if` e `elsif` para criar vários blocos.
