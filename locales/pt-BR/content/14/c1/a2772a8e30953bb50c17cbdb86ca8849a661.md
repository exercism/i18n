# Instruções

Izzy é uma observadora de aves ávida que acompanha quantas aves visitaram o jardim dela em cada dia.

Ela pediu que você a ajudasse a levar a observação de aves dela a um novo nível e implementasse algumas ferramentas que a ajudem a acompanhar e processar os dados.

Você escolheu armazenar os dados como uma lista de números inteiros. O primeiro número da lista é o número de aves que visitaram seu jardim hoje, o segundo ontem, e assim por diante.

## 1. Verifique quantas aves visitaram hoje

Implemente a função `today`. Ela deve receber uma lista de contagens diárias de aves e retornar a contagem de hoje. Se a lista estiver vazia, ela deve retornar `0`.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Incremente a contagem de hoje

Implemente a função `increment_day_count`. Ela deve receber uma lista de contagens diárias de aves e incrementar a contagem de hoje em 1. Se a lista estiver vazia, retorne `[1]`.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Verifique se houve um dia sem aves visitantes

Implemente a função `has_day_without_birds`. Ela deve receber uma lista de contagens diárias de aves. Ela deve retornar `True` se houve pelo menos um dia em que nenhuma ave visitou o jardim, e `False` caso contrário. Se a lista estiver vazia, isso conta como nenhuma ave registrada _ainda_; retorne `False`.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Calcule o número total de aves visitantes

Implemente a função `total`. Ela deve receber uma lista de contagens diárias de aves e retornar o número total que visitou seu jardim desde que você começou a coletar os dados.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Calcule o número de dias movimentados

Alguns dias são mais movimentados que outros. Um dia movimentado é aquele em que cinco ou mais aves visitaram seu jardim.

Implemente a função `busy_days`. Ela deve receber uma lista de contagens diárias de aves e retornar o número de dias movimentados.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
