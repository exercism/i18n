# use o operador de coalescência nula em vez de is null or white space

Em vez de usar `string.IsNullOrWhiteSpace` para determinar se o nome padrão deve ser usado, experimente o [operador de coalescência nula](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/null-coalescing-operator) para simplificar o código e leve em conta a diferença de comportamento.
