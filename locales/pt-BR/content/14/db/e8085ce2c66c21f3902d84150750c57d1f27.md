# Apêndice das instruções

## Implementação

Você deve definir um tipo personalizado 'DNA' com uma função 'Counts' que retorna dois valores:

- uma contagem de frequência para a fita de DNA fornecida
- um erro (se houver nucleotídeos inválidos)

Qual é um bom tipo para uma fita de DNA?

Quais são os melhores tipos em Go para representar os valores de saída?

Dê uma olhada nos casos de teste para ter uma ideia de quais podem ser as entradas possíveis.
