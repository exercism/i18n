# Instruções

Uma roda de cifra é formada por dois discos, um dentro do outro, que giram o alfabeto: ajuste-a em 3 e cada letra vira a que está três posições adiante, com o `z` dando a volta e voltando para o `a`. Detetives as usam há séculos. Você vai construir uma.

As cinco tarefas ficam na classe `CIPHER_WHEEL`.

## 1. É uma letra?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. Grite

Retorne a maiúscula de um caractere. Qualquer coisa que não seja uma letra volta inalterada.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. Que número é esse?

Retorne o número que representa um caractere.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. O primeiro caractere

Retorne o primeiro caractere de uma string.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. Gire a roda

Dada uma letra minúscula e um número de posições, retorne a letra que está esse tanto de posições adiante no alfabeto. Depois do `z`, ela dá a volta e volta para o `a`.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

Girar para trás também funciona, com um número negativo de posições.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

Você pode assumir que o caractere recebido é uma letra minúscula.
