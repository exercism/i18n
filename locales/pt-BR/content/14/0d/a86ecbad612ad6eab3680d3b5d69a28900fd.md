# Dicas

## Geral

- [Python Docs: Enum](https://docs.python.org/3/library/enum.html)

## 1. Analisar o nível de log

- Use [`str.split`](https://www.w3schools.com/python/ref_string_split.asp) para extrair o nível de log da mensagem.
- Com a parte extraída da string, acesse e retorne o membro do enum usando `LogLevel(string)`.

## 2. Suportar um nível de log desconhecido

- Crie um novo membro de nível de log Unknown no enum existente.
- Verifique se a parte extraída da string é um valor do enum `LogLevel`.
- Se o valor não corresponder a nenhum dos valores dos membros do enum, retorne o membro Unknown de `LogLevel`.

## 3. Converter a linha de log para o formato curto

- Encontre o código (um inteiro) do nível de log com base no nível de log. Existem várias soluções possíveis: condicionais, outro enum ou qualquer outra solução.
- Use formatação de string para retornar um código de nível e uma mensagem formatados corretamente.

## 4. Criar um alias

- Crie o novo membro alias chamado Warn no enum existente.
- Retorne o membro recém-criado.

## 5. Todos os nomes e valores dos membros

- Itere sobre todos os membros do enum e retorne uma lista de tuplas.
- A tupla pode ser construída com `(item1, item2)`.
- É possível acessar o nome e o valor do enum com `member.name` e `member.value`.
- Retorne a lista contendo todas as tuplas.
