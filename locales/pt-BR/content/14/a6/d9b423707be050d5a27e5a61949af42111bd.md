# Dicas

## 1. Substitua todos os espaços encontrados por underscores

- A [documentação de referência][char-docs] para `Char`s está aqui.
- Literais de `Char` ficam entre 'aspas simples', e literais de `String` entre "aspas duplas".

## 2. Remova todos os espaços em branco

- Veja [este método][isspace] para detectar caracteres de espaço em branco e [este método][isdigit] para dígitos.

## 3. Converta camel-case em kebab-case

- Veja [este método][isuppercase] para verificar se um caractere é maiúsculo.
- Veja [este método][lowercase] para converter um caractere em minúsculo.

## 5. Omita letras gregas minúsculas

- `Char`s têm suporte aos operadores de igualdade e comparação padrão.

## 6. Combine estas operações para operar sobre uma string

- É possível iterar sobre uma string, do mesmo jeito que sobre um array.
- Para fazer todas as transformações, considere usar uma compreensão.
- É possível [juntar][join] várias strings em uma só.
