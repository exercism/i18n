# Dicas

## 1. Extrair coordenadas

- Estamos tentando tirar um elemento de uma tupla.
- A indexação é uma possibilidade.
- A atribuição múltipla é uma abordagem alternativa.

## 2. Formatar coordenadas

- Lembre-se do construtor [`Tuple()`][Tuple].

## 3. Comparar coordenadas

- Você já tem uma função para converter a coordenada da Azara para o formato do Rui.
- Testar a igualdade é uma possibilidade.
- Como alternativa, teste se a coordenada está no registro do Rui (∈).

## 4. Combinar registros correspondentes

- Os registros são iguais? Você já sabe como testar isso.
- Se forem iguais, os elementos desejados precisam ser combinados em uma ordem diferente no valor de retorno.
- Nem todo elemento da tupla de entrada aparece na saída.
- O desempacotamento é seu amigo. Dar nomes significativos aos elementos é mais legível e mais fácil de depurar do que usar indexação.

[Tuple]: https://docs.julialang.org/en/v1/base/base/#Core.Tuple
