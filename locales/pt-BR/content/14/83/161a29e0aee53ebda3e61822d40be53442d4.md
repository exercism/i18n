# Introdução

Uma declaração `MACRO:` é como `:`, mas o corpo roda em *tempo de
compilação* e precisa retornar uma quotation. O compilador substitui
a chamada da macro por essa quotation retornada. Como o corpo é
código Factor comum, construir a quotation resultante é só
manipular sequências de palavras.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

As entradas de uma macro são *literais no local da chamada*. Passe
um valor não literal e o compilador vai se recusar a especializar,
porque o corpo da macro precisa do valor em tempo de compilação, e
não em tempo de execução.

Um parente próximo é o bloco de avaliação em tempo de análise `<< … >>`,
que roda código Factor arbitrário em tempo de compilação sem o
contrato de retorno de quotation. Os dois fazem parte do mecanismo
[`macros`][macros] do Factor.

[macros]: https://docs.factorcode.org/content/vocab-macros.html
