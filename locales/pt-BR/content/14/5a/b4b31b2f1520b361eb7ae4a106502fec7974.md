# Introdução

Em Haxe, uma `class` é a principal estrutura de dados, que encapsula dados (campos) e comportamento (métodos). Os campos e os métodos também são chamados de membros de uma classe.

O acesso aos membros pode ser restrito com modificadores de acesso, que são:

- `public`: o membro pode ser acessado de qualquer lugar.
- `private`: o membro só pode ser acessado pela própria classe.

Você pode pensar nas classes como modelos para criar instâncias. Para criar uma instância, basta usar a palavra-chave `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Para definir um campo, use um modificador de acesso seguido do nome da variável e do tipo:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Você também pode definir um valor inicial ao declarar um campo. Se um campo não especificar um valor inicial, ele assume o valor de `null`. Você pode acessar um campo usando a notação de ponto:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
