# Auxílio combustível

## Enunciado do problema

Todos os funcionários da ABC Corp recebem um auxílio combustível ilimitado. Os funcionários precisam enviar um registro toda vez que abastecem o veículo. Esses registros são acrescentados ao mesmo arquivo CSV e processados no fim do mês.

Como membro da equipe de operações digitais, sua tarefa é ler esse arquivo CSV e gravar os resultados em outro arquivo CSV. O arquivo de saída deve conter uma entrada para cada funcionário, com os seguintes detalhes:

- Número do funcionário
- Número de abastecimentos
- Custo total do combustível
- Total de galões
- Total de milhas acumuladas

Você recebe dois argumentos do tipo `string`.

1. Caminho do arquivo CSV de entrada
1. Caminho do arquivo CSV de saída

O arquivo CSV de entrada tem `n` linhas, e cada linha tem o seguinte formato.

| Nome da coluna      | Tipo Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

O arquivo de saída deve conter uma entrada para cada funcionário, ordenadas em ordem crescente por `employee_id`. Cada linha tem o seguinte formato:

| Nome da coluna      | Tipo Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Restrições

- Número de linhas `n` no arquivo CSV de entrada:  2 <= n <= 1000
- Número de funcionários na empresa: 97
- O preço do combustível é por galão
- Não falta nenhum registro de abastecimento

## Exemplo 1

- Entrada: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- Saída: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
