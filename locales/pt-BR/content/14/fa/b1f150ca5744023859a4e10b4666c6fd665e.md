# Dicas

## Geral

- O [tutorial de dicionários do Python][dict-tutorial] pode ser um ótimo ponto de partida.
- A documentação do Python sobre [tipos de mapeamento, os dicts][dict docs] também ajuda bastante.

## 1. Crie um inventário a partir de uma lista

- Você precisa de um [laço for][for-loop] para iterar sobre a lista de itens e, em seguida, inserir cada item no dicionário caso ele ainda não exista e incrementar a contagem do item usando o acesso ao dicionário.
- Você pode usar [`dict.setdefault`][dict setdefault] para garantir que o valor esteja definido antes de incrementar a contagem do item.
- Essa função deve [retornar][return-keyword] um dict.

## 2. Adicione itens de uma lista a um dicionário existente

- Você precisa de um [laço for][for-loop] para iterar sobre a lista de itens e, em seguida, inserir cada item caso ele ainda não esteja no dicionário e [incrementar][increment] a contagem do item usando o acesso ao dicionário.
- Você pode usar [`dict.setdefault`][dict setdefault] para garantir que o valor esteja definido antes de incrementar a contagem do item.
- A função `create_inventory` pode usar a função `add_items` passando um dicionário vazio como parâmetro.
- Essa função deve [retornar][return-keyword] um dict.

## 3. Decremente itens do inventário

- Você precisa de um [laço for][for-loop] para iterar sobre a lista de itens e, se o número de itens não for `0`, [decrementar][decrement] o número atual de itens.
- Você pode usar a verificação `key in dict`, que retorna `True` se a chave existir, para garantir que o valor esteja no dicionário antes de decrementar o número de itens.
- Essa função deve [retornar][return-keyword] um dict.

## 4. Remova um item completamente do inventário

- Se o item estiver no dicionário, [remova-o][dict-pop].
- Se o item não estiver no dicionário, não faça nada.
- Essa função deve [retornar][return-keyword] um dict.

## 5. Retorne o conteúdo do inventário

- Você precisa usar um [laço for][for-loop] no inventário e, se o número de itens for maior que `0`, adicionar a `tuple` a uma `list`.
- Você pode usar [`dict.items()`][dict items] para iterar sobre o item e o valor ao mesmo tempo; `items()` retorna uma `tuple` que você pode usar ou desestruturar, se precisar.
- Essa função deve [retornar][return-keyword] uma [list][list] de [tuples][tuples].
