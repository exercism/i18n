# Instalação

Esta trilha usa ReScript 12 e depende do [Node.js][nodejs] 22 ou superior.
Muitos sistemas já vêm com ele pré-instalado, ou talvez você já o tenha instalado para outra trilha.

Abra um terminal e rode:

```sh
node -v
```

Se o Node não estiver instalado ou aparecer uma versão mais antiga, siga as [instruções oficiais de instalação do Node.js][nodejs-install] para a sua plataforma.

## Instalando as dependências

Cada exercício de ReScript é um projeto npm independente.
Depois de baixar um exercício com a [CLI do Exercism][exercism-cli], instale as dependências do projeto, incluindo o ReScript, e você já pode começar:

```sh
cd /path/to/exercise
npm install
```
