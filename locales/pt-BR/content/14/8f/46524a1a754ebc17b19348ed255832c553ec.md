# Apêndice das instruções

## Apêndice

~~~~exercism/note
As instruções acima são sincronizadas com um repositório compartilhado para garantir consistência entre todos os tracks de linguagens.
Este apêndice traz esclarecimentos adicionais ou modifica as instruções conforme necessário, para alinhar melhor com os objetivos do track de Clojure.
~~~~

Neste exercício, no track de Clojure, você pode **assumir que a entrada é qualquer combinação aninhada de vetores e que a saída é um vetor**, como indicam os testes.
No entanto, isso não é um requisito rígido; você tem liberdade para assumir que a entrada é qualquer combinação aninhada de coisas sequenciais (listas, vetores etc.) e que a saída é uma sequência.
