# Instruções

Olá, Agente Double-Null0111.

Sua missão, caso você decida aceitá-la, é escrever um par de ferramentas para ajudar você a se infiltrar no quartel-general da UMBRA (United Minions Being Really Awful) e recuperar os planos do esquema mais recente e realmente horrível deles. Você vai precisar de duas ferramentas para cumprir esta missão.

## 1. Proteja os planos secretos recuperados com uma senha

Depois de conseguir os planos secretos, você vai precisar protegê-los para que só quem sabe a senha possa recuperá-los.

Para isso, você vai precisar implementar a função `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`.
Essa função retorna outra função que recebe possíveis strings de senha como entrada.
Se a senha digitada estiver correta, a nova função retorna o segredo escondido; mas se a senha estiver incorreta, a função retorna "Sorry. No hidden secrets here."

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. Gere uma combinação para abrir o cofre deles

Descobrimos que a UMBRA baseia todas as combinações dos seus cofres no número da sala em que está localizada.
As combinações dos cofres são geradas aplicando repetidamente uma função especial ao número da sala.
Assim, o primeiro número da combinação vem da aplicação da função ao número da sala, o segundo vem da aplicação da função ao primeiro número, e o terceiro, da aplicação da função ao segundo número.

No entanto, a UMBRA muda com frequência a função usada para gerar as combinações, então sua ferramenta vai precisar receber tanto um número de sala quanto a função adequada para gerar a combinação.

Implemente a função `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)` para gerar a combinação que você vai precisar.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
