# Dicas

## 1. Gere um planeta aleatório

- O Java não fornece uma função para escolher um elemento de uma coleção aleatoriamente.
- Lembre-se de que você pode recuperar um elemento de um array pelo índice, que é um número inteiro.

## 2. Gere um número de registro de nave estelar aleatório

- A classe `java.util.Random` fornece um método para gerar um `int` aleatório entre 0 e um valor máximo dado.

## 3. Gere uma data estelar aleatória

- O método da classe `java.util.Random` para gerar um `double` aleatório sempre retorna um número entre `0.0` e `1.0`.
