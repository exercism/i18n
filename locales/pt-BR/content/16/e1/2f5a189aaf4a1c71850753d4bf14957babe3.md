# Dicas

## 1. Determine se a lasanha está pronta

- Use uma [condicional][mdn-if-else] para retornar um resultado com base em alguma condição.
- A melhor forma de resolver a tarefa é verificar primeiro as duas condições específicas.
- Lembre-se de que parâmetros ausentes serão `undefined`, e você pode verificar se uma variável é `undefined` usando o operador de igualdade estrita `===`.

## 2. Estime o tempo de preparação

- Use um parâmetro padrão para definir o tempo médio de preparação caso ele não tenha sido informado quando a função foi chamada.
- Reveja [arrays][concept-arrays] para descobrir como determinar o número de camadas (o comprimento do array de camadas).

## 3. Calcule as quantidades de massa e molho necessárias

- Primeiro, crie duas variáveis para acompanhar a quantidade de massa e de molho.
  Defina-as com `let` para poder mudar o valor mais adiante no seu código.
  Atribua também um valor inicial adequado.
- Use um [laço `for`][concept-for-loops] para iterar sobre as camadas.
- Se você encontrar uma camada `'noodles'` ou `'sauce'` no seu laço, aumente a quantidade guardada na variável correspondente.
- Use um [objeto][concept-objects] para retornar os dois resultados.

## 4. Adicione o ingrediente secreto

- Reveja [arrays][concept-arrays] para descobrir como obter um elemento de um array e como adicionar algo ao final de um array.
- O índice do último elemento em um array `a` é `a.length - 1`.
- A função não deve ter uma instrução `return`.

## 5. Ajuste a receita

- Primeiro, calcule o fator que você precisa aplicar a todas as quantidades com base nas porções desejadas.
- Uma forma de garantir que os argumentos não sejam modificados é usar um novo objeto para guardar os resultados.
- Use um [laço `for...in`][mdn-for-in] para percorrer todas as entradas da receita original e preencher o objeto de acordo.
