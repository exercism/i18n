# Formatação de string

Além do método `String#%%`, uma forma comum de criar strings em Ruby é usar [interpolação de strings](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Por exemplo:

```ruby
# Rather than:
"One for %%s, one for me." %% %{name_variable}

# Consider:
"One for #{%{name_variable}}, one for me."
```
