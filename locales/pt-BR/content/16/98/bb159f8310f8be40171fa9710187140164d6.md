# Instruções

Seu amigo Johannes adora montar projetos de hardware do tipo "faça você mesmo" (DIY).
Ele acabou de construir uma máquina de suco e está muito empolgado com isso.
O objetivo de Johannes é conseguir preparar suco fresco todas as manhãs.

A máquina de suco de Johannes tem vários recursos sofisticados.
Como um sistema de medição embutido, que mostra quanto suco há no copo.
Também tem um temporizador, que indica há quanto tempo a máquina está funcionando.

Johannes não é o melhor em programação, mas quer criar um programa para controlar a máquina.
Por isso, pediu sua ajuda.

## 1. Luz de depuração

A máquina tem uma luz de depuração. É um mecanismo simples: se a máquina estiver ligada na tomada, a luz de depuração acende.
O programa só roda se a luz de depuração estiver acesa.

Este método deve ser um método de classe chamado `JuiceMaker`.

Defina o método de classe `JuiceMaker.debug_light_on?` que retorna `true`.

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. Inicializar a máquina

Quando a máquina for ligada, ela deve criar uma instância de uma classe chamada `JuiceMaker`.
A máquina deve ter um estado inicializado.
O estado inicializado deve conter as seguintes informações:

1. Se a máquina está em funcionamento ou não. Isso deve ser sempre `false` quando a máquina é ligada.
2. A quantidade de suco no copo, que será medida por um sensor.

Defina o estado inicializado, que recebe a quantidade de suco no copo como parâmetro, e construa o estado inicializado.
O estado inicializado deve conter uma variável de instância `@running`, definida como `false`, e uma variável de instância `@fluid`, baseada em um argumento passado quando a classe é inicializada.

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. Ligar a máquina

A máquina pode ser ligada e desligada.
Você precisa definir um método para ligar a máquina.
Quando a máquina é ligada, o estado de funcionamento deve ser definido como `true`.

Defina o método `JuiceMaker#start`, que liga a máquina.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. Status da máquina

A máquina precisa conseguir informar o status dela.
Deve retornar `true` se a máquina estiver funcionando e `false` se não estiver.

Defina o método `JuiceMaker#running?`, que retorna o status da máquina.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. Adicionar suco

A máquina pode adicionar suco ao copo.
A máquina consegue dizer quanto suco foi adicionado ao copo.
A máquina precisa de ajuda para saber quanto suco há no copo depois que o suco é adicionado.

Defina o método `JuiceMaker#add_fluid`, que recebe a quantidade de suco adicionada como parâmetro e atualiza a quantidade de suco no copo.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. Desligar a máquina

A máquina pode ser ligada e desligada.
Você precisa definir um método para desligar a máquina.
Esse método só será chamado quando a máquina estiver funcionando.
Quando a máquina é desligada, o estado de funcionamento deve ser definido como `false`.
A máquina também precisa de ajuda para determinar quanto suco há no copo depois de ser desligada.
A máquina usa cinco unidades de suco por minuto.

Defina o método `JuiceMaker#stop`, que recebe o número de minutos que a máquina ficou funcionando como parâmetro e retorna a quantidade de suco no copo depois que a máquina foi desligada.

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
