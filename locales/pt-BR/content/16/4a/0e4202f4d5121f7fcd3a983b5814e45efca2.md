# Introdução

Muitos programas precisam de valores (_aparentemente_) aleatórios para simular eventos do mundo real.

Exemplos comuns e familiares incluem:
- Um lançamento de moeda: um valor aleatório de `('Heads', 'Tails')`.
- O lançamento de um dado: um número inteiro aleatório de 1 a 6.
- Embaralhar um baralho de cartas: uma ordenação aleatória de uma lista de cartas.
- A criação de árvores e arbustos em uma simulação gráfica 3-D.

Gerar valores _realmente_ aleatórios com um computador é um [desafio técnico surpreendentemente difícil][truly-random], então você pode ver esses resultados sendo chamados de "pseudoaleatórios".

Na prática, uma biblioteca bem projetada como o módulo [`random`][random] da biblioteca padrão do Python é rápida, flexível e dá resultados amplamente bons o suficiente para a maioria das aplicações em modelagem, simulação e jogos.

Nesta breve introdução, mostramos as quatro funções mais usadas do módulo.
Incentivamos você a explorar a documentação completa do [`random`][random], pois há muitas ferramentas e opções.

Antes de usar as ferramentas do módulo `random`, você precisa primeiro importá-lo:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Para evitar digitar o nome do módulo, você pode importar funções específicas pelo nome:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` e `randint()`

Como mostrado no primeiro exemplo acima, a função `randrange()` tem três formas:

1. `randrange(stop)` fornece um número inteiro `n` tal que `0 <= n < stop`
2. `randrange(start, stop)` fornece um número inteiro `n` tal que `start <= n < stop`
3. `randrange(start, stop, step)` fornece um número inteiro `n` tal que `start <= n < stop`
    e `n` está na sequência `start, start + step, start + 2*step...`

Para o caso mais comum em que `step == 1`, `randint(a, b)` pode ser mais conveniente e legível.
Os resultados possíveis de `randint()` _incluem_ o limite superior, então `randint(a, b)` é o mesmo que usar `randrange(a, b+1)`.



## `choice()` e `choices()`

Essas duas funções assumem que você está partindo de alguma [sequência][sequence-types] ou outro contêiner.
Normalmente será uma `list` ou, com algumas limitações, uma `tuple` ou um `set` (_uma `tuple` é imutável e um `set` não tem ordem_).

A função `choice()` retorna um membro escolhido aleatoriamente de uma determinada sequência, e `choices()` retorna um número especificado de membros (`k`) escolhidos aleatoriamente de uma determinada sequência.
Nos exemplos mostrados acima, assumimos uma moeda honesta com probabilidade igual de cara ou coroa, mas pesos também podem ser especificados.

Por exemplo, se um saco contém 10 bolas vermelhas e 15 bolas verdes, e queremos tirar uma aleatoriamente:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
