# Anexo às instruções

## Palavras

Defina duas tuplas wrapper que estendem `disposable` (de
`destructors`) e armazenam o stream subjacente junto com os
contadores inteiros `bytes` e `ops`:

- `metered-input < disposable` com os slots `stream`, `bytes`, `ops`.
- `metered-output < disposable` com os slots `stream`, `bytes`, `ops`.

Construa cada uma com `new-disposable` (em vez de `new`) para que o
wrapper seja registrado no framework de destrutores.

- `<metered-input> ( stream -- m )`: encapsula um stream de entrada.
- `<metered-output> ( stream -- m )`: encapsula um stream de saída.

Declare cada tupla como instância do mixin de stream apropriado:

```
INSTANCE: metered-input  input-stream
INSTANCE: metered-output output-stream
```

Depois, forneça métodos `M:` que delegam ao stream subjacente
enquanto atualizam os contadores:

- Para `metered-input`: [`stream-read1`][stream-read1],
  [`stream-read-unsafe`][stream-read-unsafe],
  [`stream-element-type`][stream-element-type] (delegam) e
  [`dispose*`][dispose*].
- Para `metered-output`: [`stream-write1`][stream-write1],
  [`stream-write`][stream-write], [`stream-flush`][stream-flush]
  (delegam) e [`dispose*`][dispose*].

Cada leitura ou escrita bem-sucedida deve somar a quantidade de bytes
transferidos a `bytes>>` e incrementar `ops>>` em um. Uma leitura que
chega ao fim do arquivo ainda conta como uma operação, mas transfere zero bytes.
`dispose*` deve repassar para o stream subjacente.
