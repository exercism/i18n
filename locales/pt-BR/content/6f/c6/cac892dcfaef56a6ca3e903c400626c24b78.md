# Dicas

## 1. Criando a tabela de recordes

- A tabela de recordes precisa ser uma tabela hash.
- Você pode criar uma tabela hash com `make-hash-table`.

## 2. Adicionando um jogador à tabela

- Para adicionar um par chave/valor a uma tabela hash, use `(setf (gethash key table) value)`

## 3. Definindo a pontuação de um jogador

- Definir a pontuação de um jogador é quase a mesma coisa que adicionar o jogador à tabela.
- Para adicionar um par chave/valor a uma tabela hash, use `(setf (gethash key table) value)`

## 4. Obtendo uma pontuação da tabela

- Use `gethash` para obter o valor de uma chave na tabela hash.
- `gethash` tem um terceiro argumento opcional, que é o valor a ser usado se a chave não for encontrada.

## 5. Removendo um jogador da tabela

- Use `remhash` para remover uma chave da tabela.
