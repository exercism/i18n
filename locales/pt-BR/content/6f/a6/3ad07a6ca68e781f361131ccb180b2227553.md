# Introdução

## Strings

Uma `String` em Java é um objeto que representa texto imutável como uma sequência de caracteres Unicode (letras, dígitos, pontuação, etc.).
Aspas duplas são usadas para definir uma instância de `String`:

```java
String fruit = "Apple";
```

Strings são manipuladas chamando os métodos da string.
Depois que uma string foi construída, seu valor nunca pode mudar.
Quaisquer métodos que pareçam modificar uma string na verdade retornam uma nova string.
A classe `String` fornece alguns métodos _static_ para transformar as strings.
