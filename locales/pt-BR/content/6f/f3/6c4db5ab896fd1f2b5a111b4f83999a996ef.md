# Introdução

## Booleanos

Booleanos em Java são representados pelo tipo `boolean`, cujos valores podem ser `true` ou `false`.

Java suporta três operadores booleanos:  

- `!` (NOT): inverte o valor booleano  
- `&&` (AND): recebe dois booleanos e retorna `true` se ambos forem `true`
- `||` (OR): retorna `true` se qualquer um dos dois booleanos for `true`

### Exemplos

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
