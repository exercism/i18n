# Introdução

Uma definição de coleção normalmente inclui um espaço reservado entre sinais de maior e menor, muitas vezes `T` por convenção. Uma coleção assim é chamada de tipo genérico. Isso permite que quem usa a coleção especifique que tipo de itens ela vai guardar. No código de exemplo acima, estamos instanciando uma lista de strings.

Uma classe ou uma função se torna **genérica** com o uso do atributo `@:generic`. Isso faz com que o compilador identifique a classe ou a função como genérica:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
