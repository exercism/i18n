# Fundamentos

Python é uma linguagem de programação [dinâmica e fortemente tipada][dynamic typing in python].
Ela usa tanto [duck typing][duck typing] quanto [tipagem gradual][gradual typing], por meio de [type hints][type hints].
Os _estilos_ de programação imperativa, declarativa (por exemplo, funcional) e orientada a objetos são todos suportados, mas internamente **[tudo em Python é um objeto][everythings an object]**.

O Python dá muita ênfase à legibilidade do código e (_de forma semelhante ao Haskell_) usa [indentação significativa][significant indentation] para denotar definições de funções, métodos e classes.

O Python foi criado por Guido van Rossum e lançado pela primeira vez em 1991.
A [Python Software Foundation][psf] gerencia e direciona recursos para o desenvolvimento de Python e do CPython e recebe propostas de mudanças na linguagem de [membros][psf membership] da comunidade por meio das [Python Enhancement Proposals ou PEPs][peps].


A documentação completa da versão atual está em [docs.python.org][python docs].

## Atribuição de nomes (variáveis e constantes)

Em Python, não há palavras-chave usadas para criar variáveis ou constantes.
Em vez disso, quem programa pode vincular [_nomes_][facts-and-myths-about-python-names] (também chamados de _variáveis_) a qualquer tipo de objeto usando o operador de atribuição `=`: `<name> = <value>`.
Um nome pode ser reatribuído (ou revinculado) a valores diferentes (tipos de objeto diferentes) ao longo de sua existência.

Por exemplo, `my_first_variable` pode ser reatribuída muitas vezes usando `=`, e pode se referir a tipos de objeto diferentes a cada reatribuição:


```python
>>> my_first_variable = 1  # my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  # my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." # <--You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' # <--Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".

>>> import collections
>>> my_first_variable = collections.Counter([1,1,2,3,3,3,4,5,6,7]) # <--Now my_first_variable has been re-bound to a Counter object.
>>> print(type(my_first_variable))
<class 'collections.Counter'>

>>> print(my_first_variable)
Counter({3: 3, 1: 2, 2: 1, 4: 1, 5: 1, 6: 1, 7: 1})
```


### Constantes

Constantes são nomes que devem ser atribuídos apenas uma vez em um programa.
Elas devem ser definidas no nível de um [módulo][module] (arquivo), e normalmente são visíveis para todas as funções e classes do programa.
Usar `SCREAMING_SNAKE_CASE` sinaliza que o nome não deve ser reatribuído, nem seu valor alterado.


```python
# All caps signal that this is intended as a constant.
MY_FIRST_CONSTANT = 16

# Re-assignment will be allowed by the compiler & interpreter,
# but this is VERY strongly discouraged.
# Please don't do this, it could create problems in your program!
MY_FIRST_CONSTANT = "Some other value"
```


## Funções

Em Python, unidades de funcionalidade são encapsuladas em [_funções_][functions], que são elas mesmas [objetos][objects] (_é [tartarugas até o fim][turtles all the way down]_).

As funções podem ser executadas por si mesmas, passadas como argumentos para outras funções, aninhadas ou vinculadas a uma classe.
Quando funções são vinculadas a um nome de [classe][classes], elas são chamadas de [métodos][method objects].
Funções e classes relacionadas (_com seus métodos_) podem ser agrupadas no mesmo arquivo ou módulo, e importadas em parte ou no todo para uso em outros programas.

A palavra-chave `def` inicia uma [definição de função][function definition].
Cada função pode ter zero ou mais [parâmetros][parameters] formais nos parênteses `()`, seguidos de dois-pontos `:`.
As instruções do _corpo_ da função começam na linha seguinte ao `def` e devem estar _indentadas em um bloco_:


```python
# The body of a function is indented by 2 spaces & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     # <--This was only indented by 3 spaces.
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


As funções retornam _explicitamente_ um valor ou objeto por meio da palavra-chave [`return`][return]:


```python
# Function definition on first line, explicit return used on final line.
def add_two_numbers(number_one, number_two):
  return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing 
# the variable will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```

Funções que não têm uma expressão _explícita_ após um `return` retornam _implicitamente_ o objeto [`None`][none].
Os detalhes de `None` serão abordados em um conceito posterior.
Para os fins deste exercício e desta explicação, `None` é um marcador que representa nada, ou null:


```python

# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

Funções que omitem `return` também retornam _implicitamente_ o objeto [`None`][none].
Isso significa que, se você não usar `return` em uma função, o Python retornará o objeto `None` para você.

```python

# This function omits a return keyword altogether
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


### Chamando funções

As funções são [_chamadas_][calls] ou invocadas usando seu nome seguido de `()`.
A notação de ponto (`.`) é usada para chamar funções definidas dentro de uma classe ou módulo.

```python
>>> def raise_to_power(number, power):
...     return number ** power
...

>>> raise_to_power(3,3) # Invoking the function with the arguments 3 and 3.
27


# A mis-match between the number of parameters and the number of arguments will raise an error.
>>> raise_to_power(4,)
...
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: raise_to_power() missing 1 required positional argument: 'power'


# Calling methods or functions in classes and modules.
>>> start_text = "my silly sentence for examples."
>>> str.upper(start_text)  # <--Calling the upper() method from the built-in str class on start_text.
'MY SILLY SENTENCE FOR EXAMPLES.'

# Because a string is an instance of the str class, methods can also be called on them "directly".
>>> start_text = "my silly sentence for examples."
>>> start_text.upper()  # <--Calling the upper() method on start_text directly.
'MY SILLY SENTENCE FOR EXAMPLES.'

# Alternatively, we can skip the variable assignment (although this gets messy quick).
>>> "my silly sentence for examples.".upper()
'MY SILLY SENTENCE FOR EXAMPLES.'


# Importing the math module
>>> import math
>>> math.pow(2,4)  # <--Calling the pow() function from the math module.
16.0
```


## Comentários

Os [comentários][comments] em Python começam com um `#` que não faz parte de uma string, e terminam no fim da linha.
Diferente de muitas outras linguagens de programação, o Python **não suporta** marcas de comentário multilinha.
Cada linha de um bloco de comentário deve começar com o caractere `#`.

Os comentários são ignorados pelo interpretador:


```python
# This is a single line comment.

x = "foo"  # This is an in-line comment.

# This is a multi-line
# comment block over multiple lines --
# these should be used sparingly.
```


## Docstrings

A primeira instrução do corpo de uma função pode ser, opcionalmente, uma [_docstring_][docstring], que resume de forma concisa o propósito da função ou do objeto.
As docstrings são declaradas usando três aspas duplas (""") indentadas no mesmo nível do bloco de código:


```python
# An example from PEP257 of a multi-line docstring
# reformatted to use Google style non-type hinted docstrings.
# Some additional details can be found in the Sphinx documentation:
# https://www.sphinx-doc.org/en/master/usage/extensions/napoleon.html#getting-started

def complex(real=0.0, imag=0.0):
    """Form a complex number.

    Keyword Arguments:
        real (float): The real part of the number (default 0.0)
        imag (float): The imaginary part of the number (default 0.0)
        
    """

    if imag == 0.0 and real == 0.0:
        return complex_zero

```


As docstrings são lidas por ferramentas automatizadas de documentação e são retornadas ao chamar o atributo especial `.__doc__` na função, no método ou no nome da classe.
Elas são recomendadas para programas de qualquer tamanho que precisem de documentação, e suas convenções estão descritas na [PEP257][pep257].

As docstrings também podem funcionar como [testes de unidade leves][doctests], que podem ser lidos e executados pelo PyTest, ou importando o módulo `doctest`.
Testes e `doctest` serão abordados em um conceito posterior.


```python
# An example on a user-defined function using a Google style docstring. 
>>> def raise_to_power(number, power):
    """Raise a number to an arbitrary power.

    Parameters:
        number (int): The base number.
        power (int): The power to raise the base number to.
    
    Returns:
        int: The number raised to the specified power.
    
    Takes a number and raises it to the specified power, returning the result.

    """

    return number ** power
```
