# Instruções

Sua tarefa é, dado um diagrama, determinar de quais plantas cada criança da turma do jardim de infância é responsável.

A turma tem 12 crianças:

- Alice, Bob, Charlie, David, Eve, Fred, Ginny, Harriet, Ileana, Joseph, Kincaid e Larry.

São plantados quatro tipos diferentes de sementes:

| Planta | Representação no diagrama |
| ------ | ------------------------- |
| Grass  | G                         |
| Clover | C                         |
| Radish | R                         |
| Violet | V                         |

Cada criança recebe quatro copos, dois em cada linha:

```text
[window][window][window]
........................ # each dot represents a cup
........................
```

O professor distribui os copos para as crianças em ordem alfabética pelos nomes, o que significa que Alice vem primeiro e Larry vem por último.

Veja um diagrama de exemplo que representa as plantas da Alice:

```text
[window][window][window]
VR......................
RG......................
```

Na primeira linha, mais perto das janelas, ela tem uma violet e um radish.
Na segunda linha, ela tem um radish e um pouco de grass.

Seu programa vai receber as plantas da esquerda para a direita, começando pela linha mais próxima das janelas.
A partir disso, ele deve conseguir determinar quais plantas pertencem a cada estudante.

Por exemplo, se for dito que o jardim está assim:

```text
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

Então, se pedirem as plantas da Alice, ele deve fornecer:

- Violets, radishes, violets, radishes

Já se pedirem as plantas do Bob, o resultado seria:

- Clover, grass, clover, clover
