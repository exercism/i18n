# Introdução

Em JavaScript, um array, ou vetor, é uma estrutura parecida com uma lista, sem comprimento fixo, que pode armazenar qualquer tipo de primitivo ou objeto, até mesmo tipos misturados.

Para criar um array, coloque os elementos entre colchetes `[]`.
Para ler um array, coloque o índice entre colchetes `[]` depois do identificador.
Os índices de um array começam em zero.

Por exemplo:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Para descobrir quantos elementos há em um array, use a propriedade `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Para alterar um elemento do array, atribua um valor ao índice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Métodos

Alguns dos [métodos][mdn-array] disponíveis em todo objeto Array podem ser usados para adicionar ou remover elementos do array.
Aqui estão alguns para considerar ao fazer este exercício:

### push

Um `value` pode ser _adicionado_ ao final de um array usando `.push(value)`.
O método retorna o novo comprimento do array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

O _último_ `value` pode ser _removido_ de um array usando `.pop()`
O método retorna o valor removido.
O comprimento do array vai diminuir por causa dessa mudança.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

O _primeiro_ `value` pode ser _removido_ de um array usando `.shift()`
O método retorna o valor removido.
O comprimento do array vai diminuir por causa dessa mudança.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

Um `value` pode ser _adicionado_ ao início de um array usando `.unshift(value)`.
O método retorna o novo comprimento do array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

Um `value` em um `index` específico pode ser _removido_ de um array usando `.splice(index, 1)`.
O método retorna o(s) elemento(s) removido(s).

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
Esses métodos são mais poderosos do que o descrito aqui:

- Tanto `push` quanto `unshift` permitem adicionar ou inserir vários valores de uma vez, passando mais argumentos.
  Isso não é necessário para completar este exercício.
- O `splice` pode remover vários valores aumentando o segundo argumento.
  Isso não é necessário para completar este exercício.
- O `splice` também pode adicionar vários valores, passando-os como argumentos depois do `deleteCount`.
  Isso pode ser usado para substituir valores, ou inserir valores no meio de um array (por exemplo, removendo 0 elementos).
  Isso não é necessário para completar este exercício.
~~~
