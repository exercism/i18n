# Introdução

Um [`Set`][set] é uma coleção de itens com as seguintes propriedades:

- Sem ordem definida.
- Os elementos são únicos, então tentativas de adicionar duplicatas são ignoradas silenciosamente.
- Dá suporte a muitas das operações comuns em conjuntos matemáticos.

Para criar um, use o construtor `Set()`, passando qualquer iterador como parâmetro.

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

Adicione novos elementos com `push!()` (do mesmo jeito que com arrays) e remova-os com `delete!()`.

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## Operações com conjuntos

Como em vários outros tipos de coleção, você pode verificar se um elemento pertence ao conjunto com o operador `in` ou `∈` (digite `\in` e depois tab para inserir o símbolo).

```julia-repl
julia> 3 ∈ s1
true
```

As seguintes operações com pares de conjuntos são suportadas (os atalhos para o símbolo do operador aparecem entre parênteses).

- `union(A, B)` ou `A ∪ B` (`\cup`): todos os elementos em A ou B, ou em ambos.
- `intersect(A, B)` ou `A ∩ B` (`\cap`): todos os elementos comuns a A e B.
- `setdiff(A, B)` (sem símbolo): os elementos em A, mas não em B.
- `symdiff(A, B)` (sem símbolo): os elementos em A ou em B, mas não em ambos.
- `issubset(A, B)` ou `A ⊆ B` (`\subseteq`) ou `B ⊇ A` (`\supseteq`): `true` se todos os elementos de A também estão em B.
- `issetequal(A, B)` (sem símbolo): `true` se A e B contêm exatamente os mesmos elementos.
- `isdisjoint(A, B)` (sem símbolo): `true` se A e B não têm elementos em comum (ou seja, a interseção é vazia).

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

Também existem versões mutantes de muitas dessas operações, com `!` adicionado ao nome da função.
Consulte o [manual][set] para ver a lista completa de funções.
