# Instalação

## Requisitos

* Uma CPU x86 de 64 bits
* Um compilador C moderno
* A ferramenta de build Make
* O Netwide Assembler (NASM)

Observe que esta trilha só dá suporte à convenção de chamada da ABI System V
AMD64. Quem usa Windows vai precisar instalar o Subsistema Windows para Linux
(WSL) ou montar uma máquina virtual com Linux.

## Linux

Instale o software necessário com o gerenciador de pacotes do seu sistema:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Instale o Xcode Command Line Tools:

```bash
$ xcode-select --install
```

Instale o NASM usando o [Homebrew](http://brew.sh/):

```bash
$ brew install nasm
```

## Windows

Para instalar o WSL, consulte https://docs.microsoft.com/en-us/windows/wsl/install-win10.
