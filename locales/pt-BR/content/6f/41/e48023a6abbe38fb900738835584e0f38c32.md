# Instalação

## Instalando o .NET

A trilha de F# é construída sobre a plataforma [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), que roda no Windows, Linux e macOS. Para compilar projetos .NET, você pode usar a Interface de Linha de Comando (CLI) do .NET. Essa CLI faz parte do .NET SDK, que você pode instalar seguindo as [instruções de instalação](https://dotnet.microsoft.com/download). Observação: a trilha de F# exige a versão 8.0 ou superior do SDK.

Depois de concluir a instalação, você pode verificar se a CLI foi instalada com sucesso rodando este comando no terminal:

```bash
dotnet --version
```

Se a saída for uma versão maior ou igual a `8.0.100`, o .NET SDK foi instalado com sucesso.

## Usando uma IDE

Se você quer uma experiência de edição mais completa, provavelmente vai querer usar uma IDE. Estas são as IDEs mais populares que suportam a compilação de projetos .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) com a [extensão Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Observação: como o formato de projeto do .NET é bem diferente das versões anteriores, IDEs mais antigas (como o Visual Studio 2015) não são compatíveis.
