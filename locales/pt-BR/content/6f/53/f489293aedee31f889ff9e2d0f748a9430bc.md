# Dicas

## Geral

- Não se preocupe com o modo como os argumentos são _derivados_: concentre-se em combinar os argumentos para retornar o resultado esperado.

## 0. Defina um estado da máquina

- Defina uma variável com o nome `PowerOn` e um valor [boolean][booleans] verdadeiro.

## 1. Defina se o Pac-Man pode comer um fantasma

- Você pode usar o [operador][logical-operators] `-and` para combinar os argumentos e obter um resultado.


## 2. Defina se o Pac-Man marca pontos

- Você pode usar o [operador][logical-operators] `-or` para combinar os argumentos e obter um resultado.


## 3. Defina se o Pac-Man perde

- Você pode usar o [operador][logical-operators] `-not` para combinar os argumentos e obter um resultado.


## 4. Defina se o Pac-Man vence

- Combine os [operadores][logical-operators] anteriores para obter o resultado.
