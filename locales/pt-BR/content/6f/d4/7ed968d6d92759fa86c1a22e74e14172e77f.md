# Dicas

## Geral

- Leia a documentação sobre [conjuntos][set]
- A documentação sobre [listas][lists] também pode ser útil

## 1. Comece uma coleção

- A função mais apropriada de `Set` é [`Set.singleton`][singleton]

## 2. Aumente a coleção

- Use a [função `Set.insert`][insert]
- Use a [função `Set.member`][member]

## 3. Comece a trocar

- Use a [função `Set.member`][member]
- Use a [função `Set.insert`][insert]
- Use a [função `Set.remove`][remove]

## 4. Só pode haver um de cada

- Um `Set` tem a propriedade de armazenar apenas valores únicos
- Use a [função `Set.fromList`][fromList]
- Use a [função `Set.toList`][toList]
- É garantido que `Set.toList` retorna uma lista ordenada

## 5. Cartas que eles não têm

- Use a [função `Set.diff`][diff]
- Use a [função `Set.size`][size]

## 6. Cartas que todos eles têm

- Use as [funções `List.foldl` ou `List.foldr`][fold]
- Use correspondência de padrões na lista para diferenciar listas vazias de listas não vazias
- Use a [função `Set.intersect`][intersect]
- Use a [função `Set.toList`][toList]
- É garantido que `Set.toList` retorna uma lista ordenada

## 7. Todas as cartas

- Use as [funções `List.foldl` ou `List.foldr`][fold]
- Use [`Set.empty`][empty] como acumulador
- Use a [função `Set.union`][union]
- Use a [função `Set.size`][size]

## 8. Shiny para a vitória

- Use a [função `Set.partition`][partition]
- Use a [função `String.startsWith`][startsWith]
- Use a [função `Set.toList`][toList]
- É garantido que `Set.toList` retorna uma lista ordenada
