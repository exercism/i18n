# Introdução

Do [manual][man-types]

> o jq oferece o mesmo conjunto de tipos de dados que o JSON: números, strings, booleans, arrays, objetos (que, no jargão do JSON, são hashes com apenas chaves do tipo string) e `"null"`.

Vamos nos concentrar nos **números**.

## Números e operadores numéricos

Todos os números, sejam inteiros ou não, são números de ponto flutuante de precisão dupla IEEE754.
Isso nos limita a 53 bits de precisão.

Os operadores usuais estão disponíveis para uso com números:

- aritméticos: `+`, `-`, `*`, `/`, `%`
- comparação: `==`, `!=`, `<`, `<=`, `>=`, `>`
- [funções matemáticas][man-math] padrão

  Para funções de uma entrada, passe o valor por pipe para a função

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Para funções de duas entradas, as funções ignoram a entrada e esperam as
  entradas como parâmetros (lembre-se de que os parâmetros são separados por
  ponto e vírgula)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  O ponto e vírgula é o separador dos argumentos da função, não a vírgula.

## Outras expressões `jq`

Para resolver o exercício, você vai precisar conhecer as expressões condicionais.

### Expressões condicionais

O `jq` usa uma [expressão `if-then-else`][if-then-else] para **expressões condicionais**.
Como _expressão_, ela é colocada em um pipeline.

A sintaxe é: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

A cláusula `else` é opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Condições adicionais usam `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
