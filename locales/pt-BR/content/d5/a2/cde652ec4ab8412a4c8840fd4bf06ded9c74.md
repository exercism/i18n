# Instruções

Converta um número, representado como uma sequência de dígitos em uma base, para qualquer outra base.

Implemente a conversão de base de forma geral.
Dado um número na base **a**, representado como uma sequência de dígitos, converta-o para a base **b**.

## Observação

- Tente implementar a conversão por conta própria.
  Não use outra coisa para fazer a conversão no seu lugar.

## Sobre a [notação posicional][positional-notation]

Na notação posicional, um número na base **b** pode ser entendido como uma combinação linear de potências de **b**.

O número 42, *na base 10*, significa:

`(4 * 10^1) + (2 * 10^0)`

O número 101010, *na base 2*, significa:

`(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)`

O número 1120, *na base 3*, significa:

`(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)`

Acho que você entendeu a ideia!

*Sim. Esses três números acima são exatamente iguais. Parabéns!*
