# Apêndice das instruções

## Dicas

Para completar este exercício, você precisa criar o tipo de dados `Deque`
e implementar as seguintes funções:

- `mkDeque`
- `pop`
- `push`
- `unshift`
- `shift`

Você vai encontrar uma declaração de dados fictícia e as assinaturas de tipo já no lugar,
mas cabe a você definir as funções e criar um tipo de dados, um `newtype` ou um sinônimo de tipo que faça sentido.
