# Testando na linha de comando

Execute os testes com:

```bash
scarb cairo-test
```

Todos os testes, exceto o primeiro, foram ignorados. Depois de fazer o primeiro teste
passar, abra o arquivo-fonte dos testes, que fica no diretório `tests`,
remova a flag `#[ignore]` do próximo teste e faça os testes passarem
de novo. Cada teste é uma função com a flag `#[test]` acima dela.
Continue assim até passar em todos os testes.

Se você quiser rodar _todos_ os testes sem editar o arquivo-fonte dos testes, use:

```bash
scarb cairo-test --include-ignored
```

Para rodar um teste específico, ignorado ou não, por exemplo `some_test`, você pode usar:

```bash
scarb cairo-test -f some_test
```

Para saber mais sobre os testes em Cairo, consulte a [documentação de testes][cairo-tests] online.

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
