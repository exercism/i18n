# Instruções

Neste exercício você vai trabalhar em um agendador de compromissos para um salão de beleza em Nova York que abriu em 15 de setembro de 2012.

Você tem quatro tarefas, e todas elas envolvem datas de agendamento. As datas e os horários usarão um dos três formatos a seguir:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
Os testes vão definir automaticamente a cultura como `en-US`. Você não precisa definir nem especificar a cultura por conta própria.
~~~~

## 1. Interpretar a data do agendamento

Implemente a função `schedule`, que consegue interpretar uma representação textual de uma data de agendamento no formato `DateTime` correspondente:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Verificar se um agendamento já passou

Implemente a função `hasPassed`, que recebe uma data de agendamento e verifica se o agendamento ficou em algum momento no passado:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Verificar se o agendamento é à tarde

Implemente a função `isAfternoonAppointment`, que recebe uma data de agendamento e verifica se o agendamento é à tarde (>= 12:00 e < 18:00):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Descrever a data e o horário do agendamento

Implemente a função `description`, que recebe uma data de agendamento e retorna uma descrição dessa data e desse horário:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Retornar a data de aniversário

Implemente a função `anniversaryDate`, que retorna a data de aniversário deste ano, que é 15 de setembro:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
