# Dicas

## 1. Interpretar a data do agendamento em formato numérico

- O construtor vai precisar de um [DateFormat][dateformat] adequado.

## 2. Verificar se um agendamento já passou

- A comparação com o DateTime atual é sintaticamente parecida com qualquer comparação numérica.

## 3. Verificar se o agendamento é à tarde

- Pense em qual parte do DateTime é útil: _não_ a data, e os minutos importam?
- Leia as instruções para conferir a inclusão/exclusão dos limites na comparação de horários (matematicamente, isso é um intervalo semiaberto).

## 4. Descrever o horário e a data do agendamento

- O método `Dates.format()` foi feito para isso.
- Inclua a parte `Dates.` por segurança (_desculpe, isso pode ser um bug no Julia_).
- Mais uma vez, você vai precisar de um [DateFormat][dateformat].

## 5. Retornar a data do aniversário

- Qual é o ano atual?
- Construa uma `Date` para 15 de setembro deste ano.

[dateformat]: https://docs.julialang.org/en/v1/stdlib/Dates/#Dates.DateFormat
