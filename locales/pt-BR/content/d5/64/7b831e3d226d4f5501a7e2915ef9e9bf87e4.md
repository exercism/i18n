# Introdução

Para criar uma instância de uma _classe_, você chama o _construtor_ dela por meio do operador `new`. Um construtor é um tipo especial de método cujo objetivo é inicializar uma instância recém-criada. Os construtores se parecem com métodos comuns, mas não têm tipo de retorno e têm um nome que corresponde ao nome da classe.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Assim como os métodos comuns, os construtores podem ter parâmetros. Os parâmetros de um construtor geralmente são armazenados como campos (privados) para serem acessados mais tarde, ou então usados em algum cálculo pontual. Argumentos podem ser passados para os construtores do mesmo jeito que se passam argumentos para métodos comuns.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
