# Dicas

## Geral

- Leia sobre [IO][getting-started-io] no guia Getting Started.
- Leia sobre [depuração com `IO.inspect/2`][getting-started-debugging-io-inspect] no guia Getting Started.
- Leia sobre o [módulo `IO`][module-io] na documentação.

## 1. Dê boas-vindas ao novo jogador

- Existe uma [função embutida][io-puts] que escreve uma string na saída padrão.

## 2. Pergunte o nome do personagem

- Existe uma [função embutida][io-gets] que lê uma string da saída padrão. Ela também pode escrever um prompt, então não é preciso usar uma função separada para escrever a pergunta.
- Existe uma [função embutida][string-trim] no módulo `String` que pode remover espaços em branco no início e no fim da entrada.

## 3. Pergunte a classe do personagem

- Existe uma [função embutida][io-gets] que lê uma string da saída padrão. Ela também pode escrever um prompt, então não é preciso usar uma função separada para escrever a pergunta.
- Existe uma [função embutida][string-trim] no módulo `String` que pode remover espaços em branco no início e no fim da entrada.

## 4. Pergunte o nível do personagem

- Existe uma [função embutida][io-gets] que lê uma string da saída padrão. Ela também pode escrever um prompt, então não é preciso usar uma função separada para escrever a pergunta.
- Existe uma [função embutida][string-trim] no módulo `String` que pode remover espaços em branco no início e no fim da entrada.
- Existe uma [função embutida][string-to-integer] no módulo `String` que pode converter uma string em um número inteiro.

## 5. Combine as etapas anteriores em uma só

- Reutilize as funções implementadas nas etapas anteriores.
- Existe uma [função embutida][io-inspect], útil para depuração, que pode escrever na saída padrão mais do que apenas strings. Essa função aceita opções, por exemplo uma string que será escrita antes do valor passado.
- A função e a opção mencionadas acima acrescentam um dois-pontos e um espaço a essa string para você.
