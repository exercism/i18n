# Dicas

## Geral

- Use [funções anônimas][anon-fns].
- Use um [closure][closure] para referenciar a variável do escopo externo.

## 1. Crie um somador

- Retorne uma função anônima que soma o argumento da função anônima ao argumento passado para `Secret.secret_add/1`.

## 2. Crie um subtrator

- Retorne uma função anônima que subtrai o argumento passado para `Secret.secret_subtract/1` do argumento da função anônima.

## 3. Crie um multiplicador

- Retorne uma função anônima que multiplica o argumento da função anônima pelo argumento passado para `Secret.secret_multiply/1`.

## 4. Crie um divisor

- Retorne uma função anônima que divide o argumento da função anônima pelo argumento passado para `Secret.secret_divide/1`.
- Use [divisão inteira][div].

## 5. Crie uma função de "and"

- Retorne uma função anônima que realiza uma operação [bitwise _and_][bitwise-wiki] usando o argumento passado para a função anônima e o argumento passado para `Secret.secret_and/1`
- As funções do [módulo Bitwise][bitwise-hexdocs] podem ser úteis.
- Se você estiver rodando o Elixir na versão 1.9 ou inferior, vai precisar chamar `require Bitwise` no início da definição do módulo para conseguir usar o módulo _Bitwise_.

## 6. Crie uma função de "xor"

- Retorne uma função anônima que realiza uma operação [bitwise _xor_][bitwise-wiki] usando o argumento passado para a função anônima e o argumento passado para `Secret.secret_xor/1`
- As funções do [módulo Bitwise][bitwise-hexdocs] podem ser úteis.
- Se você estiver rodando o Elixir na versão 1.9 ou inferior, vai precisar chamar `require Bitwise` no início da definição do módulo para conseguir usar o módulo _Bitwise_.

## 7. Crie um combinador de funções

- Retorne uma função anônima que [compõe as funções][fn-composition] passadas para `Secret.secret_combine/2`.
- Use um `.` antes dos `()` ao chamar uma função anônima.
