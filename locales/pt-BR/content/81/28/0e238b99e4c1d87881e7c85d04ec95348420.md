# Sobre

Em Rust, métodos são funções definidas para uma struct (ou um `enum` ou objeto `trait`).
Isso muda o padrão de chamada: em vez de `frobnicate(foo)`, um método é chamado como `foo.frobnicate()`.

Métodos são parecidos com funções: são declarados com a palavra-chave `fn`,
têm um nome e podem ter parâmetros e valores de retorno.

Diferente das funções, o primeiro parâmetro de um método é sempre `self` (ou uma variante dele),
que representa a instância da struct na qual o método está sendo chamado (mais detalhes abaixo).

Vamos criar um `enum` para as casas de Hogwarts e uma `struct` que descreve a `age` e a `house` de um bruxo:

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## Definindo métodos

Para definir métodos para a struct `Wizard`, começamos um bloco `impl` (abreviação de implementação) para `Wizard`.

```rust
impl Wizard { }
```

Tudo dentro desse bloco `impl` fica associado ao tipo `Wizard`.
Repare que uma struct pode ter vários blocos `impl`.

### Usando `self`

Um método precisa ter, como primeiro parâmetro, um parâmetro chamado `self` do tipo `Self`.
O tipo `Self` é um apelido para o tipo ao qual o bloco `impl` pertence.
No nosso exemplo, `Self` representa `Wizard`.

Por conveniência, Rust permite abreviar isso usando apenas o nome `self` no lugar do primeiro parâmetro.
Os tipos de `self` mais comuns em métodos são:

- `self`: abrevia `self: Self`. A assinatura com apenas `self` consome a instância.
- `&self`: abrevia `self: &Self`. Isso empresta a instância de forma imutável.
- `&mut self`: abrevia `self: &mut Self`. Isso empresta a instância de forma mutável.

Em código mais avançado, você também pode ver assinaturas como `self: Pin<&self>`, `self: Rc<Self>`, etc.
Isso, porém, está além do escopo deste tutorial.

### Definindo um método com `&self`

Se quisermos implementar um método `info` para exibir as informações básicas do bruxo,
podemos definir esse método dentro de um bloco `impl` para `Wizard`:

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

Repare que, na assinatura de `info`, nós emprestamos a instância de forma imutável com `&self`.
Assim, podemos ler os campos `age` e `house` de uma instância de `Wizard` sem alterá-los.
Se tivéssemos usado um `self` que consome a instância em vez de emprestá-la, a instância ficaria inacessível depois que o método fosse chamado.

Com o método `info` implementado, podemos imprimir as informações básicas de um bruxo:

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### Definindo um método com `&mut self`

Se quisermos implementar um método que altera os campos de uma instância de struct,
emprestamos a instância de forma mutável com `&mut self` na assinatura do método.

Digamos que queremos criar uma nova regra em Hogwarts para permitir que os alunos troquem de casa.
Poderíamos implementar um método `switch_house` assim:

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

Agora podemos trocar a casa de um bruxo que estuda em Hogwarts:

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## Vários blocos 'impl'

Em Rust, cada item pode ter vários blocos `impl`.
Então podemos agrupar todos os métodos em um mesmo bloco `impl` ou ter vários blocos `impl` para grupos diferentes de métodos.
As duas abordagens são sintaxe válida, mas a organização típica de projetos usa um único bloco `impl` por conjunto único de restrições `where` no nível do `impl`.

## Funções associadas

É possível definir funções dentro de um bloco `impl` que não têm um parâmetro `self`.
Como não têm o parâmetro `self`, elas não são métodos.
Ainda assim, continuam associadas ao tipo implementado e são chamadas nomeando esse tipo.
Por isso, são chamadas de funções associadas (ou funções associadas ao tipo).

Você já viu algumas funções associadas, como `String::from()`:

```rust
let some_string = String::from("This is an associated function but not a method");
```

Construtores costumam ser implementados como funções associadas.
Vamos criar uma função `new` associada ao tipo `Wizard`:

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

Repare que podemos usar `Self` no lugar de `Wizard` para indicar o tipo que será retornado pela função.
Não é obrigatório usar o apelido de tipo `Self` dessa forma, mas isso pode simplificar a implementação de tipos com nomes complicados ou longos.
Agora podemos rodar o seguinte:

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
