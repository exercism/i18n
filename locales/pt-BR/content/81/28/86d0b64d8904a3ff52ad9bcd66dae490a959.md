# Dicas

## 1. Crie um carro de controle remoto

- Retorne uma lista com 4 elementos nomeados.
- `speed` e `battery_drain` são fornecidos como argumentos.
- `battery` e `distance_traveled` assumem valores padrão.

## 2. Crie uma pista de corrida

- Retorne uma lista de comprimento 1.

## 3. Verifique se a bateria está descarregada

- Para ser considerada "descarregada", a carga da bateria não precisa ser zero, apenas baixa o suficiente para que outra rodada não possa ser concluída.
- O controle do carro é feito em passos discretos. Quando falamos em "rodada", queremos dizer "cada vez que `drive()` é chamada".

## 4. Dirija o carro

- A bateria está descarregada? Se estiver, o carro deve ser atualizado?
- `battery_drain` é a porcentagem de carga perdida em cada rodada.
- `speed` é a distância percorrida em cada rodada.
- Retorne um carro atualizado, conforme o caso.

## 5. Verifique se um carro de controle remoto consegue terminar uma corrida

- Quantas rodadas mais o carro consegue completar?
- Não existem rodadas parciais, então a função [`floor`][ref-round] pode ser útil. Como alternativa, a divisão inteira `%/%` também funciona com valores de ponto flutuante, truncando o resultado.
- Qual distância o carro consegue percorrer nesse número de rodadas?
- É o suficiente?

## 6. Armazene se o carro consegue terminar uma pista com a bateria cheia

- Redefina `battery` e `distance_traveled` para os valores de um carro novo antes de qualquer cálculo.
- Listas são vetores _recursivos_, então podem conter outras listas.
- O nome do novo elemento é fornecido em tempo de execução, então a notação `$` não vai funcionar. A Introdução sugere alternativas.
- O valor do novo elemento é uma `list` de comprimento 2. Ela não pode ser um `vector`, porque mistura elementos numéricos e lógicos.
- Retorne o carro atualizado.
- Considere que vários elementos de pista podem ser adicionados, com nomes diferentes.

[ref-round]: https://www.rdocumentation.org/packages/base/versions/3.3.0/topics/Round
