# Instruções

Um novo clube de poesia abriu na cidade, e você está pensando em ir.
Como já houve incidentes no passado, o clube tem uma política de entrada bem específica, que você precisa dominar antes de tentar entrar.

O clube de poesia tem duas portas, uma na frente e outra nos fundos, e as duas são vigiadas.
Para entrar, você vai precisar descobrir a senha do dia.

A senha é sempre baseada em um poema e pode ser obtida em um processo de duas etapas.

1. O guarda recita o poema, uma linha por vez, e você precisa responder com uma letra apropriada dessa linha.
2. O guarda então diz, de uma vez, todas as letras que você respondeu, e você precisa anotá-las em um papel em um formato específico.

Os detalhes do processo dependem de qual porta você está tentando entrar.

~~~~exercism/note
Todas as strings neste exercício serão codificadas em ASCII e terminadas em NUL.
Isso significa que todos os caracteres usam codificação ASCII e toda string termina quando o '\0' (o caractere NUL, com valor `0`) é encontrado.
~~~~

~~~~exercism/note
Estas são as instruções de string mencionadas neste conceito:

| instrução  | o que ela faz                                                                                                     |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | carrega um valor de um local de memória indicado por `rsi` em `rax`                                               |
| `stos`       | armazena um valor de `rax` em um local de memória indicado por `rdi`                                              |
| `movs`       | copia um valor de um local de memória indicado por `rsi` e o armazena em um local de memória indicado por `rdi`   |

Todas elas precisam ter um sufixo para indicar o tamanho da operação:

| sufixo | tamanho          |
|--------|------------------|
| `b`    | byte             |
| `w`    | word (2 bytes)   |
| `d`    | dword (4 bytes)  |
| `q`    | qword (8 bytes)  |

Todas as instruções de string também modificam os endereços em `rsi` e/ou `rdi` (apenas nos registradores que a instrução usa).
Por padrão, elas incrementam os endereços pelo tamanho da operação.

O prefixo `rep` pode ser adicionado a qualquer uma das instruções de string acima para repeti-la um número de vezes igual a `rcx`.
~~~~

## 1. Obtenha a primeira letra de uma frase

Para determinar as letras da senha da porta da frente, você precisa responder com a primeira letra da linha do poema que o guarda recita para você.

Para chegar a uma senha bonita, os membros do clube de poesia gostam de usar poemas _acrósticos_.
Isso significa que a primeira letra de cada frase forma uma palavra.
Veja um exemplo de um dos escritores favoritos deles, Michael Lockwood.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Então, quando o guarda recitar **Stands so high**, você responde **S**; quando ele recitar **Huge hooves too**, você responde **H**.

Implemente a função `front_door_response`, que recebe como argumento o endereço na memória de uma linha do poema e retorna a primeira letra dessa linha.
Essa letra deve ser retornada como um caractere codificado em ASCII, ocupando 1 byte.

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. Capitalize uma palavra

Agora que você tem todas as letras corretas, tudo o que precisa fazer para obter a senha da porta da frente é capitalizar a palavra corretamente.

Implemente a função `front_door_password`, que recebe como argumento o endereço na memória de uma string contendo apenas as letras combinadas que você encontrou na tarefa 1.
Ela deve modificar a string de entrada [no local][in-place], para que a capitalização fique correta.
Isso significa que a string correta deve ser armazenada no mesmo local de memória da entrada.

A função não tem valor de retorno.

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. Obtenha a última letra de uma frase

Para determinar as letras da senha da porta dos fundos, você precisa responder com a última letra da linha do poema que o guarda recita para você.

Os membros do clube de poesia são muito espertos.
O poema mencionado antes também é _telestíquio_, o que significa que a última letra de cada frase também forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recitar **Stands so high**, você responde **h**; quando ele recitar **Huge hooves too**, você responde **o**.

Repare que às vezes o guarda faz pausas estilísticas (na forma de pontuação ou espaços em branco) ao recitar o poema.
Você vai precisar ignorar essas pausas para obter a letra correta.

Implemente a função `back_door_response`, que recebe como argumento o endereço na memória de uma linha do poema e retorna a última letra dessa linha.
Essa letra deve ser retornada como um caractere codificado em ASCII, ocupando 1 byte.

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. Seja gentil

Para entrar no clube de poesia pela porta dos fundos, você precisa ser ainda mais gentil.
Então, para obter a senha, desta vez você precisa capitalizar a palavra corretamente e adicionar `", please."` no final.

Implemente a função `back_door_password`, que recebe como argumentos, nesta ordem:

1. O endereço na memória de um buffer onde a string resultante será armazenada.
2. O endereço na memória de uma string contendo as letras combinadas que você encontrou na tarefa 3.

A função deve armazenar a versão gentil da senha capitalizada no [buffer][buffer].
Um _buffer_ é um array que pode ser usado para armazenar valores na memória, a fim de movê-los entre funções diferentes.

Esta função não tem valor de retorno.

```c
back_door_password("horse");
// => "Horse, please."
```
