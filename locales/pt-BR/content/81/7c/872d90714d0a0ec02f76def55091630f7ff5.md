# Instruções

Sua tarefa é descobrir se uma frase é um pangrama.

Um pangrama é uma frase que usa cada letra do alfabeto pelo menos uma vez.
Não há distinção entre maiúsculas e minúsculas, então não importa se a letra é minúscula (por exemplo, `k`) ou maiúscula (por exemplo, `K`).

Neste exercício, uma frase é um pangrama se contiver cada uma das 26 letras do alfabeto inglês.
