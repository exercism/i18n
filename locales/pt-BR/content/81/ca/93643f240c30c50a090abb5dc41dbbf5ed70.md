# Sobre

O tipo `Bool` é um dos blocos de construção da linguagem.
Ele serve para descrever se algo é verdadeiro ou falso, com os respectivos valores `True` e `False`.
O nome `Bool` é uma abreviação de Boolean, ou booleano, que é um campo da matemática relacionado ao pensamento lógico, nomeado em homenagem ao trabalho de George Boole.

## Operadores Boolean

Existem duas funções e dois operadores para manipular valores do tipo `Bool`.

- `not : Bool -> Bool`
  Essa função transforma `True` em `False` e `False` em `True`.
- `(&&) : Bool -> Bool -> Bool`
  Esse operador chamado "AND" recebe dois valores Boolean e retorna `True` se ambos forem `True`.
  Por exemplo, `True && True` retorna `True`, mas `True && False` retorna `False`.
- `(||) : Bool -> Bool -> Bool`
  Esse operador chamado "OR" recebe dois valores Boolean e retorna `True` se pelo menos um deles for `True`.
  Por exemplo, `False || False` retorna `False`, mas `True || False` retorna `True`.
- `xor : Bool -> Bool -> Bool`
  Essa função (não operador) chamada "XOR" recebe dois valores Boolean e retorna `True` se, e somente se, um for `True` e o outro for `False`.

Os operadores `&&` e `||` não têm a mesma prioridade.
A prioridade de `&&` é maior que a de `||`, assim como acontece com a multiplicação `*` e a adição `+`.
Consequentemente, a expressão `True || False && False` é equivalente a `True || (False && False)`, que é diferente de `(True || False) && False`.
Enquanto a primeira retorna `True`, a segunda retorna `False`.

## Ramificação condicional

Valores Boolean são extremamente úteis para criar ramificações no seu código que só são executadas se certas condições forem atendidas.
Em Elm, isso é feito com uma expressão `if-then-else`, usada da seguinte forma.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

O valor `someCondition` pode ser qualquer expressão que retorne um `Bool`.
Se esse valor Boolean for `True`, o código vai executar `doSomething`.
Caso contrário, ele é `False` e o código vai executar `doSomethingElse`.
O bloco `else` é obrigatório, ao contrário de algumas outras linguagens de programação.

Se você precisar encadear condições, basta encadear as expressões `if-then-else`.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
