# Apêndice de instruções

## Registradores

| Registrador | Uso          | Tipo     | Descrição                       |
| -------- | ------------ | ------- | ----------------------- |
| `$a0`    | entrada        | inteiro | número de linhas do triângulo |
| `$a1`    | entrada/saída | endereço | array de palavras          |
| `$v0`    | saída       | inteiro | número de palavras de saída  |
| `$t0-9`  | temporário    | qualquer     | para armazenamento temporário   |
