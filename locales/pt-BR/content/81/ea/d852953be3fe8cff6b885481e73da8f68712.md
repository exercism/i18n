# Sobre

Um laço `do-while` é uma alternativa ao laço `while`, com a única diferença de que um `do-while` roda pelo menos uma vez:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

Os casos em que se usa um laço `do-while` são muito raros, então o mais comum é usar o `while` normal no lugar.
