# Instruções

Você adora observar pássaros e acompanha quantos visitaram seu jardim nos últimos sete dias.

Você tem seis tarefas, todas envolvendo a quantidade de pássaros que visitaram seu jardim.

## 1. Verifique quais foram as contagens da semana passada

Para fins de comparação, você sempre mantém por perto uma cópia das contagens da semana passada, que foram: 0, 2, 5, 3, 7, 8 e 4. Implemente o método (_`static`_) `BirdCount.LastWeek()` que retorna as contagens da semana passada:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Verifique quantos pássaros visitaram hoje

Implemente o método `BirdCount.Today()` para retornar quantos pássaros visitaram seu jardim hoje. As contagens de pássaros estão ordenadas por dia, sendo o primeiro elemento a contagem do dia mais antigo e o último elemento a contagem de hoje.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. Incremente a contagem de hoje

Implemente o método `BirdCount.IncrementTodaysCount()` para incrementar a contagem de hoje:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. Verifique se houve algum dia sem visita de pássaros

Implemente o método `BirdCount.HasDayWithoutBirds()` que retorna `true` se houve algum dia em que zero pássaros visitaram o jardim; caso contrário, retorne `false`:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. Calcule o número de pássaros visitantes nos primeiros dias

Implemente o método `BirdCount.CountForFirstDays()` que retorna o número de pássaros que visitaram seu jardim desde o início da semana, mas limite a contagem ao número especificado de dias a partir do início da semana.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. Calcule o número de dias movimentados

Alguns dias são mais movimentados que outros. Um dia movimentado é aquele em que cinco ou mais pássaros visitaram seu jardim.
Implemente o método `BirdCount.BusyDays()` para retornar o número de dias movimentados:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
