# Introdução

## Números inteiros

Existem dois tipos diferentes de números em Elixir: números inteiros e números de ponto flutuante.

Números inteiros são números sem parte fracionária.

```elixir
integer = 3
# => 3
```

## Números de ponto flutuante

Números de ponto flutuante são números com um ou mais dígitos depois do separador decimal. Eles usam o formato de ponto flutuante de precisão dupla de 64 bits.

```elixir
float = 3.45
# => 3.45
```

### Trabalhando com números

Nos módulos [`Integer`][integer-functions] e [`Float`][float-functions], você encontra algumas funções úteis para trabalhar com esses tipos. Os operadores aritméticos básicos estão definidos no módulo [`Kernel`][kernel-arithmetic-operators].

### Conversão

Números inteiros e números de ponto flutuante podem ser misturados em uma única expressão aritmética. Usar um número de ponto flutuante em uma expressão garante que o resultado também será um número de ponto flutuante.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

No entanto, ao fazer uma divisão, o resultado sempre será um número de ponto flutuante, mesmo que você use apenas números inteiros.

```elixir
6 / 2
# => 3.0
```

Para converter um número de ponto flutuante em um número inteiro, você pode descartar a parte decimal com [`trunc/1`][trunc-1].
