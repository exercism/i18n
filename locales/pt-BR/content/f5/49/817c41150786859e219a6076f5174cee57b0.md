# Sobre

Em JavaScript, um set é uma estrutura de dados parecida com uma lista que só pode conter valores primitivos únicos e/ou referências de objeto.

Os sets precisam ser criados com o construtor de set; dá para inicializá-los com valores passando um array para o construtor.

```javascript
const emptySet = new Set();
const setWithInitialValues = new Set(['hello', 'world']);
```

## Adicionar e remover elementos

Um valor não pode ser adicionado a um set se for [estritamente igual][mdn-strict-equality] a qualquer um dos elementos do set.

```javascript
const set = new Set();
set.add(10);
set.add(10); // 10 is strictly equal to 10, so it can't be added again
set.size;
//=> 1;

set.has(10);
//=> true
set.delete(10);
//=> true; 10 was removed
set.delete(10);
//=> false; 10 is not in the set, so nothing happened

const obj = { color: 'magenta' };
const eerilySimilarObj = { color: 'magenta' };

set.add(obj);
set.add(eerilySimilarObj); // obj and eerilySimilarObj reference different objects, so they can both be added
set.size;
//=> 2

set.clear();
set.size;
//=> 0
```

## Converter entre sets e arrays

Arrays são convertidos em sets usando o construtor de set. Sets podem ser convertidos em arrays usando a [sintaxe de espalhamento][mdn-spread-syntax] ou `Array.from()`.

```javascript
const arrayWithDuplicates = [7, 3, 3, 9, 3];
const arrayWithoutDuplicates = [...new Set(arrayWithDuplicates)]; // [7, 3, 9]
const anotherArrayWithoutDuplicates = Array.from(new Set(arrayWithDuplicates)); // [7, 3, 9]
```

## Iteração

Um set é uma [coleção indexada por chave][mdn-keyed-collections], o que significa que seus elementos são indexados por uma chave e podem ser iterados na ordem de inserção. Como a _chave_ e o _valor_ de um elemento de um set são iguais, `Set.keys()` e `Set.values()` são intercambiáveis.

```javascript
const apples = ['Granny Smith', 'Honey Crisp', 'Royal Gala'];
const appleSet = new Set(apples);

for (let apple of appleSet.keys()) {
  console.log(apple);
}
// 'Granny Smith'
// 'Honey Crisp'
// 'Royal Gala'

for (let apple of appleSet.values()) {
  console.log(apple);
}
// 'Granny Smith'
// 'Honey Crisp'
// 'Royal Gala'

for (let apple of appleSet.entries()) {
  console.log(apple);
}
// ['Granny Smith', 'Granny Smith']
// ['Honey Crisp', 'Honey Crisp']
// ['Royal Gala', 'Royal Gala']
```

## Desempenho de busca vs. arrays

Quando se escolhe um set para armazenar uma coleção de dados (em vez de um array), em geral é porque os valores armazenados precisam ser únicos. No entanto, como também é possível garantir a unicidade com arrays, pode não ser óbvio o motivo disso.

A resposta curta é que os sets são otimizados para busca, e os arrays não. Os métodos de busca de array (como `Array.indexOf()`) têm tempo de execução que cresce linearmente com o tamanho do array; ou seja, quanto mais elementos o array tiver, mais tempo a busca leva. Já os métodos de busca de set têm tempo de execução constante, ou seja, ele permanece o mesmo independentemente do tamanho do set.

Na prática, porém, essa diferença de desempenho é insignificante, a menos que a coleção contenha uma quantidade enorme de dados.
