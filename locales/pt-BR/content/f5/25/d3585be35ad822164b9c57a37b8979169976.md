# Instruções

Neste exercício, você vai implementar um programa que determina o estado de uma partida de [jogo da velha][tic-tac-toe].
(_Talvez você também conheça o jogo como "noughts and crosses" ou "Xs and Os"._)

O jogo é disputado numa grade 3×3.
Os jogadores se revezam para colocar `X`s e `O`s na grade.
O jogo termina quando um jogador vence colocando três marcas em uma linha, coluna ou diagonal da grade, ou quando a grade inteira fica preenchida.

Neste exercício, vamos supor que o `X` começa.

Sua tarefa é determinar em qual estado um jogo está.

Há 3 estados possíveis:

- O jogo está **ongoing**.
- O jogo terminou em **draw**.
- O jogo terminou em **win**.

Se o tabuleiro dado for inválido, lance um erro apropriado.

Um tabuleiro é inválido quando atende às seguintes condições:

- O tabuleiro dado não pode ser alcançado quando os turnos acontecem na ordem correta (lembre-se de que o `X` começa).
- Houve jogadas depois que o jogo já tinha terminado.

## Exemplos

### Jogo em andamento

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Empate

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Vitória

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Inválido

#### Ordem de turnos incorreta

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Jogo continuado após a vitória

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
