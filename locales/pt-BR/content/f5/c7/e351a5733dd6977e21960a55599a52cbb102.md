# Leituras recomendadas

Como Smalltalk é amplamente usado, existe uma grande variedade de material de leitura.

## Para começar

* [Pharo Main Site](https://pharo.org/documentation):
tem uma grande quantidade de artigos e ajuda
* [Pharo Syntax Cheatsheet](https://files.pharo.org/media/pharoCheatSheet.pdf):
cabe em um cartão-postal
* [I Can Read C but not Smalltalk](https://www.eli.sdsu.edu/courses/spring01/cs635/readingSmalltalk.pdf): alguns passos simples para entender Smalltalk
* [Pharo By Example (9.0)](https://books.pharo.org/pharo-by-example9/):
um livro completo em pdf, com exemplos passo a passo
* [Learning OOP and TDD in Pharo](https://books.pharo.org/learning-oop/):
apresenta mais técnicas e conceitos de programação
* [Discord](https://discord.gg/QewZMZa) tem um
fórum on-line ativo de discussões sobre Pharo (use o link de convite no topo da [Community Page](https://pharo.org/community))
* [Pharo Mooc](https://mooc.pharo.org/):
oferece uma série de cursos completos de programação e vídeos

## Mais avançado

* [Deep Into Pharo](https://books.pharo.org/deep-into-pharo/):
leva você por tópicos mais avançados, como gráficos e análise sintática
* [Pharo with style](https://github.com/SquareBracketAssociates/Booklet-PharoWithStyle):
é o guia de formatação e design ao estilo Pharo
* [Smalltalk with style](http://sdmeta.gforge.inria.fr/FreeBooks/WithStyle/SmalltalkWithStyle.pdf):
é um guia mais amplo de formatação e design em Smalltalk
* [Enterprise Pharo - Web Perspective](http://books.pharo.org/enterprise-pharo/):
aborda aplicações web, http e dados
