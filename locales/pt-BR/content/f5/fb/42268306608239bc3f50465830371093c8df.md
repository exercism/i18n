# Introdução

## Recursão

A capacidade de algo ser definido em termos de si mesmo é chamada de recursão. Na Gleam, a recursão aparece mais comumente em funções recursivas, que são funções que chamam a si mesmas.

Uma função recursiva precisa ter pelo menos um _caso base_ e pelo menos um _caso recursivo_. Um _caso base_ retorna um valor sem chamar a função de novo. Um _caso recursivo_ chama a função de novo, modificando a entrada para que ela em algum momento corresponda ao caso base.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

A Gleam não tem sintaxe especial para laços, então toda repetição é feita com recursão.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

A Gleam também tem tipos personalizados recursivos. Em um tipo personalizado recursivo, uma ou mais variantes fazem referência ao próprio tipo nos dados que contêm.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
