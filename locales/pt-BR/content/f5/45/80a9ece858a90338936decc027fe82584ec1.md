# Classes genéricas

```sather
class LOST_BOX{T} is
   attr item : T;
   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;
end;
```

## O que é o parâmetro

`T` representa um tipo fornecido no ponto de uso. O Sather constrói uma classe
distinta para cada combinação realmente usada, no momento em que o programa é
compilado. Ou seja:

- `LOST_BOX{STR}` e `LOST_BOX{INT}` são tipos sem relação entre si;
- não há verificação em tempo de execução, nem boxing, nem conversão;
- um erro na classe aparece para cada tipo com que ela é usada.

Essa é a mesma abordagem dos templates do C++ ou dos genéricos do Rust, e
diferente dos genéricos do Java, em que o tipo é apagado e tudo é, na verdade,
um objeto.

## Parâmetros com restrição

Um `T` sem restrição pode ser atribuído, passado e retornado, e nada mais,
porque não se sabe nada além disso sobre ele. Para chamar rotinas nele, diga com
o que ele deve estar em conformidade:

```sather
class LOST_BOX{T < $STR} is
   describe : STR is return "a box holding " + item.str; end;
end;
```

`T < $STR` exige que `T` esteja em conformidade com `$STR` e, em troca, permite
chamar `item.str`. Tudo o que um `T` sem restrição não consegue fazer pode ser
liberado com uma restrição.

Sem a restrição, `item.str` não vai compilar, e a mensagem vai apontar a linha
dentro da classe genérica, não a linha que a usou.

## Rotinas genéricas?

Não existem. Só as classes recebem parâmetros. Uma rotina que precise funcionar
com vários tipos ou fica dentro de uma classe genérica, ou recebe um tipo
abstrato como `$STR`.

## Como escolher entre as duas

| | classe genérica | classe abstrata |
| --- | --- | --- |
| decidido | em tempo de compilação | em tempo de execução |
| armazena | um tipo por instanciação | qualquer tipo em conformidade |
| custo | nenhum | um despacho |

`ARRAY{$ACT}` usa as duas coisas: é genérica no tipo do elemento e abstrata no
que esse elemento pode ser.

Recorra a uma classe genérica quando o tipo for o mesmo do início ao fim e quem
usa a classe souber disso. Recorra a uma classe abstrata quando vários tipos
precisarem coexistir em uma mesma coleção.
