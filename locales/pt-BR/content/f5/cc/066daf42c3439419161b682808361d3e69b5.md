# Escrevendo o código

Escreva seu código em `<exercise_name>.zig`.
Alguns exercícios vêm com assinaturas já prontas para construções específicas do Zig, como [constantes][constants], [funções][functions], [importações][imports], [structs][structs] e [potencialmente muitas outras][et-cetera]!

Essas assinaturas prontas existem para ajudar você a completar os exercícios, oferecendo um ponto de partida claro.
Mas não é obrigatório começar por elas.
Principalmente porque qualquer código que passe nos testes é uma solução perfeitamente aceitável.

## Rodando os testes

Para rodar os testes, é só usar o seguinte comando:

```bash
zig test test_exercise_name.zig
```

substituindo `exercise_name` pelo nome do exercício.
O comando acima precisa ser rodado no diretório raiz do exercício, já que o arquivo de testes dele fica nesse mesmo lugar.
Além disso, todos os testes de qualquer exercício já vêm habilitados por padrão, e nenhum deles pode ser ignorado.

Como todos os testes seguem essas regras, você vai precisar [comentar][comments] os testes que não estão passando se quiser ir um por um.
Comentar um teste é tão simples quanto começar cada linha com `//`.
Por outro lado, quando você tiver certeza de que sua solução consegue passar nos testes, é só descomentar esses testes para ver se ela passa.
