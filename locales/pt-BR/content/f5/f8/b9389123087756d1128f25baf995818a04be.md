# 24 Pull Requests para o Exercism: Edição Ruby!

Estamos recebendo contribuições para o projeto.

Procure os seguintes rótulos na nossa lista de issues:

* first-timers only
* good first patch
* bug
* enhancement

Ou notou algo em que poderia contribuir? A documentação não está grande coisa? Falta alguma coisa? Enviou e revisou exercícios no Exercism e notou algo de que não gostou? Crie um pull request!

Confira a documentação [Como se envolver em uma trilha](https://github.com/exercism/docs/blob/master/contributing-to-language-tracks/README.md#getting-involved-in-an-exercism-language-track) e algumas [ideias do que estamos procurando](http://exercism.io/languages/ruby/todo) para os exercícios que precisam ser implementados.

Estamos à disposição para responder a perguntas no nosso fórum [building-exercism].
