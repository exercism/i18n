# Instruções

Neste exercício, você vai implementar um conjunto parcial de funções utilitárias para ajudar quem desenvolve a limpar nomes de identificadores.

Nas 5 tarefas, você vai construir aos poucos a função `clean`.
Um identificador válido é formado por zero ou mais letras e sublinhados.

Se uma string vazia for passada para a função `clean`, uma string vazia deve ser retornada.

## 1. Substitua espaços por sublinhados

Implemente uma função `clean1` para substituir qualquer espaço por sublinhados. Isso vale também para espaços no início e no fim.

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. Substitua caracteres de controle pela string em maiúsculas "[CTRL]"

Implemente `clean2` para fazer tudo o que a função anterior faz e substituir caracteres de controle comuns (\n, \t e \r ) pela string `"[CTRL]"`.

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. Converta kebab-case em camelCase

Implemente `clean3` para fazer tudo o que a função anterior faz e converter kebab-case em camelCase.

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. Omita dígitos

Implemente `clean4` para fazer tudo o que a função anterior faz e omitir todos os dígitos.

```elm
clean4 "123"
    --> ""
```

## 5. Omita letras gregas minúsculas

Por fim, implemente `clean` para fazer tudo o que a função anterior faz e omitir quaisquer letras gregas no intervalo de 'α' a 'ω'.

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
