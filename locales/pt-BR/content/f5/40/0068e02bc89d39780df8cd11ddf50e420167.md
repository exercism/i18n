# Dicas

## Geral

- Cada operação retorna um buffer atualizado em vez de modificar o original.
  Isso vale também para `read`, cujo resultado bem-sucedido contém tanto `value` quanto `updated_buffer`.

- Use atualizações de record como `{ ..buffer, length: 0 }` para preservar os demais campos.

- `List.replace` retorna um `Try` cujo record bem-sucedido contém a lista atualizada em seu campo `list`.
