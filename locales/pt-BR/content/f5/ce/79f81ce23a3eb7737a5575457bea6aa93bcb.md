# Introdução

O tipo `char` do C# é uma quantidade de 16 bits que representa os menores componentes endereçáveis de um texto.
Vários `char`s podem formar uma string como `"word"`, ou podem ser
processados de forma independente. Seus literais usam aspas simples, por exemplo `'A'`.

Os `char`s do C# são compatíveis com a codificação Unicode UTF-16, então, além do conjunto de caracteres latinos,
praticamente todos os sistemas de escrita usados no mundo podem ser representados,
por exemplo a letra grega `'β'`.

Existem muitos métodos da biblioteca padrão para inspecionar e manipular `char`s. Eles
podem ser encontrados como métodos estáticos da classe `System.Char`.
