# Sobre

Um *heap* é uma coleção que sempre sabe qual é o seu menor (ou maior)
item e permite removê-lo rapidamente: é a implementação natural de uma
*fila de prioridade*. Os heaps ficam no vocabulário [`heaps`][heaps].

`<min-heap>` cria um heap vazio cuja menor chave sai primeiro;
`<max-heap>` entrega o maior primeiro. Cada item é um *valor* guardado
sob uma *chave*, e a chave é a prioridade pela qual o Factor ordena:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Um heap é *mutável*: `heap-push` e `heap-pop` o modificam no lugar.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` lê a frente sem removê-la; `heap-pop` a remove e a
retorna; `heap-pop-all` esvazia o heap em uma lista de associações de
pares `{ key value }` em ordem de prioridade.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

Inserir custa `O(log n)` e ler a frente custa `O(1)`, então repetir
"pegar o item mais urgente e depois adicionar mais" continua rápido
mesmo para uma fila grande. A implementação é um heap binário guardado
em um array que cresce; a chave pode ser qualquer valor ordenável
(números, strings, …).

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
