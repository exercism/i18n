# Instruções

Neste exercício, você vai construir o tratamento de erros de uma calculadora simples.

O objetivo é ter uma calculadora funcionando que retorna uma string com o seguinte padrão: `16 + 51 = 67`, quando recebe os argumentos `16`, `51` e `+`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. Trate o código que pode gerar erros dentro do método `calculate`

O principal método a ser implementado nesta tarefa será o método de classe `SimpleCalculator.calculate()`.
Ele recebe três argumentos.
Os dois primeiros argumentos são números sobre os quais uma operação será realizada.
O terceiro argumento é do tipo string e, para este exercício, é necessário implementar as seguintes operações:

- adição usando a string `+`
- multiplicação usando a string `*`
- divisão usando a string `/`

## 2. Trate operações ilegais

Atualize o método `SimpleCalculator.calculate()` para lançar uma exceção `UnsupportedOperation` para símbolos de operação desconhecidos.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
Neste exercício, espera-se que você defina a exceção `UnsupportedOperation` para um escopo específico.
~~~~

## 3. Trate argumentos inválidos

Atualize o método `SimpleCalculator.calculate()` para lançar uma exceção `ArgumentError` para tipos de argumento inválidos.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. Trate exceções DivideByZero

Atualize o método `SimpleCalculator.calculate()` para tratar exceções `ZeroDivisionError`.
O código de tratamento deve retornar a string com o conteúdo `Division by zero is not allowed.`.
Qualquer outra exceção não deve ser tratada pelo método `SimpleCalculator.calculate()`.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
