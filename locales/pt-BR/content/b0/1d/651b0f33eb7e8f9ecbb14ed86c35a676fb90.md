# prefira constante no nível superior

Considere transformar o número `GIGASECOND` em uma constante:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

Somente funções, classes e constantes marcadas com `export` ficam visíveis e acessíveis de fora. Em geral, faz sentido dar um nome a [números mágicos](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29), o que melhora a manutenibilidade. Essas constantes podem ficar no mesmo arquivo sem serem expostas a outro código.
