# Instruções

Implemente uma função usando lógica proposicional para  
recriar as seguintes propriedades:

1. A & B == (A' | B')' (DeMorgan's Law)
2. [A -> (A -> B)] -> (A -> B)
3. A & (B' -> A') -> B

A função deve retornar os três teoremas escritos em notação Z3.  
Use a função `prove()` para confirmar a exatidão dos seus teoremas.  
Retorne os três teoremas, em ordem, no final da função.
