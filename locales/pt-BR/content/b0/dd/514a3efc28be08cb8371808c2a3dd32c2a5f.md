# Instruções

Neste exercício, você vai escrever um pouco de código para ajudar a se preparar para comprar um veículo.

Você tem três tarefas: uma para determinar se vai precisar tirar uma carteira de motorista, uma para ajudar a escolher entre dois veículos e uma para estimar o preço aceitável de um veículo usado.

## 1. Determine se você vai precisar de carteira de motorista

Alguns tipos de veículo exigem carteira de motorista para serem conduzidos.
Considere que apenas os tipos `'car'` e `'truck'` exigem carteira, todo o resto pode ser conduzido sem carteira.

Implemente a função `needsLicense(kind)`, que recebe o tipo de veículo e retorna um Boolean indicando se você precisa de carteira de motorista para aquele tipo de veículo.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. Escolha entre dois possíveis veículos para comprar

Você avalia as opções de veículos disponíveis.
Você consegue reduzir a duas opções, mas precisa de ajuda para tomar a decisão final.
Para isso, implemente a função `chooseVehicle(option1, option2)`, que recebe dois veículos como argumentos e retorna uma decisão que inclui a opção que vem primeiro na ordem alfabética.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. Calcule uma estimativa do preço de um veículo usado

Agora que você tomou sua decisão, quer garantir que vai pagar um preço justo na concessionária.
Como você quer comprar um veículo usado, o preço depende da idade do veículo.
Para uma estimativa aproximada, considere que, se o veículo tiver menos de 3 anos, ele custa 80% do preço original que tinha quando era novo.
Se tiver mais de 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos, mas não mais de 10 anos, custa 70% do preço original.

Implemente a função `calculateResellPrice(originalPrice, age)`, que aplica essa lógica usando `if`, `else if` e `else` (existem outras formas, caso você queira praticar).
Ela recebe o preço original e a idade do veículo como argumentos e retorna o preço estimado na concessionária.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
