# Introdução

## Laços `while`

Com um laço `while`, você pode executar código repetidamente enquanto uma determinada condição for satisfeita.
Ele é escrito com a palavra-chave `while`, seguida de uma condição entre parênteses redondos e de um bloco de código que contém o _corpo_ do laço, entre chaves.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

O JavaScript também tem o laço do-while.
Aqui, a condição é verificada depois que o corpo do laço é executado.
Isso é útil quando a condição depende de avaliações feitas dentro do corpo.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Dentro do corpo de um laço, você pode usar a palavra-chave `break` para encerrar por completo a execução do laço.
Já a palavra-chave `continue` interrompe apenas a execução da iteração atual e passa para a próxima.
Com `continue`, muitas vezes você consegue evitar envolver grandes partes do corpo do laço em uma condicional.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## Condicionais `switch`

Além da condicional `if`, o JavaScript também tem a condicional `switch` para executar lógica de forma condicional.
Ela é usada quando uma única variável precisa ser comparada com várias alternativas.
A comparação é feita verificando a igualdade estrita (`===`), veja [conceito de comparação][concept-comparison].
Para uma variável `x`, a condicional `switch` em JavaScript tem a seguinte sintaxe.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

O caso `default` é opcional e serve para quando você quer executar algum código se nenhuma das outras opções corresponder à variável.

As instruções `break` acima são necessárias porque, por padrão, todos os casos são "fallthrough" no JavaScript.
Isso significa que, sem nenhuma instrução `break`, todo o código dos casos abaixo da primeira opção correspondente seria executado, mesmo que `x` não correspondesse a essas opções.
Esse comportamento de "fallthrough por padrão" é uma armadilha comum ao usar `switch` em JavaScript.
Dentro de uma função, `return` também pode ser usado no lugar de `break` para evitar esse problema.
