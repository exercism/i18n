# Sobre

Go tem tipos numéricos básicos que representam conjuntos de valores inteiros ou de ponto flutuante.
Existem tipos diferentes dependendo do tamanho do valor que você precisa e da arquitetura do computador onde a aplicação roda (por exemplo, 32 bits e 64 bits).

Este conceito vai focar em dois tipos de número:

- `int`: por exemplo, `0`, `255`, `2147483647`.
   Um inteiro com sinal de pelo menos 32 bits (faixa de valores: -2147483648 a 2147483647).
   Mas isso depende da arquitetura do sistema.
   A maioria dos computadores modernos é de 64 bits, então `int` terá 64 bits (faixa de valores: -9223372036854775808 a 9223372036854775807).

- `float64`: por exemplo, `0.0`, `3.14`.
   Contém o conjunto de todos os números de ponto flutuante de 64 bits.

Para uma lista completa dos tipos numéricos disponíveis e mais detalhes, veja os seguintes recursos:

- [Declarações de tipos embutidos do Go][go-builtins]
- [Digital Ocean - Entendendo tipos de dados em Go][do-understanding-types]
- [Arden Labs - Entendendo tipos em Go][arden-understanding-types]

Go dá suporte ao conjunto padrão de operadores aritméticos: `+`, `-`, `*`, `/` e `%` (resto, não módulo).

Em Go, atribuir um valor entre tipos diferentes exige conversão explícita.
Por exemplo, para converter um `int` em um `float64`, você precisaria fazer o seguinte:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
