# Dicas

## Geral

- Em uma string codificada em ASCII, todos os caracteres ocupam 1 byte na memória.
- Você precisa usar `[]` para desreferenciar posições de memória.
- O valor ASCII de uma letra maiúscula é 32 a menos que o valor ASCII da letra minúscula equivalente.

## 1. Obtenha a primeira letra de uma frase

- Em uma string codificada em ASCII, todos os caracteres ocupam 1 byte na memória.
- Você precisa usar `[]` para desreferenciar posições de memória.
- O valor ASCII de uma letra maiúscula é 32 a menos que o valor ASCII da letra minúscula equivalente.
- Valores de 1 byte são retornados em `al`.

## 2. Deixe uma palavra com a inicial maiúscula

- Em uma string codificada em ASCII, todos os caracteres ocupam 1 byte na memória.
- Você precisa usar `[]` para desreferenciar posições de memória.
- O valor ASCII de uma letra maiúscula é 32 a menos que o valor ASCII da letra minúscula equivalente.
- Capitalização significa ter um único caractere _maiúsculo_, seguido de caracteres _minúsculos_.
- Só valores entre 'a' e 'z' são letras minúsculas, e só valores entre 'A' e 'Z' são letras maiúsculas.
- Então, primeiro você precisa extrair a primeira letra e convertê-la para maiúscula, caso ela esteja em minúscula.
- Depois, você precisa percorrer o resto da string: todo caractere após o primeiro deve ser convertido para minúscula, caso seja uma letra maiúscula, ou deixado como está, caso contrário.
- A string termina quando `'\0'` (o caractere NUL) é encontrado.
- Você pode usar `lodsb` para carregar em `al` um byte da posição de memória em `rsi`, alterando `rsi` em 1.
- Você pode usar `stosb` para armazenar, na posição de memória em `rdi`, um byte carregado em `al`, alterando `rdi` em 1.

## 3. Obtenha a última letra de uma frase

- Em uma string codificada em ASCII, todos os caracteres ocupam 1 byte na memória.
- Você precisa usar `[]` para desreferenciar posições de memória.
- O valor ASCII de uma letra maiúscula é 32 a menos que o valor ASCII da letra minúscula equivalente.
- Você precisa iterar sobre a string para encontrar a última letra.
- Só valores entre 'a' e 'z' são letras minúsculas, e só valores entre 'A' e 'Z' são letras maiúsculas.
- Valores de 1 byte são retornados em `al`.

## 4. Seja educado

- Em uma string codificada em ASCII, todos os caracteres ocupam 1 byte na memória.
- Você precisa usar `[]` para desreferenciar posições de memória.
- O valor ASCII de uma letra maiúscula é 32 a menos que o valor ASCII da letra minúscula equivalente.
- Reutilize uma função existente para deixar a palavra com a inicial maiúscula.
- Você pode usar `movsb` para copiar um byte do endereço de memória em `rsi` para o endereço de memória em `rdi`, alterando tanto `rsi` quanto `rdi` em 1.
- Você pode definir uma string inicializada em _section .rodata_ ou _section .data_.
- Você precisa usar `rel` para calcular um endereço relativo.
- Para um array declarado com o rótulo `arr`, `$ - arr` seria o tamanho total de `arr` em bytes, se usado logo após a declaração do array.
- Você pode usar `rep` para repetir uma instrução de string, como `movsb`, um número de vezes especificado por `rcx`.
- A string deve terminar com `'\0'` (o caractere NUL) como terminador.
- Lembre-se de que caracteres especiais com barra invertida (como `'\0'`) devem ser definidos entre crases (`` ` ``) ou usando seu valor decimal (que é `0` para NUL).
