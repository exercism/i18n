# Anexo às instruções

## Registradores

| Registrador | Uso          | Tipo    | Descrição                                  |
| ----------- | ------------ | ------- | ------------------------------------------ |
| `$a0`       | entrada      | endereço | string de pergunta terminada em nulo      |
| `$v0`       | saída        | inteiro | resultado, 0 se a pergunta não for válida  |
| `$t0-9`     | temporário   | qualquer | para armazenamento temporário             |
