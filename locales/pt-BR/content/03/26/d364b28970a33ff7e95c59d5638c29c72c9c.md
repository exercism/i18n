# Sobre

Lean é uma linguagem de programação funcional pura, estrita, de propósito geral e com tipos dependentes, que conta com um assistente de provas integrado.
Ela é usada para escrever programas junto com garantias de correção verificadas por máquina e é amplamente aplicada na verificação formal de software e matemática.

**Tipos dependentes** significa que os tipos podem depender de valores.
Isso permite codificar especificações e restrições diretamente no sistema de tipos, tornando estados inválidos efetivamente _irrepresentáveis_.

Lean se baseia no princípio de proposições como tipos, em que proposições lógicas são representadas como tipos e provas são programas que habitam esses tipos.
Todo valor de um tipo que codifica uma especificação precisa ser construído de um jeito que _prove_ que ele é válido.

**Avaliação estrita** significa que os argumentos de uma função são avaliados imediatamente, o que resulta em uma ordem de avaliação determinística.
Isso simplifica o raciocínio sobre o comportamento e o desempenho do programa.
Lean suporta avaliação preguiçosa, mas apenas de forma explícita.

**Puramente funcional** significa que as funções não alteram estado nem têm efeitos colaterais ocultos.
Uma função pura sempre retorna o mesmo valor para a mesma entrada; os efeitos precisam ser explícitos e controlados.

Lean é compilada antecipadamente para código nativo.
Seu sistema de execução conta com coleta de lixo sem rastreamento e atualizações eficientes no local para dados não compartilhados.
