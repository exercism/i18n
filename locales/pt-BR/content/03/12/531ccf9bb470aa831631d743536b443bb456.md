## General

- Classificar uma lista de mãos de pôquer pode ser encarado como um problema de ordenação.
- O Rust fornece o método [sort](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.sort) para `Vec<T> where T: Ord`.
- Os [tipos `Ord`](https://doc.rust-lang.org/std/cmp/trait.Ord.html) formam uma [ordem total](https://en.wikipedia.org/wiki/Total_order): exatamente uma entre `a < b`, `a == b` e `a > b` deve ser verdadeira.
- As mãos de pôquer não seguem uma ordem total: é possível que duas mãos sejam diferentes, mas tenham a mesma ordem de classificação. Exemplo: `"3S 4S 5D 6H JH"`, `"3H 4H 5C 6C JD"`.
- O Rust fornece a [trait `PartialOrd`](https://doc.rust-lang.org/std/cmp/trait.PartialOrd.html) para lidar com o caso de coisas que podem ser ordenadas, mas que não têm uma ordem total. Porém, o Rust não fornece um método `sort` padrão para `Vec<T> where T: PartialOrd`. O jeito padrão de ordenar um vetor nesse caso é `your_vec.sort_by(|a, b| a.partial_cmp(b).unwrap_or(Ordering::{Less|Equal|Greater}));`, dependendo do que você precisa.
- Você pode considerar implementar um tipo que representa uma mão de pôquer e que implementa `PartialOrd`.
