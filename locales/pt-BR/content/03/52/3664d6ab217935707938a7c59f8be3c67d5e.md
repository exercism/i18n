# Dicas

## Geral

## 1. Confira quais foram as contagens na semana passada

- Retorne o elemento _penúltimo_ do array.

## 2. Confira quantos pássaros visitaram ontem

- Como os dados são um array de arrays, você vai precisar indexar uma vez para obter o array da semana correta e depois indexar de novo para obter o dia desejado.
- "Hoje" é o último elemento do array da semana.

## 3. Calcule o número total de pássaros que visitaram

- É possível calcular a soma de um array usando o filtro [add][manual-add].
  Você viu essa expressão no conceito Basics e no exercício Shopping.

## 4. Calcule o número de dias movimentados

- Você vai precisar _selecionar_ os dias com contagem maior ou igual a 5 e depois retornar o tamanho do array resultante.

## 5. Confira se houve um dia sem pássaros visitantes

- A versão de um argumento do filtro [any][manual-any] será a mais adequada.

[manual-add]: https://jqlang.org/manual/#add
[manual-any]: https://jqlang.org/manual/#any
