# Intervalos

[Intervalos][range] representam um intervalo entre dois valores.
Os tipos mais comuns que suportam intervalos são `Int`, `Char` e `String`.
Eles podem ser usados para muitas coisas, como criar uma coleção rapidamente, fatiar strings, verificar se um valor está em um intervalo e iteração.
Eles são criados com o operador de intervalo `..` ou `...` (inclusivo e exclusivo, respectivamente).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

O motivo de existirem dois operadores de intervalo é permitir criar intervalos que incluem ou excluem o valor final, o que pode ser útil quando, por exemplo, trabalhamos com índices começando em zero.

Intervalos também podem ser criados com o inicializador `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Ao criar um intervalo em Crystal com os operadores de intervalo `..` ou `...` e querer chamar um método nele, você precisa envolver o intervalo entre parênteses.
Isso acontece porque, caso contrário, o método seria chamado no segundo argumento do operador de intervalo.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Obtendo substrings

Quando você quer fatiar uma string, pode usar o operador de intervalo para obter uma substring.
Ou seja, criando um intervalo com os índices inicial e final da substring.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Você também pode usar índices negativos para obter a substring a partir do fim da string.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Métodos de intervalo

Intervalos têm um conjunto de métodos que podem ser usados para trabalhar com eles.
Por exemplo, esses métodos podem ser usados para obter a soma de todos os valores do intervalo ou verificar se o intervalo inclui um valor.

| Método                  | Descrição                                                             | Exemplo                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Retorna a soma de todos os valores do intervalo                          | `(1..5).sum # => 15`            |
| [`size`][size]          | Retorna o tamanho do intervalo                                           | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Retorna `true` se o intervalo inclui o valor dado, caso contrário `false` | `(1..5).includes?(3) # => true` |

## Intervalos sem fim e sem início

Um intervalo pode ser sem fim e sem início.
O intervalo sem fim ou sem início tem seu valor inicial ou final como `nil`, mas o `nil` pode ser omitido ao definir o intervalo.

Usar intervalos sem início e sem fim é útil quando você quer, por exemplo, fatiar uma string do começo ou até o fim.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Se não for usado em uma coleção, o intervalo sem fim pode gerar uma sequência sem fim, caso não seja usado com cautela.
~~~~

## Intervalos de Char

Chars podem ser usados em intervalos e permitem obter um intervalo de caracteres entre dois caracteres.
Por exemplo, isso pode ser útil quando você quer obter o alfabeto.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Intervalos de String

Strings também podem ser usadas em intervalos, permitindo obter um intervalo de strings entre duas strings.
Mas o comportamento é um pouco diferente do de `Char` quando vários caracteres são usados em um intervalo de strings.
O comportamento pode ficar confuso ao criar intervalos de strings mais complexos, então tenha cuidado.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## Objetos personalizados em intervalos

~~~~exercism/advanced
Crystal permite usar objetos personalizados em intervalos.
O requisito para isso é que o objeto implemente o seguinte:

- incluir o módulo `Comparable`
- o método `succ`
- o método `<=>`

Esses métodos fazem com que o intervalo possa iterar sobre o objeto e comparar os objetos do intervalo.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
