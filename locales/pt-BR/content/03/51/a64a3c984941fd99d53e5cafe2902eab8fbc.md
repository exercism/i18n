# Introdução

Tuplas são uma forma simples de agrupar um conjunto fixo de dados de tipos arbitrários.
As tuplas podem ter um número arbitrário de elementos.
Você pode acessar os elementos por desestruturação.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}

fn main() {
    let (x, y, z) = (500, 6, true);

    if y == 6 {
        println!("y is 6!");
    }
}
