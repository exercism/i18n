# Complemento das instruções

## Dicas

Para este exercício, o seguinte recurso do F# é útil:

- [Sequences](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/sequences) são avaliadas de forma preguiçosa. Elas permitem que você trabalhe com uma sequência infinita de valores.

Observação: para ajudar a acelerar o cálculo, evite verificar números que você já sabe de antemão que nunca serão primos. Para mais informações, veja o [Crivo de Eratóstenes](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes).
