# Instruções

O clássico exercício introdutório. Basta dizer "Hello, World!".

["Hello, World!"](http://en.wikipedia.org/wiki/%22Hello,_world!%22_program) é o tradicional primeiro programa para quem está começando a programar em uma nova linguagem ou ambiente.

Os objetivos são simples:

- Modifique o código fornecido para que ele produza a string "Hello, World!".
- Rode a suíte de testes e verifique se ela passa.
- Envie sua solução e confira no site.

Se tudo correr bem, é hora de partir para o seu primeiro exercício de verdade.
