# Normalizações do representer

O [representer de F#][representer] aplica as seguintes normalizações:

## Remover comentários

Todos os comentários são removidos.

### Antes

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### Depois

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## Remover declarações de importação

Todas as declarações de importação são removidas.

### Antes

```fsharp
module Fake

open System
open System.IO

let message = "Hi"
```

### Depois

```fsharp
module Fake

let message = "Hi"
```

## Formatar o código

O código é formatado com a [biblioteca fantomas][fantomas].
Ela formata o código de acordo com o guia de estilo do F#.
A lista completa das transformações aplicadas pelo fantomas está [aqui][fantomas-formatting].

### Antes

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### Depois

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## Normalizar identificadores

Os identificadores são normalizados para um valor de substituição.

### Antes

```fsharp
module Fake

let foo x = x + 1
```

### Depois

```fsharp
module PLACEHOLDER_1

let PLACEHOLDER_3 PLACEHOLDER_2 = PLACEHOLDER_2 + 1
```
