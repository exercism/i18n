# Instruções

Ellen está fazendo um jogo em que o jogador precisa enfrentar aliens.
Ela acabou de aprender sobre Programação Orientada a Objetos (POO) e está ansiosa para aproveitar o que o uso de `classes` pode oferecer ao seu programa.

Para a alegria de Ellen, você se ofereceu para ajudar, e ela te deu a tarefa de programar os aliens que o jogador precisa enfrentar.


## 1. Crie a classe `Alien`

Defina a classe `Alien` com um construtor que aceita dois parâmetros `int`, `x` e `y`, colocando-os nas variáveis membro `x_coordinate` e `y_coordinate`.
Todo alien também começa com um nível de saúde de `3`, então a variável membro `health` também precisa ser inicializada.

`health` deve ser uma variável membro privada.
Para permitir que outras partes do programa leiam a informação de saúde, Ellen quer um método `public` `get_health()` que retorna um `int`.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

Agora, cada alien deve ser capaz de acompanhar internamente sua própria posição e saúde.

## 2. A função `hit`

Ellen gostaria que a `class` Alien tivesse um método `hit` que decrementa a saúde de um objeto alien em `1` quando chamado.
Assim, ela pode simplesmente chamar `some_alien_instance.hit()` em vez de ter que alterar manualmente a saúde de um alien.
Certifique-se de que os pontos de saúde não caiam abaixo de zero.
A função deve retornar `true`.
Ellen quer introduzir escudos mais para frente, que então retornariam `false` se o escudo estiver ativo.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. A função `is_alive`

Você percebe que, se a saúde continuar diminuindo, em algum momento ela provavelmente vai chegar a `0`.
Seria uma boa ideia adicionar um método `is_alive` que Ellen possa chamar rapidamente para verificar se o alien está... bem... vivo. 😉
`some_alien_instance.is_alive()` deve retornar um Boolean.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. A função `teleport`

No jogo de Ellen, os aliens podem se teletransportar!
Você vai precisar escrever um método `teleport` que recebe os valores `x_new` e `y_new` e muda as coordenadas do alien de acordo.
Por enquanto, a função deve retornar `true`.
Ellen quer adicionar bombas que bloqueiam o teletransporte em fases posteriores, que então retornariam `false` para tentativas de teletransporte malsucedidas.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. A função `collision_detection`

Se os aliens podem ser atingidos por algo, então eles precisam ser capazes de detectar quando uma colisão dessas pode acontecer.
Ellen precisa saber se dois aliens ocupam as mesmas coordenadas.
A função `collision_detection()` recebe outro objeto alien como argumento e retorna um `bool`.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
