# Introdução

Em Go, funções são valores de primeira classe.
Isso significa que você pode fazer com funções as mesmas coisas que faz com qualquer outro valor: atribuir funções a variáveis, passá-las como argumentos para outras funções ou até retornar funções de outras funções.

Abaixo, criamos duas funções, `engGreeting` e `espGreeting`, e as atribuímos à variável `greeting`:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Valores de função permitem parametrizar funções não só com dados, mas também com comportamento.
No exemplo a seguir, passamos comportamento para a função `dialog` por meio do parâmetro `greetingFunc`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

O valor de uma variável de tipo função não inicializada é `nil`.
Por isso, chamar um valor de função `nil` causa um panic.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Valores de função podem ser comparados com `nil`.
Isso pode ser útil para evitar panics desnecessários no programa.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Tipos de função

Usar valores de função é possível graças aos tipos de função em Go.
Um tipo de função denota o conjunto de todas as funções com a mesma sequência de tipos de parâmetro e a mesma sequência de tipos de resultado.
Tipos definidos pelo usuário podem ser declarados com base em tipos de função.
Por exemplo, a função `dialog` dos exemplos anteriores pode ser atualizada assim:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Funções anônimas

Outra ferramenta poderosa que existe graças ao suporte a funções de primeira classe são as funções anônimas.
Funções anônimas são definidas no ponto em que são usadas, sem um nome depois da palavra-chave `func`.
Essas funções têm acesso às variáveis da função que as envolve.

Por exemplo:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Uma chamada a `fib` declara as variáveis `n1` e `n2` e retorna uma função anônima que, por sua vez, muda os valores dessas variáveis a cada chamada da função.
A enésima chamada da função anônima retorna o enésimo número da sequência de Fibonacci a partir de 0. A função anônima interna tem acesso às variáveis locais (`n1` e `n2`) da função `fib` que a envolve.
É uma ótima forma de fazer valores de função manterem estado entre chamadas.
Dizemos que a função anônima é um closure das variáveis `n1` e `n2`. [Closures][closure] são muito usados em programação, e você pode encontrar outras linguagens que os suportam.
