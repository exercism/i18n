# Introdução

Vimos no conceito `Vectors` que um vetor pode ser usado em uma expressão condicional, gerando um vetor lógico.
Isso, por sua vez, pode ser usado em funções como `all()` e `any()`.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

A técnica é muito mais poderosa do que isso.

## Subconjuntos de vetores

É possível extrair elementos selecionados de um vetor com um número de índice ou um vetor de índices:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

Como alternativa, use um vetor lógico para filtrar o vetor original, retornando um subconjunto de entradas correspondentes ao valor `TRUE`:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

A partir daí, é um pequeno passo para gerar o vetor Boolean com uma expressão condicional:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## Encontrando índices

A função `which()` recebe um argumento Boolean e retorna um vetor de índices que resultam em `TRUE`.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## Verificando se uma entrada existe

As seções anteriores tratavam de encontrar entradas que correspondem a algum critério.

Se você só precisa saber se o vetor contém um elemento específico, basta usar o operador `%in%`.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

Isso é funcionalmente equivalente ao código a seguir, mas bem mais conveniente:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
