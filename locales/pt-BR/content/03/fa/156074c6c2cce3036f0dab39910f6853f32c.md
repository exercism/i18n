# Instruções

A empresa em que você trabalha quer reduzir a pegada de carbono, então quer que você escreva um programa para calcular o consumo de energia e o custo de manter os eletrônicos dela funcionando.

## 1. Obter as horas extras

Seu empregador tem um programa que calcula o tempo que diferentes eletrônicos levam para funcionar.
No momento, o tempo é armazenado em horas.
Quando seu empregador somou as horas, percebeu que a duração não estava correta.
Ele quer que você adicione 3 horas extras aos dados de tempo.
Ele também gostaria de saber quantas horas "extras" sobram depois de converter os dados em dias "completos" (um dia tem 24 horas).
O tempo a converter pode não corresponder a dias completos.

Implemente uma função `get_extra_hours()` que recebe um inteiro com o número de horas.
A função deve fazer o ajuste apropriado das "horas extras" e então `return` um inteiro que representa quantas horas precisam ser removidas do total para obter o tempo em dias "completos".

```python
>>> get_extra_hours(25)
4
```

## 2. Obter o valor em kW

Seu empregador quer saber o consumo de energia dos diferentes eletrônicos em kW.
kW significa quilowatt, e watt é uma unidade de potência.
O quilo no nome da unidade é um prefixo do sistema métrico que significa 1000.
Um quilowatt == 1000 watts.

Implemente uma função `get_kW_value()` que recebe um inteiro com o número de watts.
A função deve então `return` os watts em quilowatts, arredondados para 1 casa decimal.

```python
>>> get_kW_value(1150)
1.2
```

## 3. Obter o valor em kWh

Para conseguir calcular o custo de manter os eletrônicos funcionando, seu empregador precisa saber o consumo de energia em kWh.
kWh significa quilowatt-hora, e hora é uma unidade de tempo.
Um quilowatt-hora == 1000 watts usados por 1 hora.
Uma hora é composta de 60 minutos, e um minuto é composto de 60 segundos.
Uma hora equivale a 3600 segundos.
Para calcular o valor em kWh, você deve converter os watts em kW e depois fazer uma divisão inteira do resultado por 3600.

Implemente uma função `get_kWh_value()` que recebe um inteiro com o número de watts.
A função deve então `return` os quilowatt-horas como um inteiro.

```python
>>> get_kWh_value(5000000)
1
```

## 4. Obter a eficiência

Os eletrônicos não são 100% eficientes.
Por isso, seu empregador quer que você calcule a _eficiência_ dos eletrônicos.
Para obter a eficiência, você deve dividir o fator de potência (_um número de ponto flutuante entre 0 e 100_) por 100.

Implemente uma função `get_efficiency()` que recebe um número de ponto flutuante com o fator de potência.
A função deve então `return` a eficiência calculada como um número de ponto flutuante.

```python
>>> get_efficiency(80)
0.8
```

## 5. Obter o custo

Seu empregador quer saber o custo de manter os eletrônicos funcionando.
O custo de manter os eletrônicos funcionando é a potência usada multiplicada pelo custo por kWh.
A potência usada é a potência fornecida dividida pela eficiência calculada.

Implemente uma função `get_cost(<watts>,<power_factor>,<price>)` que recebe um inteiro com o número de watts, um número de ponto flutuante com o fator de potência e um número de ponto flutuante com o custo por kWh.
A função deve então `return` o custo de manter os eletrônicos funcionando como um número de ponto flutuante.

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
