# Introdução

Uma [`List`][lists] em Elm é uma coleção imutável de zero ou mais valores do mesmo tipo.

Listas podem ser definidas assim:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

A forma mais comum de adicionar um elemento a uma lista é com o operador `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

As listas são manipuladas por funções e operadores definidos no [módulo `List`][list-module] ou por [casamento de padrões][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
