# Dicas

## Geral

- Não se preocupe com o modo como os argumentos são _derivados_; foque em combinar os argumentos para retornar o resultado esperado.

## 1. Defina se o personagem ganha pontos de bônus

- Você pode usar [o operador lógico _and_][and] para combinar argumentos e obter um resultado.

## 2. Defina se o personagem pontua

- Você pode usar [o operador lógico _or_][or] para combinar argumentos e obter um resultado.

## 3. Defina se o personagem perde

- Você pode usar [o operador lógico _not_][not] para negar um argumento e obter um resultado.

## 4. Defina se o personagem vence

- Você pode usar os métodos anteriores para combinar argumentos e obter um resultado.

[not]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-NOT-Operator
[and]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-AND-Operator
[or]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-OR-Operator
