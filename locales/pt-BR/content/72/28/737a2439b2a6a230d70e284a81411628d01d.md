# Instruções

Use o Crivo de Eratóstenes para encontrar todos os números primos de 2 até um número qualquer.

O Crivo de Eratóstenes é um algoritmo simples e antigo para encontrar todos os números primos até um limite qualquer. Ele faz isso marcando repetidamente como compostos (ou seja, não primos) os múltiplos de cada primo, começando pelos múltiplos de 2. Não usa nenhuma operação de divisão nem de resto.

Crie seu intervalo, começando em dois e indo até o limite dado, inclusive. (ou seja, [2, limite])

O algoritmo consiste em repetir o seguinte, de novo e de novo:

- pegue o próximo número ainda não marcado da sua lista (ele é primo)
- marque todos os múltiplos desse número (eles não são primos)

Repita até ter processado cada número do seu intervalo.

Quando o algoritmo termina, todos os números da lista que não foram marcados são primos.

O artigo da Wikipédia tem um gráfico útil que explica o algoritmo:
https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes

Repare que este é um algoritmo bem específico, e os testes não verificam se você implementou o algoritmo, apenas se você chegou à lista correta de primos. Um bom primeiro teste é verificar se você não usa operações de divisão ou de resto (div, /, mod ou %, dependendo da linguagem).
