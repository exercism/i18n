# Instruções

Você comanda os jogos de azar do fliperama no calçadão à beira-mar. Os apostadores rolam os dados, a máquina de garra pega um prêmio, e a mesa de cartas precisa do baralho embaralhado e das mãos distribuídas, tudo movido por aleatoriedade. No fim da noite, você também quer um recurso de "replay", para que um jogo disputado possa ser rodado de novo a partir da mesma semente.

## 1. Rolar um dado

Defina `roll-die` para receber o número de lados e retornar um lançamento no intervalo de `1` a `sides` (inclusive).

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. Pegar um prêmio

Defina `pick-prize` para receber uma sequência de prêmios e retornar um deles de forma aleatória.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. Embaralhar o baralho

Defina `shuffle-deck` para receber um baralho (uma sequência) e retorná-lo com as cartas em ordem aleatória.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. Distribuir uma mão

Defina `deal-hand` para receber um baralho e uma contagem `n`, e retornar `n` cartas *distintas* do baralho.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. Repetir a partir de uma semente

Defina `play-seeded` para receber uma semente e uma quotation, e rodar a quotation com um gerador semeado a partir desse inteiro, de modo que a mesma semente sempre reproduza o mesmo resultado. O resultado da quotation deve ser retornado a quem a chamou.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
