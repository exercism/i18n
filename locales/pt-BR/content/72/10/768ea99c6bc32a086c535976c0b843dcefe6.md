# Instruções

Você vai escrever um código para gerenciar o inventário de itens de uma loja.
O inventário será uma referência de hash contendo os itens do inventário e suas quantidades.

## 1. Criar um novo inventário usando os itens

Modifique a sub-rotina `InventoryManagement::create_inventory`, que recebe uma referência de array de itens como argumento, para retornar uma referência de hash de um inventário recém-criado, em que as chaves são os nomes dos itens e os valores são a quantidade.

## 2. Adicionar ao inventário usando os itens

Modifique a sub-rotina `InventoryManagement::add_items`, que recebe uma referência de hash de inventário e uma referência de array de itens como argumentos, para retornar uma referência de hash com os itens adicionados ao inventário.

## 3. Remover os itens do inventário

Modifique a sub-rotina `InventoryManagement::remove_items`, que recebe uma referência de hash de inventário e uma referência de array de itens como argumentos, para retornar uma referência de hash com os itens removidos do inventário.
As quantidades dos itens não devem ficar abaixo de zero.

## 4. Excluir o item completamente do inventário

Modifique a sub-rotina `InventoryManagement::delete_item`, que recebe uma referência de hash de inventário e o nome de um item como argumentos, para retornar uma referência de hash com o item excluído completamente do inventário.
