# Instalando o Swift

O Swift está disponível para macOS, Linux e Windows.
O processo de instalação varia conforme o sistema operacional que você usa.
Um ponto importante sobre o suporte a Linux é que o Swift só tem suporte (oficial) nas seguintes distribuições:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

Se você usa uma distribuição de Linux diferente, vai precisar encontrar uma forma de instalar o Swift por conta própria.

## Xcode (macOS)

O Swift vem incluído no Xcode, a IDE da Apple para desenvolvimento em macOS e iOS.
Para a trilha do Exercism, você precisa ter o Xcode versão 16.0 ou superior instalado.
O Xcode está disponível gratuitamente na [Mac App Store][xcode].
Outras versões do Xcode (incluindo a beta mais recente) estão disponíveis no [centro de desenvolvedores da Apple][apple-developer-center].

## macOS e Linux

Para macOS e Linux, existe um gerenciador de instalação do Swift chamado [swiftly][swiftly].
É uma ferramenta de linha de comando que permite instalar e gerenciar várias versões do Swift no seu sistema.
O comando para instalar o swiftly no macOS está [aqui][swiftly-macos], e [aqui][swiftly-linux] para Linux.

Outra forma de instalação para macOS é o [Homebrew][homebrew].
No Linux, você pode instalar usando o tarball do [site oficial do Swift][tarball].

## Windows

A forma recomendada de instalar o Swift no Windows é usar o [instalador do WinGet][winget-windows].
Também é possível instalar o Swift usando o gerenciador de pacotes Scoop ou fazendo uma instalação manual.
Para todas as opções, consulte a página [Instalar o Swift no Windows][swift-windows].
