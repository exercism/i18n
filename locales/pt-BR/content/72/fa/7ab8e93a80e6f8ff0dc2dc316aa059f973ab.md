# Instruções complementares

## Dicas

Para completar este exercício, você precisa implementar a função `anagramsFor`,
que recebe uma *palavra* e um grupo de *palavras* e retorna as que são
anagramas da *palavra* dada.

Você deve retornar os anagramas na mesma ordem em que eles aparecem na lista de
palavras candidatas.


Se for a primeira vez que você resolve este exercício, recomendamos que você
use a assinatura fornecida:

```haskell
anagramsFor :: String -> [String] -> [String]
```

Mais tarde, pode ser uma boa ideia voltar a este problema e brincar com outros
tipos de dados e bibliotecas:

- `Text`, do pacote *text*.
- `Sequence` e `Set`, do pacote *containers*.
- `MultiSet`, do pacote *multiset*

A suíte de testes foi projetada de propósito para aceitar quase qualquer
assinatura de tipo que faça sentido, então sinta-se à vontade para encontrar
a que você considerar melhor.
