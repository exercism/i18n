# Instruções

Neste exercício, você vai escrever um pouco de código para ajudar a se preparar para comprar um veículo.

Você tem três tarefas: uma para determinar se você consegue arcar com as parcelas mensais, uma para descobrir de qual habilitação você vai precisar e uma para estimar o preço aceitável de um veículo usado.

## 1. Calcular se você pode ou não arcar com as parcelas mensais de um carro

As concessionárias da sua cidade estão todas com uma promoção de cinco anos com 0% de juros, da qual você gostaria de aproveitar.
Mas você não tem certeza se consegue arcar com as parcelas mensais do carro que quer.

A parcela mensal é o preço total do carro dividido pelo número de meses do período de cinco anos.

Implemente a função `canIBuy(vehicle:price:monthlyBudget:)`, que recebe os seguintes argumentos:
- `vehicle` - O nome do veículo que você quer comprar.
- `price` - O preço do veículo que você quer comprar.
- `monthlyBudget` - A quantia de dinheiro que você pode pagar a cada mês.

A função deve retornar a seguinte mensagem de acordo com as seguintes condições:
- Se a parcela mensal do veículo for menor ou igual ao orçamento mensal, retorne a mensagem `"Yes! I'm getting a <vehicle>"`.
- Se a parcela mensal do veículo estiver acima do seu orçamento mensal em até 10% (inclusive), retorne a mensagem `"I'll have to be frugal if I want a <vehicle>"`.
- Se a parcela mensal do veículo estiver mais de 10% acima do seu orçamento mensal, retorne a mensagem `"Darn! No <vehicle> for me"`.

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. Determinar o tipo de habilitação que você vai precisar

Você decidiu comprar um veículo usado e precisa determinar de qual tipo de habilitação você vai precisar para conduzi-lo.

Implemente a função `licenseType(numberOfWheels:)`, que recebe o argumento `numberOfWheels`, o número de rodas do veículo que você quer comprar.

A função deve retornar a seguinte mensagem de acordo com as seguintes condições:
- Se o número de rodas for 2 ou 3, retorne a mensagem `"You will need a motorcycle license for your vehicle"`.
- Se o número de rodas for 4 ou 6, retorne a mensagem `"You will need an automobile license for your vehicle"`.
- Se o número de rodas for 18, retorne a mensagem `"You will need a commercial trucking license for your vehicle"`.
- Se o número for qualquer outro, retorne a mensagem `"We do not issue licenses for those types of vehicles"`.

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. Calcular uma estimativa para o preço de um veículo usado

Agora que você tomou sua decisão, quer garantir um preço justo na concessionária.
Como você quer comprar um veículo usado, o preço depende de quantos anos o veículo tem.
Para uma estimativa aproximada, considere que, se o veículo tiver menos de 3 anos, ele custa 80% do preço original de quando era zero.
Se tiver pelo menos 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos, mas não mais de 10 anos, custa 70% do preço original.

Implemente a função `calculateResellPrice(originalPrice:yearsOld:)`, que recebe os argumentos `originalPrice`, que guarda o preço original do veículo, e `yearsOld`, que guarda a idade do veículo em anos.
A função deve retornar o preço de revenda do veículo. 

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
