# Sobre

## Operadores de comparação

Os [operadores de comparação][comparison-operators] comparam dois valores do mesmo tipo e retornam um valor `Bool` (`true` ou `false`).
Se você tentar comparar valores de tipos diferentes, o compilador gera um erro.

Os operadores de comparação padrão do Swift são:

| Operador | Descrição                | Exemplo         |
| -------- | ------------------------ | --------------- |
| `==`     | Igual a                  | `1 == 1` (true) |
| `!=`     | Diferente de             | `1 != 2` (true) |
| `<`      | Menor que                | `4 < 5`  (true) |
| `<=`     | Menor ou igual a         | `4 <= 4` (true) |
| `>`      | Maior que                | `3 > 1`  (true) |
| `>=`     | Maior ou igual a         | `2 >= 2` (true) |

## Instruções `if` e `else`

Uma [condicional][conditional-statement] executa código dependendo de a condição ser avaliada como `true` ou `false`.
A condicional mais comum é a [condicional `if`][if], que executa um bloco de código apenas quando a condição é `true`.
Escreva uma condicional `if` usando a palavra-chave `if`, seguida da condição e do bloco de código entre chaves:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Você pode combinar o `if` com uma cláusula `else` para rodar um código alternativo quando a condição é `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Para testar várias condições em sequência, encadeie as instruções com `else if`.
Uma condicional `if` não exige um bloco `else`, mas você pode incluir um para tratar os casos em que nenhuma das condições corresponde:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Expressões `if`

No Swift moderno, as instruções `if` também podem ser usadas como expressões que produzem um valor.
Cada bloco gera um valor, o que facilita atribuir resultados condicionalmente:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
