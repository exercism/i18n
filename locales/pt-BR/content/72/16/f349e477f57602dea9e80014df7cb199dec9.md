# Instalação

## Opções de instalação

A versão atual do Unison está disponível para usuários de Mac OS X, Linux de 64 bits e Windows! Se você estiver experimentando o Unison, esperamos que venha conversar com a gente no fórum do Exercism ou no [Discord do Unison](https://unison-lang.org/discord). Venha tirar dúvidas e relatar os problemas que encontrar! Queremos que você tenha uma experiência acolhedora e positiva ao começar! 😊

O Unison pode ser baixado com o [homebrew](https://brew.sh/), o [Nix](https://github.com/ceedubs/unison-nix/#usage) ou diretamente por meio de binários empacotados. Todas essas opções de download estão descritas na [página de instruções de instalação do nosso site](https://www.unison-lang.org/learn/quickstart/#installation-options). Depois de instalar o UCM, volte aqui!

### Opção 1: usando o Homebrew

Primeiro, [instale o homebrew](https://brew.sh/) se ainda não tiver feito isso.

Depois, no terminal, digite estes comandos:

```
brew tap unisonweb/unison
brew install unison-language
```

Isso vai instalar o executável do gerenciador de codebase do Unison, o `ucm`. Se você estiver atualizando de uma versão anterior, basta fazer

```
brew upgrade unison-language.
```

Observação: se aparecer um pedido de nome de usuário e senha do GitHub neste momento, verifique se você escreveu unisonweb/unison corretamente.

### Opção 2: instalação manual para usuários de Mac e Linux

[Os links de instalação manual para Linux e Mac estão aqui](https://www.unison-lang.org/learn/quickstart/#installation-options), nas respectivas seções de download manual para Linux e Mac.

Você vai rodar um comando no seu terminal mais ou menos assim, mas o link acima contém o binário mais atualizado:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### Opção 3: instalação manual para usuários de Windows

1. Defina o "Windows Terminal" como seu aplicativo de terminal padrão para obter melhores resultados. Pesquise por "Terminal" nas Configurações ou siga [este guia.](https://bit.ly/3IXwdlY)
2. Se você não tem certeza de que já o tem instalado, instale o Git:
  * Com o winget: `winget install --id Git.Git -e --source winget`
  * Se você usa o Windows 10 e não tem o winget, instale-o pela [Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1) e depois rode o comando acima.
3. [Baixe o UCM pelo link fornecido aqui](https://www.unison-lang.org/learn/quickstart/#installation-options) e extraia-o para o local que você preferir.
4. Rode o `ucm.exe`

### Opção 4: instalação com Nix
Vá para [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) e siga as instruções do readme de lá.

## Crie seu codebase do Unison

Rode `ucm` para inicializar um codebase do Unison em `$HOME/.unison`. É aqui que o Unison vai guardar definições de funções, tipos, namespaces e assim por diante. Por padrão, o Unison Codebase Manager (abreviado como "UCM") começa a baixar a biblioteca padrão, chamada `base`, que você vai usar para escrever código Unison. Isso pode demorar um pouco! 🕰

## Fluxo de trabalho com o Unison

Quando você quiser escrever código Unison, use o comando `ucm` para iniciar o gerenciador de codebase. O UCM vai então observar mudanças em qualquer arquivo com sufixo `.u` no diretório a partir do qual ele foi chamado. Por exemplo, você pode estar implementando funções em um arquivo chamado `scratch.u` em um diretório chamado `~/exercism/unison/my-exercise/`. Você deve usar `cd` para entrar em `~/exercism/unison/my-exercise/` e rodar `ucm`. Assim você garante que o UCM está observando seu arquivo `scratch.u` em busca de mudanças.

Se em algum momento você ficar em dúvida sobre qual diretório o `ucm` está observando em busca de mudanças de arquivo, ele aparece na tela de boas-vindas ao iniciar a CLI.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[Veja mais dicas de fluxo de trabalho aqui!](https://exercism.org/docs/tracks/unison/workflow)

## Suporte a editores

Você pode usar qualquer editor de texto para escrever seus arquivos `.u`. O Unison tem [suporte a LSP](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown), então sua IDE favorita pode ajudar com coisas como tipos ao passar o mouse e preenchimento automático. Alguns editores populares com suporte ao Unison estão listados abaixo:

### Vim

Usando o [vim-plug](https://github.com/junegunn/vim-plug):

1. Instale o [`vim-plug`](https://github.com/junegunn/vim-plug) se ainda não tiver feito isso.
2. Adicione o seguinte ao seu .vimrc: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. Rode o comando do vim `:PlugInstall`.

Para mais informações, rode `:help unison`
dentro do vim ou consulte o [documento de ajuda online](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt).

### Atom
No terminal, rode:

```
apm install unisonweb/atom-unison
```

### VS Code

1. Abra a visualização Extensions clicando no ícone Extensions na Activity Bar, na lateral do VS Code, ou use ⇧⌘X.
2. Busque por "unison"
3. Instale a [extensão do Unison para VS Code](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)

### Emacs
Instale o [`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs).
