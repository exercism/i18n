# Introdução

Em Python, `None` é usado com frequência para representar a ausência de um valor: um espaço reservado para definir uma variável, um objeto ou um argumento `null` (vazio).

Se você já ouviu falar ou usou um tipo `NULL` ou `nil` em outra linguagem de programação, este uso de `None` em Python vai soar familiar para você. O `None` ajuda você a declarar variáveis ou argumentos de função para os quais ainda não tem valores. Depois, conforme a necessidade, eles podem ser reatribuídos a valores específicos.

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

O `None` é avaliado como `False` quando usado em uma verificação condicional, então ele é útil para validar a "presença" ou a "ausência" de um valor, _qualquer_ valor, um padrão muito usado quando uma função ou um processo pode retornar um objeto ou uma mensagem de erro.

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
