# Salário de funcionário

## História

Neste exercício, você vai implementar as regras para calcular o salário total de um funcionário em um mês. A International Siderurgy Company (ISC) precisa de ajuda para calcular o salário dos funcionários, já que diferentes fatores podem alterar o valor final do salário de cada um.

## Tarefas

É possível implementar as seguintes tarefas:

- Adicionar um bônus de acordo com o tempo de casa.
- Penalidades para cada dia de trabalho perdido.
- Dar um bônus para cada produto vendido.
- Adicionar um multiplicador se um determinado limite de produtos vendidos for atingido.
- Verificar se o salário é menor que o salário mínimo e, se for, arredondar para cima.
- Verificar se o salário é maior que o salário máximo e, se for, arredondar para baixo.
- Calcular o salário final do funcionário, depois de aplicar todas as restrições.

## Terminologia

Estas são recomendações, não regras, para a terminologia recorrente nas instruções (incluindo os comentários do stub)

- A International Siderurgy Company (ou ISC) é a empresa que está pedindo sua ajuda
- O salário mínimo limita a faixa salarial a um valor mínimo
- O salário máximo limita a faixa salarial a um valor máximo
