# Testes

Para usar a CLI e rodar os testes do exercício, execute o seguinte comando a partir do diretório do exercício:

```bash
clojure -M:test
```

## REPL

Para usar o REPL e rodar os testes do exercício, execute o seguinte comando a partir do diretório do exercício:

```bash
$ clojure -m cljs.main -re node
```

Depois, use `require` no namespace de teste do exercício e no namespace de teste do Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Mude o ns para o namespace de teste:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

Depois, chame `run-tests`:

```clojure
=> (cljs.test/run-tests)
```
