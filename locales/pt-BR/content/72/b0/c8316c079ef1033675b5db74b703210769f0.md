# Instruções

Neste exercício, você vai trabalhar com contas poupança.
A cada ano, o saldo da sua conta poupança é atualizado com base na taxa de juros.
A taxa de juros que seu banco oferece depende da quantidade de dinheiro na sua conta (o saldo dela):

- 3,213% para um saldo menor que `0` dólares (o saldo fica ainda mais negativo).
- 0,5% para um saldo maior ou igual a `0` dólares e menor que `1000` dólares.
- 1,621% para um saldo maior ou igual a `1000` dólares e menor que `5000` dólares.
- 2,475% para um saldo maior ou igual a `5000` dólares.

Você tem quatro tarefas, e cada uma delas vai lidar com o saldo da sua conta e a taxa de juros.

## 1. Calcule a taxa de juros

Implemente a função `InterestRate()` para calcular a taxa de juros com base no saldo especificado:

```go
InterestRate(200.75)
// => 0.5
```

Observe que o valor retornado é um `float32`.

## 2. Calcule os juros

Implemente a função `Interest()` para calcular os juros com base no saldo especificado:

```go
Interest(200.75)
// => 1.003750
```

Observe que o valor retornado é um `float64`.

## 3. Calcule a atualização anual do saldo

Implemente a função `AnnualBalanceUpdate()` para calcular a atualização anual do saldo, levando em conta a taxa de juros:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

Observe que o valor retornado é um `float64`.

## 4. Calcule os anos antes de alcançar o saldo desejado

Implemente a função `YearsBeforeDesiredBalance()` para calcular o número mínimo de anos necessários para alcançar o saldo desejado, levando em conta que, a cada ano, os juros são adicionados ao saldo.
Isso significa que o saldo após um ano é: saldo inicial + juros sobre o saldo inicial.
O saldo após o segundo ano é: saldo após um ano + juros sobre o saldo após um ano.
E assim por diante, até que o saldo do ano atual seja maior ou igual ao saldo desejado.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

Observe que o valor retornado é um `int`.
