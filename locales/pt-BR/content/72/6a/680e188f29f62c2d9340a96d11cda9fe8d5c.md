# Rodando os testes

Para rodar os testes de um exercício, execute o script `<exercise>.test` no diretório do exercício:

```bash
tclsh <exercise>.test
```

Na maioria dos exercícios, todos os testes, menos o primeiro, estarão "skipped".
Isso permite que você pratique o desenvolvimento guiado por testes: escrever só o código necessário para passar em cada teste, um de cada vez.
Para ignorar os comandos de skip, defina a variável de ambiente `RUN_ALL` com um valor verdadeiro válido no Tcl \[1\] antes de rodar a suíte de testes:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Os valores verdadeiro/falso do Tcl estão documentados na página de manual da função da biblioteca C [Tcl_GetBoolean][bool].

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
