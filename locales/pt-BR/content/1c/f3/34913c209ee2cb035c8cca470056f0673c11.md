# Instruções

Neste exercício, você vai escrever código para acompanhar códigos de discagem internacional por meio de um hashmap de códigos de discagem internacional.

O mapa usa um número inteiro para as chaves (o código de discagem) e uma string (nome do país) para os valores.

Você tem 11 tarefas que envolvem códigos de discagem.

## 1. Crie um hashmap pré-preenchido

Existe um hashmap pré-preenchido que contém os seguintes 3 códigos de discagem: "United States of America", que tem o código 1, "Brazil", que tem o código 55, e "India", que tem o código 91. Defina a variável `countries` para armazenar o hashmap pré-preenchido:

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. Adicione um país a um mapa

Adicione "United Kingdom" com o código de discagem 44 ao mapa criado na tarefa 1:

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. Obtenha o nome do país correspondente a um código de país

Obtenha o nome do país com o código de discagem 55

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. Atualize o nome de um país

Mude o nome de "United States of America" para "Les États-Unis":

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. Verifique se um país existe no mapa

Verifique se existe um registro para Brazil no mapa criado na tarefa 1

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. Tente atualizar o nome de um país que não está no mapa

Tente mudar o nome de um país com um código que não está no mapa, por exemplo 999. Isso não deve mudar o mapa:

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. Remova um país do mapa

Remova India do mapa:

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. Encontre o país com o nome mais longo

Processe os valores do mapa para encontrar o que tem o nome mais longo:

```clojure
(longest-name countries)
;;=> "United States of America"
```
