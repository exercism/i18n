# Apêndice das instruções

## Espere aí, é impossível!

Implementar estas operações de lista sem usar _nenhuma_ função embutida é praticamente impossível em Roc, porque você precisa de uma forma de adicionar elementos no fim ou no início de uma lista.
Em outras linguagens, você pode usar operadores como `:` em Haskell ou `+=` em Python, mas em Roc você precisa usar as [funções de `List`](https://www.roc-lang.org/builtins/main/#Builtin.List).

Então, neste exercício, você pode usar `List.append` (mas evite usar qualquer outra função embutida).

Muitas linguagens de programação funcional usam listas encadeadas como o principal tipo de coleção.
Em uma lista encadeada, adicionar um elemento no início ou remover o primeiro elemento é eficiente, então, nessas linguagens, você implementaria as operações de lista usando `List.prepend`.
Em Roc, porém, uma `List` é um array (um bloco contíguo de bytes).
Arrays têm propriedades diferentes das listas encadeadas, como a capacidade de acessar elementos por índice com eficiência e de adicionar novos elementos ao final.
Por isso, em Roc usamos `List.append` com frequência e raramente usamos `List.prepend`.

## Nomenclatura

Roc usa nomes um pouco diferentes dos listados nas instruções gerais:

- `concat` em vez de `append`
- `join` em vez de `concatenate`
- `len` em vez de `length`
- `fold` em vez de `foldl`
- `fold_rev` em vez de `foldr`

No entanto, os seguintes nomes de função são padrão em Roc:
- `filter`
- `map`
- `reverse`

## Dica

Experimente usar:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

ou

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
