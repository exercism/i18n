# Sobre

[Nil][nil-dictionary] é uma palavra do inglês que significa "nada" ou "zero". No Elixir, `nil` é um valor especial que indica uma _ausência_ de valor.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` é um átomo, mas geralmente é escrito como `nil`, não `:nil`. Os valores Boolean `true` e `false` também são átomos.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

Você pode verificar se o valor de uma variável é `nil` usando [`==`][kernel-equal], com pattern matching, ou usando o guard [`is_nil`][kernel-is-nil].

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
