# Instruções

Você é um observador de pássaros dedicado que acompanha quantos pássaros visitaram seu jardim nos últimos sete dias.

Você tem cinco tarefas, todas sobre os números de pássaros que visitaram seu jardim.

## 1. Verifique quais foram as contagens na semana passada

Você armazena as contagens de pássaros no formato JSON.
Um array "principal" armazena arrays de contagens semanais.
Cada contagem semanal é um array de sete números inteiros, um número para cada dia da semana.
Você sempre adiciona novas semanas no final do array principal.
Implemente o filtro que retorna as contagens da semana passada.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Verifique quantos pássaros visitaram ontem

Implemente o filtro para retornar quantos pássaros visitaram seu jardim ontem.
As contagens de pássaros estão ordenadas por dia, sendo o primeiro elemento a contagem do dia mais antigo e o último elemento a contagem de hoje.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Calcule o número total de pássaros visitantes

Implemente o filtro para retornar o número total de pássaros que visitaram seu jardim esta semana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Calcule o número de dias movimentados

Alguns dias são mais movimentados que outros.
Um dia movimentado é aquele em que cinco ou mais pássaros visitaram seu jardim.
Implemente o filtro para retornar o número de dias movimentados desta semana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Verifique se houve um dia sem pássaros visitantes

Implemente o filtro que retorna `true` se houve algum dia nesta semana em que zero pássaros visitaram o jardim; caso contrário, retorne `false`.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
