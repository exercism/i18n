# Introdução

**Funções recursivas** são funções que chamam a si mesmas.

Uma _função recursiva_ precisa ter pelo menos um _caso base_ e pelo menos um _caso recursivo_.

Um **caso base** retorna um valor sem chamar a função de novo.
Um **caso recursivo** chama a função outra vez, modificando a entrada para que ela em algum momento corresponda ao caso base.

Veja um exemplo que conta os elementos de um array.

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

Uma _função recursiva_ pode ter vários _casos base_ e/ou vários _casos recursivos_.
Por exemplo, [a sequência de Fibonacci][wiki-fibonacci] é uma sequência recursiva com dois _casos base_.

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

Contar o número de ocorrências de um determinado valor `x` em uma lista tem dois _casos recursivos_.

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

Na prática, iterar sobre listas e outras estruturas de dados enumeráveis geralmente é feito com funções nativas,
como `map` e `reduce`, ou [usando streams][map-implementation] como `[.[] | select(...)]`.
Por baixo dos panos, algumas funções nativas são [implementadas usando recursão][walk-implementation].
