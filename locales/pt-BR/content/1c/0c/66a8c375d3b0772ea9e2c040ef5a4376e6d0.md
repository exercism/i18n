# Introdução

Em Factor, você combina palavras apenas escrevendo uma depois da outra: a ordem em que você as escreve *é* a forma como elas se conectam. (Os programadores chamam isso de *composição de funções*.) O corpo de uma palavra é, por si só, uma sequência de palavras: cada uma consome alguns valores da pilha e empilha o próprio resultado, e a próxima palavra continua de onde a anterior parou. Então, definir

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

já *é* a composição de `cleanupname`, `first` e `1string`.

Este exercício também apresenta as **quotations**: um trecho de código que você pode guardar como valor e executar depois, em vez de executá-lo na hora.

## Quotations

Uma quotation é um trecho de código entre colchetes. Ela não é executada quando você a escreve; fica na pilha como um valor:

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call` executa uma quotation:

```factor
3 [ 2 * ] call .    ! => 6
```

Você escreve uma quotation quando precisa passar código como dado: para ser executado depois, ou para ser passado a um *combinador*, uma palavra que recebe uma quotation como entrada.

## `compose`

`compose ( quot1 quot2 -- combined )` cola duas quotations em uma só, executando-as na ordem em que estão escritas:

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

Você normalmente vai ver que definir uma palavrinha com `:` ... `;` fica mais legível do que usar `compose`, mas `compose` é útil quando você precisa montar quotations na hora. Quando os blocos de construção ainda não são quotations, `>quotation ( seq -- quot )` (de [`quotations`][quotations]) transforma uma sequência de valores e referências a palavras em uma quotation que pode ser chamada:

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## Aplicando uma quotation a duas entradas

`bi@ ( x y quot -- ... )` executa a quotation em `x` e de novo em `y`, deixando os dois resultados na pilha:

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

A tarefa `couple` do exercício recebe dois nomes; `bi@` é a forma natural de aplicar `initial` a cada um.

## Algumas palavras para strings

O exercício precisa de algumas palavrinhas para strings, tiradas de três vocabulários: [`sequences`][sequences], [`ascii`][ascii] e [`strings`][strings]:

- `replace ( seq old new -- new-seq )` (em `splitting`): substitui uma substring.
- `[ blank? ] trim` (`trim` em `sequences`, `blank?` em `ascii`): remove espaços em branco no início e no fim.
- `1string ( char -- str )` (em `strings`): envolve um único caractere como uma string.
- `>upper ( str -- upper )` (em `ascii`): converte uma string para maiúsculas.
- `append ( s1 s2 -- s )` (em `sequences`): concatena duas strings.
- `prepend ( s1 s2 -- s )` (em `sequences`): concatena `s2` e depois `s1` (o `append` com as entradas na ordem inversa).
- `glue ( s1 s2 sep -- s )` (em `sequences`): concatena duas strings com um separador entre elas.
- `surround ( seq pre post -- new )` (em `sequences`): envolve uma string com um prefixo e um sufixo.

Caracteres Unicode podem ser escritos como `\u{XXXX}` dentro de uma string, em que `XXXX` é o ponto de código em hexadecimal. O coração `\u{2764}` (❤) aparece neste exercício.

## Saída formatada

Quando `append`/`glue`/`surround` não são expressivos o suficiente, [`formatting`][formatting] oferece o `sprintf` no estilo printf:

```
sprintf ( inputs... format-string -- str )
```

`%s` interpola uma string, `%d` um número inteiro, `%f` um número de ponto flutuante; modificadores opcionais de largura, precisão e preenchimento vêm entre o `%` e a letra do tipo:

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

Para converter nos dois sentidos entre números e strings, [`math.parser`][math.parser] tem `number>string` e `string>number`:

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
