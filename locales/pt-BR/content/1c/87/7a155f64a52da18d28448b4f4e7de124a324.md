# Anexo às instruções

## Bônus

Teste a sua função com esta string: `uüu` e veja o que acontece.
Tente escrever uma função que inverta esta string corretamente.
Dica: grapheme clusters

Para conseguir rodar o teste de bônus, remova a flag de `ignore` (`#[ignore]`) do último teste e execute os testes com:

```bash
cargo test --features grapheme
```

Para a tarefa de bônus, você vai precisar de bibliotecas externas (um `crate`, no jargão do Rust).
Um bom lugar para procurá-las é o [crates.io](https://crates.io/), o repositório oficial de crates.
Lembre-se de que apenas um conjunto limitado de crates é aceito pelo nosso test runner.
A lista completa está em [este arquivo](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml), na seção `[dependencies]`.

[Consulte a documentação](https://doc.rust-lang.org/cargo/guide/dependencies.html) para saber como usar crates externas nos seus projetos.
