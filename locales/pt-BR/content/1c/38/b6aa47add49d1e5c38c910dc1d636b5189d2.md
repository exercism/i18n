# Dicas

- A documentação do pacote `Bitwise` pode ser encontrada [aqui][bitwise-docs].

## 1. Desloque os bits de volta

- Existem duas funções para deslocar bits para a direita, mas [apenas uma][bitwise-shiftRightZfBy] sempre insere um 0.

## 2. Defina alguns bits

- [Uma das funções bit a bit][bitwise-or] sempre define um bit como 1 onde os bits em ambos os valores forem 1.

## 3. Inverta bits específicos

- Existe [uma função bit a bit][bitwise-xor] que inverte um bit onde a máscara é 1.

## 4. Limpe bits específicos

- [Uma das funções bit a bit][bitwise-and] limpa bits onde o bit na máscara é 0.
- Mas talvez você precise combiná-la com [outra função][bitwise-complement] para limpar bits onde a máscara é 1.

## 5. Descriptografe uma mensagem

- Aplique as outras funções que você escreveu à entrada na seguinte ordem, pegando a saída de uma e usando-a como entrada da próxima:

1. `setBits`
2. `flipBits`
3. `shiftBack`
4. `clearBits`

Para o passo 4, você vai precisar converter o número binário com o 1º e o 5º bits definidos (10001) para decimal.
