# Dicas

## Geral

- Você pode usar a [classe Random][random-class] para gerar números aleatórios.
- Leia mais no artigo: [Geradores de números aleatórios no Java 17][random-number-generators].

## Geração de labirinto

Você pode usar qualquer algoritmo para gerar um labirinto perfeito. O [backtracking recursivo][recursive-backtracker] é uma boa escolha.

## Caracteres de desenho de caixa

| Caractere | Nome                                        | Unicode |
|:---------:|:--------------------------------------------|:--------|
|     ┌     | desenhos de caixa: leve para baixo e direita|  U+250C |
|     ─     | desenhos de caixa: leve horizontal          |  U+2500 |
|     ┬     | desenhos de caixa: leve para baixo e horizontal |  U+252C |
|     ┐     | desenhos de caixa: leve para baixo e esquerda |  U+2510 |
|     │     | desenhos de caixa: leve vertical            |  U+2502 |
|     └     | desenhos de caixa: leve para cima e direita |  U+2514 |
|     ┴     | desenhos de caixa: leve para cima e horizontal |  U+2534 |
|     ┘     | desenhos de caixa: leve para cima e esquerda |  U+2518 |
|     ├     | desenhos de caixa: leve vertical e direita  |  U+2520 |
|     ⇨     | seta branca para a direita                  |  U+21E8 |
