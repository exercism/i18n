# Introdução

Uma `string` em Clojure é uma string do Java, ou seja, um objeto que representa texto imutável como uma sequência de caracteres Unicode (letras, dígitos, pontuação, etc.).

A biblioteca `clojure.string` fornece muitas funções padrão de manipulação e processamento de strings. Além disso, todos os métodos usuais do Java para operar com strings estão disponíveis via interop.
