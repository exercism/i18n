# Anexo às instruções

Em [concept:python/unpacking-and-multiple-assignment](https://github.com/exercism/python/tree/main/concepts/unpacking-and-multiple-assignment), você aprendeu várias técnicas para trabalhar com `lists`/`tuples` de tamanho arbitrário, além de argumentos de função de tamanho arbitrário.
Este exercício é um ótimo lugar para praticar essas técnicas.

## Como este exercício é implementado para Python

Os casos de teste desta trilha adicionam um argumento nomeado extra chamado `qualifier`.
Você deve usar o valor desse argumento nomeado para modificar o verso final do seu Provérbio.
