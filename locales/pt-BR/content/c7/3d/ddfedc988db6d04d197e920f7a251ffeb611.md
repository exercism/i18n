No Raku, blocos de código são usados à vontade.
São fundamentais para funções, mas também aparecem em ferramentas como `grep` e `map`, como blocos de instruções `if`, `for`, `while` e `given`, e até em subscritos de array.

## Rotinas

[`Subs`][type/Sub] e [`Methods`][type/Method] são tipos de [`Routines`][type/Routine] no Raku.

Uma rotina pode ser encerrada a qualquer momento com um valor de retorno, usando a palavra-chave [`return`][control-return], uma ferramenta útil para criar funções.
Se nenhum `return` for especificado, a última instrução da rotina será seu valor de retorno implícito.

Uma rotina pode ter uma [`Signature`][language/signatures] entre parênteses antes do bloco de código.

[`Routine`][type/Routine] é uma subclasse de [`Block`][type/Block].

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

Métodos serão abordados em um conceito separado, sobre classes e objetos.

## Blocos

Um [`Block`][type/Block] é um objeto de código reutilizável, normalmente usado para criar lambdas.

A última instrução de um bloco é seu valor de retorno implícito.

Um bloco pode ter uma [`Signature`][language/signatures] prefixada com `->` antes do bloco de código.

[`Block`][type/Block] é uma subclasse de [`Code`][type/Code], que é a classe base fundamental de todos os objetos de código no Raku.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Assinaturas

Uma [`Signature`][language/signatures] é composta por zero ou mais [`Parameters`][type/Parameter], separados por vírgulas.

No final de uma assinatura, é possível especificar um tipo de retorno com uma [seta de tipo de retorno][signatures-return-type-arrow] `-->`.

Uma assinatura pode ser usada para especificar os argumentos que um `Block` vai aceitar.

Este conceito vai manter as assinaturas simples, usando apenas parâmetros posicionais com variáveis de sigilo escalar e um tipo de retorno.
Isso será aprofundado em outros conceitos.

## Multi-dispatch

O Raku permite escrever várias rotinas com o mesmo nome, mas com assinaturas diferentes, usando a palavra-chave `multi`.
Esse recurso é conhecido como [multi-dispatch][multi-dispatch].
Quando a rotina é chamada pelo nome, o ambiente de execução determina o candidato adequado e o invoca.

Isso será abordado com mais detalhes em um conceito sobre tipos.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

Quando o asterisco `*` do [`Whatever`][type/Whatever] é usado em combinação com a maioria dos operadores, um objeto [`WhateverCode`][type/WhateverCode] é criado.
Isso permite criar blocos com uma sintaxe mais simples.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
