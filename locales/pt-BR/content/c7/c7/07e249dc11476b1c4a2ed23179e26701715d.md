# Instruções

Use lentes para atualizar registros aninhados (algo específico de linguagens com dados imutáveis).

Atualizar campos de registros aninhados e imutáveis é meio chato.
O código para esses casos é tão trabalhoso quanto profunda é a estrutura.
Se você tiver, digamos, um Person, que contém um Address, que tem uma Street, que tem um Number, atualizar o Number exige criar uma nova Street com o novo Number, depois um novo Address com a nova Street e, por fim, um novo Person com o novo Address.
Já se perdeu?

Uma solução para esse problema é usar [lentes][lenses].

Implemente várias funções de acesso a registros usando lentes.
A suíte de testes também permite que você dispense as lentes por completo, assim você pode experimentar abordagens diferentes.

[lenses]: https://en.wikibooks.org/wiki/Haskell/Lenses_and_functional_references
