# Sobre

[Mapas][maps] são uma estrutura de dados que guarda pares chave-valor.

- As chaves podem ser de qualquer tipo, mas precisam ser únicas.
- Os valores podem ser de qualquer tipo, não precisam ser únicos.
- Os mapas não garantem a ordem do seu conteúdo, embora pareçam garantir.
  - A implementação interna deles dá essa impressão equivocada:
    - Em tamanhos pequenos (<=32 entradas), eles são implementados como uma [lista de palavras-chave][keyword-list] ordenada.
    - Em tamanhos maiores (>32 entradas), eles são implementados como uma [hash array mapped trie][hamt] &#91;[1][stackoverflow]&#93;.
- Os mapas podem ser declarados com uma forma literal:

  ```elixir
  # An empty map
  %{}

  # A map with the atom key :a associated to the integer value 1
  %{a: 1}

  # A map with the string key "a" associated to the float value 2.0
  %{"a" => 2.0}

  # A map with the map key %{} with the list value [1 ,2, 3]
  %{%{} => [1, 2, 3]}

  # A map with keys of different types
  %{:a => 1, "b" => 2}
  ```

- Os mapas também podem ser instanciados usando o [`Map.new`][map-new] do [módulo Map][map-module]. Isso pode ser útil se você já tiver uma coleção enumerável para transformar em uma lista:

  ```elixir
  kw_list = [a: 1, b: 2]
  Map.new(kw_list)
  # => %{a: 1, b: 2}
  ```

- Os valores em um mapa podem ser acessados de várias maneiras diferentes:

  ```elixir
  my_map = %{key: "value"}

  # with a dot if the key is an atom
  my_map.key
  # => "value"

  # with [], a syntax provided by the Access behaviour
  my_map[:key]
  # => "value"

  # with pattern matching
  %{key: x} = my_map
  x
  # => "value"

  # with Map.get/2
  Map.get(my_map, :key)
  # => "value"
  ```

- O [módulo Map][map-module], incluído na biblioteca padrão, tem muitas funções úteis para trabalhar com mapas.

  ```elixir
  Map.delete(%{a: 2, b: 3}, :a)
  # => %{b: 3}
  ```

- Os mapas implementam o protocolo [`Enumerable`][enumerable], o que permite usar funções do [módulo Enum][enum].
- [Funções anônimas][anon-fn] ou [referências a funções capturadas][captured-fn] muitas vezes são necessárias como argumentos para funções do [Map][map-module] e do [módulo Enum][enum].

  ```elixir
  # Increment the value by one, if it is not found, update it with 0
  Map.update(%{a: 1}, :a, 0, &(&1 + 1))
  # => %{a: 2}

  # Sorting by a specific sub-value
  list = [{"A", 4}, {"B", 3}, {"C", 2}, {"D", 1}]
  Enum.sort_by(list, &Kernel.elem(&1, 1))
  # => [{"D", 1}, {"C", 2}, {"B", 3}, {"A", 4}]
  ```
