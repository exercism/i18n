# Anexo às instruções

Na trilha de Python, este exercício pede que você crie uma _classe_ `SpaceAge` (_[concept:python/classes]()_) que inclui métodos para todos os planetas do sistema solar.
Os métodos devem seguir a convenção de nomenclatura `on_<planet name>`.

Cada método deve `return` a idade (_naquele planeta_) em anos, arredondada para duas casas decimais:

```python
#creating an instance with one billion seconds, and calling .on_earth().
>>> SpaceAge(1000000000).on_earth()

#This is one billion seconds on Earth in years
31.69
```
