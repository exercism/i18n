# Introdução

Em Java, a sobrecarga de métodos é um recurso que permite que uma classe tenha mais de um método com o mesmo nome, desde que as listas de parâmetros sejam diferentes. Ela está relacionada ao polimorfismo em tempo de compilação (ou estático). Esse conceito é essencial para criar métodos que executam tarefas parecidas, mas com entradas diferentes.

## Por que sobrecarregar métodos?

A sobrecarga de métodos aumenta a legibilidade do programa. Métodos diferentes podem receber o mesmo nome, mas com parâmetros diferentes. Dependendo do número de parâmetros ou do tipo deles, o método correspondente é chamado.

## Como sobrecarregar métodos?

A chave da sobrecarga de métodos é a assinatura de um método. Dois métodos são considerados diferentes se tiverem assinaturas diferentes. Existem duas formas de sobrecarregar um método:

1. **Número diferente de parâmetros**: Métodos podem ter o mesmo nome, mas um número diferente de parâmetros.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Tipos diferentes de parâmetros**: Métodos podem ter o mesmo nome e o mesmo número de parâmetros, mas com tipos diferentes.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## Pontos para lembrar

- Métodos sobrecarregados precisam mudar a lista de argumentos.
- Métodos sobrecarregados também podem mudar o tipo de retorno, mas mudar apenas o tipo de retorno não caracteriza sobrecarga de métodos.
- Métodos podem ser sobrecarregados na mesma classe ou em uma subclasse.
