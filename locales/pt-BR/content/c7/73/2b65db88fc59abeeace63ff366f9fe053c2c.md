# Dicas

## Geral

- Os conceitos anteriores de [structs][], [maps][] e [métodos][] são úteis aqui.


## 1. Acompanhar os participantes

- O conceito de [definição de tipo][] explica como definir um novo tipo.
- Use `make()` para criar uma nova instância de `map`.
- Para adicionar um valor ao map, use `struct{}{}` para criar uma instância do `struct{}` vazio.

## 2. Verificar os participantes

- Se um elemento estiver no map, o conjunto contém esse valor.
- A [atribuição de dois valores][] pode ser usada para verificar se um map contém um item.

## 3. Comparar os participantes

- Dois conjuntos são iguais se todos os valores de cada conjunto estiverem contidos no outro conjunto.
- `range` pode ser usado para verificar todos os elementos do conjunto.
