# Dicas

## Geral

- Todo nome aqui termina em `!`, e todos entregam valores com `yield` em vez de `return`.
- Marque os argumentos com `once`. Nada aqui precisa que um argumento seja reavaliado a cada rodada.
- Para testar um deles, escreva um laço em volta dele. Um iterador não pode ser chamado sozinho, então não há nada para imprimir sem um `loop`.

## 1. Os marcadores

- Um `loop` dentro do iterador, controlado por `1.upto!(count)`, fazendo yield do número `spacing` vezes.
- Nada de especial é necessário para uma contagem igual a zero: `1.upto!(0)` não dá nada, então o laço interno termina na hora e o iterador acaba.

## 2. Até a trilha terminar

- Percorra o array com `elt!`, e `quit` quando o valor for `"end"`.
- A ordem importa: `quit` antes do `yield`, senão o `"end"` é entregue antes de você parar.
- Não é preciso nada para um array sem `"end"` dentro. O `elt!` se esgota e o iterador acaba.

## 3. Apenas os pássaros

- Percorra o array e faça yield só dentro de um `if`. Uma rodada que não faz yield em nada simplesmente dá a volta de novo: um iterador não é obrigado a fazer yield toda vez.
- Um nome começa com maiúscula quando seu primeiro caractere é `.is_upper`.
- Cuide do caso de uma string vazia antes de buscar o primeiro caractere dela.

## 4. Numerados

- Dois iteradores dentro do seu próprio iterador: `1.up!` para o número e `elt!` para o avistamento. É o pareamento de `duet-practice`, agora dentro de algo que você escreveu.
- Monte a string com `+`. O número vem primeiro, então comece com `number.str`, já que dá para somar um número a uma string, mas não o contrário.
