## Editores

### Gratuitos/de código aberto

- [VS Code](https://code.visualstudio.com)

  O VS Code é um editor de código aberto. Você encontra informações sobre como configurar o TypeScript [aqui](https://code.visualstudio.com/docs/languages/typescript). O VS Code é um editor popular para TypeScript porque a Microsoft mantém tanto o VS Code quanto o TypeScript, então ele funciona bem com a linguagem. O VS Code dá suporte a TS sem nenhuma configuração extra. Na verdade, o VS Code foi escrito em TypeScript!

  Um problema comum com o VS Code e o TS acontece quando as versões do seu editor e do projeto são diferentes. Isso pode fazer o VS Code exibir uma mensagem de erro possivelmente confusa. As instruções sobre como lidar com esse erro estão [aqui](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### Licenciados

- [Sublime Text](https://www.sublimetext.com)

  O Sublime Text é um editor de código popular, com suporte à maioria das linguagens por meio de plugins instaláveis. É grátis para testar, mas você será lembrado com frequência de comprar uma licença, que atualmente custa \$70 USD.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  O WebStorm é uma IDE JavaScript/TypeScript completa (ambiente de desenvolvimento integrado). Ele dá suporte a TypeScript sem nenhuma configuração extra e tem testes, depuração e análise de código integrados. É grátis para testar por 30 dias; depois, uma licença anual custa \$129 USD no primeiro ano.
