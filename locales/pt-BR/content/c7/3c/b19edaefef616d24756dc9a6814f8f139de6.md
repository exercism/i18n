## Tupla

[Tuplas][tuple] são usadas com frequência para agrupar informações. Elas diferem das listas por terem tamanho fixo e poderem guardar tipos de dados diferentes.
As tuplas são criadas com parênteses, `()`, e costumam ser usadas para retornar vários valores de uma função.

```haskell
tuple = (1, "abc", False)
```

Isso pode ser útil quando você quer, por exemplo, armazenar uma coordenada em um espaço 2D: aí você já sabe que a tupla sempre vai ter dois elementos, as coordenadas x e y.

```haskell
coordinate = (3, 4)
```

### Acessando elementos

Muitas vezes você trabalha com tuplas curtas, e pode acessar os elementos com as funções `fst` e `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## Casamento de padrões

Ao escrever funções em Haskell, podemos usar um [estilo assertivo][assertive-style] com [casamento de padrões][pattern-match-doc]:
O casamento de padrões é um recurso muito poderoso de Haskell, que permite casar com construtores de dados e vincular variáveis aos valores que estão dentro.
Como o nome sugere, o que fazemos é casar valores com padrões e, se o valor casar com o padrão, podemos vincular variáveis aos valores dentro do padrão.
O casamento de padrões é formado principalmente por estes conceitos: reconhecer valores, vincular variáveis e decompor valores.

Veja esta função, por exemplo:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Aqui temos uma função `lucky` que recebe um `Int` e retorna uma `String`.
Definimos dois padrões para a função: um que casa com o número `7` e outro que casa com qualquer outro número. O nome pode ser qualquer coisa (desde que siga a convenção de nomes de Haskell), mas usamos `x` aqui.
Se o número for `7`, a função retorna `"Lucky number seven!"`; caso contrário, retorna `"Sorry, you're out of luck, pal!"`.
O importante aqui é que os padrões são verificados de cima para baixo. Então, se tivéssemos trocado a ordem dos padrões, a função sempre retornaria `"Lucky number seven!"`.

### Padrões de lista

Um padrão muito comum é casar com listas, tomando a cabeça e a cauda da lista.
Isso acontece porque as listas são, por natureza, listas encadeadas.
Veja um exemplo de função que retorna a cabeça e a cauda de uma lista:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Temos dois padrões aqui: um que casa com uma lista vazia e outro que casa com uma lista com pelo menos um elemento.
Isso porque, se a lista estiver vazia, precisamos ter um caso para isso; do contrário, teríamos um erro em tempo de execução.
Se a lista não estiver vazia, podemos casar a cabeça da lista com `x` e a cauda da lista com `xs`.
Isso é feito com o operador `:` (cons), que serve para adicionar um elemento no início de uma lista.
Mas, no casamento de padrões, ele nos permite decompor uma lista em sua cabeça e sua cauda, ou seja, de certa forma fazendo o oposto.

O `xs` é um nome comum para a cauda de uma lista, ele deixa claro que se trata de uma lista. Mas, se você estiver trabalhando com uma lista aninhada, pode usar `xss` para deixar claro que é uma lista de listas.

### Padrões de tupla

Assim como com as listas, também podemos casar com tuplas.
Veja um exemplo de função que recebe uma tupla e retorna o primeiro e o segundo elemento:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Aqui temos um padrão que casa com uma tupla de dois elementos: o primeiro elemento é vinculado a `x` e o segundo é vinculado a `y`.

### Padrões curinga

Às vezes não nos importamos com o valor de uma variável, só queremos casar com o padrão.
É aí que entra o padrão curinga, representado por um sublinhado `_`.

Veja um exemplo de função que retorna o primeiro elemento de uma lista:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Aqui dizemos que não precisamos da cauda da lista, então usamos o padrão curinga para ignorá-la.

### Padrões de tipo

Também podemos casar com tipos, e isso é feito usando o construtor desse tipo.
Também podemos extrair valores do tipo, como fizemos com as tuplas.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

No primeiro padrão, casamos com o construtor `Guest`; no segundo, casamos com o construtor `User` e vinculamos o valor interno a `name`.
