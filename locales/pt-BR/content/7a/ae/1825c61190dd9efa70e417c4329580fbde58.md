# Testes

Para rodar os testes:
```bash
tclsh exercise.test
```

## Testes ignorados

Resolver um exercício significa fazer todos os seus testes passarem. Por padrão, só um teste (o primeiro) é executado quando você roda os testes. Isso é intencional, pois permite que você foque só em fazer esse único teste passar. Depois que ele passar, você pode habilitar o próximo teste comentando ou removendo o comando `skip` que vem antes dele.

Como alternativa, para rodar todos os testes, independentemente de estarem marcados como "ignorados":
```bash
RUN_ALL=1 tclsh exercise.test
```
