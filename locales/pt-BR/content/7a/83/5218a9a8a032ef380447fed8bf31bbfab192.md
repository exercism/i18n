# Dicas

## Geral

- Não se esqueça de exportar as três sub-rotinas públicas.
  Liste-as no array `@EXPORT_OK`.

## 1. Verifique se uma data fornecida está no passado

- Para analisar strings de data, as strings serão fornecidas no formato ISO 8601.
  Use a variável de pacote `$STRPTIME_FORMAT`.
- Os métodos `Time::Piece->strptime` ou `DateTime::Tiny->from_string` serão úteis.

## 2. Verifique se uma data fornecida está à tarde

- A "tarde" começa ao meio-dia e termina antes das 18:00.

## 3. Converta uma data em uma string que descreve um compromisso

- Use `mm/dd/yyyy` para o formato da data de saída.
  Por exemplo: 12/31/2021
- O formato de hora de saída usa a hora no intervalo de 0 a 12, sem zero à esquerda nem espaço, e o indicador am/pm em maiúsculas.
  Por exemplo: 7:59 PM
- Se você usar o módulo Time::Piece, o método `strftime` é apropriado.
