# Introdução

Uma `list` em R é uma coleção ordenada de itens, que difere dos `vectors` de algumas maneiras:

- Os itens podem ser de tipos diferentes (por exemplo, misturar `numeric` com `character`).
- Os itens podem ser estruturas complexas (por exemplo, vetores, outras listas etc.).
- Existe uma sintaxe diferente para acessar os elementos.

Analogias com outras linguagens são imprecisas.
Uma `list` de R é um pouco parecida com um dicionário do Python, mas a `list` é ordenada e pode ser acessada por índice numérico.
É um pouco parecida com uma `struct` do C, exceto que a `list` pode ser facilmente estendida em tempo de execução.

## Criando listas

Dar nomes (muitas vezes chamados de "tags") aos elementos é mais comum com listas do que com vetores:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

No entanto, as tags são opcionais, e o R vai usar apenas números de índice:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Acessando elementos de uma lista

Existem três maneiras de fazer isso, cada uma útil em contextos diferentes.

### 1. Com a notação `$tag`

Muito comum quando os nomes das tags são conhecidos de antemão.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Com a notação `[[tag]]`

Isso tem a vantagem de que o nome da tag pode ser escolhido em tempo de execução.
Repare nos colchetes duplos.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Com índice de posição

Isso funciona tenha a lista tags ou não.
Novamente, os colchetes são duplicados.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Adicionando e removendo elementos

É simples: atribuir a um elemento modifica o valor, se ele já existir, ou insere um novo, se não existir.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Para excluir, atribua `NULL` ao elemento indesejado.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
