# Dicas

## Geral

- Reveja o [conceito de Objetos][concept-class-basics] se precisar relembrar o básico.
- Leia com atenção as instruções sobre a posição dos parâmetros `x`, `y`, `width` e `height`. É fácil confundi-los.

## 1. Defina uma classe ProgramWindow

- Lembre-se de usar a [sintaxe de classe][php-class] nesta tarefa.
- Defina as [propriedades][php-properties] adicionando-as à declaração da classe.

## 2. Defina uma função construtora para a classe ProgramWindow

- Verifique se a sua função construtora não aceita nenhum argumento.
- Verifique se cada propriedade está sendo definida com o valor inteiro esperado.

## 3. Adicione um método para redimensionar a janela

- Lembre-se de usar uma nova [classe][php-class] no arquivo `Size.php` para esta tarefa.
  - Por convenção, os arquivos geralmente contêm apenas uma única classe.
- O construtor de `Size` deve aceitar argumentos para os valores iniciais das [propriedades][php-properties] da classe.
- Crie um método `resize` no objeto `ProgramWindow` para aplicar a mudança usando uma instância de `Size`.

## 4. Adicione um método para mover a janela

- Lembre-se de usar uma nova [classe][php-class] no arquivo `Position.php` para esta tarefa.
  - Por convenção, os arquivos geralmente contêm apenas uma única classe.
- O construtor de `Position` deve aceitar argumentos para os valores iniciais das [propriedades][php-properties] da classe.
- Crie um método `move` no objeto `ProgramWindow` para aplicar a mudança usando uma instância de `Position`.
