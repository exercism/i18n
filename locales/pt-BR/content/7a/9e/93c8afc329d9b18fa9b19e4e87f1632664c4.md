# Binário, octal e hexadecimal

Binário, octal e hexadecimal (_também conhecido como hex_) são [sistemas de numeração][numeral-systems] diferentes, com bases diferentes.
O binário é base 2, o octal é base 8 e o hexadecimal é base 16.
No Crystal, os inteiros normais são base 10.
Binário, octal e hexadecimal são todos representações de inteiros.
Isso significa que eles representam números positivos e negativos (_incluindo o zero_), sem frações nem decimais, e que suportam todas as operações que podemos fazer com inteiros.

## Binário

[Binário][binary] é um sistema de numeração de base 2, que usa apenas os dígitos 0 e 1.
Ele costuma representar os estados 0 ("desligado") e 1 ("ligado") do fluxo elétrico através de transistores e interruptores nos computadores, bem como as cargas positivas e negativas em mídias de armazenamento magnético.
O binário consegue representar todos os inteiros usados na base 10.

Um trecho do sistema de base 2 se parece com isto, embora continue infinitamente e não pare em 128:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Então, se quisermos representar o número 6, em binário ele seria: 110

| Valor posicional | 4   | 2   | 1   |
| ---------------- | --- | --- | --- |
| Número binário   | 1   | 1   | 0   |

E a operação seria: `4 + 2 + 0 = 6`

Outro exemplo: 19

| Valor posicional | 16  | 8   | 4   | 2   | 1   |
| ---------------- | --- | --- | --- | --- | --- |
| Número binário   | 1   | 0   | 0   | 1   | 1   |

O número binário seria: 10011
E a operação seria: `16 + 0 + 0 + 2 + 1 = 19`

## Binário no Crystal

No Crystal, podemos representar literais binários usando o prefixo `0b`.
Se escrevermos `0b10011`, o Crystal vai interpretá-lo como um número binário e convertê-lo para a base 10.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Se você escrever um número com o prefixo `0b` que não esteja no sistema binário, isso vai gerar um erro de compilação.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Operações com números binários

Como números binários são inteiros, podemos realizar neles todas as operações que fazemos com inteiros.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Convertendo de e para a representação binária

O Crystal converte automaticamente um literal binário para `Int32`.
Para converter um `Int32` em uma representação binária, use o método [`<int>.to_s(base)`][to_s] com o argumento base definido como 2.
O método retorna uma representação em string do número binário:

```crystal
19.to_s(2)
# => "10011"
```

Para converter uma representação em string de um binário em um inteiro, podemos usar o método [`<int>.to_i(base)`][to_i], passando a base (2) como argumento:

```crystal
"10011".to_i(2)
# => 19
```

Informar a base errada (_ou uma representação binária inválida_) vai gerar um `ArgumentError`:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Métodos para números binários

Existem alguns métodos que podem ser usados em inteiros para obter informações sobre a representação binária do número.

O [`<int>.bit_length`][bit_length] retorna o número de bits necessários para representar o número:

```crystal
19.bit_length
# => 5
```

O [`<int>.bit(index)`][bit] retorna o bit no índice informado, começando da direita (_bit menos significativo_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Octal

[Octal][octal] é um sistema de numeração de base 8.
Ele usa os dígitos 0, 1, 2, 3, 4, 5, 6 e 7.

No Crystal, podemos representar números octais usando o prefixo `0o`.
Assim como no binário, o Crystal converte automaticamente uma representação octal para `Int32`.

```crystal
0o123
# => 83
```

Colocar o prefixo `0o` em um número que não esteja no sistema octal vai gerar um erro de compilação.

### Convertendo de e para a representação octal

Assim como no binário, podemos usar o método [`<int>.to_s(base)`][to_s] para converter um `Int32` em uma representação octal.
E podemos usar o método [`<int>.to_i(base)`][to_s] para converter uma representação octal em um `Int32`.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Assim como no binário, informar a base errada vai gerar um `ArgumentError`.

## Hexadecimal

[Hexadecimal][hexadecimal] é um sistema de numeração de base 16.
Ele usa os dígitos de 0 a 9 e as letras A, B, C, D, E e F.
A é 10, B é 11, C é 12, D é 13, E é 14 e F é 15.

Podemos representar números hexadecimais no Crystal usando o prefixo `0x`.
Assim como no binário e no octal, o Crystal converte automaticamente literais hexadecimais para `Int32`.

```crystal
#=> 0x123
291
```
 
Colocar o prefixo `0x` em um número que não seja hexadecimal vai gerar um erro de compilação.

###  Convertendo de e para a representação hexadecimal

Assim como no binário, podemos usar o método [`<int>.to_s(base)`][to_i] para converter um `Int32` em uma representação hexadecimal.
E podemos usar o método [`<int>.to_i(base)`][to_s] para converter uma representação hexadecimal em um `Int32`.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Assim como no binário e no octal, informar a base errada vai gerar um `ArgumentError`.

## Precisão

Ao converter um número para uma representação em string, podemos especificar a precisão do número.
Ou seja, a quantidade **mínima** de dígitos usada para representar o número.
Se o número tiver menos dígitos do que a precisão, serão adicionados zeros à esquerda na representação em string.
Isso é feito passando o argumento `precision` para o método [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## Maiúsculas

Ao converter um número para uma representação em string, podemos especificar se queremos que as letras na string fiquem em maiúsculas.
Isso é feito passando o argumento `upcase` para o método [`<int>.to_s(<base>, upcase: <value>)`][to_s].

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
