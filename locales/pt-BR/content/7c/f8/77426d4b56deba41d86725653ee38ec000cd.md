# Site de um time de basquete

## História

Você está trabalhando em um site para um time de basquete. O site exibe muitos dados, mas, infelizmente, o que é exibido muda com frequência. Como os dados ficam armazenados em um único objeto, isso não é difícil de fazer, mas dá trabalho e é entediante. Por isso, você decidiu automatizar as coisas.

## Tarefas

Estes são exemplos de tarefas que se encaixam na história de automatizar o site:

- Seu objetivo é permitir que a equipe de conteúdo escolha por conta própria quais dados exibir. Ela vai fazer isso especificando, no editor de conteúdo do site, um caminho para os dados a serem exibidos. Sua tarefa é criar uma função extract que recebe um objeto e um caminho, separados por um caractere ponto. Retorne o valor naquele caminho, ou um valor padrão.

## Tarefas adicionais

A história pode continuar, por exemplo:

- A equipe de conteúdo ficou muito empolgada com essa nova funcionalidade e já pediu que um novo recurso fosse adicionado. Ela gostaria de conseguir exibir dados de elementos específicos de um array.
