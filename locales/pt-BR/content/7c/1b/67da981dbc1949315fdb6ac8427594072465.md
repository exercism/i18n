# Dicas

Todas essas tarefas exigem que a linha de log seja dividida em partes separadas.

- Confira a função [`split()`][split] para ver as opções.

## 1. Obter a mensagem de uma linha de log

- A função `split()` retorna um vetor de strings.
- Você precisa obter o elemento apropriado nesse vetor.
- Espaços em branco no início e no fim podem ser removidos com [`strip()`][strip].

## 2. Obter o nível de log de uma linha de log

- A função [`lowercase()`][lowercase] é útil aqui.
- Uma string ASCII pode ser indexada com um intervalo.
- O índice `end` se refere ao último elemento de um vetor.
- Como alternativa, a tarefa pode ser resolvida usando [`replace()`][replace] para remover caracteres indesejados.

## 3. Reformatar uma linha de log

- A [interpolação][interpolation] de string é talvez a abordagem mais simples aqui.
- Como alternativa, algumas pessoas (com experiência em outras linguagens) podem preferir [`@sprintf()`][sprintf].
