# Dicas

## Geral

- Há várias funções disponíveis na biblioteca padrão para expressões Boolean. Confira essas funções no namespace `Boolean` do [Unison share](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/Boolean).
- A habilidade Each permite operar sobre uma lista de elementos como se ela fosse um único elemento, aplicando a função desejada a cada item. Ela também pode ser usada para criar combinações de itens, chamando Each em duas listas diferentes.
- Confira a [função `guard` em `Each`](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/abilities/Each). Ela pode ser útil quando você quiser retornar algo condicionalmente a partir da habilidade Each.
- Dado o número de combinações únicas possíveis para este problema, você pode esbarrar em problemas de complexidade de espaço ou de tempo. Existem vários mecanismos para otimizar a busca. Confira os algoritmos de [backtracking](https://www.geeksforgeeks.org/backtracking-algorithms/) ou de [branch and bound](https://www.geeksforgeeks.org/branch-and-bound-algorithm/?ref=lbp).
