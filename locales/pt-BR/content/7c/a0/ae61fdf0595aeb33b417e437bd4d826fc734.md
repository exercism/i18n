# Sobre

[Symbols][symbols] são identificadores nomeados que podem ser usados para se referir a um valor.
Eles são criados por meio de um literal de symbol, ou seja, prefixando um nome com o caractere `:` por exemplo, `:foo`.
Também podem ser escritos com aspas, por exemplo `:"foo"`, o que permite, por exemplo, espaços no nome.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

Symbols são usados em muitos lugares da linguagem, inclusive como chaves em namedtuples e para representar nomes de métodos e variáveis.

## Symbols no Crystal

Os symbols no Crystal são bem diferentes dos do Ruby.
No Crystal, um symbol é um tipo de constante e, por isso, é atribuído em tempo de compilação.
Isso significa que symbols não podem ser criados dinamicamente, o que é possível no Ruby.

No Crystal, os symbols são representados como `Int32`s, o que os torna muito eficientes.

## Conversão

Symbols podem ser convertidos em strings, mas não o contrário.
Isso acontece porque symbols são criados em tempo de compilação e strings são criadas em tempo de execução.

```crystal
:foo.to_s # => "foo"
```
