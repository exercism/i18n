# Instruções

Leslie, o alienígena do Lisp, precisa fazer umas compras. É muito importante ter uma lista de compras. É preciso adicionar coisas a ela e remover coisas dela.

Claro que papel e caneta não bastam para um alienígena do Lisp. "List" já é a maior parte da palavra "Lisp"! Deve haver algumas funções escritas para ajudar a acompanhar as compras.

Você pode ajudar Leslie a acompanhar a lista de compras?

## 1. Criando uma nova lista

A primeira coisa é que Leslie precisa criar uma lista vazia. Uma função chamada `new-list` seria perfeita para isso.

```lisp
(new-list) ; => ()
```

Oh, não... Leslie já tem algumas coisas em mente, então precisa de uma função que receba três itens (por sorte, Leslie só cria listas de três itens. Nem mais, nem menos!) e crie uma nova lista de compras com essas coisas. Escreva uma função, `list-of-things`, que receba três itens e retorne uma lista com eles.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Adicionando coisas à lista.

Antes de ir à loja, Leslie olha na despensa para ver do que precisa. Ajude escrevendo a função `add-to-list`, que adiciona um item ao início de uma lista.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. Qual é a próxima coisa da lista?

Enquanto faz compras, Leslie quer saber o que procurar em seguida. Também gosta de espiar a lista para ver o segundo, o terceiro ou até o 23º item (o número da sorte da Leslie).

- `first-thing` resulta na primeira coisa da lista
- `second-thing` resulta na segunda coisa
- `third-thing` resulta na terceira coisa
- `twenty-third-thing` resulta na vigésima terceira coisa

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Removendo uma coisa da lista

Leslie quer encontrar o primeiro item da lista e removê-lo da prateleira.
Ajude escrevendo uma função `remove-first-item` que resulta em uma lista com tudo, menos o primeiro item da lista de entrada.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Listas maiores a partir de listas menores

Leslie percebeu que fez duas listas de compras sem querer, em vez de uma só! Escreva uma função, `list-append`, que retorna uma lista com os elementos da primeira lista seguidos pelos da segunda lista.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. Quanto tempo ainda?

Leslie está começando a se preocupar que essa ida às compras vai demorar. Mas afinal, quantas coisas tem nesta lista? Escreva uma função `just-how-long` para informar qual é o tamanho da lista.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
