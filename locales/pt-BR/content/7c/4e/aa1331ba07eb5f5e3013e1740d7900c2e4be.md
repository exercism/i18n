# Sobre

C# é uma linguagem de tipagem estática, o que significa que tudo tem um tipo em tempo de compilação. Escolher um nome para uma [variável][variable] é o que chamamos de definir uma variável. Depois que uma variável é definida, definir ou atualizar um valor é chamado de atribuição de variável. Uma variável pode ser definida especificando explicitamente o seu tipo ou usando a [palavra-chave `var`][var] para que o compilador do C# infira o tipo dela com base no valor atribuído. O uso de `var` é conhecido como _inferência de tipo_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

O valor de uma variável pode ser atribuído e atualizado usando o [operador `=`][assignment]. Depois de definida, o tipo de uma variável nunca pode mudar.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# é uma linguagem orientada a objetos e exige que todas as [funções][function] sejam definidas em uma _classe_, que é definida usando a [palavra-chave `class`][classes]. Objetos (ou _instâncias_) são criados usando a palavra-chave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Uma função dentro de uma classe é chamada de _método_. Cada [método][methods] pode ter zero ou mais parâmetros. Todos os parâmetros precisam ter o tipo especificado explicitamente; não há inferência de tipo para parâmetros. Da mesma forma, o tipo de retorno também precisa ser explícito. Os valores são retornados dos métodos usando a [palavra-chave `return`][return]. Para permitir que um método seja chamado por código em outros arquivos, é preciso adicionar o modificador de acesso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Os métodos são invocados usando a sintaxe de ponto (`.`) em uma instância, especificando o nome do método a chamar e passando argumentos para cada um dos parâmetros do método. Os argumentos podem, opcionalmente, especificar o nome do parâmetro correspondente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Se o método a ser chamado estiver definido na mesma classe que o método que o chama, o nome da classe pode ser omitido.

Se um método não usa nenhum _estado_ de objeto, o método pode se tornar _estático_ usando o modificador `static`. Métodos estáticos também são invocados usando a sintaxe de ponto (`.`), mas são invocados na própria classe em vez de em uma instância da classe.

Se uma classe só tem métodos estáticos, ela também pode se tornar estática usando o modificador `static`. Isso expressa a intenção da classe.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

O escopo em C# é definido entre os caracteres `{` e `}`.

C# oferece suporte a dois tipos de [comentários][comments]. Comentários de linha única são precedidos por `//` e comentários de várias linhas são inseridos entre `/*` e `*/`.

Valores inteiros são definidos como um ou mais dígitos (consecutivos) e oferecem suporte aos [operadores matemáticos padrão][operators].

O nome de uma variável [precisa seguir algumas regras][identifier-names], como começar com uma letra ou um sublinhado, e [deve seguir a convenção de nomenclatura do C#][naming-guidelines]. Se um nome de variável entrar em conflito com uma [palavra-chave do C#][csharp-keywords] reservada, ele precisa ser escapado usando `@`. O uso dessa notação não é recomendado, mas pode ser encontrado em casos excepcionais, por exemplo: `var @this`, `var @class` ou `var @var`.

Existem dois conceitos tão fundamentais para uma linguagem da família C como o C# que eles aparecem naturalmente em quase qualquer trecho de código não trivial. São eles [mutação][mutation] e [escopo][scope]. A mutação é a ideia de que uma variável pode ter seu valor alterado ao longo da vida de um programa. O escopo é a ideia de que o valor associado a um nome (de um elemento do programa) só é acessível dentro da “área” de código onde ele é definido. As principais áreas de código em C# são _classe/struct_ e _função_ (normalmente métodos), mas também podem incluir o corpo dos laços e de outras construções.
