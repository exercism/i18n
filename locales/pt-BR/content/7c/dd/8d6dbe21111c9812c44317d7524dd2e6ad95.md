# Sobre

## Opcionais

O Swift usa [_opcionais_][optionals] para permitir que os programadores representem a possível ausência de um valor.
Um opcional é um tipo que pode conter um valor ou ser [`nil`][nil], que representa a ausência de um valor.
Usar um opcional exige que o programa verifique se um valor existe antes de usá-lo, depois de desembrulhá-lo.

Qualquer tipo pode se tornar um opcional acrescentando um `?` ao final do nome do tipo.
Assim, um inteiro opcional teria o tipo `Int?` e uma string opcional teria o tipo `String?`.
Definir constantes ou variáveis de tipo opcional e atribuir valores a elas funciona igual a atribuir valores de tipos não opcionais.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

Você pode atribuir a ausência de um valor a uma variável de tipo opcional atribuindo a ela o valor especial `nil`.
O `nil` pode ser usado com todos os tipos opcionais, mas `nil`s atribuídos a dois tipos opcionais diferentes não têm o mesmo tipo e não podem ser trocados nem sequer comparados.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

Repare também que, embora o `nil` possa ser atribuído a qualquer tipo opcional, ele não pode ser atribuído a um tipo não opcional (mesmo que esse tipo não contenha `nil` de fato).
E métodos que esperam um tipo não opcional não podem receber um tipo opcional sem que ele seja desembrulhado antes.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## Usando opcionais

Como os tipos opcionais não são os mesmos que seus tipos base, os dois tipos não podem ser usados da mesma forma.
Por exemplo: `Int("123") + 1` resulta em um erro do compilador: "Value of optional type 'Int?' must be unwrapped to a value of type 'Int'".
Isso acontece porque `Int("123")` retorna um tipo `Int?` opcional, e não um tipo `Int`, já que, se a string não puder ser convertida em um inteiro, o resultado será `nil`.
Para acessar o `Int` resultante da conversão, é preciso primeiro "desembrulhá-lo".

No Swift, isso costuma ser feito com as construções `if-let` e `guard-let` da [_vinculação opcional_][optional-binding], que verificam se o valor é `nil` e, quando existe um valor, seguem um caminho de código com o valor desembrulhado vinculado a um nome fornecido, e, quando encontram `nil`, seguem um caminho diferente.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

Vale notar que a variável `safeNum` tem o tipo `Int`, e não `Int?`.
No exemplo abaixo, `num` é do tipo `Int?` e `safeNum` é do tipo `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

Essa _vinculação opcional_ é importante porque desembrulha (ou "remove") o tipo opcional do valor, permitindo que ele seja usado como um valor não opcional.
Se você apenas verificar se o valor é `nil`, o valor continuará sendo de tipo opcional:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

A opção `guard-let` também pode ser usada nos casos em que você quer retornar antes:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## Comparando opcionais

Repare que, mesmo que o tipo base de um par de opcionais possa ser comparado com os operadores de comparação padrão, os opcionais em si não podem ser comparados.
Eles só podem ser verificados quanto à igualdade.
Dois opcionais são iguais se ambos forem `nil` ou se os valores que eles envolvem forem iguais dentro de seus tipos base.

No entanto, é possível escrever código para fazer uma comparação personalizada de dois valores opcionais.
Abaixo há um exemplo de uma instrução `switch` que retorna `true` somente se ambos os valores opcionais não forem `nil` e o primeiro valor for menor que o segundo.
Para isso, ela usa o _padrão opcional_ `varName?`, que só corresponde a opcionais não `nil`, vinculando o valor dentro do opcional ao nome `varName`.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
