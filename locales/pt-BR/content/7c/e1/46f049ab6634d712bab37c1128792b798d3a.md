# Sobre

C é uma linguagem de propósito geral, usada em uma ampla variedade de aplicações, de computadores embarcados a clusters de computação de alto desempenho.

C é comum em aplicações de baixo nível, pois é uma boa alternativa às linguagens assembly mais difíceis de ler.
É possível compilar C para assembly para manter o mesmo nível de desempenho, aumentando a legibilidade e oferecendo um pouco de segurança com tipos estáticos!

C foi criada por Dennis Ritchie nos Bell Labs e usada para reimplementar o sistema operacional Unix.
Hoje, é uma das linguagens de programação mais usadas, com muitos compiladores que oferecem suporte à maioria do hardware e das plataformas disponíveis. Há muitos recursos e suporte disponíveis para ajudar você a começar!
