# Promoção de propriedades no construtor

Em classes que declaram muitas propriedades, declarar a classe, suas propriedades e um construtor para definir as propriedades separadamente exige repetição.
Com a promoção de propriedades no construtor, podemos reduzir essa repetição.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
