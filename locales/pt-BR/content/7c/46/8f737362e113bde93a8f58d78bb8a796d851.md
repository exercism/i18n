# Introdução

Variáveis declaradas com a palavra-chave `final` em vez de `var` só podem receber um valor uma vez.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```
