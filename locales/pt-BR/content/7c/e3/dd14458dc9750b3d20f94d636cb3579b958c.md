# Sobre

Uma extensão estática permite pseudo-estender tipos existentes sem modificar o código-fonte deles. Isso é feito usando a instrução `using`. As extensões estáticas podem ser uma ferramenta poderosa que permite ampliar tipos sem realmente alterá-los.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
