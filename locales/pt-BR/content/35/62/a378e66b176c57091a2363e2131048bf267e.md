# Dicas

## Instruções específicas da trilha

Tente evitar repetição de código e use funções auxiliares privadas se puder.

E você pode considerar usar uma única expressão `Boolean` em vez de `if-else` para melhorar a legibilidade.
Veja [aqui](http://cs.wellesley.edu/~cs111/spring00/lectures/boolean-simplification.html) como isso pode ser feito (o link é para Java, mas é claro que a lógica vale para Scala também).
