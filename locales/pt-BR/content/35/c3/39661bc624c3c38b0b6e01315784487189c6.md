# Instruções

Neste exercício, você vai escrever um pouco de código para ajudar na sua preparação para comprar um veículo.

Você tem três tarefas: determinar se vai precisar tirar uma carteira de motorista; escolher entre dois veículos; e estimar um preço aceitável para um veículo usado.

## 1. Determine se você vai precisar de uma carteira de motorista

Alguns tipos de veículos exigem carteira de motorista para serem conduzidos.
Considere que apenas os tipos `"car"` e `"truck"` exigem carteira; todo o resto pode ser conduzido sem carteira.

Implemente a função `needs_license`, que recebe o tipo de veículo e retorna um Boolean indicando se você precisa de carteira para aquele tipo de veículo.

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. Escolha entre dois possíveis veículos para comprar

Você avaliou suas opções de veículos disponíveis.
Você conseguiu reduzir tudo a duas opções, mas precisa de ajuda para tomar a decisão final.
Implemente a função `choose_vehicle`, que recebe como entrada um array de dois veículos e retorna uma decisão, que é a opção que vem primeiro na ordem alfabética.

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcule uma estimativa para o preço de um veículo usado

Agora que você tomou sua decisão, você quer garantir um preço justo na concessionária.
Como você está interessado em comprar um veículo usado, o preço depende de quantos anos o veículo tem.
Para uma estimativa aproximada, considere que, se o veículo tiver menos de 3 anos, ele custa 80% do preço original que tinha quando era novo.
Se tiver mais de 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos, mas não mais de 10 anos, custa 70% do preço original.

Implemente a função `resell_price`, que aplica essa lógica usando `if`, `elif` e `else`.
Ela recebe um objeto com o preço original e a idade do veículo e retorna o preço estimado na concessionária.

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
