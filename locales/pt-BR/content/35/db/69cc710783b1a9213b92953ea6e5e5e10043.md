# gofmt não foi usado

Rode `gofmt` na solução, o que ajuda a formatar o código em Go.

A formatação de código em Go é muito importante para a comunidade.
A maioria das IDEs pode ser configurada para formatar o código automaticamente a cada salvamento. Por exemplo:

- O Visual Studio Code tem [um ótimo suporte a Go](https://code.visualstudio.com/docs/languages/go)
- O Vim também tem uma [extensão fantástica para Go](https://github.com/fatih/vim-go)
- O [Jetbrains Goland](https://www.jetbrains.com/go/) é uma IDE completa para Go

Para rodar `gofmt` manualmente:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

%{gofmt}
