# Introdução

Este exercício discute alguns detalhes dos parâmetros de método e do uso deles em C#.

Os parâmetros transmitem informações de um método que faz a chamada para um método chamado.

- O comportamento dos parâmetros pode ser modificado com o uso de modificadores como `ref` e `out`.

- Um parâmetro com o modificador `out` transmite um valor de volta do método chamado para quem fez a chamada. O parâmetro pode ser passado ao método chamado sem estar inicializado e, em qualquer caso, dentro do método chamado ele é tratado como se não tivesse sido inicializado na entrada. Entender o comportamento e as regras sobre os modificadores de parâmetro fica bem mais fácil com exemplos (veja abaixo) e com mensagens do compilador.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Os parâmetros `out` precisam receber uma atribuição dentro do método chamado.

- Um parâmetro com o modificador `ref` passa um valor para o método chamado. Quando o método retorna, quem fez a chamada vai encontrar nesse parâmetro todas as atualizações feitas pelo método chamado.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Os parâmetros `ref` precisam ser variáveis, já que o método chamado vai operar diretamente sobre o parâmetro tal como quem fez a chamada o vê.
- Os modificadores `out` e `ref` são obrigatórios tanto na assinatura do método chamado quanto no momento da chamada.
