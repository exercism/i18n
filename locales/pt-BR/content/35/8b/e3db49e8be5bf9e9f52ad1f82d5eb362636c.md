# Sobre

Os caracteres de Factor são *inteiros* (pontos de código Unicode), então os `<`, `>`, `=` numéricos simples já oferecem uma ordenação que diferencia maiúsculas de minúsculas. O vocabulário [`unicode`][unicode] acrescenta predicados que entendem Unicode e conversão de maiúsculas e minúsculas de caracteres individuais.

## Predicados

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## Conversão de maiúsculas e minúsculas

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

As `>upper`, `>lower` e `>title` no nível da string aplicam essas conversões a cada caractere de uma string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
