# Integrações do Babashka com editores de texto

## nREPL

### Emacs: [CIDER](https://cider.mx/)

Este é o que deu início a tudo, e seu ecossistema [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) alimenta muitos dos outros plug-ins.

1. Instale o [Emacs](https://www.gnu.org/software/emacs/download.html) para a sua plataforma.

2. Escolha uma distribuição Emacs existente ([Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/) e [Doom Emacs](https://github.com/hlissner/doom-emacs) são todas ótimas opções) ou adicione isto ao seu `init.el`:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

Resumido da [documentação do CIDER](https://docs.cider.mx/cider/platforms/babashka.html):

Inicie o servidor nREPL a partir do diretório do projeto:

```bash
$ bb --nrepl-server
```

Crie ou abra qualquer arquivo Clojure (`.clj`) com `C-x C-f` e conecte-se a ele usando `C-c C-x c j` (cider-connect-clj).

Os [atalhos básicos do CIDER](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` ou `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` ou `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. Instale o [VSCode](https://code.visualstudio.com/).

2. Instale o [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva).

No momento, o Calva entende que o seu código-fonte está no contexto de uma pasta, ou seja, de um projeto Clojure. Uma boa forma de criar um é com o [clj-new](https://github.com/seancorfield/clj-new):

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. Inicie o servidor nREPL a partir do diretório do projeto:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

Abra a pasta do projeto no VSCode (Ctrl+K Ctrl+O) ou em outro terminal:

```bash
$ cd bbtest
bbtest$ code .
```

4. No VSCode, execute o comando do Calva `Connect to a running REPL` (ctrl+alt+c ctrl+alt+c). Quando for solicitado, escolha o projeto `Generic` e digite `localhost:1667`.

Comandos do REPL:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. Baixe o IntelliJ [aqui](https://www.jetbrains.com/idea/download/index.html).
2. Instale o Cursive seguindo o [guia do usuário](https://cursive-ide.com/userguide/) e [configure as dependências](https://cursive-ide.com/userguide/deps.html).
3. Consulte [Cursive: Working with Babashka](https://cursive-ide.com/userguide/babashka.html) para mais informações.

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. Instale o [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. Instale o pacote `chlorine`

3. Inicie o Socket REPL:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Abra a paleta de comandos do Atom (ctrl+shift+p) e execute o comando `Connect Clojure Socket REPL` com `localhost` `1666`

5. Edite os atalhos de teclado em keymap.cson pelo menu `Edit` -> `Keymap...`:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Para o Emacs, instale o [inf-clojure](https://github.com/clojure-emacs/inf-clojure) adicionando isto ao seu `init.el`:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

Inicie o socket REPL como acima e, no Emacs, execute `M-x inf-clojure-connect` (C-c M-c).

Avalie as formas com C-c C-e. Para ver uma lista de todos os comandos disponíveis no inf-clojure-mode (também conhecido como o REPL) e no inf-clojure-minor-mode, você pode invocar C-h f RET inf-clojure-mode e C-h f RET inf-clojure-minor-mode, ou simplesmente navegar pelos menus deles.

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

Baixe o [appimage do Neovim](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) e crie um alias para `vim`.

* Instale o [vim-plug](https://github.com/junegunn/vim-plug):

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

Crie o arquivo `~/.config/nvim/init.vim`:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Abra o Neovim e execute o comando `:PlugInstall`.

Adicione o comando `iced` ao $PATH:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* Inicie o servidor socket REPL, abra o arquivo-fonte e execute `:IcedConnectSocketRepl 1666`.

Comandos padrão do REPL (o `<Leader>` padrão é `\`):

- `<Leader>ei` : Avaliar o elemento interno
- `<Leader>ee` : Avaliar a lista externa
- `<Leader>et` : Avaliar a lista externa de nível superior
