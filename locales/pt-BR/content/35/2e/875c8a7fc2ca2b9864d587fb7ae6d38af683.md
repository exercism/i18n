# Introdução

Para compartilhar código entre diferentes módulos do Elixir dentro do mesmo projeto, você precisa fazer referência ao módulo externo pelo nome completo. Mas e se esse nome for longo ou confuso demais?

A forma especial `alias` permite encurtar ou alterar o nome pelo qual você faz referência a um módulo externo. Quando usada sem nenhum argumento, ela reduz o nome do módulo ao seu último segmento, por exemplo: `MyApp.Logger.Settings` vira `Settings`. Um nome personalizado pode ser especificado com a opção `:as`.

Normalmente, os aliases são adicionados no começo da definição do módulo.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```
