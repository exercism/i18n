# Instruções

Neste exercício, você vai ajudar um casal de namorados do colégio a declarar seu amor nas redes sociais.

## 1. Exiba o nome do casal separado por um coração

Implemente o método estático `HighSchoolSweethearts.DisplaySingleLine()` para receber dois nomes e exibi-los separados por um coração.
O texto formatado deve ter 61 caracteres de largura, com o coração no centro da string.

É garantido que todos os nomes vão caber tranquilamente na largura da linha.

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. Exiba as iniciais do casal em um coração em arte ascii

Implemente o método estático `HighSchoolSweethearts.DisplayBanner()`, que exibe os dois conjuntos de iniciais separados por um sinal de mais.

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
// see the ascii art below
```

## 3. Estudantes de intercâmbio alemães devem se sentir em casa com declarações sensíveis à localidade.

Implemente o método estático `HighSchoolSweethearts.DisplayGermanExchangeStudents()` para mostrar a data de início do relacionamento e o tempo de duração para nossos estudantes de intercâmbio alemães.

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
