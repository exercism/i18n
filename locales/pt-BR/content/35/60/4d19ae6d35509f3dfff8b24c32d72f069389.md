# Introdução

Quando uma quotation precisa *lembrar* valores do ambiente ao redor, o que outras linguagens chamam de *closure*, Factor usa duas ferramentas: a palavra `curry` e a sintaxe *fry* `'[ ]`.

## `curry`: capturar um valor

`curry` (em [`kernel`][kernel]) recebe um valor e uma quotation e retorna uma nova quotation com esse valor embutido:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

Aplique `curry` duas vezes para capturar dois valores:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: unir duas quotations

`compose` (em [`kernel`][kernel]) junta duas quotations:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Quotations com fry: capturar vários valores

Para mais de uma ou duas capturas, chamadas encadeadas de `curry` ficam difíceis de ler. O *fry* usa `'[ … ]` com um ou mais placeholders `_`; cada `_` é substituído por um valor retirado da pilha de dados, na ordem:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

Tanto `curry` quanto fry *consomem* seus valores da pilha no momento em que a closure é construída. A linha acima não deixa nada na pilha e é um substituto direto de `[ + + ] curry curry`.

Os placeholders são preenchidos da esquerda para a direita com os valores da pilha de baixo para cima: `2 3 '[ _ _ ]` é `[ 2 3 ]`, não `[ 3 2 ]`.

Fry também alcança *dentro* de quotations aninhadas, o que permite colocar os valores capturados exatamente onde você quiser:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

O `_` fica dentro do `[ … ]` interno, mas fry ainda o preenche.

## `call` com um efeito declarado

Quando você finalmente rodar uma quotation armazenada, declare seu efeito de pilha em `call` para que o compilador possa verificar os tipos:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## Aritmética de vetores

O vocabulário [`math.vectors`][math.vectors] combina duas sequências de mesmo comprimento elemento a elemento. `v+` e `v*` as somam ou multiplicam; `vmax` e `vmin` mantêm o maior ou o menor de cada componente. Cada um retorna um array de 2 elementos:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
