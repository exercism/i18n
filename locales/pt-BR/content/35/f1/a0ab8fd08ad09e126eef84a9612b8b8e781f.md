# Introdução

## Compreensões de listas

As compreensões oferecem um recurso para transformar _Enumerables_ de forma fácil e declarativa.

Para declarar uma compreensão bem simples, podemos usar a palavra-chave `for` seguida de um _gerador_ e de um _bloco do_, que cria os novos valores a partir dos valores enumerados.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

As compreensões também podem ter _filtros_. Os valores que não passam pelo filtro são removidos da lista final:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Podemos declarar compreensões mais complicadas ao longo de várias linhas:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

Um _produto cartesiano_ pode ser criado usando vários geradores. Isso significa que cada valor gerado pelo primeiro gerador será pareado uma vez com cada valor gerado pelo segundo gerador:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
