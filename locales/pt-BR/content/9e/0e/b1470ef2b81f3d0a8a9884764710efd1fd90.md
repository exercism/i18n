# Sobre

[Intervalos][range] representam uma sequência de um ou vários números inteiros consecutivos. Eles:

- São criados usando o [operador `..`][range-operator] e podem ser tanto crescentes quanto decrescentes.
- O passo padrão deles é `1`, mas pode ser modificado usando o [operador `..//`][range-operator-with-step] (desde o Elixir 1.12).
- Incluem os valores inicial e final.
- Implementam o [_protocolo Enumerable_][enumerable].
- São representados internamente como um struct, mas é possível fazer pattern matching com eles usando `..`.
- Podem ser usados com inteiros escritos nas notações binária, octal, hexadecimal e de code point.
- Podem ser transformados em listas com funções como [`Enum.to_list/1`][enum-to-list] ou [`Enum.map/2`][enum-map].

```elixir
Enum.to_list(9..1)
# => [9, 8, 7, 6, 5, 4, 3, 2, 1]

Enum.map(?A..?F, &<<&1>>)
["A", "B", "C", "D", "E", "F"]
```
