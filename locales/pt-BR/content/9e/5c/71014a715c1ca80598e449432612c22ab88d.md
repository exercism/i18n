# Dicas

## Geral

- [The Cairo Book: ByteArrays][book-bytearrays]
- [Starknet By Example: Strings & ByteArrays][sbe-strings]

### 1. Formate um canto mágico

- Use a macro `format!` para combinar várias entradas do tipo `ByteArray` em uma única string.
- Separe os cantos com um delimitador como `"-"` para que a saída corresponda à esperada.
- Garanta que a saída seja retornada como `ByteArray`.

### 2. Implemente o trait `Display` para `EchoStone`

- O trait `Display` permite definir como o `EchoStone` deve aparecer quando for impresso com `{}`.
- Use a macro `write!` dentro da função `fmt` para formatar a string de saída.
- Inclua os dois campos `power` e `duration` em um formato claro e conciso, por exemplo, `EchoStone [power: X, duration: Y]`.

### 3. Implemente o trait `Debug` para `EchoStone`

- O trait `Debug` é usado para fins de depuração, permitindo uma saída mais detalhada ou estruturada quando for impresso com `{:?}`.
- Siga um formato claro de depuração, como `Debugging EchoStone: { power: X, duration: Y }`.
- Use a macro `write!` para criar a saída de depuração.
