# Dicas

## 1. Retorne uma lista com os nomes dos itens

- A [função `iterator.map`][map] pode ser usada para transformar os itens de um iterador.

## 2. Retorne os itens que forem baratos

- A [função `iterator.filter`][filter] pode ser usada para remover alguns itens de um iterador.

## 3. Retorne os itens que estiverem fora de estoque

- A [função `iterator.filter`][filter] pode ser usada para remover alguns itens de um iterador.

## 4. Retorne o estoque total

- A [função `iterator.fold`][fold] pode ser usada para reduzir um iterador a um único valor.
