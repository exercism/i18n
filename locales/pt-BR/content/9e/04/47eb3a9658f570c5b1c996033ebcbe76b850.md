# Testes

## Testando de forma interativa

Inicie sua implementação de Common Lisp no diretório do exercício em que você está trabalhando (ou mude o diretório atual de uma implementação de Common Lisp já em execução para esse diretório).
Usando o roswell, faça isso com `ros run`.

(Todos os exemplos aqui assumem um exercício chamado `exercise-name`; ajuste conforme necessário.)

Carregue o arquivo de teste na sua implementação Lisp em execução, por exemplo, `(load "exercise-name-test")`.
(Isso também vai carregar o arquivo de solução para você.)
Depois que o arquivo de teste for carregado, você pode rodar os testes avaliando `(exercise-name-test:run-tests)` no REPL.

À medida que você faz mudanças na solução que está escrevendo, use a funcionalidade do seu editor para carregar as mudanças ou avalie `(load "exercise-name")` para carregar o arquivo da sua solução.

Lembre-se de avaliar `(exercise-name-test:run-tests)` para rodar os testes de novo depois de carregar sua solução atualizada.

## Testando pela linha de comando

Você pode iniciar os testes com esta invocação na linha de comando (de novo, substitua "exercise" pelo nome adequado em dois lugares)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

Esse comando é bem complicado.
Um contribuidor escreveu algumas notas sobre [como deixar a invocação mais fácil](https://glennj.github.io/exercism/cli).
