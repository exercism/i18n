# Instruções

Neste exercício, você trabalha em uma pizzaria que faz entregas para os clientes.

Você oferece três tipos de pizza:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

Os clientes também podem escolher duas opções adicionais por uma pequena taxa extra:

1. Molho extra: \$1
1. Coberturas extras: \$2

Quando os clientes fazem um pedido, uma taxa adicional é cobrada se eles pedirem apenas uma ou duas pizzas:

- 1 pizza: \$3
- 2 pizzas: \$2

Você tem três tarefas, e cada uma delas trabalha com pizzas e seus preços.

## 1. Defina os tipos de pizza e as opções

Defina a união discriminada `Pizza` para representar os tipos de pizza e as duas opções adicionais que podem ser adicionadas a uma pizza:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. Calcule o preço da pizza

Implemente a função `pizzaPrice` para calcular o preço de uma pizza:

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. Calcule o preço de um pedido

Implemente a função `orderPrice` para calcular o preço de um pedido de pizza:

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
