# Instruções

A Jen trabalha na sala de triagem de uma grande fábrica.
A sala de triagem precisa processar tudo o que chega até ela, categorizando cada item com um rótulo.
A Jen é responsável pelas coisas que foram pré-categorizadas como números e precisa de um programa para ajudá-la com a triagem.

A maioria dos valores primitivos deve receber rótulos diretos.
Para números, ela quer strings dizendo `"This is the number 2.0"` (se o número era 2).
A Jen quer a mesma saída para inteiros e números de ponto flutuante.

Existem algumas interfaces `Box` que precisam ser desembrulhadas para obter seu conteúdo.
Para um `NumberBox`, ela quer strings dizendo `"This is a box containing the number 3.0"` (se o método `Number()` retornar 3).
Para um `FancyNumberBox`, ela quer strings dizendo `"This is a fancy box containing the number 4.0"`, mas apenas se o tipo for um `FancyNumber`.

Qualquer coisa inesperada deve dizer `"Return to sender"`, para que a Jen possa devolvê-la de onde veio.

## 1. Descreva números simples

A Jen quer que os números retornem strings como `"This is the number 2.0"` (incluindo um dígito depois do ponto decimal):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Descreva uma caixa de número

A Jen quer que as caixas de número retornem strings como `"This is a box containing the number 2.0"` (de novo, incluindo um dígito depois do ponto decimal):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Implemente um método que extrai o número de uma caixa de número chique

A Jen precisa de uma função auxiliar para extrair o número de um `FancyNumberBox`.
Se o `FancyNumberBox` for um `FancyNumber`, extraia seu valor e converta-o de `string` para `int`.
Qualquer outro tipo de `FancyNumberBox` deve retornar 0.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Descreva uma caixa de número chique

Se o `FancyNumberBox` for um `FancyNumber`, a Jen quer strings dizendo `"This is a fancy box containing the number 4.0"`.
Qualquer outro tipo de `FancyNumberBox` deve dizer `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

OBSERVAÇÃO: devemos usar a função `ExtractFancyNumber`!

## 5. Implemente `DescribeAnything`, que usa todas elas

Essa é a função principal de que a Jen precisa, e ela recebe qualquer entrada.
`DescribeAnything` deve delegar para as outras funções com base no tipo do valor passado.
Mais especificamente:

- Tanto `int` quanto `float64` devem delegar para `DescribeNumber`
- `NumberBox` deve delegar para `DescribeNumberBox`
- `FancyNumberBox` deve delegar para `DescribeFancyNumberBox`
- qualquer outra coisa deve resultar em `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
