# Anexo às instruções

## Dicas

Para este exercício, o seguinte recurso do F# é bastante útil:

- O tipo [Map](https://en.wikibooks.org/wiki/F_Sharp_Programming/Sets_and_Maps#Maps) associa chaves a valores. Ele é muito parecido com o tipo `Dictionary<TKey, TValue>` do .NET, mas com uma diferença fundamental: `Map` é [imutável](https://fsharpforfunandprofit.com/posts/correctness-immutability/).
- Uma [abreviação de tipo](https://fsharpforfunandprofit.com/posts/type-abbreviations/) é usada para criar um alias descritivo para um tipo mais complexo.
