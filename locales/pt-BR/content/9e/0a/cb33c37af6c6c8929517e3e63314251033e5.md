# Instruções

Os Aliens de Lisp gostam de comemorar aniversários.
Para eles, uma data de aniversário importante é o Gigasecond.
Ou seja: 1.000.000.000 segundos desde o evento.

## 1. Calcule a data do aniversário do Gigasecond

Escreva uma função `from` que recebe 6 parâmetros: `year`, `month`, `day`, `hour`, `min`, `sec`, e calcula a data e a hora do aniversário do Gigasecond.
Essa função deve retornar a data como uma lista, com a mesma ordem e o mesmo significado dos parâmetros da entrada.

```
(from 2000 1 1 0 0 0) ; => (2031 9 9 1 46 40)
```
