# Sobre

Em JavaScript, um array (ou vetor) é uma estrutura semelhante a uma lista, sem comprimento fixo, que pode guardar qualquer tipo de primitivo ou objeto, até mesmo tipos mistos.
Ele inclui a propriedade `length` e também vários [métodos úteis][array-docs] para percorrer e modificar o array.

Para criar um array, adicione elementos entre colchetes `[]`.
Para ler do array, coloque o índice entre colchetes `[]` depois do identificador. Os índices de um array começam em zero.

Por exemplo:

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
names[1];
// => Laura
```

Arrays também podem ser criados com a sintaxe de construtor, mas, para a maioria dos usos, recomenda-se a sintaxe de literal de array.

```javascript
const names = new Array();
names.push('Jack', 'Laura', 'Paul', 'Megan');

names[1];
// => Laura
```

Arrays não podem usar `strings` como índices de elementos, é preciso usar números inteiros ([`number`][concept-numbers]).
Definir ou acessar valores não inteiros usando a notação de colchetes (ou a notação de ponto) não define nem recupera um elemento da própria lista do array, mas define ou acessa uma variável associada à coleção de propriedades do objeto desse array.
As propriedades de objeto do array e a lista de elementos do array são coisas separadas, e as operações de percurso e modificação do array não podem ser aplicadas a essas propriedades nomeadas.

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
names.length;
// => 4

// Properties can be set on arrays using bracket ['property'] or
// dot .property notation, and this will affect the length, as
// shown below.

names.magician = 'Elyse';
names.length;
// => 4

// The property shows up when logging the array, making it seem
// that the property is somehow incorporated in the array.

names;
// => ["Jack", "Laura", "Paul", "Megan", magician: "Elyse"]

// However, be aware. Properties added via non-numeric keys are
// NOT part of the array's internal list, and are not traversed
// or mutated when using one of the traversal or mutation
// operations.

names.forEach((name) => console.log(name));
// => Jack
// => Laura
// => Paul
// => Megan
```

## Excluir itens de um array

Em JavaScript, arrays são `objects` comuns, e itens podem ser excluídos com a palavra-chave `delete`.
No entanto, isso não muda o _length_ do array e deixa um buraco `empty`.
Em outras linguagens, isso é semelhante a um array esparso.
Os buracos `empty` são ignorados ao usar operações de percurso ou modificação.

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
delete names[1];

names;
// =>  ["Jack", empty, "Paul", "Megan"]

names.length;
// => 4

names.forEach((name) => console.log(name));
// => Jack
// => Paul
// => Megan
```

Se não deve haver buracos, e se o `length` deve refletir o número de itens que serão percorridos ou modificados, use `splice` em vez disso.

> O método splice() altera o conteúdo de um array removendo ou substituindo elementos existentes e/ou adicionando novos elementos no lugar.[^5]

Por exemplo:

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
names.splice(1, 1);

names;
// =>  ["Jack", "Paul", "Megan"]

names.length;
// => 3

names.forEach((name) => console.log(name));
// => Jack
// => Paul
// => Megan
```

## O comprimento de um array pode ser modificado

A propriedade `length` de um array está ligada à lista de itens que o array guarda.
Ela pode ser modificada.
Quando o comprimento aumenta, são criados buracos `empty`, que não são considerados ao percorrer ou modificar o array.
Quando o comprimento diminui, os elementos no final do array são _removidos_.

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
names.length = 6;

names;
// => ["Jack", "Laura", "Paul", "Megan", empty × 2]

names.length = 2;
// =>  ["Jack", "Laura"]
```

## Verificar se algo é um array

Como arrays são `objects`, `typeof names` retorna `"object"`.
Para verificar se algo é um array, use `Array.isArray`:

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];

typeof names;
// => "object"

Array.isArray(names);
// => true

const object = {};
Array.isArray(object);
// => false
```

Talvez dê vontade de usar `names instanceof Array`, e isso pode funcionar, mas não em todas as circunstâncias.
Leia [este artigo][instanceof-vs-array-is-array] para saber mais.

## Métodos de array

Alguns dos [métodos][array_methods] disponíveis em todo objeto Array podem ser usados para adicionar ou remover itens do array.
Aqui estão alguns deles:

### push

> O método `push()` adiciona um ou mais elementos ao final de um array e retorna o novo comprimento do array.[^1]

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
names.push('Jill'); // => 5
names;
// => ['Jack', 'Laura', 'Paul', 'Megan', 'Jill']
```

### pop

> O método `pop()` remove o último elemento de um array e retorna esse elemento.
> Esse método altera o comprimento do array.[^2]

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
names.pop(); // => 'Megan'
names;
// => ['Jack', 'Laura', 'Paul']
```

### shift

> O método `shift()` remove o primeiro elemento de um array e retorna esse elemento removido.
> Esse método altera o comprimento do array.[^3]

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
names.shift(); // => 'Jack'
names;
// => ['Laura', 'Paul', 'Megan']
```

### unshift

> O método unshift() adiciona um ou mais elementos ao início de um array e retorna o novo comprimento do array.[^4]

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
names.unshift('Jill'); // => 5
names;
// => ['Jill', 'Jack', 'Laura', 'Paul', 'Megan']
```

### splice

> O método splice() altera o conteúdo de um array removendo ou substituindo elementos existentes e/ou adicionando novos elementos no lugar.
> Esse método retorna um array contendo os elementos excluídos.[^5]

```javascript
const names = ['Jack', 'Laura', 'Paul', 'Megan'];
names.splice(2, 1, 'Jill'); // => ['Paul']
names;
// => ['Jack', 'Laura', 'Jill', 'Megan']
```
