## Boolean

Raku tem os literais Boolean `True` e `False`.
Em contexto Boolean, qualquer coisa indefinida é considerada `False`.
Além do próprio `Bool::False`, valores definidos considerados `False` incluem `0`, `NaN`, `()` (lista vazia), `""` (string vazia) e objetos do tipo `Failure`.

O operador [prefixo `?`][&prefix:<?>] força um contexto Boolean sobre um objeto.
O comportamento dele é o mesmo de chamar o método [`Bool`][routine/Bool] nesse objeto.
O operador [prefixo `!`][&prefix:<!>] dá o inverso do prefixo `?`.

## Operadores infixos Boolean

### Smartmatch

O operador [infixo `~~`][&infix:<~~>], também conhecido como smartmatch, é uma ferramenta muito usada em Raku.
O comportamento dele depende do objeto que aparece do lado direito do operador, já que ele é um atalho para o método [`ACCEPTS`][routine/ACCEPTS] desse objeto.
O valor do lado esquerdo é passado como argumento para `ACCEPTS`.
O resultado é um valor Boolean.

### AND/OR lógicos

Raku tem os operadores [`&&`][&infix:<&&>]/[`and`][&infix:<and>], [`||`][&infix:<||>]/[`or`][&infix:<or>], [`//`][&infix:<//>]/[`orelse`][&infix:<orelse>] e [`^^`][&infix:<^^>]/[`xor`][&infix:<xor>] para lógica Boolean (precedência mais alta e mais baixa, respectivamente).
Eles podem ser encadeados.

```raku
1 xor 1 xor 1;
# Nil in Raku, 1 in Perl (because the latter makes the first pair false).
```

### Ternário

Raku tem um operador [infixo `?? !!`][infix-??-!!] ternário/condicional, que se escreve como `$condition ?? $true !! $false`.

## Fluxo de controle

### if/elsif/else

Uma [`if`][control-if] condicional serve para rodar um bloco de código sob certas condições.
Para criar uma condicional `if`, a palavra-chave `if` é seguida de uma [expressão][statements-and-expressions] e depois de um [bloco][control-block].

A expressão é avaliada em [contexto Boolean][contexts-boolean], e o bloco é executado se a expressão resultar em `True`.

Uma condicional `if` pode ser estendida com as palavras-chave [`elsif` e `else`][control-else/elsif], escritas da mesma forma que `if`. Um bloco `else` é executado se todas as expressões anteriores resultarem em `False`, e um bloco `elsif` é executado da mesma forma, se a própria expressão dele resultar em `True`.

Como alternativa, `if` pode ser usado na forma de modificador de instrução:

```raku
say 'success' if True;
```

A forma de modificador de instrução não pode ser usada com `elsif` nem com `else`.

### given/when/default

A instrução [`given`][control-given] é a palavra-chave de topicalização do Raku, de forma parecida com a topicalização que `switch` faz em linguagens como C.
As palavras-chave para cada caso são [`when` e `default`][control-default-and-when].

### for/while/loop

Uma instrução [`for`][control-for] itera sobre uma lista e roda um bloco para cada item presente nessa lista.

Uma instrução [`while`][control-while] roda um bloco repetidamente enquanto a expressão dela resultar em `True`.

Uma instrução [`loop`][control-loop] pode ser escrita de duas formas.
Se receber apenas um bloco, ela roda esse bloco repetidamente até que algo interrompa o laço explicitamente.
Ela também pode ser escrita como um laço `for` no estilo C, com um inicializador, uma condição e um incremento entre parênteses antes do bloco.

```raku
loop (my $i = 0; $i < 10; $i++) {
    say $i;
}
```
