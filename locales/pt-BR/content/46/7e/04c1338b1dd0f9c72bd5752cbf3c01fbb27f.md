# Introdução

## Listas de palavras-chave

Listas de palavras-chave são uma estrutura de dados de chave-valor.

```elixir
[month: "April", year: 2018]
```

Listas de palavras-chave são listas de [tuplas][exercism-tuples] `{key, value}`, e também podem ser escritas dessa forma, mas a sintaxe mais curta é mais usada.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

As chaves em uma lista de palavras-chave precisam ser [átomos][exercism-atoms], mas os valores podem ser qualquer coisa. Cada chave pode ser usada mais de uma vez. Os pares de chave-valor em uma lista de palavras-chave são ordenados.

Você pode trabalhar com listas de palavras-chave usando as mesmas abordagens das listas, ou pode usar o módulo `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
