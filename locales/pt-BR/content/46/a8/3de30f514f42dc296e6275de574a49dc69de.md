# Módulos e caminhos em Cairo

O Cairo usa **módulos** para organizar o código.

Os módulos ajudam a estruturar projetos e a controlar a visibilidade de itens como funções, structs e traits.

## Definindo módulos

Os módulos são definidos com `mod` e podem ser aninhados:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

Funções, structs e traits são **privados por padrão**.

Use `pub` para que fiquem acessíveis fora do módulo.

## Caminhos: absolutos versus relativos

Para se referir a um item em outro módulo, você pode usar:

- **Caminhos absolutos** (começando em `crate::`):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Caminhos relativos** (começando no módulo atual):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Isso funciona se `front_of_house` estiver no mesmo módulo.

## Trazendo módulos para o escopo com `use`

Escrever caminhos completos repetidamente é inconveniente.

A palavra-chave `use` permite referências mais curtas:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

O `use` vale **apenas no escopo onde aparece**; se for necessário em outro lugar, ele precisa ser repetido.

### Uso idiomático do `use`

- Traga **módulos** para o escopo, não funções:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  Em vez de:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- Para **traits, structs e enums**, use o caminho completo:

  ```rust
  use core::num::traits::BitSize;
  ```

### Aliases com `as`

Renomeie importações quando for necessário:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Importando vários itens

Em vez de várias instruções `use`, agrupe as importações:

```rust
use shapes::{Square, Circle, Triangle};
```

## Reexportando com `pub use`

Para expor um módulo em uma estrutura diferente, use `pub use`:

```rust
pub use crate::front_of_house::hosting;
```

Agora o código externo pode usar `restaurant::hosting::add_to_waitlist()` em vez de `restaurant::front_of_house::hosting::add_to_waitlist()`.

## Usando pacotes externos com o Scarb

Para adicionar uma dependência, atualize o `Scarb.toml`:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Use `scarb add <package>` para adicionar dependências e `scarb rm <package>` para removê-las.

## O operador glob (`*`)

Para importar tudo de um módulo:

```rust
use core::num::traits::*;
```

Isso deve ser usado com cuidado, porque pode deixar o código mais difícil de ler.
