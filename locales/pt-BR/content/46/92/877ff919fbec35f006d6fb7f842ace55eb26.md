# Instruções

O mosaico do centro comunitário de artes terminou de ser instalado no mês passado, e agora a Magpie Marg o descobriu. Na maioria dos dias, ela troca uma pastilha ou outra por outras mais brilhantes do seu **tesouro** ali perto, ou arranca uma pastilha e some por uma hora.

É você quem se voluntariou para registrar cada mudança. O mosaico em si é um **array de tamanho fixo**: um espaço por posição de pastilha, guardando uma string de cor ou `f` para "ausente". O tesouro da Magpie Marg é um **vector** de pastilhas soltas que ela roubou.

## 1. Monte uma linha nova

Defina `fresh-mosaic` para receber um comprimento `n` e retornar um array de `n` espaços vazios (cada um `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Coloque uma pastilha

Defina `place-tile` para receber uma linha, uma posição e uma cor, e atualizar a linha no próprio lugar, de modo que a posição indicada passe a conter essa cor. A palavra não retorna nada.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Arranque uma pastilha

Defina `chip-tile` para receber uma linha e uma posição, e atualizar a linha no próprio lugar, de modo que a posição indicada volte a ser `f`.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Mude a cor de uma pastilha

Defina `recolour-tile` para receber uma linha, uma posição e uma quotation de um argumento, e atualizar a linha no próprio lugar aplicando a quotation à pastilha naquela posição.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Tire um snapshot antes de a Marg chegar

Defina `snapshot-mosaic` para receber uma linha e retornar uma cópia independente que não será afetada por mutações posteriores da original.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg guarda uma pastilha no bolso

Defina `stash-tile` para receber o tesouro da Marg (um vector) e uma cor, e acrescentar a cor ao tesouro. Não retorna nada.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg devolve uma pastilha

Defina `return-tile` para receber o tesouro da Marg e remover e retornar a pastilha guardada mais recentemente (a que está no topo).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
