# Operador ternário

Os _operadores ternários_ podem ser vistos como uma versão compacta do _if-else_.
Costumam ser usados em instruções de retorno (mas não só nelas): precisam de uma única linha para tomar a decisão, retornando o valor da esquerda se a expressão for `true` e o valor da direita se for `false`.

Muitas expressões simples de _if/else_ podem ser simplificadas com _operadores ternários_.

```java
// this ternary statement
return 5 > 4 ? true : false;

// is equivalent to this if/else
if ( 5 > 4 ) {
    return true;
} else {
    return false;
}
```

Então, como decidir entre _if-else_ e _ternário_?
Bem, os _operadores ternários_ são usados em cenários simples, quando você só precisa retornar um valor com base em uma condição e nenhum cálculo extra é necessário.
Use um _if-else_ para todo o resto, como condições aninhadas, expressões grandes ou quando for preciso mais de uma linha para decidir o valor de retorno.

Você até pode aninhar _operadores ternários_, mas o código costuma ficar difícil de ler.
Nesses casos, prefira `if`s aninhados.

```java
// hard to read
int value = expr1 ? expr2 && expr3 ? val1 : (val2 + val3) : expr4;

// easier to read
if (expr1){

    if (expr2 && expr3){

        return val1;
    }

    return val2 + val3;
}
return val4;


```

Os _operadores ternários_ e as instruções _if/else_ são um bom exemplo de que, na programação, você tem várias formas de chegar ao mesmo resultado.
