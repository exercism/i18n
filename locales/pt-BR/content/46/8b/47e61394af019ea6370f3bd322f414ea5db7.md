# Dicas

## 1. Começando do zero

- Para criar um array, você pode usar `make-array`.
- As dimensões de um array são especificadas como uma lista de `make-array`.
- Para definir todos os elementos com um valor inicial, use o parâmetro de palavra-chave `:inital-element`.

## 2. Partindo de um tabuleiro existente

- Para definir o conteúdo inicial de um array, use o parâmetro de palavra-chave `:initial-contents`.

## 3. Condição de vitória

- `aref` pode ser usado para obter o valor de uma casa de um array.
- `eq` pode ser usado para determinar se dois símbolos são iguais.
- `and` pode ser usado para combinar duas expressões `eq` para comparar três itens.

## 4. Em uma linha

- Os argumentos de `aref` (para um array bidimensional) são "linha" e "coluna".

## 5. Em uma coluna

- Os argumentos de `aref` (para um array bidimensional) são "linha" e "coluna".
