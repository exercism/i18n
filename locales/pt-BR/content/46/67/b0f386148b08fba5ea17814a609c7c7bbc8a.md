# Apêndice das instruções

## Registradores

| Registrador | Uso       | Tipo    | Descrição                                                  |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | entrada     | inteiro | categoria: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | entrada     | endereço | dados (array de palavras)                                  |
| `$v0`    | saída     | inteiro | pontuação resultante                                       |
| `$t0-9`  | temporário | qualquer | usados para armazenamento temporário                       |
