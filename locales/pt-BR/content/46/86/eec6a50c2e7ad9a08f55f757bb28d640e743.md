# Sobre

Swift é uma linguagem de programação compilada e multiparadigma, projetada com três objetivos principais:

- **Segurança**: recursos nativos da linguagem ajudam a detectar e prevenir bugs antes que seu code rode em produção.
- **Velocidade**: desempenho otimizado, comparável ao de linguagens baseadas em C.
- **Expressividade**: sintaxe limpa e moderna, agradável e fácil de ler e escrever.

A Apple lançou o Swift em 2014 como um substituto moderno para o Objective-C, a linguagem usada anteriormente no desenvolvimento para iOS e macOS.
Hoje, o Swift é open source e roda em plataformas da Apple, Linux e Windows.

## Primeiros passos

### Variáveis

Você pode armazenar e dar nome a valores definindo uma [variável][constants-variables].
Depois de definir uma variável, você pode usar o nome dela para se referir a esse valor em todo o seu code.
As variáveis são _mutáveis_, o que significa que seus valores podem mudar depois de definidas.

Defina uma variável com a palavra-chave `var`:

```swift
var variableName = 10
```

Swift é uma linguagem de tipagem estática, o que significa que todo valor tem um tipo conhecido em tempo de compilação.
Você pode declarar um tipo explicitamente com uma [anotação de tipo][type annotations], ou deixar o compilador do Swift [inferir o tipo][type-inferring] a partir do valor atribuído:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Você pode atualizar o valor de uma variável com o operador de atribuição (`=`):

~~~~exercism/note
O tipo de uma variável não pode mudar depois que ela for declarada.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Você pode declarar uma variável sem um valor inicial informando o tipo dela, mas precisa atribuir um valor antes de usá-la:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Constantes

As [constantes][constants-variables] também associam um nome a um valor, mas seus valores não podem ser alterados depois da atribuição.
Elas são _imutáveis_.
Defina uma constante com a palavra-chave `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Operadores aritméticos

Swift oferece os [operadores aritméticos][arithmetical-operators] padrão para a matemática básica:

- Adição: `+`
- Subtração: `-`
- Multiplicação: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Funções

Em Swift, as [funções][functions] são blocos de code autocontidos que executam uma tarefa específica.
As funções podem receber entradas, retornar um valor e ser passadas como valores para outras funções.
Defina uma função com a palavra-chave `func`, seguida do nome da função, de uma lista de parâmetros entre parênteses e de um tipo de retorno opcional:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

As funções em Swift usam [rótulos de argumento][argument-labels], que fazem o code parecer frases naturais:

- O **rótulo de argumento** é usado na chamada da função.
- O **nome do parâmetro** é usado dentro do corpo da função para acessar o valor.

Se você informar apenas um nome, o Swift o usa como rótulo de argumento e como nome do parâmetro:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Se você não quiser um rótulo de argumento na chamada da função, escreva um sublinhado (`_`) antes do nome do parâmetro:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Por padrão, todos os parâmetros de uma função são constantes (`let`), ou seja, seus valores não podem ser modificados dentro do corpo da função.

Para retornar um valor de uma função, informe o tipo de retorno depois de `->` e use a palavra-chave `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Quando uma função não retorna um valor, seu tipo de retorno é `Void` (equivalente a uma tupla vazia, `()`).
Nesses casos, você pode omitir tanto o tipo de retorno `-> Void` quanto a instrução `return`.

### Comentários

Swift oferece suporte a duas formas de [comentários][comments]:

- **Comentários de uma linha** começam com `//` e vão até o fim da linha.
- **Comentários de várias linhas** ficam entre `/*` e `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
