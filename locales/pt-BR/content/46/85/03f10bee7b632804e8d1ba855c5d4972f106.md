# Instruções

Você cuida do horário de partidas de uma pequena balsa que atende uma ilha. As partidas são registradas como datas, e você precisa de alguns auxiliares para trabalhar com elas.

## 1. Registre uma data de partida

Defina `make-date` para receber um ano, um mês e um dia e retornar o timestamp correspondente.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. Nomeie o dia da semana

Defina `weekday-name` para receber o timestamp de uma partida e retornar o nome do dia da semana em que ela cai.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. Anos bissextos

Defina `leap?` para receber um ano e retornar se ele é um ano bissexto.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. Dias em um mês

Defina `month-length` para receber um ano e um mês e retornar o número de dias desse mês (lembre-se de fevereiro).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. Dias depois

Defina `add-days` para receber um timestamp e um número de dias, e retornar o timestamp tantos dias depois.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
