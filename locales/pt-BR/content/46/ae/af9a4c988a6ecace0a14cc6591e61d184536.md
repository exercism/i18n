# Dicas

## Programação orientada a objetos

* `reset_names` é um **método de classe**.
  Veja [Variáveis de classe][class-vars] no Guia da Linguagem MoonScript.
* Você vai precisar manter o controle do estado de todas as instâncias de robô (quais nomes já foram atribuídos).
  Variáveis de classe são perfeitas para isso, mas pense em que outras abordagens também podem funcionar.

## Dicas de desempenho

* Uma boa estratégia para atribuir nomes a todos os robôs é gerar todos os 676.000 nomes primeiro e embaralhar essa lista.
  Depois, cada novo robô pode simplesmente pegar o próximo nome da lista embaralhada.

[class-vars]: https://moonscript.org/reference/#the-language/object-oriented-programming/class-variables
