# Introdução

Um dicionário (`dict`) em Python é uma estrutura de dados que associa _chaves_ [hashable][term-hashable] a _valores_ e é conhecido em outras linguagens de programação como uma [tabela hash][hashtable-wikipedia] redimensionável, hashmap ou [array associativo][associative-array].
Os dicionários são o único [tipo de mapeamento][mapping-types-dict] embutido do Python.


`Keys` devem ser hashable e únicas em todo o dicionário.
Os tipos de chave podem incluir `numbers`, `str` ou `tuples` (de valores _imutáveis_).
Eles não podem conter estruturas de dados _mutáveis_, como `lists`, `dict`s ou `set`s.
A partir do Python 3.7, a ordem das chaves de um `dict` é garantida como a ordem em que as entradas são inseridas.

`values` podem ser de qualquer tipo ou estrutura de dados.
Os valores também podem se aninhar _arbitrariamente_, então podem incluir listas de listas, subdicionários e outras estruturas de dados personalizadas ou compostas.

Dada uma `key`, os dicionários conseguem recuperar um `value` em tempo constante (em média) (_independente do número de entradas_).
Comparado a procurar um valor dentro de uma `list` ou `array` (_sem saber a posição do `index`_), um `dict` usa bem mais memória, mas tem recuperação muito rápida.
Os dicionários são especialmente úteis em cenários em que a coleção de itens é grande e precisa ser acessada e atualizada com frequência.


## Construção de dicionários

Dicionários podem ser criados de várias formas.
As duas mais diretas são usar o construtor `dict()` ou declarar um _literal_ de `dict`.

### O construtor da classe `dict()`

O `dict()` (_o construtor da classe de dicionário_) pode ser usado com qualquer iterável de pares `key`, `value` ou com uma série de _argumentos_ `<name>=<value>`:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### Literais de dicionário

Um `dict` também pode ser escrito diretamente como um _literal de dicionário_, usando chaves (`{}`) em volta de pares `key : value`:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## Acessando valores em um dicionário

Você pode acessar uma entrada de um dicionário usando uma _chave_ entre colchetes (`[]`).
Se uma `key` não existir no `dict`, um `KeyError` é lançado:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

Acessar uma entrada pelo método `.get(<key>, <default value>)` pode evitar o `KeyError`:

```python
>>> bear.get("color", 'not found')
'not found'
```

## Alterando ou adicionando valores a um dicionário

Você pode alterar o `value` de uma entrada atribuindo à sua _chave_:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

Novos pares `key`:`value` podem ser _adicionados_ da mesma forma:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## Removendo (com pop) entradas de um dicionário

Você pode usar o método `.pop(<key>)` para excluir uma entrada de um dicionário.
O `.pop()` remove o par (`key`, `value`) e retorna o `value` para uso.
Assim como o `.get()`, o `.pop(<key>)` aceita um segundo argumento (_`dict.pop(<key>, <default value>)`_) que será retornado se a `key` não for encontrada.
Isso evita que um `KeyError` seja lançado:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## Percorrendo/iterando sobre um dicionário

Percorrer um dicionário com `for item in dict` ou `while item` itera por padrão apenas sobre as _chaves_.
Você pode acessar os _valores_ dentro do mesmo laço usando _colchetes_:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

Você também pode usar o método `.items()`, que retorna tuplas (`key`, `value`) automaticamente:

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

Da mesma forma, o método `.keys()` retorna `keys` e o método `.values()` retorna os `values`.
