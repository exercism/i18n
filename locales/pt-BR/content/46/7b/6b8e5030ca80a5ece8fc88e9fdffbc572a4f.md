# Sobre

Common Lisp é um ramo da família de longa data das linguagens de programação Lisp.
É uma linguagem de programação multiparadigma que permite escolher a abordagem e o paradigma de acordo com o domínio da sua aplicação.

Common Lisp tem recursos de prototipagem rápida e um suporte excepcional para programação orientada a objetos.
Também se destaca por um sistema de macros que permite adaptar a linguagem às suas necessidades, além de um ambiente de execução que permite modificar aplicações em execução.

Para saber mais sobre Common Lisp, dê uma olhada na [página inicial do Common Lisp][common-lisp-net]
