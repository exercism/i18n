Sobre YAMLscript
================

Então você está pronto para aprender [YAMLScript](https://yamlscript.org)?!

Parabéns!

Você está prestes a embarcar em uma jornada que vai mudar a forma como você pensa
sobre dados e programação.

Ao longo do caminho, você vai aprender:

* Muito mais sobre a sintaxe da linguagem de dados
  [YAML](https://wikipedia.org/wiki/YAML)
* Grande parte dos conceitos de programação em
  [Lisp](https://en.wikipedia.org/wiki/Lisp)
* Como fazer as coisas com [Programação Funcional](
  https://wikipedia.org/wiki/Functional_programming) e estruturas de dados
  imutáveis
* O suficiente da linguagem de programação [Clojure](https://wikipedia.org/wiki/Clojure)
  para fazer estrago

YAMLscript é uma linguagem de programação nova, funcional e de código aberto, com
uma sintaxe baseada em YAML que transpila para código Clojure, que por sua vez é
executado por um interpretador binário nativo em tempo de execução chamado `ys`.

YAMLScript é uma excelente escolha para resolver exercícios do Exercism.
Todos os exercícios desta trilha foram resolvidos em 3 a 50 linhas de YAMLScript
bem espaçadas (10 a 15 em média).

É uma ótima linguagem para aprender programação funcional e conceitos de Lisp,
usando uma sintaxe limpa, amigável e praticamente indolor, inspirada nas melhores
partes de YAML, Clojure, Perl, Python, JavaScript e CoffeeScript.
