# Contador de Linhas de Código

O Contador de Linhas de Código (LoC) recebe uma solução e conta as suas linhas de código.

Por padrão, só são contadas as LoC dos arquivos enviados pelo estudante.
Se o estudante enviou um arquivo de teste, as linhas dele serão ignoradas.

Embora isso funcione bem para a maioria das submissões, alguns tracks podem precisar ignorar arquivos adicionais.
Para isso, permitimos que o Contador de Linhas de Código seja [personalizado por track][lines-of-code-counter-customize].

## Implementação

Usamos a biblioteca [tokei][tokei] para fazer a contagem de verdade.
Como os pull requests muitas vezes não são mesclados rapidamente, criamos o nosso próprio [fork][tokei-fork].
Isso nos permite iterar mais rapidamente e adicionar suporte a qualquer linguagem que quisermos.

## Linguagens suportadas

Você pode verificar se a sua linguagem tem suporte de fábrica procurando por ela no arquivo [languages.json][languages.json].

### Adicionar uma nova linguagem

Se a sua linguagem **não** tem suporte, você pode adicioná-lo assim:

1. Adicionar uma entrada para a sua linguagem no arquivo [languages.json].
   Consulte a [documentação sobre adição de linguagens][adding-language] para mais informações.
2. Adicionar testes para verificar se a contagem funciona corretamente para a sua linguagem.
   Consulte a [documentação sobre como adicionar testes][adding-tests] para mais informações.

Depois de fazer essas alterações, abra um pull request para o [repositório exercism/tokei][tokei-fork].
