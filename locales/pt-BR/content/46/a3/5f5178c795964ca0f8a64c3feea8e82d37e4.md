# Dicas

## Geral

- Dentro de uma função, use a expressão de identidade `.` para acessar a entrada.
- A saída de uma função é o resultado da última expressão no pipeline da função.

## 1. Calcular a taxa de produção por hora

- É a velocidade da linha de montagem multiplicada pela quantidade base de carros por hora, multiplicada pela taxa de sucesso.
- É possível determinar a taxa de sucesso com uma [condicional][if-then-else].
- A multiplicação usa o operador `*`.
- Os números podem ser comparados com os operadores integrados [de igualdade][eq] e [de comparação][cmp].

## 2. Calcular a quantidade de itens funcionais produzidos por minuto

- É a taxa de produção por hora dividida pelo número de minutos por hora, truncada para um número inteiro.
- A divisão usa o operador `/`.
- O resultado da divisão precisará ser truncado com [a função `trunc`][math-funcs].
