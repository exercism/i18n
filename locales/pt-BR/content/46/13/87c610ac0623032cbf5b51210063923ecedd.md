# Sobre

As funções **definidas pelo usuário** são criadas com a palavra-chave `function`. Em seguida, vêm o nome da função e uma lista de argumentos.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

As funções podem ser chamadas em um arquivo antes de serem definidas, pois são movidas para o topo do escopo.

## Nomes

Os nomes de funções em PHP seguem as regras dos outros rótulos: precisam começar com um sublinhado ou uma letra e, depois, podem vir letras, números ou sublinhados, em qualquer quantidade.
