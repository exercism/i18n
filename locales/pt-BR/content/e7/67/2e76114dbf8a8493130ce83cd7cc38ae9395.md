# Introdução

Muitos programas precisam de valores (aparentemente) aleatórios para simular eventos do mundo real.

Exemplos comuns e familiares incluem:

- Um lance de moeda: um valor aleatório que é `"H"` ou `"T"`.
- O lançamento de um dado: um número inteiro aleatório de 1 a 6.
- Embaralhar um baralho de cartas: uma ordenação aleatória de uma lista de cartas.

Gerar valores verdadeiramente aleatórios com um computador é um [desafio técnico surpreendentemente difícil][web-truly-random], então você pode ver esses resultados sendo chamados de "pseudoaleatórios".

***Importante***: este Conceito *não* aborda números aleatórios criptograficamente seguros, que são um desafio muito mais difícil.

No entanto, o R foi derivado de um pacote de estatística e é frequentemente usado para simulações, então oferece uma grande variedade de formas de gerar valores aleatórios.
Os resultados são mais do que suficientes para a maioria das aplicações de modelagem, simulação e jogos.

## [Amostragem com ou sem reposição][yt-sampling-with-replacement]

Imagine que temos um saco com 3 bolas vermelhas e 4 bolas verdes, e tiramos uma bola do saco aleatoriamente.
Para pegar uma segunda bola, há duas possibilidades:

1. Devolva a primeira bola ao saco e agite tudo bem antes de tirar outra.
   O número de bolas agora é o mesmo de antes (7), e *a proporção entre vermelhas e verdes também é a mesma*.
2. Coloque a primeira bola sobre a mesa antes de tirar a segunda.
   Agora há apenas 6 bolas no saco, e *a proporção entre vermelhas e verdes depende da cor da primeira bola*.

O cenário 1 é com reposição, o cenário 2 é sem reposição, e *eles dão resultados diferentes*.

## Valores discretos com `sample`

Para escolher entre um número limitado de valores discretos, `sample()` pode ser usado com ou sem reposição.
Isso é útil para números inteiros, strings, etc.

```R
sample(1:10, 5) # no repeats by default
#> [1] 8 3 4 2 6

sample(1:10, 5, replace = TRUE) # repeats are OK
#> [1] 10 10  7 10  9

languages <- c("Fortran", "R", "Python", "Julia")
sample(languages, 1)
#> [1] "Python"

sample(c("H", "T"), 5, replace = TRUE) # coin flips
#> [1] "T" "T" "H" "H" "H"

sample(c(TRUE, FALSE), 5, replace = TRUE) # alternative coin flips
#> [1] FALSE  TRUE FALSE  TRUE  TRUE
```

A amostragem se encaixa bem em pipelines de dados.
Por exemplo, para gerar strings alfanuméricas aleatórias:

```R
library(stringr)

c(letters, LETTERS, 0:9) |> sample(50) |> str_flatten()
#> [1] "5tX71jhbM9zUmKrpENBQyGYaZdJPVAx06leSF2s8gcfw3OviIH"
```

## Embaralhamento

Várias outras linguagens têm uma função especial para embaralhar uma sequência.

O R não tem função de embaralhamento.
*Por quê?*

Para entender isso, olhe de novo para a função `sample`.

A forma completa é `sample(x, size, replace = FALSE, prob = NULL)`, em que `x` é (normalmente) a sequência de onde amostrar e `size` é o número de itens a escolher.

Já falamos sobre `replace`, cujo padrão é a amostragem sem reposição.
Por enquanto, ignore `prob`, que permite dar pesos desiguais aos vários elementos de `x`.

O que acontece se omitirmos `size` e fornecermos apenas `x`?

```R
x <- letters[1:6]
x
#> [1] "a" "b" "c" "d" "e" "f"
sample(x)
#> [1] "e" "a" "f" "b" "c" "d"
```

No estilo típico do R, o padrão é vetor entra, vetor sai, e `size` tem como padrão `length(x)`.

"Amostrar todos os elementos de `x` sem reposição" é apenas uma forma mais técnica de dizer "embaralhar `x`".

*Assim*, não existe uma função `shuffle`, porque `sample` já faz exatamente o que precisamos!

## Trabalhando com distribuições

Os exemplos acima descreveram casos em que todos os resultados são igualmente prováveis.
Por exemplo, `sample(1:100)` tem a mesma chance de dar qualquer número inteiro de 1 a 100.

Isso é chamado de distribuição `uniform`.

Muitas situações do mundo real são bem menos simples que isso.
Como resultado, os estatísticos criaram uma grande variedade de `distributions` para descrever matematicamente resultados do "mundo real".

## Números de ponto flutuante

### Distribuição uniforme

Para uma distribuição de pesos iguais de números de ponto flutuante, use `runif()` (concentre-se em "**r**andom-**unif**orm" e resista à tendência natural, mas *errada*, de ler como "run if").
Tanto `min` quanto `max` podem ser especificados, mas têm como padrão 0 e 1.

```R
runif(5)  # generate 5 values
#> [1] 0.3038506 0.3527959 0.3319309 0.4846354 0.4386279

# generate 5 non-negative values <= 100.0
runif(5, max = 100)
#> [1] 79.70762 51.62232 52.85281 71.08571 63.94380
```
