# Dicas

## 1. Determine se você vai precisar de uma carteira de motorista

- Use o [operador de comparação de igualdade][comparison-operators] para verificar se o seu valor de entrada é igual a uma determinada string.
- Use um dos dois [operadores lógicos][logical-operators] que você aprendeu no conceito de Boolean para combinar os dois requisitos.
- Você **não** precisa de um condicional para resolver esta tarefa.
  Você pode retornar diretamente a expressão booleana que construir.

## 2. Escolha entre dois veículos em potencial para comprar

- Use um [operador de comparação][comparison-operators] para determinar qual opção vem primeiro na ordem lexicográfica.
- Depois, defina o valor de uma variável auxiliar conforme o resultado dessa comparação, com a ajuda de um [condicional if-else][if-statement].
- Por fim, monte a frase de recomendação.
  Para isso, você pode usar o operador `+` para concatenar as duas strings.

## 3. Calcule uma estimativa para o preço de um veículo usado

- Comece determinando a porcentagem do preço original com base na idade do veículo.
  Guarde-a em uma variável auxiliar.
  Use um [condicional if-else if-else][if-statement] como mencionado nas instruções.
- Nas duas condições `if`, use [operadores de comparação][comparison-operators] para comparar a idade do carro com os valores de limite.
- Para calcular o resultado, aplique a porcentagem ao preço original.
  Por exemplo, `30% of x` pode ser calculado dividindo `30` por `100` e multiplicando por `x`.

[comparison-operators]: https://golang.org/ref/spec#Comparison_operators
[logical-operators]: https://golang.org/ref/spec#Logical_operators
[if-statement]: https://golang.org/ref/spec#If_statements
