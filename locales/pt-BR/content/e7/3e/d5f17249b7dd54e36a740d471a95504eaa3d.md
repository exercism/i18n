# Instruções

Você está trabalhando na implementação de um jogo de RPG.
O personagem do jogador é representado pelo seguinte:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

Neste jogo, os jogadores precisam alcançar o nível 10 antes de desbloquear um reservatório de mana, que podem usar para conjurar feitiços.
Antes disso, a mana do Player é `Option::None`.

Você está trabalhando em duas funcionalidades deste jogo: o mecanismo de reviver e o mecanismo de conjurar feitiços.

O método `revive` deve verificar se o Player está de fato morto (a vida dele chegou a 0) e, se estiver, deve retornar uma nova instância de Player com 100 de vida.
O método `revive` deve preservar o nível do Player.
Se o nível do Player for 10 ou mais, ele deve ser revivido com 100 de mana.
Se o nível do Player for menor que 10, a mana dele deve ser `Option::None`.

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

Se o método `revive` for chamado em um Player cuja vida seja 1 ou mais, o método deve retornar `Option::None`.

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

O método `cast_spell` recebe uma referência mutável ao Player, além de um parâmetro `mana_cost` que indica quanta mana o feitiço custa.
Ele retorna a quantidade de dano que o feitiço conjurado causa.

- Se o jogador não tiver acesso a um reservatório de mana, tentar conjurar o feitiço deve diminuir a vida dele no valor do custo de mana do feitiço.
  O dano retornado deve ser 0.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- Se o jogador tiver um reservatório de mana, mas mana insuficiente, o método não deve afetar o reservatório.
O dano retornado deve ser 0.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- Caso contrário, o feitiço é conjurado com sucesso.
  O `mana_cost` deve ser descontado do reservatório de mana do Player.
  O dano retornado deve ser o dobro do custo de mana do feitiço.

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```

Divirta-se!
