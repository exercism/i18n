# Apêndice das instruções

## Dicas

Para fazer o teste passar, você vai precisar criar alguns tipos para o seu código funcionar. Você precisa de um objeto para `School` guardar uma sequência do tipo `Student`, que será uma tupla de `string` e `int` para guardar o nome e a série dos estudantes.

Aqui está um código com os tipos que pode ajudar na hora de começar

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
