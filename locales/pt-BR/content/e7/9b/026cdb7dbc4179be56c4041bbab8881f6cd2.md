# Sobre

O atributo Flags permite que os valores definidos em uma união discriminada sejam representados como posições de bits (ou seja, flags). Como flags, esses valores podem ser combinados, o que possibilita representar várias condições Boolean em um único valor.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Definir uma flag pode ser feito com o operador OR bit a bit (`|||`); limpar uma flag pode ser feito com uma combinação do operador AND bit a bit (`&&&`) e do operador de negação bit a bit (`~~~`).
Já verificar o estado de uma flag pode ser feito com o operador AND bit a bit, e também é possível usar o método HasFlag().

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```
