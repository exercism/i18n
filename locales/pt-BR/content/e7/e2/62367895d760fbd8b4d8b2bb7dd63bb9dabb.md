# Instruções

Neste exercício, você vai implementar um conjunto parcial de rotinas utilitárias para ajudar um desenvolvedor a limpar nomes de identificadores.

Nas 4 tarefas, você vai construir aos poucos a rotina `clean`. Um identificador válido é composto por zero ou mais letras e sublinhados.

Em todos os casos, a string de entrada é garantidamente não nula. Se uma string vazia for passada para a função `clean`, uma string vazia deve ser retornada.

Repare que quem chama a rotina `clean` deve evitar fazê-lo com um identificador vazio, já que identificadores assim não têm efeito.

## 1. Substitua os espaços encontrados por sublinhados

Implemente a função `clean` para substituir qualquer espaço por sublinhados. Isso também vale para espaços no início e no fim.

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. Substitua caracteres de controle pela string "CTRL" em maiúsculas

Modifique a função `clean` para substituir caracteres de controle pela string `"CTRL"` em maiúsculas.

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. Converta kebab-case em camelCase

Modifique a função `clean` para converter kebab-case em camelCase.

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. Omita letras gregas minúsculas

Modifique a função `clean` para omitir quaisquer letras gregas no intervalo de 'α' a 'ω'.

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
