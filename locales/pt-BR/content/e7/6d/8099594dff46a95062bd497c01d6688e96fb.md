# Introdução

## Casamento de padrões com literais

Embora expressões `if/else` possam ser usadas para executar lógica condicional, Haskell também tem uma forma mais poderosa de executar lógica condicional: [casamento de padrões][pattern-matching].
Com casamento de padrões, um valor pode ser testado em relação a um ou mais _padrões_.
Um exemplo desse tipo de padrão é o _padrão constante_, que compara um valor com uma constante (por exemplo, `1` ou `"hello"`).

Ao definir funções, você pode definir corpos de função separados para padrões diferentes.
Isso leva a um código limpo, simples e legível.
Você pode fazer casamento de padrões em qualquer tipo de dados: números, caracteres, listas, tuplas etc.

Por exemplo, uma função trivial que recebe um número inteiro (`Int`) e o deixa _1_ mais perto de _0_ poderia ser expressa assim:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

O casamento de padrões começa a brilhar quando usado em conjunto com outros padrões, por exemplo o _padrão variável_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

O exemplo acima trata todas as entradas diferentes de _0_ da mesma forma e produziria resultados incorretos para números negativos.
Isso pode ser resolvido usando padrões condicionais, conhecidos como _guardas_, que são expressos com o símbolo `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

Nos exemplos acima, nem todas as entradas possíveis têm um padrão correspondente.
O compilador detectará isso e emitirá um aviso.
Esse é um recurso muito útil do Haskell que ajuda a garantir que todos os caminhos possíveis sejam cobertos para evitar erros em tempo de execução.
Isso é conhecido como _verificação exaustiva_.
Para resolver o aviso, você precisa lidar com todos os casos.
Dentro das _guardas_, você pode usar a expressão `otherwise` como açúcar sintático para `True` para capturar todos os padrões restantes.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

O casamento de padrões testará um valor em relação a cada padrão, de cima para baixo, até encontrar um padrão correspondente e executar a lógica associada a esse padrão.
**A ordem dos padrões importa!**
