# sem export nomeado

Nenhum [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) chamado `%{export.name}` foi encontrado. Os testes não vão passar sem ele.

Verifique se `%{export.name}` existe e adicione `export` na frente dele:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
