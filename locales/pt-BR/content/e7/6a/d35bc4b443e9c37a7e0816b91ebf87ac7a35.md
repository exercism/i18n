# Anexo às instruções

## Defina `errno` como um valor especial

Se o buffer estiver vazio durante uma tentativa de leitura, um erro é lançado para alertar o cliente.

Esses valores de erro podem ser encontrados no arquivo de cabeçalho [`errno.h`][errno.h].

[errno.h]: https://en.wikipedia.org/wiki/Errno.h
