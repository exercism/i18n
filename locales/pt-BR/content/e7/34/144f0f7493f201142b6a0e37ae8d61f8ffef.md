# to_i{bit}

Usar o método `to_i{bit}` é uma forma válida de converter um valor para uma determinada base.
Mas, ao definir um [literal numérico][int], é mais idiomático usar o sufixo `_i{bit}`.

```crystal
# Rather than:
500034214414.to_i64

# Consider:
500034214414_i64
```

[int]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/integers.html
