# Instruções

Neste exercício, você vai escrever mais um pouco de código para ajudar a preparar a sua lasanha incrível daquele seu livro de receitas favorito.

Você tem cinco tarefas, todas relacionadas ao tempo gasto preparando a lasanha.

## 1. Permitir alterar o tempo esperado no forno

Você quer escrever uma função `remainingMinutesInOven` melhorada que recebe como parâmetro o número de minutos decorridos que a lasanha está no forno e retorna quantos minutos a lasanha ainda precisa ficar no forno, com base no tempo esperado no forno em minutos da tarefa anterior.
Antes, você dependia de um valor constante, `expectedMinutesInOven`, que vinha de fora da função `remainingMinutesInOven`.
Isso deixava as coisas um pouco bagunçadas demais para o seu gosto e não era flexível o bastante, já que não permitia alterar o tempo esperado no forno.

Para organizar tudo, defina a função `remainingMinutesInOven` que recebe como parâmetro o número de minutos decorridos que a lasanha está no forno, além de um parâmetro `expectedMinutesInOven` com valor padrão 40.
Sua função deve retornar quantos minutos a lasanha ainda precisa ficar no forno, com base no tempo esperado no forno em minutos da tarefa anterior.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. Permitir números diferentes de camadas

Você havia escrito antes uma função `preparationTimeInMinutes` que recebe como parâmetro o número de camadas que você adicionou à lasanha e retorna quantos minutos você gastou preparando a lasanha, supondo que cada camada leva 2 minutos para preparar.
No entanto, você não está muito satisfeito com essa função, já que precisa contar sozinho o número de camadas da sua lasanha antes de chamá-la, e quem tem tempo para tudo isso?

Para facilitar a sua vida, escreva uma função, `preparationTimeInMinutes`, que recebe um parâmetro variádico do tipo `String`, `layers`, no qual você lista as diferentes camadas da sua lasanha.
A função então conta o número de camadas da sua lasanha e retorna a quantidade de tempo de preparo necessária.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. Calcular as quantidades de massa e molho

Antes de começar a montar a sua lasanha, você quer ter certeza de que tem molho e massa suficientes para montar a lasanha dos seus sonhos.
Para cada camada de massa da sua lasanha, você vai precisar de 3 folhas de massa.
Para cada camada de molho da sua lasanha, você vai precisar de 0,2 litro de molho.

Defina a função `quantities` que recebe um parâmetro variádico do tipo `String`, `layers`, no qual você lista as diferentes camadas da sua lasanha.
A função então determina a quantidade de massa e de molho necessária para preparar a sua refeição. O resultado deve ser retornado em uma tupla do tipo `(noodles: Int, sauce: Double)`.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. Converter litros em onças fluidas no local

Infelizmente, o molho que você tem em mãos está com o volume indicado em onças fluidas em vez de litros.
Para ajudar a saber se você tem molho suficiente em mãos, escreva uma função, `toOz`, que recebe um parâmetro de tupla in-out, `(noodles: Int, sauce: Double)`, e converte a quantidade de molho para onças fluidas.
Repare que há 33,814 onças fluidas por litro.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. Determinar o melhor vinho para servir

Por fim, você quer saber que tipo de vinho servir com a sua lasanha.
Você ouviu dizer que deve servir vinho branco se houver mais mussarela, ricota e bechamel na lasanha do que carne e molho, e vinho tinto caso contrário.
Escreva uma função `redWine` que recebe um parâmetro variádico do tipo `String`, `layers`, no qual você lista as diferentes camadas da sua lasanha.
A função vai usar cinco funções aninhadas para determinar o número de camadas de mussarela, ricota, bechamel, molho e carne na lasanha, e comparar os números de camadas para determinar se o vinho tinto deve ser servido, retornando `true` se sim e `false` se não.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
