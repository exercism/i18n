# Anexo às instruções

## Memória reservada

O buffer para a string de entrada usa os bytes 64-191 da memória linear.

## Arrays

O WebAssembly não tem o conceito de arrays.
Para o teste das cores, retorne um buffer de caracteres delimitado por vírgulas no formato: `black,brown,red,orange,yellow,green,blue,violet,grey,white`

A partir daí, você vai precisar montar internamente um array de estruturas usando deslocamentos e comprimentos para dar estrutura a esse buffer.
