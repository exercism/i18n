# Introdução

Há três condicionais principais usadas em Julia:

- expressões `if`
- o operador ternário
- a avaliação de curto-circuito

## Expressões `if`

As expressões `if` em Julia são parecidas com as de outras linguagens:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

Se a expressão booleana depois do `if` resultar em `true`, o primeiro bloco de código roda e o segundo é ignorado.
Se a expressão booleana depois do `if` resultar em `false`, o primeiro bloco de código é ignorado e o segundo roda.
O programa continua a execução na primeira linha de código depois da palavra-chave `end`.

~~~~exercism/note
Em Julia, a palavra-chave `end` indica o fim de todas as expressões de bloco.
Essa sintaxe não é específica de expressões `if` nem de definições de função.
~~~~

Nos casos em que o segundo bloco de código seria apenas outra expressão `if`, o `elseif` permite evitar aninhar expressões `if` dentro do bloco:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

Se uma expressão `if` só precisa executar código para um dos casos, não é necessário escrever o bloco `else`.

## Operador ternário

Condicionais `if-else` simples também podem ser escritas com o operador ternário `a ? b : c`.
Se `a` for verdadeiro, `b` será avaliado.
Caso contrário, avalia-se `c`.

Por exemplo, a função a seguir

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

também pode ser escrita assim

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

Isso é especialmente útil quando você quer atribuir um valor diferente a uma variável dependendo de uma condição.
`x = a ? b : c` atribui `b` a `x` se `a` for `true` e, caso contrário, atribui `c` a `x`.
Por exemplo:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## Avaliação de curto-circuito

Se várias expressões booleanas estiverem encadeadas com os operadores `&&` e `||`, Julia vai avaliar apenas o mínimo de expressões necessário para determinar o valor de toda a cadeia.

Por exemplo, considere a cadeia de expressões `n > 0 && k > 10`.
Se `n` for igual a `5`, a primeira parte da cadeia, `n > 0`, é `true` e é necessário avaliar a segunda expressão `k > 10` para determinar se a expressão inteira é `true`.
Porém, se `n` for igual a `-5`, sabemos que a cadeia como um todo **não pode** ser `true`, porque a primeira expressão é `false`.

Se considerarmos `n > 0 || k > 10` em vez disso, acontece o contrário.
Se `n` for igual a `5`, a primeira parte da cadeia, `n > 0`, é `true` e sabemos que a cadeia inteira será `true`, independentemente da segunda expressão.
Porém, se `n` for igual a `-5`, é necessário avaliar a segunda expressão.

Esse comportamento pode ser usado para escrever condicionais `if` bem curtas:

```julia
if a
    b
end
```

é equivalente a

```julia
a && b
```

A última expressão de uma cadeia de `&&` e `||` não precisa ser uma expressão booleana.
É comum ver esse recurso sendo usado para erros ou retornos antecipados.
Por exemplo, usando a função `dessert(fruit)` de cima:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
