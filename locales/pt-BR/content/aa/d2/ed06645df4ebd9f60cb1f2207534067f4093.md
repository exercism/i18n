# Sobre

[Funções anônimas][anon-fns] são comumente usadas por conta própria em Elixir, como valores de retorno e como argumentos em funções de ordem superior, como `Enum.map/2`:

```elixir
Enum.map([1, 2, 3], fn n -> n + 1 end)
# => [2, 3, 4]
```

As funções em Elixir são tratadas como cidadãos de primeira classe:

- Funções nomeadas e anônimas podem ser atribuídas a variáveis.
- Funções nomeadas e anônimas podem ser passadas como dados, como argumentos e valores de retorno.
- Funções anônimas podem ser criadas dinamicamente.

Funções anônimas são criadas com a palavra-chave [`fn`][kernel-fn] e chamadas com um ponto (`.`):

```elixir
function_variable = fn n -> n + 1 end

function_variable.(1)
# => 2
```

Funções anônimas também podem ser criadas com a [forma abreviada de captura `&`][kernel-capture].

- O `&` inicial declara o início da expressão de captura.
- `&1`, `&2` e assim por diante referem-se aos argumentos posicionais da função anônima.

  ```elixir
  # Instead of:
  fn x, y -> abs(x) + abs(y) end

  # We can write:
  &(abs(&1) + abs(&2))
  ```

- O operador de captura `&` também pode ser usado para [_capturar_ funções nomeadas existentes][capture]:

  ```elixir
  # Instead of:
  fn a, b -> a <= b end

  # We can capture the function using its name and arity:
  &<=/2
  ```

Funções anônimas em Elixir são [closures][closure]. Elas podem acessar variáveis que estão no escopo quando a função é definida. Variáveis atribuídas dentro de uma função anônima não são acessíveis fora dela:

```elixir
y = 2

square = fn ->
  x = 3
  x * y
end

square.()
# => 6

x
# => ** (CompileError): undefined function x/0
```
