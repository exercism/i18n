# Dicas

## Geral

- O módulo `gleam/string` tem muitas [funções de string][stdlib] úteis.

## 1. Obtenha a mensagem de uma linha de log

- O operador `<>` pode ser usado em pattern matching para casar com o início de uma string.
- O módulo `gleam/string` tem uma [função][trim] para remover os espaços em branco ao redor de uma string.

## 2. Obtenha o nível de log de uma linha de log

- O módulo `gleam/string` tem uma [função][lowercase] para converter uma string em minúsculas.

## 3. Reformate uma linha de log

- O operador `<>` pode ser usado para juntar strings.
