# Sobre

Em C#, o Boolean é representado pelo tipo `bool`, cujos valores podem ser `true` ou `false`.

O C# dá suporte a quatro [operadores Boolean][operators]: `!` (NOT), `&&` (AND),  `||` (OR) e `^` (XOR). Os operadores `&&` e `||` usam _avaliação de curto-circuito_, o que significa que o lado direito do operador só é avaliado quando necessário.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

Os três operadores Boolean têm cada um uma [_precedência de operadores_][precedence] diferente. Por isso, eles são avaliados nesta ordem: primeiro `not`, depois `&&`, em seguida `^` e, por fim, `||`. Se você quiser "escapar" dessas regras, pode colocar uma expressão Boolean entre parênteses (`()`), já que os parênteses têm uma precedência ainda maior.

```csharp
!true && false   // => false
!(true && false) // => true
```
