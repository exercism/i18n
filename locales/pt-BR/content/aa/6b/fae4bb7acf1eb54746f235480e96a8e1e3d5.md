# Sobre

Condicionais são instruções que executam código diferente dependendo se uma condição é `true` ou `false`.

Uma [condicional `if`][if_statement] executa seu corpo somente quando sua condição é `true`.
O Go não tem o conceito de valores truthy ou falsy, então a condição precisa ser do tipo `bool`.
Expressões como `if mySlice { ... }` ou `if 1 { ... }` são erros de compilação.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Use `else if` para verificar condições adicionais e `else` como alternativa caso nenhuma delas seja verdadeira.
As condições são avaliadas de cima para baixo, e somente o primeiro bloco cuja condição for verdadeira será executado.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

De modo geral, o Go prefere retornar cedo do caso excepcional e evitar o `else`.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

Uma condicional `if` também pode incluir uma instrução curta de inicialização.
Isso é comum para verificar um erro logo depois de uma chamada:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

As variáveis declaradas na instrução de inicialização só estão no escopo da cadeia `if`/`else` inteira.
Vale notar que o Go não tem operador ternário, uma escolha de projeto deliberada para manter o código fácil de ler de relance.

Para saber mais, veja [Go by Example: If/Else][go_by_example_if].
