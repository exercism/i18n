# Dicas

## Geral

- Para cada tarefa, cada função deve retornar um closure de função, usando os argumentos fornecidos. Consulte a seção da documentação do Clojure sobre [closures de função][closures] para referência.

## 1. Translade as coordenadas

- Os argumentos fornecidos dão a quantidade para transladar o par de coordenadas ao longo dos eixos _x_ e _y_.

## 2. Escale as coordenadas

- Os argumentos fornecidos dão a quantidade para escalar o par de coordenadas nos eixos _x_ e _y_.

## 3. Componha as funções de transformação

- O resultado da primeira transformação é um vetor, mas as funções de transformação recebem dois argumentos numéricos. Você vai ter que obter os valores do vetor.
- Lembre-se de que a ordem em que as funções são executadas faz diferença.

## 4. Salve os resultados das funções

- Para esta função, você deve apenas memoizar o resultado da última transformação.
- Para retornar o resultado da última transformação, você vai ter que verificar se os argumentos de entrada são os mesmos.
- Para guardar o valor dos argumentos e o último resultado, você pode usar um [atom][atoms].

[atoms]: https://clojure.org/reference/atoms
[closures]: https://clojure.org/guides/higher_order_functions#_functions_returning_functions_and_closures
