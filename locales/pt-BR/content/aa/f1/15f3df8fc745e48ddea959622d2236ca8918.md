# Sobre

O ABAP dá suporte aos operadores aritméticos usuais para valores numéricos:

- `+` soma valores.
- `-` subtrai valores.
- `*` multiplica valores.
- `/` divide valores.
- `MOD` retorna o resto de uma divisão inteira.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

A multiplicação e a divisão são avaliadas antes da adição e da subtração. Use parênteses quando precisar agrupar um cálculo explicitamente.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
