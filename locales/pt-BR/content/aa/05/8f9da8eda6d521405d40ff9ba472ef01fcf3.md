# Testes na linha de comando

Execute os testes com:

```bash
$ cargo test
```

Todos os testes, exceto o primeiro, foram ignorados. Depois de fazer o primeiro teste passar, abra o arquivo-fonte dos testes, que fica no diretório `tests`, remova a flag `#[ignore]` do próximo teste e faça os testes passarem de novo. Cada teste individual é uma função com a flag `#[test]` acima dela. Continue assim até passar em todos os testes.

Se você quiser rodar _apenas os testes ignorados_ sem editar o arquivo-fonte dos testes, use:

```bash
$ cargo test -- --ignored
```

Se você estiver usando Rust 1.51 ou mais recente, pode rodar _todos_ os testes com

```bash
$ cargo test -- --include-ignored
```

Para rodar um teste específico, por exemplo `some_test`, você pode usar:

```bash
$ cargo test some_test
```

Se o teste específico estiver ignorado, use:

```bash
$ cargo test some_test -- --ignored
```

Para saber mais sobre os testes em Rust, consulte a [documentação de testes][rust-tests] online.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
