# Dicas

## 1. Verificar se o comando é válido

- Você provavelmente vai precisar de [`ignore_case`][ref-regex] na definição da regex.
- Procure apenas no início da mensagem.

## 2. Remover os emojis criptografados

- O `stringr` tem as funções [`str_replace()`][ref-str_replace] e [`str_remove()`][ref-str_remove].

## 3. Verificar se o número de telefone é válido

- Bifurque o código dependendo de a regex ser [detectada][ref-str_detect] ou não.
- Consulte o [Conceito de Strings][concept-strings] se tiver dificuldade para montar a saída.

## 4. Cumprimentar o usuário

- Você vai precisar de vários grupos de captura.
- [`str_replace()`][ref-str_replace] funciona melhor com capturas _sem nome_: mantenha a simplicidade.

## 5. Obter o link do site

- Pode haver várias correspondências em cada mensagem.
- Leia a Introdução para ver dicas (perto do final) sobre como usar `str_match_all()` e desempacotar os resultados: _um pouco confuso, mas não é assim tão difícil_.
