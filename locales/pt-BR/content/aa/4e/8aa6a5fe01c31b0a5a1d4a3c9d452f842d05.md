# Introdução

No Elixir, podemos definir atributos de módulo que podem ser usados como constantes em nossas funções.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Quando usados para definir constantes de módulo, os atributos podem ser qualquer expressão que possa ser avaliada em tempo de compilação. Depois da compilação, os atributos de módulo não ficam mais acessíveis, já que são expandidos durante a compilação, de modo semelhante a macros definidas em linguagens como o C.
