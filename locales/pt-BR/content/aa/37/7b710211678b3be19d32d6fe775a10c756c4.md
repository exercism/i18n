# Instruções adicionais

## Registradores

| Registrador | Uso       | Tipo    | Descrição                                          |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | entrada   | inteiro | número inicial                                     |
| `$v0`    | saída     | inteiro | número esperado de passos, -1 se o número for inválido |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário               |
