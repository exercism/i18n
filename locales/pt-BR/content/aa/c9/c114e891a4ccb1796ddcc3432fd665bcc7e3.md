# Criando um Analyzer

Antes de tudo, agradecemos o seu interesse em criar um Analyzer!

Estes são os passos para começar:

1. Confira [nossa lista de repositórios em busca de um `...-analyzer` já existente](https://github.com/search?q=org%3Aexercism+analyzer&type=repositories) para garantir que ele ainda não exista.
2. Dê uma olhada no [conteúdo deste diretório](/docs/building/tooling/analyzers) para ver se você se sente à vontade com a ideia de criar um Analyzer.
3. Abra um novo tópico no [fórum do Exercism][building-exercism] dizendo para qual linguagem você gostaria de criar um Analyzer.
4. Depois que um repositório de Analyzer for criado para você, use os documentos [a interface do Analyzer](/docs/building/tooling/analyzers/interface) e [Boas práticas](/docs/building/tooling/best-practices) para orientar sua implementação.

Temos uma comunidade incrivelmente amigável e acolhedora, que terá prazer em ajudar você ao longo desse processo!
Se você travar em algum ponto, abra um novo tópico no [fórum do Exercism][building-exercism] ou crie novas issues em [exercism/exercism][exercism-repo] conforme precisar 🙂

[building-exercism]: https://forum.exercism.org/c/exercism/building-exercism/125
