# Testar a trilha

_Antes_ de lançar sua trilha (ou seja, a chave `"active"` ainda é `false` no `config.json` da trilha), é importante que a trilha seja testada.
Isso ajuda a encontrar erros (comuns) e permite corrigi-los _antes_ de lançar a trilha. Dessa forma, os estudantes nunca vão esbarrar neles.

## Como habilitar a trilha para testes

Para habilitar a trilha para testes, ela precisa ser adicionada ao nosso banco de dados, o que só administradores do site podem fazer.
Abra um tópico no [fórum](https://forum.exercism.org/c/exercism/building-exercism/125) solicitando isso.

Note que adicionar a trilha ao banco de dados _não_ vai lançar a trilha, mas _vai_ deixá-la acessível no site para usuários mantenedores.

## Como encontrar testadores

As pessoas ideais para testar a trilha são outros mantenedores de trilhas, porque elas:

- Têm experiência criando uma trilha (e portanto sabem o que deveria ter sido construído)
- Conseguem acessar trilhas que ainda não estão ativas

Para que mantenedores testem sua trilha, abra um tópico no [fórum](https://forum.exercism.org/c/exercism/building-exercism/125) solicitando isso.
