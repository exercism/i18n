# Dicas

## Geral

- Use a crate `enum-iterator` para conseguir iterar sobre enums. Confira a [documentação](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) para descobrir como.

- Use a crate `int-enum` para conseguir converter de int para enum. Consulte a [documentação](https://docs.rs/int-enum/0.5.0/int_enum/) para mais detalhes.

- O trait `Debug` está aí porque você provavelmente vai precisar dele.

- Você vai precisar estender a lista de traits derivados com `derive` no seu enum de cores.
