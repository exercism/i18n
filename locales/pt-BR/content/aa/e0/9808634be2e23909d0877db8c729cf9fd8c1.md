# Apêndice das instruções

## Dicas

Para completar este exercício, você precisa criar o tipo de dados `Robot` e implementar as seguintes funções:

- `bearing`
- `coordinates`
- `mkRobot`
- `move`

Você vai encontrar uma declaração de dados provisória e as assinaturas de tipo já prontas, mas cabe a você definir as funções e criar um tipo de dados, um newtype ou um sinônimo de tipo que faça sentido.
