# Anexo das instruções

## Registradores

| Registrador | Uso          | Tipo     | Descrição                                          |
| ----------- | ------------ | -------- | -------------------------------------------------- |
| `$a0`       | entrada      | inteiro  | número de dígitos de entrada                       |
| `$a1`       | entrada      | inteiro  | base dos dígitos de entrada                        |
| `$a2`       | entrada      | inteiro  | base dos dígitos de saída                          |
| `$a3`       | entrada/saída | endereço | array sobrescrevível de palavras de dígitos        |
| `$v0`       | saída        | inteiro  | número de dígitos de saída, -1 se a entrada for inválida |
| `$t0-9`     | temporário   | qualquer | usado para armazenamento temporário                |
