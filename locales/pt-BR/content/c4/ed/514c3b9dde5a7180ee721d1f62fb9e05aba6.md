# Introdução

_Sobrecarga de métodos_ permite que vários métodos na mesma classe tenham o mesmo nome. Métodos sobrecarregados precisam ser diferentes entre si por:

- O número de parâmetros
- O tipo dos parâmetros

Não existe sobrecarga de métodos com base no tipo de retorno.

O compilador vai inferir automaticamente qual método sobrecarregado chamar, com base no número de parâmetros e no tipo deles.
