# Sobre

O Gleam não usa exceções para tratamento de erros. Em vez disso, as funções que podem ter sucesso ou falhar retornam o tipo genérico `Result`.

O tipo `Result` já vem embutido na linguagem, então você não precisa defini-lo nem importá-lo, mas se você o definisse por conta própria, ele ficaria assim:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

A variante `Ok` é retornada quando uma função tem sucesso, e a variante `Error` é retornada quando uma função falha.

Resultados são muito comuns no Gleam, e quem programa em Gleam costuma usar o [módulo `gleam/result`](https://hexdocs.pm/gleam_stdlib/gleam/result.html) para facilitar o trabalho com eles.

A função `result.map` pode ser usada para chamar uma função sobre o valor dentro de um resultado, se ele for um `Ok`, ou para repassar um `Error` inalterado.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

A função `result.try` é parecida, mas espera-se que a função de callback retorne um resultado. Isso é útil para encadear várias funções que retornam resultados.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
