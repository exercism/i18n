# Sobre

Quando os tipos não podem receber um cast implícito, você precisa usar um [operador][cast-operator] de cast explícito. O operador de cast nada mais é do que o tipo de destino entre parênteses, antes do valor que você quer converter:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

Usar um cast explícito é potencialmente perigoso. Os dois erros mais comuns são:

- Fazer um cast para um tipo incompatível. Isso vai lançar uma exceção em tempo de execução.
- Fazer um cast para um valor numérico que não é "amplo" o suficiente. Isso pode resultar em um conflito de sinal ou, no caso de números inteiros, no lançamento de uma exceção de overflow.

Observação: uma expressão do tipo `int` pode receber um cast explícito para `char`. Isso pode resultar em um `char` inválido.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
