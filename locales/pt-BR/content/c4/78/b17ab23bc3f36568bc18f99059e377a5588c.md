# Sobre

Nim é uma linguagem de propósito geral projetada e desenvolvida por Andreas Rumpf, tendo surgido pela primeira vez em 2008.
Projetada para ser eficiente, expressiva e elegante.
Nim tem tipagem estática e é compilada, mas permite que você escreva um código elegante que roda com eficiência.
Nim permite atingir muitas plataformas ao compilar o código para C, C++, JavaScript ou Objective-C.
A sintaxe do Nim é parecida com a do Python e compartilha muitas das características do Python, mas também se inspira em várias outras linguagens, como C, C++, C#, Lisp, Ada, Go, Oberon e outras.

Como o Nim é uma linguagem de propósito geral, ele pode ser usado em vários contextos, mas vem ocupando um nicho de verdade na área de desenvolvimento de jogos e programação de sistemas, incluindo sistemas embarcados.

O Nim oferece muita da conveniência que você encontra no Python e em outras linguagens, como uma sintaxe fácil de ler, um sistema de gerenciamento de pacotes para usar novas bibliotecas nos seus projetos e tracebacks amigáveis para depurar erros.

O Nim oferece a velocidade e a portabilidade do C, mas com um coletor de lixo de alto desempenho e uma sintaxe elegante que torna a linguagem muito acessível para quem está começando.
O Nim também te dá controle, permitindo que você troque o coletor de lixo ou o desligue completamente, com a opção de gerenciar a memória por conta própria.
Com o Nim, você tem uma variedade de paradigmas de programação e camadas de abstração.
