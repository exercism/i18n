# CLI

## Enviando a solução

Quando nenhum teste estiver ignorado e todos estiverem passando, você pode enviar sua solução usando `exercism submit numbers.js`.

## Enviando soluções incompletas

É possível enviar uma solução incompleta para ver como outras pessoas concluíram o exercício.
