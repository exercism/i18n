# Testes

Se você tem o binário do 8th no seu PATH, digite o comando:

```bash
8th -f test.8th
```

Se o binário do 8th não estiver no PATH, no Windows digite

```cmd
\path\to\8th -f test.8th
```

Linux ou macOS:

```bash
/path/to/8th -f test.8th
```

## Testar no REPL

Inicie o 8th, carregando o test-words.8th:

```sh
8th -f test-words.8th
```

Isso inicia uma sessão de CLI onde, depois de escrever um pouco de código no seu arquivo de solução, você pode carregá-lo no REPL.
Por exemplo, para o exercício "word-count", você digitaria:

```8th
"word-count.8th" f:include
```

E você pode rodar os testes com
```sh
"word-count-tests.8th" f:include
```

Ou você pode copiar e colar um único teste desse arquivo, ou digitar o seu próprio.

## Testes ignorados

Resolver um exercício significa fazer todos os testes passarem.
Por padrão, apenas um teste (o primeiro) é executado quando você roda os testes.
Isso é intencional, pois permite que você foque apenas em fazer esse único teste passar.
Quando ele passar, você pode habilitar o próximo teste movendo a palavra `SKIP-REST-OF-TESTS` para depois dele.

## Sobrescrever os testes ignorados

Para rodar todos os testes, incluindo os que vêm depois da palavra `SKIP-REST-OF-TESTS`, você pode definir a variável de ambiente `RUN_ALL_TESTS` com o valor `true`.
Uma forma de definir isso só enquanto os testes rodam é (macOS e Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
