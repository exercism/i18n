### Invocação dinâmica de funções

As funções awk não são objetos de primeira classe: elas não podem ser passadas de um lado para o outro como algumas outras linguagens permitem.
Porém, uma variável pode guardar o _nome_ de uma função (uma string), e a função é invocada usando uma notação especial `@varname(args)`.
Um exemplo:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
Isso está descrito em [Chamadas indiretas de funções][indirect].
Isso é uma extensão do `gawk`.
