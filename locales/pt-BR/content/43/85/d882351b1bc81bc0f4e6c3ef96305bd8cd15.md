# Introdução

Os métodos de extensão permitem adicionar métodos a tipos existentes sem criar um novo tipo derivado, sem recompilar nem modificar o tipo original de outra forma. Eles são definidos como métodos estáticos, mas são chamados usando a sintaxe de método de instância. O primeiro parâmetro vem precedido do modificador `this` e especifica em qual tipo o método opera, e eles entram em escopo no nível do namespace.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
