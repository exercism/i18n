# Anexo às instruções

## Mensagens de exceção

Às vezes é preciso [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando você fizer isso, inclua sempre uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isso deixa seu código mais legível e ajuda bastante na depuração. Em situações em que você sabe que a origem do erro será de um determinado tipo, você pode optar por lançar um dos [tipos de erro embutidos](https://docs.python.org/3/library/exceptions.html#base-classes), mas ainda assim deve incluir uma mensagem significativa.

Este exercício em particular exige que você use a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um `ValueError` se o número de entrada em `say()` estiver fora do intervalo. Os testes só vão passar se você usar `raise` na `exception` e incluir uma mensagem junto dela.

Para lançar um `ValueError` com uma mensagem, escreva a mensagem como argumento do tipo da `exception`:

```python
# if the number is negative
raise ValueError("input out of range")

# if the number is larger than 999,999,999,999
raise ValueError("input out of range")
```
