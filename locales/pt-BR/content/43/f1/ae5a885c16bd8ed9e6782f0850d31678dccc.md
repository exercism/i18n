# Instruções

Neste exercício, você vai implementar uma forma de acompanhar as pontuações máximas do jogo mais popular do fliperama da sua região.

Você tem 7 funções para implementar, todas relacionadas a retornar e manipular um dicionário de dados de pontuações máximas.

## 1. Defina um novo dicionário de pontuações máximas

Crie uma função `newScoreBoard()` que não recebe parâmetros e retorna um novo dicionário de pontuações máximas que usa valores do tipo `String` para as chaves e valores do tipo `Int` como os valores.

## 2. Adicione jogadores ao dicionário de pontuações máximas

Para adicionar um jogador ao dicionário de pontuações máximas, defina `addPlayer(_:_:_:)`, uma função que recebe 3 parâmetros:

- O primeiro parâmetro é o dicionário de pontuações. 
    Ele deve ser um parâmetro de entrada e saída.
- O segundo parâmetro é o nome de um jogador como string.
- O terceiro parâmetro é a pontuação como um número inteiro. 
    O parâmetro é opcional; implemente o terceiro parâmetro com um valor padrão de 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Remova jogadores do dicionário de pontuações

Para remover um jogador do dicionário de pontuações máximas, defina `removePlayer(_:_:)`, que recebe 2 parâmetros:

- O primeiro parâmetro é o dicionário de pontuações. 
    Ele deve ser um parâmetro de entrada e saída.
- O segundo parâmetro é o nome do jogador como string.

Essa função deve remover o jogador do dicionário se ele estiver nele e não fazer nada caso contrário.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Redefina a pontuação de um jogador

Para redefinir a pontuação de um jogador, defina `resetPlayer(_:_:)`, que recebe 2 parâmetros:

- O primeiro parâmetro é o dicionário de pontuações.
    Ele deve ser um parâmetro de entrada e saída.
- O segundo parâmetro é o nome do jogador como string, cuja pontuação você deseja redefinir.

A função define a pontuação do jogador como 0. 
Se o jogador não estiver no dicionário, nada deve acontecer.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Atualize a pontuação de um jogador

Para atualizar a pontuação de um jogador somando à pontuação anterior, defina `updateScore`, que recebe 3 parâmetros:

- O primeiro parâmetro é o dicionário de pontuações. Ele deve ser um parâmetro de entrada e saída.
- O segundo parâmetro é o nome do jogador como string, cuja pontuação você deseja atualizar.
- O terceiro parâmetro é a pontuação que você deseja **somar** à pontuação máxima armazenada.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Obtenha uma lista de jogadores com pontuações ordenada pelo nome do jogador

Defina a função `orderByPlayers`, que recebe 1 parâmetro:

- O primeiro parâmetro é o dicionário de pontuações.

A função retorna um array de tuplas `(String, Int)` que são os jogadores e suas pontuações máximas, ordenadas em ordem crescente pelo nome do jogador.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Obtenha uma lista de jogadores ordenada pela pontuação do jogador em ordem decrescente

Para obter uma lista de jogadores ordenada pelas pontuações em ordem decrescente, defina `orderByScores`, que recebe 1 parâmetro:

- O primeiro parâmetro é o dicionário de pontuações.

A função retorna um array de tuplas `(String, Int)` que são os jogadores e suas pontuações máximas, ordenadas em ordem decrescente pela pontuação do jogador.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
