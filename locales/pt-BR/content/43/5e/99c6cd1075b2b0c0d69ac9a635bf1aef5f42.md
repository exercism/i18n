# Ponteiros inteligentes

Os ponteiros inteligentes em Cairo são uma ferramenta poderosa que oferece um gerenciamento de memória seguro e eficiente.

Um ponteiro inteligente é uma estrutura de dados que age como um ponteiro comum, mas com recursos extras de segurança para evitar problemas comuns de gerenciamento de memória, como desreferenciar ponteiros nulos ou acessar memória não inicializada.

## O que é um ponteiro inteligente?

De modo geral, um ponteiro é uma variável que armazena um endereço de memória, normalmente apontando para um valor guardado nesse local.

No entanto, ponteiros brutos podem ser perigosos: se o ponteiro não aponta para uma memória válida ou é desreferenciado de forma incorreta, isso pode causar travamentos ou comportamentos imprevisíveis.

Os ponteiros inteligentes resolvem esse problema ao impor regras rígidas de gerenciamento de memória, garantindo que a memória seja acessada de forma segura e controlada.

Cairo, assim como muitas linguagens modernas, como Rust, usa ponteiros inteligentes para evitar acessos inseguros à memória.

Um ponteiro inteligente em Cairo não apenas armazena um endereço de memória, mas também acompanha o ownership e garante a segurança de memória.

## Tipos de ponteiros inteligentes em Cairo

Cairo oferece vários tipos de ponteiros inteligentes, incluindo `Box<T>` e `Nullable<T>`, cada um com uma finalidade diferente.

Vamos dar uma olhada mais de perto em como esses tipos funcionam e quando você pode usá-los.

### `Box<T>`

O tipo `Box<T>` é o principal ponteiro inteligente em Cairo.

Ele permite armazenar dados em um segmento de memória especial chamado "boxed segment". Um `Box<T>` é um ponteiro que aponta para esse segmento, e, quando você cria um box, aloca espaço para os dados nesse segmento.

Boxes são ideais em situações em que:

- Você precisa armazenar um valor de um tipo cujo tamanho não pode ser determinado em tempo de compilação.
- Você tem uma grande quantidade de dados e quer transferir o ownership sem copiá-los.

Usando um box, você consegue armazenar estruturas de dados grandes com mais eficiência.

Ao passar um `Box<T>` para uma função, apenas o ponteiro é passado, o que evita a necessidade de copiar todos os dados e melhora o desempenho, especialmente com estruturas grandes.

### `Nullable<T>`

O tipo `Nullable<T>` é outro ponteiro inteligente importante em Cairo.

Ele pode apontar para um valor válido do tipo `T` ou ser `null` quando não há valor.

Esse tipo é útil em casos nos quais você precisa armazenar valores que nem sempre existem, como em um dicionário que pode conter elementos opcionais.

Em Cairo, `Nullable<T>` costuma ser usado em dicionários para lidar com casos em que nenhum valor padrão pode ser aplicado.

Ele permite armazenar valores de forma condicional, o que facilita lidar com a ausência de dados com segurança.

## Segurança de memória com ponteiros inteligentes

Uma das principais vantagens de usar ponteiros inteligentes é que eles ajudam a garantir a segurança de memória.

Ao gerenciar o ownership e as regras de acesso, Cairo evita problemas comuns, como desreferenciar ponteiros nulos ou pendentes.

Os ponteiros inteligentes acompanham quando os dados não são mais necessários e podem desalocar a memória automaticamente quando ela sai de escopo, o que reduz o risco de vazamentos de memória.

### Exemplo: usando um `Box<T>` para tipos recursivos

Um desafio comum em muitas linguagens de programação é lidar com tipos recursivos.

Tipos recursivos são tipos que contêm referências a si mesmos.

Sem um gerenciamento de memória adequado, definir um tipo recursivo pode causar problemas como recursão infinita.

Em Cairo, `Box<T>` torna possível definir tipos recursivos com segurança.

Por exemplo, você pode usar `Box<T>` para implementar uma árvore binária, em que cada nó contém uma referência a outro nó.

Ao armazenar referências em boxes, Cairo garante que o uso de memória seja finito, e o compilador consegue determinar o tamanho de memória necessário para a estrutura.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### Benefícios de desempenho dos ponteiros inteligentes

Os ponteiros inteligentes também melhoram o desempenho dos seus programas.

Quando você usa `Box<T>`, apenas o ponteiro para os dados é passado adiante, em vez de copiar toda a estrutura de dados.

Isso é especialmente útil ao lidar com grandes conjuntos de dados, pois reduz bastante a sobrecarga das operações de memória.

No exemplo a seguir, os dados são passados por referência usando um `Box<T>` para evitar o custo de copiar toda a estrutura:

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

Neste exemplo, `pass_pointer` recebe um `Box<Cart>` em vez de um `Cart`, o que reduz a quantidade de memória copiada durante a chamada da função.
