# Anexo às instruções

## Registradores

| Registrador | Uso          | Tipo     | Descrição                              |
| ----------- | ------------ | -------- | -------------------------------------- |
| `$a0`       | entrada      | endereço | string de nome terminada em null       |
| `$a1`       | entrada      | inteiro  | número                                 |
| `$a2`       | entrada/saída | endereço | string de resultado terminada em null |
| `$t0-9`     | temporário   | qualquer | para armazenamento temporário          |
