# Instruções

Uma escola perto de você tem uma associação de estudantes muito ativa.
A associação de estudantes é administrada por um presidente e, a cada 2 anos, são realizadas eleições para eleger um novo presidente.
Na eleição deste ano, decidiu-se que era necessário um novo sistema digital para contar os votos.

A escola precisa da sua ajuda para construir esse novo sistema.

## 1. Crie um contador de votos

Uma das primeiras coisas que o novo sistema de votação precisa é de um contador de votos.
Esse contador é uma forma de acompanhar os votos que um determinado candidato tem.

Crie uma função `new_vote_counter` que aceita o número de votos iniciais de um candidato e retorna um snapshot de uma struct `VoteCounter`, inicializada com o número de votos iniciais fornecido.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. Obtenha o número de votos de um contador

Agora você tem uma forma de criar novos contadores!
Mas agora você percebe que o novo sistema também vai precisar de uma forma de obter o número de votos de um contador.

Crie uma função `vote_count` que recebe um contador (`@VoteCounter`) como argumento e retorna o número de votos no contador.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. Incremente os votos de um contador

Finalmente chegou a hora de contar os votos!
Agora você precisa de uma forma de incrementar os votos de um contador.

Crie uma função `increment_vote_count` que recebe um contador (`@VoteCounter`) como argumento e um número de votos, e incrementa o contador nesse número de votos.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. Crie os resultados da eleição

Com todos os votos contados, chegou a hora de preparar o anúncio do resultado para toda a escola.
Para isso, você percebe que ter apenas contadores de votos é insuficiente.
É preciso haver uma forma de associar o número de votos a um determinado candidato.

Crie uma função `new_election_result` que recebe o nome de um candidato e o número de votos dele e retorna um novo resultado de eleição.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

A struct de resultado da eleição já foi criada para você e está definida assim:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. Anuncie os resultados

Chegou a hora de anunciar o novo presidente para a escola!
O novo presidente será anunciado nos pequenos painéis digitais de mensagens que a escola tem.

A mensagem deve mostrar o nome do novo presidente e os votos que ele recebeu, no seguinte formato: `<candidate_name> (<votes>)`.
Este é um exemplo de mensagem assim: `"Peter (51)"`.

Crie uma função `display_result` que recebe um `@ElectionResult` como argumento e retorna um `ByteArray` com a mensagem a ser exibida.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. Recontagem de votos

Para garantir que os resultados finais estivessem corretos, os votos foram recontados.
Na recontagem, descobriu-se que o número de votos de alguns candidatos estava errado por um.

Crie uma função `decrement_votes_of_candidate` que recebe os resultados finais e o nome de um candidato cuja contagem de votos você deve decrementar.
Os resultados finais são fornecidos na forma de um `Felt252Dict<u32>`, em que as chaves são os nomes dos candidatos e os valores são o total de votos de cada um.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
