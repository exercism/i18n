# Introdução

Os [parâmetros variádicos][variadic-parameters] permitem que uma função aceite zero ou mais valores de um tipo especificado em um único parâmetro.
Você define um parâmetro variádico acrescentando três pontos (`...`) à anotação de tipo do parâmetro.

Dentro do corpo da função, o Swift disponibiliza esses valores como um array do tipo especificado:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Se uma função inclui parâmetros adicionais depois de um parâmetro variádico, o primeiro parâmetro depois do parâmetro variádico **precisa** ter um rótulo de argumento explícito para que o Swift saiba onde termina a lista de argumentos variádicos.
~~~~
