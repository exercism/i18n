# Instruções

Imprima os números de 1 a n com as seguintes regras:

1. Quando o número for múltiplo de 3, imprima "Fizz"
2. Quando o número for múltiplo de 5, imprima "Buzz"
3. Quando o número for múltiplo de 3 e de 5, imprima "Fizz Buzz"
4. Quando o número não for múltiplo de 3 nem de 5, imprima o número

A saída deve ser um vetor de strings, por exemplo: "1" "2" "Fizz" "4" "Buzz" ...
