# Instalação

## Instalando o Godot Engine

A trilha de GDScript é construída em cima do [Godot Engine][godot-engine], que roda no Windows, Linux, macOS e Android.
Por enquanto, o executor de testes para [trabalhar localmente][working-locally] exige Linux.
Esta trilha exige a versão 4.0 ou superior do Godot.

Depois de concluir a instalação, você pode verificar se a CLI foi instalada com sucesso rodando este comando em um terminal:

```bash
godot --version
```

## Instalando o executor de testes da trilha de GDScript do Exercism

Você precisa ter o [Godot instalado][installation] corretamente para usar o executor de testes.

Para compilar e testar scripts GDScript para o Exercism, o Godot será executado no modo "headless" pela CLI.
Estas instruções exigem Linux e bash no momento.

### Passo 1: Instalando a infraestrutura geral do executor de testes

Para preparar o ambiente de testes, clone [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] e mova o conteúdo para `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Passo 2: Baixando o script do executor de testes de um único exercício

Supondo que você já tenha a ferramenta `exercism` configurada e tenha baixado pelo menos um exercício de GDScript, ela deve ter criado uma pasta `gdscript` dentro do seu workspace (como aparece ao rodar `exercism configure`) para guardar os exercícios.
Salve [o executor de testes][test-local-gdscript-solution] nessa pasta e marque o arquivo como executável.

## Rodando os testes

Com os passos de instalação concluídos, você pode partir de qualquer pasta de exercício (por exemplo, `~/exercism/gdscript/two-fer`) e rodar o script (que fica um nível acima, em `../`) para testar sua solução local para esse exercício:

```sh
../test-local-gdscript-solution.sh
```

## Usando uma IDE

Para ter realce de sintaxe de GDScript em um editor como o [Visual Studio Code][vscode], você precisa de uma extensão como a [godot-tools][godot-tools] instalada, além de um servidor de depuração em execução.
O Godot inicia esse servidor de depuração automaticamente sempre que um projeto está aberto no próprio editor e o mantém em execução até que o projeto ou o próprio Godot seja fechado.
