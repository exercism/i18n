# Apêndice das instruções

## Comparação de desempenho

Se você estiver resolvendo este exercício localmente, há um arquivo `parallel_letter_frequency_benchmark_test.rb` incluído que vai comparar sua solução paralela com uma sequencial.
Você pode rodá-lo com `ruby parallel_letter_frequency_benchmark_test.rb`.
A saída vai mostrar, em formato de tabela, os tempos de execução de cada implementação para uma faixa de grandes quantidades de textos.
Fique à vontade para alterar os casos de teste.
Talvez você queira investigar como o comprimento do texto versus o número de textos afeta o tempo de execução de cada implementação.

**Observação:** Para conjuntos menores de texto, a contagem sequencial _pode_ ser mais rápida devido aos custos de sobrecarga de processamento.
