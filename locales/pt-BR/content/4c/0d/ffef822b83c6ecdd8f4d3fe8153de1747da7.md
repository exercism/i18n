# Dicas

## 1. Substitua todos os espaços encontrados por sublinhados

- A [documentação de referência][char-docs] para `char`s está aqui.
- Você pode obter `char`s de uma string da mesma forma que obtém elementos de um array, embora neste exercício possa ser melhor usar uma função de ordem superior como `String.collect`.
- Literais `char` ficam entre aspas simples.

## 2. Remova todos os espaços em branco

- Veja [este método][iswhitespace] para detectar espaços e [este método][isnumber] para dígitos.

## 3. Converta camel-case em kebab-case

- Veja [este método][tolower] para converter um caractere em minúscula.

## 5. Omita letras gregas minúsculas

- `char`s suportam os operadores padrão de igualdade e comparação.
