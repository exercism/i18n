# Introdução

Às vezes, quando você percorre uma sequência, precisa da *posição* do elemento junto com o próprio elemento. A família `*-index` em [`sequences`][sequences] entrega ambos à quotation de cada elemento. `times` é o parente próximo para iteração contada simples, útil quando você só precisa de uma contagem, não de uma sequência.

## `each-index` e `map-index`: índice na quotation

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

A quotation recebe o elemento abaixo do índice: `index` está no **topo** da pilha:

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index` executa a quotation pelo seu efeito colateral e não retorna nada. `map-index` coleta os resultados de cada elemento em uma nova sequência do mesmo tipo que a entrada.

## `times`: iteração contada

`times` (em [`math`][math]) executa sua quotation `n` vezes.

```
times ( n quot: ( -- ) -- )
```

A forma publicada `( -- )` é o *mínimo*: como `times` é `inline`, uma quotation com efeitos balanceados como `( str -- str )` funciona bem, e a pilha é encadeada entre as iterações. Isso te dá um acumulador com contagem sem nenhum estado mutável:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

O corpo de cada iteração vê a string em andamento, acrescenta a ela e deixa a nova string na pilha para a próxima iteração. O mesmo truque funciona para `each-index` e `map-index` quando você quer encadear um acumulador.
