# Instalação

A distribuição do Racket pode ser baixada em https://download.racket-lang.org

Há instaladores para

* Windows
* Linux
* macOS

Consulte a página [Getting Started](http://docs.racket-lang.org/getting-started/) do Racket para encontrar materiais de orientação.

O [Racket Guide](https://docs.racket-lang.org/guide/intro.html) apresenta a você como interagir com o Racket.

Consulte [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html) para orientações sobre como usar a IDE DrRacket.

Consulte [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html) para uma introdução às ferramentas de linha de comando do Racket e ao uso de outros editores.


## Sobre o instalador para Linux

A versão para Linux é genérica o bastante para funcionar na maioria das distribuições, incluindo distribuições relativamente antigas.

Depois de baixar o arquivo do instalador, execute-o com
```
sh racket-8.10-x86_64-linux-cs.sh
```

Talvez você precise adicionar `sudo` no início do comando para instalar em um local que exige acesso de administrador.

**Atenção: o Racket também pode estar disponível pelo gerenciador de pacotes da sua distribuição, mas pode ser uma versão mais antiga que a versão mais recente do Racket.**
Você pode optar por fazer isso mais tarde, mas, como estudante, sua experiência será muito melhor se você ficar com a versão atual disponível em https://download.racket-lang.org


## Sobre o instalador para macOS

Se sua máquina usa processadores da série M1 ou M2, selecione **Apple Silicon** no menu de plataformas antes de baixar.
