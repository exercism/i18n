# Dicas

## Geral

- O código fornecido nos namespaces das famílias deve ser tratado como algo já pronto e não deve ser modificado.
- Não copie os valores para o seu código, chame os métodos.

## 1. Tome seu lugar diante das famílias e organize seus papéis

- O namespace precisa se chamar `EstateExecutor` para que sua solução passe nos testes.

## 2. Encontre o número da conta secreta

Cada `bank_number_part` precisa ser chamado com o `secret_modifier` da lista de parâmetros.

## 3. Último passo: insira o código secreto

- Você pode chamar métodos de namespaces aninhados assim: `OuterNamespace::InnerNamespace::my_method`.

- Tome cuidado para somar os fragmentos azuis e vermelhos separadamente antes de multiplicar as duas partes.
