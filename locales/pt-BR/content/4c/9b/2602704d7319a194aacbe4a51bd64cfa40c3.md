# Dicas

## Geral

* O que um zipper mais simples sobre uma estrutura de dados de lista (não vazia) poderia fazer? Abrir mão de um grau de movimento no zipper pode ajudar se você ficar travado. Um zipper sobre uma lista só precisaria se preocupar em mover para a esquerda, mover para a direita e obter e definir um elemento no foco.
* O `t` em `Zipper t a` representa a estrutura de dados de árvore binária para os fins deste exercício. Isso dá ao zipper a capacidade de "zipar" por potencialmente mais de uma estrutura de dados!
