# Instruções

Um robô de festa está pendurando bandeirinhas para a grande bonança. Cada
varal de bandeirinhas é uma fileira horizontal de `n` bandeirinhas pequenas, e
o caractere de cada bandeirinha é decidido pela posição dela na fileira,
contando da esquerda a partir de `0`. Ajude o robô a montar os padrões abaixo.

## 1. Bandeirinhas alfabéticas

Defina `alphabet-bunting` para pegar um inteiro não negativo `n` da pilha e
retornar uma string com as primeiras `n` letras minúsculas do alfabeto.

```factor
5 alphabet-bunting .
! => "abcde"

0 alphabet-bunting .
! => ""
```

Você pode assumir que `n` é no máximo `26`.

## 2. Bandeirinhas de contagem

Defina `counting-bunting` para pegar `n` e retornar uma string de `n`
dígitos, em que a bandeirinha na posição `i` mostra `i mod 10`.

```factor
12 counting-bunting .
! => "012345678901"
```

## 3. Bandeirinhas listradas

Defina `stripe-bunting` para alternar entre dois caracteres: posições pares
recebem `*` e posições ímpares recebem `-`.

```factor
6 stripe-bunting .
! => "*-*-*-"

1 stripe-bunting .
! => "*"
```

## 4. Bandeirinhas com marcador

Toda quinta bandeirinha é um marcador especial. Defina `marker-bunting` para
que as posições `0`, `5`, `10`, … recebam `|` e as demais recebam `.`.

```factor
11 marker-bunting .
! => "|....|....|"
```

## 5. Bandeirinhas do vale

O robô pendura um varal de bandeirinhas de tamanho fixo com 10 bandeirinhas,
preso a um gancho no centro. Contando da bandeirinha mais à esquerda, na
posição `-5`, até (mas sem incluir) `5`, o caractere de cada bandeirinha é a
distância até o centro, escrita como um dígito.

Defina `valley-bunting` (sem entradas) para retornar essa string fixa.

```factor
valley-bunting .
! => "5432101234"
```
