# Introdução

## Conjuntos

Um conjunto é uma coleção imutável e não ordenada de valores únicos. Todos os itens de um conjunto precisam ser do mesmo tipo.

O módulo `gleam/set` define o tipo `Set` e fornece funções para trabalhar com conjuntos.

Você pode transformar listas e conjuntos entre si com `set.to_list` e `set.from_list`. A ordem dos itens em um conjunto não é garantida.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

Você pode criar e preencher conjuntos com `set.new`, `set.insert` e `set.delete`.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

Você pode consultar o conteúdo de um conjunto com as funções `set.contains` e `set.size`.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

Conjuntos podem ser combinados com `set.union` e `set.intersection`.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

Você pode filtrar conjuntos.

```gleam
let is_small = fn(n) { n <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
