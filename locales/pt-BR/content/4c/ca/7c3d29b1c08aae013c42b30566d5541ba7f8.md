# Sobre

[Conses][hyper-conses] são um tipo de dado básico em Common Lisp. Eles são compostos por uma cabeça e uma cauda (chamadas, por [razões históricas][history], de `car` e `cdr`).
Não há restrição quanto aos tipos de dado da cabeça e da cauda de um cons.

Os conses são criados com a função [`cons`][hyper-cons], que recebe dois objetos e resulta em um cons (às vezes também chamado de 'cons cell').

As partes de um cons podem ser acessadas com as funções [`car`][hyper-car] e [`cdr`][hyper-cdr].

## Referência

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
