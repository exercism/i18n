# Dicas

## 1. Crie um novo inventário usando os itens

- Você precisa usar `return` na sub-rotina `create_inventory` para retornar uma referência de hash, contendo os itens como chaves e a quantidade deles na referência de array `$items` como valores.

## 2. Adicione ao inventário usando os itens

- Você precisa usar `return` na sub-rotina `add_items` para retornar uma referência de hash, com a quantidade de itens aumentada por quantos houver na referência de array `$items`.

## 3. Remova os itens do inventário

- Você precisa usar `return` na sub-rotina `remove_items` para retornar uma referência de hash, com a quantidade de itens diminuída por quantos houver na referência de array `$items`.
- A contagem de itens não pode ficar abaixo de `0`.

## 4. Exclua o item completamente do inventário

- Você precisa usar `return` na sub-rotina `delete_item` para retornar uma referência de hash, com o item completamente removido do inventário.
