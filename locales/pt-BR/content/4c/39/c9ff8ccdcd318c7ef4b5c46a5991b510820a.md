# Sobre

Além das declarações de função e das expressões de função, o JavaScript também tem outra sintaxe bem concisa para definir uma função.
Essas funções são chamadas de _arrow functions_.

Neste conceito, vamos focar na sintaxe usada para escrever uma arrow function.
Há diferenças na forma como uma arrow function funciona, como a vinculação de _this_, que serão abordadas em outros conceitos.

Veja uma comparação entre uma declaração de função e uma arrow function.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Acima, você vê que a sintaxe da arrow function:

1. remove a palavra-chave `function`
2. declara o identificador `addUpTwoNumbers` como um `const`
3. adiciona uma seta grossa `=>`

Se o corpo da função contém apenas uma instrução de retorno, como no exemplo acima, as `{}` e a palavra-chave `return` podem ser omitidas.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

No caso especial de retornar apenas um objeto de uma arrow function, são necessários parênteses em volta do objeto para poder omitir a instrução de retorno.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return { num1, num2 };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

O uso de parênteses em volta dos parâmetros depende do número de parâmetros.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
