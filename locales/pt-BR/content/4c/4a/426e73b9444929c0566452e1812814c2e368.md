# não use condicional aninhada

Tente reescrever as condicionais para evitar aninhamento profundo, pois isso pode deixar o código mais difícil de acompanhar. Veja os dois trechos de código a seguir:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

Compare com o código a seguir:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

O segundo exemplo tem uma estrutura bem específica: todos os caminhos que lidam com erros ficam em blocos recuados, enquanto o "caminho feliz" fica sempre alinhado à esquerda. Isso deixa a leitura muito mais fácil, porque dá para ver rapidamente qual é o caminho mais comum, sem erros, pelo código.
