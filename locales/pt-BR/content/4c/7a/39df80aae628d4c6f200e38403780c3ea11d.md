# Instruções

Você acabou de começar a trabalhar na recepção de uma academia de escalada.
Os membros compram assinaturas por um certo número de meses e fazem check-in e check-out a cada visita.
O gerente pediu que você escrevesse um utilitário que responde às perguntas que os membros mais fazem.

## 1. Descobrir quando uma assinatura termina

Uma assinatura que começa em uma data termina no mesmo dia do mês, o número de meses informado depois.
Quando esse dia não existe no mês final, a assinatura termina no último dia desse mês.

Implemente o método `FrontDesk.membershipEnd()`, que recebe a data de início de uma assinatura e o número de meses dela e retorna a data em que ela termina:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Mostrar quanto tempo uma assinatura dura

No cartão da assinatura, a academia imprime quanto tempo a assinatura dura em anos, meses e dias.

Implemente o método `FrontDesk.membershipLength()`, que recebe a data de início e a data de término de uma assinatura e retorna a duração dela como um `Period`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Contar os dias restantes de uma assinatura

Os membros costumam perguntar quantos dias ainda faltam antes de a assinatura terminar.

Implemente o método `FrontDesk.daysLeft()`, que recebe a data de hoje e a data de término de uma assinatura e retorna o número total de dias a partir de hoje até a data de término.
Quando a data de término é hoje ou já passou, não há dias restantes, então o método retorna `0`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Medir uma visita

A academia fica aberta 24 horas por dia, e a catraca registra a data e a hora em que o membro faz check-in e check-out.

Implemente o método `FrontDesk.visitDuration()`, que recebe a data e a hora de check-in e de check-out de uma visita e retorna quanto tempo a visita durou como um `Duration`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Imprimir uma visita no recibo

O recibo mostra a duração de uma visita em horas e minutos, como `1h 35m`.
Os minutos são sempre escritos com dois dígitos, os segundos são descartados, e as horas não se limitam a um único dia.

Implemente o método `FrontDesk.formatVisit()`, que recebe a duração de uma visita e a retorna nesse formato:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
