# Instalação

Você precisa do [NodeJS LTS](https://nodejs.org/en).

> 💡 Esta track provavelmente funciona com versões estáveis mais antigas, assim como com a versão "current".
> No entanto, [por design](https://github.com/nodejs/release#release-schedule), versões ímpares nunca são estáveis.
> Certifique-se sempre de instalar uma versão par do NodeJS.

Instale o [Yarn 4+](https://yarnpkg.com/getting-started/install) usando o `corepack` do Node.JS:

```shell
corepack enable yarn
```

## Verificando sua instalação

Em geral, você precisa abrir um novo terminal para usar os binários que acabou de instalar.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_Observação: é provável que suas versões sejam diferentes destas._

## Instalação do exercício

**Cada exercício** precisa de algumas ferramentas para rodar os testes:

Você pode instalá-las rodando este comando dentro do diretório de cada exercício:

```bash
$ corepack yarn install
```

Dependendo do seu editor, o [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) precisa ser instalado em cada exercício, para funcionar com instalações Plug'n'Play.
No momento em que este texto foi escrito, os seguintes têm suporte:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
