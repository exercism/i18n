# Instalação

Primeiro, certifique-se de que o Erlang está instalado, seguindo as instruções da página de instalação do [Erlang][1] conforme for adequado.
[1]: /languages/erlang

## Homebrew para Mac OS X

Atualize seu Homebrew para a versão mais recente:

```bash
$ brew update
```

Instale o LFE:

```bash
$ brew install lfe
```

## Instalando a partir do código-fonte
Instale as "ferramentas de desenvolvedor" ou os "pacotes essenciais de compilação" do seu sistema, o `git` e o `erl` do Erlang.

Por exemplo, no Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Depois disso, você pode baixar e compilar o LFE com o seguinte:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Depois de compilar o LFE, você pode iniciar o REPL (sessão interativa) executando o binário ``lfe``:

```bash
$ ./bin/lfe
```
