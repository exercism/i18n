# Apêndice

## Bônus

Dois testes opcionais ficam desativados por padrão. Para ativá-los, adicione `const TEST_BIG_INTEGERS = true` ao escopo global do seu arquivo de solução (ou descomente a linha fornecida no stub).

Esses números ultrapassam o tipo inteiro padrão, mas inteiros de 128 bits são suficientes para passar nos testes; não há necessidade de usar `BigInt`.
