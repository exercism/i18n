# Instruções

Implemente o método clássico para compor mensagens secretas chamado código quadrado.

Dado um texto em inglês, produza a versão codificada desse texto.

Primeiro, a entrada é normalizada: os espaços e a pontuação são removidos do texto em inglês e a mensagem passa para minúsculas.

Em seguida, os caracteres normalizados são divididos em linhas. Podemos pensar nessas linhas como formando um retângulo quando são impressas com quebras de linha entre elas.

Por exemplo, a frase

```text
"If man was meant to stay on the ground, god would have given us roots."
```

é normalizada para:

```text
"ifmanwasmeanttostayonthegroundgodwouldhavegivenusroots"
```

O texto original deve ser organizado em um retângulo. O tamanho do retângulo (`r x c`) deve ser decidido pelo comprimento da mensagem, de forma que `c >= r` e `c - r <= 1`, em que `c` é o número de colunas e `r` é o número de linhas.

Nosso texto normalizado tem 54 caracteres, o que determina um retângulo com `c = 8` e `r = 7`:

```text
"ifmanwas"
"meanttos"
"tayonthe"
"groundgo"
"dwouldha"
"vegivenu"
"sroots  "
```

A mensagem codificada é obtida lendo as colunas de cima para baixo, da esquerda para a direita.

A mensagem acima é codificada como:

```text
"imtgdvsfearwermayoogoanouuiontnnlvtwttddesaohghnsseoau"
```

Produza o texto codificado em blocos que preenchem retângulos perfeitos `(r X c)`, com `c` blocos de comprimento `r`, separados por espaços. Para frases que ficam `n` caracteres abaixo do retângulo perfeito, complete cada um dos últimos `n` blocos com um único espaço no final.

```text
"imtgdvs fearwer mayoogo anouuio ntnnlvt wttddes aohghn  sseoau "
```

Repare que, se empilhássemos esses blocos, poderíamos decodificar visualmente o texto cifrado de volta para a mensagem original:

```text
"imtgdvs"
"fearwer"
"mayoogo"
"anouuio"
"ntnnlvt"
"wttddes"
"aohghn "
"sseoau "
```
