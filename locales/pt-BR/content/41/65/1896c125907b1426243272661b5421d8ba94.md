# Dicas

## Geral

- Leia sobre [`alias` e `import`][getting-started] no guia Getting Started.
- Leia sobre [composição de módulos][elixir-school-module-composition] no elixirschool.com.

## 1. Corrija o erro de compilação `Race.__struct__/0 is undefined`

- É possível criar um alias com a forma especial [`alias`][alias].

## 2. Corrija o erro de compilação `Car.__struct__/0 is undefined`

- É possível criar um alias com a forma especial [`alias`][alias].
- A forma especial `alias` aceita a opção `:as`.

## 3. Corrija o erro de compilação `undefined function puts/1`

- É possível importar funções com a forma especial [`import`][import].
- A forma especial [`import`][import] aceita a opção `:only`. O valor dela deve ser uma lista de palavras-chave com nomes de funções como chaves e aridades de funções como valores.

## 4. Corrija o erro de compilação `undefined function default_color/0`

- É possível importar funções com a forma especial [`import`][import].
- A forma especial [`import`][import] aceita a opção `:except`. O valor dela deve ser uma lista de palavras-chave com nomes de funções como chaves e aridades de funções como valores.
