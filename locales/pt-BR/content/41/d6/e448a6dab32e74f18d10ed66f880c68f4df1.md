# Sobre

A biblioteca padrão do Elixir oferece 4 módulos diferentes para trabalhar com datas e horas, cada um com seu próprio struct.

- O [módulo `Date`][date]. Um struct `Date` pode ser criado com o [sigil `~D`][sigil-d].
    ```elixir
    ~D[2021-01-01]
    ```

- O [módulo `Time`][time]. Um struct `Time` pode ser criado com o [sigil `~T`][sigil-t].
    ```elixir
    ~T[12:00:00]
    ```

- O [módulo `NaiveDateTime`][naivedatetime], para datas e horas sem fuso horário. Um struct `NaiveDateTime` pode ser criado com o [sigil `~N`][sigil-n].
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- O [módulo `DateTime`][datetime], para datas e horas com fuso horário. Usar esse módulo com fusos horários diferentes de UTC exige uma dependência externa, um banco de dados de fusos horários. Um struct `DateTime` pode ser representado com o [sigil `~U`][sigil-u], mas deve ser criado com funções de `DateTime`.

    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## Comparações

Para comparar datas ou horas entre si, procure uma função `compare` ou `diff` no módulo correspondente. Operadores de comparação como `==`, `>`, e `<` _parecem_ funcionar, mas não fazem uma comparação semântica correta para esses structs.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## Deslocamento

Datas e horas podem ser deslocadas para frente e para trás no tempo com a função `add/2` do módulo correspondente.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## Conversões

Um struct `NaiveDateTime` pode ser decomposto em um struct `Date` e um struct `Time` usando [`NaiveDateTime.to_date/1`][naivedatetime-to-date] e [`NaiveDateTime.to_time/1`][naivedatetime-to-time]. O inverso pode ser feito com [`NaiveDateTime.new!/2`][naivedatetime-new].

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
