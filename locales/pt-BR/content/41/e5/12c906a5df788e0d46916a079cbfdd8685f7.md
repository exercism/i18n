# Sobre

O Ruby vem com uma biblioteca padrão, uma coleção de classes para trabalhar com coisas como datas, json e redes. Ela também oferece recursos úteis para facilitar o trabalho com o seu código.

`OpenStruct` faz parte da biblioteca padrão e permite criar um objeto a partir de um `Hash` com facilidade. Em vez de acessar usando chaves de `Hash`, o `OpenStruct` permite usar métodos para acessar e definir valores.

Ao usar classes da biblioteca padrão, ou de qualquer outra biblioteca, você precisa carregar essa classe usando o método `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Um bônus disso é que você pode aproveitar um atalho ao usar a sintaxe de bloco. Quando um bloco chama um único método, você pode substituir o bloco por `&:` seguido do nome do método. Por exemplo, estas duas linhas são sinônimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
