# Structs

As structs reúnem um conjunto fixo e heterogêneo de dados em uma única unidade. As structs em Rust têm estas propriedades:

- Todo tipo de struct tem um nome próprio.
- Todo membro de uma struct é chamado de **campo**.
- Todo campo de uma struct tem um nome próprio.
- A visibilidade é controlada no nível do campo: cada campo pode ser, de forma independente, público, privado ou outra coisa[^1].

# Visão geral das structs

As structs são definidas com a palavra-chave `struct`, seguida do nome do tipo que a struct descreve.
Depois do nome podem vir chaves (para uma struct padrão), parênteses (para uma struct de tupla) ou um ponto e vírgula (para uma struct de unidade).

```rust
struct Item {}
```

Outros tipos são então trazidos para o corpo da struct como _campos_ da struct, cada um com seu próprio tipo:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Por fim, métodos podem ser definidos em structs dentro de um bloco `impl`:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# Variedades de struct

As structs existem em três variedades: structs com campos nomeados (structs padrão), structs de tupla e structs de unidade.

As structs são muito parecidas com **tuplas**. Na verdade, a única diferença entre structs e tuplas tem a ver com o que é anônimo. A forma geral é assim:

- As structs têm nome e campos nomeados:

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  Os campos são acessados pelo nome:

  ```rust
  let bar = foo.bar;
  ```

- As structs de tupla têm nome e campos anônimos:

  ```rust
  Foo(Bar, Bat)
  ```

  Os campos são acessados por desestruturação ou por índice numérico:

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- As tuplas são anônimas e têm campos anônimos:

  ```rust
  (Bar, Bat)
  ```

  Assim como nas structs de tupla, os campos são acessados por desestruturação ou por índice numérico.

- As structs anônimas são, como o nome sugere, anônimas, mas com campos nomeados. Talvez você as conheça de outras linguagens, como Go ou Java. Elas não existem em Rust; considera-se idiomático usar uma tupla em vez disso.

# Tipos de tamanho zero

Uma struct pode ter quantos campos forem necessários, sejam muitos ou poucos. A consequência é que é permitido uma struct ter zero campos. Uma struct com zero campos é chamada de **tipo de tamanho zero** e recebe um tratamento especial do compilador: tipos de tamanho zero (frequentemente abreviados como **ZSTs**) nunca consomem espaço na pilha ou no heap, mesmo quando você poderia esperar que consumissem. Por exemplo, `Box<T>` não aloca nenhuma memória no heap se `T` for um ZST.

Você pode usar a sintaxe de struct padrão ou de struct de tupla ao escrever um ZST:

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

Há também uma forma abreviada para ZSTs:

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

Normalmente, ao escrever um ZST, a forma abreviada é a preferida, pois você não pode misturar os estilos: o estilo usado para declarar um ZST[^2] é o mesmo estilo exigido para instanciá-lo.

Depois de toda essa discussão sobre a sintaxe dos ZSTs, vamos falar sobre por que você iria querer uma coisa dessas. Um ZST não pode armazenar nenhum dado, mas é excelente para implementar traits.
