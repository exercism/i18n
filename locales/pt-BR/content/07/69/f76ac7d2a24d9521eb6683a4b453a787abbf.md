# Como escrever um bom pedido de suporte

Quer ajuda com algo do Exercism?
Aumente suas chances de receber uma boa resposta aprendendo a escrever um bom pedido de suporte e incentivando nossa comunidade a te apoiar.

Aqui vão algumas dicas essenciais.

## Use blocos de código, não imagens

Quando você quiser compartilhar código (seja código que você escreveu, seja instruções), use um bloco de código, não uma imagem.

Como desenvolvedores, somos muito mais rápidos lendo código do que tendo que dar zoom numa imagem para enxergar as coisas.
E muitos dos nossos usuários usam leitores de tela, que não conseguem ler imagens.
Então, se você quer ser um bom membro da comunidade, incentivar nossos voluntários a te ajudar e parecer um profissional, compartilhe seu código como texto, não como imagem!

Por exemplo, você pode digitar o seguinte:

````
```
for number in range(10):
  total += number;
```
````

Isso vai ser renderizado assim:

```
for number in range(10):
  total += number;
```

Você pode até ter realce de sintaxe adicionando a linguagem na abertura do bloco de código:

````
```python
for number in range(10):
  total += number;
```
````

que vira:

```python
for number in range(10):
  total += number;
```

## Use linguagem inclusiva

O Exercism é feito de pessoas de gêneros diferentes.
Se você aparecer no nosso Discord e disser coisas como "Hey boys", você exclui imediatamente metade da nossa comunidade.
Isso significa que essas pessoas vão ajudar você menos, mas também significa que o resto da comunidade vai ajudar você menos, porque valorizamos a inclusão no Exercism.

Então, se você quer receber ajuda e quer ser uma pessoa legal, não use linguagem específica de gênero.
Tente "Hey folks", "Hey everyone" ou ouse de verdade e escolha "Hey fellow Exercists!"

Para saber mais sobre isso, leia nosso artigo sobre [as palavras que usamos](./the-words-that-we-use).
