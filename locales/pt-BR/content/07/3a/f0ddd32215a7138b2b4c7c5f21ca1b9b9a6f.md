# Sobre

Existem basicamente dois tipos de laços:

1. Fazer um laço até que uma condição seja satisfeita.
2. Iterar sobre os elementos de uma coleção.

Ambos são [possíveis em R][web-loops], embora o primeiro seja mais comum.

## `while` e `repeat`

Para problemas em aberto, em que não se sabe de antemão quantas vezes o laço será repetido, R tem o laço [`while`][ref-control], com uma condição, e o laço [`repeat`][ref-control], sem condição (equivalente a `while (TRUE)`).

A forma básica é bem simples:

```R
while (condition) {
  do_something()
}
```

Nesse caso, o programa continua repetindo o laço até que `condition` deixe de ser `TRUE`.

Há duas formas de sair do laço antes do fim:

- Um `break` faz o laço terminar, e a execução continua na linha seguinte à chave de fechamento `}` do laço.
- Um `return(x)` interrompe a execução da função atual e devolve o valor de retorno `x` para quem a chamou.

Com essas opções à disposição, às vezes é conveniente criar um laço "infinito" com `repeat { ... }` e contar com a descoberta de uma condição de parada dentro do corpo do laço para disparar um `break` ou um `return`.

Essas três variantes são equivalentes e todas terminam com `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Iterando sobre um vetor (ou outra coleção)

Isso muitas vezes não é necessário em R.
Como discutido em outros conceitos, muitas funções operam sobre vetores inteiros.

Porém, às vezes os laços explícitos são inevitáveis.
Isso acontece principalmente quando:

- O corpo do laço tem efeitos colaterais, como imprimir ou fazer leitura e escrita de arquivos.
- O laço continua até que algum critério seja atingido, depois de um número imprevisível de iterações.

A condição do laço precisa estar entre parênteses.
Assim como no corpo das funções, as chaves são opcionais (mas costumam ser incluídas) em corpos de laço de uma só linha.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Se a iteração atual não satisfizer alguma condição, é possível pular imediatamente para a próxima iteração com um `next`:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

Se você precisar do índice numérico, use [`seq_along()`][ref-seq_along].

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Usar `i in 1:length(v)` _não_ é recomendado, pois pode causar problemas quando `length(v)` é zero.
O intervalo `1:0` é equivalente a `c(1, 0)`, então o corpo do laço será executado e provavelmente vai falhar.
A função `seq_along()` foi feita para lidar com esse caso corretamente.
