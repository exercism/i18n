# Testes dos exercícios

Siga os passos abaixo para desenvolver uma solução para um exercício e testá-la localmente.

## Baixe o exercício

Abra um Command Prompt e execute o comando abaixo com o nome do exercício que você quer baixar.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Desenvolva sua solução

1. Execute o comando abaixo para navegar até o diretório do exercício que você acabou de baixar.

     >**Dica:** O local do diretório no comando abaixo depende do seu sistema operacional e do espaço de trabalho do Exercism que você configurou. Para descobrir o local do seu espaço de trabalho, execute o comando `exercism configure`.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Siga as instruções fornecidas e desenvolva uma solução para o exercício.

## Teste sua solução

Alguns exercícios de Ballerina têm um único teste, enquanto outros têm vários testes. Os testes ficam no arquivo de teste correspondente do diretório `/tests`, dentro do diretório raiz do exercício.

### Testar um exercício com um único teste

Execute o comando abaixo para rodar o teste do exercício.

Por padrão, apenas o primeiro teste fica habilitado. Isso é intencional, pois permite que você se concentre em fazer apenas esse teste passar. 
     
```sh
bal test
```

### Testar um exercício com vários testes

Siga os passos abaixo para testar um exercício com vários testes.

1. Quando o primeiro teste passar, habilite o próximo teste removendo a propriedade `enable: false` da anotação `@test:Config`.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Execute o comando abaixo para rodar o teste habilitado.

   ```sh
     bal test
   ```

3. Repita os dois passos acima para habilitar os testes restantes.

Você concluiu o exercício com sucesso ao habilitar todos os testes e garantir que sua implementação passe em cada um deles.
