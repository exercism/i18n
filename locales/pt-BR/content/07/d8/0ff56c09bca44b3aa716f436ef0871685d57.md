# Sobre

Os `Complex numbers` não são complicados.
Só precisam de um nome menos assustador.

Eles são tão úteis, especialmente em engenharia e ciência, que Julia inclui [números complexos][complex] entre os tipos numéricos padrão, ao lado de inteiros e números de ponto flutuante.

## Noções básicas

Um valor `complex` em Julia é essencialmente um par de números: geralmente, mas nem sempre, de ponto flutuante.
Essas partes são chamadas de "real" e "imaginária", por razões históricas infelizes.
De novo, é melhor focar na simplicidade por trás delas e não nos nomes estranhos.

Para criar números complexos a partir de dois números reais, basta adicionar o sufixo `im` à parte imaginária.

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> typeof(z)
ComplexF64 (alias for Complex{Float64})

julia> zi = 1 + 2im
1 + 2im

julia> typeof(zi)
Complex{Int64}
```

Assim, existem vários tipos `Complex`, derivados do tipo inteiro ou de ponto flutuante correspondente.

Para criar um número complexo a partir de variáveis reais, a sintaxe acima não funciona.
Escrever `a + bim` confunde o parser, que passa a achar que `bim` é um nome de variável (que não existe).

Escrever `b*im` é possível, mas o método preferido usa a função `complex()`.

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

Você pode se perguntar: por que `im` e não `i` ou `j`?

A maioria dos engenheiros fica satisfeita com `j`.
A maioria dos cientistas e matemáticos prefere a notação matemática `i` para _imaginário_, mas essa notação entra em conflito com o uso de `i` para significar _corrente_ na Engenharia Elétrica.

O [manual][complex] afirma que "usar o i dos matemáticos ou o j dos engenheiros para essa constante global foi rejeitado, já que são nomes de variáveis de índice muito populares".

Por uma feliz coincidência, isso também evita longas discussões entre engenheiros e todo o resto.
Fique à vontade para tirar suas próprias conclusões sobre se isso influenciou a decisão.

Para acessar as partes de um número complexo individualmente:

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> real(z)
1.2

julia> imag(z)
3.4
```

Qualquer uma das partes pode ser zero, e os matemáticos podem então falar que o número é "totalmente real" ou "totalmente imaginário".
No entanto, ele continua sendo um número complexo em Julia.

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im

julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})

julia> zi = 3.4im
0.0 + 3.4im

julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

Você talvez já tenha ouvido que "`i` (ou `j`) é a raiz quadrada de -1".

Por enquanto, tudo o que isso significa é que a parte imaginária, _por definição_, satisfaz a seguinte igualdade:

```julia-repl
julia> 1im * 1im == -1
true
```

É uma ideia simples, mas leva a consequências interessantes.

## Aritmética

Todos os `operators` matemáticos padrão e as funções elementares usadas com floats e inteiros também funcionam com números complexos. Uma pequena amostra:

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im

julia> z2 = 2 + 1.5im
2.0 + 1.5im

julia> z1 + z2  # addition
3.5 + 3.5im

julia> z1 * z2  # multiplication
0.0 + 6.25im

julia> z1 / z2  # division
0.96 + 0.28im

julia> z1^2  # exponentiation
-1.75 + 6.0im

julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

Explicar as regras de multiplicação e divisão de números complexos está fora do escopo deste conceito (_e é pouco provável que você precise fazer essas operações "à mão" com frequência_).

Qualquer introdução [matemática][math-complex] ou de [engenharia elétrica][engineering-complex] aos números complexos cobre isso, caso você queira se aprofundar no assunto.

Como alternativa, o Exercism tem um exercício de prática `Complex Numbers` em que você pode implementar do zero uma classe de números complexos com essas operações.

A divisão inteira (na maioria dos casos) ___não___ é possível com números complexos, então os operadores `//`, `÷` e `%` falham para o tipo de número complexo.
Uma exceção é usar `//` com _inteiros_ complexos para obter números racionais complexos, mas isso provavelmente raramente é útil.

## Funções

A maioria das funções matemáticas funciona com entradas complexas.

No entanto, fornecer entradas reais e esperar uma saída complexa geralmente não funciona.
Essa é uma otimização de desempenho que deve fazer mais sentido depois de você ver o conceito de Multiple Dispatch.

```julia-repl
julia> sin(1.5 + 2.0im)
3.752771340479298 + 0.25655395609048176im

julia> sqrt(-1)
ERROR: DomainError with -1.0:
sqrt was called with a negative real argument but will only return a complex result if called with a complex argument. Try sqrt(Complex(x)).

julia> sqrt(-1 + 0im)
0.0 + 1.0im
```

Existem várias funções, além de `real()` e `imag()`, com relevância especial para números complexos.
Pule essas se elas não fizerem sentido para você!

- `conj()` simplesmente inverte o sinal da parte imaginária de um número complexo (_de + para - ou vice-versa_).
    - Por causa de como a multiplicação de complexos funciona, isso é mais útil do que você imagina.
- `abs(<complex number>)` tem a garantia de retornar um número real sem parte imaginária.
- `abs2(<complex number>)` retorna o quadrado de `abs(<complex number>)`: mais rápido de calcular que `abs()`, e muitas vezes é exatamente o que um cálculo precisa.
- `angle(<complex number>)` retorna o ângulo de fase em radianos.

```julia-repl
julia> z1
1.5 + 2.0im

julia> conj(z1)
1.5 - 2.0im

julia> abs(z1)
2.5

julia> abs2(z1)
6.25

julia> angle(z1)
0.9272952180016122
```
Uma explicação parcial, para quem gosta de matemática _(de novo, fique à vontade para pular)_:

- A representação `(real, imag)` de `z1` usa, na prática, coordenadas cartesianas no plano complexo.
- O mesmo número complexo pode ser representado na notação `(r, θ)`, usando coordenadas polares.
- Aqui, `r` e `θ` são dados por `abs(z1)` e `angle(z1)`, respectivamente.

Veja um exemplo usando algumas constantes:

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im

julia> real(euler)
-1.0

julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

Então uma expressão simples com três das constantes mais importantes da natureza, `e`, `i` (ou `j`) e `pi`, dá o resultado `-1`.
Algumas pessoas acreditam que este é o resultado mais bonito de toda a matemática.
Ele remonta a cerca de 1740.

A notação polar `(r, θ)` é tão útil que existem funções embutidas `cis` (abreviação de `cos(x) + isin(x)`) e `cispi` (abreviação de `cos(πx) + isin(πx)`) que podem ajudar a construí-la de forma mais eficiente.

A utilidade da notação polar aparece na elegante fórmula de Euler, `ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`, em que `|x + iy| = 1`.
Com `|x + iy| = r`, temos a forma polar mais geral `r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`.
Repare que a forma exponencial, em particular, é compacta e fácil de manipular.

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

A igualdade aproximada acima acontece porque as funções [`cis`][cis] e [`cispi`][cispi] podem dar resultados numéricos mais agradáveis, especialmente `cispi` quando lidamos com argumentos que são fatores arbitrários de π (por exemplo, radianos!).

```julia-repl
julia> cis(π)
-1.0 + 0.0im

julia> cispi(1)
-1.0 + 0.0im

julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im

julia> cis(θ)
6.123233995736766e-17 + 1.0im

julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

Aliás, isso torna os números complexos muito úteis para realizar rotações e deslocamentos radiais em 2D.

Para rotações, o número complexo `z = x + iy` pode ser rotacionado de um ângulo `θ` em torno da origem com uma simples multiplicação: `z * ℯ^(iθ)`.
Repare que `x` e `y` aqui são apenas as coordenadas usuais no plano cartesiano real 2D, e um ângulo positivo resulta em uma rotação *anti-horária*, enquanto um ângulo negativo resulta em uma rotação *horária*.

De forma igualmente simples, um deslocamento radial `Δr` pode ser feito somando-o à magnitude `r` de um número complexo na forma polar (por exemplo, `z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`).
Repare como a parte angular permanece a mesma e apenas a magnitude, `r`, varia, como esperado.

## Seção opcional: perguntas frequentes sobre números complexos

Esta parte pode ser pulada, a menos que você tenha interesse.

### Isso não é algum ramo novo e estranho da matemática pura?

Era estranho e novo no século XVI.

500 anos depois, é central para a maior parte da engenharia e das ciências físicas.

### Por que alguém usaria isso?

Acontece que os números complexos são a forma mais simples de descrever qualquer coisa que gire ou que tenha uma propriedade ondulatória.
Por isso são usados amplamente em engenharia elétrica, processamento de áudio, física, jogos de computador e navegação, para citar apenas algumas aplicações.

Você consegue ver coisas girando.
Os números complexos talvez não façam o mundo girar, mas são ótimos para explicar _o que acontece_ como resultado de o mundo girar: veja qualquer imagem de satélite de uma grande tempestade.

De forma menos óbvia, o som é ondulatório, a luz é ondulatória, os sinais de rádio são ondulatórios e até a economia do seu país é, pelo menos em parte, ondulatória.

Boa parte desse processamento de ondas pode ser feito com funções trigonométricas (`sin()` e `cos()`), mas isso fica confuso bem rápido.

As exponenciais complexas são ___muito___ mais fáceis de trabalhar.

### Mas eu não preciso de números complexos!

Só é verdade se você morar numa caverna e buscar seu próprio alimento.

Se você está lendo isto em qualquer tipo de tela, você depende totalmente de alguns avanços úteis do século XX feitos por meio do uso de números complexos.

1. __Chips semicondutores__.
    - Eles não fazem sentido na física clássica e só podem ser explicados (e projetados) pela mecânica quântica (MQ).
    - Na MQ, tudo tem valor complexo por definição. (_é só forma de onda até o fim_)

2. __O algoritmo da Transformada Rápida de Fourier__.
    - A FFT é uma aplicação dos números complexos e está em _tudo_ ligado à transmissão de som, processamento de áudio, fotos e vídeo.

    - O MP3 e outros formatos de áudio usam a FFT para compressão, garantindo que mais áudio caiba em um espaço de armazenamento menor.
    - A compressão JPEG e o vídeo MP4, entre muitos outros formatos de imagem e vídeo, também usam a FFT para compressão.

    - A FFT também é usada nos filtros digitais que permitem às torres de celular separar o seu sinal pessoal do sinal de todo mundo.

Então você provavelmente usa tecnologia que depende de cálculos com números complexos milhares de vezes por segundo.
