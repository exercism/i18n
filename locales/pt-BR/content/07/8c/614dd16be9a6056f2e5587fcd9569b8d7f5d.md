# Instruções

Determine se um determinado conjunto de três dominós pode ser organizado de modo a formar uma corrente de dominós correta: os pontos de uma metade de uma pedra coincidem com os pontos da metade vizinha de uma pedra adjacente. Além disso, os pontos das metades das pedras que não têm vizinho (a primeira e a última pedra) precisam coincidir entre si. Alguns casos de teste podem usar pedras duplicadas em uma solução de corrente. Retorne `True` se for possível montar uma corrente de dominós correta e `False` caso contrário.

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
