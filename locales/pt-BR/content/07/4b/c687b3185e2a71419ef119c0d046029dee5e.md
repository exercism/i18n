# Apêndice

## "Null" no Tcl

O Tcl não tem um valor `null` ou `nil`.
Na prática, a string vazia costuma ser usada para indicar "nenhum valor".
Mas isso pode ser complicado em situações em que uma string vazia é de fato um valor válido, por exemplo em uma lista que representa uma linha de dados CSV.

Neste exercício, trate a string vazia como um valor null que deve ser descartado.
