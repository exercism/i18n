# Dicas

## Geral

As condicionais servem para verificar certas condições e/ou critérios. A forma mais básica de realizar uma operação condicional é usar uma única condicional `if`.

## 1. Calcular a pontuação de qualquer carta.

A função `parseCard` deve receber a string `card` (por exemplo, `ace`) e transformá-la em seu valor (por exemplo, 11).

- Use uma grande [instrução `switch`][switch-statement] na variável `card`.
- Rei, Dama, Valete e 10 podem ser tratados com um único case.
- O `switch` pode ter um caso `default`. De qualquer forma, a função deve retornar `0` para cartas desconhecidas.

## 2. Determinar se duas cartas formam um Blackjack.

`isBlackJack` verifica se 2 cartas têm o valor combinado de 21.

- Deve usar a função `parseCard` para obter o valor de cada carta.
- Deve somar os valores das 2 cartas.
- Deve retornar `true` se a soma for igual a `21`.
- Nenhuma instrução adicional é necessária aqui. O resultado da comparação pode ser retornado.

## 3. Implementar a lógica de decisão para pontuações de mão maiores que 20 pontos.

Como a função `largeHand` só é chamada para mãos com valor maior que 20, só existem 2 mãos possíveis: um **BlackJack** com valor total de `21` e **2 ases** com valor total de `22`.

- A função deve verificar [se][if-statement] `isBlackJack` é `true` e retornar "P" caso contrário.
- Se `isBlackJack` for `true`, é preciso verificar se o dealerScore é menor que 10. [Se][if-statement] for menor, retorne "W", caso contrário "S".

## 4. Implementar a lógica de decisão para pontuações de mão com menos de 21 pontos.

A função `smallHand` só é chamada se não houver ases na mão (`handScore` é menor que 21).

- Implemente cada condição usando [operadores lógicos][logical-operators] se necessário:
  - [Se][if-statement] a soma das suas cartas for 17 ou mais, você deve sempre _parar_.
  - [Se][if-statement] a soma das suas cartas for 11 ou menos, você deve sempre _pedir carta_.
  - [Se][if-statement] a soma das suas cartas estiver no intervalo [12, 16], você deve sempre _parar_ se o dealer tiver 6 ou menos.
  - [Se][if-statement] a soma das suas cartas estiver no intervalo [12, 16], você deve sempre _pedir carta_ se o dealer tiver 7 ou mais.
- (opcional) Tente otimizar as condições:
  - Junte as condições para _parar_ em uma só.
  - Junte as condições para _pedir carta_ em uma só.
  - Remova as partes redundantes das condições (por exemplo, `A || !A && B` pode ser `A || B`).
