# Dicas

## Geral

- Não existe `new` em uma classe imutável. O `create` começa com uma variável
  da classe, que já existe:

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)` não altera `b`. Ele retorna um novo rumo, e é por isso que
  esse rumo é o valor retornado.

## 1. Obter um rumo

- O `%` coloca um número dentro do intervalo, mas `-10 % 360` dá `350` só
  porque o `%` do Sather nunca dá negativo quando o lado direito é positivo.
  Então `d % 360` já basta por si só.

## 2. Girar

- Some o giro aos degrees e crie um novo rumo a partir do total:
  `#BEARING(degrees + by)`.
- O `create` já traz a resposta de volta para dentro do intervalo, então não há
  nada a fazer quando o giro passa de north.

## 3. Comparar

- Uma linha só: compare os dois `degrees`.
- O tipo do argumento é `SAME`, e você lê o atributo dele do jeito de sempre:
  `other.degrees`.

## 4. Nomear o ponto

- O truque é deslocar meio segmento antes de dividir, para que o que se mede
  seja o *centro* de cada ponto:
  `((degrees + 22) / 45) % 8` dá 0 para north, 1 para north-east, e assim por
  diante.
- Depois, um `case` sobre esse número, com os oito nomes, e também um `else`,
  que o `case` sempre precisa, mesmo quando os oito ramos cobrem todos os
  valores possíveis.

## 5. Escrever o resultado

- O `+` junta as partes, mas só uma string pode ter coisas somadas a ela. Aqui
  o número vem primeiro, então ele precisa de `degrees.str` para começar a
  junção. `"a" + 1` funciona; `1 + "a"` não compila.
- Chame `point` em vez de calcular o nome de novo.
