# Anexo das instruções

## Sintaxe do Lean

Este exercício vai exigir que você defina uma sintaxe para uma DSL parecida com a linguagem DOT.

Essa tarefa provavelmente vai exigir que você use notações ou macros.
Talvez valha a pena dar uma olhada em uma [referência][macro-reference].

~~~~exercism/note
Neste exercício, as arestas são representadas por um único `-` entre os nós, em contraste com o `--` usado na linguagem DOT de verdade.
Isso evita conflitos com a sintaxe de comentário de linha única do Lean.

Além disso, toda instrução termina em `;`, até mesmo os comentários no nível do grafo.
~~~~

[macro-reference]: https://lean-lang.org/doc/reference/latest/Notations-and-Macros/#language-extension
