# Instruções

É Dia dos Namorados. Seu parceiro tem algumas ideias de atividades e está
pedindo que você avalie cada uma: `yes`, `no` ou `maybe`.

As atividades são representadas como arrays de 2 elementos `{ tag value }`,
onde `tag` é um entre `board-game`, `chill`, `movie`, `restaurant`
ou `walk`.

| atividade                     | formato                     |
| ----------------------------- | --------------------------- |
| Jogar um jogo de tabuleiro    | `{ board-game f }`          |
| Relaxar                       | `{ chill f }`               |
| Assistir a um filme de `genre` | `{ movie genre }`          |
| Comer em um lugar de `cuisine` | `{ restaurant cuisine }`   |
| Caminhar `km` quilômetros     | `{ walk km }`               |

O gênero é um entre `crime`, `horror`, `romance`, `thriller`. A
culinária é `korean` ou `turkish`.

## 1. Avalie a culinária

Defina `rate-restaurant` para pegar uma culinária da pilha e retornar
sua aprovação:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. Avalie o gênero do filme

Defina `rate-movie` para pegar um gênero e retornar:

- `romance` → `yes`
- qualquer outra coisa → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. Avalie a caminhada

Defina `rate-walk` para pegar um número de quilômetros e retornar:

- mais de `11` → `yes`
- mais de `6`, até `11` → `maybe`
- caso contrário → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. Avalie a atividade

Defina `rate-activity` para pegar uma atividade `{ tag value }` da
pilha e retornar sua aprovação. Reutilize os auxiliares acima:

- `board-game`, `chill` → sempre `no`
- `movie` → delegue para `rate-movie`
- `restaurant` → delegue para `rate-restaurant`
- `walk` → delegue para `rate-walk`

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. Conte as aprovações

Defina `approval-counts` para pegar uma lista de atividades e retornar um
array de 3 elementos `{ yes-count maybe-count no-count }` com quantas
foram avaliadas de cada forma.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
