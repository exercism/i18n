## Instruções

Sua tarefa é gerar os labirintos perfeitos para Mickey e Minerva: aqueles com apenas uma solução e sem seções isoladas.
Eis o que você precisa saber:

- O labirinto tem formato retangular, com uma abertura no início e no fim.
- O labirinto tem salas e passagens, que se cruzam em ângulos retos.
- O programa deve aceitar dois parâmetros: linhas e colunas. O labirinto deve ter entre 5 e 100 casas.
- Um labirinto com `x` colunas de largura e `y` linhas de altura deve ter `2x + 1` caracteres de largura e `2y + 1` caracteres de altura.
- Se nenhuma semente for fornecida, gere um labirinto aleatório. Se a mesma semente for fornecida várias vezes, o labirinto resultante deve ser o mesmo todas as vezes.
- Use [caracteres de desenho de caixas][Box-drawing] para desenhar as paredes, e um símbolo de seta (⇨) para a entrada à esquerda e a saída à direita.

Está na hora de criar labirintos perfeitos para esses ratinhos aventureiros!

### Exemplos

1. O pequeno labirinto quadrado de 5x5 casas (ou 11x11 caracteres)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. O labirinto retangular de 6x18 casas
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
