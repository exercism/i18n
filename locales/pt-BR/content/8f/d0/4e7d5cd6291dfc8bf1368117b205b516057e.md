# Operador de resolução de escopo

O operador de resolução de escopo (`::`) permite referenciar uma classe para acessar suas constantes de nome, propriedades estáticas ou métodos estáticos.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Usar `self` e `static` com o operador de resolução de escopo

Pode ser necessário que um objeto referencie seu próprio escopo. Para isso, a palavra-chave `self` permite que uma classe referencie seu próprio escopo. Usar a palavra-chave `self` desacopla a classe do seu próprio nome, o que facilita a manutenção do código ao longo do tempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Use a palavra-chave `static` com o operador de resolução de escopo para fazer uma "ligação tardia" da referência à classe descendente atual.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Usar `parent` com o operador de resolução de escopo

A palavra-chave `parent` é usada para referenciar uma constante, uma propriedade ou um método da classe pai. Normalmente, ela é usada para chamar o construtor da classe pai quando um objeto está sendo instanciado:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Ressalvas

### Visibilidade de constantes, propriedades e métodos

O operador de resolução de escopo ainda segue as regras definidas pelos modificadores de visibilidade `public`, `private` e `protected`.
