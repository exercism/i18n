# Dicas

## 1. Configure os tipos de usuário e as permissões.

- Para lidar com cada enumerador de `AccountStatus`, você poderia usar uma condicional `if`, mas uma [instrução `switch`][switch] é uma ótima alternativa.


## 2. Promova trolls apenas a outros trolls.

- Você pode comparar enumerações como qualquer outro tipo com os operadores `!=` e `==`.

## 3. Verifique as permissões para usuários diferentes.

- Se você resolver a tarefa com uma instrução switch, os [fallthroughs][fallthrough] podem ser úteis.
- Você pode usar [rótulos sequenciais][fallthrough] e o rótulo [default][switch] para agrupar permissões.

## 4. Conceda acesso ao jogo e emparelhe jogadores.

- Suas principais preocupações são as contas `guest` e `troll`. Para as outras combinações, você não precisa dividir a sua lógica.

## 5. Construa uma fila de prioridades.

- Se você ordenar corretamente sua enumeração `AccountStatus`, pode usar `static_cast<int>` para comparar os enumeradores de forma compacta.
