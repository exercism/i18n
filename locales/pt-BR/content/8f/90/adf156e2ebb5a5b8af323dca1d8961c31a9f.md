# Apêndice das instruções

## Algumas observações adicionais para a implementação em C++

Este exercício usa o [contêiner vector][vector].
Talvez seja útil usar o cabeçalho [algorithm][algorithm] para resolver este exercício.

Algumas das funções de algorithm precisam de [`iterators`][iterator] como argumentos.
Eles podem ser vistos como marcadores de onde um contêiner começa e termina.
Se você quiser percorrer o contêiner inteiro, comece com `my_container.begin()` e termine com `my_container.end()`.
Se você quiser apenas os elementos 2, 3 e 4 de um vector, pode usar `my_vector.begin() + 2` e `my_vector.begin() + 4`.

Os últimos testes verificam a [imutabilidade][immutability].
Nenhuma das funções que você deve escrever deve alterar a pontuação do jogo.

Se você quiser praticar um pouco mais, pode implementar uma função que adiciona novas pontuações ao jogo.
