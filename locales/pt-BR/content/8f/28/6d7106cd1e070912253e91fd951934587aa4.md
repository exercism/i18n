# Introdução

Usar `try..rescue` é uma construção poderosa para capturar erros quando eles acontecem. Capturar erros permite que as funções retornem valores definidos quando isso for necessário. A construção `try..rescue` também nos oferece dois recursos adicionais que podemos usar:

- o bloco `else`
  - Quando o bloco `try` tem sucesso, o resultado é comparado com este bloco.
- o bloco `after`
  - Independentemente de o bloco `try` ter sucesso ou lançar um erro, o código no bloco `after` sempre é executado, desde que o programa ainda esteja rodando nesse ponto.
  - O resultado do bloco `after` não é retornado ao escopo que fez a chamada.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
