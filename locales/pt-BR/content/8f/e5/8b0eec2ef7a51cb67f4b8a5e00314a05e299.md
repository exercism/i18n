# Integração de funcionários no banco de dados

## Enunciado do problema

A ABC Corp está planejando manter em um banco de dados todas as informações de pagamentos de pequenas despesas feitos aos funcionários. Você está ajudando o departamento financeiro da ABC Corp a implementar isso. Como a ABC Corp está expandindo suas operações, adicionar novos funcionários ao sistema é um requisito comum por causa das novas contratações.

Sua tarefa é adicionar à tabela `Employee` do banco de dados os dados do novo funcionário fornecidos e retornar o valor da coluna `employee_id` gerada automaticamente, sem fazer outra consulta ao banco de dados para descobri-lo. Se ocorrer um erro durante a execução, `-1` deve ser retornado.

## Detalhes do banco de dados

Use o banco de dados H2 fornecido para este problema.

> O arquivo do banco de dados de exemplo é `gofigure.mv.db`, e o nome do banco de dados é `gofigure`. Ele está dentro da pasta `db`.

As tabelas a seguir já estão no banco de dados H2 de exemplo, com alguns dados de exemplo. Os nomes das colunas e os tipos de dados estão abaixo.

**Nome da tabela** : `Employee`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | inteiro, chave primária com incremento automático       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | inteiro        |

**Nome da tabela**: `Payment`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | inteiro, chave primária com incremento automático       |
| `date`            | data        |
| `amount`          | decimal        |
| `employee_id`     | inteiro        |
| `reason`          | string        |

* O arquivo do banco de dados é `gofigure.mv.db`. Use a URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nome de usuário: `root`
* Senha: `root`

## Restrições

* Use o arquivo do banco de dados H2 fornecido na pasta `db` para validar as consultas e o exemplo de Ballerina
* Use a abordagem de parâmetros de dependência do maven para adicionar o driver do banco de dados H2 como uma dependência de plataforma no seu Ballerina.toml
* Não faça outra consulta ao banco de dados para encontrar o id gerado automaticamente


## Ambiente de teste

* Você pode rodar os testes com `bal test`, e eles serão executados contra o banco de dados de exemplo fornecido.
