# Instruções

Neste exercício, você tem a tarefa de escrever o software de um dispositivo de criptografia que funciona realizando transformações em dados.
Você precisa de uma forma de criar funções complicadas com flexibilidade, combinando funções mais simples.

Para cada tarefa, retorne um bloco que possa ser invocado a partir do escopo de quem faz a chamada.

## 1. Crie um somador

Implemente `secret-add`.
Ela deve retornar uma função que recebe um argumento e soma a ele o argumento passado para `secret-add`.

## 2. Crie um subtrator

Implemente `secret-subtract`.
Ela deve retornar uma função que recebe um argumento e subtrai desse argumento o segredo passado para `secret-subtract`.

## 3. Crie um multiplicador

Implemente `secret-multiply`.
Ela deve retornar uma função que recebe um argumento e multiplica esse argumento pelo segredo passado para `secret-multiply`.

## 4. Crie um divisor

Implemente `secret-divide`.
Ela deve retornar uma função que recebe um argumento e divide esse argumento pelo segredo passado para `secret-divide`.

## 5. Crie um combinador de funções

Implemente `secret-combine`.
Ela deve retornar uma função que recebe um argumento e aplica a ele, em ordem, as duas funções passadas para `secret-combine`.
