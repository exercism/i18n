# Introdução

Um `bit` é o valor mais granular da computação.
A palavra `bit` significa "dígito binário".
É uma unidade de armazenamento de dados no ambiente de execução, grande o suficiente para conter um objeto que pode ter um de dois valores.
Assim, ele tem um valor binário de `1` ou `0`.
Todos os outros tipos de dados são compostos de vários `bits`.
Por exemplo, um `byte` geralmente é composto de oito `bits`.

## Máscaras de bits

Uma máscara de bits pode ser qualquer valor usado para definir bits individuais.
Por exemplo, há vinte e seis letras no alfabeto inglês.
Um valor de pelo menos vinte e seis bits, como um inteiro sem sinal de 32 bits, poderia ser usado como máscara de bits para definir uma condição `true` ou `false` para cada letra inglesa.
Qualquer valor com bits suficientes para lidar com um conjunto necessário de condições `true` ou `false` pode servir como máscara de bits.
Definir e ler os bits individuais é feito por meio do uso de operadores bit a bit.

## Operadores bit a bit

Digamos que queremos acompanhar quais letras aparecem em uma `string`.
Para nosso exemplo, vamos usar apenas as vinte e seis letras do alfabeto inglês.
Nossa máscara de bits será um inteiro sem sinal de 32 bits.
Um `0` vai representar que a letra não ocorre.
Um `1` vai representar que a letra ocorre uma ou mais vezes.
No início, a representação em bits da nossa máscara de bits será 32 `0s` em sequência: `00000000000000000000000000000000`.
A posição mais à direita será para `A`.
A segunda posição a partir da esquerda será para `B`, e assim por diante.
Digamos que estamos processando todas as letras da string em um laço, então queremos uma linha de código que funcione para definir qualquer letra.

### Operador de deslocamento à esquerda bit a bit: uma forma de posicionar um bit

`<<` é o operador bit a bit para deslocar à esquerda.

Se nossa letra for `A`, não queremos deslocar à esquerda, mas se nossa letra for `B`, queremos deslocar à esquerda uma posição, e se nossa letra for `C`, queremos deslocar à esquerda duas posições, e assim por diante.
Embora possamos enxergar `chars` como letras como `A` ou `B`, um `char` é implementado como um tipo inteiro na memória, então podemos fazer cálculos simples com um `char`.
Dada uma variável chamada `letter` que representa o `char` que estamos processando, podemos deslocar à esquerda o número necessário de posições deslocando `1` à esquerda pela diferença entre `letter` e o `char` `A`, assim: `1 << letter - 'A'`.
`A` - `A` é `0`, então deslocaria `0` posições à esquerda se `letter` for `A`.
`B` - `A` é `1`, então deslocaria `1` posição à esquerda se `letter` for `B`, e assim por diante.

### Operador OU inclusivo bit a bit: uma forma de definir um bit

Depois que sabemos _onde_ queremos definir um bit, podemos de fato defini-lo usando o operador OU inclusivo bit a bit, que é `|`.
O resultado do operador `|` será `1` em cada posição onde o operando esquerdo ou o direito tiver um bit definido.
Assim, o resultado de `0010 | 0001` seria `0011`.
(É importante lembrar que o valor é `11` em binário, mas é `3` em decimal.)
Para atribuir o resultado a um valor, o operador `|` pode ser combinado com o operador de atribuição para definir os bits assim: `|=`.
Para simplificar, o exemplo a seguir não usa um laço, mas demonstra como poderíamos processar as letras `ABA` em uma máscara de bits.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Definimos a parte mais à direita da nossa máscara como `0001` para `A`, e depois definimos a máscara como `0011` para `B`.
Definir outro `A` não altera a máscara existente.
Poderíamos ter evitado definir o bit novamente verificando se `A` já havia sido definido.

### Operador E bit a bit: uma forma de ler um bit

`&` é o operador E bit a bit.
O resultado do operador `&` será `1` em cada posição onde tanto o operando esquerdo quanto o direito tiverem um bit definido.
Assim, o resultado de `0011 & 0001` seria `0001`.
Podemos ver isso em ação no exemplo a seguir.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Operador OU exclusivo bit a bit: uma forma de inverter um bit

`^` é o operador OU exclusivo bit a bit.
Um operador OU _inclusivo_ implica que existe um operador OU _exclusivo_ com comportamento diferente.
O resultado do operador `^` será `1` em cada posição onde _apenas um_ dos operandos esquerdo ou direito tiver um bit definido.
Assim, o resultado de `0001 ^ 0011` seria `0010`.
O bit mais à direita não será definido porque _ambos_ os operandos têm `1` na posição mais à direita.
A operação OU exclusivo às vezes é representada como XOR.
Se o resultado de um valor que passou por XOR passar por XOR de novo, ele retornará o valor original.
Isso pode ser usado para uma criptografia bem simples, em que a mesma chave é usada tanto para criptografar quanto para descriptografar os dados.
Por exemplo

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## Campos de bits

Vimos como bits empacotados em um tipo de dados simples podem ser acessados por sua posição.
Bits empacotados em uma `struct` podem ser acessados pelo nome.
Esse tipo de dados é chamado de `bit field`.
Um caso de uso para `bit fields` pode ser quando uma coleção de flags ON/OFF é necessária e se deseja minimizar o uso de memória.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

A sintaxe de `unsigned int variable_name : 1;` cria um campo de `1` bit dentro de um `unsigned int` colocado dentro da struct.
Em vez de um `unsigned int`, poderia ser usado um `signed int` ou, a partir do C99, um tipo `bool`.
Uma struct contendo campos de bits também pode conter campos de outros tipos de dados, como `number_of_lights` no exemplo acima.
