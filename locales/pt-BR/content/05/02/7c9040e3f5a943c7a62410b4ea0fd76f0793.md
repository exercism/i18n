# Instruções

Neste exercício, você vai gerar mensagens de log semiestruturadas.

## 1. Emitir mensagens semiestruturadas

Você vai começar com algumas funções incompletas e o seguinte enum:

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

Seu objetivo é emitir uma mensagem de log no seguinte formato: `"[<LEVEL>]: <MESSAGE>"`.
Você vai precisar implementar funções que correspondem aos níveis de log.

Por exemplo, o trecho abaixo mostra uma saída esperada para a função `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

E para `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Divirta-se!

## 2. Prática extra opcional

Nesta suíte há um teste controlado por uma feature.
As feature gates desativam completamente a compilação de certas partes do seu programa.
Elas serão abordadas mais adiante.
Por enquanto, saiba apenas que existe um teste que só é compilado e executado quando você usa uma invocação de teste especial:

```sh
cargo test --features add-a-variant
```

Este teste tem o objetivo de mostrar como adicionar uma variante ao seu enum.
