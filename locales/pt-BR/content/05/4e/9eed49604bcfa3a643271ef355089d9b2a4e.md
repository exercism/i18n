# Introdução

O [operador condicional ternário][ternary-operator] é uma forma abreviada e concisa de uma expressão `if-else`.
Ele avalia uma condição e retorna um de dois valores, dependendo de a condição ser `true` ou `false`.

O operador usa três partes: `condition ? trueExpression : falseExpression`.
Se `condition` for `true`, o valor de `trueExpression` é avaliado e retornado; caso contrário, o valor de `falseExpression` é avaliado e retornado.

O operador ternário é ideal para escolhas simples, de uma linha só:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

O exemplo acima é um equivalente compacto de:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
