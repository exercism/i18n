# Dicas

## 1. Criar um novo placar de recordes

- Crie um novo objeto usando chaves.
- Escreva a chave como uma string para que ela possa conter espaços.
- Separe a chave e o valor com dois-pontos.

## 2. Adicionar jogadores a um placar

- Use a notação de colchetes para adicionar uma chave com um nome que está armazenado em uma variável (o argumento).
- Use o operador de atribuição (`=`) para definir um valor para a nova chave.
- Como alternativa, use o [operador `+`][man-plus] para mesclar o objeto recebido com um novo.
- Lembre-se de que os parênteses são necessários em volta das expressões usadas como chaves de objeto.

## 3. Remover jogadores de um placar

- Use a [expressão `del`][man-del].
- Referencie a chave como você fez na tarefa anterior (notação de colchetes).
- Lembre-se de que o argumento de `del` é uma _expressão de índice_, não apenas uma string.

## 4. Aumentar a pontuação de um jogador

- Primeiro, pense em como expressar o novo valor que você quer atribuir.
- Depois, use o operador de atribuição como na tarefa 2 para definir esse novo valor.
- Se ainda não fez isso, você pode usar o [operador de atribuição e atualização aritmética][man-update-assignment] `+=`.

## 5. Aplicar os pontos de bônus de segunda-feira

- Este seria um bom lugar para usar `to_entries`/`from_entries`, ou `with_entries`, para iterar sobre o objeto
- Para cada chave, defina o novo valor como você fez na tarefa 4.

## 6. Encontrar a pontuação total

- Queremos iterar sobre os _valores_ do objeto.
  Podemos usar [`map_values`][man-map_values], ou [`.[]`][man-brackets] para produzir um fluxo de valores.
- A expressão `add` pode ser usada para encontrar a soma de uma lista de números.
