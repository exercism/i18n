# Testes

## Testando interativamente

Inicie o REPL a partir do diretório em que você baixou o exercício.

Você pode executar os testes carregando o arquivo de teste no REPL com `(load "exercise-test")` (substituindo "exercise" pelo nome apropriado). Depois, avalie `(exercise-test:run-tests)` para executar todos os testes.

Se você escrever seu código diretamente no REPL, basta avaliar `(exercise-test:run-tests)`.

Se você escrever seu código no arquivo lisp do exercício, carregue-o com `(load "exercise")` e depois avalie `(exercise-test:run-tests)`.

## Testando pela linha de comando

Você pode iniciar os testes com esta chamada de linha de comando (de novo, substitua "exercise" pelo nome apropriado nos dois lugares)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
