# Anexo das instruções

## Dicas

Uma das utilidades das tuplas é retornar vários valores de uma função. Neste exercício, escreva uma função que retorna uma tupla (a parte x e a parte y de uma coordenada).

Para saber mais sobre tuplas, veja [este link](https://docs.microsoft.com/en-us/dotnet/api/system.tuple).
