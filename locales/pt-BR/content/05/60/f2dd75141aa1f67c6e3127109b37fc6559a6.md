# Instalação

- macOS: rode `brew install futhark`
- linux: rode `brew install futhark`
- Windows: use o WSL ou siga as [instruções específicas para Windows][windows-specific-instructions]

Você encontra outras formas de instalação nas [instruções oficiais de instalação][instructions].

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
