# Introdução ao Básico

[Go](https://golang.org) é uma linguagem de programação compilada e de tipagem estática.
Go é sintaticamente semelhante a C.
A linguagem costuma ser chamada de Golang por causa de seu antigo nome de domínio, golang.org, mas o nome correto é Go.

O conceito Básico vai apresentar três recursos importantes da linguagem: pacotes, funções e variáveis.

## Pacotes

As aplicações Go são organizadas em pacotes.
Um pacote é uma coleção de arquivos-fonte no mesmo diretório.
Todos os arquivos-fonte em um diretório devem compartilhar o mesmo nome de pacote.
É convenção que o nome do pacote seja o último diretório no caminho de importação.
Por exemplo, os arquivos do [pacote "math/rand"](https://golang.org/src/math/rand/) começam com a instrução `package rand`.
Quando um pacote é importado, só podem ser usadas / acessadas as entidades (funções, tipos, variáveis, constantes) cujos nomes começam com letra maiúscula.
O estilo recomendado de nomenclatura em Go é nomear identificadores com `camelCase`, exceto aqueles que devem ser acessíveis entre pacotes, que devem usar `PascalCase`.

```go
package lasagna
```

## Variáveis

Go tem tipagem estática, o que significa que todas as variáveis [precisam ter um tipo definido](https://en.wikipedia.org/wiki/Type_system) em tempo de compilação.

Variáveis podem ser definidas especificando um tipo explicitamente:

```go
var explicit int // Explicitly typed
```

Você também pode usar um inicializador, e o compilador vai definir o tipo da variável para corresponder ao tipo do inicializador.

```go
implicit := 10   // Implicitly typed as an int
```

Depois de declarada, uma variável pode receber valores usando o operador `=`.
Depois de declarada, o tipo de uma variável nunca pode mudar.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

Constantes guardam um dado, assim como as variáveis, mas o valor delas não pode mudar durante a execução do programa.

Constantes são definidas com a palavra-chave `const` e podem ser números, caracteres, strings ou valores Boolean:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funções

Funções em Go aceitam zero ou mais parâmetros.
Os parâmetros precisam ter tipo explícito, não há inferência de tipo.

As funções retornam valores usando a palavra-chave `return`.

Uma função é invocada especificando seu nome e passando argumentos para cada um dos seus parâmetros.

Repare que Go aceita dois tipos de comentários.
Comentários de uma linha são precedidos por `//`, e comentários de várias linhas são inseridos entre `/*` e `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
