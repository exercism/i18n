# Informações adicionais

## GNU awk e aritmética de precisão arbitrária

Por padrão, os números em `awk` são representados como números de ponto
flutuante de precisão dupla. Isso oferece 53 bits de precisão (veja a [Tabela
16.3][table-16.3] no manual). Infelizmente, isso não é suficiente para
concluir este exercício (alerta de spoiler: um dos testes exige 63 bits de
precisão).

"Precisão insuficiente" fica assim:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

O GNU `awk` tem a capacidade de usar números de precisão arbitrária, se as
bibliotecas relevantes tiverem sido compiladas no executável do `awk`. Verifique
a versão do seu awk e procure por "GNU MPFR":
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

Se estiver presente, habilite o recurso usando a opção `-M`:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

E se o meu `awk` não tiver a opção `-M`? Você vai ter que chamar um programa
externo que consiga fazer aritmética de precisão arbitrária, como o `bc`. Veja a
seção [Usando getline em uma variável a partir de um pipe][getline-pipe] para ver
um exemplo de como fazer isso.
