# Anexo às instruções

## Como lidar com casos extremos

Linguagens diferentes no Exercism têm expectativas diferentes sobre qual deve ser o resultado quando o comprimento das substrings é zero.
Na trilha Rust, não temos um teste para esse caso, então você é livre para fazer o que achar mais apropriado.

Considere as vantagens e desvantagens das seguintes possibilidades:
- Derrubar o programa com `panic!`.
- Retornar um `Result::Err`. (não é possível aqui, porque a assinatura da função é fornecida)
- Retornar um vetor vazio.
- Retornar um vetor contendo tantas strings vazias quanto o comprimento da string "digits" **mais um**. (isso tem algumas propriedades matemáticas bem legais!)
