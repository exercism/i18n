# Introdução

As classes são um bloco de construção fundamental dos programas em Swift.
Elas permitem agrupar propriedades (dados) e métodos (funções) relacionados em unidades de funcionalidade independentes.

### Definindo classes

Para definir uma classe, use a palavra-chave `class` seguida do nome da classe, com a definição da classe entre chaves:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

O corpo de uma classe pode conter propriedades armazenadas, que são definidas e se comportam como constantes (`let`) ou variáveis (`var`) comuns.

### Instâncias

Uma definição de classe serve como um molde: ela define um novo tipo e descreve como são os seus valores, mas não cria nenhuma instância por si só.

Para criar uma *instância* de uma classe, chame o inicializador dela escrevendo o nome da classe seguido de parênteses:

```swift
let someCharacter = GameCharacter()
```

Isso cria uma nova instância cujas propriedades são inicializadas com os valores padrão especificados na definição da classe.
Para propriedades opcionais sem valores padrão explícitos (como `name`), o Swift define `nil` como padrão.

### Acessando propriedades

Você acessa as propriedades de uma instância usando a *notação de ponto*: escreva o nome da instância, um ponto (`.`) e o nome da propriedade.
A notação de ponto também funciona para propriedades aninhadas.

Você pode usar a notação de ponto para ler valores e, se a propriedade for mutável (`var`), para atribuir novos valores:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Métodos

Além das propriedades, as classes podem definir *métodos*: funções associadas à classe.

Defina métodos dentro do corpo da classe usando a sintaxe padrão de `func`.
Se um método modifica uma propriedade, essa propriedade precisa ser declarada com `var`:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Chame métodos de uma instância usando a notação de ponto, assim como faz com as propriedades:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Toda instância de uma classe tem uma propriedade implícita chamada `self`, que se refere à própria instância.
Embora muitas vezes seja omitido ao se referir a propriedades ou métodos, `self` é comumente usado para distinguir entre nomes de propriedades e nomes de parâmetros de métodos quando eles têm o mesmo nome.
