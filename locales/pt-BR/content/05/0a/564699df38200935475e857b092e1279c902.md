# Dicas

## 1. Geral

- Leia sobre arquivos no [guia oficial de primeiros passos][getting-started-file].
- Leia sobre arquivos em [joyofelixir.com][joy-of-elixir-file].
- Dê uma olhada na [documentação do módulo `File`][file].

## 1. Ler endereços de email de um arquivo

- Existe uma [função embutida][file-read] para ler todo o conteúdo de um arquivo de uma só vez.

## 2. Abrir um arquivo de log para escrita

- Existe uma [função embutida][file-open] para abrir um arquivo.
- O segundo argumento dessa função é uma lista de modos que permite especificar que o arquivo deve ser aberto para escrita.

## 3. Registrar um email enviado

- As funções para ler e escrever em um arquivo aberto com [`File.open!/1`][file-open] podem ser encontradas no módulo [`IO`][io].
- Existe uma [função embutida][io-puts] para escrever uma string em um arquivo, seguida de uma nova linha.

## 4. Fechar o arquivo de log

- Existe uma [função embutida][file-close] para fechar um arquivo.

## 5. Enviar a newsletter

- Todas as operações necessárias em arquivos já foram implementadas nos passos anteriores.
- Antes de escrever em um arquivo, o arquivo precisa ser aberto.
- Depois que todas as operações de escrita em um arquivo terminarem, o arquivo deve ser fechado.
