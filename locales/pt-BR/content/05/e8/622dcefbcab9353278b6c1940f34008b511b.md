# Instruções

Neste exercício, você vai escrever um pouco de código para ajudar a preparar uma lasanha incrível usando seu livro de receitas favorito.

Você tem quatro tarefas, todas relacionadas ao tempo gasto no preparo da lasanha.

## 1. Defina o tempo esperado no forno em minutos

Defina uma constante chamada `$expected_minutes_in_oven`.
De acordo com o livro de receitas, o tempo esperado no forno em minutos é 40:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. Calcule o tempo restante no forno em minutos

Esse valor recebe como entrada os minutos reais que a lasanha já ficou no forno e retorna quantos minutos ela ainda precisa ficar lá, com base no tempo esperado no forno em minutos da tarefa anterior.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. Calcule o tempo de preparo em minutos

O tempo de preparo é quanto tempo leva para deixar a lasanha pronta antes de colocá-la no forno.
Leva 2 minutos para preparar cada camada.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. Calcule o tempo total de trabalho em minutos

Calcule quantos minutos no total você trabalhou no preparo da lasanha.
É a soma do tempo de preparo em minutos com o tempo em minutos que a lasanha passou no forno no momento.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
