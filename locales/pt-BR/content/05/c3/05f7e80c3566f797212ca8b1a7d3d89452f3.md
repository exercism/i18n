# Introdução

## Declaração de tipos

As declarações de tipo em PHP fornecem asserções de tipo em tempo de execução para argumentos de funções, valores de retorno e propriedades de classe.
Em funções, um tipo de retorno `void` pode ser adicionado para indicar que nenhum valor é retornado pela função.
Os tipos declarados também servem como asserções em tempo de execução de que as funções estão retornando uma resposta com um tipo razoável.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### Uniões de tipos

Se um argumento de função, valor de retorno ou propriedade de classe puder ser de mais de um tipo, uma união de tipos pode ser declarada.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### Tipos mistos

Ao trabalhar com código, nem sempre é possível especificar um tipo.
A partir do PHP 8.0, é fornecido um tipo de escape chamado `mixed`.
Mixed é equivalente a uma união de tipos de `object|resource|array|string|float|int|bool|null`.
