# Introdução

`Rational numbers` são frações com um numerador inteiro dividido por um denominador inteiro.

Por exemplo, podemos armazenar `2//3` como uma fração exata em vez do valor aproximado `Float64` `0.6666...`

A vantagem é que (exceto no caso extremo de *estouro de inteiro*) um número racional permanece exato, evitando os erros de arredondamento que muitas vezes são inevitáveis com números de ponto flutuante.

Números racionais são um tipo numérico bem simples e funcionam praticamente como você espera.
Como são um tipo padrão do Julia desde as primeiras versões, a maioria das funções os aceita como entrada do mesmo jeito que aceita inteiros e números de ponto flutuante.

## Criando números racionais

Criar um número racional é tão simples quanto usar `//` entre dois inteiros.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Os fatores comuns são removidos automaticamente, convertendo a fração para a sua "forma irredutível": os menores inteiros que representam a fração exatamente, com um denominador não negativo.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## Aritmética com números racionais

Os `arithmetic operators` usuais, `+ - * / ^ %`, funcionam com racionais, basicamente do mesmo jeito que com outros tipos numéricos.

Inteiros e outros `Rational`s podem ser incluídos e dão um resultado `Rational`.
Incluir um `float` na expressão resulta em uma saída `float`, com uma consequente (possível) perda de precisão.

Se você quiser um `float`, basta usar a função `float()` para converter um número racional.
É bem comum usar números racionais para preservar a precisão ao longo de um cálculo longo e depois converter para um número de ponto flutuante no final.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## Outras operações

No Julia, números racionais são apenas números.
O compilador geralmente converte os tipos conforme necessário.

No entanto, cuidado: as comparações funcionam para frações com uma representação decimal finita:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Mas, fora isso, um `Rational` deve ser convertido para um `Float` para fazer comparações:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Funções matemáticas aceitam racionais como entrada, mas podem dar um resultado de ponto flutuante:

```julia-repl
julia> sqrt(9//16)
0.75
```
