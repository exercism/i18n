# Testes

Para rodar os testes, primeiro instale o pacote `z3-solver`:

```
pip install z3-solver
```

Depois, você pode rodar os testes executando o seguinte comando no diretório do exercício:

```
python <snake_case_exercise>_test.py
```

em que `<snake_case_exercise>` é substituído pelo nome do exercício.
