# Dicas

## 1. Substitua os espaços encontrados por sublinhados

- [Este tutorial][chars-tutorial] é útil.
- Você pode obter `char`s de uma string usando o método [charAt][char-at].
- Você deve usar um [`StringBuilder`][string-builder] para montar a string de saída.
- Consulte a documentação de [Character][chars-docs] para encontrar um método que detecta espaços em branco. Lembre-se de que é um método estático.
- Literais `char` são escritos entre aspas simples.

## 2. Converta kebab-case em camel-case

- Consulte a documentação de [Character][chars-docs] para encontrar um método que converte um caractere para maiúscula. Lembre-se de que é um método estático.

## 3. Converta leetspeak em texto normal

- Consulte a documentação de [Character][chars-docs] para encontrar um método que detecta quando um caractere é um dígito. Lembre-se de que é um método estático.

## 4. Omita caracteres que não são letras

- Consulte a documentação de [Character][chars-docs] para encontrar um método que detecta quando um caractere é uma letra. Lembre-se de que é um método estático.
