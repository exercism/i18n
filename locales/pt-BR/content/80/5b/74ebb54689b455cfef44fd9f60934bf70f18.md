# Caracteres

`CHAR` é um caractere, escrito entre aspas simples.

```sather
   c : CHAR := 'M';
```

## Caracteres especiais

Alguns caracteres não podem ser digitados diretamente e são escritos com uma barra invertida:

| Escrito | É |
| --- | --- |
| `'\n'` | uma nova linha |
| `'\t'` | uma tabulação |
| `'\''` | uma aspa simples |
| `'\\'` | uma barra invertida |

## Perguntas

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## Maiúsculas e minúsculas

`.upper` e `.lower` mudam a caixa de uma letra e deixam todo o resto
intacto, então são seguros para aplicar a um caractere que você não verificou.

## Números

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` e `.char` são exatamente opostos. Os fatos úteis sobre a numeração
são que `'a'` a `'z'` são consecutivos, `'A'` a `'Z'` são consecutivos
e `'0'` a `'9'` são consecutivos, então:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## Dar a volta

Uma roda de cifra avança além do `z` e volta para o `a`. O `%` faz exatamente isso:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

O `%` de Sather nunca dá resultado negativo quando o lado direito é positivo, então
isso funciona tanto para girar a roda para trás quanto para a frente.

## Caracteres e strings

Um `STR` é uma sequência de bytes, e um `CHAR` é um byte. Para texto em inglês,
um byte é uma letra, então `"Marlowe".size` é 7 e `"Marlowe"[0]` é `'M'`. Para texto
com acentos ou de outro alfabeto, uma letra pode ocupar vários bytes, e aí
nenhuma dessas coisas vale.
