# Dicas para o exercício Campo de Flores em Bash

Este exercício parece exigir um array bidimensional.
O Bash só oferece [arrays][array] indexados ou associativos unidimensionais.

Dá para simular arrays multidimensionais usando arrays associativos: codifique os índices em uma string separada por vírgulas para usar como chave do array.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
