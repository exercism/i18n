# Introdução

## Booleans em R

Valores verdadeiros ou falsos são representados pelo tipo `logical`.
Ele contém apenas dois valores: `TRUE` e `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Operadores Boolean

Existem cinco operadores Boolean em R, mas apenas três são relevantes nesta etapa do currículo.
Os outros dois serão importantes ao trabalhar com vetores, assunto abordado em vários Conceitos posteriores.

`&&` é o "e" Boolean.
Ele é avaliado como `TRUE` quando as expressões de *ambos* os lados do `&&` são `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` é o "ou" Boolean.
Ele é avaliado como `TRUE` quando uma expressão em *qualquer* um dos lados do `||` é `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` é o "não" Boolean.
Ele troca os valores `TRUE` e `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Para expressões mais longas e complicadas, é melhor usar parênteses para deixar sua intenção clara.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
