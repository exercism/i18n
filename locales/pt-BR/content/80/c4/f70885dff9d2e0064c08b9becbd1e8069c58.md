# Instruções

Lilly, a alienígena de Lisp, adora cozinhar. Ela quer fazer uma festa de pizza com os amigos, mas, para aproveitar ao máximo os ingredientes, quer saber exatamente de quanto vai precisar de cada um antes de começar.

Para resolver isso, Lilly esboçou um programa que automatiza parte do planejamento, mas precisa da sua ajuda para terminá-lo.
Você vai ajudar a Lilly a fazer a festa de pizza perfeitamente proporcional?

## 1. Uma proporção de massa

Antes de tudo, toda boa pizza começa com uma massa deliciosa!

Lilly é fã de pizzas finas e crocantes, com uma borda mais grossa.
A massa necessária para o meio é constante, 200g, mas cada 20cm de borda exige 45g de massa.

Felizmente, Lilly calculou a equação para os gramas de massa (g) a partir do número de pizzas (n) e do diâmetro delas (d):

`g = n * (((45 * pi * d) / 20) + 200)`

Lilly precisa de uma função que:
* Receba o número de pizzas (n) e o diâmetro delas (d)
* E retorne a massa necessária, arredondada para o grama mais próximo (g).

Por exemplo, para fazer 4 pizzas de 30cm de diâmetro:

```lisp
(dough-calculator 4 30) ; => 1648
```

## 2. Um toque de molho

Lilly é meticulosa ao aplicar o molho, mas o tamanho das pizzas dela pode variar.

Para descobrir o diâmetro (d), ela usa a equação abaixo, com o molho aplicado (s) como variável:

`d = square-root of ((40 * s) / (3 * pi))`

Lilly precisa de uma função que calcule o diâmetro da pizza (d) a partir de cada mililitro de molho aplicado (s).

Por exemplo, se Lilly usou 250ml de molho:

```lisp
(size-from-sauce 250) ; => 32.57
```

## 3. Um pouco de queijo, por favor

No planeta de Lilly, todo queijo vem em cubos perfeitos e é vendido por tamanho.
(O que você esperava? Afinal, é um planeta alienígena...)

Mais uma vez, Lilly calculou uma equação para o número de pizzas (n) de determinado diâmetro (d) feitas a partir de um cubo de queijo de lado (l):

`n = (2 * (l^3)) / (3* pi * (d^2))`

Crie uma função que:
* Receba o lado de um cubo de queijo (l) e o diâmetro das pizzas (d),
* E retorne o número de pizzas (n) feitas, arredondando para baixo.

Por exemplo, dado um cubo de queijo de 25x25x25cm e pizzas de 30cm de diâmetro:

```lisp
(pizzas-per-cube 25 30) ; => 3
```

## 4. Uma divisão justa

Por fim, Lilly quer que cada pizza seja dividida em 8 fatias e distribuída igualmente entre os amigos.

Crie uma função que:
* Receba um número de pizzas e um número de amigos
* e retorne `T` se as pizzas puderem ser distribuídas igualmente entre os amigos e `NIL` caso contrário.

Por exemplo:

```lisp
;; For splitting 3 pizzas between 4 friends
(fair-share-p 3 4) ; => T
;; For splitting 2 pizzas between 3 friends
(fair-share-p 2 3) ; => NIL
```
