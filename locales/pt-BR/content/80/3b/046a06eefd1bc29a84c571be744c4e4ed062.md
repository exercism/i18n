# Apêndice de instruções

## Notas de implementação

A definição da interface `Cipher` está em `cipher.go`.

Suas implementações devem estar de acordo com a interface `Cipher`.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

Espera-se que `Encode` ignore todos os valores da string que não sejam A-Za-z; eles não serão representados na saída.
A saída também será normalizada para minúsculas.

As funções usadas para obter as cifras são:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

O argumento de `NewShift` deve estar no intervalo de 1 a 25 ou de -1 a -25.
Zero não é permitido.
Para argumentos inválidos, `NewShift` retorna nil.

O argumento de `NewVigenere` deve ser composto apenas por letras minúsculas de a-z.
Valores compostos inteiramente pela letra 'a' não são permitidos.
Para argumentos inválidos, `NewVigenere` retorna `nil`.
