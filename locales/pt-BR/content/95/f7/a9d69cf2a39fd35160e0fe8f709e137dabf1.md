# Instruções

Implemente a codificação e a decodificação run-length.

A codificação run-length (RLE) é uma forma simples de compressão de dados, em que sequências (elementos de dados consecutivos) são substituídas por apenas um valor de dado e uma contagem.

Por exemplo, podemos representar os 53 caracteres originais com apenas 13.

```text
"WWWWWWWWWWWWBWWWWWWWWWWWWBBBWWWWWWWWWWWWWWWWWWWWWWWWB"  ->  "12WB12W3B24WB"
```

A RLE permite reconstruir perfeitamente os dados originais a partir dos dados comprimidos, o que a torna uma compressão de dados sem perda.

```text
"AABCCCDEEEE"  ->  "2AB3CD4E"  ->  "AABCCCDEEEE"
```

Para simplificar, você pode assumir que a string não codificada conterá apenas as letras de A a Z (maiúsculas ou minúsculas) e espaços em branco. Assim, os dados a codificar nunca conterão números, e os números dentro dos dados a decodificar sempre representam a contagem do caractere seguinte.
