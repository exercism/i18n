# Recursos

Cairo é uma linguagem especialmente adequada para uso em uma rede sem permissão como a [Starknet](https://www.starknet.io/), onde ela pode oferecer uma proteção robusta contra DoS e resistência à censura. Pode ser interessante conhecer esse aspecto da linguagem. Aprender a criar contratos inteligentes na Starknet vai aprimorar seu domínio de Cairo, já que você vai estar resolvendo problemas do mundo real com a linguagem, e também vai te apresentar ao mundo da Web3.

- [Starknet Documentation](https://docs.starknet.io/) aprenda o que é a Starknet, como ela funciona e como desenvolver contratos inteligentes nela.
- [Starknet by Example](https://starknet-by-example.voyager.online/) uma coleção de exemplos de como usar a linguagem de programação Cairo para criar contratos inteligentes na Starknet.
- [Starknet Basecamp](https://www.youtube.com/@starknet_foundation) "O Basecamp é um bootcamp de programação gratuito criado especificamente para ensinar desenvolvedores a criar aplicativos web3 na Starknet usando Cairo."
- [Awesome Starknet](https://github.com/keep-starknet-strange/awesome-starknet) "Uma lista selecionada de recursos, bibliotecas, ferramentas e muito mais do StarkNet".
- [Starklings](https://starklings.app/) "Um tutorial interativo baseado na web para aprender Cairo e Starknet."
