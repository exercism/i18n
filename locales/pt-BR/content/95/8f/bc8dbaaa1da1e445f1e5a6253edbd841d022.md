# Sobre

Uma definição de coleção normalmente inclui um espaço reservado entre sinais de maior e menor, muitas vezes T por convenção. Essa coleção é chamada de tipo genérico. Isso permite que quem usa a coleção especifique que tipo de itens armazenar na coleção. No exemplo de código acima, estamos instanciando uma lista de strings.

Uma classe ou função se torna **genérica** usando o atributo `@:generic`. Isso faz com que o compilador identifique a classe ou função como genérica:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
