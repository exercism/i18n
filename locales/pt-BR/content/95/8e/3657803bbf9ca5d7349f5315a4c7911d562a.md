# Introdução

Em Go, você pode iterar sobre um `slice` usando `for` e um índice, ou pode usar `range`. O `range` também permite iterar sobre um `map`.

Cada iteração retorna dois valores: o índice/chave e uma cópia do elemento nesse índice/chave.

## Iterar sobre um slice

Mamão com açúcar: iterar sobre um `slice` segue a ordem esperada.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Iterar sobre um map

Iterar sobre um `map` traz um novo problema.
A ordem agora é aleatória.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
Pode parecer que a saída acima está incorreta, já que seria de esperar que o primeiro par chave/valor da declaração do `map`, `9 10`, fosse o primeiro a ser impresso, e não o último.
No entanto, maps são desordenados por natureza: não existe um primeiro nem um último par chave/valor.
Por isso, ao iterar sobre as entradas de um `map`, a ordem em que as entradas serão visitadas é aleatória e não segue nenhum padrão específico.
Isso significa que a saída acima é possível, mas pode ser diferente da que você obtém se tentar rodar isso por conta própria.
Para saber mais sobre isso, veja [Especificação da linguagem Go: cláusula range](https://go.dev/ref/spec#RangeClause).
~~~~

## Iteração omitindo a chave ou o valor

Em Go, uma variável não utilizada gera um erro em tempo de compilação.
Às vezes você só precisa do valor, como no primeiro exemplo:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Você pode substituir o `i` por `_`, o que diz ao compilador que não usamos aquele valor:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Se você quiser imprimir apenas o índice, pode substituir o `x` por `_`
ou simplesmente omitir a declaração:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## Definindo tipos

Uma definição de tipo cria um novo tipo nomeado, distinto de qualquer outro tipo, mesmo daquele com o mesmo tipo subjacente.

```go
type File []bool
```

Aqui, `File` se refere a uma única coluna vertical de um tabuleiro de xadrez, normalmente rotulada de A a H.
Cada casa dessa coluna é representada por um valor `Boolean` que indica se ela está ocupada ou não.
Agora que `File` está definido, podemos usá-lo dentro de outras definições:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` mapeia identificadores de colunas para valores `File`.
Cada `File` é um `slice` de `Boolean`s que representa as casas de uma coluna do tabuleiro.
Sem essas definições de tipo, `board` seria um `map[string][]bool`, o que tornaria mais difícil entender o que estamos representando.
