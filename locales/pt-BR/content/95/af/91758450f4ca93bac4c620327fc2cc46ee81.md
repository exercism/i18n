# Dicas

## Geral

- Leia sobre [bitstrings][bitstring] no guia de primeiros passos.
- Reveja a documentação da [forma especial bitstring][bitstring-form].
- Reveja [como converter números decimais em números binários][decimal-to-binary-youtube].
- O Elixir oferece suporte a [diferentes formas de escrever números inteiros][integer-literal], incluindo a notação binária.

## 1. Calcular o tamanho em bits da paleta

- Esta tarefa não usa o tipo de dados bitstring.
- Encontre o menor número positivo `n` tal que 2 elevado à potência de `n` seja maior ou igual ao número de cores que precisamos representar.
- Crie uma função recursiva para isso.
- Comece com um tamanho em bits igual a 1. Se 2 elevado à potência do tamanho em bits for maior ou igual ao número de cores, encontramos o tamanho em bits. Caso contrário, some 1 ao tamanho em bits e verifique de novo (recursão).
- Use o [operador de potência `**`][power-operator] para elevar 2 a uma potência.

## 2. Criar uma imagem vazia

- Use a [forma especial bitstring][bitstring-form] para criar um novo bitstring.

## 3. Criar uma imagem de teste

- Use a [forma especial bitstring][bitstring-form] para criar um novo bitstring.
- Use o [operador de tipo][type-operator] para especificar o tamanho em bits de cada fragmento.

## 4. Adicionar um pixel ao início de uma imagem

- A [forma especial bitstring][bitstring-form] pode ser usada para anexar um novo fragmento a um bitstring existente.
- Use o [operador de tipo][type-operator] para especificar o tamanho em bits do novo fragmento e também do bitstring existente.
- Use a função `PaintByNumber.palette_bit_size/1`, implementada anteriormente, para obter o tamanho em bits do novo fragmento.
- Use o tipo especial `::bitstring` para especificar que o fragmento antigo tem tamanho desconhecido.

## 5. Obter o primeiro pixel de uma imagem

- A [forma especial bitstring][bitstring-form] pode ser usada para [fazer pattern matching em bitstrings][bitstring-matching].
- Use a função `PaintByNumber.palette_bit_size/1`, implementada anteriormente, para obter o tamanho em bits de um pixel.
- Use o tipo especial `::bitstring` para especificar que o restante do bitstring tem tamanho desconhecido.

## 6. Remover o primeiro pixel de uma imagem

- A [forma especial bitstring][bitstring-form] pode ser usada para [fazer pattern matching em bitstrings][bitstring-matching].
- Use a função `PaintByNumber.palette_bit_size/1`, implementada anteriormente, para obter o tamanho em bits de um pixel.
- Use o tipo especial `::bitstring` para especificar que o restante do bitstring tem tamanho desconhecido.

## 7. Concatenar duas imagens

- A [forma especial bitstring][bitstring-form] pode ser usada para concatenar dois bitstrings.
- Use o tipo especial `::bitstring` para especificar que cada um dos fragmentos de bitstring tem tamanho desconhecido.
