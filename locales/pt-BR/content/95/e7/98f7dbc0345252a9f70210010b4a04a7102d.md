# Dicas

## Geral

-  Este desafio é todo sobre validar, "limpar" e processar a pergunta dada na **_ordem correta_**.
-  Se você ler as instruções e os testes com atenção, vai descobrir que há três condições que precisam ser atendidas para que uma pergunta seja "válida".
Se uma pergunta não for válida, você vai precisar [lançar][raise-statement] uma [ValueError][value-error] com uma mensagem (_`ValueError("unknown operation")`_).
   É melhor resolver essa verificação específica antes de fazer qualquer outra coisa.
-  Processar uma pergunta antes de calcular a resposta é basicamente usar [métodos de string][str-methods].
Alguns dos mais populares para investigar são `str.removeprefix`, `str.removesuffix`, `str.replace` e `str.strip`.
Outros que você pode querer conferir são `str.startswith`, `str.endswith` e `in` (_que pode se aplicar a mais do que apenas strings_).

-  É possível iterar sobre uma string. No entanto, é **muito** mais fácil iterar sobre uma lista de _palavras_ se a string que você está processando for uma frase ou um fragmento com espaços. [`str.split`][split] pode dividir uma string e retornar uma lista de "palavras".
-  Um [`while-loop`][while-loop] é muito útil para iterar sobre a pergunta e processar os itens.
-  Para menos verificações de erro e um tratamento de erros mais limpo, um [`try-except`][handling-exceptions] é recomendado enquanto você processa a pergunta.
-  **Lembre-se**: a pergunta é processada **_da esquerda para a direita_**. Isso significa que "1 plus 12 minus 3 multiplied by 4" é processado assim:
   -  Calculando "1 plus 12" (13),
   -  Calculando "13 minus 3" (10),
   -  Calculando "10 multiplied by 4" (40).
   -  O resultado do primeiro cálculo é _concatenado com o restante da pergunta para formar uma nova pergunta para o próximo passo_.
       -  Essa técnica às vezes é chamada de [padrão acumulador][accumulator-pattern], ou [fold][fold] / [foldl][foldl] em linguagens de programação funcionais como [Haskell][haskell-folds] ou Lisp.
       -  O Python inclui dois métodos criados especificamente para aplicar o `accumulator-pattern` a estruturas de dados iteráveis como `lists`, `tuples` e `strings`.
               [`functools.reduce`][reduce] e [`itertools.accumulate`][accumulate] podem ser interessantes de investigar aqui.

-  Este exercício tem muitas soluções possíveis e muitos caminhos que você pode seguir ao longo dele.
   Nenhum caminho é claramente "melhor" que outro, embora um caminho específico possa ser mais interessante ou mais adequado ao que você quer aprender ou explorar agora.
