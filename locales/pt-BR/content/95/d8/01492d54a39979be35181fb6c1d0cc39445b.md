# Introdução

Reduzir é aplicar uma função repetidamente a cada elemento de uma sequência e acumular, de alguma forma, os resultados.
A função aplicada recebe dois parâmetros: o valor acumulado atual e o item a processar.
Ela deve resultar no novo valor acumulado.

No Common Lisp, o processo é feito com a função `reduce`.
Na sua forma mais simples, ela se parece com:

`(reduce #'function-to-apply sequence :initial-value value)`

Repare que um valor inicial é fornecido. Ele será o "valor acumulado atual" que é passado para a função quando o primeiro elemento é processado.

Aqui está um exemplo que soma os números da lista, começando com um valor inicial de 10:

`(reduce #'+ '(1 2 3 4) :initial-value 10) ; => 20`

Repare que, se a sequência estiver vazia, a função nunca é chamada e a forma resulta no valor inicial.
