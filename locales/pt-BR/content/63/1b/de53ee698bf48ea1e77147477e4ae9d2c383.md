# Dicas

## Geral

- O vocabulário `locals` fornece `::` e `[| | ]`.
- Os locals não substituem o código de pilha: use-os onde eles trazem
  clareza.

## 1. Determine o estado de cozimento

- `cond` de [`combinators`][combinators] é a forma certa: um bloco
  verifica `dup not` (o timer é `f`), outro verifica `dup zero?`, e um
  padrão cuida do resto. Cada bloco deve aplicar `drop` ao timer antes
  de empilhar a string.

## 2. Estime o tempo de preparo

- `:: preparation-time ( layers minutes-per-layer -- total )`
  com `layers length minutes-per-layer *`.

## 3. Calcule a quantidade de massa e molho necessária

- Os locals permitem que você se refira a `layers` duas vezes sem `dup`.
  `count` com o predicado `[ "noodles" = ]` (ou `"sauce" =`) fornece a
  contagem de cada camada.
- `1/5` é um literal racional de Factor.

## 4. Adicione o ingrediente secreto

- `last` (em [`sequences`][sequences]) lê o último elemento;
  `suffix` acrescenta um ao final.

## 5. Escale a receita

- O fator de escala é `portions / 2`. Os locals permitem que você
  referencie `portions` dentro da lambda.
- `assoc-map` de [`assocs`][assocs] recebe uma quotation
  `( key value -- newkey newvalue )`. Dentro de `[| key value | … ]`,
  retorne os dois valores para manter a mesma chave e produzir um valor
  novo.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
