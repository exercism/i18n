# Instruções

Neste exercício você vai processar linhas de log.

Cada linha de log é uma string formatada assim: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Você tem três tarefas, e cada uma recebe uma linha de log e pede que você faça algo com ela.

Fique à vontade para usar tanto funções legadas do R base quanto a biblioteca `stringr`, e as duas permitem soluções curtas e viáveis.

## 1. Extrair a mensagem de uma linha de log

Implemente a função `message` para retornar a mensagem de uma linha de log:

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

Qualquer espaço em branco no início ou no fim deve ser removido:

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. Extrair o nível de log de uma linha de log

Implemente a função `log_level` para retornar o nível de log de uma linha de log, que deve ser retornado em letras minúsculas:

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. Reformatar uma linha de log

Implemente a função `reformat`, que reformata a linha de log, colocando a mensagem primeiro e o nível de log depois dela, entre parênteses:

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
