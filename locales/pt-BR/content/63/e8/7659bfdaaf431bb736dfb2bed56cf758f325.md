# Instruções

Neste exercício, você precisa traduzir algumas regras do clássico jogo Pac-Man em funções Haskell.

Você tem quatro regras para traduzir, todas relacionadas aos estados do jogo.

> Não se preocupe em como os argumentos são obtidos, concentre-se apenas em combinar os argumentos para retornar o resultado esperado.

## 1. Defina se o Pac-Man come um fantasma

Defina a função `eatsGhost` que recebe dois argumentos (_se o Pac-Man tem uma pastilha de poder ativa_ e _se o Pac-Man está tocando um fantasma_) e retorna um valor `Bool` quando o Pac-Man consegue comer o fantasma.
A função deve retornar `True` apenas quando o Pac-Man tem uma pastilha de poder ativa e está tocando um fantasma.

```haskell
eatsGhost False True
-- -> False
```

## 2. Defina se o Pac-Man marca pontos

Defina a função `scores` que recebe dois argumentos (_se o Pac-Man está tocando uma pastilha de poder_ e _se o Pac-Man está tocando um ponto_) e retorna um valor `Bool` se o Pac-Man marcou pontos.
A função deve retornar `True` quando o Pac-Man está tocando uma pastilha de poder ou um ponto.

```haskell
scores True True
-- -> True
```

## 3. Defina se o Pac-Man perde

Defina a função `loses` que recebe dois argumentos (_se o Pac-Man tem uma pastilha de poder ativa_ e _se o Pac-Man está tocando um fantasma_) e retorna um valor `Bool` se o Pac-Man perde.
A função deve retornar `True` quando o Pac-Man está tocando um fantasma e não tem uma pastilha de poder ativa.

```haskell
loses False True
-- -> True
```

## 4. Defina se o Pac-Man vence

Defina a função `wins` que recebe três argumentos (_se o Pac-Man comeu todos os pontos_, _se o Pac-Man tem uma pastilha de poder ativa_ e _se o Pac-Man está tocando um fantasma_) e retorna um valor `Bool` se o Pac-Man vence.
A função deve retornar `True` quando o Pac-Man comeu todos os pontos _e_ não perdeu com base nos argumentos definidos na parte 3.

```haskell
wins False True False
-- -> False
```
