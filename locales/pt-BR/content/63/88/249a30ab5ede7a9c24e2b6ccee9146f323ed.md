# Introdução

Disponíveis a partir do `PHP 8.0.0`, as **Declarações de tipos união** aceitam valores de vários tipos diferentes, em vez de um único tipo. As definições de tipos união são feitas usando o pipe (`|`) para separar os tipos.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

O PHP lança um `TypeError` em modo estrito se os parâmetros recebidos não forem um `float` ou um `int`. Em modo não estrito, um erro de tipo é lançado se os parâmetros recebidos não puderem ser convertidos em um `float` ou um `int`.

Da mesma forma, se a função não retornar um dos tipos declarados, o PHP lança um `TypeError` em tempo de execução.
