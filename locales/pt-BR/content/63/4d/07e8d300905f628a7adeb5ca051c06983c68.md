# Instruções

Sua amiga acabou de lhe enviar uma mensagem com um segredo importante. Para não deixar fácil para os outros lerem, a mensagem foi criptografada por meio de uma série de manipulações de bits. Você vai precisar escrever o código para ajudar a descriptografar a mensagem.

## 1. Desloque os bits de volta

O primeiro passo para descriptografar a mensagem é desfazer o deslocamento feito no processo de criptografia, deslocando os bits de volta para a direita. Os passos seguintes assumem que zeros são inseridos à esquerda.

Defina `shift-back`, que recebe um valor de 32 bits e uma quantidade, e retorna o valor deslocado para a direita por essa quantidade, com preenchimento de zeros.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. Defina alguns bits

Em seguida, há alguns bits que precisam ser definidos como 1.

Defina `set-bits`, que recebe um valor e uma máscara. Todo bit de `value` em que o bit correspondente de `mask` for 1 deve ser definido como 1; todos os outros bits permanecem inalterados.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. Inverta bits específicos

Alguns bits são invertidos durante a criptografia. Eles precisarão ser invertidos de volta para descriptografar a mensagem.

Defina `flip-bits`, que recebe um valor e uma máscara. Todo bit de `value` em que o bit correspondente de `mask` for 1 deve ser invertido; todos os outros bits permanecem inalterados.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. Limpe bits específicos

Por último, também há certos bits que sempre descriptografam para 0.

Defina `clear-bits`, que recebe um valor e uma máscara. Todo bit de `value` em que o bit correspondente de `mask` for 1 deve ser zerado; todos os outros bits permanecem inalterados.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
