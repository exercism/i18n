# Instruções

Você está mantendo um guia de campo: um mapa que associa o nome de cada animal ao habitat em que ele vive.

As cinco tarefas ficam todas na classe `FIELD_GUIDE`.

## 1. Está no guia?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. Onde ele vive?

Retorne o habitat registrado para um animal. Se o guia nunca ouviu falar dele, retorne `"Unknown"`.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. Adicione uma entrada

Retorne o guia com um animal a mais. Um animal que já está na lista tem o habitat substituído.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

O que essa função devolver é o guia que você deve usar daí em diante. Adicionar a um guia completamente vazio funciona e dá um guia com um animal dentro.

## 4. Quantos animais?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. Quais habitats?

Retorne o conjunto de habitats que o guia menciona. Vários animais podem compartilhar um habitat, e ele deve aparecer apenas uma vez.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
