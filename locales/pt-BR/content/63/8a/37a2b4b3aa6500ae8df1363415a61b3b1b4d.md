# Instruções

Os bondes de Melbourne cobram por zona, e o centro da cidade é grátis. Você está escrevendo as regras de tarifa para a máquina de bilhetes. Todas as tarifas são em centavos.

As quatro tarefas ficam na classe `TRAM_FARES`.

## 1. A tarifa de uma zona

A zona 0 é a Free Tram Zone e não custa nada. A zona 1 custa 550. A zona 2 custa 370. Qualquer outro número não é uma zona de bonde de jeito nenhum, e não custa nada.

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. Que tipo de bilhete?

Os bilhetes trazem uma letra. `'f'` é tarifa integral. Tanto `'c'` quanto `'s'` são concessões: uma para crianças, outra para estudantes. `'x'` é um passe livre. Qualquer outra coisa é desconhecida.

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

As quatro respostas são `"Full fare"`, `"Concession"`, `"Free pass"` e `"Unknown"`.

## 3. Que tipo de dia?

`"Sat"` e `"Sun"` indicam fim de semana. `"Mon"` a `"Fri"` indicam dia de semana. Qualquer outra coisa é desconhecida.

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

As três respostas são `"Weekend"`, `"Weekday"` e `"Unknown"`.

## 4. O limite diário

Não importa quantos bondes você pegue, você nunca paga mais do que o limite daquele dia: 1100 em um dia de semana e 700 no fim de semana. Um dia que ninguém reconhece não tem limite, que é zero.

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
