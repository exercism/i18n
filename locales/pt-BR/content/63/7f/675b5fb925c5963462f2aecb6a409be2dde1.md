# Instruções

Neste exercício, você vai ajudar um criptógrafo a administrar e verificar um sistema de comunicação seguro.
O sistema depende bastante de elementos de corpo, especificamente do tipo `felt252` em Cairo, para garantir que todas as operações aritméticas permaneçam dentro de um intervalo definido.

## 1. Calcule a soma de duas mensagens

Duas mensagens criptografadas, cada uma representada por um `felt252`, precisam ser somadas para criar uma mensagem combinada.
No entanto, por causa da criptografia, qualquer resultado que ultrapasse o valor máximo $P - 1$ precisa dar a volta usando o módulo $P$.

Implemente uma função que recebe dois valores `felt252` e retorna a soma deles, garantindo que o resultado permaneça dentro do intervalo válido:

```rust
add_messages(3618502788666131213697322783095070105623107215331596699973092056135007822949, 987654321)
// => 123456789
```

> **Observação:** O valor de retorno deve ser um `felt252`.

## 2. Calcule a diferença entre duas mensagens

Às vezes, mensagens precisam ser subtraídas para recuperar os dados originais.
Se o resultado da subtração for negativo, o sistema ajusta o resultado automaticamente somando $P$ para trazê-lo de volta ao intervalo de um valor `felt252` válido.

Implemente uma função que recebe dois valores `felt252` e retorna a diferença deles, garantindo que o resultado permaneça dentro do intervalo válido:

```rust
subtract_messages(123456789, 987654321)
// => 3618502788666131213697322783095070105623107215331596699973092056135007822949
```

> **Observação:** O valor de retorno deve ser um `felt252`.

## 3. Calcule um produto válido de duas mensagens

Para assegurar a integridade dos dados criptografados, o sistema criptográfico costuma multiplicar duas mensagens (`felt252`) para garantir que o produto delas permaneça dentro de um intervalo válido.
O resultado precisa ser calculado com o módulo $P$ para garantir que permaneça dentro do intervalo válido.

Implemente uma função que recebe dois valores `felt252` e retorna o produto deles, garantindo que o resultado permaneça dentro do intervalo válido:

```rust
multiply_messages(382927772233671078546147897004315551461400594453673204174697055647611, 9449570)
// => 123456789
```

> **Observação:** O valor de retorno deve ser um `felt252`.
