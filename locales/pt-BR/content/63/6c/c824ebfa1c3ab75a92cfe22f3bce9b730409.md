# Boolean

Algumas perguntas têm apenas duas respostas: sim ou não. O tipo de Sather para
essa resposta é `BOOL`, e as duas respostas são escritas `true` e `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Comparando

Comparar dois números dá um `BOOL`.

| Operador | Pergunta |
| --- | --- |
| `=` | eles são iguais? |
| `/=` | eles são diferentes? |
| `<` | o da esquerda é menor? |
| `<=` | menor, ou igual? |
| `>` | o da esquerda é maior? |
| `>=` | maior, ou igual? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Repare que `=` faz uma pergunta. Colocar um valor *dentro* de algo é `:=`,
que você já viu, e os dois não são a mesma coisa.

## Combinando

Três operadores constroem perguntas maiores a partir de perguntas menores.

`and` é verdadeiro quando **os dois** lados são verdadeiros.

```sather
harness_on and rope_checked
```

`or` é verdadeiro quando **pelo menos um** dos lados é verdadeiro, ou os dois.

```sather
mat_below or net_below
```

`~` inverte uma resposta: transforma verdadeiro em falso e falso em verdadeiro.

```sather
~ready       -- true exactly when ready is false
```

`and` e `or` ficam entre duas respostas; `~` fica na frente de uma.
