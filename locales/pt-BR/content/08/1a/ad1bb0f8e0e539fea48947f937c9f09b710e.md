# Instruções

Neste exercício, você vai simular um sistema computacional baseado em janelas.
Você vai criar algumas janelas que podem ser movidas e redimensionadas e que exibem o próprio conteúdo.

## 1. Defina uma struct Size

Defina uma struct chamada `Size` com duas propriedades `Int`, `width` e `height`, que armazenam a largura e a altura atuais da janela, respectivamente.
A largura e a altura iniciais devem ser 80 e 60, respectivamente.
Inclua um método `resize(newWidth:newHeight:)` que recebe novos parâmetros de largura e altura e altera as propriedades para refletir o novo tamanho.

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. Defina uma struct Position

Defina uma struct chamada `Position` com duas propriedades `Int`, `x` e `y`, que armazenam a posição horizontal e vertical atuais, respectivamente, do canto superior esquerdo da janela.
Os valores iniciais de x e y devem ser ambos 0. A posição (0, 0) é o canto superior esquerdo da tela, com os valores de `x` aumentando conforme você se move para a direita e os valores de `y` aumentando conforme você se move para baixo.

Inclua um método `moveTo(newX:newY:)` que recebe novos parâmetros x e y e altera as propriedades para refletir a nova posição.

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. Defina uma classe Window

Defina uma classe de janela com as seguintes propriedades:

- `title` : `String`, o valor inicial é "New Window"
- `screenSize` : `Size`, valor constante com `width` = 800 e `height` = 600
- `size` : `Size`, o valor inicial é o valor padrão da struct `Size`
- `position` : `Position`, o valor inicial é o valor padrão da struct `Position`
- `contents` : `String?`, o valor inicial é `nil`

Você também deve definir um inicializador vazio para a classe.

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. Adicione um método para redimensionar janelas

- `resize(to:)` : `(Size) -> ()` - Este método recebe uma struct `Size` como entrada e tenta redimensionar a janela para o tamanho especificado. No entanto, o novo tamanho não pode ultrapassar certos limites.
- A altura ou largura mínima permitida é 1.
  Alturas ou larguras solicitadas menores que 1 serão limitadas a 1.
- A altura e a largura máximas dependem da posição atual da janela, pois as bordas da janela não podem ultrapassar as bordas da tela.
  Valores maiores que esses limites serão limitados ao maior tamanho possível.
  Por exemplo, se a posição da janela estiver em `x` = 400, `y` = 300 e for solicitado um redimensionamento para `height` = 400, `width` = 300, a janela será redimensionada para `height` = 300, `width` = 300, pois a tela não é grande o suficiente na direção `y` para acomodar totalmente a solicitação.

## 5. Adicione um método para mover janelas

- `move(to:)` : `(Position) -> ()` - Este método é parecido com `resize(to:)`, mas ajusta a _posição_ da janela para o valor solicitado, e não o tamanho. Assim como em `resize`, a nova posição não pode ultrapassar certos limites.
- A menor posição é 0 tanto para `x` quanto para `y`.
- A posição máxima em qualquer direção depende do tamanho atual da janela; as bordas não podem ultrapassar as bordas da tela.
       Valores maiores que esses limites serão limitados ao maior tamanho possível. Por exemplo, se o tamanho da janela estiver em `x` = 250, `y` = 100 e for solicitada uma movimentação para `x` = 600, `y` = 200, a janela será movida para `x` = 550, `y` = 200, pois a tela não é grande o suficiente na direção `x` para acomodar totalmente a solicitação.

## 6. Adicione métodos para atualizar o texto da janela e exibir informações da janela

- `update(title:)` : `(String) -> ()` - Este método define a propriedade `title` com o valor da string passada.
- `update(text:)` : `(String?) -> ()` - Este método define a propriedade `contents` com o valor da string opcional passada.
- `display()` : `() -> String` - Este método retorna uma string que descreve o estado atual da janela. Por exemplo, se a janela tiver o `title` "My First Window" com posição: x = 10, y = 100; tamanho: width = 200, height = 150; e contents: "I 😍 my window", ele deve retornar a string: `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - Se `contents` for nil, a última linha deve ser "[This window intentionally left blank]"

## 7. Crie um inicializador para a classe Window

O sistema de janelas deve ter um inicializador para que a janela possa ser criada com entradas personalizadas.
Crie **outro** inicializador para a classe `Window`.
O inicializador deve receber os seguintes parâmetros: `title`, `contents` e dois parâmetros opcionais, `size` e `position`.
Os parâmetros `size` e `position` devem assumir como padrão os valores padrão das structs `Size` e `Position`.

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
