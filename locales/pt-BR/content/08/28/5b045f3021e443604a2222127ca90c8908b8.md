# Sobre

Em Go, podemos comparar valores usando os operadores de igualdade e de ordenação.
Temos 6 desses operadores:

| Comparison        | Operator  |
| ------------------| --------- |
| igual             | `==`      |
| diferente         | `!=`      |
| menor             | `<`       |
| menor ou igual    | `<=`      |
| maior             | `>`       |
| maior ou igual    | `>=`      |

O resultado de uma comparação é sempre um valor Boolean:

```go
a := 3

a != 4 // true
a > 5  // false
```

## Operadores de igualdade

Os operadores de igualdade `==` e `!=` verificam se um valor é igual a outro ou não, respectivamente.
Podemos usar os operadores de igualdade na maioria dos tipos em Go.
Veja alguns exemplos comuns:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## Operadores de ordenação

Os operadores de ordenação verificam se um valor é maior que (`>`), maior ou igual a (`>=`), menor que (`<`) ou menor ou igual a (`<=`) outro valor.
Esse tipo de comparação está disponível para números, bytes, runes e strings.
Ao comparar strings, a ordem de dicionário (também conhecida como ordem lexicográfica) é seguida.

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
