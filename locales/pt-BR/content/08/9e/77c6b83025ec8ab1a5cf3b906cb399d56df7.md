# Sobre o Basics

O conceito Basics apresentou o [Go](https://golang.org) como uma linguagem de programação compilada e de tipagem estática.
A linguagem costuma ser chamada de Golang por causa do antigo nome de domínio, golang.org, mas o nome correto é Go.

O conceito Basics apresenta três recursos importantes da linguagem: pacotes, funções e variáveis.

## Pacotes

As aplicações em Go são organizadas em pacotes.
Um pacote é um conjunto de arquivos-fonte que ficam no mesmo diretório.
Todos os arquivos-fonte de um diretório precisam compartilhar o mesmo nome de pacote.
Por convenção, o nome do pacote é o último diretório do caminho de importação.
Por exemplo, os arquivos do [pacote "math/rand"](https://golang.org/src/math/rand/) começam com a instrução `package rand`.
Quando um pacote é importado, apenas as entidades (funções, tipos, variáveis, constantes) cujos nomes começam com letra maiúscula podem ser usadas ou acessadas.
O estilo de nomenclatura recomendado em Go é nomear os identificadores com `camelCase`, exceto aqueles que devem ser acessíveis entre pacotes, que devem usar `PascalCase`.

```go
package lasagna
```

## Variáveis

Go tem tipagem estática, o que significa que toda variável [precisa ter um tipo definido](https://en.wikipedia.org/wiki/Type_system) em tempo de compilação.

Você pode definir variáveis especificando um tipo explicitamente:

```go
var explicit int // Explicitly typed
```

Você também pode usar um inicializador, e o compilador vai atribuir à variável o tipo do inicializador.

```go
implicit := 10   // Implicitly typed as an int
```

Depois de declarada, uma variável pode receber valores com o operador `=`.
Depois de declarada, o tipo de uma variável nunca pode mudar.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

As constantes guardam um dado assim como as variáveis, mas o valor delas não pode mudar durante a execução do programa.

As constantes são definidas com a palavra-chave `const` e podem ser números, caracteres, strings ou Boolean:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funções

As funções em Go aceitam zero ou mais parâmetros.
Os parâmetros precisam ter o tipo explícito, não há inferência de tipo.

Os valores são retornados das funções com a palavra-chave `return`.

Uma função é chamada especificando o nome dela e passando argumentos para cada um dos parâmetros da função.

Vale notar que Go aceita dois tipos de comentários.
Comentários de uma linha são precedidos por `//` e comentários de várias linhas ficam entre `/*` e `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
