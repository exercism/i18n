# Conceitos necessários para o exercício Macros

Existem muitas formas de resolver um exercício, mas vou usar o [exemplo canônico](https://github.com/exercism/rust/blob/666c366fc0d39d9f6fd8e837facea8afe2153ae2/exercises/macros/example.rs) como minha principal referência do que são os conceitos usados.

Quando falamos da lista de conceitos, queremos dizer [esta lista](https://github.com/exercism/v3/blob/master/languages/rust/reference/README.md)

Repare que, tanto nos exercícios de conceito quanto nos de prática, a lista de conceitos pré-requisitos deve ser a menor possível. O objetivo aqui não é enumerar todos os conceitos que podem ser usados em todas as abordagens possíveis do problema; é enumerar o conjunto mínimo de conhecimentos com os quais um estudante determinado conseguiria resolver o problema.

Repare que este exercício tem grande chance de se tornar um exercício de conceito para o conceito "Escrevendo macros declarativas".

## Conceitos obrigatórios

### Existentes

- structs
- (im)mutabilidade
- `Hashmap<K, V>`

### Deveriam ser adicionados

- atribuição de variável (parte de `fundamentals`)
- escopo de variável / namespaces (parte de `fundamentals`)
- métodos e funções associadas (depende de `structs`)
