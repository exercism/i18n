# Instalação


## Obtenha o GHCup

A forma recomendada de instalar as ferramentas do Haskell é pelo [GHCup][ghcup].

Com o GHCup você pode gerenciar os compiladores instalados, os gerenciadores de projeto/pacotes e o servidor de linguagem.


## Instale o Stack

Para fazer os exercícios do Exercism, você só precisa do Stack.

Para instalar o Stack, rode o comando ou o script de instalação do GHCup.
Siga as opções padrão, mas indique que você também quer instalar o Stack.

Pulou a instalação do Stack sem querer?
Sem problema: é só rodar `ghcup install stack` depois.

O GHCup vai instalar

- **Um compilador** (GHC: o Glasgow Haskell Compiler)

  A rigor, você não precisa disso para o Exercism, mas é útil quando você quer brincar com o [GHCi][ghc-guide-ghci] fora dos diretórios de exercícios.

- **Cabal**

  Um gerenciador de projeto/pacotes.
  Você não precisa disso para o Exercism.

- **Stack**

  O gerenciador de projeto/pacotes que você vai usar no Exercism.
  Ele garante que você tenha o compilador e as bibliotecas certos para cada projeto (exercício).

Para verificar se a instalação deu certo, rode qualquer um destes comandos

- `ghcup list`: se der certo, aparece uma longa lista de versões de ferramentas, com o Stack marcado como instalado
- `stack --version`: se der certo, aparece algo como `Version 2.7.5, Git revision ...`


## Obtenha a versão certa do GHC

O Stack baixa e instala o GHC automaticamente quando for necessário.
Você pode iniciar a instalação e verificar rodando os seguintes comandos em um terminal:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

Se isso mostrar algo como

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

então o GHC está instalado corretamente.


## Configure seu editor para trabalhar com Haskell

O suporte a Haskell é oferecido pelo Haskell Language Server (HLS).
O suporte de linguagem não é obrigatório, mas é altamente recomendado.


### Visual Studio Code (recomendado)

É só instalar a [extensão do Haskell para o Visual Studio Code][vscode-haskell].
Ela vai usar o GHCup para instalar o HLS automaticamente, e depois disso está tudo pronto.

**Observação:** com exercícios recém-baixados, o HLS pode ter dificuldade para iniciar.
Se isso acontecer, rode `stack test` e reinicie o servidor de linguagem.


### Outros editores

Veja a [documentação do HLS sobre configuração de editores][hls-editor-config].
Talvez você precise instalar o HLS manualmente.
Para isso, rode `ghcup install hls`.
