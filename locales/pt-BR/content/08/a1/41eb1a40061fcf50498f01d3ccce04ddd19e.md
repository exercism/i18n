# Introdução

O fluxo de controle em Cairo permite controlar o caminho de execução dos seus programas com base em condições e repetições.

## Execução condicional

Use expressões `if` para executar código com base em condições:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` é uma expressão, então pode retornar valores:

```rust
let result = if condition { 5 } else { 10 };
```

## Laços

Use `loop` para repetir código.
Um laço roda indefinidamente, a menos que você o pare; use `break` para sair do laço quando uma condição for satisfeita.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

Os laços podem retornar valores usando `break`:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

Use `continue` para pular para a próxima iteração:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
