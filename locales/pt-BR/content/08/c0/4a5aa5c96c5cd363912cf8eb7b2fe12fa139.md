# Introdução

A principal construção orientada a objetos em Java é a _classe_, que combina dados (_campos_) e comportamento (_métodos_).
Os campos e métodos de uma classe são conhecidos como seus _membros_.

O acesso aos membros pode ser controlado por meio de modificadores de acesso, sendo os dois mais comuns:

- `public`: o membro pode ser acessado por qualquer código (sem restrições).
- `private`: o membro só pode ser acessado por código da mesma classe.

Você pode pensar em uma classe como um modelo para criar instâncias dessa classe.
Para criar uma instância de uma classe (também conhecida como _objeto_), usa-se a palavra-chave `new`:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Os campos têm um tipo e um nome (definido em camelCase) e podem ser definidos em qualquer lugar de uma classe (por convenção, escritos em PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

É possível atribuir um valor inicial a um campo, se quiser.
Se um campo _não_ especificar um valor inicial, ele receberá o valor padrão do seu tipo.
Os valores dos campos de uma instância podem ser acessados e atualizados com a notação de ponto.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Os campos privados geralmente são atualizados como efeito colateral da chamada de um método.
Esses métodos normalmente não retornam nenhum valor; nesse caso, o tipo de retorno deve ser `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
