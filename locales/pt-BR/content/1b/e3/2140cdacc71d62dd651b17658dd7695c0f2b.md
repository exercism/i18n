# Condicionais

O Crystal tem o que são chamadas de expressões de controle. Elas são usadas para controlar a maneira como o programa será executado e recebem um valor verdadeiro ou falso.
Existem operadores que podem ser usados para criar valores verdadeiros ou falsos, eles são conhecidos como [operadores de igualdade e comparação][equality-and-comparison].

Existem duas expressões de controle principais, usadas para controlar qual código será executado e qual não será.
Ou seja, qual bloco será executado.

Essas duas são: `if` e a expressão `unless`.

## Operadores de comparação

Operadores de comparação são usados para comparar valores e retornar um valor `true` ou `false`.
Esses operadores exigem que dois valores do mesmo tipo sejam comparados.
Se os valores não forem do mesmo tipo, o compilador lançará um erro.
Veja a seguir uma lista dos operadores de comparação e um exemplo de quando eles retornam um valor `true`:

| Método | Descrição             | Exemplo |
| ------ | --------------------- | ------- |
| <      | menor que             | 4 < 5   |
| <=     | menor ou igual a      | 4 <= 4  |
| >      | maior que             | 3 > 1   |
| >=     | maior ou igual a      | 2 >= 2  |

## Operadores de igualdade

Operadores de igualdade são parecidos com os operadores de comparação, mas são usados para verificar se dois valores são iguais ou não.

O operador `==` verifica se dois valores são iguais, incluindo o tipo do valor.
Se os valores forem iguais, ele retorna `true`; caso contrário, retorna `false`.
O operador `==` pode comparar qualquer tipo de valor com qualquer outro tipo de valor.
O operador `!=` funciona do mesmo jeito, mas retorna `true` se os valores não forem iguais e `false` se forem iguais.

## Operador nave espacial

O operador nave espacial é um operador de comparação único, e seu nome vem da sua aparência.
Ele é único no sentido de que não retorna um valor verdadeiro ou falso, mas sim um número.
Ele é escrito como `<=>` e usado para comparar dois valores.
Ele retorna `1` se o valor da esquerda for maior que o valor da direita, `-1` se o valor da esquerda for menor que o valor da direita, e `0` se os valores forem iguais.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## Condicional if

A condicional [`if`][if] é usada para verificar se uma dada condição é verdadeira ou falsa.
Se a condição for verdadeira, o código dentro da condicional `if` será executado.
Uma condicional `if` termina com a palavra-chave `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## Condicional unless

A condicional [`unless`][unless] funciona de forma muito parecida com a condicional `if`, mas executa o código dentro da condicional `unless` se a condição for falsa.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## Cláusula else

A cláusula `else` pode ser usada junto com as condicionais `if` e `unless`.
A cláusula `else` será executada se o bloco do `if` ou o bloco do `unless` não for executado.

~~~~exercism/warning
Embora um bloco `else` possa ser usado junto com `unless,`, isso não é recomendado porque prejudica a legibilidade.
Em vez disso, recomenda-se usar `if !condition` com um bloco `else`.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## Condicionais em cascata

A condicional `elsif` pode ser usada junto com a condicional `if`.
A condicional `elsif` será executada se o bloco do `if` não for executado e a condição da condicional `elsif` for verdadeira.
As condicionais `elsif` podem ser encadeadas, e a primeira condição verdadeira será executada.
Também pode haver uma cláusula `else` no final da condicional `if`, que será executada se nenhuma das condições anteriores for verdadeira.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## Operador ternário

O Crystal tem um operador ternário, uma condicional if-else de uma linha só: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## if e unless como sufixo

As condicionais if e unless também podem ser usadas como [sufixo][if-as-suffix]. Isso é útil quando você quer executar uma única linha de código se uma condição for verdadeira.
Para isso, coloque a condicional if ou unless depois do código que você quer executar.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## Tipos com condicionais

Quando recebe atribuições de tipos diferentes, a variável fica com os dois tipos.
Isso acontece porque o compilador não sabe qual bloco será executado.
Essa atribuição múltipla, também conhecida como união, será explicada em conceitos posteriores.
Isso pode ser visto no exemplo a seguir:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
