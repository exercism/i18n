# sem literal de número inteiro

Elixir tem uma [sintaxe especial](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html#unicode-and-code-points) para escrever números inteiros que correspondem a [pontos de código Unicode](https://en.wikipedia.org/wiki/Code_point): você pode usar um `?` na frente do caractere literal para revelar seu ponto de código.

Por exemplo,

```elixir
?a === 97
?\s === 32
?ß === 223
?互 === 20114
```

No contexto de manipulação de pontos de código, essa notação é muito mais legível do que os números e deve ser sempre a preferida.
