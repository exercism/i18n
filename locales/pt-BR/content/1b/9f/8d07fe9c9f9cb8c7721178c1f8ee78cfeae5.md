# Adendo às instruções

## Sobre o Enum

A instrução Enum permite que você crie um conjunto de rótulos fortemente tipado.
Você pode usar essa enumeração no código sem precisar analisar nem conferir se há erros de ortografia.

Internamente, as enumerações são representadas por números inteiros, com valor inicial zero.
Por padrão, o PowerShell atribui o valor zero ao primeiro rótulo da lista e atribui aos demais rótulos números inteiros consecutivos.

Exemplo:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

Para saber mais sobre o Enum no PowerShell, confira o [módulo Enum.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)
