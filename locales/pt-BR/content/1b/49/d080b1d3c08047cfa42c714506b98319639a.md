# Testes

Escolha o seu sistema operacional:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# Rodando os testes

## Windows

1. Abra um Command Prompt.

2. Baixe o primeiro exercício:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. Mude para a pasta do exercício:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. Rode os testes:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(Não se preocupe se os testes falharem na primeira vez que você rodá-los, é assim que você começa cada exercício.)*

5. Resolva o exercício. 
    Leia o `instructions.md` e veja como resolver o exercício ([ver no GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Boa sorte, divirta-se e bem-vindo à trilha de COBOL!

----

## macOS

1. Abra uma janela do Terminal.

2. Baixe o primeiro exercício:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. Mude para a pasta do exercício:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. Rode os testes:

    ```
     $ bash test.sh
    ```
    *(Não se preocupe se os testes falharem na primeira vez que você rodá-los, é assim que você começa cada exercício.)*

    Dica: se você receber uma mensagem de que `basename` está faltando, você pode usar o [brew](https://brew.sh/) para instalar o coreutils. (`brew install coreutils`)

5. Resolva o exercício. 

    Leia o `instructions.md` e veja como resolver o exercício ([ver no GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Boa sorte, divirta-se e bem-vindo à trilha de COBOL!
