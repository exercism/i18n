# classes

As classes são um conceito central na [programação orientada a objetos][object-oriented-programming].
[No Crystal, tudo é um objeto][everything-is-an-object], todo objeto tem um tipo e pode responder a alguns métodos.
Classes são moldes para criar objetos, fornecendo valores iniciais para o estado, como variáveis, e implementações de comportamento, como métodos.
Objetos são instâncias de classe que guardam todas as variáveis de instância e estados.

## Definição de classe

Uma classe é definida usando a palavra-chave `class`, seguida do nome da classe escrito em `UpperCamelCase`.

```crystal
class Account
end
```

## Criando uma instância

Para [criar uma instância de uma classe][new-initialize], chame o nome da classe usando o método `new`.

```crystal
class Account
end

account = Account.new
```

No exemplo acima, a variável `account` é uma instância da classe `Account`.

Ao criar uma instância, um método especial chamado `initialize` atua como construtor.
Ele é chamado quando uma instância é criada.
O construtor permite definir o estado inicial da instância.
O método `initialize` pode receber argumentos, que são passados ao criar uma instância.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
O método `initialize` não pode retornar um valor manualmente; em vez disso, o `new` retorna a instância recém-criada.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Métodos de instância

Um método de instância é um método disponível para uma instância de uma classe e pode ser chamado nessa instância.
Os métodos de instância são definidos usando a palavra-chave `def`, seguida do nome do método.
Eles são definidos dentro da definição da classe.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Variáveis de instância

[Variáveis de instância][instance-variable] são variáveis disponíveis em todos os métodos da instância.
Para acessar uma variável de instância, você precisa definir um método de instância.
Elas podem ser inicializadas no método `initialize`.
Elas são definidas usando o prefixo `@`.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

Variáveis de instância também podem ser definidas dentro da definição da classe.

```crystal
class Account
  @age = 0
end
```

### Variáveis de instância com inicialização

Variáveis de instância podem ser inicializadas com um argumento passado ao método `initialize`.
Como o Crystal não consegue inferir o tipo do argumento usado na inicialização, ele precisa ser especificado.
Se você quiser ler mais sobre isso, pode ler: [type-inference][type-inference].
Para especificar o tipo da variável, você pode usar o símbolo `:`, seguido do tipo.
Por exemplo, se você quiser criar uma variável de instância chamada `balance` do tipo `Int32`, você pode fazer assim: `@balance : Int32`.
Ou, se você quiser criar uma variável de instância chamada `raining` do tipo `Bool`, pode fazer assim: `@raining : Bool`.

Há algumas formas de fazer isso: uma é declarar o argumento com o tipo no método `initialize` e depois atribuir a variável de instância ao argumento, como no exemplo a seguir:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Outra forma é declarar o tipo da variável de instância na definição da classe, no formato `@<variable> : <Type>`, como no exemplo a seguir:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### Forma abreviada de inicializar variáveis de instância

Existe uma forma abreviada de inicializar variáveis de instância nos argumentos do método `initialize`, usando a mesma sintaxe `@<variable> : <Type>`.
Isso combina a atribuição da variável de instância ao argumento com a declaração do tipo da variável de instância.

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## Modificar variáveis de instância

Os métodos podem modificar variáveis de instância.
Esses métodos podem ser chamados na instância da classe.
Quando um método modifica uma variável de instância, essa mudança fica disponível apenas na instância da classe em que você o chamou.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Métodos de classe

[Métodos de classe][class-methods] são métodos definidos para uma classe, mas não para suas instâncias.
Eles oferecem uma forma de criar métodos que não dependem do estado da instância.
Eles são definidos usando a palavra-chave `def`, seguida de `self.<method name>`.
`self` é uma referência ao namespace a partir do qual self está sendo chamado.
Neste caso, ele se refere à classe, `Account`.
Seria o mesmo que escrever `Account.`, mas `self.` é a forma preferida.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
