# Dicas

## 1. Crie uma nova lista

- Você pode criar uma lista vazia com a sintaxe `[]`.

## 2. Defina uma lista existente

- Você pode criar listas com vários elementos usando a sintaxe `["a", "b", "c"]`.

## 3. Adicione uma nova linguagem a uma lista

- A sintaxe de espalhamento (`[x, ..list]`) pode ser usada para adicionar um elemento ao início de uma lista.

## 4. Conte as linguagens da lista

- Há uma função no módulo `gleam/list` para [contar os elementos de uma lista][length].

## 5. Inverta a lista

- Há uma função no módulo `gleam/list` para [inverter uma lista][reverse].

## 6. Verifique se a lista é empolgante

- Você pode usar correspondência de padrões com os padrões de lista e de espalhamento de lista para corresponder a estruturas de lista específicas.

[reverse]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#reverse
[length]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#length
