# Instruções

Neste exercício, você vai escrever um programa para ajudar a se preparar para comprar um veículo.

Você tem duas tarefas: descobrir se vai precisar tirar uma carteira de motorista e estimar o preço aceitável de um veículo usado.

## 1. Descubra se você vai precisar de uma carteira de motorista

Alguns tipos de veículo exigem carteira de motorista para serem conduzidos.
Considere que só os veículos que contenham `car` ou `truck` exigem carteira de motorista; todo o resto pode ser conduzido sem ela.

Implemente um par `pattern {action}` que corresponda quando o primeiro campo for `needs_license`.
Ele deve obter o tipo de veículo do segundo campo e imprimir "true" se você precisar de carteira de motorista para esse tipo de veículo.
Se você não precisar de carteira de motorista, não precisa imprimir nada.

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. Calcule uma estimativa do preço de um veículo usado

Agora que você tomou sua decisão, quer garantir um preço justo na concessionária.
Como a ideia é comprar um veículo usado, o preço depende da idade dele.
Para uma estimativa aproximada, considere que, se o veículo tiver menos de 3 anos, ele custa 80% do preço original que tinha quando novo.
Se tiver mais de 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos, mas não mais de 10 anos, custa 70% do preço original.

Implemente um par `pattern {action}` que corresponda quando o primeiro campo for `resell_price`.
Ele deve obter o preço original do veículo do segundo campo e a idade do terceiro campo.
A ação deve imprimir o preço estimado.

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
