# Dicas

## 1. Importações de biblioteca com prefixo

- Repare que o script de teste (test/pig_latin_test.dart) importa o arquivo de solução usando um prefixo:

  ```dart
  import 'package:pig_latin/pig_latin.dart' as pigLatin;
  ```
- Saiba mais: [Especificando um prefixo de biblioteca](https://dart.dev/guides/language/language-tour#specifying-a-library-prefix)
