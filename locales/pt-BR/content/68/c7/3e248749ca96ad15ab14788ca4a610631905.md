# Dicas

## 1. Criar o enum LogLevel

- Você vai precisar definir um inicializador e um método, além dos casos do seu enum.

## 2. Fazer o parse do nível de log

- O Swift tem algumas [propriedades][string-docs] e métodos para extrair partes de uma string.
- A [instrução `switch`][switch-statement] costuma formar uma combinação natural com enums.

## 3. Converter a linha de log para o formato curto

- Métodos são definidos exatamente como funções, só que dentro do corpo do enum.
- [Valores brutos][enum-raw-values] podem ser atribuídos a casos do enum.
- A palavra-chave `self` se refere ao valor do enum dentro do corpo de um método.
