# Sobre

`call` é a primitiva universal de "rodar esta quotation agora". Quando o compilador consegue ver a quotation literalmente, consegue inferir o efeito; quando a quotation vem de uma variável, de um array ou de um parâmetro, você precisa declarar o efeito:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

A declaração `call( a b -- c )` compila para uma verificação em tempo de execução de que a quotation de fato tem o efeito declarado: uma incompatibilidade vira um erro claro em vez de um estado corrompido da pilha.

Tratar quotations como dados (empilhá-las, colocá-las em arrays, retorná-las de words) é uma das coisas que torna o código concatenativo tão compacto. Um "programa" pode ser uma sequência simples, e `each` com `call` já basta para interpretá-lo.
