# Introdução

Você acaba de ser contratado como professor de matemática.
Sua primeira semana correu bem, mas tem algo errado na segunda semana.
O problema é que todas as respostas dos seus alunos estão erradas!
Por sorte, seus conhecimentos de matemática permitiram que você identificasse o problema: as respostas dos alunos _estão_ certas, mas todas estão na base 2 (binária)!
Incrivelmente, a cada semana os alunos usam uma base diferente.
Para ajudar você a verificar rapidamente as respostas dos alunos, você vai construir uma ferramenta para converter entre bases.
