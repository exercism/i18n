# Anexo às instruções

## Notas específicas de Assembly x86-64

As funções deste exercício recebem um array contendo um ou mais números, cada um representando uma "pontuação do jogo".

No assembly x86-64, os elementos de um array são acessados como um deslocamento em bytes a partir de um ponteiro base.

Esse ponteiro base é passado em um registrador, de acordo com a [System V AMD64 ABI Calling Convention](https://www.uclibc.org/docs/psABI-x86_64.pdf).

Os 3 primeiros argumentos são passados em rdi, rsi, rdx, nessa ordem.

Como as pontuações do jogo do jogador são representadas como inteiros de 32 bits, que ocupam 4 bytes, elas podem ser lidas a partir de

| `rsi`   |
|---|
| `dword [rsi]` |
| `dword [rsi + 4]` |
| ... |
| `dword [rsi + 4*scores_count - 4]` |

`personal_top_three()` deve escrever as melhores pontuações do jogador em um buffer, também passado em um registrador e acessado da mesma forma.

| `rdi`   |
|---|
| `dword [rdi]` |
| `dword [rdi + 4]` |
| ... |

Por convenção, valores inteiros são retornados no registrador rax.
