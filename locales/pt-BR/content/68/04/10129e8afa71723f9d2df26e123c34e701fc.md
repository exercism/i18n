# Introdução

Enums em Cairo permitem que você defina um tipo que pode ser uma entre várias variantes nomeadas.

## Noções básicas

Enums, abreviação de enumerações, restringem todos os valores possíveis de algum dado a um conjunto predefinido.
Os valores possíveis de um `enum` são chamados de variantes:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

Crie valores de enum especificando a variante:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## Correspondência de padrões

Use match para lidar com diferentes variantes de enum:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

Cada braço do match lida com uma variante do enum.

## Enums com dados

Variantes de enum podem conter dados adicionais:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

Use correspondência de padrões para extrair os dados:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
