# Dicas

## Geral

- O [guia de strings do rubymostas][ruby-for-beginners.rubymonstas.org-strings] tem uma boa introdução às strings do Ruby.
- O objeto `String` tem muitos [métodos embutidos][docs-string-methods] úteis.

## 1. Obtenha a mensagem de uma linha de log

- Existem diferentes formas de procurar texto em uma string, que podem ser encontradas na [documentação oficial da linguagem Ruby][docs-string-methods].
- Existem [métodos embutidos][strip-white-space] para remover espaços em branco.

## 2. Obtenha o nível de log de uma linha de log

- Os objetos `String` do Ruby têm um [método][downcase] para realizar essa operação.

## 3. Reformate uma linha de log

- Existem várias formas de [concatenar strings][ruby-for-beginners.rubymonstas.org-strings], mas a preferida costuma ser a [interpolação de strings][ruby-for-beginners.rubymonstas.org-strings]
