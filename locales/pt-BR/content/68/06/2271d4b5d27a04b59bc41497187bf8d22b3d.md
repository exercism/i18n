# Dicas

## 1. Defina o intervalo de fileiras e colunas

- Você precisa definir duas [constantes][constants] que devem conter um [`Range`][range] de fileiras e colunas.
- As fileiras devem ser um [`Integer`][integers] `range` de 1 a 8.
- As colunas devem ser um [`String`][string] `Range` de 'A' a 'H'.
- A constante precisa ser definida no [módulo][module] `Chess`.

## 2. Verifique se a casa é válida

- Você precisa verificar se um valor está dentro de um intervalo.
- Existe [um método][include] que pode ser usado para verificar se um valor está dentro de um intervalo.

## 3. Obtenha o apelido do jogador

- Você pode obter uma fatia usando um `Range` como valor de entrada.
- Existe [um método][upcase] que pode ser usado para deixar uma string em maiúsculas.

## 4. Crie a mensagem do movimento

- Você pode indexar a string da casa para obter a fileira e a coluna.
- Você pode usar métodos já definidos para obter o apelido do jogador e verificar se o movimento é válido.
