# Apêndice das instruções

## Formato de entrada/saída

Cada conjunto de palavras é representado como uma string terminada em null, com um caractere de nova linha no final de cada palavra.

Você deve retornar os anagramas na mesma ordem em que eles aparecem nas palavras candidatas.

Um exemplo seria `"tones\nnotes\nSeton\n"`

## Registradores

| Registrador | Uso          | Tipo    | Descrição                                                      |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | entrada        | endereço | string alvo terminada em null, sem nova linha                 |
| `$a1`    | entrada        | endereço | string de candidatas terminada em null, com nova linha depois de cada palavra |
| `$a2`    | entrada/saída | endereço | string de saída terminada em null, com nova linha depois de cada palavra     |
| `$t0-9`  | temporário    | qualquer     | para armazenamento temporário                                  |
