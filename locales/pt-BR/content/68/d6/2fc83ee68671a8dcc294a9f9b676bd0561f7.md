# Traits

Uma trait especifica um conjunto de métodos que um tipo pode implementar.
As traits são úteis para definir métodos que devem ser compartilhados entre tipos.
Quando as traits são usadas com tipos genéricos, os métodos definidos podem ser chamados no tipo específico, mas também é possível chamá-los em outros tipos de dados.
De forma abstrata, com o uso de _limites de trait_, podemos especificar que o tipo genérico deve compartilhar determinado comportamento.

> **Nota:** As traits compartilham uma característica semelhante ao que se conhece como interfaces em outras linguagens de programação, com algumas diferenças.

## Definição de trait

Definir uma trait ajuda a identificar a assinatura de função que compõe o conjunto de comportamentos que um tipo pode implementar para alcançar um resultado.
Esses métodos formam o comportamento de um tipo.
Se conseguimos chamar os mesmos métodos em tipos diferentes, isso implica que os tipos envolvidos têm o mesmo comportamento.

```rust
#[derive(Drop)]
pub struct NewsArticle {
    pub headline: ByteArray,
    pub location: ByteArray,
    pub author: ByteArray,
    pub content: ByteArray,
}

// A trait for NewsArticle struct type
pub trait Summary {
    fn summarize(self: @NewsArticle) -> ByteArray;
}
```

Seguindo a definição da trait `Summary` acima, o método `summarize` é um comportamento que só pode ser chamado pelo tipo de struct `NewsArticle`.
Se for invocado em instâncias de outros tipos, gera um erro de compilação.
Declarar a trait com a palavra-chave `pub` expõe a trait deste crate a outros crates que também pretendem usá-la.
Repare também que usamos um ponto e vírgula depois de declarar as assinaturas de método nas traits.

Uma trait pode ser definida com um argumento genérico, o que permite que uma função receba um argumento de qualquer tipo de dados.
Isso introduz uma flexibilidade na assinatura de função, permitindo que ela lide com diversos tipos de dados.
No caso da trait `Summary` abaixo, ela foi reformulada para funcionar com qualquer tipo de dados, de modo que, quando o método `summarize` for invocado neles, retorne um ByteArray.

```rust
// A trait for a generic type
pub trait Summary<T> {
    fn summarize(self: @T) -> ByteArray;
}
```

Uma trait pode ter mais de um método em seu corpo; cada assinatura de método declarada é uma linha única que termina com ponto e vírgula.

## Implementação de trait em um tipo

Depois de definir as assinaturas de função que compõem uma trait, o compilador vai exigir que uma implementação também seja definida para os tipos que adotam a trait.
Escrevemos abaixo um crate de biblioteca de mídia `aggregator` que resume alguns dados de instâncias de `NewsArticle` e `Tweet`.
Para a struct `NewsArticle`, usaríamos os campos headline, author e location para retornar o valor do método `summarize` da trait `Summary`, enquanto para a struct `Tweet`, usaríamos o username e o content, assumindo que o conteúdo do tweet tem um limite de 280 caracteres.

```rust
mod aggregator {
    pub trait Summary<T> {
        fn summarize(self: @T) -> ByteArray;
    }

    #[derive(Drop)]
    pub struct NewsArticle {
        pub headline: ByteArray,
        pub location: ByteArray,
        pub author: ByteArray,
        pub content: ByteArray,
    }

    impl NewsArticleSummary of Summary<NewsArticle> {
        fn summarize(self: @NewsArticle) -> ByteArray {
            format!("{} by {} ({})", self.headline, self.author, self.location)
        }
    }

    #[derive(Drop)]
    pub struct Tweet {
        pub username: ByteArray,
        pub content: ByteArray,
        pub reply: bool,
        pub retweet: bool,
    }

    impl TweetSummary of Summary<Tweet> {
        fn summarize(self: @Tweet) -> ByteArray {
            format!("{}: {}", self.username, self.content)
        }
    }
}

use aggregator::{Summary, NewsArticle, Tweet};

fn main() {
    let news = NewsArticle {
        headline: "Cairo has become the most popular language for developers",
        location: "Worldwide",
        author: "Cairo Digger",
        content: "Cairo is a new programming language for zero-knowledge proofs",
    };

    let tweet = Tweet {
        username: "EliBenSasson",
        content: "Crypto is full of short-term maximizing projects. \n @Starknet and @StarkWareLtd are about long-term vision maximization.",
        reply: false,
        retweet: false
    };

    println!("New article available! {}", news.summarize());
    println!("New tweet! {}", tweet.summarize());
}
```

## Implementações padrão

Às vezes, uma trait pode ser definida com uma implementação padrão para alguns ou todos os métodos que a compõem.
Isso evita exigir a implementação de todos os métodos em cada tipo e melhora a legibilidade do código.
Se um tipo específico precisar de uma implementação especial de um método da trait, ele pode sobrescrever a implementação padrão.

```rust
mod aggregator {
    pub trait Summary<T> {
        fn summarize(self: @T) -> ByteArray {
            "(Read more...)"
        }
    }

    #[derive(Drop)]
    pub struct NewsArticle {
        pub headline: ByteArray,
        pub location: ByteArray,
        pub author: ByteArray,
        pub content: ByteArray,
    }

    impl NewsArticleSummary of Summary<NewsArticle> {}

    #[derive(Drop)]
    pub struct Tweet {
        pub username: ByteArray,
        pub content: ByteArray,
        pub reply: bool,
        pub retweet: bool,
    }

    impl TweetSummary of Summary<Tweet> {
        fn summarize(self: @Tweet) -> ByteArray {
            format!("{}: {}", self.username, self.content)
        }
    }
}

use aggregator::{Summary, NewsArticle, Tweet};

fn main() {
    let news = NewsArticle {
        headline: "Cairo has become the most popular language for developers",
        location: "Worldwide",
        author: "Cairo Digger",
        content: "Cairo is a new programming language for zero-knowledge proofs",
    };

    println!("New article available! {}", news.summarize()); // prints "New article available! (Read more...)"


    let tweet = Tweet {
        username: "Alice",
        content: "Cairo is fun and engaging.",
        reply: true,
        retweet: true,
    };
    println!("New tweet from {}", tweet.summarize()); // prints "New tweet from Alice: Cairo is fun and engaging."
}
```

## Como usar e gerenciar traits externas

As traits e implementações podem ser definidas em um módulo externo e usadas em outros módulos, desde que sejam importadas corretamente.
Digamos que temos uma trait `ShapeGeometry` com o método `boundary`, que deve ser implementado tanto para a struct `Circle` quanto para a `Rectangle`.
Abaixo está um exemplo de como a trait e a implementação são importadas, gerenciadas e usadas entre módulos.

```rust
// Here T is an alias type which will be provided during implementation
pub trait ShapeGeometry<T> {
    fn boundary(self: T) -> u64;
    fn area(self: T) -> u64;
}

mod rectangle {
    // Importing ShapeGeometry is required to implement this trait for Rectangle
    use super::ShapeGeometry;

    #[derive(Copy, Drop)]
    pub struct Rectangle {
        pub height: u64,
        pub width: u64,
    }

    // Implementation RectangleGeometry passes in <Rectangle>
    // to implement the trait for that type
    impl RectangleGeometry of ShapeGeometry<Rectangle> {
        fn boundary(self: Rectangle) -> u64 {
            2 * (self.height + self.width)
        }
        fn area(self: Rectangle) -> u64 {
            self.height * self.width
        }
    }
}

mod circle {
    // Importing ShapeGeometry is required to implement this trait for Circle
    use super::ShapeGeometry;

    #[derive(Copy, Drop)]
    pub struct Circle {
        pub radius: u64
    }

    // Implementation CircleGeometry passes in <Circle>
    // to implement the imported trait for that type
    impl CircleGeometry of ShapeGeometry<Circle> {
        fn boundary(self: Circle) -> u64 {
            (2 * 314 * self.radius) / 100
        }
        fn area(self: Circle) -> u64 {
            (314 * self.radius * self.radius) / 100
        }
    }
}

use rectangle::Rectangle;
use circle::Circle;

fn main() {
    let rect = Rectangle { height: 5, width: 7 };
    println!("Rectangle area: {}", ShapeGeometry::area(rect)); //35
    println!("Rectangle boundary: {}", ShapeGeometry::boundary(rect)); //24

    let circ = Circle { radius: 5 };
    println!("Circle area: {}", ShapeGeometry::area(circ)); //78
    println!("Circle boundary: {}", ShapeGeometry::boundary(circ)); //31
}
```

A visibilidade da implementação tanto de `CircleGeometry` quanto de `RectangleGeometry` não precisa ser pública, já que a trait `ShapeGeometry` é tornada pública e deve ser facilmente encontrada pelo compilador.

## Aliases de impl

As implementações podem receber um alias quando importadas, usando a palavra-chave `impl`.
Isso ajuda ao instanciar uma implementação genérica para tipos concretos.
Vamos definir uma implementação trivial da trait `Two` para todos os tipos que implementam a trait `One`, simplesmente somando duas vezes o valor de `One` e retornando a soma.
Depois, podemos expor a implementação de `Two` que funciona apenas para os tipos `u8` e `u128`.

```rust
trait Two<T> {
    fn two() -> T;
}

mod one_based {
    pub impl TwoImpl<
        T, +Copy<T>, +Drop<T>, +Add<T>, impl One: core::num::traits::One<T>
    > of super::Two<T> {
        fn two() -> T {
            One::one() + One::one()
        }
    }
}

pub impl U8Two = one_based::TwoImpl<u8>;
pub impl U128Two = one_based::TwoImpl<u128>;
```

A implementação genérica pode ser escrita em um módulo privado e, com o uso de alias de impl, podemos instanciar a implementação genérica desses dois tipos concretos.
O benefício de usar uma implementação genérica privada e não exposta é que ela evita a duplicação de código entre arquivos.
Isso também mantém a API pública simples e limpa.
