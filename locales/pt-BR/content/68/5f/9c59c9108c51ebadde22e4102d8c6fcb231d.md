# Instruções

Seu amigo Linus é maquinista e conduz trens de carga entre cidades. Apesar de ser incrível conduzindo trens, o mesmo não se pode dizer de logística ou computadores. Linus gostaria de contar com a sua ajuda com programação para organizar os detalhes dos trens e corrigir erros nos dados das rotas.

~~~~exercism/note
Este exercício poderia ser resolvido facilmente com fatiamento, indexação e vários métodos de `hash`. Mas queremos que você pratique empacotamento, desempacotamento e atribuição múltipla para resolver cada uma das tarefas abaixo.
~~~~

## 1. Crie uma lista com todos os vagões

Seu amigo vem anotando o identificador (ID) de cada vagão, mas nunca tem certeza de quantos vagões o sistema vai ter que processar em um dado momento. Para o resto do programa de logística, seria muito mais fácil ter esses dados empacotados em um único **array**.

Implemente um método `generate_list_of_wagons()` que recebe uma quantidade arbitrária de IDs de vagões.
Cada ID será um número inteiro positivo.
O método deve então `return` os IDs informados como um único **array**.

```ruby
LocomotiveEngineer.generate_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
# => [1, 7, 12, 3, 14, 8, 5]
```

## 2. Corrija a lista de vagões

Neste ponto, você já está começando a entender os dados e como eles são usados no programa de logística.
O sistema de IDs sempre atribui à locomotiva o ID **1**, e o restante dos vagões do trem recebe um ID escolhido aleatoriamente, maior que **1**.

Seu amigo precisou acoplar dois vagões novos ao trem e esqueceu de atualizar o sistema!
Agora, os dois primeiros vagões do **array** do trem precisam ser movidos para o final, senão tudo vai ficar fora de ordem.

Para complicar mais, seu amigo acabou de encontrar um segundo **array** que parece conter IDs de vagões que estão faltando.
Linus só se lembra de que, depois que os vagões novos forem movidos, os IDs desse segundo **array** devem ser colocados logo depois da locomotiva indicada.

Linus vai te agradecer muito por corrigir os erros e consolidar os dados.

Implemente um método `fix_list_of_wagons()` que recebe dois **arrays** contendo IDs de vagões.
Ele deve reposicionar os dois primeiros itens do primeiro **array** para o final e inserir os valores do segundo **array** atrás (_no lado direito_) do ID da locomotiva (**1**).
O método deve então `return` um **array** com as modificações.

```ruby
LocomotiveEngineer.fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
# => [1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Adicione as paradas que faltam

Agora que todos os dados dos vagões estão corretos, Linus gostaria que você atualizasse as informações de roteamento do sistema.
Ao longo de uma rota de transporte, um trem pode parar em algumas estações diferentes para pegar e/ou deixar carga.
Cada viagem pode ter uma quantidade diferente desses pontos de entrega intermediários.
Seu amigo gostaria que você atualizasse o **hash** de roteamento do sistema com qualquer informação de entrega que esteja faltando ou que seja adicional.

Implemente um método `add_missing_stops()` que recebe um **hash** de roteamento seguido de um número variável de argumentos de palavra-chave.
Esses argumentos podem estar na forma de um **hash** contendo uma ou mais paradas, ou de qualquer número de pares de palavra-chave `stop_<number>: "city"`.
Seu método deve então retornar o **hash** de roteamento atualizado com uma **chave** adicional que contém um **array** com todas as paradas adicionadas, na ordem.

```ruby
LocomotiveEngineer.add_missing_stops({from: "New York", to: "Miami"},
                    stop_1: "Washington, DC", stop_2: "Charlotte", stop_3: "Atlanta",
                    stop_4: "Jacksonville", stop_5: "Orlando")
# => {from: "New York", to: "Miami", stops: ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

~~~~exercism/note
As paradas sempre serão passadas na ordem correta, então você não precisa se preocupar em ordená-las.
~~~~

## 4. Estenda as informações de roteamento

Linus tem trabalhado no programa de roteamento e percebeu que algumas rotas estão sem detalhes importantes.
As informações iniciais da rota foram montadas como um **hash**, e seu amigo gostaria que você atualizasse esse **hash** com tudo o que estiver faltando.
Cada rota do sistema exige detalhes um pouco diferentes, então Linus preferiria muito uma solução genérica.

Implemente um método chamado `extend_route_information()` que recebe dois **hashes**.
O primeiro **hash** contém as cidades de origem e destino entre as quais a rota do trem passa.

O segundo **hash** contém outros detalhes da rota, como velocidade, comprimento ou temperatura do trem.
O método deve retornar um **hash** consolidado com todas as informações da rota.

~~~~exercism/note
O segundo **hash** pode conter propriedades diferentes ou em maior número do que as mostradas no exemplo.
~~~~

```ruby
LocomotiveEngineer.extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
# => {"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```
