# Sobre

O código Elixir roda na [máquina virtual BEAM][beam]. O BEAM faz parte do sistema de execução do [Erlang][erlang]. Por ter sido inspirado no Erlang e compartilhar o seu ambiente de execução, o Elixir oferece uma ótima interoperabilidade com bibliotecas Erlang. Isso significa que os desenvolvedores Elixir podem usar bibliotecas Erlang dentro do próprio código Elixir. Na verdade, escrever bibliotecas Elixir para funcionalidades que as bibliotecas Erlang já oferecem é desencorajado na comunidade Elixir.

Por isso, certas funcionalidades, como operações matemáticas ou funções de temporizador, só estão disponíveis no Elixir por meio do Erlang.

Essa relação próxima entre Elixir e Erlang significa que, para se tornar um desenvolvedor Elixir proficiente, talvez você queira investir algum tempo aprendendo a sintaxe básica do Erlang.

## Como usar

A biblioteca padrão do Erlang está disponível para uso no nosso código Elixir sem nenhum passo extra.

As funções Erlang podem ser chamadas da mesma forma que chamamos funções Elixir, com uma pequena diferença. Os nomes dos módulos Erlang são átomos em `snake_case`. Por exemplo, para chamar a função `pi/0` do módulo `math` do Erlang, você escreveria:

```elixir
:math.pi()
# => 3.141592653589793
```

## Os módulos Erlang mais usados

Os módulos Erlang mais usados oferecem funcionalidades que faltam na biblioteca padrão do Elixir. São eles:

- O módulo `timer`, que fornece funções como [`sleep/1`][erl-timer-sleep], [`send_after/2`][erl-timer-send-after] e [`send_interval/2`][erl-timer-send-interval].
- O módulo `rand`, que fornece funções como [`uniform/0`][erl-rand-uniform], [`normal/0`][erl-rand-normal] e [`seed/2`][erl-rand-seed-2].
- [`:io_lib.format/2`][erl-io-lib-format], que fornece formatação de string no estilo C (usando sequências de controle).
- O módulo `math`, que fornece funções matemáticas como [`sin/1`][erl-math-sin], [`cos/1`][erl-math-cos], [`log2/1`][erl-math-log2], [`log10/1`][erl-math-log10], [`pow/2`][erl-math-pow] e muitas outras.
- O módulo [`queue`][erl-queue], que fornece uma estrutura de dados de fila.
- O módulo [`crypto`][erl-crypto], que fornece funções criptográficas.
- O módulo [`zip`][erl-zip], que fornece funções para trabalhar com arquivos zip.
- O módulo [`calendar`][erl-calendar], que fornece funções para trabalhar com datas e horas, como [`iso_week_number/1`][erl-calendar-iso-week-number]. Para passar uma struct `Date`, `Time` ou `NaiveDateTime` para uma das funções Erlang, ela precisa ser convertida para o formato Erlang com uma função `to_erl` do módulo correspondente.

Para conhecer a biblioteca padrão do Erlang, explore o [Manual de Referência do STDLIB][erl-stdlib-ref].

A interoperabilidade do Elixir com bibliotecas Erlang não se limita à biblioteca padrão do Erlang. Qualquer biblioteca Erlang pode ser usada no código Elixir.
