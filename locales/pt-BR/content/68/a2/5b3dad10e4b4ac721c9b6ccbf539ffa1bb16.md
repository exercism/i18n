# Testes

No MacOS/Linux, execute:

```sh
$ chmod +x gradlew
```

Execute os testes com:

```sh
$ ./gradlew test
```

> Use `gradlew.bat` se você estiver no Windows

## Testes ignorados

Depois que os primeiros testes passarem, continue comentando ou removendo as anotações `@Ignore` que vêm antes dos outros testes.
