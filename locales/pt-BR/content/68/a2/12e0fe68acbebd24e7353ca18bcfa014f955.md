# Instruções

Sua empresa de design vinha trabalhando principalmente com transformações CSS para construir páginas web. Depois de algumas conversas, vocês decidem começar a usar Clojure para fazer alguns cálculos dinamicamente. Alguns dos seus colegas de equipe têm menos experiência com Clojure, então você decide usar um closure de função para criar transformações reutilizáveis para pares de coordenadas `{x, y}`.

## 1. Translade as coordenadas

Implemente a função `translate2d`, que retorna uma função usando um closure para realizar uma translação 2D repetível de um par de coordenadas.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. Escale as coordenadas

Implemente a função `scale2d`, que retorna uma função usando um closure para realizar uma escala 2D repetível de um par de coordenadas.

> Para este exercício, considere apenas valores de escala positivos.

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. Componha funções de transformação

Combine duas funções de transformação para realizar uma transformação repetível. Isso costuma ser chamado de _composição de funções_, em que o resultado da primeira função, _'f(x)'_, é usado como valor de entrada da segunda função, _'g(x)'_.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. Armazene os resultados das funções

Implemente a função `memoize-transform`. Ela recebe uma função para _memorizar_ e então retorna uma nova função que lembra as entradas da função fornecida, para que o último valor de retorno possa ser "lembrado" e calculado só uma vez caso ela seja chamada novamente com os mesmos argumentos.

> A memorização às vezes é chamada de _programação dinâmica_. Ela permite que operações caras sejam feitas só uma vez, já que o resultado fica guardado.

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
