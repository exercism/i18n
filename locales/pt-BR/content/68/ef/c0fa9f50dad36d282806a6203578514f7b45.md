# Sobre

Os criadores de Julia querem ter o bolo e comê-lo também. Como descrevem em seu post no blog ["Why We Created Julia"](http://julialang.org/blog/2012/02/why-we-created-julia), eles querem a velocidade do C, o dinamismo do Ruby e a notação matemática familiar do Matlab. Querem que ela reúna os recursos favoritos das linguagens de que mais gostam. Processamento de strings como em Perl. Cola, como o shell. Poderosa, mas não complexa a ponto de ser impenetrável.

Julia tem um [sistema de tipos](http://docs.julialang.org/en/v1/manual/types/) dinâmico, poderoso mas ao mesmo tempo claro e intuitivo. Ele permite escrever código dinâmico e especificar tipos quando mais expressividade é necessária para simplificar o código ou melhorar o desempenho. A linguagem conta com [despacho múltiplo](https://youtu.be/kc9HwsxE1OY?t=66), ou seja, ela escolhe qual método é chamado com base nos tipos de cada argumento. Isso permite escrever métodos específicos para certos tipos, ao mesmo tempo em que oferece alternativas genéricas, e é especialmente útil em código matemático, onde não fica claro por que uma operação deveria pertencer a um argumento específico.

A [metaprogramação](http://docs.julialang.org/en/v1/manual/metaprogramming/) é fácil em Julia. O código pode ser representado como uma estrutura de dados na própria linguagem, então um programa pode transformar e gerar seu próprio código, de forma semelhante a Lisp. Grandes partes da [base e biblioteca padrão de Julia](https://github.com/julialang/julia) também são escritas em Julia. Entender e modificar esse código não exige conhecimento de outra linguagem. Se uma biblioteca que você precisa usar está escrita em outra linguagem, como [C, Fortran](http://docs.julialang.org/en/v1/manual/calling-c-and-fortran-code/) ou [Python](https://github.com/JuliaPy/PyCall.jl), você pode usar interfaces simples para chamá-la diretamente do seu código.

Apesar de ser jovem, Julia já é usada no mundo real em diversas áreas, como finanças, ciência de dados e computação científica, entre outras. Você pode encontrar muitas aplicações de destaque no [Julia Blog Aggregator](https://www.juliabloggers.com/), estudos de caso de uso comercial em [juliacomputing.com](https://juliacomputing.com/case-studies/) e uma lista de publicações sobre a linguagem e suas aplicações em pesquisa [aqui](https://julialang.org/research/).
