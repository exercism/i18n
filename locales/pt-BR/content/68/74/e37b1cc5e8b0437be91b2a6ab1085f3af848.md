# Sobre

[concept:csharp/resource-cleanup]() usa a interface `IDispose` para sinalizar a quem chama uma classe que existem recursos ou estado de programa que precisam ser liberados ou redefinidos em tempo hábil quando o objeto em questão não é mais necessário. Neste exercício, introduzimos um pouco de açúcar sintático com a palavra-chave `using`, que deixa o código menos verboso e reduz a chance de chamadas importantes serem omitidas.

Em alguns casos, pode-se dizer que `using` substitui o [`try/finally`][try-finally].

```csharp
File file = null;
try
{
    file = new File("myStuff.txt");
    file.Write("more stuff");
}
finally
{
    file.Dispose();
}
```

Essa sintaxe é substituída pela forma mais compacta e à prova de erros:

```csharp
using (var file = new File("myStuff.txt")
{
    file.Write("more stuff");
}
```

Repare que vários recursos podem ser combinados de forma conveniente seguindo as regras padrão para blocos de uma linha:

```csharp
using (var file = new File("mystuff.txt")
using (var fileWriter = new StreamWriter(file)
{
     ...
}
```

No C# 8, foi introduzida a seguinte variação, em que a instrução `using` vem no início de um bloco:

```csharp
using var file = new File("myStuff.txt");
file.Write("more stuff");
```

Isso permite ter vários objetos descartáveis no mesmo bloco e lidar com o [`try/catch`][try-catch] de forma mais natural:

```csharp
using var fileIn = new File("myStuff.txt");
using var fileOut = new File("yourStuff.txt");
try
{
    var stuff = fileIn.Read();
    fileOut.Write(stuff);
}
catch (Exception)
{
    LogStuff();
}
```

As regras sobre como a palavra-chave `using` pode ser usada com instâncias de quais tipos são detalhadas [aqui][using-statement].

## Nota para quem programa em Java

Quem programa em Java pode reconhecer isso como um análogo do mecanismo de [_gerenciamento automático de recursos_][automatic-resource-management] introduzido no Java 7. Os dois são muito parecidos. A sintaxe do Java, que reaproveita o `try`, tem a vantagem de incorporar blocos `catch` de forma mais natural do que o `using` do C#.

## Versões

Repare que a versão mais flexível do `using`, aquela que não tem um bloco sintático próprio, foi introduzida no C# 8, então pode ser que você precise verificar se a base de código em que está trabalhando usa C# 8 ou posterior.
