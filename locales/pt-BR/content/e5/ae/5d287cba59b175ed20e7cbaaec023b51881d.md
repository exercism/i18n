# Introdução

## Sintaxe geral

O laço `for` é uma das instruções mais usadas para executar alguma lógica repetidamente.
Em Go, ele é formado pela palavra-chave `for`, um cabeçalho e um bloco de código que contém o corpo do laço envolvido por chaves.
O cabeçalho é composto por 3 componentes separados por ponto e vírgula `;`: init, condition e post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- O componente **init** é um trecho de código que roda uma única vez, antes de o laço começar.
- O componente **condition** precisa ser uma expressão que resulta em um Boolean e controla quando o laço deve parar.
  O código dentro do laço roda enquanto essa condição for verdadeira.
  Assim que essa expressão for falsa, nenhuma outra iteração do laço vai rodar.
- O componente **post** é um trecho de código que roda no fim de cada iteração.

**Nota:** Diferente de outras linguagens, não há parênteses `()` envolvendo os três componentes do cabeçalho.
Na verdade, inserir esses parênteses é um erro de compilação.
No entanto, as chaves `{ }` em volta do corpo do laço são sempre obrigatórias.

## Laços `for` - um exemplo

Normalmente o componente init cria uma variável contadora, o componente condition verifica se o laço deve continuar ou parar, e o componente post incrementa o contador no fim de cada repetição.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Esse laço vai imprimir os números de `1` a `9` (incluindo o `9`).
Definir o passo costuma ser feito com uma instrução de incremento ou decremento, como mostra o exemplo acima.
