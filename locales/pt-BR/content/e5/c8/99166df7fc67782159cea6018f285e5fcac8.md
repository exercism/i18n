# Sobre

A ligação descreve de onde no código um identificador pode ser acessado.
Valores com escopo de bloco, de função ou de protótipo de função não têm ligação.
Isso significa que não é possível acessá-los de fora do próprio escopo.
Para saber mais sobre escopo, veja o [conceito de escopo](../scope/introduction.md#Introduction).

## Ligação externa

Identificadores com escopo de arquivo têm ligação externa por padrão.
Um identificador com ligação externa pode ser chamado de qualquer arquivo do programa.

## Ligação interna

É possível fazer um identificador com escopo de arquivo ter ligação interna usando o especificador `static`.
Um identificador com ligação interna só pode ser usado dentro do próprio arquivo.

Por exemplo

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

Ligação estática não deve ser confundida com duração de armazenamento estática.
Para saber mais sobre duração de armazenamento estática, veja o [conceito de duração de armazenamento](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).

Se um valor (em oposição a uma função) é declarado em um cabeçalho, mas é definido no arquivo-fonte como um identificador de escopo de arquivo `static` com um valor inicializado, seu valor inicializado não será acessível de fora do arquivo-fonte.
Ele pode compilar, ligar e rodar sem erro, mas o valor será o valor zero para o identificador, mesmo que o valor seja declarado com `extern`.
(Para saber mais sobre `extern`, veja o [conceito de extern](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit).)
Um identificador de escopo de arquivo marcado como `static` em um arquivo-fonte não deve ser declarado em seu arquivo de cabeçalho.
