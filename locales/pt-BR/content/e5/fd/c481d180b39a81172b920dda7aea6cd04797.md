# Instruções

Neste exercício, você vai implementar a lógica da missão de um novo jogo de RPG que um amigo está desenvolvendo. A personagem principal do jogo é Annalyn, uma garota corajosa com um cachorro de estimação feroz e leal. Infelizmente, o desastre acontece: sua melhor amiga foi sequestrada enquanto procurava frutas na floresta. Annalyn vai tentar encontrar e libertar sua melhor amiga, podendo levar seu cachorro com ela nessa missão.

Depois de passar um tempo seguindo o rastro de sua melhor amiga, ela encontra o acampamento onde sua melhor amiga está presa. Acontece que há dois sequestradores: um cavaleiro poderoso e um arqueiro astuto.

Depois de encontrar os sequestradores, Annalyn considera quais das seguintes ações ela pode realizar:

- Ataque rápido: um ataque rápido pode ser feito se o cavaleiro estiver dormindo, pois ele leva tempo para vestir a armadura, então estará vulnerável.
- Espionar: o grupo pode ser espionado se pelo menos um deles estiver acordado. Caso contrário, espionar é perda de tempo.
- Sinalizar ao prisioneiro: pode-se sinalizar ao prisioneiro usando sons de pássaros se o prisioneiro estiver acordado e o arqueiro estiver dormindo, pois arqueiros são treinados em sinalização com pássaros e poderiam interceptar a mensagem.
- _Libertar o prisioneiro_: Annalyn pode tentar entrar furtivamente no acampamento para libertar o prisioneiro.
  Isso é arriscado e só pode dar certo de uma das duas maneiras:
  - Se Annalyn estiver com seu cachorro, ela pode resgatar o prisioneiro se o arqueiro estiver dormindo.
    O cavaleiro tem medo do cachorro e o arqueiro não terá tempo de se preparar antes que Annalyn e o prisioneiro escapem.
  - Se Annalyn não estiver com o cachorro, ela e o prisioneiro precisam ser muito furtivos!
    Annalyn pode libertar o prisioneiro se o prisioneiro estiver acordado e o cavaleiro e o arqueiro estiverem ambos dormindo, mas se o prisioneiro estiver dormindo não dá para resgatá-lo: o prisioneiro se assustaria com o aparecimento repentino de Annalyn e acordaria o cavaleiro e o arqueiro.

Você tem quatro tarefas: implementar a lógica para determinar se as ações acima estão disponíveis com base no estado dos três personagens encontrados na floresta e na presença ou não do cachorro de Annalyn.

## 1. Verifique se um ataque rápido pode ser feito

Implemente o método `canFastAttack()` que recebe um valor Boolean que indica se o cavaleiro está acordado. Esse método retorna `true` se um ataque rápido puder ser feito com base no estado do cavaleiro. Caso contrário, retorna `false`:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. Verifique se o grupo pode ser espionado

Implemente o método `canSpy()` que recebe três valores Boolean, indicando se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados. O método retorna `true` se o grupo puder ser espionado, com base no estado dos três personagens. Caso contrário, retorna `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Verifique se dá para sinalizar ao prisioneiro

Implemente o método `canSignalPrisoner()` que recebe dois valores Boolean, indicando se o arqueiro e o prisioneiro, respectivamente, estão acordados. O método retorna `true` se puder ser sinalizado ao prisioneiro, com base no estado dos dois personagens. Caso contrário, retorna `false`:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Verifique se o prisioneiro pode ser libertado

Implemente o método `canFreePrisoner()` que recebe quatro valores Boolean. Os três primeiros parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados. O último parâmetro indica se o cachorro de Annalyn está presente. O método retorna `true` se o prisioneiro puder ser libertado com base no estado dos três personagens e na presença do cachorro de Annalyn. Caso contrário, retorna `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
