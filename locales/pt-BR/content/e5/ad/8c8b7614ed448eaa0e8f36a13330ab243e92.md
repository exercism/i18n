# Testes

Execute os testes com:

```shell
npm run test
```

Você também pode rodar o Jest no modo "watch", que executa seus testes de novo automaticamente sempre que você salvar alterações no código ou no módulo de teste:

```shell
npm run watch
```

## Entendendo os testes ignorados

O método skip instrui a suíte de testes a não executar um teste. Essa função também pode ser usada com os aliases: `it.skip(name, fn)`, `xit(name, fn)` ou `xtest(name, fn)`

- Por que eles são ignorados ?

Para permitir que as pessoas se concentrem em um teste de cada vez e os ativem um a um conforme evoluem a solução.

- Como ativá-los ?

Mude `xtest` para `test`.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
