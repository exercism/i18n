# Introdução

Uma *expressão regular* (regex) é um pequeno padrão que descreve como um texto deve se parecer. Em vez de verificar uma string caractere por caractere você mesmo, você escreve o formato que quer uma vez e deixa o Factor fazer a correspondência. As ferramentas de regex do Factor ficam no vocabulário [`regexp`][regexp].

## Escrevendo um padrão

No Factor, você escreve uma regex entre `R/ ` e `/`:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

A maioria dos caracteres em um padrão significa apenas a si mesma: `R/ cat/` corresponde ao texto `cat`. O poder vem de alguns elementos especiais que representam *tipos* de caracteres ou *quantos* deles.

### Classes de caracteres: "um caractere de um conjunto"

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

Uma classe corresponde a exatamente *um* caractere. `[A-Z]` corresponde a `Q`, mas não a `QQ`.

### Quantificadores: "quantas vezes"

Coloque um destes *depois* de um elemento para dizer quantas vezes ele pode se repetir:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

Então `\d{4}` significa quatro dígitos seguidos, e `[A-Z]+` significa uma ou mais letras maiúsculas. Juntando tudo, `R/ [A-Z]+-\d+/` descreve "uma ou mais maiúsculas, um traço e então um ou mais dígitos", texto como `SALE-2024`. O `-` aqui é um caractere comum: fora de `[ ]` um traço corresponde apenas a um traço (dentro de uma classe, como em `[A-Z]`, ele marca um intervalo).

## Correspondência com uma string inteira

`matches?` responde "essa string *inteira* cabe no padrão?", o padrão precisa dar conta de cada caractere, do início ao fim:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

Mesmo que `SALE-2024` esteja dentro de `"GET SALE-2024"`, `matches?` ainda diz `f`: os caracteres extras fazem parte da string e não cabem no padrão. Quando você só se importa se o padrão aparece em *algum lugar*, use `re-contains?`: ele retorna `t` exatamente onde `matches?` retornou `f`:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## Encontrando correspondências dentro de um texto maior

`re-contains?` diz apenas *se* o padrão está lá. As próximas palavras olham para dentro e informam *o que* correspondeu: `all-matching-subseqs` retorna cada lugar em que o padrão corresponde, como uma sequência de strings, e `count-matches` apenas os conta:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## Substituindo correspondências

`re-replace` troca cada correspondência por um texto de substituição e retorna a nova string:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

O vocabulário `regexp` tem mais palavras que vale a pena conhecer. Siga os links para detalhes: [`first-match`][first-match] (apenas a primeira correspondência) e [`re-split`][re-split] (dividir uma string em cada lugar em que o padrão corresponde).
