# Testes

Para cada exemplo, são necessários os seguintes passos gerais.

Primeiro, mude para o diretório do exercício que você quer praticar, neste caso `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

Em seguida, rode os testes. O alvo `test` do make depende de `compile`, então rodar `make test` garante que seu código-fonte seja compilado e, depois, passa a rodar os testes.


```bash
$ make test
```

Parabéns! Você tem testes falhando!!!

Agora leia o `README.md` para descobrir o que você precisa fazer para que todos os seus testes passem.


Corrija o primeiro erro reportado pelo teste e rode os testes de novo.

```bash
$ make test
```

Continue corrigindo o próximo teste que falha no seu código-fonte e rodando os testes até que todos passem.

Quando todos os seus testes passarem, dê uma última olhada no seu código no diretório `src` para conferir se está tudo do jeito que você quer e envie para revisão.

Receba feedback, revise a solução, envie, tente o próximo exercício e repita o processo até alcançar a iluminação em LFE.
