# Apêndice das instruções

## Dicas

Para o nível de desafio adequado aqui, use apenas a funcionalidade presente no Prelude. Tente não usar Data.List, Data.Char, Data.Bits nem Numeric.

Tente usar seq, $! ou BangPatterns de forma adequada para garantir que a solução seja eficiente.

Não é necessário tratar entradas inválidas.

Se você já fez o exercício Octal, talvez valha a pena generalizá-lo.
