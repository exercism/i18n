# Complemento das instruções

~~~~exercism/note

A descrição acima menciona [_conjuntos matemáticos_][math-sets], mas também que um terno pitagórico {a, b, c} _**precisa**_ estar ordenado de forma que a < b < c (_ordem crescente_).

Isso torna o [tipo `set`][python-sets] do Python inadequado para este exercício, já que ele é, por natureza, _não ordenado_.
Em vez disso, você deve retornar uma [`list`][python-list] de `list`s (_por exemplo, `[[a, b, c]]`_).
Você pode gerar os ternos na ordem que quiser, já que a ordem da `list` externa será ignorada nos testes.

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
