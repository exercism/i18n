# Dicas

A menos que você tenha muita confiança nas suas habilidades com Regex, pode ajudar testar a sintaxe em um playground online como o [Regex101][regex101].

Lembre-se de definir o flavor para PCRE2.

Definir cada expressão regular antecipadamente como uma `const` pode ser um estilo útil (para clareza e desempenho).

## 1. Verificar se o comando é válido

- O caractere de âncora para o início da string é `^`.
- Você só precisa de um verdadeiro/falso como resultado da busca da regex.
- Isso poderia ser resolvido sem usar Regex, mas, por favor, mantenha o espírito de um exercício de conceito.

## 2. Remover emojis criptografados

- Um simples [`replace()`][replace].

## 3. Verificar se o número de telefone é válido

- Precisa de uma Regex mais longa, mas bastante repetitiva.
- `n` ocorrências consecutivas podem ser especificadas com a sintaxe `{n}`.
- Só precisamos de um verdadeiro/falso para a correspondência.

## 4. Obter o link do site

- Lembre-se de escapar o ponto com `\.`
- Capture a parte antes do ponto em um [match][match].

## 5. Cumprimentar o usuário

- Um `replace()` com capturas nomeadas tem o formato `r"(?<name>...) " => s"\g<name>... "`
- Novamente, um `split()` poderia resolver a tarefa, mas praticar Regex é útil.
