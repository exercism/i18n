# Instruções

Josh está trabalhando em um novo jogo de RPG e precisa da sua ajuda para implementar algumas das mecânicas.

## 1. Defina uniões de tipos

Defina uma união de tipos de `String` e `Missing` chamada `StringOrMissing`, que pode ser usada em código posterior.
Defina uma união de tipos de `Int64` e `Nothing` chamada `IntOrNothing`, que pode ser usada em código posterior.

## 2. Implemente o tipo composto Player

O tipo composto Player deve conter quatro campos, cada um com uma anotação de tipo e um valor padrão:
- O `name` é do tipo `StringOrMissing`, com valor padrão `missing`
- O `level` é do tipo `Int64`, com valor padrão `0`
- O `health` é do tipo `Int64`, com valor padrão `100`
- O `mana` é do tipo `IntOrNothing`, com valor padrão `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. Apresente-se

Implemente a função `introduce`.

Jogadores furtivos podem estar escondendo o nome e serão apresentados como `"Mighty Magician"`.
Caso contrário, use apenas o nome do jogador para apresentá-lo.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. Implemente os métodos de incremento

A função auxiliar `increment` tem dois métodos, cada um com uma assinatura de função diferente.
O argumento de cada um precisa de uma anotação de tipo para deixar a assinatura explícita.

O método `increment` para nomes deve receber o `name` de um jogador.
- Se o nome for `missing`, retorne o título "The Great".
- Caso contrário, o título " the Great" é adicionado ao nome.

Esse método `increment` retorna o novo nome.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

O método `increment` para mana deve receber o `mana` de um jogador.
- Se o mana do jogador for `missing`, retorne o valor `50`.
- Caso contrário, o mana deve ser aumentado em `100`.

Esse método `increment` retorna o mana atualizado.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. Implemente a função de título

O nível mais alto no jogo é `42`. Para reconhecer a conquista dos jogadores que alcançam esse nível, um título é anexado aos seus nomes. A função `title!` atualiza o nome de um jogador da seguinte forma.

- Se o nível do jogador for 42, o nome é atualizado usando a função `increment`.
- Caso contrário, o nome permanece inalterado.

Em ambos os casos, a função `title!` retorna o nome do jogador.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. Implemente a função de ressurreição

A função `revive!` deve verificar se o personagem do jogador está mesmo morto (a saúde dele chegou a `0`).

Se o jogador estiver morto:
- O jogador deve ser revivido com `100` de saúde.
- O mana do jogador deve ser incrementado usando a função `increment`.

Se o jogador estiver vivo, nada acontece com ele.

A função `revive!` deve retornar o jogador.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
