# Introdução

Um vetor é um array unidimensional.
Ele pode conter elementos de tipos diferentes.

## Criando vetores

Vetores podem ser criados com a função `vector` ou usando sua forma de leitura `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## Acessando elementos

Para acessar elementos de um vetor, use `aref`; os índices começam em zero:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
