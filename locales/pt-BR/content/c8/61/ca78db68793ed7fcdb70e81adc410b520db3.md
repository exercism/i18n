# Sobre

Um dos aspectos principais de trabalhar com números em F# é a distinção entre inteiros (números sem dígitos depois do separador decimal) e números de ponto flutuante (números com zero ou mais dígitos depois do separador decimal).

Os dois tipos numéricos mais usados em F# são `int` (um inteiro de 32 bits) e `float` (um número de ponto flutuante de 64 bits).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

Tanto os inteiros quanto os números de ponto flutuante podem usar o caractere `_` como _separador de dígitos_, o que ajuda na hora de escrever números grandes:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

As operações aritméticas são feitas com os [operadores aritméticos][arithmetic-operators] padrão (`+`, `-`, `*`, etc.). Números podem ser comparados com os [operadores de comparação][comparison-operators] padrão (`<`, `>=`, etc.) e com os operadores de igualdade (`=`) e de diferença (`<>`).

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

Para converter entre tipos numéricos, é preciso usar o [operador de conversão][conversion-operators] embutido. Esses operadores têm o nome do tipo para o qual vão converter.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

Ao converter entre tipos, tenha sempre cuidado. Se um valor não puder ser representado pelo tipo de destino, ele vai sofrer _overflow_.
