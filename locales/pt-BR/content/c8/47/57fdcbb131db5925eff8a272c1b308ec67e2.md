# Instruções

Sua amiga Li Mei administra uma barraca de sucos onde vende deliciosos sucos mistos de frutas. Você é cliente frequente da loja dela e percebeu que poderia deixar a vida dela mais fácil com um pouco de código em Factor.

## 1. Determine quanto tempo leva para misturar um suco

Li Mei gosta de avisar os clientes com antecedência quanto tempo eles vão esperar por um suco do menu. Ela tem dificuldade para lembrar os números exatos, porque o tempo que leva para misturar os sucos varia:

- `"Pure Strawberry Joy"` leva `0.5` minutos.
- `"Energizer"` e `"Green Garden"` levam `1.5` minutos cada.
- `"Tropical Island"` leva `3` minutos.
- `"All or Nothing"` leva `5` minutos.
- Todas as outras bebidas (por exemplo, ofertas especiais) levam `2.5` minutos.

Defina `time-to-mix-juice` para receber o nome de um suco da pilha e retornar o número de minutos que leva para misturar essa bebida.

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. Reponha o estoque de gomos de limão

Muitas das criações de Li Mei incluem gomos de limão, seja como ingrediente, seja como parte da decoração. Então, quando ela começa o turno de manhã, precisa garantir que o recipiente de gomos de limão esteja cheio para o dia que vem.

Defina `wedges-from-lime`, que recebe um tamanho de limão e retorna o número de gomos que ele produz: `6` de um limão `"small"`, `8` de um `"medium"`, `10` de um `"large"`.

Depois defina `limes-to-cut`, que recebe o número de gomos `needed` e um array de `limes` (tamanhos de limão na ordem de corte). A função corta os limões um a um, na ordem, e para assim que tiver gomos suficientes ou quando os limões acabarem. Retorne o número de limões que ela precisou cortar.

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. Liste os tempos de misturar cada pedido na fila

Li Mei gosta de acompanhar quanto tempo vai levar para misturar os pedidos pelos quais os clientes estão esperando.

Defina `order-times` para receber um array de pedidos e retornar um array com o tempo para misturar cada pedido, na mesma ordem.

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. Encerre o turno

Li Mei sempre trabalha até as 15h. Depois, seu funcionário Dmitry assume o posto. Muitas vezes, quando o turno de Li Mei termina, há bebidas que já foram pedidas mas ainda não foram preparadas; Dmitry então prepara os sucos que sobraram.

Para facilitar a passagem do turno, defina `remaining-orders`, que recebe o número de minutos `time-left` do turno de Li Mei e um array de `orders` (sucos que foram pedidos mas ainda não foram preparados). Retorne os pedidos que Dmitry vai precisar assumir, ou seja, aqueles que Li Mei não tem tempo de começar antes de o turno dela terminar.

`time-left` é sempre maior que `0`. Os pedidos são preparados na ordem em que aparecem no array. Depois que Li Mei começa um suco, ela sempre o termina, mesmo que precise trabalhar um pouco mais. Se ela tiver tempo de começar todos os pedidos, retorne um array vazio.

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
