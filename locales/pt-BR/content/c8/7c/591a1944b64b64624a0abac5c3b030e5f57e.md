# Introdução

Existem basicamente dois tipos de laços:

1. Repetir até que uma condição seja satisfeita.
2. Percorrer os elementos de uma coleção.

Os dois são possíveis em Julia, embora o segundo seja mais comum.

## O laço `while`

Para problemas em aberto, em que o número de repetições do laço não é conhecido de antemão, Julia tem o laço `while`.

A forma básica é bem simples:

```julia
while condition
    do_something()
end
```

Nesse caso, o programa continua repetindo o laço até que `condition` não seja mais `true`.

Há duas formas de sair do laço mais cedo:

- Um `break` faz o laço terminar, e a execução continua na linha seguinte ao `end` do laço.
- Um `return x` interrompe a execução da função atual e devolve o valor de retorno `x` para quem fez a chamada.

Com essas opções disponíveis, às vezes é conveniente criar um laço "infinito" com `while true ... end` e contar com a descoberta de uma condição de parada dentro do corpo do laço para disparar um `break` ou um `return`.

## Percorrer uma coleção

A ilustração mais simples é percorrer um intervalo.

Se quisermos fazer algo 10 vezes:

```julia
for n in 1:10
    do_something(n)
end
```

Se a iteração atual não satisfizer alguma condição, é possível pular imediatamente para a próxima iteração com um `continue`:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

Em uma forma mais curta, o bloco `if` poderia ser substituído por `is_useless(n) && continue`.

Muitos outros tipos de coleção podem ser percorridos: os elementos de um array, os caracteres de uma string, as chaves de um dicionário...

Os exemplos até agora percorrem o intervalo `1:10`, em que o valor também é o índice do laço.

De modo mais geral, pode ser que o índice seja necessário, e não apenas o valor.
Para isso, usa-se a função `eachindex()`, por exemplo, `for i in eachindex(my_array) ... end`.
