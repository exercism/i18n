# Noções básicas

Um programa em Sather é feito de **classes** que contêm **rotinas**.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## Classes

O nome de uma classe é escrito em maiúsculas, com sublinhados entre as
palavras: `GREETER`, `STAGE_DIRECTIONS`. O nome do arquivo geralmente
corresponde, em minúsculas: `stage_directions.sa`.

Toda rotina fica dentro de uma classe. Não existe código fora dela.

## Rotinas

Uma rotina que produz uma resposta declara o tipo de resposta depois de dois-pontos:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` é o tipo para texto. Uma rotina que não recebe argumentos é escrita e
chamada sem parênteses.

Uma rotina pode receber argumentos, escritos entre parênteses depois do nome:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return` devolve uma resposta e para a rotina na hora, então quaisquer linhas
abaixo dela são ignoradas.

## Chamadas

De fora da classe, escreva o nome da classe, depois `::`, depois a rotina:

```sather
GREETER::hello
```

De dentro da mesma classe, o nome da classe pode ser omitido. É assim que uma
rotina costuma usar outra:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## Comentários

Dois hífens começam um comentário que vai até o fim da linha.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

Por convenção, uma classe termina com um comentário que diz o nome dela.
Rotinas, laços e classes todos fecham com `end;`, então o comentário diz a qual
deles este `end;` pertence:

```sather
end; -- class GREETER
```

## Ponto e vírgula

As instruções terminam com ponto e vírgula. O ponto e vírgula depois da última
instrução de uma rotina é opcional, mas escrevê-lo sempre é uma coisa a menos
para se preocupar.
