# Instruções

Neste exercício, você precisa implementar algumas funções para manipular uma lista de linguagens de programação.

## 1. Defina uma função que retorna uma lista vazia de linguagens

Defina a função `language_list` que não recebe argumentos e retorna uma lista vazia.

```php
<?php

language_list();
// => []
```

## 2. Modifique a função para criar uma lista a partir de qualquer número de linguagens

Modifique a função `language_list` para que ela receba um argumento variádico de linguagens (strings).
Ela deve retornar a lista resultante com as linguagens na lista.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. Defina uma função para adicionar uma linguagem à lista

Defina a função `add_to_language_list` que recebe 2 argumentos: um array de linguagens e a nova linguagem.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. Defina uma função para remover um item da lista de linguagens

Defina a função `prune_language_list` para remover a primeira linguagem do array de linguagens.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. Defina uma função para obter o primeiro item da lista

Defina a função `current_language` que recebe 1 argumento (uma _lista de linguagens_).
Ela deve retornar a primeira linguagem da lista.
Considere que a lista sempre terá pelo menos um item.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. Defina uma função que retorna quantas linguagens há na lista

Defina a função `language_list_length` que recebe 1 argumento (uma _lista de linguagens_).
Ela deve retornar o número de linguagens na lista.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
