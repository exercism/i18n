# Introdução

## Comparação

Em JavaScript, números podem ser comparados usando os seguintes operadores relacionais e de igualdade.

| Comparação             | Operador  |
| ---------------------- | --------- |
| Maior que              | `a > b`   |
| Maior ou igual a       | `a >= b`  |
| Menor que              | `a < b`   |
| Menor ou igual a       | `a <= b`  |
| Igual (estrito)        | `a === b` |
| Diferente (estrito)    | `a !== b` |

O resultado da comparação é sempre um valor Boolean: `true` ou `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

Em JavaScript, os operadores de comparação acima também podem ser usados para comparar strings.
Nesse caso, aplica-se uma ordem de dicionário (lexicográfica).
Você encontra uma lista com a ordem exata de todos os caracteres [aqui][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Condicionais

Uma forma comum de executar lógica condicionalmente em JavaScript é a condicional.
Ela consiste na palavra-chave `if`, uma condição entre parênteses redondos (`()`) e um bloco de código entre chaves (`{}`).
O bloco de código só será executado se a condição resultar em `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Ela pode ser usada sozinha ou combinada com a palavra-chave `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Para aninhar outra condição na cláusula `else`, você pode usar `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
