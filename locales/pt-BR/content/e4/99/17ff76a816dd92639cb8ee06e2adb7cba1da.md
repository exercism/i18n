# Introdução

Arrays são as sequências de comprimento fixo do Factor: você pode alterar os
elementos, mas não o comprimento. Você já sabe escrever um array literal
(`{ … }`) e como fatiar e agregar um. Este exercício cobre o pequeno conjunto
de ferramentas que surge quando você constrói arrays a partir de valores na
pilha e depois consulta ou reorganiza seus conteúdos.

## Construindo a partir da pilha

`1array`, `2array`, `3array` e `4array` (em [`arrays`][arrays])
retiram 1, 2, 3 ou 4 valores do topo da pilha e os empacotam:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## Juntando

`concat` (em [`sequences`][sequences]) recebe uma sequência cujos
elementos são, por sua vez, sequências e achata tudo em um nível.
`join` faz o mesmo, com um separador inserido entre cada par:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## Invertendo

`reverse` retorna uma nova sequência com os elementos em ordem
inversa:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## É um array?

`array?` (em [`arrays`][arrays]) é o predicado de tipo. É
verdadeiro para qualquer valor construído por `<array>`, `1array`/`2array`/...,
ou um array literal `{ … }`, e falso para todo o resto
(incluindo vetores, strings e outras sequências):

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## Consultando

`index` retorna a posição do primeiro elemento igual ao
valor de entrada, ou `f` se ele não estiver presente. `member?` retorna apenas um
boolean. Ambos recebem o **elemento primeiro** e a **sequência
depois**. `members` (em [`sets`][sets]) retorna os elementos *únicos*
de uma sequência (a operação de deduplicação),
e `all-unique?` (também em `sets`) testa se a sequência
já não tem duplicatas:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
