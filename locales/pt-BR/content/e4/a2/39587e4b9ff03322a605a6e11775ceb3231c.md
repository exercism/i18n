# Introdução

Suponha que você queira todos os inteiros não negativos até 1000.
Seria um absurdo se você tivesse que digitar tudo isso em um array.

Para isso temos o tipo `range`:

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

Ranges são muito comuns: não só para você não precisar digitar tudo, mas também como tipos de retorno de funções.

Repare que ranges _não_ são vetores.
Eles são apenas um conjunto de instruções para gerar uma sequência (avaliação "preguiçosa", ou um "iterador").

Se você precisar de um range como vetor, use a função `collect()` para converter:

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

O tamanho do passo pode ser especificado, neste caso 0.3:

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

Então a sintaxe é `start:stepsize:stop`.
Os dois limites são _inclusivos_, como no exemplo com inteiros.
Se o tamanho do passo não dividir `stop - start` de forma exata, o último elemento não vai ultrapassar `stop`.

## Ranges de letras

Sequências não numéricas também podem ser usadas em ranges.
O exemplo mais simples envolve letras ASCII:

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

O tipo `Char` será abordado com mais detalhes em outro conceito.
Por enquanto, basta tratá-los como caracteres únicos entre aspas simples.

## Funções e operadores para ranges

Verifique os limites de um range com `first()` e `last()`.

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## Mais sobre indexação de vetores

Ranges de inteiros e vetores podem ser usados na indexação de vetores:

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
