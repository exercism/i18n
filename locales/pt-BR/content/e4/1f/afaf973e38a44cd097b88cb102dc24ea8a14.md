# Laços `for`

Repetição com laços é um conceito fundamental da programação que permite executar um bloco de código várias vezes.
No Swift, existem dois tipos de laços: os laços [`for-in`][for-loops] e os laços `while`.
Neste capítulo, você vai aprender sobre os laços `for-in`.

Os laços `for` permitem iterar sobre uma sequência de valores, pegando cada elemento por vez e associando-o a uma variável de sua escolha.
O Swift permite iterar sobre uma variedade de sequências, como intervalos, arrays e strings (e mais tipos, que serão abordados depois).
Quando todos os elementos da sequência tiverem sido iterados, o laço termina.

Os laços `for` são declarados com a palavra-chave `for`, seguida de um nome de variável, da palavra-chave `in` e de uma sequência de valores sobre a qual iterar.
A variável declarada no laço `for-in` é imutável, ou seja, você não pode alterar o valor dela dentro do laço.
Veja um exemplo de laço `for-in` que itera sobre um array de números:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
A variável `number` é declarada no laço `for-in` e só está disponível dentro do escopo do laço.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Iterando sobre um intervalo

Você também pode iterar sobre um intervalo de números usando um laço `for-in`.
Isso permite executar um bloco de código um número específico de vezes. Por exemplo, o intervalo `1...5` itera sobre os números 1, 2, 3, 4 e 5, então o laço é executado 5 vezes.
Às vezes você pode querer iterar sobre os índices de uma estrutura de dados como um array; nesse caso, pode usar um intervalo `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Iterando sobre uma string

Você também pode iterar sobre uma string usando um laço `for-in`.
Isso permite iterar sobre cada caractere da string. Repare que o tipo dado no laço é `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

O Swift também fornece uma função `stride` que permite criar uma sequência sobre um intervalo com um passo específico.
Essa sequência pode então ser iterada com um laço `for-in`.
A função `stride` tem as formas [`stride(from:to:by:)`][stride-to] e [`stride(from:through:by:)`][stride-through]: a primeira é exclusiva e a segunda é inclusiva.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Repare que o parâmetro `to` é exclusivo, então o laço itera até o número anterior ao parâmetro `to`, enquanto o parâmetro `through` é inclusivo, então nesse caso ele também incluiria o `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
