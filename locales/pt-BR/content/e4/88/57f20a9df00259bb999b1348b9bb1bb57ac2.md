# Introdução

Em Python, uma [tupla][tuple] é uma coleção _imutável_ de itens em _sequência_.
Como a maioria das coleções, `tuples` podem conter qualquer tipo de dado (ou vários tipos), incluindo outras `tuples`.
As tuplas dão suporte a todas as [operações comuns de sequência][common sequence operations], mas **não** dão suporte a [operações de sequência mutáveis][mutable sequence operations].

Os elementos de uma tupla podem ser iterados usando a construção `for item in <tuple>`.
Se você precisar tanto do índice quanto do valor do elemento, pode usar `for index, item in enumerate(<tuple>)`.
Como em qualquer sequência, os elementos dentro de `tuples` podem ser acessados com a _notação de colchetes_, usando um número `0-based index` a partir da esquerda ou um número `-1-based index` a partir da direita.
As tuplas também podem ser copiadas por inteiro ou em parte usando a notação de fatiamento (_`<tuple>[<start>:<stop>:<step>]`_).


## Construção de Tuplas

As tuplas podem ser formadas de várias maneiras, usando o construtor de classe `tuple(<iterable>)` ou a declaração literal `tuple`.

### Usando o construtor `tuple()` vazio ou com um _iterável_:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

Strings são iteráveis, então usar uma única `str` como argumento do construtor `tuple()` pode ter resultados surpreendentes:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

Iteráveis simples têm seus elementos adicionados um a um:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### Declarando uma tupla como _literal_:

Como o construtor `tuple(<iterable>)` só aceita _iteráveis_ (ou nada) como argumentos, é muito mais fácil criar uma tupla de um único elemento pelo método literal.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

Estruturas de dados aninhadas podem ser incluídas como elementos de `tuple`, incluindo outras `tuples`:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## Concatenação de Tuplas

As tuplas podem ser concatenadas com o operador de soma `+`, que desempacota cada `tuple` e cria uma nova `tuple` combinada.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## Acessando Elementos Dentro de uma Tupla

Os elementos dentro de uma `tuple` podem ser acessados com a _notação de colchetes_, usando um número `0-based index` a partir da esquerda ou um número `-1-based index` a partir da direita.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## Iterando Sobre os Elementos de uma Tupla

Os elementos dentro de uma `tuple` podem ser _iterados_ em um laço usando a sintaxe `for item in <tuple>`.
Se você precisar tanto dos índices quanto dos valores, pode usar `for index, item in enumerate(<tuple>)`.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## Verificando Pertencimento em uma Tupla

O operador `in` pode ser usado para verificar se algo pertence a uma `tuple`.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
