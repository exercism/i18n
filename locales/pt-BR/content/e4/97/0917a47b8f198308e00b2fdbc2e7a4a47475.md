# Sobre

Haxe tem dois tipos de número, inteiros e números de ponto flutuante:

- `Int`: Representa um número inteiro.
- `Float`: Representa um número de ponto flutuante de precisão dupla de 64 bits.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Embora todo `Int` possa ser usado onde um `Float` é esperado (ou seja, `Int` **pode ser atribuído a** ou **unifica com** `Float`), o contrário não é verdade: atribuir um `Float` a um `Int` pode causar perda de precisão e, por isso, não é permitido de forma implícita.

## Comparação

Dois números são iguais se tiverem o mesmo valor.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

Para o último caso, veja [0.30000000000000004.com][0.30000000000000004.com] para uma breve explicação.
