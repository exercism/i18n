# Ignorar

## Unicode e clusters de grafemas

Este exercício inclui testes com strings Unicode que contêm clusters de grafemas.
As funções nativas de processamento de strings do Perl não são suficientes para lidar com essas strings.
Aqui estão alguns recursos para ajudar você:

* [Trate strings Unicode como clusters de grafemas][foy]
* [Extraia por grafema em vez de ponto de código (regex)][christiansen]

[foy]: https://www.effectiveperlprogramming.com/2011/06/treat-unicode-strings-as-grapheme-clusters/
[christiansen]: https://www.perl.com/pub/2012/05/perlunicookbook-extract-by-grapheme-instead-of-codepoint-regex.html/
