# Recursos

## Módulos

O Perl já vem com um conjunto de módulos principais, que você encontra
listados no [perldoc](https://perldoc.perl.org/modules). Normalmente, você vai
conseguir usar qualquer um desses módulos imediatamente. (Algumas distribuições podem
exigir que você instale os módulos principais separadamente).

O [Awesome Perl](https://github.com/hachiojipm/awesome-perl) é uma lista selecionada de
módulos úteis e também aponta para uma seleção de outras listas de recomendações.

Existem vários instaladores de módulos disponíveis para o Perl, que permitem
instalar uma grande variedade de módulos disponíveis no [CPAN](https://metacpan.org/).

### App::cpm
Um instalador de módulos muito rápido e direto.
Há um tutorial disponível no [CPAN](https://metacpan.org/pod/App::cpm::Tutorial).

Você já vai ter ele instalado se seguiu as instruções do `local::lib`
da [documentação de instalação](https://exercism.org/tracks/perl5/installation).

Basta rodar `cpm install` para instalar os módulos necessários a partir de um `cpanfile`,
e usar `--with-recommends` ou `--with-suggested` para instalar os módulos recomendados
ou sugeridos, respectivamente.

Rode `cpm install Module::Name` para instalar um módulo específico localmente, ou
rode `cpm install -g Module::Name` para instalar globalmente.

### App::cpanminus
O instalador de módulos mais conhecido e mais usado.
As instruções de instalação estão no [CPAN](https://metacpan.org/pod/App::cpanminus).

Rode `cpanm -L local --installdeps .` para instalar os módulos necessários
a partir de um `cpanfile`.
Rode `cpanm -L local Module::Name` para instalar um módulo específico
localmente, ou rode `cpanm Module::Name` para instalar globalmente.

## Estilo de código e linting

Se você procura bons conselhos gerais sobre como escrever código Perl,
o [Perl Best Practices][PBP], de Damian Conway, é uma boa referência.

Para embelezar seu código, você pode usar o módulo
[Perl::Tidy][PerlTidy].

Você pode então usar o utilitário `perltidy` fornecido
para reformatar seu código.

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

O `perltidy` tem *muitas* opções de configuração para todos os gostos. Elas
estão documentadas [aqui][perltidyDocs].

Existe também o [tidyview], uma interface visual que permite
ajustar as diferentes opções e ver o resultado na hora.

Se você quiser impor boas práticas de código, existe também
o [Perl::Critic][perlcritic]. Ele vem com as regras descritas no
livro *Perl Best Practices* mencionado antes, mas existem muitos
plugins, e ele pode ser personalizado para se adequar a qualquer
regra interna de código.

Para usar:

    $ perlcritic some_script.pl

A ferramenta tem muitos e muitos ajustes de configuração, veja a
[documentação][perlcriticdocs] dela para saber tudo sobre eles.
