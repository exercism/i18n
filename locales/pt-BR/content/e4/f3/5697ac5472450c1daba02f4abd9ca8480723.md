# Introdução

Quando você precisa de uma linha de `n` valores em que cada um depende da sua posição, o `<iota>` e o `map` do Factor cooperam para fazer o trabalho sem escrever um contador de laço.

## `<iota>` e `map`

O `<iota>` (em [`sequences`][sequences]) recebe um inteiro não negativo `n` e retorna uma sequência *virtual* dos inteiros `0, 1, …, n-1`. O `map` então percorre essa sequência, aplicando sua quotation a cada elemento:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

A quotation recebe um inteiro (o índice) e deixa o valor dessa posição na pilha.

## Iterar e repetir por contagem

Quando você só precisa dos *efeitos colaterais* de visitar cada índice, e não de uma nova sequência, o `each-integer` (em [`math`][math]) executa uma quotation sobre `0, 1, …, n-1`:

```
each-integer ( n quot: ( i -- ) -- )
```

O `replicate` (em [`sequences`][sequences]) chama uma quotation `n` vezes e coleta os resultados, ignorando o índice, o que é útil para construir `n` valores independentes:

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## Intervalos limitados

Quando o intervalo de índices não começa em `0`, ou você quer que ele seja inclusivo nas duas extremidades, o vocabulário [`ranges`][ranges] fornece literais com notação de colchetes. Colchetes incluem a extremidade; parênteses a excluem.

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

Alguns atalhos comuns de um argumento:

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

O `<iota>` é a forma mais comum; `[a..b]` e similares são a ferramenta certa quando o intervalo começa em outro lugar que não `0` ou precisa de um limite superior inclusivo.

## Limites inferiores abertos e intervalos possivelmente vazios

Colchetes *incluem* uma extremidade; parênteses a *excluem*. O mesmo truque à esquerda dá `(a..b]` e `(a..b)`:

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

`0 n (a..b]` dá `{ 1 … n }` para `n > 0` e `{ }` para `n = 0`, a forma natural ao iterar por "todo inteiro positivo até `n`, inclusive".

## Intervalos decrescentes

Todas as quatro formas com colchetes e parênteses, `[a..b]`, `[a..b)`, `(a..b]` e `(a..b)`, contam *para baixo* quando `a > b`, e não em direção a um resultado vazio:

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## Construir uma string por posição

O `map` produz a forma que sua quotation retornar. Se a quotation deixar um código de caractere na pilha, o `>string` (em [`strings`][strings]) transforma o resultado em uma string:

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

`CHAR: A` é interpretado como o inteiro `65`. A quotation aqui dobra o índice e soma essa base, o que cai em uma letra maiúscula sim, uma não. Qualquer aritmética que você empilhar em cima do índice decide qual caractere acaba nessa posição.

## Escolha por posição

Quando o caractere depende de uma *condição* sobre o índice, faça a escolha dentro da quotation:

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

As três primeiras posições testam `i 3 <` como `t`, então recebem `a`; o restante recebe `b`. A mesma forma, `[ <test> [ <yes> ] [ <no> ] if ]`, cobre testes de paridade com `even?` / `odd?` (em [`math`][math]) e testes do tipo "cada k-ésima posição" com `mod` e `zero?`.
