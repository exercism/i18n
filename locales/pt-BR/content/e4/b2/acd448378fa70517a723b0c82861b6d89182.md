# Introdução

Kotlin é uma linguagem de programação **estaticamente tipada** desenvolvida pela JetBrains. Isso significa que o tipo das variáveis é definido em tempo de compilação.

## Variáveis

Assim como em outras linguagens de programação estaticamente tipadas, o tipo de cada variável deve ser definido em tempo de compilação. Você pode evitar declarações explícitas de tipo quando o compilador consegue inferi-lo a partir do contexto.

Kotlin tem variáveis imutáveis (`val`) e mutáveis (`var`). O valor de uma variável imutável não pode ser alterado depois que seu valor inicial é atribuído. Na maior parte do tempo, você vai usar esse tipo de variável.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

O valor de uma variável mutável pode ser alterado uma ou mais vezes:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Em Kotlin, o ponto e vírgula é opcional, exceto por alguns casos especiais que serão abordados mais adiante.

## Funções

As funções em Kotlin são definidas com a palavra-chave `fun` e são _cidadãos de primeira classe_ (nada a ver com orientação a objetos). Isso significa que você pode declará-las (as chamadas `top-level functions`) diretamente nos arquivos (por exemplo, em Java você só pode definir métodos em classes, não em arquivos):

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

Funções podem receber argumentos. Cada argumento tem um nome e um tipo. Diferente das variáveis, o tipo dos argumentos não pode ser inferido. Funções podem ter zero ou mais argumentos:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Funções em Kotlin podem ou não retornar um valor:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

Para retornar um valor de uma função, usa-se a palavra-chave `return`:

```kotlin
fun getName(): String {
    return "Alice"
}
```

Funções podem ter parâmetros com valores padrão. Esses valores serão usados se forem omitidos no local em que a função é chamada:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## Comentários

Use `//` para definir um comentário de uma linha:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

ou `/*` e `*/` para definir comentários de várias linhas:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
