# Sobre

`case` é a estrutura de seleção múltipla do Factor baseada em igualdade. É a ferramenta
certa quando a escolha depende de um *único* valor ser igual a uma entre várias
alternativas, e não quando cada bloco precisa de um teste diferente (para isso, use
`cond`).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Algumas coisas que vale a pena ter em mente:

- A igualdade é `=`. Qualquer valor que funcione com `=` pode ser uma chave: números,
  strings, caracteres, símbolos, até tuplas.
- Os blocos *correspondentes* veem a pilha *sem* o valor de entrada. Os blocos *padrão*
  o veem ainda no topo.
- Um `case` que não tem um padrão nem uma cláusula correspondente lança um erro.

O `case` compila para uma tabela de saltos quando possível, então não é só açúcar
sintático para uma cadeia de `if`: ele também é rápido.
