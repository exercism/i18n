# Instruções

Neste exercício, você vai escrever código para ajudar uma empresa de letreiros a criar mensagens personalizadas para seus letreiros.

## 1. Monte um letreiro de ocasião

Implemente a função `buildSign(occasion, name)` que recebe uma string como parâmetro `occasion` e uma string com o nome de alguém como parâmetro `name`.
Os dois parâmetros serão embutidos em uma string de template para exibir a mensagem no letreiro.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Monte um letreiro de aniversário

Implemente a função `buildBirthdaySign(age)` que recebe uma idade e, com base nela, determina parte da mensagem no letreiro.
Se a idade for 50 ou mais, o letreiro vai se referir à pessoa como _mature_; caso contrário, vai se referir a ela como _young_.
A saída esperada exata é mostrada abaixo:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Monte um letreiro de formatura

Implemente a função `graduationFor(name, year)` que recebe um nome como parâmetro do tipo string e um ano como parâmetro do tipo número, e usa interpolação de string para criar uma frase para um letreiro que usa uma quebra de linha para separar as duas linhas da mensagem.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Calcule o custo de um letreiro

Implemente a função `costOf(sign, currency)` que recebe uma string com o conteúdo do letreiro e uma string que representa a moeda.
O letreiro tem um preço base de 20 na moeda informada. Além disso, cada letra custa 2. (Os espaços em branco entram no cálculo.)
A frase retornada inclui o custo de criação do letreiro, escrito com dois dígitos após o ponto decimal, seguido da string da moeda.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
