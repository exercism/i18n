# Sobre

Os tipos personalizados são a forma como novos tipos de dados são definidos em Gleam. Eles podem ter várias _variantes_, cada uma com seu próprio nome.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Cada caso de um tipo personalizado pode, opcionalmente, carregar dados, e casos diferentes podem carregar tipos de dados diferentes. Quando uma variante carrega dados, ela é chamada de _record_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Para criar um valor de um caso específico, você pode usar o nome do caso, quando ele não carrega dados adicionais (`Spring`), ou chamá-lo como uma função, quando carrega (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Os tipos personalizados, assim como tudo em Gleam, têm _igualdade estrutural_, o que significa que dois valores da mesma variante e com os mesmos dados são equivalentes.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Você pode fazer pattern matching nas variantes de um tipo personalizado usando expressões case.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
