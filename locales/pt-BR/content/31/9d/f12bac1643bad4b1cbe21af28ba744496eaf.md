# Operadores de comparação

O PHP tem dez operadores de comparação nativos:

| Nome  | Exemplo    | Resultado                                             |
| ----- | ---------- | -------------------------------------------------- |
| Igual | `$a == $b` | true se `$a` for igual a `$b` após a conversão de tipos. |
| Idêntico | `$a === $b` | true se `$a` for igual a `$b` e for do mesmo tipo. |
| Diferente | `$a != $b` | true se `$a` não for igual a `$b` após a conversão de tipos. |
| Diferente | `$a <> $b` | true se `$a` não for igual a `$b` após a conversão de tipos. |
| Não idêntico | `$a !== $b` | true se `$a` não for igual a `$b` ou não for do mesmo tipo. |
| Menor que | `$a < $b` | true se `$a` for estritamente menor que `$b`. |
| Maior que | `$a > $b` | true se `$a` for estritamente maior que `$b`. |
| Menor ou igual a | `$a <= $b` | true se `$a` for menor ou igual a `$b`. |
| Maior ou igual a | `$a >= $b` | true se `$a` for maior ou igual a `$b`. |
| Spaceship | `$a <=> $b` | retorna um inteiro menor que, igual a ou maior que `0`i quando `$a`. |

O PHP tem definições distintas que diferenciam `equal` de `identical`.
Às vezes, `identical` também é chamado de `strictly equal`.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
