# use o placeholder de fmt para string

Em Go, as pessoas costumam preferir placeholders específicos de tipo em vez do genérico `%%v`. 
Há dois motivos para isso. Primeiro, placeholders mais específicos costumam ter opções adicionais, 
por exemplo, o formato `%%f` para valores `float` também pode especificar a precisão: `%%.2f`. 
O segundo motivo é que `%%v` aceita qualquer tipo de valor. Se o tipo de uma variável mudar durante uma refatoração, 
`%%v` vai imprimir o valor padrão daquele tipo, o que pode não ser o comportamento desejado. 
Um placeholder específico de tipo vai fazer o linter reclamar, detectando o erro antes que ele seja publicado em produção.
