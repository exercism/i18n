# Sobre

[Classes](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) são o principal construto para fazer programação orientada a objetos em F#.

Uma classe em F# é composta por seus campos e métodos. Os campos e métodos de uma classe são conhecidos como seus _membros_.

As classes em F# são definidas com a palavra-chave `type`. Os métodos são definidos com a palavra-chave `member` e são sempre públicos. Para definir campos (privados), é possível usar associações `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Classes são modelos para criar objetos. Para criar uma instância de uma classe, invoque o nome da classe como uma função. Uma instância de uma classe também é conhecida como um _objeto_.

É possível acessar os membros de um objeto usando a notação de ponto.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
