# Instruções

Você é um grande entusiasta de trens em miniatura e decidiu compartilhar sua paixão com o mundo criando uma newsletter. Você vai começar enviando a primeira edição da sua newsletter para seus amigos e conhecidos que compartilham o mesmo hobby. Você tem um arquivo de texto com uma lista dos endereços de email deles.

## 1. Ler endereços de email de um arquivo

Implemente a função `Newsletter.read_emails/1`. Ela deve receber um caminho de arquivo. O arquivo é um arquivo de texto que contém endereços de email separados por quebras de linha. A função deve retornar uma lista com os endereços de email do arquivo.

```elixir
Newsletter.read_emails("/home/my_user/documents/model_train_friends_emails.txt")
# => ["rick@example.com", "choochoo42@example.com", "anna@example.com"]
```

## 2. Abrir um arquivo de log para escrita

Enviar um email é uma tarefa que pode falhar por vários motivos imprevisíveis, como um erro de digitação no endereço de email ou problemas temporários de rede. Para garantir que você consiga tentar enviar os emails para todos os seus amigos de novo sem enviar duplicatas, você precisa registrar os endereços de email que já receberam o email. Para isso, você vai precisar de um arquivo de log.

Implemente a função `Newsletter.open_log/1`. Ela deve receber um caminho de arquivo, abrir o arquivo para escrita e retornar o PID do processo que cuida do arquivo.

```elixir
Newsletter.open_log("/home/my_user/documents/newsletter_issue1_log.txt")
# => #PID<0.145.0>
```

## 3. Registrar um email enviado

Implemente a função `Newsletter.log_sent_email/2`. Ela deve receber um PID do processo que cuida do arquivo e uma string com o endereço de email. Ela deve escrever o endereço de email no arquivo, seguido de uma quebra de linha.

```elixir
Newsletter.log_sent_email(pid, "joe@example.com")
# => :ok
```

## 4. Fechar o arquivo de log

Implemente a função `Newsletter.close_log/1`. Ela deve receber um PID do processo que cuida do arquivo e fechar o arquivo.

```elixir
Newsletter.close_log(pid)
# => :ok
```

## 5. Enviar a newsletter

Agora que você já tem todos os blocos de construção do procedimento de envio de email, precisa juntá-los em uma única função.

Implemente a função `Newsletter.send_newsletter/3`. Ela deve receber o caminho do arquivo com os endereços de email, o caminho de um arquivo de log e uma função anônima que envia um email para um determinado endereço de email. Ela deve ler todos os endereços de email do arquivo informado e tentar enviar um email para cada um deles. Se a função anônima que envia o email retornar `:ok`, escreva o endereço de email no arquivo de log, seguido de uma quebra de linha. Certifique-se de fazer isso assim que o email for enviado. Depois de terminar todos os envios, feche o arquivo de log.

```elixir
Newsletter.send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  fn email -> :ok end
)

# => :ok
```
