# Instalação

## Instale o Node.js

**Usuários de Windows e OS X**: instale o [Node.js][node] [pelo gerenciador de pacotes][node-download].

**Usuários de Linux**: instale o [Node.js][node] seguindo as instruções para a sua distribuição no [gerenciador de pacotes do Node.js][linstall].

## Instale o `jasmine-node` e o `coffeescript`

Para a maioria dos usuários, basta rodar o comando a seguir:

```bash
$ npm install -g jasmine-node coffeescript
```

Dependendo da sua configuração, pode ser que você precise de privilégios de superusuário para instalar um módulo `npm` globalmente.
É o caso se você usou o instalador oficial indicado acima.
Se o NPM exibir um erro dizendo que você não tem acesso, adicione `sudo` ao comando acima:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

Se você usou o instalador oficial, seu `PATH` deve ter sido configurado automaticamente. Mas se o seu shell tiver dificuldade para localizar os módulos instalados globalmente, ou se você compilar o Node.js a partir do código-fonte, atualize o seu `PATH` para incluir os binários do `npm` adicionando o seguinte a `~/.bash_profile` ou `~/.zshrc`:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
