# Introdução

## Filtragem de exceções

`when` é a palavra-chave para filtrar exceções. Ela fica depois da instrução `catch` e pode receber uma expressão Boolean que contenha quaisquer valores que estejam no escopo naquele momento. Se a expressão for avaliada como verdadeira, o bloco associado a essa instrução `catch` é executado. Caso contrário, a próxima instrução `catch`, se houver, é verificada.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## Exceções definidas pelo usuário

Uma exceção definida pelo usuário é qualquer classe definida no seu código que derive de `System.Exception`. Ela está sujeita a todas as regras de herança de classes, mas, além disso, o compilador e o runtime da linguagem tratam essas classes de um jeito especial, permitindo que suas instâncias sejam lançadas e capturadas fora do fluxo de controle normal, como discutido no exercício `exceptions`.

Exceções definidas pelo usuário costumam servir para carregar informações extras, como uma mensagem e outros dados relevantes, que ficam disponíveis para as rotinas de captura.
