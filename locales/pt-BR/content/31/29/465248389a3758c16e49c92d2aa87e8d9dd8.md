# evite instruções de impressão

Tente remover instruções como `System.out.println()` do seu código.
Os testes do exercício exigem que a solução _retorne_ valores dos métodos em vez de imprimi-los.

Normalmente, instruções como essas são adicionadas para ajudar a debugar o código.
Porém, uma abordagem melhor é debugar o código enquanto roda um ou mais testes de unidade.
Isso traz a vantagem adicional de você poder focar em debugar um caso de teste específico.

Aqui estão alguns links que explicam como debugar código Java enquanto roda testes de unidade em várias IDEs:

- [Executar e debugar testes Java no Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Debugar testes no IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
