# converter codepoint em string diretamente

A maneira mais fácil de converter o codepoint de um caractere em uma string com esse caractere é usar a forma especial `<<>>`. Não é preciso usar uma charlist como etapa intermediária.

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
