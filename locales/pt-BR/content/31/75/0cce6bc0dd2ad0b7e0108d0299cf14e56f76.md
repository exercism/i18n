# Apêndice de instruções

## Valor de retorno

Retorne um dos seguintes números inteiros:

| Classificação | Retorno |
|----------------|--------|
| não positivo   | 0      |
| deficiente     | 1      |
| perfeito       | 2      |
| abundante      | 3      |

## Endereços reservados

Este exercício não exige memória linear.
