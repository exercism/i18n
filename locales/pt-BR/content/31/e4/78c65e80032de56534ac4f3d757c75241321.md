# Introdução

Em Go, uma aplicação é organizada em pacotes.
Um pacote é uma coleção de arquivos de código-fonte localizados na mesma pasta.
Todos os arquivos de código-fonte de uma pasta devem ter o mesmo nome de pacote no topo do arquivo.
Por convenção, os pacotes recebem o mesmo nome da pasta em que estão localizados.

```go
package greeting
```

Go oferece uma extensa biblioteca padrão de pacotes que você pode usar no seu programa com a palavra-chave `import`.
Os pacotes da biblioteca padrão são importados pelo próprio nome.

```go
package greeting

import "fmt"
```

Um pacote importado é então acessado pelo nome do pacote:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

O Go determina se um item pode ser chamado por código de outros pacotes pela forma como ele é declarado.
Para tornar uma função, um tipo, uma variável, uma constante ou um campo de struct visíveis externamente (o que se chama de _exportada_), o nome precisa começar com uma letra maiúscula.
Isso é análogo a outras linguagens de programação, como Java, que usam modificadores de acesso como `public` e `private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
