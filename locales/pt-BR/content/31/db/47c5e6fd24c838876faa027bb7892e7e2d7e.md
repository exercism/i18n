# Instruções

Elaine está trabalhando em um novo jogo infantil que tem animais e varinhas mágicas.
Chegou a hora de programar funções para rolar um dado, gerar energia de varinha aleatória e embaralhar um slice.

## 1. Role um dado

Implemente uma função `RollADie`.

Esse será o tradicional dado de vinte lados, com números de 1 a 20.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. Gere energia de varinha

Implemente uma função `GenerateWandEnergy`.
A energia da varinha deve ser um número de ponto flutuante aleatório maior ou igual a 0.0 e menor que 12.0.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. Embaralhe um slice

O jogo tem oito animais diferentes:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

Escreva uma função `ShuffleAnimals` que retorna um slice com os oito animais em ordem aleatória.
