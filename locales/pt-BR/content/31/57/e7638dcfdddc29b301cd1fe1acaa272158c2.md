# Dicas

## Geral

- Leia sobre [recursão, pelo criador do Elm][recursion].
- Use casamento de padrões com expressões `case`.
- Tente dividir um problema em um caso base e um caso recursivo. Por exemplo, digamos que você queira contar quantos biscoitos há no pote de biscoitos com uma abordagem recursiva. O caso base é um pote vazio: ele tem zero biscoitos. Se o pote não estiver vazio, o número de biscoitos no pote é igual a um biscoito mais o número de biscoitos no pote depois de remover um biscoito.

## 1. Verifique quantos pássaros visitaram hoje

- Esta tarefa não precisa de recursão.
- É possível acessar o primeiro elemento de uma lista com casamento de padrões usando uma expressão `case`.
- Lembre-se de envolver o resultado em `Just` ao retornar um valor.

## 2. Incremente a contagem de hoje

- Esta tarefa não precisa de recursão.
- É possível acessar o primeiro elemento de uma lista com casamento de padrões usando uma expressão `case`.
- Use o [operador `::`][list-cons] para desconstruir e reconstruir a nova lista.

## 3. Verifique se houve um dia sem pássaros visitantes

- Use recursão para iterar sobre os elementos da lista até encontrar um dia sem pássaros visitantes.
- Os casos base são uma lista vazia ou um dia sem nenhum pássaro.
- Use casamento de padrões para verificar se há `0` na lista.

## 4. Calcule o número total de pássaros visitantes

- Use recursão para iterar sobre cada elemento da lista.
- O caso base é uma lista vazia.
- Use o operador `+` para somar o elemento atual ao total do restante.

## 5. Calcule o número de dias movimentados

- Use recursão para iterar sobre cada elemento da lista.
- O caso base é uma lista vazia.
- Use uma expressão `if` para verificar se o dia atual é movimentado (5 pássaros ou mais).
- Some 1 à contagem de dias movimentados no restante da lista quando encontrar um dia movimentado.
