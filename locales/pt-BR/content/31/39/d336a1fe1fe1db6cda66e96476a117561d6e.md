# Apêndice das instruções

## Implementação

Defina uma única função, SolvePuzzle, que retorna uma solução contendo duas strings, cujos valores são as respostas às perguntas do quebra-cabeça da zebra: "Quem bebe água?" e "Quem tem a zebra?". Cada resposta será uma das nacionalidades dos moradores: Englishman, Spaniard, Ukrainian, Norwegian ou Japanese.

É claro que você poderia simplesmente escrever uma função de uma linha só se desse uma espiada no programa de testes para ver a solução esperada. Mas o objetivo é desenvolver um algoritmo que use os fatos e as restrições fornecidos pelo quebra-cabeça e determine as duas respostas corretas.
