## Argumentos opcionais

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

é equivalente a

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

Na resposta no REPL, dá para ver que a primeira definição define dois métodos de uma vez.
