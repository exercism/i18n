# Introdução

## Strings

Um `string` em C# é um objeto que representa texto imutável como uma sequência de caracteres Unicode (letras, dígitos, pontuação etc.). Aspas duplas são usadas para definir uma instância de `string`:

```csharp
string fruit = "Apple";
```

### Métodos

As strings são manipuladas chamando os [métodos internos][docs-string-methods] da string.
Por exemplo, para remover os espaços em branco de uma string, você pode usar o [método Trim][tutorial-docs.microsoft.com-trim-white-space] assim:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Depois que uma string é criada, seu valor nunca pode mudar.
Qualquer método que pareça modificar uma string na verdade retorna uma nova string.

### Concatenação

Várias strings podem ser concatenadas (somadas). A forma mais simples de fazer isso é usando o operador `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Formatação

Para qualquer formatação de string mais complexa que uma simples concatenação, prefira a interpolação de strings. Para usar interpolação em uma string, coloque o símbolo de cifrão (`$`) antes dela. Depois, você pode usar chaves (`{}`) para acessar qualquer variável dentro da sua string.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
