# Sobre

A principal construção orientada a objetos em C# é a _classe_, que combina dados ([_campos_][fields]) e comportamento ([_métodos_][methods]). Os campos e métodos de uma classe são conhecidos como seus _membros_.

O acesso aos membros pode ser restringido por meio de modificadores de acesso, sendo os dois mais comuns:

- [`public`][public]: o membro pode ser acessado por qualquer código (sem restrições).
- [`private`][private]: o membro só pode ser acessado por código da mesma classe.

É comum especificar um modificador de acesso para todos os membros. Se nenhum modificador de acesso for especificado, o padrão será `private`.

Esse agrupamento de dados e comportamento relacionados, junto com a restrição de acesso aos membros, é conhecido como [encapsulamento][encapsulation], um dos conceitos centrais da orientação a objetos.

A combinação dos valores dos campos de um objeto em um dado momento é conhecida como o [estado][object-state] do objeto.

Você pode pensar em uma classe como um modelo para criar instâncias dessa classe. Para [criar uma instância de uma classe][creating-objects] (também conhecida como _objeto_), usa-se a [palavra-chave `new`][new]:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

[Campos][fields] têm um tipo e podem ser definidos em qualquer lugar de uma classe.
Campos públicos são definidos em [PascalCase][pascal-case] e campos privados são definidos em [camelCase][camel-case] e prefixados com um sublinhado `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

É possível atribuir opcionalmente um valor inicial a um campo. Se um campo _não_ especificar um valor inicial, ele receberá o [valor padrão][default-values] do seu tipo. Os valores dos campos de uma instância podem ser acessados e atualizados usando a notação de ponto.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Campos privados costumam ser atualizados como efeito colateral da chamada de um método. Esses métodos geralmente não retornam valor algum, e nesse caso o tipo de retorno deve ser [`void`][void]:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field
        _carsImported = _carsImported + numberOfCars;
    }
}
```

Observe que não é comum usar campos públicos em classes C#. Usam-se campos privados ou outros tipos de membros, que serão discutidos em exercícios posteriores.

Dentro de uma classe, a [palavra-chave `this`][this] refere-se à classe atual. Isso é especialmente útil quando um parâmetro tem o mesmo nome de um campo:

```csharp
class CarImporter
{
    private int carsImported;

    public void SetImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```

A estrutura de classe e método oferece uma forma natural de limitar a visibilidade de elementos do programa, como campos e métodos, e de evitar o conhecido [problema do estado global][so-global-state-problem]. Campos públicos, métodos e outros membros precisam ser qualificados com o nome do objeto, `object.field` ou `object.method()` (o nome da classe no caso de membros estáticos), para serem vistos por código fora da classe. Variáveis e parâmetros declarados dentro de um método só podem ser vistos dentro desse método.

Um ponto de atenção nessa abordagem: se o nome de um campo e o nome de uma variável ou parâmetro de um método forem iguais, o código dentro do método ignorará o campo, o que pode não ser o que você deseja. Em geral, evite isso quando possível, embora seja um padrão comum em construtores. Se for apropriado que o nome do campo e o da variável sejam iguais, qualifique o nome do campo com a palavra-chave `this` dentro do método.

Esses [modificadores de acesso][access-modifiers] podem ser usados para limitar ainda mais a visibilidade.
