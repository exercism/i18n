# Sobre

- Pony tem tipagem estática. Isso significa que você *precisa* definir os tipos dos dados
  nos seus programas com antecedência. Se você disser ao Pony que a variável `x` é um
  inteiro, não vai poder atribuir uma string a ela.
- É o sistema de tipos do Pony que possibilita as garantias do Pony.
  - Se o seu programa compila, ele não vai quebrar.
  - Nunca vai existir uma exceção não tratada.
  - Não existe `null`, então seu programa nunca vai tentar desreferenciar `null`.
  - Nunca vai haver uma corrida de dados.
  - Nunca vai haver um deadlock.
  - Seu código sempre será seguro quanto a capacidades (proteção contra ataques à cadeia de
    suprimentos.
- Pony não permite que você faça cast de tipos. Toda mudança de tipo precisa acontecer por
  meio de uma função que cria uma nova instância do novo tipo.
- O sistema de tipos do Pony é diferente de praticamente todas as outras linguagens, então
  vamos abordá-lo em partes pequenas.

## Primitivas

- As primitivas são a forma mais simples de organização de código em Pony.
  - Você pode pensar nelas como um contêiner, ou um namespace para funções.
  - Elas não têm campos (para isso temos as classes).
  - Elas são definidas com a palavra-chave `primitive`.

## Funções

- As funções são definidas com a palavra-chave `fun`.
  - As funções precisam ficar dentro de uma `primitive` (ou de uma `class` ou de um
    `actor`), mas elas virão depois).
  - As funções podem ter argumentos de entrada e um valor de retorno. Elas precisam ter
    tipos definidos.
  - Se você definir um tipo de retorno, sua função *precisa* retornar um valor desse
      tipo. Pony não tem o conceito de Null.

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## Comentários

Os comentários podem ser usados para deixar anotações, lembretes ou apenas remover
temporariamente código do código-fonte. Como você já viu acima, comentários de uma linha
usam `//`. Comentários de várias linhas usam `/*` e `*/`, no estilo C.

## Variáveis

- As variáveis sempre começam com uma letra minúscula
  - Vamos declará-las usando `var`. (`let` e `embed` vêm depois).
  - Se o Pony conseguir determinar o tipo da variável, ele fará isso por você.
  - O tipo da variável é verificado em tempo de compilação e nunca pode mudar.
  - Ao começar com Pony, recomendamos ser explícito quanto ao tipo.

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
