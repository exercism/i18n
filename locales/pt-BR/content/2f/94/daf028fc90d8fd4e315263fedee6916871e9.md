# Apêndice de instruções

## Formato do tabuleiro

O tabuleiro é representado como uma string terminada em nulo, com um caractere de nova linha no final de cada linha.

Um exemplo seria `"X  \n XO\nOX \n"`

## Registradores

| Registrador | Uso        | Tipo    | Descrição                                                               |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | entrada        | endereço | string de entrada terminada em nulo                                            |
| `$v0`    | saída       | inteiro | estado do jogo (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | temporário    | qualquer     | para armazenamento temporário                                                   |
