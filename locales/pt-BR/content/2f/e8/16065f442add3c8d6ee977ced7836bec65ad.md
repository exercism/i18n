# Dicas

## Geral

- Leia sobre o [comportamento `Access`][access-behaviour] na documentação.

## 1. Extraia dados de uma estrutura de mapa aninhada

- Primeiro, tokenize o caminho da string para um formato utilizável. Você pode usar as [funções do módulo `String`][string-module].
- Escreva uma função recursiva que percorra a estrutura de mapas aninhados para obter o valor ou retornar `nil`.

## 2. Refatore usando as funções incluídas

- Leia as várias [funções do módulo `Kernel`][kernel-module] para encontrar uma que possa encurtar ou simplificar sua abordagem.
