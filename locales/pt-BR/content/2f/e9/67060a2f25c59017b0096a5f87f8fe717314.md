# Instalação

## Instalando o tclsh

A única ferramenta de que você precisa é o intérprete TCL, o `tclsh`.

No Windows, o melhor lugar para obter o Tcl é o [instalador do Tcl da Magicsplat][magicsplat].

No MacOS e em sistemas operacionais do tipo Unix, o `tclsh` já estará instalado.
Normalmente, a versão instalada será 8.6.*algo*.
Para instalar a versão estável atual, a 9.0:
 - no MacOS, use o [Homebrew][brew].
 - no Linux, verifique o seu gerenciador de pacotes.
 - ou [baixe o código-fonte][download] e [compile-o][build].

Para resolver exercícios pela interface web do Exercism, o test runner (em fevereiro de 2023) usa a versão 8.7a4 do Tcl.

## Usando o shell interativo do tclsh

É comum abrir uma sessão interativa do [`tclsh`][tclsh] para testar comandos enquanto você programa.
No entanto, o tclsh oferece apenas um intérprete REPL muito básico, sem edição de linha de comando nem histórico de comandos.
Para uma experiência melhor, existe um programa chamado `rlwrap` que adiciona a funcionalidade do readline:

```bash
rlwrap tclsh
```

Para instalar o rlwrap:
 - no MacOS, use o [Homebrew][brew].
 - no Linux, verifique o seu gerenciador de pacotes.
 - ou [baixe o código-fonte][rlwrap-download] e [compile-o][rlwrap-build].

É tão prático que você vai querer usá-lo sempre: adicione isto ao seu ~/.bashrc

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## Qual versão usar?

A versão estável atual é a 9.0.
Como indicado acima, a versão 8.6 ainda é amplamente utilizada.

Você pode testar qual versão do `tclsh` está instalada executando o seguinte comando:

```bash
echo 'puts [info patchlevel]' | tclsh
```
