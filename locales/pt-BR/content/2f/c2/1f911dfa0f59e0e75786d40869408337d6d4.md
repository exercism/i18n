# Introdução

O Clojure usa o tipo subjacente `java.lang.Character`, que é uma quantidade de 16 bits para representar os menores componentes endereçáveis do texto.
Vários `char`s podem compor uma string como `"word"`, ou `char`s podem ser
processados de forma independente. Seus literais são escritos assim: `\a \b \c`.

Os `char`s do Clojure oferecem suporte à codificação Unicode UTF-16, então, além do conjunto de caracteres latinos, praticamente todos os sistemas de escrita usados no mundo podem ser representados,
por exemplo, a letra grega `'β'`.

Há muitos métodos de biblioteca para inspecionar e manipular `char`s. Esses
métodos podem ser acessados por interop como os métodos da classe `Character`. O Clojure também inclui uma biblioteca de utilitários de string integrada, `clojure.string`, que oferece muitas funções poderosas para operar sobre caracteres.
