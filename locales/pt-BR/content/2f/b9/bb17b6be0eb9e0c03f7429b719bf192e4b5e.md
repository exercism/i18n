# Test Runners

Um Test Runner é um software que executa os testes de um exercício no código de um estudante.

Os Test Runners nos dão duas vantagens:

1. Eles permitem programar no navegador, onde o estudante pode iterar sobre uma solução e ver se os testes passam ou falham.
2. Eles nos permitem informar aos mentores se o código de um estudante "funciona" ou não.

## Como contribuir com os Test Runners

Cada linguagem tem o seu próprio Test Runner, escrito nessa linguagem.
O site atua como orquestrador entre os Test Runners e as submissões dos estudantes.

Cada Test Runner fica na organização do Exercism no GitHub, em um repositório chamado `<track_slug>-test-runner` (por exemplo, [`exercism/ruby-test-runner`](https://github.com/exercism/ruby-test-runner)).
Você pode ver os Test Runners que já existem [aqui](https://github.com/search?q=topic%3Aexercism-test-runner&type=repositories).

Se você quiser ajudar em um Test Runner que já existe, abra uma issue no repositório dele perguntando onde você pode ajudar.
Se você quiser criar um Test Runner para uma linguagem que ainda não tem um, siga as instruções de [criação de um Test Runner](/docs/building/tooling/test-runners/creating-from-scratch).
