# Introdução

C é uma linguagem de tipagem estática, o que significa que tudo tem um tipo em tempo de compilação.
Escolher um nome para uma variável e definir seu tipo é o que chamamos de declarar uma variável.

Uma variável é declarada especificando explicitamente seu tipo.
O nome de uma variável deve começar com uma letra ou um sublinhado.
Alguns nomes não podem ser usados, pois são reservados [para palavras-chave][reserved-keywords] ou [para outros identificadores][reserved-identifiers].

Definir ou atualizar a variável é feito por meio da atribuição.
Atribuir o valor define a variável.
Definir a variável também é conhecido como inicialização.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

O valor de uma variável pode ser atribuído e atualizado usando o operador de atribuição simples `=`.
Depois de definida, o tipo de uma variável nunca pode mudar.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C é uma linguagem imperativa procedural.
Toda a computação é realizada como parte de uma série de instruções que fazem parte de uma função ou de várias funções.

Cada função pode ter zero ou mais parâmetros.
Ao definir uma função, todos os parâmetros e o valor de retorno precisam ter seu tipo especificado explicitamente.
Os valores são retornados das funções usando a palavra-chave `return`.
Por padrão, as funções têm classe de armazenamento externa, o que significa que ela existe durante todo o tempo de vida do programa e pode ser visível externamente ao arquivo.
Para evitar isso, pode-se adicionar a palavra-chave `static` para especificar visibilidade interna.

```c
static int add(int x, int y) {
  return x + y;
}
```

No exemplo acima, as variáveis `x` e `y` só podem ser usadas dentro da função, ou seja, elas têm escopo de função.
Escopo é a ideia de que o valor associado a um nome (de um elemento do programa) só é acessível dentro da "área" de código onde ele é definido.
As principais áreas de código em C são:

- arquivo
- função
- bloco (como dentro de laços e outras construções)

As funções são invocadas especificando o nome da função e passando argumentos para cada um dos parâmetros da função.

```c
int sum = add(1, 2);
```

C suporta dois tipos de comentários.
Comentários de uma linha são precedidos por `//` (desde o C99) e comentários de várias linhas são inseridos entre `/*` e `*/`.
