# Sobre

Um *conjunto disjunto* (uma estrutura union-find) mantém uma coleção de valores particionada em grupos que não se sobrepõem e responde rapidamente a uma pergunta: esses dois valores estão no mesmo grupo? Ele está no vocabulário [`disjoint-sets`][disjoint-sets].

`<disjoint-set>` cria uma estrutura vazia. Os valores, os *átomos*, são adicionados com `add-atom`, ou em massa com `add-atoms`; cada um começa em um grupo só para si:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` une os grupos que contêm dois átomos. A união é transitiva: depois que `a` é unido a `b` e `b` a `c`, os três compartilham um mesmo grupo.

```
equate ( atom1 atom2 disjoint-set -- )
```

Cada grupo é identificado por um único membro canônico, o seu *representante*. `representative` o retorna, e dois átomos pertencem ao mesmo grupo exatamente quando seus representantes são iguais. `equiv?` faz esse teste diretamente:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

Qual átomo é escolhido como representante de um grupo é um detalhe interno: pode ser qualquer membro do grupo, e pode mudar conforme os grupos se fundem. Nunca dependa de um átomo específico ser o representante; dependa apenas de que dois átomos do mesmo grupo concordem.

`disjoint-set-members` retorna todos os átomos que foram adicionados.

A estrutura é *mutável*: `equate` e `add-atom` alteram o conjunto disjunto no lugar, em vez de retornar um novo. A implementação usa união por rank com compressão de caminho, então uma longa sequência de chamadas de `equate` e `representative` é efetivamente de tempo constante cada uma.
