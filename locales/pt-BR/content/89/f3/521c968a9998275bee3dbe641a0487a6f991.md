# Sobre condicionais

## Operadores de comparação

Os [operadores de comparação][operators] são parecidos com os de muitas outras linguagens, com algumas extensões.

Para igualdade, os operadores são `==` (igual) e `!=` (diferente).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Além disso, os operadores `===` e `!==` testam a ["igualdade referencial"][referential-equality]: `a === b` se e somente se `a` e `b` apontam para o mesmo objeto.
Isso vai fazer mais sentido mais adiante no programa de estudos.

Os operadores de maior e menor que também são convencionais.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Ramificação com `if`

Esta é a forma completa de uma [expressão `if`][if-else]:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Os parênteses `()` em volta de cada condicional são obrigatórios.
- Uma condicional precisa resultar em um Boolean `true` ou `false`.
  Kotlin não tem o conceito de "truthy" e "falsy" que existe em algumas linguagens.
- As chaves `{}` são opcionais, se houver apenas uma única expressão.
- Tanto o `else if` quanto o `else` são opcionais, e pode haver vários blocos `else if`.

A expressão `if` também pode ser usada para "escolher" um valor:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Alternativas?

Por escolha deliberada, Kotlin _não_ tem o operador ternário `? :` que existe em Java.
Prefere-se uma forma concisa de `if ... else`:

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

Diferente do Ruby, a forma concisa `if ... else` *sempre* precisa de um `else` e, por isso, não pode ser usada como instrução de guarda:

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

Repare que, em Kotlin, `if` é uma [_expressão_][expression] que retorna um valor.
Não é uma [_instrução_][statement] como em Java.

Vamos ver mais adiante, em outro conceito, que Kotlin tem uma poderosa [construção `when`][when], destinada a substituir longas cadeias de cláusulas `else if` por pattern matching.
