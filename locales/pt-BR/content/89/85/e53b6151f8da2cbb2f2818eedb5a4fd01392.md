# Introdução

Em JavaScript, um array é uma estrutura parecida com uma lista, sem tamanho fixo, que pode conter qualquer tipo de primitivo ou objeto, até tipos misturados.

Para criar um array, coloque elementos entre colchetes `[]`.
Para ler um valor do array, coloque o índice entre colchetes `[]` depois do identificador.
Os índices de um array começam em zero.

Por exemplo:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Para saber quantos elementos há em um array, use a propriedade `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Para alterar um elemento do array, atribua um valor ao índice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Métodos

Alguns dos [métodos][array_methods] disponíveis em todo objeto Array podem ser usados para adicionar ou remover elementos do array.

### push

> O método `push()` adiciona um ou mais elementos ao final de um array e retorna o novo comprimento do array.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> O método `pop()` remove o último elemento de um array e retorna esse elemento.
> Esse método altera o comprimento do array.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> O método `shift()` remove o primeiro elemento de um array e retorna esse elemento removido.
> Esse método altera o comprimento do array.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> O método unshift() adiciona um ou mais elementos ao início de um array e retorna o novo comprimento do array.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> O método splice() altera o conteúdo de um array removendo ou substituindo elementos existentes e/ou adicionando novos elementos no lugar. Esse método retorna um array contendo os elementos excluídos.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
