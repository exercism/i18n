# Dicas

## Geral

- Lentes não são muito usadas em Roc porque a sintaxe de atualização de registros cobre bem a maioria dos casos de uso.
  Por exemplo, considere este registro aninhado:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  Agora vamos cortar o cabelo do Bob:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  Sem precisar de lentes!

- Dito isso, mesmo que lentes sejam raras em Roc, elas são comuns em outras linguagens como Haskell e Scala, então talvez você queira saber como implementá-las em Roc.
  Também é uma boa forma de praticar alguns recursos avançados de Roc, como tipos parametrizados e registros que contêm funções.
  De fato, veja uma forma de representar uma lente em Roc:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  Este é um tipo parametrizado: `whole` e `part` podem ser quaisquer tipos.
  `whole` costuma ser um registro, enquanto `part` pode ser qualquer tipo de campo.
  O campo `get` contém uma função que retorna uma `part` específica do `whole` fornecido, enquanto o campo `set` contém uma função que retorna uma cópia do `whole` fornecido, mas com uma `part` específica substituída pela `part` fornecida.

  Por exemplo, veja uma lente para obter ou definir o cabelo de uma pessoa:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  Podemos usar esta lente para focar no cabelo do Bob, assim:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  E podemos mudar o cabelo dele assim:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- Observação: os parênteses em volta de `hair_lens.set` são obrigatórios. Sem eles, Roc procuraria uma função chamada `set` no tipo de `hair_lens`.

- As lentes ficam especialmente úteis quando você começa a compô-las, o que permite obter e definir partes profundamente aninhadas.
  Isso pode ser feito implementando uma função como esta:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  Depois de implementar essa função, você pode usá-la para criar uma lente de comprimento de cabelo assim:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  Agora você pode dar outro corte de cabelo ao Bob:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- Talvez você também queira implementar uma função que permita aplicar qualquer transformação a uma parte aninhada:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  Depois de implementada, você pode usar `over` assim:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- Recomendamos que você primeiro passe nos testes usando a sintaxe de atualização de registros de Roc e depois tente usar lentes.
