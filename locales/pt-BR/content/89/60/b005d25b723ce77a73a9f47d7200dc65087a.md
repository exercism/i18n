# Introdução

## Módulos

Até agora, todos os exercícios que você viu usaram classes.
Às vezes não precisamos da sobrecarga de criar um objeto com estado, então em vez disso usamos `module`.

Um módulo é muito parecido com uma classe (na verdade, `Module` é o pai de `Class` na hierarquia de objetos), e a principal diferença é que, em vez de usar métodos de instância, usamos métodos de classe.
Os métodos de classe começam com `self.` e são chamados diretamente em um módulo.

Por exemplo:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## Laços

Há várias formas de escrever laços em Ruby, mas como tendemos a usar enumeração em vez de laços de modo geral, talvez o laço mais comum seja o laço `while`:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

Você também pode usar o `until`, que é o irmão dele.

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
