# Dicas

## 1. Verifique quantos pássaros visitaram hoje

- "Hoje" significa a última entrada do vetor `birds_per_day`.
- A última entrada de `v` pode ser acessada pelo índice `length(v)`.
- A função [`tail(v, n)`][ref-tail] é útil para ler (mas não modificar) o fim de um vetor.
  O argumento `v` é o vetor, `n` é o número de entradas a retornar, com valor padrão 6.

## 2. Incremente a contagem de hoje

- Você pode usar o índice `length(v)` para acessar a entrada de hoje.
- Como alternativa, some o vetor de comprimento 7 apropriado.
- Para construir um vetor com entradas repetidas, a função [`rep()`][ref-rep] pode ser útil.
