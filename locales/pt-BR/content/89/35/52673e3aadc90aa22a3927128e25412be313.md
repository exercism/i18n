# CONFIGURAÇÃO

Esta trilha usa duas ferramentas para rodar a suíte de testes e garantir as melhores práticas:

1. [vader.vim](https://github.com/junegunn/vader.vim)
2. [vint](https://github.com/Kuniwak/vint)

## Rodando os testes

1. Instale o [vader.vim](https://github.com/junegunn/vader.vim/#installation).
1. Abra sua solução:
    ```
    $ vim exercise.vim
    ```
1. Carregue o arquivo atual para deixar suas funções globais disponíveis para o Vim:
    ```
    :source %
    ```
1. Rode os testes:
    ```
    :Vader exercise.vader
    ```

Os caminhos podem variar.

Se você quiser um atalho prático para os passos acima, coloque isto no seu vimrc:

```vim
function! s:exercism_tests()
  if expand('%:e') == 'vim'
    let testfile = printf('%s/%s.vader', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(testfile)
      echoerr 'File does not exist: '. testfile
      return
    endif
    source %
    execute 'Vader' testfile
  else
    let sourcefile = printf('%s/%s.vim', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(sourcefile)
      echoerr 'File does not exist: '. sourcefile
      return
    endif
    execute 'source' sourcefile
    Vader
  endif
endfunction

autocmd BufRead *.{vader,vim}
      \ command! -buffer Test call s:exercism_tests()
```

Depois, abra qualquer arquivo `.vim` ou `.vader` de um diretório de exercício e rode o comando `:Test`.

## Rodando o lint nos arquivos Vim

1. Instale o [vint](https://github.com/Kuniwak/vint#quick-start).
1. Rode o lint em todos os arquivos Vim, recursivamente:
    ```
    $ vint .
    ```

Para informações mais detalhadas sobre a trilha de Vim script, veja a [página de ajuda](https://exercism.org/languages/vimscript).
