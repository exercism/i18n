# Dicas

## 1. Obtenha a primeira letra de uma frase

- Releia a introdução para descobrir como obter uma letra específica de uma string.
- Os índices começam a contar do 0.

## 2. Deixe uma palavra com a inicial maiúscula

- Colocar em maiúscula significa ter um único caractere _maiúsculo_ seguido de caracteres _minúsculos_.
- Então, primeiro você precisa extrair a primeira letra e convertê-la [para maiúscula][mdn-to-upper-case].
- Depois, você precisa determinar o resto da string (tudo além do primeiro caractere).
  O [método slice][mdn-slice] pode ajudar com isso.
- Depois de aplicar a conversão [para minúscula][mdn-to-lower-case], você pode combinar a primeira letra com o resto usando o operador de adição `+`.

## 3. Obtenha a última letra de uma frase

- Releia a introdução para descobrir como obter uma letra específica de uma string.
- O índice da última letra pode ser obtido a partir da propriedade `.length` da string e do fato de que os índices começam a contar do 0.
- As strings vêm com um método [trim][mdn-trim] que remove espaços em branco no início e no fim.

## 4. Seja gentil

- Reutilize uma função existente para deixar a palavra com a inicial maiúscula.
- O operador de adição `+` pode ser usado para concatenar duas strings.
