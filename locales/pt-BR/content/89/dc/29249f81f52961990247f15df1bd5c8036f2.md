# Strings

Strings são uma série de caracteres, entre aspas.
Tanto aspas simples quanto aspas duplas são suportadas.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Expansão de variáveis em strings

Em strings com aspas duplas, se uma variável for referenciada enquanto estiver no escopo, o valor dela é inserido na string.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Suporte à codificação de caracteres

Historicamente, as funções de string do PHP só suportavam caracteres ASCII e não suportavam as codificações Unicode modernas.
Cada caractere ASCII ocupa 1 byte, enquanto caracteres Unicode podem ter de 1 a 4 bytes.
Se você precisar manipular strings Unicode com segurança, consulte as [versões multibyte][multi-byte-fns] das funções históricas.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
