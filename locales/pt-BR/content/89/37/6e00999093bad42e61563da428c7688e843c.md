# Sobre

[Closures][closures] em Swift são blocos de código autocontidos que podem receber parâmetros para acionar seu cálculo e retornar valores
Closures também capturam valores de seu ambiente e os usam em seus cálculos.
Como são autocontidos, podem ser passados de um lado para o outro em um programa como outros valores ou atribuídos a constantes e variáveis.

Closures podem soar muito parecidos com funções em Swift; e de fato são, por um bom motivo.
Funções em Swift são casos especiais de closures que precisam ter um nome e são definidas com uma sintaxe um pouco diferente.

Embora funções em Swift sejam tecnicamente closures, quando as pessoas falam de "closures" em Swift, estão falando de [expressões de closure][closure-expressions].
Expressões de closure são escritas como uma lista de parâmetros seguida de um tipo de retorno e da palavra-chave `in`, seguida do corpo do closure, tudo dentro de um par de chaves:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Isso define uma expressão de closure do tipo `(Double, Double) -> Double`, e ela pode ser executada de maneira semelhante a uma função desse tipo, aplicando-a a parâmetros do tipo adequado:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Como não é muito conveniente escrever a expressão de closure completa toda vez que se quer executá-la, closures podem ser atribuídos a nomes, como qualquer outro valor em Swift.
Eles podem então ser chamados aplicando o nome aos parâmetros:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Como visto acima, closures, assim como funções comuns, podem omitir a palavra-chave `return` se o corpo do closure for uma única expressão.

Na maioria das vezes, closures são usados com funções de ordem superior, seja passados como parâmetros ou retornados como resultados:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
