# Instruções

O país de Hyperia tem seus problemas. Em particular, a inflação está fora de controle. Trouxeram você de avião para assumir um contrato no banco central.

## 1. Imprimir as denominações das cédulas

Para simplificar a administração interna, o banco central dividiu cada denominação em partes: uma _base_, que permanece relativamente inalterada, e um _multiplicador_ (o mesmo para todas as denominações), que pode ser alterado anualmente, semanalmente ou até diariamente.

Quando impressas, as denominações nas cédulas são o produto da _base_ pelo _multiplicador_.

Na época em que esse sistema foi introduzido, a cédula mínima já tinha uma denominação de 10.000.000. A tabela abaixo mostra a situação (para as 3 primeiras denominações) quando o sistema foi introduzido. As coisas pioraram muito desde então: não só o multiplicador muda, mas a base também.

| Base    | Multiplicador | Denominação |
| ------- | ------------- | ----------- |
| 10.000  | 1.000         | 10.000.000  |
| 50.000  | 1.000         | 50.000.000  |
| 100.000 | 1.000         | 100.000.000 |
| ...     | 1.000         | ...         |

Em resumo, isso significa que _denominação_ = _base_ \* _multiplicador_.

Implemente o método `CentralBank.DisplayDenomination()` que recebe a base e o multiplicador e retorna uma string com o produto deles (base \* multiplicador). A string numérica retornada não deve ser formatada.

Se a operação de multiplicação causar um overflow, então a string `"*** Too Big ***"` deve ser retornada.

```csharp
CentralBank.DisplayDenomination(10000L, 1000L);
// => "10000000"
CentralBank.DisplayDenomination(long.MaxValue / 2, 10000L);
// => "*** Too Big ***"
```

## 2. Exibir o PIB de Hyperia

O banco central usa a mesma abordagem de multiplicador para registrar o PIB internamente. As estatísticas são registradas em uma denominação base e depois ampliadas usando o multiplicador.

Implemente o método `CentralBank.DisplayGDP()` que recebe o PIB base e o multiplicador atual e retorna o PIB como uma string.

Se o PIB não puder ser calculado, `"*** Too Big ***"` será retornado.

```csharp
CentralBank.DisplayGDP(555f, 10000f);
// => "5550000"
CentralBank.DisplayGDP(float.MaxValue / 2, 10000f);
// => "*** Too Big ***"
```

## 3. Exibir o salário do economista-chefe

Seu chefe no banco quer garantir que não haverá problemas na hora da folha de pagamento.

Implemente o método `CentralBank.DisplayChiefEconomistSalary()` que recebe um salário expresso em unidades base (como acima) e um multiplicador e retorna uma string contendo o produto.

Se o salário não puder ser calculado, `"*** Much Too Big ***"` será retornado.

```csharp
CentralBank.DisplayChiefEconomistSalary(555000m, 10000m);
// => "5550000000"
CentralBank.DisplayChiefEconomistSalary(555000m, decimal.MaxValue / 2L);
// => "*** Much Too Big ***"
```
