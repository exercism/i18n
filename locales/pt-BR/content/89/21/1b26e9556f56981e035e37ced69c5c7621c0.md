# Crachás de nome

## História

Neste exercício você vai escrever código para imprimir crachás de nome para funcionários de uma fábrica. Cada funcionário tem um ID, um nome e o nome do departamento. Os rótulos dos crachás dos funcionários seguem este formato: `"[id] - [name] - [DEPARTMENT]"`.

Por causa de uma peculiaridade no sistema do computador, às vezes os funcionários novos ainda não têm um ID quando começam a trabalhar na fábrica. Como o crachá é obrigatório, eles vão receber um crachá temporário, sem o prefixo do ID.

Até o dono da fábrica precisa usar um crachá o tempo todo. Porém, o dono não tem um departamento. Nesse caso, o rótulo deve imprimir `"OWNER"` no lugar do nome do departamento.

## Tarefas

Estas são tarefas de exemplo que se encaixam no exercício de crachás de funcionário:

- Imprimir um crachá para um funcionário
- Imprimir um crachá para um funcionário novo
- Imprimir um crachá para o dono
