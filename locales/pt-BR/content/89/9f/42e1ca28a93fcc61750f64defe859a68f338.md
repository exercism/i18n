# Dicas

## 1. Converter localizações

- Os elementos de uma tupla podem ser acessados com pattern matching ou indexação.

## 2. Comparar as localizações do tesouro e do lugar

- Duas tuplas podem ser comparadas para verificar se são iguais, desde que tenham o mesmo comprimento e os mesmos tipos na mesma ordem.

## 3. Contar as localizações do tesouro

- A função `filter` do módulo `gleam/list` pode ser usada para remover elementos de uma lista com base em uma função que retorna um bool.
