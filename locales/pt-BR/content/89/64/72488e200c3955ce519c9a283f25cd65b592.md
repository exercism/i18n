# Dicas

## Geral

- O [Tutorial de números do Python][python-numbers-tutorial] e os [tipos numéricos do Python][python-numeric-types] podem ser uma ótima introdução.

## 1. Estimar o valor após a troca

- Você pode usar o [operador de divisão][division-operator] para obter o valor da moeda trocada.

## 2. Calcular quanto resta após uma troca

- Você pode usar o [operador de subtração][subtraction-operator] para obter o valor do troco.

## 3. Calcular o valor das cédulas

- Você pode usar o [operador de multiplicação][multiplication-operator] para obter o valor das cédulas.

## 4. Calcular o número de cédulas

- Você precisa dividir `amount` por `denomination`.
- Você precisa usar conversão de tipo para `int` para obter o número exato de cédulas.
- Para remover as casas decimais de um `float`, você pode convertê-lo para `int`.

  **Observação:** O operador `//` também faz divisão inteira. Mas, se o operando tiver `float`, o resultado ainda é `float`.

## 5. Calcular o que sobra após trocar em cédulas

- Você precisa encontrar o resto de `amount` que não corresponde a uma `denomination` inteira.
- O operador de módulo `%` pode ajudar a encontrar o resto.

## 6. Calcular o valor após a troca

- Você precisa calcular `spread` por cento de `exchange_rate` usando o operador de multiplicação e somar isso a `exchange_rate` para obter a moeda trocada.
- A taxa real precisa ser calculada. Lembre-se de somar a _taxa_ de câmbio e a _tarifa_ de câmbio.
- Você pode obter o dinheiro trocado afetado pela comissão usando a operação de divisão e a conversão de tipo para `int`.
