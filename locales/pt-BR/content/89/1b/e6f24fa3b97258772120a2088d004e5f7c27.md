# Testes

Como OCaml é uma linguagem compilada, você precisa compilar sua solução e o código de teste antes de poder rodar os testes. 
Usamos o [`dune`](https://dune.build/) para compilar.
Cada pasta tem um arquivo dune que especifica como compilar e também um Makefile que delega para o dune.

Para compilar e rodar os testes, basta digitar, na pasta do exercício:

```bash
make
```

## Criando seu primeiro módulo OCaml

Para criar um módulo que possa ser usado com o teste do exercício `bob`, coloque o seguinte em um arquivo chamado `bob.ml`:

```ocaml
open Base 

let response_for input = failwith "TODO"
```
