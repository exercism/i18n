# Instruções

Como futura mágica, Elyse precisa praticar alguns fundamentos.
Ela tem uma pilha de cartas que quer manipular.

Para facilitar um pouco as coisas, ela usa apenas as cartas de 1 a 10, então a pilha de cartas pode ser representada por um vetor de números.
A posição de uma determinada carta corresponde ao índice no vetor.

## 1. Retire uma carta da pilha

Para pegar uma carta, retorne a carta no índice `position` da pilha fornecida.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. Troque uma carta na pilha

Faça um truque de mágica e troque a carta no índice `position` pela carta de substituição fornecida.
Retorne a pilha ajustada.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. Insira uma carta no topo da pilha

Faça uma carta aparecer inserindo uma nova carta no topo da pilha.
Retorne a pilha ajustada.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. Remova uma carta da pilha

Faça uma carta desaparecer removendo da pilha a carta na `position` fornecida.
Retorne a pilha ajustada.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. Remova a carta do topo da pilha

Faça uma carta desaparecer removendo a carta do topo da pilha.
Retorne a pilha ajustada.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. Insira uma carta na base da pilha

Faça uma carta aparecer inserindo uma nova carta na base da pilha.
Retorne a pilha ajustada.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. Remova uma carta da base da pilha

Faça uma carta desaparecer removendo a carta da base da pilha.
Retorne a pilha ajustada.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. Verifique o tamanho da pilha

Verifique se o tamanho da pilha é igual a `stack_size` ou não.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
