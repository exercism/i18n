# Instruções

Neste exercício, você vai implementar a lógica de missão de um novo jogo de RPG que um amigo seu está desenvolvendo.

A personagem principal do jogo é Annalyn, uma garota corajosa com um cão de estimação feroz e leal. Infelizmente, o desastre acontece: sua melhor amiga foi sequestrada enquanto procurava frutas silvestres na floresta.

Annalyn vai tentar encontrar e libertar sua melhor amiga, levando o cão com ela nessa missão se quiser.

Depois de passar um tempo seguindo o rastro de sua melhor amiga, ela encontra o acampamento onde sua melhor amiga está presa. Acontece que há dois sequestradores: um cavaleiro poderoso e um arqueiro astuto.

Depois de encontrar os sequestradores, Annalyn considera quais das ações a seguir ela pode realizar:

- _Ataque rápido_: um ataque rápido pode ser feito se o cavaleiro estiver dormindo, pois ele leva tempo para vestir a armadura e, por isso, fica vulnerável.
- _Espionar_: o grupo pode ser espionado se pelo menos um deles estiver acordado. Caso contrário, espionar é perda de tempo.
- _Sinalizar para o prisioneiro_: é possível sinalizar para o prisioneiro usando sons de pássaros se o prisioneiro estiver acordado e o arqueiro estiver dormindo, pois arqueiros são treinados em sinais de pássaros e poderiam interceptar a mensagem.
- _Libertar o prisioneiro_: Annalyn pode tentar entrar furtivamente no acampamento para libertar o prisioneiro.
  Isso é arriscado e só pode dar certo de uma de duas maneiras:
  - Se Annalyn estiver com seu cão de estimação, ela pode resgatar o prisioneiro se o arqueiro estiver dormindo.
    O cavaleiro tem medo do cão e o arqueiro não terá tempo de se preparar antes que Annalyn e o prisioneiro escapem.
  - Se Annalyn não estiver com o cão, ela e o prisioneiro precisam ser bem sorrateiros!
    Annalyn pode libertar o prisioneiro se o prisioneiro estiver acordado e o cavaleiro e o arqueiro estiverem dormindo. Mas, se o prisioneiro estiver dormindo, ele não pode ser resgatado: levaria um susto com a aparição repentina de Annalyn e acordaria o cavaleiro e o arqueiro.

Você tem quatro tarefas: implementar a lógica para determinar se as ações acima estão disponíveis, com base no estado dos três personagens encontrados na floresta e na presença ou não do cão de Annalyn.

## 1. Verifique se é possível fazer um ataque rápido

Implemente o método `can_fast_attack()`, que recebe um valor booleano indicando se o cavaleiro está acordado. Esse método retorna `TRUE` se for possível fazer um ataque rápido, com base no estado do cavaleiro. Caso contrário, retorna `FALSE`:

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. Verifique se o grupo pode ser espionado

Implemente o método `can_spy()`, que recebe três valores booleanos indicando se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados. O método retorna `TRUE` se o grupo puder ser espionado, com base no estado dos três personagens. Caso contrário, retorna `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. Verifique se é possível sinalizar para o prisioneiro

Implemente o método `can_signal_prisoner()`, que recebe dois valores booleanos indicando se o arqueiro e o prisioneiro, respectivamente, estão acordados. O método retorna `TRUE` se for possível sinalizar para o prisioneiro, com base no estado dos dois personagens. Caso contrário, retorna `FALSE`:

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. Verifique se o prisioneiro pode ser libertado

Implemente o método `can_free_prisoner()`, que recebe quatro valores booleanos. Os três primeiros parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respectivamente, estão acordados. O último parâmetro indica se o cão de Annalyn está presente. O método retorna `TRUE` se o prisioneiro puder ser libertado, com base no estado dos três personagens e na presença do cão de Annalyn. Caso contrário, retorna `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
