# Arrays

Em Cairo, um array é uma estrutura de dados que permite armazenar uma coleção de elementos do mesmo tipo.
Arrays em Cairo têm opções limitadas de modificação.
Você só pode adicionar itens ao final de um array e remover itens do início.
Na verdade, arrays são filas cujos valores não podem ser modificados.

## Construção de arrays

Arrays são construídos principalmente com o trait `ArrayTrait`, de qualquer uma destas 4 formas de construir um array de elementos `[1, 2]`:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> Cada chamada de `append()` coloca um novo número no final do array.

## Remoção de elementos de um array

A única forma de remover elementos de um array em Cairo é pelo início.
Essa operação é feita pelo método `pop_front()`, que retorna um `Option` que pode ser desempacotado, contendo o elemento removido, ou `Option::None` se o array estiver vazio.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## Acesso a valores em um array

Para acessar elementos de um array, você pode usar os métodos `get()` ou `at()`, que retornam tipos diferentes.
Um equivalente a `arr.at(index)` é o operador de indexação `arr[index]`.

### Usando o método get()

O método `get()` é como procurar um item em uma lista pelo seu número.
Veja como funciona:

- `arr.get(index)` permite buscar um item em uma posição específica (o índice) no array.
- Ele retorna `Option::Some(value)` se o item no índice informado existir, ou `Option::None` se o índice estiver fora dos limites.

Esse método é ideal quando você quer tratar casos em que o índice pode ser inválido sem fazer seu programa quebrar.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### Usando o método at()

O método `at()` dá a você diretamente um instantâneo do elemento em um índice específico, usando a operação `unbox()` para extrair o valor armazenado de dentro da caixa.
Uma forma abreviada desse método é usar o operador de indexação `arr[index]`.
Se você tentar acessar um índice que não existe (fora dos limites), o programa entra em panic com um erro.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## Métodos relacionados ao tamanho

Para saber quantos elementos há em um array, use o método `len()`.
O valor de retorno é do tipo `usize`.

Se você quiser verificar se um array está vazio, pode usar o método `is_empty()`, que retorna `true` se o array estiver vazio e `false` caso contrário.

## `Span`

`Span` é uma struct que representa um instantâneo de um `Array`.
Ele foi projetado para oferecer acesso seguro e controlado aos elementos de um array sem modificar o array original.
`Span` é especialmente útil para garantir a integridade dos dados e evitar problemas de empréstimo ao passar arrays entre funções ou ao realizar operações somente leitura.

> Todos os métodos fornecidos por `Array` também podem ser usados com `Span`, exceto o método `append()`.

Para criar um `Span` de um `Array`, chame o método `span()`:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## O tipo `Array` de tamanho fixo

Escrevemos os valores de um array de tamanho fixo como uma lista separada por vírgulas dentro de colchetes.
O tipo do array é escrito usando colchetes com o tipo de cada elemento, um ponto e vírgula e, em seguida, o número de elementos do array.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> Observação: apenas arrays de tamanho fixo podem ser usados como constantes

Os elementos de um array de tamanho fixo podem ser acessados desestruturando o array ou convertendo-o em um `Span`, que dá suporte à indexação.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
