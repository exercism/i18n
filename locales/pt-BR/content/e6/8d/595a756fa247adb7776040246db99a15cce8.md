# Máquina de senhas

## História

Você está escrevendo um sistema embarcado para uma máquina de senhas. É um modelo bem simples. Ela consegue distribuir números consecutivos e informar qual foi o último número distribuído.

## Tarefas

- Inicie a máquina.
- Faça a máquina informar seu estado (o último número distribuído).
- Faça a máquina distribuir um número.
- Faça a máquina parar quando solicitado.
- Garanta que a máquina consiga lidar com mensagens inesperadas.
