# Instalação

## Início rápido

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

Por padrão, isso instala em `/usr/local/bin`. Para mudar isso, informe o nome do diretório:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Os binários para Linux e macOS são fornecidos via brew.

Instalar:

    brew install borkdude/brew/babashka

Atualizar:

    brew upgrade babashka

## Arch (Linux)

O `babashka` está [disponível](https://aur.archlinux.org/packages/babashka-bin/) no [Arch User Repository](https://aur.archlinux.org). É possível instalá-lo usando qualquer helper de [AUR](https://aur.archlinux.org) que você preferir, como
[yay](https://github.com/Jguer/yay), [yaourt](https://github.com/archlinuxfr/yaourt), [apacman](https://github.com/oshazard/apacman) e [pacaur](https://github.com/rmarquis/pacaur). Veja um exemplo usando `yay`:

    yay -S babashka-bin

## Windows

No Windows, você pode instalar usando o [scoop](https://scoop.sh/) e o bucket
[scoop-clojure](https://github.com/littleli/scoop-clojure).

## Download

Você também pode baixar um binário do
[Github](https://github.com/borkdude/babashka/releases). Para Linux, há um
binário estático disponível que pode ser usado no Alpine.

## Docker

Confira a imagem no [Docker hub](https://hub.docker.com/r/borkdude/babashka/).
