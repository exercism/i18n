# Sobre

CoffeeScript é uma linguagem que transcompila para JavaScript, usada para criar sites dinâmicos (tanto no navegador quanto no servidor).
O transcompilador transforma código CoffeeScript em JavaScript antes da execução, para manter a compatibilidade e o mesmo desempenho do JavaScript, ao mesmo tempo que oferece muitos recursos novos!

CoffeeScript foi criada para oferecer uma forma simplificada de escrever JavaScript, com base numa mistura das linguagens Ruby e Python.
Uma das diferenças é o uso de indentação e setas no lugar do código verboso de funções do JavaScript, além de trazer recursos úteis das linguagens funcionais, incluindo correspondência de padrões.

CoffeeScript é uma entre muitas linguagens novas que transcompilam para JavaScript, incluindo TypeScript e Flow: a comunidade está crescendo e esse tipo de linguagem é muito popular.
