# Introdução

Listas em C# são coleções de valores primitivos ou instâncias de structs ou classes. Elas são implementadas na biblioteca de classes base como `List<T>`, em que `T` é o tipo do item da lista. A API expõe um rico conjunto de métodos para criar e manipular listas.

Itens podem ser adicionados e removidos das listas. Elas crescem e diminuem conforme necessário.

```csharp
var listOfStrings = new List<string>();
```
