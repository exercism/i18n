# Introdução

Quando uma quotation precisa *lembrar* valores do seu entorno, o Factor oferece duas ferramentas: `curry`/`compose` de [`kernel`][kernel], e a sintaxe fry `'[ … ]` de [`fry`][fry].

`curry` fixa um valor na frente de uma quotation:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` cola duas quotations:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Para mais de uma ou duas capturas, o fry fica mais limpo. Cada placeholder `_` é preenchido, na ordem, com um valor retirado da pilha:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

O fry também alcança quotations aninhadas.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
