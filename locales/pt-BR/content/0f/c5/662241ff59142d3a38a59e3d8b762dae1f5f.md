# Dicas

## Geral

- [Propriedades][docs.microsoft.com-properties]
- [Usando propriedades][docs.microsoft.com-using-properties]

## 1. Permita que a balança tenha uma precisão

- Você precisa adicionar uma [propriedade somente com get][stackoverflow.com-get-only-properties] para guardar a precisão.
- Você pode inicializar a propriedade somente com `get` a partir do construtor (e apenas a partir do construtor).

## 2. Permita que o peso seja definido na balança

- Você deve adicionar uma propriedade com um [campo de apoio][docs.microsoft.com-properties-with-backing-fields] privado.

## 3. Garanta que um peso de entrada negativo seja rejeitado

- A palavra-chave `value` é usada para se referir ao valor que quem chama quer que a propriedade tenha.
- Adicione [validação][stackoverflow.com-validating-properties] ao acessador `set` da `Weight` para lançar uma exceção quando o valor for inválido.

## 4. Permita que um ajuste de tara seja aplicado à balança

- Você deve adicionar uma [propriedade autoimplementada][docs.microsoft.com-auto-implemented-properties] para o ajuste de tara.

## 5. Garanta que a balança tenha um ajuste de tara padrão

- Você pode inicializar uma [propriedade autoimplementada][docs.microsoft.com-auto-implemented-properties] como pode inicializar um campo.

## 6. Permita que o peso seja obtido

- Você deve adicionar uma propriedade somente com `get` na qual o peso de exibição correto é calculado.

## 7. Exiba corretamente a string do peso de exibição

- Você deve [formatar a string][stackoverflow.com-format-string] de forma adequada.
