# Introdução

Em Java existem dois tipos diferentes de números:

- Inteiros: números sem dígitos depois do separador decimal (números inteiros).
  Exemplos: `-6`, `0`, `1`, `25`, `976` e `-500000`.
- Números de ponto flutuante: números com zero ou mais dígitos depois do separador decimal.
  Exemplos: `-20.4`, `0.1`, `2.72`, `16.984025` e `1024.0`.

Os dois tipos numéricos mais comuns em Java são `int` e `double`.
Um `int` é um inteiro de 32 bits e um `double` é um número de ponto flutuante de 64 bits.

As operações aritméticas usam os operadores aritméticos padrão.
Números podem ser comparados com os operadores de comparação numérica padrão (por exemplo, `5 > 4` e `4 <= 5`) e com os operadores de igualdade (`==`) e de desigualdade (`!=`).

Java tem dois tipos de conversão numérica:

1. Conversões implícitas: nenhum dado é perdido e nenhuma sintaxe adicional é necessária.
2. Conversões explícitas: dados podem ser perdidos e é necessária uma sintaxe adicional na forma de um _cast_.

Como um `int` tem menos precisão que um `double`, converter de `int` para `double` é seguro e, por isso, é uma conversão implícita.
Já converter de `double` para `int` pode significar perder dados, então isso exige uma conversão explícita.
