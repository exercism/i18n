# Anexo às instruções

## Formato de entrada

O parâmetro `board`, que representa o tabuleiro, está no formato de um array de strings.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

Cada caractere de uma string representa uma casa.
Os valores válidos para uma casa são:

- ` ` um espaço em branco correspondente a uma casa vazia
- `B` uma casa pertencente ao jogador das pretas
- `W` uma casa pertencente ao jogador das brancas

## Formatos de saída

Espera-se que a função `getTerritory` retorne um objeto com 2 propriedades:

- `owner` O dono do território (`NONE`, `BLACK` ou `WHITE`)
- `territory` Um array de coordenadas que representa cada casa do território.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

Espera-se que a função `getTerritories` retorne um objeto com 3 propriedades:

- `territoryBlack` Um array de coordenadas que representa os territórios do jogador `BLACK`
- `territoryWhite` Um array de coordenadas que representa os territórios do jogador `WHITE`
- `territoryNone` Um array de coordenadas que representa os territórios que não pertencem a nenhum dos dois jogadores

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
