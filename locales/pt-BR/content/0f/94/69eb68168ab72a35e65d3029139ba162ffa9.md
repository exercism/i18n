# Introdução

Uma função é um bloco de código organizado e reutilizável usado para executar alguma ação.
Existem várias maneiras de definir funções em JavaScript.
Aqui vamos ver _declarações de função_ e _expressões de função_.
Outras possibilidades, como [arrow functions][concept-arrow-functions], serão abordadas em outros conceitos.

## Declaração de função

A forma padrão de definir uma função em JavaScript é a _declaração de função_, também chamada de _definição de função_ ou _instrução de função_.

Ela consiste na palavra-chave `function`, no nome da função e em uma lista de parâmetros separados por vírgulas, entre parênteses redondos (`()`).
Em seguida vem o corpo da função (conjunto de instruções que define o que a função faz), envolvido por chaves (`{}`).

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

Em JavaScript, uma função é invocada (chamada) ao escrever o nome da função seguido de parênteses que contêm os argumentos.

```javascript
someName(arg1, arg2, arg3);
```

## Parâmetros

Ao trabalhar com parâmetros dentro do corpo da função, fique atento a possíveis efeitos colaterais.

- Valores de [tipos de dados primitivos][mdn-primitives] são _imutáveis_.
  O valor original nunca é afetado pelo que acontece com o argumento no corpo da função.
- Para todos os outros valores (objetos, arrays, funções), uma reatribuição não afeta o valor original.
  Porém, se você modificar um argumento desses (por exemplo, adicionar uma chave a um objeto), isso também modifica o valor original que foi passado.

Por padrão, todos os parâmetros definidos na declaração da função são opcionais em JavaScript.
Se você passar menos argumentos do que o número de parâmetros, os argumentos que faltarem serão `undefined` dentro da função; veja [Null e Undefined][concept-null-undefined].
Em muitos casos, faz sentido atribuir um valor padrão mais adequado que `undefined`.
Isso pode ser feito especificando parâmetros padrão diretamente na definição da função.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## Instrução `return`

Uma instrução `return` encerra a execução da função e especifica um valor a ser retornado para quem chamou a função. Uma função pode ter várias instruções `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

O valor de retorno de uma função pode ser armazenado em uma variável.

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

O resultado de uma função que não retorna nenhum valor ou que não tem uma instrução `return` é `undefined`.
Não existem `return` implícitos em JavaScript.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

Em JavaScript, você só pode retornar exatamente um valor.
Se você quiser passar mais informações, precisa primeiro combiná-las em uma única entidade, geralmente um [objeto][concept-objects] ou um [array][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Expressão de função

Uma declaração de função é uma instrução independente.
Mas às vezes é útil definir uma função como parte de outra expressão, por exemplo, em uma atribuição, como parâmetro de uma função ([callback][concept-callbacks]) ou como valor em um [objeto][concept-objects].
Isso pode ser feito com uma expressão de função.
Ela tem a mesma sintaxe de uma declaração de função, só que o nome da função pode ser omitido para criar uma _função anônima_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
