# Dicas

## 1. Imprimir um crachá para um funcionário

- Você pode usar a [interpolação de string][string-interpolation] para criar strings de descrição.
- Existe um [método nativo para converter uma string em maiúsculas][to-upper-case].

## 2. Imprimir um crachá para um novo funcionário

- Verifique se o ID é `null` antes de usá-lo.
- Você pode usar os [operadores de igualdade][equality-operators] para comparar o valor com `null`

## 3. Imprimir um crachá para o proprietário

- Verifique se o departamento é `null` antes de usá-lo.
- Você pode usar os [operadores de igualdade][equality-operators] para comparar o valor com `null`
