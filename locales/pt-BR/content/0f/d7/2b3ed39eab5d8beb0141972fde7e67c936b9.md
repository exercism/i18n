A concatenação de strings com o operador `+` é uma abordagem válida, mas pode criar problemas de manutenção e legibilidade.
Usar o método [str.format()][str.format()] ou [f-strings][f-strings] (_também conhecidas como "literais de string formatados" ou "strings interpoladas"_) pode oferecer opções que facilitam a manutenção e deixam mais clara a substituição de variáveis dentro de strings.

O post de blog [Formatação de strings em Python][string formatting in python] é um bom ponto de partida para entender todas as opções de formatação de strings do Python, e [Técnicas mais recentes de formatação de strings em Python][newer python string format techniques] também traz boas dicas e truques para usar `str.format()` e `f-strings`.
