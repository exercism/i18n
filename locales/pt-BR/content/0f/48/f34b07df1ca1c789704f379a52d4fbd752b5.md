# Instalação

## Qual awk eu tenho?

A trilha de AWK do Exercism usa o `gawk`, o AWK do GNU.
Talvez você já o tenha; para verificar, execute este comando
```sh
awk --version
```

Se o resultado for:

* algo como `GNU Awk 5.1.0 ...`
    - Você já tem o GNU awk e pode seguir com os exercícios.

* algo como `awk version 20200816`
    - Este é o `nawk`, também conhecido como BWK awk (em homenagem a Brian Kernighan) ou "one true awk".
    - É o que vem com o MacOS e os sistemas BSD.
    - Leia abaixo as instruções de instalação.

* o erro `awk: not an option: --version`
    - Provavelmente você tem o `mawk`.
    - Confirme com: `awk -W version`, que pode retornar `mawk 1.3.4 20200120`.
    - O mawk é uma implementação de awk muito boa e rápida, mas não tem alguns dos recursos específicos do gawk que vamos usar na trilha.
    - Leia abaixo as instruções de instalação.

* o erro `awk: unrecognized option: version` seguido de `BusyBox v1.35.0 ...`
    - Talvez você esteja usando o Alpine Linux.
    - Leia abaixo as instruções de instalação.

* um erro de "command not found"
    - Então ou o seu PATH está bagunçado, ou você simplesmente não tem o awk instalado.
    - Leia abaixo as instruções de instalação.

### Linux

Varia conforme o gerenciador de pacotes da sua distro. Normalmente:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
Talvez você precise usar `sudo` para executar o comando adequado.

### MacOS

O [Homebrew][brew] é o seu melhor amigo. Siga o link para instalá-lo e depois rode:
```sh
brew install gawk
```

### Windows

Para o [WSL][wsl], veja as instruções de Linux acima.
Para o cygwin, instale o pacote `gawk`.

### Compilar a partir do código-fonte

Para os corajosos, há instruções [disponíveis no manual do `gawk`][build].
