# Apêndice das instruções

## Notas

Este exercício pede que você crie uma estrutura de dados de lista encadeada que possa ser iterada.

1. Implemente a propriedade `Count`: não deve ser possível alterar o valor dela de fora
2. Implemente o método `Push(T value)`, que adiciona um valor ao início da lista.
3. Implemente o método `Pop()`, que remove e retorna um valor do início da lista.
4. Adicione um construtor que permita a inicialização com um único valor ou com um iterável
5. Implemente a interface `IEnumerable<T>`. Para saber mais, veja [esta página](https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1).
6. Garanta que o método `Reverse()` esteja disponível.
