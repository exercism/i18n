# Aprendendo Crystal

- [Crystal Official Docs][offical-doc]: No momento, este é o recurso de aprendizado de referência para Crystal. E eles são bem completos, desde os literais e variáveis básicos até coisas mais avançadas, como macros. Eles também têm uma ótima [documentação sobre convenções de código][coding conventions].

- [Crystal for Rubyists][rubyists guide]: Uma introdução prática à linguagem Crystal.

- Crystal Playground - Embora Crystal não tenha um REPL embutido (como Ruby, Python ou Node), ele tem uma forma relativamente fácil de experimentar com código. Basta rodar `crystal play` e você deve ter um lugar para brincar com Crystal no seu navegador em localhost:8080.

- [editor online][online editor] - Um REPL baseado na web para Crystal, é um bom lugar para sentir a linguagem. 
  Sem precisar instalar nada.

[rubyists guide]: http://www.crystalforrubyists.com/
[offical-doc]: https://crystal-lang.org/reference/
[coding conventions]: https://crystal-lang.org/reference/conventions/coding_style.html
[online editor]: https://replit.com/languages/crystal
