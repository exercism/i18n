# Dicas

## Geral

- Leia a documentação sobre [operadores de comparação][comparison-operators]
- Leia a documentação sobre [ordenar listas][list-sort]
- Lembre-se de como você pode [acessar registros ou fazer casamento de padrões neles][records]

## 1. Compare os níveis de poder

- Use o [operador `(>)`][greater]

## 2. Encontre o poder mais alto

- Use a [função `max`][max]

## 3. Ordene as cartas

- Use a [função `List.sortBy`][sort-by]

## 4. As cartas mais legais primeiro

- Use as funções [`List.sortBy`][sort-by] ou [`List.sortWith`][sort-with]
- Você pode usar tuplas para ordenações hierárquicas

## 5. Poder Shiny

- Você pode definir uma ordem explicitamente ou usar a [função `compare`][compare] com um valor específico
- Você pode usar tuplas para ordenações hierárquicas

## 6. Faça suas apostas

- Use `compareShinyPower` em `expectedWinner`
- Use um `case` para [fazer casamento de padrões com a ordem][pattern-match]
