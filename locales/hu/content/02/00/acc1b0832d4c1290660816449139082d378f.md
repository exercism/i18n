# Bevezetés

Az Elixirben a tuple olyan adatszerkezet, amely adatokat csoportosít: rögzített számú, bármilyen típusú elemet tárol, de az egyes elemekhez nem tartozik külön név. A tuple-okat az Elixirben gyakran olyan műveleteknél használják, amelyek sok memóriaolvasással járnak, mert egy elem kiolvasása állandó idejű művelet. Általában viszont nem használják őket akkor, ha az elemek dinamikusan kerülnek bele vagy ki, mert ilyenkor nem a meglévő tuple módosul: helyette egy új tuple jön létre, amihez előre memóriát kell lefoglalni.

A gyakorlatban a tuple-okat az Elixirben kapcsos zárójelekkel hozzák létre. A tuple egyes elemei az `elem/2` függvénnyel érhetők el külön-külön, nullától induló indexeléssel:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## A tuple mint csoportosított információ

A gyakorlatban a tuple-okat gyakran csoportosított információk reprezentálására használják.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
