# Bemutatás

A [switch utasítás][switch] lehetővé teszi, hogy egy értéket több lehetséges egyező értékkel is összehasonlíts.
Tömörebb kódot írhatsz vele, mint ha több `else-if` elágazást használnál.
A switch utasítás a `switch` kulcsszóval kezdődik, amelyet az összehasonlítandó érték követ.
Ezután a `case` kulcsszóval definiálhatod az eseteket, a kulcsszót pedig az az érték követi, amellyel össze szeretnéd hasonlítani.
A `default` kulcsszóval definiálhatod az alapértelmezett esetet, ha egyik megadott eset sem egyezik.
Az `else-if` elágazásokhoz hasonlóan a `switch` utasítások is csak az első egyező esethez tartozó kódblokkot futtatják le.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Nézzük a következő példát:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Ehelyett így is írható:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Kötés és where utasítások

A `switch` utasításokban egyeztetett értékek nevekhez is köthetők, amelyeket az eset törzsében használhatsz.
Ezek a nevek `where` záradékokban is használhatók, amelyek további Boolean-kifejezések; ezeknek `true` értékre kell kiértékelődniük ahhoz, hogy az eset egyezzen.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
