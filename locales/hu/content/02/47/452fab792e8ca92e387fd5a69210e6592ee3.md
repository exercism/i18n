# Bevezetés

A tömbök és a listák skalárok rendezett gyűjteményét tartalmazzák.
Ha nem használunk referenciákat (amelyekről egy külön fogalomban lesz szó), ez azt jelenti, hogy a tömbök és a listák mindig laposak, azaz nem tartalmazhatnak más tömböket vagy listákat.

A legtöbb esetben a listákat zárójelek `()` veszik körül, elemeiket pedig vesszők `,` választják el.

Egy tömbváltozót általában úgy töltünk fel, hogy hozzárendelünk hozzá egy listát, pl. `my @names = ('Alice', 'Bob', 'Charlie');`.

Egy tömb vagy lista elemeihez index megadásával, azaz alsó indexszel férhetsz hozzá, pl. `('Alice', 'Bob', 'Charlie')[1] # 'Bob'`.

A Perlben az indexek `0`-tól kezdődnek.
A negatív indexek a tömb vagy lista végétől számolódnak, pl. `('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`.

## Függvények

Sok függvény létezik a tömbök és listák kezelésére; a leghasznosabbak közé tartozik a [grep][grep], amellyel egy feltételnek megfelelő elemekből szűrt új listát kapunk, a [map][map], amellyel az elemeket új értékek listájává alakítjuk, és a [sort][sort], amellyel az elemeket átrendezve új listát kapunk.

A tömbök módosítására szolgáló függvények közé tartozik a [push][push], amellyel a végére fűzhetsz elemeket, a [pop][pop], amellyel eltávolíthatod az utolsó elemet, a [shift][shift], amellyel eltávolíthatod az első elemet, az [unshift][unshift], amellyel az elejére szúrhatsz be elemeket, és a [splice][splice] a bonyolultabb módosításokhoz.

A tömbökön és listákon való iterálás egy [for(each)][perlsynforeach] utasítással szintén gyakran elő fog kerülni.

## A sigil hatása

Amikor egy tömb elemeihez férsz hozzá, az adott sigil határozza meg az eredményt.
A változónév végén álló `[]` index az, ami megmondja a Perlnek, hogy az adott nevű tömb elemeit éred el.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

Bár megengedett, az olvashatóság érdekében érdemes elkerülni, hogy a különböző változótípusok ugyanazt a nevet használják.

## Tömbök és listák

A tömbök és a listák sok mindenben hasonlítanak, és sok helyen felcserélhetően használhatók, de nem ugyanaz a két dolog.
A lista skalárok rögzített és megváltoztathatatlan gyűjteménye.
A tömb skalárok változtatható gyűjteménye, ahol mind a tartalom, mind maga a tömb mérete megváltoztatható.

Bizonyos kontextusokban másképp viselkednek.
Egy skalár kontextusban használt tömb a tömb méretét adja eredményül.
A skalár kontextusban használt lista az utolsó elemet adja, és esetleg figyelmeztetéseket is kapsz arról, hogy a többi tartalma void kontextusban használódik.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
