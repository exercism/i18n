# Bevezetés

## Számok

A Lua kétféleképpen ábrázolja a számokat: 64 bites egész számokként és dupla pontosságú lebegőpontos számokként. Támogatja a szokásos aritmetikai operátorokat: összeadás, kivonás, szorzás, osztás és negáció. Ezen felül támogatja az egészrészes osztást, a modulót és a hatványozást.

| Operátor | Példa               |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
