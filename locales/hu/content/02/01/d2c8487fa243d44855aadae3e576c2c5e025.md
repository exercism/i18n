# Útmutató

A **Chrono Realms** világában az időőrök gyakran nemcsak idővonalak fáival találkoznak, hanem **Chrono Chain**-ekkel is: összekapcsolt **TimeNode**-ok sorozataival, amelyek mindegyike egy konkrét időpillanatot képvisel.
A **Chrono Chain** egymás után következő pillanatok egyenes útvonala, ahol minden **TimeNode** a következőhöz kapcsolódik.
Ezek a **Chrono Chain**-ek akkor hasznosak, amikor az időőrök egy meghatározott eseménysorozaton haladnak végig, mert így egyetlen idővonalat tudnak követni.

Ahhoz azonban, hogy ezekkel a potenciálisan hosszú **Chrono Chain**-ekkel elboldoguljanak, az időőrök **okos mutatókat (Box<T>)** használnak: ezekkel kezelik és járják be biztonságosan a pillanatok listáit, anélkül hogy feleslegesen másolnák a memóriát, vagy túlcsordulás következne be.
Minden **TimeNode** hivatkozást tárol a következő csomópontra, így rekurzív struktúra jön létre.

Tanoncként a te feladatod, hogy egy **Chrono Chain**-t rekurzív listastruktúraként, okos mutatók segítségével valósíts meg.

Ebben a feladatban a következőket fogod tenni:

1. Létrehozol egy rekurzív `ChronoChain` enumbot, amely a pillanatok listáját képviseli.
2. A `Box<T>` okos mutatóval tárolod a rekurzív csomópontokat.
3. Írsz egy függvényt, amely `u32` értékek tömbjéből létrehoz egy `ChronoChain`-t.
4. Írsz egy függvényt, amely bejárja a `ChronoChain`-t, és összegzi a listában tárolt értékeket.

## 1. A rekurzív `ChronoChain` enum definiálása

Hozz létre egy rekurzív `ChronoChain` enumbot két változattal:

- `End`: a lista végét jelöli.
- `Link`: egy `u32` értéket és a lánc következő csomópontjára mutató, `Box`-ba csomagolt hivatkozást tartalmaz.

## 2. Függvény a ChronoChain felépítéséhez

Írj egy `ChronoChain::build` függvényt, amely `u32` értékek tömbjét kapja, és visszaad egy `ChronoChain`-t, az értékeket okos mutatók segítségével sorban összefűzve.

## 3. Az összegző függvény megvalósítása

Írj egy `ChronoChain::sum` függvényt, amely rekurzívan bejárja a `ChronoChain`-t, és összegzi az összes csomópont értékét.

## Példa a használatra

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
