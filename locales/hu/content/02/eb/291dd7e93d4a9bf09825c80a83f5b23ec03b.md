# A Szökőév fogalmai

Az első példamegoldást azért részesítem előnyben, mert a tömörsége egybevág azzal, amit az idiomatikus Rustban láttam. Azt is elkerüli, hogy a kanonikus megoldásban megjelenjen a closure fogalma.

## Kinyert fogalmak

### Általános

- Boolean logika
  - boolean
- Kifejezések
  - A Rust-függvények implicit módon kifejezéseket adnak vissza
- Aritmetika
  - maradékos osztás

### Típusok

- előjel nélküli egész számok - `u64`
- boolean - `bool`

## 1. példafeladat

[„desi-belokonska”](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09) megoldása

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## 2. példafeladat

[Kanonikus](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
