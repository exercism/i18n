# Kifizetési kötegek az adatbázisban

## A probléma leírása

Egy köteg kifizetési adatot kell beszúrnod a `Payment` táblába. A feladatod, hogy beolvasd a kifizetési adatokat a megadott bemeneti JSON-fájlból, majd a JDBC Client `batchExecute` műveletével beszúrd őket a `Payment` táblába. A minta bemeneti fájl neve `payments.json`.

A bemeneti JSON-fájl tartalma a következő JSON-sémán alapul.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

A kötegben beszúrt kifizetési adatok automatikusan generált azonosítóit kimenetként kell visszaadnod, anélkül hogy újabb lekérdezést indítanál az adatbázis felé.

Feltételezheted, hogy a `payments.json` fájlban megadott `employee_id` értékek érvényesek, és már szerepelnek az `Employee` táblában.

## Az adatbázis részletei

Ehhez a feladathoz a rendelkezésre bocsátott H2 adatbázist használd.

> A minta adatbázisfájl a `gofigure.mv.db`, az adatbázis neve pedig `gofigure`. A `db` mappában találod.

A következő táblák már megtalálhatók a minta H2 adatbázisban néhány mintaadattal együtt. Az oszlopnevek és az adattípusok az alábbiak.

**Tábla neve** : `Employee`

| **Oszlopok:**      | típus |
| -----------       | ----------- |
| `employee_id`     | egész szám, automatikusan növelt elsődleges kulcs       |
| `name`            | szöveg        |
| `city`            | szöveg        |
| `department`      | szöveg        |
| `age`             | egész szám        |

**Tábla neve**: `Payment`

| **Oszlopok:**      | típus |
| -----------       | ----------- |
| `payment_id`      | egész szám, automatikusan növelt elsődleges kulcs       |
| `date`            | dátum        |
| `amount`          | tizedes        |
| `employee_id`     | egész szám        |
| `reason`          | szöveg        |

* Az adatbázisfájl a `gofigure.mv.db`. A JDBC URL-t így add meg: `jdbc:h2:file:/path/to/db/file`
* Felhasználónév: `root`
* Jelszó: `root`

## Megkötések

* A lekérdezések és a Ballerina minta érvényesítéséhez a `db` mappában megadott H2 adatbázisfájlt használd
* A maven függőségi paraméterek megközelítésével add hozzá az H2 adatbázis-vezérlőt platformfüggőségként a Ballerina.toml fájlodhoz
* Az automatikusan generált azonosítókat anélkül kell megtalálnod, hogy újabb lekérdezést indítanál az adatbázis felé.

## Tesztkörnyezet

* A teszteket a `bal test` paranccsal futtathatod, amely a megadott mintaadatbázis ellen futtatja őket.

## Példák

### 1. példa

**Bemenet:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

Minta `payments.json` fájladat:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**Kimenet:** `[1,2,3]`

## Tippek

* Az adatbázis kezeléséhez használd a [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) modult
* A JDBC-vezérlő függőségként való hozzáadásának lépéseit az [Előfeltételek](https://lib.ballerina.io/ballerinax/java.jdbc/latest) szakaszban találod
* A JSON bemeneti fájl beolvasásához használd az [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) függvényt
* Alakítsd át a JSON-értékeket alkalmazásspecifikus típusokká, hogy típusbiztos módon dolgozhass az adatokkal. Nézd meg a [Konvertálás felhasználó által definiált típusra](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/) példát
* Az adatbázis kezeléséhez használd a [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) osztályt és a [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) távoli metódust
* Nézd meg a [kötegelt végrehajtás](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/) példát
