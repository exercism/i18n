# Bitmanipuláció

A Crystal bitenkénti operátorokkal teszi lehetővé, hogy az [`Int`][ints] értékeket bináris szinten manipuláld.

## Eltoló operátorok

A Crystalben [eltoló operátorok][shift] segítségével tolhatod a biteket balra (`<<`) vagy jobbra (`>>`).

### Balra eltolás(`<<`)

A balra eltoló operátor (`<<`) a biteket balra tolja.
Az eltolni kívánt értéket a bal oldalon, az eltolás mértékét pedig a jobb oldalon adod meg.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Ha a szám negatív, akkor az operátor helyette jobbra tol.

```crystal
0b0010 << -1
# => 0b0001
```

### Jobbra eltolás(`>>`)

A jobbra eltoló operátor (`>>`) a biteket jobbra tolja.
A balra eltoló operátorhoz hasonlóan az eltolni kívánt értéket a bal oldalon, az eltolás mértékét pedig a jobb oldalon adod meg.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

És hasonlóképpen, ha a szám negatív, akkor az operátor balra tol.

```crystal
0b0100 >> -1
# => 0b1000
```

## Bináris operátorok

A Crystalben 3 [bináris operátor][binary] (`&`, `|`, `^`) és egy `~` operátor áll rendelkezésre a bitenkénti műveletek elvégzéséhez.

### Bitenkénti ÉS(`&`)

A bináris ÉS operátor (`&`) két értéken végez bitenkénti ÉS műveletet.
Az első érték minden bitjét összehasonlítja a második érték azonos pozíciójában lévő bittel.
Az eredmény bitje 1 lesz, ha mindkét bit 1.
Ellenkező esetben 0 lesz.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### Bitenkénti VAGY(`|`)

A bináris VAGY operátor (`|`) két értéken végez bitenkénti VAGY műveletet.
Ez is összehasonlítja az első érték minden bitjét a második érték azonos pozíciójában lévő bittel.
Ha valamelyik bit 1, akkor az eredmény bitje 1 lesz.
Ellenkező esetben 0 lesz.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### Bitenkénti XOR(`^`)

A bináris XOR operátor (`^`) bitenkénti XOR műveletet végez.
A bitenkénti ÉS és bitenkénti VAGY operátorhoz hasonlóan összehasonlítja az első érték minden bitjét a második érték azonos pozíciójában lévő bittel.
Ha közülük _csak az egyik_ 1, akkor az eredmény bitje 1 lesz.
Ellenkező esetben 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### Bitenkénti NEM(`~`)

Végül a bitenkénti NEM operátor (`~`) megfordítja az érték minden bitjét.
A többi bináris operátortól eltérően ez egy unáris operátor, amely csak a jobb oldali értéken működik.

```crystal
~0b1110_0010
# => 0b0001_1101
```
