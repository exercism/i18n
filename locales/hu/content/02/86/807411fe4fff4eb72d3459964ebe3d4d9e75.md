# Bevezetés

A while ciklussal ismételten futtathatod ugyanazt a kódot, amíg egy bizonyos feltétel teljesül.
A `while` kulcsszóval írjuk le, utána egy kerek zárójelbe (`()`) tett feltétel következik, majd egy kapcsos zárójelbe (`{}`) tett kódblokk, amely a ciklus _törzsét_ tartalmazza.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

A JavaScriptben do-while ciklus is létezik.
Itt a feltételt a ciklustörzs végrehajtása után ellenőrzi a program.
Ez akkor hasznos, ha a feltétel a törzsben lévő kód eredményétől függ.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

A ciklustörzs belsejében használhatod a `break` kulcsszót, hogy teljesen leállítsd a ciklus végrehajtását.
Ezzel szemben a `continue` kulcsszó csak az aktuális iteráció végrehajtását állítja le, és a következővel folytatja.
A `continue` használatával gyakran elkerülheted, hogy a ciklustörzs nagy részeit egy elágazásba csomagold.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
