# Tippek

## 1. Készíts egy vektort az összes vagonból

- Működni fog egy klasszikus for/while ciklus is, amely `push!`-sal tölti fel a `Vector`-t.
- Másik lehetőség a [`collect()`][collect] függvény, amellyel tömörebb lehet a megoldás.
- Alternatívaként a splatting a vektorkonstruktoron belül is működik:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. Javítsd a vagonok vektorát

- Érdemes külön választani az első vagonokat és a mozdonyt minden mástól, hogy a végén a helyes sorrendben lehessen őket újra összeilleszteni.
- A splattinggel kombinált többszörös értékadás segíthet (lásd a bevezetőt).

## 3. Add hozzá a hiányzó megállókat

- Ne feledd, ez a függvény nem módosítja a bemenetet! Hozz létre egy új `Dict`-et.
- Csak a megálló nevére van szükség, a megálló számára nem, ezért minden párt fel kell bontani.
- Többféleképpen is összeállíthatod a nevek vektorát:
  -  for/while ciklus `push!()`-sal egy `Vector`-be.
  -  Tömb[komprehenció][comprehensions]
  -  [`map()`][map] egy függvény alkalmazása a vektorra.
  -  Egy [névtelen][anonymous] függvény [broadcasting][broadcasting]ja is lehetséges:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. Bővítsd az útvonalinformációkat

- A slurping után a `more_route_information` egy `Pairs()` gyűjtemény.
- A [`merge()`][merge] függvény két vagy több `Dict`s-t is összevon, de egy `Pairs()` gyűjteményt is elfogad.
  A `Pairs()` gyűjtemény explicit átalakítása `Dict`-té lehetséges, de felesleges.
