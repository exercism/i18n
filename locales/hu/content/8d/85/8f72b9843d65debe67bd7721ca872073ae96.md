# Részletek

Ahogyan egy pointer mutathat egy `int`-re vagy más alapvető adattípusra, úgy mutathat egy függvényre is.
Egy függvénypointer segítségével átadhatunk egy függvényt egy másik függvénynek.
Az olyan függvényt, amelyet paraméterként adunk át egy másik függvénynek, első osztályú függvénynek nevezzük.
Az olyan függvényt pedig, amely egy vagy több függvényt vesz át paraméterként, vagy amely maga ad vissza egy függvényt, magasabb rendű függvénynek nevezzük.

A következő példában az `is_even` és az `is_odd` első osztályú függvény.
A magasabb rendű függvény a `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
A `test_number` első argumentumaként szereplő `bool (*func) (int)` szignatúrája megegyezik az átadott függvények szignatúrájával.
Az `is_even` és az `is_odd` egyaránt egy `int` paramétert vesz át, és egy `bool` értéket ad vissza.
A `(*func)`-ban a `func` a használni kívánt függvény nevét jelöli.
Ha viszont `(*fn)` szerepelne, akkor így hívtuk volna meg: `printf(text, number, fn(number)? "true": "false");`.
Ahhoz, hogy kielégítsük a függvénypointer paramétert, a `test_number` hívásakor egy elvárt szignatúrával rendelkező függvény nevét adjuk át.
Ebből látszik, hogy egy függvénynév az adott függvény címére mutat.

Ha egy függvénypointert rossz szignatúrával hívunk meg, az nem definiált viselkedést (UB) eredményez.
A fordítótól függően lehet, hogy le sem fordul, vagy figyelmeztetéssel vagy anélkül lefordul, de aztán futásidőben összeomlik.
