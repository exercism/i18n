# Utasítások

Szenvedélyes madárfigyelő vagy, aki számon tartja, hány madár járt a kertedben az egyes napokon.

Úgy döntöttél, hogy a madárfigyelést egy új szintre emeled, és néhány eszközt készítesz, amelyek segítenek nyomon követni és feldolgozni az adatokat.

Az adatokat egész számok listájaként tárolod.
A listában az első szám azt mutatja, hány madár járt ma a kertedben, a második a tegnapi létszám, és így tovább.

```exercism/note
A valódi alkalmazásokban mindig az alapmodulokat érdemes használni, ha van rájuk lehetőség, a rekurzió megismerése érdekében azonban ebben a feladatban ne használd a `List` egyetlen függvényét sem.
```

## 1. Nézd meg, hány madár járt ma

Valósítsd meg a `today` függvényt.
A függvény a napi madárszámokat tartalmazó listát kap, és a mai nap számát adja vissza.
Ha a lista üres, az eredmény `Nothing`, egyébként a számot egy `Just` burkolja.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Növeld meg a mai nap számát

Valósítsd meg az `incrementDayCount` függvényt.
A függvény a napi madárszámokat tartalmazó listát kap, és a mai nap számát 1-gyel növeli.
Ha a lista üres, térj vissza az `[1]` listával.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Nézd meg, volt-e olyan nap, amikor egyetlen madár sem járt nálad

Valósítsd meg a `hasDayWithoutBirds` függvényt.
A függvény a napi madárszámokat tartalmazó listát kap.
`True` legyen az eredmény, ha legalább egy olyan nap volt, amikor egyetlen madár sem járt a kertedben, egyébként `False`.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Számítsd ki, összesen hány madár járt nálad

Valósítsd meg a `total` függvényt.
A függvény a napi madárszámokat tartalmazó listát kap, és visszaadja, összesen hány madár járt a kertedben attól kezdve, hogy elkezdted gyűjteni az adatokat.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Számítsd ki a forgalmas napok számát

Van, amikor több madár jár nálad, mint máskor.
Forgalmas nap az, amikor legalább öt madár járt a kertedben.

Valósítsd meg a `busyDays` függvényt.
A függvény a napi madárszámokat tartalmazó listát kap, és visszaadja a forgalmas napok számát.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
