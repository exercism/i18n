# Utasítások

Ebben a feladatban egy távirányítós autóval fogsz játszani, amelyre végre összegyűjtöttél elég pénzt, hogy megvedd.

Az autók teljes (100%-os) akkumulátorral indulnak. Valahányszor a távirányítóval vezeted az autót, 20 métert tesz meg, és az akkumulátor egy százalékát meríti. Az autó beceneve csak a létrehozásakor derül ki.

A távirányítós autón van egy menő LED-kijelző, amely két információt mutat:

- A teljes megtett távolság, amely így jelenik meg: `"<METERS> meters"`.
- Az akkumulátor hátralévő töltöttsége, amely így jelenik meg: `"Battery at <PERCENTAGE>%"`.

Ha az akkumulátor 0%-on van, nem tudod tovább vezetni az autót, és az akkumulátorkijelző a `"Battery empty"` szöveget fogja mutatni.

## 1. Készíts egy vadonatúj távirányítós autót

Valósítsd meg a `RemoteControlCar.new/0` függvényt, amely egy vadonatúj, távirányítós autót reprezentáló struktúrát ad vissza:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

A becenév kötelező a struktúrában, ezért gondoskodj róla, hogy az érték a `new` függvényben kapjon kezdőértéket, ne pedig a struktúrában.

## 2. Készíts egy vadonatúj távirányítós autót megadott becenévvel

Valósítsd meg a `RemoteControlCar.new/1` függvényt, amely egy vadonatúj távirányítós autó struktúrát ad vissza a megadott becenévvel:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. Jelenítsd meg a távolságot

Valósítsd meg a `RemoteControlCar.display_distance/1` függvényt, amely a LED-kijelzőn megjelenített távolságot adja vissza:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

Ügyelj rá, hogy a függvény argumentumként csak `RemoteControlCar` struktúrát fogadjon el.

## 4. Jelenítsd meg az akkumulátor töltöttségét

Valósítsd meg a `RemoteControlCar.display_battery/1` függvényt, amely a LED-kijelzőn megjelenített akkumulátortöltöttséget adja vissza:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

Ügyelj rá, hogy a függvény argumentumként csak `RemoteControlCar` struktúrát fogadjon el. Ha az akkumulátor 0%-on van, az akkumulátorkijelző „Battery empty” szöveget fog mutatni.

## 5. A vezetés megváltoztatja az akkumulátort és a megtett távolságot

Valósítsd meg a `RemoteControlCar.drive/1` függvényt, amely:

- 20 méterrel növeli a megtett méterek számát
- az akkumulátor 1%-át meríti

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

Ügyelj rá, hogy a függvény argumentumként csak `RemoteControlCar` struktúrát fogadjon el.

## 6. Vedd figyelembe a lemerült akkumulátorral való vezetést

Módosítsd a `RemoteControlCar.drive/1` függvényt úgy, hogy ne növelje a megtett távolságot, és ne csökkentse az akkumulátor töltöttségi százalékát, amikor az akkumulátor lemerült (0%-on van):

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
