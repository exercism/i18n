# Utasítások

Egy olyan rendszeren dolgozol, amely leegyszerűsíti a szervezeted hálózatára való bejelentkezést. A részfeladatok a hitelesítés részével foglalkoznak. A rendszer arcfelismeréssel igazolja a személyazonosságot.

A szem színét megadó paraméter minden előfordulásban garantáltan nem null.

## 1. Győződj meg róla, hogy az arcvonások egyeznek

Valósítsd meg az `Authenticator.AreSameFace()` metódust, amely ellenőrzi, hogy két arc megegyezik-e.

Adj hozzá egyenlőségvizsgáló rutinokat a `FacialFeatures` osztályhoz.

```csharp
Authenticator.AreSameFace(new FacialFeatures("green", 0.9m), new FacialFeatures("green", 0.9m);
// => true
Authenticator.AreSameFace(new FacialFeatures("blue", 0.9m), new FacialFeatures("green", 0.9m);
// => false
```

## 2. Hitelesítsd a rendszergazdát

A tiltakozásod ellenére a rendszergazda ragaszkodik ahhoz, hogy az átvételi tesztelés során legyen egy beépített identitása, így mindig hitelesíthető.

A rendszergazda e-mail-címe admin@exerc.ism. Zöld a szeme, a philtrumának a szélessége pedig 0,9.

Adj hozzá egyenlőségvizsgáló rutinokat az `Identity` osztályhoz.

Valósítsd meg az `Authenticator.IsAdmin()` metódust, amely ellenőrzi, hogy a kapott identitás megegyezik-e a rendszergazdáéval.

```csharp
var authenticator = new Authenticator();
authenticator.IsAdmin(new Identity("admin@exerc.ism", new FacialFeatures("green", 0.9m)));
// => true
authenticator.IsAdmin(new Identity("admin@thecompetition.com", new FacialFeatures("green", 0.9m)));
// => false
```

## 3. Regisztrálj új identitásokat

Valósítsd meg az `Authenticator.Register()` metódust, amely magán a hitelesítő példányon tárol el egy identitást úgy, hogy az erre az identitásra irányuló `IsRegistered()` hívások `true` értékkel térjenek vissza; ellenkező esetben az `IsRegistered()` `false` értéket ad vissza.

Hogy felismerd az identitás ismételt regisztrálására irányuló kísérleteket: ha az identitást már regisztrálták, akkor az `Authenticator.Register()` `false` értéket ad vissza, egyébként `true` értéket.

```csharp
var authenticator = new Authenticator();
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.IsRegistered(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => false
```

## 4. Akadályozd meg az érvénytelen identitások hitelesítését

Valósítsd meg az `Authenticator.IsRegistered()` metódust, és biztosítsd, hogy hamis értéket adjon vissza, ha egyetlen identitás sincs regisztrálva.

```csharp
var authenticator = new Authenticator();
authenticator.IsRegistered(new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.8m)));
// => false
```

## 5. Adj hozzá diagnosztikát a többszörös hitelesítési kísérletek felismeréséhez

Bejelentettek egy hibát, amely szerint az `Authenticator.IsRegistered()` metódust gyors egymásutánban többször is meghívják ugyanarra az identitásra. Úgy gondolod, hogy valamiféle „pattogás” probléma áll fenn, ahol pontosan ugyanazt a rekordot küldik be többször. A feladatod, hogy hozzáadj egy `Authenticator.AreSameObject()` diagnosztikai rutint a végzett tesztelés támogatására. A rutin két objektumot hasonlít össze, és `true` értéket ad vissza, ha pontosan ugyanaz a példány, egyébként `false` értéket.

```csharp
var identityA = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityB = identityA;
Authenticator.AreSameObject(identityA, identityB);
// => true

var identityC = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityD = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
Authenticator.AreSameObject(identityC, identityD);
// => false
```
