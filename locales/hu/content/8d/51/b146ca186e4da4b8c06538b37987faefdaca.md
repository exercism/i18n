# Bevezetés

A halmaz egy változtathatatlan és rendezetlen gyűjtemény, amely egyedi értékeket tartalmaz. Egy halmazban minden elemnek azonos típusúnak kell lennie.

A `gleam/set` modul definiálja a `Set` típust, és függvényeket biztosít a halmazokkal való munkához.

A listákat és halmazokat átalakíthatod egymásba a `set.to_list` és a `set.from_list` segítségével. A halmaz elemeinek sorrendje nem garantált.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

Halmazokat hozhatsz létre és tölthetsz fel a `set.new`, `set.insert` és `set.delete` segítségével.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

A halmaz tartalmát a `set.contains` és a `set.size` függvényekkel kérdezheted le.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

Egy halmaz kombinálható a `set.union` és a `set.intersect` segítségével.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

A halmazokat szűrheted.

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
