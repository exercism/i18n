# Feladatkiegészítés

## Regiszterek

| Regiszter | Használat    | Típus   | Leírás                        |
| --------- | ------------ | ------- | ----------------------------- |
| `$a0`     | bemenet      | cím     | nullával lezárt számjegy-string |
| `$a1`     | bemenet      | egész   | sorozathossz                  |
| `$v0`     | kimenet      | egész   | legnagyobb sorozatszorzat     |
| `$t0-9`   | ideiglenes   | bármilyen | ideiglenes tárolásra         |
