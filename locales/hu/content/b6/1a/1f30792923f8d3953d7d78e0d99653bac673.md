# Utasítások

Új költőklub nyílt a városban, és azon gondolkodsz, hogy csatlakozz-e.
Mivel a múltban voltak már incidensek, a klubnak nagyon szigorú ajtószabályzata van, amelyet el kell sajátítanod, mielőtt belépést kérnél.

A költőklubnak két ajtaja van, egy bejárati és egy hátsó, és mindkettőt őrzik.
A belépéshez ki kell találnod az aznapi jelszót.

A jelszó mindig egy versen alapul, és két lépésben vezethető le.

1. Az őr felmondja a verset, egyszerre egy sort, neked pedig a sor egy megfelelő betűjével kell válaszolnod.
2. Ezután az őr egyszerre megmondja az összes betűt, amivel válaszoltál, neked pedig le kell írnod őket egy papírra egy meghatározott formátumban.

A folyamat részletei attól függnek, melyik ajtón próbálsz belépni.

## 1. Keresd meg egy mondat első betűjét

A bejárati ajtó jelszavához tartozó betűk meghatározásához a verssor első betűjével kell válaszolnod, amelyet az őr felmond neked.

Hogy szép jelszó szülessen, a költőklub tagjai szívesen használnak _akrosztichon_ verseket.
Ez azt jelenti, hogy minden mondat első betűje egy szót alkot.
Íme egy példa egyik kedvenc írójuktól, Michael Lockwoodtól.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Tehát amikor az őr a **Stands so high** sort mondja fel, **S**-sel válaszolsz; amikor a **Huge hooves too** sort, **H**-val.

Valósítsd meg a `frontDoorResponse` függvényt, amely argumentumként a vers egy sorát kapja, és visszaadja a sor első betűjét.

```javascript
frontDoorResponse('Stands so high');
// => "S"
```

## 2. Írd nagybetűvel a szót

Most, hogy megvan az összes helyes betű, a bejárati ajtó jelszavához már csak annyit kell tenned, hogy a szót helyesen írod nagy kezdőbetűvel.

Valósítsd meg a `frontDoorPassword` függvényt, amely egy stringet fogad (az 1. részfeladatban összegyűjtött betűket), és helyesen nagy kezdőbetűvel adja vissza.

```javascript
frontDoorPassword('SHIRE');
// => "Shire"

frontDoorPassword('shire');
// => "Shire"
```

## 3. Keresd meg egy mondat utolsó betűjét

A hátsó ajtó jelszavához tartozó betűk meghatározásához a verssor utolsó betűjével kell válaszolnod, amelyet az őr felmond neked.

A költőklub tagjai igazán okosak.
A korábban említett vers egyben _telestichon_ is, ami azt jelenti, hogy minden mondat utolsó betűje szintén egy szót alkot:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Amikor az őr a **Stands so high** sort mondja fel, **h**-val válaszolsz; amikor a **Huge hooves too** sort, **o**-val.

Figyeld meg, hogy az őr néha stilisztikai szüneteket tart (szóközök formájában) a sor elején vagy végén.
Ezeket a szüneteket figyelmen kívül kell hagynod ahhoz, hogy levezessed a helyes betűt.

Valósítsd meg a `backDoorResponse` függvényt, amely argumentumként a vers egy sorát kapja, és visszaadja a sor utolsó nem szóköz karakterét.

```javascript
backDoorResponse('Stands so high');
// => "h"

backDoorResponse('Stands so high   ');
// => "h"
```

## 4. Légy udvarias

Hogy a hátsó ajtón keresztül bejuss a költőklubba, különösen udvariasnak kell lenned.
A jelszó levezetéséhez ezúttal helyesen kell nagy kezdőbetűvel írnod a szót, és a végére kell fűznöd a `', please'` szöveget.

Valósítsd meg a `backDoorPassword` függvényt, amely egy stringet fogad (a 3. részfeladatban összegyűjtött betűket), és visszaadja a nagy kezdőbetűvel írt jelszó udvarias változatát.

```javascript
backDoorPassword('horse');
// => "Horse, please"
```
