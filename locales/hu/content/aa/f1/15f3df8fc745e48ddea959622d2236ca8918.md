# Bemutatás

Az ABAP a numerikus értékekhez a szokásos aritmetikai operátorokat támogatja:

- A `+` összeadja az értékeket.
- A `-` kivonja az értékeket.
- A `*` összeszorozza az értékeket.
- A `/` elosztja az értékeket.
- A `MOD` egy egész osztás maradékát adja vissza.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

A szorzás és az osztás az összeadás és a kivonás előtt értékelődik ki. Ha egy számítást kifejezetten csoportosítani szeretnél, használj zárójelet.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
