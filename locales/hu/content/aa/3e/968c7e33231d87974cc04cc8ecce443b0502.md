# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat | Típus | Leírás |
| --------- | --------- | ----- | ------ |
| `$a0`    | bemenet     | cím | nullával lezárt bemeneti string                              |
| `$v0`    | kimenet     | Boolean | a bemenetben a zárójelek illeszkednek (`0` = `false`, `1` = `true`) |
| `$t0-9`  | ideiglenes | bármilyen     | ideiglenes tárolásra használatos                                |
