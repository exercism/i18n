# Névjegy

A C#-ban a Boolean értékeket a `bool` típus képviseli, amelynek értéke vagy `true`, vagy `false` lehet.

A C# négy [Boolean operátort][operators] támogat: a `!` (NOT), a `&&` (AND), a `||` (OR) és a `^` (XOR) operátort. A `&&` és a `||` operátor _rövidzárásos kiértékelést_ használ, ami azt jelenti, hogy az operátor jobb oldalát csak akkor értékeli ki, amikor szükség van rá.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

A három Boolean operátor [_operátorprecedenciája_][precedence] eltérő. Emiatt a kiértékelés sorrendje a következő: először a `not`, másodszor a `&&`, harmadszor a `^`, végül pedig a `||`. Ha »ki akarod kerülni« ezeket a szabályokat, egy Boolean kifejezést zárójelbe (`()`) tehetsz, mert a zárójelnek még nagyobb az operátorprecedenciája.

```csharp
!true && false   // => false
!(true && false) // => true
```
