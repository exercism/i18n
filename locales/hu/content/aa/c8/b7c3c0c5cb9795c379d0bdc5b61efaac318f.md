# Tippek

## Általános

- A `gleam/string` modulban számos hasznos [string-függvény][stdlib] található.

## 1. Üzenet kinyerése egy naplósorból

- Mintailesztésben a `<>` operátorral egy string elejére tudsz illeszkedni.
- A `gleam/string` modulban van egy [függvény][trim], amivel eltávolíthatod a string körüli szóközöket.

## 2. Naplózási szint kinyerése egy naplósorból

- A `gleam/string` modulban van egy [függvény][lowercase], amivel egy stringet kisbetűssé alakíthatsz.

## 3. Naplósor újraformázása

- A `<>` operátorral stringeket fűzhetsz össze.

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
[trim]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#trim
[lowercase]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#lowercase
