# Névjegy

Bár az Elixir-programozók gyakran mondják, hogy „let it crash”, és a „happy path” szerint írják a kódot, gyakran előfordul, hogy el kell kapnunk a függvényhívást, hogy egy adott értéket vagy üzenetet adjunk vissza, vagy felszabadítsunk rendszererőforrásokat.

- Ha egy függvény normál esetben hibát dob, a neve végén `!` áll.
- A függvények alternatívaként atomokat és tuple-öket adhatnak vissza, hogy jelezzék a sikert és a kudarcot:

  ```elixir
  Map.fetch(%{a: 1}, :a)
  # => {:ok, 1}
  Map.fetch(%{a: 1}, :b)
  # => :error

  Map.fetch!(%{a: 1}, :b)
  # => raises KeyError
  ```

## Kerüld az antimintákat

Kerüld azokat a programozási mintákat, amelyek a vezérlési folyamat irányítására hibákat használnak. Ez Elixirben antiminta.

```elixir
# Avoid using errors for control-flow.
try do
  {:ok, value} = MyModule.janky_function()
  "All good! #{value}."
rescue
  e in RuntimeError ->
    reason = e.message
    "Uh oh! #{reason}."
end

# Rather, use control-flow structures for control-flow.
case MyModule.janky_function() do
  {:ok, value} -> "All good! #{value}."
  {:error, reason} -> "Uh oh! #{reason}."
end
```
