# Bevezetés

Az Elixirben modulattribútumokat definiálhatunk, amelyeket konstansként használhatunk a függvényeinkben.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Ha modulkonstansok meghatározására használjuk őket, az attribútumok bármilyen kifejezést tartalmazhatnak, ami a fordításkor kiértékelhető. A fordítás után a modulattribútumok nem érhetők el, mivel a fordítás során kifejtődnek, hasonlóan a C-hez hasonló nyelvekben definiált makrókhoz.
