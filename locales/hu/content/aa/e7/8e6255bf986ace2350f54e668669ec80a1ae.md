# Tesztek

A letöltött feladathoz a következő fájlok tartoznak, amelyekkel felépítheted és tesztelheted a megoldásodat:

```text
hello-world/
├── HelloWorld.vb          # Your solution
├── HelloWorldTests.vb     # The test suite
├── HelloWorld.vbproj      # Project and build configuration
└── packages.lock.json     # Resolved project dependencies
```

A fájlnevek feladatonként változnak.
A megoldásodat az első `.vb` fájlba írd.
A második, `Tests.vb` végződésű fájl az [xUnit tesztkészlet][xunit].
Ezt általában csak azért fogod szerkeszteni, hogy engedélyezd a további teszteket.
Az utolsó két fájl egyikét sem kell szerkesztened.
A `.vbproj` fájl a projekt buildbeállításait és a közvetlen csomagreferenciáit tartalmazza.
A generált `packages.lock.json` fájl a feloldott közvetlen és tranzitív csomagverziókat rögzíti.

~~~exercism/note
A tesztek azt a viselkedést írják le, amelyet egy sikeres megoldásnak teljesítenie kell.
Segíthetnek tisztázni azokat a részleteket, amelyekre az utasítások nem térnek ki.
~~~

## A tesztek futtatása

Nyiss egy terminált a feladat könyvtárában, és futtasd:

```bash
dotnet test
```

A parancs visszaállítja a projekt függőségeit, felépíti a projektet, és lefuttatja a tesztjeit.
A `dotnet watch test` paranccsal azt is elérheted, hogy a tesztek újrafussanak, valahányszor egy forrásfájl megváltozik.

## Kihagyott tesztek

A feladatok kezdetben csak az első tesztet engedélyezik, így egyszerre egy lépésben haladva oldhatod meg a többit.
A tesztek megtalálásához nyisd meg a `Tests.vb` végződésű fájlt.
Minden teszt egy `Sub` szubrutin, amelyet egy xUnit `<Fact>` attribútum jelöl.
Egy teszt mindaddig ki lesz hagyva, amíg a `<Fact>` attribútumában van egy `Skip` argumentum:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

A teszt engedélyezéséhez egyszerűen távolítsd el a `Skip` argumentumot:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Miután az újonnan engedélyezett teszt sikeres lesz, ismételd meg ugyanezt a következő kihagyott teszttel.
Amikor minden teszt engedélyezve van és sikeres, készen vagy.
