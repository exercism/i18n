# Bemutatás

Az elágazások olyan utasítások, amelyek attól függően futtatnak más-más kódot, hogy egy feltétel `true` vagy `false`.

Az [`if` utasítás][if_statement] csak akkor hajtja végre a törzsét, ha a feltétele `true`.
Go nem ismeri a truthy és falsy értékek fogalmát, ezért a feltételnek `bool` típusúnak kell lennie.
Az olyan kifejezések, mint az `if mySlice { ... }` vagy az `if 1 { ... }`, fordítási hibát okoznak.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

További feltételek ellenőrzéséhez használd az `else if`-et, tartalék megoldásként pedig az `else`-t, ha egyik sem teljesül.
A feltételek kiértékelése fentről lefelé halad, és csak az az első ág fut le, amelynek a feltétele igaz.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

A Go általában azt részesíti előnyben, ha a kivételes esetben már korán visszatérünk, és elkerüljük az `else`-t.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

Az `if` utasítás tartalmazhat egy rövid kezdőértéket beállító utasítást is.
Ezt gyakran arra használjuk, hogy egy hívás után rögtön ellenőrizzük a hibát:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

A kezdőértéket beállító utasításban deklarált változók scope-ja csak a teljes `if`/`else` láncra terjed ki.
Fontos, hogy a Go-ban nincs ternáris operátor; ez szándékos tervezési döntés, hogy a kód könnyen áttekinthető maradjon.
