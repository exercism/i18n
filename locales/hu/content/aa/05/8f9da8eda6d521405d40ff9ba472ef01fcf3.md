# Tesztelés a parancssorból

A teszteket így futtasd:

```bash
$ cargo test
```

Az első kivételével minden teszt figyelmen kívül van hagyva. Miután az első teszt sikeres lett, nyisd meg a tesztek forrásfájlját, amely a `tests` könyvtárban található, és távolítsd el a `#[ignore]` jelzőt a következő tesztről, majd érd el, hogy a tesztek újra sikeresek legyenek. Minden különálló teszt egy függvény, amely fölött `#[test]` jelző áll. Folytasd, amíg minden teszt sikeres nem lesz.

Ha _csak a figyelmen kívül hagyott_ teszteket szeretnéd futtatni anélkül, hogy szerkesztenéd a tesztek forrásfájlját, használd ezt:

```bash
$ cargo test -- --ignored
```

Ha a Rust 1.51-es vagy újabb verzióját használod, _az összes_ tesztet így futtathatod:

```bash
$ cargo test -- --include-ignored
```

Egy adott teszt, például `some_test` futtatásához használd ezt:

```bash
$ cargo test some_test
```

Ha az adott teszt figyelmen kívül van hagyva, használd ezt:

```bash
$ cargo test some_test -- --ignored
```

Ha többet szeretnél megtudni a Rust tesztjeiről, nézd meg az online [tesztdokumentációt][rust-tests].

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
