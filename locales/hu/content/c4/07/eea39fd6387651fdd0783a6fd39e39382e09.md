# Bevezetés

## Map-ek

A **Map** olyan adatstruktúra, amely kulcs-érték párokat tárol.
Hasonló a szótárhoz más programozási nyelvekben.
A [Map][map-javadoc] interfész határozza meg a mapon végezhető műveleteket.

A Java számos különböző Map-implementációval rendelkezik.
A [HashMap][hashmap-javadoc] az egyik gyakran használt közülük.

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

A maphoz a [put][map-put-javadoc] segítségével adhatsz hozzá bejegyzéseket.

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

Minden kulcshoz csak egyetlen érték tartozhat.
Ha ugyanazzal a kulccsal hívod meg a `put` metódust, az frissíti a kulcs értékét.

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

Egy kulcs értékét a [get][map-get-javadoc] segítségével kérheted le.

```java
fruitPrices.get("apple"); // => 100
```

A [containsKey][map-containskey-javadoc] segítségével megnézheted, hogy a map tartalmaz-e egy adott kulcsot.

```java
fruitPrices.containsKey("apple");  // => true
fruitPrices.containsKey("orange"); // => false
```

A [remove][map-remove-javadoc] segítségével távolíthatsz el bejegyzéseket.

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

A [size][map-size-javadoc] metódus a bejegyzések számát adja vissza.

```java
fruitPrices.size();  // Returns 2
```

A [keySet][map-keyset-javadoc] és a [values][map-values-javadoc] metódussal a Map kulcsait, illetve értékeit kérheted le egy Set, illetve egy gyűjtemény formájában.

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
