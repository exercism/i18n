# Bevezetés

## Számok

Az ABAP-ban több numerikus típus létezik. Ebben a feladatban ezek közül kettőt fogsz használni:

- `i` egész értékekhez, például a napok számához.
- `p` csomagolt tizedes értékekhez, például az óradíjhoz vagy a kedvezményhez.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

A csomagolt számoknál meg kell adni a maximális hosszt és a tizedesjegyek számát.
A tizedes literálokat általában szöveges értékként írjuk le, és a fordítóprogram vagy a `CONV` alakítja át a cél tizedestípusra.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### Kerekítés

Az ABAP beépített numerikus függvényeket kínál a kerekítéshez.
A `floor` függvény lefelé kerekít a legközelebbi egész számra, a `ceil` pedig felfelé kerekít a legközelebbi egész számra.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## Aritmetikai operátorok

Az ABAP támogatja az aritmetikai operátorokat a numerikus értékekkel végzett számításokhoz.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

Az alapvető operátorok:

- `+` összeadás.
- `-` kivonás.
- `*` szorzás.
- `/` osztás.
- `MOD` egész osztás maradéka.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

Az ABAP a szorzást és az osztást az összeadás és a kivonás előtt értékeli ki.
A zárójelekkel egyértelművé teheted a kívánt kiértékelési sorrendet.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
