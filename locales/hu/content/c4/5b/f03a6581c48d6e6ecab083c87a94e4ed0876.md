# Tesztek

A teszteket ezzel futtasd:

```shell
corepack pnpm test
```

Ügyelj rá, hogy a kódod kövesse a bevált gyakorlatokat és a kódstílust, ahogy más felhasználók is teszik, az ESLint segítségével, amellyel statikus elemzést végezhetsz a kódon.
Az ilyen eszközök néha időt spórolnak neked azzal, hogy felismerik a JavaScript-kódodban lévő elgépeléseket vagy buta hibákat:

```shell
corepack pnpm lint
```

A Jestet „watch” módban is futtathatod; ilyenkor automatikusan újrafuttatja a tesztjeidet, amikor elmented a kód vagy a tesztmodul módosításait:

```shell
corepack pnpm watch
```

## A tesztek kihagyásának megértése

A skip metódus arra utasítja a tesztkészletet, hogy ne futtasson le egy tesztet. Ez a függvény az alábbi álneveken is használható: `it.skip(name, fn)`, `xit(name, fn)` vagy `xtest(name, fn)`

- Miért vannak kihagyva?

Hogy a felhasználók egyszerre csak egy tesztre tudjanak összpontosítani, és a megoldás fejlesztése közben egyenként engedélyezzék őket.

- Hogyan lehet engedélyezni őket?

Cseréld le a `xtest`-et `test`-re.

```javascript
test('title cased phrases', () => {
  expect(Acronyms.parse('Portable Network Graphics')).toEqual('PNG');
});
```

## Az első JavaScript 2015 modulod elkészítése

Ezen a kurzuson a tesztek általában úgy töltik be a megvalósításodat, hogy JavaScript-modulként importálják: `import { Bob } from './bob.js';`.
Neked csak exportálnod kell a megvalósításodat a hivatkozott `bob.js` fájlból:

```javascript
export function hey(message) {}
```

A modulokról további információkat a [Babel dokumentációjában](https://babeljs.io/docs/learn-es2015/#modules) találhatsz.
Hogy könnyebb legyen az indulás, van egy _skeleton_ JavaScript-fájl a könyvtárban.
