# Névjegy

A Gleam hibakezelésre nem kivételeket használ. Helyette a sikeresen vagy sikertelenül végződő függvények egy általános `Result` típust adnak vissza.

A `Result` típus be van építve a nyelvbe, ezért nem kell definiálnod vagy importálnod, de ha mégis magad definiálnád, így nézne ki:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

Amikor egy függvény sikeresen lefut, az `Ok` variánst adja vissza, amikor pedig kudarcot vall, az `Error` variánst.

A `Result` típus nagyon gyakori a Gleamben, és a Gleam-programozók általában a [`gleam/result` modult](https://hexdocs.pm/gleam_stdlib/gleam/result.html) használják, hogy könnyebb legyen velük dolgozni.

A `result.map` függvénnyel meghívhatsz egy függvényt a resultban lévő értéken, ha az `Ok`, vagy egy `Error`-t változatlanul továbbadhatsz.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

A `result.try` függvény hasonló, de a callback függvénynek resultot kell visszaadnia. Ez akkor hasznos, ha több resultot visszaadó függvényt szeretnél összefűzni.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
