# Structok

A structok egy rögzített, heterogén adathalmazt gyűjtenek össze egyetlen egységbe. A Rustban a structoknak a következő tulajdonságaik vannak:

- Minden structtípusnak van egy adott neve.
- A struct minden tagját **mezőnek** nevezzük.
- A struct minden mezőjének van egy adott neve.
- A láthatóságot mezőnként tartjuk nyilván: minden mező lehet külön-külön nyilvános, privát vagy egyéb[^1].

# A structok áttekintése

A structokat a `struct` kulcsszóval definiáljuk, amelyet annak a típusnak a neve követ, amelyet a struct leír.
A nevet ezután kapcsos zárójel (szabványos struct esetén), kerek zárójel (tuple struct esetén) vagy pontosvessző (unit struct esetén) követheti.

```rust
struct Item {}
```

Ezután további típusokat viszünk be a struct törzsébe a struct _mezőiként_, mindegyiket a saját típusával:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Végül metódusokat definiálhatunk a structokon egy `impl` blokkon belül:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# A structok fajtái

A structoknak három fajtája van: a nevesített mezőkkel rendelkező structok (szabványos structok), a tuple structok és a unit structok.

A structok nagyon hasonlítanak a **tuple-ökhöz**. Valójában az egyetlen különbség a structok és a tuple-ök között az, hogy mi az, ami névtelen. Az általános forma a következő:

- A structok nevesítettek, és a mezőik is névvel rendelkeznek:

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  A mezőket név szerint érjük el:

  ```rust
  let bar = foo.bar;
  ```

- A tuple structok nevesítettek, de a mezőik névtelenek:

  ```rust
  Foo(Bar, Bat)
  ```

  A mezőket kicsomagolással vagy numerikus indexszel érjük el:

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- A tuple-ök névtelenek, és a mezőik is névtelenek:

  ```rust
  (Bar, Bat)
  ```

  A tuple structokhoz hasonlóan a mezőket kicsomagolással vagy numerikus indexszel érjük el.

- A névtelen structok, ahogy a nevük is sugallja, névtelenek, de nevesített mezőik vannak. Talán ismerősek lehetnek más nyelvekből, például a Go-ból vagy a Javából. A Rustban nem léteznek; helyettük a tuple használata számít idiomatikusnak.

# Nulla méretű típusok

Egy structnak annyi mezője lehet, amennyi éppen szükséges, akár kevés is. Ebből az következik, hogy egy structnak az is megengedett, hogy egyetlen mezője se legyen. A nulla mezővel rendelkező structot **nulla méretű típusnak** nevezzük, és a fordító különlegesen bánik vele: a nulla méretű típusok (amelyeket gyakran **ZST**-nek rövidítenek) soha nem foglalnak stack- vagy heap-területet, még akkor sem, amikor esetleg arra számítanál. Például a `Box<T>` nem foglal heap-memóriát, ha a `T` egy ZST.

Amikor ZST-t írsz, használhatod a szabványos vagy a tuple struct szintaxisát:

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

A ZST-khez van egy rövidített forma is:

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

Amikor ZST-t írunk, általában a rövidített forma az előnyben részesített, mert a stílusokat nem lehet keverni: amilyen stílusban egy ZST-t[^2] deklaráltál, ugyanolyan stílusban kell példányosítanod is.

Miután ennyit beszéltünk a ZST-k szintaxisáról, nézzük meg, miért is akarna az ember egyáltalán ilyesmit. Egy ZST nem tud adatot tárolni, viszont remekül használható trait-ek implementálására.

[^1]: [Ezek a dokumentumok](https://doc.rust-lang.org/reference/visibility-and-privacy.html) elmagyaráznak néhány ritkábban használt láthatósági lehetőséget.
[^2]: Ez egy általános szabály egy konkrét esete: amilyen stílusban bármely structtípust deklaráltunk, ugyanolyan stílusban kell példányosítanunk is.
