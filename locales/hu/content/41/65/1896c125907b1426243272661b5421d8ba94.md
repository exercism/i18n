# Tippek

## Általános

- Olvass az [`alias` és `import`][getting-started] használatáról a Getting Started útmutatóban.
- Olvass a [modulok kompozíciójáról][elixir-school-module-composition] az elixirschool.com oldalon.

## 1. A `Race.__struct__/0 is undefined` fordítási hiba javítása

- Aliast a [`alias`][alias] speciális formával hozhatsz létre.

## 2. A `Car.__struct__/0 is undefined` fordítási hiba javítása

- Aliast a [`alias`][alias] speciális formával hozhatsz létre.
- Az `alias` speciális forma elfogad egy `:as` opciót.

## 3. Az `undefined function puts/1` fordítási hiba javítása

- A függvényeket az [`import`][import] speciális formával importálhatod.
- Az [`import`][import] speciális forma elfogad egy `:only` opciót. Az értéke egy kulcsszólista, amelyben a kulcsok a függvénynevek, az értékek pedig a függvények aritásai.

## 4. Az `undefined function default_color/0` fordítási hiba javítása

- A függvényeket az [`import`][import] speciális formával importálhatod.
- Az [`import`][import] speciális forma elfogad egy `:except` opciót. Az értéke egy kulcsszólista, amelyben a kulcsok a függvénynevek, az értékek pedig a függvények aritásai.
