# Telepítés

Először győződj meg róla, hogy telepítve van az Erlang, és kövesd az
[Erlang][1] telepítési oldalán található utasításokat, a helyzetednek megfelelően.
[1]: /languages/erlang

## Homebrew Mac OS X-hez

Frissítsd a Homebrew-t a legújabb verzióra:

```bash
$ brew update
```

Telepítsd az LFE-t:

```bash
$ brew install lfe
```

## Telepítés forrásból
Telepítsd a rendszered „fejlesztői eszközeit” vagy az „alapvető buildcsomagjait”, valamint a `git`-et és az Erlang `erl`-jét.

Például Ubuntu 18.04-en:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Ezután az alábbiakkal letöltheted és lefordíthatod az LFE-t:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Miután lefordítottad az LFE-t, elindíthatod a REPL-t (interaktív munkamenet) a ``lfe`` bináris futtatásával:

```bash
$ ./bin/lfe
```
