# Bemutató

Az Elixir standard könyvtára 4 különböző modult kínál a dátumokkal és az idővel való munkához, és mindegyiknek megvan a maga structja.

- A [`Date` modul][date]. Egy `Date` struct a [`~D` szigillummal][sigil-d] hozható létre.
    ```elixir
    ~D[2021-01-01]
    ```

- A [`Time` modul][time]. Egy `Time` struct a [`~T` szigillummal][sigil-t] hozható létre.
    ```elixir
    ~T[12:00:00]
    ```

- A [`NaiveDateTime` modul][naivedatetime] az időzóna nélküli dátum-időkhöz. Egy `NaiveDateTime` struct a [`~N` szigillummal][sigil-n] hozható létre.
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- A [`DateTime` modul][datetime] az időzónával rendelkező dátum-időkhöz. Ha ezt a modult az UTC-től eltérő időzónákhoz szeretnéd használni, külső függőségre, egy időzóna-adatbázisra lesz szükséged. Egy `DateTime` struct a [`~U` szigillummal][sigil-u] ábrázolható, de létrehozni inkább a `DateTime` függvényeivel érdemes.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## Összehasonlítás

A dátumok vagy időpontok egymással való összehasonlításához a megfelelő modulban a `compare` vagy `diff` függvényt keresd. Az olyan összehasonlító operátorok, mint a `==`, `>` és `<`, _úgy tűnik_, működnek, de ezeknél a structoknál nem végeznek helyes szemantikai összehasonlítást.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## Eltolás

A dátumok, az időpontok és a dátum-idők előre és hátra is eltolhatók az időben a megfelelő modul `add/2` függvényével.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## Átalakítások

Egy `NaiveDateTime` struct [`NaiveDateTime.to_date/1`][naivedatetime-to-date] és [`NaiveDateTime.to_time/1`][naivedatetime-to-time] segítségével bontható szét egy `Date` és egy `Time` structra. Az ellenkezőjét a [`NaiveDateTime.new!/2`][naivedatetime-new] függvénnyel érheted el.

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
