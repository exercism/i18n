# Telepítés

A [NodeJS LTS](https://nodejs.org/en) verziójára lesz szükséged.

> 💡 Ez a kurzus valószínűleg működik a régebbi stabil verziókkal, valamint a „current” verzióval is.
> A páratlan verziók azonban [tervezés szerint](https://github.com/nodejs/release#release-schedule) soha nem stabilak.
> Mindig ügyelj rá, hogy a NodeJS páros verzióját telepítsd.

Telepítsd a [Yarn 4+](https://yarnpkg.com/getting-started/install) verziót a Node.JS `corepack` segítségével:

```shell
corepack enable yarn
```

## A telepítés ellenőrzése

Ahhoz, hogy az imént telepített programokat használni tudd, általában új terminált kell nyitnod.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_Megjegyzés: a te verziószámaid valószínűleg eltérnek majd ezektől._

## A feladat telepítése

**Minden feladathoz** szükség van néhány eszközre a tesztek futtatásához:

Ezeket úgy telepítheted, ha az adott feladat könyvtárában lefuttatod a következő parancsot:

```bash
$ corepack yarn install
```

Attól függően, milyen szerkesztőt használsz, minden feladathoz telepítened kell az [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) csomagot, hogy a Plug'n'Play telepítésekkel is működjön.
A jelen írás pillanatában az alábbiak támogatottak:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
