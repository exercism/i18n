# Névjegy

A Ruby része egy Standard Library (gyakran csak „stdlib”) - osztályok gyűjteménye, amelyekkel olyan dolgokat kezelhetsz, mint a dátumok, a json vagy a hálózat.
Emellett néhány hasznos funkcióval is segít abban, hogy könnyebb legyen a kódoddal dolgozni.

Az `OpenStruct` a Standard Library része, és segítségével könnyedén létrehozhatsz egy objektumot egy `Hash`-ből.
Ahelyett, hogy `Hash`-kulcsokkal kellene hozzáférned az értékekhez, az `OpenStruct` lehetővé teszi, hogy metódusokkal érd el és állítsd be őket.

Amikor a Standard Library vagy bármely más könyvtár osztályait használod, a `require` metódussal kell betöltened az adott osztályt.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ennek egy bónusz előnye, hogy kihasználhatsz egy rövidítést, amikor blokk-szintaxist használsz.
Ha egy blokk csak egyetlen metódust hív meg, a blokkot lecserélheted a `&:` jelölésre, amelyet a metódus neve követ.
Például ez a két sor ugyanazt jelenti:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
