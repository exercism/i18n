# Boolok

A Swiftben létezik egy [`Bool`][bools] nevű típus, amellyel a `true` és `false` értékeket lehet ábrázolni.

## Logikai operátorok

A Swiftnek 3 [logikai operátora (`!`, `||`, `&&`)][logical-operators] van, amelyekkel Bool értékeket lehet összekombinálni, és olyan kifejezéseket lehet létrehozni, amelyek különböző értékeket adnak.

### És (`&&`)

Swiftben az [_és_ operátor][and] jele `&&`, és `true`-t ad vissza, ha mindkét megadott érték `true`, egyébként `false`-t.
Amikor az _és_ operátort használod, az egyik Bool a `&&` jobb oldalára kerül, a másik pedig a bal oldalára.

```Swift
true && true  // true
true && false // false
```

### Vagy (`||`)

Swiftben a [_vagy_ operátor][or] jele `||`, és `true`-t ad vissza, ha a megadott értékek közül **legalább az egyik** `true`. Ha mindkét érték `false`, akkor `false`-t ad vissza.
Amikor a _vagy_ operátort használod, az egyik bool a `||` jobb oldalára kerüljön, a másik pedig a bal oldalára.

```swift
true || true   // true
true || false  // true
false || false // false
```

### Nem (`!`)

Swiftben a [_nem_ operátor][not] jele `!`, és `true`-t ad vissza, ha a megadott Bool `false`, illetve `false`-t, ha `true`-t adsz meg.
Amikor a _nem_ operátort használod, a Bool értéket az operátor (`!`) után kell megadni.

```swift
!true  // false
!false // true
```

## Zárójelek használata (`()`)

Amikor Boolean értékekkel dolgozol, [explicit zárójelekkel][explicit-parentheses] döntheted el, hogy mely Bool értékeket értékelje ki először.
Az eredmény attól függően más lehet, hogyan használod a zárójeleket.
A Swiftben először az értékelődik ki, ami zárójelben van.

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Mivel először az értékelődik ki, ami zárójelben van, a következő példában a _nem_ operátor a zárójelben lévő kifejezésre vonatkozik.

```Swift
!true && false   // false
!(true && false) // true
```

~~~~exercism/note
Zárójelet csak akkor használj, ha az hatással van az eredményre, egyébként hagyd el őket.
~~~~
