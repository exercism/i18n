# Bevezetés

Amikor egy egyedi típus valamelyik változata adatot tárol, azt rekordnak nevezzük, és minden benne tárolt érték egy _mezőben_ található.

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

Az olvashatóság érdekében a Gleam lehetővé teszi, hogy a mezőket névvel címkézzük fel.

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

A címkékkel egy rekord konstruktorának argumentumait tetszőleges sorrendben adhatjuk meg.

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

Ha egy egyedi típusnak csak egy változata van, akkor a `.label` hozzáférési szintaxissal kérhetjük le egy rekord mezőit.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

A rekordfrissítési szintaxis akkor használható, ha az egyedi típusnak egyetlen változata van: ilyenkor egy meglévő rekordból hozunk létre újat úgy, hogy néhány mezőt új értékre cserélünk.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

A címkéket mintaillesztésnél is használhatjuk, hogy értékeket nyerjünk ki rekordokból.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h > 20.0 -> True
    _ -> False
  }
}
```

Ha csak néhány mezőre szeretnénk illeszkedni, a `..` spread operátorral figyelmen kívül hagyhatjuk a többi mezőt.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
