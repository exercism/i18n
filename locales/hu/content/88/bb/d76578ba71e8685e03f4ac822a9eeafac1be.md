# Utasítások

Egy nemrég lezajlott biztonsági felülvizsgálat után arra kértek fel, hogy tisztítsd meg a szervezet archivált naplófájljait.

## 1. A hibás naplósorok azonosítása

Képet kell kapnod arról, hogy az archívumodban hány naplósor nem felel meg a jelenlegi szabványoknak.
Úgy gondolod, hogy egy egyszerű vizsgálat megmutatja, hogy egy naplósor érvényes-e.
Ahhoz, hogy egy sor érvényesnek számítson, a következő stringek egyikével kell kezdődnie:

- [DEBUG]
- [INFO]
- [WARNING]
- [ERROR]

Valósítsd meg a `valid_line?/1` függvényt, amely `true` értéket ad vissza, ha a naplósor érvényes.

```elixir
LogParser.valid_line?("[ERROR] Network Failure")
# => true

LogParser.valid_line?("Network Failure")
# => false
```

## 2. A naplósor felbontása

Nem sokkal azután, hogy elkezdted a naplófeldolgozó projektet, rájössz, hogy az egyik alkalmazás naplói nincsenek sorokra bontva, mint a többié. Ebben a projektben ami külön sorokban lenne, az egyetlen sorban van, olyan cifra nyilakkal összekötve, mint a `<--->` vagy a `<*~*~>`.

Valójában bármely string használható elválasztóként e projekt naplóiban, amelynek az első karaktere `<`, az utolsó karaktere `>`, közte pedig a következő karakterek bármilyen kombinációja áll: `~`, `*`, `=` és `-`.

Valósítsd meg a `split_line/1` függvényt, amely egy sort kap, és stringek listáját adja vissza.

```elixir
LogParser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
# => ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Műtermékek eltávolítása a naplóból

Azt tapasztaltad, hogy a naplók valamely feldolgozási lépése szétszórta a naplókban az „end-of-line” szöveget, amelyet egy sorszám követ (közbeékelődő szóköz nélkül).

Valósítsd meg a `remove_artifacts/1` függvényt, amely kap egy stringet, eltávolít belőle minden „end-of-line” szöveget (kis- és nagybetűtől függetlenül), és egy tiszta naplósort ad vissza.

A „end-of-line” szöveget nem tartalmazó sorokat változatlanul kell visszaadni.

Csak az „end-of-line” stringet távolítsd el, a szóközöket nem kell módosítanod.

```elixir
LogParser.remove_artifacts("[WARNING] end-of-line23033 Network Failure end-of-line27")
# => "[WARNING]  Network Failure "
```

## 4. Sorok megjelölése felhasználónevekkel

Észrevetted, hogy néhány naplósor olyan mondatokat tartalmaz, amelyek felhasználókra utalnak.
Ezek a mondatok mindig a `"User"` stringet tartalmazzák, amelyet egy vagy több whitespace-karakter, majd egy felhasználónév követ.
Úgy döntesz, hogy megjelölöd az ilyen sorokat.

Valósítsd meg a `tag_with_user_name/1` függvényt, amely feldolgozza a naplósorokat:

- A `"User"` stringet nem tartalmazó sorok változatlanok maradnak.
- A `"User"` stringet tartalmazó sorok esetében a sor elé írd a `[USER]` előtagot, majd utána a felhasználónevet.

```elixir
LogParser.tag_with_user_name("[INFO] User Alice created a new project")
# => "[USER] Alice [INFO] User Alice created a new project"
```

Feltételezheted, hogy:

- A `"User"` string minden előfordulását egy vagy több whitespace-karakter és a felhasználónév követi.
- Soronként legfeljebb egy `"User"` string fordul elő.
- A felhasználónevek nem üres stringek, amelyek nem tartalmaznak whitespace-t.
