# A fogalomról

A Pythonban az [`if`][if statement], `elif` (_az „else and if” összevonása_) és `else` utasításokkal [szabályozhatod a végrehajtás menetét][control flow tools], és döntéseket hozhatsz a programodban.
A sok más programozási nyelvtől eltérően a Python 3.9-es és annál korábbi verziói nem kínálnak formális case-switch utasítást, helyette több `elif` utasítással lehet hasonló célt elérni.

A Python 3.10 egy `pattern matching` nevű, másfajta case-switch utasítást vezetett be, amelyet egy másik fogalomban tárgyalunk majd külön.

A feltételes utasítások olyan kifejezéseket használnak, amelyek `True` vagy `False` értékre jutnak, akár úgy, hogy közvetlenül egy `bool` értéket adnak vissza, akár úgy, hogy [„truthy” vagy „falsy”][truth value testing] módon értékelődnek ki.


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

Ha az `if` mellé egy opcionális `else` kódblokkot írsz, az akkor fut le, amikor az eredeti `if` feltétel `False` értékű:

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

Az `elif` több vizsgálatot és elágazást tesz lehetővé.

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

A [Boolean-műveletek][boolean operations] és az [összehasonlítások][comparisons] feltételes utasításokkal kombinálva bonyolultabb vizsgálatokat tesznek lehetővé:


```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...
...     return say
        
>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```

Alternatívaként a fenti példa átírható úgy is, hogy csak `if` utasításokat használunk benne, `returns`-szel kiegészítve.
Az ilyen átírás azonban elrejtheti, hogy a feltételek szándék szerint [_egymást kizáróak_][mutually-exclusive], és a jövőben hibákhoz vagy karbantartási problémákhoz vezethet.


```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         return 'FizzBuzz!'
...     if number % 5 == 0:
...         return 'Buzz!'
...     if number % 3 == 0:
...         return 'Fizz!'
...
...     return str(number)

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```


A feltételes utasítások egymásba is ágyazhatók.


```python
>>> def driving_status(driver_age, test_score):
...     if test_score >= 80:
...         if 18 > driver_age >= 16:
...             status = "Student driver, needs supervision."
...         elif driver_age == 18:
...             status = "Permitted driver, on probation."
...         elif driver_age > 18:
...             status = "Fully licensed driver."
...     else:
...         status = "Unlicensed!"
...
...     return status


>>> driving_status(63, 78)
'Unlicensed!'

>>> driving_status(16, 81)
'Student driver, needs supervision.'

>>> driving_status(23, 80)
'Fully licensed driver.'
```

## Feltételes kifejezések, avagy „ternáris operátorok”

Bár a Pythonban nincs külön `?` ternáris operátor, lehetőség van egysoros `conditional expressions` írására.
Ezek formája a következő: `<value if True> if <conditional test> else <value if False>`.
Mivel ezek a kifejezések nehezen olvashatóvá válhatnak, érdemes ezt az egysoros formát csak akkor használni, ha rövidíti a kódot és segíti az olvashatóságot.


```python
>>> def just_the_buzz(number):
...     return 'Buzz!' if number % 5 == 0 else str(number)
    
>>> just_the_buzz(15)
'Buzz!'

>>> just_the_buzz(7)
'7'
```

## Truthy és Falsy

A Pythonban bármely objektum [igazságérték][truth value testing] szempontjából vizsgálható, ezért feltételes utasításban, összehasonlításban vagy Boolean-műveletben is használható.
Az így kiértékelt objektumokat „truthy” vagy „falsy” értékűnek tekintjük, és `boolean context`ben használjuk őket.

```python
>>> def truthy_test(thing):
...     if thing:
...         print('This is Truthy.')
...     else:
...         print("Nope. It's Falsy.")


# Empty container objects are considered Falsy.
>>> truthy_test([])
"Nope. It's Falsy."

>>> truthy_test(['bear', 'pig', 'giraffe'])
'This is Truthy.'

# Empty strings are considered Falsy.
>>> truthy_test('')
"Nope. It's Falsy."

>>> truthy_test('yes')
'This is Truthy.'

# 0 is also considered Falsy.
>>> truthy_test(0)
"Nope. It's Falsy."
```
