# Bevezetés

## Reguláris kifejezések

A Gleam reguláris kifejezései a **PCRE** specifikációt (**P**erl **C**ompatible **R**egular **E**xpressions) követik, akárcsak más népszerű nyelvek, például a Java, a JavaScript vagy a Ruby.

A `gleam_regexp` csomag `gleam/regexp` modulja függvényeket kínál a reguláris kifejezésekkel való munkához.

~~~~exercism/note
Ez a feladat feltételezi, hogy már ismered a reguláris kifejezések szintaxisát, beleértve a karakterosztályokat, a kvantorokat, a csoportokat és az elfogásokat.

Ha fel szeretnéd frissíteni a reguláris kifejezésekkel kapcsolatos tudásodat, nézz meg egyet ezek közül a források közül: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

A reguláris kifejezések létrehozásának leggyakoribb módja a `regexp.from_string` függvény használata.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

A reguláris kifejezést létrehozó függvények hibát adnak vissza, ha a reguláris kifejezés szintaxisa érvénytelen, ezért itt egy let-assertion biztosítja, hogy a reguláris kifejezés érvényes legyen.

A `regexp.check` függvénnyel ellenőrizheted, hogy egy reguláris kifejezés illeszkedik-e egy stringre.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### Elfogások

Ha reguláris kifejezéssel szeretnél részstringeket elfogni, a `regexp.scan` függvénnyel kaphatod meg a találatok listáját.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### Módosítók

Egy reguláris kifejezés viselkedését módosíthatod, ha a `regexp.compile` függvénnyel hozod létre, és beállításokat adsz át neki.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
