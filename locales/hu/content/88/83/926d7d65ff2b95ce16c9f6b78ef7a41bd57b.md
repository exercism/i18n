# Számok

A Crystalnek van egy `Number` típusa, amely az összes numerikus típus alapja.
A `Number` típusnak két fő altípusa van: [`Int`][int] és [`Float`][float].

Az `Int` az „integer” rövidítése, és egész számokat jelöl.
Az `Int` lehet negatív és pozitív is, tizedespont nélkül.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

A `Float` tizedesponttal rendelkező számokat jelöl.
A `Float` értékek is lehetnek negatívak és pozitívak.

```crystal
10.5.class
# => Float64
```

## Konvertálás `Int` és `Float` között

A 'to_i' és 'to_f' metódusokkal `Int` és `Float` között konvertálhatsz.
`Float`-ból `Int`-té alakításkor a számot lefelé kerekítjük.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Aritmetikai operátorok

Az `Int` és `Float` értékeken használhatod az [alapvető aritmetikai operátorokat][math].
Az operátorok: `+`, `-`, `*`, `/` és `%`.
Ezekkel az operátorokkal az `Int` és `Float` értékeket vegyesen használhatod.

### Összeadás, kivonás és szorzás

A `+` operátor az összeadásra, a `-` a kivonásra, a `*` pedig a szorzásra szolgál.

| Operátor | Példa          |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Osztás

Az osztást számok elosztására használjuk.
Az osztásra a `/` operátort használjuk.
Az eredmény mindig `Float` lesz.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Egyes programozási nyelvekben a nullával való osztás eredménye hiba.

A Crystalben nullával osztva az eredmény `Infinity` vagy `-Infinity`.
Az egyetlen kivétel a nulla nullával való osztása, aminek eredménye `NaN` (nem szám).
Az `Infinity` és a `NaN` a `Float` típus különleges értékei.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### Moduló

A moduló az osztás maradékának meghatározására szolgál.
A `%` operátor a modulóhoz használatos.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Ha moduló közben nullával osztasz, az `DivisionByZeroError` hibát eredményez.
Ez eltér a normál osztástól.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Kerekítés

A `round` metódus egy opcionális argumentumot fogad: hány tizedesjegyre kerekítsen.
Alapértelmezésben a tizedesjegyek száma 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## Műveleti sorrend és zárójelek

A Crystal lehetővé teszi a zárójelek (`()`) használatát, amelyekkel csoportosíthatod a kifejezéseket.
Ez akkor hasznos, ha meg akarod változtatni a műveletek sorrendjét.

Ha több aritmetikai operátort használsz, a műveleti sorrend ugyanaz, mint a matematikában, más néven [PEMDAS][pemdas].
A sorrend a következő: zárójelek (`()`), hatványozás (`**`), szorzás (`*`) és osztás (`/`), végül összeadás (`+`) és kivonás (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
