# Bevezetés

A Cairo okos mutatói olyan fejlett adatszerkezetek, amelyek biztonsági funkciókkal egészítik ki a hagyományos mutatókat, így biztonságos és hatékony memóriakezelést tesznek lehetővé, és megelőzik az olyan gyakori problémákat, mint a nullmutatók dereferálása vagy a nem inicializált memória elérése.

## Mi az az okos mutató?

Az okos mutató úgy viselkedik, mint egy hagyományos mutató, de nyomon követi a tulajdonjogot, és biztonságos memóriahozzáférést garantál, így megelőzi az olyan problémákat, mint a null- vagy a lógó mutatók dereferálása.

## Az okos mutatók típusai

A Cairo több okos mutatótípust kínál, például `Box<T>` és `Nullable<T>`:

- **`Box<T>`**: Egy speciális memóriaszegmensben tárolja az adatokat, ideális nagy vagy dinamikus méretű adatokhoz. Lehetővé teszi a tulajdonjog átadását anélkül, hogy az adatokat másolni kellene.
- **`Nullable<T>`**: Vagy egy érvényes `T` típusú értékre, vagy `null`-ra mutat, így hasznos opcionális értékek kezeléséhez.

## Memóriabiztonság

Az okos mutatók segítenek megelőzni a nem biztonságos memóriahozzáféréseket: gondoskodnak róla, hogy a memória automatikusan felszabaduljon, amikor már nincs rá szükség, így csökkentik a memóriaszivárgás kockázatát.

### Példa: `Box<T>` használata rekurzív típusokhoz

Az olyan okos mutatók, mint a `Box<T>`, lehetővé teszik a rekurzív típusok biztonságos kezelését, például egy bináris fa esetében: hatékonyan foglalnak memóriát, és elkerülik a végtelen rekurziót.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## Teljesítményelőnyök

Az okos mutatók azzal javítják a teljesítményt, hogy hivatkozásokat adnak tovább az adatokra a nagy struktúrák másolása helyett, ezzel csökkentve a memóriaterhelést.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
