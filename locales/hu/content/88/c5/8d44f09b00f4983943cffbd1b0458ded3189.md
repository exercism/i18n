# Bevezetés

A Factor karakterei egész számok, azaz Unicode-kódpontok, így a numerikus `<`, `>`, `=` jelek közvetlenül kis- és nagybetűérzékeny rendezést adnak. A [`unicode`][unicode] szótár Unicode-tudatos predikátumokat és egykarakteres kis- és nagybetű-átalakítást ad hozzá.

## Karakterpredikátumok

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Kis- és nagybetű-átalakítás

A `ch>upper` és a `ch>lower` egyetlen karakteren végez kis- és nagybetű-átalakítást. A string-szintű `>upper` és `>lower` ezeket egy string minden karakterére alkalmazzák.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
