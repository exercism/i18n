# Utasítások

Ebben a feladatban takarékszámlákkal fogsz dolgozni. A takarékszámlád egyenlege minden évben a kamatláb alapján frissül. A kamatláb, amit a bankod ad, attól függ, mennyi pénz van a számládon (azaz mekkora az egyenleged):

- 3,213% negatív egyenleg esetén (ami negatív kamatot eredményez).
- 0,5% pozitív egyenleg esetén, ha az kevesebb mint `1000` dollár.
- 1,621% pozitív egyenleg esetén, ha az legalább `1000` dollár, de kevesebb mint `5000` dollár.
- 2,475% pozitív egyenleg esetén, ha az legalább `5000` dollár.

A kormány minden évben lehetővé teszi, hogy a pénzed egy részét adómentesen jótékony célra adományozd. Mivel rendes ember vagy, ha az egyenleged az év végén pozitív lesz, az adómentes százalékot megduplázod, és lefelé kerekíted a legközelebbi egész dollárra. Nem bánod, ha az adomány második fele után adót fizetsz.

Három feladat vár rád, amelyek mindegyike az egyenlegeddel és annak kamatlábával foglalkozik.

## 1. Számítsd ki a kamatlábat

Valósítsd meg az `interestRate` függvényt, amely a megadott egyenleg alapján kiszámítja a kamatlábat:

```fsharp
interestRate 200.75m
// => 0.5f
```

Vedd figyelembe, hogy a visszaadott érték `single` típusú.

## 2. Számítsd ki a kamatot

Valósítsd meg az `interest` metódust, amely a megadott egyenleg alapján kiszámítja a kamatot:

```fsharp
interest 200.75m
// => 1.00375m
```

Vedd figyelembe, hogy a visszaadott érték `decimal` típusú.

## 3. Számítsd ki az éves egyenlegfrissítést

Valósítsd meg az `annualBalanceUpdate` függvényt, amely a kamatlábat figyelembe véve kiszámítja az éves egyenlegfrissítést:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

Vedd figyelembe, hogy a visszaadott érték `decimal` típusú.

## 4. Számítsd ki, mennyi pénzt adományozz

Valósítsd meg az `amountToDonate` függvényt, amely az egyenleg és a kormány által engedélyezett adómentes százalék alapján kiszámítja, mennyi pénzt adományozz jótékony célra:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

Vedd figyelembe, hogy a visszaadott érték `int` típusú.
