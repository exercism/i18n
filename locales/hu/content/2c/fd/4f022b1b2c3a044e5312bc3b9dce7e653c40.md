# Feladatok

A feladatok olyan GitHub issue-k, amelyeknél szeretnénk, ha segítenél: a szöveg korrektúrázásától egészen a tanulófeladatok felépítéséig.
A weboldalon jelennek meg, és a GitHubon található megfelelő issue-kra linkelnek.
Minden feladatot egy vagy több tulajdonsággal látunk el, amelyeket az issue címkéiből veszünk.
A felhasználó ezután a tulajdonságaik alapján szűrheti a feladatokat.

## Címkék

Ahhoz, hogy egy issue feladatnak számítson, egy vagy több feladatspecifikus címkével kell ellátni.
A karbantartók így eldönthetik, hogy csak néhány issue jelenjen meg feladatként.

Minden feladatcímke formátuma: `x:<type>/<value>`, és öt feladattípust támogatunk:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### Az action típusú címke

Az `x:action/<value>` címkék azt írják le, milyen jellegű munkát fog végezni a közreműködő az issue-n.

| Címke                | Leírás                                 |
| -------------------- | -------------------------------------- |
| `x:action/create`    | Valami létrehozása a nulláról          |
| `x:action/fix`       | Egy issue javítása                     |
| `x:action/improve`   | Meglévő funkciók/tartalom fejlesztése  |
| `x:action/proofread` | Szöveg korrektúrázása                  |
| `x:action/sync`      | Tartalom szinkronizálása a legfrissebb verziójával |

### A knowledge típusú címke

Az `x:knowledge/<value>` címkék azt írják le, mennyi Exercism-tudásra van szüksége a közreműködőnek.

| Címke                      | Leírás                                     |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | Nem szükséges meglévő Exercism-tudás       |
| `x:knowledge/elementary`   | Kevés Exercism-tudás szükséges             |
| `x:knowledge/intermediate` | Meglehetősen sok Exercism-tudás szükséges  |
| `x:knowledge/advanced`     | Átfogó Exercism-tudás szükséges            |

### A module típusú címke

Az `x:module/<value>` címkék jelzik, hogy az Exercism melyik részén fog dolgozni a közreműködő.

| Címke                        | Leírás                      |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | Munka az elemzőkön          |
| `x:module/concept`           | Munka a fogalmakon          |
| `x:module/concept-exercise`  | Munka a tanulófeladatokon   |
| `x:module/generator`         | Munka a feladatgenerátorokon |
| `x:module/practice-exercise` | Munka a gyakorlófeladatokon |
| `x:module/representer`       | Munka a representereken     |
| `x:module/test-runner`       | Munka a tesztfuttatókon     |

### A size típusú címke

Az `x:size/<value>` címkék a közreműködőtől elvárt munka mennyiségét írják le.

| Címke            | Leírás                     |
| ---------------- | -------------------------- |
| `x:size/tiny`    | Nagyon kevés munka         |
| `x:size/small`   | Kevés munka                |
| `x:size/medium`  | Közepes mennyiségű munka   |
| `x:size/large`   | Sok munka                  |
| `x:size/massive` | Hatalmas mennyiségű munka  |

### A type típusú címke

Az `x:type/<value>` címkék azt írják le, milyen típusú munkát fog végezni a közreműködő.

| Címke            | Leírás                                                                                                                                                                                                          |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | Munka a folyamatos integrációval (pl. GitHub Actions workflow-k)                                                                                                                                                |
| `x:type/coding`  | Olyan kód írása, amely nem a tanulóknak szóló tartalom része. Ez általában a produkciós toolinghoz (pl. tesztfuttatók), a belső toolinghoz (generátorok) vagy az Exercism által karbantartott könyvtárakhoz kapcsolódó feladat. |
| `x:type/content` | Munka a tartalmon (pl. feladatok, fogalmak)                                                                                                                                                                     |
| `x:type/docker`  | Munka a Dockerfile-okon                                                                                                                                                                                         |
| `x:type/docs`    | Munka a dokumentáción                                                                                                                                                                                           |

## Igényelt és nem igényelt címkék

Ahhoz, hogy egy feladat elrejtődjön, mert valaki már dolgozik rajta, az issue-hoz hozzá lehet adni a `x:status/claimed` címkét.
