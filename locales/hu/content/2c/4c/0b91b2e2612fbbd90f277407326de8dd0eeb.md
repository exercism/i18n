# Utasítások

Leendő bűvészként Elyse-nek gyakorolnia kell néhány alapvető dolgot. Van egy pakli kártyája, amivel szeretne bűvészkedni.

Hogy a dolgokat egy kicsit könnyebbé tegye, csak az 1-től 10-ig terjedő kártyákat használja, így a kártyapaklija egy számokból álló belső táblával ábrázolható. Egy adott kártya pozíciója a tábla megfelelő sorának felel meg. Ez azt jelenti, hogy az 1. sor az első kártyára utal, a 2. sor a másodikra, és így tovább.

## 1. Kártya lekérése a pakliból

Egy kártya kiválasztásához add vissza a megadott pakli `position` indexén lévő kártyát.

```abap
data(stack) = value #( ( 1 ) ( 2 ) ( 4 ) ( 1 ) ).
data(card) = get_Item( stack = stack
                       position = 3 ).   " card = 4
```

## 2. Kártya cseréje a pakliban

Végezz egy kis mutatványt, és cseréld ki a `position` indexen lévő kártyát a megadott új kártyára.
Add vissza a módosított paklit.

```abap
data(stack) = value #( ( 1 ) ( 2 ) ( 4 ) ( 1 ) ).
data(new_Stack) = set_Item( stack = stack
                            position = 3 
                            replacement = 6 ).   
" new_Stack = 1, 2, 6, 1
```

## 3. Kártya beszúrása a pakli tetejére

Varázsolj elő egy kártyát úgy, hogy egy új kártyát szúrsz be a pakli tetejére.
Add vissza a módosított paklit.

```abap
data(stack) = value #( ( 5 ) ( 9 ) ( 7 ) ( 1 ) ).
data(new_Stack) = insert_Item_at_Top( stack    = stack
                                      new_Card = 8 ).   
" new_Stack = 5, 9, 7, 1, 8
```

## 4. Kártya eltávolítása a pakliból

Tüntess el egy kártyát úgy, hogy eltávolítod a megadott `position` helyen lévő kártyát a pakliból.
Add vissza a módosított paklit.

```abap
data(stack) = value #( ( 3 ) ( 2 ) ( 6 ) ( 4 ) ( 8 ) ).
data(new_Stack) = remove_Item( stack    = stack
                               position = 3 ).   
" new_Stack = 3, 2, 4, 8
```

## 5. A legfelső kártya eltávolítása a pakliból

Tüntess el egy kártyát úgy, hogy eltávolítod a pakli tetején lévő kártyát.
Add vissza a módosított paklit.

