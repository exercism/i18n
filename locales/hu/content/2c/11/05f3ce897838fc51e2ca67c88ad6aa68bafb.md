# Bemutatás

## Boolean

A PowerShellben az igaz és hamis értékek leírására a [`bool`][booleans] típus szolgál.
Ebben a típusban mindössze két érték létezik: `True` és `False`.
Az értékeket a `$` előtaggal kötheted változókhoz:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Az olyan [logikai operátorokkal][logical-operators], mint a `-and`, `-or` és `-not`, Boolean kifejezéseket kombinálhatsz és értékelhetsz ki.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## Konverzió és igazságértelmezés

A PowerShell minden típust képes implicit módon Booleanként kezelni.
A `[bool]` Boolean-típusgyorsítóval azonban explicit konverziót is végezhetsz.

Íme néhány általános szabály, amelyet a PowerShell más típusok Boolean értékekké alakítására használ:

$false:
- Üres stringek, például `''` vagy `""`
- Null értékek, például `$null`
- Nullát (0) felvevő numerikus típus

$true:
- Nem üres stringek
- Bármely más, nem gyűjtemény jellegű típus példányai

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

A gyűjteménytípusokból származó Boolean értékek átalakításának részletes szabályait [itt][collection-conversion] találod.
