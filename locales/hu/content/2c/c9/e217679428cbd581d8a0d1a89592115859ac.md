# Névjegy

A kód feltételes végrehajtásához használhatod az [`if/elif/else` kifejezéseket][conditional-expression]. Az `if/elif/else` kifejezésben használt feltétel(ek)nek `bool` típusúaknak kell lenniük. Az F#-ban nincs fogalma az _igazként értelmezett_ értékeknek.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

Mivel az `if/elif/else` kifejezés, hozzárendelhető egy névhez, vagy visszaadható egy függvényből.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

Minden ágnak ugyanazt a típust kell visszaadnia. Ha nem így teszel, fordítóhibát kapsz:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

Az `else` és az `elif` ágak elhagyhatók, de csak akkor, ha a visszaadott kifejezés típusa [`unit`][unit-type].

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

Az `if/else` kifejezés egyetlen sorba is írható. Ezt csak egyszerű `if` kifejezéseknél érdemes használni.

```fsharp
let y = if x > 5 then 10 else 20
```

[conditional-expression]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/conditional-expressions-if-then-else
