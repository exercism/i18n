# Utasítások

Ebben a feladatban a klasszikus Pac-Man játék néhány szabályát kell megvalósítanod.

Négy szabályt kell megvalósítanod, amelyek mind a játék állapotaihoz kapcsolódnak.

## 1. Határozd meg, hogy Pac-Man megeszik-e egy szellemet

Implementálj egy függvényt, amely bemenetként kapja, hogy van-e Pac-Mannél aktív energialabda, és hogy hozzáér-e egy szellemhez, majd Boolean értéket ad vissza arról, hogy meg tudja-e enni a szellemet. A függvény csak akkor adjon vissza `true`-t, ha Pac-Mannél aktív egy energialabda, és hozzáér egy szellemhez.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Határozd meg, hogy Pac-Man szerez-e pontot

Implementálj egy függvényt, amely bemenetként kapja, hogy hozzáér-e Pac-Man egy energialabdához, és hogy hozzáér-e egy ponthoz, majd Boolean értéket ad vissza arról, hogy szerzett-e pontot. A függvény akkor adjon vissza `true`-t, ha Pac-Man hozzáér egy energialabdához vagy egy ponthoz.

```lua
rules.score(true, true)
-- => true
```

## 3. Határozd meg, hogy Pac-Man veszít-e

Implementálj egy függvényt, amely bemenetként kapja, hogy van-e Pac-Mannél aktív energialabda, és hogy hozzáér-e egy szellemhez, majd Boolean értéket ad vissza arról, hogy veszít-e. A függvény akkor adjon vissza `true`-t, ha Pac-Man hozzáér egy szellemhez, és nincs aktív energialabdája.

```lua
rules.lose(false, true)
-- => true
```

## 4. Határozd meg, hogy Pac-Man nyer-e

Implementálj egy függvényt, amely bemenetként kapja, hogy Pac-Man megette-e az összes pontot, hogy van-e nála aktív energialabda, és hogy hozzáér-e egy szellemhez, majd Boolean értéket ad vissza arról, hogy nyer-e. A függvény akkor adjon vissza `true`-t, ha Pac-Man megette az összes pontot, és a 3. pontban megadott argumentumok alapján nem veszített.

```lua
rules.win(false, true, false)
-- => false
```
