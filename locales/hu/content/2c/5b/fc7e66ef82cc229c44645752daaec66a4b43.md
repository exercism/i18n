# Bevezetés

A stringekkel való munka gyakori feladat a programozásban.
Ezért a Swift számos metódust kínál a stringek manipulálására.
Ez a dokumentum a leggyakoribb stringmetódusok és tulajdonságok közül mutat be néhányat; némelyikük használatához importálni kell a Foundation keretrendszert.

## [`components(separatedBy:)`][components]

Amikor egy stringet részstringek tömbjére szeretnél bontani, használhatod a `components(separatedBy:)` metódust.
Ha például egy mondat minden szavát szeretnéd megkapni, elválasztóként használhatod a szóköz karaktert.

```swift
let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## [`hasPrefix(_:)`][hasPrefix], [`hasSuffix(_:)`][hasSuffix]

Amikor ellenőrizni szeretnéd, hogy egy string egy adott részstringgel kezdődik vagy végződik-e, használhatod a `hasPrefix(_:)` és `hasSuffix(_:)` metódusokat.
Mindkét metódus egy stringet vár argumentumként, és egy Boolean-értéket ad vissza, amely megmutatja, hogy a string a megadott részstringgel kezdődik vagy végződik-e.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## [`lowercased`][lowercased], [`uppercased`][uppercased], [`capitalized`][capitalized]

Amikor egy string kis- és nagybetűsségét szeretnéd megváltoztatni, használhatod a `lowercased`, `uppercased` és `capitalized` tulajdonságokat.
A `lowercased` tulajdonság egy új stringet ad vissza, amelyben minden karakter kisbetűs, az `uppercased` tulajdonság egy új stringet ad vissza, amelyben minden karakter nagybetűs, a `capitalized` tulajdonság pedig egy új stringet ad vissza, amelyben minden szó első karaktere nagybetűs.

```swift
let greeting = "hello, world!"
print(greeting.lowercased)  // Prints "hello, world!"
print(greeting.uppercased)  // Prints "HELLO, WORLD!"
print(greeting.capitalized) // Prints "Hello, World!"
```

## [`replacingOccurrences(of:with:)`][replacingOccurrences]

Amikor egy stringben egy részstring összes előfordulását le szeretnéd cserélni egy másik részstringre, használhatod a `replacingOccurrences(of:with:)` metódust.
Ez a metódus két stringet vár argumentumként: a lecserélendő részstringet és a helyére kerülő részstringet. Egy új stringet ad vissza, amelyben a megadott részstring minden előfordulása le van cserélve.

```swift
let greeting = "Hello, world!"
let newGreeting = greeting.replacingOccurrences(of: "world", with: "Swift")
print(newGreeting) // Prints "Hello, Swift!"
```

## [`joined(separator:)`][joined]

Ez nem a String típus, hanem az Array típus metódusa.
Amikor egy stringtömböt egyetlen stringgé szeretnél összefűzni egy megadott elválasztóval, használhatod a `joined(separator:)` metódust.
Ez a metódus egy stringet vár argumentumként, és egy új stringet ad vissza, amelyben a tömb minden eleme össze van fűzve, a megadott stringgel elválasztva.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
