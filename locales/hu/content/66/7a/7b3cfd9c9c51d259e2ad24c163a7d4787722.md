# Utasítások

Kezdő varázslóként Elyse-nek gyakorolnia kell néhány alapvető dolgot. Van egy pakli kártyája, amivel szeretne manipulálni.

Hogy egy kicsit megkönnyítse a dolgát, csak az 1-től 10-ig terjedő kártyákat használja, így a pakli egy számokból álló vektorral ábrázolható.
Egy adott kártya helye a vektorban lévő indexnek felel meg.

## 1. Kártya kivétele a pakliból

Egy kártya kiválasztásához add vissza a megadott pakli `position` indexén lévő kártyát.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. Kártya cseréje a pakliban

Egy kis kézügyességgel cseréld ki a `position` indexen lévő kártyát a megadott cserekártyára.
Add vissza a módosított paklit.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. Kártya beszúrása a pakli tetejére

Varázsolj elő egy kártyát úgy, hogy beszúrsz egy új kártyát a pakli tetejére.
Add vissza a módosított paklit.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. Kártya eltávolítása a pakliból

Tüntess el egy kártyát úgy, hogy eltávolítod a megadott `position` helyen lévő kártyát a pakliból.
Add vissza a módosított paklit.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. A pakli méretének ellenőrzése

Ellenőrizd, hogy a pakli mérete megegyezik-e a `stack_size` értékkel vagy sem.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. A pakli legfelső kártyájának eltávolítása

Tüntess el egy kártyát úgy, hogy eltávolítod a pakli legfelső kártyáját.
Add vissza a módosított paklit.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. Kártya beszúrása a pakli aljára

Varázsolj elő egy kártyát úgy, hogy beszúrsz egy új kártyát a pakli aljára.
Add vissza a módosított paklit.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. Kártya eltávolítása a pakli aljáról

Tüntess el egy kártyát úgy, hogy eltávolítod a pakli alján lévő kártyát.
Add vissza a módosított paklit.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
