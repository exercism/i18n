# Utasítások

Elyse, a leendő varázsló szeretné gyakorolni az alapokat. Van egy pakli kártyája, amit szeretne manipulálni.

Hogy egy kicsit könnyebb legyen a dolga, csak az 1-től 10-ig terjedő kártyákat használja.

## 1. Kártya lekérése a pakliból

Készítsd el a `getCard` függvényt, amely visszaadja a megadott pakli `index` pozícióján lévő kártyát. Ha az index nincs benne a pakliban, add vissza a Nothing értéket.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. Kártya megváltoztatása a pakliban

Készítsd el a `setCard` függvényt, amely visszaad egy paklit, amiben az `index` pozícióján lévő kártya a megadott új kártyára változott.
Ha az `index` nincs benne a pakliban, add vissza az eredeti paklit.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. Kártya hozzáadása a paklihoz

Készítsd el az `addCard` függvényt, amely visszaad egy paklit az új kártyával kiegészítve.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. Kártya eltávolítása a pakliból

Készítsd el a `removeCard` függvényt, amely visszaad egy paklit, amiből az `index` pozícióján lévő kártya el van távolítva.
Ha a megadott `index` nem érvényes index a pakliban, add vissza az eredeti paklit.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. A pakliban lévő páros kártyák megszámolása

Készítsd el az `evenCardCount` függvényt, amely megszámolja a pakliban lévő páros kártyákat.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
