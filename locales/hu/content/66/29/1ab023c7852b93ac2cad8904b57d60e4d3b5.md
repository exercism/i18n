# Bemutatás

A `java.time` csomag alapvető osztályai, például a `LocalDate` és a `LocalDateTime`, egyszerű metódusokat kínálnak időegységek hozzáadására és kivonására, a bonyolultabb dátumkorrekciókhoz azonban gyakran kifinomultabb logika kell (például meg kell keresni „a hónap második keddjét” vagy „az év utolsó napját”).

Erre a célra a `java.time.temporal` csomag biztosítja a [`TemporalAdjuster`][temporaladjuster-docs] funkcionális interfészt.
Ez egy temporal objektum (például egy `LocalDate`) módosításának stratégiáját írja le.
A [`TemporalAdjusters`][temporaladjusters-docs] (figyeld meg a többes számú „s”-t) segédosztály statikus gyármetódusokat tartalmaz, amelyek sok gyakori, előre definiált módosítót kínálnak.

## A TemporalAdjusters használata

Az olyan temporal objektumoknak, mint a `LocalDate` és a `LocalDateTime`, van egy `with()` metódusuk, amely egy `TemporalAdjuster` példányt fogad.
Ez a metódus egy *új* temporal objektumot ad vissza, amelyen már érvényes a módosítás.

```exercism/note
A `with(TemporalAdjuster)` használata egy _új_ példányt ad vissza, és nem frissíti a meglévő példányt, mivel a `java.time` valamennyi temporal osztálya módosíthatatlan.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## Gyakori előre definiált módosítók

A `TemporalAdjusters` osztály sok hasznos statikus metódust kínál.
Íme néhány gyakori példa:

### A hét valamelyik napjának sorszámozott megtalálása

A `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` módosító egy adott hétköznap n-edik előfordulását keresi meg a hónapon belül.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### A hónap első/utolsó adott hétköznapjának megtalálása

A `firstInMonth(DayOfWeek dayOfWeek)` és a `lastInMonth(DayOfWeek dayOfWeek)` módosító a hónapon belül egy adott hétköznap első vagy utolsó előfordulását keresi meg.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### A hónap/év első/utolsó napjának megtalálása

Egyszerűbb módosítók keresik meg az aktuális hónap vagy év első vagy utolsó napját.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### Relatív módosítások (következő/előző)

Az olyan módosítók, mint a `next()`, a `previous()`, a `nextOrSame()` és a `previousOrSame()`, egy adott hétköznap következő vagy előző előfordulását keresik meg az aktuális dátumhoz képest.

- `next()`/`previous()`: kihagyja az aktuális dátumot, ha az egyezik.
- `nextOrSame()`/`previousOrSame()`: beleszámítja az aktuális dátumot, ha az egyezik.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Egyéni módosítók

Mivel a `TemporalAdjuster` egy [`@FunctionalInterface`][functionalinterface-docs], saját módosítókat is készíthetsz lambda-kifejezésekkel azokra az esetekre, amelyeket az előre definiált metódusok nem fednek le.
Az interfész egyetlen metódus implementálását írja elő: `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

Az egyéni módosítók hatékonyak, a `TemporalAdjusters` osztály előre definiált módosítói viszont a gyakori felhasználási esetek széles körét lefedik.
