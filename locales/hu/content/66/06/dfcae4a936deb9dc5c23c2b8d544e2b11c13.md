# Tuples

A [tuple][tuple] véges, rendezett elemlista, amely immutábilis.
A tuple megköveteli, hogy minden pozíciónak rögzített típusa legyen.
Ez pedig azt jelenti, hogy a fordító tudja, melyik pozíción milyen típus áll.
A tuple-ben használt típusok pozíciónként eltérőek lehetnek, de a típusokat fordítási időben ismerni kell.

## Tuple létrehozása

Attól függően, hogy a tuple értékeinek típusai lefordításkor értelmezhetők-e, a tuple többféleképpen hozható létre.
Ha az értékek fordítási időben ismertek, a tuple a tuple-literál szintaxissal hozható létre, ellenkező esetben explicit módon deklarálni kell.
Az is fontos, hogy az értékek típusai megegyezzenek a tuple-ben megadott típusokkal, és hogy az értékek száma megegyezzen a megadott típusok számával.
Íme egy példa a tuple-literál szintaxissal történő definiálásra:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

Arra is van lehetőség, hogy a `Tuple` osztály segítségével hozzunk létre tuple-t.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

Vagy explicit módon megadhatod annak a változónak a típusát, amelynek a tuple-t értékül adod.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

A tuple típusának explicit megadása azért lehet hasznos, mert így megadhatod, hogy egy pozíción uniótípus álljon.
Ez azt jelenti, hogy egy pozíción több típus is szerepelhet.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## Konverzió

### Tuple létrehozása tömbből

Egy tömbből a `Tuple` osztály `from` metódusával hozhatsz létre tuple-t.
Ehhez meg kell adni a tuple típusát.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### Konverzió tömbbé

A `to_a` metódussal alakíthatsz át egy tuple-t tömbbé.
A kapott tömb elemtípusa a tuple minden mezője típusának uniója.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

### A tuple-definíció rövidített formája

Létezik egy rövidítés az explicit tuple-típusok definiálására.
Ez pedig az, hogy a típusokat a tuple-literálon belülre írod.

```crystal
tuple : {Int32, String, Char} = {1, "foo", 'c'}
```

## Elemek elérése

A tömbökhöz hasonlóan a tuple-ök is nullától indexeltek, vagyis az első elem a 0. indexen van.
A tömbökkel ellentétben azonban minden elem típusa rögzített és fordítási időben ismert, ezért egy tuple indexelésekor az elem típusa a pozícióhoz kötött.
Egy tuple elemének eléréséhez a `[]` operátort használhatod.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

Egy másik különbség a tömbök elemeinek eléréséhez képest, hogy ha meg van adva az index, akkor a fordító ellenőrzi, hogy az index a tuple határain belül van-e.
Ez azt jelenti, hogy futásidejű hiba helyett fordítási idejű hibát kapsz.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

Ha viszont az indexet egy változóban tárolod, akkor a fordító fordítási időben nem tudja ellenőrizni, hogy az index a tuple határain belül van-e, és helyette futásidejű hibát ad.

## Rész-tuple

Egy tuple rész-tuple-jét úgy kaphatod meg, hogy a `[]` operátort egy tartománnyal használod.
A visszaadott érték egy új tuple, amely a megadott tartomány elemeit tartalmazza.
A tartományt fordítási időben kell megadni, különben a fordító nem tudja megállapítani a rész-tuple elemeinek típusát.
Ez azt jelenti, hogy a tartománynak tartomány-literálnak kell lennie, nem pedig egy változóhoz rendelt értéknek.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## Mikor használj tuple-t?

A tuple-ök akkor hasznosak, ha rögzített számú értéket szeretnél egy csoportba fogni, amelyek típusai fordítási időben ismertek.
Ennek az az oka, hogy a tuple-ök kevesebb memóriát igényelnek és gyorsabbak, mint a tömbök, mivel a tuple-ök immutábilisek.
Egy másik felhasználási eset, amikor egy metódusból több értéket adsz vissza.
Ez különösen akkor hasznos, ha az értékek különböző típusúak, mivel a tuple minden pozíciója más típusú lehet.

Tuple-t nem érdemes használni, ha olyan adatszerkezetre van szükség, amely nőhet vagy zsugorodhat, vagy amelyet gyakran kell módosítani.
