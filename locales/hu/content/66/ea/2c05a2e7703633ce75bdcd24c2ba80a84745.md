# Függvénytúlterhelés

A Lasagne feladatban láttuk, hogyan definiáljuk a függvényeket Swiftben a `func` kulcsszóval, amelyet zárójelbe zárt paraméternévlista követ, ahol ezek a nevek egy opcionális argumentumcímkét és egy paraméternevet tartalmaznak, amelyet típusmegjelölés követ, majd a függvény kapcsos zárójelbe zárt törzse. Például:

```swift
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Int {
  let sum = x + y
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let twentySix = add(6, and: 7, doubleResult: true)
// => 26
```

Két függvény Swiftben akkor számít különbözőnek, ha eltér a nevük, _vagy_ az alábbiak bármelyike igaz:

- Eltér a paramétereik száma
- Bármely külső argumentumcímke eltér
- Bármely paraméter típusa eltér

Tehát a fenti `add(_:and:doubleResult)` definíciója alapján az alábbi függvények mindegyike különbözőnek számít, és definiálhatók és használhatók ugyanabban a programban:

```swift
// Different number of parameters
func add(_ x: Int, and y: Int) -> Int {
  x + y
}

let eleven = add(5, and: 6)
// => 11

// Different parameter type
func add(_ x: Double, and y: Int, doubleResult: Bool) -> Double {
  let sum = x + Double(y)
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let twentySeven = add(6.5, and: 7, doubleResult: true)
// => 27.0

// Different argument label
func add(_ x: Int, and y: Int, doubleThat: Bool) -> Int {
  let sum = x + y
  if doubleThat {
    return sum * 2
  } else {
    return sum
  }
}
let thirteen = add(6, and: 7, doubleThat: false)
// => 13
```

A függvények akkor is különbözőnek számítanak, ha csak a visszatérési érték változik, bár sok esetben szükséges a fordítónak egy tippet adni típusmegjelölés formájában, hogy tudja, a függvény melyik változatát hívja meg.

```swift
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Double {
  let sum = Double(x + y)
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let thirty = add(6, and: 9, doubleResult: true)
// Error: Ambiguous use of 'add(_:and:doubleResult:)'

let thirty: Double = add(6, and: 9, doubleResult: true)
// => 30
```

De pusztán egy belső paraméternév megváltoztatása nem különböztet meg két függvényt.

```swift
func add(_ w: Int, and y: Int, doubleResult: Bool) -> Int {
  let sum = w + y
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}
// Error: Invalid redeclaration of 'add(_:and:doubleResult:)'
```
