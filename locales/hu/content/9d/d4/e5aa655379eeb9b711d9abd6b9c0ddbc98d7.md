# Utasítások

Ebben a feladatban egy módot valósítasz meg arra, hogy nyilvántartsd a helyi játéktermed legnépszerűbb játékának csúcspontszámait.

## 1. Játékosok hozzáadása a ranglistához

Ha játékost szeretnél hozzáadni a ranglistához, definiálj két `add_player!` metódust, amelyek a következő argumentumokat kapják:

- Az első argumentum a pontszámok szótára.
- A második argumentum a játékos neve stringként.
- A harmadik argumentum a pontszám egész számként.
  Ez az argumentum elhagyható; ha nem adsz meg értéket, a pontszám 0 legyen.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Játékosok eltávolítása a ranglistáról

Ha játékost szeretnél eltávolítani a ranglistáról, definiáld a `remove_player!` metódust, amely 2 argumentumot kap:

- Az első argumentum a pontszámok szótára.
- A második argumentum a játékos neve stringként.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Játékos pontszámának frissítése

Ha frissíteni szeretnéd egy játékos pontszámát úgy, hogy lecseréled a korábbi pontszámot, definiáld az `update_score!` metódust, amely 3 argumentumot kap:

- Az első argumentum a pontszámok szótára.
- A második argumentum annak a játékosnak a neve stringként, akinek a pontszámát frissíteni szeretnéd.
- A harmadik argumentum az a pontszám, amelyre a tárolt csúcspontszámot állítani szeretnéd.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Játékos pontszámának visszaállítása

Ha vissza szeretnéd állítani egy játékos pontszámát, definiáld a `reset_score!` metódust, amely 2 argumentumot kap:

- Az első argumentum a pontszámok szótára.
- A második argumentum annak a játékosnak a neve stringként, akinek a pontszámát vissza szeretnéd állítani.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. Játékosok listájának lekérése

Ha le szeretnéd kérni a játékosok listáját, definiáld a `players` metódust, amely 1 argumentumot kap:

- Az első argumentum a pontszámok szótára.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
