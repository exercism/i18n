# Utasítások

Ebben a feladatban egy autógyár termelését elemző kódot fogsz írni.

## 1. Számítsd ki az óránként legyártott sikeres autók számát

Az autók egy futószalagon készülnek.
A futószalagnak van egy bizonyos sebessége, ami változtatható.
Minél nagyobb a futószalag sebessége, annál több autó készül.
A futószalag sebességének a megváltoztatása azonban a sikeresen legyártott autók számát is befolyásolja, vagyis azokét, amelyek gyártása során nem történt hiba.

Valósíts meg egy függvényt, amely megkapja az óránként legyártott autók számát és a sikerességi arányt, majd kiszámítja az óránként sikeresen legyártott autók számát.
A sikerességi arány százalékban van megadva, `0` és `100` között:

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**Megjegyzés:** a visszatérési érték `float64` típusú legyen.

## 2. Számítsd ki a percenként legyártott sikeres autók számát

Valósíts meg egy függvényt, amely megkapja az óránként legyártott autók számát és a sikerességi arányt, majd kiszámítja, hogy percenként hány autó készül el sikeresen:

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**Megjegyzés:** a visszatérési érték `int` típusú legyen.

## 3. Számítsd ki a gyártás költségét

Egy autó önálló legyártása általában 10 000 dollárba kerül, függetlenül attól, hogy sikeres lesz-e vagy sem.
Egy kis tervezéssel viszont 10 autót együtt 95 000 dollárért lehet legyártani.

Például 37 autót a következőképpen lehet legyártani:
37 = 3 x tízes csoport + 7 egyedi autó

Tehát 37 autó költsége:
3\*95,000+7\*10,000=355,000

Valósítsd meg a `CalculateCost` függvényt, amely kiszámítja egy adott számú autó gyártási költségét, függetlenül attól, hogy sikeresek-e vagy sem:

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**Megjegyzés:** a visszatérési érték `uint` típusú legyen.
