# Kiegészítés az utasításokhoz

## Induktív típus definiálása

Ez a feladat elvárja, hogy a visszatérési érték egy [induktív típus][inductive] `Classification` legyen, amelyet neked kell definiálnod.

Ennek a típusnak rendelkeznie kell egy [BEq][beq] példánnyal, azaz lehetővé kell tennie a Boolean egyenlőségvizsgálatot, és egy [Repr][repr] példánnyal, azaz a típus értékei formázhatók megjelenítéshez.

A példánydeklarációkról [ezen az oldalon][instance] olvashatsz.
A Lean sok osztályhoz automatikusan tud [példányokat generálni][deriving].

## Altípusok

A `classify` függvény argumentuma egy `Positive` nevű [altípus][subtype]:

```
def Positive := { x : Nat // x > 0 }
```

Az altípusok egy adott típus azon elemeit reprezentálják, amelyek kielégítenek egy predikátumot.
A `Positive` a `Nat` `0`-nál nagyobb elemeit reprezentálja.

Egy altípus bármely eleme tekinthető egy párnak, amely az alaptípus egy értékéből és egy bizonyításból áll; a bizonyítás matematikai értelemben azt igazolja, hogy ez az érték kielégíti a megfelelő predikátumot.

Az altípusok a típus szintjén kényszerítik ki az invariánsokat, biztosítva, hogy hibás formájú értékeket ne lehessen létrehozni.
