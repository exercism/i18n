# Bevezetés

## Castolás

A castolás és a típuskonverzió két különböző módja annak, hogy egy kifejezést egyik adattípusból a másikba alakítsunk.

Egy kifejezést a `(<type>)` cast operátorral lehet egy másik típusra castolni.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Ha a típusok nem kompatibilisek, `InvalidCastException` kivétel keletkezik. Számok esetén ez azt jelenti, hogy a fogadó típus nem tudja ábrázolni a castolt értéket. Osztályok esetén az egyik típusnak a másikból kell származnia (ez a struktúrákra is triviálisan igaz).

A _castolás_ alternatívája a `is` operátort használó _típuskonverzió_. Ezt jellemzően referenciatípusokra és nullázható típusokra alkalmazzák.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Ha egy objektum pontos típusát kell megállapítanod, akkor az `is` lehet, hogy egy kicsit túl megengedő, mert igazat ad vissza egy osztályra és minden olyan osztályra és interfészre is, amelyből az közvetlenül vagy közvetve származik. Ebben az esetben a megoldást a `typeof` és az `Object.GetType()` jelenti.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
