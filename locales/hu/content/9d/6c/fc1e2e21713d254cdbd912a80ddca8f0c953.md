# Bemutatás

A [szó szerinti stringek][verbatim-strings] segítségével többsoros stringeket írhatsz. Egy @ jel vezeti be őket. String-interpolációval is használhatók: ehhez csak tegyél egy „\$” jelet a nyitó idézőjel elé.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
