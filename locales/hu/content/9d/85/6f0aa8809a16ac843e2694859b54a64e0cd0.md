# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít egy táblákat gyártó cégnek egyedi üzeneteket készíteni a tábláira.

## 1. Hozz létre egy sor hasznos stringet

Definiáld a következő konstans stringeket, amelyeket a táblák létrehozásához fogsz használni:

- `birthday`: Ez a "Birthday" értéket tárolja
- `valentine`: Ez a "Valentine's Day" értéket tárolja
- `anniversary`: Ez a "Anniversary" stringet tárolja

## 2. Hozz létre egy sor hasznos karaktert

Definiáld a következő konstans karaktereket, amelyeket a táblák létrehozásához fogsz használni:

- `space`: Ez a " " értéket tárolja (egyetlen szóköz)
- `exclamation`: Ez a "!" értéket tárolja

## 3. Fűzd össze a kifejezéseket üzenetekké

Valósítsd meg a `buildSign(for:name:)` függvényt, amely megkapja a `for` argumentumot, amelyben az első részfeladatban definiált három string egyike van, valamint a `name` argumentumot, amely egy string, és annak a személynek a nevét tartalmazza, akinek a tábla szól.
A tábla üzenetét összefűzéssel építsd fel, és ne felejtsd el újra felhasználni a már definiált konstansokat.
A függvény adja vissza a tábla üzenetét stringként.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Készíts ballagási táblát

Valósítsd meg a `graduationFor(name:year:)` függvényt, amely megkapja a `name` argumentumot, amely egy string, és annak a személynek a nevét tartalmazza, akinek a tábla szól, valamint a `year` argumentumot, amely egy egész szám, és a ballagás évét tartalmazza.
A tábla üzenetét template stringekkel építsd fel.
A függvény adja vissza a tábla üzenetét stringként.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Számítsd ki egy tábla költségét

Valósítsd meg a `costOf(sign:)` függvényt, amely megkapja a `sign` argumentumot, amely egy string, és a tábla üzenetét tartalmazza.
A tábla alapára 20 a megadott pénznemben. Ezenfelül minden betű 2-be kerül (a szóközöket is beleszámítjuk a számításba).
A függvény adja vissza a tábla költségét egész számként.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
