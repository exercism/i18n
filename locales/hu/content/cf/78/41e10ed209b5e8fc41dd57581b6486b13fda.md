# Bevezetés

## Switch utasítások

A Wikipédia a `switch` utasítást így írja le: „egy szelekciós vezérlési mechanizmus, amely lehetővé teszi, hogy egy változó vagy kifejezés értéke megváltoztassa a program vezérlési folyamát”.

A mechanizmus a következő kulcsszavakat használja: `switch`, `case`, `break` és `default`.

A legegyszerűbb formájukban egy primitív vagy string kifejezést vizsgálnak meg, és annak értéke alapján döntenek. Például:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

A legkifinomultabb formájukban megjelenik a lefelé kasztolás, `case <Type> <variable>:`, valamint az őrök (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
