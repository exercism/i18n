# Bevezetés

Ebben a feladatban feltételesen kell végrehajtanod a logikát. C#-ban erre a leggyakoribb megoldás az `if/else` elágazás használata:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

Az `if` elágazás feltételének `bool` típusúnak kell lennie. C#-ban nem létezik olyan fogalom, hogy _truthy_ érték.
