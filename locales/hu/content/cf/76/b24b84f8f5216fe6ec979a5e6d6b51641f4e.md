# Telepítés

## A PowerShell kurzus követelményei

Az Exercism PowerShell kurzushoz a következőknek kell telepítve lenniük a gépeden:

- PowerShell vagy Windows PowerShell Core
- A Pester teszt- és mock keretrendszer modulja telepítve

(Ui.: A PowerShell támogatása a kritikus javításokra korlátozódik. A PowerShell Core-t folyamatosan karbantartják, és szélesebb körű, platformok közötti támogatást nyújt.)

### A PowerShell telepítése

A PowerShell minden Windows 7 SP1-es és újabb Windows operációs rendszeren előre telepítve van.

A PowerShell legújabb verzióját és a telepítési útmutatót minden platformhoz (Linux, macOS és Windows) [itt][installation] találod.

A [PowerShell][source-code] forráskódja és kézi telepítése is elérhető.

### A Pester keretrendszer telepítése és frissítése

A [Pester][pester] a PowerShell tesztelési keretrendszere.
A 4.0.9-es verzió óta kompatibilis a PowerShell Core-ral Windows, Linux és MacOS alatt (néhány korlátozással)

A Windows 10-en előre telepítve van, de érdemes frissítened a következő PowerShell-parancs futtatásával:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

A későbbi frissítésekhez futtasd:

```PowerShell
Update-Module -Name Pester
```

Ha szükséges, további telepítési útmutató itt érhető el: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## IDE használata

Ha teljesebb tudású szerkesztési élményre vágysz, valószínűleg IDE-t érdemes használnod.
Ezek a legnépszerűbb IDE-k, amelyek támogatják a PowerShell-projektek készítését:

### Minden platformon

- [PowerShell ISE (Integrated Scripting Environment)][ise], a PowerShellhez tartozó beépített grafikus IDE (csak Windows alatt).
  A PowerShell ISE indításához írd be a `powershell_ise.exe` parancsot egy PowerShell-konzolba.
- [Visual Studio Code][vsc] a [PowerShell-bővítménnyel][vsc-extension].
  A Visual Studio Code segítségével a teszteket is futtathatod, és a kódodat is debugolhatod.
- [Sublime Text 3][sublime] a [PowerShell package][sublime-package] csomaggal.
