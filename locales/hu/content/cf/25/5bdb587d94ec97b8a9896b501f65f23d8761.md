# String-metódusok

A `String`-nek számos metódusa van, amelyekkel stringeket lehet módosítani.  
Ezeket a metódusokat magán a stringen hívjuk meg, és gyakran láncba fűzzük őket, hogy egyszerre több műveletet hajtsunk végre egy stringen.

Az alábbiakban a leggyakoribb metódusok közül sorolunk fel néhányat.
A metódusok teljes listáját a [`String` API dokumentációjában][string-api] találod.

## String#upcase & String#downcase

Az [`upcase`][upcase] metódus egy új stringet ad vissza, amelyben minden karakter nagybetűvé alakult.

```crystal
"hello".upcase
# => "HELLO"
```

A [`downcase`][downcase] metódus egy új stringet ad vissza, amelyben minden karakter kisbetűvé alakult.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

Néhány metódus ennél specifikusabb kis- és nagybetű-átalakítást végez.
Ez akkor lehet hasznos, ha egy stringet egy adott formátumba szeretnél átalakítani.
Íme a leggyakoribb metódusok listája:

| Metódus                           | Leírás                                                                                                             | Példa                                                |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | Az első betűt nagybetűvé, a többit kisbetűvé alakítja                                                             | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | Az aláhúzásjelet camelcase formára alakítja                                                                        | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | Ugyanaz, mint a String#camelcase, de az első karaktert kisbetűsen hagyja                                           | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | Minden karaktert kisbetűvé alakít, és aláhúzást szúr be egy kisbetű és egy nagybetű közé                          | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | Minden szó első betűjét nagybetűssé alakítja, a többit kisbetűvé                                                   | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

A Crystalben vannak metódusok egy string részeinek lecserélésére.
Ezeket [`sub`][sub] (_substitution_, azaz helyettesítés) és [`gsub`][gsub] (_global substitution_, azaz globális helyettesítés) néven ismerjük.

Ezek a metódusok első argumentumként stringet, char-t vagy regexet, második argumentumként pedig stringet vagy char-t fogadnak el.
Az első argumentum a string lecserélendő része, a második argumentum pedig a helyette beillesztett érték.
A `Char`-t és a regexet későbbi fogalmakban magyarázzuk el.

A `sub` metódus az első argumentum első előfordulását cseréli le a második argumentumra.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

A `gsub` metódus ugyanúgy működik, mint a `sub`, de az első argumentum összes előfordulását lecseréli a második argumentumra.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

A chomp és a strip egy string nem kívánt karaktereinek eltávolítására használható.

A [`chomp`][chomp] metódus alapértelmezés szerint eltávolítja a string végéről az utolsó `\r`, `\n` vagy `\r\n` karaktereket.
Ha a metódust argumentummal hívjuk meg, eltávolítja a megadott értéket a string végéről.
Ha az ténylegesen ott van a string végén.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

A [`strip`][strip] metódus alapértelmezés szerint a string elejéről és végéről minden whitespace karaktert eltávolít.
Ha a metódust argumentummal hívjuk meg, eltávolítja azt az argumentumot a string elejéről és végéről.
Ha az ténylegesen ott van a string elején vagy végén.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

A [`reverse`][reverse] metódussal egy stringet fordíthatsz meg.
Ez a metódus egy új stringet ad vissza, amelyben a karakterek fordított sorrendben vannak.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

Az [`index`][index] metódussal megkeresheted egy karakter indexét egy stringben.
Az `index` metódus argumentumként `String`-et, `Char`-t vagy regexet fogad.
Opcionális második argumentumként megadhatod azt az indexet, ahonnan a keresés induljon.
Az `index` metódus az argumentum első előfordulásának indexét adja vissza.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

A [`delete_at`][delete_at] metódussal eltávolíthatsz egy karaktert egy stringből.
A `delete_at` metódus argumentumként egy indexet vár, és eltávolítja az adott indexen lévő karaktert.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Az [`insert`][insert] metódussal egy stringet szúrhatsz be egy adott indexre.
Az `insert` metódus első argumentumként egy indexet, másodikként egy stringet vár.
Az `insert` metódus egy új stringet ad vissza, amelyben a második argumentum az adott indexre került beszúrásra.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
