# Bevezetés

A függvény segítségével kódot csoportosíthatsz egy újra felhasználható egységbe.
A `func` kulcsszóból, a függvény nevéből, valamint kerek zárójelben álló, vesszővel elválasztott, nulla vagy több paraméterből és azok típusából áll.

## Függvényparaméterek

Minden paraméternek explicit típusa kell legyen; a paramétereknél nincs típuskikövetkeztetés.
A paramétereknek nincs alapértelmezett értékük, ezért minden függvényparaméter kötelező.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

Az azonos típusú paramétereket együtt is deklarálhatod, egyetlen típusmegadás után.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Paraméterek és argumentumok

Nézzünk meg gyorsan két fogalmat, amelyet gyakran összekevernek: a `parameters` és az `arguments` szót.
A függvényparaméterek a függvény szignatúrájában definiált nevek, például a fenti `PrintGreetingName` függvény `greeting` és `name` paramétere.
A függvényargumentumok azok a konkrét értékek, amelyeket a függvény meghívásakor adunk át a függvény paramétereinek.
Például az alábbi példában a `"Hello"` és a `"Katrina"` azok az argumentumok, amelyeket a `greeting` és a `name` paraméternek adunk át:

```go
PrintGreetingName("Hello", "Katrina")
```

## Visszatérési értékek

A függvényparamétereket nulla vagy több visszatérési érték követi, amelyeknek szintén explicit típusa kell legyen.
Az egyetlen visszatérési értéket zárójel nélkül írjuk, a többit zárójelbe tesszük.
A függvények a `return` kulcsszóval adják vissza az értékeket a hívó kódnak.
Egy függvényben több `return` utasítás is lehet.
A függvény végrehajtása azonnal véget ér, amint eléri valamelyik `return` utasítást.
Ha egy függvény több értéket ad vissza, azokat vesszővel választjuk el.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Függvények meghívása

Egy függvényt úgy hívunk meg, hogy megadjuk a függvény nevét, és zárójelben minden paraméterhez átadunk egy argumentumot.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Nevesített visszatérési értékek és csupasz visszatérés

A paraméterekhez hasonlóan a visszatérési értékeket is elnevezheted.
Ha nevesített visszatérési értékeket használsz, egy argumentum nélküli `return` utasítás ezeket az értékeket adja vissza.
Ezt nevezik „csupasz” visszatérésnek.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
