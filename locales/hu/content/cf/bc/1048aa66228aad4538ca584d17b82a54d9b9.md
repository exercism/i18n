# Utasítások

Egy egyszerű online játékot készítesz, amelyben egy barátod kitalálhat egy titkos számot. Szeretnél valamilyen visszajelzést adni, de úgy, hogy egy tippel se áruld el a választ. Olyan függvényt kell kitalálnod, amely különböző válaszokat ad attól függően, hogyan viszonyul a tipp a titkos számhoz.

| Feltétel                                                      | Válasz         |
| ------------------------------------------------------------- | -------------- |
| Amikor a tipp megegyezik a titkos számmal                     | "Correct"      |
| Amikor a tipp eggyel több vagy eggyel kevesebb a titkos számnál | "So close"     |
| Amikor a tipp nagyobb a titkos számnál                        | "Too high"     |
| Amikor a tipp kisebb a titkos számnál                         | "Too low"      |
| Amikor nem érkezik tipp                                       | "Make a guess" |

Minden tipp és titkos szám egész szám.

## 1. Add meg a választ, amikor a tipp megegyezik a titkos számmal

Valósítsd meg a `compare/2` függvényt, amely két argumentumot kap, a `secret_number` és a `guess` értéket, és mindkettő egész szám.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. Add meg a választ, amikor a tipp nagyobb a titkos számnál

Módosítsd a `compare` függvényt, hogy válaszoljon azokra a tippekre, amelyek nagyobbak a titkos számnál.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. Add meg a választ, amikor a tipp kisebb a titkos számnál

Módosítsd a `compare` függvényt, hogy válaszoljon azokra a tippekre, amelyek kisebbek a titkos számnál.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. Add meg a válaszokat, amikor a tipp eggyel több vagy eggyel kevesebb a titkos számnál

Módosítsd a `compare` függvényt, hogy válaszoljon azokra a tippekre, amelyek közel vannak a titkos számhoz.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. Add meg a választ, amikor nincs tipp

Módosítsd a `compare` függvényt, hogy akkor is válaszoljon, ha nincs tipp.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
