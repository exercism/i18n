# Bevezetés

Az Elixir dinamikusan típusos nyelv, ami azt jelenti, hogy nem végez fordítási idejű típusellenőrzést. A típusspecifikációk ennek ellenére a dokumentáció egy formájaként használhatók.

Egy típusspecifikációt a `@spec` modulattribútummal adhatunk a függvényhez, közvetlenül a függvénydefiníció elé. A `@spec` után a függvény neve áll, majd zárójelben az összes argumentuma típusa, vesszővel elválasztva. A visszatérési érték típusát kettős kettőspont (`::`) választja el a függvény argumentumaitól.

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## Típusok

A leggyakrabban használt típusok többek között:

- Boolean-ok: `boolean()`
- stringek: `String.t()`
- számok: `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- listák: `list()`
- bármilyen típusú érték: `any()`

Néhány típus paraméterezhető is, például a `list(integer)` egész számok listája.

Típusként literálértékek is szerepelhetnek.

A típusok uniója a függőleges vonal (`|`) segítségével írható le. Például az `integer() | :error` vagy egy egész számot, vagy a `:error` atomliterált jelent.

A típusok teljes listája a hivatalos dokumentáció [„Typespecs” szakaszában][types] található.

## Argumentumok elnevezése

A típusspecifikációban az argumentumok el is nevezhetők, ami hasznos, ha több azonos típusú argumentumot kell megkülönböztetni. Az argumentum neve, amelyet kettős kettőspont követ, az argumentum típusa elé kerül.

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## Egyedi típusok

A típusspecifikációk nem korlátozódnak a beépített típusokra. Egyedi típusok a `@type` modulattribútummal definiálhatók. Egy egyedi típus definíciója a típus nevével kezdődik, amelyet kettős kettőspont, majd maga a típus követ.

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

Egy egyedi típus ugyanabból a modulból is használható, amelyben definiálták, vagy egy másik modulból.
