# Telepítés

A Standard ML-hez a *PolyML*-t fogjuk használni.

Ha Windows-t használsz, a telepítőt letöltheted innen: [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases).
A Linux, az OS X és a Free BSD általános utasításait a [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme) oldalon találod.

Ha forráskódból szeretnéd telepíteni, a folyamat meglehetősen egyszerű:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

Ha egyéni helyre szeretnéd telepíteni, például a `$HOME/.local` könyvtárba:

```sh
$ ./configure --prefix=$HOME/.local
```

Utolsó lépés:

```sh
$ make compiler
$ make install
```

Ellenőrizd, hogy helyesen települt-e:

```sh
$ poly
```

Ha megjelenik az értelmező, készen is vagy!
Ha nem, valószínűleg hozzá kell adnod a `$HOME/.local/bin` (vagy a `<you prefix>/bin`) mappát a `$PATH`-hoz.
