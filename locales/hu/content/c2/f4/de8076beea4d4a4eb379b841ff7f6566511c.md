# Reputáció

A reputáció az a rendszer, amely lehetővé teszi, hogy az emberek „bizalmat” szerezzenek az Exercism ökoszisztémájában.

A reputáció azt méri, hogy egy adott személy mennyit tett hozzá az Exercism-höz, akár a platformhoz való hozzájárulással (például szoftverek, feladatok és dokumentációk létrehozásával), akár a közösséghez való hozzájárulással (például mentorálással).

A reputációt nem lehet „elkölteni” vagy „felhasználni”. Bizonyos reputációs küszöbök elérésével viszont új jogosultságokhoz és új közreműködési lehetőségekhez juthatsz. Egyszerűen fogalmazva: minél több reputációval rendelkezik valaki, annál inkább úgy érezzük, hogy megbízhatunk benne, és így annál nagyobb hatalmat kap. A reputáció emellett nyilvánosan megtekinthető mutatója annak, hogy mennyit adtál az Exercism-nek.

## Cél

A reputációs rendszer célja:

1. A tanulók és mentorok közötti, növekedésközpontú interakciók maximalizálása
2. A mentorok közreműködési vágyának maximalizálása

## A reputáció megszerzése

A reputációt többféleképpen is meg lehet szerezni:

| Művelet                           | Reputáció |
| --------------------------------- | ---------- |
| Megoldás sikeres mentorálása      | 5          |
| Megoldás közzététele              | 1-3        |
| Feladat írása                     | 20         |
| Feladat frissítése                | 10         |
| Fogalom írása                     | 10         |
| Fogalom frissítése                | 5          |
| Pull request létrehozása          | 3-100      |
| Pull request áttekintése          | 1-20       |
| Pull request mergelése            | 1-5        |

### Megoldás sikeres mentorálása

Minden sikeresen mentorált megoldásért (vagyis amikor a mentorálási beszélgetés lezárult) `5` reputáció jár.

### Megoldás közzététele

Minden közzétett megoldásért a feladat nehézségétől függően jár reputáció:

| Címke    | Reputáció |
| -------- | ---------- |
| `easy`   | 1          |
| `medium` | 2          |
| `hard`   | 3          |

### Feladat írása

Minden olyan feladatért, ahol a felhasználó szerzőként szerepel, `20` reputáció jár.

### Feladat frissítése

Minden olyan feladatért, ahol a felhasználó közreműködőként szerepel, `10` reputáció jár.

### Fogalom írása

Minden olyan fogalomért, ahol a felhasználó szerzőként szerepel, `10` reputáció jár.

### Fogalom frissítése

Minden olyan fogalomért, ahol a felhasználó közreműködőként szerepel, `5` reputáció jár.

### Pull request létrehozása

Alapértelmezés szerint `12` reputáció jár, amikor mergelnek egy pull requestet, amelyet a felhasználó nyitott meg.

A pull request tartalmától függően a karbantartó több (vagy kevesebb) reputációt adhat azzal, hogy az alábbi címkék egyikét hozzáadja a pull requesthez:

| Címke           | Reputáció | Példák                                                                                                                                                                                                                                                                                                                                                              |
| --------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:rep/tiny`    | 3          | <ul><li>Egyetlen elírás vagy link javítása</li><li>Egy üres sor törlése vagy egy sortörés hozzáadása</li><li>Egyetlen kódkomment módosítása vagy hozzáadása</li></ul>                                                                                                                                                                                                 |
| `x:rep/small`   | 5          | <ul><li>Egyetlen teszteset, részfeladat vagy példa javítása</li><li>Több elírás vagy link javítása egyetlen fájlban</li><li>A tartalom tisztázása néhány sor hozzáadásával a fájlhoz</li></ul>                                                                                                                                                                          |
| `x:rep/medium`  | 12         | <ul><li>Egy feladat szinkronizálása a problem-specifications repóval (a módosításokkal együtt)</li><li>Egy vagy több teszteset hozzáadása a nulláról</li><li>Több fájl javítása egy feladatban</li><li>Mentorálási jegyzetek hozzáadása egy feladathoz a nulláról</li><li>Egy kisebb hiba javítása egy tesztfuttatóban, elemzőben vagy representerben</li><li>Elemzőkommentek hozzáadása egyetlen feladathoz</li></ul> |
| `x:rep/large`   | 30         | <ul><li>Új tanuló- vagy gyakorlófeladat hozzáadása</li><li>Új fogalomdokumentáció hozzáadása</li><li>Egy meglévő fogalom vagy feladat jelentős átdolgozása</li><li>Új CI-szkriptek vagy egyéb automatizálás hozzáadása</li></ul>                                                                                                                                 |
| `x:rep/massive` | 100        | <ul><li>Tesztfuttató, elemző, representer vagy generátor létrehozása a nulláról</li><li>Ezeknek az eszközöknek a jelentős refaktorálása</li><li>Jelentős dokumentáció létrehozása a nulláról (például közreműködési vagy tesztelési útmutatók)</li></ul>                                                                                                          |

A fenti példák durva támpontot adhatnak ahhoz, hogy mikor melyik címkét érdemes használni, de a karbantartók a saját belátásuk szerint dönthetnek.

- A becsült ráfordított időt úgy kell értelmezni, mint amennyi időt egy _karbantartó_ átlagosan egy PR elkészítésére fordítana.
- Ha egynél több címke van megadva, a legmagasabb reputációértékű címke határozza meg a járó reputációt.
- Ha egy pull request még nyitva van, (még) nem jár érte reputáció.
- Ha egy pull requestet _mergelés nélkül_ zártak le, nem jár érte reputáció.

_A visszafelé kompatibilitás érdekében a járó reputáció meghatározásához az `x:size` címkék használatát is támogatjuk._

### Pull request áttekintése

Minden olyan mergelt vagy lezárt pull requestért, amelyet a felhasználó áttekintett, `5` reputáció jár.

- Ha egy pull request még nyitva van, (még) nem jár érte reputáció.
- Az áttekintésért járó reputációt felhasználónként és pull requestenként csak egyszer adjuk.
- Aki a pull requestet megnyitotta, _nem_ kap reputációt a saját pull requestje áttekintéséért.

- A pull request áttekintéséért járó reputáció megváltozik, ha az alábbi címkék valamelyikét hozzáadják a pull requesthez:

  | Címke           | Reputáció |
  | --------------- | ---------- |
  | `x:rep/tiny`    | 1          |
  | `x:rep/small`   | 2          |
  | `x:rep/medium`  | 5          |
  | `x:rep/large`   | 10         |
  | `x:rep/massive` | 20         |

  _Nem_ lehet különböző reputációs „méretet” használni a pull request szerzőjének és áttekintőjének.
  Mindkettő ugyanazon az `x:rep` címkén alapul.

  Ha egynél több címke van megadva, a legmagasabb reputációértékű címke határozza meg a járó reputációt.

  _A visszafelé kompatibilitás érdekében a járó reputáció meghatározásához az `x:size` címkék használatát is támogatjuk._

### Pull request mergelése

Minden olyan pull requestért, amelyet a felhasználó mergelt, `1` reputáció jár.

- Ha egy pull request még nyitva van, (még) nem jár érte reputáció.
- Ha egy pull requestet _mergelés nélkül_ zártak le, nem jár érte reputáció.
- Aki a pull requestet megnyitotta, _nem_ kap reputációt a saját pull requestje mergeléséért.
- Ha a pull requesthez nem tartozik egyetlen áttekintés sem, helyette `5` reputáció jár.

### Issue nyitása

A pull requestekhez hasonlóan alapértelmezés szerint **nem jár reputáció** egy issue megnyitásáért.
A pull requestekkel ellentétben viszont reputációt csak a nagy vagy masszív issue-kért adunk.

Az issue tartalmától függően a karbantartó úgy dönthet, hogy reputációt ad, ha az alábbi címkék valamelyikét hozzáadja az issue-hoz:

| Címke           | Reputáció | Példák                                               |
| --------------- | ---------- | ---------------------------------------------------- |
| `x:rep/large`   | 30         | <ul><li>Teljesen kidolgozott tanulófeladat</li></ul> |
| `x:rep/massive` | 100        | <ul><li>Egy kurzus tantervének megtervezése</li></ul> |

A fenti példák durva támpontot adhatnak ahhoz, hogy mikor melyik címkét érdemes használni, de a karbantartók a saját belátásuk szerint dönthetnek.

- A reputációnak azt a ráfordítást kell tükröznie, amennyi energiát egy _karbantartó_ az issue létrehozásába fektetne.

- Ha egynél több címke van megadva, a legmagasabb reputációértékű címke határozza meg a járó reputációt.
