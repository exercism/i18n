# Bevezetés

A C++-os utazásunkat változókkal, függvényhívásokkal és megjegyzésekkel indítjuk.

## Megjegyzések

A megjegyzéseknek két fajtája van: egysoros és többsoros.
A fordító mindent figyelmen kívül hagy, ami ugyanabban a sorban a `//` után következik.
A többsoros megjegyzéseket C-stílusú megjegyzéseknek is nevezik.
Ezeket `/*` és `*/` veszi körül.
A kettő között lévő bármi szintén figyelmen kívül marad.

## Változók

A C++ típusos nyelv.
Minden típust ismerni kell fordítási időben, és általában explicit módon meg kell adnod őket.
Egy változó típusa nem változhat.
Egy `years` nevű egész típusú változót így deklarálhatsz:

```cpp
int years;
```

Jó gyakorlat a változókat deklarációkor inicializálni.
A C++ többféle mechanizmust kínál erre.
A kapcsos zárójeles változat jobban illeszkedik a modern C++-hoz, de az egyenlőségjeles változat is nagyon gyakori.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
A C++ megengedi inicializálatlan változók használatát.
Amíg a változó szándékosan nem kap értéket, addig nem definiált, és bármit tartalmazhat.
Hogy elkerüld a beállítás előtti használatból eredő hibákat és a nem definiált viselkedést, **mindig inicializálj**.
A nem definiált viselkedés a lehető legrosszabb pillanatban összeomlaszthatja a programodat, pedig korábban jól futott.
Ezt nem lehet elégszer hangsúlyozni: minden áron kerüld a nem definiált viselkedést.
~~~~

## Aritmetikai műveletek

Az olyan aritmetikai operátorok, mint a `*`, `+` vagy `-`, részei lehetnek egy kifejezésnek, például `3 * 2` vagy `tomatoes + potatoes`.

## Változók frissítése

A változóknak új értéket adhatsz, amíg megőrzik a típusukat:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## Függvények

A függvényeknek van nevük, visszatérési típusuk és (esetleg üres) paraméterlistájuk.
Egy `always_fortyseven` nevű függvény, amely mindig 47-et adna vissza, így nézne ki:

```cpp
int always_fortyseven() {
    return 47;
}
```

Itt van a `vip_fee`, amelynek egy paramétere van:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Vagy a `total_fee`, egy függvény három paraméterrel és egy másik függvény hívásával.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

A C++-ban a függvények nem a legutolsó utasítás értékét adják vissza, mint néhány más nyelvben.
A `return` kulcsszó szükséges ahhoz, hogy a kód leforduljon.

### Üres karakterek

Az üres karakterek a forráskód formázására szolgálnak, és szóközöket, tabulátorokat vagy sortöréseket tartalmaznak.
Mivel a fordító figyelmen kívül hagyja a felesleges üres karaktereket, használhatod őket a kódod tagolására.
Az üres karakterek okos használata javíthatja a kódod olvashatóságát.
Különböző formázási szabványok léteznek, de ezek mind megegyezésen alapulnak, és a fordító nem kényszeríti ki őket.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
