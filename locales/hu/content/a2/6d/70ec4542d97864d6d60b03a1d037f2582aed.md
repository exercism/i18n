# Bevezetés

## Stringek

A karakterek és a stringek alkotják az Elm szöveges ábrázolásának alapját.
A stringek karakterek listájaként foghatók fel, és a legtöbb `List` függvénynek megvan a megfelelője a `String` modulban.

### Karakterek

A `Char` típus egyetlen Unicode-karaktert jelöl egyszeres idézőjelek között, például `'a'`.
A `Char` modul predikátumfüggvényeket (`Char -> Bool`) kínál a karakter tulajdonságainak vizsgálatához: `isUpper`, `isLower`, `isAlpha` és `isAlphaNum`.
A modul emellett függvényeket kínál egy karakter átalakításához: `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, valamint a numerikus Unicode-értékével (`Int`) való oda-vissza alakításhoz a `toCode` és `fromCode` segítségével.

### Stringek

A `String` típus beépített ábrázolást nyújt a hatékony stringkezeléshez, és bármilyen Unicode-karakterekből álló sorozatot reprezentálhat, például "this is an Elm string."
A többsoros stringeket három kettős idézőjel jelöli, és tartalmazhatnak escapeletlen idézőjeleket és sortöréseket.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### String-függvények

A `String` modul tartalmazza az összes függvényt, amelyet az alábbi táblázat összefoglal.
Néhány a leggyakrabban használt függvények közül:

`cons : Char -> String -> String` egy karaktert fűz a string elejére.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` összefűz két stringet.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` felbont egy stringet stringek listájára a megadott elválasztónál.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` összefűz egy stringlistát a megadott elválasztóval.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` lecseréli egy adott részstring összes előfordulását.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` visszaadja a karakterek számát egy stringben.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` megpróbálja átalakítani a stringet `Just Int` típusúvá, és `Nothing` értéket ad vissza a nem megfelelően formázott stringek esetén.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` ellenőrzi, hogy a második string tartalmazza-e az elsőt.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` egy adott függvényt alkalmaz a string minden `Char` karakterére.
Vedd figyelembe, hogy a megadott függvénynek `Char`-ból `Char`-ba kell leképeznie.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
