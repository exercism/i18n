# Bevezetés

A tuple könnyed módja annak, hogy fix számú, tetszőleges típusú adatot fogjunk egy csoportba.
A tuple-nek nincs saját neve; ha nevet adunk egy adatszerkezetnek, akkor az `struct`-tá válik.
A tuple mezőinek nincs nevük; ezeket destrukturálással vagy pozíció szerint lehet elérni.

## Létrehozás

A tuple-t mindig tuple-kifejezéssel hozzuk létre:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

A tuple-nek tetszőleges számú eleme lehet.

## Elérés destrukturálással

A tuple elemeit destrukturálással is elérhetjük.
Ez nem jelent mást, mint hogy a tuple egyes elemeihez változóneveket rendelünk, és ezzel el is fogyasztjuk a tuple-t.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
