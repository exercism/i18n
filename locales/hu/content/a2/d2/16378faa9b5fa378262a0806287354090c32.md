# Névjegy

Az `Enum` egy nagyon hasznos modul, amely algoritmusok sorát kínálja az enumerable-ökkel való munkához. Többek között:

- rendezést ([`sort/2`][enum-sort/2], [`sort_by/2`][enum-sort_by/2]),
- szűrést ([`filter/2`][enum-filter/2]),
- csoportosítást ([`group_by/3`][enum-group_by/3]),
- számlálást ([`count/2`][enum-count/2])
- keresést ([`find/3`][enum-find/3]),
- minimum- és maximumértékek megkeresését ([`min/3`][enum-min/3], [`max/3`][enum-max/3]),
- redukálást ([`reduce/3`][enum-reduce/3], [`reduce_while/3`][enum-reduce_while/3]),

És még rengeteg mást! A teljes listát az [`Enum` modul dokumentációjában][enum-functions] találod.

## Enumerable

Általánosságban egy _enumerable_ minden olyan adat, amelyen végig lehet iterálni, azaz egy gyűjtemény. Elixirben enumerable minden olyan adattípus, amely megvalósítja az `Enumerable` [protokollt][exercism-protocols]. Ezek a következők:

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

Ne aggódj, ha még nem ismered mindet.

Bárki megvalósíthatja az `Enumerable` protokollt a saját egyedi adatszerkezetéhez.

## Redukálás

Az `Enum.reduce/2` segítségével a teljes enumerable-t egyetlen értékké _redukálhatod_. Ehhez egy speciális, _akkumulátornak_ nevezett változóra van szükség. Az akkumulátor az iterációk között hordozza a redukálás köztes állapotát. Emiatt ez az egyik legerősebb függvény, amikor enumerable-ökkel dolgozol. Sok más speciális függvény helyettesíthető az általánosabb `reduce`-dzsel. Például...

A maximális érték megkeresése:

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

Sőt, még a leképezés is (de ehhez utána meg kell fordítani az eredményt):

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## Map-ek leképezése

- A [`Map.new/2`][map-new] függvénnyel:
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- Az [`Enum.into/3`][enum-into] függvénnyel:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- Az [`Enum.map/2`][enum-map] függvénnyel:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
