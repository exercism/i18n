# Részletesen

A [struktúrák és az osztályok][structs-and-classes] a Swift programozás két elsődleges építőköve. Mindkettő arra szolgál, hogy a kapcsolódó adatokat és függvényeket önálló, egybefüggő funkcionális egységekbe csoportosítsuk. Valójában minden alapvető típus, amivel eddig dolgoztál, például az `Int`, a `Double` és a `Character`, valamint az olyan gyűjteménytípusok, mint az `Array`, a `String` és a `Dictionary`, struktúra. És amikor struktúrát vagy osztályt definiálsz, valójában egy új típust hozol létre a Swiftben, éppúgy, ahogy azokat a típusokat használtad.

Sok a hasonlóság a Swiftben a struktúrák és az osztályok között. Többek között mindkettő képes értékeket tárolni _tulajdonságokban_, és _metódusokkal_ nyújtani funkcionalitást.

Mindkettő nyújt ezen kívül még néhány olyan funkciót is, amelyekre ez a feladat nem tér ki.

## Struktúrák definiálása

A struktúrát a `struct` kulcsszóval definiálod, amelyet a létrehozandó típus neve követ, majd a törzs, kapcsos zárójelek közé zárva.

A törzs állhat tárolt tulajdonságokból, amelyeket ugyanúgy definiálunk, és amelyek ugyanúgy viselkednek, mint a hagyományos konstansok vagy változók.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}
```

## Példányok

Ahogy fentebb szó volt róla, egy struktúra definiálása csupán egy új _típus_ létrehozása. Ez mindössze egy tervrajz arról, hogyan fognak kinézni az adott típus értékei, de valójában nem hoz létre egyetlen ilyen típusú értéket sem, amivel dolgozhatnál.

Ahhoz, hogy létrehozz egy _példányt_ ebből a típusból, a típus nevét kell leírnod, utána pedig egy zárójelpárt.

```swift
let someStats = CharacterStats()
```

Ez létrehozza az ilyen típusú értékeket, ahol a tulajdonságok a definícióban megadott alapértelmezett értékekkel töltődnek fel.

A struktúráknál a Swift automatikusan biztosít egy _tagonkénti kezdőértéket_, ahol a struktúra tulajdonságainak értékeit a zárójelek között adhatod meg, ami felülírja a definícióban megadott alapértelmezett értékeket.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Tulajdonságok elérése

A struktúra tulajdonságai _pontjelöléssel_ érhetők el: az érték nevét egy pont (`.`) követi, majd a tulajdonság neve. Ha egy struktúra valamelyik tulajdonságának magának is vannak tulajdonságai, ezzel a pontjelöléssel ezeket az egymásba ágyazott tulajdonságokat is elérheted.

Ez a jelölés arra is használható, hogy lekérdezd a tulajdonság értékét, és ahol megengedett, meg is változtasd.

```swift
someStats.health
// => 0
someStats.health = 87.3
someStats.health
// => 87.3
```
