# Részletesen

A PowerShell egy dinamikus, implicit típusú (_de az [erősen típusos][strong typed] változókat is támogatja_) szkriptnyelv a Microsofttól, amely elsősorban a feladatok automatizálására és a konfigurációkezelésre összpontosít.

A PowerShell támogatja az imperatív, a funkcionális, az objektumorientált és akár a csővezeték-alapú programozást is.

A PowerShell a .NET platformra épült, és először 2006-ban jelent meg.
Minden modern Windows operációs rendszer alapértelmezés szerint tartalmazza, de Macre és Linuxra is telepíthető.


## Változók

A PowerShellben két gyakori módja van a változók definiálásának.

A változóneveknek a PowerShellben `$` jellel kell kezdődniük, és az értékadó operátorral (`=`) kötöd a változó nevét egy értékhez.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

A változó típusát kifejezetten is megadhatod, ha kényszeríteni vagy megkövetelni szeretnéd, hogy az érték egy bizonyos típusú legyen.
A PowerShell mindent megtesz, hogy az értéket az egyik típusból a másikba alakítsa, ha lehetséges.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### Konstansok

A konstansok a PowerShellben olyan változók, amelyeket a definiálásuk után **nem lehet megváltoztatni**, és **nem lehet eltávolítani** sem.
Ez vezet el minket a változók definiálásának második módjához: a `New-Variable` parancsmag használatához.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## Függvények

A függvényeket a PowerShellben a `function` kulcsszóval definiálod.
Minden függvénynek lehet nulla vagy több formális paramétere a `()` zárójelben, amelyet a függvény törzse követ, amely `{` jellel kezdődik és `}` jellel végződik.

```powershell
function Greeting {
    return "Hello!"
}
```

A PowerShell függvényei a `return` kulcsszóval explicit módon adhatnak vissza értéket, miután a `FuncName $Arg` szintaxissal meghívtad őket.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## Megjegyzések

Az egysoros megjegyzések a PowerShellben `#` jellel kezdődnek, és a sor végéig tartanak.
A megjegyzésblokkok a PowerShellben `<#` jellel kezdődnek és `#>` jellel végződnek.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
