# Bemutató

Mivel a Clojure funkcionális nyelv, a függvények első osztályú állampolgárok benne. Ez azt jelenti, hogy ugyanúgy átadhatók más függvényeknek és hozhatók létre más függvényekkel, mint bármilyen adat. A Clojure ráadásul rengeteg magasabb rendű függvényt kínál, amelyek meglévő függvényekből származtatnak újakat. Négy fontos esetet vizsgálunk meg itt: a `partial`, a `comp`, a `memoize` és a `juxt` függvényt. Ezek a függvényt előállító függvények a magasabb rendű függvények szélesebb csoportjába tartoznak, csakúgy, mint például a `map`, a `reduce`, az `apply` és a `complement` (hogy csak néhányat említsünk), amelyek meglévő függvényeken működnek.

## partial

Általánosságban, ha adott egy létező `my-function` függvény `p1, p2, ..., pN` paraméterekkel, akkor a paraméterei közül néhányat, mondjuk a `p1, p2, ..., pM` paramétert rögzíthetünk a `v1, v2, ..., vM` állandó értéken. Ezt úgy tesszük meg, hogy a `partial` függvényt a következőképpen alkalmazzuk: `(partial my-function v1 v2 ... vM)`.

Az eredmény egy új függvény, amely az eredeti `my-function` függvényt úgy alkalmazza, hogy közben a `p1=v1, p2=v2, ..., pM=vM` értéket rögzíti. Az új függvényünk bemenetként a maradék `pM+1, pM+2, ..., pN` paramétert veszi át, amelyek értékét a `partial` alkalmazásakor még nem adtuk meg:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Egyszerű példaként definiáljunk egy `inc-by-9` függvényt, amely a bemenetét mindig 9-cel, egy rögzített értékkel növeli. Egy ilyen függvényt így valósíthatunk meg:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Második példaként adott egy `generic-greetings` függvény, amely a köszönteni kívánt személy nevét használja fel egy nyitó és egy záró szöveges üzenet mellett:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

Majd a `partial` segítségével mindig egy adott köszöntőszöveget használunk:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

A `comp` segítségével tetszőleges számú függvényből készíthetünk kompozíciót. Általánosságban `N` függvény, `f1, f2, ..., fN` komponálása azt jelenti, hogy ezeket a függvényeket egymás után alkalmazzuk, mindig az előző függvény kimenetét adva át a következőnek. Matematikai jelöléssel ezt így írjuk le:

```
f1 (f2 (... fN(x)))
```

Clojure-ben ez ezzel egyenértékű:
```clojure
(f1 (f2 (... (fN x))))
```

A comp használatával olyan új függvényt hozhatunk létre, amely elvégzi helyettünk ezt a kompozíciót:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Példaként tegyük fel, hogy össze akarunk adni egy számsorozatot, majd az eredményt meg akarjuk szorozni 6-tal. Ezt így tehetjük meg:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

A `memoize` lehetővé teszi, hogy újra felhasználjuk egy adott bemenethez korábban kiszámított eredményeket. Ugyanarra a bemenetre a *memoizált* függvény ugyanazt az eredményt adja vissza, anélkül hogy újra ki kellene számolnia. Kihasználja azt a tényt, hogy a `clojure` függvények alapértelmezés szerint *referenciálisan transzparensek*: ugyanarra a bemenetre mindig ugyanazt a kimenetet állítják elő, így a korábbi számítások könnyedén újra felhasználhatók.

Hogy lássuk, hogyan működik ez, nézzünk egy mesterséges esetet, amelyben a függvény két másodpercet alszik, mielőtt előállítja a kimenetet. Így könnyedén össze tudjuk hasonlítani a *számítási időt* a `memoize` használata előtt és után.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

A `juxt` olyan függvényt állít elő, amely balról jobbra haladva alkalmazza a neki átadott függvényeket. Az eredmény egy vektor, amelynek komponensei az egyes függvények külön-külön kiszámított eredményei:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Egyszerű példaként állítsunk elő egy függvényt, amely kiszámítja x szorzatát egymást követő tényezőkkel, 2-től 5-ig:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
