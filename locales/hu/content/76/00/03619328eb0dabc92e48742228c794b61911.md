# Bevezetés

A Common Lispben a stringek [karakterek][concept-characters] [vektorai][concept-vectors].
Úgy írjuk le őket, hogy a karaktereket kettős idézőjelek közé zárjuk (_pl._ "Hello World!").

A `stringp` predikátum csak akkor ad vissza igazat, ha a megadott érték string.

A stringeket a `subseq` függvénnyel lehet részsztringekre bontani; a függvény a stringet, egy kezdőindexet, és opcionálisan egy záróindexet vár.
Az indexelés nullától kezdődik.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

A stringek egyenlőségét a `string=` hasonlítja össze.
Ha a karakterek kis- és nagybetű szerinti különbségét figyelmen kívül kell hagyni, akkor a `string-equal` használható.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

A stringek nagybetűsítése, kisbetűsítése és szókezdő nagybetűssé alakítása a `string-upcase`, a `string-downcase` és a `string-capitalize` függvénnyel végezhető el.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
