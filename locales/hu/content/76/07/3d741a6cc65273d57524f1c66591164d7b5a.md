# Részletesen

Egy `if/elif/else` kifejezéssel feltételesen hajthatsz végre logikát. Az F#-nak azonban van egy másik, hatékonyabb módja is erre: a [mintaillesztés][pattern-matching]. A mintaillesztéssel egy értéket egy vagy több _mintával_ tudsz összevetni. Ilyen minta például a [_konstansminta_][constant-patterns], amely egy értéket egy konstanssal vet össze (például `1` vagy `"hello"`).

Az F#-ban a mintaillesztés a `match` kulcsszóval történik:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Bár ez más nyelvek `switch` utasításaira hasonlít, a mintaillesztés igazán akkor mutatja meg az erejét, ha más mintákat is használsz. Ilyen minta például a [_változóminta_][variable-patterns], amellyel egy értéket rögzíthetsz:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

Bizonyos esetekben további feltételt szeretnél hozzáadni egy mintához. Ezt _őrfeltételnek_ (guard ág) nevezik, és a `when` kulcsszóval adhatod hozzá:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

Az őrfeltétel bármilyen érvényes kifejezés lehet, akár függvényhívás is.

A fenti példában nem minden lehetséges bemenethez tartozik illeszkedő minta. A fordító észleli ezt, és figyelmeztetést ír ki. Ezt [_kimerítő illesztésnek_][exhaustive-matching] nevezik. A figyelmeztetés megszüntetéséhez minden esetet le kell kezelni. Erre a [_helyettesítő mintát_][wildcard-pattern] használhatod, amely bármilyen értékre illeszkedik:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

Ne feledd, hogy a fordító a `when` feltételekből nem tudja megállapítani, hogy az illesztés kimerítő-e:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| i when i >= 0 -> "Positive number"

// Compiler warning
```

A mintaillesztés fentről lefelé haladva veti össze az értéket az egyes mintákkal, amíg nem talál egy illeszkedő mintát, és végre nem hajtja a hozzá tartozó logikát. A minták sorrendje számít! Ezért a helyettesítő mintának mindig az utolsónak kell lennie egy `match` kifejezésben.

Bár a mintaillesztés nagyon hatékony, az egyszerű feltételes logikát általában világosabban fejezheted ki `if/else` kifejezéssel:

```fsharp
let usingPatternMatching number =
    match number with
    | 0 -> "Zero"
    | _ -> "Non-zero"

let usingIfElse number = if number = 0 then "Zero" else "Non-zero"
```
