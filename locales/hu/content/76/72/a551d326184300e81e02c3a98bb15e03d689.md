# Return

Crystalben a metódusok az utolsó kifejezésük értékét adják vissza.
Néha azonban előfordul, hogy egy értéket már az utolsó kifejezés előtt vissza kell adnod.
Erre a `return` kulcsszót használhatod, ami az utána következő kifejezés értékét adja vissza.
A `return` kulcsszó után írt kód nem fut le.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
A `return` kulcsszót hagyd el, ha a metódus utolsó kifejezése az az érték, amit vissza kell adni.
~~~~
