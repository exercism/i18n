# Bevezetés

A JavaScript dinamikus nyelv, amely támogatja az objektumorientált, az imperatív és a deklaratív (például a funkcionális programozási) stílust.

## (Újra)értékadás

Néhány fő módja van annak, hogy értékeket rendelj nevekhez a JavaScriptben: változókat vagy konstansokat használhatsz. Az Exercism-ön a változókat mindig [camelCase][wiki-camel-case] írásmóddal írjuk, a konstansokat pedig [SCREAMING_SNAKE_CASE][wiki-snake-case] írásmóddal. Nincs hivatalos útmutató, amit követni kellene, és a különböző cégeknek és szervezeteknek más-más stílusútmutatójuk van. _Nyugodtan írd a változókat úgy, ahogy szeretnéd._ Ha úgy írod őket, ahogy a feladatok elő vannak készítve, az az előnye, hogy másképp lesznek kiemelve a webes felületen és a legtöbb IDE-ben.

A JavaScriptben a változókat a [`const`][mdn-const], a [`let`][mdn-let] vagy a [`var`][mdn-var] kulcsszóval definiálhatod.

Egy változó az élettartama során több különböző értékre is hivatkozhat, ha `let`-et vagy `var`-t használsz. Például a `myFirstVariable` sokszor definiálható és újradefiniálható az `=` értékadás operátorral:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

A `let`-tel és a `var`-ral ellentétben a `const`-tal definiált változóknak csak egyszer adhatsz értéket. Így definiálunk konstansokat a JavaScriptben.

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 Egy későbbi tanulófeladatban megvizsgáljuk és elmagyarázzuk a különbséget a _konstans_ értékadás / kötés és a _konstans_ érték között.

## Függvénydeklarációk

A JavaScriptben a funkcionalitás egységeit _függvényekbe_ zárjuk, és ha a függvények összetartoznak, általában ugyanabba a fájlba csoportosítjuk őket. Ezek a függvények fogadhatnak paramétereket (argumentumokat), és a `return` kulcsszóval _adhatnak vissza_ értéket. A függvényeket a `()` szintaxissal hívjuk meg.

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 A JavaScriptben _sok_ különböző módja van a függvénydeklarációnak. Ezek a többi mód másképp néz ki, mint a `function` kulcsszó használata. A kurzus igyekszik fokozatosan bevezetni őket, de ha már ismered őket, nyugodtan használhatod bármelyiket. A legtöbb esetben az egyik vagy a másik használata nem jobb vagy rosszabb.

## Más fájlok számára elérhetővé tétel

Ahhoz, hogy egy `function`-t, egy konstanst vagy egy változót elérhetővé tegyél _más fájlokban_, [exportálnod][mdn-export] kell őket az `export` kulcsszóval. Egy másik fájl ezután az `import` kulcsszóval [importálhatja][mdn-import] őket. Ezt modulrendszernek is nevezik. Erre remek példa, ahogyan az összes teszt működik. Minden feladathoz tartozik legalább egy fájl, például a `lasagna.js`, amely az _implementációt_ tartalmazza. Emellett van legalább egy másik fájl is, például a `lasagna.spec.js`, amely a _teszteket_ tartalmazza. Ez a fájl _importálja_ a nyilvános (azaz exportált) entitásokat, hogy tesztelje az implementációt:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
