# Névjegy

A `reduce` a Factor általános foldja: bejár egy szekvenciát, és végigvezet egy akkumulátort egy bináris quotation-ön, amely megkapja a futó akkumulátort és a következő elemet, majd előállítja az új akkumulátort.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

Egy egyedi kezdőértékkel a `reduce` olyan foldokat is kifejez, amelyekre a `sum` vagy a `product` nem képes. Például egy szekvencia legnagyobb értéke, egy alapértelmezett értékkel arra az esetre, ha minden elem alulmarad:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

A `0` kezdőérték részt vesz az összehasonlításban, így egy csupa negatív szekvencia is `0`-t ad eredményül, nem pedig a saját legkisebb értékét.

## `produce`: az unfold

A `reduce` duálisa a `produce` (a [`sequences`][sequences] szókészletben): ott, ahol a `reduce` *felemészt* egy szekvenciát, a `produce` *létrehoz* egyet. Egy predikátum-quotation a futó állapotot vizsgálja; amíg ez igaz értéket ad vissza, egy törzs-quotation állítja elő a következő elemet.

```
produce ( pred quot -- seq )
```

A `reduce` és a `produce` együtt használva alkotják a Factor fold/unfold párosát.

## Kumulatív redukciók

A [`math.statistics`][math.statistics] kumulatív családja a bemenettel azonos hosszúságú szekvenciát ad vissza, amelynek minden eleme az adott pozícióig (azt is beleértve) terjedő prefixen végzett redukció:

| szó           | futó művelet       |
|---------------|--------------------|
| `cum-sum`     | futó összeg        |
| `cum-product` | futó szorzat       |
| `cum-min`     | futó minimum       |
| `cum-max`     | futó maximum       |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

A kumulatív redukciók akkor hasznosak, amikor azt szeretnéd látni, *hogyan* alakult egy mennyiség végig a szekvencián, és nem csak a végső értékét. A láncolásuk is hasznos: egy kumulatív kimenete maga is egy szekvencia, amely készen áll rá, hogy egy másikba tápláld.

[math.statistics]: https://docs.factorcode.org/content/vocab-math.statistics.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
