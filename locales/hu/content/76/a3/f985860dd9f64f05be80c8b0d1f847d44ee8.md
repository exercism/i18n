# Bővebben

Egy struct vagy class _tárolt tulajdonságokat_ definiálhat. Ezek pontosan úgy jönnek létre és úgy viselkednek, mint a közönséges konstansok vagy változók, és az adott struct vagy class egy példányának részeként tárolódnak.

```swift
class GameCharacter {
  var health = 10
  let id = makeRandomID()
}

let character1 = GameCharacter()
let character2 = GameCharacter()

character1.health // => 10
character2.health // => 10

character1.health = 25

character1.health // => 25
character2.health // => 10

// This would trigger a compiler error due to id being a constant
// character2.id = 2
```
