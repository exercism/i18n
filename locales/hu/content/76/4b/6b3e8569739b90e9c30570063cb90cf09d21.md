# Névjegy

A C++-os utazásunkat a változókkal, a függvényhívásokkal és a kommentekkel kezdjük.

## Kommentek

A kommentek kétfélék lehetnek: egysorosak és többsorosak.
A fordító mindent figyelmen kívül hagy, ami ugyanabban a sorban a `//` után következik.
A többsoros kommenteket C-stílusú kommenteknek is nevezik.
Ezeket `/*` és `*/` veszi körül.
Minden, ami ezek közé kerül, szintén figyelmen kívül marad.

## Változók

A C++ egy típusos nyelv.
Minden típust ismerni kell fordítási időben, és általában explicit módon meg is kell adnod őket.
Egy változó típusa nem változhat meg.
Egy `years` nevű egész típusú változót így deklarálhatsz:

```cpp
int years;
```

Jó gyakorlat a változókat már a deklarálásukkor inicializálni.
A C++ többféle mechanizmust kínál erre.
A kapcsos zárójeles változat jobban illeszkedik a modern C++-hoz, de az egyenlőségjeles is nagyon elterjedt.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
A C++ valóban megengedi a nem inicializált változók használatát.
Amíg a változónak szándékosan nem adsz értéket, addig az nem definiált, és bármit tartalmazhat.
A használat előtti értékadás hiányából eredő hibák és a nem definiált viselkedés elkerüléséhez érdemes **mindig inicializálni**.
A nem definiált viselkedés a lehető legrosszabb pillanatban futtathatja össze a programodat, holott korábban hibátlanul futott.
Nem lehet elégszer hangsúlyozni: mindenáron kerüld a nem definiált viselkedést.
~~~~

## Aritmetikai műveletek

Az olyan aritmetikai operátorok, mint a `*`, `+` vagy `-`, részét képezhetik egy kifejezésnek, például `3 * 2` vagy `tomatoes + potatoes`.

## Változók frissítése

A változóknak újra adhatsz értéket, amíg megőrzik a típusukat:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## Függvények

A függvényeknek nevük, visszatérési típusuk és (esetleg üres) paraméterlistájuk van.
Egy `always_fortyseven` nevű függvény, amely mindig 47-et adna vissza, így nézne ki:

```cpp
int always_fortyseven() {
    return 47;
}
```

Íme a `vip_fee`, amelynek egy paramétere van:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Vagy a `total_fee`, egy függvény három paraméterrel, amely meghív egy másik függvényt.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

A C++-ban a függvények nem adják vissza az utolsó utasítás értékét, mint néhány más nyelvben.
A `return` kulcsszó kötelező ahhoz, hogy a kód leforduljon.

### Üres helyek

Az üres helyek a forráskód formázására szolgálnak, és ide tartoznak a szóközök, a tabulátorok és a sortörések.
Mivel a fordító figyelmen kívül hagyja a felesleges üres helyeket, ezekkel tagolhatod a kódodat.
Az üres helyek okos használata javíthatja a kódod olvashatóságát.
Többféle formázási szabvány létezik, de ezek mind megegyezésen alapulnak, és a fordító nem kényszeríti ki őket.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
