# Részletek

A [with nevű speciális forma][with] lehetőséget ad arra, hogy egy sor potenciálisan sikertelen lépésből álló folyamat „boldog útjára” összpontosíts, és a hibákkal később foglalkozz.

Tegyük fel, hogy több ellenőrzéssel szeretnéd érvényesíteni egy felhasználónevet. Ilyenkor a `case`-hez fordulhatsz:

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

Lehet, hogy most olvasható, de ha több egymásba ágyazott ellenőrzést adsz hozzá, egyre zavarosabb lesz. Ebben a helyzetben használd a `with`-et:

```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

Minden lépésnél, ha egy klóz illeszkedik, a lánc addig folytatódik, amíg a `do` blokk végre nem hajtódik. Ha egy illeszkedés meghiúsul, a lánc leáll, és a nem illeszkedő klózt adja vissza.

A láncban használhatsz őröket, valamint a `=` operátort a szokásos illesztésekhez.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

Végül lehetőséged van egy `else` blokk használatára, hogy elkapd a sikertelen illesztéseket, és módosítsd a visszatérési értéket.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

Az `else` olyan, mint egy `case` utasítás a `with` klóz bármely nem illeszkedő értékére. Az első illeszkedő értéket fogja használni.
