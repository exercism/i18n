# Bevezetés

## Változók

Emlékezz vissza arra, hogy a `jq` program _kifejezések csővezetéke_.
**A változóhozzárendelés** szabálya a következő: a _változóhozzárendelés_ egy olyan kifejezés, amely így néz ki:

```jq
... | expr as $varname | ...
```

### A szűrő kimenete a bemenet

Ahogy az _identitáskifejezés_ `.` esetében, a _változóhozzárendelés_ kimenete is ugyanaz, mint a bemenete.
A változó értékének beállítása mellékhatás.

Példa, amely megmutatja, hogy a hozzárendelés utáni `.` ugyanaz, mint a kezdeti bemenet:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### A változó scope-ja

A változó scope-ja „lexikális”: a változó a csővezeték hátralévő részében marad scope-ban.
A függvényekben definiált változók (a függvényekre később térünk rá) a függvényen belül „lokálisak”.

### A változók nevei

A változónak `$` jellel kell kezdődnie.
A változónév többi része egy **azonosító**: betűvel vagy aláhúzásjellel kezdődik, amelyet betűk, számok vagy aláhúzásjelek követnek.

### Destrukturáló hozzárendelés

A kézikönyvből:

> Egyetlen `as` kifejezéssel több változó is deklarálható, ha olyan mintát adunk meg, amely _illeszkedik a bemenet szerkezetéhez_ (ezt nevezik „destrukturálásnak”).

Példák:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

A változó nevének az _objektumkulcshoz_ igazítása egyszerűsítést kínál:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### Konstansok

Ahogy a fenti példa is mutatja, a változók kényelmesen használhatók konstansok tárolására.
Jobb nevet adni a konstansoknak, mint hagyni, hogy „mágikus számok” jelenjenek meg a kódban.

### Gyakran nincs szükség változókra

Gyakran olvashatóbb, ha elhagyjuk a változókat.

Nézzük meg, hogyan számítható ki egy számlista átlaga

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

összehasonlítva ezzel:

```jq
[2, 4, 8, 7] | add / length
```

Ez jól mutatja a `jq` egyik legerősebb tulajdonságát: a szűrő bemenetét _minden_ rész-kifejezés megkapja:

- a `[2,4,8,7]` bemeneti tömb átadódik az `add`-nek (amely úgy adja össze a számokat, hogy a `+` operátort minden elemre alkalmazza)
- _ezzel párhuzamosan_ a `[2,4,8,7]` a `length`-nek is átadódik
- amikor ezek a rész-kifejezések befejeződnek, az eredményeiket elosztjuk, így megkapjuk a bemeneti tömb számainak átlagát.

### `jq` operátorok, amelyekre szükséged lesz a tanulófeladatban

#### Alternatív operátor: `//`

Az `a // b` kifejezés `b`-t adja eredményül, ha `a` hamis vagy null, egyébként `a`-t adja.
Változó beállításánál ez nagyon hasznos egy alapértelmezett érték megadásához:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### Aritmetikai operátorok

- A `+`, `-`, `*` a szokásos numerikus összeadás, kivonás és szorzás operátorai.
