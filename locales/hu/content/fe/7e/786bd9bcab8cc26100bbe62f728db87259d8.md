# Utasítások

Ebben a feladatban egy módot valósítasz meg arra, hogy nyomon kövesd a helyi játéktermed legnépszerűbb játékának csúcspontszámait.

Hat függvényt kell megvalósítanod, amelyek többnyire egy csúcspontszámokat tároló objektum kezeléséhez kapcsolódnak.

## 1. Hozz létre egy új csúcspontszám-táblát

Írj egy `create_score_board` függvényt, amely létrehoz egy objektumot, ami csúcspontszám-táblaként szolgál.
Az objektum kulcsai a játékosok nevei lesznek, az értékek pedig a pontszámaik.
A tesztelés miatt eleve szeretnél egy bejegyzést is szerepeltetni az objektumban.
Ez a kezdeti bejegyzés `"The Best Ever"` játékosnévből és `1000000` pontszámból álljon.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Adj játékosokat a csúcspontszám-táblához

Ha játékost szeretnél hozzáadni a csúcspontszám-táblához, valósítsd meg az `add_player` függvényt.
Bemenetként egy csúcspontszám-táblát kap, és két paraméterre van szüksége: a játékos nevére és a játékos pontszámára.
A függvény az új játékossal kiegészített csúcspontszám-tábla objektumot adja vissza.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Ha a játékos már szerepel a táblán, a táblát változatlanul add vissza.

## 3. Távolíts el játékosokat a csúcspontszám-tábláról

Ha a játékosok megszegik a játékterem szabályait, kézzel távolítják el őket a csúcspontszám-tábláról.
Valósítsd meg a `remove_player` függvényt, amely bemenetként egy táblát és egy paramétert kap: az eltávolítandó játékos nevét.
A függvény eltávolítja az adott játékos bejegyzését a tábláról, és az új táblát adja vissza.
Ha a játékos eleve nem szerepelt a táblán, a táblával nem történik semmi; változatlanul kell visszaadni.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Növeld egy játékos pontszámát

Ha egy játékos újabb játékot fejez be a játékteremben, bizonyos mennyiségű pont hozzáadódik a táblán szereplő korábbi pontszámához.
Valósítsd meg az `update_score` függvényt, amely bemenetként egy csúcspontszám-táblát kap, és két paraméterre van szüksége: a játékos nevére és a hozzáadandó pontszámra.
A függvény a frissítés elvégzése utáni csúcspontszám-táblát adja vissza.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Ha a játékos még nem szerepelt a táblán, e függvény adja hozzá.

## 5. Alkalmazd a hétfői bónuszpontokat

A játékterem hétfőnként külön csúcspontszám-táblát vezet.
A nap végén a táblán szereplő minden játékos 100 további pontot kap.

Valósítsd meg az `apply_monday_bonus` függvényt.
A függvény minden, a táblán szereplő játékoshoz hozzáadja a bónuszpontokat.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Határozd meg a teljes pontszámot

A különböző játéktermek versengenek egymással, hogy eldőljön, kinek vannak a legjobb játékosai.
A legnagyobb összpontszámot elérő játékterem nyeri el a megtiszteltetést.

Írj egy `total_score` függvényt.
Bemenetként egy csúcspontszám-táblát kap, és az összes játékos pontszámának összegét adja vissza.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
