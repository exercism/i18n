# Lebegőpontos számok

A PHP-ban a lebegőpontos számok a valós számok egy részhalmazának ábrázolására szolgálnak.
Egy vagy több számjegyből állnak, amelyeket tizedesjel választ el egymástól.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## Gyakori buktatók

Nem minden szám és aritmetikai művelet végezhető el lebegőpontos számokkal.
Ha dollárt és centet lebegőpontos számokkal ábrázolunk, az gyakran kerekítési hibákhoz vezet.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
