# Áttekintés

## Összehasonlító operátorok

Az [összehasonlító operátorok][comparison-operators] értékek összehasonlítására szolgálnak, és `true` vagy `false` értéket adnak vissza.
Ezekhez az operátorokhoz két, azonos típusú érték kell az összehasonlításhoz.
Ha az értékek típusa nem egyezik, a fordító hibát jelez.
Íme az összehasonlító operátorok listája, és egy-egy példa arra, mikor adnak `true` értéket:

| Operátor | Leírás                | Példa   |
| -------- | --------------------- | ------- |
| ==       | egyenlő               | 1 == 1  |
| !=       | nem egyenlő           | 1 != 2  |
| <        | kisebb, mint          | 4 < 5   |
| <=       | kisebb vagy egyenlő   | 4 <= 4  |
| >        | nagyobb, mint         | 3 > 1   |
| >=       | nagyobb vagy egyenlő  | 2 >= 2  |

## If és else elágazások

A [feltételes utasítás][conditional-statement] segítségével olyan kódot futtathatsz, amely egy `true` vagy `false` értékű feltételtől függ.
A legalapvetőbb feltételes utasítás az [elágazás][if], amely akkor futtat kódot, ha a feltétel `true`.
Egy elágazás deklarálásához az `if` kulcsszót használod, utána a feltétel, majd a kapcsos zárójelbe írt végrehajtandó kód következik.

```swift
let wheelCount = 4
if wheelCount == 4 {
  print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Az if kombinálható az else kulcsszóval, hogy akkor futtasson kódot, amikor a feltétel `false`.
Az else elágazást mindig if elágazással együtt kell használni, önmagában nem állhat.
Egy else elágazás deklarálásához az `else` kulcsszót egy if elágazás záró kapcsos zárójele után írod, majd a kapcsos zárójelbe írt végrehajtandó kód következik.

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
  print("You will need an umbrella")
} else {
  print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Az elágazások else if segítségével láncolhatók is, hogy több feltételt ellenőrizhess.
Ugyanazt az elvet követi, mint egy elágazás definiálása, csak itt a kulcsszó `if` helyett `else if`.
Ahogy az elágazásokhoz hasonlóan ezeknek sem kell else elágazás a helyes működéshez, de ha kell, lehet.

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange or apple")
}
// Prints "Your favorite fruit is an apple"
```

## If-kifejezés

Az elágazások kifejezésként is használhatók, hogy értéket rendelj egy változóhoz.
Az if blokk utolsó utasítása lesz az if-kifejezés értéke.
Ez akkor lehet hasznos, ha egy változónak egy feltétel alapján szeretnél értéket adni.

```swift
let CpuBits = 32
let largest = if CpuBits == 64 {
  "x86_64"
} else {
  "x86_32"
}

print(largest)
// Prints "x86_32"
```

## Ternáris operátor

A [ternáris operátor][ternary-operator] az if-else elágazás rövidített formája.
Egy boolean kifejezést, valamint két, kettősponttal elválasztott kifejezést kap.
Ha a boolean kifejezés igaz, az első kifejezés értékelődik ki, egyébként a második.
A felépítése a következő: `Boolean-expression ? expression1 : expression2`.

A ternáris operátor remekül jön, ha az if-else elágazás rövid formájára van szükséged, és a kifejezések is rövidek:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

A fenti példa a lenti kód rövidített megfelelője:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
