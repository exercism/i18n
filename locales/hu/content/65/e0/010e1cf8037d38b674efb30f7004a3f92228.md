# Közreműködés a GitHubon keresztül

Az Exercism kódbázisához [GitHubon][github] keresztül járulhatsz hozzá.

Ahogy a neve is mutatja, a GitHub verziókezelő rendszerként a [gitet][git] használja.
Ha még nem ismered a Gitet, a legjobb online forrás a [Pro Git][pro-git].

Ha még nem ismered a Gitet és a közreműködés menetét, itt van néhány forrás, ami segíthet az indulásban:

- [Bevezetés a GitHubba - interaktív kurzus][github-course]
- [Hogyan hozz létre Pull Requestet a GitHubon - útmutató][pr-tutorial]
- [Hogyan készíts egyszerű GitHub PR-t - videó anthonywritescode-tól][anthonywritescode]

## Útmutatók

Arról, hogy hogyan gondoskodhatsz róla, hogy szívesen fogadják a közreműködésedet, a [Hogyan készíts remek Pull Requestet][great-pr] útmutatóban olvashatsz bővebben.

Ezen kívül több, kifejezetten az Exercism-höz kapcsolódó Pull Request-útmutatónk is van:

- [Hogyan készíts remek Pull Requestet][how-to-make-a-great-pr]
- [A közreműködők útmutatója a Pull Requestekhez][contributors-pr-guide]
- [A karbantartók útmutatója a Pull Requestekhez][maintainers-pr-guide]
- [Karbantartói jogosultságok a repóban][maintainers-repo-permissions]
