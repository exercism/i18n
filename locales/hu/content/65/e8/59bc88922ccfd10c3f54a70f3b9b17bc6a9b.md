# Bevezetés

Az osztályok F#-ban az objektumorientált programozás elsődleges építőelemei.

Egy osztály F#-ban mezőkből és metódusokból áll. Egy osztály mezőit és metódusait _tagoknak_ nevezzük.

Az osztályokat F#-ban a `type` kulcsszóval definiáljuk. A metódusokat a `member` kulcsszóval definiáljuk, és mindig nyilvánosak. (Privát) mezők definiálásához `let` kötéseket használhatunk.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Az osztályok sablonként szolgálnak objektumok létrehozásához. Egy osztály példányának létrehozásához hívd meg az osztály nevét függvényként. Egy osztály példányát _objektumnak_ is nevezik.

Egy objektum tagjait pont jelöléssel érhetjük el.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
