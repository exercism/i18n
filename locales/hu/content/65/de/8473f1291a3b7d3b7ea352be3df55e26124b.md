# Részletek

A típusdefiníció egy új, nevesített típust hoz létre, amely minden más típustól különbözik, még az azonos mögöttes típusútól is.

## Típusok definiálása

A típusdefiníció a `type` kulcsszóval kezdődik, amelyet az új típus neve és a mögöttes típusa követ:

```go
type File []bool
```

A `File` itt a sakktábla egyetlen függőleges oszlopára utal, amelyet általában A-tól H-ig címkéznek.
Ebben az oszlopban minden mezőt egy Boolean érték jelöl, amely jelzi, hogy foglalt-e vagy sem.
Most, hogy a `File` definiálva van, más definíciókban is használhatjuk:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

A `Chessboard` az oszlopazonosítókat `File` értékekhez rendeli.
Minden `File` Boolean értékekből álló szelet, amely egy sakktábla-oszlop mezőit képviseli.
E típusdefiníciók nélkül a `board` egy `map[string][]bool` lenne, ami megnehezítené annak megértését, hogy mit képviselünk.

## A definiált típusok különböznek

Bár a `Score` és az `int` is egész értékeket tárol, a köztük való átalakítás explicit konverziót igényel:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

A `42` típus nélküli konstans, ezért közvetlenül hozzárendelhető egy `Score` típusú változóhoz.

A definiált típusoknak metódusaik is lehetnek; ezeket a Metódusok fogalom tárgyalja.

## Struct típusok

A struct definíciók ugyanazt a `type` kulcsszót használják:

```go
type Player struct {
    Name  string
    Score Score
}
```

A struct típusokat a Struct fogalom tárgyalja.

## Típusaliasok

A típusalias egy másik nevet hoz létre egy létező típushoz ahelyett, hogy új típust hozna létre.
Mivel az alias és az eredeti típus azonos, értékeik felcserélhetően használhatók.
Az aliasokat a `type` kulcsszóval, az alias nevével, az egyenlőségjellel (`=`) és a létező típussal deklarálod.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
