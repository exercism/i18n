# Tanulás

Érdekel, hogy belevágj a Groovyba, vagy szeretnél többet megtudni, miközben a feladatokon dolgozol?

Próbáld ki a Groovy-t ezekkel:

* [egy böngészőben, online értelmezővel](https://www.jdoodle.com/execute-groovy-online)
* [a Groovy Console](http://groovy-lang.org/groovyconsole.html), ha a parancssorba beírod a `groovyConsole` parancsot
* [a Groovy Shell](http://groovy-lang.org/groovyconsole.html), ha a parancssorba beírod a `groovysh` parancsot

Ismerkedj meg gyorsan a Groovyval ezekkel:

* Tim Rows [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) című útmutatója ugyanolyan hasznos a nem Java-s fejlesztőknek is
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* SmartThings [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html) című útmutatója
* néhány a JDriven [online Groovy Koans](http://www.groovy-koans.org/) feladatai közül

Merülj el mélyebben ezekkel:

* a [Groovy dokumentáció](http://www.groovy-lang.org/documentation.html)
* a [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), a Groovy _nagy könyve_
* Ken Kousen [Making Java Groovy](https://www.manning.com/books/making-java-groovy) című könyve
