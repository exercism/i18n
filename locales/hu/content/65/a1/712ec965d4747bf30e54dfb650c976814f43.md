# Csak olvasható osztályok és tulajdonságok

A csak olvasható osztályok és tulajdonságok lehetővé teszik, hogy az osztályok nyilvános tulajdonságokat adjanak meg a könnyű hozzáférés érdekében, de megakadályozzák a módosításukat.
Ahhoz, hogy egy tulajdonságot csak olvashatóként deklarálj, a `readonly` kulcsszót a típus megadása elé kell tenned.
A tulajdonság egyszer kaphat értéket, de ha megpróbálod újra hozzárendelni vagy módosítani az értékét, az Error-t eredményezi.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

A csak olvasható osztályok erre a viselkedésre épülnek, és ha `readonly`-ként vannak deklarálva, minden tulajdonságra alkalmazzák a csak olvasható deklarációt.
Emellett megakadályozzák a dinamikus tulajdonságok hozzáadását.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
