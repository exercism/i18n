# Bevezetés

Egy `:` definíció közvetlenül meg tudja hívni önmagát. A Factor fordítója ugyanúgy kikövetkezteti a rekurzív szavak veremhatását, mint bármely más szóét: a sima rekurzióhoz nem kell külön deklaráció.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

A két rész a rekurzió *alapesete* (itt az üres sorozat összege `0`), illetve a *rekurzív lépés* (leveszünk egy elemet, a maradékon rekurzívan folytatjuk, majd összevonjuk az eredményeket).

A sorozatrekurzió kanonikus társai az `if-empty` és az `unclip`. Az `if-empty ( seq emptyquot nonemptyquot -- )` a sorozattól függően a két quotation egyikét futtatja; az `unclip` leveszi az első elemet, így a rekurzív lépésnek már valami egyszerűbbel kell dolgoznia.
