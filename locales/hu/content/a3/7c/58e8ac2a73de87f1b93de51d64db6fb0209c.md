# Bevezetés

## Stringek

Az Elixirben a stringeket dupla idézőjelek határolják, és UTF-8 kódolásúak:

```elixir
"Hi!"
```

A stringek a `<>/2` operátorral fűzhetők össze:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Az Elixir stringjei támogatják az interpolációt a `#{}` szintaxissal:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Ha sortörés karaktert szeretnél tenni egy stringbe, használd a `\n` escape-kódot:

```elixir
"1\n2\n3\n"
```

Ha sok sortörést tartalmazó szövegekkel szeretnél kényelmesen dolgozni, használd inkább a háromszoros idézőjeles heredoc szintaxist:

```elixir
"""
1
2
3
"""
```

Az Elixir rengeteg függvényt kínál a stringek kezeléséhez a `String` modulban.

## Pipe operátor

A `|>` operátort pipe operátornak nevezik. Arra használható, hogy függvényhívásokat fűzzünk össze úgy, hogy az előző függvényhívás visszaadott értéke a következő függvényhívás első argumentumaként adódik át.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
