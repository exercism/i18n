# Utasítások kiegészítése

## Kurzusspecifikus utasítások

Ebben a feladatban az a cél, hogy metódusokat adjunk az `Int` struktúrához Swiftben.
Erre a legegyszerűbb megoldás az [extensions][extensions] használata.

```swift
extension Int {
  // 
}
```

Az `Int` dokumentációja [itt][int] található.

[int]: https://developer.apple.com/documentation/swift/int
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
