# Bevezetés

## Struct típusok

Már találkoztunk a struct típusokkal; ismétlésképpen: a `struct` nevesített elemek sorozata, ezeket _mezőknek_ nevezzük, és minden mezőnek van neve és típusa.
Egy mező nevének a `struct`-on belül egyedinek kell lennie.
A structok az objektumorientált programozási paradigma _osztályához_ hasonlíthatók.

Új structot úgy hozol létre, hogy használod a `type` és a `struct` kulcsszót, majd a mezők nevét és típusát az alábbi példa szerint explicit módon megadod.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Nem struct típusok

Nem struct típusokat is definiálhatsz, amelyeket beépített típusdeklarációk álneveként használhatsz.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Olyan nem struct típusokat is definiálhatsz, amelyek tömbökből és map-ekből állnak.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
