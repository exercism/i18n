# A fogalomról

A Swiftben a closure-ök és a függvények hozzá tudnak férni a körülöttük lévő scope konstansaihoz és változóihoz.
Ezekhez az értékekhez akkor is hozzá tudnak férni, miután a körülöttük lévő scope befejezte a futását.
Ezt a viselkedést [_értékek elkapásának_][capturing-values] nevezzük.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
    func adder(_ i: Int) -> Int {
        base + i
    }
    return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15

func makeLogger(logLevel: String) -> (String) -> Void {
    let logHeader = "[\(logLevel)]: "
    return { msg in print(logHeader, msg) }
}
// makeLogger: (String) -> (String) -> Void

let infoLogger = makeLogger(logLevel: "info")
// infoLogger: (String) -> Void

infoLogger("This is a log message")
// prints "[info]: This is a log message"
```

A fenti példákban a `makeAdder(base:)` és a `makeLogger(logLevel:)` is olyan függvényt vagy closure-t ad vissza, amely a befoglaló scope-jából kap el értékeket.
A visszaadott függvények továbbra is hivatkoznak a `base` és a `logHeader` értékére, még azután is, hogy a `makeAdder(base:)` és a `makeLogger(logLevel:)` visszatért.

[capturing-values]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID103
