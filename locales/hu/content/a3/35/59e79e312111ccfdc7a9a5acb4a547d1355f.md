# Utasítások

Ebben a feladatban egy szerepjáték mechanikáit fogod megvalósítani.
A játékos karakterét a következő típus írja le:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

A játékban a játékosoknak el kell érniük a 10. szintet, mielőtt feloldják a manapooljukat, hogy elkezdhessenek varázslatokat szórni.
Ebben a játékban két funkción fogsz dolgozni: a feltámasztás mechanikáján és a varázslás mechanikáján.

## 1. Mutatkozz be

Írd meg az `introduce` függvény tartalmát.
Vedd figyelembe, hogy a `Player` rekord `Name` mezője egy `Option`.
A lopakodó játékosok elrejthetik a nevüket azzal, hogy `None`-ra állítják -- az ilyen játékosok `"Mighty Magician"` néven mutatkoznak be.
Egyébként egyszerűen a saját neveddel mutatkozz be.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Valósítsd meg a feltámasztás mechanikáját

A `revive` függvénynek ellenőriznie kell, hogy a játékos karaktere valóban halott-e (az életereje elérte a 0-t).
Ha igen, egy új, 100 életerejű `Player` példányt kell visszaadnia.
Ellenkező esetben, ha a játékos karaktere nem halott, a `revive` függvény `None`-t ad vissza.

Ha a játékos szintje 10 vagy magasabb, akkor 100 manával kell feltámasztani.
Ha a játékos szintje 10 alatt van, a manája `None` legyen.
A `revive` függvénynek meg kell őriznie a játékos szintjét.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Ha a `revive` metódust olyan játékoson hívják meg, akinek az életereje 1 vagy magasabb, a függvénynek `None`-t kell visszaadnia.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Valósítsd meg a varázslás mechanikáját

A `castSpell` függvény argumentumként egy `int`-et kap, amely megadja, mennyi manába kerül a varázslat, valamint egy `Player`-t.
Visszaadja a frissített játékost, valamint azt a sebzést, amelyet az elszórt varázslat okoz.
Egy sikeres varázslás a varázslat manaköltségének kétszeresével egyenlő sebzést okoz.
Ha azonban a játékosnak nincs elég manája, semmi sem történik, a játékos változatlan marad, és nem keletkezik sebzés.
Ha a játékosnak még manapoolja sincs, a varázslási kísérletnek a varázslat manaköltségével kell csökkentenie az életerejét, és nem okoz sebzést.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
