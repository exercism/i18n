# Függvények

A JavaScriptben a függvények _első osztályú objektumok_, ami azt jelenti, hogy hozzárendelhetők változókhoz és tulajdonságokhoz, átadhatók más függvényeknek, és visszaadhatók függvényekből. Rendelkezhetnek tulajdonságokkal és metódusokkal, akárcsak bármely más _objektum_.

## Bemenet: argumentumok átadása

A JavaScript függvényei lehetővé teszik, hogy argumentumokat adj át nekik híváskor. Az argumentumok mindig [érték szerint adódnak át](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). Más szóval, ha egy függvény egy paraméternek a függvényen belül új értéket ad, az érték a függvényen kívül nem változik meg. Ez nem jelenti azt, hogy az átadott objektumokat ne lehetne módosítani.

> [!TIP]
> Amikor egy objektumot adunk át, akkor az objektumra mutató referencia adódik át érték szerint. Emiatt úgy _tűnik_, mintha az objektumok átadása másképp működne, de valójában nem ez a helyzet.

Példa egy olyan függvényre, amely két argumentumot vesz át, és összeszorozza őket:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Kimenet: visszatérési érték

A JavaScriptben egy függvény egyetlen értéket adhat vissza a `return` kulcsszó használatával, amelyet egy kifejezés követ. Amikor egy függvény nem ad vissza semmit, a visszatérési értéke `undefined`.

Példa egy olyan függvényre, amely visszaad egy értéket:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Függvények definiálása

Négyféle függvény létezik a JavaScriptben:

1. Sima függvények, amelyek bármit visszaadhatnak, és mindig a végéig futnak;
2. Aszinkron függvények, amelyek mindig egy `Promise`-t adnak vissza, és az `await` operátorral szüneteltethetők és folytathatók;
3. Generátorfüggvények: amelyek mindig egy `Generator` objektumot adnak vissza, és a `yield` operátorral szüneteltethetők és folytathatók;
4. Aszinkron generátorfüggvények; amelyek mindig egy `AsyncGenerator` objektumot adnak vissza, és _mind_ a `yield`, _mind_ az `await` operátorral szüneteltethetők és folytathatók.

Ezt a négy fajtát háromféleképpen lehet definiálni:

1. deklarációval
2. kifejezéssel
3. konstruktorral

Végül van néhány speciális szintaxis a _nyílfüggvények és metódusok_ definiálására.
