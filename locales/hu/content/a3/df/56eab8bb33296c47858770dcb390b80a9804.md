# Részletesebben

A [stringek][getting-started-strings] az Elixirben kettős idézőjelek közé kerülnek, és UTF-8-kódolásúak:

```elixir
"Hi!"
```

A stringek összefűzhetők a [`<>/2`][kernel-concat] operátorral:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

A stringek az Elixirben támogatják az [interpolációt][string-interpolation] a `#{}` szintaxissal:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Az interpoláción belül bármilyen Elixir-kifejezés érvényes. Ha egy stringet adsz meg, az változatlanul bekerül az interpolációba. Ha bármilyen más értéket adsz meg, az Elixir megpróbálja stringgé alakítani.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Az Elixir sok függvényt kínál a stringek kezeléséhez a `String` modulban. Ha nem vagy benne biztos, hogyan dolgozz fel egy stringet úgy, ahogy szeretnéd, nézd át a [`String` modulban elérhető függvényeket][string-module-functions], és valószínűleg meg is találod, amire szükséged van.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

Amikor ezek közül a függvények közül használsz néhányat, ne feledd, hogy egy string első karakterének indexe `0`.

Néhány karaktert [escape-elni][escape-characters] kell, hogy bekerülhessen egy stringbe, például a sortöréseket, a kettős idézőjeleket vagy a `#` karaktert:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

Ha sok sortörést tartalmazó szövegekkel szeretnél kényelmesen dolgozni, használd inkább a [három idézőjeles heredoc szintaxist][heredoc-syntax]:

```elixir
"""
1
2
3
"""
```

Ezt a szintaxist nagyon gyakran kódrészletek dokumentálására használják:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
