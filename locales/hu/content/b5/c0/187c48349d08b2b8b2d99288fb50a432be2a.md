# Utasítások

A feladatod, hogy fogj egy játék gólszerzőinek listáját, és számold meg, hány gólt szerzett az egyes játékosok.

A `PlayerName` a `String` típusaliasa, amely megkönnyíti a kód olvasását, és megkülönbözteti a `String` ezen használatát a `String` más használataitól.

## 1. A gólszerzők összesítése

Először implementáld az `updateGoalCountForPlayer` függvényt, amely inicializálja vagy növeli egy játékos gólszámát.
Ezután implementáld az `aggregateScorers` függvényt, amely az `updateGoalCountForPlayer` használatával megszámolja, hány gólt szerzett az egyes játékosok.
Ez a függvény egy `List PlayerName` értéket kap (a gólt szerző játékosok neveit, amely ismétlődő játékosneveket tartalmazhat), és egy `Dict PlayerName Int` értéket ad vissza, amely a listában szereplő összes játékost tartalmazza, és azt is, hogy hány gólt szereztek.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. A jelentéktelen játékosok eltávolítása

Implementáld a `removeInsignificantPlayers` függvényt, amely kiszűri azokat a játékosokat, akik kevesebb gólt szereztek, mint a küszöbérték.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. A játékos gólszámának nullázása

Implementáld a `resetPlayerGoalCount` függvényt, amely egy játékos megszerzett góljait nullára állítja.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Egy játékos gólszámának formázása

Implementáld a `formatPlayer` függvényt, amely egy játékos gólszámát szövegként formázza. Ha a játékos nem szerepel a szótárban, feltételezd, hogy a gólszáma nulla.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Az összes játékos gólszámának formázása

Implementáld a `formatPlayers` függvényt, amely az összes játékos gólszámát szövegként formázza. A játékosokat a nevük szerint kell sorba rendezni.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Játékok összevonása

Implementáld a `combineGames` függvényt, amely megszámolja, hogy az egyes játékosok összesen hány gólt szereztek a két játékban.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
