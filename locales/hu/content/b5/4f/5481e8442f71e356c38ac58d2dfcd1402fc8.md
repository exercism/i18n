# Bevezetés

## Tömbök

A JSON a következőképpen definiálja a **tömb** fogalmát:

> A tömb értékek rendezett gyűjteménye.
> A tömb `[` bal szögletes zárójellel kezdődik és `]` jobb szögletes zárójellel végződik.
> Az értékeket `,` (vessző) választja el.

A tömbök nulla vagy több _bármilyen típusú_ JSON-értéket tartalmazhatnak.
A tömbben lévő elemek nem feltétlenül azonos típusúak.

### Tömbök létrehozása

A zárójelek segítségével elemeket gyűjthetsz egy tömbbe.

```jq
[1, 2, 3]
```

Egy _stream_ elemeit úgy gyűjtheted tömbbe, hogy zárójelek közé zárod.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### Méret

A `length` függvény egy tömb elemeinek számát adja vissza.

### Indexelés és szeletelés

A tömbök indexelése nullától kezdődik.

Egy tömb eleméhez zárójeles kifejezéssel férhetsz hozzá:
a `.[2]` a harmadik elemet adja.

A negatív indexek a tömb végétől számolódnak visszafelé:
a `.[-1]` az utolsó elemet adja, a `.[-2]` pedig az utolsó előttit.

A **szelet** a tömb egy részsorozata.
A `.[10:15]` 5 elemet ad vissza a 10-es indextől kezdve, a záró index _nem_ számít bele.

Van néhány kényelmi függvény is:

- A `first` az első elemet adja.
- A `last` az utolsó elemet adja.
- A `nth(n)` az `n` indexű elemet adja.

### Iterálás

A `jq` számos függvényt kínál a gyakori iterációs műveletekhez:

- A `map(expr)` egy új tömböt ad vissza, amelyben az `expr` minden elemre egymás után alkalmazva van.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- A `select(expr)` egy olyan függvény, amely az `expr`-t egy _egyetlen értékre_ alkalmazza;
  ha a kifejezés eredménye igaz, akkor a függvény visszaadja az értéket;
  ha az eredmény hamis, akkor _semmi_ nem adódik vissza, nem `null`, hanem tényleg semmi.

  Ha egy tömbre szeretnéd alkalmazni, kombináld a `map`-pal.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Másik lehetőségként alkalmazd a `select`-et egy _streamre_, és gyűjtsd össze az eredményeket.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- Az `any(condition)` és az `all(condition)` logikai értéket ad vissza arról, hogy a tömbben lévő elemek közül bármelyik/mindegyik teljesíti-e a feltételt.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
