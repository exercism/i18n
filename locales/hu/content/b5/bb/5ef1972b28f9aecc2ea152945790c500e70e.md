# Utasítások

A távirányítós autó projekt, amelyet a `classes` feladatban indítottál el, jól sikerült (gratulálunk!), és néhány nemrégiben kötött szponzorációs megállapodásnak köszönhetően van pénz a költségvetésben fejlesztésekre.

A költségvetés egy részét telemetria biztosítására fordítják.

Hogy a szponzorok kedvében járjanak, egy panelt szereltek fel az autóra, amely a szponzorok nevét jeleníti meg, miközben az autó körbehalad a pályán.

Észre fogod venni, hogy ezeknek a divatos új technológiáknak a bevezetése drasztikusan csökkentette az autó akkumulátorának élettartamát.

## 1. Tedd lehetővé, hogy a távirányítós autó megjelenítse a szponzorok nevét

Valósítsd meg a `SetSponsors()` metódust, amely egy vagy több szponzornevet fogad, és eltárolja azokat az autón.

Ne feledd, hogy a `SetSponsors()` metódus argumentuma garantáltan nem null.

Valósítsd meg a `DisplaySponsor()` metódust, amely megjeleníti a kiválasztott szponzort. Az elsőként átadott szponzor `sponsorNum` értéke 0, a másodiké 1, és így tovább.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. Kérd le az autó telemetriai adatait

Valósítsd meg a `RemoteControlCar.GetTelemetryData()` metódust.

A `GetTelemetryData()` metódus tegye elérhetővé az akkumulátorszázalékot és a méterben megtett távolságot `out` paramétereken keresztül.

A `GetTelemetryData()` metódus `false` értéket adjon vissza, ha a serialNum argumentum kisebb a korábban kapott értéknél. (Valami probléma merült fel a több telemetriai csomóponttal kapcsolatban.) Ebben az esetben a `serialNum` a legmagasabb korábbi `serialNum` értékre áll be, az akkumulátorszázalék és a megtett méterek pedig `-1`-re állnak. Sikeres hívás esetén a `serialNum` változatlan marad.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. Adj hozzá funkciót, hogy a telemetriai rendszer le tudja kérni a méterenkénti akkumulátorhasználatot

Valósítsd meg a `TelemetryClient.GetBatteryUsagePerMeter()` metódust.

Ez meghívja a `RemoteControlCar.GetTelemetryData()` metódust. Ha a `GetTelemetryData()` `false` értéket ad vissza, vagy az autót nem vezették, akkor ennek a rutinnak „no data” értéket kell visszaadnia. Ha a `GetTelemetryData()` `true` értéket ad vissza, akkor a következő formájú üzenetet kell visszaadni: „usage-per-meter=BATTERY-USAGE-PER-METER”. A számítás: (100 - az aktuális akkumulátorszázalék) osztva az eddig megtett távolsággal méterben.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
