# Bevezetés

## Objektumok

A JSON-**objektum** (hogy más nyelvek terminológiáját használjuk) lényegében egy „hash”, „map” vagy „szótár”.

A JSON így definiálja az _objektumot_:

> Az objektum **név**/**érték** párok rendezetlen halmaza.
> Az objektum `{` nyitó kapcsos zárójellel kezdődik és `}` záró kapcsos zárójellel végződik.
> Minden _nevet_ `:` kettőspont követ, a _név/érték_ párokat pedig `,` vessző választja el.

A _név_ **csak string lehet**.
A _név_ másik elnevezése a _kulcs_.

Az _érték_ bármilyen JSON-típusú lehet.
Egy objektumon belül a különböző _értékek_ eltérő típusúak lehetnek, mint ebben a példában.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Figyelj rá, hogy az _utolsó_ kulcs-érték pár után **nem lehet** vessző.

### Objektumok létrehozása

A név/érték párok összegyűjtéséhez kapcsos zárójelet használj.
Bár a neveknek stringnek kell lenniük, nem kell őket idézőjelbe tenni, ha **azonosítószerűek** (alfanumerikus karakterekből és alulvonásból állnak, és nem számjeggyel kezdődnek).

```jq
{name: "Jane", age: 42}
```

Lehet olyan kulcsokat is használni, amelyek nem _azonosítószerűek_.
Csak tedd őket idézőjelbe.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Ha a név egy kifejezés eredménye, akkor a kifejezést **zárójelbe kell** tenni.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

### Indexelés

Az értékeket **pontjelöléssel** lehet kiolvasni egy objektumból.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Ha a kulcsra nem tudsz azonosítóként hivatkozni, használj **szögletes zárójeles jelölést**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

### Kulcs-érték párok hozzáadása vagy módosítása

Ha új kulcs-érték párt szeretnél hozzáadni egy objektumhoz, vagy frissíteni szeretnéd egy meglévő kulcs értékét, használd a `=` értékadó operátort úgy, hogy a bal oldalon egy indexkifejezés áll.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

A `+` operátor _összevonja_ az objektumokat.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

### Kulcs eltávolítása

Egy kulcs eltávolításához használd a `del` függvényt.
Az visszaadja a frissített objektumot.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

A `del` paramétere egy **indexkifejezés** (pont- vagy szögletes zárójeles jelöléssel), amely az objektum egy kulcsára oldódik fel.
A `jq` ezt **útvonalkifejezésnek** nevezi.
Nem elég pusztán egy stringet megadni.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

### Tagság

- Annak ellenőrzésére, hogy az objektum rendelkezik-e egy kulccsal, használd a `has` függvényt.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Azt, hogy egy kulcs szerepel-e egy objektumban, az `in` operátorral ellenőrizheted.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

### Az összes kulcs listázása

Az összes kulcs listázásához használd a `keys` függvényt.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Vegyük észre, hogy a `keys` _rendezi_ a kulcsokat.
Ha az eredeti sorrendben szeretnéd megkapni a kulcsokat, használd a `keys_unsorted` függvényt.

Nincs arra megfelelő függvény, hogy az összes _értéket_ listázd.
A `.[]` szűrő azonban _folyamként_ adja ki az objektum értékeit, és ez a folyam a `[...]` tömbkonstruktorral fogható meg.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

### Iterálás

- A `map_values(filter)` függvény a szűrőt az objektum minden egyes _értékére_ alkalmazza.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Ahhoz, hogy egy objektumon iteráljunk, először kulcs-érték objektumok tömbjévé kell alakítanunk.
  Ezt a `to_entries` függvény végzi el.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  Ezen a ponton már használhatjuk a tömbiterációs függvényeket, például a `map`-et.

- A `from_entries` függvény ennek a fordítottja: kulcs-érték objektumok tömbjét alakítja objektummá.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- Ha egy szűrőt az objektum _minden_ kulcs-érték párjára alkalmazni szeretnél, használd a `with_entries(filter)` függvényt.

  Például ha adott egy objektum, amely nevet képez le életkorra, a kulcsok és az értékek a következőképpen cserélhetők fel.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  az alábbi kimenetet eredményezi:

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  A `with_entries(filter)` ugyanaz, mint

  ```jq
  to_entries | map(filter) | from_entries
  ```
