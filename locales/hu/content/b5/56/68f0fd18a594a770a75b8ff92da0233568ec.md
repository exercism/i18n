# Bevezetés

Az objektumok kezdőértékeinek megadása a konstruktorok alternatívája. A szintaxist az alábbi példa szemlélteti. Ehhez egy kapcsos zárójelek közé írt, vesszővel elválasztott név-érték párokból álló listát adsz meg, amelyben a nevet és az értéket `=` választja el egymástól:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

A gyűjteményeket is inicializálhatod ilyen módon. Ez jellemzően vesszővel elválasztott listákkal valósul meg, ahogy az alábbi példa mutatja:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

A szótáraknál a következő szintaxist használjuk:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```
