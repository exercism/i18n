# Részletek

Ha a paraméterek típusai kikövetkeztethetők, a Swift azt is megengedi, hogy a closure definíciójából elhagyd a paraméterneveket és az `in` kulcsszót. A paraméterekre ehelyett egy speciális [rövidített szintaxissal][shorthand-argument-names] is hivatkozhatsz, ahol a `$0` az első paramétert, a `$1` a másodikat jelöli, és így tovább.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

Ezt a stílust leggyakrabban akkor használjuk, amikor closure-öket adunk át magasabb rendű függvényeknek, és a tömörség számít.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
