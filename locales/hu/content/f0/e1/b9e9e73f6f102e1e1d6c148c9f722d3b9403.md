# Utasítások

Miközben sütiket készülsz sütni a barátaidnak, rájöttél, hogy a receptben használt mérések egy részét át kell váltanod.
Mivel csak a metrikus rendszert ismered, ki kell találnod egy módot arra, hogy a gyakori amerikai konyhai mértékegységeket milliliterre (mL) váltsd, hogy megkönnyítsd a dolgodat.

Használd ezt az átváltási táblázatot a megoldáshoz:

| Átváltandó mértékegység | térfogat | milliliterben (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| amerikai csésze          | 1      | 240                 |
| amerikai folyadék uncia  | 1      | 30                  |
| amerikai teáskanál     | 1      | 5                   |
| amerikai evőkanál   | 1      | 15                  |

Mivel tehetséges programozópalánta vagy, úgy döntesz, hogy a millilitert használod átmeneti mértékegységként, hogy megkönnyítsd bármelyik felsorolt mértékegység átváltását bármelyik másikra (akár önmagára is).

## 1. Szerezd meg a számértéket egy térfogatpárból

Készítsd el a `getVolume` függvényt. Egy térfogatpár tuple esetén csak a számértéket adja vissza.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. Váltsd át a térfogatpárt milliliterre

Készítsd el a `toMilliliter` függvényt. Egy térfogatpár tuple esetén az átváltási táblázat segítségével milliliterre kell váltania a térfogatot.

Használj több függvényklózt és mintaillesztést, hogy minden mértékegységhez létrehozd a függvényt. Az egyes mértékegységeket jelölő atomok: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.
Az átváltás eredményét tuple-be csomagolva add vissza.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. Váltsd át a milliliteres térfogatpárt egy másik mértékegységre

Készítsd el a `fromMilliliter` függvényt. Egy térfogatpár tuple és a kívánt mértékegység esetén az átváltási táblázat segítségével a kívánt mértékegységre kell váltania a térfogatot.

Használj több függvényklózt és mintaillesztést, hogy minden mértékegységhez létrehozd a függvényt. Az egyes mértékegységeket jelölő atomok: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. Válts át bármelyik mértékegységről bármelyikre

Készítsd el a `convert` függvényt. Egy térfogatpár tuple és a kívánt mértékegység esetén a megadott térfogatot a kívánt mértékegységre kell váltania.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
