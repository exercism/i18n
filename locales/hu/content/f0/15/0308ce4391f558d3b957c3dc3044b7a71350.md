# Bemutatás

## Számok és numerikus operátorok

Minden **szám** – akár egész, akár nem – IEEE754 szabványú, dupla pontosságú lebegőpontos szám.
A `jq` implementációja a C `double` típusát használja.
Ez 53 bitre korlátozza a pontosságot.

A szokásos operátorok számokkal is használhatók:

- aritmetikai: `+`, `-`, `*`, `/`, `%`
- összehasonlítás: `==`, `!=`, `<`, `<=`, `>=`, `>`
- szabványos [matematikai függvények][man-math]

  Egy bemenetes függvényeknél az értéket a függvénybe irányítjuk:

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Két bemenetes függvényeknél a függvény figyelmen kívül hagyja a bemenetet, és a
  bemeneteket paraméterként várja:

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  A függvényargumentumok elválasztója a pontosvessző, nem a vessző.

~~~~exercism/caution
Mit jelent az, hogy „Ez 53 bitre korlátozza a pontosságot”?

Íme egy szemléltetés:

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

Ez jól néz ki. Mi történik, ha megnöveljük a kitevőt?

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

Ezeknek a számoknak nem szabadna egyenlőnek lenniük. 
Így néz ki a „pontosságvesztés”.
Ez azt jelenti, hogy a `jq` nem képes tetszőlegesen nagy számok kezelésére.
~~~~

## Feltételes kifejezések

A `jq` a **feltételes kifejezésekhez** az [`if-then-else` kifejezést][if-then-else] használja.
Mivel _kifejezésről_ van szó, csővezetékbe kerül.

A szintaxis: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

Az `else` ág elhagyható.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

További feltételekhez az `elif` használható

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
