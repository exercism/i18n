# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] egy kifejezés, amely egy értéket ad vissza.
A Pyret egy adott kódblokkon belül csak egyetlen kifejezést engedélyez, kivéve, ha a külső blokk `block`-kal van megjelölve.
A második példában a `block` hozzáadása a függvénydeklarációhoz lehetővé teszi, hogy 42-t írjunk ki, mielőtt visszaadjuk.

## Spy-k

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

A spy utasítás fogad egy opcionális címkét és egy vagy több változót, majd kiírja minden változót és annak értékét.
Mivel nem kifejezés, a spy utasítás használható egy blokkban anélkül, hogy a külső blokkot `block`-kal kellene megjelölni.

[print]: https://pyret.org/docs/latest/_global_.html#%28idx._%28gentag._57%29%29
[spy]: https://pyret.org/docs/latest/s_spies.html
