# Visszatérés

Crystalben egy metódus utolsó kifejezésének értéke lesz a visszatérési érték.
Néha viszont az utolsó kifejezés előtt kell visszaadnod egy értéket.
Erre a `return` kulcsszót használhatod, amely a mögötte álló kifejezés értékét adja vissza.
A `return` kulcsszó után írt kód nem hajtódik végre.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
A `return` kulcsszót el kell hagyni, ha a metódus utolsó kifejezése az az érték, amelyet vissza kell adni.
~~~~
