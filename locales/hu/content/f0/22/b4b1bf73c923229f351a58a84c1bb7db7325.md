# A tesztek futtatása

A terminálból lépj be a feladat alapkönyvtárába, majd futtasd a teszteket a következő paranccsal:

```bash
$ mix test
```

Ez lefuttatja a `test` almappában található tesztfájlt, amelynek a neve `_test.exs`-re végződik.

Dokumentáció:

* [`mix test` - az Elixir tesztfuttató eszköze](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit` - az Elixir egységteszt-könyvtára](https://hexdocs.pm/ex_unit/ExUnit.html)

## Függőben lévő tesztek

A gyakorlófeladatok tesztcsomagjaiban az első kivételével az összes tesztet kihagyásra jelölték.

Amint egy teszt sikeresen lefut, a következőt úgy aktiválhatod, hogy a megfelelő `@tag :pending` sort kikommenteled egy `#` jellel.

Például:

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

Ha egyszerre szeretnéd futtatni az összes tesztet, az összes kihagyott tesztet bevonhatod a `--include` kapcsolóval a `mix test` parancsban:

```bash
$ mix test --include pending
```

Vagy az összes tesztet engedélyezheted úgy, hogy kikommenteled az `ExUnit.configure` sort a `test/test_helper.exs` fájlban.

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## Hasznos `mix test` opciók

* `test/<FILE>.exs:LINENUM` - csak egyetlen tesztet futtat, azt, amelyik a `<FILE>.exs` fájlban a `LINENUM` sorban van definiálva
* `--failed` - csak azokat a teszteket futtatja, amelyek legutóbb sikertelenek voltak
* `--max-failures` - a tesztcsomag leállítja a tesztek kiértékelését, amikor eléri ezt a számú sikertelen tesztet
* `--seed 0` - kikapcsolja a véletlenszerűsítést, így egy fájl tesztjei mindig ugyanabban a sorrendben futnak le, ahogy definiálták őket
