# Bevezetés

A Factorban egy új szót a `: name ( stack-effect ) body ;` formával definiálsz.
A törzs szavak sorozata; az új szavad meghívásakor ezek sorban lefutnak.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Amikor egy rutin nagyra nő, *faktorizálhatod*, sőt *érdemes is*: a szavak
csoportjait kisebb, elnevezett szavakká bontod, amelyek mindegyikének egyetlen
feladata van. A nyelv innen kapta a nevét.

## Szókészletek

Minden `.factor` fájl deklarál egy szókészletet az `IN:` utasítással. Az egyik
szókészletben lévő szavak meghívhatják egy másik szókészlet szavait, ha a
másikat felsorolod a `USING:` listában.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

A könyvtárszerkezet követi a pontokkal tagolt szókészletnevet: a `my-vocab`
szókészlet a `my-vocab/my-vocab.factor` fájlban található, a `my-vocab.helpers`
szókészlet pedig a `my-vocab/helpers/helpers.factor` fájlban. A Factor betöltője
tranzitívan követi a `USING:` deklarációkat, és igény szerint tölti be az egyes
szókészleteket.
