# Bemutatás

Az Elmben a [`List`][lists] egy változhatatlan gyűjtemény, amely nulla vagy több azonos típusú értéket tartalmaz.
Mivel a listák változhatatlanok, egy lista létrehozása után az értéke soha nem változhat.
Az Elm listáinak van _feje_ (az első elem) és _farka_ (minden, ami az első elem után következik).
A lista farka maga is egy lista.

A listák típusjelölése így definiálható

```elm
List String --> a list of String
List Int --> a list of Int
```

A listákat így definiálhatod:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

Egy elemet leggyakrabban a `::` (cons) operátorral adhatsz hozzá egy listához:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

A listák összefűzésére a `++` operátor vagy a `List.append` használható:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

A listákkal a [`List` modul][list-module] függvényei és operátorai dolgoznak.

```elm
List.length [ 7, 8 ] --> 2
```

Minden függvény és operátor, amely úgy tűnik, hogy módosítja a listát (például elemet ad hozzá), valójában egy új listát ad vissza.
A teljesítmény azonban általában nem jelent problémát, mert a listák implementációja megakadályozza a felesleges allokációkat és másolásokat.

A listákat [mintázatillesztéssel][list-destructuring] is feldolgozhatod.

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
