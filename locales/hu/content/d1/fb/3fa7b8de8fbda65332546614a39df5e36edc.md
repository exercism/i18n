# Kiegészítés az utasításokhoz

## Tippek

Implementálnod kell a `responseFor` függvényt, amely egy adott bemenetre visszaadja Bob válaszát. Ha nem vagy biztos a típusokban, használhatod a megadott szignatúrát, de ne hagyd, hogy az korlátozza a kreativitásodat:

```haskell
responseFor :: String -> String
```

A feladat megoldásához érdemes utánanéznod a következőknek:

- [Őrök][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

Ez a feladat szöveges adatokkal dolgozik. Történelmi okokból a Haskell `String` típusa ugyanazt jelenti, mint a `[Char]`, azaz a karakterek listája. A szöveges adatok hatékonyabb kezeléséhez használhatod a `Text` típust.

A feladat opcionális kiterjesztéseként a következőket teheted:

- Olvass a Haskell [stringtípusairól](https://haskell-lang.org/tutorial/string-types).
- Vedd fel a `- text` elemet a package.yaml fájl függőségei közé.
- Importáld a `Data.Text` modult [a következő módon](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Most már írhatsz például ilyet: `responseFor :: Text -> Text`, és hivatkozhatsz a `Data.Text` kombinátoraira, például így: `T.isSuffixOf`.
- Nézd meg a [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) dokumentációját,
- Ezután a Bob.hs fájlban lecserélheted a `String` minden előfordulását `Text`-re:

    ```haskell
    responseFor :: Text -> Text
    ```

Ez a rész teljesen opcionális.
