# Bevezetés

Amikor `java.time` objektumokkal (például `LocalDate`) dolgozol, gyakran kell összetett dátumkorrekciókat végezned, például megkeresned a hónap második keddjét.
Ahelyett, hogy ezt kézzel számolnád ki, használhatod a **`TemporalAdjusters`** osztályt.

A `java.time.temporal.TemporalAdjusters` segédosztály (figyeld meg a többes számú »s«-t) sok gyakori dátumkorrekcióhoz kínál statikus metódusokat.
Ezeket a korrekciókat egy időobjektumon (például `LocalDate`) a `.with()` metódussal alkalmazod.

```exercism/note
A `with(TemporalAdjuster)` hívása egy _új_ példányt ad vissza, a meglévőt nem frissíti, mert a `java.time` objektumok nem módosíthatók.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Íme néhány fontos korrekciós objektum, amely hasznos lehet az ütemezési számításokhoz:

## A hét adott sorszámú napjának megkeresése

A `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` metódussal megkeresheted egy hétköznap n-edik előfordulását.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

## A hónap első/utolsó adott hétköznapjának megkeresése

Használd a `firstInMonth(DayOfWeek dayOfWeek)` vagy a `lastInMonth(DayOfWeek dayOfWeek)` metódust.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

## Relatív korrekciók (következő/előző)

Az olyan korrekciós objektumok, mint a `next()`, a `previous()`, a `nextOrSame()` és a `previousOrSame()`, az aktuális dátumhoz képest keresik meg egy adott hétköznap következő vagy előző előfordulását.

- `next()`/`previous()`: kizárja az aktuális dátumot, ha az egyezik.
- `nextOrSame()`/`previousOrSame()`: belefoglalja az aktuális dátumot, ha az egyezik.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Egyéni korrekciós objektumok

A `TemporalAdjuster` funkcionális interfész, ezért saját korrekciós objektumot is írhatsz lambda alakban: a lambda megkapja a módosítandó időobjektumot, és visszaadja a módosítottat.
Ugyanúgy a `.with()` metódussal alkalmazod, mint az előre definiált korrekciós objektumokat, és belül maga is használhatja azokat.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

A `TemporalAdjusters` osztály korrekciós objektumainak használata nagyban leegyszerűsítheti a dátumkezelési feladatokat.
