# Bevezetés

A listák beépítettek az Elixir nyelvbe. Alaptípusnak számítanak, és szögletes zárójelekkel jelöljük őket. A listák lehetnek üresek, vagy tetszőleges számú, bármilyen típusú elemet tartalmazhatnak. Például:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Az Elixir a listákat láncolt listaként valósítja meg, amelyben minden csomópont két értéket tárol: az első elemet és egy másik listát az összes többi elemmel. A lista első elemét _fejnek_, a fennmaradó elemek listáját pedig _faroknak_ nevezzük. Ezt a jelölést a kódban is használhatjuk:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

A _`[head | tail]`_ jelöléssel elemeket fűzhetünk a lista elé:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

A `Kernel` modulban számos függvény áll rendelkezésre a listákkal való munkához, és emellett ott van a teljes `List` modul is.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
