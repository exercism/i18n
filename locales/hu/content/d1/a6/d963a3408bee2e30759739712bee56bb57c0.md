# Tesztek futtatása

Ha a `sbt` telepítve van, a teszteket a parancssorból így futtathatod:

```bash
$ sbt test
```

Ne feledd, hogy ha minden alkalommal az `sbt test` parancsot futtatod, az lassú lesz, mert minden hívásnál újrainicializálja az `sbt`-t.

Az `sbt` úgy működik, mint egy shell: ha egyszer elindítottad, parancsokat futtathatsz benne.

Például az `sbt` segítségével újrafuttathatod a tesztjeidet, valahányszor a forrásfájlok megváltoznak:
```bash
$ sbt
>~ test
```

Figyelj rá, hogy az első kivételével az összes teszt le van tiltva, hogy legyen min dolgoznod.
A folytatáshoz egyszerűen töröld a `pending` kulcsszót minden teszteset elejéről.

Ha többet szeretnél megtudni az `sbt`-ről, nézz körül [itt](https://www.scala-sbt.org/).


A teszteket az alábbi IDE-kben is futtathatod

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA Scala beépülő modullal](https://www.jetbrains.com/idea/)
