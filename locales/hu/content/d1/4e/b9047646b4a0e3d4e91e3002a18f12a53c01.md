# Bevezetés

A Common Lispben egy függvény rendelkezhet névvel ellátott paraméterekkel (ezeket „kulcsszóparamétereknek” nevezzük).
Ezeket a lambda-listában a `&key` lambda-lista kulcsszó jelöli.
A kulcsszóparaméterek nem kötelező paraméterek.
Az opcionális paraméterekhez hasonlóan kaphatnak alapértelmezett értékeket és szimbólumokat, amelyek a „megadva vagy sem” állapotukhoz kötődnek.

Amikor egy függvényt kulcsszóparaméterekkel hívunk meg, a paraméter nevét kulcsszóként a paraméter értéke elé írjuk.
A kulcsszóparamétereket a függvény hívója tetszőleges sorrendben adhatja meg.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

Vigyázni kell, amikor opcionális és kulcsszóparamétereket kombinálunk, mert előfordulhat, hogy az opcionális paraméterek kapják meg a kulcsszónevet és az argumentumot:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
