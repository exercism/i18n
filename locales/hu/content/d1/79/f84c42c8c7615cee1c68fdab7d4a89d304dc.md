# Tudnivalók

A Gleam szabványos könyvtárának `gleam/order` modulja tartalmazza az `Order` típust, amelyet értékek összehasonlítására használunk.

Az `Order` definíciója így néz ki:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

A típusnak három változata van, és mindegyik egy érték meg egy másik érték viszonyát írja le:

- `Gt` - az érték _nagyobb_, mint a másik érték.
- `Eq` - az érték _egyenlő_ a másik értékkel.
- `Lt` - az érték _kisebb_, mint a másik érték.

Ha egy adattípus méret szerint összehasonlítható, a modulok gyakran definiálnak hozzá egy `compare` függvényt, amely `Order` értéket ad vissza. Például a `gleam/float` és a `gleam/int` is definiál `compare` függvényt, amelyek tizedes törteken, illetve egész számokon működnek.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

A rendező függvények, például a `list.sort`, gyakran olyan függvényt várnak paraméterként, amely `Order` értéket ad vissza, így a hívó határozhatja meg, hogyan rendeződjön a lista.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
