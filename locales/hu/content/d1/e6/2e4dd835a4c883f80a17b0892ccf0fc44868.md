# Case

[`case`][case] (más nyelvekben gyakran switch néven ismert) egy vezérlési kifejezés, akárcsak az if-else.
A `case` lehetővé teszi több if-else-if utasítás láncolását, olvashatóbb lehet, és hatékony szerkezeteket tesz lehetővé.

A `case`-t a `case` kulcsszó vezeti be, amelyet egy opcionális kifejezés követ.
Ezután minden ágnál a `when` kulcsszót használjuk, amelyet egy kifejezés követ; ezt hasonlítja össze a program a `case` kifejezésével.
A `when` kulcsszó ne legyen beljebb húzva, mint a `case` kulcsszó.
A `when` kulcsszó után az a kód áll, amely akkor fut le, ha a `case` kifejezés megegyezik a `when` kifejezéssel.
A `case` megenged egy opcionális `else` ágat is, amely akkor fut le, ha egyetlen másik ág sem illeszkedik.

A `case` kifejezés kiértékelése után a program összehasonlítja minden `when` kifejezéssel.
Az összehasonlítás a [`case`-illesztés operátorával (`===`)][case-subsumption] történik.

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## A `case`-illesztés operátora (`===`)

A `case`-illesztés operátora (`===`) némileg eltér az egyenlőség operátorától (`==`).
Ez az operátor azt vizsgálja, hogy a jobb oldal eleme-e a bal oldal által leírt halmaznak.
Ez azt jelenti, hogy számít, melyik operandus hova kerül.
A működés a bal oldal típusától függ: például egy `Range` azt ellenőrzi, hogy a jobb oldal benne van-e a tartományban, egy `Object` pedig azt, hogy a jobb oldal a `Object` egy példánya-e.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## `case` több kifejezéssel

A `case` lehetővé teszi, hogy egyetlen ágban több kifejezést adjunk meg, az egyes lehetséges értékeket vesszővel elválasztva.
A kód akkor fut le, ha a kifejezések bármelyike illeszkedik.
Ez akkor lehet hasznos, ha egy ághoz több lehetséges érték tartozik.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## `case` tartományokkal

A `case` azt is ellenőrizheti, hogy egy érték benne van-e egy tartományban.
Ehhez a `when` kifejezésként egy tartományt adunk meg.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## A `case` kifejezés elhagyása

Ha nincs szükség a `case` kifejezésre, el is hagyható.
Ekkor minden `when` kifejezés igaz vagy hamis értéke dönt az illeszkedésről, így úgy viselkednek, mint az if-else-if utasítások.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## Egysoros `when`

A Crystal megengedi az egysoros `case` utasításokat.
Ez akkor hasznos, ha egy egyszerű, egysoros utasításod van.
Egysoros formában a `when` ágat így írod le: `when <expression> then <statement>.`
Az `else` ágban pedig így: `else <statement>`.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## `case` típusokkal

A `case` lehetővé teszi a típusok szerinti illesztést.
Az összehasonlítás az `is_a?` operátort használja a változó típusának ellenőrzésére.
Ez például lehetővé teszi, hogy egy uniótípus minden típusához külön ágat írjunk.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## Az implicit objektum

A `case` lehetővé teszi egy implicit objektum használatát.
Ennek köszönhetően például egy `when` kifejezés metódushívás lehet a `case` kifejezésen.
Attól függően, hogy a metódus igaz vagy hamis értéket ad vissza, az ág illeszkedni fog vagy sem.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
