# Bevezetés

## Sorok

A Gleam standard könyvtára egy `Queue` típust valósít meg a `gleam/queue` modulban. Hasonló a `List` típushoz, de van néhány lényeges különbség:

- A `Queue` típusnak nincs olyan literál szintaxisa, amellyel sorokat lehetne létrehozni vagy mintaillesztést végezni rajtuk.
- Az elemeket hatékonyan lehet hozzáadni és elvenni a `Queue` típus elejéről és végéről is, míg a `List` típusnál csak az elejéről lehet hatékonyan hozzáadni és elvenni elemeket.

A legtöbbször a `List` típust akarod majd használni, de amikor a gyűjtemény végéről is hozzá kell tudnod adni és elvenni elemeket, a `Queue` típus jó választás.

A sorokat a `queue.new` és a `queue.from_list` függvénnyel hozhatod létre:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Az elemeket a `queue.push_front` és a `queue.push_back` függvénnyel adhatod hozzá a sorhoz:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Az elemeket a `queue.pop_front` és a `queue.pop_back` függvénnyel veheted el a sorból:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Egy sort a `queue.to_list` függvénnyel alakíthatsz listává:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

### A sorok egyenlősége

A sorok megvalósítása miatt előfordulhat, hogy két sor, amely ugyanazokat az elemeket ugyanabban a sorrendben tartalmazza, nem egyenlő a `==` operátor szerint, amely szerkezetileg hasonlítja össze az értékeket. Például:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Ha két sort egyenlőség szempontjából kell összehasonlítanod, használhatod a `queue.is_logically_equal` függvényt.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
