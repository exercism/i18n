# Bevezetés

Az elágazások olyan utasítások, amelyek attól függően futtatnak különböző kódot, hogy egy feltétel `true` vagy `false`.

Egy `if` elágazás csak akkor futtatja a törzsét, ha a feltétele `true`.
A Go nem ismeri a truthy és falsy értékek fogalmát, ezért a feltételnek `bool` típusúnak kell lennie.
Az olyan kifejezések, mint az `if mySlice { ... }` vagy az `if 1 { ... }`, fordítási hibát adnak.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

További feltételek ellenőrzésére használj `else if`-et, tartalékként pedig `else`-t, ha egyik sem teljesül.
A feltételek fentről lefelé értékelődnek ki, és csak az első ág fut le, amelynek a feltétele igaz.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Egy `if` elágazás tartalmazhat egy rövid kezdőérték-utasítást is.
Az így deklarált változókra csak a teljes `if`/`else` láncon belül érvényes a scope.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
