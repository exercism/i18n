# Függvények

A függvények alapvető fontosságúak a Cairo-ban.

A Cairo konvenciója szerint a függvény- és változóneveket **snake case**-ben írjuk: a szavak kisbetűsek, és aláhúzásjel választja el őket.

Íme egy példa:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

A függvényeket az `fn` kulcsszóval definiáljuk; utána a név következik, majd a paraméterek zárójele (ha vannak), végül a kapcsos zárójelbe zárt törzs.

Egy függvényt úgy hívunk meg, hogy leírjuk a nevét, majd zárójelet teszünk utána.

A függvények sorrendje nem számít, amíg scope-ban vannak.

## Paraméterek

A függvények fogadhatnak **paramétereket**, amelyek a függvény szignatúrájában definiált változók.

Amikor meghívod a függvényt, **argumentumokat** adsz át, vagyis azokat az értékeket, amelyeket ezeknek a paramétereknek továbbítasz.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

Itt az `x` egy `felt252` típusú paraméter.

Amikor `5`-tel hívjuk meg, a függvény ezt írja ki: „The value of x is: 5”.

A több paramétert vessző választja el:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

Ez ezt írja ki: `The measurement is: 5h`.

## Utasítások és kifejezések

A Cairo függvényei **utasításokból** és **kifejezésekből** állnak:

- Az **utasítások** végrehajtanak valamit, de nem adnak vissza értéket.
Például a `let x = 3;` egy utasítás.
- A **kifejezések** kiértékelődnek egy értékké.
Például az `5 + 6` értéke `11`.

A kapcsos zárójelbe zárt blokkok is kifejezések, és a végső értékük lesz a visszatérési érték:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

Itt az `y` megkapja a `4` értéket.

## Visszatérési értékek

A függvények visszaadhatnak értékeket; a visszatérési típust a `->` szintaxissal adod meg.

Alapértelmezés szerint a függvény a legutolsó kifejezésének értékét adja vissza:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

Ez ezt írja ki: `The value of x is: 5`.

Bonyolultabb esetekre:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

Ez ezt írja ki: `The value of x is: 6`.

Vigyázz, hogy ne tegyél pontosvesszőt a legutolsó kifejezés végére, mert azzal utasítássá alakítanád, és a függvény a várt érték helyett `()`-t (unit típust) adna vissza.
