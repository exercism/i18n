# Az utasítások kiegészítése

## A kimenet formátuma

A dalszöveget nullával lezárt stringként add ki.

## Regiszterek

| Regiszter | Használat     | Típus   | Leírás                        |
| --------- | ------------- | ------- | ----------------------------- |
| `$a0`     | bemenet       | egész szám | kezdő versszak              |
| `$a1`     | bemenet       | egész szám | záró versszak               |
| `$a2`     | bemenet/kimenet | cím   | nullával lezárt kimeneti string |
| `$t0-9`   | ideiglenes    | bármi   | ideiglenes tárolásra          |
