# Bevezetés

## Stringek

Az F#-ban a `string` egy objektum, amely megváltoztathatatlan szöveget reprezentál Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként, és a következőképpen definiálható:

```fsharp
let fruit = "Apple"
```

A stringekkel úgy dolgozhatsz, hogy vagy a string metódusait hívod meg, vagy a `String` modul függvényeit használod. Miután egy string létrejött, az értéke soha nem változhat. Azok a metódusok/függvények, amelyek úgy tűnnek, hogy módosítják a stringet, valójában egy új stringet adnak vissza.

A stringeket többféleképpen is összefűzheted vagy formázhatod.
* Az összefűzéshez használhatod a `+` operátort:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* A szöveg formázásához használhatod a `sprintf` függvényt, ahol helyőrzők vannak egy formátumszövegben (`%s` a `string` értékekhez), és az értékeket argumentumként adod meg:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
