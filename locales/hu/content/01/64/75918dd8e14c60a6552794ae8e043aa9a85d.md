# Bevezetés

## Karakterek

### Karakterek

A Java `char` primitív típus egyetlen karakter 16 bites reprezentációja.
Több `char` alkothat egy stringet, például `"word"`, vagy a `char`-okat önállóan is feldolgozhatod.
A `char` literált egyszeres idézőjelek veszik körül (pl. `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

### `char`-ok kinyerése egy `String`-ből

A `String.toCharArray` metódus egy String `char`-jait tömbként adja vissza.
Ahogy a tömböknél említettük, egy `for` ciklussal végigmehetsz a tömb elemein.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### A Character osztály

Sok beépített könyvtári metódus létezik a `char`-ok vizsgálatára és manipulálására.
Ezek a `java.lang.Character` osztály statikus metódusaiként érhetők el.
Íme néhány példa:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### `char` hozzáadása egy `String`-hez

A `+` operátorral hozzáadhatsz egy `char`-t egy `String`-hez.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Vigyázz, hogy _ne_ használd a `+` operátort két `char` összefűzésére, hogy `String` legyen belőlük!
Ha két `char`-t így adsz össze, az egy `int` lesz, _nem_ pedig egy `String`!
Például:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Ez azért van, mert a Java a `char`-t `int`-té alakítja (lásd a [Java Language Specification][jls-main] [4.2 Primitive Types and Values ][jls-primitives] szakaszát).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Ha viszont sok karaktert kell összefűzni, hatékonyabb lehet helyette egy `StringBuilder`-t használni:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
