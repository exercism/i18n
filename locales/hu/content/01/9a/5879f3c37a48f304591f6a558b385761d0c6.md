# Bevezetés

Az Elixirben a dokumentáció első osztályú állampolgár.

A kódod dokumentálására gyakran két modulattribútumot használunk: a `@moduledoc` egy modul dokumentálására szolgál, a `@doc` pedig az attribútum után következő függvény dokumentálására. A `@moduledoc` attribútum általában a modul első sorában található, a `@doc` pedig általában közvetlenül egy függvénydefiníció előtt, vagy a függvény típusspecifikációja előtt, ha van ilyen. A dokumentációt általában többsoros stringben írják heredoc szintaxissal.

Az Elixir dokumentációja [**Markdown**][markdown] nyelven íródik.

```elixir
defmodule String do
  @moduledoc """
  Strings in Elixir are UTF-8 encoded binaries.
  """

  @doc """
  Converts all characters in the given string to uppercase according to `mode`.

  ## Examples

      iex> String.upcase("abcd")
      "ABCD"

      iex> String.upcase("olá")
      "OLÁ"
  """
  def upcase(string, mode \\ :default)
end
```

[markdown]: https://docs.github.com/en/github/writing-on-github/basic-writing-and-formatting-syntax
