# Utasítások

Refaktoráld a faépítő algoritmust.

Egyes webes fórumok faelrendezést használnak, így a bejegyzések fa formájában jelennek meg.
A bejegyzéseket azonban általában rendezetlen rekordhalmazként tárolja egy adatbázis.
Ezért amikor a bejegyzéseket megjelenítjük a felhasználónak, újra fel kell építeni a fa szerkezetét.

A feladatod az lesz, hogy refaktorálj egy működő, de lassú és csúnya kódrészt, amely erősen absztrahált rekordok faépítési logikáját valósítja meg.
A rekordok csak egy azonosítót és egy szülőazonosítót tartalmaznak.
Az azonosító mindig 0 (beleértve) és a rekordlista hossza (nem beleértve) között van.
Minden rekord szülőazonosítója kisebb, mint a saját azonosítója, kivéve a gyökérrekordot, amelynek a szülőazonosítója megegyezik a saját azonosítójával.

Példa egy fára:

```text
root (ID: 0, parent ID: 0)
|-- child1 (ID: 1, parent ID: 0)
|    |-- grandchild1 (ID: 2, parent ID: 1)
|    +-- grandchild2 (ID: 4, parent ID: 1)
+-- child2 (ID: 3, parent ID: 0)
|    +-- grandchild3 (ID: 6, parent ID: 3)
+-- child3 (ID: 5, parent ID: 0)
```
