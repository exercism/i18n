# Debug

A [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) segítségével üzeneteket fűzhetsz a sikertelen tesztekhez, így:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

Egy sikertelen tesztnél a csatolt log ez lesz: `secondsInOneHour: 3600`.

Van azonban egy buktató: a legfelső szintű konstansok csak egyszer értékelődnek ki, még mielőtt a tesztek elindulnának, ezért a tesztek nem tudják elkapni a logüzeneteiket. Például:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

ez a tesztek során nem ír ki semmilyen logot, mert a `secondsInOneHour`-hoz tartozó JavaScript-változó már kiértékelődött a 3600 értékre.
