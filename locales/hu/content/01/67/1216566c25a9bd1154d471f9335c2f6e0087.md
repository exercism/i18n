# Bevezetés

## Első lépések

### Változók

Az értékeket névhez rendelheted, ha definiálsz egy [változót][constants-variables], és értéket adsz neki.
Ez a név aztán az egész programban arra használható, hogy erre az értékre hivatkozz.
A változók _módosíthatók_, ami azt jelenti, hogy az értékük bármikor megváltoztatható.

A változókat a `var` kulcsszóval definiálod.

```swift
var variableName = 10
```

A Swift típusbiztos, statikusan típusos nyelv, ami azt jelenti, hogy minden értéknek már fordítási időben van típusa.
A változó típusát vagy explicit módon megadhatod [típusannotációkkal][type annotations], vagy hagyhatod, hogy a fordító [kikövetkeztesse a típust][type-inferring].

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

Egy változó értékét a `=` operátorral frissíted.

~~~~exercism/note
A változó típusa az első definiálás után végleges.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

A változókat értékadás nélkül is deklarálhatod, ha megadod a nevét és a típusát, de nem használhatod őket addig, amíg értéket nem kaptak.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Konstansok

A [konstansok][constants-variables] hasonlítanak a változókhoz abban, hogy névhez és értékhez vannak rendelve, de a konstans értéke a kezdeti értékadás után nem változtatható meg, vagyis _módosíthatatlan_.
A konstansokat a `let` kulcsszóval definiálod.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Összeadás, kivonás és szorzás

A Swiftben [operátorok][arithmetical-operators] állnak rendelkezésre az összeadáshoz, kivonáshoz és szorzáshoz.
Ezek rendre a `+`, a `-` és a `*`.

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Függvények

A Swiftben a [függvények][functions] olyan kódrészletek, amelyek egy feladatot látnak el.
A függvénynek van visszatérési típusa, így értékként is használható, és argumentumként átadható más függvényeknek.
A Swiftben a függvényeket a `func` kulcsszóval definiálod, amelyet a függvény neve, vesszővel elválasztott argumentumok és egy visszatérési típus követ.

Az argumentumokat egy argumentumcímke, valamint egy kettősponttal és egy típussal követett paraméternév adja meg.
A visszatérési típust egy `->` és a visszaadott érték típusa adja meg.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

A Swift argumentumai kicsit különlegesek a többi nyelvhez képest: [argumentumcímkéket][argument-labels] használnak.
Az argumentumcímkét a függvény hívásakor használod.
A paraméternevet a függvény törzsén belül használod az argumentum értékére való hivatkozáshoz.
Ha csak egy nevet adsz az argumentumnak, az argumentumcímkeként és paraméternévként is használatos lesz.
Ha az argumentumcímke neve `_`, akkor az argumentumnak nem lesz címkéje a függvény hívásakor, például: `functionName(argumentValue)`

Egy függvény hívásához a függvény nevét, majd az argumentumcímkét és az argumentum értékét használod, így:

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Minden argumentum alapértelmezés szerint módosíthatatlan, és a függvényen belül nem változtatható meg.
Ha egy függvénynek visszatérési típusa van, mindenképpen adj vissza ilyen típusú értéket.
Ezt a `return` kulcsszóval teszed, amelyet a visszaadni kívánt érték követ.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Ha a függvények nem adnak vissza értéket, a visszatérési típusuk `Void`, ami ugyanaz, mint a `()`, de ilyenkor a visszatérési típus el is hagyható.
