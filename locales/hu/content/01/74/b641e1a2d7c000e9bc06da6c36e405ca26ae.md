# Használj farokhívásos rekurziót

A feladat célja, hogy megtanítsa a farokhívásos rekurziót. Oldd meg úgy, hogy nem használsz olyan rekurzív függvényeket, amelyek nem farokrekurzívak.

A megoldásodban talált farokhívásos rekurziót használó függvények: %{tail_call_recursive_functions}. A megoldásodban talált további rekurzív függvények: %{non_tail_call_recursive_functions}.

Ne feledd, farokhívásos rekurzióról akkor van szó, amikor a függvény által kiértékelt _utolsó_ kifejezés a függvény önmagára irányuló hívása.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
