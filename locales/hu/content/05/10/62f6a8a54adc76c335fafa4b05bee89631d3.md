# Bevezetés az alapokba

A [Go](https://golang.org) egy statikusan típusos, fordított programozási nyelv.
A Go szintaxisa a C-hez hasonlít.
A nyelvet gyakran emlegetik Golang néven a korábbi domainneve, a golang.org miatt, de a helyes neve Go.

Az Alapok fogalom három fontos nyelvi jellemzőt mutat be: a csomagokat, a függvényeket és a változókat.

## Csomagok

A Go-alkalmazásokat csomagokba szervezzük.
Egy csomag az ugyanabban a könyvtárban található forrásfájlok gyűjteménye.
Egy könyvtár minden forrásfájljának ugyanazt a csomagnevet kell viselnie.
Az a szokás, hogy a csomagnév az importálási útvonal utolsó könyvtára legyen.
Például a ["math/rand" csomag](https://golang.org/src/math/rand/) fájljai a `package rand` utasítással kezdődnek.
Amikor egy csomagot importálunk, csak azok az entitások (függvények, típusok, változók, konstansok) használhatók, amelyeknek a neve nagybetűvel kezdődik.
A Go-ban az ajánlott elnevezési stílus szerint az azonosítókat `camelCase` stílusban írjuk, kivéve azokat, amelyeknek csomagokon át elérhetőknek kell lenniük, mert azokat `PascalCase` stílusban.

```go
package lasagna
```

## Változók

A Go statikusan típusos, ami azt jelenti, hogy minden változónak [meghatározott típussal kell rendelkeznie](https://en.wikipedia.org/wiki/Type_system) fordítási időben.

A változókat definiálhatjuk úgy, hogy kifejezetten megadunk egy típust:

```go
var explicit int // Explicitly typed
```

Használhatsz kezdőértéket is, és ilyenkor a fordító a kezdőérték típusához igazítja a változó típusát.

```go
implicit := 10   // Implicitly typed as an int
```

Ha egyszer deklaráltál egy változót, értéket adhatsz neki a `=` operátorral.
Egy változó típusa a deklaráció után soha nem változhat.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Konstansok

A konstansok a változókhoz hasonlóan egy adatot tárolnak, de az értékük a program futása közben nem változhat.

A konstansokat a `const` kulcsszóval definiáljuk, és lehetnek számok, karakterek, stringek vagy Boolean-ok:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Függvények

A Go-függvények nulla vagy több paramétert fogadnak.
A paraméterek típusát kifejezetten meg kell adni, itt nincs típuskövetkeztetés.

A függvények a `return` kulcsszóval adnak vissza értékeket.

Egy függvényt úgy hívunk meg, hogy megadjuk a függvény nevét, és argumentumot adunk át a függvény minden paraméteréhez.

Fontos, hogy a Go kétféle megjegyzést támogat.
Az egysoros megjegyzéseket `//` előzi meg, a többsorosakat pedig `/*` és `*/` közé írjuk.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
