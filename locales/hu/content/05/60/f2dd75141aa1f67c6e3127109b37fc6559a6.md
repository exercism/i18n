# Telepítés

- macOS: futtasd a `brew install futhark` parancsot
- linux: futtasd a `brew install futhark` parancsot
- Windows: vagy használd a WSL-t, vagy kövesd [a Windows-specifikus utasításokat][windows-specific-instructions]

További telepítési módokat a [hivatalos telepítési útmutatóban][instructions] találsz.

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
