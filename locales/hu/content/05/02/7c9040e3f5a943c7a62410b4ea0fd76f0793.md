# Utasítások

Ebben a feladatban félig strukturált naplóüzeneteket fogsz előállítani.

## 1. Félig strukturált üzenetek előállítása

Néhány előre elkészített, üres törzsű függvényből és a következő felsorolásból indulsz ki:

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

A célod, hogy a következő formátumban állíts elő naplóüzenetet: `"[<LEVEL>]: <MESSAGE>"`.
Ehhez olyan függvényeket kell megvalósítanod, amelyek megfelelnek a naplózási szinteknek.

Például az alábbi részlet a `log` függvény egy várható kimenetét mutatja be.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Az `info` függvény esetében pedig:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Jó szórakozást!

## 2. További gyakorlás (nem kötelező)

Ebben a tesztkészletben van egy feature-kapuval védett teszt.
A feature-kapuk bizonyos programrészek fordítását teljesen letiltják.
Ezekre később még kitérünk.
Egyelőre csak annyit jegyezz meg, hogy van egy teszt, amely csak akkor fordul le és fut le, ha egy speciális parancsot használsz a teszteléshez:

```sh
cargo test --features add-a-variant
```

Ez a teszt azt hivatott megmutatni, hogyan adj hozzá egy új változatot a felsorolásodhoz.
