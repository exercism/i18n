# Kiegészítés az utasításokhoz

## Néhány megjegyzés az Arturo stringjeiről

A tesztekben olyan szintaxissal találkozhatsz, ami új lehet számodra: több soros stringek, `{ braces }` közé zárva.

### Hivatkozások

* [`:string` típus][string] a nyelvi referenciában.
* [Basic Usage][usage] dokumentáció a Strings modulban.

[string]: https://arturo-lang.io/documentation/language/#string
[usage]: https://arturo-lang.io/documentation/library/strings/#basic-usage

### Arturo stringliterálok

Az Arturóban többféleképpen írhatsz stringliterált:

1. Egysoros stringek kettős idézőjelben

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. Sorvégi stringek „okos idézőjellel” (`«`)

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   Ezek jól olvashatók, ha rövid stringekből álló listád van:

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. Több soros stringek kapcsos zárójelbe zárva.
   A „közös” behúzás törlődik.
   A kezdő és záró sortörések törlődnek.

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. A verbatim stringek pontosan megmaradnak, a kezdő és záró whitespace-szel együtt

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. A heredoc stílusú stringek egy 3 vagy több kötőjelből álló sor alatt helyezkednek el, egészen a fájl végéig.
   Ez ugyanúgy működik, mint a Perl `__DATA__` kulcsszava.
   Ez a stílus hasznos lehet egy modulban, ahol a fájl végén egy változóban tárolhatod a dokumentációt vagy a licenc szövegét.

    Ha ez egy „mymodule.art” nevű fájlban van

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    Ezután

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
