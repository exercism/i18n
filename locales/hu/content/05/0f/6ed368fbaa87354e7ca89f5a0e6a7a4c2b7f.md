# Bevezetés

Az osztályok a Swift programok egyik alapeleme.
Lehetővé teszik, hogy a kapcsolódó tulajdonságokat (adatokat) és metódusokat (függvényeket) önálló funkcionális egységekbe csoportosítsuk.

### Osztályok definiálása

Egy osztály definiálásához használd a `class` kulcsszót, majd írd le az osztály nevét, az osztálydefiníciót pedig tedd kapcsos zárójelek közé:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

Egy osztály törzse állhat tárolt tulajdonságokból, amelyeket ugyanúgy definiálunk, és amelyek ugyanúgy viselkednek, mint a szokásos konstansok (`let`) vagy változók (`var`).

### Példányok

Egy osztálydefiníció tervrajzként szolgál: egy új típust definiál, és leírja, hogyan fognak kinézni az értékei, de önmagában nem hoz létre egyetlen példányt sem.

Ahhoz, hogy létrehozd egy osztály *példányát*, írd le az osztály nevét, majd utána egy pár zárójelet:

```swift
let someCharacter = GameCharacter()
```

Ez egy új példányt hoz létre, amelynek a tulajdonságai az osztálydefinícióban megadott alapértelmezett értékekkel töltődnek fel.
Az olyan opcionális tulajdonságok esetében, amelyeknek nincs kifejezett alapértelmezett értékük (mint például a `name`), a Swift ezeket `nil`-re állítja.

### Tulajdonságok elérése

Egy példány tulajdonságait *pontjelöléssel* érheted el: írd le a példány nevét, egy pontot (`.`), majd a tulajdonság nevét.
A pontjelölés az egymásba ágyazott tulajdonságoknál is működik.

A pontjelöléssel értékeket olvashatsz ki, és ha a tulajdonság módosítható (`var`), új értékeket is adhatsz neki:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Metódusok

A tulajdonságok mellett az osztályok *metódusokat* is definiálhatnak, vagyis az osztályhoz kapcsolódó függvényeket.

A metódusokat az osztály törzsén belül definiáld a szokásos `func` szintaxissal.
Ha egy metódus módosít egy tulajdonságot, akkor azt a tulajdonságot `var`-ral kell definiálni:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

A metódusokat egy példányon pontjelöléssel hívod meg, akárcsak a tulajdonságokat:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Minden osztálypéldánynak van egy `self` nevű implicit tulajdonsága, amely magára a példányra hivatkozik.
Bár a tulajdonságokra vagy metódusokra hivatkozva gyakran elhagyható, a `self`-et általában akkor használjuk, hogy megkülönböztessük egymástól a tulajdonságok és a metódusparaméterek nevét, amikor azok megegyeznek.
