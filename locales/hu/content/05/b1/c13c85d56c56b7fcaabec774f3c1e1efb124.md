# Bevezetés

A `bit` a legapróbb érték a számítástechnikában.
A `bit` szó a »binary digit«, azaz a kettes számrendszerbeli számjegy rövidítése.
Ez egy akkora adattárolási egység a végrehajtási környezetben, amely elég nagy ahhoz, hogy eltároljon egy objektumot, amely két érték valamelyikét veheti fel.
Ennek megfelelően bináris értéke `1` vagy `0`.
Minden más adattípus több `bits`-ből áll.
Például egy `byte` általában nyolc `bits`-ből áll.

## Bitmaszkok

A bitmaszk bármilyen érték lehet, amelyet az egyes bitek beállítására használunk.
Az angol ábécében például huszonhat betű van.
Egy legalább huszonhat bites érték, például egy előjel nélküli 32 bites egész szám, bitmaszkként használható ahhoz, hogy minden angol betűhöz beállítsunk egy `true` vagy `false` feltételt.
Bármely érték, amelyben elég bit van a szükséges `true` vagy `false` feltételek kezeléséhez, szolgálhat bitmaszkként.
Az egyes bitek beállítása és kiolvasása bitenkénti operátorokkal történik.

## Bitenkénti operátorok

Tegyük fel, hogy nyomon akarjuk követni, mely betűk fordulnak elő egy `string`-ben.
A példánkban csak az angol ábécé huszonhat betűjét használjuk.
A bitmaszkunk egy előjel nélküli 32 bites egész szám lesz.
A `0` azt jelképezi, hogy a betű nem fordul elő.
A `1` azt jelképezi, hogy a betű egyszer vagy többször előfordul.
Kezdetben a bitmaszkunk bináris reprezentációja 32 `0s` egymás után: `00000000000000000000000000000000`.
A jobb szélső pozíció az `A` betűé lesz.
A balról számított második a `B` betűé, és így tovább.
Tegyük fel, hogy a string összes betűjét egy ciklusban dolgozzuk fel, ezért szeretnénk egyetlen kódsort, amely bármely betű beállítására működik.

### Bitenkénti balra léptető operátor: így pozicionálhatsz egy bitet

A `<<` a bitenkénti balra léptetés operátora.

Ha a betűnk `A`, nem akarunk balra léptetni, de ha a betűnk `B`, egy pozícióval akarunk balra léptetni, ha pedig `C`, kettővel, és így tovább.
Bár a `chars`-t `A` vagy `B` betűkként érzékeljük, a `char` a memóriában egész szám típusként van megvalósítva, ezért egyszerű számításokat végezhetünk vele.
Ha adott egy `letter` nevű változó, amely a feldolgozott `char`-t jelöli, a szükséges számú pozícióval balra léptethetünk úgy, hogy az `1`-et balra léptetjük a `letter` és az `A` `char` közötti különbséggel, így: `1 << letter - 'A'`.
`A` - `A` az `0`, tehát `0` pozícióval léptetne balra, ha a `letter` értéke `A`.
`B` - `A` az `1`, tehát `1` pozícióval léptetne balra, ha a `letter` értéke `B`, és így tovább.

### Bitenkénti inkluzív VAGY operátor: így állíthatsz be egy bitet

Ha már tudjuk, _hol_ akarunk beállítani egy bitet, be is állíthatjuk a bitenkénti inkluzív VAGY operátorral, amely a `|`.
A `|` operátor eredménye minden olyan pozícióban `1` lesz, ahol a bal vagy a jobb operandusban be van állítva egy bit.
Tehát a `0010 | 0001` eredménye `0011` lenne.
(Fontos megjegyezni, hogy az érték binárisan `11`, tizedesen viszont `3`.)
Ahhoz, hogy az eredményt hozzárendeljük egy értékhez, a `|` operátor kombinálható az értékadás operátorával, és így állíthatjuk be a biteket: `|=`.
Az egyszerűség kedvéért a következő példa nem használ ciklust, de bemutatja, hogyan dolgozhatnánk fel az `ABA` betűket egy bitmaszkban.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

A maszk jobb szélső részét `A` esetén `0001`-re állítjuk, majd `B` esetén a maszkot `0011`-re.
Egy újabb `A` beállítása nem változtatja meg a meglévő maszkot.
Elkerülhettük volna a bit újbóli beállítását, ha megnézzük, hogy az `A` már be van-e állítva.

### Bitenkénti ÉS operátor: így olvashatsz ki egy bitet

A `&` a bitenkénti ÉS operátor.
A `&` operátor eredménye minden olyan pozícióban `1` lesz, ahol mind a bal, mind a jobb operandusban be van állítva egy bit.
Tehát a `0011 & 0001` eredménye `0001` lenne.
Ezt működés közben a következő példában láthatjuk.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Bitenkénti kizáró VAGY operátor: így billenthetsz át egy bitet

A `^` a bitenkénti kizáró VAGY operátor.
Az _inkluzív_ VAGY operátor léte magában foglalja, hogy van egy más viselkedésű _kizáró_ VAGY operátor is.
A `^` operátor eredménye minden olyan pozícióban `1` lesz, ahol a bal és a jobb operandus közül _csak az egyikben_ van beállítva egy bit.
Tehát a `0001 ^ 0011` eredménye `0010` lenne.
A jobb szélső bit nem lesz beállítva, mert _mindkét_ operandusban `1` van a jobb szélső pozícióban.
A kizáró VAGY műveletet néha XOR-ként jelölik.
Ha egy XOR-olt érték eredményét ismét XOR-oljuk, visszakapjuk az eredeti értéket.
Ez egy nagyon egyszerű titkosításhoz használható, ahol ugyanazt a kulcsot használjuk az adatok titkosításához és visszafejtéséhez is.
Például

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## Bitmezők

Láttuk, hogyan lehet az egyszerű adattípusba csomagolt biteket a pozíciójuk alapján elérni.
A `struct`-ba csomagolt biteket a nevük alapján érhetjük el.
Az ilyen adattípust `bit field`-nek nevezzük.
A `bit fields`-re akkor lehet szükség, amikor egy csomó BE/KI jelzőre van szükség, és a memóriahasználat minimalizálása a cél.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

Az `unsigned int variable_name : 1;` szintaxisa egy `1` bites mezőt hoz létre egy `unsigned int`-en belül, amely a structban kap helyet.
`unsigned int` helyett használhatunk `signed int`-et, vagy a C99-es szabványtól kezdve akár `bool` típust is.
Egy bitmezőket tartalmazó struct más adattípusú mezőket is tartalmazhat, mint például a fenti példában a `number_of_lights`.
