# Utasítások

Ebben a feladatban kódot írsz majd, hogy a kedvenc szakácskönyvedből egy ragyogó lasagnét készíthess.

Négy részfeladatod van, mindegyik a lasagna elkészítésével töltött időhöz kapcsolódik.

## 1. Definiáld a sütőben töltött várható időt percekben

Definiálj egy `$expected_minutes_in_oven` nevű konstanst.
A szakácskönyv szerint a sütőben töltött várható idő 40 perc:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. Számítsd ki a hátralévő sütési időt percekben

Ez az érték bemenetként a lasagna sütőben töltött tényleges perceit kapja, és visszaadja, hány percet kell még a lasagnának a sütőben maradnia, az előző részfeladat várható sütési ideje alapján.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. Számítsd ki az előkészítési időt percekben

Az előkészítési idő azt jelenti, mennyi ideig tart, míg a lasagna elkészül, mielőtt a sütőbe kerül.
Minden réteg elkészítése 2 percet vesz igénybe.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. Számítsd ki a teljes munkával töltött időt percekben

Számítsd ki, hogy összesen hány percet dolgoztál a lasagna elkészítésén.
Ez az előkészítési idő percekben mért értékének és a lasagna által a sütőben eddig eltöltött perceknek az összege.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
