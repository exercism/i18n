# Tippek

## 1. Definiáld a `TreasureChest` opaque típust.

- Az opaque típusokat az `opaque` kulcsszóval definiáljuk.

## 2. Definiáld a `create` függvényt.

- Egy string hosszát a [`string.length` függvénnyel][length] kaphatod meg.

## 3. Definiáld az `open` függvényt.

- Két string egyenlőségét a `==` operátorral hasonlíthatod össze.

[length]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#length
