# Bevezetés

## Típusdeklaráció

A PHP-beli típusdeklarációk futásidőben típusellenőrzést biztosítanak a függvények argumentumaihoz, visszatérési értékeihez és az osztálytulajdonságokhoz.
Függvényeknél hozzáadható `void` visszatérési típus, jelezve, hogy a függvény nem ad vissza értéket.
A deklarált típusok futásidőben azt is ellenőrzik, hogy a függvények megfelelő típusú választ adnak vissza.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### Típusuniók

Ha egy függvényargumentum, visszatérési érték vagy osztálytulajdonság egynél több típusú lehet, akkor típusunió deklarálható.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### Vegyes típusok

Amikor kóddal dolgozunk, előfordulhat, hogy nem tudunk típust megadni.
A PHP 8.0-tól kezdve van egy `mixed` nevű kiskapu típus.
A `mixed` egyenértékű a `object|resource|array|string|float|int|bool|null` típusunióval.
