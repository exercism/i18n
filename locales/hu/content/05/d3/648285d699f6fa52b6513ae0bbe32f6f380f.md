# Kiegészítés

## GNU awk és tetszőleges pontosságú aritmetika

Alapértelmezés szerint az `awk`-ban a számok dupla pontosságú lebegőpontos számként vannak ábrázolva. Ez 53 bitnyi pontosságot biztosít (lásd a kézikönyv [16.3. táblázatát][table-16.3]). Sajnos ez nem elegendő a feladat teljesítéséhez (spoilerveszély: az egyik teszt 63 bitnyi pontosságot igényel).

A „nem elegendő pontosság” így néz ki:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

A GNU `awk` képes tetszőleges pontosságú számok használatára, ha a megfelelő könyvtárakat belefordították az `awk` futtatható állományába. Ellenőrizd az awk verzióját, és keresd a „GNU MPFR” szöveget:
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

Ha megvan, engedélyezd ezt a lehetőséget a `-M` kapcsolóval:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

Mi van, ha az `awk`-om nem támogatja a `-M` kapcsolót? Egy külső programot kell meghívnod, amely képes tetszőleges pontosságú aritmetikára, például a `bc`-t. Nézd meg a [getline használata változóba olvasáshoz csőből][getline-pipe] szakaszt, ahol példát találsz erre.
