# Névjegy

A Factor feltételes elágazásai mind **quotations**-t használnak ágként, szögletes zárójelbe írt kódot, `[ ... ]`, amely értékként kerül a verembe, nem pedig végrehajtódik, amíg az elágazás ki nem választja. (A **quotations**-ről egy későbbi feladatban részletesen lesz szó.)

A három alapvető a `kernel`-ben található:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

Két csillagos változat a Boolean-t értékként kezeli, amikor igaz, a kanonikus „érték-vagy-`f`” pár:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

Kettőnél több ág esetén a `cond` (a `combinators` szóban) végigjár egy `{ predicate body }` párokból álló tömböt, és lefuttatja az első olyan predikátum testét, amely igaz. A hagyományos minta minden predikátumban `dup`-ot használ, hogy a bemenet megmaradjon, a test pedig egy `drop`-pal kezdődik, hogy eldobja azt, mielőtt az eredményt a verembe tenné:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

A predikátum nélküli, legvégén szereplő bejegyzés az alapértelmezett ág.
