# Leírás

Ha ugyanazt a logikát szeretnénk többször végrehajtani, ciklusokat használhatunk. Ha a ciklusban lévő kódot mindenképpen legalább egyszer végre kell hajtani, `do`/`while` ciklust használhatunk:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

Ezt ritkábban használjuk, mint a `while` ciklust, bizonyos esetekben viszont természetesebb megjelenésű kódot eredményez.
