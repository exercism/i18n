# függvényszintű guard használata

[comment]: # (Ez a hiba akkor jelenik meg, ha a megoldás használ guardokat, de nem a függvényklózban)

A függvényklózban [guardokat](https://hexdocs.pm/elixir/master/guards.html) használj, hogy a `two_fer/1` ne hajtson végre kódot nem bináris bemenetekkel.

```elixir
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

Ha egy függvényt olyan argumentumokkal hívsz meg, amelyek egyik megadott klóznak sem felelnek meg, `FunctionClauseError` hibát kapsz.

```elixir
hello(123)

# => ** (FunctionClauseError) no function clause matching in hello/1
#
#    The following arguments were given to Foo.hello/1:
#
#    # 1
#    123
```
