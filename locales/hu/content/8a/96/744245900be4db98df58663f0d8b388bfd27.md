# Névjegy

## Számok

A Swiftnek két fő számtípusa van: az egészek és a lebegőpontos számok.
Az [egész számok][integers] olyan számok, amelyeknek nincs törtrészük, például `0`, `1`, `-1`, `42` és `-273`.
A [lebegőpontos számok][floatingpoint] olyan számok, amelyeknek törtrészük van, például `0.0`, `3.14` és `-1.36969e-10`.
A Swift emellett aláhúzásjelekkel is átláthatóbbá teheti a számokat: az `1_000_000` ugyanaz, mint a `1000000`.
A lebegőpontos számok tizedes vagy exponenciális jelöléssel is felírhatók.

A legtöbb esetben az egészek típusát [`Int`][int]-ként, a lebegőpontos számokét pedig [`Double`][double]-ként adod meg.

Ha egy változót vagy konstanst `Int` vagy `Double` típusúként szeretnél deklarálni, típusannotációt használhatsz:

```swift
let speed: Int = 42                           // speed is an Int
let pi: Double = 3.14                         // pi is a Double
let giga: Double = 1_000_000_000              // giga is a Double
let plancksConstant : Double = 6.62607015e-34 // plancksConstant is a Double
```

## Aritmetikai operátorok

~~~~exercism/caution
A Swiftben nem keverhetők a típusok az aritmetikai műveletekben, ezért nem használhatsz aritmetikai operátort egy `Int` és egy `Double` között, és fordítva sem.
Ezért először típuskonverziót kell végezned.
~~~~

A Swiftnek természetesen van egy sor [aritmetikai operátora][arithmetic-operators], amelyekkel alapvető matematikai műveleteket végezhetsz el.
A `+` operátor az összeadásra, a `-` operátor a kivonásra, a `*` operátor pedig a szorzásra szolgál.

| Operátor | Példa                 |
| -------- | ----------------------- |
| `+`      | `4 + 6   // equals  10` |
| `-`      | `15 - 10 // equals  5`  |
| `*`      | `2 * 3   // equals  6`  |

### Osztás

A `/` operátor az osztásra szolgál.
Lebegőpontos szám használatakor az eredmény is lebegőpontos szám lesz.
Egész számok használatakor viszont az eredmény egész szám lesz.

```swift
5 / 2.0 // equals 2.5
5 / 2   // equals 2
```

A nullával való osztás eredménye a szám típusától függően más lesz.
Ha egy lebegőpontos számot osztasz nullával, az eredmény `inf` lesz, vagy `-inf`, ha az osztandó szám negatív.
Az egyetlen kivétel az, amikor nullát osztasz nullával, és a kettő közül az egyik lebegőpontos szám, ilyenkor az eredmény `nan` lesz.
Ha egy egész számot osztasz nullával, fordítási hibát kapsz.

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following code will not compile
print(5 / 0) // error: division by zero
```

### Maradék

A [`%` operátor][reminder-operator] az osztás maradékát adja meg, és csak egész számokkal működik.
Az operátor az első argumentum másodikkal való osztásának maradékát adja vissza.
És ahogy az osztásnál, ha a második argumentum értéke nulla, fordítási hibát kapsz.

~~~~exercism/note
Más nyelvekben ezt az operátort modulo operátorként is ismerik.
A Swiftben azonban nem ugyanúgy működik, mint a modulo operátor, mert szigorúan véve a maradékot adja vissza, nem a modulót.
~~~~

```swift
5 % 2  // equals 1
-5 % 2 // equals -1

// The following code will not compile
5 % 0 // error: division by zero
```

## Számok kerekítése

A számok kerekítéséhez egy lebegőpontos szám `rounded()` metódusát használod.
A legközelebbi egész számra kerekítéshez a `rounded()` metódust argumentum nélkül hívod meg.
Felfelé vagy lefelé kerekítéshez a `rounded(.up)`, illetve a `rounded(.down)` metódust használhatod.

```swift
let x = 3.14
let y = x.rounded()      // y equals 3.0
let w = x.rounded(.down) // w equals 3.0
let z = x.rounded(.up)   // z equals 4.0
```

## Típuskövetkeztetés

A Swift a kontextus alapján [kikövetkezteti, milyen típusú][typeinference] egy szám, további információ nélkül pedig a fordító azt feltételezi, hogy a szám `Int`.
Ha szeretnéd megmondani a fordítónak, hogy egy egész szám `Double` legyen, akkor vagy típusannotációt használsz, vagy a szám literál végére írsz egy `.0`-t. Például:

```swift
let x = 42         // x is an Int
let y = 42.0       // y is a Double
let z: Double = 42 // z is a Double
```

## Típuskonverzió

A Swiftben ahhoz, hogy egy értéket egyik típusból a másikba alakíts, [típuskonverziót][type-conversion] kell végezned.
Ahhoz például, hogy egy `Int` értéket `Double` típusúvá alakíts, vagy fordítva, a következőt kell tenned:

```swift
let x = 42
let d = Double(x)
print(d)           // Prints 42.0
print(type(of: d)) // Prints Double

let pi = 3.14
let iPi = Int(pi)
print(iPi)           // Prints 3
print(type(of: iPi)) // Prints Int
```
