# Bevezetés

Ez a feladat arra az egészszám-aritmetikára épül, amit a [Leah ínycsiklandó lasagnéja][lasagna] feladatban láttál. Itt lebegőpontos számokkal fogsz dolgozni, és kiválasztod a feladathoz illő osztási szót.

## Egész és lebegőpontos számok

A Factor megkülönbözteti az egész számokat (`1`, `42`, `1_000_000`) a lebegőpontos számoktól (`1.0`, `3.14`, `6.02e23`). Ha egy számításban vegyítesz egy egész és egy lebegőpontos számot, az eredmény lebegőpontos lesz:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

A számjegyek csoportosításához aláhúzásjelet tehetsz a számba, például `1_000_000`, és a Factor egyszerűen figyelmen kívül hagyja őket.

## Osztási szavak

A Factornak külön szavai vannak az osztásra. Mind a [`math`][math] szótárban található.

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

A `/` két egész számra `ratio`-t (a Factor egzakt racionális típusát) ad, vagy `float`-ot, ha valamelyik bemenet lebegőpontos. A `/f` akkor is lebegőpontos eredményt kényszerít ki, ha mindkét bemenet egész. A `/i` mindig a nulla felé csonkít.

## Ellenőrzés

Számpredikátumok a [`math`][math], a [`math.functions`][math.functions] és a [`math.primes`][math.primes] szótárból:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## Lebegőpontosból egész szám

A [`math.functions`][math.functions] szótár `floor`, `ceiling` és `round` szava mind lebegőpontos értéket ad vissza (`3.0`-t, nem `3`-at). Hogy valódi egész számot kapj, fűzd mögé a `>integer`-t:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## Hatványok és abszolútérték

A `sq`, `^` és `abs` (a [`math.functions`][math.functions] szótárban) négyzetet, tetszőleges hatványt és abszolútértéket számol:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## Minimum és maximum

A `min ( x y -- z )` és a `max ( x y -- z )` (a [`math.order`][math.order] szótárban) két szám közül a kisebbet, illetve a nagyobbat adja vissza:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

A leggyakoribb felhasználás a *leszorítás*: egy értéket a `max`-szal egy alsó korláthoz rögzítesz (például a `0 max` nem engedi, hogy egy érték negatív legyen), a `min`-nel pedig egy felső korláthoz.

## Rendezési predikátumok

A `math.order` emellett `before?`, `after?`, `before=?` és `after=?` predikátumokat is kínál olyan összehasonlításokhoz, amelyek bármilyen rendezhető típuson működnek (számokon, stringeken, karaktereken):

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

Ezeket használd a `<`/`<=` helyett, amikor az értékek stringek is lehetnek, mert az aritmetikai operátorok nem működnek stringeken.
