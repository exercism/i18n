# Tesztek

Minden feladat tartalmaz egy tesztfájlt.
A teszteket a `bats` programmal futtathatod.

```bash
bats hello_world.bats
```

Ha a tesztek helyi futtatása közben hibakeresési kimenetet szeretnél kiírni, lásd a [Helyi hibakeresés][debugging] részt.

A `bats`-et telepíteni kell.
A [Tesztek a Bash kurzussal][tests] oldalon útmutatást találsz arról, hogyan telepítsd a `bats`-et a saját rendszeredre.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Segítség az assert függvényekhez

A tesztek a [bats-assert][bats-assert] könyvtár függvényeit használják.
A különféle `assert*` függvények leírása ott található.

[bats-assert]: https://github.com/bats-core/bats-assert

## Kihagyott tesztek

Egy feladat megoldása azt jelenti, hogy minden tesztje sikeres.
Alapértelmezés szerint a tesztek futtatásakor csak egy teszt (az első) fut le.
Ez szándékos, mert így arra összpontosíthatsz, hogy éppen azt az egy tesztet teljesítsd.
Ha ez sikerült, a következő tesztet a következő annotáció kikommentelésével vagy eltávolításával engedélyezheted:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## A kihagyások felülbírálása

Az összes teszt futtatásához, beleértve a `skip` annotációval ellátottakat is, ezt futtathatod:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Kényelmes lehet egy burkolófüggvény használata, hogy kevesebbet kelljen gépelned:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Ezután a teszteket így futtathatod:

```bash
bats
```
