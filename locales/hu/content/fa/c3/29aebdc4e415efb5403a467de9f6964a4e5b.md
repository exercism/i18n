# osztályok

Az osztályok központi fogalom az [objektumorientált programozásban][object-oriented-programming].
[A Crystalben minden objektum][everything-is-an-object], minden objektumnak van típusa, és képes válaszolni bizonyos metódusokra.
Az osztályok tervrajzok, amelyek alapján objektumokat hozunk létre: kezdőértéket adnak az állapotnak, például a változóknak, és megvalósítják a viselkedést, például a metódusokat.
Az objektumok az osztályok példányai, amelyek tartalmazzák az összes példányváltozót és állapotot.

## Az osztály definiálása

Egy osztályt a `class` kulcsszóval definiálunk, utána az osztály neve következik `UpperCamelCase` írásmóddal.

```crystal
class Account
end
```

## Példány létrehozása

Ha [egy osztály példányát szeretnéd létrehozni][new-initialize], hívd meg az osztályon a `new` metódust.

```crystal
class Account
end

account = Account.new
```

A fenti példában az `account` változó az `Account` osztály egy példánya.

Példány létrehozásakor egy `initialize` nevű speciális metódus működik konstruktorként.
Ez akkor hívódik meg, amikor létrejön egy példány.
A konstruktor segítségével beállíthatod a példány kezdőállapotát.
Az `initialize` metódus fogadhat argumentumokat, amelyeket a példány létrehozásakor adsz át.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
Az `initialize` metódus nem adhat vissza értéket kézzel, helyette a `new` adja vissza az újonnan létrehozott példányt.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Példánymetódusok

A példánymetódus olyan metódus, amely egy osztály példányán érhető el, és meghívható azon a példányon.
A példánymetódusokat a `def` kulcsszóval definiáljuk, utána a metódus neve következik.
Az osztálydefiníción belül definiáljuk őket.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Példányváltozók

A [példányváltozók][instance-variable] olyan változók, amelyek a példány minden metódusában elérhetők.
Egy példányváltozó eléréséhez példánymetódust kell definiálnod.
Kezdőértéket az `initialize` metódusban adhatsz nekik.
A `@` előtaggal definiáljuk őket.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

A példányváltozókat az osztálydefiníción belül is definiálhatod.

```crystal
class Account
  @age = 0
end
```

### Példányváltozók kezdőértékkel

A példányváltozóknak kezdőértéket adhatsz az `initialize` metódusnak átadott argumentummal.
Mivel a Crystal nem tudja kikövetkeztetni a példányosításkor használt argumentum típusát, ezért meg kell adnod azt.
Ha többet szeretnél erről olvasni: [típuskövetkeztetés][type-inference].
A változó típusának megadásához használd a `:` jelet, utána a típust.
Ha például egy `balance` nevű, `Int32` típusú példányváltozót szeretnél létrehozni, ezt így teheted: `@balance : Int32`.
Vagy ha egy `raining` nevű, `Bool` típusú példányváltozót szeretnél létrehozni: `@raining : Bool`.

Többféleképpen is megvalósíthatod: az `initialize` metódusban megadhatod az argumentum típusát, majd hozzárendelheted a példányváltozót az argumentumhoz, ahogy az alábbi példában:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Egy másik módszer, ha a példányváltozó típusát az osztálydefinícióban adod meg `@<variable> : <Type>` formában, ahogy az alábbi példában:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## Példányváltozók módosítása

A metódusok módosíthatják a példányváltozókat.
Ezeket a metódusokat az osztály példányán hívhatod meg.
Amikor egy metódus módosít egy példányváltozót, a változás csak abban az osztálypéldányban lesz látható, amelyen meghívtad.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Osztálymetódusok

Az [osztálymetódusok][class-methods] olyan metódusok, amelyeket egy osztályhoz definiálunk, nem pedig a példányaihoz.
Segítségükkel olyan metódusokat hozhatsz létre, amelyek nem függnek a példány állapotától.
A `def` kulcsszóval definiáljuk őket, utána a `self.<method name>` következik.
A `self` arra a névtérre hivatkozik, ahonnan éppen meghívják.
Ebben az esetben az osztályra, az `Account`-ra utal.
Ugyanaz lenne, mintha `Account.`-ot írtál volna, de a `self.` az ajánlott megoldás.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
