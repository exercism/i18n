# Kiegészítés az utasításokhoz

Ez egy jó feladat arra, hogy kísérletezz a nem szabványos stringliterálokkal és a metaprogramozással.

A nem szabványos stringliterálok rövid bemutatását ebben a [blogbejegyzésben](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html) találod. A metaprogramozás részletes útmutatója a [kézikönyvben](https://docs.julialang.org/en/v1/manual/metaprogramming/) olvasható.

A megoldásodat kibővítheted az alábbiakban leírt funkcionalitás hozzáadásával.

Az A bónuszhoz elég a blogbejegyzésben bemutatott alapvető ismeret. A B bónuszhoz már lényegesen több tudás kell a Julia metaprogramozásából.

## A bónusz
Valósíts meg egy stringliterált, amely `ROT13`-ként működik a stringen:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## B bónusz
Valósítsd meg az `R<i>` stringliterálokat (`i = 0, ..., 26`), amelyek `i` értékkel eltolják a stringet:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
