# Bevezetés

A rekord olyan mezők gyűjteménye (amelyek különböző típusúak is lehetnek), amelyek összetartoznak. Rekord definiálásához a `type` kulcsszót használjuk. A rekord mezőit a `{` és `}` karakterek között definiáljuk, és minden mezőnek van neve _és_ típusa. Rekord létrehozásához add meg a mezők nevét, és rendelj értéket hozzájuk a `{` és `}` karakterek között. Rekord létrehozásakor minden mezőnek értéket kell adni. Egy rekordpéldány mezőértékei pontjelöléssel érhetők el.

Rekord definiálásakor vagy létrehozásakor minden mező vagy külön sorban van, vagy egy sorban pontosvesszőkkel (`;`) elválasztva.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Mivel a rekordok változtathatatlanok, a létrehozásuk után a mezőértékeik soha nem változhatnak. Ha szeretnéd módosítani egy rekord értékeit, a `with` kulcsszóval másolatot készíthetsz egy meglévő rekordról, de egy vagy több mező új értékével.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

A rekordok _strukturális egyenlőséggel_ rendelkeznek, ami azt jelenti, hogy ugyanazon rekord két példánya azonos értékekkel egyenértékű.

A rekordok mezőihez nemcsak pontjelöléssel férhetsz hozzá: a rekordokat kötésekben és mintaillesztésben is _szétbonthatod_:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
