# Karbantartóknak

## Segédszkript Fortran-tesztek létrehozásához: create_fortran_test.py

Egy feladathoz tartozó teszt legegyszerűbb létrehozási módja a `bin/create\_fortran\_test.py` szkript használata.

Ezzel a szkripttel létrehozhatsz egy kezdeti <exercise>\_test.f90 fájlt, amely sablonként szolgálhat a tesztjeidhez.
A generált fájlban általában a „response” függvényt kell lecserélned a megfelelő függvényhívásra.

Azt is vedd figyelembe, hogy a Fortran problémásan kezeli az olyan speciális karaktereket, mint a `\n` és a `\t`, ezért ezek kezelésére különösen figyelj.

### Előfeltételek

- Működő CMake és Fortran-fordító
- Python3.x (Lehet, hogy Python2-vel is működik, de nem fáradtam azzal, hogy visszafelé kompatibilissé tegyem)
- a https://github.com/exercism/problem-specifications.git legújabb verziója
- git

### Munkafolyamat egy új teszt létrehozásához

- húzd le a legújabb változtatásokat az `exercism/problem-specifications` tárolóból, pl. git clone git@github.com:exercism/problem-specifications.git
- Hozz létre egy új ágat az új feladat elkészítéséhez, pl. git checkout -b exercise-bob
- futtasd le ezt a szkriptet ahhoz a példához, amelyet létre akarsz hozni
- másold a `config/CMakeLists.txt` fájlt a feladat könyvtárába (ehhez használhatod a `bin/update-cmake-files` szkriptet)
- valósítsd meg a működő feladatot
- javítsd a potenciálisan problémás teszteket (lásd pl. az exercise/bob „Test 20” és „Test 24” esetét)
- győződj meg róla, hogy a `ctest` parancs hibák nélkül lefut
- másold a megoldásodat a .meta/example.f90 fájlba, és távolítsd el a tényleges implementációt a feladat fájljából, pl. bob.f90
- frissítsd a .docs és .meta könyvtárakat
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - cseréld le a „# Description” fejlécet „# Instructions”-re
  - töltsd ki kézzel a .meta/tests.toml fájlt (amíg nem létezik automatizált megoldás)
  - töltsd ki kézzel a .meta/config.json fájlt (amíg nem létezik automatizált megoldás)
    - Használd a ../problem-specifications/exercises/bob/metadata.yml fájlt
- nyiss egy pull requestet a változtatásaiddal

A bob példához:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### A `CMakeLists.txt` módosítása

Amikor a cmake fájlt módosítod, frissítsd a mesterpéldányt a `config/` könyvtárban, és a `bin/update-cmake-files` szkripttel másold át az összes feladat könyvtárába.

## Megoldás

Amikor elkészült a megoldásod, másold be a „.meta” könyvtárba „example.f90” néven.

Lehet, hogy meg akarod hagyni a függvény vagy szubrutin egy vázlatos implementációját, amely segít a tanulónak, és a feladat nevét viselő fájlt is meghagyod a feladat könyvtárában.
