# Bevezetés

## Stringek

A Common Lispben a stringek karakterekből álló [vektorok][concept-vectors]. Úgy írjuk le őket, hogy a karaktereket dupla idézőjelbe tesszük (_például_ "Hello World!").

A `stringp` predikátum csak akkor ad vissza igazat, ha a megadott érték egy string.

A stringeket a `subseq` függvénnyel lehet részstringekre bontani, amely megkapja a stringet, egy kezdőindexet és tetszőlegesen egy záróindexet.
Az indexelés nullától indul.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

A stringek egyenlőségét a `string=` függvénnyel hasonlíthatod össze.
Ha a karakterek kis- és nagybetűs írásmódja nem számít, akkor a `string-equal`-t használhatod.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

A stringek nagybetűsítését, kisbetűsítését és a szavak kezdőbetűjének nagybetűssé tételét a `string-upcase`, a `string-downcase` és a `string-capitalize` függvénnyel végezheted el.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
