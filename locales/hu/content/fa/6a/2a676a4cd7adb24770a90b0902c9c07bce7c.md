# Telepítés

A PureScript telepítésének legegyszerűbb módja a Node.js és az NPM használata.

Ha a számítógépeden még nincs telepítve a Node.js, letöltheted a [Node.js weboldaláról](https://nodejs.org/). Amint a Node.js fut, írd be ezt a parancsot a terminálba, hogy telepítsd a PureScript fordítót és a Spago build eszközt:

    npm install --global purescript spago

További információkat a [PureScript tárolóban](https://github.com/purescript/purescript/blob/master/INSTALL.md) találsz.
