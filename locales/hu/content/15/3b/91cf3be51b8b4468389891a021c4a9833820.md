# Bevezetés

A Pythonnak három különböző beépített számítípusa van: egész számok ([`int`][int]), lebegőpontos számok ([`float`][float]) és komplex számok ([`complex`][complex]).
A törtek ([`fractions.Fraction`][fractions]) és a decimálisok ([`decimal.Decimal`][decimals]) szintén elérhetők, ha importálod őket a szabványos könyvtárból.

A **tizedesjegy nélküli** egész számok, köztük a hexadecimális ([_`hex()`_][hex]), oktális ([_`oct()`_][oct]) és bináris ([_`bin()`_][bin]) számok is, `ints`-ként vannak azonosítva:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

A tizedespontot tartalmazó számok (törtrésszel vagy anélkül) `floats`-ként vannak azonosítva:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## Aritmetika

A Python teljes mértékben támogatja az aritmetikát e különböző számítípusok között, és amikor a bináris aritmetikai operátorokkal (`+`, `-`, `*`, `/`, `//` és `%`) használod őket, a szűkebb számokat a kevésbé szűk megfelelőikhez igazítja.

### Összeadás és kivonás

Az összeadás és kivonás operátorai úgy viselkednek, mint a hétköznapi matematikában.
Ha az operandusok közül egy vagy több `float`, akkor a többi `int`s-ből is `float`s lesz:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### Szorzás

Az összeadáshoz és kivonáshoz hasonlóan a szorzás is a kevésbé szűk megfelelőikhez igazítja a szűkebb számokat:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### Osztás

Az osztás mindig `float`-ot ad vissza, még akkor is, ha az eredmény egész szám:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### Egészrészes osztás

Ha `int` eredményre van szükséged, az egészrészes osztással csonkolhatod az eredményt.
Az egészrészes osztást a `//` operátorral végzed el:

```python
>>> 6//5
1

>>> 6//2
3
```

### Modulo

A modulo operátor (`%`) a két operandus osztásának maradékát adja vissza:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

Az 5 % 3 egy másik megközelítésben:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## Kerekítés

A Python biztosít egy beépített [`round(number, <decimal_places>)`][round] függvényt, amellyel egy lebegőpontos számot adott számú tizedesjegyre kerekíthetsz.
Ha nem adod meg a tizedesjegyek számát, a szám a legközelebbi egész számra kerekedik, és `int`-et ad vissza:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## Precedencia és zárójelek

A Pythonban zárójelekkel csoportosíthatod a kifejezéseket.
Ez akkor hasznos, ha felül akarod bírálni a műveletek alapértelmezett sorrendjét.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

A Python az operátorok precedenciájában a [PEMDAS][pemdas] szabályt követi.
Ez azt jelenti, hogy a `()`-en belüli számítások élveznek elsőbbséget, ezt követi a `**`, majd a `*`, `/`, `//`, `%`, `+` és `-`:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## Pontosság és ábrázolás

A Python egész számai [tetszőleges pontosságúak][arbitrary-precision], a számjegyek számát csak a gazdarendszer rendelkezésre álló memóriája korlátozza.

A lebegőpontos számok általában C-beli `double` típussal vannak megvalósítva (_15 tizedesjegy pontossággal_), de ábrázolásuk a gazdarendszertől függően változhat.
A komplex számoknak van egy `real` és egy `imaginary` része, mindkettőt lebegőpontos számok ábrázolják.

A lebegőpontos aritmetika programozási nyelvek közötti problémáinak és korlátainak részletesebb tárgyalásához nézd meg a [0.30000000000000004.com][0.30000000000000004.com] oldalt és [A Python útmutatót][floating point math].
