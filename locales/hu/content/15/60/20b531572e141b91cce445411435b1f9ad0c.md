# Bevezetés

A felsorolás során egy gyűjteményen (`Array`, `Hash` stb.) haladunk végig, és valamilyen műveletet végzünk el minden egyes objektumon.

A felsorolás kulcsfontosságú fogalom a Rubyban: olyan műveleteknél használjuk, mint a rendezés (`sort_by`), a csoportosítás (`group_by`), a leképezés (`map`), a redukálás (`reduce`) és még sok más.
A felsorolással leggyakrabban úgy találkozol majd, mint a gyűjteményeken való végighaladás idiomatikus módjával, ciklusok használata helyett.

Egy egyszerű felsorolás a `map` és a `with_index` használatával így néz ki:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
