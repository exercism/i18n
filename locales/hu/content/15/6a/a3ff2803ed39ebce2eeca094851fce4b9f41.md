# Bevezetés

A [`fractions`][fractions] modul segítségével [`rational numbers`][rational] hozhatunk létre, és azokkal dolgozhatunk. Ezek olyan törtek, amelyeknél egy egész számlálót egy egész nevezővel osztunk.
Például a `2/3`-at pontos törtként tárolhatjuk el a közelítő `float` érték, `0.6666...` helyett.

Az `int`, `float` és `complex` számokkal ellentétben a törteknek nincs literál alakjuk.
A tört konstruktora azonban meglehetősen rugalmas.

A legkézenfekvőbb, hogy két egész számot fogadhat el argumentumként.
A közös tényezőket automatikusan eltávolítja, így a tört a „legegyszerűbb alakjára" egyszerűsödik (_a törtet pontosan reprezentáló legkisebb egész számokra_):

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

A tört konstruktora egy string reprezentációt is fel tud dolgozni:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

A törtek `float` paraméterekkel is dolgozhatnak, de ez problémákba ütközhet, mert a tizedes értéket belül binárisan ábrázoljuk, ami csak közelítő lehet.
A reprezentáció e problémájáról bővebben lásd a [0.30000000000000004][0.30000000000000004] weboldalt, valamint a Python dokumentációjában a [Floating Point Arithmetic: Issues and Limitations ][fp-issues] című részt.

Ha megbízhatóbb eredményt szeretnénk, amikor `float` értékeket használunk törtekkel, használhatjuk a `<fraction>.limit_denominator()` metódust.


## Műveletek törtekkel

A szokásos [`arithmetic operators`][operators] `+ - * / **` ugyanúgy működnek törtekkel, mint más numerikus típusokkal.

Egész számok és más `Fraction`-ok is szerepelhetnek a kifejezésben, és az eredmény `Fraction` lesz.
Ha `float` is szerepel a kifejezésben, az eredmény `float` lesz, ami (esetleges) pontosságvesztéssel járhat:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Számos szabványos numerikus Python-függvény is azt az eredményt adja, amire az `int` és `float` típusokkal számíthatsz:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
