# Bevezetés

Ahogy az Alapok fogalomban láttad, egy AWK-program **minta-művelet párokból** áll.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## Mit értünk „minta” alatt?

A „minta” bármilyen AWK-kifejezés.
A művelet végrehajtásáról az dönt, hogy a kifejezés eredménye igaz-e vagy hamis.

## Az üres minta

A minta elhagyható.
Ilyenkor a művelet minden rekordra lefut.

Kiírhatjuk a passwd fájl összes felhasználónevét.

```sh
awk -F: '{print $1}' /etc/passwd
```

## Reguláris kifejezések

Az AWK össze tud hasonlítani stringeket reguláris kifejezésekkel, és logikai eredményt kap.

Egy adott mező illesztéséhez használd a `~` operátort, amellyel reguláris kifejezésre illeszthetsz.
Ez az operátor bal oldali operandusként egy stringet, jobb oldaliként egy reguláris kifejezést vár.
A reguláris kifejezés literálját `/` perjelek közé írjuk.

Ha meg szeretnéd keresni a passwd fájlban azokat a felhasználókat, akik bash-sel jelentkeznek be:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

A `!~` a „regex **nem** illeszkedik” operátor.

Ha egy reguláris kifejezést az aktuális rekordra akarsz illeszteni, ezt így teheted: `$0 ~ /regex/`.
Ez annyira gyakori, hogy van rá rövidítés: elhagyhatod a `$0`-t és a `~`-ot, és egyszerűen csak ezt írhatod: `/regex/`

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
Hasonlítsd össze ezt az AWK egysorosat a megfelelő grep paranccsal

```sh
grep 'regex' data.txt
```

Az AWK egy teljes programozási nyelvet ad a kezedbe anélkül, hogy le kellene mondanod a tömörségről.
~~~~

A GNU AWK reguláris kifejezéseinek sajátosságaival egy későbbi fogalomban foglalkozunk részletesebben.

## Kifejezések

Az AWK-kifejezések (számítási, logikai vagy bármilyen más jellegűek) használhatók mintaként.

Ha ki akarod nyerni az összes olyan felhasználót, akinek az UID-je legalább 1000:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Emlékezz rá, hogy az AWK hamis értékei a nulla szám és az üres string, minden más szám vagy string pedig igaz.
Bármely kifejezés használható mintaként, amelynek az értéke szám vagy string.

## Függvények

Bármely [beépített][builtins] vagy [felhasználó által definiált][user-defined] függvény használható kifejezésben, és így mintában is.
Íme néhány példa:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## Állandó minták

Gyakori AWK-idióma a következő:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

Az `1` olyan minta, amely igaz, és nincs hozzá tartozó művelet.
Ez azt jelenti: „írd ki az aktuális rekordot”.
