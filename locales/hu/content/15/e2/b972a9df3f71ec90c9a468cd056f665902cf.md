# Tömbmetódusok

A tömbök gyakori adatszerkezetek, amelyekkel a programozás során gyakran dolgozunk.
Ezért létezik egy sor metódus, amelyekkel a tömböket kezelhetjük.
Ide tartozik a rendezés, a megfordítás, a beszúrás és még sok más.

Ezek közül néhány metódus destruktív, ami azt jelenti, hogy módosítja az eredeti tömböt.
Mások nem destruktívak, azaz új tömböt adnak vissza, és nem módosítják az eredetit.

Íme néhány a leggyakoribb metódusok közül, amelyeket a tömbök kezelésekor használhatsz:

## insert

Amikor egy elemet szeretnél beszúrni egy tömbbe, használhatod az [`insert`][insert] metódust, amely egy indexet és egy elemet vár argumentumként.
Az elem a megadott indexre kerül, a tömb többi eleme pedig jobbra tolódik.
Ha az index túlmutat a tömb határain, akkor `IndexError` hibát kapunk.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Amikor egy adott elemet szeretnél törölni egy tömbből, használhatod a [`delete`][delete] metódust, amely egy elemet vár argumentumként.
A metódus visszaadja az eltávolított elemet.
Ha az elem nem szerepel a tömbben, akkor `nil`-t ad vissza.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Amikor egy tömb első vagy utolsó elemére vagy kíváncsi, használhatod a [`first`][first] és a [`last`][last] metódust.
Ezek a metódusok egy opcionális argumentumot fogadnak, amely megadja, hány elemet adjanak vissza.
Ez olvashatóbbá teheti a kódot, mint a `0` vagy `-1` index használata vagy egy tartomány megadása.
Ha a tömb üres, akkor `Enumerable::EmptyError` hibát kapunk.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Amikor meg szeretnéd fordítani egy tömböt, használhatod a [`reverse`][reverse] metódust, amely egy új tömböt ad vissza fordított sorrendben.
Fontos megjegyezni, hogy a `reverse` új tömböt ad vissza, és nem módosítja az eredeti tömböt.
Ha az eredeti tömböt szeretnéd módosítani, tegyél egy `!` jelet a metódus nevének végére.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

A következő metódusok akkor hasznosak, ha olyan műveleteket végzel, mint egy tömb egydimenzióssá tétele, `nil` elemek eltávolítása, az ismétlődések kiszűrése vagy tömbök tömbjének transzponálása.
A `reverse`-hez hasonlóan ezek a metódusok is új tömböt adnak vissza, és nem módosítják az eredetit.

| Metódus | Leírás | példa |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | Új tömböt ad vissza, amely ennek a tömbnek az egydimenziós, rekurzív kilapítása. Vagyis minden tömbelem esetén annak elemeit kiemeli az új tömbbe. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | A tömb egy másolatát adja vissza, amelyből minden nil elem el van távolítva. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | Feltételezi, hogy a tömb tömbökből áll, és [transzponálja][transpose] a sorokat és az oszlopokat. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | Új tömböt ad vissza úgy, hogy eltávolítja az ismétlődő értékeket. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

A hozzáfűző metódus (`<<`) akkor hasznos, ha objektumokat szeretnél hozzáadni egy tömbhöz.
Ha viszont két tömböt fűzöl össze, használhatod a [`+`][concat] operátort, amely egy új tömböt ad vissza, benne mindkét tömb elemeivel.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Ha egy tömböt fűzöl hozzá egy másik tömbhöz, az a tömb egyetlen elemként kerül bele.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Ha ellenőrizni szeretnéd, hogy egy tömb üres-e, használhatod az [`empty?`][empty?] metódust, amely `true` értéket ad vissza, ha a tömb üres, egyébként pedig `false`-t.
Ez olvashatóbb, mint a tömb hosszát a `0` értékkel összehasonlítani.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Ha egy elem indexére vagy kíváncsi egy tömbben, használhatod az [`index`][index] metódust, amely egy elemet vár argumentumként.
Ha az elem nem szerepel a tömbben, akkor `nil`-t ad vissza.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Ha tudni szeretnéd, hány elem van egy tömbben, használhatod a [`size`][size] metódust.

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Ha meg szeretnéd számolni, hányszor szerepel egy elem egy tömbben, használhatod a [`count`][count] metódust.

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Ha rendezni szeretnél egy tömböt, használhatod a [`sort`][sort] metódust, amely egy új tömböt ad vissza rendezett elemekkel.
A `reverse`-hez hasonlóan ez a metódus is új tömböt ad vissza, és nem módosítja az eredetit.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
