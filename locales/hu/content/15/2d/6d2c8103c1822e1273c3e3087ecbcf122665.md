# Representer normalizálások

A [JavaScript representer][github-javascript-representer] a következő normalizálásokat alkalmazza:

## Kommentek eltávolítása

Minden komment eltávolításra kerül.
A következő példák egyenértékűek:

### Példa kommentekkel

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### Példa kommentek nélkül

```javascript
function hello() {
  return 'hi there';
}
```

## Whitespace normalizálása

Amikor a kód reprezentálva van, a _sorrendje_ számít, a fizikai elhelyezkedése viszont nem.
Ez azt jelenti, hogy a whitespace normalizálva van.
A következő példák egyenértékűek:

### Példa két szóközös behúzással

```javascript
function hello() {
  return 'hello world';
}
```

### Példa négy szóközös behúzással

```javascript
function hello() {
  return 'hello world';
}
```

### Példa érdekes behúzással

```javascript
function hello() {
  return 'hello world';
}
```

## Azonosítók normalizálása

Az azonosítók egy helyőrző értékre normalizálódnak.

### Előtte

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### Utána

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
