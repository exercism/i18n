# Tesztek

A tesztek futtatásához futtasd a következő parancsot:

```bash
make
```

## Kihagyott tesztek

Egy feladat megoldásához az kell, hogy minden tesztje sikeres legyen.
Alapértelmezés szerint a tesztek futtatásakor csak egy teszt (az első) fut le.
Ez szándékos, így arra összpontosíthatsz, hogy épp azt az egy tesztet sikeressé tedd.
Amint ez sikerül, a következő tesztet a `TEST_IGNORE()` sor törlésével engedélyezheted.
Ha minden tesztet engedélyeztél, és a megoldásod mindet sikeresen teljesíti, akkor megoldottad a feladatot!

## Hibakeresés

A hibakeresés megkönnyítésére több makrót is definiáltunk a `debug.mac` fájlban.
Ezeket egy vagy több, megfelelő méretű argumentummal hívhatod meg.
Például:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

Ahhoz, hogy bármelyik makrót használhasd, a `debug.mac` fájlt be kell illesztened a megoldásfájl elején:

```x86asm
%include "debug.mac"
```
