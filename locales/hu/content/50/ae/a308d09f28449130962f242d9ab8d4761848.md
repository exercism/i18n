# Részletesen

A lokális változók nem helyettesítik a veremmel dolgozó kódot, hanem mellette élnek. Akkor nyúlj hozzájuk, ha:

- Ugyanarra a bemenetre többször is hivatkozol.
- A műveletek természetes sorrendje nem egyezik a verem sorrendjével.
- Egy magasabb rendű szó belsejében vagy, amely egyszerre több értéket ad át a lambdának (`assoc-map`: `( key value -- newkey newvalue )`).

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

A `[let code :> name code :> name ... body ]` lokális kötéseket hoz létre egy quotationön belül vagy a listenerben, ahol a `:>`-nek egyébként nem lenne lexikális scope-ja, amibe köthetne:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

A `:>` módosító utótaggal újra tudsz kötni egy lokális változót, ami hasznos az imperatív jellegű ciklusokban:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
