# A témáról

A Java statikusan típusos nyelv, ami azt jelenti, hogy mindennek már fordítási időben van típusa.
Ha egy névhez értéket rendelünk, azt nevezzük a változó definiálásának.

```java
int explicitVar = 10; // Explicitly typed
```

A változó értékét az [`=` operátorral][assignment] rendelheted hozzá, illetve frissítheted.
A változó típusa a definiálás után soha nem változhat meg.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

A Java objektumorientált nyelv, és minden függvényt egy _osztályon_ belül kell definiálni, az osztályokat pedig a [`class` kulcsszóval][classes] hozod létre.
Az osztályon belüli függvényt _metódusnak_ nevezzük.
Minden [metódusnak][methods] lehet nulla vagy több paramétere.
Minden paraméter típusát explicit módon meg kell adni, a paramétereknél nincs típuskövetkeztetés.
Hasonlóképpen a visszatérési típust is explicit módon kell megadni.
A függvények a [`return` kulcsszóval][return] adják vissza az értékeket.
Ahhoz, hogy egy metódust más osztályok is meghívhassanak, hozzá kell adni a `public` hozzáférés-módosítót.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Egy metódus meghívásához meg kell adnod az osztályát és a metódus nevét, majd minden paraméterhez át kell adnod egy argumentumot.

```java
int sum = new Calculator().add(1, 2);
```

Ha egy metódus nem használja az osztály _állapotát_ (ahogy ebben a feladatban sem), akkor a `static` módosítóval _statikussá_ teheted.
Hasonlóképpen, ha egy osztályban csak statikus metódusok vannak, magát az osztályt is statikussá teheted a `static` módosítóval.

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

A scope Java-ban a `{` és `}` karakterek között értelmezett.

A Java kétféle [megjegyzést][comments] támogat.
Az egysoros megjegyzést `//` előzi meg, a többsoros megjegyzést pedig `/*` és `*/` közé írod.

Az egész értékeket egy vagy több (egymást követő) számjegy alkotja, és támogatják a [szokásos matematikai operátorokat][operators].
