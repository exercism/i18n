# Utasítások

Ebben a feladatban a legjobb barátaiddal egy „Wizard and Warriors” nevű szerepjátékot játszotok. Te vagy a játékmester, akinek az a feladata, hogy életre keltse a játék világát a játékosok számára. Ennek egyik kulcsfontosságú része, hogy leírd a játékot a játékosoknak: milyen egy karakter állapota, hogy néz ki a város, ahová épp tartanak, és így tovább.

Öt részfeladat vár rád, amelyekben a játék egy-egy részét kell leírnod a játékosoknak.

## 1. Írj le egy karaktert

Minden karakternek van kasztja és szintje, valamint megadott számú életerőpontja, és így írható le: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. Valósítsd meg a (statikus) `GameMaster.Describe` metódust, amely egyetlen paraméterként egy `Character` példányt kap, és visszaadja a leírását.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Írj le egy úti célt

Minden úti célnak van neve és lakosságszáma, és így írható le: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. Valósítsd meg a (statikus) `GameMaster.Describe` metódust, amely egyetlen paraméterként egy `Destination` példányt kap, és visszaadja a leírását.

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Írd le az utazási módot

A karakterek kétféleképpen utazhatnak el egy úti célhoz:

- Gyalog, leírása: `"You're traveling to your destination by walking."`
- Lóháton, leírása: `"You're traveling to your destination on horseback."`

Valósítsd meg a (statikus) `GameMaster.Describe` metódust, amely egyetlen paraméterként egy `TravelMethod` értéket kap, és visszaadja a leírását.

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. Írd le, ahogy egy karakter egy úti célhoz utazik

Amikor egy karakter egy úti célhoz utazik, az az egyes leírások kombinációjaként írható le: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. Valósítsd meg a (statikus) `GameMaster.Describe` metódust, amely paraméterként egy `Character`, egy `Destination` és egy `TravelMethod` értéket kap, és visszaadja a leírását.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Írd le, ahogy egy karakter egy úti célhoz utazik az utazási mód megadása nélkül

A legtöbb esetben a karakterek gyalog utaznak egy úti célhoz. A kényelem kedvéért a játékosok elhagyhatják az utazási mód megadását; ilyenkor az utazási mód automatikusan a gyaloglás lesz. Valósítsd meg a (statikus) `GameMaster.Describe` metódust, amely paraméterként egy `Character` és egy `Destination` értéket kap, és visszaadja a leírását.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
