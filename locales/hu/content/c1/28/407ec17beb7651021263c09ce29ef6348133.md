# Bevezetés

A diszkriminált unió típus rögzített számú nevesített esetet képvisel. A diszkriminált unió minden értéke pontosan egy nevesített esetnek felel meg.

A diszkriminált uniót a `type` kulcsszóval definiáljuk, az eseteket függőleges vonal (`|`) karakterek választják el egymástól:

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

A diszkriminált unió minden esetéhez opcionálisan tartozhat adat, és a különböző esetekhez különböző típusú adatok tartozhatnak. Ha egyik esethez sem tartozik adat, akkor a diszkriminált unió ahhoz hasonlít, amit más nyelvek általában _felsorolásnak_ (vagy _enumnak_) neveznek.

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Egy adott esethez tartozó értéket úgy hozhatsz létre, hogy a nevére hivatkozol (például `Success`). Mivel az esetnevek valójában konstruktorfüggvények, a hozzájuk tartozó adatot szokásos függvényargumentumként adhatod át. Ha egy másik diszkriminált unió is definiált ilyen nevű esetet, akkor a teljes nevét kell használnod (például `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

A diszkriminált uniók _strukturális egyenlőséggel_ rendelkeznek, ami azt jelenti, hogy két érték, amely ugyanahhoz az esethez tartozik és ugyanazzal az (opcionális) adattal rendelkezik, egyenlő.

Bár a diszkriminált uniókkal `if/elif/else` kifejezésekkel is dolgozhatsz, a velük való munka ajánlott módja az _azonosító mintát_ használó mintaegyeztetés:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
