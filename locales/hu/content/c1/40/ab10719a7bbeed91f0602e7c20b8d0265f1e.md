# Bevezetés

## Mintaillesztés

Egy `if/elif/else` kifejezéssel feltételesen hajthatsz végre logikát. Az F#-nak azonban van egy másik, hatékonyabb módja is a feltételes végrehajtásra: a mintaillesztés. A mintaillesztés során egy értéket egy vagy több _mintával_ vethetsz össze. Ilyen minta például a _konstans minta_, amely egy értéket egy konstanshoz hasonlít (például `1` vagy `"hello"`).

Az F#-ban a mintaillesztés a `match` kulcsszóval történik:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Bár ez más nyelvek `switch` utasításaira hasonlíthat, a mintaillesztés akkor mutatja meg igazán az erejét, amikor más mintákat is használsz. Ilyen például a _változóminta_, amellyel egy értéket rögzíthetsz:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

Bizonyos esetekben további feltételt szeretnél adni egy mintához. Ezt _őrszemnek_ (feltételnek) nevezik, és a `when` kulcsszóval adhatod hozzá:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

A fenti példában nem minden lehetséges bemenethez tartozik illeszkedő minta. A fordító ezt észleli, és figyelmeztetést ír ki. Ezt _kimerítő ellenőrzésnek_ nevezik. A figyelmeztetés megoldásához minden esetet kezelned kell. Erre a _wildcard minta_ használható, amely bármilyen értékre illeszkedik:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

A mintaillesztés egy értéket fentről lefelé haladva vet össze minden mintával, amíg nem talál egy illeszkedő mintát, és végre nem hajtja a hozzá tartozó logikát. A minták sorrendje számít!
