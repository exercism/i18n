# Utasítások

Ebben a feladatban naplósorokat fogsz feldolgozni.

Minden naplósor egy string, amelynek formátuma a következő: `"[<LVL>]: <MESSAGE>"`.

Ezek a különböző naplószintek:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Három részfeladatod van.

## 1. Naplószint feldolgozása

Definiálj egy `LogLevel` enumot, amelynek hat eleme van, és ezek megfelelnek a fenti naplószinteknek.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

Ezután implementáld a `LogLine.getLogLevel()` metódust, amely egy naplósor feldolgozott naplószintjét adja vissza:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. Ismeretlen naplószint kezelése

Sajnos előfordul, hogy egyes naplósorok naplószintje ismeretlen.
Hogy ezeket a naplósorokat szépen kezeld, adj hozzá egy `UNKNOWN` elemet a `LogLevel` enumhoz, amelyet ismeretlen naplószint feldolgozásakor kell visszaadni:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. Naplósor átalakítása rövid formátumra

Egy naplósor naplószintje meglehetősen terjengős.
Hogy csökkentsük a naplósorok tárolásához szükséges lemezterületet, kifejlesztettek egy rövid formátumot: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

A kódolt naplószint nem más, mint egy naplószint egyszerű hozzárendelése egy számhoz:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

Implementáld a `LogLine.getOutputForShortLog()` metódust, amely ki tudja írni a rövidített naplósor-formátumot:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
