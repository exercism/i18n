# Kiegészítés az utasításokhoz

## A bemenet formátuma

Minden bemeneti listát egy nullával lezárt string képvisel, amelyben minden bemenet végén egy újsor karakter áll.

Erre egy példa: `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## Regiszterek

| Regiszter | Használat      | Típus   | Leírás                                                             |
| --------- | -------------- | ------- | ------------------------------------------------------------------ |
| `$a0`     | bemenet        | cím     | nullával lezárt bemeneti string, minden bemenet után újsorral      |
| `$a1`     | bemenet/kimenet | cím     | nullával lezárt kimeneti string                                    |
| `$t0-9`   | ideiglenes     | bármilyen | ideiglenes tárolásra                                             |
