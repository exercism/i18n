# Kiegészítés az utasításokhoz

## Rendezési csomag

Ez a feladat megköveteli, hogy rendezz egy tömböt, erre viszont nincs beépített lehetőség a szabványos könyvtárban.
Írhatnál saját rendezőkönyvtárat is, de jobb megoldás a [sorts csomag](https://github.com/diku-dk/sorts) használata.

Ezt a csomagot úgy használhatod a megoldásodban, hogy a megoldás könyvtárában lefuttatod a következő parancsot:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

Ezután importáld a [kívánt rendezőalgoritmusokat](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) így:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
