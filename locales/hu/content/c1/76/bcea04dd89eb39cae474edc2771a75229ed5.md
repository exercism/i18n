# Kiegészítés az utasításokhoz

## Megvalósítás

Ebben a feladatban egy olyan eljárást fogsz megvalósítani, amely lefoglalja a visszaadott stringet. A string felszabadítása az eljárás hívójának a felelőssége.

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
