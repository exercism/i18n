# Névjegy

A [tuple-ök][tuples] több értéket egyetlen összetett értékbe csoportosítanak.
A tömbökkel ellentétben a tuple-ön belüli értékeknek nem kell azonos típusúnak lenniük, és a tuple mérete a létrehozás után rögzített.

Egy tuple létrehozásához az értékeket vesszővel elválasztva zárójelbe teszed:

```swift
let order = ("biscuits", 2.99, 3)
```

A típusmegjelöléseket explicit módon is megadhatod:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Ahhoz, hogy egy névtelen tuple egyes elemeit kinyerd, használd a nullától induló indexelési szintaxist (`.0`, `.1` és így tovább):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Nevesített tuple-ök

A tuple egyes elemeit már a tuple definiálásakor elnevezheted:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Az elemek elnevezése olvashatóbbá teszi a kódot, és lehetővé teszi, hogy az elemeket a címkéik segítségével, pontszintaxissal érd el:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

Az elemneveket a típusmegjelölésben is szerepeltetheted:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Tuple-ök módosítása

Ha egy tuple-t változóként (`var`) hozol létre, akkor módosíthatod az elemeit:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Több visszatérési érték

Bár a Swift függvényei csak egyetlen értéket adhatnak vissza, ha tuple-t adsz vissza, több értéket is csomagolhatsz, és [több értéket adhatsz vissza][multiple-return-values] egy függvényből:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Tuple-ök felbontása

A tuple értékeit különálló konstansokba vagy változókba bonthatod fel:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

A tuple-ök felbontása közvetlenül `for-in` ciklusokban is működik:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
