# Részletesen

## Függvénytípusok

Korábban már láttuk, hogyan definiáljuk a függvényszignatúrákat: a függvény nevét egy vesszővel elválasztott paramétercímke-lista követi a típusaikkal együtt, majd a `->` és a függvény által visszaadott értékek típusa.

Ha eltávolítanánk a szignatúrából az összes nevet és címkét, megmaradna a [függvény típusa][function-types].

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Figyeld meg, hogy az első két függvény típusa ugyanaz, `(String, Int) -> String`, pedig a két függvény nagyon különböző módon működik. Mindkettő bemenetként kap egy `String` és egy `Int` értéket, és egy `String` értéket ad vissza. És ahogy a harmadik függvény típusából látszik, bár úgy tűnik, hogy nem ad vissza semmit, valójában `()`-t ad vissza, ami a `Void` típus egyetlen értéke. Vedd észre, hogy a `()` és a `Void` típusnévként felcserélhető, így a `printString` típusát `String) -> Void` alakban is felírhatjuk.

Ezek a típusok ugyanúgy használhatók, mint bármely más típus a Swiftben, például szerepelhetnek változók vagy konstansok deklarációjában. És mivel a függvények értékek a Swiftben, a már létező függvényeket hozzárendelhetjük ezekhez a konstansokhoz/változókhoz:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

Ahogy más változóknál/konstansoknál, a hozzárendelt értéknek is a megfelelő típusúnak kell lennie:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Függvénytípusok paramétertípusként

Mivel a függvénytípusok mindenhol használhatók, ahol más típusok is, ebből következik, hogy [paramétertípusként is használhatók][functions-as-parameters]: átadhatók más függvényeknek, és azokon belül meg is hívhatók.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## Függvénytípusok visszatérési típusként

Hasonlóképpen a függvényeknél [a függvénytípusok visszatérési típusként is használhatók][functions-as-returns]. Más szóval írhatunk olyan függvényeket, amelyek más függvényeket hoznak létre és adnak vissza. Amikor ilyen függvényt készítünk, a visszaadott függvény használhatja a szülőfüggvénynek átadott többi paramétert vagy a benne létrehozott helyi változókat.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## Értékek elkapása

Ahogy a fenti `makeAdder(base:)` függvény is mutatja, az egymásba ágyazott függvények hozzáférnek a körülvevő függvények paramétereihez és változóihoz. Ráadásul ezekhez az értékekhez a befoglaló függvény lefutása után is hozzá tudnak férni. Ezt a hozzáférést, annak megszerzését és megtartását [_elkapásnak_][capturing-values] nevezzük.

## Magasabb rendű függvények

Azokat a függvényeket, amelyek paraméterként függvényeket fogadnak és/vagy függvényt adnak vissza, magasabb rendű függvényeknek nevezzük. A Swift számos magasabb rendű függvényt kínál a különféle könyvtáraiban. Ilyen például a `sorted(by:)` metódus, amely a Swift gyűjteményein, például az `Array`-en érhető el: egy `T` típusú elemekből álló tömb esetén egy `(T, T) -> Bool` típusú függvényt vár, amely eldönti, hogy két érték közül melyik kerüljön előbb a rendezett tömbben. `true`-t ad vissza, ha a bal oldali értéknek kell előbb szerepelnie, és `false`-t, ha a jobb oldalinak.

Egy másik példa a gyűjtemények `contains(where:)` metódusa, amely egy `T` típusú elemekből álló gyűjtemény esetén egy `(T) -> Bool` típusú függvényt vár, amely `true`-t ad vissza, ha az elem megfelel valamilyen tulajdonságnak, egyébként pedig `false`-t. A `contains(where:)` ezután `true`-t ad vissza, ha a gyűjtemény valamelyik eleme megfelel ennek a tulajdonságnak.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
