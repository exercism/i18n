# Névjegy

A [magasabb rendű függvény](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) olyan függvény, amelyik a következők egyikét teszi:

- Egy függvényt vár argumentumként
- Függvényt ad vissza

Egy függvény argumentumként nem más, mint egy közönséges argumentum, azzal a különbséggel, hogy meg is tudod hívni.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
