# Bevezetés

A kapcsolódás azt írja le, hogy a kódban honnan érhető el egy azonosító.
Azoknak az értékeknek, amelyek blokk, függvény vagy függvényprototípus scope-pal rendelkeznek, nincs kapcsolódásuk.
Ez azt jelenti, hogy a scope-jukon kívülről nem érhetők el.
A scope-ról bővebben lásd a [scope fogalmat](../scope/introduction.md#Introduction).

## Külső kapcsolódás

A fájl scope-pal bíró azonosítók alapértelmezés szerint külső kapcsolódásúak.
Egy külső kapcsolódású azonosító a program bármelyik fájljából elérhető.

## Belső kapcsolódás

A fájl scope-pal bíró azonosító a `static` kulcsszó használatával belső kapcsolódásúvá tehető.
A belső kapcsolódású azonosító csak a saját fájlján belül használható.

Például

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

A statikus kapcsolódást nem szabad összekeverni a statikus tárolási időtartammal.
A statikus tárolási időtartamról bővebben lásd a [tárolási időtartam fogalmat](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).
