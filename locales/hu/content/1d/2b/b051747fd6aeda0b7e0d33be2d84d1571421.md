# Kiegészítés az utasításokhoz

## Kimeneti formátum

A dalszöveget nullával lezárt stringként add ki.

## Regiszterek

| Regiszter | Használat     | Típus   | Leírás                        |
| --------- | ------------- | ------- | ----------------------------- |
| `$a0`     | bemenet       | egész szám | kezdő palackok             |
| `$a1`     | bemenet       | egész szám | leveendő palackok          |
| `$a2`     | bemenet/kimenet | cím   | nullával lezárt kimeneti string |
| `$t0-9`   | ideiglenes    | bármilyen | ideiglenes tároláshoz       |
