# Részletesen

A Java stringekről a legfontosabb, amit meg kell jegyezned, hogy módosíthatatlan objektumok, amelyek szöveget Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként ábrázolnak.
A `String` példányát idézőjelek közé írt szöveggel hozod létre:

```java
String fruit = "Apple";
```

A string módosításához a [`String`][string-class] osztály metódusait használhatod.
Mivel egy string értéke a létrehozása után soha nem változik, a stringkezelő metódusok mindig új stringet adnak vissza.

A stringet idézőjel (`"`) karakterek határolják.
Néhány speciális karaktert escape-elni kell a visszaperjel (`\`) karakterrel.
A Java-ban escape-elendő karakterek:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Végül, egy stringet többféleképpen is összefűzhetsz.
A legegyszerűbb módja a `+` operátor:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Ha a formázás bonyolultabb az egyszerű összefűzésnél, akkor a `String.format` metódust érdemes használni.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

További lehetőségek:

- használd a [`StringBuilder` osztályt][string-builder]
- használd a [`String.concat` metódust][string-concat]
