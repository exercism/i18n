# Névjegy

## Feltételes utasítások

A feltételes utasítások döntéshozó utasítások, amelyek vagy mellékhatásokat hajtanak végre, vagy egy program végrehajtásának menetét szabályozzák.
A feltételes utasítások közé tartoznak az `if`, `if/else`, `switch` és `ternary` utasítások.

A feltételes utasításokkal kérdéseket teszünk fel egy értékről vagy értékek viszonyáról.
A kérdés Boolean választ ad, de maga az `if` elágazás bármilyen értéket visszaadhat, vagy egyszerűen csak végrehajthat egy mellékhatást.

## If-elágazások

A legegyszerűbb `if` elágazás kiértékel egy kifejezést, és végrehajt egy sort.
A vizsgált kifejezés mindig zárójelben van.

Végrehajthat egy mellékhatást

```c
if (count > 10)
    printf("count is greater than 10");
```

vagy megváltoztathatja a végrehajtás menetét


```c
if (count > 10)
    return sum;
```

Ha egy `if` elágazás egynél több sort hajt végre, akkor a sorokat kapcsos zárójelek közé kell tennie

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Néhány fejlesztőcsapat előírhatja, hogy az `if` elágazások mindig használjanak kapcsos zárójelet, még egyetlen sor esetén is.


## If Else

Egy `if` elágazás összekapcsolható egy `else` ággal

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## If Else If


Az `else` összekapcsolható egy másik `if`-fel, hogy létrehozza az úgynevezett `if-else-if ladder` szerkezetet.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Switch


Néha egy `if-else-if ladder` jobban reprezentálható egy `switch`-csel.
Az `if`-hez hasonlóan a vizsgált kifejezés mindig zárójelben van.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

A `default` eset akkor fut le, ha a vizsgált érték nem egyezik egyik korábbi esettel sem.

Ha egy `switch` eset nem tér vissza, akkor általában egy `break` utasítást szúrnak be az egyes esetek végére, különben a logika „átesik” a következő esetre.
Néha az átesést szándékosan használják

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Amikor az átesés véletlenül történik, az egy bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Egy `switch` előnyös lehet, ha konkrét értékeket vizsgálunk értéktartomány helyett.
Gyorsabb lehet, mint egy `if-else-if ladder`, mert a fordító képes lehet optimalizálni a `switch` utasítást olyan módokon, ahogyan egy létrával nem tud.
Egy `switch` néha olvashatóbbnak tűnhet, mint egy létra.

## Ternáris (más néven feltételes) operátor

A ternáris operátor egy háromrészes feltételes utasítás, amelyet gyakran érték beállítására használnak.
A vizsgálandó kifejezés a kérdőjel előtt van, és nem kell zárójelben lennie.
Az igaz esetén visszaadott érték a kettőspont előtt, a hamis esetén visszaadott érték pedig a kettőspont után áll.
Vagy értékliterál vagy változó adható vissza.

```c
int i = j > 5 ? 5: j;
```

A ternáris operátorok egymásba ágyazhatók a szintaktikai zsúfoltság csökkentésére.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## Feltételes összehasonlítások lebegőpontos értékeknél

A lebegőpontos számok megvalósításából adódóan egy egyszerű matematikai művelet kerekítési hibát eredményezhet, ami miatt az egyenlőségvizsgálat nem a várt eredményt adja.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

Egy toleranciaérték, amelyet `epsilon`-nak neveznek, használható annak meghatározására, hogy egy érték milyen tartományon belül eshet ahhoz, hogy egy másik értékkel összehasonlítva még egyenlőnek tekintsük.
Egyes platformok beépített konstansokkal rendelkeznek a float és double epsilon értékekhez.
A részletekért nézd meg a fordítód dokumentációját.
Az epsilon kiszámítása bonyolult lehet, és platformonként változhat: akár az egyes gépek között is.
Íme egy példaprogram egy egyszerű összehasonlítással.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

Légy óvatos, amikor `float`-okat vagy `double`-okat hasonlítasz össze egyenlőségre!
