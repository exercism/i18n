# Tippek

## Általános

- Olvass a függvénykompozícióról a [kézikönyvben][function-composition-manual].
- Böngészd át a [_Stringekhez_ elérhető metódusokat][string-methods].

## 1. Tisztítsd meg a nevet

- Van egy [beépített metódus][string-replace], amivel egy részstring minden előfordulását lecserélheted egy stringben.
- Van egy [beépített metódus][string-strip], amivel eltávolíthatod a string elejéről és végéről a szóközöket.

## 2. Szerezd meg a név első betűjét

- Ha egy adott karaktert szeretnél kivenni egy stringből, használhatsz [indexelést][string-indexing].
- Ennek a legtisztább módja a kompozíciós operátor (`∘`) használata.

## 3. Formázd a kezdőbetűt

- Van egy [beépített metódus][string-uppercase], amivel egy string összes karakterét nagybetűssé alakíthatod.

## 4. Tedd a kezdőbetűket a szívbe

- Unicode-karaktereket így használhatsz a stringekben: `'\u<id>'`, ahol a szív emodzsi esetében az id a `2764`.
- Ezt megteheted [összefűzéssel][string-concatenation] vagy [interpolációval][string-interpolation].
