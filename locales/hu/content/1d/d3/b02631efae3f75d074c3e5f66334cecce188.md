# Bevezetés

A phantom típusok egy egyedi típusnak olyan típusparaméterei, amelyeket a típus értékkonstruktorai közül egyik sem használ.

Ez kicsit elvont, úgyhogy nézzünk egy példát:

```gleam
pub type Length(unit) {
  Length(amount: Float)
}
```

Ebben a példában a `unit` típusparamétert a `Length` értékkonstruktor nem használja, így a `unit` phantom típus.

Ez a fel nem használt típusparaméter haszontalannak tűnhet, de arra használható, hogy további megkötéseket tegyünk arra, hogyan használhatók a `Length` értékek.

Például írhatunk egy `double` függvényt, amely megszorozza a hosszúságot. Bármilyen mértékegységű hosszúsággal működik, ezért a típusparamétere generikus típusváltozó.

```gleam
// This function accepts all Length values
pub fn double(length: Length(unit)) -> Length(unit) {
  Length(length.amount *. 2.0)
}
```

Írhatunk egy `add_inch` függvényt is, amely csak akkor működik, ha a hosszúság hüvelykben van.

```gleam
// A unit type for inches. It is never constructed so we don't
// define any constructors for it.
pub type Inches

pub fn add_inch(length: Length(Inches)) -> Length(Inches) {
  Length(length.amount +. 1.0)
}
```

Az `add_inch` függvény nem fogad el más mértékegység-paraméterrel rendelkező hosszúságot; a phantom típus gondoskodik róla, hogy csak a megfelelő mértékegység legyen használható.

Írhatunk olyan függvényt is, amely biztosítja, hogy két hosszúságérték ugyanabban a mértékegységben legyen, ehhez ugyanazt a típusváltozót használjuk mindkettőhöz.

```gleam
pub fn add(a: Length(unit), b: Length(unit)) -> Length(unit) {
  Length(a.amount +. b.amount)
}
```
```gleam
let two_meters: Length(Meters) = Length(2.0)
let two_inches: Length(Inches) = Length(2.0)

add(two_meters, two_meters)
// -> Length(4.0): Length(Meters)

add(two_meters, two_inches)
// Type error! The unit type parameters do not match.
```

A phantom típusok jól működnek az opaque típusokkal. Ha más modulok nem tudnak `Length` értéket létrehozni, akkor biztosíthatjuk, hogy ne is lehessen érvénytelen mértékegység-típussal létrehozni őket, és hogy csak a fent definiált függvényeket lehessen velük használni.
