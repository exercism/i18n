# Az Emacs telepítése

Mivel az Emacs Lisp (elisp) az Emacs bővítőnyelve, először telepítened kell a [GNU Emacs](http://www.gnu.org/software/emacs/)ot.

Érdemes a legfrissebb Emacset beszerezni, de a feladatok célverziójának a 28.1-es vagy annál újabb verziót tekintsd.
Ha már telepítve van az Emacs, az `M-x emacs-version RET` paranccsal ellenőrizheted a verzióját.

## OS X-en
A legegyszerűbb, ha felkeresed az [Emacs For Mac OS X](http://emacsformacosx.com/) oldalt, és letöltöd a dmg-t, amivel a GNU Emacs csomagolt OS X-alkalmazásként települ.

Léteznek alternatívák is, például az Aquamacs (nem ajánlott), vagy ha úgy szeretnéd, a [Homebrew](https://formulae.brew.sh/formula/emacs)n keresztüli telepítés.

## Linuxon
Egyes disztribúciókon az Emacs már eleve telepítve van, mivel a GNU része.

### Ubuntu
A legfrissebb Emacs telepítésére jelenleg a [snap](https://snapcraft.io/emacs) használata ajánlott:

```
sudo snap install emacs --classic
```

Ha nem szeretnéd a snapet használni, az Emacset apt segítségével is telepítheted, de az Ubuntu tárolóiban elérhető verzió gyakran elavult.
Ha az apttal egy újabb Emacs-verziót szeretnél telepíteni, [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs)t kell használnod, vagy [forrásból kell fordítanod](https://www.emacswiki.org/emacs/BuildingEmacs).

Ha nem ragaszkodsz a legfrissebb verzióhoz, akkor egyszerűen ennyi elég:

```
sudo apt-get install emacs
```

### Arch
Az Arch általában a legfrissebb Emacs-verzióval érkezik, ezért futtasd ezt:

```
sudo pacman -S emacs
```

és készen is vagy.

### Egyéb disztribúciók
Nézd meg a disztribúciódnál, hogy melyik verzió a jelenlegi, majd használd a csomagkezelődet, vagy fordíts forrásból, ahogy épp megfelelő.

### Windows
Ha Windowson szeretnéd telepíteni az Emacset, keresd fel a legközelebbi
[FTP archív tükröt](https://ftpmirror.gnu.org/emacs/windows), töltsd le a telepítőt (=emacs-XX.X-installer.exe=), és indítsd el.
Ha az Emacset telepítés nélkül szeretnéd használni, letöltheted az =emacs-XX.x.zip= mintázatú fájlt, csomagold ki, és indítsd el a `bin\runemacs.exe` fájlt.

Ha [MSYS2](https://www.msys2.org/)t használsz, az Emacs 64 bites buildjét így telepítheted:

```
pacman -S mingw-w64-x86_64-emacs
```

vagy a 32 bites buildet ezzel:

```
pacman -S mingw-w64-i686-emacs
```
