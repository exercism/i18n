# Részletesen

Egy érték átvitelre való előkészítése egyszerre három dolgot jelent: szerializálni kell, ki kell választani belőle a megfelelő darabot, és nem szabad másolni, amikor épp nem kell. Ezt a három területet három Factor-idióma fedi le.

## `unparse` - értékből forrásszöveg

Az [`unparse`][unparse] (a `prettyprint` szótárban) bármely érték forrásformájú szövegét adja vissza. A parser fordítottja: a `dup unparse parse` kör oda-vissza helyreállítja az értéket.

```factor
USING: prettyprint ;

{ 1 2 3 } unparse .   ! => "{ 1 2 3 }"
"hi" unparse .        ! => "\"hi\""
123 unparse .         ! => "123"
```

Vesd össze a `>string` szóval (ami csak karaktersorozatokon működik) és a `number>string` szóval (csak számokon). Az `unparse` az univerzális megoldás, cserébe viszont Factor-szintaxist állít elő (az idézőjelbe tett stringek megtartják az idézőjeleiket). Ezért akkor a megfelelő eszköz, amikor a fogadó fél majd visszaparsolja a szöveget, ember által olvasható kimenethez viszont rossz választás.

## Szeletek - nézetek, nem másolatok

| szó           | hatás                                          |
|---------------|------------------------------------------------|
| `head`        | `( seq n -- newseq )` - az első n elemet másolja |
| `head-slice`  | `( seq n -- slice )` - az első n elem nézete    |
| `tail`        | `( seq n -- newseq )` - az n. indextől másol    |
| `tail-slice`  | `( seq n -- slice )` - nézet az n. indextől     |
| `head*`       | `( seq n -- newseq )` - az utolsó n kivételével mindent másol |
| `head-slice*` | `( seq n -- slice )` - az utolsó n kivételével mindennek a nézete |
| `tail*`       | `( seq n -- newseq )` - az utolsó n elemet másolja |
| `tail-slice*` | `( seq n -- slice )` - az utolsó n elem nézete  |

A `slice` egy olyan tuple, amely egy kezdő- és egy záróindexet, valamint a mögöttes sorozatot tárolja. Megvalósítja a [sequence protocol][sequence-protocol] nevű protokollt, ezért bármilyen sorozatművelet működik rajta. Akkor nyúlj a szeletes változatokhoz, amikor egyébként csak azért foglalnál memóriát, hogy olvashass; és akkor a másoló változatokhoz, amikor meg kell őrizned az adatot, miután a mögöttes sorozat esetleg megváltozott.

## Több bemenetes cleave - `2bi`, `3bi`, `2tri`, `3tri`

Az egyszerű cleave szavak, a `bi` és a `tri` két vagy három quotationt alkalmaz a verem *egyetlen* bemenetére. A `2`-es és `3`-as előtagú változatok mindegyik quotationt *két*, illetve *három* bemenetre alkalmazzák:

```
bi   ( x       p q   -- )
2bi  ( x y     p q   -- )
3bi  ( x y z   p q   -- )

tri  ( x       p q r -- )
2tri ( x y     p q r -- )
3tri ( x y z   p q r -- )
```

Mindegyik quotation *az összes* bemenetet megkapja, ezért a `2bi` szót akkor használd, amikor mindkét vetítés a pár mindkét elemétől függ, és ne akkor, amikor ugyanazt a vetítést külön-külön szeretnéd alkalmazni mindegyik bemenetre (arra a `bi@` való).

```factor
1 2 [ + ] [ * ] 2bi . .       ! => 2  3   (both use 1 and 2)
1 2 3 [ + + ] [ * * ] 3bi . . ! => 6  6
```

Ha *egyetlen* quotationt akarsz külön-külön alkalmazni mindegyik bemenetre, akkor inkább a `bi@` (két bemenet) vagy a `tri@` (három bemenet) szót válaszd: ugyanaz a család, más a felépítés.
