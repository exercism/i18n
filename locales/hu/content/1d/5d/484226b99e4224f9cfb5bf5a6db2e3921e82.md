# Bemutató

A `string` a C++-ban egy módosítható objektum, amely szöveget karakterek (betűk, számjegyek, írásjelek stb.) sorozataként ábrázol.
A stringeket a metódusaik meghívásával kezeljük.

## A stringek könyvtára

A C++-ban a string típust és a hozzá tartozó függvényeket használat előtt be kell illeszteni a stringek könyvtárából.
Ezt úgy teheted meg, hogy a fájlod elejére beírod a `#include <string>` sort.
Így bekerülnek a `std` névtérbe.
A string literál a kettős idézőjelet használja: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## Gyakori stringműveletek

A stringek összefűzéséhez használhatod a `+` operátort:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

Ahhoz, hogy a stringek könyvtárát használd, tudnod kell, hogy egy objektumhoz tartozó függvényt is meg lehet hívni.
Ezeket tagfüggvényeknek nevezzük.
A tanterv későbbi részében többet is megtudsz a tagfüggvényekről és a hozzájuk kapcsolódó osztály fogalmáról.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


A `find` függvény is nagyon hasznos.
A stringen tagfüggvényként hívjuk meg, és egy stringet vár argumentumként.
A `find` a stringben az első előfordulás nullától indexelt pozícióját adja vissza.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("!");
// => 24
```

Létezik a `to_string` függvény is, amellyel egész számokat és float/double értékeket lehet stringgé alakítani.
A `to_string` egy stringet ad vissza.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
