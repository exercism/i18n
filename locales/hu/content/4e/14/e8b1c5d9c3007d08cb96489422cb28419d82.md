# Névjegy

A Swift egy fordított, többparadigmás nyelv.
A következő célokkal:

- Legyenek biztonsági funkciói, amelyek megakadályozzák a hibákat éles környezetben

- Nyújtson a C-alapú nyelvekéhez hasonlítható sebességet

- Olyan szintaxisa legyen, amelyet öröm olvasni és írni

A Swiftet az Objective-C leváltására fejlesztették ki, amely az iOS- és macOS-alkalmazások fejlesztésének elsődleges nyelve volt.
A Swiftet az Apple Inc. fejlesztette.
A nyelv első kiadása 2014-ben jelent meg.
Ma már nyílt forráskódú, és minden Apple-eszközön, Linuxon és Windowson is elérhető.

## Első lépések

### Változók

Az értékeket nevekhez rendelheted úgy, hogy definiálsz egy [változót][constants-variables], és értéket adsz neki.
Ezután ezt a nevet használhatod arra, hogy a program során bárhol erre az értékre hivatkozz.
A változók _módosíthatók_, ami azt jelenti, hogy az értékük bármikor megváltoztatható.

A változókat a `var` kulcsszóval definiálod.

```swift
var variableName = 10
```

A Swift típusbiztos, statikusan típusos nyelv, ami azt jelenti, hogy minden értéknek van típusa fordítási időben.
A változó típusát vagy explicit módon megadod [típusannotációkkal][type annotations], vagy hagyod, hogy a fordító [kikövetkeztesse a típust][type-inferring].
```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

A változó értékének frissítése az `=` operátorral történik.

~~~~exercism/note
A változó típusa az első definiálás után rögzül.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

A változókat deklarálhatod úgy is, hogy csak a nevet és a típust adod meg, érték nélkül, de nem használhatók, amíg nem kaptak értéket.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Konstansok

A [konstansok][constants-variables] abban hasonlítanak a változókhoz, hogy egy névhez és egy értékhez vannak rendelve, a konstans értéke azonban a kezdeti értékadás után nem módosítható, így _megváltoztathatatlan_.
A konstansokat a `let` kulcsszóval definiálod.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Összeadás, kivonás és szorzás

A Swiftnek vannak [operátorai][arithmetical-operators] az összeadáshoz, kivonáshoz és szorzáshoz.
Ezek rendre a `+`, a `-` és a `*` operátorok.

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Függvények

A Swiftben a [függvények][functions] olyan kódrészletek, amelyek egy feladatot látnak el.
A függvénynek van visszatérési típusa, ezért értékként is használható, és argumentumként átadható más függvényeknek.
A Swiftben a függvényeket a `func` kulcsszóval definiálod, amelyet a függvény neve, vesszővel elválasztott argumentumok, majd egy visszatérési típus követ.

Az argumentumokat egy argumentumcímke, valamint egy paraméternév határozza meg, amelyet kettőspont, majd egy típus követ.
A visszatérési típust egy `->` jelöli, amelyet a visszatérési érték típusa követ.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

A Swift argumentumai kicsit különlegesek más nyelvekhez képest: [argumentumcímkéket][argument-labels] használnak.
Az argumentumcímkét a függvény hívásakor használod.
A paraméternevet a függvény törzsén belül használod az argumentum értékére való hivatkozáshoz.
Ha csak egy nevet adsz az argumentumnak, az argumentumcímkeként és paraméternévként is szolgál.
Ha az argumentumcímke neve `_`, akkor a függvény hívásakor az argumentumnak nem lesz címkéje, például: `functionName(argumentValue)`

Egy függvény hívásához a függvény nevét használod, amelyet az argumentumcímke és az argumentum értéke követ, így:

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Alapértelmezés szerint minden argumentum megváltoztathatatlan, és a függvényen belül nem módosítható.
Ha egy függvénynek van visszatérési típusa, mindenképp adj vissza egy ilyen típusú értéket.
Ezt a `return` kulcsszóval teszed, amelyet a visszaadandó érték követ.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Ha a függvények nem adnak vissza értéket, visszatérési típusuk `Void`, ami ugyanaz, mint a `()`, de ezekben az esetekben a visszatérési típus el is hagyható.
