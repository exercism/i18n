# Bevezetés

## Az _if-then_ utasítás

A Java legalapvetőbb vezérlési szerkezete az _if-then_ utasítás.
Ezzel az utasítással csak akkor hajtódik végre egy kódrészlet, ha egy adott feltétel `true`.
Az _if-then_ utasítást az `if` ág segítségével definiáljuk:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

A fenti példában, ha az autóból elfogyott az üzemanyag, a `Car.drive` metódus meghívása nem tesz semmit.

## Az _if-then-else_ utasítás

Az _if-then-else_ utasítás alternatív végrehajtási utat biztosít arra az esetre, amikor az `if` ágban szereplő feltétel `false` értékre értékelődik ki.
Ez az alternatív végrehajtási út egy `if` ág után következik, és az `else` ág segítségével definiáljuk:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

A fenti példában, ha az autóból elfogyott az üzemanyag, a `Car.drive` metódus meghívása egy másik metódust hív meg, amely leállítja az autót.

Az _if-then-else_ utasítás több feltételt is támogat az `else if` ág használatával:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

A fenti példában, ha az üzemanyag kevesebb vagy egyenlő, mint `5`, az autó tovább halad, de kigyullad az üzemanyagszintjelző lámpa.
Amikor az üzemanyag eléri a `0`-t, az autó megáll.
