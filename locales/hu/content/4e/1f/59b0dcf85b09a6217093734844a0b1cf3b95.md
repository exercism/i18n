# Utasítások

A feladatod, hogy értelmezz egy Smart Game Format (SGF) szöveget, és a játékot reprezentáló fa adatszerkezetet adj vissza.

Az SGF-szöveg csomópontokból álló fát ír le. A teljes fát zárójelek `()` veszik körül.
A fában minden csomópontot egy pontosvessző `;` jelöl, amelyet tulajdonságok sorozata követ.
Egy tulajdonság egy nagybetűs azonosítóból (például `AB`) és az őt követő, szögletes zárójelbe `[]` zárt egy vagy több értékből áll.

Például a `(;FF[4]C[root])` szöveg egyetlen gyökércsomópontból álló fát ír le. Ennek a csomópontnak két tulajdonsága van:
- `FF` tulajdonság `4` értékkel
- `C` tulajdonság `root` értékkel

**Változatok (fák és ágak)**
Az SGF a fák egymásba ágyazásával támogatja a játékváltozatokat. Egy fának több gyermekfája is lehet, amelyeket szintén zárójelek vesznek körül.
Például a `(;A[B](;C[D])(;E[F]))` szöveg egy `A` tulajdonságú gyökércsomópontot ír le, amelynek két gyermekága van:
1. Egy csomópont `C` tulajdonsággal és `D` értékkel
2. Egy csomópont `E` tulajdonsággal és `F` értékkel

**Formázás és escape-elés**
A zárójelek közötti értékek escape-elt karaktereket tartalmazhatnak. Egy fordított perjel `\`, amelyet bármilyen karakter követ, azt a literál karaktert jelöli (például a `\]` szöveget literál `]`-ként kell értelmezni). Továbbá, ha egy sortörés előtt fordított perjel áll, az sorfolytatásként működik, és el kell távolítani az értékből. Az értéken belüli összes többi sortörést meg kell őrizni.

**Hibakezelés**
Érvénytelen SGF-szövegek esetén hibát kell dobni. Az alábbiak példák érvénytelen SGF-szövegekre:
- Egy fa, amely nem `()` zárójelekkel kezdődik.
- Egy csomópont, amely nem pontosvesszővel `;` kezdődik.
- Olyan tulajdonságazonosítók, amelyek nem kizárólag nagybetűkből állnak.
- Hiányzó zárójelek vagy nem párosított zárójelek.

### Adatszerkezet

Az értelmező függvényednek a fa egy reprezentációját kell visszaadnia. Gyakori megközelítés, hogy minden fát egy két mezőből álló objektumként ábrázolunk:
- `properties`: Egy objektum (vagy Map), amelynek kulcsai a tulajdonságazonosítók (stringek), értékei pedig stringtömbök (mivel egy tulajdonságnak több értéke is lehet).
- `children`: A gyermekfákat tartalmazó tömb.


Példa:

Bemenet: `(;FF[4]C[root])`
Kimenet: `{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

Bemenet: `(;A[B](;C[D])(;E[F]))`
Kimenet: `{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
