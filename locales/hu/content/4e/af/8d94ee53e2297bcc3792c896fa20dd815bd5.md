# Bevezetés

## Interfészek

Az interfész egy olyan típus, amelynek tagjai egy összetartozó funkcionalitáscsoportot határoznak meg. Elválasztja az osztály használatát annak implementációjától, ami lehetővé teszi több különböző implementáció létét, illetve olyan általános viselkedés támogatását, mint a formázás, az összehasonlítás vagy a konverzió.

Az interfész szintaxisa hasonlít az osztályéhoz vagy a struktúráéhoz, azzal a különbséggel, hogy a metódusok és a tulajdonságok csak szignatúraként jelennek meg, törzs nélkül.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Az interfészben meghatározott összes műveletet implementálni kell.

Az interfészek a többi tag mellett példánymetódusokat és tulajdonságokat is tartalmazhatnak

## Rendezés

Ahhoz, hogy egy objektum összehasonlítható legyen egy másikkal, implementálnia kell az `IComparable<T>` interfészt.
Ennek az interfésznek egyetlen metódusa van, amelyet implementálni kell: `int CompareTo(T other)`.

A `CompareTo` metódusnak három lehetséges visszatérési értéke van:

- Nullánál kisebb érték: az aktuális objektum kisebb, mint a másik objektum.
- Nullánál nagyobb érték: az aktuális objektum nagyobb, mint a másik objektum.
- Az érték nulla: az aktuális objektum egyenlő a másik objektummal.
