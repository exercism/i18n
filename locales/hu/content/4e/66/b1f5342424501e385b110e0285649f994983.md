# Utasítások

Egy jelzőállomás kódgeneráló eszközkészletét gondozod.
Minden makró egy *sablon*: egy kis minta, amellyel a fordító
minden hívási helyen speciális kódot állít elő.

Te csak a négy makrót írod meg. A tesztfájl apró
burkoló szavakat definiál, amelyek *meghívják* a makróidat (egy
makrót csak a generált kódon keresztül lehet megfigyelni), majd
ellenőrzi a burkoló szavak futásidejű eredményeit. A burkoló
szavakat hagyd úgy, ahogy vannak.

Minden részfeladatnál a törzs a hívási hely literál bemeneteit
kapja meg a vermen, és **egy quotation** maradjon utána.
A »compiles to« sorok mutatják meg azt a lineáris kódot,
amelyet a quotationnek elő kell állítania.

## 1. Kétszer egymás után

A `twice` egy literál quotationt kap, és olyan quotationt ad
vissza, amely az eredetit kétszer egymás után futtatja.

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N ismétlés

A `repeat-quot` egy literál quotationt és egy literál `n` számot
kap, és olyan quotationt ad vissza, amely az eredetit `n`-szer
futtatja egymás után. `n = 0` esetén az üres quotationt adja
vissza: `[ ]`.

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. Több összefűzése

A `compose-many` egy literál tömböt kap, amely quotationokat
tartalmaz, és egyetlen quotationt ad vissza, amely sorban
lefuttatja mindegyiket. Üres tömb esetén az üres quotationt adja
vissza.

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. Kigöngyölt iteráció

Az `each-literal` egy literál sorozatot és egy quotationt kap.
Olyan quotationt ad vissza, amely a sorozat minden eleménél a
veremre teszi az adott elemet, majd lefuttatja a quotationt.
Az iteráció így fordítási időben zajlik le, ezért a generált kód
lineáris.

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

Ez a négy közül a leginkább szerkezeti jellegű: a generált kódot
egyszerre alakítja a sorozat hossza *és* az elemeinek értékei.
A tippek lépésről lépésre végigvezetnek az összeállításán.
