# Bevezetés

Az előző feladatban láttuk, hogy Go-ban kétféleképpen írhatunk kommentet: az egysoros kommenteket `//` előzi meg, a többsoros kommentblokkokat pedig `/*` és `*/` fogja közre.

## Dokumentációs kommentek

Go-ban a kommentek fontos szerepet játszanak a kód dokumentálásában.
A `godoc` parancs használja őket: kinyeri ezeket a kommenteket, és dokumentációt készít belőlük a Go-csomagokról.
A dokumentációs kommentnek teljes mondatnak kell lennie, amely annak a nevével kezdődik, amit leír, és ponttal végződik.

A kommenteknek a csomagokat és az exportált azonosítókat is meg kell előzniük, például az exportált függvényeket, metódusokat, csomagszintű változókat, konstansokat és struktúrákat. Utóbbiakról a következő feladatokban tanulsz majd többet.

Egy csomagszintű változó így nézhet ki:

```go
// TemperatureCelsius represents a certain temperature in degrees Celsius.
var TemperatureCelsius float64
```

## Csomagkommentek

A csomagkommenteket közvetlenül a csomagra vonatkozó utasítás (`package x`) elé kell írni, és a `Package x ...` formával kell kezdődniük, például így:

```go
// Package kelvin provides tools to convert
// temperatures to and from Kelvin.
package kelvin
```

## Függvénykommentek

A függvénykommentet közvetlenül a függvénydeklaráció elé kell írni.
Legyen teljes mondat, amely a függvény nevével kezdődik.
Egy exportált függvény kommentje, például a `Calculate` esetében, a `Calculate  ...` formát kövesse.
Azt is el kell magyaráznia, milyen argumentumokat vár a függvény, mit tesz velük, és mit jelentenek a visszatérési értékei, a végén ponttal):

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
