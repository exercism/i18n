# Részletesen

A Boolean-okat Java-ban a `boolean` típus képviseli, amelynek értéke `true` vagy `false` lehet.

A Java három [logikai operátort][operators] ismer:

- `!` (NOT): tagadja a logikai értéket
- `&&` (AND): két logikai értéket vesz át, és igaz lesz, ha mindkettő igaz
- `||` (OR): igaz lesz, ha a két logikai érték közül bármelyik igaz

A `&&` és a `||` operátor _rövidzárásos kiértékelést_ használ, ami azt jelenti, hogy az operátor jobb oldalát csak akkor értékeli ki, amikor arra szükség van.

Ezeket feltételes vagy logikai operátoroknak is nevezik.
A `!` operátort a dokumentáció néha bitenkénti műveletként sorolja be, de a hagyományos _NOT_ jelentéssel bír.

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

A három logikai operátor [_precedenciája_][precedence] különböző.
Ennek következtében a kiértékelés sorrendje a következő: először a `not`, aztán a `&&`, végül a `||`.
Ha meg szeretnél „szabadulni” ezektől a szabályoktól, egy logikai kifejezést zárójelbe (`()`) tehetsz, mert a zárójel precedenciája még ennél is nagyobb.

```java
!true && false   // => false
!(true && false) // => true
```
