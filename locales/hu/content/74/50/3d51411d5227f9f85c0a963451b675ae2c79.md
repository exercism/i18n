# Bemutatás

Azokat az adatszerkezeteket, amelyek nulla vagy több elemet tárolhatnak, _gyűjteményeknek_ nevezzük. A **tömb** olyan gyűjtemény, amelynek rögzített a mérete/hossza, és amelynek minden eleme azonos típusú kell legyen. Az elemeket index segítségével rendelheted hozzá egy tömbhöz, illetve kérdezheted le belőle. A C# tömbjei nullától indexelnek, ami azt jelenti, hogy az első elem indexe mindig nulla:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

A tömböket egy rövidített jelöléssel is létrehozhatod, amellyel egyszerre hozod létre a tömböt és adod meg az értékeit. Mivel a fordító most már meg tudja állapítani, hány eleme lesz a tömbnek, a hossz elhagyható:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

A tömbökkel úgy dolgozhatsz, hogy meghívod a tömbpéldány [metódusait][array-methods] vagy [tulajdonságait][array-properties], illetve használod a [`Array` osztályban][array-class] definiált statikus metódusokat.

## Iteráció

A tömb egyben _gyűjtemény_ is, ami azt jelenti, hogy egy [`foreach` ciklussal][foreach-statement] végigiterálhatsz _az összes_ értékén:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Egy tömböt [`for` ciklussal][for-statement] is bejárhatsz:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

A `foreach` ciklus azonban általában előnyösebb a `for` ciklusnál, a következő okok miatt:

- A `foreach` ciklus garantáltan _az összes_ értéken végigiterál. Egy `for` ciklusnál könnyű kihagyni elemeket, például ha az indexekkel elcsúszol.
- A `foreach` ciklus _deklaratívabb_: a kódod azt közli, _mit_ szeretnél vele elérni, nem pedig azt, _hogyan_ akarod megcsinálni, mint a `for` ciklus.
- A `foreach` ciklus hibabiztos, míg a `for` ciklusoknál könnyen elcsúszhat az index.
- A `foreach` ciklus minden gyűjteménytípuson működik, beleértve azokat is, amelyek nem támogatják az elemek indexelővel való elérését.

Ahhoz, hogy a `foreach` ciklus garantáltan _az összes_ értéken végigiteráljon, a fordító nem engedi meg, hogy egy gyűjteményt egy `foreach` cikluson belül módosíts:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

A `for` ciklusnak viszont van néhány előnye a `foreach` ciklussal szemben:

- Bármelyik indexnél kezdheted vagy állhatsz meg.
- Bármilyen (Boolean) befejezési feltételt használhatsz.
- Kihagyhatsz elemeket, ha testre szabod a ciklusváltozó léptetését.
- A gyűjteményeket hátulról előre is feldolgozhatod, visszafelé számolva.
- `for` ciklusokat gyűjtemények nélküli esetekben is használhatsz.

Kapcsolódó témák:

- Érdemes tudnod, hogy a C# támogatja a [többdimenziós tömböket][multi-dimensional-arrays], például `int[,] arr = new int[10, 5]`, ami nagyon hasznos lehet.
- Azt is érdemes tudnod, hogy `Array.CreateInstance` hívásával [`System.Array`][system-array-object] típusú objektumokat példányosíthatsz. Az ilyen objektumok kevéssé hasznosak, főleg a VB.NET kóddal való együttműködéshez jók. Nem cserélhetők fel a szabványos tömbökkel (`T[]`). Lehet nem nulla az alsó határuk.
