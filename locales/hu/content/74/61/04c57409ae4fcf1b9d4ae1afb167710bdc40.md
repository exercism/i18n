# Bevezetés

A magasabb rendű függvény olyan függvény, amelyik vagy:

- argumentumként kap egy függvényt
- függvényt ad vissza

A függvényargumentum is csak egy közönséges argumentum, csak éppen meg is tudod hívni.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
