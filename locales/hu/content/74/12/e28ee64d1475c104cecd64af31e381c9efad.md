# Bevezetés a for ciklusokba

A [for ciklus](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) lehetővé teszi, hogy egy utasításcsoportot ismételten végrehajtsunk, amíg valamilyen feltétel teljesül.
A ciklus négy részből áll:

```java
for (initialization; test; update) {
    body;
}
```

Az `initialization` beállítja a ciklus kezdeti állapotát, és pontosan egyszer fut le a ciklus elején.
Általában deklarál és értéket ad egy változónak, amelyet a test kifejezésben és az update utasításban használunk.
Például:

```java
int i = 1
```

A `test` kifejezés azt vizsgálja, hogy a ciklusnak véget kell-e érnie.
Ha `true` értékre értékelődik ki, akkor a ciklustörzs, majd az update kifejezés hajtódik végre.
Ha `false` értékre értékelődik ki, akkor sem a ciklustörzs, sem az update utasítás nem hajtódik végre, és a végrehajtás a ciklus záró kapcsos zárójele után folytatódik.
Általában azt a változót ellenőrzi, amelyet az inicializálási blokkban rendeltünk hozzá.
Például:

```java
i <= 10
```

A ciklustörzs végrehajtása után az `update` kifejezés hajtódik végre.
Általában növeli vagy csökkenti a ciklusváltozót valamilyen értékkel.
Például:

```java
i++
```

Egy `for` ciklus, amely kiírja az első négy négyzetszámot, így nézne ki:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

A kimenet a következő lenne:

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

Ha egy gyűjtemény minden elemén végig szeretnénk menni, a `for-each` ciklus az ajánlott, de `for` ciklussal is megtehető, például így:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

A `for` ciklusnak azonban van néhány előnye a `for-each` ciklussal szemben:

- Tetszőleges indexnél kezdheted vagy fejezheted be.
- Bármilyen (boolean) lezárási feltételt használhatsz.
- Kihagyhatsz elemeket a ciklusváltozó léptetésének testreszabásával.
- Feldolgozhatod a gyűjteményeket hátulról előre, visszafelé számolva.
- `for` ciklusokat olyan helyzetekben is használhatsz, amelyekben nincs gyűjtemény.
