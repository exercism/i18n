# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat       | Típus      | Leírás                                              |
| --------- | --------------- | ---------- | --------------------------------------------------- |
| `$a0`     | bemenet         | cím        | szótömb a vödrök kapacitásaival                      |
| `$a1`     | bemenet         | egész szám | kezdő vödör (1 vagy 2)                              |
| `$a2`     | bemenet         | egész szám | célmennyiség                                        |
| `$a3`     | bemenet/kimenet | cím        | szótömb a vödrök végső tartalmával                   |
| `$v0`     | kimenet         | egész szám | a szükséges műveletek száma, vagy -1, ha nem lehetséges |
| `$t0-9`   | ideiglenes      | bármilyen  | átmeneti tárolásra szolgál                          |
