# Utasítások

Ebben a feladatban a [Go játék szabályait](https://matmoore.github.io/learngo/) fogod alkalmazni. Maguk a szabályok már meg vannak írva, neked már csak alkalmaznod kell őket, hogy frissítsd a Game-et, és kezeld a hibákat, illetve a szabályok megsértését.

A játék reprezentációja a következő:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

A játékban 4 szabály van:

- Minden ponton csak egy kő lehet (`oneStonePerPointRule`)
- Az ellenfél köveit le lehet venni! (`captureRule`)
- Nem rakhatsz le követ olyan pontra, ahol az önmagát venné le (`libertyRule`)
- Ugyanazt a pontot kétszer nem használhatod (`koRule`)

## 1. Alkalmazd a szabályokat

Írd meg az `applyRules` függvény tartalmát, amely egy kezdeti `Game`-et és egy szabályhalmazt kap, és visszaadja az új `Game`-et, miután a szabályokat alkalmaztuk.

Az `oneStonePerPointRule`, a `libertyRule` és a `koRule` mind a szabályok megsértését ellenőrzik, és hibát adhatnak vissza, ezért a visszatérési típusuk `Result String Game`. Ha ezek közül bármelyik szabály megbukik, az eredeti játékot kell visszaadni, de a `error` mezőt frissíteni kell a megfelelő hibával.

A `captureRule` nem ellenőrzi a szabálysértéseket, ezért nem tud megbukni (bár visszaadhat egy megváltozott `Game`-et), így a visszatérési típusa `Game`.

Ha minden szabály sikeresen lefut, akkor a szabályoktól származó `Game`-módosításokat meg kell tartani, és a játékost le kell cserélni. Erre szolgál a `changePlayer` függvény.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
