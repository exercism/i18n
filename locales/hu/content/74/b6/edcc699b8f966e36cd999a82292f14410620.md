# Utasítások

Szenvedélyes madárfigyelő vagy, aki nyomon követi, hány madár járt a kertedben.
A madarak megszámolásához általában egy jegyzetfüzetbe írt rovátkákat használsz, de hogy jobban dolgozhass az adataiddal, digitalizáltad az elmúlt hetek madárszámait.

## 1. Határozd meg, eddig összesen hány madarat számoltál

Kezdjük az adatelemzést egy átfogó képpel.
Nézd meg, összesen hány madarat számoltál meg, mióta elkezdted vezetni a naplódat.

Készíts egy `TotalBirdCount` függvényt, amely egy `int`-ekből álló szeletet fogad el, benne a napi madárszámmal.
A függvény adja vissza a megszámolt madarak összlétszámát.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Számold ki, hány madár látogatta a kertet egy adott héten

Most, hogy már van egy általános képed a madárszámaidról, szeretnél egy részletesebb elemzést is készíteni.

Készíts egy `BirdsInWeek` függvényt, amely a napi madárszámokat tartalmazó szeletet és egy hét sorszámát fogadja el.

A függvény adja vissza, összesen hány madarat számoltál meg abban az adott héten.
Feltételezheted, hogy a heteket mindig teljesen nyomon követed.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Javíts ki egy számolási hibát

Rájöttél, hogy amíg a madarakat próbáltad nyomon követni, végig volt egy madár, amely a kert egy távoli sarkában rejtőzött.

Kiszámoltad, hogy ez a madár mindig minden második napot a kertedben töltött.

Azt nem tudod pontosan, hol volt a köztes napokon, de az biztos, hogy nem a kertedben.

A madárfigyelői megérzésed azt is súgja, hogy a madár a listádon szereplő első napon a kertedben volt.

Ezekkel az új információkkal írj egy `FixBirdCountLog` függvényt, amely argumentumként a naponta megszámolt madarak szeletét kapja, és visszaadja a szeletet a számolási hiba kijavítása után.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
