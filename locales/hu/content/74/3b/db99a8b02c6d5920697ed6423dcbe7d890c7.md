# PaySwitch - Fizetésátváltó

## A probléma

Az **Insure Everyone** nevű cég külföldi valutákban fizeti az alkalmazottait. A jogszabályi előírások miatt azonban a fizetést át kell váltani a helyi valutára. Az alkalmazottai a világ minden táján dolgoznak.
Az Insure Everyone HR-osztálya egy tehetséges fejlesztő segítségét kéri egy olyan program megírásához, amely minden alkalmazott fizetését átváltja a hozzá tartozó helyi valutára. Az Insure Everyone egy külső API által biztosított árfolyamokra támaszkodik.

A külső árfolyam-API ismeretében olyan függvényt kell írnod, amely megkapja a `source currency` forrásvalutát, a `salary` fizetést (forrásvalutában) és az alkalmazott `local currency` helyi valutáját, majd visszaadja a fizetést a helyi valutában.

## Megkötések

* 500 <= `salary` <= 10000
* A `sourceCurrency` és a `targetCurrency` [ISO-valutakódok (alfabetikusak)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes). A tesztbemenet érvénytelen valutakódokat is tartalmazhat.
* A visszaadott árfolyam pontosságát `5` tizedesjegyig mérik.

## Példa

### 1. példa

#### Bemenet:
* Fizetés: 1000
* Forrásvaluta: USD
* Célvaluta: GBP

#### Kimenet:

Feltéve, hogy a külső valutaváltó a következő átváltási árfolyam-választ adta vissza (kihagyva):

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

A függvénynek `735.84000`-t kell visszaadnia.

### 2. példa

#### Bemenet:

* Fizetés: 1000
* Forrásvaluta: GBP
* Célvaluta: USD

#### Kimenet:

Feltéve, hogy a külső valutaváltó a következő átváltási árfolyam-választ adta vissza (kihagyva):

```json
{
    "base": "GBP",
    "rates": {
        // omitted
        "USD": 1.35898,
        // omitted
    }
}
```

A függvénynek `1358.9800`-t kell visszaadnia.

## Tippek

* A kapott JSON-választ átalakíthatod egy felhasználó által definiált típusra (pontosabban egy nyílt rekordra) a könnyebb hozzáférés érdekében. További információért lásd a [HTTP-kliens adatkötése](https://ballerina.io/learn/by-example/http-client-data-binding/) oldalt.
