# Bevezetés

A szöveggel való munka gyakori feladat a programozásban.
A Swift a Foundation keretrendszerrel együtt számos kényelmes metódust és tulajdonságot kínál a stringek vizsgálatához, átalakításához és manipulálásához.

## Stringek felbontása a `components(separatedBy:)` metódussal

Ha egy stringet egy elválasztó alapján részstringek tömbjére szeretnél bontani, használd a `components(separatedBy:)` metódust (ehhez importálni kell a Foundation keretrendszert):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Előtagok és utótagok ellenőrzése a `hasPrefix(_:)` és `hasSuffix(_:)` metódussal

Ha ellenőrizni szeretnéd, hogy egy string egy adott karaktersorozattal kezdődik vagy végződik-e, használd a `hasPrefix(_:)` és `hasSuffix(_:)` metódust:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## A kis- és nagybetűsség megváltoztatása

A string kis- és nagybetűsségét az alábbi szabványos metódusokkal és tulajdonságokkal alakíthatod át:

- `lowercased()`: A string kisbetűs másolatát adja vissza.
- `uppercased()`: A string nagybetűs másolatát adja vissza.
- `capitalized`: Olyan másolatot ad vissza, amelyben minden szó első betűje nagybetűs (a Foundation keretrendszerből).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Részstringek cseréje a `replacingOccurrences(of:with:)` metódussal

Ha egy cél-részstring minden előfordulását le szeretnéd cserélni egy másik stringre, használd a `replacingOccurrences(of:with:)` metódust (a Foundation keretrendszerből):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Stringek összefűzése a `joined(separator:)` metódussal

A `joined(separator:)` metódus a stringek gyűjteményeihez tartozik, például a `[String]` típushoz.
Az elemeket egyetlen stringgé fűzi össze egy elválasztó segítségével:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
