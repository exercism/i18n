# A milliárd dolláros HTTP-kérdés

## A feladat

Az a feladatod, hogy egy adott országcsoportban megkeresd a nettó vagyon szerinti első `x` milliárdost (az országok száma = `N`). Ennek megvalósításához hozzáférést kaptál egy API-hoz, amely országonként visszaadja a milliárdosok adatait.

Az API elérésének egyszerűsítéséhez használhatod az [`ims/billionairehub` kliens](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) connectort, amellyel ahhoz az API-hoz csatlakozhatsz, amely országonként adja vissza a milliárdosok adatait.

## Megkötések

* 1 <= N <= 5
* 1 <= x <= 10

## 1. példa

Bemenet

```
Countries: ["United States"]
Limit: 3
```

Kimenet

```
["Elon Musk", "Jeff Bezos", "Bill Gates"]
```

## 2. példa

Bemenet

```
Countries: ["China", "India"]
Limit: 5
```

Kimenet

```
["Mukesh Ambani", "Gautam Adani & family", "Zhong Shanshan", "Zhang Yiming", "Ma Huateng"]
```

## Tesztkörnyezet

* A milliárdos API-hoz való csatlakozáshoz szükséges Client ID-t és Client Secretet a `tests/Config.toml` fájlban kaptad meg. Ezekkel inicializálhatod a klienst.
* A megvalósítás futtatásához és teszteléséhez használd a `bal test` parancsot.

## Tippek

* Az `ims/billionairehub` csomag [kliens](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client)ével meghívhatod az országonkénti milliárdosokat visszaadó API-t. Konkrétan a `getBillionaires("<country>")` remote metódust használhatod.
* Először megkeresheted az egyes országok leggazdagabb embereit, majd összevonhatod őket, hogy megkapd az első `x`-et.
* A szűréshez és a rendezéshez kényelmesek lesznek a [lekérdezéskifejezések](https://ballerina.io/learn/by-example/query-expressions/).
