# Tippek

## Általános

- A lencséket nem nagyon használják Rocban, mert a rekordfrissítő szintaxis a legtöbb esetet szépen lefedi.
  Vegyük például ezt az egymásba ágyazott rekordot:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  Most adjunk Bobnak egy hajvágást:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  Nincs szükség lencsékre!

- Mindezek ellenére, bár a lencsék ritkák Rocban, más nyelvekben, például Haskellben és Scalában gyakoriak, szóval kíváncsi lehetsz rá, hogyan lehetne megvalósítani őket Rocban.
  Ez egyébként jó módja annak is, hogy gyakorolj néhány haladó Roc-jellemzőt, például a paraméterezett típusokat és a függvényeket tartalmazó rekordokat.
  Íme egy mód arra, hogyan ábrázolhatunk egy lencsét Rocban:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  Ez egy paraméterezett típus: a `whole` és a `part` bármilyen típus lehet.
  A `whole` általában rekord, a `part` pedig bármilyen mezőtípus lehet.
  A `get` mező egy olyan függvényt tartalmaz, ami visszaadja a kapott `whole` egy adott `part`-ját, a `set` mező pedig egy olyan függvényt, ami a kapott `whole` egy másolatát adja vissza úgy, hogy egy adott `part`-ját lecseréli a kapott `part`-ra.

  Például íme egy lencse, amivel egy személy haját olvashatod ki vagy állíthatod be:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  Ezzel a lencsével Bob hajára fókuszálhatunk, így:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  A haját pedig így változtathatjuk meg:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- Megjegyzés: a `hair_lens.set` körüli zárójelek kötelezőek: nélkülük a Roc egy `set` nevű függvényt keresne a `hair_lens` típusában.

- A lencsék különösen akkor válnak hasznossá, amikor elkezded őket összefűzni: így mélyen egymásba ágyazott részeket is ki tudsz olvasni és be tudsz állítani.
  Ezt egy ilyen függvény megvalósításával teheted meg:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  Ha egyszer megvan ez a függvény, így hozhatsz létre egy hajhossz-lencsét:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  Most újra megvághatod Bob haját:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- Az is lehet, hogy szeretnél egy olyan függvényt is megvalósítani, amivel bármilyen átalakítást alkalmazhatsz egy egymásba ágyazott részre:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  Ha kész van, így használhatod az `over` függvényt:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- Azt javasoljuk, először a Roc rekordfrissítő szintaxisával teljesítsd a teszteket, aztán próbáld ki a lencséket.
