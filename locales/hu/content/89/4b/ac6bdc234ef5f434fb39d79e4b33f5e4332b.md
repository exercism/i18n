# Névjegy

Egy *diszjunkt halmaz* (union-find adatszerkezet) értékek egy gyűjteményét tartja nyilván, egymást nem átfedő csoportokba osztva, és gyorsan válaszol egy kérdésre: ugyanabba a csoportba tartozik-e ez a két érték? A [`disjoint-sets`][disjoint-sets] szókészletben található.

A `<disjoint-set>` egy üres szerkezetet hoz létre. Az értékeket (az *atomokat*) az `add-atom` adja hozzá, vagy tömegesen az `add-atoms`; mindegyik a saját, egytagú csoportjában kezd:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

Az `equate` egyesíti a két atomot tartalmazó csoportokat. Az egyesítés tranzitív: ha `a`-t egyenlővé tettük `b`-vel, és `b`-t `c`-vel, akkor mind a három ugyanabba a csoportba tartozik.

```
equate ( atom1 atom2 disjoint-set -- )
```

Minden csoportot egyetlen kanonikus tag azonosít, ez a csoport *reprezentánsa*. A `representative` ezt adja vissza, és két atom pontosan akkor tartozik ugyanahhoz a csoporthoz, ha a reprezentánsaik egyenlők. Az `equiv?` közvetlenül elvégzi ezt a vizsgálatot:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

Az, hogy egy csoport reprezentánsává melyik atom válik, belső részlet: bármelyik tag lehet, és a csoportok egyesülésekor változhat is. Soha ne számíts arra, hogy egy adott atom a reprezentáns; csak arra, hogy két, ugyanabba a csoportba tartozó atom reprezentánsa megegyezik.

A `disjoint-set-members` minden hozzáadott atomot visszaad.

A szerkezet *módosítható*: az `equate` és az `add-atom` helyben módosítja a diszjunkt halmazt, ahelyett hogy újat adna vissza. A megvalósítás rang szerinti egyesítést használ úttömörítéssel, így az `equate` és a `representative` hívásokból álló hosszú sorozatban minden egyes hívás gyakorlatilag állandó idejű.
