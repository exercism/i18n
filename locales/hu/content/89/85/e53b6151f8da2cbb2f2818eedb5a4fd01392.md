# Bevezetés

A JavaScriptben a tömb egy listaszerű szerkezet, amelynek nincs rögzített hossza, és bármilyen típusú primitív értéket vagy objektumot tárolhat, akár vegyes típusokat is.

Tömb létrehozásához írd az elemeket szögletes zárójelek (`[]`) közé.
A tömbből való olvasáshoz tedd az indexet szögletes zárójelek (`[]`) közé az azonosító után.
A tömb indexei nullától kezdődnek.

Például:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

A tömbben lévő elemek számának lekéréséhez használd a `length` tulajdonságot:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Egy elem megváltoztatásához a tömbben adj értéket az adott indexen:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Metódusok

Az Array objektumon elérhető [metódusok][array_methods] közül néhányat arra használhatsz, hogy elemeket adj a tömbhöz vagy távolíts el belőle.

### push

> A `push()` metódus egy vagy több elemet fűz a tömb végéhez, és visszaadja a tömb új hosszát.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> A `pop()` metódus eltávolítja a tömb utolsó elemét, és visszaadja azt az elemet.
> Ez a metódus megváltoztatja a tömb hosszát.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> A `shift()` metódus eltávolítja a tömb első elemét, és visszaadja az eltávolított elemet.
> Ez a metódus megváltoztatja a tömb hosszát.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> Az unshift() metódus egy vagy több elemet fűz a tömb elejéhez, és visszaadja a tömb új hosszát.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> A splice() metódus megváltoztatja a tömb tartalmát: eltávolít vagy lecserél meglévő elemeket, illetve új elemeket szúr be a helyükre. Ez a metódus egy tömböt ad vissza, amely a törölt elemeket tartalmazza.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
