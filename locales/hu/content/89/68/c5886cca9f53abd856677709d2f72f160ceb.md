# Bevezetés

Ahogy a [`Nothingness`][concept-nothingness] fogalomban is láttuk, az R-nek többféle módja van arra, hogy olyan adatokat ábrázoljon, amelyek hiányoznak (`NULL`), ismeretlenek (`NA`), vagy matematikailag érvénytelenek (`NaN`, `Inf`).
Általában az R ezekkel igyekszik a helyszínen jelezni a problémákat, majd kivétel dobása nélkül folytatja.

## `stop()`

Némelyik probléma túl alapvető ahhoz, hogy hagyjuk a programot tovább futni.
Ebben az esetben használd a `stop(msg)` függvényt, amely azonnal leállítja a programot egy `Error`-ral, és kiírja a `msg`-t.

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

Más nyelvek `assert`-jéhez hasonlóan ez egy kényelmes wrapper a `stop()` körül.
Paraméterként tetszőleges számú, vesszővel elválasztott logikai feltételt adhatsz meg, és a program csak akkor folytatódik, ha mindegyikük `TRUE`.

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `warning()` és `message()`

Ezek a nem végzetes állapotokra adott válaszok, például:

- Figyelmeztetni egy olyan problémára, amelyből a program legalább részben helyre tud állni.
- Tájékoztatni a felhasználót egy hosszan futó program előrehaladásáról.

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

A `suppressWarnings()` függvény alkalmanként hasznos lehet az Exercismen belül, hogy elkerüljük, hogy a nem kívánt kimenet összezavarja a tesztfuttatót.
