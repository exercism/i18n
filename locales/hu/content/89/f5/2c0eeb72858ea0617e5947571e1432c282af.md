# Tippek

## 1. Szerezd meg a mondat első betűjét

- Nézd át újra a bevezetőt, hogy megtudd, hogyan kérhetsz le egy adott betűt egy stringből.
- Az indexek 0-tól kezdődnek.

## 2. Alakítsd nagybetűssé a szót

- A nagybetűsítés azt jelenti, hogy egyetlen _nagybetűs_ karaktert _kisbetűs_ karakterek követnek.
- Először tehát ki kell nyerned az első betűt, és [nagybetűssé][mdn-to-upper-case] kell alakítanod.
- Ezután meg kell határoznod a string többi részét (mindent az első karakteren kívül).
  Ebben a [slice metódus][mdn-slice] segíthet.
- Miután [kisbetűssé][mdn-to-lower-case] alakítottad, az első betűt az összeadás operátorral (`+`) fűzheted össze a többivel.

## 3. Szerezd meg a mondat utolsó betűjét

- Nézd át újra a bevezetőt, hogy megtudd, hogyan kérhetsz le egy adott betűt egy stringből.
- Az utolsó betű indexét a string `.length` tulajdonságából és abból vezetheted le, hogy az indexek 0-tól kezdődnek.
- A stringekhez tartozik egy [trim][mdn-trim] metódus, amely eltávolítja a string elején és végén lévő szóközöket.

## 4. Légy udvarias

- Használj újra egy meglévő függvényt a szó nagybetűssé alakításához.
- Két string összefűzéséhez az összeadás operátor (`+`) használható.
