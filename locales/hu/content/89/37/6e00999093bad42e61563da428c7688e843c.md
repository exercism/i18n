# Névjegy

A [closure][closures] a Swiftben egy önálló kódblokk: paramétereket adhatsz át neki, amivel elindítod a számítását, és értéket ad vissza.
A closure emellett értékeket is rögzít a környezetéből, és felhasználja őket a számításaiban.
Mivel önmagában áll, a programban ugyanúgy továbbadhatod, mint bármely más értéket, vagy hozzárendelheted konstansokhoz és változókhoz.

A closure nagyon hasonlíthat a Swift-függvényekre, és valóban hasonlít is, méghozzá jó okkal.
A Swift-függvény valójában a closure egy speciális esete: neki kötelező a neve, és egy kicsit más szintaxissal definiáljuk.

Bár a Swift-függvény technikailag closure, amikor az emberek „closures”-ról beszélnek a Swiftben, valójában closure expressionre gondolnak.
A closure expression a következőképpen íródik le: egy paraméterlista, majd a visszatérési típus, majd az `in` kulcsszó és a closure törzse, mindez egy pár kapcsos zárójelben:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Ez egy `(Double, Double) -> Double` típusú closure expressiont definiál, és ugyanúgy végrehajtható, mint egy ilyen típusú függvény, ha a megfelelő típusú paraméterekre alkalmazod:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Mivel nem túl kényelmes minden alkalommal kiírni a teljes closure expressiont, amikor végre akarod hajtani, a closure hozzárendelhető egy névhez, akárcsak a Swift bármely más értéke.
Ezután úgy hívhatod meg, hogy a nevet a paraméterekre alkalmazod:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Ahogy fentebb láttuk, a closure a hagyományos függvényekhez hasonlóan elhagyhatja a `return` kulcsszót, ha a törzse egyetlen kifejezésből áll.

Leggyakrabban a closure-t magasabb rendű függvényekkel együtt használjuk: vagy paraméterként adjuk át nekik, vagy visszatérési értékként kapjuk vissza:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
