# A feltételes elágazásokról

## Összehasonlító operátorok

Az [összehasonlító operátorok][operators] sok más nyelvhez hasonlítanak, néhány kiegészítéssel.

Az egyenlőséghez két operátor tartozik: a `==` (egyenlő) és a `!=` (nem egyenlő).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Ezen kívül a `===` és a `!==` operátor a [„referenciális egyenlőséget”][referential-equality] vizsgálja:
`a === b` akkor és csak akkor, ha `a` és `b` ugyanarra az objektumra mutat.
Ennek a tanterv későbbi részében majd több értelme lesz.

A nagyobb/kisebb operátorok szintén a megszokott módon működnek.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Elágazás `if`-fel

Ez az [`if` kifejezés][if-else] teljes alakja:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- A feltétel körüli zárójel (`()`) kötelező.
- A feltételnek `true` vagy `false` Boolean értékre kell kiértékelődnie.
  A Kotlin nem ismeri a „truthy” és „falsy” fogalmát, amelyeket néhány nyelvben megtalálsz.
- A kapcsos zárójel (`{}`) elhagyható, ha csak egyetlen kifejezés van benne.
- Az `else if` és az `else` is elhagyható, és több `else if` blokk is állhat egymás után.

Az `if` kifejezéssel értéket is „választhatsz”:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Alternatívák?

Szándékos döntés eredményeképp a Kotlin _nem_ tartalmazza a Java-ból ismert `? :` ternáris operátort.
Helyette az `if ... else` tömör alakját érdemes használni:

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

A Rubyval ellentétben a tömör `if ... else` alaknak *mindig* szüksége van egy `else` ágra, ezért nem használható guard utasításként:

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

Vedd észre, hogy a Kotlinban az `if` egy [_kifejezés_][expression], amely értéket ad vissza.
Nem [_utasítás_][statement], mint a Java-ban.

Egy későbbi fogalomban majd látni fogod, hogy a Kotlinban van egy hatékony [`when`][when] szerkezet, amely a hosszú `else if` láncokat hivatott felváltani mintaillesztéssel.
