# BEÁLLÍTÁS

Ez a kurzus két eszközt használ a tesztkészlet futtatásához és a legjobb gyakorlatok betartásához:

1. [vader.vim](https://github.com/junegunn/vader.vim)
2. [vint](https://github.com/Kuniwak/vint)

## Tesztek futtatása

1. Telepítsd a [vader.vim](https://github.com/junegunn/vader.vim/#installation)-et.
1. Nyisd meg a megoldásodat:
    ```
    $ vim exercise.vim
    ```
1. Olvasd be az aktuális fájlt, hogy annak globális függvényei elérhetők legyenek a Vim számára:
    ```
    :source %
    ```
1. Futtasd a teszteket:
    ```
    :Vader exercise.vader
    ```

Az elérési utak változhatnak.

Ha kényelmes gyorsparancsot szeretnél a fenti lépésekhez, tedd ezt a vimrc fájlodba:

```vim
function! s:exercism_tests()
  if expand('%:e') == 'vim'
    let testfile = printf('%s/%s.vader', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(testfile)
      echoerr 'File does not exist: '. testfile
      return
    endif
    source %
    execute 'Vader' testfile
  else
    let sourcefile = printf('%s/%s.vim', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(sourcefile)
      echoerr 'File does not exist: '. sourcefile
      return
    endif
    execute 'source' sourcefile
    Vader
  endif
endfunction

autocmd BufRead *.{vader,vim}
      \ command! -buffer Test call s:exercism_tests()
```

Ezután nyiss meg egy tetszőleges `.vim` vagy `.vader` fájlt egy feladat könyvtárából, és futtasd a `:Test` parancsot.

## Vim-fájlok lintelése

1. Telepítsd a [vint](https://github.com/Kuniwak/vint#quick-start)-et.
1. Linteld rekurzívan az összes Vim-fájlt:
    ```
    $ vint .
    ```

Ha részletesebb információra van szükséged a Vim script kurzusról, nézd meg a [súgóoldalt](https://exercism.org/languages/vimscript).
