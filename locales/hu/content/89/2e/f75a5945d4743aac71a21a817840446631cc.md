# Bemutatás

A C#-ban a tuple egy adatszerkezet, amely adatokat rendez, és két vagy több, bármilyen típusú mezőt tartalmaz.

A tuple-t általában úgy hozzuk létre, hogy két vagy több, vesszővel elválasztott kifejezést zárójelek közé írunk.

```csharp
string boast = "All you need to know";
bool success = !string.IsNullOrWhiteSpace(boast);
(bool, int, string) tripple = (success, 42, boast);
```

Mint bármely más kifejezés, a tuple többféleképpen is használható: [értékadásokban][tuple-assignment], mező vagy változó inicializálásához, metódus [visszatérési értékeként][tuple-return-values] vagy paraméterként átadva. [Egyenlőség][tuple-equality] szempontjából is vizsgálhatók. A tuple-ok egyenlőségét a `pattern-matching-tuples` feladat mutatja be részletesen, de a teljesség kedvéért az alábbi kódban is láthatsz rá példát.

A mezőket pontszintaxissal érhetjük el. Alapértelmezés szerint az első mező a `Item1`, a második a `Item2`, és így tovább. Az alapértelmezettől eltérő nevekről lentebb, az _Elnevezés_ szakaszban olvashatsz.

A tuple generikus paraméterként is használható, például: `IList<(bool, string)>`

Ezen kívül a tuple-ok támogatják a „dekonstrukciót”, amelyről lentebb lesz szó, és használhatók mintaillesztésben is, amelyről egy későbbi feladatban olvashatsz.

```csharp
// initialization
(int, int, int) vertices = (90, 45, 45);

// assignment
vertices = (60, 60, 60);

//  return value
(bool, int) GetSameOrBigger(int num1, int num2)
{
    return (num1 == num2, num1 > num2 ? num1 : num2);
}

// method argument
int Add((int, int) operands)
{
    return operands.Item1 + operands.Item2;
}

// equality testing
var estimateA = (42, 1729);
var estimateB = (2*3*7, 7*13*19);
bool result = estimateA == estimateB;
// => result == true
```

Ez a [bevezető][tuples] bemutatja, hogyan definiálhatók és használhatók a tuple-ok.

## Elnevezés

Az olyan mezőnevek, mint a `Item1`, nem teszik olvashatóvá a kódot. Háromféleképpen adhatunk nevet a mezőknek: a) a típusdeklarációban, b) a létrehozó kifejezésben, c) [tuple-vetítés kezdőértékeivel][tuple-projection-initializers] (ez utóbbit itt nem szemléltetjük).

```csharp
// name items in declaration
(bool success, string message) results = (true, "well done!");
bool mySuccess = results.success;
string myMessaage = results.message;

// name items in creating expression
var results2 = (success: true, message: "well done!");
bool mySuccess2 = results2.success;
string myMessaage2 = results2.message;
```

Ne próbálj túl okos lenni az elnevezési mechanizmussal. Ez valójában csak szintaktikai cukor. Például nem változtathatod meg egy tuple mezőneveit, amikor egy másik tuple-ból adsz neki értéket.

## Dekonstrukció

Néha kényelmes egy tuple mezőit több változónak értékül adni, és szükség esetén inicializálni őket. Ezt a mechanizmust [dekonstrukciónak][tuple-deconstruction] nevezzük. (A saját objektumaidra is alkalmazható. Lásd [itt][udt-deconstruction].)

```csharp
var goodNumbers = (42, 3.142, 1729);
(int ultimateQuestion, var π, var ramanujan) = goodNumbers;
return ultimateQuestion;
// => 42
```

## Mezők értékadása

A tuple-ok mezői egyenként is kaphatnak értéket. Mivel azonban a C# a megváltoztathatatlanság felé halad, ez a fajta használat nem terjedt el. A tuple-okat gyakran úgy használjuk, mintha megváltoztathatatlanok lennének, pedig természetesen nem azok.

```csharp
(int, string) tpl;
tpl.Item1 = 1;
tpl.Item2 = "bad";
tpl.Item2 = "even worse";
// => (1, "even worse";
```

## Háttér

A most tárgyalt tuple-okat nem szabad összekeverni a [`System.Tuple`][system-tuple] típussal, amely valószínűleg csak örökölt kódbázisokban fordul elő.

A helyzet kicsit zavarosabb, ha a `System.ValueTuple`-ról van szó. A [`System.ValueTuple`][system-value-tuple] utolsó túlterhelésének [dokumentációja][system-value-tuple] így fogalmaz: „Az értéktuple-típusok biztosítják azt a futtatókörnyezeti megvalósítást, amely a C#-ban támogatja a tuple-okat.” „Értéktuple-típusokon” itt a `System.ValueTuple` generikus túlterheléseit értik. „Tuple-okon” pedig azokat a dolgokat, amelyekkel ebben a feladatban foglalkoztunk. Lényegében azt mondják, hogy a `System.ValueTuple` a tuple-ok egyik megvalósítási részlete. Ez valószínűleg legtöbbször nem érdekli különösebben az embereket. Sajnos a „tuple-okról” szóló dokumentációk nagy része, köztük a Microsofté is, bőségesen tele van `System.ValueTuple`-ra tett hivatkozásokkal. Az ilyen hivatkozásokat valószínűleg nyugodtan át lehet síklani.

## Egyéb felhasználások és korlátok

A mintaillesztés különösen termékeny felhasználási módja a tuple-oknak. Ezzel egy későbbi feladatban foglalkozunk.

A tuple-ok néhány egyéb apró stilisztikai lehetőséget is kínálnak:

- Többszörös értékadás (különösen konstruktorokban), például `(this.field1, this.field2) = (arg1, arg2);`
- Értékek felcserélése vagy újrafelhasználása, például `(a, b) = (b, a);`
- Használat `struct` helyett egy listában
- Használat szótár kulcsaként vagy egy halmaz tartalmaként.
- Használat LINQ-ban. (A LINQ-val későbbi feladatokban foglalkozunk.)

A dokumentáció a tuple-okat könnyűsúlyú mechanizmusként írja le, és éppen ez a sikeres használatuk kulcsa. Ha egy tuple-t osztály vagy struct helyett használunk, az a mezőtípusok és esetleg a nevek unalmas ismétlődéséhez vezethet. Ez különösen akkor igaz, ha metódusargumentumként vagy gyűjtemények generikus argumentumaként használjuk.

Az olyan trükköket, mint a többszörös értékadás és az értékek felcserélése, érdemes megfontoltan használni.

Az egyenlőségen és a nem egyenlőségen kívül más relációs műveleteket nem támogatnak.

Vedd figyelembe, hogy a tuple-ok viszonylag nemrég kerültek be a nyelvbe (C# 7), ezért ha használni szeretnéd őket, győződj meg róla, hogy a kódbázisod a nyelv [7-es vagy újabb verzióját][language-version] használja.
