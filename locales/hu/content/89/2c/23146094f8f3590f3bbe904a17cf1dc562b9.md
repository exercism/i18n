# Kiegészítő utasítások

## A Tcl `apply` parancsa

A tesztesetek elsőre zavarosnak tűnhetnek.
Neked ezt kell megvalósítanod: 

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

Miért van annyi kapcsos zárójel abban az utolsó argumentumban?

Emlékezz rá, hogy a `proc` parancs definíciója így néz ki:

```tcl
proc procName argList body
```

A Tcl-nek van egy `apply` parancsa:

```tcl
apply func ?arg1 arg2 ...?
```

ez a „func” egy kételemű lista, `{argList body}`, ami lényegében egy névtelen proc (vagy „lambda”).
Az `apply` parancs meghívja azt a névtelen procot, és átadja neki a szükséges argumentumokat.

Például ezek egyenértékűek:

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

Az `apply` használatával egyszerűbb a kódblokkokat továbbadni.

Hivatkozás: [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm), [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm).
