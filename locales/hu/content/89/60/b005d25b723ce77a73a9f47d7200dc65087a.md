# Bevezetés

## Modulok

Az eddigi feladataid mind osztályokat használtak.
Néha azonban nincs szükség arra a többletterhel, amit egy állapottal rendelkező objektum létrehozása jelent, ezért inkább `module`-t használunk.

A modul nagyon hasonlít az osztályhoz (valójában az objektumhierarchiában a `Module` a `Class` szülője), a fő különbség pedig az, hogy példánymetódusok helyett osztálymetódusokat használunk.
Az osztálymetódusok `self.`-fel kezdődnek, és közvetlenül a modulon hívjuk meg őket.

Például:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## Ciklusok

Többféleképpen is írhatunk ciklust Rubyban, de mivel általában inkább felsorolást használunk, mintsem ciklusokat, a leggyakrabban látott ciklus talán a `while` ciklus:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

Használhatod a testvérét, az `until`-t is:

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
