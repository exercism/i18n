# Stringek

A stringek karakterek sorozatai, idézőjelek közé zárva.
Mind az egyszeres, mind a kettős idézőjel támogatott.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Változók behelyettesítése stringekbe

A kettős idézőjeles stringekben, ha olyan változóra hivatkozunk, amely a scope-ban van, az értéke bekerül a stringbe.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Karakterkódolás támogatása

Korábban a PHP stringfüggvényei csak az ASCII-karaktereket támogatták, a modern Unicode-kódolásokat nem.
Az ASCII-karakterek egyenként 1 byte hosszúak, a Unicode-karakterek viszont 1-4 byte hosszúak lehetnek.
Ha biztonságosan szeretnél Unicode-stringeket kezelni, nézd meg a korábbi függvények [többbájtos változatait][multi-byte-fns].

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
