# Bevezetés

Az, hogy egy tömb egyben _gyűjtemény_ is, azt jelenti, hogy az értékeit nemcsak index alapján érheted el, hanem egy `foreach` ciklussal _az összes_ értékén végig is iterálhatsz:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
