# Bevezetés

## Result

A `Result` típus az Elm nyelv megoldása a hibajelentésre, és egyben lehetővé teszi a hibák utáni helyreállítást is. Némileg hasonlít a `Maybe` típushoz, de míg a `Maybe`-t olyan függvények adhatják vissza, amelyek elbukhatnak, semmit sem árul el arról, hogy miért buktak el. A `Result` tartalmazza ezt a kontextust arról, hogy miért hibázott valami.

A `Result` típus definíciója a következő:

```elm
type Result error value
  = Ok value
  | Err error
```

Ezt az Elm terminológiában „custom type” definíciónak nevezik.
Az `error` és a `value` az `OK value`-ban és az `Error error`-ban egy típusváltozót jelöl, ami azt jelenti, hogy bármilyen típus lehet, például `Int`, `Bool` vagy `String`.
Ennek megfelelően a `Result String Int` egy olyan változó, amelynél egy `Int` szerepel, és ha hiba van, azt egy `String` képviseli.
Létezik egy [Result modul](https://package.elm-lang.org/packages/elm/core/latest/Result), amely rengeteg hasznos segédfüggvényt kínál a `Result` típushoz.
