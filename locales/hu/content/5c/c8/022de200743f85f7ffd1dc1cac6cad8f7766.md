# Utasítások

Ebben a feladatban egy egyszerű, egész számokkal dolgozó számológép hibakezelését építed meg.
Hogy egyszerűbb legyen a helyzet, az összeadást, a szorzást és az osztást végző metódusokat előre megkaptad.

A cél egy működő számológép, amely a következő formátumú Stringet adja vissza: `16 + 51 = 67`, ha a `16`, `51` és `+` argumentumokat kapja.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. Valósítsd meg a calculate metódust néhány alapvető művelet támogatásához

Ebben a részfeladatban a fő megvalósítandó metódus a `CalculatorConundrum.calculate()` lesz.
Három argumentumot vár.
Az első két argumentum, az `operand1` és az `operand2`, egész számok, amelyeken egy műveletet fogunk elvégezni.
A harmadik argumentum, az `operation`, String típusú, és ebben a feladatban a következő műveleteket kell megvalósítanod:

- összeadás a `+` String segítségével
- szorzás a `*` String segítségével
- osztás a `/` String segítségével

## 2. Kezeld a szabálytalan műveleteket

Frissítsd a `CalculatorConundrum.calculate()` metódust, hogy kezelje a szabálytalan műveleteket:

- Ha az `operation` argumentum `null`, akkor `IllegalArgumentException`-t kell dobni a `Operation cannot be null` üzenettel.
- Ha az `operation` argumentum `""`, akkor `IllegalArgumentException`-t kell dobni a `Operation cannot be empty` üzenettel.
- Ha az `operation` argumentum bármi más, mint a `+`, `*` vagy `/`, akkor `IllegalOperationException`-t kell dobni a `Operation '{operation}' does not exist` üzenettel.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. Kezeld a nullával való osztáskor dobott kivételt

Java-ban a nullával való osztás `ArithmeticException` kivételt dob.
Frissítsd a `CalculatorConundrum.calculate()` metódust, hogy elkapja ezt a kivételt, majd dobjon `IllegalOperationException`-t a `Division by zero is not allowed` üzenettel, kiváltó okként pedig adja meg az elkapott `ArithmeticException`-t.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
