# Utasítások

Ebben a feladatban egy távirányítású autóval fogsz játszani, amelyre végre összegyűjtöttél annyi pénzt, hogy megvedd.

Az autók tele (100%-os) akkumulátorral indulnak.
Valahányszor elvezeted az autót a távirányítóval, 20 métert tesz meg, és az akkumulátor egy százalékát meríti le.
Az autó beceneve a létrehozásáig nem ismert.

A távirányítású autónak van egy menő LED-kijelzője, amely két adatot mutat:

- A megtett teljes távolságot, amely így jelenik meg: `"<METERS> meters"`.
- Az akkumulátor hátralévő töltöttségét, amely így jelenik meg: `"Battery at <PERCENTAGE>%"`.

Ha az akkumulátor 0%-on van, nem tudod tovább vezetni az autót, és az akkumulátor-kijelző ezt mutatja: `"Battery empty"`.

## 1. Hozz létre egy vadonatúj távirányítású autót

Valósítsd meg a `new_remote_control_car/0` függvényt, amely egy vadonatúj távirányítású autó objektumot ad vissza:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Hozz létre egy vadonatúj távirányítású autót becenévvel

Valósítsd meg a `new_remote_control_car/1` függvényt, amely egy vadonatúj, megadott becenevű távirányítású autó objektumot ad vissza:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Jelenítsd meg a távolságot

Valósítsd meg a `display_distance/0` függvényt, amely bemenetként egy autó objektumot kap, és visszaadja a LED-kijelzőn megjelenő távolságot jelző szöveget:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Jelenítsd meg az akkumulátor töltöttségét

Valósítsd meg a `display_battery/0` függvényt, amely bemenetként egy autó objektumot kap, és visszaadja a LED-kijelzőn megjelenő akkumulátor-töltöttséget jelző szöveget:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Ha az akkumulátor 0%-on van, az akkumulátor-kijelző ezt mutatja: „Battery empty”.

## 5. A vezetés megváltoztatja az akkumulátor töltöttségét és a megtett távolságot

Valósítsd meg a `drive/0` függvényt, amely:

- bemenetként egy autó objektumot kap
- 20 méterrel növeli a megtett méterek számát
- az akkumulátor 1%-át meríti le
- a módosított autó objektumot adja vissza

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Vedd figyelembe a lemerült akkumulátorral való vezetést

Módosítsd a `drive/0` függvényt úgy, hogy ne növelje a megtett távolságot, és ne csökkentse az akkumulátor töltöttségét, amikor az akkumulátor lemerült (0%-on van):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
