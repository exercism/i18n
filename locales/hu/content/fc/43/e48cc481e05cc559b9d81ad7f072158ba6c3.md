# Bevezetés

A `guard` utasítás a Swiftben korai visszatérésre szolgál a Swift-függvényekből, ha egy olyan szükséges feltétel nem teljesül, amelynek teljesülnie kell a további feldolgozáshoz. Például:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Itt a `guard` ellenőrzi, hogy a `guard` kulcsszót követő Boolean-kifejezés igazra értékelődik-e. Ha igen, akkor a feldolgozás a `guard` utasítás utáni kóddal folytatódik (itt: `let root = myValue.squareRoot()`). Ellenkező esetben az else ág kódja fut le. Az `if` utasítással ellentétben a `guard` utasításnak _kell_ else ággal rendelkeznie, és az if-else szerkezet else ágával ellentétben a `guard` else ágának _el kell_ hagynia a `guard` utasítás scope-ját. Azaz olyan vezérlésátadó utasítást kell használnia, mint például a `return`, a `continue` vagy a `break`, illetve hibát kell dobnia, vagy ki kell lépnie a programból.
