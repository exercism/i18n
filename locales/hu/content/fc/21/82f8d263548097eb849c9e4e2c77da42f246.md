# Utasítások

Indítunk egy sajtklubot, amely ML segítségével választja ki az új sajtokat, hogy a sajtkedvelő ügyfeleinknek kínálhassa őket, az előzményeik és az ízlésük alapján.

Az új tagoknak ki kell tölteniük egy kezdeti kérdőívet, hogy legyen néhány alapadatunk, amivel elindulhatunk.
Ebből kiderült, hogy az ügyfeleknek van egy csoportja, a hangsúlyos ügyfeleké, akiknek a kritikáiból hiányzik minden árnyalat.
Mivel ez helyrehozhatatlanul eltorzíthat egy árnyaltabban működő algoritmust, külön algoritmust állítottunk fel az igényeik kiszolgálására.
A feladatod, hogy néhány segédfüggvényt készíts, amelyekkel kezelni tudod az adataikat.

~~~~exercism/note
Bár a következő részfeladatokat többféleképpen is meg lehet oldani, mindegyik megoldható legfeljebb két magasabb rendű függvénnyel.
~~~~

## 1. Ügyfelek osztályozása

Az értékelési rendszer alapja az öt csillag, ami egyszerűen az `1:5` egész számokból áll.
A hangsúlyos ügyfelek csak `1` vagy `5` értékelést adnak, és szeretnénk tudni, hogy egy ügyfél mutatja-e ezt a viselkedést.

Készítsd el az `all_15()` függvényt, amely egy értékeléseket tartalmazó vektort kap, és `true`-t ad vissza, ha minden értékelés `1` vagy `5`, egyébként pedig false értéket.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. Ügyfelek elnevezése

Az ügyfél nevét (vagy azonosítóját) össze kell kapcsolnunk az értékeléseivel.

Készítsd el a `name_customers()` függvényt, amely egy nevekből álló vektort és egy értékeléseket tartalmazó listát kap, és ezeket egy listákból álló listába fésüli össze.

A belső listák elemeinek a neve `name` és `rating` legyen.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. A hangsúlyos ügyfelek különválasztása

A hangsúlyosabb ügyfeleket külön kell választanunk a többiektől.

Készítsd el az `emphatics()` függvényt, amely ügyfeleket és értékeléseket kap.
Egy olyan listát ad vissza, amely csak azokra korlátozódik, akik kizárólag `1` vagy `5` csillagos értékelést adnak.`

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. Az értékelések átalakítása binárissá

Mivel a hangsúlyos ügyfelek csak `1` és `5` értékelést használnak, számítási szempontból kényelmesebb lesz, ha ezeket `0`-ra és `1`-re változtatjuk.

Készítsd el a `to_binary()` függvényt, amely a hangsúlyos értékelések vektorát kapja.
Bináris értékeléseket ad vissza: az `1` helyére `0`, az `5` helyére `1` kerül.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. Átlagos értékelések kiszámítása az idő múlásával

Szeretnéd az idő múlásával egyre jobb ajánlásokat adni minden egyes ügyfélnek (nem csak a hangsúlyosaknak), ahogy egyre jobban megérted az ízlésüket.

Készítsd el a `satisfactions()` függvényt, amely egy értékeléseket tartalmazó vektort kap.
Az eddigi halmozott átlagos értékelések vektorát adja vissza.
Az eredményeket kerekítsd két tizedesjegyre.

Reméljük, hogy a számok egyre csak nőnek, a boldog ügyfelek kedvéért!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
