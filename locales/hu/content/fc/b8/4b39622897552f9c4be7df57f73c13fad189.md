# Bevezetés

## Alapok

### Függvények

A Gleamben a függvényeket a `pub fn` szintaxissal definiálod.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Ez a függvény két argumentumot vesz át, mindkettő `Int` típusú, és `Int` típusú értéket ad vissza. A Gleamben nincs `return` kulcsszó, a függvény értéke mindig az utolsó kifejezés értéke, ami _implicit módon visszaadódik_.

Az argumentumok típusannotációja és a visszatérési típus megadása opcionális, és a Gleam mindig teljes körűen ellenőrzi a kódod típusait. A Gleam-programozók általában az egyértelműség kedvéért ellátják a függvényeiket típusannotációval, de nyugodtan el is hagyhatod őket.

```gleam
pub fn add(x, y) {
  x + y
}
```

Egy függvényt a `function_name(argument1, argument2)` szintaxissal hívhatsz meg.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### Változók

A Gleamben a változókat a `let name = expression` szintaxissal definiálod.

```gleam
pub fn main() {
  let count = 1
}
```

A változókat típusannotációval is deklarálhatod. A függvényargumentumokhoz hasonlóan ezek is opcionálisak, bár a legtöbb Gleam-programozó a rövidség kedvéért elhagyja a változók típusannotációját.

```gleam
pub fn main() {
  let count: Int = 1
}
```

### String literálok

A Gleamben a stringeket kettős idézőjelek közé írjuk.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### Kódmegjegyzések

A megjegyzésekkel jegyzeteket hagyhatsz más fejlesztőknek, akik a forráskódot olvassák. A Gleamben a megjegyzések egysorosak, és `//` előzi meg őket.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
