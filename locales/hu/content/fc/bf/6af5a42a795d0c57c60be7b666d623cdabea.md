# Char

A `Char` egy adattípus a Crystalben, amely egy 32 bites [Unicode][unicode] kódpontot reprezentál.
A méretük miatt memóriahatékonyak, és olyan tulajdonságokkal rendelkeznek, amelyekkel a stringek nem.
Egyes idézőjelekkel (`'`) hozod létre őket, és csak egyetlen Unicode-kódpont kerülhet bele.

```crystal
'a' # => 'a'
'a'.class # => Char
```

A Crystalben elég gyakori, hogy Char értékekkel dolgozol, amikor stringekkel foglalkozol, mivel a String osztály jó néhány metódusa Char értéket ad vissza, vagy Char értéket vár argumentumként.
Például a [`String#[]`][index] metódus egy Char értéket ad vissza, a [`String#chars`][chars] metódus pedig Char értékek gyűjteményét.

## Növelés / csökkentés

Mivel a Char egy 32 bites Unicode-kódpont, támogatja a növelést és a csökkentést, így ha van egy `'a'`, akkor egyet hozzáadva a `'b'` karaktert kapod.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Létezik egy [`Char#succ`][succ] nevű metódus is, amely a Unicode-táblázatban a következő karaktert adja vissza, valamint a [`Char#pred`][pred], amely az előző karaktert adja vissza.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Összefűzés

Mivel a Char csak egy 32 bites Unicode-kódpont reprezentálására szolgál, két Char értéket nem lehet összefűzni.
Ezért Char értékeket csak stringekkel lehet összefűzni.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Tulajdonságmetódusok

A Crystalben néhány metódus segít információt szerezni egy karakterről, például hogy szám vagy betű-e, illetve hogy kis- vagy nagybetű-e.
Íme néhány metódus listája, a teljes listát a [Char API][char-api] oldalon találod:

| Metódus                          | Leírás                                               |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | `true`-t ad vissza, ha a Char egy szám               |
| [`Char#letter?`][letter]         | `true`-t ad vissza, ha a Char egy betű               |
| [`Char#lowercase?`][lowercase]   | `true`-t ad vissza, ha a Char kisbetű                |
| [`Char#uppercase?`][uppercase]   | `true`-t ad vissza, ha a Char nagybetű               |
| [`Char#ascii?`][ascii]           | `true`-t ad vissza, ha a Char ASCII-karakter         |
| [`Char#whitespace?`][whitespace] | `true`-t ad vissza, ha a Char whitespace-karakter    |

## Konvertálás

### Konvertálás kódpontok és Char értékek között

Mivel a Char egy 32 bites Unicode-kódpont, át tudsz konvertálni Char és kódpont (Int) között.
Erre a [`Char#ord`][ord] metódust használhatod, amely a Char kódpontját adja vissza, vagy az [`Int#chr`][chr] metódust, amely a kódponthoz tartozó Char értéket adja vissza.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Konvertálás típusok között

Ahogy a többi adattípusnál, a Char értékeknél is van néhány metódus a típusok közötti konvertálásra.
A leggyakoribb a `Char#to_s` metódus, amely a Char értéket stringgé alakítja. Emellett ott van a `Char#to_i` metódus, amely a Char értéket Int értékké alakítja, és a `Char#to_f` metódus, amely Float értékké.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
