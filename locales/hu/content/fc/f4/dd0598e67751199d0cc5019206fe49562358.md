# Bevezetés

A Swiftben a closure-ök önálló kódrészek: paramétereket adhatsz át nekik, amivel elindítod a számításukat, és értéket adnak vissza. A closure-ök emellett értékeket rögzítenek a környezetükből, és fel is használják őket a számításaikban. Mivel önállóak, a programban úgy adhatók tovább, mint bármely más érték, illetve hozzárendelhetők konstansokhoz és változókhoz.

A closure-ök első hallásra nagyon hasonlíthatnak a Swift függvényeihez, és ez így is van, méghozzá nem véletlenül. A Swiftben a függvények csupán a closure-ök speciális esetei: nevük kell hogy legyen, és kicsit más szintaxissal definiáljuk őket.

Bár a Swift függvényei technikailag closure-ök, amikor az emberek „closure”-ökről beszélnek a Swiftben, általában closure-kifejezésekre gondolnak. A closure-kifejezés egy paraméterlistából, egy visszatérési típusból, majd az `in` kulcsszóból és a closure törzséből áll, az egész pedig egy pár kapcsos zárójelben van:

```swift
{ (a: Double, b: Double) -> Double in
  return a + b / 2.0
}
```

Ez egy `(Double, Double) -> Double` típusú closure-kifejezést definiál, és ugyanúgy végrehajtható, mint egy ilyen típusú függvény, mégpedig úgy, hogy megfelelő típusú paraméterekre alkalmazzuk:

```swift
{ (a: Double, b: Double) -> Double in
  return a + b / 2.0
}(10.0, 15.0)
// => 12.5
```

Ahogy fentebb látható, a closure-ök a hagyományos függvényekhez hasonlóan elhagyhatják a `return` kulcsszót, ha a closure törzse egyetlen kifejezés.
