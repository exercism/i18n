# Utasítások

A Mecha Munch™, egy élelmiszerbevásárlást automatizáló cég, épp most vett fel, hogy a rendelési alkalmazásukon dolgozz.
A csapatod feladata, hogy elkészítsen egy MVP-t (_[minimálisan működőképes termék][mvp]_), amely a bevásárlókosár minden alapvető műveletét kezeli, így a felhasználók hozzáadhatják, eltávolíthatják és rendezhetik a bevásárlásaikat.
Szerencsére a pénzzel és a fizetéssel kapcsolatos funkciókat egy másik csapat kezeli!

## 1. Tételek hozzáadása a felhasználó bevásárlókosarához

Az MVP tegye lehetővé, hogy a felhasználó tételeket adjon a bevásárlókosarához.
Ez lehet egyetlen tétel vagy egyszerre több tétel is.
Mivel ez egy MVP, a tétel mennyiségét az _ismétlődések_ jelzik.
Ha a felhasználó 2 Oranges-t szeretne hozzáadni, az 'Oranges' kétszer fog szerepelni a bemeneti iterálhatóban.
Ha a felhasználó kosarában már szerepel a tétel, a kosárban lévő mennyiséget 1-gyel kell növelni.
Ha a tétel _új_ a kosárban, akkor 1-es mennyiséggel kell hozzáadni.

Hozd létre az `add_item(<current_cart>, <items_to_add>)` függvényt, amely argumentumként egy kosárszótárat és bármilyen lista jellegű, hozzáadandó tételekből álló iterálhatót fogad.
A függvény adjon vissza egy új/frissített bevásárlókosár-szótárat a felhasználónak.

```python
>>> add_item({'Banana': 3, 'Apple': 2, 'Orange': 1},
              ('Apple', 'Apple', 'Orange', 'Apple', 'Banana'))
{'Banana': 4, 'Apple': 5, 'Orange': 2}

>>> add_item({'Banana': 3, 'Apple': 2, 'Orange': 1},
              ['Banana', 'Orange', 'Blueberries', 'Banana'])
{'Banana': 5, 'Apple': 2, 'Orange': 2, 'Blueberries': 1}
```

## 2. A felhasználó jegyzetalkalmazásában felsorolt tételek beolvasása

Hoppá.
Úgy tűnik, a termékcsapat [funkciótúltengésbe][feature creep] kezdett.
Extra funkciókat szeretnének hozzáadni az MVP-hez.
Az alkalmazásnak mostantól úgy kell bevásárlókosarat létrehoznia, hogy beolvassa a tételeket a felhasználó jegyzetalkalmazásából.
Kényelmes a felhasználóknak, de kicsit több munka a csapatnak.

Hozd létre a `read_notes(<notes>)` függvényt, amely argumentumként bármilyen lista jellegű iterálhatót elfogad.
A függvény dolgozza fel a tételeket, és hozzon létre egy felhasználói bevásárlókosarat/szótárat.
Minden tételt 1-es mennyiséggel kell hozzáadni.
Ezután az új felhasználói kosarat kell visszaadni.

```python
>>> read_notes(('Banana','Apple', 'Orange'))
{'Banana': 1, 'Apple': 1, 'Orange': 1}

>>> read_notes(['Blueberries', 'Pear', 'Orange', 'Banana', 'Apple'])
{'Blueberries' : 1, 'Pear' : 1, 'Orange' : 1, 'Banana' : 1, 'Apple' : 1}
```

## 3. A receptek „ötletek” szakaszának frissítése

Az alkalmazásnak van egy „ötletek” szakasza, amely különféle konyhákból származó elkészült receptekkel van tele.
A felhasználó kiválaszthatja ezek közül bármelyiket, és annak minden hozzávalója automatikusan a bevásárlókosarába kerül.
A projektmenedzser megkért, hogy hozz létre egy módot ezeknek az „ötletek” recepteknek a szerkesztésére, mivel a tartalomcsapat folyamatosan változtatja a hozzávalókat és a mennyiségeket.

Hozd létre az `update_recipes(<ideas>, <recipe_updates>)` függvényt, amely argumentumként egy „ötletek” szótárat és egy receptfrissítésekből álló iterálhatót fogad.
A függvény adja vissza az új/frissített „ötletek” szótárat.

```python
>>>update_recipes(
    {'Banana Bread' : {'Banana': 1, 'Apple': 1, 'Walnuts': 1, 'Flour': 1, 'Eggs': 2, 'Butter': 1},

    )
...

{'Banana Bread': {'Banana': 4, 'Walnuts': 2, 'Flour': 1, 'Butter': 1, 'Milk': 2, 'Eggs': 3}, 
 'Raspberry Pie': {'Raspberry': 1, 'Orange': 1, 'Pie Crust': 1, 'Cream Custard': 1}}

>>> update_recipes(
    {'Banana Bread' : {'Banana': 1, 'Apple': 1, 'Walnuts': 1, 'Flour': 1, 'Eggs': 2, 'Butter': 1},
    'Raspberry Pie' : {'Raspberry': 1, 'Orange': 1, 'Pie Crust': 1, 'Cream Custard': 1},
```

## 4. A felhasználói kosár tételeinek rendezése

Miután a felhasználó elkezdett egy kosarat, az alkalmazás lehetővé teszi számára, hogy ábécésorrendbe rendezze a tételeit.
Ez megkönnyíti a dolgok megtalálását, és segít az olyan adatbeviteli hibák esetén, mint amikor 'potatoes' és 'Potato' is szerepel az adatbázisban.

Hozd létre a `sort_entries(<cart>)` függvényt, amely argumentumként egy bevásárlókosarat/szótárat fogad, és visszaad egy új, ábécésorrendbe rendezettet.

```python
>>> sort_entries({'Banana': 3, 'Apple': 2, 'Orange': 1})
{'Apple': 2, 'Banana':3, 'Orange': 1}
```

## 5. A felhasználói bevásárlókosár elküldése a boltba teljesítésre

Az alkalmazásnak el kell küldenie egy adott felhasználó kosarát a boltba teljesítésre.
A bolt dolgozóinak azonban tudniuk kell, hogy a tétel melyik folyosón található, és hogy szükséges-e hűtés.
Tehát (_meglehetősen önkényesen_) a „teljesítési kosarat” fordított ábécésorrendbe kell rendezni, a tételmennyiségeket pedig a helyszínre és a hűtésre vonatkozó információval együtt kell megadni.

Hozd létre a `send_to_store(<cart>, <aisle_mapping>)` függvényt, amely egy felhasználói bevásárlókosarat és egy szótárat fogad, amely minden tételhez tartalmazza a bolti folyosó számát és egy `True`/`False` értéket arról, hogy szükséges-e hűtés.
A függvény `return`-nel adjon vissza egy összevont „teljesítési kosarat”, amely minden egyes megrendelt tételhez tartalmazza a mennyiséget, a folyosót és a hűtést.
A tételek _fordított_ ábécésorrendben jelenjenek meg.

```python
>>> send_to_store({'Banana': 3, 'Apple': 2, 'Orange': 1, 'Milk': 2},
                  {'Banana': ['Aisle 5', False], 'Apple': ['Aisle 4', False], 'Orange': ['Aisle 4', False], 'Milk': ['Aisle 2', True]})
{'Orange': [1, 'Aisle 4', False], 'Milk': [2, 'Aisle 2', True], 'Banana': [3, 'Aisle 5', False], 'Apple': [2, 'Aisle 4', False]}
```

## 6. A bolti készlet frissítése, hogy tükrözze a felhasználó rendelését

Az alkalmazás nem adhat le vég nélkül vásárlói rendeléseket.
Előbb-utóbb a boltból elfogynak a különféle termékek.
Ezért az MVP-alkalmazásodnak frissítenie kell a bolti készletet minden alkalommal, amikor egy felhasználó elküldi a rendelését a boltba.
Különben a vásárlók olyan termékeket rendelnek, amelyek valójában nem elérhetők.

Hozd létre az `update_store_inventory(<fulfillment_cart>, <store_inventory>)` függvényt, amely egy „teljesítési kosarat” és egy bolti készletet fogad.
A függvény csökkentse a bolti készlet mennyiségeit a „teljesítési kosárban” szereplő „megrendelt” számmal, majd adja vissza a frissített bolti készletet.
Ahol egy bolti tétel darabszáma 0-ra csökken, ott a darabszámot a 'Out of Stock' üzenettel kell helyettesíteni.

```python
>>> update_store_inventory({'Orange': [1, 'Aisle 4', False], 'Milk': [2, 'Aisle 2', True], 'Banana': [3, 'Aisle 5', False], 'Apple': [2, 'Aisle 4', False]},
{'Banana': [15, 'Aisle 5', False], 'Apple': [12, 'Aisle 4', False], 'Orange': [1, 'Aisle 4', False], 'Milk': [4, 'Aisle 2', True]})

{'Banana': [12, 'Aisle 5', False], 'Apple': [10, 'Aisle 4', False], 'Orange': ['Out of Stock', 'Aisle 4', False], 'Milk': [2, 'Aisle 2', True]}
```
