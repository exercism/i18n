# Tömbök

A Cairoban a tömb egy olyan adatszerkezet, amellyel azonos típusú elemek gyűjteményét tárolhatod.
A Cairoban a tömbök módosítási lehetőségei korlátozottak.
Elemeket csak a tömb végéhez fűzhetsz hozzá, és csak az elejéről távolíthatsz el.
A tömbök valójában olyan sorok, amelyeknek az értékei nem módosíthatók.

## Tömb létrehozása

A tömböket elsősorban az `ArrayTrait` trait használatával hozod létre, és az alábbi 4 mód bármelyikével összeállíthatsz egy `[1, 2]` elemekből álló tömböt:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> Minden `append()` hívás egy új számot tesz a tömb végére.

## Elemek eltávolítása a tömbből

Cairoban egy tömb elemeit csak az elejéről távolíthatod el.
Ezt a műveletet a `pop_front()` metódus végzi, amely egy kibontható `Option`-t ad vissza: ez tartalmazza az eltávolított elemet, vagy `Option::None`-t, ha a tömb üres.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## Értékek elérése a tömbben

A tömbelemek eléréséhez a `get()` vagy az `at()` tömbmetódust használhatod, amelyek különböző típusokat adnak vissza.
Az `arr.at(index)` megfelelője az `arr[index]` indexelő operátor.

### A get() metódus használata

A `get()` metódus olyan, mint amikor egy listában a sorszám alapján keresel ki egy elemet.
Így működik:

- Az `arr.get(index)` segítségével egy adott pozíción (indexen) lévő elemet kérhetsz le a tömbből.
- `Option::Some(value)` értéket ad vissza, ha a megadott indexen létezik elem, vagy `Option::None`-t, ha az index kívül esik a tartományon.

Ez a metódus ideális, ha olyan eseteket szeretnél kezelni, amikor az index érvénytelen lehet, anélkül hogy a programod összeomlana.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### Az at() metódus használata

Az `at()` metódus közvetlenül egy pillanatképet ad a megadott indexen lévő elemről, az `unbox()` művelettel kinyerve a dobozban tárolt értéket.
Ennek a metódusnak egy rövidített formája az `arr[index]` indexelő operátor használata.
Ha olyan indexet próbálsz elérni, amely nem létezik (kívül esik a tartományon), a program pánikol és hibát dob.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## Mérettel kapcsolatos metódusok

A tömbben lévő elemek számának meghatározásához a `len()` metódust használd.
A visszatérési érték `usize` típusú.

Ha ellenőrizni szeretnéd, hogy egy tömb üres-e, használhatod az `is_empty()` metódust, amely `true`-t ad vissza, ha a tömb üres, egyébként pedig `false`-t.

## `Span`

A `Span` egy struktúra, amely egy `Array` pillanatképét reprezentálja.
Arra tervezték, hogy biztonságos és szabályozott hozzáférést biztosítson a tömb elemeihez anélkül, hogy módosítaná az eredeti tömböt.
A `Span` különösen hasznos az adatintegritás megőrzéséhez és a kölcsönzési problémák elkerüléséhez, amikor tömböket adsz át függvények között, vagy csak olvasási műveleteket végzel.

> Az `Array` összes metódusa használható `Span`-nal is, kivéve az `append()` metódust.

Egy `Array` `Span`-jának létrehozásához hívd meg a `span()` metódust:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## A rögzített méretű `Array` típus

A rögzített méretű tömb értékeit vesszővel elválasztott listaként írjuk a szögletes zárójelek közé.
A tömb típusát szögletes zárójelekkel írjuk le: az egyes elemek típusa, majd egy pontosvessző, végül a tömbben lévő elemek száma.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> Megjegyzés: konstansként csak rögzített méretű tömb használható

A rögzített méretű tömb elemeit vagy a tömb szétbontásával érheted el, vagy úgy, hogy `Span`-ná alakítod, amely támogatja az indexelést.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
