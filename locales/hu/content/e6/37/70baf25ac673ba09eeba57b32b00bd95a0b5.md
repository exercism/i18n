# Bevezetés

Amikor egy quotationnek *emlékeznie* kell a környezetéből származó értékekre, a Factor két eszközt kínál: a `curry`/`compose` szavakat a [`kernel`][kernel] szótárból, és a `'[ … ]` fry szintaxist a [`fry`][fry] szótárból.

A `curry` beéget egy értéket a quotation elejére:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

A `compose` két quotationt ragaszt össze:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Ha egynél-kettőnél több értéket kell rögzíteni, a fry tisztább. Minden `_` helyőrzőbe sorban egy-egy, a veremről leemelt érték kerül:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

A fry az egymásba ágyazott quotationökbe is belenyúlik.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
