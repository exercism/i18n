# Bevezetés

A C#-ban a listák primitív értékek, illetve struktúrák vagy osztályok példányainak gyűjteményei. Az alaposztály-könyvtárban `List<T>` formában valósulnak meg, ahol `T` a listában lévő elem típusa. Az API gazdag metóduskészletet kínál a listák létrehozásához és kezeléséhez.

A listákhoz hozzáadhatsz elemeket, és el is távolíthatsz belőlük. Szükség szerint nőnek és zsugorodnak.

```csharp
var listOfStrings = new List<string>();
```
