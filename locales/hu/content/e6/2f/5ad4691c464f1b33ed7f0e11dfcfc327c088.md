# Bevezetés

## Listák

Az Elmben a [`List`][lists] nulla vagy több azonos típusú értékből álló, megváltoztathatatlan gyűjtemény.

A listákat így definiálhatod:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

A leggyakoribb módja annak, hogy elemet adj egy listához, a `::` (cons) operátor:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

A listákat a [`List` modulban][list-module] definiált függvényekkel és operátorokkal, illetve [mintaillesztéssel][list-destructuring] kezelheted

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```

[list-module]: https://package.elm-lang.org/packages/elm/core/latest/List
