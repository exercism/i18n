# Bevezetés

A [tartományok][range] két érték közötti intervallumot jelölnek.
A tartományokat jellemzően olyan típusokkal együtt használjuk, mint az `Int`, `String` és `Character`, hogy sorozatokon iteráljunk, gyűjteményeket szeleteljünk, vagy ellenőrizzük, hogy egy érték a határokon belülre esik-e.

A Swiftben két fő tartományoperátor van:

- **Zárt tartományoperátor (`...`)**: A kezdő- és a végértéket is tartalmazza (`1...5` az 1, 2, 3, 4 és 5 értékeket tartalmazza).
- **Félig nyílt tartományoperátor (`..<`)**: A kezdőértéket tartalmazza, a végértéket nem (`1..<5` az 1, 2, 3 és 4 értékeket tartalmazza).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Ha közvetlenül egy tartományliterálon szeretnél metódust meghívni, tedd a tartománykifejezést zárójelbe, hogy a fordító először a tartományt értékelje ki:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Tartomány átalakítása tömbbé

Egy számtartományt az `Array(_:)` kezdőértékével alakíthatsz `Array` típusú tömbbé:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Tömb szeletelése tartományokkal

Tartományokkal egy tömb részleteit szeletelheted:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Tartomány tulajdonságai és metódusai

A tartományok gyakori műveletei:

| Tag                     | Leírás                                                     | Példa                                |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Visszaadja a tartomány elemeinek számát                    | `(1...5).count` a `5` értéket adja vissza |
| [`contains(_:)`][contains] | Visszaadja a `true` értéket, ha a tartomány tartalmazza a megadott értéket | `(1...5).contains(3)` a `true` értéket adja vissza |

## Egyoldalú tartományok

A Swift az egyoldalú (részleges) tartományokat is támogatja, amelyeknél vagy a kezdő-, vagy a végértéket hagyod el:

- `array[2...]`: A 2-es indextől a gyűjtemény végéig.
- `array[...2]`: A gyűjtemény elejétől a 2-es indexig, azt is beleértve.
- `array[..<2]`: A gyűjtemény elejétől a 2-es indexig, de azt már nem beleértve.

## String- és karaktertartományok

Tartományokat olyan karakterek vagy stringek között is létrehozhatsz, amelyek megfelelnek a `Comparable` protokollnak:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
