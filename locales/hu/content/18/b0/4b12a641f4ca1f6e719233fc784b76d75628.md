# Utasítások

Egy online divatbutikban dolgozol.
Beugrik egy ötleted egy weboldalfunkcióra, ahol a felhasználónak szetteket ajánlunk.
A lehetséges szettek, azok árai és az össze nem illő lehetőségek kiszűrése mind érdekesek.

## 1. Hozz létre egy ruhadarabot


Valósítsd meg a `clothingitem()` függvényt, amely két `Tuple`-t kap: az egyik a `categories`, a másik a hozzájuk tartozó `qualities`.
A függvény egy `Dict`-et adjon vissza, amelyben a kulcsok a `categories`, az értékek pedig a `qualities`.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

A függvényednek tetszőleges számú `categories` bejegyzést kezelnie kell.

## 2. Ajánlj kombinációkat

Valósítsd meg a `get_combinations()` függvényt, amely egy felsőkből álló `Tuple`-t és egy alsókból álló `Tuple`-t kap.
A függvény a tuple-ök `cartesian product`-ját adja vissza kétdimenziós tömbként (azaz `Matrix`-ként).
Minden elem egy `(top, bottom)` kombináció, `Tuple`-ként.
A felsők a sorok mentén változnak, az alsók az oszlopok mentén.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. Add össze a szettek árait

Minden ruhadarabhoz tartozik egy `price` mező, így hasznos lehet, ha össze tudjuk hasonlítani a szettek teljes árát.
Valósítsd meg a `get_prices()` függvényt, amely ruhakombinációk tömbjét kapja.
A függvény egy ugyanolyan alakú tömböt adjon vissza, amelyben a szettek árai a megfelelő helyükön szerepelnek.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. Szűrd ki az össze nem illő szetteket

Minden ruhadarabnak van egy `base_color` mezője.
Ezzel a mezővel távolítsd el az összes olyan kombinációt, ahol a felső és az alsó alapszíne megegyezik.
Valósítsd meg a `filter_clashing()` függvényt, amely ruhakombinációk tömbjét kapja.
Add vissza a megfelelő kombinációk egydimenziós tömbjét (azaz `Vector`-t).

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
