# Bevezetés

Az interfész egy olyan típus, amelynek tagjai egy összetartozó funkciócsoportot határoznak meg. Elválasztja az osztály használatát a megvalósítástól, így lehetővé tesz több különböző megvalósítást, vagy valamilyen általános viselkedés, például a formázás, az összehasonlítás vagy a konvertálás támogatását.

Az interfész szintaxisa hasonló az osztály vagy a struktúra szintaxisához, azzal a különbséggel, hogy a metódusok és tulajdonságok csak szignatúraként jelennek meg, és nem adunk meg hozzájuk törzset.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Az interfész által definiált összes műveletet implementálni kell.

Az interfészek más tagok mellett példánymetódusokat és tulajdonságokat is tartalmazhatnak.
