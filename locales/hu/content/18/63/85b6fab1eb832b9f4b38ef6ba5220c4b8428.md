# Bool

A Swiftnek van egy [`Bool`][bools] nevű típusa, amely a `true` és `false` értékek reprezentálására szolgál.

## Logikai operátorok

A Swiftben 3 [logikai operátor (`!`, `||`, `&&`)][logical-operators] van, amelyekkel Bool értékeket lehet kombinálni, és különböző értékű kifejezéseket alkotni.

### És (`&&`)

A Swiftben az [_és_ operátort][and] a `&&` jelöli, és `true`-t ad vissza, ha mindkét megadott érték `true`, egyébként `false`-t ad vissza.
Az _és_ operátor használatakor az egyik Bool a `&&` jobb oldalára, a másik a bal oldalára kerül.

```Swift
true && true  // true
true && false // false
```

### Vagy (`||`)

A Swiftben a [_vagy_ operátort][or] a `||` jelöli, és `true`-t ad vissza, ha a megadott értékek közül **legalább az egyik** `true`; ha viszont mindkét érték `false`, akkor `false`-t ad vissza.
A _vagy_ operátor használatakor az egyik Bool a `||` jobb oldalára, a másik a bal oldalára kerül.

```swift
true || true   // true
true || false  // true
false || false // false
```

### Nem (`!`)

A Swiftben a [_nem_ operátort][not] a `!` jelöli, és `true`-t ad vissza, ha a megadott Bool `false`, és `false`-t, ha `true`.
A _nem_ operátor használatakor a Bool értéket az operátor (`!`) után kell elhelyezni.

```swift
!true  // false
!false // true
```

## A zárójelek használata (`()`)

Amikor Bool értékekkel dolgozol, [explicit zárójelekkel][explicit-parentheses] eldöntheted, hogy mely Bool értékeket értékelje ki először.
Az eredmény attól függően változhat, hogyan használod a zárójeleket.
A Swiftben először a zárójelben lévő rész értékelődik ki.

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Mivel először a zárójelben lévő rész értékelődik ki, a következő példában a _nem_ operátor a zárójelben lévő kifejezésre fog vonatkozni.

```Swift
!true && false   // false
!(true && false) // true
```

~~~~exercism/note
Csak akkor használj zárójelet, ha az befolyásolja az eredményt, egyébként hagyd el őket.
~~~~
