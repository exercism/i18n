# Helyi hibakeresés

Amikor a Bash-kurzus tesztjeit a [Bats](https://github.com/bats-core/bats-core) segítségével futtatod, a Bats a kimenetre vonatkozó állításokhoz az STDOUT-ot és az STDERR-t is rögzíti.

```exercism/caution
Ez helyben működik a `bats`-szel, de **nem** az Exercism online szerkesztőjében.
```

Ha a hibakeresési kimenetet anélkül szeretnéd kiírni, hogy az hatással lenne a teszt eredményére, írd a 3-as fájlleíróra (fd).

```bash
echo 'debug message' >&3
```

A Bats megjeleníti a tesztfutás közben a 3-as fájlleíróra írt kimenetet, de nem építi be az olyan állításokba, mint az `assert_output`.

Példa egy futtatásra:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

Ez akkor hasznos, ha helyben futtatod a teszteket.
