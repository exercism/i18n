# Bővebben

A [variadikus paraméterek][variadic-parameters] segítségével egy függvény egyetlen paraméterhez nulla vagy több megadott típusú értéket fogadhat el.
Variadikus paramétert úgy definiálsz, hogy a paraméter típusjelölése után három pontot (`...`) írsz.

A függvény törzsén belül a Swift ezeket az értékeket a megadott típusú tömbként teszi elérhetővé:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Ha egy függvényben a variadikus paraméter után további paraméterek is szerepelnek, akkor a variadikus paramétert követő első paraméternél **kötelező** explicit argumentumcímkét megadni, hogy a Swift tudja, hol ér véget a variadikus argumentumlista.
~~~~
