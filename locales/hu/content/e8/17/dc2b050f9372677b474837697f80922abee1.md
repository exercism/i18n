# Kiegészítés az utasításokhoz

## Megvalósítás

Ha a lista utolsó eleme `object` és nem `string`, akkor egy minősítőt tartalmaz, amely módosítja a közmondás utolsó sorát.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
