# Bevezetés

Néha egy állapotot több szó között kell megosztani anélkül, hogy minden alkalommal átfűznéd a veremhatásaikon. A Factor *dinamikus változói*, amelyeket a `SYMBOL:` segítségével deklarálunk, minden szó számára hozzáférést adnak egy névtérben tárolt értékhez.

## `SYMBOL:` és `SYMBOLS:`

A `SYMBOL: name` egyetlen változót deklarál. A `SYMBOLS: a b c ;` egyszerre többet:

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## Beállítás és lekérés

A `set-global` és a `get-global` (a [`namespaces`][namespaces] szótárban) a globális névtéren működik:

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

Modulszintű állapothoz a `-global` változatokra van szükséged.

## Scope-hoz kötött kötések a `with-variable` segítségével

Egy dinamikus változó egy második, *scope-hoz kötött* változatot is támogat. A `set` / `get` / `change` (a `-global` utótag nélkül) az *aktuális* dinamikus scope-ot olvassa és írja, a `with-variable` pedig (a [`namespaces`][namespaces] szótárban) friss scope-ot hoz létre, amely egy quotation futásáig tart:

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

A változó a `value` értékhez van kötve, amíg a `quot` fut; amint visszatér, a kötés eltűnik. Így egy külső hívó „be tud injektálni” egy értéket, amelyet a belső kód el tud olvasni anélkül, hogy minden veremszignatúrán át kellene fűzni.

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

Ez a feladat végig a globális változatot használja, de a párhuzamos `set`/`get`/`change` család felismerése hasznos, amikor mások kódját olvasod.

## Módosítható vektorok

Mivel a dinamikus változók referenciát tárolnak, egy *módosítható* gyűjteményt is tarthatsz bennük, és a helyén frissítheted:

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

A `V{ … }` egy vektorliterál. A `V{ }` literált mindig `clone`-ozd, mielőtt eltárolod: a literálok megosztottak a hívások között.

## `find`: az első egyezés

A `find` (a [`sequences`][sequences] szótárban) visszaadja az első olyan elemet, amelyre egy predikátum igazat ad, valamint annak indexét:

```
find ( seq quot -- index elt/f )
```

Ha semmi sem egyezik, mindkét érték `f`. Az index eldobása a `nip`-pel, majd az `unless*` használata a szokásos „alapérték, ha hiányzik” kombináció.

## `reject`: a találatok elvetése

A `reject` (szintén a [`sequences`][sequences] szótárban) a `filter` ellentéte: azokat az elemeket adja vissza, amelyekre a predikátum *nem* igaz.
