# Utasítások

Ebben a feladatban néhány függvényt kell megvalósítanod, amelyek egy programozási nyelvekből álló listát kezelnek.

## 1. Definiálj egy függvényt, amely egy üres nyelvlistát ad vissza

Definiáld a `new/0` függvényt, amely nem vár argumentumot, és egy üres listát ad vissza.

```elixir
LanguageList.new()
# => []
```

## 2. Definiálj egy függvényt, amely hozzáad egy nyelvet a listához

Definiáld az `add/2` függvényt, amely 2 argumentumot vár: egy _nyelvlistát_ és egy _nyelv_ string literálját. A kapott listát úgy kell visszaadnia, hogy az új nyelv a megadott lista elejére kerül.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Definiálj egy függvényt, amely eltávolít egy nyelvet a listából

Definiáld a `remove/1` függvényt, amely 1 argumentumot vár (egy _nyelvlistát_). A listát az első elem nélkül kell visszaadnia. Feltételezd, hogy a listában mindig van legalább egy elem.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Definiálj egy függvényt, amely a lista első elemét adja vissza

Definiáld a `first/1` függvényt, amely 1 argumentumot vár (egy _nyelvlistát_). A listában szereplő első nyelvet kell visszaadnia. Feltételezd, hogy a listában mindig van legalább egy elem.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Definiálj egy függvényt, amely visszaadja, hány nyelv van a listában

Definiáld a `count/1` függvényt, amely 1 argumentumot vár (egy _nyelvlistát_). A listában lévő nyelvek számát kell visszaadnia.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Definiálj egy függvényt, amely megállapítja, hogy a lista tartalmaz-e funkcionális nyelvet

Definiáld a `functional_list?/1` függvényt, amely 1 argumentumot vár (egy _nyelvlistát_). Boolean értéket kell visszaadnia. Igazat kell visszaadnia, ha a _„Elixir”_ a lista egyik nyelve.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
