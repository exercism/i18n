# Maradék

A matematikában a **maradék** az a mennyiség, amely valamilyen számítás elvégzése után „megmarad”.
Például az `5 / 3` maradéka `2`.

Sok programozási nyelv a százalékjelet (`%`) használja operátorként a maradék kiszámítására.
Például:
```javascript
5 % 3 == 2
```

A maradékot gyakran ki lehet számítani egész számokon és lebegőpontos számokon is.
Például,
```javascript
5.3 % 3 == 2.3
```

Ha negatív számokkal dolgozol, az eredmény előjele mindig megegyezik az osztandóéval (a bal oldali számmal, amelyet osztunk).
Például:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Egyes nyelvek (például a Python) a `%` operátort a modulo kiszámítására használják, nem a maradékéra.
Ez másképp kezeli a negatív számokat.
Erről többet megtudhatsz [a Wikipédián](https://en.wikipedia.org/wiki/Modulo).
