# Névjegy

A Rustban a Boolean értékeket a `bool` típus képviseli, amelynek értéke `true` vagy `false` lehet.

A Rust egy [Boolean tagadási operátort][negation operators] támogat: `!` (Not).

A Rust hat [összehasonlító operátort][comparison operators] támogat: `==` (Equal), `!=` (Not equal), `>` (Greater than), `<` (Less than), `>=`
(Greater than or equal to), `<=` (Less than or equal to). Segítségükkel nem Boolean értékek viszonyát lehet Boolean értékké kiértékelni.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Más nyelvekkel ellentétben a `0` nem `false`, és a nem nulla érték sem `true`.

A Rust három [logikai bináris operátort][logical binary operators] támogat: `&` (Logical And), `|` (Logical Or), `^` (Logical Xor).

A Rust két [Boolean operátort][lazy boolean operators] támogat: `||` (Or), `&&` (And). Abban térnek el a `|` és `&` operátortól, hogy a jobb oldali operandus
csak akkor értékelődik ki, ha a bal oldali operandus még nem határozza meg a kifejezés eredményét. Ez azt jelenti, hogy a `||` csak akkor értékeli ki
a jobb oldali operandusát, ha a bal oldali operandus értéke `false`, a `&&` pedig csak akkor, ha `true`.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
