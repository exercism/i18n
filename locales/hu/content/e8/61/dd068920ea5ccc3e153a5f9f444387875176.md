# Részletesen

A [while-ciklus][while-loops] olyan vezérlési utasítás, amely addig futtat kódot, amíg egy adott feltétel igaz.
A Swift kétféle while-ciklust kínál: a while- és a repeat-while-ciklust.
A while-ciklus feltételét a ciklusmag végrehajtása előtt értékeli ki; ha a feltétel hamis, a ciklusmag egyáltalán nem fut le.
A while-ciklusok felépítése a Swiftben a következő:

```swift
while <#condition#> {
  <#code#>
}
```

Itt a ciklus addig fut, amíg a count nagyobb, mint 0, és eközben kiírja a 2-es és az 1-es számot, valamint a „Liftoff!” szöveget.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

A [repeat-while-ciklus][while-loops] hasonló a while-ciklushoz, de a feltételét a ciklusmag végrehajtása után értékeli ki.
Ez azt jelenti, hogy a ciklusmag mindig lefut legalább egyszer, akkor is, ha a feltétel hamis.
A repeat-while-ciklusok felépítése a Swiftben a következő:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Itt a ciklus csak egyszer fut le, mert a feltétel hamis.
Mivel repeat-while-ciklusról van szó, a ciklusmag egyszer lefut, mielőtt a feltételt kiértékelné.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Opcionális kötést használó ciklusok

A while-ciklusok egyik gyakori változata a Swiftben az opcionális kötést használó while-ciklus.
Ezek a ciklusok addig ismétlődnek, amíg egy opcionális értéket adó függvény hívása nem `nil` értékkel tér vissza.
Ez a (nem opcionális) érték aztán egy általad választott névhez kötődik, és a ciklusmagban használhatod.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
