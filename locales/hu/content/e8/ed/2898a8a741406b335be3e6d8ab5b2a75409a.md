# Bevezetés

A Factor elágazásai **quotation**ök közül választanak: ezek szögletes zárójelbe írt kódrészletek, `[ ... ]`. Amikor leírsz egy `[ ... ]`-t, a kód értékként kerül fel a veremre ahelyett, hogy lefutna; ezután az elágazás dönti el, hogy melyik quotation fusson le. (A quotationökkel egy későbbi feladatban foglalkozunk részletesen.)

Az `if` (a [`kernel`][kernel] szótárban) a Factor alapvető elágazása. Egy Boolean értéket és két quotationt vár: az elsőt futtatja, ha a Boolean igaz, egyébként a másodikat.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

A `when` csak akkor futtatja le a quotationt, ha a Boolean igaz, az `unless` pedig csak akkor, ha hamis. Többirányú elágazáshoz ott van a `cond` (a [`combinators`][combinators] szótárban):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
