# Bevezetés

## Feltételes elágazások: if

### Logikai operátorok

A Java három logikai operátort támogat: a `&&` (ÉS), a `||` (VAGY) és a `!` (NEM) operátort.

### Az if elágazás

Minden feltételes művelet alapvető típusa a `boolean` típus, amelynek az értéke `true` vagy `false` lehet. A feltételes elágazásokat gyakran vezérlési mechanizmusként használjuk, hogy különféle feltételeket ellenőrizzünk. Egy adott eset ellenőrzésére `if` elágazást használhatsz, amely akkor futtatja a kódját, ha a feltétel `true`, például így:

```java
int val;

if(val == 9) {
    // conditional code
}
```

Ha egynél több esetről van szó, több `if` elágazást is egymás után fűzhetsz az `else if` és az `else` elágazás segítségével.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### A switch utasítás

A Java egy `switch` utasítást is kínál azokra az esetekre, amikor több lehetőség közül kell választani.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
