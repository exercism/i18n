# Utasítások

Készíts egy RESTful API-t az adósságcédulák nyilvántartására.

Négy lakótárs gyakran szokott kölcsönkérni egymástól, és nehezen emlékszik rá, ki kinek és mennyivel tartozik.

A feladatod, hogy készíts egy egyszerű [RESTful API-t][restful-wikipedia], amely POST-kérésekként fogadja az [adósságcédulákat][iou], és GET-kérésekre meghatározott összesítő információkat tud visszaadni.

## API-leírás

### Felhasználói objektum

```json
{
  "name": "Adam",
  "owes": {
    "Bob": 12.0,
    "Chuck": 4.0,
    "Dan": 9.5
  },
  "owed_by": {
    "Bob": 6.5,
    "Dan": 2.75
  },
  "balance": "<(total owed by other users) - (total owed to other users)>"
}
```

### Metódusok

| Leírás                   | HTTP-metódus | URL    | Payload formátuma                                                         | Válasz payload nélkül                  | Válasz payloaddal                                                               |
| ------------------------ | ----------- | ------ | ------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------- |
| Felhasználói adatok listája | GET         | /users | `{"users":["Adam","Bob"]}`                                                | `{"users":<List of all User objects>}` | `{"users":<List of User objects for <users> (sorted by name)}`                  |
| Felhasználó létrehozása  | POST        | /add   | `{"user":<name of new user (unique)>}`                                    | N/A                                    | `<User object for new user>`                                                    |
| Adósságcédula létrehozása | POST        | /iou   | `{"lender":<name of lender>,"borrower":<name of borrower>,"amount":5.25}` | N/A                                    | `{"users":<updated User objects for <lender> and <borrower> (sorted by name)>}` |
