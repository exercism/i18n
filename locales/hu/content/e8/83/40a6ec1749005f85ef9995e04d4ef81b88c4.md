# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat  | Típus   | Leírás                                        |
| --------- | ---------- | ------- | --------------------------------------------- |
| `$a0`     | bemenet    | cím     | nullával lezárt string nyolcas számjegyekből  |
| `$v0`     | kimenet    | egész   | a bemeneti string tízes számrendszerbeli értéke |
| `$t0-9`   | ideiglenes | bármi   | ideiglenes tárolásra használatos              |
