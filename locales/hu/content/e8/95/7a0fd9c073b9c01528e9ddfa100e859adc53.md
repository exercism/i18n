# Bevezetés

## Agent

Az `Agent` modul absztrakciót nyújt [folyamatok és a _receive-send_ ciklus][exercism-processes] létrehozásához. A továbbiakban az `Agent` modullal indított folyamatokat _agentfolyamatoknak_ fogjuk nevezni. Egy _agentfolyamat_ lehet az a választás, amely egy központilag megosztott állapotot képvisel.

Egy _agentfolyamat_ indításához az `Agent` a `start/2` függvényt kínálja. Az _agentfolyamat_ `start`_-tal_ való indításakor a megadott függvény adja vissza a folyamat kezdeti állapotát:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Ahogy a `Map` vagy a `List`, úgy az `Agent` is számos függvényt kínál az _agentfolyamatokkal_ való munkához.

Az `Agent`-tel kapcsolatos összes funkcionalitást célszerű egy modulba szervezni és egységbe zárni a modellezett terület számára.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
