# Bevezetés

## A try/rescue/else/after

A `try..rescue` használata erőteljes szerkezet a hibák elkapására, amikor azok bekövetkeznek. A hibák elkapása lehetővé teszi, hogy a függvények meghatározott értékeket adjanak vissza, amikor arra szükség van. A `try..rescue` szerkezet emellett két további lehetőséget is kínál, amelyeket kihasználhatunk:

- az `else` blokk
  - Ha a try blokk sikeresen lefut, az eredmény erre a blokkra illeszkedik.
- az `after` blokk
  - Akár sikerrel jár a try blokk, akár hibát dob, az `after` blokkban lévő kód mindig lefut, amennyiben a program ezen a ponton még fut.
  - Az `after` blokk eredménye nem kerül vissza a hívó scope-ba.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## Dinamikus hívás

Amikor az Elixir feloldja a meghívandó függvényt, a modul nevével végzi a keresést. A keresés dinamikusan is elvégezhető, ha a modul neve egy változóhoz van kötve.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Belsőleg a modul neve egy atom. Minden Elixir-modul atom automatikusan megkapja az `Elixir.` előtagot.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
