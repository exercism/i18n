# Bővebben

A Flags attribútum lehetővé teszi, hogy a megkülönböztetett unióban definiált értékek bitpozíciókként (azaz jelzőbitként) jelenjenek meg.
Jelzőbitként ezek az értékek kombinálhatók, így több logikai feltétel is ábrázolható egyetlen értékben.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Egy jelzőbitet a bitenkénti VAGY operátorral (`|||`) állíthatunk be, törölni pedig a bitenkénti ÉS operátor (`&&&`) és a bitenkénti tagadás operátor (`~~~`) kombinációjával lehet.
A jelzőbit állapotát a bitenkénti ÉS operátorral ellenőrizhetjük, de használhatjuk a HasFlag() metódust is.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Az F# nyelven elérhető bitenkénti operátorok teljes listáját a [bitenkénti operátorok összefoglalója][bitwise-operators] oldalon találod.

[bitwise-operators]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/bitwise-operators#summary-of-bitwise-operators
