# Utasítások

Egy szerepjáték megvalósításán dolgozol.
A játékos karakterét a következő kód írja le:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

A játékban a játékosoknak el kell érniük a 10. szintet, hogy feloldják a manapoolt, amit varázslatok megidézésére használhatnak.
Ezt megelőzően a `Player` manája `Option::None`.

Két funkción dolgozol ebben a játékban: a feltámasztás mechanikáján és a varázslás mechanikáján.

A `revive` metódusnak ellenőriznie kell, hogy a `Player` valóban halott-e (az életereje elérte a 0-t), és ha igen, a metódusnak egy új `Player` példányt kell visszaadnia 100 életerővel.
A `revive` metódusnak meg kell őriznie a `Player` szintjét.
Ha a `Player` szintje 10 vagy annál nagyobb, akkor 100 manával kell feltámasztani.
Ha a `Player` szintje 10 alatti, akkor a manája `Option::None` legyen.

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

Ha a `revive` metódust olyan `Player`-re hívják, amelynek az életereje 1 vagy annál több, akkor a metódusnak `Option::None`-t kell visszaadnia.

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

A `cast_spell` metódus egy módosítható referenciát kap a `Player`-re, valamint egy `mana_cost` paramétert, amely megadja, mennyi manába kerül a varázslat.
Visszaadja, hogy a megidézett varázslat mennyi sebzést okoz.

- Ha a játékosnak nincs hozzáférése manapoolhoz, akkor a varázslat megidézésekor az életereje a varázslat manaköltségével csökken.
  A visszaadott sebzésnek 0-nak kell lennie.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- Ha a játékosnak van manapoolja, de nincs elég manája, a metódus ne módosítsa a poolt.
A visszaadott sebzésnek 0-nak kell lennie.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- Egyébként a varázslat sikeresen megidéződik.
  A `mana_cost` levonódik a `Player` manapooljából.
  A visszaadott sebzésnek a varázslat manaköltségének kétszeresének kell lennie.

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```
