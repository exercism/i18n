# Bevezetés

A Juliában három elsődleges feltételes utasítás használatos:

- `if`-kifejezések
- A ternáris operátor
- A rövidzár-kiértékelés

## `if`-kifejezések

A Juliában az `if`-kifejezések hasonlítanak a más nyelvekben megszokottakhoz:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

Ha az `if` utáni logikai kifejezés `true`-ra értékelődik ki, akkor az első kódblokk fut le, a második pedig kimarad.
Ha az `if` utáni logikai kifejezés `false`-ra értékelődik ki, akkor az első kódblokk marad ki, a második fut le.
A program az `end` kulcsszó utáni első kódsornál folytatódik.

~~~~exercism/note
A Juliában az `end` kulcsszó minden blokk-kifejezés végét jelzi.
Ez a szintaxis nem csak az `if`-kifejezésekre vagy a függvénydefiníciókra jellemző.
~~~~

Azokban az esetekben, amikor a második kódblokk csupán egy újabb `if`-kifejezés lenne, az `elseif` segítségével elkerülhetjük, hogy `if`-kifejezéseket ágyazzunk egymásba a blokkon belül:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

Ha egy `if`-kifejezésnek csak az egyik esetben kell kódot végrehajtania, nem kell kiírni az `else` ágat.

## Ternáris operátor

Az egyszerű `if-else` utasítások a ternáris operátorral is megírhatók: `a ? b : c`.
Ha `a` igaz, akkor `b` értékelődik ki.
Ellenkező esetben `c` értékelődik ki.

Például a következő függvény

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

így is megírható:

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

Ez különösen akkor hasznos, ha egy feltételtől függően más értéket szeretnél adni egy változónak.
Az `x = a ? b : c` a `b`-t adja értékül az `x`-nek, ha `a` `true`, egyébként pedig a `c`-t.
Például:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## Rövidzár-kiértékelés

Ha több logikai kifejezést fűzünk össze a `&&` és a `||` operátorral, a Julia csak annyi kifejezést értékel ki, amennyi a lánc egészének értékéhez feltétlenül szükséges.

Vegyük például az `n > 0 && k > 10` kifejezésláncot.
Ha az `n` értéke `5`, a lánc első része, az `n > 0`, `true`, és ahhoz, hogy megállapítsuk, az egész kifejezés `true`-e, a második kifejezést, a `k > 10`-et is ki kell értékelni.
Ha viszont az `n` `-5`, akkor tudjuk, hogy a lánc egésze **nem** lehet `true`, mert az első kifejezése `false`.

Ha viszont a `n > 0 || k > 10` kifejezést vesszük, minden fordítva történik.
Ha az `n` `5`, a lánc első része, az `n > 0`, `true`, és tudjuk, hogy az egész lánc `true` lesz, függetlenül a második kifejezéstől.
Ha viszont az `n` `-5`, akkor ki kell értékelni a második kifejezést.

Ez a viselkedés nagyon rövid `if`-kifejezések írására használható:

```julia
if a
    b
end
```

ezzel egyenértékű:

```julia
a && b
```

A `&&` és `||` láncban az utolsó kifejezés nem feltétlenül logikai kifejezés.
Gyakran találkozhatsz azzal, hogy ezt a lehetőséget korai hibákra vagy visszatérésekre használják.
Például a fenti `dessert(fruit)` függvénnyel:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
