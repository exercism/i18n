# Utasítások

Ebben a feladatban még egy kis kódot írsz majd, hogy segíts magadnak megfőzni a remek lasagnét a kedvenc szakácskönyvedből.

Öt részfeladat vár rád, mindegyik a lasagne elkészítési idejéhez kapcsolódik.

## 1. A várt sütési idő módosításának lehetővé tétele

Szeretnél írni egy továbbfejlesztett `remainingMinutesInOven` függvényt, amely paraméterként megkapja, hány perc telt el azóta, hogy a lasagne a sütőbe került, és visszaadja, hány percet kell még a sütőben maradnia, az előző részfeladatban megadott, percben kifejezett várt sütési idő alapján.
Korábban egy `expectedMinutesInOven` nevű konstans értékre támaszkodtál, amely a `remainingMinutesInOven` függvényen kívülről származott.
Ez egy kicsit zsúfoltnak tűnt a számodra, ráadásul nem is volt elég rugalmas, mivel nem teszi lehetővé a várt sütési idő megváltoztatását.

Hogy rendet tegyél, definiáld a `remainingMinutesInOven` függvényt, amely paraméterként megkapja, hány perc telt el azóta, hogy a lasagne a sütőben van, valamint egy `expectedMinutesInOven` paramétert, amelynek alapértelmezett értéke 40.
A függvényed adja vissza, hány percet kell még a lasagnének a sütőben maradnia, az előző részfeladatban megadott, percben kifejezett várt sütési idő alapján.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. A rétegek eltérő számának engedélyezése

Korábban írtál egy `preparationTimeInMinutes` függvényt, amely paraméterként megkapja a lasagnéhoz adott rétegek számát, és visszaadja, hány percet töltöttél a lasagne előkészítésével, feltételezve, hogy minden réteg 2 percet vesz igénybe.
Ez a függvény azonban nem igazán nyerte el a tetszésedet, mert magadnak kell megszámolnod a lasagnében lévő rétegeket, mielőtt meghívnád, és kinek van erre ideje?

Hogy megkönnyítsd a dolgodat, írj egy `preparationTimeInMinutes` függvényt, amely egy variadikus `String` paramétert kap, a `layers`-t, amelyben felsorolod a lasagne különböző rétegeit.
A függvény ezután megszámolja a lasagnében lévő rétegeket, és visszaadja a szükséges előkészítési időt.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. A tészta és a szósz mennyiségének kiszámítása

Mielőtt elkezdenéd összeállítani a lasagnét, szeretnél megbizonyosodni arról, hogy van elég szószod és tésztád az álmaid lasagnéjához.
A lasagnéd minden tésztarétegéhez 3 tésztalapra lesz szükséged.
A lasagnéd minden szószrétegéhez 0,2 liter szószra lesz szükséged.

Definiáld a `quantities` függvényt, amely egy variadikus `String` paramétert kap, a `layers`-t, amelyben felsorolod a lasagne különböző rétegeit.
A függvény ezután meghatározza a fogáshoz szükséges tészta és szósz mennyiségét. Az eredményt egy `(noodles: Int, sauce: Double)` típusú tuple-ban kell visszaadni.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. A literek átváltása folyadékunciára helyben

Sajnos a kéznél lévő szósz térfogata folyadékunciában van megadva, nem literben.
Hogy segítsen eldönteni, van-e elég szósz a kezed ügyében, írj egy `toOz` függvényt, amely egy in-out tuple paramétert, `(noodles: Int, sauce: Double)`-t kap, és átváltja a szósz mennyiségét folyadékunciára.
Ne feledd, hogy egy literben 33,814 folyadékuncia van.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. A legjobb bor kiválasztása a felszolgáláshoz

Végül szeretnéd tudni, milyen bort szolgálj fel a lasagnéd mellé.
Azt hallottad, hogy fehérbort kell felszolgálni, ha több mozzarella, ricotta és béchamel van a lasagnében, mint hús és szósz, egyébként pedig vörösbort.
Írj egy `redWine` függvényt, amely egy variadikus `String` paramétert kap, a `layers`-t, amelyben felsorolod a lasagne különböző rétegeit.
A függvény öt egymásba ágyazott függvényt használ, hogy meghatározza a mozzarella-, ricotta-, béchamel-, szósz- és húsrétegek számát a lasagnében, majd összehasonlítja a rétegek számát, hogy eldöntse, felszolgáljunk-e vörösbort; ha igen, `true`-t ad vissza, ha nem, `false`-t.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
