# Bevezetés

## Mintailesztés literálokkal

Bár feltételes logika megvalósítására használhatók `if/else` kifejezések, a Haskell ennél erősebb módot is kínál ugyanerre: a [mintaillesztést][pattern-matching].
A mintaillesztéssel egy értéket egy vagy több _mintával_ lehet összevetni.
Ilyen minta például a _konstansminta_, amely egy értéket egy konstanssal vet össze (például `1` vagy `"hello"`).

A függvények definiálásakor külön függvénytörzset adhatsz meg a különböző mintákhoz.
Ez áttekinthető, egyszerű és olvasható kódhoz vezet.
Bármilyen adattípusra illeszthetsz mintát: számokra, karakterekre, listákra, tuple-okra és így tovább.

Például egy egyszerű függvény, amely egy egész számot (`Int`) vesz át, és _1_-gyel közelebb viszi a _0_-hoz, így írható le:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

A mintaillesztés akkor mutatja meg igazán az erejét, ha más mintákkal együtt használjuk, például a _változómintával_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

A fenti példa a _0_-tól eltérő összes bemenetet ugyanúgy kezeli, és negatív számokra hibás eredményt adna.
Ezt feltételes mintákkal lehet megoldani, ezeket _őröknek_ nevezzük, és a `|` szimbólummal fejezzük ki őket:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

A fenti példákban nem minden lehetséges bemenetre illeszkedik minta.
A fordító ezt észleli, és figyelmeztetést ír ki.
Ez a Haskell egyik nagyon hasznos szolgáltatása, amely segít abban, hogy minden lehetséges ág le legyen fedve, és így elkerüljük a futásidejű hibákat.
Ezt _kimerítő ellenőrzésnek_ nevezik.
A figyelmeztetés megszüntetéséhez minden esetet kezelned kell.
Az _őrökön_ belül az `otherwise` kifejezést használhatod a `True` szintaktikai cukorkájaként, hogy elkapd az összes fennmaradó mintát.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

A mintaillesztés felülről lefelé haladva veti össze az értéket minden mintával, amíg nem talál illeszkedő mintát, és végre nem hajtja az adott mintához tartozó logikát.
**A minták sorrendje számít!**
