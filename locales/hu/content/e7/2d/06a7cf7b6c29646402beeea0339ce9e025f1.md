# nincs nevesített export

Nem található `%{export.name}` nevű [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export). A tesztek enélkül nem lesznek sikeresek.

Győződj meg róla, hogy a `%{export.name}` létezik, és írd elé az `export` szót:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
