# Utasítások

Ebben a feladatban a klasszikus Pac-Man játék néhány szabályát kell lefordítanod Gleam-függvényekre.

Négy szabályt kell lefordítanod, amelyek mind a játék állapotaihoz kapcsolódnak.

> Ne foglalkozz azzal, hogy honnan származnak az argumentumok, csak azzal, hogy a kívánt eredmény visszaadásához hogyan kombináld őket.

## 1. Határozd meg, hogy Pac-Man megeszik-e egy szellemet

Határozd meg az `eat_ghost` függvényt, amely két argumentumot vár (_hogy aktív-e Pac-Mannél egy energialabda_, illetve _hogy hozzáér-e Pac-Man egy szellemhez_), és Boolean értéket ad vissza arról, hogy Pac-Man meg tudja-e enni a szellemet. A függvény csak akkor adjon vissza `True`-t, ha Pac-Mannek aktív egy energialabdája, és hozzáér egy szellemhez.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Határozd meg, hogy Pac-Man pontot szerez-e

Határozd meg a `score` függvényt, amely két argumentumot vár (_hogy hozzáér-e Pac-Man egy energialabdához_, illetve _hogy hozzáér-e Pac-Man egy ponthoz_), és Boolean értéket ad vissza arról, hogy Pac-Man szerzett-e pontot. A függvény akkor adjon vissza `True`-t, ha Pac-Man hozzáér egy energialabdához vagy egy ponthoz.

```gleam
score(True, True)
// -> True
```

## 3. Határozd meg, hogy Pac-Man veszít-e

Határozd meg a `lose` függvényt, amely két argumentumot vár (_hogy aktív-e Pac-Mannél egy energialabda_, illetve _hogy hozzáér-e Pac-Man egy szellemhez_), és Boolean értéket ad vissza arról, hogy Pac-Man veszít-e. A függvény akkor adjon vissza `True`-t, ha Pac-Man hozzáér egy szellemhez, és nincs nála aktív energialabda.

```gleam
lose(False, True)
// -> True
```

## 4. Határozd meg, hogy Pac-Man nyer-e

Határozd meg a `win` függvényt, amely három argumentumot vár (_hogy Pac-Man megette-e az összes pontot_, _hogy aktív-e Pac-Mannél egy energialabda_, és _hogy hozzáér-e Pac-Man egy szellemhez_), és Boolean értéket ad vissza arról, hogy Pac-Man nyer-e. A függvény akkor adjon vissza `True`-t, ha Pac-Man megette az összes pontot, és a 3. részben meghatározott argumentumok alapján nem veszített.

```gleam
win(False, True, False)
// -> False
```
