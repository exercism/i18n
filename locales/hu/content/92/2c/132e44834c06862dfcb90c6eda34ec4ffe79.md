# Bemutatás

A struktúrák és osztályok példányainak mindegyike rendelkezik egy implicit `self` nevű értékkel, amely magára a példányra hivatkozik. A `self`-nek többféle felhasználása is van, de leggyakrabban arra szolgál, hogy egyértelművé tegyük vele egy struktúra vagy osztály tulajdonságainak és metódusainak a nevét, amikor össze lehetne keverni őket.

```swift
struct MySelf {
  var x = 0

  mutating func move(x: Int) {
    // here if we just say x = x it is unclear if we mean
    // the property x or the method parameter x, so we use
    // self for clarity
    self.x = x
  }
}
```

A struktúráknak és osztályoknak van egy `Self` értékük is, amely nem a struktúra vagy osztály példányára, hanem magára a típusára hivatkozik.
