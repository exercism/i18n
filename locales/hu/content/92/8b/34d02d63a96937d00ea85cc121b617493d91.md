# Kiegészítés az utasításokhoz

## Kivételüzenetek

Néha [kivételt kell dobni](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Amikor ezt teszed, mindig szerepeltetned kell egy **értelmes hibaüzenetet**, amely jelzi, mi a hiba forrása. Ez olvashatóbbá teszi a kódodat, és jelentősen segít a hibakeresésben. Azokban az esetekben, amikor tudod, hogy a hiba forrása egy bizonyos típus, választhatod, hogy a [beépített hibatípusok](https://docs.python.org/3/library/exceptions.html#base-classes) egyikét dobod, de továbbra is szerepeltetned kell egy értelmes üzenetet.

Ez a konkrét feladat megköveteli, hogy a [raise utasítást](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) használd, hogy „dobd” a `ValueError`-t, ha a `preorder` és `inorder` argumentumok hosszúságban, elemekben eltérnek, vagy az elemek nem egyediek. A tesztek csak akkor mennek át, ha `raise`-eled a `exception`-t, és üzenetet is fűzöl hozzá.

Ahhoz, hogy egy `ValueError`-t üzenettel dobj, írd az üzenetet az `exception` típus argumentumaként:

```python
# if preorder and inorder are not the same length
raise ValueError("traversals must have the same length")

# if preorder and inorder do not share the same elements
raise ValueError("traversals must have the same elements")
    
# if element repeat (are not unique)    
raise ValueError("traversals must contain unique items")
```
