# Utasítások

Új költészeti klub nyílt a városban, és épp azon gondolkodsz, hogy benézz oda.
Mivel korábban már történtek incidensek, a klubnak nagyon sajátos ajtószabályzata van, amelyet el kell sajátítanod, mielőtt a belépést megkísérled.

A költészeti klubban két ajtó van, és mindkettőt őr vigyázza.
Ahhoz, hogy bejuss, ki kell derítened az aznapi jelszót:

## 1. Bontsd fel a stringet külön sorokra

Először is a verset külön sorokra kell bontanod.
Az őr felmond egy verset, neked pedig sorokra kell bontanod.

Valósítsd meg a `splitOnNewlines` függvényt, amely egy stringet kap, és a sortörés karaktert elválasztóként használva stringek tömbjére bontja azt.
A függvény egy stringtömböt adjon vissza, amelyben minden string a vers egy-egy sora.

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. Bejárati ajtó

1. Az őr felmond egy verset.
2. A verset külön sorokra kell bontanod.
3. Ki kell venned minden sor első betűjét.
   - Ha egy sor üres, helyette a `_` jelet használd.
4. A betűket össze kell illesztened, így egy szó áll össze belőlük.

Például egyik kedvenc írójuk Michael Lockwood, akitől az alábbi _akrosztichon_ vers származik; az akrosztichon azt jelenti, hogy minden mondat első betűje egy szót ad ki:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Amikor az őr felmondja a verset, külön sorokra bontod, és minden sor első betűjével válaszolsz, azaz `["S", "H", "I", "R", "E"]`.

Ezután az őr megadja neked azt a szót, amelyet a válaszul adott betűk tömbje alkot, hogy nagy kezdőbetűs alakba hozd.
Végül a visszaadott jelszó `"SHIRE"`, és bejutsz.

Valósítsd meg a `frontDoorPassword` függvényt, amely egy stringet kap, ami a verset képviseli.
A függvény adja vissza azt a jelszót, amelyet az őrnek megadnál.

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. A hátsó ajtó

A klub hátsó részében találod a leghíresebb költőket, ez a VIP-részleghez hasonlít.
Mivel ez nem mindenkinek jár, a hátsó ajtó procedúrája kicsit bonyolultabb.

1. Az őr felmond egy verset.
2. A verset sorokra kell bontanod.
3. Ki kell venned minden sor utolsó betűjét.
   - A sor végén néha szóközök lehetnek, ezért ezeket le kell vágnod.
4. A betűket össze kell illesztened, majd a belőlük álló szó végére be kell írnod a `", please"` szöveget.

Például a korábban említett vers egyben _telestichon_ is, ami azt jelenti, hogy minden mondat utolsó betűje egy szót ad ki:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Amikor az őr felmondja a verset, külön sorokra bontod, levágod a sorok végéről a szóközöket, és minden sor első betűjével válaszolsz, azaz `["h", "o", "r", "s", "e"]`.

Ezután az őr megadja neked azt a szót, amelyet a válaszul adott betűk tömbje alkot, hogy nagy kezdőbetűs alakba hozd, és a végére fűzd a `", please"` szöveget.
Végül a visszaadott jelszó `"horse, please"`, és bejutsz.

Valósítsd meg a `backDoorPassword` függvényt, amely egy stringet kap, ami a verset képviseli.
A függvény adja vissza azt a jelszót, amelyet az őrnek megadnál.

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. A titkos szoba

A klub hátsó termében van még egy ajtó, amely a titkos szobába vezet, ahová csak a legkiválóbb költők léphetnek be.

1. Az őr felmond egy verset.
2. A verset sorokra kell bontanod.
3. Ki kell venned az i<sup>th</sup> sor i<sup>th</sup> betűjét. 
4. A betűket össze kell illesztened, majd a belőlük álló szó végére be kell írnod a `"!"` jelet.
5. A szót nagybetűs alakba kell hoznod.

Például a korábban említett vers egy módosított változata illik erre a mintára:

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

Amikor az őr felmondja a verset, külön sorokra bontod, levágod a sorok végéről a szóközöket, és minden sor i<sup>th</sup> betűjével válaszolsz, azaz ["S", "u", "p", "e", "r"].

Ezután az őr megadja neked azt a szót, amelyet a válaszul adott betűk tömbje alkot, hogy nagybetűs alakba hozd, és a végére fűzd a `"!"` jelet.
Végül a visszaadott jelszó `SUPER!`, és bejutsz.

Valósítsd meg a `secretRoomPassword` függvényt, amely egy stringet kap, ami a verset képviseli.
A függvény adja vissza azt a jelszót, amelyet az őrnek megadnál.

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
