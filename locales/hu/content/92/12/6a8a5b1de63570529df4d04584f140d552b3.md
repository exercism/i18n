# Kiegészítés az utasításokhoz

## A kiinduló kód

A `src/TreeBuilding.hs` már tartalmaz egy működő megoldást, ami minden teszten átmegy.
Ez lassú és nehezen olvasható, a feladatod, hogy jobbá tedd anélkül, hogy elrontanád a teszteket.

A `buildTree` `Nothing`-ot ad vissza, ha a rekordok nem alkotnak érvényes fát.

## A reprezentáció megváltoztatása

A tesztek soha nem használják közvetlenül a `Tree` konstruktorait.
Ehelyett a várt fákat ezzel a függvénnyel építik fel:

```haskell
node :: Int -> [Tree] -> Tree
```

ahol a `node i children` az `i` azonosítójú csomópont a megadott gyerekekkel, az azonosítók növekvő sorrendjében.

Ez azt jelenti, hogy szabadon megváltoztathatod, hogyan reprezentálod a `Tree`-t, például így:

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

amíg a `Tree`-nek továbbra is van `Eq` és `Show` instance-a, és a `node` megtartja a jelentését.
Ha olyan könyvtárat használsz, mint a `containers`, ne felejtsd el felvenni a `dependencies` közé a `package.yaml`-ban.
