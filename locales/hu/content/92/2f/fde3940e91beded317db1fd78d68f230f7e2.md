# Utasítások

Egy tengerparti rádióállomáson vagy, a csatornaforgalmat figyeled: üzenetek futnak be a vonalra, feljegyzed őket, majd visszaküldöd a válaszokat. Öt apró szó elvégzi egy egész műszak munkáját.

A tesztek `<string-reader>` bemeneteket (bejövő forgalmat) adnak neked, a kimenőhöz pedig `<string-writer>`-t használnak. Itt viszont minden szó ugyanúgy működik egy valódi `<file-reader>`-rel vagy socketen keresztül is.

## 1. Hallgasd végig

Definiáld a `hear-out` szót, hogy egy bemeneti adatfolyam teljes tartalmát egyetlen stringbe olvassa.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. Számold meg az üzeneteket

Definiáld a `count-messages` szót, hogy beolvassa egy bemeneti adatfolyam minden sorát, és visszaadja, hány sor volt.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. Visszhangozd vissza az utolsó adást

Definiáld az `echo-back` szót, hogy beolvassa az összes sort, és **a legutolsót nagybetűvel** adja vissza, ez a szabványos rádiós »ezt mondtad« válasz.

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. Sugározz egy üzenetet

Definiáld a `broadcast` szót, hogy egy üzenetet írjon egy adott írónak, és kiürítse az adatfolyamot, hogy azonnal kimenjen. Nem ad vissza semmit.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. Rögzítsd egy quotation kimenetét

Definiáld a `capture` szót, hogy lefuttasson egy quotationt úgy, hogy a környezeti kimenet egy friss string-writer legyen, és visszaadja, amit a quotation kiírt. A quotation nem fogad el argumentumot, egyszerűen a szokásos módon a környezeti adatfolyamba ír.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
