# A Boolean típus

Cairo-ban a Boolean típus elengedhetetlen a logikai műveletekhez és a feltételes elágazásokhoz.
A Cairo-beli Boolean értékek egy `felt252` méretűek, ami hatékony helykihasználást tesz lehetővé, miközben megőrzi az igaz/hamis logika egyszerűségét.

A Boolean típust Cairo-ban a `bool` kulcsszóval jelöljük.
Ez lehetővé teszi Boolean változók deklarálását és kezelését a nyelvben.
Például nézzük a következő példát:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

Ebben a példában két Boolean változót deklarálunk.
A `t` változóhoz a `true` értéket rendeljük, és implicit módon Boolean típusúként deklaráljuk, míg az `f` változót explicit módon a `bool` típussal látjuk el, és a `false` értéket rendeljük hozzá.

Fontos megjegyezni, hogy amikor Boolean változót deklarálunk Cairo-ban, kötelező a `true` vagy `false` literált használni értékként.
Ez azt jelenti, hogy egész literálok, például a `0` vagy az `1`, nem használhatók a `false` vagy a `true` helyettesítésére.
A szabály szigorú érvényesítése biztosítja a típusbiztonságot, és megelőzi a lehetséges logikai hibákat az okosszerződés-fejlesztésben.

## Boolean operátorok Cairo-ban

- `||` (logikai VAGY): `true`-t ad vissza, ha legalább az egyik operandus `true`.
- `&&` (logikai ÉS): `true`-t ad vissza, ha mindkét operandus `true`.
- `!` (logikai NEM): Az operandus ellentétes Boolean értékét adja vissza.

## Példakód

A következő kódrészlet bemutatja, hogyan használhatók a Boolean típusok Cairo-ban.
Bemutatja a Boolean változók deklarálását, a Boolean kifejezések értékadását és az állítások használatát a Boolean logika helyességének ellenőrzésére:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
