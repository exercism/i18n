# Utasítások

Ebben a feladatban egy kis pékség napi működésének kezelésében segítesz, a Cairo vezérlési szerkezeteit használva.

## 1. Számítsd ki a rendelés végösszegét

Valósítsd meg a `calculate_total` függvényt, amely egy rendelés költségét számítja ki a sütemény típusa és mennyisége alapján:

- Croissant: darabonként 3 érme
- Muffin: darabonként 2 érme  
- Cookie: darabonként 1 érme

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Alkalmazd a mennyiségi kedvezményeket

Valósítsd meg az `apply_discount` függvényt, amely a rendelés végösszege alapján alkalmaz kedvezményeket.
A százalékos kedvezményt a végösszegre alkalmazd, majd kerekítsd le a legközelebbi egész érmére (lefelé kerekítés).

- 20 érme vagy annál nagyobb rendelés: 10% kedvezmény
- 10 érme vagy annál nagyobb rendelés: 5% kedvezmény
- 10 érménél kevesebb rendelés: nincs kedvezmény

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Készíts sütési ütemtervet

Valósítsd meg a `baking_schedule` függvényt, amely egy napi sütési tervet készít.
A pékség óránként 5 rendelésből álló adagokban süt:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Használj megfelelő vezérlési szerkezeteket (`if`/`else`, `loop`), hogy hatékonyan oldd meg az egyes problémákat.
