# Bevezetés

A JSON így definiálja a **tömböt**:

> A tömb értékek sorrendbe rendezett gyűjteménye.
> A tömb egy `[` nyitó szögletes zárójellel kezdődik és egy `]` záró szögletes zárójellel végződik.
> Az értékeket `,` vessző választja el.

A tömbök nulla vagy több _bármilyen típusú_ JSON-értéket tartalmazhatnak.
A tömb elemeinek nem kell mind ugyanolyan típusúaknak lenniük.

## Tömbök létrehozása

A zárójelek segítségével elemeket gyűjthetsz egy tömbbe.

```jq
[1, 2, 3]
```

Egy _stream_ elemeit úgy gyűjtheted tömbbe, hogy zárójelek közé foglalod.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## Méret

A `length` függvény a tömb elemeinek számát adja vissza.

## Indexelés és szeletelés

A tömbök indexelése nullától kezdődik.

Egy tömb elemének lekéréséhez zárójeles kifejezést használhatsz:
a `.[2]` a harmadik elemet adja.

A negatív indexek a tömb végétől visszafelé számolnak:
a `.[-1]` az utolsó elemet adja, a `.[-2]` pedig az utolsó előttit.

A **szelet** a tömb egy részsorozata.
A `.[10:15]` 5 elemet ad vissza a 10-es indextől kezdve; a záró index _nincs benne_.

Néhány kényelmi függvény is a rendelkezésedre áll:

- a `first` az első elemet adja.
- a `last` az utolsó elemet adja.
- a `nth(n)` az `n` indexű elemet adja.

## Iterálás

A `jq` számos függvényt kínál a gyakori iterációs feladatok lefedésére:

- A `map(expr)` egy új tömböt ad vissza, amelyben az `expr` minden elemre sorban alkalmazva van.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- A `select(expr)` egy olyan függvény, amely az `expr`-t egy _egyetlen értékre_ alkalmazza;
  ha a kifejezés eredménye igaz, akkor az értéket adja vissza;
  ha az eredmény hamis, akkor _semmit_ nem ad vissza, nem `null`-t, hanem tényleg semmit.

  Hogy ezt egy tömbre alkalmazd, kombináld a `map`-pel.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Vagy alkalmazd a `select`-et egy _streamre_, és gyűjtsd össze az eredményeket.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- Az `any(condition)` és az `all(condition)` egy Boolean értéket ad vissza attól függően, hogy a tömb bármelyik/mindegyik eleme teljesíti-e a feltételt.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
