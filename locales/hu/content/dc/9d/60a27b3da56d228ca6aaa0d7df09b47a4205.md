# Részletesen

Előfordul, hogy ha egy függvény sok argumentumot vár, nehéz megjegyezni, milyen sorrendben kell megadni őket. Az olvashatóság érdekében a Gleam lehetővé teszi, hogy az argumentumokat névvel lásd el.

Egy argumentum felcímkézéséhez a címke nevét az argumentum neve elé írd, szóközzel elválasztva.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Ha egy függvényt címkézett argumentumokkal hívsz meg, az argumentumokat tetszőleges sorrendben megadhatod. Az alábbi `replace`-hívások mind egyenértékűek:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

A címkék mindig opcionálisak. Attól, hogy egy függvény argumentumai címkével rendelkeznek, még meghívhatók címkék nélkül is.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

Ha egy függvényt címkézett argumentumokkal definiálsz, az első címkézett argumentum utáni összes argumentumnak is címkével kell rendelkeznie.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
