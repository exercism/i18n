# Bevezetés

## Generikus típusok

Egy gyűjtemény definíciója általában tartalmaz egy helyőrzőt csúcsos zárójelben, amelyet a szokás szerint gyakran `T`-nek nevezünk. Az ilyen gyűjteményt generikus típusnak nevezzük. Ez lehetővé teszi, hogy a gyűjtemény használója megadja, milyen típusú elemeket tároljon a gyűjteményben. Az alábbi példakódban egy stringekből álló listát példányosítunk.

## Listák

A C#-ban a listák primitív értékek, illetve struktúrák vagy osztályok példányainak gyűjteményei. Az alaposztály-könyvtárban `List<T>` formában vannak megvalósítva, ahol a `T` a listában tárolt elem típusa. Az API gazdag metóduskészletet kínál a listák létrehozásához és kezeléséhez.

A listákhoz elemek adhatók, és elemek eltávolíthatók belőlük. Szükség szerint nőnek és zsugorodnak.

```csharp
var listOfStrings = new List<string>();
```
