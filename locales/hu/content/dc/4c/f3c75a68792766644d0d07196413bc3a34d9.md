# Bevezetés

A Wikipédia a `switch` utasítást így írja le: „a kiválasztás egyik vezérlési mechanizmusa, amely lehetővé teszi, hogy egy változó vagy kifejezés értéke megváltoztassa a program vezérlési folyamát”.

A mechanizmusban a következő kulcsszavak játszanak szerepet: `switch`, `case`, `break` és `default`.

A legegyszerűbb esetben egy primitív vagy string kifejezést vizsgálnak, és annak értéke alapján döntenek. Például:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

A legkifinomultabb formájukban megjelenik bennük a leszármazott típusra való átalakítás, a `case <Type> <variable>:` forma és az esetőrök (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
