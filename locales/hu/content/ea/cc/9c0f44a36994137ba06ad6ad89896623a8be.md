# Utasítások

A Mecha Munch™, egy élelmiszer-bevásárlást automatizáló cég épp most vett fel, hogy a rendelési alkalmazásukon dolgozz.
A csapatod feladata, hogy elkészítsen egy MVP-t (_[minimálisan életképes termék][mvp]_), amely a bevásárlókosár összes alapvető műveletét kezeli, és lehetővé teszi a felhasználóknak, hogy hozzáadják, eltávolítsák és rendezzék a bevásárlásaikat.
Szerencsére a pénzzel és a fizetéssel kapcsolatos funkciókat egy másik csapat intézi!

## 1. Termék(ek) hozzáadása a felhasználó bevásárlókosarához

Az MVP-nek lehetővé kell tennie, hogy a felhasználó termékeket adjon a bevásárlókosarához.
Ez lehet egyetlen termék vagy egyszerre több termék is.
Mivel ez egy MVP, a termék mennyiségét az _ismétlődések_ jelzik.
Ha a felhasználó 2 „Oranges”-t szeretne hozzáadni, az „Oranges” kétszer fog megjelenni a bemeneti iterálható sorozatban.
Ha a termék már benne van a felhasználó kosarában, a kosárban lévő mennyiséget 1-gyel kell növelni.
Ha a termék _új_ a kosárban, akkor 1-es mennyiséggel kell hozzáadni.

Hozd létre az `add_items!(<cart>, <items>)` függvényt, amely argumentumként egy kosárszótárt és a hozzáadandó termékek iterálható sorozatát kapja.
A függvény adja vissza a felhasználó frissített bevásárlókosár-szótárát.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. A receptek „ötletek” szakaszának frissítése

Az alkalmazásban van egy „ötletek” szakasz, amely különféle konyhák kész receptjeivel van tele.
A felhasználó kiválaszthatja bármelyik receptet, és annak minden hozzávalója automatikusan bekerül a bevásárlókosarába.
A projektmenedzser megkért, hogy hozz létre egy módot ezeknek az „ötletek” recepteknek a szerkesztésére, mivel a tartalomcsapat folyamatosan módosítja a hozzávalókat és a mennyiségeket.

Hozd létre az `update_recipes!(<ideas>, <updates>)` függvényt, amely argumentumként egy „ötletek” szótárt és a receptfrissítések szótárát kapja.

## 3. A felhasználó bevásárlókosarának elküldése a boltba teljesítésre

Az alkalmazásnak el kell küldenie egy adott felhasználó kosarát a boltba teljesítésre.
A boltban dolgozóknak viszont tudniuk kell, hol található a termék, egy egyedi folyosókód segítségével.
A „teljesítési kosarat” a termékek folyosókódjai szerint kell rendezni, hogy a bolti dolgozók hatékonyabban dolgozhassanak.

Hozd létre a `send_to_store(<cart>, <aislecodes>)` függvényt, amely egy felhasználói bevásárlókosarat és egy szótárt kap, amely a bolt folyosószámait tartalmazza.
A függvény adjon vissza egy összevont „teljesítési kosarat”, amelyben minden megrendelt termékhez egy `aislecode => quantity` pár tartozik.
A termékek a folyosókódjuk sorrendjében jelenjenek meg.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. A bolt készletének frissítése a felhasználó rendelése alapján

Az alkalmazás nem adhat le vég nélkül vásárlói rendeléseket.
Előbb-utóbb a bolt kifogy majd a különféle termékekből.
Ezért az MVP-alkalmazásnak minden alkalommal frissítenie kell a bolt készletét, amikor a felhasználó elküldi a rendelését a boltba.
Különben a vásárlók olyan termékeket rendelnek, amelyek valójában nem is elérhetők.

Hozd létre az `update_store_inventory!(<inventory>, <cart>)` függvényt, amely egy `cart` és egy `inventory` argumentumot kap.
A függvény csökkentse a bolt készletének mennyiségeit a „cartban” megrendelt darabszámmal, majd adjon vissza egy szótárt azokról a termékekről, amelyek elfogytak (azaz elérték a `0`-t).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Az elfogyott termékek újrarendelése

A készlet frissítésén túl az alkalmazás a feltöltésben is segíthet.
Az MVP-nek képesnek kell lennie arra, hogy egy mini-rendelést készítsen minden olyan termékből, amely egy vásárlói rendelés után elfogyott.
Ez segít egyszerűbbé tenni egy nagyobb rendelés elindítását.
Ráadásul néha vannak olyan akciós termékek, amelyek csak korlátozott ideig kaphatók, és nincsenek benne a készletlistában.
Ha ezek az akciós időszak vége előtt elfogytak, akkor bizonyítottan népszerűek, és felvehetők a készletlistára.

Hozd létre a `reorder!(<outofstock>, <stock>)` függvényt, amely `outofstock` és `stock` argumentumot kap.
A `stock` szótár a szokásos készletcikkeket és azok újrarendelési mennyiségeit tartalmazza.
Az `outofstock` szótár az `update_store_inventory!` eredménye, vagyis a nulla mennyiségű termékek szótára.
Az `outofstock` mennyiségeit a `stock`-ban szereplő értékekre kell frissíteni, és vissza kell adni.
Emellett minden olyan terméket az `outofstock`-ból, amely nem szerepel a `stock`-ban, fel kell venni a `stock`-ba `100` alapértelmezett mennyiséggel.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
