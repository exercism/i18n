# Generikus adattípusok

A Cairo generikusai lehetővé teszik, hogy újrafelhasználható kódot írj, amely különböző típusokkal működik, így elkerülheted az ismétlődést és javíthatod a karbantarthatóságot.

A generikusokat használhatod függvényekkel, struktúrákkal, felsorolásokkal, trait-ekkel és metódusokkal.

## Generikus függvények

Egy generikus függvény különböző típusokon működik anélkül, hogy külön implementációra lenne szükség.

Például:

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Itt a `T` bármely típus helyőrzője.

A Cairo-nak azonban trait-korlátokra van szüksége ahhoz, hogy a generikus típus megfeleljen bizonyos követelményeknek.

Ha `T`-nek droppolhatónak kell lennie, frissíthetjük a szignatúrát:

```rust
fn largest_list<T, impl TDrop: Drop<T>>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

A trait-korlátok, például a `Drop` vagy a `PartialOrd`, megkötéseket adnak a generikusokhoz adott műveletekhez.

## Névtelen megkötések

Ha egy trait-implementációt nem használsz közvetlenül egy függvényben, névtelen megkötéseket írhatsz a `+` jellel:

```rust
fn smallest_element<T, +PartialOrd<T>, +Drop<T>, +Copy<T>>(list: @Array<T>) -> T {
    let mut smallest = *list[0];
    let mut index = 1;

    while index < list.len() {
        if *list[index] < smallest {
            smallest = *list[index];
        }
        index += 1;
    };

    smallest
}
```

Így nem kell nevet adni az olyan trait-eknek, mint a `TPartialOrd`, ami csökkenti a bőbeszédűséget.

## Struktúrák generikusokkal

A generikusoknak köszönhetően a struktúrák mezői rugalmasak lehetnek.

Például:

```rust
#[derive(Drop)]
struct Wallet<T> {
    balance: T,
}

let w = Wallet { balance: 42 };
```

Ha egy struktúrának több generikus típusra van szüksége, csak adj hozzá további helyőrzőket:

```rust
#[derive(Drop)]
struct Wallet<T, U> {
    balance: T,
    address: U,
}

let w = Wallet { balance: 42, address: '0xabc' };
```

## Felsorolások generikusokkal

A felsorolások is tárolhatnak generikus adattípusokat.

Például:

```rust
enum Option<T> {
    Some: T,
    None,
}
```

Az `Option<T>` felsorolás bármely típus opcionális értékét képviselheti.

Hasonlóképpen a `Result<T, E>` lehetővé teszi a siker és a hiba típusának megadását:

```rust
enum Result<T, E> {
    Ok: T,
    Err: E,
}
```

## Generikus metódusok

A metódusok is használhatnak generikusokat.

Például:

```rust
#[derive(Copy, Drop)]
struct Wallet<T> {
    balance: T,
}

trait WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T;
}

impl WalletImpl<T, +Copy<T>> of WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T {
        *self.balance
    }
}

let w = Wallet { balance: 50 };
assert!(w.balance() == 50);
```

Adott generikus típusokhoz is definiálhatsz metódusokat, például a `Wallet<u128>`-hoz:

```rust
trait WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128);
}

impl WalletReceiveImpl of WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128) {
        self.balance += value;
    }
}

let mut w = Wallet { balance: 50 };
w.receive(100);
assert!(w.balance() == 150);
```

## Generikus típusok keverése

A generikusok összetett kombinációkat is kezelhetnek.

Például két különböző típusú `Wallet` példány összekeverése:

```rust
trait WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2>;
}

impl WalletMixImpl<T1, +Drop<T1>, U1, +Drop<U1>> of WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2> {
        Wallet { balance: self.balance, address: other.address }
    }
}

let w1 = Wallet { balance: true, address: 10 };
let w2 = Wallet { balance: 32, address: 100 };
let w3 = w1.mixup(w2);

assert!(w3.balance);
assert!(w3.address == 100);
```

A `+Drop` megkötések hozzáadásával a fordító gondoskodik az erőforrások megfelelő kezeléséről.

A generikusok hatékony eszközök, de a megkötések gondos kezelését igénylik.

Használd őket újrafelhasználható, típusfüggetlen és tömör kód írásához.
