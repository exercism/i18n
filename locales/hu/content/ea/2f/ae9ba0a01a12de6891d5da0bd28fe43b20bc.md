# Utasítások

Ebben a feladatban olyan kódot írsz, amely névjelvényeket nyomtat gyári alkalmazottak számára.

## 1. Nyomtass jelvényt egy alkalmazottnak

Az alkalmazottaknak van azonosítójuk, nevük és részlegnevük. Az alkalmazotti jelvények címkéi a következő formátumot követik: `"[id] - name - DEPARTMENT"`.
Valósítsd meg a `Badge.print()` metódust úgy, hogy visszaadja az alkalmazott jelvényének címkéjét:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Ügyelj arra, hogy a részleg neve a címkén csupa nagybetűvel jelenjen meg.

## 2. Nyomtass jelvényt egy új alkalmazottnak

A számítógépes rendszer egyik furcsasága miatt előfordul, hogy az új alkalmazottaknak a gyárban való kezdéskor még nincs azonosítójuk.
Mivel a jelvény kötelező, ideiglenes jelvényt kapnak, amelyen nincs ott az azonosító előtagja. Módosítsd a `Badge.print()` metódust, hogy támogassa azokat az új alkalmazottakat, akiknek még nincs azonosítójuk:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Nyomtass jelvényt a tulajdonosnak

Még a gyár tulajdonosának is mindig jelvényt kell viselnie.
A tulajdonosnak azonban nincs részlege. Ebben az esetben a címkén a részlegnév helyett `"OWNER"` szerepeljen.
Módosítsd a `Badge.print()` metódust, hogy a tulajdonos számára is kiírjon egy címkét:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

Figyelj rá, hogy előfordulhat, hogy a tulajdonos egyben új alkalmazott is:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
