# Divatbutik

## Történet

Egy online divatbutikot vezetsz. Közeleg a Black Friday, ezért számba kell venned a készletedet, hogy biztosan készen állj.

A készlet egyetlen elemét egy map/szótár írja le, a teljes készlet pedig az ilyen map/szótárak listája/tömbje.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## Feladatok

- Rendezd a termékeket ár szerint
- Keresd meg az összes olyan terméket, amelynek hiányzik az ára
- Növeld a termék mennyiségét
- Számítsd ki a termék teljes mennyiségét
