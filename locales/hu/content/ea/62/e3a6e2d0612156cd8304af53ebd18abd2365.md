# Kiegészítés az utasításokhoz

## A projekt felépítése

Az Exercism Clojure-feladatai a függőségkezelés és a tesztelés két legelterjedtebb eszközét támogatják: a [leiningen][leiningen]t és a [Clojure CLI][clojure-cli]-t.

A `test` könyvtárban találsz egy `hello_world_test.clj` nevű tesztfájlt.
A kódodat a `src/hello_world.clj` fájlba írd. A `hello-world` névteret kell használnia, hogy a tesztek megtalálják.

### Tesztek futtatása a Clojure CLI-vel

```
$ clj -X:test
```

### Tesztek futtatása Leiningennel

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Ezután a feladatot ezzel küldd be:

```
$ exercism submit src/hello_world.clj
```

Részletesebb útmutatásért és tanulási anyagokért nézd meg [az Exercism Clojure nyelvi oldalát][exercism-clojure].

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
