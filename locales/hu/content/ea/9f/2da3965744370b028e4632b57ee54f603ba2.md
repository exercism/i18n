# Bevezetés

## Konstansok

A `const` módosító minden olyan mezőre alkalmazható (és általában alkalmazni is kell), amelynek az értéke fordítási időben ismert, és nem változik a program élettartama alatt.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

A `readonly` módosító minden olyan mezőre alkalmazható (és általában alkalmazni is kell), amelyet nem lehet `const`-tá tenni, amelynek az értéke nem változik a program élettartama alatt, és amely vagy egy soron belüli kezdőértékkel, vagy a példányosítás során kap értéket (a konstruktorban vagy egy konstruktor által hívott metódusban).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## Védekező másolás

Biztonságra érzékeny helyzetekben (vagy akár csak egy nagy kódbázison, ahol a fejlesztőknek különböző prioritásaik és szándékaik vannak) arra kell törekedned, hogy egy osztály nyilvános API-ját ne lehessen megkerülni azzal, hogy egy metódus módosítható paramétereit elfogadod és eltárolod, vagy hogy egy osztály módosítható tagját visszatérési értékként vagy `out` paraméterként kiadod.

## Csak olvasható gyűjtemények

Bár a `readonly` módosító megakadályozza, hogy egy mező értékét vagy referenciáját felülírják, a referenciatípus tagjait semmilyen módon nem védi.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Ahhoz, hogy egy referenciatípus minden tagja védve legyen, a mezőket `readonly`-vá teheted, az automatikus tulajdonságokat pedig `set` elérő nélkül definiálhatod.

A Base Class Library (BCL) biztosít néhány csak olvasható változatot azokból a gyűjteményekből, amelyeknél meg kell akadályozni, hogy a gyűjtemény tagjai frissüljenek. Ezek burkolók formájában érkeznek:

- A `ReadOnlyDictionary<T>` a `Dictionary<T>`-t csak olvashatóként teszi elérhetővé.
- A `ReadOnlyCollection<T>` a `List<T>`-t csak olvashatóként teszi elérhetővé.
