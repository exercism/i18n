# Bevezetés

A függvénydeklarációk és a függvénykifejezések mellett a JavaScriptnek van egy másik, nagyon tömör szintaxisa is függvények definiálására.
Ezeket a függvényeket _nyílfüggvényeknek_ nevezzük.

Ebben a fogalomban arra a szintaxisra összpontosítunk, amivel egy nyílfüggvényt leírunk.
A nyílfüggvények működése több szempontból is eltér, például a `this` kötésében, de ezekkel más fogalmakban foglalkozunk majd.

Íme egy összehasonlítás egy függvénydeklaráció és egy nyílfüggvény között.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

A fentiekben láthatod, hogy a nyílfüggvény szintaxisa:

1. eltávolítja a `function` kulcsszót
2. az `addUpTwoNumbers` azonosítót `const`-ként deklarálja
3. hozzáad egy vastag nyilat (`=>`)

Ha a függvény törzse csak egy `return` utasítást tartalmaz, mint a fenti példában, akkor a `{}` és a `return` kulcsszó elhagyható.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

Ha egy nyílfüggvényből csak egy objektumot adunk vissza, akkor a `return` utasítás elhagyásához zárójelbe kell tenni az objektumot.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

A paraméterek körüli zárójel használata a paraméterek számától függ.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
