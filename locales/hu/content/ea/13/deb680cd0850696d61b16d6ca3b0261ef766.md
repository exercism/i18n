# Bevezetés

A [Go](https://golang.org) egy statikusan típusos, fordított programozási nyelv.
Ez a feladat a nyelv három fontos jellemzőjét mutatja be: a csomagokat, a függvényeket és a változókat.

## Csomagok

A Go-alkalmazások csomagokba szerveződnek.
Egy csomag az ugyanabban a könyvtárban található forrásfájlok gyűjteménye.
Egy könyvtár összes forrásfájljának ugyanazt a csomagnevet kell használnia.
Amikor importálsz egy csomagot, csak azok az entitások (függvények, típusok, változók, konstansok) használhatók és érhetők el, amelyeknek a neve nagybetűvel kezdődik.
A Go ajánlott elnevezési stílusa szerint az azonosítókat `camelCase` stílusban nevezzük el, kivéve azokat, amelyeknek csomagokon átnyúlóan elérhetőnek kell lenniük, mert azokat `PascalCase` stílusban kell írni.

```go
package lasagna
```

## Változók

A Go statikusan típusos, ami azt jelenti, hogy minden változónak [már fordításkor meg kell lennie a típusának](https://en.wikipedia.org/wiki/Type_system).

A változókat definiálhatod úgy, hogy kifejezetten megadod a típusukat:

```go
var explicit int // Explicitly typed
```

Használhatsz kezdőértéket is, ilyenkor a fordító a kezdőérték típusának megfelelő típust rendeli a változóhoz.

```go
implicit := 10   // Implicitly typed as an int
```

Amiután egy változót deklaráltál, az `=` operátorral adhatsz neki értéket.
Egy változó típusa a deklaráció után soha nem változhat meg.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Konstansok

A konstansok ugyanúgy egy adatot tárolnak, mint a változók, de az értékük a program futása közben nem változhat meg.

A konstansokat a `const` kulcsszóval definiáljuk, és lehetnek számok, karakterek, stringek vagy Boolean értékek:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Függvények

A Go-függvények nulla vagy több paramétert fogadnak.
A paraméterek típusát mindig meg kell adni, itt nincs típuskövetkeztetés.

A függvények a `return` kulcsszóval adják vissza az értékeket.

Egy függvényt úgy hívunk meg, hogy megadjuk a nevét, és minden paraméteréhez átadunk egy argumentumot.

Fontos, hogy a Go kétféle megjegyzést támogat.
Az egysoros megjegyzések előtt `//` áll, a többsorosakat pedig `/*` és `*/` közé írjuk.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
