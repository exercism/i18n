# Bevezetés

## Feltételes utasítások

A feltételes utasítások olyan döntéshozó utasítások, amelyek vagy mellékhatásokat hajtanak végre, vagy egy program végrehajtásának menetét szabályozzák.
A feltételes utasítások közé tartozik az `if`, az `if/else`, a `switch` és a `ternary` utasítás.

A feltételes utasításokat arra használjuk, hogy kérdéseket tegyünk fel egy értékről vagy értékek viszonyáról.
A kérdés kiértékelése Boolean-választ ad, de maga az `if` elágazás bármilyen értéket visszaadhat, vagy egyszerűen csak végrehajthat egy mellékhatást.

## If-elágazások

A legegyszerűbb `if` elágazás kiértékel egy kifejezést, és végrehajt egy sort.
A vizsgált kifejezést mindig zárójelbe tesszük.

Végrehajthat egy mellékhatást

```c
if (count > 10)
    printf("count is greater than 10");
```

vagy megváltoztathatja a végrehajtás menetét


```c
if (count > 10)
    return sum;
```

Ha egy `if` elágazás egynél több sort hajt végre, a sorokat kapcsos zárójelbe kell tennie

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Egyes fejlesztőcsapatok előírhatják, hogy az `if` elágazások mindig használjanak kapcsos zárójelet, még egyetlen sor esetén is.


## If else

Egy `if` elágazás összekapcsolható egy `else` ággal

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## If else if


Az `else` összekapcsolható egy másik `if` elágazással, létrehozva az úgynevezett `if-else-if ladder` szerkezetet.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Switch


Néha egy `if-else-if ladder` jobban ábrázolható egy `switch` utasítással.
Az `if`-hez hasonlóan a vizsgált kifejezést mindig zárójelbe tesszük.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

A `default` ág akkor fut le, ha a vizsgált érték nem egyezik egyetlen korábbi ággal sem.

Ha egy `switch` ág nem ad vissza értéket, akkor általában egy `break` zárja le az egyes ágakat, különben a vezérlés „átesik” a következő ágra.
Néha az átesést szándékosan használják

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Ha az átesés véletlenül történik, az egy bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

A `switch` akkor lehet előnyös, ha konkrét értékeket vizsgálunk egy értéktartomány helyett.
Gyorsabb lehet, mint egy `if-else-if ladder`, mert a fordító képes lehet optimalizálni a `switch` utasítást olyan módokon, amelyekre egy létrával nem.
A `switch` néha olvashatóbbnak tűnhet, mint egy létra.

## Ternary (más néven feltételes) operátor

A ternary operátor egy háromrészes feltételes utasítás, amelyet gyakran egy érték beállítására használnak.
A vizsgálandó kifejezés a kérdőjel előtt van, és nem kell zárójelbe tenni.
Az igaz esetén visszaadott érték a kettőspont előtt, a hamis esetén visszaadott érték pedig a kettőspont után van.
Akár értékliterál, akár változó visszaadható.

```c
int i = j > 5 ? 5: j;
```

A ternary operátorok egymásba ágyazhatók a szintaktikai zsúfoltság csökkentésére.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
