# Tippek

## Általános

- A Python dokumentációjának [stringekről szóló bevezetője][python-str-doc] áttekintést ad a Python `str` típusáról.
- A [`str.join()`][str-join] és a [`str.split()`][str-split] string-metódusok nagyon hasznosak a stringek feldolgozásakor.
- A Python dokumentációjának [szekvenciatípusokról szóló része][common sequence operations] összefoglalja az összes szekvenciára jellemző műveleteket, beleértve a `strings`, `lists`, `tuples` és `ranges` típusokat is.

A feladat négy részfeladatból áll, mindegyikhez tartozik egy szöveg vagy szavak, amelyekkel dolgozni kell.

## 1. Adj előtagot egy szóhoz

- A rövid stringek összefűzhetők a `+` operátorral.

## 2. Adj előtagot szócsoportokhoz

- Akár hiszed, akár nem, itt mindössze a [`str.join()`][str-join] kell. **Ciklusra nincs szükség.**
- A tesztek egy `list`-et adnak majd a függvényednek. Nem kell módosítanod ezt a `list`-et, ha sikerül kitalálnod egy jó elválasztó stringet.
- Ne feledd, hogy az elválasztó stringek az elemek közé kerülnek, és egyetlen stringgé „ragasztják” össze őket. Az elválasztók szóköz _nélkül_ illesztődnek be, bár magukba az elválasztókba tehetsz szóköz karaktereket.
- A [`str.split()`][str-split]hez hasonlóan a `str.join()` is képes tetszőleges hosszúságú stringet feldolgozni, amely bármilyen Unicode kódpontból állhat. A `str.split()`-tel _ellentétben_ azonban tetszőleges hosszúságú iterálhatókat is képes feldolgozni, például `list`, `tuple` és `set` típusokat.

## 3. Távolíts el egy utótagot egy szóból

- A stringek indexelhetők vagy szeletelhetők balról (0-tól indulva) vagy jobbról (-1-től indulva).
- Ha egy tetszőleges hosszúságú string utolsó kódpontját szeretnéd, használhatod a `[-1]`-et.
- A string utolsó három betűje „levágható” negatív indexszel. Pl. `beautiful'[:-3] == 'beauti`

## 4. Nyerj ki és alakíts át egy szót

- A [`str.split()`][str-split] használata egy `list`-et ad vissza, amely a szóközök mentén feldarabolt stringekből áll.
- A `lists` szekvenciák, és indexelhetők.
- A [`str.split()`][str-split] közvetlenül is indexelhető: `'Exercism rocks!'.split()[0] == 'Exercism'`
- Vigyázz az írásjelekkel! A pontok szelettel eltávolíthatók: `'dark.'[:-1] == 'dark'`
