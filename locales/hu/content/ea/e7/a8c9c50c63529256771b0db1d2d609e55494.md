# Bevezetés

A komprehenziók segítségével könnyedén és deklaratív módon alakíthatod át az _Enumerables_ értékeit.

Egy nagyon egyszerű komprehenzióhoz használhatod a `for` kulcsszót, amelyet egy _generátor_ és egy _do-blokk_ követ, ez utóbbi pedig a felsorolt értékekből állítja elő az új értékeket.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

A komprehenzióknak _szűrőik_ is lehetnek. Azok az értékek, amelyek nem mennek át a szűrőn, kimaradnak a végső listából:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Bonyolultabb komprehenziókat több sorba is írhatsz:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

Több generátor használatával _Descartes-szorzat_ is létrehozható. Ez azt jelenti, hogy az első generátor minden egyes értéke pontosan egyszer párosul a második generátor minden egyes értékével:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
