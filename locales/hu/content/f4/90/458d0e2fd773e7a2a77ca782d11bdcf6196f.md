# Utasítások

Lucian barátnője éppen hazafelé tart, és Lucian még nem készítette el az évfordulós vacsorájukat!

Ebben a feladatban kódot írsz, hogy segíts Luciannak elkészíteni egy ínycsiklandó lasagnét a kedvenc szakácskönyvéből.

Négy részfeladat vár rád, mindegyik a lasagne elkészítésével töltött időhöz kapcsolódik.

## 1. Határozd meg a várható sütési időt percben

Definiáld az `ovenTime()` függvényt, amely nem fogad argumentumot, és visszaadja, hány percig kell a lasagnének a sütőben lennie.
A szakácskönyv szerint a várható sütési idő 40 perc:

```cpp
ovenTime();
// => 40
```

## 2. Számítsd ki a hátralévő sütési időt percben

Definiáld a `remainingOvenTime(int actualMinutesInOven)` függvényt, amely argumentumként megkapja, hogy a lasagne hány perce van a sütőben, és visszaadja, hogy a lasagnének még hány percig kell a sütőben maradnia, az előző részfeladatban megadott várható sütési idő alapján.

```cpp
remainingOvenTime(30);
// => 10
```

## 3. Számítsd ki az előkészítési időt percben

Definiáld a `preparationTime(int numberOfLayers)` függvényt, amely argumentumként megkapja, hány réteget raktál a lasagnére, és visszaadja, hány percet töltöttél a lasagne elkészítésével, feltéve, hogy egy réteg elkészítése 2 percet vesz igénybe.

```cpp
preparationTime(2);
// => 4
```

## 4. Számítsd ki az eltelt időt percben

Definiáld az `elapsedTime(int numberOfLayers, int actualMinutesInOven)` függvényt, amely két argumentumot vár: az első argumentum a lasagnére rakott rétegek száma, a második pedig az, hogy a lasagne hány perce van a sütőben. A függvény adja vissza, hány percet dolgoztál a lasagne elkészítésén, ami az előkészítési idő percben és a lasagne által a sütőben eddig eltöltött idő összege.

```cpp
elapsedTime(3, 20);
// => 26
```
