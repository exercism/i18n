# Bevezetés

A tuple értékek sorrenddel rendelkező tárolója. Mint minden Gleam-adattípushoz hasonlóan a tuple-ok is megváltoztathatatlanok. Egy tuple minden eleme lehet más típusú, sőt akár maguk az elemek is lehetnek további tuple-ok.

A tuple-ok vesszővel elválasztott értékek a `#(` és a `)` között: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Az azonos hosszúságú és azonos típusú (ugyanabban a sorrendben szereplő) tuple-ok összehasonlíthatók egyenlőség szempontjából.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Háromféleképpen juthatsz hozzá a tuple-ban tárolt értékekhez:

- Indexelés.
- Mintaillesztés `let`-tel.
- Mintaillesztés `case`-szel.

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
