# Bevezetés

A *tuple* a Factor rekord-, struct- és osztálytípusa. Minden tuple-osztálynak rögzített, névvel ellátott mezőkészlete van, és a Factor automatikusan generál hozzájuk gettereket és settereket.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

A `boa` (az argumentumok sorrendjében) a veremből, a deklaráció sorrendjében tölti fel a mezőket. A `new` minden mezőt a deklarált `initial:` értékére állítva épít fel egy példányt (vagy `f`-re, ha nincs megadva).

Az egyes mezők gettere `slot>>`, a settere `>>slot`; a setter *módosítja* az objektumot, ezért ha nem destruktív frissítésre van szükséged, előbb hívd meg a `clone`-t:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

A mezők alapértékét a `{ name initial: value }` forma adja meg; `initial:` nélkül az alapérték `f`.
