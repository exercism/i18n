# Utasítások

Ebben a feladatban egy hasznos segédprogramot írsz, hogy ne kelljen fejben tartanod a sávok értékeit.
A program bemenetként 1, 4 vagy 5 színt kap, és ohmban adja meg a helyes értéket.
A színsávok kódolása a következő:

| Szín   | Érték |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

A [`Resistor Color Trio`][resistor-color-trio-exercise] feladatban az első három színsávot fejtetted meg.
Például: az orange-orange-brown a `330` fő értéket jelentette.
Ebben a feladatban most a _tűrést_ is hozzávesszük.
A tűrés azt mutatja, hogy egy érték legfeljebb mennyivel lehet a fő érték felett vagy alatt.
Például ha az utolsó sáv a green, a legnagyobb tűrés `±0.5%` lesz.

A tűréssáv értéke a következők egyike lehet:

| Szín   | Tűrés     |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

A négy sávos ellenállás felépítése a következő:

| 1. sáv  | 2. sáv  | 3. sáv     | 4. sáv    |
| ------- | ------- | ---------- | --------- |
| 1. érték | 2. érték | szorzó | tűrés |

Példák:

- Az orange-orange-brown-green `330` ohmot ad `±0.5%` tűréssel.
- Az orange-orange-red-grey `3300` ohmot ad `±0.05%` tűréssel.

A négy- és az ötsávos ellenállás között az a különbség, hogy az ötsávoson van egy plusz sáv, amely pontosabb értéket jelez.

| 1. sáv  | 2. sáv  | 3. sáv  | 4. sáv     | 5. sáv    |
| ------- | ------- | ------- | ---------- | --------- |
| 1. érték | 2. érték | 3. érték | szorzó | tűrés |

Példák:

- Az orange-orange-orange-black-green `333` ohmot ad `±0.5%` tűréssel.
- Az orange-red-orange-blue-violet `323 million` ohmot ad `±0.1%` tűréssel.

Léteznek egysávos ellenállások is.
Az egysávos ellenálláson csak a black szín szerepel, 0 értékkel.

A programodnak az ellenállássávok színeit tartalmazó bemeneti `list`-ből egy címkét kell előállítania:

"... ohms ±...%"

Tehát a `["orange", "orange", "black", "green"]` bemeneti `list` esetén ezt kell visszaadnia:

"33 ohms ±0.5%"

Amikor több ezer ohmról van szó, „kiloohms”-ot mondunk.
Ez ahhoz hasonló, mint amikor 1000 méternél „kilométer”-t, 1000 grammnál „kilogramm”-ot mondunk.

Tehát a `["orange", "orange", "orange", "grey"]` bemeneti `list` esetén ezt kell visszaadnia:

"33 kiloohms ±0.05%"

Amikor több millió ohmról van szó, „megaohms”-ot mondunk.

Tehát a `["orange", "orange", "blue", "red"]` bemeneti `list` esetén ezt kell visszaadnia:

"33 megaohms ±2%"
