# kernel format

A `format` metódus mellett a Rubyban gyakran [string-interpoláció](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) segítségével hozunk létre stringeket. Például:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
