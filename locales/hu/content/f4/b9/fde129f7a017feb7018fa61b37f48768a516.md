# Névjegy

Mostanra már tudod, hogyan kell bejárni egy szeletet vagy egy mapet Go-ban.

Ismétlésként: megtanultad, hogy minden iteráció két értéket ad vissza, az indexet vagy kulcsot, valamint az adott indexen vagy kulcson lévő elem egy másolatát.

## Szelet bejárása

Gyerekjáték: a szelet bejárása a várt sorrendben történik.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Map bejárása

A map bejárása új problémát vet fel: a sorrend most véletlenszerű.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
Úgy tűnhet, hogy a fenti kimenet hibás, hiszen azt várnánk, hogy a map deklarálásakor szereplő első kulcs-érték pár, `9 10`, elsőként jelenik meg a kimenetben, nem pedig utolsóként.
A mapek azonban természetüknél fogva rendezetlenek, nincs köztük első vagy utolsó kulcs-érték pár.
Emiatt amikor egy map bejegyzésein iterálsz, a bejegyzések bejárási sorrendje véletlenszerű lesz, és nem követ semmilyen meghatározott mintát.
Ez azt jelenti, hogy a fenti kimenet lehetséges, de eltérhet attól, amit akkor kapsz, ha ezt magad is lefuttatod.
Ha többet szeretnél megtudni erről, nézd meg a [Go nyelvi specifikáció: range záradék](https://go.dev/ref/spec#RangeClause) oldalt.
~~~~

## Iteráció a kulcs vagy az érték elhagyásával

Go-ban egy fel nem használt változó hibát okoz fordításkor.
Néha csak az értékre van szükséged, ahogy az első példában is:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Az `i` helyére `_`-t írhatsz, ami jelzi a fordítónak, hogy nem használjuk azt az értéket:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Ha csak az indexet szeretnéd kiírni, az `x` helyére is `_`-t írhatsz, vagy egyszerűen elhagyhatod a deklarációt:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

Végül, de nem utolsósorban, ha végre kell hajtanod valamilyen műveletet, de nem érdekelnek a szelet vagy a map értékei és kulcsai, akkor az indexet és az értéket is elhagyhatod:

```go
xi := []int{10, 20, 30}
count := 0
for range xi {
  count++
}
// count value:
// 3
```
