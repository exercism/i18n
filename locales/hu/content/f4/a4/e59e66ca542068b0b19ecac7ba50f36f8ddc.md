# Szétbontás

A szétbontás során egy elemet az alkotórészeire bontunk, és mindegyiket egy-egy kisebb változóhoz kötjük.

## Tuple-ök szétbontása

A tuple-ök szétbontása egyszerű: csak rendelj a tuple minden mezőjéhez egy-egy új változónevet:

```rust
let (first, second) = (1, 2);
```

## Tuple structok szétbontása

A tuple structok szétbontása ugyanolyan, mint a tuple-ök szétbontása, csak a struct nevét is oda kell írni:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## Structok szétbontása

A structok szétbontása hasonló a tuple structok szétbontásához. Csak használd a mezőneveket:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## Részleges szétbontás

A `..` operátorral szétbontáskor figyelmen kívül hagyhatsz néhány mezőt:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## Feltételes szétbontás

A structok és tuple-ök szétbontása nem hibázhat. Az enum típusokat viszont szintén szét lehet bontani, az `if let`, a `while let` és a `match` nyelvi szerkezet használatával.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
