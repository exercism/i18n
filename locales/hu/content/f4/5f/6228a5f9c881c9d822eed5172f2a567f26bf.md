# Bevezetés

A Factor asszociatív tömbjei (a hashtáblák és rokonaik) egy közös
[protokollt][assoc-protocol] osztanak meg, amely az [`assocs`][assocs] szótárból
származik. A hashtábla literál alakja a `H{ }`:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

Gyakori műveletek:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

A hashtáblák *módosíthatók*: a módosítás előtt `clone`-ozd le az `H{ }`
literált, hogy a literál ne legyen megosztva a hívások között.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
