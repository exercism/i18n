# Utasítások

Az alapoktól kiindulva alakítsd át a stringként megadott hármas számrendszerű számot (például '102012') a tízes számrendszerbeli megfelelőjévé.

A programnak a szabálytalan hármas számrendszerű számot megadó stringeket 0 értékként kell kezelnie.

A hármas számrendszerű számok három jelet tartalmaznak: 0, 1 és 2.

A hármas számrendszerű szám utolsó helyiértéke az egyesek helye, a hátulról második a hármasoké, a hátulról harmadik a kilenceseké, és így tovább.

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

Ha a programozási nyelved szabványos könyvtára kínál egy metódust az átalakításra, tegyél úgy, mintha nem létezne, és magad implementáld.
