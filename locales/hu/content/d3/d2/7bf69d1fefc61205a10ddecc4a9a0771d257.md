# Használj string interpolációt a string-összefűzés helyett

Ha dinamikusan szeretnél összeállítani egy stringet, használj [string interpolációt](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/) a string-összefűzés helyett. A legfőbb előnye, hogy kevesebb a „zaj”: míg a string-összefűzésnél minden string közé `+` jelet kell tenni, a string interpolációnál nincs ilyen megkötés. Emiatt a string interpolációt használó kód általában egy kicsit könnyebben olvasható.
