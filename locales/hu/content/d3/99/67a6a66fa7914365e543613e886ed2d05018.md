# Bevezetés

## A `use` kifejezések használata

Gleamben gyakori, hogy magasabb rendű függvényeket írunk és használunk, vagyis olyan függvényeket, amelyek más függvényeket fogadnak argumentumként. Előfordul, hogy amikor egyszerre sok magasabb rendű függvényt használunk, a kód a sok behúzási szint miatt nehezen olvashatóvá válik.

Például itt van egy függvény, amely több olyan függvényt hív meg, amelyek `Result(Int, Nil)` értéket adnak vissza, és összegzi az értékeket, ha mind a négy sikeres.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

A Gleam `use` kifejezéseivel ezt a kódot behúzás nélkül is leírhatjuk, ami gyakran olvashatóbbá teszi.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

A `use` kifejezés összegyűjti a blokkban utána következő összes utasítást, és azokat callback függvényként adja át a függvényhívás utolsó argumentumaként. A `use` kulcsszó és a `<-` szimbólum között álló változók azoknak az argumentumoknak a nevei, amelyeket a callback függvény meg fog kapni.

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

A callback függvény tetszőleges számú argumentumot kaphat, de akár egyet sem.

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

Nincs különösebb követelmény az olyan függvények létrehozásához, amelyeket `use` kifejezéssel lehet meghívni, azon kívül, hogy utolsó argumentumként egy callback függvényt fogadnak.

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

A Gleam `use` kifejezései nagyon hatékony lehetőséget kínálnak, és sok problémára alkalmazhatók, de ha túl sokat használjuk őket, nehezen olvashatóvá tehetik a kódot. Általában jobb a szokásos függvényhívási szintaxist használni, és csak akkor nyúlni a `use` kifejezésekhez, amikor olvashatóbbá teszik a kódot.
