# Részletesen

A Boolean típusnak Lua-ban két hagyományos értéke van: `true` és `false`. Ezek az értékek hozzárendelhetők egy változóhoz, kombinálhatók logikai operátorokkal (`and`, `or`, `not`), és feltételes vizsgálatokban használhatók (például vezérlési szerkezetekben).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

A feltételes vizsgálatok és a logikai operátorok a Boolean `false`-t és a `nil`-t is hamisnak tekintik, minden mást pedig igaznak.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Az `and` és az `or` is *rövidzár-kiértékelést* használ, ami azt jelenti, hogy a második operandusukat csak akkor értékelik ki, amikor erre szükség van. Minden művelet kiértékelése az [operátorprecedencia](https://www.lua.org/manual/5.4/manual.html#3.4.8) szerint történik, ahol a `not` az `and` és az `or` előtt értékelődik ki.

Mivel csak a `false` és a `nil` számít hamisnak, minden más pedig igaznak, a Lua-ban gyakori idióma a következő:
```lua
x = x or y
```

Ez megegyezik a következővel:
```lua
if not x then
  x = y
end
```

Gyakori, hogy ezt függvényekben arra használjuk, hogy alapértelmezett értéket adjunk egy paraméternek, ha annak nincs értéke (azaz `nil`):
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
