# Bevezetés

A metódusoknak lehet változó számú paraméterük, amely lehetővé teszi, hogy a hívó nulla vagy több argumentumot adjon meg, mintha azok normál paraméterek lennének. A metódus ezeket az argumentumokat egyetlen tömbként kapja meg.

Ahhoz, hogy egy paraméter változó számú paraméter legyen, add hozzá a `params` kulcsszót a paraméterdeklarációhoz:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
