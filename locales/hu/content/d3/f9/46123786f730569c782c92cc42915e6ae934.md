# Utasítások

Amikor épp sütiket készülsz sütni a barátaidnak, rájössz, hogy a receptben szereplő mérések egy részét át kell váltanod. Mivel csak a metrikus rendszert ismered, ki kell találnod egy módot arra, hogy a gyakori amerikai konyhai mértékegységeket milliliterre (mL) váltsd a saját kényelmed érdekében.

Használd ezt az átváltási táblázatot a megoldásodhoz:

| Átváltandó mértékegység | térfogat | milliliterben (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| amerikai csésze          | 1      | 240                 |
| amerikai folyadék uncia  | 1      | 30                  |
| amerikai teáskanál     | 1      | 5                   |
| amerikai evőkanál   | 1      | 15                  |

Mivel tehetséges programozópalánta vagy, úgy döntesz, hogy a millilitert használod átmeneti mértékegységként, hogy megkönnyítsd bármely felsorolt mértékegység átváltását bármely másikra (még önmagára is).

## 1. Keresd ki a numerikus komponenst egy térfogatpárból

Valósítsd meg a `KitchenCalculator.get_volume/1` függvényt. Egy térfogatpár tuple esetén csak a numerikus komponenst adja vissza.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Váltsd át a térfogatpárt milliliterre

Valósítsd meg a `KitchenCalculator.to_milliliter/1` függvényt. Egy térfogatpár tuple esetén az átváltási táblázat segítségével milliliterre kell váltania a térfogatot.

Használj több függvényklózt és mintaillesztést az egyes mértékegységekhez tartozó függvények létrehozásához. Az egyes mértékegységeket jelölő atomok: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. Az átváltás eredményét tuple-be csomagolva add vissza.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Váltsd át a milliliteres térfogatpárt másik mértékegységre

Valósítsd meg a `KitchenCalculator.from_milliliter/2` függvényt. Egy térfogatpár tuple és a kívánt mértékegység esetén az átváltási táblázat segítségével a kívánt mértékegységre kell váltania a térfogatot.

Használj több függvényklózt és mintaillesztést az egyes mértékegységekhez tartozó függvények létrehozásához. Az egyes mértékegységeket jelölő atomok: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Váltsd át bármely mértékegységből bármelyikbe

Valósítsd meg a `KitchenCalculator.convert/2` függvényt. Egy térfogatpár tuple és a kívánt mértékegység esetén a megadott térfogatot a kívánt mértékegységre kell váltania.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
