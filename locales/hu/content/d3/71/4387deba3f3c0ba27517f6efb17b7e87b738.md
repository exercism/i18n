# Bevezetés

A Pyretnek két különálló Boolean primitíve van, a `true` és a `false`.
Ez a két érték azt fejezi ki, hogy egy állítás vagy feltétel igaz-e vagy hamis.

```pyret
"a" == "a" # true
"a" == "b" # false
```

A Pyret biztosítja az `and` és az `or` operátorokat, amelyekkel Boolean értékeket kombinálhatsz.

Az and operátor igazat ad vissza, ha mindkét oldal igaz, minden más kombináció esetén pedig hamisat.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

Az or operátor igazat ad vissza, ha legalább az egyik oldal igaz, és hamisat, ha mindkét oldal hamis.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

A `not()` egy beépített függvény, amely igazat hamisra vagy hamisat igazra fordít.

```pyret
not(true) # false
not(false) # true
```
