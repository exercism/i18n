# Részletesen

A [struktúrák][structs-and-classes] (amelyeket gyakran *struct*nak neveznek) a Swift-programok egyik elsődleges építőköve. A struktúrákkal egyéni típusokat hozhatsz létre, amelyek a kapcsolódó tulajdonságokat (adatokat) és metódusokat (viselkedést) csoportosítják. Valójában a Swift szabványos típusai, köztük az `Int`, a `Double`, a `Bool`, a `String`, az `Array` és a `Dictionary`, mind struktúraként vannak megvalósítva.

## Struktúrák definiálása

A struktúrát a `struct` kulcsszóval definiálod, amelyet a típus neve követ, majd a definíciót tartalmazó kapcsos zárójelek. A Swift konvenciója szerint a struktúrák neve `UpperCamelCase` stílusban íródik:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Példányok létrehozása

A struktúra definíciója csupán egy tervrajz. Egy struktúra *példányának* létrehozásához hívd meg a kezdőértékét: írd le a típus nevét, majd egy zárójelpárt:

```swift
var someStats = CharacterStats()
```

Ez létrehoz egy példányt, amely a definícióban megadott alapértelmezett tulajdonságértékekkel töltődik fel.

A Swift emellett automatikusan létrehoz a struktúrákhoz egy **tagonkénti kezdőértéket**, amellyel név szerint adhatod meg a tulajdonságok értékét:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Tulajdonságok elérése és módosítása

Egy példány tulajdonságait *pontjelöléssel* érheted el és módosíthatod:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Mivel a struktúrák értéktípusok, egy példány tulajdonságainak módosításához magát a példányt `var` kulcsszóval kell deklarálni. Ha a példányt `let` kulcsszóval deklarálod, minden tulajdonsága megváltoztathatatlanná válik.
