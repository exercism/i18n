# Bemutatás

Az Elm egy élvezetes nyelv megbízható webalkalmazások építésére.
Barátságos hibaüzenetek, kiváló teljesítmény, kis méretű erőforrások, és nincsenek futásidejű kivételek.

Az Elm talán leghíresebb és legszélesebb körben másolt része a The Elm Architecture, amely egy egyszerű minta a webalkalmazások felépítésére, és minden Elm-webalkalmazás így készül.

A lényeg, hogy a kódod egy `Model` köré épül, amely az alkalmazásod állapotát írja le; van egy mód a modelled frissítésére (`update`), és egy mód a modelled megjelenítésére (`view`).

A `Model` tartalmazza az alkalmazás állapotát, vagyis minden adatot, amire az alkalmazásnak szüksége van.
Ha elképzelsz egy egyszerű alkalmazást egy beviteli mezővel és egy szöveggel, amely a beírt szöveg fordítottját mutatja, a modell a lentihez hasonlóan nézne ki.
Ezt a példát megnézheted az [Elm Guide][elm-guide-text-fields] oldalon is.

```elm
type alias Model =
  { text : String
  }
```

Az `update` egy függvény, amelyet egy `Msg`-sel hívunk meg, amikor történik valami változás (például a felhasználó rákattint egy gombra).
Megkapja a `Msg`-et és az aktuális `Model`-t, és visszaad egy új `Model`-t.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

A `view` egy függvény, amely HTML-t ad vissza, amit a böngésző megjelenít a felhasználónak.
Megkapja az aktuális `Model`-t, és visszaad egy `Html Msg`-t (ezt a típust használja az Elm a HTML megjelenítésére).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
