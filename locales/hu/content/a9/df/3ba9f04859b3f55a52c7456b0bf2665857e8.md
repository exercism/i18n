# Utasítások

Miközben tovább dolgozol az _Instruments of Texas_-nál, szépen halad az RPN-számológép Elixir-implementációja. A csapatod olyan hibákat szeretne dobni, amelyek konkrétabbak, mint a standard könyvtár által biztosított általános hibák. Épp kutatást végzel, de úgy döntöttetek, hogy létrehoztok két új hibát, amelyek megvalósítják az _Exception Behaviour_-t.

## 1. Hiba nullával való osztás esetén

Egy szám nullával való osztása definiálatlan eredményt ad, amit a csapat szerint a legjobban egy hiba fejez ki.

Úgy valósítsd meg a `DivisionByZeroError` modult, hogy a hibaüzenete a következő legyen: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Hiba verem alulcsordulás esetén

Az RPN-számológépek _vermet_ használnak, hogy nyilvántartsák a számokat, mielőtt összeadnák őket. A csapat ezt a _vermet_ számok listájaként ábrázolja (egészek és lebegőpontos számok), például: `[3, 4.0]`. Minden művelethez adott mennyiségű számnak kell lennie a vermen, hogy elvégezhesse a számítást. Amikor nincs elég szám a vermen, azt verem alulcsordulásnak nevezzük. Valósítsd meg a `StackUnderflowError` kivételt, amely alapértelmezett üzenetet és opcionális kiegészítő kontextust biztosít

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Írj egy osztást végző függvényt

Valósítsd meg a `divide/1` függvényt, amely egy vermet _(két szám listáját)_ kap, és:

- _verem alulcsordulás_ hibát dob, amikor a vermen nincs elég szám
- _nullával való osztás_ hibát dob, amikor az osztó 0 (figyeld meg, hogy a számok verme fordított sorrendben van tárolva)
- elvégzi az osztást, amikor nem dobódik hiba

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> Figyelj, a lista sorrendje fordított!
