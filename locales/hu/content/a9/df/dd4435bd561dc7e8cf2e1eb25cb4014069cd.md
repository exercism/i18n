# Bevezetés

A Gleam szótárai kulcs-érték párokban tárolják az információt. Más nyelvekben ezeket asszociatív tömböknek, hash-eknek vagy szótáraknak is nevezik.

A szótár kulcsaihoz és értékeihez bármilyen típus használható, és a szótár nem garantálja a bejegyzések sorrendjét, amikor azokhoz hozzáférünk vagy azokat visszakapjuk.

## Szótárak használata

A szótárakat a `gleam/dict` modul függvényeivel hozzuk létre és módosítjuk.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
