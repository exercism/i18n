# Bevezetés

A `|>` operátort pipe operátornak hívják. Arra való, hogy függvényhívásokat fűzz egymás után úgy, hogy az előző hívás visszaadott értéke a következő hívásnak adódjon át.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

A fenti kód ugyanazt jelenti, mint az alábbi:

```gleam
string.append(string.uppercase("hello"), "?!")
```

A pipe operátor vagy első argumentumként adja át az értéket a függvényhívásnak, vagy egyetlen argumentumként egy új hívásnak, aszerint, hogy melyik esetben lesz a típus helyes.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Néha az értéket egy másik pozícióba szeretnénk átadni. Ilyenkor a `_` helyőrzővel jelölheted, hogy hova kerüljön az érték.

```gleam
100
|> some_function(1, _, 2)
```
