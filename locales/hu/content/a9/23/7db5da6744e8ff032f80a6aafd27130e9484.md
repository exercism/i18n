# Bevezetés

## Tömbök

A Rubyban a **tömbök** rendezett, egész számokkal indexelt gyűjtemények, amelyek bármilyen objektumot tartalmazhatnak.
A tömbök indexelése `0`-tól indul.
A negatív index a tömb végétől számítva értendő. A `-1` index például az utolsó elemre mutat, a `-2` az utolsó előttire, és így tovább.

### Tömbök létrehozása

A tömböket általában a `[]` jelöléssel hozzuk létre.
Bármilyen típusú objektumot tartalmazhatnak.

```ruby
array = [1, "two", 3.0]
```

### Elemekre hivatkozás

A tömb elemeit az indexeik alapján kérhetjük le a `#[]` metódussal.
Ez visszaadja az adott indexű elemet, vagy egy altömböt ad vissza, amely a kezdőindexnél kezdődik és a megadott hosszon át tart.
A negatív indexek a tömb végétől visszafelé számolnak.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### Segédmetódusok

A tömbökön sok hasznos segédmetódus érhető el.
Íme néhány a gyakoribbak közül:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## Felsorolás

Ahelyett, hogy ciklusokkal iterálnánk végig a gyűjteményeken, a Rubyban felsorolást használunk.

A felsorolás során végiglépkedünk egy gyűjteményen (ebben az esetben egy tömbön), és valamilyen műveletet hajtunk végre minden objektumon. A felsorolás kulcsfontosságú fogalom a Rubyban, és olyan dolgokra használjuk, mint a rendezés, csoportosítás, leképezés, redukálás és még sok más.

Egy felsorolás, amely kiírja a tömb minden szavát, így néz ki:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

Ebben a példában a `.each` metódust hívtuk meg a tömbünkön, és átadtunk neki egy _blokkot_, amely egy paramétert (`word`) vesz át, és kiírja azt.

A _blokkokat_ sokkal részletesebben is megvizsgáljuk majd később a kurzus során, egyelőre azonban gondolj rájuk úgy, mint névtelen függvényekre, amelyek nulla vagy több argumentumot vehetnek át.
A `do...end` szintaxissal (fent) vagy a `{}` szintaxissal (lent) definiálhatók.

Íme néhány további példa olyan tömbmetódusokra, amelyek blokkokat használnak:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
