# Részletesen

A `use` makró lehetővé teszi, hogy gyorsan bővítsük a modulunkat egy másik modul által nyújtott funkcionalitással. Amikor `use`-olunk egy modult, az a modul kódot injektálhat a modulunkba, például definiálhat függvényeket, `import`-álhat vagy `alias`-olhat más modulokat, vagy beállíthat modulattribútumokat.

Ha valaha is megnézted az Exercism-ön néhány Elixir feladat tesztfájlját, valószínűleg észrevetted, hogy mindegyik `use ExUnit.Case`-tal kezdődik. Ez az egyetlen kódsor teszi elérhetővé a `test` és `assert` makrókat a tesztmodulban.

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## `__using__/1` makró

Hogy pontosan mi történik, amikor `use`-olsz egy modult, azt az adott modul `__using__/1` makrója határozza meg. Egy argumentumot vár, egy kulcsszólistát a beállításokkal, és egy [idézett kifejezést][concept-ast] ad vissza. Az ebben az idézett kifejezésben lévő kód bekerül a modulunkba, amikor a `use`-t hívjuk.

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

A beállítások megadhatók második argumentumként a `use` hívásakor, pl. `use ExUnit.Case, async: true`. Ha nincsenek kifejezetten megadva, egy üres listára állnak be.

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
