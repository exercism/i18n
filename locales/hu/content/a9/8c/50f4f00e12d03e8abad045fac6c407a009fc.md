# Névjegy
A ciklus arra való, hogy egy vagy több utasítást ismételten meghívjunk egy kötegben.
Az utasítások egy kötegének minden lefutását iterációnak nevezzük.

## While ciklus

A `while` ciklus addig hajt végre egy köteg utasítást, amíg a ciklus elején lévő Boolean kifejezés igaz.
Amikor a Boolean kifejezés hamis, a ciklus leáll, és a végrehajtás a ciklus utáni következő kódsorra folytatódik.

Ha a Boolean kifejezés már az elejétől hamisra értékelődik, a `while` ciklus egyáltalán nem fut le, és a végrehajtás a ciklus utáni következő kódsorra folytatódik.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Fontos, hogy legyen egy feltétel, amely lezárja a ciklust; különben végtelen ciklus lesz, amely megakadályozza a kód előrehaladását.
Ha a fenti kódból eltávolítanánk a `++`-t az `i` mellől, az végtelen ciklus lenne.

## Do ciklus

A `do` ciklusnál a Boolean kifejezést a ciklus alján vizsgáljuk.
A `do` ciklus mindig lefut legalább egyszer, ahogy a következő példa mutatja

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Egy `while` ciklussal ez bőbeszédűbb lenne

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## For ciklus

Gyakran előfordul, hogy egy ciklus frissít egy változót, és akkor ér véget, amikor a változó elér egy bizonyos értéket.
A `for` ciklus arra való, hogy egy sorban, zárójelek között inicializáljunk, frissítsünk és teszteljünk egy vagy több változót.
Az első rész a változó inicializálására szolgál, a második a változó tesztelésére, a harmadik pedig a változó értékének frissítésére.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Ez kevésbé bőbeszédű, mint a `while` ciklus megfelelője, mégis jól olvasható.

A `for` ciklus inicializáló és frissítő részei egynél több változót is kezelhetnek, ha a feltételeken belül vesszőoperátorral választjuk el a kifejezéseket.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Ez a következőt írja ki:

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

A `for` egyik részét sem kell megadni.
Az üres tesztelő kifejezés igazra értékelődik, így egy `for` ciklussal is definiálhatunk végtelen ciklust, például így

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

Ez hasonlít a `while` ciklushoz: az `i` inicializálása a ciklus előtt történik, és a cikluson belül növeljük.
Emellett az `i` tesztelése is a cikluson belül történik, és a ciklus a `break` utasítással ér véget.

## Break utasítás

Néha egy ciklusnak olyan különleges feltétel miatt kell véget érnie, amelyet nem a Boolean kifejezésében tesztelünk.
A `break` utasítás véget vet a ciklusnak, és a végrehajtás a ciklus utáni következő kódsorra folytatódik.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Ez a következőt írja ki:

```
i is 0
j is 5
After the loop
```

## Continue utasítás

Néha előfordulhat, hogy egy ciklusnak el kell kezdenie a következő iterációt anélkül, hogy befejezné az aktuális iterációt.
A `continue` utasítás leállítja az aktuális iteráció végrehajtását, és a következő iteráció elején folytatja a végrehajtást.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Ez a következőt írja ki:

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

Nem írja ki az `i` és `j` értékét, amikor mindkettő `2`.
