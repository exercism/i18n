# Bevezetés

A `switch()` függvény tömör helyettesítője lehet egy hosszú `if` ... `else if` vizsgálatsorozatnak.
A leggyakrabban string az érték, amire váltunk, és ilyenkor a választóból elhagyhatók az idézőjelek.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Vedd észre, hogy az opciók csak akkor esnek át, ha az érték üresen marad, mint az `M` esetében a fenti példában.
Nem kell `break` utasításokat írnod, mint néhány más nyelvben.

Amikor `character` típusra váltunk, az utolsó érték az alapértelmezett, mint itt is.
Egész szám típusoknál nem adható meg alapértelmezett érték.

## Függvények a `dplyr`-ben

A base R-beli `switch` meglehetősen korlátozott: csak egyetlen bemenetre tud pontos egyezést végezni.
Ez észszerűnek tűnt, amikor az R 1993-ban megjelent, de a modern használathoz fejlesztésre szorul.

~~~~exercism/note
Ahogy a [`Conditionals`][concept-conditionals] fogalomnál említettük, a `tidyverse` csomaggyűjtemény célja, hogy kiegészítse (és néha helyettesítse) a base R funkcionalitását anélkül, hogy befolyásolná a visszafelé kompatibilitást.

A `dplyr` csomagot úgy vonhatod be a scope-ba, hogy a kódod elejére írod a `library(dplyr)` (az egyetlen csomaghoz) vagy a `library(tidyverse)` (a teljes gyűjteményhez) utasítást.

~~~~

A `dplyr` könyvtár két extra függvényt biztosít a `switch`-hez kapcsolódóan.

### A `recode_values` és a `replace_values` függvény

Ez a két rokon függvény lehetővé teszi a régi értékek vektorizált, switch-szerű leképezését új értékekre.

A fő különbség köztük az, hogy a `recode_values()` egy teljesen új vektort hoz létre, míg a `replace_values()` egy létező vektor részleges frissítését teszi lehetővé.

Az egyeztetés továbbra is pontos, de:

- A bal oldali opciók lehetnek vektorok, és a bemenet akkor egyezik, ha bármelyik elem egyezik.
- A bal oldali opciókat és a jobb oldali eredményeket tilde (`~`) köti össze az `=` helyett.
- Alapértelmezett érték minden esetben megadható.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### A `case_when` függvény

A `case_when` tovább viszi a `case_match` szintaxisát, mivel bármilyen logikai kifejezést megenged a `~` bal oldalán.

A bemeneti vektort (a lenti példában `x`) nem argumentumként adod meg, csak már definiálva kell lennie.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

A `between()` függvény szintén a `dplyr` része.
