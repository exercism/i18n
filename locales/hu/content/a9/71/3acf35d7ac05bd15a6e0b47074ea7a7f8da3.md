# Bevezetés

A string a Factorban karakterek sorozata. A [`sequences`][sequences] szókészlet legtöbb szava stringeken is működik, a [`splitting`][splitting], [`ascii`][ascii] és társaik szókészletben található, kifejezetten stringkezelésre való szavak mellett.

## Stringliterálok

A stringeket dupla idézőjelbe írjuk. A szokásos escape-szekvenciák is támogatottak: `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Hossz és indexelés

Mivel a string sorozat, a [`sequences`][sequences] szókészlet `length` és `nth` szava közvetlenül működik rajta.

A `length` a karakterek számát adja vissza:

```factor
"hello" length .    ! => 5
```

Az `nth` egy 0-alapú indexet és a sorozatot veszi át, és az adott pozíción lévő elemet adja vissza. String esetén ez az elem egy *karakter*, azaz egy kódpont (egész szám), nem pedig egyetlen karakterből álló részstring:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## Egy karaktertől vissza a stringhez

Ahhoz, hogy egyetlen kódpontból egykarakteres stringet csinálj, használd a [`strings`][strings] szókészlet `1string ( char -- str )` szavát. A `CHAR:` egy literál kódpont beolvasáskori formája:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## Feldarabolás

A [`splitting`][splitting] szókészlet darabokra vágja a stringet.

A `split1` az elválasztó *első* előfordulásánál vág, és visszaadja mindkét felét:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

A `split` az elválasztóhalmaz *bármelyik* karakterénél vág, és eközben üres darabok is keletkezhetnek:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

A `harvest` (a [`sequences`][sequences] szókészletből) eldobja az üres darabokat:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Egy darab kiválasztása

Miután a stringet darabok tömbjévé vágtuk szét, a `first`, `second`, `third` és `fourth` (a [`sequences`][sequences] szókészletből) az adott pozíción lévő darabot adja vissza:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Ha egyszerre az összes kezdő darabot a vermen szeretnéd látni, a `first2` és a `first3` egyetlen lépésben fejt ki közülük kettőt vagy hármat:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

Magán a stringen a `first` az első **karaktert** adja vissza, egy kódpontot, nem pedig egy részstringet:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Trimmelés

A `[ blank? ] trim` (a [`sequences`][sequences] szókészletből, a `blank?` pedig az [`ascii`][ascii] szókészletből) eltávolítja a vezető és a záró whitespace-t:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Kis- és nagybetűváltás

A `>lower` és a `>upper` (az [`ascii`][ascii] szókészletből) egy új stringet ad vissza, amelyben megváltoztak a kis- és nagybetűk:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Összefűzés

Két [`sequences`][sequences] szó állít elő stringeket:

A `surround` egy stringet egy előtaggal és egy utótaggal vesz körbe:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

A `glue` két stringet fűz össze, közéjük egy elválasztót téve:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
