# Bevezetés

## Tuple-ök

A tuple névtelen, de rendezett értékek _módosíthatatlan_ csoportosítása.
A tuple-ök bármilyen (vagy többféle) adattípust tárolhatnak, akár más tuple-öket is.

A tuple-öket a `(` és `)` karakterek között álló, vesszővel elválasztott értékekként definiáljuk: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Csak az azonos hosszúságú és azonos típusokból (ugyanabban a sorrendben) álló tuple-ök hasonlíthatók össze.
A tuple-ök szerkezeti egyenlőséggel rendelkeznek, ami azt jelenti, hogy _csak_ akkor egyenlők, ha minden értékük egyenlő.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Háromféleképpen nyerhetsz ki értékeket egy tuple-ből:

- Az `fst` és `snd` függvények
- Tuple-ök szétbontása
- Mintaillesztés

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
