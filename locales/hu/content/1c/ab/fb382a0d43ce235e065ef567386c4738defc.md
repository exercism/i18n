# Kiegészítés az utasításokhoz

## Várjunk csak, ez lehetetlen!

Ezeknek a listaműveleteknek a megvalósítása _bármilyen_ beépített függvény használata nélkül gyakorlatilag lehetetlen Roc-ban, mert szükséged van egy módra, amivel elemeket fűzhetsz a lista végére vagy elejére.
Más nyelvekben használhatsz operátorokat, például a `:`-t Haskellben vagy a `+=`-t Pythonban, de Roc-ban a [`List` függvényeket](https://www.roc-lang.org/builtins/main/#Builtin.List) kell használnod.

Tehát ebben a feladatban használhatod a `List.append`-et (de kerüld bármely más beépített függvény használatát).

Sok funkcionális programozási nyelv elsődleges gyűjteménytípusként láncolt listákat használ.
Láncolt listánál hatékony egy elemet elé fűzni vagy kivenni az első elemet, ezért azokban a nyelvekben a `List.prepend` használatával valósítanád meg a listaműveleteket.
Roc-ban viszont a `List` egy tömb (összefüggő bájtokból álló blokk).
A tömbök más tulajdonságokkal rendelkeznek, mint a láncolt listák, például hatékonyan el lehet érni az elemeket index alapján, és új elemeket lehet hozzáfűzni.
Emiatt Roc-ban gyakran használjuk a `List.append`-et, és ritkán a `List.prepend`-et.

## Elnevezések

A Roc némileg eltérő neveket használ, mint az általános utasításokban szereplők:

- `concat` az `append` helyett
- `join` a `concatenate` helyett
- `len` a `length` helyett
- `fold` a `foldl` helyett
- `fold_rev` a `foldr` helyett

Roc-ban azonban a következő függvénynevek szabványosak:
- `filter`
- `map`
- `reverse`

## Tipp

Próbáld ki a következőt:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

vagy

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
