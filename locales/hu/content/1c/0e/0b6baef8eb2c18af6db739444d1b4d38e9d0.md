# Bemutatás

A [nil][nil-dictionary] egy angol szó, amely azt jelenti, hogy „semmi” vagy „nulla”. Az Elixirben a `nil` egy különleges érték, amely egy érték _hiányát_ jelöli.

```elixir
# I do not have a favorite color
favorite_color = nil
```

A `nil` egy atom, de általában `nil`-ként írjuk, nem `:nil`-ként. A `true` és `false` logikai értékek szintén atomok.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

Ellenőrizheted, hogy egy változó értéke `nil`-e, a [`==`][kernel-equal] operátorral, mintaillesztéssel, vagy az [`is_nil` guard][kernel-is-nil] használatával.

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
