# Bevezetés

Az F# `char` típusa egy 16 bites érték, amellyel a szöveg legkisebb címezhető egységeit reprezentáljuk; alapértelmezés szerint változtathatatlan.

A `char` értékek literálként, aposztrófok között adhatók meg:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

A string `char`-ok sorozata.

Egy-egy `char` a stringből (nullától induló) indexeléssel kérdezhető le:

```fsharp
"Exercism"[4] //  =>  'c'
```

A stringen való végigiterálás minden lépésben egy `char`-t ad vissza.

A következő példa a kényelem kedvéért egy magasabb rendű függvényt és egy névtelen függvényt használ.
Ezekről a tantervben később lesz szó rendesen, egyelőre viszont tömör módot adnak arra, hogy ciklust írj a string karakterein.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Ahogy fent látható, egy `char` átalakítható `int` értékké.
Ez más írásrendszereknél is működik (*legalábbis néha*):

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

A karakterek összehasonlításakor a mögöttes Int16-ot veszi alapul:

```fsharp
'A' < 'D'  // =>  true
```

Egy `int` is átalakítható `char`-rá:

```fsharp
char 77  // => 'M'
```

A `System.Char` könyvtár tartalmazza a .NET nyelvtől elvárható összes metódust, például a nagybetűssé és kisbetűssé alakítást:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
