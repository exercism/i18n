# Utasítások

Szenvedélyes madárfigyelő vagy, aki nyomon követi, hány madár járt a kertedben az elmúlt hét napban.

Öt részfeladatod van, és mindegyik a kertedbe látogató madarak számával foglalkozik.

## 1. Nézd meg, mennyi volt a számuk múlt héten

A madárszámokat JSON formátumban tárolod.
Egy „fő” tömb heti számokat tartalmazó tömböket tárol.
Minden heti szám egy hét egész számból álló tömb, a hét minden napjához egy szám.
Az új heteket mindig a „fő” tömb végéhez fűzöd hozzá.
Valósítsd meg azt a szűrőt, amely visszaadja a múlt heti számokat.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Nézd meg, hány madár járt itt tegnap

Valósítsd meg a szűrőt, amely visszaadja, hány madár járt a kertedben tegnap.
A madárszámok nap szerint vannak rendezve: az első elem a legrégebbi nap száma, az utolsó pedig a mai napé.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Számold ki az összes látogató madár számát

Valósítsd meg a szűrőt, amely visszaadja, összesen hány madár járt a kertedben ezen a héten.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Számold ki a forgalmas napok számát

Van, amelyik nap forgalmasabb a többinél.
Forgalmas nap az, amikor öt vagy több madár járt a kertedben.
Valósítsd meg a szűrőt, amely visszaadja az e heti forgalmas napok számát.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Nézd meg, volt-e olyan nap, amikor egyetlen madár sem járt itt

Valósítsd meg azt a szűrőt, amely `true`-t ad vissza, ha ezen a héten volt olyan nap, amikor nulla madár járt a kertedben; egyébként pedig `false`-t ad vissza.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
