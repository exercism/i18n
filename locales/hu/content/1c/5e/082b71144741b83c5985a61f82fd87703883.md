# Bevezetés

**A rekurzív függvények** olyan függvények, amelyek önmagukat hívják.

Egy _rekurzív függvénynek_ legalább egy _alapesetre_ és legalább egy _rekurzív esetre_ van szüksége.

**Az alapeset** értéket ad vissza anélkül, hogy újra meghívná a függvényt.
**A rekurzív eset** újra meghívja a függvényt, és úgy módosítja a bemenetet, hogy az előbb-utóbb megfeleljen az alapesetnek.

Íme egy példa, ami megszámolja egy tömb elemeit.

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

Egy _rekurzív függvénynek_ sok _alapesete_ és/vagy sok _rekurzív esete_ lehet.
Például [a Fibonacci-sorozat][wiki-fibonacci] egy olyan rekurzív sorozat, amelynek két _alapesete_ van.

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

Egy adott `x` érték előfordulásainak megszámolásához egy listában két _rekurzív eset_ tartozik.

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

A gyakorlatban a listákon és más felsorolható adatszerkezeteken való iterálás leggyakrabban beépített függvényekkel történik,
például a `map` és a `reduce` segítségével, vagy [folyamok használatával][map-implementation], mint például `[.[] | select(...)]`.
A háttérben néhány beépített függvény [rekurzióval van megvalósítva][walk-implementation].
