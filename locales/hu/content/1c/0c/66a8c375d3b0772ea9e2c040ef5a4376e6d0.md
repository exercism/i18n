# Bevezetés

A Factorban a szavakat egyszerűen egymás után írva fűzöd össze: az, hogy milyen sorrendben írod le őket, *egyben* az összekapcsolás módja is. (A programozók ezt *függvénykompozíciónak* nevezik.) Egy szó teste maga is szavak sorozata: mindegyik elvesz néhány értéket a stackről, és ráteszi a saját eredményét, a következő szó pedig onnan folytatja, ahol az előző abbahagyta. Így ha ezt definiálod:

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

az máris *maga* a `cleanupname`, a `first` és a `1string` kompozíciója.

Ez a feladat emellett bemutatja a **quotation** fogalmát is: egy kódrészletet, amit értékként eltárolhatsz, és később futtathatsz le, ahelyett hogy azonnal lefutna.

## Quotationok

A quotation egy szögletes zárójelbe zárt kódrészlet. Leíráskor még nem fut le, hanem értékként ott ül a stacken:

```factor
[ 2 * ] .       ! => [ 2 * ]
```

A `call` futtat egy quotationt:

```factor
3 [ 2 * ] call .    ! => 6
```

Quotationt akkor írsz, amikor kódot kell adatként átadnod: hogy később fusson le, vagy hogy átadd egy *kombinátornak*, azaz egy olyan szónak, amely bemenetként quotationt kap.

## `compose`

A `compose ( quot1 quot2 -- combined )` két quotationt ragaszt eggyé, és abban a sorrendben futtatja le őket, ahogy leírtad:

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

Általában azt tapasztalod majd, hogy egy kis szó definiálása `:` ... `;` között olvashatóbb, mint a `compose`, de a `compose` akkor jön jól, ha menet közben kell quotationokat építened. Ha az építőelemek még nem quotationok, akkor a `>quotation ( seq -- quot )` (a [`quotations`][quotations] szótárból) értékek és szóhivatkozások sorozatából csinál hívható quotationt:

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## Egy quotation alkalmazása két bemenetre

A `bi@ ( x y quot -- ... )` lefuttatja a quotationt `x`-en, majd újra `y`-on, és mindkét eredményt a stacken hagyja:

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

A feladat `couple` részfeladatának két név a bemenete; a `bi@` a természetes módja annak, hogy az `initial`-t mindkettőre alkalmazd.

## Néhány szó stringekhez

A feladathoz néhány apró, stringekkel dolgozó szó kell, három szótárból: [`sequences`][sequences], [`ascii`][ascii] és [`strings`][strings].

- `replace ( seq old new -- new-seq )` (a `splitting` szótárban): részstring cseréje.
- `[ blank? ] trim` (a `trim` a `sequences`-ben, a `blank?` az `ascii`-ban): a string elején és végén lévő whitespace eltávolítása.
- `1string ( char -- str )` (a `strings`-ben): egyetlen karaktert csomagol stringbe.
- `>upper ( str -- upper )` (az `ascii`-ban): egy stringet nagybetűssé alakít.
- `append ( s1 s2 -- s )` (a `sequences`-ben): két stringet fűz össze.
- `prepend ( s1 s2 -- s )` (a `sequences`-ben): előbb `s2`-t, majd `s1`-et fűz össze (`append` ellenkező sorrendű bemenetekkel).
- `glue ( s1 s2 sep -- s )` (a `sequences`-ben): két stringet fűz össze úgy, hogy egy elválasztó kerül közéjük.
- `surround ( seq pre post -- new )` (a `sequences`-ben): egy stringet előtaggal és utótaggal vesz körül.

A Unicode-karaktereket egy stringen belül `\u{XXXX}` formában írhatod le, ahol a `XXXX` a kódpont hexadecimális értéke. Ebben a feladatban megjelenik a szív, `\u{2764}` (❤).

## Formázott kimenet

Amikor az `append`/`glue`/`surround` már nem elég kifejező, a [`formatting`][formatting] biztosítja a printf-stílusú `sprintf`-et:

```
sprintf ( inputs... format-string -- str )
```

A `%s` egy stringet, a `%d` egy egészet, az `%f` egy tizedes törtet helyettesít be; a `%` és a típusbetű közé opcionális szélesség-, pontosság- és kitöltésmódosítók kerülhetnek:

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

A számok és a stringek közötti oda-vissza alakításhoz a [`math.parser`][math.parser] kínálja a `number>string` és a `string>number` szót:

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
