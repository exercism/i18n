# Bevezetés

A generikusok lehetővé teszik, hogy olyan kódot írj, amely több típussal is működik, duplikáció nélkül. A generikus típusokat úgy definiálod, hogy csúcsos zárójeleket használsz: `<T>`, ahol a `T` bármely típus helyőrzője.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

A Cairo megköveteli a trait-korlátokat, hogy meghatározzák, milyen műveleteket kell a generikus típusnak támogatnia. A megkötéseket a `+` szintaxissal adhatod hozzá:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

A struktúrák is lehetnek generikusak:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

A trait-ek is lehetnek generikusak, így különböző típusokkal is működhetnek:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

A függvények elfogadhatnak generikus paramétereket trait-korlátokkal, így bármely olyan típussal működnek, amely megvalósítja a szükséges traitet:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
