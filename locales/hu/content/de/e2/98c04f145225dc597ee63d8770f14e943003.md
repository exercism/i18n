# Névjegy

A `bit` a számítástechnika legapróbb, tovább már nem bontható értéke.
A `bit` szó a „bináris számjegy” rövidítése.
Ez az adattárolás egy egysége a végrehajtási környezetben, amely elég nagy ahhoz, hogy egy olyan objektumot tároljon, amely két érték valamelyikét veheti fel.
Ennélfogva bináris értéke vagy `1`, vagy `0`.
Minden más adattípus több `bits`-ből áll.
Például egy `byte` általában nyolc `bits`-ből áll.

## Hogyan írjunk le bitértékeket

A `Bits` kettes számrendszert alkotnak.
A `2` minden többszöröse abba a helyiértékbe kerül, amit mi tízes/százas/ezres/stb. helyiértékként ismerünk, azzal a különbséggel, hogy a „tízes” „kettes”, a „százas” „négyes”, az „ezres” „nyolcas” lenne, és így tovább.
Tehát a tízes számrendszerbeli `2` érték a bináris `10` lenne, a `4` a `100`, a `8` pedig az `1000`.
A tízes számokhoz hasonlóan az értékek jobbról balra haladva egyre nagyobbak.
Gondolhatunk úgy a tízes számrendszerbeli `5`-re, hogy a bináris `101` képviseli, ahol egy `1` áll az „egyes” helyiértéken és egy `1` a „négyes” helyiértéken.
A bináris literálok azonban nem részei a C nyelv szabványának.
A C nyelv szabványa csak egyetlen `1` vagy `0` bináris értéket támogat.
A bináris literálokat _viszont_ támogatják egyes nem szabványos fordítóbővítmények, például a gnu fordító, ha a literál elé `0b`-t írunk.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

Fontos megjegyezni, hogy az ilyen jelölést nem támogatja minden fordító, és akadálya lehet a kód hordozhatóságának a különböző fordítók között.

A bináris értékek leírásának gyakori módja a hexadecimális jelölés, ami egy tizenhatos számrendszer.
A C nyelv hexadecimális jelölése a literál elé `0x`-et vagy `0X`-et tesz.
Mivel a tízes számrendszerbeli `16` értéket a `1` képviseli a tízesek helyén, a tízes számrendszerbeli `10` hexadecimálisan `0xA`, a `11` `0xB`, a `12` `0xC`, a `13` `0xD`, a `14` `0xE`, a `15` pedig `0xF`.
Így például a tízes számrendszerbeli `42` érték `0x2A`-ként írható le: `2`-szer `16` (= `32`) plusz `10` (= `42`).

Binárisan a `42`-t gondolhatjuk `00101010`-ként: `32` plusz `8` plusz `2`.
Azt mondanánk, hogy jobbról a második, negyedik és hatodik bit „be van állítva”, ami azt jelenti, hogy `0` helyett `1`.
A második bit a `2`, a negyedik bit a `8`, a hatodik bit pedig a `32`.
Ennek a három bitnek a beállítása a `42` értéket adja.

## Bitmaszkok

Egy bitmaszk bármilyen érték lehet, amit egyes bitek beállítására használunk.
Az angol ábécében például huszonhat betű van.
Egy legalább huszonhat bites érték, például egy előjel nélküli 32 bites egész szám, bitmaszkként használható ahhoz, hogy minden angol betűhöz beállítsunk egy `true` vagy `false` feltételt.
Bármely érték, amelyben elég bit van a szükséges `true` vagy `false` feltételek halmazának kezeléséhez, szolgálhat bitmaszkként.
Az egyes bitek beállítása és kiolvasása bitenkénti operátorok használatával történik.

## Bitenkénti operátorok

Tegyük fel, hogy nyomon szeretnénk követni, mely betűk fordulnak elő egy `string`-ben.
A példánkban csak az angol ábécé huszonhat betűjét használjuk.
A bitmaszkunk egy előjel nélküli 32 bites egész szám lesz.
A `0` azt jelenti majd, hogy a betű nem fordul elő.
A `1` azt jelenti majd, hogy a betű egyszer vagy többször előfordul.
Kezdetben a bitmaszkunk bitsorozata 32 egymás utáni `0s` lesz: `00000000000000000000000000000000`.
A jobb szélső hely az `A` betűé.
Balról a második a `B` betűé, és így tovább.
Tegyük fel, hogy a string összes betűjét egy ciklusban dolgozzuk fel, ezért egyetlen olyan kódsort szeretnénk, amely bármely betű beállítására alkalmas.

### Bitenkénti balra tolás operátora: így pozicionálunk egy bitet

A `<<` a balra tolás bitenkénti operátora.

Ha a betűnk `A`, akkor nem akarunk balra tolni, ha viszont `B`, akkor egy pozícióval balra tolunk, ha pedig `C`, akkor kettővel balra, és így tovább.
Bár a `chars`-t olyan betűkként érzékeljük, mint az `A` vagy a `B`, a `char` a memóriában egész szám típusként valósul meg, így egyszerű számításokat végezhetünk vele.
Ha adott egy `letter` nevű változó, amely a feldolgozott `char`-t képviseli, akkor a szükséges számú pozícióval balra tolhatunk úgy, hogy a `1`-et a `letter` és az `A` `char` közötti különbséggel toljuk balra, így: `1 << letter - 'A'`.
`A` - `A` = `0`, tehát nulla pozícióval tol balra, ha a `letter` értéke `A`.
`B` - `A` = `1`, tehát egy pozícióval tol balra, ha a `letter` értéke `B`, és így tovább.

### Bitenkénti inkluzív VAGY operátor: így állítunk be egy bitet

Amint tudjuk, _hol_ szeretnénk beállítani egy bitet, valójában a bitenkénti inkluzív VAGY operátorral állíthatjuk be, ami a `|`.
A `|` operátor eredménye minden olyan pozícióban `1` lesz, ahol a bal vagy a jobb oldali operandus bitje be van állítva.
Tehát a `0010 | 0001` eredménye `0011` lenne.
(Fontos megjegyezni, hogy az érték binárisan `11`, tízes számrendszerben viszont `3`.)
Ahhoz, hogy az eredményt egy értékhez rendeljük, a `|` operátor összekapcsolható az értékadó operátorral, és így állíthatjuk be a biteket: `|=`.
Az egyszerűség kedvéért a következő példa nem használ ciklust, de bemutatja, hogyan dolgozhatnánk fel az `ABA` betűket egy bitmaszkban.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

A maszk jobb szélső részét `0001`-re állítjuk az `A` esetében, majd a maszkot `0011`-re a `B` esetében.
Egy újabb `A` beállítása nem változtat a meglévő maszkon.
Elkerülhettük volna a bit újbóli beállítását, ha megnézzük, hogy az `A` már be volt-e állítva.

### Bitenkénti ÉS operátor: így olvasunk ki egy bitet

A `&` a bitenkénti ÉS operátor.
A `&` operátor eredménye minden olyan pozícióban `1` lesz, ahol a bal és a jobb oldali operandus bitje is be van állítva.
Tehát a `0011 & 0001` eredménye `0001` lenne.
Ezt működés közben a következő példában láthatjuk.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Bitenkénti kizáró VAGY operátor: így billentünk át egy bitet

A `^` a bitenkénti kizáró VAGY operátor.
Egy _inkluzív_ VAGY operátor létezése magával vonja, hogy van egy más viselkedésű _kizáró_ VAGY operátor is.
A `^` operátor eredménye minden olyan pozícióban `1` lesz, ahol a bal és a jobb oldali operandus közül _csak az egyiknek_ van beállított bitje.
Tehát a `0001 ^ 0011` eredménye `0010` lenne.
A jobb szélső bit nem lesz beállítva, mert _mindkét_ operandusnak `1` van a jobb szélső pozíciójában.
A kizáró VAGY műveletet néha XOR-ként jelölik.
Ha egy XOR-olt érték eredményét ismét XOR-oljuk, visszakapjuk az eredeti értéket.
Ez egy nagyon egyszerű titkosításhoz használható, ahol ugyanazt a kulcsot használjuk az adatok titkosításához és visszafejtéséhez.
Például

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### Bitenkénti jobbra tolás operátora: így felezünk meg egy értéket

A `>>` a jobbra tolás bitenkénti operátora.
Általában minden egyes jobbra tolt pozíció után az eredmény az érték fele.
Például

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

Ha a jobb oldali operandus értéke negatív, vagy nagyobb vagy egyenlő, mint az előléptetett bal oldali operandus szélessége, a viselkedés nem meghatározott.
Ez a balra toló operátorra is vonatkozik.
Ha előjel nélküli helyett előjeles egész számot használunk, akkor az előjeliség is közrejátszhat.
A következő példa egy rendszer viselkedését mutatja, amikor egy előjeles egész számot túl messzire tolunk balra vagy jobbra.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

Mivel a viselkedés nem meghatározott, egy másik rendszer eltérő eredményeket adhat.
Bitek tolásakor fontos, hogy tisztában legyünk a használt adattípus korlátaival.

## Bitmezők

Láttuk, hogyan lehet egy egyszerű adattípusba csomagolt biteket a pozíciójuk alapján elérni.
A `struct`-ba csomagolt biteket a nevük alapján érhetjük el.
Az ilyen adattípust `bit field`-nek nevezzük.
A `bit fields`-ek egyik felhasználási esete az lehet, amikor ON/OFF jelzők gyűjteményére van szükség, és a memóriahasználat minimalizálása a cél.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

Az `unsigned int variable_name : 1;` szintaxis egy `1` bites mezőt hoz létre a structban elhelyezett `unsigned int`-en belül.
Egy `unsigned int` helyett használhatunk `signed int`-et, vagy a C99-es vagy annál újabb szabványtól kezdve akár `bool` típust is.
Egy bitmezőket tartalmazó struct más adattípusú mezőket is tartalmazhat, például a fenti példában szereplő `number_of_lights`-ot.
