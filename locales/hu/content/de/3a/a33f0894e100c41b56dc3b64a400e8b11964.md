# Névjegy

A Gleam szótárai azok az adatszerkezetek, amelyek kulcs-érték párokban tárolják az információt. Más nyelvekben ezeket asszociatív tömböknek, hash-eknek vagy szótáraknak is nevezik.

Bármilyen típus használható a kulcsokhoz és értékekhez egy szótárban, és nem garantálják a bejegyzések sorrendjét sem eléréskor, sem visszaadáskor.

## A szótárak használata

A szótárakat a `gleam/dict` modul függvényeivel hozhatod létre és kezelheted.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
