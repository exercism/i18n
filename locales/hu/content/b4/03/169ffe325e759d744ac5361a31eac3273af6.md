# Tudnivalók

A Gleamben a konstansok segítségével neveket adhatunk értékeknek. Definíciójukhoz a `const` kulcsszót használjuk.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Ha a `pub` kulcsszóval definiáljuk őket, a modulkonstansok más modulokból is elérhetők, egyébként csak abból a modulból érhetők el, amelyikben definiáltuk őket.
