# Bevezetés

A legtöbb program függ valamilyen könyvtáraktól. Ezeket kézzel kezelni igazi szenvedés lehet. Szerencsére a Rust ökoszisztémája alapértelmezés szerint tartalmazza a `cargo`-t! A `cargo` egy projekt függőségeit is képes kezelni.

A Rustban gyakran találkozhatsz azzal, hogy a külső csomagokra „crate”-ként hivatkoznak. A crate a Rustban egy fordítási egység. A crate binárisba vagy könyvtárba fordítható.

Az esetek többségében egy külső függőség hozzáadása olyan egyszerű, mint egy sor hozzáadása a `Cargo.toml` fájlodhoz.
