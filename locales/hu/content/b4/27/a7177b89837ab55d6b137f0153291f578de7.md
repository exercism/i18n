## Változók

A változók szimbolikus nevek, amelyek vagy értékekre, vagy konténerekre hivatkoznak.
A változónevek kezdődhetnek egy [sigil][sigils] nevű speciális karakterrel is, de akár anélkül is, amelyet egy azonosító követ.
A sigilt egy [twigil][twigils] is követheti.

A különböző sigillel ellátott változók különböző típusú adatszerkezeteket tárolnak.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

Gyakran találkozol majd a `^` és a `:` twigillel, amelyek a kódblokk-szignatúrák rövidítéseiként működnek.
A `^` a pozicionális paraméterekhez tartozik.
A `:` a nevesített paraméterekhez.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## Konténerek

A konténerek teszik lehetővé, hogy egy változó módosítható legyen.

A `constant` kulcsszóval deklarált változóknak, valamint a sigil nélküli változóknak (amelyeket az azonosító előtt egy `\` előz meg) nincs konténerük, hanem közvetlenül értékekre hivatkoznak.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## Típusok

A változók típusmegkötéssel is deklarálhatók.
A típusmegkötésekhez konverziók is tartozhatnak: ilyenkor a kívánt típus argumentumaként egy elfogadott típust adsz meg.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

A típusmegkötések használata lehetővé teszi, hogy kihasználd a multi-diszpatch rutinokat.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

A Raku típusai csupán egy másik fajta objektumok.
A `class`, a `role` vagy az `enum` deklarálása módot ad saját típusobjektumok létrehozására.
Például a beépített `Bool` típust egy enummal hozták létre: `enum Bool <False True>`.

A `subset` kulcsszóval más típusokra épülő egyszerű típusmegkötéseket is létrehozhatsz.
Az így kapott új típust tovább szűkítheted egy `where` feltétellel.
A `where` feltétel szignatúrában is használható.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
