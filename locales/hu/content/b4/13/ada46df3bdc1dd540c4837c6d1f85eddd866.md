# Bevezetés

Az AWK egy nagyon kicsi nyelv, és csak néhány alapvető adattípusa van.
Ebben a leckében a számokról és a stringekről lesz szó.

## Számok

Az AWK-ban a számok dupla pontosságú lebegőpontos számként vannak megvalósítva.
Nincs különbség egész számok, lebegőpontos számok és dupla pontosságú számok között.

Az AWK ismeri a nyolcas számrendszerű számkonstansokat (`0`-val kezdődnek) és a tizenhatos számrendszerű számkonstansokat (`0x`-szel vagy `0X`-szel kezdődnek).

### Numerikus műveletek

Használhatod a [szabványos aritmetikai operátorokat][ops-arith]: `+`, `-`, `*`, `/`, `%`.
A hatványozás operátora a `^` (ezt a POSIX írja elő), de a `**` is használható.
Van néhány [beépített numerikus függvény][funcs-numeric], köztük trigonometrikus függvények, véletlenszám-generálás, valamint az `int(x)`, amely egy számot az _x_ és a nulla közötti legközelebbi egész számra csonkol.

Bitenkénti _operátorok_ nincsenek.
A gawk függvényként valósítja meg őket.
Az argumentumoknak nemnegatív számoknak kell lenniük.

| függvény            | művelet                                        |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | az argumentumok bitenkénti ÉS művelete         |
| `or(a, b [, ...])`  | az argumentumok bitenkénti VAGY művelete       |
| `xor(a, b [, ...])` | az argumentumok bitenkénti kizáró vagy művelete |
| `lshift(v, count)`  | a _v_ értéke _count_ bittel balra eltolva      |
| `rshift(v, count)`  | a _v_ értéke _count_ bittel jobbra eltolva     |
| `compl(v, count)`   | _v_ bitenkénti komplemense                     |

## Stringek

A stringek az AWK-ban karakterek sorozatai.
Egy stringkonstanst kettős idézőjelek közé írva adsz meg.

~~~~exercism/caution
A GNU awk engedélyezi a Unicode-karaktereket a stringekben, más awk-implementációk viszont nem feltétlenül.
Hasonlítsuk össze a `gawk`-ot a `mawk`-kal, egy másik népszerű AWK-implementációval:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### Stringműveletek

Csak egyetlen stringművelet van: az összefűzés.
Az összefűzésnek nincs külön operátora;
ha két stringet egyszerűen egymás mellé írsz, azzal összefűzöd őket:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
A `print` egy **utasítás**, nem függvény.
A `print` nem igényel zárójeleket.
~~~~

Az AWK rengeteg [stringkezelő függvénnyel][funcs-string] rendelkezik.
Ahogy haladunk előre a kurzusban, ezeket részletesen is megismerjük.

## Számok és stringek közötti átalakítás

Nincsenek explicit operátorok a számok és a stringek közötti átalakításra.
Az AWK ezt implicit módon, a program kontextusától függően végzi el.
Ez nagyon egyszerűvé teszi a bemeneti mezők értékeivel való munkát: az AWK általában pontosan azt teszi, amit szeretnél.

* A `print x + y` a `+` numerikus műveletnek köszönhetően számmá alakítja az `x` és `y` változók értékét.
* A `print x y` az összefűzés műveletének köszönhetően stringgé alakítja az `x` és `y` változók értékét.

Ha ezt explicit módon szeretnéd jelezni, a `0 + x` megadja _x_ számalakját, a `"" x` pedig _x_ stringalakját.

### Stringből számmá

Zavaró lehet, ahogyan az AWK egy stringet számmá alakít.
Az egyszerű magyarázat az, hogy az AWK a string elejétől kezdve „számjegyeket” olvas, amíg „nem szám” karaktert nem talál.
Néhány példa:

* a `"2.5"` a `2.5` számmá alakul;
* a `"1e3"` az `1000` számmá alakul (tudományos jelölés);
* a `"456abc"` a `456` számmá alakul (mivel az `a` nem „számjegy”, itt megáll az átalakítás).
* az `"abc789"` a `0` számmá alakul (a string **elején** nincsenek számjegyek).

A részletes leírás [a kézikönyvben][str-to-num] található.

## Egy változó típusának meghatározása

A [`typeof(var)` függvény][func-typeof] stringként adja vissza a típust.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
a kimenete
```none
42 string
43 number
```
