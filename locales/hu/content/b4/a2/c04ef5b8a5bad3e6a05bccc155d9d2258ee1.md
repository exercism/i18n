# Utasítások

A hajó pénztárosa vagy, aki az éléskamra leltárát kezeli. A leltár egy hashtábla, amelyben minden kulcs egy tételnév, az érték pedig a készleten lévő mennyiség.

## 1. Készíts leltárt egy listából

Definiáld a `create-inventory` függvényt úgy, hogy egy tételnevek sorozatát vegye át, és egy olyan hashtáblát adjon vissza, amely minden egyedi nevet a darabszámával párosít.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Adj hozzá további tételeket

Definiáld az `add-items` függvényt úgy, hogy egy leltárt és egy tételek sorozatát vegyen át, és egy új leltárt adjon vissza, amelyben minden felsorolt tétel darabszáma meg van növelve. Az eredeti leltárt nem szabad módosítani.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Csökkentsd a darabszámokat

Definiáld a `decrement-items` függvényt úgy, hogy egy leltárt és egy tételek sorozatát vegyen át, és egy új leltárt adjon vissza, amelyben minden felsorolt tétel darabszáma eggyel csökkent. A darabszámok soha nem eshetnek nulla alá, és a leltárban még nem szereplő tételeket ki kell hagyni (nem szúrunk be negatív bejegyzéseket).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Távolíts el egy tételt teljesen

Definiáld a `remove-item` függvényt úgy, hogy egy leltárt és egy tételt vegyen át, és egy új leltárt adjon vissza, amelyből el van távolítva az a tétel. Ha a tétel nincs a leltárban, adj vissza egy változatlan másolatot.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Listázd az elérhető tételeket

Definiáld a `list-inventory` függvényt úgy, hogy egy leltárt vegyen át, és egy `{ name quantity }` párokból álló tömböt adjon vissza, amely csak azokat a tételeket tartalmazza, amelyek mennyisége nullánál nagyobb, név szerint ábécérendbe szedve.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
