# Bevezetés

## Tulajdonságok

A C#-ban a tulajdonság egy osztály olyan tagja, amely hozzáférést biztosít az osztályon belüli adatokhoz.
A hívók beállíthatják vagy lekérdezhetik (get) az adatokat. A tulajdonságok vagy automatikusan implementáltak, vagy
háttérmezővel rendelkeznek. Egy set és/vagy egy get hozzáférőt tartalmaznak.
Más nyelvekben a „mutátor” nagyjából egy set hozzáférővel egyenértékű, a „hozzáférő” pedig nagyjából
egy get hozzáférővel, bár a szintaxis felépítése teljesen más.

Egy tulajdonság beállításakor a bemeneti érték validálható, formázható
vagy más módon manipulálható, sőt valójában bármilyen programozási művelet végrehajtható, amely az
osztályban lévő kódból elérhető.

Hasonlóképpen egy tulajdonság lekérdezésekor az adatok kiszámíthatók vagy formázhatók, és ismét
bármilyen programozási művelet végrehajtható, amely az osztály számára elérhető.

A tulajdonságoknak ugyanúgy vannak hozzáférés-módosítóik (`public`, `private` stb.), mint más
osztálytagoknak, de a set hozzáférő hozzáférési szintje független lehet a lekérdező (get)
hozzáférőétől, és fordítva. Egy tulajdonságnak nem kell mindkét hozzáférővel rendelkeznie; lehet csak az egyik (vagy get, vagy set).

A tulajdonságok kifejezésének alapvető szintaxisa kétféle formát ölthet:

### Mezővel/kifejezéssel támogatott tulajdonságok:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### Automatikusan implementált tulajdonságok

```
public int MyProperty { get; private set; } = 42;
```

Az inicializálás nem kötelező.
