# Utasítások kiegészítése

## Regiszterek

| Regiszter | Használat | Típus | Leírás                                                                                |
| -------- | --------- | ------- | ------------------------------------------------------------------------------------- |
| `$a0`    | bemenet   | egész szám | szám                                                                                |
| `$v0`    | kimenet   | egész szám | besorolás (`1` = `perfect`, `2` = `abundant`, `3` = `deficient`, `-1` = `error`) |
| `$t0-9`  | ideiglenes | bármilyen | ideiglenes tárolásra használatos                                                    |
