# Az aritmetikai operátorokról

## Operátorok

A Go a következő aritmetikai operátorokat támogatja:

| Operátor | Példa          |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

Egész számok osztásakor a maradék elvész (pl. `5 / 2 == 2`).

A `+` operátor stringeket is összefűz: `"foo" + "bar" == "foobar"`.

## Vegyes típusú aritmetika

A Go nem engedélyezi az aritmetikai műveleteket különböző numerikus típusok között:

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

Az operandusoknak azonos típusúnak kell lenniük, ami néha explicit típuskonverziót igényel:

```go
x := float64(42)
n := 2.0
value := n * x 
```

## Rövidített értékadás

Minden operátornak van egy rövidített értékadó formája, amely helyben frissíti a változót:

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## Növelés és csökkentés

Ha egy változó után állnak, a növelő (`++`) és csökkentő (`--`) utasítások 1-gyel növelik vagy csökkentik a változóban tárolt numerikus értéket.
Ha a változó elé tesszük őket, az szintaxishiba.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

Mivel utasítások, nem adnak vissza értéket.
