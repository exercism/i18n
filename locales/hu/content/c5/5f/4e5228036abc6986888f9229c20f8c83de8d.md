# Bevezetés

A Common Lispben sok különböző egyenlőség-predikátum van.
Ez eltér azoktól a programozási nyelvektől, amelyekben csak egy vagy kettő lehet (például talán a `==` és a `===`).
Ezek közül néhány predikátum a Common Lispben típusra jellemző, mások viszont általánosak.
Itt az utóbbiakról lesz szó.

Négy általános egyenlőség-predikátum van, és abban különböznek, hogy mennyire szigorúan tekintik „egyenlőnek” a dolgokat.
A legszigorúbbtól a legengedékenyebbig sorrendben: `eq`, `eql`, `equal` és `equalp`.

Íme egy gyors definíciógyűjtemény (néhány részletet kihagyva):

- `eq`: az egyenlőséget úgy definiálja, hogy a két objektum azonos.
  _például_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: az egyenlőséget úgy definiálja, hogy két azonos típusú és értékű szám, két ugyanolyan karakter, vagy bármi más esetén az, hogy `eq`-k.
  _például_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: az egyenlőséget a következőképpen definiálja: két lista akkor `equal`, ha minden elemük is `equal`; két string akkor `equal`, ha minden elemük `eql`; két tömb akkor `equal`, ha `eq`-k; minden más pedig akkor `equal`, ha `eql`-ek.
  _például_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: az egyenlőséget a következőképpen definiálja: a stringeket és a karaktereket kis- és nagybetű megkülönböztetése nélkül hasonlítja össze; a számokat némi típuskonverzióval hasonlítja össze; a listák és a tömbök akkor `equalp`, ha minden elemük is `equalp`, a struktúrák akkor, ha azonos típusúak és minden slotjuk `equalp`, a hash-táblák pedig akkor, ha a kulcsaik és az értékeik `equalp`
  _például_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
