# Utasítások

Ebben a feladatban félig strukturált naplóüzeneteket fogsz előállítani.

## Félig strukturált üzenetek előállítása

Néhány csonkolt függvénnyel és a következő enummal kezded:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

A célod, hogy a következő formátumban állíts elő naplóüzeneteket: `"[<LEVEL>]: <MESSAGE>"`.
Olyan függvényeket kell implementálnod, amelyek megfelelnek a naplózási szinteknek.

Például az alábbi kódrészlet a `log` függvény várható kimenetét mutatja be.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

És az `info` esetében:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Jó szórakozást!
