# Kiegészítő utasítások

## Kivételüzenetek

Néha szükség van arra, hogy [kivételt dobj][raise-an-exception]. Amikor ezt teszed, mindig adj meg egy **beszédes hibaüzenetet**, amely megmutatja, mi a hiba forrása. Ettől a kódod olvashatóbb lesz, és nagyban segít a hibakeresésben. Ha tudod, hogy a hiba forrása egy adott típusú lesz, választhatsz, hogy a [beépített hibatípusok][built-in-errors] egyikét dobod, de ilyenkor is adj meg hozzá beszédes üzenetet.

Ennél a feladatnál a [raise utasítással][raise-statement] kell „dobj” egy `ValueError`-t, ha az `answer()` függvénynek átadott kérdés hibás/érvénytelen, vagy ismeretlen műveletet tartalmaz. A tesztek csak akkor futnak át, ha egyszerre `raise`-eled az `exception`-t és üzenetet is fűzöl hozzá.
**Figyelem**: Minden esetben más üzenetre van szükség, még akkor is, ha ugyanazt a _hibatípust_ dobod.
Nézd meg figyelmesen a teszteket.

Ha egy [`ValueError`][value-error] t szeretnél dobni egy üzenettel együtt, írd az üzenetet az `exception` típus argumentumaként:


```python
# if the question contains an unknown operation.
raise ValueError("unknown operation")

# if the question is malformed or invalid.
raise ValueError("syntax error")
```

Ha egy adott kódblokkon belül szeretnéd _kezelni_ a dobott hibát, használhatsz [try-except][handling-exceptions] blokkot.
A `try-except` blokkok „körülveszik” azt a kódot, amely potenciálisan hibát okozhat, és az összes kivételt egyetlen hibához, több hibához vagy a probléma kezelésére szolgáló más kódrészletekhez rendelik:


```python
while len(equation) > 1:
        try:
           # The questionable/error-prone code goes here,in an indented block
           # It can contain statements, loops, if-else blocks, or other executable code.
           x_value, operation, y_value, *rest = equation
           ...
           ...

        except:
            # Code for what to do when an error gets thrown in the code above.
            # This could be one error, or more complicated logging, error checking and messaging.
            raise ValueError("syntax error")
```
