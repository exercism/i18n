# Bevezetés

A `for` ciklusok a legösszetettebb ciklustípus PHP-ban. Úgy viselkednek, mint a `for` ciklusok `C`-ben, `Java`-ban és `JavaScript`-ben. Az alapformája:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

Az első kifejezés (_expr1_) a ciklus kezdete előtt értékelődik ki. A második kifejezés (_expr2_) minden iteráció előtt értékelődik ki, és ha _truthy_ értéket ad, akkor az utasítások végrehajtódnak. A harmadik kifejezés (_expr3_) a végrehajtott utasítások után értékelődik ki.
