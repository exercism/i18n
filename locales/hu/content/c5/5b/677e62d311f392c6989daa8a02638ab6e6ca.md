# Bevezetés

## Típuskonverzió

A Go-ban a különböző típusok közötti átalakítást explicit módon kell elvégezni.
A típusok közötti átalakítás (más néven **típusátalakítás**) egy olyan függvénnyel történik, amelynek a neve a cél típus neve.
Például egy `int` típus `float64`-té alakításához a következőt kell tenned:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Primitív típusok és stringek közötti konverzió

Létezik egy `strconv` csomag a primitív típusok (például `int`) és a `string` közötti konverzióhoz.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## Típusállítások

A Go-ban az interfészek kétértelműséget okozhatnak a mögöttes típussal kapcsolatban.
A típusállítás lehetővé teszi, hogy kinyerjük az interfész érték mögöttes konkrét értékét a következő szintaxissal: `interfaceVariable.(concreteType)`.

Például:

```go
var input any = 12
number := input.(int)
```

MEGJEGYZÉS: ez pánikot okoz, ha az interfész változó nem a konkrét típus értékét tartalmazza.

Tesztelhetjük, hogy egy interfész érték egy adott konkrét típust tartalmaz-e, ha kihasználjuk a típusállítás mindkét visszatérési értékét: a mögöttes értéket és egy boolean értéket, amely jelzi, hogy az állítás sikeres volt-e.
Például:

```go
str, ok := input.(string) // no panic if input is not a string
```

Ha az `input` egy `string` értéket tartalmaz, akkor a `str` lesz a mögöttes érték, és az `ok` igaz lesz.
Ha az `input` nem tartalmaz `string` értéket, akkor a `str` a `string` típus zéró értéke lesz (azaz `""` - az üres string), és az `ok` hamis lesz.
Egyik esetben sem lép fel pánik.

## Típusváltások

A **típusváltás** több típusállítást tud egymás után végrehajtani.
Ugyanaz a szintaxisa, mint egy típusállításnak (`interfaceVariable.(concreteType)`), de a `concreteType` helyére a `type` kulcsszó kerül.
Íme egy példa:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
