# Instructions

A közeledben lévő helyi iskolában nagyon aktív a diákegyesület.
A diákegyesületet egy elnök vezeti, és kétévente választást tartanak, hogy új elnököt válasszanak.

Az idei választáson úgy döntöttek, hogy új digitális rendszerre van szükség a szavazatok megszámlálásához.
Az iskola a segítségedet kéri az új rendszer megépítésében.

## 1. Hozz létre egy szavazatszámlálót

Az új szavazási rendszer egyik első eleme egy szavazatszámláló.
Ez a számláló segít nyomon követni, hogy egy adott jelölt hány szavazatot kapott.

Hozz létre egy `NewVoteCounter` függvényt, amely elfogadja egy jelölt kezdeti szavazatainak számát, és egy `int`-re mutató mutatót ad vissza, amely a megadott kezdeti szavazatszámmal inicializálódik.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. Kérd le a szavazatok számát egy számlálóból

Most már van módod új számlálók létrehozására! De rájössz, hogy az új rendszernek arra is szüksége lesz, hogy le tudja kérni a szavazatok számát egy számlálóból.

Hozz létre egy `VoteCount` függvényt, amely argumentumként egy számlálót (`*int`) vár, és visszaadja a számlálóban lévő szavazatok számát.
Ha a számláló `nil`, feltételezd, hogy a számlálóhoz nem tartozik szavazat:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. Növeld egy számláló szavazatainak számát

Végre eljött a szavazatszámlálás ideje! Most szükséged van egy módra, amellyel növelheted a számlálóban lévő szavazatok számát.

Hozz létre egy `IncrementVoteCount` függvényt, amely argumentumként egy számlálót (`*int`) és egy szavazatszámot vár, és ennyivel növeli a számlálót.
Feltételezheted, hogy az átadott mutató soha nem `nil`.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. Hozd létre a választási eredményeket

Most, hogy minden szavazatot megszámláltunk, ideje előkészíteni az eredményhirdetést az egész iskola számára.
Ehhez rájössz, hogy nem elég, ha csupán szavazatszámlálókkal rendelkezel.
Kell egy mód arra, hogy egy adott jelölthöz hozzárendeld a szavazatok számát.

Hozz létre egy `NewElectionResult` függvényt, amely megkapja egy jelölt nevét és a szavazatai számát, majd visszaad egy új választási eredményt.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

A választási eredmény struktúra már létre van hozva neked, és így van definiálva:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. Hirdesd ki az eredményeket

Itt az idő, hogy az iskola tudtára add az új elnököt!
Az új elnököt az iskola kicsi digitális üzenőtábláin hirdetik ki.
Az üzenetnek mutatnia kell az új elnök nevét és a kapott szavazatok számát a következő formátumban: `<candidate_name> (<votes>)`.
Íme egy példa egy ilyen üzenetre: `"Peter (51)"`.

Hozz létre egy `DisplayResult` függvényt, amely argumentumként egy `*ElectionResult` értéket kap, és visszaad egy stringet a megjelenítendő üzenettel.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. Szavazatok újraszámlálása

Hogy megbizonyosodjanak a végleges eredmények pontosságáról, újraszámlálták a szavazatokat.
Az újraszámlálás során kiderült, hogy néhány jelölt szavazatainak száma eggyel eltért.

Hozz létre egy `DecrementVotesOfCandidate` függvényt, amely megkapja a végleges eredményeket és egy jelölt nevét, akinek csökkentened kell a szavazatai számát.
A végleges eredmények `map[string]int` formában vannak megadva, ahol a kulcsok a jelöltek nevei, az értékek pedig az összes szavazatuk.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
