# Névjegy

A Boolean-kifejezés egy vagy több értéktől feltett kérdés, amelyre `true` vagy `false` a válasz.
Egy igaz kifejezés `1`-et ad vissza, egy hamis kifejezés pedig `0`-t.
A számoknak is van igaz/hamis értékük. A nulla `false`, a nem nulla `true`.

A régi C-kód vagy közvetlenül az `int` típust használja Boolean-értékekhez, vagy a programozó olyan konstansokat definiálhatott, mint a `TRUE` és a `FALSE`, hogy az `1`-et és a `0`-t Boolean-reprezentációra képezze le.

A C99 verzióban hozzáadták a `_Bool` típust.
A `stdbool.h` fejlécfájl három új Boolean-szimbólumot definiál: `bool`, `true` és `false`.
A `true` az `1`-nek, a `false` a `0`-nak, a `bool` pedig a `_Bool`-nek felel meg.
Így most a programozók ahelyett, hogy közvetlenül `int`-eket használnának, vagy saját Boolean-leképezéseket készítenének, beilleszthetik a `stdbool.h`-t, és automatikusan Boolean-szimbólumokat kapnak a kódjukban.

## Összehasonlító operátorok

A C hat összehasonlító operátort támogat: `==` (egyenlő), `!=` (nem egyenlő), `>` (nagyobb mint), `<` (kisebb mint), `>=` (nagyobb vagy egyenlő), `<=` (kisebb vagy egyenlő).
Ezek az operátorok az értékek közötti viszonyokat hasonlítják össze, és Boolean-értékekké oldják fel.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Boolean-operátorok

A C három Boolean-operátort támogat: `||` (vagy), `&&` (és) és `!` (nem).

A `!` egy operandussal használatos.
Megfordítja az operandus Boolean-értékét.
Például a `0` `false`, a `!0` pedig `true`.

A `||` és a `&&` két operandussal használatos.
A jobb oldali operandus csak akkor értékelődik ki, ha a bal oldali operandus még nem határozza meg a kifejezés eredményét.
Vagyis a `||` csak akkor értékeli ki a jobb oldali operandusát, ha a bal oldali operandusa `false`-ra értékelődik.
A `&&` csak akkor értékeli ki a jobb oldali operandusát, ha a bal oldali operandusa `true`-ra értékelődik.

## Rövidzárás

Ha nem értékeljük ki az összes operandust, azt „rövidzárásnak” nevezzük.
A rövidzárás tömör és hatékony módja bizonyos helyzetek kezelésének.
Például gyakori idióma, hogy ellenőrizzük, egy mutató nem `NULL`-e, és (&&), ha nem `NULL`, akkor dereferáljuk, így elkerülve egy `NULL` mutató dereferálását.
A rövidzárás azonban bugokhoz is vezethet.
Néha a programozó elfelejti, hogy a `||` vagy `&&` jobb oldali operandusa nem mindig értékelődik ki.
Ha a jobb oldali operandus olyan kifejezés, amelynek mellékhatása várhatóan mindig bekövetkezik, akkor az a bal oldali operandus Boolean-értékétől függően bugot eredményez.

## Boolean-kifejezés visszaadása

Egy Boolean-kifejezés eredménye közvetlenül visszaadható.
Például ez az `if` elágazás

```c
if (count > 0)
    return true;
else
    return false;
end
```

helyettesíthető ezzel:

```c
return count > 0;
```
