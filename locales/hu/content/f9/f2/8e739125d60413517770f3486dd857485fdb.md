# Névjegy

A kezdőértékek speciális metódusok, amelyek az enum egy értékének beállítására szolgálnak. A definíciójuk nagyon hasonlít egy metóduséhoz, csak nincs benne `func` kulcsszó, nincs visszatérési típus, a névnek `init`-nek kell lennie, és a kezdőértéknek _muszáj_ az enum egy értékét a `self`-nek értékül adnia. A kezdőértékeket vagy pontjelöléssel hívjuk meg, vagy úgy, hogy a kezdőérték paramétereit az enum nevének adjuk át.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```
