# defguard kérdőjellel

[comment]: # (2 paramétert igényel:)
[comment]: # (- expected: a javított név)
[comment]: # (- actual: a helytelen név, amelyet a tanuló használt)

Az Elixir sajátos elnevezési konvenciói közé tartozik az is, hogyan nevezzük el a [Boolean értéket visszaadó és guard kifejezésekben érvényes ellenőrzéseket](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> A típusellenőrzések és más, guard kifejezésekben engedélyezett Boolean-ellenőrzések `is_` előtaggal kapják a nevüket.

Az ilyen típusú ellenőrzések közé tartoznak bizonyos beépített függvények, makrók és guard kifejezések.

```elixir
# this is the expected name for checks that return booleans and are valid in guard clauses

%{expected}

# this is the current name

%{actual}
```
Figyeld meg, hogy az olyan függvények és makrók, amelyek Boolean értéket adnak vissza, de nem érvényesek guard kifejezésekben, más konvenciót követnek, és `?` utótaggal kapják a nevüket (`def foo?`, `defmacro foo?`). A két konvenciót nem szabad keverni.
