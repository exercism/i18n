# Tudnivalók

A Go-ban a stringek módosíthatatlanok.
Ha egy ciklusban `+` jellel fűzöd össze a stringeket, az gyakori memóriafoglalással jár, és az adatok többször is másolódnak.
A [`strings` csomag](https://pkg.go.dev/strings) [`Builder`](https://pkg.go.dev/strings#Builder) típusa segít minimalizálni a memóriahasználatot, mert hatékonyan állítja össze a stringeket.

## Stringek építése

A `strings.Builder` nullértéke azonnal használatra kész, kifejezett inicializálás vagy memóriafoglalás nélkül.
Az új adatokat az egyes írási metódusokkal töltheted be a builderbe.
Minden írási metódus hibaértéket ad vissza, hogy megfeleljen a Go szabványos interfészeinek, ez az érték azonban garantáltan mindig `nil`, és a mindennapi kódban általában figyelmen kívül hagyjuk.

A leggyakrabban használt metódusok:

- `WriteString(s string) (int, error)`: Hozzáfűz egy stringet a pufferhez.
- `WriteRune(r rune) (int, error)`: Hozzáfűzi egy rune UTF-8 kódolását.
- `WriteByte(c byte) error`: Hozzáfűz egyetlen byte-ot.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Lekérés és alaphelyzetbe állítás

Amikor elkészültél a szöveg összeállításával, a `String()` metódus meghívásával kinyerheted a felhalmozott tartalmat egy szokásos Go-string formájában.
A `String()` meghívása nagyon olcsó művelet, mert a mögöttes byte-szeletet közvetlenül stringként adja vissza, anélkül hogy lemásolná a felhalmozott adatokat.

Ha ugyanazt a buildert szeretnéd újra felhasználni egy új string összeállításához (például egy cikluson belül), meghívhatod a `Reset()` metódust.
Ez kiüríti a belső puffert, így tiszta lappal kezdheted a következő string felépítését, miközben a már lefoglalt memóriakapacitás a háttérben megmarad.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
