# Bevezetés

Az _if/else_ elágazáshoz hasonlóan a `switch` utasítással is megváltoztathatod a program menetét, ha feltételesen futtatsz kódot.
A különbség az, hogy a `switch` utasítás csak egy primitív vagy string kifejezés értékét tudja összehasonlítani előre meghatározott konstans értékekkel.

Néhány kulcsszó hasznos, amikor switch utasítást használsz.

- `switch`: ezzel a kulcsszóval deklarálhatod a switch szerkezetét.
  Utána az a kifejezés vagy változó következik, amely megváltoztatja az eredményt.
- `case`: ezzel a kulcsszóval deklarálod az eredmény lehetséges változatait.
- `break`: a `break` kulcsszó nagyon hasznos ahhoz, hogy a switch végrehajtása a kívánt folyamat végén leálljon.
  Ha elfelejted, a program folytatódik, és váratlan eredményekhez vezethet.
- `default`: ahogy a neve is mutatja, akkor használd alapértelmezett eredményként, amikor egyetlen másik case sem egyezik a kifejezésed eredményével.

A legegyszerűbb esetben egy primitív vagy string kifejezést vizsgálnak, és annak értéke alapján döntenek.
Például:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
