# Bevezetés

## Összehasonlító operátorok

Az R operátorai ugyanazok, mint sok más programozási nyelvben:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Elágazás

Az if-else alapformája így néz ki:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

Ebben az esetben a Boolean körüli zárójel (`()`) és az utasítás körüli kapcsos zárójel (`{}`) is kötelező.
Egy egyszerű `if` elágazás lerövidíthető:

```R
if (x == 0) return("success")
```
