# Utasítások

Eljött végre a nap, amire olyan sokáig vártál, és most büszke tulajdonosa vagy egy gyönyörű farmnak az Alpokban.

Továbbra sem szeretsz túl korán kelni, hogy megetesd a teheneidet.
Mivel kiváló mérnök vagy, építesz egy etetőadagolót, a `FEED-M-ALL`-t.

A projekted befejezéséhez már csak egyetlen dolog hiányzik: egy kódrészlet, amely kiszámítja, mennyi takarmányt kapjon minden tehén.
Fontos, hogy minden tehén ugyanannyit kapjon, el kell kerülnöd a konfliktusokat.
A tehenek nagyon érzékenyek.

Szerencsére nem neked kell kidolgoznod a takarmánymennyiség kiszámításához szükséges összes képletet.
Egy titokzatos külső könyvtárat használsz, amelyet az interneten találtál.
Elvileg ettől lesznek a legboldogabbak a tehenek.
A könyvtár közzétesz egy típust, amely megvalósítja a következő interfészt.
Erre fogsz támaszkodni a saját kódodban.

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

Ahogy a kódodon dolgozol, fokozatosan javítani fogod a hibakezelést, hogy az robusztusabb legyen, és később könnyebben lehessen debugolni, amikor a mindennapi farméletedben használod.

## 1. Oszd el egyenletesen a takarmányt

Először is arra összpontosítasz, hogy megírd a tehenenkénti takarmánymennyiség kiszámításához szükséges kódot.

Valósítsd meg a `DivideFood` függvényt, amely argumentumként egy `FodderCalculator`-t és a tehenek számát egész számként fogadja.
*Ennél a részfeladatnál feltételezed, hogy az átadott tehenek száma mindig nagyobb nullánál.*
A függvénynek a tehenenkénti takarmánymennyiséget kell visszaadnia `float64`-ként, vagy egy hibát, ha az történt.

A számításhoz először le kell kérdezned az összes tehén teljes takarmánymennyiségét.
Ezt úgy teheted meg, hogy meghívod a `FodderAmount` metódust, és átadod neki a tehenek számát.
Ezenkívül szükséged van egy tényezőre is, amellyel ezt a mennyiséget meg kell szorozni.
Ezt a tényezőt a `FatteningFactor` metódus meghívásával kapod meg.
Ezzel a két értékkel és a tehenek számával most már kiszámíthatod a tehenenkénti takarmánymennyiséget (`float64`-ként).
Ezt kell visszaadnia a `DivideFood` függvénynek.

Ha a meghívott metódusok egyike hibát ad vissza, a végrehajtásnak le kell állnia, és azt a hibát változatlan formában vissza kell adnia a `DivideFood` függvénynek.

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. Ellenőrizd a tehenek számát

Miközben az első részfeladaton dolgoztál, rájöttél, hogy a használt külső könyvtár nem olyan jó minőségű, mint gondoltad.
Például nem tud megfelelően kezelni az érvénytelen bemeneteket.
Ezt a korlátot úgy szeretnéd megkerülni, hogy a saját kódodban ellenőrzést adsz a bemeneti értékhez.

Írj egy `ValidateInputAndDivideFood` függvényt, amelynek ugyanaz a szignatúrája, mint a fenti `DivideFood`-nak.

- Ha az átadott tehenek száma nagyobb 0-nál, a függvény hívja meg a `DivideFood`-ot, és adja vissza a hívás eredményét.
- Ha a tehenek száma 0 vagy kevesebb, a függvény adjon vissza egy hibát a következő üzenettel: `"invalid number of cows"`.

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. Javítsd a hibakezelést

Jó döntés volt ellenőrizni a tehenek számát, mielőtt továbbadtad, de nem vagy egészen elégedett a nem túl konkrét hibaüzenettel.
Úgy döntesz, hogy jobban csinálod: létrehozol egy egyedi hibatípust `InvalidCowsError` néven.

Az egyedi hibának tartalmaznia kell a tehenek számát (`int`) és egy egyedi üzenetet (`string`), az `Error` metódusnak pedig a következő formátumban kell sorosítania az adatokat:

```txt
{number of cows} cows are invalid: {custom message}
```

Felvértezve az egyedi hibáddal valósítsd meg a `ValidateNumberOfCows` függvényt, amely a tehenek számát egész számként fogadja, és egy hibát (vagy nil-t) ad vissza.

- Ha a tehenek száma kisebb 0-nál, a függvény egy `InvalidCowsError` hibát ad vissza, amelynek egyedi üzenete `"there are no negative cows"`.
- Ha a tehenek száma 0, a függvény egy `InvalidCowsError` hibát ad vissza, amelynek egyedi üzenete `"no cows don't need food"`.
- Egyébként a függvény `nil`-t ad vissza, jelezve, hogy az ellenőrzés sikeres volt.

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

Miután rengeteg munkát fektettél ebbe az ellenőrző függvénybe, észreveszed, hogy már este van, és otthagyod az asztalodat, hogy élvezd a naplementét a hegyek fölött.
Az új ellenőrző függvény tényleges beépítését a kódodba egy másik napra hagyod.
