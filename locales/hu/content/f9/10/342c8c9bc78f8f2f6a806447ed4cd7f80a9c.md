# Bevezetés

A *quotation* egy kódrészlet `[ ]` zárójelben. Egy érték:
betolhatod a verembe, átadhatod egy másik szónak, vagy eltárolhatod
egy tömbben.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

A legtöbb magasabb rendű szó második argumentumként egy quotationt vár:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

A quotation törzse egyszerű, hétköznapi Factor-kód: ugyanazok az
operátorok és veremhatások, amelyeket mindenhol máshol használsz.

Amikor adatokból építesz kódot, például darabokat fűzöl össze, vagy
tokeneket rendelsz műveletekhez, az eredmény egy sorozat; futtasd át a
`>quotation` szón, hogy hívhatóvá váljon:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
