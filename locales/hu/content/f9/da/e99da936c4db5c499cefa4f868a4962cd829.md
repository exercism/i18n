# Bevezetés

Ez a feladat arra az adatveremre és veremhatás-jelölésre épül, amivel a [Cargo Shuffle][cargo-shuffle] feladatban találkoztál. Itt olyan szavakat írsz majd, amelyek Boolean értékeket kombinálnak.

## Shuffle szavak

A leggyakoribb shuffle szavak a [`kernel`][kernel] szótárban találhatók:

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## Boolean-ok

Két Boolean-literál létezik: `t` és `f`. A Factorban az `f` az egyetlen hamis érték. Minden más igaz értékű, köztük a `0` és az üres gyűjtemények is.

```factor
t .    ! => t
f .    ! => f
```

## Boolean szavak

Ez a három Boolean szó a `kernel` szótárból származik:

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

A kimenetekben szereplő `?` a veremhatás-jelölés megállapodása szerint »Boolean értéket« jelöl.

Az alábbi részfeladatok egyikéhez szükséged lesz a `swap` szóra.
