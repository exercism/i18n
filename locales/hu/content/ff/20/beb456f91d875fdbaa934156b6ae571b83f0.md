# Bevezetés

## Switch utasítások

Az _if/else_ utasításhoz hasonlóan a `switch` utasítással is megváltoztathatod a program menetét, méghozzá úgy, hogy feltételesen hajtasz végre kódot.
A különbség az, hogy a `switch` utasítás csak egy primitív vagy string kifejezés értékét tudja összehasonlítani előre meghatározott konstans értékekkel.

Néhány kulcsszó hasznos, amikor switch utasítást használsz.

- `switch`: ezzel a kulcsszóval deklarálod a switch szerkezetét.
  Utána az a kifejezés vagy változó következik, amely megváltoztatja az eredményt.
- `case`: ezzel a kulcsszóval deklarálod az eredmény lehetséges változatait.
- `break`: a `break` kulcsszó nagyon hasznos ahhoz, hogy a switch végrehajtása a kívánt folyamat végén megálljon.
  Ha elfelejted, a program folytatódik, és ez váratlan eredményekhez vezethet.
- `default`: ahogy a neve is sugallja, akkor használd, amikor egyetlen más eset sem illeszkedik a kifejezésed eredményére.

A legegyszerűbb esetben egy primitív vagy string kifejezést vizsgálnak, és az értékük alapján döntenek.
Például:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
