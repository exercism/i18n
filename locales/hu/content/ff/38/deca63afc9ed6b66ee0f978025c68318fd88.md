# Névjegy

## Számok

A Swift két fő számkategóriát különböztet meg: az egészeket és a lebegőpontos számokat.

- Az [egész számok][integers] olyan számokat jelölnek, amelyeknek nincs törtrészük, például `0`, `1`, `-1`, `42` és `-273`.
- A [lebegőpontos számok][floatingpoint] olyan számokat jelölnek, amelyeknek van törtrészük, például `0.0`, `3.14` és `-1.36969e-10`.

A számliterálokba aláhúzásjeleket szúrhatsz be az olvashatóság javításához: az `1_000_000` ugyanaz, mint a `1000000`.
A lebegőpontos literálok tizedes vagy exponenciális jelöléssel is felírhatók.

A legtöbb esetben az egészekhez [`Int`][int]-et, a lebegőpontos számokhoz pedig [`Double`][double]-t használsz:

```swift
let speed: Int = 42                           // Explicit Int
let pi: Double = 3.14                         // Explicit Double
let giga: Double = 1_000_000_000              // Double with readability underscores
let plancksConstant: Double = 6.62607015e-34  // Double in scientific notation
```

## Aritmetikai operátorok

A Swift szabványos [aritmetikai operátorokat][arithmetic-operators] biztosít a numerikus számításokhoz:

| Operátor | Leírás    | Példa |
| -------- | -------------- | ------- |
| `+`      | Összeadás       | `4 + 6` értéke `10` |
| `-`      | Kivonás    | `15 - 10` értéke `5`  |
| `*`      | Szorzás | `2 * 3` értéke `6`  |

~~~~exercism/caution
A Swift típusbiztos, és nem engedi, hogy az aritmetikai műveletekben különböző numerikus típusokat keverj.
Egy `Int` és egy `Double` értéket nem adhatsz össze vagy szorozhatsz össze közvetlenül; először az egyik típust a másikhoz kell alakítanod.
~~~~

### Osztás

A `/` operátor az osztást végzi.
Ha mindkét operandus egész szám, az egész osztás levágja a törtrészt:

```swift
5.0 / 2.0 // 2.5 (Double division)
5 / 2     // 2 (integer division truncates the remainder)
```

Ha egy nem nulla lebegőpontos számot osztasz nullával, az eredmény `inf` vagy `-inf` lesz.
Ha a `0.0`-t `0.0`-val osztod, az eredmény `nan` (Not a Number).
Ezzel szemben, ha egy egész számot osztasz nullával, az fordítási vagy futásidejű hibát okoz:

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following line will not compile:
// print(5 / 0) // Error: Division by zero
```

### Maradék operátor

A [maradék operátor][remainder-operator] (`%`) azt a maradékot számítja ki, amely két egész szám osztása után megmarad:

```swift
5 % 2  // 1
-5 % 2 // -1

// Dividing by zero produces an error:
// 5 % 0 // Error: Division by zero
```

~~~~exercism/note
A Swiftben a `%` valódi *maradék* operátor, nem modulo operátor.
Az eredmény mindig az első operandus (az osztandó) előjelét veszi fel, függetlenül a második operandus előjelétől:

```swift
5 % -2  // 1
-5 % 2  // -1
```
~~~~

## Lebegőpontos számok kerekítése

Egy lebegőpontos számot a `rounded()` metódussal kerekíthetsz.
A `rounded()` alapértelmezés szerint a legközelebbi egész számra kerekít.
Megadhatsz egy konkrét [kerekítési szabályt][rounding-rule] is, például a `.up` vagy a `.down` értéket:

```swift
let x = 3.14
let y = x.rounded()      // 3.0
let w = x.rounded(.down) // 3.0
let z = x.rounded(.up)   // 4.0
```

## Típuskövetkeztetés

Amikor egy numerikus konstanst vagy változót típusannotáció nélkül deklarálsz, a Swift kikövetkezteti a típusát:

- Az egész számok alapértelmezett típusa `Int`.
- A tizedespontot tartalmazó számok alapértelmezett típusa `Double`.

```swift
let x = 42         // Inferred as Int
let y = 42.0       // Inferred as Double
let z: Double = 42 // Explicitly typed as Double
```

## Típuskonverzió

Ahhoz, hogy különböző típusú értékek között műveleteket végezz, alakítsd át az egyik értéket típusinicializálókkal, például a `Double(_:)` vagy az `Int(_:)` segítségével:

```swift
let integerCount = 42
let floatingCount = Double(integerCount)
print(floatingCount) // Prints 42.0

let pi = 3.14
let integerPi = Int(pi)
print(integerPi) // Prints 3 (fractional part is truncated)
```
