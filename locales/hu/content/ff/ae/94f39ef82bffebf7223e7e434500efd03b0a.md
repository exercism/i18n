# Névjegy

A [repeat-while ciklusok][repeat-loops] hasonlítanak a `while` ciklusokhoz, egy lényeges különbséggel: a feltétel ellenőrzése nem a ciklus törzsének végrehajtása előtt, hanem *utána* történik.
Emiatt a `repeat-while` ciklus garantáltan legalább egyszer végrehajtja a kódblokkját.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
