# Bevezetés

A JSON-**objektum** más nyelvek terminológiájával élve egy „hash”, „map” vagy „szótár”.

A JSON így definiál egy _objektumot_:

> Az objektum **név**/**érték** párok rendezetlen halmaza.
> Az objektum `{` nyitó kapcsos zárójellel kezdődik, és `}` csukó kapcsos zárójellel végződik.
> Minden _nevet_ `:` kettőspont követ, a _név/érték_ párokat pedig `,` vessző választja el.

A _név_ **csak string lehet**.
A _nevet_ másképp _kulcsnak_ is hívják.

Az _érték_ bármilyen JSON-típusú lehet.
Ugyanabban az objektumban a különböző _értékek_ különböző típusúak lehetnek, mint ebben a példában.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Vegyük észre, hogy az _utolsó_ kulcs-érték pár után **nem lehet** vessző.

## Objektumok létrehozása

A név/érték párok összegyűjtéséhez kapcsos zárójeleket használj.
Bár a neveknek stringnek kell lenniük, nem kell őket idézőjelbe tenni, ha **azonosítószerűek** (alfanumerikus karakterekből és aláhúzásjelből állnak, és nem számjeggyel kezdődnek).

```jq
{name: "Jane", age: 42}
```

Érvényes olyan kulcsokat használni, amelyek nem _azonosítószerűek_.
Csak tedd őket idézőjelbe.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Ha a név egy kifejezés eredménye, akkor a kifejezést **zárójelbe** kell tenni.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## Indexelés

Az értékeket **pont jelöléssel** kérjük le az objektumból.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Ha nem tudsz a kulcsra azonosítóként hivatkozni, használd a **szögletes zárójeles jelölést**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## Kulcs-érték párok hozzáadása vagy módosítása

Ha új kulcs-érték párt szeretnél hozzáadni egy tömbhöz, vagy frissíteni szeretnéd egy meglévő kulcs értékét, használd a `=` értékadó operátort úgy, hogy a bal oldalon egy indexkifejezés áll.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

A `+` operátor _egyesíti_ az objektumokat.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## Kulcs eltávolítása

A kulcs eltávolításához használd a `del` függvényt.
A frissített objektumot adja vissza.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

A `del` paramétere egy **indexkifejezés** (pont- vagy szögletes zárójeles jelöléssel), amely az objektum egy kulcsára oldódik fel.
A `jq` ezt **útvonalkifejezésnek** nevezi.
Nem elég egyszerűen egy stringet megadni.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## Tagság

- Ha ellenőrizni szeretnéd, hogy az objektumnak van-e egy kulcsa, használd a `has` függvényt.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Azt, hogy egy kulcs benne van-e egy objektumban, az `in` segítségével vizsgálhatod.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## Az összes kulcs listázása

Az összes kulcs listázásához használd a `keys` függvényt.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Vegyük észre, hogy a `keys` _rendezi_ a kulcsokat.
Ha az eredeti sorrendben szeretnéd lekérni őket, használd a `keys_unsorted` függvényt.

Nincs olyan megfelelő függvény, amely az összes _értéket_ listázná.
A `.[]` szűrő azonban _stream_-ként adja ki az objektum értékeit, és ez a stream a `[...]` tömbkonstruktorral fogható meg.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## Iterálás

- A `map_values(filter)` függvény a szűrőt az objektum minden egyes _értékére_ alkalmazza.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Ahhoz, hogy egy objektumon iteráljunk, először kulcs-érték objektumok tömbjévé kell alakítanod.
  Ezt a `to_entries` függvény végzi el.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  Ezen a ponton már használhatod a tömbiterációs függvényeket, például a `map`-et.

- A `from_entries` függvény ennek az ellentéte: kulcs-érték objektumok tömbjét alakítja vissza objektummá.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- Ha egy szűrőt az objektum _minden egyes_ kulcs-érték párjára alkalmazni szeretnél, használd a `with_entries(filter)` függvényt.

  Például ha adott egy objektum, amely egy nevet életkorhoz rendel, a kulcsok és az értékek a következőképpen cserélhetők fel.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  az alábbi kimenetet adja:

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  A `with_entries(filter)` ugyanaz, mint

  ```jq
  to_entries | map(filter) | from_entries
  ```
