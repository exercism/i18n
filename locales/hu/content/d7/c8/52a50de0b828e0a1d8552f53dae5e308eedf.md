# Utasítások

Sarah egy új szerepjátékot fejleszt, és a játékosmechanikához kérné a segítségedet.

## 1. Definiáld a `player` tuple-t

Definiálj egy `player` tuple osztályt négy slottal és alapértékekkel:

| slot     | alapérték |
| -------- | --------- |
| `name`   | `f`       |
| `level`  | `0`       |
| `health` | `100`     |
| `mana`   | `f`       |

Ha egyszer definiáltad, egy játékost literálként is létrehozhatsz:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. Mutasd be a játékost

Definiáld az `introduce` szót úgy, hogy a játékos nevét adja vissza. A lopakodó
játékosok elrejtik a nevüket (a `name` értéke `f`), és őket
`"Mighty Magician"` néven kell bemutatni.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. Támaszd fel az elesett játékost

Definiáld a `revive` szót úgy, hogy egy *új* játékost adjon vissza, amelynek a
`health` értéke 100, a `mana` értéke pedig 100, de csak akkor, ha a játékos
`health` értéke `0`. Ha a játékos még életben van, adj vissza `f`-et.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. Szenvedj el sebzést

Definiáld a `take-damage` szót úgy, hogy egy *új* játékost adjon vissza, amelynek
a `health` értéke a megadott mértékkel csökkent, de soha nem esik `0` alá.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
