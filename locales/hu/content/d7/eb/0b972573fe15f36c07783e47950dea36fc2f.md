# Bemutatás

Az Elixir az igaz és hamis értékeket a Boolean típussal ábrázolja. Csak két érték létezik: `true` és `false`. Ezeket az értékeket Boolean operátorokkal lehet kombinálni ([`and/2`][strict-and], [`or/2`][strict-or], [`not/1`][strict-not]):

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Az [`and/2`][strict-and], [`or/2`][strict-or] és [`not/1`][strict-not] operátor szigorúan Boolean jellegű, ami azt jelenti, hogy az _első_ argumentumuknak Boolean-nek kell lennie. Vannak ezzel egyenértékű Boolean operátorok is, amelyek bármilyen típusú argumentummal működnek: [`&&/2`][and], [`||/2`][or] és [`!/1`][not].

A Boolean operátorok _rövidzárásos kiértékelést_ használnak, ami azt jelenti, hogy az operátor jobb oldalán álló kifejezés csak akkor értékelődik ki, ha szükséges.

Mindegyik operátornak más a precedenciája: a `not/1` az `and/2` és az `or/2` előtt értékelődik ki. Zárójelekkel elérhető, hogy a kifejezés egy része a többiek előtt értékelődjön ki:

```elixir
not true and false
# => false

not (true and false)
# => true
```

Amikor olyan függvényt írsz, amely Boolean értéket ad vissza, [szokás, hogy a függvény nevét][naming] `?` jellel zárd le. Ugyanez a konvenció használható a Boolean értéket tároló változóknál is.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
