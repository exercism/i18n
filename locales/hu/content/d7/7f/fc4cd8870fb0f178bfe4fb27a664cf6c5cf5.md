# Bevezetés

Az olyan osztályok, mint a `LocalDate` és a `LocalDateTime`, egy _időpontot_ írnak le.
A `java.time` csomagban két olyan osztály is van, amely _időtartamot_ ír le:

- A `java.time.Period` években, hónapokban és napokban megadott időtartam, például „2 hónap és 5 nap”.
- A `java.time.Duration` órákban, percekben, másodpercekben, ezredmásodpercekben és nanoszekundumokban megadott időtartam, például „1 óra és 30 perc”.

A `Period` a naptárat követi, ezért dátumokkal és dátum-időkkel használod.
A `Duration` pontos időt mér, ezért időkkel és dátum-időkkel használod, dátumokkal viszont nem.

```exercism/note
A többi `java.time` osztályhoz hasonlóan a `Period` és a `Duration` is változhatatlan.
A metódusok, amelyek úgy tűnik, hogy megváltoztatják őket, valójában egy _új_ példányt adnak vissza.
```

## `Period`

A `Period` példányát az egyik statikus factory metódusával hozod létre:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

A `toString()` eredménye az [ISO-8601][iso-8601-durations] jelölést használja: egy `P` (a „period” rövidítése), amit az évek (`Y`), hónapok (`M`) és napok (`D`) száma követ.

Egy dátumhoz hozzáadhatsz egy periódust, vagy kivonhatsz belőle egyet:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Mivel a hónapok hossza eltérő, előfordulhat, hogy a hónapok hozzáadása olyan napra esik, amely nem létezik.
Ilyenkor az eredmény az adott hónap utolsó érvényes napjára tolódik vissza:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

A `Period.between()` az egyik dátumtól (beleértve) a másikig (nem beleértve) tartó periódust adja vissza:

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## Egységek számlálása a `ChronoUnit` segítségével

A `Period` külön tárolja az éveket, hónapokat és napokat.
A `getDays()` tehát csak a periódus napokban megadott _részét_ adja vissza, nem a napok teljes számát.
Ha két dátum között egyetlen egység összes előfordulását szeretnéd megszámolni, használd a [`java.time.temporal.ChronoUnit`][chronounit-docs] `between()` metódusát:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

Az eredmény negatív lesz, ha a második dátum korábbi az elsőnél:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

A `Duration` példányát szintén statikus factory metódusokkal hozod létre:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

Az ISO-8601 jelölésben a `T` választja el a dátumrészt az időrésztől, ezért írjuk az időtartamokat `PT...` alakban.

Egy dátum-időhöz hozzáadhatsz egy időtartamot, vagy kivonhatsz belőle egyet:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

A `Duration.between()` két dátum-idő között eltelt pontos időt adja vissza:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Egy időtartamot egyetlen egységre válthatsz át olyan metódusokkal, mint a `toHours()`, `toMinutes()` és `toSeconds()`.
Ezek az adott egységben kifejezett _teljes_ mennyiséget adják vissza, lefelé kerekítve:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Ha egy időtartamot az órához hasonlóan részekre szeretnél bontani, használd inkább a `toXxxPart()` metódusokat:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
