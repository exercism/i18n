# Utasítások

A barátod, Kojo nagy számrajongó.
Van egy kis weboldala, a „fun-with-numbers”.
Kojo nem túl jó programozásban, ezért segítséget kért tőled.

Két segédfüggvényt fogsz építeni Kojo weboldalának új számjátékaihoz, és egy harmadikat, amely ellenőrzi a felhasználó által megadható bemenetet.

## 1. Számítsd ki a nyerőgépen lévő számok összegét

Kojo weboldalának egyik játéka úgy néz ki, mint egy nyerőgép, amely két számkerekes csoportot mutat.
Minden számjegycsoport egy-egy számot jelöl.
A játék mechanikájához Kojónak tudnia kell ennek a két számnak az összegét.

Írj egy `twoSum` függvényt, amely két tömböt fogad paraméterként.
Mindegyik tömb egy vagy több 0 és 9 közötti számból áll.
A függvény mindegyik tömböt számként értelmezze, és adja vissza a két szám összegét.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Állapítsd meg, hogy egy szám palindrom-e

A weboldal egy másik játéka egy kis kvíz, amelynek a neve „Lucky Numbers”.
A felhasználó beírhat egy számot, és utána meglátja, hogy a szám egy titkos sorozathoz vagy mintázathoz tartozik-e.
A „szerencseszámok” sorozata vagy mintázata minden hónapban változik, és minden felhasználónak csak korlátozott számú próbálkozása van, hogy kitalálja.

Az e havi szerencseszámok palindrom számok legyenek.
A palindrom számok értéke nem változik, ha a számjegyeiket megfordítjuk.

Valósítsd meg az új `luckyNumber` függvényt, amely paraméterként egy számot fogad.
A függvény `true` értéket adjon vissza, ha a szám palindrom, egyébként pedig `false` értéket.
A bemeneti szám mindig pozitív egész szám lesz.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Készíts hibaüzenetet érvénytelen felhasználói bemenethez

A weboldal különböző pontjain vannak beviteli mezők, ahová a felhasználók számokat írhatnak be, majd egy gombra kattintva elindíthatnak valamilyen műveletet.
Kojo szeretné javítani az oldala felhasználói élményét.
Hibaüzenetet szeretne megjeleníteni arra az esetre, ha a felhasználó rákattint a gombra, de a mező érvénytelen bemeneti értéket tartalmaz.

Íme néhány további információ arról, hogyan adódik egy beviteli mező értéke.

- Ha a felhasználó beír valamit egy mezőbe, a hozzá tartozó érték mindig string, még akkor is, ha csak számokat gépelt be.
- Ha a felhasználó beír valamit, de aztán újra törli, a változó egy üres string lesz.
- Mielőtt a felhasználó egyáltalán elkezdett volna gépelni, a változó lehet `undefined` vagy `null`.

Írj egy `errorMessage` függvényt, amely paraméterként fogadja a felhasználói bemenetet.
Ha a felhasználó nem adott meg semmilyen bemenetet, az `errorMessage` a `'Required field'` értéket adja vissza.
Ha a bemenet nem reprezentál egy nem nulla számot (a JavaScript konverziós szabályai szerint), a `'Must be a number besides 0'` értéket kell visszaadnia.
Minden más esetben feltételezheted, hogy a bemenet érvényes, a visszatérési érték egy üres string legyen.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
