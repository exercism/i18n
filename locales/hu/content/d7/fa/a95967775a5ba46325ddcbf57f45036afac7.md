# Bevezetés

A Cairo-ban a típuskonverziók segítségével az adatokat egyik típusból a másikba alakíthatod, ami rugalmas és biztonságos adatkezelést tesz lehetővé.

## Alapok

A Cairo több mechanizmust kínál a típuskonverzióhoz:

### Közvetlen kasztolás

Kompatibilis numerikus típusoknál közvetlen kasztolást használhatsz:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### Az Into trait

Az `Into` trait egyik típusból a másikba való átalakítást tesz lehetővé:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### A TryInto trait

Azokhoz az átalakításokhoz, amelyek meghiúsulhatnak, használd a `TryInto`-t, amely egy `Option`-t ad vissza:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## Egyedi típuskonverziók

A saját típusaidhoz is implementálhatod az `Into` traitet:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## Biztonsági szempontok

- Használd a `TryInto`-t, ha az átalakítás meghiúsulhat (például nagy típusból kicsibe)
- Használd az `Into`-t, ha az átalakítás mindig sikerül
- Mindig kezeld a `TryInto`-ból származó `Option::None` eseteket
- Az előjeles és előjel nélküli típusok közötti átalakításnál figyelj a túlcsordulásra és az alulcsordulásra
