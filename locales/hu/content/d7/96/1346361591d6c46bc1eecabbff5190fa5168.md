# Bevezetés

## Függvények exportálása

A függvények exportálásáról az első fogalomban volt szó, most gyorsan átismételjük.

Az Elmben minden fájl egy modul, és minden más kód előtt szerepelnie kell benne egy `module` utasításnak.

A modulneveknek meg kell egyezniük a fájlnevükkel, tehát a `Calculator` modulnak a Calculator.elm fájlban kell lennie, a `Parser.Utils` modulnak pedig a Parser/Utils.elm fájlban.

Egy modulban definiált bármi csak a modulon belülről érhető el, kívülről nem, kivéve, ha szerepel az `exposing` felsorolásban.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Függvények importálása más modulokból

A más modulokban definiált függvényeket importálással érheted el.
Amikor importálsz egy modult, az összes általa közzétett függvény elérhetővé válik.
Az viszont, hogy hogyan éred el őket, attól függ, hogyan importálod a modult.

A minősített importálás az alapértelmezett, és egy ilyen modulban lévő függvényt (például a `List` modul `map` függvényét) a modul nevének előtagként való használatával érhetsz el (`List.map`).

A nyílt importálás közvetlen hozzáférést ad a modul közzétett függvényeihez, előtag nélkül. Ezt az `exposing` kulcsszóval éred el, mintegy tükörképeként az exportálásnál használtnak. Közzétehetsz minden elérhető függvényt (`..`), vagy csak bizonyosakat (például a `map` függvényt).

Típusokat és azok konstruktorait is importálhatod más modulokból, de ez egy későbbi fogalom.

A minősített importálást érdemes előnyben részesíteni, mert átláthatóbb, és elkerülhetők vele a névütközések.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Típusannotációk

A típusannotációkat a `name : parameter types -> return type` formában adjuk meg, a paramétertípusokat szintén `->` választja el egymástól.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

A függvényparaméterek megadásához zárójeleket is használhatsz (ezek maguk is ugyanazzal a szintaxissal definiálhatók, innen a zárójelek szükségessége).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Számok

Az Elmben kétféle szám létezik, amelyeket az `Int` és a `Float` típus határoz meg.
Az `Int` a pozitív és negatív egész számok halmazának felel meg.
A `Float` a valós számok halmazának felel meg, a számítógép pontossága által korlátozva.
A számokon definiált műveletek általában az egyik vagy a másik típuson működnek, de a kettőt nem keverheted.
Vannak függvények a kettő közötti átalakításra, például a `toFloat`, amely `Int`-et alakít `Float`-tá, valamint a `round`, `floor`, `ceiling` és `truncate`, amelyek egy `Float`-ot alakítanak `Int`-té, más-más szemantikával.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Műveletek stringekkel

A szavak és mondatok kódban való leírására az Elmnek van egy natív `String` típusa.
A stringliterálokat dupla idézőjelek közé írjuk, például `"Hello World!"`.
A stringek összefűzésére szolgáló `++` operátor és az egyenlőségvizsgáló `==` operátor alapból elérhető.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

A legtöbb további stringkezelő függvény a `String` modulban található, amelyet importálnod kell.

https://package.elm-lang.org/packages/elm/core/latest/String
