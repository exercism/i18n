# A Python telepítése

Ha a Python még nem érhető el a rendszereden, platformonkénti részletes útmutatót a hivatalos dokumentáció [Python Setup and Usage][using python] szakaszában találsz.
A Real Python is kínál egy [hasznos útmutatót][helpful guide] a telepítéshez különböző platformokon, köztük iOS-en és Androidon.

Végül Brett Cannon írásai, a [A quick-and-dirty guide][quick-and-dirty] és a [Why you should use `python -m pip`][python-m-pip], igen hasznos tanácsokkal szolgálnak arról, hogyan kezeld a Python-telepítéseket és a csomagokat.

**Megjegyzés MacOS-felhasználóknak:** a MacOS Monterey (12.3) előtt a `Python 2.7` előre telepítve volt az operációs rendszerrel.
A `Python 2.7` használatát az Exercism és a legtöbb más program nem támogatja.
Helyette a [Python 3][Python-three downloads] verziót telepítsd az alábbiakban részletezett módszerek valamelyikével.
A MacOS Monterey (12.3) óta a MacOS egyetlen Python-verziót sem telepít előre.

Néhány gyors hivatkozás a dokumentációba operációs rendszer szerint:

-  [Windows][windows] Ezen kívül a Microsoft [installing Python on windows][python-on-windows] című cikke is hasznos.
-  [Unix & Linux Systems][unix-and-linux] (_ezek nagy része MacOS-en is működik_)
-  [MacOS][macos]

   Érdemes átnézni a Real Python [Installing Python][installing-python] című cikkében bemutatott módszerek közül néhányat, vagy a fentebb hivatkozott Brett Cannon-cikkeket.


Az Exercism tesztjei és a tooling jelenleg a `3.10` - `3.13.5` verziót támogatja (_tesztek_), illetve a [`Python 3.13.5`][313-new-features] verziót (_tooling_).
A támogatás alóli kivételeket ott jelöljük, ahol előfordulnak.
A legtöbb feladat `Python 3.6+` verzióval, sőt akár korábbiakkal is működik.
Az [Active Python Releases][active-python-releases] alatt fel nem sorolt verziók támogatását azonban nem garantáljuk.


A jelenleg támogatott verziókról a [Python 3.13.x dokumentáció][3.13 docs] ad felvilágosítást.
