# Utasítások

Ebben a feladatban a [Pac-Man][Pac-Man] néhány szabályát kell megvalósítanod, a klasszikus 1980-as évekbeli játéktermi játékét.

Négy szabályt kell megvalósítanod, amelyek mind a játék állapotaihoz kapcsolódnak.

> _Ne foglalkozz azzal, hogyan származnak az argumentumok, csak arra összpontosíts, hogy az argumentumokat összekombinálva a kívánt eredményt add vissza._

## 1. Határozd meg, hogy Pac-Man megeszik-e egy szellemet

Definiáld az `eat_ghost()` függvényt, amely két paramétert vesz át (_hogy Pac-Mannek aktív-e az energiagolyója_, illetve _hogy Pac-Man éppen ér-e egy szellemet_), és logikai értéket ad vissza arról, hogy Pac-Man meg tud-e enni egy szellemet.
 A függvény csak akkor adjon vissza `True` értéket, ha Pac-Man energiagolyója aktív, és éppen ér egy szellemet.

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Határozd meg, hogy Pac-Man pontot szerez-e

Definiáld a `score()` függvényt, amely két paramétert vesz át (_hogy Pac-Man éppen ér-e egy energiagolyót_, illetve _hogy Pac-Man éppen ér-e egy pontot_), és logikai értéket ad vissza arról, hogy Pac-Man szerzett-e pontot.
 A függvény akkor adjon vissza `True` értéket, ha Pac-Man energiagolyót vagy pontot ér.

```python
>>> score(True, True)
...
True
```

## 3. Határozd meg, hogy Pac-Man veszít-e

Definiáld a `lose()` függvényt, amely két paramétert vesz át (_hogy Pac-Mannek aktív-e az energiagolyója_, illetve _hogy Pac-Man éppen ér-e egy szellemet_), és logikai értéket ad vissza arról, hogy Pac-Man veszített-e.
 A függvény akkor adjon vissza `True` értéket, ha Pac-Man éppen ér egy szellemet, és nincs aktív energiagolyója.

```python
>>> lose(False, True)
...
True
```

## 4. Határozd meg, hogy Pac-Man nyer-e

Definiáld a `win()` függvényt, amely három paramétert vesz át (_hogy Pac-Man megette-e az összes pontot_, _hogy Pac-Mannek aktív-e az energiagolyója_, illetve _hogy Pac-Man éppen ér-e egy szellemet_), és logikai értéket ad vissza arról, hogy Pac-Man nyert-e.
 A függvény akkor adjon vissza `True` értéket, ha Pac-Man megette az összes pontot, és a 3. részben meghatározott szabályok szerint nem veszített.

```python
>>> win(False, True, False)
...
False
```
