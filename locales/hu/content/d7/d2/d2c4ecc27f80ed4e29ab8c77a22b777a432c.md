# Bevezetés

A [`Time`][time] a Go-ban egy időpillanatot leíró típus.
A dátum- és időinformációk a metódusain keresztül érhetők el, hasonlíthatók össze és módosíthatók, de van néhány függvény, amelyet magán a `time` csomagon hívunk meg.
Az aktuális dátumot és időt a [`time.Now`][now] függvénnyel kérheted le.

A [`time.Parse`][parse] függvény stringeket alakít `Time` típusú értékekké.
A Go sajátos módon írja le, hogyan adod meg az elemzéshez várt formátumot.
A formátumot úgy írod le, hogy példát adsz rá ennek a különleges időbélyegnek az értékeivel:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

Például:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

A [`Time.Format()`][format] metódus az idő egy stringes reprezentációját adja vissza.
Ahogy a `Parse` függvénynél, a célformátumot itt is egy olyan példán keresztül adod meg, amely a különleges időbélyeg értékeit használja.

Például:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## Formátumbeállítások

Egyéni formátumhoz ezeknek a beállításoknak a kombinációját használd.
A Go-ban emellett előre definiált dátum- és időbélyeg-[formátumkonstansok][const] is elérhetők.

| Idő         | Beállítások                                    |
| ----------- | ---------------------------------------------- |
| Év          | 2006 ; 06                                      |
| Hónap       | Jan ; January ; 01 ; 1                         |
| Nap         | 02 ; 2 ; \_2 (a vezető 0-hoz)                  |
| A hét napja | Mon ; Monday                                   |
| Óra         | 15 ( 24 órás időformátum ) ; 3 ; 03 (AM vagy PM) |
| Perc        | 04 ; 4                                         |
| Másodperc   | 05 ; 5                                         |
| AM/PM jelölés | PM                                           |
| Az év napja | 002 ; \_\_2                                    |

A `time.Time` típusnak számos metódusa van egy adott időrész eléréséhez. Például óra: [`Time.Hour()`][hour], hónap: [`Time.Month()`][month].
Hogy ez pontosan hogyan működik, arról a [hivatalos dokumentációban][time] olvashatsz.

A [`time`][time] csomag egy másik típust is tartalmaz, a [`Duration`][duration]-t, amely egy eltelt időtartamot ír le, emellett támogatja az időzónákat, az időzítőket és más kapcsolódó funkciókat, amelyekről egy másik fogalomban lesz szó.
