# Utasítások

Ebben a feladatban egy módot valósítasz meg arra, hogy számon tartsd a helyi játékterem legnépszerűbb játékának csúcspontszámait.

## 1. Definiálj egy új csúcspontszámok mapjét

Egy új csúcspontszámok mapjének létrehozásához definiáld a `HighScore.new/0` függvényt, amely nem vesz át egyetlen argumentumot sem, és egy új, üres csúcspontszámok mapjét adja vissza.

```elixir
HighScore.new()
# => %{}
```

## 2. Adj hozzá játékosokat a csúcspontszámok mapjéhez

Ahhoz, hogy felvegyél egy játékost a csúcspontszámok mapjébe, definiáld a `HighScore.add_player/3` függvényt, amely 3 argumentumot vesz át:

- Az első argumentum a csúcspontszámok mapje.
- A második argumentum a játékos neve stringként.
- A harmadik argumentum a pontszám egész számként. Ez az argumentum opcionális, ezért a harmadik argumentumot 0 alapértelmezett értékkel valósítsd meg.

Az alapértelmezett kezdőpontszámot modulattribútumban tárold. Később még szükség lesz rá.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. Távolíts el játékosokat a csúcspontszámok mapjéből

Ahhoz, hogy eltávolíts egy játékost a csúcspontszámok mapjéből, definiáld a `HighScore.remove_player/2` függvényt, amely 2 argumentumot vesz át:

- Az első argumentum a csúcspontszámok mapje.
- A második argumentum a játékos neve stringként.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. Állítsd vissza egy játékos pontszámát

Egy játékos pontszámának visszaállításához definiáld a `HighScore.reset_score/2` függvényt, amely 2 argumentumot vesz át:

- Az első argumentum a csúcspontszámok mapje.
- A második argumentum annak a játékosnak a neve stringként, akinek a pontszámát vissza szeretnéd állítani.

A függvénynek akkor is működnie kell, ha a játékosnak még nincs pontszáma.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. Frissítsd egy játékos pontszámát

Ahhoz, hogy egy játékos pontszámát a korábbi pontszámhoz hozzáadva frissítsd, definiáld a `HighScore.update_score/3` függvényt, amely 3 argumentumot vesz át:

- Az első argumentum a csúcspontszámok mapje.
- A második argumentum annak a játékosnak a neve stringként, akinek a pontszámát frissíteni szeretnéd.
- A harmadik argumentum az a pontszám, amelyet a tárolt csúcspontszámhoz **hozzá** szeretnél adni.

A függvénynek akkor is működnie kell, ha a játékosnak nincs korábbi pontszáma: ilyenkor feltételezd, hogy a korábbi pontszám 0.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. Kérd le a játékosok listáját

Ahhoz, hogy megkapd a játékosok listáját, definiáld a `HighScore.get_players/1` függvényt, amely 1 argumentumot vesz át:

- Az első argumentum a csúcspontszámok mapje.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
