# Bevezetés

## Összehasonlító operátorok

Az R operátorkészlete ugyanaz, mint sok más nyelvé:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Elágazás

Az if-else alapformája így néz ki:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

Ebben az esetben a boolean körüli zárójelek (`()`) és a törzs körüli kapcsos zárójelek (`{}`) is kötelezőek.

Egy egyszerű `if` utasítás lerövidíthető:

```R
if (x == 0) return("success")
```
