# Bevezetés

## Opaque típusok

A Gleamben az opaque típusok olyan egyedi típusok, amelyek értékeit csak az a modul hozhatja létre vagy illeszthet rájuk mintát, amelyik magát a típust definiálja. Ez akkor hasznos, ha olyan típusokat szeretnénk létrehozni, amelyeket csak egy meghatározott módon szabad használni.

Az opaque típusokat az `opaque` kulcsszóval definiáljuk.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Ezt a `PositiveInt` típust olyan helyzetekben érdemes használni, ahol egy egész számra van szükség, de annak nullának vagy nagyobbnak kell lennie. Egy sima Gleam `Int` nem lenne jó erre, mert az negatív is lehet.

Az a modul, amelyik definiálja ezt a típust, definiálhat egy függvényt a benne tárolt egész szám értékének kiolvasására, és egy függvényt a `PositiveInt` típus létrehozására, amely hibát ad vissza, ha az érték nem pozitív.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Ezzel az API-val más modulok nem hozhatnak létre negatív értékű `PositiveInt`-et, így minden függvény, amelyik `PositiveInt`-et kap, biztos lehet benne, hogy az érték pozitív.
