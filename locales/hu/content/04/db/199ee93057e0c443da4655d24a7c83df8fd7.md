# Névjegy

## Egyenlőség

Az Elm típusainál az „ugyanaz-e” kérdést az [egyenlőségoperátorral][equality-operator] `(==)` ellenőrizheted.
A nem-egyenlőség operátora a `(/=)` (*nem* `!=`, mint sok más nyelvben).

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

Mindkét összehasonlított értéknek ugyanolyan típusúnak kell lennie.
Az egyenlőségoperátor literálokon, tuple-okon, rekordokon és egyedi típusokon működik.
Az operátor strukturális egyenlőséget vizsgál, ami azt jelenti, hogy az egyenlő értékeknek a tartalma és a mély szerkezete is megegyezik, függetlenül a típusmegjelöléstől vagy a memóriabeli helyüktől.

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Figyelem: függvényeket *soha ne* hasonlíts össze, mert a program futásidőben összeomlik tőle.
Erről a korlátozásról [itt][equality-operator] találsz több információt.

## Összehasonlítások

Az [összehasonlító operátorok][comparison-operators] `(<)`, `(<=)`, `(>)`, `(>=)`, valamint a `min`, `max` és `compare` függvény `comparable` típusokon működnek.
A `comparable` egy különleges típus, amely az összes beépített, összehasonlítható típust fogja össze: számokat, karaktereket, stringeket, `comparable` értékek listáit és `comparable` értékekből álló tuple-okat.
A karakterek összehasonlítása a [unicode kódpontjaik][unicode-codepoint] alapján történik.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

A sorozatszerű típusok (stringek, listák és tuple-ok) összehasonlítása [lexikografikus sorrendben][lexicographic-order] történik.
Röviden: a sorozatok elemeit páronként, sorrendben hasonlítjuk össze, amíg nem találunk egy kisebb elemet, vagy el nem fogy az egyik sorozat.

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

Más típusok, például a rekordok vagy az egyedi típusok értékei nem hasonlíthatók össze közvetlenül.

Néhány beépített típus megköveteli, hogy a tartalma `comparable` legyen, például a `Set` vagy a `Dict` kulcsai, mivel a szerkezetük egy belső rendezésre épül.
Ez azt jelenti, hogy egyedi típusokat nem tárolhatsz `Set`-ben, bár a közösség kínál alternatívákat: [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] és mások.

A `comparable` értékek listáit a `List.sort`, a `comparable` értékekre leképezhető értékek listáit pedig a `List.sortBy` segítségével rendezheted.
Ha többszintű rendezésre van szükséged (rendezés az egyik tulajdonság szerint, majd a holtversenyek eldöntése egy másik szerint), a `List.sortBy`-hoz használhatsz tuple-okat vagy listákat (többek között [más alternatívák][sort-by] is léteznek), mivel a tuple-ok és a listák lexikografikus sorrendben rendeződnek.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

A `compare` függvény két `comparable` értéket vesz át, és egy `Order` értékkel tér vissza.
Az `Order` egy olyan típus, amely egyetlen művelettel megmondja, hogy egy érték nagyobb (`GT`), egyenlő (`EQ`) vagy kisebb (`LT`), mint egy másik.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

Összehasonlító függvényeket tetszőleges típusokhoz is készíthetsz, és például a `List.sortWith` segítségével rendezhetsz velük:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
