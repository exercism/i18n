# A switch utasítás

A `switch` utasítás egy `if..elseif..else` feltételes vezérlési szerkezetet valósít meg.

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      $message = 'First letter of the english alphabet';
      break;
    case 'z':
      $message = 'Last letter of the english alphabet';
      break;
    case 'l':
    default:
      $message = 'A letter, neither the first nor the last of the alphabet';
  }
  return $message;
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

A `switch` utasítások egyik különleges jellemzője az egyes `case` ágak „fall-through” viselkedése.
Figyeld meg a példában, hová kerültek pontosan a `break` utasítások.
`break` utasítás nélkül az egyes `case` ágak végrehajtása az első `case` kezdetétől addig tart, amíg egy `break` utasítás kiértékelésre nem kerül.
A `case` ágak sorrendje egy `switch`-en belül azért fontos, mert csak az első illeszkedő ágig történik kiértékelés.

> Egy figyelmeztetés: a „fall-through” viselkedés lehetővé teszi, hogy a hasonló `case` ágak közösen használjanak kódot, de nem szándékolt viselkedés és hibák forrása is lehet, ha elfelejted a `break` utasítást.

Minden `case` nem szigorú (laza) összehasonlítást végez:

```php
function matches($value): string
{
  switch ($value) {
    case false:
      return 'matches false';
    case true:
      return 'matches true';
  }
}

// matches([]) => 'matches false'
// matches(0) => 'matches false'
// matches(null) => 'matches false'
// matches('') => 'matches false'

// matches([1]) => 'matches true'
// matches(1) => 'matches true'
// matches('a') => 'matches true'
```

## `break` nélküli `switch`-minta

Tegyük fel, hogy a fenti példafüggvényt átírjuk:

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      return 'First letter of the english alphabet';
    case 'z':
      return 'Last letter of the english alphabet';
    case 'l':
    default:
      return 'A letter, neither the first nor the last of the alphabet';
  }
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

A függvény viselkedése ugyanaz marad, de ha közvetlenül a `switch` utasításból adunk vissza értéket, elkerülhetjük a `break` utasítás esetleges elhagyását.

## Feltételes kifejezéses `switch`-minta

A `switch` utasítás egy másik használati mintája, hogy minden `case` ágat egy kifejezéssel hasonlítunk össze:

```php
function compareSum(int $sum): string
{
  switch (true) {
    case $sum < 10:
      return 'Less than 10';
    case $sum > 10:
      return 'More than 10';
    default:
      return 'Sum is 10';
  }
}
```

Ez némi rugalmasságot ad változatosabb kifejezések írásához és a függvények összeállításához, amikor eldöntjük, melyik `case` ág fusson le.
