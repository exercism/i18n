# Bevezetés

## `Base.@kwdef`

A `Base.@kwdef` makróval automatikusan definiálhatunk olyan konstruktorokat, amelyek kulcsszóargumentumokat fogadnak egy [struct][struct] definíciójához.
Emellett lehetővé teszi a mezők alapértelmezett értékeinek beállítását is.

Például a következő definíció

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

egyszerre három konstruktort definiál

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

beleértve egy kulcsszóargumentumokon alapuló konstruktort is

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

míg a szokványos definíció

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

csak a következő kettőt definiálja

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

ezeknél viszont manuálisan kellene megírni a kulcsszavakon alapuló konstruktort.

### Mikor használjuk a `Base.@kwdef`-et?

A kulcsszavakon alapuló konstruktorok különösen hasznosak sok argumentumot fogadó structok létrehozásához, főleg akkor, ha az argumentumok típusa vagy értéke nem utal közvetlenül a jelentésükre.

Vegyük a következő definíciót:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

Nem derül ki, mit jelent az egyes értékek, ha nem ismerjük a típus definícióját.
És még ha ismerjük is a definíciót, valószínűleg újra meg újra meg kellene néznünk a sorrendet.

Ha viszont kulcsszavakon alapuló konstruktort használunk, a jelentésük azonnal nyilvánvaló:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
A `Base.@kwdef` nincs exportálva, és a kézikönyv sem dokumentálja, ezért nem része [a Julia nyilvános API-jának][public-api].
Ez azt jelenti, hogy a felülete technikailag nincs garantáltan stabil, és a Julia kisebb frissítései között megváltozhat.

A makrót azonban széles körben használják az ökoszisztémában, így valószínűtlen, hogy visszafelé nem kompatibilis módon megváltoztatnák.

További információért lásd:

- [Mit csinál a `@kwdef`?][discourse-kwdef]
- [A #32659-es Julia issue: a `@kwdef` felvétele a kézikönyvbe][add-kwdef-to-manual]
- [A #33192-es Julia issue: a `@kwdef` exportálása][export-kwdef]

~~~~
