# Bevezetés

A C#-ban a kivételek strukturált, egységes és típusbiztos módot kínálnak a futásidőben fellépő hibák kezelésére. A kivételek és a hibák megfelelő kezelése fontos, ha meg akarjuk akadályozni, hogy az alkalmazás összeomoljon.

A C#-ban minden kivétel alaptípusa a `System.Exception` osztály. Ez olyan fontos tulajdonságokat tartalmaz, mint a `Message`, amely ember által olvasható leírást ad arról, miért dobódott a kivétel.

Ahhoz, hogy jelezzük, hogy a kód egy adott részén hibának kell történnie, létre kell hozni egy új kivételobjektumot, majd a `throw` kulcsszóval dobni kell:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Amikor egy kivétel dobódik, a futtatókörnyezet feladata, hogy megtalálja azt a kódrészletet, amely felelős a kivétel kezeléséért. Ha nem található megfelelő kezelő, a futtatókörnyezet a program végrehajtásának leállítása mellett megjeleníti a kezeletlen kivétel üzenetét is.

Egy kivétel kezelőjének létrehozásához a C# a try-catch utasítást használja, amely egy `try` blokkból és egy vagy több `catch` ágból áll. A `try` blokknak azt a kódot kell tartalmaznia és óvnia, amelynél előfordulhat, hogy kivétel dobódik. A `catch` ágakban annak a kódnak kell lennie, amely a hiba bekövetkezése után kezeli a program viselkedését. Fontos megjegyezni, hogy a `try` blokk után a kivételek sorrendje számít, mert ha több kivétel szerepel, akkor az első illeszkedő `catch` ág fut le.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
