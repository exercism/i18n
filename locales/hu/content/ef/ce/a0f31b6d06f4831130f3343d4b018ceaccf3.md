# Bools

A Crystalben létezik egy [`Bool`][bools] nevű típus.
Ez a `true` és `false` értékeket képviseli.

## Logikai operátorok

A Crystalben három logikai operátor van (`!`, `||`, `&&`), amelyek Bool értékeket kapcsolnak össze, és különböző értékeket adó kifejezéseket hoznak létre.

### És(`&&`)

A Crystalben az [_és_ operátort][and] a `&&` jelöli, és akkor ad vissza `true`-t, ha mindkét érték `true`; egyébként `false`-t ad vissza.
Az _és_ operátor használatakor az egyik Bool a `&&` jobb oldalára, a másik pedig a bal oldalára kerül.

```crystal
true && true
# => true

true && false
# => false
```

### Vagy(`||`)

A Crystalben a [_vagy_ operátort][or] a `||` jelöli, és akkor ad vissza `true`-t, ha a megadott értékek közül **legalább az egyik** `true`.
Ha mindkét érték `false`, akkor `false`-t ad vissza.
A _vagy_ operátor használatakor az egyik Bool a `||` jobb oldalára, a másik pedig a bal oldalára kerül.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Nem(`!`)

A Crystalben a _nem_ operátort a `!` jelöli: `true`-t ad vissza, ha a megadott Bool `false`, és `false`-t, ha `true` az értéke.
A _nem_ operátor használatakor a Bool értéket az operátor (`!`) után kell elhelyezni.

```crystal
!true
# => false

!false
# => true
```

## Zárójelek használata(`()`)

Amikor Bool értékekkel dolgozol, zárójelekkel eldöntheted, hogy mely Bool értékek értékelődjenek ki először.
Az eredmény attól függően lehet más, hogyan használod a zárójeleket.
A Crystalben először a zárójelben lévő rész értékelődik ki.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Mivel először a zárójelben lévő rész értékelődik ki, a következő példában a _nem_ operátor a zárójelben lévő kifejezésre vonatkozik.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Zárójeleket csak akkor használj, ha befolyásolják az eredményt; egyébként hagyd el őket.
~~~~

## Truthy és falsey

A Crystalben a „falsey” értékek: `false`, `nil` és a null pointerek; **minden más** „truthy”.
Ezek az értékek a fent említett logikai operátorokkal használhatók.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## Metóduselnevezési konvenciók Boolean értékeknél

A Crystalben gyakori, hogy a truthy vagy falsey értéket visszaadó metódus nevét kérdőjellel (`?`) látjuk el.
A legtöbb esetben ez a metódus Bool értéket ad vissza, de ez nem kötelező.
Ez azt jelenti, hogy a metódus olyan helyeken is használható, ahol truthy vagy falsey értéket várunk, például egy `if` elágazás feltételeként:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

A nevük végén kérdőjelet viselő metódusok, amelyek nem adnak vissza Bool értéket, gyakran `nil`-t adnak vissza helyette. A `nil` _hasonló más nyelvek `None` vagy `null` értékéhez_.
