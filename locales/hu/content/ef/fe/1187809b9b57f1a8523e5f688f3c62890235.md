# Bevezetés

A Swift beépített [`Bool`][bools] típust kínál az igazságértékek, a `true` és a `false` reprezentálására.

## Logikai operátorok

A Swift három [logikai operátort][logical-operators] (`!`, `&&` és `||`) kínál Boolean kifejezések kombinálására és kiértékelésére.

### Logikai ÉS (`&&`)

Az [_és_ operátor][and] (`&&`) csak akkor ad vissza `true`-t, ha mindkét operandus `true`.
Ha valamelyik operandus `false`, akkor `false`-t ad vissza.
A `&&` jel mindkét oldalára tegyél egy kifejezést vagy egy Boolean értéket:

```swift
true && true  // true
true && false // false
```

### Logikai VAGY (`||`)

A [_vagy_ operátor][or] (`||`) akkor ad vissza `true`-t, ha az operandusok közül **legalább az egyik** `true`.
Csak akkor ad vissza `false`-t, ha mindkét operandus `false`.
A `||` jel mindkét oldalára tegyél egy kifejezést vagy egy Boolean értéket:

```swift
true || true   // true
true || false  // true
false || false // false
```

### Logikai NEM (`!`)

A [_nem_ operátor][not] (`!`) megfordítja a Boolean értéket.
`true`-t ad vissza, ha az érték `false`, és `false`-t, ha az érték `true`.
A `!` operátort közvetlenül az érték vagy a kifejezés elé helyezd:

```swift
!true  // false
!false // true
```

## A zárójelek használata (`()`)

A [zárójelek][explicit-parentheses] segítségével csoportosíthatod a kifejezéseket, és szabályozhatod a kiértékelés sorrendjét.
A Swiftben először a zárójelben lévő kifejezések értékelődnek ki:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

A zárójelezés azt is meghatározza, hogyan vonatkozik a NEM operátor az összetett kifejezésekre:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Akkor használj zárójelet, ha tisztázni szeretnéd a kiértékelés sorrendjét, vagy egy összetett feltételt könnyebben olvashatóvá szeretnél tenni.
Kerüld a felesleges zárójeleket, amikor az alapértelmezett műveleti elsőbbség egyébként is egyértelmű.
~~~~
