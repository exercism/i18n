# Kiegészítés az utasításokhoz

## Kurzusspecifikus utasítások

Történelmileg az Elm a funkcionális reaktív programozást használta, mígnem aztán az Elm Architecture használatára specializálódott.

Ezt a feladatot úgy oldd meg, mintha egy webalkalmazást írnál az Elm Architecture használatával.
A program kimenete a következő szerkezetű HTML legyen

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

ahol a `<dl>` a leíró lista eleme, a `<dt>` a leíró kifejezés eleme és a `<dd>` a leíró részletek eleme, és mindegyikük szabványos HTML-elem.

Hiba esetén a kimenet a következő szerkezetű legyen

```html
<div>
  <p>error message</p>
</div>
```
