### Terminológia

A `Vector{T}` az egydimenziós tömbök (`Array{T, 1}`) másik elnevezése.

## Párok

A `Pair` olyan adatszerkezet, amely pontosan két elemet tartalmaz, és ezek a `first` és a `second` mezőn keresztül érhetők el.

Létrehozhatod őket `x => y` alakban:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

A `Pair` elemei különböző típusúak is lehetnek:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

A `Pair` típusnak két gyakori felhasználása van a Juliában: a szótárak és a helyettesítések.

### Helyettesítések

Sok helyettesítő metódus argumentumként egy `Pair` értéket vár, hogy világos legyen, melyik elemet cseréli le.
Ez olyan szintaxist tesz lehetővé, mint például

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

ahol a gyűjteményben szereplő minden `4` helyére `0` kerül, szemben a kevésbé világos szintaxissal

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
