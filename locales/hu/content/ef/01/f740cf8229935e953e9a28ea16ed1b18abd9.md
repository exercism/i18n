# Az IO.puts előnyben részesítése a log_sent_email függvényben

Amikor sort írsz egy fájlba, inkább az `IO.puts/2` függvényt használd az `IO.write/2` helyett, mert az `IO.puts/2` automatikusan odatesz egy újsor karaktert a végére.

```elixir
# preferred
IO.puts(pid, email)

# not preferred
IO.write(pid, email)
IO.write(pid, "\n")
```
