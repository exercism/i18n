# Bevezetés

## Összehasonlítások

A C++-ban összehasonlító operátorokkal hasonlíthatsz össze értékeket.

| Összehasonlítás   | Operátor  |
| ------------------| --------- |
| egyenlő           | `==`      |
| nem egyenlő       | `!=`      |
| kisebb            | `<`       |
| kisebb vagy egyenlő | `<=`    |
| nagyobb           | `>`       |
| nagyobb vagy egyenlő | `>=`   |

Ezeknek az összehasonlításoknak az eredménye mindig egy Boolean érték:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

A `==` és a `!=` operátorok rendre azt ellenőrzik, hogy egy érték egyenlő-e egy másikkal vagy sem.
Íme néhány gyakori példa:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

A többi operátor azt vizsgálja, hogy az egyik érték nagyobb-e (`>`), nagyobb vagy egyenlő-e (`>=`), kisebb-e (`<`), illetve kisebb vagy egyenlő-e (`<=`), mint egy másik érték.
Ez a fajta összehasonlítás számokra és stringekre érhető el.
Stringek összehasonlításakor a szótári sorrendet (más néven lexikográfiai sorrendet) követjük.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## Elágazások

A C++ feltételes szerkezetei hasonlóak más nyelvekéhez.
Bármely feltételes művelet mögöttes típusa a `bool` típus, amelynek értéke `true` vagy `false` lehet.
A feltételes szerkezeteket gyakran vezérlési mechanizmusként használjuk különböző feltételek ellenőrzésére.

Használhatsz `if` utasítást, amely akkor futtatja a kódját, ha a mögöttes feltétel `true`, például így:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Ha egynél több esetről van szó, több `if` utasítást is összefűzhetsz az `else if` és az `else` utasításokkal.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

A C++17 óta az `if` utasítások tartalmazhatnak egy rövid kezdőértéket megadó utasítást is, amellyel egy vagy több változót inicializálhatsz az `if` utasításhoz.
Például:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Megjegyzés: a kezdőértékadásban létrehozott változókra az if utasítás végén túl már nem lehet hivatkozni.
