# Részletesen

A `|>` operátor neve pipe operátor. A segítségével függvényhívásokat fűzhetsz egymás után úgy, hogy az előző függvényhívás által visszaadott érték adódik át a következő függvényhívásnak.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

A fenti kód megegyezik a következővel:

```gleam
string.append(string.uppercase("hello"), "?!")
```

A pipe operátor az értéket vagy első argumentumként adja át a függvényhívásnak, vagy egyetlen argumentumként egy új hívásnak, attól függően, hogy melyiknek lesz megfelelő a típusa.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Néha az értéket egy másik pozícióba szeretnénk átadni. Ilyenkor a `_` helyőrzővel jelölheted, hogy hová kerüljön az érték.

```gleam
100
|> some_function(1, _, 2)
```
