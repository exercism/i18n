# Névjegy

A Common Lispben minden kifejezés.
Egy kifejezés vagy egyetlen dolog (ezt nevezzük atomnak), vagy dolgok listája (amit zárójelekkel határolunk: `()`).

## Idézés

Minden S-kifejezés, így a szimbólumok is, idézhető:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Ez az idézés megakadályozza, hogy az S-kifejezés kiértékelődjön, és helyette adatként kezeli.
Íme egy remek [Stack Overflow-válasz][so-quoting], amely kicsit részletesebben tárgyalja az idézést.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
