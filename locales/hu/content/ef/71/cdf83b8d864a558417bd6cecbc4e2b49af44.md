# Debug

Mivel a jelenlegi tesztfuttató a [PonyTest](https://stdlib.ponylang.io/pony_test--index/) könyvtárat használja, a Main actor a test.pony fájlban van, és a megoldásod részeként nem szabad módosítanod.

Ahogy az a Pony alkalmazásokban bevált gyakorlat, az `Env`-hez nem biztosítunk hozzáférést, csak ha feltétlenül szükséges. Ez azt jelenti, hogy szinte minden esetben nem tudod használni a printf-stílusú hibakeresést az `env.out.print()` segítségével.

A Ponynak viszont van egy [debug](https://stdlib.ponylang.io/debug--index/) modulja, amellyel a `-d` kapcsolóval fordított programok különleges hozzáférést kaphatnak az STDOUT-hoz és az STDERR-hez anélkül, hogy az `Env`-hez hozzáférnének.

Ha printf-stílusú hibakeresésre van szükséged, ezt a funkciót használd.

Példa a hibakeresésre:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
