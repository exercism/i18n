# Leírás

A pitagoraszi számhármas három természetes számból álló halmaz, {a, b, c}, amelyre

```text
a² + b² = c²
```

és amelyre

```text
a < b < c
```

Például,

```text
3² + 4² = 5².
```

Egy N egész szám bemenet esetén keresd meg az összes olyan pitagoraszi számhármast, amelyre `a + b + c = N`.

Például N = 1000 esetén pontosan egy olyan pitagoraszi számhármas van, amelyre `a + b + c = 1000`: `{200, 375, 425}`.
