# Bevezetés

A Factor hibarendszere három részből áll: a `throw` (a [`kernel`][kernel] szótárban) hibát dob, a `recover` (a [`continuations`][continuations] szótárban) elkap egy hibát, az `ERROR:` pedig egy tuple típusú hibaosztályt definiál.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

A `recover ( try recovery -- )` lefuttatja a *try* idézetet; ha az hibát dob, a hiba a veremre kerül, és lefut a *recovery* idézet.

Az `ERROR:` egyszerre deklarálja az osztályt *és* egy konstruktor szót, amely egy új példányt dob:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
