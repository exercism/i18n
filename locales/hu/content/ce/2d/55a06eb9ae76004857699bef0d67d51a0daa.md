# Őrfeltételek használata

[comment]: # (Ez a hiba akkor jelenik meg, ha a megoldás egyáltalán nem használ őrfeltételeket)

Használj [őrfeltételeket](https://hexdocs.pm/elixir/master/guards.html), hogy a `two_fer/1` ne hajtódjon végre nem bináris bemenetek esetén.

> Ne feledd, az Elixirben a [stringek](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) [bináris adatnak](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) számítanak.

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> Ez az őrfeltétel az `iex`-ben tesztelhető

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
