# A magasabb rendű függvényekről

A Kotlinban a függvények első osztályú állampolgárok.
Ez azt jelenti, hogy változókban tárolhatók, argumentumként átadhatók, sőt más függvények vissza is adhatják őket.
Például egy függvény hozzárendelése az `addOne` változóhoz:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Egy függvény visszaadhat egy másik függvényt is:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}
```

Miután hozzárendeltük, a függvény a változón keresztül hívható meg, mintha csak egy másik függvény lenne:
```kotlin
addOne(3)
// => 4
```

## Függvénytípusok deklarálása

Egy változó vagy paraméter típusa a `(parameter types) -> return type` szintaxissal deklarálható.
Például egy változó deklarálása:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

Egy függvényparaméter esetén pedig:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Lambda-kifejezések

A lambda-kifejezés a függvénydefiniálás rövidebb módja.
Formája `{ parameters -> body }`.
A kifejezés a törzs utolsó utasításának utolsó értékét adja vissza.
Például:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

A Kotlin ki tudja következtetni a típusokat, ha van elég információ.
Például a fenti példák így is írhatók:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## Az `it` használata egyparaméteres lambdáknál

Ha a kifejezésnek csak egy paramétere van, a paraméter elhagyható.
A Kotlin ilyenkor egy `it` nevű paramétert tesz elérhetővé a törzsben.
Például:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Záró lambdák átadása

Ha egy függvény utolsó argumentuma egy lambda, a lambda-kifejezést közvetlenül a zárójelek _után_ írjuk.
Például:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
