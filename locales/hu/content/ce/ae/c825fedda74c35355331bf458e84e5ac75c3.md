# Bevezetés

Ha rövid szavakról van szó, a veremmel való zsonglőrködés megteszi. Amikor viszont egy szónak több bemenete van, és név szerint kell rájuk hivatkoznod, a Factor a *locals*-t kínálja: nevesített kötéseket, amelyeket `::` (szódefiníciókhoz) vagy `[| | ]` (inline lambdákhoz) vezet be, és mindkettő a [`locals`][locals] szótárból származik.

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Egy quotation belsejében a `[| inputs | body ]` egy olyan lambda, amelynek nevesített bemenetei vannak:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
