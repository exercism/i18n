# Exercism API

## Leírás

A legtöbb Exercism nyelvi kurzus az `exercism` parancssori eszközzel kéri le és küldi be a feladatokat, amely REST API-n keresztül kommunikál az `exercism.io`-val. A Pharo Smalltalk nyelvi kurzus ehelyett ugyanezt a REST API-t használja, hogy feladatokat vigyen be a Pharo image-be és hozzon ki onnan, mindenféle közvetítő tooling nélkül. Ez a dokumentum részletesen bemutatja az Exercism API-t, különös tekintettel arra, hogyan használja a Pharo Smalltalk nyelvi kurzus. A Pharo Smalltalk tooling karbantartóinak szánjuk.

## Fejlécek

Minden végpontnál a kérés fejléceit a következő értékekre kell állítani:

```
Authorization: Bearer <token>
```

A `<token>` értéke a felhasználó parancssori hitelesítési tokenje, amely a `https://exercism.io/my/settings` címen érhető el.

## Feladatok lekérése

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

A fenti URL-ben a `<slug>` a feladat neve, például `hello-world`, a `<language>` pedig a nyelvi kurzus, például `pharo-smalltalk`.

### Válasz

#### 200

Egy sikeres kérés JSON-adatokat tartalmazó választ küld vissza. A JSON-ben a feladatra vonatkozó információk és egy URL található, amelyről a feladat fájljai letölthetők.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

A nyelvi kurzus neve nem egyértelmű, vagy a beküldött feladatfájlok nem változtak.

#### 403

A megoldás nincs feloldva a felhasználó számára, vagy nem csatlakozott a nyelvi kurzushoz.

#### 404

A nyelvi kurzus vagy a feladat nem található.

## Feladatok beküldése

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### Válasz

#### 201

Sikeres beküldés.

#### 400

Egy beküldött fájl túl nagy (több mint egy megabájt), vagy a megoldás duplikátum.

#### 403

A megoldás nem érhető el a felhasználó számára. A megoldás felhasználói azonosítója és az aktuális felhasználó azonosítója nem egyezik.

#### 404

A megoldás azonosítója nem található.
