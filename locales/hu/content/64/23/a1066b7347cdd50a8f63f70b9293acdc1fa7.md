# Utasítások

A feladatod, hogy a kézbesítési dátum leírásait _tényleges_ kézbesítési dátumokká alakítsd, attól függően, hogy mikor kezdődött a megbeszélés.

A kézbesítési dátum leírásainak két típusa van:

1. Rögzített: előre meghatározott szavak halmaza.
2. Változó: olyan szavak, amelyek tartalmaznak változó részt, de előre meghatározott mintákat követnek.

## Rögzített kézbesítési dátum leírások

Három rögzített kézbesítési dátum leírás van:

- `"NOW"`
- `"ASAP"` (amint lehetséges)
- `"EOW"` (a hét vége)

A következő táblázat mutatja, hogyan kell ezeket lefordítani:

| Leírás   | A megbeszélés kezdete      | Kézbesítési dátum                     |
| -------- | -------------------------- | ------------------------------------- |
| `"NOW"`  | -                          | Két órával a megbeszélés kezdete után |
| `"ASAP"` | 13:00 előtt                | Ma 17:00-kor                          |
| `"ASAP"` | 13:00-kor vagy utána       | Holnap 13:00-kor                      |
| `"EOW"`  | Hétfőn, kedden vagy szerdán | Pénteken 17:00-kor                    |
| `"EOW"`  | Csütörtökön vagy pénteken  | Vasárnap 20:00-kor                    |

## Változó kézbesítési dátum leírások

Két változó kézbesítési dátum leírásminta van:

- `"<N>M"` (N-edik hónap)
- `"Q<N>"` (N-edik negyedév)

| Leírás   | A megbeszélés kezdete             | Kézbesítési dátum                                            |
| -------- | --------------------------------- | ------------------------------------------------------------ |
| `"<N>M"` | Az N-edik hónap előtt             | 8:00-kor az idei év N-edik hónapjának _első_ munkanapján     |
| `"<N>M"` | Az N-edik hónapban vagy utána     | 8:00-kor a jövő évi N-edik hónap _első_ munkanapján          |
| `"Q<N>"` | Az N-edik negyedévben vagy előtte | 8:00-kor az idei év N-edik negyedévének _utolsó_ munkanapján |
| `"Q<N>"` | Az N-edik negyedév után           | 8:00-kor a jövő évi N-edik negyedév _utolsó_ munkanapján     |

~~~~exercism/note
A munkanap a hétfő, a kedd, a szerda, a csütörtök vagy a péntek.

Egy év négy negyedévből áll, mindegyik három hónapot tartalmaz:
1. Január/február/március
2. Április/május/június
3. Július/augusztus/szeptember
4. Október/november/december.
~~~~
