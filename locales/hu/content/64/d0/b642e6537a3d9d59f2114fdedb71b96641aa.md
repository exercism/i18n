# Utasítások kiegészítése

## Kimeneti formátum

A fehérjeszekvenciát nullával lezárt stringként add ki, minden fehérje után egy újsor karakterrel.

Egy példa kimenet így néz ki: `"Methionine\nPhenylalanine\nSerine\n"`

Ha a bemenet érvénytelen, üres stringet adj ki.

## Regiszterek

| Regiszter | Használat     | Típus   | Leírás                        |
| --------- | ------------- | ------- | ----------------------------- |
| `$a0`     | bemenet       | cím     | nullával lezárt bemeneti string  |
| `$a1`     | bemenet/kimenet | cím   | nullával lezárt kimeneti string  |
| `$t0-9`   | ideiglenes    | bármilyen | ideiglenes tárolásra szolgál  |
