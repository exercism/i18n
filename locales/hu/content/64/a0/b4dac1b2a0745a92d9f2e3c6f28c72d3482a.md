# Utasítások

Ebben a feladatban segédfüggvények egy részét valósítod meg, hogy segíts egy fejlesztőnek megtisztítani az azonosítók neveit.

Az 5 részfeladatban fokozatosan építed fel a `clean` függvényt.
Egy érvényes azonosító nulla vagy több betűből és alulvonásból áll.

Ha üres stringet adsz át a `clean` függvénynek, akkor annak üres stringet kell visszaadnia.

## 1. A szóközöket cseréld alulvonásra

Valósítsd meg a `clean1` függvényt, amely a szóközöket alulvonásra cseréli. Ez a kezdő és a záró szóközökre is érvényes.

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. A vezérlőkaraktereket cseréld a nagybetűs "[CTRL]" stringre

Valósítsd meg a `clean2` függvényt, amely mindent megtesz, amit az előző függvény, és a gyakori vezérlőkaraktereket (\n, \t és \r ) a `"[CTRL]"` stringre cseréli.

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. Alakítsd át a kebab-case-t camelCase-vá

Valósítsd meg a `clean3` függvényt, amely mindent megtesz, amit az előző függvény, és átalakítja a kebab-case-t camelCase-vá.

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. A számjegyek elhagyása 

Valósítsd meg a 'clean4` függvényt, amely mindent megtesz, amit az előző függvény, és elhagyja az összes számjegyet.

```elm
clean4 "123"
    --> ""
```

## 5. A görög kisbetűk elhagyása

Végül valósítsd meg a `clean` függvényt, amely mindent megtesz, amit az előző függvény, és elhagyja az 'α' és 'ω' közötti görög betűket.

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
