# Bevezetés

## Tömbök destrukturálása

A JavaScript tömbbeli destrukturálási szintaxisa tömör módja annak, hogy értékeket nyerj ki egy tömbből, és különálló változókhoz rendeld őket.

Ebben a példában a `numberOfMoons` tömb minden értéke a hozzá tartozó bolygóhoz van rendelve:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

Röviden:

- A szintaxissal nevet adhatsz egy tömb _pozíció szerinti_ elemeinek, és új értékadással felcserélhetsz változókat.
- A destrukturálási szintaxis függvényparamétereken belül is használható, és bármely iterálható értéken elérhető.
- Ha egy pozíciót név nélkül hagyod (vagyis _egyetlen_ változónevet sem írsz oda), az a pozíció csendben figyelmen kívül marad.

## Objektumok destrukturálása

A JavaScriptben destrukturálási szintaxis arra is van, hogy tulajdonságokat nyerj ki egy objektumból, és különálló változókhoz rendeld őket.

Ebben a példában időjárás-szimbólumokat nyerünk ki a `weather` objektumból:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

Röviden:

- A szintaxissal tulajdonságokat nyerhetsz ki, illetve nyerhetsz ki és nevezhetsz át egyszerre.
- A destrukturálási szintaxis függvényparamétereken belül is elérhető.
