# Számok

A Crystalnek van egy `Number` típusa, amely az összes numerikus típus alaptípusa.
A Number típuson belül két fő altípus található: [`Int`][int] és [`Float`][float].

Az `Int` az integer szó rövidítése, és egész számokat jelöl.
Az `Int` lehet negatív és pozitív is, tizedespont nélkül.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

A `Float` tizedespontos számokat jelöl.
A `Float`-ok egyaránt lehetnek negatívak és pozitívak.

```crystal
10.5.class
# => Float64
```

## Átalakítás `Int` és `Float` között

A 'to_i' és 'to_f' metódusokkal `Int` és `Float` között válthatsz át.
Amikor `Float`-ból `Int`-vé alakítasz, a szám lefelé kerekítődik.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Aritmetikai operátorok

Az [alapvető aritmetikai operátorokat][math] `Int` és `Float` értékeken is használhatod.
Az operátorok a `+`, `-`, `*`, `/` és `%`.
Ezeknek az operátoroknak a használatakor szabadon keverheted az `Int` és `Float` értékeket.

### Összeadás, kivonás és szorzás

A `+` operátor az összeadásra, a `-` operátor a kivonásra, a `*` operátor pedig a szorzásra szolgál.

| Operator | Example        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Osztás

Az osztás számok elosztására szolgál.
A `/` operátor az osztásra szolgál.
Az eredmény mindig Float lesz.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Egyes programozási nyelvekben a nullával való osztás eredménye hiba.

A Crystalben a nullával való osztás eredménye `Infinity` vagy `-Infinity`.
Az egyetlen kivétel a nulla nullával való osztása, aminek az eredménye `NaN` (nem szám).
Az `Infinity` és a `NaN` a `Float` típus különleges értékei.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## Egész osztás

Az egész osztás számok elosztására szolgál, és az eredmény egész részét adja vissza.
Az eredmény mindig lefelé kerekítve egy Int lesz.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
Az egész osztásnál a nullával való osztás `DivisionByZeroError` kivételt eredményez.
Ez eltér a szokásos osztástól.
~~~~

### Maradékos osztás

A maradékos osztás egy osztás maradékát adja meg.
A `%` operátor a maradékos osztásra szolgál.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
A maradékos osztásnál a nullával való osztás DivisionByZeroError kivételt eredményez.
Ez eltér a szokásos osztástól.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Hatványozás

A hatványozás egy szám hatványra emelésére szolgál.
A `**` operátor a hatványozásra szolgál.
Egy `Float` és egy `Int` közötti művelet eredménye `Float` lesz.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## Kerekítés

A `round` metódus egy opcionális argumentumot fogad: hány tizedesjegyre kerekítsen.
A tizedesjegyek alapértelmezett száma 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### Felfelé és lefelé kerekítés

A `ceil` és `floor` metódusokkal felfelé vagy lefelé is kerekíthetsz `Int`-té.
A `ceil` metódus felfelé, a `floor` metódus lefelé kerekít.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## Műveleti sorrend és zárójelek

A Crystal engedélyezi a zárójeleket (`()`), amelyekkel kifejezéseket csoportosíthatsz.
Ez akkor hasznos, ha meg szeretnéd változtatni a műveletek sorrendjét.

Ha több aritmetikai operátort használsz, a műveletek sorrendje ugyanaz, mint a matematikában, amit [PEMDAS][pemdas] néven is ismerünk.
A sorrend a következő: zárójelek (`()`), hatványozás (`**`), szorzás (`*`) és osztás (`/`), végül összeadás (`+`) és kivonás (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
