# Bevezetés

A dinamikus memóriát könyvtári függvények valósítják meg, amelyeket a programozó arra használ, hogy futásidőben memóriát foglaljon és szabadítson fel.
Mivel a memória lefoglalását és felszabadítását a programozó irányítja, a dinamikus memória pontosan annyira biztonságos, amennyire a programozó mentes az emberi hibáktól.
Éppen ezért a dinamikus memória a programozási hibák egyik fő forrása, és a hackertámadások egyik fő célpontja.

## malloc

A `malloc` egy `stdlib.h`-ban deklarált függvény, amely dinamikus memória lefoglalására szolgál.
Ha a foglalás sikeres, a függvény egy mutatót ad vissza, amely a lefoglalt memória első bájtjának címére mutat.
Ha a foglalás nem sikeres, a visszatérési érték `NULL`.
Érdemes ellenőrizni a `malloc` eredményét, hogy nem `NULL`-e, és ha nem sikerült a foglalás, azt megfelelően kezelni.
A visszaadott mutató típusa `pointer-to-void`, amely nagyjából „általános” mutatónak tekinthető, és átalakítható arra a konkrét típusra, amelyet a memória használ.
A `malloc` egyetlen paramétert vár, amely a kívánt memória mérete bájtban.
Egy tömb lefoglalásához szükséges teljes méret az egyes elemek adattípusának mérete szorozva az elemek számával.
Az egyes elemek adattípusának méretét leggyakrabban a `sizeof` operátorral lehet megkapni.
A következő példa ezt mutatja be

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

Fontos megjegyezni, hogy a `malloc` által újonnan lefoglalt memória nincs inicializálva, hanem szemét értékeket tartalmazhat.
Vegyük észre, hogy a `numbers` mutató `sizeof` értéke nem a tömb elemeinek száma, és nem is a lefoglalt memória teljes mennyisége.
A `malloc` által visszaadott mutató mérete megegyezik bármely mutató méretével az adott rendszeren.
A példakód egy 64 bites rendszeren futott, így a mutató mérete 8 bájt volt (szorozva bájtonként 8 bittel = 64 bit).
A mutató típusa implicit módon `pointer-to-void`-ból `pointer-to-int`-té alakult.
Explicit módon is át lehetett volna alakítani, például így: `int * numbers = (int *) malloc(sizeof(int) * count);`.
Ha az érték(ek)be biztosan írunk, mielőtt olvasnánk belőlük, akkor a `malloc` használata hatékony módja lehet a memóriafoglalásnak.
Ha azonban fennáll a lehetősége annak, hogy az érték(ek)et inicializálás előtt olvassák, akkor a `malloc` használata kockázatos.
A memóriafoglalás biztonságosabb módja a `calloc` használata, amely az újonnan lefoglalt memóriát nullára állítja.

A fenti példákban figyeljük meg, hogy szerepel bennük a `free(numbers)` hívás.

## free

A `free` egy `stdlib.h`-ban deklarált függvény, amely a dinamikusan lefoglalt memória felszabadítására szolgál.
A dinamikusan lefoglalt memória addig marad lefoglalva, amíg a `free` fel nem szabadítja.
Egyes operációs rendszerek automatikusan felszabadíthatják a dinamikusan lefoglalt memóriát, amikor a program befejeződik, de a helyes gyakorlat az, hogy erre ne támaszkodjunk.
A `free` egyetlen paramétert vár: egy mutatót a dinamikusan lefoglalt memóriára.
Az olyan mutatót, amelyet a felszabadítása után nem állítunk `NULL`-ra, lógó mutatónak nevezzük.
Egy lógó mutató a szándékolt memóriától eltérő területre is mutathat.
Így a lógó mutató adatromláshoz, valamint tetszőleges kód behelyettesítéséhez és végrehajtásához vezethet.
Egy olyan, lefoglalt memóriára mutató mutató, amelyet nem töröltünk `NULL` értékre állítással, a program feltörésére használható.
Helyes gyakorlat, hogy a mutatót `NULL`-ra állítjuk, miután átadtuk a `free`-nek.

## calloc

A `calloc` egy `stdlib.h`-ban deklarált függvény, amely egyszerre foglal dinamikus memóriát, és állítja az újonnan lefoglalt memóriát nullára.
Ha a foglalás sikeres, a függvény egy mutatót ad vissza, amely a lefoglalt memória első bájtjának címére mutat.
Ha a foglalás nem sikeres, a visszatérési érték `NULL`.
Érdemes ellenőrizni a `calloc` eredményét, hogy nem `NULL`-e, és ha nem sikerült a foglalás, azt megfelelően kezelni.
A visszaadott mutató típusa `pointer-to-void`, amely nagyjából „általános” mutatónak tekinthető, és átalakítható arra a konkrét típusra, amelyet a memória használ.
A `calloc` két paramétert vár.
Az első paraméter azt adja meg, hogy a megadott adattípusból hány darabot kell lefoglalni.
A második paraméter a lefoglalandó megadott adattípus mérete.

A következő példában minden `printf` utasításnak mindig `0`-t kell mutatnia, mert a `calloc` garantáltan nullázza az újonnan lefoglalt értékeket.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

A `realloc` egy `stdlib.h`-ban deklarált függvény, amely a meglévő lefoglalt memória bővítésére vagy szűkítésére szolgál.
Ha az újrafoglalás sikeres, a függvény egy mutatót ad vissza, amely az újrafoglalt memória első bájtjának címére mutat.
Ha az újrafoglalás nem sikeres, a visszatérési érték `NULL`.
Érdemes ellenőrizni a `realloc` eredményét, hogy nem `NULL`-e, és ha nem sikerült az újrafoglalás, azt megfelelően kezelni.
A `realloc` két paramétert vár.
Az első paraméter egy mutató a meglévő, újrafoglalni kívánt memóriára.
A második paraméter az újrafoglalt memória mérete bájtban.
A memória bővítése előtt beállított értékek megmaradnak.
Fontos megjegyezni, hogy a memória bővítésekor hozzáadott memória nincs nullára inicializálva, és az értéke(i) bármi lehet(nek).
A memória szűkítésekor eltávolított memória szintén nincs inicializálva, és megőrizheti az érték(eke)t.
A következő példa egy tömb bővítését és szűkítését mutatja be

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
