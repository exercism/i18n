# Utasítások

Larry egy Lisp Alien, aki szeret kódot írni, hogy játékokkal játszhasson.
Ma néhány függvényt szeretne írni, amelyek segítenek neki egy olyan játékban, ami nagyon hasonlít az amőbához.

Az amőbához hasonlóan ezt a játékot is egy 3x3-as rácsot alkotó táblán játsszák.

## 1. Kezdjük a nulláról

Először Larrynek egy függvényre van szüksége, amely üres táblát készít: `make-empty-board`.
A tábla minden cellája `NIL` legyen.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Kiindulás egy meglévő táblából

Ezután Larrynek egy olyan függvényre van szüksége, amely sorok listájából készít táblát.
Például:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. Győzelmi feltétel

Ha előfordul, hogy egy sorban ugyanabból a szimbólumból van 3, akkor az a játékos nyert.
Larrynek szüksége lesz egy `all-the-same-p` nevű függvényre, amely egy 3 elemű tömböt kapva `T` értékre értékelődik ki, ha minden elem ugyanaz a szimbólum.
(Két szimbólum azonosságát az `eq` segítségével lehet megállapítani.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. Egy sorban

Most Larrynek módot kell találnia egy sor elemeinek lekérésére.
A `row` függvény egy táblát és egy sorszámot kap, és a sor elemeit tartalmazó tömböt kell visszaadnia.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. Egy oszlopban

Végül Larrynek módot kell találnia egy oszlop elemeinek lekérésére.
A `column` függvény egy táblát és egy oszlopszámot kap, és az oszlop elemeit tartalmazó tömböt kell visszaadnia.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
