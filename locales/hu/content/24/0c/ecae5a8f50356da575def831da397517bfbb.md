# Bevezetés

Az egészeket nemcsak számértékként, hanem bitmintákként is szemlélhetjük.
A Factor `math` vocabularyje a szabványos, alacsony szintű műveleteket
tartalmazza ezeken a bitmintákon, a `math.bitwise` vocabulary pedig néhány
segédszót ad hozzá a rögzített szélességű értékek kezeléséhez.

## Biteltolás

A `shift ( m n -- m' )` eltolja `m` bitjeit. A *pozitív* `n` balra tolja
el (minden lépésben 2-vel szoroz); a *negatív* `n` jobbra tolja el (minden
lépésben 2-vel oszt):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

Pozitív egészeknél a jobbra tolás lehullatja az alsó biteket, és nullákkal
tölti fel a helyüket. *Negatív* egészeknél a Factor `shift` művelete
aritmetikai: megőrzi az előjelbitet, és fogalmilag az előjelbit másolataival
tölti fel balról. (A Factor egészei tetszőleges pontosságúak, így „a bal”
addig nyúlik, ameddig csak kell.)

## Bitenkénti logika

A négy alapvető logikai művelet:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

A `0b1011` `bitnot` művelete azért `-12`, mert a Factor egészei tetszőleges
pontosságúak: a `0b1011` bitjeit megfordítva fogalmilag „csupa egyest”
kapunk, amelynek alsó négy bitje `0100`-ra fordul, ez pedig előjeles
nagyszámként olvasva `-12`.

## Egy érték kezelése N bitként

A `math.bitwise`-ból származó `bits ( x n -- y )` az alsó `n` bitjére
maszkolja `x`-et. Ez a Factor-i módja annak, hogy „egy értéket N bites
előjel nélküli egészként értelmezzünk”:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

Ez a második példa fontos ebben a feladatban. Ha egy negatív, kettes
komplemensű Int32 értékből indulsz ki, és „logikailag” jobbra szeretnéd
tolni (balról nullákkal feltöltve) `amount` bittel, akkor a Factorban ez a
szokásos megoldás:

```
( value -- shifted )
32 bits  amount neg  shift
```

Először maszkolj 32 bitre, hogy áttérj az előjel nélküli értelmezésre,
aztán tolj el. Mivel a maszkolt érték nem negatív, a `shift` egyszerűen
lehullatja az alsó biteket, és nullákkal tölti fel a helyüket.
