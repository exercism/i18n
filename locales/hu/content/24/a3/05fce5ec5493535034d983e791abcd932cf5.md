# Bevezetés

Mivel a Clojure funkcionális nyelv, a függvények első osztályú állampolgárok benne. Ez azt jelenti, hogy ugyanúgy átadhatók más függvényeknek, és más függvények elő is állíthatják őket, mint bármilyen adatot. A Clojure ráadásul gazdag magasabb rendű függvénykészlettel rendelkezik, amelyek meglévő függvényekből származtatnak újakat. Négy fontos esetet vizsgálunk meg itt: a `partial`, a `comp`, a `memoize` és a `juxt` függvényt. Ezek a függvénygeneráló függvények a magasabb rendű függvények szélesebb kategóriájába tartoznak, amelybe beletartozik például a `map`, a `reduce`, az `apply` vagy a `complement` is, és amelyek mind meglévő függvényeken működnek.

## partial

Általánosságban, ha adott egy létező `my-function` függvény `p1, p2, ..., pN` paraméterekkel, akkor a paraméterei közül néhánynak, `p1, p2, ..., pM`-nek rögzíthetjük az értékét rendre `v1, v2, ..., vM`-re. Ezt úgy tesszük meg, hogy a `partial` függvényt a következőképpen alkalmazzuk: `(partial my-function v1 v2 ... vM)`.

Az eredmény egy új függvény, amely az eredeti `my-function` függvényt `p1=v1, p2=v2, ..., pM=vM` rögzítésével alkalmazza. Az új függvényünk bemenetként a fennmaradó `pM+1, pM+2, ..., pN` paramétereket veszi át, amelyeknek az értékét nem adtuk meg a `partial` alkalmazásakor:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Egyszerű példaként definiáljunk egy `inc-by-9` függvényt, amely 9-cel, egy rögzített értékkel növeli meg azt, amit csak átadunk neki. Ezt így valósíthatjuk meg:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Második példaként adott egy `generic-greetings` függvény, amely annak a személynek a nevét használja, akit köszönteni szeretnénk, valamint egy kezdő és egy záró szöveges üzenetet:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

Ezután a `partial` segítségével mindig egy adott köszöntőszöveget használhatunk:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

A `comp` segítségével tetszőleges számú függvényből készíthetünk kompozíciót. Általánosságban `N` függvény, `f1, f2, ..., fN` komponálása azt jelenti, hogy ezeket a függvényeket sorban egymás után alkalmazzuk, és az előző függvény kimenetét adjuk át a következőnek. Matematikai jelöléssel ez így fejezhető ki:

```
f1 (f2 (... fN(x)))
```

A Clojure-ban ez ezzel egyenértékű:
```clojure
(f1 (f2 (... (fN x))))
```

A comp használatával létrehozhatunk egy új függvényt, amely elvégzi helyettünk ezt a kompozíciót:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Példaként tegyük fel, hogy össze szeretnénk adni egy számsorozatot, majd az eredményt meg szeretnénk szorozni 6-tal. Ezt így tehetjük meg:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

A `memoize` lehetővé teszi, hogy újra felhasználjuk egy adott bemenethez korábban kiszámított eredményeket. Ugyanarra a bemenetre a *memoizált* függvény ugyanazt az eredményt adja vissza anélkül, hogy újra ki kellene számolnia. Kihasználja azt a tényt, hogy a `clojure` függvények alapértelmezés szerint *referenciálisan átlátszók*: ugyanarra a bemenetre mindig ugyanazt a kimenetet állítják elő, ami lehetővé teszi a korábbi számítások egyszerű újrafelhasználását.

Hogy lássuk, hogyan működik ez, használjunk egy mesterséges esetet, amelyben a függvény két másodpercet alszik, mielőtt előállítja a kimenetet, így könnyen összehasonlíthatjuk a *számítási időt* a `memoize` használata előtt és után.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

A `juxt` olyan függvényt generál, amely balról jobbra haladva alkalmazza a neki átadott függvényeket. Az eredmény egy vektor, amelynek komponensei az egyes függvények külön-külön kapott eredményei:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Egyszerű példaként generáljunk egy függvényt, amely kiszámítja x szorzatát egymást követő tényezőkkel, 2-től 5-ig:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
