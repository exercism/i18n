# A szótárakról

A [szótárak][dictionaries] a Swift elsődleges gyűjteménytípusainak egyike.
A szótár egyedi kulcsok és a hozzájuk tartozó értékek közötti, sorrend nélküli hozzárendeléseket tárol.
A szótárban az összes kulcsnak ugyanolyan típusúnak kell lennie, és az összes értéknek is ugyanazt a típust kell képviselnie.

A szótárliterálokat vesszővel elválasztott `key: value` párokként írjuk le, amelyeket szögletes zárójelbe zárunk:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

A szótárak típusát kétféleképpen írhatjuk le explicit módon: `Dictionary<Key, Value>` formában, vagy a rövidített `[Key: Value]` szintaxissal.

Üres szótár létrehozásához add meg explicit módon a kulcs és az érték típusát:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## Értékek elérése

Az értékeket indexelő jelöléssel érheted el: tedd a kulcsot szögletes zárójelek közé a szótár neve után.
Mivel előfordulhat, hogy egy kulcs nem létezik a szótárban, az indexelő hozzáférés egy *opcionális* értéket (`Value?`) ad vissza.
Ha a kulcs jelen van, a Swift a becsomagolt értéket adja vissza; ha nem, `nil`-t ad vissza:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

Ha el szeretnéd kerülni az opcionális értékekkel való munkát, megadhatsz egy alapértelmezett értéket a `default` paraméterrel:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## Szótárak módosítása

A `var`-ral deklarált módosítható szótáraknál az indexelő értékadással adhatsz hozzá vagy frissíthetsz kulcs-érték párokat:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## Végigiterálás egy szótáron

Egy szótár minden kulcs-érték párján végigiterálhatsz egy `for-in` ciklussal.
Minden elem egy `(key, value)` tuple formájában jelenik meg:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## Szótárak rendezése

Mivel a szótárak sorrend nélküliek, a rendezésük kulcs-érték párokból álló tömböt eredményez.
Átadhatsz egy closure-t a `sorted(by:)` metódusnak, amely két `(key, value)` tuple-t hasonlít össze, és `true` értéket ad vissza, ha az első tuple-nek a második előtt kell szerepelnie:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
