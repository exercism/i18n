# Utasítások

Ebben a feladatban különböző típusú távirányítós autók közötti versenyeket fogsz megszervezni.
Minden autónak megvan a maga sebessége és akkumulátorfogyasztási jellemzője.

Az autók tele (100%-os) akkumulátorral indulnak. Valahányszor vezeted az autót a távirányítóval,
az megteszi az autó sebességével megegyező métert, és a hátralévő akkumulátorszázalékot az
akkumulátorfogyasztásával csökkenti.

Ha egy autó akkumulátora az akkumulátorfogyasztása százaléka alá csökken, már nem tudod vezetni
az autót.

Minden versenypályának megvan a maga hossza. Az autókat úgy tesztelik, hogy megnézik, képesek-e
kifutni a pályát anélkül, hogy kimerülne az akkumulátoruk.

## 1. Hozz létre egy távirányítós autót

Definiálj egy `car` listát a következő elemekkel:

- speed
- battery_drain
- battery
- distance_traveled

Lehetővé teheted távirányítós autó létrehozását egy `new_car` függvény definiálásával, amely
paraméterként az autó méterben mért sebességét és az akkumulátorfogyasztás százalékát kapja, és
egy `car` listát ad vissza.

Egy új autó akkumulátora 100%-on van, a megtett távolság pedig nulla.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. Hozz létre egy versenypályát

Definiálj egy másik listát `track` néven, amelynek egyetlen eleme a `track_length`.
Lehetővé teheted versenypálya létrehozását egy `new_track` függvény definiálásával, amely a
pálya méterben mért távolságát kapja:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. Ellenőrizd, hogy lemerült-e az akkumulátor

Valósítsd meg a `battery_drained()` függvényt, amely jelzi, hogy lemerült-e az akkumulátor.
Az akkumulátor akkor számít lemerültnek, ha nincs benne elég energia egy újabb mozgáshoz.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. Vezesd az autót

Valósítsd meg a `drive` függvényt, amely az autó sebessége alapján frissíti a megtett méterek
számát, és az akkumulátorfogyasztásnak megfelelően csökkenti az akkumulátort.
Ha nincs elég akkumulátor egy újabb vezetéshez, az autó nem mozdul.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. Ellenőrizd, hogy egy távirányítós autó be tudja-e fejezni a versenyt

Egy verseny befejezéséhez az autónak képesnek kell lennie megtenni a verseny hosszát. Ez azt
jelenti, hogy nem merül ki az akkumulátora, mielőtt átlépné a célvonalat.

Valósítsd meg a `can_finish` függvényt, amely paraméterként egy `car` és egy `track` értéket kap,
és `TRUE`-t ad vissza, ha az autó be tudja fejezni a versenyt; egyébként `FALSE`-t.

Tételezd fel, hogy éppen a verseny rajtvonalánál vagy, és elindítod az autó motorját a versenyhez.
Vedd figyelembe, hogy az autó akkumulátora nem feltétlenül van teljesen feltöltve a verseny
kezdetekor.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. Tárold el, hogy az autó tele akkumulátorral be tudja-e fejezni a pályát

Létrehoztál több különböző hosszúságú pályát, és el kell tárolnod, hogy az autód tele
akkumulátorral be tudja-e fejezni őket.

Valósítsd meg a `store_track` függvényt, amely egy autót, egy pályát és egy pályanevet kap, és
egy frissített autót ad vissza egy extra elemmel.
Ennek az elemnek a neve a pálya `name` értéke legyen, az értéke pedig egy allista, amely
tartalmazza a `track_length` értéket, valamint egy `complete` logikai értéket, amely megmutatja,
hogy az autó teljesíteni tudja-e a pályát.

Előfordulhat, hogy az argumentumban kapott autó nincs teljesen feltöltve, ezért a használata előtt
mindenképp állítsd vissza az akkumulátort és a megtett távolságot.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
