# Kiegészítés az utasításokhoz

## Arturo-specifikus információk

Ebben a feladatban a korokat egy [fizikai mennyiség][physical-quantities] formájában kell visszaadnod, egy saját mértékegységgel, amely az adott bolygón egy év hosszát jelöli.
Az Arturóban egy mennyiség egy számértékből és egy hozzá tartozó [mértékegységből][unit-of-measurement] áll.

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
Az Arturo beépített `yr mértékegysége 31556952 másodpercnek felel meg.
Ezért definiálnod és használnod kell a saját, évhez tartozó mértékegységedet, az utasításokban korábban említett másodpercek számának megfelelően.
~~~~

A mennyiségek [átválthatók][convert] egy másik, kompatibilis mértékegységre.
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
A lebegőpontos számok pontossági korlátai miatt az Arturo néha racionális számként tárolja a skalárt.
A [`to` függvény][to] segítségével ehelyett közelítő lebegőpontos számként kérheted le az értéket.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Az Arturo emellett lehetővé teszi, hogy saját mértékegységeket [adjunk meg][specify] a mennyiségekhez.

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
