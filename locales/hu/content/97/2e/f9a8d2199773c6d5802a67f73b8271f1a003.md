# Részletek

Ha ugyanazt a logikát szeretnéd többször végrehajtani, használhatsz ciklusokat. A C# egyik leggyakoribb ciklustípusa a `while` ciklus, amely addig ismétlődik, amíg egy Boolean-feltétel kiértékelésének eredménye nem lesz `false`.

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 1;
}
```
