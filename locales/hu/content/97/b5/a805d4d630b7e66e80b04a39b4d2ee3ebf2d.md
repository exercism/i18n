# Bevezetés

## Lebegőpontos számok

A lebegőpontos szám olyan szám, amelynek a tizedesjel után nulla vagy több számjegy áll. Például `-2.4`, `0.1`, `3.14`, `16.984025` és `1024.0`.

A különböző lebegőpontos típusok különböző számú számjegyet tudnak tárolni a tizedesjel után, ezt nevezzük pontosságnak.

A C#-ban három lebegőpontos típus van:

- `float`: 4 bájt (kb. 6-9 számjegyes pontosság). Írásmódja: `2.45f`.
- `double`: 8 bájt (kb. 15-17 számjegyes pontosság). Ez a leggyakoribb típus. Írásmódja: `2.45` vagy `2.45d`.
- `decimal`: 16 bájt (28-29 számjegyes pontosság). Általában pénzügyi adatok kezelésekor használjuk, mert a pontossága csökkenti a kerekítési hibák esélyét. Írásmódja: `2.45m`.

Amint látható, a típusok különböző számú számjegyet tudnak tárolni. Ha például a PI-t egy `float`-ban próbálod tárolni, az csak az első 6 tizedesjegyet tárolja el (az utolsó tárolt számjegyet kerekítve).

## While-ciklusok

Ebben a feladatban szükséged lehet egy ciklusra. C#-ban többféleképpen is írhatsz ciklust, de itt a `while` ciklus a legmegfelelőbb:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## Do-while-ciklusok

Ha a ciklusban lévő kódnak legalább egyszer mindenképpen le kell futnia, akkor `do`/`while` ciklust használhatsz:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
