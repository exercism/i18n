# Bevezetés

A karakterosztályokon és a kvantorokon túl a reguláris kifejezések *szerkezetet* és *kontextust* is le tudnak írni. Ezek a lehetőségek ugyanabba a [`regexp`][regexp] szótárba és ugyanabba a `R/ /` literálba tartoznak.

A kerek zárójelek `( )` a minta egy részét csoportosítják, így egy kvantor vagy egy `|` („ez vagy az”) az egész csoportra vonatkozik; a csoport után álló `?` pedig választhatóvá teszi azt:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

A horgonyok a mintát egy adott pozícióhoz rögzítik: `^` (kezdet), `$` (vég) és `\b` (szóhatár).

A *lookaround* a hely környezete alapján illeszkedik, anélkül hogy elfogyasztaná azt:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

A záró `/` utáni opcióbetű az egész mintát megváltoztatja; az `i` kis- és nagybetűtől függetlenné teszi:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

A Factor az elfogó csoportok helyett lookaroundot használ: nincs elfogó csoport kinyerése, visszahivatkozás és lusta kvantor.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
