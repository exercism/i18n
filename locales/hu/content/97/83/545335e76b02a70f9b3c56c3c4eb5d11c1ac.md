# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít felkészülni egy jármű megvásárlására.

Három részfeladat vár rád: az egyikben eldöntöd, hogy kell-e jogosítvány, a másikban segítesz választani két jármű közül, a harmadikban pedig megbecsülöd egy használt jármű elfogadható árát.

## 1. Döntsd el, hogy szükséged lesz-e jogosítványra

Egyes járműfajták vezetéséhez jogosítvány kell.
Tételezd fel, hogy csak a `"car"` és a `"truck"` típushoz kell jogosítvány, minden más vezethető jogosítvány nélkül.

Valósítsd meg a `needs_license(kind)` függvényt, amely a jármű fajtáját stringként kapja, és egy Boolean értékkel tér vissza, ami megmutatja, hogy szükség van-e jogosítványra az adott járműfajtához.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. Válassz két lehetséges jármű közül, amelyiket megvásárolod

Mérlegeled a rendelkezésre álló járműveket.
Sikerül kettőre szűkítened a kört, de segítségre van szükséged a végső döntéshez.
Ehhez valósítsd meg a `choose_vehicle(option1, option2)` függvényt, amely két járművet kap argumentumként, és egy döntést ad vissza, amelyben az szerepel, amelyik lexikográfiai sorrendben előrébb van.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

A visszaadott string kövesse a „<CHOSEN_VEHICLE> is clearly the better choice.” mintát, ahol a `<CHOSEN_VEHICLE>` a kapott argumentumok közül kiválasztott opció.

## 3. Becsüld meg egy használt jármű árát

Most, hogy döntöttél, szeretnéd biztosítani, hogy tisztességes árat fizetsz a kereskedésben.
Mivel használt járművet szeretnél venni, az ár attól függ, milyen idős a jármű.
Durva becsléshez tételezd fel, hogy ha a jármű kevesebb mint 3 éves, az új kori eredeti ára 80%-ába kerül.
Ha legalább 10 éves, akkor 50%-ába.
Ha a jármű legalább 3 éves, de kevesebb mint 10 éves, az eredeti ár 70%-ába kerül.

Valósítsd meg a `calculate_resell_price(original_price, age)` függvényt, amely ezt a logikát `if`, `else if` és `else` segítségével alkalmazza (más megoldások is léteznek, ha gyakorolni szeretnél).
Az eredeti árat és a jármű korát kapja argumentumként, és a kereskedésben becsült árat adja vissza.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> Megjegyzés: a visszatérési érték típusa `double`.
