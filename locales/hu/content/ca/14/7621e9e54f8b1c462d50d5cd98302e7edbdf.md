# Bevezetés

## Boolean-ok

Az Elixir az igaz és hamis értékeket a Boolean típussal ábrázolja. Csak két érték van: `true` és `false`. Ezek az értékek egy változóhoz köthetők:

```elixir
true_variable = true
false_variable = false
```

Szigorú Boolean-kifejezéseket értékelhetünk ki a `and/2`, `or/2` és `not/1` operátorokkal.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Amikor olyan függvényt írsz, amely Boolean értéket ad vissza, szokás a függvénynév végére egy `?`-t tenni. Ugyanezt a konvenciót alkalmazhatod azoknál a változóknál is, amelyek Boolean értékeket tárolnak.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
