# Utasítások

Egy vidámparkkal dolgozol, és kaptál egy specifikációt egy olyan rendszer megtervezéséhez, amely a látogatók nyilvántartását és a játékokat kezeli. Az a feladatod, hogy modellezd az `Attendee` osztályt (a parkba látogató személyt).

## 1. Hozz létre új látogatókat

Valósítsd meg az `Attendee` osztály `Attendee#initialize` metódusát; vegyen át egy magasságot (centiméterben), és tárolja el egy példányváltozóban.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. Milyen magas a látogató

Valósítsd meg az `Attendee` osztály `Attendee#height` getterét; adja vissza a példány magasságát.

```ruby
Attendee.new(106).height
# => 106
```

## 3. Mi a bérletazonosító

Nem minden látogató vásárolt bérletet, de tudnunk kell, hogy van-e bérlete vagy nincs. Valósítsd meg az `Attendee` osztály `Attendee#pass_id` getterét; adja vissza a példány pass_id értékét, vagy `nil`-t, ha a látogatónak nincs.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Tedd lehetővé, hogy az emberek bérletet vásároljanak

Valósítsd meg az `Attendee#issue_pass!` metódust, hogy módosítsa a példány állapotát, és állítsa a bérletazonosító példányváltozót az argumentumra. Adja vissza a bérletazonosítót.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Vond vissza a bérletet

Néhány vendég veszélyes viselkedéssel megszegi a szabályokat, ezért a park szeretné visszavonni a bérleteket. Valósítsd meg az `Attendee#revoke_pass!` metódust, hogy módosítsa a példány állapotát, és állítsa a bérletazonosítót `nil`-re.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
