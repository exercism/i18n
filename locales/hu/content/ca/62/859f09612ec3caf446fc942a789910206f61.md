# Tesztek futtatása

Az SWI Prologot vagy interaktívan futtathatod, vagy közvetlenül a parancssorból.

## Parancssor

A következő paranccsal futtathatod a teszteket a parancssorból:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

A `<exercise>` helyére írd be annak a feladatnak a nevét, amelyet megvalósítasz.

## Interaktív

A Prolog interaktív futtatásához először futtasd:

```bash
swipl
```

Miután a Prolog konzol elindult, töltsd be a megvalósításodat, és futtasd a teszteket a következőkkel:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

A `<exercise>` helyére írd be annak a feladatnak a nevét, amelyet megvalósítasz.

### Változtatások újratöltése

Miután a fenti fájlok betöltődtek, a módosításaidat úgy alkalmazhatod, hogy lefuttatod:

```
?- make.
```

## Kihagyott tesztek

Amikor először kezdesz el egy feladatot, csak az első teszt fog lefutni. A többi teszt ki van hagyva, mert a `condition(pending)` hozzá van adva a `test` célhoz.
Miután az első teszt sikeres lett, a következő tesztnél szüntesd meg a kihagyást úgy, hogy a `condition(pending)`-ben a `pending`-et `true`-ra állítod.
Ismételd meg minden tesztnél, amíg az összes fut és sikeres nem lesz.

### Parancssor

A `-- --all` argumentumot add a parancs végéhez, hogy a függőben lévő tesztek is lefussanak:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
