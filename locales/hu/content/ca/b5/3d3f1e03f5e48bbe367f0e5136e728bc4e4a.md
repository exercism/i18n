# Bevezetés

## Tömbök és vektorok

A C++ különböző konténereket kínál arra, hogy azonos típusú elemeket rendezett módon tárolj bennük.
Van `std::array` a rögzített méretű konténerekhez, és `std::vector`, amely dinamikus átméretezésre is képes.

### Létrehozás

Amikor tömböt vagy vektort deklarálsz, meg kell adnod, hogy milyen típusú elemeket fog tárolni a konténer.
A tömböknél a méretet is meg kell adni.
Nézd meg ezeket a példákat, hogy lásd a két konténertípus létrehozását:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

A vektorok általában több helyet igényelnek, mert memóriát foglalnak le a további növekedéshez.
A méretet nem kell megadnod:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> Megjegyzés: Még nem kell ismerned a template fogalma mögötti pontos mechanikát, arról külön fogalom szól majd lejjebb a tantervben.

### Elemek elérése

A vektorok és a tömbök ugyanazokat a függvényeket használják az elemeik elérésére.
A `front` és a `back` tagfüggvénnyel lekérheted a konténer első és utolsó elemét.
Az adott elemek eléréséhez ott van az `at` és a `[]` operátor is.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> Megjegyzés: Ha a konténer tartományán kívüli pozíciót választasz, a `[]` nem definiált viselkedéshez vezethet.
> Az `at` függvény viszont kivételt dob, ami hosszú távon megkönnyítheti az életedet.

### A vektor módosítói

Mivel a `vector` mérete nem rögzített, hozzáadhatsz és eltávolíthatsz elemeket.
Erre a célra két gyakori függvény az `emplace_back` és a `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### Kapacitás

Azt, hogy egy konténer üres-e, az `empty` tagfüggvénnyel ellenőrizheted.
Ha tudni szeretnéd az elemek számát, használd a `size` függvényt.
