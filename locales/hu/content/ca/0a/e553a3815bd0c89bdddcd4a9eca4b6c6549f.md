# Bevezetés

A Go függvényei és metódusai több értéket is visszaadhatnak:

```go
func GetCard() (Card, error) { ... }
```

Minden visszatérési értéket sorrendben kell hozzárendelni, vesszővel elválasztva:

```go
card, err := GetCard()
```

Az értékadás minden pozíciója egy-egy változót deklarál.
A Go nem fordul le, ha egy deklarált változót soha nem használsz.
Az üres azonosító (`_`) veszi át a változó nevének helyét, hogy kihagyd az adott visszatérési értéket:

```go
card, _ := GetCard()
```

Az `error` egy beépített interfész.
A `nil` értékű hiba azt jelenti, hogy nem történt hiba; bármely nem `nil` érték azt jelenti, hogy valami elromlott.
A konvenció szerint azoknak a függvényeknek, amelyek elbukhatnak, az utolsó visszatérési értékként egy `error`-t kell visszaadniuk.
A hívónak ezt ellenőriznie kell, mielőtt bármely más visszatérési értéket használna:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
