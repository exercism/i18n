# Bevezetés

## Rekurzió

Rekurziónak nevezzük, amikor valami önmaga segítségével definiálható. A Gleamben a rekurzió leggyakrabban rekurzív függvényekben jelenik meg, amelyek önmagukat hívják.

A rekurzív függvénynek legalább egy _alapesetre_ és legalább egy _rekurzív esetre_ van szüksége. Az _alapeset_ úgy ad vissza egy értéket, hogy nem hívja meg újra a függvényt. A _rekurzív eset_ újra meghívja a függvényt, és módosítja a bemenetet, hogy az előbb-utóbb megfeleljen az alapesetnek.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

A Gleamben nincs külön szintaxis a ciklusokra, ezért minden ciklus rekurzióval valósul meg.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

A Gleam emellett a rekurzív egyedi típusokat is támogatja. Egy rekurzív egyedi típusnál a változatai közül egy vagy több a bennük tárolt adatban magára a típusra hivatkozik.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
