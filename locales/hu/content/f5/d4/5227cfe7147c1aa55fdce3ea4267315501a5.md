# Tesztek

Minden feladat tartalmaz egy tesztfájlt.
A teszteket a `bats` programmal futtasd.

```bash
bats test-hello-world.bats
```

A `bats` programot telepíteni kell.
A `bats` rendszeredre való telepítésének útmutatóját a [Tesztelés a Bash-kurzuson][bash] oldalon találod.

### A bats bashben van megvalósítva

A bats fájl egy bash-szkript, benne néhány különleges függvénnyel, amelyeket a `bats` parancs felismer.
Néhány teszt így néz ki:

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

Ez a `<<<` szintaxis egy bash [Here String][here-string].
A jobb oldali karakterláncot a bal oldali program standard bemenetére küldi.
Ez ([nagyjából][so]) ugyanaz, mint

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## Segítség az assert függvényekhez

A tesztek a [bats-assert][bats-assert] könyvtár függvényeit használják.
A különféle `assert*` függvények leírása ott található.

## Kihagyott tesztek

Egy feladat megoldása azt jelenti, hogy minden tesztje sikeres lesz.
Alapértelmezés szerint csak egy teszt (az első) fut le, amikor futtatod a teszteket.
Ez szándékos, mert így arra összpontosíthatsz, hogy épp azt az egy tesztet teljesítsd.
Miután sikerül, a következő tesztet úgy engedélyezheted, hogy kikommentezed vagy eltávolítod a

    [[ $BATS_RUN_SKIPPED == true ]] || skip

megjegyzéseket, amelyek a többi teszt elé kerülnek.

## A kihagyások felülbírálása

Az összes teszt futtatásához, beleértve a `skip` megjegyzésekkel ellátottakat is, ezt futtathatod:

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

Kényelmes lehet egy segédfüggvényt használni, hogy kevesebbet kelljen gépelni: `bash`-ben ezt teheted:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Ezután a teszteket csak ennyivel futtatod:

```bash
bats
```

## Hibakeresés `jq`-ban

A `jq` rendelkezik egy hasznos [`debug`][debug] szűrővel.
Használd, miközben a feladatmegoldásaidat fejleszted, hogy megvizsgáld, milyen adat van éppen a jq csővezetékében.
További részletekért lásd a [hibakeresési dokumentumot][debugging].
