# Részletesebben

A *kupac* egy olyan gyűjtemény, amely mindig ismeri a legkisebb (vagy legnagyobb) elemét, és gyorsan el is távolíthatod belőle; ez a *prioritási sor* természetes megvalósítása. A kupacok a [`heaps`][heaps] szókészletben találhatók.

A `<min-heap>` egy üres kupacot hoz létre, amelyből először a legkisebb kulcs kerül elő; a `<max-heap>` pedig a legnagyobbat adja ki először. Minden elem egy *érték*, amely egy *kulcs* alatt tárolódik, és a prioritást épp ez a kulcs adja: ez alapján rendez a Factor.

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

A kupac *módosítható*: a `heap-push` és a `heap-pop` helyben változtatja meg.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

A `heap-peek` anélkül olvassa ki a legelső elemet, hogy eltávolítaná; a `heap-pop` eltávolítja, és visszaadja; a `heap-pop-all` pedig kiüríti a kupacot, és egy prioritási sorrendbe rendezett, `{ key value }` párokból álló asszociációs listába gyűjti.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

A beszúrás `O(log n)`, a legelső elem kiolvasása pedig `O(1)`, így a „vedd ki a legsürgősebb elemet, majd adj hozzá még többet” minta ismételt alkalmazása akkor is gyors marad, ha nagy a sor. A megvalósítás egy növekvő tömbben tárolt bináris kupac; a kulcs bármilyen rendezhető érték lehet (számok, stringek, …).
