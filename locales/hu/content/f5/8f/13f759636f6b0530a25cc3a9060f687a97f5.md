# Névjegy

A `for` ciklusok a legösszetettebb ciklustípus a PHP-ban. Úgy viselkednek, mint a `C`, a `Java` és a `JavaScript` `for` ciklusai. Az alapformájuk a következő:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

Az első kifejezést (_expr1_) a program még a ciklus elindulása előtt kiértékeli. A második kifejezést (_expr2_) minden iteráció előtt kiértékeli, és ha az értéke _truthy_, akkor végrehajtja az utasításokat. A végrehajtott utasítások után a program kiértékeli a harmadik kifejezést (_expr3_).
