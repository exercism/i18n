# Névjegy

Egy függvény akkor [farokrekurzív][recursion-tc], ha az _utolsó_ dolog, amit végrehajt, önmaga meghívása.

Valahányszor meghívunk egy függvényt, a [függvényhívási verem][call-stack] tetejére kerül egy _veremkeret_, benne a lokális változókkal, argumentumokkal és így tovább. Amikor a függvény visszatér, a veremkeret lekerül a veremről.

A farokrekurzív függvények lehetővé teszik a [farokhívás-optimalizálást][tail-call-optimization]. Ez egy olyan optimalizálás, amely lehetővé teszi, hogy a következő függvényhívás újra felhasználja az utolsó veremkeretet, mert az előző függvényről biztosak lehetünk benne, hogy már nem lesz rá szüksége. Ez mérsékli a függvényhívási verem túlcsordulásának veszélyét, ami az a helyzet, amikor olyan sok keret van a függvényhívási vermen, hogy már nem maradt memória egy újabb létrehozásához.

- Ahhoz, hogy Elixirben farokrekurziót érjünk el, gyakran szükség van egy akkumulátorra az adatok változtathatatlanságának szabályai miatt.

  - Az akkumulátor egy olyan változó, amelyet továbbadunk a rekurzív híváson, és amely _eddig_ megőrzi a rekurzív függvény aktuális állapotát, míg végül az alapeset vissza nem adja a végső eredményt.

    ```elixir
    # Count the length of a list without an accumulator
    def count([]), do: 0
    def count([_head | tail]), do: 1 + count(tail)

    # Count the length of a list with an accumulator
    def count(list), do: do_count(list, 0)

    defp do_count([], count), do: count
    defp do_count([_head | tail], count), do: do_count(tail, count + 1)
    ```

- Amikor listákkal dolgozol, ne feledd, hogy ezek egyszeresen láncolt listaként vannak megvalósítva: az elejére fűzés nagyon gyors, a végére fűzés viszont nagyon lassú.

  ```elixir
  # Reverse a list with an accumulator
  def reverse(list), do: do_reverse(list, [])

  defp do_reverse([], acc), do: acc

  defp do_reverse([head | tail], acc) do
    do_reverse(tail, [head | acc])
  end
  ```
