# Egész számok

Az egész számok a `{..., -2, -1, 0, 1, 2, ...}` halmaz elemei.
Egy egész szám maximumát és minimumát az határozza meg, hogy milyen rendszeren fut a PHP.
A legtöbb modern rendszeren ez jellemzően 64 bites érték, ami azt jelenti, hogy a `-9_223_372_036_854_775_808` és a `9_223_372_036_854_775_807` közötti értékeket is ábrázolni tudja, a határokat is beleértve.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Az egész literálértékeket 10-estől eltérő számrendszerben is leírhatod, ha egy számrendszer-előtagot használsz:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
