# Figyelmen kívül hagyás

## További jq parancssori kapcsolók

A tesztekben feltűnhet néhány extra kapcsoló a `jq`-hoz.

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

Mik ezek?

- `-s`

  Ez a „slurp” mód.
  Ahelyett, hogy a bemenetet JSON-objektumok folyamaként kezelné,
  az összes bemenetet egyetlen tömbbe szippantja be.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  A `-r` kapcsolót talán már láttad: az „nyers” stringeket ír ki (idézőjelek nélkül).
  Ez épp az ellenkezője.
  A bemenet minden sorát stringként veszi.

  Két példa:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

Ha ezt a két kapcsolót együtt használod, _nem_ stringek tömbjét kapod:
a teljes bemenetet egyetlen stringként kapod meg, a sorvégi újsorokat is beleértve.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

Ennek a kezelése is része a feladat kihívásának.
