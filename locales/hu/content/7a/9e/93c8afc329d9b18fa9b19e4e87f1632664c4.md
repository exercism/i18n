# Kettes, nyolcas és tizenhatos számrendszer

A kettes, a nyolcas és a tizenhatos számrendszer (_más néven hex_) különböző alappal rendelkező [számrendszerek][numeral-systems].
A kettes számrendszer 2-es alapú, a nyolcas 8-as, a tizenhatos pedig 16-os.
A Crystalban a szokásos egész számok tízes alapúak.
A kettes, a nyolcas és a tizenhatos számrendszer mind az egész számok reprezentációi.
Ez azt jelenti, hogy pozitív és negatív számokat (_a nullát is beleértve_) reprezentálnak törtek és tizedesjegyek nélkül, és minden olyan műveletet támogatnak, amit egész számokkal elvégezhetünk.

## A kettes számrendszer

A [kettes számrendszer][binary] egy 2-es alapú számrendszer, amely csak a 0 és az 1 számjegyet használja.
Általában a számítógépek tranzisztorain és kapcsolóin átfolyó elektromos áram 0 („ki”) és 1 („be”) állapotát reprezentálja, valamint a mágneses adathordozók pozitív és negatív töltéseit.
A kettes számrendszer minden olyan egész számot képes reprezentálni, amit a tízes számrendszerben használunk.

A 2-es alapú számrendszer egy részlete így néz ki, bár a végtelenségig folytatódik, és nem áll meg 128-nál:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Ha tehát a 6-os számot szeretnénk reprezentálni, az kettes számrendszerben így néz ki: 110

| Helyiérték    | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| Kettes szám   | 1   | 1   | 0   |

A művelet pedig ez lenne: `4 + 2 + 0 = 6`

Egy másik példa: 19

| Helyiérték    | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| Kettes szám   | 1   | 0   | 0   | 1   | 1   |

A kettes számrendszerbeli szám ez lenne: 10011
A művelet pedig ez lenne: `16 + 0 + 0 + 2 + 1 = 19`

## A kettes számrendszer a Crystalban

A Crystalban a kettes számrendszerbeli literálokat a `0b` előtaggal reprezentálhatjuk.
Ha `0b10011`-et írunk, a Crystal kettes számrendszerbeli számként értelmezi, és átváltja tízes alapra.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Ha olyan számot írsz `0b` előtaggal, amely nem a kettes számrendszerben van, az fordítási hibát eredményez.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Műveletek kettes számrendszerbeli számokkal

Mivel a kettes számrendszerbeli számok egész számok, minden olyan műveletet elvégezhetünk rajtuk, amit egész számokkal is.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Átváltás kettes reprezentációra és vissza

A Crystal automatikusan `Int32`-vé alakítja a kettes számrendszerbeli literált.
Ha egy `Int32`-t kettes reprezentációvá szeretnénk alakítani, használd a [`<int>.to_s(base)`][to_s] metódust úgy, hogy az alap argumentum értéke 2 legyen.
A metódus a kettes számrendszerbeli szám string reprezentációját adja vissza:

```crystal
19.to_s(2)
# => "10011"
```

Ha egy kettes számrendszerbeli szám string reprezentációját egész számmá szeretnénk alakítani, használhatjuk a [`<int>.to_i(base)`][to_i] metódust, argumentumként a 2-es alapot átadva:

```crystal
"10011".to_i(2)
# => 19
```

Ha rossz alapot adunk meg (_vagy érvénytelen kettes reprezentációt_), az `ArgumentError` hibát eredményez:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Kettes számrendszerrel kapcsolatos metódusok

Bizonyos metódusok egész számokon használhatók, hogy információt kapjunk a szám kettes reprezentációjáról.

A [`<int>.bit_length`][bit_length] visszaadja, hány bit szükséges a szám reprezentálásához:

```crystal
19.bit_length
# => 5
```

A [`<int>.bit(index)`][bit] visszaadja a megadott indexű bitet, jobbról kezdve (_a legkisebb helyiértékű bitet_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## A nyolcas számrendszer

A [nyolcas számrendszer][octal] egy 8-as alapú számrendszer.
A 0, 1, 2, 3, 4, 5, 6 és 7 számjegyeket használja.

A Crystalban a nyolcas számrendszerbeli számokat a `0o` előtaggal reprezentálhatjuk.
Ahogy a kettes számrendszernél, a Crystal a nyolcas reprezentációt is automatikusan `Int32`-vé alakítja.

```crystal
0o123
# => 83
```

Ha olyan számot látunk el `0o` előtaggal, amely nem a nyolcas számrendszerben van, az fordítási hibát eredményez.

### Átváltás nyolcas reprezentációra és vissza 

Ahogy a kettes számrendszernél, itt is használhatjuk a [`<int>.to_s(base)`][to_s] metódust, hogy egy `Int32`-t nyolcas reprezentációvá alakítsunk.
És a [`<int>.to_i(base)`][to_s] metódussal egy nyolcas reprezentációt alakíthatunk `Int32`-vé.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Ahogy a kettes számrendszernél, a rossz alap megadása itt is `ArgumentError` hibát eredményez.

## A tizenhatos számrendszer

A [tizenhatos számrendszer][hexadecimal] egy 16-os alapú számrendszer.
A 0 - 9 számjegyeket és az A, B, C, D, E és F betűket használja.
Az A a 10, a B a 11, a C a 12, a D a 13, az E a 14, az F pedig a 15.

A tizenhatos számrendszerbeli számokat a Crystalban a `0x` előtaggal reprezentálhatjuk.
Ahogy a kettes és a nyolcas számrendszernél, a Crystal a tizenhatos literálokat is automatikusan `Int32`-vé alakítja.

```crystal
#=> 0x123
291
```
 
Ha egy nem tizenhatos számrendszerbeli számot `0x` előtaggal látunk el, az fordítási hibát eredményez.

###  Átváltás tizenhatos reprezentációra és vissza

Ahogy a kettes számrendszernél, itt is használhatjuk a [`<int>.to_s(base)`][to_i] metódust, hogy egy `Int32`-t tizenhatos reprezentációvá alakítsunk.
És a [`<int>.to_i(base)`][to_s] metódussal egy tizenhatos reprezentációt alakíthatunk `Int32`-vé.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Ahogy a kettes és a nyolcas számrendszernél, a rossz alap megadása itt is `ArgumentError` hibát eredményez.

## A pontosság

Amikor egy számot string reprezentációvá alakítunk, megadhatjuk a szám pontosságát.
Ez a szám reprezentálásához használt számjegyek **minimális** mennyiségét jelenti.
Ha a szám kevesebb számjegyből áll, mint a pontosság, a string reprezentáció elejére vezető nullák kerülnek.
Ezt úgy érjük el, hogy a `precision` argumentumot átadjuk a [`<int>.to_s(<base>, precision: <value>)`][to_s] metódusnak.

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## A nagybetűsítés

Amikor egy számot string reprezentációvá alakítunk, megadhatjuk, hogy a string betűit nagybetűssé szeretnénk-e alakítani.
Ezt úgy érjük el, hogy az `upcase` argumentumot átadjuk a [`<int>.to_s(<base>, upcase: <value>)`][to_s] metódusnak.

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
