# Tesztek

A tesztek futtatásához:
```bash
tclsh exercise.test
```

## Kihagyott tesztek

Egy feladat megoldása azt jelenti, hogy az összes tesztje sikeres lesz. Alapértelmezés szerint a tesztek futtatásakor csak egy teszt (az első) fut le. Ez szándékos: így arra tudsz összpontosítani, hogy éppen az az egy teszt legyen sikeres. Ha ez sikerült, a következő tesztet úgy kapcsolhatod be, hogy kikommentezed vagy törlöd az előtte álló `skip` parancsot.

Vagy lefuttathatod az összes tesztet is, függetlenül attól, hogy »kihagyott« állapotban vannak:
```bash
RUN_ALL=1 tclsh exercise.test
```
