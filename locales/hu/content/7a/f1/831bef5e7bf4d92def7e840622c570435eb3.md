# Bevezetés

A `list` az R-ben elemek rendezett gyűjteménye, amely néhány ponton eltér a `vectors`-tól:

- Az elemek különböző típusúak lehetnek (például `numeric` és `character` vegyesen).
- Az elemek összetett struktúrák is lehetnek (például vektorok, más listák stb.).
- Az elemek eléréséhez más szintaxis tartozik.

A más nyelvekkel vont párhuzamok pontatlanok.
Az R `list` némileg hasonlít a Python szótárára, azonban a `list` rendezett, és numerikus indexszel érhető el.
Némileg hasonlít a C `struct`-jára is, azzal a különbséggel, hogy a `list` futásidőben könnyen bővíthető.

## Listák létrehozása

Az elemek elnevezése (amit gyakran „tag”-nek hívnak) gyakoribb a listák, mint a vektorok esetében:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

A tagek azonban elhagyhatók, ilyenkor az R egyszerűen indexszámokat használ:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## A listaelemek elérése

Erre háromféle lehetőség van, és mindegyik más-más helyzetben hasznos.

### 1. `$tag` jelöléssel

Nagyon gyakori, ha a tagnevek előre ismertek.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. `[[tag]]` jelöléssel

Ennek előnye, hogy a tagnév futásidőben választható meg.
Figyeld meg a dupla zárójelet.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Pozícióindexszel

Ez attól függetlenül működik, hogy a listának vannak-e tagjei.
A zárójelek itt is duplák.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Elemek hozzáadása és törlése

Egyszerű: ha értéket rendelsz egy elemhez, az módosul, ha már létezik, és beszúródik, ha új.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Törléshez rendeld a `NULL` értéket a nem kívánt elemhez.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
