# Kiegészítés az utasításokhoz

## A Node-folyamat

A többi feladattól eltérően a `grep.js`-t _nem_ importáljuk be a `grep.spec.js` tesztfájlba. Ehelyett úgy használjuk, mintha egy futtatható program lenne. Hogy ez működjön, a `grep.js` fájlt elláttuk egy shebanggel és egy megjegyzéssel, amely elmagyarázza, hogy ez mit csinál:

```javascript
#!/usr/bin/env node

// The above line is a shebang. On Unix-like operating systems, or environments,
// this will allow the script to be run by node, and thus turn this JavaScript
// file into an executable. In other words, to execute this file, you may run
// the following from your terminal:
//
// ./grep.js args
//
// If you do not have a Unix-like operating system or environment, for example
// Windows without WSL, you can use the following inside a window terminal,
// such as cmd.exe:
//
// node grep.js args
//
// Read more about shebangs here: https://en.wikipedia.org/wiki/Shebang_(Unix)
```

A tesztek elindítanak egy új node-_folyamatot_, amely lefuttatja a `grep.js`-t.

## Argumentumok beolvasása

Ahhoz, hogy megtudd, milyen argumentumokkal indult el a _folyamat_, használd a `process.argv`-t.

## Fájlok beolvasása

A `readLines` függvény rendelkezésre áll. Nem kell átalakítanod a fájl elérési útját, hogy használhasd. A `readlines` függvény az aktuális munkakönyvtárból _oldja fel_ az elérési utat, ami a `grep.js` folyamatai esetében a feladat könyvtárára van beállítva.

## Kimenet írása

A kimenet írásához a következőket használd:

- `console.log`, ha a szabványos kimeneti folyamra akarsz írni,
- `console.error`, ha a szabványos hibafolyamra akarsz írni.

A tesztek akkor tekintik sikeresnek (resolved) a végrehajtást, ha semmi sem íródik a szabványos hibafolyamra, és akkor tekintik sikertelennek (rejected), ha valami íródik a szabványos hibafolyamra.
