# Bevezetés

A Go-ban a `struct` olyan nevesített elemek sorozata, amelyeket _mezőknek_ nevezünk; minden mezőnek van neve és típusa.
Egy mező nevének egyedinek kell lennie a structon belül.
A structok az objektumorientált programozási paradigma _osztályaihoz_ hasonlíthatók.

## A struct definiálása

Új structot a `type` és a `struct` kulcsszóval hozol létre, majd a mezők nevét és típusát explicit módon adod meg.
Például itt definiáljuk a `Shape` structot, amely egy alakzat nevét és méretét tárolja:

```go
type Shape struct {
    name string
    size int
}
```

A structokban a mezőnevek a Go konvencióját követik: a kisbetűvel kezdődő nevű mezők csak az ugyanabban a csomagban lévő kód számára láthatók, míg a nagybetűvel kezdődők más csomagokból is láthatók.

## Structpéldányok létrehozása

Miután definiáltad a `structot`, létre kell hoznod egy új példányt, amelyben a mezőket a nevükkel adod meg, tetszőleges sorrendben:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

A példány mezőinek olvasásához vagy módosításához a `.` jelölést használd:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

A mezők, amelyekhez nem rendeltél kezdőértéket, a nullaértéküket kapják.
Például:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Létrehozhatsz egy `struct` példányt a mezőnevek használata nélkül is, amennyiben a mezőket _sorrendben_ adod meg:

```go
s := Shape {
	"Oval",
	20,
}
```

Ez a szintaxis azonban _törékeny kódnak_ számít, mert eltörhet, amikor új mező kerül a structba, különösen akkor, ha az új mező típusa más.
A következő példában egy plusz mezőt adunk a `Shape` structhoz:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## „New” függvények

Néha jó, ha vannak olyan függvényeink, amelyek segítenek structpéldányokat létrehozni.
A konvenció szerint ezeket a függvényeket általában `New`-nak hívják, vagy a nevük `New`-val kezdődik, de mivel egyszerű függvényekről van szó, bármilyen nevet adhatsz nekik.
Más nyelvek konstruktorai juthatnak róluk eszedbe, de a Go-ban ezek is csak egyszerű függvények.

A következő példában az egyik ilyen `New` függvényt használjuk arra, hogy létrehozzunk egy új `Shape` példányt, és automatikusan beállítsuk az alakzat `size` mezőjének alapértelmezett értékét:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

A `New` függvények használatának a következő előnyei lehetnek:

* a megadott értékek ellenőrzése
* az alapértelmezett értékek kezelése
* mivel a `New` függvényeket gyakran ugyanabban a csomagban deklarálják, mint az általuk inicializált structokat, még a struct privát mezőit is inicializálhatják
