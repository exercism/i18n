# Tippek

## 1. Generálj egy véletlenszerű bolygót

- A Java nem kínál függvényt arra, hogy egy gyűjteményből véletlenszerűen válassz ki egy elemet.
- Ne feledd, hogy egy tömb elemeit az indexük alapján kérheted le, az index pedig egy egész szám.

## 2. Generálj egy véletlenszerű csillaghajó-lajstromszámot

- A `java.util.Random` osztály biztosít egy metódust, amellyel 0 és egy megadott maximum között véletlenszerű `int` értéket generálhatsz.

## 3. Generálj egy véletlenszerű csillagdátumot

- A `java.util.Random` osztály véletlenszerű `double` értéket generáló metódusa mindig `0.0` és `1.0` közötti számot ad vissza.
