# string formázás

A `String#%%` metódus mellett a Rubyban gyakran [string-interpolációval](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) hozunk létre stringeket. Például:

```ruby
# Rather than:
"One for %%s, one for me." %% %{name_variable}

# Consider:
"One for #{%{name_variable}}, one for me."
```
