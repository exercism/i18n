# Bevezetés

Sok programnak van szüksége (_látszólag_) véletlenszerű értékekre valós események szimulálásához.

Gyakori, ismerős példák:
- Érmedobás: véletlenszerű érték a `('Heads', 'Tails')`-ból.
- Kockadobás: véletlenszerű egész szám 1 és 6 között.
- Kártyapakli megkeverése: egy kártyalista véletlenszerű sorrendje.
- Fák és bokrok létrehozása egy 3D-s grafikai szimulációban.

A számítógéppel előállított _valóban_ véletlenszerű értékek [meglepően nehéz technikai kihívást][truly-random] jelentenek, ezért ezekre az eredményekre „álvéletlen” néven is bukkanhatsz.

A gyakorlatban egy jól megtervezett könyvtár, mint a Python szabványos könyvtárának [`random`][random] modulja, gyors, rugalmas, és olyan eredményeket ad, amelyek bőven elég jók a legtöbb modellezési, szimulációs és játékalkalmazáshoz.

Ebben a rövid bevezetőben a modul négy leggyakrabban használt függvényét mutatjuk be.
Érdemes felfedezned a teljes [`random`][random] dokumentációt, mert rengeteg eszköz és lehetőség van benne.

Mielőtt használhatnád a `random` modul eszközeit, először importálnod kell:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Hogy elkerüld a modul nevének beírását, importálhatsz konkrét függvényeket név szerint:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` és `randint()`

Ahogy a fenti első példában is látszik, a `randrange()` függvénynek három formája van:

1. `randrange(stop)` egy olyan `n` egész számot ad, amelyre `0 <= n < stop`
2. `randrange(start, stop)` egy olyan `n` egész számot ad, amelyre `start <= n < stop`
3. `randrange(start, stop, step)` egy olyan `n` egész számot ad, amelyre `start <= n < stop`,
    és `n` a `start, start + step, start + 2*step...` sorozatba esik

A leggyakoribb esetben, amikor `step == 1`, a `randint(a, b)` kényelmesebb és olvashatóbb lehet.
A `randint()` lehetséges eredményei _tartalmazzák_ a felső határt, így a `randint(a, b)` ugyanaz, mint a `randrange(a, b+1)` használata.



## `choice()` és `choices()`

Ez a két függvény azt feltételezi, hogy valamilyen [sorozatból][sequence-types] vagy más konténerből indulsz ki.
Ez jellemzően egy `list`, vagy bizonyos megkötésekkel egy `tuple` vagy egy `set` (_a `tuple` módosíthatatlan, a `set` pedig rendezetlen_).

A `choice()` függvény egy véletlenszerűen kiválasztott elemet ad vissza egy adott sorozatból, a `choices()` pedig egy megadott számú (`k`) véletlenszerűen kiválasztott elemet ad vissza egy adott sorozatból.
A fenti példákban egy szabályos érmét feltételeztünk, ahol a fej és az írás valószínűsége egyenlő, de súlyokat is megadhatsz.

Például ha egy zacskóban 10 piros és 15 zöld golyó van, és szeretnénk véletlenszerűen kihúzni egyet:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
