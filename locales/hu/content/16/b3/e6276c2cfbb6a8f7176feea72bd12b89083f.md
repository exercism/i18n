# Ismertetés

A `Result` típus az Elm nyelv megoldása a hibajelentésre és a hibák utáni helyreállításra. Némileg hasonlít a `Maybe` típushoz, de míg a `Maybe` `Nothing` értéke valamilyen kudarcot kódol, addig nem mond semmit arról, hogy _miért_ hiúsult meg. A `Result` viszont kontextust ad arról, hogy valami miért hibázott.

## Definíció és típusváltozó

A `Result` típus definíciója a következő:

```elm
type Result error value
  = Ok value
  | Err error
```

Röviden: ez a típus egy olyan művelet eredményét kódolja, amely vagy sikerül és visszaad egy `value` értéket, vagy meghiúsul és a hiba magyarázatát (`error`) adja vissza.

Az Elm terminológiájában ezt „custom type” definíciónak nevezik. A custom type-okat egy másik fogalom mutatja be részletesen ezen a kurzuson, de a `Result` megértéséhez most nem lesz rájuk szükségünk. Az `OK value` és az `Error error` `error` és `value` része egy típusváltozót jelöl: ez bármilyen típus lehet, például `Int`, `Bool` vagy `String`. Így a `Result String Int` olyan értéket jelöl, amely várhatóan egy `Int`-et tartalmaz, és ha hiba van, azt egy `String` képviseli.

```elm
ageFromString : String -> Result String Int
ageFromString input =
  case String.toInt input of
    Nothing ->
      Err "That is not a number!"

    Just age ->
      if age < 0 then
        Err "Please try again after you are born."

      else if age > 135 then
        Err "Are you some kind of turtle?"

      else
        Ok age
```

## A Result érték tartalmának kiolvasása

Egy `Result` érték tartalmát „mintaillesztéssel” olvashatod ki. A mintaillesztést szintén részletesebben mutatja be egy másik fogalom, ezért most csak arra összpontosítunk, hogyan működik a mintaillesztés egy `Result` esetében.

```elm
formatAge : Int -> String
formatAge age =
    "You are " ++ toString(age)

howOldAmI : String -> String
howOldAmI age =
    case ageFromString age of
        Err message -> message
        Ok age -> formatAge age

howOldAmI "Bananas"
    --> "That is not a number!"

howOldAmI "32"
    --> "You are 32"
```

Valahányszor `Result` értéket használsz, az Elm fordítója ellenőrzi, hogy a kódod minden lehetséges esetet lekezel-e, így sosem fordulhat elő, hogy csak az `Ok value` esetet kezeled. Ez elsőre idegesítőnek tűnhet, de ez az Elm nyelv egyik legnagyobb erőssége. Több száz hibát előz meg, és a fordító vezette refaktorálást félelemmentes, kifizetődő élménnyé teszi.

## A Result érték tartalmának kezelése

Több függvény is rendelkezésre áll a `Result` típusok kezeléséhez, és ezek általában előnyösebbek a mintaillesztésnél. A `Result.map` segítségével átalakíthatod a benne lévő értéket, a `Result.andThen` pedig olyan függvények összefűzésére való, amelyek meg is hiúsulhatnak.

A Result.map az Ok érték megváltoztatására szolgál, és hasznos függvények egymás után fűzéséhez anélkül, hogy aggódnod kellene, tartalmaz-e hibát a Result. Ha az érték Ok, a Result.map meghívja a láncolt függvényt (lásd alább a `formatAge`-et), ha viszont hiba van, a Result.map nem csinál semmit, egyszerűen visszaadja a hibát.

```elm
howOldAmI : String -> Result String String
howOldAmI age =
    Result.map formatAge (ageFromString age)

howOldAmI "Bananas"
    --> Err "That is not a number!" (ageFromString returns Err, so Result.map just returns the Err)

howOldAmI "32"
    --> Ok "You are 32" (ageFromString returns Ok 32, Result.map passses this to formatAge)
```

A Result.andThen szintén az Ok érték megváltoztatására szolgál, és hasznos függvények összefűzéséhez anélkül, hogy aggódnod kellene, tartalmaz-e hibát a Result. Hasonlít a Result.map működéséhez, de a Result.andThen olyan láncolt függvénnyel (lásd alább a `formatSpecialBirthday`-t) dolgozik, amely maga is Result típusú értéket ad vissza. A `Result.map` is meg tudja ezt tenni, de a végén egy plusz beágyazási szint keletkezik, amit az `andThen` ügyesen elkerül.

```elm
formatSpecialBirthday : Int -> Result String String
formatSpecialBirthday age =
    if age == 18 then
        Ok "Welcome to adulthood!"

    else if age == 65 then
        Ok "Welcome to retirement!"

    else
        Err "Not a special birthday"

specialBirthdayMessage : String -> Result String String
specialBirthdayMessage age =
    Result.andThen formatSpecialBirthday (ageFromString age)

specialBirthdayMessage "Bananas"
    --> Err "That is not a number!" (ageFromString returns Err, so Result.andThen just returns the Err)

specialBirthdayMessage "32"
    --> Err "Not a special birthday" (ageFromString returns Ok 32, Result.map passses this to formatSpecialBirthday, which returns Err)

specialBirthdayMessage "18"
    --> Ok "Welcome to adulthood" (ageFromString returns Ok 32, Result.map passses this to formatSpecialBirthday, which returns Ok)
    --> If we used Result.map, it would be OK (Ok "Welcome to audulthood"), which is annoying
```
