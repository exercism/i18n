# Utasítások

Ebben a feladatban telefonszámokat fogsz elemezni.

Két funkciót kell megvalósítanod.

A rutinoknak átadott telefonszámok garantáltan NNN-NNN-NNNN formátumúak, például 212-515-9876, és nem null értékűek.

## 1. Egy telefonszám elemzése

Az elemzésnek 3 adatot kell visszaadnia:

1. Annak jelzése, hogy a szám New York-i körzetszámmal kezdődik-e, azaz az első 3 számjegy a 212
2. Annak jelzése, hogy a szám hamis-e, mert az 5. és 7. pozíció között (1-től számozva) 555 szerepel előtagként
3. A szám utolsó 4 számjegye.

Valósítsd meg a (statikus) `PhoneNumber.Analyze()` metódust, amely előállítja a telefonszám adatait.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. Annak felismerése, hogy egy telefonszám előtagkódja hamis-e (555)

Valósítsd meg a (statikus) `PhoneNumber.IsFake()` metódust, amely az 1. részfeladatban előállított telefonszám-adatok alapján megállapítja, hogy a telefonszám hamis-e.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
