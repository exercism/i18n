# Névjegy

A Swiftben nem tudsz egy stringbe egész számmal indexelni (például `string[3]`).
Mivel a Swift stringjei változó hosszúságú Unicode-karakterekből állnak, egy karakter megkereséséhez végig kell haladnod az előtte lévő karaktereken.

Ha egy adott pozícióban lévő karakterhez hozzá akarsz férni, ki kell számítanod egy `String.Index` típusú indexet.
Ezeket az indexeket *opaque indexeknek* nevezik, mert a belső szerkezetüket a Swift kezeli, nem pedig nyers egészekként módosítod közvetlenül:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
