# Kiegészítés az utasításokhoz

## Kurzusra vonatkozó utasítások

Ez a feladat arra összpontosít, hogy metódusokat adj az `Array` struktúrához Swiftben. Ezt a legegyszerűbben [extension][extensions] használatával lehet megtenni.

```swift
extension Array {
  // Write your code for the 'Strain' exercise in this file.
}
```

Az `Array` dokumentációja [itt][array] érhető el.

[array]: https://developer.apple.com/documentation/swift/array
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
