# Kiegészítés az utasításokhoz

A rács minden sora egy szóként jelenik meg.

Például

```
    0 1 0
    1 0 0
    1 1 0
```

így jelenik meg:

```
0x2
0x4
0x6
```

A rácsnak legfeljebb 32 oszlopa lehet.

## Regiszterek

| Regiszter | Használat     | Típus   | Leírás                        |
| -------- | ------------ | ------- | --------------------------- |
| `$a0`    | bemenet       | egész szám | sorok száma              |
| `$a1`    | bemenet       | egész szám | oszlopok száma           |
| `$a2`    | bemenet       | cím     | a rács az aktuális generációhoz |
| `$a3`    | bemenet/kimenet | cím   | a rács a következő generációhoz |
| `$t0-9`  | ideiglenes    | bármilyen | ideiglenes tárolásra használatos |
