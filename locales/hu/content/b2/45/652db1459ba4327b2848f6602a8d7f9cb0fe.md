# Bevezetés

A Pairs and Dicts fogalom a Julia szótártípusának alapjaival foglalkozott.

Mivel a `Dict`-ek fontos és gyakran használt gyűjteménytípusok, rengeteg függvény áll rendelkezésre a kezelésükre.

## Bejegyzések lekérése

Egy bejegyzés legegyszerűbben kulcs alapján kérhető le (ahogy sok más nyelvben is).
Ha viszont egy nem létező kulcsot kérünk le, `KeyError`-t kapunk.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

A lekérés előtt ellenőrizhetnénk a kulcs meglétét is (például a `haskey(d, 4)` hívással), de néha hasznos, ha a hiányzó kulcsokhoz egyszerűen egy alapértelmezett értéket kapunk.

Erre szolgál a `get()` függvény és annak módosító változata, a `get!()`.
Abban különböznek, hogy a „hiányzó” kulcs bekerül-e a `Dict`-be.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

A korábbi fogalomban láttuk, hogy a `delete!()` kulcs alapján töröl egy bejegyzést.
Ez összeköthető az érték lekérésével a `pop!()` függvény használatával.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Iteráció

Ha egy `Dict`-en iterálunk, alapértelmezés szerint `key => value` párokat kapunk.
Az összetevőket a szokásos `.first` és `.second` elnevezéssel érhetjük el.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Gyakran csak a kulcsokra vagy csak az értékekre van szükségünk, ez pedig egyszerűen megoldható.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Egyesítés

Két `Dict` összevonása hasznos lehet, de tisztázni kell, mi történjen azokkal a kulcsokkal, amelyek egynél több bemenetben is szerepelnek.

A `merge()` és `merge!()` függvények tetszőleges számú megadott `Dict`-et vonnak össze balról jobbra.

A meglévő kulcsok értékeit egyszerűen felülírják, így a jobb szélső `Dict` „győz”.

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

A `mergewith()` és `mergewith!()` függvényeknél az első argumentumként egy függvényt adhatunk meg, amely meghatározza, hogyan vonódjanak össze az ismétlődő kulcsok.
Az összeadás egyszerű példa erre.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Vegyük észre, hogy a `mergewith` függvények jó példát mutatnak a magasabb rendű függvények működésére.
