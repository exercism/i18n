# Kiegészítés az utasításokhoz

## Kimeneti formátum

A tanuló növényeit egy nullával lezárt stringként írd ki, vesszőt és szóközt használva elválasztóként.

## Regiszterek

| Regiszter | Használat     | Típus    | Leírás                        |
| --------- | ------------- | -------- | ----------------------------- |
| `$a0`     | bemenet       | cím      | a kert ábrája                 |
| `$a1`     | bemenet       | cím      | a tanuló neve                 |
| `$a2`     | bemenet/kimenet | cím    | nullával lezárt kimeneti string |
| `$t0-9`   | ideiglenes    | bármilyen | ideiglenes tárolásra használatos |
