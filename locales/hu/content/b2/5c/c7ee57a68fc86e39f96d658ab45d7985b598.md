# Tesztek

A feladatok mind a [Pester][pester] keretrendszert használják a mockoláshoz és a teszteléshez.
Minden teszt egy `[Exercise].tests.ps1` nevű fájlban lesz, ahogy az a Pester keretrendszerben szokásos.
Ha a megfelelő könyvtárban vagy (abban, amelyik az `[Exercise].ps1` és az `[Exercise].tests.ps1` fájlt tartalmazza),
a teszteket PowerShellből a következő hívással futtathatod:

``` PowerShell
Invoke-Pester
```

Ez az összes `.tests.ps1` fájlt lefuttatja, amit a könyvtárban talál.

Ha nem PowerShellt, hanem más shellt használsz, a teszteket a következő hívással futtathatod:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Tesztek futtatása a Visual Studio Code-ban

Győződj meg róla, hogy a Visual Studio Code-ban telepítve van [a PowerShell-bővítmény][extension].

A teszteket a Visual Studio Code-ban többféleképpen is futtathatod:

- A `.Tests.ps1` szkript futtatása a Debug menüből. A billentyűparancsok: `F5` vagy `Shift + F5`
- A szerkesztőn belülről a tesztek kódjában a `Describe` kulcsszó felett található „Run Tests” hivatkozásra kattintva
- Egy Task beállítása a Pester keretrendszer futtatásához

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
