# Bevezetés

A _ternáris operátor_ egy könnyű, kompakt alternatívája az egyszerű _if/else_ elágazásoknak.
Általában return utasításokban használják (de nem kizárólag ott). Egyetlen sorban hozza meg a döntést: visszaadja a bal oldali értéket, ha a kifejezés `true`, és a jobb oldali értéket, ha `false`, a következőképpen:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Sok egyszerű _if/else_ kifejezés egyszerűsíthető _ternáris operátor_ használatával.
