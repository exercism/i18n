# Részletesen

A tömbök és a listák skalárokból álló rendezett gyűjtemények.
Ha nem használunk referenciákat (amelyekről egy külön fogalomban lesz szó), ez azt jelenti, hogy a tömbök és a listák mindig laposak, azaz nem tartalmazhatnak más tömböket vagy listákat.

A legtöbb esetben a listákat zárójelek `()` veszik körül, az elemeiket pedig vesszők `,` választják el.

Egy tömbváltozót általában úgy töltünk fel, hogy értékül adunk neki egy listát, például: `my @names = ('Alice', 'Bob', 'Charlie');`.

Egy tömb vagy lista elemeihez indexek megadásával, azaz alsó indexszel férhetsz hozzá, például: `('Alice', 'Bob', 'Charlie')[1] # 'Bob'`.

A Perlben az indexek `0`-tól kezdődnek.
A negatív indexek a tömb vagy lista végétől számolódnak, például: `('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`.

## Függvények

Sok függvényt implementáltak a tömbök és a listák kezelésére; ezek közül a leghasznosabbak közé tartozik a [grep][grep], amely egy feltételnek megfelelő elemekből álló új, szűrt listát ad, a [map][map], amely az elemeket egy új értéklistává alakítja, és a [sort][sort], amely az elemeket átrendezett új listában adja vissza.

A tömbök módosítására szolgáló függvények közé tartozik a [push][push], amely a tömb végére fűz elemeket, a [pop][pop], amely eltávolítja az utolsó elemet, a [shift][shift], amely eltávolítja az első elemet, az [unshift][unshift], amely a tömb elejére szúr be elemeket, és a [splice][splice] az összetettebb módosításokhoz.

A tömbök és listák bejárása egy [for(each)][perlsynforeach] utasítással szintén gyakran fog előkerülni.

## A sigilek eltérései

Amikor egy tömb elemeihez férsz hozzá, az adott sigil határozza meg az eredményt.
A változónév végén álló `[]` alsó index az, ami megmondja Perlnek, hogy az adott nevű tömböt éred el.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

Bár megengedett, az olvashatóság érdekében érdemes elkerülni, hogy a különböző változótípusok ugyanazt a nevet használják.

## Tömbök és listák

A tömbök és a listák sok hasonlóságot mutatnak, és sok helyen felcserélhetően használhatók, de nem ugyanaz a két dolog.
A lista skalárok rögzített és megváltoztathatatlan gyűjteménye.
A tömb skalárok változó gyűjteménye, amelynek a tartalma és maga a mérete is megváltoztatható.

Bizonyos kontextusokban eltérően viselkednek.
A skalár kontextusban használt tömb a tömb méretét adja vissza.
A skalár kontextusban használt lista a lista utolsó elemét adja vissza, és esetleg figyelmeztetéseket kapsz arról, hogy a többi tartalma void kontextusban használódik.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
