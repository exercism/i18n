# Bemutatás

Ahhoz, hogy megértsd a [`Box`][box] típust, érdemes tisztában lenni azzal, hogy mi a [verem és a halom][stack and heap].

A verem a memória egy olyan területe, amely utolsóként be, elsőként ki (LIFO) pufferként működik. Nagyon gyors adatot betolni a verembe, és gyorsan ki is lehet onnan venni.
Az adatok lehetnek változók vagy függvénycímek, de a méretüknek a fordítás idején ismertnek és rögzítettnek kell lennie.

Ha az adat mérete a fordítás idején nem ismert, vagy változhat, akkor azt a halmon kell lefoglalni. A foglalás során a halmon keresni kell egy elég nagy helyet
az adat tárolására, oda kell írni az adatot, majd az adat memóriacímét be kell tolni a verembe. Mindez lényegesen több időt vesz igénybe, mint egyszerűen a veremre tenni az adatot. A halomról adatot kiolvasni kicsit lassabb, mert a veremben lévő címen keresztül kell eljutni az adat halmon lévő helyéhez.

A `Box` egy okos mutató, amely a halmon foglal helyet az adatnak. A cím a veremben van, és a halmon lévő adatra mutat. Az egyik [ok][reasons] arra, hogy `Box`-ot használj, az, hogy a halomra tedd az adatot, amikor olyan típusod van, amelynek a mérete a fordítás idején nem ismert, és a típus egy értékét olyan helyen szeretnéd használni, ahol pontos méretre van szükség. Ennek egy gyakorlati esete, amikor több structod van, amelyeket ugyanúgy szeretnél kezelni egy trait segítségével, amelyet mindegyik megvalósít, ahogy az alábbi példa mutatja.

Tegyük fel, hogy két structunk van. Mindkét struct egy-egy olyan dolgot képvisel, ami idegesítő lehet. Elérhetjük, hogy mindegyik struct megvalósítson egy Annoyance traitet, így:

```rust
struct WerewolfOfLondon;
struct Rooster;

trait Annoyance {
    fn annoy(&self) -> &'static str;
}

impl Annoyance for WerewolfOfLondon {
    fn annoy(&self) -> &'static str {
        "ahhh-OOOOOOO!"
    }
}

impl Annoyance for Rooster {
    fn annoy(&self) -> &'static str {
        "errr-errr-errr-errr-ERRRRRRRRR!"
    }
}
```

Most tegyük fel, hogy szeretnénk egy függvényt, amely a neki átadott napszak alapján visszaad egy Annoyance-t. Először ezzel próbálkozhatunk, amiről kiderül, hogy nem fordul le:

```rust
enum TimeOfDay {
    Midnight,
    Morning,
}

//return something that implements Annoyance
fn annoy_me(time_of_day: TimeOfDay) -> impl Annoyance {
    match time_of_day {
        TimeOfDay::Midnight => WerewolfOfLondon,
        TimeOfDay::Morning => Rooster,
    }
}

// `match` arms have incompatible types
// expected struct `WerewolfOfLondon`, found struct `Rooster`
// this is found to be of type `WerewolfOfLondon`
// `match` arms have incompatible types
// you could change the return type to be a boxed trait object
// if you change the return type to expect trait objects, box the returned expressions

```

A fordító, segítőkészsége teljében, pontosan megmondja, mit kell tennünk: egy boxolt trait objektumot kell visszaadnunk. Ha nem tudod, mi az a trait objektum, egyszerűen úgy írhatjuk le, mint egy módját annak, hogy egy függvény [dinamikus diszpécseléssel][dynamic dispatch] visszaadjon egy konkrét objektumot, jóllehet bármilyen olyan objektumot visszaadhatna, amely megvalósít egy adott traitet. Mivel dinamikus diszpécselésre van szükség, megpróbálhatjuk egyszerűen a trait neve elé tenni a `dyn` kulcsszót, és meglátjuk, megússzuk-e.

```rust
fn annoy_me(time_of_day: TimeOfDay) -> dyn Annoyance {
    match time_of_day {
        TimeOfDay::Midnight => WerewolfOfLondon,
        TimeOfDay::Morning => Rooster,
    }
}

// the size for values of type `dyn Annoyance` cannot be known at compilation time
// the trait `Sized` is not implemented for `dyn Annoyance`
// all local variables must have a statically known size
// unsized locals are gated as an unstable feature
```

Az egyik hiba az, hogy a `dyn Annoyance` mérete nem ismert a fordítás idején. Ennek az az oka, hogy az `annoy_me` a meghívása előtt nem tudja, milyen konkrét trait objektumot fog visszaadni. Az Annoyance-t megvalósító structoknak különböző mezőik lehetnek, és különböző méretűek lehetnek. És arra is emlékeztetnek minket, hogy a `Box` egyik felhasználási módja olyan típusokra való, amelyek mérete a fordítás idején nem ismert. Ezért most egy `Box`olt visszatérési értékkel próbálkozunk, és a match kifejezésből visszaadott értékeket is `Box`ba tesszük, így:

```rust
fn annoy_me(time_of_day: TimeOfDay) -> Box<dyn Annoyance> {
    match time_of_day {
        TimeOfDay::Midnight => Box::new(WerewolfOfLondon),
        TimeOfDay::Morning => Box::new(Rooster),
    }
}
```

A `Box` szignatúrája `Box<T>`, ahol a `T` a boxolandó konkrét típust jelöli, amelyet a csúcsos zárójelek közé írunk, mint a fenti `Box<dyn Annoyance>` esetében.

A boxolt trait objektumot így használhatjuk fel:

```rust
fn be_annoying(annoying_one: &dyn Annoyance) {
    println!("{:?}", annoying_one.annoy());
}

pub fn main() {
    let my_annoyance = annoy_me(TimeOfDay::Midnight);
    be_annoying(&*my_annoyance);
    let my_annoyance = annoy_me(TimeOfDay::Morning);
    be_annoying(&*my_annoyance);
}
```

amely a következőt írja ki:

```rust
"ahhh-OOOOOOO!"
"errr-errr-errr-errr-ERRRRRRRRR!"
```

Mivel a `my_annoyance` típusa `Box<dyn Annoyance>`, a `Box`-ról a `*` deref operátorral kell dereferálni. Ezután `dyn Annoyance`-ként hivatkozunk rá, hogy a `be_annoying` függvény kölcsön tudja venni.

Egy másik megvalósítási mód az lenne, ha elhagynánk azt a követelményt, hogy a paraméternek mérete legyen. Ebben az esetben a fordítás minden Annoyance-variánshoz külön függvényt hozna létre, hogy statikusan lehessen diszpécselni (ezt a folyamatot [monomorfizálásnak][monomorphization] nevezik), így:

```rust
fn be_annoying<A: Annoyance + ?Sized>(annoying_one: &A) {
    println!("{:?}", annoying_one.annoy());
}
```

Egy újabb megvalósítási mód az lenne, hogy a `be_annoying` függvény fogadjon egy `Box<dyn Annoyance>` értéket, és [deref-konverzióval][deref coercion] elkerülje a `Box` kézi dereferálását. Ez átadná az Annoyance trait objektum tulajdonjogát a `be_annoying` függvénynek. Az objektum a függvény végén kikerülne a scope-ból, és többé nem lenne elérhető.

```rust
fn be_annoying(annoying_one: Box<dyn Annoyance>) {
    println!("{:?}", annoying_one.annoy());
}

pub fn main() {
    let my_annoyance = annoy_me(TimeOfDay::Midnight);
    be_annoying(my_annoyance);
    let my_annoyance = annoy_me(TimeOfDay::Morning);
    be_annoying(my_annoyance);
}
```
