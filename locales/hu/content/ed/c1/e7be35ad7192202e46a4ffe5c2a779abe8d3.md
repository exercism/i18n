# Bevezetés

A Common Lisp kódok S-kifejezésekből (szimbolikus kifejezésekből) állnak. Ezeket röviden sexprnek hívják. Minden sexpr vagy atom, vagy cons. Az S-kifejezések kiértékelésekor automatikusan visszaadnak egy értéket, amely a kifejezés helyére kerül. Amikor saját függvényt írsz (a `defun` segítségével), a függvény törzsének utolsó értéke automatikusan visszaadódik:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
