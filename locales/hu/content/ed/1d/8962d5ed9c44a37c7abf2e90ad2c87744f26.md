# A változókról

## Változók

A _változók_ olyan helyek, ahol adatokat tárolhatsz.
A Bash kétféle adatot ismer: stringeket és tömböket.
A tömbökről később lesz szó.

Így rendelsz értéket egy változóhoz:
```bash
name="value"
```

~~~~exercism/note
**Fontos:** az egyenlőségjel körül _nem lehet szóköz_!

Ha mégis van szóköz, mint ebben a példában,

```bash
x = 10
```

akkor a bash az `x` **parancsot** hívja meg a `=` és a `10` **két argumentummal**!
~~~~

A változókat _paramétereknek_ is nevezhetjük.
Ebben a dokumentumban a két kifejezést felváltva használjuk.

Íme néhány fontos paraméter, amelyet a bash használ vagy beállít:

* `PATH`: azon könyvtárak kettősponttal elválasztott listája, amelyekben a külső parancsokat keresi.
* `IFS`: a belső mezőelválasztó.
   Alább meglátjuk, hogyan használjuk.
* `PWD`: az aktuális munkakönyvtárad.
   Ugyanaz az értéke, mint a `pwd` parancs kimenetének.
* `RANDOM`: egy álvéletlen egész szám 0 és 32767 között.
* `BASH_VERSION`: a futó bash-példány verziószáma.

## Változónevek

A változónév _nagybetűkből, kisbetűkből, számokból és alulvonásból_ áll.
Nem kezdődhet számmal.

~~~~exercism/caution
Bevált gyakorlat, hogy **kerüljük a csupa nagybetűs változóneveket**.
A shell ezt a konvenciót használja a saját paramétereinél, és nem szeretnéd véletlenül felülírni azokat a shellparamétereket, amelyeknek különleges jelentésük van.

## Paraméterkiterjesztés

Egy paraméter értékét a `$varname` szintaxissal kapod meg.

```bash
x=10
echo "The value of x is $x"
```

Hogy a változónév ne keveredjen a körülötte lévő szöveggel, kapcsos zárójelbe teheted a változónevet.
Ha például a `10x10` stringet szeretnéd kiírni:

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

Néhány [stílusútmutató][google-style-guide] az esetek többségében a kapcsos zárójelek használatát javasolja az olvashatóság és/vagy a következetesség érdekében.

## Pozíciós paraméterek

Ahogy a [Parancsok és argumentumok][cmds-args] leckében szó volt róla, a parancsok fogadhatnak argumentumokat.
A bash-szkriptek sem kivételek.
A bash aktuális példányának argumentumait _pozíciós paramétereknek_ nevezzük.
Ezeket a speciális paraméterekkel kérheted le:

* `$1`: az első pozíciós paraméter
* `$2` ... `$9`: a további paraméterek
* `${10}` ...: kétjegyű számoknál már kapcsos zárójel kell.
* `$0`: az aktuális szkript neve.

A shellfüggvények argumentumai is pozíciós paraméterek, és pontosan ugyanígy kezeljük őket.
A függvényekről egy későbbi leckében lesz szó bővebben.

### Különleges pozíciós paraméterek

Néhány _speciális paraméter_ segít a pozíciós paraméterek kezelésében.

* `$#` értéke a pozíciós paraméterek _száma_.
* `"$@"` értéke az összes pozíciós paraméter listája, mindegyik külön szóként.
* `"$*"` értéke egyetlen string, amelyben az összes pozíciós paramétert egy karakter fűzi össze.
  * Az összefűző karakter a `$IFS` változó _első karaktere_, ami alapértelmezés szerint egy szóköz.

A `"$@"` a legbiztonságosabb módja annak, hogy a pozíciós paramétereket átadd egy másik parancsnak, miközben biztonságosan idézőjelben maradnak.
Ezt használod arra is, hogy végigmenj a pozíciós paramétereken:

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

A gyakorlatban a `"$@"`-t gyakrabban használjuk, mint a `"$*"`-ot.

## Parancshelyettesítés

A bash-szkriptekben gyakran előforduló művelet, hogy elkapod egy parancs kimenetét, és eltárolod egy változóban.
Ehhez a _parancshelyettesítést_ használod.

```bash
var=$(command)
```

Ha például egy stringet csupa nagybetűssé szeretnél alakítani, ezt teheted:

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## Még néhány szó a paraméterkiterjesztésről

A bashben számos beépített lehetőség van a változók és stringek kezelésére, így nem kell külső parancsokat hívnod.

* Szöveg csupa nagybetűssé alakítása.
  Az előző részben megmutattam, hogyan lehet a `tr` paranccsal nagybetűssé alakítani egy szöveget.
  Ha ezt bashben szeretnéd megtenni:

  ```bash
  echo "${text^^}"
  ```

  Hasonlóképpen a `${text,,}` kisbetűssé alakítja az értéket.

* Alapértelmezett érték megadása, ha a változó üres.

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* Keresés és csere.

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

Sok más érdekes paraméterkiterjesztés is létezik: részstring kinyerése, a string hosszának lekérdezése, alapérték _hozzárendelése_, szöveg eltávolítása az érték elejéről vagy végéről, és még sok más.
Olvass róluk [a kézikönyvben][param-exp].
