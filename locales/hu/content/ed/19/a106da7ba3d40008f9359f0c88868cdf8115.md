# A fogalomról

Amikor Gleam-ben egy értéken mintaillesztést végzünk, gondoskodnunk kell róla, hogy a minták lefedjék a típus minden lehetséges értékét, különben a kód nem fordul le.

Ezt a függvényt el kellene utasítani, mert nem kezeli azt az esetet, amikor a lista üres:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

A Gleam-programokban a legtöbbször minden lehetséges esetet szeretnénk kezelni, de néhány programban, például prototípusokban és gyors szkriptekben, előfordulhat, hogy csak a hibátlan lefutásra akarunk összpontosítani, és nem írunk kódot a többi esetre. Ilyenkor jön képbe a Gleam `let assert` utasítása.

A let assert segítségével egy minta a típusnak csupán néhány lehetséges értékét fedheti le, és ha a minta nem illeszkedik egy értékre, a program összeomlik. A `let assert` használatával a fenti függvényt így írhatjuk meg:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

A Gleam-könyvtárakban soha nem szabad let assert utasításokat használni, mert azok összeomlaszthatják a programot; helyette a `Result` típust kell használni, és hagyni, hogy az alkalmazás fejlesztője döntse el, hogyan kezelje a hibákat.
