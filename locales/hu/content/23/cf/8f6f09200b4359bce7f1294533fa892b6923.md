# Tesztek

Minden feladatnál van egy egyszeri beállítás, ami néhány percet is igénybe vehet:

```
npm install
```

Nyiss meg két shellt, és az elsőben indítsd el a build folyamatot.

```
npm start
```

A másodikban pedig indítsd el a teszteket.

```
npm test
```

Ahogy szerkeszted a kódot, a két folyamat folyamatosan újraépít és újrafuttatja a teszteket.
