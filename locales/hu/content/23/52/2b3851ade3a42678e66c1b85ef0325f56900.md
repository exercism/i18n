# Csak olvasható osztályok és tulajdonságok

A csak olvasható osztályok és tulajdonságok lehetővé teszik, hogy az osztályok nyilvános tulajdonságokat adjanak meg a könnyű elérés érdekében, de megakadályozzák a módosításukat.
Ahhoz, hogy egy tulajdonságot csak olvashatóként jelölj meg, a típus megadása előtt szerepelnie kell a `readonly` szónak.
A tulajdonság egyszer kaphat értéket, de bármilyen kísérlet az érték újbóli hozzárendelésére vagy módosítására Error-t eredményez.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

A csak olvasható osztályok erre a viselkedésre épülnek: ha `readonly` kulcsszóval deklarálod őket, a csak olvasható jelölést minden tulajdonságukra alkalmazzák.
Ráadásul megakadályozzák dinamikus tulajdonságok hozzáadását.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
