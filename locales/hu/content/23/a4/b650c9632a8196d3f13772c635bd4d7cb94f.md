# Bevezetés

A [tuple-ök][tuples] több értéket egyetlen összetett értékké csoportosítanak.
A tömbökkel ellentétben a tuple-ben lévő értékeknek nem kell azonos típusúnak lenniük, és a tuple mérete a létrehozás után rögzített.

Egy tuple létrehozásához az értékeket zárójelbe teszed, vesszővel elválasztva:

```swift
let order = ("biscuits", 2.99, 3)
```

A típusannotációkat explicit módon is megadhatod:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Ha egy névtelen tuple-ből ki szeretnéd nyerni az egyes elemeket, használd a nullától induló indexszintaxist (`.0`, `.1` stb.):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Nevesített tuple-ök

A tuple definiálásakor nevet adhatsz az egyes elemeknek:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Az elemek elnevezése olvashatóbbá teszi a kódot, és lehetővé teszi, hogy az elemeket a címkéik segítségével, pont jelöléssel érd el:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

Az elemneveket a típusannotációban is megadhatod:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Tuple-ök módosítása

Ha egy tuple-t változóként (`var`) deklarálsz, frissítheted az elemeit:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Több érték visszaadása

Bár a Swift függvényei csak egyetlen értéket adhatnak vissza, egy tuple visszaadásával több értéket is becsomagolhatsz, és [több értéket adhatsz vissza egy függvényből][multiple-return-values]:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Tuple-ök felbontása

A tuple értékeit felbonthatod (kicsomagolhatod) külön konstansokra vagy változókra:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

A tuple-ök felbontása közvetlenül `for-in` ciklusokban is működik:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
