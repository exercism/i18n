# Utasítások

Az egyik barátodnak van egy régi nagykereskedése, **Gross Store** néven.
A név onnan ered, hogy mennyiséget árul a bolt: mindent [nagytucatban][gross-unit].
A barátod megkért, hogy készíts egy értékesítési pont (POS) rendszert a boltja számára.
**Először egy prototípust szeretnél készíteni hozzá.**
**A prototípusodban a rendszered csak a mennyiséget fogja rögzíteni.**
A barátod adott egy listát a mértékegységekről, hogy segítsen:

| Mértékegység       | Érték |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. A mértékegység tárolása a programodban

Ahhoz, hogy használni tudd a mértékegységet, el kell tárolnod azt a programodban.

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. Új vevői számla létrehozása

Ehhez egy olyan függvényt kell implementálnod, amely új (üres) számlát készít a vevő számára.

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. Termék hozzáadása a vevő számlájához

Ehhez a következőket kell tenned:

- Add vissza a `false` értéket, ha a megadott `unit` nincs benne a `units` mapban.
- Egyébként vedd fel a terméket a vevő `bill` számlájára a termék neve szerint indexelve, majd add vissza a `true` értéket.
- Ha a termék már szerepel a számlán, növeld a mennyiségét a megadott `unit`-hoz tartozó értékkel.

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> Jegyezd meg, hogy a visszaadott érték típusa `bool`.

## 4. Termék eltávolítása a vevő számlájáról

Ehhez a következőket kell tenned:

- Add vissza a `false` értéket, ha a megadott termék **nincs** a számlán
- Add vissza a `false` értéket, ha a megadott `unit` nincs benne a `units` mapban.
- Add vissza a `false` értéket, ha az új mennyiség 0-nál kevesebb lenne.
- Ha az új mennyiség 0, teljesen távolítsd el a terméket a `bill` számláról, majd add vissza a `true` értéket.
- Egyébként csökkentsd a termék mennyiségét, és add vissza a `true` értéket.

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> Jegyezd meg, hogy a visszaadott érték típusa `bool`.

## 5. Egy adott termék mennyiségének visszaadása a vevő számlájáról

Ehhez a következőket kell tenned:

- Add vissza a `0` és a `false` értéket, ha az `item` nincs a számlán.
- Egyébként add vissza a termék `bill`-ben lévő mennyiségét és a `true` értéket.

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> Jegyezd meg, hogy a visszaadott értékek típusa `int` és `bool`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
