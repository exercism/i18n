# Bevezetés

## Alapértelmezett paraméterértékek

[Alapértelmezett paraméterértékeket][default-parameter-values] egy függvény bármelyik paraméteréhez megadhatsz úgy, hogy a paraméterlistában a paraméter típusjelölése után értéket rendelsz a paraméterhez. Ha megadtál egy alapértelmezett paraméterértéket, a függvény hívója elhagyhatja ezt a paramétert a híváskor, és helyette az alapértelmezett érték használatos.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Variadikus paraméterek

A Swiftben a [_variadikus paraméterek_][variadic-parameters] lehetővé teszik, hogy egy függvény egyetlen paraméterébe nulla vagy több azonos típusú értéket adj át. Ezt úgy jelölöd, hogy a paraméter típusjelölése után `...`-t írsz.

Ezeket az értékeket a rendszer automatikusan egy tömbbe csoportosítja, amelynek elemei ugyanolyan típusúak, mint a variadikus paraméter típusa.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Vedd figyelembe, hogy a variadikus paraméterek használatakor a Swiftnek van egy korlátja.
Ha egy függvény definíciójában a variadikus paraméter után további paraméterek következnek, akkor a variadikus paramétert követő első paraméterhez _kötelező_ argumentumcímkét adni.

## In-out paraméterek

Egy függvény törzsén belül a paramétereket konstansként, nem változóként kezeli a nyelv; ha megpróbálod módosítani egy paraméter értékét, az fordítási idejű hibát okoz.
Ha egy függvény módosítani szeretné egy paraméter értékét, [_in-out paramétert_][in-out-parameters] kell használnia, hogy ezt a módosíthatóságot egyértelművé tegye.

Az in-out paraméterek használatához a programozónak három dologra kell ügyelnie:

1. A függvénydefinícióban az in-out paramétereket kifejezetten meg kell jelölni úgy, hogy az `inout` kulcsszót a paraméter típusjelölésében a `:` és a típusnév közé írjuk.
2. Az in-out paraméternek átadott értéket változóként kell deklarálni, nem konstansként. Ugyanígy literál sem lehet.
3. A függvényhívásban a változó neve elé `&`-t kell írni, ami kifejezetten jelzi, hogy módosítható.

Ha ezt megtetted, a függvény belső másolatot készít az in-out paraméterről, a függvény törzsében leírtak szerint módosítja, majd amikor visszatér, a módosított értéket visszamásolja a hívótól kapott változóba.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Van néhány további szabály, amit érdemes szem előtt tartanod az in-out paraméterekkel kapcsolatban.

1  Az in-out paramétereket használó függvényen belül nem hivatkozhatsz arra a változóra, amelyet in-out paraméterként adtál át.
2. Ugyanaz a változó nem adható át több in-out paraméterként ugyanabban a függvényben.
   Például az `inoutFunc(&mutVar, &mutVar)` hívás fordítási hibát vált ki.
~~~~

## Egymásba ágyazott függvények

A Swiftben [függvényeket más függvényeken belül is definiálhatsz][nested-functions].
Ezeket **egymásba ágyazott függvényeknek** nevezzük.

Az egymásba ágyazott függvényeket gyakran privát segédfüggvényként használjuk, hogy olyan konkrét feladatokat lássanak el a befoglaló függvény számára, amelyek nem zsúfolják tele a külső scope-ot:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Az egymásba ágyazott függvények úgy viselkednek, mint a szokásos függvények, de a láthatóságuk a befoglaló függvény törzsére korlátozódik.
