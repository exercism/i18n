# A listákról

A **listák** a rendezett sorozatgyűjtemény Java-ban.
A tömbökkel ellentétben egy `List` mérete növekedhet, hogy bármennyi elemet befogadjon.
Az egyik szabványos implementáció az `ArrayList`, amely mögött egy átméretezhető tömb áll.
Egy másik szabványos implementáció a `LinkedList` osztály, amely mögött egy kétszeresen láncolt lista áll.

A `List`-ek lehetnek üresek, vagy tetszőleges számú elemet tartalmazhatnak (a duplikátumokat is beleértve).
A `List`-ek egy **generikus interfész**, amely típusparaméterrel jelzi, hogy milyen típusú objektumokat tartalmazhatnak.
Például:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

A `List`-ek számos hasznos metódussal rendelkeznek elemek hozzáadásához, eltávolításához, lekéréséhez és egy elem jelenlétének ellenőrzéséhez:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```

A [`Collections`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Collections.html) osztály is tartalmaz néhány hasznos segédprogramot a `List`-hez hasonló gyűjtemények kezeléséhez:

```java
List<Integer> numbers = new ArrayList<>(List.of(1, 5, 3, 2, 4));
Collections.sort(numbers); // [1, 2, 3, 4, 5]
Collections.reverse(numbers); // [5, 4, 3, 2, 1]
Collections.fill(numbers, 42); // [42, 42, 42, 42, 42]
List<Integer> fiveNines = Collections.nCopies(5, 9); // [9, 9, 9, 9, 9]
```
