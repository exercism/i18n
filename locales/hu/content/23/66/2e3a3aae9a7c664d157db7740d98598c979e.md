# Tesztek

## Parancssor

A következő paranccsal futtathatod a teszteket a parancssorból:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

A `<exercise>` helyére írd be annak a feladatnak a nevét, amelyet éppen megvalósítasz.

## Interaktív

A Prolog interaktív futtatásához először futtasd ezt:

```bash
swipl
```

Miután elindul a Prolog konzol, töltsd be az implementációdat, és futtasd a teszteket ezzel:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

A `<exercise>` helyére írd be annak a feladatnak a nevét, amelyet éppen megvalósítasz.

### Változtatások újratöltése

Miután a fenti fájlok betöltődtek, alkalmazhatod az elvégzett változtatásokat ezzel:

```
?- make.
```

## Kihagyott tesztek

Amikor először elkezdesz egy feladatot, csak az első teszt fut le. A többi tesztet kihagytuk azzal, hogy a `test` célhoz hozzáadtuk a `condition(pending)` feltételt. Miután az első teszt sikeres, oldd fel a következő teszt kihagyását úgy, hogy a `condition(pending)` feltételben a `pending` értékét `true`-ra módosítod. Ismételd meg minden tesztnél, amíg az összes le nem fut és sikeres nem lesz.

### Parancssor

A parancs végére írd be a `-- --all` argumentumot, hogy a függőben lévő tesztek is lefussanak:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
