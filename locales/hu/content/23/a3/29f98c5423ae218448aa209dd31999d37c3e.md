# Fizetési audit adatbázisban

## A feladat

Az ABC Corp szeretné, ha betöltenéd az SQL-adatbázis összes adatát egy [Ballerina-táblába](https://ballerina.io/learn/by-example/table-syntax/) további feldolgozás céljából. Ezután meg kell keresned azoknak a dolgozóknak a nevét, akiknek a fizetési bejegyzései meghaladják az adott összeget (például 3000,00), a betöltött Ballerina-tábla lekérdezésével.

**1. lépés:**

Hozz létre egy Ballerina-táblát a következő oszlopokkal.

`payment_id` - egész szám

`amount` - tizedes tört

`employee_name` - string

**2. lépés:**

Töltsd fel a fenti Ballerina-táblát az H2-adatbázis megfelelő teljes adathalmazának betöltésével. A `payment_id`-t használd a tábla elsődleges kulcsaként.

**3. lépés**

Kérdezd le a Ballerina-táblát Ballerina lekérdezési kifejezésekkel, hogy megtaláld azoknak a dolgozóknak a nevét, akiknek a fizetési bejegyzései meghaladják az adott összeget. Az eredményt a dolgozó neve szerint növekvő sorrendbe rendezd. A visszaadás előtt távolítsd el az ismétlődő neveket az eredményből.

> MEGJEGYZÉS: A megoldás megvalósításához kötelező Ballerina-táblát használni.

## Az adatbázis részletei

Ehhez a feladathoz a mellékelt H2-adatbázist használd.

> A minta adatbázisfájl a `gofigure.mv.db`, az adatbázis neve pedig `gofigure`. A `db` mappában található.

A következő táblák már benne vannak a minta H2-adatbázisban némi mintaadattal. Az oszlopnevek és az adattípusok lentebb láthatók.

**Tábla neve**: `Employee`

| **Oszlopok:**      | típus |
| -----------       | ----------- |
| `employee_id`     | egész szám, automatikusan növekvő elsődleges kulcs       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | egész szám        |

**Tábla neve**: `Payment`

| **Oszlopok:**      | típus |
| -----------       | ----------- |
| `payment_id`      | egész szám, automatikusan növekvő elsődleges kulcs       |
| `date`            | dátum        |
| `amount`          | tizedes tört        |
| `employee_id`     | egész szám        |
| `reason`          | string        |

* Az adatbázisfájl a `gofigure.mv.db`. A JDBC URL-t így add meg: `jdbc:h2:file:/path/to/db/file`
* Felhasználónév: `root`
* Jelszó: `root`

## Megkötések

* A lekérdezések és a Ballerina minta érvényesítéséhez a `db` mappában található H2-adatbázisfájlt használd
* A maven dependency params megközelítéssel add hozzá az H2-adatbázis-vezérlőt platformfüggőségként a Ballerina.toml fájlodhoz

## Tesztkörnyezet

* A teszteket a `bal test` paranccsal futtathatod, és a megadott mintaadatbázis ellen futnak le.

## Tippek

* Az adatbázissal való munkához használd a [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) modult
* A JDBC-vezérlő függőségként való hozzáadásának lépéseit lásd az [Előfeltétel](https://lib.ballerina.io/ballerinax/java.jdbc/latest) szakaszban
* Az adatok adatbázisból való lekérdezéséhez használd a [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) remote metódust
* Nézd meg az [Egyszerű lekérdezés](https://ballerina.io/learn/by-example/mysql-query-operation) példát
* Nézd meg a [Táblaszintaxis](https://ballerina.io/learn/by-example/table) példát
* A [Táblák lekérdezése](https://ballerina.io/learn/by-example/querying-tables) segítségével keresd meg a szükséges adatokat a Ballerina-táblából
