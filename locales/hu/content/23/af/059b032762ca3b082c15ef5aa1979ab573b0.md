# Bevezetés

Az öröklődés az OOP (objektumorientált programozás) egyik alapvető fogalma.
Egy IS-A kapcsolatot fejez ki.
A programozásban szó szerint ugyanazt jelenti, mint az angolban: tulajdonságokat örökölni a szülőtől (a programozásban ezek a tulajdonságok általában függvények és változók).

Vegyük például az `Animal` osztályt, ahogy az alábbi kód mutatja:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

Az `Animal` szülőosztály, mert az általa definiált tulajdonságok általánosságban minden állatra kiterjeszthetők.

Vegyük a `Lion` nevű állatot, amelynek az osztálya így néz ki:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
Az `Override` annotációval jelezhetjük, hogy egy alosztály metódusa felülírja a szülőosztály egyik metódusát.
Szigorúan véve nem kötelező, de bevált gyakorlat használni.
~~~~

Ha pedig ezt írjuk:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Megjegyzés: itt az `Animal` osztályt `Lion`-nal inicializáljuk.
A kimenet így néz ki:

```java
Lion here!!
```

Az OOP szerint az öröklődésnek sok fajtája létezik, de a Java ezek közül csak néhányat támogat (a többszintűt és a hierarchikust).
Ha többet szeretnél olvasni róla, olvasd el [ezt][java-inheritance].

[java-inheritance]: https://www.javatpoint.com/inheritance-in-java#:~:text=On%20the%20basis%20of%20class,will%20learn%20about%20interfaces%20later.
