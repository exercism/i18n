# Ismertető

A [`Rational numbers`][rational] olyan törtek, amelyek számlálója és nevezője is egész szám.

Például a `2//3`-at tárolhatjuk pontos törtként a hozzávetőleges `Float64` érték `0.6666...` helyett.

Az előnye az, hogy (leszámítva az [egész túlcsordulás][integer-overflow] szélsőséges esetét) a racionális szám pontos marad, elkerülve azokat a kerekítési hibákat, amelyek a lebegőpontos számoknál gyakran elkerülhetetlenek.

Néhány további részlet a Julia [kézikönyvének oldalán][julia-rational] olvasható.

A racionális számok meglehetősen egyszerű numerikus típusok, és nagyjából úgy viselkednek, ahogy elvárnád.
Mivel a Julia korai verziói óta szabványos típusnak számítanak, a legtöbb függvény ugyanúgy elfogadja őket bemenetként, mint az egészeket és a lebegőpontos számokat.

## Racionális számok létrehozása

A létrehozás olyan egyszerű, hogy csak a `//`-t kell két egész szám közé írni.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

A közös tényezőket automatikusan eltávolítja, ezzel a törtet a [„legegyszerűbb alakjára"][lowest-terms] hozza: ezek a legkisebb egész számok, amelyek pontosan reprezentálják a törtet, és a nevezőjük nem negatív.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

A végtelen eredmények elfogadottak, a `NaN` azonban nem.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Műveletek racionális számokkal

A szokásos [`arithmetic operators`][operators] `+ - * / ^ %` lényegében ugyanúgy működnek a racionális számokkal, mint a többi numerikus típussal.

Az egész számok és más `Rational`-ok is szerepelhetnek benne, és az eredmény is `Rational` lesz.
Ha egy `float` is bekerül a kifejezésbe, az eredmény `float` lesz, ami esetleges pontosságvesztéssel járhat.

Ha `float`-ra van szükséged, egyszerűen a `float()` függvénnyel alakítsd át a racionális számot.
Teljesen megszokott, hogy valaki racionális számokat használ a pontosság megőrzésére egy hosszú számítás során, majd a végén lebegőpontos számmá alakítja az eredményt.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

A racionális számok [komplex számokkal][complex] is kombinálhatók.
A komplex számokról egy [külön fogalomban][complex-concept] olvashatsz.

## Egyéb műveletek

Juliában a racionális számok egyszerűen számok.
A fordító általában szükség szerint átalakítja a típusokat.

Arra azonban figyelj, hogy az összehasonlítások csak véges tizedestört alakú törtek esetén működnek:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Minden más esetben viszont az összehasonlításhoz a `Rational`-t `Float`-tá kell alakítani:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

A matematikai függvények elfogadnak racionális számokat bemenetként, de az eredményük lehet lebegőpontos:

```julia-repl
julia> sqrt(9//16)
0.75
```
