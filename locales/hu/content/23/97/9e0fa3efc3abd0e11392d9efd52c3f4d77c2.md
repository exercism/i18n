# Utasítások

Feltörekvő bűvészként Elyse-nek sokféleképpen kell elemeznie a pakliját.
Hogy egyszerű legyen a dolog, csak 1-10 értékű kártyákat használ.

## 1. Állapítsd meg, hány adott típusú kártya van a pakliban

Elyse szeretné tudni, hány adott típusú kártya van a paklijában.

Írj egy `cardTypeCheck` függvényt, amely két paramétert kap: egy kártyatömböt (Elyse pakliját) és a megszámolandó kártya típusát.

<!--prettier-ignore -->
~~~exercism/note
A függvény használjon `forEach`-ot, és adja vissza a megadott típusú kártyák számát a pakliban.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. Állapítsd meg, hány páratlan vagy páros kártya van

Egy másik trükkhöz Elyse-nek tudnia kell, hány páratlan vagy páros kártya van a paklijában.

Készíts egy `determineOddEvenCards` függvényt, amely két paramétert kap: egy kártyatömböt (Elyse pakliját) és egy Boolean értéket (a true a „páros”, a false a „páratlan” megfelelője).

Ez a függvény egyetlen számot adjon vissza: a pakliban lévő páratlan vagy páros kártyák számát (attól függően, mit ér a második argumentum).

<!--prettier-ignore -->
~~~exercism/note
Gyakorlásképpen ezúttal `for...of` ciklust használj a függvény megvalósításában.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
