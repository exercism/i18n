# Bevezetés

A C#-ban egy _osztály_hierarchia _öröklődéssel_ definiálható, ami lehetővé teszi, hogy egy leszármaztatott osztály (`Car`) örökölje a szülőosztálya (`Vehicle`) viselkedését és adatait. Ha nincs megadva szülő, az osztály az `object` osztályból örököl.

A szülőosztályok háromféleképpen nyújthatnak funkcionalitást a leszármaztatott osztályoknak:

- Definiálhatnak egy hagyományos metódust.
- Definiálhatnak egy `virtual` metódust, ami olyan, mint egy hagyományos metódus, de a leszármaztatott osztályok _megváltoztathatják_.
- Definiálhatnak egy `abstract` metódust, ami egy implementáció nélküli metódus, amelyet a leszármaztatott osztályoknak _meg kell valósítaniuk_. Egy `abstract` metódusokat tartalmazó osztályt szintén `abstract`-ként kell megjelölni. Az absztrakt osztályok nem példányosíthatók.

A `protected` hozzáférés-módosító lehetővé teszi, hogy egy szülőosztály tagja elérhető legyen egy leszármaztatott osztályban, más osztályokból viszont blokkolja a hozzáférést.

A leszármaztatott osztályok a `base` kulcsszón keresztül érhetik el a szülőosztály tagjait.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

A leszármaztatott osztály konstruktora automatikusan meghívja a szülő konstruktorát, _mielőtt_ lefuttatná a saját konstruktorának logikáját. A szülőosztály konstruktorának a `base` kulcsszóval adhatsz át argumentumokat:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

Amikor egynél több osztály származik egy bázisosztályból, a két (vagy több) osztály gyakran a bázisosztály metódusának különböző változatait valósítja meg. Ez egy nagyon fontos alapelv, amit polimorfizmusnak nevezünk. A fenti példa egy változatában például megmutatjuk, hogyan változtathatja meg a viselkedését a `Vehicle`-t használó kód attól függően, hogy milyen típusú járművet példányosítottak.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
