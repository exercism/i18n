# Bevezetés

A [tömböknek][arrays-concept] beépített metódusaik vannak a tömb tartalmának elemzésére.
Ezek a metódusok többsége argumentumként egy olyan függvényt vár, amely igaz vagy hamis értéket ad vissza.
Az ilyen függvény neve [`predicate`][predicate_in_programming].

A beépített metódusokat _egy `for` ciklus_ vagy a beépített `forEach` metódus helyett érdemes használni:

Példa elemzésre `for` ciklussal:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Példa elemzésre beépített metódussal:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Az alábbiakban néhány további hasznos beépített metódust látsz, amelyekkel egy tömböt elemezhetsz. A tömbmetódusok teljes listáját az [MDN][mdn-array-methods] oldalán találod.

## `includes`

> Az includes() metódus meghatározza, hogy a tömb az elemei között tartalmaz-e egy adott értéket, és attól függően igaz vagy hamis értéket ad vissza. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> Az every() metódus megvizsgálja, hogy a tömb minden eleme átmegy-e a megadott függvény által megvalósított teszten. Boolean értéket ad vissza. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> A some() metódus megvizsgálja, hogy a tömb legalább egy eleme átmegy-e a megadott függvény által megvalósított teszten. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> A find() metódus visszaadja a megadott tömbben annak az első elemnek az értékét, amely megfelel a megadott tesztelő függvénynek. Ha egyetlen érték sem felel meg a tesztelő függvénynek, undefined értéket ad vissza. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> A findIndex() metódus visszaadja annak az első elemnek az indexét a tömbben, amely megfelel a megadott tesztelő függvénynek. Egyébként -1-et ad vissza, ami azt jelzi, hogy egyetlen elem sem ment át a teszten. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
