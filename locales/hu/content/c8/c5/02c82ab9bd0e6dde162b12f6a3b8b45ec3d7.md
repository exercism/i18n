# If, Elseif, Else

Az `if`, `elseif` és `else` kulcsszavakat használó feltételes elágazások a program vezérlésének alapvető részei.
Az `if` elágazás kiértékel egy kifejezést, és ha annak értéke `true`, végrehajtja a megfelelő kódágat.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Ha a kifejezés nem logikai érték, akkor a kiértékelés határozza meg, hogy az érték „igaznak” vagy „nem hamisnak” minősül-e.
PHP-ban a következő értékek számítanak egyenlőnek a false értékkel:

- boolean `false`
- egész szám `0`
- tizedes tört `0.0` és `-0.0`
- üres tömb `[]`
- üres string `""` vagy numerikus string `"0"`
- `null`

Minden más érték igaznak számít.

## Több feltétel kezelése

Egy `if` elágazás után az `elseif` és az `else` segítségével több feltételt is egymás után láncolhatsz.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Csak egyetlen, igaznak értékelt ág fut le.
Ezért ha több feltétel is igaznak értékelődhet, fontos a sorrendjük, ahogy leírod őket.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
