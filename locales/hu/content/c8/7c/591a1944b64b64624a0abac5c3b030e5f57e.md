# Bevezetés

Alapvetően kétféle ciklus létezik:

1. Ismétlés addig, amíg egy feltétel teljesül.
2. Végigiterálás egy gyűjtemény elemein.

Mindkettő lehetséges Juliában, bár a második talán gyakoribb.

## A `while` ciklus

Azokra a nyitott végű problémákra, ahol előre nem tudjuk, hányszor megyünk körbe a cikluson, a Julia a `while` ciklust kínálja.

Az alapforma meglehetősen egyszerű:

```julia
while condition
    do_something()
end
```

Ebben az esetben a program addig járja körbe a ciklust, amíg a `condition` már nem `true`.

Kétféleképpen lehet idő előtt kilépni a ciklusból:

- A `break` hatására a ciklus kilép, és a végrehajtás a ciklus `end` utáni sorban folytatódik.
- A `return x` leállítja az aktuális függvény végrehajtását, és az `x` visszatérési értéket visszaadja a hívónak.

Ezekkel a lehetőségekkel néha kényelmes egy „végtelen” ciklust létrehozni a `while true ... end` segítségével, majd a ciklustörzsben talált leállási feltételre bízni, hogy az kiváltsa a `break` vagy `return` utasítást.

## Ciklus egy gyűjtemény elemein

A legegyszerűbb példa egy tartományon való végigiterálás.

Ha valamit tízszer szeretnénk elvégezni:

```julia
for n in 1:10
    do_something(n)
end
```

Ha az aktuális iteráció nem teljesít valamilyen feltételt, a `continue` segítségével azonnal átugorhatunk a következő iterációra:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

Rövidebb formában az `if` blokk helyettesíthető ezzel: `is_useless(n) && continue`.

Sok más gyűjteménytípuson is végig lehet iterálni: egy tömb elemein, egy string karakterein, egy szótár kulcsain...

Az eddigi példák az `1:10` tartományon iterálnak, ahol az érték egyben a ciklus indexe is.

Általánosabban előfordulhat, hogy nemcsak az értékre, hanem az indexre is szükség van.
Erre az `eachindex()` függvény szolgál, például így: `for i in eachindex(my_array) ... end`.
