# String-metódusok

A `String` osztálynak számos metódusa van, amelyekkel stringeket manipulálhatsz.  
Ezeket a metódusokat magán a stringen hívod meg, és gyakran láncba fűzve több műveletet is végrehajtanak egy stringen.

Az alábbiakban a leggyakoribb metódusok közül sorolunk fel néhányat.
A metódusok teljes listáját a [`String` API-dokumentációban][string-api] találod.

## String#upcase és String#downcase

Az [`upcase`][upcase] metódus egy új stringet ad vissza, amelyben minden karakter nagybetűre van alakítva.

```crystal
"hello".upcase
# => "HELLO"
```

A [`downcase`][downcase] metódus egy új stringet ad vissza, amelyben minden karakter kisbetűre van alakítva.

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub és String#gsub

A Crystalben vannak metódusok egy string részeinek cseréjére.
Ezek a [`sub`][sub] (_helyettesítés_) és a [`gsub`][gsub] (_globális helyettesítés_).

Ezek a metódusok első argumentumként stringet, karaktert vagy regexet, másodikként pedig stringet vagy karaktert fogadhatnak.
Az első argumentum a string azon része, amelyet lecserélünk, a második pedig a csere.
A `Char` típust és a regexeket későbbi fogalmakban magyarázzuk el.

A `sub` metódus az első argumentum első előfordulását cseréli le a második argumentumra.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

A `gsub` metódus ugyanúgy működik, mint a `sub`, de az első argumentum összes előfordulását lecseréli a második argumentumra.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp és String#strip

A chomp és a strip segítségével eltávolíthatod a nem kívánt karaktereket egy stringből.

A [`chomp`][chomp] metódus alapértelmezés szerint a string végéről eltávolítja az utolsó `\r`, `\n` vagy `\r\n` karaktereket.
Ha a metódust argumentummal hívod meg, akkor a megadott értéket távolítja el a string végéről, amennyiben az ott szerepel.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

A [`strip`][strip] metódus alapértelmezés szerint eltávolítja a string elejéről és végéről az összes whitespace karaktert.
Ha a metódust argumentummal hívod meg, akkor azt az argumentumot távolítja el a string elejéről és végéről, amennyiben az ott szerepel.

```crystal
" hello ".strip
# => "hello"
```

## String#index

Az [`index`][index] metódussal megkeresheted egy karakter indexét egy stringben.
Az `index` metódus argumentumként `String`-et, `Char`-t vagy regexet fogad.
Opcionálisan egy második argumentumot is kaphat, amellyel megadhatod, melyik indextől keressen.
Az `index` metódus az argumentum első előfordulásának indexét adja vissza.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

A [`delete_at`][delete_at] metódussal eltávolíthatsz egy karaktert egy stringből.
A `delete_at` metódus argumentumként egy indexet kap, és eltávolítja az adott indexen álló karaktert.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Az [`insert`][insert] metódussal egy adott indexre szúrhatsz be egy stringet.
Az `insert` metódus első argumentumként egy indexet, másodikként egy stringet kap.
Az `insert` metódus egy új stringet ad vissza, amelyben a második argumentum az adott indexre van beszúrva.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
