# Utasítások

Ebben a feladatban néhány függvényt kell megvalósítanod, amelyek egy programozási nyelvekből álló listát kezelnek.

## 1. Definiálj egy függvényt, amely egy üres nyelvlistát ad vissza

Definiáld a `language_list` függvényt, amely nem fogad argumentumot, és egy üres listát ad vissza.

```php
<?php

language_list();
// => []
```

## 2. Módosítsd a függvényt, hogy tetszőleges számú nyelvből listát hozzon létre

Módosítsd a `language_list` függvényt úgy, hogy variadikus argumentumként nyelveket (stringeket) fogadjon.
Adja vissza az így létrejött listát, benne a nyelvekkel.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. Definiálj egy függvényt, amely hozzáad egy nyelvet a listához

Definiáld az `add_to_language_list` függvényt, amely 2 argumentumot fogad: egy nyelvekből álló tömböt és az új nyelvet.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. Definiálj egy függvényt, amely eltávolít egy elemet a nyelvlistából

Definiáld a `prune_language_list` függvényt, amely eltávolítja az első nyelvet a nyelvek tömbjéből.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. Definiálj egy függvényt, amely visszaadja a lista első elemét

Definiáld a `current_language` függvényt, amely 1 argumentumot fogad (egy _nyelvlistát_).
Adja vissza a lista első nyelvét.
Feltételezheted, hogy a listában mindig van legalább egy elem.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. Definiálj egy függvényt, amely visszaadja, hány nyelv van a listában

Definiáld a `language_list_length` függvényt, amely 1 argumentumot fogad (egy _nyelvlistát_).
Adja vissza a listában lévő nyelvek számát.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
