# Utasítások

Josh egy új szerepjátékon dolgozik, és segítségre van szüksége a mechanikák egy részének megvalósításához.

## 1. Definiáld a típusuniókat

Definiálj egy `String` és `Missing` alkotta `StringOrMissing` nevű típusuniót, amelyet a későbbi kódban használhatsz.
Definiálj egy `Int64` és `Nothing` alkotta `IntOrNothing` nevű típusuniót, amelyet a későbbi kódban használhatsz.

## 2. Valósítsd meg a Player összetett típust

A Player összetett típus négy mezőt tartalmaz, és mindegyikhez tartozik típusannotáció és alapértelmezett érték:
- A `name` egy `StringOrMissing`, alapértéke `missing`
- A `level` egy `Int64`, alapértéke `0`
- A `health` egy `Int64`, alapértéke `100`
- A `mana` egy `IntOrNothing`, alapértéke `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. Mutatkozz be

Valósítsd meg az `introduce` függvényt.

Lehet, hogy az alattomos játékosok elrejtik a nevüket, és ilyenkor `"Mighty Magician"` néven mutatkoznak be.
Egyébként egyszerűen a játékos nevével mutasd be őt.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. Valósítsd meg az increment metódusokat

Az `increment` segédfüggvénynek két metódusa van, és mindegyikük függvényszignatúrája más.
Mindegyik argumentumához típusannotáció kell, hogy a szignatúra egyértelmű legyen.

A nevekhez tartozó `increment` metódus egy játékos `name` mezőjét kapja.
- Ha a név `missing`, add vissza a "The Great" címet.
- Egyébként a " the Great" cím kerül a név után.

Ez az `increment` metódus az új nevet adja vissza.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

A manához tartozó `increment` metódus egy játékos `mana` mezőjét kapja.
- Ha a játékos manája `missing`, adj vissza `50` értéket.
- Egyébként a manát `100`-zal kell megnövelni.

Ez az `increment` metódus a frissített manát adja vissza.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. Valósítsd meg a title függvényt

A játékban a legmagasabb szint a `42`.  Hogy elismerjük azoknak a játékosoknak a teljesítményét, akik elérik ezt a szintet, a nevükhöz egy cím kerül.  A `title!` függvény a következőképpen frissíti a játékos nevét.

- Ha a játékos szintje 42, a nevet az `increment` függvénnyel frissítjük.
- Egyébként a név változatlan marad.

Mindkét esetben a `title!` függvény a játékos nevét adja vissza.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. Valósítsd meg a revive függvényt

A `revive!` függvénynek ellenőriznie kell, hogy a játékos karaktere valóban halott-e (az életereje elérte a `0`-t).

Ha a játékos halott:
- A játékost `100` életerővel kell feléleszteni.
- A játékos manáját az `increment` függvénnyel kell megnövelni.

Ha a játékos életben van, nem történik vele semmi

A `revive!` függvény a játékost adja vissza.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
