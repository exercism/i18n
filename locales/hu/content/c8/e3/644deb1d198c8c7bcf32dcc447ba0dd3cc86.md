# Bemutatás

A crate a fordítás egysége Rustban. Egy crate lefordítható binárisba vagy könyvtárba. A legtöbb esetben a `cargo` segítségével kezeled a külső függőségeket. Egy függőség hozzáadása olyan egyszerű is lehet, mint egy sort beírni a `Cargo.toml` fájlodba.

- [A csomagok és a Cargo bemutatása a Rust könyvben](https://doc.rust-lang.org/book/ch07-00-managing-growing-projects-with-packages-crates-and-modules.html)
