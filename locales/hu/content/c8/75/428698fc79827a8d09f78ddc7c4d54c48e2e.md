# Bevezetés

A vektor egydimenziós tömb.
Különböző típusú elemeket is tartalmazhat.

## Vektorok létrehozása

Vektorokat létrehozhatsz a `vector` függvénnyel, de használhatod a `#()` olvasói alakot is.

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## Elemek elérése

Egy vektor elemeihez az `aref` segítségével férhetsz hozzá, az indexelés nullától indul:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
