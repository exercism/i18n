# Bemutatás

Amikor F#-ban számokkal dolgozol, az egyik kulcsfontosságú szempont az egész számok (amelyekben a tizedesjel után nincs számjegy) és a lebegőpontos számok (amelyekben a tizedesjel után nulla vagy több számjegy áll) közötti különbség.

Az F#-ban a leggyakrabban használt két numerikus típus az `int` (32 bites egész szám) és a `float` (64 bites lebegőpontos szám).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

Az egész számok és a lebegőpontos számok egyaránt használhatják a `_` karaktert _számjegy-elválasztóként_, ami nagy számok megadásakor segíthet:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

A számítások a szokásos [aritmetikai operátorokkal][arithmetic-operators] történnek (`+`, `-`, `*` stb.). A számokat a [szokásos összehasonlító operátorokkal][comparison-operators] (`<`, `>=` stb.), valamint az egyenlőség- (`=`) és a nem egyenlőség operátorral (`<>`) lehet összehasonlítani.

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

A numerikus típusok közötti átalakításhoz a beépített [konverziós operátort][conversion-operators] kell használni. Ezek az operátorok arról a típusról kapták a nevüket, amelyre átalakítanak.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

A típusok közötti átalakításnál mindig légy óvatos. Ha egy értéket a célul szolgáló típus nem tud ábrázolni, az érték _túlcsordul_.
