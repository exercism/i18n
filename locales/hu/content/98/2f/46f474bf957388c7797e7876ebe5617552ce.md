# While- és until-ciklusok

A ciklus egy vezérlési szerkezet, amely lehetővé teszi, hogy a kód egy adott feltétel alapján ismételten végrehajtódjon.

## While-ciklusok

A while-ciklus egy vezérlési szerkezet, amely lehetővé teszi, hogy a kód egy adott feltétel alapján ismételten végrehajtódjon.
A while-cikluson belüli kód addig fut, amíg a feltétel igaz értékű.
A while-ciklusokat gyakran akkor használjuk, amikor az iterációk száma előre nem ismert, de bármilyen helyzetben bevethetők, ahol ciklusra van szükség.

A feltételt a cikluson belüli kód végrehajtása előtt értékeljük ki, ami azt jelenti, hogy ha a feltétel hamis, a cikluson belüli kód soha nem fut le.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

Ha egy stringen szeretnél végigmenni, a string hosszán is iterálhatsz.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## Until-ciklusok

Az until-ciklusok ugyanúgy működnek, mint a while-ciklusok, azzal a különbséggel, hogy a cikluson belüli kód addig fut, amíg a feltétel igaz értékű nem lesz.
Ez ugyanaz a különbség, mint az `if` és az `unless` között.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### Végtelen ciklusok

A while-ciklusok gyakori hibája, hogy „végtelen ciklusba” kerül a program, amely soha nem ér véget.
Végtelen ciklust az is okozhat, hogy egy feltétel _soha_ nem értékelődik igaz vagy hamis értékűre.
Ez gyakran programozói hiba következménye, például amikor elfelejtjük léptetni a ciklusváltozót.
Néha azonban a végtelen ciklus a legvilágosabb módja a program logikája megvalósításának.
Sőt, olykor elengedhetetlen a végtelen ismétlés: egy HTTP-szerver például megvárja a bejövő kapcsolatot, kiszolgálja, majd a következő kapcsolatra vár.

## Break

A `break` kulcsszóval idő előtt kiléphetsz egy ciklusból.
Ez kényelmes lehet, ha bizonyos feltételek teljesülése esetén már előbb ki szeretnél lépni a ciklusból.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## Next

A `next` kulcsszóval átugorhatsz a ciklus következő iterációjára.
Ez kényelmes lehet, ha bizonyos iterációkat ki szeretnél hagyni.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## Típusok ciklus közben

Ciklus közben a változó típusa eltérő lehet.
A következő példában az `a` típusa `Int32 | String`, mert a ciklus első részében `Int32` és `String` is lehet.
Az `a` változó csak a ciklus első részében viseli az `Int32 | String` típust, mivel a ciklus indulásakor `Int32`-t tartalmaz, a második iterációban pedig egy `String`-et.
Ezt a többtípusos rendszert később részletesen elmagyarázzuk.
Mivel azonban biztosak vagyunk benne, hogy a ciklus második része csak `String`-et tartalmaz, a ciklus második részében az `a` típusa `String`.
Futásidőben soha nem tartalmaz egyszerre `Int32`-t és `String`-et.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
