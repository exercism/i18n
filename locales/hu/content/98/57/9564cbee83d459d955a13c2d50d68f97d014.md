# Tippek

## 1. A jóváhagyás definiálása

- Egyedi típusokat a `pub type Name { Variant1 }` szintaxissal definiálhatsz.

## 4. A tevékenység definiálása

- Adatot tartalmazó egyedi típusokat a `pub type Name { Variant1(SomeType) }` szintaxissal definiálhatsz.

## 5. A tevékenység értékelése

- Az egyedi típusváltozatokra case-kifejezésekkel illeszthetsz mintát.
- Ha egy mintához további feltételt szeretnél adni, az `if` kulcsszóval őrt rendelhetsz hozzá.
