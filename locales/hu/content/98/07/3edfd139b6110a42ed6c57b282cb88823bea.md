# Bevezetés

A hash a Perl egyik adattípusa: rendezetlen gyűjtemény, amelyben string kulcsokhoz skaláris értékek tartoznak.

Egy hash változót általában úgy hozol létre, hogy hozzárendelsz egy listát, például: `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

A listák elemeit általában vesszővel választjuk el, de gyakran találkozhatsz az úgynevezett „kövér vesszővel” (`=>`), amellyel a kulcsokat és az értékeket választjuk el egymástól egy listában.
A viselkedése majdnem ugyanaz, mint a vesszőé, de van egy plusz előnye: a bal oldali elemet stringként értelmezi.

A hash-t feltöltheted úgy is, hogy az egyes kulcsokhoz közvetlenül rendelsz értéket, például: `$scores{Alice} = 10;`.

Egy hash értékeit úgy érheted el, hogy a kulcsokat indexként megadod, például: `$scores{Bob} # 15`.

A kulcsok egy hash-en belül egyediek.
Ha egy kulcs többször szerepel, csak az utoljára megadott érték marad meg.

## Függvények

A hash-ekkel dolgozó függvények közé tartozik a [keys][keys] és a [values][values], amelyekkel a hash megfelelő részeit kérheted le listaként.
A [keys][keys] és a [values][values] függvény által visszaadott listák hasznosak lehetnek listafüggvényekhez, például a [grep][grep], a [map][map] és a [sort][sort] esetében, valamint a [for][for] ciklusokban.

További hash-függvények az [exists][exists], amellyel ellenőrizheted, hogy létezik-e egy kulcs a hash-ben (akkor is, ha az értéke `undef`), és a [delete][delete], amellyel eltávolíthatsz egy kulcsot a hash-ből.

## A sigilek eltérései

Amikor egy hash értékeit kéred le, a használt sigil dönti el az eredményt.
A változónév végén álló `{}` index jelzi a Perlnek, hogy az adott nevű hash elemeit éred el.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Bár megengedett, az olvashatóság érdekében érdemes elkerülni, hogy a különböző változótípusok ugyanazt a nevet viseljék.
