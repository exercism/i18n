# Kiegészítés az utasításokhoz

## Szavak

A `classify ( n -- str )` a következő stringek egyikét adja vissza: `"perfect"`,
`"abundant"` vagy `"deficient"`.

## Hibák

Ha a bemenet nulla vagy negatív, a következő stringet kell dobni:

```
"Classification is only possible for positive integers."
```

(szó szerint, a záró pontot is beleértve).
