# Utasítások

Ebben a feladatban egy 2012. szeptember 15-én megnyílt New York-i szépségszalon időpont-ütemezőjén fogsz dolgozni.

## 1. Időpont dátumának értelmezése

Valósítsd meg az `AppointmentScheduler.schedule()` metódust, amely egy időpont szöveges reprezentációját a megfelelő `LocalDateTime` értékké alakítja:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. Ellenőrizd, hogy egy időpont már elmúlt-e

Valósítsd meg az `AppointmentScheduler.hasPassed()` metódust, amely egy időpontot vár, és ellenőrzi, hogy az időpont valamikor a múltban volt-e:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. Ellenőrizd, hogy az időpont délutánra esik-e

Valósítsd meg az `AppointmentScheduler.isAfternoonAppointment()` metódust, amely egy időpontot vár, és ellenőrzi, hogy az időpont délutánra esik-e (>= 12:00 és < 18:00):

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Írd le az időpont idejét és dátumát

Valósítsd meg az `AppointmentScheduler.getDescription()` metódust, amely egy időpontot vár, és visszaad egy leírást annak dátumáról és idejéről:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. Add vissza az évforduló dátumát

Valósítsd meg az `AppointmentScheduler.getAnniversaryDate()` metódust, amely az idei évforduló dátumát adja vissza, ami szeptember 15-e:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
