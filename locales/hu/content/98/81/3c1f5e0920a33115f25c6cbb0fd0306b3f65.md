# Kiegészítés az utasításokhoz

## Szavak

Definiálj egy `custom-set` tuple-t, és az `INSTANCE: custom-set set` deklarációval
jelentsd ki, hogy a `set` mixin egy példánya.

- `<custom-set> ( -- set )` létrehoz egy üres halmazt.
- `>custom-set ( seq -- set )` halmazt épít egy sorozatból, a duplikátumokat
  csendben elhagyva.

Ezután adj meg `M:` metódusokat (a `sets` szótárból) a `custom-set` típus
`members`, `in?`, `adjoin` és `set-like` szavaihoz. Ha az `INSTANCE:`
deklaráció és ez a négy metódus a helyén van, akkor a `sets` szótár
`null?`, `union`, `intersect`, `diff`, `subset?`, `set=` és `intersects?`
szava mind működik a halmazodon a protokoll alapértelmezett
implementációin keresztül. A tesztek közvetlenül ezeket a szavakat hívják.

Az `adjoin ( elt set -- )` mutáló: ha az `elt` még nincs benne, helyben
hozzáadja a `set`-hez.
