# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít felkészülni egy jármű megvásárlására.

Három részfeladat vár rád: az egyikben meghatározod, hogy szükséged lesz-e jogosítványra, a másikban két jármű közül választasz, a harmadikban pedig megbecsülöd egy használt jármű elfogadható árát.

## 1. Állapítsd meg, hogy szükséged lesz-e jogosítványra

Egyes járműtípusok vezetéséhez jogosítvány kell.
Tegyük fel, hogy csak a `"car"` és a `"truck"` típushoz kell jogosítvány, minden mást jogosítvány nélkül is vezetni lehet.

Valósítsd meg a `needsLicense(kind)` függvényt, amely a jármű típusát kapja, és egy boolean értékkel jelzi, hogy kell-e jogosítvány az adott típusú járműhöz.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. Válassz két szóba jöhető jármű közül

Mérlegeled a rendelkezésre álló járműveket.
Sikerül két lehetőségre szűkítened a kört, de segítségre van szükséged a végső döntéshez.
Ehhez valósítsd meg a `chooseVehicle(option1, option2)` függvényt, amely két járművet kap argumentumként, és egy döntést ad vissza, amely tartalmazza az [lexikográfiai sorrend][lexicographical-order] szerint elsőként szereplő lehetőséget.

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Becsüld meg egy használt jármű árát

Most, hogy meghoztad a döntést, szeretnél biztos lenni benne, hogy tisztességes árat kapsz a kereskedésben.
Mivel használt járművet szeretnél venni, az ár attól függ, milyen idős a jármű.
Durva becslésként tételezzük fel, hogy ha a jármű kevesebb mint 3 éves, az eredeti, vadonatúj kori árának 80%-ába kerül.
Ha legalább 10 éves, akkor 50%-ába.
Ha a jármű legalább 3 éves, de kevesebb mint 10 éves, az eredeti ár 70%-ába kerül.

Valósítsd meg a `calculateResellPrice(originalPrice, age)` függvényt, amely ezt a logikát `if`, `else if` és `else` segítségével alkalmazza (más megoldások is vannak, ha gyakorolni szeretnél).
Az eredeti árat és a jármű korát kapja argumentumként, és a kereskedésben becsült árat adja vissza.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
