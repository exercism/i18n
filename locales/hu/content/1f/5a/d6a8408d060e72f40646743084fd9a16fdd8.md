# Null

A null egy primitív értéktípus, amelynek egyetlen értéke van: `null`.
A nullt gyakran a semmi kifejezésére használjuk.
A null „falsey” értéknek számít, de különbözik a `false` értéktől és más falsey értékektől.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Null értékek kezelése

A PHP-ban a null értékek gyakori hibaforrást jelenthetnek, mert gyakran hibaállapot helyett vagy a semmi kifejezésére adják vissza őket.
A hibák megelőzéséhez gyakran „null-ellenőrzést” kell végezni, hogy mielőtt bármit tennénk az értékkel, megbizonyosodjunk róla, hogy az nem null.

Az ismételt null-ellenőrzés viszont könnyen hibához vezethet, ezért a PHP két operátort kínál a null értékek kezelésére: a null-biztos elérést végző `?->` operátort és a null-összevonó `??` operátort.
