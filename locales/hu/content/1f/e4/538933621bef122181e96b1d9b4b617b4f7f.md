# Bevezetés

## Szótárak

A szótár olyan elemek gyűjteménye, amelyben minden elem egy kulcsból és egy értékből áll, úgy, hogy ha egy kulcsot átadunk a szótár valamelyik metódusának, akkor a hozzá tartozó értéket adja vissza. Ugyanaz a szerepe, mint más nyelvekben a map-eknek vagy az asszociatív tömböknek.

A szótár a következőképpen hozható létre:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Vagy

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Figyeld meg, hogy a kulcs- és értéktípusok a szótár definíciójának részét képezik.

Létrehozás után a szótár bejegyzéseit hozzáadhatod vagy eltávolíthatod a beépített `Add` és `Remove` metódusaival.

A szótárban lévő értékek lekérése vagy frissítése úgy történik, hogy a szótárt egy kulccsal indexeljük:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

A következővel tesztelheted, hogy létezik-e egy kulcs a szótárban:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

A szótár bejárása a kulcs/érték párjain megy végig. A szótáraknak vannak olyan tulajdonságaik is, amelyekkel a kulcsain vagy az értékein is végigmehetsz.
