# Bevezetés

Az SQL-ben a `SELECT` utasítással adatokat kérdezhetsz le egy adatbázisból.
A `SELECT` utasítás eredménye egy eredményhalmaz.
Az eredményhalmaz sorokba és oszlopokba rendezett értékeket tartalmaz.
Minden oszlop az adatok egy-egy tulajdonsága.
Minden sor minden oszlophoz tartalmaz egy értéket.

Gondolhatsz úgy is rá, hogy az oszlopok összessége egy adatszerkezetet ír le: minden oszlop az adatszerkezet egy-egy mezője, minden sor pedig az adatszerkezet egy példánya.

A `SELECT` utasítással megadhatod, milyen adatokat szeretnél lekérdezni.
Emellett tetszés szerint átalakíthatod, szűrheted és/vagy módosíthatod a kimeneti adatok alakját.

## Az alapok

Egy egyszerű `SELECT` utasítás felépítése a következő:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
A `FROM` és a `WHERE` záradék elhagyható.
Teljesen érvényes például egy ilyen utasítás: `SELECT "Hello, world.";`.

Az sem kötelező, hogy sort törj: a `SELECT` utasítás egyes záradékait (vagyis részeit) bármilyen szóköz elválasztja.
~~~~

A `SELECT` kulcsszót közvetlenül azoknak az oszlopoknak a listája követi, amelyeket az eredményben szeretnél látni.
A `FROM` záradék jelöli meg az adatok forrását, ami jellemzően egy tábla az adatbázisban.
A `WHERE` záradék egy vagy több feltétel alapján szűri a kimeneti adatokat.

## Adatok szűrése a `WHERE` záradékkal

A `WHERE` záradékkal szűrheted a `SELECT` utasítással lekérdezett adatokat.
Ha például csak az Appliances kategóriájú termékeket szeretnénk, ezt írhatjuk:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

Eredmény:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

Vagy ha csak azokat az adatokat szeretnénk, amelyeknél a weight értéke 2.0 és 6.0 közé esik:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

Eredmény:
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```

A `=` és a `BETWEEN...AND` mellett a `WHERE` záradék sokféle kifejezést támogat, például az összehasonlítást (`<`, `<=`, `>`, `>=`), a mintára illesztést (`LIKE`, `GLOB`, `REGEXP`, `MATCH`), valamint annak ellenőrzését, hogy egy érték szerepel-e egy listában (`IN`, `NOT IN`).
A teljes dokumentációt az [SQL nyelvi kifejezések](sql-expr) oldalon találod.
