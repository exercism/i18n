# Tippek

## Általános

- Böngészd a [_string modul_ban elérhető függvényeket][string-module-functions], hogy felfedezd, milyen stringműveleteket kínál a Gleam standard könyvtára.

## 1. Szerezd meg a név első betűjét

- Van egy [függvény][string-first], amivel egy string első karakterét kérheted le.
- Több [függvény][string-trim] is van, amivel egy string elejéről, végéről, illetve mindkettőről eltávolíthatod a szóközöket.

## 2. Alakítsd az első betűt monogrammá

- Van egy [függvény][string-upcase], ami egy string összes karakterét nagybetűssé alakítja.
- A `<>` operátorral stringeket fűzhetsz össze.

## 3. Bontsd fel a teljes nevet keresztnévre és vezetéknévre

- Van egy [függvény][string-split], ami whitespace-karakterekre bontja fel a stringet.
- A lista első néhány elemét mintaillesztéssel rendelheted változókhoz.

## 4. Tedd a monogramot a szívbe

- A `<>` operátorral stringeket fűzhetsz össze.
