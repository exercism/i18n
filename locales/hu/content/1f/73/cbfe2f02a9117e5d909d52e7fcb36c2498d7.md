# Részletesen

A `while` és az `until` (a [`kernel`][kernel] modulban) quotation-vezérelt cikluskombinátorok arra az esetre, amikor előre nem ismered az iterációk számát:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

A `while` addig folytatja, amíg a `pred` igaz értéket hagy a vermen; az `until` addig folytatja, amíg a `pred` `f`-et hagy a vermen. Mindkettő leáll és visszatér, amikor a predikátuma átbillen.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

Amikor a vermen áramló egyetlen érték nem ad elég állapotot (mondjuk egyszerre egy hátralévő lista, egy futó összeg és egy számláló), a legtisztább minta az, ha az áttekinthetőség kedvéért nevesített *locals*-t használsz. A localsokat a tananyag későbbi részében mutatjuk be részletesebben; itt elég annyit tudnod, hogy a `:: word ( a b -- c )` a bemeneteit nevesített localsként deklarálja, a `:> name!` pedig hozzáad egy módosítható localt, amelyet a törzs a `value name!` kifejezéssel frissíthet.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```
