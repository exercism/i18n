# A Haskell szintaxis alapjai

## Konstansok és függvények

A Haskell-programok definíciókból és kifejezésekből épülnek fel.

Egy konstans értéket `name = expression` formában definiálunk.

```haskell
five = 5

six = 3 + 3
```

A függvényeket `name parameters... = expression` formában definiáljuk, a paramétereket pedig csak szóköz választja el egymástól.

```haskell
add number1 number2 = number1 + number2
```

Egy függvény meghívása is kifejezés, és úgy történik, hogy megadjuk a függvény nevét, majd minden paraméteréhez átadunk egy-egy argumentumot, szóközzel elválasztva, ahogy a függvénydefinícióknál is.

```haskell
five = add 2 3
```

Zárójelekkel megadhatjuk egy kifejezés kiértékelési sorrendjét.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Behúzás / jelentéssel bíró szóközök

A Haskell a szóközöket és a behúzást használja a kódrészek határainak megjelölésére.
***Az olyan kódot, amely valamely kifejezés része, beljebb kell húzni, mint a kifejezés kezdetét.***

- A modul-, az import- és a legfelső szintű függvénydefinícióknak a bal szélső oszlopban kell kezdődniük.
- Ha egy kifejezés több sorra bomlik, a kifejezés részét képező kódot legalább egy szóközzel beljebb kell húzni a kifejezés alatt.
- A kifejezés azon részeit, amelyek összetartoznak, ugyanannyi szóközzel érdemes behúzni.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## Modulok

A modulok függvényeket exportálnak.
Ez azt jelenti, hogy használhatod azokat a függvényeket, amelyeket a modul az export utasításában elérhetővé tesz.
Egy modul definiálhat függvényeket kizárólag belső használatra is.
Alapértelmezés szerint azokat a függvényeket, amelyeket nem exportálsz kifejezetten, nem lehet a modulon kívülről használni.

A modul elején megadjuk a modul nevét.
Ha van egy Calculator.hs nevű fájlunk, akkor a modulunk neve is Calculator legyen.
Ezután megadjuk, hogy mely függvényeket exportálja, és ezután kezdhetjük el írni a függvényeket.
Kezdjük tehát ezzel.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Kommentek

A komment olyan szöveg a Haskell-fájlban, amit nem kódként értelmezünk.
Elsősorban arra szolgál, hogy te és a többi programozó elolvassa.
Az egysoros kommentekhez van egy egyszerű szintaxis, amely két kötőjelen alapul.
Többsoros kommentekre is van lehetőség a `{-` és `-}` nyitó és záró elhatároló pár segítségével.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
