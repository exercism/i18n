# százalékos vagy „régi stílusú” formázás

Ez a megoldás `%%-formatting`-et vagy [régi stílusú formázást][old-style formatting] használ stringek formázásához.

Bár a `%%-formatting` teljesen érvényes megközelítés, reprezentációs vagy olvashatósági problémákat okozhat.
A [str.format()][str.format()] metódus vagy az [f-strings][f-strings] (_más néven „formázott stringliterálok” vagy „interpolált stringek”_) használata olyan lehetőségeket kínálhat, amelyek javítják az olvashatóságot, és világosabbá teszik a stringeken belüli változócserét.

A [String Formatting in Python][string formatting in python] blogbejegyzés jó kiindulópont ahhoz, hogy megértsd a Python összes stringformázási lehetőségét, és a [Newer Python String Format Techniques][newer python string format techniques] is jó tippeket és trükköket kínál a `str.format()` és az `f-strings` használatához.
