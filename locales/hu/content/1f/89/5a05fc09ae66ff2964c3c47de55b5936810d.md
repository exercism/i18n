# Források

## Így készítsd el az első Coffee-modulodat

Ahhoz, hogy létrehozz egy modult, amelyet a `Bob = require './bob'` sorral tudsz betölteni, írd ezt a kódot a `bob.coffee` fájlba:

```coffeescript
class Bob

module.exports = Bob
```

A modulokról bővebb információt a [Node dokumentációjában](http://nodejs.org/api/modules.html#modules_module_exports) találsz.

## Visual Studio Windowson

Ha rendelkezel a Visual Studio fizetős verziójával, letölthetsz egy olyan Visual Studio-megoldást, amely már be van állítva a CoffeeScripthez és a Visual Studio által támogatott többi nyelvhez.

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. Töltsd le a GitHubról az [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) sablont úgy, hogy az oldalon a Download Zip gombra kattintasz.
2. Csomagold ki a sablont a feladataid könyvtárába, például a `C:\src\exercises` mappába.
2. Telepítsd az [Exercism CLI](http://exercism.io/cli)-t.
3. Nyiss egy parancssort a feladatod könyvtárában.
4. Add hozzá az API-kulcsodat az exercismhez: `exercism configure --key=YOUR_API_KEY`
5. Állítsd be a forráskönyvtáradat az exercismben: `exercism configure --dir=C:\src\exercises`
6. [Töltsd le az első feladatodat](http://exercism.io/languages/coffeescript): `exercism fetch coffeescript`
7. Nyisd meg az Exercism-megoldást a Visual Studióban.
8. Bontsd ki az Exercism.coffeescript projektet.
9. Kattints a **Show All Files** elemre a Solution Explorer nézetben (lásd lent).
10. A feladat, amelyet épp letöltöttél, szürkén fog megjelenni. Kattints jobb gombbal a mappára, és válaszd az **Include In Project** lehetőséget.
11. Kezdj el kódolni...

![Add files](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Ahhoz, hogy a Visual Studióban CoffeeScripttel dolgozhass, telepítened kell a [Web Essentials](http://vswebessentials.com/) bővítményt. Ez a JavaScripttel való munkát is sokkal könnyebbé teszi.

A unit teszteket a projektben található batch-fájllal futtathatod egy node.js parancssorból.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

Ha a tesztek futtatásakor nem látsz semmilyen kimenetet, valószínűleg nem egy Node.js parancssorban vagy.
