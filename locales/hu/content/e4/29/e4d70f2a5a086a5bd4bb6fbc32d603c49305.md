# Bevezetés

## Összehasonlítás

JavaScriptben a számokat a következő relációs és egyenlőségoperátorokkal lehet összehasonlítani.

| Összehasonlítás          | Operátor  |
| ------------------------ | --------- |
| Nagyobb, mint            | `a > b`   |
| Nagyobb vagy egyenlő     | `a >= b`  |
| Kisebb, mint             | `a < b`   |
| Kisebb vagy egyenlő      | `a <= b`  |
| (Szigorú) egyenlőség     | `a === b` |
| Nem (szigorú) egyenlőség | `a !== b` |

Az összehasonlítás eredménye mindig egy Boolean érték: `true` vagy `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

JavaScriptben a fenti összehasonlító operátorok stringek összehasonlítására is használhatók.
Ilyenkor egy szótári (lexikografikus) sorrend érvényesül.
Az összes karakter pontos sorrendjének listáját [itt][utf-16-list] találod.

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Feltételes elágazások

A logika feltételes végrehajtásának gyakori módja JavaScriptben az `if` elágazás.
Az `if` kulcsszóból, egy kerek zárójelbe zárt feltételből és egy kapcsos zárójelbe zárt kódblokkból áll.
A kódblokk csak akkor fut le, ha a feltétel `true` értékre értékelődik ki.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Használható önmagában, vagy összekapcsolható az `else` kulcsszóval.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Ha további feltételt szeretnél az `else` ágba ágyazni, használhatod az `else if` szerkezetet.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
