# Névjegy

A `case` a Factor egyenlőségalapú többirányú elágazása. Akkor a megfelelő eszköz, ha a választás egy *egyetlen* érték és a több alternatíva valamelyikének egyenlőségétől függ, nem pedig akkor, ha minden ág külön tesztet igényel (erre használd a `cond`-ot).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Néhány dolog, amit érdemes szem előtt tartani:

- Az egyenlőség jele a `=`. Bármi lehet kulcs, amire a `=` működik: számok, stringek, karakterek, szimbólumok, sőt tuple-ök is.
- Az *egyező* ágak a vermet *a bemeneti érték nélkül* látják. Az *alapértelmezett* ágak viszont úgy látják, hogy az még mindig a verem tetején van.
- Az olyan `case`, amelynél nincs alapértelmezett ág és nincs egyező ág sem, hibát dob.

A `case` ahol lehet, ugrótáblává fordul, így nem csupán egy `if`-lánc szintaktikai cukra, hanem gyors is.
