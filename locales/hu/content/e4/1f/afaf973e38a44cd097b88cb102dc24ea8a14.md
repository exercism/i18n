# For ciklusok

A ciklusok a programozás egyik alapvető fogalma: segítségükkel egy kódrészletet többször is végrehajthatsz.
A Swiftben kétféle ciklus létezik: a [`for-in` ciklusok][for-loops] és a `while` ciklusok.
Ebben a fejezetben a `for-in` ciklusokkal ismerkedhetsz meg.

A for ciklusokkal értékek egy sorozatán iterálhatsz: sorra veszed az egyes elemeket, és egy általad választott változóhoz kötöd őket.
A Swiftben sokféle sorozaton iterálhatsz, például tartományokon, tömbökön és stringeken (valamint további típusokon, amelyekről később lesz szó).
Amikor a sorozat minden elemén végigmentél, a ciklus kilép.

A for ciklust a `for` kulcsszóval hozod létre, utána egy változónév, majd az `in` kulcsszó és egy sorozat következik, amelyen iterálni szeretnél.
A `for-in` ciklusban megadott változó nem módosítható, vagyis az értékét a cikluson belül nem változtathatod meg.
Íme egy példa egy `for-in` ciklusra, amely számok egy tömbjén iterál:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
A `number` változót a `for-in` ciklusban hozod létre, és csak a ciklus scope-ján belül érhető el.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Iterálás egy tartományon

Egy számtartományon is iterálhatsz `for-in` ciklussal.
Így egy kódrészletet meghatározott számú alkalommal hajthatsz végre. A `1...5` tartomány például az 1, 2, 3, 4 és 5 számokon iterál, tehát a ciklus ötször fut le.
Néha egy adatszerkezet, például egy tömb indexein szeretnél iterálni; ilyenkor a `0..<array.count` tartományt használhatod.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Iterálás stringen

Egy stringen is iterálhatsz `for-in` ciklussal.
Így a string minden karakterén végigmehetsz. Figyeld meg, hogy a ciklusban megadott érték típusa `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

A Swift egy `stride` függvényt is biztosít, amellyel egy adott lépésközű sorozatot hozhatsz létre egy tartomány fölött.
Ezen aztán egy `for-in` ciklussal iterálhatsz.
A `stride` két formában érhető el: [`stride(from:to:by:)`][stride-to] és [`stride(from:through:by:)`][stride-through]. Az első nem foglalja magában a végértéket, a második viszont igen.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Figyeld meg, hogy a `to` paraméter nem tartalmazza a végértéket, ezért a ciklus a `to` paraméter előtti számig iterál, a `through` paraméter viszont tartalmazza, így ebben az esetben a `10` is belekerül.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
