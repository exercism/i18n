# Bevezetés

A Pythonban a [tuple][tuple] egy _megváltoztathatatlan_, _sorrendben_ tárolt elemekből álló gyűjtemény.
A legtöbb gyűjteményhez hasonlóan a `tuples` bármilyen (vagy többféle) adattípust tárolhat, más `tuples`-öket is beleértve.
A `tuples` minden [általános sorozatműveletet][common sequence operations] támogat, a [módosítható sorozatműveleteket][mutable sequence operations] viszont **nem**.

A tuple elemein a `for item in <tuple>` szerkezettel lehet végigiterálni.
Ha az elem indexére és értékére is szükség van, a `for index, item in enumerate(<tuple>)` használható.
Mint minden sorozatnál, a `tuples` elemei _zárójeles jelöléssel_ érhetők el, balról egy `0-based index` számmal vagy jobbról egy `-1-based index` számmal.
A tuple-ök egészben vagy részben szeletjelöléssel (_`<tuple>[<start>:<stop>:<step>]`_) is másolhatók.


## Tuple létrehozása

A tuple-ök többféleképpen létrehozhatók: a `tuple(<iterable>)` osztálykonstruktorral vagy a `tuple` literál deklarációval.

### A `tuple()` konstruktor használata üresen vagy _iterálható_ argumentummal:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

A stringek iterálhatók, ezért ha egyetlen `str`-t adsz a `tuple()` konstruktor argumentumaként, az meglepő eredményeket hozhat:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

Egyetlen iterálható elem esetén az elemek egyenként adódnak hozzá:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### Tuple deklarálása _literálként_:

Mivel a `tuple(<iterable>)` konstruktor csak _iterálhatókat_ (vagy semmit) fogad el argumentumként, sokkal egyszerűbb egy egyelemű tuple-t a literál módszerrel létrehozni.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

Egymásba ágyazott adatszerkezetek is szerepelhetnek `tuple` elemekként, beleértve a többi `tuples`-t is:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## Tuple-ök összefűzése

A tuple-ök összefűzhetők a plusz `+` operátorral, amely kibontja az egyes `tuple`-öket, és létrehoz egy új, egyesített `tuple`-t.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## Elemek elérése egy tuple-ben

Egy `tuple` elemei _zárójeles jelöléssel_ érhetők el, balról egy `0-based index` számmal vagy jobbról egy `-1-based index` számmal.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## Végigiterálás egy tuple elemein

Egy `tuple` elemein ciklusban a `for item in <tuple>` szintaxissal lehet _végigiterálni_.
Ha az indexekre és az értékekre is szükség van, a `for index, item in enumerate(<tuple>)` használható.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## Tagság ellenőrzése egy tuple-ben

Az `in` operátorral ellenőrizhető, hogy egy elem benne van-e egy `tuple`-ben.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
