# Bevezetés

A Kotlin egy **statikusan típusos** programozási nyelv, amelyet a JetBrains fejlesztett ki. Ez azt jelenti, hogy a változók típusa már fordítási időben meghatározódik.

## Változók

A többi statikusan típusos programozási nyelvhez hasonlóan minden változó típusát a fordítási időben kell megadni. Ahol a fordító a kontextusból ki tudja következtetni a típust, ott elhagyhatod a kifejezett típusmegadást.

A Kotlinban vannak módosíthatatlan (`val`) és módosítható (`var`) változók. Egy módosíthatatlan változó értékét nem lehet megváltoztatni, miután megkapta a kezdőértékét. Az esetek többségében ezt a fajta változót fogod használni.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

Egy módosítható változó értékét akár többször is megváltoztathatod:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

A pontosvesszők a Kotlinban elhagyhatók, néhány különleges esettől eltekintve, amelyekre később térünk ki.

## Függvények

A függvényeket a Kotlinban a `fun` kulcsszóval definiálod, és _első osztályú állampolgárok_ (nem kapcsolódik az OOP-hoz). Ez azt jelenti, hogy közvetlenül a fájlokban is deklarálhatod őket (ezek az úgynevezett `top-level functions`). Javában például metódusokat kizárólag osztályokban definiálhatsz, fájlokban nem:

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

A függvények fogadhatnak argumentumokat. Minden argumentumnak van neve és típusa. A változókkal ellentétben az argumentumok típusát nem lehet kikövetkeztetni. Egy függvénynek nulla vagy több argumentuma is lehet:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

A Kotlin-függvények vagy visszaadnak egy értéket, vagy nem:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

Egy értéket a `return` kulcsszóval adhatsz vissza egy függvényből:

```kotlin
fun getName(): String {
    return "Alice"
}
```

A függvényeknek lehetnek alapértelmezett értékű paramétereik. Ezeket az értékeket a függvény akkor használja, ha a meghívásakor nem adod meg őket:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## Megjegyzések

Egy egysoros megjegyzést a `//` jelöléssel hozhatsz létre:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

többsoros megjegyzést pedig a `/*` és a `*/` jelöléssel:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
