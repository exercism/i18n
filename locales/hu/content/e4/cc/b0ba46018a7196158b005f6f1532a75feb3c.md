# Utasítások

Ebben a feladatban egy táblagyártó cégnek írsz kódot, hogy egyedi üzeneteket készíthessen a tábláira.

## 1. Készíts alkalmi táblát

Valósítsd meg a `buildSign(occasion, name)` függvényt, amely az `occasion` paraméterként egy stringet fogad, a `name` paraméterként pedig egy nevet tartalmazó stringet.
A két paraméter egy template stringbe kerül, és ez adja ki a táblán látható üzenetet.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Készíts születésnapi táblát

Valósítsd meg a `buildBirthdaySign(age)` függvényt, amely egy életkort fogad, és az életkor alapján eldönti a táblán lévő üzenet egy részét.
Ha az életkor 50 vagy több, a tábla _érettként_ szólítja meg a felhasználót, egyébként _fiatal_ként.
A pontosan elvárt kimenet alább látható:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Készíts ballagási táblát

Valósítsd meg a `graduationFor(name, year)` függvényt, amely egy nevet fogad string paraméterként, egy évet pedig szám paraméterként, és string-interpolációval hozza létre a táblára szánt szöveget, amelyben egy sortörés választja el az üzenet két sorát.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Számítsd ki egy tábla árát

Valósítsd meg a `costOf(sign, currency)` függvényt, amely egy stringet fogad, ami a tábla tartalmát tartalmazza, és egy stringet, ami a pénznemet jelöli.
A tábla alapára 20 a megadott pénznemben. Ezenkívül minden betű után 2-t számítunk fel. (A szóközök is beleszámítanak a számításba.)
A visszaadott szöveg tartalmazza a tábla elkészítésének költségét két tizedesjeggyel, majd utána a pénznem stringjét.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
