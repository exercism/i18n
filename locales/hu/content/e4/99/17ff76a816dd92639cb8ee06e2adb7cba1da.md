# Bevezetés

A tömbök a Factor fix hosszúságú sorozatai: az elemeiket módosíthatod, de a hosszukat nem. Azt már tudod, hogyan kell felírni egy tömbliterált (`{ … }`), és hogyan kell egy tömböt felszeletelni és aggregálni. Ez a feladat azt a kis eszközkészletet mutatja be, amire akkor van szükség, amikor a verem értékeiből tömböt építesz, majd megkeresed vagy átrendezed a tartalmát.

## Építés a veremből

Az `1array`, `2array`, `3array` és `4array` (a [`arrays`][arrays] szótárban) 1, 2, 3 vagy 4 értéket vesz le a verem tetejéről, és egy tömbbé fogja össze őket:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## Összefűzés

A `concat` (a [`sequences`][sequences] szótárban) egy olyan sorozatot vesz, amelynek elemei maguk is sorozatok, és egy szinttel kilapítja őket. A `join` ugyanezt teszi, de minden pár közé egy elválasztót szúr be:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## Megfordítás

A `reverse` egy új sorozatot ad vissza, amelyben az elemek fordított sorrendben szerepelnek:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## Tömb-e?

Az `array?` (a [`arrays`][arrays] szótárban) a típuspredikátum. Igaz minden olyan értékre, amelyet a `<array>`, az `1array`/`2array`/... vagy egy `{ … }` tömbliterál hozott létre, és hamis minden másra (beleértve a vektorokat, a stringeket és a többi sorozatot):

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## Keresés

Az `index` annak az első elemnek a pozícióját adja vissza, amely megegyezik a bemeneti értékkel, vagy `f`-et, ha nincs ilyen. A `member?` csak egy Boolean értéket ad vissza. Mindkettő az **elemet várja először**, a **sorozatot pedig másodszor**. A `members` (a [`sets`][sets] szótárban) egy sorozat *egyedi* elemeit adja vissza (ez a deduplikációs művelet), az `all-unique?` (szintén a `sets` szótárban) pedig azt vizsgálja, hogy a sorozatban már nincsenek-e ismétlődések:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
