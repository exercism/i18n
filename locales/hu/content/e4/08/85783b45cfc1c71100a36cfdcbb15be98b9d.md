# Az egyedi típusokról

Az új adattípusokat Gleamben egyedi típusokkal definiáljuk. Egy egyedi típusnak több _változata_ is lehet, és mindegyiknek saját neve van.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Egy egyedi típus minden változata opcionálisan tárolhat adatot, és a különböző változatok különböző típusú adatokat tárolhatnak. Amikor egy változat adatot tárol, azt _rekordnak_ nevezzük.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Egy adott változathoz tartozó értéket úgy hozhatunk létre, hogy a nevére hivatkozunk, ha nem tartalmaz további adatot (`Spring`), vagy függvényként hívjuk meg, ha igen (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Az egyedi típusok Gleamben mindennel együtt _strukturális egyenlőséggel_ bírnak, ami azt jelenti, hogy két érték, amelyek ugyanahhoz a változathoz tartoznak és ugyanazt az adatot tárolják, egyenértékű.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Az egyedi típusok változataira case kifejezésekkel illeszthetünk mintát.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
