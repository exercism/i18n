# Részletek

## Összehasonlító operátorok

Az [összehasonlító operátorok][comparison-operators] értékek összehasonlítására szolgálnak, és `true` vagy `false` értéket adnak vissza.
Ezek az operátorok két, azonos típusú értéket várnak összehasonlításra.
Ha az értékek nem azonos típusúak, a fordító hibát dob.
Íme az összehasonlító operátorok listája, és egy-egy példa arra, mikor adnak `true` értéket:

| Operátor | Leírás                | Példa |
| ------ | --------------------- | ------- |
| ==     | egyenlő                 | 1 == 1  |
| !=     | nem egyenlő             | 1 != 2  |
| <      | kisebb, mint             | 4 < 5   |
| <=     | kisebb vagy egyenlő    | 4 <= 4  |
| >      | nagyobb, mint          | 3 > 1   |
| >=     | nagyobb vagy egyenlő | 2 >= 2  |

## `if` és `else` elágazások

A [feltételes utasítás][conditional-statement] lehetővé teszi, hogy egy feltétel alapján futtass kódot, ahol a feltétel vagy `true`, vagy `false`.
A legegyszerűbb feltételes utasítás az [`if` elágazás][if], amely akkor futtat kódot, amikor a feltétel `true`.
Egy `if` elágazás deklarálásához az `if` kulcsszót írod le, utána a feltételt, majd a végrehajtandó kódot kapcsos zárójelben.

```swift
let wheelCount = 4
if wheelCount == 4 {
  print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Az `if` összekapcsolható az `else`-szel, hogy akkor futtasson kódot, amikor a feltétel `false`.
Az `else` elágazást `if` elágazással együtt kell használni, önmagában nem állhat.
Egy `else` elágazás deklarálásához az `if` elágazás kapcsos zárójele után az `else` kulcsszót írod le, majd a végrehajtandó kódot kapcsos zárójelben.

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
  print("You will need an umbrella")
} else {
  print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Az `if` elágazások `else if` használatával láncba is fűzhetők, hogy több feltételt ellenőrizzenek.
Ugyanazt az elvet követi, mint egy `if` elágazás definiálása, csak a kulcsszó `else if` az `if` helyett.
Ahogy az `if` elágazásoknak, ezeknek sem kell `else` elágazás ahhoz, hogy érvényesek legyenek, de ha szükséges, kaphatnak egyet.

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange or apple")
}
// Prints "Your favorite fruit is an apple"
```

## `if` kifejezés

Az `if` elágazások kifejezésként is használhatók, így értéket rendelhetsz egy változóhoz.
Az `if` blokk utolsó utasítása lesz az `if` kifejezés értéke.
Ez akkor lehet hasznos, ha egy feltétel alapján szeretnél értéket rendelni egy változóhoz.

```swift
let CpuBits = 32
let largest = if CpuBits == 64 {
  "x86_64"
} else {
  "x86_32"
}

print(largest)
// Prints "x86_32"
```
