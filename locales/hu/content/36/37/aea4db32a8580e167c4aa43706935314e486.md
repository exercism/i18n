# Bevezetés

Ha a paraméterek típusai kikövetkeztethetők, a Swift megengedi azt is, hogy a closure definíciójából elhagyjuk a paraméterneveket és az `in` kulcsszót. A paraméterekre ilyenkor egy speciális rövidített szintaxissal hivatkozhatunk, ahol a `$0` az első paramétert jelöli, a `$1` a másodikat, és így tovább.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
