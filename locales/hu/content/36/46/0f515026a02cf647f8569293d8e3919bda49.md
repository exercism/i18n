# Részletesen

Az ABAP-nak több numerikus típusa van. A kisebb bevezető feladatokhoz leggyakrabban az `i`-t használjuk egész értékekhez, a `p`-t pedig csomagolt tizedesértékekhez.

Használd az `i`-t, ha az érték csak egész szám lehet, például a napok száma. Használj tizedes típust, ha az érték tizedesjegyeket is tartalmazhat, például egy óradíj.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

A csomagolt számokat gyakran használják üzleti alkalmazásokban, amikor rögzített számú tizedesjegyre van szükség. Az ABAP emellett tizedes lebegőpontos számokkal (`decfloat16` és `decfloat34`) és bináris lebegőpontos számokkal (`f`) is rendelkezik. A bináris lebegőpontos számok hasznosak lehetnek tudományos számításokhoz, de nem jó alapértelmezett választás a pénzzel kapcsolatos példákhoz, mert sok tizedes tört nem ábrázolható pontosan.
