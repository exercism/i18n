# Névjegy

A `Maybe` típus jelenti az Elm nyelvben a megoldást a választható értékekre.
Ezért rengeteg alapvető Elm-függvény típusszignatúrájában találkozunk vele, és elengedhetetlen, hogy megértsük.

## Definíció és típusváltozó

A `Maybe` típus definíciója a következő:

```elm
type Maybe a = Nothing | Just a
```

Az Elm szóhasználatában ezt „custom type” definíciónak nevezik.
A custom type-okkal egy másik fogalom foglalkozik részletesen ezen a kurzuson, de a `Maybe` megértéséhez most nincs rájuk szükség.
A `Maybe a` és a `Just a` definíciójában az `a` egy típusváltozót jelöl, ami azt jelenti, hogy bármilyen típus lehet, például `Int`, `Bool` vagy `String`.
Ennek megfelelően a `Maybe String` egy olyan változó, amely tartalmazhat egy stringet, a `Maybe Int` pedig egy `Int` értéket.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

A `Maybe` típusdefiníciójában a függőleges vonal (a `|`) a „VAGY” szót jelenti.
Azt jelzi, hogy egy ilyen típusú érték vagy `Nothing`, vagy `Just` valami, ami `a` típusú.
Képzeld el, hogy a nevet és a kort nem töltötte ki az illető, akkor a következőt kapnánk:

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Egy `Maybe` érték tartalmának kiolvasása

Egy `Maybe` érték tartalmát mintaillesztéssel olvashatod ki.
A mintaillesztést szintén egy másik fogalom mutatja be részletesebben, ezért most csak arra összpontosítunk, hogyan működik a mintaillesztés egy `Maybe` esetében.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Valahányszor `Maybe` értéket használsz, az Elm fordítója ellenőrzi, hogy a kódod minden esetet kezel-e, így soha nem fordulhat elő, hogy egy `Maybe` mintaillesztésekor csak azt az esetet kezeled, amikor `Just someValue` van.
Ez elsőre idegesítőnek tűnhet, de ez az Elm nyelv egyik legnagyobb erőssége.
Ez több száz bugtól óv meg, és a fordító által vezérelt refaktorálást félelemmentes, kifizetődő élménnyé teszi.

## További függvények a `Maybe` kezeléséhez

A `Maybe` modulban számos hasznos függvény is van a `Maybe` típusok kezelésére.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
