# Utasítások

Alakítsd át a stringként megadott hármas számrendszerű számot (például '102012') a tízes számrendszerbeli megfelelőjévé az alapoktól kiindulva.

A program az érvénytelen hármas számrendszerű számot megadó stringeket tekintse 0 értékűnek.

A hármas számrendszerű számok három szimbólumot tartalmaznak: 0, 1 és 2.

A hármas számrendszerű szám utolsó helye az egyesek helye. Az utolsó előtti a hármasok helye, a hátulról harmadik a kilencesek helye, és így tovább.

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

Ha a nyelved szabványos könyvtára kínál egy metódust az átalakítás elvégzésére, tedd úgy, mintha nem létezne, és valósítsd meg magad.
