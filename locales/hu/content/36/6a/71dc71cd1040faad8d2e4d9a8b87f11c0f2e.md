# string felosztás használata

Go-ban az egyes karakterekkel a beépített `rune` típus segítségével dolgozhatsz.
Egy `string`-et így alakíthatsz át `[]rune`-ná (rune-ok szeletévé):

```go
aRunes := []rune(a)
```

A stringet fel lehet ugyan bontani sok kis stringre (rune-onként egyre), de ez nem hatékony.
