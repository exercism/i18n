# Bevezetés

A `String` egyes karakterei ugyanazzal az indexelési módszerrel érhetők el, mint amit a tömböknél használunk.
A stringekhez használt [indexek][string-indices] azonban _nem_ egész számok, és nem lehet velük közvetlenül dolgozni.
Ehelyett valamilyen más, ismert indexből kell kiszámítanod őket, például a `startIndex`-ből, amely egy nem üres string első karakterének pozíciójára mutat. Ehhez a [`String`][string-docs] és [`NSString`][nsstring-docs] könyvtárakban elérhető metódusokat használhatod (amikor a `Foundation` modul importálva van, a Swift stringjei hozzáférnek az NSString összes tulajdonságához és metódusához).

Vegyük például a következő stringet:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Ahhoz, hogy megkapd az „orange” szóban a „g” betűt, nem írhatod le, hogy `csv[21]`, ehelyett egy `String.Index` típusú értéket kell kiszámítanod, és azt kell indexként megadnod.
Jegyezd meg, hogy ezek az indexek önmagukban nem arra valók, hogy emberek olvassák őket.
Ezek az úgynevezett _átlátszatlan indexek_: az embernek nem kell tudnia, mi van bennük.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Jegyezd meg azonban, hogy ha az eltolás nem érvényes indexre mutat, azaz olyan indexet adna vissza, amely a `startIndex` előtt vagy az `endIndex` után van, akkor a művelet hibát jelez, és a program összeomlik.
Hogy ezt elkerüld, megadhatsz egy korlátozó indexet.
Ez opcionális indexet ad vissza, és nil-t ad minden olyan indexre, amely egyébként érvénytelen lenne.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Ráadásul az indexeket nem lehet megosztani a stringek között.
Ha például a fentebb kiszámított, az „orange” szóban lévő „g”-hez tartozó `index` segítségével a `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"` stringbe indexelsz, azaz leírod, hogy `fam[index]`, a program összeomlik.

Mindennek sok oka van, de lényegében mind ugyanabban csúcsosodik ki: „a Unicode trükkös”.

Általánosságban, ha egyes karakterekhez véletlenszerű hozzáférést szeretnél, akkor valószínűleg más adatszerkezetet érdemes használnod, például `Array<Character>`.

## Néhány hasznos metódus

A Swiftben a `first` és a `last` metódussal kaphatod meg egy string első és utolsó karakterét.
Ezek a metódusok opcionális karaktert adnak vissza, így ha a string üres, akkor nil-t adnak vissza.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

A `prefix` és a `suffix` metódussal egy string egy részstringjét is megkaphatod.
Ezek a metódusok egy egész számot várnak argumentumként, és visszaadják a string első vagy utolsó n karakterét tartalmazó részstringet.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
