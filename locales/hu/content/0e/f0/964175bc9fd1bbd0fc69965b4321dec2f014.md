# Bevezetés

A tulajdonság a C#-ban egy osztály olyan tagja, amely hozzáférést biztosít az osztályon belüli adatokhoz. A hívók beállíthatják vagy lekérdezhetik (get) ezeket az adatokat. A tulajdonságok vagy automatikusan implementáltak, vagy rendelkeznek háttérmezővel. Egy set és/vagy egy get hozzáférőből állnak. Néhány más nyelvben a „mutator” nagyjából megfelel a set hozzáférőnek, az „accessor” pedig a get hozzáférőnek, bár a szintaxis felépítése teljesen más.

Amikor beállítasz egy tulajdonságot, a bemeneti értéket érvényesítheted, formázhatod vagy más módon alakíthatod, és valójában bármilyen programozási művelet végrehajtható, amely az osztály kódjából elérhető.

Hasonlóképpen, amikor lekérdezel egy tulajdonságot, az adat kiszámítható vagy formázható, és ismét bármilyen programozási művelet végrehajtható, amely az osztály számára elérhető.

A tulajdonságoknak ugyanúgy vannak hozzáférés-módosítóik (`public`, `private` stb.), mint más osztálytagoknak, a set hozzáférőnek azonban lehet a lekérdező (get) hozzáférőtől független hozzáférési szintje, és fordítva. Egy tulajdonságnak nem kell mindkét hozzáférővel rendelkeznie, lehet csak az egyik (get vagy set).

A tulajdonságok kifejezésének alapvető szintaxisa kétféle formát ölthet:

## Mezőalapú/kifejezésalapú tulajdonságok:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## Automatikusan implementált tulajdonságok

```
public int MyProperty { get; private set; } = 42;
```

A kezdőérték megadása nem kötelező.
