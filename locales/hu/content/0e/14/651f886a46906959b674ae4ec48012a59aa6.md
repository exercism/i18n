# Tesztek

Egy Elm-projekt tesztjei a projekt `tests/` alkönyvtárában találhatók.
Az egyes feladatok tesztkészlete a feladat gyökérkönyvtárából futtatható.

```bash
$ cd ~/exercism/elm/hello-world
$ elm-test
```

## Változások figyelése

A tesztek automatikus újrafuttatása, amikor mented a változtatásokat:

```bash
$ elm-test --watch
```

## A tesztvezérelt fejlesztés menete

A legtöbb feladatnál a tesztek már meg vannak írva a `tests/Tests.elm` fájlban.
A célod az, hogy sikeresek legyenek: írd meg ehhez a szükséges kódot a `src/<exercise>.elm` fájlban.
Először az első hibát jelző tesztre összpontosíts, javítsd ki,
majd töröld vagy kommenteld ki a következő `skip <|` részletet a tesztfájlban, és ismételd mindaddig,
amíg minden teszt sikeres nem lesz.

## Elakadtál?

Első célod az legyen, hogy a kódod leforduljon, még akkor is, ha `Debug.todo` szerepel benne.
Ha úgy érzed, nem tudod, hogyan csinálj meg valamit,
gyakran hasznos, ha azt a részt kiemeled egy saját, még nem implementált függvénybe.

```elm
complexOperationOnMultipleStrings : List String -> List String
complexOperationOnMultipleStrings allStrings =
    List.map complexOperation allStrings


complexOperation : String -> String
complexOperation input =
    Debug.todo "Extracted operation into its own function"
```

Ha típusannotációt adsz ehhez a kiemelt függvényhez,
az segít a gondolkodásodban, és a fordítónak is jobb hibaüzeneteket ad majd.

## A kódod rendbetétele

Érdemes lehet [`elm-format`](https://github.com/avh4/elm-format) futtatni a kódodon, mielőtt beküldöd,
sőt akár be is állíthatod a szövegszerkesztődben, hogy mentéskor automatikusan formázza.
