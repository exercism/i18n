# Típuszsonglőrködés

A típuszsonglőrködés más néven automatikus típuskonverzió.
Típuszsonglőrködésről akkor beszélünk, amikor két különböző típusú értéket egy művelet elvégzéséhez ugyanarra a típusra alakítunk.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Ez történhet implicit módon (lásd a fenti példát), vagy explicit módon, `C`-stílusú típusátalakítással:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

A manuális típusátalakításnál engedélyezett típusok: `bool`, `int`, `float`, `string`, `array`, `object`.
A leggyakrabban arra használjuk a típusátalakítást, hogy egy egész számot (`int`) lebegőpontos számmá (`float`) alakítsunk, vagy fordítva.
