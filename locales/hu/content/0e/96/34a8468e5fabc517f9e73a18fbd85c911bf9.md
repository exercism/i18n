# Bemutatás

A [`for` ciklus][for-statement] lehetővé teszi, hogy ismételten végrehajts egy kódrészletet, amíg egy feltétel teljesül.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

A `for` ciklus négy részből áll:

1. A kezdőérték: a ciklusba való belépés előtt egyszer hajtódik végre. Általában a cikluson belül használt változók definiálására szolgál.
2. A feltétel: minden iteráció előtt kiértékelődik. A ciklus addig fut tovább, amíg ez `true` értéket ad.
3. A léptetés: minden iteráció után hajtódik végre. Általában a ciklusváltozó (vagy ciklusváltozók) módosítására (gyakran növelésére vagy csökkentésére) szolgál.
4. A törzs: az a kód, amely minden iterációban végrehajtódik.

## `for` és `foreach` ciklusok összehasonlítása

Általában a [concept:csharp/foreach-loops]() használata előnyösebb a `for` ciklusokkal szemben, a következő okok miatt:

- A `foreach` ciklus garantáltan _minden_ értéken végigmegy. A `for` ciklusnál könnyen kihagyhatsz elemeket, például egy off-by-one hiba miatt.
- A `foreach` ciklus _deklaratívabb_: a kódod _azt_ fejezi ki, hogy mit szeretnél csinálni, szemben a `for` ciklussal, amely _azt_, hogy hogyan szeretnéd megtenni.
- A `foreach` ciklust nem lehet elrontani, míg a `for` ciklusoknál könnyen elkövethetsz egy off-by-one hibát.
- A `foreach` ciklus minden gyűjteménytípuson működik, még azokon is, amelyek nem támogatják az elemek indexelővel való elérését.

Hogy garantált legyen, hogy a `foreach` ciklus _minden_ értéken végigmenjen, a fordító nem engedi meg, hogy egy `foreach` cikluson belül módosíts egy gyűjteményt:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

A `for` ciklusnak azonban van néhány előnye a `foreach` ciklussal szemben:

- A kívánt indexnél kezdhetsz vagy állhatsz meg.
- Bármilyen (Boolean) lezárási feltételt használhatsz.
- Kihagyhatsz elemeket a ciklusváltozó léptetésének testreszabásával.
- A gyűjteményeket hátulról előre is feldolgozhatod, visszafelé számolva.
- Olyan esetekben is használhatsz `for` ciklust, amelyekben nincs szó gyűjteményekről.
