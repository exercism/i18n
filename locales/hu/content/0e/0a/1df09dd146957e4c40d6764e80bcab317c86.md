# Bevezetés

A *tuple* több nevesített értéket fog össze egyetlen objektummá: ezt más nyelvek rekordnak, struktúrának vagy osztálynak nevezik. Minden tuple-osztálynak rögzített, nevesített slotjai vannak, és hozzájuk a Factor automatikusan generál gettereket és settereket.

## Tuple definiálása

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

Minden slotot `{ name initial: default-value }` alakban deklarálsz. `initial:` záradék nélkül az alapérték `f`.

## Tuple létrehozása

A legegyszerűbb konstruktor a `new`:

```factor
point new .
! => T{ point }
```

A `boa` (a „by order of arguments”, azaz az argumentumok sorrendje szerinti rövidítés) a deklaráció sorrendjében tölti fel a slotokat az adatveremből:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

A `T{ class { slot value } … }` literál szintaxissal olyan tuple-t hozhatsz létre, amelyben a slotoknak csak egy részét állítod be, és a kiírás is ugyanígy néz ki:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Amikor egy slot értéke megegyezik az alapértékével, a nyomtató kihagyja.

## Slot olvasása

A Factor minden slothez generál egy `slot>>` gettert. A getterek az [`accessors`][accessors] névtérben élnek:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Slot frissítése

A settereket `>>slot` alakban írod le, és *helyben módosítják* a tuple-t:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Ha az eredeti példányt érintetlenül akarod hagyni, előbb `clone`-ozz:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

A `change-slot` egy olyan quotationt vár, amely a jelenlegi értékből állítja elő az újat:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

A `change-x` szintén módosítja a tuple-t, ezért ha meg akarod őrizni az eredetit, mielőtt meghívod, `clone`-ozz.
