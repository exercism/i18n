# Bevezetés

A ternáris operátorokkal az if-feltételeket utasításblokkok helyett kifejezésekben is megadhatod. Ez a funkcionális programozás megközelítéseit idézi, és gyakran kifejezőbbé, kevésbé hibahajlamossá teheti a kódot.

A ternáris operátor három kifejezést kapcsol össze: egy feltételt, amelyet az a kifejezés követ, amelyet akkor értékelünk ki és adunk vissza, ha a feltétel igaz (az `if` rész, amelyet a `?` vezet be), és egy olyan kifejezést, amelyet akkor értékelünk ki és adunk vissza, ha a feltétel hamis (az `else` rész, amelyet a `:` vezet be).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
