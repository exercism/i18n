# Bevezetés

A `str` osztály [számos hasznos metódust][str methods] kínál a stringekkel való munkához és azok összeállításához. Ezek közé tartozik a keresés, a tisztítás, a felbontás, az átalakítás, a fordítás és számos más technika.

A stringek [sorozatok][text sequence], amelyek [Unicode-kódpontokból][unicode code points] állnak. Az egyes „karakterek” vagy kódpontok (_1 hosszúságú stringek_) balról egy `0-based index` számmal, jobbról pedig egy `-1-based index` számmal érhetők el. A stringek minden [általános sorozatműveletet][common sequence operations] megvalósítanak.

Bejárhatók `for item in <str>` vagy `for index, item in enumerate(<str>)` szintaxissal. Össze is fűzhetők a `<str> + <other str>` vagy a `<str>.join(<iterable>)` használatával.

A stringek _változtathatatlanok_, ami azt jelenti, hogy egy `str` objektum értéke a memóriában nem változhat meg. A `str`-en működő függvények vagy metódusok (_mint amilyeneket itt épp megismerünk_) az adott `str` objektum egy új `instance`-ét adják vissza ahelyett, hogy az eredeti `str`-et módosítanák.

A Python stringmetódusainak egy kis válogatása következik. A teljes listát a Python dokumentációjában találod, a [str osztály][str methods] leírásánál.


A [`<str>.title()`][str-title] feldolgoz egy stringet, és a benne talált minden „szó” első „karakterét” nagybetűssé alakítja. Pythonban ez nagyban függ a használt [nyelvi kodektől][codecs], valamint attól, hogy az adott nyelv hogyan ábrázolja a szavakat és a karaktereket. Egy nyelvhez vagy karakterkészlethez [locale][locale] szabályok is érvényben lehetnek.


```python
man_in_hat_th = 'ผู้ชายใส่หมวก'
man_in_hat_ru = 'мужчина в шляпе'
man_in_hat_ko = '모자를 쓴 남자'
man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```

A [`<str>.endswith(<suffix>)`][str-endswith] `True`-t ad vissza, ha a string végződése `<suffix>`, egyébként `False`-t.


```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

A [`<str>.strip(<chars>)`][str-strip] a `str` egy másolatát adja vissza, amelyből eltávolította a vezető és a záró `<chars>` karaktereket. A `<chars>`-ben megadott kódpontok nem előtagként vagy utótagként működnek: a kódpontok **minden kombinációját** eltávolítja, a string **mindkét végétől** kiindulva. Ha a `<chars>` nincs megadva, a whitespace-kódpontok minden kombinációja eltávolításra kerül.


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
```


A [`<str>.replace(<substring>, <replacement substring>)`][str-replace] a string egy másolatát adja vissza, amelyben a `<substring>` minden előfordulását `<replacement substring>` váltja fel.

Az alábbi idézet [The Hunting of the Snark][The Hunting of the Snark] című műből származik, [Lewis Carroll][Lewis Carroll] tollából.

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```
