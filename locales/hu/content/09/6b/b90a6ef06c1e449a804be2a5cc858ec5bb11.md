# Utasítások

Ebben a feladatban a [Blackjack][blackjack] néhány szabályát fogod megvalósítani, például azt, hogyan zajlik a játék, és hogyan számolják a pontokat.

~~~~exercism/note
Ebben a feladatban a lapokat számok képviselik; a számkártyákat a számértékük jelöli, a bubi, a dáma, a király és az ász pedig rendre 11, 12, 13 és 14. (A jokereket nem használjuk a játékban.)

Hogy könnyebb legyen ezzel a reprezentációval dolgozni, néhány konstans a fájl elején van definiálva: a `C2`-től a `C10`-ig a számkártyáké, a `CJ` a bubié, a `CQ` a dámáé, a `CK` a királyé, a `CA` pedig az ászé.

[Szabványos, francia színekből álló 52 lapos paklit][standard_deck] feltételezünk, a legtöbb változatban azonban több paklit kevernek össze a játékhoz.

[standard_deck]: https://en.wikipedia.org/wiki/Standard_52-card_deck
~~~~

~~~~exercism/note
Ezek a fogalomban említett utasítások:

| Utasítás      | Leírás                                                 |

| cmp a, b      | a jelzőket a - b alapján állítja be                    |

| jcc a         | a kód az a címkén folytatódik, ha a `cc` feltétel teljesül |

| jg          | a > b (előjeles)     |
| jb          | a < b (előjel nélküli) |
| ja          | a > b (előjel nélküli) |
| jle         | a <= b (előjeles)    |
| jge         | a >= b (előjel nélküli) |
| jbe         | a <= b (előjel nélküli) |
| jae         | a >= b (előjel nélküli) |
| jne         | a != b               |
| jnl         | !(a < b) (előjeles)  |
| jng         | !(a > b) (előjeles)  |
| jnb         | !(a < b) (előjel nélküli) |
| jna         | !(a > b) (előjel nélküli) |
| jnle        | !(a <= b) (előjeles) |
| jnge        | !(a >= b) (előjeles) |
| jnbe        | !(a <= b) (előjel nélküli) |

## 1. Számítsd ki egy lap értékét

A **Blackjackben** a `CA` értéke 1 vagy 11, a kéztől függően (erről később még lesz szó).
A figurás lapok (`CJ`, `CQ` és `CK`) 10 pontot érnek, minden más lap a _számértékét_ éri.

Definiáld a `value_of_card` függvényt a `card` paraméterrel, amely egy lapot képviselő szám.
A függvénynek a kapott lap _számértékét_ kell visszaadnia.
Mivel a `CA` több értéket is felvehet (1 **vagy** 11), egyelőre rögzítsük a `CA` értékét 1-ben.
Később majd írsz egy függvényt, amely egy meglévő kéz alapján meghatározza a `CA` értékét.

```c
value_of_card(13)
// => 10

value_of_card(4)
// => 4

value_of_card(14)
// => 1
```

## 2. Határozd meg, melyik lapnak nagyobb az értéke

Definiáld a `higher_card` függvényt a `card_one` és `card_two` paraméterekkel, amelyek két lapot képviselő számok.
A pontozás szempontjából a `CJ`, a `CQ` és a `CK` értéke egyaránt 10.
A függvénynek azt kell visszaadnia, hogy melyik lapnak nagyobb a pontozási értéke.
Ha a két lap értéke egyenlő, mindkettőt add vissza.

A `CA` több értéket is felvehet, ezért ebben a részfeladatban 1-ben rögzítjük az értékét.

```c
higher_card(13, 11)
// => {13, 11}

higher_card(4, 6)
// => 6

>>> higher_card(13, 14)
// => 13
```

~~~~exercism/note
Ahhoz, hogy egy függvényből két egész számot adj vissza, a `rax` és az `rdx` regisztert is használnod kell:

```x86asm
returning_two_values:
    mov rax, rdi
    mov rdx, rsi
    ret
```

Ha csak egy lapot adsz vissza, a `rdx`-et 0-ra kell állítani.
~~~~

## 3. Számítsd ki egy ász értékét

Ahogy korábban említettük, a `CA` _vagy_ 1, **vagy** 11 pontot ér, a kéztől függően.
A **Blackjack** szabályai szerint a `CA`-k értékét úgy kell megválasztani, hogy maximalizálja a kéz pontszámát, de ne lépje túl a 21-et (azaz ne „égjen be").

Definiáld a `value_of_ace` függvényt a `card_one` és `card_two` paraméterekkel; ez a két szám a kézben már meglévő két lapot képviseli, _mielőtt_ megkapod az utolsó `CA`-t.
A függvényednek azt kell visszaadnia, hogy melyik értéket, 1-et vagy 11-et kapja majd a következő `CA`.
Ne feledd: az új kéz értékének (a `CA`-val együtt) a lehető legnagyobbnak kell lennie, _anélkül_ hogy túllépné a 21-et.

**Tipp**: ha már van a kezünkben `CA`, akkor a következő `CA` értéke 1 lesz.

```c
value_of_ace(6, 13)
// => 1

value_of_ace(7, 3)
// => 11
```

## 4. Állapítsd meg, hogy blackjack-e a kéz

Ha a játékos első két lapként egy `CA`-t és egy tízes lapot (`C10`, `CJ`, `CQ` vagy `CK`) kap, akkor 21 pontja lesz.
Ezt a kezet nevezik **blackjacknek**.

Definiáld az `is_blackjack` függvényt a `card_one` és `card_two` paraméterekkel, amelyek két lapot képviselő számok.
A függvénynek 1-et kell visszaadnia, ha a kétlapos kéz **blackjack**, egyébként 0-t.
Hogy könnyebb legyen az értékekkel dolgozni, a fájl elején definiálva vannak a `TRUE` és `FALSE` konstansok, amelyek rendre 1-et és 0-t jelentenek.

**Megjegyzés**: A pontszám _kiszámítását_ többféleképpen is meg lehet oldani.
De ha lehet, szeretnénk, ha azt ellenőriznéd, hogy van-e a kézben egy `CA` és egy tízes lap, ahelyett hogy _összeadnád_ a lapok értékét.

```c
is_blackjack(14, 13)
// => 1

is_blackjack(10, 9)
// => 0
```

## 5. Párok szétválasztása

Ha a játékos első két lapja azonos értékű (például két `C6`, vagy egy `CQ` és egy `CK`), a játékos dönthet úgy, hogy két külön kézként kezeli őket.
Ezt nevezik „párok szétválasztásának".

Definiáld a `can_split_pairs` függvényt a `card_one` és `card_two` paraméterekkel, amelyek két lapot képviselő számok.
A függvénynek 1-et kell visszaadnia, ha a kétlapos kéz két kézre választható szét, egyébként 0-t.
Hogy könnyebb legyen az értékekkel dolgozni, a fájl elején definiálva vannak a `TRUE` és `FALSE` konstansok, amelyek rendre 1-et és 0-t jelentenek.

```c
can_split_pair(12, 13)
// => 1

can_split_pair(10, 14)
// => 0
```

## 6. Duplázás

Ha az eredeti két lap összesen 9, 10 vagy 11 pontot ér, a játékos az eredeti tétével megegyező további tétet tehet.
Ezt nevezik „duplázásnak".

Definiáld a `can_double_down` függvényt a `card_one` és `card_two` paraméterekkel, amelyek két lapot képviselő számok.
A függvénynek 1-et kell visszaadnia, ha a kétlapos kéz lehetővé teszi a játékos számára a „duplázást", egyébként 0-t.
Hogy könnyebb legyen az értékekkel dolgozni, a fájl elején definiálva vannak a `TRUE` és `FALSE` konstansok, amelyek rendre 1-et és 0-t jelentenek.

```c
can_double_down(14, 9)
// => 1

can_double_down(10, 2)
// => 0
```
