# Bevezetés

A Factor [`random`][random] szókészlete egyetlen általános szót kínál, a `random`-ot, amely az argumentumához igazodik, emellett segédszavakat a sorozatok keveréséhez és mintavételezéséhez.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

Ha a `random` szót egy `n` egész számmal hívod meg, egy `[0, n)` intervallumba eső értéket ad vissza; ha egy sorozattal, akkor egy véletlenszerű elemet. A `randomize` helyben keveri a sorozatot, a `sample` pedig egymástól különböző elemeket húz.

Alapértelmezés szerint ezek egy globális generátorból húznak, amelyet a rendszeróra inicializál. Hogy az eredmények megismételhetők legyenek, telepíts egy maggal inicializált generátort a `<mersenne-twister>` (a [`random.mersenne-twister`][mt] szókészletből) és a `with-random` használatával:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[random]: https://docs.factorcode.org/content/vocab-random.html
[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
