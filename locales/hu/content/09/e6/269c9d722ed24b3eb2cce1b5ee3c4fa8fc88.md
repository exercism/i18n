# Bevezetés

## Csomagok és modulok

### Importálás

Egy modul általában a `use` kulcsszóval töltődik be.
Ez egyszerre tölti be a modult, és hívja meg rajta az `import` metódust, importálva minden exportált szimbólumot.

A csomag `@EXPORT` tömbjében szereplő szimbólumok alapértelmezés szerint importálódnak.
A csomag `@EXPORT_OK` tömbjében szereplő szimbólumokat viszont explicit módon kell importálni.

### Exportálás

Ahhoz, hogy egy szimbólum importálható legyen, először exportálni kell.
Az [Exporter][Exporter] modul a Perl része, és az egyik legkényelmesebb megoldás az exportálásra.

A modul definiálása:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

A modul használata:
```perl
use Foo ('bar');

bar();
```

### Alapmodulok

Az [Exporter][Exporter] mellett a Perl számos [alapmodult][perl-core-modules] kínál használatra.
Néhány példa, amely hasznos lehet az itt előforduló feladatokhoz: [List::Util][List::Util], [Time::Piece][Time::Piece] és [Math::BigRat][Math::BigRat].

### CPAN

Az alapmodulok mellett a [CPAN][metacpan] több ezer, a Perl közösség által készített további modult kínál telepítésre.
A Perl kurzus egy [cpanfile][test-runner-cpanfile] segítségével telepít egy válogatást azokból a modulokból, amelyek az Exercism Perl tesztfuttatójával használhatók.
