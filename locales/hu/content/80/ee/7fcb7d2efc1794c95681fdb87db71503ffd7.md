# Tippek a Virágmező feladathoz (Bash)

Úgy tűnik, ehhez a feladathoz kétdimenziós tömbre van szükség.
A Bash csak egydimenziós, indexelt vagy asszociatív [tömböket][array] kínál.

A többdimenziós tömböket asszociatív tömbök segítségével szimulálhatod: alakítsd az indexeket vesszővel elválasztott stringgé, és használd a tömb kulcsaként.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
