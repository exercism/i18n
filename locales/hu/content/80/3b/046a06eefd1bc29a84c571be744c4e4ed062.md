# Kiegészítés az utasításokhoz

## Megvalósítási megjegyzések

A Cipher interfész definíciója a `cipher.go` fájlban található.

A megvalósításaidnak meg kell felelniük a Cipher interfésznek.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

Az `Encode` várhatóan figyelmen kívül hagyja a szövegben mindazokat a karaktereket, amelyek nem A-Za-z közé esnek, ezek nem jelennek meg a kimenetben.
A kimenet emellett kisbetűssé normalizálódik.

A rejtjelek előállítására szolgáló függvények:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

A `NewShift` argumentumának az 1-től 25-ig vagy a -1-től -25-ig terjedő tartományban kell lennie.
A nulla nem megengedett.
Érvénytelen argumentum esetén a `NewShift` nil-t ad vissza.

A `NewVigenere` argumentuma csak kisbetűkből, a-tól z-ig állhat.
A csupa „a” betűből álló értékek nem megengedettek.
Érvénytelen argumentum esetén a `NewVigenere` `nil`-t ad vissza.
