# Bevezetés

## Boolean értékek az R-ben

Az igaz és hamis értékeket a `logical` típus képviseli.
Csak két értéket tartalmaz: `TRUE` és `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Boolean operátorok

Az R-ben öt Boolean operátor van, de a tanterv ezen szakaszában csak három számít.
A másik kettő akkor lesz fontos, amikor vektorokkal dolgozol, amelyekről több későbbi fogalomban is szó lesz.

A `&&` a Boolean „és”.
Az eredménye `TRUE` lesz, ha a `&&` *mindkét* oldalán a kifejezés `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

A `||` a Boolean „vagy”.
Az eredménye `TRUE` lesz, ha a `||` *bármelyik* oldalán a kifejezés `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

A `!` a Boolean „nem”.
Felvescseréli a `TRUE` és `FALSE` értékeket.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Hosszabb és bonyolultabb kifejezéseknél érdemes zárójeleket használni, hogy világos legyen a szándékod.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
