# Bevezetés

A `Rational numbers` olyan törtek, amelyeknek a számlálója és a nevezője is egész szám.

Például a `2//3`-at eltárolhatjuk pontos törtként a hozzávetőleges `Float64` érték helyett, ami `0.6666...`

Ennek az az előnye, hogy (kivéve az *egész szám túlcsordulás* szélsőséges esetét) a racionális szám pontos marad, elkerülve azokat a kerekítési hibákat, amelyek a lebegőpontos számoknál gyakran elkerülhetetlenek.

A racionális számok meglehetősen egyszerű numerikus típust alkotnak, és pontosan úgy viselkednek, ahogy várnád.
Mivel a Julia korai verziói óta szabványos típusnak számítanak, a legtöbb függvény ugyanúgy elfogadja őket bemenetként, mint az egész számokat és a lebegőpontos számokat.

## Racionális számok létrehozása

A létrehozás nem bonyolultabb annál, mint hogy `//`-t írunk két egész szám közé.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

A közös tényezőket automatikusan eltávolítja, így a tört a „legegyszerűbb alakjára” redukálódik: a legkisebb egész számokra, amelyek pontosan reprezentálják a törtet, nem negatív nevezővel.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## Aritmetika racionális számokkal

A szokásos `arithmetic operators`, a `+ - * / ^ %` ugyanúgy működik a racionális számokkal, lényegében mint a többi numerikus típussal.

Az egész számok és más `Rational`-ok is szerepelhetnek benne, és `Rational` eredményt adnak.
Ha `float` kerül a kifejezésbe, az eredmény is `float` lesz, ami a pontosság esetleges elvesztésével járhat.

Ha `float`-ra van szükséged, egyszerűen a `float()` függvénnyel alakítsd át a racionális számot.
Teljesen megszokott, hogy egy hosszú számítás során racionális számokkal őrizzük meg a pontosságot, majd a végén lebegőpontos számmá alakítjuk az eredményt.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## Egyéb műveletek

A Juliában a racionális számok egyszerűen csak számok.
A fordító általában szükség szerint átalakítja a típusokat.

Vigyázat azonban: az összehasonlítás csak véges tizedestört alakkal rendelkező törteknél működik:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Minden más esetben viszont az összehasonlításhoz a `Rational`-t `Float`-tá kell alakítani:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

A matematikai függvények elfogadnak racionális számokat bemenetként, de lebegőpontos eredményt adhatnak:

```julia-repl
julia> sqrt(9//16)
0.75
```
