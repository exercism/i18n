# Bevezetés

## Számok

A Haskellnek van egy `Num` típusa, amely az összes numerikus típus alapja.
A szám típuson belül négy fő altípus van: [`Int`][int], [`Integer`][integer], [`Double`][double] és [`Float`][float].

A Haskellben két egész típus van, amelyek egész számokat reprezentálnak.
Az `Int` fix méretű egész, az `Integer` pedig tetszőleges pontosságú egész.
Egy `Integer` bármekkora számot képes tárolni, egészen a géped memóriájának határáig, míg az `Int` a 32 vagy 64 biten ábrázolható pozitív és negatív egészek halmazának felel meg (garantáltan legalább -2^29 és 2^29 - 1 között).

Figyelj rá, hogy negatív számok írásakor zárójeleket használj, hogy elkerüld a félreértést.

```haskell
1

(-1)
```

A `Float` a valós számok halmazának felel meg, a számítógép pontossága által korlátozva.
A számokon definiált műveletek általában az egyik vagy a másik típuson működnek, de nem mindkettőn.
A `Double` dupla pontosságú lebegőpontos szám.

```haskell
10.5
```

### Átváltás egészek és lebegőpontos számok között

A `toFloat` függvénnyel egy `Int`-et vagy `Integer`-t `Float`-té alakíthatsz.

```haskell
toFloat 1
-- -> 1.0
```

Létezik a `fromIntegral` is, amely bármilyen numerikus típust átalakít a következtetett, szükséges numerikus típussá.

```haskell
fromIntegral 1
-- -> 1.0
```

Ha egy `Float`-ot `Int`-té szeretnél alakítani, használhatod a [`round`][round], [`floor`][floor] vagy [`ceiling`][ceiling] függvényt.
A `round` a legközelebbi egészhez kerekít, a `floor` lefelé, a `ceiling` pedig felfelé kerekít.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

### Aritmetikai operátorok

A numerikus típusokon használhatod az [alapvető aritmetikai operátorokat][math].
Az operátorok: `+`, `-`, `*`, `/` és `%`.
Ezek használatakor a számok típusának meg kell egyeznie.
A `fromIntegral` függvény átalakítja őket, hogy a típusok illeszkedjenek.

#### Összeadás, kivonás és szorzás

A `+` operátor az összeadásra, a `-` a kivonásra, a `*` pedig a szorzásra szolgál.

| Operátor | Példa          |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

#### Osztás

Az osztás számok elosztására szolgál.
Az osztásra a `/` operátort használjuk.
Az eredmény mindig lebegőpontos szám lesz.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
Egyes programozási nyelvekben a nullával való osztás eredménye hiba.

A Haskellben nullával osztva az eredmény `Infinity` vagy `-Infinity`.
Az egyetlen kivétel a nulla osztása nullával, aminek eredménye `NaN` (Not a Number, azaz nem szám).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

### Egész osztás

Az egész osztás egész számok elosztására szolgál, és az eredmény egész részét adja.
A Haskellben két egész osztó függvény van, amelyek abban különböznek, hogyan kerekítenek, amikor az eredmény negatív:

- A `div` lefelé kerekít, a negatív végtelen felé.
- A `quot` a nulla felé kerekít.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Ha egész osztásnál nullával osztasz, az kivételt eredményez.
Ez eltér a normál osztástól.
~~~~

#### Maradék

Az egész osztás maradékát a `mod` vagy a `rem` segítségével kaphatod meg.
Ezek az eredmény előjelében térnek el, ha az egyik szám negatív:

- A `mod` a `div`-hez tartozik, és eredményének előjele az osztóval egyezik.
- A `rem` a `quot`-hoz tartozik, és eredményének előjele az osztandóval egyezik.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Bármely `x` és `y` esetén (ahol `y` nem nulla) a következő törvényszerűségek érvényesek:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Ha mindkét szám pozitív, a `div` és a `quot` ugyanazt az eredményt adja, ahogy a `mod` és a `rem` is.
Ebben az esetben a `quot` és a `rem` némileg hatékonyabb lehet, mert a `div`-nek és a `mod`-nak extra lépésekre van szüksége a negatív számok kezeléséhez.
~~~~

~~~~exercism/caution
Ha `mod` vagy `rem` használatakor nullával osztasz, az kivételt eredményez.
Ez eltér a normál osztástól.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

### Hatványozás

A Haskellben három „hatványra emelő” operátor van, amelyek különbözőképpen működnek, és különböző argumentumtípusokat fogadnak.

- A `**` két **lebegőpontos számot** fogad, és logaritmusokkal számítja ki a hatványt.
- A `^^` egy **lebegőpontos** számot emel pozitív vagy negatív **egész** kitevőre.
- A `^` **bármilyen numerikus típust** emel **pozitív egész** kitevőre.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

### Prioritás és zárójelek

A Haskell engedi a zárójelek (`()`) használatát, amelyekkel kifejezéseket csoportosíthatsz.
Ez akkor hasznos, ha meg szeretnéd változtatni a műveletek sorrendjét.

Ha több aritmetikai operátort használsz, a műveletek sorrendje ugyanaz, mint a matematikában, amit [PEMDAS][pemdas] néven is ismernek.
A sorrend: zárójelek (`()`), kitevők (`**`), szorzás (`*`) és osztás (`/`), majd összeadás (`+`) és kivonás (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
