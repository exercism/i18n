# Tesztek

A weboldalunk tesztfuttatójaként a [pytest][Getting Started Guide] eszközt használjuk.
Ha a Python-kurzus feladatainak tesztjeit helyben szeretnéd letölteni és futtatni, telepítened kell a `pytest` csomagot a fejlesztői gépedre.
Érdemes a következő `pytest` bővítményeket is telepítened:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

Javasoljuk továbbá a [pylint][pylint] kódellenőrző program használatát, mivel része a weboldalon adott automatikus visszajelzésnek, és nagyon hasznos statikus elemzőeszköz lehet.
A kényelmes használat érdekében a `pytest` [pytest-pylint][pytest-pylint] bővítményével a `pylint`-et a `pytest` segítségével futtathatod a parancssorból.

A Pylint beállítása kicsit sok lehet, ezért az [oktatóanyag a pylint.readthedocs.io oldalról][tutorial from pylint.readthedocs.io] segíthet az indulásban, ahogy a Real Python [Kódminőség: eszközök és bevált gyakorlatok][Code Quality: Tools and Best Practices] áttekintése is.

## A pytest telepítése

A Pytest a Python beépített [`pip`][pip] segédprogramjával telepíthető és frissíthető.

További tippekért Brett Cannon remek [gyors és egyszerű útmutatót írt arról, hogyan telepíts csomagokat Pythonhoz][quick-and-dirty], valamint egy nagyszerű magyarázatot is [arról, miért a `python -m pip`-et érdemes használni][python-m-pip].
A Python parancssori argumentumairól bővebben lásd a Python dokumentációjának [parancssor és környezet][python command line] szakaszát.

**Megjegyzés:** A `Python3` és a `py` a te rendszereden lehet, hogy a Python aliasa, de az is lehet, hogy nem.
A lenti telepítési parancsokat ennek megfelelően igazítsd hozzá.
Ha virtuális környezetbe telepíted a `pytest`-et, a parancsok futtatása előtt győződj meg róla, hogy a környezet **be van aktiválva**.
Ellenkező esetben a `pytest` telepítése globális lesz.

#### Windows

```powershell
PS C:\Users\foobar> py -m pip install pytest pytest-cache pytest-subtests pytest-pylint
Successfully installed pytest-8.3.3 ...
```

#### Linux / MacOS

```bash
$ python3 -m pip install pytest pytest-cache pytest-subtests pytest-pylint
Successfully installed pytest-8.3.3 ...

```

A telepítés sikerességének ellenőrzéséhez:

```bash
$ python3 -m pytest --version
pytest 8.3.3
```

## A tesztek futtatása

A tesztek futtatásához a terminálban a `cd` parancs segítségével lépj be abba a mappába, ahol a feladat található (_a lenti `<exercise-folder-location>` helyére írd a saját elérési utadat_).

```bash
$ cd <exercise-folder-location>
```

<br>

~~~~exercism/note
 `<exercise-folder-location>` or most things inside angle brackets denote a **_placeholder value_**.
A normal path or file name should be written _without_ any brackets.  


For example: `/Users/janedoe/exercism/python/exercises/concept/chaitanas-colossal-coaster` (on *nix systems), `C:\Users\janedoe\exercism\python\exercises\practice\hello-world\` (on Windows), `myFolder` or `my_file.py`.
~~~~  

<br>


A futtatni kívánt fájl neve általában `_test.py` végződésű.
Ez a fájl tartalmazza a feladat megoldásához tartozó teszteket, és ugyanazok a tesztek futnak le a weboldalon is, amikor feltöltesz egy megoldást.
Ezután futtasd a következő parancsot a terminálban, és a `<exercise_test.py>` helyére írd a tesztfájl elérési útját/nevét:

```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

### Figyelmeztetések elhárítása

Ha a fenti parancsban nem használod a `pytest -o markers=task` beállítást, előfordulhat, hogy `warnings` üzeneteket kapsz „unknown markers” szöveggel, amikor egy olyan tesztet futtatsz, amely az _új_ szintaxisunkat használja.

Hogy ne kelljen minden egyes tesztfuttatásnál beírnod a `pytest -o markers=task` parancsot, használhatsz egy `pytest.ini` konfigurációs fájlt, amely a Python-kurzus könyvtárának legfelső szintjéről tölthető le: [pytest.ini][pytest.ini].

Saját `pytest.ini` fájlt is létrehozhatsz a következő tartalommal:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

Ha ezt a fájlt az Exercism-feladatok _gyökér-_ vagy _munkakönyvtárába_ helyezed el, regisztrálja a markereket, és megszűnnek a figyelmeztetések.
A pytest markereiről bővebb információt a `pytest` dokumentációjában a [tesztfüggvények megjelölése][marking test functions with attributes] és az [egyedi markerekkel való munka][working with custom markers] című részben találsz.

_A pytest-konfigurációk testreszabásáról bővebb információt a pytest dokumentációjában, a [konfigurációs fájlformátumok][configuration file formats] című részben találsz._

### Sikertelen tesztek

Amikor egy teszt elbukik, a `pytest` kiírja a terminálra minden sikertelen teszt szövegét, valamint az egyes tesztek várt és tényleges `return` értékét.
Alább egy általános példa egy sikertelen tesztre:

```bash
$(my_venv) python3 -m pytest -o markers=task <exercise_test.py>

=================== FAILURES ====================
______________ name_of_failed_test ______________
# Test code inside of <exercise_test.py> that failed.
...
E   TypeOfError: ReturnedValue != ExpectedValue

exercise_test.py:<line_of_failed_test>: TypeOfError
============ short test summary info ============
FAILED exercise_test.py::ExerciseTest::name_of_failed_test
========== 1 failed, 2 passed in 0.13s ==========
```

### További argumentumok

Ha pontosan szabályozni szeretnéd, mit ír ki a pytest a képernyőre, íme néhány hasznos parancssori argumentum, amelyekkel testre szabhatod a működését.

#### Minden részlet megjelenítése [`-v`]

A `-v` (_verbose_) kapcsoló hozzáadásával a sikertelen tesztek mellett a környezeti információkat és a tesztek összegzését is megjeleníted:

#### Leállás az első hiba után [`-x`]

A `-x` kapcsolóval a tesztek a szokásos módon futnak le, de a futtatás az első sikertelen tesztnél leáll.
Ez akkor segít, ha egyszerre csak egy részfeladatot vagy egyetlen teszt hibáját szeretnéd kinyomozni:

```bash
$(my_venv) python3 -m pytest -o markers=task -x exercises/<exercise_name>/<test_file_test.py>

=================== FAILURES ====================
_______________ example_test_foo ________________
...
...
============ short test summary info ============
FAILED example_test.py::ExampleTest::example_test_foo
!!!!!!!!!!! stopping after 1 failures !!!!!!!!!!!
========== 1 failed, 5 passed in 0.28s ==========
```

#### Előbb a sikertelen tesztek [`--ff`]

A `pytest-cache` bővítmény megjegyzi, mely tesztek buktak el legutóbb, amikor a `pytest`-et futtattad, így a `--ff` kapcsoló hatására a `pytest` **először** a korábban sikertelen teszteket futtatja le, majd a többi teszttel folytatja.
Ez felgyorsíthatja a tesztelést, ha sok apró javítást végzel egy adott részfeladat vagy bemenet körül.

```bash
$(my_venv) python3 -m pytest -o markers=task --ff <example_file_test.py>
==================== 7 passed in 503s ====================
```

### Javasolt munkafolyamat

Javasoljuk a következő parancsokat, amelyek megkönnyítik és (talán) felgyorsítják a hibakeresést:

Először válts át a tesztelni kívánt feladat könyvtárába:

```bash
$(my_venv) cd path/to/exercise
```

Ezután futtasd a teszteket a korábban ismertetett `-x` és `--ff` argumentumokkal:

```bash
$(my_venv) python3 -m pytest -o markers=task -x --ff <example_file_test.py>
```

Ez lefuttatja a megoldásod tesztjeit.
Amikor a `pytest` sikertelen tesztbe ütközik, a program leáll, és megmondja, melyik teszt bukott el.
Amikor javítasz, és újra lefuttatod a tesztet, a `pytest` először a korábban elbukott tesztet futtatja le, majd folytatja a többi teszttel.

### A PDB, a Python hibakereső használata a pytesttel

Ha profiként szeretnél hibát keresni, a `pytest` parancs után használhatod a `--pdb` argumentumot, és beugorhatsz a beépített [Python hibakeresőbe][pdb], a `PDB`-be.

```bash
$(my_venv) python3 -m pytest -o markers=task -x --ff --pdb <example_file_test.py>
=============== 4 passed in 0.15s ===============
```

Amikor egy teszt elbukik, a `PDB`-be beugorva lépésenként haladhatsz végig a kódodon, miközben az aktuális scope-ot látod, és megnézheted a változók értékét, valamint a különböző függvények szignatúráját.
A `PDB` modulról bővebb részleteket a [Python PDB-dokumentációjában][pdb] találsz.
Ezenkívül a [`pytest` PDB-ről szóló dokumentációja][pytest-pdb] és [ez az útmutató a Real Pythontól](https://realpython.com/python-debugging-pdb/) rendkívül hasznos.

## További információk

### A Python hozzáadása a PATH-hoz

**Megjegyzés:** Ha Windowson a [PSF Installer][psf-installer] segítségével telepítetted a Pythont, akkor a parancs `py` lesz a `python3` helyett.

Egy kicsit idegesítő lehet minden egyes modulfuttatásnál beírni, hogy `python3 -m`.
Ezt elkerülheted, ha a Python-telepítésed `Scripts` mappáját hozzáadod a PATH-hoz.
Ha nem tudod, hová telepítetted a Pythont, futtasd a következő parancsot a terminálban:

```bash
$ python3 -c "import os, sys; print(os.path.dirname(sys.executable))"
<python_directory>
```

A _visszaadott_ könyvtár az, ahová az éppen aktív Python-verziód telepítve van; ebben a szakaszban `<python_directory>` néven hivatkozunk rá.

#### Windows

Kattints a `Windows Start` gombra, keresd meg az _Edit the system environment variables_ elemet, és nyomj Entert.
Ezután nyomd meg az `Environment Variables...` gombot:

![Nyomd meg a kék gombot, lol](https://raw.githubusercontent.com/exercism/python/main/docs/img/Windows-SystemProperties.png)

Ezután keresd meg a `Path` változót a _User variables_ listában, jelöld ki, és kattints az `Edit...` gombra:

![A Path változó kijelölése](https://raw.githubusercontent.com/exercism/python/main/docs/img/Windows-EnvironmentVariables.png)

Ezután adj hozzá egy új sort a képen látható módon, a `<python_directory>` helyére pedig írd a Python-telepítésed könyvtárát:

![A Python hozzáadása a Path-hoz](https://raw.githubusercontent.com/exercism/python/main/docs/img/Windows-AddPythonPath.png)

#### MacOS/Linux

Az alábbiak a legtöbb Linux- és MacOS-változaton működnek `bash` shell esetén.
A parancsok Linux-disztribúciónként, valamint attól függően is eltérhetnek, hogy `fish` vagy `zsh` shellt használsz.
A `<python_directory>` helyére a `python3 -c "import os, sys; print(os.path.dirname(sys.executable))"` parancs kimenetét írd.

```bash
export PATH="$PATH:<python_directory>"
```
