# Utasítások

Ha Raspberry Pi segítségével szeretnél valamit építeni, valószínűleg _ellenállásokat_ fogsz használni.
Ehhez a feladathoz két dolgot kell tudnod róluk:

- Minden ellenállásnak van egy ellenállásértéke.
- Az ellenállások kicsik, olyannyira, hogy ha rájuk nyomtatnád az ellenállásértéket, nehezen lehetne elolvasni.

Hogy megkerüljék ezt a problémát, a gyártók színkódolt sávokat nyomtatnak az ellenállásokra, amelyek jelölik az ellenállásértéküket.
Minden sávnak van egy pozíciója és egy számértéke.

Az ellenállás első két sávja egyszerű kódolást követ: minden szín egyetlen számhoz rendelődik.

A harmadik sáv a szorzó.

Ebben a feladatban egy hasznos programot fogsz készíteni, hogy ne kelljen fejben tartanod a sávok értékeit.

Az ellenállások színkódolásáról bővebb információt az [elektronikus színkód Wikipédia-szócikkben][e-color-code] találsz.

## 1. Definiálj egy elnevezett vektort

A színek kódolása a következő:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

Hozd létre a `resistor_bands` elnevezett vektort, amelyben a színek a nevek, a számok pedig az értékek.

## 2. Add vissza egy sávhoz tartozó értéket

Először is jó lenne, ha meg tudnád keresni bármelyik színes sávhoz tartozó értéket.

Definiálj egy `band_value(band)` függvényt, amely egy `string`-et kap paraméterül, egy sáv színét.
A függvény visszaadja az adott színhez tartozó értéket.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. Add vissza két sávhoz tartozó értéket

Az ellenállás első két sávja együtt egyetlen számot alkot.
Ha az első két sávhoz tartozó szám `m`, illetve `n`, akkor együtt az `mn` számot adják.

Definiálj egy `two_band_value(bands)` függvényt, amely egy két sáv színét tartalmazó `string`-ekből álló `vector`-t kap.
A függvény visszaadja a két szín kombinációjához tartozó értéket.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. Add vissza mindhárom sávhoz tartozó ohmértéket

Végül meg kell határoznod a teljes ellenállásértéket ohmban, az első két sáv és a harmadik sáv együttes felhasználásával.
Ehhez meg kell keresned a kétsávos értéket és egy szorzót.
A szorzó úgy képzelhető el, mint ahány nullát a kétsávos érték végére fűzünk.

Definiálj egy `ohms(bands)` függvényt, amely egy három sáv színét tartalmazó `string`-ekből álló `vector`-t kap.
A függvény visszaadja a három szín kombinációjához tartozó ellenállásértéket ohmban.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
