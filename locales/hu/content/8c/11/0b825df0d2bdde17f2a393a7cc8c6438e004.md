# Bevezetés a parancsokba és argumentumokba

Ez a kurzus nem arról szól, hogyan használd a bash-t interaktív shellként.
Arról szól, hogy megtanulj programokat írni a bashben, a programozási nyelvben.

A bash program, vagyis a _szkript_, fájlban tárolt parancsok sorozata.
A bash (a futtatható fájl) beolvassa a fájlt, és sorrendben végrehajtja a parancsokat.

## A shebang

A szkript első sora általában egy _értelmeződirektíva_, más néven _hashbang_ vagy _shebang_:

```bash
#!/usr/bin/env bash
```

Amikor az operációs rendszer végrehajt egy nem bináris fájlt, beolvassa az első sort.
Ha a sor `#!`-tal kezdődik, a kernel ezt használja annak meghatározására, hogy melyik értelmező hajtsa végre a fájlt.
A `#!`-nak a fájl legeslegeljén kell állnia, előtte nem lehet szóköz vagy üres sor.

Itt az `env` a `PATH`-ban keresi a `bash` futtatható fájlt.
Találkozhatsz az egyszerűbb `#!/bin/bash` változattal is, amely beégeti az értelmező helyét; az `env`-es forma hordozhatóbb.

~~~~exercism/note
Ne hagyd, hogy megtévesszenek az interneten található olyan szkriptek vagy példák, amelyek `/bin/sh`-t használnak értelmezőként.
**A `sh` nem `bash`!**
A bash „sh-kompatibilis”, és a legtöbb `sh` szkriptet le tudja futtatni, de bizonyos bash-funkciók elromlanak vagy váratlanul viselkednek `sh`-ban.
~~~~

## Kommentek

A `#` karakterrel kezdődő sor _komment_, a bash figyelmen kívül hagyja.
A komment egy parancs után is állhat ugyanabban a sorban: a `#`-tól a sor végéig mindent figyelmen kívül hagy.
A kommentek a szkriptet olvasó embereknek szólnak.

## Szavak és argumentumok

A bash a bemenetéről olvassa a parancsokat (ami általában vagy egy terminál, vagy egy fájl).
Az általa beolvasott minden egyes sor _parancsnak_ számít, azaz egy végrehajtandó utasításnak.
(Néhány haladó eset, például a több soron átívelő parancsok, később kerül szóba.)

A bash minden parancsot **szavakra** bont, amelyeket whitespace-karakterek (szóközök és tabulátorok) határolnak.
Az első szó a végrehajtandó _parancs_ neve.
Az összes többi szó a parancs _argumentumaivá_ válik (opciók, fájlnevek stb.).

Egy parancs lehet bash-beépített parancs, például az `echo`, vagy _futtatható_ program, például a `head`, az `awk` vagy a `sed`.

## Az `echo` parancs

Az `echo` kiírja az argumentumait, egyetlen szóközzel elválasztva, és egy újsorral fejezi be:

```bash
echo flour sugar eggs
```

A kimenete:

```text
flour sugar eggs
```

Az argumentumok közötti whitespace mennyisége nem számít:

```bash
echo flour       sugar        eggs
```

```text
flour sugar eggs
```

Az `echo` argumentumok nélküli meghívása egy üres sort ír ki.

## Az opciók is argumentumok

Sok parancs elfogad _opciókat_, amelyek megváltoztatják a működésüket.
A bash számára az opció semmiben sem különleges: olyan szó, mint bármelyik másik, amelyet whitespace választ el a szomszédaitól.
Maguk a parancsok döntik el, hogyan értelmezzék az argumentumaikat.
A szokás szerint az opciók `-` jellel kezdődnek.

A `head` parancs egy fájl első sorait írja ki.
Ha adott egy `list.txt` fájl:

```bash
head -n 2 list.txt
```

A bash ezt a sort négy szóra bontja:

| Szó        | Szerep                                                       |
| ---------- | ------------------------------------------------------------ |
| `head`     | a végrehajtandó parancs                                      |
| `-n`       | opció, amely megmondja a `head`-nek, hogy _sorokat_ számoljon |
| `2`        | a `-n` opció értéke                                          |
| `list.txt` | a beolvasandó fájl                                           |

A bash változatlanul átadja az utolsó három szót a `head`-nek.
A `head` az, amely megérti, hogy a `-n`-et egy szám követi, és hogy a fennmaradó szó egy fájl.

Mivel a whitespace választja el egymástól a szavakat, számít, hova teszed.
A `head -n 2` két argumentumot ad a `head`-nek (`-n` és `2`), míg a `head -n2` egyet (`-n2`).
Sok parancs elfogadja mindkét formát, de ez a parancson múlik.
A bash-t ez nem érdekli; csak szavakra bontja a sort.

## Az argumentumok idézőjelbe tétele

Az [idézőjelek][Quotes] _egyetlen argumentummá_ fogják össze a szavakat.
Az idézőjeleken belüli whitespace megmarad, és maguk az idézőjel-karakterek nem részei az argumentumnak:

```bash
echo "flour       sugar        eggs"
```

```text
flour       sugar        eggs
```

Ha egy argumentum, például egy fájlnév whitespace-t tartalmaz, tedd idézőjelbe:

```bash
head -n 1 my shopping list.txt     # three files: "my", "shopping", "list.txt"
head -n 1 "my shopping list.txt"   # one file
```

## Szkript futtatása

Szkript futtatásához add át argumentumként a `bash` parancsnak:

```bash
bash myscript
```

Így használva a `#!` sor csupán egy komment.
Az operációs rendszernek mondod meg, hogyan futtassa a fájlt.

Másik lehetőség, hogy futtathatóvá jelölöd a szkriptfájlt, és úgy futtatod, mint bármely más programot:

```bash
chmod +x myscript
./myscript
```

Most az operációs rendszer a `#!` sor alapján határozza meg, melyik értelmezőt használja.
