# Telepítés

## Az R futtatókörnyezet telepítése
Látogasd meg a [CRAN kezdőlapját](https://cran.r-project.org/). Ott letöltési linkeket találsz Linuxhoz, Mac OSX-hez és Windowshoz. Töltsd le és futtasd az operációs rendszeredhez tartozó telepítőt.

## Az RStudio IDE telepítése (ajánlott)
Az RStudio egy népszerű, platformfüggetlen integrált fejlesztőkörnyezet (IDE) az R nyelvű programozáshoz (emellett más nyelveket is támogat, például a Pythont, a JavaScriptet és a Markdownt). Az RStudio használatával könnyebbé válik a kódmegoldásaid megírása és a tesztek futtatása.

Töltsd le és telepítsd az [RStudio aktuális stabil verzióját](https://www.rstudio.com/products/rstudio/download/). Vagy szerezd be egy közelgő kiadás [előzetes verzióját](https://www.rstudio.com/products/rstudio/download/preview/).

## A Visual Studio Code R-kiterjesztésének telepítése (alternatíva)
A Visual Studio Code R-kiterjesztése támogatja a bővített szintaxiskiemelést, a kódkiegészítést, a lintelést, a formázást, az R-terminálokkal való interakciót, az adatok, ábrák, munkaterület-változók és súgóoldalak megtekintését, a csomagok kezelését és az R Markdown dokumentumokkal való munkát.

Töltsd le és telepítsd az [R-kiterjesztés aktuális verzióját](https://code.visualstudio.com/docs/languages/r)

## Az R-csomagok telepítése a tesztek futtatásához
A specifikációk tesztfuttatója a Hadley Wickham-féle [`testthat`](https://github.com/hadley/testthat) könyvtár, amely népszerű választás az R-csomagok készítői körében.

A könyvtár telepítéséhez írd be a következőt az RStudio konzoljába (vagy bárhová, ahol éppen R-t használsz).

```{R}
install.packages("testthat")
```

Bár valószínűtlen, hogy _szükséged lesz_ csomagok telepítésére az Exercism feladatainak megoldásához, érdemes lehet behozni egy általános célú segédcsomagot, például a [`tidyverse`](https://github.com/tidyverse/tidyverse)-t, amely illik a programozási stílusodhoz. Egy `tidyverse`-hez hasonló csomag telepítéséhez és betöltéséhez:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
