# Tömbmetódusok

A tömbök gyakori adatszerkezetek, amelyekkel gyakran dolgozunk.
Ezért számos metódus áll rendelkezésre a tömbök kezeléséhez.
Többek között rendezésre, megfordításra, beszúrásra és még sok másra.

Ezek közül néhány destruktív, ami azt jelenti, hogy módosítja az eredeti tömböt.
Mások nem destruktívak, azaz új tömböt adnak vissza, és nem módosítják az eredetit.

Íme néhány a leggyakoribb metódus közül, amelyeket a tömbök kezelésekor használhatsz:

## insert

Amikor egy elemet szúrsz be egy tömbbe, használhatod az [`insert`][insert] metódust, amely egy indexet és egy elemet vár argumentumként.
Az elem a megadott indexre kerül, a tömb többi eleme pedig jobbra tolódik.
Ha az index kívül esik a tömb határain, akkor `IndexError` keletkezik.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Ha egy adott elemet szeretnél törölni egy tömbből, használhatod a [`delete`][delete] metódust, amely egy elemet vár argumentumként.
A metódus visszaadja az eltávolított elemet.
Ha az elem nem szerepel a tömbben, akkor `nil`-t ad vissza.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Ha egy tömb első vagy utolsó elemét szeretnéd megkapni, használhatod a [`first`][first] és a [`last`][last] metódust.
Ezek a metódusok egy opcionális argumentumot fogadnak, amely megadja, hány elemet adjanak vissza.
Ez javíthatja az olvashatóságot ahhoz képest, mintha a `0` vagy a `-1` indexet, vagy egy tartományt használnál.
Ha a tömb üres, akkor `Enumerable::EmptyError` keletkezik.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Ha meg szeretnél fordítani egy tömböt, használhatod a [`reverse`][reverse] metódust, amely egy új tömböt ad vissza, benne az elemekkel fordított sorrendben.
Fontos megjegyezni, hogy a `reverse` új tömböt ad vissza, és nem módosítja az eredeti tömböt.
Ha módosítani szeretnéd az eredeti tömböt, tegyél egy `!` jelet a metódus nevének végére.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## Concat(`+`)

A hozzáfűző metódus (`<<`) akkor hasznos, ha objektumokat szeretnél hozzáadni egy tömbhöz.
Két tömb összekapcsolásához azonban használhatod a [`+`][concat] operátort, amely egy új tömböt ad vissza, benne mindkét tömb elemeivel.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Ha egy tömböt fűzöl hozzá egy másik tömbhöz, akkor a tömb egyetlen elemként kerül hozzáadásra.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Ha azt szeretnéd ellenőrizni, hogy egy tömb üres-e, használhatod az [`empty?`][empty?] metódust, amely `true` értéket ad vissza, ha a tömb üres, és `false`-t egyébként.
Ez javítja az olvashatóságot ahhoz képest, mintha a tömb hosszát hasonlítanád össze a `0` értékkel.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Ha egy elem indexét szeretnéd megkapni egy tömbben, használhatod az [`index`][index] metódust, amely egy elemet vár argumentumként.
Ha az elem nem szerepel a tömbben, akkor `nil`-t ad vissza.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Ha szeretnéd tudni, hány elem van egy tömbben, használhatod a [`size`][size] metódust.

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Ha meg szeretnéd számolni, hogy egy elem hányszor fordul elő egy tömbben, használhatod a [`count`][count] metódust.

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Ha szeretnél rendezni egy tömböt, használhatod a [`sort`][sort] metódust, amely egy új tömböt ad vissza, benne a rendezett elemekkel.
A `reverse`-hez hasonlóan ez a metódus is új tömböt ad vissza, és nem módosítja az eredeti tömböt.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
