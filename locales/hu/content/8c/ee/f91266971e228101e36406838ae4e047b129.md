### Függvények exportálása

A függvények exportálásáról már az első fogalomban szó volt, itt egy gyors ismétlés következik.

Az Elmben minden fájl egy modul, és minden más kód előtt szerepelnie kell benne egy `module` utasításnak.

A modulneveknek meg kell egyezniük a fájlnevekkel, tehát a `Calculator` modulnak a Calculator.elm fájlban kell lennie, a `Parser.Utils` modulnak pedig a Parser/Utils.elm fájlban.

Minden, ami egy modulon belül van definiálva, csak azon a modulon belül érhető el, és kívülről nem lehet hozzáférni, hacsak nem szerepel az `exposing`-ban.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### Függvények importálása más modulokból

A más modulokban definiált függvényeket importokon keresztül éred el.
Amikor importálsz egy modult, minden olyan függvény elérhetővé válik, amelyet az a modul közzétett.
Az viszont, hogy hogyan éred el őket, attól függ, hogyan importáltad a modult.

Alapértelmezésben a minősített importot használjuk, és egy ilyen modulban lévő függvényt (például a `map` függvényt a `List` modulban) úgy érünk el, hogy a modul nevét írjuk elé (`List.map`).

A nyílt importok közvetlen hozzáférést adnak az adott modulban közzétett függvényekhez, előtag nélkül. Az `exposing` kulcsszóval valósulnak meg, mintegy tükörképeként az exportnál használtnak. Közzétehetsz minden elérhető függvényt (a `..` használatával), vagy csak bizonyosakat (például a `map`-et).

Más modulokból típusokat és azok konstruktorait is importálhatod, de ez egy későbbi fogalom.

A minősített importot részesítjük előnyben, mert átláthatóbb, és segít elkerülni a névütközéseket.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

### Típusannotációk

A típusannotációkat a `name : parameter types -> return type` formában adjuk meg, a paramétertípusokat szintén `->` választja el egymástól.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Zárójelekkel függvényparamétereket definiálhatunk (amelyek maguk is ugyanezzel a szintaxissal vannak megadva, innen a zárójelek szükségessége).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

### Számok

Az Elmben kétféle szám létezik, amelyeket az `Int` és a `Float` típus definiál.
Az `Int` a pozitív és negatív egész számok halmazának felel meg.
A `Float` a valós számok halmazának felel meg, a számítógép pontossága által korlátozva.
A számokon definiált műveletek általában az egyik vagy a másik típuson működnek, de nem keverik őket.
Léteznek függvények a kettő közötti átalakításra, mint például a `toFloat`, amely `Int`-et alakít `Float`-tá, valamint a `round`, `floor`, `ceiling` és `truncate`, amelyek egy `Float`-ot alakítanak `Int`-té, különböző szemantikával.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

### Stringműveletek

Szavak és mondatok leírására az Elmben van egy natív `String` típus.
A stringliterálokat idézőjelek közé írjuk, például `"Hello World!"`.
A stringösszefűző `++` operátor és az egyenlőségvizsgáló `==` operátor alapértelmezésben elérhető.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

A legtöbb egyéb stringfüggvény a `String` modulban van, amelyet importálni kell.

https://package.elm-lang.org/packages/elm/core/latest/String
