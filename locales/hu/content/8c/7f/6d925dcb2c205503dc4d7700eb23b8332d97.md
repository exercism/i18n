# Bevezetés

A `call` (a [`kernel`][kernel] szótárban) végrehajt egy quotationt. Amikor a quotation veremhatását nem lehet kikövetkeztetni, jellemzően azért, mert a quotation máshonnan származik, a `call` veremhatását explicit módon kell megadnod:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Mivel a quotationok értékek, egy tömb számok és quotationok keverékét is tartalmazhatja, így „egy program” csupán egy újabb sorozat:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
