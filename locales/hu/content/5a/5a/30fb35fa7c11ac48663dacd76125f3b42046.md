# Névjegy

A függvények egy vagy több argumentumhoz is deklarálhatnak [alapértelmezett értéket][default-arguments].

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- A fenti példa lefordításakor az Elixir létrehoz egy függvénydefiníciót a `number/0` (nincs argumentum) és a `number/1` (egy argumentum) számára.
- Ha egynél több argumentumnak van alapértelmezett értéke, az Elixir balról jobbra haladva alkalmazza őket, hogy pótolja a hiányzó argumentumokat.
- Ha a függvénynek több klauzulája van, az alapértelmezett argumentumokhoz kötelező [függvényfejlécet][function-header] írni.
- Alapértelmezett értékként bármilyen kifejezés állhat.
- A névtelen függvényeknek nem lehet alapértelmezett argumentumuk.

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
