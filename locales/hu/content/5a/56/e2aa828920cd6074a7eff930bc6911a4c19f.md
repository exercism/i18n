# Utasítások

Mary nagy rajongója a _Star Trek: The Next Generation_ tévésorozatnak. Gyakran játszik tollal és papírral játszható szerepjátékokat, amelyekben ő és a barátai a _Starship Enterprise_ legénységét alakítják. Mary karaktere Picard kapitány, ami azt jelenti, hogy neki kell vezetnie a kapitányi naplót. Imádja a játék kreatív részét, de nem szeret a helyszínen véletlenszerű adatokat generálni.

Segíts Marynek véletlenszerű generátorokat készíteni a kapitányi naplóban gyakran megjelenő adatokhoz.

## 1. Generálj egy véletlenszerű bolygót

A _Starship Enterprise_ útjai során sok bolygóval találkozik. A Star Trek univerzumában a bolygókat tulajdonságaik alapján kategóriákba sorolják. A Föld például egy M osztályú bolygó. Az összes lehetséges bolygóosztály: D, H, J, K, L, M, N, R, T és Y.

Implementáld a `random_planet_class/0` függvényt. A bolygóosztályok egyikét kell véletlenszerűen visszaadnia.

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. Generálj egy véletlenszerű csillaghajó-lajstromszámot

Az Enterprise (lajstromszáma NCC-1701) nem az egyetlen csillaghajó, amelyik az űrben repked! Amikor egy másik csillaghajóval találkozik, Marynek naplóznia kell annak a csillaghajónak a lajstromszámát.

A lajstromszámok az „NCC-” előtaggal kezdődnek, majd egy 1000 és 9999 közötti (a határokat is beleértve) szám következik.

Implementáld a `random_ship_registry_number/0` függvényt, amely egy véletlenszerű csillaghajó-lajstromszámot ad vissza.

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. Generálj egy véletlenszerű csillagidőt

Mi értelme a naplónak, ha nem tartalmaz dátumokat?

A csillagidő egy lebegőpontos szám. A _Starship Enterprise_ kalandjai a _The Next Generation_ első évadában a 41000.0 és 42000.0 közötti csillagidőkben játszódnak. A „4” a 24. századot jelöli, az „1” pedig az első évadot.

Implementáld a `random_stardate/0` függvényt, amely egy 41000.0 (a határt is beleértve) és 42000.0 (a határt kizárva) közötti lebegőpontos számot ad vissza.

Az implementációhoz egy Erlang-függvényt kell használni.

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. Formázd a csillagidőt

A kapitányi naplóban a csillagidőket általában egyetlen tizedesjegyre kerekítik.

Implementáld a `format_stardate/1` függvényt, amely egy lebegőpontos számot kap, és egy stringet ad vissza a szám egyetlen tizedesjegyre kerekített értékével.

Az implementációhoz egy Erlang-függvényt kell használni.

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
