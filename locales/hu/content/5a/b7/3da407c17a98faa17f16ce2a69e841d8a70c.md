# Char

A `Char` egy adattípus a Crystalben, amely egy 32 bites [Unicode][unicode] kódpontot reprezentál.
A méretük memóriahatékonnyá teszi őket, és olyan tulajdonságokat ad nekik, amelyekkel a String nem rendelkezik.
Aposztrófokkal (`'`) hozod létre őket, és csak egyetlen Unicode-kódpont kerülhet beléjük.

```crystal
'a' # => 'a'
'a'.class # => Char
```

A Crystalben meglehetősen gyakori, hogy Char-okkal dolgozol, amikor Stringekkel foglalkozol, mert a String osztály jó néhány metódusa Char-t ad vissza, vagy Char-t vár argumentumként.
Például a [`String#[]`][index] metódus egy Char-t ad vissza, a [`String#chars`][chars] metódus pedig Char-ok gyűjteményét.

## Növelés / csökkentés

Mivel a Char egy 32 bites Unicode-kódpont, támogatja a növelést és a csökkentést, így ha a `'a'` karaktered van, egyet hozzáadva megkapod a `'b'`-t.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Létezik egy [`Char#succ`][succ] nevű metódus is, amely a Unicode-táblázat következő karakterét adja vissza, és a [`Char#pred`][pred] is, amely az előző karakterét.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Összefűzés

Mivel a Char csak egy 32 bites Unicode-kódpont reprezentálására szolgál, két Char nem fűzhető össze.
Ezért a Char csak Stringekkel fűzhető össze.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Tulajdonságvizsgáló metódusok

A Crystalben néhány metódus segít információt szerezni egy karakterről, például hogy szám-e vagy betű, illetve hogy kis- vagy nagybetű-e.
Íme néhány a metódusok közül, a teljes listát a [Char API][char-api] oldalon találod:

| Method                           | Description                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | `true` értéket ad vissza, ha a Char szám               |
| [`Char#letter?`][letter]         | `true` értéket ad vissza, ha a Char betű               |
| [`Char#lowercase?`][lowercase]   | `true` értéket ad vissza, ha a Char kisbetű            |
| [`Char#uppercase?`][uppercase]   | `true` értéket ad vissza, ha a Char nagybetű           |
| [`Char#ascii?`][ascii]           | `true` értéket ad vissza, ha a Char ASCII-karakter     |
| [`Char#whitespace?`][whitespace] | `true` értéket ad vissza, ha a Char whitespace-karakter |

## Konvertálás

### Konvertálás kódpontok és Char-ok között

Mivel a Char egy 32 bites Unicode-kódpont, átválthatsz Char-ok és kódpontok (Int) között.
Erre a [`Char#ord`][ord] metódus használható, amely a Char kódpontját adja vissza, vagy az [`Int#chr`][chr] metódus, amely a kódpont Char-ját adja vissza.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Konvertálás típusok között

Ahogy a többi adattípusnál, a Char-oknál is van néhány metódus a típusok közötti átalakításra.
A leggyakoribb a `Char#to_s` metódus, amely a Char-t Stringgé alakítja. De van a `Char#to_i` metódus is, amely a Char-t Int-té alakítja, és a `Char#to_f` metódus, amely a Char-t Float-tá alakítja.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Escape-elés

Ahogy a Stringeknél, itt is vannak olyan karakterek, amelyeket nem lehet közvetlenül leírni, és ezek leírásához escape-elni kell őket.
A `\` karakterrel escape-szekvenciát írhatsz, amelyet az escape-elni kívánt karakter követ.

Ezek a speciális karakterek a Crystalben:

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | Riasztás                      |
| `\b`     | Visszatörlés                  |
| `\e`     | Escape                        |
| `\f`     | Lapdobás                      |
| `\n`     | Soremelés vagy új sor         |
| `\r`     | Kocsivissza                   |
| `\t`     | Vízszintes tabulátor          |
| `\v`     | Függőleges tabulátor          |
| `\\`     | Fordított perjel              |
| `\'`     | Aposztróf                     |
| `\"`     | Idézőjel                      |
| `\377`   | Oktális ASCII-karakter        |
| `\xFF`   | Hexadecimális ASCII-karakter  |
| `\uFFFF` | Hexadecimális Unicode-karakter |
