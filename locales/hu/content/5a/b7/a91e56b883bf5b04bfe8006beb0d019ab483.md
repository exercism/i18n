# Bevezetés

## Boolean értékek R-ben

Az igaz és hamis értékeket a `logical` típus képviseli.
Ez csak két értéket tartalmaz: `TRUE` és `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Boolean operátorok

R-ben öt Boolean operátor van, de a tanterv ezen a pontján csak három játszik szerepet.
A másik kettő majd a vektorokkal való munka során lesz fontos, amelyekről több későbbi fogalomban is szó lesz.

A `&&` a Boolean „és”.
Eredménye `TRUE`, ha a `&&` *mindkét* oldalán lévő kifejezés `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

A `||` a Boolean „vagy”.
Eredménye `TRUE`, ha a `||` *bármelyik* oldalán lévő kifejezés `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

A `!` a Boolean „nem”.
Felcseréli a `TRUE` és `FALSE` értékeket.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Hosszabb és bonyolultabb kifejezéseknél a legjobb, ha zárójelekkel teszed egyértelművé a szándékodat.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
