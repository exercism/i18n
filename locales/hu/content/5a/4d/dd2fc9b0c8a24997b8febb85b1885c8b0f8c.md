# Bevezetés

A blokk utasítások és deklarációk egyetlen szintaktikai egységbe csoportosított halmaza.
A blokkokat gyakran, de nem mindig kapcsos zárójelben definiáljuk.
A blokkok függvényeken belül és más blokkokon belül is egymásba ágyazhatók.

A függvény némileg úgy viselkedik, mint egy blokk.
Egy függvényben definiált változó azonosítója a függvényen kívülről nem látható, ahogy egy blokkban definiált változó azonosítója sem látható a blokkon kívülről.
Két függvényben lévő két változónak lehet ugyanaz a neve, mert a két függvény nem lát bele a másikba, ahogy két blokkban lévő két változónak is lehet ugyanaz a neve, mert a két blokk nem lát bele a másikba.
A függvények és a blokkok azonban nem azonosak.
Egy függvényt nem lehet egy másik függvénybe ágyazni, egy blokkot viszont be lehet ágyazni egy másik blokkba.

A következő példában a `number` a `main` függvényen belül van definiálva.
A `flag` pedig a `main` függvényen belül egymásba ágyazott `if` blokkban van definiálva.
A blokkon belül definiált változók csak azon a blokkon belül érvényesek.
Ezért a kód lefordítására tett kísérlet fordítási hibát eredményez.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

A hibaüzenet megtévesztő lehet, hiszen a `flag` _már_ korábban szerepel a függvényben.
A `flag` azonban a függvényen belüli blokkban van definiálva.
A belső blokk „látja” a külső függvény `number` változóját, a külső függvény viszont nem „látja” a belső blokkjában definiált `flag` változót.
Amint a végrehajtás kilép a blokkból, a `flag` változó automatikusan megsemmisül, és a program számára többé nem elérhető.
A `main` függvény maga először az utolsó `printf` utasításban látja meg a `flag` azonosítót.
Ha eltávolítjuk az utolsó `printf` utasítást, a program lefordul, és futtatáskor `1`-et ír ki.
Ez azért van, mert a `flag` változó érvényes az első `printf` utasítást tartalmazó blokkban.

A `C99`-től kezdve az egysoros `if`, `for`, `while` és `do` utasításokat is blokknak tekintjük.
A következő példában bár az `i` nincs kapcsos zárójelben definiálva, csak a `for` utasítás által definiált blokkban létezik, és a külső `main` függvény nem látja.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

Ha eltávolítjuk az utolsó `printf` utasítást, a program lefordul, és futtatáskor a `0 2 4 6 8 10 ` szöveget írja ki.
Egyes nyelvek, például a Go és a Rust, egyértelműen kimondják, hogy az egysoros feltételes és ciklusutasítások is blokkot alkotnak.
Megkövetelik, hogy az ilyen egysoros utasításokat is kapcsos zárójelbe zárjuk.
