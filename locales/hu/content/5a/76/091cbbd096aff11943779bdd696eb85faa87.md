## General

- Egy string definiálásához használhatsz kettős idézőjelet: `"`.
- Stringek összefűzéséhez használhatod a `+` operátort.
- A `#{}` segítségével be tudsz interpolálni egy stringet.

## 1. Köszöntsd az új vendéget a buliban

- Egy string összefűzhető egy másik stringgel a `+` operátor segítségével.

## 2. Köszöntsd azt az új vendéget, akinek ma van a születésnapja

- Egy szám stringgé alakításához használhatod a `to_s` metódust.

## 3. Adj útbaigazítást

- Egy szám kerekítéséhez használhatod a `round` metódust.
- Egy string adott karakterének eléréséhez használhatod a `[]` metódust, amelynek egy egész számot kell átadnod, ez pedig egy index.
