# SQLite-specifikus utasítások

* A **digits** oszlop egész számok JSON-kódolt listáját tartalmazza.
  Például:
  ```json
  [1,0,1,0,1,0]
  ```
* A **result** oszlopnak JSON-kódolt adatot kell tartalmaznia: egy objektumot, amelyben a számjegyek egész számként szerepelnek, vagy bármely hiba leírását.
  Például:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  vagy
  ```json
  {"error":"some error description"}
  ```

## Táblaséma

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
