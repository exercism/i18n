# Bevezetés

## Első lépések

### Változók

Az értékek nevekhez rendelhetők, ha definiálsz egy [változót][constants-variables], és értéket rendelsz hozzá. Ez a név ezután a program teljes futása során arra az értékre hivatkozik. A változók _módosíthatók_, ami azt jelenti, hogy az értékük bármikor megváltoztatható.

A változókat a `var` kulcsszóval definiálod.

```swift
var variableName = 10
```

A Swift típusbiztos, statikusan típusos nyelv, ami azt jelenti, hogy minden értéknek van típusa fordítási időben. A változó típusát vagy explicit módon megadhatod [típusannotációval][type annotations], vagy hagyhatod, hogy a fordító [kikövetkeztesse a típust][type-inferring].

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

Egy változó értékének frissítése a `=` operátorral történik.

~~~~exercism/note
A változó típusa az első definiálás után rögzül.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

A változókat deklarálhatod úgy is, hogy csak a nevet és a típust adod meg, érték hozzárendelése nélkül, de nem használhatod őket addig, amíg nem kapnak értéket.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Konstansok

A [konstansok][constants-variables] abban hasonlítanak a változókhoz, hogy egy névhez és egy értékhez kapcsolódnak, de a konstans értéke az első hozzárendelés után nem változtatható meg, így _változtathatatlan_. A konstansokat a `let` kulcsszóval definiálod.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Összeadás, kivonás és szorzás

A Swiftben [operátorok][arithmetical-operators] állnak rendelkezésre az összeadáshoz, a kivonáshoz és a szorzáshoz. Ezek az operátorok rendre a `+`, a `-` és a `*`.
  
```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Függvények

A Swiftben a [függvények][functions] olyan kódrészek, amelyek egy feladatot hajtanak végre. A függvénynek van visszatérési típusa, így értékként is használható, és argumentumként átadható más függvényeknek. A Swiftben a függvényeket a `func` kulcsszóval definiálod, amelyet a függvény neve, vesszővel elválasztott argumentumok és egy visszatérési típus követ.

Az argumentumokat egy argumentumcímke, valamint egy paraméternév határozza meg, amelyet kettőspont és egy típus követ. A visszatérési típust egy `->` jelöli, amelyet a visszatérési érték típusa követ.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

A Swift argumentumai kicsit különlegesek a többi nyelvhez képest: [argumentumcímkéket][argument-labels] használnak. Az argumentumcímkét a függvény hívásakor használod. A paraméternév a függvény törzsén belül arra szolgál, hogy az argumentum értékére hivatkozz. Ha csak egy nevet adsz az argumentumnak, az lesz egyszerre az argumentumcímke és a paraméternév. Ha az argumentumcímke neve `_`, akkor a függvény hívásakor az argumentumnak nem lesz címkéje, például: `functionName(argumentValue)`

Egy függvény hívásához a függvény nevét, majd az argumentumcímkét és az argumentum értékét írod le, így:

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Az argumentumok alapértelmezés szerint változtathatatlanok, és a függvényen belül nem módosíthatók. Ha egy függvénynek van visszatérési típusa, mindenképp olyan értéket adj vissza, amely megfelel annak a típusnak. Ezt a `return` kulcsszóval teszed, amelyet a visszaadni kívánt érték követ.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Ha a függvények nem adnak vissza értéket, a visszatérési típusuk `Void`, ami megegyezik a `()`-tal, de ezekben az esetekben a visszatérési típus el is hagyható.
