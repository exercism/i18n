# Bevezetés

## Névtelen függvények

A Gleamben a függvények első osztályú értékek, ami azt jelenti, hogy olyan értékek, mint bármely más: hozzárendelhetők változókhoz, argumentumként adhatók át, és más függvények visszaadhatják őket.

Egy modulban definiált nevesített függvényre a nevével hivatkozhatunk.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

A Gleamben névtelen függvények is vannak, amelyeket más függvényeken belül definiálunk.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Egy függvény típusát a névtelen függvényekéhez hasonló szintaxissal adjuk meg. Egy olyan függvény típusát, amely egy `Int`-et és egy `Float`-ot kap, és egy `Int`-et ad vissza, így írjuk le:

```gleam
fn(Int, Float) -> Int
```

A névtelen függvények hivatkozhatnak olyan változókra, amelyek a definiálásuk idején a scope-ban voltak, ezáltal _closure_-ökké válnak.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

A _function capture_ szintaxis kényelmes rövidítést kínál olyan névtelen függvények létrehozásához, amelyek egyetlen argumentumot adnak át egy függvénynek. Ez a két kifejezés egyenértékű:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
