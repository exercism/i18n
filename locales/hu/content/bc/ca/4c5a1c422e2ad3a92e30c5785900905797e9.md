# Karbantartói repo-jogosultságok

Egy kurzus karbantartója az, aki tagja a kurzus GitHub-csapatának.
A kurzus csapatába csak _meghívóval_ lehet bekerülni.

```exercism/note
Ha szeretnél kurzuskarbantartó lenni, nyiss egy témát a [fórumon](https://forum.exercism.org/c/exercism/building-exercism/125).
```

## Karbantartási kategória

Öt karbantartási kategória van:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

A kurzusok karbantartási kategóriáját három változó határozza meg:

1. Aktív-e a kurzus (azaz csatlakozhatnak-e a tanulók a kurzushoz a weboldalon)
2. A kurzuskarbantartók száma
3. Azoknak a kurzuskarbantartóknak a száma, akik tagjai a `cross-track-maintainers` GitHub-csapatnak is

A karbantartási kategória meghatározásához keresd meg a táblázatban az első olyan kategóriát, amelyik illik a kurzusra:

| Kategória             | Aktív? | Karbantartók száma | Cross-track karbantartók száma |
| --------------------- | ------ | ------------------ | ------------------------------ |
| wip-track             | Nem    | Bármennyi          | Bármennyi                      |
| unmaintained          | Igen   | 0                  | 0                              |
| maintained-autonomous | Igen   | > 0                | = a karbantartók száma         |
| maintained-solitary   | Igen   | 1                  | 0                              |
| maintained            | Igen   | > 1                | < a karbantartók száma         |

## Repo-jogosultságok

A karbantartási kategória alapján állítjuk be a kurzus GitHub-repója (repói) jogosultságait.

| Kategória             | PR szükséges | PR-jóváhagyás szükséges | Cross-track csapatok áttekintése |
| --------------------- | ------------ | ----------------------- | -------------------------------- |
| wip-track             | Nem          | Nem                     | Nem                              |
| unmaintained          | Igen         | Igen                    | Igen                             |
| maintained-solitary   | Igen         | Igen                    | Igen                             |
| maintained-autonomous | Igen         | Nem                     | Nem                              |
| maintained            | Igen         | Nem                     | Nem                              |

```exercism/caution
A `wip-track` az egyetlen kategória, amelyben a karbantartók pusholhatnak a `main` ágra.
```

```exercism/caution
A tooling-repók _mindig_ megkövetelik a PR jóváhagyását, mert a tartalmukat egy [CODEOWNERS-fájl](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners) védi.
```
