# Bemutató

Az Elixirben kétféle szám létezik: egész számok és tizedes törtek.

Az egész számok olyan számok, amelyeknek nincs törtrészük.

```elixir
integer = 3
# => 3
```

Az egész számokkal való munkához néhány hasznos függvényt az [`Integer`][integer] modulban találsz.

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

A nagy egész számokat (de a tizedes törteket is) általában úgy formázzuk, hogy minden három számjegyet aláhúzással választunk el egymástól, csoportokba rendezve.

```elixir
1_000_000
# => 1000000
```

Az Elixirben a számok maximális méretét csak a rendszeren rendelkezésre álló memória korlátozza, mert az Elixir [tetszőleges pontosságú aritmetikát][arbitrary-precision-arithmetic] használ.

Az Elixir emellett rövidített jelöléseket is támogat a [bináris, oktális és hexadecimális egész számok][integers-in-other-bases] beírásához.

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Összehasonlítás

Az egész számok és a tizedes törtek egyenlőnek tekinthetők ([`==`][kernel-equal]), ha ugyanaz az értékük. Mivel azonban különböző típusúak, soha nem szigorúan egyenlők ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
