# Bevezetés

A Unison az igaz és hamis értékeket a `Boolean` típussal ábrázolja. Mindössze két érték létezik: `true` és `false`.

```unison
trueVariable = true
falseVariable = false
```

A logikai kifejezéseket három operátorral értékelhetjük ki: az és operátor jele `&&`, a vagyé `||`, a nemé pedig `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

A Unison logikai kifejezéseinél lehetőség van rövidre záró kiértékelésre: ha egy `&&` kifejezés első argumentuma `false`, nincs ok arra, hogy folytassuk a második argumentum kiértékelését.
Hasonlóképpen, ha egy `||` kifejezés első argumentuma `true`, a kifejezés azonnal `true` értéket ad vissza.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
