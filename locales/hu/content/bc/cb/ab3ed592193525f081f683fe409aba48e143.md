# Bevezetés

A switch-kifejezés egy értéket a minták egy halmazának valamelyik esetéhez párosíthat, majd visszaadja a hozzá tartozó értéket, vagy végrehajtja a hozzá tartozó műveletet. A hozzárendelést a `=>` szimbólum jelöli. Ezen kívül minden mintához tartozhat egy opcionális esetőr, amelyet a `when` kulcsszó vezet be. Az esetőr kifejezésnek igazra kell kiértékelődnie ahhoz, hogy a switch adott „ágát” kiválassza a program. Az eseteket (más néven _switch-ágakat_) szöveges sorrendben értékeli ki a program, és amint egyezést talál, azonnal leáll, és visszaadja a hozzá tartozó értéket.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
