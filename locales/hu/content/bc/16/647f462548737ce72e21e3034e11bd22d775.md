# Bevezetés

A tuple névtelen, de sorrenddel rendelkező értékek _módosíthatatlan_ csoportja.
A tuple bármilyen adattípust (vagy akár többfélét is) tárolhat, köztük más tuple-öket is.

A tuple-t vesszővel elválasztott értékek alkotják, amelyeket a `(` és a `)` karakterek közé írsz: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Csak az azonos hosszúságú és azonos típusú (azonos sorrendben lévő) tuple-ök hasonlíthatók össze.
A tuple-öknél strukturális egyenlőség érvényes, ami azt jelenti, hogy akkor és _csak_ akkor egyenlők, ha minden értékük egyenlő.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Háromféleképpen nyerhetsz ki értékeket egy tuple-ből:

- Az `fst` és `snd` függvény
- A tuple szétbontása
- Mintailesztés

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
