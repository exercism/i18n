# Tippek

## Általános

- Három Boolean operátor áll rendelkezésre a Boolean értékekkel való munkához: `not`, `&&` és `||`.
- Egyetlen kifejezésben több operátort is kombinálhatsz.

## 1. Határozd meg, hogy a pac-man megehet-e egy szellemet

- A függvénynek `Bool` értéket kell visszaadnia.
- A `&&` Boolean operátorral kombinálhatod össze az argumentumokat, hogy megkapd az eredményt.

## 2. Határozd meg, hogy a pac-man pontot szerez-e

- A függvénynek `Bool` értéket kell visszaadnia.
- A `||` Boolean operátorral kombinálhatod össze az argumentumokat, hogy megkapd az eredményt.

## 3. Határozd meg, hogy a pac-man veszít-e

- A függvénynek `Bool` értéket kell visszaadnia.
- A `&&` és `not` Boolean operátorokkal kombinálhatod össze az argumentumokat, hogy megkapd az eredményt.

## 4. Határozd meg, hogy a pac-man nyer-e

- A függvénynek `Bool` értéket kell visszaadnia.
- A `&&` és `not` Boolean operátorokkal kombinálhatod össze az argumentumokat, valamint az egyik korábban implementált függvény eredményét.
