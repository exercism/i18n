# Utasítások

Ozan lejátszási listát állít össze egy közelgő kirándulásra. Nem szeretné ugyanazt a számot kétszer meghallgatni, a lista viszont olyan hosszúra nyúlt, hogy már alig emlékszik rá, mely számok kerültek már rá.

Ozan zenelejátszójának API-ja csak tömbökkel tud dolgozni, ezért megpróbál olyan kódot írni, amely a `Array.indexOf()` metódussal ellenőrzi, hogy egy szám szerepel-e már a listán, mielőtt hozzáadná. Sajnos a programja túl sokáig fut. Szüksége van a segítségedre!

Amikor Ozan segítségére sietsz, döbbenten látod, hogy a listáján _félmillió_ szám van. Talán ismersz egy másik adatszerkezetet, amellyel hatékonyabban kezelheted a lejátszási listát?

## 1. Az ismétlődő számok eltávolítása

Valósítsd meg a `removeDuplicates` függvényt, amely egy lejátszási listát vesz át _paraméterként_, és egy új lejátszási listát _ad vissza_, amelyben minden szám egyedi.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. Annak ellenőrzése, hogy egy számot már hozzáadtak-e

Valósítsd meg a `hasTrack` függvényt, amely egy lejátszási listát és egy számot vesz át _paraméterként_, és egy Boolean értéket _ad vissza_, amely megmutatja, hogy a lejátszási lista tartalmazza-e a számot.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. Egy szám hozzáadása

Valósítsd meg az `addTrack` függvényt, amely egy lejátszási listát és egy számot vesz át _paraméterként_, és egy új lejátszási listát _ad vissza_, amely tartalmazza a számot.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. Egy szám törlése

Valósítsd meg a `deleteTrack` függvényt, amely egy lejátszási listát és egy számot vesz át _paraméterként_, és egy új lejátszási listát _ad vissza_, amely nem tartalmazza a számot.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. Az egyedi előadók listázása

Valósítsd meg a `listArtists` függvényt, amely egy lejátszási listát vesz át _paraméterként_, és _visszaadja_ a lejátszási listán szereplő egyedi előadók listáját. Figyeld meg, hogy a számok nevei a következő formátumban vannak: `<SONG> - <ARTIST>`.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
