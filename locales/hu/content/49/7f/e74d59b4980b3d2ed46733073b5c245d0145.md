# Utasítások

Alakítsd át a stringként megadott bináris számot (pl. „101010”) a tízes számrendszerbeli megfelelőjévé, az alapoktól kiindulva.

Valósítsd meg a binárisból tízes számrendszerbe történő átalakítást. A program egy bináris bemeneti stringből tízes számrendszerbeli kimenetet állítson elő. A programnak az érvénytelen bemeneteket is kezelnie kell.

## Megjegyzés

- Az átalakítást magad valósítsd meg.
  Ne használj mást arra, hogy elvégezze helyetted az átalakítást.

## A binárisról (2-es alap)

A tízes számrendszer 10-es alapú.

A 23-as szám a 10-es alapú jelölésben felfogható a 10 hatványainak lineáris kombinációjaként:

- A jobb szélső számjegyet 10^0 = 1-gyel szorozzuk
- A következő számjegyet 10^1 = 10-zel szorozzuk
- ...
- Az *n*-edik számjegyet 10^_(n-1)_-gyel szorozzuk.
- Végül ezeket az értékeket összeadjuk.

Tehát: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

A bináris hasonló, csak nem a 10, hanem a 2 hatványait használja.

Tehát: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
