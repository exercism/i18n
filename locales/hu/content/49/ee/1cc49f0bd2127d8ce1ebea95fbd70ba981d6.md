# Bevezetés

Az AWK egy nagyon kicsi nyelv, és csak néhány alapvető adattípusa van.
Ebben a leckében a számokról és a stringekről lesz szó.

## Számok

Az AWK-ban a számok dupla pontosságú lebegőpontos számként vannak megvalósítva.
Nem tesz különbséget egész számok, lebegőpontos számok és dupla pontosságú számok között.

Az AWK ismeri a nyolcas számrendszerbeli számkonstansokat (amelyek `0`-val kezdődnek) és a tizenhatos számrendszerbelieket (amelyek `0x`-szel vagy `0X`-szel kezdődnek).

### Numerikus műveletek

Használhatod a szabványos aritmetikai operátorokat: `+`, `-`, `*`, `/`, `%`.
A hatványozás operátora a `^`.
Van néhány beépített numerikus függvény, köztük trigonometrikus függvények, véletlenszám-generálás, valamint az `int(x)`, amely egy számot az _x_ és a nulla közötti legközelebbi egész számra csonkít.

## Stringek

Az AWK stringjei karakterek sorozatai.
A stringkonstanst kettős idézőjelek közé írva adod meg.

### Stringműveletek

Csak egyetlen stringművelet létezik: az összefűzés.
Az összefűzésnek nincs külön operátora;
egyszerűen egymás mellé írsz két stringet, és azok összefűződnek:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
A `print` egy **utasítás**, nem függvény.
A `print` nem igényel zárójelet.
~~~~

Az AWK rengeteg stringkezelő függvénnyel rendelkezik.
Ezekkel részletesen megismerkedünk majd, ahogy haladunk a kurzuson.

## Számok és stringek közötti átalakítás

Nincsenek explicit operátorok a számok és a stringek közötti átalakításra.
Az AWK ezt implicit módon végzi el a program kontextusa alapján.
Ez nagyon egyszerűvé teszi a bemeneti mezőértékekkel való munkát: az AWK általában pontosan azt teszi, amit szeretnél.

* A `print x + y` az `x` és `y` változók értékét számmá alakítja a `+` numerikus műveletnek köszönhetően.
* A `print x y` az `x` és `y` változók értékét stringgé alakítja az összefűzés műveletének köszönhetően.

Ha szeretnél ebben explicit lenni, a `0 + x` az _x_ számreprezentációját adja, a `"" x` pedig az _x_ stringreprezentációját.

### Stringekből számokká

Zavaró lehet, ahogyan az AWK egy stringet számmá alakít.
Egyszerű gondolatmenet: az AWK a string elejétől kezdve „számkaraktereket” olvas, amíg nem talál egy „nem szám” karaktert.
Néhány példa:

* A `"2.5"` a `2.5` számmá alakul;
* A `"1e3"` az `1000` számmá alakul (tudományos jelölés);
* A `"456abc"` a `456` számmá alakul (mert az `a` nem „számjegy”, itt megáll az átalakítás).
* A `"abc789"` a `0` számmá alakul (a string **elején** nincsenek számok).
