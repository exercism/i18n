# Részletesen

A Factor a véletlenszerűséget a [`random`][random] vocabulary egyetlen generikus word köré összpontosítja:

```
random ( obj -- elt )
```

Az argumentum alapján választja ki a megfelelő viselkedést:

- egy **egész szám** `n` egy véletlen egész számot ad a `[0, n)` intervallumból;
- egy **sorozat** egy véletlen elemet ad vissza;
- az assoc, a hash-set és a `uniform-distribution` tuple is támogatott.

Erre két, sorozatokhoz készült segédword épül:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

A `randomize` módosítja a sorozatot, és vissza is adja, ezért ha meg akarod őrizni az eredeti sorrendet, előbb hívd meg a `clone`-t.

## Honnan származik a véletlenszerűség?

A `random` azt a generátort olvassa, amelyet a `random-generator` dinamikus változó tárol. Alapértelmezés szerint ez egy Mersenne Twister, amelynek a kezdőértékét a rendszeróra adja, így folyamatonként más lesz. Egy quotation erejéig más generátort is beállíthatsz:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

Mivel a `with-random` egyszerűen csak a quotation lefutásáig köti a `random-generator`-t, az ezt becsomagoló wordöt érdemes `inline`-ként megjelölni, hogy a quotation a hívó számára a stacken hagyhassa az eredményét.

Ezeken kívül a `random` más eloszlásokhoz olyan wordöket kínál, mint a `random-bits`, a `random-unit`, a `uniform-random` és a `normal-random`, a nem reprodukálható és a kriptográfiai igényekhez pedig a `system-random-generator` és a `secure-random-generator`.
