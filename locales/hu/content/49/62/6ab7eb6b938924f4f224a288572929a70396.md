# Utasítások

Ebben a feladatban egy mérleget fogsz modellezni.

## 1. Hozd létre a mérleg kezdeti állapotát

Inicializáláskor a mérlegnek a gyári beállításaira kell támaszkodnia, amelyek attól függően térnek el, hogy hol árulják a gépet.
Ennek megfelelően a mérleget egy pontossággal lehet inicializálni, valamint azzal, hogy metrikus vagy angolszász mértékegységrendszert használ.

Valósítsd meg a `WeighingMachine#initialize` metódust, amely két argumentumot vár: a `precision` nevűt, ami egy `Int32`, és a `metric` nevűt, ami egy `Bool`.
A `metric` argumentum `true` értéke azt jelenti, hogy a mérlegnek a metrikus rendszert kell használnia, egyébként az angolszász rendszert.
Az initialize metódusnak emellett a `@weight` példányváltozót is `0.0`-ra kell állítania.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. Tedd lehetővé, hogy a mérlegnek pontossága legyen

Hogy a különböző igényeket kiszolgáljuk, minden mérleget testre szabhatunk egy pontossággal (a tizedesjel utáni számjegyek számával).

Valósítsd meg a `WeighingMachine#precision` getter metódust, amely visszaadja a mérleg pontosságát.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. Tedd lehetővé, hogy a mérlegen beállítható legyen a súly

Valósítsd meg a `WeighingMachine#weight` tulajdonságot, hogy a súlyt le lehessen kérdezni _és_ be is lehessen állítani:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. Tedd lehetővé, hogy a gép váltson a metrikus és az angolszász mértékegységek között

Valósítsd meg a `WeighingMachine#metric=` tulajdonságot, hogy a mértékegységet be lehessen állítani.
Boolean értéket kell elfogadnia.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
