# Utasítások

Ebben a feladatban egy számkitalálós játékot játszol egy barátoddal. A szabályok egyszerűek: titokban választasz egy számot `1` és `100` között, és a barátod megpróbálja kitalálni, hogy melyik számot választottad. Hogy segíts a barátodnak, különbözőképpen válaszolsz attól függően, hogy mennyire volt közel a tipp a választott számodhoz (`42`). Ezek a szabályok a különböző válaszokhoz:

- Ha a tipp `42`: "Correct"
- Ha a tipp `41` vagy `43`: "So close"
- Ha a tipp kevesebb, mint `41`: "Too low"
- Ha a tipp nagyobb, mint `43`: "Too high"

Négy feladatod van, hogy kódold a tippekre adott válaszokat.

## 1. Válasz egy helyes tippre

Valósítsd meg a `reply` függvényt, hogy válaszolj egy helyes tippre:

```gleam
reply(42)
// -> "Correct"
```

## 2. Válasz egy közeli tippre

Módosítsd a `reply` függvényt, hogy válaszolj a közeli tippekre:

```gleam
reply(41)
// -> "So close"
```

## 3. Válasz a túl alacsony tippekre

Módosítsd a `reply` függvényt, hogy válaszolj a túl alacsony tippekre:

```gleam
reply(25)
// -> "Too low"
```

## 4. Válasz a túl magas tippekre

Módosítsd a `reply` függvényt, hogy válaszolj a túl magas tippekre:

```gleam
reply(88)
// -> "Too high"
```
