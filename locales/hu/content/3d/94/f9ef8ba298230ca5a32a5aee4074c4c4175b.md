# Bevezetés


## Boolean értékek

A PowerShellben a [`bool`][booleans] típus jelöli az igaz és hamis értékeket.
Ebben a típusban csak két érték létezik: `True` és `False`.
Ezeket az értékeket a `$` előtaggal kötheted változókhoz:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

A Boolean-kifejezéseket [`logical operators`][logical-operators], például a `-and`, `-or` és `-not` használatával kombinálhatod és értékelheted ki.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## Kommentalapú súgó

A [`Comment-based help`][comment-based help] a PowerShellben részletes információkkal szolgál a kommentekben megírt függvényekhez és szkriptekhez.
Speciális súgó-komment kulcsszavakkal adja meg a tárgyalt témákat, például `.SYNOPSIS`, `.EXAMPLE` vagy `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

A kommentalapú súgó információit a `Get-Help` parancsmaggal jelenítheted meg.

```powershell
> Get-Help -Name "ExampleFunction"
```
