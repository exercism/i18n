# Utasítások

Szenvedélyes madárfigyelő vagy, aki számon tartja, hány madár járt a kertedben az elmúlt hét napban.

Öt részfeladat vár rád, és mindegyik azzal foglalkozik, hány madár járt a kertedben.

## 1. Nézd meg, mennyi volt a madárszám a múlt héten

Az összehasonlítás kedvéért mindig magadnál tartod a múlt heti madárszámok másolatát, ezek pedig a következők voltak: 0, 2, 5, 3, 7, 8 és 4. Valósítsd meg a `BirdCount.last_week` metódust, amely visszaadja a múlt heti madárszámokat:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Nézd meg, hány madár járt nálad tegnap

Valósítsd meg a `BirdCount#yesterday` metódust, amely visszaadja, hány madár járt a kertedben tegnap. A madárszámok napok szerint vannak rendezve: az első elem a legrégebbi nap száma, az utolsó pedig a mai napé.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Számold ki, összesen hány madár járt nálad

Valósítsd meg a `BirdCount#total` metódust, amely visszaadja, hogy összesen hány madár járt a kertedben:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Számold ki a forgalmas napok számát

Néhány nap forgalmasabb, mint a többi. Forgalmas nap az, amikor öt vagy több madár járt a kertedben.
Valósítsd meg a `BirdCount#busy_days` metódust, amely visszaadja a forgalmas napok számát:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Nézd meg, volt-e olyan nap, amikor egyetlen madár sem járt nálad

Valósítsd meg a `BirdCount#day_without_birds?` metódust, amely `true` értéket ad vissza, ha volt olyan nap, amikor nulla madár járt a kertedben; egyébként pedig `false` értéket ad vissza:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
