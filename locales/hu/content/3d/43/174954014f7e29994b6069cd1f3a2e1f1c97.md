# Tanulás

A Vim már eleve remek, beépített dokumentációval érkezik. A dokumentációt a `:help` paranccsal érheted el.

Bevezetőként nézd meg a `:h user-manual` parancsot.

A Vim szinte minden telepítése is tartalmaz egy interaktív oktatóanyagot:

```
$ vimtutor
```

A Vim évtizedek óta létezik, és még mindig népszerű. Rengeteg anyagot találsz róla az interneten, némelyik jobb, mint a többi. A jók [itt](https://exercism.org/docs/tracks/vimscript/resources) találhatók.
