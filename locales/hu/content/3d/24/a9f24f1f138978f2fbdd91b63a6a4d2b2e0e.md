# Bevezetés

## Alapok

Az F#-ben, amikor egy értéket egy névhez rendelünk, azt _kötésnek_ nevezzük. A kötések változtathatatlanok, ami miatt más nyelvek konstanaihoz hasonlítanak. Mivel az F# statikusan típusos nyelv, minden kötésnek már fordításkor van típusa.

A kötéseket a `let` kulcsszóval definiáljuk. A legtöbb kötésnél a típus megadása nem kötelező, mivel az F# _típuskikövetkeztetése_ általában ki tudja következtetni a típust az értékük alapján. Egy kötés így néz ki:

```fsharp
// Automatically inferred type
let fingers = 10
```

A függvények is szabályos kötések, csak egy vagy több paraméterrel. Egy függvény automatikusan az utolsó kifejezését adja vissza. A típuskikövetkeztetés a legtöbb függvénynél is működik: elemzi, hogy milyen értékekkel hívjuk meg a függvényt, és milyen értéket ad vissza.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Egy függvény meghívásához meg kell adni a nevét, és minden paraméteréhez át kell adni egy-egy argumentumot.

```fsharp
let five = add 2 3
```

Ha egy kötés típusát nem lehet kikövetkeztetni, a fordító hibát jelez. Ennek javításához adj meg egy explicit típusmegjelölést a kötéshez.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Az F#-ben a kötések csak azután használhatók, _miután_ definiáltuk őket. Ha egy kötést a definiálása előtt használunk, fordítási hibát kapunk.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

Az F# a jelentős szóközökkel határozza meg a scope-ot. Ez azt jelenti, hogy a scope-ot a kód szóközökkel való behúzása határozza meg, a kötést deklaráló sorhoz képest. Az alapértelmezett konvenció szerint a behúzáshoz négy szóközt használunk:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Az F# kötéseit (köztük a függvényeket) általában modulokba rendezzük. Egy modul a kapcsolódó funkciókat csoportosítja, és a `module` kulcsszóval definiáljuk. A modul definíciójának meg kell előznie a kötéseit:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

Az F# kétféle megjegyzést támogat. Az egysoros megjegyzéseket `//` előzi meg, a többsoros megjegyzéseket pedig `(*` és `*)` közé írjuk.
