# Névjegy

A legtöbb programozási nyelvhez hasonlóan a Gleamnek is vannak „mellékhatásai”, ezért a függvények olvashatják és módosíthatják a világ állapotát, valamint értéket is visszaadhatnak.

A Gleam szabványos könyvtárában lévő `gleam/io` modul függvényeket biztosít stringek kiírásához a konzolra.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Más csomagok további IO-függvényeket is biztosíthatnak, például a `simplifile` csomag, amely fájlok olvasásához és írásához nyújt függvényeket.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
