# Telepítés

## A .NET 10 telepítése

A Visual Basic kurzus a .NET 10-et használja.
Ahhoz, hogy a feladatokat helyben le tudd fordítani és tesztelni tudd, telepítsd [a .NET 10 SDK-t a saját operációs rendszeredhez][install-sdk]:
Az SDK-t telepítsd, ne csak a futtatókörnyezetet.

## Ellenőrizd a telepítést

Nyiss egy új terminált, és futtasd ezt:

```bash
dotnet --version
```

A parancsnak `10.0.0` vagy újabb verziót kell kiírnia.

## Szerkesztőtámogatás

A .NET SDK és egy egyszerű szövegszerkesztő minden, amire a feladatok megoldásához szükséged van.
Ha fejlettebb funkciókat szeretnél, például kódkiegészítést és hibakeresést, fontold meg az alábbi szerkesztők egyikét:

- [Visual Studio 2026][visual-studio] Windows alatt
- [Visual Studio Code][visual-studio-code] Windows, Linux vagy macOS alatt
- [JetBrains Rider][rider] Windows, Linux vagy macOS alatt

[rider]: https://www.jetbrains.com/rider/
[visual-studio]: https://visualstudio.microsoft.com/downloads/
