# Részletesen

[Felsorolási típusokat][enumeration types] akkor használhatsz, amikor konstans értékek egy rögzített halmazával van dolgod. Az `enum` használata típusbiztos módot ad a konstans értékek kezelésére. A felsorolás definiálása az `enum` kulcsszóval történik. Egy felsorolástagra úgy hivatkozunk, hogy elé írjuk a felsorolás nevét és egy pontot (pl. `Status.Active`).

A felsorolás minden tagja egy név és egy `int` érték társítása. Ha az első taghoz nem tartozik explicit érték, az értéke `0` lesz. Ha egy felsorolástaghoz nem adunk meg explicit értéket, akkor az értéke automatikusan az előző tag értéke plusz `1` lesz.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

A felsorolások nagyon deklaratívak. Hasonlítsd össze a következő két metódushívást:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

A kódot olvasó számára a második változat (a felsorolással) lesz könnyebben érthető.

## Numerikus típusú felsorolások

Bár az értékek alapértelmezett numerikus típusa `int`, ez megváltoztatható bármely más [integrál numerikus][integral numeric] típus explicit megadásával.

A következő felsorolás a `byte` numerikus típust használja az értékeihez:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## Konvertálás felsorolástaggá

Valahányszor valami Booleanszerűt szeretnél modellezni, mindig gondold meg, hogy felsorolást használj. A fent említett olvashatósági előnyök mellett a felsorolásoknak van még egy előnyük a Boolean értékekkel szemben: egy felsoroláshoz mindig hozzáadhatók új értékek, egy Boolean érték viszont soha nem lesz más, csak `true` vagy `false`. Így a felsorolás használata jövőállóbb.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Vedd figyelembe, hogy bár egész számokat _át lehet_ alakítani felsorolássá, ez váratlan eredményekhez vezethet, ha az egész szám nem felel meg egyetlen felsorolásértéknek sem:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Felsorolás értelmezése

Néha hasznos lehet egy stringet a neve alapján felsorolástaggá alakítani az [`Enum.Parse`][enum parse] metódussal:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Annak ellenőrzésére, hogy létezik-e egy név vagy egy érték a felsorolásban, használhatod az [`Enum.TryParse`][enum tryparse] vagy az [`Enum.IsDefined`][enum isdefined] metódust; mindkettő egy Boolean értékkel tér vissza, amely megmutatja, hogy létezik-e a felsorolástag:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
