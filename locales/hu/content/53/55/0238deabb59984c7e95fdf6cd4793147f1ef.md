# Modulo

A modulo összehasonlítás teljesen érvényes a Crystalben, de az osztás maradékát olvashatóbban tudod összehasonlítani a [`divisible_by?`][divisible_by] metódussal.
Vagy ami még jobb, ha azt szeretnéd ellenőrizni, hogy egy szám páratlan vagy páros-e, használd az [`odd?`][odd?] és [`even?`][even?] metódusokat.

Például:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```

[odd?]: https://crystal-lang.org/api/Int.html#odd%%3F%%3ABool-instance-method
[even]: https://crystal-lang.org/api/Int.html#odd%%3F%%3ABool-instance-method
