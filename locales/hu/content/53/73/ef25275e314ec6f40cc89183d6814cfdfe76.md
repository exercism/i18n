# Részletesen

Amikor végigmegyünk egy sorozaton, néha maga az elem nem elég: a pozícióra is szükséged van. A Factor *indexelt* iterációs szavainál az elemenkénti quotation mindkettőt megkapja, az indexet a verem tetején. A `times` a kapcsolódó szó, ha nem sorozaton, hanem megadott számú alkalommal iterálunk.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| szó          | hatás                                                                |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, de erről lentebb                            |

Egy apró bonyodalom a `times`-szal kapcsolatban: bár a quotation hatását `( -- )`-ként dokumentálják, a szó `inline`, ezért egy kiegyensúlyozott hatású quotation, például `( str -- str )`, simán működik, és az iterációk között végigvezeti a vermet. Így akkumulátort építhetsz megadott számú iterációból anélkül, hogy módosítható állapotra lenne szükséged:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

Ugyanez a trükk működik az `each-index` és a `map-index` esetében is: az elemenként megadott hatás *minimum*, nem maximum.
