# Tartományok

A [tartományok][range] két érték közötti intervallumot jelölnek.
A leggyakoribb típusok, amelyek támogatják a tartományokat, az `Integer` és a `String`.
Sok mindenre jók: gyorsan készíthetsz velük gyűjteményt, szeletelhetsz stringeket, ellenőrizheted, hogy egy érték benne van-e egy tartományban, és iterálhatsz.
A `..` vagy a `...` tartományoperátorral hozhatók létre (az előbbi a végértéket is tartalmazza, az utóbbi nem).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

Azért van két tartományoperátor, hogy létrehozhass a végértéket tartalmazó és nem tartalmazó tartományokat is; erre például a nulla alapú indexeknél lehet szükség.

Tartományt a `Range` kezdőértékével is létrehozhatsz.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Amikor Rubyban a `..` vagy a `...` operátorral hozol létre egy tartományt, és metódust szeretnél meghívni rajta, zárójelbe kell tenned a tartományt.
Különben ugyanis a metódus a tartományoperátor második argumentumán hívódna meg.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Substringek kinyerése

Ha stringet szeretnél szeletelni, a tartományoperátorral substringet nyerhetsz ki.
Ehhez hozz létre egy tartományt a substring kezdő- és végindexével.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Negatív indexekkel a string végéről is kinyerheted a substringet.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Tartománymetódusok

A tartományokhoz több metódus is tartozik, amelyekkel dolgozhatsz.
Ezekkel például kiszámolhatod a tartomány összes értékének összegét, vagy ellenőrizheted, hogy a tartomány tartalmaz-e egy értéket.

| Metódus                 | Leírás                                                                  | Példa                           |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Visszaadja a tartomány összes értékének összegét                         | `(1..5).sum # => 15`            |
| [`size`][size]          | Visszaadja a tartomány méretét                                          | `(1..5).size # => 5`            |
| [`include?`][indlude]   | `true`-t ad vissza, ha a tartomány tartalmazza a megadott értéket, egyébként `false`-t | `(1..5).include?(3) # => true` |

## Végtelen és kezdet nélküli tartományok

Egy tartomány lehet végtelen és kezdet nélküli is.
A végtelen, illetve kezdet nélküli tartománynak a kezdő-, illetve végértéke `nil`, de a tartomány definiálásakor a `nil` elhagyható.

A kezdet nélküli és végtelen tartományok akkor jönnek jól, ha például egy stringet az elejétől vagy a végéig szeretnél szeletelni.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Ha nem gyűjteményen használod, a végtelen tartomány végtelen sorozatot indíthat be, szóval bánj vele óvatosan.
~~~~

## Stringtartományok

Stringeket tartományokban is használhatsz, így két string közötti stringintervallumot kaphatsz.
Bizonyos stringeknél a viselkedése kicsit váratlan lehet, ezért óvatosan használd.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
