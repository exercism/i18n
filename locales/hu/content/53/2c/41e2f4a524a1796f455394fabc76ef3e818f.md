# Strings

A stringek karakterek sorozatai, amelyeket idézőjelek közé zárunk.
Az egyszeres és a kettős idézőjel egyaránt használható.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Változók behelyettesítése a stringekbe

A kettős idézőjelbe zárt stringekben, ha egy változóra hivatkozunk, miközben az a scope-ban van, annak értéke bekerül a stringbe.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Karakterkódolás támogatása

A történelem során a PHP stringfüggvényei csak az ASCII-karaktereket támogatták, a modern Unicode-kódolásokat nem.
Az ASCII-karakterek egyenként 1 bájt hosszúak, míg a Unicode-karakterek 1-4 bájt hosszúak is lehetnek.
Ha biztonságosan szeretnél Unicode stringeket kezelni, nézd meg a régi függvények [többbájtos változatait][multi-byte-fns].

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
