# Bevezetés

## Számok

A C#-ban két különböző számtípus létezik:

- Egész számok: olyan számok, amelyeknél a tizedesjel mögött nincs számjegy, azaz nincs törtrészük. Például: `-6`, `0`, `1`, `25`, `976` és `500000`.
- Lebegőpontos számok: olyan számok, amelyeknél a tizedesjel mögött nulla vagy több számjegy áll. Például: `-2.4`, `0.1`, `3.14`, `16.984025` és `1024.0`.

A C#-ban a két leggyakoribb numerikus típus az `int` és a `double`. Az `int` egy 32 bites egész szám, a `double` pedig egy 64 bites lebegőpontos szám.

A számításokat a szabványos aritmetikai operátorokkal végezzük. A számokat a szabványos numerikus összehasonlító operátorokkal, illetve az egyenlőség (`==`) és egyenlőtlenség (`!=`) operátorokkal hasonlíthatjuk össze.

A C#-ban kétféle numerikus konverzió létezik:

1. Implicit konverziók: nem vész el adat, és nem szükséges hozzájuk további szintaxis.
2. Explicit konverziók: adat veszhet el, és szükség van további szintaxisra, méghozzá _cast_ formájában.

Mivel az `int` pontossága kisebb, mint a `double`-é, az `int`-ből `double`-be konvertálás biztonságos, ezért implicit konverzió. A `double`-ből `int`-be konvertálás viszont adatvesztéssel járhat, így az explicit konverziót igényel.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## Elágazások

Ebben a feladatban a logikát feltételesen kell végrehajtanod. A C#-ban erre a leggyakoribb megoldás az `if/else` elágazás használata:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

Az `if` elágazás feltételének `bool` típusúnak kell lennie. A C# nem ismeri a _truthy_ értékek fogalmát.
