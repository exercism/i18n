# Bevezetés

Az ABAP-nak több numerikus típusa van. Ebben a feladatban ezek közül kettőt fogsz használni:

- `i` egész értékekhez, például a napok számához.
- `p` csomagolt tizedes értékekhez, például egy óradíjhoz vagy kedvezményhez.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

A csomagolt számoknál megadod a maximális hosszt és a tizedesjegyek számát. A tizedes literálokat általában szövegként írjuk le, és vagy a fordító, vagy a `CONV` alakítja át a cél tizedestípusra.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

Az ABAP beépített numerikus függvényeket biztosít a kerekítéshez. A `floor` függvény lefelé kerekít a legközelebbi egész számra, a `ceil` pedig felfelé kerekít a legközelebbi egész számra.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
