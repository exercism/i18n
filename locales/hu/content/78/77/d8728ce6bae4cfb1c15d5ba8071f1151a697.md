# Utasítások

Ebben a feladatban olyan kódot írsz, amellyel listát vezethetsz azokról a programozási nyelvekről, amelyeket meg szeretnél tanulni az Exercism-ön.

Hat részfeladat vár rád, és mindegyikben listákkal fogsz foglalkozni.

## 1. Hozz létre egy új listát

Ahhoz, hogy nyilván tudd tartani azokat a nyelveket, amelyeket meg szeretnél tanulni, létre kell hoznod egy új listát. Definiáld a `newList` kötést, amely egy új, üres listát tartalmaz.

```fsharp
newList
// => []
```

## 2. Definiálj egy meglévő listát

Jelenleg van egy papírlapod, amelyen azok a nyelvek szerepelnek, amelyeket meg szeretnél tanulni: F#, Clojure és Haskell. Definiáld az `existingList` kötést, amely ezt a listát reprezentálja.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Adj hozzá egy új nyelvet egy listához

Ahogy felfedezed az Exercism-öt, és egyre érdekesebb nyelvekre bukkansz, szeretnéd őket felvenni a listádra. Valósítsd meg az `addLanguage` függvényt, amely egy új nyelvet szúr be a listád elejére.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Számold meg a nyelveket a listán

Kényelmetlen egyenként megszámolni a nyelveket. Valósítsd meg a `countLanguages` függvényt, amely megszámolja, hány nyelv van a listádon.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Fordítsd meg a listát

Egyszer csak rájössz, hogy a listád valójában visszafelé van rendezve! Valósítsd meg a `reverseList` függvényt, amely megfordítja a listádat.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Ellenőrizd, hogy izgalmas-e a lista

Bár minden nyelvet szeretsz, az F# különleges helyet foglal el a szívedben. Ezért igazán izgalmasnak tartasz egy nyelvlistát, ha:

- A lista első eleme az F#.
- A lista második eleme szintén F#, és a listán vagy két, vagy három nyelv szerepel.

Valósítsd meg az `excitingList` függvényt, amely ellenőrzi, hogy izgalmas-e egy nyelvlista:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
