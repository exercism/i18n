# Telepítés

A feladatok megoldásához a következő szoftverekre lesz szükséged:

1. [`OPAM`, az OCaml csomagkezelő](https://opam.ocaml.org/)

   A `OPAM` telepítéséhez és konfigurálásához az operációs rendszereden lásd a [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html) oldalt.

2. Az OCaml fordító

   Az elérhető verziók listája:

   ```bash
   opam switch
   ```

   Ha már van egy switch-ed az OCaml 5.1-hez, vagy töltsd be azt az `opam switch <switch-name>` parancs futtatásával, vagy hozz létre egy új switch-et a következő futtatásával:

   ```bash
   opam switch create exercism 5.4.0
   ```

   Az `exercism` név itt opcionális, de a switch-ek elnevezése jó gyakorlat.

3. Telepítsd a kiterjesztett szabványos könyvtárakat és a tesztkönyvtárakat

   A következő futtatásával telepítheted a kurzushoz szükséges függőségeket:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   Egyes feladatok csak az OCaml szabványos könyvtárát használják, mások a Jane Street által készített kiterjesztett könyvtárakat, a Base-t és a Core_kernel-t.
   A tesztkönyvtár neve OUnit, és néhány feladat emellett a QCheck könyvtárat használja tulajdonságalapú tesztekhez.
   A fenti parancs futtatása telepíti ezeket a könyvtárakat.

4. Telepítsd és használd az interaktív shellt (opcionális)

   A [`utop` beállítása és használata](https://dev.realworldocaml.org/install.html) összefoglalója:

   ```bash
   opam install utop
   ```

   Hozz létre egy új `.ocamlinit` nevű fájlt a home könyvtáradban, és add hozzá a következő sorokat:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. Telepítsd a VS Code eszközöket (opcionális)

   Ha VS Code-ot használsz:
   - Telepítsd az OCaml nyelvi szervert [innen](https://github.com/ocaml/ocaml-lsp).
   - Telepítsd az OCaml VS Code kiterjesztést [innen](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform), vagy keress rá a `OCaml Platform`-ra az Ocaml Labs-tól.
