# Kiegészítés az utasításokhoz

## Megvalósítás

Az elemeket [rekordok](https://lfe.gitbooks.io/reference-guide/content/16.html) képviselik, amelyek az `item.lfe` fájlban vannak definiálva.
A súly lekéréséhez használd az `item-weight`, az érték lekéréséhez pedig az `item-value` függvényt.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
