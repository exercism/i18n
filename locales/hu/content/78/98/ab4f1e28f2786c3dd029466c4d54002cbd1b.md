# Bevezetés

Sok programnak (pszeudo)véletlen értékekre van szüksége valós események szimulálásához.

Gyakori, jól ismert példák:

- Érmedobás: egy véletlen érték a ('H', 'T') halmazból.
- Kockadobás: egy véletlen egész szám 1 és 6 között.
- Kártyapakli megkeverése: egy kártyalista véletlen sorrendbe rendezése.
- Fák és bokrok létrehozása egy 3-D grafikai szimulációban.

Valóban véletlen értékek előállítása számítógéppel [meglepően nehéz technikai kihívás][why-randomness-is-hard], ezért léteznek „pszeudovéletlen” generátorok is.

~~~exercism/advanced
A JavaScript [nyelvi specifikációja][spec] nem írja elő, hogyan kell megvalósítani a véletlenszám-generálást.
Minden jelentős böngésző és JavaScript-futtatókörnyezet PRNG-t (pszeudovéletlen számgenerátort) valósít meg.
Mivel ezek a számok nem kriptográfiailag biztonságosak, soha nem szabad olyasmire használni őket, ami valódi vagy legalább kriptográfiailag biztonságos véletlen számokat igényel, például tanúsítványok vagy jelszavak generálására vagy ilyen műveletekre.

Létezik egy [Web Cryptography][rfc] nevű szabvány, amely szabványosítja a JavaScriptben végzett kriptográfia interfészét.
Ezt [a böngészők][crypto-web] éppúgy megvalósítják, mint az olyan futtatókörnyezetek, mint a [Node.JS][crypto-node] és a [Deno][crypto-deno].

Ez a fogalom nem a Web Cryptóról szól, és a pszeudovéletlen számgenerálásra szorítkozik.

## Véletlen számok generálása

JavaScriptben pszeudovéletlen számokat a [`Math.random()`][Math.random] függvénnyel generálhatsz.
Ez egy pszeudovéletlen lebegőpontos számot ad vissza 0 (beleértve) és 1 (kizárva) között.

Ahhoz, hogy _min_ (beleértve) és _max_ (kizárva) közötti véletlen számot kapj, használhatsz egy ilyesmi függvényt:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

~~~exercism/advanced

## Véletlen egész számok generálása

Véletlen egész szám előállításához a `Math.floor()` vagy a `Math.ceil()` segítségével alakíthatod egész számmá a véletlenszerűen generált számot.

[why-randomness-is-hard]: https://www.malwarebytes.com/blog/news/2013/09/in-computers-are-random-numbers-really-random
[Math.random]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random
