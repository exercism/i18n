# Bevezetés

Ha belegondolunk, hogy a nyelv, amit használunk, a Lisp, és a neve a _LIST Processing_ rövidítése, azt hihetnénk, hogy a nyelv rendelkezik az elemek listáinak kezeléséhez szükséges eszközökkel. És igazad is lenne!

Bár a Common Lispben a listákon kívül más adatszerkezetek is vannak, a listák használata mégis nagyon gyakori.

A lista a Common Lispben elemek sorozata. **Cons**nak is nevezik (többnyire történelmi okokból). Maguknak az elemeknek nem kell azonos típusúaknak lenniük. Például lehet egy listád `1`, `two` és `"III"` elemekből.

## Listák létrehozása

Egyszerűen beírhatsz egy idézőjellel ellátott listát, például így: `'(1 two "III")`, amitől létrejön és kiértékelődik egy lista (az értéke `(1 two "III")` lesz).

Két fő függvény is szolgál a listák létrehozására: a `list` és a `cons`.

A `list` nulla vagy több argumentumot fogad, és az értéke egy olyan lista lesz, amely ezekből az értékekből jön létre:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

A `cons` két elemet fogad, és létrehoz egy listát, amelynek az első elem a `car`-ja (a lista feje), a második pedig a `cdr`-je (a lista többi része):

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

A `car` és a `cdr` függvénnyel érheted el egy lista `car`-ját és `cdr`-jét.

(A `first` és a `rest` a `car` és a `cdr` szinonimája, és pontosan ugyanúgy működnek.)

## Hossz és véletlen elérés

A lista hosszát a `length` segítségével állapíthatod meg. Az üres lista hossza nulla.

Egy tetszőleges elemhez az `nth`-val férhetsz hozzá (figyelem: a listák indexelése nullától indul).

_Nem_ hiba, ha a lista hosszánál nagyobb indexet kérsz. Ehelyett az értéke `nil` lesz:

```lisp
(nth 23 '(short list)) ; => nil
```

Több segédfüggvény is segít hozzáférni a lista első elemeihez: `first`, `second`, `third`, egészen a `tenth`-ig. Menő, mi?

## Listák összefűzése

Két vagy több listát az `append`-del fűzhetsz össze:

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

Az `append` minden argumentumának listának kell lennie.
