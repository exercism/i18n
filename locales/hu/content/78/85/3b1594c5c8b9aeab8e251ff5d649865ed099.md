# Kiegészítés az utasításokhoz

## Callable

A PHP-ben létezik a [callable](https://www.php.net/manual/en/language.types.callable.php) fogalma.

Ezek többféle formát is ölthetnek, de mi most az [anonim függvényekre](https://www.php.net/manual/en/functions.anonymous.php) összpontosítunk.

Létrehozhatsz egy anonim függvényt egy változóban, és meg is hívhatod paraméterekkel:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
