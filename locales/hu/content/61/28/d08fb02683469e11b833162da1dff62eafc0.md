# Utasítások

Miközben az _Instruments of Texas_-nál dolgozol, az a feladatod, hogy egy C#-ban írt kísérleti számológépen dolgozz. Egy tesztkörnyezetet építesz, amellyel a számológép számos funkcióját ellenőrzöd, kezdve a szorzással. Meglátod majd, hogy különös figyelmet igényel az az eset, amikor a szorzás két operandusa is negatív.

A `Calculator` osztályt biztosítottuk neked, és nem szabad módosítanod.

## 1. Egészítsd ki a felhasználó által definiált `CalculationException` kivétel definícióját

Egészítsd ki a `CalculationException` konstruktorának definícióját, amelynek el kell tárolnia (be kell csomagolnia) a számológép által dobott kivételt, valamint azokat az operandusokat, amelyek feldolgozása éppen folyt a kivétel dobásának pillanatában.

## 2. Kezeld a túlcsordulásos eseteket a számológépben, és adj több információt a hívónak

Valósítsd meg a `CalculatorTestHarness.Multiply()` metódust, amelynek meg kell hívnia a konstruktornak átadott `Calculator` példány `Calculator.Multiply()` metódusát, átadva neki az x és y egész értékeket. Ha a `Calculator.Multiply()` metódusban túlcsordulás történik, az `OverflowException` kivételt dob. Ezt a kivételt a `CalculatorTestHarness.Multiply()` metódusban kell elkapni, és be kell csomagolni egy `CalculationException` kivételbe, valamint az átadott x és y értékeket a kivétel operandusaiként kell eltárolni. Az újonnan létrehozott `CalculationException` objektumot kell dobni. A `Calculator.Multiply()` metódus visszatérési értékét figyelmen kívül hagyhatod, ha a hívás sikeres.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. Teszteld a szorzás műveletet érvényes bemenetekkel

Valósítsd meg a `CalculatorTestHarness.TestMultiplication()` metódust, amely két egész számot vesz át, és meghívja a `CalculatorTestHarness.Multiply()` metódust. Ekkor a `"Multiply succeeded"` érték adódik vissza.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. Teszteld a szorzás műveletet negatív bemenetekkel

Módosítsd a `CalculatorTestHarness.TestMultiplication()` metódust úgy, hogy a `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"` érték adódjon vissza, ha mindkét egész argumentum negatív (nullánál kisebb).

A `<INNER_EXCEPTION_MESSAGE>` helyőrzőt a `CalculationException` belső kivételének üzenetére kell cserélni.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. Teszteld a szorzás műveletet pozitív bemenetekkel

Módosítsd a `CalculatorTestHarness.TestMultiplication()` metódust úgy, hogy a `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"` érték adódjon vissza, ha az egész argumentumok közül legalább az egyik nem negatív.

A `<INNER_EXCEPTION_MESSAGE>` helyőrzőt a `CalculationException` belső kivételének üzenetére kell cserélni.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
