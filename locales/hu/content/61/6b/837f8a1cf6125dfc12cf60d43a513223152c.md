# Bemutatás

[A struct- és osztálytagok számos fajtája][expression-bodied-members] (a mezők a fő kivétel) használhatja az expression-bodied member szintaxist. Ha egy tagot kifejezéssel definiálsz, gyakran tömörebb és olvashatóbb kódot kapsz, mint a hagyományos blokkokkal vagy utasításokkal.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

Egy expression-bodied member nem tartalmazhat több utasításból álló blokkot, de aki funkcionális háttérrel rendelkezik, az kapjon egy figyelmeztetést: amire egy hagyományos tag képes, azt ezekkel a tagokkal is el lehet érni. A „kifejezés” lehet értékadás, ami mellékhatásokat hoz létre, vagy metódushívás, ami azt jelenti, hogy bármi lehetséges.

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
