# Bevezetés

Az _enum típus_ egy speciális adattípus, amely lehetővé teszi, hogy egy változó előre definiált konstansok halmaza legyen.
A változó értéke csak a számára előre meghatározott értékek egyike lehet.
Gyakori példák közé tartoznak az égtájak (`NORTH`, `SOUTH`, `EAST` és `WEST` értékei) és a hét napjai.

Mivel konstansokról van szó, az enum típus mezőinek neve csupa nagybetűvel íródik.

## Enum típus definiálása

A Java programozási nyelvben az `enum` kulcsszóval definiálsz egy enum típust.
Egy hét napjait reprezentáló enum típust például így adsz meg:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Mindig használj enum típust, amikor konstansok egy rögzített halmazát szeretnéd reprezentálni.
Ide tartoznak a természetes enum típusok, például a Naprendszerünk bolygói, valamint azok az adathalmazok, amelyeknél fordítási időben ismered az összes lehetséges értéket: például egy menü választási lehetőségei, parancssori kapcsolók és így tovább.

## Enum típus használata

Az alábbi kód megmutatja, hogyan használhatod a fent definiált `DayOfWeek` enum típust:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## Metódusok és mezők hozzáadása

A Java programozási nyelv enum típusai sokkal erősebbek, mint más nyelvek megfelelői.
Az `enum` deklaráció egy _osztályt_ definiál (ezt nevezzük _enum típusnak_).
Az enum osztály törzse tartalmazhat metódusokat és további mezőket:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

A `getNumberOfStars` metódus meghívása a `Rating` enum típus egyik tagján:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
