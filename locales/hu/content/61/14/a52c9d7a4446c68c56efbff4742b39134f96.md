A [`Strings`][concept-strings] fogalomban már tárgyalt függvények közül sok eleve regexes keresésre készült.

A Strings fogalmat szándékosan egyszerűen tartottuk: csak stringliterálokra kerestünk egyezést, de helyette bármilyen regexminta használható.

Formálisan egy regexet R-ben a [`regex()`][ref-regex] meghívásával hozunk létre.
A kényelem kedvéért a `stringr` függvényei minden mintaként átadott stringet regexként kezelnek.
Az alábbi példában az első `str_replace_all()` szintaktikai cukor, amely a második változatnak felel meg:

```R
input <- "Some input string"

# "\\s" matches any whitespace character
input |> str_replace_all("\\s", "_")
[1] "Some_input_string"

input |> str_replace_all(regex("\\s"), "_")
[1] "Some_input_string"
```

A [puskalap][cheat-stringr] hasznos útmutató: minden `pattern` argumentummal rendelkező függvény (pirossal szedve) elfogad regexet, a 2. oldal pedig összefoglalja a regex szintaxisát.

Ne feledd, hogy a [`regex()`][ref-regex] függvény továbbra is fontos lehet, ha felül kell írnod az alapértelmezéseket, például a kis- és nagybetű megkülönböztetését vagy a területi beállítást.

```R
# default is case sensitive
"A Mixed Assortment" |> 
    str_replace_all(regex("[aeiou]", ignore_case = TRUE), "*")
#> [1] "* M*x*d *ss*rtm*nt"
```

Sok regexkód tartalmaz backslash-t, például a fentebb használt `\s`.
A normál R stringekben a `\`-t duplázni kell az escape-eléshez, innen a `"\\s"`.

A backslashek elszaporodhatnak és zavaróvá válhatnak, ezért bonyolult esetekben segíthet, ha [raw stringeket][book-raw] használsz.

Alapértelmezés szerint a raw string definiálásának szintaxisa `r"( )"`, de más határolójelek is megengedettek.
Mivel a kerek zárójelek `( )` és a szögletes zárójelek `[ ]` egyaránt gyakoriak a regex szintaxisában (a rögzítő csoportokhoz és az opcióscsoportokhoz), a kapcsos zárójelek `{ }` jó választás lehet.

```R
input |> str_replace_all(r"{\s\w}", "__")
#> [1] "Some__nput__tring"
```

## Egyezések felismerése

Íme néhány kérdés, és néhány függvény, amelyek segíthetnek megválaszolni őket.

Néhány példa a `fruit` vektort használja: ez 80 gyümölcsnevet tartalmaz, és a `stringr` mellékeli gyakorláshoz.

_Tartalmaz a string egyezést?_
A `str_detect()`, vagy a `str_starts()`, `str_ends()` függvénnyel elkerülheted a `^` vagy `$` horgonyok használatát.

```R
# berries begining with b
fruit |> str_detect("^b.*berry") |> head(15)
#> [1] FALSE FALSE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE  TRUE  TRUE FALSE FALSE FALSE FALSE

# alternative syntax
fruit |> str_starts("b.*berry") |> head(15)
#> [1] FALSE FALSE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE  TRUE  TRUE FALSE FALSE FALSE FALSE
```

_Csak azokat a stringeket add vissza, amelyek tartalmaznak egyezést?_
A stringekhez a `str_subset()`, az indexekhez pedig a `str_which()` függvényt használd.

```R
fruit |> str_subset("a...e")
[1] "apple"       "blackberry"  "mandarine"   "nectarine"   "pineapple"   "pomegranate" "raspberry"   "salal berry"
> fruit |> str_which("a...e")
[1]  1  7 48 51 62 64 70 73
```

_Hány egyezés van az egyes stringekben?_
Használd a `str_count()` függvényt.

```R
# count vowels
fruit |> str_count("[aeiou]") |> head(10)
#> [1] 2 3 4 3 3 2 2 3 5 3
```

_Hol van az egyezés?_
Interaktív használathoz a `str_view()`, általánosabb esetekben a `str_locate()` vagy a `str_locate_all()`.

```R
# str_view only shows matching elements, with match in < > delimiters
fruit |> str_view("a...e")
 [1] │ <apple>
 [7] │ bl<ackbe>rry
[48] │ mand<arine>
[51] │ nect<arine>
[62] │ pine<apple>
[64] │ pomegr<anate>
[70] │ r<aspbe>rry
[73] │ sal<al be>rry

# str_locate returns all elements
fruit |> str_locate("a...e") |> head(10)
      start end
 [1,]     1   5
 [2,]    NA  NA
 [3,]    NA  NA
 [4,]    NA  NA
 [5,]    NA  NA
 [6,]    NA  NA
 [7,]     3   7
 [8,]    NA  NA
 [9,]    NA  NA
[10,]    NA  NA
```

## Rögzítések

Gyakran szeretnénk tudni, hogy _mi_ egyezik.
Ezt úgy érhetjük el, hogy rögzítő csoportokat teszünk zárójelbe a regexen belül.

A regexen belül vissza is hivatkozhatsz a rögzítésekre a `\1`, `\2` stb. segítségével.
Például így találhatunk ismétlődő betűpárokat:

```R
fruit |> str_subset("(..)\\1")
[1] "banana"      "coconut"     "cucumber"    "jujube"      "papaya"      "salal berry"
```

Hasonló szintaxissal a rögzítések a csere-stringekben is használhatók:

```R
# double to triple
fruit |> 
  str_subset("(..)\\1") |> 
  str_replace("(..)\\1", "\\1\\1\\1")
[1] "bananana"      "cococonut"     "cucucumber"    "jujujube"      "papapaya"      "salalal berry"
```

A későbbi feldolgozáshoz gyűjtsd össze az egyezéseket a `str_match()` függvénnyel, ha csak az első egyezés kell, vagy a `str_match_all()` függvénnyel, ha az összes.

A rögzítő csoportok bármelyik nyelvben hajlamosak bonyolult kimenetet adni.
Az R megközelítése (_amely ráadásul vektorizált is, ami külön kihívás_) az, hogy a `str_match()` egy mátrixot állít elő, soronként egy-egy bemeneti stringgel, ahol az 1. oszlop a teljes egyező stringet tartalmazza, a többi oszlop pedig a különféle rögzítő csoportokat.

Előnyös lehet a nevesített csoportok használata, mert az eredménymátrix oszlopneveivé válnak.

```R
recipe <- "dissolve 25g sugar in 200ml water"
recipe |> str_match("(\\d+g) .* (\\d+ml)")
     [,1]                 [,2]  [,3]   
[1,] "25g sugar in 200ml" "25g" "200ml"

# use named capture groups
recipe |> str_match("(?<wt>\\d+g) .* (?<vol>\\d+ml)")
                          wt    vol    
[1,] "25g sugar in 200ml" "25g" "200ml"
```

Ebben a tantervben nem sokat beszéltünk a mátrixokról, de van egy [fogalmi dokumentum][concept-matrices-arrays], amit megnézhetsz.
A mátrixok nem illenek jól a Tidyverse ökoszisztémába, pedig régóta a Base R részei.

Röviden: a mátrixokat úgy kezeld, mint a két indexű vektorokat, `[rows, cols]` sorrendben.
Bármelyik indexet hagyd üresen, hogy megkapd a teljes sort vagy oszlopot.

Amikor egyetlen `r` sort kérsz le `m[r,]` alakban, vagy egyetlen `c` oszlopot `m[,c]` alakban, a visszaadott érték alapértelmezés szerint egy vektorrá lapul.

```R
> amounts <- recipe |> str_match("(?<wt>\\d+g) .* (?<vol>\\d+ml)")

# get all of row 1, as a named vector
> amt1 <- amounts[1,]
> amt1
                                       wt                  vol 
"25g sugar in 200ml"                "25g"              "200ml" 

# get a vector element
amt1["wt"] |> unname()
[1] "25g"
```

Elkerülhetetlenül a `str_match_all()` kimenete még összetettebb szerkezetű:

- Az eredmény egy lista, bemeneti stringenként egy-egy elemmel.
- Ha csak egyetlen bemeneti string van, bontsd ki a kimenetet `[[1]]` indexeléssel, ahogy a [Lists fogalom][concept-lists] leírja.
- Minden elem egy mátrix, ugyanazokkal az oszlopokkal, mint a `match()` esetében.
- A mátrix minden sora egy sikeres rögzítés.

```R
mix <- "Mix 200g of sugar, 180g of flour and 150g of butter"

# raw output
> str_match_all(mix, "(\\d+)g")
[[1]]
     [,1]   [,2] 
[1,] "200g" "200"
[2,] "180g" "180"
[3,] "150g" "150"

# we just want the first list element
> str_match_all(mix, "(\\d+)g")[[1]]
     [,1]   [,2] 
[1,] "200g" "200"
[2,] "180g" "180"
[3,] "150g" "150"

# captures are in column 2, so get that as a vector
> str_match_all(mix, "(\\d+)g")[[1]][,2]
[1] "200" "180" "150"
```

Persze előfordulhat, hogy nincs egyezés.
Ilyenkor az eredmény a speciális `NA` érték lesz.
Készülj fel ennek ellenőrzésére, ahogy a [Nothingness fogalom][concept-nothingness] leírja.

```R
# failed match
recipe |> str_match("(not here)")
     [,1] [,2]
[1,] NA   NA  
```
