# A szótárakról

A [szótárak][dictionaries] a Swift három elsődleges gyűjteménytípusának egyike.
A szótárak _kulcsok_ és _értékek_ közötti leképezéseket tárolnak: a kulcsok az egyik típus elemei, az értékek pedig egy másik típus elemei (ami lehet ugyanaz a típus is, mint a kulcsoké).

A szótárliterálokat `key: value` párok sorozataként írjuk le, amelyeket vessző választ el, és szögletes zárójelbe zárunk.
Üres szótárakat úgy írhatunk le, hogy a szótár típusneve után egy zárójelpárt teszünk, például `[Int: String]()`, vagy ha a típus a kontextusból meghatározható, akkor csupán egy kettőspontot közrefogó szögletes zárójelpárral: `[:]`.
A szótárak típusneveit kétféleképpen írhatjuk: `Dictionary<K, V>` vagy `[K: V]`, ahol `K` a szótárban lévő kulcsok típusa, `V` pedig az értékek típusa.
Üres szótár létrehozásakor meg kell adni a típust.

```swift
var addresses: Dictionary<String, String> = ["The Munsters": "1313 Mockingbird Lane", "The Simpsons": "742 Evergreen Terrace", "Buffy Summers": "1630 Revello Drive"]
var sequences: [String: [Int]] = ["Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4], "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37], "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]]
let constants = ["pi": 3.14159, "e": 2.71828, "phi": 1.618033, "avogadro": 6.02214076e23]
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

A szótár elemei indexelő jelöléssel érhetők el: a szótár neve után szögletes zárójelek következnek, amelyek közrefogják azt a kulcsot, amelyhez a megfelelő értéket szeretnénk.

Figyelj azonban arra, hogy a visszaadott érték nem _Value_ típusú, hanem opcionális típusú: _Value?_.
Ez azért van, mert megadhatsz olyan kulcsot, amely nem szerepel a szótárban.
Ilyen esetekben a Swift úgy dönt, hogy `nil`-t ad vissza, ahelyett hogy hibát dobna.

```swift
let munster: String? = addresses["The Munsters"]
// Returns "1313 Mockingbird Lane"
let carmichael = sequences["Carmichael"]
// Returns [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
let planck = constants["planck"]
// Returns nil
```

Ha el akarod kerülni a visszatérési érték opcionális típusát, megadhatsz egy alapértelmezett értéket, amelyet akkor ad vissza, ha a kulcs nem található a szótárban.

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828
let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []
let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

Ez az indexelő jelölés használható arra, hogy lekérdezzük a kulcshoz tartozó értéket, és arra is, hogy beállítsuk a kulcshoz tartozó értéket, feltéve, hogy a szótárt változóként definiáltuk (azaz `var`-ral).
Ezzel frissíthető a kulcshoz tartozó érték, vagy új _kulcs: érték_ pár adható a szótárhoz.

```swift
sequence["Euler's totient"]?.append(contentsOf: [6,4])
sequence["Euler's totient"]
// Returns [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]
addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."
constants["Gelfond's"] = 23.140692
// compiler error: "Cannot assign through subscript: 'constants' is a 'let' constant"
```

A tömbökhöz hasonlóan a szótár _kulcs: érték_ párjain egyesével végigmehetsz egy for-in ciklussal.
Ez a fajta ciklus a szótár minden _kulcs: érték_ párját veszi, és a párt egy megadott névhez köti, hogy a ciklustörzsben tovább dolgozhass vele.
A pár tuple-ként van ábrázolva, és ugyanúgy szétbontható, mint a többi tuple, hogy minden elemet egy névhez rendeljünk. Például a címjegyzék kiírásához ezt írhatod:

```swift
for (name, address) in addresses {
  print("\(name) lives at \(address)")
}

// prints out:
// Betty Cooper lives at 111 Queens Ave.
// The Munsters lives at 1313 Mockingbird Lane
// The Simpsons lives at 742 Evergreen Terrace
// Buffy Summers lives at 1630 Revello Drive
```

A többi gyűjteménytípushoz hasonlóan a szótárak tetszőleges rendezőfüggvények szerint rendezhetők.
Ehhez először definiálnod kell egy függvényt, amely két _kulcs: érték_ párt vesz át, tuple-ként ábrázolva, és `Bool` értéket ad vissza. A visszatérési érték akkor legyen `true`, ha az első _kulcs: érték_ párnak a rendezett eredményben a második _kulcs: érték_ pár _előtt_ kell szerepelnie.

Ezután ezt a függvényt átadhatod a szótár `sorted(by:)` metódusának, amely a _kulcs: érték_ párok rendezett tömbjét adja vissza.
Például hogy a `constants` szótárt a konstans értéke plusz a konstans nevében lévő karakterek száma szerint rendezzük, ezt írhatnánk:

```swift
func weirdSort(_ lhs: (String, Double), _ rhs: (String, Double)) -> Bool {
  let left = lhs.1 + Double(lhs.0.count)
  let right = rhs.1 + Double(rhs.0.count)
  return left < right
}

let sortedConstants = constants.sorted(by: weirdSort)
// returns [(key "e", value 2.71828), (key "phi", value 1.618033), (key "pi", value 3.14159), (key "avogadro", value 6.02214076e+22)]
```
