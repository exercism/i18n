# Alias

Az [`alias` speciális forma][alias] segítségével lerövidítheted vagy megváltoztathatod annak a külső modulnak a nevét, amelyre hivatkozol. Egyéni nevet a `:as` opcióval adhatsz meg.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

Ha argumentum nélkül használod, a modulnevet az utolsó tagjára rövidíti, például

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

Több aliast a `{}` segítségével csoportosíthatsz:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

Az aliasokat általában a moduldefiníció elején adjuk meg, de bárhol szerepelhetnek. Lexikális scope-pal rendelkeznek, ami azt jelenti, hogy a függvénydefiníción belül megadott alias nem lesz elérhető egy másik függvényben.

A nem használt aliasok fordítói figyelmeztetést váltanak ki.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
