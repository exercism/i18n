# Bevezetés

## Attribútumok

A [C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) arra ad lehetőséget, hogy egy deklarációt díszítve metaadatot rendelj hozzá egy osztályhoz, egy metódushoz, egy enumhoz, egy mezőhöz, egy tulajdonsághoz vagy bármely [más támogatott](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) deklarációhoz.

Egy attribútumot úgy alkalmazhatsz, hogy a deklaráció előtti sorba írod, például egy `ClassAttribute` és egy `FieldAttribute` használatával:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Ez a deklaratív metaadat csak plusz strukturált információt rendel a kódhoz, és nem módosítja annak viselkedését. A metaadatot viszont a kód más részei arra használják, hogy megváltoztassák a célpont viselkedését, vagy hogy hozzáadjanak, megváltoztassanak, eltávolítsanak vagy korlátozzanak bizonyos funkciókat.

Sok [előre definiált és fenntartott attribútum](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute) létezik, például: `Flags`, `Obsolete`, `Conditional` és `Experimental`. Mindegyiknek megvan a maga szemantikai jelentése, amit a C# dokumentációjában nézhetsz meg. Fontos, hogy egy attribútum teljes neve, mint például a [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) esetében, `<Name>Attribute` formájú (pl. `FlagsAttribute`).

## Jelzőbites enumok

A C# [`enum` típusa](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) nevesített konstansok rögzített halmazát jelöli (egy felsorolást).

Az `enum` egy tagja általában pontosan egy ilyen nevesített konstansra hivatkozhat. Néha azonban hasznos egynél több konstansra hivatkozni. Ehhez az `enum`-ot a [`Flags` attribútummal](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) láthatod el.

Egy jelzőbites enumot a következőképpen definiálhatsz (bináris egész jelöléssel, `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Egy `PhoneFeatures` példány, amelynek értéke `0b00000011`, egyszerre állítja be a `Call` _és_ a `Text` jelzőbitet.

Alapértelmezés szerint az `int` típust használja az enum tagjainak értékeihez. Más egész típust is használhatsz, ha megadod a típust az enum deklarációjában:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
