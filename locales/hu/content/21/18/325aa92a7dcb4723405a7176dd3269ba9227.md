# Bevezetés

A `Tuple` sok szempontból nagyon hasonlít a `Vector`-hoz (egydimenziós `array`).
Azonban van néhány fontos különbség.

- A tuple-ok kerek zárójelbe `( )` kerülnek a szögletes zárójel `[ ]` helyett, bár a zárójel elhagyható, ha a jelentés egyértelmű.
- A tuple-oknak nem kell homogénnek lenniük: az egyes elemek típusát külön tárolják.
- A tuple-ok változtathatatlanok.

A változtathatatlanság több fordítóoptimalizálást tesz lehetővé, és a tuple-okat hatékonyabbá teszi a vektoroknál, ezért előnyben kell részesíteni őket, amikor a változtathatóság nem szükséges.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

Létezik egy `Tuple()` konstruktor is, amely bármilyen iterálható gyűjteményt tuple-vá alakít.
Hasznos, hogy a stringet karakterek iterálható gyűjteményeként kezeli.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

Minden tuple esetében lehetséges az elemeket index alapján elérni, vagy végigiterálni rajtuk.

Bármely tisztán numerikus tuple használható matematikai függvényekben, például a `sum()`-ban, pontosan úgy, mint a tömbök.

## Kicsomagolás

Egy tuple kicsomagolható különálló elemekre többszörös értékadás segítségével.
Azokhoz az elemekhez, amelyekre nincs szükség, használd az aláhúzás `_` jelet dummy változóként.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

A Python programozók nagyon ismerik ezt a többszörös értékadás szintaxist.

## Nevesített tuple-ok

A `Tuple` csak értékeket tartalmaz.
A `NamedTuple` minden értékhez nevet rendel.

Az egyes mezők ezután „pont” jelöléssel érhetők el:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

A név belsőleg `Symbol`-ként tárolódik (egy változtathatatlan típus, és a nevet egy kettőspont `:` előzi meg), így egy alternatív szintaxis is elérhető:

```julia-repl
julia> nt[:b]
7.3
```

Könnyű külön megszerezni a neveket (más néven „kulcsokat”) vagy az értékeket:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

Vedd figyelembe, hogy egy nevesített tuple feletti iteráció csak az _értékeket_ adja, a _neveket_ figyelmen kívül hagyja.

A tuple-ok (nevesítettek vagy sem) nagyon gyakori módjai a strukturált adatok függvényekhez és függvényektől való továbbításának.
A változtathatatlanság jó ebben a felhasználási esetben, mivel adatbiztonságot nyújt, és lehetővé teszi agresszívabb fordítóoptimalizálásokat.
