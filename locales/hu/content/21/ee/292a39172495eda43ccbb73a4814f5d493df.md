# Utasítások

Astrid, a kalandvágyó alkimista, igyekszik egységesíteni a különböző birodalmakból gyűjtött mágikus mértékegységeket.
Néhány birodalom előjeles mértékegységeket használ (amelyek negatívak is lehetnek), mások viszont előjel nélkülieket (amelyek mindig pozitívak).
Ráadásul Astridnak két egyedi típusa van bizonyos ritka hozzávalókhoz, és szeretné, ha könnyedén át tudna alakítani közöttük.

A küldetésed, hogy segíts Astridnak az előjeles és előjel nélküli egészek közötti átváltásban, valamint hogy a Cairo `Into` és `TryInto` traitjeivel egyedi típuskonverziókat hozz létre a különleges hozzávalóihoz.

## 1. Mágikus mértékegységek átváltása előjeles és előjel nélküli alak között

Astrid mérései néha pozitív vagy negatív értékként érkeznek (előjeles egészek), bizonyos feladatokhoz viszont biztosítania kell, hogy az értékek mindig pozitívak legyenek (előjel nélküli egészek).

Segíts Astridnak egy olyan függvény megírásával, amely átváltja:

1. Az előjeles egészt (`i32`) előjel nélküli egésszé (`u16`).
2. Az előjel nélküli egészt (`u16`) előjeles egésszé (`i32`).

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. Egyedi hozzávalótípusok konverziója

Astrid két ritka hozzávalóval dolgozik, amelyeket egy-egy egyedi típus, az **Essence** és az **Elixir** képvisel.
Szeretné **Essence**-ből **Elixir**-t készíteni, de visszafelé nem.

Segíts Astridnak létrehozni két egyedi típust, az `Essence`-t és az `Elixir`-t, és megvalósítani az `Into` traitet, amellyel `Essence`-ből `Elixir`-t lehet átalakítani.

Írj egy függvényt, amely fogad egy `Essence`-t, és a `.into()` segítségével `Elixir`-ré alakítja.

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
