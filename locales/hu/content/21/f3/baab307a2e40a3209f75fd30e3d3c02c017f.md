# Bevezetés

A Gleam futhat az Erlang virtuális gépen (BEAM) vagy JavaScript-futtatókörnyezeteken. Sok más nyelv is használja ezeket a futtatókörnyezeteket, és gyakran hasznos, ha a Gleamből más nyelveken írt kódot hívhatsz.

A Gleam _külső függvények_ funkciójának segítségével más nyelveken írt függvényeket importálhatsz Gleambe, és futásidejű többletköltség nélkül hívhatod meg őket.

Ha a Gleam-projekt az Erlang virtuális gépen fut, és a `reverse` függvényt az Erlang `lists` modulból szeretnéd meghívni, ezt úgy teheted meg, hogy hozzáadod a `@external` attribútumot egy Gleam-függvény fejlécéhez, így:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Ezután normál Gleam-függvényként hívható:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Ha megpróbálod lefordítani ezt a kódot JavaScript-futtatókörnyezetekre, hibaüzenettel fog meghiúsulni, mivel nincs JavaScript-implementáció. Másik implementáció is megadható a JavaScript-futtatókörnyezetekhez, így:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Arra is van lehetőség, hogy olyan Gleam-implementációt írj, amelyet akkor használ a Gleam, ha az aktuális fordítási célhoz nincs külső implementáció:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
