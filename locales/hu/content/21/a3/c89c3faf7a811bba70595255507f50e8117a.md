# Szótárak

A Cairo szótárai kulcs-érték tárolók, hasonlóak más nyelvek mapjaihoz vagy hash table-jeihez.

A Cairo változhatatlan memóriamodellje miatt azonban néhány egyedi tulajdonsággal is rendelkeznek.

## Alapgondolat

A `Felt252Dict<T>` típus biztosítja a szótárfunkcionalitást a Cairóban: kulcstípusa `felt252`, értéktípusa pedig bármely támogatott `T` típus.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## Fontos jellemzők

A más nyelvekben megszokott szótáraktól eltérően a Cairo szótárainak van néhány különleges tulajdonságuk:

1. A kulcsok csak `felt252` értékek lehetnek.
2. Minden kulcs implicit módon nulla értékkel indul.
3. Bejegyzéseket nem törölhetsz, csak az értékeket frissítheted.
4. Az értékeknek implementálniuk kell a `Felt252DictValue` traitet.

## Teljesítménnyel kapcsolatos megjegyzés

A Cairo változhatatlan memóriamodellje miatt a szótárműveletek bonyolultsága $O(n)$, ahol $n$ a szótáron végrehajtott műveletek száma.

Minden művelet egy új bejegyzést hoz létre, amely rögzíti a változást.

## Összetett típusok használata

Az olyan típusokat, amelyek nem implementálják a `Felt252DictValue` traitet (például a tömböket vagy a structokat), beburkolhatod `Nullable<T>`-be:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## Memóriakezelés

A szótárak implementálják a `Destruct` traitet, ami azt jelenti, hogy automatikusan „összepréselődnek” (validálódnak és optimalizálódnak), amikor kikerülnek a scope-ból.

Ez a Cairo bizonyítási rendszerének a része, és a háttérben történik.

Ne feledd: bár a szótárak kevésbé tűnhetnek hatékonynak, mint más nyelvekben, épp így tervezték őket, hogy megfeleljenek a Cairo egyedi memóriamodelljének és a bizonyítási rendszer követelményeinek.
