# Utasítások

Megint a konyhában vagy, és tovább finomítod a lasagne receptjét a [Leah ínycsiklandó lasagnéja][lasagna] feladatból. Az itteni részfeladatokban egyszerre több bemenettel kell zsonglőrködnöd, és pont ilyenkor jönnek jól a *locals*, a Factor névvel ellátott kötései.

## 1. Határozd meg a főzés állapotát

Definiáld a `cooking-status` szót úgy, hogy kivegyen egy időzítőértéket a veremről, és egy állapotot leíró stringet adjon vissza.

- `0` → `"Lasagna is done."`
- `f` (az időzítőt sosem állítottad be) → `"You forgot to set the timer."`
- bármely más szám → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Becsüld meg az előkészítési időt

Definiáld a `preparation-time` szót úgy, hogy kapjon egy tömböt a rétegek neveivel és a rétegenkénti átlagos percszámot, majd adja vissza a teljes előkészítési időt.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Számítsd ki a szükséges tésztát és szószt

Definiáld a `quantities` szót úgy, hogy kapjon egy tömböt a rétegek neveivel, és *két* értéket adjon vissza: a szükséges tészta grammját (tésztarétegenként 50 g) és a szükséges szósz literjét (szószrétegenként `1/5` liter).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Add hozzá a titkos összetevőt

A barátod küld egy listát az összetevőkről, és a *legutolsó* elem a titka. Definiáld az `add-secret-ingredient` szót úgy, hogy kapja meg az ő listáját és a tiédet, majd adja vissza a te listádat a titkos összetevővel a végén.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Méretezd át a receptet

A szakácskönyv receptje két adagra elég. Definiáld a `scale-recipe` szót úgy, hogy kapjon egy receptet (egy hashtable-t, amely az összetevő nevéhez rendeli a mennyiséget) és a cél adagszámot, majd adjon vissza egy új, megfelelően átméretezett receptet.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
