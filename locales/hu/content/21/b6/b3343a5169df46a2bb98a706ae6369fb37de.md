Leendő bűvészként Elyse-nek gyakorolnia kell néhány alapvető dolgot.
Van egy kártyapaklija, amit szeretne manipulálni.

Hogy kicsit egyszerűbb legyen a dolga, csak az 1-től 10-ig terjedő kártyákat használja.

## 1. Kártya lekérése a pakliból

Add vissza a megadott pakli `idx` pozícióján lévő kártyát.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. Kártya cseréje a pakliban

Cseréld ki az `idx` pozíción lévő kártyát a megadott új kártyára, és add vissza a módosított paklit.
Figyelem: ez mutálja (megváltoztatja) a bemeneti vektort, és ez így van rendjén.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. Kártya beszúrása a pakli tetejére

Szúrj be egy új kártyát a pakli tetejére, és add vissza a paklit.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. Kártya eltávolítása a pakliból

Távolítsd el az `idx` pozíción lévő kártyát a pakliból, és add vissza a paklit.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. A felső kártya eltávolítása a pakliból

Távolítsd el a pakli tetején lévő kártyát, és add vissza a paklit.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. Kártya beszúrása a pakli aljára

Szúrj be egy új kártyát a pakli aljára, és add vissza a paklit.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. Kártya eltávolítása a pakli aljáról

Távolítsd el a pakli alján lévő kártyát, és add vissza a paklit.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. A pakli méretének ellenőrzése

Ellenőrizd, hogy a pakli mérete megegyezik-e a megadott `deck_size` értékkel vagy sem.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
