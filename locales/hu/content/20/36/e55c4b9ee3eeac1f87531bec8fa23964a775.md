# Kiegészítés az utasításokhoz

## Kurzusspecifikus utasítások

### Az aknamező formátuma

Az aknamezőt stringként ábrázoljuk, minden sor végén egy újsor karakterrel.

Például: `"   \n * \n   \n"`

### Fenntartott memória

A bemeneti string puffere a lineáris memória 64-319. bájtját használja.

A bemeneti string igény szerint helyben módosítható.
