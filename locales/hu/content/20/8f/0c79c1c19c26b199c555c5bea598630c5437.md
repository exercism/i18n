# Konstruktor tulajdonságpromóció

Azokban az osztályokban, amelyek sok tulajdonságot deklarálnak, az osztály, a tulajdonságok és a tulajdonságok beállítására szolgáló konstruktor külön-külön történő deklarálása ismétléssel jár.
A konstruktor tulajdonságpromócióval csökkenthetjük az ismétlést.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
