# Bevezetés

Az Elixir az igaz és hamis értékeket a boolean típussal ábrázolja. Mindössze két érték létezik: `true` és `false`. Ezeket az értékeket hozzárendelhetjük egy változóhoz:

```elixir
true_variable = true
false_variable = false
```

Szigorú boolean kifejezéseket a `and/2`, `or/2` és `not/1` operátorokkal értékelhetünk ki.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Amikor olyan függvényt írunk, amely boolean értéket ad vissza, a függvénynév végére `?`-t szokás tenni. Ugyanezt a konvenciót követhetjük az olyan változóknál is, amelyek boolean értéket tárolnak.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
