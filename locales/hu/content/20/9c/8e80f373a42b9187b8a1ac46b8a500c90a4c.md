# Utasítások

Ebben a feladatban naplóbejegyzéseket fogsz feldolgozni.

Minden naplósor egy karakterlánc, amelynek formátuma a következő: `"[<LEVEL>]: <MESSAGE>"`.

Háromféle naplószint létezik:

- `INFO`
- `WARNING`
- `ERROR`

Három részfeladatod van, és mindegyik kap egy naplósort, amellyel valamit tenned kell. Sokféleképpen megoldhatod ezeket a részfeladatokat: válaszd ki a kedvenc technikáidat a fenti példák közül, és lássuk, mire jutsz.

## 1. Üzenet kinyerése egy naplósorból

Valósítsd meg a `message` függvényt, amely visszaadja a naplósor üzenetét:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

A kezdő és a záró szóközöket el kell távolítani:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. Naplószint kinyerése egy naplósorból

Valósítsd meg a `log_level` függvényt, amely visszaadja a naplósor naplószintjét, méghozzá kisbetűvel:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. Naplósor újraformázása

Valósítsd meg a `reformat` függvényt, amely újraformázza a naplósort: az üzenet kerül előre, utána pedig a naplószint zárójelben:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
