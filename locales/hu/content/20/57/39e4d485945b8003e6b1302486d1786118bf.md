# Bemutatás

A [`sequences`][sequences] szókészlet egyetlen
[protokollt][sequence-protocol] definiál, amelyet a tömbök (`{ … }`), a vektorok (`V{ … }`),
a stringek, a tartományok és a szeletek egyaránt megvalósítanak. Bármit megtehetsz az
egyikkel, ugyanazt megteheted a többivel is.

| szó         | hatás                             |
|-------------|-----------------------------------|
| `length`    | `( seq -- n )`                    |
| `first`     | `( seq -- elt )`                  |
| `second`    | `( seq -- elt )`                  |
| `third`     | `( seq -- elt )`                  |
| `fourth`    | `( seq -- elt )`                  |
| `last`      | `( seq -- elt )`                  |
| `rest`      | `( seq -- tailseq )`              |
| `but-last`  | `( seq -- headseq )`              |
| `nth`       | `( n seq -- elt )` (0-tól indexelve) |
| `head`      | `( seq n -- headseq )`            |
| `head*`     | `( seq n -- headseq )` (az utolsó n kivételével) |
| `tail`      | `( seq n -- tailseq )`            |
| `tail*`     | `( seq n -- tailseq )` (az utolsó n) |
| `subseq`    | `( from to seq -- newseq )`       |
| `remove-nth`| `( n seq -- newseq )`             |
| `pad-head`  | `( seq n elt -- padded )`         |
| `pad-tail`  | `( seq n elt -- padded )`         |
| `prefix`    | `( seq elt -- newseq )`           |
| `suffix`    | `( seq elt -- newseq )`           |
| `unclip`    | `( seq -- rest first )`           |
| `unclip-last` | `( seq -- butlast last )`       |
| `empty?`    | `( seq -- ? )`                    |
| `if-empty`  | `( seq emptyquot nonemptyquot -- … )` |
| `member?`   | `( elt seq -- ? )`                |
| `reverse`   | `( seq -- newseq )`               |
| `index`     | `( elt seq -- i/f )`              |
| `index-or-length` | `( elt seq -- i )` (ha nincs benne, a hossza) |
| `count`     | `( seq quot -- n )`               |
| `concat`    | `( seqs -- seq )`                 |
| `sum`       | `( seq -- n )`                    |
| `product`   | `( seq -- n )`                    |
| `find`      | `( seq quot -- i/f elt/f )`       |
| `find-last` | `( seq quot -- i/f elt/f )`       |
| `produce`   | `( pred quot -- seq )`            |

A tömbök fix hosszúságúak, ezért a `prefix`/`suffix`/`append`/`prepend`
műveletek mind új sorozatot adnak vissza, nem pedig növelik az eredetit.
A vektorok átméretezhetők, a `push` és a `pop` helyben működik, de ha
friss másolatot szeretnél, a `clone` a helyes kiindulópont.

## Átalakítások

A `>array`, a `>string` és a `>vector` (a saját szókészletükben) bármely
sorozatot a megnevezett konkrét típusra alakítja. Akkor használd őket, ha a
hívó egy adott reprezentációt szeretne, vagy hogy egy szeletet vagy más
lusta sorozatot konkrét sorozattá alakíts.

```factor
USING: arrays sequences strings vectors ;

V{ 1 2 3 } >array  .   ! => { 1 2 3 }
{ 65 66 67 } >string . ! => "ABC"
"abc" >vector .        ! => V{ CHAR: a CHAR: b CHAR: c }
```
