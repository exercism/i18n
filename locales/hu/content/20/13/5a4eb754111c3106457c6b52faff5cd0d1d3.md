# Bevezetés

Amikor több különálló lehetséges érték közül kell választanod, a `case` (amely a [`combinators`][combinators] szótárban található) tisztább megoldás, mint az `if`-ek láncolata.

## `case`

```
case ( obj assoc -- )
```

A `case` levesz a verem tetejéről egy értéket, valamint egy *assoc*-ot, ami klózokból áll. Minden klóz így néz ki: `{ value [ body ] }`. Az első olyan klóz nyer, amelynek az értéke `=` a bemenettel; a teste úgy fut le, hogy a bemeneti érték *már elfogyott*. Egy záró bejegyzés, ami csak `[ body ]`, az alapértelmezett eset: ekkor a bemenet *még mindig a vermen van*, amikor lefut.

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

Az egyenlőséget a `=` dönti el, így bármi, ami egyenlőnek bizonyul, használható kulcsként: a számok, a stringek és a szimbólumok is.

## `cond` a feltételes ágakhoz

Amikor a választás egy *predikátumtól* függ, nem pedig egyenlőségtől (például `x > 11`), akkor a `cond` a megfelelő eszköz. A `cond`-dal már találkoztál a [Cars, Assemble!][cars-assemble] feladatban.

## Szimbólumok

A `SYMBOL:` olyan szót deklarál, amely önmagát teszi a veremre: egy önmagát kiértékelő címkeérték. A `SYMBOLS:` egyszerre többet deklarál:

```factor
SYMBOLS: yes no maybe ;
```

Most a `yes` egy érték, ami `=`-lel összehasonlítható, és használhatod a `case` kulcsaként:

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
