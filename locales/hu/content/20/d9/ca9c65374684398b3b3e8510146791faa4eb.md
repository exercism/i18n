# Tesztek

## Clojure CLI

Az Exercism Clojure-feladatai egy `deps.edn` fájllal érkeznek, amely egy `:test` aliast tartalmaz a [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) futtatásához:

``` bash
clj -X:test
```

## Leiningen

A feladat tesztjeit a Leiningennel is lefuttathatod, ha a feladat könyvtárában kiadod a következő parancsot:

```bash
lein test
```
