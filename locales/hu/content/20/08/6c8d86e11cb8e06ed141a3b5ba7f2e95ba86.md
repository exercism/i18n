# Bevezetés

A PHP-ban lehetőség van arra, hogy függvényeket más függvényeken belül deklaráljunk. Ezeket a függvényeket nem kell elnevezni, de értékül adhatjuk őket változóknak, vagy akár közvetlenül át is adhatjuk egy másik függvénynek, amely függvényparamétert vár.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
