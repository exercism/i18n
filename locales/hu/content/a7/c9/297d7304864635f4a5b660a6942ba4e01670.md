# Bevezetés a típuskonverzióba

A Go-ban a különböző típusok közötti átalakítást mindig explicit módon kell elvégezni.
A típusok közötti átalakítás (más néven **típusátalakítás**) egy olyan függvénnyel történik, amely a célul kitűzött típus nevét viseli.
Ha például egy `int` értéket szeretnél `float64`-té alakítani, ezt így teheted meg:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Átalakítás primitív típusok és stringek között

A primitív típusok (például az `int`) és a `string` közötti átalakításhoz a `strconv` csomag áll rendelkezésre.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```
