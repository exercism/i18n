# Utasítások

Ebben a feladatban naplósorokat fogsz feldolgozni.

Minden naplósor egy string, amelynek a formátuma a következő: `"[<LEVEL>]: <MESSAGE>"`.

Három különböző naplózási szint létezik:

- `INFO`
- `WARNING`
- `ERROR`

Három részfeladat vár rád, és mindegyik kap egy naplósort, amivel valamit tenned kell.

## 1. Üzenet kinyerése egy naplósorból

Valósítsd meg a `message` függvényt, amely visszaadja egy naplósor üzenetét:

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

A kezdő és záró szóközöket el kell távolítani:

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. Naplózási szint kinyerése egy naplósorból

Valósítsd meg a `logLevel` függvényt, amely visszaadja egy naplósor naplózási szintjét, csupa kisbetűvel:

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. Naplósor újraformázása

Valósítsd meg a `reformat` függvényt, amely újraformázza a naplósort: az üzenetet teszi előre, utána pedig zárójelben a naplózási szintet:

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
