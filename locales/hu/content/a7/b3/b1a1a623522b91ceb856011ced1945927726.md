# Névjegy

A JavaScriptben van egy növelő és egy csökkentő operátor.
Ezek egy változót helyben módosítanak.
A `++` eggyel növel egy számot, a `--` pedig eggyel csökkent.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

A fenti példa a postfix növelő és csökkentő operátort mutatja be.
Ebben az esetben az operátor a változó után áll, és a kifejezés visszatérési értéke a változónak a növelés vagy csökkentés _előtti_ értéke.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

Van egy prefix változat is, amelyben az operátor a változó előtt áll.
Ekkor a visszatérési érték a változónak a növelés vagy csökkentés _utáni_ értéke.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
