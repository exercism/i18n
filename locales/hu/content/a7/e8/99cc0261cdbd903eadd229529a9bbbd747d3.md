# Bevezetés

## Öröklődés

Az öröklődés az OOP (objektumorientált programozás) egyik központi fogalma.
Egy „IS-A” kapcsolatot ír le.
A programozásban szó szerint ugyanazt jelenti, mint az angolban: tulajdonságokat örökölsz a szülőtől (a programozásban ezek a tulajdonságok általában függvények és változók).

Tekintsd például az `Animal` osztályt, ahogy az alábbiakban látható:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

Az `Animal` egy szülőosztály, mert a benne lévő tulajdonságok általánosságban minden állatra kiterjeszthetők.

Tekintsünk egy `Lion` nevű állatot, amelynek az osztálya így néz ki:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
Az `Override` annotációval jelezheted, hogy az alosztály egy metódusa felülírja a főosztály metódusát.
Nem szigorúan kötelező, de ajánlott használni.
~~~~

Most pedig, amikor ezt írjuk:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Megjegyzés: az `Animal` osztályt `Lion` értékkel inicializáljuk.
A kimenet a következő lesz:

```java
Lion here!!
```

Az OOP szerint az öröklődésnek több típusa van, de a Java csak néhányat támogat belőlük (a többszintűt és a hierarchikust).
Ha többet szeretnél olvasni róla, olvasd el [ezt][java-inheritance].
