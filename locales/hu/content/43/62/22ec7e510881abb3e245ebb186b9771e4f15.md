# Stringek

A Crystalben van egy [`String`][strings] nevű típus, amit szöveg ábrázolására használunk.
A Crystal stringek Unicode-karakterek sorozatai.
A stringek módosíthatatlanok, ami azt jelenti, hogy létrehozásuk után nem változtathatók meg.
Ez azt jelenti, hogy minden alkalommal új string jön létre, amikor módosítasz egy stringet; ezért az eredeti string nem változik.

Egy string definiálásához dupla idézőjelet `"` használsz.

```crystal
"Hello World"
```

## Összefűzés

Két string összefűzéséhez a `+` operátort használod.
A `+` operátor egy új stringet ad vissza, ami a két stringet összefűzi.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Stringek és számok közötti átalakítás

A `to_i` metódus egy stringet egész számmá alakít.
Alternatívaként a `to_f` metódussal lebegőpontos számot kaphatsz.
Ha a string nem alakítható számmá, akkor `ArgumentError` kivétel keletkezik.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Egy egész vagy lebegőpontos szám a `to_s` metódussal stringgé alakítható.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpoláció

Az interpoláció kényelmes módja a stringek kombinálásának és kifejezések stringbe ágyazásának.
Egy string interpolálásához a `#` karaktert használhatod, amit kapcsos zárójelek `{}` követnek, a kifejezés pedig a zárójelek között van.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

A Crystal automatikusan stringgé alakítja a kifejezés eredményét.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Méret

Amikor tudni szeretnéd, hány karakter van egy stringben, használhatod a `size` metódust, ami a string hosszát egész számként adja vissza.
A string mérete a string tárolt tulajdonsága, így nem kell minden metódushíváskor kiszámolni a méretet, ami nagyon gyorssá teszi.

```crystal
"Hello World".size
# => 11
```

## Indexelés

Az indexelés arra való, amikor egy adott karaktert szeretnél lekérni egy stringből.
Ahhoz, hogy karaktert kérj le egy `String`-ből, használhatod a megszokott szögletes zárójeles jelölést.

~~~~exercism/note
A `[]` egy String példánymetódusként van megvalósítva, ahol az index a metódus argumentuma.
~~~~

A Crystalben egy string első karaktere a 0. indexen található.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Ahhoz, hogy egy karaktert a string végéről kérj le, veheted a string hosszát mínusz egyet, hogy megkapd az utolsó karakter indexét; a második utolsó karakterhez a string hosszát mínusz kettőt, és így tovább.
Erre van egy egyszerűbb megoldás: egyszerűen használj negatív indexet, ahol az utolsó karakter a -1. indexen van, a második utolsó a -2. indexen, és így tovább.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

## Escape-elés

Néhány karaktert nem lehet közvetlenül stringbe írni, helyette escape-szekvenciát kell használnod.
Például, ha dupla idézőjelet szeretnél használni egy stringben, escape-elned kell a dupla idézőjelet.
A `\` karaktert használhatod escape-szekvencia írásához, amit az escape-elni kívánt karakter követ.

Ezek a speciális karakterek a Crystalben:

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | Riasztás                      |
| `\b`     | Visszatörlés                  |
| `\e`     | Escape                        |
| `\f`     | Lapdobás                      |
| `\n`     | Soremelés vagy újsor          |
| `\r`     | Kocsivissza                   |
| `\t`     | Vízszintes tabulátor          |
| `\v`     | Függőleges tabulátor          |
| `\\`     | Visszaperjel                  |
| `\'`     | Aposztróf                     |
| `\"`     | Dupla idézőjel                |
| `\377`   | Nyolcas számrendszerű ASCII-karakter |
| `\xFF`   | Tizenhatos számrendszerű ASCII-karakter |
| `\uFFFF` | Tizenhatos számrendszerű Unicode-karakter |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Többsoros stringek

Többsoros string írásához ugyanazt a szintaxist használod, mint egy egysoros stringnél, de minden sorhoz, amit a stringben szeretnél, új sort kezdesz.

```crystal
"Hello
World"
# => "Hello\nWorld"
```
