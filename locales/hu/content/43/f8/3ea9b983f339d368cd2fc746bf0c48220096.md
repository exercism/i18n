### Dinamikus függvényhívás

Az awk-függvények nem első osztályú objektumok: nem lehet őket úgy ide-oda adogatni, ahogy néhány más nyelv megengedi.
Egy változóban viszont eltárolhatod egy függvény _nevét_ (egy stringet), és a függvényt a speciális `@varname(args)` jelöléssel hívod meg.
Egy példa:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
Ezt a [Közvetett függvényhívások][indirect] szakasz írja le.
Ez a `gawk` egyik kiterjesztése.
