# Utasítások

A közeledben lévő helyi iskolának van egy nagyon aktív diákönkormányzata.
A diákönkormányzatot egy elnök vezeti, és kétévente választásokat tartanak új elnök megválasztására.
Az idei választáson úgy döntöttek, hogy új digitális rendszerre van szükség a szavazatok megszámlálásához.

Az iskola a segítségedet kéri az új rendszer megépítésében.

## 1. Szavazatszámláló létrehozása

Az új szavazási rendszer egyik első eleme egy szavazatszámláló.
Ez a számláló arra való, hogy nyomon kövesse, hány szavazata van egy adott jelöltnek.

Hozz létre egy `new_vote_counter` függvényt, amely elfogadja egy jelölt kezdeti szavazatainak számát, és visszaadja egy `VoteCounter` struktúra pillanatképét, a megadott kezdeti szavazatszámmal inicializálva.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. Szavazatok számának lekérése egy számlálóból

Most már van módod új számlálók létrehozására!
De most rájössz, hogy az új rendszernek is szüksége lesz egy módra, hogy lekérje a szavazatok számát egy számlálóból.

Hozz létre egy `vote_count` függvényt, amely argumentumként egy számlálót (`@VoteCounter`) fogad, és visszaadja a számlálóban lévő szavazatok számát.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. A számláló szavazatainak növelése

Végre eljött az idő a szavazatok megszámlálására!
Most szükséged van egy módra, amellyel növelheted a szavazatok számát egy számlálóban.

Hozz létre egy `increment_vote_count` függvényt, amely argumentumként egy számlálót (`@VoteCounter`) és egy szavazatszámot fogad, majd megnöveli a számlálót ennyi szavazattal.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. A választási eredmények létrehozása

Most, hogy minden szavazatot megszámoltak, itt az idő előkészíteni az eredményhirdetést az egész iskola számára.
Ehhez észreveszed, hogy nem elég, ha csak a szavazatok számlálói vannak.
Kell egy mód arra, hogy a szavazatok számát egy adott jelölthöz rendeld.

Hozz létre egy `new_election_result` függvényt, amely megkapja egy jelölt nevét és a szavazatai számát, majd visszaad egy új választási eredményt.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

A választási eredmény struktúra már létre van hozva neked, és így van definiálva:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. Az eredmények kihirdetése

Itt az idő bejelenteni az iskolának az új elnököt!
Az új elnököt az iskola kis digitális üzenőtábláin fogják kihirdetni.

Az üzenetnek mutatnia kell az új elnök nevét és a kapott szavazatok számát, a következő formátumban: `<candidate_name> (<votes>)`.
Íme egy példa egy ilyen üzenetre: `"Peter (51)"`.

Hozz létre egy `display_result` függvényt, amely argumentumként egy `@ElectionResult`-et fogad, és egy `ByteArray`-t ad vissza a megjelenítendő üzenettel.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. Szavazatok újraszámlálása

Hogy megbizonyosodjanak a végeredmény pontosságáról, újraszámolták a szavazatokat.
Az újraszámláláskor kiderült, hogy néhány jelölt szavazatainak száma eggyel eltért.

Hozz létre egy `decrement_votes_of_candidate` függvényt, amely megkapja a végeredményeket és egy jelölt nevét, akinek csökkentened kell a szavazatai számát.
A végeredmények egy `Felt252Dict<u32>` formájában vannak megadva, ahol a kulcsok a jelöltek nevei, az értékek pedig az adott jelölt összes szavazata.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
