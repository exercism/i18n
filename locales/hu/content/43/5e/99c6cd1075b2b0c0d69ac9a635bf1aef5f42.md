# Okos mutatók

Az okos mutatók a Cairoban egy erőteljes eszköz, amely biztonságos és hatékony memóriakezelést tesz lehetővé.

Az okos mutató egy olyan adatszerkezet, amely úgy viselkedik, mint egy hagyományos mutató, de extra biztonsági funkciókkal rendelkezik, hogy elkerülje a gyakori memóriakezelési problémákat, például a null mutatók hivatkozásfeloldását vagy a nem inicializált memória elérését.

## Mi az az okos mutató?

Általánosságban a mutató egy olyan változó, amely egy memóriacímet tárol, és általában az adott címen tárolt értékre mutat.

A nyers mutatók azonban veszélyesek lehetnek: ha a mutató nem érvényes memóriára mutat, vagy helytelenül oldják fel a hivatkozását, az összeomláshoz vagy kiszámíthatatlan viselkedéshez vezethet.

Az okos mutatók szigorú memóriakezelési szabályok betartatásával oldják meg ezt a problémát, biztosítva, hogy a memória elérése biztonságos és szabályozott módon történjen.

A Cairo, akárcsak számos modern nyelv, például a Rust, okos mutatókat használ a nem biztonságos memóriaelérés megelőzésére.

A Cairoban egy okos mutató nemcsak egy memóriacímet tárol, hanem a tulajdonjogot is nyomon követi, és biztosítja a memóriabiztonságot.

## Okos mutatók típusai a Cairoban

A Cairo többféle okos mutatót kínál, többek között a `Box<T>` és a `Nullable<T>` típust, amelyek mind más célt szolgálnak.

Nézzük meg közelebbről, hogyan működnek ezek a típusok, és mikor érdemes használni őket.

### `Box<T>`

A `Box<T>` típus a Cairo legfontosabb okos mutatója.

Lehetővé teszi, hogy az adatokat egy speciális memóriaszegmensben tárold, amelyet „boxed segmentnek” neveznek. A `Box<T>` egy erre a szegmensre mutató mutató, és amikor boxot hozol létre, helyet foglalsz az adatnak ebben a szegmensben.

A boxok ideálisak olyan helyzetekben, amikor:

- Olyan típusú értéket kell tárolnod, amelynek mérete nem határozható meg fordítási időben.
- Nagy mennyiségű adatod van, és a tulajdonjogot másolás nélkül szeretnéd átadni.

Box használatával hatékonyabban tárolhatsz nagy adatszerkezeteket.

Amikor egy `Box<T>`-t adsz át egy függvénynek, csak a mutató adódik át, így nem kell az egész adatot másolni, ami javítja a teljesítményt, különösen nagy szerkezetek esetén.

### `Nullable<T>`

A `Nullable<T>` egy másik fontos okos mutató a Cairoban.

Vagy egy érvényes `T` típusú értékre mutat, vagy `null`, ha nincs érték.

Ez a típus olyan esetekben hasznos, amikor olyan értékeket kell tárolnod, amelyek nem mindig léteznek, például egy szótárban, amely opcionális elemeket tartalmazhat.

A Cairoban a `Nullable<T>`-t jellemzően szótárakban használják olyan esetek kezelésére, amikor nem alkalmazható alapértelmezett érték.

Lehetővé teszi az értékek feltételes tárolását, megkönnyítve az adatok biztonságos hiányának kezelését.

## Memóriabiztonság okos mutatókkal

Az okos mutatók használatának egyik fő előnye, hogy segítenek biztosítani a memóriabiztonságot.

A tulajdonjog és a hozzáférési szabályok kezelésével a Cairo megelőzi az olyan gyakori problémákat, mint a null vagy lógó mutatók hivatkozásfeloldása.

Az okos mutatók nyomon követik, hogy mikor nincs már szükség az adatokra, és automatikusan felszabadíthatják a memóriát, amikor az kikerül a scope-ból, csökkentve a memóriaszivárgás kockázatát.

### Példa: `Box<T>` használata rekurzív típusokhoz

Sok programozási nyelvben gyakori kihívás a rekurzív típusok kezelése.

A rekurzív típusok olyan típusok, amelyek hivatkozásokat tartalmaznak önmagukra.

Megfelelő memóriakezelés nélkül egy rekurzív típus definiálása olyan problémákhoz vezethet, mint a végtelen rekurzió.

A Cairoban a `Box<T>` teszi lehetővé a rekurzív típusok biztonságos definiálását.

Például a `Box<T>` segítségével bináris fát valósíthatsz meg, ahol minden csomópont egy másik csomópontra mutató hivatkozást tartalmaz.

A hivatkozások boxokban tárolásával a Cairo biztosítja, hogy a memóriahasználat véges legyen, és a fordító meg tudja határozni a szerkezet által igényelt memóriaméretet.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### Az okos mutatók teljesítményelőnyei

Az okos mutatók a programjaid teljesítményét is javítják.

Amikor `Box<T>`-t használsz, csak az adatra mutató mutató adódik tovább, ahelyett hogy a teljes adatszerkezetet másolnád.

Ez különösen nagy adathalmazok esetén hasznos, mivel jelentősen csökkenti a memóriaműveletek többletköltségét.

A következő példában az adatok referenciaként adódnak át egy `Box<T>` segítségével, hogy elkerüljük a teljes szerkezet másolásának költségét:

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

Ebben a példában a `pass_pointer` egy `Cart` helyett `Box<Cart>`-ot kap, ami csökkenti a függvényhívás során másolt memória mennyiségét.
