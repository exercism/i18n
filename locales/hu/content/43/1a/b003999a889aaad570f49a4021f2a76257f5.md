# Tesztek

Ha a 8th bináris szerepel a path-on, írd be a következő parancsot:

```bash
8th -f test.8th
```

Ha a 8th bináris nincs rajta a PATH-on, Windowson ezt írd be:

```cmd
\path\to\8th -f test.8th
```

Linuxon vagy macOS-en:

```bash
/path/to/8th -f test.8th
```

## Tesztelés a REPL-ben

Indítsd el a 8th-ot a test-words.8th betöltésével:

```sh
8th -f test-words.8th
```

Ez egy parancssori felület munkamenetet indít, ahol miután írtál egy kis kódot a megoldásfájlodba, betöltheted azt a REPL-be.
Például a „word-count” feladatnál ezt írnád be:

```8th
"word-count.8th" f:include
```

A teszteket pedig így futtathatod:
```sh
"word-count-tests.8th" f:include
```

Vagy bemásolhatsz egyetlen tesztet abból a fájlból, vagy beírhatod a sajátodat.

## Kihagyott tesztek

Egy feladat megoldása azt jelenti, hogy az összes tesztjét sikeressé teszed.
Alapértelmezés szerint csak egy teszt (az első) fut le, amikor futtatod a teszteket.
Ez szándékos, mert így arra összpontosíthatsz, hogy épp azt az egy tesztet tedd sikeressé.
Amint sikerül, engedélyezheted a következő tesztet úgy, hogy a `SKIP-REST-OF-TESTS` szót utána helyezed.

## A kihagyások felülírása

Az összes teszt futtatásához, beleértve a `SKIP-REST-OF-TESTS` szó utániakat is, beállíthatod a `RUN_ALL_TESTS` környezeti változót `true` értékre.
Ennek egyik módja, hogy csak a tesztek futtatásának idejére állítod be (macOS és Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
