# Bevezetés

A kiterjesztő metódusok lehetővé teszik, hogy metódusokat adjunk a meglévő típusokhoz anélkül, hogy új származtatott típust hoznánk létre, újrafordítanánk a kódot, vagy más módon módosítanánk az eredeti típust. Statikus metódusként vannak definiálva, de példánymetódus-szintaxissal hívjuk meg őket. Első paraméterük előtt a `this` módosító áll, amely megadja, hogy a metódus melyik típuson működik; a metódusok névtér szintjén kerülnek be a scope-ba.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
