# Telepítés

## A Godot Engine telepítése

A GDScript kurzus a [Godot Engine][godot-engine]re épül, amely Windowson, Linuxon, macOS-en és Androidon fut.
Egyelőre a [helyi munkához][working-locally] tartozó tesztfuttató Linuxot igényel.
Ez a kurzus a Godot 4.0-s vagy újabb verzióját igényli.

A telepítés befejezése után a következő parancs terminálban való futtatásával ellenőrizheted, hogy a parancssori felület telepítése sikeres volt-e:

```bash
godot --version
```

## Az Exercism GDScript kurzus tesztfuttatójának telepítése

A tesztfuttató használatához [megfelelően telepített Godotra][installation] lesz szükséged.

Ahhoz, hogy GDScript-szkripteket fordíts és tesztelj az Exercism-höz, a Godotot „headless” módban futtatjuk a parancssori felületről.
Ezek az utasítások egyelőre Linuxot és bash-t igényelnek.

### 1. lépés: A teljes tesztfuttató infrastruktúra telepítése

A tesztelés előkészítéséhez klónozd a [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] tárolót, és mozgasd a tartalmát a `/opt/test-runner/` könyvtárba:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### 2. lépés: Az egy feladathoz tartozó tesztfuttató szkript letöltése

Feltéve, hogy beállítottad az `exercism` eszközt, és letöltöttél legalább egy GDScript-feladatot, a munkaterületed alatt létre kellett hoznia egy `gdscript` mappát (ezt az `exercism configure` futtatása mutatja meg), amely a feladatokat tárolja.
Mentsd el [a tesztfuttatót][test-local-gdscript-solution] ebbe a mappába, és jelöld a fájlt futtathatóként.

## A tesztek futtatása

A telepítési lépések elvégzése után bármelyik feladat könyvtárából kiindulhatsz (pl. `~/exercism/gdscript/two-fer`), és lefuttathatod a szkriptet (amely egy szinttel feljebb, a `../` mappában található), hogy teszteld a helyi megoldásodat arra a feladatra:

```sh
../test-local-gdscript-solution.sh
```

## IDE használata

Ahhoz, hogy GDScript-szintaxiskiemelést kapj egy olyan szerkesztőben, mint a [Visual Studio Code][vscode], telepítened kell egy bővítményt, például a [godot-tools][godot-tools]t, valamint futnia kell egy hibakereső kiszolgálónak.
A Godot ezt a hibakereső kiszolgálót automatikusan elindítja, amikor egy projekt meg van nyitva a saját szerkesztőjében, és addig fut, amíg a projektet vagy magát a Godotot be nem zárják.
