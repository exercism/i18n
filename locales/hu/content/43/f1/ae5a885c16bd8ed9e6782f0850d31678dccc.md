# Utasítások

Ebben a feladatban egy módot valósítasz meg arra, hogy nyomon kövesd a helyi játéktermed legnépszerűbb játékának csúcspontszámait.

Hét függvényt kell megvalósítanod, amelyek mindegyike egy csúcspontszám-adatokat tároló szótár visszaadásához és módosításához kapcsolódik.

## 1. Definiálj egy új csúcspontszám-szótárat

Hozz létre egy `newScoreBoard()` függvényt, amely nem vár paramétert, és egy új csúcspontszám-szótárat ad vissza, amelyben a kulcsok `String`, az értékek pedig `Int` típusúak.

## 2. Adj játékosokat a csúcspontszám-szótárhoz

Ha játékost szeretnél hozzáadni a csúcspontszám-szótárhoz, definiáld az `addPlayer(_:_:_:)` függvényt, amely 3 paramétert vár:

- Az első paraméter a pontszámok szótára. 
    Ennek in-out paraméternek kell lennie.
- A második paraméter a játékos neve stringként.
- A harmadik paraméter a pontszám egész számként. 
    A paraméter opcionális, a harmadik paramétert 0 alapértelmezett értékkel valósítsd meg.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Távolítsd el a játékosokat a pontszámok szótárából

Ha el szeretnél távolítani egy játékost a csúcspontszám-szótárból, definiáld a `removePlayer(_:_:)` függvényt, amely 2 paramétert vár:

- Az első paraméter a pontszámok szótára. 
    Ennek in-out paraméternek kell lennie.
- A második paraméter a játékos neve stringként.

A függvény távolítsa el a játékost a szótárból, ha benne van, egyébként pedig ne tegyen semmit.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Állítsd vissza egy játékos pontszámát

Ha vissza szeretnéd állítani egy játékos pontszámát, definiáld a `resetPlayer(_:_:)` függvényt, amely 2 paramétert vár:

- Az első paraméter a pontszámok szótára.
    Ennek in-out paraméternek kell lennie.
- A második paraméter a játékos neve stringként, akinek a pontszámát vissza szeretnéd állítani.

A függvény a játékos pontszámát 0-ra állítja. 
Ha a játékos nincs benne a szótárban, akkor ne történjen semmi.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Frissítsd egy játékos pontszámát

Ha úgy szeretnéd frissíteni egy játékos pontszámát, hogy hozzáadsz az előző pontszámhoz, definiáld az `updateScore` függvényt, amely 3 paramétert vár:

- Az első paraméter a pontszámok szótára. Ennek in-out paraméternek kell lennie.
- A második paraméter a játékos neve stringként, akinek a pontszámát frissíteni szeretnéd.
- A harmadik paraméter a pontszám, amelyet **hozzá** szeretnél adni a tárolt csúcspontszámhoz.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Kérj listát a játékosokról a nevük szerint rendezett pontszámokkal

Definiáld az `orderByPlayers` függvényt, amely 1 paramétert vár:

- Az első paraméter a pontszámok szótára.

A függvény egy `(String, Int)` tuple-ökből álló tömböt ad vissza, ami a játékosokat és csúcspontszámaikat tartalmazza, a játékos neve szerint növekvő sorrendbe rendezve.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Kérj listát a játékosokról a pontszámuk szerint csökkenő sorrendben

Ha listát szeretnél kapni a játékosokról a pontszámuk szerint csökkenő sorrendben, definiáld az `orderByScores` függvényt, amely 1 paramétert vár:

- Az első paraméter a pontszámok szótára.

A függvény egy `(String, Int)` tuple-ökből álló tömböt ad vissza, ami a játékosokat és csúcspontszámaikat tartalmazza, a játékos pontszáma szerint csökkenő sorrendbe rendezve.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
