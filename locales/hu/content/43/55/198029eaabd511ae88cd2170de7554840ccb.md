# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat       | Típus     | Leírás                          |
| --------- | --------------- | --------- | ------------------------------- |
| `$a0`     | bemenet         | cím       | nullával lezárt név string      |
| `$a1`     | bemenet         | egész szám | szám                            |
| `$a2`     | bemenet/kimenet | cím       | nullával lezárt eredmény string |
| `$t0-9`   | ideiglenes      | bármilyen | ideiglenes tárolásra            |
</output>
