# Bevezetés

Go-ban a `for range` egy kódrészletet ismétel meg egy `range`-kifejezés értékein.
A `range`-kifejezés dönti el, hogy az egyes iterációk egy vagy két értéket adnak-e vissza.

## `range`-kifejezések

### `range` egy `slice` felett

A `slice` feletti `range` sorrendben adja vissza minden elem indexét és értékét:

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### `range` egy `map` felett

A `map` feletti `range` minden kulcsot és értéket visszaad, de az iteráció sorrendje nem garantált.
A Go szándékosan véletlenszerűvé teszi a `map` feletti iteráció sorrendjét, ezért ugyanaz a program futásonként más kimenetet adhat.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### `range` egy string felett

A `string` feletti `range` a bájtindexet és az egyes rune-okat (Unicode-kódpontokat) adja vissza.
A következő példában a `子` három bájtot foglal el, ezért a `猫` a `3` bájtindexnél kezdődik, nem az `1`-nél.

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

Ha inkább rune-indexekre van szükséged, alakítsd át a stringet rune-okból álló slice-dá:

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### `range` egy egész szám felett

A `range` közvetlenül egy egész szám felett is iterálhat: ilyenkor `0`-tól az adott számig adja vissza az értékeket, de magát a számot már nem.
A nulla és a negatív értékek érvényesek, de egyetlen iterációt sem eredményeznek.

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### `range` egy iterátor felett

A `range` elfogad `iter.Seq[V]` vagy `iter.Seq2[K, V]` típusú iterátort.
Az iterátor olyan függvény, amely egyszerre egy értéket állít elő egy értéksorozatból.
A `range` aztán végighaladhat ezeken az értékeken.

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### `range` egy channel felett

Végül a `range` fogadhatja az egy channelen keresztül küldött értékeket egészen addig, amíg a channelt máshol be nem zárják.
A channelekről a kurzus tantervének későbbi részében lesz szó bővebben.

## Az index vagy az érték elhagyása

A Go nem fordítja le a programot, ha egy változót deklarálsz, de soha nem használod.

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

Ha csak az értékre van szükséged, rendeld az indexet vagy a kulcsot `_`-hoz, hogy figyelmen kívül hagyd.

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

Ha csak az indexre van szükséged, hagyd el teljesen az értéket:

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

Ha sem az indexre, sem az értékre nincs szükséged, mindkettőt elhagyhatod:

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
