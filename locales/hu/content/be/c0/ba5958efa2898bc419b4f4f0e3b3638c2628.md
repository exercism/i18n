# Részletesen

A *reguláris kifejezés* (regex) egy kis minta, amely leírja egy szöveg alakját. A Factor regexeszközei a [`regexp`][regexp] szókészletben találhatók, a mintát pedig `R/ ` és `/` közé írt literálként adjuk meg.

A mintában a legtöbb karakter önmagára illeszkedik. A kifejezőerőt a karakterosztályok és a kvantorok adják:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

A `R/ [A-Z]{2}-\d{4}/` tehát a »két nagybetű, egy kötőjel, négy számjegy« alakzatra illeszkedik.

## Illesztés a teljes stringre vagy keresés

A `matches?` csak akkor sikeres, ha a *teljes* string illeszkedik a mintára. A többi szó viszont a stringen *belül* keres:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## Szeletek

A `first-match` és a `re-split` `slice` objektumokat ad vissza: ezek könnyűsúlyú nézetek az eredeti stringbe, nem pedig új stringek. Ha önálló stringre van szükséged (például hogy összehasonlítsd egy stringliterállal), a `>string` szóval alakítsd át a slice-ot. Az `all-matching-subseqs` már eleve stringeket ad vissza.

## Helyettesítés

A `re-replace` minden találatot lecserél a helyettesítő stringre, és visszaadja az eredményt:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## Minta építése futásidőben

A `R/ /` a fájl betöltésekor értelmeződik. Ha futásidőben kiszámított stringből szeretnél mintát építeni, használd a `<regexp>` szót:

```
<regexp> ( string -- regexp )
```
