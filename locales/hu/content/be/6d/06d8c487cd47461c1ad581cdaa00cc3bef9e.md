# https://www.php.net/manual/en/language.basic-syntax.phptags.php"A hatókörfeloldó operátor

A hatókörfeloldó operátor (`::`) segítségével egy osztályra hivatkozhatunk, hogy hozzáférjünk a nevesített konstansaihoz, statikus tulajdonságaihoz vagy statikus metódusaihoz.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## A `self` és a `static` használata a hatókörfeloldó operátorral

Előfordulhat, hogy egy objektumnak a saját hatókörére kell hivatkoznia. Erre a `self` kulcsszó ad lehetőséget: segítségével egy osztály a saját hatókörére hivatkozhat. A `self` kulcsszó használatával az osztály leválik a saját nevéről, ami megkönnyíti a kód hosszú távú karbantartását.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

A `self` azonban lexikálisan ahhoz az osztályhoz kötődik, amelyben megjelenik.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

A `MyOtherClass::getMyValue` kiértékelése így is `1` lesz `99` helyett. Ha ezt el akarod kerülni, használd a `static` kulcsszót a hatókörfeloldó operátorral, hogy a hivatkozás „késői kötéssel” az aktuális leszármazott osztályra vonatkozzon.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## A `parent` használata a hatókörfeloldó operátorral

Előfordulhat, hogy kifejezetten egy szülő hatókörből elérhető konstansra, tulajdonságra vagy metódusra kell hivatkoznod:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

Az objektumorientált programozásban leggyakrabban arra használjuk a `parent` kulcsszót, hogy egy objektum példányosításakor meghívjuk a szülő konstruktorát:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Fenntartások

### A konstansok, tulajdonságok és metódusok láthatósága

A hatókörfeloldó operátorra továbbra is a `public`, `private` és `protected` láthatósági módosítókban lefektetett szabályok érvényesek.
