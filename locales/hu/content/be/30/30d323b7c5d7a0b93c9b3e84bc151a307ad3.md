# Részletesen

A `PHP 8.0.0`-tól érhető el: az **Unió típusdeklarációk** több különböző típus értékét is elfogadják egyetlen típus helyett. Az unió típusoknál a típusokat egy függőleges vonallal (`|`) választjuk el egymástól.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Finomságok

- A `null` típust _nullable_ módon is deklarálhatod, ha a `?Type` vagy a `Type1|Type2|null` alakot használod.
- a kétszer szereplő vagy felesleges típusok megadása fordítási idejű hibát okoz.
- a `void` nem használható unió típusdeklaráció részeként.
