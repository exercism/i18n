# Ajánlott tanulási források

Az Exercism feladatokat és visszajelzést kínál, de ha most ismerkedsz meg az ABAP-pal, nehéz lehet belevágni. Ezek az ingyenes források segíthetnek az indulásban:

* SAP Learning Journey [Learning the Basics of ABAP Programming](https://learning.sap.com/courses/learn-the-basics-of-abap-programming-on-sap-btp)
* [ABAP for Newbies Community](https://pages.community.sap.com/topics/abap/abap-for-newbies)
* [ABAP Language Documentation](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm)
* [ABAP Starter](https://github.com/Keller-Michael/ABAP_starter)
* [ABAP Cheat Sheets](https://github.com/SAP-samples/abap-cheat-sheets)

Ha most ismerkedsz az ABAP-pal, javasoljuk, hogy végezd el az SAP Learning Journey következő egységeit:

- Getting Started
- ABAP Language Basics
- Local Classes 

Ezután készen állsz arra, hogy ABAP-feladatokat oldj meg az Exercismen.

Ha összetettebb feladatokhoz érsz, javasoljuk, hogy ezeket az egységeket is nézd át:

- Structures
- Complex Internal Tables

Ezek a témák hasznosak lehetnek a nehezebb Exercism-feladatok megoldásában.
