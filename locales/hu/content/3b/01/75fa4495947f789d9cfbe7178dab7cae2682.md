# Utasítások

Daphne egy rendszert fejlesztett, amellyel a kísérleteit futtatja és rögzíti azok eredményeit. A kód egy része kicsit bőbeszédűvé és ismétlődővé vált, ezért megkért, hogy írj néhány `use` kifejezést, amelyek segítenek letisztázni.

## 1. Definiáld a `with_retry` függvényt

Néha egy kísérlet egy egyszeri hiba miatt elbukhat, ezért ha egy kísérlet sikertelen, Daphne szeretné újra megpróbálni, hogy lássa, másodszorra sikerül-e.

Definiáld a `with_retry` függvényt, amely argumentumként egy eredményt visszaadó függvényt kap.

Ha a függvény `Ok` értéket ad vissza, akkor a `with_retry` is azt az értéket adja vissza.

Ha a függvény `Error` értéket ad vissza, akkor a `with_retry` újra meghívja a függvényt, és annak a hívásnak az eredményét adja vissza.

Daphne így fogja használni a függvényt:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. Definiáld a `record_timing` függvényt

Daphne úgy rögzíti, hogy mennyi ideig tart az egyes kísérletek futtatása, hogy minden kísérlet előtt és után meghív egy időnaplózó függvényt.

Definiáld a `record_timing` függvényt, amely két argumentumot kap:
- Egy időnaplózó függvényt, amely nem kap argumentumot, és `Nil`-t ad vissza.
- Egy kísérletfüggvényt, amely nem kap argumentumot, és egy eredményt ad vissza.

A `record_timing` először meghívja az időnaplózó függvényt, majd a kísérletfüggvényt, aztán ismét az időnaplózó függvényt, végül pedig visszaadja a kísérletfüggvény eredményét.

Daphne így fogja használni a függvényt:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. Definiáld a `run_experiment` függvényt

A kísérletek három fázisból állnak: az előkészítésből, a végrehajtásból és a rögzítésből. Mindhárom fázis eredményt ad vissza, és mindegyik fázisnak szüksége van az előző fázis sikeres eredményére ahhoz, hogy lefusson.

Definiáld a `run_experiment` függvényt, amely négy argumentumot kap:
- A kísérlet nevét egy `String`-ként.
- Egy előkészítő függvényt, amely nem kap argumentumot, és egy eredményt ad vissza.
- Egy végrehajtó függvényt, amely argumentumként az előkészítő függvény `Ok` értékét kapja, és egy eredményt ad vissza.
- Egy rögzítő függvényt, amely argumentumként az előkészítő és a végrehajtó függvény `Ok` értékét kapja, és egy eredményt ad vissza.

Ha mindhárom függvény sikeresen lefut, akkor a `run_experiment` a `Ok(#(experiment_name, recording_data))` értéket adja vissza.

Ha bármelyik függvény `Error` értéket ad vissza, akkor a `run_experiment` azt az értéket adja vissza.

Daphne így fogja használni a függvényt:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
