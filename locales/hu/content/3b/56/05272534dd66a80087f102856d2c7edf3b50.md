# Módosíthatóság

A Cairo a blokkláncra tervezett felépítésével alapértelmezés szerint módosíthatatlan memóriamodellt valósít meg.
Ez azt jelenti, hogy ha egy érték egyszer bekerült a memóriába, nem írható felül, csak olvasható.
A Cairo azonban biztosít egy mechanizmust módosítható változók létrehozására a `mut` kulcsszóval.
Amikor egy változót módosíthatóként deklarálunk, és az értéke megváltozik, az új érték egy új memóriacellába kerül, a változó pedig frissül, hogy az új cellára mutasson.
Ez a mechanizmus rugalmasságot tesz lehetővé, miközben megőrzi a módosíthatatlanság előnyeit.

Az alábbi példában az `x` módosíthatatlan változóként van deklarálva.
Ha megváltoztatjuk az `x` értékét, a fordító hibát jelez.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

A `mut` kulcsszóval deklarálhatjuk az `x`-et módosítható változóként.
Ez lehetővé teszi, hogy az `x` értékét a deklarálás után megváltoztassuk.

```rust
let mut x = 5;
x = 10;
```

Végső soron rajtad múlik, hogy élsz-e a módosíthatósággal vagy sem, és hogy az adott helyzetben mi tűnik a legvilágosabbnak.

## Konstansok

A módosíthatatlan változókhoz hasonlóan a konstansok olyan értékek, amelyek egy névhez vannak kötve, és nem változhatnak, de néhány dologban különböznek a változóktól:

- A konstansokat a `const` kulcsszóval deklaráljuk
- Nem használhatod a `mut` kulcsszót konstansoknál
- Az érték típusát mindig explicit módon meg kell adni
- A konstansok csak globális scope-ban deklarálhatók
- A konstansok értéke csak konstans kifejezés lehet, nem pedig egy futásidőben kiszámított érték eredménye

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

A `consteval_int!` makróval létrehozhatsz olyan `const` változót, amely valamilyen számítás eredménye.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## Árnyékolás

Lehetséges, és gyakran idiomatikus is, hogy ugyanazt a változónevet újra felhasználjuk, miközben egy adott érték átalakul, egyszerűen úgy, hogy több `let` utasítással újra deklaráljuk.
Ezt _árnyékolásnak_ nevezik.
Valójában a második változó árnyékolja az elsőt, és magához vonja a változónév minden használatát mindaddig, amíg őt magát is árnyékba nem vonja egy másik változó, vagy amíg a scope véget nem ér.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

Árnyékolással akár a változó típusát is megváltoztathatjuk, miközben ugyanazt a változónevet használjuk.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
