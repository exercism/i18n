# Bevezetés

## Stringek

Emlékezz vissza, hogy a `jq` ugyanazokat az adattípusokat támogatja, mint a JSON.
A JSON a **stringeket** így írja le:

> A string nulla vagy több Unicode-karakter sorozata, kettős idézőjelek közé zárva, fordított perjeles escape-szekvenciák használatával.

### Escape-szekvenciák

A stringen belül a fordított perjel karakterrel ágyazhatsz be „speciális” karaktereket:

- `\"` egy szó szerinti idézőjel,
- `\\` egy szó szerinti fordított perjel,
- whitespace-karakterek `\n`, `\t`, `\r`, `\f`, `\b`
- unicode-karakterek `\uAAAA`, ahol `A` egy hexadecimális számjegy

### String hossza

A karakterek számának meghatározásához a `length` függvényt használd.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### Részstringek

A **szeletelés** jelöléssel részstringeket nyerhetsz ki.
A szintaxis `.[i:j]`.
A visszaadott részstring hossza `j - i`, és az `i` indexű karaktertől (beleértve) a `j` indexű karakterig (kizárva) adja vissza a karaktereket.
Mindkét index lehet negatív, ilyenkor a string végétől számol vissza.
Mindkét index elhagyható, ilyenkor a string elejére vagy végére utal.
Az indexelés nullától kezdődik.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### Összefűzés

A stringek összefűzéséhez a `+` operátort használd:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Ha stringek tömbjét kapod, használd az `add` függvényt:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### Szétvágás és összekapcsolás

A szétvágáshoz a `split/1` függvényt vagy a `/` operátort használhatod:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

A `split/1` inverze a `join/1`.

Gyakran szükség van arra, hogy egy stringet karakterek tömbjévé alakítsunk.
Erre kétféleképpen van lehetőség:

1. vágd szét üres stringen

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` segítségével alakítsd _kódpontok_ tömbjévé

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   Az `implode` az `explode` inverze.

### Részstring indexének megkeresése

Az `index/1` függvényt használd; az index nullától kezdődik.

```jq
"hello" | index("el")'   # => 1
```

Ha a részstring nincs benne a stringben, az eredmény `null`

```jq
"hello" | index("elk")   # => null
```

### String-interpoláció

Egy stringen belül a `\(expression)` szekvencia beágyazza a kifejezés _eredményét_ [a stringbe][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### Kis- és nagybetűváltás

Az `ascii_downcase` és `ascii_upcase` függvényeket használd.
