# Utasítások

Leendő varázslóként Elyse-nek gyakorolnia kell néhány alapvető dolgot.

Van egy kártyapaklija, amit szeretne mozgatni.

Hogy egy kicsit könnyebb legyen, csak az 1-től 10-ig terjedő kártyákat használja.

A kártyapaklit egy `Array` reprezentálja: a pakli alja a tömb elején, a teteje pedig a tömb végén van.

## 1. Szúrj be egy kártyát a pakli tetejére

Valósítsd meg az `insert_top` függvényt, amely a pakli egy másolatát adja vissza úgy, hogy a megadott új kártya a pakli tetejére kerül.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. Vegyél le egy kártyát a pakli tetejéről

Valósítsd meg a `remove_top_card` függvényt, amely a pakli egy másolatát adja vissza, miután eltávolította annak felső kártyáját.

Ha a megadott pakli üres, akkor az eredeti paklit kell visszaadni, változatlanul.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. Szúrj be egy kártyát a pakli aljára

Valósítsd meg az `insert_bottom` függvényt, amely a pakli egy másolatát adja vissza úgy, hogy a megadott új kártya a pakli aljára kerül.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. Vegyél le egy kártyát a pakli aljáról

Valósítsd meg a `remove_bottom_card` függvényt, amely a pakli egy másolatát adja vissza, miután eltávolította annak alsó kártyáját.

Ha a megadott pakli üres, akkor az eredeti paklit kell visszaadni, változatlanul.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. Ellenőrizd a pakli méretét

Valósítsd meg a `check_size_of_stack` függvényt, amely ellenőrzi, hogy a pakli mérete megegyezik-e a megadott `stack_size` értékkel vagy sem.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
