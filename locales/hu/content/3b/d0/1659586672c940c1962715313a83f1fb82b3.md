# Utasítások

A barátod épp most küldött neked egy üzenetet egy fontos titokkal.
Mivel nem akarta, hogy mások könnyen elolvashassák, az üzenetet bitműveletek sorozatával titkosította.
Neked kell megírnod a függvényeket, amelyek segítenek visszafejteni az üzenetet.

## 1. A bitek visszatolása

Az üzenet visszafejtésének első lépése, hogy a titkosítás során eltolt biteket visszatoljuk jobbra.
A visszafejtés további lépései abból indulnak ki, hogy a 0-k a bal oldalról kerülnek be.

Valósítsd meg a `shift_back()` függvényt, amely egy értéket és az eltolás helyeinek számát kapja, és végrehajtja az eltolást.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Néhány bit beállítása

Ezután néhány bitet 1-re kell állítani.

Valósítsd meg a `set_bits()` függvényt, amely egy értéket és egy maszkot kap, és visszaadja annak eredményét, hogy az érték bitjeit 1-re állítja.
Az `value` bitjét ott kell 1-re állítani, ahol a `mask` megfelelő bitje is 1.
Minden más bit változatlan marad.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Bizonyos bitek megfordítása

A titkosítás során bizonyos bitek megfordulnak.
Ezeket vissza kell fordítani az üzenet visszafejtéséhez.

Valósítsd meg a `flip_bits()` függvényt, amely egy értéket és egy maszkot kap.
A maszk megmondja, hogy az érték mely bitjeit kell megfordítani.
Ahol a `mask` bitje 1, ott a `value` megfelelő bitje megfordul.
Minden más bit változatlan marad.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Bizonyos bitek 0-ra állítása

Végül vannak olyan bitek is, amelyek mindig 0-ra fejtődnek vissza.

Valósítsd meg a `clear_bits()` függvényt, amely egy értéket és egy maszkot kap.
A `value` bitjeit ott kell 0-ra állítani, ahol a maszk bitje 1.
Minden más bit változatlan marad.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
