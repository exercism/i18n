# Tesztek

  ## Gyors áttekintés

  1. Végezd el a módosításokat a `<myFileName>.u` fájlban
  2. Mentsd el a `<myFileName>.u` fájlt
  3. Ha a fájl átmegy a típusellenőrzésen, futtasd az `add` vagy `update` UCM-parancsokat
    * Ha a fájl nem megy át a típusellenőrzésen, addig módosítsd a kódot a `<myFileName>.u` fájlban, amíg le nem fordul. Ne felejtsd el `update`-elni a függvényeidet a módosítások után! 
  4. Futtasd a `load <myFileName>.test.u` parancsot az UCM cli-ben, hogy a teszteket scope-ba hozd és lefuttasd őket

  ## Végigvezetés

  Ha egy Exercism-feladaton dolgozol a parancssorból, valószínűleg abban a könyvtárban fogod megírni a megoldásodat, amely az adott feladat nevét viseli. Ha például a feladat a `hello-world`, akkor először a `cd` paranccsal lépj be a `~/exercism/unison/hello-world` könyvtárba, majd onnan nyisd meg a `ucm`-et. Az implementációdat a `hello.u` fájlban módosítsd, és amikor elégedett vagy vele, írd be az `add` vagy `update` parancsot az Unison codebase manager CLI-ben (UCM), hogy a munkádat a fájlból a codebase-be emeld.

  Az egyes feladatok tesztjeit tartalmazó fájl neve `.test.u` utótaggal végződik. A teszteket az UCM `load` parancsával érdemes scope-ba hozni és lefuttatni. A `load` parancs argumentumként egy fájlútvonalat vár. A hello world feladatnál ez valahogy így nézhet ki:

  ```
  .> load hello.test.u
  ```

  Az UCM-től kapsz egy üzenetet a scope-ba került terminusokról, és ami a legfontosabb, a teszt futtatásának eredményét is látnod kell:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  Tegyük fel, hogy a tesztjeid nem mentek át elsőre. Válts vissza a `myExercise.u` fájl szerkesztésére, és mentés után `update`-elhetsz:

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  Ezután újra betölthetjük a tesztjeinket, hogy lássuk, változott-e valami!

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
