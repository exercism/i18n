# Bevezetés

## Switch

A [switch utasítás][switch] lehetővé teszi, hogy egy értéket több lehetséges egyező értékkel hasonlíts össze.
Segítségével tömörebb kódot írhatsz, mint több `else-if` utasítás használatával.
A switch utasítás a `switch` kulcsszóval kezdődik, amelyet az összehasonlítandó érték követ.
Ezután az eseteket a `case` kulcsszóval definiálhatod, amelyet az az érték követ, amellyel össze szeretnéd hasonlítani.
A `default` kulcsszóval adhatod meg az alapértelmezett esetet, amikor egyik eset sem egyezik.
Az `else-if` utasításokhoz hasonlóan a `switch` utasítások is csak az első egyező esethez tartozó kódblokkot hajtják végre.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Nézzük a következő példát:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Ehelyett így is írható:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## While-ciklusok

A [while-ciklus][while-loops] egy vezérlési utasítás, amely lehetővé teszi, hogy a kód addig fusson, amíg egy adott feltétel igaz.
A Swift kétféle while-ciklust kínál: a while és a repeat-while ciklust.
A while-ciklus feltételét a ciklusmag végrehajtása előtt értékeli ki; ha a feltétel hamis, a ciklusmag egyáltalán nem fut le.
A while-ciklusok felépítése Swiftben a következő:

```swift
while <#condition#> {
  <#code#>
}
```

Itt a ciklus addig fut, amíg a count nagyobb, mint 0, és ennek eredményeként kiírja a 2-es és 1-es számot, valamint a „Liftoff!” szöveget.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

A [repeat-while ciklus][while-loops] hasonló a while-ciklushoz, de a feltétel a ciklusmag végrehajtása után értékelődik ki.
Ez azt jelenti, hogy a ciklusmag mindig legalább egyszer lefut, még akkor is, ha a feltétel hamis.
A repeat-while ciklusok felépítése Swiftben a következő:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Itt a ciklus csak egyszer fut le, mivel a feltétel hamis.
Mivel repeat-while ciklusról van szó, a ciklusmag egyszer lefut, mielőtt a feltétel kiértékelődik.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Vezérlésátadás

A Swift rendelkezik olyan utasításokkal, amelyekkel megváltoztatható a ciklusok normál vezérlési folyama.
Ezeket vezérlésátadó utasításoknak nevezzük.
A `return`-t már láttad; ez a fogalom további vezérlésátadó utasításokat mutat be, köztük a `continue`-t, a `break`-et és a címkéket.
A `fallthrough`-ról ebben a fogalomban nem lesz szó, de a [Swift könyvben][fallthrough] olvashatsz róla.

### Continue

Néha szükség van arra, hogy egy ciklusban idő előtt a következő iterációra ugorjunk, anélkül hogy befejeznénk a ciklus aktuális iterációjának többi utasítását.
Erre a `continue` kulcsszó használható.
Amikor a `continue` végrehajtódik, a ciklus a következő ellenőrzéshez ugrik, hogy lássa, lefuttatható-e a ciklus következő iterációja, azaz a `while` a while és repeat-while ciklusokban, vagy annak ellenőrzése, hogy van-e még elem a sorozatban a for-in ciklusokban.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

A break arra szolgál, hogy idő előtt kilépjünk egy ciklusból.
Amikor a `break` végrehajtódik, a ciklus azonnal kilép, és a program a ciklus utáni első utasítással folytatódik.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Címkék

Amikor a ciklusok egymásba vannak ágyazva, előfordul, hogy a `break` vagy a `continue` segítségével a külső ciklusokból szeretnénk kilépni vagy azokat újraindítani, amelyek tartalmazzák azt a ciklust, amelyben a `break` vagy a `continue` szerepel.
Az ilyen esetekben címkékkel adhatod meg, hogy melyik ciklusból lépj ki vagy melyiket indítsd újra.
Egy ciklus címkézhető úgy, hogy a ciklust indító `while`, `repeat` vagy `for` elé egy nevet és egy kettőspontot írsz.

Hogy lásd, milyen hatása van a címkék ilyen használatának, nézd meg a következő ciklust.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
