# Utasítások

Ebben a feladatban egy olyan programot fogsz megvalósítani, amely megállapítja egy [tic-tac-toe][] játék állását.
(_A játékot „noughts and crosses” vagy „Xs and Os” néven is ismerheted._)

A játékot egy 3×3-as rácsban játsszák.
A játékosok felváltva `X`-et és `O`-t tesznek a rácsra.
A játék akkor ér véget, amikor az egyik játékos nyer azzal, hogy három jelét egy sorban, oszlopban vagy a rács egyik átlója mentén helyezi el, illetve amikor az egész rács megtelik.

Ebben a feladatban feltételezzük, hogy `X` kezd.

A te feladatod eldönteni, hogy egy adott játék melyik állapotban van.

Három lehetséges játékállapot van:

- A játék **folyamatban van**.
- A játék **döntetlennel** ért véget.
- A játék **győzelemmel** ért véget.

Ha a megadott tábla érvénytelen, dobj egy megfelelő hibát.

Egy tábla érvénytelen, ha teljesíti a következő feltételeket:

- A megadott táblához nem lehet eljutni, ha a köröket a helyes sorrendben játsszák (ne feledd, hogy `X` kezd).
- A játékot azután is folytatták, hogy már véget ért.

## Példák

### Folyamatban lévő játék

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Döntetlen

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Győzelem

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Érvénytelen

#### Hibás körsorrend

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Játék folytatása győzelem után

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
