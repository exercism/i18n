# Tippek

## Általános

- A `MACRO:` a [`macros`][macros] szókészletben van. Az építőelemek a
  `kernel` (`dup`, `curry`), a `sequences` (`append`, `concat`,
  `<repetition>`, `map`) és a `quotations` (`>quotation`) szókészletben
  találhatók.
- A makró törzsének **egy quotationt** kell hagynia a vermen. Ha a
  törzs egy kódból álló tömböt állít elő, fejezd be a `>quotation` szóval.
- Hogy ellenőrizd a gondolatmenetedet, futtasd a törzs szavait egy literálon a
  listenerben, és nézd meg, milyen quotationt kapsz vissza. Annak a feladat
  „compiles to” sorában szereplő egyenes vonalú kódnak kell lennie.

## 1. Kétszer egymás után

- `[ A ]`-t kapsz, és `[ A A ]`-t szeretnél. Készíts másolatot, és fűzd össze
  őket: `dup append`.

## 2. N ismétlés

- `[ A ] n`-t kapsz, és `n` darab összefűzött másolatot szeretnél.
- A `<repetition>` elkészíti a másolatokat, de a hatása
  `( length elt -- repetition )`, vagyis a darabszámnak felül kell lennie,
  ezért először `swap`-elj.
- Utána kilapítsd és alakítsd át: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Sok quotation összefűzése

- A quotationök tömbjét már megkapod, csak egyetlen quotationné kell
  kilapítanod. A `concat >quotation` a teljes törzs.

## 4. Kibontott iteráció

Kapsz egy sorozatot és egy quotationt, például `{ 10 20 30 } [ + ]`, és a
`[ 10 + 20 + 30 + ]`-t szeretnéd. Három lépésben építsd fel.

**Egy elem.** Ha egy elemet beleégetsz a quotationbe, az pontosan az, amit a
`curry` csinál:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Minden elem.** Ezt rá szeretnéd `map`-elni a sorozatra, de a `map` a leképező
quotationnek csak egy bemenetet ad át (az elemet), miközben neked a `[ + ]`-ra
is minden alkalommal szükséged van. Ezért először égetd bele a `[ + ]`-t a
leképező quotationbe, megint a `curry` segítségével:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

A `[ curry ] curry` úgy olvasható, hogy »tedd fel a kis `[ curry ]` quotationt,
majd curryzd bele a `[ + ]`-t«, amiből `[ [ + ] curry ]` lesz. Ha ezt leképezed
egy `e` elemre, az `e [ + ] curry` fut le, ami nem más, mint `[ e + ]`.

**Fűzd össze őket.** Ugyanaz a befejezés, mint a többi feladatnál:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- A teljes törzs: `[ curry ] curry map concat >quotation`.
