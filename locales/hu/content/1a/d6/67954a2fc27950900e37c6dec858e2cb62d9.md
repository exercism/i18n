# Bemutató

Egy _osztály_ példányát úgy hozzuk létre, hogy a [`new` operátoron][new] keresztül meghívjuk a [_konstruktorát_][constructors]. A konstruktor a metódusok egy különleges fajtája, amelynek a célja, hogy inicializálja az újonnan létrehozott példányt. [A konstruktorok úgy néznek ki, mint a sima metódusok][constructor-syntax], de nincs visszatérési típusuk, és a nevük megegyezik az osztály nevével.

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

A sima metódusokhoz hasonlóan a konstruktoroknak is lehetnek paramétereik. A konstruktor paramétereit általában (privát) [mezőkként][fields] tároljuk, hogy később hozzáférjünk, vagy egyszeri számításban használjuk fel. A konstruktoroknak ugyanúgy adhatunk át argumentumokat, mint a sima metódusoknak.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

A konstruktor megadása nem kötelező. Ha nem adunk meg konstruktort, a fordító generál egy [paraméter nélküli konstruktort][parameterless-constructors]:

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

Ha a mezők kezdőértéket kapnak, a fordító olyan kódot állít elő, amelyben az értékadás valójában a konstruktoron belül történik. A következő osztálydeklarációk ezért (funkcionalitás szempontjából) egyenértékűek:

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
