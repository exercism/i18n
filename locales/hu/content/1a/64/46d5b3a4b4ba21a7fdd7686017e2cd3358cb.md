# Hibakeresés

A hibakeresés megkönnyítéséhez kihasználhatod, hogy a konzol minden kimenetét elkapja a rendszer, és meg is jeleníti a teszteredmények ablakában.
Bármilyen értéket kiírhatsz, ha átadod a `@show`-nak.

A `@show` kiír egy kifejezést és annak eredményét, miközben magát az eredményt is visszaadja.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

Használhatod a [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) függvényt vagy bármilyen más módszert is, amely a [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)) felé írja a kimenetet.
