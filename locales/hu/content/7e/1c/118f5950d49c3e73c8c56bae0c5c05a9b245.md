# Utasítások

Ebben a feladatban naplósorokat fogsz feldolgozni.

Minden naplósor egy `"[<LEVEL>]: <MESSAGE>"` formátumú string.

Három naplószint van: `INFO`, `WARNING` és `ERROR`.

Három részfeladatod van. Mindegyik egyetlen naplósort vesz le a veremről.

## 1. Üzenet kinyerése egy naplósorból

Definiáld a `message` szót úgy, hogy a naplósor üzenetét adja vissza. A vezető és a záró whitespace-t el kell távolítani.

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. Naplószint kinyerése egy naplósorból

Definiáld a `log-level` szót úgy, hogy a naplósor szintjét adja vissza, kisbetűssé alakítva.

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. Egy naplósor újraformázása

Definiáld a `reformat` szót úgy, hogy előre az üzenet kerüljön, mögé pedig zárójelben a kisbetűs naplószint.

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***Megjegyzés:*** Ebben a feladatban minden string ASCII. A későbbi feladatokban majd a Unicode-kompatibilis stringkezeléssel foglalkozunk.
