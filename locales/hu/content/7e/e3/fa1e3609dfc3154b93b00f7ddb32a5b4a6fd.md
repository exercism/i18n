# Utasítások

Elyse, a leendő bűvész folytatja a képzését. Több kártyapaklit kap majd, amelyekkel végre kell hajtania a trükkjeit.
Hogy egy kicsit könnyebb legyen a dolga, csak az 1-től 10-ig terjedő kártyákat használja.

Ebben a feladatban beépített metódusokkal elemezd egy vektor tartalmát.

## 1. Állapítsd meg, hogy szerepel-e egy kártya

Elyse szeretné megállapítani, hogy egy kártya jelen van-e a pakliban, más szóval hogy a pakli tartalmaz-e egy adott számot.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. Keresd meg egy kártya pozícióját

Elyse szeretné tudni egy kártya pozícióját (indexét) a pakliban.
Ha a kártya nincs a pakliban, add vissza a `-1`-et.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. Állapítsd meg, hogy minden kártya páros-e

Elyse szeretné tudni, hogy minden kártya páros-e, más szóval hogy a pakli minden száma páros-e.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. Ellenőrizd, hogy a pakli tartalmaz-e páratlan értékű kártyát

Elyse szeretné tudni, hogy van-e páratlan szám a pakliban.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. Szerezd meg a pakli első páratlan kártyáját

Elyse szeretné tudni az első páratlan kártya értékét.
Ha nincs páratlan kártya a pakliban, add vissza a `-1`-et.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. Állapítsd meg az első páros kártya pozícióját

Elyse szeretné tudni az első páros kártya pozícióját.
Ha nincs páros kártya a pakliban, add vissza a `-1`-et.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
