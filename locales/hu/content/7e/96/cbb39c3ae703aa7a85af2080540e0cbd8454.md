# Bevezetés

## Tömbök és vektorok

A C++ különböző tárolókat kínál, amelyekkel azonos típusú elemeket tárolhatsz rendezett módon.
Rögzített méretű tárolókhoz ott van a `std::array`, a dinamikus átméretezéshez pedig a `std::vector`.

### Létrehozás

Amikor tömböt vagy vektort deklarálsz, meg kell adnod, hogy a tároló milyen típusú elemeket fog tárolni.
A tömböknél a méretet is meg kell adni.
Nézd meg ezeket a példákat, hogy lásd a két tárolótípus inicializálását:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

A vektorok általában több helyet igényelnek, mert memóriát foglalnak a további növekedéshez.
A méretet nem kell megadnod:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> Megjegyzés: A template fogalom mögötti pontos működést még nem kell ismerned, annak a tantervfa egy későbbi ágán lesz saját fogalma.

### Elemek elérése

A vektorok és a tömbök ugyanazokkal a függvényekkel férnek hozzá az elemeikhez.
A `front` és a `back` tagfüggvénnyel lekérheted a tároló első és utolsó elemét.
Az adott elemek eléréséhez ott van még az `at` és a `[]` operátor.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> Megjegyzés: Ha a tárolód tartományán kívüli pozíciót választasz, a `[]` nem definiált viselkedéshez vezethet.
> Az `at` függvény ezzel szemben kivételt dob, ami hosszú távon megkönnyítheti az életedet.

### A vektor módosítói

Mivel a `vector` mérete nem rögzített, elemeket adhatsz hozzá és vehetsz el belőle.
Erre a célra két gyakori függvény az `emplace_back` és a `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### Kapacitás

A tárolók ürességét az `empty` tagfüggvénnyel ellenőrizheted.
Ha tudni szeretnéd az elemek számát, használhatod a `size` függvényt.
