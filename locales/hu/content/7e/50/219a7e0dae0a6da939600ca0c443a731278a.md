# Utasítások

Szenvedélyes madárfigyelő vagy, aki számontartja, hány madár járt a kertedben az elmúlt hét napban.

Hat részfeladat vár rád, és mindegyik a kertedbe látogató madarak számával foglalkozik.

## 1. Ellenőrizd, hány madár járt ma

A `today()` függvényt úgy valósítsd meg, hogy visszaadja, hány madár járt ma a kertedben. A madárszámok nap szerinti sorrendben állnak: az első elem a legrégebbi naphoz tartozó szám, az utolsó pedig a maihoz.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Növeld meg a mai nap értékét

Az `increment_todays_count()` függvényt úgy valósítsd meg, hogy megnövelje a mai nap értékét:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Ellenőrizd, volt-e olyan nap, amikor nem járt madár

A `has_day_without_birds()` függvényt úgy valósítsd meg, hogy `TRUE` értéket adjon vissza, ha volt olyan nap, amikor nulla madár járt a kertedben; egyébként pedig `FALSE` értéket:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Számold ki a látogató madarak számát az első megadott számú napra

A `count_for_first_days()` függvényt úgy valósítsd meg, hogy visszaadja, hány madár járt a kertedben a hét elejétől, de a számolást korlátozd a hét elejétől megadott számú napra.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Számold ki a forgalmas napok számát

Vannak forgalmasabb napok, mint a többi. Forgalmas nap az, amikor legalább öt madár járt a kertedben.
A `busy_days()` függvényt úgy valósítsd meg, hogy visszaadja a forgalmas napok számát:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. Számold ki a madárlátogatások futóösszegét az elmúlt héten

Kíváncsi vagy rá, hogy összesen hány madár járt itt eddig ezen a héten.
Számold ki a halmozott összeget minden napra.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. Rendezd a napok neveit aszerint, mennyire voltak forgalmasak

Gyanítod, hogy a madárlátogatásokat a közeli úti forgalom mintázata befolyásolja, ami miatt a hétvége más, mint a hétköznapok.

Rendezd a napok rövidítéseit _csökkenő_ sorrendbe aszerint, hány madár járt itt.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
