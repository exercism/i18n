# Bevezetés

A Rubyhez tartozik egy standard könyvtár (gyakran csak „stdlib”), amely osztályok gyűjteménye: velük olyan dolgokkal dolgozhatsz, mint a dátumok, a json vagy a hálózatkezelés.
Emellett néhány hasznos lehetőséget is kínál, amelyek megkönnyítik a kódoddal való munkát.

Az `OpenStruct` a standard könyvtár része, és segítségével könnyedén létrehozhatsz egy objektumot egy `Hash`-ből.
Ahelyett, hogy `Hash`-kulcsokkal kellene elérned az értékeket, az `OpenStruct` lehetővé teszi, hogy metódusokkal olvasd és állítsd be őket.

Amikor a standard könyvtár vagy bármely más könyvtár osztályait használod, a `require` metódussal kell betöltened az adott osztályt.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ennek ráadásul van egy előnye: a blokk szintaxis használatakor kihasználhatsz egy rövidítést.
Ha egy blokk csak egyetlen metódust hív meg, a blokkot lecserélheted `&:`-ra, mögé írva a metódus nevét.
Például ez a két sor ugyanazt jelenti:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
