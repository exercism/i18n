# Bevezetés a for-each ciklusokba

A [for-each ciklus](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) mechanizmust kínál arra, hogy egy kódblokkot a kollekció minden elemére végrehajts.
Egyes dokumentációk (például az Oracle dokumentációja) továbbfejlesztett for ciklusként hivatkoznak rá.

Íme az általános szintaxis:

```java
for(declaration: collection) {
    body;
}
```

A `declaration` deklarálja azt a változót, amely a kollekcióból átvett értékeket tárolja.

A `collection` egy tömb vagy kollekció, amely azokat az értékeket tartalmazza, amelyeket a ciklusváltozó megkap.

A `body` azokat az utasításokat tartalmazza, amelyek a kollekció minden egyes értékére egyszer futnak le.

Például:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

aminek a kimenete:

```text
a
e
i
o
u
```

A `for-each` ciklust általában előnyben részesítjük a `for` ciklussal szemben, a következő okok miatt:

- A `for-each` ciklus garantáltan _minden_ értéken végigmegy.
- A `for-each` ciklus _deklaratívabb_, ami azt jelenti, hogy a kód azt közli, _mit_ csinál, és nem azt, _hogyan_ csinálja.
- A `for-each` ciklus hibabiztos, míg a `for` ciklusoknál könnyen előfordulhat off-by-one hiba (gondolj a `<` és a `<=` használatára).
- A `for-each` ciklus minden kollekciótípuson működik, még azokon is, amelyek nem támogatják az elemek indexszel való elérését (például egy `Set`).
