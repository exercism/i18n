# Részletesen

Az olyan adatszerkezeteket, amelyek nulla vagy több elemet tartalmazhatnak, _kollekcióknak_ nevezzük.
A Rubiban egy **tömb** olyan kollekció, amely megőrzi a benne elhelyezett objektumok sorrendjét.
A tömbök bármilyen objektumot tárolhatnak.
Az objektumokat index segítségével adhatod hozzá egy tömbhöz, illetve kérheted le belőle.
A Rubyban a tömbök indexelése nullától indul, vagyis az első elem indexe mindig nulla:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

Rubiban többféleképpen is létrehozhatsz Array-t:

- A literál konstruktorral: `[]` _(a leggyakoribb)_
- Az `Array.new` explicit meghívásával
- A Kernel `Array()` metódusának meghívásával

Az `Array.new` metódus két opcionális argumentumot támogat: a tömb kezdeti méretét és egy alapértelmezett objektumot.

Ha megadod a méretet és az alapértelmezett objektumot, a tömb az alapértelmezett objektum `size` darab másolatával töltődik fel.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

Mivel a tömb minden eleme ugyanazt a hash-t tárolja, az egyik módosítása az összeset érinti.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

Ha különálló példányokat szeretnél, a blokkos változatot használd, amely minden egyes inicializálandó elemnél a blokk visszatérési értékét használja:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

A Ruby tömbjeinek további jellemzője, hogy belekeverik az [Enumerable][enumerable-module] modult, amely rengeteg hasznos metódust ad a tömb elemeinek bejárásához, kereséséhez, rendezéséhez, szűréséhez és így tovább.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
[for-loop]: https://launchschool.com/books/ruby/read/loops_iterators#forloops
