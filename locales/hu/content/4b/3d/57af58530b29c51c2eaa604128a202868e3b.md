# Utasítások

Üres puffereket fogsz inicializálni, majd listázod a Fibonacci-sorozat első öt számát, azaz elemét.

A Fibonacci-sorozat olyan számsorozat, amelyben minden elem az előző kettő összege. A sorozatot egytől indítjuk, így az első két elem 1 és 1.

## 1. Hozz létre egy `count` darab nullát tartalmazó puffert.

Készíts egy függvényt, amely egy `count` darab nullát tartalmazó puffert hoz létre.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Listázd fel a Fibonacci-sorozat első öt elemét

Készíts egy függvényt, amely visszaadja a Fibonacci-sorozat első öt számát.
Az első öt eleme: `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
