# Tesztek

A PureScript gyakorlatok tesztcsomagjai a gyakorlat könyvtárából futtathatók
a spago eszközzel:

    cd <exercism-workspace>/purescript/<exercise name>
    spago test

ahol a(z) `<exercism-workspace>` a CLI munkakönyvtára.

Például:

    cd ~/exercism/purescript/accumulate
    spago test
