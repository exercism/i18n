# Bevezetés

## Igaz és hamis

Az igaz és hamis logikai állapotokat a `true` és `false` jelöli a Rubyban.

```ruby
happy = true
sad = false
```

## Egyenlőség és összehasonlítás

A Rubyban a szokásos egyenlőségjelekkel hasonlíthatsz össze objektumokat egymással:
- A `==` segítségével ellenőrizheted, hogy két objektum egyenlő-e.
- A `>` segítségével ellenőrizheted, hogy a bal oldali objektum **nagyobb-e**, mint a jobb oldali.
- A `<` segítségével ellenőrizheted, hogy a bal oldali objektum **kisebb-e**, mint a jobb oldali.
- A `>=` és a `<=` segítségével rendre a „nagyobb vagy egyenlő” és a „kisebb vagy egyenlő” feltételt tesztelheted.

A szokásos operátorokkal logikai műveleteket is végezhetsz:
- A `&&` vagy `and` operátorral ellenőrizheted, hogy `x and y` igaz-e.
- A `||` vagy `or` operátorral ellenőrizheted, hogy `x or y` igaz-e.
- A `!` vagy `not` operátorral megfordíthatod az egyenlőséget, például `x != y` (az x nem egyenlő y-nal).

Néhány példa:
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
