# Bemutató

A `generator` olyan függvény vagy kifejezés, amely egy különleges típusú [iterátort][iterator] ad vissza, amelyet [generátor-iterátornak][generator-iterator] nevezünk.
A `Generator-iterators` [lusta][lazy iterator]: nem tárolja a `values` értékeit a memóriában, hanem _generálja_ őket, amikor szükség van rájuk.

A generátorfüggvény úgy néz ki, mint bármely más függvény, de egy vagy több [yield-kifejezést][yield expression] tartalmaz.
Minden `yield` felfüggeszti a kód végrehajtását, elmentve az aktuális végrehajtási állapotot (_beleértve az összes lokális változót és a try-utasításokat_).
Amikor a generátor folytatja a működést, onnan veszi fel az állapotot, ahol felfüggesztették, ellentétben a hagyományos függvényekkel, amelyek minden híváskor visszaállnak.


## Generátor létrehozása

A generátorokat nagyon hasonlóan hozzuk létre, mint más ciklikus vagy rekurzív függvényeket, de szükség van bennük egy [`yield` kifejezésre](#the-yield-expression), amelyet kicsit később részletesen is megvizsgálunk.

Példa erre egy olyan függvény, amely egy adott számlistából visszaadja a _négyzeteket_.  
A jelenlegi formájában az összes bemenetet fel kell dolgozni, mielőtt bármilyen értéket vissza lehet adni:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Ezt a függvényt így alakíthatod generátorrá:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

Ennek az az oka, hogy akkor érdemes generátort használni, amikor nincs szükséged az összes értékre _egyszerre_.

Ez memóriát és feldolgozási teljesítményt takarít meg, mivel csak az az érték kerül kiszámításra, amelyen éppen _dolgozol_.


## Generátor használata

A generátorok (_technikailag [`generator-iterator`ok][generator-iterator], lásd a lenti megjegyzést._) az `iterator` egyik fajtája, és a Pythonban bárhol használhatók, ahol `iterator`-t vagy `iterable`-t várunk.
Ide tartoznak azok a _függvények_ vagy _objektumok_ is, amelyek `iterable`-t/`iterator`-t várnak argumentumként.
Ha mélyebben bele szeretnél ásni, nézd meg a [How to Make an Iterator in Python][how-to-iterator] oldalt.


~~~~exercism/note

A generátor-iterátorok az [iterátorok][iterator] egy különleges részhalmazát alkotják.
Az `Iterators` az a mechanizmus, illetve protokoll, amely lehetővé teszi, hogy végigiteráljunk az _iterable_ objektumokon.
A generátor-iterátorok és a gyakori Python [`iterables`][iterables] által visszaadott iterátorok nagyon hasonlóan viselkednek, de néhány fontos különbségre érdemes figyelni:

- _[Lusta kiértékelésűek][lazy evaluation]_; az iteráció _egyirányú_, és nincs „visszalépés” egy korábbi értékre.
- Az iterálás _felemészti_ őket, mivel végigmegyünk a visszaadott értékeken; nincs visszaállítás és nincs mentés a memóriában.
- Nem rendezhetők és nem fordíthatók meg.
- Nem sorozattípusok, és _nincs_ `indexes`-ük. 
  Nem hivatkozhatsz egy korábbi vagy későbbi értékre összeadással vagy kivonással, és nem használhatod a szögletes zárójeles (`[]`) jelölést vagy a szeletelést.
- Nem használhatók a `len()` függvénnyel, mert nincs hosszuk.
- Lehetnek _végesek_ vagy _végtelenek_. Vigyázz, amikor egy _végtelen_ `generator-iterator` összes értékét összegyűjtöd!

[iterator]: https://docs.python.org/3.11/glossary.html#term-iterator
[iterables]: https://wiki.python.org/moin/Iterator
[lazy evaluation]: https://en.wikipedia.org/wiki/Lazy_evaluation
~~~~


A `squares_generator()` generátor használatához:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

A generátoron belüli értékeket a `next()` függvénnyel is előállíthatod, illetve elérheted.
A `next()` meghívja egy generátorobjektum `__next__()` metódusát, „előrehaladva” vagy kiértékelve a generátor kódját egészen a `yield` kifejezéséig, amely aztán „kiadja”, vagyis visszaadja az értéket.

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Amikor egy `generator` teljesen elfogyott, és nincs több visszaadható értéke, `StopIteration` hibát dob.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```

### Az iterable-ök és a generátorok különbsége

A generátorok az _iterátorok_ egy különleges részhalmazát alkotják.
Az `Iterators` az a mechanizmus, illetve protokoll, amely lehetővé teszi, hogy végigiteráljunk az _iterable_ objektumokon.
A generátorok és a gyakori Python [`iterables`][iterables] által visszaadott iterátorok nagyon hasonlóan viselkednek, de néhány fontos különbségre érdemes figyelni:

- A generátorok _egyirányúak_; nincs „visszalépés” egy korábbi értékre.

- A generátorokon való végigiterálás felemészti a visszaadott értékeket; nincs visszaállítás.

- A generátorok (_mivel lustán értékelődnek ki_) nem rendezhetők és nem fordíthatók meg.

- A generátoroknak _nincs_ `indexes`-ük, ezért nem hivatkozhatsz egy korábbi vagy későbbi értékre összeadással vagy kivonással.

- A generátorok nem használhatók a `len()` függvénnyel.

- A generátorok lehetnek _végesek_ vagy _végtelenek_, vigyázz, amikor egy _végtelen_ generátor összes értékét összegyűjtöd.

## A yield-kifejezés

A [yield-kifejezés][yield expression] nagyon hasonlít a `return` kifejezéshez.

A `return` kifejezéssel _ellentétben_ a `yield` egy _adott ponton_ adja át az értékeket a hívónak, és felfüggeszti további értékek kiértékelését, illetve visszaadását mindaddig, amíg azokat nem kérik.

Amikor a `yield` kiértékelődik, szünetelteti a befoglaló függvény végrehajtását, és visszaadja a függvény értékeit _abban az adott pillanatban_.

A függvény ezután _scope_-ban marad, és amikor a `__next__()` meghívásra kerül, a végrehajtás addig folytatódik, amíg újra nem találkozik egy `yield` kifejezéssel.

~~~~exercism/note
A `yield` kifejezések használata függvényeken kívül tilos.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```

## Miért használjunk generátorokat?

A generátorok sok helyen hasznosak.

Amikor egy nagy gyűjteménnyel dolgozol, lehet, hogy nem akarod az összes értékét a `memory`-be tenni.
Egy generátorral darabonként dolgozhatsz fel nagyobb adathalmazokat, ami memóriát takarít meg és javítja a teljesítményt.

A generátorok akkor is nagyon hasznosak, amikor egy folyamat vagy számítás _összetett_, _költséges_ vagy _végtelen_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Mostantól, valahányszor meghívod a `__next__()` metódust az `infinite_sequence` objektumon, az a _korábbi szám_ + 1 értékkel tér vissza.
