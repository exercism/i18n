# Bemutatás

A PHP számos operátort kínál a számtani műveletek elvégzéséhez. A számtani operátorainál a PHP a matematikában megszokott műveleti sorrendet követi. A PHP a következő operátorokat biztosítja:

* Identitás (+)
* Negáció (-)
* Összeadás (+)
* Kivonás (-)
* Szorzás (*)
* Osztás (/)
* Modulo (%)
* Hatványozás (**)

Nézzük meg mindegyiket, és azt is, hogyan használhatók:

## Identitás (+)

Az identitás operátor (+) egyetlen értéken működik (egyoperandusú operátor). Az eredmény a változó `float` vagy `int` értéke lesz.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## Negáció (-)

A negáció operátor egyetlen értéken működik (egyoperandusú operátor), és a számérték ellentettjét adja vissza.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## Összeadás (+) és kivonás (-)

Az összeadás operátor a két oldalán álló értéket adja össze, míg a kivonás operátor a jobb oldali értéket vonja ki a bal oldaliból.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## Osztás (/)

Az osztás operátor a bal oldali érték és a jobb oldali érték hányadosát adja. Ha a jobb oldali érték 0, `DivisionByZeroError` hibát okoz.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## Szorzás (*)

A szorzás operátor a bal és a jobb oldali érték szorzatát adja vissza.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## Modulo (%)

A modulo operátor azt a maradékot adja vissza, ami a bal oldali érték jobb oldalival való osztásakor keletkezik. Ez az operátor nagyon hasznos annak megállapítására, hogy egy szám maradék nélkül osztja-e a másikat, hogy egy érték páros vagy páratlan-e, és még sok minden másra.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## Hatványozás (**)

A hatványozás operátor a bal oldali értéket emeli a jobb oldali érték hatványára. A PHP 5.6 előtt ugyanehhez a `pow` függvényt kellett használni.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

A hatványozás operátor mindkét oldalon támogat egész és tizedes tört értékeket, így négyzetgyökök (vagy más gyökök) és bonyolultabb exponenciális értékek kiszámítására is használhatod.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## A műveletek sorrendje

A PHP a matematikában megszokott műveleti sorrendet követi. Ez azt jelenti, hogy a műveletek nem balról jobbra haladva értékelődnek ki: minden operátornak van elsőbbsége, és a műveletek az elsőbbségük szerint oldódnak meg. A műveletek sorrendje:

* zárójelek
* hatványozás
* szorzás, osztás
* összeadás, kivonás

A szorzás és az osztás ugyanazon az elsőbbségi szinten van. Hasonlóképpen az összeadás és a kivonás is ugyanazon az elsőbbségi szinten van.

Ez azt jelenti, hogy az alábbi érték 17 lesz 10 helyett, mert a szorzás elsőbbsége nagyobb, mint az összeadásé:

```php
$value = 2 + 3 * 5;
```

A PHP ezenkívül számos hasznos értékadó operátort kínál, amelyek a számtani operátorokat kombinálják az értékadással, amikor egy változón műveletet végzel, és az eredményt visszaírod ugyanabba a változóba. Ezekről az `Assignment Operators` fogalomban lesz szó.
