# Bevezetés

## Boolean-ok a Juliában

Az igaz és hamis értékeket a `Bool` típus képviseli.
Csak két értéke van: `true` és `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Boolean operátorok

Három Boolean operátor van a Juliában.

A `&&` a Boolean „és”.
`true`-ra értékelődik ki, ha a `&&` *mindkét* oldalán álló kifejezés `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

A `||` a Boolean „vagy”.
`true`-ra értékelődik ki, ha a `||` *valamelyik* oldalán álló kifejezés `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

A `!` a Boolean „nem”.
Felcseréli egymással a `true` és a `false` értékeket.

```julia-repl
julia> !true
false

julia> !false
true
```

Hosszabb és bonyolultabb kifejezéseknél a legjobb, ha zárójelekkel teszed egyértelművé a szándékodat.

```julia-repl
julia> (true || false) && (false && true)
false
```
