# A típuskonverzióról

A Go megköveteli a különböző típusok közötti explicit konverziót.
Ez például fordítási hibát okoz:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

A típusok közötti konverzió (más néven **kasztolás**) egy olyan függvénnyel történik, amely a cél típus nevét viseli.
Egy `v` értéket a `T(v)` segítségével konvertálunk `T` típusúvá.
Ha például egy `int`-et `float64` típusúvá szeretnél konvertálni, a következőt kell tenned:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

Ugyanez érvényes bármilyen saját típusra is:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## Konvertálás primitív típusok és stringek között

A primitív típusok (például az `int`) és a `string` közötti konvertáláshoz a `strconv` csomag áll rendelkezésre.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

FIGYELEM: a szokásos kasztolási módszer nem viselkedik így.
Például:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

Íme néhány további gyakori konverziós módszer:

| Módszer     | Cél                               |
| ----------- | --------------------------------- |
| ParseBool   | `string` konvertálása `bool`-ra   |
| FormatBool  | `bool` konvertálása `string`-re   |
| ParseFloat  | `string` konvertálása `float`-ra  |
| FormatFloat | `float` konvertálása `string`-re  |
| ParseInt    | `string` konvertálása `int`-re    |
| FormatInt   | `int` konvertálása `string`-re    |
