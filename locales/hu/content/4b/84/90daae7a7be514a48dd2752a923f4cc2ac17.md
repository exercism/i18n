# Utasítások

Azon dolgozol, hogy megvalósíts egy szerepjátékot. A játékos karakterét a következő reprezentálja:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

A játékban a játékosoknak el kell érniük a 10. szintet, hogy feloldhassák a manapoolt, és elkezdhessenek varázslatokat használni. Addig a Player manája `None`.

Két funkción dolgozol ebben a játékban: a feltámasztási mechanikán és a varázslási mechanikán.

A `revive` metódusnak ellenőriznie kell, hogy a Player valóban halott-e (az életereje elérte a 0-t), és ha igen, a metódusnak egy új Player példányt kell visszaadnia 100 életerővel.
Ha a Player szintje 10 vagy magasabb, akkor 100 manával kell feltámasztani.
Ha a Player szintje 10 alatt van, a manája `None` kell legyen. A `revive` metódusnak meg kell őriznie a Player szintjét.

```rust
let dead_player = Player { health: 0, mana: None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: None, level: 2 }
```

Ha a `revive` metódust egy olyan Player példányon hívják meg, amelynek az életereje 1 vagy annál több, akkor a metódusnak `None`-t kell visszaadnia.

```rust
let alive_player = Player { health: 1, mana: Some(15), level: 11 };
alive_player.revive()
// Returns None
```

A `cast_spell` metódus egy módosítható referenciát vár a Playerre, valamint egy `mana_cost` paramétert, amely megadja, mennyi manába kerül a varázslat. Visszaadja a varázslat által okozott sebzés mértékét, ami mindig a varázslat manaköltségének kétszerese, ha a varázslat sikeresen létrejön.

- Ha a játékosnak nincs hozzáférése manapoolhoz, a varázslat megkísérlésének csökkentenie kell az életerejét a varázslat manaköltségével. A visszaadott sebzésnek 0-nak kell lennie.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, None);
  ```

- Ha a játékosnak van manapoolja, de nincs elég manája, a metódus ne befolyásolja a poolt, hanem adjon vissza 0-t.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Some(3));
  ```

- Egyébként a `mana_cost`-ot le kell vonni a Player manapooljából, és a megfelelő mennyiségű sebzést kell visszaadni.

  ```rust
  let wizard = Player { health: 123, mana: Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Some(20));
  ```
