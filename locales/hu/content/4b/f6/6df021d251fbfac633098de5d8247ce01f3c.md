# Variadikus paraméterek

A Swiftben a [_variadikus paraméterek_][variadic-parameters] lehetővé teszik, hogy egy függvény egyetlen paraméterének nulla vagy több azonos típusú értéket adjunk át.
Ezt úgy jelöljük, hogy a paraméter típusmegjelölése után `...`-ot írunk.

Ezek az értékek automatikusan egy tömbbe kerülnek, amelynek elemei ugyanolyan típusúak, mint a variadikus paraméter típusa.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

A variadikus paraméterek használatakor a Swiftnek két korlátja van:

1. A Swiftben egy függvénynek csak egy variadikus paramétere lehet. Eldöntötték, hogy ezt a megkötést a Swift egy jövőbeli kiadásában eltávolítják, de egyelőre még érvényben van.
2. Ha egy függvény definíciójában a variadikus paraméter után is következnek paraméterek, akkor a variadikus paramétert követő első paraméternél _kötelező_ az argumentumcímke.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
