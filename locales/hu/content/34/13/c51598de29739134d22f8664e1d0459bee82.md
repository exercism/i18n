# Utasítások

Ebben a feladatban olyan kódot írsz, amely egy autógyár összeszerelősorának a termelését elemzi.
Az összeszerelősor sebessége `0` (kikapcsolva) és `10` (maximum) között változhat.

A legkisebb sebességén (`1`) óránként `221` autó készül.
A termelés a sebességgel lineárisan nő.
Így ha a sebességet `4`-re állítod, óránként `4 * 221 = 884` autót kell gyártania.
A nagyobb sebesség viszont megnöveli annak az esélyét, hogy hibás autók készülnek, amelyeket aztán ki kell selejtezni.

Három részfeladat vár rád.

## 1. Számítsd ki a sikerességi arányt

Készítsd el a (_statikus_) `AssemblyLine.SuccessRate()` metódust, amely egy adott sebességhez kiszámítja annak arányát, hogy egy darab hiba nélkül készül el.
A következő táblázat megmutatja, hogyan befolyásolja a sebesség a sikerességi arányt:

- `0`: 0%-os sikerességi arány.
- `1`-től `4`-ig: 100%-os sikerességi arány.
- `5`-től `8`-ig: 90%-os sikerességi arány.
- `9`: 80%-os sikerességi arány.
- `10`: 77%-os sikerességi arány.

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. Számítsd ki az óránkénti termelési rátát

Készítsd el a (_statikus_) `AssemblyLine.ProductionRatePerHour()` metódust, amely a sikerességi arányt figyelembe véve kiszámítja az összeszerelősor óránkénti termelési rátáját:

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

Figyeld meg, hogy a visszaadott érték egy `double`.

## 3. Számítsd ki a percenként gyártott működő darabok számát

Készítsd el a (_statikus_) `AssemblyLine.WorkingItemsPerMinute()` metódust, amely kiszámítja, hogy percenként hány működő autó készül:

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

Figyeld meg, hogy a visszaadott érték egy `int`.
