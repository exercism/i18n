# Kiegészítés az utasításokhoz

## Megvalósítási megjegyzések

A fa objektumnak két attribútuma van:

- `String` label
- `List<Tree>` children

A tesztprogram fákat hoz létre a `Tree.of` építőfüggvény ismételt alkalmazásával.
Például a következő utasítás

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

a következő fát állítja elő:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

Feltételezheted, hogy a tesztfákban nem lesznek ismétlődő értékek.

---

A feladat érdekes része a `FromPov` és a `PathTo` metódus.

A `FromPov` metódus egy `from` string argumentumot kap, amely az értékével kijelöl egy
csomópontot a fában. Egy olyan fát kell visszaadnia, amelynek a gyökerében a `from` érték
áll. Az eredeti fát módosíthatod, és visszaadhatod azt, vagy létrehozhatsz egy új fát, és
visszaadhatod azt. Ha új fát adsz vissza, nyugodtan felhasználhatod vagy
megsemmisítheted az eredetit. Persze az a szép, ha érintetlenül hagyod.

A `PathTo` metódus két string argumentumot kap, a `from` és a `to` értéket, amelyek az
értékük alapján két csomópontot jelölnek ki a fában. A fában az első csomóponttól a
másodikig vezető legrövidebb utat kell visszaadnia.

## Kivételüzenetek

Néha szükség van arra, hogy [kivételt dobj](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html).
Ilyenkor mindig adj meg egy **beszédes hibaüzenetet**, amely megmutatja, mi a hiba
forrása. Ettől olvashatóbb lesz a kódod, és a hibakeresésben is sokat segít.

Ennél a feladatnál a [throw kulcsszó](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)
segítségével kell „dobnod” több `UnsupportedOperationException` kivételt, ha a `Tree()` osztálynak
olyan fát adsz át, amelyet nem lehet újraorientálni, vagy ha nem található út a `start node` és
az `end node` között.
A tesztek csak akkor futnak át, ha `throw`-olod az `exception`-t, és üzenetet is fűzöl hozzá.

Ha üzenettel szeretnél `UnsupportedOperationException` kivételt dobni, írd az üzenetet az
`exception` típus argumentumaként:

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
