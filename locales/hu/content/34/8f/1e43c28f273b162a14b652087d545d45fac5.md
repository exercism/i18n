# Bevezetés

A Boolean értékeket Java-ban a `boolean` típus képviseli, amelynek értéke `true` vagy `false` lehet.

A Java három logikai operátort támogat:  

- `!` (NOT): tagadja a logikai értéket  
- `&&` (AND): két logikai értéket vesz át, és igazat ad vissza, ha mindkettő igaz  
- `||` (OR): igazat ad vissza, ha a két logikai érték közül bármelyik igaz  

## Példák

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
