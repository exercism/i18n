# Utasítások

Folytatod a korábban épített készletkezelő rendszer fejlesztését.
Mióta felfedezted az `OpenStruct`-ot és a blokk-rövidítéseket, úgy döntöttél, hogy kicsit refaktorálod a kódot.
Ahelyett, hogy hash-ekben tárolnád a tételeket, most az újonnan szerzett tudásodat fogod használni.

## 1. Tételek lekérhetővé tétele

Továbbra is le szeretnéd kérni a raktárkészletben lévő tételek listáját, de ezúttal olyan objektumok legyenek, amelyeken metódusokat lehet meghívni.

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. Az `item_names` refaktorálása

Refaktoráld az `item_names` metódust úgy, hogy a hash-ek helyett az újonnan tanult blokk-rövidítést használja.
Emlékeztetőül, a metódusnak ezt kell visszaadnia:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. A `total_stock` refaktorálása

Refaktoráld a `total_stock` metódust úgy, hogy hash-re való hivatkozás helyett az OpenStruct metódusát használja.
Emlékeztetőül, a metódusnak ezt kell visszaadnia:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

# => 36
```
