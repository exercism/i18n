# Bevezetés

## Nil

A Gleamben a `Nil` egy olyan típus, amelynek egyetlen értéke van, és ezt az értéket is `Nil`-nek hívják. Más nyelvek `void` típusához hasonló abban, hogy akkor használjuk, amikor egy függvénynek nincs más, megfelelőbb visszatérési értéke.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

A Gleam értékei nem viselkednek úgy, mint más nyelvek „nil-able” vagy „nullable” értékei. Egy érték csak akkor lehet `Nil`, ha a típusa `Nil`, és bármely más típusú érték soha nem lehet `Nil`.

## IO

A legtöbb programozási nyelvhez hasonlóan a Gleamnek is vannak „mellékhatásai”, így a függvények olvashatják és módosíthatják a világ állapotát, miközben vissza is adhatnak egy értéket.

A `gleam/io` modul a Gleam szabványos könyvtárában függvényeket biztosít stringek konzolra írásához.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Más csomagok más IO-függvényeket is biztosíthatnak, például a `simplifile`, egy csomag, amely fájlok olvasásához és írásához biztosít függvényeket.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
