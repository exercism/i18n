# Bevezetés

## Stringek

A C#-ban a `string` olyan objektum, amely változtathatatlan szöveget reprezentál Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként. Egy `string` példány definiálásához kettős idézőjelet használunk:

```csharp
string fruit = "Apple";
```

### Metódusok

A stringeket úgy módosíthatod, hogy meghívod a string [beépített metódusait][docs-string-methods].
Ha például el szeretnéd távolítani a szóközöket egy stringből, használhatod a [Trim metódust][tutorial-docs.microsoft.com-trim-white-space], így:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Miután létrehoztál egy stringet, az értéke soha nem változhat meg.
Minden metódus, amely úgy tűnik, hogy módosítja a stringet, valójában egy új stringet ad vissza.

### Konkatenáció

Több stringet össze lehet fűzni (összeadni). Ennek legegyszerűbb módja a `+` operátor használata.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Formázás

Ha a stringformázás összetettebb az egyszerű konkatenációnál, akkor érdemes a string-interpolációt választani. Az interpoláció használatához a string elé írd a dollár (`$`) jelet. Ezután kapcsos zárójelekkel (`{}`) érheted el a stringen belüli változókat.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
