# Bevezetés

A kulcslisták kulcs-érték adatszerkezetek.

```elixir
[month: "April", year: 2018]
```

A kulcslisták `{key, value}` [tuple-ök][exercism-tuples] listái, és így is leírhatók, de a rövidebb szintaxist többen használják.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

A kulcslistában a kulcsoknak [atomnak][exercism-atoms] kell lenniük, az értékek viszont bármilyenek lehetnek. Ugyanaz a kulcs többször is előfordulhat. A kulcs-érték párok a kulcslistában megőrzik a sorrendjüket.

A kulcslistákkal ugyanúgy dolgozhatsz, mint a listákkal, de használhatod a `Keyword` modult is.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
