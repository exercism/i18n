# Bevezetés

A C statikusan típusos nyelv, ami azt jelenti, hogy mindennek már fordításkor van típusa.
Amikor nevet adsz egy változónak, és meghatározod a típusát, azt a változó deklarálásának nevezzük.

Egy változót úgy deklarálsz, hogy kifejezetten megadod a típusát.
A változó neve betűvel vagy aláhúzásjellel kezdődik.
Néhány nevet nem használhatsz, mert [kulcsszavak][reserved-keywords] vagy [más azonosítók][reserved-identifiers] számára foglaltak.

A változó beállítása és frissítése értékadással történik.
Az érték beállítása definiálja a változót.
A változó definiálását inicializálásnak is nevezik.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

A változó értékét a `=` egyszerű értékadó operátorral adhatod meg és frissítheted.
Miután egy változót definiáltál, a típusa soha nem változhat meg.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

A C imperatív, procedurális nyelv.
Minden számítás egy vagy több függvényhez tartozó utasítások sorozataként valósul meg.

Minden függvénynek lehet nulla vagy több paramétere.
Amikor definiálsz egy függvényt, minden paraméter és a visszatérési érték típusát is kifejezetten meg kell adnod.
A függvények a `return` kulcsszóval adják vissza az értékeket.
A függvények alapértelmezés szerint külső tárolási osztályúak, ami azt jelenti, hogy a program teljes élettartama alatt léteznek, és a fájlon kívülről is láthatók.
Ezt megelőzendő a `static` kulcsszó hozzáadásával belső láthatóságot adhatsz meg.

```c
static int add(int x, int y) {
  return x + y;
}
```

A fenti példában az `x` és `y` változók csak a függvényen belül használhatók, azaz a scope-juk a függvényre korlátozódik.
A scope azt az elképzelést jelenti, hogy egy névhez (egy programelem nevéhez) tartozó érték csak abban a „területen” érhető el, ahol definiálták.
A fő kódterületek C-ben a következők:

- fájl
- függvény
- blokk (például ciklusokon és más szerkezeteken belül)

A függvényeket úgy hívod meg, hogy megadod a függvény nevét, és argumentumokat adsz át minden paraméterhez.

```c
int sum = add(1, 2);
```

A C kétféle megjegyzést támogat.
Az egysoros megjegyzéseket `//` előzi meg (a C99 óta), a többsoros megjegyzéseket pedig `/*` és `*/` közé írod.
