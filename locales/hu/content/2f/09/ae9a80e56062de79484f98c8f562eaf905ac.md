# Bemutatás

A C# elsődleges objektumorientált építőeleme az _osztály_, amely adatok ([_mezők_][fields]) és viselkedés ([_metódusok_][methods]) kombinációja. Az osztály mezőit és metódusait _tagoknak_ nevezzük.

A tagokhoz való hozzáférést hozzáférés-módosítókkal lehet korlátozni, a két leggyakoribb:

- [`public`][public]: a tagot bármely kód elérheti (nincs megkötés).
- [`private`][private]: a tagot csak az ugyanabban az osztályban lévő kód érheti el.

Szokás minden tagnál megadni a hozzáférés-módosítót. Ha nem adsz meg hozzáférés-módosítót, akkor alapértelmezésben `private` lesz.

A kapcsolódó adatok és viselkedés fent említett csoportosítását, valamint a tagokhoz való hozzáférés korlátozását [egységbezárásnak][encapsulation] nevezzük, ami az objektumorientált programozás egyik alapvető fogalma.

Egy objektum mezőértékeinek egy adott pillanatban fennálló összességét az objektum [állapotának][object-state] nevezzük.

Az osztályra úgy gondolhatsz, mint egy sablonra, amivel az adott osztály példányait hozod létre. Egy osztály [példányának létrehozásához][creating-objects] (más néven _objektum_) a [`new` kulcsszót][new] használjuk:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

A [mezőknek][fields] típusuk van, és egy osztályon belül bárhol definiálhatók.
A nyilvános mezőket [PascalCase][pascal-case] írásmóddal definiáljuk, a privát mezőket pedig [camelCase][camel-case] írásmóddal, és ezek neve alulvonással `_` kezdődik:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Egy mezőnek opcionálisan adhatsz kezdőértéket. Ha egy mező _nem_ kap kezdőértéket, akkor a típusa [alapértelmezett értékét][default-values] veszi fel. Egy példány mezőértékeit pont jelöléssel érheted el és frissítheted.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

A privát mezőket általában egy metódus meghívásának mellékhatásaként frissítjük. Az ilyen metódusok jellemzően nem adnak vissza értéket, ilyenkor a visszatérési típus [`void`][void] kell legyen:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field
        _carsImported = _carsImported + numberOfCars;
    }
}
```

Vedd figyelembe, hogy a C# osztályokban nem szokás nyilvános mezőket használni. Vagy privát mezőket használunk, vagy más típusú tagokat, amelyekről a későbbi feladatokban lesz szó.

Egy osztályon belül a [`this` kulcsszó][this] az aktuális osztályra utal. Ez különösen akkor hasznos, ha egy paraméter neve megegyezik egy mező nevével:

```csharp
class CarImporter
{
    private int carsImported;

    public void SetImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```

Az osztály- és metódusszerkezet természetes módot ad a program elemeinek, például a mezőknek és metódusoknak a láthatóságának korlátozására, és elkerüli a jól ismert [globális állapot problémáját][so-global-state-problem]. A nyilvános mezőket, metódusokat és egyéb tagokat az objektum nevével kell minősíteni, `object.field` vagy `object.method()`, (statikus tagok esetén az osztály nevével), hogy az osztályon kívüli kód láthassa őket. A metóduson belül deklarált változók és paraméterek csak azon a metóduson belül láthatók.

Ezzel a megközelítéssel kapcsolatban egy dologra kell vigyázni: ha egy mező neve és egy metódusban lévő változó vagy paraméter neve megegyezik, akkor a metóduson belüli kód figyelmen kívül hagyja a mező nevét, ami nem biztos, hogy az, amit szeretnél. Általánosságban, ahol lehet, kerüld ezt, bár a konstruktorokban gyakori minta. Ha indokolt, hogy a mező és a változó neve megegyezzen, akkor a metóduson belül minősítsd a mező nevét a `this` kulcsszóval.

Ezekkel a [hozzáférés-módosítókkal][access-modifiers] tovább korlátozhatod a láthatóságot.
