# Bevezetés

Emlékezz vissza az Alapok fogalomra: egy AWK program **minta-művelet párokból** áll.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## Mit értünk „minta” alatt?

A „minta” bármilyen AWK-kifejezés.
A kifejezés eredményének igaz/hamis volta dönti el, hogy a művelet végrehajtódik-e.

## Az üres minta

A minta elhagyható.
Ebben az esetben a művelet minden rekordra végrehajtódik.

Kiírhatjuk a passwd fájl összes felhasználónevét.

```sh
awk -F: '{print $1}' /etc/passwd
```

## Reguláris kifejezések

Az AWK össze tud hasonlítani stringeket reguláris kifejezésekkel, hogy logikai értéket kapjunk.

A `~` reguláris kifejezést illesztő operátorral illeszthetsz egy adott mezőt.
Ez az operátor bal oldali operandusként egy stringet, jobb oldali operandusként pedig egy reguláris kifejezést vár.
A reguláris kifejezés literál `/` jelek közé van zárva.

Hogy megtaláld a passwd fájlban azokat a felhasználókat, akik bash-sal jelentkeznek be:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

A `!~` a „reguláris kifejezés **nem** illeszkedik” operátor.

Ha egy reguláris kifejezést az aktuális rekorddal szeretnél illeszteni, ezt teheted: `$0 ~ /regex/`.
Ez annyira gyakori, hogy van rá rövidítés: elhagyhatod a `$0`-t és a `~`-t, és egyszerűen csak `/regex/`-et írhatsz.

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
Hasonlítsd össze ezt az AWK egysorost a megfelelő grep paranccsal

```sh
grep 'regex' data.txt
```

Az AWK egy teljes programozási nyelvet ad, anélkül hogy feláldozná a tömörséget.
~~~~

A GNU AWK reguláris kifejezéseinek sajátosságaiba egy későbbi fogalomban mélyedünk majd el jobban.

## Kifejezések

Az AWK kifejezései (aritmetikai, logikai vagy egyéb) használhatók mintaként.

Az összes 1000-es vagy annál nagyobb UID-vel rendelkező felhasználó kinyeréséhez:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Emlékezz rá, hogy az AWK hamis értékei a nulla szám és az üres string, minden más szám vagy string pedig igaz.
Bármely kifejezés, amely számot vagy stringet eredményez, használható mintaként.

## Függvények

Bármely [beépített][builtins] vagy [felhasználó által definiált][user-defined] függvény használható kifejezésben, és így mintában is.
Néhány példa:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## Konstans minták

Egy gyakori AWK-idióma:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

Az `1` egy igaz értékű minta, amelyhez nem tartozik művelet.
Ez azt jelenti, hogy „írjuk ki az aktuális rekordot”.
