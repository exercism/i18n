## Opcionális paraméterek

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

ezzel egyenértékű:

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

A REPL válaszában láthatod, hogy az első definíció egyszerre két metódust hoz létre.
