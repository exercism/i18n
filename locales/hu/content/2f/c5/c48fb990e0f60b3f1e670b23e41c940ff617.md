# Bevezetés

A Cairoban a kiírással üzeneteket, hibakeresési információkat vagy formázott értékeket jeleníthetsz meg a program futása közben.
Az olyan sokoldalú makrókkal, mint a println!
és a format!, alapvető adattípusokat, egyéni formátumokat vagy akár összetett szerkezeteket is kiírhatsz.
Így könnyedén megvizsgálhatod és hatékonyan közvetítheted a program viselkedését.
