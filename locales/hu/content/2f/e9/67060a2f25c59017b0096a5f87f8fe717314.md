# Telepítés

## A tclsh telepítése

Az egyetlen eszköz, amire szükséged van, a TCL-értelmező, a `tclsh`.

Windowson a Tcl beszerzésének legjobb módja [a Magicsplat Tcl-telepítője][magicsplat].

MacOS-en és a Unix-szerű operációs rendszereken a `tclsh` már telepítve van.
A telepített verzió jellemzően 8.6.*valami* szokott lenni.
A jelenlegi stabil, 9.0-s verzió telepítéséhez:
 - MacOS-en használd a [Homebrew][brew]-t.
 - Linuxon nézd meg a csomagkezelődet.
 - vagy [töltsd le a forráskódot][download], és [fordítsd le][build].

Ha a feladatokat az Exercism webes felületén oldod meg, a tesztfuttató (2023 februárjában) a Tcl 8.7a4-es verzióját használja.

## Az interaktív tclsh shell használata

Gyakori, hogy programozás közben elindítasz egy interaktív [`tclsh`][tclsh] munkamenetet, hogy kipróbáld a parancsokat.
A `tclsh` azonban csak egy nagyon egyszerű REPL-értelmezőt nyújt, parancssori szerkesztés és parancselőzmény nélkül.
A jobb élmény érdekében létezik egy `rlwrap` nevű program, amely readline-funkcionalitást ad hozzá:

```bash
rlwrap tclsh
```

Az rlwrap telepítéséhez:
 - MacOS-en használd a [Homebrew][brew]-t.
 - Linuxon nézd meg a csomagkezelődet.
 - vagy [töltsd le a forráskódot][rlwrap-download], és [fordítsd le][rlwrap-build].

Annyira hasznos, hogy mindig ezt akarod majd használni: írd ezt a ~/.bashrc fájlodba

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## Melyik verziót használd?

A jelenlegi stabil verzió a 9.0.
Ahogy fentebb is látszik, a 8.6-os verzió még mindig széles körben használatban van.

A következő paranccsal ellenőrizheted, hogy a `tclsh` melyik verziója van telepítve:

```bash
echo 'puts [info patchlevel]' | tclsh
```
