# Utasítások kiegészítése

## A tábla formátuma

A táblát egy nullával lezárt string képviseli, és minden sor végén egy újsor karakter áll.

Erre egy példa: `"X  \n XO\nOX \n"`

## Regiszterek

| Regiszter | Használat    | Típus   | Leírás                                                                  |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | bemenet      | cím     | nullával lezárt bemeneti string                                         |
| `$v0`    | kimenet      | egész szám | a játék állapota (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | ideiglenes   | bármilyen | ideiglenes tárolásra                                                   |
