# Bevezetés

## Struktúrák

A C# `struct`-ok szorosan kapcsolódnak a `class`-ekhez. Van állapotuk és viselkedésük. Rendelkeznek konstruktorokkal, amelyek argumentumokat várnak; a példányok hozzárendelhetők, egyenlőségre tesztelhetők és gyűjteményekben tárolhatók.

```csharp
enum Unit
{
    Kg,
    Lb
}
struct Weight
{
    private double count;
    private Unit unit;

    public Weight(double count, Unit unit)
    {
        this.count = count;
        this.unit = unit;
    }

    public override string ToString()
    {
        return count.ToString() + unit.ToString();
    }
}

new Weight(77.5, Unit.Kg).ToString();
// => "77.6Kg"
```
