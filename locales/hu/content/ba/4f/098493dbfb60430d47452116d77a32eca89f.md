# Bevezetés

A Pythonban az [`if`][if statement], az `elif` (_az 'else and if' rövidítése_) és az `else` utasítások szolgálnak a végrehajtás [vezérlésére][control flow tools], és velük hoz döntéseket a program.
A legtöbb más programozási nyelvvel ellentétben a Python 3.9-es és annál korábbi verziói nem kínálnak hivatalos case-switch utasítást; helyette inkább több `elif` utasítással oldják meg ugyanezt.

A Python 3.10-ben megjelenik egy `pattern matching` nevű, másfajta case-switch utasítás, amiről egy másik fogalomnál külön lesz szó.

Az elágazások olyan kifejezéseket használnak, amelyeknek `True` vagy `False` értékre kell kiértékelődniük. Ez történhet úgy, hogy közvetlenül egy `bool` értéket adnak vissza, vagy úgy, hogy [„truthy” vagy „falsy”][truth value testing] értékelődnek ki.


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

Ha az `if`-fel párosítva megadunk egy opcionális `else` kódblokkot is, az akkor fut le, amikor az eredeti `if` feltétel `False`-ra értékelődik ki:

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

Az `elif` lehetővé teszi, hogy több feltételt is kiértékeljünk, és ezzel több ágra váljunk szét.

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

A [Boolean-műveletek][boolean operations] és az [összehasonlítások][comparisons] összekapcsolhatók az elágazásokkal, így bonyolultabb vizsgálatokat is írhatunk:

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
