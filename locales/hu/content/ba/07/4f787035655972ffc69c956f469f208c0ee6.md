# Bevezetés

Emlékezz rá, hogy a `jq` program egy _kifejezésekből álló pipeline_.
**A változó-hozzárendelés** a következő szabályt követi: a _változó-hozzárendelés_ egy olyan kifejezés, amely így néz ki:

```jq
... | expr as $varname | ...
```

## A szűrő a bemenetet adja vissza

Ahogy az _identitáskifejezés_ `.` esetében, a _változó-hozzárendelés_ kimenete is ugyanaz, mint a bemenete.
A változó értékének beállítása mellékhatás.

Az alábbi példa azt mutatja, hogy a hozzárendelés utáni `.` ugyanaz, mint a kezdeti bemenet:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## A változó scope-ja

A változó scope-ja „lexikális”: a változó a pipeline hátralévő részében is scope-ban marad.
A függvényeken belül definiált változók (a függvényekre később térünk rá) „lokálisak” az adott függvényben.

## A változók nevei

A változó nevének `$` jellel kell kezdődnie.
A változónév többi része egy **azonosító**: betűvel vagy alulvonással kezdődik, amelyet betűk, számok vagy alulvonások követnek.

## Destrukturáló hozzárendelés

A kézikönyvből:

> Egyetlen `as` kifejezéssel több változót is deklarálhatsz, ha olyan mintát adsz meg, amely _illeszkedik a bemenet szerkezetéhez_ (ezt nevezik „destrukturálásnak”).

Példák:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Ha a változó nevét az _objektumkulcshoz_ igazítod, egy rövidítést kapsz:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Konstansok

Ahogy a fenti példa is mutatja, a változók hasznosak konstansok tárolására.
Jobb nevet adni a konstansoknak, mint hogy „mágikus számok” jelenjenek meg a kódban.

## A változókra gyakran nincs is szükség

Gyakran olvashatóbb, ha elhagyod a változókat.

Vegyük egy számlista átlagának kiszámítását:

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

és hasonlítsuk össze ezzel:

```jq
[2, 4, 8, 7] | add / length
```

Ez jól mutatja a `jq` egyik legerősebb tulajdonságát: a szűrő bemenetét _minden_ részkifejezés megkapja:

- a `[2,4,8,7]` bemeneti tömb az `add` bemenetére kerül (amely összeadja a számokat úgy, hogy a `+` operátort minden elemre alkalmazza)
- _ezzel párhuzamosan_ a `[2,4,8,7]` a `length` bemenetére is bekerül
- amikor ezek a részkifejezések befejeződnek, az eredményeiket elosztja egymással, és visszaadja a bemeneti tömb számainak átlagát.

## `jq` operátorok, amelyekre a tanulófeladatban szükséged lesz

### Alternatív operátor: `//`

Az `a // b` kifejezés `b`-t ad vissza, ha `a` hamis vagy null, egyébként `a`-t adja vissza.
Amikor változót állítasz be, ez nagyon hasznos az alapértelmezett érték megadásához:

```jq
(.input.theAnswer // 42) as $answer | ...
```

### Aritmetikai operátorok

- A `+`, `-`, `*` a szokásos numerikus összeadás, kivonás és szorzás operátorai.
