# Bevezetés

Sok nyelvben van valami, például `null` vagy `none`, amivel jelezni lehet, hogy egy érték nem létezik. Mivel az R nagy mennyiségű (gyakran rendetlen) adat kezelésére készült, több formája is van a semminek.

A cél összességében az, hogy a hiányzó vagy gyanús értékeket előfordulásukkor megjelöljük, majd kivétel dobása nélkül folytassuk.

## NULL

Ha egy érték valóban nem létezik, azt `NULL` jelöli. Ez valószínűleg a legközelebb áll ahhoz, amit a C vagy a Python tenne.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

Sok esetben a `NULL` értékeket egyszerűen figyelmen kívül hagyjuk:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Azokban az esetekben, amikor egy érték létezik, de nem tudjuk, mi az, `NA`-t használunk. Például amikor egy úton haladó járműveket számolunk, előfordulhat, hogy az emberi megfigyelők megbetegedhetnek, vagy az automatikus érzékelők elromolhatnak, a forgalom viszont tovább folyik.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Így az `NA` egy helyőrző, amely figyelmezteti az embereket, hogy dönteniük kell, hogyan kezeljék ezt.

## Üres vektorok

Talán meglepő, hogy az R-nek nincs szabványos módja az üresség ellenőrzésére, bár néhány harmadik féltől származó csomag saját függvényeket valósít meg, például az `is.empty()`-t.

Még egy üres vektor létrehozása sem teljesen nyilvánvaló. Egy korábbi részben láttuk, hogy a `c()` argumentumok nélkül `NULL`-t ad vissza, nem vektort.

```R
is.vector(c())
#> [1] FALSE
```

Az olyan függvények, mint a `logical()` vagy az `integer()`, egy argumentumot várnak, amely megadja a kívánt hosszt; ez lehet nulla is.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Létrehozhatunk egy vektort, majd eltávolíthatunk belőle minden elemet, ahogy a [Vektorok fogalma][concept-vectors] részben le van írva. Így egy megfelelő típusú, nulla hosszúságú vektort kapunk.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
