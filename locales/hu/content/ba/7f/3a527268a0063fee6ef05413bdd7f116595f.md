# Bevezetés

## Osztályok

A C# elsődleges objektumorientált építőeleme az _osztály_, amely adatok (_mezők_) és viselkedés (_metódusok_) kombinációja. Az osztály mezőit és metódusait _tagoknak_ nevezzük.

A tagokhoz való hozzáférést hozzáférés-módosítókkal lehet korlátozni, amelyek közül a két leggyakoribb:

- `public`: a tagot bármely kód elérheti (nincs megkötés).
- `private`: a tagot csak az ugyanabban az osztályban lévő kód érheti el.

Egy osztályra gondolhatsz úgy, mint egy sablonra, amellyel az osztály példányait hozhatod létre. Egy osztály példányának (más néven _objektumnak_) a létrehozásához a `new` kulcsszót használjuk:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

A mezőknek típusuk van, és az osztály bármely pontján definiálhatók.
A nyilvános mezőket PascalCase-ben, a privát mezőket camelCase-ben definiáljuk, és egy alulvonás (`_`) előzi meg őket:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Egy mezőnek opcionálisan adhatsz kezdőértéket. Ha egy mező _nem_ ad meg kezdőértéket, akkor a típusának alapértelmezett értékét kapja. Egy példány mezőértékei pontjelöléssel érhetők el és frissíthetők.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

A privát mezőket általában egy metódus meghívásának mellékhatásaként frissítjük. Az ilyen metódusok általában nem adnak vissza értéket, ilyenkor a visszatérési típus `void` legyen:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
