# Bevezetés

## Pipe operátor

A `|>` operátor neve pipe operátor. Arra használható, hogy egymás után fűzd vele a függvényhívásokat úgy, hogy az előző függvényhívás által visszaadott érték a következő függvényhívásnak adódjon át.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

A fenti kód ugyanazt jelenti, mint a következő:

```gleam
string.append(string.uppercase("hello"), "?!")
```

A pipe operátor az értéket vagy első argumentumként adja át a függvényhívásnak, vagy egyetlen argumentumként egy új hívásnak, attól függően, hogy melyiknél lesz a típus helyes.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Néha az értéket egy másik pozícióba szeretnénk átadni, ilyenkor a `_` helyőrzővel jelölhetjük meg, hova kerüljön az érték.

```gleam
100
|> some_function(1, _, 2)
```
