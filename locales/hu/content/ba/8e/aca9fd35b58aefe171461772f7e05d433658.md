# Tesztek futtatása

Egy adott feladat tesztjének futtatásához lépj be a mappába a `cd` paranccsal, majd futtasd a következőt:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

A tesztek egy TestBox nevű könyvtárat használnak, amely támogatja az xUnit és a BDD stílusú tesztelést. Minden tesztcsomag [BDD stílusban](https://testbox.ortusbooks.com/content/primers/bdd/specs.html) íródik, amely closure segítségével írja le a tesztspecifikációkat. Nem kell amiatt aggódnod, hogy telepítened kell a TestBox-ot, mert a CLI tesztfuttató ezt elintézi helyetted. Csupán arra van szükség, hogy az első futtatáskor kapcsolódj az internethez. Többet itt olvashatsz róla:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
