# Bevezetés

## Listák

A Gleamben egy lista egy megváltoztathatatlan gyűjtemény, amely nulla vagy több értéket tartalmaz. Egy listában minden értéknek ugyanolyan típusúnak kell lennie. Mivel a listák megváltoztathatatlanok, miután létrehoztál egy listát, az értéke soha nem változhat meg. Minden függvény vagy operátor, amely úgy tűnik, hogy módosítja a listát (például hozzáad egy elemet), valójában egy új listát ad vissza.

A listákat így definiálhatod:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

A leggyakoribb módja annak, hogy elemet adj a listához, a spread szintaxis használata:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

A Gleam standard könyvtárában található [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) modul számos hasznos függvényt tartalmaz a listákkal való munkához. Ezt a modult nagyon gyakran használják a Gleam-kódban, ezért érdemes megismerkedned vele.

A listaminták arra is használhatók a case kifejezésekben, hogy listákra illeszkedj, és a bennük lévő értékeket változókhoz rendeld:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Amellett, hogy pontos hosszúságú listákra illeszkedhetsz, a spread szintaxissal legalább egy bizonyos hosszúságú listákra is illeszkedhetsz:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

A spread szintaxis arra is használható, hogy a lista maradékát egy változóhoz rendeld:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

A case kifejezéseknek minden lehetséges értékre mintát kell tartalmazniuk abból a típusból, amelyre illeszkednek, ezért gyakran használnak egy záró, eldobó mintát (`_`), hogy kezeljék a maradék értékeket.
