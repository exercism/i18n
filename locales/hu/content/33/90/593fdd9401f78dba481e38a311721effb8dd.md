# Kiegészítés az utasításokhoz

## Megvalósítás

Ebben a feladatban egy eljárást fogsz megvalósítani, amelynek az a feladata, hogy lefoglalja a visszaadott stringet. A string felszabadítása az eljárás hívójának a felelőssége.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
