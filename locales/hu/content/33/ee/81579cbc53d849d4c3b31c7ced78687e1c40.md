# Utasítások

Ebben a feladatban olyan kódot írsz, amely számon tartja, milyen programozási nyelveket szeretnél megtanulni az Exercism-ön.

Kilenc részfeladat vár rád, és mindegyik a listákkal való munkáról szól.

## 1. Hozz létre egy új listát

Ahhoz, hogy számon tudd tartani a megtanulni kívánt nyelveket, létre kell hoznod egy új listát.

Valósítsd meg a statikus `Languages.NewList()` metódust, amely egy új, üres listát ad vissza.

```csharp
Languages.NewList()
// => empty list
```

## 2. Definiálj egy meglévő listát

Jelenleg van egy papírlapod, amelyen azok a nyelvek szerepelnek, amelyeket meg szeretnél tanulni: C#, Clojure és Elm.

Valósítsd meg a statikus `Languages.GetExistingLanguages()` metódust, amely visszaadja ezt a listát.

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. Adj hozzá egy új nyelvet egy listához

Ahogy egyre többet fedezel fel az Exercism-ön, és egyre érdekesebb nyelvekre bukkansz, szeretnéd felvenni őket a listádra.

Valósítsd meg a statikus `Languages.AddLanguage()` függvényt, amely egy új nyelvet fűz a listád végére.

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. Számold meg a listán lévő nyelveket

Kényelmetlen egyenként megszámolni a nyelveket.

Valósítsd meg a statikus `Languages.CountLanguages()` metódust, amely megszámolja, hány nyelv van a listádon.

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. Ellenőrizd, hogy szerepel-e egy nyelv a listán

Valósítsd meg a statikus `Languages.HasLanguage()` metódust, amellyel ellenőrizheted, hogy egy nyelv szerepel-e a listán.

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. Fordítsd meg a listát

Egy ponton rájössz, hogy a listád valójában fordított sorrendben van!

Valósítsd meg a statikus `Languages.ReverseList()` metódust, amely megfordítja a listádat.

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. Ellenőrizd, hogy izgalmas-e a lista

Bár minden nyelvet szeretsz, a C# különleges helyet foglal el a szívedben. Ezért igazán izgatott leszel egy nyelvlistától, ha az alábbi feltételek valamelyike igaz:

- A lista első eleme a C#.
- A lista második eleme a C#, és a listán vagy két vagy három nyelv szerepel.

Valósítsd meg a statikus `Languages.IsExciting()` metódust, amellyel ellenőrizheted, hogy izgalmas-e egy nyelvlista:

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.Nyelv eltávolítása

Valósítsd meg a statikus `Languages.RemoveLanguage()` metódust, amely eltávolít egy megadott nyelvet a listáról.

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. Ellenőrizd, hogy a listán szereplő összes nyelv egyedi-e

Valósítsd meg a statikus `Languages.IsUnique()` metódust, amellyel ellenőrizheted, hogy ismétlődik-e valamelyik nyelv a listán.

Garantált, hogy a nyelvek listája (azaz a paraméter) nem üres, amikor ezt a metódust meghívják, és az sem számít, ha a lista módosul.

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
