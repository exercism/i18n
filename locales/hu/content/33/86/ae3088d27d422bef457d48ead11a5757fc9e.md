# Bevezetés

Előfordul, hogy egy magasabb rendű függvény paraméterként kap egy másik függvényt, és úgy használja, hogy az átadott függvény a magasabb rendű függvény lefutása _után_ hívódik meg. Ezt nevezik a magasabb rendű függvényből való escapingnek, az átadott függvényt pedig _escaping függvénynek_ hívjuk.

Ez leggyakrabban aszinkron kódban fordul elő, de olyan magasabb rendű függvényeknél is megtörténhet, amelyek visszaadják az átadott függvényt (vagy egy olyan függvényt, amely meghívja azt). Például:

```swift
func emptyKitchen(_ order: String) -> String {
  "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}
```

Itt a `prepare` függvény a `kitchen` paraméteréhez egy függvényt fogad el, majd létrehoz egy új, `newKitchen` nevű függvényt, amely meghívhatja a `kitchen` függvényt. Ezt a `newKitchen` függvényt aztán visszaadja a hívónak. Ha Swiftben megpróbáljuk megírni ezt a függvényt, a következő hibát kapjuk: _Escaping local function captures non-escaping parameter 'kitchen'_

A Swift azért jelez hibát ebben az esetben, mert vannak olyan helyzetek, amikor a beágyazott vagy átadott függvény olyan értéket rögzít, ami memóriaszivárgáshoz vezethet. Hogy ez hogyan történik, és hogyan lehet megelőzni ezeket a szivárgásokat, az túlmutat e feladat keretein. Ezt a hibát viszont meg lehet szüntetni azzal, hogy az `@escaping` attribútumot az átadott függvény típusszignatúrája elé tesszük.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}

let restaurant =
  prepare(order: "sandwich",
          kitchen: prepare(order: "chicken",
                           kitchen: prepare(order: "steak",
                                            kitchen: emptyKitchen)))

restaurant("pork chop")
// => "Sorry, we're all out of pork chop."
restaurant("chicken")
// => "One chicken coming up!"
```

Ez az attribútum azt jelzi a Swift-fordítónak, hogy a szerző tudatában van annak, hogy e függvény escapingjének engedélyezésével memóriaszivárgás léphet fel.
