# Tesztek

Egy feladat letöltéséhez, például a `hello-world`-hoz, nyiss meg egy terminált, és futtasd a következőt:

```bash
exercism download --track roc --exercise hello-world
```

Ezután lépj be a feladat könyvtárába, és szerkeszd a kódot a feladat megoldásához. Például:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

Minden feladathoz tartozik egy tesztkészlet. A teszteket a `roc test` parancs segítségével futtathatod, például:

```
roc test hello-world-test.roc
```

Ha megoldottad a feladatot, 0 sikertelen tesztet kell látnod, például:

```
All (5) tests passed in 123.4 ms.
```

Ha viszont hibák vannak a kódodban, azok így fognak kinézni:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

Ez segíteni fog a kódod kijavításában. Ha a kódod működik, beküldheted az `exercism submit` paranccsal (további részletekért lásd a feladat könyvtárában lévő `HELP.md` fájlt).
