# Útmutató

Eljött a szezonzáró a helyi klubban. Te vezeted a ranglistát a célegyenesben: a versenyzők sorrendben érnek célba, a pályák címkéket kapnak, és a hivatalos nyilvántartást is fel kell jegyezni a következő futam előtt.

A versenyzők nevei egy tömb formájában, a célba érés sorrendjében érkeznek: a 0. név a győztes, az 1. a második helyezett, és így tovább.

## 1. Rajtszámok kiosztása

Definiáld az `assign-bibs` szót úgy, hogy egy versenyzőnevekből álló tömböt kapjon, és egy `{ position name }` párokból álló tömböt adjon vissza, a pozícióval az élen.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Pályacímkék

Definiáld a `lane-labels` szót úgy, hogy egy versenyzőnevekből álló tömböt kapjon, és olyan stringeket adjon vissza, mint a `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. A versenyzők megjelölése

Definiáld a `tag-racers` szót úgy, hogy egy versenyzőnevekből álló tömböt *és* egy tag stringet kapjon, és `"<tag>/<index>: <name>"` formájú címkéket adjon vissza. Ugyanaz a tag épül be minden címkébe.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. A célba érések rögzítése

Definiáld a `record-finishes` szót úgy, hogy egy versenyzőnevekből álló tömböt és egy nyilvántartást (vektort) kapjon. Minden versenyzőnél fűzz a nyilvántartás végére egy `"<index>: <name>"` formájú stringet, helyben. Semmit nem ad vissza.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Körcsengők

Definiáld a `lap-bells` szót úgy, hogy egy `laps` számot kapjon, és egy olyan stringet adjon vissza, amely a `"ding "` `laps` alkalommal történő ismétléséből áll.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
