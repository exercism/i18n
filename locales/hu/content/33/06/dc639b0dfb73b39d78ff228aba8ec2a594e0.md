# Névjegy

Az F#-ban a [`list`][lists] nulla vagy több értékből álló, megváltoztathatatlan gyűjtemény. A listában lévő összes értéknek ugyanolyan típusúnak kell lennie. Mivel a listák megváltoztathatatlanok, miután létrehoztál egy listát, annak értéke soha nem változhat meg. Az F# listáknak van _head_ (az első elem) és _tail_ (minden, ami az első elem után következik) része. Egy lista _tail_ része maga is egy lista.

A listákat a következőképpen definiálhatod:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

A leggyakoribb módja annak, hogy elemet adj egy listához, a `::` (cons) operátor:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

A listákat a `@` operátorral vagy a `List.append` függvénnyel fűzheted össze:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

A listákat a [`List` modulban][list-module] definiált függvények és operátorok kezelik. Ezen függvények némelyike egy `list` példány [tulajdonságaként][list-properties] is elérhető:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

Itt nincs helyes vagy helytelen választás. Általában a `List` modul függvényei jobban működnek együtt a típuskövetkeztetéssel, míg a tulajdonságok tömörebb kódot tesznek lehetővé.

Minden függvény vagy operátor, amely úgy tűnik, hogy módosítja a listát (például egy elem hozzáadásával), valójában egy új listát ad vissza. A teljesítmény azonban általában nem jelent problémát, mivel a listák implementációja megakadályozza a felesleges allokációkat és másolásokat.

Mivel a listák egyszeresen láncolt listaként vannak implementálva, egy elem elé fűzése (a `::` operátorral) nagyon gyors, míg egy elem index alapján történő elérése viszonylag lassú lehet.

A listákat mintaillesztéssel is feldolgozhatod a [_list_][list-pattern] és [_cons_][cons-pattern] mintákon keresztül:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Mintaillesztéskor egy értéket _el is dobhatsz_; ha egy adott esetben _nem_ érdekel egy érték (azaz nem fogod _használni_), egy alulvonással (`'_'`) jelezheted ezt:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Az egyszeres `'_'` mintaillesztéskor mindig _utolsó_ legyen: minden érték, amely _nem_ illeszkedik a többi eset egyikére sem, ezzel az esettel lesz kezelve.
