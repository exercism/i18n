# Bevezetés

## Az interfész mint metódushalmaz

A legegyszerűbb formájában az **interfésztípus** metódusaláírások halmaza.
Íme egy példa egy interfészdefinícióra, amely két metódust tartalmaz, `Add`-ot és `Value`-t:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Az `increment`-hez hasonló paraméternevek elhagyhatók az interfészdefinícióból, de gyakran növelik az olvashatóságot.

A Go-beli interfésznevek nem tartalmazzák az `Interface` vagy az `I` szót.
Ehelyett gyakran `er`-re végződnek, például `Reader`, `Stringer`.

## Interfész megvalósítása

Bármely típus, amely definiálja az interfész metódusait, automatikusan, implicit módon „megvalósítja” az interfészt.
A Go-ban nincs `implements` kulcsszó.

A következő típus a fentebb látott `Counter` interfészt valósítja meg.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Az interfész megvalósításához nem számít, hogy a metódusnak érték- vagy pointer receiver-e van.
(Nézd át újra a [metódusokról szóló fogalmat][concept-methods], ha bizonytalan vagy bennük.)

> Egy interfésztípusú érték bármilyen olyan értéket tárolhat, amely megvalósítja ezeket a metódusokat. ((Go Tour: Interfaces)[go-tour-interfaces])

Ez azt jelenti, hogy a `Stats` mostantól mindenhol használható, ahol a `Counter` interfészt várják.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Mivel az interfészek implicit módon valósulnak meg, egy típus könnyedén megvalósíthat több interfészt is.
Ehhez csak a szükséges metódusokat kell definiálnia.

## Az üres interfész

A Go-ban van egy nagyon különleges interfésztípus, az **üres interfész**, amely nulla metódust tartalmaz.
Az üres interfészt így írjuk: `interface{}`.
A Go 1.18-as vagy annál újabb verziójában `any` is használható.
Aliaszként definiálták.

Mivel az üres interfésznek nincsenek metódusai, minden típus implicit módon megvalósítja.
Ez akkor hasznos, ha olyan függvényt definiálunk, amely általánosan bármilyen értéket elfogad.
Ebben az esetben a függvény paramétere az üres interfésztípust használja.
