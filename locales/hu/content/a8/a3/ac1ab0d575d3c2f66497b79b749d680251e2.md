# Bevezetés

A for ciklus az egyik leggyakrabban használt utasítás arra, hogy valamilyen logikát ismételten végrehajtsunk.
JavaScriptben ez a `for` kulcsszóból, a kerek zárójelbe zárt _fejlécből_ és egy kapcsos zárójelbe zárt kódblokkból áll, amely a ciklus _törzsét_ tartalmazza.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

A kezdőérték általában beállít egy számlálóváltozót, a feltétel ellenőrzi, hogy folytatódjon-e a ciklus vagy leálljon, a léptetés pedig minden ismétlés végén növeli a számlálót.
A fejléc egyes részeit pontosvesszők választják el.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

A léptetést gyakran a JavaScript növelő vagy csökkentő operátorával adjuk meg, ahogy a fenti példában is látható.
Ezek az operátorok helyben módosítanak egy változót.
A `++` eggyel növel egy számot, a `--` eggyel csökkent egy számot.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
