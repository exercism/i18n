# Utasítások

Ebben a feladatban olyan kódot írsz majd, amely segít egy szabadúszónak kommunikálni egy projektmenedzserrel.
A feladatod, hogy néhány segédeszközt biztosíts a napi és havi díjak gyors kiszámításához, opcionálisan egy megadott kedvezménnyel.

Először néhány szabályt rögzítünk a szabadúszó és a projektmenedzser között:

- A napi díj az óradíj nyolcszorosa.
- Egy hónapban 22 számlázható nap van.

Néha a szabadúszó kedvezményt ajánl a napi díjára (például a leghűségesebb ügyfeleinek vagy nonprofit ügyfeleknek).

A kedvezményeket százalékokat reprezentáló törtszámokként modellezzük, például `25.0` (25%).

~~~~exercism/note
Ezek a lebegőpontos utasítások utótagjai:

| Utótag | Operandusméret |
|--------|--------------|
| `ss`   | 32 bites       |
| `sd`   | 64 bites       |

Ezek néhány az ebben a fogalomban említett utasítás közül:

| Utasítás       | Leírás                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | b-t az a-ba másolja                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | az egész b-t lebegőpontos a-vá alakítja                 |
| roundss/roundsd a, b, c | a lebegőpontos b-t c szerint kerekíti, és az a-ban tárolja |
| cvtss2si/cvtsd2si a, b  | a lebegőpontos b-t egész a-vá alakítja                 |
| comiss/comisd a, b      | összehasonlítást végez a és b között, kivétel, ha `NaN` |
| ucomiss/ucomisd a, b    | összehasonlítást végez a és b között, beállítja a `PF` jelzőt, ha `NaN` |

Ezek a kerekítést vezérlő számok a `roundss` és `roundsd` utasításban:

| Szám | Mód         |
|:-------|:-------------|
| 0      | Legközelebbihez kerekítés      |
| 1      | Lefelé kerekítés |
| 2      | Felfelé kerekítés    |
| 3      | Csonkítás     |
~~~~

## 1. Számítsd ki a napi díjat egy óradíj alapján

Implementálj egy `daily_rate` nevű függvényt, amely kiszámítja a paraméterként kapott óradíjból a napi díjat, 64 bites lebegőpontos számként.
A szerződés szerint egy nap 8 számlázható órából áll.

```c
daily_rate(60)
// => 480.0
```

A visszaadott napi díjnak 64 bites lebegőpontos számnak kell lennie.

## 2. Számítsd ki a kedvezményes árat

Implementálj egy `apply_discount` függvényt, amely kiszámítja a kedvezmény utáni árat.
Két paramétert kell fogadnia: az eredeti árat és a kedvezmény mértékét százalékban, mindkettőt 64 bites lebegőpontos számként.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

A visszaadott értéknek mindig 64 bites lebegőpontos számnak kell lennie.

## 3. Számítsd ki a havi díjat egy óradíj és egy kedvezmény alapján

Implementálj egy `monthly_rate` függvényt, amely kiszámítja a kedvezményes havi díjat.
Két paramétert kap: egy óradíjat és a kedvezményt százalékban, mindkettőt 64 bites lebegőpontos számként.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

A visszaadott havi díjat felfelé kell kerekíteni (a felső egészre), a legközelebbi 64 bites egész számra.

## 4. Számítsd ki a teljes munkanapok számát egy költségvetés, egy óradíj és egy kedvezmény alapján

Implementálj egy `days_in_budget` függvényt, amely a következő paramétereket kapja:

1. Egy költségvetést, 64 bites előjel nélküli egész számként.
2. Egy óradíjat, 64 bites lebegőpontos számként.
3. Egy kedvezményt százalékban, 64 bites lebegőpontos számként.

A függvény adja vissza a költségvetésből fedezhető teljes munkanapok számát.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

A visszaadott napok számát lefelé kell kerekíteni (az alsó egészre), a legközelebbi 32 bites egész számra.
