# explicit visszatérés

Távolítsd el az explicit visszatérést, hogy egyszerűbb legyen a metódus.

Rubyban a metódus az utolsóként kiértékelt utasítás eredményét adja vissza. Ezért felesleges explicit módon használni a `return` kulcsszót, kivéve, ha a metódusból korán szeretnél visszatérni.

Például ez `16`-ot ír ki, mert a `multiply` metódus az utolsó kifejezése, az `a * b` eredményét adja vissza.

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
