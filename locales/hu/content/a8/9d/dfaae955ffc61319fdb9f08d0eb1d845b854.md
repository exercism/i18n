# Utasítások

Éppen az új, nagyra becsült **Wings Quest** játékot fejleszted.
A játékban egy madár vagy, amely ide-oda mozog, és magokat gyűjt.
A játékos akkor nyer, ha felszedi az összes magot.
Ha a játékos kapcsolatba kerül egy sassal, elveszíti az összes magját, és veszít.
Ez alól a szabály alól van egy kivétel: a játékosnak lehet aktív power-upja, amitől magasabban repül, mint a többi madár.

A feladatod, hogy megírj néhány szabályt, amelyeket a játékban használni fognak.

## 1. Határozd meg, hogy a madár kap-e bónuszpontokat

A játékban a madár bónuszpontokat kap, ha úgy ér hozzá egy sashez, hogy közben aktív a power-upja.

Definiáld a `bonusPoints(powerUpActive:touchingEagle:)` függvényt, amely két argumentumot vár: a `powerUpActive` argumentum azt jelzi, hogy a madárnak aktív-e a power-upja, a `touchingEagle` argumentum pedig azt, hogy a madár hozzáér-e egy sashez.
A függvény csak akkor adjon vissza `true` értéket, ha a madárnak aktív a power-upja, és hozzáér egy sashez, egyébként `false` értéket.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. Határozd meg, hogy a madár szerez-e pontot

A játékban a játékos pontot kap, amikor felvesz egy magot vagy egy power-upot.

Definiáld a `score(touchingPowerUp:touchingSeed:)` függvényt, amely két argumentumot vár: a `touchingPowerUp` argumentum azt jelzi, hogy a madár hozzáér-e egy power-uphoz, a `touchingSeed` argumentum pedig azt, hogy hozzáér-e egy maghoz.
A függvény akkor adjon vissza `true` értéket, ha a madár hozzáér egy power-uphoz vagy egy maghoz, egyébként `false` értéket.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. Határozd meg, hogy a madár veszít-e

Definiáld a `lose(powerUpActive:touchingEagle:)` függvényt, amely két argumentumot vár: a `powerUpActive` argumentum azt jelzi, hogy a madárnak aktív-e a power-upja, a `touchingEagle` argumentum pedig azt, hogy a madár hozzáér-e egy sashez.
A függvény akkor adjon vissza `true` értéket, ha a szereplő hozzáér egy sashez, és nincs aktív power-upja, egyébként `false` értéket.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. Határozd meg, hogy a madár nyer-e

Definiáld a `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)` függvényt, amely a következő argumentumokat várja:

- `hasPickedUpAllSeeds`: hogy a madár felszedte-e az összes magot.
- `powerUpActive`: hogy a madárnak aktív-e a power-upja.
- `touchingEagle`: hogy a madár hozzáér-e egy sashez.

A függvény akkor adjon vissza `true` értéket, ha a madár összegyűjtötte az összes magot, és a 3. részben meghatározott argumentumok alapján nem veszített, egyébként `false` értéket.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
