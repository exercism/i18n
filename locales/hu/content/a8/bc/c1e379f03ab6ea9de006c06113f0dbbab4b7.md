# rescue nélkül

Ne használj kivételeket a vezérlésfolyam irányítására.
Próbáld megoldani ezt a feladatot `rescue` használata nélkül.

Ha olyan szabványos könyvtári függvényt használsz, amelynek a neve `!`-re végződik (hibát dob), keress egy ezzel egyenértékű függvényt `!` nélkül (gyakran `{:ok, result}` vagy `{:error, message}` értéket ad vissza).

Megjegyzés: ha ezt az automatikus visszajelzést látod a megoldásodon, lehet, hogy a többi automatikus visszajelzés nem pontos.
Először ezt a problémát javítsd ki!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
