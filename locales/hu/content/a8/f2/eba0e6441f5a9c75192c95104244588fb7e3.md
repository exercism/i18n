# Bevezetés

A Clojure-ban a `vector` egy szekvenciális, indexelt, megváltoztathatatlan gyűjtemény, amely nulla vagy több értéket tartalmaz. Ez azt jelenti, hogy egy vektor létrehozása után az már nem módosítható. A vektorokkal dolgozó függvények új vektort adnak vissza, az eredeti vektor pedig változatlan marad. A vektorban lévő értékek heterogén típusúak lehetnek. A vektorokat a következőképpen definiálhatod:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

Az elemeket index segítségével kérheted le a vektorból. A Clojure vektorai nullaalapúak, vagyis az első elem indexe mindig nulla:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Az eredeti vektor változatlan marad:

```clojure
numbers
;;=> [2 3 5]
```

Ahhoz, hogy megjegyezd a frissített értéket, tovább kell adnod, vagy el kell mentened egy var-ban:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
