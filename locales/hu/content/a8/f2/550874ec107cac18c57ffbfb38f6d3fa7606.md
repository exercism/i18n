# Kiegészítés az utasításokhoz

Bár a Stringekhez vannak `#reversed` és `#reverseDo:` metódusok, ki tudod találni, hogyan csinálhatod meg ezt magad, alacsonyabb szintű karakteriterációval és streamekkel?

Hogy könnyebben böngészhess a kódban, a Pharo-ban van egy remek kódkereső eszköz. A Shift-Enter lenyomásával aktiválhatod.

MEGJEGYZÉS: Az Exercism konvencióját követve a megoldás neve ReverseString, egy Smalltalkosabb név viszont a StringReverser lenne.

## A Smalltalk és a Stringek

A stringek kapcsán van néhány nyilvánvaló apróság, például hogy a megjegyzésekhez kettős idézőjelet, a stringekhez szimpla idézőjelet használunk, a karaktereknek pedig külön szintaxisuk van (pl. $x az „x” karakterre), és ezek első olvasásra összezavarhatnak, mert a konvenciók eltérnek a más nyelvekben használtaktól.

Szó van továbbá a szimbólum fogalmáról is: ez egy olyan string, amely a teljes memóriában egyedi; azaz amikor létrehozzák (tipikusan fordításkor), egy memóriakeresés indul annak megállapítására, hogy létezik-e hozzá hasonló; és csak az eredetit használják. Az indok nemcsak a memóriamegtakarítás, hanem a szimbólumok összehasonlításakor elért jelentős gyorsulás is.

```smalltalk
"this is a comment"
'this is a string'
#'this is a symbol'
#thisIsASymbolToo
```

A Smalltalk programokban ráadásul nagyon kevés vessző van, mert azoknak nincs szintaktikai szerepük.
Ezért például a tömbliterálokban sincs vessző; pl.
`#(1 2 3 4 5)`
A vessző viszont önálló operátor, és akkor találkozol vele, amikor két stringet fűzöl össze; pl.
`'string1', 'string2'`

Végezetül érdemes tudni, hogy a String és a Character külön osztályok. A String a Characterek gyűjteménye. Ez váratlanul érhet, amikor stringeken iterálsz, mert könnyen előfordulhat, hogy karaktereket adsz át egy olyan metódusnak, amely stringeket vár. Vegyük például a következőt:
```smalltalk
(('hello' at: 2) = $e) inspect.
(('hello' at: 2) = 'e') inspect.
```

## A Smalltalk és a streamek
A streamek hasznosak a szekvenciális olvasáshoz és íráshoz.  Tisztábbá teszik a kódot, mert nincs szükség egy index léptetésére.
A streamek bármilyen kollekción működnek.
```smalltalk
stream := WriteStream on: String new.
stream nextPut: $h ; nextPutAll: 'ell' ; nextPut: $o.
stream contents inspect
```
