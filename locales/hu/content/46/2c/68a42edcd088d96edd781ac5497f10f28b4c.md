# Utasítások

Ebben a feladatban középiskolás szerelmespároknak segítesz, hogy a közösségi médiában nyilvánosan kifejezzék a szerelmüket: egy ASCII-szívet rajzolsz a névbetűikkel:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. Szerezd meg a név első betűjét

Valósítsd meg a `first_letter` függvényt. A függvény egy nevet kap, és visszaadja annak első betűjét. A névből eltávolít minden felesleges szóközt.

```gleam
first_letter("Jane")
// -> "J"
```

## 2. Formázd a nevet névbetűvé

Valósítsd meg az `initial` függvényt. A függvény egy nevet kap, és visszaadja annak első betűjét nagybetűvel, mögötte egy ponttal. Ügyelj rá, hogy újra felhasználd a `first_letter` függvényt, amit az előző lépésben definiáltál.

```gleam
initial("Robert")
// -> "R."
```

## 3. Bontsd fel a teljes nevet keresztnévre és vezetéknévre

Valósítsd meg az `initials` függvényt. A függvény egy teljes nevet kap, amely egy keresztnévből és egy vezetéknévből áll, szóközzel elválasztva, és visszaadja a névbetűket. Ügyelj rá, hogy újra felhasználd az `initial` függvényt, amit az előző lépésben definiáltál.

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. Tedd a névbetűket a szívbe

Valósítsd meg a `pair` függvényt. A függvény két teljes nevet kap, és visszaadja a névbetűket egy ASCII-szív belsejében. Ügyelj rá, hogy újra felhasználd az `initials` függvényt, amit az előző lépésben definiáltál.

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
