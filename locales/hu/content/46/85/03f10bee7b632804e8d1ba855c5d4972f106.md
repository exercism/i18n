# Utasítások

Egy kis szigeti komp menetrendjét kezeled. Az indulásokat dátumként
rögzítik, és szükséged lesz néhány segédfüggvényre, hogy dolgozhass velük.

## 1. Rögzíts egy indulási dátumot

Definiáld a `make-date` függvényt úgy, hogy fogadjon egy évet, egy hónapot
és egy napot, majd adja vissza a hozzá tartozó időbélyeget.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. Nevezd meg a hét napját

Definiáld a `weekday-name` függvényt úgy, hogy fogadja egy indulás
időbélyegét, és adja vissza a hét azon napjának a nevét, amelyre esik.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. Szökőévek

Definiáld a `leap?` függvényt úgy, hogy fogadjon egy évet, és adja vissza,
hogy szökőév-e.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. Napok egy hónapban

Definiáld a `month-length` függvényt úgy, hogy fogadjon egy évet és egy
hónapot, és adja vissza a hónap napjainak a számát (ne feledkezz meg
februárról).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. Napokkal később

Definiáld az `add-days` függvényt úgy, hogy fogadjon egy időbélyeget és egy
napszámot, és adja vissza az ennyi nappal későbbi időbélyeget.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
