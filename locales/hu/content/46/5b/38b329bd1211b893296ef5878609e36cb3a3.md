# Bevezetés

A [`string`][ref-string] a Kotlinban Unicode-karakterek változhatatlan sorozata.

A [`Immutable`][wiki-immutable] azt jelenti, hogy egy stringen végzett bármely műveletnek új stringet kell visszaadnia: az eredeti string soha nem változhat meg.

A [`Unicode`][wiki-unicode] azt jelenti, hogy a világ írásrendszereinek többsége ábrázolható vele, de (ellentétben a régebbi nyelvekkel, például a C-vel) nincs 1:1 megfelelés a karakterek és a bájtok között.

A stringet kettős idézőjelek `" "` veszik körül.

Néhány karaktert escape-elni kell: a `\\`, valamint a szokásos nem nyomtatható karakterek, például a `\t` (tabulátor) és a `\n` (sortörés).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

A többsoros stringeket három kettős idézőjel veszi körül, és tetszőleges szöveget tartalmazhatnak (nem kell escape-elni).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

A [trimIndent][trimIndent-doc] segítségével eltávolíthatod a sorok közös behúzását.
Ez hasznos a string formázásához:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Másik lehetőség a [trimMargin][trimMargin-doc], amellyel megadhatsz egy határolójelet.
A `String` minden sora ezután a határolójel után kezdődik.
A határolójel alapértelmezés szerint `|`, de paraméterként megadhatsz ettől eltérőt is.
Például:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

A stringeket a `+` operátorral fűzheted össze, de ezt érdemes a rövid és egyszerű esetekre korlátozni.
Vannak más, gyakran jobb lehetőségek is.

## String-sablonok

Ez arra utal, amit más nyelvek „interpolációnak” neveznek.

Ha egy string dollárjelet `$` tartalmaz, amelyet azonosító követ, vagy kapcsos zárójeleket (`{expression}`), amelyek egy kifejezést fognak közre, akkor ezek helyére rendre az érték, illetve a kifejezés eredménye kerül.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

A kapcsos zárójelek `{ }` akkor kellenek a kifejezések körül, amikor az értelmezés egyébként kétértelmű lenne.

Általában a string-sablonok használata hatékonyabb és idiomatikusabb módja a stringek összefűzésének, mint a `+`.

## Stringfüggvények

A Kotlin _sok_ [`functions`][ref-string-functions] függvényt kínál a stringek kezeléséhez.

Többségük [`extensions functions`][ref-extensions], nem pedig a `String` osztály tagja, bár ennek kevés hatása van arra, hogyan használjuk őket.

~~~~exercism/note
A Kotlin meglehetősen bonyolult [dokumentációs][ref-string-functions] oldalai elrejtik a bővítő függvényeket az alapértelmezett nézetben.
Mindenképpen kattints a `Members & Extensions` elemre, hogy kibontsd ezt a szakaszt.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

A következő példák csak egy kis válogatást mutatnak abból, ami elérhető:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
