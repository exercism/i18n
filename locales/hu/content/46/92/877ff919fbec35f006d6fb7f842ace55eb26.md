# Utasítások

A közösségi művészeti központ mozaikjának a telepítése múlt
hónapban fejeződött be, és most Magpie Marg fedezte fel. A legtöbb
napon kicserél egy-két csempét fényesebbekre a közeli
**kincsraktárából**, vagy kipiszkál egy csempét, és eltűnik egy
órára.

Te vagy az az önkéntes, aki feljegyzi az összes változást. A mozaik
maga egy **rögzített méretű tömb**: minden csemepozícióhoz egy hely
tartozik, benne egy szín string, vagy `f`, ami a hiányzót jelöli.
Magpie Marg kincsraktára egy **vektor** a lopott, laza csempékből.

## 1. Rakj ki egy új sort

Definiáld a `fresh-mosaic` szót úgy, hogy átvesz egy `n` hosszúságot,
és visszaad egy `n` üres helyből álló tömböt (mindegyik `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Helyezz el egy csempét

Definiáld a `place-tile` szót, amely átvesz egy sort, egy pozíciót és
egy színt, majd helyben frissíti a sort, hogy a megadott pozíció azt a
színt tárolja. A szó nem ad vissza semmit.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Pattints ki egy csempét

Definiáld a `chip-tile` szót, amely átvesz egy sort és egy pozíciót,
majd helyben frissíti a sort, hogy a megadott pozíció ismét `f`
legyen.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Színezz át egy csempét

Definiáld a `recolour-tile` szót, amely átvesz egy sort, egy pozíciót
és egy egyargumentumos quotationt, majd helyben frissíti a sort úgy,
hogy a megadott pozíción lévő csempére alkalmazza a quotationt.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Készíts pillanatképet, mielőtt Marg megérkezik

Definiáld a `snapshot-mosaic` szót, amely átvesz egy sort, és visszaad
egy független másolatot, amelyet nem érintenek az eredeti későbbi
módosításai.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg zsebre tesz egy csempét

Definiáld a `stash-tile` szót, amely átveszi Marg kincsraktárát (egy
vektort) és egy színt, majd a színt hozzáfűzi a kincsraktárhoz. Nem ad
vissza semmit.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg visszaad egy csempét

Definiáld a `return-tile` szót, amely átveszi Marg kincsraktárát, majd
eltávolítja és visszaadja a legutóbb elrejtett csempét (a legfelsőt).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
