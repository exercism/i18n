# Névjegy

A Swift egy fordított, többparadigmás programozási nyelv, amelyet három fő célkitűzéssel terveztek:

- **Biztonság**: A beépített nyelvi funkciók segítenek elkapni és megelőzni a bugokat, mielőtt a kódod éles környezetben futna.
- **Sebesség**: Optimalizált teljesítmény, amely a C-alapú nyelvekéhez hasonlítható.
- **Kifejezőerő**: Letisztult, modern szintaxis, amelyet élvezetes és könnyű olvasni és írni.

Az Apple 2014-ben mutatta be a Swiftet az Objective-C modern leváltásaként, amely addig az iOS- és macOS-fejlesztés nyelve volt.
Ma a Swift nyílt forráskódú, és Apple-platformokon, Linuxon és Windowson fut.

## Első lépések

### Változók

Az értékeket eltárolhatod és elnevezheted úgy, hogy definiálsz egy [változót][constants-variables].
Miután definiáltál egy változót, a nevével a kódodban bárhol hivatkozhatsz erre az értékre.
A változók _módosíthatók_, ami azt jelenti, hogy az értékük a definiálásuk után is megváltozhat.

A változókat a `var` kulcsszóval definiálod:

```swift
var variableName = 10
```

A Swift statikusan típusos nyelv, ami azt jelenti, hogy minden érték típusa ismert fordítási időben.
A típust explicit módon is megadhatod [típusannotációval][type annotations], vagy hagyhatod, hogy a Swift fordítója [kikövetkeztesse a típust][type-inferring] a hozzárendelt értékből:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

A változó értékét az értékadó operátorral (`=`) frissítheted:

~~~~exercism/note
A változó típusa a deklarálása után nem változhat meg.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Deklarálhatsz változót kezdőérték nélkül is, ha megadod a típusát, de használat előtt értéket kell adnod neki:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Konstansok

A [konstansok][constants-variables] szintén nevet rendelnek egy értékhez, de az értékük az értékadás után nem változtatható meg.
Ezek _megváltoztathatatlanok_.
A konstansokat a `let` kulcsszóval definiálod:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Aritmetikai operátorok

A Swift szabványos [aritmetikai operátorokat][arithmetical-operators] biztosít az alapvető matematikai műveletekhez:

- Összeadás: `+`
- Kivonás: `-`
- Szorzás: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Függvények

A Swiftben a [függvények][functions] önálló kódrészletek, amelyek egy adott feladatot látnak el.
A függvények fogadhatnak bemeneteket, adhatnak vissza értéket, és értékként továbbadhatók más függvényeknek.
A függvényeket a `func` kulcsszóval definiálod, amelyet a függvény neve, zárójelbe tett paraméterlista és egy opcionális visszatérési típus követ:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

A Swift függvényei [argumentumcímkéket][argument-labels] használnak, amelyektől a kód természetes mondatokként olvasható:

- Az **argumentumcímkét** a függvény hívásakor használod.
- A **paraméternév** a függvény törzsén belül szolgál az érték elérésére.

Ha csak egy nevet adsz meg, a Swift azt argumentumcímkeként és paraméternévként is használja:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Ha nem szeretnél argumentumcímkét a függvény hívásakor, írj egy alulvonást (`_`) a paraméternév elé:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

A függvények minden paramétere alapértelmezés szerint konstans (`let`), ami azt jelenti, hogy az értékük a függvény törzsén belül nem módosítható.

Ha értéket szeretnél visszaadni egy függvényből, a `->` után megadod a visszatérési típust, és használod a `return` kulcsszót:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Ha egy függvény nem ad vissza értéket, a visszatérési típusa `Void` (ami egyenértékű egy üres tuple-lel, `()`).
Az ilyen függvényekben elhagyhatod a `-> Void` visszatérési típust és a `return` utasítást is.

### Megjegyzések

A Swift kétféle [megjegyzést][comments] támogat:

- Az **egysoros megjegyzéseket** `//` előzi meg, és a sor végéig tartanak.
- A **többsoros megjegyzéseket** `/*` és `*/` közé kell tenni.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
