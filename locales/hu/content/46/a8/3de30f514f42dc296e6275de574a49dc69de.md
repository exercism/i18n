# Modulok és útvonalak Cairo-ban

A Cairo **modulokkal** szervezi a kódot.

A modulok segítenek a projektek felépítésében, és szabályozzák az olyan elemek láthatóságát, mint a függvények, a structok és a trait-ek.

## Modulok definiálása

A modulokat a `mod` kulcsszóval definiáljuk, és egymásba is ágyazhatók:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

A függvények, a structok és a trait-ek **alapértelmezés szerint privátak**.

A `pub` kulcsszóval teheted őket elérhetővé a moduljukon kívül.

## Útvonalak: abszolút és relatív

Ha egy másik modulban lévő elemre szeretnél hivatkozni, ezeket használhatod:

- **Abszolút útvonalak** (a `crate::`-ból kiindulva):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Relatív útvonalak** (az aktuális modulból kiindulva):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Ez akkor működik, ha a `front_of_house` ugyanabban a modulban van.

## Modulok behozatala a scope-ba a `use` kulcsszóval

Kényelmetlen mindig kiírni a teljes útvonalat.

A `use` kulcsszóval rövidebb hivatkozásokat írhatsz:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

A `use` **csak abban a scope-ban érvényes, ahol szerepel**; ha máshol is szükség van rá, meg kell ismételni.

### A `use` idiomatikus használata

- **Modulokat** hozz be a scope-ba, ne függvényeket:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  Ez helyett:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- **Trait-eknél, structoknál és enumoknál** a teljes útvonalat használd:

  ```rust
  use core::num::traits::BitSize;
  ```

### Álnevek az `as` kulcsszóval

Ha szükséges, nevezd át az importokat:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Több elem importálása

Több `use` utasítás helyett csoportosítsd az importokat:

```rust
use shapes::{Square, Circle, Triangle};
```

## Újraexportálás `pub use`-jal

Ha egy modult más szerkezetben szeretnél elérhetővé tenni, használd a `pub use`-t:

```rust
pub use crate::front_of_house::hosting;
```

Mostantól a külső kód a `restaurant::hosting::add_to_waitlist()` hívást használhatja a `restaurant::front_of_house::hosting::add_to_waitlist()` helyett.

## Külső csomagok használata a Scarbbal

Függőség hozzáadásához frissítsd a `Scarb.toml` fájlt:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Függőségek hozzáadásához a `scarb add <package>`, eltávolításukhoz pedig a `scarb rm <package>` parancsot használd.

## A glob operátor (`*`)

Egy modul összes elemének importálásához:

```rust
use core::num::traits::*;
```

Óvatosan használd, mert nehezebben olvashatóvá teheti a kódot.
