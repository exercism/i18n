# Bevezetés

## Kulcsszólisták

A kulcsszólisták kulcs-érték adatszerkezetek.

```elixir
[month: "April", year: 2018]
```

A kulcsszólisták `{key, value}` [tuple-ok][exercism-tuples] listái, és ilyen formában is leírhatók, de a rövidebb szintaxist szélesebb körben használják.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

A kulcsszólistában a kulcsoknak [atomoknak][exercism-atoms] kell lenniük, de az értékek bármik lehetnek. Egy kulcs többször is használható. A kulcs-érték párok a kulcsszólistában sorrendben vannak.

A kulcsszólistákkal ugyanazokkal a megközelítésekkel dolgozhatsz, mint a listákkal, vagy használhatod a `Keyword` modult.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
