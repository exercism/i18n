# Kiegészítő utasítások

## Regiszterek

| Regiszter | Használat | Típus      | Leírás                                                     |
| --------- | --------- | ---------- | ---------------------------------------------------------- |
| `$a0`     | bemenet   | egész szám | kategória: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`     | bemenet   | cím        | kockák (word-tömb)                                         |
| `$v0`     | kimenet   | egész szám | az elért pontszám                                          |
| `$t0-9`   | ideiglenes | bármilyen | ideiglenes tárolásra szolgál                               |
</br>
