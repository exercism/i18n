# Névjegy

A **felhasználó által definiált** függvényeket a `function` kulcsszóval hozzuk létre. Utána egy függvénynévnek és az argumentumok listájának kell következnie.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

A függvényeket egy fájlban akár a definiálásuk előtt is meg lehet hívni, mert a scope-juk tetejére kerülnek.

## Elnevezés

A PHP-ban a függvénynevek ugyanazokat a szabályokat követik, mint a többi azonosító: aláhúzással vagy betűvel kell kezdődniük, amit tetszőleges számú betű, szám vagy aláhúzás követhet.
