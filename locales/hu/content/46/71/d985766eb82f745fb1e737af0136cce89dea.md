# Bevezetés

A Pythonban a szótár (`dict`) olyan adatszerkezet, amely [hash-elhető][term-hashable] _kulcsokat_ rendel _értékekhez_, más programozási nyelvekben pedig átméretezhető [hash-táblaként][hashtable-wikipedia], hashmapként vagy [asszociatív tömbként][associative-array] ismerik.
A szótárak a Python egyetlen beépített [leképezéstípusa][mapping-types-dict].


A `Keys`-nek hash-elhetőnek kell lennie, és a szótárban egyedinek.
A kulcsok típusa lehet `numbers`, `str` vagy `tuples` (_megváltoztathatatlan_ értékekből).
Nem tartalmazhatnak _megváltoztatható_ adatszerkezeteket, például `lists`, `dict`s vagy `set`s.
A Python 3.7-től kezdve a `dict` kulcsainak sorrendje garantáltan az a sorrend, amelyben a bejegyzéseket beszúrtad.

A `values` bármilyen adattípusú vagy szerkezetű lehet.
 Az értékek _tetszőlegesen_ egymásba ágyazhatók, így tartalmazhatnak listák listáit, alszótárakat, valamint más egyéni vagy összetett adatszerkezeteket.

Ha adott egy `key`, a szótárak (átlagosan) állandó idő alatt képesek lekérdezni egy `value`-t (_függetlenül a bejegyzések számától_).
Ahhoz képest, hogy egy értéket egy `list`-ben vagy `array`-ben kell megkeresni (_anélkül, hogy ismernéd az `index` pozícióját_), a `dict` lényegesen több memóriát használ, de a visszakeresés nála sokkal gyorsabb.
A szótárak különösen hasznosak olyan helyzetekben, amikor az elemek gyűjteménye nagy, és gyakran kell elérni és frissíteni őket.


## Szótár létrehozása

A szótárakat többféleképpen is létrehozhatod.
A két legegyszerűbb mód a `dict()` konstruktor használata vagy egy `dict` _literál_ deklarálása.

### A `dict()` osztálykonstruktor

A `dict()` (_a szótár osztály konstruktora_) bármilyen, `key`, `value` párokból álló iterálhatóval használható, vagy `<name>=<value>` _argumentumok_ sorozatával:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### Szótári literálok

Egy `dict` közvetlenül is megadható _szótári literálként_, kapcsos zárójelekkel (`{}`), amelyek `key : value` párokat zárnak közre:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## Értékek elérése egy szótárban

Egy szótár bejegyzését egy _kulcs_ segítségével érheted el szögletes (`[]`) zárójelekkel.
Ha egy `key` nem létezik a `dict`-ben, `KeyError` keletkezik:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

A `KeyError` elkerülhető, ha a bejegyzést a `.get(<key>, <default value>)` metódussal éred el:

```python
>>> bear.get("color", 'not found')
'not found'
```

## Szótárértékek módosítása vagy hozzáadása

Egy bejegyzés `value`-ját úgy módosíthatod, hogy értéket rendelsz a _kulcsához_:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

Új `key`:`value` párok ugyanígy _adhatók hozzá_:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## Szótárbejegyzések eltávolítása (popolása)

A `.pop(<key>)` metódussal törölhetsz egy szótárbejegyzést.
A `.pop()` eltávolítja a (`key`, `value`) párt, és visszaadja a `value`-t, hogy felhasználhasd.
A `.get()`-hez hasonlóan a `.pop(<key>)` is elfogad egy második argumentumot (_`dict.pop(<key>, <default value>)`_), amelyet akkor ad vissza, ha a `key` nem található.
Ez megakadályozza, hogy `KeyError` keletkezzen:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## Egy szótár bejárása és iterálása

Ha a `for item in dict` vagy a `while item` szerkezettel járod be a szótárat, alapértelmezés szerint csak a _kulcsokon_ iterálsz.
Ugyanezen cikluson belül a _szögletes zárójelek_ segítségével férhetsz hozzá az _értékekhez_:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

A `.items()` metódust is használhatod, amely automatikusan (`key`, `value`) tuple-öket ad vissza:

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

Hasonlóképpen a `.keys()` metódus a `keys`-t, a `.values()` metódus pedig a `values`-t adja vissza.
