# Utasítások

Az a feladatod, hogy létrehozz egy naplókönyvtárat, amely segít a szervezeted naplóinak kezelésében.
Ez a könyvtár lehetővé teszi a felhasználók számára, hogy azonosítsák, melyik alkalmazás bocsátotta ki az adott naplót, kijavítsák a sérült naplókat és meghatározzák, hogy egy adott naplósor egy bizonyos karakterkorláton belül van-e.

## 1. Azonosítsd, melyik alkalmazás bocsátotta ki a naplót

A naplók több alkalmazásból származnak, amelyek mindegyike saját, zárt naplóformátumot használ.
Mielőtt egy naplót egy naplóaggregációs rendszerben tárolnánk, azonosítani kell, hogy melyik alkalmazás bocsátotta ki.

Készítsd el az `Application` függvényt, amely egy naplósort kap, és visszaadja azt az alkalmazást, amely a naplósort kibocsátotta.

Egy adott naplósort kibocsátó alkalmazás azonosításához keresd meg a naplósorban az alábbi táblázatban meghatározott karaktert:

| Alkalmazás       | Karakter  | Unicode-kódpont    |
|------------------|-----------|--------------------|
| `recommendation` | ❗        | `U+2757`           |
| `search`         | 🔍        | `U+1F50D`          |
| `weather`        | ☀         | `U+2600`           |

Ha egy naplósor nem tartalmazza a fenti táblázatban szereplő karakterek egyikét sem, add vissza a hívónak a `default` értéket.
Ha egy naplósor a fenti táblázatban szereplő karakterek közül egynél többet tartalmaz, add vissza a balról jobbra haladva elsőként megtalált karakterhez tartozó alkalmazást.

```go
Application("❗ recommended search product 🔍")
// => recommendation
```

## 2. Javítsd a sérült naplókat

A naplózási infrastruktúrában előforduló ritka, de makacs hiba miatt bizonyos karakterek a naplókban megsérülhetnek.
Miután időt töltöttél a sérült karakterek és eredeti értékük azonosításával, úgy döntesz, hogy frissíted a naplókönyvtárat, hogy segítsen a sérült naplók javításában.

Készítsd el a `Replace` függvényt, amely egy naplósort, egy sérült karaktert és az eredeti értéket kapja, és visszaad egy módosított naplósort, amelyben a sérült karakter minden előfordulása az eredeti értékre van cserélve.

```go
log := "please replace '👎' with '👍'"

Replace(log, '👎', '👍')
// => please replace '👍' with '👍'"
```

## 3. Állapítsd meg, hogy egy napló megjeleníthető-e

A naplók megjelenítéséért felelős rendszereknek korlátja van arra, hogy naplósoronként hány karakter jeleníthető meg.
Ezért a felhasználók azt kérik, hogy ez a könyvtár tartalmazzon egy segédfüggvényt annak meghatározására, hogy egy naplósor belefér-e egy adott karakterkorlátba.

Készítsd el a `WithinLimit` függvényt, amely egy naplósort és egy karakterkorlátot kap, és visszaadja, hogy a naplósor a karakterkorláton belül van-e.

```go
WithinLimit("hello❗", 6)
// => true
```
