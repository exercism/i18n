# Bevezetés

## Típuszsonglőrködés

A típuszsonglőrködést automatikus típuskonverziónak is nevezik.
A típuszsonglőrködés azt jelenti, hogy két különböző típusú érték ugyanarra a típusra alakul, hogy elvégezhető legyen egy művelet.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Ez történhet automatikusan (lásd a fenti példát), vagy explicit módon, `C`-stílusú kasztolással:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

A kézi kasztolásnál megengedett típusok: `bool`, `int`, `float`, `string`, `array`, `object`.
A kasztolást leggyakrabban arra használjuk, hogy egy egész számot (`int`) tizedes törtté (`float`) alakítsunk, vagy fordítva.
