# Kiegészítés az utasításokhoz

## Szavak

Definiálj egy `cmplx` tuple-t `real` és `imaginary` mezővel. A
`real>>` és `imaginary>>` mezőelérőket a tuple definíciója adja ingyen,
és a tesztek ezekkel olvassák ki a valós és képzetes részt.

- `<cmplx> ( real imag -- cmplx )` - komplex szám létrehozása.
- `>cmplx ( pair -- cmplx )` - `cmplx` építése ebből:
  `{ real imaginary }`.
- `cmplx>pair ( cmplx -- pair )` - `{ real imaginary }` visszaadása.
- `c+ ( a b -- c )`, `c- ( a b -- c )`, `c* ( a b -- c )`,
  `c/ ( a b -- c )` - két komplex szám aritmetikája.
- `c-abs ( a -- |a| )` - abszolútérték (valós szám).
- `c-conj ( a -- a* )` - komplex konjugált.
- `c-exp ( z -- e^z )` - komplex exponenciális.

A Factor `MATH:` generikusai (`+`, `-`, `*`, `/`) csak a beépített
matematikai hierarchián diszpécselnek, ezért ez a feladat az ezekre a
generikusokra írt metódusok helyett külön szóneveket használ.

A valós számokat komplex számokkal vegyítő aritmetika tesztjei
kimaradnak: az itteni műveletek mindegyike két `cmplx` érték között
történik.
