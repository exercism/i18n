# Bevezetés

A [struktúrák][structs-and-classes] (közkeletű nevükön *structok*) a Swift-programok egyik elsődleges építőeleme.
A struktúrák segítségével olyan egyéni típusokat hozhatsz létre, amelyek a kapcsolódó tulajdonságokat (adatokat) és metódusokat (viselkedést) együtt csoportosítják.
Valójában a Swift szabványos típusai, köztük az `Int`, `Double`, `Bool`, `String`, `Array` és `Dictionary`, mind struktúraként vannak megvalósítva.

## Struktúrák definiálása

A struktúrát a `struct` kulcsszóval definiálod, amelyet a definiálandó típus neve követ, végül a definícióját tartalmazó kapcsos zárójelek.
A Swift konvenciója szerint a struktúrák nevét `UpperCamelCase` stílusban írjuk:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Példányok létrehozása

A struktúra definíciója egy tervrajz.
Egy struktúra *példányának* létrehozásához hívd meg a kezdőértékét úgy, hogy leírod a típus nevét, majd utána egy pár zárójelet:

```swift
var someStats = CharacterStats()
```

Ez létrehoz egy példányt, amely a definícióban megadott alapértelmezett tulajdonságértékekkel lesz feltöltve.

A Swift emellett automatikusan létrehoz egy **tagonkénti kezdőértéket** a struktúrákhoz, amellyel a tulajdonságokat név szerint adhatod meg:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Tulajdonságok elérése és módosítása

Egy példány tulajdonságait _pontnotációval_ érheted el és módosíthatod:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Mivel a struktúrák értéktípusok, egy példány tulajdonságainak módosításához magát a példányt `var` kulcsszóval kell deklarálni.
Ha a példányt `let` kulcsszóval deklarálod, az összes tulajdonsága megváltoztathatatlanná válik.
