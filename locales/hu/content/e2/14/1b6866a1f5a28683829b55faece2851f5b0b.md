# A hash-ekről

A hash a Perl egyik adattípusa, amely rendezetlen gyűjteményt tartalmaz: string kulcsokhoz skaláris értékek párosulnak.

A hash változót általában úgy töltjük fel, hogy hozzárendelünk egy listát, pl. `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

A listák elemeit általában vessző választja el, de gyakran látni fogod az úgynevezett „kövér vesszőt” (`=>`), amely egy listában a kulcsokat és az értékeket választja el.
A viselkedése majdnem megegyezik a vesszőével, de van egy előnye: a bal oldali elemet stringként értelmezi.

A hash feltölthető úgy is, hogy egyes kulcsokhoz rendelünk értéket, pl. `$scores{Alice} = 10;`.

A hash értékeihez a kulcsok alsó indexben való megadásával férhetünk hozzá, pl. `$scores{Bob} # 15`.

A hash-ben a kulcsok egyediek.
Ha egy kulcs többször szerepel, csak az utolsóként megadott érték marad meg.

## Függvények

A hash-ekkel való munkához tartozó függvények közé tartozik a [keys][keys] és a [values][values], amelyekkel a hash megfelelő részeit listaként kérhetjük le.
A [keys][keys] és [values][values] függvények által visszaadott listák hasznosak lehetnek listafüggvényekhez, például a [grep][grep], [map][map] és [sort][sort] függvényhez, valamint a [for][for] ciklusokhoz.

További hash-függvények: az [exists][exists], amellyel ellenőrizhetjük, hogy létezik-e egy kulcs a hash-ben (akkor is, ha az értéke `undef`), és a [delete][delete], amellyel eltávolíthatunk egy kulcsot a hash-ből.

## A sigil változékonysága

Amikor egy hash értékeit kérjük le, az adott sigil határozza meg az eredményt.
A változónév végén lévő `{}` alsó index jelzi a Perlnek, hogy az adott nevű hash-hez férsz hozzá.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Bár megengedett, az olvashatóság érdekében ajánlott, hogy a különböző változótípusok ne osszák ugyanazt a nevet.
