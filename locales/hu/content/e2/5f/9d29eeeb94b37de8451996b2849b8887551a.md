# Hibakeresés

A Red-szkripted minden kimenete látható a konzolon, amikor minden tesztet futtatsz. A `print` segítségével bármit kiírhatsz, például a szavak értékeit:

```red
print ["x =" x]
```

A `probe` függvény is nagyon hasznos. Kiértékeléskor kiértékeli a bemenetét, kiírja az eredményt a típusát tükröző módon, és visszaadja. Így a legtöbb esetben „átlátszó”, és beillesztheted kifejezésekbe:

```red
x: 10
y: probe x + 5
```

Néha a `type?` nevű függvény (igen, kérdőjel van a nevében!) is hasznos lehet egy érték típusának ellenőrzéséhez:

```red
print ["x type:" type? x]
```

Vannak további, fejlettebb hibakeresési technikák is, amelyek [a Red Wiki oldalán vannak felsorolva](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
