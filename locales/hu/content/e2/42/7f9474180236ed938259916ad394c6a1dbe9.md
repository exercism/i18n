# Kiegészítés az utasításokhoz

Azt az irányt, amerre a robot néz, a következő számok egyike fejezi ki:

- Észak = 0
- Kelet = 1
- Dél = 2
- Nyugat = 3

Ha a bemenet érvénytelen, adj vissza -1 irányértéket (a többi értéket figyelmen kívül hagyjuk).

## Fenntartott memória

A bemeneti string puffere a lineáris memória 64-319. bájtját használja.

A bemeneti string szükség esetén módosítható.
