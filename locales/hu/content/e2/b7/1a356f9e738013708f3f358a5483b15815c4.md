# Tippek

## Általános

- A Go szeletei nullától indexelődnek.
  A szelet első indexe a `0`.
- A beépített [`append`][append-builtin] függvény [`variadic`][variadic-gobyexample]
- Egy szelet elemeit a három pont jelöléssel fűzheted hozzá egy másik szelethez:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. Hozz létre egy szeletet adott kártyákkal

- Ha egy szeletet előre feltöltött adatokkal szeretnél létrehozni, használd a szeletliterál jelölést: `s := []T{x1, x2, ..., xn}`.

## 2. Kártya kivétele a pakliból

- Egy szelet `n`-edik elemének eléréséhez [használj indexet][go-slices].
- Annak ellenőrzéséhez, hogy egy elem létezik-e egy szeletben, használj feltételt, és hasonlítsd össze az indexet [a szelet hosszával][len-builtin].

## 3. Kártya cseréje a pakliban

- Egy szelet `n`-edik elemének beállításához [használj indexet][go-slices], és adj neki új értéket.
- Ha új elemet szeretnél hozzáadni egy szelet végéhez, használd az `append` függvényt.

## 4. Kártyák hozzáadása a pakli tetejéhez

- A szelet elejéhez úgy adhatsz hozzá elemeket, hogy az eredeti szelet elemeit a `value` argumentumnak átadott szelethez fűzöd.

## 5. Kártya eltávolítása a pakliból

- Egy elem eltávolítása egy szeletből úgy történhet, hogy az `index` utáni részt az index előtti részhez fűzöd.
