# Utasítások

Ebben a feladatban nagy sportrajongó vagy, és épp most fedeztél fel magadban szenvedélyt az NBA kosárlabda iránt.
Mivel még új vagy az NBA kosárlabdában, mélyelemzést végzel az NBA történetéből: nyomon követed a csapatokat, az edzőket és a győzelmi/vereség statisztikáikat, és összehasonlítod őket egymással.

Mivel még nincs kedvenc csapatod, egy algoritmust is fejlesztesz majd, amivel eldöntheted, hogy egy adott csapatnak szurkolj-e.
Hét részfeladat segít abban, hogy kifejleszd a saját _csapatszurkolási_ algoritmusodat.

## 1. Definiáld a modellt

Definiáld a `Coach` típusaliast egy rekordhoz a következő két mezővel, a következő sorrendben:

- `name`: az edző neve, típusa `String`.
- `formerPlayer`: jelzi, hogy az edző korábban játékos volt-e, típusa `Bool`.

Definiáld a `Stats` típusaliast egy rekordhoz a következő két mezővel, a következő sorrendben:

- `wins`: a győzelmek száma, típusa `Int`.
- `losses`: a vereségek száma, típusa `Int`.

Definiáld a `Team` típusaliast egy rekordhoz a következő három mezővel, a következő sorrendben:

- `name`: a csapat neve, típusa `String`.
- `coach`: a csapat edzője, típusa `Coach`.
- `stats`: a csapat statisztikái, típusa `Stats`.

## 2. Hozz létre egy csapatot

Olyan harmadik féltől származó kóddal szeretnél együttműködni, amelynek van egy csapat fogalma, de más sorrendben hívja meg a kódodat a paraméterekkel. Adj hozzá egy `createTeam` függvényt a következő szignatúrával: `String -> Stats -> Coach -> Team`.

## 3. Cseréld le az edzőt

Mivel az NBA-tulajdonosok türelmetlenek, rájöttél, hogy a rossz csapateredmények gyakran az edző lecseréléséhez vezetnek.
Valósítsd meg a `replaceCoach` függvényt, amely paraméterként az új edzőt és a csapatot kapja, és visszaadja a csapatot, de az új edzővel:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Ellenőrizd, hogy szurkolj-e egy csapatnak

A jövőben egy bonyolult algoritmust tervezel kidolgozni arról, hogy szurkolj-e egy csapatnak vagy sem, de első próbálkozásként úgy döntöttél, hogy minden olyan csapatnak szurkolsz, amelynek több győzelme van, mint veresége.

Szeretnéd, ha ez a függvény más helyzetekben is újrahasznosítható lenne, ezért használj kiterjeszthető rekordot a típus szignatúrában, hogy bármilyen rekordot elfogadjon, amely rendelkezik a szükséges mezőkkel.
Hogy a függvény a lehető legtömörebb legyen, mintázatillesztéssel szeretnéd kinyerni a `stats` mezőt a függvény paraméteréből.
Valósítsd meg a `rootForTeam` függvényt, amely egy csapatot kap, és `True` értéket ad vissza, ha szurkolni kell a csapatnak; egyébként `False` értéket ad vissza.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
