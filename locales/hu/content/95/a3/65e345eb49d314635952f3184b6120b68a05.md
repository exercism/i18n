# Bevezetés

## Kivételek

A C#-ban a kivételek strukturált, egységes és típusbiztos módot kínálnak a futásidőben fellépő hibák kezelésére. A kivételek és a hibák megfelelő kezelése fontos, ha meg akarjuk akadályozni, hogy az alkalmazás összeomoljon.

A C#-ban minden kivétel alaposztálya a `System.Exception` osztály. Fontos tulajdonságokat tartalmaz, például a `Message` tulajdonságot, amely a kivétel dobásának okáról ad ember által olvasható leírást.

Ahhoz, hogy jelezd, hogy a kód egy bizonyos részén hibának kell lennie, létre kell hozni egy új kivételobjektumot, majd a `throw` kulcsszóval el kell dobni:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Amikor egy kivétel eldobódik, a futtatókörnyezet feladata, hogy megtalálja azt a kódrészt, amely felelős a kivétel kezeléséért. Ha nem talál megfelelő kezelőt, a futtatókörnyezet a program végrehajtásának leállítása mellett megjeleníti a kezeletlen kivételről szóló üzenetet.

Egy kivétel kezelőjének létrehozásához a C# a try-catch utasítást használja, amely egy `try` blokkból és egy vagy több `catch` ágból áll. A `try` blokkban annak a kódnak kell szerepelnie, amely kivételt válthat ki, és ezt védi is a blokk. A `catch` ágakban a hiba bekövetkezése utáni programviselkedést kezelő kódnak kell szerepelnie. Fontos megjegyezni, hogy a `try` blokk utáni kivételek sorrendje számít, mert ha több kivétel van felsorolva, az első illeszkedő `catch` ág fut le.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
