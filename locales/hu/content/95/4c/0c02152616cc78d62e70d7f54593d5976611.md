# Bevezetés

A tuple kiterjeszthet egy másik tuple-t. A `TUPLE: child < parent slots ;`
egy olyan osztályt deklarál, amelynek a példányai egyben a `parent`
példányai is: a sajátjaik mellett megkapják a szülő slotjait is, és rajtuk
a szülő accessorai is működnek, pont mintha a gyermeken lettek volna
definiálva.

```factor
USING: accessors ;

TUPLE: animal name age ;
TUPLE: dog < animal breed ;

"Rex" 4 "labrador" dog boa .
! => T{ dog { name "Rex" } { age 4 } { breed "labrador" } }

"Rex" 4 "labrador" dog boa name>> .   ! => "Rex"   (inherited accessor)
```

## A `boa` slotjainak sorrendje

A `boa` konstruktor a slotokat *deklarációs sorrendben, a szülőkkel
kezdve* várja. A fenti `dog` esetében:

```
dog boa ( name age breed -- dog )
```

Egy unoka, `puppy < dog `, amely hozzáad egy `weeks` slotot, így nézne ki:

```
puppy boa ( name age breed weeks -- puppy )
```

## A predikátumok hierarchiája

Minden `TUPLE:` deklaráció létrehoz egy predikátumot (`name?`).
Öröklés esetén a predikátumok egymásba ágyazódnak. Minden leszármazott
kielégíti a felmenői predikátumait:

```factor
"Rex" 4 "labrador" dog boa
dup dog? .        ! => t
dup animal? .     ! => t
```

Ez viszont fordítva nem igaz: egy `animal`, amely nem `dog`, nem elégíti
ki a `dog?` predikátumot.

## Előretekintés

A generikus metódusok (`M:`, amelyeket a [`generics`][generics]
mutat be) szintén felfelé diszpécselnek a hierarchiában: az `animal`-re
definiált metódus minden leszármazottnál lefut, hacsak egy konkrétabb
felülírás nem élvez elsőbbséget. Ezt rögtön a feladat után a
`boatswains-bilge`-ben látni fogod.

[generics]: https://docs.factorcode.org/content/article-generic.html
