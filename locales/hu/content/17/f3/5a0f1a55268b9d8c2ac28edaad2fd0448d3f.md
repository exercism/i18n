# Bevezetés

Javában véletlenszámokat a `java.util.Random` osztály egy példányával generálhatsz.

## Véletlen egészek

Véletlen egész számot a `nextInt()` metódussal generálhatsz.
Ez egy `Integer.MIN_VALUE` és `Integer.MAX_VALUE` közötti értéket generál.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Ha korlátozni szeretnéd a generált értékek tartományát, a `nextInt(int)` metódust használd.
Ez egy értéket generál a `0`-tól (a `0`-t is beleértve) a megadott felső korlátig (a felső korlátot kivéve).

Például ez egy `0` és `9` közötti véletlen számot generál.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

Ez pedig egy `10` és `19` közötti véletlen számot generál.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## Véletlen lebegőpontos számok

Egy véletlen lebegőpontos számot a `nextDouble()` metódussal generálhatsz.
Ez egy `0.0` és `1.0` közötti értéket generál.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

Ez pedig egy `100.0` és `200.0` közötti véletlen számot generál.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
