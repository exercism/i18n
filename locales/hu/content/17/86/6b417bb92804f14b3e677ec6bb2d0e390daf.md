# Bevezetés

A legtöbb programozási nyelvhez hasonlóan a Gleamnek is vannak „mellékhatásai”: a függvények nemcsak értéket adhatnak vissza, hanem olvashatják és módosíthatják is a világ állapotát.

A Gleam standard könyvtárának `gleam/io` modulja olyan függvényeket tartalmaz, amelyekkel stringeket írhatsz ki a konzolra.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Más csomagok is kínálhatnak egyéb IO-függvényeket, például a `simplifile`, amely fájlok olvasására és írására biztosít függvényeket.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
