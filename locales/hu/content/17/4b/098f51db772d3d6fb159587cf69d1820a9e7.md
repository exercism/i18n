# Bevezetés

A `switch()` függvény tömör alternatívája lehet egy hosszú `if` ... `else if` vizsgálatsorozatnak.
A `switch()`-nek átadott változó leggyakrabban string, és ilyenkor az idézőjeleket el lehet hagyni a választóból.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Figyeld meg, hogy az opciók csak akkor csúsznak át a következőre, ha az érték üresen marad, ahogy az `M` is a fenti példában.
Nem kell `break` utasításokat használni, mint néhány más nyelvben.

Amikor `character` típusra váltunk, az utolsó érték lesz az alapértelmezett, mint itt is.
Egész típusoknál nem adható meg alapértelmezett érték.

## Függvények a `dplyr`-ben

A base R `switch`-e meglehetősen korlátozott: csak egyetlen bemenetre tud pontos egyezést végezni.
Ez ésszerűnek tűnt, amikor az R 1993-ban megjelent, de a modern használathoz fejlesztésre szorul.

~~~~exercism/note
Ahogy a [`Conditionals`][concept-conditionals] fogalomban említettük, a `tidyverse` csomaggyűjtemény célja, hogy kiegészítse (és néha helyettesítse) a base R funkcionalitását anélkül, hogy a visszafelé kompatibilitást befolyásolná.

A `dplyr` csomagot úgy hozhatod be, ha a kódod elejére írod a `library(dplyr)` (az egyes csomaghoz) vagy a `library(tidyverse)` (a teljes gyűjteményhez) utasítást.

[concept-conditionals]: https://exercism.org/tracks/r/concepts/conditionals
~~~~

A `dplyr` csomag két további függvényt kínál a `switch`-hez kapcsolódóan.

### A `recode_values` és `replace_values` függvények

Ez a két rokon függvény vektorizált, `switch`-szerű leképezést tesz lehetővé a régi értékekről az új értékekre.

A fő különbség közöttük az, hogy a `recode_values()` teljesen új vektort hoz létre, míg a `replace_values()` egy meglévő vektor részleges frissítését teszi lehetővé.

Az egyeztetés továbbra is pontos, de:

- A bal oldali opciók vektorok is lehetnek, és a bemenet akkor egyezik, ha bármelyik elem egyezik.
- A bal oldali opciók és a jobb oldali eredmények tilde (`~`) jellel kapcsolódnak össze `=` helyett.
- Alapértelmezett érték minden esetben megadható.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### A `case_when` függvény

A `case_when` továbbfejleszti a `case_match` szintaxist: bármilyen logikai kifejezés állhat a `~` bal oldalán.

A bemeneti vektort (a lenti példában `x`-et) nem argumentumként kell megadni, csak már definiálva kell lennie.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

A `between()` függvény szintén a `dplyr` része.
