# SQLite-specifikus utasítások

A **list_one** és **list_two** oszlopok JSON-kódolt egész számok listáját tartalmazzák.

Példa:

```json
[1, 2, 3]
```

## Táblaséma

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
