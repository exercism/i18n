# Osztályok

Az osztályok a kódszervezés egységei PHP-ban.
Az olyan kód, amely egy dolog viselkedését írja le, vagy egy folyamat viselkedését írja le, osztályba rendezhető.
Azokat a függvényeket, amelyeket egy osztályhoz rendelünk, a szokás szerint `methods`-nek nevezzük.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Az osztályokat a `new` kulcsszóval példányosítjuk, ez lefoglalja a memóriát az osztály példánya számára, és meghívja az osztály konstruktor metódusát.
A példányosított osztályokat értékül adhatjuk egy változónak.
Egy osztálypéldány metódusainak meghívásához a `->` elérési operátort használhatjuk.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Egy példányosított osztály a saját példányára a különleges `$this` változóval hivatkozhat.
Az osztályoknak tulajdonságaik is lehetnek, ezek olyan változóként viselkednek, amelyek az osztályobjektum példányához kötődnek.
Ezekre a tulajdonságokra belülről és kívülről is hivatkozhatunk.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
