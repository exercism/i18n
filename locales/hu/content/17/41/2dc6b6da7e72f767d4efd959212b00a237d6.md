# Utasítások

Egy egészségfigyelő rendszer megvalósításán dolgozol. Ennek részeként nyomon kell követned a felhasználók egészségügyi statisztikáit.

Kiindulásként néhány csonkolt függvényt találsz egy `impl` blokkban, valamint az alábbi `struct` definíciót:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

A célod, hogy megvalósítsd a `User` `struct` csonkolt metódusait, amelyeket az `impl` blokkban definiáltunk.

A `new` metódus például a megadott névvel, életkorral és súllyal rendelkező `User` példányt ad vissza.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

A `weight` metódus a `User` súlyát adja vissza.

```rust
bob.weight();
// Returns: 155.2
```

A `set_age` metódus beállítja a `User` életkorát.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
