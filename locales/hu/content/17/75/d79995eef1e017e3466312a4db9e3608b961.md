# Bevezetés

A rekurzió egy módja annak, hogy egy függvényben ismételjük a kódot úgy, hogy a függvény önmagát hívja.
A ciklusok/iteráció egy másik módjának is tekinthető.
A ciklusokhoz hasonlóan egy Boolean kifejezés vagy `True`/`False` teszt dönti el, mikor álljon le a rekurzív végrehajtás.
A ciklusokkal ellentétben a leállás nélküli rekurzió Pythonban nem futhat a végtelenségig.
A függvényhívásokban használt értékek a saját [keretükben][stack-frame] kapnak helyet a Python [értelmező vermében][what-is-the-call-stack].
Ha a függvényhívások összesített száma több helyet foglal el, mint amennyi a veremben rendelkezésre áll, az hibát eredményez.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

Ez a következőt írja ki:

```
The step is 1
The step is 2
After recursion
```

Előfordulhatnak olyan helyzetek, amelyek rekurzióval kifejezve olvashatóbbak és/vagy könnyebben átgondolhatók, mint ciklusokkal kifejezve.
