# Bevezetés

Az interfész egy olyan típus, amelynek tagjai egy összetartozó funkcionalitáscsoportot definiálnak. Elválasztja az osztály használatát a megvalósítástól, ami lehetővé tesz több különböző implementációt, illetve támogatást nyújt bizonyos általános viselkedéshez, például a formázáshoz, az összehasonlításhoz vagy a konverzióhoz.

Az interfész szintaxisa hasonlít az osztályéhoz, azzal a különbséggel, hogy a metódusok csak szignatúraként jelennek meg, és nem tartozik hozzájuk törzs.

```java
public interface Language {
    String getLanguageName();
    String speak();
}

public class ItalianTraveller implements Language, Cloneable {

    // from Language interface
    public String getLanguageName() {
        return "Italiano";
    }

    // from Language interface
    public String speak() {
        return "Ciao mondo";
    }

    // from Cloneable interface
    public Object clone() {
        ItalianTraveller it = new ItalianTraveller();
        return it;
    }
}
```

Az interfész által definiált összes műveletet meg kell valósítania a megvalósító osztálynak.

Az interfészek általában példánymetódusokat tartalmaznak.

A Java osztálykönyvtárban a fent bemutatott `Cloneable` mellett található egy példa interfészre a `Comparable<T>`.
A `Comparable<T>` interfészt akkor érdemes implementálni, amikor egy kollekcióban alapértelmezett generikus rendezési sorrendre van szükség.
