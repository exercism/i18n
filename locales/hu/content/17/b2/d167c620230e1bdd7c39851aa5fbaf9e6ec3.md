# Utasítások

Te vagy a jelzőőr egy tengerparti járőrhajón. A mai tarisznyában öt kis szónak kell készen állnia, mire megkezdődik a reggeli őrség.

## 1. Idézz egy értéket

A hajónapló minden megfigyelést *Factor-forrásformában* rögzít, ugyanabban a szövegben, amelyet a parser majd visszaolvas. Definiáld a `quote-value` szót, hogy bármely értéket a forrásforma szövegévé alakítson.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. Szedd le a jelző keretét

A beérkező jelzők mindkét végükön egy-egy jelölőkarakterrel körítve érkeznek. Definiáld a `flag-body` szót, hogy mindent visszaadjon, ami a két jelölő *között* van: dobd el az első karaktert, és dobd el az utolsót is.

Másolás helyett szeletet (nézetet) adj vissza.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. Bontsd ketté a jelzőt

Minden jelző egy rövid előtagkódból és az azt követő tartalomból áll. Definiáld a `split-flag` szót, amely egy jelzőt és egy fejléc-hosszt vesz át, és *mind* a fejlécszeletet, mind a törzsszeletet visszaadja.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. Háromszögelj két leolvasásból

Két egymást követő jelzőleolvasás három származtatott mérést ad: a *különbségüket* `a - b`, a *felezőpontjukat* `(a + b) / 2` és a *arányukat* `a / b`. Mindegyik mérés mindkét leolvasást felhasználja.

Definiáld a `triangulate` szót, hogy egy leolvasáspárból mindhármat visszaadja.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. Foglalj össze három leolvasást

Három egymást követő leolvasást az **összegük**, a **szorzatuk** és a **maximumuk** formájában foglalunk össze. Mindegyik statisztika mindhárom leolvasást felhasználja.

Definiáld a `triangle-stats` szót, hogy mindhárom értéket visszaadja.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
