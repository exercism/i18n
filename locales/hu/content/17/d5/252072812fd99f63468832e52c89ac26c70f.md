# Utasítások kiegészítése

## Megvalósítás

Megengedett az alapvető nyelvi eszközök használata tömbök létrehozásához és szétbontásához destrukturálással, valamint a `[]` tömbliterál használata, de az `Array.prototype` egyetlen függvényét sem használhatod.

Ahhoz, hogy tesztelni tudd a megoldásodat, gondoskodj róla, hogy a `forEach` implementálva legyen.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
