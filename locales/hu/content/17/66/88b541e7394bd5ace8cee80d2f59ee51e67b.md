# Bemutatás

A metódusoknak lehet varargs paraméterük, amivel a hívó nulla vagy több argumentumot adhat meg, mintha azok szokásos paraméterek lennének. A metódus ezeket az argumentumokat egyetlen tömbben kapja meg.

Ahhoz, hogy egy paraméter varargs paraméter legyen, add hozzá a [`params` kulcsszót](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params) a paraméter deklarációjához:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
