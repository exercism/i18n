# Utasítások

A cégedet azzal bízták meg, hogy felhasználói bemenetből CSV-rekordokat állítson elő.

Szükségünk van egy builderre, amely az [RFC 4180](https://tools.ietf.org/html/rfc4180) szabványban meghatározottak szerint állít elő CSV-rekordokat.

Bár létezik formális specifikáció, a cégednek csak a következő funkciókat kell megvalósítania:
- új rekordbuilder létrehozása
- egyedi mező hozzáadása a rekordhoz
- a rekord szerializálása alapvető escape-eléssel

Az alapvető escape-elés a következőt jelenti:

- A sortörést, idézőjelet vagy vesszőt tartalmazó mezőket idézőjelek közé kell zárni.

- Ha a mezőket idézőjelek közé zárjuk, akkor a mezőn belül előforduló idézőjelet úgy kell escape-elni, hogy elé egy másik idézőjelet teszünk.


## 1. Új builder létrehozása

Egy új builder létrehozásához a `new` metódust kell implementálnod.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. Egyedi mezők hozzáadása a rekordhoz

A mezők rekordbuilderhez való hozzáfűzéséhez az `add` metódust kell implementálnod.
Az `add` argumentumként immutable string szeleteket, `&str`-t vár.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. A rekord szerializálása alapvető escape-eléssel

A `build` metódust kell implementálnod.
A `build` elfogyasztja a buildert, és egy CSV-rekordot ad vissza.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
