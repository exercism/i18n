# Bevezetés

## Ternáris operátorok

A _ternáris operátor_ egy könnyűsúlyú, tömör alternatíva az egyszerű _if/else_ utasításokhoz.
Általában return utasításokban használják (de nem kizárólag azokban), és egyetlen sorban hozza meg a döntést: visszaadja a bal oldali értéket, ha a kifejezés `true`, a jobb oldali értéket pedig, ha `false`, a következőképpen:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Sok egyszerű _if/else_ kifejezés egyszerűsíthető _ternáris operátorokkal_.
