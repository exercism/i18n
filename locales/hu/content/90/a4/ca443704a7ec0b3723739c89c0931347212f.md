# szakasz a megjegyzésekről

A Go nyelvhez [kiváló útmutató](https://golang.org/doc/effective_go.html) tartozik arról, hogyan érdemes megjegyzéseket írni. Van egy szabványos formátum, amelyet a dokumentációs megjegyzésekhez használhatsz, és amelyet a `godoc` eszköz aztán automatikusan szép dokumentációvá alakíthat.

A csomaghoz tartozó megjegyzés a `Package` szóval kezdődjön, amelyet a csomag neve követ, így:

```go
// Package cook provides handy conversion methods for units typically used in recipes.
package cook
```

Az exportált függvények, metódusok, konstansok és csomagszintű változók esetében a megjegyzés a névvel kezdődjön, és egy igei kifejezéssel folytatódjon:

```go
// TbsToMl converts tablespoons to milliliters.
func TbsToMl(tbs int) int {
	// ...
}
```

A [CodeReviewComments](https://github.com/golang/go/wiki/CodeReviewComments#comment-sentences) wiki tovább pontosítja, hogy a dokumentációs megjegyzések teljes mondatok legyenek, amelyek ponttal végződnek.

Amellett, hogy az olvashatóságot is szolgálja, ezen ajánlások követése javítja a kódod megjelenését a [Go dokumentációs eszközeiben](http://whipperstacker.com/2015/09/30/go-documentation-godoc-godoc-godoc-org-and-go-doc/), például a [godoc.org](http://godoc.org), a `godoc` és a `go doc` esetében.

Szánj rá egy percet, és olvasd el a hivatalos stílusútmutató, az [Effective Go](https://golang.org/doc/effective_go.html) dokumentációs megjegyzésekről szóló szakaszát, hogy lásd az érvelést ezen döntések mögött.
