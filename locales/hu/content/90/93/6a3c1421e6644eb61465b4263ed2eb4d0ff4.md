# Bővebben

A [rekord][records] olyan mezők gyűjteménye, amelyek összetartoznak, és amelyek különböző típusúak is lehetnek. Egy [rekord definiálásához][define] a `type` kulcsszót használjuk. A rekord mezőit a `{` és `}` karakterek között adjuk meg, és minden mezőnek van neve _és_ típusa.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

Egy [rekord létrehozásához][create] add meg a mezők nevét, és rendelj hozzájuk értéket a `{` és `}` karakterek között. Létrehozáskor a rekord minden mezőjéhez tartoznia kell értéknek. A mezőket tetszőleges sorrendben megadhatod, nem kell követniük a rekordtípus definíciójában szereplő sorrendet. Egy rekordpéldány mezőértékeihez pont jelöléssel férhetsz hozzá.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

Rekord definiálásakor vagy létrehozásakor minden mező külön sorba kerül, vagy, ha egy sorban vannak, pontosvesszővel (`;`) választjuk el őket:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

Ha egy rekord mezőnevei egyediek, a típusmegjelölés elhagyható, mert a fordító magától ki tudja következtetni a típust. Ha viszont a mezőnevek kombinációja _nem_ egyedi, kétféleképpen segíthetsz a fordítónak a helyes rekord kiválasztásában: vagy explicit típust adsz meg a rekord kötéséhez, vagy a mezők elé írod a rekord típusát:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

Mivel a rekordok változtathatatlanok, a létrehozásuk után a mezőértékeik soha nem változnak. Ha mégis meg szeretnéd változtatni egy rekord értékeit, a `with` kulcsszóval [készíthetsz másolatot egy létező rekordról úgy, hogy egy vagy több mező új értéket kap][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

A rekordok [_strukturális egyenlőséggel_][equality] rendelkeznek, ami azt jelenti, hogy ugyanannak a rekordnak két azonos értékű példánya egyenértékű:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

A rekordok mezőihez nemcsak pont jelöléssel férhetsz hozzá: kötésekben és mintaillesztésben is _szétbonthatod_ őket a [rekordminta][record-patterns] segítségével:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
