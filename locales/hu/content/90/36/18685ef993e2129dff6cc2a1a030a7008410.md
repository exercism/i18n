# Bevezetés

## Alapok

### Változók

Az Elixir dinamikusan típusos nyelv, ami azt jelenti, hogy egy változó típusát csak futásidőben ellenőrzi. Az egyeztető `=` operátorral bármilyen típusú értéket hozzáköthetünk egy változónévhez:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### Modulok

Az Elixir egy [funkcionális programozási nyelv][functional-programming], és minden nevesített függvényt egy _modulban_ kell definiálni. A `defmodule` kulcsszóval definiálunk modult. Minden modul elérhető futásidőben az összes többi modul számára, és nincs szükség _hozzáférési módosítóra_, hogy a program más részei számára láthatóvá váljanak. A _modul_ más programozási nyelvek _osztályához_ hasonló.

```elixir
defmodule Calculator do
  # ...
end
```

### Nevesített függvények

A _nevesített függvényeket_ modulban kell definiálni. A `def` kulcsszóval definiálunk egy _nyilvános_ nevesített függvényt.

Minden függvénynek lehet nulla vagy több argumentuma. Egy függvény utolsó kifejezésének értéke mindig _implicit módon visszaadódik_.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

Egy függvény meghívásához meg kell adni a modulját és a függvénynevét, majd minden argumentumához át kell adni egy értéket.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

A `defp` kulcsszó a `def` helyett használható _privát_ függvény definiálására. A privát függvényeket csak ugyanazon a modulon belül lehet használni, amely definiálta őket.

Ha egy függvényt ugyanabban a modulban hívunk meg, amelyben definiálták, a modul nevét elhagyhatjuk.

Rövid függvényeket egysoros szintaxissal is írhatsz (figyeld meg a `do` kulcsszó körüli vesszőt `,` és kettőspontot `:`).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### Függvények aritása

Gyakori, hogy a függvényekre az _aritásukkal_ hivatkozunk. Egy függvény _aritása_ az általa elfogadott argumentumok száma.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### Elnevezési konvenciók

A modulneveknél `PascalCase`-t használjunk. Egy modulnévnek nagybetűvel `A-Z` kell kezdődnie, és tartalmazhat betűket `a-zA-Z`, számokat `0-9` és aláhúzásjeleket `_`.

A változó- és függvényneveknél `snake_case`-t használjunk. Egy változó- vagy függvénynévnek kisbetűvel `a-z` vagy aláhúzásjellel `_` kell kezdődnie, tartalmazhat betűket `a-zA-Z`, számokat `0-9` és aláhúzásjeleket `_`, és végződhet kérdőjelre `?` vagy felkiáltójelre `!`.

### Szabványos könyvtár

Az Elixirnek nagyon gazdag és jól dokumentált szabványos könyvtára van. A dokumentáció online elérhető a [hexdocs.pm/elixir][docs] címen. Mentsd el valahova ezt a linket, sokat fogod használni!

A legtöbb beépített adattípushoz tartozik egy megfelelő modul, amely függvényeket kínál az adott adattípus kezeléséhez, például az `Integer` modul az egészekhez, a `String` modul a stringekhez, a `List` modul a listákhoz, és így tovább.

Figyelemre méltó a `Kernel` modul. Ez biztosítja azokat az alapvető képességeket, amelyekre a szabványos könyvtár többi része épül, például aritmetikai operátorok, vezérlési folyam makrói és még sok más. A `Kernel` modul függvényei automatikusan importálódnak, így a `Kernel.` előtag nélkül használhatod őket.
