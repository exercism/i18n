# Bevezetés

Az `array` az F#-ban egy módosítható gyűjtemény, amely nulla vagy több értéket tárol, és rögzített hosszúságú. Ez azt jelenti, hogy a tömb létrehozása után a mérete nem változhat, az értékei viszont igen. Egy tömbben minden értéknek ugyanolyan típusúnak kell lennie. A tömböket így definiálhatod:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

A tömb elemeit index segítségével érheted el, és indexszel rendelhetsz nekik új értéket. Az F# tömbjei nullaalapúak, ami azt jelenti, hogy az első elem indexe mindig nulla:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

A tömböket vagy az `Array` modulban definiált függvényekkel és operátorokkal kezelheted, vagy kézzel, mintaillesztéssel, az _array_ minta segítségével:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Mintaillesztéskor egy értéket el is _dobhatsz_; ha egy adott esetben _nem_ érdekel egy érték (vagyis nem fogod _használni_), egy alulvonással (`'_'`) jelezheted ezt:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Az egyetlen `'_'` mintaillesztéskor mindig _utolsó_ legyen. Minden olyan értéket, amely _nem_ illeszkedik a többi eset egyikére sem, ez az eset kezel.
