# típusspecifikáció használata

[comment]: # (Ez a figyelmeztetés akkor jelenik meg, ha a megoldásban nincs típusspecifikáció)

A függvény bemenetei és kimenete közötti szerződés kifejezéséhez használj [típusspecifikációkat](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs) (`@spec`).

- Az Elixir dinamikusan típusos nyelv, ami azt jelenti, hogy a típusellenőrzés csak futásidőben történik. A típusspecifikációk használata lehetővé teszi, hogy a linterek és a statikus elemző eszközök, például a [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) (amely az Erlang [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html) eszközén alapul), kiértékeljék a kódot nem szándékolt viselkedések szempontjából.
- A beépített típusok [teljes listáját](https://hexdocs.pm/elixir/typespecs.html#basic-types) megtalálod a [nyelvi dokumentációban](https://hexdocs.pm/elixir/typespecs.html#content)
- A típusokat zárójellel vagy anélkül is megadhatod, például `atom()` vagy `atom`
  - Az Exercism Elixir-stílusa szerint zárójel nélkül érdemes megadni őket.

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
