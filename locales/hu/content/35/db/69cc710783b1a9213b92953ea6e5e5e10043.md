# A gofmt nincs használatban

Futtasd a `gofmt`-ot a megoldásodon; ez segít a Go-ban írt kód formázásában.

A Go közösségében nagyon fontos a kód formázása.
A legtöbb IDE beállítható úgy, hogy minden mentéskor automatikusan formázza a kódot. Például:

- A Visual Studio Code-nak [remek Go-támogatása](https://code.visualstudio.com/docs/languages/go) van
- A Vimhez is van egy [fantasztikus Go-kiterjesztés](https://github.com/fatih/vim-go)
- A [Jetbrains Goland](https://www.jetbrains.com/go/) egy komplett Go-IDE

Ha kézzel akarod futtatni a `gofmt`-ot:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
