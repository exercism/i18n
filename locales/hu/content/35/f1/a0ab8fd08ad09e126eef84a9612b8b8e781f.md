# Bevezetés

## Listaértelmezések

A listaértelmezések egyszerű és deklaratív módot kínálnak az _Enumerable_-ok átalakítására.

Egy egészen egyszerű értelmezéshez a `for` kulcsszót használhatjuk, amelyet egy _generátor_ és egy _do-blokk_ követ; ez utóbbi az enumerált értékekből állítja elő az új értékeket.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

Az értelmezéseknek _szűrői_ is lehetnek. Azok az értékek, amelyek nem mennek át a szűrőn, kimaradnak a végső listából:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Bonyolultabb értelmezéseket több sorban is deklarálhatunk:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

Több generátor használatával _Descartes-szorzat_ hozható létre. Ez azt jelenti, hogy az első generátor által előállított minden érték egyszer párosul a második generátor által előállított minden értékkel:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
