# Bemutatás

A Factor karakterei *egész számok*, azaz Unicode-kódpontok, így a sima numerikus
`<`, `>`, `=` jelekkel máris megkapod a kis- és nagybetűre érzékeny sorrendet. A
[`unicode`][unicode] szókészlet ezen felül Unicode-tudatos predikátumokat és
egyetlen karakterre működő kis- és nagybetű-átalakítást kínál.

## Predikátumok

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## Kis- és nagybetű-átalakítás

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

A sztring szintű `>upper`, `>lower` és `>title` ezeket a sztring minden
karakterére alkalmazza.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
