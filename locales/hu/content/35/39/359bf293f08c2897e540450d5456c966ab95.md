# Utasítások

Ebben a feladatban segítesz a középiskolás szerelmeseknek, hogy nyilvánosan vállalják a szerelmüket a közösségi médiában.

## 1. Jelenítsd meg a pár nevét egy szívvel elválasztva

Készítsd el a statikus `HighSchoolSweethearts.DisplaySingleLine()` metódust, amely két nevet vesz át, és azokat egy szívvel elválasztva jeleníti meg.
A formázott szöveg 61 karakter széles legyen, a szív pedig a string közepén legyen.

Minden név biztosan bőven belefér a sor szélességébe.

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. Jelenítsd meg a pár kezdőbetűit egy ascii art szívben

Készítsd el a statikus `HighSchoolSweethearts.DisplayBanner()` metódust, amely a két kezdőbetű-készletet egy plusz jellel elválasztva jeleníti meg.

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
// see the ascii art below
```

## 3. Gondoskodj róla, hogy a német cserediákok otthon érezzék magukat a területi beállításra érzékeny deklarációkkal.

Készítsd el a statikus `HighSchoolSweethearts.DisplayGermanExchangeStudents()` metódust, amely megmutatja a német cserediákjaink kapcsolatának kezdetét és annak időtartamát.

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
