# Bevezetés

Amikor egy quotationnek *emlékeznie* kell a környezetéből származó értékekre (amit más nyelvek *closure*-nak hívnak), a Factor két eszközt használ: a `curry` szót és a `'[ ]` *fry* szintaxist.

## `curry`: egy érték rögzítése

A `curry` (a [`kernel`][kernel] szókészletben) átvesz egy értéket és egy quotationt, majd visszaad egy új quotationt, amelybe az az érték be van építve:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

Két érték rögzítéséhez alkalmazd kétszer a `curry`-t:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: két quotation összefűzése

A `compose` (a [`kernel`][kernel] szókészletben) két quotationt ragaszt össze:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Fry quotationok: több érték rögzítése

Egynél-kettőnél több rögzítésnél az egymás után fűzött `curry` hívások nehezen olvashatóvá válnak. A *fry* a `'[ … ]` formát használja egy vagy több `_` helyőrzővel; minden `_` helyére egy-egy érték kerül, amelyet sorban leveszünk az adatverem tetejéről:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

Mind a `curry`, mind a fry *leveszi* az értékeit a verem tetejéről abban a pillanatban, amikor a closure felépül. A fenti sor semmit sem hagy a veremben, és közvetlenül kiváltja a `[ + + ] curry curry` kifejezést.

A helyőrzőket balról jobbra töltjük fel, a verem aljától a teteje felé haladó értékekkel: a `2 3 '[ _ _ ]` eredménye `[ 2 3 ]`, nem pedig `[ 3 2 ]`.

A fry *bele* is nyúl az egymásba ágyazott quotationokba, így pontosan oda teheted a rögzített értékeket, ahová szeretnéd:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

A `_` a belső `[ … ]` belsejében van, de a fry ettől függetlenül kitölti.

## `call` deklarált veremhatással

Amikor végül lefuttatsz egy eltárolt quotationt, add meg a veremhatását a `call`-nál, hogy a fordító ellenőrizni tudja a típusait:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## Vektoraritmetika

A [`math.vectors`][math.vectors] szókészlet két azonos hosszúságú sorozatot elemenként kombinál össze. A `v+` és a `v*` összeadja, illetve összeszorozza őket; a `vmax` és a `vmin` pedig minden komponensből a nagyobbat, illetve a kisebbet tartja meg. Mindegyikük egy kételemű tömböt ad vissza:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
