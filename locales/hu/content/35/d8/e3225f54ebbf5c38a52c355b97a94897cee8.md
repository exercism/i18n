# Bevezetés

Ez a feladat a metódusparaméterek néhány részletét és azok C#-ban való használatát tárgyalja.

A paraméterek információt közvetítenek a hívó metódustól a hívott metódus felé.

- A paraméterek viselkedését módosítók, például a `ref` és az `out` használatával lehet megváltoztatni.

- Az `out` módosítóval ellátott paraméter értéket ad vissza a hívott metódusból a hívónak. A paraméter átadható a hívott metódusnak anélkül, hogy kezdőértéket kapott volna, és a hívott metóduson belül mindenképpen úgy kezelik, mintha belépéskor még nem lett volna kezdőértéke. A paramétermódosítók viselkedését és szabályait a legkönnyebben példákon keresztül (lásd alább) és a fordító üzeneteiből értheted meg.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Az `out` paramétereknek a hívott metóduson belül értéket kell kapniuk.

- A `ref` módosítóval ellátott paraméter értéket ad át a hívott metódusnak. Amikor a metódus visszatér, a hívó abban a paraméterben látja a hívott metódus által végrehajtott módosításokat.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- A `ref` paramétereknek változóknak kell lenniük, mivel a hívott metódus közvetlenül azon a paraméteren dolgozik, ahogyan a hívó látja.
- Az `out` és a `ref` módosítóra egyaránt szükség van a hívott metódus szignatúrájában és a hívás helyén is.
