# Ternáris operátor

A ternáris operátor alternatív szintaxist kínál arra, hogy `if..else..` összehasonlítást végezz, és értéket adj vissza.

## Szintaxis

A PHP biztosít egy elágazást, amellyel egy művelet kiértékelhető a feltétel igazságtartalma alapján.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Ugyanezt a műveletet a ternáris operátorral is kifejezheted:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

Az összehasonlítás szintaxisa rövid, jelölése: `(condition) ? (evaluate if true) : (evaluate if false);`.
