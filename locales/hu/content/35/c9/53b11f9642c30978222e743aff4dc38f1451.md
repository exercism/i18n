# Utasítások

A feladatod, hogy RNS-szekvenciákat fehérjékké fordíts.

Az RNS-szálak három nukleotidból álló szekvenciákból, úgynevezett **kodonokból** állnak.
Minden kodon egy **aminosavnak** felel meg.
Ha ezek az aminosavak összekapcsolódnak, fehérjét alkotnak.

A való világban 64 kodon létezik, amelyek 20 aminosavnak felelnek meg.
Ebben a feladatban azonban a lehetséges 64 közül csak néhányat fogsz használni.
Ezeket az alábbi táblázat sorolja fel:

| Kodon              | Aminosav      |
| ------------------ | ------------- |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Például az „AUGUUUUCU” RNS-szekvencia három kodonból áll: „AUG”, „UUU” és „UCU”.
Ezek a Methionine, Phenylalanine és Serine aminosavaknak felelnek meg.

## A „STOP” kodonok

A fenti táblázatban észreveheted, hogy három **„STOP” kodon** van.
Ha ilyen kodonba ütközöl, hagyd figyelmen kívül a szekvencia hátralévő részét: a fehérje elkészült.

Például az „AUGUUUUCUUAAAUG” tartalmaz egy „STOP” kodont („UAA”).
Amint elérünk ehhez a ponthoz, leállunk a feldolgozással.
Ezért csak az előtte lévő részt vesszük figyelembe (azaz „AUGUUUUCU”), és nem a utána következő kodonokat (azaz „AUG”).

Tudj meg többet a [fehérjetranszlációról a Wikipédián][protein-translation].
