# Bevezetés

A [`Basics`][basics] fogalom két módját mutatta be annak, hogyan definiálhatsz függvényt.

A legáltalánosabb esetben a többsoros forma:

```julia
function muladd(x, y, z)
    x * y + z
end
```

Rövid definíciókhoz az „értékadó”, avagy „egysoros” forma:
```julia
muladd(x, y, z) = x * y + z
```

Egy harmadik, még rövidebb formában egy rövid, egyszer használatos függvényt név nélkül is létrehozhatsz:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

Ebben az esetben az `x -> 2x` egy „névtelen függvény”.
Ez ugyanaz, amit más nyelvek „lambda-függvénynek” neveznek.

Figyeld meg, hogy több argumentumnál zárójelre van szükség, mint a `(x, y) -> x * y` esetében.

A névtelen függvények gyakoriak a Julia-kódban, különösen magasabb rendű függvényekkel, például a `map()` és `filter()` függvénnyel együtt használva (ezekről egy későbbi fogalomban részletesebben is szó lesz).

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## Függvényargumentumok

A tantervben eddig csak olyan függvényekkel találkoztunk, amelyeknek pontosan meghatározott számú argumentuma van, és a hívásnak mindegyiket meg kell adnia, a helyes sorrendben.
Ez meglehetősen korlátozó és kényelmetlen lenne, ezért több más lehetőség is létezik.

### Opcionális argumentumok

Sok nyelvhez hasonlóan a Julia is lehetővé teszi, hogy egy függvénydefinícióban az egyes argumentumoknak alapértelmezett értéket adj meg.

A függvényhívás ezután vagy megad egy értéket az adott argumentumnak, vagy elhagyja, és az alapértelmezett értékre támaszkodik.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

Minden alapértelmezés _nélküli_ argumentumnak meg kell előznie az alapértelmezéssel _rendelkező_ argumentumokat, ami azt jelenti, hogy az `f(x=2, y)` érvénytelen lenne.

### Kulcsszóargumentumok

Az eddigi példák mind `positional arguments` formát használnak, ahol a függvényhívásban megadott értékek sorrendjének meg kell egyeznie a függvénydefinícióban szereplő megfelelő argumentumok sorrendjével.

Sok nyelvhez hasonlóan a Julia is engedélyezi a `keyword arguments` használatát.
A függvényhívásban meg kell adni az argumentum nevét, de több kulcsszóargumentum ezután tetszőleges sorrendben megadható.

A Julia sajátos vonása, hogy a függvénydefinícióban a kulcsszóargumentumokat (ha vannak) egy `;` pontosvesszőnek kell megelőznie, hogy elválassza őket a pozicionális argumentumoktól.
Egy függvényhívásban az utolsó pozicionális argumentum és az első kulcsszóargumentum között a `;` és a `,` közül bármelyik használható.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

Az alapértelmezett értékek opcionálisan megadhatók, pontosan úgy, mint a pozicionális argumentumoknál.

Gyakori, hogy egy függvényhívásban `myarg=myarg` alakú szintaxishoz jutsz, amikor egy, a paraméterrel azonos nevű változót már előre kiszámoltál.
Ebben a helyzetben megengedett egy rövidített szintaxis:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat és slurp

Ezek a szokásos nevei a Julia szintaxis egy hasznos részének, ha esetleg tűnődtél volna rajta.
Mindkettő a `...` operátorra utal.

#### Splat

A splattinget függvény_hívásokban_ használjuk, hogy egy gyűjteményt a függvény által igényelt egyedi értékekké bontsunk szét.

Ezt talán könnyebb bemutatni, mint elmagyarázni:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

Néhány „függvényhívást” szintaktikai cukorka rejt el, így a splatting kevésbé nyilvánvaló módokon is használható.

Például a többszörös értékadás a háttérben egy tuple konstruktor függvényt használ:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

A kulcsszóargumentumok splattinggel is megadhatók, jellemzően egy `named tuple` használatával.
Egy `Dict` is működik, de a kulcsoknak symbolnak kell lenniük (a stringek nem működnek).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

A slurpinget a függvény_definícióban_ használjuk, hogy tetszőleges számú egyedi értéket egy gyűjteménybe csomagoljunk.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

A slurpölt argumentum neve (jelen esetben `more`) nem számít.
Ennek a változónak a típusát a fordító választja meg, de pozicionális argumentumok esetén valószínűleg `tuple` vagy valami hasonló lesz.

A kulcsszóargumentumok is slurpölhetők, ami egy `Dict`-et (vagy hasonlót) eredményez.

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

A hívásban bármilyen kulcsszóargumentum használható.
A függvénydefiníció dönti el, hogy mely kulcsszavakra reagál, és melyeket hagy figyelmen kívül.
