# Bevezetés

A lebegőpontos számok olyan számok, amelyeknél a tizedeselválasztó után egy vagy több számjegy áll. A 64 bites dupla pontosságú lebegőpontos formátumot használják.

```elixir
float = 3.45
# => 3.45
```

## Számokkal való munka

Az [`Integer`][integer-functions] és a [`Float`][float-functions] modulban néhány hasznos függvényt találsz, amelyekkel ezekkel a típusokkal dolgozhatsz. Az alapvető aritmetikai operátorok a [`Kernel`][kernel-arithmetic-operators] modulban vannak definiálva.

## Átalakítás

Egy aritmetikai kifejezésben egész és lebegőpontos számok is szerepelhetnek egymás mellett. Ha egy kifejezésben lebegőpontos szám szerepel, az eredmény is biztosan lebegőpontos lesz.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Osztásnál viszont az eredmény mindig lebegőpontos lesz, akkor is, ha csak egész számokat használsz.

```elixir
6 / 2
# => 3.0
```

Ha egy lebegőpontos számot egésszé szeretnél alakítani, a tizedes részt a [`trunc/1`][trunc-1] függvénnyel dobhatod el.
