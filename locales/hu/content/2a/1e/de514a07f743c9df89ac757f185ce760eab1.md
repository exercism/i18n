# Részletesen

Az operációs rendszer állapotát tároló erőforrásokat (fájlleírók, socketek, zárolások) *garantáltan* fel kell szabadítani, még akkor is, ha egy kivétel kibontja a vermet. A Factor [`destructors`][destructors] szókészlete egy kis keretrendszert ad ehhez, és a legtöbb beépített erőforrás (`<file-reader>`, `<file-writer>`, socketek, …) már illeszkedik is hozzá.

## Az osztály és a generikus szó

Egy osztály úgy csatlakozik, hogy kiterjeszti a `disposable` osztályt, és megvalósítja a `dispose*` szót:

```factor
TUPLE: my-handle < disposable underlying ;

: <my-handle> ( underlying -- handle )
    my-handle new-disposable swap >>underlying ;

M: my-handle dispose* underlying>> dispose ;
```

A `new-disposable ( class -- obj )` lefoglalja a tuple-t, *és* regisztrálja is az aktuális destruktor-scope-ban, így a foglalás és a következő biztonságos pont között fellépő kivétel nem tudja kiszivárogtatni az erőforrást. A keretrendszer garantálja, hogy a `dispose*` objektumonként **legfeljebb egyszer** fut le, az ismételt `dispose` hívások nem csinálnak semmit.

## A nyilvános hívók a `dispose` szót használják

| szó               | hatás                                         |
|-------------------|-----------------------------------------------|
| `dispose`         | `( obj -- )`: felszabadítja; kétszer is biztonságos hívni |
| `with-disposal`   | `( disposable quot -- )`: egy erőforrást scope-ba von |
| `with-destructors`| `( quot -- )`: megnyit egy regisztrációs scope-ot |
| `&dispose`        | `( obj -- obj )`: normál *vagy* hibás kilépéskor is felszabadít |
| `|dispose`        | `( obj -- obj )`: csak akkor szabadít fel, ha a scope kibomlik |

A `with-disposal` az egyetlen erőforrást kezelő forma. Ha egynél több erőforrásod van, nyiss egy `with-destructors` scope-ot, és minden megszerzett erőforrást regisztrálj `&dispose`-szal (mindig fel akarod szabadítani), vagy `|dispose`-szal (csak hiba esetén szabadít fel, a sikeres ág megtartja).

```factor
[
    "in.txt"  utf8 <file-reader> &dispose
    "out.txt" utf8 <file-writer> &dispose
    [ read1 ] [ write1 ] bi
] with-destructors
```

## A `cleanup` az alapvető primitív

Ha egyszeri try/finally-ra van szükséged regisztráció nélkül, a [`cleanup`][cleanup] (a `continuations` szókészletből) az alacsonyabb szintű szó:

```
cleanup ( try cleanup-always cleanup-error -- )
```

A `with-destructors` szigorúan nagyobb tudású (a regisztrációs lista futásidőben is bővülhet), a `cleanup` viszont természetes választás, amikor a megszerzés és a felszabadítás párosítása kötött és helyi.
