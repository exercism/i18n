# Bevezetés

## Összehasonlítások

A Python a következő alapvető összehasonlító operátorokat támogatja:

| Operátor | Művelet                  | Leírás                                                               |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | „nagyobb, mint”             | az `a > b` akkor `True`, ha `a` értéke **szigorúan** nagyobb, mint `b` értéke        |
| `<`      | „kisebb, mint”                | az `a < b` akkor `True`, ha `a` értéke **szigorúan** kisebb, mint `b` értéke           |
| `==`     | „egyenlő”                 | az `a == b` akkor `True`, ha `a` értéke **szigorúan** egyenlő `b` értékével           |
| `>=`     | „nagyobb vagy egyenlő” | az `a >= b` akkor `True`, ha érték szerint `a > b` VAGY `a == b`                        |
| `<=`     | „kisebb vagy egyenlő”    | az `a <= b` akkor `True`, ha érték szerint `a < b` vagy `a == b`                        |
| `!=`     | „nem egyenlő”                 | az `a != b` akkor `True`, ha az `a == b` értéke `False`                                 |
| `is`     | „azonosság”                 | az `a is b` **_akkor és csak akkor_** `True`, ha `a` és `b` ugyanaz az _objektum_ |
| `is not` | „tagadott azonosság”         | az `a is not b` akkor `True`, ha `a` és `b` **nem** ugyanaz az _objektum_       |
| `in`     | „tartalmazásvizsgálat”         | az `a in b` akkor `True`, ha `a` tagja, részhalmaza vagy eleme `b`-nek            |
| `not in` | „tagadott tartalmazásvizsgálat” | az `a not in b` akkor `True`, ha `a` nem tagja, részhalmaza vagy eleme `b`-nek  |

Mindegyikük prioritása ugyanaz (_ez magasabb, mint a [Boolean-műveletek][boolean operations] prioritása, de alacsonyabb az aritmetikai vagy bitenkénti műveletek prioritásánál_).

## Összehasonlítás különböző adattípusok között

A különböző típusú objektumok (_a numerikus típusok kivételével_) alapértelmezés szerint soha nem számítanak egyenlőnek.
Egy `class` nem azonos példányai szintén _**nem**_ számítanak egyenlőnek, kivéve, ha a `class` olyan speciális [rich comparison][rich comparisons] metódusokat definiál, amelyek testre szabják az `object` alapértelmezett összehasonlítási viselkedését.
A `rich comparisons` használatával történő testreszabást egy későbbi feladatban tárgyaljuk.
Ha (sokkal) részletesebben szeretnél olvasni erről a témáról, nézd meg az [értékek összehasonlítása][value comparisons] részt a Python dokumentációjában.

A numerikus típusok (többnyire) kivételt képeznek ez alól a típusegyezési szabály alól.
Egy `integer` **egyenlőnek tekinthető** egy `float`-tal (_vagy egy [`octal`][octal] egyenlő egy [`hexadecimal`][hex] értékkel_), amennyiben a típusok az összehasonlításhoz implicit módon átalakíthatók.

A Python szabványos könyvtárában található többi numerikus típus ([complex][complex numbers], [decimal][decimal numbers], [fractions][rational numbers]) esetében az összehasonlító operátorok ott vannak definiálva, ahol „van értelmük” (_vagyis ahol az implicit átalakítás nem változtatja meg az eredményt_), de `TypeError`-t dobnak, ha a mögöttes objektumok nem alakíthatók át pontosan az összehasonlításhoz.
Ha többet szeretnél megtudni azokról a szabályokról, amelyeket a Python a _numerikus átalakításnál_ használ, nézd meg az [aritmetikai átalakítások][arithmetic conversions] részt a Python dokumentációjában.

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

Egy szám bármely rendezett összehasonlítása egy `NaN` (_not a number_) típussal `False`.
A Python `NaN` definíciójának zavaró mellékhatása, hogy a `NaN` soha nem számít egyenlőnek a `NaN`-nal.

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## Stringek összehasonlítása

A számokkal ellentétben a stringek (`str`) összehasonlítása [_lexikografikusan_][lexographic order] történik, az egyes Unicode-kódpontjaik alapján (_amit úgy kapunk meg, hogy a `str` minden kódpontját átadjuk a beépített [`ord()`][ord] függvénynek, amely egy `int` értéket ad vissza_).
Ha mindkét string minden kódpontja megegyezik, és _**ugyanabban a sorrendben**_ szerepel, a két string egyenlőnek számít.
Ez az összehasonlítás „páronkénti” módon történik: elsőt az elsővel, másodikat a másodikkal, és így tovább.
A Python 3.x-ben a `str` és a `bytes` nem alakítható át és nem hasonlítható össze közvetlenül.

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## Az összehasonlítások láncolása

Az összehasonlító operátorok _tetszőlegesen_ láncolhatók, ami azt jelenti, hogy bármilyen hosszúságú, bármilyen kombinációban használhatók.
Fontos, hogy egy kifejezés kiértékelése `left`-től `right`-ig halad.

Például az `x < y <= z` egyenértékű az `x < y` `and` `y <= z` kifejezéssel, azzal a kivétellel, hogy `y` kiértékelése **csak egyszer** történik meg.
Mindkét esetben `z` kiértékelése **egyáltalán nem** történik meg, ha az `x < y` értéke `False`.
Ezt gyakran `short-circuit evaluation`-nek nevezik: a kiértékelés leáll, ha a kifejezés igazságértéke már meghatározható.

A `Short circuiting`-et többféle Boolean operátor és függvény is támogatja, és a Pythonban az összehasonlítások láncolása is.
Sok más programozási nyelvvel ellentétben, köztük a `C`, a `C++`, a `C#` és a `Java` nyelvvel, a Pythonban az olyan láncolt kifejezések, mint az `a < b < c`, hagyományos [matematikai értelmezéssel][three way boolean comparison] és precedenciával rendelkeznek.

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## Objektumazonosság összehasonlítása

Az `is` és az `is not` operátor az objektum [_azonosságát_][object identity] vizsgálja, szemben az objektum _értékével_.
Egy objektum azonossága létrehozása után soha nem változik, és a [`id()`][id function] függvénnyel deríthető ki.

A `<apple> is <orange>` **_akkor és csak akkor_** értékelődik ki `True`-ra, ha `id(<apple>)` == `id(<orange>)`.
A `<apple> is not <orange>` ennek az ellenkezőjét adja.

Mivel ezek singleton értékek, a `None` és a `NotImplemented` összehasonlítását mindig az `is` és az `is not` operátorral érdemes végezni.
A részletekért erről a konvencióról lásd a Python referenciadokumentációját az [értékek összehasonlításáról][value comparisons none], valamint a [PEP8][pep8 programming recommendations] útmutatót.

```python
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## Tagsági vizsgálatok

Az `in` és a `not in` operátor a _tagságot_ vizsgálja.
A `<fish> in <soup>` akkor értékelődik ki `True`-ra, ha `<fish>` tagja a `<soup>`-nak (_azaz ha `<fish>` részhalmaza a `<soup>`-nak, vagy benne van a `<soup>`-ban_), egyébként pedig `False`.
A `<fish> not in <soup>` a tagadását, vagyis a `<fish> in <soup>` _ellentétét_ adja eredményül.

String- és bytes-típusok esetén a `<name> in <fullname>` **_akkor és csak akkor_** `True`, ha `<name>` részstringje a `<fullname>`-nek.

```python
# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 
                'id': 67826, 'age': 33, 
                'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
