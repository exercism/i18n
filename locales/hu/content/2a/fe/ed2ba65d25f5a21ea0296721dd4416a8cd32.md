# Tippek

## 1. Alakítsd át a bináris ábrázolást egész számmá

- Van egy [beépített metódus][string-to_i], amivel egy bináris ábrázolású stringet egész számmá alakíthatsz a számrendszer megadásával.

## 2. Szerezd meg az egész szám legkisebb helyiértékű bitjét

- Van egy [beépített metódus][integer-bit], amivel egy egész számból kiolvashatsz egy bitet az index megadásával.
- A legkisebb helyiértékű bit a legjobbra eső bit.
  Ez a 0. indexen található.

## 3. Szerezd meg a hexadecimális értéket egy színcsatornából

- Van egy [beépített metódus][integer-to_s], amivel egy egész számot hexadecimális ábrázolású stringgé alakíthatsz a számrendszer megadásával.
- A metódus fogadhat egy opcionális argumentumot, amellyel megadhatod a generált számjegyek számának pontosságát.

## 4. Szerezd meg a hexadecimális értéket RGB-ből

- A hexadecimális értéket a már definiált metódusokkal is megkaphatod egy színcsatornából.
