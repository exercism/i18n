# Bevezetés

A Pythonban két ciklusszerkezet létezik.
A `while` ciklus a _határozatlan_ (meg nem számlált) iterációhoz, a `for` ciklus pedig a _határozott_, (megszámlált) iterációhoz használatos.
A `break`, a `continue` és az `else` kulcsszavak segítenek testre szabni a ciklus viselkedését.
A `range()` és az `enumerate()` segít a ciklusszámlálásban és az indexelésben.


## While

A [`while`][while statement] ciklus mindaddig folytatja a végrehajtást, amíg a `loop expression` vagy „teszt” `True` értéket nem ad egy [`boolean context`][truth value testing] esetén, és akkor áll le, amikor `False` lesz:

```python

# Lists are considered "truthy" in a boolean context if they
# contain one or more values, and "falsy" if they are empty.

>>> placeholders = ["spam", "ham", "eggs", "green_spam", "green_ham", "green_eggs"]

>>> while placeholders:
...     print(placeholders.pop(0))
...
'spam'
'ham'
'eggs'
'green_spam'
'green_ham'
'green_eggs'
```


## For

A Python alapvető [`for`][for statement] `loop`-ja jobban leírható _`for each`_ ciklusként: végigmegy bármely [iterable object][iterable] értékein, és akkor áll le, amikor a [`next()`][next built-in] hívása már nem ad vissza több értéket:

```python

>>> word_list = ["bird", "chicken", "barrel", "bongo"]

>>> for word in word_list:
...    if word.startswith("b"):
...        print(f"{word.title()} starts with a B.")
...    else:
...        print(f"{word.title()} doesn't start with a B.")
...
'Bird starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel starts with a B.'
'Bongo starts with a B.'
```


## Sequence Object range()

Amikor nincs megadva konkrét `iterable`, a speciális [`range()`][range] sorozatot használjuk ciklusszámlálóként.
A `range()`-nek meg kell adni egy `int` értéket, amelynél a sorozat `stop`-ol, emellett opcionálisan `start` és `step` paramétereket is fogadhat.
Ha nincs megadva `start` szám, a sorozat 0-tól kezdődik.
A `range()` objektumok **lazák** (_az értékek csak kérésre generálódnak_), támogatják az összes [common sequence operations][common sequence operations] műveletet, és fix mennyiségű memóriát foglalnak, függetlenül a megadott sorozat hosszától.

```python
# Here we use range to produce some numbers, rather than creating a list of them in memory.
# The values will start with 1 and stop *before* 7

>>> for number in range(1, 7):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
'1 is odd.'
'2 is even.'
'3 is odd.'
'4 is even.'
'5 is odd.'
'6 is even.'

# range() can also take a *step* parameter.
# Here we use range to produce only the "odd" numbers, starting with 3 and stopping *before* 15.

>>> for number in range(3, 15, 2):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
...
'3 is odd.'
'5 is odd.'
'7 is odd.'
'9 is odd.'
'11 is odd.'
'13 is odd.'
```


## Values and Indexes with enumerate()

Ha az értékekre és az indexeikre is szükség van, a beépített [`enumerate(<iterable>)`][enumerate] (`index`, `value`) párokat ad vissza:

```python

>>> word_list = ["bird", "chicken", "barrel", "apple"]

# *index* and *word* are the loop variables.
# Loop variables can be any valid python name.

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    else:
...        print(f"{word.title()} (at index {index}) doesn't start with a B.")
...
'Bird (at index 0) starts with a B.'
'Chicken (at index 1) doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Apple (at index 3) doesn\'t start with a B.'


# The same method can be used as a "lookup" for pairing items between two lists.
# Of course, if the lengths or indexes don't line up, this doesn't work.

>>> word_list = ["cat", "chicken", "barrel", "apple", "spinach"]
>>> category_list = ["mammal", "bird", "thing", "fruit", "vegetable"]

>>> for index, word in enumerate(word_list):
...    print(f"{word.title()} is in category: {category_list[index]}.")
...
'Cat is in category: mammal.'
'Chicken is in category: bird.'
'Barrel is in category: thing.'
'Apple is in category: fruit.'
'Spinach is in category: vegetable.'
```


## Altering Loop Behavior

A [`continue`][continue statement] kulcsszóval előre lehet ugrani a következő iterációra:

```python
word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple", "bear"]

# This will skip *bird*, at index 0
for index, word in enumerate(word_list):
    if index == 0:
        continue
    if word.startswith("b"):
        print(f"{word.title()} (at index {index}) starts with a b.")

'Barrel (at index 2) starts with a b.'
'Bongo (at index 3) starts with a b.'
'Bear (at index 6) starts with a b.'
```


A [`break`][break statement] (_ahogy sok C-vel rokon nyelvben_) kulcsszóval leállítható az iteráció, és „ki lehet törni” a legbelső `loop`-ból:

```python
>>>  word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    elif word == "sliver":
...       break
...    else:
...       print(f"{word.title()} doesn't start with a B.")
... print("loop broken.")
...
'Bird (at index 0) starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'loop broken.'
```
