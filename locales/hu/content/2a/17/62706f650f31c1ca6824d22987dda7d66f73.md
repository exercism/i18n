# Bevezetés

## Charlistek

A charlisteket a `~c` sigillel hozod létre.

```elixir
~c"hello"
```

~~~~exercism/note
Figyelj rá, hogy az Elixir régebbi verzióiban a charlisteket `'hello'` formában, aposztrófokkal jelölik.
~~~~

Bár nagyon hasonlítanak a stringekhez, a két adattípus jelentősen különbözik egymástól. A charlist egész számok listája. Az egész számok egy adott karakter Unicode-értékét reprezentálják, amit kódpontnak is neveznek.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Ha egy karakter elé `?`-t teszel, megkapod a kódpontját.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Mivel a charlistek listák, ugyanúgy dolgozhatsz velük, mint bármely más listával: rekurzióval és mintaillesztéssel.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Két listát a `++` operátorral fűzhetsz össze.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Minél hosszabb az első lista, annál lassabb az összefűzés, ezért kerüld, hogy ismételten hozzáfűzz tetszőleges hosszúságú listákhoz.

## Case

A `case` egy vezérlési szerkezet, amellyel egy adott értéket több mintával is összehasonlíthatsz. A `case` kifejezés klauzuláit felülről lefelé haladva értékeli ki, amíg egyezést nem talál.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
