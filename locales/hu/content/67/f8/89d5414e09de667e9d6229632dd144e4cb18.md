# Részletesen

Egészeken a [Bitwise modul][bitwise-hexdocs] függvényeivel [bitenkénti bináris műveleteket][bitwise-wiki] hajthatsz végre.

- [`band/2`][bitwise-and]: bitenkénti ÉS
- [`bsl/2`][bitwise-shift-left]: bitenkénti BALRA TOLÁS
- [`bsr/2`][bitwise-shift-right]: bitenkénti JOBBRA TOLÁS
- [`bxor/2`][bitwise-xor]: bitenkénti KIZÁRÓ VAGY
- [`bor/2`][bitwise-or]: bitenkénti VAGY
- [`bnot/1`][bitwise-not]: bitenkénti NEM

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
