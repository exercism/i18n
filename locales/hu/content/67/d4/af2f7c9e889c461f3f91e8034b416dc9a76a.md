# Bevezetés

A struktúra- és osztálytagok számos típusa (a fő kivétel a mezők) használhatja a kifejezéstörzsű tagok szintaxisát. Egy tag kifejezéssel való definiálása gyakran tömörebb és olvashatóbb kódot eredményez, mint a hagyományos blokkok és utasítások.

A metódusok és a csak olvasható tulajdonságok is azon tagok közé tartoznak, amelyek kifejezéstörzzsel definiálhatók.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
