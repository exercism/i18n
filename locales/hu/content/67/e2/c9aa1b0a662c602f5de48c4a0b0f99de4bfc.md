# Bevezetés

A `rune` típus a Go-ban az `int32` álneve.
Mivel a mögöttes típusa `int32`, a `rune` típus egy előjeles 32 bites egész értéket tárol.
Az `int32` típustól eltérően azonban a `rune` típusban tárolt egész érték egyetlen Unicode-karaktert ábrázol.

## A Unicode és a Unicode-kódpontok

A Unicode az ASCII-t is magában foglalja, és úgy ábrázolja a karaktereket, hogy minden karakterhez egyedi számot rendel.
Ezt az egyedi számot Unicode-kódpontnak nevezzük.
A Unicode célja, hogy a világ összes karakterét Unicode-kódpontként ábrázolja, beleértve a különféle ábécéket, számokat, szimbólumokat és még az emojikat is.

A Go-ban a `rune` típus egyetlen Unicode-kódpontot ábrázol.

Az alábbi táblázat példákat mutat Unicode-karakterekre a Unicode-kódpontjukkal és a decimális értékükkel együtt:

| Unicode-karakter | Unicode-kódpont | Decimális érték |
|-------------------|--------------------|---------------|
| 0                 | `U+0030`           | `48`          |
| A                 | `U+0041`           | `65`          |
| a                 | `U+0061`           | `97`          |
| ¿                 | `U+00BF`           | `191`         |
| π                 | `U+03C0`           | `960`         |
| 🧠                | `U+1F9E0`          | `129504`      |

## UTF-8

A UTF-8 egy változó hosszúságú karakterkódolás, amely minden Unicode-kódpontot 1, 2, 3 vagy 4 bájtként kódol.
Mivel egy Unicode-kódpont legfeljebb 4 bájtként kódolható, a `rune` típusnak képesnek kell lennie legfeljebb 4 bájt adat tárolására.
Ezért a `rune` típus az `int32` álneve, hiszen az `int32` típus legfeljebb 4 bájt adatot képes tárolni.

A Go forráskódfájljai UTF-8-cal vannak kódolva.

## A rune-ok használata

A `rune` típusú változókat úgy deklarálod, hogy egy karaktert egyszeres idézőjelek közé teszel:

```go
myRune := '¿'
```

Mivel a `rune` csupán az `int32` álneve, ha kiírod egy rune típusát, `int32`-t kapsz:

```go
myRune := '¿'
fmt.Printf("myRune type: %T\n", myRune)
// Output: myRune type: int32
```

Hasonlóképpen, ha kiírod egy rune értékét, annak egész (decimális) értékét kapod:

```go
myRune := '¿'
fmt.Printf("myRune value: %v\n", myRune)
// Output: myRune value: 191
```

A rune által ábrázolt Unicode-karakter kiíratásához a `%c` formázási direktívát használd:

```go
myRune := '¿'
fmt.Printf("myRune Unicode character: %c\n", myRune)
// Output: myRune Unicode character: ¿
```

A rune által ábrázolt Unicode-kódpont kiíratásához a `%U` formázási direktívát használd:

```go
myRune := '¿'
fmt.Printf("myRune Unicode code point: %U\n", myRune)
// Output: myRune Unicode code point: U+00BF
```

## A rune-ok és a stringek

A Go-ban a stringek UTF-8-cal vannak kódolva, ami azt jelenti, hogy Unicode-karaktereket tartalmaznak.
A stringekben a karakterek 1, 2, 3 vagy 4 bájtként tárolódnak és kódolódnak, attól függően, hogy milyen Unicode-karaktert ábrázolnak.

A Go-ban a szeletek sorozatok ábrázolására szolgálnak, és ezeken a szeleteken a range segítségével lehet végigiterálni.
Amikor végigiterálunk egy stringen, a Go a stringet rune-ok sorozatává alakítja, amelyek mindegyike 4 bájt (ne feledd, a rune típus az `int32` álneve!)

Bár egy string csupán bájtok szelete, a `range` kulcsszó egy string rune-jai felett iterál, nem a bájtjai felett.

Ebben a példában az `index` változó az aktuális rune bájtsorozatának kezdőindexét, a `char` változó pedig magát az aktuális rune-ot ábrázolja:

```go
myString := "❗hello"
for index, char := range myString {
  fmt.Printf("Index: %d\tCharacter: %c\t\tCode Point: %U\n", index, char, char)
}
// Output:
// Index: 0	Character: ❗		Code Point: U+2757
// Index: 3	Character: h		Code Point: U+0068
// Index: 4	Character: e		Code Point: U+0065
// Index: 5	Character: l		Code Point: U+006C
// Index: 6	Character: l		Code Point: U+006C
// Index: 7	Character: o		Code Point: U+006F
```

Mivel a rune-ok 1, 2, 3 vagy 4 bájtként tárolhatók, egy string hossza nem mindig egyezik meg a benne lévő karakterek számával.
A beépített `len` függvénnyel egy string bájtban mért hosszát kapod meg, a `utf8.RuneCountInString` függvénnyel pedig egy string rune-jainak számát:

```go
import "unicode/utf8"

myString := "❗hello"
stringLength := len(myString)
numberOfRunes := utf8.RuneCountInString(myString)

fmt.Printf("myString - Length: %d - Runes: %d\n", stringLength, numberOfRunes)
// Output: myString - Length: 8 - Runes: 6
```
