# Névjegy

Az Elm egy teljesen funkcionális nyelv, ezért nincsenek utasítások, csak kifejezések, a függvények pedig mindig egyetlen kifejezésből állnak.

Ez a kicsi, egyszerű függvényeket ösztönzi, ami általában véve jó dolog, de néha a függvények elkerülhetetlenül bonyolultabbak lesznek, és kell egy mód arra, hogy az ilyen függvényeket is elegánsan lehessen megírni.

Itt jönnek képbe a `let` kifejezések. Két részük van: egy `let` szakasz, ahol annyi definíciót hozhatsz létre, amennyire szükséged van, majd egy `in` szakasz, amely egyetlen kifejezés, és használhatja ezeket a definíciókat.

Számítástechnikai értelemben a `let` egy olyan scope-ot hoz létre, amely lokális az `in` szakaszban szereplő kifejezéshez.

A `let` kifejezés néhány helyzetben hasznos:

- Kifejezések egyszerűsítése
- Közbülső kifejezések eredményeinek elnevezése
- Egy nagyra növő kifejezés kisebb darabokra bontása

A `let` kifejezésen belül a legtöbb dolgot megteheted, a destrukturálást is beleértve, az alábbiak azonban nem megengedettek:

- Custom Types
- Type Alias'
- Névárnyékolás (nem definiálhatsz újra / használhatsz fel újra egy olyan nevet, amely már benne van a scope-ban)

## Kifejezések egyszerűsítése

Ez a kifejezés három szám köbét adja össze, de nehezen olvasható, és könnyen megeshetne, hogy a számítás a különböző számoknál más-más lesz.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

Egy `let` kifejezésben definiálhatsz egy `cube` függvényt, amivel a számítás egyszerűbb, kifejezőbb és biztonságosabb lesz. Ez a függvény kaphatna típusannotációt is, de az idiomatikus Elm-kódban ez viszonylag ritka.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Közbülső kifejezések eredményeinek elnevezése

Ez a kód definiálja a sideArea és topArea értékeket, hogy a számítás egyszerűbb és kifejezőbb legyen.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Nagy kifejezés feldarabolása

Ez a kód egy kezdő mintát hoz létre a [Game of Life](https://playgameoflife.com/) játékhoz (egy gyakori programozási példafeladat).

Nem fontos pontosan értened, hogyan működik, de remélhetőleg nyilvánvaló, hogy nagyon nagy lenne, ha egyetlen kifejezésként írnánk meg, `let` nélkül.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
