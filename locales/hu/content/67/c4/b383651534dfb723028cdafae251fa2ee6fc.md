# Utasítások

Ismerd meg az ABAP belső tábláinak alapjait.

Az osztályodban van egy `initial_data` nevű belső tábla. Három oszlopa van: `GROUP`, `NUMBER` és `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## 1. lépés

Az első feladatod, hogy befejezd a `fill_itab` metódust, és 6 rekordot helyezz el a táblában a következő értékekkel:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## 2. lépés

Ezután valósítsd meg az `add_to_itab` metódust, hogy a belső tábla végére fűzz egy rekordot a következő értékkel:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## 3. lépés

Most rendezd a belső táblát a `sort_itab` metódusban úgy, hogy a `GROUP` oszlop ábécé sorrendben, a `NUMBER` oszlop pedig csökkenő sorrendben legyen.

## 4. lépés

A `search_itab` metódusban keresd meg a rendezett táblában azt a rekordot, amelynek a `NUMBER` oszlopában 6 áll, és add vissza az indexét.
