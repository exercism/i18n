# Tesztek

## Az összes teszt futtatása

A megoldásod tesztelésére egy `.rakutest` kiterjesztésű Raku szkript szolgál.
A teszteket a következő paranccsal futtathatod:

`prove6`

Mielőtt elkezdenéd a feladatot, a kimenet valószínűleg valahogy így fog kinézni:

```
# Failed test 'Say Hi!'
# at t/hello-world.rakutest line 6
# expected: "Hello, World!"
#  matcher: 'infix:<eq>'
#      got: "Goodbye, Mars!"
# You failed 1 test of 1
t/hello-world.rakutest ... Dubious, test returned 1
Failed 1/1 subtests
```

Módosítanod kell a `lib/` könyvtárban található `.rakumod` kiterjesztésű modult, és megoldást kell írnod, hogy átmenjenek a tesztek.
Amint a tesztek sikeresek, a fenti parancs kimenete valószínűleg valahogy így fog kinézni:

```
t/hello-world.rakutest ... ok
All tests successful.
```

## Leállás az első hiba után

Ha be van állítva a `RAKU_TEST_DIE_ON_FAIL` környezeti változó, a tesztfuttató az első hiba után leáll. Például:

Linuxon / OS X-en:

```bash
export RAKU_TEST_DIE_ON_FAIL=1
# now all the follow up runs will stop at the first failure
prove6
# until we do
unset RAKU_TEST_DIE_ON_FAIL
# or you can use it for one run like this:
RAKU_TEST_DIE_ON_FAIL=1 prove6
```

Vagy Windowson:

```
SET RAKU_TEST_DIE_ON_FAIL=1
REM now all the follow up runs will stop at the first failure
prove6
REM until we do
set RAKU_TEST_DIE_ON_FAIL=
```

További információért lásd a
[Raku dokumentáció tesztelésről szóló fejezetét](https://docs.raku.org/language/testing.html).

A modulok telepítéséről a [Raku dokumentáció modulokról szóló részében](https://docs.raku.org/language/modules#Looking_for_and_installing_modules.) olvashatsz.
