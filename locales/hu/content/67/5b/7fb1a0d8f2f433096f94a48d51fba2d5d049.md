# Debug

A YS rendelkezik egy beépített `DBG` függvénnyel, amely hasznos lehet a megoldásod debugolásához.
Tetszőleges számú argumentumot fogad, és ezeket a stderr-en keresztül a konzolra írja.
Az utolsó argumentumot adja vissza, így közvetlenül a kódodban is használhatod.


Használhatod a `.>` inline operátort is, amely a `.DBG()` rövidítése.

Íme egy példa kódfájl:

```yaml
# file: program.ys

!YS-v0

defn do-it(nums):
  x =: 5

  DBG: -'my vars' x nums

  nums: .map(\(_ * x)).>
        .reverse().>
        .map(str).>
        .join(' - ')

say: do-it(3 .. 5)
```

Amikor a `ys` paranccsal futtatod ezt a kódot, a következő kimenetet látod:

```txt
>>>
"my vars"
5
(3 4 5)
<<<
>>>(15 20 25)<<<
>>>(25 20 15)<<<
>>>("25" "20" "15")<<<
25 - 20 - 15
```


## Fordítás

Egy másik gyakori módja a probléma feltárásának, ha megnézed, milyen Clojure-kódra fordul le a YS-kódod.

Ezt úgy teheted meg, hogy a `ys` parancssori értelmezőt a `-c` kapcsolóval futtatod.

Így néz ki a fenti `program.ys` fájl lefordítva:

```clojure
$ ys -c program.ys
(defn do-it [nums]
 (let [x 5]
  (DBG "my vars" x nums)
  (join
   (DBG
    (+map
     (DBG (reverse (DBG (+map nums (fn [& [_1]] (mul+ _1 x))))))
     str))
   " - ")))
(say (do-it (rng 3 5)))
```

Jól látszik, hogyan fordult le a `.>` operátor a `DBG` függvényhívásra.
