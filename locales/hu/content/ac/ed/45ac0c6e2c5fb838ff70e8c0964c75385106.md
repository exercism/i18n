# Feladatok megoldása

Az Exercism elsősorban feladatok megoldásával segít neked a tanulásban.

Az Exercismen kétféleképpen oldhatsz meg feladatokat:

1. [Online, a weboldal böngészőben futó szerkesztőjével](/docs/using/solving-exercises/using-the-online-editor)
2. [A helyi gépeden a CLI segítségével](/docs/using/solving-exercises/working-locally)

## Melyik lehetőséget válasszam?

Az online szerkesztő és a CLI használata más-más előnnyel és hátránnyal jár:

|            | Online szerkesztő                     | CLI                                          |
| ---------- | -------------------------------------- | -------------------------------------------- |
| Telepítés  | Nem                                    | Igen (pl. SDK)                               |
| Szerkesztés | Böngésző                               | A kedvenc szerkesztőd                        |
| Tesztelés  | Tesztek futtatása a weboldalon         | Tesztek futtatása helyben                    |
| Hibakeresés | Korlátozott támogatás (csak néhány kurzushoz) | Teljes támogatás (a környezetedtől függően) |

Általában véve az online szerkesztő ideális új kurzusok elkezdéséhez, a CLI-alapú megközelítés viszont remek választás, ha a saját, személyre szabott programozási környezetedet szeretnéd használni.
