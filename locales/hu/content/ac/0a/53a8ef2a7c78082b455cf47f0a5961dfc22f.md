# Generátorok

A `generator` egy olyan függvény vagy kifejezés, amely egy különleges típusú [iterátort][iterator] ad vissza, amelyet [`generator iterator`][generator-iterator]-nak nevezünk.
A `Generator-iterator`-ok [lusta][lazy iterator] iterátorok: nem tárolják az `values`-üket a memóriában, hanem _generálják_ az értékeiket, amikor szükség van rájuk.

Egy generátorfüggvény úgy néz ki, mint bármelyik másik függvény, de tartalmaz egy vagy több [yield kifejezést][yield expression].
Minden `yield` felfüggeszti a kód végrehajtását, és elmenti az aktuális végrehajtási állapotot (_beleértve az összes lokális változót és a try-utasításokat_).
Amikor a generátor folytatódik, onnan veszi fel az állapotot, ahol felfüggesztődött, ellentétben a hagyományos függvényekkel, amelyek minden híváskor visszaállnak az elejére.


## Generátor létrehozása

A generátorokat nagyon hasonlóan hozzuk létre, mint a többi ciklusos vagy rekurzív függvényt, de szükség van hozzájuk egy [`yield` kifejezésre](#the-yield-expression), amelyet kicsit később részletesen meg is nézünk.

Példa erre egy olyan függvény, amely egy adott számlistából visszaadja a _négyzeteket_.
Ahogy most meg van írva, az összes bemenetet fel kell dolgozni, mielőtt bármilyen értéket vissza lehetne adni:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Ezt a függvényt így alakíthatod át generátorrá:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

Ennek az az értelme, hogy akkor használsz generátort, amikor nem kell az összes értéket _egyszerre_ előállítanod.
Ez memóriát és számítási kapacitást takarít meg, hiszen csak az az érték számítódik ki, amelyen _éppen dolgozol_.


## Generátor használata

A generátorok a Pythonban a legtöbb `iterables` helyett használhatók.
Ez magában foglalja azokat a _függvényeket_ vagy _objektumokat_, amelyek `iterable`/`iterator` argumentumot várnak.

A `squares_generator()` generátor használatához:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

A `generator` belsejében lévő értékeket a `next()` függvénnyel is előállíthatod, illetve elérheted.
A `next()` meghívja egy generátoriterátor-objektum `__next__()` metódusát, „előrehaladva” vagy kiértékelve a kódot egészen a `yield` kifejezéséig, amely aztán „kiszolgáltat”, azaz visszaad egy értéket:

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Amikor egy `generator-iterator`-t teljesen felhasználtál, és nincs több visszaadható értéke, akkor `StopIteration` hibát dob.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

A generátoriterátorok az [iterátorok][iterator] egy különleges részhalmazát alkotják.
Az `Iterators` az a mechanizmus/protokoll, amely lehetővé teszi az _iterables_ feletti végigiterálást.
A generátoriterátorok és a gyakori Python-[`iterables`][iterables] által visszaadott iterátorok nagyon hasonlóan viselkednek, de van néhány fontos különbség, amire érdemes figyelni:

- _[Lazán értékelődnek ki][lazy evaluation]_; az iteráció _egyirányú_, és nincs „visszalépés” egy korábbi értékre.
- A visszaadott értékeken végigiterálva _felhasználódnak_; nincs visszaállítás és nincs mentés a memóriában.
- Nem rendezhetők és nem fordíthatók meg.
- Nem sorozattípusok, és _nincs_ bennük `indexes`.
  Nem hivatkozhatsz egy korábbi vagy későbbi értékre összeadással vagy kivonással, és nem használhatod a szögletes zárójeles (`[]`) jelölést vagy a szeletelést.
- Nem használhatók a `len()` függvénnyel, mivel nincs hosszuk.
- Lehetnek _végesek_ vagy _végtelenek_; légy óvatos, amikor egy _végtelen_ `generator-iterator` összes értékét próbálod összegyűjteni!

## A yield kifejezés

A [yield kifejezés][yield expression] nagyon hasonlít a `return` kifejezéshez.
A `return` kifejezéssel _ellentétben_ a `yield` egy _adott ponton_ adja át az értékeket a hívónak, és felfüggeszti a további értékek kiértékelését/visszaadását egészen addig, amíg azokat nem kérik.
Amikor a `yield` kiértékelődik, szünetelteti a körülvevő függvény végrehajtását, és visszaadja a függvény értékeit _abban az adott pillanatban_.
A függvény ezután _scope-ban marad_, és amikor meghívják a `__next__()`-et, a végrehajtás folytatódik, amíg újra nem találkozik egy `yield`-del.


~~~~exercism/note
A `yield` kifejezések használata függvényeken kívül tilos.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## Miért hozzunk létre generátort?

A generátorok sok helyen hasznosak.

Amikor egy potenciálisan nagy értékgyűjteménnyel dolgozol, lehet, hogy nem akarod az összeset a memóriába tenni.
Egy generátorral darabonként dolgozhatsz fel nagyobb adathalmazokat, ami memóriát takarít meg és javítja a teljesítményt.

A generátorok akkor is nagyon hasznosak, ha egy folyamat vagy számítás _összetett_, _költséges_ vagy _végtelen_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Mostantól, valahányszor meghívják a `__next__()`-et az `infinite_sequence` objektumon, az a _korábbi szám_ + 1 értéket adja vissza.
