# Utasítások

Bob pénzügyi tanácsadó, és segít az embereknek kezelni a kiadásaikat.
Bob ügyfelei kiadási rekordokat küldenek neki, hogy elemezze azokat.
Bobnak vannak rekordjai a korábbi időszakokról, így látni tudja a kiadások változásait.
Bob nem szereti a naptárakat, és a dátumok helyett *Bob-korszakot* használ.
A Bob-korszak azon napok száma, amelyek Bob ügyfelének tevékenységének megkezdése óta elteltek.

Ebben a feladatban egy olyan programot építesz, amely segít Bobnak kezelni és elemezni az ügyfelei kiadásait.

Bob `Record` és `DaysPeriod` típusokkal dolgozik.

A `Record` egy kiadási rekordot reprezentál, amely tartalmazza a napot, amelyen a kiadás történt, az elköltött összeget és a kiadás kategóriáját.

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

A `DaysPeriod` egy napokból álló tartományt reprezentál, és tartalmazza az összes napot a `From` naptól egészen a `To` napig.
A tartomány mindkét végpontja benne van.

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. Általános rekordszűrő megvalósítása

Bob minden nap rengeteg rekorddal foglalkozik, de attól függően, hogy éppen milyen elemzést készít, nem mindegyikük érdekes.
Segítsünk Bobnak elvégezni a rekordok néhány alapvető szűrését.

Valósítsd meg az általános `Filter` függvényt, amely egy függvény által megadott feltétel szerint szűri a rekordokat.
Ez a szűrőfüggvény rekordok egy gyűjteményét és egy predikátumfüggvényt fogad, és csak azokat a rekordokat adja vissza a gyűjteményből, amelyek kielégítik a predikátumot.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. Rekordok szűrése egy adott időszakon belül

Bobnak gyakran kell szűrnie azokat a rekordokat, amelyek egy adott időszakon belül vannak.

Valósítsd meg a `ByDaysPeriod` függvényt, amely segít Bobnak ilyen szűrőket létrehozni.
Ez a függvény egy `DaysPeriod` értéket fogad, és visszaad egy függvényt, amely egy rekordot vesz át, és megmondja, hogy a rekord benne van-e abban az időszakban, amelyet az argumentumként megadott `DaysPeriod` határoz meg.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. Rekordok szűrése kategória szerint

Azon kívül, hogy időszak szerint szűri a rekordokat, Bobnak a kategóriájuk szerint is szűrnie kell a rekordokat.

Valósítsd meg a `ByCategory` függvényt, amely segít Bobnak ilyen szűrőket létrehozni.
Ez a függvény egy kategóriát fogad, és visszaad egy függvényt, amely egy rekordot vesz át, és megmondja, hogy a rekord kategóriája megegyezik-e az argumentumként megadott kategóriával.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. Egy időszak kiadásainak teljes összegének kiszámítása

Bob a kiadások teljes összegét is szeretné tudni egy adott időszakban.

Valósítsd meg a `TotalByPeriod` függvényt, amely visszaadja a kiadások összegét az adott napokból álló időszakban.

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. Egy kategória rekordjainak teljes kiadásának kiszámítása egy időszakban

A legösszetettebb, ügyfeleinek készített jelentésekhez Bobnak egyszerre kell a rekordokat kategória és időszak szerint szűrnie.
Ez azt jelenti, hogy Bob szeretné tudni az adott időszakban egy kategóriába tartozó rekordok teljes kiadását.

Valósítsd meg a `CategoryExpenses` függvényt, amely visszaadja egy kategória kiadásainak teljes összegét egy adott napokból álló időszakban.
A függvénynek meg kell különböztetnie azt az esetet, amikor az adott kategória egyáltalán nem szerepel a kiadási rekordokban, attól az esettől, amikor a megadott időszakban nincsenek kiadások ebben a kategóriában.
Ha a kategória egyetlen rekordnak sem a kategóriája (függetlenül az időszaktól), a függvénynek hibát kell visszaadnia.

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
