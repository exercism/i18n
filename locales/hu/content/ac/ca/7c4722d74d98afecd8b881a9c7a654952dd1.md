# Bevezetés

Amikor valamit önmaga segítségével definiálunk, azt rekurziónak nevezzük. A Gleamben a rekurzió leggyakrabban rekurzív függvényekben fordul elő, vagyis olyan függvényekben, amelyek önmagukat hívják meg.

Egy rekurzív függvényben legalább egy _alapeset_ és legalább egy _rekurzív eset_ kell legyen. Az _alapeset_ úgy ad vissza egy értéket, hogy nem hívja meg újra a függvényt. A _rekurzív eset_ újra meghívja a függvényt, és közben úgy módosítja a bemenetet, hogy az előbb-utóbb illeszkedjen az alapesetre.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

A Gleamben nincs külön szintaxis a ciklusokra, ezért minden ciklus rekurzióval valósul meg.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

A Gleam a rekurzív saját típusokat is támogatja. Egy rekurzív saját típusban a változatok közül egy vagy több a bennük tárolt adatban önmagára hivatkozik.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
