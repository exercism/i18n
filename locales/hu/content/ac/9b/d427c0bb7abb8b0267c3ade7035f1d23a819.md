# defmacro `_is` utótaggal és kérdőjellel

[comment]: # (- option2: the correct name for guards)

Az Elixirnek megvannak a maga elnevezési konvenciói, amelyek többek között azt is meghatározzák, hogyan nevezzük el azokat a [függvényeket, amelyek Boolean értéket adnak vissza](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo), illetve azokat az [ellenőrzéseket, amelyek Boolean értéket adnak vissza, és guard kifejezésekben is érvényesek](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> A Boolean értéket visszaadó függvények neve kérdőjellel végződik.

> A guard kifejezésekben engedélyezett típusellenőrzések és egyéb Boolean-ellenőrzések neve `is_` előtaggal kezdődik.

A makrók mindkét helyzetben használhatók, ezért a jelölés az esettől függ, a két elnevezési konvenciót viszont nem szabad összekeverni.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
