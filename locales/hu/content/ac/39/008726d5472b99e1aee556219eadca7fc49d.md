# Utasítások

Határozd meg, hogy egy háromszög egyenlő oldalú, egyenlő szárú vagy általános háromszög-e.

Az _egyenlő oldalú_ háromszög mindhárom oldala ugyanolyan hosszú.

Az _egyenlő szárú_ háromszögnek legalább két oldala ugyanolyan hosszú.
(Néha úgy határozzák meg, hogy pontosan két oldala ugyanolyan hosszú, de ebben a feladatban legalább kettőről beszélünk.)

Az _általános_ háromszög minden oldala különböző hosszú.

## Megjegyzés

Ahhoz, hogy egy alakzat egyáltalán háromszög legyen, minden oldalának hossza > 0 kell legyen, és bármely két oldal hosszának összege nagyobb vagy egyenlő kell legyen, mint a harmadik oldal hossza.

Egyenletekkel:

Legyenek `a`, `b` és `c` a háromszög oldalai.
Ekkor a következő három kifejezés mindegyike igaz kell legyen:

```text
a + b ≥ c
b + c ≥ a
a + c ≥ b
```
