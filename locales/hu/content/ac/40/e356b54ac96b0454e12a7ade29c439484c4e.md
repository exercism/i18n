# Utasítások

A barátod nemrég küldött neked egy üzenetet egy fontos titokkal.
Mivel nem akarta, hogy mások könnyen elolvashassák, az üzenetet egy sor bitmanipulációval titkosította.
Írnod kell egy programot, amely segít visszafejteni az üzenetet.

## 1. Told vissza a biteket

A visszafejtés első lépése, hogy a titkosítás során végzett eltolást visszavonjuk, mégpedig úgy, hogy a biteket visszatoljuk balra.
Az eltolás mértéke üzenetenként változhat.

Valósítsd meg a `Secrets.shift_back` metódust, amely egy értéket és a balra eltolás mértékét kapja.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Alkalmazz bitmaszkot

A következő lépés egy bitmaszk alkalmazása, amellyel bizonyos bitek értékét nyerhetjük ki.
A maszkot úgy alkalmazzuk, hogy bitenkénti AND műveletet végzünk az érték és a maszk között.

Valósítsd meg a `Secrets.apply_mask` metódust, amely egy értéket kap, és alkalmaz rá egy maszkot.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Állíts be néhány bitet

A bitek balra tolása néhány új 0 bitet hozott létre.
Ezek közül néhányat 1-re kell állítani.
A bitenkénti OR hasznos arra, hogy bizonyos biteket 1-re állítsunk, a többit pedig változatlanul hagyjuk.

Valósítsd meg a `Secrets.set_bits` metódust, amely két értéket kap, és bitenkénti OR műveletet végez rajtuk.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. Fordítsd vissza a XOR-t

A titkosítási folyamat részeként a rendszer egy megbeszélt értékkel végez XOR műveletet.
Hogy visszajuss az eredeti értékhez, a titkosított értéken egyszerűen újra el kell végezni a XOR műveletet ugyanezzel a megbeszélt értékkel.
Egy félreértés miatt azonban a barátod megfordította a megbeszélt érték bitjeit (azaz bitenkénti NOT műveletet alkalmazott a megbeszélt értékre), mielőtt a XOR-t elvégezte.

Valósítsd meg a `Secrets.reverse_xor` metódust, amely a titkosított és a megbeszélt értéket kapja, és kiszámítja az eredeti értéket.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
