# Utasítások

Éppen egy egészségfigyelő rendszer megvalósításán dolgozol.
Ennek részeként nyomon kell követned a felhasználók egészségügyi statisztikáit.

Kezdetnek néhány csonkolt függvénnyel indulsz egy `impl` blokkban, valamint a következő struct-definícióval:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

A célod, hogy implementáld a `User` `struct` `impl` blokkban definiált csonkolt metódusait.

Például a `new` metódusnak egy `User` struct egy példányát kell visszaadnia a megadott névvel, életkorral és súllyal.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

A `weight` metódusnak vissza kell adnia a `User` súlyát.

```rust
bob.weight();
// Returns: 72
```

A `set_age` metódusnak be kell állítania a `User` életkorát.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
