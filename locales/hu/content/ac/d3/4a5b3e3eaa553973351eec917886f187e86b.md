# Utasítások

Ebben a feladatban naplósorokkal fogsz dolgozni.

Minden naplósor egy `"[<LVL>]: <MESSAGE>"` formátumú string.

Ezek a különböző naplózási szintek:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Három részfeladatod van, amelyeket mind teljesítened kell a szükséges funkció biztosításához.

## 1. Hozd létre a LogLevel felsorolást

Definiálj egy `LogLevel` felsorolást, amelynek hat esete megfelel a fenti naplózási szinteknek, valamint egy ismeretlen eset a hiányzó vagy nem szabványos naplózási szintekhez.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. Értelmezd a naplózási szintet

Ezután valósítsd meg a `LogLevel` kezdőértékét, hogy értelmezze egy naplósor naplózási szintjét:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. Alakítsd át a naplósort rövid formátumra

Egy naplósor naplózási szintje meglehetősen hosszadalmas.
Hogy csökkentsük a naplósorok tárolásához szükséges lemezterületet, kifejlesztettek egy rövid formátumot: `"<ENCODED_LEVEL>:<MESSAGE>"`.

A kódolt naplózási szint egyszerű megfeleltetés a naplózási szint és egy szám között:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

Valósítsd meg a `shortFormat(message: String) -> String` metódust, amely `String`-ként kiírja a rövidített naplósor-formátumot:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
