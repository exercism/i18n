# Utasítások

Ebben a feladatban egy módot valósítasz meg arra, hogy nyilván tartsd a helyi játékterem legnépszerűbb játékának csúcseredményeit.

Öt függvényt kell megvalósítanod, amelyek közül a legtöbb egy csúcseredményeket tároló objektum kezeléséhez kapcsolódik.

## 1. Hozz létre egy új eredménytáblát

Készíts egy `createScoreBoard` nevű függvényt, amely létrehoz egy eredménytáblaként szolgáló objektumot.
Az objektum kulcsai a játékosok nevei lesznek, az értékek pedig a pontszámaik.
A tesztelés kedvéért rögtön be szeretnél venni egy bejegyzést az objektumba.
Ez a kezdő bejegyzés a `The Best Ever` játékosnévből és az `1000000` pontszámból álljon.

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. Adj hozzá játékosokat egy eredménytáblához

Ha játékost szeretnél hozzáadni az eredménytáblához, definiáld az `addPlayer` függvényt.
Három paramétert fogad:

- Az első paraméter egy létező eredménytábla-objektum.
- A második paraméter a játékos neve stringként.
- A harmadik paraméter a pontszám számként.

A függvény az új játékos hozzáadása után ugyanazt az eredménytábla-objektumot adja vissza, amelyet megkapott.

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. Távolítsd el a játékosokat egy eredménytábláról

Ha a játékosok megszegik a játékterem szabályait, kézzel eltávolítják őket az eredménytábláról.
Definiáld a `removePlayer` függvényt, amely két paramétert vesz át:

- Az első paraméter egy létező eredménytábla-objektum.
- A második paraméter a játékos neve stringként.

Ennek a függvénynek el kell távolítania az adott játékos bejegyzését a tábláról, majd ezután vissza kell adnia a táblát.
Ha a játékos eleve nem szerepelt a táblán, a táblával nem történik semmi, és változatlanul kell visszaadni.

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. Növeld egy játékos pontszámát

Ha egy játékos újabb játékot fejez be a játékteremben, bizonyos pontszám hozzáadódik a táblán lévő korábbi pontszámához.
Valósítsd meg az `updateScore` függvényt, amely három paramétert vesz át:

- Az első paraméter egy létező eredménytábla-objektum.
- A második paraméter annak a játékosnak a neve, akinek növelni kell a pontszámát.
- A harmadik paraméter az a pontszám, amelyet a tárolt csúcseredményhez **hozzá** szeretnél adni.

A függvény a frissítés elvégzése után adja vissza az eredménytáblát.

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. Alkalmazz hétfői bónuszpontokat

A játékterem hétfőnként külön eredménytáblát vezet.
A nap végén azon a táblán szereplő minden játékos 100 pluszpontot kap.

Valósítsd meg az `applyMondayBonus` függvényt, amely átvesz egy eredménytáblát.
A függvény hozzáadja a bónuszpontokat minden játékoshoz, aki szerepel a táblán.
Ezután visszaadja a táblát.

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
