# Névjegy

Egy érték scope-ja azt határozza meg, hogy a programban hol férhetsz hozzá az adott értékhez.

## A scope négy fajtája: blokk, függvény, függvényprototípus, fájl

### Blokk scope

A blokk scope-pal rendelkező érték csak abból a blokkból érhető el, amelyben definiálták.
A blokkokról bővebben lásd a [blokk fogalmát](../blocks/introduction.md#Introduction).

### Függvény scope

A függvény scope egy különleges fajtája a scope-nak, amely a `goto` utasításokhoz használt címkékre vonatkozik.
Két azonos nevű címkét nem használhatsz ugyanabban a függvényben, még akkor sem, ha a címkéket a függvényen belül külön blokkokban definiáltad.

### Függvényprototípus scope

A függvényprototípus scope egy másik különleges scope-típus, amely csak a prototípusban elnevezett paraméterekre vonatkozik (ezt deklarációnak is nevezik, de ne feledd, hogy nem minden deklaráció prototípus).
Egy paraméter neve általában opcionális egy függvénydeklarációban.
Egy név scope-ja csak a deklaráción belül releváns.
A következő példában a `len` azonosítót definiáljuk, majd később hivatkozunk rá a függvénydeklarációban.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Figyeld meg, hogy egy deklaráción belül a neveknek egyezniük kell, amikor ugyanarra a változóra hivatkozol.
Ha a `my_func` függvényt így deklarálnád: `void my_func(int len, int numbers[length]);`, akkor valami ilyesmi fordítási hiba keletkezne:

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

A függvénydefinícióban nem kell ugyanazt a nevet használni a paraméterhez, mint amit a függvénydeklarációban használtál.
A fenti példában a `len` szerepelt a deklarációban, a `length` pedig a definícióban, ami azt mutatja, hogy a `len` azonosító scope-ja csak a függvénydeklaráción belülre terjedt ki.

### Fájl scope

A fájl scope-pal rendelkező érték a fájl bármely pontjáról elérhető.
Az ilyen értékeket egy függvényen kívül definiáljuk.
