# Utasítások

Ebben a feladatban kódot írsz majd, hogy segíts megfőzni egy remek lasagnét a kedvenc szakácskönyvedből.

Öt részfeladat vár rád, és mindegyik a lasagna elkészítési idejéhez kapcsolódik.

## 1. Határozd meg a várható sütési időt percben

Definiáld az `expectedMinutesInOven` immutable változót, amely visszaadja, hány percig kell a lasagnának a sütőben lennie.
Exportálni kell.
A szakácskönyv szerint a várható sütési idő 40 perc:

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. Számítsd ki a hátralévő sütési időt percben

Valósítsd meg a `remainingMinutesInOven` eljárást, amely paraméterként megkapja, hány perce van már a sütőben a lasagna, és visszaadja, hány percig kell még a sütőben maradnia, az előző részfeladatban megadott várható sütési idő alapján.

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. Számítsd ki az előkészítési időt percben

Valósítsd meg a `preparationTimeInMinutes` eljárást, amely paraméterként megkapja a lasagnába tett rétegek számát, és visszaadja, hány percet töltöttél a lasagna előkészítésével, feltételezve, hogy minden réteg elkészítése 2 percet vesz igénybe.

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. Számítsd ki a teljes munkával töltött időt percben

Valósítsd meg a `totalTimeInMinutes` eljárást, amely két paramétert vár: a `numberOfLayers` paraméter a lasagnába tett rétegek száma, az `actualMinutesInOven` paraméter pedig az, hány perce van már a sütőben a lasagna.
Az eljárás adja vissza, összesen hány percet dolgoztál a lasagna elkészítésén, ami az előkészítési idő és a lasagna által eddig a sütőben töltött idő összege.

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
