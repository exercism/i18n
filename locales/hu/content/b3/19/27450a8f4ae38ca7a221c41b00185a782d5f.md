# For-ciklusok

A ciklusok a programozás alapvető fogalmai: segítségükkel egy kódrészletet többször is végrehajthatsz.
A Swiftben kétféle ciklus létezik: [`for-in` ciklusok][for-loops] és `while` ciklusok.
Ebben a fejezetben a `for-in` ciklusokról tanulsz.

A `for` ciklusokkal egy értéksorozaton iterálhatsz: minden elemet sorra veszel, és egy általad választott változóhoz kötöd.
A Swift sokféle sorozaton enged iterálni, például tartományokon, tömbökön és stringeken (és további típusokon, amelyekre később térünk ki).
Miután a sorozat minden elemén végigment, a ciklus kilép.

A `for` ciklusokat a `for` kulcsszóval deklarálod, amelyet egy változónév, az `in` kulcsszó és egy sorozat követ, amelyen iterálni szeretnél.
A `for-in` ciklusban megadott változó nem módosítható, ami azt jelenti, hogy a cikluson belül nem változtathatod meg az értékét.
Íme egy példa egy `for-in` ciklusra, amely egy számokból álló tömbön iterál:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
A `number` változó a `for-in` ciklusban jön létre, és csak a ciklus scope-ján belül érhető el.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Iterálás egy tartományon

Egy számtartományon is iterálhatsz `for-in` ciklussal.
Így egy kódrészletet meghatározott számú alkalommal hajthatsz végre. Például az `1...5` tartomány az 1, 2, 3, 4 és 5 számokon megy végig, tehát a ciklus ötször fut le.
Néha előfordul, hogy egy adatszerkezet, például egy tömb indexein szeretnél iterálni; ilyenkor használhatod a `0..<array.count` tartományt.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Iterálás egy stringen

Egy stringen is iterálhatsz `for-in` ciklussal.
Így a string minden egyes karakterén végigmehetsz; jegyezd meg, hogy a ciklusban megadott típus `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

A Swift egy `stride` függvényt is biztosít, amellyel egy tartományon egy adott lépésközzel hozhatsz létre sorozatot.
Ezen aztán `for-in` ciklussal iterálhatsz.
A `stride` a [`stride(from:to:by:)`][stride-to] vagy a [`stride(from:through:by:)`][stride-through] formában érhető el; az első nem tartalmazza a végértéket, a második viszont igen.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Vedd figyelembe, hogy a `to` paraméter nem tartalmazza a végértéket, így a ciklus a `to` paraméter előtti számig iterál, míg a `through` paraméter tartalmazza, tehát ebben az esetben a `10`-et is beleértve.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
