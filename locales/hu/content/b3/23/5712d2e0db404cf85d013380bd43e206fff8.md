# Bevezetés

## Egyenlőség

Az Elm típusainál a `(==)` egyenlőségoperátorral ellenőrizheted, hogy két érték „ugyanaz-e”. Az egyenlőtlenség-operátor a `(/=)` (*nem* `!=`, mint sok más nyelvben). Az egyenlőségoperátor literálokon, tuple-okon, rekordokon és egyedi típusokon működik.

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Ne feledd: függvényeket *soha ne* hasonlíts össze, mert ettől a program futásidőben összeomlik.

## Összehasonlítások

A `(<)`, `(<=)`, `(>)` és `(>=)` összehasonlító operátorok, valamint a `min`, `max` és `compare` függvény `comparable` típusokon működnek. A `comparable` egy különleges típus, amely minden összehasonlítható beépített típust egyesít: számokat, karaktereket, stringeket, `comparable` értékek listáit és `comparable` értékek tuple-jait.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

Más típusok, például a rekordok vagy az egyedi típusok értékei nem hasonlíthatók össze közvetlenül.

Néhány beépített típus megköveteli, hogy a tartalma `comparable` legyen, ilyen például a `Set` vagy a `Dict` kulcsai, mert a felépítésük egy belső sorrendre támaszkodik.

A `comparable` értékek listáit a `List.sort` függvénnyel rendezheted, az olyan értékek listáit pedig, amelyek leképezhetők `comparable` értékekre, a `List.sortBy` függvénnyel. Ha többszintű rendezésre van szükséged (rendezés az egyik tulajdonság szerint, a holtversenyeket pedig egy másikkal döntöd el), a tuple-okat vagy listákat a `List.sortBy` függvénnyel is használhatod, mert a tuple-ok és a listák lexikográfiai sorrendben rendeződnek.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

A `compare` függvény két `comparable` értéket vesz át, és egy `Order` értéket ad vissza. Az `Order` egy olyan típus, amely egyetlen művelettel megállapítja, hogy egy érték nagyobb (`GT`), egyenlő (`EQ`) vagy kisebb (`LT`), mint egy másik.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

Összehasonlító függvényeket tetszőleges típusokhoz is készíthetsz, és használhatod őket például arra, hogy a `List.sortWith` segítségével rendezd a listát:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
