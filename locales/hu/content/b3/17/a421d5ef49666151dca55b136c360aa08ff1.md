# Névjegy

A Gleam az igaz és hamis értékeket a `Bool` típussal ábrázolja. Mindössze két érték létezik: `True` és `False`. Ezeket az értékeket változóhoz kötheted:

```gleam
let true_variable = True
let false_variable = False
```

A `&&`, `||` és `!` operátorokkal Boolean értékeket lehet manipulálni:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

A `&&` és `||` operátor rövidzárásos kiértékelést használ, ami azt jelenti, hogy az operátor jobb oldalán álló kifejezés csak akkor értékelődik ki, ha szükséges.

Az operátoroknak eltérő a precedenciájuk: a `!` a `&&` és a `||` előtt értékelődik ki. A kapcsos zárójelekkel (`{}`) elérhető, hogy a kifejezés egyik része a többiek előtt értékelődjön ki:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
