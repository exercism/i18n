# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít felkészülni egy jármű megvásárlására.

Három részfeladat vár rád: az egyikben eldöntöd, hogy szükséged lesz-e jogosítványra, a másikban segítesz választani két jármű közül, a harmadikban pedig megbecsülöd egy használt jármű elfogadható árát.

## 1. Döntsd el, hogy szükséged lesz-e jogosítványra

Egyes járművek vezetéséhez jogosítvány kell.
Feltételezzük, hogy csak a `car` és `truck` fajtához kell jogosítvány, minden más vezethető jogosítvány nélkül.

Valósítsd meg a `needs_license(kind)` függvényt, amely megkapja a jármű fajtáját, és egy Boolean értéket ad vissza arról, hogy szükség van-e jogosítványra az adott fajtájú járműhöz.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. Válassz két lehetséges jármű közül

Mérlegeld a rendelkezésre álló járműveket.
Sikerül két lehetőségre szűkítened a kört, de segítségre van szükséged a végső döntéshez.
Ehhez valósítsd meg a `choose_vehicle(option1, option2)` függvényt, amely két járművet kap argumentumként, és visszaad egy döntést, ami egyszerűen a szótári sorrendben elsőként szereplő lehetőség.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. Becsüld meg egy használt jármű árát

Most, hogy meghoztad a döntésed, szeretnéd biztosítani, hogy tisztességes árat kapj a kereskedésben.
Mivel használt járművet szeretnél venni, az ár attól függ, milyen idős a jármű.
Durva becsléshez feltételezzük, hogy ha a jármű 3 évnél fiatalabb, az az eredeti, vadonatúj kori árának 80%-ába kerül.
Ha több mint 10 éves, akkor 50%-ába.
Ha a jármű legalább 3 éves, de nem idősebb 10 évnél, akkor az eredeti ár 70%-ába kerül.

Valósítsd meg a `calculate_resale_price(original_price, age)` függvényt.
Megkapja az eredeti árat és a jármű korát argumentumként, és visszaadja a kereskedésben becsült árat.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
