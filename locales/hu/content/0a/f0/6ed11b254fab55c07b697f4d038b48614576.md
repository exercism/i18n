# Bevezetés

## Összehasonlítás

### Egyenlőség

Az Elm típusoknál az „ugyanaz-e” kérdés a `(==)` egyenlőségoperátorral ellenőrizhető.
A nem egyenlőség operátora a `(/=)` (*nem* `!=`, mint sok más nyelvben).
Az egyenlőségoperátor literálokon, tuple-okon, rekordokon és egyedi típusokon működik.

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Vedd figyelembe, hogy függvényeket *soha ne* hasonlíts össze, mert ettől a program futásidőben összeomlik.

### Összehasonlítások

A `(<)`, `(<=)`, `(>)`, `(>=)` összehasonlító operátorok és a `min`, `max`, `compare` függvények `comparable` típusokon működnek.
A `comparable` típus egy speciális típus, amely az összes beépített, összehasonlítható típust csoportosítja: számokat, karaktereket, stringeket, összehasonlítható dolgok listáit és összehasonlítható dolgokból álló tuple-okat.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

Más típusok értékei, például a rekordok vagy az egyedi típusok, nem hasonlíthatók össze közvetlenül.

Néhány beépített típus megköveteli, hogy a tartalma `comparable` legyen, például a `Set` vagy a `Dict` kulcsaié, mert a szerkezetük belső sorrendezésre támaszkodik.

A `comparable` értékek listái a `List.sort` függvénnyel rendezhetők, és az olyan értékek listái, amelyek leképezhetők `comparable` értékekre, a `List.sortBy` függvénnyel rendezhetők.
Ha hierarchikus rendezésre van szükséged (egy tulajdonság szerint rendezel, a holtversenyeket pedig egy másikkal döntöd el), a `List.sortBy` függvénnyel is használhatók tuple-ok vagy listák, mert a tuple-ok és a listák lexikográfiai sorrendben rendeződnek.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

A `compare` függvény két `comparable` értéket vesz fel, és egy `Order` értéket ad vissza.
Az `Order` egy olyan típus, amely egyetlen műveletben eldönti, hogy egy érték nagyobb (`GT`), egyenlő (`EQ`) vagy kisebb (`LT`), mint egy másik.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

Összehasonlító függvények tetszőleges típusokhoz is készíthetők, és például arra használhatók, hogy a `List.sortWith` függvénnyel rendezzünk velük:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
