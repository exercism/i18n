# Bevezetés

Egy típus akkor _generikus típus_, ha _típusparaméter_ segítségével bármilyen típusú értéket tartalmazhat.

Például a `Box` típusnak `a` a típusparamétere (kisbetűvel írva).

```gleam
pub type Box(a) {
  Box(a)
}
```

Az `a` típusparaméter bármilyen típus helyőrzője, így a `Box` használható stringekkel, egész számokkal vagy bármilyen más típussal.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

Egy típusnak több típusparamétere is lehet, amelyeket vesszővel választunk el egymástól.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## Generikus függvények

A típusparamétereket függvények argumentumaiban is használhatjuk.

Ez a függvény egy `a` típusú értéket vesz át, és kétszer meghív egy olyan függvényt, amely egy `a`-t vesz át és egy `b`-t ad vissza.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
