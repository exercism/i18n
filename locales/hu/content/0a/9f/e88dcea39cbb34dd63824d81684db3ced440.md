# Bevezetés

## Alapok 1

### Konstansok és függvények

Egy konstans értéket `name = expression` formában definiálunk, ahol az Elmben minden definíció kivételével kifejezésnek számít.

```elm
five = 5

six = 3 + 3
```

A függvényeket `name parameters... = expression` formában definiáljuk, a paramétereket pedig csak szóköz választja el egymástól.

```elm
add number1 number2 = number1 + number2
```

Egy függvény meghívása szintén kifejezés, és úgy történik, hogy megadjuk a nevét, majd minden paraméteréhez átadunk egy argumentumot, szóközzel elválasztva, éppúgy, mint a függvény definiálásakor.

```elm
five = add 2 3
```

Zárójelekkel megadhatjuk egy kifejezés kiértékelési sorrendjét.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

### Behúzás / a whitespace jelentősége

Az Elm nem használ szintaktikai jelölőket, például kapcsos zárójelet, zárójelet vagy pontosvesszőt a kódrészek határainak kijelölésére. Helyettük szóközöket és behúzásokat használ.

- A modul-, import- és legfelső szintű függvénydefinícióknak a bal szélső oszlopban kell kezdődniük.
- Ha egy kifejezés több sorra tagolódik, a kifejezéshez tartozó kódot legalább egy szóközzel be kell húzni a kifejezés alá.
- A kifejezés összetartozó részeit ugyanannyi szóközzel érdemes behúzni.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

### Modulok

Az Elmben minden fájl egy modul, és minden más kód előtt szerepelnie kell benne egy `module` utasításnak.
A modulneveknek meg kell egyezniük a fájlnevükkel, így a `Calculator` modulnak a Calculator.elm fájlban kell lennie.
A modulon belül definiált bármi privát a láthatósága, és kívülről nem érhető el, kivéve, ha szerepel az `exposing` listában.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### Kommentek

A komment az Elm-fájlban lévő szöveg, amelyet a program nem kódként értelmez.
Elsősorban arra szolgál, hogy te és a többi programozó elolvassátok.
Az egysoros kommentekhez van egy egyszerű szintaxis, amely két egymást követő kötőjelen alapul.
Többsoros kommentek is írhatók a `{-` és `-}` nyitó és záró határoló párral.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```

### Formázás

Létezik egy [stílusútmutató](https://elm-lang.org/docs/style-guide), és az [elm-format](https://github.com/avh4/elm-format) segítségével automatikusan formázhatod a kódot.
