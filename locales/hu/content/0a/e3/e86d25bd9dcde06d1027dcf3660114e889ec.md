# Utasítások

Ebben a feladatban egy új RPG küldetéslogikáját valósítod meg, amelyet egy barátod fejleszt. A játék főszereplője Annalyn, egy bátor lány, akinek van egy elszánt és hűséges kutyája. Sajnos azonban baj történik: a legjobb barátját elrabolták, miközben bogyókat keresett az erdőben. Annalyn megpróbálja megtalálni és kiszabadítani a legjobb barátját, és ehhez akár a kutyáját is magával viheti.

Miután egy ideig a legjobb barátja nyomát követi, megtalálja a tábort, ahol fogva tartják. Kiderül, hogy két emberrabló van: egy hatalmas lovag és egy ravasz íjász.

Miután megtalálta az emberrablókat, Annalyn végiggondolja, melyik alábbi akciót tudja végrehajtani:

- Gyors támadás: gyors támadást akkor lehet végrehajtani, ha a lovag alszik, mert időbe telik, míg felveszi a páncélját, így sebezhető lesz.
- Kémkedés: akkor lehet kémkedni a csoport után, ha legalább az egyikük ébren van. Egyébként a kémkedés időpocsékolás.
- A rab jelzése: madárhangokkal lehet jelezni a rabnak, ha a rab ébren van és az íjász alszik, mert az íjászokat madárjelekre képezték ki, így elkaphatnák az üzenetet.
- _A rab kiszabadítása_: Annalyn megpróbálhat belopakodni a táborba, hogy kiszabadítsa a rabot.
  Ez kockázatos vállalkozás, és csak kétféleképpen sikerülhet:
  - Ha Annalyn magával hozta a kutyáját, akkor kiszabadíthatja a rabot, ha az íjász alszik.
    A lovag fél a kutyától, és az íjásznak nem lesz ideje felkészülni, mielőtt Annalyn és a rab megszökne.
  - Ha Annalyn nem hozta magával a kutyáját, akkor neki és a rabnak nagyon óvatosnak kell lennie!
    Annalyn akkor szabadíthatja ki a rabot, ha a rab ébren van, a lovag és az íjász pedig alszik, de ha a rab alszik, nem lehet megmenteni: Annalyn hirtelen felbukkanása megijesztené, és felébresztené a lovagot meg az íjászt.

Négy részfeladat vár rád: meg kell valósítanod annak logikáját, hogy az alábbi akciók elérhetők-e, az erdőben talált három szereplő állapota és Annalyn kutyájának jelenléte alapján.

## 1. Ellenőrizd, hogy a »gyors támadás« akció lehetséges-e

Készíts egy `canExecuteFastAttack` nevű függvényt, amely egy logikai értéket vár, és ez jelzi, hogy a lovag ébren van-e. A függvény akkor ad vissza `true`-t, ha a »gyors támadás« akció elérhető a szereplő állapota alapján. Egyébként `false`-t ad vissza:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. Ellenőrizd, hogy a »kémkedés« akció lehetséges-e

Készíts egy `canSpy` nevű függvényt, amely három logikai értéket vár; ezek rendre azt jelzik, hogy a lovag, az íjász és a rab ébren van-e. A függvény akkor ad vissza `true`-t, ha a »kémkedés« akció elérhető a szereplők állapota alapján. Egyébként `false`-t ad vissza:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. Ellenőrizd, hogy a »rab jelzése« akció lehetséges-e

Készíts egy `canSignalPrisoner` nevű függvényt, amely két logikai értéket vár; ezek rendre azt jelzik, hogy az íjász és a rab ébren van-e. A függvény akkor ad vissza `true`-t, ha a »rab jelzése« akció elérhető a szereplők állapota alapján. Egyébként `false`-t ad vissza:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. Ellenőrizd, hogy a »rab kiszabadítása« akció lehetséges-e

Készíts egy `canFreePrisoner` nevű függvényt, amely négy logikai értéket vár. Az első három paraméter rendre azt jelzi, hogy a lovag, az íjász és a rab ébren van-e. Az utolsó paraméter azt jelzi, hogy Annalyn kutyája jelen van-e. A függvény akkor ad vissza `true`-t, ha a »rab kiszabadítása« akció elérhető a szereplők állapota és Annalyn kutyájának jelenléte alapján. Egyébként `false`-t ad vissza:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
