# Függvényannotációk sorrendje

A megszokott gyakorlat szerint a `@doc` függvényannotációk megelőzik a `@spec` függvényannotációkat, a `@spec` függvényannotációknak pedig közvetlenül a függvény előtt kell állniuk. Ha a függvénynek több klóza van, a függvényannotációk az első klóz elé kerülnek.

Példa:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
