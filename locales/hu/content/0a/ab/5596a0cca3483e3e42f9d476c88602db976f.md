# Bevezetés

A Boolean típusnak Luában két hagyományos logikai értéke van: `true` és `false`. Ezek az értékek hozzárendelhetők egy változóhoz, összekapcsolhatók logikai operátorokkal (`and`, `or`, `not`), és feltételes vizsgálatokban is használhatók (például vezérlési szerkezetekben).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

A feltételes vizsgálatok és a logikai operátorok a `false` Boolean értéket és a `nil`-t is hamisként értelmezik, minden mást pedig igazként.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Az `and` és az `or` is *rövidzár-kiértékelést* használ, ami azt jelenti, hogy a második operandusukat csak akkor értékelik ki, amikor feltétlenül szükséges. Minden művelet kiértékelése az [operátorok elsőbbsége](https://www.lua.org/manual/5.4/manual.html#3.4.8) szerint történik, ahol a `not` kiértékelése megelőzi az `and` és az `or` kiértékelését.
