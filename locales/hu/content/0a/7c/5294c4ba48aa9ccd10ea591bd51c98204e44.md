# A representer normalizálásai

Az [Elixir representer][representer] számos normalizálást végez.
A részletekért nézd meg a kódot vagy a [tesztadatokat][test-data].

## Kommentek és doksik eltávolítása

Minden komment, doksi, moduldoc és typedoc eltávolításra kerül.

### Előtte

```elixir
defmodule Fake do
  @moduledoc """
  Fake module to demonstrate stuff
  """

  @doc "Not much to see here"
  def foo do
    # TODO: return bar
    nil
  end
end
```

### Utána

```elixir
defmodule Fake do
  def foo do
    nil
  end
end
```

## Az importok sorrendjének rendezése

A modulok vagy függvények elején álló import utasítások a következő sorrendbe kerülnek: `alias`, `use`, `require`, `import`.

### Előtte

```elixir
defmodule Fake do
  import D
  alias A.U.V
  use B
  alias A.{T, S}
  require C

  def foo do
    import Z
    alias X
    use Y
  end

  import NotTouched
  alias NotTouched
end
```

### Utána

```elixir
defmodule Fake do
  alias A.{S, T}
  alias A.U.V
  use B
  require C
  import D

  def foo do
    alias X
    use Y
    import Z
  end

  import NotTouched
  alias NotTouched
end
```

## A kód formázása

A kód a [mix code][mix-code] segítségével formázódik, ami `do` `end` blokkokat kényszerít ki.
A pipe-okban lévő összes függvény zárójelekkel íródik.
A típusok zárójel nélkül.

### Előtte

[//]: # (elixir-formatter-disable-next-block)

```elixir
defmodule    Fake   do
        @type foo() :: integer() | atom
def foo, do:    nil |> bar
end
```

### Utána

```elixir
defmodule Fake do
  @type foo() :: integer | atom
  def foo do
    nil |> bar()
  end
end
```

## Azonosítók normalizálása

Az azonosítók egy helyőrző értékre normalizálódnak.
Néhány speciális változó és modulattribútum (`_`, `@spec`, `__MODULE__`, stb.) nem kerül lecserélésre.
A mapokban, structokban és kulcsszólistákban lévő kulcsok nem normalizálódnak.

### Előtte

```elixir
defmodule Fake do
  alias Fake, as: SuperFake
  @my_constant 42

  @impl true
  def foo(bar) when is_integer(bar) do
    bar + @my_constant
  end

  def foo(%{a: a} = bar) do
    %{bar | a: a + @my_constant}
  end

  def foo(_), do: nil
end
```

### Utána

```elixir
defmodule Placeholder_1 do
  alias Placeholder_1, as: Placeholder_2
  @placeholder_6 42
  @impl true
  def placeholder_4(placeholder_5) when is_integer(placeholder_5) do
    placeholder_5 + @placeholder_6
  end

  def placeholder_4(%{a: placeholder_7} = placeholder_5) do
    %{placeholder_5 | a: placeholder_7 + @placeholder_6}
  end

  def placeholder_4(_) do
    nil
  end
end
```

## Kulcsok rendezése mapokban és structokban

A mapokban és structokban lévő kulcsok rendeződnek.
A kulcsszólistákban lévő kulcsok nem rendeződnek.

### Előtte

```elixir
defmodule Fake do
  def foo do
    %MyStruct{z: 3, y: 2, x: 1}
    m = %{c: 3, a: 1, b: 2}
    %{m | b: 20, a: 10}
    [b: 2, a: 1]
  end
end
```

### Utána

```elixir
defmodule Fake do
  def foo do
    %MyStruct{x: 1, y: 2, z: 3}
    placeholder_3 = %{a: 1, b: 2, c: 3}
    %{placeholder_3 | a: 10, b: 20}
    [b: 2, a: 1]
  end
end
```
