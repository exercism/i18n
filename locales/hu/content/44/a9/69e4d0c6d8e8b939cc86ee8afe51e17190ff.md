# A fogalomról

Az osztályok a Swift programozás egyik alapeleme. Lehetővé teszik, hogy a kapcsolódó adatokat és függvényeket önálló funkcionális egységekbe csoportosítsuk.

### Osztályok definiálása

Egy osztály definiálásához kezdd a `class` kulcsszóval, majd írd le a létrehozni kívánt típus nevét, ezután következik az osztály törzse, kapcsos zárójelek közé zárva.

A törzs állhat tárolt tulajdonságokból, amelyeket ugyanúgy definiálunk, és amelyek ugyanúgy viselkednek, mint a szokásos konstansok vagy változók.

```swift
class GameCharacter {
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### Példányok

Ahogy fentebb említettük, egy osztály definiálása csupán egy új _típus_ definiálása. Ez csak a tervrajz arra nézve, hogyan fognak kinézni az adott típus értékei, de valójában nem hoz létre egyetlen ilyen típusú értéket sem, amivel dolgozhatnál.

Ahhoz, hogy létrehozz egy _példányt_ az adott típusból, írd le a típus nevét, majd utána egy pár zárójelet.

```swift
let someCharacter = GameCharacter()
```

Ez létrehozza az ilyen típusú értékeket, ahol a tulajdonságok a definícióban megadott alapértelmezett értékekkel töltődnek fel. Figyelj rá, hogy opcionális esetekben, mint a GameCharacter `name` tulajdonsága, ha nem adsz meg értéket, a tulajdonság alapértéke nil lesz, akárcsak a szokásos opcionális típusoknál, ahol az értéket nem adjuk meg azonnal.

### Tulajdonságok elérése

Az osztály tulajdonságait _pontjelöléssel_ érheted el, ahol az érték nevét egy pont (`.`) követi, majd a tulajdonság neve. Ha egy osztály valamely tulajdonságának magának is vannak tulajdonságai, ezzel a pontjelöléssel ezeket az egymásba ágyazott tulajdonságokat is elérheted.

Ez a jelölés használható a tulajdonság értékének kiolvasására, és ahol engedett, a megváltoztatására is.

```swift
someCharacter.name
// => nil
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Metódusok

A tulajdonságokhoz hasonlóan, amelyek adatot tárolnak az osztályaidban, _metódusokat_ is definiálhatsz, amelyek függvényeket tárolnak az osztályodban.

A metódusokat ugyanúgy definiáljuk, mint egy szokásos függvényt, csak az osztály törzsén belül. Ráadásul, ha egy tulajdonságot egy metódus meg tud változtatni, akkor azt a tulajdonságot `var`-ral kell definiálni `let` helyett, akárcsak a szokásos változókat.

```swift

class GameCharacter {
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    if damage > 100 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
}
```

Ezeket a metódusokat pontjelöléssel hívhatod meg, akárcsak a tulajdonságokat.

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Az osztálypéldányok mindegyikének van egy `self` nevű implicit értéke, amely magára a példányra hivatkozik. A `self`-nek többféle felhasználása is van, de leggyakrabban a struktúra vagy osztály tulajdonságai és metódusai nevének egyértelműsítésére szolgál, amikor valami félreértés adódhat.
