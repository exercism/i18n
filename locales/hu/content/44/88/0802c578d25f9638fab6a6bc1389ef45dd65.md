# Utasítások

Fordítsd le az RNS-szekvenciákat fehérjékké.

Az RNS három nukleotidból álló szekvenciákra bontható, amelyeket kodonoknak nevezünk, majd ezekből fehérje lesz, így:

RNS: `"AUGUUUUCU"` => lefordítva:

Kodonok: `"AUG", "UUU", "UCU"`
=> amelyekből az alábbi szekvenciájú fehérje lesz =>

Fehérje: `"Methionine", "Phenylalanine", "Serine"`

64 kodon létezik, amelyek 20 aminosavnak felelnek meg; ebben a feladatban azonban nem fontos az összes kodonszekvencia és a belőlük keletkező aminosav.
Ha egy kodonra működik, a programnak mindegyikre működnie kell.
Nyugodtan bővítsd a tesztcsomag listáját, hogy mindegyiket tartalmazza.

Három lezáró kodon is van (más néven „STOP” kodonok); ha a riboszóma ilyen kodonba fut, minden fordítás véget ér, és a fehérje lezárul.

Az utána következő kodonokat figyelmen kívül hagyja, így:

RNS: `"AUGUUUUCUUAAAUG"` =>

Kodonok: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Fehérje: `"Methionine", "Phenylalanine", "Serine"`

Figyeld meg, hogy a `"UAA"` stopkodon lezárja a fordítást, és a végső Methionine nem kerül be a fehérje szekvenciájába.

Az alábbiakban a feladathoz szükséges kodonok és a belőlük keletkező aminosavak találhatók.

| Kodon              | Aminosav      |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |
