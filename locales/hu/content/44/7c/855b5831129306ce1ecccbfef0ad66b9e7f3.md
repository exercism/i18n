# A `string`ról

A `string` a Clojure-ban egy Java string, azaz egy objektum, amely nem változtatható szöveget ábrázol Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként, és a következőképpen definiálható:

```clojure
(def fruit "Apple")
```

A `clojure.string` könyvtár számos szabványos függvényt kínál stringek kezeléséhez és feldolgozásához. Ráadásul a stringeken működő összes megszokott Java-metódus is elérhető interop segítségével.
