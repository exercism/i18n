# Névjegy

Az Elixir a [_Behaviour_][behaviours] mechanizmust használja arra, hogy közös, általános felületeket biztosítson, ugyanakkor minden őt megvalósító modul számára lehetővé tegye a saját implementációját. E mechanizmusok egyike az _Access Behaviour_.

Az _Access Behaviour_ közös felületet ad kulcs alapú adatok lekéréséhez egy adatszerkezetből. Mapre és kulcsszólistára van megvalósítva.

Az [`Access`][access] modul definiálja a felülethez szükséges callbackeket. A [`Map`][map] és a [`Keyword`][keyword] modul ezután megvalósítja a szükséges callbackeket: [`fetch/2`][map-fetch], [`get_and_update/3`][map-get-and-update] és [`pop/2`][map-pop]

A behaviour használatához egy kötött változó után írj _szögletes zárójelet_, majd a kulccsal kérd le a hozzá tartozó értéket. A map bármilyen típusú kulcsot támogat, a kulcsszólista viszont csak atomkulcsokat.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

Ha a kulcs nem létezik az adatszerkezetben, akkor `nil` lesz a visszatérési érték. Ez nem szándékolt viselkedés forrása lehet, mert nem dob hibát.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

Vedd figyelembe, hogy maga a `nil` is megvalósítja az Access Behaviourt, és bármely kulcsra mindig `nil`-t ad vissza.

```elixir
nil[:key]
# => nil
```

A structok nem valósítják meg az Access Behaviourt.
