# Utasítások

Ebben a feladatban egy New York-i szépségszalon időpont-ütemezőjén fogsz dolgozni, amely 2012. szeptember 15-én nyílt meg.

Öt részfeladat vár rád, és mindegyik az időpontok dátumaival foglalkozik.
A időpontok 24 órás formátumban vannak (nincs AM/PM).
Hogy az időzónákkal kapcsolatos problémák a lehető legegyszerűbbek legyenek, feltételezd, hogy minden UTC-t használ.

## 1. A csupa számból álló időpont értelmezése

Valósítsd meg a `schedule_appointment()` függvényt, amely egy időpont szöveges reprezentációját alakítja át a megfelelő `DateTime` formátumra.

Ügyelj arra, hogy a bemenet az amerikai hónap/nap/év sorrendet követi.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Annak ellenőrzése, hogy egy időpont már elmúlt-e

Valósítsd meg a `has_passed()` függvényt, amely egy időpontot kap, és ellenőrzi, hogy az időpont a múltban van-e:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Annak ellenőrzése, hogy az időpont délutánra esik-e

Valósítsd meg az `is_afternoon_appointment()` függvényt, amely egy időpontot kap, és ellenőrzi, hogy az délutánra esik-e (>= 12:00 és < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Egy időpont hét napjának ellenőrzése

Valósítsd meg a `day_of_week()` függvényt, amely a hét napjának _sorszámát_ adja vissza.
A szalon vasárnap zárva tart, ezért a hétfő az 1. nap, a szombat pedig a 6.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. Időpont átütemezése

Ha egy vendég át szeretné tenni az időpontját, az automatikusan a következő péntekre kerül, ugyanabban az időpontban (mivel ez a hét leglassabb napja).

Valósítsd meg a `reschedule()` függvényt, amely az eredeti időpontot kapja meg (szöveges formában, hónap/nap/év sorrendben), és visszaadja az átütemezett időpontot.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

Ha az eredeti időpont hétfő és csütörtök közé esett, akkor _ezen_ a héten péntekre ütemezd át.
Pénteki vagy szombati időpontok esetén a _következő_ hét péntekjére ütemezd át.
