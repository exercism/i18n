# Bevezetés

A Go-ban a Boolean értékeket az előre deklarált Boolean típus, a `bool` képviseli, amelynek értéke `true` vagy `false` lehet. Ez egy definiált típus.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

A Go három logikai operátort támogat, amelyekkel a kifejezéseket Boolean értékekre lehet kiértékelni, és `true` vagy `false` értéket adnak vissza.

| Operátor | Mit jelent |
| --- | --- |
| `&&` (és) | Akkor igaz, ha mindkét állítás igaz. |
| `\|\|` (vagy) | Akkor igaz, ha legalább az egyik állítás igaz. |
| `!` (nem) | Csak akkor igaz, ha az állítás hamis. |
