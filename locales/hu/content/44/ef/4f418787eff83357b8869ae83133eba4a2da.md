# Bemutató

A Clojure-ban a `vector` egy sorrendi, indexelt, megváltoztathatatlan gyűjtemény, amely nulla vagy több értéket tartalmaz. Ez azt jelenti, hogy miután létrehoztál egy vektort, azt már nem lehet módosítani. A vektorokon működő függvények új vektort adnak vissza, az eredeti vektor pedig változatlan marad. A vektorban lévő értékek különböző típusúak is lehetnek. A vektorokat így definiálhatod:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

A vektor elemeit index segítségével kérheted le. A Clojure vektorai nullától indexeltek, ami azt jelenti, hogy az első elem indexe mindig nulla:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Az eredeti vektor változatlan marad:

```clojure
numbers
;;=> [2 3 5]
```

Ahhoz, hogy megjegyezd a frissített értéket, tovább kell adnod, vagy el kell tárolnod egy varban:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
