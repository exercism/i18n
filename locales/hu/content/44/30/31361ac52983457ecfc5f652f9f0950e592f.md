# Részletek

Azt a képességet, hogy valami önmaga segítségével definiálható legyen, rekurziónak nevezzük. A Gleamben a rekurzió leggyakrabban rekurzív függvényekben fordul elő, vagyis olyan függvényekben, amelyek önmagukat hívják meg.

Egy rekurzív függvénynek legalább egy _alapesetre_ és legalább egy _rekurzív esetre_ van szüksége. Az _alapeset_ úgy ad vissza egy értéket, hogy nem hívja meg újra a függvényt. A _rekurzív eset_ újra meghívja a függvényt, és módosítja a bemenetet, hogy az előbb-utóbb illeszkedjen az alapesethez.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

A Gleamben nincs külön szintaxisa a ciklusokra, ezért minden ciklust rekurzióval írunk meg.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

A Gleam támogatja a rekurzív egyedi típusokat is. Egy rekurzív egyedi típusban a változatok közül egy vagy több a bennük tárolt adatban magára a típusra hivatkozik.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
