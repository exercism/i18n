# Utasítások

Ebben a feladatban olyan kódot írsz, amely azoknak a programozási nyelveknek a listáját dolgozza fel, amelyeket az Exercism platformon szeretnél gyakorolni.

Hat részfeladat vár rád.

## 1. Hozz létre egy új listát

Mielőtt nyelveket adhatnál hozzá, először létre kell hoznod egy új listát. Definiálj egy függvényt, amely egy üres listát ad vissza.

```clojure
(new-list)
;; => ()
```

## 2. Adj hozzá egy új nyelvet a listához

Miközben az Exercismet böngészve olyan nyelveket találsz, amelyeket meg szeretnél tanulni, hozzá kell majd tudnod adni őket a listádhoz. Definiálj egy függvényt, amely egy új nyelvet a listád elejére szúr be.

```clojure
(add-language '("Clojurescript") "JavaScript")
;; => '("JavaScript" "Clojurescript")
```

## 3. Ellenőrizd a legutóbb hozzáadott nyelvet

Szeretnéd gyorsan ellenőrizni, hogy melyik nyelvet adtad hozzá épp. Definiálj egy függvényt, amely a listád első nyelvét adja vissza.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Távolítsd el az első nyelvet a listáról

Néha meggondolod magad egy nyelvvel kapcsolatban, amelyet épp hozzáadtál. Definiálj egy függvényt, amely eltávolítja az első nyelvet a listádról.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Számold meg a listán lévő nyelveket

A nyelveket egyenként megszámolni kényelmetlen. Definiálj egy függvényt, amely megszámolja, hány nyelv van a listádon.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Rakd össze az egészet

Definiálj egy `learning-list` függvényt, amelyben a fentebb definiált függvények némelyikét fogod használni.

- Hozz létre egy üres listát
- Adj hozzá 2 új programozási nyelvet a listához.

  - „Clojure”
  - „Lisp”

- Távolítsd el a „Lisp” nyelvet a listáról, mert lehet, hogy nem lesz elég időd rá idén, és elég hasonló a Clojure-hoz.
- Adj hozzá még 2 programozási nyelvet a listához.

  - „Java”
  - „JavaScript”

- Add vissza a nyelvek teljes számát. Tipp: 3-nak kell lennie.

```clojure
(learning-list)
;; => 3
```
