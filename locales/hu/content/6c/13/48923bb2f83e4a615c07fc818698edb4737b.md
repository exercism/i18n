# string interpoláció használata a string formázás helyett

A C#-ban gyakoribb megközelítés, hogy [string interpolációt](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/) használjunk, ahelyett, hogy `string.Format` hívással dinamikusan felépítenénk egy stringet.

Ne feledd, hogy a string interpoláció csak egy fordítói trükk, más néven szintaktikai cukor. Ez azt jelenti, hogy egy string interpolációs kifejezés lefordításakor a fordító valójában `string.Format` hívássá alakítja. A string interpoláció használatának előnye tehát pusztán vizuális.
