# Utasítások

Ebben a feladatban olyan kódot írsz, amely névjelvényeket nyomtat gyári alkalmazottaknak.

## 1. Jelvény nyomtatása egy alkalmazottnak

Az alkalmazottaknak van azonosítójuk, nevük és részlegnevük. Az alkalmazottak jelvénycímkéi a következő formátumot követik: `"[id] - name - DEPARTMENT"`. Valósítsd meg a (_statikus_) `Badge.Print()` metódust, amely egy alkalmazott jelvénycímkéjét adja vissza:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Figyelj arra, hogy a címkén a részleg neve csupa nagybetűvel szerepel.

## 2. Jelvény nyomtatása egy új alkalmazottnak

A számítógépes rendszer sajátossága miatt előfordul, hogy az új alkalmazottaknak még nincs azonosítójuk, amikor elkezdenek dolgozni a gyárban. Mivel a jelvény kötelező, ideiglenes jelvényt kapnak, amelyen nincs ott az azonosító előtagja. Módosítsd a (_statikus_) `Badge.Print()` metódust, hogy azoknak az új alkalmazottaknak is működjön, akiknek még nincs azonosítójuk:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Jelvény nyomtatása a tulajdonosnak

A gyár tulajdonosának is folyamatosan jelvényt kell viselnie. A tulajdonosnak azonban nincs részlege. Ebben az esetben a címkére a részleg neve helyett az `"OWNER"` kerüljön. Módosítsd a (_statikus_) `Badge.Print()` metódust, hogy a tulajdonos számára is nyomtasson címkét:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Figyelj arra, hogy előfordulhat, hogy a tulajdonos egyben új alkalmazott is:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
