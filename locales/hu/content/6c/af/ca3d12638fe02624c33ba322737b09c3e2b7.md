# Tartományok

A [tartományok][range] két érték közötti intervallumot jelölnek.
A leggyakoribb típusok, amelyek támogatják a tartományokat, az `Integer` és a `String`.
Sok mindenre használhatók: gyorsan létrehozhatsz velük egy gyűjteményt, feldarabolhatsz stringeket, ellenőrizheted, hogy egy érték benne van-e egy tartományban, vagy iterálhatsz.
A `..` vagy a `...` tartományoperátorral hozhatók létre (előbbi a záróértéket is beleérti, utóbbi nem).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

Azért van két tartományoperátor, hogy olyan tartományokat is létrehozhass, amelyek tartalmazzák a záróértéket, vagy épp nem. Ez hasznos lehet például a nullától indexelt tömbökkel való munka során.

Tartományokat a `Range` konstruktorral, a `new` metódussal is létrehozhatsz.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Amikor Rubyban a `..` vagy `...` operátorral hozol létre egy tartományt, és metódust szeretnél hívni rajta, zárójelbe kell tenned a tartományt.
Ennek az az oka, hogy különben a metódus a tartományoperátor második argumentumán hívódik meg.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Részstringek kinyerése

Ha egy stringből részstringet szeretnél kivágni, a tartományoperátorral is megkaphatod.
Ehhez a részstring kezdő- és végindexével hozol létre egy tartományt.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Negatív indexekkel a string végéről is kinyerhetsz részstringet.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Tartományok metódusai

A tartományoknak van egy sor metódusuk, amelyekkel dolgozhatsz velük.
Ezekkel például kiszámíthatod a tartomány összes értékének összegét, vagy ellenőrizheted, hogy a tartomány tartalmaz-e egy értéket.

| Metódus                 | Leírás                                                                  | Példa                           |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | A tartomány összes értékének összegét adja vissza                       | `(1..5).sum # => 15`            |
| [`size`][size]          | A tartomány méretét adja vissza                                         | `(1..5).size # => 5`            |
| [`include?`][indlude]   | `true`-t ad vissza, ha a tartomány tartalmazza a megadott értéket, egyébként `false`-t | `(1..5).include?(3) # => true` |

## Végtelen és kezdet nélküli tartományok

Egy tartomány lehet végtelen és kezdet nélküli is.
A végtelen vagy kezdet nélküli tartománynál a kezdő- vagy végérték `nil`, de a tartomány definiálásakor a `nil` elhagyható.

A kezdet nélküli és végtelen tartományok akkor hasznosak, ha például egy stringet az elejétől vagy a végéig szeretnél feldarabolni.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
Ha nem gyűjteményen használod, a végtelen tartomány végtelen sorozatot eredményezhet, ezért óvatosan bánj vele.
~~~~

## String-tartományok

A stringek tartományokban is használhatók, így két string közötti stringek intervallumát kaphatod meg.
Bizonyos stringekkel a viselkedése kissé váratlan lehet, ezért óvatosan használd.

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
