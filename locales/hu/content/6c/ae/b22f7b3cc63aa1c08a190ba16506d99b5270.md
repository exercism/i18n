# Felesleges return

A Scala bevált gyakorlatai szerint a `return` kulcsszót kerülni kell. Scalában egy függvény utolsó kifejezésének eredménye implicit módon visszaadódik. A `return` explicit megadása egy függvény végén nem szándékolt mellékhatásokkal járhat. [Say No To Return](https://blog.knoldus.com/scala-best-practices-say-no-to-return/).
