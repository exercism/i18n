# Bevezetés

## Felsorolások

A C# `enum` típusa névvel ellátott állandók rögzített halmazát jelöli (ez a felsorolás). Legfőbb célja, hogy típusbiztos módot adjon a numerikus állandókkal való munkához, és hogy a lehetséges értékeket egy előre meghatározott halmazra korlátozza. Egy egyszerű felsorolás így definiálható:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Ha nem adod meg őket kifejezetten, a felsorolás tagjai automatikusan növekvő egész értékeket kapnak, az első érték pedig a nulla lesz. Az értékeket kifejezetten is megadhatod:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
