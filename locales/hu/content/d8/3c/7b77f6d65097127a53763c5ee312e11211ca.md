# Bevezetés

## Megjegyzések

A Common Lisp lehetővé teszi a programozó számára, hogy „megjegyzéseket” írjon, amelyeket a számítógép figyelmen kívül hagy.
Az egysoros megjegyzések egy vagy több pontosvesszővel (`;`) kezdődnek, és néha láthatod a következőt:

```lisp
(code...) ; => value
```

Ahol a megjegyzés arra szolgál, hogy jelezze, milyen értéket ad vissza a Common Lisp a sorban lévő kód futtatása után.

Idiomatikus, hogy egy pontosvesszőt használunk egy rövid megjegyzéshez a sor végén, kettőt egy hosszabb megjegyzéshez egy kódrészlet felett, hármat egy hosszú megjegyzéshez, amely leír valamit, például egy függvényt, és négyet egy olyan megjegyzéshez, mint egy fejléc a forrásfájl tetején.

## Cons

Minden Common Lisp objektum vagy „atom” (egyetlen, oszthatatlan érték), vagy „cons” (amit a „cons” konstruktor függvény épít fel).
Egy cons két részből áll: az első elemből és a többi elemből.
Történelmi okokból ezt a két részt `car`-nak és `cdr`-nek nevezik.
Amikor ezeket a consokat kódként értékeljük ki, az első elem (`car`) a meghívott függvényt képviseli, míg a többi elem (`cdr`) a függvény argumentumait:

```lisp
(<function> <arg1> <arg2> ... <argN>)
; ^ car ^  |        ^ cdr ^
```

## Kifejezések

Minden Common Lisp kód S-kifejezésekből (szimbolikus kifejezésekből) áll. Ezeket röviden sexpr-eknek hívják. Minden sexpr vagy atom, vagy cons. Amikor az S-kifejezéseket kiértékeljük, automatikusan visszaadnak valamilyen értéket, amely a kifejezés helyére kerül. Amikor saját függvényeket írsz (a `defun` használatával), a `defun` törzsében lévő utolsó érték automatikusan visszaadódik:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```

## Szimbólumok

A szimbólumok a Common Lispben speciális értékek, amelyek más értékekre mutathatnak, vagy _kulcsszavak_ esetében önmagukra.
Amikor a Lisp kiértékeli a szimbólumokat, azok helyére a mutatott értékek kerülnek:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

Vedd figyelembe, hogy a kulcsszavakat egy kezdő kettőspont (`:`) jelöli.

Az idézés, vagyis a `'` hozzáadása egy S-kifejezés elé, arra utasítja a Lispt, hogy ne értékelje ki azt a kifejezést.
Azzal, hogy idézőjelet tettünk a `'foo` elé a `defun` példánkban, elkerültük, hogy a Lisp megpróbálja kikeresni (és nem találja) azt, amire a `FOO` mutatott volna, és helyette magát a `FOO` értéket adta vissza.
Ha a `FOO` nincs sehol definiálva a programunkban:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

Egyelőre ezt tekintheted egyszerűen úgy, mint egy módot arra, hogy szimbólumokat adj vissza egy függvényből, de később újra elővesszük az idézést, és a jövőbeli tanulófeladatokban tovább vizsgáljuk a következményeit.
