# Kiegészítés az utasításokhoz

## Kimeneti formátum

A tanuló növényeit string formájában add ki, vesszővel és szóközzel elválasztva.

## Fenntartott memória

A diagram string puffere a lineáris memória 1024-2047. bájtjait használja.
A tanuló string puffere a lineáris memória 2048-3071. bájtjait használja.

A bemeneti stringek igény szerint helyben is módosíthatók.
