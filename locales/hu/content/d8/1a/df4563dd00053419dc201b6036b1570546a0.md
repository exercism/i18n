# Bevezetés

A Common Lisp többféle feltételes kifejezést kínál, amelyek között a fő különbség az, hogy hány ágat támogatnak.

- A `when` és az `unless` egyetlen ágat tesz lehetővé:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

A feltételkifejezés utáni rész több kifejezésből is állhat.

- Az `if` a klasszikus if-then-else szerkezetet biztosítja:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Ne feledd, hogy a then- és az else-ág egyaránt csak egyetlen kifejezés lehet.

- A `cond` lehetővé teszi, hogy több águnk legyen anélkül, hogy egymásba ágyaznánk az `if` kifejezéseket:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Ne feledd, hogy a feltételkifejezés után tetszőleges számú kifejezés állhat.

- A `case` a klasszikus „switch” stílusú szerkezetet kínálja: egyetlen értéket vet össze több ággal:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Ne feledd, hogy a `cond`-hoz hasonlóan itt is tetszőleges számú kifejezés állhat a feltételkifejezés után.
