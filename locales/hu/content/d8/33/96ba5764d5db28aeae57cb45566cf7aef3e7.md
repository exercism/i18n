# Névjegy

A [repeat-while ciklusok][repeat-loops] hasonlítanak a while ciklusokhoz, abban viszont különböznek, hogy a Boolean-kifejezés a ciklus törzsének végrehajtása _után_ jelenik meg, és ekkor értékelődik ki. Emiatt ezek a ciklusok mindig lefutnak legalább egyszer.

```swift
repeat {
  print("This runs at least once")
} while false
print("Loop done")

// prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
