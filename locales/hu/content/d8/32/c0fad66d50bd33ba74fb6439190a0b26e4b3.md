# Utasítások

Ebben a feladatban egy szerepjátékban játszol, ahol különböző típusú harcosok harcolhatnak egymás ellen.
A játéknak minden harcostípusra más szabályai vannak.
Két konkrét típusra összpontosítunk: a Wizard és a Warrior típusra.

A Warrior típusra ezek a szabályok érvényesek:

- A Warrior soha nem sebezhető.
- A Warrior `6` pont sebzést okoz, ha a harcos, akit megtámad, nem sebezhető.
- A Warrior `10` pont sebzést okoz, ha a harcos, akit megtámad, sebezhető.

A Wizard típusra ezek a szabályok érvényesek:

- A Wizard előre elkészíthet egy varázslatot.
- A Wizard sebezhető, kivéve, ha előre elkészített egy varázslatot.
- A Wizard `12` pont sebzést okoz, ha előre elkészített egy varázslatot.
- A Wizard `3` pont sebzést okoz, ha nem készített elő varázslatot.

## 1. Hozd létre a Warrior osztályt

Hozz létre egy új `Warrior` nevű osztályt.
Ez az osztály a meglévő `Fighter` osztályból örököljön.

## 2. A Warrior leírása

Frissítsd a `Warrior` osztályt úgy, hogy a `toString()` metódusa leírja, milyen típusú harcosról van szó.
A metódusnak a `"Fighter is a Warrior"` stringet kell visszaadnia.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Tedd sebezhetetlenné a Warriorokat

Frissítsd a `Warrior` osztályt úgy, hogy az `isVulnerable()` metódusa mindig `false` értéket adjon vissza.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Számítsd ki a Warrior sebzéspontjait

Frissítsd a `Warrior` osztályt úgy, hogy a `getDamagePoints(Fighter)` metódusa a fenti szabályok szerint kiszámítsa a Warrior által okozott sebzést.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Hozd létre a Wizard osztályt

Hozz létre egy másik új `Wizard` nevű osztályt.
Ez az osztály szintén a meglévő `Fighter` osztályból örököljön.

## 6. A Wizard leírása

Frissítsd a `Wizard` osztályt úgy, hogy a `toString()` metódusa leírja, milyen típusú harcosról van szó.
A metódusnak a `"Fighter is a Wizard"` stringet kell visszaadnia.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Tedd lehetővé, hogy a Wizardok varázslatot készítsenek elő, és tedd őket sebezhetővé, ha nem készítettek elő varázslatot

Frissítsd a `Wizard` osztályt úgy, hogy hozzáadj egy `prepareSpell()` nevű metódust.
Az osztálynak emlékeznie kell rá, mikor hívják meg ezt a metódust, és biztosítania kell, hogy az `isVulnerable()` metódusa csak akkor adjon vissza `false` értéket, ha egy varázslat elő van készítve.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Számítsd ki a Wizard sebzéspontjait

Frissítsd a `Wizard` osztályt úgy, hogy a `getDamagePoints(Fighter)` metódusa a fenti szabályok szerint kiszámítsa a Wizard által okozott sebzést.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
