Ez a feladat a lehetséges megoldások széles skáláját kínálja, külső crate-ek segítségével kombinálva. Hogy a munka mennyisége kezelhető maradjon, ez a dokumentum a lehetőségek egy kis válogatását tartalmazza. A Crossbeam-megoldások fogalomkészlete hasonló az itt felsoroltakhoz, a Rayon pedig csak egy részhalmazt igényel.

## Általános

- Stringek: konkrétan itt a `str` mindig tényező
- Unicode: az ASCII- és a Unicode-metódusok teljesítménybeli/funkcióbeli engedményei. A benchmark torzul, ha a benchmark Unicode-metódusokat használ, a megoldás pedig ASCII-metódusokat.
- Iterátorok: a bemeneten vagy annak darabjain iterálva.
- Gyűjtemények: `HashMap` fölött iterálva és `Entry` használatával. A handle-eket általában `Vec`-be gyűjtik.
- Referenciák
- Számok: konkrétan az `Add` trait
- For ciklus: iterátorban nem lehet szálakat joinolni a `move` miatt.
- **Opcionális** Láthatóság: az implementációs részletek maradjanak nem nyilvánosak
- **Opcionális** szeletek: a `.chunks()` gyakran használt metódus a bemenet felosztására munkaszálakhoz. Alternatívaként részszeleteket használnak.
- **Opcionális** Magasabb rendű függvények: a `HashMap`-ek egyesíthetők egy magasabb rendű függvénnyel és egy iterátorral.
- **Opcionális** Típusok: a bemenet felosztásához egész számokat alakíthatunk lebegőpontos értékekké a kerekítés alkalmazásához.
- **Opcionális** Crate-ek

## Std megközelítés csatornákkal vagy anélkül

- Párhuzamosság - altéma: szálak indítása/joinolása.
- Iterátorok - altéma: lusta kiértékelés; ugyanannak az iterátornak a használata a szálak indításához és joinolásához megakadályozza a párhuzamosságot.
- Élettartamok - altémák: `'static lifetime` és explicit `move` szemantika
- Iterátorok/élettartamok - altéma: fogyasztó iterátorok; szálakat nem lehet joinolni iterátor használatával.
- Option típus: szál- vagy csatornaeredmények kicsomagolása
- Függvények: konkrétan magasabb rendű függvények szükségesek a szálak indításához. A closure-ök itt egy lehetőség.

## Std megközelítés csatornákkal

- Párhuzamosság - altéma: csatornák.
- Tuple-ok: a `mpsc::channel()` egy tuple-t ad vissza
- Destrukturálás: a tuple értékadáskor destrukturálható
- Élettartamok: `drop()`

## Alternatív megközelítés megosztott változókkal

- Referenciaszámlálás: összesített adatok megosztása szálak között referenciaszámlált gyűjteménnyel.
- **Dicséretes említés**: Párhuzamosság - altéma: mutexek. Ehhez a feladathoz nem szükséges/hasznos, de így is gyakori fogalom. Kapcsolódó: `RwLock`.

### Példa std-del és csatornákkal

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### Példa crate-tel és Arc-cal

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
