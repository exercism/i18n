# A match alapjai

A `match` operátor összehasonlít egy értéket minták sorozatával, majd aszerint futtat kódot, hogy melyik minta illeszkedik.

## Literálok illesztése

A legalapvetőbb szinten a `match` összehasonlít egy értéket több lehetséges mintával, és az első illeszkedő ágat választja. Mindig csak egy ág választódik ki, és a vezérlés soha nem „folyik át” egy másik ágba. A `match` egy kifejezés, amelynek értéke lehet.

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## Kimerítőség

Az illesztés mindig kimerítő: a Rust nem fordítja le a programot, ha lehetséges, hogy egy érték átcsúszik a réseken. Ebben segít, hogy a `_` egy helyettesítő karakter, amely bármire illeszkedik.

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## Illesztés vezérlési folyamként

Bár a `match` kifejezésként értéket állíthat elő, utasításként is használható pusztán a vezérlési folyam irányítására.

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## Tartományok illesztése

A match ágakat nem kell egyetlen értékként megadni; tartományok is lehetnek.

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## Vagy-minták

Egy match ág illeszkedhet több lehetséges opció egyikére is, ha a `|` tokent elválasztóként használjuk.

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## Strukturális illesztés és kötés

Az illesztés létrehozhat egy kötést, amely egy adott match ágon belül érvényes. Ez különösen hasznos olyan enumok kicsomagolásához, amelyek adatot hordoznak a változataikban.

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```

Erről a témáról bővebben a `match-advanced` fogalomban.
