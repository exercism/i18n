# Bevezetés

A JavaScriptben a _template stringek_ segítségével kifejezéseket ágyazhatsz be a stringekbe, amit string-interpolációnak is neveznek.
Ez a funkció kibővíti a beépített [`String`][string-reference] globális objektum képességeit.

JavaScriptben úgy hozhatsz létre template stringeket, hogy a szöveget backtickek közé teszed.
Ezek nemcsak új sorokat és más speciális karaktereket engednek meg a szövegben, hanem változókat és más kifejezéseket is beágyazhatsz beléjük.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

A fenti példában a backtickek, (<code>\`\`</code>), jelölik a template stringet. A `${...}` az a helyőrző, amelyet a behelyettesítéshez használunk.
A nem string típusú értékek _implicit módon_ stringgé alakulnak.
Erről a [típuskonverzió][type-conversion-concept] fogalomban olvashatsz.
A template stringekben bármilyen típusú kifejezést használhatsz.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Amikor a stringeket több sorba tördelve szeretnéd formázni:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Ha egy hagyományos stringben szeretnél sortörést megjeleníteni a template string használata helyett (vagyis nem backtickek között), használhatod a `\n` sortörés escape-szekvenciát:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

A rendelkezésre álló behelyettesítési lehetőségekkel logikát is vihetsz a folyamatba, hogy eldöntsd, mi legyen a kimeneti string.
A logika egyik kezelési módja a [feltételes operátor][ternary-operator] használata.
Ez ugyanazt a feltételes `if/else` működést adja, kicsit más formában.

Ha logikát szeretnél vinni a template string szintaxisába:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
