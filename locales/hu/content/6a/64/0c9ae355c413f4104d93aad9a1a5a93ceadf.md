# Utasítások

Ebben a feladatban ismét a távirányítós autókkal fogsz dolgozni.

Kifejlesztettek egy kísérleti autót, és a tesztpályát alkalmassá kell tenni arra, hogy mind a sorozatgyártású, mind a kísérleti modelleket kezelni tudja. A két típusú autót már megépítették, és neked kell megoldást találnod arra, hogy mindkettőt kezelni tudd a tesztpályán.

Ráadásul a sorozatgyártású autók kezdenek sikereket elérni. A csapatvezető szeretné fenntartani a versenyszellemet azzal, hogy közzéteszi a sorozatgyártású autók rangsorát.

## 1. Tedd lehetővé, hogy az autókat ugyanazon a tesztpályán lehessen vezetni

Adj hozzá egy metódust az `IRemoteControlCar` interfészhez, amellyel elérhetővé válnak a `Drive()` implementációi mindkét autótípus számára.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. Tedd lehetővé, hogy össze lehessen hasonlítani a különböző modellek által a tesztpályán megtett távolságot

Adj hozzá egy tulajdonságot az `IRemoteControlCar` interfészhez, amellyel elérhetővé válnak a `DistanceTravelled` tulajdonság implementációi mindkét autótípus számára.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. Tedd lehetővé a sorozatgyártású autók rangsorolását

Implementáld az `IComparable<T>` interfészt a `ProductionRemoteControlCar` osztályban. Az autók alapértelmezett rendezési sorrendje a győzelmek számának növekvő sorrendje legyen.

Implementáld a statikus `TestTrack.GetRankedCars()` metódust úgy, hogy a kapott autókat a győzelmek számának növekvő sorrendjében adja vissza.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
