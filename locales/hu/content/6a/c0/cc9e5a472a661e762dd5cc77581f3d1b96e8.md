# Tippek

## Általános

- Olvass a stringekről a hivatalos [Első lépések útmutatóban][getting-started-strings].
- Böngészd a [függvényeket, amelyeket a _String modul_ kínál][string-module-functions], hogy felfedezd, milyen műveleteket kínál a stringeken az Elixir standard könyvtára.

## 1. A név első betűjének lekérése

- Van egy [beépített függvény][string-first], amellyel lekérheted egy string első karakterét.
- Több [beépített függvény][string-trim] is létezik, amelyek egy string elejéről, végéről vagy mindkettőjéről eltávolítják a whitespace-karaktereket.

## 2. Az első betű formázása kezdőbetűvé

- Van egy [beépített függvény][string-upcase], amely egy string összes karakterét nagybetűssé alakítja.
- Van egy [operátor][kernel-concat], amely két stringet fűz össze.

## 3. A teljes név felbontása keresztnévre és vezetéknévre

- Van egy [beépített függvény][string-split], amely whitespace-karakterek mentén bontja fel a stringet.
- Egy lista első néhány elemét mintaillesztéssel rendelheted változókhoz.

## 4. A kezdőbetűk elhelyezése a szívben

- Van egy speciális szintaxis, amellyel [kifejezést interpolálhatsz][string-interpolation] egy stringbe.
- Van egy speciális szintaxis [többsoros stringek][heredoc-syntax] írására, amellyel nem kell escape-elni a sortöréseket.
