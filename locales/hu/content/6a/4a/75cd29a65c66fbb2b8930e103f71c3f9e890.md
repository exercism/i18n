# Ciklusok

A Rustban a ciklusok arra szolgálnak, hogy egy kódrészletet ismételten végrehajts, amíg meg nem mondod nekik, hogy álljanak le, vagy amíg egy bizonyos feltétel nem teljesül.

A ciklusok legalapvetőbb változata a `loop` kulcsszót használja:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

A fenti kódrészlet végtelen ciklust hoz létre. A ciklusból való kilépéshez a break kulcsszót használd:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## Ciklusok `for` és `while` használatával

A `loop` kulcsszó mellett `for` és `while` ciklusokat is készíthetsz.

A `for` ciklus egy gyűjtemény vagy iterátor elemein való iterálásra szolgál.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

A tartományok is iterátorok, ezért nagyon kényelmes a `for` ciklussal bejárni őket:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

A while ciklus addig ismétli a kódot, amíg egy feltétel teljesül. A korábbi példát átírhatnánk while ciklussal a következőképpen:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

A ciklusokról további információért nézd meg a Rust könyvben a [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops) részt.
