# Bevezetés

A rekurzió egy módja annak, hogy egy függvényben ismételjünk kódot úgy, hogy a függvény önmagát hívja.
Ez egy másik módja a ciklusnak/iterációnak. A ciklusokhoz hasonlóan a függvénynek itt is ki kell értékelnie egy Boolean kifejezést, hogy tudja, mikor álljon le.
A ciklusokkal ellentétben a soha véget nem érő rekurzió nem fut a végtelenségig.
Az egyes függvényhívásokban használt értékek a saját veremkeretükbe kerülhetnek.
Ha a függvényhívások mennyisége több helyet foglal el, mint amennyi a veremben van, az veremtúlcsordulási hibát eredményez.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Ez a következőt írja ki:

```
The number is 1
The number is 2
After recursion
```

Előfordulhatnak olyan helyzetek, amelyek rekurzióval kifejezve olvashatóbbak és/vagy könnyebben végiggondolhatók, mint ciklusokkal kifejezve.
