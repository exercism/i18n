# Bevezetés

## Reguláris kifejezések

Az Elixirben a reguláris kifejezések a **PCRE** specifikációt követik (**P**erl **C**ompatible **R**egular **E**xpressions, azaz Perl-kompatibilis reguláris kifejezések), akárcsak más népszerű nyelvek, például a Java, a JavaScript vagy a Ruby.

A `Regex` modul függvényeket kínál a reguláris kifejezésekkel való munkához. A `String` modul néhány függvénye is elfogad reguláris kifejezéseket argumentumként.

~~~~exercism/note
Ez a feladat feltételezi, hogy már ismered a reguláris kifejezések szintaxisát, beleértve a karakterosztályokat, a mennyiségjelölőket, a csoportokat és az elfogásokat.

Ha fel szeretnéd frissíteni a reguláris kifejezésekről szerzett tudásodat, nézd meg az alábbi források egyikét: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

### Sigils

A reguláris kifejezések létrehozásának leggyakoribb módja a `~r` sigil használata.

```elixir
~r/test/
```

Ne feledd, hogy az Elixir összes sigilje [különböző típusú határolójelet][sigils] támogat, nem csak a `/`-t.

### Illesztés

A `=~/2` operátorral olyan reguláris kifejezés illesztését végezheted el, amely `boolean` eredményt ad vissza. Másik lehetőségként a `Regex` modulban és a `String` modulban is található `match?/2` függvény.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### Elfogás

Ha egy egyszerű logikai ellenőrzés nem elég, a `Regex.run/3` függvénnyel kérheted le az összes elfogás listáját (vagy `nil`-t, ha nem volt találat). A visszaadott lista első eleme mindig a teljes reguláris kifejezésre illeszkedő találat, a további elemek pedig az illeszkedő csoportok.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### Módosítók

Egy reguláris kifejezés viselkedése speciális jelzők hozzáfűzésével módosítható. Ha sigillel hozol létre reguláris kifejezést, a módosítókat a második határolójel után add meg.

A gyakori módosítók:
- `i` - a keresést kis- és nagybetűtől függetlenné teszi.
- `u` - engedélyezi az Unicode-specifikus mintákat, például a `\p`-t, és eléri, hogy a `\w`, `\s` és hasonló karakterosztályok az Unicode karakterekre is illeszkedjenek.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
