# Telepítés


## GHCup telepítése

A Haskell-eszközök telepítésének ajánlott módja a [GHCup][ghcup] használata.

A GHCuppal a telepített fordítókat, a projekt- és csomagkezelőket, valamint a nyelvi szervert kezelheted.


## A Stack telepítése

Az Exercism feladatainak megoldásához csak a Stackre van szükséged.

A Stack telepítéséhez futtasd a GHCup telepítőparancsát vagy -szkriptjét.
Kövesd az alapértelmezett beállításokat, de jelezd, hogy a Stacket is telepíteni szeretnéd.

Véletlenül kihagytad a Stack telepítését?
Semmi baj: csak futtasd utólag a `ghcup install stack` parancsot.

A GHCup a következőket telepíti:

- **Egy fordítóprogramot** (GHC: a Glasgow Haskell Compiler)

  Szigorúan véve nincs rá szükséged az Exercism-höz, de jól jön, ha a feladatkönyvtárakon kívül szeretnél a [GHCi][ghc-guide-ghci]-val játszani.

- **Cabal**

  Egy projekt- és csomagkezelő.
  Az Exercism-höz nincs rá szükséged.

- **Stack**

  Az a projekt- és csomagkezelő, amelyet az Exercism-höz fogsz használni.
  Gondoskodik róla, hogy minden egyes projekthez (feladathoz) a megfelelő fordító és a szükséges könyvtárak legyenek elérhetők.

A telepítés sikerességének ellenőrzéséhez futtasd az alábbi parancsok valamelyikét:

- `ghcup list`: a siker egy hosszú eszközverzió-listának tűnik, amelyben a Stack telepítettként van megjelölve
- `stack --version`: a siker így néz ki: `Version 2.7.5, Git revision ...`


## A megfelelő GHC-verzió

A Stack automatikusan letölti és telepíti a GHC-t, amikor szükség van rá.
A telepítést elindíthatod és ellenőrizheted, ha a következő parancsokat futtatod egy terminálban:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

Ha ez valami ilyesmit ír ki:

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

akkor a GHC megfelelően telepítve van.


## Állítsd be a szerkesztődet a Haskell használatához

A Haskell-támogatást a Haskell Language Server (HLS) nyújtja.
A nyelvi támogatás nem kötelező, de erősen ajánlott.


### Visual Studio Code (ajánlott)

Csak szerezd be a [Visual Studio Code Haskell-kiterjesztését][vscode-haskell].
Ez a GHCup segítségével automatikusan telepíti a HLS-t, és ezzel minden készen is áll.

**Megjegyzés:** a frissen letöltött feladatoknál a HLS-nek gondjai lehetnek az indulással.
Ha ez történik, futtasd a `stack test` parancsot, és indítsd újra a nyelvi szervert.


### Más szerkesztők

Lásd a [HLS szerkesztőkonfigurációs dokumentációját][hls-editor-config].
Lehet, hogy kézzel kell telepítened a HLS-t.
Ehhez futtasd a `ghcup install hls` parancsot.
