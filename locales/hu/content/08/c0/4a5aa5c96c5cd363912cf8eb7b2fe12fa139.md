# Bevezetés

A Java elsődleges objektumorientált építőeleme az _osztály_, amely adatok (_mezők_) és viselkedés (_metódusok_) kombinációja.
Az osztály mezőit és metódusait együtt _tagoknak_ nevezzük.

A tagokhoz való hozzáférést hozzáférés-módosítókkal szabályozhatod, amelyek közül a két leggyakoribb:

- `public`: a tagot bármely kód elérheti (nincs megkötés).
- `private`: a tagot csak az ugyanabban az osztályban lévő kód érheti el.

Az osztályra gondolhatsz úgy, mint egy sablonra, amellyel az adott osztály példányait hozod létre.
Egy osztály példányának (más néven _objektumának_) létrehozásához a `new` kulcsszót használjuk:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

A mezőknek típusuk és nevük van (camelCase írásmóddal definiálva), és egy osztályban bárhol definiálhatók (a konvenció szerint PascalCase írásmóddal):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Egy mezőnek opcionálisan adhatsz kezdőértéket.
Ha egy mező _nem_ kap kezdőértéket, akkor a típusának alapértelmezett értékét veszi fel.
Egy példány mezőértékeit pontjelöléssel érheted el és frissítheted.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

A privát mezőket általában egy metódus meghívásának mellékhatásaként frissítjük.
Az ilyen metódusok jellemzően nem adnak vissza értéket; ilyenkor a visszatérési típus `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
