# Bemutatás

Go-ban az egyenlőség- és rendezési operátorokkal hasonlíthatunk össze értékeket.
Hat ilyen operátorunk van:

| Összehasonlítás   | Operátor  |
| ------------------| --------- |
| egyenlő           | `==`      |
| nem egyenlő       | `!=`      |
| kisebb            | `<`       |
| kisebb vagy egyenlő | `<=`    |
| nagyobb           | `>`       |
| nagyobb vagy egyenlő | `>=`   |

Az összehasonlítás eredménye mindig egy Boolean érték:

```go
a := 3

a != 4 // true
a > 5  // false
```

## Egyenlőségoperátorok

A `==` és a `!=` egyenlőségoperátorok rendre azt vizsgálják, hogy egy érték egyenlő-e egy másikkal, vagy sem.
Az egyenlőségoperátorokat a Go legtöbb típusán használhatjuk.
Íme néhány gyakori példa:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## Rendezési operátorok

A rendezési operátorok azt ellenőrzik, hogy az egyik érték nagyobb-e (`>`), nagyobb vagy egyenlő-e (`>=`), kisebb-e (`<`), illetve kisebb vagy egyenlő-e (`<=`), mint egy másik érték.
Ez a fajta összehasonlítás számokra, byte-okra, rune-okra és stringekre érhető el.
A stringek összehasonlításakor a szótári sorrendet követjük (amit lexikografikus sorrendnek is neveznek).

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
