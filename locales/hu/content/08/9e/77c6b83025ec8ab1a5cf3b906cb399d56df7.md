# Az Alapokról

Az Alapok fogalom bemutatta a Go-t mint statikusan típusos, fordított programozási nyelvet.
A nyelvet gyakran Golangnak nevezik a korábbi domainneve, a golang.org miatt, de a valódi neve Go.

Az Alapok fogalom három fontos nyelvi jellemzőt mutat be: csomagok, függvények és változók.

## Csomagok

A Go-alkalmazások csomagokba szerveződnek.
A csomag az ugyanabban a könyvtárban található forrásfájlok gyűjteménye.
Az egy könyvtárban lévő összes forrásfájlnak ugyanazt a csomagnevet kell viselnie.
Az a szokás, hogy a csomag neve az importálási útvonal utolsó könyvtára.
Például a [„math/rand” csomag](https://golang.org/src/math/rand/) fájljai a `package rand` utasítással kezdődnek.
Amikor egy csomagot importálunk, csak azok az entitások (függvények, típusok, változók, konstansok) használhatók / érhetők el, amelyek neve nagybetűvel kezdődik.
A Go-ban ajánlott elnevezési stílus az, hogy az azonosítókat `camelCase` stílusban nevezzük el, kivéve azokat, amelyeket csomagokon át elérhetőnek szánnak; ezek `PascalCase` stílusúak.

```go
package lasagna
```

## Változók

A Go statikusan típusos, ami azt jelenti, hogy minden változónak fordítási időben [meghatározott típussal kell rendelkeznie](https://en.wikipedia.org/wiki/Type_system).

A változókat úgy is definiálhatjuk, hogy kifejezetten megadjuk a típusukat:

```go
var explicit int // Explicitly typed
```

Használhatsz kezdőértéket is, és a fordító a kezdőérték típusához igazítja a változó típusát.

```go
implicit := 10   // Implicitly typed as an int
```

A deklarálás után a változóknak a `=` operátorral adhatunk értéket.
A deklarálás után egy változó típusa soha nem változhat meg.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Konstansok

A konstansok ugyanúgy tárolnak adatot, mint a változók, de értékük a program futása közben nem változhat meg.

A konstansokat a `const` kulcsszóval definiáljuk, és lehetnek számok, karakterek, stringek vagy Booleanok:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Függvények

A Go-függvények nulla vagy több paramétert fogadnak el.
A paraméterek típusát kifejezetten meg kell adni, típuskövetkeztetésre nincs lehetőség.

A függvények a `return` kulcsszóval adnak vissza értékeket.

Egy függvényt úgy hívunk meg, hogy megadjuk a függvény nevét, és minden paraméteréhez átadunk egy-egy argumentumot.

Jegyezd meg, hogy a Go kétféle megjegyzést támogat.
Az egysoros megjegyzéseket `//` előzi meg, a többsorosakat pedig `/*` és `*/` közé írjuk.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
