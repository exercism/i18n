# Tesztek

A teszteket így futtatod:

```bash
$ wrenc exercise-name.spec.wren
```

Például a `hello-world` feladathoz:

```bash
$ wrenc hello-world.spec.wren
```


## A kihagyott tesztek megértése

A `skip` metódus arra utasítja a tesztcsomagot, hogy egy adott tesztet ne futtasson le.

- Miért vannak kihagyva?

Hogy a felhasználók egyszerre csak egy tesztre összpontosíthassanak, és a megoldás
fejlesztése közben egyenként engedélyezhessék őket.

- Hogyan lehet engedélyezni őket?

Egy kihagyott teszt:

```js
// this test will be skipped and not run
skip.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

Egyszerűen cseréld ki a `skip.test`-et `do.test`-re.

```js
// now the test will be run normally
do.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

## Az első Wren-modulod elkészítése

Ezen a kurzuson a tesztek úgy töltik be a megoldásodat, hogy Wren-modulként importálják:
`import "./bob" for Bob`. A megoldásod exportálásához nincs szükség különleges szintaxisra.
Egyszerűen nevezd el `Bob`-nak az osztályodat, hogy illeszkedjen a `for
Bob` importáló utasításokhoz, és máris minden működni fog.

```javascript
class Bob {
  static hey(message) {
    // Your solution to the exercise goes here
  }
}
```

A modulokról további információt a
[Wren modularitási dokumentációjában][modularity] találsz.
Hogy könnyebb legyen az indulás, minden feladat könyvtárában van egy _skeleton_ Wren-fájl.

[modularity]: https://wren.io/modularity.html
