# Bevezetés

A vezérlési szerkezetek a Cairoban lehetővé teszik, hogy feltételek és ismétlések alapján szabályozd, hogyan fusson le a programod.

## Feltételes végrehajtás

Az `if` kifejezésekkel feltételek alapján hajthatsz végre kódot:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

Az `if` egy kifejezés, ezért értéket is visszaadhat:

```rust
let result = if condition { 5 } else { 10 };
```

## Ciklusok

A `loop` segítségével ismételhetsz kódot.
A ciklus a végtelenségig fut, hacsak meg nem állítod. Ha egy feltétel teljesül, a `break`-kel léphetsz ki belőle.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

A ciklusok a `break` segítségével adhatnak vissza értéket:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

A `continue` segítségével ugorhatsz a következő iterációra:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
