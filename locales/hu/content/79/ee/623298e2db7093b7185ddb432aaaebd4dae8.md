# Kiegészítés az utasításokhoz

## Kimeneti formátumok

A `treeFromTraversals` függvénynek egy 3 tulajdonságból álló objektumot kell visszaadnia:

- `value`: az aktuális csomópont értéke
- `left`: egy objektum, amely a csomópont bal oldali gyermekét tartalmazza
- `right`: egy objektum, amely a csomópont jobb oldali gyermekét tartalmazza

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

Ha a fa üres, üres objektumot kell visszaadni.
