# Tippek

## Általános

- Talán olyan DSL-t szeretnél létrehozni, amely címkék és rekordok listáin alapul, valahogy így:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- Vagy esetleg inkább a függvényhívások láncolatán alapuló DSL-t szeretnél, valahogy így:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  Vagy talán egészen más terved van?
  Hajrá, csináld!

- Ugyanakkor a DSL általában akkor jobb, ha világos, tömör és nem túl meglepő (például a `minus` függvény kivonásra való, nem arra, hogy élt építs vele két csomópont között, mint a `node("a") - node("b")` esetében).
