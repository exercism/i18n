Az UMBRA erői megint mozgolódnak, és rajtad múlik, hogy meghiúsítsd a legújabb tervüket.
A hírszerző részlegünk arról értesített minket, hogy a Minionok bűzbombát készülnek elsütni a kormányzó bálján.

Mivel a minionok olyan ügyetlenek, gyakran véletlenül aktiválják a bűzbombákat a laborjaikban és az irodáikban.
És mivel folyton elfelejtik, hogyan kell hatástalanítani a bűzbombáikat, létrehoztak egy rendszert, amely legyártja a hatástalanítási utasításokat. Ezek a bomba azonosítószáma alapján megadják, milyen sorrendben kell elvágni a vezetékeket.

A feladatod, hogy megírd azt a kódot, amellyel hatástalanítani tudod a bálon a bűzbombát, mielőtt elsül.

## 1. Írj closure-t, amely megcserél két vezetéket

Minden bűzbombán három különböző színű vezeték van.
Írj egy closure-t, amely átvesz egy `(String, String, String)` tuple-t, és visszaadja a tuple-t úgy, hogy az első két elem sorrendje felcserélődik.
Rendeld ezt a closure-t a `flip` névhez.

Fontos megjegyezni, hogy a típusnak `ChangeClosure`-nek (vagy egy sendable típusnak) kell lennie; a típusdefiníció a stub fájlban található.
Ellenkező esetben a kód nem fordul le.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Írj closure-t, amely elforgatja a vezetékeket

Írj egy closure-t, amely átvesz egy `(String, String, String)` tuple-t, és visszaadja a tuple-t úgy, hogy a vezetékek sorrendje balra elforgatva.
Rendeld ezt a closure-t a `rotate` névhez.

Fontos megjegyezni, hogy a típusnak `ChangeClosure`-nek (vagy egy sendable típusnak) kell lennie; a típusdefiníció a stub fájlban található.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Készíts vezetékkeverő generátort

Ahhoz, hogy kitaláld, milyen sorrendben kell elvágni a bűzbomba vezetékeit, meg kell valósítanod egy függvényt, amely a bűzbomba azonosítószáma alapján legyártja a megfelelő keverőfüggvényt.

Valósítsd meg a függvényt:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

amely bemenetként átvesz egy closure-t, amely megcserél két vezetéket, és egy closure-t, amely elforgatja a három vezetéket, majd visszaad egy closure-t.
Ez a visszaadott closure átveszi a bűzbomba azonosítószámát és a három vezeték sorrendjét, majd kiszámítja, milyen sorrendben kell elvágni a vezetékeket.
Az azonosítószám nyolc bitből áll, és minden bit eldönti, hogy meg kell-e cserélni vagy el kell-e forgatni a vezetékeket.

Az azonosítószám minden bitjére, a jobb szélső bittel kezdve, a `flipper` closure-t alkalmazod a vezetékek tuple-jére, ha a bit 0, és a `rotator` closure-t alkalmazod, ha a bit 1; így megkapod a vezetékek új állapotát.
Miután mind a nyolc bitre alkalmaztad a hozzá tartozó closure-t, a vezetékek végső állapota adja meg azt a sorrendet, amelyben el kell vágni őket.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
