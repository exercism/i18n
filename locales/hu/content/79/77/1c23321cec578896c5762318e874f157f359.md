# Bevezetés

## Számok összehasonlítása

JavaScriptben a számokat az alábbi relációs és egyenlőségoperátorokkal lehet összehasonlítani.

| Összehasonlítás          | Operátor  |
| ------------------------ | --------- |
| Nagyobb, mint            | `a > b`   |
| Nagyobb vagy egyenlő     | `a >= b`  |
| Kisebb, mint             | `a < b`   |
| Kisebb vagy egyenlő      | `a <= b`  |
| (Szigorú) egyenlőség     | `a === b` |
| Nem (szigorú) egyenlőség | `a !== b` |

Az összehasonlítás eredménye mindig logikai érték, tehát vagy `true`, vagy `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## Stringek összehasonlítása

JavaScriptben a fenti összehasonlító operátorokkal stringeket is össze lehet hasonlítani.
Ilyenkor a szótár (lexikográfiai) sorrend érvényesül.
Az összes karakter pontos sorrendjének listáját [itt][utf-16-list] találod.

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Szigorú egyenlőség

Talán elgondolkodtál már azon, miért három egyenlőségjel jelöli az egyenlőségvizsgálatot JavaScriptben.
A `===` a _szigorú egyenlőség_ vizsgálatát jelöli, ami azt jelenti, hogy nem történik típuskonverzió, és a különböző típusú értékek sosem egyenlők.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

JavaScriptben az egyenlőségvizsgálat ajánlott módja a `===` és a `!==` használata.

Létezik a `==` és a `!=` is, amelyek a _nem szigorú egyenlőség_ vizsgálatát jelentik.
Kerüld ezeket, mert az összehasonlítás előtt implicit típuskonverziót alkalmaznak.
Az ilyen esetek kimenetele nehezen megjósolható, és néha nem az, amire számítanál.

```javascript
0 == false;
// => true
```
