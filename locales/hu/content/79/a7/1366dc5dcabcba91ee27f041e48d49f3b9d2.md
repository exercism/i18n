# Utasítások

Ebben a feladatban különféle típusú távirányítós autók közötti versenyeket fogsz megszervezni.
Minden autónak megvannak a maga jellemzői, és a torna szezonja során számos különböző pályán fut versenyeken.

~~~~exercism/note
A feladat függvényei egy C forrásfájlban vannak deklarálva a megadott szignatúrákkal.
Az x86-64-assembly kódodnak követnie kell ezeket az előírásokat.
~~~~

## 1. Hozz létre egy távirányítós autót

Definiáltál egy `car_t` struktúrát, amely egy távirányítós autót reprezentál:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

A `new_car` függvény x86-64 assemblyben való definiálásával tedd lehetővé egy távirányítós autó létrehozását.
A `battery` mező mindig a `100.0` értékkel kezdődik.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Hozz létre egy új pályát

A pályákat egy `track_t` struktúra reprezentálja:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

Az `enum surface_t` a pálya különböző burkolatait tartja nyilván:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

A `new_track` függvény x86-64 assemblyben való definiálásával tedd lehetővé egy új pálya létrehozását.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Hozz létre egy versenyeseményt

Minden versenyben legfeljebb 6 autó vesz részt, amelyek meghatározott számú kört futnak egy pályán.
A versenyeket egy `race_t` struktúra reprezentálja:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Definiálj egy `new_race` függvényt x86-64 assemblyben.
A kezdetkor még egyetlen autó részvétele sincs megerősítve a versenyre:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Erősítsd meg egy autó részvételét a versenyen

Amikor egy autó tulajdonosa kéri, hogy az részt vegyen egy versenyen, a részvétele csak akkor erősíthető meg, ha a lista még nem tele.

Definiálj egy `add_participant` függvényt x86-64 assemblyben.
Ha van hely még egy résztvevőnek a versenyben, az autó bekerül a listára, a számláló frissül, és a részvétele megerősítést nyer.
Ellenkező esetben a verseny szervezőinek tájékoztatniuk kell az autó tulajdonosát, hogy ezúttal nem tud részt venni.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Hozz létre egy tornát

A szezonra ütemezett versenyeket egy `tournament_t` struktúrában tartod nyilván:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Definiálj egy `add_race` függvényt x86-assemblyben, amely hozzáad egy versenyt a torna tömbjéhez, és frissíti a számlálóját is.
Feltételezheted, hogy a `races` tömbben mindig lesz elég hely az új verseny számára.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
