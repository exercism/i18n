# A fogalomról

A Common Lispben a hamis értékeket az üres lista (`()`) vagy a `nil` szimbólum képviseli.
Ezek az értékek idézve és idézés nélkül is leírhatók.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

A Lispben minden más érték igaznak számít.
Létezik egy speciális, állandó `t` szimbólum is, amely mindig egyenlő `t`-vel (ezért mindig igaz).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
