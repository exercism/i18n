# Bevezetés

A C#-ban a `null` literál egy érték hiányát jelöli. A _nullázható_ típus olyan típus, amely megengedi a `null` értékeket.

A C# 8.0 előtt a referenciatípusok mindig nullázhatók voltak, az értéktípusok viszont nem. Egy értéktípus azonban nullázhatóvá tehető, ha egy kérdőjelet (`?`) fűzünk hozzá.

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Ha egy olyan változó tagját éred el, amelynek az értéke `null`, a kód ugyan lefordul, futásidőben viszont `NullReferenceException` dobódik:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

Ennek a gyakori hibatípusnak az ellensúlyozására a C# 8 lehetővé teszi egy olyan funkció bekapcsolását, amely alapértelmezés szerint nem nullázhatóvá teszi a referenciatípusokat:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

A nullázható értékekkel való biztonságos munkához előbb ellenőrizd, hogy `null`-e az érték:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

A `??` operátorral alapértelmezett értéket adhatsz vissza, ha az érték `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

A `?.` operátorral biztonságosan hívhatsz meg tagokat egy esetleg `null` értéken:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
