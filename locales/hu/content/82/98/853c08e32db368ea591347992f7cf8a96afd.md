# Utasítások

Leendő varázslóként Elyse-nek gyakorolnia kell néhány alapvető dolgot. Van egy pakli kártyája, amivel szeretne trükközni.

Hogy a dolgok kicsit könnyebbek legyenek, csak az 1-től 10-ig terjedő kártyákat használja, így a paklija számokból álló tömbként ábrázolható. Egy adott kártya pozíciója a tömbben lévő indexnek felel meg. Ez azt jelenti, hogy a 0. pozíció az első kártyára utal, az 1. pozíció a másodikra, és így tovább.

<!-- prettier-ignore-start -->
~~~~exercism/note
Két függvény kivételével mindegyik frissítse a kártyák tömbjét, majd adja vissza a módosított tömböt. Ez egy gyakori munkamód, az úgynevezett Builder pattern, amivel a függvényeket szépen egymás után fűzheted.

A két kivétel a `getItem`, amely az adott pozíción lévő kártyát adja vissza, és a `checkSizeOfStack`, amely `true`-t ad vissza, ha a kapott méret megegyezik.
~~~~
<!-- prettier-ignore-end -->

## 1. Kérj el egy kártyát a pakliból

Egy kártya kiválasztásához add vissza a kapott pakli `position` indexén lévő kártyát.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Cserélj ki egy kártyát a pakliban

Mutass be egy kis kézügyességet, és cseréld ki a `position` indexen lévő kártyát a megadott cserekártyára.
Add vissza a módosított paklit.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Szúrj be egy kártyát a pakli tetejére

Varázsolj elő egy kártyát úgy, hogy egy új kártyát szúrsz a pakli tetejére.
Add vissza a módosított paklit.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Vegyél el egy kártyát a pakliból

Tüntess el egy kártyát úgy, hogy eltávolítod a pakliból az adott `position` pozíción lévő kártyát.
Add vissza a módosított paklit.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Vedd le a pakli felső kártyáját

Tüntess el egy kártyát úgy, hogy eltávolítod a pakli tetején lévő kártyát.
Add vissza a módosított paklit.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Szúrj be egy kártyát a pakli aljára

Varázsolj elő egy kártyát úgy, hogy egy új kártyát szúrsz a pakli aljára.
Add vissza a módosított paklit.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Vegyél el egy kártyát a pakli aljáról

Tüntess el egy kártyát úgy, hogy eltávolítod a pakli alján lévő kártyát.
Add vissza a módosított paklit.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Ellenőrizd a pakli méretét

Ellenőrizd, hogy a pakli mérete egyenlő-e a `stackSize` értékkel vagy sem.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
