# Bemutatás

A [komprehenzió][for] segítségével az _Enumerable_ értékek egyszerűen és deklaratívan alakíthatók át. Valójában _szintaktikai cukor_, amely megkönnyíti az enumerable-okon való iterálást Elixirben.

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

A komprehenziónak három része van:

1. _generátorok_:
   - Olyan szerkezetekből felsorolt értékek, amelyek megvalósítják az [_Enumerable_][enumerable] protokollt.
   - Mintaillesztő kifejezések a felsorolt értékek szétbontásához.
2. _Szűrők_: Boolean feltételek, amelyek kiválasztják, hogy a felsorolt értékek közül melyeket használjuk az új értékek létrehozásakor.
3. _Gyűjthetők_: Olyan szerkezet, amely megvalósítja a [_Collectable_][collectable] protokollt, és az új értékek gyűjtésére szolgál.

A komprehenziók lehetnek egysorosak és többsorosak. Ha egynél több generátort használunk, akkor a generált értékek [Descartes-szorzatát][cartesian-product] járjuk be. Ez azt jelenti, hogy az első generátor által generált minden érték pontosan egyszer párosul a második generátor által generált minden értékkel.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

A do-blokkban szereplő érték **az _Enumerable_-ból generált minden egyes értéknél** bekerül a _gyűjthetőbe_.

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

A mintaillesztés a komprehenzióban is előfordulhat, akár a `<-` bal oldalán, akár saját sorban.

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
