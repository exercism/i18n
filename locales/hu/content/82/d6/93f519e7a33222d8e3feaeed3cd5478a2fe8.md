# Kiegészítés az utasításokhoz

## Megvalósítás

Feltételezések:

1. A nulla a kimenetekben mindig [0] alakban jelenik meg [] helyett.
2. Semmilyen más esetben nem szerepelnek vezető nullák a kimenetekben.
3. A bemenetekben elfogadottak a vezető nullák.
4. A bemeneti számjegyek üres sorozata nullának számít, nem hibának.

A problémás eseteket úgy kezeld, hogy olyan hibát adsz vissza, amelynek az Error() metódusa
a következő üzenetek egyikét adja vissza:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
