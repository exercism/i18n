# Vektorok mint verem

A verem olyan lineáris adatszerkezet, amelyet arra optimalizáltak, hogy az egyik végéről érjük el. Találó hasonlat rá egy tűre fűzött papírköteg: az új lapokat mindig ugyanarra a végére fűzzük, a lapokat pedig fordított sorrendben vesszük le, mint ahogy felkerültek. Amelyik lap előbb került fel, az kerül le utoljára, amelyik pedig utoljára került fel, az kerül le először.

A Rust `Vec` adatszerkezete alkalmas arra, hogy veremként használjuk. A [`push` metódus](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) az elemeket a vektor végéhez fűzi. A [`pop` metódus](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) eltávolítja a vektor utolsó elemét. A `push` és a `pop` is csak amortizált `O(1)` időt igényel.

## Példa

Ebben a példában egy vektort használunk veremként egy egyszerű [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation) számológéphez. A teljes forráskód megtalálható a [playgroundon](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736).

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
