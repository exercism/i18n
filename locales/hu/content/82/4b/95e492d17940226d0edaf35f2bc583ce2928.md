# Utasítások

Mikát, a rendezvényszervezőt előléptették a munkahelyén, és új feladatai részeként ő felel a rendezvények adatbázisáért. Gyorsan észrevette, hogy rengeteg adatot olyan formában tárolnak, amivel nehéz dolgozni, ezért összefogtok, hogy egy egyszeri szkripttel kitakarítsátok. Mivel a szkriptet csak egyszer fogjátok lefuttatni, és biztos vagy az adatok szerkezetében, úgy gondolod, hogy ez jó hely a Gleam _let-állításainak_ a használatára.

## 1. Hibák kinyerése

Minden korábbi rendezvényhez tartozik egy lista az esemény során felmerült problémákról. Ezeket eredményként tárolták, de mindig az `Error` változatban. Készítsd el az `extract_error` függvényt, amely egy olyan eredményt vesz át, amelyről feltételezzük, hogy mindig `Error`, és visszaadja a benne lévő hibaértéket.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. Csapatelőtag eltávolítása

A csapatnevek elé a „Team ” szó került, de erre nincs szükség. Készítsd el a `remove_team_prefix` függvényt, amely eltávolítja az előtagot a csapatnévből.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. Régió és csapat szétválasztása

Minden rendezvényt egy csapat szervez, és minden csapat egy régióhoz tartozik. Az adatbázisban egyetlen stringben tárolják őket, vesszővel elválasztva. Készítsd el a `split_region_and_team` függvényt, amely két stringből álló tuple-re bontja a stringet: az egyik a régió, a másik a csapat. A „Team ” előtagot el kell távolítani a csapatnévből.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
