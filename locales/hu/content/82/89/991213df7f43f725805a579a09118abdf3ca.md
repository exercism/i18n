# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat | Típus       | Leírás                                                     |
| --------- | --------- | ----------- | ---------------------------------------------------------- |
| `$a0`     | bemenet   | cím         | az első szín null-terminált stringként                     |
| `$a1`     | bemenet   | cím         | a második szín null-terminált stringként                   |
| `$a2`     | bemenet   | cím         | a harmadik szín null-terminált stringként (lehet üres is)  |
| `$v0`     | kimenet   | egész szám  | az ellenállás értéke                                       |
| `$t0-9`   | ideiglenes | bármilyen  | ideiglenes tárolásra                                       |
