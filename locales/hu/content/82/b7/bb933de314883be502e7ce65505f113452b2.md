# Utasítások

Ebben a feladatban hat súlyossági szintű naplóüzeneteket dolgozol majd fel.

Minden naplósor egy string, amelynek a formátuma a következő: `"[<LVL>]: <MESSAGE>"`.

Ezek a különböző naplószintek:

| SZINT     | LVL   |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. A naplószint értelmezése

Definiálj egy `LogLevel` enumot, amelynek hat tagja megfelel a fent meghatározott naplószinteknek.
Ezután definiáld a `parse_log_level` függvényt, amely paraméterként a naplóüzenetet kapja, és visszaadja a szintjének megfelelő enum tagját.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. Ismeretlen naplószint kezelése

Sajnos néha előfordulnak olyan naplóüzenetek, amelyeknek _ismeretlen_ a súlyossági szintje. Hogy ezeket a »titokzatos« naplóüzeneteket elegánsan kezelni tudd a `parse_log_level` függvényben, adj hozzá egy `Unknown` tagot a `LogLevel` enumhoz, amelyet ismeretlen naplószint értelmezésekor ad vissza:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. Naplóüzenet átalakítása rövid formátumra

Egy naplósor szintje meglehetősen bőbeszédű. A naplóüzenetek tárolásához szükséges lemezterület csökkentésére bevezettek egy rövid formátumot: `"[<CODE_LEVEL>]:<MESSAGE>"`.

A naplószintek kódjai egy egyszerű megfeleltetést követnek:

| SZINT     | KÓD  |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

Definiáld a `convert_to_short_log()` függvényt, amely két paramétert kap:

1. Naplószint: a küldött napló szintje. Pl.: `LogLevel.Error`.
2. Naplóüzenet: a `str` típusú üzenet.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. Alias létrehozása

Úgy tűnik, a felhasználó `LogLevel.Warn` néven hozott létre naplókat `LogLevel.Warning` helyett. Hozz létre egy `alias`-t a `LogLevel.Warning` számára, és a `get_warn_alias` függvényben add vissza az új tagot.

Ezt ugyanazon a `LogLevel` enum osztályon teheted meg, amelyet már a fájl elején definiáltál. Mindkét naplószintnek ugyanarra az értékre kell mutatnia: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. Az összes tag neve és értéke

Definiáld a `get_members()` függvényt.

Ez a függvény egy `(name, value)` tuple-ökből álló listát adjon vissza, amely a `LogLevel` enum összes tagját tartalmazza.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
