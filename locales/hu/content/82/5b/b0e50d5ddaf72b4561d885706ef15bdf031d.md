# Bevezetés

A C#-ban azokat az adatszerkezeteket, amelyek nulla vagy több elemet tudnak tárolni, _gyűjteményeknek_ nevezzük. A **tömb** olyan gyűjtemény, amelynek rögzített a mérete/hossza, és amelynek minden eleme ugyanolyan típusú kell hogy legyen. Az elemeket index segítségével rendelheted a tömbhöz, és azzal is kérdezheted le. A C# tömbjei nullától indexeltek, ami azt jelenti, hogy az első elem indexe mindig nulla:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

A tömböket rövidebb jelöléssel is létrehozhatod, amellyel egyszerre hozod létre a tömböt és adod meg az értékeit. Mivel a fordító így már meg tudja állapítani, hány eleme lesz a tömbnek, a hossz elhagyható:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

A tömböket kétféleképpen kezelheted: meghívhatod egy tömppéldány metódusait vagy tulajdonságait, vagy használhatod az `Array` osztályban definiált statikus metódusokat.
