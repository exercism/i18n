# Részletesen

## Bevezetés

A generikusok olyan nyelvi funkciók, amelyek lehetővé teszik a kód újrafelhasználását.
Például egy lista hosszának kiszámításához nem kell tudnunk, hogy milyen típusú elemeket tartalmaz.
Ezért használ a `length` függvény egy generikus `a` típusparamétert a típusszignatúrájában.

```elm
length : List a -> Int
```

## Paraméterek a típusokban

Ha egy típus egy másik típusra nézve generikus, akkor azt a másik típust kisbetűs névvel jelöljük, és típusparaméternek nevezzük.
Gyakori példák a `List`, a `Maybe` és a `Result` egyedi típusok.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Egy fontos megjegyzés a típusparaméterek nevéhez: több karakter hosszúak is lehetnek.
Az egyetlen megkötés, hogy kisbetűs neveknek kell lenniük.
Ezért amikor hasznos, igyekszünk leíró neveket adni nekik.

Egy típus több másik típusra nézve is lehet generikus, és így több típusparamétere is lehet.
Ebben az esetben minden független típus külön kisbetűs nevet kap.
A függetlenség nem akadálya annak, hogy ugyanazzá a típussá váljanak, csupán lehetővé teszi, hogy különbözőek legyenek.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

A rekord típusaliasoknak is lehetnek típusparamétereik, bár ez ritkább.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## Típusparaméterek a függvényekben

Mivel a típusok lehetnek generikusak, a függvények is azok lehetnek.
Generikus típusokkal dolgozó függvényeket is írhatunk, ilyen például a `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Azokat a függvényeket, amelyek paraméterként más függvényeket fogadnak, magasabb rendű függvényeknek nevezzük, és ezek is lehetnek generikusak.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```

A típusparaméterek megjelenhetnek egy függvény bemeneteiben és kimenetében is, és a típusparaméterek által lehetővé tett generikusságot általában **parametrikus polimorfizmusnak** nevezik.
Ez ellentétben áll az ad hoc polimorfizmussal, amelyet függvénytúlterhelésnek is neveznek, és ahol ugyanaz a függvénynév több implementációhoz is használható, ha a típusok eltérnek.
Ez szintén ellentétben áll az altípus-polimorfizmussal, ahol a típusok hierarchiába rendezhetők, és egy típusra definiált függvényt annak altípusaival is meg lehet hívni.
Elmben a generikusság egyetlen elérhető mechanizmusa a parametrikus polimorfizmus.
