# Halmazok


A [halmaz][type-set] egy _módosítható_ és _nem sorrendezett_ gyűjtemény, amely [_hashable_][hashable] objektumokat tartalmaz.
A halmaz elemei csak különbözőek lehetnek, ismétlődő elemek nem szerepelhetnek benne.
Többféle adattípust és akár egymásba ágyazott szerkezeteket is tárolhatnak, például egy `tuples`-ből álló `tuple`-t, amennyiben minden elem _hashed_ lehet.
A halmazoknak van egy megváltoztathatatlan változata is, a [`frozensets`][type-frozenset].

A halmazokat leggyakrabban arra használjuk, hogy gyorsan eltávolítsuk az ismétlődéseket más adatszerkezetekből vagy elemcsoportokból.
Arra is jók, hogy hatékonyan hasonlítsunk össze dolgokat, amikor nincs szükség a sorrendezésre és az ismétlődések nyomon követésére.

A többi gyűjteménytípushoz (_szótár, lista, tuple_) hasonlóan a `sets` a következőket támogatja:
- Iteráció `for item in <set>` segítségével
- Tagság vizsgálata `in` és `not in` operátorral,
- Hossz kiszámítása `len()` segítségével, valamint
- Sekély másolat készítése `copy()` segítségével

A `sets` a következőket nem támogatja:
- Bármilyen indexelést
- Sorrend kialakítását rendezéssel vagy beszúrással
- Szeletelést
- Összefűzést `+` segítségével


A tagság vizsgálata egy `set`-ben átlagosan állandó időbonyolultságú, szemben a `list`-ben vagy `string`-ben való tagságvizsgálattal, ahol az időbonyolultság az adatok hosszával együtt nő.
Az olyan metódusok, mint a `<set>.union()`, `<set>.intersection()` vagy `<set>.difference()`, szintén átlagosan állandó időbonyolultságúak.


## Halmazliterálok

Egy `set` közvetlenül _halmazliterálként_ adható meg kapcsos `{}` zárójelekkel és az elemek közötti vesszőkkel.
Az ismétlődő elemek csendben kimaradnak:

```python
>>> one_element = {'➕'}
{'➕'}

>>> multiple_elements = {'➕', '🔻', '🔹', '🔆'}
{'➕', '🔻', '🔹', '🔆'}

>>> multiple_duplicates =  {'Hello!', 'Hello!', 'Hello!', 
                            '¡Hola!','Привіт!', 'こんにちは！', 
                            '¡Hola!','Привіт!', 'こんにちは！'}
{'こんにちは！', '¡Hola!', 'Hello!', 'Привіт!'}
```

A halmazliterálok ugyanazokat a kapcsos zárójeleket használják, mint a `dict` literálok, ezért üres `set` létrehozásához a `set()` konstruktort kell használnod.


## A `set` konstruktor

A `set()` (_a `set` osztály konstruktora_) bármilyen `iterable` argumentummal használható.
Az `iterable` elemein végigmegyünk, és egyenként adjuk hozzá őket a `set`-hez.
Az elemek sorrendje nem marad meg, és az ismétlődések csendben kimaradnak:

```python
# To create an empty set, the constructor must be used.
>>> no_elements = set()
set()

# The tuple is unpacked & each element is added.  
# Duplicates are removed.
>>> elements_from_tuple = set(("Parrot", "Bird", 
                               334782, "Bird", "Parrot"))
{334782, 'Bird', 'Parrot'}

# The list is unpacked & each element is added.
# Duplicates are removed.
>>> elements_from_list = set([2, 3, 2, 3, 3, 3, 5, 
                              7, 11, 7, 11, 13, 13])
{2, 3, 5, 7, 11, 13}
```

### Buktatók halmazok létrehozásakor

A „kicsomagoló” viselkedése miatt a `set()` stringgel való használata meglepő lehet:

```python
# String elements (Unicode code points) are 
# iterated through and added *individually*.
>>> elements_string = set("Timbuktu")
{'T', 'b', 'i', 'k', 'm', 't', 'u'}

# Unicode separators and positioning code points 
# are also added *individually*.
>>> multiple_code_points_string = set('अभ्यास')
{'अ', 'भ', 'य', 'स', 'ा', '्'}
```

A halmazok különböző adattípusokat és _egymásba ágyazott_ adattípusokat is tárolhatnak, de minden `set` elemnek _hashable_-nek kell lennie:

```python
# Attempting to use a list for a set member throws a TypeError
>>> lists_as_elements = {['🌈','💦'], 
                        ['☁️','⭐️','🌍'], 
                        ['⛵️', '🚲', '🚀']}

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'list'


# Standard sets are mutable, so they cannot be hashed.
>>> sets_as_elements = {{'🌈','💦'}, 
                        {'☁️','⭐️','🌍'}, 
                        {'⛵️', '🚲', '🚀'}}

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'set'
```


## Munka halmazokkal

A halmazok metódusai általában a [matematikai halmazműveleteket][mathematical-sets] utánozzák.
Ezeknek a metódusoknak a többségének (_de nem mindegyikének_) van [operátor][operator] megfelelője.
A metódusok általában bármilyen `iterable` argumentumot elfogadnak, az operátorok viszont megkövetelik, hogy a művelet mindkét oldala `set` vagy `frozenset` legyen.


### Diszjunkt halmazok

A `<set>.isdisjoint(<other_collection>)` metódussal vizsgálható, hogy egy `set` elemei átfedésben vannak-e egy másik `set` elemeivel.
A metódus bármilyen `iterable` vagy `set` argumentumot elfogad.
`True`-t ad vissza, ha a két halmaznak **nincs közös eleme**, és `False`-t, ha az elemek **közösek**.
Nincs operátor megfelelője:


```python
# Both mammals and additional_animals are lists.
>>> mammals = ['squirrel','dog','cat','cow', 'tiger', 'elephant']
>>> additional_animals = ['pangolin', 'panda', 'parrot', 
                          'lemur', 'tiger', 'pangolin']

# Animals is a dict.
>>> animals = {'chicken': 'white',
               'sparrow': 'grey',
               'eagle': 'brown and white',
               'albatross': 'grey and white',
               'crow': 'black',
               'elephant': 'grey', 
               'dog': 'rust',
               'cow': 'black and white',
               'tiger': 'orange and black',
               'cat': 'grey',
               'squirrel': 'black'}
               
# Birds is a set.
>>> birds = {'crow','sparrow','eagle','chicken', 'albatross'}

# Mammals and birds don't share any elements.
>>> birds.isdisjoint(mammals)
True

# There are also no shared elements between 
# additional_animals and birds.
>>> birds.isdisjoint(additional_animals)
True

# Animals and mammals have shared elements.
# **Note** The first object needs to be a set or converted to a set
# since .isdisjoint() is a set method.
>>> set(animals).isdisjoint(mammals)
False
```


### Részhalmazok és szuperhalmazok

A `<set>.issubset(<other_collection>)` metódussal ellenőrizhető, hogy a `<set>` minden eleme megtalálható-e az `<other_collection>`-ben is.
Az operátoros forma: `<set> <= <other_set>`:


```python
# Both mammals and additional_animals are lists.
>>> mammals = ['squirrel','dog','cat','cow', 'tiger', 'elephant']
>>> additional_animals = ['pangolin', 'panda', 'parrot', 
                          'lemur', 'tiger', 'pangolin']

# Animals is a dict.
>>> animals = {'chicken': 'white',
               'sparrow': 'grey',
               'eagle': 'brown and white',
               'albatross': 'grey and white',
               'crow': 'black',
               'elephant': 'grey', 
               'dog': 'rust',
               'cow': 'black and white',
               'tiger': 'orange and black',
               'cat': 'grey',
               'squirrel': 'black'}

# Birds is a set.
>>> birds = {'crow','sparrow','eagle','chicken', 'albatross'}

# Set methods will take any iterable as an argument.
# All members of birds are also members of animals.
>>> birds.issubset(animals)
True

# All members of mammals also appear in animals.
# **Note** The first object needs to be a set or converted to a set
# since .issubset() is a set method.
>>> set(mammals).issubset(animals)
True

# Both objects need to be sets to use a set operator
>>> birds <= set(mammals)
False

# A set is always a loose subset of itself.
>>> set(additional_animals) <= set(additional_animals)
True
```

A `<set>.issuperset(<other_collection>)` a `.issubset()` inverze.
Azzal ellenőrizhető vele, hogy az `<other_collection>` minden eleme megtalálható-e a `<set>`-ben is.
Az operátoros forma: `<set> >= <other_set>`:


```python
# All members of mammals also appear in animals.
# **Note** The first object needs to be a set or converted to a set
# since .issuperset() is a set method.
>>> set(animals).issuperset(mammals)
True

# All members of animals do not show up as members of birds.
>>> birds.issuperset(animals)
False

# Both objects need to be sets to use a set operator
>>> birds >= set(mammals)
False

# A set is always a loose superset of itself.
>>> set(animals) >= set(animals)
True
```


### Halmazmetszetek

A `<set>.intersection(*<other iterables>)` egy új `set`-et ad vissza, amely az eredeti `set` és az összes `<others>` közös elemeit tartalmazza (_más szóval azt a `set`-et, ahol minden [metszi][intersection] egymást_).
A metódus operátoros változata: `<set> & <other set> & <other set 2> & ... <other set n>`:


```python
>>> perennials = {'Annatto','Asafetida','Asparagus','Azalea',
                 'Winter Savory', 'Broccoli','Curry Leaf','Fennel', 
                 'Kaffir Lime','Kale','Lavender','Mint','Oranges',
                 'Oregano', 'Tarragon', 'Wild Bergamot'}

>>> annuals = {'Corn', 'Zucchini', 'Sweet Peas', 'Marjoram', 
              'Summer Squash', 'Okra','Shallots', 'Basil', 
              'Cilantro', 'Cumin', 'Sunflower', 'Chervil', 
              'Summer Savory'}

>>> herbs = ['Annatto','Asafetida','Basil','Chervil','Cilantro',
            'Curry Leaf','Fennel','Kaffir Lime','Lavender',
            'Marjoram','Mint','Oregano','Summer Savory', 
            'Tarragon','Wild Bergamot','Wild Celery',
            'Winter Savory']


# Methods will take any iterable as an argument.
>>> perennial_herbs = perennials.intersection(herbs)
{'Annatto', 'Asafetida', 'Curry Leaf', 'Fennel', 'Kaffir Lime',
 'Lavender', 'Mint', 'Oregano', 'Wild Bergamot','Winter Savory'}

# Operators require both groups be sets.
>>> annuals & set(herbs)
 {'Basil', 'Chervil', 'Marjoram', 'Cilantro'}
```


### Halmazegyesítések

A `<set>.union(*<other iterables>)` egy új `set`-et ad vissza, amely a `<set>` és az összes `<other iterables>` elemeit tartalmazza.
A metódus operátoros formája: `<set> | <other set 1> | <other set 2> | ... | <other set n>`:


```python
>>> perennials = {'Asparagus', 'Broccoli', 'Sweet Potato', 'Kale'}
>>> annuals = {'Corn', 'Zucchini', 'Sweet Peas', 'Summer Squash'}
>>> more_perennials = ['Radicchio', 'Rhubarb', 
                      'Spinach', 'Watercress']

# Methods will take any iterable as an argument.
>>> perennials.union(more_perennials)
{'Asparagus','Broccoli','Kale','Radicchio','Rhubarb',
'Spinach','Sweet Potato','Watercress'}

# Operators require sets.
>>> set(more_perennials) | perennials
{'Asparagus',
 'Broccoli',
 'Kale',
 'Radicchio',
 'Rhubarb',
 'Spinach',
 'Sweet Potato',
 'Watercress'}
```


### Halmazkülönbségek

A `<set>.difference(*<other iterables>)` egy új `set`-et ad vissza az eredeti `<set>` azon elemeivel, amelyek nincsenek benne az `<others>`-ben.
A metódus operátoros változata: `<set> - <other set 1> - <other set 2> - ...<other set n>`.

```python
>>> berries_and_veggies = {'Asparagus', 
                          'Broccoli', 
                          'Watercress', 
                          'Goji Berries', 
                          'Goose Berries', 
                          'Ramps', 
                          'Walking Onions', 
                          'Blackberries', 
                          'Strawberries', 
                          'Rhubarb', 
                          'Kale', 
                          'Artichokes', 
                          'Currants'}

>>> veggies = ('Asparagus', 'Broccoli', 'Watercress', 'Ramps',
               'Walking Onions', 'Rhubarb', 'Kale', 'Artichokes')

# Methods will take any iterable as an argument.
>>> berries = berries_and_veggies.difference(veggies)
{'Blackberries','Currants','Goji Berries',
 'Goose Berries', 'Strawberries'}

# Operators require sets.
>>> berries_and_veggies - berries
{'Artichokes','Asparagus','Broccoli','Kale',
'Ramps','Rhubarb','Walking Onions','Watercress'}
```


# Szimmetrikus halmazkülönbség

A `<set>.symmetric_difference(<other iterable>)` egy új `set`-et ad vissza, amely azokat az elemeket tartalmazza, amelyek a `<set>`-ben VAGY az `<other>`-ben benne vannak, **de nem mindkettőben**.
A metódus operátoros változata:  `<set> ^ <other set>`:


```python
>>> plants_1 = {'🌲','🍈','🌵', '🥑','🌴', '🥭'}
>>> plants_2 = ('🌸','🌴', '🌺', '🌲', '🌻', '🌵')


# Methods will take any iterable as an argument.
>>> fruit_and_flowers = plants_1.symmetric_difference(plants_2)
>>> fruit_and_flowers
{'🌸', '🌺', '🍈', '🥑', '🥭','🌻' }


# Operators require both groups be sets.
>>> fruit_and_flowers ^ plants_1
{'🌲',  '🌸', '🌴', '🌵','🌺', '🌻'}

>>> fruit_and_flowers ^ set(plants_2)
{'🥭', '🌴', '🌵', '🍈', '🌲', '🥑'}
```

~~~~exercism/note

Több mint két halmaz szimmetrikus különbsége olyan `set`-et eredményez, amely egyszerre tartalmazza az egyes `set`-ek egyedi elemeit ÉS a sorozatban több mint két `set` között megosztott elemeket is (_részletek a Wikipédia [szimmetrikus különbségről][symmetric_difference] szóló cikkében_).  

Ahhoz, hogy csak a sorozat egyes `set`-jeire egyedileg jellemző elemeket kapjuk meg, külön lépésben össze kell gyűjteni az összes kételemű kombináció metszetét, majd el kell távolítani azokat:  


```python
>>> one = {'black pepper','breadcrumbs','celeriac','chickpea flour',
           'flour','lemon','parsley','salt','soy sauce',
           'sunflower oil','water'}

>>> two = {'black pepper','cornstarch','garlic','ginger',
           'lemon juice','lemon zest','salt','soy sauce','sugar',
           'tofu','vegetable oil','vegetable stock','water'}

>>> three = {'black pepper','garlic','lemon juice','mixed herbs',
             'nutritional yeast', 'olive oil','salt','silken tofu',
             'smoked tofu','soy sauce','spaghetti','turmeric'}

>>> four = {'barley malt','bell pepper','cashews','flour',
            'fresh basil','garlic','garlic powder', 'honey',
            'mushrooms','nutritional yeast','olive oil','oregano',
            'red onion', 'red pepper flakes','rosemary','salt',
            'sugar','tomatoes','water','yeast'}

>>> intersections = (one & two | one & three | one & four | 
                     two & three | two & four | three & four)
...
{'black pepper','flour','garlic','lemon juice','nutritional yeast', 
'olive oil','salt','soy sauce', 'sugar','water'}

# The ^ operation will include some of the items in intersections, 
# which means it is not a "clean" symmetric difference - there
# are overlapping members.
>>> (one ^ two ^ three ^ four) & intersections
{'black pepper', 'garlic', 'soy sauce', 'water'}

# Overlapping members need to be removed in a separate step
# when there are more than two sets that need symmetric difference.
>>> (one ^ two ^ three ^ four) - intersections
...
{'barley malt','bell pepper','breadcrumbs', 'cashews','celeriac',
  'chickpea flour','cornstarch','fresh basil', 'garlic powder',
  'ginger','honey','lemon','lemon zest','mixed herbs','mushrooms',
  'oregano','parsley','red onion','red pepper flakes','rosemary',
  'silken tofu','smoked tofu','spaghetti','sunflower oil', 'tofu', 
  'tomatoes','turmeric','vegetable oil','vegetable stock','yeast'}
```
