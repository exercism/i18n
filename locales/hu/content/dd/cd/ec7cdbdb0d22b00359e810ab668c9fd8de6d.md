# Utasítások

Ebben a feladatban néhány függvényt kell megvalósítanod, amelyek egy programozási nyelvek listáját kezelik.

## 1. Definiálj egy függvényt, amely egy üres nyelvlistát ad vissza

Definiáld a `new` függvényt, amely nem fogad argumentumot, és egy üres listát ad vissza.

```haskell
new
-- -> []
```

## 2. Definiálj egy függvényt, amely hozzáad egy nyelvet a listához

Definiáld az `add/2` függvényt, amely két argumentumot fogad: egy _nyelvlistát_ és egy _nyelv_ string literálját.
A függvény adja vissza az eredményül kapott listát, amelyben az új nyelv a megadott lista elé van fűzve.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Definiálj egy függvényt, amely eltávolít egy nyelvet a listából

Definiáld a `remove` függvényt, amely egy argumentumot fogad: egy _nyelvlistát_.
A függvény adja vissza a listát az első elem nélkül. Feltételezd, hogy a listában mindig van legalább egy elem.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Definiálj egy függvényt, amely visszaadja a lista első elemét

Definiáld a `first` függvényt, amely egy argumentumot fogad: egy _nyelvlistát_.
A függvény adja vissza a lista első nyelvét.
Feltételezd, hogy a listában mindig van legalább egy elem.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Definiálj egy függvényt, amely visszaadja, hogy hány nyelv van a listában

Definiáld a `count` függvényt, amely egy argumentumot fogad: egy _nyelvlistát_.
A függvény adja vissza a listában lévő nyelvek számát.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Definiálj egy függvényt, amely meghatározza, hogy a lista tartalmaz-e funkcionális nyelvet

Definiáld az `isFunctionalList` függvényt, amely egy argumentumot fogad: egy _nyelvlistát_.
A függvény adjon vissza egy Boolean értéket.
A függvény adja vissza a `True` értéket, ha a _"Haskell"_ szerepel a lista nyelvei között.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
