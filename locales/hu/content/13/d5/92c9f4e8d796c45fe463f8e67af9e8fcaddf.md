# Bevezetés

## Hashtáblák

A hashtáblák a Common Lispben asszociatív adatok tárolására szolgáló adatszerkezetek.
A kulcsokat (amelyek bármilyen objektumok lehetnek) értékekhez rendelik (amelyek szintén bármilyen objektumok lehetnek).
Más nyelvekben ezt a fogalmat map, szótár vagy hash néven ismerheted.

### Hashtáblák létrehozása

Hashtáblát a `make-hash-table` függvénnyel hozhatsz létre.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Figyeld meg, hogy a hashtábla kiírt formája implementációfüggő, ezért a te REPL-edben máshogy nézhet ki.)

### Értékek kiolvasása kulcsok alapján

Ha egy kulcshoz tartozó értéket szeretnél kiolvasni a hashtáblából, a `gethash` függvényt használod:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

A `gethash` [több értéket][concept-multiple-values] ad vissza, amit egy másik fogalomban magyarázunk el.

### Értékek beszúrása

Ha értéket szeretnél beszúrni egy hashtáblába, a `setf`-et a `gethash`-sal együtt használod, így:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Ez a `*hash-table*` hashtáblában a `:foo` kulcshoz tartozó értéket `:bar`-ra módosítja.
Az értéket adja vissza.

A `setf` használatát egy másik fogalomban magyarázunk el.
