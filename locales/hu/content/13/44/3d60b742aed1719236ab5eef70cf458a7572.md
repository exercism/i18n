# Utasítások

A varázslók és harcosok játék témáját folytatva itt az ideje, hogy hozzáadjunk egy általános célú kockadobó metódust. Ez a hagyományos 18 oldalú kocka lesz, 1-től 18-ig tartó számokkal. A játékosok emellett varázserőt is generálnak.

## 1. Tedd lehetővé, hogy egy _varázslók és harcosok_ játékos kockát dobjon.

Valósítsd meg a `RollDie()` metódust a `Player` osztályon.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. A játékosoknak szükségük van az erejükre. Adj módot a varázserő generálására

Valósítsd meg a `GenerateSpellStrength()` metódust a `Player` osztályon. A varázserő 0.0 és 100.0 között van, utóbbit nem beleértve.

Vedd figyelembe, hogy a varázserőnek valós számnak kell lennie (nem egész számnak), hogy csökkenjen a döntetlen esélye, amikor két ellenfél erejét összehasonlítják.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
