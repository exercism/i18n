# Névjegy

A string a Factorban karakterek sorozata, és a teljes [`sequences` protokollal][sequence-protocol] rendelkezik, például a `length`, `nth`, `head`, `tail`, `map`, `filter` és hasonló szavakkal, emellett saját szótárai is vannak.

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

A stringspecifikus szavak többnyire a [`splitting`][splitting], [`ascii`][ascii] és [`unicode`][unicode] szótárban találhatók:

| szó          | szótár        | mit csinál                            |
|--------------|---------------|---------------------------------------|
| `split1`     | [`splitting`][splitting]   | az első előfordulásnál vág           |
| `split`      | [`splitting`][splitting]   | a halmaz bármely karakterénél vág    |
| `harvest`    | [`sequences`][sequences]   | üres darabok eltávolítása a felbontás eredményéből |
| `replace`    | [`splitting`][splitting]   | részstring cseréje                    |
| `surround`   | [`sequences`][sequences]   | körbeveszi egy előtaggal és utótaggal |
| `glue`       | [`sequences`][sequences]   | két string összefűzése elválasztóval  |
| `join`       | [`sequences`][sequences]   | stringek tömbjének összefűzése elválasztóval |
| `>lower`     | [`ascii`][ascii]       | kisbetűssé alakít (ASCII)             |
| `>upper`     | [`ascii`][ascii]       | nagybetűssé alakít (ASCII)            |
| `[ blank? ] trim` | [`sequences`][sequences] | kezdő és záró whitespace eltávolítása |
| `first`, `second`, `third`, `fourth` | [`sequences`][sequences] | a kezdő hely |
| `first2`, `first3`         | [`sequences`][sequences]   | két vagy három kezdő hely kicsomagolása |
| `>string`    | [`strings`][strings]     | karakterek sorozatából stringgé alakít |
| `1string`    | [`strings`][strings]     | egyetlen karaktert egykarakteres stringgé alakít |
| `CHAR: x`    | parser        | egykarakteres literál (pl. `CHAR: A` → `65`) |

A szám ↔ string oda-vissza alakításhoz a [`math.parser`][math.parser] biztosítja a `number>string` és `string>number` szavakat. Formátumstring-kimenethez a [`formatting`][formatting] biztosítja a `sprintf` és társait.

Unicode-kompatibilis kis- és nagybetű-átalakításhoz vagy karakterosztályozáshoz használd a [`unicode`][unicode] szótárban található megfelelő szavakat.
