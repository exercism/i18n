# Bevezetés

A Gleam nem kivételekkel kezeli a hibákat, helyette azok a függvények adnak vissza egy általános `Result` típust, amelyek vagy sikerülhetnek, vagy elbukhatnak.

A `Result` típus a nyelvbe van építve, ezért nem kell definiálnod vagy importálnod, de ha mégis magad definiálnád, így nézne ki:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

Az `Ok` változatot akkor adja vissza egy függvény, amikor sikerül, az `Error` változatot pedig akkor, amikor elbukik.

A Result típus nagyon gyakori a Gleamben, a Gleam-programozók pedig gyakran használják a [`gleam/result` modult](https://hexdocs.pm/gleam_stdlib/gleam/result.html), hogy könnyebb legyen a velük való munka.

A `result.map` függvénnyel meghívhatsz egy függvényt a resultban lévő értéken, ha az `Ok`, vagy változatlanul továbbadhatsz egy `Error`-t.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

A `result.try` függvény hasonló, de itt a visszahívó függvénynek resultot kell visszaadnia. Ez akkor hasznos, ha több resultot visszaadó függvényt fűzöl össze.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
