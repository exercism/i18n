# Bevezetés a változókba

## Változók

A _változók_ olyan helyek, ahol adatokat tárolhatsz.
A bashben kétféle adat létezik: string és tömb.
A tömbökről később ejtünk szót.

Így rendelsz értéket egy változóhoz:
```bash
name="value"
```

~~~~exercism/note
**Fontos**: az egyenlőségjel körül _nem lehet szóköz_!

Ha mégis van szóköz, mint ebben a példában,

```bash
x = 10
```

akkor a bash az `x` **parancsot** fogja meghívni a **két argumentummal**: `=` és `10`!
~~~~

A változókat _paramétereknek_ is nevezik.
Ebben a dokumentumban a két kifejezést felváltva használjuk.

Íme néhány fontos paraméter, amelyet a bash használ vagy beállít:

* `PATH`: a külső parancsok megtalálásához használt könyvtárak kettősponttal elválasztott listája.
* `IFS`: a „belső mezőelválasztó”.
   Hogyan használjuk, azt alább meglátjuk.
* `PWD`: az aktuális munkakönyvtárad.
   Az értéke megegyezik a `pwd` parancs kimenetével.
* `RANDOM`: egy álvéletlen egész szám 0 és 32767 között.
* `BASH_VERSION`: a futó bashpéldány verzióját tartalmazó string.

## Változónevek

A változónév _nagybetűkből, kisbetűkből, számokból és aláhúzásjelekből_ áll.
Nem kezdődhet számmal.

~~~~exercism/caution
Ajánlott gyakorlat, hogy **kerüld a csupa nagybetűs változóneveket**.
A shell ezt a konvenciót használja a saját paramétereinél, és nem szeretnéd véletlenül felülírni azokat a shell-paramétereket, amelyeknek különleges jelentésük van.

## Paraméterkibontás

Egy paraméter értékét a `$varname` szintaxissal kapod meg.

```bash
x=10
echo "The value of x is $x"
```

Hogy a változónév ne keveredjen össze a körülötte lévő szöveggel, kapcsos zárójelbe is teheted a nevét.
Például a `10x10` string kiírásához:

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

Néhány [stílusútmutató][google-style-guide] a legtöbb esetben a kapcsos zárójelek használatát javasolja az olvashatóság és/vagy a következetesség érdekében.

## Pozíciós paraméterek

Ahogy a [Parancsok és argumentumok][cmds-args] leckében is szó volt róla, a parancsok fogadhatnak argumentumokat.
A bash-szkriptek sem kivételek.
Az aktuális bashpéldány argumentumait _pozíciós paramétereknek_ nevezzük.
Ezeket a következő speciális paraméterekkel kérheted le:

* `$1`: az első pozíciós paraméter
* `$2` ... `$9`: a további paraméterek
* `${10}` ...: kétjegyű számoknál kapcsos zárójel kell.
* `$0`: az aktuális szkript neve.

A shell-függvények argumentumai is pozíciós paraméterek, és ugyanígy kezeljük őket.
A függvényekről egy későbbi leckében lesz szó bővebben.

### Speciális pozíciós paraméterek

Van néhány _speciális paraméter_, amely segít a pozíciós paraméterek kezelésében.

* `$#` a pozíciós paraméterek _számát_ adja.
* `"$@"` az összes pozíciós paraméter listáját adja, mindegyiket külön szóként.
* `"$*"` egyetlen stringgé fűzi össze az összes pozíciós paramétert, egy karakterrel elválasztva.
  * Az összefűzéshez használt karakter a `$IFS` változó _első karaktere_, amely alapértelmezés szerint szóköz.

A `"$@"` a legbiztonságosabb módja annak, hogy a pozíciós paramétereket egy másik parancsnak add át, miközben biztonságosan idézőjelben maradnak.
Ezt használod majd akkor is, amikor végig akarsz menni a pozíciós paramétereken:

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

A gyakorlatban a `"$@"`-t gyakrabban használják, mint a `"$*"`-ot.

## Parancsbehelyettesítés

A bash-szkriptekben gyakran végrehajtott művelet, hogy elkapod egy parancs kimenetét, és eltárolod egy változóban.
Ehhez a _parancsbehelyettesítést_ használod.

```bash
var=$(command)
```

Például egy string nagybetűssé alakításához ezt teheted:

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## Még több a paraméterkibontásról

A bashnek sok beépített eszköze van a változók és stringek kezelésére, így nem kell külső parancsokat meghívnod.

* Szöveg nagybetűssé alakítása.
  Az előző szakaszban megmutattam, hogyan lehet a `tr`-rel nagybetűssé alakítani egy szöveget.
  Ha ezt bashben szeretnéd megtenni:

  ```bash
  echo "${text^^}"
  ```

  Hasonlóképpen a `${text,,}` kisbetűssé alakítja az értéket.

* Adj meg egy alapértelmezett értéket, ha a változó üres.

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* Keresés és csere.

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

Sok más érdekes paraméterkibontás is létezik: részstring kinyerése, a string hosszának lekérdezése, alapértelmezett érték _hozzárendelése_, szöveg eltávolítása az érték elejéről vagy végéről, és még sok minden más.
Ezekről [a kézikönyvben][param-exp] olvashatsz.
