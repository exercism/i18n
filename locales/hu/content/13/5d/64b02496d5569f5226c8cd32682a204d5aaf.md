# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat | Típus      | Leírás                              |
| --------- | --------- | ---------- | ----------------------------------- |
| `$a0`     | bemenet   | cím        | tényezőszavak tömbje                |
| `$a1`     | bemenet   | egész szám | a tényezők száma                    |
| `$a2`     | bemenet   | egész szám | felső határ                         |
| `$v0`     | kimenet   | egész szám | a felső határon belüli többszörösök összege |
| `$t0-9`   | ideiglenes | bármi     | ideiglenes tárolásra használatos    |
