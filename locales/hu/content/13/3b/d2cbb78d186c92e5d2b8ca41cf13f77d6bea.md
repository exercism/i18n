# Utasítások

Alakítsd át a kifejezést a rövidítésévé.

A tech-rajongók imádják a TLA-t (Three Letter Acronyms, azaz hárombetűs rövidítéseket)!

Segíts némi szakzsargont gyártani: írj olyan programot, amely egy hosszú nevet, például a Portable Network Graphics nevet a rövidítésévé alakítja (PNG).

A központozást a következőképpen kezeljük: a kötőjelek szóelválasztók (akárcsak a whitespace); minden egyéb írásjel eltávolítható a bemenetből.

Például:

| Bemenet                   | Kimenet |
| ------------------------- | ------- |
| As Soon As Possible       | ASAP    |
| Liquid-crystal display    | LCD     |
| Thank George It's Friday! | TGIF    |
