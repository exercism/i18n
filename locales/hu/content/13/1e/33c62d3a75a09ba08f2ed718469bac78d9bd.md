# Telepítés

A C nyelv kurzushoz a következő szoftvereknek kell telepítve lenniük a gépeden:

* Egy modern C-fordító
* A Make build eszköz

Az Apple Xcode IDE a fordítót és a natív build rendszert egyetlen IDE-be, azaz integrált fejlesztői környezetbe vonja össze.
A Linux-környezetekben a fordító és a natív build rendszer általában külön parancssori eszközként érhető el.

## Linux

Linuxon a fordítóhoz gcc-re vagy clangre lesz szükséged, a natív buildhez pedig `make`-re.
A Make a legtöbb unix rendszeren előre telepítve van, de valószínűleg a csomagkezelődből is elérhető.
A Debian- és Ubuntu-alapú disztribúciókon mindent, amire szükséged van, telepíthetsz a `sudo apt-get install build-essential` paranccsal, ha még nincs telepítve.

## MacOS

A MacOS felhasználók a [Homebrew][] segítségével telepíthetik a gcc-t vagy a clanget a `brew install gcc` vagy a `brew install llvm` paranccsal.

## Windows

Windows 10-en ajánlott a [Windows Subsystem for Linux][] használata, majd a fenti, Linuxra vonatkozó utasítások követése.

Ha a Windows egy korábbi verzióját használod, vagy a WSL Bash nem elérhető számodra, használhatod az [MSYS][] vagy a [mingw-w64][] eszközt.

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
