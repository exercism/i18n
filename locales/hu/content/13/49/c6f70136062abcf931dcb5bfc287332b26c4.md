# Boolean

A Haskellben létezik egy [`Bool`][bools] nevű típus.
Ez a `True` és a `False` felsorolása.

## Logikai operátorok

A Haskellben három logikai operátor van (`not`, `||`, `&&`), amelyek Boolean-okat kombinálnak, és különböző értékeket előállító kifejezéseket hoznak létre.

### És(`&&`)

A Haskellben az [_és_ operátort][and] a `&&` jelöli, és `True`-t ad vissza, ha mindkét érték `True`; egyébként `False`-t ad vissza.
Az _és_ operátor használatakor az egyik Boolean a `&&` jobb oldalára, a másik a bal oldalára kerül.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### Vagy(`||`)

A Haskellben a [_vagy_ operátort][or] a `||` jelöli, és `True`-t ad vissza, ha a megadott értékek közül **legalább az egyik** `True`.
Ha mindkét érték `False`, akkor `False`-t ad vissza.
A _vagy_ operátor használatakor az egyik Boolean a `||` jobb oldalára, a másik a bal oldalára kerül.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Nem(`not`)

A Haskellben a _nem_ operátort a `not` jelöli: `True`-t ad vissza, ha a megadott Boolean `False`, és `False`-t ad vissza, ha `True`-t kap.
A _nem_ operátor használatakor a Boolean az operátor (`not`) után áll.

```haskell
not True
-- -> False

not False
-- -> True
```

## Zárójelek használata(`()`)

Amikor Boolean-okkal dolgozol, zárójelekkel döntheted el, hogy mely Boolean-ok értékelődjenek ki először.
Az eredmény attól függően változhat, hogyan használod a zárójeleket.
A Haskellben először a zárójelben lévő rész értékelődik ki.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Mivel a zárójelben lévő rész értékelődik ki először, a következő példában a _nem_ operátor a zárójelben lévő kifejezésre vonatkozik.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
Zárójelet csak akkor használj, ha az befolyásolja az eredményt; egyébként hagyd el őket.
~~~~
