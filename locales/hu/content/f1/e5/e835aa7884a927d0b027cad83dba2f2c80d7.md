# A felső szintű konstans kiemelése ajánlott

Érdemes lehet a konstanst a felső szintű scope-ba kiemelni:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Csak az `export`-olt függvények, osztályok és konstansok láthatók és érhetők el kívülről.
Ezek a konstansok ugyanabban a fájlban maradhatnak anélkül, hogy más kód számára elérhetővé válnának.
Ráadásul a konstansok kiemelése memóriát takarít meg, mert elkerüli az ismétlődő memóriafoglalásokat a függvényekben, amikor ugyanazokat a konstansokat újra felhasználod.
