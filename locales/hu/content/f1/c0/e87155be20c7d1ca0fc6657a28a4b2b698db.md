# Névjegy

A [Java](https://go.java/index.html) sokoldalúságának és kompatibilitásának köszönhetően a ma elérhető egyik legnépszerűbb programozási nyelv.
Széles körben használják szoftverfejlesztésre, mobilalkalmazásokhoz és nagyobb rendszerek fejlesztéséhez.

A Java 1995-ben született, és a [Oracle](https://www.oracle.com/index.html) tartja karban.
Bár nem olyan fiatal, mint néhány újabb nyelv, a Java ma is igencsak népszerű.
Úgy tervezték, hogy gyors, biztonságos, megbízható, kezdők számára barátságos és nagymértékben hordozható legyen.
Ez a hordozhatóság abból fakad, hogy a Java egy platformfüggetlen [Java virtuális gépen (JVM)](https://en.wikipedia.org/wiki/Java_virtual_machine) fut.
Az Android-alkalmazásokat is Java használatával fejlesztik, mivel az [Android operációs rendszer](<https://en.wikipedia.org/wiki/Android_(operating_system)>) Java nyelvi környezetben fut.

A Java közösség hatalmas!
A GitHubon például több mint 1,5 millió Java-projekt található.
Azt is érdemes megemlíteni, hogy a Javának van a második legnagyobb közössége a [StackOverflow-n](https://stackoverflow.com/questions/tagged/java)!
Ez azért fontos, mert minél nagyobb egy programozási nyelv közössége, annál nagyobb támogatásra számíthatsz.

A Java emellett egy hatékony és jól megtervezett, beépített [API-készlettel (alkalmazásprogramozási felületekkel)](https://docs.oracle.com/en/java/javase/11/docs/api/index.html) rendelkezik, amelyeket sokféle feladatra használhatsz: adatbázis-kapcsolatra, hálózatkezelésre, I/O-ra, XML-elemzésre, segédprogramokra és még sok másra.

A laptopoktól az adatközpontokig, a játékkonzoloktól a tudományos szuperszámítógépekig, a mobiltelefonoktól az internetig [mindenhol ott van a Java](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
