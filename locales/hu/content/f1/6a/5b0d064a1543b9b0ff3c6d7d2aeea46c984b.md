# Bevezetés

A C++-ban az összehasonlító operátorokkal hasonlíthatsz össze értékeket.

| Összehasonlítás   | Operátor  |
| ------------------| --------- |
| egyenlő           | `==`      |
| nem egyenlő       | `!=`      |
| kisebb            | `<`       |
| kisebb vagy egyenlő | `<=`    |
| nagyobb           | `>`       |
| nagyobb vagy egyenlő | `>=`   |

Ezeknek az összehasonlításoknak az eredménye mindig egy Boolean érték:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

A `==` és a `!=` operátor azt ellenőrzi, hogy egy érték egyenlő-e egy másikkal, illetve hogy nem egyenlő-e vele.
Íme néhány gyakori példa:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

A többi operátor azt vizsgálja, hogy az egyik érték nagyobb-e (`>`), nagyobb vagy egyenlő-e (`>=`), kisebb-e (`<`), illetve kisebb vagy egyenlő-e (`<=`), mint egy másik érték.
Ez a fajta összehasonlítás számokra és stringekre is elérhető.
Stringek összehasonlításakor a szótári sorrendet (más néven lexikográfiai sorrendet) követjük.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
