# Bevezetés

Sok más programozási nyelvvel ellentétben JavaScriptben két különböző dolog is jelöli egy (értelmes) érték hiányát.
Ez a `null` és az `undefined`.

## Null

A primitív `null` érték bármilyen típusú változó szándékos „üres értékeként” szolgál.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Egy változó `null` voltát a [szigorú egyenlőség operátorral][mdn-strict-equality] (`===`) ellenőrizheted.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Az a változó, amelyiknek nem adtál értéket, `undefined` típusú.[^1]

Ez azt jelenti, hogy míg a `null` egy üres értéket jelöl (de mégiscsak egy értéket), addig az `undefined` egy érték teljes hiányát jelöli. 🤯

Az `undefined` többféle helyzetben is megjelenik.

- Ha egy változót érték nélkül deklarálsz (azaz nincs kezdőértéke), akkor az `undefined`.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- Ha egy objektumban egy nem létező kulcs értékét próbálod elérni, `undefined`-et kapsz.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- Ha egy függvény nem ad vissza értéket, az eredmény `undefined`.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- Ha egy függvénynek nem adsz át egy argumentumot, az `undefined` lesz, kivéve, ha annak az argumentumnak van alapértelmezett értéke.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

Egy változó `undefined` voltát szintén a szigorú egyenlőség operátorral (`===`) ellenőrizheted.

```javascript
let name;

name === undefined;
// => true
```

## Opcionális láncolás

Ha egy objektumban egy egymásba ágyazott értéket próbálsz lekérni, de a szülő kulcs nem létezik, a JavaScript hibát dob.
Ennek egyszerű elkerülésére 2020-ban bekerült a nyelvi specifikációba az opcionális láncolás.
Az opcionális láncolás operátorral (`?.`) elérheted, hogy a JavaScript csak akkor próbálja meg elérni az egymásba ágyazott kulcsot, ha a szülő nem `null` és nem is `undefined`.
Egyébként `undefined`-et ad vissza.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Nullish coalescing

Vannak helyzetek, amikor alapértelmezett értéket szeretnél adni egy változónak, ha az `null` vagy `undefined` (de csak akkor).
Ennek megoldására 2020-ban bevezették a nullish coalescing operátort (`??`).
Csak akkor adja vissza a jobb oldali operandust, ha a bal oldali operandus `null` vagy `undefined`.
Egyébként a bal oldali operandust adja vissza.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
