# Tesztek

## A feladat fájljai

A letöltött feladat a következő fájlokat tartalmazza a megoldásod felépítéséhez és teszteléséhez:

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

A fájlnevek feladatonként változnak.
A megoldásodat abba a `.vb` fájlba írd, amelynek neve nem `Tests`-re végződik.
A `Tests.vb`-re végződő fájl az xUnit tesztkészlet; általában csak a `Skip` argumentumok eltávolítása érdekében kell szerkesztened.
Általában nem kell szerkesztened a projektfájlt vagy a lock fájlt.

## A tesztek futtatása

Nyiss egy terminált a feladat könyvtárában, és futtasd:

```bash
dotnet test
```

A parancs visszaállítja a projekt függőségeit, felépíti a projektet, és lefuttatja a tesztjeit.
A `dotnet watch test` parancsot is használhatod, hogy a forrásfájlok változásakor újrafuttasd a teszteket.

## Kihagyott tesztek

A feladatok kezdetben csak az első tesztet engedélyezik, így a többit lépésenként oldhatod meg.
A tesztek megtalálásához nyisd meg a `Tests.vb`-re végződő fájlt.
Minden teszt egy `Sub` szubrutin, amelyet egy xUnit `<Fact>` attribútum jelöl.
Egy teszt addig marad kihagyva, amíg a `<Fact>` attribútumában szerepel egy `Skip` argumentum:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

A teszt engedélyezéséhez egyszerűen távolítsd el a `Skip` argumentumot:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Miután az újonnan engedélyezett teszt sikeres lesz, ismételd meg ezt a folyamatot a következő kihagyott teszttel.
Amikor minden teszt engedélyezve van és sikeres, elkészültél.
