# Bevezetés

## Időbeállítók

Amikor `java.time` objektumokkal, például `LocalDate`-dal dolgozol, gyakran összetett dátumkorrekciókat kell végrehajtanod, például meg kell keresned a hónap második keddjét.
Ahelyett, hogy ezt manuálisan számolnád ki, használhatod a **`TemporalAdjusters`** osztályt.

A `java.time.temporal.TemporalAdjusters` segédosztály (figyeld meg a többes számú „s” végződést) számos gyakori dátumkorrekcióhoz kínál statikus metódusokat.
Ezeket a korrekciókat egy időbeli objektumon (például `LocalDate`-on) a `.with()` metódussal alkalmazod.

```exercism/note
A `with(TemporalAdjuster)` használata egy _új_ példányt ad vissza, és nem frissíti a meglévő példányt, mert a `java.time` objektumok megváltoztathatatlanok.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Íme néhány kulcsfontosságú időbeállító, amely hasznos lehet az ütemezési számításokhoz:

### A hét adott sorszámú napjának megkeresése

A `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` metódussal megkeresheted egy hét valamely napjának n-edik előfordulását.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

### A hónap első/utolsó adott napjának megkeresése

Használd a `firstInMonth(DayOfWeek dayOfWeek)` vagy a `lastInMonth(DayOfWeek dayOfWeek)` metódust.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Relatív beállítások (következő/előző)

Az olyan időbeállítók, mint a `next()`, `previous()`, `nextOrSame()` és `previousOrSame()`, egy adott hét napjának következő vagy előző előfordulását keresik meg az aktuális dátumhoz képest.

- `next()`/`previous()`: kizárja az aktuális dátumot, ha az megfelel.
- `nextOrSame()`/`previousOrSame()`: beleszámítja az aktuális dátumot, ha az megfelel.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

### Egyéni időbeállítók

A `TemporalAdjuster` funkcionális interfész, ezért saját időbeállítót is írhatsz lambda kifejezésként, amely megkapja a beállítandó időbeli objektumot, és visszaadja a beállítottat.
Ugyanúgy a `.with()` metódussal alkalmazod, mint az előre definiált időbeállítókat, és belül maga is használhatja azokat.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

A `TemporalAdjusters` osztály ezen időbeállítóinak használata nagyban leegyszerűsítheti a dátumkezelési feladatokat.
