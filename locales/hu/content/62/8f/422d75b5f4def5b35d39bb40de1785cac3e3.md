# Instructions

Ebben a feladatban segédrutinok egy részét valósítod meg, amelyek segítenek egy fejlesztőnek rendbe tenni az azonosítók neveit.
Az 5 részfeladatban fokozatosan építed fel a `Clean` rutint.
Egy érvényes azonosító nulla vagy több betűből és alulvonásból áll.
A bemeneti string minden esetben garantáltan nem null.
Ha üres stringet adsz át a `Clean` függvénynek, akkor annak üres stringet kell visszaadnia.
Ne feledd, hogy a hívónak érdemes elkerülnie, hogy üres azonosítóval hívja meg a `Clean` rutint, mert az ilyen azonosítók hatástalanok.

## 1. A szóközöket cseréld alulvonásra

Valósítsd meg a (_statikus_) `Identifier.Clean()` metódust, hogy a szóközöket alulvonásra cserélje.
Ez a kezdő és a záró szóközökre is igaz.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. A vezérlőkaraktereket cseréld a nagybetűs „CTRL” stringre

Módosítsd a (_statikus_) `Identifier.Clean()` metódust, hogy a vezérlőkaraktereket a nagybetűs `"CTRL"` stringre cserélje.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Alakítsd át a kebab-case-t camelCase-re

Módosítsd a (_statikus_) `Identifier.Clean()` metódust, hogy a kebab-case-t camelCase-re alakítsa.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Hagyd el azokat a karaktereket, amelyek nem betűk

Módosítsd a (_statikus_) `Identifier.Clean()` metódust, hogy elhagyja az összes olyan karaktert, amely nem betű.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Hagyd el a görög kisbetűket

Módosítsd a (_statikus_) `Identifier.Clean()` metódust, hogy elhagyja az 'α' és 'ω' közötti tartományba eső görög betűket.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
