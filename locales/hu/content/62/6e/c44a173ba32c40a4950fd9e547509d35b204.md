# Utasítások

Ebben a feladatban egy barátoddal játszol számkitalálós játékot. A szabályok egyszerűek: titokban választasz egy számot `1` és `100` között, a barátod pedig megpróbálja kitalálni, hogy melyik számot választottad. Hogy segíts a barátodnak, más-más választ adsz attól függően, hogy milyen közel járt a tipp a választott számhoz (`42`). A különböző válaszok szabályai a következők:

- Ha a tipp `42`: "Correct"
- Ha a tipp `41` vagy `43`: "So close"
- Ha a tipp kisebb, mint `41`: "Too low"
- Ha a tipp nagyobb, mint `43`: "Too high"

Négy részfeladat vár rád, hogy kódold a tippekre adott válaszokat.

## 1. Helyes tipp megválaszolása

Valósítsd meg a `reply` függvényt, hogy válaszoljon egy helyes tippre:

```fsharp
reply 42
// => "Correct"
```

## 2. Közeli tipp megválaszolása

Alakítsd át a `reply` függvényt, hogy válaszoljon a közeli tippekre:

```fsharp
reply 41
// => "So close"
```

## 3. Túl alacsony tippek megválaszolása

Alakítsd át a `reply` függvényt, hogy válaszoljon a túl alacsony tippekre:

```fsharp
reply 25
// => "Too low"
```

## 4. Túl magas tippek megválaszolása

Alakítsd át a `reply` függvényt, hogy válaszoljon a túl magas tippekre:

```fsharp
reply 88
// => "Too high"
```
