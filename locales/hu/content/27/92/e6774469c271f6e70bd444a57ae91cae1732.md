# Bevezetés

Az Elixirben a mapok kulcs-érték párok tárolására szolgáló adatszerkezetek. Más nyelvekben ezeket asszociatív tömbnek (PHP), hashnek (Perl 5, Raku) vagy szótárnak (Python) is nevezik.

A kulcsok és az értékek bármilyen adattípusúak lehetnek, de ha a kulcs atom, akkor rövidített szintaxist használhatunk. A mapok nem garantálják a bejegyzések sorrendjét, sem amikor hozzáférünk hozzájuk, sem amikor visszaadjuk őket.

## Literál alakok

Egy üres mapet egyszerűen a `%{}` szintaxissal deklarálunk. Ha elemeket szeretnénk adni egy map literálhoz, két alak közül választhatunk:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Bár nincs kanonikus formátum, válassz egy következetes módot a kulcs-érték literálpárok megjelenítésére.

## A _Map modul_ függvényei

Az Elixir sok függvényt kínál a mapokkal való munkához a _Map modulban_. A _Map modul_ egyes függvényei egy _anonim_ függvényt várnak, amely segít a map átalakításában.
