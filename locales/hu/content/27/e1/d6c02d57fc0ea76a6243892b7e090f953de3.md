# Bevezetés

Az F#-ban a `string` olyan objektum, amely megváltoztathatatlan szöveget reprezentál Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként, és a következőképpen definiáljuk:

```fsharp
let fruit = "Apple"
```

A stringeket vagy a string metódusainak meghívásával, vagy a `String` modul függvényeivel lehet manipulálni. Ha egyszer létrejött egy string, az értéke soha nem változhat meg. Azok a metódusok vagy függvények, amelyek úgy tűnik, hogy módosítják a stringet, valójában egy új stringet adnak vissza.

A stringeket többféleképpen is összefűzheted vagy formázhatod.
* Az összefűzéshez használhatod a `+` operátort:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* A szöveg formázásához használhatod a `sprintf` függvényt: a formázó szövegben helyőrzők vannak (`%s` egy `string` számára), az értékeket pedig argumentumként adod meg:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
