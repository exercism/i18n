# Bevezetés

A tuple rendezett értéktároló. Mint minden Gleam adattípus, a tuple-ok is megváltoztathatatlanok.
Egy tuple minden eleme lehet más típusú, sőt akár más tuple-ok is lehetnek.

A tuple-okat vesszővel elválasztott értékekként definiáljuk a `#(` és `)` között: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Az azonos hosszúságú és azonos típusú (azonos sorrendű) tuple-ok összehasonlíthatók egyenlőségre.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Háromféleképpen juthatsz hozzá a tuple-ban tárolt értékekhez:

- Indexelés.
- Mintaillesztés `let`-tel.
- Mintaillesztés `case`-szel.

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

A tuple indexelés használható `case` kifejezés őreiként.

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
