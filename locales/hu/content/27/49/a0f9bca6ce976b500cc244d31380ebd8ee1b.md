# Utasítások

Ebben a feladatban naplósorokkal fogsz dolgozni.

Minden naplósor egy string, amelynek formátuma a következő: `"[<LVL>]: <MESSAGE>"`.

A különböző naplószintek a következők:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Három részfeladatod van.

## 1. Naplószint értelmezése

Definiálj egy `LogLevel` enumot, amelynek hat eleme van, a fenti naplószinteknek megfelelően.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

Ezután valósítsd meg a (_statikus_) `LogLine.ParseLogLevel()` metódust, amely értelmezi egy naplósor naplószintjét:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. Ismeretlen naplószint kezelése

Sajnos időnként előfordul, hogy egyes naplósorok naplószintje ismeretlen. Hogy ezeket a naplósorokat szépen kezelni tudd, adj hozzá egy `Unknown` elemet a `LogLevel` enumhoz, amelyet ismeretlen naplószint értelmezésekor kell visszaadni:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. Naplósor átalakítása rövid formátumra

A naplósorok naplószintje meglehetősen hosszú. Hogy csökkentsük a naplósorok tárolásához szükséges lemezterületet, kifejlesztettek egy rövid formátumot: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

A kódolt naplószint egyszerű megfeleltetés: minden naplószinthez egy szám tartozik:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

Valósítsd meg a (_statikus_) `LogLine.OutputForShortLog()` metódust, amely ki tudja írni a lerövidített naplósor-formátumot:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
