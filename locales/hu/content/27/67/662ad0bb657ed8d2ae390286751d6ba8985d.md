# Bevezetés

Ha valamit önmagára hivatkozva definiálunk, azt rekurziónak nevezzük. Az F#-ban a rekurzió leggyakrabban rekurzív függvényekben jelenik meg, vagyis olyan függvényekben, amelyek önmagukat hívják meg.

Egy rekurzív függvénynek legalább egy _alapesetre_ és legalább egy _rekurzív esetre_ van szüksége. Az _alapeset_ úgy ad vissza egy értéket, hogy nem hívja meg újra a függvényt. A _rekurzív eset_ újra meghívja a függvényt, és közben úgy módosítja a bemenetet, hogy az előbb-utóbb megfeleljen az alapesetnek.

A rekurzív függvényeket ugyanúgy definiáljuk, mint a hagyományos függvényeket, csak a `rec` módosítóval. E módosító nélkül a függvény _nem_ tudja meghívni önmagát, és minden ilyen kísérlet fordítási hibát eredményez. A rekurziót tehát kifejezetten kérni kell.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

Az F# emellett rekurzív típusokat is támogat, méghozzá diszkriminált unió típusokon keresztül. Egy rekurzív diszkriminált unió típus esetei közül egy vagy több a saját adatában magára a diszkriminált unió típusra hivatkozik. A rekurzív függvényekhez hasonlóan a rekurzív típusoknak is kell alapesetük. A rekurzív függvényekkel ellentétben viszont a rekurzív típusok nem használják a `rec` kulcsszót.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
