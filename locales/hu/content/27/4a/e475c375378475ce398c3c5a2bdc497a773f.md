# Bevezetés

A Go-ban a `map` egy beépített adattípus, amely kulcsokat rendel értékekhez.
Más programozási nyelvekben a `map` fogalmát ismerheted szótár, hash-tábla, kulcs-érték tároló vagy asszociatív tömb néven.

Szintaktikailag a `map` így néz ki:

```go
map[KeyType]ElementType
```

Azt is fontos tudni, hogy minden kulcs egyedi, ami azt jelenti, hogy ha ugyanazt a kulcsot kétszer rendeled hozzá, az felülírja a megfelelő kulcshoz tartozó értéket.

Egy `map` létrehozásához így tehetsz:

```go
  // With map literal
  foo := map[string]int{}
```

vagy

```go
  // or with make function
  foo := make(map[string]int)
```

Íme néhány művelet, amit egy `map`-pel elvégezhetsz

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

Ha olyan kulcs értékét próbálod lekérdezni, amely nem létezik a `map`-ben, akkor az értéktípus nullaértékét kapod vissza.
Ez összezavarhat, különösen akkor, ha az `ElementType` alapértéke (például egy int esetében a 0) érvényes érték.
Annak ellenőrzésére, hogy egy kulcs létezik-e a `map`-ben, ezt használhatod:

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
