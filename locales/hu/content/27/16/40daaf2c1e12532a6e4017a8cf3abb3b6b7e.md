# Névjegy

## Bevezetés

A generikus típusok olyan nyelvi funkció, amely lehetővé teszi a kód újrafelhasználását.
Például ahhoz, hogy kiszámítsuk egy lista hosszát, nem szabad, hogy számítson, milyen típust tárol a lista.
Ezért használ a `length` függvény egy `a` generikus típusparamétert a típusszignatúrájában.

```elm
length : List a -> Int
```

## Paraméterek a típusokban

Amikor egy típus egy másik típusra nézve generikus, akkor arra a másik típusra kisbetűs nevet használunk, és típusparaméternek nevezzük.
Gyakori példák erre a `List`, a `Maybe` és a `Result` egyedi típusok.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Egy fontos megjegyzés a típusparaméterek nevéhez: több karakterből is állhatnak.
Az egyetlen megkötés, hogy kisbetűs nevek kell legyenek.
Ezért amikor hasznos, leíró neveket adunk nekik.

Egy típus több másik típusra nézve is lehet generikus, így több típusparamétere is lehet.
Ebben az esetben minden független típus különböző kisbetűs nevet kap.
Az, hogy függetlenek, nem akadálya annak, hogy ugyanaz a típus legyenek, csupán lehetővé teszi, hogy különbözőek legyenek.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

A rekordtípus-aliasoknak is lehetnek típusparamétereik, bár ez kevésbé gyakori.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## Típusparaméterek a függvényekben

Mivel a típusok lehetnek generikusak, a függvények is azok lehetnek.
Írhatunk generikus típusokkal dolgozó függvényeket, például a `Maybe.withDefault`-ot.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Azokat a függvényeket, amelyek más függvényeket vesznek át paraméterként, magasabb rendű függvényeknek nevezzük, és ezek is lehetnek generikusak.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
