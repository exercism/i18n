# Bevezetés

A Go alapvető numerikus típusai egész vagy lebegőpontos értékek halmazát képesek reprezentálni.

Ez a fogalom két számtípusra összpontosít:

- `int`: pl. `0`, `255`, `2147483647`.
   Egy előjeles egész szám, amely legalább 32 bites (értéktartománya: -2147483648-tól 2147483647-ig).
   Ez azonban a rendszer architektúrájától függ.
   A legtöbb modern számítógép 64 bites, ezért az `int` mérete 64 bit lesz (értéktartománya: -9223372036854775808-tól 9223372036854775807-ig).

- `float64`: pl. `0.0`, `3.14`.
   A 64 bites lebegőpontos számok halmazát tartalmazza.

A Go támogatja a szabványos aritmetikai operátorokat: `+`, `-`, `*`, `/` és `%` (maradékosztás, nem modulo).

A Go-ban egy érték különböző típusok közötti hozzárendeléséhez explicit konverzió kell.
Ha például egy `int` értéket `float64`-té szeretnél alakítani, a következőt kell tenned:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
