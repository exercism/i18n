## MacOS

Először telepítsd a Lua-t és a [Luarocks][2]-ot a [Homebrew][1] segítségével:

```shell
$ brew install lua luarocks
```

Ezután telepítsd a [Busted][3] tesztkeretrendszert Lua-hoz:

```shell
$ luarocks install --local busted
```

Add hozzá a `~/.luarocks/bin` könyvtárat a rendszered `$PATH` változójához:

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

Ne feledd, ez csak ideiglenes.
Ha tartósan szeretnéd hozzáadni a `$PATH`-hoz, akkor attól függően, hogy melyik shellt használod, be kell írnod a `.bashrc`, `.zshrc` vagy `config.fish` fájlba.

Ezután futtasd a teszteket:

```shell
$ busted
```

## Windows 10: WSL

Először engedélyezned kell a [WSL (Windows Subsystem for Linux)][7] szolgáltatást a [PowerShell][8] (rendszergazdaként) használatával:

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

Ez újraindítást igényel.

Ezután telepítsd az Ubuntu-t a [Microsoft Store][9]-ból, **vagy** töltsd le, majd telepítsd PowerShell-lel:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

Ezután frissítsd a csomaglistádat:

```shell
PS> wsl
$ sudo apt-get update
```

Most már készen állsz a [LuaRocks][2] és a [Busted][3] telepítésére, ha követed a fenti [Ubuntu utasításokat](#ubuntu).

Ha ezzel megvagy, a teszteket közvetlenül bármelyik Windows parancssorból futtathatod:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### A Gitbash telepítése

Ez a lépés nem kötelező. Lehet, hogy kicsit módosítanod kell a következő lépéseken, ha inkább a Windows natív parancssori felületét vagy egy másik parancssori felületet szeretnél használni.

Letöltés [itt][10].
Telepítési útmutató [itt][11].

### A Docker telepítése

Kövesd az utasításokat a [Docker for Windows][12] telepítéséhez.
Miután befejezted a telepítést, az alábbi parancs futtatásával ellenőrizheted, hogy megfelelően telepítetted-e.

```shell
$ docker --version
```

_Előfordulhat, hogy hibaüzenetet kapsz, amikor először próbálod futtatni a Dockert._

`cannot enable hyper-v service`

_Ha ez előfordul, kövesd ezeket az utasításokat a [Hyper V engedélyezéséhez][13]. Lehet, hogy le kell tiltanod a beállítást, újra kell indítanod a számítógépet, és az indítás után újra engedélyezned kell._

### A busted telepítése

Miután telepítetted a Gitbash-t és a Dockert, telepíthetsz egy busted 'konténert'.

A Gitbashben futtasd a következőt:

Töltsd le ezt a széles körben használt Docker-konténert a következő futtatásával:

```shell
$ docker pull imega/busted
```

Hozz létre egy függvényt, hogy ne kelljen minden alkalommal beírnod a teljes parancsot.
Add hozzá ezt a `.bashrc` fájlhoz:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

Most a parancssori felületen beléphetsz abba a könyvtárba, amelyben a teszteket futtatni szeretnéd. Futtasd a következőt:

```shell
$ dbusted $PWD
```

Látnod kell a busted tesztjeid kimenetét.
