# Bevezetés

A C# típusok definiálhatók egy class vagy struct scope-ján belül. A befoglaló típus egyfajta namespace-t biztosít. A típushoz a befoglaló típuson keresztül férsz hozzá, pont szintaxissal.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

A belső típusokhoz beállíthatsz hozzáférési szinteket.

A külső típus privát tagjai a belső típus tagjainak a scope-jába tartoznak, de fordítva nem.
