# Bemutató

A PHP-ban egy változót is meghívhatunk függvényként, ha zárójelet [`()`] teszünk utána. Amikor a PHP megpróbálja meghívni a függvényt, olyan függvényt keres, amelynek a neve megegyezik a változó értékével.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## Statikus osztályfüggvények meghívása

A statikus osztályfüggvényeket ugyanígy hívhatjuk meg:

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## Osztálypéldányok függvényeinek meghívása

Egy osztálypéldány függvényét is meghívhatjuk:

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
