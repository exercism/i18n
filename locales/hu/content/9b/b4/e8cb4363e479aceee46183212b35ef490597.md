# Részletesen

## Aritmetikai operátorok

A JavaScript 6 különböző operátort kínál a számokon végzett alapvető aritmetikai műveletekhez.

- `+`: Az összeadás operátor két szám összegének kiszámítására szolgál.

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: A kivonás operátor két szám különbségének meghatározására szolgál.

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: A szorzás operátor két szám szorzatának kiszámítására szolgál.

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: Az osztás operátor két szám elosztására szolgál.
  Mivel a JavaScript számai mindig lebegőpontos számok, nincs egészosztás.

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: A maradék operátor egy elvégzett osztás maradékának meghatározására szolgál.

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: A hatványozás operátor egy szám hatványra emelésére szolgál.
  Ez megegyezik a [`Math.pow()`][mdn-math-pow] használatával.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## A műveletek sorrendje

Ha egy sorban több operátort használsz, a JavaScript követi a precedenciasorrendet, amelyet [ez a precedenciatáblázat][mdn-operator-precedence] mutat.
Hogy a mi esetünkre egyszerűsítsük: a JavaScript az általános iskolai matematikaórákon tanult PEDMAS-szabályt használja (zárójel, hatvány, osztás/szorzás, összeadás/kivonás).

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## Rövidített értékadó operátorok

A rövidített értékadó operátorok rövidebb módját adják annak, hogy olyan kódot írjunk le, amely aritmetikai műveletet végez egy változón, majd az új értéket ugyanannak a változónak adja.
Vegyünk például két változót, `x`-et és `y`-t.
Ekkor az `x += y` ugyanazt jelenti, mint az `x = x + y`.
Ezt gyakran egy számmal használjuk `y` változó helyett.
A többi 5 művelet is elvégezhető hasonló módon.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
