# Utasítások

A helyi költőklub új évadot kezd. A költők csatlakoznak a klubhoz, és valahányszor ketten közösen írnak egy verset, ugyanannak az *írókörnek* a tagjaivá válnak. A klub szeretné nyomon követni, hogy ki kivel osztozik egy írókörön, és téged kértek meg, hogy megírd azokat a szavakat, amelyek ezt kezelik.

A diszjunkt halmaz pont ideális erre: minden költő egy atom, és egy írókör egy csoport.

## 1. Nyisd meg a klubot

Definiáld a `new-club` szót, amely egy költők sorozatát veszi át, és egy friss diszjunkt halmazt ad vissza, amelyben minden költő regisztrálva van. Minden költő a saját írókörében kezd.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. Jegyezz fel egy együttműködést

Definiáld a `collaborate` szót, amely két költőt és egy klubot vesz át. Összevonja a két költő írókörét, és visszaadja a klubot, hogy az együttműködéseket egymás után fel lehessen jegyezni.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. Keresd meg egy költő írókörét

Definiáld a `circle-of` szót, amely egy költőt és egy klubot vesz át, és visszaadja a költő írókörének reprezentánsát. Két költő, aki ugyanabban az írókörben van, mindig ugyanazt a reprezentánst jelenti.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. Közös írókörben vannak?

Definiáld a `same-circle?` szót, amely két költőt és egy klubot vesz át, és `t`-t ad vissza, ha mindkét költő ugyanahhoz az írókörhöz tartozik, egyébként pedig `f`-et. A költők reprezentánsait hasonlítsd össze ahelyett, hogy beépített egyenlőségvizsgálatot használnál.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
