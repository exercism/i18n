# Tesztek

Ha a feladat könyvtárából szeretnéd futtatni a teszteket, add ki a következő parancsot:

```sh
odin test .
```

Amíg tesztelsz, az Odin átvizsgálhatja a kódodat: olyan dolgokat kereshet, mint a nem használt importok és változók. A teszteket így futtathatod:

```sh
odin test . -vet
```

További lehetőségekért nézd meg az `odin test -help` parancsot.
