# Bevezetés

A leghasznosabb sorozatszavak egyik bemenete egy *quotation*, amellyel
a műveletet vezérlik:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

A `map-sum` (szintén a `sequences` szótárban) végigfuttat egy quotationt
a sorozaton, és az eredményeket egyetlen menetben összegzi. Ugyanez a
minta működteti a `sort-by`-t (a [`sorting`][sorting] szótárban), valamint
a `minimum-by` és `maximum-by` szót (a `sequences` szótárban).

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
