# Bevezetés

A Góban a konstans egy egyszerű, változatlan érték, amelyet a `const` kulcsszóval rendelünk egy névhez:

```go
const myWebsite = "Exercism"
```

Az ilyen konstansok típus nélküliek, de a szintaxisuk alapján kapnak egy alapértelmezett típust, amikor típusra van szükség, például amikor egy metódusnak adjuk át őket.
Típusos konstansokat úgy hozhatunk létre, hogy kifejezetten megadunk egy típust:

```go
const myWebsite string = "Exercism"
```

A Góban nincsenek felsorolástípusok, mint néhány más nyelvben, viszont van egy előre deklarált azonosító, az `iota`, amellyel felsorolt konstansokat hozhatunk létre.
Egy blokkon belüli konstansok implicit módon ismétlődnek:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
