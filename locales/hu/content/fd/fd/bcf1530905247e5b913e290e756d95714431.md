# Bevezetés

A *kupac* olyan gyűjtemény, amely mindig ismeri a legkisebb elemét, és amelyből azt gyorsan eltávolíthatod; ez a *prioritási sor* természetes megvalósítása. A kupacok a [`heaps`][heaps] szókészletben találhatók.

A `<min-heap>` egy üres kupacot hoz létre, amelyből először a legkisebb kulcs kerül ki; a `<max-heap>` ennek a tükörképe. Minden elem egy *érték*, amelyet egy *kulcs* alatt tárolunk, és a kulcs a prioritás:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

A kupac *módosítható*: a `heap-push` helyben változtatja meg. A `heap-peek` visszaadja az első értéket és kulcsot anélkül, hogy eltávolítaná; a `heap-pop` eltávolítja és visszaadja; a `heap-pop-all` pedig prioritási sorrendben egy asszociációs listába üríti a kupacot, amely `{ key value }` párokból áll:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
