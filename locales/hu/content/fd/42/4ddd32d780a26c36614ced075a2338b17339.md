# Utasítások

Nagy rajongója vagy a [Numberphile Youtube-csatornának](https://www.youtube.com/watch?v=PeUbRXnbmms), és épp most láttál egy remek videót a _Lucas Number Sequence_-ről. Ezt a sorozatot szeretnéd Elixirben létrehozni.

A függvényed tervezése közben szeretnéd kihasználni a lusta kiértékelést, hogy annyi számot generálhass, amennyit csak akarsz, de csak akkor, ha tényleg szükséged van rájuk. Ezért úgy döntesz, hogy streamet használsz.

## 1. Szűrd ki a hibás argumentumokat

Adj hozzá egy guard klauzulát, amely hibát dob, ha nem egész számmal vagy 1-nél kisebb egésszel próbálod generálni a sorozatot. Ha ezt már az első lépésben megteszed, elkerülöd a végtelen rekurzióból eredő hibákat a későbbi lépésekben.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. Generáld az alapeseteket

Tudod, hogy a sorozatnak két kezdő száma van, amelyek nem ugyanazt a szabályt követik. Írj két alapeset-klauzulát, amelyek visszaadják ezeket a számokat:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. Hozd létre az általános esetet

Ha a sorozat hosszabb 2-nél, akkor tudod, hogy a következő számhoz az előző kettőt kell összeadnod, és így tovább. Írd meg az általános esetet.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
