# Bevezetés

A Swiftben van néhány olyan utasítás, amellyel megváltoztatható a ciklusok szokásos vezérlési folyama.
Ezeket vezérlésátadó utasításoknak nevezzük.
A `return`-t már láttad; ez a fogalom továbbiakat mutat be, többek között a `continue`-t, a `break`-et és a címkéket.
A `fallthrough`-t nem tárgyaljuk ebben a fogalomban, de olvashatsz róla a [Swift könyvben][fallthrough].

## Continue

Előfordul, hogy a ciklus következő iterációjára kell ugrani, anélkül hogy befejeznénk a ciklus aktuális iterációjának többi utasítását.
Erre használhatod a `continue` kulcsszót.
Amikor a `continue` végrehajtódik, a ciklus a következő ellenőrzéshez ugrik, hogy megnézze, lefuthat-e a ciklus következő iterációja, azaz a while és repeat-while ciklusokban a `while` feltételhez, a for-in ciklusokban pedig ahhoz az ellenőrzéshez, hogy van-e még elem a sorozatban.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

A break a ciklusból való korai kilépésre szolgál.
Amikor a `break` végrehajtódik, a ciklus azonnal kilép, és a program a ciklus utáni első utasítással folytatódik.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Címkék

Amikor a ciklusok egymásba vannak ágyazva, előfordul, hogy a `break` vagy a `continue` segítségével azokból a külső ciklusokból szeretnél kilépni vagy azokat újraindítani, amelyek tartalmazzák azt a ciklust, amelyben a `break` vagy a `continue` szerepel.
Ilyen esetekben címkékkel jelölheted meg, melyik ciklusból lépj ki, illetve melyiket indítsd újra.
Egy ciklust úgy címkézhetsz meg, hogy a ciklust indító `while`, `repeat` vagy `for` elé egy nevet, utána pedig egy kettőspontot írsz.

Hogy lásd, milyen hatása van a címkék ilyen használatának, nézzük meg a következő ciklust.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
