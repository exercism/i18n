# Kiegészítés az utasításokhoz

## Kivételek testreszabása és dobása

Néha szükséges, hogy a kódodban kivételeket egyszerre [testreszabj](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) és [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)-elj. Amikor ezt teszed, mindig adj meg egy **jelentőségteljes hibaüzenetet**, amely jelzi a hiba forrását. Ez olvashatóbbá teszi a kódodat, és jelentősen segít a hibakeresésben.

Egyéni kivételeket új kivételosztályok létrehozásával hozhatsz létre (a részletekért lásd: [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes).) amelyek általában a [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) alosztályai.

Azokban az esetekben, amikor tudod, hogy a hiba forrása egy bizonyos kivételtípus származéka lesz, választhatsz, hogy az _Exception_ osztály alatti [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) egyikéből örökölsz. A hiba dobásakor akkor is adj meg egy jelentőségteljes üzenetet.

Ez a konkrét feladat megköveteli, hogy létrehozz egy _egyéni kivételt_, amelyet [dobni](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/„kiváltani” kell, amikor a verem nincs kellően feltöltve. A tesztek csak akkor fognak sikeresen lefutni, ha testreszabod a megfelelő kivételt, `raise`-eled azt a kivételt, és megfelelő hibaüzeneteket adsz meg.


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

Ezenkívül ez a feladat megköveteli, hogy több `built-in exceptions`-t dobj hibaüzenetekkel.
Ahhoz, hogy egy `built-in exception`-t üzenettel dobj, írd az üzenetet az `exception` típus argumentumaként:

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
