# Bevezetés

Ahhoz, hogy egy globális függvényt definiálj Common Lisp-ben, a `defun` kifejezést használod.
Ez a kifejezés első argumentumaként egy paraméterlistát vár (az üres lista azt jelenti, hogy a függvénynek nincsenek paraméterei).
Ezt követi egy opcionális dokumentációs string (lásd alább), majd nulla vagy több kifejezés, amelyek a függvény „törzsét” alkotják.

A függvényeknek nulla vagy több paraméterük lehet.

```lisp
(defun no-args () (+ 1 1))

(defun add-one (x) (1+ x))

(defun add-nums (x y) (+ x y))
```

Egy függvény meghívása úgy történik, hogy kiértékelünk egy kifejezést, amelyben a függvényt jelölő szimbólum a kifejezés első eleme, a függvény argumentumai (ha vannak) pedig a kifejezés többi eleme.

Az az érték, amelyre egy függvény kiértékelődik, a függvény törzsében kiértékelt utolsó kifejezés értéke. 
Minden függvény kiértékelődik egy értékre.

```lisp
(add-nums 2 2) ;; => 4
```

A függvényeknek opcionálisan dokumentációs stringjük is lehet (más néven „docstring”).
Ha meg van adva, az argumentumlista után, de a függvény törzse előtt áll.
A dokumentációs string a `documentation` segítségével érhető el.

```lisp
(defun add-nums (x y) "Add X and Y together" (+ x y))

(documentation 'add-nums 'function) ;; => "Add X and Y together"

;; Note that if one provides a docstring but fails to provide a body
;; then the docstring is interpreted by Common Lisp as the body, not
;; the docstring
(defun no-body ())
(no-body) ;; => NIL

(defun mistake () "This is not a docstring")
(mistake) ;; => "This is not a docstring"
(documentation 'mistake 'function) ;; => NIL
```
