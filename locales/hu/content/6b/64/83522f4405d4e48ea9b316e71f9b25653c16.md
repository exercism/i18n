# Bevezetés

A `Tuple` sok szempontból nagyon hasonlít a `Vector`-hoz (egydimenziós `array`).
Néhány fontos különbség azonban van.

- A tuple-okat kerek zárójel `( )` közé írjuk szögletes zárójel `[ ]` helyett, bár a kerek zárójel elhagyható, ha a jelentés egyértelmű.
- A tuple-oknak nem kell homogénnek lenniük: minden elem típusát külön tárolja.
- A tuple-ok módosíthatatlanok.

A módosíthatatlanság miatt a fordító több optimalizálást tud végezni, és a tuple-ok gyorsabbak a vektoroknál, ezért érdemes előnyben részesíteni őket, amikor nincs szükség módosíthatóságra.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

Létezik egy `Tuple()` konstruktor is, amely bármilyen bejárható gyűjteményt tuple-vá alakít.
Hasznos módon a stringet karakterek bejárható gyűjteményeként kezeli.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

Bármelyik tuple esetében hozzáférhetsz az elemekhez index alapján, vagy végigmehetsz rajtuk egy ciklussal.

Bármelyik tisztán numerikus tuple használható matematikai függvényekben, például a `sum()` esetében is, pontosan úgy, mint a tömbök.

## Kicsomagolás

Egy tuple kicsomagolható az egyes elemeire többes értékadással.
A nem szükséges elemek helyére írj aláhúzásjelet `_` dummy változóként.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

A Python-programozók számára ez a többes értékadásos szintaxis nagyon ismerős lesz.

## Nevesített tuple-ok

A `Tuple` csak értékeket tartalmaz.
A `NamedTuple` minden értékhez hozzárendel egy nevet.

Az egyes mezők ezután »pont« jelöléssel érhetők el:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

A nevet a rendszer belül `Symbol` típusként tárolja (módosíthatatlan típus, kettőspont `:` előtaggal), ezért egy alternatív szintaxis is elérhető:

```julia-repl
julia> nt[:b]
7.3
```

Könnyen hozzájuthatsz külön a nevekhez (más néven »kulcsok«) vagy az értékekhez:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

Vedd figyelembe, hogy egy nevesített tuple bejárása csak az _értékeket_ adja, a _neveket_ figyelmen kívül hagyja.

A tuple-ok (akár nevesítettek, akár nem) nagyon gyakori módjai a strukturált adatok függvényekhez való átadásának és visszavételének.
Ebben a felhasználási esetben a módosíthatatlanság előnyös: adatbiztonságot nyújt, és agresszívabb fordítói optimalizálást tesz lehetővé.
