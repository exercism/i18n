# Utasítások kiegészítése

## Tippek

A `decode` és `encode` függvényeket kell megvalósítanod, amelyek egy `String`-et kódolnak és dekódolnak affin rejtjel segítségével.
Használhatod a megadott szignatúrát, ha bizonytalan vagy a típusokban, de ne hagyd, hogy korlátozza a kreativitásodat.

Ez a feladat szöveges adatokkal dolgozik.
Történelmi okokból a Haskell `String` típusa a `[Char]`, azaz karakterek listájának szinonimája.
A szöveges adatok hatékonyabb kezeléséhez a `Text` típus használható.

A feladat opcionális kiegészítéseként a következőket teheted:

- vedd fel a `- text` elemet a package.yaml függőségeid listájára.
- importáld a `Data.Text` modult [a következő módon](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- használd a `Text` típust, például `decode :: Text -> Text`, és hivatkozz a `Data.Text` kombinátoraira például így: `T.pack`.
- keresd ki a [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) dokumentációját.
- cseréld le a `String` minden előfordulását `Text`-re az Affine.hs fájlban, azaz:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

Ez a rész teljesen opcionális.
