# Névjegy

Az F#-ban a Boolean értékeket a `bool` típus képviseli, amelynek értéke `true` vagy `false` lehet.

Az F# három [Boolean operátort][operators] támogat: a `not` (NOT), a `&&` (AND) és a `||` (OR) operátort. A `&&` és `||` operátor _rövidre záró kiértékelést_ használ, ami azt jelenti, hogy az operátor jobb oldalát csak akkor értékeli ki, amikor arra szükség van.

```fsharp
true || false // => true
true && false // => false
```

A három Boolean operátornak más-más az _operátorprecedenciája_. Emiatt a kiértékelés sorrendje a következő: először a `not`, aztán a `&&`, végül a `||`. Ha „ki akarsz szökni” ezek alól a szabályok alól, zárójelbe (`()`) tehetsz egy Boolean kifejezést, mert a zárójelnek még nagyobb az operátorprecedenciája.

```fsharp
not true && false   // => false
not (true && false) // => true
```
