# Névjegy

A Gleam `Iterator` típusa abban hasonlít a listához, hogy ez is értékek rendezett gyűjteménye, ahol minden érték azonos típusú. A listától abban tér el, hogy lusta: nem tárolja egyszerre az összes értékét a memóriában, hanem akkor számolja ki őket, amikor éppen szükség van rájuk.

Ez akkor hasznos, ha nagyon nagy, sőt végtelen sorozatokkal dolgozunk, mert így akkor is kezelni tudjuk őket, ha nincs elég szabad memóriánk ahhoz, hogy egyszerre tároljuk az összeset.

A `gleam/iterator` modul definiálja az `Iterator` típust, valamint az iterátorokkal való munkához szükséges függvényeket.

A listákhoz használt függvények közül sok iterátorokra is létezik, például a `map`, a `filter` és a `take`. Ezek a függvények iterátorokat adnak vissza, így valójában semmilyen munkát nem végeznek addig, amíg az iterátort fel nem használjuk.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

Az `unfold` függvénnyel olyan iterátorokat hozhatunk létre, amelyek egy ismételten meghívott függvényből állítják elő a sorozat következő értékét.

Az alábbi példában az `unfold` függvény egy olyan iterátort hoz létre, amely a Fibonacci-sorozatot állítja elő:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

Ez a sorozat végtelen, ezért a `take` függvénnyel tesszük végessé, mielőtt az értékeket listába gyűjtenénk. Ha egy végtelen iterátoron hívjuk meg a `to_list` függvényt, a program addig fut, amíg el nem fogy a memória, és össze nem omlik.
