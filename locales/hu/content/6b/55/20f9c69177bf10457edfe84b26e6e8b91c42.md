# Utasítások

A csapatod egy meteorológiai alkalmazáson dolgozik.
Definiáltak egy API-t, amely különböző, meteorológiai adatokat reprezentáló típusokat és konstansokat tartalmaz; lásd a `meteorology.go` fájlt.

A feladatod, hogy minden típushoz adj hozzá megfelelő `String` metódusokat, hogy implementálják a `Stringer` interfészt.

## 1. Implementáld a `Stringer` interfészt a `TemperatureUnit` típushoz

Némi vita után a csapat abban állapodott meg, hogy a hőmérséklet mértékegysége `Celsius` vagy `Fahrenheit` lesz.
Az értékeket az alábbi példák szerint kell formázni.

Ahhoz, hogy a `TemperatureUnit` típus implementálja a `Stringer` interfészt, adj hozzá egy `String` metódust.
Ennek a metódusnak a `"°C"` stringgel kell visszatérnie, ha a hőmérséklet mértékegysége Celsius, illetve a `"°F"` stringgel, ha a hőmérséklet mértékegysége Fahrenheit.

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. Implementáld a `Stringer` interfészt a `Temperature` típushoz

A hőmérsékletértékek egy egész számból és egy hőmérséklet-mértékegységből állnak.
Formázásuk az alábbi példák szerint történik.

Ehhez add hozzá a `Temperature` típushoz a `String` metódust, hogy implementálja a `Stringer` interfészt.
Ennek a metódusnak egy stringet kell visszaadnia, amelyben a hőmérséklet számértéke és a hőmérséklet mértékegysége egy szóközzel elválasztva szerepel: `<temperature> <unit>`:

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. Implementáld a `Stringer` interfészt a `SpeedUnit` típushoz

Hosszas megbeszélések után a csapat abban állapodott meg, hogy a szélsebesség mértékegysége `KmPerHour` vagy `MilesPerHour` lesz.
Az értékeket az alábbi példák szerint kell formázni.

Ehhez add hozzá a `SpeedUnit` típushoz a `String` metódust, hogy implementálja a `Stringer` interfészt.
Ennek a metódusnak a `"km/h"` stringgel kell visszatérnie, ha a sebesség mértékegysége kilométer per óra, illetve a `"mph"` stringgel, ha a sebesség mértékegysége mérföld per óra:

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. Implementáld a `Stringer` interfészt a `Speed`-hez

A szélsebességértékek egy egész számból és egy sebességmértékegységből állnak.
Formázásuk az alábbi példa szerint történik.

Ehhez add hozzá a `Speed` típushoz a `String` metódust, hogy implementálja a `Stringer` interfészt.
Ennek a metódusnak egy stringet kell visszaadnia, amelyben a sebesség számértéke és a sebesség mértékegysége egy szóközzel elválasztva szerepel: `<speed> <unit>`:

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. Implementáld a `Stringer` interfészt a `MeteorologyData` típushoz

A meteorológiai adatok megadják a helyszínt, a hőmérsékletet, a szélirányt, a szélsebességet és a páratartalmat.
Formázásuk az alábbi példa szerint történik:

Ehhez add hozzá a `MeteorologyData` típushoz a `String` metódust, hogy implementálja a `Stringer` interfészt.
Ennek a metódusnak a következő formátumban kell visszaadnia a meteorológiai adatokat:

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
