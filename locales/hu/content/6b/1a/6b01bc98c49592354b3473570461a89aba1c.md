# Ismertető

## Modulok

A Gleam-kód modulokba rendeződik, és minden fájl egy Gleam-modul.

Eddig a `pub fn` szintaxissal írtunk függvényeket, amely egy más modulok számára nyilvánosan elérhető függvényt definiál. A `fn` kulcsszóval definiált függvények csak abban a modulban érhetők el, amelyben definiálták őket, és más modulok nem használhatják őket.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

A Gleam-moduloknak nevük van, és a név a `src` vagy `test` könyvtáron belüli fájlútvonalukon alapul.

Például egy `src\geometry\rectangle.gleam` (Windows esetén) vagy `src/geometry/rectangle.gleam` (UNIX-szerű operációs rendszereken) fájlban definiált modul neve `geometry/rectangle` lenne.

## Függvények importálása más modulokból

A más modulokban definiált függvényeket importokkal érhetjük el.
Az adott modulban található, általa közzétett összes függvény elérhetővé válik, amikor importálod azt a modult.
Az azonban, hogy hogyan érhetők el, attól függ, hogyan importálod a modult.

A minősített importok az alapértelmezettek, és egy ilyen modulon belüli függvény elérése (például a `map` függvény a `gleam/list` modulban) a modulnév előtagként való használatával történik (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Alapértelmezés szerint a modulra utaló név a modulnév utolsó része, ebben az esetben `int`, de ez az `as` kulcsszóval megváltoztatható.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

A nem minősített importok közvetlen hozzáférést biztosítanak az adott modulban közzétett függvényekhez, előtag használata nélkül.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

A minősített importok előnyösebbek, mert világosabbá teszik az olvasó számára, hogy honnan származik egy függvény, és segítenek elkerülni a névütközéseket.
