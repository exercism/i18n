# Utasítások

Ebben a feladatban segédrutinok egy részét fogod megvalósítani, hogy segíts egy fejlesztőnek rendbe tenni a SqueakyClean neveket.

A 4 részfeladatban lépésről lépésre építed fel a `clean` metódust.
Egy érvényes SqueakyClean név nulla vagy több betűből és alulvonásból áll.

A bemeneti string minden esetben garantáltan nem null. Ne feledd, hogy a `clean` metódusnak érvényesként kell kezelnie az üres stringet is.

## 1. Cseréld alulvonásra az előforduló szóközöket

Valósítsd meg a (_static_) `SqueakyClean.clean()` metódust úgy, hogy a szóközöket alulvonásra cserélje. Ez a vezető és záró szóközökre is vonatkozik.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Alakítsd át a kebab-case-t camelCase-re

Módosítsd a (_static_) `SqueakyClean.clean()` metódust, hogy a kebab-case-t camelCase-re alakítsa.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Alakítsd át a leetspeaket normál szöveggé

Módosítsd a (_static_) `SqueakyClean.clean()` metódust, hogy a [leetspeaket][leet-speak] normál szöveggé alakítsa.

Az egyszerűség kedvéért csak a `4`, `3`, `0`, `1` és `7` karaktereket cseréljük `a`, `e`, `o`, `l`, illetve `t` betűre.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Hagyd ki a nem betű karaktereket

Módosítsd a (_static_) `SqueakyClean.clean()` metódust, hogy kihagyja azokat a karaktereket, amelyek nem betűk.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
