# A fogalomról

A Go slice-jai hasonlítanak más nyelvek listáihoz vagy tömbjeihez.
Egy adott típus (vagy interfész) több elemét tárolják.

A Go slice-jai tömbökön alapulnak.
A tömbök mérete rögzített.
A slice ezzel szemben egy tömb elemeinek dinamikusan méretezett, rugalmas nézete.

A slice-t így írjuk: `[]T`, ahol a `T` a slice elemeinek típusa:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

A megadott, nullától számolt indexű elemet a szögletes zárójeles jelöléssel kérheted le vagy állíthatod be:

```go
withData[1] = 5
x := withData[1] // x is now 5
```

Új slice-t hozhatsz létre egy meglévő slice-ból úgy, hogy egy elemtartományt kérsz le belőle.
Ehhez megint a szögletes zárójeles jelölést használod, de most a kezdő (beleértve) és a záró (nem beleértve) indexet is megadod.
Ha nem adsz meg kezdő indexet, az alapértelmezett értéke 0.
Ha nem adsz meg záró indexet, az a slice hossza lesz.

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

Elemeket az `append` függvény segítségével adhatsz egy slice-hoz.
Az alábbi példában a `4`-et és a `2`-t fűzzük hozzá az `a` slice-hoz.

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

Az `append` mindig új slice-t ad vissza, és ha csak elemeket szeretnénk hozzáfűzni egy meglévő slice-hoz, gyakran visszaértékeljük az eredményt abba a slice-változóba, amelyet első argumentumként adtunk át, ahogy fent is tettük.

Az `append` két slice összefűzésére is használható:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## Indexek a slice-okban

Amikor slice-ok indexeivel dolgozol, mindig védekezned kell valamilyen ellenőrzéssel, ami biztossá teszi, hogy az index valóban létezik.
Ha ezt elmulasztod, az egész alkalmazás összeomlik.

## Üres slice-ok

A `nil`-slice-ok jelentik az alapértelmezett üres slice-t.
Nincs semmi hátrányuk az olyan slice-okkal szemben, amelyekben nincsenek értékek.
A `len` függvény működik a `nil`-slice-okon, elemeket inicializálás nélkül is hozzáadhatsz hozzájuk, és így tovább.
Ha új slice-t hozol létre, inkább a `var s []int` (`nil`-slice) formát válaszd a `s := []int{}` (üres, nem `nil` slice) helyett.

## Teljesítmény

Amikor iteratívan feltöltendő slice-okat hozol létre, könnyen javíthatsz a teljesítményen, ha ismert a slice végleges mérete.
A kulcs, hogy a lehető legkevesebbszer kelljen memóriát lefoglalni, ami meglehetősen költséges, és akkor fordul elő, ha a slice túlnő a számára lefoglalt memóriaterületen.
Ezt a legbiztonságosabban úgy csinálhatod meg, hogy megadod a slice kapacitását (`cap`) az `s := make([]int, 0, cap)` hívással, majd a szokásos módon az `append` segítségével fűzöl hozzá elemeket.
Így azonnal lefoglalódik `cap` darab elem helye, miközben a slice hossza nulla.
A gyakorlatban a `cap` gyakran egy másik slice hossza: `s := make([]int, 0, len(otherSlice))`.

## Az `append` nem tiszta függvény

A Go `append` függvénye a teljesítményre van optimalizálva, ezért nem készít másolatot a bemeneti slice-ról.
Ez azt jelenti, hogy az eredeti slice (az `append` első paramétere) néha megváltozik.
