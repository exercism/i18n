# Bemutatás

A [szimbólumok][symbols] olyan elnevezett azonosítók, amelyekkel egy értékre hivatkozhatunk.
A szimbólumok szimbólumliterál segítségével jönnek létre, mégpedig úgy, hogy a név elé egy `:` karaktert írunk, például `:foo`.
Idézőjelek között is leírhatók, például `:"foo"`, így például szóköz is szerepelhet a névben.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

A nyelv sok helyen használ szimbólumokat: többek között hashek kulcsaiként, metódusnevek és változónevek jelölésére.

## Azonosító

Az a különbség a szimbólumok és a stringek között, hogy a szimbólumok azonosítók, nem pedig adatot vagy szöveget jelölnek.
Ez azt jelenti, hogy két azonos nevű szimbólum mindig ugyanaz az objektum.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## Szimbólumok módosítása

A szimbólumok megváltoztathatatlanok, ami azt jelenti, hogy nem lehet őket módosítani.
Ez azt jelenti, hogy amikor „módosítasz” egy szimbólumot, valójában egy új szimbólumot hozol létre.
Néhány metódussal lehet szimbólumokat manipulálni, és ezek mind új szimbólumot adnak vissza.
Az összes metódus megtalálható a [Symbol API][symbols-api] oldalon.

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

Az az előnye annak, hogy a szimbólumok megváltoztathatatlanok, hogy memóriatakarékosabbak, mint a stringek, ugyanakkor biztonságosabbak azonosítóként használni őket.

## Konvertálás

A szimbólumokat át lehet alakítani stringekké, és fordítva.
Ez akkor lehet hasznos, ha módosítani szeretnél egy szimbólumot, vagy ha szimbólumot szeretnél stringként használni.
Ahhoz, hogy egy stringet szimbólumként jeleníts meg, a `String#to_sym` metódust használhatod, az ellenkezőjéhez pedig a `Symbol#to_s` metódust.
Mivel a szimbólumoknak csak korlátozott számú metódusuk van, hasznos lehet szimbólumot stringgé alakítani, hogy stringmetódusokat használhass rajtuk, ha új szimbólumra van szükség.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
