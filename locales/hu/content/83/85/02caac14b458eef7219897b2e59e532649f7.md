# Bevezetés

A függvény egy szervezett, újrafelhasználható kódblokk, amelyet valamilyen művelet elvégzésére használunk.
JavaScriptben többféleképpen is definiálhatunk függvényeket.
Most a _függvénydeklarációkat_ és a _függvénykifejezéseket_ nézzük meg.
Más lehetőségekkel, például a [nyílfüggvényekkel][concept-arrow-functions], más fogalmaknál foglalkozunk majd.

## Függvénydeklaráció

A függvények definiálásának szokásos módja JavaScriptben a _függvénydeklaráció_, amelyet _függvénydefiníciónak_ vagy _függvényutasításnak_ is neveznek.

A `function` kulcsszóból, a függvény nevéből, valamint a kerek zárójelben felsorolt, vesszővel elválasztott paraméterekből áll.
Ezt követi a függvény törzse (az utasítások gyűjteménye, amely meghatározza, mit tesz a függvény), kapcsos zárójelbe zárva.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

JavaScriptben egy függvényt úgy hívunk meg, hogy leírjuk a függvény nevét, majd utána zárójelben megadjuk az argumentumokat.

```javascript
someName(arg1, arg2, arg3);
```

## Paraméterek

Amikor a függvény törzsén belül paraméterekkel dolgozol, légy tisztában a lehetséges mellékhatásokkal.

- A [primitív adattípusok][mdn-primitives] értékei _módosíthatatlanok_.
  Az eredeti értéket soha nem befolyásolja, hogy mi történik az argumentummal a függvény törzsében.
- Minden más érték (objektumok, tömbök, függvények) esetében az újraértékadás nem befolyásolja az eredeti értéket.
  Ha viszont módosítod az ilyen argumentumot (például hozzáadsz egy kulcsot egy objektumhoz), az az átadott eredeti értéket is módosítja.

JavaScriptben alapértelmezés szerint a függvénydeklarációban megadott összes paraméter opcionális.
Ha kevesebb argumentumot adsz meg, mint amennyi paraméter van, a hiányzó argumentumok értéke `undefined` lesz a függvényen belül, lásd [Null és undefined][concept-null-undefined].
Sok esetben érdemes egy megfelelőbb alapértelmezett értéket adni az `undefined` helyett.
Ezt úgy teheted meg, hogy közvetlenül a függvénydefinícióban adsz meg alapértelmezett paramétereket.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## A `return` utasítás

A `return` utasítás befejezi a függvény végrehajtását, és megadja a függvény hívójának visszaadandó értéket. Egy függvényben több `return` utasítás is lehet.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

Annak a függvénynek az eredménye, amely nem ad vissza értéket, vagy nincs benne `return` utasítás, `undefined`.
JavaScriptben nincsenek implicit `return` utasítások.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

JavaScriptben csak pontosan egy értéket adhatsz vissza.
Ha több információt szeretnél átadni, először egyetlen egységbe kell összevonni, általában egy [objektumba][concept-objects] vagy egy [tömbbe][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Függvénykifejezés

A függvénydeklaráció önálló utasítás.
Néha viszont hasznos, ha egy függvényt egy másik kifejezés részeként definiálunk, például értékadásban, függvényparaméterként ([callback][concept-callbacks]) vagy egy [objektum][concept-objects] értékeként.
Ezt függvénykifejezéssel teheted meg.
Ugyanaz a szintaxisa, mint a függvénydeklarációnak, azzal a különbséggel, hogy a függvény nevét elhagyhatod, így _névtelen függvényt_ hozhatsz létre.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
