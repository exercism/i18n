# Bevezetés

## Generikusok

Egy típus akkor _generikus típus_, ha egy _típusparaméter_ segítségével bármilyen típusú értéket tartalmazhat.

Például ennek a `Box` típusnak az `a` a típusparamétere (kisbetűvel írva).

```gleam
pub type Box(a) {
  Box(a)
}
```

Az `a` típusparaméter bármilyen típus helyőrzője, így a `Box` használható stringekkel, int-ekkel vagy bármilyen más típussal.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

Egy típusnak több típusparamétere is lehet, ezeket vesszővel választjuk el.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

### Generikus függvények

A típusparamétereket a függvények argumentumaiban is használhatjuk.

Ez a függvény egy `a` típusú értéket kap, és kétszer meghív egy olyan függvényt, amely egy `a` típusú értéket kap és egy `b` típusút ad vissza.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
