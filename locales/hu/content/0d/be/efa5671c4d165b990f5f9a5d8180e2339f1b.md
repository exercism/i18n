# Bemutatás

Az Elmben a [Custom Types][custom-types] rögzített számú, megnevezett esetet ír le. Minden érték pontosan egy megnevezett esetnek felel meg. Más nyelvekben és kontextusokban ezeket _összegtípus_, _diszkriminált unió_, _címkézett unió_ és _algebrai adattípus_ néven ismerik.

A diszkriminált unió minden esetéhez tartozhat opcionálisan adat, és a különböző esetekhez különböző típusú adat tartozhat. Ha egyik esethez sem tartozik adat, akkor a diszkriminált unió ahhoz hasonló, amit más nyelvek általában _felsorolásnak_ (vagy _enumnak_) neveznek.

Egy Custom Type létrehozásához a `type` kulcsszót használod, és ehhez nagyon kevés szintaxis kell. Ez az Elm-programozás egyik legfontosabb technikája: arra szolgál, hogy a kódban lehetséges értékek pontosan megegyezzenek a való élet érvényes értékeivel. Így nem marad hely érvénytelen adatoknak, és lehetetlenné válik, hogy [a lehetetlen állapotok megjelenjenek a kódban][impossible-states].

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

Egy adott esethez tartozó értéket létrehozhatsz úgy, hogy a nevére hivatkozol (`Spring`), ha az ugyanabban a modulban van definiálva, vagy az `import SeasonModule exposing (Season(..))` stílusú szintaxissal importáltad; illetve a teljesen minősített nevére hivatkozva (`Season.Spring`), ha az `import SeasonModule exposing (Season)` stílusú szintaxissal importáltad.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

A Custom Type-oknak, akárcsak az Elmben mindennek, _strukturális egyenlőségük_ van: ez azt jelenti, hogy két érték akkor egyenértékű, ha ugyanahhoz az esethez tartozik, és ugyanazok az (opcionális) adatai.

A Custom Type-okkal a legkényelmesebben [mintaillesztéssel][pattern-matching] dolgozhatsz:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
