# Bevezetés

A függvények alapértelmezett értékeket deklarálhatnak egy vagy több argumentumhoz. Nézzük meg ezt a függvényt:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Fordításkor az Elixir létrehoz egy függvénydefiníciót a `number/0` (argumentum nélküli) és a `number/1` (egy argumentumos) függvényhez.

Ha egynél több argumentumnak van alapértelmezett értéke, akkor az alapértelmezett értékek balról jobbra töltik ki a hiányzó argumentumokat.

Ha a függvénynek egynél több klóza van, az alapértelmezett argumentumokat egy függvényfejlécben (törzs nélküli függvényben) kell definiálni a függvényklózok előtt:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
