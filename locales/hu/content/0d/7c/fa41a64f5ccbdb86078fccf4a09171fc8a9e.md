# Névjegy

Bármely érték lehet hiba. A `throw` (a `kernel` szótárban) jelez: az aktuális szó veremhatása elvész, és a vezérlés a legközelebbi befoglaló `recover`-hoz tekeredik vissza.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

Az `ERROR:` egy elemző szó, amely egy lépésben definiál egy hiba-tuple osztályt *és* egy konstruktor szót:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

Így minden egyedi hiba kap egy saját osztályt, egy kényelmes dobó konstruktort és egy osztálypredikátumot (`name?`), amellyel az elkapott hibákat tesztelheted:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

A finally stílusú takarításhoz lásd a `cleanup` szót a `continuations` szótárban. Az újraindítható feltételekhez lásd a `condition` szót.
