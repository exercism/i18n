# A fogalomról

Az osztályok a Swift programok egyik alapeleme.
Lehetővé teszik, hogy a kapcsolódó tulajdonságokat (adatokat) és metódusokat (függvényeket) önálló funkcionális egységekbe csoportosítsuk.

### Osztályok definiálása

Egy osztály definiálásához használd a `class` kulcsszót, majd írd le az osztály nevét, az osztálydefiníciót pedig kapcsos zárójelek közé zárva:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

Az osztály törzse tartalmazhat tárolt tulajdonságokat, amelyeket ugyanúgy definiálunk, és amelyek ugyanúgy viselkednek, mint a szokásos konstansok (`let`) vagy változók (`var`).

### Példányok

Egy osztálydefiníció tervrajzként szolgál: meghatároz egy új típust, és leírja, hogyan néznek ki az értékei, de önmagában nem hoz létre egyetlen példányt sem.

Egy osztály _példányának_ létrehozásához írd le az osztály nevét, majd utána egy pár zárójelet, és ezzel meghívod az osztály kezdőértékét:

```swift
let someCharacter = GameCharacter()
```

Ez létrehoz egy új példányt, amelynek tulajdonságai az osztálydefinícióban megadott alapértelmezett értékekkel inicializálódnak.
Az olyan opcionális tulajdonságok esetében, amelyekhez nincs kifejezett alapértelmezett érték (például a `name`), a Swift a `nil` értéket használja alapértékként.

### Tulajdonságok elérése

Egy példány tulajdonságait _pontjelöléssel_ érheted el: írd le a példány nevét, egy pontot (`.`), majd a tulajdonság nevét.
A pontjelölés az egymásba ágyazott tulajdonságoknál is működik.

A pontjelöléssel értékeket olvashatsz ki, és ha a tulajdonság módosítható (`var`), új értéket is adhatsz neki:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Metódusok

A tulajdonságok mellett az osztályok _metódusokat_ is definiálhatnak, vagyis az osztályhoz tartozó függvényeket.

A metódusokat az osztály törzsén belül definiálod a szokásos `func` szintaxissal.
Ha egy metódus megváltoztat egy tulajdonságot, akkor azt a tulajdonságot `var`-ral kell deklarálni:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

A metódusokat egy példányon pontjelöléssel hívod meg, akárcsak a tulajdonságokat:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Egy osztály minden példányának van egy `self` nevű implicit tulajdonsága, amely magára a példányra hivatkozik.
Bár a tulajdonságokra vagy metódusokra való hivatkozáskor gyakran elhagyható, a `self`-et leggyakrabban arra használjuk, hogy megkülönböztessük a tulajdonságok és a metódusparaméterek nevét, amikor azok megegyeznek.
