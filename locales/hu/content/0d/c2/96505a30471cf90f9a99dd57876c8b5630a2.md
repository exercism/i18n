# Utasítások

Amikor épp sütiket készülsz sütni a barátaidnak, rájössz, hogy a receptben szereplő néhány mértékegységet át kell váltanod.
Mivel csak a metrikus rendszert ismered, ki kell találnod egy módot arra, hogy a gyakori amerikai sütési mértékegységeket milliliterre (mL) váltsd a saját könnyebbségedre.

Használd ezt az átváltási táblázatot a megoldásodhoz:

| Átváltandó mértékegység | térfogat | milliliterben (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| amerikai csésze          | 1      | 240                 |
| amerikai folyékony uncia  | 1      | 30                  |
| amerikai teáskanál     | 1      | 5                   |
| amerikai evőkanál   | 1      | 15                  |

Mivel tehetséges programozótanonc vagy, úgy döntesz, hogy a millilitert átmeneti mértékegységként használod, hogy könnyebben átválthass bármelyik felsorolt mértékegységről bármelyik másikra (még önmagára is).

## 1. A numerikus komponens kinyerése egy térfogatpárból

Valósítsd meg a `KitchenCalculator.get_volume` metódust.
Egy térfogatpár tuple esetén csak a numerikus komponenst kell visszaadnia.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. A térfogatpár átváltása milliliterre

Valósítsd meg a `KitchenCalculator.to_milliliter` metódust.
Egy térfogatpár tuple esetén a térfogatot milliliterre kell váltania az átváltási táblázat segítségével.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. A milliliter térfogatpár átváltása másik mértékegységre

Valósítsd meg a `KitchenCalculator.from_milliliter` metódust.
Egy térfogatpár tuple és a kívánt mértékegység esetén a térfogatot a kívánt mértékegységre kell váltania az átváltási táblázat segítségével.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Átváltás bármelyik mértékegységből bármelyikbe

Valósítsd meg a `KitchenCalculator.convert` metódust.
Egy térfogatpár tuple és a kívánt mértékegység esetén a megadott térfogatot a kívánt mértékegységre kell váltania.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
