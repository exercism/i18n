# Bevezetés

## Tömbök

A C#-ban azokat az adatszerkezeteket, amelyek nulla vagy több elemet tartalmazhatnak, _gyűjteményeknek_ nevezzük. A **tömb** egy olyan gyűjtemény, amelynek rögzített a mérete/hossza, és amelynek elemei mind ugyanazon típusúak kell legyenek. Az elemek index segítségével rendelhetők hozzá a tömbhöz, illetve kérhetők le belőle. A C# tömbök nulla alapúak, ami azt jelenti, hogy az első elem indexe mindig nulla:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

A tömbök definiálhatók egy rövidített jelöléssel is, amely lehetővé teszi, hogy egyszerre hozd létre a tömböt és állítsd be az értékét. Mivel a fordító most már meg tudja állapítani, hogy hány eleme lesz a tömbnek, a hossz elhagyható:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

A tömbökkel úgy végezhetsz műveleteket, hogy meghívod egy tömbinancia metódusait vagy tulajdonságait, illetve hogy az `Array` osztályban definiált statikus metódusokat használod.

## For ciklusok

A `for` ciklus segítségével ismételten végrehajthatsz kódot, amíg egy feltétel teljesül.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

A `for` ciklus négy részből áll:

1. A kezdőérték: egyszer hajtódik végre, mielőtt belépnénk a ciklusba. Általában a cikluson belül használt változók definiálására szolgál.
2. A feltétel: minden ciklusiteráció előtt végrehajtódik. A ciklus addig folytatódik, amíg ez `true`-ra értékelődik.
3. Az iterátor: minden ciklusiteráció után hajtódik végre. Általában a ciklusváltozó(k) módosítására (gyakran növelésére/csökkentésére) szolgál.
4. A törzs: az a kód, amely minden ciklusiterációban végrehajtódik.

## Foreach ciklusok

Az, hogy a tömb egyben _gyűjtemény_ is, azt jelenti, hogy az értékek index szerinti elérése mellett egy `foreach` ciklussal végig is iterálhatsz az _összes_ értékén:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
