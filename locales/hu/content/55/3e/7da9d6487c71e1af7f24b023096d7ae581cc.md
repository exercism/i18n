# Tippek

## Általános

- [Útmutató az enum típusokkal való munkához][docs.microsoft.com-enumeration-types].

## 1. Naplószint értelmezése

- Van egy [módszer egy string egy részének lekérésére][docs.microsoft.com_system_string_substring].
- Egy [`switch` utasítás][docs.microsoft.com_keyword_switch] segítségével elegánsan kezelheted a különböző naplószinteket.

## 2. Ismeretlen naplószint kezelése

- Van egy [speciális switch-eset][docs.microsoft.com_keyword_switch_default], amellyel elkaphatod a nem meghatározott eseteket.

## 3. Naplósor átalakítása rövid formátumra

- [Az enumtagokhoz konkrét értékeket rendelhetsz][docs.microsoft.com_creating-an-enumeration-type].
- Egy enum számmá alakítását [castolással][docs.microsoft.com_enumeration-types-casting] vagy egy [formátumstring][docs.microsoft.com_system.enum.tostring] használatával végezheted el.
