# Bevezetés

## Egymásba ágyazott típusok

A C# típusai definiálhatók egy osztály vagy struct scope-ján belül. A befoglaló típus egyfajta névteret biztosít. A típust a befoglaló típuson keresztül lehet elérni, pont szintaxissal.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Beállíthatod a hozzáférési szinteket a belső típusokhoz.

A külső típus privát tagjai a belső típus tagjainak a scope-jában vannak, de fordítva nem.
