# Tömbök

A PHP-ban a tömbök rendezett leképezések.
A leképezés olyan adatszerkezet, amely egy kulcshoz egy értéket rendel.
A tömbök sokoldalúak: használhatod őket lineáris tömbként (mint a `C`-ben vagy a `Java`-ban), listaként [vektorként], hash-táblaként, szótárként, kollekcióként, veremként vagy sorként.

A kulcs megadása nem kötelező, de ha megadod, akkor csak `int` vagy `string` lehet.
Ha nem adsz meg kulcsot, a PHP alapértelmezés szerint növekvő sorrendben egész kulcsokat rendel hozzá, `0`-tól kezdve.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Egy tömb minden típusú értéket tárolhat.
Az egyes értékek típusa akár eltérő is lehet.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## Tömbök használata

A tömböket létrehozhatod literálként (ahogy a fenti kódban is láttad), de létrehozhatod és módosíthatod őket függvényekkel is.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

Az értékek eléréséhez, hozzárendeléséhez és hozzáfűzéséhez használd az indexoperátort:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

A tömb elemein a foreach segítségével mehetsz végig:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
