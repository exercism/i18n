# Utasítások

Mary nagy rajongója a Star Trek: Az új nemzedék című tévésorozatnak.
Gyakran játszik asztali szerepjátékokat, amelyekben a barátaival együtt úgy tesznek, mintha a Starship Enterprise legénysége lennének.
Mary karaktere Picard kapitány, ezért neki kell vezetnie a kapitányi naplót.
Imádja a játék kreatív részét, de nem szeret helyben véletlenszerű adatokat generálni.

Segíts Marynek véletlenszerű generátorokat készíteni azokhoz az adatokhoz, amelyek gyakran előfordulnak a kapitányi naplóban.

## 1. Generálj egy véletlenszerű csillaghajó-lajstromszámot

Az Enterprise (lajstromszáma NCC-1701) nem az egyetlen csillaghajó az űrben!
Amikor egy másik csillaghajóval találkozik, Marynek fel kell jegyeznie annak a csillaghajónak a lajstromszámát.

A lajstromszámok kezdete az „NCC-” előtag, ezt követi egy 1000 és 9999 közötti szám (mindkét végpontot beleértve).

Valósítsd meg a `randomShipRegistryNumber()` függvényt, amely véletlenszerű csillaghajó-lajstromszámot ad vissza.

```javascript
randomShipRegistryNumber();
// => "NCC-1947"
```

## 2. Generálj egy véletlenszerű csillagidőt

Mi értelme a naplónak, ha nincsenek benne dátumok?

A csillagidő egy lebegőpontos szám.
A Starship Enterprise kalandjai a Star Trek: Az új nemzedék első évadában a 41000.0 és a 42000.0 közötti csillagidőben játszódnak.
A „4” a 24. századra utal, a „1” pedig az első évadra.

Valósítsd meg a `randomStardate` függvényt, amely egy 41000.0 (beleértve) és 42000.0 (kizárva) közötti lebegőpontos számot ad vissza.

```javascript
randomStardate();
// => 41458.15721310934
```

## 3. Generálj egy véletlenszerű bolygót

A Starship Enterprise utazásai során sok bolygóval találkozik.
A Star Trek világegyetemének bolygóit a tulajdonságaik alapján kategóriákba sorolják.
Például a Föld egy M osztályú bolygó.
Az összes lehetséges bolygóosztály: D, H, J, K, L, M, N, R, T és Y.

Valósítsd meg a `randomPlanetClass()` függvényt.
A függvény véletlenszerűen adja vissza az egyik bolygóosztályt.

```javascript
randomPlanetClass();
// => "K"
```
