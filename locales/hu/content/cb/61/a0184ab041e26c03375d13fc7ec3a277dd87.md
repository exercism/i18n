# Bevezetés

A Python egy [dinamikus és erősen típusos][dynamic typing in python] programozási nyelv.
Egyszerre alkalmaz [kacsa típusozást][duck typing] és [fokozatos típusozást][gradual typing], [típusannotációk][type hints] segítségével.
A Python nagy hangsúlyt fektet a kód olvashatóságára, és (_a Haskellhez hasonlóan_) [szemantikus behúzást][significant indentation] használ a függvények, a metódusok és az osztályok definíciójának jelölésére.

A Pythont Guido van Rossum alkotta meg, és először 1991-ben jelent meg.

Az imperatív, a deklaratív (például a funkcionális) és az objektumorientált programozási _stílust_ is támogatja, de belül **[a Pythonban minden objektum][everythings an object]**.

Hogy mindez mit is jelent, abba jobban elmélyedünk, ahogy tovább haladunk a Python-kurzus fogalmain.

Ez az első fogalom (`basics`) a Python nyelvének négy fő jellemzőjét mutatja be:
1.  Névhozzárendelés (_változók és konstansok_),
2.  Függvények (_a `def` és a `return` kulcsszó_),
3.  Megjegyzések, és
4.  Docstringek.

<br>

## Névhozzárendelés (változók és konstansok)

A programozók a hozzárendelő `=` operátorral bármilyen típusú objektumhoz hozzáköthetnek [_neveket_][facts-and-myths-about-python-names] (más néven _változókat_): `<name> = <value>`.
Egy név élettartama során újra hozzárendelhető (vagy újra köthető) más értékekhez (más objektumtípusokhoz):


```python
>>> my_first_variable = 1  # <--my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  # <--my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." # <--You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' # <--Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### Konstansok

A konstansok olyan nevek, amelyeket egy programban csak egyszer rendelünk hozzá, bár a Python nem akadályozza meg az újrahozzárendelést.
A `SCREAMING_SNAKE_CASE` használata jelzi a kódot olvasó bárkinek, hogy a nevet **nem** szabad újra hozzárendelni, és az értékét sem módosítani.
A konstansokat [modul][module] (fájl) szinten érdemes definiálni, és általában egy program összes függvénye és osztálya számára láthatók.



## Függvények

A `def` kulcsszó kezdi a [függvénydefiníciót][function definition].
Minden függvénynek lehet nulla vagy több formális [paramétere][parameters] a `()` zárójelben, amit egy `:` kettőspont követ.
A függvény _törzsének_ utasításai a `def`-et követő sorban kezdődnek, és _blokkon belül behúzva_ kell lenniük.


```python
# The body of this function is indented by 2 spaces & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     # <--This was only indented by 3 spaces.
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


A függvények a [`return`][return] kulcsszóval _explicit módon_ adnak vissza egy értéket vagy objektumot:


```python
# Function definition on first line, explicit return used on final line.
def add_two_numbers(number_one, number_two):
  return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing 
# the variable will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


Azok a függvények, amelyeknél a `return` után nem áll _explicit_ kifejezés, _implicit módon_ a [`None`][none] objektumot adják vissza.
A `None` részleteire egy későbbi fogalomban térünk ki.
Ennek a feladatnak és magyarázatnak a szempontjából a `None` egy helyőrző, amely a semmit, azaz a nullt jelöli:


```python
# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

Azok a függvények is, amelyek elhagyják a `return` utasítást, _implicit módon_ a [`None`][none] objektumot adják vissza.
Ez azt jelenti, hogy ha nem használod a `return`-t egy függvényben, a Python helyetted a `None` objektumot adja vissza.

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


## Megjegyzések

A [megjegyzések][comments] a Pythonban egy `#` karakterrel kezdődnek, amely nem része egy stringnek, és a sor végéig tartanak.
Sok más programozási nyelvvel ellentétben a Python **nem támogatja** a többsoros megjegyzésjeleket.
Egy megjegyzésblokk minden sorának a `#` karakterrel kell kezdődnie.


## Docstringek

A függvénytörzs első utasítása opcionálisan lehet egy [_docstring_][docstring], amely tömören összefoglalja a függvény vagy objektum célját.
A docstringeket olyan automatikus dokumentációs eszközök olvassák, mint a [Sphinx][sphinx], és úgy érhetők el, hogy a függvény, a metódus vagy az osztály nevén meghívjuk a különleges `.__doc__` attribútumot.
A docstringek általános konvencióit a [PEP257][pep257] írja le, de a pontos formátum projektenként és csapatonként változhat.
A docstringeket hármas idézőjelekkel (""") deklaráljuk, ugyanolyan behúzással, mint a kódblokkot:


```python

    """Form a complex number.
```
