# Boolean-literálok visszaadásának elkerülése

Ahelyett, hogy egy feltétel után Boolean-literálokat adnál vissza, közvetlenül magát a feltételt is visszaadhatod.

Példa:

```java
// instead of
if (someExpression) {
  return true;
} else {
  return false;
}

// ... return the expression directly
return someExpression;
```
