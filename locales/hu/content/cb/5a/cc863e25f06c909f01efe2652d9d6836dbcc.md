# Utasítások

Sakkrajongóként szeretnéd megírni a játék saját változatát.
Persze, már rengeteg sakkimplementáció elérhető online, de a tiéd egyedi lesz!

Először egy sakktáblát valósítasz meg.

A sakkjátszma egy nyolc mező széles és nyolc mező hosszú táblán zajlik.
A mezőket egy betű és egy szám azonosítja.

## 1. A sorok és az oszlopok tartományának meghatározása

A játéknak tárolnia kell a tábla sorait.
A sorok a tábla sorai, és 1-től 8-ig vannak számozva.

A játéknak a tábla oszlopait is tárolnia kell.
Az oszlopok a tábla oszlopai, és az A-tól H-ig terjedő betűk azonosítják őket.

Definiáld a `ranks` és a `files` konstansot, amelyek rendre a sorok és az oszlopok tartományát tárolják.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. Ellenőrizd, hogy a mező érvényes-e

A játéknak ellenőriznie kell, hogy egy mező érvényes-e.
Egy mező akkor érvényes, ha a sor és az oszlop a sorok és az oszlopok tartományán belül van.

Definiáld az `isValidSquare(rank:file:)` metódust, amely a `rank` és a `file` argumentumot kapja: a `rank` a sor `Int` típusú értékét, a `file` pedig az oszlop `String` típusú értékét tartalmazza.
A metódus akkor `true`-t adjon vissza, ha a sor és az oszlop a sorok és az oszlopok tartományán belül van, egyébként pedig `false`-t.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. A sor lekérése

A játék a tábla összes mezőjét egy egydimenziós tömbben tárolja.
A mezők a sor és az oszlop összefűzéséből létrejövő stringek, például "1A", "8B", "4G" és így tovább.
Egy mező sorának lekéréséhez a játéknak ki kell számítania a sor első mezőjének indexét.

Definiáld a `getRow(rank:)` metódust, amely a `rank` argumentumot kapja, ami a sor `Int` típusú értékét tartalmazza.
A metódus egy stringekből álló tömböt adjon vissza, amely a sor mezőit reprezentálja.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
