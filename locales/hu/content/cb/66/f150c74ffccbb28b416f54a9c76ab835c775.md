# Utasítások

Ebben a feladatban olyan konstansokat hozol létre, amelyeket egy bank működése során használunk.

Öt részfeladat vár rád:

## 1. A kölcsön fix kamatlábának ábrázolása

Hozd létre a `FixedInterestRate` típus nélküli numerikus konstansot, amely az 5% (5/100) értéket tárolja, majd implementáld a `GetFixedInterestRate` függvényt, amely visszaadja azt:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Az év napjainak számának ábrázolása

Hozd létre a `DaysPerYear` konstanst `int` típussal, hogy a 365 értéket tárolja, majd implementáld a `GetDaysPerYear` függvényt, amely visszaadja azt:

```go
GetDaysPerYear()
// => 365
```

## 3. Az év hónapjainak ábrázolása

Egy blokkban használd a Go felsorolóját tizenkét típus nélküli numerikus konstans létrehozásához, amelyek az év hónapjaihoz az 1-től 12-ig terjedő értékeket tárolják. Nevezd el őket `Jan`, `Feb`, `Mar` és így tovább néven, majd implementáld a `GetMonth` függvényt, amely visszaadja egy adott hónap értékét:

```go
GetMonth(Jan)
// => 1
```

## 4. Egy bankszámlaszám ábrázolása

Hozd létre az `AccountNo` típus nélküli string konstanst, amely az XF348IJ értéket tárolja, majd implementáld a `GetAccountNumber` függvényt, amely visszaadja azt:

```go
GetAccountNumber()
// => "XF348IJ"
```
