# Utasítások

Ebben a feladatban egy távirányítású autóval fogsz játszani, amire végre összegyűjtötted a pénzt.

Az autók feltöltött (100%-os) akkumulátorral indulnak. Valahányszor elvezetsz egy autót a távirányítóval, 20 métert tesz meg, és az akkumulátor egy százalékát veszíti.

A távirányítású autón van egy menő LED-kijelző, amely két adatot mutat:

- A megtett teljes távolságot, így megjelenítve: `"Driven <METERS> meters"`.
- Az akkumulátor hátralévő töltöttségét, így megjelenítve: `"Battery at <PERCENTAGE>%"`.

Ha az akkumulátor 0%-on áll, nem tudod tovább vezetni az autót, és a kijelzőn a `"Battery empty"` felirat jelenik meg.

Hat részfeladat vár rád, amelyek mindegyike a távirányítású autó példányaival dolgozik.

## 1. Vásárolj egy vadonatúj távirányítású autót

Valósítsd meg a (_statikus_) `JedliksToyCar.buy()` metódust, amely egy vadonatúj távirányítású autó példányt ad vissza:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Jelenítsd meg a megtett távolságot

Valósítsd meg a `JedliksToyCar.distanceDisplay()` metódust, amely a LED-kijelzőn látható távolságot adja vissza:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Jelenítsd meg az akkumulátor töltöttségét

Valósítsd meg a `JedliksToyCar.batteryDisplay()` metódust, amely a LED-kijelzőn látható akkumulátor-töltöttséget adja vissza:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Frissítsd a megtett méterek számát vezetéskor

Valósítsd meg a `JedliksToyCar.drive()` metódust, amely frissíti a megtett méterek számát:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Frissítsd az akkumulátor töltöttségét vezetéskor

Frissítsd a `JedliksToyCar.drive()` metódust úgy, hogy az akkumulátor töltöttségét is frissítse:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Akadályozd meg a vezetést, ha lemerült az akkumulátor

Frissítsd a `JedliksToyCar.drive()` metódust úgy, hogy lemerült (0%-os) akkumulátor esetén se a megtett távolság ne növekedjen, se az akkumulátor töltöttsége ne csökkenjen:

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
