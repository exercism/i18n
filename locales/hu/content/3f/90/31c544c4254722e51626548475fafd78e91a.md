# Bevezetés

## Osztályok

A Java elsődleges objektumorientált építőeleme az _osztály_, amely adatok (_mezők_) és viselkedés (_metódusok_) kombinációja.
Egy osztály mezőit és metódusait együtt _tagoknak_ nevezzük.

A tagokhoz való hozzáférést hozzáférés-módosítókkal szabályozhatod; a két leggyakoribb:

- `public`: a tagot bármely kód elérheti (nincs megkötés).
- `private`: a tagot csak az ugyanabban az osztályban lévő kód érheti el.

Az osztályt tekintheted egy sablonnak, amellyel az adott osztály példányait létrehozod.
Egy osztály példányának (más néven _objektumnak_) a létrehozásához a `new` kulcsszót használjuk:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

A mezőknek típusuk és nevük van (camelCase írásmóddal definiálva), és az osztályon belül bárhol definiálhatók (konvenció szerint PascalCase írásmóddal):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Egy mezőhöz opcionálisan rendelhetsz kezdőértéket.
Ha egy mező _nem_ kap kezdőértéket, akkor a típusának alapértékét veszi fel.
Egy példány mezőértékeit pont jelöléssel érheted el és frissítheted.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

A privát mezőket általában egy metódus meghívásának mellékhatásaként frissítjük.
Az ilyen metódusok általában nem adnak vissza értéket; ebben az esetben a visszatérési típus `void` kell hogy legyen:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
