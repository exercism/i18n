# Bevezetés

## Paraméterek

Ez a feladat a metódusparaméterek néhány részletével és azok C#-beli használatával foglalkozik.

A paraméterek információt közvetítenek a hívó metódustól a hívott metódushoz.

- A paraméterek viselkedése módosítható olyan módosítók használatával, mint a `ref` és az `out`.

- Az `out` módosítóval ellátott paraméter egy értéket közvetít vissza a hívott metódustól a hívóhoz. A paraméter inicializálás nélkül átadható a hívott metódusnak, és a hívott metódusban mindenképpen úgy kezelik, mintha belépéskor nem inicializálták volna. A paramétermódosítók viselkedését és szabályait a legkönnyebben példákon keresztül (lásd alább) és a fordító üzenetein keresztül értheted meg.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Az `out` paramétereknek a hívott metóduson belül értéket kell kapniuk.

- A `ref` módosítóval ellátott paraméter értéket ad át a hívott metódusnak. Amikor a metódus visszatér, a hívó a paraméterben megtalálja a hívott metódus által végrehajtott összes módosítást.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- A `ref` paramétereknek változóknak kell lenniük, mert a hívott metódus közvetlenül azon a paraméteren fog működni, ahogyan a hívó látja.
- Az `out` és a `ref` módosítóra egyaránt szükség van a hívott metódus szignatúrájában és a hívás helyén is.
