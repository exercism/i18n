# Bevezetés

## Névtelen függvények

Az Elixirben a függvények első osztályú állampolgárok. Ez a következőket jelenti:

- A nevesített és a névtelen függvényeket változókhoz lehet rendelni.
- A nevesített és a névtelen függvényeket adatként lehet továbbadni, akár argumentumként, akár visszatérési értékként.
- A névtelen függvények dinamikusan létrehozhatók.

A névtelen függvényeknek a nevesített függvényekkel ellentétben nincs statikus hivatkozásuk, csak akkor érhetők el, ha egy változóhoz rendeljük őket, vagy ha azonnal meghívjuk őket.

A névtelen függvényeket például arra használhatjuk, hogy:

- Adatokat rejtsünk el lexikális scope-pal (más néven closure).
- Dinamikusan hozzunk létre függvényeket futásidőben.

A névtelen függvények a `fn` fenntartott szóval kezdődnek, az argumentumokat a `->` token választja el a függvény törzsétől, és egy `end` zárja le őket. A nevesített függvényekhez hasonlóan a függvény utolsó kifejezése _implicit módon visszaadódik_ a hívó függvénynek.

Egy függvényhivatkozás meghívásához egy `.`-ot kell tenned a hivatkozást tartalmazó változó és az argumentumok listája közé:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Akár a rövidített capture-jelölést is használhatod, hogy ez még tömörebb legyen:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## Bitmanipuláció

Az Elixir sok függvényt kínál a bitekkel való munkához, ezek a _Bitwise modulban_ találhatók.

- `band/2`: bitenkénti AND
- `bsl/2`: bitenkénti SHIFT LEFT
- `bsr/2`: bitenkénti SHIFT RIGHT
- `bxor/2`: bitenkénti XOR
- `bor/2`: bitenkénti OR
- `bnot/1`: bitenkénti NOT

Íme egy példa egy bitenkénti függvény használatára:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Minden bitenkénti függvény csak egész számokkal működik.

Ha 1.9-es vagy annál régebbi Elixir-verziót használsz, a modul definíciójának elején meg kell hívnod a `require Bitwise`-ot, hogy használhasd a _Bitwise_ modult.
