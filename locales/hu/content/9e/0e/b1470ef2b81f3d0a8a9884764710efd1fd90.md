# Részletesen

[A tartományok][range] egy vagy több egymást követő egész szám sorozatát reprezentálják. Jellemzőik:

- A [`..` operátorral][range-operator] hozhatók létre, és lehetnek növekvő vagy csökkenő sorrendűek is.
- Az alapértelmezett lépésközük `1`, de a [`..//` operátorral][range-operator-with-step] módosítható (az Elixir 1.12 óta).
- Mind az első, mind az utolsó értéket tartalmazzák.
- Megvalósítják az [_Enumerable protokollt_][enumerable].
- Belül struktúraként vannak reprezentálva, de a `..` segítségével mintával is illeszthetők.
- Használhatók bináris, oktális, hexadecimális és kódpont jelöléssel írt egész számokkal.
- Listává alakíthatók olyan függvényekkel, mint az [`Enum.to_list/1`][enum-to-list] vagy az [`Enum.map/2`][enum-map].

```elixir
Enum.to_list(9..1)
# => [9, 8, 7, 6, 5, 4, 3, 2, 1]

Enum.map(?A..?F, &<<&1>>)
["A", "B", "C", "D", "E", "F"]
```
