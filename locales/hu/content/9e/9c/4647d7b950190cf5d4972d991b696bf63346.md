# Utasítások

Jen egy nagy gyár válogatótermében dolgozik.
A válogatóteremnek mindent fel kell dolgoznia, ami bekerül oda, méghozzá úgy, hogy címkével látja el.
Jen azokért a dolgokért felel, amelyeket előre számként kategorizáltak, és egy programra van szüksége, amely segít neki a válogatásban.

A legtöbb primitív érték egyszerű címkét kap.
A számoknál olyan stringeket szeretne, amelyek azt mondják, hogy `"This is the number 2.0"` (ha a szám 2 volt).
Jen ugyanilyen kimenetet szeretne az egész számoknál és a tizedes törteknél is.

Van néhány `Box` interfész, amelyeket ki kell bontani, hogy hozzájussunk a tartalmukhoz.
Egy `NumberBox` esetén olyan stringeket szeretne, amelyek azt mondják, hogy `"This is a box containing the number 3.0"` (ha a `Number()` metódus 3-at ad vissza).
Egy `FancyNumberBox` esetén olyan stringeket szeretne, amelyek azt mondják, hogy `"This is a fancy box containing the number 4.0"`, de csak akkor, ha a típus `FancyNumber`.

Bármi váratlan esetén `"Return to sender"` legyen a válasz, hogy Jen visszaküldhesse őket oda, ahonnan jöttek.

## 1. Egyszerű számok leírása

Jen szeretné, ha a számok olyan stringeket adnának vissza, mint a `"This is the number 2.0"` (egy tizedesjegyet is beleértve):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Egy számdoboz leírása

Jen szeretné, ha a számdobozok olyan stringeket adnának vissza, mint a `"This is a box containing the number 2.0"` (itt is egy tizedesjegyet is beleértve):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Valósíts meg egy metódust, amely kinyeri a számot egy díszes számdobozból

Jennek szüksége van egy segédfüggvényre, amely kinyeri a számot egy `FancyNumberBox`-ból.
Ha a `FancyNumberBox` egy `FancyNumber`, akkor nyerd ki az értékét, és alakítsd át `string`-ből `int`-té.
Bármely más típusú `FancyNumberBox` esetén 0-t kell visszaadni.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Egy díszes számdoboz leírása

Ha a `FancyNumberBox` egy `FancyNumber`, akkor Jen olyan stringeket szeretne, amelyek azt mondják, hogy `"This is a fancy box containing the number 4.0"`.
Bármely más típusú `FancyNumberBox` esetén `"This is a fancy box containing the number 0.0"` legyen a válasz.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

Megjegyzés: használnunk kell az `ExtractFancyNumber` függvényt!

## 5. Valósítsd meg a `DescribeAnything` függvényt, amely mindegyiket használja

Ez az a fő függvény, amelyre Jennek szüksége van, és amely bármilyen bemenetet elfogad.
A `DescribeAnything` a kapott érték típusa alapján delegálja a munkát a többi függvénynek.
Pontosabban:

- az `int` és a `float64` is a `DescribeNumber` függvényre delegáljon
- a `NumberBox` a `DescribeNumberBox` függvényre delegáljon
- a `FancyNumberBox` a `DescribeFancyNumberBox` függvényre delegáljon
- bármi más esetén `"Return to sender"` legyen az eredmény

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
