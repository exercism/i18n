# Bevezetés

Ahogy a [`Nothingness`][concept-nothingness] fogalomban láttuk, az R-nek többféle módja van az olyan adatok ábrázolására, amelyek hiányoznak (`NULL`), ismeretlenek (`NA`), vagy matematikailag érvénytelenek (`NaN`, `Inf`).
Általában az R ezekkel próbálja helyben jelezni a problémákat, és kivétel dobása nélkül folytatja.

## `stop()`

Néhány probléma túl alapvető ahhoz, hogy a program folytatódhasson.
Ebben az esetben használd a `stop(msg)` függvényt, hogy azonnal leállítsd a programot egy `Error` kiváltásával, és kiírd a `msg` üzenetet.

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

Más nyelvek `assert` utasításához hasonlóan ez egy kényelmes burkoló a `stop()` függvényhez.
A paraméterei tetszőleges számú, vesszővel elválasztott Boolean feltétel, és a program csak akkor folytatódik, ha ezek mindegyike `TRUE`.

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `try()`

Az R-nek többféle módja van a hibák kezelésére.
Ezek a Common Lisp-en alapulnak, és jelentősen eltérnek számos népszerű nyelvtől.

A legegyszerűbb, ha a potenciálisan problémás kódot `try()` függvénybe csomagolod.

```R
g <- function(val) {
  log10(val)
}

g(3)
#> [1] 0.4771213

g("3")
#> Error in log10(val) : non-numeric argument to mathematical function

# with try() and a default value
h <- function(val) {
  result <- NA
  try(result <- log10(val))
  result
}

h(3) # works as before
#> [1] 0.4771213

h("3") # returns a default value plus the error message
#> Error in log10(val) : non-numeric argument to mathematical function
#> [1] NA
```

## `warning()` and `message()`

Ezek nem végzetes feltételekre adott válaszok, például:

- Figyelmeztetés egy problémára, amelyből a program legalább részben helyre tud állni.
- A felhasználó tájékoztatása egy hosszan futó program előrehaladásáról.

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

A `suppressWarnings()` függvény alkalmanként hasznos lehet az Exercism-ön belül, hogy a nem kívánt kimenet ne zavarja össze a tesztfuttatót.
