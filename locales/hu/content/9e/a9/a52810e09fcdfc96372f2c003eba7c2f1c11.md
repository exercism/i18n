# Tippek

## 1. Add vissza az elemek nevének listáját

- Az [`iterator.map` függvény][map] segítségével átalakíthatod egy iterátor elemeit.

## 2. Add vissza az olcsó elemeket

- Az [`iterator.filter` függvény][filter] segítségével eltávolíthatsz elemeket egy iterátorból.

## 3. Add vissza azokat az elemeket, amelyek nincsenek raktáron

- Az [`iterator.filter` függvény][filter] segítségével eltávolíthatsz elemeket egy iterátorból.

## 4. Add vissza a teljes készletet

- Az [`iterator.fold` függvény][fold] segítségével egyetlen értékre redukálhatod az iterátort.

[map]: https://hexdocs.pm/gleam_stdlib/gleam/iterator.html#map
[filter]: https://hexdocs.pm/gleam_stdlib/gleam/iterator.html#filter
[fold]: https://hexdocs.pm/gleam_stdlib/gleam/iterator.html#fold
