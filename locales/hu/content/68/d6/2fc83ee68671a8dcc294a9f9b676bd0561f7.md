# Trait-ek

A trait metódusok egy halmazát határozza meg, amelyeket egy típus implementálhat.
A trait-ek akkor hasznosak, amikor olyan metódusokat definiálunk, amelyeket több típus között szeretnénk megosztani.
Amikor a trait-eket generikus típusokkal használjuk, a definiált metódusok meghívhatók az adott típuson, de más adattípusokon is.
Absztrakt módon, _trait-korlátok_ használatával megadhatjuk, hogy a generikus típusnak egy bizonyos viselkedéssel kell rendelkeznie.

> **Megjegyzés:** A trait-ek hasonló funkciót töltenek be, mint amit más programozási nyelvekben interfészeknek neveznek, néhány különbséggel.

## A trait definíciója

A trait definiálása segít meghatározni azt a függvényszignatúrát, amely a viselkedések azon halmazát alkotja, amelyet egy típus egy eredmény elérése érdekében implementálhat.
Ezek a metódusok alkotják egy típus viselkedését.
Ha ugyanazokat a metódusokat különböző típusokon tudjuk meghívni, az azt jelenti, hogy az érintett típusok viselkedése azonos.

```rust
#[derive(Drop)]
pub struct NewsArticle {
    pub headline: ByteArray,
    pub location: ByteArray,
    pub author: ByteArray,
    pub content: ByteArray,
}

// A trait for NewsArticle struct type
pub trait Summary {
    fn summarize(self: @NewsArticle) -> ByteArray;
}
```

A fenti `Summary` trait definíciója alapján a `summarize` metódus olyan viselkedés, amelyet csak a `NewsArticle` struct típus hívhat meg.
Ha más típusú példányokon hívjuk meg, az fordítási hibát dob.
Ha a trait-et a `pub` kulcsszóval deklaráljuk, a trait láthatóvá válik ebben a crate-ben más crate-ek számára is, amelyek szintén szeretnék használni.
Figyeld meg azt is, hogy a trait-ekben a metódusszignatúrák deklarálása után pontosvesszőt használunk.

Egy trait definiálható generikus argumentummal is, amely lehetővé teszi, hogy egy függvény bármilyen adattípusú argumentumot fogadjon el.
Ez rugalmasságot ad a függvényszignatúráknak, hogy különféle adattípusokat kezelhessenek.
Az alábbi `Summary` trait esetében ezt úgy alakítottuk át, hogy bármilyen adattípusra működjön, így amikor a `summarize` metódust meghívják rajtuk, egy ByteArray-t ad vissza.

```rust
// A trait for a generic type
pub trait Summary<T> {
    fn summarize(self: @T) -> ByteArray;
}
```

Egy trait törzsében több metódus is lehet; minden deklarált metódusszignatúra egysoros, és pontosvesszővel végződik.

## Trait implementálása egy típuson

Miután definiáltuk a trait-et alkotó függvényszignatúrákat, a fordító gondoskodik arról, hogy az implementáció is megfelelően definiálva legyen azokhoz a típusokhoz, amelyek átveszik a trait-et.
Az alábbiakban írtunk egy `aggregator` nevű média könyvtár crate-et, amely összefoglal néhány adatot `NewsArticle` és `Tweet` példányokból.
A `NewsArticle` struct esetében a headline, a szerző és a helyszín mezőket használnánk, hogy visszaadjuk a `Summary` trait `summarize` metódusának értékét, míg a `Tweet` struct esetében a felhasználónevet és a tartalmat használnánk, feltételezve, hogy a tweet tartalma 280 karakterre korlátozódik.

```rust
mod aggregator {
    pub trait Summary<T> {
        fn summarize(self: @T) -> ByteArray;
    }

    #[derive(Drop)]
    pub struct NewsArticle {
        pub headline: ByteArray,
        pub location: ByteArray,
        pub author: ByteArray,
        pub content: ByteArray,
    }

    impl NewsArticleSummary of Summary<NewsArticle> {
        fn summarize(self: @NewsArticle) -> ByteArray {
            format!("{} by {} ({})", self.headline, self.author, self.location)
        }
    }

    #[derive(Drop)]
    pub struct Tweet {
        pub username: ByteArray,
        pub content: ByteArray,
        pub reply: bool,
        pub retweet: bool,
    }

    impl TweetSummary of Summary<Tweet> {
        fn summarize(self: @Tweet) -> ByteArray {
            format!("{}: {}", self.username, self.content)
        }
    }
}

use aggregator::{Summary, NewsArticle, Tweet};

fn main() {
    let news = NewsArticle {
        headline: "Cairo has become the most popular language for developers",
        location: "Worldwide",
        author: "Cairo Digger",
        content: "Cairo is a new programming language for zero-knowledge proofs",
    };

    let tweet = Tweet {
        username: "EliBenSasson",
        content: "Crypto is full of short-term maximizing projects. \n @Starknet and @StarkWareLtd are about long-term vision maximization.",
        reply: false,
        retweet: false
    };

    println!("New article available! {}", news.summarize());
    println!("New tweet! {}", tweet.summarize());
}
```

## Alapértelmezett implementációk

Néha egy trait definiálható alapértelmezett implementációval a trait-et alkotó metódusok egy részére vagy mindegyikére.
Ezzel elkerülhető, hogy minden típusnál minden metódust implementálni kelljen, és javítja a kód olvashatóságát.
Ha egy adott típusnak különleges implementációra van szüksége egy trait metódusához, felülírhatja az alapértelmezett implementációt.

```rust
mod aggregator {
    pub trait Summary<T> {
        fn summarize(self: @T) -> ByteArray {
            "(Read more...)"
        }
    }

    #[derive(Drop)]
    pub struct NewsArticle {
        pub headline: ByteArray,
        pub location: ByteArray,
        pub author: ByteArray,
        pub content: ByteArray,
    }

    impl NewsArticleSummary of Summary<NewsArticle> {}

    #[derive(Drop)]
    pub struct Tweet {
        pub username: ByteArray,
        pub content: ByteArray,
        pub reply: bool,
        pub retweet: bool,
    }

    impl TweetSummary of Summary<Tweet> {
        fn summarize(self: @Tweet) -> ByteArray {
            format!("{}: {}", self.username, self.content)
        }
    }
}

use aggregator::{Summary, NewsArticle, Tweet};

fn main() {
    let news = NewsArticle {
        headline: "Cairo has become the most popular language for developers",
        location: "Worldwide",
        author: "Cairo Digger",
        content: "Cairo is a new programming language for zero-knowledge proofs",
    };

    println!("New article available! {}", news.summarize()); // prints "New article available! (Read more...)"


    let tweet = Tweet {
        username: "Alice",
        content: "Cairo is fun and engaging.",
        reply: true,
        retweet: true,
    };
    println!("New tweet from {}", tweet.summarize()); // prints "New tweet from Alice: Cairo is fun and engaging."
}
```

## Külső trait-ek használata és kezelése

A trait-ek és implementációk külső modulban is definiálhatók, és más modulokban is használhatók, feltéve, hogy megfelelően importáljuk őket.
Tegyük fel, hogy van egy `ShapeGeometry` trait-ünk a `boundary` metódussal, amelyet mind a `Circle`, mind a `Rectangle` struct számára implementálni kell.
Az alábbi példa bemutatja, hogyan importálhatók, kezelhetők és használhatók a trait-ek és implementációk a modulok között.

```rust
// Here T is an alias type which will be provided during implementation
pub trait ShapeGeometry<T> {
    fn boundary(self: T) -> u64;
    fn area(self: T) -> u64;
}

mod rectangle {
    // Importing ShapeGeometry is required to implement this trait for Rectangle
    use super::ShapeGeometry;

    #[derive(Copy, Drop)]
    pub struct Rectangle {
        pub height: u64,
        pub width: u64,
    }

    // Implementation RectangleGeometry passes in <Rectangle>
    // to implement the trait for that type
    impl RectangleGeometry of ShapeGeometry<Rectangle> {
        fn boundary(self: Rectangle) -> u64 {
            2 * (self.height + self.width)
        }
        fn area(self: Rectangle) -> u64 {
            self.height * self.width
        }
    }
}

mod circle {
    // Importing ShapeGeometry is required to implement this trait for Circle
    use super::ShapeGeometry;

    #[derive(Copy, Drop)]
    pub struct Circle {
        pub radius: u64
    }

    // Implementation CircleGeometry passes in <Circle>
    // to implement the imported trait for that type
    impl CircleGeometry of ShapeGeometry<Circle> {
        fn boundary(self: Circle) -> u64 {
            (2 * 314 * self.radius) / 100
        }
        fn area(self: Circle) -> u64 {
            (314 * self.radius * self.radius) / 100
        }
    }
}

use rectangle::Rectangle;
use circle::Circle;

fn main() {
    let rect = Rectangle { height: 5, width: 7 };
    println!("Rectangle area: {}", ShapeGeometry::area(rect)); //35
    println!("Rectangle boundary: {}", ShapeGeometry::boundary(rect)); //24

    let circ = Circle { radius: 5 };
    println!("Circle area: {}", ShapeGeometry::area(circ)); //78
    println!("Circle boundary: {}", ShapeGeometry::boundary(circ)); //31
}
```

A `CircleGeometry` és `RectangleGeometry` implementációinak láthatóságának nem kell nyilvánosnak lennie, mivel a `ShapeGeometry` trait nyilvános, és a fordítónak könnyen meg kell találnia.

## impl aliaszok

Az implementációk importáláskor aliaszolhatók az `impl` kulcsszóval.
Ez akkor segít, amikor egy generikus implementációt konkrét típusokhoz példányosítunk.
Definiáljunk egy egyszerű implementációt a `Two` trait-hez minden olyan típusra, amely implementálja a `One` trait-et, egyszerűen kétszer hozzáadva a `One` értékét, és visszaadva az összeget.
Ezután felfedhetjük a `Two` implementációt, amely csak `u8` és `u128` típusokra működik.

```rust
trait Two<T> {
    fn two() -> T;
}

mod one_based {
    pub impl TwoImpl<
        T, +Copy<T>, +Drop<T>, +Add<T>, impl One: core::num::traits::One<T>
    > of super::Two<T> {
        fn two() -> T {
            One::one() + One::one()
        }
    }
}

pub impl U8Two = one_based::TwoImpl<u8>;
pub impl U128Two = one_based::TwoImpl<u128>;
```

A generikus implementáció privát modulban is megírható, és az impl aliasz használatával példányosíthatjuk e két konkrét típus generikus implementációját.
A privát és nem felfedett generikus implementáció előnye, hogy megakadályozza a kódduplikációt a fájlok között.
Ez ráadásul egyszerűen és tisztán tartja a nyilvános API-t.
