# Bevezetés

A Cairo enumjai lehetővé teszik, hogy olyan típust definiálj, amely több elnevezett változat egyike lehet.

## Alapok

Az enumok, a felsorolás rövidítése, valamely adat összes lehetséges értékét egy előre meghatározott halmazra korlátozzák.
Az `enum` lehetséges értékeit változatoknak nevezzük:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

Az enumértékeket a változat megadásával hozod létre:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## Mintaillesztés

A match segítségével különböző enumváltozatokat kezelhetsz:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

A match minden ága az enum egy-egy változatát kezeli.

## Adatot tartalmazó enumok

Az enumváltozatok további adatokat tárolhatnak:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

Mintaillesztéssel kinyerheted az adatokat:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
