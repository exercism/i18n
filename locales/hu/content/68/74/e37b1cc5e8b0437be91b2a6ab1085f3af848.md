# Leírás

A [concept:csharp/resource-cleanup]() az `IDispose` interfészt használja, hogy jelezze egy osztály hívóinak, hogy vannak olyan erőforrások vagy programállapotok, amelyeket időben fel kell szabadítani vagy vissza kell állítani, amikor az adott objektumra már nincs szükség. Ebben a feladatban bevezettünk némi szintaktikai cukrot a `using` kulcsszóval, ami kevésbé terjengőssé teszi a kódot, és csökkenti annak esélyét, hogy fontos hívások kimaradjanak.

A `using` bizonyos esetekben a [`try/finally`][try-finally] helyettesítőjének tekinthető.

```csharp
File file = null;
try
{
    file = new File("myStuff.txt");
    file.Write("more stuff");
}
finally
{
    file.Dispose();
}
```

Ezt a szintaxist a következő, tömörebb és hibabiztos forma váltja fel:

```csharp
using (var file = new File("myStuff.txt")
{
    file.Write("more stuff");
}
```

Figyeld meg, hogy több erőforrás is kényelmesen összekapcsolható az egysoros blokkokra vonatkozó szokásos szabályok szerint:

```csharp
using (var file = new File("mystuff.txt")
using (var fileWriter = new StreamWriter(file)
{
     ...
}
```

A C# 8-ban bevezették a következő változatot, amelyben a `using` utasítás egy blokk elején áll:

```csharp
using var file = new File("myStuff.txt");
file.Write("more stuff");
```

Ez lehetővé teszi, hogy ugyanabban a blokkban több eldobható objektumod legyen, és hogy természetesebben kezeld a [`try/catch`][try-catch] szerkezetet:

```csharp
using var fileIn = new File("myStuff.txt");
using var fileOut = new File("yourStuff.txt");
try
{
    var stuff = fileIn.Read();
    fileOut.Write(stuff);
}
catch (Exception)
{
    LogStuff();
}
```

A `using` kulcsszó használatára vonatkozó szabályok, valamint hogy milyen típusok példányainál alkalmazható, [itt][using-statement] találhatók.

## Megjegyzés Java-fejlesztőknek

A Java-fejlesztők felismerhetik ezt a Java 7-ben bevezetett [_automatikus erőforrás-kezelés_][automatic-resource-management] mechanizmus analógiájaként. Nagyon hasonlóak. A Java szintaxisa, amely a `try` kulcsszót új célra használja, azzal az előnnyel jár, hogy természetesebben építi be a `catch` blokkokat, mint a C# `using` konstrukciója.

## Verziók

Vedd figyelembe, hogy a `using` rugalmasabb változata, amelynek nincs saját szintaktikai blokkja, a C# 8-ban jelent meg, ezért lehet, hogy ellenőrizned kell, hogy a kódbázis, amelyen dolgozol, C# 8-at vagy újabbat használ-e.
