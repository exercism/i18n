# Kiegészítés az utasításokhoz

## Bemeneti/kimeneti formátum

Minden szóhalmazt nullvégződésű stringként ábrázolunk, minden szó végén egy újsorkarakterrel.

Az anagrammákat ugyanabban a sorrendben kell visszaadnod, ahogyan a jelölt szavak listájában szerepelnek.

Egy példa erre: `"tones\nnotes\nSeton\n"`

## Regiszterek

| Regiszter | Használat       | Típus     | Leírás                                                  |
| --------- | --------------- | --------- | ------------------------------------------------------- |
| `$a0`     | bemenet         | cím       | nullvégződésű célstring, újsor nélkül                   |
| `$a1`     | bemenet         | cím       | nullvégződésű jelöltstring, minden szó után újsorral    |
| `$a2`     | bemenet/kimenet | cím       | nullvégződésű kimeneti string, minden szó után újsorral |
| `$t0-9`   | ideiglenes      | bármilyen | ideiglenes tárolásra                                    |
