# Utasítások

A tervezőcég, ahol dolgozol, eddig elsősorban CSS-transzformációkkal épített weboldalakat. Egy kis megbeszélés után úgy döntötök, hogy a dinamikus számításokat mostantól Clojure-rel végzitek. Néhány kollégád kevésbé járatos a Clojure-ben, ezért úgy döntesz, hogy egy függvény-closure segítségével hozol létre újrahasznosítható transzformációkat `{x, y}` koordinátapárokhoz.

## 1. A koordináták eltolása

Valósítsd meg a `translate2d` függvényt. Ez egy olyan függvényt ad vissza, amely egy closure-t használva egy koordinátapár ismételhető kétdimenziós eltolását végzi el.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. A koordináták skálázása

Valósítsd meg a `scale2d` függvényt. Ez egy olyan függvényt ad vissza, amely egy closure-t használva egy koordinátapár ismételhető kétdimenziós skálázását végzi el.

> Ehhez a feladathoz feltételezd, hogy csak pozitív skálázási értékek fordulnak elő.

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. Transzformációs függvények komponálása

Fűzz össze két transzformációs függvényt egy ismételhető transzformációhoz. Ezt gyakran _függvénykompozíciónak_ nevezik, ahol az első függvény, _'f(x)'_ eredménye lesz a második függvény, _'g(x)'_ bemenete.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. A függvények eredményeinek mentése

Valósítsd meg a `memoize-transform` függvényt. Ez egy _memoizálandó_ függvényt vesz át, majd visszaad egy új függvényt, amely megjegyzi a kapott függvény bemeneteit, így a legutóbbi visszatérési érték „megjegyezhető”, és csak egyszer számítódik ki, ha ugyanazokkal az argumentumokkal hívják meg újra.

> A memoizálást néha _dinamikus programozásnak_ is nevezik; lehetővé teszi, hogy a költséges műveleteket csak egyszer hajtsuk végre, mivel az eredményüket megjegyzi.

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
