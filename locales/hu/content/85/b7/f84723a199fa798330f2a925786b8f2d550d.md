# Utasítások

Ebben a feladatban kódot fogsz írni, ami segít megfőzni egy remek lasagnét a kedvenc szakácskönyvedből.
Négy részfeladat vár rád, mindegyik a lasagne elkészítésével töltött időhöz kapcsolódik.

## 1. Határozd meg a várható sütőidőt percben

Határozd meg az `expectedMinutesInOven` konstansot, amely azt tárolja, hogy hány percig kell a lasagnének a sütőben lennie.
A szakácskönyv szerint a várható sütőidő 40 perc:

```swift
expectedMinutesInOven
// Returns 40
```

## 2. Számítsd ki a hátralévő sütőidőt percben

Határozd meg a `remainingMinutesInOven(elapsedMinutes:)` függvényt, amelynek az `elapsedMinutes` argumentuma azt tartalmazza, hogy hány percig volt már a lasagne a sütőben.
A függvény adja vissza, hogy hány percig kell még a lasagnének a sütőben maradnia, az előző részfeladatban megadott várható sütőidő alapján.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. Számítsd ki az előkészítési időt percben

Határozd meg a `preparationTimeInMinutes(layers:)` függvényt, amelynek a `layers` argumentuma azt tartalmazza, hogy hány réteget raktál a lasagnébe.
A függvény adja vissza, hogy hány percet töltöttél a lasagne előkészítésével, feltéve, hogy egy réteg előkészítése 2 percet vesz igénybe.

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. Számítsd ki a teljes munkával töltött időt percben

Határozd meg a `totalTimeInMinutes(layers:elapsedMinutes:)` függvényt, amely két argumentumot vár: a `layers` paraméter a lasagnébe tett rétegek száma, az `elapsedMinutes` paraméter pedig az, hogy hány percig volt a lasagne a sütőben.
A függvény adja vissza, hogy összesen hány percet dolgoztál a lasagne elkészítésén, ami az előkészítési idő és a lasagne által eddig a sütőben eltöltött idő összege.

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
