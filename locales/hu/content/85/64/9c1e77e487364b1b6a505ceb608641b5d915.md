# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít egy szabadúszónak egyeztetni az ügyfeleivel bizonyos projektek árairól.
Írsz néhány segédfüggvényt, amelyekkel gyorsan kiszámíthatók az ügyfelek költségei.

```exercism/note
A `ratePerHour` változó és a `dayRate` függvény a pénzhez kapcsolódik.
A mértékegység az időegységre jutó pénzösszeg: rendre óra, illetve nap.
```

## 1. Számítsd ki a napidíjat egy óradíj alapján

Egy ügyfél felveszi a kapcsolatot a szabadúszóval, hogy érdeklődjön az árai felől.
A szabadúszó elmagyarázza, hogy **_naponta 8 órát dolgozik._**
A szabadúszó azonban csak a projekt óradíját ismeri.
Segíts neki megbecsülni a napidíjat egy adott óradíj alapján.

```javascript
dayRate(89);
// => 712
```

A napidíjat nem kell kerekíteni, sem „rögzített” pontosságra váltani.

## 2. Számítsd ki a munkanapok számát egy rögzített költségvetés alapján

Egy másik nap egy projektmenedzser felajánlja a szabadúszónak, hogy dolgozzon egy rögzített költségvetésű projekten.
A rögzített költségvetés és a szabadúszó óradíja alapján segíts neki kiszámítani, hány napot dolgozna, mire a költségvetés kimerül.
Az eredményt **lefelé kell kerekíteni** a legközelebbi egész számra.

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. Számítsd ki a kedvezményes árat nagy projektek esetén

A szabadúszó ügyfelei gyakran több hónapon át tartó projektekre kérik fel.
Ilyenkor a szabadúszó úgy dönt, hogy minden teljes hónap után kedvezményt ad, a fennmaradó napokat pedig napidíjon számlázza.
A kiváló munka-magánélet egyensúlyod miatt naptári hónaponként csak 22 napot dolgozol, így **_minden hónapban 22 számlázható nap van._**
Segíts neki megbecsülni egy ilyen projekt költségét, ha adott az óradíj, a projektben lévő számlázható napok száma és a havi kedvezmény mértéke.
A kedvezményt mindig számként adjuk át, ahol a `42%` `0.42` lesz. Az eredményt **felfelé kell kerekíteni** a legközelebbi egész számra.

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
