# Kiegészítő utasítások

## Regiszterek

| Regiszter | Használat     | Típus   | Leírás                                      |
| --------- | ------------- | ------- | ------------------------------------------- |
| `$a0`     | bemenet       | cím     | az első szín null-terminált stringként      |
| `$a1`     | bemenet       | cím     | a második szín null-terminált stringként    |
| `$a2`     | bemenet       | cím     | a harmadik szín null-terminált stringként   |
| `$a3`     | bemenet/kimenet | cím   | null-terminált kimeneti string              |
| `$t0-9`   | ideiglenes    | bármilyen | ideiglenes tárolásra szolgál              |
</br>
