# A tesztek futtatása

A tesztkészlet futtatásához hajtsd végre a következő parancsot:

```bash
stack test
```

#### Ha ilyen hibaüzenetet kapsz...

```
No .cabal file found in directory
```

vagy

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

valószínűleg a stack egy régi verzióját használod, és frissítened kell. Próbáld meg futtatni:

```bash
stack upgrade
```

A frissítés további lehetőségeit pedig a [Stack dokumentációjában](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade) nézheted meg.

#### Egyébként, ha ilyen hibaüzenetet kapsz...

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

Csak tedd azt, amit ír, és le fogja tölteni meg telepíteni a megfelelő fordítóverziót:

```bash
stack setup
```

# A *GHCi* futtatása

Ha GHCi-ben szeretnél kísérletezni a megoldásoddal, csak futtasd a következő parancsot:

```bash
stack ghci
```
