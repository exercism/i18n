# Tesztek

## Tesztek futtatása

A tesztek futtatásához hajtsd végre a következő parancsot:

```bash
dotnet test
```

## A feladat megoldása

Egy feladat megoldásához az kell, hogy minden tesztje sikeres legyen. Alapértelmezés szerint csak egy teszt fut le (az első), amikor futtatod a teszteket. Ez szándékos, mert így arra összpontosíthatsz, hogy az az egy teszt sikeres legyen. Amint sikeres lesz, a következő tesztet úgy engedélyezheted, hogy eltávolítod a `Skip = "Remove this Skip property to run this test"` részt a teszt `[<Fact>]` vagy `[<Theory>]` attribútumából. Amikor minden tesztet engedélyeztél, és a megvalósításod mindet sikeressé teszi, akkor megoldottad a feladatot!

Hogy könnyebben elindulj, minden feladathoz jár egy váz implementációs fájl. Ezt a fájlt kiindulópontként használhatod a megoldásod felépítéséhez. Nyugodtan törölheted vagy módosíthatod, ha úgy gondolod, hogy így a helyes.

## Csomagok használata

A legtöbb feladatot külső csomagok használata nélkül is meg tudod oldani. Ha viszont egy feladatnál mégis külső csomagot szeretnél használni, a következő paranccsal adhatod hozzá a projektedhez:

```bash
dotnet add package [package-name]
```
