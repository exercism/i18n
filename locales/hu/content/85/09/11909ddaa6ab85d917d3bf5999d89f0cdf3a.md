# Részletesen

A charlistokat a `~c` sigil segítségével hozod létre.

```elixir
~c"hello"
```

~~~~exercism/note
Figyeld meg, hogy az Elixir régebbi verzióiban a charlistokat `'hello'` alakban, aposztrófokkal jelölték.
~~~~

A charlist egész számok listája. Az egész számok egy adott karakter Unicode-értékét jelentik, más néven a kódpontját.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## A charlistok _valóban_ listák

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

Mivel a charlistok listák, ugyanúgy dolgozhatsz velük, mint bármely más listával: rekurzióval és mintaillesztéssel, vagy a [`List`][list] modullal.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

Két listát a [`++`][kernel-concat-list] operátorral fűzhetsz össze.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Minél hosszabb az első lista, annál lassabb az összefűzés, ezért ne fűzz hozzá ismételten tetszőleges hosszúságú listákhoz.

## Nyomtathatóság

Ha egy egész számokból álló lista csak nyomtatható karakterek kódpontjait tartalmazza, charlistként jelenik meg. Még akkor is, ha a `[]` szintaxissal hoztad létre.

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

Ha egy egész számokból álló lista akár csak egyetlen nyomtathatatlan karakter kódpontját is tartalmazza (pl. `0-6`, `14-26`, `28-31`), listaként jelenik meg. Még akkor is, ha a `~c""` szintaxissal hoztad létre.

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

A nyomtathatóságot a [`List.ascii_printable?`][list-ascii-printable] függvénnyel ellenőrizheted.

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

Tartsd észben, hogy ez ugyanazon adatok _megjelenítésének_ két különböző módja. Az értékek szigorúan egyenlők.

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

Amikor egy listát a [`IO.inspect`][io-inspect] függvénnyel írsz ki, a [`:charlists`][inspect-opts] opcióval szabályozhatod, hogyan jelenjenek meg a listák.

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## Kódpontok

Ha egy karakter elé `?`-t teszel, megkapod a kódpontját.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## Charlistok és stringek

Az ugyanazokból a karakterekből álló charlistok és stringek nem számítanak egyenlőnek.

```elixir
~c"hello" == "hello"
false
```

A charlistben minden érték egy karakter [Unicode-kódpontja][unicode-table], a stringben viszont a kódpontok [UTF-8][utf8] kódolással szerepelnek.

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

Figyeld meg, hogyan kódolódik az `ü` (kódpontja `252`) a UTF-8-ban `195` és `188` értékként.

**A gyakorlatban a charlistokat ritkán használják**. Legfőbb felhasználási területük az Erlanggal való együttműködés, különösen régebbi könyvtárak használatakor, amelyek nem fogadnak el binárisokat argumentumként.

Amikor Elixirrel dolgozol, **szöveg tárolásához stringeket használj**. A `String` modul rengeteg függvényt kínál a szöveg feldolgozásához, olyanokat, amelyek charlistokhoz nem érhetők el.

A charlistokat a [`to_string`][kernel-to-string] függvénnyel alakíthatod stringgé.

```elixir
to_string(~c"hello")
# => "hello"
```
