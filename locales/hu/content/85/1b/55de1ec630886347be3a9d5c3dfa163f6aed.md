# Bevezetés

## Függvénytípusok

Ha eltávolítanád az összes nevet és címkét egy Swift-függvény szignatúrájából, akkor a függvény típusa maradna.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Figyeld meg, hogy az első két függvény típusa ugyanaz, `(String, Int) -> String`, pedig a két szignatúra különbözik, és a két függvény nagyon másképp működik. Mindkettő egy `String`-et és egy `Int`-et vesz bemenetként, és egy `String`-et ad vissza. És ahogy az a harmadik függvény típusából látszik, bár a függvény törzse látszólag nem ad vissza semmit, valójában implicit módon `()`-t ad vissza, ami a `Void` típus egyetlen értéke.

Ezek a függvénytípusok ugyanúgy használhatók, mint bármely más típus a Swiftben; például szerepelhetnek változók vagy konstansok deklarációjában. És mivel a Swiftben a függvények értékek, a már létező függvények hozzárendelhetők ezekhez a konstansokhoz/változókhoz:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Ahogy más változóknál/konstansoknál, az érték, amit hozzárendelsz, csak a megfelelő típusú lehet:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Függvénytípusok paramétertípusként

Mivel a függvénytípusok mindenhol használhatók, ahol más típusok, ebből következik, hogy paramétertípusként is szerepelhetnek: átadhatók más függvényeknek, és azokon belül meg is hívhatók.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Függvénytípusok visszatérési típusként

Hasonlóképpen a függvénytípusok visszatérési típusként is használhatók a függvényeknél. Más szóval írhatsz olyan függvényeket, amelyek más függvényeket hoznak létre és adnak vissza. Amikor ilyen függvényeket készítesz, a visszaadott függvény használhatja a függvénynek átadott többi paramétert vagy a szülőfüggvényben létrehozott helyi változókat.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
