# Utasítások

Egy kutatóállomás biztonsági pultjánál dolgozol. A munkatársak *jelvényeket* hordanak, amelyek kódjai szigorú formátumot követnek. A belépési napló tele van ezekkel a kódokkal, hétköznapi szöveg közé keveredve, és a naplót meg kell tisztítani, mielőtt bárkivel megoszthatnánk. Mindegyik feladathoz a reguláris kifejezések a megfelelő eszköz.

Egy érvényes jelvénykód **két nagybetűből, egy kötőjelből, majd négy számjegyből** áll, például: `NS-1024`.

## 1. Ellenőrizd a jelvénykódot

Definiáld a `valid-badge?` szót, amely egy stringet kap, és `t`-t ad vissza, ha a *teljes* string érvényes jelvénykód, egyébként pedig `f`-et.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. Szedd ki az összes kódot egy naplósorból

Definiáld a `badge-codes` szót, amely a belépési napló egy sorát kapja, és sorrendben visszaadja az összes benne előforduló jelvénykód sorozatát.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. Számold meg a számjegyeket egy kódban

Definiáld a `digit-count` szót, amely egy stringet kap, és visszaadja, hogy hány számjegyet tartalmaz.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. Takard ki a jelszavakat

A naplósorok néha egy jelszót `pass=` formában rögzítenek, amelyet a titok követ (bármennyi, szóközt nem tartalmazó karakter). Definiáld a `redact` szót, amely egy sort kap, és úgy adja vissza, hogy minden ilyen jelszót `pass=****`-ra cserél.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
