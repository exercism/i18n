# Bevezetés

## Számok

A Javában két különböző típusú szám létezik:

- Egész számok: olyan számok, amelyeknél a tizedesjel mögött nincs számjegy (egész értékek).
  Például: `-6`, `0`, `1`, `25`, `976` és `-500000`.
- Lebegőpontos számok: olyan számok, amelyeknél a tizedesjel mögött nulla vagy több számjegy áll.
  Például: `-20.4`, `0.1`, `2.72`, `16.984025` és `1024.0`.

A Javában a két leggyakoribb numerikus típus az `int` és a `double`.
Az `int` egy 32 bites egész szám, a `double` pedig egy 64 bites lebegőpontos szám.

A számtani műveleteket a szokásos aritmetikai operátorokkal végezzük el.
A számokat össze lehet hasonlítani a szokásos numerikus összehasonlító operátorokkal (pl. `5 > 4` és `4 <= 5`), valamint az egyenlőség (`==`) és az egyenlőtlenség (`!=`) operátorokkal.

A Javában kétféle numerikus konverzió létezik:

1. Implicit konverziók: nem vész el adat, és nincs szükség további szintaxisra.
2. Explicit konverziók: adat veszhet el, ezért további szintaxisra, egy _cast_-ra van szükség.

Mivel az `int` kevésbé pontos, mint a `double`, az `int`-ből `double`-be való átalakítás biztonságos, ezért implicit konverzió.
A `double`-ből `int`-be való átalakítás viszont adatvesztéssel járhat, ezért explicit konverziót igényel.

## If-else elágazások

### Az _if-then_ elágazás

A Java legalapvetőbb vezérlési utasítása az _if-then_ elágazás.
Ezzel az elágazással csak akkor fut le egy kódrészlet, ha egy adott feltétel `true`.
Az _if-then_ elágazást az `if` ág adja meg:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

A fenti példában, ha az autóban nincs üzemanyag, a `Car.drive` metódus meghívása nem tesz semmit.

### Az _if-then-else_ elágazás

Az _if-then-else_ elágazás arra az esetre kínál alternatív végrehajtási utat, amikor az `if` ágban lévő feltétel `false` értékűre értékelődik ki.
Ez az alternatív végrehajtási út az `if` ág után következik, és az `else` ág adja meg:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

A fenti példában, ha az autóban nincs üzemanyag, a `Car.drive` metódus meghívása egy másik metódust hív meg, amely leállítja az autót.

Az _if-then-else_ elágazás több feltételt is támogat az `else if` ág használatával:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

A fenti példában, ha az üzemanyag kevesebb vagy egyenlő, mint `5`, az autó továbbra is halad, de felgyullad az üzemanyaglámpa.
Amikor az üzemanyag eléri a `0`-t, az autó megáll.
