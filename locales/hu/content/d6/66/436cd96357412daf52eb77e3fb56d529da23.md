# Bevezetés

A `Time` modul ember által olvasható dátumok és időpontok megjelenítésére szolgál.
Bár a `Time` segítségével technikailag lehetséges az időpontok manipulálása, az Elm-közösségnek vannak olyan csomagjai, amelyek sokkal jobban illenek erre a feladatra, például a [`justinmimbs/date`][date] vagy a [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Az időpontokat a `Posix` átlátszatlan típus képviseli, amely a Unix epoch időt csomagolja magába: az 1970. január 1. éjfél (UTC) óta eltelt ezredmásodpercek számát.
A `Posix` egy egyértelmű érték, amely nem változik az időzónák között, ezért jó választás az idő tárolására.
Egy Elm-alkalmazásban a `Posix` időpontokat általában külső források biztosítják, például a böngésző.

Egy `Posix` átalakítható ezredmásodpercek számává és fordítva a következő függvényekkel:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Időzónák

A mindennapi életünkben mi, emberek általában nem `Posix` értékeket olvasunk, hanem a helyi időt részesítjük előnyben, amely a Földön elfoglalt helyünktől és a helyi nyári időszámítás szabályaitól függ.
Elmben ezt az információt a `Zone` átlátszatlan típus kódolja, amelyet általában a böngésző biztosít.

Van egy különleges `Zone`, amely mindig elérhető:

```elm
utc : Zone
```

## Emberi időpontok

Egy `Posix` és egy `Zone` birtokában már elegendő információnk van ahhoz, hogy a helyi időt bármilyen részletességgel megjelenítsük.
Íme az ehhez használható függvények listája:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Két további, a `Time` modulhoz tartozó egyedi típust is észrevehettél:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Ezeknek az egyedi típusoknak az ember által olvasható értékekké alakítása a felhasználókra marad.
