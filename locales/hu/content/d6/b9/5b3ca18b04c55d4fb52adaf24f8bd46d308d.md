# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít egy szabadúszónak kommunikálni egy projektmenedzserrel.
A feladatod, hogy néhány segédfüggvényt készíts a napi és a havi díj gyors kiszámításához, opcionálisan egy megadott kedvezménnyel.

Először rögzítsünk néhány szabályt a szabadúszó és a projektmenedzser között:

- A napi díj az óradíj nyolcszorosa.
- Egy hónapban 22 számlázható nap van.

Néha a szabadúszó kedvezményt ajánl a napi díjából (például a leghűségesebb ügyfeleinek vagy nonprofit ügyfeleknek).

A kedvezményeket százalékot jelentő tizedes törtekként modellezzük, például `25.0` (25%).

## 1. Számítsd ki a napi díjat egy óradíj alapján

Készíts egy `daily_rate` nevű függvényt, amely egy paraméterként kapott óradíjból kiszámítja a napi díjat.
A szerződés szerint egy nap 8 számlázható órából áll.

```cpp
daily_rate(60)
// => 480.0
```

A visszaadott napi díj típusa `double` legyen.

## 2. Számítsd ki a kedvezményes árat

Készíts egy `apply_discount` függvényt, amely kiszámítja a kedvezmény utáni árat.
Két paramétert várjon: az eredeti árat és a kedvezmény mértékét százalékban.

```cpp
apply_discount(150, 10)
// => 135.0
```

A visszaadott érték mindig `double` típusú legyen, és semmilyen módon ne legyen kerekítve.

## 3. Számítsd ki a havi díjat egy óradíj és egy kedvezmény alapján

Készíts egy `monthly_rate` függvényt, amely kiszámítja a kedvezményes havi díjat.
Két paramétere legyen: egy óradíj és a kedvezmény százalékban.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

A visszaadott havi díjat felfelé kell kerekíteni (vedd a felső egészrészét) a legközelebbi egész számra.

## 4. Számítsd ki a teljes munkanapok számát egy költségkeret, egy óradíj és egy kedvezmény alapján

Készíts egy `days_in_budget` függvényt, amely egy költségkeretet, egy óradíjat és egy kedvezményt kap, és kiszámítja, hogy hány teljes munkanapra elegendő ez.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

A visszaadott napok számát lefelé kell kerekíteni (vedd az alsó egészrészét) a következő egész számra.
