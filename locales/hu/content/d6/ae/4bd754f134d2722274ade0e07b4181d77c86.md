# Névjegy

A Java `char` primitív típus egyetlen Unicode-karakter 16 bites reprezentációja.

~~~~exercism/note
A `char` típus az [eredeti Unicode-specifikáción][unicode-specification] alapul, amely 16 bitet használt a karakterek ábrázolására.
Ez elég a leggyakoribb betűk lefedésére, és lefedi a 0x0000 és 0xFFFF közötti karaktereket.
A specifikáció azóta 0x01FFFF-ig kibővítette a lehetséges karakterek tartományát.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

Több `char` alkothat egy stringet, például `"word"`, vagy a `char`-ok egymástól függetlenül is feldolgozhatók.
A `char` literált egyszeres idézőjelek veszik körül (pl. `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## A `String` `char`-jainak lekérése

A `String.toCharArray` metódus egy String karaktereit tömbként adja vissza.
Ahogy a [tömbök][concept-arrays] részben említettük, egy `for` ciklussal végigmehetsz a tömbön.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## A [Character][docs-character] osztály

Sok beépített könyvtári metódus létezik a `char`-ok vizsgálatára és kezelésére.
Ezek a [`java.lang.Character`][docs-character] osztály statikus metódusaiként találhatók meg.
Íme néhány példa:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
A Character osztály néhány metódusának van egy túlterhelt változata, amely `char` vagy `int` értéket is fogadhat.
Például az `isDigit` metódusnak van egy olyan változata, amely [`char`][is-digit-char] értéket fogad, és egy másik, amely [`int`][is-digit-int] értéket.
Ahogy korábban említettük, a `char` típus csak a 0x0000 és 0xFFFF közötti karaktereket tudja ábrázolni.
Az `int` viszont minden karaktert képes ábrázolni, ezért vannak az `int` túlterhelések.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## Egy `char` hozzáadása egy `String`-hez

A `+` operátor használható egy `char` hozzáadására egy `String`-hez.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Vigyázz, hogy _ne_ használd a `+` operátort két `char` összefűzésére, hogy `String`-et hozz létre!
Ha két `char`-t így adsz össze, az egy `int` lesz, _nem_ egy `String`!
Például:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Ez azért van, mert a Java a `char`-t `int`-té lépteti elő (lásd a [4.2 Primitív típusok és értékek][jls-primitives] című részt a [Java Language Specification][jls-main] című dokumentumban).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Ha azonban sok karaktert kell hozzáadni, hatékonyabb lehet helyette egy [`StringBuilder`][docs-stringBuilder]-t használni:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
