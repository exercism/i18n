# Kiegészítés az utasításokhoz

## További utasítások

Kapsz egy „isogram” nevű táblát.
Az első oszlop, a „phrase”, valamilyen szöveget tartalmaz.
El kell döntened, hogy a szókapcsolat izogram-e.
A második oszlopot, az „is_isogram”-ot egész szám értékkel frissítsd:

* 1, ha a szókapcsolat izogram,
* 0, ha nem az.

~~~~exercism/note
Az SQLite összehasonlító műveletei a Boolean értékeket 0/1 számként adják vissza

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
