# Bevezetés

A *quotation* (kód `[ ]` zárójelben) maga is érték a Factorban, akárcsak egy szám vagy egy string. Eltárolhatod egy változóban, beleteheted egy tömbbe, átadhatod egy másik wordnek, és később *meghívhatod*.

## `call`

A `call` (a [`kernel`][kernel]-ben) végrehajt egy quotationt:

```factor
3 4 [ + ] call .
! => 7
```

Amikor egy quotationt olyan helyen hívsz meg `call`-lal, ahol a Factor nem tudja kikövetkeztetni a veremhatását, akkor a hatást explicit módon meg kell adnod:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

Ez egy futásidejű ellenőrzést fordít le, amely azt vizsgálja, hogy a quotation tényleg a megadott hatással rendelkezik-e.

## Quotationök a sorozatokban

Mivel a quotationök értékek, egy tömbben számok és quotationök is keveredhetnek:

```factor
{ 3 4 [ + ] }
```

Ettől a „program” egy hétköznapi sorozattá válik, és az `each` lesz a természetes módja annak, hogy lefuttassunk egyet:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## A sorozat végének szeletelése

A `head*` mindent visszaad, kivéve az utolsó `n` elemet; a `last2` pedig az utolsó kettőt:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

A `suffix`-szel együtt ez minden, amire szükséged van egy „a felső kettőt elfogyasztja, egy eredményt tol a veremre” veremművelet megírásához.
