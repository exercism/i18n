# Tesztek

Mielőtt megpróbálod futtatni a teszteket, győződj meg róla, hogy a feladat mappája megfelelően be van állítva: kövesd a telepítési lépéseket, vagyis a `corepack yarn install` parancsot és az Editor SDK beállítását.

A teszteket ezzel futtathatod:

```bash
$ corepack yarn test
```

Ügyelj rá, hogy a kódod kövesse a bevált gyakorlatokat, ahogy más felhasználók is teszik, az eslint segítségével, ami egy eszköz a kódod statikus elemzéséhez.
Az ilyen eszközök időt takarítanak meg neked a kódodban lévő elgépelések vagy buta hibák felismerésében:

```bash
$ corepack yarn lint
```

Vagy csináld mindkettőt egyszerre:

```bash
$ corepack yarn test && corepack yarn lint
```

Az Exercism TypeScript-kurzusa nem írja elő a kód _stílusát_, így szabadon választhatsz: írhatsz pontosvesszőt vagy anélkül, használhatsz tabulátort vagy szóközöket, és bármit, ami ezek között van.

## Az első modulod elkészítése

Ezen a kurzuson a tesztek általában modulként importálva töltik be a megvalósításodat: `import Bob from './bob';`.
Ahhoz, hogy ez működjön, exportálnod kell a megvalósításodat abból a fájlból, amelyben a tesztek a modulodat keresik, ez pedig a `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

Minden feladatban adtunk neked vázakat, és ebbe beleírtuk neked ezt az `export`-ot.
