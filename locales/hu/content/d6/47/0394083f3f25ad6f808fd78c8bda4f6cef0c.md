# Az anonim függvényekről és a closure-ökről

A PHP-ban lehetőség van arra, hogy függvényeken belül további függvényeket hozzunk létre. Ezeket a függvényeket nem kell elnevezni, értékül adhatók viszont változóknak, sőt közvetlenül át is adhatók egy másik függvénynek, amely függvényparamétert vár.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

Az előbbi példában definiált és az array_filter függvénynek átadott függvény egy anonim függvény. Az `array_filter` ezt használja annak eldöntésére, hogy egy adott érték bekerüljön-e a visszaadott eredménybe. Ha a függvény `true`-t ad vissza egy értékre, akkor az bekerül az eredménytömbbe.

Az anonim függvények arra is használhatók, hogy a függvényen kívüli, de scope-ban lévő változókra hivatkozzunk a függvény belsejéből. Ezt úgy szokás nevezni, hogy a függvény scope-ja „bezárul” a függvényben használt változó fölött, innen ered a „closure” név. Egyes nyelvekben a scope-ban lévő összes változó automatikusan használható a closure-ön belül. A PHP-ban az aktuális objektumra mutató `$this` automatikusan használható a closure-ön belül. Minden más változóra kifejezetten hivatkozni kell a `use` kulcsszóval.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

A fenti `makeAdderFunction` függvényben a beérkező `$number` érték „bezáródik” a belső, anonim függvénybe, amelyet aztán visszaadunk. Ezután, valahányszor végrehajtjuk ezt a függvényt, tudni fogja a beérkezett `$number` értékét. Ha újra meghívnád a függvényt egy másik számmal, az egy teljesen másik függvényt adna vissza. Az nem változtatná meg az első függvényhívás által visszaadott értékeket vagy működést.
Ha egynél több változó fölött kell bezáródnod, azokat vesszővel elválasztva beírhatod a `use` kulcsszó után.

A PHP-ban létezik egy rövidebb függvényszintaxis is, az úgynevezett `arrow functions`. Ezeknek viszonylag egyszerűnek kell lenniük. Az alapformájuk:

```php
fn(arguments) => expression
```

Ennél a függvénytípusnál nem kell `use`-ot használnod. Automatikusan bezáródik a szülő scope minden értéke fölé, és elkapja azokat. A benne szereplő kifejezés automatikusan visszatérési értékké válik, anélkül hogy a `return` kulcsszót használnod kellene. Ezzel átírhatnánk a fenti `onlyOdds` függvényt így:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

A fenti `makeAdderFunction` átírható így is:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Megjegyzés:** Ha a függvény nem írható fel kifejezésként, akkor a rövidebb arrow function szintaxis nem használható.

A változók érték szerint adódnak át az anonim függvényeknek és a closure-öknek, és ott is érték szerint használódnak. Ez azt jelenti, hogy ha a függvényen belül megváltoztatod egy változó értékét, az nem befolyásolja a függvényen kívüli változó értékét. Ha azt szeretnéd, hogy az érték módosuljon, referenciaként adhatod át.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

A fenti példában az `array_walk` végigmegy a tömb minden elemén, és minden értéket átad a hívásban megadott függvénynek. Folyamatos összeget vezet a `$total` változóban, amelyhez mindig a szám abszolút értékét adja hozzá. Azt is nyilvántartja, hány szám volt összesen. Mindkét változó referenciaként használódik a closure-ben, amit a `use` részben mindegyik változó előtti `&` jelez. Ez azt jelenti, hogy a változókon történő módosítások az `array_walk` befejeződése után is megmaradnak, így a függvény vissza tudja adni a tömbben lévő számok abszolút értékeinek átlagát.

Az anonim függvények és a closure-ök kényelmes módot kínálhatnak olyan függvény definiálására, amelyre csak egyetlen kontextusban lehet szükség, vagy olyan függvény definiálására, amely dinamikusan állít elő egy másik függvényt olyan paraméterek alapján, amelyek máskor ismertek, mint amikor a függvényt ténylegesen használjuk.
