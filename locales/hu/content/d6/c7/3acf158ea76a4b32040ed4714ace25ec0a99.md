# Utasítások kiegészítése

## Szavak

Definiálj egy `linked-list-node` tuple-t.

Definiálj egy `linked-list` tuple-t, és adj meg egy `M: linked-list length` metódust (a `sequences` szótárból), hogy a tesztek közvetlenül meg tudják hívni a `length`-et a listádon.

- `<linked-list> ( -- linked-list )` - létrehoz egy üres listát.
- `>linked-list ( seq -- linked-list )` - a `seq` minden elemét sorrendben egy új listára teszi.
- `linked-list>array ( linked-list -- array )` - visszaadja az értékeket, a lista tetejével kezdve.
- `list-push ( linked-list value -- linked-list )` - rátesz egy értéket a lista tetejére.
- `list-pop ( linked-list -- linked-list value )` - leveszi és visszaadja a lista tetején lévő értéket.
- `list-peek ( linked-list -- value )` - visszaadja a lista tetején lévő értéket anélkül, hogy levenné.
- `list-reverse ( linked-list -- linked-list )` - visszaad egy listát, amelyben az elemek fordított sorrendben vannak.

Ha a lista üres, a `list-pop` és a `list-peek` hívásakor dobj egy `list-empty` hibaosztályt.
