# Bools

A Crystalben van egy [`Bool`][bools] nevű típus.
Ez a `true` és `false` értékeket jelöli.

## Logikai operátorok

A Crystalnek három logikai operátora van (`!`, `||`, `&&`), amelyek Bool értékeket kombinálnak, és olyan kifejezéseket alkotnak, amelyek különböző értékeket adnak eredményül.

### És(`&&`)

A Crystalben az [_és_ operátort][and] a `&&` jelöli, és akkor ad vissza `true`-t, ha mindkét érték `true`; egyébként `false`-t ad vissza.
Az _és_ operátor használatakor az egyik Bool a `&&` jobb oldalára, a másik a bal oldalára kerül.

```crystal
true && true
# => true

true && false
# => false
```

### Vagy(`||`)

A Crystalben a [_vagy_ operátort][or] a `||` jelöli, és akkor ad vissza `true`-t, ha a megadott értékek közül **legalább az egyik** `true`.
Ha mindkét érték `false`, akkor `false`-t ad vissza.
A _vagy_ operátor használatakor az egyik Bool a `||` jobb oldalára, a másik a bal oldalára kerül.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Nem(`!`)

A Crystalben a _nem_ operátort a `!` jelöli: `true`-t ad vissza, ha a megadott Bool `false`, és `false`-t, ha `true`-t kap.
A _nem_ operátor használatakor a Bool értéket az operátor (`!`) után kell megadni.

```crystal
!true
# => false

!false
# => true
```

## Zárójelek használata(`()`)

Amikor logikai értékekkel dolgozol, zárójelekkel döntheted el, melyik Bool értékelődjön ki először.
Az eredmény attól függően változhat, hogyan használod a zárójeleket.
A Crystalben először a zárójelben lévő rész értékelődik ki.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Mivel a zárójelben lévő rész értékelődik ki először, a következő példában a _nem_ operátor a zárójelben lévő kifejezésre vonatkozik.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Zárójelet csak akkor használj, ha az befolyásolja az eredményt; egyébként hagyd el.
~~~~
