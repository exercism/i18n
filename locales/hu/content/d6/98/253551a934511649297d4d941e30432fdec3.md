# Bevezetés

A [`function`][function] egy módja annak, hogy a kódot elkülönítsük, hogy azt a program egy vagy több pontjáról a nevével hívhassuk meg.
A függvényeket meghatározott és ismétlődő feladatok elvégzésére használjuk.

Formálisabban: a függvény minden olyan Python-objektum, amelyre a [`function call`][calls] művelet alkalmazható.
Egy függvény használható arra, hogy valamilyen művelet eredményeként egy vagy több értéket visszaadjon ([`return`][return]), illetve arra, hogy egy vagy több [`side effects`][side effects] jöjjön létre.
Ha egy függvény nem ad meg visszatérési értéket, akkor is `None`-t ad vissza.

Az alábbi egy olyan függvény példája, amelynek mellékhatása van:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

A fenti példában a [`def`][def] kulcsszó jelzi a függvénydefiníció kezdetét.
A `hello` a függvény neve.
Az üres zárójelek azt jelentik, hogy nem adunk át értéket a függvénynek.
A függvény törzsét az egyetlen `print("Hello")` utasítás alkotja.
A `print` szintén egy függvény.
A `print` függvény zárójelében szereplő `"Hello"` egy [`argument`][arguments].
Az argumentum segítségével a `print` függvény tudja, hogy mit írjon ki.
Figyeld meg, hogy a függvény törzse be van húzva.
A behúzás azért fontos, mert a Python erre támaszkodik, hogy tudja, hol ér véget az a kódblokk.
A függvény törzse vagy a program végénél ér véget, vagy közvetlenül azelőtt a sor előtt, amely _nincs_ behúzva.
Mivel a `hello()` nem ad meg `return` értéket, végrehajtja a mellékhatását, azaz meghívja a `print()`-et, majd visszaad `None`-t.
Végül a függvényt a nevével és a zárójelekkel hívjuk meg, ami jelzi a Python-értelmezőnek, hogy ez egy _hívható_ név.

Az alábbi egy olyan függvény példája, amely visszatérési értékkel rendelkezik:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

Ennek a függvénynek a törzse megváltozott: a `print` _meghívása_ helyett most a `string` "Hello" _visszaadása_ történik.
Végül a kód továbbra is kiírja a `"Hello"`-t, de a mellékhatás a _hívó kódban_ jelentkezik, nem pedig a `hello` függvényben.
Ha elhagynánk a zárójeleket a `hello` függvény hívásakor (például `print(hello)`), akkor a `print` valami ilyesmit írna ki:

```
<function hello at 0x0000026E18E93E20>
```

Fontos, hogy még ha egy függvény nem is fogad el argumentumot (_azaz nincsenek paraméterei_), akkor is az üres zárójeleket kell használni a helyes _meghívásához_.
Ez eltér az olyan nyelvtől, mint például a Ruby, amely nem igényel üres zárójelet egy argumentum nélküli függvény meghívásához.

Egy függvény definíciójában nulla vagy több [`parameters`][parameters] szerepelhet. A paraméter határozza meg, hogy a függvény milyen argumentumokat fogad el.

Az alábbi egy olyan függvény példája, amely elfogad egy argumentumot:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

A paraméter neve `name`.
A `"Bob"` az az argumentum, amelyet a program átad a `hello` függvénynek.
A függvény _visszaadja_ a `string` "Hello, Bob" értéket.

Mi történik, ha valaki argumentum nélkül hívja meg a `hello` függvényt?
A program hibát dob:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Ha nem szeretnénk, hogy a program argumentum nélkül hibát dobjon (_de szeretnénk engedni, hogy a hívó kód ne adjon meg egyet_), megadhatunk egy [alapértelmezett argumentumot][default arguments].
Az alapértelmezett argumentum meghatározza, hogy milyen értéket használjon a program, ha a függvény hívásakor hiányzik az argumentum.

Az alábbi egy olyan függvény példája, amely alapértelmezett argumentummal rendelkezik:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

A `name` paraméter kapja a `"you"` alapértelmezett argumentumot, így a program a `Hello, you` szöveget írja ki, ha nem adunk át `name` argumentumot.

Ha többet szeretnél megtudni a függvényargumentumokról, nézd meg a [függvényargumentumok][function arguments] fogalmat.
