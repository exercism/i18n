# Bevezetés

## Túlcsordulás

Aritmetikai túlcsordulás akkor következik be, amikor egy számítás, például egy aritmetikai művelet vagy típuskonverzió olyan értéket eredményez, amely nagyobb, mint a fogadó típus kapacitása.

Az `int` és `long` típusú kifejezések, valamint előjel nélküli megfelelőik ilyenkor csendben átfordulnak.

Az egészszám-műveletek viselkedése módosítható a `checked` kulcsszó használatával. Ha egy `checked` blokkon belül túlcsordulás történik, a rendszer egy `OverflowException` példányt dob.

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

A `float` és `double` típusú kifejezések a végtelen egy speciális értékét veszik fel.

A `decimal` típusú kifejezések `OverflowException` példányt dobnak.
