# Referenciák és pillanatképek

Amikor átadunk egy változót egy függvénynek, a tulajdonjoga általában átkerül, és az eredeti változó használhatatlanná válik. Ez kissé körülményes lehet, ha egy állapotot többször szeretnénk elérni.
A Cairo két lehetőséget kínál arra, hogy egy értéket anélkül adjunk át, hogy megsemmisítenénk vagy elmozdítanánk: a `references` és a `snapshots`.

## Pillanatképek

A pillanatképek egy érték megváltoztathatatlan nézetét adják egy adott időpillanatban, lehetővé téve, hogy megtartsd egy változó tulajdonjogát, miközben hozzáférsz az állapotához.
A változó bármilyen módosítása új memóriacellát hoz létre, így a pillanatkép nézete változatlan marad.

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## Desnap operátor

Ha egy pillanatképet vissza szeretnél alakítani egy közönséges változóvá, használhatod a desnap operátort, a `*`-ot, amely a `@` operátor ellentéte.
Csak azok a típusok desnapelhetők, amelyek implementálják a `Copy` traitet.

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## Módosítható referenciák

A módosítható referenciák lehetővé teszik, hogy módosítható értékeket adj át egy függvénynek, és azok implicit módon visszatérjenek, miközben a hívó kontextus megtartja a tulajdonjogot.
Ez a `ref` módosítóval érhető el, feltéve, hogy a változó a `mut` kulcsszóval módosíthatóként van deklarálva.

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
