# Bevezetés

Az R-ben nincs külön [halmaz][wiki-set] típus, helyette többféle függvény végzi el a hasonló műveleteket vektorokon.

A [`%in%`][ref-match] operátor azt vizsgálja, hogy egy érték tagja-e a halmaznak.
Ez az infix operátor az `is.element()` függvény szinonimája.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

A kapcsolódó függvények:

- A [`unique()`][ref-unique] eltávolítja a duplikátumokat.
- A [`union()`][ref-sets] egyesíti a halmazokat (matematikailag `A ∪ B`).
- Az [`intersect()`][ref-sets] megkeresi a két halmaz közös elemeit (`A ∩ B`).
- A [`setdiff()`][ref-sets] kivonja az egyik halmazt a másikból (`A - B`).
- A [`setequal`][ref-sets] a halmazok egyenlőségét vizsgálja, figyelmen kívül hagyva a duplikátumokat és a sorrendet.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

A függvények minden esetben másolatot adnak vissza, az argumentumokat pedig változatlanul hagyják.

## Hashtáblák

A fent leírt vektorműveletek a base R részei.
Kis problémák esetén hasznosak, nagy halmazoknál viszont lassúvá válnak.

Több harmadik féltől származó csomag is megvalósít [hashtáblákat][wiki-hash], hogy bizonyos helyzetekben javítsa a teljesítményt.

Például a [`hashtable`][ref-hashtable] csomag `hashmap` és `hashset` implementációkat kínál, amelyek jobban skálázódnak.
A legtöbb külső csomaghoz hasonlóan ez sem érhető el az Exercismen, de érdemes megismerkedni vele, ha valós problémákkal foglalkozol.
