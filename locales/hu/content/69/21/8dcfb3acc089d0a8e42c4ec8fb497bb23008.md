# Bevezetés

## Névterek

A kód szervezésének egyik fontos módszere a névterek használata.
Két függvény neve ütközhet, amit azzal oldhatunk fel, hogy különböző névterekbe tesszük őket.
A névterek egymásba ágyazhatók, ami segíthet a nagy kódbázisok tagolásában.
A névterek elérése a `::` scope-feloldó operátorral történik.

Az alábbi példa két különböző `foo` függvény használatát mutatja.
Ezeket úgy használjuk együtt, hogy az elejükre írjuk a megfelelő névteret.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
