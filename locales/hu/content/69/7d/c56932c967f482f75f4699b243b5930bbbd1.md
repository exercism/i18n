# Vezérlési folyam

Az `if` kifejezések és a ciklusok a Cairoban a következő módon vezérlik a végrehajtás folyamát:
`

- **`if` kifejezések** feltételesen hajtanak végre kódot attól függően, hogy egy feltétel `true`-ra értékelődik-e.
- **Ciklusok** (például `loop`, `while` és `for`) ismételten végrehajtanak kódot, amíg egy megadott feltétel igaz marad, vagy amíg egy kilépési feltétel teljesül.

Ezek a szerkezetek alapvetőek a logika és az iteráció megvalósításához a Cairoban.

## `if` kifejezések

A Cairoban az `if` kifejezések lehetővé teszik, hogy feltételes logika alapján vezéreljed a végrehajtás folyamát.
Olyan felépítést követnek, amelyben a kód attól függően fut le, hogy egy Boolean feltétel `true` vagy `false` értékre értékelődik-e.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

Ez a példa egy egyszerű `if` blokkot mutat be a Cairoban.
A `"It's hot outside!"` üzenet csak akkor kerül kiírásra, ha a `temperature > 25` feltétel `true`-ra értékelődik.
Ha a feltétel `false`, nem fut le kód, és a program folytatódik.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

Ennek a kódnak a futtatása a `"The number is less than 10."` szöveget írja ki a konzolra.

### Több feltétel kezelése `else if` kifejezéssel

Több feltételt úgy is kezelhetsz, hogy az `if` és az `else` szerkezetet `else if` kifejezéssé kombinálod.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

Ennek a kódnak a futtatása a `"Grade: B"` szöveget írja ki a konzolra.

### Az `if` használata `let` utasításban

A Cairoban az `if` kifejezés használható a `let` utasítás jobb oldalán, és így az eredményt egy változóhoz rendelheted.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## Ciklusok

A ciklusok alapvető szerkezetek, amelyek lehetővé teszik a kódblokkok ismétlését, hatékony és szabályozott feladatvégrehajtást biztosítva.
A ciklusok végigmehetnek egy sorozaton, vagy feltétel alapján ismételten végrehajthatnak kódot.
A Cairo három fő ciklusváltozatot kínál:

- **loop**: Alapvető ciklus, amely a végtelenségig fut, hacsak egy `break` utasítással kifejezetten le nem állítod.
- **while**: Addig hajt végre kódot, amíg egy megadott feltétel `true` marad.
  Leáll, amikor a feltétel `false` lesz.
- **for**: Végighalad egy gyűjtemény elemein, például tömbökön, és minden elemre végrehajtja a kódot.

### Kód ismétlése a `loop` segítségével

A `loop` kulcsszó arra utasítja a Cairót, hogy egy kódblokkot újra és újra végrehajtson, a végtelenségig, vagy amíg kifejezetten nem jelzed, hogy álljon le.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Ennek a kódnak a futtatása a `"again!"` szöveget írja ki a konzolra a végtelenségig, amíg a program ki nem fogy a gázból, vagy manuálisan le nem állítod.

> Megjegyzés: A Cairo beépített gázmérővel akadályozza meg, hogy végtelen ciklusú programot futtassunk.
> A gázmérő egy mechanizmus, amely korlátozza, hogy egy programban mennyi számítást lehet elvégezni.
> A gáz egy mértékegység, amely egy utasítás számítási költségét fejezi ki.
> Amikor a gázmérő kifogy, a program leáll.

Ha ki akarsz lépni egy ciklusból, helyezd el a `break` kulcsszót a cikluson belül, hogy megmondd a programnak, mikor álljon le a végrehajtással.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

A `continue` kulcsszó arra utasítja a programot, hogy ugorjon a ciklus következő iterációjára, és hagyja ki az aktuális iteráció hátralévő kódját.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Ennek a programnak a futtatása nem írja ki az `i` értékét, amikor egyenlő `5`-tel.

#### Értékek visszaadása `loop`-ból

Visszaadhatsz egy értéket egy `loop`-ból úgy, hogy a `break` kulcsszó után megadod a visszaadni kívánt értéket.
Ez lehetővé teszi, hogy kilépj a `loop`-ból, és egy eredményt adj át a kód többi részének.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### Feltételes ciklusok a `while` segítségével

A `while` addig futtat kódot, amíg egy feltétel `true`, és kilép, amikor a feltétel `false` lesz.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### Végighaladás egy gyűjteményen a `for` segítségével

A `for` végighalad egy gyűjtemény minden elemén, és minden elemre végrehajtja a kódot.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
