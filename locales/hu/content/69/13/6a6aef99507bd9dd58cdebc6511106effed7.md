# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít Larrynek, a Lisp-űrlénynek feldolgozni és formázni a naplószövegeket. Ezek a naplószövegek különféle rendszerektől érkeznek, és fel kell dolgozni őket, hogy az üzeneteik megjeleníthetők legyenek egy informatív monitorozási kijelzőn.

A naplószövegek formája `"[<level>]: <message>"`. A szint a következő értékek egyike: `info`, `warn` vagy `ohno`.

## 1. Az üzenet kinyerése

Definiálj egy `log-message` nevű függvényt, amely egy naplószöveget vesz át, és a benne lévő üzenetre értékelődik ki.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. A súlyosság meghatározása

A naplószöveg szintje határozza meg a súlyosságát.

- az `info` szint `:everything-ok` súlyosságot jelent
- a `warn` szint `:getting-worried` súlyosságot jelent
- az `ohno` szint `:run-for-cover` súlyosságot jelent

Definiálj egy `log-severity` nevű függvényt, amely egy naplószöveget vesz át, és a megfelelő súlyosságra értékelődik ki.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. A valóság szeszélyeinek kezelése

Sajnos előfordul, hogy a naplószövegek nincsenek mindig helyesen formázva. Egészen pontosan a napló szintje nem feltétlenül csupa kisbetű, ahogy fentebb megadtuk. Módosítsd a `log-severity` függvényt, hogy kezelje ezt az esetet.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. A naplóüzenet újraformázása a napló súlyossága szerint

A súlyosságtól függően az üzenetet különbözőképpen kell módosítani:

- `:everything-ok` súlyosság esetén az üzenetet csupa kisbetűre kell alakítani.
- `:getting-worried` súlyosság esetén az üzenetben minden szót nagybetűvel kell kezdeni.
- `:run-for-cover` súlyosság esetén az üzenetet csupa nagybetűre kell alakítani.

Definiálj egy `log-format` nevű függvényt, amely egy naplóüzenetet vesz át, és egy megfelelően formázott üzenetre értékelődik ki.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
