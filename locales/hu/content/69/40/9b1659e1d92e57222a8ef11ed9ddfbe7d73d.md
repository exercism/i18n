# Bevezetés

A tulajdonságokhoz hasonlóan, amelyek adatot tárolnak a struktúráidban és az osztályaidban, _metódusokat_ is definiálhatsz, amelyek függvényeket tárolnak a struktúrában vagy az osztályban.

A metódusokat ugyanúgy definiálod, mint egy hagyományos függvényt, csak éppen a struktúra vagy az osztály törzsén belül. Ne feledd: ha egy függvény megváltoztatja egy struktúra valamelyik tulajdonságának az értékét, akkor a függvény elé be kell írni a `mutating` kulcsszót. Ha pedig egy tulajdonságot egy metódus meg tud változtatni, akkor azt a tulajdonságot `var`-ral kell definiálni, nem `let`-tel, akárcsak a hagyományos változókat.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

Ezeket a metódusokat pontszintaxissal hívhatod meg, akárcsak a tulajdonságokat.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
