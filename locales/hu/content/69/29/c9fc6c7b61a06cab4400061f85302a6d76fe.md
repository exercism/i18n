# Utasítások

Ebben a feladatban log sorokat fogsz feldolgozni.

Minden log sor egy string, amely a következő formátumú: `"[<LEVEL>]: <MESSAGE>"`.

Három különböző log szint létezik:

- `INFO`
- `WARNING`
- `ERROR`

Három részfeladatod van, mindegyik egy log sort kap, és valamit tenned kell vele.

## 1. Üzenet kinyerése egy log sorból

Valósítsd meg a `message` függvényt, amely visszaadja egy log sor üzenetét:

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

A kezdő és záró whitespace-eket el kell távolítani:

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. Log szint kinyerése egy log sorból

Valósítsd meg a `log_level` függvényt, amely visszaadja egy log sor log szintjét kisbetűvel:

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. Log sor újraformázása

Valósítsd meg a `reformat` függvényt, amely újraformázza a log sort úgy, hogy az üzenetet teszi előre, a log szintet pedig utána zárójelben:

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
