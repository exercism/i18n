# Bővebben

A [párok és szótárak][pairs-dicts] fogalom a Julia szótártípusának alapjaival foglalkozott.

Mivel a [`Dict`-ek][dict] fontos és gyakran használt gyűjteménytípusok, számos függvény is létezik a kezelésükre.

## Bejegyzések lekérése

A legegyszerűbb módja egy bejegyzés lekérésének a kulcs megadása (ahogy sok más nyelvben is).
Ha azonban egy nem létező kulcsot kérünk le, `KeyError`-t kapunk.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

A lekérés előtt ellenőrizhetnénk a kulcs meglétét (például a `haskey(d, 4)` vagy a `4 ∈ keys(d)` segítségével), de néha hasznos, ha egyszerűen csak egy alapértelmezett értéket kapunk a hiányzó kulcsokhoz.

Erre való a [`get()`][get] függvény és mutáló változata, a [`get!()`][get-bang].
A kettő abban tér el, hogy a „hiányzó” kulcs bekerül-e a `Dict`-be.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

A korábbi fogalomban láttuk, hogy a `delete!()` kulcs alapján eltávolít egy bejegyzést.
Ez összeköthető az érték lekérésével a `pop!()` függvény használatával.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Iteráció

A `Dict` feletti iterálás alapértelmezés szerint `key => value` párokat ad vissza.
A komponensek a szokásos `.first` és `.second` elnevezéssel érhetők el.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Gyakran csak a kulcsokat vagy csak az értékeket szeretnénk használni, ami egyszerű.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Összefésülés

Két `Dict` összekapcsolása hasznos lehet, de tisztázni kell, mit szeretnénk tenni azokkal a kulcsokkal, amelyek több bemenetben is szerepelnek.

A [`merge()`][merge] és a [`merge!()`][merge-bang] függvény tetszőleges számú megadott `Dict`-et fésül össze balról jobbra.

A meglévő kulcsok értékei egyszerűen felülíródnak, így a jobb szélső `Dict` „győz”.

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

A [`mergewith()`][mergewith] és a [`mergewith!()`][mergewith-bang] függvény első argumentumként egy függvényt fogad, amellyel meghatározhatjuk, hogyan fésülődjenek össze az ismétlődő kulcsok.
Az összeadás egyszerű példa erre.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Két vektor összefűzése szintén népszerű művelet összefésüléskor.
Erre a Julia a [`vcat()`][vcat] függvényt használja, ennek okait a [`Multi Dimensional Arrays`][multidim] fogalom magyarázza el.

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

Több [`Set`][sets] esetén a megfelelő összefésülő függvény a [`union`][union].

Vegyük észre, hogy a `mergewith` függvények jó példái a [magasabb rendű függvények][hof] működésének.
