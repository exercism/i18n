# Utasítások

Ebben a feladatban egy naplózott jelentés soraival fogsz dolgozni.
Minden naplósor egy string, amelynek formátuma a következő: `"[<LEVEL>]: <MESSAGE>"`.

Három különböző naplózási szint van:

- `INFO`
- `WARNING`
- `ERROR`

Három részfeladatod van; mindegyik kap egy naplósort, és valamit tenned kell vele.

## 1. Keresd ki az üzenetet egy naplósorból

Valósítsd meg a `log_line::message` metódust, amely visszaadja egy naplósor üzenetét:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. Keresd ki a naplózási szintet egy naplósorból

Valósítsd meg a `log_line::log_level` metódust, amely visszaadja egy naplósor naplózási szintjét; a szintet nagybetűvel kell visszaadni:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. Formázd újra a naplósort

Valósítsd meg a `log_line::reformat` metódust, amely újraformázza a naplósort: az üzenet kerül előre, utána pedig zárójelben a naplózási szint következik:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
