# Részletesen

A [modulattribútumok][module-attr] használhatók úgy, mint a [„konstansok”][attr-as-const], amelyek már fordítási időben kiértékelődnek.

```elixir
defmodule Example do
  @number 2

  def number(), do: @number
end
```

Szigorúan véve azonban mégsem viselkednek konstansként, mert felülírhatók, ha újra definiálod őket a modulon belül:

```elixir
defmodule Example do
  @standard_message "Hello, World!"
  @standard_message "Overwritten!"

  def message(), do: @standard_message
end
```

[module-attr]: https://hexdocs.pm/elixir/module-attributes.html
[attr-as-const]: https://hexdocs.pm/elixir/module-attributes.html#as-constants
