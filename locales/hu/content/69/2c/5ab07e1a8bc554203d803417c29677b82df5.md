# Bevezetés

## Tuple-ök

Az Elixirben a tuple egy olyan adatszerkezet, amely adatokat rendez el, rögzített számú, bármilyen típusú elemet tartalmaz, de az egyes elemeknek nincs kifejezett nevük. A tuple-öket az Elixirben gyakran használják memóriaolvasás-igényes műveletekhez, mert egy elem kiolvasása konstans idejű művelet. Általában nem használjuk őket olyankor, amikor elemeket dinamikusan kell hozzáadni vagy eltávolítani, mert a meglévő tuple módosítása helyett új tuple jön létre, amihez előre memóriát kell lefoglalni.

A gyakorlatban az Elixirben kapcsos zárójelekkel hozunk létre tuple-t. Egy tuple elemei egyenként elérhetők az `elem/2` függvénnyel, nulla alapú indexeléssel:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

### Tuple-ök mint csoportosított információ

A tuple-öket a gyakorlatban gyakran csoportosított információ ábrázolására használják.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```

## Mintaillesztés

A mintaillesztés használata meghatározó az Elixir magabiztos, idiomatikus kódjában. Talán emlékszel rá, hogy a `=/2` operátort inkább illesztő operátorként, mintsem értékadó operátorként írják le. Amikor az illesztő operátort használod, és a bal oldali minta illeszkedik a jobb oldalra, akkor a bal oldalon lévő változók értéket kapnak, a kifejezés értéke pedig a jobb oldal értéke lesz. Ha nincs egyezés, `MatchError` kivétel keletkezik.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

Ne feledd, az illesztés jobbról balra történik.

Az utolsó példában, ha nincs szükségünk egy változóra a mintaillesztésben, akkor a `_`-ra hivatkozva eldobhatjuk. A futtatókörnyezet nem követi nyomon azokat a változókat, amelyek `_`-tal kezdődnek.

### Mintaillesztés nevesített függvényekben

A mintaillesztés akkor is hasznos eszköz, amikor több függvényklauzulát hozunk létre. A mintaillesztést a függvények argumentumain is használhatjuk, ami meghatározza, hogy melyik függvényklauzula hívódik meg, a fájl tetejétől lefelé haladva az első egyezésig. A változók a függvényfejben kötődhetnek, és a függvénytörzsben használhatók.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
