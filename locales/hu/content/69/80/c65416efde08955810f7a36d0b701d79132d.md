# Telepítés

A Reason telepítéséhez szükséged lesz a Node Package Managerre (npm). Az utasításokat [itt](https://www.npmjs.com/get-npm) találod.

Ha már megvan az npm, ezzel a paranccsal telepítheted a Reasont:
```
npm install -g bs-platform
```

A Reason több szerkesztővel is integrálható, a részleteket [itt](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors) olvashatod.

Néhány parancssori eszköz (köztük egy REPL, amellyel egy shellben Reason-kifejezéseket értékelhetsz ki) [itt](https://github.com/reasonml/reason-cli) érhető el.
