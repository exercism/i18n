# Utasítások kiegészítése

## Szavak

- `<bst> ( data-seq -- tree )`: úgy épít fel egy fát, hogy a `data-seq` minden elemét sorrendben beszúrja.
- `sorted-data ( tree -- seq )`: a fa elemeit növekvő sorrendben adja vissza (bejárás sorrendjében).

## Tuple-hierarchia

A bináris keresőfa egy csomópontja vagy *üres*, vagy *adatot és két részfát tartalmaz*. Ezt egy kis öröklődési hierarchiaként modellezd:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

A `bst` az absztrakt szülő, a `leaf` az üres fa esete, a `branch` pedig egy értéket és két `bst` gyereket hordoz (amelyek maguk is vagy `leaf`, vagy `branch` típusúak).

## Sorrend

Az adatokat a `before=?` függvénnyel hasonlítsd össze (a `math.order` modulból), amely a számok mellett stringekkel is működik. A tesztek ugyanis stringadatokat használnak, például `"1"`, `"2"`, `"3"`.
