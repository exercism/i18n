# Névjegy

A Factor sorozatkönyvtára nagymértékben támaszkodik a *quotationökre*, vagyis a `[ ]` zárójelbe írt kódra, hogy paraméterezze az iterációt. A minta mindig ugyanaz: adj át egy sorozatot és egy quotationt, a magasabb rendű szó pedig minden elemre lefuttatja a quotationt.

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

Íme a gyakran használt szavak teljes sora:

| szó          | alak                                       |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

Amikor a *saját* szavad egy futásidejű quotationt ad tovább ezeknek a kombinátoroknak, a `; inline` szóval deklaráld a szavadat, hogy a kombinátor hatáskövetkeztetése lássa a quotation alakját a hívás helyén. A csak literál quotationökből felépülő szavaknak erre nincs szükségük.

Az alapvető sorozatműveleteken túl:

| szókészlet         | mit biztosít                                  |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

A páros (`bi`, `tri`) és az „n-áris” kombinátorok (`2map`, `2each`, `zip`) ugyanezt a mintát követik, amikor a quotationnek több bemenetre van szüksége.
