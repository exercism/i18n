# Bevezetés

A Factor bemenete és kimenete *streamekre* épül: olyan objektumokra, amelyekből bájtokat vagy karaktereket olvasol, illetve amelyekbe írsz. Az [`io`][io] szókészlet ugyanannak a [protokollnak][stream-protocol] két nézetét adja.

## A két nézet

Az **explicit stream** szavak a streamet argumentumként kapják. Mindegyikük `stream-` kezdetű:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

Az **ambient stream** szavak abból a streamből olvasnak vagy abba írnak, amelyik éppen *be van kötve*: ez a programszintű dinamikus `input-stream` vagy `output-stream` változó. Rövid nevük van:

```
read1 read readln write write1 print flush
```

A hétköznapi kód többnyire az ambient formát használja. Az explicit formához akkor nyúlsz, amikor egy konkrét stream van a kezedben, és nem akarod lecserélni az ambientet.

## Memóriabeli streamek

A feladatban string-alapú streamekkel fogsz dolgozni, amelyek az [`io.streams.string`][io.streams.string] szókészletből származnak:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

A `<string-reader>` egy literál stringből olvas, mintha az egy fájl lenne; a `<string-writer>` összegyűjt mindent, amit beleírnak, hogy később visszaolvashasd. Mindkettő ugyanazt a protokollt valósítja meg, mint a fájlstreamek, így a tanulságok közvetlenül átvihetők a `<file-reader>` / `<file-writer>` párosra.

## Scope beállítása `with-…` kombinátorokkal

Ha egy explicit streamet egy quotation idejére ambientként akarsz bekötni, majd utána felszabadítani, használj egy `with-…` kombinátort:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

A [`with-string-writer`][with-string-writer] az a kényelmi forma, amellyel »összegyűjtheted, mit ír ki ez a quotation«: felépíti a writert, lefuttatja a quotationt úgy, hogy az a writer legyen az ambient kimenet, és visszaadja az elkapott stringet:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

A `with-…` kombinátorok mind destruktor-kombinátorok (ugyanabba a családba tartoznak, mint a [`boatswains-bilge`][boatswains-bilge] `with-disposal` és `with-destructors` szavai): a stream akkor is felszabadul kilépéskor, ha a quotation kivételt dob.
