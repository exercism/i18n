# Utasítások

Ebben a feladatban egy szépségszalon időpont-ütemezőjén dolgozol majd, amely 2012. szeptember 15-én nyílt meg.

Öt részfeladat vár rád, és mindegyikben időpontokkal lesz dolgod.

## 1. Egy időpont dátumának beolvasása

Valósítsd meg a `Schedule` függvényt, amely egy időpont szöveges formáját alakítja át a megfelelő `time.Time` formátumra:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. Ellenőrizd, hogy egy időpont már elmúlt-e

Valósítsd meg a `HasPassed` függvényt, amely átvesz egy időpontot, és ellenőrzi, hogy az a múltban volt-e:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. Ellenőrizd, hogy az időpont délutánra esik-e

Valósítsd meg az `IsAfternoonAppointment` függvényt, amely átvesz egy időpontot, és ellenőrzi, hogy az délutánra esik-e (>= 12:00 és < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. Írd le az időpont dátumát és idejét

Valósítsd meg a `Description` függvényt, amely átvesz egy időpontot, és visszaadja annak a dátumnak és időnek a leírását:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. Add vissza a szalon megnyitásának évfordulóját

Valósítsd meg az `AnniversaryDate` függvényt, amely visszaadja a szalon megnyitásának évfordulóját az aktuális évre UTC-ben.

Tegyük fel, hogy a jelenlegi év 2020:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**Megjegyzés:** a visszatérési érték egy `time.Time`, és a napszak nem számít.
