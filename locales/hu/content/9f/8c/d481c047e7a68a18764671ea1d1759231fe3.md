# Utasítások

Folytatva a vidámparki munkádat, most olyan segédmetódusokat kell írnod, amelyek segítenek ellenőrizni, hogy egy látogató használhat-e egy játékot.

## 1. Nézd meg, hogy egy látogatónak van-e bérlete

Valósítsd meg az `Attendee#has_pass?` metódust, amely Boolean (`true`/`false`) értéket ad vissza aszerint, hogy van-e bérlete.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Nézd meg, hogy egy látogató befér-e egy játékba

Valósítsd meg az `Attendee#fits_ride?` metódust, amellyel megnézheted, hogy egy látogató befér-e egy játékba a magassága alapján.
A játékhoz szükséges minimális magasságot argumentumként kapod meg.
A látogató magasságának nagyobbnak vagy egyenlőnek kell lennie a játékhoz megadott minimális magasságnál.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Nézd meg, hogy egy látogató felszállhat-e egy játékra

Valósítsd meg az `Attendee#allowed_to_ride?` metódust, amellyel megnézheted, hogy egy látogató felszállhat-e egy játékra. A játékhoz szükséges minimális magasságot argumentumként kapod meg. A látogatónak rendelkeznie kell bérlettel, és be kell férnie a játékba.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
