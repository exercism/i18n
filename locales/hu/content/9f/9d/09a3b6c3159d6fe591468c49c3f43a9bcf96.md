# Struktúrák

A struktúrák egyedi adattípusok, amelyekkel több összefüggő értéket nevezhetsz el és csomagolhatsz egybe.
Hasonlók a tuple-okhoz, de rugalmasabbak, és minden adategységet elnevezhetsz velük, ami átláthatóbbá teszi a kódot.
A struktúrák a Cairo-ban a következő tulajdonságokkal rendelkeznek:

- Minden struktúratípusnak saját neve van.
- A struktúra minden tagját **mezőnek** nevezzük.
- A struktúra minden mezőjének saját neve van.
- A láthatóságot mezőszinten követjük: minden mező külön-külön lehet nyilvános vagy privát.

## Struktúrák definiálása és példányosítása

Struktúra definiálásához használd a `struct` kulcsszót, utána egy nevet, majd kapcsos zárójeleket, amelyekben a mezők nevükkel és típusukkal szerepelnek:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Egy `struct` példányának létrehozásához add meg a `struct` nevét, és használj kapcsos zárójeleket a mezők kulcs-érték párjaival.
Figyeld meg, hogy a mezőket tetszőleges sorrendben felsorolhatod, amikor példányt hozol létre:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Egy struktúrapéldány kezelése

A pont jelöléssel férhetsz hozzá egy `struct` példány mezőihez, vagy módosíthatod azokat.
Figyeld meg, hogy egy mező módosításához a példánynak módosíthatónak kell lennie:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Ahogy bármely kifejezésnél, létrehozhatsz egy új `struct` példányt a függvénytörzs utolsó kifejezéseként, amit a függvény implicit módon visszaad:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Mezőinicializálási rövidítés

A legutóbbi példában volt értelme ugyanúgy elnevezni az `email` és `username` függvényparamétereket, mint a `struct` mezőit, de kissé unalmas ismételgetni őket, amikor a struktúramezőkhöz rendeljük őket.
Szerencsére van egy kényelmes rövidítés, amellyel ugyanilyen nevű változókból inicializálhatod a struktúramezőket:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Példányok létrehozása más példányokból struktúrafrissítő szintaxissal

A struktúrafrissítő szintaxissal új példányt hozhatsz létre egy meglévőből úgy, hogy néhány mezőt megváltoztatsz, a többit pedig változatlanul hagyod.
Ezt a `..` operátorral érheted el.

Frissítő szintaxis nélkül:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Struktúrafrissítő szintaxissal:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

A `..user1` szintaxis átmásolja a maradék mezőket a `user1`-ből a `user2`-be.
Figyeld meg, hogy ez átmozgatja az adatokat a `user1`-ből a `user2`-be, ezért a `user1` nem használható utána, ha nem másolható típusokat tartalmaz.
