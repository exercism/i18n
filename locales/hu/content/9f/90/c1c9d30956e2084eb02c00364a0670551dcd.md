# Bevezetés

A [math/rand][mathrand] csomag támogatást nyújt pszeudovéletlen számok generálásához.

Így generálhatsz egy véletlen egész számot `0` és `99` között:

```go
n := rand.Intn(100) // n is a random int, 0 <= n < 100
```

A `rand.Float64` függvény egy véletlen lebegőpontos számot ad vissza `0.0` és `1.0` között:

```go
f := rand.Float64() // f is a random float64, 0.0 <= f < 1.0
```

Arra is van lehetőség, hogy egy szeletet (vagy más adatszerkezetet) összekeverj:

```go
x := []string{"a", "b", "c", "d", "e"}
// shuffling the slice put its elements into a random order
rand.Shuffle(len(x), func(i, j int) {
	x[i], x[j] = x[j], x[i]
})
```

## Magok

A `math/rand` csomag által generált számsorozatok nem valódi véletlen számok.
Egy adott „mag” érték esetén az eredmény teljesen determinisztikus.

A Go 1.20-as és újabb verzióiban a magot automatikusan, véletlenszerűen választja ki, így a program minden futtatásakor más véletlenszám-sorozatot kapsz.

A Go korábbi verzióiban a mag alapértelmezés szerint `1` volt.
Ezért ahhoz, hogy a program egyes futtatásainál különböző sorozatokat kapj, a véletlenszám-generátor magját kézzel kellett beállítanod, például az aktuális idővel, mielőtt bármilyen véletlen számot lekérnél.

```go
rand.Seed(time.Now().UnixNano())
```

[mathrand]: https://pkg.go.dev/math/rand
