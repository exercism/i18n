# Utasítások

Ebben a feladatban naplósorokkal fogsz dolgozni.

Minden naplósor egy string, amelynek a formátuma a következő: `"[<LEVEL>]: <MESSAGE>"`.

Három különböző naplózási szint létezik:

- `INFO`
- `WARNING`
- `ERROR`

Három részfeladat vár rád, mindegyik kap egy naplósort, és valamit tenned kell vele.

## 1. Szerezd ki egy naplósor üzenetét

Valósítsd meg a (_statikus_) `LogLevels.message()` metódust, amely visszaadja a naplósor üzenetét:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Az elején és a végén lévő szóközöket el kell távolítani:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Szerezd ki egy naplósor naplózási szintjét

Valósítsd meg a (_statikus_) `LogLevels.logLevel()` metódust, amely visszaadja a naplósor naplózási szintjét, méghozzá kisbetűvel:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Formázd újra a naplósort

Valósítsd meg a (_statikus_) `LogLevels.reformat()` metódust, amely újraformázza a naplósort: az üzenet kerül előre, utána pedig zárójelben a naplózási szint követi:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
