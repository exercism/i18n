# A kurzusról

Az [F#](https://try.fsharp.org/) egy erősen típusos, funkcionális nyelv, amely a Microsoft .NET nyelvi stackjének a része.

Bár az F# remekül használható adatelemzési feladatokhoz, szinte minden problémát elegánsan meg tud oldani, amivel csak előhozakodsz.

Mivel az F# a .NET futtatókörnyezetben fut, hozzáférsz a teljes .NET ökoszisztémához, beleértve a [nuget.org](https://www.nuget.org/) összes csomagját is.

A meglévő .NET-kóddal való integrációt az is tovább egyszerűsíti, hogy az F#-ban akár objektumorientált kódot is írhatsz.

Az F# honlapja a [fsharp.org](http://fsharp.org/), és remek bevezetőt találsz az F#-hoz a [F# for fun and profit](http://fsharpforfunandprofit.com/) oldalon.
