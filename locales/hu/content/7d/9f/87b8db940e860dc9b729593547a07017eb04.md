# Általános

- API-dokumentáció: [package regexp][package-regexp]
- A reguláris kifejezések szintaxisa: [regexp/syntax][regexp-syntax]
- A [regex101.com][regex101] weboldalon van egy online reguláris kifejezés-tesztelő.
- Érdemes a reguláris kifejezéseket [raw string literálként][raw-string-literals] megírni, backtickek közé zárva.

## 1. Azonosítsd az összekeveredett naplósorokat

- Itt hasznos lehet a [regexp.MatchString][fun-re-match-string] függvény vagy a [MatchString][method-match-string] metódus.
- Egy reguláris kifejezésben a `^` karakter egy sor, illetve string elejére illeszkedik.

## 2. Bontsd fel a naplósort

- Itt hasznos lehet a [Split][regexp-split] metódus.

## 3. Számold meg, hány sor tartalmaz `password` szót idézőjelbe tett szövegben

- Ha a reguláris kifejezés elé `(?i)`-t teszel, az illesztés kis- és nagybetűre érzékennyé válik.
  Ezzel beállítod az `i` jelzőt.
  Nézd meg [ezt az útmutatót][yourbasic-i-flag].

## 4. Távolítsd el a napló maradványait

- Itt hasznos lehet a [ReplaceAllString][replace-all-string] metódus.

## 5. Címkézd fel a sorokat felhasználónevekkel

- Itt hasznos lehet a [FindStringSubmatch][find-string-submatch] metódus.
