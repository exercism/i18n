# Bevezetés

A kivételek a hibakezelés egyik formája.
Azért hívják őket kivételeknek, mert általában akkor jelennek meg, amikor valamilyen váratlan eseménnyel kerülünk szembe.

A kódunk bármely pontján „raise”-elhetünk egy kivételt.
Ezt a `raise` metódussal tesszük, átadva neki egy objektumot, általában egy Exception objektumot, bár egyszerű stringeket is használhatunk.
Például a feladatok vázaiban láthatod, hogy a beépített `RuntimeError`-t használjuk, hogy jelezzük a Rubynak, hogy egy metódus még nincs implementálva.
Használhatod a `raise(ExceptionObject, params)` rövidített szintaxisát is.
Ha elhagyjuk a kivételosztályt, a Ruby alapértelmezés szerint a `RuntimeError`-t használja.
Például:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Amikor a Ruby ezt látja, a hibát feljuttatja a program tetejéig, majd kilép.
Ha például megpróbálsz elosztani valamit nullával, valami ilyesmit fogsz látni:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
