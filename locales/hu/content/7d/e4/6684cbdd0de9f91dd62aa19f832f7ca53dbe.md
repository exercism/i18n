# Bevezetés

## Számok

A [kézikönyvből][man-types]

> A jq ugyanazokat az adattípusokat támogatja, mint a JSON: számok, stringek, Boolean értékek, tömbök, objektumok (amelyek a JSON szóhasználatában olyan hash-ek, amelyeknek csak string kulcsai vannak) és a „null”.

Most a **számokra** összpontosítsunk.

### Számok és numerikus operátorok

Minden szám, akár egész, akár nem, IEEE754 kétszeres pontosságú lebegőpontos szám.
Ez a pontosságot 53 bitre korlátozza.

A szokásos operátorok használhatók számokkal:

- aritmetika: `+`, `-`, `*`, `/`, `%`
- összehasonlítás: `==`, `!=`, `<`, `<=`, `>=`, `>`
- szabványos [matematikai függvények][man-math]

  Az egy bemenetet fogadó függvényeknél az értéket a függvénybe irányítjuk

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  A két bemenetet fogadó függvényeknél a függvények figyelmen kívül hagyják a
  bemenetet, és a bemeneteket paraméterként várják (emlékezz rá, hogy a
  paramétereket pontosvessző választja el)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  A függvényargumentumok elválasztója a pontosvessző, nem a vessző.

### További `jq` kifejezések

A feladat megoldásához ismerned kell a feltételes kifejezéseket.

#### Feltételes kifejezések

A `jq` egy [`if-then-else` kifejezést][if-then-else] használ a **feltételes kifejezésekhez**.
_Kifejezésként_ egy pipeline-ba kerül.

A szintaxis a következő: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

Az `else` ág elhagyható.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

További feltételekhez az `elif` kulcsszót használd

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
