# Kiegészítés az utasításokhoz

## A kert formátuma

A kertet egy nullával lezárt string képviseli, amelynek minden sorának végén egy újsor karakter áll.

Egy példa erre: `"   \n * \n   \n"`

## Regiszterek

| Regiszter | Használat     | Típus    | Leírás                              |
| --------- | ------------- | -------- | ----------------------------------- |
| `$a0`     | bemenet       | cím      | nullával lezárt bemeneti string     |
| `$a1`     | bemenet/kimenet | cím    | nullával lezárt kimeneti string     |
| `$t0-9`   | ideiglenes    | bármilyen | ideiglenes tárolásra                |
