# Részletek

A `[ ]`-ben leírt quotation a névtelen függvény vagy a kódblokk
megfelelője a Factorban. Első osztályú érték: a veremre tehetsz,
eltárolhatsz vagy továbbadhatsz, és csak akkor fut le, amikor
valami *meghívja*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

A quotation szavak sorozata, és a Factor mindenütt használja őket,
ahol egy viselkedést késleltetni vagy paraméterezni kell:

- az `if` / `when` / `unless` / `cond` ágai
- a `filter`, `count`, `any?`, `all?` predikátuma
- a `map`, `each`, `reduce` átalakítása
- a `times`, `while`, `loop` törzse

A quotation veremhatása általában kikövetkeztethető. Ha mégsem,
ami jellemzően akkor fordul elő, amikor eltárolod, és csak később
hívod meg `call`-lal, akkor add meg a hatást explicit módon:
`call( a b -- c )`.

## Quotationok kombinálása

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

A `compose` két quotationt fűz össze egymás után egyetlen új
quotationné, amely először az elsőt, majd a másodikat futtatja le.
A `curry` egy rögzített értéket fűz elé, és olyan quotationt ad
vissza, amely az eredeti meghívása előtt a veremre teszi ezt az
értéket. Mindkettő hétköznapi quotationt ad, amelyet `call`-lal
meghívhatsz, eltárolhatsz, vagy átadhatsz kombinátoroknak.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
