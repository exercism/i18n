# Bevezetés

Alapértelmezés szerint a változók arra a scope-ra korlátozódnak, amelyben definiáltad őket. Ha egy fájlban definiáltad őket egy függvényen vagy osztályon kívül, akkor a fájl scope-jára korlátozódnak. Ha egy függvényben vagy osztályban definiáltad őket, akkor a függvény vagy az osztály scope-jára korlátozódnak.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

A változókat ezenkívül kifejezetten `global` vagy `static` scope-pal is deklarálhatod.
