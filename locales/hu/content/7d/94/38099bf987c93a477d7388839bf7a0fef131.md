# Utasítások

Ebben a feladatban néhány metódust kell megvalósítanod, amelyek egy programozási nyelveket tartalmazó tömbbel dolgoznak.

## 1. Definiálj egy metódust, amely egy üres nyelvtömböt ad vissza

Definiáld a `LanguageList.list` metódust, amely nem vesz át argumentumot, és egy üres, `Array(String)` típusú tömböt ad vissza.

```crystal
LanguageList.list()
# => []
```

## 2. Definiálj egy metódust, amely hozzáad egy nyelvet a tömbhöz

Definiáld a `LanguageList.add` metódust, amely 2 argumentumot vesz át (egy _nyelvtömböt_ és egy _nyelv_ string literálját).
A metódusnak vissza kell adnia a tömböt úgy, hogy az új nyelv a tömb végére került.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. Definiálj egy metódust, amely eltávolít egy nyelvet a tömbből

Definiáld a `LanguageList.remove` metódust, amely 1 argumentumot vesz át (egy _nyelvtömböt_).
A metódusnak a tömböt az utolsó elem nélkül kell visszaadnia.
Feltételezzük, hogy a tömbben mindig van legalább egy elem.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. Definiálj egy metódust, amely visszaadja a tömb n-edik elemét

Definiáld a `LanguageList.at` függvényt, amely 2 argumentumot vesz át (egy _nyelvtömböt_ és egy indexet).
A metódusnak a tömbben az n-edik indexen lévő nyelvet kell visszaadnia.
Feltételezzük, hogy az adott indexen mindig lesz nyelv.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. Definiálj egy metódust, amely feldolgozza a nyelvek egy stringjét

Definiáld a `LanguageList.parse` metódust, amely 1 argumentumot vesz át (egy vesszővel elválasztott nyelvekből álló string literált).
A metódusnak egy nyelvekből álló tömböt kell visszaadnia.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
