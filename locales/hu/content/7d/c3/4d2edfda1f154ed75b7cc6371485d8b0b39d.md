# Utasítások

Fordítsd le az RNS-szekvenciákat fehérjékké.

Az RNS három nukleotidból álló szekvenciákra bontható, amelyeket kodonoknak nevezünk, majd ezek polipeptiddé fordíthatók le, például így:

RNS: `"AUGUUUUCU"` => ebből lesz

Kodonok: `"AUG", "UUU", "UCU"`
=> amelyekből egy polipeptid lesz a következő szekvenciával =>

Fehérje: `"Methionine", "Phenylalanine", "Serine"`

64 kodon létezik, amelyek 20 aminosavnak felelnek meg; ebben a feladatban azonban nem fontos az összes kodonszekvencia és a belőlük keletkező aminosav.
Ha egy kodonra működik, a programnak mindegyikre működnie kell.
Nyugodtan bővítheted azonban a tesztek listáját, hogy mindegyiket tartalmazza.

Három lezáró kodon is van (más néven „STOP” kodon); ha a riboszóma bármelyik ilyen kodonnal találkozik, minden fordítás véget ér, és a fehérje lezárul.

Az ezután következő kodonokat figyelmen kívül hagyja, például így:

RNS: `"AUGUUUUCUUAAAUG"` =>

Kodonok: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Fehérje: `"Methionine", "Phenylalanine", "Serine"`

Figyeld meg, hogy a stop kodon `"UAA"` lezárja a fordítást, és a végső metionin nem kerül be a fehérje szekvenciájába.

Az alábbiak a feladathoz szükséges kodonok és a belőlük keletkező aminosavak.

| Kodon              | Fehérje       |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Tudj meg többet a [fehérjetranszlációról a Wikipédián][protein-translation].
