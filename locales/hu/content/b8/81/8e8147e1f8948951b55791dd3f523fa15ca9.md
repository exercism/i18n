# Bevezetés

## Boolean értékek a Julia nyelvben

Az igaz vagy hamis értékeket a `Bool` típus képviseli.
Ez csak két értéket tartalmaz: `true` és `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Boolean operátorok

A Julia nyelvben három Boolean operátor van.

A `&&` a Boolean „és”.
Az értéke akkor `true`, ha a `&&` *mindkét* oldalán álló kifejezés `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

A `||` a Boolean „vagy”.
Az értéke akkor `true`, ha a `||` *valamelyik* oldalán álló kifejezés `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

A `!` a Boolean „nem”.
Ez felcseréli a `true` és `false` értékeket.

```julia-repl
julia> !true
false

julia> !false
true
```

Hosszabb és bonyolultabb kifejezéseknél érdemes zárójeleket használni, hogy egyértelmű legyen a szándékod.

```julia-repl
julia> (true || false) && (false && true)
false
```
