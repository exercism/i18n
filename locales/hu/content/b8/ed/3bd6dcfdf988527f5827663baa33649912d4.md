# Névjegy

Néha nincs szükséged az állapottal rendelkező objektum létrehozásával járó többletterhelésre.
Ilyen esetekben használhatsz egy `module`-t.

A `module` nagyon hasonlít egy osztályhoz (sőt, a `Module` a `Classes` szülője az objektumhierarchiában); a fő különbség az, hogy példánymetódusok helyett osztálymetódusokat használunk.
Az osztálymetódusok a `self.` előtaggal kezdődnek, és közvetlenül a modulon hívjuk meg őket.

Például:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
