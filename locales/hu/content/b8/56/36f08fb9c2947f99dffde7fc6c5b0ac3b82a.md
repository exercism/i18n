# Bevezetés

A C#, mint sok statikusan típusos nyelv, számos olyan típust kínál, amelyek egész számokat reprezentálnak, mindegyik saját értéktartománnyal. A skála alsó végén a `sbyte` típus minimumértéke -128, maximumértéke pedig 127. Mint minden egész szám típusnál, ezek az értékek `<type>.MinValue` és `<type>.MaxValue` formában érhetők el. A felső végén a `long` típus minimumértéke -9 223 372 036 854 775 808, maximumértéke pedig 9 223 372 036 854 775 807. Közöttük helyezkedik el a `short` és az `int` típus.

A tartományokat az határozza meg, hogy a rendszer mekkora tárolási szélességet oszt ki az adott típusnak. Például egy `byte` 8 bitet használ, egy `long` pedig 64 bitet.

A fenti típusok mindegyikéhez tartozik egy előjel nélküli megfelelő: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint` és `long`/`ulong`. Az értékek tartománya minden esetben 0-tól a negatív előjeles maximum kétszereséig plusz 1-ig terjed.

| Típus  | Szélesség | Minimum                    | Maximum                     |
| ------ | --------- | -------------------------- | --------------------------- |
| sbyte  | 8 bit     | -128                       | +127                        |
| short  | 16 bit    | -32_768                    | +32_767                     |
| int    | 32 bit    | -2_147_483_648             | +2_147_483_647              |
| long   | 64 bit    | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 bit     | 0                          | +255                        |
| ushort | 16 bit    | 0                          | +65_535                     |
| uint   | 32 bit    | 0                          | +4_294_967_295              |
| ulong  | 64 bit    | 0                          | +18_446_744_073_709_551_615 |

Az egyik típusú változó (vagy kifejezés) könnyen konvertálható egy másik típusúvá. Például egy értékadás során, ha a hozzárendelt érték típusa (bal oldal) garantálja, hogy az érték a fogadó típus (jobb oldal) értéktartományába esik, akkor elég egy egyszerű értékadás:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

Másrészt, ha a forrástípus értéktartománya nem részhalmaza a fogadó típus értéktartományának, akkor akkor is szükség van egy explicit típuskonverzióra, azaz a `()` műveletre, ha az adott érték a fogadó típus tartományán belül esik:

```csharp
short s = 42;
uint ui = (uint)s;
```

## Bitek közötti átalakítás

A `BitConverter` osztály kényelmes módot kínál arra, hogy az egész szám típusokat bájtok tömbjévé és vissza alakítsuk.
