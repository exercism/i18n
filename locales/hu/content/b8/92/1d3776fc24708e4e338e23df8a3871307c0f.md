# Bevezetés

## Igaz és hamis

Az igaz és hamis logikai állapotokat a Rubyban a `true` és a `false` jelöli.
Ezeket használhatod önálló literálként, de logikai vagy összehasonlító metódusok eredményeként is megjelenhetnek.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _Truthy_ és _falsey_

Amikor `if` elágazásokban vagy más logikai környezetben értékelsz ki objektumokat, minden objektum _truthy_ értékűnek számít, **kivéve** a `false`-t és a `nil`-t.

## Vezérlési folyam

A _truthy_ és _falsey_ kiértékelés a vezérlési folyamban hasznos.
Ahogy a procedurális nyelvekben, a Rubyban is van `if`...`else` szerkezet, de gyakoribb lehet, hogy az `if`-et „őrző” utasításként használod egy kifejezés kiértékelésének a módosítására.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

A Ruby azért kínálja az `unless`-t, hogy a kód jól olvasható legyen.
Például: a `eat_desert if not too_full` helyett írhatod azt is, hogy `eat_desert unless too_full`.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
