# Bevezetés a tömbökbe

Javában a tömbök segítségével ugyanabból a típusból tárolhatsz több értéket egyetlen adatszerkezetben.
Más adatszerkezetektől eltérően a tömb mérete a létrehozás után már nem változik.
A tömb elemeihez index segítségével férhetsz hozzá, és indexszel értéket is adhatsz nekik.
A Java tömbjei nullaalapú indexelést használnak: az első elem indexe 0, a másodiké 1, és így tovább.

Így néz ki a tömb inicializálásának szokásos szintaxisa:

```java
type[] variableName = new type[size];
```

A `type` a tömbben tárolt elemek típusa, ami lehet primitív típus (például `int`) vagy osztály (például `String`).

A `size` pedig az elemek száma, amit a tömb tárolni fog (ez később nem változtatható meg).
A tömb létrehozása után az elemek az alapértelmezett értékükre inicializálódnak (jellemzően `0`, `false` vagy `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

A tömböket egy rövidített jelöléssel is definiálhatod, amellyel egyszerre hozhatod létre a tömböt és állíthatod be az értékeit:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

Mivel a fordító most már meg tudja állapítani, hány eleme lesz a tömbnek, a hossz elhagyható.

A tömb elemeihez szögletes zárójeles indexjelöléssel férhetsz hozzá, és ugyanígy adhatsz nekik értéket:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

Ha olyan indexre hivatkozol, amely kívül esik a tömb érvényes indexein, `IndexOutOfBoundsException`-t kapsz.

A tömböket kezelheted egy tömbpéldány metódusainak vagy tulajdonságainak meghívásával, illetve az `Arrays` osztályban definiált statikus metódusokkal is (ezeket jellemzően csak generikus kódban használjuk).
A `length` tulajdonság a tömb hosszát tárolja.
Így érheted el:

```java
int arrayLength = someArray.length;
```

A Java emellett egy hasznos segédosztályt is kínál: a [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) rengeteg hasznos, tömbökkel kapcsolatos metódust tartalmaz (például `Arrays.equals`).

A Java a [többdimenziós tömböket](https://www.programiz.com/java-programming/multidimensional-array) is támogatja, például az `int[][] arr = new int[3][4];` létrehozását, ami nagyon hasznos lehet.

Mivel a tömb egyben _gyűjtemény_ is, az értékek index szerinti elérésén kívül egy `for-each` ciklussal az _összes_ értékén végigmehetsz:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

Ha nagyobb kontrollt szeretnél afölött, hogy mely értékeken iterálj, `for` ciklust használhatsz:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
