# Áttekintés

A [tartományok][range] két érték közötti intervallumot jelölnek.
A tartományokat gyakran használjuk olyan típusokkal együtt, mint az `Int`, a `String` és a `Character`, hogy sorozatokon iteráljunk, gyűjteményeket szeleteljünk, vagy ellenőrizzük, hogy egy érték a határokon belül van-e.

A Swift két fő tartományoperátort kínál:

- **Zárt tartományoperátor (`...`)**: a kezdő- és a végértéket is tartalmazza (`1...5` az 1, 2, 3, 4 és 5 értékeket tartalmazza).
- **Félig nyílt tartományoperátor (`..<`)**: a kezdőértéket tartalmazza, a végértéket viszont nem (`1..<5` az 1, 2, 3 és 4 értékeket tartalmazza).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Ha egy metódust közvetlenül egy tartományliterálon hívsz meg, tedd zárójelbe a tartománykifejezést, hogy a fordító először a tartományt értékelje ki:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Tartomány átalakítása tömbbé

Egy számtartományt az `Array(_:)` kezdőértékkel alakíthatsz `Array` típusú tömbbé:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Tömb szeletelése tartományokkal

A tartományokkal egy tömb részleteit szeletelheted:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## A tartomány tulajdonságai és metódusai

A tartományok gyakori műveletei közé tartoznak a következők:

| Tag                        | Leírás                                                       | Példa                                  |
| -------------------------- | ------------------------------------------------------------ | -------------------------------------- |
| `count`                    | Visszaadja a tartomány elemeinek számát                      | `(1...5).count` a `5` értéket adja vissza |
| [`contains(_:)`][contains] | `true`-t ad vissza, ha a tartomány tartalmazza a megadott értéket | `(1...5).contains(3)` a `true` értéket adja vissza |

## Egyoldali tartományok

A Swift ezen kívül támogatja az egyoldali (részleges) tartományokat is, amelyeknél a kezdő- vagy a végértéket elhagyod:

- `array[2...]`: a 2-es indextől a gyűjtemény végéig.
- `array[...2]`: a gyűjtemény elejétől a 2-es indexig, azt is beleértve.
- `array[..<2]`: a gyűjtemény elejétől a 2-es indexig, de azt már nem beleértve.

## String- és karaktertartományok

Tartományt olyan karakterek vagy stringek között is létrehozhatsz, amelyek megfelelnek a `Comparable` protokollnak:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
