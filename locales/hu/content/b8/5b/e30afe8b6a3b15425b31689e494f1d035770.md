# Tartományok

A [tartományok][range] két érték közötti intervallumot jelölnek.
A leggyakrabban használt, tartományokat támogató típusok az `Int`, a `Char` és a `String`.
Sok mindenre használhatók, például gyűjtemények gyors létrehozására, stringek szeletelésére, annak ellenőrzésére, hogy egy érték benne van-e egy tartományban, és iterációra.
A `..` vagy a `...` tartományoperátorral hozhatók létre (előbbi zárt, utóbbi nyílt).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Azért van két tartományoperátor, hogy olyan tartományokat hozhass létre, amelyek tartalmazzák vagy nem tartalmazzák a végértéket. Ez hasznos lehet például akkor, ha nullától kezdődő indexekkel dolgozol.

A tartományokat a `Range` kezdőértékével is létrehozhatod.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Amikor Crystalkan a `..` vagy a `...` tartományoperátorral hozol létre egy tartományt, és metódust szeretnél meghívni rajta, zárójelbe kell tenned a tartományt.
Ellenkező esetben ugyanis a metódus a tartományoperátor második argumentumán hívódna meg.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Részstringek kinyerése

Ha egy stringet szeretnél szeletelni, a tartományoperátorral részstringet kaphatsz.
Ehhez olyan tartományt hozz létre, amely a részstring kezdő- és záróindexét adja meg.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Negatív indexekkel a string végétől is kinyerheted a részstringet.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## A tartományok metódusai

A tartományoknak van egy sor metódusa, amelyekkel dolgozhatsz rajtuk.
Ezekkel például megkaphatod a tartomány összes értékének összegét, vagy ellenőrizheted, hogy a tartomány tartalmaz-e egy értéket.

| Method                  | Description                                                             | Example                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | A tartomány összes értékének összegét adja vissza                       | `(1..5).sum # => 15`            |
| [`size`][size]          | A tartomány méretét adja vissza                                         | `(1..5).size # => 5`            |
| [`includes?`][indludes] | `true`-t ad vissza, ha a tartomány tartalmazza a megadott értéket, egyébként `false`-t | `(1..5).includes?(3) # => true` |

## Végtelen és kezdet nélküli tartományok

Egy tartomány lehet végtelen és kezdet nélküli.
A végtelen vagy kezdet nélküli tartománynál a kezdő- vagy a végérték `nil`, de a `nil` el is hagyható a tartomány megadásakor.

A kezdet nélküli és végtelen tartományok akkor hasznosak, ha például egy stringet az elejétől vagy a végéig szeretnél szeletelni.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Ha nem gyűjteményen használod, a végtelen tartomány végtelen sorozatot eredményezhet, ha nem bánsz vele óvatosan.
~~~~

## `Char` típusú tartományok

A `Char` értékek is használhatók tartományokban, így két karakter közötti karakterintervallumot kapsz.
Ez például akkor hasznos, ha az ábécét szeretnéd megkapni.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Stringtartományok

A stringek is használhatók tartományokban, így két string közötti stringintervallumot kaphatsz.
A viselkedésük azonban némileg eltér a `Char`-tól, ha több karaktert használsz egy stringtartományban.
Bonyolultabb stringtartományoknál a viselkedés zavaróvá válhat, ezért légy óvatos.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
