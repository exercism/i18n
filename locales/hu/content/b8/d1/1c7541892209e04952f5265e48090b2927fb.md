# Kiegészítés az utasításokhoz

## Tippek

Az Sgf modulnak a következő szignatúrájú parseSgf modult kell exportálnia:

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

Hasznos lehet, ha lemásolod az SgfTree és az SgfNode alábbi definícióit:

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```

A parsec könyvtár a Haskell Platform része. Használd ki az előnyeit.
