# Bevezetés

A Factor a dátumokat és az időpontokat a [`calendar`][calendar] szótárral modellezi. Egy időpont egy `timestamp`, egy időtartam pedig egy `duration`.

## Dátum létrehozása

A `<date>` (a [`calendar`][calendar] szótárban) egy `timestamp`-et hoz létre a megadott nap éjfélkor:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

A `>date<` visszabontja a `timestamp`-et az alkotóelemeire:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## Dátum vizsgálata

A `day-of-week` egész számként adja vissza a hét napját, ahol a `0` a vasárnap, a `6` pedig a szombat. A `day-names` (a [`calendar.english`][english] szótárban) a hozzájuk tartozó nevek listája, így a `day-names nth` szóvá alakítja a számot:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

A `leap-year?` egy évet (vagy egy `timestamp`-et) fogad el, a `days-in-month` pedig visszaadja egy `timestamp` hónapjának hosszát, már a szökőéveket is figyelembe véve:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## Dátumaritmetika

Az olyan szavak, mint a `days`, a `weeks` és a `hours`, egy `duration`-t hoznak létre, a `time+` pedig eltol egy `timestamp`-et ennyivel:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

A műveletek helyesen viszik át az értékeket a hónap- és évhatárokon, és két `timestamp`, amely ugyanazt a pillanatot jelöli, `=`-lel összehasonlítva egyenlőnek adódik.

## A napon belüli időpontok

A `<timestamp>` egy teljes `timestamp`-et hoz létre, egészen a másodpercig. Az utolsó argumentuma az UTC-től való eltolás; az `instant` (egy nulla hosszúságú `duration`) az UTC-n tartja a `timestamp`-et:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

A `>time<` a `>date<` párja: órára, percre és másodpercre bontja a `timestamp`-et:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

A `seconds` és a `minutes` ugyanúgy `duration`-t hoz létre, mint a `days`, a `weeks` és a `hours`, így bármelyik átadható a `time+`-nak:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

Egy `timestamp` egyes mezőit a `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` és `second>>` hozzáférőkkel olvashatod ki:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
