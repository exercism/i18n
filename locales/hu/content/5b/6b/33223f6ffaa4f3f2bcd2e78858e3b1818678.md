# Bevezetés

A PowerShell a Microsoft dinamikus és implicit módon típusos (de az erősen típusos változókat is támogató) szkriptnyelve, amely elsősorban feladatautomatizálásra és konfigurációkezelésre összpontosít.

A PowerShell támogatja az imperatív, a funkcionális, az objektumorientált és akár a pipeline stílusú programozást is.

A PowerShell a .NET platformra épült, és először 2006-ban jelent meg.
Minden modern Windows operációs rendszerben alapértelmezés szerint megtalálható, valamint Macre és Linuxra is telepíthető.


## Változók

A PowerShellben két gyakori módja van a változók definiálásának.

A PowerShellben a változóneveknek `$` jellel kell kezdődniük, és az értékadó operátort (`=`) kell használniuk ahhoz, hogy a változónevet egy értékhez rendeljék.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

A változó típusát explicit módon is megadhatod, ha ki akarod kényszeríteni vagy meg akarod követelni, hogy az érték egy bizonyos típusú legyen.
A PowerShell minden tőle telhetőt megtesz, hogy az értéket egyik típusból a másikba alakítsa, ha lehetséges.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Konstansok

A konstansok a PowerShellben olyan változók, amelyeket a definiálásuk után **nem lehet megváltoztatni**, és **nem lehet eltávolítani**.
Ez elvezet minket a változók definiálásának második módjához: a `New-Variable` parancsmag használatához.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

A változók létrehozásának részletesebb és haladóbb módjairól olvasd el a [New-Variable][New-Variable] oldalt.


## Függvények

A PowerShellben a [függvények][functions] a `function` kulcsszóval definiálhatók.
Minden függvénynek lehet nulla vagy több formális paramétere a `()` zárójelben, ezt követi a függvény scope, amely `{` jellel kezdődik és `}` jellel végződik.

```powershell
function Greeting {
    return "Hello!"
}
```

A PowerShell függvényei a `return` kulcsszóval explicit módon adhatnak vissza értékeket, miután a `FuncName $Arg` szintaxissal meghívták őket.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

A részletes függvénydefiníció megírásának és a függvények implicit értékvisszaadásának haladóbb áttekintését a `Functions` fogalommodulban tárgyaljuk.


## Megjegyzések

Az egysoros megjegyzések a PowerShellben `#` jellel kezdődnek, és a sor végéig tartanak.
A megjegyzésblokkok a PowerShellben `<#` jellel kezdődnek és `#>` jellel végződnek.
A megjegyzésblokkok haladóbb bemutatása, amellyel megjegyzésalapú súgót hozhatsz létre, a `Functions` fogalommodulban lesz.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
