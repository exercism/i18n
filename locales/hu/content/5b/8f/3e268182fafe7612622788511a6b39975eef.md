# Utasítások

Ebben a feladatban egy ablakkezelésen alapuló számítógépes rendszert fogsz szimulálni.
Létrehozol majd néhány ablakot, amelyek mozgathatók és átméretezhetők.
A következő ábra szemlélteti azokat az értékeket, amelyekkel az alábbiakban dolgozni fogsz.

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. A programablak tulajdonságainak meghatározása

A megadott osztályváz felhasználásával hozd létre a `y`, `x`, `height` és `width` értékekhez tartozó tulajdonságokat.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. A programablak kezdőértékeinek meghatározása

Definiálj egy konstruktorfüggvényt a `ProgramWindow` osztályhoz.
Nem szabad argumentumot fogadnia, de a konstruktor futása során állítsd be a tulajdonságai alapértelmezett értékeit.
A kezdeti `y` és `x` értékét állítsd `0`-ra.
A kezdeti `height` és `width` értékét pedig egy `600x800`-as képernyőméretre.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. Függvény definiálása az ablak átméretezéséhez

Definiálj egy új Size osztályt a `Size.php` fájlban.
A konstruktorának argumentumként kell megkapnia a `height` és `width` tulajdonságok értékét.
Ezenkívül a `ProgramWindow`-nak szüksége van egy átméretező függvényre, amely megkapja a `Size` objektum példányát, és frissíti a saját tulajdonságait.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. Függvény definiálása az ablak mozgatásához

Definiálj egy új Position osztályt a `Position.php` fájlban.
A konstruktorának argumentumként kell megkapnia a `y` és `x` tulajdonságok értékét.
Ezenkívül a `ProgramWindow`-nak szüksége van egy mozgató függvényre, amely megkapja a `Position` objektum példányát, és frissíti a saját tulajdonságait.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
