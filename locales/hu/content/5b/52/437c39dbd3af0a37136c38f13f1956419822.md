# Utasítások

Ebben a feladatban kódot írsz majd, ami segít elkészíteni egy remek lasagnét a kedvenc szakácskönyvedből.

Négy részfeladatot kapsz, amelyek mind a lasagna elkészítésével töltött időhöz kapcsolódnak.

~~~~exercism/note
Használhatsz típuskövetkeztetést, amikor nem adsz meg semmilyen típust, vagy explicit típusmegadást, amikor megadod a típusokat.
Ha az utóbbit választod, típusként az `int`-et használd.
~~~~

## 1. Határozd meg a várható sütési időt percekben

Definiáld az `expectedMinutesInOven` kötést, amivel ellenőrizheted, hány percig kell a lasagnának a sütőben lennie. A szakácskönyv szerint a várható sütési idő 40 perc:

```fsharp
expectedMinutesInOven
// => 40
```

## 2. Számold ki a hátralévő sütési időt percekben

Definiáld a `remainingMinutesInOven` függvényt, amely paraméterként megkapja, hogy a lasagna hány perce van már a sütőben, és visszaadja, hány percet kell még a sütőben töltenie, az előző részfeladatban megadott várható sütési idő alapján.

```fsharp
remainingMinutesInOven 30
// => 10
```

## 3. Számold ki az előkészítési időt percekben

Definiáld a `preparationTimeInMinutes` függvényt, amely paraméterként megkapja a lasagnéba tett rétegek számát, és visszaadja, hány percet töltöttél a lasagna előkészítésével, feltéve, hogy egy réteg elkészítése 2 percet vesz igénybe.

```fsharp
preparationTimeInMinutes 2
// => 4
```

## 4. Számold ki az eltelt időt percekben

Definiáld az `elapsedTimeInMinutes` függvényt, amely két paramétert kap: az első paraméter a lasagnéba tett rétegek száma, a második paraméter pedig az, hogy hány perce van a lasagna a sütőben. A függvény adja vissza, hány percet dolgoztál a lasagna elkészítésén, ami az előkészítési idő és a lasagna által a sütőben eddig eltöltött idő összege.

```fsharp
elapsedTimeInMinutes 3 20
// => 26
```
