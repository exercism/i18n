# Bevezetés

## Konstansok és függvények

Egy konstans értéket `name = expression` formában definiálunk,
ahol is az Elmben a definíciókon kívül minden kifejezés.

```elm
five = 5

six = 3 + 3
```

A függvényeket `name parameters... = expression` formában definiáljuk,
a paramétereket pedig csak szóközzel választjuk el egymástól.

```elm
add number1 number2 = number1 + number2
```

Egy függvény meghívása szintén kifejezés, és úgy történik, hogy
leírjuk a nevét, majd a függvény minden paraméteréhez átadunk egy-egy argumentumot,
szóközzel elválasztva, akárcsak a függvény definiálásakor.

```elm
five = add 2 3
```

Zárójelekkel megadhatod egy kifejezés kiértékelési sorrendjét.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Behúzás / jelentéssel bíró szóközök

Az Elm nem használ szintaktikai jelölőket, például kapcsos zárójeleket, kerek zárójeleket vagy pontosvesszőket a kódrészek határainak kijelölésére. Helyettük szóközöket és behúzásokat használ.

- A modul-, az import- és a legfelső szintű függvénydefinícióknak a bal szélső oszlopban kell kezdődniük.
- Ha egy kifejezés több sorra tagolódik, a kifejezéshez tartozó kódot legalább egy szóközzel be kell húzni a kifejezés alá.
- A kifejezés azon részeit, amelyek összetartoznak, ugyanannyi szóközzel érdemes behúzni.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Modulok

Az Elmben minden fájl egy modul, és minden más kód előtt szerepelnie kell benne egy `module` utasításnak.
A modulneveknek meg kell egyezniük a fájlnevükkel, így a `Calculator` modulnak a Calculator.elm fájlban kell lennie.
Minden, ami egy modulon belül definiálva van, privát hatókörrel rendelkezik a modulra nézve,
és a modulon kívülről nem érhető el, kivéve, ha szerepel az `exposing` listában.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Megjegyzések

A megjegyzés olyan szöveg az Elm-fájlban, amelyet nem kódként értelmezünk.
Elsősorban arra való, hogy te magad és más programozók elolvassátok.
Az egysoros megjegyzésekhez van egy egyszerű szintaxis, amely a dupla kötőjelen alapul.
A többsoros megjegyzések is lehetségesek a `{-` és `-}` nyitó és záró
jelölőpárral.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```

## Formázás

és az [elm-format](https://github.com/avh4/elm-format) segítségével automatikusan formázhatod a kódot.
