# Bevezetés

A Factor *konkatenatív* nyelv: minden szó a bemeneteit egy közös **adatveremből** olvassa be, a kimeneteit pedig oda teszi vissza. Nincs más mód az értékek átadására.

Ha leírsz egy literált, az a verem tetejére kerül; a kódot balról jobbra olvassuk:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

A *veremhatás*-deklaráció egy szó szerződését dokumentálja:

```factor
: restow ( a b -- b a ) swap ;
```

A `( a b -- b a )` azt jelenti, hogy a szó két értéket levesz a veremről, és kettőt hagy maga után fordított sorrendben. A nevek csupán dokumentációt jelentenek: a fordító csak a bemenetek és a kimenetek *számát* ellenőrzi. A verem teteje pedig a jobb oldali név.

A `kernel` hétköznapi **shuffle szavai** átrendezik a verem tetejét:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

A szavakat `:`-tal definiálod, és `;`-vel zárulnak; a fordító nem fogad el olyan definíciót, amelynek a törzse nem egyezik a deklarált veremhatással.
