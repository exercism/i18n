# Bevezetés

A hibákról érdemes beszámolni, ha egy programban vagy egy kódrészletben valami nem stimmel vagy váratlanul történik.

A hibák JavaScript-objektumok.

Az objektum fő tulajdonsága a `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

A `throw` szintaxissal Error-t dobhatsz.

```javascript
throw new Error('Oops');
```

Amikor egy `Error`-t dobnak, a jelenlegi végrehajtás leáll, és a hívási verem első catch blokkjában folytatódik.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

Ahogy a JavaScript bármelyik osztályánál, az alosztályok is örökölhetnek az `Error`-ból, hogy az `extends` kulcsszóval egyedi hibákat hozzanak létre.
Az `instanceof` szintaxissal ellenőrizheted, hogy az elkapott hiba az `Error` egy adott alosztályának a példánya-e.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
