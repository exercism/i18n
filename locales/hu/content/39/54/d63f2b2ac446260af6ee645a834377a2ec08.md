# Névjegy

A PHP-ben számos beépített ciklusvezérlő szerkezet van, például a `while`. A `while` utasítás alapvető formája a következő:

```php
while (expr) {
  // statements
}
```

Amíg a kifejezés (_expr_) _igaz_ értéket ad, a ciklus ismételten végrehajtja a benne lévő utasításokat. Ha a kifejezés (_expr_) már az első iteráció előtt hamis értéket ad, akkor az utasítások soha nem futnak le.

Használhatsz `do-while` ciklust is, amely a kifejezés (_expr_) kiértékelése előtt egyszer már lefuttatja a ciklus utasításait.

```php
do {
  // statements
} while (expr);
```
