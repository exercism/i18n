# Bevezetés

A hash-táblák a Common Lispben olyan adatszerkezetek, amelyek asszociatív adatok tárolására szolgálnak.
Kulcsokat (amelyek bármilyen objektumok lehetnek) rendelnek értékekhez (amelyek szintén bármilyen objektumok lehetnek).
Más nyelvekben ugyanezt a fogalmat map, szótár vagy hash néven találod meg.

## Hash-táblák létrehozása

Hash-táblát a `make-hash-table` függvénnyel hozhatsz létre.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(A hash-tábla nyomtatott megjelenése implementációfüggő, ezért a REPL-edben másképp is kinézhet.)

## Értékek kiolvasása kulcsok alapján

Ha egy kulcshoz tartozó értéket szeretnél kiolvasni a hash-táblából, a `gethash` függvényt használod:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

A `gethash` [több értéket][concept-multiple-values] ad vissza, amelyeket egy másik fogalomnál magyarázunk el.

## Értékek beszúrása

Érték hash-táblába szúrásához a `setf`-et használod a `gethash`-sel együtt, így:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Ez a `*hash-table*` hash-táblában a `:foo` kulcshoz tartozó értéket `:bar`-ra módosítja.
Az értéket adja vissza.

A `setf` használatáról egy másik fogalomnál lesz szó.
