# Utasítások

Határozd meg az első N természetes szám összegének négyzete, valamint az első N természetes szám négyzetösszege közötti különbséget.

Az első tíz természetes szám összegének négyzete
(1 + 2 + ... + 10)² = 55² = 3025.

Az első tíz természetes szám négyzetösszege
1² + 2² + ... + 10² = 385.

Így az első tíz természetes szám összegének négyzete és négyzetösszege közötti különbség 3025 - 385 = 2640.

Nem várjuk el tőled, hogy első elvekből kiindulva magadtól hatékony megoldást találj a feladatra; a kutatás megengedett, sőt kifejezetten ajánlott.
A feladathoz tartozó legjobb algoritmus megtalálása a szoftverfejlesztés egyik kulcsfontosságú készsége.
