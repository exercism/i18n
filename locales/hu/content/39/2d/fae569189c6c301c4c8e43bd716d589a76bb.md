# Utasítások

A barátodnak van egy **Gross Store** nevű régi nagykereskedése.

A név onnan ered, hogy a bolt mindent [nagytucatban][gross-unit] árul.

A barátod megkért, hogy készíts a boltja számára egy értékesítési pont (POS) rendszert.

**Először is egy prototípust szeretnél építeni hozzá.**

**A prototípusodban a rendszer csak a mennyiséget rögzíti majd.**

A barátod adott egy listát a mértékegységekről, hogy segítsen:

| Mértékegység       | Érték |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Tárold a mértékegységet a programodban

Ahhoz, hogy használni tudd a mértékegységet, el kell tárolnod azt a programodban.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Hozz létre egy új vásárlói számlát

Ehhez egy olyan függvényt kell implementálnod, amely új (üres) számlát hoz létre a vásárlónak.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Adj hozzá egy tételt a vásárló számlájához

Ehhez a következőket kell tenned:

- Add vissza a `false` értéket, ha a megadott `unit` nincs benne a `units` szótárban.
- Egyébként add hozzá a tételt a vásárló `bill` számlájához a tétel nevével indexelve, majd add vissza a `true` értéket.
- Ha a tétel már szerepel a számlán, növeld a mennyiségét a megadott `unit`-hoz tartozó értékkel.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> A visszaadott érték típusa `bool`.

## 4. Távolíts el egy tételt a vásárló számlájáról

Ehhez a következőket kell tenned:

- Add vissza a `false` értéket, ha a megadott tétel **nincs** a számlán.
Egy tétel akkor számít nem lévőnek a számlán, ha a mennyisége 0.
- Add vissza a `false` értéket, ha a megadott `unit` nincs benne a `units` szótárban.
- Add vissza a `false` értéket, ha az új mennyiség 0-nál kisebb lenne.
- Ha az új mennyiség 0, a tétel eltávolítottnak számít a `bill` számláról, így visszaadhatod a `true` értéket.
- Egyébként csökkentsd a tétel mennyiségét, és add vissza a `true` értéket.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> A visszaadott érték típusa `bool`.

## 5. Add vissza egy adott, a vásárló számláján szereplő tétel mennyiségét

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> A visszaadott érték típusa `u32`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
