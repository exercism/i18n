# Bevezetés

Az R-ben a `list` elemek rendezett gyűjteménye, amely néhány szempontból eltér a `vectors`-tól:

- Az elemek különböző típusúak lehetnek (pl. `numeric` keverése `character`-rel).
- Az elemek összetett struktúrák lehetnek (pl. vektorok, más listák stb.).
- Az elemek eléréséhez némileg más szintaxist használunk.

A más nyelvekkel való párhuzamok pontatlanok.
Az R-beli `list` némileg hasonlít a Python szótárához, de a `list` rendezett, és numerikus indexszel érhető el.
Némileg hasonlít a C `struct`-hoz, azzal a különbséggel, hogy a `list` futásidőben könnyen bővíthető.

## Listák létrehozása

Az elemek megnevezése (amit gyakran „címkéknek” neveznek) gyakoribb a listáknál, mint a vektoroknál:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

A címkék azonban opcionálisak, és ilyenkor az R egyszerűen indexszámokat használ:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Listaelemek elérése

Háromféleképpen tehetjük ezt meg, mindegyik más helyzetben hasznos.

### 1. `$tag` jelöléssel

Nagyon gyakori, ha a címkenevek előre ismertek.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. `[[tag]]` jelöléssel

Ennek az az előnye, hogy a címkenév futásidőben választható.
Figyeld meg a dupla zárójeleket.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Pozícióindexszel

Ez akkor is működik, ha a listának vannak címkéi, és akkor is, ha nincsenek.
Itt is dupla zárójeleket használunk.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Elemek hozzáadása és törlése

Egyszerű: ha egy elemhez értéket rendelünk, az módosítja, ha létezik, vagy beszúrja, ha új.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Törléshez rendelj `NULL`-t a nem kívánt elemhez.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
