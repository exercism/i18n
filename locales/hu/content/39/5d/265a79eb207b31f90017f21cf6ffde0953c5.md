# Bevezetés

A Gleam listája nulla vagy több értékből álló, változtathatatlan gyűjtemény. A listában szereplő értékeknek mind ugyanolyan típusúnak kell lenniük. Mivel a listák változtathatatlanok, egy lista létrehozása után az értéke soha nem változhat. Minden függvény és operátor, amely úgy tűnik, hogy módosítja a listát (például elemet ad hozzá), valójában egy új listát ad vissza.

A listákat így definiálhatod:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

A leggyakoribb módja, hogy hozzáadj egy elemet a listához, a spread szintaxis:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

A Gleam standard könyvtárában található [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) modul rengeteg hasznos függvényt tartalmaz a listákkal való munkához. Ezt a modult nagyon gyakran használják Gleam-kódban, ezért jó, ha jól ismered.

A case kifejezésekben listamintákkal illeszkedhetsz a listákra, és a bennük lévő értékeket változókhoz rendelheted:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

A pontos hosszúságú listákra való illeszkedés mellett a spread szintaxissal legalább egy bizonyos hosszúságú listákra is illeszkedhetsz:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

A spread szintaxissal a lista maradékát is hozzárendelheted egy változóhoz:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

A case kifejezésekben a beillesztett típus minden lehetséges értékéhez tartoznia kell mintának, ezért a maradék értékek kezelésére gyakran egy záró, mindent eldobó minta (`_`) szolgál.
