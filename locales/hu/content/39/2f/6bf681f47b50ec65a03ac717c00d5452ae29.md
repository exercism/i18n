# Bevezetés

## Alias

Ahhoz, hogy egy projekten belül kódot ossz meg különböző Elixir-modulok között, a külső modulra a teljes nevével kell hivatkoznod. De mi van, ha ez a név túl hosszú vagy zavaró?

Az `alias` speciális forma lehetővé teszi, hogy lerövidítsd vagy megváltoztasd azt a nevet, amellyel egy külső modulra hivatkozol. Ha argumentumok nélkül használod, a modulnevet az utolsó szegmensére rövidíti, például a `MyApp.Logger.Settings` névből `Settings` lesz. Egyéni nevet a `:as` opcióval adhatsz meg.

Az aliasokat általában a moduldefiníció elején adod hozzá.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

Az `import` speciális forma lehetővé teszi, hogy egy külső modul függvényeit a modul nevének említése nélkül használd.

Egy teljes külső modul importálása ütközéseket okozhat a meglévő helyi függvényekkel. Ennek elkerülésére két opció áll rendelkezésre: az `:except` és az `:only`. Mindkettő egy kulcsszólistát vár, amelyben a kulcs a függvény neve, az érték pedig a függvény aritása.

Az importokat általában a moduldefiníció elején adod hozzá.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
