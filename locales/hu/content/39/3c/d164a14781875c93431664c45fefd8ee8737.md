# Tuple-ok

Az Elmben a tuple-ok két vagy három értéket tárolhatnak, és mindegyik érték bármilyen típusú lehet.
Az Elmben a tuple-okat leginkább egyszerű, átmeneti típusokra használjuk.
Ezért a tuple-ok legfeljebb 3 értéket tárolhatnak, és hogy ez még inkább ösztönözzön, kényelmi függvényeket csak 2 értékhez kapunk.
Bonyolultabb adatokhoz a legjobb, ha rekordokra váltunk.
Gyakori felhasználás, ha egy függvényből egynél több értéket kell visszaadnod.
A tuple-ok mezőinek nincs nevük, csak destrukturálással vagy pozíció alapján érhetők el.

Elolvashatsz egy [rövid bevezetést a tuple-okba][tuples-concise].
Van egy [részletesebb bevezetés][tuples-in-depth] is, a [Tuple modul API-dokumentációja][tuple-core] pedig kódpéldákat és részletes leírást tartalmaz.

## Deklaráció

A tuple-okhoz tartozó típusokat zárójelekkel hozzuk létre, és az elemtípusaikat vessző választja el.

```elm
type alias IntStringTuple = (Int, String)
```

### Létrehozás

A tuple-okat zárójelekkel hozzuk létre, és az elemeiket vessző választja el.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

A `Tuple.pair` segítségével is létrehozhatsz egy két értéket tartalmazó tuple-t.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### Elérés

Vannak függvények a tuple-ok értékeinek pozíció szerinti elérésére is: a `Tuple.first` és a `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

A tuple-ok _destrukturálhatók_ kötésekben, tuple-mintaillesztéssel.
A destrukturálás elvégezhető let-kifejezésekben, függvénydeklarációkban és case-utasításokban.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

A case-utasításban a mintaillesztés lehetővé teszi az értékek tartalmára való illesztést is:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
