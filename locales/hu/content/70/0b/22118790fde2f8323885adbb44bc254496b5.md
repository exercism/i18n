# Bevezetés

## Az `if` kifejezés

A `jq`-ban a **feltételes kifejezés** így néz ki: `if A then B else C end`.

Az `if-then-else` a `jq` többi beépítettjéhez hasonlóan egy szűrő: bemenetet kap, és kimenetet állít elő.

Ha az `A` kifejezés „igaz” értéket ad, akkor az `if` szűrő kiértékeli `B`-t.
Ellenkező esetben `C`-t értékeli ki.
Az `if` szűrő bemenetét a `B` vagy a `C` kapja meg.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
Az `else` ág **elhagyható**; a következő két utasítás ugyanazt jelenti.

```jq
if A then B else . end
if A then B end
```
~~~~

## Egymásba ágyazott elágazások

További feltételeket az `elif` segítségével adhatsz hozzá.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Annyi `elif` ágat használhatsz, amennyire szükséged van.

## Mi számít igaznak?

A `jq`-ban csak két „hamis” érték létezik: a `false` és a `null`.
Minden más „igaz”, még a nulla, valamint az üres string, az üres tömb és az üres objektum is.

## Boolean-operátorok

A **Boolean-operátorokkal** (`and` és `or`) összetett lekérdezéseket építhetsz.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Tagadáshoz használd a `not`-ot. Ez egy **szűrő**, nem operátor.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## Alternatív operátor

Az **alternatív operátor** segítségével „alapértelmezett” értéket adhatsz meg arra az esetre, ha egy kifejezés hamis vagy null.

```jq
A // B

# This is identical to
if A then A else B end
```

Szemléltetésképpen:

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
