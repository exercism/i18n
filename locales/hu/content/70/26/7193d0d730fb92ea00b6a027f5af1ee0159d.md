# Bevezetés

A _nyelvet_ **AWK**-nak, az AWK-programokat értelmező _futtatható programot_ pedig **`awk`** vagy **`gawk`** néven említjük.

## Minták és műveletek

Az AWK-program **minta-művelet párokból** áll:

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

A **minta** lehet reguláris kifejezés, amely a bemenetre illeszkedik.
Az is lehet bármilyen kifejezés, amely igaz/hamis értéket ad.

A **művelet** egy vagy több AWK-parancs.
A hozzá tartozó kapcsos zárójelek kötelezőek.

Ha a minta eredménye _igaz_, akkor a hozzá tartozó művelet kiértékelődik.

## Rekordok és mezők

Az AWK a bemenetet **rekordok** sorozataként dolgozza fel.
Minden rekord nulla vagy több **mezőre** bomlik.

Az alapértelmezett viselkedés:

- a bemenetet rekordokra bontja úgy, hogy az újsort tekinti „rekordelválasztónak”, így minden _sor_ egy rekord.
- a rekordot mezőkre bontja úgy, hogy a whitespace-t tekinti „mezőelválasztónak”, így minden _szó_ egy mező.

## Minták és műveletek, folytatás

A minta elhagyható, ilyenkor a művelet _minden bemeneti rekordra_ kiértékelődik.

A művelet is elhagyható, ilyenkor az alapértelmezett művelet az aktuális rekord kiírása.

### Különleges minták

Két különleges mintát gyakran használnak.

- A `BEGIN` a hozzá tartozó műveletet még azelőtt kiértékeli, hogy bármilyen bemenetet feldolgozna.
- Az `END` a hozzá tartozó műveletet az összes bemenet feldolgozása után értékeli ki.

## Mezőváltozók

A mezőkre `$1`, `$2`, `$3` stb. formában hivatkozhatsz.

Az aktuális rekord a `$0`.

Íme néhány más gyakran használt beépített változó.

### A bemenet feldolgozását szabályozó beépített változók

- Az `RS` a bemeneti rekordelválasztó.
  Mint említettük, az alapértelmezett értéke egy újsor.
- Az `FS` a bemeneti mezőelválasztó.

Ezeket a változókat gyakran a `BEGIN` műveletblokkban állítják be.

### Információt hordozó beépített változók

Ezeket a változókat az AWK automatikusan beállítja a program futása során.

- Az `NF` az aktuális rekord mezőinek számát tárolja.
  - A legutolsó mező értékét a `$NF` adja meg.
- Az `NR` az aktuális rekord sorszámát tárolja.
  - Ha több bemeneti fájlt dolgoz fel, az `NR` az eddig feldolgozott rekordok összesített számát tartalmazza.
- Az `FNR` az aktuális bemeneti fájl aktuális rekordszámát tárolja.
  - Az NR és az FNR közötti különbség szemléltetésére íme egy gyakori AWK-idióma.
    ```awk
    NR == FNR {action}
    ```
    Ez azt jelenti: „ha a felhalmozott rekordszám megegyezik az aktuális fájl rekordszámával”.
    Ez csak az _első bemeneti fájl_ rekordjaira lehet igaz.

## Igaz/hamis értékek

Az AWK ugyanazt az igaz/hamis értelmezést használja, mint a C.

- A `0` szám hamis.
- Minden más szám igaz.

Mivel az AWK szövegfeldolgozó nyelv, az igaz/hamis értékek a stringekre is kiterjednek.

- Az üres string (`""`) hamis.
- Minden nem üres string igaz.

## Megjegyzések

A megjegyzések a `#` karakterrel kezdődnek, és a sor végéig tartanak.

## Példák

A Unix-szerű rendszereken az `/etc/passwd` felhasználókra vonatkozó információkat tartalmaz.
Minden felhasználó külön sorban szerepel, a mezőket kettőspont választja el.

A felhasználónevek listázásához:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Figyeld meg, hogy a `{print $1}` művelethez nem tartozik minta, ezért minden rekordnál végrehajtódik.

Ha a kimenetet csak azokra a felhasználókra akarjuk korlátozni, akik a bash-t használják bejelentkezési shellként, ezt tehetjük:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
