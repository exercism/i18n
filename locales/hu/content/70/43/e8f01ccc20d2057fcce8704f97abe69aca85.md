# Tesztek

A legtöbb teszt azt ellenőrzi, hogy a várt értéket adod-e vissza: vagy értéket rendelsz a [result]-hoz, vagy átadsz egy értéket az [exit]-nek.

Néhány teszt pedig azt ellenőrzi, hogy a [raise] segítségével a várt kivételt dobod-e.

## A tesztek futtatása

A tesztek futtatásához a `make` segédprogramra van szükség.

A feladat könyvtárában állva írd be egy konzolba vagy terminálba:

```sh
make
```

Ha még csak hozzá sem nyúltál a feladat megoldásfájljához, valami ilyesmit látsz majd:

```
Please implement your solution.
```

Töröld hát ezt a sort, mielőtt elkezded írni a megoldásodat.

Alapértelmezés szerint csak az első teszt fut le.

```text
TAP version 14
1..10
ok 1 - ...
```

Az összes teszt futtatásához írd be:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

Ha minden teszt sikeres, készen vagy a feladattal, és beküldheted a megoldást.

Egyetlen tesztet is kiválaszthatsz futtatásra, ha megadod a hozzá tartozó számot, például:

```sh
make test=2
```

csak a második tesztet futtatja le.
