# Kiegészítő utasítások

## Regiszterek

| Regiszter | Használat | Típus | Leírás                |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | bemenet     | cím | a tárgyak súlyainak tömbje      |
| `$a1`    | bemenet     | cím | a tárgyak értékeinek tömbje       |
| `$a2`    | bemenet     | egész szám | a tárgyak száma            |
| `$a3`    | bemenet     | egész szám | maximális súly             |
| `$v0`    | kimenet    | egész szám | maximális érték              |
| `$t0-9`  | ideiglenes | bármi     | ideiglenes tárolásra szolgál |
