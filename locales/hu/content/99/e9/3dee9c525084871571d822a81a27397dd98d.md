# Utasítások

Egy kalóz egy rejtett öblökből álló térképen tervez útvonalat.
A térkép egy hashtábla, amelynek a kulcsa az öböl neve; minden
érték azon öblöknek a tömbje, amelyeket abból közvetlenül el
lehet érni.

## 1. A dagálysor kiürítése

Definiáld a `tide-queue` szót, hogy egy elemekből álló tömböt vegyen
át, minden elemet sorrendben tegyen rá egy friss deque-re, majd az
összeset pakolja vissza egy tömbbe úgy, hogy megőrizze az eredeti
sorrendet. Ez a FIFO viselkedés: a végére teszed be, az elejéről
veszed ki.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. Elérhető öblök

Definiáld a `coves-reachable` szót, hogy egy kezdő öblöt és egy
térképet vegyen át, és visszaadjon egy hash-setet minden olyan
öbölről, amely elérhető a `start` pontból, magát a `start` pontot is
beleértve.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

A BFS frontvonalaként használj egy `<dlist>`-et, a meglátogatott
halmazhoz pedig egy `HS{ }`-t.

## 3. Ugrások száma

Definiáld a `hop-count` szót, hogy egy kezdő öblöt, egy célöblöt és
egy térképet vegyen át, és visszaadja a köztük lévő legkevesebb
ugrást, vagy `f`-et, ha a cél nem érhető el.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

A deque-ben minden öblöt a kezdőponttól mért távolságával együtt
tárolj (egy kételemű tömb is megfelel).

## 4. Aranyszámlálás

A váz a `gold-count` szót `:`-tal deklarálja. Változtasd `MEMO:`-ra
(nem `:`-ra), hogy minden öböl eredménye csak egyszer számolódjon ki,
és onnantól a gyorsítótárból jöjjön. Az öböl aranyát a feladat által
biztosított `gold-distribution` konstansban keresd ki.
Az az öböl, amelyik nem szerepel az eloszlásban, nulla arannyal
rendelkezik.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. Kincsesútvonal

Definiáld a `treasure-route` szót, hogy egy kezdő öblöt és egy
térképet vegyen át, és visszaadja a legtöbb arannyal rendelkező
elérhető öblöt. Használd a 2. részfeladat `coves-reachable` szavát és
a 4. részfeladat `gold-count` szavát.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

A memoizált `gold-count` ingyenessé teszi az ismételt
lekérdezéseket, ami akkor hasznos, ha az algoritmus több része is
ugyanazt az öblöt kérdezi le.
