# Bevezetés

**A closure** egy [Clojure-beli][clojure-guide-closures] programozási minta, amely lehetővé teszi, hogy egy függvényen belül egy külső [lexikális scope][wiki-lexical-scope] változóit használd. A Clojure transzparensen támogatja a closure-öket, és gyakran anélkül használjuk őket, hogy tudnánk, mik is azok.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Állapot megőrzése és értékek továbbadása closure-ökkel

Egy atom segítségével megőrizhetünk bizonyos állapotot:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Az `increment` minden további hívása növeli a számlálóját:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
