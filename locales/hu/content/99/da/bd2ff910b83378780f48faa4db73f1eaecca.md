# Debug

Amikor egy teszt sikertelen, megjelenik egy üzenet, amely leírja, mi ment rosszul, és hogy melyik bemenetnél. A programodban tetszőleges értékeket vizsgálhatsz meg, ha átadod őket a `debug` metódusnak. Ez elkapja az értékeket, és megmutatja a kimenetet.

```ruby
debug "The value is #{value}."
debug "The input is #{input.inspect}"
```
