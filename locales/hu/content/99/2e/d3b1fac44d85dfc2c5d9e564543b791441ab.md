# Utasítások kiegészítése

## Regiszterek

| Regiszter | Használat     | Típus   | Leírás                        |
| --------- | ------------- | ------- | ----------------------------- |
| `$a0`     | bemenet       | egész szám | N, a háromszög oldalainak összege |
| `$a1`     | bemenet/kimenet | cím   | az a értékei                  |
| `$a2`     | bemenet/kimenet | cím   | a b értékei                   |
| `$a3`     | bemenet/kimenet | cím   | a c értékei                   |
| `$v0`     | kimenet       | egész szám | a számhármasok száma       |
| `$t0-9`   | ideiglenes    | bármi   | ideiglenes tárolásra          |
