# Bevezetés

Mielőtt megjelent a `Promise` osztály, az aszinkron kód kezelésének csak egyetlen módja létezett: a _callback-minta_.

A callback egy olyan függvény, amelyet argumentumként adunk át egy másik függvénynek, és amely akkor hívódik meg, amikor a másik függvényben valamilyen művelet befejeződött. Az ilyen callback-függvényeknél gyakori minta, hogy első paraméterként egy „error” értéket fogadnak (lásd az alábbi példát).

```javascript
function callback(error, arg2, arg3) {}
```

Hogyan kapcsolódik mindez az aszinkron kódhoz?

Történelmileg a callback-minta tette lehetővé, hogy egy aszinkron feladat befejeződése után elvégezzünk valamilyen munkát, anélkül hogy blokkolnánk az egész programot.

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

A fenti példában a `fetchProduct` függvény (amely aszinkron) második argumentumként egy callback-függvényt kap, amely eldönti, mi történjen, amikor a termék adatai megérkeztek.
