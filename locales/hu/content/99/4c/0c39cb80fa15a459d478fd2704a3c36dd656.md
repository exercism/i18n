# Bevezetés

A Python az igaz és hamis értékeket a [`bool`][bools] típussal ábrázolja, amely az `int` alosztálya.
Ebben a típusban csak két érték van: `True` és `False`.
Ezeket az értékeket egy változóhoz rendelheted:

```python
>>> true_variable = True
>>> false_variable = False
```

A Boolean kifejezéseket az `and`, `or` és `not` operátorokkal értékelheted ki:

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
