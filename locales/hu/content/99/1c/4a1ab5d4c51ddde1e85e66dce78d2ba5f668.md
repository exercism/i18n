# Részletesen

A .NET alap osztálykönyvtárai a reguláris kifejezések feldolgozásához biztosítják a [`Regex`][regex] osztályt.

A C# és a reguláris kifejezések más változatai közötti összehasonlítást ebben a [cikkben][regex-comparison] találod.

## Rögzítő csoportok

Az egyik szempont, amit érdemes figyelembe venni, a rögzítő csoportok, amelyek a szövegnek a reguláris kifejezés mintájának különböző részeire illeszkedő darabjait adják vissza. A rögzítő csoportok kezeléséhez hozzá kell szokni. Nézd meg ezt a [dokumentációt][capture].

Figyeld meg, hogy itt egy hierarchia játszik szerepet, amikor rögzítő csoportok, `(?<capture-name>pattern)`, vannak a dologban:

- ahol nulla vagy több találat halmaza tér vissza (egy minden egyes, a szövegben talált találathoz).
- Minden találat több rögzítő csoportot tartalmaz.
- Minden csoport több rögzítést tartalmaz.

Ezen kívül:

- A `Match` a `Group`-ból származik.
- A `Group` a `Capture`-ből származik.

Buktatók:

- A legbiztonságosabb megoldás a nevesített rögzítések használata.
- A rögzítő csoportok általában ugyanabban a sorrendben szerepelnek a `Groups` gyűjteményben, mint ahogy a szövegben megjelennek.
- Úgy tűnik, a `Groups[0]` a teljes találatra vonatkozik.
- Szinte biztos, hogy a `Groups[<capture name>].Value` az, ami érdekel. Az egyes rögzítések (a `Caputures[0]`-t kivéve) úgy tűnik, diagnosztikai célokat szolgálnak, ha egyáltalán megjelennek.

## Regex-beállítások

Ismerkedj meg a [`RegexOptions`][regex-options] osztállyal.

A szokásos `IgnoreCase` beállítások mellett ott van a `MultiLine` is, amely akkor hasznos, ha egyszerre több szövegsort dolgozol fel, valamint az `IgnorePatternWhitespace`, amely szó szerinti stringekkel, string-interpolációval és megjegyzésekkel párosítva nagyon kifejező tud lenni, ahogy az alábbi példa is mutatja:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

Egy másik érdekes beállítás a `RegexOptions.Compiled` a [lefordított][regex-compilation] regexekhez.
