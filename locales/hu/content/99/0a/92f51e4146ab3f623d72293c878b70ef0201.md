# használj string-interpolációt

[comment]: # (Ez a figyelmeztetés akkor jelenik meg, ha a megoldás nem használ string-interpolációt)

Használj [string-interpolációt](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20) ahhoz, hogy a `name` paramétert beilleszd a kimeneti stringbe.

- Ahol lehet, az Exercism Elixir kurzusa az olvashatóság érdekében a string-összefűzés helyett a string-interpolációt javasolja.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [Bármilyen Elixir-kifejezés](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30) szerepelhet a string-interpoláció szintaxisában

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
