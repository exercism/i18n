# A Kotlin telepítése

Ahhoz, hogy Kotlinban gyakorolj az Exercism feladataival, az Exercism CLI és a kedvenc szövegszerkesztőd mellett a következőkre van szükséged:

* a **Java Development Kit** (JDK): a Kotlin Java bájtkódra fordul, ezért telepítened kell a JDK-t, amely egyszerre tartalmaz egy Java futtatókörnyezetet *és* fejlesztőeszközöket (leginkább a Java fordítót); valamint
* a **Gradle**, egy kifejezetten JVM-alapú projektekhez készült build eszköz, amely támogatja a Kotlint.

Válaszd ki az operációs rendszeredet:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

… vagy …

* ha nem szeretnél csomagkezelőt használni, [telepíthetsz kézzel](#h-install-manually) is.

Opcionálisan [Java IDE-t](#h-java-ides) is használhatsz.

## Windows

Nyiss egy rendszergazdai parancssort. (Ha segítségre van szükséged a rendszergazdai parancssor megnyitásához, lásd: [rendszergazdai parancssor megnyitása Windows 8+-ban](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (vagy [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Ha még nem telepítetted a Chocolatey-t, tedd meg most:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Telepítsd a JDK-t:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

Javasoljuk, hogy zárd be a rendszergazdai parancssort, és nyiss egy új parancssort. Az Exercism feladatainak gyakorlásához nincs szükség rendszergazdai jogosultságokra.

Most már készen állsz arra, hogy elkezdd az Exercism Kotlin kurzusát!

Az induláshoz lásd: „[A tesztek futtatása](https://exercism.org/docs/tracks/kotlin/tests)”.

## macOS

Az alábbiakban a legelterjedtebb módszerrel, a Homebrew-val való telepítés lépéseit találod. Ha inkább másképp szeretnéd, [telepíthetsz macOS-en Homebrew nélkül](#h-installing-on-macos-without-homebrew) is.

### Telepítés

1. Ha még nem telepítetted a [Homebrew](http://brew.sh)-t, tedd meg most:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Add hozzá a [Homebrew Cask](https://caskroom.github.io/) repót, amivel előre lefordított binárisokat, például a JDK-t is telepíthetsz.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Telepítsd a JDK-t:

       ```
        $ brew install --cask adoptopenjdk11
       ```

Most már készen állsz arra, hogy elkezdd az Exercism Kotlin kurzusát!

Az induláshoz lásd: „[A tesztek futtatása](https://exercism.org/docs/tracks/kotlin/tests)”.

### Debian

Ha Debian-t vagy annak leszármazottját (például Ubuntu vagy Linux Mint) használod, az APT-t használd:

*(tesztelve: Ubuntu 14, 16 és 18)*

1. Telepítsd a JDK-t:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```

### Más Linux-disztribúciók

A Jdk 11 telepítésének sokféle módja van, de az egyik legegyszerűbb a SDKMAN használata, 
amellyel könnyedén telepítheted az OpenJdk11-et. Kövesd az alábbi lépéseket:

1. Telepítsd a SDKMAN-t:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (ha ez nem működik, nézd meg az itt található útmutatót: https://sdkman.io/install )
1. Telepítsd az openjdk11-et:
    ```
    $ sdk install java 11.0.2-open
    ```

*MEGJEGYZÉS: ezek az utasítások gyakorlott Windows-felhasználóknak szólnak. Ha még nem tudod, hogyan kell környezeti változókat beállítani, vagy nem érzed magad biztonságban a könyvtárszerkezet kezelésében, erősen javasoljuk, hogy a Chocolatey-alapú telepítést használd, [fentebb](#h-windows).*
