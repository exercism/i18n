# Kiegészítés az utasításokhoz

## Tipp

Egy *visszatérési típussal* rendelkező függvény csak az adott *típusú* adatot és `null`-t adhatja vissza. A függvény hívója viszont csak egyetlen adattípusra számít.

Példa:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
Hogy világosabb legyen, hogy ez a függvény `null`-t vagy több adattípust is visszaadhat, használd a `dynamic`-ot.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
