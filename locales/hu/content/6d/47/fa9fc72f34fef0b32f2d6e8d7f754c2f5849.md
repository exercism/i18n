# Telepítés

Ezen a kurzuson a megoldások 32 bites RISC-V assembly nyelven íródnak, és emuláció alatt futnak, így nincs szükség RISC-V hardverre.
Minden feladat tartalmaz egy Makefile-t, amely lefordítja a teszteket és futtatja azokat.
A használatához három eszközre van szükséged:

- [Zig][zig], amely a `zig cc` segítségével biztosítja a RISC-V assemblert, a C fordítót és a linkert.
- [Make][make], amely a buildet futtatja.
- `qemu-riscv32` a [QEMU][qemu]-ból, amely futtatja az eredményül kapott programot.

## macOS

Indíts el egy Linux virtuális gépet bármilyen megfelelő virtualizációs megoldással (pl. [Lima][lima]), és kövesd az alábbi Linux-disztribúciós részt.

## Windows

Használd a [Windows Subsystem for Linux][wsl] alrendszert, és kövesd az alábbi Linux-disztribúciós részt.
Alternatívaként állíts be egy Linux virtuális gépet.

## Debian / Ubuntu

Telepítsd a Make-et és a QEMU felhasználói módú emulátorait:

```shell
sudo apt install make qemu-user
```

Ezután telepítsd a Zig 0.15.2-es vagy újabb verzióját a [Közvetlen letöltés][zig-install] alatt leírtak szerint.

## Fedora

Telepítsd mindhárom eszközt ezzel:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

Telepítsd mindhárom eszközt ezzel:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

Telepítsd mindhárom eszközt ezzel:

```shell
sudo zypper install zig make qemu-linux-user
```

## A telepítés ellenőrzése

Ellenőrizd, hogy mindhárom eszköz megtalálható-e:

```shell
zig version
make --version
qemu-riscv32 --version
```

Ezután tölts le egy feladatot az Exercism CLI-vel, és futtasd a tesztjeit:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
