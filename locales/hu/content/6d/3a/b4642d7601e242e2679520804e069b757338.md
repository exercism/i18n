# Kiegészítés az utasításokhoz

## Építsd meg a saját DSL-ed

Ebben a feladatban teljesen szabadon megtervezheted a gráf-DSL-t, amelyről mindig is álmodtál.

Talán egy olyan DSL-t szeretnél létrehozni, amely címkék és rekordok listáira épül, valahogy így:

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

Vagy inkább a függvényhívások láncolatára épülő DSL-t részesítenéd előnyben, így:

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

Vagy esetleg egészen más terved van? Vágj bele! A tesztek csupán néhány konkrét gráf létrehozását kérik, azt viszont teljesen rád bízzák, hogyan építed fel őket.

Ugyanakkor a DSL általában akkor jobb, ha világos, tömör, és nem túl meglepő (pl. a `minus` függvény kivonásra való, nem pedig arra, hogy két csomópont közötti élet építs vele, mint a `node("a") - node("b")` esetében).

Hogy megduplázd a szórakozást, ha kedved tartja, megvalósíthatsz egy `to_dot` függvényt is, amely a gráfodat DOT formátumra alakítja!
