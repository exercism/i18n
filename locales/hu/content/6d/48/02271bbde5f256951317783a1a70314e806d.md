# Telepítés

## A .NET telepítése

A C# kurzus a [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) platformra épül, amely Windows, Linux és macOS rendszeren fut.
.NET-projektek összeállításához használhatod a .NET parancssori felületet (CLI).
Ez a CLI a .NET SDK része, amelyet a [telepítési útmutató](https://dotnet.microsoft.com/download/dotnet/8.0) követésével telepíthetsz.
Megjegyzés: a C# kurzushoz 9.0-s vagy annál újabb SDK-verzió szükséges.

A telepítés befejezése után a következő parancs terminálban való futtatásával ellenőrizheted, hogy a CLI sikeresen települt-e:

```bash
dotnet --version
```

Ha a kimenet egy `9.0.100`-as vagy annál nagyobb verzió, akkor a .NET SDK sikeresen települt.

## IDE használata

Ha funkciókban gazdagabb szerkesztési élményt szeretnél, valószínűleg egy [IDE vagy integrált fejlesztői környezet](https://en.wikipedia.org/wiki/Integrated_development_environment) használatára lesz szükséged.
Ezek a legnépszerűbb IDE-k, amelyek támogatják a .NET-projektek összeállítását:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) a [C# bővítménnyel](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Megjegyzés: mivel a .NET projektformátuma jelentősen eltér a korábbi verzióktól, a régebbi IDE-k (például a Visual Studio 2015) nem támogatottak.
