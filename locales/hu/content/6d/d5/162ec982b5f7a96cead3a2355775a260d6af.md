# Láthatóság

Amikor osztályokkal rendezzük a kódot, a tulajdonságok, metódusok és konstansok láthatósága segíthet kialakítani a megfelelő absztrakciókat és felelősségköröket.
A tulajdonságok, metódusok és konstansok láthatóságát az határozza meg, hogy a deklarálásukkor a `public`, `private` vagy `protected` kulcsszó melyikét használjuk.
A láthatóság mindig arra vonatkozik, hogy az osztály tulajdonságát, metódusát vagy konstansát kívülről használjuk-e.
Azaz ha egy tulajdonságot `public`-ként deklarálunk, akkor az kívülről megfigyelhető és használható.
A `private` tulajdonságok, metódusok és konstansok kívülről nem figyelhetők meg, és nem is használhatók.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

A `protected` tulajdonságok, metódusok és konstansok csak maga az osztály és a belőle öröklő gyermekosztályok számára figyelhetők meg.

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
