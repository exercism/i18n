# Források

* A [The Rust Programming Language](https://doc.rust-lang.org/book/) nagyszerű segítség, ha most kezdesz a Rusttal, de akkor is, ha egy-egy nyelvi elemet szeretnél alaposabban megismerni.
* A [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) példákon keresztül mutatja be mindazt, amit a leggyakrabban fogsz írni Rustban.
* A [Rust API Documentation](http://doc.rust-lang.org/std/) segítségével új metódusokat fedezhetsz fel, és megnézheted, hogyan is működnek.
* A [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) hasznos lehet, ha rákeresel a problémádra, hátha már megválaszolták. Kérdéseket is feltehetsz, és válaszolhatsz is másoknak.
* A [Rust User Forum](http://users.rust-lang.org) a Rustról szóló általános beszélgetések helyszíne.
* A [/r/rust](http://www.reddit.com/r/rust/) a hivatalos Rust-subreddit.
* A [The Rust Programming Language](https://discord.gg/rust-lang) hivatalos szervere a [Discord](https://discordapp.com/)on, ahol gyorsan kérdezhetsz, és beszélgethetsz a nyelvről.
