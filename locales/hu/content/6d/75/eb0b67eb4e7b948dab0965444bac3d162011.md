# Bevezetés

Amikor Gleam-ben mintaillesztést végzünk egy értéken, ügyelnünk kell rá, hogy a minták a típus minden lehetséges értékét lefedjék, különben a kód nem fordul le.

Ezt a függvényt el kell utasítani, mert nem kezeli azt az esetet, amikor a lista üres:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

A Gleam-programokban legtöbbször minden lehetséges esetet kezelni akarunk, de néhány programban, például prototípusokban és gyors szkriptekben előfordulhat, hogy csak a happy path esetével akarunk foglalkozni, és nem írunk kódot a többi esetre. Itt jön képbe a Gleam `let assert`.

A let assert segítségével egy minta a típusnak csak néhány lehetséges értékére illeszkedhet, és ha a minta nem illeszkedik egy értékre, a program összeomlik. A `let assert` használatával a fenti függvényt így írhatjuk meg:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

A Gleam-könyvtárak soha nem használhatnak let assertet, mert az összeomlaszthatja a programot. Ehelyett a `Result` típust kell használniuk, és hagyniuk kell, hogy az alkalmazás fejlesztője döntse el, hogyan kezelje a hibákat.
