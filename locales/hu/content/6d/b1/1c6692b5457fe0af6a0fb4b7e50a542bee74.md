# Kiegészítés az utasításokhoz

## A `from_quote` előnyei és hátrányai

A `DateOfBirth.from_quote` függvény egy `"YYYY-MM-DD"` formátumú stringet alakít át `DateOfBirth` értékké.
Ettől lehetővé válik, hogy ilyen kódot írj:

```roc
birthdate : DateOfBirth
birthdate = "2019-01-20"
```

Ez a kód implicit módon meghívja a `DateOfBirth.from_quote("2019-01-20")`-t fordítási időben.
Ez potenciálisan felgyorsíthatja a programot, mivel futásidőben nem kell foglalkoznia a szöveg feldolgozásával, és biztosítja, hogy a `from_quote` által elutasított dátumok már fordítási időben kiszűrődjenek, nem futásidőben.
Ráadásul így a kód szép és olvasható lesz.
Például íme a feladat egyik tesztje:

```roc
# multiple birthdates with one shared birthday
expect {
	shared_birthday(["1966-07-29", "1977-02-12", "2001-07-29", "1980-11-10"])
}
```

Előfordulhat azonban, hogy aki ezt a kódot olvassa, azt feltételezi, hogy a `shared_birthday` függvény `List(Str)`-et vár, pedig valójában `List(DateOfBirth)`-et.
Ez zavarhoz és hibákhoz vezethet.
Ezért talán a kicsit hosszabb, de egyértelműbb formátumot részesíted előnyben: a `"2019-01-20".DateOfBirth` alakot, amely szintén meghívja a `from_quote`-ot fordítási időben.

A saját programjaidban érdemes lehet egy kényelmes konstruktort adnod, például ezt:

```roc
DateOfBirth := { year : I64, month : U8, day : U8 }.{
    from_ymd : I64, U8, U8 -> Try(DateOfBirth, [InvalidMonth, InvalidDay])
    from_ymd = |year, month, day| ...
}
```

Ezt a konstruktort fordítási időben is meghívhatod, így:

```roc
Ok(birthdate) = DateOfBirth.from_ymd(2019, 1, 20)
```

Megjegyzés: Ha ezt a definíciót a legfelső szinten helyezed el, az fordítási időben fut le (mivel a függvény tiszta, és a bemenetek fordítási időben ismertek).
Egy függvényen belül ugyanezt a konstruktort futásidőben is használhatod.

## A `random` könyvtár

A [`roc-random` csomag](https://github.com/kili-ilo/roc-random) a `random` álnéven érhető el a tesztalkalmazásban.
A kiinduló kód importálja a `random.Random`-ot.

## Tippek

<details>
<summary>Tippek megjelenítése</summary>

A `Random.Generator(a)` azt írja le, hogyan generálhatsz egy `a` típusú értéket.
A húzások összekombinálásához a `Random.list`-et, az eredményeik átalakításához a `Random.map`-et használd.
A `Random.step(state, generator)` egy `{ value, state }` értéket ad vissza. A frissített állapotot vidd tovább a szimulált csoportok között, hogy ne ismétlődjön ugyanaz a minta.

</details>
