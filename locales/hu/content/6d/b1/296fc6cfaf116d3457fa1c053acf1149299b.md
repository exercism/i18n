# Bevezetés

A C++-ban, akárcsak sok más nyelvben, vannak _mutatók_.
Már tudod, hogy a _referenciák_ és a _mutatók_ hasonlítanak egymásra, de gondolj rájuk úgy, mint ami egy szinttel közelebb van a számítógéped belső működéséhez.
A _mutatók_ olyan változók, amelyek objektumok címét tárolják.
Segítségükkel közvetlenül dolgozhatsz objektumokkal, ami lehetővé teszi a dinamikus memóriafoglalást és a hatékony adatkezelést a C++-ban.

Ha most találkozol először a _mutatókkal_, kissé rejtélyesnek tűnhetnek, de ha egyszer megszokod őket, egészen egyszerűek.

A C++ kulcsfontosságú részét képezik, ezért szánj rá időt, hogy igazán megértsd őket.
Az ebben a fogalomban bemutatott csupasz változatot _buta mutatónak_ vagy _nyers mutatónak_ is szokás nevezni.
A modern C++-ban már _okos mutatók_ is vannak, de az alap típus egyáltalán nem okos: minden munkát neked kell kézzel elvégezned.

Mielőtt belemennénk a részletekbe, érdemes megérteni, mire is használjuk a _mutatókat_.
A _mutatók_ segítségével egy objektum címét oszthatjuk meg a programunk más részeivel, ami két fő okból hasznos:

1. A _referenciákhoz_ hasonlóan a mutatók elkerülik a másolatokat, és segítenek csökkenteni a program erőforrás-igényét.
1. A _referenciákkal_ ellentétben a mutatók más objektumokra is átirányíthatók.
1. A mutatók ezen kívül null értékre is mutathatnak, jelezve, hogy éppen semmilyen objektumra nem mutatnak.

## Általános szintaxis

A C++-ban egy mutató deklarálásakor meg kell adni az adattípust, amelyre a mutató mutat, majd egy csillagot (`*`) és a mutató nevét.
A mutatók deklarálásukkor nem kapnak automatikusan kezdőértéket.
Explicit értékadás nélkül a mutató jellemzően meghatározatlan értéket tárol, amit gyakran „szemétcímnek” neveznek.
Bár egyes fordítók `nullptr` kezdőértékkel látják el a mutatókat, ez a viselkedés nem garantált minden fordítónál, ezért fontos, hogy ne támaszkodj rá.
A legjobb gyakorlat, ha a nyers mutatóknak explicit kezdőértéket adsz, és használat előtt ellenőrzöd, hogy nem null értékűek; így elkerülhetők a lehetséges problémák.

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

Ahhoz, hogy egy változó címét egy mutatóhoz rendeld, a címképző operátort (`&`) használod.
Egy mutató dereferálásához az _indirekciós operátort_ (`*`) használod.

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

Figyelem: a dereferálást explicit módon kell elvégezni, míg a _referenciák_ egyszerűen aliasként működtek.

## Mutatóaritmetika

A _mutatóaritmetika_ lehetővé teszi, hogy aritmetikai műveleteket végezz a mutatókon, ami különösen tömbökkel dolgozva hasznos.
Ha egy mutatóhoz egész számot adsz, az egy másik elemre fog mutatni.

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

## Tagváltozók elérése

A C++-ban a `->` operátorral érheted el egy objektum tagjait az objektumra mutató mutatón keresztül.
Ez egy rövidítés, amely leegyszerűsíti a mutatók által mutatott objektumok tagjainak elérését.
Ha például `ptr` egy olyan objektumra mutat, amelynek van egy `x` tagváltozója, akkor a `(*ptr).x` helyett közvetlenül a `ptr->x` kifejezést használhatod.
Ez az operátor javítja a kód olvashatóságát és csökkenti a terjengősséget, amikor objektumokra mutató mutatókkal dolgozol.

Íme egy rövid példa: egy `Superhero` _struct_, amelynek van egy `superpower` tagváltozója.
A main függvény létrehoz egy `dianaPrince` mutatót egy `Superhero` objektumra (amely Wonder Womant személyesíti meg).
A `->` operátorral férünk hozzá a `superpower` tagváltozóhoz, bemutatva Wonder Woman ikonikus „Lasso of Truth” fegyverét.

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
// Memory cleanup:
delete dianaPrince;
```

## Mutatók és referenciák

A mutatók és a referenciák egyaránt lehetővé teszik az objektumok közvetett elérését, de képességeikben és biztonsági szempontjaikban különböznek.
A mutatók rugalmasak: kicserélheted, mire mutatnak, és null értéket is kaphatnak.
Ez a rugalmasság azonban kockázatokkal jár: ilyen például a null mutató dereferálása vagy a lógó mutatók létrehozása.
A referenciák ezzel szemben nem lehetnek null értékűek, és létrehozásukkor érvényes objektumhoz kötődnek, így ezek a kockázatok elkerülhetők.
Mivel biztonságosabbak, a referenciákat előnyben kell részesíteni a mutatókkal szemben, kivéve, ha a mutatók nyújtotta plusz funkciókra van szükség.
