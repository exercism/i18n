# Bevezetés

A Gleamben kétféle szám létezik: egész számok és lebegőpontos számok.

Az egész számoknak nincs törtrészük.

```gleam
let integer = 3
// -> 3
```

A Gleam több operátort is kínál, amelyek egész számokkal működnek.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
