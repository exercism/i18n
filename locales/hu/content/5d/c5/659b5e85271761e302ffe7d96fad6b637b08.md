# Bevezetés

Előfordul, hogy egy függvény sok argumentumot vár, és ilyenkor nehéz megjegyezni, milyen sorrendben kell megadni őket. Az olvashatóság érdekében a Gleam lehetővé teszi, hogy az argumentumokat névvel lásd el.

Egy argumentum címkézéséhez a címke nevét az argumentum neve elé írd, szóközzel elválasztva.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Amikor egy függvényt címkézett argumentumokkal hívsz meg, az argumentumokat tetszőleges sorrendben megadhatod. Az alábbi `replace`-hívások mind egyenértékűek:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

A címkék mindig opcionálisak. Attól még, hogy egy függvénynek címkézett argumentumai vannak, címkék nélkül is meghívhatod.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
