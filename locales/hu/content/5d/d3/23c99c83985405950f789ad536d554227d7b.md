# Bevezetés

Az SQL-ben a `SELECT` utasítással adatokat kérhetsz le egy adatbázisból.
A `SELECT` utasítás eredménye egy eredményhalmaz.
Az eredményhalmaz sorokba és oszlopokba rendezett értékeket tartalmaz.
Minden oszlop az adat egy adott attribútuma.
Minden sor minden oszlophoz tartalmaz egy értéket.

Gondolhatsz úgy is rá, hogy az oszlopok halmaza egy adatszerkezetet ír le: minden oszlop az adatszerkezet egy mezője, minden sor pedig az adatszerkezet egy példánya.

A `SELECT` utasítással megadhatod, milyen adatokat szeretnél lekérni.
Ha akarod, át is alakíthatod, szűrheted és/vagy módosíthatod a kimeneti adatok alakját.

## Az alapok

Egy egyszerű `SELECT` utasítás felépítése a következő:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
A `FROM` és a `WHERE` záradék nem kötelező.
Egy ilyen utasítás például teljesen érvényes: `SELECT "Hello, world.";`.

Az is fontos, hogy nem kell sortöréseket használnod: a `SELECT` utasítás egyes záradékait (azaz részeit) bármilyen szóköz elválasztja.
~~~~

A `SELECT` kulcsszó után közvetlenül azoknak az oszlopoknak a listája áll, amelyeket az eredményben szeretnél látni.
A `FROM` záradék nevezi meg az adatok forrását, ami általában egy tábla az adatbázisban.
A `WHERE` záradék egy vagy több feltétel alapján szűri a kimeneti adatokat.

## Az adatok szűrése a WHERE záradékkal

A `WHERE` záradék segítségével szűrheted a `SELECT` utasítással lekérdezett adatokat.
Ha például csak az Appliances értékeket szeretnénk, így tehetünk:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

Eredmény:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

Vagy ha csak azokat az adatokat szeretnénk, amelyeknél a weight 2.0 és 6.0 között van:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

Eredmény:
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```
