# Bevezetés

A Ruby egy dinamikus [objektumorientált nyelv][object-oriented-programming].
A Rubyban minden egy [objektum][object].

Két fő módja van annak, hogy objektumokat nevekhez rendelj a Rubyban: változókkal vagy konstansokkal.
A változókat mindig [snake case][snake-case] stílusban írjuk.
Egy változó az élettartama során különböző objektumokra hivatkozhat.
Például a `my_first_variable` többször is definiálható és újradefiniálható a `=` operátorral:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

A konstansoknak azonban csak egyszer szabad értéket kapniuk.
Nagybetűvel kell kezdődniük, és általában csupa nagybetűvel írjuk őket, a szavakat alulvonással elválasztva.

Például:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

A Ruby osztályokba szerveződik.
Az osztályokat a `class` kulcsszóval definiáljuk, amelyet az osztály neve követ.
Az objektumokat általában úgy hozzuk létre, hogy az osztályokat a `.new` metódussal példányosítjuk.

Például:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

A funkcionalitás egységei metódusokba vannak zárva, hasonlóan más nyelvek _függvényeihez_.
Egy metódus opcionálisan definiálható pozicionális argumentumokkal és/vagy kulcsszavas argumentumokkal, amelyek definiálása és hívása a `:` szintaxissal történik.
A metódusok vagy implicit módon visszaadják az utoljára kiértékelt utasítás eredményét, vagy a `return` kulcsszóval explicit módon visszaadhatnak egy objektumot.
A metódusokat a `.` szintaxissal hívjuk meg.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
