# Bevezetés

A JavaScript tömbbontó szintaxisa tömör módja annak, hogy értékeket nyerj ki egy tömbből, és azokat különálló változókhoz rendeld.

Ebben a példában a `numberOfMoons` tömb minden egyes értékét a hozzá tartozó bolygóhoz rendeljük:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```
