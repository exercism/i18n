# Bevezetés

A kovariancia és a kontravariancia fontos fogalom a PHP-ban, mert a PHP kikényszeríti, hogy ezeket a szabályokat betartsd, amikor osztályokat vagy interfészeket terjesztesz ki.

A kovariancia megőrzi két típus kapcsolatát, a kontravariancia viszont megfordítja azt. Röviden ez azt jelenti, hogy amikor osztályokat terjesztesz ki, és függvényeket írsz felül, a metódusod paramétereinél megengedhetsz kevésbé vagy jobban specifikus típusokat, a metódusból pedig kevésbé vagy jobban specifikus típusokat adhatsz vissza.

## Példák

Nézzük a következő osztályt:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

Ha kiterjeszted az osztályt, az eredetileg deklaráltnál több paramétertípust engedhetsz meg, de nem adhatsz vissza mást, mint az eredeti visszatérési típusokat.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

A következő kiterjesztett osztály nem érvényes, mert további vagy tágabb típusokat nem lehet visszaadni:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
