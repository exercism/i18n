# Bevezetés

Egy metódusparamétert opcionálissá tehetünk úgy, hogy alapértelmezett értéket adunk neki. Amikor egy opcionális paraméterekkel rendelkező metódust hívunk meg, a hívónak nem kell értéket átadnia ezeknek. Ha egy opcionális paraméterhez nem adunk át értéket, akkor annak az alapértelmezett értéke lesz használva.

Az opcionális paraméterek _csak_ a paraméterlista végén állhatnak; nem követheti őket nem opcionális paraméter.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
