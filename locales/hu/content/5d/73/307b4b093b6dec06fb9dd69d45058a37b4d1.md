# Bevezetés

## Idő

A `Time` modul arra szolgál, hogy ember által olvasható dátumokat és időpontokat jelenítsünk meg vele.
Bár a `Time` modullal technikailag lehetséges időpontokat manipulálni, vannak olyan Elm közösségi csomagok, amelyek sokkal jobban illenek erre a feladatra, például a [`justinmimbs/date`][date] vagy a [`CoderDennis/elm-time-format`][elm-time-format].

### Posix

Az időpontokat a `Posix` átlátszatlan típus reprezentálja, amely a Unix epoch időt csomagolja be: az 1970. január 1-jei UTC éjfél óta eltelt ezredmásodpercek számát.
A `Posix` egyértelmű érték, amely nem változik az időzónák között, ezért jó választás az idő nyilvántartására.
Egy Elm-alkalmazásban a `Posix` időpontokat jellemzően külső források adják, például a böngésző.

Egy `Posix`-t át lehet alakítani ezredmásodpercek számává, és fordítva, a következő függvényekkel:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

### Időzónák

A mindennapi életünkben mi, emberek általában nem `Posix` értékeket olvasunk, hanem a helyi időt részesítjük előnyben, amely a Földön elfoglalt helyünktől és a helyi nyári időszámítás szabályaitól függ.
Elmben ezt az információt a `Zone` átlátszatlan típus kódolja, amelyet általában a böngésző biztosít.

Van egy különleges `Zone`, amely mindig elérhető:

```elm
utc : Zone
```

### Emberi időpontok

Egy `Posix` és egy `Zone` birtokában elegendő információnk van ahhoz, hogy a helyi időt bármilyen részletességgel megjelenítsük.
Íme az ehhez használható függvények listája:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Két további `Time` egyedi típust is észrevehettél:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Ezeket az egyedi típusokat a felhasználóknak kell ember által olvasható értékekké alakítaniuk.
