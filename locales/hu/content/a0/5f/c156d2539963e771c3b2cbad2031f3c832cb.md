# Bevezetés

## Modulok

A modulokkal összetartozó kódot csoportosíthatsz, elkerülheted a névütközéseket, és általában minden nem triviális kódbázisban megtalálhatók.

A szintaxis a következő:

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

A modul scope-ján kívül a modulba zárt típusokra úgy hivatkozunk, hogy a típusnév elé a dupla kettőspont `::` szintaxist tesszük.
Másik lehetőség, és általában ez a szokásosabb, hogy a fájl elejére (vagy egy modulon belülre) egy `use` direktívát teszel, és akkor a típusok előtag nélkül használhatók.
Ugyanazon a modulon belül nincs szükség a típusnevek minősítésére.

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

Egy modult vagy típust a `use core::array::ArrayTrait as Arr;` szintaxissal nevezhetsz át, majd az aliast bárhol használhatod, ahol a modult vagy a típust lehetne.
