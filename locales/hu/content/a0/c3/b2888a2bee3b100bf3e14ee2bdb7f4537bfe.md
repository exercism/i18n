# Bevezetés

A C#-ban két különböző számtípus létezik:

- Egész számok: olyan számok, amelyeknél a tizedesjel mögött nincs számjegy (azaz egész értékek). Például `-6`, `0`, `1`, `25`, `976` és `500000`.
- Lebegőpontos számok: olyan számok, amelyeknél a tizedesjel mögött nulla vagy több számjegy áll. Például `-2.4`, `0.1`, `3.14`, `16.984025` és `1024.0`.

A C#-ban a két leggyakoribb numerikus típus az `int` és a `double`. Az `int` egy 32 bites egész szám, a `double` pedig egy 64 bites lebegőpontos szám.

A számtani műveleteket a szokásos aritmetikai operátorokkal végezzük. A számokat a szokásos numerikus összehasonlító operátorokkal, valamint az egyenlőség (`==`) és az egyenlőtlenség (`!=`) operátorral lehet összehasonlítani.

A C#-ban kétféle numerikus konverzió létezik:

1. Implicit konverziók: nem vész el adat, és nincs szükség további szintaxisra.
2. Explicit konverziók: adat veszhet el, és további szintaxisra van szükség _cast_ formájában.

Mivel az `int` kevesebb pontossággal rendelkezik, mint a `double`, az `int`-ből `double`-ba való átalakítás biztonságos, ezért implicit konverzió. A `double`-ből `int`-be való átalakítás viszont adatvesztéssel járhat, ezért ott explicit konverzióra van szükség.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
