Távolítsd el a `Boolean(...)` minden explicit hívását.

A JavaScriptben egy kifejezés eredményét nem kell egy adott típusra _konvertálni_.
Egy bináris kifejezés eredményét például visszaadhatod úgy, ahogy van, és nincs szükség külön hívásra ahhoz, hogy `boolean` legyen belőle.

```javascript
// instead of
return Boolean(some_expression);

// ...In JavaScript, in general, values don't need to be explicitly changed
return some_expression;
```
