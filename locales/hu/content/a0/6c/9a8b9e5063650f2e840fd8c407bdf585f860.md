# Névjegy

A **closure-ok** egy [programozási minta a Clojure-ban][clojure-guide-closures], amely lehetővé teszi, hogy egy függvényen belül egy külső [lexical scope][wiki-lexical-scope] változóit használjuk. A Clojure transzparensen támogatja a closure-okat, és gyakran anélkül használjuk őket, hogy tudnánk, mi is az.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Closure-ok állapot megőrzésére és értékek továbbadására

Egy atom használatával megőrizhetünk bizonyos állapotot:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Az `increment` egymást követő meghívásai mind eggyel növelik a számlálót:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
