# Névjegy

A `when` a kulcsszó a kivételszűrésben. A catch utasítás után helyezkedik el, és olyan Boolean-kifejezést fogadhat el, amely az adott pillanatban scope-ban lévő bármely értéket tartalmazhat. Nem csak a kivétel tagjai lehetnek. Ha a kivétel típusa megegyezik, és a kifejezés igazra értékelődik, akkor a `catch` utasításhoz tartozó blokk végrehajtódik, ellenkező esetben a következő `catch` utasítás, ha van ilyen, ellenőrzésre kerül.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- Ez a [Kivételszűrők][exception-filters] cikk bemutatja, hogyan kell szűrni a kivételeket.

[exception-filters]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/when
