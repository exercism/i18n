# A feladat kiegészítése

## Regiszterek

| Regiszter | Használat      | Típus   | Leírás                          |
| --------- | -------------- | ------- | ------------------------------- |
| `$a0`     | bemenet        | cím     | null-terminált bemeneti string  |
| `$a1`     | bemenet        | egész   | eltolási kulcs                  |
| `$a2`     | bemenet/kimenet | cím    | null-terminált eredmény string  |
| `$t0-9`   | ideiglenes     | bármi   | ideiglenes tárolásra            |
