# Utasítások

Szenvedélyes madárfigyelő vagy, aki nyomon követi, hány madár járt a kertedben.
Általában egy füzetben rovátkákkal számolod meg a madarakat, de szeretnéd jobban feldolgozni az adataidat.
Már digitalizáltad az elmúlt hetek napi madárszámait, amelyeket a füzetben vezettél.

Most szeretnéd meghatározni, összesen hány madarat számoltál meg, kiszámolni egy adott hét madárszámát, és kijavítani egy számolási hibát.

## 1. Határozd meg, összesen hány madarat számoltál eddig

Kezdjük az adatok elemzését egy átfogó áttekintéssel.
Nézd meg, összesen hány madarat számoltál meg, mióta vezeted a naplódat.

Készíts egy `totalBirdCount` függvényt, amely egy tömbhöz hasonló objektumot fogad el, ami a napi madárszámokat tartalmazza.
A függvény adja vissza az összes megszámolt madár számát.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. Számold ki egy adott héten látogató madarak számát

Most, hogy már van egy általános képed a madárszámaidról, szeretnél egy részletesebb elemzést készíteni.

Készíts egy `birdsInWeek` függvényt, amely elfogad egy napi madárszámokat tartalmazó, tömbhöz hasonló objektumot és egy hét sorszámát.
A függvény visszaadja az adott héten megszámolt madarak összes számát.
Feltételezheted, hogy a heteket mindig teljesen vezeted.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. Javíts ki egy számolási hibát

Rájöttél, hogy amíg a madarakat próbáltad nyomon követni, mindvégig ott bujkált egy a kert egy távoli zugában.
Kiderítetted, hogy ez a madár mindig minden második napot a kertedben töltött.
Nem tudod pontosan, hol volt a napok között, de biztosan nem a kertedben.
A madárfigyelő megérzésed azt is mondja, hogy a madár azon az első napon, amelyet a listádon vezettél, a kertedben volt.

Ezen új információ birtokában írj egy `fixBirdCountLog` függvényt, amely argumentumként egy napi madárszámokat tartalmazó, tömbhöz hasonló objektumot fogad el. A függvény a megadott tömb módosításával javítsa ki a számolási hibát.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
