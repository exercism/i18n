# Utasítások

A közelben található egy „Tech Palace” nevű háztartásigép-bolt.
A bolt tulajdonosa nemrég egy nagy kijelzőt telepített, hogy marketingüzeneteket jelenítsen meg vele, és hogy különleges üdvözlést mutasson, amikor a vásárlók a bejáratnál leolvastatják a hűségkártyájukat.
A kijelző sok apró LED-lámpából áll, és több sor szöveget is meg tud jeleníteni.

A bolt tulajdonosának segítségre van szüksége az új kijelző szövegét előállító kóddal kapcsolatban.

## 1. Készítsd el az üdvözlő üzenetet

<!-- markdownlint-disable-next-line MD038 -->
A legtöbb vásárlónál, aki leolvastatja a hűségkártyáját, a bolt tulajdonosa azt szeretné, hogy a kijelzőn a `Welcome to the Tech Palace, ` szöveg jelenjen meg, majd utána a vásárló neve csupa nagybetűvel.

Valósítsd meg a `welcome_message` függvényt, amely a vásárló nevét egy rövid string (`felt252`) argumentumként fogadja, és a kívánt üzenetet `ByteArray`-ként adja vissza.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. Adj hozzá egy díszes szegélyt

A bolt hűséges, sokat vásárló ügyfelei számára a tulajdonos díszesebbé tenné az üdvözlő kijelzőt azzal, hogy az üdvözlő üzenet elé és mögé is egy-egy csillagsort tesz.
Még nem tudják biztosan, hány csillag legyen a sorokban, ezért beállíthatóvá szeretnék tenni.

Írj egy `add_border` függvényt, amely egy üdvözlő üzenetet (egy `ByteArray`) és a soronkénti csillagok számát (`u32` típus) fogadja argumentumként.
A visszatérési értéke egy `ByteArray` legyen, amely 3 sorból áll: a kívánt számú csillagot tartalmazó sor, majd a bemenetként kapott üdvözlő üzenet, végül egy újabb csillagsor.

```rust
add_border("Welcome!", 10)
```

A következőt kell visszaadnia:

```bash
**********
Welcome!
**********
```

## 3. Tisztítsd meg a régi marketingüzeneteket

Mielőtt felszerelték ezt az új kijelzőt, a boltban egy hasonló kijelző volt, amely csak nem beállítható, statikus sorokat tudott megjeleníteni.
A tulajdonos szeretne néhány régi marketingüzenetet újra felhasználni az új kijelzőn.
A régi adatokban azonban már benne van egy csillagszegély, és néhány szerencsétlen szóköz is.
A feladatod, hogy megtisztítsd az üzeneteket, hogy újra felhasználhatók legyenek.

Valósítsd meg a `clean_up_message` függvényt, amely a régi marketingüzenetet egy `ByteArray`-ként fogadja.
A függvény először távolítsa el az összes csillagot a szövegből, majd a maradék szöveg elejéről és végéről a szóközöket.
Ezután a megtisztított üzenetet kell visszaadnia.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
