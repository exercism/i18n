# Tippek

## 1. Bontsd fel a stringet külön sorokra

- A Swiftnek van egy [metódusa][nsstring-components-docs] arra, hogy egy stringet egy megadott elválasztó mentén stringek tömbjévé bontson.

## 2. Bejárati ajtó

- Az őr felmond egy verset, neked pedig külön sorokra kell bontanod a verset. Ehhez használhatsz egy már létező függvényt.
- Egy `for` ciklussal végigiterálhatsz a vers sorain.
- A string `first` tulajdonságával lekérheted a string első karakterét.
- Az egyes sorok első karakterének tárolásához használhatsz karakterek tömbjét vagy egy stringet.

## 3. Hátsó ajtó

- Az őr felmond egy verset, neked pedig külön sorokra kell bontanod a verset. Ehhez használhatsz egy már létező függvényt.
- Egy `for` ciklussal végigiterálhatsz a vers sorain.
- A string `last` tulajdonságával lekérheted a string utolsó karakterét.
- Az egyes sorok utolsó karakterének tárolásához használhatsz karakterek tömbjét vagy egy stringet.

## 4. Titkos szoba

- Az őr felmond egy verset, neked pedig külön sorokra kell bontanod a verset. Ehhez használhatsz egy már létező függvényt.
- Használhatsz egy `for` ciklust, amely a vers sorainak hosszán megy végig.
- A Swiftnek van egy [metódusa][indexing] arra, hogy egy string adott indexén lévő karaktert lekérje.
- A Swiftnek van egy [metódusa][uppercased] arra, hogy egy stringet nagybetűssé alakítson.

[indexing]: https://developer.apple.com/documentation/swift/string/index(_:offsetby:)
