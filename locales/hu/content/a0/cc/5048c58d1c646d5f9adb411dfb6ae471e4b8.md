# Bevezetés

Sok nyelvben létezik valami, például a `null` vagy a `none`, amivel egy nem létező értéket lehet jelölni.
Mivel az R-t nagy mennyiségű (gyakran rendezetlen) adat kezelésére tervezték, több formája is van a semminek.

A fő cél, hogy a hiányzó vagy gyanús értékeket megjelölje, amint előfordulnak, majd anélkül folytassa, hogy kivételt dobna.

## NULL

Ha egy érték valóban nem létezik, azt a `NULL` jelöli. Ez valószínűleg a legközelebb áll ahhoz, ahogy a C vagy a Python kezelné.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

Sok esetben a `NULL` értékeket egyszerűen figyelmen kívül hagyja:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Ha egy érték létezik, de nem tudjuk, mi az, akkor az `NA` értéket használjuk. Például amikor az úton haladó járműveket számolják, előfordulhat, hogy az emberi megfigyelők megbetegednek, vagy az automatikus érzékelők elromlanak, de a forgalom továbbra is folyik.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Így az `NA` egy helyőrző, amely figyelmezteti az embereket, hogy dönteniük kell arról, hogyan kezeljék.

## NaN

A `NaN` a „Not a Number” (magyarul: „nem szám”) rövidítése, és számítási problémát jelez olyan helyzetekben, amikor számot vártunk volna.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

Ez nem az egyetlen lehetőség az „érvénytelen” számításokra.
A nullával való osztás `Inf` vagy `-Inf` értéket ad vissza nem nulla számláló esetén, anélkül hogy hibát dobna.

```R
1 / 0
#> [1] Inf
```

## Üres vektorok

Talán meglepő, de az R-nek nincs szabványos módja az üresség ellenőrzésére.

Még egy üres vektor létrehozása sem teljesen nyilvánvaló.
Egy korábbi részben láttuk, hogy a `c()` argumentumok nélkül `NULL`-t ad vissza, nem vektort.

```R
is.vector(c())
#> [1] FALSE
```

Az olyan függvények, mint a `logical()` vagy az `integer()`, egy argumentumot várnak, amely megadja a kívánt hosszúságot, ami nulla is lehet.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Létrehozhatunk egy vektort, majd eltávolíthatjuk az összes elemét, ahogy a [Vektorok fogalom][concept-vectors] leírja.
Ez egy 0 hosszúságú, megfelelő típusú vektort eredményez.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
