# Utasítások

Ebben a feladatban kódot írsz majd, hogy segíts elkészíteni egy fantasztikus lasagnát a kedvenc szakácskönyvedből.

Négy részfeladat vár rád, amelyek mind a lasagna elkészítésével töltött időhöz kapcsolódnak.

## 1. A várható sütési idő meghatározása percben

Definiáld az `expectedMinutesInOven()` metódust, amely nem vesz át egyetlen paramétert sem, és visszaadja, hány percig kell a lasagnának a sütőben lennie. A szakácskönyv szerint a várható sütési idő 40 perc:

```java
Lasagna lasagna = new Lasagna();
lasagna.expectedMinutesInOven();
// => 40
```

## 2. A hátralévő sütési idő kiszámítása percben

Definiáld a `remainingMinutesInOven()` metódust, amely paraméterként átveszi, hogy a lasagna hány perce van a sütőben, és visszaadja, hány percig kell még a sütőben maradnia, az előző részfeladatban megadott várható sütési idő alapján.

```java
Lasagna lasagna = new Lasagna();
lasagna.remainingMinutesInOven(30);
// => 10
```

## 3. Az előkészítési idő kiszámítása percben

Definiáld a `preparationTimeInMinutes()` metódust, amely paraméterként átveszi a lasagnához adott rétegek számát, és visszaadja, hány percet töltöttél a lasagna előkészítésével, feltéve, hogy minden réteg elkészítése 2 percet vesz igénybe.

```java
Lasagna lasagna = new Lasagna();
lasagna.preparationTimeInMinutes(2);
// => 4
```

## 4. A teljes munkával töltött idő kiszámítása percben

Definiáld a `totalTimeInMinutes()` metódust, amely két paramétert vesz át: az első paraméter a lasagnához adott rétegek száma, a második pedig az, hogy hány perce van a lasagna a sütőben. A függvény adja vissza, hogy összesen hány percet dolgoztál a lasagna elkészítésén, ami az előkészítési idő és a lasagna által a sütőben eddig eltöltött idő összege.

```java
Lasagna lasagna = new Lasagna();
lasagna.totalTimeInMinutes(3, 20);
// => 26
```
