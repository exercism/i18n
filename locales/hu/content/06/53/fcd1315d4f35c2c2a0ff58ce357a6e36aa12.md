De a dolgok kissé rendezetlenek: úgy tűnik, Azara koordinátái másképp vannak formázva és rendezve, mint Ruiéi, és folyton egyik listáról a másikra kell pillantaniuk, hogy kitalálják, melyik kincs melyik helyszínhez tartozik.
Mivel feltörekvő fsharp-osok, hozzád fordultak segítségért, hogy írj egy kis programot (valójában függvények egy csoportját), amellyel jobban rendszerezhetik a vadászat adatait.

## 1. Koordináták kinyerése

Valósítsd meg a `getCooordinate()` függvényt, amely átvesz egy `(treasure, coordinate)` párt Azara listájáról, és csak a kinyert térképkoordinátát adja vissza.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. Koordináták formázása

Valósítsd meg a `convertCoordinate()` függvényt, amely átvesz egy `"2A"` formátumú koordinátát, és egy `(2, 'A')` formátumú tuple-t ad vissza.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. Koordináták egyeztetése

Valósítsd meg a `compareRecords()` függvényt, amely átvesz egy `(treasure, coordinate)` párt és egy `(location, coordinate, quadrant)` rekordot, majd összehasonlítja a bennük lévő koordinátákat.
Add vissza a **`true`** értéket, ha a koordináták „egyeznek”, és a **`false`** értéket, ha nem.
A pontos összehasonlításhoz formázd át a koordinátákat, ahogy szükséges.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. Az egyező rekordok összekapcsolása

Valósítsd meg a `createrecord()` függvényt, amely átvesz egy `(treasure, coordinate)` párt Azara listájáról és egy `(location, coordinate, quadrant)` rekordot Rui listájáról, majd visszaadja a `(coordinate, location, quadrant, treasure)` értéket, **ha a koordináták egyeznek**.
Ha a koordináták _nem_ egyeznek, adj vissza egy ugyanilyen alakú tuple-t, de `""` értékekkel kitöltve.
A pontos összehasonlításhoz formázd át a koordinátákat, ahogy szükséges.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
