# Utasítások

Írj egy függvényt, amely a közönséges számokat [sorszámnevekké](https://en.wikipedia.org/wiki/Ordinal_numeral) alakítja. A nullánál (0) egyszerűen add vissza a "0" értéket stringként.

A sorszámnevek olyan számok, amelyek leírják, hogy valami hányadik helyen áll egy listában. Ebben a szövegkörnyezetben fogjuk használni a sorszámneveket, mégpedig angol helyesírással írva őket.

A sorszámnevek (legalábbis ezek egyik formája) így néznek ki:

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

Tehát ha megadsz egy közönséges számot, megkapod a sorszámos megfelelőjét:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
