# Bevezetés

A Swiftben a `String` `Character` értékek rendezett gyűjteménye, amely ember által olvasható szöveget ábrázol. A Swift stringjei teljes mértékben támogatják a Unicode-karaktereket és az emojikat.

Stringet úgy hozol létre, hogy egy string literál segítségével idézőjelek (`"`) közé zárod a szöveget. A különleges karakterek escape-szekvenciákat használnak. A `\n` például egy újsor-karaktert jelöl, a `\"` pedig egy escape-elt idézőjelet egy string literálon belül.

Az üres stringet két idézőjel jelöli, amelyek között semmi sem áll (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
