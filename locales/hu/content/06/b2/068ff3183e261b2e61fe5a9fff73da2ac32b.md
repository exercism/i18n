# If, Elseif, Else

Az `if`, `elseif` és `else` kulcsszavakat használó feltételes utasítások a program vezérlési folyamatának alapvető részét képezik.
Az `if` utasítás kiértékel egy kifejezést, és ha az `true`, akkor végrehajtja a kód adott ágát.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Ha a kifejezés nem Boolean érték, akkor a kiértékelés határozza meg, hogy az érték igaznak vagy hamisnak számít-e.
A PHP-ban a következő értékek számítanak egyenlőnek a hamissal:

- Boolean `false`
- egész szám `0`
- tizedes tört `0.0` és `-0.0`
- üres tömb `[]`
- üres string `""` vagy numerikus string `"0"`
- `null`

Minden más érték igaznak számít.

## Több feltétel kezelése

Az `if` utasítás után az `elseif` és az `else` segítségével több feltételt is láncolhatsz egymáshoz.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Csak egyetlen igaznak értékelt feltételes utasítás fut le.
Ezért ha több feltétel is igazra értékelődhet, fontos a sorrendjük.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
