# Útmutatás

Ebben a feladatban egy általános (vagy inkább varázslatos!) TreasureChestet fogsz írni, hogy kincseket tárolj benne.

## 1. A TreasureChest típus definiálása

Definiálj egy `TreasureChest{T}` parametrikus típust két mezővel.

- Egy `password` mező `String` típussal, amely a kincsesláda jelszavát tárolja.
- Egy `treasure` mező `T` típussal, amely a kincset tárolja.
Ez az érték általános, így a kincs bármi lehet.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. A get_treasure() függvény definiálása

Ez a függvény két argumentumot vár.

- Egy `String` típust (a jelszó kipróbálásához)
- Egy `TreasureChest` típust

A függvénynek össze kell vetnie a megadott jelszókísérletet a `TreasureChest` `password` mezőjével.

- Ha a jelszavak megegyeznek, add vissza a kincset.
- Ha a jelszavak nem egyeznek meg, adj vissza `nothing`-ot.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. A multiply_treasure() függvény definiálása

Ez a függvény két argumentumot vár.

- Egy `n` egész szorzót.
- Egy `TreasureChest{T}` típust.

A függvény egy új `TreasureChest{Vector{T}}` értéket ad vissza, amelynek
- ugyanaz a jelszava, mint az eredetinek
- a megsokszorozott kincse egy `n` hosszúságú `Vector{T}`, benne az eredeti kincs `n`-szer megismételve.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
