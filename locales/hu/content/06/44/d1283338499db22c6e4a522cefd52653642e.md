# Bevezetés

A szerencsejátékokhoz kell valamilyen véletlenforrás. A Factor [`random`][random] szókészlete ad egy általános szót, a `random`-ot, amely alkalmazkodik ahhoz, amit átadsz neki, emellett segédszavakat a keveréshez és a mintavételhez, valamint egy módot arra, hogy a véletlent *reprodukálhatóvá* tedd a tesztekhez.

## Egy szó megjelölése `inline`-ként

A feladat néhány részfeladatában olyan szót definiálsz, amely argumentumként egy *quotation*t (egy `[ … ]` blokkot) kap, és lefuttatja azt. A Factornak van egy szigorú szabálya erről: **azt a szót, amely egy argumentumként kapott quotationt `call`-ol, `inline`-ként kell deklarálni**, ezt úgy írod le, hogy közvetlenül a záró `;` után odaírod az `inline` szót.

Az `inline` azt mondja a fordítónak, hogy a szó törzsét illessze be minden hívási helyre, ahelyett hogy egyszer, önmagában lefordítaná.

- A hívó quotationje közvetlenül beillesztődik, így **bármit hagy a quotation a vermen, az visszafolyik a hívóhoz**, pedig a szó saját veremhatása nem deklarál kimenetet.

Íme egy kis szó, amely `10`-et tesz a veremre, majd lefuttatja a kapott quotationt:

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

A veremhatása, `( quot -- )`, nem nevez meg kimenetet, mégis ha két *különböző* hatású quotationnel hívod meg, más-más eredményt kapsz, és mindegyik visszafolyik a hívóhoz:

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random`: egy elem

A `random` (a [`random`][random] szókészletben) generikus az argumentumára:

```
random ( obj -- elt )
```

- Ha egy **egész számot** `n` kap, egy véletlen egész számot ad vissza a `[0, n)` intervallumból:

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- Ha egy **sorozatot** kap, egy véletlen elemet ad vissza:

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

Egy szabályos dobókocka dobásához eggyel eltolod a tartományt: a `6`-ra hívott `random` 0-tól 5-ig ad értéket, így a `6 random 1 +` 1-től 6-ig.

## Több érték kihúzása

Ha rögzített számú véletlen húzást szeretnél összegyűjteni, ismételj meg egy quotationt a `replicate` szóval (a [`sequences`][sequences] szókészletből):

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize`: helyben keverés

A `randomize` (a [`random`][random] szókészletben) a sorozatot véletlen sorrendű elemekkel adja vissza:

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

**Helyben** keveri a sorozatot, és ugyanazt a sorozatot adja vissza, ezért előbb `clone`-ozd, ha meg akarod tartani az eredeti sorrendet.

## `sample`: több különböző elem

A `sample` (a [`random`][random] szókészletben) `n` *különböző* elemet húz egy sorozatból, akárcsak egy kártyapakli osztásakor, ahol ugyanaz a lap soha nem kerül elő kétszer:

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

Ha több elemet kérsz, mint amennyi a sorozatban van, az hiba.

## Reprodukálható véletlen

Alapértelmezés szerint a `random` egy globális generátorból húz, amelyet a rendszeróra alapján indít el, így minden futás más. Tesztekhez, vagy amikor olyan játékot szeretnél, amelyet *újra le tudsz játszani*, köss egy generátort egy rögzített **mag** értékhez.

A `<mersenne-twister>` (a [`random.mersenne-twister`][mt] szókészletben) egy egész szám magból épít generátort, a `with-random` (a [`random`][random] szókészletben) pedig lefuttat egy quotationt azzal a generátorral beállítva:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

A quotationön belül minden, a `random`, a `randomize` és a `sample`, a beállított maggal rendelkező generátorból húz, így ugyanaz a mag mindig ugyanazt az eredményt hozza.

Az a szó, amely argumentumként quotationt kap, és `with-random`-on keresztül futtatja, az [Egy szó megjelölése `inline`-ként](#marking-a-word-inline) szakaszban leírt szabály alá esik: a `with-random` végül `call`-olja azt a quotationt, ezért az ilyen burkolót `inline`-ként kell megjelölni.
