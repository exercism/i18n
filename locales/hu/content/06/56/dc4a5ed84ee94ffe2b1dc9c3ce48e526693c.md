# Bevezetés

A PHP számos operátort kínál aritmetikai műveletek elvégzésére. Az aritmetikai operátorainál a PHP a szokásos matematikai műveleti sorrendet követi. A PHP a következő operátorokat biztosítja:

* Identitás (+)
* Negáció (-)
* Összeadás (+)
* Kivonás (-)
* Szorzás (*)
* Osztás (/)
* Modulo (%)
* Hatványozás (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
