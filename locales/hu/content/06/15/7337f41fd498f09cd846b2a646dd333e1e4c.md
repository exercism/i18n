# Bevezetés

A repeat-while ciklusok hasonlóak a while ciklusokhoz, azonban abban különböznek tőlük, hogy a Boolean kifejezés a ciklus törzsének végrehajtása _után_ jelenik meg, és ekkor értékelődik ki. Ezért ezek a ciklusok mindig legalább egyszer lefutnak.

```swift
repeat {
  print("This runs at least once")
} while false
print("Loop done")

// prints:
// This runs at least once
// Loop done
```
