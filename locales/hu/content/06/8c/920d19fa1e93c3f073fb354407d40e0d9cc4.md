# Bevezetés

Azokat a típusokat, amelyek megvalósítják az `IEnumerable<T>` interfészt, _felsorolhatónak_ nevezzük. Minden beépített gyűjteménytípus megvalósítja ezt az interfészt.

Egy felsorolható típuson `foreach` ciklussal iterálhatunk:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Ahhoz, hogy egy típus megvalósítsa az `IEnumerable<T>` interfészt, egyetlen metódust kell megvalósítania: `IEnumerator<T> GetEnumerator()`. Ahogy látható, a felsorolható típus magát a gyűjtemény fölötti iterálást egy `IEnumerator<T>` típusra bízza. Ezen az interfészen egy tulajdonságot és három metódust kell megvalósítani:

- `public T Current { get; }`: az aktuális elemet adja vissza.
- `public bool MoveNext ();`: átlép a következő elemre, és `true`-t ad vissza, ha a következő elemre lépés sikeres volt, `false`-t pedig, ha nem (nincs több elem).
- `public void Reset ();`: visszaállítja a felsorolót a kezdeti állapotába, azaz az első elem előtti állapotba.
