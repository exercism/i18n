# Kiegészítés az utasításokhoz

## Hogyan épül fel ez a feladat a Python-kurzusban?

A feladat tesztjei azt várják, hogy a programodat egy Garden [`class`][classes in python]-ként valósítsd meg (_lásd még: [concept:python/classes]()_).
Ha még nem ismered a Python osztályait, ez a [Real Python útmutató][how-to-make-a-class] jó további kiindulópont lehet.

A `class`-ednek implementálnia kell egy `plants` nevű [`method`][methods]-ot, amely argumentumként egy tanuló nevét kapja, és visszaadja a tanulóhoz tartozó növénynevek `list`-jét.


## Konstruktorok

A példakert létrehozása:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

Ez a tesztekben így jelenne meg: `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`.

Ahhoz, hogy ez a reprezentáció működjön, a `class`-ednek implementálnia kell egy [`__init__()`][init] [speciális metódust][special-methods].
Ha nem ismered a `__init__()`-et vagy a [_konstruktorokat_][what-is-a-constructor], a Python dokumentációjának [osztály- és példányobjektumok][class vs instance objects in python] című része részletesebb magyarázatot ad.


## Alapértelmezett paraméterek

Néhány tesztben a tanulók egy `list`-jét adják át argumentumként az `__init__()`-nek.
Ennek felül kell írnia a feladatkiírásban megadott tizenkét tanulós névsort.
Mindkét utasításnak működnie kell az `__init__()` metódusoddal:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

Az egyik megközelítés, hogy a tanulók `list`-jét [alapértelmezett argumentummá][default argument values] alakítod; a Python dokumentációja részletesen ír a `default parameters`-ről, miközben a [függvénydefiníciókat][function definitions] is elmagyarázza.
