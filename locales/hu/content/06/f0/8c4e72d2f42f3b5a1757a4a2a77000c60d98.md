# Bevezetés

A **reguláris kifejezések** (regexek) olyan karaktersorozatok, amelyek egy szövegben keresendő mintát határoznak meg.

A reguláris kifejezések szintaxisának megtanulása meghaladja e témakör kereteit.
Arra összpontosítunk, milyen kifejezéseket kínál a `jq` a reguláris kifejezések használatához.

## A reguláris kifejezések változata

A különböző eszközök a reguláris kifejezések különböző változatait valósítják meg.
A `jq` az [Oniguruma][oniguruma] reguláris kifejezés könyvtárat építi be, amely nagyrészt kompatibilis a Perl v5.8 reguláris kifejezéseivel.

A `jq` által használt konkrét szintaxis [megtalálható az Oniguruma GitHub-tárolójában][onig-syntax].

<!-- prettier-ignore -->
~~~~exercism/caution
A `jq`-nak nincs különleges szintaxisa a reguláris kifejezésekhez.
Ezeket egyszerűen stringként fejezzük ki.
Ez azt jelenti, hogy a reguláris kifejezésben szereplő backslash karaktereket escape-elni kell a stringben.

Például a számjegyeket jelölő karakterosztályt (`\d`) így kell írni: `"\\d"`.
~~~~

<!-- prettier-ignore-end -->

## A reguláris kifejezések függvényei

A `jq`-ban a reguláris kifejezések használata [néhány szűrőre][jq-regex-funcs] korlátozódik.

### Egyszerű illesztés

Ha tudni szeretnéd, hogy egy string illeszkedik-e egy mintára, használd a `test` szűrőt.

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

Ez a szűrő _boolean_ eredményt ad vissza.

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### Információk az illesztésről

Ha ki szeretnéd nyerni azt a részstringet, amely ténylegesen illeszkedett a mintára, használd a `match` szűrőt.

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

Ez a szűrő a következőt adja vissza:

- semmit, ha nem volt illesztés, vagy
- egy objektumot, amely különféle tulajdonságokat tartalmaz, ha volt illesztés.

Ez a példa két egymást követő, azonos magánhangzót keres a visszahivatkozás szintaxisával, `\1`.

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

A `match` szűrő _minden_ illesztéshez egy objektumot ad vissza.
Ez a példa a `"g"` jelző működését mutatja be, amellyel az összes magánhangzót megtalálhatod.

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### Elkapott részstringek

A `match` szűrőhöz hasonlóan a `capture` szűrő is objektumot ad vissza, ha volt illesztés.

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

A visszaadott objektum a **nevesített elkapások** leképezése.

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### Csak a részstringek

A `scan` szűrő hasonló a `"g"` jelzővel ellátott `match` szűrőhöz.

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

A `scan` részstringek _folyamát_ adja vissza.

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

A részstringek összegyűjtéséhez használd a `[...]` tömbkonstruktort.

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### Egy string felosztása

Ha tudod, hogy a string mely részeit szeretnéd **megtartani**, használd a `match` vagy a `scan` szűrőt.
Ha tudod, mely részeit szeretnéd **elvetni**, használd a `split` szűrőt.

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
Az **egyargumentumos** `split` szűrő a paraméterét **rögzített stringként** kezeli.

Ha reguláris kifejezést szeretnél használni a `split` szűrővel, **meg kell** adnod a második argumentumot; az üres string is megfelel.
~~~~

<!-- prettier-ignore-end -->

Egy példa, amely egy stringet tetszőleges whitespace karakterek mentén bont fel.

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### Helyettesítések

A `sub` és a `gsub` szűrő átalakíthatja a bemeneti stringet: a bemenet illeszkedő részeit egy helyettesítő stringgel cseréli ki.

Ha csak az első illesztést szeretnéd kicserélni, használd a `sub` szűrőt.
Ha az összes illesztést, akkor a `gsub` szűrőt.

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

A helyettesítő szöveg hivatkozhat az illeszkedő részstringekre; használj nevesített elkapásokat és [string-interpolációt][jq-interp].

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## Jelzők

A fenti szűrők mindegyikében a FLAGS egy string, amely a támogatott jelzők közül nulla vagy több jelzőből áll.

- `g` - globális keresés (az összes illesztést megtalálja, nem csak az elsőt)
- `i` - kis- és nagybetűt nem megkülönböztető keresés
- `m` - többsoros mód (a '.' az újsorokra is illeszkedik)
- `n` - az üres illesztések figyelmen kívül hagyása
- `p` - az s és az m mód is engedélyezve van
- `s` - egysoros mód ('^' -> '\A', '$' -> '\Z')
- `l` - a lehető leghosszabb illesztések keresése
- `x` - kiterjesztett regexformátum (a whitespace-t és a megjegyzéseket figyelmen kívül hagyja)

Például

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
