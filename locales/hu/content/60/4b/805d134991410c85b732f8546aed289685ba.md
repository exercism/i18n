# Névjegy

A felsorolás során végigmegyünk egy gyűjteményen (`Array`, `Hash` stb.), és minden objektumon végrehajtunk valamilyen műveletet.

A felsorolás kulcsfontosságú fogalom a Rubyban, és olyan feladatokhoz használjuk, mint a rendezés (`sort_by`), a csoportosítás (`group_by`), a leképezés (`map`), a redukálás (`reduce`), és még sok más.
Leggyakrabban a felsorolás jelenti a gyűjteményeken való végigmenés idiomatikus módját, nem pedig a ciklusok használata.

Egy egyszerű felsorolás, amely egy tömb minden szavát kiírja, így nézne ki:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

Ebben a példában az `Array#each` metódust hívtuk meg, és átadtunk neki egy _blokkot_, amely egy paramétert (`word`) kap, és kiírja azt.

A felsoroló metódusokat is láncolhatjuk.
Például az `each`-re fűzhetjük a `.with_index` metódust, hogy egy objektum indexét és az értékét is kiírjuk:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

A `Hash` objektumok felsorolása pontosan ugyanaz, mint az `Array` objektumoké, azzal a különbséggel, hogy a blokk két argumentumot kap: a kulcsot és az értéket:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

A fentebb leírt metódusok az [`Enumerable` modul][enumerable-module] részei, amely benne van az `Array`-ben, a `Hash`-ben és más olyan osztályokban is, amelyeknek szükségük van a felsorolás képességére.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
