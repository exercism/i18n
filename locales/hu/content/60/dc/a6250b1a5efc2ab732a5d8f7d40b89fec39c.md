# A nyelvről

A Batch szkriptelés egy szkriptnyelv, amelyet elsősorban parancsok futtatására használnak a Windows Command Prompt (cmd.exe) környezetében.
Segítségével a felhasználók automatizálhatják a feladatokat, kezelhetik a fájlokat és irányíthatják a rendszerkörnyezetet parancssori utasítások sorozatán keresztül.

Bár a Batch szkriptelés egyszerű, a feladatok széles skáláját képes kezelni, az egyszerű fájlműveletektől a bonyolultabb automatizálási folyamatokig.

A Batch-fájlok kiterjesztése `.bat` vagy `.cmd`, és a Windows parancsértelmezője közvetlenül futtathatja őket.

Rugalmasságának köszönhetően a Batch szkriptelés hatékony eszköz a rendszergazdák, a fejlesztők és a haladó felhasználók számára, akiknek rendszeres feladatokat kell automatizálniuk, vagy egyéni parancssori eszközöket szeretnének készíteni.
