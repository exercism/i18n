# Tippek

## Általános

- Az olvasó szavak a [`io`][io] szótárban élnek; a string-stream
  konstruktorok és a `with-string-writer` pedig az
  [`io.streams.string`][io.streams.string] szótárban.
- Az író kiürítésével foglalkozó részfeladatnál a lokálisok (`::` és `:>`)
  olvashatóan tartják a törzset, amikor kétszer kell ugyanahhoz a
  streamhez nyúlnod.

## 1. Hallgasd végig az egészet

- Egy szó: `stream-contents`.

## 2. Számold meg az üzeneteket

- A `stream-lines` sorok tömbjére bontja a streamet;
  a `length` adja vissza a darabszámot.

## 3. Verd vissza az utolsó hívást

- Ugyanaz a `stream-lines`, mint fentebb, aztán a `last`, majd a `>upper` (az
  `ascii` szótárból).

## 4. Sugározz ki egy üzenetet

- A `stream-write` írja az üzenetet, a `stream-flush` tolja ki. Az írót
  kétszer használod, ezért nyúlj a `::` lokálisokhoz:
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. Rögzítsd egy quotation kimenetét

- Egy szó: `with-string-writer`. A záró `;` után tedd be az `inline`
  kulcsszót, hogy a fordító átlásson a quotation argumentumon:
  `: capture ( quot -- captured ) with-string-writer ; inline`.
