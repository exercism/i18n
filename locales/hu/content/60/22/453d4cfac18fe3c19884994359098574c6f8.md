# Bevezetés

## Összehasonlítás

A Go-ban a számokat a következő relációs és egyenlőségoperátorokkal hasonlíthatod össze.

| Összehasonlítás   | Operátor  |
| ------------------| --------- |
| egyenlő           | `==`      |
| nem egyenlő       | `!=`      |
| kisebb            | `<`       |
| kisebb vagy egyenlő | `<=`    |
| nagyobb           | `>`       |
| nagyobb vagy egyenlő | `>=`   |

Az összehasonlítás eredménye mindig egy Boolean érték, tehát vagy `true`, vagy `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

A fenti összehasonlító operátorokkal stringeket is össze lehet hasonlítani.
Ilyenkor lexikográfiai (szótári) sorrend érvényesül.
Például:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## Elágazások

A Go feltételes elágazásai hasonlók más nyelvekéhez.
Bármely feltételes művelet mögöttes típusa a `bool` típus, amelynek az értéke `true` vagy `false` lehet.
A feltételes elágazásokat gyakran vezérlési mechanizmusként használjuk különféle feltételek ellenőrzésére.

Egy adott eset ellenőrzésére `if` utasítást használhatsz, amely akkor futtatja a kódját, ha a mögöttes feltétel `true`, például így:

```go
var value string

if value == "val" {
    return "was val"
}
```

Ha egynél több esetről van szó, több `if` utasítást is összefűzhetsz az `else if` és az `else` utasításokkal.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Az `if` utasítás tartalmazhat egy rövid kezdőérték-utasítást is, amellyel egy vagy több változót inicializálhatsz az `if` utasításhoz.
Például:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> Megjegyzés: a kezdőérték-utasításban létrehozott változók az `if` utasítás végén kikerülnek a scope-ból.
