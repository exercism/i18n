# Osztály statikus kulcsszavai

A PHP-ban az osztály a kódszervezés egysége, amely gyakran egy dolog, szolgáltatás vagy eljárás példányát képviseli.
A `static` és `self` kulcsszavak használatával a tulajdonságok és metódusok az osztályra vonatkoztatva létezhetnek minden példány számára (vagy egyetlen példány nélkül is).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Korlátozás

A statikus osztálymetódusok csak a saját osztályuk más statikus tulajdonságait vagy osztálymetódusait hívhatják meg.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
