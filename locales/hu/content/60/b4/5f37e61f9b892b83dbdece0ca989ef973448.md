# Bevezetés

Az Elmben az [egyedi típusok][custom-types] meghatározott számú elnevezett esetet jelölnek. Minden érték pontosan az egyik elnevezett esetnek felel meg.

Az egyedi típust a `type` kulcsszóval definiáljuk, és ehhez nagyon kevés szintaxisra van szükség. Az Elm-programozás egyik legfontosabb technikái közé tartoznak: a segítségükkel a kódban lehetséges értékek pontosan megfelelnek a való életben érvényes értékeknek, ami nem hagy helyet az érvénytelen adatoknak, és [lehetetlenné teszi, hogy a lehetetlen állapotokat leképezzük a kódban][impossible-states].

```elm
type Season
    = Spring
    | Summer
    | Autumn
    | Winter
```

Az egyedi típus minden esetéhez opcionálisan kapcsolódhat adat, és a különböző esetekhez különböző típusú adat tartozhat. Ha egyik esethez sem kapcsolódik adat, akkor ez a diszkriminált unió ahhoz hasonló, amit más nyelvek általában _felsorolásnak_ (vagy _enum_) neveznek.

```elm
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

Egy adott esethez tartozó értéket létrehozhatunk úgy, hogy a nevére hivatkozunk (`Spring`), amikor ugyanabban a modulban van definiálva, vagy az `import SeasonModule exposing (Season(..))` stílusú szintaxissal importáltuk, illetve úgy, hogy a teljesen minősített nevére hivatkozunk (`Season.Spring`), amikor az `import SeasonModule exposing (Season)` stílusú szintaxissal importáltuk.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

Az egyedi típusoknak, ahogy az Elmben mindennek, _strukturális egyenlőségük_ van, ami azt jelenti, hogy két érték, amely ugyanahhoz az esethez tartozik és ugyanazzal az (opcionális) adattal rendelkezik, egyenértékű.

Az egyedi típusokkal való munkához a [mintaillesztést][pattern-matching] érdemes használni:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
