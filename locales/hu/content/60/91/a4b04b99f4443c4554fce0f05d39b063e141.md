# Bevezetés

A Swiftben a stringek karakterek gyűjteményei, ahol a karakterek többé-kevésbé egyetlen nyomtatható elemet jelentenek. A Swift stringjei ezért Unicode-karaktereket és emojikat is tartalmazhatnak.

A stringeket Swiftben egyszerűen létrehozhatod string literálokkal. A string literálok ahhoz hasonlítanak, amit sok más programozási nyelvben láthatsz: karakterek egy pár idézőjel (`"`) között. Bizonyos karakterek külön jelölést használnak a stringeken belül, hogy helyesen lehessen ábrázolni őket. Ilyen például az újsor-karakter, amelyet `\n`-ként írunk a stringeken belül, vagy az idézőjel, amelyet `\"`-ként írunk le egy stringen belül, így a fordító tudja, hogy nem ez az idézőjel zárja le a stringet.

Az üres stringet két idézőjel jelöli, amelyek között semmi sem áll.

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
