# Bevezetés

## Névterek

A névterekkel összetartozó kódot csoportosíthatsz, és elkerülheted a névütközéseket. A legegyszerűbb kódbázisok kivételével gyakorlatilag mindenhol megtalálhatók.

A szintaxis a következő:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

A névterekbe zárt típusokra a névtér scope-ján kívül úgy hivatkozunk, hogy a típusnév elé pontszintaxissal odaírjuk a névtér nevét. Másik, gyakrabban használt megoldás, hogy a fájl elejére (vagy egy névtérbe) beírsz egy `using` direktívát, és akkor a típus az előtag nélkül is használható. Ugyanazon a névtéren belül nem kell minősítened a típusneveket.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

Egy névtérnek álnevet is adhatsz a `using MyAlias = MySpace;` szintaxissal, majd az álnevet bárhol használhatod, ahol magát a névteret is használhatnád.
