# Bevezetés

A `Result` típus lehetővé teszi, hogy egy függvény egyetlen értékkel jelezze a következőket:

- hogy a művelet sikeres volt-e vagy sem
- siker esetén a művelet eredményértékét
- hiba esetén a hiba okát

## Használat

A `Result` egy generikus típus, amely két mögöttes típust tartalmaz:

- a sikeres művelet eredményének a típusát
- a hiba okát reprezentáló típust

A `Result` típus emellett egy [diszkriminált unió][discriminated-union], amelynek a következő esetei lehetnek:

- `Ok <value>`, amely egy sikeres eredményt képvisel
- `Error <reason>`, amely egy hibát képvisel

A következő függvény megmutatja, hogyan hozhatsz létre egy `Result` értéket:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

Ebben a példában az `Ok` érték egy string (a megadott név), az `Error` érték pedig szintén egy string (a hiba oka, ember számára olvasható formában).

## Egy `Result` érték tartalmának kiolvasása

Vegyük a következő típusdefiníciót és függvényszignatúrát:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

Az `openFile` függvényt meghívó kód mintaillesztéssel kezelheti a sikeres és a hibás eseteket, ahogy a következő példa mutatja:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
