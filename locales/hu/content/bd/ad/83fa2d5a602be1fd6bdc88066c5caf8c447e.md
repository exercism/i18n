# Bevezetés

## Erőforrás élettartama

[concept:csharp/resource-cleanup]() az `IDispose` interfészt használja annak jelzésére, hogy egy objektum erőforrását vagy más programállapotát fel kell szabadítani vagy vissza kell állítani, amikor az objektumra már nincs szükség (és hogy a szemétgyűjtőre támaszkodva ez nem valósulna meg, illetve nem biztosítaná a szükséges szintű kontrollt), valamint hogy az `IDisposable.Dispose()` metódus a természetes hely az ilyen takarítási műveletekhez.

Létezik egy másik szerkezet is, a `using` blokk, amely a hívó szemszögéből lehetővé teszi, hogy az összes erőforrás élettartamának kezelését egyetlen utasításba gyűjtsük.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

A fenti példában a `file`-hoz kapcsolódó fájlrendszer-erőforrások visszaadódnak az operációs rendszernek, amikor a `using` blokkból kilépünk.

Ahhoz, hogy a minta működjön, a `using` utasításban szereplő változónak referenciatípusnak kell lennie, amely megvalósítja az `IDisposable` interfészt, és a `Dispose()` metódusában fel kell szabadítania az erőforrásokat, illetve vissza kell állítania a program állapotát.

A C# 8 finomítást vezet be a mintába. A `using` utasítás egy blokk elejére helyezhető.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

A Java-fejlesztők felismerhetik ezt a Java 7-ben bevezetett _automatikus erőforrás-kezelés_ mechanizmus analógjaként.
