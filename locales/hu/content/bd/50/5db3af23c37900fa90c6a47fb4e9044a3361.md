# Kiegészítés az utasításokhoz

## Építsd meg a saját DSL-ed

Ebben a feladatban teljesen szabadon megtervezheted a gráf-DSL-t, amelyről mindig is álmodtál.

A tesztek csupán néhány konkrét gráf létrehozását kérik, azt viszont teljesen rád bízzák, hogyan építed fel őket.

Hogy megduplázd a szórakozást, ha kedved tartja, megvalósíthatsz egy `to_dot` függvényt is, amely a gráfodat DOT formátumra alakítja!

## A gráf reprezentációja

A DSL-edet a `Graph.roc` fájlban definiáld, majd ezzel építsd fel a vázban kért gráfokat.
Az egyes `EdgeId`-kban szereplő két csomópont-azonosítót ábécésorrendben kell megadni.

| Definíció | Felépítendő gráf |
| --- | --- |
| `empty_graph` | Egy üres gráf |
| `graph_with_one_node` | Egy csomópont |
| `graph_with_one_node_with_attribute` | Egy csomópont egy attribútummal |
| `graph_with_one_edge` | Egy él |
| `graph_with_one_attribute` | Egy gráf-attribútum |
| `graph_with_nodes_edges_and_attributes` | Csomópontok, élek és attribútumok |
| `multiple_edges_on_one_line` | Több él egy sorban |
| `only_1_edge_between_nodes` | Csak egy él az egyes csomópontpárok között |
