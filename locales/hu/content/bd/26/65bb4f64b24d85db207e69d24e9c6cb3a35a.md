# Debug

Amikor egy teszt sikertelen, egy üzenet jelenik meg arról, hogy mi ment rosszul, és melyik bemenetnél. A programodban tetszőleges értékeket vizsgálhatsz meg úgy, hogy átadod őket a `debug` metódusnak (ez az `exercism/test_runner` modulból érhető el). Ez rögzíti az értékeket, és megmutatja a kimenetet.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
