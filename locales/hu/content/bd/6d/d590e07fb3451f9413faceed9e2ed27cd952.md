# Tudnivalók

## Öröklődés

A Java az egyik alapszolgáltatásaként támogatja az öröklődést, amivel számos objektumorientált elvet, például az absztrakciót is megvalósíthatsz.

Egy osztály kiterjeszthet egy másik osztályt az `extends` kulcsszóval, és örökölhet egy interfésztől az `implements` kulcsszóval.

## Hozzáférési módosítók

A hozzáférési módosítók azt szabályozzák, hogy egy osztály tagváltozóihoz és metódusaihoz más osztályok (vagy a kód bármely más része) hogyan férhetnek hozzá.

Négy hozzáférési módosító létezik:

- `private`
- `public`
- `protected`
- alapértelmezett (nem kell kulcsszó)

Ezekről [ebben a cikkben][access-modifiers] olvashatsz többet.

## Öröklődés vagy kompozíció

Ez a két fogalom nagyon hasonló, ezért gyakran összekeverik őket.

- Az öröklődésnél a gyermekosztály IS-A kapcsolatban áll a szülőosztályával.

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

Itt a `Dog` IS-A `Animal`

- A kompozíció HAS-A kapcsolatot fejez ki.

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

Itt a `Car` HAS-A `Engine`
