# Bevezetés

## Első lépések

### Változók

Egy [változó][constants-variables] definiálásával értékeket tárolhatsz el és láthatsz el névvel.
A változó definiálása után a nevével az egész kódodban erre az értékre hivatkozhatsz.
A változók _módosíthatók_, ami azt jelenti, hogy az értékük a definiálásuk után is megváltozhat.

A változót a `var` kulcsszóval definiálod:

```swift
var variableName = 10
```

A Swift statikusan típusos nyelv, ami azt jelenti, hogy minden értéknek már fordítási időben ismert a típusa.
A típust vagy explicit módon megadhatod [típusannotációval][type annotations], vagy hagyhatod, hogy a Swift fordító a hozzárendelt értékből [kikövetkeztesse a típust][type-inferring]:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Egy változó értékét az értékadó operátorral (`=`) frissítheted:

~~~~exercism/note
A változó típusa a deklarálás után nem változhat meg.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

A változót kezdőérték nélkül is deklarálhatod, ha megadod a típusát, de használat előtt értéket kell adnod neki:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Konstansok

A [konstansok][constants-variables] szintén nevet rendelnek egy értékhez, de az értékük az értékadás után nem változtatható meg.
Ezek _módosíthatatlanok_.
A konstanst a `let` kulcsszóval definiálod:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Aritmetikai operátorok

A Swift szabványos [aritmetikai operátorokat][arithmetical-operators] biztosít az alapvető számításokhoz:

- Összeadás: `+`
- Kivonás: `-`
- Szorzás: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Függvények

A Swiftben a [függvények][functions] önálló kódrészek, amelyek egy adott feladatot látnak el.
A függvények fogadhatnak bemeneteket, adhatnak vissza értéket, és értékként továbbadhatók más függvényeknek.
A függvényt a `func` kulcsszóval definiálod, amelyet a függvény neve, zárójelbe írt paraméterlista és egy opcionális visszatérési típus követ:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

A Swift-függvények [argumentumcímkéket][argument-labels] használnak, amelyektől a kód úgy olvasható, mint a természetes mondatok:

- Az **argumentumcímkét** a függvény hívásakor használod.
- A **paraméternevet** a függvény törzsén belül használod az érték eléréséhez.

Ha csak egy nevet adsz meg, a Swift azt argumentumcímkeként és paraméternévként is használja:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Ha nem szeretnél argumentumcímkét a függvény hívásakor, írj egy alulvonást (`_`) a paraméternév elé:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Minden függvényparaméter alapértelmezés szerint konstans (`let`), ami azt jelenti, hogy az értékük a függvény törzsén belül nem módosítható.

Ahhoz, hogy egy függvény értéket adjon vissza, a `->` után meg kell adnod a visszatérési típust, és használnod kell a `return` kulcsszót:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Ha egy függvény nem ad vissza értéket, a visszatérési típusa `Void` (ami egy üres tuple-lal egyenértékű, azaz `()`).
Az ilyen függvényeknél elhagyhatod a `-> Void` visszatérési típust és a `return` utasítást is.

### Megjegyzések

A Swift kétféle [kommentet][comments] támogat:

- Az **egysoros kommentek** `//`-tal kezdődnek, és a sor végéig tartanak.
- A **többsoros kommenteket** `/*` és `*/` közé írod.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
