# Bevezetés

A _string_ a JavaScript szöveges adatok tárolására szolgáló adattípusa.

## String létrehozása

Úgy hozol létre egy stringet, hogy a szöveget egyszeres vagy kétszeres idézőjelbe foglalod.
Az Exercism-ön egyszeres idézőjeleket használunk.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## A stringek karakterek listájaként

A stringet tekintheted karakterek listájaként, ahol az első karakter indexe `0`.
Egy string egyes karaktereit szögletes zárójelekkel és a kívánt betű indexével érheted el.

```javascript
'cat'[1];
// => 'a'
```

A string karaktereinek számát a `length` tulajdonság elérésével állapíthatod meg.

```javascript
'cat'.length;
// => 3
```

## Összefűzés és metódusok

A stringek összefűzésének legegyszerűbb módja a `+` összeadásoperátor használata.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

A stringek rengeteg segédmetódust kínálnak, a teljes listát lásd az [MDN dokumentációjában a stringmetódusokról][mdn-string-methods].
Az alábbi lista néhány gyakran használt segédmetódust mutat be.

- [`toUpperCase`][mdn-to-upper-case] és [`toLowerCase`][mdn-to-lower-case] - az összes karakter kis- és nagybetűs írásmódját változtatja meg
- [`trim`][mdn-trim] - eltávolítja a szóközöket az elejéről és a végéről
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] és [`endsWith`][mdn-ends-with] - meghatározza, hogy egy másik string része-e az adott stringnek
- [`slice`][mdn-slice] - egy szakaszt emel ki a stringből

A stringek megváltoztathatatlanok JavaScriptben. Ezért egy „módosítás”, például a fenti metódusok valamelyikével, mindig új stringet hoz létre helyette.
