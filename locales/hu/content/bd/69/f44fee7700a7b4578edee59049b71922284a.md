# Utasítások

Ebben a feladatban középiskolás szerelmespároknak segítesz szerelmet vallani a közösségi médiában azzal, hogy unicode szívet generálsz a kezdőbetűikből:

```
❤ J.  +  M. ❤
```

## 1. Tisztítsd meg a nevet

Valósítsd meg a `cleanupname` metódust.
Ez kap egy nevet, eltávolít belőle minden `-` karaktert, és szóközre cseréli őket.
A név elejéről és végéről is eltávolít minden whitespace-t.

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. Kérd le a név első betűjét

Valósítsd meg a `firstletter` metódust.
Ez kap egy nevet, és visszaadja annak első betűjét stringként.
Ügyelj rá, hogy újrahasználd a korábbi lépésben definiált `cleanupname`-t, és más függvényekkel komponálva építsd fel.

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. Alakítsd az első betűt iniciálévá

Valósítsd meg az `initial` metódust.
Ez kap egy nevet, és visszaadja annak első betűjét nagybetűvel, egy ponttal a végén.
Ügyelj rá, hogy újrahasználd a korábbi lépésben definiált `firstletter`-t.

```julia-repl
initial("Robert")
"R."
```

## 4. Tedd az iniciálékat a szívbe

Valósítsd meg a `couple` metódust.
Ez két nevet kap, és az iniciálékat emoji szívekkel körbevéve adja vissza.
Ügyelj rá, hogy újrahasználd a korábbi lépésben definiált `initial`-t.

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
