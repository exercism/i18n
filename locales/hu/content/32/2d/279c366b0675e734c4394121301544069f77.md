# Bevezetés

Néha nincs szükséged arra a többletre, amivel egy állapottal rendelkező objektum létrehozása jár. Ilyen esetekben `module`-t használhatsz.

A modul nagyon hasonló egy osztályhoz (valójában a `Module` a `Class` őse az objektumhierarchiában). A fő különbség az, hogy nem példánymetódusokat, hanem osztálymetódusokat használunk. Az osztálymetódusok a `self.` előtaggal kezdődnek, és közvetlenül a modulon hívjuk meg őket.

Például:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
