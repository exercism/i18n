# Bevezetés

Az `if` elágazás mellett a JavaScriptben ott van a `switch` utasítás is, amellyel feltételesen hajthatsz végre kódot.
Akkor használjuk, amikor egyetlen változót több értékkel kell összehasonlítani.
Az összehasonlítás szigorú egyenlőség (`===`) vizsgálatával történik, lásd [az összehasonlítás fogalmát][concept-comparison].
Egy `x` változó esetén a JavaScript `switch` utasítása a következő szintaxissal rendelkezik.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

A `default` eset elhagyható, és akkor használjuk, amikor szeretnél futtatni valamilyen kódot, ha a változó egyik másik értékkel sem egyezik.

A fenti `break` utasításokra azért van szükség, mert a JavaScriptben alapértelmezés szerint az összes eset „átesik” a következőre.
Ez azt jelenti, hogy `break` utasítás nélkül az első egyező érték alatti összes eset kódja lefutna, még akkor is, ha `x` nem egyezett azokkal az értékkel.
Ez az alapértelmezett „átesés” gyakori buktató, amikor `switch`-et használsz JavaScriptben.
Egy függvényen belül a probléma elkerülésére a `break` helyett `return`-t is használhatsz.
