# A fogalomról

Amikor Haskell-függvényeket írunk, használhatjuk a [mintaillesztést][pattern-matching].
A mintaillesztés a Haskell egyik nagyon erős eszköze, amellyel adatkonstruktorokra illeszkedhetsz, és változókat köthetsz a bennük lévő értékekhez.
Ahogy a neve is sugallja, értékeket illesztünk mintákra, és ha az érték illeszkedik a mintára, változókat köthetünk a mintában lévő értékekhez.
A mintaillesztés főként ezekből az építőelemekből áll: értékek felismerése, változók kötése és értékek szétbontása.

~~~~exercism/note
A mintaillesztés az olyan nyelvekben, mint az Elixir, kicsit eltér a Haskell mintaillesztésétől.
Az Elixir például engedélyezi, hogy ugyanaz a kötésnév többször szerepeljen egy mintában, a Haskell viszont nem.
~~~~


Vegyük például ezt a függvényt:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Itt van egy `lucky` függvény, amely egy `Int`-et vár, és egy `String`-et ad vissza.
Két mintát definiáltunk a függvényhez: az egyik a `7` számra illeszkedik, a másik bármely más számra. A név bármi lehet (amíg követi a Haskell elnevezési konvencióját), de itt `x`-et használunk.
Ha a szám `7`, a függvény a `"Lucky number seven!"` értéket adja vissza, különben a `"Sorry, you're out of luck, pal!"` értéket.
Fontos megjegyezni, hogy a minták fentről lefelé ellenőrződnek, így ha felcseréltük volna a sorrendjüket, a függvény mindig a `"Lucky number seven!"` értéket adná vissza.

## Listaminták

Az egyik leggyakoribb minta a listákra illesztés: ilyenkor a lista fejét és farkát vesszük ki.
Ennek az az oka, hogy a listák láncolt listák.
Íme egy példa egy függvényre, amely visszaadja egy lista fejét és farkát:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Itt két mintánk van: az egyik az üres listára illeszkedik, a másik pedig egy legalább egy elemet tartalmazó listára.
Ez azért van, mert ha a lista üres, kell rá egy eset, különben futásidejű hibát kapnánk.
Ha a lista nem üres, a lista fejét `x`-hez, a farkát pedig `xs`-hez illeszthetjük.
Ezt a `:` (cons) operátorral tesszük, amely egy elemet fűz a lista elejére.
A mintaillesztésben viszont lehetővé teszi, hogy egy listát a fejére és a farkára bontsunk, ami bizonyos értelemben az ellenkezője.

Az `xs` gyakori név a lista farkára; azt hangsúlyozza, hogy egy listáról van szó. Ha viszont egymásba ágyazott listával dolgoznál, használhatod az `xss`-t, hogy jelezd: listák listájáról van szó.

## Tuple-minták

Ahogy a listáknál, úgy a tuple-oknál is illeszkedhetünk.
Íme egy példa egy függvényre, amely egy tuple-t vár, és visszaadja az első és a második elemét:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Itt egy olyan mintánk van, amely egy kételemű tuple-ra illeszkedik; az első elem `x`-hez, a második `y`-hoz van kötve.

## Wildcard minták

Néha nem érdekel minket egy változó értéke, csak a mintára akarunk illeszkedni.
Itt jön képbe a wildcard minta, amelyet egy alulvonás `_` jelöl.

Íme egy példa egy függvényre, amely visszaadja egy lista első elemét:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Itt azt mondjuk, hogy nincs szükségünk a lista farkára, ezért a wildcard mintával figyelmen kívül hagyjuk.

## Típusminták

Típusokra is illeszkedhetünk; ezt az adott típus konstruktorával tesszük.
Az értékeket is kinyerhetjük a típusból, ahogy a tuple-oknál tettük.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

Az első mintában a `Guest` konstruktorra illeszkedünk, a másodikban a `User` konstruktorra, és a benne lévő értéket a `name` változóhoz kötjük.
