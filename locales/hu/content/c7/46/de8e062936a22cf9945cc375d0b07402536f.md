## Szerkesztők

### Ingyenes / nyílt forráskódú

- [VS Code](https://code.visualstudio.com)

  A VS Code egy nyílt forráskódú kódszerkesztő. Arról, hogyan állítsd be a TypeScriptet, [itt](https://code.visualstudio.com/docs/languages/typescript) találsz információt. A VS Code népszerű szerkesztő a TypeScripthez, mert a Microsoft egyszerre gondozza a VS Code-ot és a TypeScriptet, így jól működnek együtt; a VS Code minden további beállítás nélkül támogatja a TS-t. Sőt, magát a VS Code-ot is TypeScriptben írták!

  Gyakori probléma a VS Code és a TS használatakor, ha a szerkesztőd és a projekted verziója eltér, mert ilyenkor a VS Code esetleg zavaró hibaüzenetet jeleníthet meg. Hogyan kezeld ezt a hibát, arról [itt](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions) olvashatsz.

### Fizetős

- [Sublime Text](https://www.sublimetext.com)

  A Sublime Text népszerű kódszerkesztő, amely a legtöbb nyelvet telepíthető bővítményeken keresztül támogatja. Ingyen kipróbálható, de rendszeresen fel fog szólítani, hogy vásárolj licencet, ami jelenleg \$70 USD-ba kerül.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  A WebStorm egy teljes körű JavaScript/TypeScript IDE (integrált fejlesztői környezet). Külön beállítás nélkül támogatja a TypeScriptet, és beépített tesztelést, hibakeresést meg kódelemzést kínál. 30 napig ingyen kipróbálható, utána az éves licenc az első évben \$129 USD-ba kerül.
