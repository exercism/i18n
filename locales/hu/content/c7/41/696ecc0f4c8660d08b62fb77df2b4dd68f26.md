# Tömbök

A tömbök PHP-ban rendezett leképezések.
A leképezés olyan adatszerkezet, amely egy kulcshoz egy értéket rendel.
A tömbök sokoldalúak: kezelheted őket lineáris tömbként (mint a `C`-ben vagy `Java`-ban), listaként [vektor], hash-táblaként, szótárként, gyűjteményként, vermeként vagy sorként.

A kulcs megadása nem kötelező, de ha megadod, annak `int` vagy `string` típusúnak kell lennie.
Ha nem adsz meg kulcsot, a PHP alapértelmezés szerint egész szám kulcsokat használ növekvő sorrendben, `0`-tól kezdve.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Egy tömb minden típusú értéket tárolhat.
Az egyes értékek típusa eltérő lehet.

## A tömbök használata

A tömböket deklarálhatod literálként (a kódban leírva, ahogy fent is láttad), vagy létrehozhatod és módosíthatod őket függvényekkel.
Az indexelő operátorral érhetsz el értékeket, rendelhetsz értéket hozzájuk és fűzhetsz hozzá újakat:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```
