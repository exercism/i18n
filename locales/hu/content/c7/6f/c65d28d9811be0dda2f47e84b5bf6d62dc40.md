# Bevezetés

A [concept:csharp/resource-cleanup]() az `IDispose` interfészt használja arra, hogy jelezze: egy objektum erőforrását vagy a program egyéb állapotát fel kell szabadítani, illetve vissza kell állítani, amikor az objektumra már nincs szükség (és hogy a szemétgyűjtőre hagyatkozva ez nem valósulna meg, illetve nem lenne meg a kívánt szintű kontroll), valamint hogy az `IDisposable.Dispose()` metódus a természetes helye az ilyen takarítási műveleteknek.

Létezik egy másik szerkezet is, a `using` blokk, amellyel a hívó szemszögéből az erőforrás-élettartam kezelése egyetlen utasításba sűríthető.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

A fenti példában a `file`-hoz tartozó fájlrendszer-erőforrások felszabadulnak, és visszakerülnek az operációs rendszerhez, amikor kilépünk a `using` blokkból.

Ahhoz, hogy a minta működjön, a `using` utasításban szereplő változónak olyan referenciatípusnak kell lennie, amely megvalósítja az `IDisposable` interfészt, és a `Dispose()` metódusában fel kell szabadítania az erőforrásokat, illetve vissza kell állítania a program állapotát.

A C# 8 finomítja a mintát: a `using` utasítás egy blokk elejére is kerülhet.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

A Java-fejlesztők felismerhetik benne a Java 7-ben bevezetett _automatikus erőforrás-kezelés_ mechanizmusának megfelelőjét.
