# Bevezetés

A Java-ban a metódustúlterhelés egy olyan lehetőség, amelynek köszönhetően egy osztályban több azonos nevű metódus is lehet, feltéve, hogy a paraméterlistájuk eltér.
A fordításidejű (vagy statikus) polimorfizmushoz kapcsolódik.
Ez a fogalom kulcsfontosságú ahhoz, hogy olyan metódusokat hozzunk létre, amelyek hasonló feladatot látnak el, de más bemenettel.

## Miért érdemes túlterhelni a metódusokat?

A metódustúlterhelés növeli a program olvashatóságát.
Több különböző metódus is kaphat ugyanolyan nevet, ha mások a paramétereik.
Attól függően, hogy hány paramétere van a metódusnak, illetve milyen típusúak a paraméterei, a megfelelő metódus hívódik meg.

## Hogyan terheljük túl a metódusokat?

A metódustúlterhelés kulcsa a metódus szignatúrája.
Két metódust akkor tekintünk különbözőnek, ha a szignatúrájuk eltér.
Egy metódust kétféleképpen terhelhetünk túl:

1. **Eltérő számú paraméter**: A metódusok neve lehet ugyanaz, a paramétereik száma viszont nem.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Eltérő paramétertípusok**: A metódusok neve és a paramétereik száma is megegyezhet, a típusaik viszont
   eltérhetnek.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## Amire érdemes emlékezni

- A túlterhelt metódusok argumentumlistájának meg kell változnia.
- A túlterhelt metódusok visszatérési típusa is megváltozhat, önmagában azonban a visszatérési típus
  módosítása még nem jelent metódustúlterhelést.
- A metódusokat ugyanazon osztályon belül vagy egy alosztályban is túlterhelhetjük.

Ebben a fogalomban a Java metódustúlterhelésének különféle példáit és árnyalatait járjuk körül.
