A Raku bőven használ kódblokkokat.
Alapvetőek a függvényeknél, de megjelennek olyan eszközökben is, mint a `grep` és a `map`, `if`, `for`, `while` és `given` utasítások blokkjaiban, sőt a tömbindexelésben is.

## Rutinok

A [`Subs`][type/Sub] és a [`Methods`][type/Method] a [`Routines`][type/Routine] típusai a Rakuban.

Egy rutinból bármikor kiléphetsz visszatérési értékkel a [`return`][control-return] kulcsszó segítségével, ami hasznos eszköz a függvények létrehozásához.
Ha nem adsz meg `return`-t, a rutin utolsó utasítása lesz az implicit visszatérési értéke.

A rutin kódblokkja előtt zárójelben szerepelhet egy [`Signature`][language/signatures].

A [`Routine`][type/Routine] a [`Block`][type/Block] alosztálya.

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

A metódusokról egy külön, az osztályokkal és objektumokkal foglalkozó fogalomban lesz szó.

## Blokkok

A [`Block`][type/Block] egy újrahasználható kódobjektum, amelyet jellemzően lambdák létrehozására használunk.

A blokk utolsó utasítása az implicit visszatérési értéke.

A blokk kódblokkja előtt `->` előtaggal jelölt [`Signature`][language/signatures] állhat.

A [`Block`][type/Block] a [`Code`][type/Code] alosztálya, amely a Raku összes kódobjektumának végső ősosztálya.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Szignatúrák

A [`Signature`][language/signatures] nulla vagy több [`Parameters`][type/Parameter] részből áll, amelyeket vessző választ el.

A szignatúra végén a visszatérési típust egy [visszatérési típus nyíllal][signatures-return-type-arrow] `-->` adhatod meg.

Egy szignatúrával megadhatod, milyen argumentumokat fogad el a `Block`.

Ez a fogalom egyszerűen tartja a szignatúrákat: csak pozicionális paramétereket használ skaláris szigillumú változókkal és egy visszatérési típussal.
Ezekről más fogalmakban lesz részletesebben szó.

## Multi-Dispatch

A Rakuban a `multi` kulcsszóval több azonos nevű, de eltérő szignatúrájú rutint írhatsz.
Ez a lehetőség [multi-dispatch][multi-dispatch] néven ismert.
Amikor név szerint hívod meg a rutint, a futásidejű környezet dönti el, melyik jelölt a megfelelő, és azt hívja meg.

Erről egy típusokról szóló fogalomban lesz bővebben szó.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

Amikor a [`Whatever`][type/Whatever] `*` csillagot a legtöbb operátorral együtt használod, létrejön egy [`WhateverCode`][type/WhateverCode] objektum.
Így egyszerűbb szintaxissal hozhatsz létre blokkokat.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
