# Névjegy

Egy tisztán funkcionális nyelvben, mint az Elm, egy ugyanazokkal az argumentumokkal meghívott függvénynek mindig ugyanazt az értéket kell visszaadnia.
Ezért egy `rand : Int` típusszignatúrájú függvényt csak így lehet megvalósítani: (`rand = 4`)[xkcd-random], ami nem sok jót ígér, ha véletlen egész számokat akarunk generálni.

Akkor mégis hogyan generáljunk véletlenszerű értékeket Elmben?
Két részre bontjuk a problémát: először leírjuk, milyen értéket szeretnénk generálni egy `Random.Generator a` segítségével, aztán generálunk egy értéket.

Az értékgenerálás első módja, hogy létrehozunk egy `Random.Seed`-et az `initialSeed : Int -> Seed` segítségével.
A `Seed` egy átlátszatlan típus, amely egy egész számot tartalmaz, és tudja, hogyan alakítsa át ezt az egész számot véletlenszerűnek tűnő módon (ezt hívják pszeudovéletlennek).
Ha már van egy `Seed`-ed, azzal generálhatsz egy értéket egy `Generator a` segítségével.
A `Generator a` egy átlátszatlan típus, amely tudja, hogyan használja fel a magban lévő egész számot arra, hogy létrehozzon egy `a` típusú pszeudovéletlen értéket, valamint egy új magot a frissített egész számmal.

Érték generálásához használhatjuk a `step : Generator a -> Seed -> ( a, Seed )` függvényt, amely visszaad egy értéket és egy új magot, amellyel további értékeket generálhatunk.

Használjuk ezeket a függvényeket, hogy `n` véletlenszerű értéket nyerjünk ki egy generátorból:

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

Figyeld meg, hogy ezek a függvények mind tiszták, így ha kétszer hívod meg őket ugyanazokkal az argumentumokkal, ugyanazokat az értékeket kapod.

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

A második módja az értékgenerálásnak a `Random.generate : (a -> msg) -> Generator a -> Cmd msg` használata, de erre csak egy Elm-alkalmazáson belül van lehetőség.
Ebben az esetben az Elm futtatókörnyezete a `step` mellett külső, nem tiszta erőforrásokat is használhat a magok előállításához, és ha ugyanazt a függvényt kétszer hívod meg, más eredményt kapsz.

Mostantól a generátorokra összpontosítunk.

A `Random` modul két alapvető generátort kínál, amelyekkel egész számokat és tizedes törteket hozhatunk létre egy adott tartományon belül:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

Ezeket az értékeket össze lehet fűzni tuple-okba, illetve értékek listáiba:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

Az `elm-community/random-extra` csomag sokkal több generátort kínál különféle adatszerkezetekhez: stringekhez, dátumokhoz, szótárakhoz, tömbökhöz, halmazokhoz és így tovább.

Készíthetünk olyan generátorokat is, amelyek mindig csak egyetlen értéket adnak vissza, a `Random.constant` segítségével:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

A `Random.uniform` segítségével egyforma valószínűséggel választhatunk véletlenszerűen a megadott elemek közül:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

A `Random.uniform` két argumentumot kap (`Red` és `[Green, Blue]`), hogy garantáltan legyen legalább egy érték, amelyből választhat, mivel egyetlen lista üres is lehet.

A valószínűségeket a `Random.weighted` segítségével is finomhangolhatjuk:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

Az értékeknek nem kell 100-at kiadniuk, úgyis újra lesznek normalizálva.

Egy generátor belsejébe a `Random.map` segítségével juthatunk el:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

Használhatjuk a `Random.map2`-t egészen a `Random.map5`-ig, hogy több generátort kombináljunk:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

Bonyolultabb felhasználásokhoz itt van a `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, amellyel az egyik generátor által előállított értéket felhasználhatjuk egy másik létrehozásához:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

Néha hasznos, ha egy generátort önmagára hivatkozva definiálunk.
Ilyen esetekben előfordulhat, hogy a `Random.lazy`-t kell használnod, hogy a fordító ne fejtse ki végtelenségig a generátort.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

Ez a példa kicsit nehéz, úgyhogy bontsuk szét részeire.

A `Peano` egy olyan típus, amely a pozitív egész számokat reprezentálja: a `Zero` a 0, a `Next(Zero)` az 1, a `Next(Next(Zero))` pedig a 2, és így tovább.
A `peano` függvényt azért definiáljuk, hogy véletlenszerű `Peano`-számot kapjunk.

Először is jegyezd meg, hogy a `Random.lazy` semmit sem tesz hozzá a logikához, csupán megakadályozza, hogy a fordító végtelenségig `peano`-t írjon `peano`-ba.

A `Random.uniform` segítségével választunk a nulla (50% valószínűséggel) és egy másik `Peano`-szám plusz egy (50% valószínűséggel) között.
A korábbi példától eltérően azonban a `Random.uniform` most nem értékek közül választ (mint a `Zero`), hanem generátorok közül (mint a `Random.constant Zero`), mivel magát a `peano`-t szeretnénk felhasználni.
Ez azt jelenti, hogy a `Random.uniform` egy `Generator (Generator Peano)` típusú értéket ad vissza, amire viszont nincs szükségünk.

Ahhoz, hogy a generátort „kilapítsuk”, átvezetjük azt a `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` függvénybe, ahol azt szeretnénk, hogy `b` a `Peano` legyen.
Mivel a `Generator a` itt `Generator (Generator Peano)`, `a` csak `Generator Peano` lehet, a `(a -> Generator b)` függvénynek pedig `(Generator Peano -> Generator Peano)` típusúnak kell lennie.
Nem szeretnénk semmin sem változtatni, így az `identity` a megfelelő választás.

Végül is milyen számokat fog előállítani a `peano`?
Tudjuk, hogy az esetek 50%-ában 0-t ad, az esetek másik 50%-ában pedig önmaga egy következő iterációját plusz egyet.
Ez azt jelenti, hogy a kapott számok a következők lesznek: 0 (az esetek 50%-ában), 1 (az esetek 25%-ában), 2 (12%-ában), 3 (6%-ában) és így tovább.
A `peano` tetszőlegesen nagy számokat állíthat elő, de exponenciálisan csökkenő valószínűséggel.
