## Tuple

A [tuple-ök][tuple] gyakran információ csoportosítására szolgálnak. Abban különböznek a listáktól, hogy rögzített méretűek, és különböző adattípusokat is tárolhatnak bennük. A tuple-öket zárójelekkel (`()`) hozzuk létre, és gyakran arra használjuk őket, hogy egy függvény több értéket adjon vissza.

```haskell
tuple = (1, "abc", False)
```

Ez akkor lehet hasznos, ha például egy koordinátát szeretnél tárolni egy kétdimenziós térben: ilyenkor tudod, hogy a tuple-nak mindig két eleme lesz, az x és az y koordináta.

```haskell
coordinate = (3, 4)
```

### Az elemek elérése

Elég gyakran rövid tuple-ökkel dolgozol, és ilyenkor az elemeket a `fst` és az `snd` függvénnyel érheted el.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## Mintaillesztés

Amikor Haskell-függvényeket írunk, használhatunk [kijelentő stílust][assertive-style] a [mintaillesztéssel][pattern-match-doc]:
A mintaillesztés a Haskell egyik nagyon erős eszköze, amellyel adatkonstruktorokra illeszthetünk, és a bennük lévő értékekhez köthetünk változókat.
Ahogy a neve is sugallja, az értékeket mintákra illesztjük, és ha az érték illeszkedik a mintára, akkor a mintában lévő értékekhez köthetünk változókat.
A mintaillesztés elsősorban ezekből a fogalmakból épül fel: értékek felismerése, változók kötése és értékek szétbontása.

Nézzük például ezt a függvényt:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Itt van egy `lucky` függvény, amely egy `Int`-et kap, és egy `String`-et ad vissza.
Két mintát definiáltunk a függvényhez: az egyik a `7` számra illeszkedik, a másik bármely más számra. A név bármi lehet (amíg követi a Haskell elnevezési konvencióját), itt viszont `x`-et használunk.
Ha a szám `7`, a függvény a `"Lucky number seven!"` értéket adja vissza, egyébként pedig a `"Sorry, you're out of luck, pal!"` értéket.
Itt az a fontos, hogy a mintákat fentről lefelé haladva ellenőrzi a program, így ha felcserélnénk a minták sorrendjét, a függvény mindig a `"Lucky number seven!"` értéket adná vissza.

### Listaminták

Nagyon gyakori minta a listákra illesztés, ami a lista fejének és farkának a kivétele.
Ennek az az oka, hogy a listák lényegében láncolt listák.
Íme egy példa egy olyan függvényre, amely visszaadja egy lista fejét és farkát:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Két minta van itt: az egyik az üres listára illeszkedik, a másik pedig egy legalább egy elemet tartalmazó listára.
Erre azért van szükség, mert ha a lista üres, akkor külön esetet kell kezelnünk, különben futásidejű hibát kapnánk.
Ha a lista nem üres, akkor a lista fejét `x`-hez, a farkát pedig `xs`-hez illeszthetjük.
Ezt a `:` (cons) operátorral csináljuk, amellyel egy elemet fűzhetünk a lista elejére.
A mintaillesztésben viszont épp az ellenkezőjét teszi lehetővé: szétbontja a listát a fejére és a farkára.

Az `xs` gyakori név a lista farkára, és arra utal, hogy egy listáról van szó. Ha viszont egymásba ágyazott listával dolgoznál, `xss`-et használhatsz, jelezve, hogy listák listájáról van szó.

### Tuple-minták

A listákhoz hasonlóan tuple-ökre is illeszthetünk.
Íme egy példa egy olyan függvényre, amely egy tuple-t kap, és visszaadja az első és a második elemét:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Itt egy olyan minta van, amely egy kételemű tuple-re illeszkedik: az első elem `x`-hez, a második pedig `y`-hoz van kötve.

### Wildcard minták

Néha nem érdekel minket egy változó értéke, csak a mintára szeretnénk illeszkedni.
Ilyenkor jön a képbe a wildcard minta, amelyet aláhúzásjel (`_`) jelöl.

Íme egy példa egy olyan függvényre, amely visszaadja egy lista első elemét:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Itt azt mondjuk ki, hogy nincs szükségünk a lista farkára, ezért a wildcard mintával figyelmen kívül hagyjuk.

### Típusminták

Típusokra is illeszthetünk, ezt az adott típus konstruktorával tesszük.
Az értékeket ki is nyerhetjük a típusból, ahogy a tuple-öknél tettük.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

Az első mintában a `Guest` konstruktorra illeszkedünk, a másodikban pedig a `User` konstruktorra, és a benne lévő értéket `name`-hez kötjük.
