# Bevezetés

A Clojure-ben a `string` egy Java string, azaz egy olyan objektum, amely módosíthatatlan szöveget ábrázol Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként.

A `clojure.string` könyvtár számos szabványos függvényt kínál stringek kezelésére és feldolgozására. Ezen kívül a stringekkel végzett műveletekhez használt szokásos Java-metódusok mindegyike elérhető interop segítségével.
