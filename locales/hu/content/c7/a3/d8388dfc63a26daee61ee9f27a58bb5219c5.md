# Bemutatás

A [map][maps] olyan adatszerkezet, amely kulcs-érték párokat tárol.

- A kulcsok bármilyen típusúak lehetnek, de egyedinek kell lenniük.
- Az értékek bármilyen típusúak lehetnek, és nem kell egyedinek lenniük.
- A mapek nem garantálják a tartalmuk sorrendjét, pedig úgy tűnhet, hogy igen.
  - Ezt a téves benyomást a mögöttes megvalósításuk okozza:
    - Kis méretnél (legfeljebb 32 bejegyzés) rendezett [Keyword list][keyword-list] formájában valósulnak meg.
    - Nagyobb méretnél (több mint 32 bejegyzés) [hash array mapped trie][hamt] formájában valósulnak meg &#91;[1][stackoverflow]&#93;.
- A mapek literál formában is deklarálhatók:

  ```elixir
  # An empty map
  %{}

  # A map with the atom key :a associated to the integer value 1
  %{a: 1}

  # A map with the string key "a" associated to the float value 2.0
  %{"a" => 2.0}

  # A map with the map key %{} with the list value [1 ,2, 3]
  %{%{} => [1, 2, 3]}

  # A map with keys of different types
  %{:a => 1, "b" => 2}
  ```

- A mapek a [Map modul][map-module] [`Map.new`][map-new] függvényével is létrehozhatók. Ez akkor lehet hasznos, ha már van egy felsorolható gyűjteményed, amelyet listává szeretnél alakítani:

  ```elixir
  kw_list = [a: 1, b: 2]
  Map.new(kw_list)
  # => %{a: 1, b: 2}
  ```

- Egy map értékeihez sokféleképpen hozzáférhetsz:

  ```elixir
  my_map = %{key: "value"}

  # with a dot if the key is an atom
  my_map.key
  # => "value"

  # with [], a syntax provided by the Access behaviour
  my_map[:key]
  # => "value"

  # with pattern matching
  %{key: x} = my_map
  x
  # => "value"

  # with Map.get/2
  Map.get(my_map, :key)
  # => "value"
  ```

- A standard könyvtár részeként elérhető [Map modul][map-module] sok hasznos függvényt kínál a mapek használatához.

  ```elixir
  Map.delete(%{a: 2, b: 3}, :a)
  # => %{b: 3}
  ```

- A mapek megvalósítják az [`Enumerable`][enumerable] protokollt, így használhatók az [Enum modul][enum] függvényei.
- A [Map][map-module] és az [Enum modul][enum] függvényeihez gyakran [névtelen függvényekre][anon-fn] vagy [rögzített függvényhivatkozásokra][captured-fn] van szükség argumentumként

  ```elixir
  # Increment the value by one, if it is not found, update it with 0
  Map.update(%{a: 1}, :a, 0, &(&1 + 1))
  # => %{a: 2}

  # Sorting by a specific sub-value
  list = [{"A", 4}, {"B", 3}, {"C", 2}, {"D", 1}]
  Enum.sort_by(list, &Kernel.elem(&1, 1))
  # => [{"D", 1}, {"C", 2}, {"B", 3}, {"A", 4}]
  ```
