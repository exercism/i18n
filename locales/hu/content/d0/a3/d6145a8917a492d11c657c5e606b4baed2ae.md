# SQLite-ra vonatkozó utasítások

Ennél a feladatnál az `etl` tábla `result` oszlopát kell a helyes értékre állítanod, az `input` oszlopban található JSON-objektum alapján. A result objektum kulcsait ábécésorrendben kell szerepeltetni.

## Táblaséma

```sql
CREATE TABLE "etl" ("input" TEXT, "result" TEXT);
```
