# Utasítások

Ebben a feladatban olyan kódot írsz majd, amely segít egy szabadúszónak kommunikálni egy projektmenedzserrel: néhány segédeszközt készítesz, amelyekkel gyorsan kiszámítható a napi és a havi díj, adott esetben egy megadott kedvezménnyel.

Először is rögzítünk néhány szabályt a szabadúszó és a projektmenedzser között:

A napi díj az óradíj nyolcszorosa.
Egy hónapban 22 számlázható nap van.
A szabadúszó felajánlja, hogy kedvezményt ad, ha a projektmenedzser úgy dönt, hogy havonta számlázhat, ami jól jöhet, ha a projektmenedzsernek egy bizonyos keretösszeggel kell gazdálkodnia.

A kedvezményeket százalékot jelképező törtszámként modellezzük, például 25.0 (25%).

## 1. A napi díj kiszámítása adott óradíj esetén

Készíts egy függvényt, amely kiszámítja a napi díjat egy adott óradíj alapján:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

A visszaadott napi díj egy lebegőpontos szám legyen.

## 2. Kedvezményes ár kiszámítása

Készíts egy függvényt, amely kiszámítja az árat a kedvezmény alkalmazása után.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

A visszaadott érték mindig lebegőpontos szám legyen, semmilyen módon ne legyen kerekítve.

## 3. A havi díj kiszámítása adott óradíj és kedvezmény esetén

Készíts egy függvényt, amely kiszámítja a havi díjat, és alkalmazza a kedvezményt:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

A visszaadott havi díjat felfelé kerekítve (a felső egész értéket véve) a legközelebbi egész számra kell megadni.

## 4. A munkanapok számának kiszámítása adott keretösszeg, óradíj és kedvezmény esetén

Készíts egy függvényt, amely átvesz egy keretösszeget, egy óradíjat és egy kedvezményt, majd kiszámítja, hogy az hány munkanapot fedez.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

A visszaadott napok számát lefelé kerekítve (az alsó egész értéket véve) egy tizedesjegyre kell megadni.
