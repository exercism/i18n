# Telepítés

## Mac

Telepítsd a homebrew segítségével: `brew install swi-prolog`.
Vagy töltsd le a gépedhez tartozó forrást a [SWI Prolog weboldaláról](http://www.swi-prolog.org/download/devel).

## Windows

Töltsd le a gépedhez tartozó forrást a [SWI Prolog weboldaláról](http://www.swi-prolog.org/download/devel).

## Linux

Kövesd a disztródhoz tartozó utasításokat [innen](http://www.swi-prolog.org/build/unix.html).
