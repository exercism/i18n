# helyőrző

## Hogyan oldd meg bash-ben

A `bash` nem tud beépített módon **értelmezni** dátum-idő stringeket.
Ehhez a feladathoz külső segédprogramot kell meghívnod.

* A GNU `date` parancs `-d` opciójával [sokféle formátum][gnu-date] értelmezhető.
* Ha Macet használsz, nézd meg a [BSD `date` parancsot][bsd-date] és annak `-f` opcióját.
* A Perl széles körben elérhető, és a [`Time::Piece` moduljával][time-piece] is értelmezhetők az időbélyegek.

A `bash` külső eszközök nélkül is képes **formázni** a dátumokat.
Ha adott egy egész szám típusú időérték (az epoch óta eltelt másodpercek), akkor [a `printf` `%()T` formázója][bash-printf] „strftime” stílusú formázást tud alkalmazni.

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
