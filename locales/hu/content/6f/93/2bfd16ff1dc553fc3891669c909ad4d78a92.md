# Alapok

A Python egy [dinamikus és erősen típusos][dynamic typing in python] programozási nyelv.
A [kacsa típusozást][duck typing] és a [fokozatos típusozást][gradual typing] egyaránt alkalmazza, [típusjelöléseken][type hints] keresztül.
Az imperatív, a deklaratív (például funkcionális) és az objektumorientált programozási _stílusok_ mind támogatottak, de belül **[a Pythonban minden objektum][everythings an object]**.

A Python nagy hangsúlyt fektet a kód olvashatóságára, és (_a Haskellhez hasonlóan_) [jelentős behúzást][significant indentation] használ a függvények, a metódusok és az osztályok definíciójának jelzésére.

A Pythont Guido van Rossum alkotta meg, és először 1991-ben jelent meg.
A [Python Software Foundation][psf] kezeli és irányítja a Python és a CPython fejlesztéséhez szükséges erőforrásokat, és a közösség [tagjaitól][psf membership] [Python Enhancement Proposal, azaz PEP][peps] formájában fogad javaslatokat a nyelv módosítására.


A jelenlegi kiadás teljes dokumentációja a [docs.python.org][python docs] oldalon található.

## Névhozzárendelés (változók és konstansok)

A Pythonban nincsenek kulcsszavak a változók vagy konstansok létrehozására.
Ehelyett a programozók a `=` értékadás operátorral [_neveket_][facts-and-myths-about-python-names] (más néven _változókat_) köthetnek bármilyen típusú objektumhoz: `<name> = <value>`.
Egy név az élettartama során újraértékadható (vagy újraköthető) különböző értékekhez (különböző objektumtípusokhoz).

Például a `my_first_variable` a `=` használatával sokszor újraértékadható, és minden újraértékadásnál más objektumtípusra hivatkozhat:


```python
>>> my_first_variable = 1  # my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  # my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." # <--You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' # <--Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".

>>> import collections
>>> my_first_variable = collections.Counter([1,1,2,3,3,3,4,5,6,7]) # <--Now my_first_variable has been re-bound to a Counter object.
>>> print(type(my_first_variable))
<class 'collections.Counter'>

>>> print(my_first_variable)
Counter({3: 3, 1: 2, 2: 1, 4: 1, 5: 1, 6: 1, 7: 1})
```


### Konstansok

A konstansok olyan nevek, amelyeket egy programban csak egyszer szánunk értékadásra.
[Modul][module] (fájl) szinten érdemes definiálni őket, és általában a program összes függvénye és osztálya számára láthatók.
A `SCREAMING_SNAKE_CASE` használata jelzi, hogy a nevet nem szabad újraértékadni, és az értékét sem módosítani.


```python
# All caps signal that this is intended as a constant.
MY_FIRST_CONSTANT = 16

# Re-assignment will be allowed by the compiler & interpreter,
# but this is VERY strongly discouraged.
# Please don't do this, it could create problems in your program!
MY_FIRST_CONSTANT = "Some other value"
```


## Függvények

A Pythonban a funkcionalitás egységeit [_függvények_][functions] zárják egységbe, amelyek maguk is [objektumok][objects] (_[teknősbékák egészen a végtelenségig][turtles all the way down]_).

A függvények önmagukban futtathatók, átadhatók más függvények argumentumaként, egymásba ágyazhatók, vagy egy osztályhoz köthetők.
Amikor egy függvényt egy [osztály][classes] nevéhez kötünk, [metódusnak][method objects] nevezzük.
A kapcsolódó függvények és osztályok (_a metódusaikkal együtt_) csoportosíthatók ugyanabban a fájlban vagy modulban, és részben vagy egészben importálhatók más programokban való használatra.

A `def` kulcsszó kezdi a [függvénydefiníciót][function definition].
Minden függvénynek lehet nulla vagy több formális [paramétere][parameters] a `()` zárójelben, amelyet egy `:` kettőspont követ.
A függvény _törzsét_ alkotó utasítások a `def` utáni sorban kezdődnek, és _blokkban behúzva_ kell állniuk:


```python
# The body of a function is indented by 2 spaces & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     # <--This was only indented by 3 spaces.
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


A függvények a [`return`][return] kulcsszóval _explicit módon_ adnak vissza egy értéket vagy objektumot:


```python
# Function definition on first line, explicit return used on final line.
def add_two_numbers(number_one, number_two):
  return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing 
# the variable will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```

Azok a függvények, amelyekben a `return` után nem áll _explicit_ kifejezés, _implicit módon_ a [`None`][none] objektumot adják vissza.
A `None` részleteit egy későbbi fogalomban tárgyaljuk.
Ennek a feladatnak és magyarázatnak a szempontjából a `None` egy helyőrző, amely a semmit, azaz a null értéket képviseli:


```python

# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

Azok a függvények is _implicit módon_ a [`None`][none] objektumot adják vissza, amelyekből hiányzik a `return`.
Ez azt jelenti, hogy ha nem használsz `return`-t egy függvényben, a Python helyetted visszaadja a `None` objektumot.

```python

# This function omits a return keyword altogether
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


### Függvények hívása

A függvényeket úgy [_hívjuk_][calls] meg, hogy a nevük után `()`-t írunk.
Egy osztályon vagy modulon belül definiált függvény hívásához pont (`.`) jelölést használunk.

```python
>>> def raise_to_power(number, power):
...     return number ** power
...

>>> raise_to_power(3,3) # Invoking the function with the arguments 3 and 3.
27


# A mis-match between the number of parameters and the number of arguments will raise an error.
>>> raise_to_power(4,)
...
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: raise_to_power() missing 1 required positional argument: 'power'


# Calling methods or functions in classes and modules.
>>> start_text = "my silly sentence for examples."
>>> str.upper(start_text)  # <--Calling the upper() method from the built-in str class on start_text.
'MY SILLY SENTENCE FOR EXAMPLES.'

# Because a string is an instance of the str class, methods can also be called on them "directly".
>>> start_text = "my silly sentence for examples."
>>> start_text.upper()  # <--Calling the upper() method on start_text directly.
'MY SILLY SENTENCE FOR EXAMPLES.'

# Alternatively, we can skip the variable assignment (although this gets messy quick).
>>> "my silly sentence for examples.".upper()
'MY SILLY SENTENCE FOR EXAMPLES.'


# Importing the math module
>>> import math
>>> math.pow(2,4)  # <--Calling the pow() function from the math module.
16.0
```


## Megjegyzések

A [megjegyzések][comments] a Pythonban egy `#` jellel kezdődnek, amely nem része egy stringnek, és a sor végéig tartanak.
Sok más programozási nyelvvel ellentétben a Python **nem támogatja** a többsoros megjegyzésjeleket.
Egy megjegyzésblokk minden sorának a `#` karakterrel kell kezdődnie.

A megjegyzéseket az értelmező figyelmen kívül hagyja:


```python
# This is a single line comment.

x = "foo"  # This is an in-line comment.

# This is a multi-line
# comment block over multiple lines --
# these should be used sparingly.
```


## Docstringek

Egy függvénytörzs első utasítása opcionálisan lehet egy [_docstring_][docstring], amely tömören összefoglalja a függvény vagy az objektum célját.
A docstringeket három dupla idézőjellel (""") deklaráljuk, ugyanolyan behúzással, mint a kódblokkot:


```python
# An example from PEP257 of a multi-line docstring
# reformatted to use Google style non-type hinted docstrings.
# Some additional details can be found in the Sphinx documentation:
# https://www.sphinx-doc.org/en/master/usage/extensions/napoleon.html#getting-started

def complex(real=0.0, imag=0.0):
    """Form a complex number.

    Keyword Arguments:
        real (float): The real part of the number (default 0.0)
        imag (float): The imaginary part of the number (default 0.0)
        
    """

    if imag == 0.0 and real == 0.0:
        return complex_zero

```


A docstringeket az automatikus dokumentációs eszközök olvassák, és úgy kapjuk meg őket, hogy a függvény, a metódus vagy az osztály nevén meghívjuk a speciális `.__doc__` attribútumot.
Minden méretű programhoz ajánlottak, ahol dokumentációra van szükség, és a konvencióikat a [PEP257][pep257] írja le.

A docstringek [könnyűsúlyú egységtesztként][doctests] is működhetnek, amelyeket a PyTest olvashat és futtathat, vagy a `doctest` modul importálásával.
A tesztelést és a `doctest`-et egy későbbi fogalomban tárgyaljuk.


```python
# An example on a user-defined function using a Google style docstring. 
>>> def raise_to_power(number, power):
    """Raise a number to an arbitrary power.

    Parameters:
        number (int): The base number.
        power (int): The power to raise the base number to.
    
    Returns:
        int: The number raised to the specified power.
    
    Takes a number and raises it to the specified power, returning the result.

    """

    return number ** power
...

# Calling the .__doc__ attribute of the function and printing the result.
>>> print(raise_to_power.__doc__)
Raise a number to an arbitrary power.

Parameters:
    number (int): The base number.
    power (int): The power to raise the base number to.

Returns:
    int: The number raised to the specified power.

Takes a number and raises it to the specified power, returning the result.

...

# Printing the __doc__ attribute of the built-in type: str.
>>> print(str.__doc__)
str(object='') -> str
str(bytes_or_buffer[, encoding[, errors]]) -> str

Create a new string object from the given object. If encoding or
errors is specified, then the object must expose a data buffer
that will be decoded using the given encoding and error handler.
Otherwise, returns the result of object.__str__() (if defined)
or repr(object).
encoding defaults to 'utf-8'.
errors defaults to 'strict'.
```
