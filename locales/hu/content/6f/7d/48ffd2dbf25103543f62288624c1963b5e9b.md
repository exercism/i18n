# Bevezetés

A [kézikönyvből][man-types]

> A jq ugyanazokat az adattípusokat támogatja, mint a JSON: számok, stringek, Boolean-ok, tömbök, objektumok (amelyek a JSON nyelvén csak string kulcsokkal rendelkező hash-ek), valamint a „null”.

Most a **számokra** összpontosítsunk.

## Számok és numerikus operátorok

Minden szám, akár egész, akár nem, IEEE754 kétszeres pontosságú lebegőpontos szám.
Ez a pontosságot 53 bitre korlátozza.

A szokásos operátorok számokkal is használhatók:

- aritmetika: `+`, `-`, `*`, `/`, `%`
- összehasonlítás: `==`, `!=`, `<`, `<=`, `>=`, `>`
- szabványos [matematikai függvények][man-math]

  Egy bemenetes függvényeknél az értéket a pipe segítségével add át a függvénynek

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Két bemenetet váró függvényeknél a függvény figyelmen kívül hagyja a bemenetet, és a
  bemeneteket paraméterként várja (emlékezz rá, hogy a paramétereket pontosvessző választja el)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  A függvényargumentumok elválasztója a pontosvessző, nem a vessző.

## További `jq` kifejezések

A feladat megoldásához ismerned kell a feltételes kifejezéseket.

### Feltételes kifejezések

A `jq` a **feltételes kifejezésekhez** az [`if-then-else` kifejezést][if-then-else] használja.
Mivel _kifejezésről_ van szó, egy pipeline-ba kerül.

A szintaxis: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

Az `else` ág opcionális.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

További feltételekhez az `elif` használható

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
