# Bevezetés

A JavaScriptben a tömb egy listaszerű szerkezet, amelynek nincs rögzített hossza, és bármilyen primitív típust vagy objektumot tárolhat, akár vegyesen is.

Tömb létrehozásához írd az elemeket szögletes zárójelek (`[]`) közé.
A tömb beolvasásához írd az indexet szögletes zárójelbe (`[]`) az azonosító után.
A tömb indexei nullától kezdődnek.

Például:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Ha meg akarod tudni, hány elem van egy tömbben, használd a `length` tulajdonságot:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Ha meg akarsz változtatni egy elemet a tömbben, rendelj értéket az adott indexhez:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Metódusok

A minden Array objektumon elérhető [metódusok][mdn-array] közül néhány használható arra, hogy elemeket adj a tömbhöz, vagy eltávolíts belőle.
Íme néhány, amit érdemes szem előtt tartanod, amikor ezen a feladaton dolgozol:

### push

Egy `value` értéket a `.push(value)` metódussal _adhatsz hozzá_ egy tömb végéhez.
A metódus a tömb új hosszát adja vissza.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

A _legutolsó_ `value` értéket a `.pop()` metódussal _távolíthatod el_ egy tömbből.
A metódus az eltávolított értéket adja vissza.
A tömb hossza e változás miatt csökkenni fog.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

A _legelső_ `value` értéket a `.shift()` metódussal _távolíthatod el_ egy tömbből.
A metódus az eltávolított értéket adja vissza.
A tömb hossza e változás miatt csökkenni fog.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

Egy `value` értéket a `.unshift(value)` metódussal _adhatsz hozzá_ egy tömb elejéhez.
A metódus a tömb új hosszát adja vissza.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

Egy adott `index`-en lévő `value` értéket a `.splice(index, 1)` metódussal _távolíthatod el_ egy tömbből.
A metódus az eltávolított elemet (elemeket) adja vissza.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
Ezek a metódusok többre képesek, mint ahogy fentebb leírtuk:

- A `push` és az `unshift` is lehetővé teszi, hogy egyszerre több értéket adj hozzá, ha több argumentumot adsz meg.
  Erre nincs szükség a feladat megoldásához.
- A Splice több értéket is eltávolíthat, ha megnöveled a második argumentumot.
  Erre nincs szükség a feladat megoldásához.
- A Splice több értéket is hozzáadhat, ha a `deleteCount` után argumentumként megadod őket.
  Ezzel értékeket cserélhetsz ki, vagy értékeket szúrhatsz be egy tömb közepére (például 0 elem eltávolításával).
  Erre nincs szükség a feladat megoldásához.
~~~
