# Bevezetés

## Boolean-ok

A Boolean-okat Java-ban a `boolean` típus képviseli, amelynek az értéke `true` vagy `false` lehet.

A Java három logikai operátort támogat:  

- `!` (NOT): negálja a Boolean értékét  
- `&&` (AND): két Boolean értéket kap, és `true`-t ad vissza, ha mindkettő `true`
- `||` (OR): `true`-t ad vissza, ha a két Boolean érték közül bármelyik `true`

### Példák

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
