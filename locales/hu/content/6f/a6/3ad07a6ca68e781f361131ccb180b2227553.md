# Bevezetés

## Stringek

A Java `String` egy objektum, amely megváltoztathatatlan szöveget ábrázol Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként.
A `String` példányt kettős idézőjelek között hozzuk létre:

```java
String fruit = "Apple";
```

A stringeket a metódusaik meghívásával kezeljük.
Ha egyszer létrehoztunk egy stringet, az értéke soha nem változhat.
Azok a metódusok, amelyek úgy tűnik, hogy módosítják a stringet, valójában egy új stringet adnak vissza.
A `String` osztály néhány _statikus_ metódust kínál a stringek átalakítására.
