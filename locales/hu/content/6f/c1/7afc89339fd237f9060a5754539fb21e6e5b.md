# Telepítés

## Követelmények

* 64 bites x86-os CPU
* Modern C-fordító
* A Make buildeszköz
* A Netwide Assembler (NASM)

Ne feledd, hogy ez a kurzus kizárólag a System V AMD64 ABI hívási konvencióját támogatja. A Windows-felhasználóknak telepíteniük kell a Windows Subsystem for Linuxot (WSL), vagy be kell állítaniuk egy Linux virtuális gépet.

## Linux

Telepítsd a szükséges szoftvereket a rendszered csomagkezelőjével:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Telepítsd az Xcode Command Line Tools eszközt:

```bash
$ xcode-select --install
```

Telepítsd a NASM-et a [Homebrew](http://brew.sh/) segítségével:

```bash
$ brew install nasm
```

## Windows

A WSL telepítéséről itt olvashatsz: https://docs.microsoft.com/en-us/windows/wsl/install-win10.
