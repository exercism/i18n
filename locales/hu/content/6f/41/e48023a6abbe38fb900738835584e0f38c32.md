# Telepítés

## A .NET telepítése

Az F# kurzus a [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) platformra épül, amely Windows, Linux és macOS rendszeren fut. A .NET projektek felépítéséhez használhatod a .NET parancssori felületét (CLI). Ez a CLI a .NET SDK része, amelyet a [telepítési útmutató](https://dotnet.microsoft.com/download) követésével telepíthetsz. Megjegyzés: az F# kurzushoz legalább 8.0-s SDK-verzió szükséges.

A telepítés befejezése után ellenőrizheted, hogy a CLI sikeresen települt-e, ha lefuttatod ezt a parancsot egy terminálban:

```bash
dotnet --version
```

Ha a kimenetben egy `8.0.100` vagy annál nagyobb verzió szerepel, akkor a .NET SDK sikeresen települt.

## IDE használata

Ha gazdagabb szerkesztési élményre vágysz, valószínűleg IDE-t érdemes használnod. Ezek a legnépszerűbb IDE-k, amelyek támogatják a .NET projektek felépítését:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) a [Ionide-fsharp bővítménnyel](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Megjegyzés: mivel a .NET projektformátuma jelentősen eltér a korábbi verzióktól, a régebbi IDE-k (például a Visual Studio 2015) nem támogatottak.
