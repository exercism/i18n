# Bevezetés

Cairóban az operátor-túlterhelés lehetővé teszi, hogy egyedi viselkedést definiálj a szabványos operátorokhoz, például a `+`, `-`, `==`, `<` és társaikhoz, amikor a saját típusaiddal dolgozol.

Ezt úgy érheted el, hogy meghatározott trait-eket implementálsz a saját típusaidhoz.

## Az operátorok alapvető traitjei

### `Add` és `Sub`

Az `Add` és a `Sub` trait segítségével meghatározhatod, hogyan működik a típusoddal az összeadás (`+`) és a kivonás (`-`):

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

A `PartialEq` trait lehetővé teszi a típusod példányai közötti egyenlőség-összehasonlítást (`==` és `!=`).

Ezt gyakran automatikusan is származtathatod a `#[derive(PartialEq)]` használatával.

### `PartialOrd`

A `PartialOrd` trait összehasonlítási műveleteket tesz lehetővé (`<`, `>`, `<=`, `>=`) a típusod példányai között.

Ehhez legalább az `lt` (kisebb, mint) metódust kell implementálnod:

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
