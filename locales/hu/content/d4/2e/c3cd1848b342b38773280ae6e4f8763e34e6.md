# Utasítások

Üdvözlünk *ChronoRealms* világában, egy varázslatos birodalomban, ahol a hatalmas Timekeepers irányítják az idő folyását.

Ebben a birodalomban a Timekeepers „TimeShards” nevű különleges egységeket kezelnek, amelyeket össze lehet adni, ki lehet vonni, össze lehet hasonlítani, sőt az egyenlőségüket is ellenőrizni lehet.

A feladatod, hogy segíts a Timekeepers-nek egyedi operátorok megvalósításával, amelyekkel ezeket a TimeShards egységeket kezelheted.

A Timekeepers-nek szükségük van egy egyedi `TimeShard` structra, amely a következő műveleteket támogatja:

1. **TimeShards összeadása és kivonása**: A Timekeepers-nek képesnek kell lenniük TimeShards egységeket összeadni és kivonni, hogy irányíthassák az idővonalat.
2. **TimeShards összehasonlítása**: Néha a TimeShards egységeket össze kell hasonlítani, hogy lássuk, melyik a nagyobb, vagy hogy egyenlők-e.
3. **Az egyenlőség ellenőrzése**: A Timekeepers-nek ellenőrizniük kell, hogy két TimeShards egység értéke azonos-e.

A küldetésed, hogy megvalósítsd a következő trait-eket a `TimeShard` struct típushoz:

1. **Összeadás (`Add`)**: Lehetővé teszi két `TimeShard` példány összeadását.
2. **Kivonás (`Sub`)**: Lehetővé teszi, hogy az egyik `TimeShard` példányt kivonjuk a másikból.
3. **Egyenlőség (`PartialEq`)**: Lehetővé teszi a Timekeepers-nek, hogy ellenőrizzék, két `TimeShard` példány ugyanaz-e.
4. **Összehasonlítás (`PartialOrd`)**: Lehetővé teszi két `TimeShard` példány összehasonlítását, hogy lássuk, melyik a nagyobb vagy kisebb.

A `TimeShard` egy struct lesz, amely egy egész számot (`i32`) tárol.

Valósítsd meg a szükséges trait-eket, hogy megkönnyítsd a Timekeepers munkáját.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
