# Utasítások

Egy kicsi fordított lengyel jelölésű (RPN) számológépet építesz.
A számológép állapota egy *értékek verme* (amelyet egy Factor array reprezentál), a *művelet* pedig egy quotation, amely kap egy ilyen vermet, és egy újat ad vissza.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. Az összeadás megvalósítása

Az `add-op`-ot úgy definiáld, hogy levegye a verem tetejéről a két felső értéket, a veremre tegye az összegüket, és adja vissza az új vermet.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. A szorzás megvalósítása

A `multiply-op`-ot ugyanígy definiáld, csak szorzásra.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. Egyetlen művelet alkalmazása

Az `apply-op`-ot úgy definiáld, hogy levegyen az adatveremről egy vermet és egy műveletet (egy quotationt), és visszaadja az új számológép-vermet.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. Egy program kiértékelése

Az `evaluate`-et úgy definiáld, hogy kapjon egy kezdő vermet és egy műveletekből álló arrayt, majd sorra alkalmazza az egyes műveleteket, és adja vissza a végső vermet.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. Kiértékelés név alapján

Most a program *operátornevek* (stringek) listája, és a számológép minden nevet megkeres egy assocban, amely a neveket műveletekhez rendeli.

Az `evaluate-named`-et úgy definiáld, hogy kapjon egy kezdő vermet, a névvel ellátott műveletek egy assocját és nevek egy arrayét, majd adja vissza a végső vermet.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. Biztonságos osztás

Egy igazi számológép nem adhat csendben szemét eredményt, ha nullával kell osztania. A `zero-divisor-error` hibaosztályt már definiáltuk a számodra. A `divide-op`-ot az `add-op` és a `multiply-op` mintájára valósítsd meg, azzal a különbséggel, hogy friss `zero-divisor-error`-t `throw`-ol, ha a verem tetején lévő osztó `0`.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
