# Kiegészítés az utasításokhoz

## Megvalósítás

A feladat függvényei egy vagy több számot tartalmazó tömböt fogadnak, amelyek mindegyike egy-egy „játékpontszámot” jelöl.

A játékos pontszámai innen olvashatók ki:

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

A `personal_top_three()` a játékos legjobb pontszámait ide írja:

| `output`   |
|---|
| `output[0]` |
| ... |
