# Bevezetés

A Java 8-ban bevezetett `java.time` csomag több osztályt is tartalmaz a dátumokkal és idővel való munkához.

## `LocalDate`

A `java.time.LocalDate` osztály egy időzóna nélküli dátumot reprezentál az [ISO-8601 naptárrendszerben][iso-8601], például `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

A dátumok összehasonlíthatók más dátumokkal:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

A `LocalDate` példánynak getter metódusai vannak, amelyekkel kinyerhetők belőle az időrészek:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

A `LocalDate` példány metódusokkal rendelkezik, amelyekkel időegységeket adhatunk hozzá:

```exercism/note
Ezek a metódusok egy _új_ `LocalDate` példányt adnak vissza, és nem frissítik a meglévő példányt, mivel a `LocalDate` osztály megváltoztathatatlan.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

## `LocalDateTime`

A `java.time.LocalDateTime` osztály egy időzóna nélküli dátum-időt reprezentál az [ISO-8601 naptárrendszerben][iso-8601], például `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

Egy `LocalDate` példányt átalakíthatsz `LocalDateTime`-má:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## Dátum-idők formázása

A `LocalDate` és a `LocalDateTime` is az [ISO-8601][iso-8601] szabványos jelölést használja, amikor `String`-ből `String`-be konvertál.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

Nem lehetséges egy `LocalDate` vagy `LocalDateTime` értéket ilyen módon, eltérő formátummal parse-olni egy `String`-ből.
Helyette, ha egyéni formátummal szeretnél dátumokat formázni, a `java.time.format.DateTimeFormatter` osztályt kell használnod:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

A megadott egyéni formátum létrehozásakor megadhatsz egy locale-t is, hogy különböző régiókra formázhass és parse-olhass:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
