# Telepítés

## Ubuntu (és a legtöbb más Debian-alapú disztribúció)

Ha helyben szeretnéd lefordítani a kódot, gcc-re és make-re lesz szükséged, amelyeket így telepíthetsz:

```shell
sudo apt install gcc make
```

Ha nem ARM64-es hardveren futsz, telepítsd a [QEMU][] emulátort és a GCC ARM64 kereszt-fordítóláncot a következővel:

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Használd a [Windows Subsystem for Linux][]-t egy Debian-alapú disztribúcióval, és kövesd a fenti Ubuntu-utasításokat.
Vagy állíts be egy Linux rendszerű virtuális gépet.

## macOS

Egy Linux rendszerű virtuális gépet bármilyen megfelelő virtualizációs megoldással elindíthatsz (például [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
