# Bevezetés

A struktúrák és osztályok példányai mindegyikének van egy implicit `self` nevű értéke, amely magára a példányra utal. A `self`-nek többféle használata is van, de leggyakrabban arra szolgál, hogy egyértelművé tegye a struktúra vagy osztály tulajdonságainak és metódusainak nevét, amikor némi zavar léphet fel.

```swift
struct MySelf {
  var x = 0

  mutating func move(x: Int) {
    // here if we just say x = x it is unclear if we mean
    // the property x or the method parameter x, so we use
    // self for clarity
    self.x = x
  }
}
```
