# Részletek

Az F#-ban mindent, aminek típusa van és definiálható, _értéknek_ nevezünk. Ide tartoznak a Boolean-ok, az egész számok és a listák, de a függvények is. Az egész számokat egy vagy több (egymást követő) számjegy alkotja, és támogatják az [alapértelmezett matematikai operátorokat][operators].

Amikor egy értéket egy névhez rendelünk, azt _kötésnek_ nevezzük. A [kötések][bindings] nem módosíthatók, ezért más nyelvek állandóihoz hasonlítanak. A kötéseket a `let` kulcsszóval hozzuk létre.

Mivel az F# statikusan típusos nyelv, minden kötésnek van típusa. A legtöbb kötésnél a típus megadása nem kötelező, mert az F# _típuskövetkeztetése_ általában az érték alapján kitalálja a típust.

```fsharp
// Automatically inferred type
let fingers = 10
```

A [függvények][functions] szintén hétköznapi kötések, csak egy vagy több paraméterrel. Egy függvény automatikusan visszaadja az utolsó kifejezését. A típuskövetkeztetés a legtöbb függvénynél is működik: elemzi, hogy milyen értékekkel hívjuk meg a függvényt, és hogy milyen értéket ad vissza.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Egy függvényt úgy hívunk meg, hogy leírjuk a nevét, majd minden paraméteréhez átadunk egy-egy argumentumot.

```fsharp
let five = add 2 3
```

Ha egy kötés típusa nem következtethető ki, a fordító hibát jelez. Ezt úgy javíthatod, hogy megadod a kötés típusát.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Az F#-ban a kötéseket csak azután használhatod, _miután_ létrehoztad őket. Ha egy kötést a létrehozása előtt használsz, az fordítási hibát okoz.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 + 4

let add x y = x + y
```

A scope kijelölése a jelentős whitespace-szel történik: a kódot a kötést deklaráló sorhoz képest szóközökkel húzod be. Az alapértelmezett konvenció szerint négy szóközzel húzunk be.

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Az F# kötéseit (köztük a függvényeket) általában modulokba szervezzük. Egy modul az egymáshoz tartozó funkcionalitást csoportosítja, és a `module` kulcsszóval hozzuk létre. A modul definíciójának meg kell előznie a kötéseit:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

Az F# kétféle [megjegyzést][comments] támogat. Az egysoros megjegyzéseket `//` előzi meg, a többsorosakat pedig `(*` és `*)` közé írjuk.
