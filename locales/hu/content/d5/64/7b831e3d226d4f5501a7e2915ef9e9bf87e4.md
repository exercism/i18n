# Bevezetés

Egy _osztály_ példányát úgy hozod létre, hogy a `new` operátoron keresztül meghívod a _konstruktorát_. A konstruktor egy speciális metódus, amelynek a célja egy újonnan létrehozott példány inicializálása. A konstruktorok úgy néznek ki, mint a szokásos metódusok, de nincs visszatérési típusuk, és a nevük megegyezik az osztály nevével.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

A szokásos metódusokhoz hasonlóan a konstruktoroknak is lehetnek paramétereik. A konstruktor paramétereit általában (privát) mezőkben tároljuk, hogy később hozzáférjünk hozzájuk, vagy valamilyen egyszeri számításban használjuk fel őket. A konstruktoroknak ugyanúgy adhatunk át argumentumokat, mint a szokásos metódusoknak.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
