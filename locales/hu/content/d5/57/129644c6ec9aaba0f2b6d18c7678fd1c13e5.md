# Utasítások

Ebben a feladatban egy New York-i szépségszalon időpont-ütemezőjén fogsz dolgozni, amely 2012. szeptember 15-én nyílt meg.

Négy részfeladatod lesz, és mindegyik időpontok dátumával foglalkozik. A dátumok és az időpontok az alábbi három formátum egyikét használják:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
A tesztek automatikusan beállítják a culture értékét `en-US`-ra. Neked magadnak nem kell beállítanod vagy megadnod a culture-t.
~~~~

## 1. Az időpont dátumának beolvasása

Valósítsd meg a `schedule` függvényt, amely egy időpont dátumának szöveges ábrázolását a megfelelő `DateTime` formátumba olvassa be:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Ellenőrizd, hogy az időpont már elmúlt-e

Valósítsd meg a `hasPassed` függvényt, amely egy időpont dátumát kapja, és ellenőrzi, hogy az időpont valamikor a múltban volt-e:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Ellenőrizd, hogy az időpont délutánra esik-e

Valósítsd meg az `isAfternoonAppointment` függvényt, amely egy időpont dátumát kapja, és ellenőrzi, hogy az időpont délutánra esik-e (>= 12:00 és < 18:00):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Írd le az időpont idejét és dátumát

Valósítsd meg a `description` függvényt, amely egy időpont dátumát kapja, és visszaadja az adott dátum és időpont leírását:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Add vissza az évforduló dátumát

Valósítsd meg az `anniversaryDate` függvényt, amely az idei évforduló dátumát adja vissza, ami szeptember 15-e:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
