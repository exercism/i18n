# Részletesen

A C egy statikusan típusos nyelv, ami azt jelenti, hogy mindennek van típusa fordítási időben.
Amikor egy [változó][variable] számára nevet választunk, és beállítjuk a típusát, azt a változó deklarálásának nevezzük.

Egy változót úgy deklarálunk, hogy kifejezetten megadjuk a típusát.
A változóneveknek [be kell tartaniuk bizonyos szabályokat][name-rules], például hogy betűvel vagy aláhúzásjellel kell kezdődniük.
Egyes nevek nem használhatók, mert [kulcsszavak][reserved-keywords] vagy [más azonosítók][reserved-identifiers] számára vannak fenntartva.

A változó beállítása vagy frissítése értékadással történik.
Az érték beállítása definiálja a változót.
A változó definiálását inicializálásnak is nevezik.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

A változó értéke a [`=` egyszerű értékadó operátorral][assignment-operator] adható meg és frissíthető.
Definiálás után a változó típusa soha nem változhat.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

A C egy [imperatív][imperative], [procedurális][procedural] nyelv.
Minden számítás [utasítások][statements] sorozataként zajlik, amelyek egy vagy több [függvény][function] részei.

Minden függvénynek lehet nulla vagy több [paramétere][parameters].
Egy függvény definiálásakor minden paraméter és a visszatérési érték típusát is kifejezetten meg kell adni.
A függvények a [`return` kulcsszóval][return-keyword] adnak vissza értéket.
A függvények alapértelmezés szerint külső [tárolási osztály][storage class]úak, ami azt jelenti, hogy a program teljes élettartama alatt léteznek, és a fájlon kívülről is láthatók lehetnek.
Ezt elkerülendő a `static` kulcsszó hozzáadásával belső láthatóságot adhatunk meg.

```c
static int add(int x, int y) {
  return x + y;
}
```

A fenti példában az `x` és `y` változók csak a függvényen belül használhatók, azaz a scope-juk a függvényre korlátozódik.
A [scope][scope] azt jelenti, hogy egy névhez (egy programelem nevéhez) tartozó érték csak abban a kódterületen érhető el, ahol definiálták.
A C fő kódterületei:

- fájl
- függvény
- blokk (például ciklusokon és más szerkezeteken belül)

A függvényeket úgy hívjuk meg, hogy megadjuk a függvény nevét, és minden paraméterhez átadunk egy argumentumot.

```c
int sum = add(1, 2);
```

A C kétféle [megjegyzést][comments] támogat.
Az egysoros megjegyzések elé `//` kerül (a C99 óta), a többsoros megjegyzéseket pedig `/*` és `*/` közé kell írni.
