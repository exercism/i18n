# Tesztelés a parancssorban

A teszteket ezzel futtathatod:

```bash
scarb cairo-test
```

Az első kivételével minden teszt ignorálva van. Miután az első teszt sikeresen lefut, nyisd meg a `tests` könyvtárban található tesztek forrásfájlját, vedd le a következő teszt `#[ignore]` jelzőjét, és érd el, hogy a teszt újra sikeres legyen. Minden egyes teszt egy függvény, amely felett `#[test]` jelző áll. Addig folytasd, amíg minden teszt sikeres nem lesz.

Ha a tesztek forrásfájljának szerkesztése nélkül szeretnéd lefuttatni _az összes_ tesztet, ezt használd:

```bash
scarb cairo-test --include-ignored
```

Ha egy konkrét tesztet szeretnél lefuttatni, függetlenül attól, hogy ignorálva van-e vagy sem, például a `some_test` tesztet, ezt használhatod:

```bash
scarb cairo-test -f some_test
```

Ha többet szeretnél megtudni a Cairo tesztjeiről, nézd meg az online [tesztdokumentációt][cairo-tests].

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
