# Névjegy

A [rekordok][records] olyan adatszerkezetek, amelyek címkékkel ellátott, összetartozó információkat csoportosítanak.
Hasonlítanak a JavaScript vagy Java objektumaihoz, illetve a C vagy Rust structjaihoz, de néhány lényeges ponton különböznek tőlük.

## Rekordok létrehozása

A rekordokat [kapcsos zárójelekkel hozzuk létre][create], az elemeiket pedig vesszők választják el.

```elm
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

A rekord típusát is hasonló szintaxissal definiáljuk, azzal a különbséggel, hogy az egyenlőségjeleket (`=`) kettőspontok (`:`) helyettesítik.

```elm
firefly : { name : String, creator : String, episodes : Int }
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

Ezeknek a típusdefinícióknak az ismétlése körülményes, ezért gyakori megoldás, hogy [típusaliasszal][record-types] osszuk meg a definíciót.

```elm
type alias TvSeries =
    { name : String
    , creator : String
    , episodes : Int
    }

firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

A típusalias automatikusan ad egy konstruktorfüggvényt is a rekordhoz.
Ez néha meglepő, hiszen az Elmben a függvényeknek kisbetűvel kell kezdődniük, a típuskonstruktorok viszont ez alól az egyik kivételt jelentik.

```elm
firefly : TvSeries
firefly = TvSeries "Firefly" "Joss Whedon" 14
```

## Rekordmezők elérése

A rekordpéldányok mezőértékeinek [elérésének][access] fő módja a pontjelölés, például a `firefly.creator`.
Az Elm fordító emellett támogat olyan speciális elérőfüggvényeket is, amelyek ponttal (`.`) kezdődnek, például a `.creator`, és bármelyik olyan rekordon működnek, amelynek van ilyen nevű mezője.
Ez a második kivétel az alól a szabály alól, hogy a függvényeknek kisbetűvel kell kezdődniük.
Valójában a felhasználó által definiált függvényeknek kisbetűvel kell kezdődniük, de az imént megismert két példát a fordító generálja, nem a programozó.

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

firefly.name
    --> "Firefly"

.creator firefly
    --> "Joss Whedon"
```

A rekordokat kötésekben is _destrukturálhatjuk_ a [rekordminta-illesztés][pattern-matching] segítségével.
A destrukturálás bármelyik olyan rekordon működik, amelynek megvannak a szóban forgó nevű mezői.

```elm
episodesCount : TvSeries -> Int
episodesCount { episodes } =
    episodes

complicatedCopy : TvSeries -> TvSeries
complicatedCopy show =
    let
        { name, creator } = show
    in
    { name = name
    , creator = creator
    , episodes = episodesCount show
    }
```

## Rekordok frissítése

Ahogy az Elmben minden, a rekordok is megváltoztathatatlanok, ezért ha egyszer egy rekordot definiáltál, a mezőértékei soha nem változhatnak.
Létezik [egy speciális szintaxis, amellyel egy meglévő rekord másolatát hozhatod létre úgy, hogy közben egy vagy több mezőjét megváltoztatod][update].
Ez a szintaxis a függőleges vonalat (`|`) használja, hogy megkülönböztesse az eredeti rekordot a megváltozó mezőktől, például: `{ oldRecord | field1 = newValue }`.

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

updatedFirefly : TvSeries
updatedFirefly =
    { firefly | creator = "J Whedon", episodes = 15 }
```

## Rekordok összehasonlítása

Az Elm a [strukturális egyenlőséget][equality] használja, ami azt jelenti, hogy ugyanannak a rekordnak két, azonos értékekkel rendelkező példánya egyenlő.

```elm
firefly1 = TvSeries "Firefly" "Joss Whedon" 14
firefly2 = TvSeries "Firefly" "Joss Whedon" 14

firefly1 == firefly2
    --> True
```

## Bővíthető rekordok

Az Elm a [strukturális típusozást][structural-typing] is támogatja, ami azt jelenti, hogy ha egy függvény egy x és y mezővel rendelkező rekordot vár, akkor bármelyik olyan rekorddal működik, amelyben megvannak ezek a mezők, legyen az kétdimenziós pont, háromdimenziós pont, űrhajó stb.
Ezeknek a rekordtípusoknak a definíciójában szerepel egy függőleges vonal (`|`), például `{ a | x : Float, y : Float }`, és az Elm szóhasználatában „bővíthető rekordoknak” nevezzük őket.
Figyelj a különbségre: a típusdefinícióban szereplő függőleges vonal (`|`) bővíthető rekord definícióját jelöli (`{ a | x : Int }`), míg egy tényleges rekordpéldányban a `|` azt jelenti, hogy a rekord néhány mezőjét frissítjük.

```elm
point2d = { x = 1, y = 2 }
point3d = { x = 3, y = 4, z = 7 }

.x point2d --> 1
.x point3d --> 3

length : { a | x : Float, y : Float } -> Float
length vector =
    sqrt (vector.x * vector.x + vector.y * vector.y)

length point2d --> 2.236068
length point3d --> 5

translateX : { a | x : Float } -> { a | x : Float }
translateX vector =
    { vector | x = vector.x + 1 }

translateX point2d --> { x = 2, y = 2 }
translateX point3d --> { x = 4, y = 4, z = 7 }
```
