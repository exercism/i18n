# Tippek

## Általános

- A struct példányait úgy hozod létre, hogy leírod a struct nevét, majd mögé kapcsos zárójelbe a mezőértékeket.
- A `@T` segítségével egy adott `T` típusú érték snapshotjait hozhatod létre, pl. a `let i: @u32 = @1;` egy olyan `i` változót hoz létre, amely az `u32` típusú `1` érték snapshotja;
- Egy snapshotból a `*` (desnap) operátorral nyerhetsz ki értéket, pl. `let int = *an_int_snapshot;`.
- A `mut` kulcsszóval módosíthatóvá nyilváníthatsz egy értéket, például így: `let mut i = 1;`.

## 1. Hozz létre egy szavazatszámlálót

- Létre kell hoznod egy mutatót egy `VoteCounter` structra, más szóval egy `@VoteCounter`-t.
- A struct példányának létrehozásakor közvetlenül hozzárendelheted a `value` paramétert.

## 2. Kérdezd le a szavazatok számát egy számlálóból

- A `*` operátort használhatod egy snapshoton, hogy desnappeld és megkapd az értékét, pl. `*my_snapshot`

## 3. Növeld egy számláló szavazatainak számát

- Ahelyett, hogy módosítanád a `@VoteCounter` snapshotot, egy új, megnövelt szavazatszámú `VoteCounter` példányt kell visszaadnod.
- A mögöttes szavazatszámláló értéket a `*` operátorral desnappelheted, vagy meghívhatod az előző részfeladatban létrehozott függvényt.

## 4. Hozd létre a választás eredményét

- Hozz létre egy új `ElectionResult` structot vagy változót, amelynek `name` és `vote_counter` mezőit a függvény argumentumaiban szereplő értékekkel töltöd ki.
- Úgy hozhatsz létre `VoteCounter` snapshotot, hogy a `@` operátort a változónév/structdeklaráció elé teszed, vagy meghívhatod a `new_vote_counter` függvényt, amit valamelyik korábbi részfeladatban készítettél.

## 5. Hirdesd ki az eredményeket

- Bár egy `ElectionResult` snapshotját kapod, a mezőit ugyanúgy elérheted a pont `.` jelöléssel, mintha nem is snapshot lenne!
- Az üzenetet úgy állítsd össze, hogy eléred a struct `name` és `vote_counter` mezőit.
- Amikor egy egymásba ágyazott snapshotot desnappelel, annyi `*` operátort kell alkalmaznod, ahány snapshotot desnappelni akarsz:

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. Szavazatok újraszámlálása

- [A szótárak megvalósítása miatt][dictionaries underneath] az a követelmény, hogy módosíthatónak kell lenniük ahhoz, hogy mind módosíthass bennük, mind olvashass belőlük, ami azt jelenti, hogy a függvényen belül a szótáron végzett módosítások a függvényen kívül is láthatók lesznek.
- Egy `let mut m: Felt252Dict<u32>` kulcsának értékét úgy növelheted, hogy összekombinálod a `get` és `insert` függvényét: `m.insert('mykey', m.get('mykey') + 1);`

[dictionaries underneath]: https://book.cairo-lang.org/ch03-02-dictionaries.html#dictionaries-underneath
