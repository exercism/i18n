# Utasítások

Ebben a feladatban egy „Wizard and Warriors” nevű szerepjátékkal játszol, amelyben vagy varázslóként, vagy harcosként játszhatsz.

A harcosokra és a varázslókra más-más szabályok vonatkoznak, amelyek meghatározzák, mennyi sebzéspontot okoznak.

A harcosra ezek a szabályok érvényesek:

- 6 sebzéspontot okoz, ha a megtámadott karakter nem sebezhető
- 10 sebzéspontot okoz, ha a megtámadott karakter sebezhető

A varázslóra ezek a szabályok érvényesek:

- 12 sebzéspontot okoz, ha a varázsló előre előkészített egy varázslatot
- 3 sebzéspontot okoz, ha a varázsló nem készített elő varázslatot

A karakterek általában soha nem sebezhetők. A varázslók viszont _sebezhetők_, ha nem készítettek elő varázslatot.

Hat részfeladat vár rád, amelyek harcos és varázsló karakterekkel dolgoznak.

## 1. Írj le egy karaktert

Bírd felül a `Character` osztály `ToString()` metódusát úgy, hogy a karakter leírását adja vissza, a következő formában: `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. A karakterek alapértelmezés szerint ne legyenek sebezhetők

Gondoskodj róla, hogy a `Character.Vulnerable()` metódus mindig `false` értéket adjon vissza.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Tedd lehetővé, hogy a varázslók előkészítsenek egy varázslatot

Valósítsd meg a `Wizard.PrepareSpell()` metódust, hogy a varázsló előre előkészíthessen egy varázslatot.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. A varázslók legyenek sebezhetők, ha nem készítettek elő varázslatot

Gondoskodj róla, hogy a `Vulnerable()` metódus `true` értéket adjon vissza, ha a varázsló nem készített elő varázslatot; egyébként `false` értéket adjon vissza.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Számítsd ki a varázsló sebzéspontjait

Valósítsd meg a `Wizard.DamagePoints()` metódust, amely a kiosztott sebzéspontokat adja vissza: 12 sebzéspont, ha elő van készítve egy varázslat, és 3 sebzéspont, ha nincs.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Számítsd ki a harcos sebzéspontjait

Valósítsd meg a `Warrior.DamagePoints()` metódust, amely a kiosztott sebzéspontokat adja vissza: 10 sebzéspont, ha a célpont sebezhető, és 6 sebzéspont, ha nem.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
