# Bevezetés

A [switch utasítás][switch] egy értéket több lehetséges egyező mintával hasonlít össze.
Tisztább és olvashatóbb alternatívát nyújt ahhoz képest, mintha több `if-else` elágazást fűznél egymás után.

A `switch` utasítás a `switch` kulcsszóval kezdődik, amelyet a vizsgálandó érték követ.
Minden lehetséges egyezést a `case` kulcsszó vezet be.
A `default` kulcsszó egy tartalék esetet definiál, amely akkor fut le, ha egyetlen megadott eset sem egyezik.
Az `if-else` láncokhoz hasonlóan a `switch` utasítás is csak az első egyező esethez tartozó kódblokkot hajtja végre.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Nézzük a következő `if-else` láncot:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Ugyanez `switch` utasítással tisztábban is leírható:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
