# For-ciklusok

A ciklusok a programozás egyik alapvető fogalma: segítségükkel ugyanazt a kódrészletet többször is végrehajthatod.
A Swiftben kétféle ciklus létezik: [`for-in` ciklusok][for-loops] és `while` ciklusok.
Ebben a fejezetben a `for-in` ciklusokkal ismerkedsz meg.

A for-ciklusokkal egy értéksorozaton mehetsz végig: minden elemet sorra veszel, és a saját magad által választott változóhoz kötöd.
A Swiftben sokféle sorozaton végigmehetsz, például tartományokon, tömbökön és stringeken (valamint további típusokon, amelyekre később térünk ki).
Amikor a sorozat minden elemén végigmentél, a ciklus véget ér.

A for-ciklust a `for` kulcsszóval deklarálod, amelyet egy változónév, az `in` kulcsszó, majd a bejárandó értékek sorozata követ.
A `for-in` ciklusban megadott változó módosíthatatlan, vagyis az értékét a cikluson belül nem változtathatod meg.
Íme egy példa egy `for-in` ciklusra, amely egy számtömbön megy végig:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
A `number` változót a `for-in` ciklus hozza létre, és csak a ciklus scope-jában érhető el.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Iterálás egy tartományon

Egy számtartományon is végigmehetsz `for-in` ciklussal.
Így egy kódrészletet meghatározott számú alkalommal hajthatsz végre: az `1...5` tartomány például az 1, 2, 3, 4 és 5 számokon megy végig, tehát a ciklus ötször fut le.
Néha egy tömbhöz hasonló adatszerkezet indexein szeretnél végigmenni, ilyenkor a `0..<array.count` tartományt használhatod.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Iterálás egy stringen

Egy stringen is végigmehetsz `for-in` ciklussal.
Így a string minden karakterén végigmész, és figyeld meg, hogy a ciklusban megadott változó típusa `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## Nem használt változók

Ha nem kell a ciklusváltozó értéke, egy aláhúzással (`_`) jelezheted, hogy figyelmen kívül hagyod.

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

A Swift egy `stride` függvényt is kínál, amellyel adott lépésközű sorozatot hozhatsz létre egy tartomány fölött.
Ezen a sorozaton aztán egy `for-in` ciklussal mehetsz végig.
A `stride` két változatban érhető el: [`stride(from:to:by:)`][stride-to] és [`stride(from:through:by:)`][stride-through]. Az elsőnél a felső határ nem része a sorozatnak, a másodiknál igen.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Figyeld meg, hogy a `to` paraméternél a felső határ nem része a sorozatnak, így a ciklus a `to` értéke előtti számig megy el, a `through` paraméternél viszont a határ is benne van, tehát ebben az esetben a `10` is megjelenik.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
