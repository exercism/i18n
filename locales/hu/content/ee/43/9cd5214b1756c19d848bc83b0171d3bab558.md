# Számtípusok

A Crystalban számos különböző számtípus létezik, különféle célokra.
Például egyes típusok gyorsabbak, de kisebb a lehetséges értékeik tartománya, mint másoknak.
Néhány típusnak nagyobb a lehetséges értéktartománya, de lassabbak.

A Crystalban léteznek előjeles és előjel nélküli egész típusok is.
Az előjeles egész típusok lehetnek pozitívak vagy negatívak.
Az előjel nélküli egész típusok csak pozitívak lehetnek.

## Előjeles egész típusok

Ezek az [előjeles egész típusok][int] a Crystalban:

| Típus    | Méret (bit) | Tartomány                                                                                                   |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128-tól 127-ig                                                                                             |
| `Int16`  | 16          | -32_768-tól 32_767-ig                                                                                       |
| `Int32`  | 32          | -2_147_483_648-tól 2_147_483_647-ig                                                                         |
| `Int64`  | 64          | -9_223_372_036_854_775_808-tól 9_223_372_036_854_775_807-ig                                                 |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728-tól 170_141_183_460_469_231_731_687_303_715_884_105_727-ig |

A kisebb típusok kevesebb memóriát használnak és gyorsabbak, mint a nagyobb típusok, de kisebb a lehetséges értékeik tartománya.

Ha tudod, hogy az értékek egy bizonyos tartományon belül lesznek, a legjobb a lehető legkisebb típust használni a memória megtakarítása és a teljesítmény javítása érdekében.

Az alapértelmezett egész típus az `Int32`.
Ha egy egész számot adott típussal akarsz deklarálni, használhatod a típusnevet utótagként, a `<number>_I <bit>` hozzáadásával.

```crystal
1_i8.class
# => Int8
```

A különböző egész típusok közötti átalakításhoz használhatod a `to_i<bit>` metódust.
A `to_i` metódus az alapértelmezett egész típusra, az `Int32`-re alakít.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Előjel nélküli egész típusok

Ezek az [előjel nélküli egész][uint] típusok a Crystalban:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

Az előjeles és előjel nélküli egészek között az egyetlen különbség, hogy az előjel nélküli egészek csak pozitívak lehetnek.
Ha egy előjel nélküli egész számot adott típussal akarsz deklarálni, használhatod a típusnevet utótagként, a `<number>_u<bit>` hozzáadásával.
A különböző előjel nélküli egész típusok közötti átalakításhoz használhatod a `to_u<bit>` metódust.
A `to_u` metódus az alapértelmezett előjel nélküli egész típusra, az `UInt32`-re alakít.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Lebegőpontos típusok

Ezek a lebegőpontos típusok a Crystalban:

| Típus     | Méret (bit) | Tartomány            |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38-tól 3.4E+38-ig   |
| `Float64` | 64          | 2.3E-308-tól 1.7E+308-ig |

Két különböző [lebegőpontos típus][float] van, az egyik pontosabb, mint a másik.

Az alapértelmezett lebegőpontos típus a `Float64`.

A különböző lebegőpontos típusok közötti átalakításhoz használhatod a `to_f<bit>` metódust.
A `to_f` metódus az alapértelmezett lebegőpontos típusra, a `Float64`-re alakít.

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
