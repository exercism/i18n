# Bevezetés

## Rekurzió

A rekurzív függvények olyan függvények, amelyek önmagukat hívják meg.

Egy rekurzív függvénynek legalább egy _alapesetre_ és legalább egy _rekurzív esetre_ van szüksége.

Az _alapeset_ úgy ad vissza egy értéket, hogy közben nem hívja meg újra a függvényt.
A _rekurzív eset_ újra meghívja a függvényt, és úgy módosítja a bemenetet, hogy az előbb-utóbb megfeleljen az alapesetnek.

Az Elmben a rekurzív függvényeket jellemzően mintaillesztéssel definiáljuk `case` kifejezésekkel vagy több függvényklóz használatával.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### Ciklusok rekurzióval

Az immutabilitás miatt az Elmben a ciklusokat másképp írjuk, mint az imperatív nyelvekben.
Például a ciklusok jellemzően így néznek ki:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Egy olyan funkcionális nyelvben, mint az Elm, nem lehet módosítani a változókat.
Ezért a ciklusokat rekurzióval kell megvalósítani.

Egy `for` ciklus megfelelője az Elmben így nézne ki:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

A gyakorlatban az Elmben a listák és más adatszerkezetek iterálására legtöbbször a `List` modul függvényeit használjuk, például a `List.map`, a `List.filter` és a `List.foldl` függvényt.
A háttérben ezeket a függvényeket rekurzióval valósították meg.
