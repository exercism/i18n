# Bevezetés

## Külső függvények

A Gleam futhat az Erlang virtuális gépen (BEAM), vagy JavaScript futtatókörnyezeteken. Sok más nyelv is használja ezeket a futtatókörnyezeteket, és gyakran hasznos, ha a Gleamből meg tudjuk hívni az ezeken a nyelveken írt kódot.

A Gleam _külső függvény_ szolgáltatása lehetővé teszi, hogy más nyelvekben írt függvényeket importálj a Gleamba, és futásidejű többletköltség nélkül hívd meg őket.

Ha a Gleam-projekted az Erlang virtuális gépen fut, és a `reverse` függvényt szeretnéd meghívni az Erlang `lists` moduljából, azt úgy teheted meg, hogy hozzáadod a `@external` attribútumot egy Gleam-függvény fejéhez, így:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Ezután normál Gleam-függvényként hívhatod meg:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Ha ezt a kódot JavaScript futtatókörnyezetekre próbálod lefordítani, hibaüzenettel fog meghiúsulni, mert nincs JavaScript-implementáció. Egy másik implementációt is megadhatsz a JavaScript futtatókörnyezetekhez, így:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Az is lehetséges, hogy írj egy Gleam-implementációt, amelyet akkor használ a rendszer, ha nincs külső implementáció az aktuális fordítási célhoz:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## Külső típusok

A külső típusok segítségével más nyelvekben, például Erlangban vagy JavaScriptben definiált adattípusokra hivatkozhatsz.

Külső típus definiálásához deklarálj egy típust, de ne adj meg hozzá konstruktorokat. Ezután ugyanúgy használhatod, mint bármely más típust.

```gleam
pub type OrderedDictionary(element)
```
