# Bevezetés

Sok más nyelvvel ellentétben a JavaScriptben két különböző dolog is jelöli egy (értelmes) érték hiányát.
Van a `null` és az `undefined`.

## Null

A `null` primitív értéket szándékos „üres értékként” használjuk bármilyen típusú változóhoz.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Azt, hogy egy változó null-e, a [szigorú egyenlőség operátor][mdn-strict-equality] `===` segítségével ellenőrizheted.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Az a változó, amelynek nem adtunk értéket, `undefined` típusú.<sup>1</sup>

Ez azt jelenti, hogy míg a `null` egy üres értéket jelöl (de mégiscsak egy értéket), addig az `undefined` egy érték teljes hiányát jelöli. 🤯

Az `undefined` többféle helyzetben is megjelenik.

- Ha egy változót érték nélkül deklarálunk (kezdőérték nélkül), akkor az `undefined` lesz.
- Ha egy objektumban egy nem létező kulcshoz próbálsz hozzáférni, `undefined`-et kapsz.
- Ha egy függvény nem ad vissza értéket, az eredmény `undefined`.
- Ha egy argumentumot nem adunk át egy függvénynek, az `undefined` lesz, kivéve, ha az argumentumnak van alapértelmezett értéke.

```javascript
let name;
console.log(name);
// => undefined
```

Azt, hogy egy változó undefined-e, a szigorú egyenlőség operátor `===` segítségével ellenőrizheted.

```javascript
let name;

name === undefined;
// => true
```

## Opcionális láncolás

Ha megpróbálsz lekérni egy egymásba ágyazott értéket egy objektumból, de a szülő kulcs nem létezik, a JavaScript hibát dob.
Ennek egyszerű elkerülésére 2020-ban bekerült a nyelvi specifikációba az opcionális láncolás.
Az opcionális láncolás operátorral `?.` elérheted, hogy a JavaScript csak akkor próbálja meg elérni az egymásba ágyazott kulcsot, ha a szülő nem `null` és nem `undefined`.
Ellenkező esetben `undefined`-et ad vissza.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Nullish coalescing

Vannak olyan helyzetek, amikor alapértelmezett értéket szeretnél alkalmazni, ha egy változó null vagy undefined (de csak akkor).
Ennek kezelésére 2020-ban bevezették a nullish coalescing operátort `??`.
Csak akkor adja vissza a jobb oldali operandust, ha a bal oldali operandus `null` vagy `undefined`.
Ellenkező esetben a bal oldali operandust adja vissza.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
