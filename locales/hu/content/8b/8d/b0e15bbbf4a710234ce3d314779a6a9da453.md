# Utasítások

Beágyazott rendszert írsz egy Take-A-Number géphez. Ez egy nagyon egyszerű modell. Egymást követő számokat tud kiadni, és meg tudja mondani, mi volt az utoljára kiadott szám.

## 1. Indítsd el a gépet

Valósítsd meg a `start/0` függvényt. Hozzon létre egy új folyamatot, és adja vissza a folyamat PID-jét. Az új folyamatnak egyelőre nem kell semmit tennie.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

Ne feledd, hogy a PID minden futtatáskor eltérő lehet.

## 2. Jelentsd a gép állapotát

Módosítsd a gépet úgy, hogy az újonnan létrehozott folyamat készen álljon az üzenetek fogadására (indíts egy _receive_-ciklust) `0` kezdőállapottal. Legyen képes fogadni a `{:report_state, sender_pid}` üzeneteket. Ezekre az üzenetekre válaszul küldje el az aktuális állapotát (az utoljára kiadott sorszámot) a `sender_pid`-nek, majd várjon további üzenetekre.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. Adj ki számokat

Módosítsd a gépet úgy, hogy fogadni tudja a `{:take_a_number, sender_pid}` üzeneteket. Növelje az állapotát 1-gyel, küldje el az új állapotot a `sender_pid`-nek, majd várjon további üzenetekre.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. Állítsd le a gépet

Módosítsd a gépet úgy, hogy fogadni tudja a `:stop` üzenetet. Ekkor hagyja abba a további üzenetekre való várakozást.

## 5. Hagyd figyelmen kívül a váratlan üzeneteket

Módosítsd a gépet úgy, hogy amikor váratlan üzenetet kap, hagyja figyelmen kívül, és folytassa a további üzenetekre való várakozást.
