# Tesztek


A weboldalunk tesztfuttatója a [pytest][pytest: Getting Started Guide].
Ha helyben szeretnéd futtatni a Python-kurzus tesztjeit, telepítened kell a `pytest`-et a fejlesztői gépedre.
A következő `pytest` bővítményeket is érdemes telepítened:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

Bővebb információt a weboldalunk [Python tesztelési útmutatójában][Python track tests page] találsz.


### Tesztek futtatása

A mellékelt tesztek futtatásához a terminálban a `cd` parancs segítségével lépj be abba a mappába, ahol a feladat található (_az alábbi `<exercise-folder-location>` helyére írd be a saját elérési utadat_).
A tesztfájlok általában `_test.py`-ra végződnek, és ugyanazok a tesztek futnak le a weboldalon, amikor beküldesz egy megoldást.

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

Ezután futtasd a `pytest` parancsot a terminálban, a `<exercise_test.py>` helyére pedig írd be a tesztfájl nevét:

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### Gyakori kapcsolók
- `-o` : felülírja az alapértelmezett `pytest.ini`-t (_ezzel elkerülheted a markerekkel kapcsolatos figyelmeztetéseket_)
- `-v` : részletes kimenet engedélyezése.
- `-x` : az első hiba után leállítja a tesztek futtatását.
- `--ff` : a korábbi futtatás hibás tesztjeit futtatja először, mielőtt a többi tesztesetre sor kerülne.

További opciókért használd a `python3 -m pytest -h` vagy a `py -m pytest -h` parancsot.


### Figyelmeztetések javítása

Ha a `pytest` meghívásakor nem használod a `pytest -o markers=task` parancsot, akkor az új szintaxist használó teszteknél `PytestUnknownMarkWarning` figyelmeztetést kaphatsz:

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

Hogy ne kelljen minden egyes tesztfuttatásnál beírnod a `pytest -o markers=task` parancsot, használhatsz egy `pytest.ini` konfigurációs fájlt.
Készítettünk egyet, amely a Python-kurzus könyvtárának legfelső szintjéről tölthető le: [pytest.ini][pytest.ini].

Saját `pytest.ini` fájlt is létrehozhatsz a következő tartalommal:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

Ha a `pytest.ini` fájlt a Python-kurzus feladatainak _gyökér-_ vagy _munkakönyvtárába_ helyezed, az regisztrálja a markereket, és megszünteti a figyelmeztetéseket.
A pytest markerekről bővebb információt a `pytest` dokumentációjában találsz: [marking test functions][pytest: marking test functions with attributes] és [working with custom markers][pytest: working with custom markers].

A pytest konfigurációk testreszabásáról a `pytest` dokumentációjában, a [configuration file formats][pytest: configuration file formats] oldalon találsz információt.
