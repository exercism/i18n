# Bevezetés

Az ABAP támogat egy objektumorientált programozási modellt, amely az ABAP Objects osztályaira és interfészeire épül.

## (Újra)értékadás

Néhány fő módja van annak, hogy értéket rendelj nevekhez az ABAP-ban: változók vagy konstansok használatával. Az Exercismen a változókat mindig [snake-case][wiki-snake-case] írásmóddal írjuk. Nincs hivatalos útmutató, amihez tartsd magad, és a különböző cégeknek és szervezeteknek más-más stílusútmutatójuk van. _Nyugodtan írd a változókat úgy, ahogy neked tetszik_. Ami előnye annak, ha úgy írod őket, ahogy a feladatok elő vannak készítve, hogy a webes felületen és a legtöbb IDE-ben másképp lesznek kiemelve.

Az ABAP-ban a változókat a [`constant`][constant] vagy a [`data`][data] kulcsszóval lehet definiálni.

Egy változó az élettartama során különböző értékekre hivatkozhat, ha `data`-t használsz. Például a `my_first_variable` sokszor definiálható és újradefiniálható az [értékadó operátor `=`][assignment] segítségével:

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

A `data`-val ellentétben azok a változók, amelyeket `constant`-tal definiálunk, csak egyszer kaphatnak értéket. Így definiálunk konstansokat az ABAP-ban.

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## Osztály- és metódusdeklarációk

Az ABAP-ban a funkcionalitás egységeit _metódusokba_ zárjuk, és a metódusokat általában ugyanabba az [osztályba][classes] csoportosítjuk, ha összetartoznak. Ezek a metódusok fogadhatnak paramétereket (argumentumokat), és a metódusdefinícióban a `returning` kulcsszóval _visszaadhatnak_ egy értéket. A metódusokat a `( )` szintaxissal hívjuk meg.

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 Az ABAP-ban _sok_ különböző módon lehet osztályokat és metódusokat deklarálni. A kurzus igyekszik fokozatosan bevezetni őket, de ha már ismered őket, nyugodtan használd bármelyiket. A legtöbb esetben az egyik vagy a másik használata nem jobb vagy rosszabb.
