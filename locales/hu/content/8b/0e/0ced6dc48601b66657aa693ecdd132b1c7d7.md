# Utasítások

Épp a nagyra becsült új játékot, a **Crystal Hunter**t fejleszted.
A játékban egy karaktert irányítasz, aki mozog és kristályokat gyűjt.
A játékos akkor nyer, ha összegyűjti az összes kristályt.
Ha a játékos kapcsolatba kerül egy banditával, elveszíti az összes kristályát és a játékot.
Ez alól a szabály alól van egy kivétel: a játékosnak lehet aktív power-upja, ami láthatatlanná teszi őt a banditák számára.

A célod, hogy megírj néhány szabályt, amelyeket a játékban felhasználnak.

## 1. Határozd meg, hogy a karakter kap-e bónuszpontokat

A játékban a karakter bónuszpontokat kap, ha úgy ér hozzá egy banditához, hogy közben aktív power-upja van.

Definiáld a `Rules#bonus_points?` metódust, amely két argumentumot vár (_van-e a karakternek aktív power-upja_, és _hozzáér-e a karakter egy banditához_), és egy Boolean értéket ad vissza, ami megmondja, hogy a karakter kap-e bónuszpontokat.
A metódus csak akkor adjon vissza `true`-t, ha a karakternek aktív a power-upja, és hozzáér egy banditához, egyébként `false`-t.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. Határozd meg, hogy a karakter szerez-e pontot

A játékos pontot szerez, amikor felvesz egy kristályt vagy egy power-upot.

Definiáld a `Rules#score?` metódust, amely két argumentumot vár (_hozzáér-e a karakter egy power-uphoz_, és _hozzáér-e a karakter egy kristályhoz_), és egy Boolean értéket ad vissza, ami jelzi, hogy a karakter szerzett-e pontot.
A metódus `true`-t adjon vissza, ha a karakter hozzáér egy power-uphoz vagy egy kristályhoz, egyébként `false`-t.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. Határozd meg, hogy a karakter veszít-e

Definiáld a `Rules#lose?` metódust, amely két argumentumot vár (_aktív-e a karakter power-upja_, és _hozzáér-e a karakter egy banditához_), és egy Boolean értéket ad vissza, ami jelzi, hogy a karakter veszít-e.
A metódus `true`-t adjon vissza, ha a karakter hozzáér egy banditához, és nincs aktív power-upja, egyébként `false`-t.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. Határozd meg, hogy a karakter nyer-e

Definiáld a `Rules#win?` metódust, amely három argumentumot vár (_felszedte-e a karakter az összes kristályt_, _aktív-e a karakter power-upja_, és _hozzáér-e a karakter egy banditához_), és egy Boolean értéket ad vissza, ami jelzi, hogy a karakter nyer-e.
A metódus `true`-t adjon vissza, ha a karakter összegyűjtötte az összes kristályt, és a 3. részben meghatározott argumentumok alapján nem veszített, egyébként `false`-t.

```crystal
Rules.new.win?(false, true, false)
# => false
```
