# SQLite-specifikus utasítások

A **result** oszlopban egy JSON-kódolt, objektumokból álló objektumnak kell szerepelnie, ahol minden szó egy kulcs, a hozzá tartozó darabszám pedig egy egész szám.

Vegyük például a fenti mondatot: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
Ehhez a bemenethez a **result** a következő kell legyen:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## Tábla sémája

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
