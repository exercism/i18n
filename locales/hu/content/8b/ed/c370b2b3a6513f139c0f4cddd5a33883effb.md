# Tippek

## Általános

- A [`Map` API dokumentációja][map-docs] felsorolja a `Map` interfészen elérhető metódusokat.

## 1. Add vissza a kódokat egy Map-ben

- [Olyan módon][declaring-members] kell definiálnod egy `Map`-et, hogy az osztály metódusaiban is használni tudd.

## 2. Adj elemeket a szótárhoz

- A Map rendelkezik egy [metódussal][map-put-docs], amellyel hozzáadhatod és frissítheted egy kulcs értékét.

## 3. Keresd ki egy hívószám országát

- A Map rendelkezik egy [metódussal][map-get-docs], amellyel lekérheted egy kulcs értékét.

## 4. Ne engedj meg duplikátumokat

- Van mód arra, hogy ellenőrizd, hogy a Map tartalmaz-e egy [kulcsot][map-contains-key-docs] vagy egy [értéket][map-contains-value-docs].

## 5. Keresd meg egy ország hívószámát

- Van [mód][map-entry-set-docs] arra, hogy egy Map bejegyzéseiből iterálható gyűjteményt kapj, amellyel végigmehetsz a kulcs-érték párokon.

## 6. Frissítsd az ország hívószámát

- Ne feledkezz meg arról, hogy az ország korábbi hívószáma is benne lesz a Map-ben.
- Van egy [metódus][map-remove-docs] egy bejegyzés eltávolítására a Map-ből.
