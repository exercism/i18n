# Utasítások

Egy nemrég lezajlott biztonsági vizsgálat után arra kértek, hogy tisztítsd meg a szervezet archivált naplófájljait.

## 1. Azonosítsd a hibás naplósorokat

Fogalmat kell alkotnod arról, hogy az archívumodban hány naplósor nem felel meg a jelenlegi szabványoknak.
Úgy gondolod, hogy egy egyszerű ellenőrzés megmutatja, hogy egy naplósor érvényes-e.
Ahhoz, hogy egy sor érvényesnek számítson, a következő stringek egyikével kell kezdődnie:

- `[DEBUG]`
- `[INFO]`
- `[WARNING]`
- `[ERROR]`

Valósítsd meg az `is_valid_line` függvényt, amely `True`-t ad vissza, ha a naplósor érvényes.

```gleam
log_parser.valid_line("[ERROR] Network Failure")
// -> True

log_parser.valid_line("Network Failure")
// -> False
```

## 2. Bontsd fel a naplósort

Nem sokkal azután, hogy elkezdted a naplófeldolgozó projektet, rájössz, hogy az egyik alkalmazás naplói nincsenek sorokra bontva, mint a többieké. Ebben a projektben az, aminek külön sorokban kellene lennie, egyetlen sorban van, cifra nyilakkal összekapcsolva, mint például a `<--->` vagy a `<*~*~>`.

Valójában bármely string, amelynek az első karaktere `<`, az utolsó karaktere `>`, és közte nulla vagy több a következő karakterek közül: `~`, `*`, `=` és `-`, elválasztóként használható e projekt naplóiban.

Valósítsd meg a `split_line` függvényt, amely egy sort kap, és stringek listáját adja vissza.

```gleam
log_parser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
// -> ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Címkézd meg a sorokat felhasználónevekkel

Észrevetted, hogy néhány naplósor olyan mondatokat tartalmaz, amelyek felhasználókra utalnak.
Ezek a mondatok mindig tartalmazzák a `"User"` stringet, amelyet egy vagy több whitespace-karakter, majd egy felhasználónév követ.
Úgy döntesz, hogy megcímkézed az ilyen sorokat.

Valósítsd meg a `tag_with_user_name` függvényt, amely feldolgozza a naplósorokat:

- A(z) `"User"` stringet nem tartalmazó sorok változatlanok maradnak.
- A(z) `"User"` stringet tartalmazó sorok esetén a sor elé írd a `[USER]` címkét, amelyet a felhasználónév követ.

```gleam
log_parser.tag_with_user_name("[INFO] User Alice created a new project")
// -> "[USER] Alice [INFO] User Alice created a new project"
```

Feltételezheted, hogy:

- A(z) `"User"` string minden előfordulását egy vagy több whitespace-karakter, majd a felhasználónév követi.
- Minden sorban legfeljebb egyszer fordul elő a(z) `"User"` string.
- A felhasználónevek nem üres stringek, amelyek nem tartalmaznak whitespace-t.
