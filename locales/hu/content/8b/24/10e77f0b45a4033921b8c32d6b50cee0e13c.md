# Bevezetés

## Iterátorok

A Gleam `Iterator` típusa abban hasonlít a listához, hogy értékek rendezett gyűjteménye, amelyek mindegyike ugyanolyan típusú. A listától abban különbözik, hogy lusta: nem tárolja az összes értékét egyszerre a memóriában, hanem csak akkor számítja ki őket, amikor szükség van rájuk.

Ez akkor hasznos, ha nagyon nagy vagy akár végtelen méretű sorozatokkal dolgozunk, mert így akkor is tudunk velük dolgozni, ha nincs elég szabad memóriánk ahhoz, hogy egyszerre tároljuk az összeset.

A `gleam/iterator` modul definiálja az `Iterator` típust, valamint az iterátorokkal való munkához szükséges függvényeket.

A listákhoz használt függvények közül sok az iterátoroknál is megtalálható, például a `map`, a `filter` és a `take`. Ezek a függvények iterátorokat adnak vissza, így valójában nem végeznek semmilyen munkát, amíg az iterátort fel nem használjuk.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

Az `unfold` függvénnyel iterátorokat hozhatunk létre egy olyan függvényből, amelyet ismételten meghívunk, hogy előállítsa a sorozat következő értékét.

Itt az `unfold` függvényt használjuk egy olyan iterátor létrehozására, amely a Fibonacci-sorozatot állítja elő:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

Ez a sorozat itt végtelen, ezért a `take` függvénnyel tesszük végessé, mielőtt az értékeket listába gyűjtenénk. Ha egy végtelen iterátoron hívjuk meg a `to_list` függvényt, a program addig fut, amíg el nem fogy a memória, és össze nem omlik.
