# Bevezetés

A Gleamben két különböző számtípus van: az egészek és a lebegőpontos számok.

Az egészek egész számokat jelölnek.

```gleam
let integer = 3
// -> 3
```

Az egészekhez az áttekinthetőség kedvéért alulvonásokat is hozzáadhatsz.

```gleam
1_000_000 // One million
```

A Gleamben számos operátor működik egész számokkal.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
