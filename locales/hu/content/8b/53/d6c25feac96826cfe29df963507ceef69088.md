# Bevezetés

## Enumok

Az _enum típus_ egy speciális adattípus, amely lehetővé teszi, hogy egy változó előre definiált konstansok halmaza legyen.
A változónak meg kell egyeznie az egyik olyan értékkel, amelyet előre meghatároztak hozzá.
Gyakori példák közé tartoznak az égtájak (`NORTH`, `SOUTH`, `EAST` és `WEST` értékek) és a hét napjai.

Mivel ezek konstansok, az enum típus mezőinek nevei csupa nagybetűvel íródnak.

### Enum típus definiálása

A Java programozási nyelvben úgy definiálsz enum típust, hogy az `enum` kulcsszót használod.
Például egy hét napjait reprezentáló enum típust így adnál meg:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Enum típusokat érdemes használnod, amikor konstansok egy rögzített halmazát szeretnéd reprezentálni.
Ide tartoznak az olyan természetes enum típusok is, mint a Naprendszerünk bolygói, valamint azok az adathalmazok, amelyeknél fordítási időben ismered az összes lehetséges értéket, például egy menü választási lehetőségei, a parancssori kapcsolók és így tovább.

### Enum típus használata

Íme néhány kódrészlet, amely megmutatja, hogyan használd a fent definiált `DayOfWeek` enumot:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### Metódusok és mezők hozzáadása

A Java programozási nyelv enum típusai sokkal nagyobb tudásúak, mint más nyelvek megfelelői.
Az `enum` deklaráció egy _osztályt_ definiál (ezt hívják _enum típusnak_).
Az enum osztály törzse tartalmazhat metódusokat és egyéb mezőket:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

A `getNumberOfStars` metódus meghívása a `Rating` enum típus egyik tagján:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
