# a String charAt vagy codePointAt metódusát kell használni

Amikor a Hamming-távolság kiszámításához karaktereket hasonlítasz össze, a String `charAt` vagy `codePointAt` metódusát használd.
A többi megoldás általában további tárhelyet igényel, mert a karakterekből új tömböt vagy listát kell létrehozni.
