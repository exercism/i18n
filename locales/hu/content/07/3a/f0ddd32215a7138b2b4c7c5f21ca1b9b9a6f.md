# Részletesen

Alapvetően kétféle ciklus létezik:

1. Addig ismétlünk, amíg egy feltétel teljesül.
2. Végigmegyünk egy gyűjtemény elemein.

Mindkettő [megvalósítható R-ben][web-loops], bár az első talán gyakoribb.

## `while` és `repeat`

Azoknál a nyitott végű problémáknál, ahol előre nem tudjuk, hányszor fut le a ciklus, R kínál egy feltételes [`while`][ref-control] ciklust és egy feltétel nélküli [`repeat`][ref-control] ciklust (ez utóbbi a `while (TRUE)` megfelelője).

Az alapvető forma meglehetősen egyszerű:

```R
while (condition) {
  do_something()
}
```

Ebben az esetben a program addig járja körbe a ciklust, amíg a `condition` már nem `TRUE`.

Kétféleképpen lehet idő előtt kilépni a ciklusból:

- A `break` kilép a ciklusból, és a végrehajtás a ciklus záró kapcsos zárójele (`}`) utáni következő sorral folytatódik.
- A `return(x)` leállítja az aktuális függvény végrehajtását, és visszaadja az `x` visszatérési értéket a hívónak.

Ezekkel a lehetőségekkel néha kényelmes egy „végtelen” ciklust létrehozni a `repeat { ... }` segítségével, majd a ciklus törzsén belül megkeresni a leállási feltételt, amely `break`-et vagy `return`-t vált ki.

Ez a három változat egyenértékű, és mindegyik `x == 0.4444...` értékkel végződik.

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Iterálás vektorokon (vagy más gyűjteményeken)

Erre R-ben gyakran nincs szükség.
Ahogy más fogalmaknál is szó volt róla, sok függvény a teljes vektoron működik.

Az explicit ciklusok azonban néha elkerülhetetlenek.
Ez különösen akkor igaz, ha:

- a ciklus törzsének mellékhatásai vannak, például kiíratás vagy fájl-I/O.
- a ciklus addig folytatódik, amíg el nem érünk egy bizonyos kritériumot, kiszámíthatatlan számú iteráció után.

A ciklus feltételét zárójelbe kell tenni.
Ahogy a függvények törzsénél, úgy az egysoros ciklustörzseknél is elhagyható a kapcsos zárójel (de gyakran kiírják).

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Ha az aktuális iteráció nem teljesít valamilyen feltételt, a `next` utasítással azonnal a következő iterációra ugorhatunk:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

Ha szükség van a numerikus indexre, használd a [`seq_along()`][ref-seq_along] függvényt.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Az `i in 1:length(v)` használata _nem_ javasolt, mert problémákat okozhat, ha a `length(v)` nulla.
Az `1:0` intervallum ugyanaz, mint a `c(1, 0)`, így a ciklus törzse lefut, és valószínűleg hibát okoz.
A `seq_along()` függvényt kifejezetten arra tervezték, hogy ezt az esetet helyesen kezelje.
