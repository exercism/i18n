# Feladatok tesztelése

Az alábbi lépéseket követve dolgozz ki egy megoldást egy feladathoz, és teszteld helyben.

## Töltsd le a feladatot

Nyiss egy Command Promptot, és futtasd az alábbi parancsot a kiválasztott feladat nevével a letöltéshez.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Dolgozd ki a megoldásodat

1. Futtasd az alábbi parancsot, hogy belépj az újonnan letöltött feladat könyvtárába.

     >**Tipp:** Az alábbi parancsban szereplő könyvtár helye az operációs rendszeredtől és a beállított Exercism munkaterülettől függ. A munkaterületed helyét az `exercism configure` parancs futtatásával tudhatod meg.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Kövesd a megadott utasításokat, és dolgozz ki egy megoldást a feladathoz.

## Teszteld a megoldásodat

Egyes Ballerina-feladatokhoz egyetlen teszt tartozik, másokhoz több. A teszteket a feladat gyökérkönyvtárában lévő `/tests` könyvtár megfelelő tesztfájljában találod.

### Feladat tesztelése egyetlen teszttel

Futtasd az alábbi parancsot a feladat tesztjének futtatásához.

Alapértelmezés szerint csak az első teszt van engedélyezve. Ez szándékos, így arra tudsz összpontosítani, hogy csak azt az egy tesztet sikeressé tedd. 
     
```sh
bal test
```

### Feladat tesztelése több teszttel

Az alábbi lépéseket követve tesztelhetsz egy több teszttel rendelkező feladatot.

1. Amint az első teszt sikeres, engedélyezd a következő tesztet az `@test:Config` annotáció `enable: false` tulajdonságának eltávolításával.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Futtasd az alábbi parancsot az engedélyezett teszt futtatásához.

   ```sh
     bal test
   ```

3. Ismételd meg a fenti két lépést a többi teszt engedélyezéséhez.

Akkor teljesítetted sikeresen a feladatot, ha minden tesztet engedélyeztél, és az implementációd mindegyiken átmegy.

Sok sikert, és jó szórakozást a feladatok megoldásához!
