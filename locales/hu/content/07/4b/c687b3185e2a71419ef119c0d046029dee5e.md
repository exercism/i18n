# Kiegészítés

## „Null” a Tcl-ben

A Tcl-nek nincs `null` vagy `nil` értéke.
A gyakorlatban gyakran az üres string jelöli, hogy „nincs érték”.
Ez viszont kényes lehet olyan helyzetekben, amikor az üres string valójában érvényes érték, például egy olyan listában, ami a CSV-adatok egy sorát reprezentálja.

Ebben a feladatban az üres stringet tekintsd `null` értéknek, amelyet el kell dobni.
