# Bevezetés

A JavaScript objektum-destrukturálási szintaxisa tömör módja annak, hogy egy objektumból tulajdonságokat nyerjünk ki, és azokat különálló változókhoz rendeljük.

Ebben a példában időjárás-szimbólumokat nyerünk ki a `weather` objektumból:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

cloud_with_lightning;
// => '🌩️'
```
