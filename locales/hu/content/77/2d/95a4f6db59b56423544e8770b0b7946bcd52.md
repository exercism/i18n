# Bevezetés

## Függvények

A Gleamben a függvényeket a `pub fn` szintaxissal definiálod.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Ez a függvény két argumentumot vesz át, mindkettő `Int` típusú, és egy `Int` típusú értéket ad vissza. A Gleamben nincs `return` kulcsszó, egy függvény utolsó kifejezésének értéke mindig _implicit módon visszaadódik_.

Az argumentumok típusannotációi és a visszatérési típus megadása opcionális, a Gleam pedig mindig teljesen típusellenőrzi a kódodat. A Gleam-programozók általában az áttekinthetőség kedvéért típusannotációkkal látják el a függvényeiket, de nyugodtan elhagyhatod őket, ha szeretnéd.

```gleam
pub fn add(x, y) {
  x + y
}
```

Egy függvényt a `function_name(argument1, argument2)` szintaxissal hívhatsz meg.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Változók

A Gleamben a változókat a `let name = expression` szintaxissal definiálod.

```gleam
pub fn main() {
  let count = 1
}
```

A változókat típusannotációval is deklarálhatod. A függvényargumentumokhoz hasonlóan ezek is opcionálisak, bár a legtöbb Gleam-programozó a rövidség kedvéért elhagyja a változók típusannotációit.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## String literálok

A Gleamben a stringeket kettős idézőjelek közé írjuk.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Kódkommentek

A kommentekkel megjegyzéseket hagyhatsz a forráskódot olvasó fejlesztőknek. A Gleamben a kommentek egysorosak, és `//` előzi meg őket.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
