# Bevezetés

A Gleamben a konstansokkal nevet adhatunk az értékeknek. Definíciójukhoz a `const` kulcsszót használjuk.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Ha a `pub` kulcsszóval definiálod őket, a modulkonstansok más modulokból is elérhetők, egyébként csak abból a modulból férhetsz hozzájuk, amelyben definiáltad őket.
