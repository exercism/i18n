# Utasítások

Ebben a feladatban a húgodnak segítesz szerkeszteni az iskolai dolgozatát. A tanár a helyes írásjelekre, a nyelvtanra és a kiváló szóhasználatra figyel.

Négy részfeladatban kell karakterláncokat megtisztítanod és módosítanod.

## 1. Írd nagybetűvel a dolgozat címét

Minden jó dolgozathoz megfelelően formázott cím kell.
Valósítsd meg a `capitalize_title(<title>)` függvényt, amely paraméterként egy `title` `str`-t kap, és minden szó első betűjét nagybetűssé teszi.
A függvény egy title case formátumú `str`-t adjon vissza.


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. Ellenőrizd, hogy minden mondat ponttal végződik-e

Szeretnéd, ha a dolgozat írásjelei tökéletesek lennének.
Valósítsd meg a `check_sentence_ending()` függvényt, amely paraméterként egy `sentence` értéket kap. A függvény egy `bool` értéket adjon vissza.


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. Tisztítsd meg a szóközöket

Ahhoz, hogy a dolgozat professzionálisnak tűnjön, el kell távolítani a felesleges szóközöket.
Valósítsd meg a `clean_up_spacing()` függvényt, amely paraméterként egy `sentence` értéket kap.
A függvénynek el kell távolítania a felesleges szóközöket a mondat elejéről és végéről is, és egy új, frissített `str` mondatot kell visszaadnia.


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. Cserélj ki szavakat szinonimára

Ahhoz, hogy a dolgozat _még jobb_ legyen, néhány melléknevet kicserélhetsz a szinonimájára.
Írd meg a `replace_word_choice()` függvényt, amely paraméterként egy `sentence`, egy `old_word` és egy `new_word` értéket kap.
A függvény cserélje le az `old_word` összes előfordulását a `new_word`-re, és adjon vissza egy új `str`-t a frissített mondattal.


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
