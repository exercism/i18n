# Kiegészítés az utasításokhoz

## Az IO folyamata

A többi feladattól eltérően a `grep` esetében a „külvilággal” is kapcsolatba kell lépni: fájlokat kell olvasni, rendszerhibákat kezelni, és a `stdout`-ra írni.

A Leanben a rendszerrel való interakció általában az [IO][io] monádban történik, amely lehetővé teszi, hogy a mellékhatások egy elkülönített környezetben jelentkezzenek, anélkül hogy a legtöbb más függvény tiszta állapotát befolyásolnák.

## Argumentumok beolvasása

A Leanben egy fájl futtatható szkriptként is meghívható, akár közvetlenül, önálló szkriptként a `lean --run` paranccsal, akár a `lake` használatával.

Egy Lean-projektnek egyetlen belépési pontja van: a `main` nevű függvény, amely egy `List String`-et kap, benne a neki átadott összes argumentummal.
Azért, hogy ebben a feladatban ugyanúgy kapja meg az argumentumokat, mintha a `Grep.lean`-t futtatható programként futtatnánk, az átadás ugyanígy történik.

## Fájlok olvasása

A Lean [függvényeket][files] kínál a fájlok kezelésére az `IO.FS` monádban.
Például az `IO.FS.readFile` segítségével egy adott útvonalon lévő fájl tartalmát olvashatod be `String`-ként.

## Kimenet írása

A feladatban az eredményt nem visszatérési értékként kell megadni, hanem a szabványos kimenetre vagy a szabványos hibakimenetre kell írni.
Erre a célra [függvények][console] állnak rendelkezésre a Leanben.

## Rendszerhibák kezelése

A `Except`-beli hibákkal ellentétben az `IO` kivételei valódi futásidejű kivételek.
A kezelésükhöz használhatod a `try`/`catch` szerkezetet:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
