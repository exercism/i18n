# Utasítások

Andrew, aki fejlesztőként dolgozik a cégénél, nemrég egy könnyűsúlyú SQL-lekérdezés-generátort épített egy adatbázis-migrációs eszközhöz.
Az első, naiv implementációja tökéletesen működött kis adathalmazokon.
A nagy éles migrációk során azonban az alkalmazás túlzott memóriát kezdett fogyasztani, és nagy terhelés alatt megakadt.
Miután profilozta az alkalmazást, Andrew rájött, hogy a ciklusokon belüli hagyományos string-összefűzés arra kényszerítette a Go-t, hogy folyamatosan újraallokálja a memóriát.
Most a te segítségedet kéri, hogy a Go `strings.Builder` segítségével írd át a segédprogramot úgy, hogy az alkalmazás jól skálázódjon, és nagy mennyiségű szöveget is kezeljen anélkül, hogy összeroppantaná a memóriakupacot.

## 1. SELECT-lekérdezések generálása

Valósítsd meg a `BuildSelectQuery` függvényt.
Paraméterként egy táblanevet (`string`) és az oszlopnevek szeletét (`[]string`) kapja.
Egy teljes, pontosvesszővel végződő SQL `SELECT` utasítást kell visszaadnia.
Ha az oszlopok szelete üres vagy `nil`, a lekérdezés essen vissza a `*` helyettesítő karakterre, és az összes oszlopot válassza ki.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Kötegelt INSERT utasítások generálása

Valósítsd meg a `BuildBatchInserts` függvényt.
Paraméterként egy táblanevet (`string`) és az adatbázissorokat reprezentáló kétdimenziós szeletet (`[][]ColumnValue`) kapja.
Egy sor minden eleme egy adott oszlopnevet kapcsol össze a hozzá tartozó string értékkel.
A függvénynek az egyes `INSERT` SQL utasítások szeletét kell visszaadnia.
A strukturált szeletes formátum kiszámítható és stabil kimeneti sorrendet biztosít a lekérdezéseknél.
Ha a bemeneti sorok szelete üres, adj vissza egy üres string szeletet.
Ha valamelyik sor üres, hagyd ki.
A `VALUES` záradékban a string értékeket aposztráffal (`'`) kell körbevenni.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
