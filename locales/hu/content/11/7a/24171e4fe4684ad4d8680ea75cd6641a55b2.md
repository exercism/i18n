## Utasítások

Egy újrahasznosító központ vett fel téged dolgozni.
A hely szűke miatt minden termék ugyanarra a futószalagra kerül, ez viszont odavezetett, hogy a különböző anyagok összekeveredtek, és használhatatlanná váltak.
Hogy ezt helyrehozd, az a feladatod, hogy függvényeket írj, amelyek megállapítják egy termék típusát.

### 1. Ellenőrizd, hogy egy érték boolean-e

Valósítsd meg az `isBoolean` függvényt, amely ellenőrzi, hogy egy érték boolean-e.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Ellenőrizd, hogy egy érték szám-e

Valósítsd meg az `isNumber` függvényt, amely ellenőrzi, hogy egy érték _véges_ `number` vagy `bigint`, azaz nem `NaN` és nem `Infinity`.

Néha előfordul, hogy az azonosítók beolvasására szolgáló eszköz hibázik, és egy nem numerikus értéket `NaN`-ként (Not a Number) vagy `Infinity`-ként olvas be.
A függvényednek ezt is helyesen kell kezelnie.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Ellenőrizd, hogy egy érték objektum-e

Valósítsd meg az `isObject` függvényt, amelynek ellenőriznie kell, hogy az érték objektum-e.
A futószalagon a `null` a semmit jelenti, és nem számít objektumnak.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Ellenőrizd, hogy egy string numerikus-e

Valósítsd meg az `isNumericString` függvényt, amelynek ellenőriznie kell, hogy az érték olyan string-e, amely csak számjegyekből áll, vagy egy mínuszjelből, amelyet számjegyek követnek, és negatív számot jelöl.
Csak az egész számokat vesszük figyelembe, a tizedes törteket az újrahasznosító robot ez az ellenőrzése nem tekinti numerikusnak.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Ellenőrizd, hogy egy objektum elektronikus-e

Valósítsd meg az `isElectronic` függvényt, amely ellenőrzi, hogy egy objektum a megadott `ElectronicDevice` osztály vagy annak valamelyik gyermekosztálya példánya-e.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Ellenőrizd, hogy egy érték nem üres tömb-e

Valósítsd meg az `isNonEmptyArray` függvényt, amely ellenőrzi, hogy egy érték nem üres tömb-e.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Ellenőrizd, hogy egy érték üres tömb-e

Valósítsd meg az `isEmptyArray` függvényt, amely ellenőrzi, hogy egy érték üres tömb-e.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Ellenőrizd, hogy egy objektumnak van `type` tulajdonsága vagy metódusa

Valósítsd meg a `hasType` függvényt, amely ellenőrzi, hogy egy objektumnak van-e `type` tulajdonsága vagy metódusa.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Dobj hibát, ha egy objektumnak nincs `id` tulajdonsága vagy metódusa

Valósítsd meg az `assertHasId` függvényt, amely `Error`-t dob, ha egy objektumból hiányzik az `id` tulajdonság.

Ha egy objektumnak van `id` tulajdonsága, akkor nem szabad semmit visszaadnia.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Ellenőrizd, hogy egy objektumnak van `id` tulajdonsága

Valósítsd meg a `hasIdProperty` függvényt, amely ellenőrzi, hogy egy objektumnak van-e `id` tulajdonsága.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Ellenőrizd, hogy egy objektumnak van definiált `type` tulajdonsága

Valósítsd meg a `hasDefinedType` függvényt, amely ellenőrzi, hogy egy objektumnak van-e olyan `type` tulajdonsága, amely nem `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
