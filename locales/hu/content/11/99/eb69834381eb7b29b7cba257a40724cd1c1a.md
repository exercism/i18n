# Bevezetés

A C# `enum` típus névvel ellátott konstansok rögzített halmazát jelöli (egy felsorolást). Legfőbb célja, hogy típusbiztos módot nyújtson a numerikus konstansok kezelésére, az elérhető értékeket pedig egy előre meghatározott halmazra korlátozza. Egy egyszerű enum a következőképpen definiálható:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Ha nem adjuk meg kifejezetten, az enum tagjai automatikusan növekvő egész értékeket kapnak, az első érték pedig nulla lesz. Az értékeket kifejezetten is hozzárendelhetjük:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
