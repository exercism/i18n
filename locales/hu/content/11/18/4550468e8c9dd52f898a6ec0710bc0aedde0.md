# Utasítások

A HTTP-végpontok sokkal jobbak, ha típusellenőrzést is használunk. Ha egy Record típust adunk egy POST-kéréshez, az biztosítja, hogy minden alkalommal a megfelelő adatok menjenek át.

## Célok

- Módosítsd a megadott kódot.
- Add hozzá ehhez a recordhoz a szükséges attribútumokat, hogy két operandust és egy operátort fogadjon el.
- Adj hozzá egy HTTP-erőforrás-függvényt, amely a '/calc' útvonalon fogadja a POST-kéréseket.
- A függvény payloadként a Calculation record típust fogadja el, és egy általános JSON-objektumot adjon vissza.

### Bemenet

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Kimenet

```json
{ "expression": "4+10.2", "result": 14.2 }
```
