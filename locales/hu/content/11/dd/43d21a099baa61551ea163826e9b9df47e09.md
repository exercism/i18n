# Utasítások

Egy kis időjárási állomást vezetsz a Moldva partján, Prágában, és minden műszakban feljegyzed a hőmérséklet-méréseket egy egyszerű szöveges naplóba, soronként egyet. Egy műszaknyi nyilvántartást öt apró szó intéz el.

Mindegyik szó megkapja a naplófájl elérési útját.

## 1. Olvasd be az összes mérést

Definiáld a `read-readings` szót úgy, hogy a napló összes mérését stringek tömbjeként adja vissza, soronként egyet.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. Keresd meg a legutóbbi mérést

Definiáld a `latest-reading` szót úgy, hogy a legutóbbi mérést adja vissza, azaz a napló utolsó sorát.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. Olvasd be a nyers naplót

Definiáld a `log-text` szót úgy, hogy a teljes naplófájlt egyetlen stringként adja vissza, pontosan úgy, ahogyan tárolva van.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. Jegyezz fel egy mérést

Definiáld a `record-reading` szót úgy, hogy egy új mérést fűzzön a napló végére külön sorban, a korábbi méréseket érintetlenül hagyva. Nem ad vissza semmit.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. Írd újra a naplót

Definiáld a `rewrite-log` szót úgy, hogy a teljes naplót lecserélje egy friss, mérésekből álló tömbre, soronként egyet.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
