# Egymásba ágyazott függvények

A függvényeket [más függvényeken belül][nested-functions] is definiálhatjuk.
Ezt gyakran segédfüggvények létrehozására használjuk, amelyek csak a befoglaló függvényüknek hasznosak, így nem szennyezik a külső névteret.

Ezeket a függvényeket ugyanúgy definiáljuk és hívjuk, mint a normál függvényeket, de a befoglaló függvényen kívül nem láthatók.

```swift
func makeNumber(_ number: Int) -> Int {
  func double(_ x: Int) -> Int { 2 * x }
  func add(_ x: Int) -> Int { x + 1 }

  return number.isMultiple(of: 2) ? add(double(number)) : double(number)
}

makeNumber(3)
// Returns 6
makeNumber(4)
// Returns 9
```

[nested-functions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Nested-Functions
