# Tesztek

Ha a teszteket a parancssorból szeretnéd futtatni, a feladat könyvtárából futtasd a következő parancsot:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## GUI

Ha a teszteket a MARS szimulátor GUI-n keresztül szeretnéd futtatni, az utolsó sor kikommentelésével `include`-old a megvalósításodat a `runner.mips` alján.
