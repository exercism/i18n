# Utasítások

Egy őrhajó fedélzetén vagy őrtiszt, amely épp a Bering-szoroson halad át. Három forrás kiáltja be minden látható jégtábla és partfok helyzetét:

- A **térképasztal** iránytű szerinti égtájakban beszél: `north`, `east`, `south`, `west`. Csak irány, távolság nélkül.
- A **navigátor** *poláris* koordinátákban beszél, az őrhajó utolsó helymeghatározásához képest: egy nagyság tengeri mérföldben, és egy irányszög fokban, északtól az óramutató járásával megegyező irányban (tehát a `0` az észak, a `90` a kelet, a `180` a dél, a `270` a nyugat).
- Az **árbóctetői őrszem** *relatív* koordinátákban beszél: egy előre mért távolság, és a `ahead`, `starboard`, `behind`, `port` egyike. A relatív irányszögeket *a hajó pillanatnyi irányához* mérjük. Ezt az irányt a kapitány minden őrség előtt bemondja a hídon.

A feladatod, hogy mindhármat egy közös derékszögű `(x, y)` koordinátarendszerbe alakítsd, hogy a térkép megrajzolható legyen. Az irányszögek fokban értendők; a `(0, 1)` egy tengeri mérföld északra, az `(1, 0)` egy tengeri mérföld keletre.

## 1. Az adatmodell, és a kardinális irány derékszögű koordinátái

Először fektesd le azokat az elemeket, amelyeket az egész feladat használ:

- Definiálj három tuple-t: `cardinal` (egy mező: `direction`), `polar` (mezők: `magnitude` és `bearing`), valamint `relative` (mezők: `distance` és `bearing`).
- Deklaráld az irányszimbólumokat a `SYMBOLS:` szóval: `north`, `east`, `south`, `west`, `ahead`, `starboard`, `behind`, `port`.
- Deklaráld a `heading` dinamikus változót a `SYMBOL:` szóval (a 3. részfeladat használja).
- Deklarálj két generikus szót: `GENERIC: >cartesian ( direction -- x y )` és `GENERIC: flip ( direction -- direction' )`. A metódusaikat a következő részfeladatokban adod hozzá.

Ezután add hozzá a `>cartesian` `M: cardinal` metódusát, amely az adott irány egységvektorát adja vissza.

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. Derékszögű koordináták poláris irányhoz

Adj hozzá egy `M: polar` metódust a `>cartesian` szóhoz, amely a poláris alakot `(x, y)` koordinátákká alakítja:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. Derékszögű koordináták relatív irányhoz

Adj hozzá egy `M: relative` metódust a `>cartesian` szóhoz. A csavar: a relatív irányszöget a hajó *pillanatnyi irányához* mérjük, ami nem része a tuple-nek. Olvasd ki a `heading` változót (amit az 1. részfeladatban deklaráltál) a `heading get` szóval, add hozzá az irányeltolást (`ahead = 0`, `starboard = 90`, `behind = 180`, `port = 270`), és állítsd elő a derékszögű pontot. A hívó a `with-variable` blokkban állítja be a `heading` értékét.

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. Flip

Add hozzá a `flip` generikus (amit az 1. részfeladatban deklaráltál) metódusait, hogy az ellentétes irányt adja vissza.

- `cardinal` esetén: north ↔ south, east ↔ west.
- `polar` esetén: adj hozzá 180°-ot az irányszöghez (modulo 360).
- `relative` esetén: ahead ↔ behind, starboard ↔ port.

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. Irányszögek összeadása

Definiáld az `add-bearings ( a b -- x y )` szót, amely mindkét irányt derékszögű koordinátákká alakítja, és visszaadja az összegüket. Bármilyen kombinációban működik `cardinal`, `polar` és `relative` irányokkal, ez a jutalma annak, hogy a `>cartesian` szóhoz generikust használsz.

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
