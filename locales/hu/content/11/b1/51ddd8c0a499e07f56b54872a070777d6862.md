# Kiegészítés az utasításokhoz

A komplex számok hatványozásához exponenciális függvényre, valamint szinusz- és koszinuszfüggvényre van szükség, amelyek egyike sem érhető el WebAssemblyben. Szerencsére ezek kiszámításához használhatsz egy [Taylor-sort](https://en.wikipedia.org/wiki/Taylor_series). A várt értékekkel való egyezéshez legalább `1/26!` pontosságra van szükséged.

## Exponenciális függvény

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Szinuszfüggvény

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## Koszinuszfüggvény

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
