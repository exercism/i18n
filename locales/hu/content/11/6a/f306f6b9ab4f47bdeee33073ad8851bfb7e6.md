# Részletesen

A `TUPLE:` olyan osztályt hoz létre, amelynek nevesített mezői vannak. A Factor
automatikusan generál egy konstruktor szót (az osztálynévhez fűzött `new`
utótaggal), egy `boa` („az argumentumok sorrendje szerinti”) konstruktort, egy
`T{ class … }` literál szintaxist, valamint mezőnkénti elérő szavakat.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

Az [`accessors`][accessors] elérőrendszere mezőnként négy változatot kínál:
`name>>`, `>>name`, `change-name`, valamint a mutáló párt, a
`[ … ] change-name` szót. A `>>name` és a `change-name` magát a tuple-t
módosítja; ha az eredeti példányt érintetlenül szeretnéd hagyni, előbb klónozd
le a `clone` szóval.

A tuple típusnál a `=` szerkezeti egyenlőséget jelent, és kiíráskor a nem
alapértelmezett mezőértékek is megjelennek.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
