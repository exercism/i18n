# Kiegészítés az utasításokhoz

## A `from_quote` előnyei és hátrányai

Ez a feladat egy `from_quote` függvényt definiál a `Time` típusban. Ez lehetővé teszi, hogy ilyen kódot írj:

```roc
time : Time
time = "00:01:23"
```

Ez a kód implicit módon meghívja a `Time.from_quote("00:01:23")`-t fordítási időben. Ez felgyorsíthatja a programot, mert futásidőben nem kell az elemzéssel foglalkozni, ráadásul a `from_quote` által elutasított időpontokat már fordítási időben elkapja, nem futásidőben. Ráadásul a kód szép és olvasható lesz tőle. Például íme a feladat egyik tesztje:

```roc
## start initiates time tracking for current lap
expect {
	result = Stopwatch.create()
		.start()?
		.advance_time("00:00:05")
		|> expect_current_lap("00:00:05")

	result.is_ok()
}
```

Aki viszont ezt a kódot olvassa, könnyen azt hiheti, hogy az `advance_time` függvény `Str`-t vár, pedig valójában `Time`-t. Ez zavart és hibákat okozhat. Ezért lehet, hogy a kicsit hosszabb, de egyértelműbb formát választod: `"00:00:05".Time`, amely szintén meghívja a `from_quote`-ot fordítási időben.

A saját programjaidban viszont inkább a `from_str`-t érdemes használnod:

```roc
Time := { ... }.{
    from_str : time_str -> Try(Time, [InvalidTime])
    from_str = |time_str| ...
}
```

A `from_str`-t (vagy bármely más tiszta függvényt) fordítási időben is meghívhatod, így:

```roc
Ok(time) = Time.from_str("00:01:23")
```

Megjegyzés: ha ezt a definíciót a legfelső szintre teszed, akkor az fordítási időben fut le (mivel a függvény tiszta, és a bemenete fordítási időben ismert). Egy függvényen belül viszont futásidőben használhatod a `from_str`-t.
