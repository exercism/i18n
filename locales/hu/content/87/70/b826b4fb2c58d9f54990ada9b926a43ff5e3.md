# Utasítások

Megint mozgalmas éjszaka az antwerpeni rendező pályaudvaron. Te vagy
a szolgálatban lévő forgalmista: a beérkező teherkocsikat kimenő
vonatokba kell újracsoportosítani, a kapcsolókat átvizsgálni, az
útvonalakat az elágazásoknál szétválasztani, az azonos rakományokat
pedig a számlázáshoz összevonni.

Minden *kocsi* egy string, amely megmondja, mit szállít:
`"coal"`, `"timber"`, `"crates"` stb.

## 1. Kapcsolj kocsikat vonatokba

Definiáld a `couple` szót úgy, hogy egy kocsikból álló tömböt és egy
`n` hosszúságot vegyen át, és `n` kocsiból álló, nem átfedő vonatokat
adjon vissza. Az utolsó vonat rövidebb is lehet, ha a darabszám nem
osztható egyenlően.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Vess egy pillantást a kapcsolókra

Definiáld a `peek-couplings` szót úgy, hogy egy kocsikból álló tömböt
vegyen át, és minden szomszédos párt adjon vissza, hogy az ellenőr
meg tudja vizsgálni az egyes kapcsolókat.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Bontsd szét a láncot az elágazásoknál

Definiáld a `split-at-junctions` szót úgy, hogy egy kocsikból álló
tömböt és egy `junctions` tömböt vegyen át (ezek azok a kocsik,
amelyek töréspontot jelölnek), és adja vissza az elágazást jelölő
kocsik közötti szakaszokat. Magukat az elágazást jelölő kocsikat nem
tartja meg.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Vond össze az azonos rakományokat

Definiáld a `coalesce-cargo` szót úgy, hogy egy kocsikból álló tömböt
vegyen át, és az ugyanazt a rakományt szállító *egymást követő*
kocsikat sorozatokba csoportosítsa.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
