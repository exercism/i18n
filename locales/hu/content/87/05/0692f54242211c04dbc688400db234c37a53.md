# Bevezetés

A Gleamben gyakori, hogy magasabb rendű függvényeket írunk és használunk, vagyis olyan függvényeket, amelyek más függvényeket vesznek át argumentumként. Néha, amikor egyszerre több magasabb rendű függvényt használunk, a kód nehezen olvashatóvá válhat a sok behúzási szint miatt.

Például itt van egy függvény, amely több olyan függvényt hív meg, amelyek `Result(Int, Nil)` értéket adnak vissza, és összegzi az értékeket, ha mind a négy sikeres.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

A Gleam `use` kifejezései lehetővé teszik, hogy ezt a kódot behúzás nélkül írjuk meg, ami gyakran könnyebbé teszi az olvasást.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

A `use` kifejezés összegyűjti a blokkban következő összes utasítást, és visszahívó függvényként átadja azt a függvényhívás utolsó argumentumaként. A `use` kulcsszó és a `<-` szimbólum közötti változók azoknak az argumentumoknak a nevei, amelyeket a visszahívó függvénynek átadunk.

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

A visszahívó függvény tetszőleges számú argumentumot fogadhat, vagy akár egyet sem.

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

Nincsenek különleges követelmények ahhoz, hogy olyan függvényt hozzunk létre, amely `use` kifejezéssel hívható, azon kívül, hogy az utolsó argumentumként visszahívó függvényt vár.

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

A Gleam `use` kifejezései nagyon erős funkció, amely sok problémára alkalmazható, de túlzott használatuk esetén nehezen olvashatóvá tehetik a kódot. Általában érdemes a normál függvényhívási szintaxist használni, és csak akkor nyúlni a `use` kifejezésekhez, amikor azok könnyebbé teszik a kód olvasását.
