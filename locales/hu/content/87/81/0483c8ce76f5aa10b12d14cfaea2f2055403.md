# Kiegészítés az utasításokhoz

## Szavak

A `find-fewest-coins ( coins target -- result )` egy érmecímletekből álló tömböt ad vissza, amelynek összege `target`. A `coins` egy hash set (például `HS{ 1 5 10 25 }`); a `sets` szókészlet szavaival (`members`, `in?`, …) dolgozhatsz vele.

Ha a `coins` egyetlen kombinációjából sem jön ki a `target`, dobj egy `cannot-make-change` hibát.
