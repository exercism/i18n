# A stringekről

A Kotlinban a [`string`][ref-string] egy megváltoztathatatlan, Unicode-karakterekből álló sorozat.

A [`Immutable`][wiki-immutable] azt jelenti, hogy egy stringen végzett bármely műveletnek új stringet kell visszaadnia: az eredeti string soha nem változhat meg.

A [`Unicode`][wiki-unicode] azt jelenti, hogy a világ írásrendszereinek többsége ábrázolható, de (ellentétben a régebbi nyelvekkel, például a C-vel) nincs 1:1 megfeleltetés a karakterek és a bájtok között.
Ez a [`Chars`][concept-chars] fogalomban részletesebben is szóba kerül.

A stringet kettős idézőjelek (`" "`) veszik körül.

Néhány karaktert escape-elni kell: a `\\`-t, valamint a szokásos nem nyomtatható karaktereket, például a `\t` (tabulátor) és a `\n` (új sor) karaktert.

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

A többsoros stringeket 3 kettős idézőjel veszi körül, és tetszőleges szöveget tartalmazhatnak (nem kell escape-elni).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

A [trimIndent][trimIndent-doc] használatával eltávolíthatod a sorok közös behúzását.
Ez hasznos a string formázásához:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Másik lehetőség, hogy a [trimMargin][trimMargin-doc] segítségével megadhatsz egy határolójelet.
A `String` minden sora ezután a határolójel után kezdődik.
A határolójel alapértelmezésben `|`, de paraméterként más határolójelet is megadhatsz.
Például:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

A stringek összefűzhetők `+` jellel, de ezt érdemes a rövid és egyszerű esetekre korlátozni.
Vannak más, gyakran jobb lehetőségek is.

## String-sablonok

[`Templates`][ref-templates] arra utal, amit más nyelvek „interpolációnak” neveznek.

Ha egy string dollárjelet `$` tartalmaz, amelyet egy azonosító követ, vagy kapcsos zárójeleket (`{expression}`), amelyek egy kifejezést vesznek körül, akkor azok helyére rendre az érték vagy a kifejezés eredménye kerül.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## String formázása

A JVM platformon (csak ott) a `String.format()` pontosabb formázást tesz lehetővé, mint a string-sablonok, a (_nagyon régi!_) [`printf`][wiki-printf] függvényekhez hasonló [szintaxissal][web-formats].

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

~~~~exercism/advanced
A Kotlin több különböző célplatformra fordítható: a Java virtuális gépre, JavaScriptre, natív binárisokra Linuxra, Windowsra, Androidra és Apple-re, valamint a WebAssembly két változatára.

Lényegében ugyanaz a kód használható mindegyikhez, de a célplatformok eltérő képességei miatt különbségek lehetnek abban, hogy mely szabványos könyvtári függvények támogatottak.

Az Exercism jelenleg a JVM-et használja teszteléshez.
~~~~

## Stringfüggvények

A Kotlin _sok_ [`functions`][ref-string-functions] függvényt biztosít a stringek kezelésére.

Többségük [`extensions functions`][ref-extensions], nem pedig a `String` osztály tagja, bár ennek kevés hatása van arra, hogyan használjuk őket.

~~~~exercism/note
A Kotlin meglehetősen összetett [dokumentációs][ref-string-functions] oldalai alapértelmezett nézetben elrejtik a kiterjesztő függvényeket.
Ennek írásakor a legértékesebb tartalom egy `Members & Extensions` nevű lapon rejtőzik.
Kattints rá, hogy kibontsd ezt a részt, és lásd a `String` osztály összes elérhető tagját és kiterjesztését.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Az alábbi példa csak egy kis válogatást mutat abból, ami elérhető:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## String építése

Néha egy hosszú stringet szakaszosan kell felépíteni, például egy cikluson belül.

A stringek `+` jellel történő összefűzése hamar sem elegánssá, sem hatékonnyá nem válik: a megváltoztathatatlanság miatt _rengeteg_ másolásra van szükség.

A Kotlinnak több hatékonyabb módja is van több string összekapcsolására:

- String-sablonok, a fentiekben leírt módon.
- [`joinToString()`][ref-jointostring], amelyet a [Listák][concept-lists] fogalomban fogunk tárgyalni.
- Java [`StringBuilder`][ref-stringbuilder], amelyet nem tekintenek különösebben idiomatikus Kotlinnak.
- Kotlin [`buildString()`][ref-buildstring], amely a `StringBuilder`-t egy tömörebb és idiomatikusabb szintaxisba csomagolja.
Ez a stringépítési logikát lambda argumentumként veszi át, amelyet egy későbbi fogalomban tárgyalunk.

Lényegében a `StringBuilder` egy listaszerű struktúra, számos kényelmes metódussal.
Íme egy kis válogatás:

- [`append()`][ref-sb-append] a végére fűzéshez.
- [`insert()`][ref-sb-insert] egy megadott pozícióra való beszúráshoz.
- [`deleteAt()`][ref-sb-deleteat] és [`deleteRange()`][ref-sb-deleterange] a megadott pozíció(k)ról való törléshez.
- `toString()` a végén egy normál stringgé alakításhoz: mindent egyetlen, hatékony műveletben fűz össze.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Egy `buildString()` példa, későbbi fogalmakból származó szintaxissal:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
