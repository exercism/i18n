# Bevezetés

## Öröklődés

C#-ban az _osztályok_ hierarchiája _öröklődéssel_ definiálható, amellyel egy származtatott osztály (`Car`) örökölheti a szülőosztálya (`Vehicle`) viselkedését és adatait. Ha nincs megadva szülőosztály, az osztály az `object` osztályból örököl.

A szülőosztályok háromféleképpen biztosíthatnak funkcionalitást a származtatott osztályoknak:

- Definiálnak egy hagyományos metódust.
- Definiálnak egy `virtual` metódust, amely olyan, mint egy hagyományos metódus, de a származtatott osztályok _megváltoztathatják_.
- Definiálnak egy `abstract` metódust, amely implementáció nélküli metódus, és amelyet a származtatott osztályoknak _implementálniuk kell_. Az `abstract` metódusokat tartalmazó osztályt magát is `abstract`-ként kell megjelölni. Az absztrakt osztályokból nem lehet példányt létrehozni.

A `protected` hozzáférés-módosító lehetővé teszi, hogy egy szülőosztály tagját egy származtatott osztályban el lehessen érni, más osztályok elől viszont elzárja a hozzáférést.

A származtatott osztályok a `base` kulcsszón keresztül érik el a szülőosztály tagjait.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

A származtatott osztály konstruktora automatikusan meghívja a szülő konstruktorát, _mielőtt_ lefuttatná a saját konstruktor logikáját. A szülőosztály konstruktorának a `base` kulcsszóval adhatók át argumentumok:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

Amikor egynél több osztály származik egy bázisosztályból, a két (vagy több) osztály gyakran a bázisosztály egy metódusának különböző változatait valósítja meg. Ez egy nagyon fontos elv, az úgynevezett polimorfizmus. A fenti példa egy változatában például azt mutatjuk meg, hogy a `Vehicle`-et használó kód hogyan változtathatja meg a viselkedését attól függően, hogy milyen típusú járműből hoztunk létre példányt.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
