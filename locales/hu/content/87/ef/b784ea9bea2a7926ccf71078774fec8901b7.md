# Utasítások

Ebben a feladatban naplósorok feldolgozásával foglalkozol.

Minden naplósor egy string, amelynek formátuma a következő: `"[<LEVEL>]: <MESSAGE>"`.

Három különböző naplószint létezik:

- `INFO`
- `WARNING`
- `ERROR`

Három részfeladatod van, és mindegyik kap egy naplósort, amivel valamit csinálnod kell.

## 1. Üzenet kinyerése egy naplósorból

Valósítsd meg a (_statikus_) `LogLine.Message()` metódust, amely visszaadja egy naplósor üzenetét:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

A vezető és záró whitespace-karaktereket el kell távolítani:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. A naplószint kinyerése egy naplósorból

Valósítsd meg a (_statikus_) `LogLine.LogLevel()` metódust, amely visszaadja egy naplósor naplószintjét, mégpedig kisbetűvel:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Egy naplósor újraformázása

Valósítsd meg a (_statikus_) `LogLine.Reformat()` metódust, amely újraformázza a naplósort: az üzenet kerül előre, utána pedig zárójelben a naplószint:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
