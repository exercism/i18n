# Kiegészítés az utasításokhoz

## Szavak

Definiálj egy `rat` tuple-t `numerator` és `denominator` mezővel.
A `<rat>` az argumentumait a legegyszerűbb alakra hozza, az előjelet
a számlálón tartva (így a nevező mindig pozitív).

- `<rat> ( numerator denominator -- rat )`: egyszerűsített racionális
  számot hoz létre.
- `>rat ( pair -- rat )`: `{ numerator denominator }`-ból épít egy `rat`-et.
- `rat>pair ( rat -- pair )`: visszaadja a `{ numerator denominator }`-t.
- `r+ ( a b -- c )`, `r- ( a b -- c )`, `r* ( a b -- c )`,
  `r/ ( a b -- c )`: aritmetika két racionális számon.
- `r-abs ( a -- |a| )`: abszolútérték.
- `r^ ( a n -- a^n )`: racionális számot emel egész kitevőre
  (negatív kitevő is megengedett).
- `real^r ( x a -- y )`: valós számot emel racionális kitevőre,
  és lebegőpontos számot ad vissza.

A Factor `MATH:` generikusai (`+`, `-`, `*`, `/`) csak a beépített
matematikai hierarchiára vannak definiálva, ezért ez a feladat külön
szóneveket használ e generikusok metódusai helyett.
