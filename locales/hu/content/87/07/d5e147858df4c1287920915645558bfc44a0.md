# Bevezetés

Ez akár egy _nagy_ témakör is lehet!
Akár egy hosszú könyvet is lehetne írni róla, és többen meg is tették (keress rá az Amazonon az „unicode book” kifejezésre, ha néhány példát szeretnél látni).

## Egy nagyon rövid történelmi áttekintés

A karakterek kezelése a számítógépeken sokkal egyszerűbb volt a korábbi évtizedekben, amikor a programozók azt feltételezték, hogy az angol az egyetlen fontos nyelv.
Szóval: 26 betű kis- és nagybetűs formában, 10 számjegy, néhány írásjel, plusz egy kód (0x07) egy csengő megkondításához, és mindez belefért 7 bitbe: ez az [ASCII][wiki-ascii] karakterkészlet.

Természetesen az emberek elkezdték kérdezni, mi lesz az à, ä és Ł betűkkel, aztán mások azt firtatták, mi lesz az ऄ, ஹ és ญ jelekkel, a fiatalok pedig emojikat akartak 😱.
Mit lehet ilyenkor tenni?

Hogy rövidre fogjam: sok okos és türelmes embernek évekig bizottságokban kellett dolgoznia, hogy kidolgozza a [Unicode][web-unicode] karakterkészlet és az olyan kódolások részleteit, mint a [UTF-8][wiki-utf-8], ráadásul rengeteg szoftvert kellett _nagyon_ bonyolult módon újraírni.
Ráadásul rengeteg új bug is keletkezett.

Hogy _semmi_ ne törjön el, a Unicode/UTF-8 kialakítása gondoskodik róla, hogy az első 127 kód azonos legyen az ASCII-vel _(még a csengő is)_.

## Karakterek Kotlinban

A 2005 körül vagy után tervezett nyelveknek óriási előnyük, hogy már létezett egy viszonylag stabil Unicode-szabvány.

A Kotlin (amelyet először 2011-ben adtak ki) abból indulhatott ki, hogy a felhasználók sokféle (emberi) nyelvet fognak használni, és szükségük lesz a Unicode-ra ezek kifejezéséhez.

A karakterliterálokat aposztrófok közé írjuk, és különböznek a kettős idézőjelek közé írt stringektől.
Ez valószínűleg magától értetődő a C/C++ világából érkezőknek, a Python- és JavaScript-programozóknak viszont zavaró lehet.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

A `Char` és az `Int` közötti átalakítás egyszerű:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

A fordító _némely_ egész aritmetikai műveletet engedélyez `Char` értékeken:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Néhány függvény a `Char` típushoz

Ahogy mindig, most is jóval [több függvény][ref-char-lib] létezik, mint amennyit itt tárgyalhatnánk, úgyhogy ez csak egy válogatás belőlük.

- A megfelelő ábécék esetében válthatsz kis- és nagybetűt a [`uppercase()`][ref-uppercase] és a [`lowercase()`][ref-lowercase] függvénnyel.
- A kis- és nagybetűs írásmódot az [`isUpperCase()`][ref-isuppercase] és az [`isLowerCase()`][ref-islowercase] függvénnyel ellenőrizheted.
- A karakter típusát ezekkel ellenőrizheted:
    - [`isLetter()`][ref-isletter], sok ábécét lefed
    - [`isDigit()`][ref-isdigit], a 0..9 tartományban
    - `isLetterOrDigit()`, az előző kettőt egyesíti
    - [`isWhitespace()`][ref-iswhitespace], bármilyen whitespace-karakter

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Char-lista és string közötti átalakítások

Stringből Char-listába a `toList()` függvénnyel válthatunk.

Char-listából stringbe a [`joinToString()`][ref-jointostring] függvény szolgál, amely egy elválasztót (gyakran az üres stringet) vesz argumentumként.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Ne feledd, hogy a `joinToString()` egy Listán vagy Arrayen működik.
Ha egyetlen `Char`-t szeretnél _átalakítani_ egyetlen karakterből álló stringgé, használd a `toString()` függvényt.

```kotlin
'a'.toString() // => "a"
```

Annak ellenőrzésére, hogy egy karakter szerepel-e egy `String`ben, illetve `Char`-ek listájában vagy tömbjében, az `in` operátor szolgál, amely a [`contains()`][ref-contains] függvényre képeződik le.

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
