# Bevezetés

Az `Integer` bármekkora számot tárolhat, egészen a géped memóriájának határáig, az `Int` pedig a 32 vagy 64 biten ábrázolható pozitív és negatív egészek halmazának felel meg (garantáltan legalább a -2^29 és 2^29 közötti tartomány).

A `Float` a valós számok halmazának felel meg, amelyet a számítógép pontossága korlátoz.
A számokon értelmezett műveletek általában az egyik vagy a másik típuson működnek, de nem mindkettőn.

A `Float` és az `Integer` közötti átalakítást végző függvények közé tartozik többek között a `toFloat`, amely `Int`/`Integer` értéket alakít `Float`-tá, és a `ceiling`, amely egy `Float`-ot alakít `Int`-té.

Az egész típusról (`Int` vagy `Integer`) bármely más numerikus típusra való átalakítás a `fromIntegral` függvénnyel történik.
A cél típusát automatikusan kikövetkezteti.
Például:

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
