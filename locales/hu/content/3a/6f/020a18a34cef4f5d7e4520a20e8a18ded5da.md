# Bevezetés

A C++-ban a logikai értékeket a `bool` típus képviseli.
Egy `bool` értéke vagy `true`, vagy `false`.

## Logikai operátorok

A C++ három logikai operátort támogat: `!` (NEM), `&&` (ÉS) és `||` (VAGY).
Használhatod a `not`, `and` és `or` alternatív változataikat is.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Operátorok elsőbbsége

A három logikai operátor _elsőbbsége_ eltér.
Ezért ebben a sorrendben értékelődnek ki: először a `!`, aztán a `&&`, végül a `||`.
Ha más sorrendet szeretnél kikényszeríteni, zárójelbe tehetsz egy logikai kifejezést (vagyis `()`), mert a zárójelek elsőbbsége még ennél is nagyobb.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Konverzió

Ha `true` vagy `false` értéket használsz ott, ahol számot várunk, akkor azok `1`-re, illetve `0`-ra alakulnak.
Ha számot használsz egy logikai műveletben, akkor a `0` kivételével mindent `true`-ként kezelünk, még a negatív értékeket is.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
