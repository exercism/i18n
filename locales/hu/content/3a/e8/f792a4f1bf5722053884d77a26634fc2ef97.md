# Bemutatás

[A structok][getting-started] olyan speciális [map-ek][maps], amelyeknek meghatározott kulcskészletük van.

- A structok fordítási idejű ellenőrzéseket és alapértelmezett értékeket biztosítanak.
- A struct arról a modulról kapja a nevét, amelyben definiálják.
- Struct definiálásához használd a [`defstruct`][docs-defstruct] szerkezetet.
  - Ez a szerkezet általában közvetlenül a moduldefiníció után következik.
- A `defstruct` elfogad vagy [atomok][atom] listáját (ilyenkor az alapérték `nil`), vagy kulcsszólistákat (megadott alapértékekhez).
  - Az alapérték nélküli mezőknek meg kell előzniük az alapértékkel rendelkező mezőket.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Mezők elérése és frissítése

- A [map-ekkel][maps] dolgozó függvények többsége a structokkal is működik.
  - Az [_Access Behaviour_][access-behaviour] kivétel, és a structokhoz **nincs** implementálva.
- A structok mezőinek eléréséhez ajánlott a _statikus elérési operátort_, a `.` jelet használni.

- Mezőértékek lekérése:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- Mezőértékek frissítése

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## A mezőértékek inicializálásának kikényszerítése

- Az [`@enforce_keys` modulattribútum][enforcing-keys] egy futásidejű ellenőrzést hoz létre, amely szerint a megadott mezőknek a struct létrehozásakor **nem** `nil` értéket kell kapniuk.
- Az `@enforce_keys` után a mezőkulcsok listája áll (ezek [atomok][atom]).
- Ha egy kikényszerített kulcsot nem inicializálnak, hiba keletkezik.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
