# Bevezetés

## Számok összehasonlítása

A `jq`-ban a számokat a következő relációs és egyenlőségoperátorokkal lehet összehasonlítani.

| Összehasonlítás     | Operátor |
| ------------------- | -------- |
| Nagyobb mint        | `a > b`  |
| Nagyobb vagy egyenlő | `a >= b` |
| Kisebb mint         | `a < b`  |
| Kisebb vagy egyenlő | `a <= b` |
| Egyenlő             | `a == b` |
| Nem egyenlő         | `a != b` |

Az összehasonlítás eredménye mindig Boolean érték, tehát vagy `true`, vagy `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## Stringek összehasonlítása

A fenti összehasonlító operátorok stringek összehasonlítására is használhatók.
Ilyenkor szótári (lexikográfiai) sorrend érvényesül.
A sorrendet _a Unicode-kódpont értéke_ határozza meg.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Légy óvatos, amikor két olyan változót hasonlítasz össze, amelyek számértéket látszanak tartalmazni, de string típusúak.
A szótári sorrend miatt az eredmény nem ugyanaz lesz, mint a szám típusú értékek összehasonlításakor.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## „Szigorú” egyenlőség

A `jq` `==` operátora olyan, mint a JavaScript `===`: azok a dolgok, amelyek ugyanúgy „néznek ki”, de különböző típusúak, nem egyenlők.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## Tömbök összehasonlítása

Két tömb akkor egyenlő, ha az összes megfelelő elemük egyenlő.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## Objektumok összehasonlítása

Két objektum akkor egyenlő, ha ugyanazok a kulcs-érték párok alkotják.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
