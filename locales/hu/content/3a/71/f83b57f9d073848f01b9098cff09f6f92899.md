# Bevezetés

Pumpák, szelepek, tömlők: mindent, ami operációs rendszer erőforrását tartja (egy nyitott fájlt, egy hálózati kapcsolatot), *fel kell szabadítani*, amikor végeztél vele. A Factor [`destructors`][destructors] szókincse olyan keretrendszerbe csomagolja ezeket, amely garantálja a takarítást, még akkor is, ha egy hiba félúton megszakítja a kódodat.

## Az osztály és a generikus

Egy osztály úgy csatlakozik a keretrendszerhez, hogy kiterjeszti a `disposable` osztályt, és megvalósítja a `dispose*` generikust:

```factor
USING: accessors destructors kernel ;

TUPLE: pump < disposable opened ;

: <pump> ( -- pump )
    pump new-disposable t >>opened ;

M: pump dispose* f >>opened drop ;
```

A `new-disposable ( class -- obj )` lefoglalja a tuple-t, *és* regisztrálja is a keretrendszerben. Egy kivétel a lefoglalás és a következő biztonságos pont között így nem szivárogtathatja el az erőforrást. A keretrendszer garantálja, hogy a `dispose*` objektumonként **legfeljebb egyszer** fut le. Az ismételt `dispose` hívások nem csinálnak semmit.

## A külső hívók a `dispose`-t használják

```
dispose          ( obj -- )                ! release; safe to call twice
with-disposal    ( disposable quot -- )    ! scope one resource
with-destructors ( quot -- )               ! open a registry scope
&dispose         ( obj -- obj )            ! dispose on normal *or* failure exit
|dispose         ( obj -- obj )            ! dispose only if the scope unwinds
```

A `with-disposal` az egyetlen erőforrásra vonatkozó forma: a belső idézet számára a veremre teszi a disposable-t, és kilépéskor felszabadítja.

```factor
USING: destructors io ;

<pump> [
    "pumping" print
] with-disposal
! pump released on the way out — even if `print` had thrown
```

Ha egynél több erőforrással dolgozol, nyiss egy `with-destructors` scope-ot, és regisztráld az összes megszerzett erőforrást. A `&dispose` (és-jel) azt jelenti: „mindig szabadítsd fel kifelé menet, siker vagy hiba esetén is.” A `|dispose` (függőleges vonal) azt jelenti: „**csak** hiba esetén szabadítsd fel”. Ez akkor hasznos, ha a sikeres ág átadja az erőforrást egy hívónak, aki átveszi a tulajdonjogot.

```factor
[
    <pump> &dispose
    <pump> &dispose
    ! ... use the pumps ...
] with-destructors
! both pumps released
```

Ha egy puszta try/finally kell, nyilvántartás nélkül, akkor a [`cleanup`][cleanup] (a `continuations` szókincsben) az alacsonyabb szintű primitív. A `with-destructors` viszont a modern, idiomatikus Factor.
