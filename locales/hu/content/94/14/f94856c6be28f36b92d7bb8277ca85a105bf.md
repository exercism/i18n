# Bevezetés

## For ciklusok

A `for` utasítás egy kódblokkot ismétel.
Az első sora szabályozza, hogy milyen gyakran ismétlődjön a blokk:

```go
for init; condition; post {
    // loop body
}
```

- Az **init** utasítás egyszer fut le, az első iteráció előtt. Gyakori, hogy itt deklarálod a ciklus által használt számlálóváltozót, és kezdőértéket adsz neki.
- A **feltétel** egy Boolean-kifejezés, amelyet minden iteráció előtt kiértékelünk. A ciklus akkor áll le, amikor az értéke `false` lesz.
- A **post** utasítás minden befejezett iteráció után fut le. Arra használhatod, hogy frissítsd a számlálót.

Az `init; condition; post` részt ne tedd zárójelbe.
A ciklus törzsét körülvevő kapcsos zárójelek viszont mindig kötelezőek.

Ez a ciklus az `i`-t `1`-re állítja, kiírja az `i` aktuális értékét, a következő iterációra megnöveli, és leáll, amikor az `i` eléri a `10`-et:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
