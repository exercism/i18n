# Bevezetés

A Cairo-ban a Boolean értékeket az előre deklarált `bool` Boolean-típus képviseli, amelynek értéke `true` vagy `false` lehet.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

A Cairo három logikai operátort támogat, amelyek a kifejezéseket Boolean értékké értékelhetik ki, és `true` vagy `false` értéket adnak vissza.

| Operátor    | Mit jelent                                    |
| ----------- | --------------------------------------------- |
| `&&` (és)  | Akkor igaz, ha mindkét állítás igaz.       |
| `\|\|` (vagy) | Akkor igaz, ha legalább az egyik állítás igaz. |
| `!` (nem)   | Csak akkor igaz, ha az állítás hamis.    |
