# Adatbázis: nagy összegű kiadások

## A feladat

Az ABC Corp arra kér, hogy keresd meg azoknak az alkalmazottaknak a nevét és részlegét, akiknek van a megadott összegnél (pl. `3000.00`) nagyobb kifizetési bejegyzésük.

A szükséges adatok visszaadásához készíts egy `HighPayment` nevű recordot. A record definíciója a következő.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

A szükséges adatokat a JDBC-kliens `query` műveletével kérdezd le az adatbázisból.

> MEGJEGYZÉS: Az eredményt a `payment_id` szerint növekvő sorrendben rendezd.

## Az adatbázis részletei

Ehhez a feladathoz a rendelkezésre bocsátott H2 adatbázist használd.

> A mintaadatbázis fájlja `gofigure.mv.db`, az adatbázis neve pedig `gofigure`. A `db` mappában található.

A következő táblák már benne vannak a minta H2 adatbázisban néhány mintaadattal együtt. Az oszlopnevek és az adattípusok az alábbiak.

**Tábla neve**: `Employee`

| **Oszlopok:**      | típus |
| -----------       | ----------- |
| `employee_id`     | egész szám, automatikusan növelt elsődleges kulcs       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | egész szám        |

**Tábla neve**: `Payment`

| **Oszlopok:**      | típus |
| -----------       | ----------- |
| `payment_id`      | egész szám, automatikusan növelt elsődleges kulcs       |
| `date`            | dátum        |
| `amount`          | tizedes tört        |
| `employee_id`     | egész szám        |
| `reason`          | string        |

* Az adatbázisfájl neve `gofigure.mv.db`. A JDBC URL-t így add meg: `jdbc:h2:file:/path/to/db/file`
* Felhasználónév: `root`
* Jelszó: `root`

## Megkötések

* A lekérdezések és a Ballerina-minta érvényesítéséhez a `db` mappában megadott H2 adatbázisfájlt használd.
* A H2 adatbázis-illesztőprogramot a Maven dependency params megközelítéssel add hozzá platformfüggőségként a Ballerina.toml fájlodban.

## Tesztkörnyezet

* A teszteket a `bal test` paranccsal futtathatod, amelyek a megadott mintaadatbázison futnak le.

## Példák

### 1. példa

**Bemenet:** dbFilePath: `“/Path/to/file/gofigure”`, amount: `3000`

## Tippek

* Az adatbázissal való munkához a [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) modult használd.
* A JDBC-illesztőprogram függőségként való hozzáadásának lépéseit az [Előfeltétel](https://lib.ballerina.io/ballerinax/java.jdbc/latest) szakaszban találod.
* Az adatok adatbázisból való lekérdezéséhez a [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) remote metódust használd.
* Nézd meg a [Simple query](https://ballerina.io/learn/by-example/mysql-query-operation) példát.
* Az adatok eléréséhez a Ballerina [stream](https://ballerina.io/learn/by-example/stream-type) típusát használd.
* A szükséges adathalmazt SQL joinokkal keresd meg az adatbázisból.
