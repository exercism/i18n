# Halmazok

A [`set`][type-set] egy _módosítható_ és _rendezetlen_ gyűjtemény, amely [_hash-elhető_][hashable] objektumokat tartalmaz.
A halmaz elemei csak különbözőek lehetnek, ismétlődő elemek nem szerepelhetnek benne.
Többféle adattípust és akár egymásba ágyazott struktúrákat is tárolhatnak, például `tuple`-ök `tuples`-jét, feltéve hogy minden elem _hash-elhető_.
A halmazoknak létezik egy módosíthatatlan [`frozenset`][type-frozenset] változata is.

A halmazokat leggyakrabban arra használjuk, hogy gyorsan eltávolítsuk az ismétlődő elemeket más adatszerkezetekből vagy elemcsoportokból.
Hatékony összehasonlításra is használhatók, amikor nincs szükség a sorrendiségre és az ismétlődések követésére.

A többi gyűjteménytípushoz hasonlóan (_szótárak, listák, tuple-ök_) a `sets` a következőket támogatja:
- Iteráció `for item in <set>` segítségével,
- Tagság vizsgálata az `in` és a `not in` segítségével,
- Hossz kiszámítása a `len()` függvénnyel, valamint
- Sekély másolatok készítése a `copy()` metódussal.

A `sets` nem támogatja:
- Semmilyen indexelést
- Sorrend kialakítását rendezéssel vagy beszúrással
- Szeletelést
- Összefűzést a `+` operátorral


Ha egy `set`-ben vizsgáljuk a tagságot, annak (átlagosan) állandó az időbonyolultsága, szemben egy `list` vagy `string` tagságvizsgálatával, ahol az időbonyolultság az adat hosszával együtt nő.
Az olyan metódusoknak, mint a `<set>.union()`, `<set>.intersection()` vagy `<set>.difference()`, szintén (átlagosan) állandó az időbonyolultságuk.


## Halmazok létrehozása

Bár a halmazokat sokféleképpen létrehozhatod, a legegyszerűbb módok: egy _halmazliterál_ deklarálása, a `set` osztály konstruktorának (`set()`) használata, valamint egy _halmazértelmezés_ használata.

### Halmazliterálok

Egy `set` közvetlenül is megadható _halmazliterálként_, kapcsos `{}` zárójelekkel és az elemek közötti vesszőkkel.
Az ismétlődő elemeket csendben elhagyja:


```python
>>> one_element = {'➕'}
{'➕'}

>>> multiple_elements = {'➕', '🔻', '🔹', '🔆'}
{'➕', '🔻', '🔹', '🔆'}

>>> multiple_duplicates =  {'Hello!', 'Hello!', 'Hello!', 
                            '¡Hola!','Привіт!', 'こんにちは！', 
                            '¡Hola!','Привіт!', 'こんにちは！'}
{'こんにちは！', '¡Hola!', 'Hello!', 'Привіт!'}
```

A halmazliterálok ugyanazokat a kapcsos zárójeleket használják, mint a `dict` literálok, ezért üres `set` létrehozásához a `set()`-et kell használnod.

### A halmazkonstruktor

A `set()` (_a `set` osztály konstruktora_) bármilyen `iterable`-lel használható, ha argumentumként adod át.
Az `iterable` elemein végigmegy, és egyenként adja hozzá őket a `set`-hez.
Az elemek sorrendje nem marad meg, és az ismétlődő elemeket csendben elhagyja:


```python
# To create an empty set, the constructor must be used.
>>> no_elements = set()
set()

# The tuple is unpacked & each element is added.  
# Duplicates are removed.
>>> elements_from_tuple = set(("Parrot", "Bird", 
                               334782, "Bird", "Parrot"))
{334782, 'Bird', 'Parrot'}

# The list is unpacked & each element is added.
# Duplicates are removed.
>>> elements_from_list = set([2, 3, 2, 3, 3, 3, 5, 
                              7, 11, 7, 11, 13, 13])
{2, 3, 5, 7, 11, 13}
```

### Halmazértelmezések

A `lists` és a `dicts` típushoz hasonlóan a halmazok _értelmezéssel_ is létrehozhatók:

```python
# First, a list with duplicates
>>> numbers = [1,2,3,4,5,6,6,5,4,8,9,9,9,2,3,12,18]

# This set comprehension squares the numbers divisible by 3
# Duplicates are removed.
>>> calculated = {item**2 for item in numbers if item % 3 == 0}
{9, 36, 81, 144, 324}
```

### Buktatók halmazok létrehozásakor

Az „unpacking” viselkedése miatt meglepő lehet, ha a `set` konstruktort egy stringgel használod:

```python
# String elements (Unicode code points) are 
# iterated through and added *individually*.
>>> elements_string = set("Timbuktu")
{'T', 'b', 'i', 'k', 'm', 't', 'u'}

# Unicode separators and positioning code points 
# are also added *individually*.
>>> multiple_code_points_string = set('अभ्यास')
{'अ', 'भ', 'य', 'स', 'ा', '्'}
```

Ne feledd: a halmazok különböző adattípusokat és _egymásba ágyazott_ adattípusokat is tárolhatnak, de minden `set` elemnek _hash-elhetőnek_ kell lennie:

```python
# Attempting to use a list for a set member throws a TypeError
>>> lists_as_elements = {['🌈','💦'], 
                        ['☁️','⭐️','🌍'], 
                        ['⛵️', '🚲', '🚀']}

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'list'


# Standard sets are mutable, so they cannot be hashed.
>>> sets_as_elements = {{'🌈','💦'}, 
                        {'☁️','⭐️','🌍'}, 
                        {'⛵️', '🚲', '🚀'}}

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'set'
```

Egy `set`-ekből álló `set` azonban létrehozható a `frozenset()` típus segítségével:

```python
# Frozensets don't have a literal form.
>>> set_1 = frozenset({'🌈','💦'})
>>> set_2 = frozenset({'☁️','⭐️','🌍'})
>>> set_3 = frozenset({'⛵️', '🚲', '🚀'})

>>> frozen_sets_as_elements = {set_1, set_2, set_3}
>>> frozen_sets_as_elements
{frozenset({'⛵️', '🚀', '🚲'}),
 frozenset({'🌈', '💦'}),
 frozenset({'☁️', '⭐️', '🌍'})}
```


## Halmazelemek hozzáadása és eltávolítása

Elemeket a `<set>.add(<item>)` és a `<set>.remove(<item>)` metódussal adhatsz hozzá vagy távolíthatsz el egy `set`-ből.
A `.remove(<item>)` metódus `KeyError`-t dob, ha az elem nincs benne a `set`-ben:

```python
>>> creatures = {'crow', 'duck', 'fish', 'monkey', 'elephant'}
>>> creatures.add('beaver')
>>> creatures.remove('duck')
>>> creatures
{'beaver', 'crow', 'elephant', 'fish', 'monkey'}

# Trying to remove an item that is not present raises a KeyError
>>> creatures.remove('bear')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  KeyError: 'bear'
```

### További módszerek halmazelemek eltávolítására

- A `<set>.discard(<item>)` eltávolít egy elemet a `set`-ből, de **nem** dob `KeyError`-t, ha az elem nincs benne.
- A `<set>.clear()` eltávolítja az összes elemet a halmazból.
- A `<set>.pop()` eltávolít és _visszaad_ egy **tetszőleges** elemet, és `KeyError`-t dob, ha a `set` üres.


## Halmazműveletek

A halmazoknak vannak olyan metódusai, amelyek nagyjából a [matematikai halmazműveleteket][mathematical-sets] utánozzák.
E metódusok többségének (_de nem mindegyikének_) van [operátor][operator] megfelelője.
A metódusok általában bármilyen `iterable`-t elfogadnak argumentumként, míg az operátorok megkövetelik, hogy a művelet mindkét oldala `set` vagy `frozenset` legyen.


### Halmazok közötti tagságvizsgálat

A `<set>.isdisjoint(<other_collection>)` metódussal vizsgálható, hogy egy `set` elemei átfedésben vannak-e egy másik halmaz elemeivel.
A metódus bármilyen `iterable`-t vagy `set`-et elfogad argumentumként.
`True`-t ad vissza, ha a két halmaznak **nincs közös eleme**, és `False`-t, ha **vannak közös elemeik**.

```python
# Both mammals and additional_animals are lists.
>>> mammals = ['squirrel','dog','cat','cow', 'tiger', 'elephant']
>>> additional_animals = ['pangolin', 'panda', 'parrot', 
                          'lemur', 'tiger', 'pangolin']

# Animals is a dict.
>>> animals = {'chicken': 'white',
               'sparrow': 'grey',
               'eagle': 'brown and white',
               'albatross': 'grey and white',
               'crow': 'black',
               'elephant': 'grey', 
               'dog': 'rust',
               'cow': 'black and white',
               'tiger': 'orange and black',
               'cat': 'grey',
               'squirrel': 'black'}
               
# Birds is a set.
>>> birds = {'crow','sparrow','eagle','chicken', 'albatross'}

# Mammals and birds don't share any elements.
>>> birds.isdisjoint(mammals)
True

# There are also no shared elements between 
# additional_animals and birds.
>>> birds.isdisjoint(additional_animals)
True

# Animals and mammals have shared elements.
# **Note** The first object needs to be a set or converted to a set
# since .isdisjoint() is a set method.
>>> set(animals).isdisjoint(mammals)
False
```

### Részhalmazok és szuperhalmazok vizsgálata

A `<set>.issubset(<other_collection>)` metódussal ellenőrizhető, hogy a `<set>` minden eleme benne van-e a `<other_collection>`-ban is.
Az operátoros forma: `<set> <= <other_set>`:

```python
# Set methods will take any iterable as an argument.
# All members of birds are also members of animals.
>>> birds.issubset(animals)
True

# All members of mammals also appear in animals.
# **Note** The first object needs to be a set or converted to a set
# since .issubset() is a set method.
>>> set(mammals).issubset(animals)
True

# Both objects need to be sets to use a set operator
>>> birds <= set(mammals)
False

# A set is always a loose subset of itself.
>>> set(additional_animals) <= set(additional_animals)
True
```

A `<set>.issuperset(<other_collection>)` az `.issubset()` fordítottja.
Arra szolgál, hogy ellenőrizze, hogy a `<other_collection>` minden eleme benne van-e a `<set>`-ben is.
Az operátoros forma: `<set> >= <other_set>`:


```python
# All members of mammals also appear in animals.
# **Note** The first object needs to be a set or converted to a set
# since .issuperset() is a set method.
>>> set(animals).issuperset(mammals)
True

# All members of animals do not show up as members of birds.
>>> birds.issuperset(animals)
False

# Both objects need to be sets to use a set operator
>>> birds >= set(mammals)
False

# A set is always a loose superset of itself.
>>> set(animals) >= set(animals)
True
```

### „Valódi” részhalmazok és szuperhalmazok

A `<set> < <other_set>` és a `<set> > <other_set>` a _valódi részhalmazok_ vizsgálatára szolgál.
Egy `set` akkor valódi részhalmaz, ha a `<` operátorra teljesül, hogy (`<set> <= <other_set>`) **ÉS** (`<set> != <other_set>`).

Egy `set` akkor valódi szuperhalmaz, ha a `>` operátorra teljesül, hogy (`<set> >= <other_set>`) **ÉS** (`<set> != <other_set>`).
Ezeknek az operátoroknak nincs metódusmegfelelőjük:

```python
>>> animal_names = {'albatross','cat','chicken','cow','crow','dog',
                   'eagle','elephant','sparrow','squirrel','tiger'}

>>> animals_also = {'albatross','cat','chicken','cow','crow','dog',
                   'eagle','elephant','sparrow','squirrel','tiger'}

>>> mammals = {'squirrel','dog','cat','cow', 'tiger', 'elephant'}
>>> birds   = {'crow','sparrow','eagle','chicken', 'albatross'}

>>> mammals < animal_names
True

>>> animal_names > birds
True

# A set is not a *proper subset* if set == other set.
>>> animals_also < animal_names
False

# A set is never a *proper subset* of itself
>>> animals_also < animals_also
False
```

### Halmazok uniója

A `<set>.union(*<other iterables>)` egy új `set`-et ad vissza, amely a `<set>` és az összes `<other iterables>` elemeit tartalmazza.
E metódus operátoros formája: `<set> | <other set 1> | <other set 2> | ... | <other set n>`.

```python
>>> perennials = {'Asparagus', 'Broccoli', 'Sweet Potato', 'Kale'}
>>> annuals = {'Corn', 'Zucchini', 'Sweet Peas', 'Summer Squash'}
>>> more_perennials = ['Radicchio', 'Rhubarb', 
                      'Spinach', 'Watercress']

# Methods will take any iterable as an argument.
>>> perennials.union(more_perennials)
{'Asparagus','Broccoli','Kale','Radicchio','Rhubarb',
'Spinach','Sweet Potato','Watercress'}

# Operators require sets.
>>> set(more_perennials) | perennials
{'Asparagus',
 'Broccoli',
 'Kale',
 'Radicchio',
 'Rhubarb',
 'Spinach',
 'Sweet Potato',
 'Watercress'}
```

### Halmazok különbsége

A `<set>.difference(*<other iterables>)` egy új `set`-et ad vissza az eredeti `<set>` azon elemeivel, amelyek nincsenek benne a `<others>`-ban.
E metódus operátoros változata: `<set> - <other set 1> - <other set 2>  -  ... - <other set n>`.

```python
>>> berries_and_veggies = {'Asparagus', 
                          'Broccoli', 
                          'Watercress', 
                          'Goji Berries', 
                          'Goose Berries', 
                          'Ramps', 
                          'Walking Onions', 
                          'Blackberries', 
                          'Strawberries', 
                          'Rhubarb', 
                          'Kale', 
                          'Artichokes', 
                          'Currants'}

>>> veggies = ('Asparagus', 'Broccoli', 'Watercress', 'Ramps',
               'Walking Onions', 'Rhubarb', 'Kale', 'Artichokes')

# Methods will take any iterable as an argument.
>>> berries = berries_and_veggies.difference(veggies)
{'Blackberries','Currants','Goji Berries',
 'Goose Berries', 'Strawberries'}

# Operators require sets.
>>> berries_and_veggies - berries
{'Artichokes','Asparagus','Broccoli','Kale',
'Ramps','Rhubarb','Walking Onions','Watercress'}
```

### Halmazok metszete

A `<set>.intersection(*<other iterables>)` egy új `set`-et ad vissza azokkal az elemekkel, amelyek közösek az eredeti `set`-ben és az összes `<others>`-ban (vagyis az a `set`, ahol minden [metszi egymást][intersection]).
E metódus operátoros változata: `<set> & <other set> & <other set 2> & ... & <other set n>`

```python
>>> perennials = {'Annatto','Asafetida','Asparagus','Azalea',
                 'Winter Savory', 'Broccoli','Curry Leaf','Fennel', 
                 'Kaffir Lime','Kale','Lavender','Mint','Oranges',
                 'Oregano', 'Tarragon', 'Wild Bergamot'}

>>> annuals = {'Corn', 'Zucchini', 'Sweet Peas', 'Marjoram', 
              'Summer Squash', 'Okra','Shallots', 'Basil', 
              'Cilantro', 'Cumin', 'Sunflower', 'Chervil', 
              'Summer Savory'}

>>> herbs = ['Annatto','Asafetida','Basil','Chervil','Cilantro',
            'Curry Leaf','Fennel','Kaffir Lime','Lavender',
            'Marjoram','Mint','Oregano','Summer Savory', 
            'Tarragon','Wild Bergamot','Wild Celery',
            'Winter Savory']


# Methods will take any iterable as an argument.
>>> perennial_herbs = perennials.intersection(herbs)
{'Annatto', 'Asafetida', 'Curry Leaf', 'Fennel', 'Kaffir Lime',
 'Lavender', 'Mint', 'Oregano', 'Wild Bergamot','Winter Savory'}

# Operators require both groups be sets.
>>> annuals & set(herbs)
 {'Basil', 'Chervil', 'Marjoram', 'Cilantro'}
```

### Halmazok szimmetrikus különbsége

A `<set>.symmetric_difference(<other iterable>)` egy új `set`-et ad vissza, amely azokat az elemeket tartalmazza, amelyek a `<set>`-ben **vagy** a `<other>`-ben benne vannak, de **nem mindkettőben**.
E metódus operátoros változata: `<set> ^ <other set>`.

```python
>>> plants_1 = {'🌲','🍈','🌵', '🥑','🌴', '🥭'}
>>> plants_2 = ('🌸','🌴', '🌺', '🌲', '🌻', '🌵')


# Methods will take any iterable as an argument.
>>> fruit_and_flowers = plants_1.symmetric_difference(plants_2)
>>> fruit_and_flowers
{'🌸', '🌺', '🍈', '🥑', '🥭','🌻' }


# Operators require both groups be sets.
>>> fruit_and_flowers ^ plants_1
{'🌲',  '🌸', '🌴', '🌵','🌺', '🌻'}

>>> fruit_and_flowers ^ set(plants_2)
{'🥭', '🌴', '🌵', '🍈', '🌲', '🥑'}
```

~~~~exercism/note

Kettőnél több halmaz szimmetrikus különbsége olyan `set`-et eredményez, amely egyszerre tartalmazza az egyes `set`-ek egyedi elemeit ÉS a sorozat kettőnél több halmaza között megosztott elemeket (_a részleteket lásd a Wikipédiának a [szimmetrikus különbségről][symmetric_difference] szóló cikkében_).  

Ha csak a sorozat egyes `sets`-jeire egyedileg jellemző elemeket szeretnéd megkapni, akkor az összes kéthalmazos kombináció metszetét külön lépésben össze kell gyűjteni, majd el kell távolítani:  


```python
>>> one = {'black pepper','breadcrumbs','celeriac','chickpea flour',
           'flour','lemon','parsley','salt','soy sauce',
           'sunflower oil','water'}

>>> two = {'black pepper','cornstarch','garlic','ginger',
           'lemon juice','lemon zest','salt','soy sauce','sugar',
           'tofu','vegetable oil','vegetable stock','water'}

>>> three = {'black pepper','garlic','lemon juice','mixed herbs',
             'nutritional yeast', 'olive oil','salt','silken tofu',
             'smoked tofu','soy sauce','spaghetti','turmeric'}

>>> four = {'barley malt','bell pepper','cashews','flour',
            'fresh basil','garlic','garlic powder', 'honey',
            'mushrooms','nutritional yeast','olive oil','oregano',
            'red onion', 'red pepper flakes','rosemary','salt',
            'sugar','tomatoes','water','yeast'}

>>> intersections = (one & two | one & three | one & four | 
                     two & three | two & four | three & four)
...
{'black pepper','flour','garlic','lemon juice','nutritional yeast', 
'olive oil','salt','soy sauce', 'sugar','water'}

# The ^ operation will include some of the items in intersections, 
# which means it is not a "clean" symmetric difference - there
# are overlapping members.
>>> (one ^ two ^ three ^ four) & intersections
{'black pepper', 'garlic', 'soy sauce', 'water'}

# Overlapping members need to be removed in a separate step
# when there are more than two sets that need symmetric difference.
>>> (one ^ two ^ three ^ four) - intersections
...
{'barley malt','bell pepper','breadcrumbs', 'cashews','celeriac',
  'chickpea flour','cornstarch','fresh basil', 'garlic powder',
  'ginger','honey','lemon','lemon zest','mixed herbs','mushrooms',
  'oregano','parsley','red onion','red pepper flakes','rosemary',
  'silken tofu','smoked tofu','spaghetti','sunflower oil', 'tofu', 
  'tomatoes','turmeric','vegetable oil','vegetable stock','yeast'}
```
