# Bemutatás
A C++ beépített szám típusait fel lehet osztani egész számokra és lebegőpontos számokra.
Az egész számok olyan számok, amelyeknek nincs törtrészük, például `0`, `691` vagy `-2`.
A lebegőpontos számok tizedespontot tartalmazó számok, például `6.02214076`, `0.1` vagy `-1.616`.

## Egész számok
A következő példa négy különböző változó deklarációját és kezdőértékének beállítását mutatja

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Amikor értéket adsz egy `int` változónak, azt közvetlenül egy literál segítségével is megteheted.
A literál egy közvetlenül a kódba írt szám, például `9241`.
A különböző számrendszerekhez más-más egész literál tartozik.
A tízes számrendszerbeli egész literálok a leggyakoribbak, és a `0`-tól `9`-ig terjedő számjegyeket használják.
Egy speciális előtag, például a `0x` hozzáadásával más számrendszerek is használhatók.
A fenti példa a `9421` számot mutatja be a négy ábrázolási módjában és előtagjával.
Minden változó ugyanarra az értékre van beállítva.

Ha többet szeretnél megtudni a különböző számábrázolási rendszerekről, vess egy pillantást [erre a rövid útmutatóra][cpp_numerical_bases].

A számjegyeket aposztróffal is elválaszthatod, hogy könnyebben olvashatók legyenek.
A `9'241` ugyanaz, mint a `0b0100'100'0001'1001` vagy a `92'4'1`.

## Lebegőpontos számok

A lebegőpontos literáloknak kétféle alakja van.
A szemléletes `0.0024` mellett használhatod a tudományos jelölését is: `2.4e-3`.
A leggyakoribb lebegőpontos típus a `double`.

## Aritmetika

A C++ támogatja a `+`, `-`, `*`, `/`, `(` és `)` jelet, valamint a `%` operátort kifejezések alkotásához.
Két egész szám közötti művelet eredménye is egész szám.
Az `5 / 2` `2`-t ad vissza.
Ha a műveletben részt vevő típusok egyike lebegőpontos, az eredmény is lebegőpontos lesz.
Az `5.0 / 2` és az `5 / 2.0` `2.5`-t ad vissza.
A `%` a maradék operátor, és egy egész osztás maradékát adja vissza: az `5%3` eredménye `2`.

## Az értékadó operátor

Az értékadó operátor egy literált rendel a változóhoz.
Ez mindig jobbról balra történik, soha nem fordítva.

```cpp
int length = 5;
int width = 2;
length = width;
```

Itt az `5` egész érték a `length` változóhoz rendelődik.
Majd a `2` egész érték a `width` változóhoz.
Végül a `width` értéke átmásolódik a `length` változóba, és a korábbi `5` érték elvész.
Azt is vedd figyelembe, hogy a `width` értékét csak az értékadás pillanatában másoljuk a `length`-be.
Ezért ha a `width` értéke később megváltozik, az nem befolyásolja a `length` értékét.

Az értékadó operátor kombinálható a többi operátorral (aritmetikai és bitenkénti); ezek a `compound assignment`, azaz összetett értékadó operátorok: `+=`, `-=`, `*=`, `/=`, `%=`.
Ezek az operátorok úgy módosítják a változó aktuális értékét, hogy egy műveletet hajtanak végre rajta.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

A `people` és `eggs` változó kezdeti értéke `0`.
Ezután a `people` változó meglévő `0` értékéhez hozzáadjuk a `2` egész értéket, és az eredményt visszaírjuk a `people`-be.
A `people` most `2` lesz.
Később személyenként `3` tojást adunk hozzá, ami összesen `6` tojást jelent.
Most adjuk hozzá ezt a `6`-ot az `eggs` változó meglévő `0` értékéhez, és írjuk vissza az `eggs`-be.
Az `eggs` most `6` lesz.
A megfelelő kifejezés a `people = people + 2` és az `eggs = eggs + (3 * people)` lenne.

## Kasztolás

A kasztolás az egyik típusból a másikba való átalakítás.
Ha `double`-ra van szükség, a helyén `int` is használható.
A fenti `5.0 / 2` példánál a `2` implicit módon `2.0`-ra alakul.
Egy `int`-té alakított `double` információt veszíthet.
Jó gyakorlat az ilyen, más `T` típusra történő átalakításokat explicit módon a `static_cast<T>` segítségével elvégezni.
A régi, C-stílusú `(T)` szerinti átalakítást a modern C++ nem javasolja, de azért ismerni érdemes.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## Pontosság és ábrázolás

A C++ számai nem lehetnek tetszőlegesen nagyok.
Az `int` például 32 biten van ábrázolva.
Ez `2^32` szám ábrázolásához elég, ami nagyjából 4 milliárd.
A `0`-t is beleszámítva ez azt jelenti, hogy a legkisebb `int` a `-2^31`, a legnagyobb pedig a `2^31 - 1`.

A lebegőpontos számokat általában 15 tizedesjegy pontossággal implementálják, de az ábrázolásuk a gazdarendszertől függően változhat.
