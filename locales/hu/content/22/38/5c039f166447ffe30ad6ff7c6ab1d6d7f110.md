# Bevezetés

A [mintaillesztés][pattern-matching] kifejező erejű elágazó kódot tesz lehetővé, a [destrukturálás][destructuring] pedig elegánsan köti az értékeket a változókhoz.
Mindkettő elsajátítása rendkívül hasznos az elm programozóknak, együtt használva pedig nagyban javítják a kód olvashatóságát.

## Egyszerű mintaillesztés

A mintaillesztés a kezelt adat alakja szerint ágaztatja el a kódot.
Így természetesen illeszkedik az egyedi típusok fogalmához, amelyek azt fejezik ki, milyen alakokat ölthet egy adat.
Ha például adott egy `Color` egyedi típus, amely vagy `Blue`, vagy `Red`, akkor írhatunk egy `toString` függvényt, amely a színre illesztett mintával a megfelelő stringet adja vissza.

```elm
type Color = Blue | Red

toString : Color -> String
toString color =
    case color of
        Blue -> "blue"
        Red -> "red"
```

A mintaillesztés olyan egyedi típusokra is működik, amelyek nem egyszerű felsorolások.
Nézzünk egy `hello` függvényt, amely paraméterként egy `Maybe String`-et kap, ami vagy egy személy nevét tartalmazza, vagy semmit.
Mintaillesztéskor kisbetűs neveket adhatunk az adatoknak, hogy az adatot ehhez a változóhoz kössük, és felhasználhassuk az illesztés jobb oldalán.

```elm
hello : Maybe String -> String
hello maybeName =
    case maybeName of
        Nothing -> "Hello stranger!"
        -- here we bind 'name' to the data inside the 'Just'
        Just name -> "Hello " ++ name ++ "!"
```

A mintaillesztésnek kimerítőnek kell lennie, különben a fordító megtagadja a fordítást.
Néha viszont nem törődünk bizonyos adatokkal, vagy egy `case` kifejezés néhány ágával.
Ilyenkor ahelyett, hogy változónevet keresnénk a kötéshez, és minden esetre külön ágat írnánk, használhatjuk az aláhúzás helyettesítő karaktert, a `_`-t.

```elm
type Entity = Friend { name: String } | Stranger | Alien

hello : Entity -> String
hello entity =
    case entity of
        -- here we don't care about the data held by 'Friend'
        Friend _ -> "Hi!"
        -- mandatory because pattern matching must be exhaustive,
        -- but for all other cases, we answer the same thing
        _ -> "Hello stranger!"
```

## Haladó mintaillesztés

Az egyedi típusok mellett olyan típusokra is illeszthetünk mintát, amelyeknek literáljaik vannak, például `Char`, `String`, `Int` és `Floats`.

```elm
howMany : Int -> String
howMany count =
    case count of
        0 -> "none!"
        1 -> "there is one!"
        2 -> "a couple!"
        _ -> "too many to count!"

greekLetter : String -> String
greekLetter letter =
    case letter of
        "a" -> "alpha"
        "b" -> "beta"
        _ -> "I don't remember"
```

Ha egynél több értékre akarunk illeszteni beágyazás nélkül, gyakori elm trükk, hogy az illesztendő értékeket [_ad hoc tuple_-okba][ad-hoc-tuples] fogjuk össze, így:

```elm
howManyGreekLetters : Int -> String -> String
howManyGreekLetters count letter =
    case ( count, letter ) of
        ( 0, _ ) -> "none!"
        ( 1, "a" ) -> "there is an alpha!"
        ( 1, "b" ) -> "there is a beta!"
        _ -> "at least two!"
```

És mivel a listák kedvesek a funkcionális programozóknak, [ezekre is illeszthetünk mintát][pattern-match-lists], ugyanazzal a szintaxissal, amellyel felépülnek, a `::` operátor segítségével.

```elm
head : List a -> Maybe a
head list =
    case list of
        [] -> Nothing
        x :: _ -> Just x
```

Végül a mintaillesztés rekurzívan is működik, ami mély belemerülést tesz lehetővé összetett és rekurzív típusokba.

```elm
type Activity = Work | Play Game
type Game = Boardgame String | VideoGame String

pickActivity : Activity -> Bool
pickActivity activity =
    case activity of
        -- The only thing we want is playing Catan
        Play (Boardgame "Catan") -> True
        _ -> False
```

## Destrukturálás

A destrukturálás nagyon hasonlít a mintaillesztéshez: lehetővé teszi változók hozzákötését a típusokon belüli adatokhoz.
A fő különbség, hogy ezt a mechanizmust akkor nevezzük destrukturálásnak, ha csak egyetlen alak lehetséges, és akkor mintaillesztésnek, ha több.
A destrukturálás gyakran előfordul `let` kötésekben, függvényargumentumokban, és persze `case` kifejezésekben, a mintaillesztéssel vegyítve.

```elm
pairSum : ( Int, Int ) -> Int
pairSum pair =
    -- Destructuring of a pair in a 'let' binding
    let ( x, y ) = pair
    in x + y

-- Custom type containing a single variant
type Container = Box String

-- Destructuring of the container as function argument
-- to bind its content directly without the need of 'let' or 'case'.
unbox : Container -> String
unbox (Box str) =
    str

-- Destructuring combined with pattern matching
unboxMaybe : Maybe Container -> Maybe String
unboxMaybe maybeContainer =
    case maybeContainer of
        Nothing -> Nothing
        Just (Box "42") -> Just "The answer to the universe!"
        Just (Box str) -> Just str
```

A destrukturálás használható egyváltozatú egyedi típusokra, tuple-okra, és rekordokra is, ahol nagyon kényelmes.
Egy [rekord destrukturálásához][records-pattern-matching] használhatjuk a mezői közül akárhányat: egyet, kettőt, ..., vagy az összes mezőt.

```elm
type alias Circle =
    { radius : Float
    , center : ( Float, Float )
    }

perimeter : Circle -> Float
perimeter { radius } =
    2 * pi * radius
```

Sajnos az elm szintaxisa nem teszi lehetővé a rekordok rekurzív destrukturálását.
A korábbi `Circle` példában nincs mód arra, hogy a kör középpontjának `x`` and `y pozícióját egyszerre elérjük.
Először a `center`-hez kell hozzáférnünk, majd destrukturálnunk kell, hogy megkapjuk az `x` és `y` pozícióját.

```elm
left : Circle -> Float
left { radius, center } =
    let ( x, _ ) = center
    in x - radius
```

És van egy utolsó tippünk is!
Néha egyszerre szeretnénk könnyen hozzáférni egy dolog egészéhez és annak egy részéhez.
Itt jöhet jól az [`as` kulcsszó][as-keyword].
Ez lehetővé teszi, hogy egy dolog egészének álnevet adjunk, miközben a tartalmát továbbra is destrukturálhatjuk.

```elm
-- Make the circle smaller if the radius is sufficiently big.
-- Otherwise, return the circle unchanged.
smaller : Float -> Circle -> Circle
smaller reduction ({ radius, center } as circle) =
    if reduction < radius then
        { radius = radius - reduction
        , center = center
        }
    else
        circle
```
