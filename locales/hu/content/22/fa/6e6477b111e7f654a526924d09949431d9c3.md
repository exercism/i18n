# Névjegy

A fájl egy névvel ellátott folyam a lemezen. Az [`io.files`][io.files] szókészlet két módot kínál arra, hogy egy fájllal dolgozz: teljes fájlt kezelő kényelmi szavakat, amelyek egyetlen hívásban olvassák vagy írják a teljes tartalmat, és folyamnyitókat (a `with-…` kombinatorokat) a fokozatos olvasáshoz vagy íráshoz. Mindkettő ugyanarra a [folyamprotokollra][stream-protocol] épül, mint az `io-streams` fogalom memóriabeli folyamai: a `<file-reader>` és a `<string-reader>` ugyanazokra a szavakra válaszol.

Minden fájlszó egy **kódolást** kap: ez az a séma, amely a bájtokat karakterekké alakítja, és vissza. Szöveg esetén ez szinte mindig az `io.encodings.utf8` szókészletből származó [`utf8`][utf8]; a bináris munkához a `latin1` vagy egy `<byte-array>` kódolás kell.

## Teljes fájl beolvasása

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

A `file-contents` az egész fájlt egyetlen stringként adja vissza. A `file-lines` a fájl sorait tömbként adja vissza, a sorvégek levágásával. Ez akkor jön jól, ha minden sor egy rekord.

```factor
USING: io.encodings.utf8 io.files ;

"forecast.txt" utf8 file-contents   ! => "sunny\ncloudy\n"
"forecast.txt" utf8 file-lines      ! => { "sunny" "cloudy" }
```

## Teljes fájl kiírása

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Mindkettő **felülírja** a fájlt, és létrehozza, ha még nem létezik. A `set-file-contents` szó szerint kiírja a stringet; a `set-file-lines` egy sorozat minden elemét külön sorba írja, és maga gondoskodik a sortörésekről.

```factor
{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
! forecast.txt now holds "sunny\ncloudy\n"
```

## Hatókörhöz kötött folyamok

Ha hozzá szeretnél fűzni a fájlhoz, vagy darabonként szeretnél olvasni és írni, nyisd meg egy `with-…` kombinatorral, és a quotation belsejében használd az aktuális folyam szavait:

```
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
with-file-appender   ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files ;

"log.txt" utf8 [ "another line" print ] with-file-appender
```

A `with-file-writer` először csonkolja a fájlt; a `with-file-appender` megtartja a meglévő tartalmat, és utána ír. Mindegyik egy destruktoros hatókör: a fájlleíró bezárul, amikor a quotation befejeződik, akkor is, ha kivételt dob. Ugyanezt a garanciát nyújtják a `boatswains-bilge` kombinatorok, itt a fájlokra szabva.

## Teljes fájl vagy hatókörhöz kötött?

Akkor nyúlj a `file-contents` / `file-lines` / `set-file-contents` / `set-file-lines` szavakhoz, ha a fájl elég kicsi ahhoz, hogy elférjen a memóriában, és egyszerre az egésszel akarsz dolgozni. A `with-…` nyitókhoz akkor nyúlj, ha hozzá akarsz fűzni, ha egy nagy fájlt szeretnél soronként folyamként olvasni a `readln` segítségével, vagy ha keverni akarod az olvasást és az írást. Minden olyan esetben, amikor a teljes fájl memóriában tartása pazarló vagy hibás lenne.
