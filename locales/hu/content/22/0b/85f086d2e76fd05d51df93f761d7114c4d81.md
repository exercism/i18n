# kerülni kell az imperatív ciklust

Ennél a feladatnál kerüld a for ciklusok használatát.

A bevezető szerint a JavaScript Array objektumnak vannak olyan beépített metódusai, amelyeket kifejezetten elemzésre szántak.

Nézd meg a bevezetőt és/vagy az [MDN dokumentációt](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array#instance_methods) arról, hogy milyen metódusok állnak rendelkezésedre.
