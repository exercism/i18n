# Bevezetés

A Clojure-ben a `vector` egy szekvenciális, indexelt, nem módosítható gyűjtemény, amely nulla vagy több értéket tartalmaz. Ez azt jelenti, hogy miután létrehoztunk egy vektort, azt többé nem lehet megváltoztatni. A vektorokon dolgozó függvények új vektort adnak vissza, az eredeti vektor pedig változatlan marad. A vektorban lévő értékek különböző típusúak is lehetnek. A vektorokat így definiálhatjuk:

```clojure
(def empty [])
(def single-value [5])
```

A vektor elemeit index segítségével kérhetjük le. A Clojure vektorai nullától indexelődnek, ami azt jelenti, hogy az első elem indexe mindig nulla:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Az eredeti vektor változatlan marad:

```clojure
numbers
;;=> [2 3 5]
```

Ahhoz, hogy megjegyezzük a frissített értéket, tovább kell adnunk, vagy el kell kapnunk egy var-ban:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
