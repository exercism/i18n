# Bemutatás

A Gleamben a lista nulla vagy több értékből álló, megváltoztathatatlan gyűjtemény. A listában lévő értékeknek mind ugyanolyan típusúnak kell lenniük. Mivel a listák megváltoztathatatlanok, miután létrejött egy lista, az értéke soha nem változhat meg. Minden függvény és operátor, ami úgy tűnik, hogy módosítja a listát (például elemet ad hozzá), valójában egy új listát ad vissza.

A listákat a következőképpen definiálhatod:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

A leggyakoribb módja annak, hogy elemet adj egy listához, hogy a spread szintaxissal az elejére fűzöd:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

A Gleam szabványos könyvtárában található [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) modul sok hasznos függvényt tartalmaz a listákkal való munkához. Ezt a modult nagyon gyakran használják a Gleam-kódban, ezért érdemes jól ismerned.

A listamintákat case-kifejezésekben használhatod, hogy illeszkedj a listákra, és a bennük lévő értékeket változókhoz rendeld:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

A pontos hosszúságú listákra való illesztés mellett a spread szintaxissal olyan listákra is illeszkedhetsz, amelyek legalább egy bizonyos hosszúságúak:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

A spread szintaxis arra is használható, hogy a lista maradékát egy változóhoz rendeld:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

A case-kifejezésekben minden lehetséges értékhez mintát kell adnod abból a típusból, amire illeszkedsz, ezért a maradék értékek lefedésére gyakran egy záró eldobó mintát (`_`) használsz.
