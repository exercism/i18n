# Részletesen

A `cond` mellett az Elixir a [`if/2`][getting-started-if] makrót is biztosítja, amely akkor hasznos, ha csak egyetlen feltételt kell ellenőrizned.

Az [`if/2`][kernel-if] egy feltételt és két opciót fogad. Az első opciót adja vissza, ha a feltétel _truthy_, a másodikat pedig, ha a feltétel _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Ha a második opciót nem adod meg, `nil` lesz a visszatérési érték.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

Az `if` kifejezést egyetlen sorban is leírhatod. Figyeld meg a feltétel utáni vesszőt.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Ez a szintaxis nagyon rövid kifejezéseknél hasznos, de kerüld, ha a kifejezés nem fér el egyetlen sorban.

## _Truthy_ és _falsy_

Az Elixirben minden adattípus _truthy_ vagy _falsy_ értékre értékelődik ki, amikor Boolean kontextusban (például egy `if` kifejezésben) találkozol vele. Minden adat _truthy_-nak számít, **kivéve** a `false`-t és a `nil`-t. Az üres stringek, a `0` egész szám és az üres listák is _truthy_-nak számítanak az Elixirben. Ebben a tekintetben [az Elixir a Rubyhoz hasonlít, de különbözik a JavaScripttől, a Pythontól és a PHP-tól][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

A [`&&/2`][kernel-and], a [`||/2`][kernel-or] és a [`!/1`][kernel-not] _truthy_ Boolean operátorok, amelyek bármilyen értékkel működnek, és kiegészítik a _strict_ Boolean operátorokat: az [`and/2`][kernel-boolean-and], az [`or/2`][kernel-boolean-or] és a [`not/1`][kernel-boolean-not] operátort.

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
