# Utasítások

Egy exkluzív mozit vezetsz.
Ahhoz, hogy bejussanak egy filmre, az embereknek éves bérletet kell venniük, utána ingyen nézhetnek filmeket.

A mozid nyilvántartja a belépéseket.
Ezt a nyilvántartást szeretnéd használni arra, hogy nyomon kövesd, mely tagok használták fel az éves bérletüket ebben a hónapban.
Emellett információt szeretnél kapni a vásárlóid életkori összetételéről is.
Rájössz, hogy ezeket a célokat halmazokkal is meg tudod oldani.

## Halmazok

A halmaz tökéletes adattípus az ilyen jellegű adatok tárolására.

A halmaz olyan adattípus, amely különböző, egyedi értékeket tárol, meghatározott sorrend nélkül.
A különböző és egyedi azt jelenti, hogy egy elem vagy benne van a halmazban, vagy nincs; egy tömbtől eltérően nem szerepelhet többször a halmazban.
A halmazok jellemzően rendezetlenek; ha kilistázod egy halmaz elemeit, a kapott sorrend eltérhet attól, ahogy hozzáadtad őket, sőt még az előző listázáskor kapott sorrendtől is!

A halmazok egyik alapvető tulajdonsága a tagságvizsgálat: annak lehetősége, hogy ellenőrizzük, tartalmaz-e egy halmaz egy adott elemet.
A tagságvizsgálat szinte minden halmazhasználat középpontjában áll.

A Go nem biztosít beépített halmaz adattípust.
Halmaz helyett gyakran `map[<type>]struct{}` vagy `map[<type>]bool` típust használunk; a halmazhoz hasonlóan a `map` is engedi különböző, egyedi elemek hozzáadását, és támogatja a tagságvizsgálatot.

## 1. Hely a résztvevők adatainak tárolására

A látogatottság és az életkori összetétel nyomon követéséhez halmazt szeretnél használni.

Nem szeretnél külön halmazt írni a neveknek és az életkoroknak; helyette használhatsz egy generikus halmazt mindkettőhöz.
Definiáld a `Set` típust `map[T comparable]struct{}`-ként a résztvevők tárolásához.
Írj egy `NewSet[T comparable]()` függvényt, amely egy üres `Set[T]`-t ad vissza.

```go
names := NewSet[string]()
```

## 2. A résztvevők nyomon követése

Most már készen állsz arra, hogy rögzítsd a résztvevők adatait.

Írj egy `Add[T]()` metódust, amely hozzáad egy elemet a halmazhoz.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. A résztvevők ellenőrzése

Most, hogy van egy halmazod a résztvevőkről, ellenőrizheted, hogy megjelentek-e bizonyos tagok és életkori csoportok.
Írj egy `Contains[T](element)` metódust, amely visszaadja, hogy egy tag vagy életkori csoport benne van-e a `Set`-ben.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. A résztvevők összehasonlítása

Eltelt egy újabb hónap, és van egy új `Set`-ed az életkori összetételről.
A marketingmenedzsered szeretné tudni, hogy az e havi új bemutatók megváltoztatták-e, milyen életkori csoportok jönnek el.
Írj egy `Equals[T](other)` metódust, amely megállapítja, hogy két halmaznak ugyanazok-e az elemei.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
