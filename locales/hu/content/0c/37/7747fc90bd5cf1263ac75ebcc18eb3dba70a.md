# Docker

A representereinket Docker-image-ekként élesítjük.

Kérünk, olvasd el az általános Tooling Docker-információkat, hogy megismerkedj a működésükkel.

## Integráció

Amikor egy representert futtatunk, hogy elkészítsük egy megoldás reprezentációját, egy ilyen Docker-parancsot futtatunk:

```shell
docker run \
        --rm \
        --network none \
        --mount type=bind,src="${solution_dir}",dst=/solution \
        --mount type=bind,src="${output_dir}",dst=/output \
        --tmpfs /tmp:rw \
        "exercism/${track_slug}-representer" \
        "${exercise_slug}" "/solution" "/output"
```

Láthatod, hogy három argumentumot adunk át a Docker-image-nek:

1. A feladat slugja
2. A megoldás könyvtárának elérési útja
3. A kimeneti könyvtár elérési útja

## Konvenciók

A representereink mindegyike a következő konvenciókat használja a megvalósításában:

- A `Dockerfile` a repo gyökérkönyvtárában van.
- A munkakönyvtár a `/opt/representer` legyen.
- A belépési pont a `/opt/representer/bin/run.sh`
- A `/opt/representer/bin/run.sh` szkript 3 argumentumot fogad:
  1. A feladat slugja
  2. A megoldás könyvtárának elérési útja
  3. A kimeneti könyvtár elérési útja

További információért lásd: [A felület](/docs/building/tooling/test-runners/interface).

```exercism/note
Az új representer-repók alapértelmezés szerint ezeket a konvenciókat fogják használni.
```
