# Utasítások

Tori klímaújságíró, és cikket szeretne írni a különböző városok időjárásáról. Adatai vannak a különböző városok időjárásáról, és a hőmérsékletük alapján szeretné rangsorolni őket, csakhogy a hőmérsékletek egy része Fahrenheitben, más része Celsiusban van. Segítségre van szüksége ahhoz, hogy a hőmérsékleteket ugyanabba a mértékegységbe váltsa, és sorrendbe állítsa őket.

## 1. Fahrenheit átváltása Celsiusra

Definiáld a `fahrenheit_to_celsius` függvényt, amely argumentumként egy Fahrenheitben megadott hőmérsékletet kap, és visszaadja a hőmérsékletet Celsiusban.

A Fahrenheit Celsiusra váltásához vonj le 32-t a Fahrenheit-értékből, majd oszd el az eredményt 1,8-del.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. Két hőmérséklet összehasonlítása

Definiáld a `compare_temperature` függvényt, amely két hőmérsékletet kap, és egy `Order` értéket ad vissza, amely jelzi, hogy az első hőmérséklet kisebb-e, egyenlő-e vagy nagyobb-e, mint a második hőmérséklet.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. Városok rendezése hőmérséklet szerint

Definiáld a `sort_cities_by_temperature` függvényt, amely városok egy listáját kapja, és a leghidegebbtől a legmelegebbig adja vissza őket.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
