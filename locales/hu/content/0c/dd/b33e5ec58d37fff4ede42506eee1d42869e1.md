# Ne módosítsd a megadott szignatúrákat

Ahogy az utasítások is említik, a `makeChest` és a `makeTreasureChest` szignatúráját nem szabad módosítanod.
Pontosan így kell maradniuk:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
