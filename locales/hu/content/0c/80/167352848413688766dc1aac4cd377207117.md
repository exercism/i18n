# Névjegy

A rekurzió arra való, hogy egy függvényben ismételjük a kódot úgy, hogy a függvény önmagát hívja meg.
Ez egy másik módja annak, hogy ciklust alkossunk, illetve iteráljunk. A ciklusokhoz hasonlóan a függvénynek itt is meg kell vizsgálnia egy Boolean-kifejezést, hogy tudja, mikor álljon le.
A ciklusokkal ellentétben a soha véget nem érő rekurzió nem fut a végtelenségig.
Az egyes függvényhívásokban használt értékek a veremben a saját keretükbe kerülhetnek.
Ha a függvényhívások száma több helyet foglal el, mint amennyi a veremben van, az veremtúlcsordulási hibához vezet.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Ez a következőt írja ki:

```
The number is 1
The number is 2
After recursion
```

Lehetnek olyan helyzetek, amelyek rekurzióval kifejezve olvashatóbbak és/vagy könnyebben átgondolhatók, mint ciklussal kifejezve.


## Farokhívás

Farokhívásról akkor beszélünk, amikor egy függvény utolsó utasítása csak önmagát hívja meg, és semmi mást nem tesz.

A farokhívás a rekurzió egy sajátos formája, amely lehetővé teheti, hogy a fordító a lefordított kódban ciklussá alakítsa a rekurziót.
Ez a legjobbat hozza ki mindkét világból: a rekurzió olvashatóságát a ciklus teljesítményével.
A rekurziónak ciklussá fordítását `tail call elimination`, illetve `tail call optimization.` néven emlegetik.

Amikor egy farokhívást ciklussá fordít a fordító, nem jön létre új veremkeret minden függvényhívásnál.
A függvény eredeti hívásakor kapott címre frissített értékek kerülnek átadásra, ami veremhelyet takarít meg és javítja a teljesítményt.

Ez a példa nem farokhívás, mert a függvény 1-et ad hozzá az önmagára irányuló hívás eredményéhez

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

Ez a következőt írja ki:

```
The number is 1
The number is 2
j is 3 after recursion
```

Ha farokhívássá szeretnéd alakítani, tedd a `j`-t a `printIncrement` paraméterévé

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

Lehet, hogy úgy találod, a farokhívás könnyebben átgondolható, mint egy rekurzív hívás, amely nem farokhívás.
A fordítók azonban általában nem garantálják, hogy minden farokhívást optimalizálnak.
Rekurzió használatakor mindig fontos tudni, hogy nem lesz olyan sok iteráció, hogy a verem túlcsorduljon.
