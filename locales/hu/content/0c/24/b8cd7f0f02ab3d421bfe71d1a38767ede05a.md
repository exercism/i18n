# Részletek

A [ternáris feltételes operátor][ternary-operator] az `if-else` kifejezés tömör formája.
Kiértékel egy feltételt, és attól függően adja vissza a két érték egyikét, hogy a feltétel `true` vagy `false`.

Az operátor három részből áll: `condition ? trueExpression : falseExpression`.
Ha a `condition` értéke `true`, akkor a `trueExpression` értékelődik ki és adódik vissza, ellenkező esetben a `falseExpression` értékelődik ki és adódik vissza.

A ternáris operátor egyszerű, egysoros döntésekhez ideális:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

A fenti példa az alábbi kód tömör megfelelője:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
