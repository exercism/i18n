# Bevezetés

A Go-ban a `struct` névvel ellátott elemek sorozata, amelyeket _mezőknek_ nevezünk; minden mezőnek van neve és típusa.
Egy mező nevének egyedinek kell lennie a structon belül.
A structokat az objektumorientált programozás paradigmájában _osztályokhoz_ lehet hasonlítani.

## Egy struct definiálása

Új structot a `type` és a `struct` kulcsszó használatával hozol létre, a mezők nevét és típusát pedig explicit módon adod meg.
Például itt egy `Shape` structot definiálunk, amely egy alakzat nevét és méretét tárolja:

```go
type Shape struct {
    name string
    size int
}
```

A structok mezőnevei követik a Go konvencióját: a kisbetűvel kezdődő nevű mezők csak az ugyanabban a csomagban lévő kód számára láthatók, a nagybetűvel kezdődők viszont más csomagokból is.

## Structpéldányok létrehozása

Miután definiáltad a `struct`-ot, létre kell hoznod egy új példányt, és a mezőket a nevük megadásával, tetszőleges sorrendben adhatod meg:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Egy példány mezőinek beolvasásához vagy módosításához a `.` jelölést használd:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Azok a mezők, amelyeknek nem adsz kezdőértéket, a nullaértéküket kapják.
Például:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Létrehozhatsz egy `struct` példányát a mezőnevek használata nélkül is, amennyiben a mezőket _sorrendben_ adod meg:

```go
s := Shape {
	"Oval",
	20,
}
```

Ez a szintaxis azonban _törékeny kódnak_ számít, mert eltörhet, amikor új mező kerül bele, különösen akkor, ha az új mező típusa más.
A következő példában egy plusz mezőt adunk a `Shape`-hez:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## „New” függvények

Néha kellemes lehet olyan függvényekkel dolgozni, amelyek segítenek structpéldányokat létrehozni.
A konvenció szerint ezeket a függvényeket általában `New`-nak hívják, vagy a nevük `New`-val kezdődik, de mivel ezek csak közönséges függvények, bármilyen nevet adhatsz nekik.
Talán más nyelvek konstruktoraira emlékeztetnek, de Go-ban ezek csak közönséges függvények.

A következő példában az egyik ilyen `New` függvény arra szolgál, hogy létrehozza a `Shape` egy új példányát, és automatikusan beállítsa az alakzat `size` mezőjének alapértelmezett értékét:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

A `New` függvények használatának a következő előnyei lehetnek:

* a megadott értékek ellenőrzése
* az alapértelmezett értékek kezelése
* mivel a `New` függvényeket gyakran ugyanabban a csomagban deklarálják, mint a structokat, amelyeket inicializálnak, akár a struct privát mezőit is inicializálhatják

Ha mélyebben szeretnél elmerülni ebben a típusban, nézd meg ezeket a forrásokat: [Go by Example: Structs][go-by-example-structs], [A Tour of Go: Structs][tour-of-go-structs] vagy [Structures in Go (structs)][medium-structures-in-go]

## A beépített `new`

Egy struct új példányát a beépített `new` segítségével is létrehozhatod:

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

Ebben a példában a `new` létrehozza a `Shape` struct egy példányát úgy, hogy minden értéket a típusuk nullaértékére inicializál, és visszaad egy mutatót rá.

~~~~exercism/note
A legtöbb esetben nem fogsz olyat látni, hogy a structok új példányait a beépített `new`-val hoznák létre.
Mindig részesítsd előnyben a structliterált, egy saját `New` függvényt vagy bármely más, a csomag által biztosított függvényt, amely segíthet egy struct felépítésében.
A beépített `new`-t csak végső esetben használd structok új példányainak létrehozására.
~~~~
