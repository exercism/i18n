A Raku rendkívül gazdag, rugalmas és erőteljes programozási nyelv.
Rugalmasságának köszönhetően a programozók a saját stílusukhoz illő, kifejező kódot írhatnak.

A Raku nagy nyelv, amelyben bőven van mit tanulni, felfedezni és kísérletezni.
Ez a tanterv az alapokat igyekszik lefedni, hogy el tudj kezdeni vele dolgozni.

Az objektumorientált programozás a Raku szívében van, a nyelv azonban nem kényszeríti rád az objektumorientált gyakorlatot.
Objektumorientált természete miatt ez a tanterv gyakran hivatkozik majd [objektumokra, osztályokra és metódusokra][object-orientation].

## Változók

Az alapoknál csak skaláris [változókat][variables] használunk, hogy egyszerű maradjon a dolog.

A skaláris változók olyan [azonosítók][identifiers], amelyek előtt a `$` szigil áll.

A skaláris változók gyakorlatilag bármit tartalmazhatnak, és alapértelmezett típusuk [`Any`][Any].

A legtöbb változót, amit használsz, [deklarálni][variable-declarator] kell.
Egyelőre maradj a [`my`][my] és a [`constant`][constant] mellett.

```raku
my $foo;
constant $BAR;
```

## Szubrutinok

A szubrutint a [`sub`][sub-declarator] deklarációs kulcsszóval deklaráljuk.

A `sub` deklarációt egy opcionális [azonosító][identifiers], majd egy opcionális [szignatúra][signatures], végül egy [blokk][blocks] követi.

A szubrutinok (többek között) exportálhatók a [`is export`][exporting] tulajdonság hozzáadásával.

Egy szubrutint meg lehet hívni az azonosítón egy [postcircumfix `( )`][postcircumfix-()] operátorral.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## Operátorok

A Rakuban [operátorok][operators] széles választéka van.
Az Alapok fogalom gyakorlataihoz néhány egyszerű matematikai operátort használunk majd Rakuban, például a `+` és a `-` jelet.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

Ha szeretnéd, könnyedén definiálhatsz saját operátorokat Rakuban.
A legtöbb beépített operátor szubrutinként is elérhető.

## Csomagok és modulok

A Rakuban többféle [csomag][package-declarator] létezik. Az Alapok fogalomban csak a `module`-t használjuk.

Ahhoz, hogy egy egész fájlt `module`-ként deklarálj, a moduldeklaráció elé a `unit` kerül.

```raku
unit module Foo;

sub bar () { ... }
```

## Megjegyzések

A Rakuban [egysoros][single-line-comments] és [többsoros/beágyazott][multi-line-comments] megjegyzések vannak.

Az egysoros megjegyzések `#`-tel kezdődnek, és a sor végéig tartanak.

A többsoros/beágyazott megjegyzések egy kettőskereszttel kezdődnek, amelyet egy backtick és egy Unicode nyitó írásjel követ.
Egy hozzá illő, páros záró írásjellel végződnek.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## Stíluskonvenciók

A változók és szubrutinok [azonosítói][identifiers] Rakuban `kebab-case` stílusban íródnak.
A konstansok `ALL-CAPS` stílusban íródnak.
A csomagnevek `PascalCase` stílusban íródnak.
