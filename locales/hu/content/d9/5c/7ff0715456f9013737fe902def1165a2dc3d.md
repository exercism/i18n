# Bevezetés

A `Complex numbers` nem bonyolult.
Csak egy kevésbé ijesztő névre van szükségük.

Annyira hasznosak, különösen a mérnöki tudományokban és a természettudományokban, hogy a Julia a komplex számokat szabványos numerikus típusként kezeli, az egész számok és a lebegőpontos számok mellett.

## Alapok

A Júliában egy `complex` érték lényegében egy számpár: általában, de nem mindig lebegőpontos.
Ezeket „valós” és „képzetes” résznek nevezik, sajnálatos történelmi okokból.
Ismét jobb a mögöttes egyszerűségre összpontosítani, nem a furcsa nevekre.

Ha két valós számból komplex számot szeretnél létrehozni, egyszerűen csak írd a képzetes rész után az `im` utótagot.

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> typeof(z)
ComplexF64 (alias for Complex{Float64})
julia> zi = 1 + 2im
1 + 2im
julia> typeof(zi)
Complex{Int64}
```

Így többféle `Complex` típus létezik, amelyek a megfelelő egész- vagy lebegőpontos típusból származnak.

Ha valós változókból szeretnél komplex számot létrehozni, a fenti szintaxis nem működik.
Az `a + bim` írásmód összezavarja az értelmezőt, és azt hiszi, hogy a `bim` egy (nem létező) változónév.

A `b*im` írásmód is lehetséges, de az ajánlott módszer a `complex()` függvény használata, amely megkerüli a szorzás és az összeadás műveletét.

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

Ha külön-külön szeretnéd elérni egy komplex szám részeit:

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> real(z)
1.2
julia> imag(z)
3.4
```

Vagy együtt:

```julia-repl
julia> reim(z)
(1.2, 3.4)
```

Bármelyik rész lehet nulla, és a matematikusok ilyenkor „teljesen valósról” vagy „teljesen képzetesről” beszélhetnek.
A Júliában azonban ez még mindig komplex szám.

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im
julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})
julia> zi = 3.4im
0.0 + 3.4im
julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

Lehet, hogy hallottad már, hogy „`i` (vagy `j`) a -1 négyzetgyöke”.

Egyelőre ez csak annyit jelent, hogy a képzetes rész _definíció szerint_ kielégíti a következő egyenlőséget:

```julia-repl
julia> 1im * 1im == -1
true
```

Ez egyszerű gondolat, de érdekes következményekhez vezet.

## Aritmetika

Minden szabványos matematikai `operators` és elemi függvény, amelyet lebegőpontos és egész számokkal használunk, komplex számokkal is működik. Íme egy kis ízelítő:

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im
julia> z2 = 2 + 1.5im
2.0 + 1.5im
julia> z1 + z2  # addition
3.5 + 3.5im
julia> z1 * z2  # multiplication
0.0 + 6.25im
julia> z1 / z2  # division
0.96 + 0.28im
julia> z1^2  # exponentiation
-1.75 + 6.0im
julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

## Függvények

A `real()` és `imag()` mellett számos más függvény is különösen hasznos a komplex számokhoz.

- A `conj()` egyszerűen megfordítja egy komplex szám képzetes részének előjelét (_pluszból mínuszba vagy fordítva_).
    - A komplex szorzás működése miatt ez hasznosabb, mint gondolnád.
- Az `abs(<complex number>)` garantáltan olyan valós számot ad vissza, amelynek nincs képzetes része.
- Az `abs2(<complex number>)` az `abs(<complex number>)` négyzetét adja vissza: gyorsabb kiszámítani, mint az `abs()`-t, és gyakran pont erre van szükség egy számításban.
- Az `angle(<complex number>)` a fázisszöget adja vissza radiánban.

```julia-repl
julia> z1
1.5 + 2.0im
julia> conj(z1)
1.5 - 2.0im
julia> abs(z1)
2.5
julia> abs2(z1)
6.25
julia> angle(z1)
0.9272952180016122
```
Részleges magyarázat a matematika iránt érdeklődőknek:

- A `z1` `(real, imag)` reprezentációja lényegében derékszögű koordinátákat használ a komplex síkon.
- Ugyanaz a komplex szám `(r, θ)` jelöléssel is ábrázolható, polárkoordináták segítségével.
- Itt `r`-t és `θ`-t rendre az `abs(z1)`, illetve az `angle(z1)` adja.

Íme egy példa néhány konstans használatával:

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im
julia> real(euler)
-1.0
julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

A poláris `(r, θ)` jelölés annyira hasznos, hogy léteznek beépített `cis` (a `cos(x) + isin(x)` rövidítése) és `cispi` (a `cos(πx) + isin(πx)` rövidítése) függvények, amelyek segíthetnek hatékonyabban felépíteni azt.

A poláris jelölés hasznossága Euler elegáns képletében mutatkozik meg: `ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`, ahol `|x + iy| = 1`.
Ha `|x + iy| = r`, akkor megkapjuk a poláris forma általánosabb alakját: `r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`.
Vedd észre, hogy különösen az exponenciális alak tömör és könnyen kezelhető.

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

A fenti megközelítő egyenlőség azért van, mert a `cis` és a `cispi` függvények szebb numerikus eredményeket adhatnak, különösen a `cispi`, amikor olyan argumentumokkal van dolgunk, amelyek a π tetszőleges tényezői (pl. radiánok!).

```julia-repl
julia> cis(π)
-1.0 + 0.0im
julia> cispi(1)
-1.0 + 0.0im
julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im
julia> cis(θ)
6.123233995736766e-17 + 1.0im
julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

Mellesleg ez teszi a komplex számokat nagyon hasznossá a kétdimenziós forgatások és radiális eltolások végrehajtásában.

Forgatásokhoz a `z = x + iy` komplex szám egy egyszerű szorzással elforgatható `θ` szöggel az origó körül: `z * ℯ^(iθ)`.
Vedd észre, hogy az itteni `x` és `y` csupán a szokásos koordináták a valós kétdimenziós derékszögű síkon, és egy pozitív szög *óramutató járásával ellentétes* forgatást eredményez, míg egy negatív szög *óramutató járásával megegyezőt*.

Hasonlóképpen egyszerűen egy `Δr` radiális eltolás úgy hozható létre, hogy hozzáadjuk egy poláris alakú komplex szám `r` nagyságához (pl. `z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`).
Vedd észre, hogy a szög rész változatlan marad, és csak az `r` nagyság változik, ahogy az várható.
