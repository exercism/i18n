# Bevezetés

## Konstansok

A Gleam konstansai segítségével nevet adhatunk értékeknek. A `const` kulcsszóval definiáljuk őket.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Ha a `pub` kulcsszóval definiáljuk őket, a modulkonstansok más modulokból is elérhetők, egyébként csak abból a modulból érhetők el, amelyben definiáltuk őket.

## Sorrend

A Gleam standard könyvtárának `gleam/order` modulja tartalmazza az `Order` típust, amelyet értékek összehasonlítására használunk.

Az `Order` definíciója így néz ki:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

A típusnak három változata van, amelyek egy érték és egy másik érték viszonyát írják le:

- `Gt` - az érték _nagyobb, mint_ a másik érték.
- `Eq` - az érték _egyenlő_ a másik értékkel.
- `Lt` - az érték _kisebb, mint_ a másik érték.

Ha egy adattípus összehasonlítható nagyság szerint, a modulok gyakran definiálnak egy `compare` függvényt, amely `Order` értéket ad vissza. Például a `gleam/float` és a `gleam/int` is definiál `compare` függvényt, amelyek rendre a lebegőpontos számokon, illetve az egész számokon működnek.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

A rendező függvények, például a `list.sort`, gyakran olyan függvényt várnak, amely `Order` értéket ad vissza, így a hívó határozhatja meg, hogyan rendeződjön a lista.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
