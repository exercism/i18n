# Bevezetés

A vektor egydimenziós tömb.
Különböző típusú elemeket tartalmazhat.

## Vektorok létrehozása

Vektorokat a `vector` függvénnyel vagy annak olvasói alakjával, a `#()`-tal is létrehozhatsz:

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

Mivel tömbök, a `make-array` függvénnyel is létrehozhatók:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## Vektor predikátum

Ha ellenőrizni szeretnéd, hogy egy objektum vektor-e, egyszerűen használd a `vectorp` predikátumot.

## Elemek elérése

Egy vektor elemeit az `aref` függvénnyel érheted el; az indexelés nullától indul:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
