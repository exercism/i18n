# Bevezetés

A *generikus szó* olyan műveletet deklarál, amelynek az argumentuma osztályától függően több különböző megvalósítása lehet. A metódusokat az `M:` kulcsszóval adjuk hozzá.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

A `GENERIC:` deklarálja a szót és a veremhatását. Az `M:` egy adott osztályon definiál metódust; a Factor futásidőben a legfelső argumentum osztálya alapján választja ki a megfelelő metódust.

Megkérdezheted a generikus szótól, hogy mely osztályokhoz van metódusa, és utólag is hozzáadhatsz vagy eltávolíthatsz metódusokat. Nincs külön öröklődési szintaxis: minden tuple osztály automatikusan alkalmas arra, hogy metódusokat definiáljunk rajta.
