# Bevezetés

A PHP-ban egy változót úgy hívhatsz meg függvényként, hogy zárójelet [`()`] teszel utána. Amikor a PHP megpróbálja meghívni a függvényt, olyan függvényt keres, amelynek a neve megegyezik a változó értékével.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
