- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [Forráskód](#source)

## macOS

A macOS alapértelmezés szerint tartalmazza a Vimet, de az egy reménytelenül elavult változat.

Valószínűleg vagy a [MacPorts](https://www.macports.org), vagy a [Homebrew](https://brew.sh) segítségével telepítesz szoftvereket.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

Ha grafikus felületet szeretnél, vess egy pillantást a [MacVim](https://macvim-dev.github.io/macvim)re.

## Ubuntu / Debian

Telepíts egy teljes értékű Vimet grafikus támogatással (`gvim`):

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

A [Chocolatey](https://chocolatey.org) használatával:

```
C:\> choco install vim
```

Vagy töltsd le és telepítsd közvetlenül [innen](http://www.vim.org/download.php#pc).

## Forráskód

Ha magad szeretnéd lefordítani a legújabb Vimet, nézd meg a [hivatalos tárolót a GitHubon](https://github.com/vim/vim).
