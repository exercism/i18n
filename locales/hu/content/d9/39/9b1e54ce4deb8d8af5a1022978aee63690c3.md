# Névjegy

## Include-ok

Ahhoz, hogy más fájlok tartalmát beilleszd, a C++ az `include` direktívát használja.
Ezeket az include-okat a fájl elején kell megadni.
Fordításkor a direktívát tartalmazó sor helyére a megfelelő fájl tartalma kerül.
Az include-ok után a névterek ugyanolyanok maradnak, mint az eredeti fájlban.

## A szabványos könyvtár

A szabványos könyvtár sok gyakori függvényt, algoritmust és adatszerkezetet kínál.
A szabványos könyvtár a `std` névteret használja.

Egy példa erre a C numerikus könyvtára, a `cmath`.
Ez számos gyakori matematikai műveletet kínál.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
A szabványos könyvtárakat csúcsos zárójellel `<>` illesztjük be a kettős idézőjel `"` helyett.
A különbség az, hogy a fordító hol keresi a megfelelő fájlokat.
A csúcsos zárójeles változatnál az aktuális projektben való keresés kimarad, és a fordító egyenesen a rendszer include-könyvtáraiban kezd.
Ha helyi fájlokat szeretnél beilleszteni, kettős idézőjelet használnál: `#include "myfile"`
~~~~
