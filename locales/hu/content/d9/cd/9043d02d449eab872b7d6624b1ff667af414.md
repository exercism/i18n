# Bevezetés a generikus típusokba

A **generikus típus** egy olyan generikus osztály vagy interfész, amely típusokkal van paraméterezve.
Ez lehetővé teszi, hogy a fordító kikényszerítse a típusbiztonságot az osztályon vagy interfészen.

Vegyük ezt a nem generikus `Container` interfészt:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Mivel Object típusokat fogad és ad vissza, bármilyen nem primitív típussal működik.
Ez azonban áldozattal jár, mert előfordulhat, hogy az egyik kódrészlet `Integer` értékekre számítva hívja meg a `get` metódust, miközben egy másik kódrészlet `String` értékeket adva hívja a `set` metódust, ami futásidejű kivételt eredményez.

A **generikus osztály** és a **generikus interfész** formátuma a következő:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

Az osztály vagy interfész nevét követő, csúcsos zárójelekkel (`<>`) határolt típusparaméter-szakasz adja meg a típusparamétereket (más néven típusváltozókat): `T1`, `T2`, ..., `Tn`.
Ezeket az osztály vagy interfész törzsén belül használhatod ahhoz, hogy megkapd a generikus típusbiztonságot.

Íme a `Container` generikus változata:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

Amikor létrehozod, most már meg kell adnod, milyen típust tárol, és a fordító kikényszeríti ezt a megszorítást:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```
