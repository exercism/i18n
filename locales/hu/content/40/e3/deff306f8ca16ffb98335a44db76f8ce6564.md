# Bevezetés

A Factorban az adatok többsége *szekvenciákban* él. Az arrayek (`{ … }`), a vektorok (`V{ … }`) és a stringek ugyanazt a [protokollt][sequence-protocol] használják, amelyet a [`sequences`][sequences] szótár biztosít.

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

Az aggregációk (`sum`, `count`, `any?`, `all?`) és az olyan predikátumok, mint az `empty?` és a `member?`, minden szekvenciatípuson egységesen működnek. Új szekvenciák létrehozása mutáció nélkül: `prefix`, `suffix`, `append`, `unclip`, `unclip-last`.

A `>array`, a `>vector` és a `>string` (az [`arrays`][arrays] szótárban és a megfelelő szótárakban) a szekvenciatípusok közötti átalakításra szolgálnak, amikor egy általános művelet eredményeként egy adott konkrét típusra van szükséged.

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
