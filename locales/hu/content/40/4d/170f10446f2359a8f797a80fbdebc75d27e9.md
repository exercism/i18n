# Telepítés

## Melyik verziót válaszd?

Azt javasoljuk, hogy olyan stabil PHP-kiadást használj, amely aktív támogatással rendelkezik.
Jelenleg ezek a **PHP 8.2, 8.3 és 8.4**.
A jelenlegi kiadásokról és azok ütemtervéről a [hivatalos PHP-dokumentációban](https://www.php.net/supported-versions.php) találsz részleteket.

## PHP telepítése

A Linux és a macOS legtöbb csomagkezelője előre elkészített csomagokat kínál.
A PHP letölthető és forrásból lefordítható, erről a [php.net/downloads.php](https://php.net/downloads.php) és a [windows.php.net/download](https://windows.php.net/download) oldalon találsz információt.

~~~~exercism/note
A feladatok megoldásához nincs szükség olyan webszerverre, mint az nginx vagy az Apache HTTP server.
~~~~

### Linux

A különböző disztribúciók eltérő módszereket használnak.
A csomagkezelődtől függően a következő parancsok egyikével telepítheted:

```shell
yum install php
```

vagy

```shell
apt-get install php
```

További útmutatásért olvasd el a PHP kézikönyvének [Telepítés Unix rendszerekre](https://www.php.net/manual/en/install.unix.php) szakaszát.

### macOS

Bár a macOS gyakran tartalmazza a PHP-t, az rendszerint elavult.
A PHP telepítéséhez a [Homebrew](https://brew.sh/) használatát javasoljuk.
A Homebrew-t a [honlapjukon](https://brew.sh/#install) található utasításokat követve telepítheted.

A telepítés ellenőrzéséhez próbáld ki a következő parancsot, amely e sorok írásakor a Homebrew `4.5.x` verzióját írja ki.

```shell
brew --version 
```

Telepítsd a PHP-t a Homebrew segítségével

```shell
brew install php@8.4
```

Ennek a most telepített PHP verzióját kell kiírnia, legalább a `8.2.0`-t.

```shell
php -v
```

További útmutatásért olvasd el a kézikönyv [Telepítés macOS-re](https://www.php.net/manual/en/install.macosx.php) szakaszát.

### Windows

A Windows hivatalos PHP binárisai a [windows.php.net/download](https://windows.php.net/download) oldalról tölthetők le.

Vannak előre összeállított csomagok, többek között a [WAMP](https://www.wampserver.com/en/) (Windows, Apache, MySQL, PHP) és a [XAMPP](https://www.apachefriends.org/de/index.html).

További útmutatásért olvasd el a kézikönyv [Telepítés Windows rendszerekre](https://www.php.net/manual/en/install.windows.php) szakaszát.

### Docker

Ha a konténeralapú megoldásokat kedveled, letöltheted a [hivatalos PHP image-et a Docker Hubról](https://hub.docker.com/_/php).
A [Dockerre](https://docs.docker.com/engine/install/) is szükséged lesz.

### Egyéb

Ha más operációs rendszert szeretnél használni, nézd meg a [php.net/manual/en/install](https://www.php.net/manual/en/install.php) oldalon található útmutatót.

## PHPUnit telepítése

~~~~

### PHP-archívum (PHAR) használatával

Az Exercism feladataihoz a PHPUnit legegyszerűbb használati módja egy PHP-archívumként (PHAR) csomagolt terjesztés letöltése, ami egyben a PHPUnit ajánlott használati módja is.
A PHAR-t ugyanoda tárold, ahová az `exercism` CLI-t is tetted, hogy a PHPUnitot bárhonnan futtathasd.

A PHPUnit csomagok egy kiadását PHP-archívumként töltheted le:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

Ezután tedd futtathatóvá a letöltött fájlt:

```shell
chmod +x phpunit.phar
```

Majd helyezd át ugyanoda, ahová az `exercism` CLI-t is, és nevezd el a parancsot `phpunit`-nak:

```shell
mv phpunit.phar ~/bin/phpunit
```

Mostantól bárhonnan futtathatod a `phpunit`-ot, ahogyan az a [PHP-kurzus tesztelési dokumentációjában](https://exercism.org/docs/tracks/php/tests) is látható:

```shell
phpunit --version
```

A kimenetnek így kell kinéznie:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

Követheted a hivatalos [PHPUnit telepítési útmutatót](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) is a PHPUnit telepítéséhez.

### Composer használatával

A PHPUnit 11-es verziója a [Composerrel](https://getcomposer.org) is telepíthető.

#### A Composer telepítése

Telepítsd a [Composer](https://getcomposer.org) alkalmazást az eszközöd operációs rendszerének megfelelő [telepítési útmutató](https://getcomposer.org/doc/00-intro.md) szerint. Az egyszerű használat érdekében globálisan telepíteni javasoljuk.

#### A PHPUnit hozzáadása globális eszközként

A következő paranccsal:

```shell
composer global require phpunit/phpunit ^11.5
```

Ügyelj rá, hogy a 11.5-ös vagy újabb verziót telepítsd.
