# Névjegy

Azok a típusok, amelyek megvalósítják az [`IEnumerable<T>`][IEnumerable] interfészt, _felsorolhatók_. Minden beépített gyűjteménytípus megvalósítja ezt az interfészt.

Egy felsorolható típuson `foreach` ciklussal is végigmehetsz:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Ahhoz, hogy egy típus megvalósítsa az `IEnumerable<T>` interfészt, egyetlen metódust kell megvalósítania: `IEnumerator<T> GetEnumerator()`.
Amint látható, a felsorolható típus magát a gyűjteményen való iterálást egy `IEnumerator<T>` típusra bízza.
Ezen az interfészen egy tulajdonságot és három metódust kell megvalósítani:

- `public T Current { get; }`: az aktuális elem lekérése.
- `public bool MoveNext ();`: lépés a következő elemre; `true`-t ad vissza, ha a lépés a következő elemre sikeres volt, és `false`-t, ha nem (nincs több elem).
- `public void Reset ();`: a felsoroló visszaállítása a kezdeti állapotába (az első elem előttire).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
