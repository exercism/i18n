# Tesztek

Mielőtt megpróbálnád futtatni a teszteket, győződj meg róla, hogy a feladatmappa megfelelően be van állítva: kövesd a telepítési lépéseket, vagyis a `corepack yarn install` parancsot és az Editor SDK beállítását.

A teszteket így futtathatod:

```bash
$ corepack yarn test
```

## Kihagyott tesztek

A tesztegyüttesekben az első kivételével minden teszt ki van hagyva.

Amint egy teszt sikeresen lefut, a következőt úgy kapcsolhatod be, hogy a `xit`-et `it`-re változtatod.
A teszteket ezenkívül `xdescribe`-dal is csoportosíthatod.
A csoportot úgy kapcsolhatod be, hogy ezt `describe`-ra változtatod.
Végül néhány feladatban opcionális tesztek is lehetnek, ezeket `it.skip` jelöli.
Az opcionális teszt futtatásához töröld a `.skip`-ot.
