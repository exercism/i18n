# Bevezetés

Mivel a Clojure összes szabványos adattípusa megváltoztathatatlan, *referenciatípusokat* kínál, amelyek szabályozott módosítást tesznek lehetővé. Ezek közül a legegyszerűbbeket és a leggyakrabban használtakat atomoknak nevezzük.

Az atomokat az `atom` függvénnyel hozzuk létre, amely egy kezdőértéket vár:

```clojure
(def players (atom ()))
```

Az atom aktuális értékét a `deref` függvénnyel vagy a `@` rövidítéssel olvashatjuk ki:

```clojure
@players
;;=> ()
```

A `players` atom aktuális értékét a `swap!` függvénnyel módosíthatjuk, amely egy függvény alkalmazásával frissíti az értéket:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

A `reset!` függvény lecseréli az atom értékét, függetlenül annak aktuális értékétől:

```clojure
(reset! players ())
```
