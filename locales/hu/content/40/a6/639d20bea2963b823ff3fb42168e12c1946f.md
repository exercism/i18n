# Kiegészítés az utasításokhoz

## Hogyan épül fel ez a feladat a Python-kurzuson

A feladat tesztjei elvárják, hogy létrehozz egy `Matrix` [`class`][classes]-t (_lásd még [concept:python/classes]()_).
Ez nem ugyanaz, mint egy harmadik féltől származó könyvtár, például a [Numpy][numpy-matrix] Matrix-objektumának _használata_; ezt nem támogatjuk.
 _Ne aggódj, nem olyan bonyolult, mint gondolnád!_
 Ha több kiindulópontot és részletet szeretnél a `classes`-ról és az adatszerkezetekről, nézd meg az alábbi forrásokat:


-   [**A First Look at Classes**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) a Python 3 dokumentációjából. 
-   [**How to Define a Class in Python**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) a Real Python weboldaláról.  
-   [**Data Structures in Python**](https://docs.python.org/3/tutorial/datastructures.html) a Python 3 dokumentációjából.

[numpy-matrix]: https://numpy.org/doc/stable/reference/generated/numpy.matrix.html
