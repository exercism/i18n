# Utasítások kiegészítése

## Tippek

Egy `convert` függvényt kell megvalósítanod, amely a számot esőcsepp-hanggá alakítva adja vissza. Nyugodtan használhatod a megadott szignatúrát, ha bizonytalan vagy a típusokban, de ne hagyd, hogy az korlátozza a kreativitásodat:

```haskell
convert :: Int -> String
```

Ez a feladat szöveges adatokkal dolgozik. Történelmi okokból a Haskell `String` típusa a `[Char]`, azaz a karakterek listájának a szinonimája. A szöveges adatok hatékonyabb kezeléséhez a `Text` típus használható.

A feladat opcionális kiterjesztéseként a következőket teheted:

- Olvass a Haskell [stringtípusairól](https://haskell-lang.org/tutorial/string-types).
- Vedd fel a `- text`-et a package.yaml függőségeinek listájára.
- Importáld a `Data.Text` modult [a következő módon](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- Most már írhatsz például ilyet: `convert :: Int -> Text`, és hivatkozhatsz a `Data.Text` kombinátoraira például így: `T.pack`.
- Nézd meg a [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) dokumentációját,
- Ezután a Raindrops.hs fájlban lecserélheted a `String` összes előfordulását `Text`-re:

```haskell
convert :: Int -> Text
```

Ez a rész teljesen opcionális.
