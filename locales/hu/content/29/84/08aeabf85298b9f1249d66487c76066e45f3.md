# Utasítások

Ebben a feladatban különböző típusú távirányítós autók közötti versenyeket fogsz szervezni. Minden autónak megvannak a saját sebesség- és akkumulátorfogyasztási jellemzői.

Az autók teljesen feltöltött (100%-os) akkumulátorral indulnak. Valahányszor elvezeted az autót a távirányítóval, annyi métert tesz meg, amennyi az autó sebessége, és a hátralévő akkumulátorszázalékot az akkumulátorfogyasztásával csökkenti.

Ha egy autó akkumulátora az akkumulátorfogyasztása százaléka alá csökken, többé nem tudod vezetni az autót.

Minden versenypályának megvan a maga hossza. Az autókat úgy tesztelik, hogy képesek-e úgy teljesíteni a pályát, hogy közben nem merül le az akkumulátoruk.

Hat részfeladat vár rád, amelyek mindegyike távirányítós autók példányaival dolgozik.

## 1. Távirányítós autó létrehozása

Tedd lehetővé egy távirányítós autó létrehozását úgy, hogy definiálsz egy konstruktort a `NeedForSpeed` osztályhoz, amely két paraméterként átveszi az autó méterben mért sebességét és az akkumulátorfogyasztás százalékát (mindkettő `int` típusú):

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
```

## 2. Versenypálya létrehozása

Tedd lehetővé egy versenypálya létrehozását úgy, hogy definiálsz egy konstruktort a `RaceTrack` osztályhoz, amely egyetlen paraméterként átveszi a pálya méterben mért hosszát (`int` típusú):

```java
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Vezesd az autót

Valósítsd meg a `NeedForSpeed.drive()` metódust, amely az autó sebessége alapján frissíti a megtett méterek számát. Valósítsd meg a `NeedForSpeed.distanceDriven()` metódust is, amely visszaadja az autó által megtett méterek számát:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.distanceDriven();
// => 5
```

## 4. A lemerült akkumulátor ellenőrzése

Frissítsd a `NeedForSpeed.drive()` metódust, hogy az autó akkumulátorfogyasztása alapján merítse az akkumulátort. Valósítsd meg a `NeedForSpeed.batteryDrained()` metódust is, amely jelzi, hogy az akkumulátor már túlságosan lemerült-e a vezetéshez:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.batteryDrained();
// => false
```

## 5. A Nitro távirányítós autó létrehozása

A legkelendőbb távirányítós autó a Nitro, amelynek lenyűgöző, 50 méteres végsebessége van 4%-os akkumulátorfogyasztás mellett. Valósítsd meg a (statikus) `NeedForSpeed.nitro()` metódust, amely ezt a típusú autót adja vissza:

```java
var car = NeedForSpeed.nitro();
car.drive();
car.distanceDriven();
// => 50
```

## 6. Annak ellenőrzése, hogy egy távirányítós autó célba tud-e érni egy versenyen

Ahhoz, hogy egy autó célba érjen egy versenyen, képesnek kell lennie megtenni a verseny távját. Ez azt jelenti, hogy nem merül le az akkumulátora, mielőtt átlépi a célvonalat. Valósítsd meg a `RaceTrack.canFinishRace()` metódust, amely paraméterként egy `NeedForSpeed` példányt vesz át, és `true`-t ad vissza, ha az autó célba tud érni a versenyen; ellenkező esetben `false`-t ad vissza:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);

int distance1 = 100;
var race1 = new RaceTrack(distance1);

int distance2 = 300;
var race2 = new RaceTrack(distance2);

race1.canFinishRace(car);
// => true

race2.canFinishRace(car);
// => false
```
