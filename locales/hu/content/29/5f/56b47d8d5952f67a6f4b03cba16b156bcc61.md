# Névjegy

Az F# stringjei módosíthatatlan objektumok, amelyek szöveget Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként ábrázolnak. Egy `string` példány definiálásához kettős idézőjelet használunk:

```fsharp
let fruit = "Apple"
```

Egy stringet úgy módosíthatunk, hogy meghívjuk valamelyik [metódusát][methods] vagy [tulajdonságát][properties], esetleg a [`String` modul][string-module] valamelyik függvényét használjuk. Mivel a string értékek a definiálásuk után soha nem változnak meg, minden stringmanipulációs metódus és függvény új stringet ad vissza.

A stringet kettős idézőjel (`"`) karakterek határolják. Néhány speciális karaktert [escape-elni][escaping] kell a visszaperjel (`\`) karakterrel. A stringek elé egy `@` (at) szimbólumot is tehetünk, amitől [verbatim string][verbatim] lesz belőlük, amely figyelmen kívül hagyja az escape-elt karaktereket.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

Vagy definiálhatók a stringek [hármas idézőjelekkel][triple-quoted] is (`"""`), amivel anélkül tehetünk kettős idézőjelet a stringbe, hogy escape-elnénk.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

Végül a stringek összefűzése a [`+` operátorral][plus-operator] lehetséges:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
