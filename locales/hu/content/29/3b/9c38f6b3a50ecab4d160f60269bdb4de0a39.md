# A for-each ciklusokról

A [for-each ciklus](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) lehetőséget ad arra, hogy egy gyűjtemény minden elemén lefuttass egy kódblokkot.
Egyes dokumentációk (például az Oracle dokumentációja) „enhanced for” ciklusként hivatkoznak rá.

Íme az általános szintaxis:

```java
for(declaration: collection) {
    body;
}
```

A `declaration` deklarálja azt a változót, amely a gyűjteményből hozzárendelt értékeket tárolja.

A `collection` egy tömb vagy gyűjtemény, amely azokat az értékeket tartalmazza, amelyeket a ciklusváltozónak rendelünk hozzá.

A `body` azokat az utasításokat tartalmazza, amelyek a gyűjtemény minden egyes értékére egyszer futnak le.

Például:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

aminek a kimenete:

```text
a
e
i
o
u
```

A `for-each` ciklus általában előnyösebb a `for` ciklusnál, a következő okok miatt:

- A `for-each` ciklus garantáltan _az összes_ értéket bejárja.
- A `for-each` ciklus _deklaratívabb_, ami azt jelenti, hogy a kód azt fejezi ki, _mit_ csinál, és nem azt, _hogyan_ csinálja.
- A `for-each` ciklust nem lehet elrontani, míg a `for` ciklusoknál könnyen becsúszik egy off-by-one hiba (gondolj a `<` és a `<=` használatára).
- A `for-each` ciklus minden gyűjteménytípuson működik, még azokon is, amelyek nem támogatják az elemek indexszel való elérését (például egy `Set`).
