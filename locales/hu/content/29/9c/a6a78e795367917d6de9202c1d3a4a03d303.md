# Bevezetés

## Magyarázat

A `number` és `string` primitív adattípusok mellett van még egy fontos adattípus a JavaScriptben: az `object`.
Az objektumok kulcs-érték párokból álló gyűjtemények.
Ezért ugyanúgy használhatók, mint amit más nyelvekben gyakran mapnek vagy szótárnak neveznek.

Más nyelvekben egy mapban gyakran minden értéknek ugyanolyan adattípusúnak kell lennie.
A JavaScriptben csak a kulcs típusa kötött: `string` kell hogy legyen.
Egy objektumon belül az értékek különböző típusúak lehetnek.
Lehetnek primitív típusok, például számok, de lehetnek tömbök, más objektumok vagy akár függvények is.
Ez nagyon sokoldalúvá teszi az objektumokat, ezért kulcsfontosságú szereplői a JavaScript [objektumorientált programozásának][oop] (OOP) is.

A következőkben az objektumokra mint gyűjteményekre vagy mapokra összpontosítunk.
Az objektumok további felhasználási eseteiről más fogalmakban lesz szó, lásd például az [Osztályok][concept-classes] fogalmat.

## Objektum létrehozása

Egy objektumot kapcsos zárójellel hozol létre.
Közvetlenül is megadhatsz néhány bejegyzést.
Ehhez először a kulcsot add meg, majd egy kettőspontot, végül az értéket.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

Az utolsó bejegyzés utáni vessző elhagyható a JavaScriptben.

Felmerülhet benned, hogy miért nincsenek a kulcsok idézőjelbe téve, pedig elvileg stringek.
Ez egy rövidített jelölés.
Ha a kulcs megfelel egy JavaScript [azonosító][mdn-identifier] elnevezési szabályainak, elhagyhatod az idézőjeleket.
Ha a kulcs neve speciális karaktereket tartalmaz, a szokásos string jelölést kell használnod.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Érték lekérése

Egy adott kulcs értékét kétféleképpen kérheted le: pontjelöléssel és szögletes zárójeles jelöléssel.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

A pontjelölés rövidítésként ugyanolyan megkötéssel jár, mint az idézőjelek elhagyása.
Csak akkor működik, ha a kulcs követi az azonosítók elnevezési szabályait.

## Érték hozzáadása vagy módosítása

Egy értéket az `=` értékadó operátorral adhatsz hozzá vagy módosíthatsz.
Itt is a pont- és a szögletes zárójeles jelölés áll rendelkezésre.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Bejegyzés törlése

Egy kulcs-érték párt a `delete` kulcsszóval törölhetsz egy objektumból.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Kulcs létezésének ellenőrzése

A `hasOwnProperty` metódussal ellenőrizheted, hogy létezik-e egy adott kulcs egy objektumban.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Végighaladás egy objektumon

Van egy speciális `for...in` ciklus, amellyel egy objektum összes kulcsán végighaladhatsz.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

A nehezen észrevehető hibák elkerülése érdekében mindig feltételezd, hogy a `for...in` ciklus tetszőleges sorrendben járja be a kulcsokat.
Arra is figyelj, hogy a `for...in` az [örökölt kulcsokat][concept-inheritance] is bevonja az iterációba.
