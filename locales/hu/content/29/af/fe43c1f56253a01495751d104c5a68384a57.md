# Iteráció

A programozásban az [iteráció][iteration] egy kódrészlet többszöri megismétlését jelenti.
Ezt megteheted például `while`- és `until`-ciklusokkal.
Rekurzióval is megoldható, ami egy önmagát meghívó függvény.

Leggyakrabban azonban egy elemgyűjteményen szeretnél iterálni, például egy `Array`, `Range` vagy `String` objektumon.
A Crystalben az `Array` és a `Range` osztály is tartalmazza az [`Enumerable`][enumerable] modult, ami számos metódust kínál az elemeken való iteráláshoz.
A `String` osztálynak eközben saját metóduskészlete van a karaktereken való iteráláshoz.

A Crystalben ráadásul nincs `for` utasítás, mint sok más nyelvben.
Helyette több metódus is használható az iteráláshoz.

## Iterálás

A leggyakoribb módja a gyűjteményen való iterálásnak a [`each`][each] metódus használata, ami a gyűjtemény minden elemét átadja egy blokknak.
Ez egy `Range` segítségével könnyedén megtehető.
Tegyük fel, hogy 1 és 3 között szeretnél ciklust futtatni; ekkor az `each` metódussal iterálhatsz a tartományon.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Még egyszerűbb, ha csak adott számú alkalommal szeretnél iterálni: használhatod a [`times`][times] metódust, ami az `Int` osztályon érhető el.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Iterálás `String`-en

A `String` karakterek sorozata, és nem tartozik az `Enumerable` modulhoz, ami azt jelenti, hogy saját metóduskészlete van a karaktereken való iteráláshoz.
A leggyakoribb módja a `String`-en való iterálásnak a [`each_char`][each_char] metódus használata, ami a `String` minden karakterét átadja egy blokknak.

~~~~exercism/note
Az `each_char` metódus egy `Char` objektumot ad át a blokknak, nem pedig egy `String` objektumot.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

A `String`-en való iterálás másik módja a [`each_line`][each_line] metódus használata.
Ezt a metódust főleg akkor használod, amikor egy fájlt soronként olvasol be.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Iterálás olyan objektumon, amely tartalmazza az `Enumerable` modult

Az [`Enumerable`][enumerable] modul számos metódust kínál egy gyűjtemény elemein való iteráláshoz.
Gyűjtemények, amelyek tartalmazzák az `Enumerable` modult: `Array`, `Range`, `Hash`, `Set` és mások; az utóbbiakkal későbbi fogalmakban fogsz találkozni.

A leggyakoribb módja az `Array`-en való iterálásnak a [`each`][each] metódus használata, ami az `Array` minden elemét átadja egy blokknak.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

A [`map`][map] metódus egy másik módja az `Array`-en való iterálásnak: egy új `Array`-t ad vissza, amely a blokk minden elemre való alkalmazásának eredményeit tartalmazza.
Hasonlít az `each` metódushoz, de egy új `Array`-t ad vissza az átalakított elemekkel.
Az átalakítás nagyon hasznos, ha egy függvényt szeretnél alkalmazni a gyűjtemény minden elemére, ami gyakori művelet.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Egy `if`-hez hasonló vezérlési szerkezettel azt is megválaszthatod, hogy mely elemeket alakítsd át.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### Indexszel

Néha tudnod kell, hogy éppen melyik elemen iterálsz; erre az [`each_with_index`][each_with_index] vagy a [`map_with_index`][map_with_index] metódust használhatod.
Minden elemet és annak indexét átadja egy blokknak, és a metódus elfogad egy opcionális argumentumot is a kezdőindex megadásához.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Ne feledd, hogy az [`each_char_with_index`][each_char_with_index] metódus is elérhető `String` objektumokhoz.

### sum

A [`sum`][sum] metódus a gyűjtemény összes elemének összegét adja vissza, és elfogad egy opcionális blokkot is, amellyel az elemeket az összegzés előtt átalakíthatod.
Egy opcionális argumentumot is elfogad az összeg kezdőértékének megadásához.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

A [`reduce`][reduce], amit más nyelvekben fold néven is ismernek, egy olyan metódus, amely egy összekapcsoló művelettel és egy kezdőértékkel az összes elemet összevonja a gyűjteményben.
A `reduce` metódusnál van egy akkumulátor, amit átad a blokknak; az akkumulátor az előző iteráció eredménye.
Ez egy rekurzív folyamattá válik, amely összevonja a gyűjtemény összes elemét.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

A `reduce` hasonlíthat a `sum`-hoz, de rugalmasabb, mert megadhatod az akkumulátor kezdőértékét és az összekapcsoló műveletet.
A `reduce` segítségével megvalósíthatod a `sum`, `count` és más metódusokat.
