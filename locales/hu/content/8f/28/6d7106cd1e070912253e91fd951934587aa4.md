# Bevezetés

A `try..rescue` használata hatékony szerkezet a hibák elkapására, amikor azok előfordulnak. A hibák elkapása lehetővé teszi, hogy a függvények meghatározott értékeket adjanak vissza, amikor szükséges. A `try..rescue` szerkezet két további lehetőséget is kínál, amelyeket kihasználhatunk:

- az `else` blokk
  - Ha a try blokk sikeresen lefut, az eredmény erre a blokkra illeszkedik.
- az `after` blokk
  - Akár sikeresen lefut a try blokk, akár hibát dob, az `after` blokkban lévő kód mindig végrehajtódik, amennyiben a program eljut addig a pontig.
  - Az `after` blokk eredménye nem kerül vissza a hívó scope-ba.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
