# Bevezetés

A Python egy [dinamikusan és erősen][dynamic typing in python] típusos programozási nyelv.
Egyszerre használ [duck typingot][duck typing] és [fokozatos típusozást][gradual typing] a [típusjelzések][type hints] révén.

Bár a Python sokféle programozási _stílust_ támogat, a Pythonban belül **minden egy [objektum][everythings an object]**.
Ez magában foglalja a számokat, a stringeket, a listákat, sőt még a függvényeket is.

Hogy mindez mit jelent, arra a kurzus előrehaladtával térünk majd vissza.

Ez az első feladat a Python nyelv négy fontos jellemzőjét mutatja be:
1.  Névhozzárendelés (_változók és konstansok_),
2.  Függvények (_a `def` és a `return` kulcsszó_),
3.  Megjegyzések, és
4.  Docstringek.

## Névhozzárendelés (változók és konstansok)

A programozók a hozzárendelés `=` operátorával bármilyen típusú objektumhoz hozzáköthetnek [_neveket_][facts-and-myths-about-python-names] (más néven _változókat_): `<name> = <value>`.
Egy név az élettartama során újra hozzárendelhető (vagy újraköthető) más értékekhez (más objektumtípusokhoz).


```python
>>> my_first_variable = 1  #<-- my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  #<-- my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." #<-- You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' #<-- Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### Konstansok

A konstansok olyan nevek, amelyeket egy programban csak egyszer szánunk hozzárendelni.
Általában [modul][module] (fájl) szinten érdemes definiálni őket, és jellemzően a program összes függvénye és osztálya számára láthatóak.
A `SCREAMING_SNAKE_CASE` használata azt jelzi, hogy a nevet nem szabad újra hozzárendelni, és az értékét nem szabad módosítani.


## Függvények

A `def` kulcsszó vezeti be a [függvénydefiníciót][function definition].
Minden függvénynek lehet nulla vagy több formális [paramétere][parameters] a `()` zárójelek között, amelyet egy `:` kettőspont követ.
A függvény _törzsének_ utasításai a `def` utáni sorban kezdődnek, és _blokkon belül behúzva_ kell állniuk.


```python
# The body of a function is indented by 2 spaces, & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     #this was only indented by 3 spaces
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


A függvények a [`return`][return] kulcsszóval _explicit módon_ adnak vissza egy értéket vagy objektumot:


```python
# Function definition on first line, explicit return used on final line.
>>> def add_two_numbers(number_one, number_two):
        return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing it 
# will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


Azok a függvények, amelyekben a `return` után nem áll _explicit_ kifejezés, _implicit módon_ a [`None`][none] objektumot adják vissza.
A `None` részleteire egy későbbi feladatban térünk ki.
E feladat és a magyarázat szempontjából a `None` egy helyőrző, amely a semmit, azaz a null értéket képviseli:


```python

# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

Azok a függvények is _implicit módon_ a [`None`][none] objektumot adják vissza, amelyekből hiányzik a `return`.
Ez azt jelenti, hogy ha nem használod a `return` kulcsszót egy függvényben, a Python helyetted a `None` objektumot adja vissza.

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


### Függvények hívása

A függvényeket úgy [_hívjuk_][calls] meg, hogy a nevük után `()` következik.
Az osztályon vagy modulon belül definiált függvények meghívásához pont (`.`) jelölést használunk.

```python
>>> def raise_to_power(number, power):
...     return number ** power
...

>>> raise_to_power(3,3) # <--Invoking the function with the arguments 3 and 3.
27


# A mismatch between the number of parameters and the number of arguments will raise an error.
>>> raise_to_power(4,)
...
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: raise_to_power() missing 1 required positional argument: 'power'


# Calling methods or functions in classes and modules.
>>> start_text = "my silly sentence for examples."
>>> str.upper(start_text)  # <--Calling the upper() method from the built-in str class on start_text.
'MY SILLY SENTENCE FOR EXAMPLES.'


# Importing the math module
>>> import math

>>> math.pow(2,4)  # <--Calling the pow() function from the math module.
16.0
```


## Megjegyzések

A [megjegyzések][comments] a Pythonban egy `#` jellel kezdődnek, amely nem része egy stringnek, és a sor végéig tartanak.
Sok más programozási nyelvtől eltérően a Python **nem támogatja** a többsoros megjegyzésjeleket.
Egy megjegyzésblokk minden sorának a `#` karakterrel kell kezdődnie.


## Docstringek

Egy függvénytörzs első utasítása opcionálisan lehet egy [_docstring_][docstring], amely tömören összefoglalja a függvény vagy objektum célját.
A docstringeket három dupla idézőjellel (""") deklaráljuk, a kódblokkal azonos szintre behúzva:


```python

# An example from PEP257 of a multi-line docstring
# reformatted to use Google style non-type hinted docstrings.
# Some additional details can be found in the Sphinx documentation:
# https://www.sphinx-doc.org/en/master/usage/extensions/napoleon.html#getting-started

def complex(real=0.0, imag=0.0):
    """Form a complex number.

    Keyword Arguments:
        real (float): The real part of the number (default 0.0)
        imag (float): The imaginary part of the number (default 0.0)
        
    """

    if imag == 0.0 and real == 0.0:
        return complex_zero

```


A docstringeket olyan automatikus dokumentációs eszközök olvassák, mint a [Sphinx][sphinx], és úgy kérhetők le, hogy meghívjuk a különleges `.__doc__` attribútumot a függvény, metódus vagy osztály nevén.
A docstringek általános konvencióit a [PEP257][pep257] írja le, de a pontos formátum projektenként és csapatonként változik.
Az Exercism tanulófeladatai igyekeznek követni a Google stílusát a típusjelzés nélküli kód esetében.

A docstringek [könnyűsúlyú egységtesztként][doctests] is működhetnek, amelyről egy későbbi feladatban lesz szó.


```python
# An example on a user-defined function using a Google style docstring. 
>>> def raise_to_power(number, power):
    """Raise a number to an arbitrary power.

    Parameters:
        number (int): The base number.
        power (int): The power to raise the base number to.
    
    Returns:
        int: The number raised to the specified power.
    
    Takes a number and raises it to the specified power, returning the result.

    """

    return number ** power
...

# Calling the .__doc__ attribute of the function and printing the result.
>>> print(raise_to_power.__doc__)
Raise a number to an arbitrary power.

Parameters:
    number (int): The base number.
    power (int): The power to raise the base number to.

Returns:
    int: The number raised to the specified power.

Takes a number and raises it to the specified power, returning the result.
```
