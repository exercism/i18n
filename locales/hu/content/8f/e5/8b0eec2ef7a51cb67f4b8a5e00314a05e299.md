# Új alkalmazottak felvétele adatbázisban

## A feladat

Az ABC Corp szeretné az alkalmazottainak teljesített aprópénztári kifizetésekkel kapcsolatos összes információt adatbázisban nyilvántartani. Te az ABC Corp pénzügyi osztályát segíted ennek megvalósításában. Mivel az ABC Corp bővíti tevékenységét, az új felvételek miatt gyakori igény, hogy új alkalmazottakat adjunk a rendszerhez.

A feladatod, hogy a megadott új alkalmazott adatait hozzáadd az adatbázis `Employee` táblájához, és visszaadd az automatikusan generált `employee_id` oszlop értékét anélkül, hogy újabb lekérdezést indítanál az adatbázis felé a megkereséséhez. Ha a végrehajtás során hiba történik, a visszatérési érték `-1` legyen.

## Az adatbázis részletei

Ehhez a feladathoz a megadott H2 adatbázist használd.

> A mintaadatbázis fájlja `gofigure.mv.db`, az adatbázis neve pedig `gofigure`. A `db` mappában találod.

A következő táblák már megtalálhatók a minta H2 adatbázisban némi mintaadattal együtt. Az oszlopnevek és az adattípusok alább láthatók.

**Tábla neve** : `Employee`

| **Oszlopok:**      | típus |
| -----------       | ----------- |
| `employee_id`     | egész szám, automatikusan növekvő elsődleges kulcs       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | egész szám        |

**Tábla neve**: `Payment`

| **Oszlopok:**      | típus |
| -----------       | ----------- |
| `payment_id`      | egész szám, automatikusan növekvő elsődleges kulcs       |
| `date`            | dátum        |
| `amount`          | tizedes tört        |
| `employee_id`     | egész szám        |
| `reason`          | string        |

* Az adatbázis fájlja `gofigure.mv.db`. A JDBC URL-t így használd: `jdbc:h2:file:/path/to/db/file`
* Felhasználónév: `root`
* Jelszó: `root`

## Megkötések

* A lekérdezések és a Ballerina minta ellenőrzéséhez a `db` mappában megadott H2 adatbázisfájlt használd
* A maven dependency params megközelítést használd ahhoz, hogy az H2 adatbázis-vezérlőt platformfüggőségként hozzáadd a Ballerina.toml fájlodhoz
* Ne indíts újabb lekérdezést az adatbázis felé az automatikusan generált id megkereséséhez


## Tesztkörnyezet

* A teszteket a `bal test` paranccsal futtathatod, és a rendszer a megadott mintaadatbázis ellen futtatja őket.

## Példák

### 1. példa

**Bemenet** : dbFilePath: `"./db/gofigure"`, name : `“John Doe”`, city: `“Omaha”`, department : `“Sales”`, age: `24`

**Kimenet** : `4`

### 2. példa

**Bemenet** : dbFilePath: `"./db/invalidDB"`, name : `“John"`, city: `"Colombo"`, department : `"HR"`, age: `25`

**Kimenet** : `-1`

## Tippek

* Az adatbázissal való munkához a [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) modult használd
* A JDBC-vezérlő függőségként való hozzáadásának lépéseit az [Előfeltétel](https://lib.ballerina.io/ballerinax/java.jdbc/latest) szakaszban találod
* Az adatok beszúrásához az [execute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-execute) remote metódust használd
* Nézd meg a [DML- és DDL-műveletek](https://ballerina.io/learn/by-example/mysql-execute-operation/) példákat
