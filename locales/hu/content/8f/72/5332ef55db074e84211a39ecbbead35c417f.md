## Utasítások

Az a feladatod, hogy tökéletes labirintusokat készíts Mickey és Minerva számára: olyanokat, amelyeknek csak egyetlen megoldásuk van, és nincsenek elszigetelt részeik. Íme, amit tudnod kell:

- A labirintus téglalap alakú, és a bejáratnál meg a kijáratnál is van egy-egy nyílás.
- A labirintusban szobák és folyosók vannak, amelyek derékszögben metszik egymást.
- A program két paramétert fogadjon el: a sorok és az oszlopok számát. A labirintus mérete 5 és 100 cella között legyen.
- Egy `x` oszlop széles és `y` sor magas labirintus `2x + 1` karakter széles és `2y + 1` karakter magas legyen.
- Ha nem adsz meg seedet, generálj véletlenszerű labirintust. Ha ugyanazt a seedet többször is megadod, minden alkalommal ugyanaz a labirintus jöjjön létre.
- A falak megrajzolásához [keretrajzoló][Box-drawing] karaktereket használj, a bal oldali bejárathoz és a jobb oldali kijárathoz pedig egy nyíl szimbólumot (⇨).

Itt az idő, hogy tökéletes labirintusokat készíts ezeknek a kalandvágyó egereknek!

### Példák

1. Az 5x5 cellás kis négyzet alakú labirintus (vagy 11x11 karakter)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. A 6x18 cellás téglalap alakú labirintus
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
