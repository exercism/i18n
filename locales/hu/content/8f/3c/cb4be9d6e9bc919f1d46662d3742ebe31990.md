# Utasítások

Valentin-nap van. A párodnak van néhány programötlete, és arra kér, hogy értékeld mindegyiket: `yes`, `no` vagy `maybe`.

A tevékenységeket kételemű tömbök (`{ tag value }`) képviselik, ahol a `tag` a következők egyike: `board-game`, `chill`, `movie`, `restaurant` vagy `walk`.

| tevékenység               | forma                       |
| ------------------------- | --------------------------- |
| Játssz egy társasjátékkal | `{ board-game f }`          |
| Lazulj                    | `{ chill f }`               |
| Nézz meg egy `genre` műfajú filmet | `{ movie genre }`   |
| Étkezz egy `cuisine` étteremben | `{ restaurant cuisine }` |
| Sétálj `km` kilométert    | `{ walk km }`               |

A műfaj a következők egyike: `crime`, `horror`, `romance`, `thriller`. A konyha `korean` vagy `turkish`.

## 1. Értékeld a konyhát

Definiáld úgy a `rate-restaurant` szót, hogy levegyen egy konyhát a veremből, és adja vissza az értékelésedet:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. Értékeld a film műfaját

Definiáld úgy a `rate-movie` szót, hogy egy műfajt vesz át, és visszaad:

- `romance` → `yes`
- bármi más → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. Értékeld a sétát

Definiáld úgy a `rate-walk` szót, hogy egy kilométerszámot vesz át, és visszaad:

- több mint `11` → `yes`
- több mint `6`, legfeljebb `11` → `maybe`
- egyébként → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. Értékeld a tevékenységet

Definiáld úgy a `rate-activity` szót, hogy levegyen a veremből egy `{ tag value }` tevékenységet, és visszaadja az értékelésedet. Használd újra a fenti segédszavakat:

- `board-game`, `chill` → mindig `no`
- `movie` → delegálj a `rate-movie`-ra
- `restaurant` → delegálj a `rate-restaurant`-ra
- `walk` → delegálj a `rate-walk`-ra

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. Számold össze az értékeléseket

Definiáld úgy az `approval-counts` szót, hogy egy tevékenységlistát vesz át, és visszaad egy 3 elemű tömböt (`{ yes-count maybe-count no-count }`), amely megmutatja, hogy hány tevékenység milyen értékelést kapott.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
