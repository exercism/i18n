# A scope-feloldó operátor

A scope-feloldó operátor (`::`) segítségével egy osztályra hivatkozhatunk, hogy elérjük annak névkonstansait, statikus tulajdonságait vagy statikus metódusait.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## A `self` és a `static` használata a scope-feloldó operátorral

Előfordulhat, hogy egy objektumnak a saját scope-jára kell hivatkoznia. Ezt teszi lehetővé a `self` kulcsszó: egy osztály így a saját scope-jára hivatkozhat. A `self` kulcsszó használatával az osztály függetlenedik a saját nevétől, ami hosszú távon megkönnyíti a kód karbantartását.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

A `static` kulcsszót a scope-feloldó operátorral használva „late bind” módon hivatkozhatsz az aktuális leszármazott osztályra.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## A `parent` használata a scope-feloldó operátorral

A `parent` kulcsszóval a szülőosztály konstansaira, tulajdonságaira vagy metódusaira hivatkozhatunk. Leggyakrabban arra használjuk, hogy egy objektum létrehozásakor meghívjuk a szülő konstruktorát:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Fenntartások

### A konstansok, tulajdonságok és metódusok láthatósága

A scope-feloldó operátor továbbra is követi a `public`, `private` és `protected` láthatósági módosítókban lefektetett szabályokat.
