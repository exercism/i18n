# Bevezetés

A kivételek a Rubyben, akárcsak sok más nyelvben, a váratlan események kezelésének egy módját adják. Ha meg akarod akadályozni, hogy a programod összeomoljon, fontos, hogy megfelelően kezeld a kivételeket.

Amikor kivétel keletkezik, akár explicit módon dobod, akár a Ruby-értelmező dobja, a program letér a normál működés útjáról, és végül egy hibaüzenettel kilép:

```ruby
raise ArgumentError.new("Something went wrong!")
=> Traceback (most recent call last):
.
.
ArgumentError (Something went wrong!)
```

```ruby
1/0
=> Traceback (most recent call last):
.
.
ZeroDivisionError (divided by 0)
```

Ha meg akarjuk állítani ezt a leállási folyamatot, reagálnunk kell a kivételre. Ezt nevezik a kivétel „elkapásának”:

```ruby
begin
  # ...any code that raises an exception
rescue
  puts 'Got an exception'
end
```

Ez a program nem omlik össze, és kiírja, hogy „Got an exception”. Kilépés helyett a Ruby lefuttatja a `rescue` blokkban lévő kódot, ami kiír egy üzenetet.

Ahogy a Rubyben minden, a kivételek is objektumok, és általában adatokat tárolnak a kivételről. Így juthatunk hozzá a kivétel objektumához:

```ruby
begin
  # ...any code that raises an exception
rescue => e
  puts "Exception class: #{ e.class.name }"
  puts "Exception Message:#{e.message}"
end
```

A Rubyben saját kivételeket is dobhatsz. Például:

```ruby
begin
  raise ArgumentError.new("Invalid argument")
rescue ArgumentError => e
  puts e.message
end
```

Az előző kivétel a Ruby beépített kivételei közül való, de egyéni kivételeket is definiálhatsz, és dobhatod őket:

```ruby
class CustomError < StandardError
end

raise CustomError.new("Something went wrong")
```
