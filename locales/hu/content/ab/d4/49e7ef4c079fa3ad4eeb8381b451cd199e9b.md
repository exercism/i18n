# Utasítások

Elyse, a leendő varázsló, éppen az alapokat gyakorolja.
Van egy pakli kártyája, amit szeretne manipulálni.

Hogy kicsit könnyebb legyen a dolga, csak az 1-től 10-ig terjedő kártyákat használja, így a kártyapaklija egy számvektorral ábrázolható.
Egy adott kártya pozíciója a vektor indexének felel meg.

## 1. Kártya lekérése a pakliból

Egy kártya kiválasztásához add vissza a megadott pakli `position` indexű kártyáját.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. Kártya cseréje a pakliban

Végezz egy kis kézügyességet, és cseréld ki a `position` indexű kártyát a megadott cserekártyára.
Add vissza a módosított paklit.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. Kártya beszúrása a pakli tetejére

Varázsolj elő egy kártyát úgy, hogy egy új kártyát szúrsz be a pakli tetejére.
Add vissza a módosított paklit.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. Kártya eltávolítása a pakliból

Tüntesd el a kártyát úgy, hogy eltávolítod a megadott `position` helyen lévő kártyát a pakliból.
Add vissza a módosított paklit.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. A felső kártya eltávolítása a pakliból

Tüntesd el a kártyát úgy, hogy eltávolítod a pakli tetején lévő kártyát.
Add vissza a módosított paklit.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. Kártya beszúrása a pakli aljára

Varázsolj elő egy kártyát úgy, hogy egy új kártyát szúrsz be a pakli aljára.
Add vissza a módosított paklit.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. Kártya eltávolítása a pakli aljáról

Tüntesd el a kártyát úgy, hogy eltávolítod a pakli alján lévő kártyát.
Add vissza a módosított paklit.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. A pakli méretének ellenőrzése

Ellenőrizd, hogy a pakli mérete egyenlő-e a `stack_size` értékkel vagy sem.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
