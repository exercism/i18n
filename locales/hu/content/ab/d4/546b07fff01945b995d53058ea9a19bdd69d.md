# Bemutatás

A stringekkel végzett munka gyakori feladat a programozásban.
Ezért a Swift számos metódust kínál a stringek kezelésére.
Ez a dokumentum a leggyakoribb stringmetódusok és tulajdonságok egy részét mutatja be; némelyikükhöz importálni kell a Foundation keretrendszert.

## [`components(separatedBy:)`][components]

Amikor egy stringet részsztringek tömbjére szeretnél bontani, használhatod a `components(separatedBy:)` metódust.
Ha például egy mondat minden szavát szeretnéd megkapni, elválasztóként a szóköz karaktert használhatod.

```swift
let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## [`hasPrefix(_:)`][hasPrefix], [`hasSuffix(_:)`][hasSuffix]

Amikor ellenőrizni szeretnéd, hogy egy string egy adott részsztringgel kezdődik-e vagy végződik-e, a `hasPrefix(_:)` és a `hasSuffix(_:)` metódust használhatod.
Mindkét metódus egy stringet vár argumentumként, és egy Boolean értéket ad vissza, amely megmutatja, hogy a string a megadott részsztringgel kezdődik-e vagy végződik-e.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## [`lowercased`][lowercased], [`uppercased`][uppercased], [`capitalized`][capitalized]

Amikor egy string kis- és nagybetűs alakját szeretnéd megváltoztatni, a `lowercased`, az `uppercased` és a `capitalized` tulajdonságot használhatod.
A `lowercased` tulajdonság egy új stringet ad vissza, amelyben minden karakter kisbetűs, az `uppercased` egy új stringet ad vissza, amelyben minden karakter nagybetűs, a `capitalized` pedig egy új stringet ad vissza, amelyben minden szó első karaktere nagybetűs.

```swift
let greeting = "hello, world!"
print(greeting.lowercased)  // Prints "hello, world!"
print(greeting.uppercased)  // Prints "HELLO, WORLD!"
print(greeting.capitalized) // Prints "Hello, World!"
```

## [`replacingOccurrences(of:with:)`][replacingOccurrences]

Amikor egy stringben egy részsztring minden előfordulását le szeretnéd cserélni egy másik részsztringre, a `replacingOccurrences(of:with:)` metódust használhatod.
Ez a metódus két stringet vár argumentumként: a lecserélendő részsztringet és azt, amelyikkel lecseréled. Egy új stringet ad vissza, amelyben a megadott részsztring minden előfordulása le van cserélve.

```swift
let greeting = "Hello, world!"
let newGreeting = greeting.replacingOccurrences(of: "world", with: "Swift")
print(newGreeting) // Prints "Hello, Swift!"
```

## [`joined(separator:)`][joined]

Ez nem a String típus, hanem a tömb típus metódusa.
Amikor stringek egy tömbjét egyetlen stringgé szeretnéd összefűzni egy megadott elválasztóval, a `joined(separator:)` metódust használhatod.
Ez a metódus egy stringet vár argumentumként, és egy új stringet ad vissza, amelyben a tömb minden eleme össze van fűzve, a megadott stringgel elválasztva.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
