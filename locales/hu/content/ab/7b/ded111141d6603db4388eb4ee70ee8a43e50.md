# Utasítások

Éjszakai műszak van Hull rakpartján. Az *Olwen* teherhajó a rakpart mellé van kikötve, és egy dokkmunkás-csapat párhuzamosan dolgozza fel a rakományjegyzéket. Minden ládát meg kell mérni, mielőtt a hajóra kerül, és a kikötőmester egyetlen, folyamatosan vezetett **tonnaösszesítőt** tart nyilván, amelyet minden emelés frissít. A bökkenő: csak egy rakparti daru van, ezért nem szakíthatja szét az összesítőt, ha két dokkmunkás egyszerre frissíti.

Minden láda a benne lévő tételek súlyainak tömbje. A láda súlya ezeknek a tételeknek az összege.

## 1. Mérj meg egy ládát

Definiáld a `weigh-crate` szót úgy, hogy átvegyen egy ládát, és adja vissza a teljes súlyát. Ez egyszerű, soros munka: egy láda be, egy szám ki.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. Mérd meg a teljes rakományjegyzéket párhuzamosan

Definiáld a `weigh-all` szót úgy, hogy átvegyen egy ládatömböt, és adja vissza a súlyaik tömbjét, ugyanabban a sorrendben. Használd a `parallel-map` szót, hogy a ládánkénti munka egyidejűleg történjen.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. Építs egy vadonatúj darut

Definiáld a `<crane>` szót úgy, hogy létrehozzon egy új darut: egy tuple-t egy friss `<lock>`-kal és `0` tonnával. A daru az a megosztott erőforrás, amelyet a következő részfeladatok védeni fognak.

```factor
<crane> tonnage>> .
! => 0
```

## 4. Emelj fel egy ládát az aktuális összesítőre

Definiáld a `hoist-crate` szót úgy, hogy átvegyen egy `weight` értéket és egy `crane`-t, és a súlyt **a daru zára alatt** adja hozzá a daru tonnájához, hogy az olvasás-hozzáadás-írás atomi legyen a többi, egy időben emelő dokkmunkással szemben.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. Olvasd le az aktuális tonnát

Definiáld a `crane-tonnage` szót úgy, hogy adja vissza a daru aktuális tonnáját, szintén a zár alatt, hogy az olvasás ne láthasson szétszakadt értéket egy emelés közepén.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. Rakod be a rakományt

Definiáld a `load-cargo` szót úgy, hogy átvegyen egy ládatömböt és egy darut, és **minden ládához indítson egy dokkmunkás szálat**, amely megméri a ládát, és a súlyát ráemeli a darura. A szó csak akkor tér vissza, amikor minden dokkmunkás végzett. A csatlakozás összehangolásához használd a `<promise>` és a `?promise` szót.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
