# A feladatleírás kiegészítése

## Kurzusspecifikus tudnivalók

Ha kicsit másra vágysz, kipróbálhatsz egy `unfold` függvényt használó megoldást is.
A `foldLeft/Right` valószínűleg már ismerős: „map” segítségével egy egész kollekciót alakítasz át valami mássá (többnyire egy nem kollekcióvá).
Az `unfold` ezzel épp ellentétes művelet: „map” segítségével valamit (többnyire egy nem kollekciót) kollekcióvá alakítasz.
Az `unfold` tehát logikus kiegészítése, sőt része az FP standard eszköztárának.

Ez a feladat felfogható az `unfold` egyik felhasználási eseteként: „map” egy `Int`-et egy `String`-gé (ami persze implicit módon egy `Seq[Char]`).

A Scala kollekcióiban a 2.13-as verzió óta megtalálható, például a [`List.unfold`][list] és az `Iterator.unfold`.
Egy kezdőállapotot és egy függvényt vár. A függvény a következő elemet és a következő állapotot adja vissza, vagy `None`-t, ha meg kell állni:

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
