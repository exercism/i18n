# Bevezetés

A JavaScriptben az `Array` osztálynak számos hatékony beépített metódusa van a tömbök átalakítására.
Ezekkel a metódusokkal sokkal könnyebb az egyik tömböt egy másikká alakítani, mint ha egyszerű for ciklussal vagy közvetlenebb manipulációval tennénk.

Egyes metódusok [_tiszták_][pure-function-definition], vagyis nem módosítják az eredeti tömböt.
Ehelyett egy új tömböt adnak vissza.
Más metódusok viszont módosítják azt a tömböt, amelyen meghívták őket, és **nem** adják vissza a módosított tömböt.

A leggyakrabban használt tömbtátalakító metódusok közül mutatunk be néhányat alább.
Az elérhető metódusok teljes listáját az [MDN dokumentációban][array-methods] találod.

### map (tiszta)

Úgy hozhatsz létre új tömböt, hogy minden elemet egy argumentumként átadott függvény szerint alakítasz át.
Ezeket a callback függvényeket gyakran [nyílfüggvényként][concept-arrow-functions] írjuk.

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

Érdemes megjegyezni, hogy a kapott tömb hossza mindig megegyezik az eredetiével.

### filter (tiszta)

Egy szűrőfüggvény segítségével új tömböt hoz létre a jelenlegiből (a szűrőfüggvény igazat ad vissza, ha az elemet meg kell tartani, és hamisat, ha el kell távolítani).

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (tiszta)

Egyetlen értékké redukálja a tömböt egy olyan függvény segítségével, amely paraméterként egy _akkumulátort_ és a tömb aktuális elemét kapja.
Ez a függvény megmondja, hogyan kell az aktuális elemet beolvasztani az akkumulátorba, és visszaadja azt az akkumulátort, amelyet a következő iterációban használunk.

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

Megfordítja egy tömb elemeit.

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

Ez a metódus módosítja azt a tömböt, amelyen meghívták.

### slice (tiszta)

Egy kezdő- és egy záróindex megadásával rész-tömböt hoz létre abból a tömbből, amelyen meghívták.

A záróindexen lévő elem nem kerül bele.
Ráadásul minden paraméter elhagyható:
a kezdőindex alapértéke `0`, a záróindexé pedig a tömb hossza.

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

Eltávolítja, illetve lecseréli és/vagy új elemeket ad hozzá egy tömbhöz.

A következő paramétereket várja:

- annak az elemnek az indexét, ahol a tömb módosítását kezdeni szeretnéd
- a törölni kívánt elemek számát
- a tömbbe beszúrandó elemeket (elhagyható)

A `splice` visszaadja azokat az elemeket, amelyeket eltávolított.

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

Alapértelmezés szerint a `sort` úgy rendezi a tömb elemeit, hogy először stringgé alakítja őket, majd string-összehasonlítást alkalmaz (lásd [Összehasonlítás][concept-comparison]).
A rendezés _helyben_ történik, ami azt jelenti, hogy az eredeti tömb módosul.
A `sort` vissza is adja ezt a módosított tömböt, ami kényelmes, ha további metódusokat szeretnél hozzáláncolni.

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

A rendezés viselkedésének testreszabásához argumentumként átadhatsz egy összehasonlító függvényt.
Magát az összehasonlító függvényt két argumentummal hívjuk meg, amelyek a tömb két eleme.
Ezután a következőket kell visszaadnia:

- negatív számot, ha az első argumentumnak a második elé kell kerülnie a rendezésben
- pozitív számot, ha az első argumentumnak a második mögé kell kerülnie
- `0`-t, ha az elemek sorrendje változatlan kell maradjon

Például a számok rendezéséhez a következő összehasonlító függvényt használhatod.

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
