# Instructions

Ebben a feladatban olyan kódot írsz, amely névjelvényeket nyomtat egy gyár alkalmazottai számára. Minden alkalmazottnak van azonosítója, neve és részlegneve. Az alkalmazotti jelvények felirata a következő formátumú: `"[id] - name - DEPARTMENT"`.

## 1. Nyomtass jelvényt egy alkalmazottnak

Valósítsd meg a `NameBadge.print/3` függvényt. Paraméterként egy azonosítót, egy nevet és egy részleget kap. Adja vissza a jelvény feliratát úgy, hogy a részleg neve nagybetűvel szerepel benne.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Nyomtass jelvényt egy új alkalmazottnak

A számítógépes rendszer sajátossága miatt előfordul, hogy az új alkalmazottaknak a gyárban való kezdéskor még nincs azonosítójuk. Mivel a jelvény kötelező, ideiglenes jelvényt kapnak, amelyen nincs ott az azonosító előtagja.

Egészítsd ki a `NameBadge.print/3` függvényt. Ha hiányzik az azonosító, akkor a függvény az azonosító nélkül nyomtatja ki a jelvényt.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Nyomtass jelvényt a tulajdonosnak

Még a gyár tulajdonosának is mindig jelvényt kell viselnie. A tulajdonosnak viszont nincs részlege. Ebben az esetben a feliraton a részleg neve helyett `"OWNER"` szerepel.

Egészítsd ki a `NameBadge.print/3` függvényt. Ha hiányzik a részleg, akkor feltételezd, hogy a jelvény a cég tulajdonosáé.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Vedd figyelembe, hogy előfordulhat, hogy a tulajdonos egyben új alkalmazott is.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
