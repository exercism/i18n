# Bevezetés

A Common Lisp lehetővé teszi a programozó számára, hogy „megjegyzéseket” írjon, amelyeket a számítógép figyelmen kívül hagy.
Az egysoros megjegyzések egy vagy több pontosvesszővel (`;`) kezdődnek, és alkalmanként a következővel találkozhatsz:

```lisp
(code...) ; => value
```

Ilyenkor a megjegyzés azt jelzi, hogy milyen értéket ad vissza a Common Lisp, miután az adott sorban lévő kód lefutott.

Idiómaszerű egyetlen pontosvesszőt használni egy sor végére írt rövid megjegyzéshez, kettőt egy kódrészlet fölötti hosszabb megjegyzéshez, hármat egy hosszú, valamit, például egy függvényt leíró megjegyzéshez, négyet pedig egy olyan megjegyzéshez, mint amilyen egy forrásfájl elején álló fejléc.
