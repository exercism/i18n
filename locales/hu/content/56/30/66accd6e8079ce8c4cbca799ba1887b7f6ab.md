# Kiegészítés az utasításokhoz

## A `Print` nem teszi idézőjelbe a stringértékeket

Ebben a feladatban numerikus pontszámokat kell manipulálnod.
#[a: 1]` and `#[a: "1"]` nem ugyanaz:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

A hibakeresés gyakori módszere, hogy `print`-tel kiíratod az értékeket.
A kimenet azonban nem tesz idézőjelet a stringek köré.
Ezért egy `"1"` numerikus string nyomtatva ugyanúgy néz ki, mint az `1` egész szám.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
A feladat teszteredményében láthatsz egy ilyen eredményt: `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`.
A két összehasonlított szótár nyomtatva ugyanúgy néz ki.
Az első szótárban viszont numerikus stringértékek vannak, a másodikban egész számok, tehát nem ugyanazok. 
Hibakereséskor az `inspect` segítségével ellenőrizheted a szótár tartalmát.

## Az `Express` viszont idézőjelbe teszi a stringértékeket

Az `express` egy értéket Arturo-kóddá alakít, és egy stringet ad vissza, ami azt a kódreprezentációt írja le.
Ebben az eredményben minden stringérték idézőjelbe kerül.
Ezért az `express "1"` a `"1"` értéket adja vissza, nem az `1`-et.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
