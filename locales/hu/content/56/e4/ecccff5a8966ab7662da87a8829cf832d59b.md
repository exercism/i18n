# Bevezetés

A Boolean kifejezés egy vagy több értékre feltett kérdés, amelyre `true` vagy `false` a válasz.
Egy igaz kifejezés `1`-et ad vissza; egy hamis kifejezés `0`-t ad vissza.
A számoknak is van igaz/hamis értékük. A nulla `false`; a nem nulla `true`. 

A régi C-kód vagy közvetlenül az `int` típust használja Boolean értékekhez, vagy a programozó definiálhatott olyan konstansokat, mint a `TRUE` és a `FALSE`, hogy az `1`-et és a `0`-t Boolean reprezentációra képezze le.

A C99-es verzióban hozzáadták a `_Bool` típust.
A `stdbool.h` fejlécfájl három új Boolean szimbólumot definiál: `bool`; `true` és `false`.
A `true` az `1`-re képeződik le; a `false` a `0`-ra; a `bool` pedig a `_Bool`-ra.
Így mostantól ahelyett, hogy közvetlenül `int`-eket használnának, vagy saját Boolean leképezéseket készítenének, a programozók beilleszthetik a `stdbool.h` fejlécfájlt, és automatikusan Boolean szimbólumokat kapnak a kódjukban.

## Összehasonlító operátorok

A C hat összehasonlító operátort támogat: `==` (egyenlő), `!=` (nem egyenlő), `>` (nagyobb mint), `<` (kisebb mint), `>=` (nagyobb vagy egyenlő), `<=` (kisebb vagy egyenlő).
Ezek az operátorok összehasonlítják az értékek közötti viszonyokat, és Boolean értékekké értékelik ki őket.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Boolean operátorok

A C három Boolean operátort támogat: `||` (vagy), `&&` (és), és `!` (nem). 

A `!` egy operandussal használatos.
Megfordítja az operandus Boolean értékét.
Például a `0` `false`, de a `!0` `true`.

A `||` és a `&&` két operandussal használatos.
A jobb oldali operandus csak akkor értékelődik ki, ha a bal oldali operandus még nem határozza meg a kifejezés eredményét.
Azaz a `||` csak akkor értékeli ki a jobb oldali operandusát, ha a bal oldali operandusa `false`-ra értékelődik.
A `&&` csak akkor értékeli ki a jobb oldali operandusát, ha a bal oldali operandusa `true`-ra értékelődik.
