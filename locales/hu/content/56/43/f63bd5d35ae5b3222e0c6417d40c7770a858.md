# Bevezetés

## Stringek

A stringek karakterek sorozatai, amelyeket idézőjelek vesznek körül.
A szimpla és a dupla idézőjel is támogatott.

```php
<?php

$where = "Spain";
$what = 'rain';
```

### Változók behelyettesítése stringekbe

A dupla idézőjeles stringekben, ha egy változó scope-ban van, és hivatkozunk rá, az értéke bekerül a stringbe.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### Karakterkódolás támogatása

A PHP stringfüggvényei történelmileg csak az ASCII karaktereket támogatták, és nem támogatták a modern Unicode-kódolásokat.
Az ASCII-karakterek egyenként 1 bájtosak, míg a Unicode-karakterek 1-4 bájt hosszúak lehetnek.
Ha biztonságosan szeretnél Unicode stringeket manipulálni, nézd meg a régi függvények [többbájtos változatait][multi-byte-fns].

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
