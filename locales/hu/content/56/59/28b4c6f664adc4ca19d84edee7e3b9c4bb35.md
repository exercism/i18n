# Variadikus paraméterek

A Swiftben a [_variadikus paraméterek_][variadic-parameters] segítségével nulla vagy több azonos típusú értéket adhatsz át egyetlen paraméterben egy függvénynek. Ezt úgy jelölöd, hogy a paraméter típusjelölése után `...`-t írsz.

Ezeket az értékeket a Swift automatikusan egy tömbbe csoportosítja, amelynek elemei ugyanolyan típusúak, mint a variadikus paraméter típusa.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Tudd, hogy a variadikus paraméterek használatakor a Swiftnek van egy korlátja.
Ha egy függvény definíciójában a variadikus paraméter után is következnek paraméterek, akkor a variadikus paramétert követő első paraméterhez _kötelező_ argumentumcímkét írni.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
