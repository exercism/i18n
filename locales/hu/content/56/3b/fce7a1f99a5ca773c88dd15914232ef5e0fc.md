# Bemutató

A listák a Haskell egyik alapvető adattípusa, amellyel értékek gyűjteményét tárolhatod.
A listák _változtathatatlanok_, ami azt jelenti, hogy nem módosíthatók.
Bármely művelet, amely megváltoztat egy listát, új listát ad vissza.
A Prelude-ban számos függvény áll rendelkezésre, amelyekkel listákkal dolgozhatsz.

A Haskellben a listák [láncolt listákként][linked-list-wiki] vannak megvalósítva, nem pedig összefüggő memóriaterületek tömbjeiként.
Ezért egy lista adott elemének elérése a lista hosszától függő, lineáris időt vesz igénybe.

A listákat felírhatod literál formában, fej-farok jelöléssel (amely a `cons` operátort, a `:`-t használja), vagy a kettő kombinációjával:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

A fej-farok jelöléssel elemeket fűzhetsz egy listához.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Az, hogy iteráció közben elemeket fűzünk egy lista végéhez, antimintának számít.
Egy elem hozzáfűzése az egész lista bejárását igényli, hogy a végére illesszük az elemet; ezért ha minden iterációban új elemet fűznénk hozzá, minden iterációban be kellene járni a teljes listát.

Ugyanezt elérhetjük úgy, hogy az elemet a megfordított lista elejére fűzzük, majd az eredményt megfordítjuk. Az elejére fűzés gyors művelet, konstans időt igényel.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Íme néhány gyakori Prelude-függvény listákhoz:

- [`head`][head] visszaadja a lista _fejét_: a lista _első_ elemét.
- [`tail`][tail] visszaadja a lista _farkát_: a listát az _első_ elem _nélkül_.
- [`length`][length] visszaadja a lista elemeinek számát.
- [`elem`][elem] egy Boolean értéket ad vissza, ami megmutatja, hogy a keresett elem szerepel-e a listában.

Létezik emellett a [`Data.List` modul][list] is.

## Listatípusok

A Haskellben a listák **homogének**.
Ez azt jelenti, hogy egy lista minden eleme ugyanolyan típusú.
Ha különböző típusú elemeket próbálsz ugyanabba a listába tenni, típushibát kapsz.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

Egy lista típusmegjelölése `[a]`, ahol az „a” a lista által tárolt típus, például `String` vagy `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
