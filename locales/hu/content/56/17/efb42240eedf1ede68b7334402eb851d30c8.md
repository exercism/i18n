# Utasítások

Ebben a feladatban a [Go játék szabályait](https://matmoore.github.io/learngo/) fogod alkalmazni. Maguk a szabályok már meg vannak írva, neked csak alkalmaznod kell őket, hogy frissítsd a `Game`-et, és kezeld a hibákat, illetve a szabályok megsértését.

A játék ábrázolása a következő:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

A játékban 4 szabály van:

- Egy ponton csak egy kő lehet.
- Az ellenfél köveit le lehet ütni.
- Nem helyezhetsz követ olyan pontra, ahol a kő önmagát ütné le.
- Ugyanazt a pontot nem használhatod kétszer.

## 1. A szabályok alkalmazása

Írd meg az `apply_rules` függvény tartalmát, amely egy kezdeti `Game`-et és egy szabályhalmazt kap, és visszaadja az új `Game`-et, miután alkalmaztad a szabályokat.

A szabályok közül három ellenőrzi a szabályok megsértését, és hibát adhat vissza, ezért a visszatérési típusuk `Result(Game, String)`. Ha ezek bármelyike elbukik, az eredeti játékot kell visszaadni, de az `error` mezőt a megfelelő hibaüzenettel frissítve.

A másik szabály nem ellenőriz megsértést, így nem is bukhat el (bár módosított `Game`-et adhat vissza), ezért a visszatérési típusa `Game`.

Ha minden szabály átmegy, akkor a szabályok által a `Game`-en eszközölt változtatásokat meg kell tartani, és a játékost le kell cserélni.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
