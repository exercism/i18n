# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít egy táblakészítő cégnek egyedi üzeneteket készíteni a tábláihoz.

## 1. Készíts alkalmi táblát

Valósítsd meg a `build_sign( )` metódust, amely egy stringet fogad el az `occasion` paraméterként, és egy nevet tartalmazó stringet a `name` paraméterként. A két paraméter egy string-sablonba kerül beágyazásra, hogy kiadja a táblán megjelenő üzenetet.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Készíts születésnapi táblát

Valósítsd meg a `build_birthday_sign( )` metódust, amely egy életkort fogad el, és az életkor alapján meghatározza a táblán szereplő üzenet egy részét. Ha az életkor 50 vagy több, a tábla a _mature_ szót tartalmazza, egyébként pedig a _young_ szót.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Készíts ballagási táblát

Valósítsd meg a `graduation_for( )` metódust, amely egy nevet vesz át string paraméterként és egy évet numerikus paraméterként, és string-sablonok segítségével hoz létre egy szöveget a táblához, amelyben egy újsor választja el az üzenet két sorát.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Számítsd ki egy tábla költségét

Valósítsd meg a `cost_of( sign currency )` függvényt, amely átvesz egy stringet, amely a tábla tartalmát tartalmazza, és egy stringet, amely a pénznemet jelöli.
A tábla alapára 20 a megadott pénznemben. Ezen felül minden betűért 2-t kell fizetni. (A szóközöket is beleszámítjuk a számításba.)
A visszaadott szöveg tartalmazza a tábla elkészítésének költségét, két tizedesjegyre kiírva, majd ezt követi a pénznemet jelölő string.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
