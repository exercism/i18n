# Bevezetés

A kódszervezés egyik fontos módszere a névtér.
Két függvény neve ütközhet, amit úgy oldhatsz fel, hogy különböző névterekbe teszed őket.
A névterek egymásba ágyazhatók, ami segíthet a nagy kódbázisok strukturálásában.
A névtereket a `::` scope-feloldó operátorral éred el.

Az alábbi példa két különböző `foo` függvény használatát mutatja be.
Úgy használjuk őket együtt, hogy eléjük írjuk a hozzájuk tartozó névteret.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
