# Részletesen

A [while-ciklus][while-loops] olyan vezérlési utasítás, amely lehetővé teszi, hogy a kód addig fusson, amíg egy bizonyos feltétel igaz.
A Swift kétféle while-ciklust kínál: a while- és a repeat-while-ciklust.
A while-ciklus feltételét a program a ciklusmag végrehajtása előtt értékeli ki; ha a feltétel hamis, a ciklusmag egyáltalán nem fut le.
A while-ciklusok szerkezete Swiftben a következő:

```swift
while <#condition#> {
  <#code#>
}
```

Itt a ciklus addig fut, amíg a count nagyobb 0-nál, és eközben kiírja a 2-es és az 1-es számot, valamint a „Liftoff!” szót.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

A [repeat-while-ciklus][while-loops] hasonlít a while-ciklushoz, de a feltételét a ciklusmag végrehajtása után értékeljük ki.
Ez azt jelenti, hogy a ciklusmag mindig lefut legalább egyszer, akkor is, ha a feltétel hamis.
A repeat-while-ciklusok szerkezete Swiftben a következő:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Itt a ciklus csak egyszer fut le, mert a feltétel hamis.
Mivel ez egy repeat-while-ciklus, a ciklusmag a feltétel kiértékelése előtt egyszer lefut.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

[repeat-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Repeat-While
