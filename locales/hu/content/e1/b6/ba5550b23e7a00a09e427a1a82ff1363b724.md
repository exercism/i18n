# Bevezetés

## Számok

A Go tartalmaz alapvető numerikus típusokat, amelyek egész vagy lebegőpontos értékek halmazát képesek reprezentálni.
Különböző típusok vannak attól függően, hogy mekkora értékre van szükséged, és hogy milyen architektúrájú a számítógép, amelyen az alkalmazás fut (pl. 32 bites és 64 bites).

Ebben a feladatban csak a következőkkel fogsz foglalkozni:

- `int`: pl. `0`, `255`, `2147483647`.
  Egy előjeles egész szám, amelynek mérete legalább 32 bit (értéktartománya: -2147483648-tól 2147483647-ig).
  Ez azonban a rendszer architektúrájától függ.
  A legtöbb modern számítógép 64 bites, ezért az `int` mérete 64 bit lesz (értéktartománya: -9223372036854775808-tól 9223372036854775807-ig).

- `float64`: pl. `0.0`, `3.14`.
  A 64 bites lebegőpontos számok halmazát tartalmazza.

- `uint`: pl. `0`, `255`.
  Egy előjel nélküli egész szám, amely ugyanolyan méretű, mint az `int` (értéktartománya: 0-tól 4294967295-ig 32 bit esetén, és 0-tól 18446744073709551615-ig 64 bit esetén).

A számok más numerikus típusokká alakíthatók típuskonverzióval.

## Aritmetikai operátorok

A Go számos szabványos aritmetikai operátort támogat:

| Operátor | Példa        |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

Egész számok osztásakor a maradék elvész (pl. `5 / 2 == 2`).

A Go támogatja a fenti operátorokhoz a rövidített értékadást (pl. az `a += 5` az `a = a + 5` rövidítése).
A Go támogatja a `++` és `--` növelő és csökkentő utasításokat is (pl. `a++`).

## Típusok közötti konverzió

A típusok közötti konverzió egy függvénnyel történik, amelynek a neve a cél típus neve.
Például:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
var y float64 = 11.9 // y has type float64
i := int(y) // i has type int (ie. 11)
```

## Aritmetikai műveletek különböző típusokon

Sok nyelvben végezhetsz aritmetikai műveleteket különböző típusú változókon, de a Go-ban ez hibát ad.
Például:

```go
var x int = 42

// this line produces an error
value := float32(2.0) * x // invalid operation: mismatched types float32 and int

// you must convert int type to float32 before performing arithmetic operation
value := float32(2.0) * float32(x)
```
