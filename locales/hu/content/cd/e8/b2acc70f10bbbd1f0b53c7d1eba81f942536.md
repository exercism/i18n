# Utasítások

Ebben a feladatban a [Pac-Man][Pac-Man], a klasszikus 1980-as évekbeli arkádjáték néhány szabályát kell megvalósítanod.

Összesen hat részfeladat van, ezek közül négy a játék állapotaihoz kapcsolódó szabály.

> _Ne foglalkozz azzal, hogyan állnak elő a függvények argumentumai, csak arra összpontosíts, hogy az argumentumokat kombinálva a szándékolt eredményt add vissza._


## 0. Definiálj egy erőállapotot

Definiálj egy `PowerOn` nevű változót olyan értékkel, amely azt jelöli, hogy az erő valóban be van kapcsolva.

```powershell
> $PowerOn
True
```

## 1. Határozd meg, hogy Pac-Man megeszik-e egy szellemet

Definiáld az `EatGhost` függvényt, amely két paramétert vesz át (_hogy Pac-Mannek aktív-e erőgolyója_ és _hogy Pac-Man hozzáér-e egy szellemhez_), és egy Boolean értéket ad vissza arról, hogy Pac-Man meg tudja-e enni a szellemet.
A függvény csak akkor adjon vissza `True` értéket, ha Pac-Mannek aktív erőgolyója van, és éppen hozzáér egy szellemhez.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Határozd meg, hogy Pac-Man szerez-e pontot

Definiáld a `Score` függvényt, amely két paramétert vesz át (_hogy Pac-Man hozzáér-e egy erőgolyóhoz_ és _hogy Pac-Man hozzáér-e egy pöttyhöz_), és egy Boolean értéket ad vissza arról, hogy Pac-Man szerzett-e pontot.
A függvény akkor adjon vissza `True` értéket, ha Pac-Man hozzáér egy erőgolyóhoz vagy egy pöttyhöz.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Határozd meg, hogy Pac-Man veszít-e

Definiáld a `Lose` függvényt, amely két paramétert vesz át (_hogy Pac-Mannek aktív-e erőgolyója_ és _hogy Pac-Man hozzáér-e egy szellemhez_), és egy Boolean értéket ad vissza arról, hogy Pac-Man veszít-e.
A függvény akkor adjon vissza `True` értéket, ha Pac-Man hozzáér egy szellemhez, és nincs aktív erőgolyója.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Határozd meg, hogy Pac-Man nyer-e

Definiáld a `Win` függvényt, amely három paramétert vesz át (_hogy Pac-Man megette-e az összes pöttyöt_, _hogy Pac-Mannek aktív-e erőgolyója_, és _hogy Pac-Man hozzáér-e egy szellemhez_), és egy Boolean értéket ad vissza arról, hogy Pac-Man nyer-e.
A függvény akkor adjon vissza `True` értéket, ha Pac-Man megette az összes pöttyöt, és a 3. részben megadott paraméterek alapján nem veszített.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. Írj Synopsis-t a győzelmi feltételhez

Térj vissza az utolsó függvényhez, és a kommentblokkhoz adj hozzá egy `Synopsis` szakaszt, amely röviden leírja, hogyan lehet megnyerni a játékot.
A leírásnak legalább tíz karakter hosszúnak kell lennie.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
