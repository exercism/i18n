# Kiegészítés az utasításokhoz

## Tippek

A `countWords` bármilyen hash tábla típust visszaadhat, amelynek a kulcsa `string`, az értéke pedig `int`.

A hash táblákat (más programozási nyelvekben „szótárnak” vagy „mapnak” nevezik) a `tables` modul valósítja meg, lásd a [documentation]

Például a `countWords` visszaadhat egy `TableRef[string, int]` értéket

```nim
proc countWords*(sentence: string): TableRef[string, int] =
  ...
```

[documentation]: https://nim-lang.org/docs/tables.html
