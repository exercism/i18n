# Tippek

## 1. A kártyák előállításához szükséges adatok kinyerése reguláris kifejezéssel

- A `\p{L}` bármilyen nyelv bármilyen betűjére illeszkedik.
- Az alábbi kifejezéssel tudod kinyerni az adatokat:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
