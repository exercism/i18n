# Getters and setters

A getter és a setter olyan metódusok, amelyekkel egy objektum tulajdonságának értékét olvashatod és írhatod.
A Crystal rendelkezik makrókkal, így könnyen definiálhatsz gettert és settert egy tulajdonsághoz.
A makrók segítségével fordítási időben generálhatsz kódot, amiről később, a makró fogalomnál lesz szó.

A Rubyben ezeket a metódusokat az `attr_reader`, az `attr_writer` és az `attr_accessor` metódussal definiálod, és felületesen nézve nagyon hasonlítanak a Crystal megvalósításához.
A Crystal ezeket `getter`, `setter` és `property` makróként definiálta.

## Getters

A getter egy olyan makró, amely egy példányváltozó értékét visszaadó metódust definiál.
Ez azt jelenti, hogy ha hozzá akarsz férni a példányváltozóhoz, már nem kell `@`-ot írnod elé (metódusokban, az initialize kivételével); helyette meghívhatod azt a metódust, amelyet a getter makró definiált.

A getter makró több példányváltozót is elfogad, amelyeket vesszővel választasz el egymástól.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Amint látod, a getter használatával kevesebb kódot írsz, és a kód olvashatóbb lesz.
A Ruby és a Crystal abban is különbözik, hogy a Crystal a getter makrónak argumentumként elfogadja a változónevet és a szimbólumot is.
A szimbólumokról később, a szimbólum fogalomnál lesz szó.

## Setters

A setter egy olyan makró, amely egy példányváltozó értékét beállító metódust definiál.
Ez a makró nem túl gyakori, helyette általában a `property` makrót használjuk.
A létrejövő metódusok így néznek ki: `name_of_method=`; az `=` teszi lehetővé, hogy a tulajdonságot be lehessen állítani.

Ez a metódusdefiníció kicsit különleges, mert a metódus által kapott argumentum az `=` jel után van.
A Crystalben több más különleges metódus is ezt a szintaxist használja, például a `+` metódus.

A getter makróhoz hasonlóan, miután definiáltál egy settert, a példányváltozó értékének frissítéséhez meghívhatod azt a metódust, amelyet a setter makró definiált.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

A property egy olyan makró, amely egy példányváltozóhoz gettert és settert is definiál.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
