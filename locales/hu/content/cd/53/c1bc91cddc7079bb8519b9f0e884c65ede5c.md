# Bevezetés

A Kotlin `when` egy feltételes kifejezés, amellyel több lehetőség közül választhatsz.
Hasonló a Java `switch`-jéhez, és rugalmasabb, mint az `if` ... `else if` ... `else` láncolata.

Az `if`-hez hasonlóan a `when` is használható kifejezésként, amely értéket ad vissza.

## Értékre illesztés

A `when` zárójelébe írd be az illesztendő értéket.
Az ágak sorra összevetik ezt az értéket, amíg valamelyik illeszkedik:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Minden ág `pattern -> result` formában szerepel.
- Az ágak fentről lefelé haladva kerülnek sorra, amíg illeszkedést nem találnak.
  Csak az első illeszkedő ág fut le.
- A fent fel nem sorolt értékekre az `else` ágat használd (hasonlóan az `if`-lánc záró `else` ágához).

Ez a [mintaillesztéshez][pattern-matching] hasonlít.
A `pattern` lehet maga az illesztendő érték, de az `is` kulcsszóval típus szerint is illeszthetsz:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

Vagy az `in` kulcsszóval ellenőrizheted, hogy az érték benne van-e egy tartományban, gyűjteményben, stringben, vagy bármi másban, aminek van `contains` metódusa:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## Őrfeltételek

Értékre illesztéskor a minta után egy `if`-fel további feltételeket is megadhatsz.
Ezeket a feltételeket nevezzük őrfeltételeknek.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

Még `else if` is használható.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Feltételekre illesztés

Másik lehetőség, hogy elhagyod az értéket, és minden ágra Boolean feltételt írsz:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Az ágak itt is fentről lefelé haladva kerülnek sorra, és csak az az első ág fut le, amelynek feltétele `true`.

## A `when` használata kifejezésként

Ha a `when`-et az eredményéért használod (változóhoz rendeled, egy függvényből adod vissza, és így tovább), minden lehetséges esetet le kell fedned.

- Értékre illesztéskor adj hozzá `else` ágat, hacsak az összes lehetséges értéket nem kezeled már (például egy `Boolean` vagy egy `enum` összes értékét).
- Feltételekre illesztéskor kötelező az `else` ág, mert a fordító nem tudhatja, hogy a feltételeid minden esetet lefednek.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
