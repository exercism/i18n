# Bevezetés

A Swiftben az enum olyan mechanizmus, amellyel új típusokat hozhatsz létre. Az így keletkező típusokat véges számú, névvel ellátott érték alkotja, amelyek további kapcsolódó információt hordozhatnak, és tulajdonságok meg metódusok is kapcsolódhatnak hozzájuk.

## Enumok definiálása

A legegyszerűbb enumokat az alábbi módon definiálhatod.

```swift
enum NESButton {
  case up
  case down
  case left
  case right
  case a
  case b
  case select
  case start
}
```

A rövidség kedvéért több eset is írható egyetlen sorba, vesszőkkel elválasztva, egyetlen `case` kulcsszóval.

```swift
enum NESButton {
  case up, down, left, right, a, b, select, start
}
```

Ez egy `NESButton` nevű új típust definiál, amelynek lehetséges értékei `up`, `down`, `left`, `right`, `a`, `b`, `select` és `start`. Ezekre az értékekre úgy hivatkozhatsz, hogy a típus neve után írsz egy pontot (`.`) és az értéket. Ha a típusnév kikövetkeztethető, csak a pontra és az értékre van szükség.

## Metódusok

A Swift többi típusához hasonlóan az enumok is tartalmazhatnak metódusokat, amelyekkel az enum az aktuális értékétől függő funkcionalitást nyújthat.

A metódusok a függvényekhez hasonlítanak, csak éppen az enum törzsén belül definiálod őket, és az enum aktuális értékéhez kötődnek. Elérésük _pont jelöléssel_ történik: az enumérték neve után egy pont (`.`) áll, majd a metódus neve és a paraméterei.

A metóduson belül az enumértékre `self` néven hivatkozhatsz, a típusszignatúrában pedig, ha paraméterként fogadsz el vagy visszaadsz egy értéket ebből az enumból, a típusra `Self` néven hivatkozhatsz.

### Kezdőértékek

A kezdőértékek speciális metódusok, amelyekkel az enum egy értékét állítod be. A definíciójuk nagyon hasonlít a metóduséhoz, csak itt nincs `func` kulcsszó, nincs visszatérési típus, a nevük pedig `init` kell legyen, és a kezdőértéknek _kötelezően_ hozzá kell rendelnie egy enumértéket a `self`-hez. A kezdőértéket vagy pont jelöléssel hívod meg, vagy úgy, hogy a kezdőérték paramétereit az enum nevének adod át.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```

### Nyers értékek

Az enumok egy belső értéket is hordozhatnak, ezt _nyers értéknek_ nevezzük. A nyers értékeknek mind ugyanolyan típusúaknak kell lenniük, amelyet az enum definíciójában adsz meg. Így például `Character` értékeket rendelhetünk a `NESButton` enumunkhoz a definíció módosításával:

```swift
enum NESButton: Character {
  case up = "⬆️"
  case down = "⬇️"
  case left = "⬅️"
  case right = "➡️"
  case a = "🅰️"
  case b = "🅱️"
  case select = "✅"
  case start = "🚦"
}
```

Itt a `: Character` mondja meg a fordítónak, hogy a nyers értékek `Character` típusúak lesznek, és a nyers érték hozzárendelése minden érték után következik.

A nyers értékeket minden érték automatikusan generált `rawValue` tulajdonságán keresztül érheted el.

```swift
NESButton.left.rawValue
// => "⬅️"
NESButton.b.rawValue
// => "🅱️"
```

A Swift `String` és `Int` nyersérték-típus esetén implicit módon is hozzárendelheti a nyers értékeket. Ha a nyersérték típusa `String`, akkor a nyers érték implicit módon az érték nevéből származó `String` lesz, kivéve, ha az implicit értéket egy explicit hozzárendeléssel felülírod.

Ha a nyersérték típusa `Int`, a nyers érték implicit módon 1-gyel nagyobb lesz, mint az előző eset nyers értéke, kivéve, ha explicit hozzárendeléssel felülírod. Az első eset alapértelmezett nyers értéke 0, hacsak másképp nem adod meg.

```swift
enum Coin: String {
  case heads
  case tails = "eagle"
}

Coin.heads.rawValue
// => "heads"
Coin.tails.rawValue
// => "eagle"

enum Dwarf: Int {
  case grumpy, sleepy, sneezy, happy = 8, bashful, dopey, doc
}

Dwarf.grumpy.rawValue
// => 0
Dwarf.sneezy.rawValue
// => 2
Dwarf.happy.rawValue
// => 8
Dwarf.bashful.rawValue
// => 9
```
