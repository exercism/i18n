# Részesítsd előnyben a kiemelt felső szintű konstanst

Ahelyett, hogy a függvényen belül definiálnád a konstanst, érdemes lehet a
felső szintre kiemelni. A konstansok, függvények és osztályok, amelyek
nincsenek `export`álva, a fájlon kívülről nem érhetők el.

```javascript
const %{name} = %{value}

export const gigasecond = (...)
```
