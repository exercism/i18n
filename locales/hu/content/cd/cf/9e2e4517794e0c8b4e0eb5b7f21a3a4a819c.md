# Bevezetés

A reguláris kifejezések Gleamben a **PCRE** specifikációt (**P**erl **C**ompatible **R**egular **E**xpressions) követik, hasonlóan más népszerű nyelvekhez, mint a Java, a JavaScript vagy a Ruby.

A `gleam/regex` modul függvényeket kínál a reguláris kifejezésekkel való munkához.

~~~~exercism/note
Ez a feladat feltételezi, hogy már ismered a reguláris kifejezések szintaxisát, beleértve a karakterosztályokat, a mennyiségjelölőket, a csoportokat és a rögzítéseket.

Ha fel kell frissítened a reguláris kifejezésekkel kapcsolatos tudásodat, nézd meg az alábbi források egyikét: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

A reguláris kifejezések létrehozásának leggyakoribb módja a `regex.from_string` függvény használata.

```gleam
let assert Ok(re) = regex.from_string("test")
```

A `regex.from_string` függvény `Error`-t ad vissza, ha a reguláris kifejezés szintaxisa érvénytelen, ezért itt egy let assert biztosítja, hogy a reguláris kifejezés érvényes legyen.

A `regex.check` függvénnyel ellenőrizheted, hogy egy reguláris kifejezés illeszkedik-e egy stringre.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Rögzítések

Ha egy reguláris kifejezéssel részstringeket szeretnél rögzíteni, a `regex.scan` függvény illeszkedések listáját adja vissza.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Módosítók

A reguláris kifejezés viselkedését úgy módosíthatod, hogy a `regex.compile` függvénnyel hozod létre, és beállításokat adsz át neki.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
