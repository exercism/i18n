# Utasítások

Szenvedélyes madárfigyelő vagy, aki számon tartja, hány madár járt a kertedben az elmúlt hét napban.

Hat részfeladatod van, és mindegyik azzal foglalkozik, hány madár látogatott el a kertedbe.

## 1. Ellenőrizd, mennyi volt a számuk az előző héten

Az összehasonlítás kedvéért mindig magadnál tartod az előző heti számok másolatát, ezek pedig a következők voltak: 0, 2, 5, 3, 7, 8 és 4. Hozz létre egy vektort, amely az előző heti számokat tartalmazza:

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. Ellenőrizd, hány madár járt ma a kertedben

Valósítsd meg a `today` függvényt, amely visszaadja, hány madár járt ma a kertedben. A madárszámok napok szerint vannak sorrendben: az első elem a legrégebbi nap száma, az utolsó pedig a mai napé.

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. Növeld meg a mai nap számát

Valósítsd meg az `inc-bird` függvényt, amely megnöveli a mai nap számát:

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. Ellenőrizd, volt-e olyan nap, amikor egyetlen madár sem járt itt

Valósítsd meg a `day-without-birds?` predikátumfüggvényt, amely `true`-t ad vissza, ha volt olyan nap, amikor egyetlen madár sem járt a kertben; egyébként `false`-t:

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. Számold ki a látogató madarak számát az első megadott számú napra

Valósítsd meg az `n-days-count` függvényt, amely visszaadja, hány madár járt a kertedben a hét kezdetétől számítva, de a számolást korlátozd a hét kezdetétől megadott számú napra.

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. Számold ki a forgalmas napok számát

Egyes napok forgalmasabbak, mint a többi. Forgalmas nap az, amikor öt vagy több madár járt a kertedben.
Valósítsd meg a `busy-days` függvényt, amely visszaadja a forgalmas napok számát:

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. Ellenőrizd, páratlan hét-e

Az elmúlt évben rájöttél, hogy bizonyos hetek ugyanazt a páratlan mintát követik, amelyben a látogató madarak száma váltakozva egy és nulla. Valósítsd meg az `odd-week?` függvényt, amely `true`-t ad vissza, ha az adott hét madárszám-mintája megegyezik a páratlan mintával:

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
