# Részletek

A(z) [concept:csharp/enumerables]() végigjárható egy [`foreach` ciklussal][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

A `foreach` ciklus három részből áll:

1. A deklaráció: definiálod a változót, amely az iterált értéket fogja tartalmazni. Ez a változó (csak) a cikluson belül használható.
2. Az iterálható objektum: az az objektum, amelyen a ciklus végigmegy.
3. A ciklus törzse.

## `for` és `foreach` ciklusok összehasonlítása

A `foreach` ciklus azonban általában előnyösebb a `for` ciklusnál, mégpedig a következő okok miatt:

- A `foreach` ciklus garantáltan _minden_ értéken végigmegy. Egy `for` ciklusnál viszont könnyű kihagyni elemeket, például ha eggyel elcsúszik az indexelés.
- A `foreach` ciklus _deklaratívabb_: a kódod azt fejezi ki, _mit_ szeretnél elérni, míg a `for` ciklus azt, _hogyan_ akarod megtenni.
- A `foreach` ciklussal nem lehet mellélőni, a `for` ciklusoknál viszont könnyen elcsúszhat az indexelés eggyel.
- A `foreach` ciklus minden gyűjteménytípuson működik, még azokon is, amelyeknél nem lehet indexelővel hozzáférni az elemekhez.

Hogy a `foreach` ciklus garantáltan _minden_ értéken végigmenjen, a fordító nem engedi meg, hogy egy gyűjteményt `foreach` cikluson belül módosíts:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

A `for` ciklusnak viszont van néhány előnye a `foreach` ciklussal szemben:

- A kívánt indexnél kezdhetsz és fejezheted be a ciklust.
- Bármilyen (Boolean) befejezési feltételt használhatsz.
- Kihagyhatsz elemeket, ha testre szabod a ciklusváltozó léptetését.
- A gyűjteményeket hátulról előre is feldolgozhatod, ha visszafelé számolsz.
- `for` ciklust olyan helyzetekben is használhatsz, ahol nincs szó gyűjteményekről.

Kapcsolódó témák:

- Érdemes tudnod, hogy a C# támogatja a [többdimenziós tömböket][multi-dimensional-arrays], például `int[,] arr = new int[10, 5]`, amelyek nagyon hasznosak lehetnek.
- Arról is érdemes tudnod, hogy [`System.Array`][system-array-object] típusú objektumokat az `Array.CreateInstance` metódussal is létrehozhatsz. Ezek az objektumok kevéssé hasznosak, főként a VB.NET kóddal való együttműködéshez. Nem cserélhetők fel a szabványos tömbökkel (`T[]`). Az alsó korlátjuk lehet nullától eltérő.
