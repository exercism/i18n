# A tuple típus

A tuple sokoldalú és hatékony összetett adattípus a Cairo-ban, amellyel különböző típusú értékeket csoportosíthatsz egyetlen egységbe.
A tuple-ök hossza rögzített, ami azt jelenti, hogy a méretük a deklarálásuk után nem változtatható meg.

## Tuple létrehozása

Egy tuple létrehozásához vesszővel elválasztott értéklistát írj zárójelek közé.
A tuple minden pozíciójának meghatározott típusa van, és ezek a típusok eltérhetnek egymástól.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

Egy tuple több különböző adattípusú értéket is tárolhat, köztük más tuple-öket is.
Például:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

Itt a `nested_tup` változó egy olyan tuple, amely két tuple-t tartalmaz, ami azt mutatja, hogy a tuple-ök elemekként más tuple-öket is tárolhatnak.

## Tuple-ök szétbontása

Ha egy tuple egyes értékeihez szeretnél hozzáférni, mintafelismeréssel szétbonthatod a tuple-t.
Így a tuple az őt alkotó részeire bomlik.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## Deklarálás és szétbontás egyszerre

Egy tuple-t egyszerre is deklarálhatsz és bonthatsz szét.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## Az egységtípus `()`

Az egységtípus egy különleges típus a Cairo-ban, amelynek csak egyetlen értéke van: `()`.
Egy olyan tuple képviseli, amelynek nincsenek elemei.
Az egységtípus mérete mindig nulla, ráadásul garantáltan nem létezik a lefordított kódban.

A Cairo-ban minden kifejezés visszaad egy értéket, és ha egy kifejezés nem ad vissza semmit, akkor implicit módon `()`-t ad vissza.
Ez hasznos lehet azoknak a függvényeknek, amelyeknek vissza kell adniuk egy értéket, de nincs értelmes érték, amit visszaadhatnának.

## Nevesített tuple típus deklarálása

A nevesített tuple lehetővé teszi, hogy egy tuple-höz leíróbb típusaliast hozz létre, ami javítja a kód olvashatóságát.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

Ebben a példában a `Point` egy nevesített tuple típus, amely két előjel nélküli 32 bites egész számot képvisel, így a kód kifejezőbb lesz.
