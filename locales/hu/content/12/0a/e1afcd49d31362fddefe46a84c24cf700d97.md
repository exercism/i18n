# Bevezetés

A Perl egy programozási nyelv, amelyet Larry Wall alkotott meg, és amely először 1987-ben jelent meg.

## Csomagok és modulok

A csomag kód gyűjteménye, amelyet gyakran egy ugyanilyen nevű, `.pm` kiterjesztésű modulfájl tartalmaz.
A modul ezután beimportálható egy másik fájlba, jellemzően a `use` kulcsszóval.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Változók

Léteznek skalár (`$foo`), tömb (`@bar`) és hash (`%baz`) változók.
Az egyszerűség kedvéért itt csak skalár változókat használunk.
Egy skalár érték a következő lehet: egy string, egy szám, egy logikai érték vagy egy [hivatkozás][perlreftut] valamire.
Az érték hiányát az `undef` jelöli.


A `my` és az `our` kulcsszó a lexikális scope-ban deklarál egy változót, például `my $foo;`.
Az `our` hatására a változó egy ugyanilyen nevű csomagváltozó álneve is lesz.
A változók deklarálásának más módjai is vannak, amelyeket itt nem tárgyalunk.

Egy változónak az `=` operátorral adhatsz értéket, például `$foo = 1;`, és ezt megteheted a változó deklarálásával egy időben is, például `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Szubrutinok

A `sub` kulcsszó deklarál egy [szubrutint][perlsub].
A `return` kulcsszó kilép a szubrutinból, és a megadott értékeket adja vissza, vagy üres listát, ha nincs megadva semmi.
Ha nincs megadva `return`, a visszaadott értéket a hívott szubrutin kontextusa (skalár, lista vagy void) és az utolsó utasítása határozza meg.

```perl
sub hello () {
    return 'Hello, World!';
}
```

A Perl újabb verzióiban formális paramétereket adhatsz meg egy [szignatúrában][perlsubsig].
A paraméterlista skalár, tömb vagy hash változókat tartalmazhat.
Az üres paraméterlista azt jelenti, hogy a szubrutin nulla argumentumot fogad el.
A Perl régebbi verzióiban az argumentumokat a speciális `@_` változóból kellett kiolvasni, ezzel itt nem foglalkozunk.
