# string-összefűzés

A string-összefűzés teljesen szabályos Rubyban, de egy stringet gyakrabban állítunk össze [string-interpolációval](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Például:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
