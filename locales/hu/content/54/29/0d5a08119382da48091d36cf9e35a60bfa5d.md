# Bevezetés

## Összehasonlító operátorok

Az összehasonlító operátorok sok más nyelvhez hasonlóak.

Az egyenlőségvizsgálathoz a `==` (egyenlő) és a `!=` (nem egyenlő) operátort használjuk.

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

A nagyobb és kisebb operátorok szintén megszokottak.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Elágazás `if`-fel

Ez az `if` kifejezés teljes formája:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Minden feltétel körül kötelező a zárójel (`()`).
- A feltételnek Boolean `true` vagy `false` értékre kell kiértékelődnie.
  A Kotlinban nincs olyan „truthy” és „falsy” fogalom, mint amilyen néhány más nyelvben létezik.
- A kapcsos zárójelek (`{}`) elhagyhatók, ha csak egyetlen kifejezés van.
- Az `else if` és az `else` is elhagyható, és több `else if` blokk is szerepelhet.

Az `if` kifejezéssel értéket is „választhatsz”:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Alternatívák?

Szándékos döntés, hogy a Kotlinban _nincs_ a Javában megtalálható `? :` ternáris operátor.
Az `if ... else` tömör formáját érdemes használni:

```Kotlin
return if (isOK) goodValue else badValue
```
