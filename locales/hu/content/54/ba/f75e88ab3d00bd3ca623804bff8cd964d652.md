# Bevezetés

A Swift felsorolásai olyan mechanizmust kínálnak, amellyel új típusokat hozhatunk létre. Ezeket véges számú nevesített érték alkotja, amelyek további kapcsolódó információt hordozhatnak, és tulajdonságok, valamint metódusok kapcsolódhatnak hozzájuk.

## Felsorolások definiálása

A legalapvetőbb felsorolásokat az alábbiak szerint definiálhatjuk.

```swift
enum NESButton {
  case up
  case down
  case left
  case right
  case a
  case b
  case select
  case start
}
```

A rövidség kedvéért több eset is írható egyetlen sorba, vesszővel elválasztva, egyetlen `case` kulcsszóval.

```swift
enum NESButton {
  case up, down, left, right, a, b, select, start
}
```

Ez egy új, `NESButton` nevű típust definiál, melynek lehetséges értékei: `up`, `down`, `left`, `right`, `a`, `b`, `select` és `start`. Ezekre az értékekre úgy hivatkozhatunk, hogy a típus nevét egy pont (`.`) és az érték követi. Ha a típusnév kikövetkeztethető, csak a pont és az érték szükséges.

## Metódusok

A Swift többi típusához hasonlóan a felsorolások is tartalmazhatnak metódusokat, amelyek segítségével a felsorolás az aktuális értékére épülő funkciókat nyújthat.

A metódusok a függvényekhez hasonlóak, csak éppen a felsorolás törzsén belül vannak definiálva, és az aktuális felsorolásértékhez kötődnek. Elérésük _pontjelöléssel_ történik, ahol a felsorolásérték nevét egy pont (`.`) követi, majd a metódus neve és paraméterei.

A metóduson belül a felsorolásértékre `self` néven hivatkozhatunk, a típus-aláírásban pedig, ha paraméterként elfogadunk vagy visszaadunk egy felsorolásértéket, a típusra `Self` néven hivatkozhatunk.

### Kezdőértékek

A kezdőértékek speciális metódusok, amelyek egy felsorolásérték beállítására szolgálnak. Definíciójuk nagyon hasonlít egy metóduséhoz, csak éppen nincs `func` kulcsszó, nincs visszatérési típus, a névnek `init`-nek kell lennie, és a kezdőértéknek _muszáj_ egy felsorolásértéket rendelnie a `self`-hez. A kezdőértékeket vagy pontjelöléssel hívjuk meg, vagy a kezdőérték paramétereit átadva a felsorolás nevének.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```

### Nyers értékek

A felsorolások hordozhatnak magukkal egy belső értéket is, amelyet _nyers értéknek_ nevezünk. A nyers értékeknek mind ugyanolyan típusúnak kell lenniük, amelyet a felsorolás definíciójában deklarálunk. Így például Character értékeket rendelhetünk a `NESButton` felsorolásunkhoz a definíció módosításával:

```swift
enum NESButton: Character {
  case up = "⬆️"
  case down = "⬇️"
  case left = "⬅️"
  case right = "➡️"
  case a = "🅰️"
  case b = "🅱️"
  case select = "✅"
  case start = "🚦"
}
```

Itt a `: Character` tudatja a fordítóval, hogy a nyers értékek `Character` típusúak lesznek, és a nyers érték hozzárendelése minden érték után következik.

A nyers értékek elérhetők minden érték automatikusan generált `rawValue` tulajdonságán keresztül.

```swift
NESButton.left.rawValue
// => "⬅️"
NESButton.b.rawValue
// => "🅱️"
```

A Swift implicit módon rendelhet nyers értékeket `String` és `Int` nyers értékekhez. Ha a nyers érték típusa `String`, akkor a nyers érték implicit módon az érték nevéhez lesz rendelve Stringként, hacsak az implicit értéket felül nem írja egy explicit hozzárendelés.

Ha a nyers érték típusa `Int`, akkor a nyers érték implicit módon eggyel nagyobb lesz, mint az előző eset nyers értéke, hacsak felül nem írja egy explicit hozzárendelés. Az első eset alapértelmezett nyers értéke 0, hacsak másképp nem rendelkezünk.

```swift
enum Coin: String {
  case heads
  case tails = "eagle"
}

Coin.heads.rawValue
// => "heads"
Coin.tails.rawValue
// => "eagle"

enum Dwarf: Int {
  case grumpy, sleepy, sneezy, happy = 8, bashful, dopey, doc
}

Dwarf.grumpy.rawValue
// => 0
Dwarf.sneezy.rawValue
// => 2
Dwarf.happy.rawValue
// => 8
Dwarf.bashful.rawValue
// => 9
```
