# A tizedes törtekről

A tizedes törtek olyan számok, amelyekben a tizedesjel után egy vagy több számjegy áll.

```gleam
let float = 3.45
// -> 3.45
```

A tizedes törteknek is megvan a saját operátorkészletük.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

A tizedes törtekbe az áttekinthetőség kedvéért aláhúzásjeleket is beírhatsz.

```gleam
1_000_000.0 // One million
```

A tizedes törteknél tudományos jelölést is használhatsz:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
