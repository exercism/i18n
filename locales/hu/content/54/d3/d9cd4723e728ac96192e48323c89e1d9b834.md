# A témáról

A Gleamben a `case` kifejezéssel feltételesen futtathatsz kódot. A `case` kifejezéssel egy értéket egy vagy több _mintával_ lehet összevetni. Ilyen minta például a _literál minta_, amely egy értéket egy literál értékkel vet össze (például `1` vagy `"hello"`).

A `case` kifejezéseket a `case` kulcsszóval írjuk:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Bár ez más nyelvek `switch` utasításaihoz hasonlíthat, a mintaillesztés akkor mutatja meg igazán az erejét, ha más mintákat is használunk. Ilyen minta a _változóminta_, amellyel értéket rendelhetünk egy változóhoz. Ebben a példában az `i` változó a `number` értékét kapja, ha az nem `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Bizonyos esetekben további feltételt szeretnél adni egy mintához. Ezt _őrnek_ hívják, és az `if` kulcsszóval adhatod meg:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Teljesítménybeli okokból az őrökben csak egyszerű matematikai és Boolean-operátorok engedélyezettek, más függvények nem használhatók bennük.

A fenti példában nem minden lehetséges bemenethez tartozik illeszkedő minta. A fordító észleli ezt, és hibát jelez. Ezt _teljességvizsgálatnak_ nevezik. A figyelmeztetés elhárításához minden esetet kezelni kell. Erre az _eldobó minta_ használható, amely bármely értékre illeszkedik:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

A `case` kifejezés egy értéket fentről lefelé haladva vet össze a mintákkal, amíg illeszkedő mintát nem talál, majd végrehajtja a hozzá tartozó logikát. A minták sorrendje számít!
