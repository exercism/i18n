# Utasítások

Sakkrajongóként szeretnéd megírni a játék saját változatát. Igaz, máris rengeteg sakkimplementáció elérhető az interneten, de a tiéd egyedi lesz!

De mielőtt szabadjára engednéd a fantáziádat, a legalapvetőbb dolgokkal kell kezdened. Kezdjük a tábla előállításával.

A sakktábla minden mezőjét egy betűből és egy számból álló pár azonosítja. A mezők függőleges oszlopait, amelyeket file-oknak neveznek, A-tól H-ig jelölik. A mezők vízszintes sorait, amelyeket rank-oknak neveznek, 1-től 8-ig számozzák.

## 1. A rank-tartomány meghatározása

Valósítsd meg a `rank_range()` függvényt. Egy egész számokból álló tartományt kell visszaadnia 1-től 8-ig.

```julia-repl
julia> rank_range()
# output omitted
```

## 2. A file-tartomány meghatározása

Valósítsd meg a `file_range()` függvényt.
Egy karakterekből álló tartományt kell visszaadnia a nagybetűs A-tól a nagybetűs H-ig.

```julia-repl
julia> file_range()
# output omitted
```

## 3. A rank-tartomány átalakítása rank-ok vektorává

Valósítsd meg a `ranks()` függvényt. Egy egész számokból álló vektort kell visszaadnia 1-től 8-ig.
Ne írd le kézzel a vektort, hanem a `rank_range()` függvény által visszaadott tartományból állítsd elő.

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. A file-tartomány átalakítása file-ok vektorává

Valósítsd meg a `files` függvényt. Egy karakterekből álló vektort kell visszaadnia 'A'-tól 'H'-ig.
Ne írd le kézzel a vektort, hanem a `file_range()` függvény által visszaadott tartományból állítsd elő.

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
