# Névjegy

Bár a `readonly` módosító megakadályozza, hogy egy mezőben lévő érték vagy hivatkozás felülíródjon, a referenciatípus tagjait nem védi.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Ahhoz, hogy egy referenciatípus minden tagja védve legyen, a mezőket `readonly`-vá tehetjük, és az automatikus tulajdonságokat `set` hozzáférő nélkül definiálhatjuk.

A Base Class Library (BCL) biztosít néhány csak olvasható gyűjteményváltozatot olyan esetekre, amikor követelmény, hogy egy gyűjtemény tagjai ne legyenek frissíthetők. Ezek burkolók formájában jelennek meg:

- [`ReadOnlyDictionary<T>`][ReadOnlyDictionary]
- [`ReadOnlyCollection<T>`][ReadOnlyCollection]

[ReadOnlyDictionary]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlydictionary-2
[ReadOnlyCollection]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlycollection-1
