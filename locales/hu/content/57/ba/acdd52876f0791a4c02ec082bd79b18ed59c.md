# Bemutatás

## Több visszatérési érték

A Swift-függvényekből [több értéket is vissza lehet adni][multiple-return-values] úgy, hogy a különböző értékekből létrehozunk egy tuple-t, és azt visszaadjuk.

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
  return (reverse: str.reverse, length: str.count)
}

reverseAndLength("Hello")
// => (reverse: "olleH", length: 5)
```

## A `return` elhagyása

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
  (reverse: str.reverse, length: str.count)
}
```

Ha egy függvény teljes törzse egyetlen kifejezés, [a `return` kulcsszó elhagyható][implicit-returns].

Megjegyzendő, hogy ez minden visszatérési típusra igaz, nem csak a több értéket visszaadókra.

[multiple-return-values]: https://docs.swift.org/swift-book/LanguageGuide/Functions.html#ID164
[implicit-returns]: https://docs.swift.org/swift-book/LanguageGuide/Functions.html#ID607
