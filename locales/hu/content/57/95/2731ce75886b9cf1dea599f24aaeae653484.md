# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat  | Típus    | Leírás                          |
| --------- | ---------- | -------- | ------------------------------- |
| `$a0`     | bemenet    | cím      | könyvszavak tömbje              |
| `$a1`     | bemenet    | egész    | a könyvek száma                 |
| `$v0`     | kimenet    | egész    | ár, centben megadva             |
| `$t0-9`   | átmeneti   | bármilyen| átmeneti tárolásra szolgál      |
