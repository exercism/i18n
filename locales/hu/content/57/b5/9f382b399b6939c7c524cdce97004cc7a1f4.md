# Utasítások

Boris nagy modellvasút-rajongó, és úgy döntött, hogy megosztja a szenvedélyét a világgal: hírlevelet indít. Először a hírlevél első számát küldi el azoknak a barátainak és ismerőseinek, akik osztoznak a hobbijában; az e-mail-címeiket egy szövegfájlban tárolja.

Tipp: a fájlműveletekhez használd a [simplifile](https://hexdocs.pm/simplifile/simplifile.html) modult.

## 1. E-mail-címek beolvasása fájlból

Valósítsd meg a `read_emails` függvényt. Ez egy olyan szövegfájl elérési útját kapja, amelyben soronként egy-egy e-mail-cím szerepel, és visszaadja a fájlban lévő e-mail-címek listáját.

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. Naplófájl létrehozása íráshoz

Az e-mail küldése olyan feladat, amely sok kiszámíthatatlan ok miatt meghiúsulhat, például egy elírt e-mail-cím vagy átmeneti hálózati probléma miatt. Hogy biztos lehess benne, hogy az e-maileket újra el tudd küldeni minden barátodnak anélkül, hogy duplikátumokat küldenél, naplóznod kell azokat az e-mail-címeket, amelyek már megkapták az e-mailt. Ehhez egy naplófájlra lesz szükséged.

Valósítsd meg a `create_log_file` függvényt. Ez egy fájl elérési útját kapja, és létrehoz egy új, üres fájlt azon a helyen.

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. Elküldött e-mail naplózása

Valósítsd meg a `log_sent_email` függvényt. Ez egy naplófájl elérési útját és egy stringet kap, amely az e-mail-címet tartalmazza. Az e-mail-címet kiírja a fájlba, utána pedig egy sortörést.

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. A hírlevél elküldése

Most, hogy megvan az e-mail-küldési folyamat minden építőeleme, egyetlen függvényben kell összekapcsolnod őket.

Valósítsd meg a `send_newsletter` függvényt. Ez az e-mail-címeket tartalmazó fájl elérési útját, egy naplófájl elérési útját és egy névtelen függvényt kap, amely elküld egy e-mailt egy adott e-mail-címre.

Be kell olvasnia az összes e-mail-címet a megadott fájlból, és meg kell kísérelnie e-mailt küldeni mindegyikre. Ha az e-mailt küldő névtelen függvény `Ok` értéket ad vissza, írd ki az e-mail-címet a naplófájlba. Ügyelj rá, hogy ezt rögtön az e-mail elküldése után megtedd.

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
