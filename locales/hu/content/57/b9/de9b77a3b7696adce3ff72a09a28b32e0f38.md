# Kiegészítés az utasításokhoz

## Kimeneti formátum

A gyémántot nullával lezárt stringként írd ki, minden sor végén egy újsor karakterrel.

Egy példa a kimenetre: `"  A  \n B B \nC   C\n B B \n  A  \n"`

## Regiszterek

| Regiszter | Használat    | Típus   | Leírás                        |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | bemenet      | byte    | betű                          |
| `$a1`    | bemenet/kimenet | cím   | nullával lezárt eredmény string |
| `$t0-9`  | ideiglenes   | bármi   | ideiglenes tárolásra          |
