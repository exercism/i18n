# A Java telepítése

Ahhoz, hogy Java nyelven gyakorolhass az Exercism feladatain, az Exercism CLI-n és a kedvenc szövegszerkesztődön kívül a **Java Development Kit** (JDK) is kell.
A JDK egyszerre tartalmaz Java Runtime-ot _és_ fejlesztőeszközöket (közülük is leginkább a Java-fordítót).

Manapság sokféle JDK létezik, és ezek egy része nyílt forráskódú.
Az Exercismnél az [Eclipse Temurin by Adoptium][adoptium] használatát ajánljuk.

## Támogatott Java-verziók

Az Exercism Java-kurzusa a Java 25 LTS-t és a korábbi verziókat támogatja.

## Az Eclipse Temurin telepítése

Ha az Eclipse Temurint szeretnéd telepíteni a gépedre, nézd meg a kiváló [telepítési útmutatójukat][adoptium-installation-guide].
Itt megtalálod, hogyan telepítheted a JDK-t a kedvenc csomagkezelőddel, és letölthető telepítőkre mutató hivatkozásokat is találsz minden jelentős operációs rendszerhez.

## Java IDE-k

Sok ingyenes IDE érhető el Javához.
Íme néhány népszerű választás:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code a Java-bővítménnyel][vscode-java]
