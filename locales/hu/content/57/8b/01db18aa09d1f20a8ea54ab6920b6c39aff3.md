# Utasítások

Lamont egy Lisp-űrlény, aki a saját videojátékát szeretné megírni. Az egyik feladat, amelyben a segítségedet kéri, a csúcspontszám-lista vezetése.

## 1. A csúcspontszám-táblázat létrehozása

Definiálj egy `make-high-score-table` nevű függvényt, amely nem fogad argumentumot, és egy új, üres hash-táblázatra értékelődik ki:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. Játékos hozzáadása a táblázathoz

Ha játékost szeretnél hozzáadni a táblázathoz, definiálj egy `add-player` nevű függvényt, amely két argumentumot vár:
- a csúcspontszám-táblázatot
- a játékos nevét keywordként

Állítsd a játékos kezdő pontszámát nullára.

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. Játékos pontszámának beállítása

Ha be szeretnéd állítani egy játékos pontszámát, definiálj egy `set-score` nevű függvényt, amely három argumentumot vár:
- a csúcspontszám-táblázatot
- a játékos nevét keywordként
- a játékos pontszámát egész számként

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. Pontszám lekérdezése a táblázatból

Ha le szeretnéd kérdezni egy játékos pontszámát a táblázatból, definiálj egy `get-score` nevű függvényt, amely két argumentumot vár:
- a csúcspontszám-táblázatot
- a játékos nevét keywordként

Ez a függvény a játékoshoz tárolt pontszámra értékelődjön ki.
Ha ehhez a játékoshoz nincs tárolt pontszám, vagy a játékos még nincs benne a táblázatban, akkor az érték `0` legyen.

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. Játékos eltávolítása a táblázatból

Ha el szeretnél távolítani egy játékost a csúcspontszám-táblázatból, definiálj egy `remove-player` nevű függvényt, amely két argumentumot vár:
- a csúcspontszám-táblázatot
- a játékos nevét keywordként

Ennek a függvénynek gördülékenyen kell kezelnie azt az esetet, amikor a játékost még nem adták hozzá a táblázathoz.
Nyilvánvaló, hogy miután egy játékost eltávolítottunk, ha lekérdezzük a pontszámát a táblázatból, az nulla lesz.

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
