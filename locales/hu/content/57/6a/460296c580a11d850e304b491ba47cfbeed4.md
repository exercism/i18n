# Utasítások

Ebben a feladatban megtakarítási számlákkal fogsz dolgozni.
A megtakarítási számlád egyenlege minden évben a kamatláb alapján frissül.
A bank által adott kamatláb a számládon lévő pénz mennyiségétől (az egyenlegtől) függ:

- 3,213% `0` dollárnál kisebb egyenleg esetén (az egyenleg még negatívabb lesz).
- 0,5% `0` dollárnál nagyobb vagy azzal egyenlő, és `1000` dollárnál kisebb egyenleg esetén.
- 1,621% `1000` dollárnál nagyobb vagy azzal egyenlő, és `5000` dollárnál kisebb egyenleg esetén.
- 2,475% `5000` dollárnál nagyobb vagy azzal egyenlő egyenleg esetén.

Négy részfeladatod van, mindegyik az egyenleggel és annak kamatlábával foglalkozik.

## 1. Számítsd ki a kamatlábat

Valósítsd meg az `interest_rate` függvényt, amely a megadott egyenleg alapján kiszámítja a kamatlábat:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. Számítsd ki a kamatot

Valósítsd meg a `yearly_interest` függvényt, amely a megadott egyenleg alapján kiszámítja a kamatot:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. Számítsd ki az egyenleg éves frissítését

Valósítsd meg az `annual_balance_update` függvényt, amely kiszámítja az egyenleg éves frissítését, figyelembe véve a kamatlábat:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. Számítsd ki a kívánt egyenleg eléréséhez szükséges éveket

Valósítsd meg a `years_until_desired_balance` függvényt, amely kiszámítja a kívánt egyenleg eléréséhez szükséges minimális évek számát, figyelembe véve, hogy minden évben kamat adódik az egyenleghez.
Ez azt jelenti, hogy az egyenleg egy év után: kezdő egyenleg + a kezdő egyenleg kamata.
A második év utáni egyenleg az egy év utáni egyenleg + az egy év utáni egyenleg kamata.
És így tovább, amíg az aktuális év egyenlege nem lesz nagyobb vagy egyenlő, mint a cél egyenleg.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

Vedd figyelembe, hogy a visszaadott érték egy `int`.
