# Bevezetés

Az `OpenStruct` segítségével könnyedén létrehozhatsz egy objektumot egy `Hash`-ből.
Ahelyett, hogy `Hash`-kulcsokkal kellene elérnünk az értékeket, az `OpenStruct` metódusokkal teszi lehetővé azok elérését és beállítását.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ennek a megközelítésnek az egyik előnye, hogy a blokk szintaxis használatakor kihasználhatunk egy rövidítést.
Ha egy blokk csak egyetlen metódust hív meg, akkor a blokkot lecserélheted a `&:` jelre, amelyet a metódus neve követ.
Például ez a két sor ugyanazt jelenti:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Standard könyvtár

A korábbi feladatokban látott osztályok mind a Ruby Core könyvtárához tartoztak.

Az OpenStruct a Ruby Standard könyvtárának a része (ezt gyakran csak „stdlib” rövidítéssel emlegetik): olyan osztályok gyűjteménye, amelyek segítségével többek között dátumokkal, JSON-nal és hálózatkezeléssel dolgozhatsz.
Emellett hasznos funkciókat is kínál, amelyekkel könnyebb dolgozni a kódoddal.

Ha olyan osztályokat használsz, amelyek nem a Core könyvtárból származnak (a saját kódod más fájlokban, a stdlibből származó osztályok vagy külső függőségek), akkor azokat a `require` metódussal kell importálnod, mielőtt használhatnád őket.
Például:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
