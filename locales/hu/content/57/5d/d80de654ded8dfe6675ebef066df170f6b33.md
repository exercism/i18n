# Bevezetés

A Rustban minden olyan típus, amely implementálja az [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) traitet, iterátorként kezelhető.
A Rust beépített [`collections`](https://doc.rust-lang.org/std/collections/index.html) gyűjteményei az `iter`, `iter_mut` és `into_iter` metódusokkal alakíthatók át iterátorokká.
Az iterátorok sok [hatékony metódust](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods) kínálnak, például a `collect`, `map`, `filter` és `fold` metódust, amelyekkel műveleteket végezhetsz az adataidon.

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
