# Tippek

## Általános

- [Metódusok túlterhelése C#-ban][member-overloading].
- A [string-interpoláció][string-interpolation] használható a leíró szövegek formázására.

## 3. Az utazási mód leírása

- A feltételes logikához használhatsz egy [egyszerű feltételt][if-statement].

## 4. Egy karakter leírása, aki egy úti cél felé utazik

- Újra felhasználhatod a meglévő leíró funkciót.
- Használhatsz [kifejezéseket interpolált stringekben][string-interpolation-expressions], ami azt jelenti, hogy metódusokat hívhatsz közvetlenül a string interpolált részeiben.

## 5. Egy karakter leírása, aki egy úti cél felé utazik az utazási mód megadása nélkül

- Újra felhasználhatod a meglévő funkciót, amely explicit utazási módot vár.
- Az [opcionális paraméterek][optional-arguments] segítségével leegyszerűsítheted a szükséges kód mennyiségét.
