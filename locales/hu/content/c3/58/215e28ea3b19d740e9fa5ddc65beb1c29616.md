# Tesztek

## A tesztek futtatása

1. Tölts le egy feladatot:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Lépj be a feladat könyvtárába:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Futtasd a teszteket:

    ```bash
    $ ./gradlew test
    ```

A legtöbb feladatnál alapértelmezés szerint csak az első teszt fut le.  
A többi teszt `@Ignore` jelöléssel van ellátva, ezért kimaradnak.  
Ahogy megoldasz egy tesztet, vedd le az `@Ignore` jelölést a következőről, és haladj tovább.

Ez a tesztvezérelt fejlesztés (röviden TDD) bevett gyakorlata.
Arra szolgál, hogy egyszerre csak egy problémán dolgozz.
