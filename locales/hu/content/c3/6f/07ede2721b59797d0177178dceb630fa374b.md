# Telepítés

## A Clojure CLI telepítése
A Clojure parancssori eszközöket biztosít, amelyekkel elindíthatsz egy Clojure REPL-t, használhatsz Clojure- és Java-könyvtárakat, valamint elindíthatsz Clojure-programokat.

Ha telepítened kell a Java-t, az [Adoptium Temurin 17](https://adoptium.net/) használatát javasoljuk.

### Linux
Győződj meg róla, hogy a következő függőségek telepítve vannak: `bash`, `curl`, `rlwrap` és `Java`.
A Clojure-t kétféleképpen telepítheted:

1. LinuxBrew, amihez [Homebrew](https://brew.sh/) kell

```bash
brew install clojure/tools/clojure
```

2. Telepítő szkript

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew Mac OS X-hez
Telepítsd a parancssori eszközöket a brew segítségével a [clojure/tools](https://github.com/clojure/homebrew-tools) tapről:

```bash
brew install clojure/tools/clojure
```

#### Java

A Java bármelyik disztribúciója megfelel. Ha szükséges, a Temurin a brew segítségével telepíthető:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

A Clojure Windows alatti támogatása nemrég jelentősen javult. Korábban a WSL2 használatát javasoltuk, ami remekül működik, mára viszont van PowerShell-telepítő is. A Clojure Windows alatt jelenleg alfa állapotban van, az ismert hibákat a [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues) oldalon találod.

Győződj meg róla, hogy a Java telepítve van, és a `JAVA_HOME` környezeti változó be van állítva, majd futtasd:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

A Clojure Windows alatti telepítésének másik módja a [Scoop](https://scoop.sh/) csomagkezelő. A Scoop telepítéséhez nyisd meg a PowerShellt, és futtasd egymás után ezt a 2 parancsot:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Ahhoz, hogy a Clojure-t a Scoop segítségével telepítsd, először két fontos bucketet kell hozzáadnod:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

Most pedig készen állunk arra, hogy a Java-t és a Clojure-t a következő parancsokkal telepítsük:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

Ha a fenti lépések sikeresen lefutottak, a Clojure-t a következővel indíthatod el:

```sh
clj
```

## A Leiningen telepítése (opcionális)

Bár már nincs rá szükség, továbbra is támogatjuk a teljes körű projektkezelő eszközt, a [Leiningen](https://leiningen.org/)t. Számos hasznos feladatot kínál, például kényelmes tesztelést, buildeket és egy fejlettebb REPL-t.

1. Töltsd le a [lein szkriptet](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) vagy a [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) fájlt (Windows)
2. Helyezd a `$PATH`-ba, ahol a shell megtalálja (pl. `/usr/local/bin/`)
3. Tedd futtathatóvá (`sudo chmod a+x /usr/local/bin/lein`)
4. Futtasd a `lein` parancsot.
