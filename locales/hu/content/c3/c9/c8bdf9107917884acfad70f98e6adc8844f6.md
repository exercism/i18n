# Bevezetés

A Flags attribútum lehetővé teszi, hogy a diszkriminált unióban definiált értékek bitpozíciókként (azaz jelzőbitként) legyenek ábrázolhatók.
Jelzőbitként az ilyen értékek kombinálhatók, így egyetlen értékben több Boolean feltétel is ábrázolható.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Egy jelzőbitet a bitenkénti VAGY operátorral (`|||`) állíthatsz be, a törléséhez pedig a bitenkénti ÉS operátor (`&&&`) és a bitenkénti negáció operátor (`~~~`) kombinációját használhatod.
Egy jelzőbit állapotát a bitenkénti ÉS operátorral is ellenőrizheted, de a `HasFlag()` metódust is használhatod.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Az F# nyelvben elérhető bitenkénti operátorok teljes listáját a [bitenkénti operátorok összefoglalója][bitwise-operators] oldalon találod.

[bitwise-operators]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/bitwise-operators#summary-of-bitwise-operators
