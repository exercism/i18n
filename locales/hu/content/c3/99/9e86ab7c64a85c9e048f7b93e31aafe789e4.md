# Utasítások

Keresd meg az első N természetes szám összegének négyzete és négyzetek összege közötti különbséget.

Az első tíz természetes szám összegének négyzete
(1 + 2 + ... + 10)² = 55² = 3025.

Az első tíz természetes szám négyzeteinek összege
1² + 2² + ... + 10² = 385.

Az első tíz természetes szám összegének négyzete és négyzeteinek összege közötti különbség tehát 3025 - 385 = 2640.

Nem kell magadtól, az alapokból kiindulva hatékony megoldást találnod erre; a kutatás megengedett, sőt kifejezetten ajánlott. A probléma legjobb algoritmusának megtalálása kulcsfontosságú készség a szoftverfejlesztésben.
