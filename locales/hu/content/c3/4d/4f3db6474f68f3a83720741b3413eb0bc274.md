# Bevezetés

## Generikus típusok

A **generikus típus** olyan generikus osztály vagy interfész, amelyet típusokra paraméterezünk.
Ez lehetővé teszi, hogy a fordító kikényszerítse a típusbiztonságot az osztályon vagy az interfészen.

Vegyük szemügyre ezt a nem generikus `Container` interfészt:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Mivel `Object` típusokat fogad és ad vissza, bármilyen nem primitív típussal működik.
Ez azonban áldozattal jár, mert előfordulhat, hogy az egyik kódrészlet `Integer` értékekre számítva hívja meg a `get` metódust, miközben egy másik kódrészlet `String` értékeket adva hívja a `set` metódust, ami futásidejű kivételhez vezet.

A **generikus osztály** és a **generikus interfész** formátuma a következő:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

Az osztály vagy interfész neve után álló, csúcsos zárójelekkel (`<>`) határolt típusparaméter-szakasz adja meg a típusparamétereket (más néven típusváltozókat): `T1`, `T2`, ..., `Tn`.
Ezeket az osztály vagy interfész törzsében használhatod, hogy megkapd a generikus típusbiztonságot.

Íme a `Container` generikus változata:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

Létrehozásakor meg kell adnunk, milyen típust tárol, és a fordító kikényszeríti ezt a megszorítást:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```

## Listák

A **listák** a rendezett sorozatot megvalósító kollekciók Java-ban.
A tömbökkel ellentétben a [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) mérete növekedhet, hogy bármennyi elemet befogadjon.
Az egyik szabványos implementáció az `ArrayList`, amelyet egy átméretezhető tömb támogat.
Egy másik szabványos implementáció a `LinkedList` osztály, amelyet egy kétszeresen láncolt lista támogat.

A `List` lehet üres, vagy tetszőleges számú elemet tartalmazhat (az ismétlődőket is beleértve).
A `List` **generikus interfész**, amelynek típusa megmutatja, milyen típusú objektumokat tartalmazhat.
Például:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

A `List` számos hasznos metódussal rendelkezik elemek hozzáadásához, eltávolításához, lekéréséhez és egy elem meglétének ellenőrzéséhez:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
