## `jq` tippek

Ez a feladat arról szól, hogy fogunk egy bemeneti objektumot, és átalakítjuk egy új objektummá. Íme néhány beépített függvény, ami segíthet:

- [`to_entries`][x_entries]
  - ez a függvény bemenetként egy objektumot kap
  - egy _tömböt_ ad vissza, amelynek minden eleme egy `{"key": "K", "value": V}` objektum
    - minden `K` a bemeneti objektum egyik kulcsa
    - minden `V` a `K`-hoz tartozó érték.
- [`from_entries`][x_entries]
  - az inverz művelet
  - `{"key": K, "value": V}` objektumok tömbjét kapja, és egy objektumot épít belőlük

Egy példa:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

az alábbi kimenetet adja:

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
