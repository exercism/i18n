# Tippek

## Általános

- A `clojure.string` névtérben számos hasznos [stringkezelő függvény][string-ns] található.

## 1. Üzenet kinyerése egy naplósorból

- A [`split`][split] függvénnyel reguláris kifejezés mentén darabolhatsz fel egy stringet.
- A [`trim`][trim] függvénnyel eltávolíthatod a szóközöket egy string elejéről és végéről.

## 2. Naplószint kinyerése egy naplósorból

- Egy `string` a [`lower-case`][lower-case] függvénnyel alakítható kisbetűssé.

## 3. Naplósor újraformázása

- A [`str`][str] függvénnyel fűzhetsz össze stringeket.
