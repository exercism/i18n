# Egész számok

Az egész számok olyan számok, amelyek a `{..., -2, -1, 0, 1, 2, ...}` halmaz elemei.
Egy egész szám legnagyobb és legkisebb értékét az határozza meg, hogy milyen rendszeren fut a PHP.
A legtöbb modern rendszeren ez jellemzően 64 bites érték, ami azt jelenti, hogy `-9_223_372_036_854_775_808` és `9_223_372_036_854_775_807` közötti értékeket tud ábrázolni, a két végpontot is beleértve.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Az egész literálértékeket a 10-es számrendszertől eltérő számrendszerben is leírhatod, ha egy számrendszert jelölő előtagot teszel eléjük:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
