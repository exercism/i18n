# Bevezetés

A legtöbbször a Factor az iterációt olyan kombinátorokkal oldja meg, mint az `each`, a `map` és a `count`. Néha viszont a legtisztább módja egy számítás leírásának a **rekurzió**: egy szó, ami önmagát hívja.

## Rekurzív szó definiálása

Egy `:` definíció közvetlenül hívhatja önmagát:

```factor
: count-down ( n -- )
    dup 0 = [ drop ] [ dup . 1 - count-down ] if ;

5 count-down
! prints 5 4 3 2 1
```

## Elágazás üres és nem üres esetén

Az `if-empty` (a [`sequences`][sequences] része) a rekurzió természetes alapesete:

```
if-empty ( seq emptyquot nonemptyquot -- )
```

```factor
{ 4 0 9 } [ "empty" ] [ "got data" ] if-empty .
! => "got data"
```

Az `emptyquot` úgy fut le, hogy a (üres) sorozatot már elhasználta; a `nonemptyquot` pedig úgy, hogy a sorozat még a vermen van.

## `cond`: őrzött ágak láncolata

Amikor a rekurziódnak kettőnél több esete van, a `cond` (a [`combinators`][combinators] része) segít, hogy a kód olvasható maradjon:

```factor
: classify ( n -- label )
    {
        { [ dup 0 < ] [ drop "negative" ] }
        { [ dup 0 = ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

## Előrehivatkozások a `DEFER:` segítségével

Egy `:` definíció közvetlenül hívhatja önmagát, de amikor két szó *egymást* hívja, a Factor az elsőt már azelőtt látja, hogy a második létezne. A `DEFER:` lefoglal egy nevet, hogy az első definíció le tudjon fordulni:

```factor
DEFER: even?

: odd? ( n -- ? ) dup 0 = [ drop f ] [ 1 - even? ] if ;
: even? ( n -- ? ) dup 0 = [ drop t ] [ 1 - odd? ] if ;
```

A `DEFER:` akkor is hasznos, ha egy segédszót természetesebb az őt használó szó *után* olvasni.
