# Bevezetés

Az F# `char` típusa egy 16 bites érték, amely a szöveg legkisebb címezhető egységeit reprezentálja, és alapértelmezés szerint nem módosítható.

A `char` értékek literálként adhatók meg szimpla idézőjelek között:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

A string karakterek sorozata.

Egy adott `char` a stringből (nulla alapú) indexeléssel kérhető le:

```fsharp
"Exercism"[4] //  =>  'c'
```

Ha végigmegyünk egy stringen, minden lépésben egy `char`-t kapunk.

A következő példa a kényelem kedvéért egy magasabb rendű függvényt és egy névtelen függvényt használ.
Ezekkel a tanterv későbbi részében foglalkozunk részletesen, most azonban lényegében egy tömör módot adnak arra, hogy ciklust írjunk egy string karakterei fölött.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Ahogy fentebb látható, egy `char` átalakítható az `int` értékévé.
Ez más írásrendszereknél is működik (*legalábbis néha*):

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

A karakterek összehasonlításához a mögöttes Int16-ot használja:

```fsharp
'A' < 'D'  // =>  true
```

Ezenkívül egy `int` is átalakítható `char` értékké:

```fsharp
char 77  // => 'M'
```

A `System.Char` könyvtár tartalmazza a .NET nyelvtől elvárható metódusok teljes készletét, például a nagybetűssé és kisbetűssé alakítást:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
