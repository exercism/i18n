# Eszközök közreműködőknek

A tanulóknak csak az [INSTALLATION.md](INSTALLATION.md) fájlban felsorolt eszközökre van szükségük.
A közreműködőknek néhány további eszköz is kell, mert a kurzus szkriptjei ezeket használják:

- `git`, amivel klónozhatod a tárolót és pull requesteket nyithatsz.
- `jq`, amelyet a `bin/verify-exercises` és a `bin/add-practice-exercise` használ.
- `curl`, amelyet a `bin/fetch-configlet` használ.
- Python 3.11 vagy újabb, a tesztgenerátorhoz.
- `clang-format`, amelyet a tesztgenerátor futtat az általa írt fájlokon.
- `pre-commit`, amely minden commit előtt lefuttatja a tároló ellenőrzéseit.

Telepítsd őket a disztribúciódhoz tartozó paranccsal, majd kövesd a »A tároló beállítása« szakasz lépéseit.

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## A tároló beállítása

A tároló gyökeréből:

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
