# Kiegészítés az utasításokhoz

## Az Enumról

Az enum utasítással erősen típusos címkehalmazt hozhatsz létre.
Ezt a felsorolást a kódban anélkül használhatod, hogy értelmezni vagy helyesírási hibákat ellenőrizni kellene.

A felsorolásokat belül egész számok képviselik, kezdőértékük nulla.
Alapértelmezés szerint a PowerShell a lista első címkéjéhez a nulla értéket rendeli, a többi címkéhez pedig egymást követő egészeket.

Példa:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

Ha többet szeretnél megtudni az Enumról a powershellben, nézd meg az [Enum modul.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum) oldalt.
