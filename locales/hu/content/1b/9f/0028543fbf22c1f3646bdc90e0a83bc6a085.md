# Bevezetés

Az Elixir reguláris kifejezései a **PCRE** specifikációt követik (Perl-kompatibilis reguláris kifejezések), hasonlóan más népszerű nyelvekhez, például Java, JavaScript vagy Ruby esetében.

A `Regex` modul függvényeket kínál a reguláris kifejezésekkel való munkához. A `String` modul néhány függvénye szintén elfogad reguláris kifejezéseket argumentumként.

~~~~exercism/note
Ez a feladat feltételezi, hogy már ismered a reguláris kifejezések szintaxisát, beleértve a karakterosztályokat, kvantorokat, csoportokat és a rögzítéseket.

Ha fel szeretnéd frissíteni a reguláris kifejezésekkel kapcsolatos tudásodat, nézd meg ezeknek a forrásoknak az egyikét: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

## Sigilek

A reguláris kifejezések létrehozásának leggyakoribb módja a `~r` sigil használata.

```elixir
~r/test/
```

Vedd figyelembe, hogy az összes Elixir sigil támogatja a [különböző típusú határolójeleket][sigils], nem csak a `/` jelet.

## Illesztés

A `=~/2` operátorral olyan illesztést hajthatsz végre, amely `boolean` eredményt ad vissza. Másik lehetőségként a `Regex` modulban is vannak `match?/2` függvények, csakúgy, mint a `String` modulban.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## Rögzítés

Ha egy egyszerű Boolean-ellenőrzés nem elég, használd a `Regex.run/3` függvényt, hogy megkapd az összes rögzítés listáját (vagy `nil`-t, ha nem volt egyezés). A visszaadott lista első eleme mindig a teljes reguláris kifejezésre illeszkedő találat, a további elemek pedig az illesztett csoportok.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## Módosítók

A reguláris kifejezés viselkedése speciális jelzők hozzáfűzésével módosítható. Amikor sigilt használsz reguláris kifejezés létrehozására, a módosítókat a második határolójel után add meg.

A gyakori módosítók:
- `i` - az illesztést kis- és nagybetűktől függetlenné teszi.
- `u` - engedélyezi az Unicode-specifikus mintákat, például a `\p`-t, és hatására a `\w`, `\s` stb. karakterosztályok is illeszkednek az Unicode karakterekre.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
