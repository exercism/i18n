# Tesztek

Válaszd ki az aktuális operációs rendszeredet:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# A tesztek futtatása

## Windows

1. Nyisd meg a Command Promptot.

2. Töltsd le az első feladatot:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. Lépj be a feladat mappájába:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. Futtasd a teszteket:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(Ne aggódj, ha a tesztek az első futtatáskor elbuknak, minden feladatot így kezdesz.)*

5. Oldd meg a feladatot. 
    Olvasd át az `instructions.md` fájlt, és nézd meg, hogyan kell megoldani a feladatot ([megtekintés a GitHubon](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Sok szerencsét, jó szórakozást, és üdv a COBOL kurzuson!

----

## macOS

1. Nyiss meg egy terminálablakot.

2. Töltsd le az első feladatot:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. Lépj be a feladat mappájába:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. Futtasd a teszteket:

    ```
     $ bash test.sh
    ```
    *(Ne aggódj, ha a tesztek az első futtatáskor elbuknak, minden feladatot így kezdesz.)*

    Tipp: Ha olyan üzenetet kapsz, hogy hiányzik a `basename`, a [brew](https://brew.sh/) segítségével telepítheted a coreutils csomagot. (`brew install coreutils`)

5. Oldd meg a feladatot. 

    Olvasd át az `instructions.md` fájlt, és nézd meg, hogyan kell megoldani a feladatot ([megtekintés a GitHubon](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Sok szerencsét, jó szórakozást, és üdv a COBOL kurzuson!
