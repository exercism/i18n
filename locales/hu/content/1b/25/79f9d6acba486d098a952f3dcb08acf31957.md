# Utasítások

A feladatod, hogy tökéletes labirintusokat készíts Mickey és Minerva számára, olyanokat, amelyeknek csak egyetlen megoldásuk van, és nincsenek elszigetelt részeik.
Íme, amit tudnod kell:

- A labirintus téglalap alakú, a bejáratánál és a kijáratánál nyílással.
- A labirintusban szobák és folyosók vannak, amelyek derékszögben metszik egymást.
- A program két paramétert fogadjon el: a sorokat és az oszlopokat. A labirintus mérete 5 és 100 cella között legyen.
- Egy `x` oszlop széles és `y` sor magas labirintus `2x + 1` karakter széles és `2y + 1` karakter magas legyen.
- Ha nem adsz meg seedet, generálj véletlenszerű labirintust. Ha ugyanazt a seedet többször is megadod, a kapott labirintus minden alkalommal ugyanaz legyen.
- A falak rajzolásához használj [box-drawing][Box-drawing] karaktereket, a bal oldali bejárathoz és a jobb oldali kijárathoz pedig egy nyíl szimbólumot (⇨).

Itt az idő, hogy tökéletes labirintusokat készíts ezeknek a kalandvágyó egereknek!

## Példák

1. Egy kis négyzet alakú labirintus, 5x5 cella (vagy 11x11 karakter)

    ```text
    ┌───────┬─┐
    │       │ │
    │ ┌─┬── │ │
    │ │ │   │ ⇨
    │ │ │ ──┤ │
    ⇨ │ │   │ │
    ┌─┤ └── │ │
    │ │     │ │
    │ │ ────┘ │
    │         │
    └─────────┘
    ```

2. Egy téglalap alakú labirintus, 6x18 cella

    ```text
    ┌───────────┬─────────┬───────────┬─┐
    │           │         │           │ │
    │ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
    │ │       │ │ │ │   │     │ │   │   ⇨
    │ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
    │   │ │ │   │   │   │   │ │ │   │   │
    └── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
    ⇨   │   │       │ │   │   │ │   │   │
    ┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
    │ │   │   │ │ │ │   │   │   │     │ │
    │ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
    │   │       │       │     │     │   │
    └───┴───────┴───────┴─────┴─────┴───┘
    ```
