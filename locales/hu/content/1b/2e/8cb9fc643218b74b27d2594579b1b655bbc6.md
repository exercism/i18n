# Osztályok

Az osztályok központi fogalom az [objektumorientált programozásban][object-oriented-programming].
[A Crystalben minden objektum][everything-is-an-object], minden objektumnak van típusa, és bizonyos metódusokra tud válaszolni.
Az osztályok tervrajzok az objektumok létrehozásához: kezdőértéket adnak az állapotnak, például a változóknak, és megvalósítják a viselkedést, például a metódusokat.
Az objektumok az osztály példányai, amelyek tárolják az összes példányváltozót és állapotot.

## Az osztály definiálása

Egy osztályt a `class` kulcsszóval definiálunk, amelyet az osztály `UpperCamelCase` írásmóddal írt neve követ.

```crystal
class Account
end
```

## Példány létrehozása

Egy osztály példányának [létrehozásához][new-initialize] hívd meg a `new` metódust az osztályon.

```crystal
class Account
end

account = Account.new
```

A fenti példában az `account` változó az `Account` osztály egy példánya.

Példány létrehozásakor egy `initialize` nevű speciális metódus tölti be a konstruktor szerepét.
Ez akkor hívódik meg, amikor létrejön egy példány.
A konstruktor segítségével beállíthatod a példány kezdeti állapotát.
Az `initialize` metódus fogadhat argumentumokat, amelyeket példány létrehozásakor adunk át.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
Az `initialize` metódus nem adhat vissza értéket kézzel; helyette a `new` adja vissza az újonnan létrehozott példányt.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Példánymetódusok

A példánymetódus olyan metódus, amely egy osztály példányán érhető el, és azon a példányon hívható meg.
A példánymetódusokat a `def` kulcsszóval definiáljuk, utána a metódus neve következik.
Ezeket az osztály definícióján belül definiáljuk.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Példányváltozók

A [példányváltozók][instance-variable] olyan változók, amelyek a példány minden metódusában elérhetők.
Egy példányváltozó eléréséhez példánymetódust kell definiálnod.
Kezdőértéket a `initialize` metódusban adhatsz nekik.
A `@` előtaggal definiáljuk őket.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

A példányváltozókat az osztály definícióján belül is definiálhatod.

```crystal
class Account
  @age = 0
end
```

### Példányváltozók kezdőértékkel

A példányváltozóknak kezdőértéket adhatsz az `initialize` metódusnak átadott argumentummal.
Mivel a Crystal nem tudja kikövetkeztetni a kezdőérték beállításakor használt argumentum típusát, meg kell adnod azt.
Ha erről többet szeretnél olvasni, ezt olvasd el: [type-inference][type-inference].
A változó típusának megadásához a `:` szimbólumot használhatod, utána a típus következik.
Például ha egy `balance` nevű, `Int32` típusú példányváltozót szeretnél létrehozni, ezt írhatod: `@balance : Int32`.
Vagy ha egy `raining` nevű, `Bool` típusú példányváltozót szeretnél létrehozni, ezt írhatod: `@raining : Bool`.

Ezt többféleképpen is megvalósíthatod. Az egyik, hogy az `initialize` metódusban típussal együtt deklarálod az argumentumot, majd a példányváltozónak értékül adod az argumentumot, ahogy a következő példában:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Egy másik lehetőség, hogy a példányváltozó típusát az osztály definíciójában deklarálod `@<variable> : <Type>` formában, ahogy a következő példában:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### Rövidebb forma a példányváltozók kezdőértékének beállítására

Van egy rövidebb forma, amellyel közvetlenül az `initialize` metódus argumentumaiban adhatsz kezdőértéket a példányváltozóknak, ugyanezzel a szintaxissal: `@<variable> : <Type>`.
Ez egyesíti a példányváltozó értékadását az argumentumból és a példányváltozó típusának deklarálását.

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## Példányváltozók módosítása

A metódusok módosíthatják a példányváltozókat.
Ezek a metódusok az osztály példányán hívhatók meg.
Amikor egy metódus módosít egy példányváltozót, a változás csak abban a példányban jelenik meg, amelyen meghívtad a metódust.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Osztálymetódusok

Az [osztálymetódusok][class-methods] olyan metódusok, amelyeket az osztályhoz definiálunk, nem annak példányaihoz.
Lehetővé teszik olyan metódusok létrehozását, amelyek nem függenek a példány állapotától.
A `def` kulcsszóval definiáljuk őket, utána `self.<method name>` következik.
A `self` arra a névtérre hivatkozik, amelyből a `self`-et hívjuk.
Ebben az esetben ez az `Account` osztályra utal.
Ugyanazt jelentené, mintha `Account.` szerepelne, de a `self.` az ajánlott megoldás.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
