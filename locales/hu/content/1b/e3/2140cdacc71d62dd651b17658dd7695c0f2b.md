# Feltételes elágazások

A Crystalben vannak úgynevezett vezérlőkifejezések; ezekkel szabályozható, hogyan fut le a program, és igaz vagy hamis értéket vesznek fel.
Vannak operátorok, amelyekkel igaz vagy hamis értékeket hozhatunk létre; ezeket [egyenlőség- és összehasonlító operátoroknak][equality-and-comparison] nevezzük.

Két fő vezérlőkifejezés szabályozza, hogy melyik kód fut le és melyik nem, azaz hogy melyik ág fut le.

Ez a kettő az `if` és az `unless` kifejezés.

## Összehasonlító operátorok

Az összehasonlító operátorok értékeket hasonlítanak össze, és `true` vagy `false` értéket adnak vissza.
Ezekkel az operátorokkal csak két azonos típusú értéket lehet összehasonlítani.
Ha az értékek nem azonos típusúak, a fordító hibát dob.
Íme az összehasonlító operátorok listája, és egy-egy példa arra, mikor adnak `true` értéket:

| Metódus | Leírás                | Példa   |
| ------ | --------------------- | ------- |
| <      | kisebb, mint          | 4 < 5   |
| <=     | kisebb vagy egyenlő   | 4 <= 4  |
| >      | nagyobb, mint         | 3 > 1   |
| >=     | nagyobb vagy egyenlő  | 2 >= 2  |

## Egyenlőségoperátorok

Az egyenlőségoperátorok hasonlítanak az összehasonlító operátorokhoz, de arra szolgálnak, hogy megvizsgálják, két érték egyenlő-e.

A `==` operátor megvizsgálja, hogy két érték egyenlő-e, az érték típusát is beleértve.
Ha az értékek megegyeznek, `true`-t ad vissza, ellenkező esetben `false`-t.
A `==` operátor bármilyen típusú értéket össze tud hasonlítani bármilyen más típusú értékkel.
A `!=` ugyanígy működik, de `true`-t ad vissza, ha az értékek nem egyenlők, és `false`-t, ha egyenlők.

## Az űrhajó-operátor

Az űrhajó-operátor különleges összehasonlító operátor, a nevét pedig arról kapta, ahogy kinéz.
Abban a tekintetben különleges, hogy nem igaz vagy hamis értéket ad vissza, hanem egy számot.
`<=>` alakban írjuk, és két érték összehasonlítására használjuk.
`1`-et ad vissza, ha a bal oldali érték nagyobb a jobb oldalinál, `-1`-et, ha a bal oldali érték kisebb a jobb oldalinál, és `0`-t, ha az értékek egyenlők.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## Az if elágazás

Az [`if`][if] elágazással megvizsgálhatjuk, hogy egy adott feltétel igaz vagy hamis-e.
Ha a feltétel igaz, akkor lefut az if elágazáson belüli kód.
Az if elágazást az `end` kulcsszó zárja.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## Az unless elágazás

Az [`unless`][unless] elágazás nagyon hasonlóan működik az `if` elágazáshoz, de az `unless` elágazáson belüli kódot akkor futtatja, ha a feltétel hamis.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## Az else elágazás

Az `else` elágazás az `if` és az `unless` elágazással együtt használható.
Az `else` elágazás akkor hajtódik végre, ha az `if` ág vagy az `unless` ág nem hajtódik végre.

~~~~exercism/warning
Bár az `else` ág használható `unless,` mellett is, ezt nem ajánlott megtenni, mert rontja az olvashatóságot.
Helyette az `if !condition` használata javasolt `else` ággal.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## „Lépcsőzetes” if elágazások

Az `elsif` elágazás az if elágazással együtt használható.
Az `elsif` elágazás akkor hajtódik végre, ha az if ág nem hajtódik végre, és az `elsif` elágazás feltétele igaz.
Az `elsif` elágazásokat egymás után lehet fűzni, és az első igaz feltételhez tartozó ág fut le.
Az if elágazás végén egy else ág is állhat, amely akkor fut le, ha a korábbi ágak egyike sem volt igaz.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## A ternáris operátor

A Crystalben van ternáris operátor, amely egy egysoros if-else elágazás: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## Az if és az unless utótagként

Az if és az unless elágazás [utótagként][if-as-suffix] is használható; ez akkor hasznos, ha egyetlen kódsort szeretnél futtatni, amennyiben egy feltétel igaz.
Ehhez az if vagy unless elágazást a futtatni kívánt kód mögé kell tenni.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## Típusok feltételes elágazásokkal

Ha a különböző ágakban más-más típust rendelünk a változóhoz, a változó mindkét típust hordozni fogja.
Ennek az az oka, hogy a fordító nem tudja, melyik ág fog lefutni.
Ezt a többszörös értékadást, amelyet uniónak is neveznek, későbbi fogalmakban magyarázzuk el.
Ez a következő példában látható:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
