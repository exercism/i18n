# Kiegészítés az utasításokhoz

## A fa kiírása

Ez a feladat tartalmaz néhány előre meghatározott osztálymetódust, amelyek segítenek a fát szép formátumban kiírni.
Ezek fő célja, hogy segítsék a debuggingot, és nagyobb átláthatóságot nyújtsanak.
Ha az osztály többi részét helyesen implementálod, akkor kiírja neked a fát.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
