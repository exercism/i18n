# Részletesen

## Trailing closure

A Swift a closure-ök kezeléséhez egy további szintaktikai változatot is kínál, amelyet [trailing closure][trailing-closures] néven ismerünk. Trailing closure-ról akkor beszélünk, amikor egy függvény paraméterlistájának az utolsó paramétere függvénytípusú. Ilyenkor, ha closure-t adunk át, a closure a záró zárójel _után_ is írható, az argumentumcímke pedig elmarad. Ha a függvénynek csak egyetlen paramétere van, a zárójeleket teljesen el is hagyhatod.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```

## Több trailing closure

A Swift korábbi verziói csak egyetlen trailing closure-t engedélyeztek, az 5.2.4-es verziótól kezdve viszont már több trailing closure is használható. Ha egy függvény paraméterlistájának a végén egynél több closure található, a trailing closure szintaxissal mindegyiket a zárójeleken kívülre helyezheted. Azonban csak az első argumentumcímke marad el, a többit viszont fel kell tüntetned:

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> (),
              onFailure handleFailure: () -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  } else {
    handleFailure()
  }
}

fetchURL("https://www.swift.org") {
  print($0)
} onFailure: {
  print("Error: https://www.swift.org could not be fetched")
}
// prints the fetched html string on successful fetch or prints error message on failure
```

[trailing-closures]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID102
