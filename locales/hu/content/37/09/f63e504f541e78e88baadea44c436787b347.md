# Stringek

A Crystalben létezik egy [`String`][strings] nevű típus, amely a szöveg ábrázolására szolgál.
A Crystal stringjei Unicode-karakterek sorozatai.
A stringek immutable-ok, ami azt jelenti, hogy létrehozásuk után már nem változtathatók meg.
Ez azt jelenti, hogy minden alkalommal új string jön létre, amikor módosítasz egy stringet, így az eredeti string változatlan marad.

Egy string definiálásához dupla idézőjelet (`"`) használsz.

```crystal
"Hello World"
```

## Összefűzés

Két string összefűzéséhez a `+` operátort használd.
A `+` operátor egy új stringet ad vissza, amely a két stringet összefűzi.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Stringek és számok közötti átalakítás

A `to_i` metódus egy stringet egész számmá alakít.
Alternatívaként a `to_f` metódust is használhatod, amely lebegőpontos számot ad vissza.
Ha a string nem alakítható számmá, akkor `ArgumentError` kivétel keletkezik.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Egy egész vagy lebegőpontos szám a `to_s` metódussal alakítható stringgé.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpoláció

Az interpoláció kényelmes módja annak, hogy stringeket kapcsolj össze és kifejezéseket ágyazz be stringekbe.
Egy string interpolálásához a `#` karaktert használhatod, amelyet kapcsos zárójelek (`{}`) követnek, a kifejezést pedig a zárójelek közé írod.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

A Crystal automatikusan stringgé alakítja a kifejezés eredményét.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Méret

Ha tudni szeretnéd, hány karakterből áll egy string, a `size` metódust használhatod, amely a string hosszát adja vissza egész számként.
A string mérete a string egy tárolt tulajdonsága, ezért nem kell minden metódushíváskor kiszámolni, ami miatt nagyon gyors.

```crystal
"Hello World".size
# => 11
```

## Indexelés

Az indexelésről akkor beszélünk, amikor egy adott karaktert szeretnél kiolvasni egy stringből.
Ha egy karaktert szeretnél kiolvasni egy `String`-ből, a megszokott zárójeles jelölést használhatod.

~~~~exercism/note
A `[]` egy String példánymetódusként van megvalósítva, ahol az index a metódus argumentuma.
~~~~

Egy string első karaktere a 0. indexen van.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Ha a string végéről szeretnél karaktert kiolvasni, kivehetsz a string hosszából egyet, hogy megkapd az utolsó karakter indexét, az utolsó előtti karakterhez pedig a string hosszából kettőt, és így tovább.
Erre van egy egyszerűbb megoldás: használj negatív indexet, ahol az utolsó karakter a -1. indexen van, az utolsó előtti a -2. indexen, és így tovább.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### Részstring vizsgálata

A Crystal indexeléssel is támogatja annak vizsgálatát, hogy egy string tartalmaz-e egy részstringet.
Ugyanaz a zárójeles jelölés működik, csak index helyett egy részstringet adsz meg.
Ha a részstring megtalálható a stringben, akkor a részstringet kapod vissza, ellenkező esetben `NilAssertionError` kivétel keletkezik.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

Ha `Bool` értékkel szeretnéd jelezni, hogy megtalálható-e a részstring, akkor az `includes?` metódust használhatod.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## Escape-elés

Néhány karaktert nem lehet közvetlenül beírni egy stringbe, helyette escape szekvenciát kell használnod.
Ha például dupla idézőjelet szeretnél használni egy stringben, escape-elni kell a dupla idézőjelet.
A `\` karakterrel írhatsz escape szekvenciát: utána írod azt a karaktert, amelyet escape-elni szeretnél.

Ezek a speciális karakterek a Crystalben:

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | Riasztás                      |
| `\b`     | Visszatörlés                  |
| `\e`     | Escape                        |
| `\f`     | Űrlapelőtolás                 |
| `\n`     | Soremelés vagy újsor          |
| `\r`     | Kocsivissza                   |
| `\t`     | Vízszintes tabulátor          |
| `\v`     | Függőleges tabulátor          |
| `\\`     | Fordított perjel              |
| `\'`     | Szimpla idézőjel              |
| `\"`     | Dupla idézőjel                |
| `\377`   | Oktális ASCII-karakter        |
| `\xFF`   | Hexadecimális ASCII-karakter  |
| `\uFFFF` | Hexadecimális Unicode-karakter |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Többsoros stringek

Ha többsoros stringet szeretnél írni, ugyanazt a szintaxist használod, mint az egysoros stringnél, de minden sorhoz új sort kezdesz.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

A [Unicode][unicode] szabvány a szöveg kódolására, ábrázolására és feldolgozására szolgál a különböző írásrendszerekben.
A Unicode több mint 100 000 karaktert támogat, köztük betűket, írásjeleket, szimbólumokat és emojikat.

Mivel a Crystal Unicode-ot használ a stringekhez, például emojikat is tehetsz a stringekbe.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

Néha olyan karaktert szeretnél használni, amely nem elérhető például a szerkesztődben vagy a rendszeredben.
Ebben az esetben a Unicode escape szekvenciával írhatod le a karaktert.

```crystal
"\u{1F310}"
# => "🌐"
```
