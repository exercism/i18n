# Bevezetés

Minden Factor-forrásfájl deklarál egy *szókészletet* az `IN:` kulcsszóval, és a `USING:` kulcsszóval importálja az általa használt további szókészleteket.

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

A könyvtár elrendezése a pontokkal tagolt szókészletnevet követi:

- a `my-vocab` szókészlet helye: `my-vocab/my-vocab.factor`
- a `my-vocab.helpers` szókészlet helye: `my-vocab/helpers/helpers.factor`

A Factor szókészletbetöltője tranzitívan követi a `USING:` deklarációkat: amikor egy fájl, amelyet betöltesz, importál egy másik szókészletet, az a szókészlet automatikusan betöltődik.

Gyakran egy nagy rutint két szókészletre bontasz: egy segédszókészletre, amely kis, újrahasznosítható szavakat tartalmaz, és egy fő szókészletre, amely importálja őket, és összeállítja az eredményt.
