# Utasítások kiegészítése

## Kurzusspecifikus utasítások

A függvényeknek a szorzatot, valamint a faktorok tömbjének eltolását és hosszát kell visszaadniuk.
A faktorokat egyszerűen i32-ek párjaiként írjuk a memóriába:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

A legnagyobb egyjegyű palindromszorzat esetén ez így nézne ki:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
