# Névjegy

A [tuple-okat][tuple] gyakran használjuk információk csoportosítására; a listáktól abban különböznek, hogy fix méretűek, és különböző adattípusokat tárolhatnak.
A tuple-okat kapcsos zárójelekkel, `()` hozzuk létre, és gyakran arra használjuk őket, hogy egy függvényből több értéket adjunk vissza.

```haskell
tuple = (1, "abc", False)
```

Ez akkor jön jól, ha például egy koordinátát szeretnél tárolni egy kétdimenziós térben: ilyenkor tudod, hogy a tuple-nak mindig két eleme lesz, az x és az y koordináta.

```haskell
coordinate = (3, 4)
```

## Az elemek elérése

Elég gyakran rövid tuple-okkal dolgozol, és az elemeket a `fst` és `snd` függvényekkel érheted el.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
