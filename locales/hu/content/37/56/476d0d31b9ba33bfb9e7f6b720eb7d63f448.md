# Bevezetés

A programozásban elengedhetetlen, hogy szabályosan kezeljük a hibákat, így a váratlan helyzetek nem omlasztják össze a programot, és nem okoznak kiszámíthatatlan viselkedést.
A Cairo két fő mechanizmust kínál a hibakezelésre:

1. **Helyreállíthatatlan hibák** a `panic` kulcsszóval, amely azonnal leállítja a programot.
2. **Helyreállítható hibák** a `Result` típussal, amelyek segítségével a program kezelni tudja a hibákat, és reagálni tud rájuk.

## Helyreállíthatatlan hibák `panic` használatával

Néha a program olyan súlyos hibába fut, hogy nem tud tovább haladni.
Ilyen esetekben a Cairo a `panic` függvénnyel azonnal leállítja a végrehajtást.
Ez akkor hasznos, ha egy hiba, például egy tartományon kívüli index elérése lehetetlenné teszi, hogy a program értelmesen folytassa a működését.
A `panic` függvény egy `ByteArray` üzenetet fogad, amely leírja a hiba okát.

Például Cairoban:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

Ez a példa egy kikényszerített panicot mutat be, amely azonnal leállítja a programot egy üzenettel.

### Az `assert!` makró

Az `assert!` makró hasznos eszköz arra, hogy meghatározott feltételeket érvényesíts a kódodban.
Ha az `assert!` feltétele `false` értékre értékelődik ki, a program panicot vált ki egy `ByteArray` hibaüzenettel.
Ezt gyakran használjuk feltételezések ellenőrzésére fejlesztés közben, illetve annak biztosítására, hogy az értékek megfeleljenek bizonyos kritériumoknak.

Például:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

Ha `x` nem nagyobb nullánál, a program panicot vált ki a következő üzenettel: `"x must be greater than zero"`. Az `assert!` segít az invariánsok és az előfeltételek ellenőrzésében anélkül, hogy kézzel kellene hibakezelő kódot írnod.

## Helyreállítható hibák a `Result` típussal

Nem minden hiba kell, hogy leállítsa a programot.
Egyes hibákat szabályosan kezelhetünk, így a program folytathatja a működését.
A Cairo `Result` enumja képviseli ezeket a helyreállítható hibákat, és két változata van:

- `Result::Ok` a sikert jelzi.
- `Result::Err` egy hibát képvisel.

A `Result` használatával egy függvény visszaadhat sikeres értéket vagy hibát, így a hívó függvény eldöntheti, mi történjen ezután.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

Ebben a példában, ha `b` nulla, a függvény hibát ad vissza; egyébként az osztás eredményét adja vissza.
