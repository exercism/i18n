# Utasításkiegészítés

Ha a bemenet érvénytelen, üres hosszúságot adj vissza.

## Fenntartott címek

Az első string puffere a lineáris memória 1024-2047. bájtjait használja.
A második string puffere a lineáris memória 2048-3071. bájtjait használja.
A harmadik string puffere a lineáris memória 3072-4095. bájtjait használja.

A lineáris memória 0-1023. bájtjainak első szegmense szabadon használható.
