# Bevezetés

A Go-ban nem létezik az üres, a null vagy az undefined fogalma a változók értékeinél.
A kifejezett kezdőérték nélkül deklarált változók az adott típus nullaértékét kapják.

Az olyan primitív típusok, mint a Boolean értékek, a numerikus típusok és a stringek nullaértéke rendre `false`, `0`, illetve `""`.

A `nil` azonosító, ami a nullát jelenti, az összetettebb típusok, például a mutatók, függvények, interfészek, szeletek, csatornák és mapek nullaértéke.

A következő táblázat részletezi a Go típusainak nullaértékét.

| Típus     | Nullaérték |
| --------- | ---------- |
| Boolean   | `false`    |
| numerikus | `0`        |
| string    | `""`       |
| mutató    | `nil`      |
| függvény  | `nil`      |
| interfész | `nil`      |
| szelet    | `nil`      |
| csatorna  | `nil`      |
| map       | `nil`      |

Talán feltűnt, hogy a fenti táblázatból hiányoznak a struct típusok.
Ennek az az oka, hogy egy struct típus nullaértéke a mezőitől függ.
Egy struct akkor veszi fel a nullaértékét, amikor minden mezője felveszi a saját nullaértékét.
