## 1. Azonosítószám generálása

Minden szolgának van egy egyedi azonosítója, amely naponta változik, és attól függ, hány titkot ismernek, és hány órát alszanak.
Írnod kell egy függvényt, amely átveszi a napot (mint egy `Int`), és létrehoz egy azonosítógeneráló függvényt az adott napra.
Az azonosítógeneráló függvény két paramétert vár:

1. a birtokolt titkok száma
2. a szolga alvási óráinak száma

Az azonosítót a következőképpen számítjuk ki:

1. a birtokolt titkok számát megszorozzuk az alvási órák számával
2. az eredményhez hozzáadjuk a napot (amelyet egy `Int` reprezentál)

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. A megszerzett titkos tervek védelme titkos jelszóval

Miután megszerezted a titkos terveket, védened kell azokat, hogy csak azok szerezhessék vissza, akik ismerik a jelszót.
Ehhez implementálnod kell a `protectSecret(secret: String, password: String) : (String) -> String` függvényt.
Ez a függvény visszaad egy másik függvényt, amely lehetséges jelszavakat vár bemenetként.
Ha a megadott jelszó helyes, az új függvény visszaadja a rejtett titkot, de ha a jelszó helytelen, a függvény a következőt adja vissza: „Sorry. No hidden secrets here.”

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. Találd meg a titkos jelszót

Az UMBRA bázisán számos szoba van, amelyeket egy biztonsági őr őriz, aki elkéri tőled a titkos jelszót.
A titkos jelszó a szoba számától függ.
Sajnos az algoritmusnak csak a felét ismerjük, amellyel a jelszó kiszámítható.
A másik felét az egyik szolgától tudhatod meg.

Implementáld a `getPassword` függvényt, amely a következőket veszi át, és visszaadja a jelszót:

1. a szoba száma
2. a szolga függvénye, és visszaadja a titkos jelszót

A titkos jelszót úgy kapjuk meg, hogy meghívjuk a szolga függvényét egy másik függvénnyel, amely az általunk ismert algoritmust reprezentálja.
Az algoritmusunk része:

1. átvesz két számot, és összeadja őket
2. az eredményt megszorozza a szoba azonosítójával

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
