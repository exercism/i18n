# Utasítások

A tengerparti móló játéktermében te működteted a szerencsejátékokat. A látogatók kockát dobnak, a markolós gép nyereményt emel ki, a kártyaasztalnál pedig meg kell keverni a paklit és ki kell osztani a lapokat, mindezt a véletlen műveli. Az éjszaka végén szeretnél egy „visszajátszás” funkciót is, hogy egy vitatott játékot ugyanabból a seedből újra le lehessen játszani.

## 1. Dobj egy kockával

Definiáld a `roll-die` szót úgy, hogy átvegye az oldalak számát, és visszaadjon egy dobást az `1` és `sides` közötti tartományból (a határokat is beleértve).

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. Szerezz nyereményt

Definiáld a `pick-prize` szót úgy, hogy átvegyen egy nyereménysorozatot, és véletlenszerűen visszaadjon közülük egyet.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. Keverd meg a paklit

Definiáld a `shuffle-deck` szót úgy, hogy átvegyen egy paklit (egy sorozatot), és visszaadja úgy, hogy a lapok véletlenszerű sorrendben legyenek benne.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. Oszd ki a lapokat

Definiáld a `deal-hand` szót úgy, hogy átvegyen egy paklit és egy `n` darabszámot, majd visszaadjon `n` *különböző* lapot a pakliból.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. Visszajátszás seedből

Definiáld a `play-seeded` szót úgy, hogy átvegyen egy seedet és egy idézetet, majd futtassa le az idézetet egy olyan generátorral, amelynek a seedje ebből az egész számból indul, így ugyanaz a seed mindig ugyanazt az eredményt adja. Az idézet eredményét vissza kell adni a hívónak.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
