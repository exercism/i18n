# A tesztek futtatása

Egy feladat tesztjeinek futtatásához futtasd az `<exercise>.test` szkriptet a feladat könyvtárában:

```bash
tclsh <exercise>.test
```

A legtöbb feladatnál az első kivételével minden teszt „skipped” lesz.
Ez neked, a fejlesztőnek is lehetővé teszi, hogy tesztvezérelt fejlesztést folytass: csak annyit kódolj, amennyi ahhoz kell, hogy egyszerre egy tesztet teljesíts.
A kihagyást vezérlő utasítások felülírásához a tesztcsomag futtatása előtt állítsd a `RUN_ALL` környezeti változót egy érvényes Tcl igaz értékre \[1\]:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: A Tcl igaz/hamis értékeit a C könyvtári függvény man oldala dokumentálja: [Tcl_GetBoolean][bool].

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
