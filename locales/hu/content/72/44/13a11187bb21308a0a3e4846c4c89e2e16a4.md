# Bevezetés

A Pythonban a `None` gyakran egy érték hiányát jelöli: egy `null` (üres) változó, objektum vagy argumentum definiálására szolgáló helyőrző.

Ha hallottál már a `NULL` vagy `nil` típusról, vagy használtad is ezt a típust más programozási nyelvben, akkor a `None` ilyen használata a Pythonban ismerős lesz számodra. A `None` segít olyan változókat vagy függvényargumentumokat deklarálni, amelyeknek még nincs értékük. Ezeket később szükség szerint újra hozzárendelheted konkrét értékekhez.

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

A `None` `False` értéket ad, ha feltételvizsgálatban használod, ezért hasznos egy érték, _bármilyen_ érték jelenlétének vagy hiányának ellenőrzésére. Ez egy gyakran használt minta, amikor egy függvény vagy folyamat esetleg visszaad egy hibaobjektumot vagy üzenetet.

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
