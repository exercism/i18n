# Részletek

## Összehasonlító operátorok

Az [összehasonlító operátorok][comparison-operators] két azonos típusú értéket hasonlítanak össze, és `Bool` értéket (`true` vagy `false`) adnak vissza.
Ha eltérő típusú értékeket próbálsz összehasonlítani, a fordító hibát jelez.

A Swift szabványos összehasonlító operátorai a következők:

| Operátor | Leírás                   | Példa           |
| -------- | ------------------------ | --------------- |
| `==`     | Egyenlő                  | `1 == 1` (igaz) |
| `!=`     | Nem egyenlő              | `1 != 2` (igaz) |
| `<`      | Kisebb, mint             | `4 < 5`  (igaz) |
| `<=`     | Kisebb vagy egyenlő      | `4 <= 4` (igaz) |
| `>`      | Nagyobb, mint            | `3 > 1`  (igaz) |
| `>=`     | Nagyobb vagy egyenlő     | `2 >= 2` (igaz) |

## `if` és `else` elágazások

A [feltételes utasítás][conditional-statement] egy feltétel alapján futtat kódot attól függően, hogy a feltétel `true` vagy `false` értékre értékelődik ki.
A leggyakoribb feltételes utasítás az [`if` elágazás][if], amely csak akkor futtat egy kódblokkot, ha a feltétel `true`.
Egy `if` elágazást az `if` kulcsszóval írsz le, utána a feltétel következik, majd a kapcsos zárójelbe zárt kódblokk:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Az `if` összekapcsolható egy `else` ággal, hogy alternatív kódot futtass, amikor a feltétel `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Ha több feltételt szeretnél egymás után ellenőrizni, fűzd láncba az elágazásokat `else if` használatával.
Az `if` elágazáshoz nem kötelező `else` ág, de hozzáadhatsz egyet, hogy kezeld azokat az eseteket, amikor egyik feltétel sem teljesül:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## `if` kifejezések

A modern Swiftben az `if` elágazások kifejezésként is használhatók, amelyek értéket állítanak elő.
Minden ág kiértékelődik egy értékre, így könnyen rendelhetsz értéket feltételesen:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
