# Utasítások

Ebben a feladatban megtakarítási számlákkal fogsz dolgozni.
A megtakarítási számlád egyenlege minden évben a kamatlába alapján frissül.
A bank által adott kamatláb attól függ, mennyi pénz van a számládon (az egyenlegeden):

- 3.213% `0` dollárnál kisebb egyenleg esetén (az egyenleg még negatívabb lesz).
- 0.5% `0` dollárnál nagyobb vagy azzal egyenlő, és `1000` dollárnál kisebb egyenleg esetén.
- 1.621% `1000` dollárnál nagyobb vagy azzal egyenlő, és `5000` dollárnál kisebb egyenleg esetén.
- 2.475% `5000` dollárnál nagyobb vagy azzal egyenlő egyenleg esetén.

Négy részfeladat vár rád, mindegyik az egyenlegeddel és annak kamatlábával foglalkozik.

## 1. Számítsd ki a kamatlábat

Valósítsd meg az `InterestRate()` függvényt, amely a megadott egyenleg alapján kiszámítja a kamatlábat:

```go
InterestRate(200.75)
// => 0.5
```

Vedd figyelembe, hogy a visszaadott érték `float32` típusú.

## 2. Számítsd ki a kamatot

Valósítsd meg az `Interest()` függvényt, amely a megadott egyenleg alapján kiszámítja a kamatot:

```go
Interest(200.75)
// => 1.003750
```

Vedd figyelembe, hogy a visszaadott érték `float64` típusú.

## 3. Számítsd ki az éves egyenlegfrissítést

Valósítsd meg az `AnnualBalanceUpdate()` függvényt, amely a kamatlábat figyelembe véve kiszámítja az éves egyenlegfrissítést:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

Vedd figyelembe, hogy a visszaadott érték `float64` típusú.

## 4. Számítsd ki, hány év kell a kívánt egyenleg eléréséig

Valósítsd meg a `YearsBeforeDesiredBalance()` függvényt, amely kiszámítja, hogy minimálisan hány év szükséges a kívánt egyenleg eléréséhez, figyelembe véve, hogy minden évben kamat adódik az egyenleghez.
Ez azt jelenti, hogy az egy év utáni egyenleg: kezdő egyenleg + a kezdő egyenleg kamata.
A második év utáni egyenleg: az egy év utáni egyenleg + az egy év utáni egyenleg kamata.
És így tovább, amíg az adott évi egyenleg nagyobb vagy egyenlő nem lesz, mint a cél-egyenleg.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

Vedd figyelembe, hogy a visszaadott érték `int` típusú.
