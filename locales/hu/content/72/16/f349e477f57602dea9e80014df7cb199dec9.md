# Telepítés

## Telepítési lehetőségek

Az Unison aktuális kiadása elérhető Mac OS X, 64 bites Linux és Windows felhasználók számára! Reméljük, hogy ha kipróbálod az Unisont, eljössz beszélgetni velünk az Exercism fórumára vagy a [Unison Discordra](https://unison-lang.org/discord). Gyere, tedd fel a kérdéseidet, és jelentsd, ha problémákba ütközöl! Szeretnénk, hogy barátságos és pozitív élményben legyen részed, amikor elkezdesz ismerkedni vele! 😊

Az Unison letölthető a [homebrew](https://brew.sh/) segítségével, a [Nixszel](https://github.com/ceedubs/unison-nix/#usage), vagy közvetlenül a csomagolt binárisokkal. Ezeket a letöltési lehetőségeket a [weboldalunk telepítési útmutató oldala](https://www.unison-lang.org/learn/quickstart/#installation-options) írja le. Ha már telepítetted az UCM-et, gyere vissza ide!

### 1. lehetőség: Homebrew használata

Először [telepítsd a homebrew-t](https://brew.sh/), ha még nem tetted meg.

Utána írd be ezeket a parancsokat a parancssorba:

```
brew tap unisonweb/unison
brew install unison-language
```

Ez telepíti az Unison codebase manager futtatható fájlt, az `ucm`-et. Ha egy korábbi verzióról frissítesz, csak írd be a következőt:

```
brew upgrade unison-language.
```

Megjegyzés: ha ezen a ponton a GitHub felhasználónevedet és jelszavadat kéri, győződj meg róla, hogy helyesen írtad be a unisonweb/unison nevet.

### 2. lehetőség: Kézi telepítés Mac és Linux felhasználóknak

[A Linux és Mac kézi telepítéséhez tartozó linkek itt találhatók](https://www.unison-lang.org/learn/quickstart/#installation-options), a megfelelő Linux és Mac kézi letöltési szakaszban.

Egy ehhez hasonló parancsot fogsz futtatni a shelleben, de a legfrissebb binárist a fenti link tartalmazza:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### 3. lehetőség: Kézi telepítés Windows felhasználóknak

1. A legjobb eredmény érdekében állítsd be a „Windows Terminal” alkalmazást alapértelmezett terminálalkalmazásnak. Keresd meg a „Terminal” elemet a Beállításokban, vagy kövesd [ezt az útmutatót.](https://bit.ly/3IXwdlY)
2. Ha nem vagy benne biztos, hogy már megvan, telepítsd a Gitet:
  * winget használatával: `winget install --id Git.Git -e --source winget`
  * Ha Windows 10-en vagy, és nincs winget telepítve, telepítheted [a Microsoft Store-ból](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1), majd futtasd a fenti parancsot.
3. [Töltsd le az UCM-et az itt megadott linkkel](https://www.unison-lang.org/learn/quickstart/#installation-options), és csomagold ki egy általad választott helyre.
4. Futtasd az `ucm.exe`-t

### 4. lehetőség: Telepítés Nixszel
Menj a [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) oldalra, és kövesd az ottani readme utasításait.

## Hozd létre az Unison kódbázisodat

Futtasd az `ucm`-et, hogy inicializálj egy Unison kódbázist a `$HOME/.unison` könyvtárban. Itt fogja az Unison tárolni a függvénydefiníciókat, típusokat, névtereket és így tovább. Alapértelmezés szerint az Unison Codebase Manger (rövidítve „UCM”) elkezdi letölteni a `base` nevű szabványos könyvtárat, amelyet az Unison kód írásához fogsz használni. Ez eltarthat egy pillanatig! 🕰

## Az Unison munkafolyamat

Amikor Unison kódot szeretnél írni, kiadod az `ucm` parancsot, amellyel elindítod a codebase managert. Az UCM ezután figyelni fogja minden `.u` kiterjesztésű fájl változásait abban a könyvtárban, ahonnan elindítottad. Például előfordulhat, hogy függvényeket implementálsz egy `scratch.u` nevű fájlban, egy `~/exercism/unison/my-exercise/` nevű könyvtárban. Ilyenkor lépj be a `cd` paranccsal a `~/exercism/unison/my-exercise/` könyvtárba, és futtasd az `ucm`-et. Ezzel biztosítod, hogy az UCM figyelje a `scratch.u` fájlod változásait.

Ha valaha is bizonytalan vagy benne, hogy az `ucm` melyik könyvtárban figyeli a fájlváltozásokat, azt a cli indításakor megjelenő üdvözlőképernyő kiírja.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[További munkafolyamat-tippeket itt találsz!](https://exercism.org/docs/tracks/unison/workflow)

## Szerkesztőtámogatás

Bármilyen szövegszerkesztőt használhatsz a `.u` fájljaid írásához. Az Unison [támogatja az LSP-t](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown), így a kedvenc IDE-d olyan dolgokban segíthet, mint a típusok megjelenítése ráhúzáskor és az automatikus kiegészítés. Az alábbiakban néhány népszerű, Unisont támogató szerkesztőt sorolunk fel:

### Vim

[vim-plug](https://github.com/junegunn/vim-plug) használatával:

1. Telepítsd a [`vim-plug`](https://github.com/junegunn/vim-plug)-ot, ha még nem tetted meg.
2. Írd hozzá a következőt a .vimrc fájlodhoz: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. Add ki a vim `:PlugInstall` parancsát.

További információért futtasd a `:help unison` parancsot a vimből, vagy nézd meg az [online súgót](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt).

### Atom
A konzolból futtasd:

```
apm install unisonweb/atom-unison
```

### VS Code

1. Nyisd meg az Extensions nézetet úgy, hogy az Activity Bar Extensions ikonjára kattintasz a VS Code oldalán, vagy a ⇧⌘X billentyűkombinációval.
2. Keresd meg az „unison” kifejezést
3. Telepítsd a [Unison VS Code-bővítményt](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)

### Emacs
Telepítsd a [`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs)-ot.
