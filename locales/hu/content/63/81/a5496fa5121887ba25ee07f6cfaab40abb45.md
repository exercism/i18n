# Kiegészítés az utasításokhoz

A lencséket nem használják sok mindenre a Rocban, mert a rekordfrissítési szintaxis szépen lefedi a legtöbb felhasználási esetet. Vegyük például ezt az egymásba ágyazott rekordot:

```roc
bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
```

Most pedig adjunk Bobnak egy hajvágást:

```roc
new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
```

Lencsékre nincs szükség! Ennek ellenére, bár a lencsék ritkák a Rocban, más nyelvekben, például Haskellben és Scalában gyakoriak, ezért kíváncsi lehetsz rá, hogyan lehetne megvalósítani őket Rocban. Ez emellett jó módja annak is, hogy gyakorold néhány haladó Roc-lehetőséget, például a paraméterezett típusokat és a függvényeket tartalmazó rekordokat. Íme, így lehet ábrázolni egy lencsét Rocban:

```roc
Lens(whole, part) := {
	get : whole -> part,
	set : whole, part -> whole,
}
```

Ez egy paraméterezett típus: a `whole` és a `part` bármilyen típus lehet. A `whole` jellemzően egy rekord, a `part` viszont bármilyen mezőtípus lehet. A `get` mező egy olyan függvényt tartalmaz, amely visszaadja az adott `whole` egy konkrét `part`-ját, a `set` mező pedig egy olyan függvényt, amely az adott `whole` egy másolatát adja vissza, azzal a különbséggel, hogy egy konkrét `part`-ot a megadott `part`-ra cserél.

Például íme egy lencse, amellyel lekérheted vagy beállíthatod egy személy haját:

```roc
hair_lens = {
	get: |person| person.hair,
	set: |person, hair| { ..person, hair },
}
```

Ezzel a lencsével Bob hajára fókuszálhatunk, így:

```roc
bob_hair = bob |> hair_lens.get
```

És így megváltoztathatjuk a haját:

```roc
new_hair = { ..bob.hair, length: Short }
new_bob = bob |> (hair_lens.set)(new_hair)
```

Megjegyzés: a `hair_lens.set` körüli zárójelek kötelezőek: nélkülük a Roc egy `set` nevű függvényt keresne a `hair_lens` típusában.

A lencsék különösen akkor válnak hasznossá, amikor elkezded őket komponálni, mert így mélyen egymásba ágyazott részeket is le tudsz kérdezni és be tudsz állítani. Ezt egy ilyen függvény megvalósításával érheted el:

```roc
compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
```

Ha egyszer megvalósítottad ezt a függvényt, ezzel létrehozhatsz egy hajhossz-lencsét is, így:

```roc
length_lens = {
	get: |hair| hair.length,
	set: |hair, length| { ..hair, length },
}
hair_length_lens = compose(hair_lens, length_lens)

```

Most pedig adhatsz Bobnak még egy hajvágást:

```roc
set_hair_length = hair_length_lens.set
new_bob = bob |> set_hair_length(Short)
```

Az is lehet, hogy szeretnél megvalósítani egy olyan függvényt, amellyel bármilyen átalakítást alkalmazhatsz egy egymásba ágyazott részre:

```roc
over : Lens(whole, part), whole, (part -> part) -> whole
```

Ha megvalósítottad, így használhatod az `over` függvényt:

```roc
cut_hair = |current_length| match current_length {
	Long => Short
	Short => Bald
	Bald => Bald
}
new_bob = hair_length_lens |> over(bob, cut_hair)
```

Ebben a feladatban a tesztek azt ellenőrzik majd, hogy a kódod képes-e módosítani a következő egymásba ágyazott rekord különféle beágyazott részeit:

```roc
test_person : Person
test_person = {
	name: { forenames: "Jane Joanna", surname: "Doe" },
	birth: {
		born_at: { street: "Longway", house_number: 1024, place: "Springfield", country: "United States" },
		born_on: { year: 1984, month: 4, day: 12 },
	},
	address: { street: "Shortlane", house_number: 2, place: "Fallmeadow", country: "Canada" },
}
```

Azt javasoljuk, hogy először a Roc rekordfrissítési szintaxisával menj át a teszteken, aztán próbálkozz inkább lencsékkel.
