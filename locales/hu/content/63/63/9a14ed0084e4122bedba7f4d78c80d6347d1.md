# Elm szintaxis alapok 2

## Függvények exportálása

A függvények exportálásáról már volt szó az első fogalomban, most gyorsan átismételjük.

Az Elmben minden fájl egy modul, és minden más kód előtt tartalmaznia kell egy `module` utasítást.

A modulneveknek egyezniük kell a fájlnevükkel, tehát a `Calculator` modulnak a Calculator.elm fájlban kell lennie, a `Parser.Utils` modulnak pedig a Parser/Utils.elm fájlban.

Egy modulon belül minden definiált dolog privát scope-ban van, és kívülről nem érhető el, hacsak nem szerepel az `exposing` listában.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Függvények importálása más modulokból

A más modulokban definiált függvényeket importokon keresztül éred el.
Amikor importálsz egy modult, az összes általa exportált függvény elérhetővé válik.
Az viszont attól függ, hogyan importálod a modult, hogy miként éred el őket.

A minősített import az alapértelmezett; egy ilyen modul függvényét (például a `List` modul `map` függvényét) úgy éred el, hogy a modul nevét írod elé (`List.map`).

A nyílt import közvetlen hozzáférést ad a modul exportált függvényeihez, előtag nélkül. Az `exposing` kulcsszóval hozod létre őket, az exportálásnál használt kulcsszó tükörképeként. Exportálhatod az összes elérhető függvényt (a `..` segítségével), vagy csak bizonyosakat (például a `map`-et).

Importálhatsz típusokat és azok konstruktorait is más modulokból, ami egy későbbi fogalom.

A minősített importot érdemes előnyben részesíteni az átláthatóság érdekében és a névütközések elkerülésére.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Típusannotációk

A típusannotációt a `name : parameter types -> return type` formában adod meg, a paramétertípusokat szintén `->` választja el.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Zárójelekkel függvényparamétereket definiálhatsz (amelyek maguk is ugyanezzel a szintaxissal definiálódnak, innen ered a zárójelek szükségessége).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Számok

Az Elmben kétféle szám érhető el, amelyeket az `Int` és a `Float` típus definiál.
Az `Int` a pozitív és negatív egész számok halmazának felel meg.
A `Float` a valós számok halmazának felel meg, a számítógép pontossága által korlátozva.
A számokon értelmezett műveletek általában vagy az egyik, vagy a másik típuson működnek, a kettőt pedig nem lehet keverni.
Léteznek függvények a kettő közötti átalakításra, ilyen például a `toFloat`, amely `Int`-et alakít `Float`-tá, valamint a `round`, a `floor`, a `ceiling` és a `truncate`, amelyek egy `Float`-ot alakítanak `Int`-té, eltérő szemantikával.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## String-műveletek

A szavak és mondatok kódban való leírására az Elmnek van egy natív `String` típusa.
A string literálokat idézőjelek közé írod, például: `"Hello World!"`.
Alapértelmezés szerint elérhető egy string-összefűző operátor (`++`) és egy egyenlőségoperátor (`==`).

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

A legtöbb más string-függvény a `String` modulban van, amelyet importálnod kell.

https://package.elm-lang.org/packages/elm/core/latest/String
