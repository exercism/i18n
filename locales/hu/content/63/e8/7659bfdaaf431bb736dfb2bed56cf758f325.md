# Utasítások

Ebben a feladatban a klasszikus Pac-Man játék néhány szabályát kell Haskell-függvényekre fordítanod.

Négy szabályt kell lefordítanod, amelyek mind a játék állapotaihoz kapcsolódnak.

> Ne törődj azzal, hogyan származnak az argumentumok, csak arra összpontosíts, hogy az argumentumokat kombinálva a kívánt eredményt add vissza.

## 1. Határozd meg, hogy Pac-Man megeszik-e egy szellemet

Definiáld az `eatsGhost` függvényt, amely két argumentumot vesz át (_hogy aktív-e Pac-Mannél egy energiagolyó_, illetve _hogy hozzáér-e Pac-Man egy szellemhez_), és egy `Bool` értéket ad vissza, amikor Pac-Man képes megenni a szellemet.
A függvény csak akkor adjon vissza `True` értéket, ha Pac-Man energiagolyója aktív, és épp hozzáér egy szellemhez.

```haskell
eatsGhost False True
-- -> False
```

## 2. Határozd meg, hogy Pac-Man pontot szerez-e

Definiáld a `scores` függvényt, amely két argumentumot vesz át (_hogy hozzáér-e Pac-Man egy energiagolyóhoz_, illetve _hogy hozzáér-e Pac-Man egy ponthoz_), és egy `Bool` értéket ad vissza, ha Pac-Man pontot szerzett.
A függvény akkor adjon vissza `True` értéket, ha Pac-Man energiagolyóhoz vagy ponthoz ér hozzá.

```haskell
scores True True
-- -> True
```

## 3. Határozd meg, hogy Pac-Man veszít-e

Definiáld a `loses` függvényt, amely két argumentumot vesz át (_hogy aktív-e Pac-Mannél egy energiagolyó_, illetve _hogy hozzáér-e Pac-Man egy szellemhez_), és egy `Bool` értéket ad vissza, ha Pac-Man veszít.
A függvény akkor adjon vissza `True` értéket, ha Pac-Man hozzáér egy szellemhez, és nincs aktív energiagolyója.

```haskell
loses False True
-- -> True
```

## 4. Határozd meg, hogy Pac-Man nyer-e

Definiáld a `wins` függvényt, amely három argumentumot vesz át (_hogy Pac-Man megette-e az összes pontot_, _hogy aktív-e Pac-Mannél egy energiagolyó_, illetve _hogy hozzáér-e Pac-Man egy szellemhez_), és egy `Bool` értéket ad vissza, ha Pac-Man nyer.
A függvény akkor adjon vissza `True` értéket, ha Pac-Man megette az összes pontot, _és_ a 3. részben definiált argumentumok alapján nem veszített.

```haskell
wins False True False
-- -> False
```
