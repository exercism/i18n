# Bevezetés

A `Result` típus lehetővé teszi, hogy egy függvény egyetlen értéket adjon vissza, amely a következőket jelzi:
- Hogy a művelet sikeres volt-e vagy sikertelen
- Sikeres művelet esetén a művelet eredményértéke
- Sikertelen művelet esetén a hiba oka

## Használat

A `Result` típus egy generikus típus, amely két mögöttes típust tartalmaz:
- A sikeres művelet eredményének típusa
- A hiba típusa sikertelenség esetén

A `Result` típus emellett egy [diszkriminált unió][discriminated-union], amelynek a következő lehetséges esetei vannak:
* `Ok <value>` egy sikeres eredményt jelöl
* `Error <reason>` egy sikertelenséget jelöl

A következő függvény bemutatja, hogyan hozhatsz létre `Result` értéket:

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

Ebben a példában az `Ok` érték egy string (a megadott név), az `Error` érték pedig szintén egy string (a hiba oka, ember által olvasható formában).

## A `Result` érték tartalmának kiolvasása

Vizsgáld meg a következő típusdefiníciót és függvényszignatúrát:

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

Az `openFile` függvényt meghívó kód mintaillesztéssel kezelheti a sikeres és sikertelen eseteket, ahogy a következő példában:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
