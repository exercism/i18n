# Bevezetés

A `PHP 8.0.0`-tól elérhető **Union Type Declarations** egyetlen típus helyett több különböző típus értékeit is elfogadja. Az uniós típusdefiníciókban a típusokat a függőleges vonal (`|`) választja el egymástól.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

A PHP strict módban `TypeError` hibát dob, ha a beérkező paraméterek nem `float` vagy `int` típusúak. Nem strict módban pedig akkor dob típushibát, ha a beérkező paramétereket nem lehet `float`-tá vagy `int`-té alakítani.

Hasonlóképpen, ha a függvény nem a deklarált típusok egyikét adja vissza, a PHP futásidőben `TypeError` hibát dob.
