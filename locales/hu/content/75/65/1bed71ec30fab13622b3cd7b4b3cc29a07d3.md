# Entry API

Az Entry API gyakran a legidiomatikusabb módja egy map adatszerkezet tartalmának módosítására. Rusttól szokatlan módon azonban nem formalizálták traitként; csupán típusok és metódusok halmaza, amelyek a standard könyvtár map típusain vannak megvalósítva.

Alapvetően a `map.entry()` metódus egy `enum`-ot biztosít:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

Az előnyét a további, ezen az `enum`-on megvalósított metódusok adják. Ha például egy adott kulcshoz szeretnéd lekérni és esetleg módosítani az értéket, és az érték típusának alapértéke megfelelő, egyszerűen ezt teheted:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

A számlálóhoz hasonló alkalmazásoknál ez nagyon megkönnyíti a dolgunkat:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

Ha a típus alapértéke nem megfelelő az alkalmazásodhoz, saját konstans alapértéket adhatsz meg az `or_insert` segítségével, vagy kiszámíthatsz egyet az `or_insert_with` segítségével.

Bizonyos esetekben előfordulhat, hogy egy meglévő értéken szeretnél számítást végezni, mielőtt bármilyen lehetséges beszúrás megtörténne. Ezekben az esetekben az `and_modify` teszi ezt lehetővé. Ez az alkalmazás azonban meglehetősen ritka. Az `and_modify` metódust gyakrabban arra használják, hogy elkerüljék a dereferálás szükségességét:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

Néha hasznos közvetlenül az entryre match-elni. Ez megengedett:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

További információért lásd a [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) és a [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html) oldalt.
