# Utasítások

A Conda Airlines a programozás világának legnagyobb légitársasága, amely naponta több mint 10 000 járatot indít!

Jelenleg az összes ülést kézzel osztják ki az utasoknak, ezt automatizálni kell.

Felkértek _téged_, hogy készíts szoftvert az utasok üléskiosztásának automatizálására.
Elvárják, hogy a szoftvered memóriatakarékos és nagy teljesítményű legyen.

## 1. Generálj ülésbetűket

A Conda ülésbetűket szeretne generálni a repülőgépeihez.
Egy repülőgép üléssorokból áll.
Minden sorban _4 ülés_ van.
Egy sor ülései mindig `A`, `B`, `C` és `D` nevet kapják.
A sor első ülése `A`, a második ülése `B`, és így tovább.
Miután elérte a `D`-t, újra `A`-val kell kezdenie.

Készíts egy `generate_seat_letters(<number>)` függvényt, amely egy `int` értéket fogad, ami megmondja, hány ülésbetűt kell generálni.
A függvény ezután az ülésbetűk egy _iterálható_ sorozatát adja vissza.

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. Generálj üléseket

A Conda egy olyan rendszert szeretne, amely adott számú ülést tud generálni a repülőgépeihez.
Minden repülőgépben _4 ülés_ van soronként.
A sorokat számokkal jelöljük, `1`-től indulva és felfelé haladva.
Az ülések sorrendje ilyen legyen: `1A`, `1B`, `1C`, `1D`, `2A`, `2B`, `2C`, `2D`, `3A`, `3B`, `3C`, `3D`, ...

Íme egy példa:

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|     Sor     |  5  | 21  |
|  Ülésbetű   |  A  |  D  |
|   Eredmény  | 5A  | 21D |

Sok légitársaságnál az utasok babonája miatt nincs 13-as számú _sor_ a járatokon.
A Conda Airlines is követi ezt a hagyományt, ezért ügyelj rá, hogy _ne_ generálj ülést a 13-as _sorhoz_.

Készíts egy `generate_seats(<number>)` függvényt, amely egy `int` értéket fogad, ami megmondja, hány ülést kell generálni.
A függvény ezután a generált ülések egy _iterálható_ sorozatát adja vissza.

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. Rendelj üléseket az utasokhoz

Most, hogy van már egy függvényed az ülések generálására, azzal üléseket is kioszthatsz az utasoknak.

Készíts egy `assign_seats(<passengers>)` függvényt, amely egy utasneveket tartalmazó `list`-et fogad.
A függvény ezután egy _szótárat_ adjon vissza, amelyben a `passenger` a _kulcs_ és a `seat_number` az _érték_.

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. Jegykódok

A Conda Airlines egyedi kódot szeretne minden jegyhez.
Mivel nagy légitársaság, rengeteg járatuk van.
Ez azt jelenti, hogy több járat is ugyanazzal az ülésszámmal közlekedik.
Szeretnék, ha készítenél egy rendszert, amely egyedi jegyet állít elő, egy _12_ karakter hosszú stringet.

A kód az `assigned_seat` értékkel kezdődik, ezt követi a `flight_id`.
A kód többi részét `0s` tölti ki.

Készíts egy `generate_codes(<seat_numbers>, <flight_id>)` függvényt, amely `seat_numbers` egy `list`-jét és a flightszámot tartalmazó `string`-et fogad.
A függvény ezután egy `generator`-t adjon vissza, amely `ticket_number` értékeket ad.

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
