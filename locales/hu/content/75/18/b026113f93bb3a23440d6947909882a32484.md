# Match-kifejezések

A match kifejezés kiértékel egy értéket és egy feltételt, hogy visszaadjon egy kiértékelendő kifejezést. Csakúgy, mint egy ternáris operátornál, ha a feltétel nem illeszkedik, a visszaadandó kifejezés nem kerül kiértékelésre. Egy feltétel illesztéséhez azonossági ellenőrzés [szigorú egyenlőség vagy `===`] történik.

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

Egyenlőségvizsgálathoz [`==`] átrendezheted a feltételt:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

Ha egy match kifejezésben egyetlen feltétel sem illeszkedik, `UnhandledMatchError` dobódik.
