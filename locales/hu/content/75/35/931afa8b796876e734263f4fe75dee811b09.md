# Utasítások

Adott két tetszőleges lista, `A` és `B`. Állapítsd meg, hogy:

- Az `A` lista egyenlő a `B` listával; vagy
- Az `A` lista tartalmazza a `B` listát (az `A` a `B` szuperlistája); vagy
- Az `A` listát a `B` lista tartalmazza (az `A` a `B` részlistája); vagy
- A fentiek egyike sem igaz, így az `A` és a `B` lista nem egyenlő

Pontosabban: az `A` lista akkor egyenlő a `B` listával, ha mindkét lista ugyanazokat az értékeket ugyanabban a sorrendben tartalmazza.
Az `A` lista akkor szuperlistája a `B` listának, ha az `A` tartalmaz egy `B`-vel egyenlő részsorozatot.
Az `A` lista akkor részlistája a `B` listának, ha a `B` tartalmaz egy `A`-val egyenlő részsorozatot.

Példák:

- Ha `A = []` és `B = []` (mindkét lista üres), akkor `A` és `B` egyenlő
- Ha `A = [1, 2, 3]` és `B = []`, akkor `A` szuperlistája `B`-nek
- Ha `A = []` és `B = [1, 2, 3]`, akkor `A` részlistája `B`-nek
- Ha `A = [1, 2, 3]` és `B = [1, 2, 3, 4, 5]`, akkor `A` részlistája `B`-nek
- Ha `A = [3, 4, 5]` és `B = [1, 2, 3, 4, 5]`, akkor `A` részlistája `B`-nek
- Ha `A = [3, 4]` és `B = [1, 2, 3, 4, 5]`, akkor `A` részlistája `B`-nek
- Ha `A = [1, 2, 3]` és `B = [1, 2, 3]`, akkor `A` és `B` egyenlő
- Ha `A = [1, 2, 3, 4, 5]` és `B = [2, 3, 4]`, akkor `A` szuperlistája `B`-nek
- Ha `A = [1, 2, 4]` és `B = [1, 2, 3, 4, 5]`, akkor `A` és `B` nem egyenlő
- Ha `A = [1, 2, 3]` és `B = [1, 3, 2]`, akkor `A` és `B` nem egyenlő
