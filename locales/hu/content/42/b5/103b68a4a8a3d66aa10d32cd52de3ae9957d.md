# Bevezetés

A struktúrák a Swift programozás alapvető építőelemei. A kapcsolódó adatokat és függvényeket önálló funkcionális egységekbe csoportosítják. Minden alapvető típus, amellyel eddig dolgoztál, például az `Int`, `Double` és `Character`, valamint a gyűjteménytípusok, mint az `Array`, `String` és `Dictionary`, valójában struktúrák.

## Struktúrák definiálása

A struktúra a `struct` kulcsszóval definiálható, amelyet a definiálandó típus neve követ, majd a törzs, kapcsos zárójelek között.

A törzs tárolt tulajdonságokból állhat, amelyek ugyanúgy definiálhatók és viselkednek, mint a szokásos konstansok vagy változók.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}
```

## Példányok

Ahogy fentebb említettük, egy struktúra definiálása csupán egy új _típus_ definiálását jelenti. Ez csak egy tervrajz arra, hogyan fognak kinézni az adott típus értékei, de valójában nem hoz létre semmilyen értéket ebből a típusból, amellyel dolgozhatnál.

Ahhoz, hogy létrehozd az adott típus egy _példányát_, írd le a típus nevét, majd utána egy pár zárójelet.

```swift
let someStats = CharacterStats()
```

Ez létrehozza az ilyen típusú értékeket, ahol a tulajdonságok a definícióban megadott alapértelmezett értékekkel lesznek feltöltve.

A struktúrák esetében a Swift automatikusan biztosít valamit, amit _tagonkénti kezdőértéknek_ neveznek, ahol a struktúra tulajdonságainak értékeit a zárójelek között adhatod meg, és ezek felülírják a definícióban szereplő alapértelmezett értékeket.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Tulajdonságok elérése

A struktúra tulajdonságai _pontnotációval_ érhetők el, ahol az érték nevét egy pont (`.`) és a tulajdonság neve követi.

```swift
someStats.health
// => 0
someStats.health = 87.3
```
