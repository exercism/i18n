# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat | Típus   | Leírás                                            |
| --------- | --------- | ------- | ------------------------------------------------- |
| `$a0`     | bemenet   | egész szám | szám                                           |
| `$v0`     | kimenet   | Boolean | Armstrong-szám-e (`0` = `false`, `1` = `true`)     |
| `$t0-9`   | ideiglenes | bármi  | ideiglenes tárolásra használt                     |
