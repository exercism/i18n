# Névjegy

A literálok rögzített értékek, amelyeket közvetlenül a kódban használunk.
Futásidőben nem igényelnek semmilyen számítást.
Többféle formában jelennek meg, hogy hatékonyan ábrázolják a különböző adattípusokat.
A leggyakoribb literálok numerikus jellegűek, de a dátum-, idő- és stringtípusokhoz is tartoznak literáloperátorok.
Egy későbbi fogalom bemutatja, hogyan használhatók a felhasználó által definiált literáloperátorok.

## Numerikus literálok

A numerikus literálok közé tartozik a decimális, az oktális, a hexadecimális és a bináris ábrázolásmód.
Ezeket az alapokat már tárgyaltuk a [számok fogalmánál][numbers-concept].

Az olyan ábrázolásokat, mint a `23`, a `0x50f7ba11` és a `0xba5eba11`, a fordító `int`-ként értelmezi.
Az általános `int` típus előjeles, és ([a fordítótól és a rendszertől függően][in-depth-integers]) gyakran a `-2'147'483'648` és a `2'147'483'647` közötti tartományt fedi le.
Ez a legtöbb esetben elég, és nem kell aggódnod az adott típus miatt.

Vannak felhasználási esetek, amikor nagyobb tartományra vagy nagyon kis memórialábnyomra van szükség.
Hogy egyértelmű legyél, a numerikus literálban közvetlenül megadhatod a konkrét egésztípust.

Ha nincs szükség negatív számokra, de a nagyobb tartományra igen, az `u` vagy `U` utótagot használjuk az _előjel nélküli_ egészekhez.
Nagyobb tartomány eléréséhez a long és long long típusoknál az `L`, sőt az `LL` utótag használható.

~~~~exercism/caution
A kisbetűs `l` használata megengedett, de könnyen összetéveszthető az `1` számmal, ezért nem ajánlott.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

A lebegőpontos számok a fordításkor rendszerint `double` típusként értelmeződnek.
Ez egy jó alapértelmezett eset, és a szűkebb `float` típust használó esetek ritkábbak, mint a fenti előjel nélküli példa.

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## Karakter- és stringliterálok

Más fogalmaknál már használtunk karakterliterálokat egyszeres idézőjelben, például `'}'` vagy `'@'`.

A C++-ban a `char` az első 128 [ASCII-karakterkódra][ascii-code] korlátozódik.
Ha több ASCII-karaktert vagy kiterjesztett ASCII-karaktert, például `‰`-t, vagy akár Unicode-karaktereket, például `麗`-t és `ẞ`-t szeretnél használni, más típusokra van szükség.
Egy korábbi fogalomban a stringliterálokat _kettős idézőjellel_ vezettük be: `"一体どういう意味ですか。C++です"`.
Ennek a japán mondatnak a tényleges típusa `const char (&)[46]`, azaz egy C-stílusú string.

A stringliterálok használata alapértelmezés szerint nincs engedélyezve.
Ahhoz, hogy a _string_ literált (`""s`) vagy a _string-view_ literált (`""sv`) használd, a kapcsolódó névtérrel kell jelezned, hogy ezeket használni szeretnéd:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

A _string_view_ egy const stringre mutató referenciának tekinthető.
