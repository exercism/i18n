# ne használj egymásba ágyazott elágazást

Próbáld meg átírni az elágazásokat, hogy elkerüld a mély egymásba ágyazást, mert az nehezebben követhető kódhoz vezethet. Nézd meg a következő két kódrészletet:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

Hasonlítsd össze a következő kóddal:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

A második példa felépítése nagyon jellegzetes: minden hibát kezelő útvonal behúzott blokkban van, a „happy path” pedig mindig a bal szélhez igazodik. Így a kód nagyon könnyen olvasható, mert gyorsan látszik, melyik a leggyakoribb, hibamentes útvonal benne.
