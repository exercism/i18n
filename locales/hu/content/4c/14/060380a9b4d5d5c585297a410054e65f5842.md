# Bevezetés

Néha, amikor végigmész egy sorozaton, szükséged van az elem *pozíciójára* is, maga az elem mellett. A `*-index` család a [`sequences`][sequences] szókészletben mindkettőt átadja az elemenkénti quotationnek. A `times` közeli rokona a sima, számolt iterációnak: akkor hasznos, ha csak egy darabszámra van szükséged, nem egy sorozatra.

## `each-index` és `map-index`: az index a quotationben

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

A quotation az elemet kapja meg, az indexet pedig közvetlenül alatta: az `index` van a verem **tetején**:

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

Az `each-index` a quotationt a mellékhatásáért futtatja, és nem ad vissza semmit. A `map-index` az elemenkénti eredményeket egy új sorozatba gyűjti, amely ugyanolyan fajtájú, mint a bemenet.

## `times`: számolt iteráció

A `times` (a [`math`][math] szókészletben) `n`-szer futtatja le a quotationjét.

```
times ( n quot: ( -- ) -- )
```

A dokumentált `( -- )` alak a *minimum*, mert a `times` `inline`, így egy hatásában kiegyensúlyozott quotation, például a `( str -- str )` is gond nélkül működik, és a verem értékei átöröklődnek az egyik iterációból a másikba. Ez így egy számolt akkumulátort ad, mindenféle módosítható állapot nélkül:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

Az egyes iterációk törzse látja az éppen futó stringet, hozzáfűz valamit, és a következő iteráció számára az új stringet hagyja a vermen. Ugyanez a trükk működik az `each-index` és a `map-index` esetében is, ha egy akkumulátort szeretnél végigvezetni.
