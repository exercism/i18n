# Bevezetés

A veremmel való zsonglőrködés rövid szavaknál rendben van. Ha viszont egy szónak több bemenete van, és ezekre név szerint kell hivatkoznod, a Factor *lokálisokat* kínál: névvel ellátott kötéseket, amelyeket a `::` (szódefiníciókhoz) vagy a `[| | ]` (beágyazott lambdákhoz) vezet be.

## `:: ( inputs -- outputs )`

Cseréld le a `:`-t `::`-ra, és a bemeneti nevekből lokális változók lesznek a törzsben:

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Hasonlítsd össze a veremrendezgetős változattal:

```factor
! DOCTEST: SKIP   (shown for comparison — would re-define hypotenuse)
: hypotenuse ( a b -- c )
    [ sq ] bi@ + sqrt ;
```

Mindkettő helyes. A lokálisok akkor a leghasznosabbak, ha egy bemenetre többször hivatkozol, vagy ha a műveletek sorrendje nem esik egybe természetesen a verem sorrendjével.

## Köztes értékek kötése a `:>` segítségével

A `::`-tal létrehozott törzsben (vagy egy beágyazott `[| ... |]` lambdában) a `:>` levesz egy értéket az adatveremről, és egy friss lokálishoz köti:

```
value :> name      ! immutable binding
value :> name!     ! mutable binding (name! is its setter)
```

A változtathatatlan forma a gyakoribb: ezzel nevezhetsz el egy köztes értéket, hogy a törzs fentről lefelé olvasható legyen:

```factor
USING: locals math ;

:: average-3 ( x y z -- avg )
    x y + z + :> sum
    sum 3 / ;
```

A `!` végződés módosíthatóként deklarálja a lokálist; a törzs későbbi részében a `value name!` (kettőspont és `:>` nélkül) új értéket ad neki:

```factor
USING: kernel locals math math.order ;

:: clamped ( x lo hi -- y )
    x :> v!
    v lo < [ lo v! ] when
    v hi > [ hi v! ] when
    v ;
```

A módosítható lokálisok azokban az iterációs szavakban hasznosak igazán, amelyekkel a későbbi feladatokban találkozol (pl. `while`).

## `[let` - scope bárhonnan

A `:>` csak lexikális scope-on belül működik, amit a `::` és a `[| ... |]` automatikusan létrehoz. Ha egy sima `:`-os szóból vagy a listenerből szeretnél lokálisokat bevezetni, csomagold a kódot `[let ... ]`-be:

```
[let code :> name code :> name ... body ]
```

Minden `:> name` az előző kifejezés verem tetején lévő értékét köti; a kötések a forma további részében is láthatók.

```factor
USING: locals math ;

[let 3 :> x 4 :> y x x * y y * + ] .   ! => 25
```

A `[let` a híd a veremstílusú `:`-os definíciók és a névvel ellátott kötések között. Kényelmes, amikor egy szónak csak egy szelete profitál a lokálisokból.

## Lambdák - `[| inputs | body ]`

Egy quotation belsejében a `[| inputs | body ]` olyan lokálisokat vezet be, amelyekre a törzs név szerint hivatkozhat. Ez különösen hasznos magasabb rendű szavaknál, például az `assoc-map`-nél, ahol a quotation a `key` *és* a `value` értéket is megkapja:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value neg ] assoc-map .
! => H{ { "a" -1 } { "b" -2 } }
```

Ugyanez a forma működik a `map-index`-nél is (a [`sequences`][sequences] szókészletben), amelynek a quotationje az elemet *és* annak indexét is megkapja. A nevek világossá teszik, melyik operandus milyen szerepet játszik:

```factor
USING: locals sequences ;

! Divide each element by its 1-based position:
{ 10 80 270 } [| elt i | elt i 1 + / ] map-index .
! => { 10 40 90 }
```

A lambda veremhatását a bemeneti lista és a törzs által előállított értékek határozzák meg.

## Mikor használj lokálisokat

Akkor nyúlj a lokálisokhoz, ha:

- Ugyanazt a bemenetet több helyen is használod.
- A műveletek természetes sorrendje nem egyezik a verem sorrendjével, és a javításukra szolgáló `dup`/`swap`/`rot` nehezen olvasható.
- Egy magasabb rendű szónak átadott beágyazott lambdában vagy, amely egyszerre több értéket ad át neked (mint az `assoc-map`-nél).

Ha a törzs tiszta, lineáris folyam, a sima `:`-os definíciók rövidebbek és legalább olyan olvashatók maradnak.

## `assoc-map` - egyszerre egy bejegyzés

Az `assoc-map` (a [`assocs`][assocs] szókészletben) egy quotationt futtat le egy asszociatív gyűjtemény minden egyes bejegyzésén:

```
assoc-map ( assoc quot: ( key value -- newkey newvalue ) -- newassoc )
```

A quotation megírásának legtisztább módja egy lokálisokat használó lambda.

## `cond` újra

Amikor `f` *vagy* egy számérték alapján kell elágaznod, a `cond` pont a megfelelő forma. Nem kell `case`, mert nincs egyetlen érték, amihez hasonlíthatnál.
