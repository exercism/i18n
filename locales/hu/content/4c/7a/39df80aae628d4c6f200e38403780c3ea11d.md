# Instrukciók

Nemrég kezdtél el dolgozni egy mászóterem recepcióján.
A tagok meghatározott számú hónapra vásárolnak tagságot, és minden látogatásukkor be- és kijelentkeznek.
A vezető megkért, hogy írj egy segédet, ami megválaszolja a tagok leggyakoribb kérdéseit.

## 1. Számold ki, mikor jár le egy tagság

A tagság a kezdő dátum hónapjának ugyanazon napján jár le, a megadott számú hónappal később.
Ha ez a nap nem létezik a záró hónapban, akkor a tagság helyette a hónap utolsó napján jár le.

Készítsd el a `FrontDesk.membershipEnd()` metódust, amely egy tagság kezdő dátumát és a hónapok számát kapja, és visszaadja a lejárat dátumát:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Írd ki, mennyi ideig tart egy tagság

A tagsági kártyára a terem ráírja, hogy mennyi ideig tart a tagság években, hónapokban és napokban.

Készítsd el a `FrontDesk.membershipLength()` metódust, amely egy tagság kezdő és záró dátumát kapja, és `Period` típusú értékként visszaadja a tagság hosszát:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Számold meg, hány nap van hátra egy tagságból

A tagok gyakran kérdezik, hány napjuk van hátra a tagságuk lejártáig.

Készítsd el a `FrontDesk.daysLeft()` metódust, amely a mai dátumot és a tagság záró dátumát kapja, és visszaadja a mai naptól a záró dátumig hátralévő napok számát.
Ha a záró dátum a mai nap, vagy már elmúlt, akkor nincs hátralévő nap, így a metódus `0`-t ad vissza:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Mérd meg egy látogatás időtartamát

A terem a nap 24 órájában nyitva van, és a beléptetőkapu rögzíti egy tag be- és kilépésének dátumát és időpontját.

Készítsd el a `FrontDesk.visitDuration()` metódust, amely egy látogatás be- és kilépési dátumát és időpontját kapja, és `Duration` típusú értékként visszaadja, mennyi ideig tartott a látogatás:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Írd ki a látogatást a nyugtára

A nyugta a látogatás hosszát órákban és percekben mutatja, például így: `1h 35m`.
A perceket mindig két számjeggyel írjuk, a másodperceket elhagyjuk, és az órák számát nem korlátozza egyetlen nap.

Készítsd el a `FrontDesk.formatVisit()` metódust, amely egy látogatás időtartamát kapja, és ebben a formátumban adja vissza:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
