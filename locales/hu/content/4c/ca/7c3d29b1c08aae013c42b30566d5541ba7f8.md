# Névjegy

A [consok][hyper-conses] a Common Lisp egyik alapvető adattípusa. Egy fejből és egy farokból állnak (amelyeket [történelmi okokból][history] `car`-nek és `cdr`-nek neveznek).
A cons feje és farka bármilyen adattípusú lehet.

A consokat a [`cons`][hyper-cons] függvénnyel hozzuk létre; ez két objektumot vár, és egy consra értékelődik ki (ezt néha „cons cell”-nek is nevezik).

A cons részeihez a [`car`][hyper-car] és a [`cdr`][hyper-cdr] függvénnyel férhetsz hozzá.

## Referencia

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
