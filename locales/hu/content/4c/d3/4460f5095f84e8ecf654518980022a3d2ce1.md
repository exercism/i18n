# Bevezetés

Sok programnak van szüksége (pszeudo)véletlen értékekre, hogy valós eseményeket szimuláljon.

Gyakori, ismerős példák:

- Érmefeldobás: egy véletlen érték a ('H', 'T') halmazból.
- Kockadobás: egy véletlen egész szám 1 és 6 között.
- Kártyapakli megkeverése: egy kártyalista véletlen sorrendje.
- Fák és bokrok létrehozása egy 3-D grafikai szimulációban.

Valóban véletlen értékeket generálni számítógéppel [meglepően nehéz technikai kihívás][why-randomness-is-hard], ezért léteznek „pszeudovéletlen” generátorok is.

## Véletlen számok generálása

JavaScriptben a [`Math.random()`][Math.random] függvénnyel generálhatsz pszeudovéletlen számokat.
Ez egy pszeudovéletlen lebegőpontos számot ad vissza 0 (beleértve) és 1 (kizárva) között.

Ahhoz, hogy egy _min_ (beleértve) és _max_ (kizárva) közötti véletlen számot kapj, valahogy így nézhet ki egy függvény:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## Véletlen egész számok generálása

Véletlen egész szám generálásához a `Math.floor()` vagy a `Math.ceil()` segítségével alakíthatod egész számmá a véletlenszerűen generált számot.
