# Tippek

## Általános

- Olvass a stringekről a hivatalos [String-útmutatóban][string-guide].
- Böngészd a [_Stringekhez_ elérhető metódusokat][string-methods].

## 1. Tisztítsd meg a nevet

- Egy részstring minden előfordulását lecserélheted egy stringben egy [beépített metódussal][string-replace].
- A string elején és végén lévő whitespace-karaktereket eltávolíthatod egy [beépített metódussal][string-strip].

## 2. Szerezd meg a név első betűjét

- Ha ki szeretnél venni egy adott karaktert egy stringből, használhatod az [indexelő operátort][string-indexing].

## 3. Formázd az első betűt kezdőbetűvé

- A string összes karakterét nagybetűssé alakíthatod egy [beépített metódussal][string-upcase].

## 4. Tedd a kezdőbetűket a szívbe

- Van egy speciális szintaxis, amellyel [interpolálhatsz][string-interpolation] egy kifejezést egy stringbe.
- Egy szív emojit escape-eléssel tehetsz egy stringbe: `\u<id>`, a szív emoji azonosítója pedig `2764`.
