# Introduction

A C# egy statikusan típusos nyelv, ami azt jelenti, hogy fordítási időben mindennek van típusa. Ha egy névhez értéket rendelsz, az a változó definiálása. Egy változót definiálhatsz úgy, hogy explicit módon megadod a típusát, vagy úgy, hogy a C# fordító a hozzárendelt érték alapján következtessen a típusára (ezt nevezik _típuskövetkeztetésnek_). Ezért az alábbi két változódefiníció egyenértékű:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Egy változó értékét a `=` operátorral frissítheted. Ha egyszer definiáltál egy változót, annak a típusa soha nem változhat.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

A C# egy [objektumorientált nyelv][object-oriented-programming], és elvárja, hogy minden függvényt egy _osztályon_ belül definiálj. Az osztály definiálásához a `class` kulcsszót használod. Az objektumokat (vagy _példányokat_) a `new` kulcsszóval hozod létre.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Az osztályon belüli függvényt _metódusnak_ nevezzük. Minden metódusnak lehet nulla vagy több paramétere. Minden paraméter típusát explicit módon meg kell adnod, a paramétereknél nincs típuskövetkeztetés. Hasonlóképpen a visszatérési típust is explicit módon meg kell adnod. Az értékeket a metódusok a `return` kulcsszóval adják vissza. Ahhoz, hogy egy metódust más fájlokban lévő kód is hívhasson, hozzá kell adnod a `public` hozzáférés-módosítót.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

A metódusokat egy példányon pont (`.`) szintaxissal hívod meg: megadod a hívni kívánt metódus nevét, és átadod az argumentumokat a metódus minden egyes paraméteréhez. Az argumentumoknál opcionálisan megadhatod a hozzájuk tartozó paraméter nevét is.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

A hatókört a C#-ban a `{` és a `}` karakterek között definiálod.

A C# kétféle megjegyzést támogat. Az egysoros megjegyzések elé `//` kerül, a többsorosakat pedig a `/*` és a `*/` közé írjuk.

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
