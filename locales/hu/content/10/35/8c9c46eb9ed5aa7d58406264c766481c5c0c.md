# Bevezetés

A `case` egy vezérlési szerkezet, amellyel egy adott értéket több mintával is össze tudunk hasonlítani. A `case` kifejezés ágai felülről lefelé értékelődnek ki, amíg egyezést nem találunk.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
