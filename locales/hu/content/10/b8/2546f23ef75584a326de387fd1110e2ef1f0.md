# Utasítások

Ebben a feladatban egy nemzetközi hívószámokat tartalmazó szótár kezeléséhez írsz kódot, egy `Map` segítségével.

A szótár lehetővé teszi, hogy a nemzetközi hívószám (a map kulcsa, `Integer`ként) alapján kikeresd egy ország nevét (a map értéke, `String`ként).

## 1. A hívószámok visszaadása egy mapben

Valósítsd meg a `getCodes` metódust, amely nem vesz át paramétert, és visszaadja a szótárban jelenleg szereplő hívószámokat és országokat tartalmazó mapet.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. Bejegyzések hozzáadása a szótárhoz

A szótárt fel kell tölteni tartalommal.
Valósítsd meg a `setDialingCode` metódust, amely átvesz egy hívószámot és a hozzá tartozó országot, majd hozzáadja a hívószámot és az országot.
Ha a hívószám már szerepel a mapben, frissítsd a mapet a megadott hívószámmal és országgal.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. Egy hívószámhoz tartozó ország kikeresése

Valósítsd meg a `getCountry` metódust, amely átvesz egy hívószámot, és visszaadja a hívószámhoz tartozó ország nevét.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. Ne engedj meg duplikátumokat

Amikor hívószámot adsz hozzá, ügyelni kell arra, hogy se egy hívószám, se egy ország ne kerülhessen be kétszer.
Ha ez mégis megtörténik, feltételezhetjük, hogy az első bejegyzés a helyes.
Valósítsd meg az `addNewDialingCode` metódust, amely bejegyzést ad hozzá a megadott hívószámhoz és országhoz.
A `setDialingCode` metódustól eltérően azonban nem tesz semmit, ha a hívószám vagy az ország már szerepel a mapben.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. Egy ország hívószámának megkeresése

Ritkán fordul elő, de előfordulhatnak hibák.
A hiba kijavításához tudnunk kell, hogy az ország jelenleg melyik hívószámhoz van rendelve.
Hogy megtaláld, melyik hívószámot kell kijavítani, valósítsd meg a `findDialingCode` metódust, amely átvesz egy országot, és visszaadja az ország hívószámát.
Ha az ország _nincs_ benne a mapben, adj vissza `null` értéket.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. Az ország hívószámának frissítése

Most, hogy tudjuk, melyik hívószámot kell kijavítani, nekiláthatunk a frissítésnek.
Valósítsd meg az `updateCountryDialingCode` metódust, amely átveszi az ország új hívószámát és az ország nevét, és ennek megfelelően frissít.
Ha az ország _nincs_ benne a mapben, ne tégy semmit (mivel ez a metódus csak a hibák kijavításában segít).

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
