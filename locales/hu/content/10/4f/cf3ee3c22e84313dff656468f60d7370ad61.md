# Case

[Case][case] (más nyelvekben gyakran switch néven ismert) egyfajta vezérlési szerkezet, akárcsak az if-else.
A case segítségével több if-else-if utasítást fűzhetsz egymáshoz, ami olvashatóbb is lehet, miközben megmarad a program futásának vezérlése.

A case a `case` kulcsszóval kezdődik, amelyet egy opcionális kifejezés követ.
Ezután minden ághoz a `when` kulcsszót használjuk, amelyet egy kifejezés követ, és ezt hasonlítjuk össze a case kifejezésével.
A `when` kulcsszó ne legyen beljebb húzva, mint a `case` kulcsszó.
A `when` kulcsszó után az a kód következik, amely akkor fut le, ha a case kifejezése megegyezik a when kifejezésével.
A case-hez tartozhat egy opcionális `else` utasítás is, amely akkor fut le, ha egyetlen másik eset sem illeszkedik.

A case kifejezését kiértékeljük, majd minden `when` kifejezéssel összehasonlítjuk.
Az összehasonlítás a case egyenlőségoperátorával (`===`) történik.

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## A case egyenlőségoperátora (`===`)

A case egyenlőségoperátora (`===`) kicsit más, mint az egyenlőségoperátor (`==`).
Ez az operátor azt vizsgálja, hogy a jobb oldal tagja-e a bal oldal által leírt halmaznak.
Ez azt jelenti, hogy korántsem mindegy, hova kerül az egyes operandusok.
Az, hogy hogyan működik, a bal oldal típusától függ: egy `Range` például azt vizsgálja, hogy a jobb oldal benne van-e a tartományban, egy `Object` pedig azt, hogy a jobb oldal a `Object` egy példánya-e.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Case több kifejezéssel

A case-ben egyetlen ághoz több kifejezést is megadhatsz, a lehetséges értékeket vesszővel elválasztva.
A kód akkor fut le, ha a kifejezések bármelyike illeszkedik.
Ez akkor lehet hasznos, ha egy ághoz több lehetséges értéket szeretnél rendelni.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## Case tartományokkal

A case azt is ellenőrizheti, hogy egy érték egy tartományba esik-e.
Ehhez csak egy tartományt kell megadnod when kifejezésként.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Case kifejezés nélkül

Ha nincs szükség case kifejezésre, nyugodtan elhagyhatod.
Ekkor minden when kifejezés igazságérték alapján értékelődik ki.
Így úgy viselkednek, mint az if-else-if utasítások.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## Egysoros when

A Ruby lehetővé teszi az egysoros case utasításokat.
Ez akkor jön jól, ha egy egyszerű, egysoros utasításod van.
Az egysoros when utasítás alakja `when <expression> then <statement>`.
Ha pedig az `else` utasításban használod, akkor `else <statement>` a formája.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## Case típusokkal

A case segítségével típusokra is illeszkedhetsz.
Ez akkor hasznos, ha egy változó típusától függően más-más viselkedést szeretnél.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
