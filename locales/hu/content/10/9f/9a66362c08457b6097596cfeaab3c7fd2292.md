# Bevezetés

A rekurzív függvények olyan függvények, amelyek önmagukat hívják meg.

Egy rekurzív függvényben legalább egy _alapesetnek_ és legalább egy _rekurzív esetnek_ lennie kell.

Az _alapeset_ anélkül ad vissza egy értéket, hogy újra meghívná a függvényt.
A _rekurzív eset_ újra meghívja a függvényt, és úgy módosítja a bemenetet, hogy az előbb-utóbb megfeleljen az alapesetnek.

Az Elmben a rekurzív függvényeket jellemzően `case` kifejezésekkel végzett mintaillesztéssel vagy több függvényklózzal definiáljuk.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## Ciklusok rekurzióval

A változhatatlanság miatt az Elmben a ciklusok másképp néznek ki, mint az imperatív nyelvekben.
Például a ciklusok általában így néznek ki:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Egy funkcionális nyelvben, mint amilyen az Elm, a változók módosítása nem lehetséges.
Ezért a ciklusokat rekurzióval kell megvalósítani.

A `for` ciklus megfelelője az Elmben így nézne ki:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

A gyakorlatban az Elmben a listákon és más adatszerkezeteken való iterálás leggyakrabban a `List` modul függvényeivel történik, például a `List.map`, `List.filter` és `List.foldl` függvénnyel.
A háttérben ezek a függvények rekurzióval vannak megvalósítva.
