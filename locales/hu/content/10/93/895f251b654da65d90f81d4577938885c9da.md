# Utasítások

Ellen egy olyan játékot készít, amelyben a játékosnak alienekkel kell harcolnia.
Éppen most tanult az objektumorientált programozásról (OOP), és alig várja, hogy kihasználja, mit nyújthat a programjának a `classes` használata.

Ellen örömére felajánlottad a segítségedet, ő pedig rád bízta, hogy programozd le azokat az alieneket, amelyekkel a játékosnak harcolnia kell.


## 1. Az Alien osztály létrehozása

Definiáld az Alien osztályt egy konstruktorral, amely két paramétert fogad, `<x_coordinate>` és `<y_coordinate>`, és ezeket az `x_coordinate`, illetve `y_coordinate` példányváltozókba teszi.
Minden alien 3-as életerőszinttel is indul, tehát a `health` változót is inicializálni kell.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

Így minden alien képes lesz belsőleg nyilvántartani a saját pozícióját és életerejét.

## 2. A `hit` metódus

Ellen szeretné, ha az Alien `class`-nek lenne egy `hit` metódusa, ami meghívásakor 1-gyel csökkenti egy alien objektum életerejét.
Így egyszerűen csak `<alien>.hit()`-et kell hívnia, ahelyett hogy kézzel módosítaná az alien életerejét.
Rajtad áll, hogy a `hit()` az életerőpontokat nullára vagy az alá csökkenti-e.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. Az `is_alive` metódus

Rájössz, hogy ha az életerő folyamatosan csökken, akkor egy ponton valószínűleg eléri a 0-t (_vagy akár annál is kevesebbet!_).
Jó ötlet lenne hozzáadni egy `is_alive` metódust, amit Ellen gyorsan meghívhat, hogy ellenőrizze, vajon az alien... nos... életben van-e. 😉
A `<alien>.is_alive()` egy boolean értéket adjon vissza.

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. A `teleport` metódus

Ellen játékában az alienek képesek teleportálni!
Írnod kell egy `teleport` metódust, amely új `x_coordinate` és `y_coordinate` értékeket vesz át, és ennek megfelelően módosítja az alien koordinátáit.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. A `collision_detection` metódus

Nyilvánvaló, hogy ha az alieneket eltalálhatja valami, akkor fel kell tudniuk ismerni, amikor ilyen ütközés történik.
Az ütközésészlelő algoritmusok viszont bonyolultak lehetnek, és te még nem tudod, hogyan kell megvalósítani egyet.
Ellen azt mondta, hogy később megcsinálja, de szeretné, ha a `collision_detection` metódus mégis megjelenne az osztályban, emlékeztetőül arra, hogy ki kell dolgozni a funkcionalitást.
Valamilyen változót kell átvennie (valószínűleg egy másik objektumot), de valójában csak ennyit tudsz.
Gondoskodnod kell róla, hogy a metódusdefiníció osztályba helyezése ne okozzon hibát, amikor meghívják:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. Alienek számlálása

Ellen egy új kéréssel tért vissza hozzád.
Szeretné számon tartani, hány alien jött létre a játék teljes időtartama alatt.
Azt mondja, ennek köze van a pontozási rendszerhez.

Például:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. Alienek listájának létrehozása

Ellen imádja, amit eddig csináltál, de még egy szívességet kérne.
Szeretne egy önálló (az `Alien()` osztályon _kívül_ álló) függvényt, amely pozíciók listájából (`tuples` formában megadva) `Alien()` objektumokból álló `list`-et készít.

Például:

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)
(4, 7)
(-1, 0)
```
