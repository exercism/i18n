# Utasítások

Szenvedélyes madarász vagy, aki számon tartja, hány madár járt a kertedben az elmúlt hét napban.

Hat részfeladatod van, és mindegyik a kertedbe látogató madarak számával foglalkozik.

## 1. Ellenőrizd, mennyi volt a számok értéke a múlt héten

Összehasonlítás céljából mindig magadnál tartod a múlt heti számok másolatát, amelyek a következők voltak: 0, 2, 5, 3, 7, 8 és 4. Valósítsd meg a (_statikus_) `BirdCount.LastWeek()` metódust, amely visszaadja a múlt heti számokat:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Ellenőrizd, hány madár járt ma

Valósítsd meg a `BirdCount.Today()` metódust, amely visszaadja, hány madár járt a kertedben ma. A madárszámok napok szerint vannak rendezve: az első elem a legrégebbi naphoz tartozó szám, az utolsó elem pedig a mai.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. Növeld meg a mai naphoz tartozó számot

Valósítsd meg a `BirdCount.IncrementTodaysCount()` metódust, amely megnöveli a mai naphoz tartozó számot:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. Ellenőrizd, volt-e olyan nap, amikor egyetlen madár sem járt a kertben

Valósítsd meg a `BirdCount.HasDayWithoutBirds()` metódust, amely `true` értéket ad vissza, ha volt olyan nap, amikor nulla madár járt a kertben; egyébként pedig `false` értéket:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. Számold ki, hány madár járt a hét első néhány napján

Valósítsd meg a `BirdCount.CountForFirstDays()` metódust, amely visszaadja, hány madár járt a kertedben a hét elejétől számítva, de a számolást korlátozd a hét elejétől számított megadott számú napra.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. Számold ki a forgalmas napok számát

Van, amikor több madár jár a kertedben, és van, amikor kevesebb. Forgalmas napnak az számít, amikor öt vagy több madár járt a kertedben.
Valósítsd meg a `BirdCount.BusyDays()` metódust, amely visszaadja a forgalmas napok számát:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
