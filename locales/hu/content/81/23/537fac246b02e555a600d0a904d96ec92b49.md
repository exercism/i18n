# Részletesen

Mivel a Clojure összes szabványos adattípusa megváltoztathatatlan, *referenciatípusokat* kínál, amelyek szabályozott módosítást tesznek lehetővé. Ezek közül a legegyszerűbbeket és leggyakrabban használtakat atomoknak nevezzük.

Az atomokat az `atom` függvénnyel hozod létre, amely egy kezdőértéket vár:

```clojure
(def players (atom ()))
```

Az atom aktuális értékét akár a `deref`, akár a `@` rövidítés segítségével kiolvashatod:

```clojure
@players
;;=> ()
```

A `players` atom aktuális értékét a `swap!` segítségével módosíthatod, amely egy függvény alkalmazásával frissíti annak értékét:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

A `reset!` függvény lecseréli az atom értékét, függetlenül annak aktuális értékétől:

```clojure
(reset! players ())
```
