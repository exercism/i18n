# Névjegy

A Rustban a metódusok olyan függvények, amelyeket egy structhoz (vagy `enum`hoz, illetve `trait` objektumhoz) definiálunk.
Ez megváltoztatja a hívás módját: a metódust nem `frobnicate(foo)` alakban, hanem `foo.frobnicate()` formában hívjuk meg.

A metódusok hasonlóak a függvényekhez: a `fn` kulcsszóval deklaráljuk őket, van nevük, és lehetnek paramétereik és visszatérési értékük.

A függvényektől eltérően egy metódus első paramétere mindig `self` (vagy annak valamilyen változata), amely azt a structpéldányt jelöli, amelyen a metódust meghívjuk (a részleteket lásd alább).

Hozzunk létre egy `enum`ot a Roxfort házaihoz, és egy `struct`ot, amely leírja egy varázsló `age` és `house` mezőjét:

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## Metódusok definiálása

Ahhoz, hogy metódusokat definiáljunk a `Wizard` structhoz, elindítunk egy `impl` (az implementáció rövidítése) blokkot a `Wizard` számára.

```rust
impl Wizard { }
```

Minden, ami ebben az `impl` blokkban szerepel, a `Wizard` típushoz lesz társítva.
Fontos, hogy egy structnak több `impl` blokkja is lehet.

### A `self` használata

Egy metódus első paramétere mindig egy `self` nevű, `Self` típusú paraméter.
A `Self` típus annak a típusnak az álneve, amelyre az `impl` blokk vonatkozik.
A példánkban a `Self` a `Wizard`-ot jelöli.

A Rust kényelmi okokból megengedi, hogy ezt lerövidítsük, és az első paraméter helyén csak a `self` nevet használjuk.
A metódusoknál használt gyakori `self` típusok:

- `self`: a `self: Self` rövidítése. A puszta `self` szignatúra felemészti a példányt.
- `&self`: a `self: &Self` rövidítése. Ez megváltoztathatatlanul kölcsönzi a példányt.
- `&mut self`: a `self: &mut Self` rövidítése. Ez megváltoztathatóan kölcsönzi a példányt.

Fejlettebb kódban olyan szignatúrákkal is találkozhatsz, mint például `self: Pin<&self>`, `self: Rc<Self>` stb.
Ez azonban túlmutat a jelenlegi oktatóanyag keretein.

### Metódus definiálása `&self`-fel

Ha egy `info` metódust szeretnénk implementálni a varázsló alapvető adatainak megjelenítésére, ezt a metódust a `Wizard` egy `impl` blokkjában definiálhatjuk:

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

Figyeld meg, hogy az `info` szignatúrájában `&self`-fel megváltoztathatatlanul kölcsönözzük a példányt.
Így egy `Wizard` példány `age` és `house` mezőjét anélkül olvashatjuk ki, hogy megváltoztatnánk őket.
Ha a kölcsönzés helyett egy felemésztő `self`-et használtunk volna, a példány a metódus meghívása után elérhetetlenné válna.

Az `info` metódus implementálása után kiírhatjuk egy varázsló alapvető adatait:

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### Metódus definiálása `&mut self`-fel

Ha olyan metódust szeretnénk implementálni, amely egy structpéldány mezőit módosítja, akkor a metódus szignatúrájában `&mut self`-fel megváltoztathatóan kölcsönözzük a példányt.

Tegyük fel, hogy egy új szabályt szeretnénk bevezetni a Roxfortban, amely megengedi a diákoknak, hogy házat váltsanak.
A `switch_house` metódust így implementálhatjuk:

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

Most már házat válthatunk egy Roxfortban tanuló varázslónak:

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## Több „impl" blokk

A Rustban minden elemnek lehet több `impl` blokkja.
Így az összes metódust egyetlen `impl` blokkba csoportosíthatjuk, vagy több `impl` blokkot hozhatunk létre a metódusok különböző csoportjaihoz.
Mindkét megközelítés érvényes szintaxis, a tipikus projektstruktúra azonban az `impl`-szintű `where` korlátok minden egyedi halmazához egyetlen `impl` blokkot használ.

## Társított függvények

Egy `impl` blokkon belül definiálhatunk olyan függvényeket, amelyek nem tartalmaznak `self` paramétert.
Mivel nincs `self` paraméterük, nem metódusok.
Az implementált típushoz viszont így is hozzátartoznak, és úgy hívjuk meg őket, hogy megnevezzük ezt a típust.
Ezért nevezik őket társított függvényeknek (vagy típushoz társított függvényeknek).

Már találkoztál néhány társított függvénnyel, például a `String::from()` függvénnyel:

```rust
let some_string = String::from("This is an associated function but not a method");
```

A konstruktorokat gyakran társított függvényként implementálják.
Hozzunk létre egy `new` függvényt, amely a `Wizard` típushoz társul:

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

Figyeld meg, hogy a függvény visszatérési típusának megadásához a `Wizard` helyett használhatjuk a `Self`-et.
Nem kötelező így használni a `Self` típusaliast, de leegyszerűsítheti az implementációt a bonyolult vagy bőbeszédű nevű típusok esetében.
Most már lefuttathatjuk a következőt:

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
