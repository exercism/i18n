# Utasítások

A városban új költészeti klub nyílt, és azon gondolkodsz, hogy csatlakozz-e.
Mivel korábban már voltak incidensek, a klub nagyon sajátos ajtópolitikát folytat, amelyet el kell sajátítanod, mielőtt megpróbálnál bejutni.

A költészeti klubnak két ajtaja van, egy elülső és egy hátsó, és mindkettőt őrzik.
A belépéshez ki kell találnod az aznapi jelszót.

A jelszó mindig egy versen alapul, és két lépésben vezethető le.

1. Az őr felmondja a verset, egyszerre egy sort, neked pedig a sor egy megfelelő betűjével kell válaszolnod.
2. Ezután az őr egyszerre megmondja az összes betűt, amivel válaszoltál, és ezeket egy papírra kell leírnod egy meghatározott formátumban.

A folyamat részletei attól függnek, hogy melyik ajtón próbálsz bejutni.

~~~~exercism/note
Ebben a feladatban minden string ASCII-kódolású, és NUL karakterrel végződik.
Ez azt jelenti, hogy minden karakter ASCII-kódolást használ, és minden string ott ér véget, ahol a '\0' (a NUL karakter, amelynek értéke `0`) megjelenik.
~~~~

~~~~exercism/note
Ezek a fogalomban említett string utasítások:

| utasítás | mit csinál                                                                                                          |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | egy értéket tölt be az `rsi` által megadott memóriacímről az `rax`-be                                              |
| `stos`       | egy értéket tárol el az `rax`-ből az `rdi` által megadott memóriacímre                                             |
| `movs`       | átmásol egy értéket az `rsi` által megadott memóriacímről, és eltárolja az `rdi` által megadott memóriacímre       |

Mindegyiküknek rendelkeznie kell egy utótaggal, amely a művelet méretét jelzi:

| utótag | méret            |
|--------|------------------|
| `b`    | byte             |
| `w`    | word (2 bájt)    |
| `d`    | dword (4 bájt)   |
| `q`    | qword (8 bájt)   |

A string utasítások mindegyike módosítja az `rsi` és/vagy `rdi` címét is (csak azokon a regisztereken, amelyeket az utasítás használ).
Alapértelmezés szerint a művelet méretével növelik a címeket.

A `rep` előtag bármelyik fenti string utasításhoz hozzáadható, hogy `rcx`-szer ismételje meg.
~~~~

## 1. Szerezd meg egy mondat első betűjét

Az elülső ajtó jelszavához tartozó betűk meghatározásához a vers azon sorának első betűjével kell válaszolnod, amelyet az őr felmond.

Hogy szép jelszó szülessen, a költészeti klub tagjai szívesen használnak _akrosztichon_ verseket.
Ez azt jelenti, hogy minden mondat első betűje együtt egy szót alkot.
Íme egy példa egyik kedvenc költőjüktől, Michael Lockwood-tól.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Tehát amikor az őr a **Stands so high** sort mondja fel, a válaszod **S**, amikor pedig a **Huge hooves too** sort, a válaszod **H**.

Valósítsd meg a `front_door_response` függvényt, amely argumentumként a vers egy sorának memóriacímét kapja, és visszaadja a sor első betűjét.
Ezt a betűt ASCII-kódolt karakterként kell visszaadnod, amely 1 bájtot foglal el.

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. Írd nagy kezdőbetűvel a szót

Most, hogy megvan az összes helyes betű, már csak helyesen kell nagy kezdőbetűvel írnod a szót, hogy megkapd az elülső ajtó jelszavát.

Valósítsd meg a `front_door_password` függvényt, amely argumentumként annak a stringnek a memóriacímét kapja, amely csak az 1. részfeladatban megtalált betűk együttesét tartalmazza.
A bemeneti stringet [helyben][in-place] kell módosítania, hogy helyesen legyen nagy kezdőbetűvel írva.
Ez azt jelenti, hogy a helyes stringet ugyanarra a memóriacímre kell írni, ahol a bemenet van.

A függvénynek nincs visszatérési értéke.

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. Szerezd meg egy mondat utolsó betűjét

A hátsó ajtó jelszavához tartozó betűk meghatározásához a vers azon sorának utolsó betűjével kell válaszolnod, amelyet az őr felmond.

A költészeti klub tagjai igazán okosak.
A korábban említett vers egyben _telestichon_ is, ami azt jelenti, hogy minden mondat utolsó betűje szintén egy szót alkot:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Amikor az őr a **Stands so high** sort mondja fel, a válaszod **h**, amikor pedig a **Huge hooves too** sort, a válaszod **o**.

Vedd figyelembe, hogy az őr néha stilisztikai szüneteket tart (írásjelek vagy szóközök formájában), amikor felmondja a verset.
Ezeket a szüneteket figyelmen kívül kell hagynod, hogy megkapd a helyes betűt.

Valósítsd meg a `back_door_response` függvényt, amely argumentumként a vers egy sorának memóriacímét kapja, és visszaadja a sor utolsó betűjét.
Ezt a betűt ASCII-kódolt karakterként kell visszaadnod, amely 1 bájtot foglal el.

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. Légy udvarias

Ahhoz, hogy a hátsó ajtón keresztül bejuss a költészeti klubba, különösen udvariasnak kell lenned.
Így a jelszó levezetéséhez ezúttal helyesen kell nagy kezdőbetűvel írnod a szót, és a végére be kell szúrnod a `", please."` szöveget.

Valósítsd meg a `back_door_password` függvényt, amely a következő argumentumokat fogadja, ebben a sorrendben:

1. Egy buffer memóriacímét, ahová a létrejövő string kerül.
2. Annak a stringnek a memóriacímét, amely a 3. részfeladatban megtalált betűk együttesét tartalmazza.

A függvénynek a [buffer][buffer]ben kell eltárolnia a nagy kezdőbetűvel írt jelszó udvarias változatát.
A _buffer_ egy tömb, amellyel értékeket lehet a memóriában tárolni, hogy azokat különböző függvények között mozgathassuk.

Ennek a függvénynek nincs visszatérési értéke.

```c
back_door_password("horse");
// => "Horse, please."
```

[buffer]: https://en.wikipedia.org/wiki/Data_buffer
