# Bemutatás

Az atomokat akkor érdemes használnod, ha konstansok egy csoportját szeretnéd kifejezni. Az atomok típusbiztos módot kínálnak az értékek összehasonlítására. Az atomot a neve határozza meg, amelyet egy kettőspont előz meg:

```elixir
# Atoms start with a ':',
# followed by alphanumeric snake_cased characters
:an_atom
```

Az Elixir szabványos könyvtárának sok függvénye atomot ad vissza az eredmény jelölésére:

```elixir
Enum.fetch([1], 0)
# => {:ok, 1}
Enum.fetch([1], 2)
# => :error
```

Az [_atomokat_][atom] belsőleg egy keresőtáblában lévő egész szám reprezentálja, amelyet a rendszer automatikusan állít be. Ezért az atomok összehasonlítása gyorsabb, mint a stringeké. Ezt a belső értéket nem lehet megváltoztatni. Általában [anti-mintának][anti-pattern] tartják, ha a felhasználótól származó bemenetből dinamikusan hozunk létre atomokat. A futtatókörnyezetben csak korlátozott számú atomnak van hely, ezért ha az atomtábla megtelik, az új atomok futásidejű létrehozása meghiúsulhat.

[atom]: https://hexdocs.pm/elixir/basic-types.html#atoms
[anti-pattern]: https://en.wikipedia.org/wiki/Anti-pattern
