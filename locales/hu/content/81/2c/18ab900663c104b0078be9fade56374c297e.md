# Kiegészítő utasítások

## Regiszterek

| Regiszter | Használat      | Típus     | Leírás                     |
| --------- | -------------- | --------- | -------------------------- |
| `$a0`     | bemenet        | egész szám | a háromszög sorainak száma |
| `$a1`     | bemenet/kimenet | cím       | szavak tömbje              |
| `$v0`     | kimenet        | egész szám | a kimeneti szavak száma    |
| `$t0-9`   | ideiglenes     | bármilyen | ideiglenes tárolásra       |
