# Bevezetés

## Egész számok

Az Elixirben kétféle szám létezik: egész számok és lebegőpontos számok.

Az egész számok olyan számok, amelyeknek nincs törtrészük.

```elixir
integer = 3
# => 3
```

## Lebegőpontos számok

A lebegőpontos számok olyan számok, amelyekben a tizedeselválasztó után egy vagy több számjegy áll. A 64 bites dupla pontosságú lebegőpontos formátumot használják.

```elixir
float = 3.45
# => 3.45
```

### Számok kezelése

Az [`Integer`][integer-functions] és a [`Float`][float-functions] modulban hasznos függvényeket találsz ezeknek a típusoknak a kezeléséhez. Az alapvető aritmetikai operátorokat a [`Kernel`][kernel-arithmetic-operators] modul definiálja.

### Átalakítás

Egy aritmetikai kifejezésben egész és lebegőpontos számokat is keverhetsz. Ha egy kifejezésben lebegőpontos szám szerepel, az eredmény is lebegőpontos lesz.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Osztásnál viszont az eredmény mindig lebegőpontos szám lesz, még akkor is, ha csak egész számokat használsz.

```elixir
6 / 2
# => 3.0
```

Egy lebegőpontos számot úgy alakíthatsz egész számmá, hogy a [`trunc/1`][trunc-1] függvénnyel eldobod a törtrészét.
