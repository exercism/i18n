# Bevezetés

A JavaScript dinamikus nyelv, amely támogatja az objektumorientált, az imperatív és a deklaratív (például funkcionális programozási) stílusokat.

## (Újra)értékadás

Néhány alapvető módja van annak, hogy értéket rendelj nevekhez a JavaScriptben: használhatsz változókat vagy konstansokat. Az Exercism-ön a változókat mindig [camelCase][wiki-camel-case] írásmóddal írjuk, a konstansokat pedig [SCREAMING_SNAKE_CASE][wiki-snake-case] írásmóddal. Nincs hivatalos útmutató, amit követni kellene, és a különböző cégeknek és szervezeteknek is különféle stílusútmutatóik vannak. _Nyugodtan írd le a változókat úgy, ahogy csak szeretnéd_. Ha úgy írod le őket, ahogy a feladatokban szerepelnek, az az előnye, hogy a webes felületen és a legtöbb IDE-ben is másképp lesznek kiemelve.

A JavaScriptben a változókat a [`const`][mdn-const], a [`let`][mdn-let] vagy a [`var`][mdn-var] kulcsszóval definiálhatod.

A `let` vagy a `var` használatakor egy változó az élettartama során több különböző értékre is hivatkozhat. Például a `myFirstVariable` sokszor definiálható és újradefiniálható az `=` értékadás operátorral:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

A `let`-tel és a `var`-ral ellentétben a `const`-tal definiált változóknak csak egyszer adhatsz értéket. A JavaScriptben így definiáljuk a konstansokat.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 Egy későbbi tanulófeladatban részletesen megnézzük és elmagyarázzuk a különbséget a _konstans_ értékadása / kötése és a _konstans_ értéke között.

## Függvénydeklarációk

A JavaScriptben a funkcionalitás egységeit _függvényekbe_ zárjuk, és ha a függvények összetartoznak, általában ugyanabba a fájlba csoportosítjuk őket. Ezek a függvények fogadhatnak paramétereket (argumentumokat), és a `return` kulcsszóval _adhatnak vissza_ értéket. A függvényeket a `()` szintaxissal hívod meg.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 A JavaScriptben _sok_ különböző módon deklarálhatsz függvényt. Ezek a többi módszerek másképp néznek ki, mint a `function` kulcsszó használata. A kurzus ezeket fokozatosan vezeti be, de ha már ismered őket, nyugodtan használhatod bármelyiket. A legtöbb esetben az egyik vagy a másik használata nem jobb vagy rosszabb.

## Elérhetővé tétel más fájlok számára

Ahhoz, hogy egy `function`, egy konstans vagy egy változó _más fájlokban_ is elérhető legyen, [exportálni][mdn-export] kell őket az `export` kulcsszóval. Egy másik fájl ezután az `import` kulcsszóval [importálhatja][mdn-import] őket. Ezt modulrendszernek is nevezik. Kiváló példa erre, hogyan működik az összes teszt. Minden feladatnak van legalább egy fájlja, például a `lasagna.js`, amely az _implementációt_ tartalmazza. Ezen kívül van legalább egy másik fájl is, például a `lasagna.spec.js`, amely a _teszteket_ tartalmazza. Ez a fájl _importálja_ a nyilvános (azaz exportált) entitásokat, hogy tesztelje az implementációt:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
