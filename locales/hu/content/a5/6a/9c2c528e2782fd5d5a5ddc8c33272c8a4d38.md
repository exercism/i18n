# Bevezetés

A Factorban a karakterek egészek, Unicode-kódpontok, így a numerikus
`<`, `>`, `=` közvetlenül kis- és nagybetű-érzékeny rendezést ad. A
[`unicode`][unicode] szókészlet Unicode-tudatos predikátumokat és
egyetlen karakterre vonatkozó kis- és nagybetű-átalakítást tesz hozzá.

## Karakterpredikátumok

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## Kis- és nagybetű-átalakítás

A `ch>upper` és a `ch>lower` egyetlen karakter betűállapotát váltja át.
A karakterlánc-szintű `>upper` és `>lower` pedig a karakterlánc minden
karakterére alkalmazza őket.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

A `capitalize` egy teljes karakterláncot csupa kisbetűssé alakít, majd
az első karakterét nagybetűssé teszi: ez egyetlen szó címformátuma.

```factor
"hELLO" capitalize .   ! => "Hello"
```

## Karakterliterálok

A `CHAR: A` beolvasásakor az `A` egész kódpontját kapod. Nevesített
karakterekhez használd a `space`, `tab`, `\n` stb. neveket:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## Szimbólumok

Amikor egy szónak nem értéket, hanem címkét kell visszaadnia, mondjuk
`yes`/`no`/`maybe` értéket boolean helyett, deklaráld minden címkét
*szimbólumként*. A szimbólum olyan szó, amely meghívva önmagát teszi a
veremre, és két szimbólum csak akkor egyenlő, ha ugyanaz a nevük.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

A `SYMBOL: name` egyetlen szimbólumot deklarál, a `SYMBOLS: a b c ;`
pedig többet.
