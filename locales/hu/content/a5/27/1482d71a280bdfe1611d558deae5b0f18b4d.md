# Kiegészítés az utasításokhoz

## Fenntartott memória

A bemeneti string puffere a lineáris memória 64-191. bájtját használja.

## A bemenet formátuma

A bemenet egyetlen stringként érkezik, három sorral, és mindegyik sor végén egy sortörés van. A kereszt és a karika mindig nagybetűs `X` és `O`.

Tehát a tábla

```
X··
OXO
XOX
```
így lesz kódolva

```
"X  \nOXO\nXOX\n"
```
