# Tesztek

## Az Exercism GDScript kurzus tesztfuttatójának telepítése

A tesztfuttató használatához [helyesen telepített Godotra][installation] lesz szükséged.

Ahhoz, hogy GDScript szkripteket fordíts és tesztelj az Exercism-höz, a Godotot „headless” módban futtatjuk a CLI-ből.
Ezek az utasítások jelenleg Linuxot és bash-t igényelnek.

### 1. lépés: Az átfogó tesztfuttató-infrastruktúra telepítése

A tesztelés beállításához klónozd a [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] tárat, és mozgasd a tartalmát a `/opt/test-runner/` könyvtárba:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### 2. lépés: Az egy feladathoz tartozó tesztfuttató szkript letöltése

Feltételezve, hogy az `exercism` eszközt már beállítottad, és letöltöttél legalább egy GDScript feladatot, létre kellett hoznia egy `exercism/gdscript` mappát a feladatok tárolására.
Mentsd el [a tesztfuttatót][test-local-gdscript-solution] ebbe a mappába, és jelöld a fájlt futtathatóként, vagy egyszerűen csak hozz létre egy hivatkozást rá:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## A tesztek futtatása

A telepítési lépések elvégzése után bármelyik feladat könyvtárából kiindulhatsz (pl. `~/exercism/gdscript/two-fer`), és futtathatod a szkriptet (amely egy szinttel feljebb, a `../` mappában található), hogy leteszteld a helyi megoldásodat arra a feladatra:

```sh
../test-local-gdscript-solution.sh
```
