Az Elixirnek megvannak a maga elnevezési konvenciói, köztük az is, hogyan nevezzük el azokat a [függvényeket, amelyek boolean értéket adnak vissza](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo):

> A boolean értéket visszaadó függvények neve kérdőjellel végződik.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

Vedd figyelembe, hogy a guardok, valamint néhány beépített függvény és makró, amely boolean értéket ad vissza és guardban is használható, más konvenciót követ: a nevük `is_` előtaggal kezdődik (`def is_integer`, `defguard is_foo`, `defmacro is_foo`). A két konvenciót nem szabad összekeverni.
