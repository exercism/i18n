# Bevezetés

A Cairo-nak nincs natív string típusa, de kétféleképpen is kezelheti őket: rövid stringekként szimpla idézőjelekkel, illetve `ByteArray`-ként dupla idézőjelekkel.

A rövid string olyan ASCII string, amelyben minden karakter egyetlen bajton van kódolva.

A Cairo alapértelmezés szerint a `felt252` típust használja a rövid stringekhez, így azok maximális hossza mindössze 31 karakter.

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

Technikailag bármely `felt252`-nél kisebb egész típus ábrázolható a rövid string formátummal.

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

A 31 karakternél hosszabb stringekhez a Cairo a `ByteArray` típust kínálja, amelynek hossza korlátlan.

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

A ByteArray típusok a `+` operátorral fűzhetők össze:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Egyes speciális karaktereket egy kezdő visszaperjellel kell escape-elni, például a `\t` a tabulátort, a `\n` pedig az új sort jelöli a stringekben.

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Egy ByteArray egyes bájtjaihoz akár az indexük segítségével is hozzáférhetsz.

De légy óvatos: a visszaadott bájt típusa `u8`, nem pedig `ByteArray`!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

A core könyvtár számos hasznos metódust és operátort biztosít a ByteArray típusok kezeléséhez.

A ByteArray metódusairól bővebb információt a [ByteArrayTrait dokumentációjában][docs] találsz.

Íme néhány példa:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
