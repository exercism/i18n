# Kiegészítés az utasításokhoz

## Tippek

Meg kell valósítanod a `recite` függvényt, amely kiírja a „The Twelve Days of Christmas” dal szövegét. Használhatod a megadott szignatúrát, ha bizonytalan vagy a típusokban, de ne hagyd, hogy korlátozza a kreativitásodat.

Ez a feladat szöveges adatokkal dolgozik. Történelmi okokból a Haskell `String` típusa ugyanaz, mint a `[Char]`, azaz karakterek listája. A szöveges adatok hatékonyabb kezeléséhez a `Text` típus használható.

A feladat opcionális kiterjesztéseként

- olvashatsz a [string típusokról](https://haskell-lang.org/tutorial/string-types) Haskellben.
- felveheted a `- text`-et a függőségeid listájára a package.yaml-ban.
- importálhatod a `Data.Text`-et [a következő módon](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- írhatsz például `recite :: Int -> Int -> [Text]`-et, és például `T.pack` néven hivatkozhatsz a `Data.Text` kombinatorokra.
- kikeresheted a [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) dokumentációját.
- lecserélheted a `String` összes előfordulását `Text`-re a TwelveDays.hs fájlban, azaz:

```haskell
recite :: Int -> Int -> [Text]
```

Ez a rész teljesen opcionális.
