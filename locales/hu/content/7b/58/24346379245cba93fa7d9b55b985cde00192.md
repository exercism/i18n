# Bevezetés

A [repeat-while ciklusok][repeat-loops] hasonlóak a `while` ciklusokhoz, de van egy lényeges különbség: a feltétel ellenőrzésére nem a ciklus törzsének végrehajtása előtt, hanem *után* kerül sor.
Ezért egy `repeat-while` ciklus kódblokkja garantáltan legalább egyszer lefut.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
