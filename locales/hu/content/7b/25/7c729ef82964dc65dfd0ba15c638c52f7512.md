# Bevezetés

A Gleamben az új adattípusokat egyedi típusokkal definiáljuk. Ezeknek több _változatuk_ lehet, mindegyiknek saját neve van.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Az egyedi típus minden változata opcionálisan tartalmazhat adatot, és a különböző változatokhoz különböző típusú adat tartozhat. Ha egy változat tartalmaz adatot, azt _rekordnak_ nevezzük.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Egy adott változat értékét úgy hozhatjuk létre, hogy a nevére hivatkozunk, ha nem tartalmaz további adatot (`Spring`), vagy függvényként hívjuk meg, ha tartalmaz (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Az egyedi típusok a Gleam minden más eleméhez hasonlóan _strukturális egyenlőséggel_ bírnak, ami azt jelenti, hogy két ugyanolyan változatú és ugyanolyan adatú érték egyenértékű.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Az egyedi típusok változataira case kifejezésekkel lehet mintaillesztést végezni.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
