# Tippek

## Általános

- [Konstansok][const]

## 1. A kölcsön fix kamatlábának ábrázolása

- A konstans típus nélküli legyen, de ott is elfogadhatónak kell lennie, ahol egy lebegőpontos szám használható.
  A függvénynek vissza kell adnia a konstanst.

## 2. Az év napjainak számának ábrázolása

- A függvénynek vissza kell adnia a konstanst.

## 3. Az év hónapjainak ábrázolása

- Létezik egy [azonosító][iota] a felsorolt konstansok létrehozásához.
  Egy blokk így néz ki: [ez][block].
  A függvénynek egy argumentumot kell fogadnia, és azt vissza kell adnia.

## 4. Egy számlaszám ábrázolása

- A konstans típus nélküli legyen, de ott is elfogadhatónak kell lennie, ahol egy string használható.
  A függvénynek vissza kell adnia a konstanst.

[const]: https://golang.org/doc/effective_go.html#constants
[iota]: https://golang.org/ref/spec#Iota
[block]: https://golang.org/pkg/debug/macho/#pkg-constants
