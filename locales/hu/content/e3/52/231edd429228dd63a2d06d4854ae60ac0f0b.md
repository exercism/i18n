# Telepítés

## Célverzió

A kurzushoz tartozó tesztelés az `alpine:3.24.1` Docker-image-en fut, amely 2026 szeptemberétől a `sqlite3 version 3.53.4` verziót használja.
Arra törekszünk, hogy a kurzushoz tartozó eszközök a legfrissebb Ubuntu LTS-kiadáson is működjenek.
Előfordulhat, hogy a felhasználóknál újabb verziók vannak telepítve, de tudniuk kell, hogy bizonyos funkciók nem feltétlenül működnek a tesztfuttatónkkal.
A funkciókat az [SQLite verziótörténetében][version-history] lehet összehasonlítani.

## Windows

Az SQLite Windowsra telepítéséhez kövesd ezeket a lépéseket:

1. Töltsd le az előre lefordított Windows-binárisokat a [hivatalos letöltési oldalról][sqlite-download].
2. Csomagold ki a letöltött ZIP-fájlt egy általad választott könyvtárba.
   Például: `C:\Program Files\sqlite3`.
3. Add hozzá a `sqlite3.exe` fájlt tartalmazó könyvtárat a rendszer PATH környezeti változójához.
   A folyamat minden Windows-verziónál kicsit más, de az információ könnyen megkereshető.
   Például [útmutató Windows 11-hez][windows-11-install] és [Windows 10-hez][windows-10-install].

## macOS

macOS-en az SQLite előre telepítve van.
Ha viszont újabb verzióra van szükséged, használhatod a [Homebrew-t][homebrew]:

```bash
brew install sqlite
```

## Ubuntu / Debian

Ubuntu és Debian alapú rendszereken az SQLite-ot az apt segítségével telepítheted:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

CentOS, Fedora és Red Hat alapú rendszereken az SQLite-ot a yum vagy a dnf segítségével telepítheted:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

Arch Linuxon az SQLite-ot a pacman segítségével telepítheted:

```bash
sudo pacman -S sqlite
```

## Egyéb telepítési módok és régebbi verziók

További információért és alternatív telepítési módokért lásd az [SQLite letöltési oldalát][sqlite-download].
