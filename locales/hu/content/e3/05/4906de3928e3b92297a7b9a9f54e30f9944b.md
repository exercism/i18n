# Tippek
Az `Either` gyakori használata, hogy olyan számítást jelöljünk vele, amely hibát eredményezhet
(ha a tényleges hiba nem érdekes, akkor az egyszerűbb `Option` típus jobb választás lehet).
Hiba hiányában az eredmény általában egy `Right` (emlékeztetőül: a »helyes« érték),
míg egy hiba egy `Left`, például egy `Left[String]`, amely hibaüzenetet tartalmaz.
Jegyezd meg, hogy a Scala 2.12-ben az `Either` alapértelmezés szerint jobbra döntő, így a várt módon működik olyan műveleteknél, mint a `filter`, a `map`, a `flatMap`, vagy egy for-kifejezésben.
Ha nem ismered az `Either`-t, elolvashatod [ezt az útmutatót](http://danielwestheide.com/blog/2013/01/02/the-neophytes-guide-to-scala-part-7-the-either-type.html). De vedd figyelembe, hogy ez az útmutató a 2.12 előtti Scala-verziókról szól. A Scala 2.12-ben nyugodtan figyelmen kívül hagyhatod a `RightProjection`-t, és elhagyhatod a `.right`-ot.
Az `Either` egy úgynevezett [monád](https://en.wikipedia.org/wiki/Monad_(functional_programming)), amely egy »számítási aspektust« fed le,
jelen esetben a hibakezelést.
A monádok helyes használata nagyon tömör, mégis elegáns
és olvasható kódot eredményezhet. A helytelen használat könnyen az ellenkezőjét eredményezheti.
Nézd meg [ezt a videót](https://www.youtube.com/watch?v=Mw_Jnn_Y5iA), hogy többet tudj meg.
## Gyakori buktatók, amelyeket érdemes elkerülnöd
Néhány ökölszabály vonatkozik az `Either`-re:
1. Ha nincs rá szükséged, ne használd. Ahelyett, hogy
```scala
def add1(x: Int): Either[String, Int] = Right(x + 1)
```
jobb, ha ezt írod:
```scala
def add1(x: Int): Int = x + 1
```
(van `Either.map`, amellyel ilyen egyszerű függvényeket alkalmazhatsz,
így nem kell őket `Either`-rel teletűzdelned).
2. Ne »csomagold ki«, ha valóban nincs rá szükséged.
Gyakran vannak beépített függvények a célodra. A korai kicsomagolás jelei az `isLeft/isRight` vagy a mintaillesztés. Például ahelyett, hogy
```scala
val x: Either[String, Int] = ...

if (x.isRight) x.right.get + 1 else x.left.get
// or
x match {
  case Right(n) => n + 1
  case Left(s) => s
}
```
jobb, ha ezt használod:
```scala
x fold (identity, _ + 1)
```
3. A monádokat for-kifejezésen belül is használhatod, ami nagyszerű.
Ez akkor ajánlott, ha több `Either` példányt szeretnél »összeállítani«. Ahelyett, hogy
```scala
val xo: Either[String, Int] = ...
val yo: Either[String, Int] = ...
val zo: Either[String, Int] = ...

xo.flatMap(x =>
  yo.flatMap(y =>
    zo.map(z =>
	    x + y + z)))
```
jobb, ha ezt használod:
```scala
for {
  x <- xo
  y <- yo
  z <- zo
} yield x + y + z
```
