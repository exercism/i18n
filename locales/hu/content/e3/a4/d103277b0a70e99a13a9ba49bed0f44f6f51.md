# Bevezetés

A *kombinatorika* annak a matematikája, hogy megszámoljuk és felsoroljuk, hányféleképpen választhatók ki vagy rendezhetők el egy gyűjtemény elemei. A Factor [`math.combinatorics`][math.combinatorics] szókészlete két alapvető kérdést fed le:

- **Kombinációk**: olyan kiválasztások, amelyeknél a sorrend *nem* számít.
- **Permutációk**: olyan elrendezések, amelyeknél a sorrend *számít*.

Mindkét kérdéshez tartozik egy *számoló* szó, amely egy számot ad vissza, és egy *felsoroló* szó, amely magukat a kiválasztásokat adja vissza, valamint egy streamelő `each-` változat, amely mindegyikkel meghív egy quotationt:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
