# Bevezetés

A Java statikusan típusos nyelv, ami azt jelenti, hogy egy változó típusa már fordítási időben ismert.
Azt, hogy egy névhez értéket rendelünk, a változó definiálásának nevezzük.
A változót a típusának explicit megadásával definiáljuk.

```java
int explicitVar = 10;
```

Egy változó értékének frissítése a `=` operátorral történik.
Itt a `=` nem a matematikai egyenlőséget jelöli.
Egyszerűen értéket rendel egy változóhoz.
Miután definiáltuk, egy változó típusa soha nem változhat.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

A Java [objektumorientált nyelv][object-oriented-programming], és minden függvényt _osztályon_ belül kell definiálni.
Az osztály definiálására a `class` kulcsszót használjuk.

```java
class Calculator {
    // ...
}
```

Az osztályon belüli függvényt _metódusnak_ nevezzük.
Minden metódusnak lehet nulla vagy több paramétere.
Minden paraméter típusát explicit módon meg kell adni, a paramétereknél nincs típuskövetkeztetés.
Hasonlóképpen a visszatérési típust is explicit módon meg kell adni.
A metódusok az értékeket a `return` kulcsszóval adják vissza.
Ahhoz, hogy egy metódust más osztályok is meg tudjanak hívni, hozzá kell adni a `public` hozzáférés-módosítót.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Egy metódus meghívása úgy történik, hogy megadjuk az osztályát és a metódus nevét, majd átadjuk az argumentumokat a metódus minden paraméteréhez.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

A scope Javában a `{` és `}` karakterek között van definiálva.

A Java kétféle megjegyzést támogat.
Az egysoros megjegyzések előtt `//` áll, a többsoros megjegyzéseket pedig a `/*` és `*/` közé kell írni.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
