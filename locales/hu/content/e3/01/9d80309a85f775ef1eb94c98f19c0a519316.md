# Tanulás

Az Exercism feladatokat és visszajelzést nyújt, de azoknak, akik most ismerkednek a Common Lisppel, nehéz lehet belevágni.
Ezek az anyagok segíthetnek az indulásban:

* [A Road to Common Lisp][road-to-cl], blogbejegyzés arról, hogyan jutott el egy ember a Common Lispig, és hogyan érdemes elkezdeni
* [Practical Common Lisp][practical-cl], teljes könyv a Common Lisp tanulásához, ingyenesen elérhető online (nyomtatásban is)
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  különböző szerzők tollából
* [Awesome Common Lisp Learning][awesome-cl]

Lásd még a Common Lisp kurzushoz tartozó Exercismen: [Fontos anyagok][track-resources].
