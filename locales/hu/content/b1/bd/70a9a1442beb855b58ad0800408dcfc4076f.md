# Névjegy

A Gleam standard könyvtára a `gleam/queue` modulban egy `Queue` típust valósít meg. Hasonló a `List` típushoz, de néhány lényeges különbséggel:

- A `Queue` típusnak nincs olyan literál szintaxisa, amellyel queue-kat lehet létrehozni vagy mintaillesztést végezni rajtuk.
- A `Queue` típusnál az elemek hatékonyan adhatók hozzá és távolíthatók el mind az elején, mind a végén, míg a `List` típusnál csak az elején lehet hatékonyan elemeket hozzáadni és eltávolítani.

A legtöbb esetben a `List` típust érdemes használnod, de amikor egy gyűjtemény végéről is tudnod kell elemeket hozzáadni és eltávolítani, a `Queue` típus jó választás.

A queue-k létrehozásához a `queue.new` és a `queue.from_list` függvényeket használhatod:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

A queue-hoz az elemeket a `queue.push_front` és a `queue.push_back` függvényekkel adhatod hozzá:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

A queue-ból az elemeket a `queue.pop_front` és a `queue.pop_back` függvényekkel távolíthatod el:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

A queue-t a `queue.to_list` függvénnyel listává alakíthatod:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## A queue-k egyenlősége

A queue-k megvalósítása miatt előfordulhat, hogy két queue, amely ugyanazokat az elemeket ugyanabban a sorrendben tartalmazza, nem egyenlő a `==` operátor szerint, amely strukturálisan hasonlítja össze az értékeket. Például:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Ha két queue-t egyenlőség szempontjából kell összehasonlítanod, használhatod a `queue.is_logically_equal` függvényt.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
