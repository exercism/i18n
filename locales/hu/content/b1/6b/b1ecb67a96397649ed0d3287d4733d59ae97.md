# Kiegészítés az utasításokhoz

## Szavak

- `tick ( matrix cols -- matrix' )`: léptesd tovább a rácsot egy generációval, és add vissza az új rácsot.

A rács minden sorát 64 bites egész számként ábrázoljuk; a `cols` az oszlopok száma (legfeljebb 64). Például

```
    0 1 0
    1 0 0
    1 1 0
```

így jelenik meg:

```
0b010
0b100
0b110
```
