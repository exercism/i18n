# Kiegészítő utasítások

## Regiszterek

| Regiszter | Használat | Típus   | Leírás                                            |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | bemenet   | cím     | nullával lezárt, hexadecimális karakterekből álló string |
| `$v0`    | kimenet   | egész szám | a bemeneti string decimális értéke             |
| `$t0-9`  | ideiglenes | bármilyen | ideiglenes tárolásra szolgál                   |
