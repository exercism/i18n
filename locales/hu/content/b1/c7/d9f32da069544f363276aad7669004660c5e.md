# Tippek

## Általános

- Minden olvasással és írással kapcsolatos szó a [`io.files`][io.files] szótárban
  található; az `utf8` kódolást, amelyet mindegyik elfogad, a
  [`io.encodings.utf8`][utf8] szótár adja.

## 1. Olvasd be az összes mérést

- A `file-lines` a sorok egy tömbjét adja vissza, a sortöréseket eltávolítva.

## 2. Keresd meg a legutóbbi mérést

- Olvasd be a sorokat a `file-lines` szóval, majd vedd az utolsót a `last`
  szóval (a `sequences` szótárból).

## 3. Olvasd be a nyers naplót

- A `file-contents` egyetlen stringként adja vissza a fájlt, sortörésekkel
  együtt.

## 4. Rögzíts egy mérést

- Nyisd meg a fájlt hozzáfűzésre, és a mérést a `print` szóval írd ki az
  idézeten belül:
  `with-file-appender ( path encoding quot -- )`. A mérés az idézeten belül
  használatos, míg az útvonal előtte fogy el, ezért a `::` lokálisok
  olvashatóvá teszik a törzset:
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`.

## 5. Írd át a naplót

- A `set-file-lines` egy sorozat minden elemét külön sorba írja, és a
  sortöréseket is hozzáadja helyetted.

[io.files]: https://docs.factorcode.org/content/vocab-io.files.html
[utf8]: https://docs.factorcode.org/content/vocab-io.encodings.utf8.html
