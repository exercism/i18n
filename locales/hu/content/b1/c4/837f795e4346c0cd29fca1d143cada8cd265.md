# Bevezetés

## Egész számok

A Gleamben kétféle szám létezik: egész számok és tizedes törtek.

Az egész számok egész értékű számok.

```gleam
let integer = 3
// -> 3
```

A Gleamben számos operátor működik egész számokkal.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```

## Tizedes törtek

A tizedes törtek olyan számok, amelyekben a tizedesjel után egy vagy több számjegy áll.

```gleam
let float = 3.45
// -> 3.45
```

A tizedes törteknek is megvan a maguk operátorkészlete.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

## Modulok

### Modulok

A Gleam-kód modulokba szerveződik, és minden fájl egy-egy Gleam-modul.

Eddig a `pub fn` szintaxissal írtunk függvényeket, ami olyan függvényt definiál, amely a többi modul számára is nyilvánosan elérhető. A `fn`-nel definiált függvények csak abban a modulban érhetők el, amelyben létrehoztuk őket, más modulokból nem használhatók.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

A Gleam-moduloknak nevük van, és a név a `src` vagy `test` könyvtáron belüli fájlútvonalukon alapul.

Például egy `src\geometry\rectangle.gleam` fájlban (Windowson) vagy `src/geometry/rectangle.gleam` fájlban (UNIX-szerű operációs rendszereken) definiált modul neve `geometry/rectangle` lenne.

### Függvények importálása más modulokból

A más modulokban definiált függvényeket importokon keresztül érjük el.
Amikor importálunk egy modult, az általa hozzáférhetővé tett összes függvény elérhetővé válik.
Az viszont, hogy hogyan érhetők el, attól függ, hogyan importáltuk a modult.

A minősített importok az alapértelmezettek, és egy ilyen modulon belüli függvényt (például a `map` függvényt a `gleam/list` modulban) úgy érünk el, hogy a modul nevét előtagként írjuk elé (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Alapértelmezés szerint a modulra hivatkozó név a modulnév utolsó része, ebben az esetben `int`, de ezt az `as` kulcsszóval megváltoztathatjuk.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

A minősítetlen importok közvetlen hozzáférést tesznek lehetővé a modul hozzáférhetővé tett függvényeihez, előtag nélkül.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

A minősített importokat érdemes előnyben részesíteni, mert világosabbá teszik az olvasó számára, hogy honnan származik egy függvény, és segítenek elkerülni a névütközéseket.


### Standard könyvtár

A Gleamnek gazdag és jól dokumentált standard könyvtára van. A dokumentáció online érhető el a [hexdocs.pm/gleam_stdlib][docs] oldalon. Mentsd el valahova ezt a linket, sokat fogod használni!

A legtöbb beépített adattípushoz tartozik egy-egy modul, amely függvényeket kínál az adott adattípussal való munkához, például az egész számokhoz a `gleam/int` modul, a stringekhez a `gleam/string` modul, a listákhoz a `gleam/list` modul, és így tovább.

[docs]: https://hexdocs.pm/gleam_stdlib/
