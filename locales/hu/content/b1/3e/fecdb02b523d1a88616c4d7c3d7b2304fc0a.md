# Bevezetés

A bináris adatokkal való munka minden nyelvben fontos fogalom, és az Elixir elegáns szintaxist kínál a bináris adatok írásához, mintaillesztéséhez és létrehozásához.

Az Elixirben a bináris adatokat bitstring típusnak nevezik. A bináris adat _típusa_ (amit nem szabad összekeverni a bináris adatokkal általában) a bitstring egy speciális formája, amelyről egy későbbi feladatban lesz szó.

A bitstring literálokat a `<<>>` bitstring speciális forma segítségével definiáljuk. Amikor bitstring literált definiálunk, az szegmensekből épül fel. Minden szegmensnek van egy értéke és egy típusa, amelyeket a `::` operátor választ el. A típus adja meg, hogy hány bitet használunk az érték kódolására. A típus teljesen elhagyható, ilyenkor az alapértelmezett érték egy 8 bites egész szám.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

A `::1` típusmegadás rövidítése a `::size(1)` írásmódnak. A hosszabb szintaxist kell használnod, ha a bitméret egy változóból származik.

## Bináris

A bináris egész literálokat írhatjuk közvetlenül kettes számrendszerbeli jelöléssel is, ha a literál elé `0b`-t teszünk. Ne feledd, hogy ezek a tesztek eredményében vagy az iex használatakor mégis tízes számrendszerbeli számként jelennek meg.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## Csonkítás

Ha a szegmens értéke meghaladja a szegmens típusának kapacitását, az érték balról csonkolódik.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## Eléfűzés és hozzáfűzés

Egy meglévő bitstring elé és mögé is fűzhetsz a speciális forma segítségével. A `::bitstring` típust a meglévő bitstringen kell használnod, ha annak mérete ismeretlen.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## Összefűzés

A változókban tárolt bitstringeket a speciális forma segítségével fűzhetjük össze. A `::bitstring` típust kell használni, amikor két ismeretlen méretű bitstringet fűzünk össze.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## Mintaillesztés

A speciális formából mintaillesztéssel is kinyerhetünk értékeket. Minden egyes rögzíteni kívánt töredéknél tudnod kell, hány bitből áll, egyetlen kivétellel: a `::bitstring` típus használható ismeretlen méretű bitstringre való mintaillesztésre, de csak az utolsó töredéknél.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## Bitstringek vizsgálata

~~~~exercism/note
A bitstringeket (a tesztfuttató vagy az iex) a létrehozásukhoz használt formátumtól
eltérő formátumban is kiírhatja. Ez a bitstringek tanulása során gyakran
zavart okoz.
~~~~

Alapértelmezés szerint a bitstringek 8 bites (egy bájtos) töredékekben jelennek meg, még akkor is, ha más méretű töredékekkel hoztad létre őket.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

Ha olyan bitstringet hozol létre, amely egy nyomtatható, UTF-8-kódolású stringet reprezentál, az stringként jelenik meg.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
