# Utasítások

Alizé online divatbutikot vezet. Közeleg a nagy éves akció, ezért szeretne olyan funkciókat készíteni, amelyek segítenek felmérni a raktárkészletet.

A raktárkészlet egyetlen elemét egy egyedi típus írja le.

```gleam
Item(
  name: "White Shirt",
  price: 40,
  quantity: 6,
)
```

## 1. Add vissza a terméknevek listáját

Valósítsd meg az `item_names` függvényt, amely termékek iterátorát kapja, és a nevük iterátorát adja vissza ugyanabban a sorrendben.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> item_names
|> iterator.to_list

// -> ["Maxi Brown Dress", "Red Short Skirt", "Black Short Skirt", "Bamboo Socks Cats"]
```

## 2. Add vissza az olcsó termékeket

Valósítsd meg a `cheap` függvényt, amely termékek iterátorát kapja, és azoknak a termékeknek az iterátorát adja vissza, amelyek 30-nál kevesebbe kerülnek.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> cheap
|> iterator.to_list

// -> [
//   Item(price: 29, name: "Black Short Skirt", quantity: 4),
//   Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
// ]
```

## 3. Add vissza az elfogyott termékeket

Valósítsd meg az `out_of_stock` függvényt, amely visszaadja azokat a termékeket, amelyekből elfogyott a készlet.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> out_of_stock
|> iterator.to_list

// -> [
//   Item(price: 50, name: "Red Short Skirt", quantity: 0),
// ]
```

## 4. Add vissza a teljes készletet

Valósítsd meg a `total_stock` függvényt, amely kiszámítja a raktáradban lévő termékek teljes mennyiségét:

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> total_stock

// -> 19
```
