# string-összefűzés

A string-összefűzés teljesen elfogadható a Crystal nyelvben, de a string összeállításának egy gyakoribb módja a [string-interpoláció][interpolation].
Például:

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
