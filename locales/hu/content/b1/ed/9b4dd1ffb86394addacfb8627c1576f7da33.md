# Utasítások

Ebben a feladatban egy `TranslationService`-t készítesz, amely alapvető fordítási szolgáltatásokat nyújt az ingyenes tagoknak, és fejlett fordítást a prémium tagoknak, minőségbiztosítással.

**Az API**

Találtál egy világűrbeli fordítási API-t, amely ésszerű időn belül teljesít bármilyen fordítási `request`-et.
Ezt szeretnéd kihasználni.
Az űrbéli fordítók rendkívül szeszélyesek, és utálják a felesleges ismétlődést, ezért _API storage_ műholdakat is biztosítanak, ahonnan `fetch`-csel lekérheted a korábbi fordításokat anélkül, hogy zavarnád őket.

**_Fordítás lekérése_**

Az `api.fetch(text)` lekéri a `text` fordítását az _API storage_-ból, és egy `promise`-t ad vissza, amely két értéket biztosít:

- `translation`: maga a fordítás
- `quality`: a minőség számmal kifejezve

Ha egy fordítás nem található az _API storage_-ban, az API egy `NotAvailable` hibát dob.
A fordításokat az `api.request` metódussal lehet hozzáadni.
Ha a „text” nem fordítható le, az API egy `Untranslatable` hibát dob.

```javascript
api.fetch('jIyaj');
// => Promise({ resolved: 'I understand' })
```

**_Fordítás kérése_**

Egyes fordítások biztosan léteznek, de még nem kerültek be az _API storage_-ba. Ez a különbség a `NotAvailable` (nincs a tárhelyen, de kérhető) és az `Untranslatable` (nem fordítható le) között.

Az `api.request(text, callback)` azt kéri, hogy készüljön el a `text` fordítása, és kerüljön be az _API storage_-ba.
Amikor elkészül, meghívódik a `callback` függvény.

- Siker esetén a `callback` az `undefined` értéket kapja: ez azt jelzi, hogy a fordítás sikeres volt, és az `api.fetch` metódussal érhető el.
- Hiba esetén a `callback` egy `error`-t kap: ez azt jelzi, hogy valami hiba történt.
  Az űrbéli API _instabil_, ami azt jelenti, hogy az API gyakran hibázik.
  Ha ez megtörténik, nyugodtan meghívhatod újra az `api.request`-et.

```javascript
api.request('majQa’', callback);
// => undefined
//
// later: the passed callback is called with undefined
//        because it was successful.
```

**⚠ Figyelem! ⚠**

<!-- prettier-ignore-start -->
~~~~exercism/caution
Az API úgy fejti ki a varázsát, hogy minden beérkező `request` hatására odateleportálja a különböző fordítókat.
Ez nagyon költséges művelet, ezért nem szabad meghívni, amikor egy fordítás *elérhető*.
Sajnos nem mindenki olvassa el a kézikönyvet, ezért létezik egy rendszer, amely kizárja a renitens felhasználókat.

Ha az `api.request`-et egy elérhető `text`-re hívják meg, az API egy `AbusiveClientError`-t dob erre a hívásra, **és minden utána következőre is**.
Ügyelj rá, hogy *soha* ne kérj fordítást, ha valamit már lefordítottak.
~~~~

## 1. Fordítás lekérése, a minőség figyelmen kívül hagyásával

Az ingyenes szolgáltatás csak azokat a fordításokat nyújtja, amelyek éppen benne vannak az _API storage_-ban.

Készíts egy `free(text)` metódust, amely az ingyenes tagoknak az _API storage_-ban már létező fordításokat nyújtja.
Hagyd figyelmen kívül a minőséget, és add tovább az API által dobott hibákat.

- Visszaadja a fordítást, ha le tudja kérni, a minőségétől függetlenül
- Továbbadja a fordítási API bármely hibáját
- Az `api.fetch` metódust használja (az `api.fetch` egy `promise`-t ad vissza)

```javascript
service.free('jIyaj');
// => Promise<...> resolves "I understand."

service.free("jIyajbe'");
// => Promise<...> rejects Error("Not yet translated")
```

## 2. Fordítások kötegének lekérése, mindent vagy semmit

Készíts egy `batch([text, text, ...])` metódust az ingyenes tagoknak, amely az ingyenes szolgáltatással lefordít egy szövegtömböt, és vagy az összes fordítást adja vissza, vagy egyetlen hibát.

- Az összes fordítással teljesül (ugyanabban a sorrendben), ha mindegyik elérhető
- Az első előforduló hibával elutasít
- `BatchIsEmpty` hibával utasít el, ha nincs megadva szöveg

```javascript
service.batch(['jIyaj', "majQa'"]);
// => Promise<...> resolves ["I understand.", "Well done!"]

service.batch(['jIyaj', "jIyajbe'"]);
// => Promise<...> rejects new Error("Not yet translated")

service.batch([]);
// => Promise<...> rejects BatchIsEmpty()
```

## 3. Fordítás kérése, legfeljebb kétszeri újrapróbálkozással

Készíts egy `request(text)` metódust a prémium felhasználóknak, amely azt _kéri_, hogy egy fordítás kerüljön be az _API storage_-ba.
A kérésnek hiba esetén automatikusan újra kell próbálkoznia.
Ugyanarra a kérésre legfeljebb **3 hívást** hajthat végre (_ne bosszantsd fel az űrbéli fordítókat!!!_).

- Ha az `api.request` nem ad vissza hibát, `undefined` értékkel teljesül
- Ha az `api.request` hibát ad vissza, próbálkozz újra legfeljebb kétszer
- Ha elfogynak az újrapróbálkozások, az utoljára kapott hibával utasíts el

```javascript
service.request("jIyajbe'");
// => Promise<...> resolves (with nothing), can now be retrieved using the fetch API
```

## 4. Fordítás lekérése, a minőség vizsgálata vagy a fordítás kérése

Készíts egy `premium(text, quality)` metódust a prémium felhasználóknak, amely lekér egy fordítást.
Ha egy fordítás `NotAvailable`, kérd a fordítást, és miután bekerült az _API storage_-ba, kérd le.
A metódus csak akkor adja vissza a fordítást, ha az eléri egy bizonyos `quality` küszöböt.

- Ha az `api.fetch` sikeresen teljesül, a teljesülés előtt ellenőrizd a minőséget
- Ha az `api.fetch` elutasít, helyette _kérd_ a fordítást
- Ha az `api.request` elutasít, add tovább a hibát

```javascript
service.premium("jIyajbe'", 100);
// => Promise<...> resolves "I don't understand."

service.premium("'arlogh Qoylu'pu'?", 100);
// => Promise<...> rejects QualityThresholdNotMet()

service.premium("'arlogh Qoylu'pu'?", 40);
// => Promise<...> resolves "What time is it?"
```
