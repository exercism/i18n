# A részletekről

## Opcionális típusok

A Swift az [_opcionálisokat_][optionals] arra használja, hogy a programozók kifejezhessék egy érték esetleges hiányát.
Az opcionális egy olyan típus, amely vagy tartalmaz egy értéket, vagy [`nil`][nil], ami az érték hiányát jelöli.
Egy opcionális használatához a programnak ellenőriznie kell, hogy tényleg van-e benne érték, mielőtt kicsomagolás után felhasználná.

Bármelyik típusból lehet opcionálist csinálni, ha a típusnév végére egy `?` jelet írunk.
Egy opcionális egész szám típusa tehát `Int?`, egy opcionális string típusa pedig `String?` lenne.
Az opcionális típusú konstansok és változók definiálása és az értékadás nekik ugyanúgy történik, mint a nem opcionális típusú értékek esetében.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

Egy opcionális típusú változónak úgy adhatod meg az érték hiányát, hogy a speciális `nil` értéket rendeled hozzá.
A `nil` minden opcionális típussal használható, de a két különböző opcionális típushoz rendelt `nil` nem ugyanaz a típus, nem cserélhetők fel, sőt még össze sem hasonlíthatók.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

Azt is vedd észre, hogy bár a `nil` bármelyik opcionális típushoz hozzárendelhető, egy nem opcionális típushoz nem rendelhető hozzá (még akkor sem, ha az valójában nem tartalmaz `nil`-t).
Egy nem opcionális típust váró metódusnak pedig nem adhatsz át opcionális típust anélkül, hogy előbb ki ne csomagolnád.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## Opcionális értékek használata

Mivel az opcionális típusok nem ugyanazok a típusok, mint az alaptípusaik, a két típust nem lehet ugyanúgy használni.
Például: az `Int("123") + 1` fordítási hibát eredményez: „Value of optional type 'Int?' must be unwrapped to a value of type 'Int'”.
Ez azért van, mert az `Int("123")` egy opcionális `Int?` típust ad vissza, nem `Int` típust, hiszen ha a string nem alakítható át egész számmá, az eredmény `nil` lesz.
Ahhoz, hogy a konverzió eredményeként kapott `Int` értéket elérjük, előbb „ki kell csomagolnunk”.

Erre a Swiftben leggyakrabban az `if-let` és a `guard-let` szerkezetet használjuk, amelyek az [_opcionális kötést_][optional-binding] valósítják meg: ellenőrzik, hogy `nil`-e az érték, és ha létezik érték, az egyik ágon a kicsomagolt értéket egy megadott névhez kötik, ha pedig `nil`-t találnak, egy másik ágon folytatják.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

Érdemes megjegyezni, hogy a `safeNum` változó típusa `Int`, nem pedig `Int?`.
Az alábbi példában a `num` típusa `Int?`, a `safeNum` típusa pedig `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

Ez az _opcionális kötés_ azért fontos, mert kicsomagolja (vagyis „eltávolítja”) az opcionális típust az értékből, így az nem opcionális értékként használható.
Ha csak feltétellel ellenőriznéd, hogy `nil`-e az érték, az érték típusa továbbra is opcionális maradna:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

A `guard-let` pedig azokban az esetekben használható, amikor korán szeretnél visszatérni:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## Opcionális értékek összehasonlítása

Vedd észre, hogy bár két opcionális alaptípusa összehasonlítható a szokásos összehasonlító operátorokkal, maguk az opcionálisok nem hasonlíthatók össze.
Csak az egyenlőségüket lehet ellenőrizni.
Két opcionális akkor egyenlő, ha mindkettő `nil`, vagy ha a bennük tárolt értékek az alaptípusukon belül egyenlők.

Írhatunk azonban olyan kódot, amely egyedi összehasonlítást végez két opcionális értéken.
Az alábbi példában egy `switch` utasítás csak akkor ad vissza `true` értéket, ha mindkét opcionális érték nem `nil`, és az első érték kisebb a másodiknál.
Ehhez az _opcionális minta_ `varName?` formáját használja, amely csak a nem `nil` opcionálisokra illeszkedik, és az opcionálison belüli értéket a `varName` névhez köti.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
