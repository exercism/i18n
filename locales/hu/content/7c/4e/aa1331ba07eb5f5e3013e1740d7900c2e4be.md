# Névjegy

A C# egy statikusan típusos nyelv, ami azt jelenti, hogy mindennek van típusa fordítási időben. Amikor nevet választasz egy [változónak][variable], azt a változó definiálásának nevezzük. Miután egy változót definiáltál, egy érték beállítását vagy frissítését értékadásnak nevezzük. Egy változót definiálhatsz úgy, hogy explicit módon megadod a típusát, vagy úgy, hogy a [`var` kulcsszót][var] használod, amivel a C# fordítója a hozzárendelt érték alapján következtet a típusára. A `var` használatát _típuskövetkeztetésnek_ nevezzük.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

A változó értékét a [`=` operátorral][assignment] adhatod meg és frissítheted. Miután definiáltad, a változó típusa soha nem változhat meg.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

A C# objektumorientált nyelv, és minden [függvényt][function] egy _osztályon_ belül kell definiálni, az osztályokat pedig a [`class` kulcsszóval][classes] hozzuk létre. Az objektumokat (vagy _példányokat_) a `new` kulcsszóval hozzuk létre.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Az osztályon belüli függvényt _metódusnak_ nevezzük. Minden [metódusnak][methods] lehet nulla vagy több paramétere. Minden paraméternél explicit módon meg kell adni a típust, a paramétereknél nincs típuskövetkeztetés. Hasonlóképpen a visszatérési típust is explicit módon meg kell adni. A metódusok a [`return` kulcsszóval][return] adnak vissza értéket. Ahhoz, hogy egy metódust más fájlok kódjából is meg lehessen hívni, hozzá kell adni a `public` hozzáférési módosítót.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

A metódusokat pont (`.`) szintaxissal hívjuk meg egy példányon, megadva a meghívandó metódus nevét, és átadva az argumentumokat a metódus minden paraméteréhez. Az argumentumoknál opcionálisan megadhatod a hozzájuk tartozó paraméter nevét.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Ha a meghívni kívánt metódus ugyanabban az osztályban van definiálva, mint a hívó metódus, az osztály nevét elhagyhatod.

Ha egy metódus nem használja az objektum _állapotát_, akkor a `static` módosítóval _statikussá_ tehető. A statikus metódusokat is pont (`.`) szintaxissal hívjuk meg, de nem az osztály egy példányán, hanem magán az osztályon.

Ha egy osztálynak csak statikus metódusai vannak, maga az osztály is statikussá tehető a `static` módosítóval. Ez fejezi ki az osztály szándékát.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

A scope a C#-ban a `{` és `}` karakterek között van meghatározva.

A C# kétféle [megjegyzést][comments] támogat. Az egysoros megjegyzések előtt `//` áll, a többsoros megjegyzéseket pedig `/*` és `*/` közé írjuk.

Az egész értékek egy vagy több (egymást követő) számjegyből állnak, és támogatják az [alapértelmezett matematikai operátorokat][operators].

A változóneveknek [be kell tartaniuk néhány szabályt][identifier-names], például hogy betűvel vagy aláhúzással kezdődjenek, és [követniük kell a C# elnevezési konvencióját][naming-guidelines]. Ha egy változónév ütközik egy fenntartott [C# kulcsszóval][csharp-keywords], akkor a `@` jellel kell escape-elni. Ennek a jelölésnek a használata nem ajánlott, de kivételes esetekben előfordulhat, például: `var @this`, `var @class` vagy `var @var`.

Van néhány olyan fogalom, amely annyira alapvető a C#-hoz hasonló C-családba tartozó nyelvekben, hogy szinte minden nem triviális kódrészletben természetes módon előfordul. Ezek a [mutáció][mutation] és a [scope][scope]. A mutáció azt jelenti, hogy egy változó értéke a program futása során megváltozhat. A scope azt jelenti, hogy egy programelem nevéhez tartozó érték csak a kód azon „területén” belül érhető el, ahol definiálták. A fő kódrészek C#-ban az _osztály/struktúra_ és a _függvény_ (többnyire metódusok), de ide tartozhatnak a ciklusok és más szerkezetek törzsei is.
