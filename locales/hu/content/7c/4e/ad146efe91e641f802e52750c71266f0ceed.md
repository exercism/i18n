# Karbantartóknak

## Tesztek generálása: `bin/generate_tests.py`

A tesztfájlok a [exercism/problem-specifications](https://github.com/exercism/problem-specifications)
kanonikus adataiból generálódnak egy Jinja-sablon segítségével, amely minden feladatnál a
`.meta/template.j2` fájlban található.

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

A szkript a problem-specifications tárolót a configlet gyorsítótárából olvassa
(`~/.cache/exercism/configlet/problem-specifications`, amelyet a `bin/configlet sync` tölt fel),
vagy egy `problem-specifications` nevű szülőkönyvtárból.
Csak a `.meta/tests.toml` fájlban szereplő esetek generálódnak.

A Fortran stringliteráljai nem tartalmazhatnak olyan escape-szekvenciákat, mint a `\n` és a `\t`.
Az `escape_quote_whitespace` sablonszűrő ezeket `" // NEWLINE // "`, `" // TAB // "` és
`" // CARRIAGE_RETURN // "` alakúra írja át, ezért a sablonnak deklarálnia kell ezeket a
konstansokat (lásd `exercises/practice/bob/.meta/template.j2`).

### Előfeltételek

- Működő CMake és Fortran-fordító
- Python 3.12+ a `jinja2` csomaggal
- git

### Munkafolyamat egy új feladat hozzáadásához

A `bob` feladatot használva példaként:

- Hozz létre egy új ágat, pl. `git checkout -b exercise-bob`
- Futtasd a `bin/add-exercise bob` parancsot (ehhez `jq` és `curl` kell). Ez:
  - letölti a configletet, és lefuttatja a `configlet create` parancsot, amely hozzáadja a feladatot a `config.json` fájlhoz, valamint szinkronizálja a dokumentációját, a metaadatait és a `tests.toml` fájlját a problem-specifications tárolóból
  - rendezi a `config.json` fájlt a `bin/reorder-exercises` szkripttel
  - átmásolja az `exercises/shared/CMakeLists.txt` fájlt a feladat könyvtárába
  - létrehoz egy vázlatos megoldást, egy vázlatos `.meta/example.f90` fájlt és egy kezdő `.meta/template.j2` fájlt (az `exercises/shared/template.j2` alapján)

  A GitHub-felhasználónevedet kéri be, kivéve ha átadod a `-a <username>` kapcsolót, és az 1-es nehézséget állítja be, kivéve ha átadod a `-d <difficulty>` kapcsolót.

- Szerkeszd a `.meta/template.j2` fájlt úgy, hogy minden eset a megfelelő függvényt hívja meg a megfelelő bemenetekkel, majd generáld le a teszteket:

  ```bash
  bin/generate_tests.py bob
  ```

- Írj egy működő megoldást a `.meta/example.f90` fájlba. A tanuló fájlját (pl. `bob.f90`) cseréld le a tesztek által hívott függvények vagy szubrutinok vázára, hogy segíts a tanulónak az indulásban
- Győződj meg róla, hogy minden teszt sikeres, a teljes buildet a tároló gyökeréből futtatva:

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- Futtasd a `bin/reorder-exercises` és a `bin/configlet lint` parancsot
- Ha minden sikeres, nyiss egy pull requestet a változtatásaiddal

### A `CMakeLists.txt` módosítása

Amikor a cmake fájlt módosítod, frissítsd a mesterpéldányt az `exercises/shared/` könyvtárban, és a `bin/update-cmake-files` szkripttel másold át az összes feladat könyvtárába.
