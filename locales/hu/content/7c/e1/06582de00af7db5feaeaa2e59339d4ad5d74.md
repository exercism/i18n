# Bevezetés

Az `if/else` kifejezésekkel is megvalósítható feltételes logika, de a Haskellben erre van egy nagyobb erejű eszköz is: a [mintaillesztés][pattern-matching].
A mintaillesztéssel egy értéket egy vagy több _minta_ ellen lehet megvizsgálni.
Ilyen minta például a _konstans minta_, amely egy értéket egy konstanshoz illeszt (például `1` vagy `"hello"`).

Függvények definiálásakor különböző mintákhoz külön függvénytörzset adhatsz meg.
Ez letisztult, egyszerű és jól olvasható kódhoz vezet.
Bármilyen adattípusra illeszthetsz mintát, számokra, karakterekre, listákra, tuple-ökre stb.

Például egy egyszerű függvény, amely egy egész számot (`Int`) vesz át, és _1_-gyel közelebb visz a _0_-hoz, így írható le:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

A mintaillesztés akkor kezd igazán ragyogni, ha más mintákkal együtt használod, például a _változó mintával_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

A fenti példa a _0_ kivételével minden bemenetet ugyanúgy kezel, és negatív számokra hibás eredményt adna.
Ezt feltételes mintákkal, azaz _őrökkel_ lehet megoldani, amelyeket a `|` szimbólummal fejezünk ki:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

A fenti példákban nem minden lehetséges bemenethez tartozik illeszkedő minta.
A fordító ezt észleli, és figyelmeztetést ír ki.
Ez a Haskell egyik nagyon hasznos tulajdonsága, amely segít lefedni az összes lehetséges ágat, hogy elkerüljük a futásidejű hibákat.
Ezt _kimerítő ellenőrzésnek_ nevezik.
A figyelmeztetés megszüntetéséhez minden esetet kezelned kell.
Az _őrökön_ belül az `otherwise` kifejezést használhatod a `True` szintaktikai cukraként, hogy elkapd az összes többi mintát.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

A mintaillesztés egy értéket fentről lefelé haladva megvizsgál minden mintával szemben, amíg nem talál egy illeszkedő mintát, és végre nem hajtja az ahhoz a mintához tartozó logikát.
**A minták sorrendje számít!**
