# Bemutató

A [szimbólumok][symbols] nevesített azonosítók, amelyekkel egy értékre hivatkozhatsz.
A szimbólumokat szimbólumliterállal hozhatod létre: egyszerűen a név elé írj egy `:` karaktert, például `:foo`.
Idézőjelek között is írhatók, például `:"foo"`, így például szóköz is szerepelhet a névben.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

A szimbólumok a nyelv számos helyén előfordulnak, például namedtuple-ök kulcsaiként, illetve metódus- és változónevek jelölésére.

## Szimbólumok a Crystalben

A Crystal szimbólumai meglehetősen különböznek a Rubyétól.
A Crystalben a szimbólum egyfajta konstans, ezért fordítási időben kap értéket.
Ez azt jelenti, hogy szimbólumokat nem lehet dinamikusan létrehozni, ami a Rubyban viszont lehetséges.

A Crystalben a szimbólumokat `Int32`-ként ábrázolják, ezért rendkívül hatékonyak.

## Konvertálás

A szimbólumokat át lehet alakítani stringgé, fordítva viszont nem.
Ez azért van, mert a szimbólumok fordítási időben jönnek létre, a stringek pedig futási időben.

```crystal
:foo.to_s # => "foo"
```
