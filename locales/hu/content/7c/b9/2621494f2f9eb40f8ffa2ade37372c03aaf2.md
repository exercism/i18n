# Instrukciók

Leslie-nek, a Lisp-űrlénynek bevásárolnia kell. Nagyon fontos, hogy legyen bevásárlólistája. Az ember hozzáad dolgokat, és levesz róla.

Persze egy Lisp-űrlénynek nem elég a papír meg a toll. Ráadásul a „list” szó a „Lisp” szó nagy része! Biztosan meg kell írni néhány függvényt, amelyek segítenek nyilván tartani a bevásárlást.

Segítesz Leslie-nek nyilván tartani a bevásárlólistát?

## 1. Új lista készítése

Először is Leslie-nek létre kell hoznia egy üres listát. Erre tökéletes lenne egy `new-list` nevű függvény.

```lisp
(new-list) ; => ()
```

Jaj, ne... Leslie-nek már most eszébe jutott néhány dolog, ezért kell neki egy függvény, amely három elemet vesz át (szerencsére Leslie mindig csak három elemből álló listát készít. Se többet, se kevesebbet!), és ezekből új bevásárlólistát hoz létre. Írj egy `list-of-things` függvényt, amely három elemet vesz át, és visszaad belőlük egy listát.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Dolgok hozzáadása a listához

Mielőtt elindul a boltba, Leslie átnézi a kamrát, hogy lássa, mire van szüksége. Segíts neki egy `add-to-list` függvény megírásával, amely hozzáad egy elemet a lista elejéhez.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. Mi következik a listán?

Vásárlás közben Leslie szeretné tudni, hogy mi után nézzen legközelebb. Szeret előre belepillantani a listába, hogy lássa a második, a harmadik, sőt a huszonharmadik elemet is (ez a szerencseszáma).

- A `first-thing` a lista első elemét adja vissza
- A `second-thing` a másodikat
- A `third-thing` a harmadikat
- A `twenty-third-thing` a huszonharmadikat

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Egy dolog eltávolítása a listáról

Leslie megkeresi a lista első elemét, és leveszi a polcról.
Segíts neki egy `remove-first-item` függvény megírásával, amely a bemeneti lista minden elemét visszaadja, kivéve az elsőt.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Nagyobb listák kisebbekből

Leslie rájött, hogy véletlenül két bevásárlólistát készített egy helyett! Írj egy `list-append` függvényt, amely olyan listát ad vissza, amelyben az első lista elemeit a második lista elemei követik.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. Milyen hosszú a lista?

Leslie kezd aggódni, hogy ez a bevásárlás elhúzódik. Hány dolog is van ezen a listán? Írj egy `just-how-long` függvényt, amely megmondja, milyen hosszú a listája.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
