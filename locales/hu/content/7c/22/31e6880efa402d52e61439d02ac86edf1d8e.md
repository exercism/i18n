# Konstruktor tulajdonság-promóció

Azokban az osztályokban, amelyek sok tulajdonságot deklarálnak, külön kell deklarálni az osztályt, a tulajdonságait, majd egy konstruktort, amely beállítja ezeket a tulajdonságokat, és ez rengeteg ismétléssel jár.
A konstruktor tulajdonság-promócióval csökkenthetjük az ismétlés mértékét.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
