# Utasítások

Ebben a feladatban még egy kis kódot írunk, ami a kedvenc szakácskönyvedből származó remek lasagnéd elkészítéséhez és megsütéséhez kapcsolódik.

Öt részfeladat vár rád.
Az első magával a sütéssel kapcsolatos, a másik négy a tökéletes előkészítésről szól.

## 1. Állapítsd meg, hogy elkészült-e a lasagne

Amikor lasagne van a sütőben, szeretnéd tudni, hogy kiveheted-e már vagy sem.
Hogy a lasagne ne égjen meg a sütőben, általában beállítasz egy időzítőt.
Néha viszont megfeledkezel róla.

Írj egy `cookingStatus` függvényt, amely paraméterként fogadja az időzítőn maradt időt percekben.
A függvénynek három lehetséges eredménye lehet.

- Ha az időzítő `0`-t mutat, az eredmény a `'Lasagna is done.'` legyen.
- Ha az időzítő bármilyen más számot mutat, az eredmény a `'Not done, please wait.'` legyen.
- Ha a függvényt időzítőérték nélkül hívod meg, az eredmény a `'You forgot to set the timer.'` legyen.

Az időzítő soha nem mutat 0-nál kisebb értéket.

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. Becsüld meg az előkészítési időt

A következő lasagnéhez, amit elkészítesz, szeretnél elég időt fenntartani, hogy aztán élvezhesd a sütést.
Már megtervezted, milyen rétegekből áll majd a lasagne.
Most ez alapján szeretnéd megbecsülni, mennyi ideig tart az előkészítés.

Készíts egy `preparationTime` függvényt, amely paraméterként fogadja a rétegek tömbjét és a rétegenkénti átlagos előkészítési időt percekben.
A függvény adja vissza a teljes előkészítési idő becslését a rétegek száma alapján.
Ha a függvényt az átlagos előkészítési idő megadása nélkül hívod meg, akkor `2` percet kell feltételezni helyette.

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. Számítsd ki a szükséges tészta és szósz mennyiségét

Az idő fenntartása mellett szeretnél elegendő szószt és tésztát is biztosítani ahhoz, hogy megsüsd álmaid lasagnéjét.
A lasagne minden tésztarétegéhez 50 gramm tésztára lesz szükséged.
Minden szószréteghez 0,2 liter szószra lesz szükséged.

Definiáld a `quantities` függvényt, amely paraméterként egy rétegekből álló tömböt vesz át.
A függvény ezután meghatározza, mennyi tészta és szósz kell az étel elkészítéséhez.
Az eredményt egy objektumként kell visszaadni, amelynek kulcsai `noodles` és `sauce`.

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. Add hozzá a titkos összetevőt

Nemrég meglátogattál egy barátodat, és lasagnét ettél nála.
Fantasztikus volt, és volt benne valami különleges.
A barátod elküldte az összetevők listáját, és elárulta, hogy a lista utolsó eleme az a „titkos összetevő", amitől az étel olyan különleges lett.
Most te is szeretnéd hozzáadni ezt a titkos összetevőt a saját receptedhez.

Írj egy `addSecretIngredient` függvényt, amely paraméterként két, összetevőket tartalmazó tömböt fogad.
Az első paraméter a barátod által küldött lista, a második pedig a saját recepted összetevőlistája.
A függvény fűzze hozzá a barátod listájának utolsó elemét a te listád végéhez.
A receptedet képviselő tömböt közvetlenül kell módosítani, és a függvény ne adjon vissza semmit.
Az első argumentumot viszont nem szabad módosítani.

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. Méretezd át a receptet

A szakácskönyvedben szereplő mennyiségek csak két adag lasagnéhez elegendőek.
Mivel legközelebb több emberre szeretnél főzni, szeretnéd kiszámolni a különböző adagszámokhoz szükséges mennyiségeket.

Készíts egy `scaleRecipe` függvényt, amely két paramétert vesz át.

- Egy receptobjektum, amely a 2 adaghoz szükséges mennyiségeket tartalmazza.
  Az objektum formátumát az alábbi példában láthatod.
- Az elkészíteni kívánt adagok száma.

A függvény adjon vissza egy receptobjektumot a kívánt adagszámhoz szükséges mennyiségekkel.
Az eredeti receptet viszont meg szeretnéd őrizni.
Ez azt jelenti, hogy ebben a részfeladatban a recept argumentumot nem szabad módosítani.

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
