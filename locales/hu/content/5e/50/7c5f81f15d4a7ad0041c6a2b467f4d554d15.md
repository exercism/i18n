# Részletek

[`fold`][fold] egy [fogyasztó iterátoradaptor][consuming iterator adaptor], amely egy függvényt alkalmaz az iteráció minden elemére, és az eredményt egy új értékbe gyűjti.

A `fold` minden lépése két argumentumot vár. Az első az akkumulátor kezdőértéke. A második egy closure, amely maga is két argumentumot kap: az akkumulátort és egy elemet. A closure visszatérési értéke lesz az akkumulátor következő értéke. Amikor az iterátor kimerül, a `fold` az akkumulátor végső értékét adja vissza.

A `fold`-ot akkor érdemes használni, ha egy gyűjteményt egyetlen értékké szeretnél alakítani. Ha például a páros számok összegét szeretnéd megkapni:

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

A kimenet `30`.

Amit `fold`-dal meg lehet csinálni, azt gyakran elvégzi egy vagy több másik függvény is. A fenti esetben ha a `(1..=10)`-en [`filter`][filter]-t alkalmaznánk, majd [`sum`][sum]-ot, az kevesebb kód lenne, és ugyanarra az eredményre jutnánk, például így:

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

Más, a `fold`-nál gyakrabban használt függvények például a [`product`][product] és a [`collect`][collect].

Az akkumulátor nem csak számértékekhez használható. Például:

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

A kimenet `FeeFiFoFum`
