# Utasítások

Az [Armstrong-szám][armstrong-number] olyan szám, amelyet úgy kapsz, hogy minden számjegyét a számjegyek számának megfelelő hatványra emeled, majd az így kapott értékeket összeadod.

Például:

- A 9 Armstrong-szám, mert `9 = 9^1 = 9`
- A 10 _nem_ Armstrong-szám, mert `10 != 1^2 + 0^2 = 1`
- A 153 Armstrong-szám, mert: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- A 154 _nem_ Armstrong-szám, mert: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

Írj kódot annak eldöntésére, hogy egy szám Armstrong-szám-e.

[armstrong-number]: https://en.wikipedia.org/wiki/Narcissistic_number
