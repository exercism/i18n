# Bevezetés

A Kotlinban az osztályokkal adatokat és viselkedést zárhatsz egységbe.
Az osztályt a `class` kulcsszóval deklarálod.
Például:

```kotlin
class Car
```

Az osztály egy példányát úgy hozod létre, hogy meghívod.

```kotlin
val instance = Car()
```

## Tulajdonságok

A fenti példákban a `Car` osztályt tulajdonságok nélkül deklaráltuk.
Az osztály tulajdonságait a törzsben, a `{}` között deklarálhatod: a módosítható tulajdonságokhoz `var`, a módosíthatatlanokhoz `val` kell.
Például:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

Másik lehetőség, hogy a tulajdonságokat egy olyan konstruktorban definiálod, amely megkapja őket.

## Konstruktorok

A Kotlinban kétféle konstruktor van: elsődleges és másodlagos.
Az elsődleges konstruktort az osztály deklarációjával egy sorban deklarálod.
Például:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

A `constructor` kulcsszó elhagyható, ha nincsenek annotációk és láthatósági módosítók:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
A Kotlinban az osztály törzs nélkül is definiálható, ha csak tulajdonságokat tartalmaz; a kapcsos zárójelek (`{}`) nem szükségesek:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

Egy osztálynak csak egy elsődleges konstruktora lehet.
A másodlagos konstruktorok olyan további konstruktorok, amelyeket a `constructor` kulcsszóval, az osztály törzsében deklarálva adhatsz hozzá.
Például:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

A másodlagos konstruktoroknak a `this` meghívásával kell meghívniuk az elsődleges konstruktort.

## Kezdőérték-blokkok

Az elsődleges konstruktor állítja be az osztály tulajdonságait.
Ha az objektum létrehozása közben többre van szükség, további műveleteket `init` blokkokkal végezhetsz.

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## Függvények

A függvényeket az osztály törzsében definiálhatod.
Például:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## Láthatóság

A tulajdonságok és függvények láthatósága `private`, `public`, `internal` vagy `protected` lehet.

- `private`: csak az osztályon belülről érhető el
- `protected`: az osztályon belülről és az alosztályokból is elérhető
- `internal`: az ugyanabban a modulban lévő elemek érhetik el
- `public`: az osztályt használó más komponensek is elérhetik

Például:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
