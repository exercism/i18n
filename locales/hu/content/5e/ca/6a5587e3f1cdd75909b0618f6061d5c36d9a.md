# A tesztek futtatása

Válaszd ki az operációs rendszeredet:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Nyisd meg a Command Promptot.
2. Töltsd le az első feladatot:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Lépj be a feladat mappájába:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Futtasd le a teszteket:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Ne aggódj, ha eleinte megbuknak a tesztek, minden feladatot így kezdesz el.)_

5. Oldd meg a feladatot. Keresd meg és dolgozd át az `instructions.append.md` útmutatót ([megtekintés a GitHubon][hello-world-tutorial]).

Sok sikert! Jó szórakozást!

## macOS

1. A terminálablakban töltsd le az első feladatot:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Lépj be a feladat mappájába:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. Futtasd le a teszteket:

   ```sh
   ./gradlew test
   ```

   _(Ne aggódj, ha eleinte megbuknak a tesztek, minden feladatot így kezdesz el.)_

4. Oldd meg a feladatot. Keresd meg és dolgozd át az `instructions.append.md` útmutatót ([megtekintés a GitHubon][hello-world-tutorial]).

Sok sikert! Jó szórakozást!

## Linux

1. A terminálablakban töltsd le az első feladatot:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Lépj be a feladat mappájába:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. Futtasd le a teszteket:

   ```sh
   ./gradlew test
   ```

   _(Ne aggódj, ha eleinte megbuknak a tesztek, minden feladatot így kezdesz el.)_

   Ha a következő hibát kapod:

   ```sh
   ./gradlew: Permission denied
   ```

   Akkor a fájlról hiányzik a futtatási jogosultság. Ennek javításához futtasd ezt:

   ```sh
   chmod +x ./gradlew
   ```

   És most már le kell tudnod futtatni az előző parancsot.

4. Oldd meg a feladatot. Keresd meg és dolgozd át az `instructions.append.md` útmutatót ([megtekintés a GitHubon][hello-world-tutorial]).

Sok sikert! Jó szórakozást!

[hello-world-tutorial]: https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial
