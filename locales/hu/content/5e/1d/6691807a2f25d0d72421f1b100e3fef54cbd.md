# Utasítások

Ebben a feladatban visszatérsz a szalonok világába (amelyek először a `datetimes` feladatban bukkantak fel). Ahogy több más projektjeidnél is történt, egy másik ügyfeled is nagy sikert ért el, és a New York-i bázisuk mellett Londonban és Párizsban is nyitott üzleteket.

## 1. Add meg az adminisztrátoroknak a UTC (egyeztetett világidő) szerinti időpontok helyi idő szerinti megfelelőjét

Valósítsd meg a statikus `Appointment.ShowLocalTime()` metódust, amely átvesz egy UTC szerinti időt, és helyi időként adja vissza

```csharp
// For a student in NY
Appointment.ShowLocalTime(new DateTime(2030, 7, 25, 13, 45, 0));
// => {2030, 7, 25, 8, 45, 0}
```

## 2. Ütemezz időpontokat New Yorkban, Londonban és Párizsban

A szalonok maguk felelősek a saját foglalásaik felvételéért. A megadott idő a szalon helyszíne szerinti helyi idő. Ha például valaki 13:45-öt ad meg egy időpontra a New York-i szalonban, akkor azt várja, hogy az ügyfél éppen ebéd után érkezik meg. Hasonlóképpen, ha valaki 13:45-öt adna meg a londoni szalonhoz, ő is azt várná, hogy az ügyfél éppen ebéd után érkezik meg.

Hasznos lesz, ha ismered New York, London és Párizs időzóna-azonosítóját.

Macen (OSX) és Linuxon ezek a következők:

- New York - America/New_York
- London - Europe/London
- Paris - Europe/Paris

Windowson pedig ezek:

- New York - Eastern Standard Time
- London - GMT Standard Time
- Paris - W. Europe Standard Time

Valósítsd meg a statikus `Appointment.Schedule()` túlterhelést, amely átvesz egy helyszínt és egy időpontot leíró szöveget, és visszaadja az időpont UTC szerinti idejét.

A `Schedule()` megvalósításának lehetővé kell tennie, hogy a kód lefordítás után Linuxon, Windowson és Macen is fusson. Ez az első feladat, ahol foglalkoznod kell az operációs rendszerrel. Külön kódelágakra lesz szükség, hogy kezelni tudd az időzóna-azonosítók fent leírt eltéréseit.

A bemenetként kapott dátum-idő szövegek garantáltan érvényesek.

```csharp
Appointment.Schedule("7/25/2030 13:45:00", Location.Paris);
// => {2030, 7, 25, 11, 45, 0}
```

## 3. Küldj figyelmeztetéseket az ügyfeleknek az időpont előtti időközökben

Valósítsd meg a statikus `Appointment.GetAlertTime()` metódust, amely 1 nappal (korai), 1 óra 45 perccel (normál) és 30 perccel (késői) az időpont előtt küldi a figyelmeztetéseket.

```csharp
Appointment.GetAlertTime(new DateTime(2030, 7, 25, 14, 45, 0), AlertLevel.Early);
// => {2030, 7, 24, 14, 45, 0}
```

## 4. Ha a nyári időszámítás nemrég változott, üzenetet küldünk az ügyfeleknek, hogy emlékeztessük őket.

Valósítsd meg a statikus `Appointment.HasDaylightSavingChanged()` metódust, amely `true` értéket ad vissza, ha a nyári időszámítás az elmúlt 7 napban aktívvá vagy inaktívvá vált.

```csharp
Appointment.HasDaylightSavingChanged(new DateTime(2020, 3, 30, 14, 45, 0), Location.London);
// => true
```

## 5. A helyi dátum-idő formátum használata az időpontok megadásához

Ahhoz, hogy az időpontokat a helyi személyzet számára ismerős formátumban lehessen megadni, az a feladatod, hogy készíts egy kísérleti rutint, amellyel a dátumok és az időpontok a szalon helyszínének megfelelő alapértelmezett formátumban adhatók meg.

Valósítsd meg az `Appointment.NormalizeDateTime()` metódust, amely átvesz egy jól formázott, a helyszínhez illő formátumú dátum-idő szöveget, és `DateTime` objektummá alakítja. A dátum-idő UTC szerinti idővé alakítására nem teszünk kísérletet.

Ha hibás formátumot adnak meg, akkor egy 1/1/1 értékű `DateTime` objektumot kell visszaadni.

```csharp
Appointment.NormalizeDateTime("25/11/2019 13:45:00", Location.London);
// => {2019, 11, 25, 13, 45, 0}
Appointment.NormalizeDateTime("25/11/2019 13:45:00", Location.NewYork);
// => {1, 1, 1, 0, 0, 0}
```
