# Rust-referencia

## Fogalmak

A Rust tanulófeladatok az alapoktól a nyelv mesterfokú ismeretéig tanítják a fogalmakat. Az alábbiakban osztályozzuk és listázzuk őket.

Az Exercism fogalmai gyakorlati módon szolgálják a tanulókat, ezért különböznek az absztrakt elképzelésektől. Ez a dokumentum meghatározza, mit jelentenek ezek a fogalmak a Rustban. Az alábbi vizuális csoportosítást azért adtuk hozzá, hogy segítsük a kurzuskarbantartókat egy hatékony referenciadokumentum létrehozásában. Az ilyen csoportosítások _nem_ pedagógiai felosztások. Ezért kérünk, ne hivatkozz rájuk a tanítás során.

A jelölőnégyzetek azt jelzik, hogy a fogalmakat már tanítjuk-e a tanulófeladatok hozzárendelési listájában.

## Tanulófeladatok hozzárendelése

Bár az az ideális, ha a fent felsorolt fogalmak mindegyikéhez egyetlen tanulófeladat tartozik, amely pontosan egy fogalmat tanít, és csak az előfeltételeire támaszkodik, ez nem teljesen gyakorlatias. Például nehéz lenne olyan feladatot tervezni, amely megtanítja, mi az a függvény, anélkül hogy bármit is tudnánk a primitívekről; ugyanígy nehéz lenne primitíveket tanítani tesztcsomaggal, a függvények ismerete nélkül.

A táblázatban szereplő feladatoknak egy DAG-ot kell alkotniuk, amely végül lefedi az összes fent felsorolt fogalmat.

| feladat                  | előfeltételek                                | tanít                                                    | leírás                                                                           |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | függvények, tesztcsomagok                                | add vissza a `&str` literált: `"hello world"`                                     |
| `compiled-calculator`    | `hello-world`                                | egész számok, változóértékadás                           | végezz el egy sor matematikai műveletet, és implicit módon add vissza az eredményt |
| `conditionals`           | `hello-world`                                | elágazások                                               | háromágú `if` / `else if` / `else` szerkezetként érdemes megírni; implicit visszatérés |
| `slices`                 | `hello-world`, `compiled-calculator`         | szeletek                                                 | szelet kinyerése egy paraméterből, amely egészek szelete                          |
| `loops`                  | `slices`                                     | alapszintű ciklus egy szeleten                           | ideálisan korai visszatéréssel, hogy nehézkes legyen iterátorként kifejezni        |
| `iterator-use`           | `slices`                                     | iterátorok használata, `collect`                         |
| `integer-sizes`          | `compiled-calculator`                        | nem `i32` egészek, típuskonverzió                        | még mindig mind előjeles                                                         |
| `unsigned-ints`          | `integer-sizes`                              | előjel nélküli egészek                                   |
| `indexing`               | `integer-sizes`, `slices`                    | indexelés, `usize`                                       |
| `floats`                 | `compiled-calculator`                        | lebegőpontos számok                                      | valószínűleg ugyanaz a lefordított számológép feladat, nem egész eredményekkel    |
| `bools`                  | `compiled-calculator`                        | Boolean-ok, Boolean operátorok                           |
| `char`                   | `compiled-calculator`                        | `char` adattípus                                         | tartalmazzon néhány széles `char` példát                                          |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | megjegyzés: módosíthatatlan!                                                      |
| `string-use`             | `str-use`                                    | `String`                                                 | megjegyzés: tulajdonolt, módosítható                                              |
| `format-macro`           | `string-use`                                 | `format!` makró                                          |
| `str-vs-string`          | `str-use`, `string-use`                      | kombinálás, konvertálás, költségek stb.                  |
| `generics-basics`        | `integer-sizes`, `floats`                    | külső trait-ek használata korlátként, alapvető generikusok | valószínűleg még mindig a lefordított számológép, csak generikusan               |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | struktúra létrehozása és használata adatok kezelésére    | `Person` rendelkezik névvel, magassággal és a birtokolt cipők számával            |
| `implicit-return`        | `compiled-calculator`                        | scope-ok, kifejezések, implicit visszatérés              |
| `explicit-return`        | `implicit-return`, `conditionals`            | explicit `return` utasítás                               |
| `methods`                | `structs`, `explicit-return`                 | `impl` blokkok, metódusok                                |
| `tuples`                 | `structs`                                    | tuple-ök                                                 | névtelen struktúrákként tanítsd; tanítsd a `.0` szintaxist                       |
| `tuple-structs`          | `tuples`, `structs`                          | tuple-struktúrák (nevesített tuple-ök)                   |
| `basic-enums`            | `unsigned-ints`                              | alapvető enumok (mezők nélkül), `match`                  |
| `enums`                  | `basic-enums`, `tuple-structs`               | tuple szintaxis enumváltozatokhoz                        |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | alapértelmezett módosíthatatlanság; explicit módosíthatóság |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | valószínűleg az implementációtól függően csak az `option` vagy a `result` egyikétől fog függeni |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | trait manuális implementálása                            | valószínűleg az `Iterator` implementálása                                        |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
