# Utasítások

Szenvedélyes madármegfigyelő vagy, és naponta számba veszed, hány madár látogatja a kertedet. A darabszámokat egy tömbben tárolod, a legrégebbi nap van elöl.

## 1. A mai darabszám

Definiáld a `today` függvényt úgy, hogy levegye a veremről a napi darabszámokat tartalmazó tömböt, és adja vissza a mai nap darabszámát.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. A mai darabszám növelése

Definiáld az `increment-todays-count` függvényt úgy, hogy egy új tömböt adjon vissza, amelyben a mai darabszám eggyel megnőtt. Az eredeti tömböt nem szabad módosítani.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. Volt-e olyan nap, amikor egyetlen madár sem járt a kertedben?

Definiáld a `has-day-without-birds?` függvényt úgy, hogy `t`-t adjon vissza, ha legalább egy napon nulla madarat számoltál, egyébként pedig `f`-et.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Az első néhány nap összege

Definiáld a `count-for-first-days` függvényt úgy, hogy fogadjon egy darabszámokból álló tömböt és egy `n` számot, és adja vissza az első `n` darabszám összegét.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. A forgalmas napok megszámolása

A forgalmas nap olyan nap, amikor legalább öt madár járt a kertedben. Definiáld a `busy-days` függvényt úgy, hogy adja vissza a tömbben lévő forgalmas napok számát.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. A hiányzó napok pótlása

Ha egy `n` napos időszak minden napján nem figyeltél meg madarakat, akkor a végén hiányzó napokat töltsd fel `0`-val. Definiáld a `pad-missing-days` függvényt úgy, hogy fogadjon egy darabszámokból álló tömböt és egy `n` célhosszt, és adjon vissza egy legalább `n` hosszúságú tömböt, amelynek a plusz helyei `0`-ák. A meglévő darabszámokat változatlanul meg kell őrizni; ha a bemenet már legalább `n` hosszú, add vissza változatlanul.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
