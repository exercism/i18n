# Bemutatás

A [switch utasítás][switch] egy értéket több lehetséges egyező mintával hasonlít össze.
Tisztább és olvashatóbb alternatívát kínál azzal szemben, ha több `if-else` elágazást fűzünk egymás után.

A `switch` utasítás a `switch` kulcsszóval kezdődik, amelyet a vizsgálandó érték követ.
Minden lehetséges egyezést a `case` kulcsszó vezet be.
A `default` kulcsszó egy tartalék esetet definiál, amely akkor fut le, ha egyik megadott eset sem egyezik.
Az `if-else` láncokhoz hasonlóan a `switch` utasítás is csak az első egyező esethez tartozó kódblokkot futtatja le.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Nézzük a következő `if-else` láncot:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Ugyanez `switch` utasítással tisztábban is megírható:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Értékkötés és where záradékok

A `switch` egyik esete a neki megfelelő értékeket ideiglenes konstansokhoz vagy változókhoz kötheti, hogy az eset törzsében használhasd őket.
Az esetek `where` záradékot is tartalmazhatnak, amellyel az egyezés előtt további Boolean-feltételeket ellenőrizhetsz:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
