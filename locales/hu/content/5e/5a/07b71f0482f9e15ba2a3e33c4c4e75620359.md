# Bevezetés

A `when` kulcsszó a kivételek szűrésére szolgál. A `catch` utasítás után áll, és olyan Boolean-kifejezést fogadhat, amely az adott pillanatban a scope-ban lévő bármely értéket tartalmazhatja. Ha a kifejezés igazra értékelődik, akkor az adott `catch` utasításhoz tartozó blokk fut le. Ellenkező esetben a rendszer a következő `catch` utasítást vizsgálja, ha van ilyen.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
