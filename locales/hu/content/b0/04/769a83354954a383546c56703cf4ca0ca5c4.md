# Utasítások

Ebben a feladatban egy egyszerű számológép hibakezelését építed fel.

A cél egy működő számológép, amely a következő mintázatú stringet adja vissza: `16 + 51 = 67`, ha a `16`, `51` és `+` argumentumokat kapja.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. A hibát dobó kód kezelése a `calculate` metóduson belül

Ebben a részfeladatban a fő megvalósítandó metódus a `SimpleCalculator.calculate()` osztálymetódus lesz.
Három argumentumot vár.
Az első két argumentum az a két szám, amelyeken a műveletet elvégzed.
A harmadik argumentum string típusú, és ehhez a feladathoz a következő műveleteket kell megvalósítanod:

- összeadás a `+` stringgel
- szorzás a `*` stringgel
- osztás a `/` stringgel

## 2. A szabálytalan műveletek kezelése

Frissítsd a `SimpleCalculator.calculate()` metódust, hogy ismeretlen műveleti jelek esetén `UnsupportedOperation` kivételt dobjon.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
Ebben a feladatban a `UnsupportedOperation` kivételt egy adott scope-ra kell definiálnod.
~~~~

## 3. Az érvénytelen argumentumok kezelése

Frissítsd a `SimpleCalculator.calculate()` metódust, hogy érvénytelen argumentumtípusok esetén `ArgumentError` kivételt dobjon.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. A nullával való osztás kivételeinek kezelése

Frissítsd a `SimpleCalculator.calculate()` metódust, hogy kezelje a `ZeroDivisionError` kivételeket.
A kezelő kódnak a `Division by zero is not allowed.` tartalmú stringet kell visszaadnia.
A `SimpleCalculator.calculate()` metódus más kivételt ne kezeljen.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
