# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat    | Típus   | Leírás                                 |
| --------- | ------------ | ------- | -------------------------------------- |
| `$a0`     | bemenet      | cím     | nullával lezárt kérdés string          |
| `$v0`     | kimenet      | egész szám | az eredmény, 0, ha a kérdés érvénytelen |
| `$t0-9`   | ideiglenes   | bármilyen | ideiglenes tárolásra                   |
