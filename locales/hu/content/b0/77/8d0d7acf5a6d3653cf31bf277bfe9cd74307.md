# Tippek a Bash Aknakereső feladathoz

Úgy tűnik, ez a feladat kétdimenziós tömböt igényel.
A Bash csak egydimenziós indexelt vagy asszociatív [tömböket][array] kínál.

A többdimenziós tömbök asszociatív tömbök használatával szimulálhatók: kódold az indexeket egy vesszővel elválasztott stringgé, hogy a tömb kulcsaként használd.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
