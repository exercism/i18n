# Részesítsd előnyben a felső szintű konstanst

Érdemes lehet kiemelni a `GIGASECOND` számot egy konstansba:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

Kívülről csak azok a függvények, osztályok és konstansok láthatók és érhetők el, amelyek `export`álva vannak. Általában érdemes nevet adni a [mágikus számoknak](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29), ami javítja a karbantarthatóságot. Ezek a konstansok ugyanabban a fájlban maradhatnak anélkül, hogy ki lennének téve más kódnak.
