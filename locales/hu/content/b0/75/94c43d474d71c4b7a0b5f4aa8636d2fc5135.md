# Bevezetés

## While-ciklusok

A while-ciklussal ismételten végrehajthatsz kódot, amíg egy bizonyos feltétel teljesül.
A `while` kulcsszóval írjuk le, amelyet kerek zárójelbe zárt feltétel követ, majd egy kapcsos zárójelbe zárt kódblokk, amely a ciklus _törzsét_ tartalmazza.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

A JavaScriptben do-while ciklus is létezik.
Itt a feltétel ellenőrzése a ciklustörzs végrehajtása után történik.
Ez akkor hasznos, ha a feltétel a törzsben végzett kiértékelésektől függ.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

A ciklustörzsön belül a `break` kulcsszóval teljesen leállíthatod a ciklus végrehajtását.
Ezzel szemben a `continue` kulcsszó csak az aktuális iteráció végrehajtását állítja le, és a következővel folytatja.
A `continue` segítségével gyakran elkerülheted, hogy a ciklustörzs nagy részeit elágazásba csomagold.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## Switch-utasítások

Az elágazás mellett a JavaScriptben switch-utasítás is létezik a logika feltételes végrehajtására.
Akkor használjuk, amikor egyetlen változót több lehetőséggel kell összehasonlítani.
Az összehasonlítás szigorú egyenlőség (`===`) vizsgálatával történik, lásd [az összehasonlítás fogalmát][concept-comparison].
Egy `x` változó esetén a JavaScript switch-utasítása a következő szintaxissal rendelkezik.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

A `default` eset opcionális, és arra szolgál, hogy lefuttass valamilyen kódot, ha a változó egyik másik lehetőséggel sem egyezik.

A fenti `break` utasításokra azért van szükség, mert a JavaScriptben alapértelmezés szerint minden eset „átesik” a következőre.
Ez azt jelenti, hogy `break` utasítás nélkül az első egyező lehetőség alatti összes eset kódja lefutna, még akkor is, ha `x` nem egyezett azokkal a lehetőségekkel.
Ez az „alapértelmezett átesés” gyakori buktató, amikor `switch`-et használsz a JavaScriptben.
Egy függvényen belül a `break` helyett `return`-t is használhatsz, hogy elkerüld ezt a problémát.
