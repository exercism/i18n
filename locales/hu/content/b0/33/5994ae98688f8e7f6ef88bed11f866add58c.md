# Bemutatás

A struktúrák és osztályok minden példánya rendelkezik egy implicit `self` nevű tulajdonsággal, amely magára a példányra hivatkozik.
A `self` leggyakrabban arra szolgál, hogy egyértelművé tegyük vele egy példánytulajdonság és egy ugyanolyan nevű paraméter nevét:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

A Swift-típusoknak van egy nagybetűs `Self` kulcsszavuk is, amely nem a példányra, hanem a példány *típusára* hivatkozik.
