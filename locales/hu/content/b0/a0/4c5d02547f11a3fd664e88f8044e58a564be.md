# Bemutatás

## JSON

A [JSON][json] (JavaScript Object Notation) egy ember által olvasható adat- és fájlformátum, amelyet gyakran használnak adatok cseréjére, különösen webalkalmazásokban. Nem meglepő tehát, hogy különleges helyet foglal el az Elm nyelvben.

Az Elm a [`Json.Decode`][decode] és a [`Json.Encode`][encode] core modulokat biztosítja JSON-adatok feldolgozásához és írásához. A JSON-dekóderekkel _deklarálhatod_, milyen típusú adatra számítasz, és milyen adatszerkezetre képezze le az adatot.

Ha dinamikusan típusos nyelvekből érkezel, a dekóderek gyakran nehézkesnek vagy első ránézésre túl merevnek tűnnek. Bár kétségtelenül bőbeszédűek, legalábbis Elmben, értékes eszközt jelentenek ahhoz, hogy kifejezetten leírd, mit vár a program a beérkező adatoktól, és [nem kevésbé kifejezőek, mint a dinamikus típusok][dynamic-types-not-more-open].

Importáljunk néhány aliast és típust a modulokból:

```elm
import Json.Decode as Decode exposing (Decoder, Error)
import Json.Encode as Encode exposing (Value)
```

Ha a `Decode.decodeString : Decoder a -> String -> Result Error a` függvényt egy dekóderrel és egy JSON-stringgel hívod meg, az vagy sikerül, ha a string megfelel a dekóder specifikációjának, vagy meghiúsul. A nyers JSON-adatot a dekóder definiálásakor semmilyen módon nem tudod megvizsgálni, ami szokatlannak tűnhet, ha imperatív nyelvekből érkezel.

## Alapvető adattípus-dekóderek

A JSON-nak néhány alapvető adattípusa van:

- String: idézőjelek közé írva `"hello world"`
- Boolean: vagy `true`, vagy `false`
- Number: például `34` vagy `0.12`
- Null: az adat hiánya `null`

Mindegyikhez tartozik egy-egy `Decode`-függvény:

```elm
Decode.decodeString Decode.string """\"hello\""""
    --> Ok "hello"

Decode.decodeString Decode.string """null"""
    --> Err ...

Decode.decodeString Decode.bool """true"""
    --> Ok True

Decode.decodeString Decode.bool """0"""
    --> Err ...

Decode.decodeString Decode.int """12"""
    --> Ok 12

Decode.decodeString Decode.float """3.14"""
    --> Ok 3.14

Decode.decodeString (Decode.null AnyValue) """null"""
    --> Ok AnyValue

Decode.decodeString (Decode.null AnyValue) """true"""
    --> Err ...
```

Jegyezd meg, hogy a `Decode.null` segítségével eldöntheted, hogyan modellezd a `null` értéket a programodban: tetszőleges értéket kér argumentumként (talán `()`, `Nothing`, vagy bármi, ami a programodhoz illik).

## Dekóderek kombinálása

A JSON emellett két adatszerkezetet is definiál az alapvető adattípusok gyűjtésére:

- Array: más adattípusok gyűjteménye `[0, null, "none", []]`
- Object: kulcs-érték párok gyűjteménye `{"id": 1, "is_admin": false, "more_info": {}}`

A `Decode` ezek dekódolásához is kínál függvényeket:

```elm
Decode.decodeString (Decode.list Decode.int) """[1, 2, 3]"""
    --> Ok [1, 2, 3]

Decode.decodeString (Decode.list Decode.int) """[1, 2, 3, "not an int"]"""
    --> Err ...

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": 71 }"""
    --> Ok (Dict.fromList [("key1", 17), ("key2", 71)])

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": "seventy-one" }"""
    --> Err ...
```

A `Decode.list : Decoder a -> Decoder (List a)` és a `Decode.dict : Decoder a -> Decoder (Dict String a)` függvények argumentumként egy dekódert várnak, amelynek az adatszerkezet minden egyes elemét dekódolnia kell. Ha az argumentumként kapott dekóder nem tud dekódolni egy array vagy object érték valamelyik elemét, akkor az egész dekóder meghiúsul, ami gyakori minta.

Az egyszerű dekóderek bonyolultabbakká való kombinálása a technika lényege. Egy példán keresztül bemutatunk még néhány függvényt, amelyekkel tetszőlegesen összetett, valós adatokhoz illő dekódereket építhetsz.

## GeoJSON

Hogy gyakoroljuk az alapvető dekóderek kombinálását összetett JSON-adatok feldolgozásához, építsünk dekódereket a GeoJSON-adatok (egy részhalmazának) feldolgozásához. A [GeoJSON][geojson] egy speciális, JSON-alapú adatformátum, amelyet földrajzi jellemzők, például helyek, útvonalak vagy régiók ábrázolására használnak; ezeket 2D-s vagy 3D-s földrajzi koordinátákkal adják meg, más tulajdonságok mellett.

### Geometriai objektum

A GeoJSON Geometriai objektum egy olyan objektum, amely tartalmaz egy `type` mezőt string értékkel (7 lehetséges típusérték van), valamint egy `coordinates` mezőt földrajzi koordinátákkal (amelyek szerkezete a típustól függ). Például

```json
{
  "type": "Point",
  "coordinates": [127.831, 26.461]
}
```

vagy

```json
{
  "type": "LineString",
  "coordinates": [
    [127.831, 26.461],
    [127.829, 26.465],
    [127.829, 26.469],
    [127.83, 26.47]
  ]
}
```

A Geometriai objektumot a következő típussal ábrázolhatod Elmben:

```elm
type Geometry
  = Point (List Float)
  | LineString (List (List Float))
  | ...
```

Egy adott mező értékének megvizsgálásához használhatod a `Decode.field : String -> Decoder a -> Decoder a` függvényt, amely egy objektum egy konkrét kulcsának értékét dekódolja.

```elm
decodePointCoordinates : Decoder (List Float)
decodePointCoordinates =
    Decode.field "coordinates" (Decode.list Decode.float)

decodeLineStringCoordinates : Decoder (List (List Float))
decodeLineStringCoordinates =
    Decode.field "coordinates" (Decode.list (Decode.list Decode.float))
```

A dekóder által sikeresen beolvasott érték átalakításához használhatod a `Decode.map : (a -> value) -> Decoder a -> Decoder value` függvényt, vagy bármelyik rokonát, a `Decode.map2  (a -> b -> value) -> Decoder a -> Decoder b -> Decoder value`-től a `Decode.map8`-ig.

Ebben az esetben a `type` mező értéke alapján szeretnénk eldönteni, melyik koordináta-dekódert használjuk, amire tökéletesen illik a `Decode.andThen : (a -> Decoder b) -> Decoder a -> Decoder b` és barátai, a `Decode.succeed : a -> Decoder a` és a `Decode.fail : String -> Decoder a`.

```elm
decodeGeometry : Decoder Geometry
decodeGeometry =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                case value of
                    "Point" ->
                        decodePointCoordinates |> Decode.map Point

                    "LineString" ->
                        decodeLineStringCoordinates |> Decode.map LineString

                    _ ->
                        Decode.fail "Geometry not implemented yet, or invalid type value"
            )
```

Ezen a ponton jegyezd meg, hogy a `Decode.andThen` segítségével érvényesíthetnénk is a koordinátákat (ellenőrizhetnénk, hogy a koordináták párokban vagy hármasokban jönnek-e, és hogy a koordinátaértékeknek van-e földrajzi értelmük).

```elm
Decode.decodeString decodeGeometry """{"type": "Point", "coordinates": [127.831, 26.461]}"""
    --> Ok (Point [127.831, 26.461])

Decode.decodeString decodeGeometry """{"type": "LineString", "coordinates": [127.831, 26.461]}"""
    --> Err ...
```

### Feature objektum

A GeoJSON Feature objektum valami térben körülhatároltat ábrázol: van egy `type` mezője a `"Feature"` értékkel, egy `geometry` mezője egy Geometriai objektummal vagy `null`-lal, egy `properties` mezője egy tetszőleges JSON-objektummal vagy `null`-lal, valamint egy opcionális `id` mezője JSON string- vagy számértékkel.

```json
{
  "type": "Feature",
  "geometry": null,
  "properties": null
}
```

vagy

```json
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
```

Először is foglalkozzunk az `id` mezővel. Ha létezik, akkor stringeket vagy számokat kell kezelnie, így vagy bevezetünk egy egyedi típust az értékhez, vagy mindig stringként mentjük.

Két lehetséges dekóder közötti választáshoz használhatjuk a `Decode.oneOf : List (Decoder a) -> Decoder a` függvényt.

```elm
decodeFeatureId : Decoder String
decodeFeatureId =
    Decode.oneOf
        [ Decode.string
        , Decode.int |> Decode.map String.fromInt
        , Decode.float |> Decode.map String.fromFloat
        ]
        |> Decode.field "id"

Decode.decodeString decodeFeatureId """{"id": "seventeen"}"""
    --> Ok "seventeen"

Decode.decodeString decodeFeatureId """{"id": 17}"""
    --> Ok "17"

Decode.decodeString decodeFeatureId """{"type": "Point"}"""
    --> Er ...
```

Ahhoz, hogy kifejezzük, hogy a mező opcionális, ugyanezt a technikát használhatjuk

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.oneOf
        [ decodeFeatureId |> Decode.map Just
        , Decode.succeed Nothing
        ]
```

De használhatjuk helyette a `Decode.maybe : Decoder a -> Decoder (Maybe a)` függvényt is

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.maybe decodeFeatureId

Decode.decodeString decodeMaybeFeatureId """{"id": 17}"""
    --> Ok (Just "17")

Decode.decodeString decodeMaybeFeatureId """{"type": "Point"}"""
    --> Ok Nothing
```

Jegyezd meg, hogy a `decodeMaybeFeatureId` (vagy bármelyik `Decode.maybe`-be csomagolt dekóder) mindig sikeres lesz, hiszen mindig visszaeshet az `Ok Nothing` értékre, bár egy őt használó dekóder ettől még meghiúsulhat

```elm
Decode.decodeString (Decode.list decodeMaybeFeatureId) """{"id": 17}"""
    --> Err ...
```

Következzék a `geometry` mező, amely vagy egy Geometriai objektum, vagy `null` lehet. Megint használhatnánk a `Decode.oneOf`-ot, de van egy jobb megoldás: a `Decode.nullable : Decoder a -> Decoder (Maybe a)`.

```elm
decodeFeatureGeometry : Decoder (Maybe Geometry)
decodeFeatureGeometry =
    Decode.nullable decodeGeometry
        |> Decode.field "geometry"

Decode.decodeString decodeFeatureGeometry """{"geometry": {"type": "Point", "coordinates": [127.831, 26.461]}}"""
    --> Ok (Just (Point [127.831, 26.461]))

Decode.decodeString decodeFeatureGeometry """{"geometry": null}"""
    --> Ok Nothing

Decode.decodeString decodeFeatureGeometry """{"geometry": {}}"""
    --> Err ...
```

A `Decode.maybe` és a `Decode.nullable` szignatúrája ugyanaz, a viselkedésük viszont különbözik, mivel egy `Decode.nullable` `OK Nothing` eredménye csak a konkrét `null` JSON-értékből származhat.

Végül a `properties` mező tartalmazhat tetszőleges JSON-objektumot vagy `null`-t, ami a `Decode.value : Decoder Value` feladata.

```elm
decodeProperties : Decoder (Maybe (Dict String Value))
decodeProperties =
    Decode.nullable (Decode.dict Decode.value)
        |> Decode.field "properties"


Decode.decodeString decodeProperties """{"properties": null}"""
    --> Ok Nothing

Decode.decodeString decodeProperties """{"properties": {"country": "Japan"}}"""
    --> Ok (Just (Dict.fromList [("country", <internals>)]))

Decode.decodeString decodeProperties """{"properties": 17}"""
    --> Err ...
```

Jegyezd meg, hogy a `Value` egy átlátszatlan típus, ami azt jelenti, hogy nem könnyű megvizsgálni a tartalmát. A használatához vagy írhatsz hozzá egy dekódert, és lefuttathatod a `Decode.decodeValue : Decoder a -> Value -> Result Error a` függvénnyel, vagy közvetlenül elküldheted JavaScriptnek egy porton keresztül.

Készen állunk a Feature objektumok feldolgozására:

```elm
type alias Feature =
    { id : Maybe String
    , geometry : Maybe Geometry
    , properties : Maybe (Dict String Value)
    }

decodeFeature : Decoder Feature
decodeFeature =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                if value /= "Feature" then
                    Decode.fail "not a Feature"

                else
                    Decode.map3 Feature
                        decodeMaybeFeatureId
                        decodeFeatureGeometry
                        decodeProperties
            )

Decode.decodeString decodeFeature """{"type": "Feature", "geometry": null, "properties": null}"""
    --> Ok { geometry = Nothing, id = Nothing, properties = Nothing }

"""
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
"""
  |> Decode.decodeString decodeFeature
    --> Ok { geometry = Just (Point [127.831,26.461]), id = Just "0157", properties = Just (Dict.fromList [("country",<internals>)]) }
```

## JSON-kódolók

A kódolókkal érvényes JSON-t írhatsz Elm-értékekből az `Encode.encode : Int -> Value -> String` függvény segítségével. Az első argumentum a végeredmény behúzásának mértékét adja meg, a második pedig a kiírandó JSON-érték.

Egy `Value` vagy a `Decode.value`-ból szerezhető be, vagy valamelyik kódoló állítja elő:

```elm
Encode.encode 0 (Encode.string "hello")
    --> "hello"

Encode.encode 0 (Encode.bool True)
    --> "true"

Encode.encode 0 (Encode.int 12)
    --> "12"

Encode.encode 0 (Encode.float 3.14)
    --> "3.14"

Encode.encode 0 Encode.null
    --> "null"

Encode.encode 0 (Encode.list Encode.int [1, 2, 3])
    --> "[1,2,3]"

Encode.encode 4 (Encode.list Encode.int [1, 2, 3])
    --> "[\n    1,\n    2,\n    3\n]"

Encode.encode 0 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\"key1\":17,\"key2\":71}"

Encode.encode 4 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\n    \"key1\": 17,\n    \"key2\": 71\n}"
```

valamint az `Encode.object : List ( String, Value ) -> Value` függvénnyel

```elm
Encode.object
    [ ( "key1", Encode.int 17 )
    , ( "key2", Encode.int 71 )
    ]
    |> Encode.encode 0
    --> "{\"key1\":17,\"key2\":71}"
```

Definiáljunk kódolókat a korábban definiált GeoJSON-dekóderekhez

```elm
encodeGeometry : Geometry -> Value
encodeGeometry geometry =
    case geometry of
        Point coord ->
            Encode.object
                [ ( "type", Encode.string "Point" )
                , ( "coordinates", Encode.list Encode.float coord )
                ]

        LineString coord ->
            Encode.object
                [ ( "type", Encode.string "LineString" )
                , ( "coordinates", Encode.list (Encode.list Encode.float) coord )
                ]

encodeFeature : Feature -> Value
encodeFeature feature =
    let
        maybeId =
            case feature.id of
                Nothing ->
                    []

                Just id ->
                    [ ( "id", Encode.string id ) ]
    in
    Encode.object
        (maybeId
            ++ [ ( "type", Encode.string "Feature" )
               , ( "geometry"
                 , case feature.geometry of
                    Nothing ->
                        Encode.null

                    Just geometry ->
                        encodeGeometry geometry
                 )
               , ( "properties"
                 , case feature.properties of
                    Nothing ->
                        Encode.null

                    Just dict ->
                        Encode.dict identity identity dict
                 )
               ]
        )
```

Általában véve jó teszt a dekóder-kódoló párokra, ha ellenőrzöd, hogy `elmValue |> encoder |> decoder == elmValue`.

## Mi mást?

Nem tértünk ki a `Json` modulok minden egyes függvényére. A ki nem említett dolgok közé tartozik például: dekóderek array-ek `Array`-é vagy object-ek `List (String, a)`-vá alakításához, dekóderek egy vagy több elemű array-ekhez, dekóderek beágyazott JSON-objektumok adott mezőihez vagy array-ek adott elemeihez, rekurzív struktúrák dekódolása, valamint az `Error` különböző változatai és azok megjelenítése.

Más gyakran használt csomagok közé tartozik a [`Json.Decode.Pipeline`][pipeline], amely kényelmes folyamatot vezet be összetett JSON-struktúrákhoz, valamint a [`Json.Decode.Extra`][extra], amely további dekódereket, kódolókat és segédfüggvényeket kínál.
