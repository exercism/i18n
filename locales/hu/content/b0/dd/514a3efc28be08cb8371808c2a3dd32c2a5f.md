# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít felkészülni egy jármű megvásárlására.

Három részfeladat vár rád: az egyikben eldöntöd, hogy kell-e jogosítvány, a másikban segítesz választani két jármű közül, a harmadikban pedig megbecsülöd egy használt jármű elfogadható árát.

## 1. Döntsd el, hogy szükséged lesz-e jogosítványra

A járművek egy részének vezetéséhez jogosítvány kell.
Tegyük fel, hogy csak a `'car'` és a `'truck'` típushoz kell jogosítvány, minden mást jogosítvány nélkül is lehet vezetni.

Valósítsd meg a `needsLicense(kind)` függvényt, amely a jármű típusát kapja, és egy boolean értéket ad vissza arról, hogy kell-e jogosítvány az adott típusú járműhöz.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. Válassz két lehetséges jármű közül

Felméred a rendelkezésre álló járműveket.
Sikerül két lehetőségre szűkítened a kört, de segítségre van szükséged a végső döntéshez.
Ehhez valósítsd meg a `chooseVehicle(option1, option2)` függvényt, amely két járművet kap argumentumként, és egy döntést ad vissza, amelyben az szerepel, amelyik előrébb van szótári sorrendben.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. Becsüld meg egy használt jármű árát

Most, hogy meghoztad a döntést, szeretnéd biztosítani, hogy tisztességes árat kapj a kereskedésben.
Mivel használt járművet szeretnél venni, az ár attól függ, milyen idős a jármű.
Durva becsléshez feltételezd, hogy ha a jármű 3 évnél fiatalabb, az új kori eredeti árának 80%-ába kerül.
Ha 10 évnél idősebb, akkor 50%-ába.
Ha a jármű legalább 3 éves, de nem idősebb 10 évnél, az eredeti ár 70%-ába kerül.

Valósítsd meg a `calculateResellPrice(originalPrice, age)` függvényt, amely ezt a logikát alkalmazza `if`, `else if` és `else` segítségével (más megoldások is léteznek, ha gyakorolni szeretnél).
Az eredeti árat és a jármű korát kapja argumentumként, és a kereskedésben becsült árat adja vissza.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
