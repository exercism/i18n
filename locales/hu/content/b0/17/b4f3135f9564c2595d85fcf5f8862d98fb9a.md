# Névjegy

A Go beépített numerikus típusai egész vagy lebegőpontos értékek halmazát képesek reprezentálni.
Attól függően, hogy mekkora értéket szeretnél tárolni, és hogy milyen architektúrájú az a számítógép, amelyen az alkalmazás fut, többféle típus áll rendelkezésre (például 32 és 64 bites).

Ez a fogalom két számtípusra összpontosít:

- `int`: például `0`, `255`, `2147483647`.
   Egy előjeles egész szám, amely legalább 32 bites (értéktartománya: -2147483648-tól 2147483647-ig).
   Ez azonban a rendszer architektúrájától függ.
   A legtöbb modern számítógép 64 bites, ezért az `int` mérete 64 bit (értéktartománya: -9223372036854775808-tól 9223372036854775807-ig).

- `float64`: például `0.0`, `3.14`.
   A 64 bites lebegőpontos számok halmazát tartalmazza.

A rendelkezésre álló numerikus típusok teljes listáját és a részleteket a következő forrásokban találod:

- [A Go beépített típusdeklarációi][go-builtins]
- [Digital Ocean - Adattípusok megértése a Go-ban][do-understanding-types]
- [Arden Labs - A típusok megértése a Go-ban][arden-understanding-types]

A Go a szokásos aritmetikai operátorokat támogatja: `+`, `-`, `*`, `/` és `%` (maradékképzés, nem modulo).

A Go-ban két különböző típus közötti értékadáshoz explicit konverzióra van szükség.
Ha például egy `int` értéket `float64` típusra szeretnél alakítani, ezt így teheted:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
