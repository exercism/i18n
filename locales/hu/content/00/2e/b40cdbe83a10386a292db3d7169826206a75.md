# Bevezetés

A Common Lispben létezik a Nyomtató fogalma, amely magában foglal minden olyan függvényt, amely Lisp-adatok szöveges reprezentációját írja ki. Az egyik ilyen függvény a `format`, amellyel a programozó tetszőlegesen formázhatja az adatokat.

A `format` és általában a Lisp Nyomtató képességei nagy témát jelentenek; itt a `format` használatának alapjait írjuk le.

## A FORMAT függvény

A `format` függvény legalább két argumentumot vár: egy folyamot, amelyre a kiírás történik, és egy vezérlő stringet, amely meghatározza, mit és hogyan kell kiírni.

A folyamok önálló fogalmat alkotnak, és máshol lesz róluk szó. Egyelőre viszont elég annyit tudni, hogy a kiírás a folyamra történik, és erre az argumentumra két speciális érték létezik: `t` és `nil`. A `t` azt jelenti, hogy a szabványos kimenetre írunk (valójában arra a folyamra, amelyhez a `*standard-output*` változó hozzá van kötve). A `nil` pedig azt jelenti, hogy létrehozunk egy stringet, és visszaadjuk azt.

Vedd észre, hogy a `format` mindig `nil` értékre értékelődik ki, kivéve az utóbbi esetben, amikor a `nil` van megadva folyamként. Ez gyakori módja az egyszerű string-interpolációnak vagy string-összeállításnak.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## Formátumdirektívák

A vezérlő string tartalmazhat „formátumdirektívákat”, amelyek utasításokat adnak a `format` számára arról, hogy mit írjon ki, és hogyan értelmezze a `format` többi paraméterét. Bizonyos értelemben a vezérlő string egy program, amelyet a `format` értelmez és futtat. Minden direktíva `~` karakterrel kezdődik, amelyet egy karakter követ (_pl._ `~A`, `~D`, `~&`). A karakter kis- és nagybetűje nem számít.

A legtöbb formátumdirektíva egyszerűen beilleszt a kimenetbe egy argumentumot, amelyet a `format` kap. Ezt úgy mondják, hogy „elfogyasztja” az argumentumot. Néhány direktíva nem fogyaszt argumentumot, vagy egynél többet fogyaszt. Egy direktíva például lehetővé teszi, hogy ugrálj az argumentumlistában, vagy kihagyj argumentumokat.

## Alapvető formázás

Egy nagyon általános célú formátumdirektíva a `~A`. Ez az adat egy „ember által olvasható” változatát írja ki.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

Egy másik hasznos formátumdirektíva a `~S`. Ez az adat egy „gép által olvasható” változatát írja ki. Ez nagyon hasznos lehet, ha szeretnéd, hogy a létrehozott kimenetet Lisp-adatként lehessen értelmezni. Sok mindennél ugyanúgy fog kinézni, mint a `~A`, de jegyezd meg, hogy például stringeknél a kimenet tartalmazni fogja az idézőjeleket (másik stringbe ágyazva escape-elve), így az érték visszaolvasható string paraméterként.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

Két további nagyon hasznos direktíva a `~%` és a `~&`. Az előbbi egy új sor karaktert ír ki, míg az utóbbi egy „friss sort”. A különbség az, hogy a `~%` mindig kiír egy új sort, míg a `~&` csak akkor, ha éppen nem egy sor elején vagyunk. Egyik sem fogyaszt argumentumot.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

Végül a `~~` egy egyszerű direktíva, amely egy literál `~` karaktert ír ki.
