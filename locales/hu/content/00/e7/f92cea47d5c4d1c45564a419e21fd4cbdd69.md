# Bevezetés

## Osztályok

Az osztályok a kódszervezés alapegységei a PHP-ben.
Az olyan kód, amely egy dolog vagy egy folyamat viselkedését írja le, egy osztályba csoportosítható.
A konvenció szerint az osztályhoz rendelt függvényeket `methods` néven nevezzük.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Az osztályokat a `new` kulcsszóval példányosítjuk; ez memóriát foglal az osztálypéldány számára, és meghívja az osztály konstruktor metódusát.
A példányosított osztályokat hozzárendelhetjük egy változóhoz.
Egy osztálypéldány metódusainak meghívásához a `->` hozzáférési operátort használhatjuk.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Egy példányosított osztály a saját példányára a különleges `$this` változóval hivatkozhat.
Az osztályoknak tulajdonságaik is lehetnek; ezek az osztályobjektum példányához kötött változókként viselkednek.
Ezekre a tulajdonságokra kívülről és belülről is hivatkozhatunk.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
