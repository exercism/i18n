# Bevezetés

Néha egy sorozatot nem elemenként, hanem *darabok* sorozataként kell szemlélned. A [`grouping`][grouping], a [`splitting`][splitting] és a [`splitting.monotonic`][splitting.monotonic] szókészletek négyféle módot kínálnak erre.

## `group` – *n* méretű, nem átfedő darabok

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

Ha a sorozat hossza nem *n* többszöröse, az utolsó csoport rövidebb lesz *n*-nél.

## `clump` – *n* méretű, átfedő csúszóablak

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

Ha a sorozat rövidebb *n*-nél, az eredmény üres.

## `split-when` – felbontás ott, ahol a predikátum igazat ad

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

Minden elemre külön lefut a predikátum; azok az elemek, amelyekre igazat ad, a *töréspontok*, és nem kerülnek bele az eredménybe.

## `monotonic-split` – futamok felbontása ott, ahol a szomszédos párok vizsgálata elbukik

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

A predikátum mindig *szomszédos párokra* fut le. Amíg igazat ad, addig folytatódik a futam; amikor `f`-et ad vissza, új darab kezdődik. A `[ = ]` predikátummal az egyenlő elemek futamait kapod, a `[ <= ]` predikátummal a nem csökkenő futamokat, és így tovább.

## Mikor melyiket használd

- **`group`/`clump`**: ismered a kívánt *méretet*.
- **`split-when`**: tudod, hogy néz ki egy *töréselem*.
- **`monotonic-split`**: tudod, mitől *tartozik még össze* két szomszédos elem.
