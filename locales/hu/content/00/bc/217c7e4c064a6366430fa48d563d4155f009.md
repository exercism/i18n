# Bevezetés

A JavaScriptben a feltételes logika egyik gyakori megvalósítási módja az elágazás.
Ez az `if` kulcsszóból, egy kerek zárójelbe zárt feltételből és egy kapcsos zárójelbe zárt kódblokkból áll.
A kódblokk csak akkor hajtódik végre, ha a feltétel értéke `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Használhatod önmagában, vagy összekapcsolhatod az `else` kulcsszóval.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Ha további feltételt szeretnél az `else` ágba ágyazni, használhatod az `else if` szerkezetet.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
