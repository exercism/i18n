# Bemutatás

A [`list`][list] egy módosítható gyűjtemény, amely _sorrendben_ tárolja az elemeket.
Ahogy a legtöbb gyűjtemény (_lásd a beépített [`tuple`][tuple], [`dict`][dict] és [`set`][set] típusokat_), a listák bármilyen (vagy akár többféle) adattípusra tárolhatnak hivatkozást, beleértve a többi listát is.
A Pythonban [sorozatnak][sequence type] számítanak, és egészben vagy részben [szeleteléssel][slice notation] másolhatók.
Ahogy bármely sorozatban, a `lists` elemeire balról `0-based index` számmal, jobbról `-1-based index` számmal is hivatkozhatsz.

A listák támogatják mind a [közös][common sequence operations], mind a [módosítható][mutable sequence operations] sorozatműveleteket, például a `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` és `<list>.reverse()` metódusokat.
Az elemeken a `for item in <list>` szerkezettel iterálhatsz, illetve a `for index, item in enumerate(<list>)` szerkezettel, amikor az elemre és az elem indexére is szükséged van.

A Python sok hasznos [metódust][list-methods] kínál a listákkal való munkához.

 Mivel a listák módosíthatók, a lista-metódusok **megváltoztatják a metódusnak átadott eredeti listaobjektumot**.
Ha nem szeretnéd módosítani az eredetit, akkor az eredeti `list`-ről `slice` vagy `<list>.copy()` segítségével kell `shallow copy`-t (_legalábbis_) készítened.


## Elemek hozzáadása

Elemeket a meglévő lista végéhez a `<list>.append(<item>)` metódussal adhatsz hozzá:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

Ahelyett, hogy _a végére fűzné_, a `<list>.insert(<index>, <item>)` a lista egy _adott indexére_ szúrja be az elemet.
Az `<index>` annak az elemnek az indexe, amely _elé_ az új elemet szeretnéd beszúrni.
Az `<item>` a beszúrandó elem.

**Megjegyzés**: Ha az `<index>` értéke 0, az elem a lista elejére kerül.
Ha az `<index>` nagyobb, mint a lista utolsó indexe, az elem az utolsó helyre kerül, ami megegyezik a `<list>.append(<item>)` használatával.

```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```

Egy `iterable` a `<list>.extend(<iterable>)` metódussal _fűzhető össze_ egy meglévő listával (a kettőt összefűzve).
A `<list>.extend(<iterable>)` _kicsomagolja_ a megadott iterábilist, és elemeit ugyanabban a sorrendben hozzáfűzi a cél lista végéhez.
Ha ilyenkor a `<list>.append(<item>)` metódust használnád, az a teljes iterábilist _**egyetlen elemként**_ adná hozzá.


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]
```


## Elemek eltávolítása

A `<list>.remove(<item>)` metódussal eltávolíthatsz egy elemet a listából.
 A `<list>.remove(<item>)` `ValueError` kivételt dob, ha az elem nem szerepel a listában.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError.
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```

Vagy használhatod a `<list>.pop(<index>)` metódust, amely **eltávolít** egy elemet, és a `return` segítségével vissza is adja azt további felhasználásra.

A `<list>.pop(<index>)` egyetlen opcionális paramétert fogad: az eltávolítandó és visszaadandó elem `index`ét.
Ha nem adod meg az opcionális `<index>` argumentumot, a lista utolsó eleme törlődik és kerül visszaadásra.
Ha az `<index>` nagyobb, mint a lista utolsó indexe, `IndexError` kivétel keletkezik.


```python
>>> numbers = [1, 2, 3]
>>> numbers.pop(0)
1

>>> numbers
[2, 3]
>>> numbers.pop()
3

>>> numbers
[2]

# This will throw an error because there is only index 0.
>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

Egy `list` összes eleme eltávolítható a `<list>.clear()` metódussal. Ez nem fogad paramétert.


```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```


## Megfordítás és átrendezés

A listaelemek sorrendje _**helyben**_ megfordítható a `<list>.reverse()` metódussal. Ez módosítja az eredeti listát.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```

Egy lista _**helyben**_ átrendezhető a [`<list>.sort()`][sort] segítségével.
Az alapértelmezett rendezési sorrend balról _növekvő_.
A Python dokumentációja [további tippeket és technikákat kínál a rendezéshez][sorting how to].


~~~~exercism/note
 2002 és 2022 között a Python belsőleg egy [`Timsort`][timsort] nevű algoritmust használt a listák elrendezésére, de a `Python 3.11`-től kezdve [`Powersort`][powersort]ra váltott.
A változással kapcsolatos részleteket és a Python-csapat vitáját a GitHub [78742-es issue][78742] oldalán olvashatod.  

Az algoritmus technikai részleteiről lásd J. Ian Munro és Sebastian Wild [Nearly-Optimal Mergesorts: Fast, Practical Sorting Methods That Optimally Adapt to Existing Runs][nearly-optimal-mergesorts] című dolgozatát.

[78742]: https://github.com/python/cpython/issues/78742
[nearly-optimal-mergesorts]: https://arxiv.org/abs/1805.04154
[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Ha egy listát _csökkenő_ sorrendbe szeretnél rendezni, add át a metódusnak a `reverse=True` argumentumot:


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```


Ha nem szeretnéd módosítani az eredeti `list`-et, használhatod a beépített [`sorted()`][sorted] és [`reversed()`][reversed] függvényt.
 A `sorted(<list>)` egy rendezett _másolatot_ ad vissza, és ugyanazokat a paramétereket fogadja, mint a `<list>.sort()`.
 A `reversed(<list>)` egy _iterátort_ ad vissza, amely a lista elemeit fordított sorrendben szolgáltatja.
 Az `Iterators` fogalmát egy másik feladatban tárgyaljuk részletesen.


## Egy elem előfordulásai egy listában

Egy elem előfordulásainak számát a `<list>.count(<item>)` segítségével derítheted ki.
 Visszaadja, hogy az `<item>` összesen hányszor szerepel elemként a listában.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```


## Elemek indexének megkeresése

A `<list>.index(<item>)` a megadott elem _első előfordulásának_ indexszámát adja vissza.
 Ha nincs előfordulás, `ValueError` kivétel keletkezik.
 Az indexelés balról `0-based`, ami azt jelenti, hogy az első elem pozíciója a `0` index.
 A jobbról történő indexelés is támogatott, `-1` indexszel kezdve.


```python
>>> items = [7, 4, 1, 0, 2, 5]
>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

A `start` és `end` indexek megadásával a lista egy adott szakaszán belül kereshetsz:


```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]
>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```

Ha nincs szükséged egy elem pontos helyére, a beépített `in` operátor hatékonyabb a tagság ellenőrzésére.


```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> "Thomas" in names
True
```


## Másolatok készítése

Ne feledd, hogy a Pythonban a változók olyan nevek, amelyek mögöttes objektumokra mutatnak.
 A nevek egy program élettartama alatt különböző objektumokhoz köthetők, illetve újraköthetők.
 Ha egy `list` objektumot egy új változó _**névnek**_ adsz értékül, az nem másolja le az objektumot vagy a rá hivatkozó adatokat.
 Az új és a régi név ugyanarra a `list` objektumra fog mutatni.
 Ráadásul a listák _konténer_ típusú objektumok: a helytakarékosság érdekében a konténerek csak _hivatkozásokat_ tárolnak a bennük lévő elemekre, magukat az elemeket nem.
 Ez az „optimalizálás” váratlan következményekkel járhat a gyanútlanok számára.

A `<list>.copy()` egy új `list` objektumot hoz létre, de **nem** hoz létre új objektumokat a hivatkozott _elemek_ számára: a másolat „sekély”.
 Egy `shallow copy` általában elegendő, ha az egyik `list` objektumból szeretnél elemeket hozzáadni vagy eltávolítani anélkül, hogy a másikat módosítanád.
 Ha viszont bármilyen esély van rá, hogy egy `list` _mögöttes elemei_ véletlenül módosulnak (_ezzel az összes kapcsolódó sekély másolatot is módosítva_), akkor a `copy` modul [`copy.deepcopy()`][deepcopy] függvényét kell használni egy teljes, azaz „mély” másolat készítéséhez **az összes** hivatkozásról és objektumról.

A nevek, értékek, listák és egymásba ágyazott listák viselkedésének részletes magyarázatáért nézd meg [Ned Batchelder][ned batchelder] remek blogbejegyzését: [Names and values: making a game board][names and values].
 A [Shallow vs Deep Copying of Python Objects][shallow vs deep] szintén jó összefoglalót ad a másolással kapcsolatos szempontokról.
