# Bevezetés

A `string` a Go-ban bájtok megváltoztathatatlan sorozata, amelyek nem feltétlenül karaktereket jelölnek.

A string literált kettős idézőjelek közé írjuk:

```go
const name = "Jane"
```

A stringek a `+` operátorral fűzhetők össze:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Néhány speciális karaktert egy kezdő visszaperjellel kell escape-elni, például a `\t` egy tabulátort, a `\n` pedig egy új sort jelöl a stringekben.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

A `strings` csomag sok hasznos függvényt tartalmaz a stringekkel való munkához.
Ha többet szeretnél megtudni a stringfüggvényekről, nézd meg a [strings csomag dokumentációját](https://pkg.go.dev/strings).
Íme néhány példa:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
