# Utasítások

Az _Instruments of Texas_-nál dolgozva az a feladatod, hogy egy kísérleti, fordított lengyel jelölésű [RPN] számológépen dolgozz, amely Elixirben íródott. A csapatodnak az okoz gondot, hogy néhány művelet hibát dob, és emiatt összeomlik a folyamat. Az a feladatod, hogy írj egy függvényt, amely becsomagolja a műveletvégző függvényt, hogy a hibákat elegánsabban lehessen kezelni idiomatikus Elixir-kóddal.

## 1. Figyelmeztesd a csapatot

Valósítsd meg a `calculate!/2` függvényt úgy, hogy meghívja a műveletfüggvényt, egyetlen argumentumként a vermet adva át neki. A műveletfüggvény máshol van definiálva, de tudod, hogy vagy sikeresen lefut, vagy hibát dob.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> A `!`-ra végződő függvénynevek arra figyelmeztetik a programozókat, hogy ez a függvény hibát dobhat

## 2. Csomagold be a hibát

Ahogy jobban utánanézel, észreveszed, hogy sok függvény atomokkal és tuple-okkal jelzi a sikerét vagy a kudarcát. Valósítsd meg a `calculate/2` függvényt ezzel a stratégiával.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. Add tovább az üzenetet

Néhány hiba fontos információt tartalmaz, amire a kollégáidnak szüksége van ahhoz, hogy a rendszer helyesen működjön. Valósítsd meg a `calculate_verbose/2` függvényt, hogy továbbadja a hibaüzenetet. A hiba egy struktúra, amelynek van egy `:message` mezője.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
