# Tesztek

A tesztfuttató használatához [helyesen telepített Godotra][installation] lesz szükséged.

## A tesztek futtatása

A [tesztfuttató][test runner] a megoldások betöltésére és tesztelésére szolgál.
A tesztfuttató elindításához töltsd le helyben, majd futtasd a `godot` paranccsal.
A jövőben a tesztfuttató automatikusan letöltődik a feladatokkal együtt, amikor az `exercism download` parancsot használod.

### A tesztfuttató letöltése

Az alábbi shell-részlettel töltheted le a tesztfuttatót.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### A tesztfuttató futtatása

A tesztfuttatót a `godot` futtatja headless módban (IDE nélkül).
A `-s` vagy a `--script` kapcsoló mondja meg a Godotnak, hogy a tesztfuttató szkriptjét futtassa.
A tesztfuttató két argumentumot vár: a megoldás slugját és a megoldáskönyvtár elérési útját.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

Például:

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
