# Bevezetés

A *reguláris kifejezés* (regex) egy kis minta, amely leírja, hogyan kell kinéznie egy szövegnek. A Factor regexeszközei a [`regexp`][regexp] vocabularyben találhatók, a mintát pedig `R/ ` és `/` közé írjuk.

A mintában a legtöbb karakter önmagát jelenti. Néhány különleges elem viszont azt adja meg, hogy milyen *fajtájú* karaktert várunk, vagy hogy *hányat*:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

A `R/ [A-Z]{2}-\d{4}/` tehát azt jelenti, hogy „két nagybetű, egy kötőjel, négy számjegy”.

A `matches?` azt vizsgálja, hogy egy *teljes* string illeszkedik-e a mintára:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

Más szavak a string *belsejét* vizsgálják: az `all-matching-subseqs` minden találatot visszaad, a `count-matches` megszámolja őket, a `re-contains?` megmondja, hogy van-e egyáltalán találat, a `re-replace` pedig minden találatot új szövegre cserél:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
