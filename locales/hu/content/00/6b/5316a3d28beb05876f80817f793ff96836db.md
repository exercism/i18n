# Bővebben

Az Elixirben a függvényeket dinamikusan is meg lehet hívni.

Minden modulnév atom. Az Elixirben minden modulnév fordításkor automatikusan megkapja az `Elixir.` előtagot.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Az Elixir futásidőben is meg tudja határozni, melyik függvényt kell meghívni, mégpedig úgy, hogy a modul nevével keresést végez. A keresést dinamikusan is elvégezhetjük, ha a modul neve egy változóhoz van kötve.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
