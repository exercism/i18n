# Osztály statikus kulcsszavai

Az osztály a kódszervezés egysége a PHP-ban, amely gyakran egy dolog, szolgáltatás vagy eljárás példányát írja le.
A `static` és `self` kulcsszó használatával a tulajdonságok és metódusok az osztályra vonatkoztatva létezhetnek, minden példány (vagy épp egyetlen példány) számára.

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Korlátozás

A statikus osztálymetódusok csak a saját osztályuk más statikus tulajdonságait vagy osztálymetódusait hívhatják meg.
