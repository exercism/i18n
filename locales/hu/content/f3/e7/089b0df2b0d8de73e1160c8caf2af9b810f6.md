# Utasítások

A barátod épp most küldött neked egy üzenetet egy fontos titokkal.
Hogy ne legyen könnyű másoknak elolvasni, az üzenetet egy sor bitmanipulációval titkosították.
Neked kell megírnod a metódusokat, amelyek segítenek visszafejteni az üzenetet.

## 1. Toldd vissza a biteket

Az üzenet visszafejtésének első lépése, hogy visszavonjuk a titkosításnál végzett eltolást: a biteket visszatoljuk jobbra.
A visszafejtés további lépései abból indulnak ki, hogy a bal oldalról 0-k kerülnek be.

Valósítsd meg a `Secrets.shiftBack` metódust, amely egy értéket és az eltolás helyeinek számát kapja, és végrehajtja az eltolást.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Állíts be néhány bitet

Ezután van néhány bit, amit 1-re kell állítani.

Valósítsd meg a `Secrets.setBits` metódust, amely egy értéket és egy maszkot kap, és visszaadja az eredményt, miután az érték bitjeit 1-re állította.
Az érték azon bitjeit kell 1-re állítani, ahol a maszk bitje is 1.
Minden más bit változatlan marad.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Fordítsd meg a megadott biteket

A titkosítás során néhány bitet megfordítanak.
Ahhoz, hogy visszafejtsük az üzenetet, ezeket vissza kell fordítani.

Valósítsd meg a `Secrets.flipBits` metódust, amely egy értéket és a maszkot kapja.
A maszk megmutatja, hogy az érték mely bitjeit kell megfordítani.
Ha egy bit 1 a maszkban, akkor az értékben lévő bit megfordul.
Minden más bit változatlan marad.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Töröld a megadott biteket

Végül vannak olyan bitek is, amelyek mindig 0-ra fejtődnek vissza.

Valósítsd meg a `Secrets.clearBits` metódust, amely egy értéket és egy maszkot kap.
A `value` azon bitjeit kell 0-ra állítani, ahol a maszkban 1 áll.
Minden más bit változatlan marad.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
