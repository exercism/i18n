# Bevezetés

## Listák

Tekintve, hogy a nyelv, amit használunk, a Lisp, a _LIST Processing_ rövidítése, könnyen azt feltételezhetnéd, hogy a nyelv rendelkezik a listák kezeléséhez szükséges eszközökkel. És igazad is lenne!

Bár a Common Lisp a listákon kívül más adatszerkezeteket is kínál, a listák használata továbbra is igen elterjedt.

A Common Lispben a lista elemek sorozata. A neve **cons** is (többnyire történelmi okokból).
Maguk az elemek nem feltétlenül azonos típusúak.
Például lehet egy listád, amely `1`, `two` és `"III"` elemeket tartalmaz.

### Listák létrehozása

Egyszerűen beírhatsz egy idézőjeles listát, például így: `'(1 two "III")`, és ezzel létrehozol és kiértékelsz egy listát (az értéke `(1 two "III")` lesz).

Emellett két fő függvény szolgál a listák létrehozására: a `list` és a `cons`.

A `list` nulla vagy több argumentumot vesz át, és az értéke egy olyan lista lesz, amelyet ezekből az értékekből hozott létre:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

A `cons` két elemet vesz át, és olyan listát hoz létre, amelynek az első elem a `car`-ja (a lista feje), a második pedig a `cdr`-je (a lista többi része):

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

A `car` és a `cdr` függvénnyel hozzáférhetsz egy lista `car`-jához és `cdr`-jéhez.

(A `first` és a `rest` a `car` és a `cdr` szinonimája, és pontosan ugyanúgy működnek.)

### Hossz és véletlen hozzáférés

Egy lista hosszát a `length` segítségével állapíthatod meg.
Az üres lista hossza nulla.

Egy tetszőleges elemhez az `nth` segítségével férhetsz hozzá (figyelem: a listák indexelése nullától indul).

_Nem_ hiba olyan indexet kérni, amely nagyobb, mint amilyen hosszú a lista.
Ehelyett az értéke `nil` lesz:

```lisp
(nth 23 '(short list)) ; => nil
```

Emellett több segédfüggvény is létezik egy lista első elemeihez való hozzáféréshez: `first`, `second`, `third`, egészen `tenth`-ig. Menő, mi?

### Listák összefűzése

Két vagy több listát az `append` segítségével fűzhetsz össze:

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

Az `append`-nek átadott minden argumentumnak listának kell lennie.
