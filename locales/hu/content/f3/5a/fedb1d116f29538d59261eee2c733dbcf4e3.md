# Névjegy

A Rust a [char][char type] típust egyetlen karakter ábrázolására használja. A `char` literált aposztrófok közé írjuk, például `'a'`.
Minden `char` négy bájt méretű, és egyetlen [Unicode skaláris értéket][unicode scalar] ábrázol.

Azonban a [`char`][character type] nem mindig az, amit betűnek tekintünk. Vannak olyan nyelvek, például a hindi, amelyek [diakritikus jeleket][diacritics] használnak,
ezek speciális szimbólumok, amelyek módosítják azt a karaktert, amelyhez kapcsolódnak. Bár a diakritikus jel a Rustban külön `char`, a diakritikus jelet és a módosított karaktert együtt szoktuk betűnek tekinteni.

A karakter és a diakritikus jele együttesének neve [grafémafürt][grapheme cluster]. Vannak külső crate-ek, amelyek grafémafürtök feldolgozására használhatók,
például a [unicode-segmentation][unicode-segmentation].

Példa

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

Kiírja:

```rust
2
'u'
'\u{308}'
```

A `'\u{308}'` egy másik módja a `char` literál írásának. A `\u` jelzi, hogy egy Unicode `char`-ról van szó, ahol a `{308}` az adott karakter
vagy diakritikus jel egyedi Unicode-száma.
