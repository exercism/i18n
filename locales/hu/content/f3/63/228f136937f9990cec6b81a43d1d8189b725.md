# Utasítások

Ebben a feladatban egy egyszerű, egész számokkal dolgozó számológép hibakezelését építed fel.
A számológépnek támogatnia kell az összeadást, a szorzást és az osztást, és az eredményt formázott stringként kell visszaadnia.
Emellett hibakezelést is megvalósítasz a szabálytalan műveletek és a nullával való osztás kezelésére.

A cél, hogy egy működő számológépet kapj, amely a következő formátumú stringet adja vissza:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Valósítsd meg a számológép műveleteit

Ebben a részfeladatban a fő függvény a `SimpleCalculator::calculate` lesz, amely három argumentumot vár: két egész számot és egy `ByteArray`-t, amely a műveletet jelöli.
Valósítsd meg a következő műveleteket:

- **Összeadás** a `+` jellel
- **Szorzás** a `*` jellel
- **Osztás** a `/` jellel

## 2. Kezeld a szabálytalan műveleteket

Ha a művelet jele nem `+`, `*` vagy `/`, a számológépnek vagy pánikolnia kell, vagy hibát kell visszaadnia:

- Ha a művelet üres string, akkor pánikolj a `ByteArray` típusú `"Operation cannot be an empty string"` hibaüzenettel.
- Minden más érvénytelen művelet esetén add vissza a következőt: `Result::Err("Operation is out of range")`.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. Kezeld a nullával való osztás hibáit

Amikor `0`-val próbálsz osztani, a számológépnek pánikolnia kell egy hibaüzenettel, amely jelzi, hogy a nullával való osztás nem megengedett.
A visszaadott eredmény egy `felt252` érték legyen: `'Division by zero is not allowed'`.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
