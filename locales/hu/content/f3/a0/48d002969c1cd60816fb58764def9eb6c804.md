# Utasítások

Karl listát szeretne vezetni azokról a nyelvekről, amelyeket az Exercism weboldalán szeretne megtanulni.
Karlnak új nyelveket kell tudnia hozzáadni, a régieket eltávolítani, és ellenőrizni, hogy bizonyos nyelvek rajta vannak-e a listán.
Nagyon izgalmas lenne, ha Karl Javát vagy Kotlint szeretne tanulni!

## 1. Definiálj egy függvényt, amely ellenőrzi, hogy üres-e a nyelvek listája

Karlnak tudnia kell, ha egyszer üres lesz a nyelvek listája, hogy újabbakat kereshessen, amiket megtanulhat!
Definiálj egy `isEmpty` nevű metódust, amely akkor ad vissza `true`-t, ha egyetlen nyelv sincs a listában.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Definiálj egy függvényt, amely hozzáad egy nyelvet a listához

Karl már alig várja, hogy Kotlint és Pythont tanulhasson!
Segíts Karlnak elkezdeni: definiálj egy `addLanguage` nevű metódust, amely átveszi a nyelvet, amit meg szeretne tanulni, és hozzáadja a listához.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Definiálj egy függvényt, amely eltávolít egy nyelvet a listáról

Karl úgy döntött, hogy egyelőre nem szeretne Scalát tanulni.
Segíts Karlnak eltávolítani a listáról: definiálj egy `removeLanguage` nevű metódust, amely átveszi az eltávolítandó nyelvet, és eltávolítja a listáról.

```java
languageList.removeLanguage("Scala");
```

## 4. Definiálj egy függvényt, amely visszaadja a lista első elemét

Karl szeretne emlékezni az első nyelvre, amelyet a listához adott (és amely még mindig rajta van a listán).
Definiálj egy `firstLanguage` nevű metódust, amely visszaadja a lista első nyelvét.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Definiálj egy függvényt, amely visszaadja, hány nyelv van a listában

Karlnak tudnia kell, hány nyelvet próbál megtanulni.
Segíts Karlnak megtalálni a választ: definiálj egy `count` nevű metódust, amely visszaadja a listában lévő nyelvek számát.

```java
int two = languageList.count(); // 2
```

## 6. Definiálj egy függvényt, amely megállapítja, hogy egy nyelv rajta van-e a listán

Karl éppen azon gondolkodik, hogy a Pythont vagy a Ruby-t akarta-e megtanulni.
Definiálj egy `containsLanguage` nevű metódust, amely átveszi a nyelvet, amiről érdeklődik, hogy Karl megtudhassa!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Definiálj egy függvényt, amely megállapítja, hogy izgalmas-e a lista

Ha Karl Javát vagy Kotlint szeretne tanulni, az nagyon izgalmas!
Definiálj egy `isExciting` nevű metódust, amely igazat ad vissza, ha Karl Javát vagy Kotlint szeretne tanulni.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
