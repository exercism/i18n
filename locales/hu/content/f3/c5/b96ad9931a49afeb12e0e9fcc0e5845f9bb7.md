# Utasítások

Ebben a feladatban egy titkosító eszköz szoftverét kell megírnod, amely az adatok átalakításával működik. Szükséged van egy módszerre, amellyel egyszerűbb függvények összekapcsolásával rugalmasan hozhatsz létre bonyolult függvényeket.

Minden részfeladatban adj vissza egy névtelen függvényt, amely a hívó scope-ból meghívható.

## 1. Készíts egy összeadót

Valósítsd meg a `secret_add` függvényt. Olyan függvényt kell visszaadnia, amely egy argumentumot vár, és hozzáadja ahhoz a `secret_add`-nak átadott argumentumot.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. Készíts egy kivonót

Valósítsd meg a `secret_subtract` függvényt. Olyan függvényt kell visszaadnia, amely egy argumentumot vár, és kivonja abból a `secret_subtract`-nek átadott értéket.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. Készíts egy szorzót

Valósítsd meg a `secret_multiply` függvényt. Olyan függvényt kell visszaadnia, amely egy argumentumot vár, és megszorozza azt a `secret_multiply`-nek átadott értékkel.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. Készíts egy osztót

Valósítsd meg a `secret_divide` függvényt. Olyan függvényt kell visszaadnia, amely egy argumentumot vár, és elosztja azt a `secret_divide`-nek átadott értékkel.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. Készíts egy függvény-összekapcsolót

Valósítsd meg a `secret_combine` függvényt. Olyan függvényt kell visszaadnia, amely egy argumentumot vár, és sorban alkalmazza rá a `secret_combine`-nak átadott két függvényt.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
