# Az ismertetés

A rekurzív függvények olyan függvények, amelyek önmagukat hívják meg.

Egy rekurzív függvénynek legalább egy _alapesettel_ és legalább egy _rekurzív esettel_ kell rendelkeznie.

Az _alapeset_ úgy ad vissza egy értéket, hogy nem hívja meg újra a függvényt.
A _rekurzív eset_ újra meghívja a függvényt, és úgy módosítja a bemenetet, hogy az előbb-utóbb illeszkedjen az alapesethez.

Elmben a rekurzív függvényeket jellemzően mintaillesztéssel, `case` kifejezésekkel definiáljuk.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

Egy rekurzív függvénynek több alapesete és/vagy több rekurzív esete is lehet.
Például [a Fibonacci-sorozat][fibonacci] egy rekurzív sorozat, amelynek két alapesete van:

```elm
fibonacci : Int -> Int
fibonacci n =
    case n of
        0 ->
            0

        1 ->
            1

        _ ->
            fibonacci (n - 1) + fibonacci (n - 2)
```

Vedd észre, hogy ez a konkrét implementáció exponenciálisan lassú, mivel a kapcsolódó Fibonacci-számokat két független rekurzív hívásban a nulláról számolja ki újra.

Egy adott `x` érték előfordulásainak megszámolása egy listában két rekurzív esetet használ:

```elm
countOccurrences : List a -> a -> Int
countOccurrences list x =
    case list of
        [] ->
            0

        head :: tail ->
            if head == x then
                1 + countOccurrences tail x
            else
                countOccurrences tail x
```

## Ciklusok rekurzióval

A megváltoztathatatlanság miatt az Elmben a ciklusok másképp íródnak, mint az imperatív nyelvekben.
Például a ciklusok általában így néznek ki:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Egy funkcionális nyelvben, mint az Elm, a változók módosítása nem lehetséges.
Ezért a ciklusokat rekurzióval kell megvalósítani.

Egy `for` ciklus megfelelője Elmben így nézne ki:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

A gyakorlatban az Elmben a listák és más adatszerkezetek bejárása leggyakrabban a [`List`][module-list] modul függvényeivel történik, mint például a `List.map`, a `List.filter` és a `List.foldl`.
A háttérben ezek a függvények rekurzióval vannak megvalósítva.

## Végtelen végrehajtás

A rekurzív függvények, ha helytelenül vannak megvalósítva, vagy ha túl sok rekurzív hívást hajtanak végre, soha nem adhatják vissza az eredményüket.
Ez azért lehet problémás, mert minden alkalommal, amikor egy függvényt meghívunk, a memóriában eltárolódik egy hivatkozás arra, hova kell visszatérnie a futtatókörnyezetnek az eredménnyel (a [hívási veremben][wiki-call-stack]).
Ha egy rekurzív függvény túl sokszor, vagy akár végtelenszer hívja meg önmagát, elfogyhat a memória, ami a futtatókörnyezet összeomlását okozza (a [veremtúlcsordulási hiba][wiki-stack-overflow]).
Az Elm futtatókörnyezete a rekurzióra és a megbízhatóságra van optimalizálva, de a végtelen rekurzió így is okozhat problémákat.

A végtelen végrehajtás problémáját a következők okozhatják:

- Elfelejtünk megvalósítani egy alapesetet.
- A mintaillesztésben nem kezeljük az összes lehetséges esetet.
- A rekurzív hívásnál nem módosítjuk megfelelően az argumentumot, és így soha nem érjük el az alapesetet.
