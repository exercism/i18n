# Bevezetés

Ahogy egy mutató mutathat egy `int`-re vagy más alapvető adattípusra, úgy egy függvényre is mutathat.
Egy függvénymutatóval átadhatunk egy függvényt egy másik függvénynek.
Az olyan függvényt, amelyet paraméterként adunk át egy másik függvénynek, első osztályú függvénynek nevezzük.
Az olyan függvényt pedig, amely egy vagy több függvényt vesz át paraméterként, vagy amely függvényt ad vissza, magasabb rendű függvénynek nevezzük.

A következő példában az `is_even` és az `is_odd` első osztályú függvények.
A magasabb rendű függvény a `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
A `test_number` első argumentumának, a `bool (*func) (int)` függvényszignatúrának meg kell egyeznie a átadott függvények szignatúrájával.
Az `is_even` és az `is_odd` is egy `int` paramétert vár, és egy `bool` értéket ad vissza.
A `(*func)`-ban a `func` a használni kívánt függvény nevét jelöli.
Ha `(*fn)` szerepelne, akkor így kellene meghívni: `printf(text, number, fn(number)? "true": "false");`.
Ahhoz, hogy kielégítsük a függvénymutató paramétert, a `test_number` meghívásakor egy olyan függvény nevét adjuk át, amely a várt szignatúrával rendelkezik.
Így láthatjuk, hogy egy függvénynév a névvel jelölt függvény címére mutat.
