# Bevezetés

Swiftben nem indexelhetsz egy stringet egész számmal (például `string[3]`).
Mivel a Swift stringjei változó hosszúságú Unicode-karakterekből állnak, egy karakter megkereséséhez végig kell haladni az előtte lévő karaktereken.

Ahhoz, hogy egy adott pozícióban lévő karakterhez hozzáférj, ki kell számítanod egy `String.Index` típusú indexet.
Ezeket az indexeket *átlátszatlan indexeknek* nevezzük, mert a belső szerkezetüket a Swift kezeli, nem pedig nyers egészként manipulálod őket:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
