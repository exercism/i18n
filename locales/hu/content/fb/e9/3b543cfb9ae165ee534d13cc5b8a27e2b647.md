# Utasítások

Hirtelen megkívántad a palacsintát.
Modern, technikailag fogékony emberként JSON formátumban írod meg a palacsinta hozzávalóinak bevásárlólistáját.
A lista felépítése a következő:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Egy hozzávalót JSON-objektumként ábrázolunk, például így:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Egy hozzávalónak lehet egy `"substitute"` nevű opcionális tulajdonsága, amelyben egy másik, helyette használható összetevő neve szerepel stringként.

Nézzük meg, hogyan vizsgálhatjuk meg a bevásárlólistát a `jq` segítségével!

## 1. A bevásárlólista nevének kinyerése

Írj egy kifejezést, amely kiírja a bevásárlólista "name" elemét!

## 2. A szükséges hozzávalók megszámolása

Csak a "required" hozzávalókat számold. Az opcionális hozzávalókat ne vedd bele.

## 3. Mennyi cukor?

Írj egy kifejezést, amely kiírja a cukor mennyiségét!
Csak a számértékre van szükség.

## 4. A helyettesíthető hozzávalók leképezése

Néhány hozzávaló helyettesíthető (ha nincs meg az X hozzávaló, használhatod helyette az Y-t).
Adj ki egy JSON-objektumot, amely az ajánlott hozzávalót a helyettesítőjéhez rendeli.
Az opcionális hozzávalókat is vedd bele a leképezésbe.
