# Utasítások

Ebben a feladatban naplósorokkal fogsz dolgozni.

Minden naplósor egy string, amelynek formátuma a következő: `"[<LEVEL>]: <MESSAGE>"`.

Három különböző naplózási szint van:

- `INFO`
- `WARNING`
- `ERROR`

Több részfeladat vár rád, és mindegyik kap egy naplósort, amelyikkel valamit tenned kell.

## 1. Egy adott részstring utáni szöveg kinyerése

Ha megnézed az elmúlt hónap naplóit, láthatod, hogy a tesztüzenet mindig egy adott részstring után található. Mivel számítasz rá, hogy a közeljövőben ki kell majd nyerned a tesztüzenetet, úgy döntesz, írsz egy segédmetódust, amely ebben segít.

Valósítsd meg a (_static_) `LogAnalysis.SubstringAfter()` bővítőmetódust, amely átvesz egy string elválasztót, és visszaadja az elválasztó utáni részstringet.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. A két részstring közötti szöveg kinyerése

Ha jobban megnézed, láthatod, hogy a naplózási szint mindig szögletes zárójelek (`[` és `]`) között található. Mivel arra is számítasz, hogy előbb-utóbb ki kell nyerned a naplózási szintet, úgy döntesz, írsz még egy segédmetódust, amely ebben segít.

Valósítsd meg a (_static_) `LogAnalysis.SubstringBetween()` bővítőmetódust, amely átvesz két string elválasztót, és visszaadja a két elválasztó közötti részstringet.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. Az üzenet kinyerése egy naplósorból

Valósítsd meg a (_static_) `LogAnalysis.Message()` bővítőmetódust, amely visszaadja a naplósorban található üzenetet.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. A naplózási szint kinyerése egy naplósorból

Valósítsd meg a (_static_) `LogAnalysis.LogLevel()` bővítőmetódust, amely visszaadja egy naplósor naplózási szintjét.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
