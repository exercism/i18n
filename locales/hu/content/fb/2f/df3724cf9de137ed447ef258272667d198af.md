# privát segédfüggvények

[comment]: # (2 paramétert vár:)
[comment]: # (- expected: a helyesbített függvénydefiníció)
[comment]: # (- actual: a helytelen függvénydefiníció, amit a tanuló használt)

Egy kódbázis nyilvános felületét érdemes alaposan megtervezni, mert minden nyilvános függvény növeli a hosszú távú karbantartási költségeket, és megnehezíti a refaktorálást.

Az Exercism minden feladatában a nyilvános felületet a tesztcsomag határozza meg.
Ha egy függvényt tesztelnek, akkor nyilvánosnak kell lennie.
Minden más függvény legyen privát, beleértve az azonos nevű, de eltérő aritású függvényeket is.

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
Ne feledd, hogy az alapértelmezett argumentumok megváltoztatják egy függvény aritását.

Amikor könyvtárat írsz, gyakran szükség van arra, hogy a függvényeket nyilvánossá tegyed, hogy a modulok használhassák őket.
Hogy az ilyen függvényeket elrejtsd a dokumentációból, a könyvtárak szerzői a függvénydefiníciók elé beírják a `@doc false`-t, vagy a `@moduledoc false`-t, ami az egész modult elrejti.
