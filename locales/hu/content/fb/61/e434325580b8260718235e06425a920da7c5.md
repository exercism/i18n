# felesleges elágazások

[Elágazások][conditionals] feleslegesen szerepelnek ebben a megoldásban.
Ha [alapértelmezett argumentumot][default argument] használsz a [str.format][str.format] vagy az [f-stringek][f-strings] mellett (_más néven „formatted string literals” vagy „interpolated strings”_), a kód világosabb és kevésbé terjengős lehet.

További részletekért nézd meg ezt a bejegyzést a [Python alapértelmezett argumentumairól][python default arguments].
A [Stringformázás Pythonban][string formatting in python] blogbejegyzés is jó kiindulópont lehet ahhoz, hogy megismerd a Python stringformázási lehetőségeit.
