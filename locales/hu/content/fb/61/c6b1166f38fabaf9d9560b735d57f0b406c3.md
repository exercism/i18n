# Az Elm szintaxis alapjai 1

## Konstansok és függvények

Az Elm programok definíciókból és kifejezésekből állnak.
Az Elmben minden vagy definíció, vagy kifejezés.

A konstans értéket a `name = expression` formával definiáljuk.

```elm
five = 5

six = 3 + 3
```

A függvényeket a `name parameters... = expression` formával definiáljuk,
a paramétereket pedig csak szóköz választja el egymástól.

```elm
add number1 number2 = number1 + number2
```

Egy függvény meghívása szintén kifejezés, és úgy történik, hogy leírjuk a függvény nevét,
majd minden paraméteréhez átadunk egy-egy argumentumot, szóközzel elválasztva,
akárcsak a függvény definíciójánál.

```elm
five = add 2 3
```

Zárójelekkel megadhatjuk egy kifejezés kiértékelési sorrendjét.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Behúzás / jelentéssel bíró whitespace

Az Elm nem használ szintaktikai jelölőket, például kapcsos zárójelet, zárójelet vagy
pontosvesszőt a kódrészek határainak kijelölésére. Helyettük a whitespace-t és a behúzást
használja.

- A modul-, az import- és a legfelső szintű függvénydefinícióknak a bal szélső oszlopban kell kezdődniük.
- Ha egy kifejezést több sorra tördelünk, a kifejezéshez tartozó kódot legalább egy szóközzel beljebb kell húzni a kifejezés alatt.
- A kifejezés azon részeit, amelyek összetartoznak, ugyanannyi szóközzel kell behúzni.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Modulok

Az Elmben minden fájl egy modul, és minden más kód előtt szerepelnie kell benne egy `module`
utasításnak.
A modulneveknek meg kell egyezniük a fájlnevükkel, tehát a `Calculator` modulnak a
Calculator.elm fájlban kell lennie.
A modulon belül definiált dolgok kizárólag a modulon belülről érhetők el, kívülről nem,
kivéve, ha szerepelnek az `exposing` listában.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Megjegyzések

A megjegyzés olyan szöveg az Elm fájlban, amelyet a program nem értelmez kódként.
Elsősorban arra szolgál, hogy te és más programozók elolvassátok.
Az egysoros megjegyzésekhez egyszerű szintaxis tartozik, amely két kötőjelen alapul.
Többsoros megjegyzések is írhatók a `{-` és `-}` nyitó és záró határoló párral.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```

formázhatod a kódot.
