# Ismertető

## For ciklusok

A `for` utasítás egy kódblokkot ismétel.
Az első sora szabályozza, hogy a blokk hányszor ismétlődjön:

```go
for init; condition; post {
    // loop body
}
```

- Az **init** utasítás egyszer fut le, az első iteráció előtt. Gyakori, hogy itt deklarálunk és látunk el kezdőértékkel egy számlálóváltozót, amelyet a ciklus használ.
- A **condition** egy Boolean kifejezés, amelyet a program minden iteráció előtt kiértékel. A ciklus akkor áll le, amikor ez `false`-ra értékelődik.
- A **post** utasítás minden befejezett iteráció után fut le. Számláló frissítésére használható.

Az `init; condition; post` részt ne tedd zárójelek közé.
A ciklustörzset körülvevő kapcsos zárójelek `{ }` viszont mindig kötelezőek.

Ez a ciklus `1`-re állítja az `i`-t, kiírja az `i` aktuális értékét, a következő iterációhoz megnöveli, és akkor áll le, amikor az `i` eléri a `10`-et:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## A ciklus további formái

### Csak feltételből álló ciklus

Az init és post utasítás el is hagyható.
Egy csak feltételt tartalmazó `for` utasítás ugyanazt a célt szolgálja, mint más nyelvekben a `while` ciklus.
Go-ban nincs `while` kulcsszó.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Végtelen ciklus

A `for` utasítás feltétel nélkül is felírható:

```go
for {
    // loop body
}
```

Ez a ciklus magától nem áll le.
A végrehajtásnak kifejezetten ki kell lépnie a ciklusból, például `break`-kel vagy `return`-nel.

## A ciklus vezérlése

### Break és Continue

Ebben a ciklusban a `break` kilép a ciklusból:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

A `continue` kihagyja az aktuális ciklustörzs hátralévő részét, és a következő iterációval kezd:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### Címkézett break és continue

Egymásba ágyazott ciklusoknál a címke nélküli `break` vagy `continue` a legbelső ciklusra vonatkozik.
Egy külső ciklust úgy látsz el címkével, hogy közvetlenül fölé a sorba írsz egy azonosítót, utána pedig egy kettőspontot.
Ezután a ciklus címkéjét a `break` vagy a `continue` után írod, hogy hozzá irányítsd a műveletet:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
