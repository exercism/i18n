# Névjegy

Alapértelmezés szerint a változók arra a scope-ra korlátozódnak, amelyben definiáltad őket. Ha egy függvényen vagy osztályon kívül, egy fájlban definiálod őket, akkor a fájl scope-ján belül maradnak. Ha egy függvényben vagy osztályban definiálod őket, akkor a függvény vagy az osztály scope-ján belül maradnak.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Globális scope

Ha a `global` kulcsszót egy változó értékadása elé írod, egy globális scope-ú változót hozol létre. Ezt a mintát gyakran nem ajánlják, mert [szorosan csatolt kódot](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>) eredményez.

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Statikus scope

Ha a `static` kulcsszót egy változó értékadása vagy deklarációja elé írod, az megőrzi a változó scope-ját, az értéke pedig a végrehajtási scope-ok között is megmarad.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

Ebben a példában a `$count` változó 0-ra inicializálódik, _de csak az első függvényhívásnál_. Minden további hívásnál az érték átkerül a következő hívásba. Így a függvény minden meghívása egyre nagyobb egész számot ad vissza.
