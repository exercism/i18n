# Utasítások

A közeledben lévő helyi iskolában működik egy nagyon aktív diákegyesület.
A diákegyesületet egy elnök vezeti, és kétévente új elnököt választanak.

Az idei választáson úgy döntöttek, hogy szükség van egy új, digitális szavazatszámláló rendszerre. Az iskola a segítségedet kéri ennek az új rendszernek a megépítéséhez.

## 1. Szerezd meg a szavazatok számát egy `ElectionResult`-ból

Az új rendszernek szüksége lesz egy módra, amivel lekérdezheti a szavazatok számát egy számlálóból.

A választási eredmény structot már létrehozták neked, és így van definiálva:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

Mivel a `struct` minden tagja nyilvános, nem kell `constructor`-t írnod egy `ElectionResult` objektum inicializálásához.
Ehelyett használhatsz `initializer list`-et:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

Készíts egy `vote_count` függvényt, amely argumentumként egy `ElectionResult`-ra mutató referenciát kap, és visszaadja az `ElectionResult`-ban lévő szavazatok számát.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. Növeld egy `ElectionResult` szavazatainak számát

Végre eljött az idő a szavazatok feldolgozására!
Most egy módra van szükséged, amivel növelheted a szavazatok számát egy `ElectionResult`-ban.

Készíts egy `void` függvényt `increment_vote_count` néven, amely argumentumként egy `ElectionResult`-ra mutató referenciát és egy szavazatszámot kap, majd megnöveli az `ElectionResult`-ot az adott szavazatszámmal.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. Szavazatszámlálás és elnökség

Az iskola leadta a szavazatait, és most itt az idő, hogy megnézzük az eredményt, és megállapítsuk, ki a győztes.

Készíts egy `determine_result` függvényt, amely referenciaként megkapja a végeredményt, és visszaad egy referenciát az új elnök `ElectionResult`-jára.
A győztes nevét is módosítania kell úgy, hogy elé fűzi a „President” szót.
A végeredményt egy `std::vector<ElectionResult>`-ra mutató `reference` formájában kapod meg; ez a vektor az összes induló jelölt `ElectionResults`-át tartalmazza.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

Hogy egyszerű legyen, a következőket feltételezheted:
- A `vector`-nak legalább egy eleme van.
- Az első helyen nem lesz holtverseny.
