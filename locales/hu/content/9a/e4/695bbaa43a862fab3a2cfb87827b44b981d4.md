# Bevezetés

Az `Option` típus az F# nyelv mechanizmusa az olyan értékek kezelésére, amelyek létezhetnek, de nem is. Típusbiztos alternatívát nyújt a `null` használatával szemben, amely más nyelvekben gyakori az ilyen értékek kezelésére. Számos szabványos F#-könyvtári függvény használja, ezért a megértése elengedhetetlen az F# szabványos könyvtárának hatékony használatához.

## Használat 

Az `Option` típus egy generikus típus (van egy mögöttes típusa).  
Az `Option` értékek vagy `Some value` alakúak, ami egy konkrét értéket jelöl, vagy `None`, ami azt jelöli, hogy nincs érték.

A következő függvény bemutatja, hogyan hozhatsz létre `Option` értéket:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
A `T option` a `Option<T>` utólagos szintaktikai megfelelője; a két szintaktikai forma felcserélhetően használható.
Az F# stílusútmutató szerint azonban az Option típusoknál az utólagos jelölést érdemes előnyben részesíteni (lásd: [az F# stílusútmutató Formázás: típusok és típusannotációk című része](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

## Az Option érték tartalmának kiolvasása

Az `Option` érték kiolvasásának idiomatikus módja a mintaillesztés, ahogy a következő példa mutatja:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Option értékek kicsomagolása alapértelmezett értékekkel

Az `Option` értékek „kicsomagolhatók” (a bennük tárolt típusra alakíthatók), ha az `Option.defaultValue` függvénnyel alapértelmezett értéket adsz meg. 
Ez különösen akkor hasznos, ha biztosítani szeretnéd, hogy az érték ne `None` legyen.
Például:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
