# Névjegy

Egy metódusparaméter opcionálissá tehető úgy, hogy alapértelmezett értéket adunk neki. Ha egy paraméter opcionális, a hívónak nem kell argumentumot megadnia hozzá; ilyenkor az alapértelmezett értéket használja. Az [opcionális paramétereknek][optional-arguments] a paraméterlista végén _kell_ lenniük; nem követhetik őket nem opcionális paraméterek. Ha egy metódusnak több opcionális paramétere van, ezek közül csak néhányat adhatsz meg [nevesített argumentumokkal][named-arguments].

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

Egy opcionális paraméter értéke csak az alábbiak egyike lehet:

- Konstans kifejezés (pl. `"hi"`, `2`, `DayOfWeek.Friday`, `null` stb.)
- Értéktípus `new` kifejezése
- Értéktípus `default` kifejezése
