# Bemutatás

A Pythonban az [összehasonlító operátor][comparisons] (_más néven relációs operátor_) két [operandus][operand] _értékét_ vizsgálja, és Boolean `True` vagy `False` értéket ad vissza aszerint, hogy a `comparison` feltétel teljesül-e vagy sem.

Az alábbi táblázat a leggyakoribb összehasonlító operátorokat mutatja be a Pythonban:

| Operátor | Művelet                  | Leírás                                                               |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | „nagyobb, mint”             | `a > b` akkor `True`, ha `a` értéke **szigorúan** nagyobb, mint `b` értéke        |
| `<`      | „kisebb, mint”                | `a < b` akkor `True`, ha `a` értéke **szigorúan** kisebb, mint `b` értéke           |
| `==`     | „egyenlő”                 | `a == b` akkor `True`, ha `a` értéke **szigorúan** egyenlő `b` értékével           |
| `>=`     | „nagyobb vagy egyenlő” | `a >= b` akkor `True`, ha `a > b` VAGY `a == b`                        |
| `<=`     | „kisebb vagy egyenlő”    | `a <= b` akkor `True`, ha `a < b` vagy `a == b`                        |
| `!=`     | „nem egyenlő”                 | `a != b` akkor `True`, ha `a == b` értéke `False`                                 |
| `is`     | „azonosság”                 | `a is b` akkor `True`, ha **_és csakis akkor, ha_** `a` és `b` ugyanaz az _objektum_ |
| `is not` | „tagadott azonosság”         | `a is not b` akkor `True`, ha  **_és csakis akkor, ha_** `a` és `b` **nem** ugyanaz az _objektum_       |
| `in`     | „tartalmazásvizsgálat”         | `a in b` akkor `True`, ha `a` tagja, részhalmaza vagy eleme `b`-nek            |
| `not in` | „tagadott tartalmazásvizsgálat” | `a not in b` akkor `True`, ha `a` nem tagja, részhalmaza vagy eleme `b`-nek  |

Mindegyikük azonos prioritású (_ez magasabb, mint a [Boolean-műveleteké][boolean operations], de alacsonyabb, mint az aritmetikai vagy bitenkénti műveleteké_).

## Összehasonlítás különböző adattípusok között

A különböző típusú objektumok (_a numerikus típusok kivételével_) alapértelmezés szerint soha nem lesznek egyenlők.
Egy `class` nem azonos példányai szintén _**nem**_ számítanak egyenlőnek, hacsak a `class` nem definiál speciális [gazdag összehasonlító][rich comparisons] metódusokat, amelyek testre szabják az `object` alapértelmezett összehasonlítási viselkedését.
Ennél (sokkal) részletesebb leírásért lásd az [Értékek összehasonlítása][value comparisons] szakaszt a Python dokumentációjában.

A numerikus típusok (többnyire) kivételt képeznek ez alól a típusegyeztetési szabály alól.
Egy `integer` **egyenlőnek tekinthető** egy `float` típussal (_vagy egy [`octal`][octal] egy [`hexadecimal`][hex] típussal_), amennyiben a típusok az összehasonlításhoz implicit módon átalakíthatók.

A többi numerikus típusnál ([complex][complex numbers], [decimal][decimal numbers], [fractions][rational numbers]) az összehasonlító operátorok ott vannak definiálva, ahol „van értelmük” (_ahol az implicit átalakítás nem változtatja meg az eredményt_), de `TypeError` hibát dobnak, ha a mögöttes objektumok nem alakíthatók pontosan át az összehasonlításhoz.
A numerikus átalakítás szabályairól, amelyeket a Python használ, bővebben az [aritmetikai átalakítások][arithmetic conversions] szakaszban olvashatsz a Python dokumentációjában.

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex 
# number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

Ha egy számot rendezés szerint összehasonlítasz egy `NaN` (_nem szám_) típussal, az eredmény `False` lesz.
A `NaN` Python-beli definíciójának zavarba ejtő mellékhatása, hogy a `NaN` soha nem egyenlő önmagával.
Ha kíváncsi vagy rá, miért definiálták a `NaN`-t így a Pythonban, ez a [Stack Overflow-poszt a NaN-ról][so nan post] a nemzetközi szabvány megalkotásáról érdekes olvasmány.

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## Stringek összehasonlítása

A stringeket (`str`) [_lexikográfiailag_][lexographic order] hasonlítjuk össze, az egyedi Unicode-kódpontjaik alapján (_amit úgy kapunk, hogy a `str` minden kódpontját átadjuk a beépített [`ord()`][ord] függvénynek, amely egy `int` értéket ad vissza_).
Ha a két string összes kódpontja megegyezik, és _**ugyanabban a sorrendben**_ követik egymást, a két string egyenlőnek számít.
Ez az összehasonlítás „páronkénti” módon történik: elsőt az elsővel, másodikat a másodikkal, és így tovább.
A Python 3.x-ben a `str` és a `bytes` nem konvertálható és nem hasonlítható össze közvetlenül.

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## Konténer adattípusok összehasonlítása

A konténer adattípusok (_`lists`, `tuples`, `sets`, `dicts` stb._) szintén [_lexikográfiailag_][lexographic order] hasonlítódnak össze: akkor egyenlők, ha mindkét konténer ugyanazokat az adatokat **és** ugyanazokat az adattípusokat tartalmazza (_`lists` és `tuples` esetén a **sorrendjüknek** is meg kell egyeznie_), egyébként nem egyenlők.

```python
>>> [1, 2] == [1, 2]
True

# But if the data is not in the same order, they are not equal.
>>> [2, 1] == [1, 2]
False

# The same holds true for tuples
>>> (3,4,5) == (5,4,3)
False

# Length is also compared
>>> [1, 2] < [1, 2, 3]
True

# Comparing dicts
>>> {'name': 'John', 'age': 19} == {'name': 'John', 'age': 18}
False

>>> {'name': 'John', 'age': 19} == {'name': 'John', 'age': 19}
True
```

## Összehasonlítások láncolása

Az összehasonlító operátorok _tetszőlegesen_ láncolhatók.
Fontos, hogy egy kifejezés kiértékelése `left`-tól `right` felé halad.
Például az `x < y <= z` egyenértékű az `x < y and y <= z` kifejezéssel, azzal a kivétellel, hogy `y` **csak egyszer** kerül kiértékelésre.
Mindkét esetben `z` **egyáltalán** _nem_ kerül kiértékelésre, ha `x < y` értéke `False`.
Ezt gyakran `short-circuit evaluation`-nek nevezik: a kiértékelés leáll, ha a kifejezés igazságértéke már megállapítható.

A `Short circuiting`-et több Boolean-operátor és függvény támogatja, valamint a Pythonban az összehasonlítások láncolása is.
Sok más programozási nyelvtől eltérően, többek között a `C`, `C++`, `C#` és `Java` nyelvtől, a Pythonban az `a < b < c`-hez hasonló láncolt kifejezéseknek hagyományos [matematikai értelmezése][three way boolean comparison] és precedenciája van.

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## Azonosság-összehasonlítások

Az `is` és az `is not` operátor egy objektum [_azonosságát_][object identity] vizsgálja, szemben az objektum _értékével_.
Egy objektum azonossága a létrehozása után soha nem változik, és az [`id()`][id function] függvénnyel deríthető ki.

A `<apple> is <orange>` akkor `True`, ha _**és csakis akkor, ha**_ `id(<apple>)` == `id(<orange>)`.
A `<apple> is not <orange>` ennek az ellenkezőjét adja.

Mivel egyedi (singleton) értékek, a `None` és a `NotImplemented` összehasonlításához mindig az `is` és az `is not` operátort használd.
Erről a konvencióról bővebben a Python referenciadokumentációjának [értékek összehasonlítása][value comparisons none] szakaszában és a [PEP8][PEP8 programming recommendations] útmutatóban olvashatsz.

```python

# A list of favorite numbers.
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and Python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## Tagságvizsgálatok

Az `in` és a `not in` operátor a _tagságot_ vizsgálja.
A `<fish> in <soup>` akkor `True`, ha `<fish>` tagja `<soup>`-nak (_azaz ha `<fish>` részhalmaza `<soup>`-nak, vagy benne foglaltatik_), egyébként `False`.
A `<fish> not in <soup>` a tagadását, vagyis a `<fish> in <soup>` _ellentétét_ adja vissza.

String- és bytes-típusok esetén a `<name> in <fullname>` akkor `True`, _**ha és csakis akkor**_, ha `<name>` részstringje a `<fullname>`-nek.

```python

# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 'id': 67826, 'age': 33, 'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
