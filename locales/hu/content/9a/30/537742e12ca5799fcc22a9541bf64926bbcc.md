# Kiegészítő utasítások

## Fenntartott memória

A bemeneti string puffere a lineáris memória 64-191. bájtját használja.


## Kimeneti formátum

A számsort egyetlen összefüggő u8-tömbként várjuk; a deszerializálás során hosszúság szerint darabolódik szét:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
