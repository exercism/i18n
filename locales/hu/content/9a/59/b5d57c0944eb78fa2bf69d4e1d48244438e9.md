# Utasítások

Szenvedélyes madármegfigyelő vagy, aki számontartja, hány madár járt a kertedben az elmúlt hét napban.

Hat részfeladat vár rád, és mindegyik a kertedbe látogató madarak számával foglalkozik.

## 1. Nézd meg, mennyi volt a számuk a múlt héten

Hogy legyen mihez hasonlítanod, mindig magadnál tartod a múlt heti számok másolatát, amelyek ezek voltak: 0, 2, 5, 3, 7, 8 és 4. Definiáld a `lastWeek` kötést, amely a múlt heti számokat tartalmazza:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Nézd meg, hány madár járt itt tegnap

Készítsd el a `yesterday` függvényt, amely visszaadja, hány madár járt a kertedben tegnap. A madárszámok nap szerint követik egymást: az első elem a legrégebbi naphoz tartozó szám, az utolsó pedig a mai.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Számold ki, összesen hány madár járt itt

Készítsd el a `total` függvényt, amely visszaadja, összesen hány madár járt a kertedben:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Ellenőrizd, volt-e olyan nap, amikor nem járt itt madár

Készítsd el a `dayWithoutBirds` függvényt, amely `true`-t ad vissza, ha volt olyan nap, amikor nulla madár járt a kertben; egyébként `false`-t ad vissza:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Növeld a mai nap számát

Készítsd el az `incrementTodaysCount` függvényt, amely megnöveli a mai nap számát, és visszaadja a frissített számokat:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Ellenőrizd a szokatlan hetet

Az elmúlt év során rájöttél, hogy néhány hét ugyanazt a szokatlan mintázatot mutatja:
- A hét minden páros napján egyetlen madár sem járt itt
- A hét minden páros napján pontosan 10 madarat figyeltél meg
- A hét minden páratlan napján pontosan 5 madarat figyeltél meg

Készítsd el az `unusualWeek` függvényt, amely `true`-t ad vissza, ha az idei hét madárszám-mintázata megegyezik valamelyik szokatlan mintázattal:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Figyeld meg, hogy a napok paritása 1-től indexelt, nem 0-tól: a tömb első eleme egy páratlan napnak felel meg)
