# Névjegy

A karakterosztályokon és a kvantorokon túl a reguláris kifejezések a szöveg *szerkezetét* és *környezetét* is le tudják írni. Ezek a lehetőségek ugyanabban a [`regexp`][regexp] szókészletben találhatók, és az `R/ /` literállal írjuk le őket.

## Csoportosítás és alternáció

A kerek zárójel (`( )`) a minta egy részét csoportosítja, így egy kvantor vagy a `|` („ez vagy az”) az egész csoportra vonatkozik. A csoport után álló `?` opcionálissá teszi azt:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## Horgonyok

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

A *szóhatár* (`\b`) ott van, ahol egy szókarakter (betű, számjegy vagy aláhúzásjel) egy nem szókarakterrel találkozik, beleértve a string két végét is. A `\bcat\b` tehát csak akkor illeszkedik a `cat`-re, ha az önmagában áll:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## Körülnézés

A *körülnézés* azt vizsgálja, mi áll közvetlenül egy adott pont előtt vagy után, anélkül hogy ezek a karakterek a találat részévé válnának. Nullaszélességű:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## Beállítások

A lezáró `/` utáni opcióbetű az egész mintát megváltoztatja. Az `i` nem tesz különbséget kis- és nagybetű között:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## Az egyes találatok átalakítása

A `map-matches` minden találatra lefuttat egy quotationt, és összegyűjti az eredményeket; az `each-match` ugyanezt csak a mellékhatásokért teszi. Mindkettő átadja a quotationnek a találat `start` indexét, az `end` indexét és a teljes stringet, így a `subseq` visszaadja az illeszkedő szöveget:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Amit a Factor nem támogat

A Factor reguláriskifejezés-motorjában nincs **elfogó csoportok kinyerése** (a `( )` csoport szerkezetbe rendezi a mintát, de a hozzá tartozó illeszkedő szöveget nem tudod visszaolvasni), nincs **visszahivatkozás** (`\1`), és nincsenek **lusta / nem mohó** kvantorok (`*?`, `+?`). A körülnézés az elfogó csoportok idiomatikus helyettesítője: arra illeszkedsz, amit szeretnél, és a körülötte lévő környezet ismerteti fel.
