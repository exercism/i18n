# Kiegészítés az utasításokhoz

## Kivételüzenetek

Néha szükség van arra, hogy [kivételt dobj](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Ilyenkor mindig adj meg egy **beszédes hibaüzenetet**, amely megmutatja, mi a hiba forrása. Ettől olvashatóbb lesz a kódod, és a hibakeresésben is sokat segít. Ha tudod, hogy a hiba forrása egy adott típusú, választhatsz a [beépített hibatípusok](https://docs.python.org/3/library/exceptions.html#base-classes) közül, de ilyenkor is adj meg beszédes üzenetet.

Ennél a feladatnál a [raise utasítással](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) kell „dobnod” egy `ValueError`-t a bemeneti és a kimeneti számrendszer különböző eseteinél. A tesztek csak akkor futnak át, ha `raise`-eled az `exception`-t, és értelmes üzenetet is fűzöl hozzá.

Ha `ValueError`-t szeretnél dobni üzenettel, írd oda az üzenetet az `exception` típus argumentumaként:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
