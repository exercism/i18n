# Névjegy

A tulajdonságoknak két fő típusa van:

1. automatikusan implementált tulajdonságok, amelyeknél a `get` és `set` hozzáférőknek nincs törzsük. Lehetnek explicit módon inicializálva, de az is lehet, hogy nem. Például:
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. azok, amelyeknél a hozzáférők kifejezéseket értékelnek ki és utasításokat hajtanak végre. A kód lehet olyan egyszerű, mint egy háttérmező visszaadása vagy értékadása. Például:
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

Jelentős átfedés van a tulajdonságok és a metódusok viselkedésében és képességeiben.
Amikor nem automatikusan implementált tulajdonságokról van szó, bármilyen utasítást vagy kifejezést tartalmazhatnak, amely az osztály scope-ján belül előfordulhat. Gyakori esetben úgy szokták leírni őket, hogy egy háttérmezőt csomagolnak.
Bár az esetek nagy részében nyilvánvaló, hogy egy adott helyzetben viselkedést tulajdonságként vagy metódusként érdemes kódolni, gyakran a fejlesztő mérlegelésén múlik, és különösen az, hogy mennyi kód fusson le a hozzáférőkben. Gyakran előfordul érvényesség-ellenőrzés a set hozzáférőben, valamint egyszerű számítás vagy formázás a get hozzáférőben:

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

A többi osztálytaghoz hasonlóan a tulajdonságoknak is lehetnek hozzáférési szintjeik.
Legtöbbször a tulajdonságok nem privát hozzáférési szinttel rendelkeznek, összhangban a lényegi rendeltetésükkel. Néha az egyik hozzáférő hozzáférési szintje eltér a tulajdonságétól. A `TareWeight` esetében a meglehetősen mesterkélt „biztonsági” megkötés miatt lehetőség volt arra, hogy nyilvános tulajdonságot privát get hozzáférővel hozzunk létre. Ez azt jelenti, hogy az osztályon kívüli kód beállíthatja a tulajdonság értékét, de azt csak az osztályon belüli kód olvashatja (get).

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

A nem nyilvános set hozzáférők is támogatottak, de gyakoribb eset, hogy a set hozzáférő teljesen elhagyható. Ez talán azért van, mert a tulajdonság értékét az osztály konstruktorában állítják be.

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

Ez a feladat a tulajdonságok alapvető használatával foglalkozott. A haladóbb témákat más feladatokban találod:

- kifejezéstörzsű tulajdonságok, get és set hozzáférők (a kifejezéstörzsű tagok fogalomban)
- tulajdonságok interfészeken (az Interfészek fogalomban)
- tulajdonságok/absztrakt tulajdonságok absztrakt osztályokon (az Öröklés fogalomban)
- a `readonly` kulcsszó használata tulajdonságokkal (a Módosíthatatlanság fogalomban)
- statikus tulajdonságok (a Statikus tagok fogalomban)
- indexelők (az Indexelők fogalomban)
