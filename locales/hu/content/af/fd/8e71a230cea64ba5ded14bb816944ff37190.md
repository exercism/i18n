# Névjegy

A `Time` modul ember számára olvasható dátumok és időpontok megjelenítésére szolgál.
Bár a `Time` modullal technikailag lehetséges az időpontok manipulálása, az Elm közösségének vannak olyan csomagjai, amelyek sokkal jobban illenek erre a feladatra, például a [`justinmimbs/date`][date] vagy a [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Az időpontokat az opaque `Posix` típus reprezentálja, amely a Unix epoch időt zárja magába, vagyis az 1970. január 1-jei éjfél (UTC) óta eltelt ezredmásodpercek számát.
A `Posix` egyértelmű érték, amely nem tér el időzónánként, ezért jó választás az idő tárolására.
Egy Elm-alkalmazásban a `Posix` időket általában külső források adják meg, például a böngésző.

A `Posix` értéket a következő függvényekkel lehet ezredmásodpercek számává alakítani, és fordítva:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Időzónák

A mindennapokban mi, emberek általában nem `Posix` értékeket olvasunk, hanem a helyi időt részesítjük előnyben, ami a Földön elfoglalt helyünktől és a helyi nyári időszámítás szabályaitól függ.
Az Elmben ezt az információt az opaque `Zone` típus kódolja, amelyet általában a böngésző ad meg.

Van egy különleges `Zone`, amely mindig elérhető:

```elm
utc : Zone
```

## Időpontok emberi formában

Egy `Posix` és egy `Zone` birtokában már minden részletességi szinten meg tudjuk jeleníteni a helyi időt.
Íme az ehhez használható függvények listája:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Feltűnhetett, hogy még két saját típus tartozik a `Time`-hoz:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Ezeket a saját típusokat a felhasználóknak kell ember számára olvasható értékekké alakítaniuk.
