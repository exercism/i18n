# Bevezetés

Ez a feladat a Ruby alapvető építőelemeit mutatja be.
Sok mindent átfog, de ne aggódj, ha elsőre soknak tűnik: ahogy haladunk előre a kurzuson, mindenbe sokkal mélyebben is belemegyünk.

A Rubyval kapcsolatban az egyik kulcsfontosságú dolog, amit meg kell értened, hogy egy [objektumorientált nyelv][object-oriented-programming], és hogy **a Rubyban minden egy [objektum][object]**. A számok, a stringek, a tömbök: mind objektumok.

## Változók és konstansok

Az objektumokat jellemzően úgy használjuk, hogy nevet adunk nekik, akár változók, akár konstansok segítségével.

A változókat mindig [snake case][snake-case] stílusban írjuk.
Egy változó az élettartama során különböző objektumokra hivatkozhat.
Például a `my_first_variable` a `=` operátorral sokszor definiálható és újradefiniálható:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

A konstansok viszont arra valók, hogy csak egyszer kapjanak értéket.
Nagybetűvel kell kezdődniük, és általában csupa nagybetűvel írjuk őket, a szavakat alulvonással elválasztva.
Például:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## Osztályok

A Ruby osztályokba szerveződik.
Az osztályokat a `class` kulcsszóval definiáljuk, amelyet az osztály neve követ.
Az objektumokat általában úgy hozzuk létre, hogy az osztályokat a `.new` metódussal példányosítjuk.
Például:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## Metódusok

A funkcionalitás egységeit metódusokba zárjuk, hasonlóan más nyelvek _függvényeihez_.

Egy metódus definiálható pozicionális argumentumokkal, kulcsszó-argumentumokkal (amelyeket a `:` szintaxissal definiálunk és hívunk meg), vagy egyáltalán nem lehet argumentuma.

A metódusok vagy implicit módon visszaadják az utoljára kiértékelt utasítás eredményét, vagy a `return` kulcsszóval explicit módon visszaadhatnak egy objektumot.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

A metódusokat a `.` szintaxissal hívjuk meg:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
