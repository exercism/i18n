# Bevezetés

A Gleamben az opaque típusok olyan egyedi típusok, amelyeknél a típusba tartozó értékeket csak az a modul hozhatja létre, vagy illeszthet rájuk mintát, amelyik magát a típust definiálja. Ez akkor hasznos, ha olyan típust szeretnénk létrehozni, amelyet csak egy meghatározott módon szabad használni.

Az opaque típusokat az `opaque` kulcsszóval definiáljuk.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Ezt a `PositiveInt` típust olyan helyzetekben érdemes használni, ahol int típusú értékre van szükség, de annak nullának vagy annál nagyobbnak kell lennie. Egy hétköznapi Gleam `Int` erre nem alkalmas, mert az negatív értéket is felvehet.

Az a modul, amelyik ezt a típust definiálja, definiálhat egy függvényt a belső int érték lekérésére, és egy függvényt a `PositiveInt` típus létrehozására, amely hibát ad vissza, ha az érték nem pozitív.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Ezzel az API-val más modulok nem tudnak negatív értékű `PositiveInt` típust létrehozni, így minden függvény, amely `PositiveInt` típust kap, biztos lehet benne, hogy az érték pozitív.
