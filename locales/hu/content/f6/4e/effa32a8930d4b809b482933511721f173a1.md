# Bevezetés

Az Elmben a szöveges reprezentáció alapját a karakterek és a stringek adják.
A stringekre gondolhatsz úgy, mint karakterek listáira, és a legtöbb `List`-függvény megfelelője megtalálható a `String` modulban.

## Karakterek

A `Char` típus egyetlen Unicode-karaktert reprezentál, aposztrófok között, például `'a'`.
A `Char` modul predikátumfüggvényeket (`Char -> Bool`) kínál egy karakter tulajdonságainak vizsgálatára: `isUpper`, `isLower`, `isAlpha` és `isAlphaNum`.
A modul emellett függvényeket is kínál a karakter átalakítására (`toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`), valamint a numerikus Unicode-értékével (`Int`) való oda-vissza alakításra a `toCode` és a `fromCode` segítségével.

## Stringek

A `String` típus beépített reprezentációt nyújt a hatékony stringmanipulációhoz, és bármilyen Unicode-karakterekből álló sorozatot reprezentálhat, például „this is an Elm string.”
A többsoros stringeket három dupla idézőjel jelöli, és előfordulhatnak bennük escape nélküli idézőjelek és sortörések.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## Stringfüggvények

A `String` modul tartalmazza az alábbi táblázatban összefoglalt összes függvényt.
A leggyakrabban használt függvények közé tartozik például:

A `cons : Char -> String -> String` egy karaktert fűz a string elejére.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

A `(++): String -> String -> String` két stringet fűz össze.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

A `split : String -> String -> List String` a megadott elválasztónál stringek listájára bontja a stringet.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

A `join : String -> List String -> String` egy megadott elválasztóval fűz össze egy stringlistát.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
A `replace : String -> String -> String -> String` egy adott részstring összes előfordulását lecseréli.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

A `length : String -> Int` a stringben lévő karakterek számát adja vissza.
```elm 
length "Hello world." 
    --> 12
```

A `toInt : String -> Maybe Int` megpróbál egy stringet `Just Int`-té alakítani, és `Nothing`-ot ad vissza a hibásan formázott stringekre.
```elm
toInt "-42" 
    --> Just -42
```    

A `contains : String -> String -> Bool` ellenőrzi, hogy a második string tartalmazza-e az elsőt.
```elm
contains "the" "theory" 
    --> True
```

A `map : (Char -> Char) -> String -> String` a megadott függvényt a string összes `Char` értékére alkalmazza.
Figyelem: a megadott függvény csak `Char`-ból `Char`-ba történő leképezés lehet.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
