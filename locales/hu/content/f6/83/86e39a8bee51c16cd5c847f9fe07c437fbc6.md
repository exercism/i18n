# Bevezetés

## Számok

Sok programozási nyelv külön numerikus típusokat használ a különféle számok ábrázolására, a JavaScriptben viszont csak kettő van:

- `number`: numerikus adattípus dupla pontosságú, 64 bites lebegőpontos formátumban (IEEE 754).
  Például: `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` és `500000`.
- `bigint`: numerikus adattípus, amely _egész számokat_ tud ábrázolni tetszőleges pontosságú formátumban.
  Például: `-12n`, `0n`, `4n` és `9007199254740991n`.

Ha tetszőleges pontosságra van szükséged, vagy rendkívül nagy számokkal dolgozol, használd a `bigint` típust.
Egyébként valószínűleg a `number` típus a jobb választás.

### Kerekítés

Van egy beépített globális objektum, a `Math`, amely különféle [kerekítő függvényeket][ref-math-object-rounding] kínál.
A tizedes törteket például lefelé (`floor`) vagy felfelé (`ceil`) kerekítheted a legközelebbi egész számra.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## Aritmetikai operátorok

A JavaScript 6 különböző operátort kínál a számokon végzett alapvető aritmetikai műveletekhez.

- `+`: Az összeadás operátora a számok összegének kiszámítására szolgál.
- `-`: A kivonás operátora két szám különbségének kiszámítására szolgál
- `*`: A szorzás operátora két szám szorzatának kiszámítására szolgál.
- `/`: Az osztás operátora két szám elosztására szolgál.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: A maradék operátora egy elvégzett osztás maradékát adja meg.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: A hatványozás operátora egy szám hatványra emelésére szolgál.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### A műveletek sorrendje

Ha egy sorban több operátort használsz, a JavaScript egy elsőbbségi sorrendet követ, ahogyan [ez az elsőbbségi táblázat][mdn-operator-precedence] is mutatja.
A mi esetünkre egyszerűsítve: a JavaScript a PEDMAS-szabályt (zárójelek, hatványozás, osztás/szorzás, összeadás/kivonás) használja, amelyet az általános iskolai matekórán tanultunk.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### Rövidített értékadó operátorok

A rövidített értékadó operátorok rövidebb módot kínálnak arra, hogy aritmetikai műveletet hajts végre egy változón, és az új értéket ugyanannak a változónak add értékül.
Vegyél például két változót, `x`-et és `y`-t.
Ekkor az `x += y` ugyanaz, mint az `x = x + y`.
Ezt gyakran egy számmal használjuk a `y` változó helyett.
A többi 5 művelet is elvégezhető hasonló stílusban.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
