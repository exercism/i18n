# Utasítások

Ebben a feladatban nagy sportrajongó vagy, és most fedezted fel, hogy mennyire vonz az NBA-kosárlabda. Mivel még új vagy az NBA kosárlabdájában, alaposan elmélyedsz az NBA történetében: számon tartod a csapatokat, az edzőket és a győzelmi/vereségi statisztikáikat, és összehasonlítod őket egymással.

Mivel még nincs kedvenc csapatod, egy algoritmust is fejlesztesz majd, amivel eldöntheted, hogy szurkolj-e egy adott csapatnak.

Hét részfeladat segít kidolgozni a saját _szurkolj-egy-csapatért_ algoritmusodat.

## 1. Definiáld a modellt

Definiáld a `Coach` rekordot a következő két mezővel:

- `Name`: az edző neve, típusa `string`.
- `FormerPlayer`: megmutatja, hogy az edző korábban játékos volt-e, típusa `bool`.

Definiáld a `Stats` rekordot a következő két mezővel:

- `Wins`: a győzelmek száma, típusa `int`.
- `Losses`: a vereségek száma, típusa `int`.

Definiáld a `Team` rekordot a következő három mezővel:

- `Name`: a csapat neve, típusa `string`.
- `Coach`: a csapat edzője, típusa `Coach`.
- `Stats`: a csapat statisztikái, típusa `Stats`.

## 2. Hozd létre egy csapat edzőjét

Valósítsd meg a `createCoach` függvényt, amely paraméterként az edző nevét és a korábbi játékos státuszát kapja, és visszaadja a `Coach` rekordot:

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. Hozd létre egy csapat statisztikáit

Valósítsd meg a `createStats` függvényt, amely paraméterként a győzelmek és a vereségek számát kapja, és visszaadja a `Stats` rekordot:

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. Hozz létre egy csapatot

Valósítsd meg a `createTeam` függvényt, amely paraméterként a csapat nevét, az edzőt és a rekordot kapja, és visszaadja a `Team` rekordot:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. Cseréld le az edzőt

Mivel az NBA tulajdonosai türelmetlenek, azt tapasztaltad, hogy a rossz csapateredmények gyakran az edző lecseréléséhez vezetnek. Valósítsd meg a `replaceCoach` függvényt, amely paraméterként a csapatot és az új edzőt kapja, és visszaadja a csapatot, de már az új edzővel:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. Ellenőrizd, hogy ugyanaz-e a csapat

Miközben a statisztikákat elemzed, csapatok és rekordjaik listáit vezeted. Néha hibázol, és ilyenkor duplikált bejegyzések kerülnek a listádra. Valósítsd meg az `isSameTeam` függvényt, amely két csapatot kap, és `true`-t ad vissza, ha ugyanaz a csapat; egyébként `false`-t ad vissza:

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. Ellenőrizd, hogy szurkolj-e egy csapatnak

Miután sok csapatot és mérkőzést megvizsgáltál, kitaláltál egy algoritmust. Ha az alábbiak közül valamelyik igaz, szurkolsz annak a csapatnak:

- Az edző neve „Gregg Popovich”
- Az edző korábban játékos volt
- A csapat neve „Chicago Bulls”
- A csapat 60 vagy több mérkőzést nyert
- A csapatnak több a veresége, mint a győzelme

Valósítsd meg a `rootForTeam` függvényt, amely egy csapatot kap, és `true`-t ad vissza, ha szurkolni kell annak a csapatnak; egyébként `return` false:

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
