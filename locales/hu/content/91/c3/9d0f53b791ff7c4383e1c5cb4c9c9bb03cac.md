# Utasítások

Elyse, a leendő varázsló, folytatja a képzését.
Több pakli kártyát kap, amelyekkel be kell mutatnia a trükkjeit.
Hogy egy kicsit könnyebb legyen, csak az 1-től 10-ig terjedő kártyákat használja.
Minden kártyából csak egy van, a paklijaiban nincsenek ismétlődő lapok.

Ebben a feladatban a Julia Base könyvtárából származó metódusokkal elemezd egy tömb tartalmát.

## 1. Állapítsd meg, hogy egy kártya jelen van-e

Elyse szeretné megállapítani, hogy egy kártya jelen van-e a pakliban, azaz hogy a pakli tartalmaz-e egy adott számot.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. Keresd meg egy kártya pozícióját

Elyse szeretné tudni egy kártya pozícióját (indexét) a pakliban.
Ha a kártya nincs a pakliban, add vissza `nothing`-ot.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. Állapítsd meg, hogy minden kártya páros-e

Elyse szeretné tudni, hogy minden kártya páros-e, azaz hogy a pakli minden száma páros-e.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. Ellenőrizd, hogy a pakli tartalmaz-e páratlan értékű kártyát

Elyse szeretné tudni, hogy van-e páratlan szám a pakliban.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. Határozd meg az első páros kártya pozícióját

Elyse szeretné tudni az első páros kártya pozícióját.
Ha nincs páros kártya a pakliban, add vissza `nothing`-ot.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. Szerezd meg a pakliból az első páratlan kártyát

Elyse szeretné tudni az első páratlan kártya értékét.
Ha nincs páratlan kártya a pakliban, add vissza `nothing`-ot.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
