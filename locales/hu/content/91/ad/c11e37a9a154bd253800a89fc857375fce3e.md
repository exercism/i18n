# A témáról

A `SYMBOL:` nem *tárol* értéket, csupán egy név. Az érték egy névtérben él, és a név ennek a kulcsa.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Két scope:

- **global**: a `set-global`, `get-global` és `change-global` szavakkal írható és olvasható. Az értékek a folyamat teljes élettartama alatt megmaradnak.
- **dynamic**: a `set`, `get` és `change` szavakkal írható és olvasható. A kötések a `with-variable` forma futásáig élnek, így a külső kód „injektálhat” egy értéket, amelyet a belső kód lát, anélkül hogy ehhez minden közbeeső szignatúrát módosítani kellene.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

A `SYMBOL:` és a `SYMBOLS:` a szótár betöltésekor deklarálja a szimbólumokat, így azok fájlok között is megosztható hivatkozások lesznek.
