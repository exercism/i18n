# A fogalomról

Ahhoz, hogy egy objektum összehasonlítható legyen egy másik objektummal, implementálnia kell az `IComparable<T>` interfészt.
Ennek az interfésznek egyetlen metódusa van, amit implementálni kell: `int CompareTo(T other)`.

A `CompareTo` metódusnak három lehetséges visszatérési értéke van:

- Nullánál kisebb érték: az aktuális objektum kisebb, mint a másik objektum.
- Nullánál nagyobb érték: az aktuális objektum nagyobb, mint a másik objektum.
- Az érték nulla: az aktuális objektum egyenlő a másik objektummal.

```csharp
public class Book : IComparable<Book>
{
    public int PageCount { get; set; }

    public int CompareTo(Book other)
    {
        // If other is not a valid object reference, this instance is greater.
        if (other == null) return 1;

        // Compare books using their number of pages
        return PageCount.CompareTo(other.PageCount);
    }
}

var smallBook = new Book { PageCount = 99 };
var largeBook = new Book { PageCount = 3333 };

smallBook.CompareTo(largeBook);
// => -1
```
