# Utasítások

Élt egyszer egy különc programozó egy furcsa házban, amelynek rácsos ablakai voltak.
Egy nap elvállalt egy állást egy online álláshirdetési oldalon keresztül, hogy építsen egy bulirobotot.
A robotnak az a feladata, hogy köszöntse az embereket, és a helyükre kísérje őket.
Az első kiadás nagyon technikaira sikerült, és jól mutatta, hogy a programozó mennyire nem ért az emberekhez.
Ebből néhány dolog a következő kiadásba is átkerült.

## 1. Köszöntsd az új vendéget a buliban

Valósítsd meg a `Welcome` függvényt, amely a megadott név felhasználásával egy üdvözlő üzenetet ad vissza:

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. Köszöntsd azt az új vendéget, akinek ma van a születésnapja

Valósítsd meg a `HappyBirthday` függvényt, amely a személy megadott neve és életkora alapján egy születésnapi üzenetet ad vissza.
Sajnos a programozó egy kicsit kérkedő típus, így a robotnak fitogtatnia kell a tudását minden vendég születésnapjáról.

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. Add meg az útbaigazítást

Valósítsd meg az `AssignTable` függvényt, amely útbaigazítást ad.
Öt paramétert kell fogadnia.

- Az új vendég neve, akit köszönteni kell (`string`)
- Az asztal száma (`int`)
- Az asztalszomszéd neve (`string`)
- Az irány, amerre az asztal található (`string`)
- Az asztal távolsága (`float64`)

A pontos eredményformátum az alábbi példában látható.

A robot az asztal számát háromjegyű formátumban adja meg.
Ha a szám kevesebb mint háromjegyű, akkor annyi vezető nullát kap, hogy háromjegyű legyen (pl. a 3-ból 003 lesz).
A robot az asztal távolságát is megemlíti.
Szerencsére csak egy jegyre kerekített pontossággal.

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
