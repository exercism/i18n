# Névjegy

A Factor `<iota>` egy *virtuális* sorozatot állít elő a `0, 1, …, n-1` egészekből.
Ha `map`-pel végigmegyünk rajta, egy táblázatos sorozatot kapunk,
amelyben minden elem a pozíciójának a függvénye:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Két dolog segít abban, hogy egy egész számokból álló kódsorozatot
stringgé alakíts:

| szó       | szerep                                                  |
|-----------|---------------------------------------------------------|
| `CHAR:`   | értelmezés idejű literál, amely egy karakter kódpontját teszi a veremre |
| `>string` | kódpontok sorozatát stringgé alakítja                   |

A kettőt együtt használva megkapod a szokásos idiómát, amellyel
pozíció szerint indexelt karaktersort építhetsz:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Ha a karaktert a blokkon belül `if`-fel (vagy `?`-lel) választod ki,
a pozíciónkénti döntés közel marad ahhoz az indexhez, amelytől függ.
