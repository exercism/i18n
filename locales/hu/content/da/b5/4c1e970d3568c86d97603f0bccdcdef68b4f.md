# Break, Continue

Amikor ciklust vagy iteráló vezérlőszerkezetet használsz, a `break` és a `continue` kulcsszó segíthet a program folyamatának irányításában.
A `break` kulcsszó kilép a ciklus kontextusából a külső scope-ba, ezzel lezárva a ciklust.
A `continue` kulcsszó kihagyja az aktuális iteráció hátralévő részét, és a következő iteráció elején újraindítja a ciklus kontextusát.
Bár ritka, a kulcsszóhoz megadhatsz egy számot, amellyel szabályozhatod, hány kontextusból lépj ki, illetve hányat ugorj át a következő iterációra.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

Az előző példában a `continue` ötször (5) fut le, a hatodik (6) iterációban viszont a `break` fut le, és a kód kilép a ciklusból.
