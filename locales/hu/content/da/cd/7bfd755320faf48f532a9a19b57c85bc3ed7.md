# Róla

A Pythonban [az enum][enum-docs] egyedi nevek halmaza, amelyek egyedi, **állandó** értékekhez vannak kötve.
Az `Enums` definiálása egy `Enum` osztályból való örökléssel történik.
A beépített enumtípusok az `enum` modulban érhetők el, az `Enum` osztály pedig a `from enum import Enum` utasítással importálható.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

Figyeld meg, hogy az `enum` tagok értékei bármilyen adattípusúak lehetnek, például `str`, `tuple`, `float` és így tovább.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Az `Enums` [függvényhívás szintaxissal][enum-functional-example] is létrehozhatók.

```python
from enum import Enum

Animal = Enum('Animal', 'ANT BEE CAT DOG')
list(Animal)
#=> [<Animal.ANT: 1>, <Animal.BEE: 2>, <Animal.CAT: 3>, <Animal.DOG: 4>]

Animal.ANT.value
#=> 1
```

Ha egy `enum` két tagjának ugyanazt az értéket adod, a később definiált tag a korábbi álneve lesz. Egy `enum` két különböző tagja nem kaphatja ugyanazt a nevet.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>
```

Az enum tagjain a szokásos `for member in` szintaxissal lehet végigmenni:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)

# __members__.items() helps you to loop through alias as well
for member in Color.__members__.items():
    print(member)
#=> ('RED', <Color.RED: 1>)
#=> ('GREEN', <Color.GREEN: 2>)
#=> ('ALIAS_OF_RED', <Color.RED: 1>)
```

Az `Enum` tagjai összehasonlíthatók az [`is` (_identitásoperátor_)][identity-keyword] vagy az `is not` használatával. A `==` és a `!=` (_egyenlőségoperátorok_) ugyanígy működik:


```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Egész számok értékként való hozzárendeléséhez az [`auto()` függvény][enum-auto-docs] `1`-től indul, és automatikusan állítja be a további értékeket.

```python
class Shape(Enum):
    CIRCLE = auto()
    SQUARE = auto()
    OVAL = auto()
```

Az álnevek tiltásához (_az azonos értékek különböző névvel való megjelenésének megakadályozásához_) az [osztálydekorátor][class-decorator] [`@enum.unique`][enum-unique-decorator] dekorátor használható.

```python
@enum.unique
class Shape(Enum):
    CIRCLE = 1
    SQUARE = 2
    TRIANGLE = 1
#=> ValueError: duplicate values found in <enum 'Shape'>: TRIANGLE -> CIRCLE
```

Egy adott értékhez tartozó `enum` tag eléréséhez ezt a jelölést használhatod: `<EnumName>(<value>)`.

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```

Egy egyedi, [korlátozott `Enum`][restricted-enums] úgy hozható létre, hogy az `Enum` osztályt bármilyen mix-in vagy adattípussal leszármaztatod.
Például:


```python
class StrEnum(str, Enum):
    pass
```

Az `Enum` leszármaztatása csak akkor megengedett, ha az `enum` **nem** definiál egyetlen tagot sem.
