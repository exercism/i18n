# Bevezetés

A konstansok fordítási időben beállított értékek, amelyekhez nem rendelhető új érték.
Egyetlen konstans deklarálásához használd a `const` kulcsszót:

```go
const greeting = "hello"
```

Egy blokkban több konstanst is deklarálhatunk.
Egy blokkon belül az a konstans, amelynek nincs kifejezetten megadott értéke, megismétli az előző kifejezést:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

A konstansokat általában csomagszinten deklaráljuk, de függvényen belül is deklarálhatók.

## Típusos és típus nélküli konstansok

Ha egy konstanst típus megadása nélkül deklarálunk, az típus nélküli lesz.
A típus nélküli konstansnak nincs rögzített típusa; az értéke határozza meg, hogy milyen típusokkal kompatibilis.
Amíg a mögöttes érték kompatibilis, a fordító minden használatnál átalakítja a szükséges típusra:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

A típusos konstans már a deklarációkor rögzíti a típust:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## Mi lehet konstans

A konstansok értéke csak Boolean, szám, string vagy rune lehet.
Mivel az értékek fordítási időben állnak be, egy függvényhívás eredménye nem használható konstansként.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

Egy konstansblokkon belül az `iota` a konstans blokkon belüli pozícióját jelöli:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

Az első utáni minden konstans ugyanazt a kifejezést örökli, az `iota` pedig minden lépésnél eggyel nő.

Az `iota` kifejezéseken belül is használható.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
