# Utasítások

Ebben a feladatban még egy kis kódot írunk, ami a kedvenc szakácskönyvedből származó ragyogó lasagnéd elkészítéséhez és megsütéséhez kapcsolódik.

Négy részfeladatod van.
Az első magához a sütéshez kapcsolódik, a másik három a tökéletes előkészítésről szól.

## 1. Becsüld meg az előkészítési időt

Arra a következő lasagnéra, amit el fogsz készíteni, szeretnél elég időt félretenni, hogy élvezhesd a főzést.
Már megtervezted, milyen rétegei lesznek a lasagnédnak.
Most ezek alapján szeretnéd megbecsülni, mennyi ideig tart majd az előkészítés.

Készíts egy `PreparationTime` függvényt, amely egy rétegekből álló slice-ot `[]string` típusként, valamint a rétegenkénti átlagos előkészítési időt percben `int` típusként fogad.
A függvény a rétegek száma alapján becsülje meg és adja vissza a teljes előkészítési időt `int` típusként.
A Go-ban a függvényeknek nincs alapértelmezett értékük.
Ha az átlagos előkészítési időt `0`-ként adják át (ami az `int` alapértelmezett kezdőértéke), akkor a `2` alapértelmezett értéket kell használni.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. Számítsd ki a szükséges tészta és szósz mennyiségét

Amellett, hogy időt szánsz rá, szeretnéd azt is biztosítani, hogy legyen elég szósz és tészta az álmaid lasagnéjának elkészítéséhez.
A lasagnéd minden tésztarétegéhez 50 gramm tésztára lesz szükséged.
A lasagnéd minden szószrétegéhez 0,2 liter szószra lesz szükséged.

Definiáld a `Quantities` függvényt, amely paraméterként egy rétegekből álló slice-ot vesz át `[]string` típusként.
A függvény ezután meghatározza, mennyi tésztára és szószra lesz szükség az ételed elkészítéséhez.
Az eredményt két értékként kell visszaadni: `noodles` `int` típusként és `sauce` `float64` típusként.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. Add hozzá a titkos összetevőt

Nemrég meglátogattál egy barátodat, és lasagnét ettél nála.
Fantasztikus volt, és volt benne valami különleges.
A barátod elküldte az összetevők listáját, és elmondta, hogy a lista utolsó eleme a „titkos összetevő”, amitől az étel olyan különleges lett.
Most ezt a titkos összetevőt a saját receptedhez is hozzá szeretnéd adni.

Írj egy `AddSecretIngredient` függvényt, amely paraméterként két `[]string` típusú összetevőslice-ot fogad.
Az első paraméter a barátod által küldött lista, a második a saját recepted összetevőlistája.
Az összetevőlistád utolsó eleme mindig `"?"`.
A függvény cserélje le ezt a barátod listájának utolsó elemére.
**Megjegyzés:** az `AddSecretIngredient` nem ad vissza semmit, közvetlenül a saját összetevőlistádat kell módosítanod.
A barátod összetevőit tartalmazó listát **nem** szabad módosítani.
Ráadásul, mivel a `slice` pointerként kerül át a függvénybe, az `AddSecretIngredient` függvénynek átadott két `[]string` argumentum módosításai közvetlenül érvényesülnek.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Méretezd át a receptet

A szakácskönyvedben szereplő mennyiségek csak két adagra elegendő lasagnét adnak.
Mivel legközelebb több embernek szeretnél főzni, ki szeretnéd számítani a mennyiségeket különböző adagszámokhoz.

Készíts egy `ScaleRecipe` függvényt, amely két paramétert fogad.

- Egy `float64` típusú slice-ot a 2 adaghoz szükséges mennyiségekkel.
- Az elkészíteni kívánt adagok számát.

A függvény egy `float64` típusú slice-ot adjon vissza a kívánt adagszámhoz szükséges mennyiségekkel.
Az eredeti receptet viszont meg szeretnéd tartani.
Ez azt jelenti, hogy a `quantities` argumentumot nem szabad módosítani ebben a függvényben.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
