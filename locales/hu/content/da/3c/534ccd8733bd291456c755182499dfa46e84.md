# Bevezetés

A Cairo nyelvben a függvények segítségével a kódot egy újrahasznosítható egységbe foghatod össze, amitől a programjaid modulárisabbak és könnyebben érthetőek lesznek.
A Cairo függvényei az `fn` kulcsszóból, a függvény nevéből, a zárójelbe írt paraméterlistából és egy kódblokkból állnak, amely meghatározza, mit csinál a függvény.

## Függvényparaméterek

A Cairoban minden függvényparaméternél meg kell adni a típust.
A Cairo nem következtet a típusokra, és alapértelmezett paraméterértékek sincsenek, ezért minden paraméter kötelező.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## Paraméterek és argumentumok

Fontos különbséget tenni a `parameters` és az `arguments` között:

- A **paraméterek** a függvénydefinícióban használt változónevek, mint például a `greeting` és a `name` a `print_greeting_name` függvényben.
- Az **argumentumok** azok a tényleges értékek, amelyeket a függvény meghívásakor adunk át neki.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## Utasítások és kifejezések

A függvények törzse utasítások sorozatából áll, amelyek a végén opcionálisan egy kifejezéssel zárulnak.

- Az utasítások olyan műveletek, amelyek valamilyen hatást fejtenek ki, és nem adnak vissza értéket.
- A kifejezések egy eredményértékké értékelődnek ki.

Ha a `let` kulcsszóval hozol létre egy változót, és adsz neki értéket, az utasítás.

```rust
let y = 6;
```

A fenti utasításban viszont a `6` egy kifejezés, amely a `6` értékké értékelődik ki.

Egy függvény meghívása is kifejezés, mert mindig kiértékelődik egy értékké: a függvény explicit visszatérési értékévé, ha van ilyen, egyébként pedig az „unit” típus `()`.

## Visszatérési értékek

A Cairo függvényei értéket adhatnak vissza annak a kódnak, amely meghívja őket.
A visszatérési értéket a paraméterek után soroljuk fel, egy `->` nyíllal elválasztva.
A Cairoban a függvény visszatérési értéke megegyezik a függvény törzsének blokkjában szereplő utolsó kifejezés értékével.
A `return` kulcsszóval és egy érték megadásával korábban is visszatérhetsz a függvényből.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## Függvények meghívása

A Cairoban egy függvény meghívásához egyszerűen a függvény nevét írod le, utána zárójelben az argumentumokat.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
