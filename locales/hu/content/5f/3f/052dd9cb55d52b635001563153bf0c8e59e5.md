# Bevezetés

## Rekordok

A rekord olyan mezők gyűjteménye, amelyek összetartoznak, és amelyek akár különböző típusúak is lehetnek. Rekord definiálásához a `type` kulcsszót használjuk. A rekord mezőit a `{` és `}` karakterek között definiáljuk, és minden mezőnek van egy neve _és_ egy típusa. Rekord létrehozásához megadjuk a mezők nevét, majd a `{` és `}` karakterek között értéket rendelünk hozzájuk. Rekord létrehozásakor minden mezőnek értéket kell adni. Egy rekordpéldány mezőértékei pontjelöléssel érhetők el.

Rekord definiálásakor/létrehozásakor minden mezőnek vagy külön sorban kell lennie, vagy pontosvesszővel (`;`) elválasztva, ha egy sorban van.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Mivel a rekordok nem módosíthatók, miután létrehoztunk egy rekordot, a mezőértékei soha nem változhatnak. Ha szeretnéd módosítani egy rekord értékeit, a `with` kulcsszóval készíthetsz egy másolatot egy létező rekordról, de egy vagy több mező új értékével.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

A rekordok _strukturális egyenlőséggel_ rendelkeznek, ami azt jelenti, hogy ugyanazon rekord két azonos értékű példánya egyenértékű.

Amellett, hogy pontjelöléssel hozzáférhetsz egy rekord mezőihez, a rekordok kötésekben és mintaillesztésben is _szétbonthatók_:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
