# Névjegy

A [ternáris operátorok][ternary-operators] segítségével a feltételeket kifejezésekben, nem pedig utasításblokkokban adhatod meg. Ez a funkcionális programozás megközelítéseit idézi, és gyakran kifejezőbbé teszi a kódot, valamint kevésbé hajlamossá a hibákra.

A ternáris operátor három kifejezést kapcsol össze: egy feltételt, majd egy kifejezést, amely akkor értékelődik ki, és az értéke adódik vissza, ha a feltétel igaz (ez az `if` rész, amelyet a `?` vezet be), végül egy kifejezést, amely akkor értékelődik ki, és az értéke adódik vissza, ha a feltétel hamis (ez az `else` rész, amelyet a `:` vezet be).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
