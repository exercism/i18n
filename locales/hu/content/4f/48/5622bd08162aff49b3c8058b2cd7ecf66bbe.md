# Bevezetés

## Eredmények

A Gleam nem kivételekkel kezeli a hibákat: helyette azok a függvények adják vissza a generikus `Result` típust, amelyek sikerrel járhatnak vagy kudarcot vallhatnak.

A `Result` típus be van építve a nyelvbe, így nem kell definiálnod vagy importálnod, de ha mégis magad definiálnád, így nézne ki:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

Az `Ok` változatot akkor adja vissza a függvény, ha sikerrel jár, az `Error` változatot pedig akkor, ha kudarcot vall.

A `Result` nagyon gyakori a Gleamben, és a Gleam-programozók gyakran használják a [`gleam/result` modult](https://hexdocs.pm/gleam_stdlib/gleam/result.html), hogy könnyebb legyen velük dolgozni.

A `result.map` függvénnyel meghívhatsz egy függvényt az eredmény belsejében lévő értéken, ha az `Ok`, vagy változatlanul továbbengedhetsz egy `Error`-t.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

A `result.try` függvény hasonló, de itt a visszahívó függvénynek eredményt kell visszaadnia. Ez akkor hasznos, ha több eredményt visszaadó függvényt szeretnél egymás után fűzni.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
