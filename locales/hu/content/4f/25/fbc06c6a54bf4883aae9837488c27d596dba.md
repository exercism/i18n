# Tesztek futtatása

A terminálból lépj be a feladat alapkönyvtárába, majd futtasd a teszteket a következővel:

```bash
$ gleam test
```

Ez lefuttatja a `test` almappában található tesztfájlt, vagyis azt a fájlt, amelynek a neve `_test.gleam`-re végződik.

## Tesztfüggvények

A tesztek egy [saját tesztkeretrendszert](https://github.com/exercism/gleam-test-runner/tree/main/runner) használnak. A tesztkeretrendszer minden nyilvános függvényt tesztnek tekint a `test` könyvtárban, ha a neve `_test`-re végződik.

Például:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
