# Debug

A hibakeresés megkönnyítésére több makró is definiálva van a [debug.mac fájlban][debug].
Ezeket egy vagy több, megfelelő típusú és méretű argumentummal lehet meghívni.
Például:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rel mem, rsi ; prints two NUL-terminated strings
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
debug_flag e        ; prints true if je would jump, and false otherwise
```

Ahhoz, hogy ezek közül bármelyiket használd, a `debug.mac` fájlt be kell illesztened a megoldásfájl elejére:

```x86asm
%include "debug.mac"
```

Figyelem: az `rsp`-t minden makró ideiglenesen módosítja.
Egy vermen lévő érték hibakereséséhez előbb töltsd be magát az értéket vagy annak címét egy másik regiszterbe.

[debug]: https://github.com/exercism/x86-64-assembly/tree/main/templates/debug.mac
