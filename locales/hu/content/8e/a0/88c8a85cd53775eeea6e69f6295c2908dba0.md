# Utasítások

Ebben a feladatban olyan kódot írsz, amely segít egy szabadúszónak egyeztetni az ügyfeleivel bizonyos projektek árairól.
Néhány segédmetódust írsz, amelyekkel gyorsan kiszámíthatod az ügyfelek költségeit.

```exercism/note
A `rate_per_hour` paraméter és a `day_rate` metódus a pénzhez kapcsolódik.
A mértékegység az időegységre jutó pénz: rendre óra és nap.
```

## 1. Számítsd ki a napi díjat egy óradíj alapján

Egy ügyfél felveszi a kapcsolatot a szabadúszóval, hogy érdeklődjön a díjairól.
A szabadúszó elmagyarázza, hogy **_napi 8 órát dolgozik._**
A szabadúszó azonban csak a projekt óradíját ismeri.
Segíts neki megbecsülni a napi díjat egy óradíj alapján.

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

A napi díjat nem kell kerekíteni, sem „fix” pontosságúra alakítani.

## 2. Számítsd ki a munkanapok számát egy rögzített költségvetés alapján

Egy másik nap egy projektmenedzser felajánlja a szabadúszónak, hogy dolgozzon egy rögzített költségvetésű projekten.
A rögzített költségvetés és a szabadúszó óradíja alapján segíts neki kiszámítani, hány napot dolgozna, amíg a költségvetés ki nem merül.
Az eredményt _muszáj_ **lefelé kerekíteni** a legközelebbi egész számra.

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. Számítsd ki a kedvezményes díjat nagyobb projektek esetén

A szabadúszó ügyfelei gyakran több hónapon át tartó projektekre kérik fel.
Ilyenkor a szabadúszó úgy dönt, hogy minden teljes hónapra kedvezményt ad, a fennmaradó napokat pedig napi díjon számlázza.
A kiváló munka-magánélet egyensúlyod miatt minden naptári hónapban csak 22 napot dolgozol, így **_minden hónapban 22 számlázható nap van._**
Segíts neki megbecsülni az ilyen projektek költségét egy óradíj, a projektben lévő számlázható napok száma és egy havi kedvezménymérték alapján.
A kedvezményt mindig számként kell megadni, ahol a `42%` értéke `0.42`. Az eredményt _muszáj_ **felfelé kerekíteni** a legközelebbi egész számra.

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
