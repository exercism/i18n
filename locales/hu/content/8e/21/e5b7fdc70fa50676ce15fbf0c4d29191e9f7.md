# Operátortúlterhelés

Az operátortúlterhelés néhány programozási nyelv olyan lehetősége, amely megengedi a szabványos operátorok, például az összeadás (`+`), a kivonás (`-`), a szorzás (`*`) és az osztás (`/`) újradefiniálását, hogy azok felhasználó által definiált típusokkal is működjenek.

Ettől a kód szintaxisa intuitívabb lehet, mert a felhasználó által definiált típusokon végzett műveleteket ugyanúgy lehet leírni, mint a primitív típusokon végzett műveleteket.

Cairoban az operátortúlterhelést adott trait-ek implementálásával érheted el.

Minden operátorhoz tartozik egy trait, és az operátor túlterheléséhez meg kell adnod ennek a trait-nek egy implementációját egy saját típusra.
Fontos azonban, hogy az operátortúlterhelést megfontoltan használd.

A helytelen használat zavart kelthet, és megnehezítheti a kód karbantartását, például amikor a túlterhelt operátornak nincs szemantikai jelentése.

Vegyünk egy példát, amelyben két `Potions`-t kell összevonni.

A `Potions`-nak két adatmezője van: mana és health.

Két `Potions` összevonásakor a megfelelő mezőiket össze kell adni.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

A fenti kódban az `Add` trait-et implementáljuk a `Potion` típusra.

Az add függvény két argumentumot kap: `lhs` és `rhs` (bal és jobb oldal).

A függvény törzse egy új `Potion` példányt ad vissza, amelynek mezőértékei az `lhs` és az `rhs` értékeinek kombinációjából állnak össze.

A példa is mutatja, hogy egy operátor túlterheléséhez meg kell adni a túlterhelt konkrét típust.

A túlterhelt generikus trait az `Add<T>`, a `Potion` típusra pedig az `Add<Potion>`-nal adunk meg konkrét implementációt.
