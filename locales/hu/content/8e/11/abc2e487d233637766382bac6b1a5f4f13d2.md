# Bevezetés

A Swiftben vannak olyan utasítások, amelyekkel megváltoztatható a ciklusok szokásos vezérlésmenete.
Ezeket vezérlésátadó utasításoknak nevezzük.
A `return` utasítással már találkoztál; ez a fogalom továbbiakkal ismertet meg, köztük a `continue`, `break` és a címkék.

## Continue

Néha szükség lehet arra, hogy egy ciklus következő iterációjára korán ugorjunk, anélkül hogy befejeznénk a ciklus aktuális iterációjában lévő többi utasítást.
Erre a `continue` kulcsszót használhatod.
Amikor a `continue` végrehajtódik, a ciklus a következő ellenőrzéshez ugrik, hogy lássa, futtatható-e a ciklus következő iterációja, azaz a while és repeat-while ciklusokban a `while` feltételhez, a for-in ciklusokban pedig ahhoz az ellenőrzéshez, hogy van-e még elem a sorozatban.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

A break kulcsszó arra szolgál, hogy korán kilépj egy ciklusból.
Amikor a `break` végrehajtódik, a ciklus azonnal kilép, és a program a ciklus utáni első utasítással folytatódik.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Címkék

Amikor a ciklusok egymásba vannak ágyazva, előfordulhat, hogy `break` vagy `continue` használatával ki szeretnél lépni azokból a külső ciklusokból, amelyek tartalmazzák azt a ciklust, amelyben a `break` vagy `continue` szerepel, vagy újra szeretnéd indítani azokat.
Ilyen esetekben címkékkel jelölheted meg, hogy melyik ciklusból lépj ki vagy melyiket indítsd újra.
Egy ciklus címkézhető úgy, hogy a ciklust indító `while`, `repeat` vagy `for` elé egy nevet és egy kettőspontot írsz.

Hogy lásd, milyen hatása van a címkék ilyen használatának, nézzük meg a következő ciklust.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

A `fallthrough` kulcsszó arra szolgál, hogy egy switch utasításban a következő case-re essen át.
Ez azt jelenti, hogy a következő case ágban lévő kód anélkül fut le, hogy ellenőrizné a feltételét vagy feltételeit.
Ettől a switch utasítás úgy fog viselkedni, mint más programozási nyelvekben, ahol nem kötelező a `break` utasítás ahhoz, hogy egy case egyezése után kilépj a switch utasításból.
A `fallthrough` kulcsszóról a [Swift könyv][fallthrough]ben olvashatsz bővebben.

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```

[fallthrough]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Fallthrough
