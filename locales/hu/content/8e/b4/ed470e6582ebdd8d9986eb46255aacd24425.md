# Utasítások

Számold meg a téglalapokat az alábbihoz hasonló ASCII-ábrán.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

A fenti ábra az alábbi 6 téglalapot tartalmazza:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

Felteheted, hogy a bemenet mindig szabályos téglalap (azaz minden sor hossza megegyezik az első sor hosszával).
