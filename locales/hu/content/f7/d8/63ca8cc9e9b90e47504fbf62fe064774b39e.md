# Tippek

## 1. Határozd meg, hogy Pac-Man megehet-e egy szellemet

* A függvénynek boolean értéket kell visszaadnia.
* Az `and` logikai operátorral összekombinálhatod az argumentumokat, hogy eredményt kapj.

## 2. Határozd meg, hogy Pac-Man pontot szerez-e

* A függvénynek boolean értéket kell visszaadnia.
* A `or` boolean operátorral összekombinálhatod az argumentumokat, hogy eredményt kapj.

## 3. Határozd meg, hogy Pac-Man veszít-e

* A függvénynek boolean értéket kell visszaadnia.
* Az `and` és a `not` boolean operátorral összekombinálhatod az argumentumokat, hogy eredményt kapj.

## 4. Határozd meg, hogy Pac-Man nyer-e

* A függvénynek boolean értéket kell visszaadnia.
* Az `and` és a `not` boolean operátorral összekombinálhatod az argumentumokat és a korábban megvalósított függvények egyikének eredményét.
