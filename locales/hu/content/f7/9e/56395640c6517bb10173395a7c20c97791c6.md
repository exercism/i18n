# Munkafolyamatok

A GitHub Actions a _munkafolyamatok_ fogalmát használja: ezek olyan szkriptek, amelyek automatikusan lefutnak, valahányszor egy adott esemény bekövetkezik (például amikor pusholsz egy commitot).

Minden GitHub Actions-munkafolyamat egy `.yml` fájlban van definiálva a `.github/workflows` könyvtárban.
A munkafolyamatokról a következő dokumentációkban olvashatsz:

- [Munkafolyamat-szintaxis](https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions)
- [Mikor fusson a munkafolyamatod](https://docs.github.com/en/actions/writing-workflows/choosing-when-your-workflow-runs/triggering-a-workflow)
- [Hol fusson a munkafolyamatod](https://docs.github.com/en/actions/writing-workflows/choosing-where-your-workflow-runs)
- [Mit csináljon a munkafolyamatod](https://docs.github.com/en/actions/writing-workflows/choosing-what-your-workflow-does)
- [Munkafolyamatok írása](https://docs.github.com/en/actions/writing-workflows)
- [Bevált gyakorlatok](/docs/building/github/gha-best-practices)

## Megosztott munkafolyamatok

Néhány munkafolyamat több repozitórium között van megosztva.

```exercism/caution
A megosztott munkafolyamatok automatikusan szinkronizálódnak (az [org-wide-files repozitóriumból](https://github.com/exercism/org-wide-files/)).
Ezért a tartalmukat ne módosítsd kézzel.
```

### Általános munkafolyamatok

- [Címkék szinkronizálása](/docs/building/tracks/ci/workflows/sync-labels): a repozitórium címkéinek szinkronizálása fájlból

### Kurzusspecifikus munkafolyamatok

- [configlet](/docs/building/tracks/ci/workflows/configlet): ellenőrzi, hogy a kurzus (konfigurációs) fájljai megfelelően strukturáltak-e, szintaktikailag és szemantikailag is
- [Nem változtak fontos fájlok](/docs/building/tracks/ci/workflows/no-important-files-changed): azokra a pull requestekre kommentel, amelyek a meglévő megoldások újratesztelését eredményeznék
- [Test](/docs/building/tracks/new/setup-continuous-integration#h-test-workflow): ellenőrzi a kurzus feladatait

### Tooling-specifikus munkafolyamatok

- [Élesítés](/docs/building/tracks/ci/workflows/deploy): a kurzus tooling Docker image-ét élesíti a Docker Hubra és az ECR-be

### Opcionális munkafolyamatok

Vannak olyan munkafolyamatok is, amelyeket a kurzusok opcionálisan bekapcsolhatnak:

- [Közösségi közreműködések szüneteltetése](/docs/building/tracks/ci/workflows/pause-community-contributions): automatikusan kommentel azokra az új issue-kra és pull requestekre, amelyeket nem az Exercism GitHub-szervezet tagjai hoztak létre
