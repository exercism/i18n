# Utasítások

Tanársegéd vagy, aki a tanulók vizsgáit javítja.
Az eredmények kézi nyilvántartása egyre fárasztóbb és egyre hibahajlamosabb.
Úgy döntesz, hogy kicsit érdekesebbé teszed a dolgot, és írsz néhány függvényt, amelyek megszámolják és kiszámítják az osztály eredményeit.

## 1. A pontszámok kerekítése

Bár a vizsgakérdésekre adhatsz „részleges pontszámot", a vizsga végső pontszámai csak `int`-ek lehetnek.
Ezért mielőtt bármi mást tehetnél az osztály pontszámaival, végig kell menned a pontszámokon, és minden `float` pontszámot `int`-té kell alakítanod. Szerencsédre a Python beépített [`round()`][round] függvényével ezt könnyedén megteheted.

Készítsd el a `round_scores(student_scores)` függvényt, amely egy `student_scores` `list`-et kap.
A függvény _fogyassza el_ a bemeneti `list`-et, és `return`-nel adjon vissza egy új listát, amelyben minden pontszám `int`-té alakult.
A pontszámok sorrendje a kapott `list`-ben nem számít.

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. Nem átmenő tanulók

Ahogy javítottad a vizsgát, észrevetted, hogy néhány tanuló nem teljesített olyan jól, mint remélted.
De elkalandozott a figyelmed, és elfelejtetted feljegyezni, hogy pontosan _hány_ tanulóról van szó.

Készítsd el a `count_failed_students(student_scores)` függvényt, amely egy `student_scores` `list`-et kap.
A függvény számolja össze, hány tanulónak nincs átmenő pontszáma, és adja vissza ezt a számot egész számként.
Ahhoz, hogy egy tanuló átmenő osztályzatot szerezzen a vizsgán, **40**-nél nagyobb pontszámra van szüksége.

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. A „legjobb"

A tanár, akit segítesz, meg szeretné találni azt a tanulócsoportot, amelyik „a legjobban" teljesített ezen a vizsgán.
Az, hogy mi számít „a legjobbnak", folyton változik, ezért meg kell keresned azokat a pontszámokat, amelyek **nagyobb vagy egyenlő**, mint az aktuális küszöb.

Készítsd el az `above_threshold(student_scores, threshold)` függvényt, amely paraméterként `student_scores`-t (az osztályzatok `list`-ét) és `threshold`-ot (a „csúcspontszám" küszöbét) veszi át.
A függvény adjon vissza egy `list`-et minden olyan pontszámmal, amely `>=` a `threshold`-nál.

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. A betűosztályzatok kiszámítása

A tanár, akit segítesz, szeret betűosztályzatokat is adni a számokban kifejezett pontszámok mellé.
Mivel a tanulók ritkán érnek el 100 pontot egy vizsgán, a „betűosztályzatok" alsó küszöbeit a legmagasabb elért pontszám alapján számítják ki, és ezek egyenletesen nőnek a legmagasabb pontszám és a **<= 40**-es bukási küszöb között.

Készítsd el a `letter_grades(highest)` függvényt, amely argumentumként a vizsgán elért „legmagasabb" pontszámot kapja, és visszaad egy `list`-et minden „amerikai stílusú" osztályzatsáv alsó pontszámküszöbével: `["D", "C", "B", "A"]`.


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. Nevek párosítása a pontszámokhoz

Van egy listád a vizsgapontszámokról csökkenő sorrendben, és egy másik listád a tanulók neveivel, amelyek szintén a vizsgapontszámaik szerint csökkenő sorrendben vannak.
Szeretnéd minden tanuló nevét a hozzá tartozó vizsgapontszámhoz párosítani, és kiírni az osztály összesített rangsorát.

Készítsd el a `student_ranking(student_scores, student_names)` függvényt `student_scores` és `student_names` paraméterekkel.
A `student_names` `list` minden tanulónevét párosítsd a `student_scores` `list`-ből származó pontszámával.
Feltételezheted, hogy minden `list` argumentum a legmagasabb pontszámtól a legalacsonyabbig van rendezve.
A függvény egy `list`-et adjon vissza stringekkel, a következő formátumban: `<rank>. <student name>: <student score>`.

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. A „tökéletes" pontszám

Bár a 100-as „tökéletes" pontszám ritka egy vizsgán, érdekes tudni, hogy legalább egy tanuló elérte-e.

Készítsd el a `perfect_score(student_info)` függvényt `student_info` paraméterrel.
A `student_info` egy `list`-ekből álló `list`, amely minden tanuló nevét és pontszámát tartalmazza: `[["Charles", 90], ["Tony", 80]]`.
A függvény `return`-nel _az első_ `[<name>, <score>]` párt adja vissza annak a tanulónak, aki 100 pontot ért el a vizsgán.

Ha a `student_info`-ban nincs 100-as pontszám, akkor üres `list`-et kell visszaadni (`[]`).

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```

[round]: https://docs.python.org/3/library/functions.html#round
