# Utasítások

Egy online divatbutikot vezetsz. A készleted minden terméke egy kételemű tömb: `{ name price }`, a teljes készlet pedig egy termékekből álló tömb.

A hiányzó árat `f`-ként rögzítjük.

## 1. Rendezd a készletet ár szerint

Definiáld a `sort-by-price` függvényt, amely egy új tömböt ad vissza az ár szerint növekvő sorrendbe rendezett termékekkel.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. Keresd meg az ár nélküli termékeket

Definiáld a `with-missing-price` függvényt, amely egy olyan tömböt ad vissza, amely csak azokat a termékeket tartalmazza, amelyeknek az ára `f`.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. Számold meg a drága termékeket

Definiáld az `expensive-items` függvényt, amely egy készletet és egy árküszöböt vesz paraméterül, és visszaadja, hogy hány termék kerül szigorúan többe a küszöbnél.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. Keresd meg a legolcsóbb terméket

Definiáld a `cheapest-item` függvényt, amely a legkisebb árú terméket adja vissza. Az ár nélküli (`f`) termékek nem fordulnak elő a bemenetben.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. Add össze az összes árat

Definiáld a `total-price` függvényt, amely visszaadja az összes ár összegét. Az ár nélküli (`f`) termékek nem fordulnak elő a bemenetben.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. Formázd a terméket árcédulaként

Definiáld a `format-price-tag` függvényt, amely egy termékhez `"name: $price"` formátumú stringet ad vissza. Az ár nélküli (`f`) termékek itt nem fordulnak elő.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
