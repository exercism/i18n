# Bevezetés

## Reguláris kifejezések JavaScriptben

A [reguláris kifejezés][mdn-regular-expressions] (vagy regex) olyan karaktersorozat, amellyel egy string bizonyos elemeit célozhatjuk meg és alakíthatjuk át. Ennek köszönhetően a következőkre vagyunk képesek:

- **Kereshetsz** szöveget egy stringben
- **Lecserélhetsz** részstringeket egy stringben
- **Kinyerhetsz** információt egy stringből

> 💡 A JavaScript regex-implementációja része a nyelv ECMA-262 szabványának. Ez azt jelenti, hogy nem kell a böngészőspecifikus kompatibilitás miatt aggódnod.

## Hogyan hozzunk létre reguláris kifejezéseket?

JavaScriptben a reguláris kifejezéseket többnyire `/pattern/modifiers` formában írjuk.

Kétféleképpen hozhatunk létre reguláris kifejezést:

1. **Reguláris kifejezés literál**:

```javascript
const regex = /[a-z]/;
```

2. **RegExp** konstruktor:

```javascript
const regex = new RegExp('[a-z]');
```

Mindkét esetben a JavaScript egy objektumot hoz létre a regexből. Ajánlott a literált használni alapértelmezésként, mivel így a minta megváltoztathatatlan.

A RegExp konstruktort olyan esetekben használhatod, amikor a regex változni fog, vagy amikor még nem ismered (például egy bemenet esetén).

## 🏴‍☠️ Módosítók

A reguláris kifejezéseknek vannak opcionális szuperképességeik, az úgynevezett [`flags`][mdn-flags] módosítók, amelyek további funkciókat tesznek elérhetővé.

A leggyakrabban használtak közül néhány:

- `/g` - globális keresés
- `/i` - kis- és nagybetűre nem érzékeny
- `/m` - többsoros keresés

Íme egy egyszerű példa:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

A `g` karakterrel egy string összes lehetséges találatát feldolgozhatjuk. E funkció nélkül a JavaScript csak az első `Home` találatot emelte volna ki.

A kis- és nagybetűre nem érzékeny `/i` módosítóval rugalmasabban kereshetünk mintát. Így nem számít, hogy amit keresünk, csupa nagybetűvel (`UPPERCASE`) vagy kisbetűvel (`lowercase`) szerepel-e.

A `RegExp` konstruktor használatakor más a módosítók hozzáadásának a szintaxisa.

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## A leggyakoribb függvények

Ha a reguláris kifejezéseket a JavaScript beépített függvényeivel kombináljuk, erőteljes eszközöket kapunk a stringek kezeléséhez és az adatok kinyeréséhez.

Íme néhány a regexszel leggyakrabban együtt használt függvény közül.

### Test

A [test()][mdn-regex-test]] metódus egy reguláris kifejezés és egy megadott string között keres egyezést. Igaz vagy hamis értéket ad vissza.

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

A [match()][mdn-regex-match] metódussal egy hasznos tömböt kapunk, amelynek a tartalma attól függ, hogy a keresett egyezések jelen vannak-e vagy sem.

Így egyaránt tudunk **keresni** és **információt kinyerni** bármely stringből. Például:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

Ha jelen van a globális keresés `/g` módosítója, a metódus nem csupán az egyetlen találatot adja vissza a hasznos információkkal (például az indexszel vagy a bemenettel) együtt, hanem a tömbben az összes előfordulást visszaadja:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

A JavaScript [replace()][mdn-regex-replace] metódusával egy adott stringen belül kereshetsz egy értéket, és lecserélheted egy kívánt új értékre.

```javascript
string.replace(searchValue, newValue);
```

A kereséshez használt minta lehet egyetlen string vagy egy reguláris kifejezés.

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

Ráadásul a csere helyére függvényt is tehetünk, hogy minden egyes értéket tovább alakítsunk.

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### Split

A JavaScript [split()][mdn-regex-split] metódusa más módját kínálja annak, hogy reguláris kifejezésekkel stringeket használjunk és alakítsunk.

Így a regex segítségével egy minta felismerésével darabolhatunk fel egy adott stringet, például `str.split(/[,.\s]/)`. Ez a minta tölti be a `separator` szerepét.

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
