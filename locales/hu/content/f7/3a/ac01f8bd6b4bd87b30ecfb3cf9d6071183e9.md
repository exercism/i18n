# Bevezetés

A C# [`enum` típusa](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) névvel ellátott konstansok rögzített halmazát jelöli (egy felsorolást).

Rendszerint egy `enum` tag csak pontosan egy névvel ellátott konstansra hivatkozhat. Néha azonban hasznos lehet, ha egynél több konstansra hivatkozhatsz. Ehhez az `enum` típusra teheted a [`Flags` attribútumot](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute).

Egy flags enum definiálása így néz ki (a `0b` bináris egészjelölést használva):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Egy `PhoneFeatures` példány, amelynek az értéke `0b00000011`, a `Call` _és_ a `Text` jelzővel is rendelkezik.

Alapértelmezés szerint az `enum` tagok értéke `int` típusú. Más egész számtípust is használhatsz, ha az `enum` deklarációjában megadod a típust:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
