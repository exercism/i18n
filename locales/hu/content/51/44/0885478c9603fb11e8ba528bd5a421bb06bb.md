# Névjegy

A Clojure-ban egy érték névhez kötését [_var_][vars]-nak nevezzük. A legfelső szintű (globális) var-ok hasonlók más nyelvek konstansaihoz, de a dinamikus fejlesztés elősegítése érdekében gyakran újradefiniálják őket.

A legfelső szintű var-okat a [`def`][def] segítségével definiáljuk:

```clojure
(def fingers 10)
```

Az értékeken végzett aritmetikai műveletekhez használhatod a [számokkal végzett műveletek][operators]hez tartozó alapvető függvényeket.

A `defn` makróval definiálhatsz egy [függvényt][functions], amely nulla vagy több argumentumot fogad. A függvény mindig a törzsében található utolsó kifejezés eredményét adja vissza.

```clojure
(defn add [x y]
  (+ x y))
```

Egy függvény meghívásához meg kell adni a nevét, és minden paraméteréhez át kell adni egy-egy argumentumot.

```clojure
(def five (add 2 3))
```

A Clojure-ban a függvényeket és értékeket csak _azután_ lehet használni, miután definiálták őket. Ha a definiálása előtt használod, fordítási hiba lesz.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

A Clojure-ban a whitespace-nek a formázáson kívül nincs jelentősége.

A Clojure-ban a függvények és var-ok névterekbe rendeződnek. Egy névtér a kapcsolódó funkcionalitást csoportosítja, és a `ns` makróval definiáljuk:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

A Clojure kétféle megjegyzést támogat. Az egysoros megjegyzéseket `;` előzi meg, a `comment` forma pedig a `(comment` és a `)` közötti rész kiértékelésének megakadályozására szolgál.
