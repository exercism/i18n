# A `match` alapjai

A `match` kifejezéssel egyszerűen összehasonlíthatsz egy értéket minták sorozatával, majd a találatnak megfelelő kódot futtathatod. A minták literálértékekből, változónevekből, wildcardokból és sok más dologból állhatnak.

```rust
#[derive(Drop)]
enum Color {
    Red,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red => println!("The color is Red"),
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Yellow;
    print_color_type(color); // prints "The color is Yellow"
}
```

Ha egy `match`-ág több sor kódból áll, kapcsos zárójelek `{}` közé kell tenned:

```rust
fn specified_color(color: Color) -> felt252 {
    let mut response: felt252 = '';

    match color {
        Color::Red => {
            response = 'You passed in Red';
        },
        Color::Yellow => {
            response = 'You passed in Yellow';
        },
        Color::Green => {
            response = 'You passed in Green';
        },
    }

    response
}
```

A `match` kifejezés arra is képes, hogy a mintára illeszkedő értékekhez kössön. Így kinyerheted egy enumváltozat hozzátartozó értékét.

```rust
#[derive(Drop, Debug)]
enum ColorType {
    Light,
    Dark,
}

#[derive(Drop)]
enum Color {
    Red: ColorType,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red(state) => {
            println!("The color is Red");
            println!("The Color Type is {:?}", state);
        },
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Red(ColorType::Dark);
    print_color_type(color);
}
```

A `Color` enum `Red` változatát kibővítettük egy hozzátartozó enummal. A `match` kifejezés segítségével ki tudtuk nyerni a hozzátartozó értéket, a `state`-et. Ez egyszerűen egy változónév, amelyet később a kódágban használhatsz.

## Az `Option` enumtípus illesztése

A beépített `Option` enumot is kezelheted a `match` kifejezéssel.

Tervezzünk egy függvényt, amely egy `Option<u8>` paramétert kap. Ha a kapott paraméterben van érték, adjunk hozzá egyet, különben a függvény a `None` értéket adja vissza, minden művelet nélkül.

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
        Option::None => Option::None,
    }
}

fn main() {
    let three: Option<u8> = Option::Some(3);
    let four: Option<u8> = add_one(three);
    let none = add_one(Option::None);

    println!("{three:?}"); // prints "Option::Some(3)"
    println!("{four:?}"); // prints "Option::Some(4)"
    println!("{none:?}"); // prints "Option::None(())"
}
```

> Megjegyzés: a `{:?}` egy speciális formázási szintaxis, amellyel a `println!` makrónak átadott paraméter debug formáját írhatod ki.
> További információt a [The Cairo Book][debugging] című könyvben találsz.

A `match` vezérlési szerkezet egyik előnye a kimerítő jellege: az ágak mintáinak _minden_ lehetőséget le kell fedniük. Nézd meg az előző példa azon változatát, amely nem kezeli a `None` esetet:

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
    }
     // this code does not compile, as we forgot to handle the `None` case
}
```

## Mindent elkapó minta a `_` wildcarddal

Az enumoknál előfordulhat, hogy néhány konkrét értékre külön műveletet végzünk, minden más értékre pedig egy alapértelmezett műveletet: ehhez vegyünk fel egy új ágat `_` mintával a `match` kifejezés utolsó ágaként. A `_` minta egy speciális minta, amely bármely értékre illeszkedik, és nem köt hozzá értéket.

Az `is_red` függvény egy paramétert kap, és `true`-t ad vissza, ha a szín `Red`, egyébként bármely más színre `false`-t:

```rust
fn is_red(color: Color) -> bool {
    match color {
        Color::Red => true,
        _ => false,
    }
}
```

## Mintaillesztés a `|` operátorral

A Cairo `match` vezérlési szerkezete lehetővé teszi, hogy egy értéket több mintával illessz a `|` (_vagy_) operátorral. Ez leegyszerűsíti a kódot.

Például a `Color` enum használatával írjunk egy függvényt, amely `true`-t ad vissza `Red` vagy `Green` színre, és `false`-t minden más színre:

```rust
fn is_red_or_green(color: Color) -> bool {
    match color {
        Color::Red | Color::Green => true,
        _ => false,
    }
}
```

## Mintailesztés `felt252`-vel és egész típusú változókkal

Lehetséges `felt252` és egész értékű változók illesztése egy értékhalmazra. Van azonban néhány megkötés:

- Csak az egyetlen `felt252`-be beleférő egészeket támogatja (azaz a `u256` nem támogatott).
- A 0-nak az első ágban kell szerepelnie.
- Minden ágnak egy folytonos szakaszt kell lefednie, szorosan kapcsolódva a többi ághoz.

Valósítsunk meg egy hatoldalú kockadobó játékot. Amikor dobsz a kockával, egy 0 és 5 közötti számot kapsz. Ha a dobás eredménye 0, 1 vagy 2, nyersz. Ha 3, újra dobhatsz. Minden más értékre veszítesz:

```rust
fn toss(value: u8) {
    match value {
        0 | 1 | 2 => println!("you won!"),
        3 => println!("you can roll again!"),
        _ => println!("you lost...")
    }
}

fn main() {
    toss(2); // prints "you won!".
    toss(3); // prints "you can roll again!".
    toss(5); // prints "you lost...".
}
```

## Tuple-ök illesztése

A tuple-ök egy mintahalmazra is illeszthetők. Ezeket a mintákat a tuple-ökhöz hasonlóan építjük fel.

```rust
#[derive(Drop)]
enum DayType {
    Week,
    Weekend,
    Holiday
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn vending_machine_accept(c: (DayType, Coin)) -> bool {
    match c {
        (DayType::Week, _) => true, // accepts all coins during week day
        (_, Coin::Dime) | (_, Coin::Quarter) => true, // accepts only Dime or Quarter coin for all specified days
        (_, _) => false, // returns false for other instances
    }
}
```

Az utolsó `match`-ágban mindegy, hogy `(_, _)`-t vagy csak a `_` wildcardot használjuk bármely nap- és színkombináció illesztésére, mert funkcionálisan ugyanazok.
