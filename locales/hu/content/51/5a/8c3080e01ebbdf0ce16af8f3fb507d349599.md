# Bevezetés

Az `Agent` modul absztrakciót kínál [folyamatok és a _fogadás-küldés_ ciklus][exercism-processes] létrehozására. A továbbiakban az `Agent` modullal indított folyamatokat _agentfolyamatoknak_ nevezzük. Egy _agentfolyamat_ választható arra, hogy egy központi, megosztott állapotot képviseljen.

Egy _agentfolyamat_ indításához az `Agent` a `start/2` függvényt biztosítja. Az _agentfolyamat_ `start`-olásakor megadott függvény visszaadja a folyamat kezdőállapotát:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Ahogy a `Map` vagy a `List`, úgy az `Agent` is számos függvényt kínál az _agentfolyamatokkal_ való munkához.

Szokás, hogy az `Agent`-tel kapcsolatos összes funkciót egyetlen modulba rendezzük és zárjuk egységbe, amely a modellezett tartományhoz tartozik.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
