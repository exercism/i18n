# Utasítások

Ebben a feladatban olyan kódot írsz, amely jelvényeket nyomtat a gyár dolgozói számára.

## 1. Jelvény nyomtatása egy dolgozónak

A dolgozóknak van azonosítójuk, nevük és részlegnevük.
A dolgozói jelvények címkéi a következő formátumban vannak: `"[id] - name - DEPARTMENT"`.
Valósítsd meg a `printBadge()` metódust, amely visszaadja egy dolgozó jelvényének címkéjét:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Vedd figyelembe, hogy a címkén a részleg nevének csupa nagybetűvel kell szerepelnie.
~~~~

## 2. Jelvény nyomtatása egy új dolgozónak

A számítógépes rendszer egyik sajátossága miatt előfordul, hogy az új dolgozóknak még nincs azonosítójuk, amikor elkezdenek a gyárban dolgozni.
Mivel a jelvény kötelező, kapnak egy ideiglenes jelvényt, amelyen nincs ott az azonosító előtagja.
Módosítsd a `printBadge()` metódust, hogy támogassa azokat az új dolgozókat, akiknek még nincs azonosítójuk:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Jelvény nyomtatása a tulajdonosnak

Még a gyár tulajdonosának is folyamatosan jelvényt kell viselnie.
A tulajdonosnak viszont nincs részlege.
Ebben az esetben a címkére a részleg neve helyett a `"OWNER"` szöveg kerül.
Módosítsd a `printBadge()` metódust, hogy a tulajdonos számára is címkét nyomtasson:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Vedd figyelembe, hogy előfordulhat, hogy a tulajdonos egyben új dolgozó is:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
