# Bevezetés

## Nullázhatóság

Java-ban a `null` literál az érték hiányát jelöli.

A primitív adattípusoknak Java-ban mindig van alapértelmezett értékük, ezért soha nem lehetnek `null` értékűek.
Konvenció szerint kisbetűvel kezdődnek, például `int`.

A referenciatípusok egy objektum memóriacímét tárolják, és felvehetik a `null` értéket is.
Általában nagybetűvel kezdődnek, például `String`.

Ha megpróbálsz egy primitív változónak `null` értéket adni, az fordítási idejű hibát eredményez, mert a változó mindig a hozzá rendelt típus primitív értékét tárolja.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Ha egy referenciaváltozónak adsz `null` értéket, az nem eredményez fordítási idejű hibát, mert a referenciaváltozók nullázhatók.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
