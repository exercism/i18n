# Bevezetés

## Párok

A `Pair` nem más, mint két összekapcsolt elem.
Az elemeket aztán ötletesen `first` és `second` néven emlegetjük.

Létrehozhatod őket a `=>` operátorral vagy a `Pair()` konstruktorral is.

```julia-repl
julia> p1 = "k" => 2
"k" => 2

julia> p2 = Pair("k", 2)
"k" => 2

# Both forms of syntax give the same result
julia> p1 == p2
true

# Each component has its own separate type
julia> dump(p1)
Pair{String, Int64}
  first: String "k"
  second: Int64 2

# Get a component using dot syntax
julia> p1.first
"k"

julia> p1.second
2
```

## Szótárak

Egy `Pair`-ekből álló `Vector` olyan, mint bármely más tömb: rendezett, típusában homogén, és a memóriában egymás után tárolódik.

```julia-repl
julia> pv = ['a' => 1, 'b' => 2, 'c' => 3]
3-element Vector{Pair{Char, Int64}}:
 'a' => 1
 'b' => 2
 'c' => 3

# Each pair is a single entry
julia> length(pv)
3
```

A `Dict` felületesen nézve hasonló, de a tárolás most úgy van megvalósítva, hogy kulcs alapján gyorsan vissza lehessen keresni, még akkor is, ha a bejegyzések száma nagyra nő.

```julia-repl
julia> pd = Dict('a' => 1, 'b' => 2, 'c' => 3)
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

julia> pd['b']
2

# Key must exist
julia> pd['d']
ERROR: KeyError: key 'd' not found

# Generators are accepted in the constructor (and note the unordered output)
julia> Dict(x => 1 / x for x in 1:5)
Dict{Int64, Float64} with 5 entries:
  5 => 0.2
  4 => 0.25
  2 => 0.5
  3 => 0.333333
  1 => 1.0
  ```

Más nyelvekben a `Dict`-hez nagyon hasonló dolgot szótárnak (Python), Hash-nek (Ruby) vagy HashMap-nek (Java) nevezhetnek.

A `Pair`-eknél, akár önmagukban állnak, akár egy Vector-ban, kevés megkötés vonatkozik az egyes komponensek típusára.

Ahhoz, hogy egy `Pair` érvényes legyen egy `Dict`-ben, olyan `key => value` párnak kell lennie, ahol a `key` „hashable”.
Ez legfőképpen azt jelenti, hogy a `key`-nek _megváltoztathatatlannak_ kell lennie, így a `Char`, az `Int`, a `String`, a `Symbol` és a `Tuple` mind rendben van, a `Vector` viszont nem megengedett.

### A Dict módosítása

A bejegyzéseket hozzáadhatod új kulccsal, vagy felülírhatod egy már létező kulccsal.

```julia-repl
julia> pd
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

# Add
julia> pd['d'] = 4
4

# Overwrite
julia> pd['a'] = 42
42

julia> pd
Dict{Char, Int64} with 4 entries:
  'a' => 42
  'c' => 3
  'd' => 4
  'b' => 2
```

Egy bejegyzés eltávolításához használd a `delete!()` függvényt, amely módosítja a Dict-et, ha a kulcs létezik, egyébként pedig csendben semmit sem tesz.

```julia-repl
julia> delete!(pd, 'd')
Dict{Char, Int64} with 3 entries:
  'a' => 42
  'c' => 3
  'b' => 2
```

### Kulcs vagy érték létezésének ellenőrzése

Többféle megközelítés létezik.
Egy kulcs ellenőrzésére ott van a `haskey()` függvény:

```julia-repl
julia> haskey(pd, 'b')
true
```

Vagy kereshetsz a kulcsok vagy az értékek között:

```julia-repl
julia> 'b' in keys(pd)
true

julia> 43 in values(pd)
false

julia> 42 ∈ values(pd)
true
```
