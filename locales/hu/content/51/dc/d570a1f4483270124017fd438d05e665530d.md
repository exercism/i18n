# Bevezetés

A charlist a `~c` sigil segítségével jön létre.

```elixir
~c"hello"
```

~~~~exercism/note
Vedd figyelembe, hogy az Elixir régebbi verzióiban a charlist `'hello'` alakban, aposztrófokkal jelenik meg.
~~~~

Bár nagyon hasonlít a stringekhez, a két adattípus jelentősen különbözik egymástól. A charlist egész számok listája. Az egész számok egy adott karakter Unicode-értékét jelentik, amelyet kódpontnak is neveznek.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Ha egy karakter elé `?`-t teszel, megkapod a kódpontját.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Mivel a charlist lista, ugyanúgy dolgozhatsz vele, mint bármely más listával: rekurzióval és mintaillesztéssel.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Két listát a `++` operátorral fűzhetsz össze.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Minél hosszabb az első lista, annál lassabb az összefűzés, ezért kerüld, hogy ismételten hozzáfűzz tetszőleges hosszúságú listákhoz.
