# Utasítások

Ebben a feladatban egy távirányítású autóval fogsz játszani, amelyre végre összegyűjtöttél annyi pénzt, hogy megvedd.

Az autók feltöltött (100%-os) akkumulátorral indulnak. Valahányszor elindítod az autót a távirányítóval, 20 métert tesz meg, és az akkumulátor töltöttsége egy százalékkal csökken.

A távirányítású autón van egy menő LED-kijelző, amely két adatot mutat:

- A teljes megtett távolságot, így jelenik meg: `"Driven <METERS> meters"`.
- Az akkumulátor hátralévő töltöttségét, így jelenik meg: `"Battery at <PERCENTAGE>%"`.

Ha az akkumulátor 0%-on áll, nem tudod tovább vezetni az autót, és az akkumulátor kijelzője ezt mutatja: `"Battery empty"`.

Hat részfeladat vár rád, amelyek mindegyike a távirányítású autó példányaival dolgozik.

## 1. Vásárolj egy vadonatúj távirányítású autót

A (_statikus_) `RemoteControlCar.Buy()` metódust úgy valósítsd meg, hogy egy vadonatúj távirányítású autópéldányt adjon vissza:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. Jelenítsd meg a megtett távolságot

A `RemoteControlCar.DistanceDisplay()` metódust úgy valósítsd meg, hogy a LED-kijelzőn látható távolságot adja vissza:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. Jelenítsd meg az akkumulátor töltöttségi szintjét

A `RemoteControlCar.BatteryDisplay()` metódust úgy valósítsd meg, hogy az akkumulátor töltöttségi szintjét a LED-kijelzőn látható formában adja vissza:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. Frissítsd a megtett méterek számát vezetéskor

A `RemoteControlCar.Drive()` metódust úgy valósítsd meg, hogy frissítse a megtett méterek számát:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. Frissítsd az akkumulátor töltöttségi szintjét vezetéskor

A `RemoteControlCar.Drive()` metódust frissítsd úgy, hogy az akkumulátor töltöttségi szintjét is frissítse:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. Akadályozd meg a vezetést, amikor lemerül az akkumulátor

A `RemoteControlCar.Drive()` metódust frissítsd úgy, hogy amikor az akkumulátor lemerült (0%-on áll), ne növelje a megtett távolságot, és ne csökkentse az akkumulátor töltöttségi szintjét:

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
