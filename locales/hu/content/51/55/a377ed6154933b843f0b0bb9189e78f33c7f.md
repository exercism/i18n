# Bevezetés

A ciklus arra való, hogy egy vagy több utasítást ismételten, egy csoportban hajtsunk végre.
Egy utasításcsoport minden egyes végrehajtását iterációnak nevezzük.

## While-ciklus

A `while` ciklus addig hajtja végre az utasítások egy csoportját, amíg a ciklus elején álló Boolean-kifejezés igaz.
Amikor a Boolean-kifejezés hamis, a ciklus leáll, és a végrehajtás a ciklus utáni következő kódsorral folytatódik.

Ha a Boolean-kifejezés már az elején hamis értéket ad, a `while` ciklus egyszer sem fut le, és a végrehajtás rögtön a ciklus utáni következő kódsorral folytatódik.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Fontos, hogy legyen egy feltétel, ami lezárja a ciklust; különben végtelen ciklus keletkezik belőle, ami megakadályozza, hogy a kód továbbhaladjon.
Ha a fenti kódban az `i` mögül elhagynánk a `++`-t, végtelen ciklust kapnánk.

## Do-ciklus

A `do` ciklus esetében a Boolean-kifejezés ellenőrzése a ciklus alján történik.
A `do` ciklus mindig lefut legalább egyszer, ahogy a következő példában is

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

`while` ciklussal ugyanez körülményesebb lenne

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## For-ciklus

Egy ciklus gyakran frissít egy változót, és akkor ér véget, amikor a változó elér egy bizonyos értéket.
A `for` ciklus arra való, hogy egy vagy több változót egyetlen sorban, zárójelben kezdőértékkel lássunk el, majd frissítsünk és ellenőrizzünk.
Az első rész a változó kezdőértékének megadására szolgál, a második a változó ellenőrzésére, a harmadik pedig a változó értékének frissítésére.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Ez kevésbé körülményes, mint a megfelelő `while` ciklus, mégis jól olvasható.
