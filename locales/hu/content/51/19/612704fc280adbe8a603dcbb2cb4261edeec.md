# Részletesen

A Factorban a sorozatoknak két fajtája van, ha *módosítani* szeretnéd őket:

- A **tömbök** (`{ … }`) hossza rögzített. Az `set-nth` / `change-nth` szavakkal
  megváltoztathatod, hogy *mi van* az egyes pozíciókban, de nem tudod
  növelni vagy csökkenteni őket.
- A **vektorok** (`V{ … }`) változó hosszúságúak. A `push` a végére fűz,
  a `pop` eltávolítja és visszaadja az utolsó elemet.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| word            | effect                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`, azaz `n` darab `elt` másolatából álló tömb |
| `<vector>`      | `( n -- vector )`, azaz üres vektor `n` kapacitással |
| `V{ }`          | üres vektorliterál                             |
| `set-nth`       | `( elt n seq -- )`, azaz értékadás az `n` indexű elemnek |
| `change-nth`    | `( i seq quot -- )`, azaz `quot` alkalmazása az `i` indexű elemre |
| `push`          | `( elt seq -- )`, azaz hozzáfűzés egy vektorhoz  |
| `suffix!`       | `( seq elt -- seq )`, azaz helyben hozzáfűzés, visszaadja a vektort |
| `pop`           | `( seq -- elt )`, azaz az utolsó elem eltávolítása és visszaadása |
| `pop*`          | `( seq -- )`, azaz az utolsó elem eltávolítása, eldobása |
| `clone`         | `( obj -- copy )`, azaz friss, független másolat |
| `new-sequence`  | `( n exemplar -- newseq )`, azaz friss sorozat, ugyanolyan osztályú, mint az `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )`, azaz friss, átméretezhető változat |

Ha módosítasz egy sorozatot, amit a hívó adott át, a változás a hívó
számára is látható lesz, hiszen ugyanazt az objektumot tartja kézben. Ha
viszont nem ezt szeretnéd, először készíts független másolatot a `clone`
szóval.
