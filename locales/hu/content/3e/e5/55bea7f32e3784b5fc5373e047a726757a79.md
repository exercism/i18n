# Utasítások

A városodban több pizzaszelet-üzlet is van, és szeretnél írni egy webalkalmazást, amellyel két különböző pizzakonfigurációt hasonlíthatsz össze, hogy megtudd, ki adja a nagyobb szeletet.

## 1. Írj egy függvényt, amely kiszámítja a szeletméreteket, és érvénytelen bemenet esetén nil-t ad vissza.

Valósítsd meg a `sliceSize(diameter: Double?, slices: Int?) -> Double?` függvényt, amely egy pizza átmérője és a pizzánkénti szeletek száma alapján visszaadja egy szelet területét.
Negatív átmérő és 1-nél kevesebb szeletszám esetén add vissza a `nil` értéket, hiszen nincs olyan pizza, amelynek negatív az átmérője, és egy pizzát sem lehet 1-nél kevesebb szeletre vágni.
Ha bármelyik paraméter `nil`, akkor is add vissza a `nil` értéket.

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Dolgozd fel a webalkalmazásod bemenetét, hogy meghatározd, melyik szelet a nagyobb.

A webalkalmazásod négy stringet ad át a `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String` függvényednek.
Az első és a második string az első pizza átmérője, illetve szeletszáma, a harmadik és a negyedik pedig a második pizza átmérője, illetve szeletszáma.

Úgy valósítsd meg a `biggestSlice` függvényt, hogy megpróbálja az egyes pizzák átmérőjét és szeletszámát rendre `Double` és `Int` típusra alakítani.
Ha mindkét érték kinyerhető a stringekből, az első függvényeddel próbáld meg kiszámítani a területet, ellenkező esetben az adott szelet területe `nil`.
Amint megvan mindkét szelet területe, hasonlítsd össze a két területet a következő szabályok szerint:

1. Ha az A szelet területe `Double`, a B szeleté pedig `nil`, add vissza a „Slice A is bigger” értéket. Ha ez fordítva igaz, add vissza a „Slice B is bigger” értéket.
2. Ha mindkét terület `Double` típusú, add vissza a „Slice A is bigger” vagy a „Slice B is bigger” értéket aszerint, hogy melyik szelet területe nagyobb.
3. Ha mindkét terület `nil`, vagy ha mindkettő `Double` típusú és egyenlők, add vissza a „Neither slice is bigger” értéket.

~~~~exercism/note
Még ha a bemenet 0 területű szeletet eredményez is, a szelet akkor is érvényesnek számít, és nagyobbnak kell tekinteni, mint egy `nil` területű szelet.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
