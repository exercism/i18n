# Tesztek

Ha a CLI-eszközzel töltöttél le egy feladatot, akkor egy, a feladatról elnevezett Uiua-fájlt és egy `tests.ua` fájlt kell látnod.
Ez a fájl tartalmazza az összes tesztesetet, amelyek megegyeznek azokkal, amiket a tesztfuttató futtat, amikor feltöltöd a megoldásodat.
Nyugodtan adj hozzá további teszteseteket a kísérletezéshez.
A tesztek módosítása azonban nem befolyásolja az online tesztfuttató folyamatát.

## Helyi tesztelés

Egy feladat tesztjeinek futtatásához nyiss egy terminált a feladat könyvtárában, és futtasd a `uiua test tests.ua` parancsot.

Egy szerkesztetlen `hello-world` feladat kimenete például így nézhet ki:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

Az `Error` sor a kódod tényleges kimenetét mutatja.
A sorszám a várt eredmény helyét jelöli a `tests.ua` fájlban.
Egy helyes megoldás eredménye:

```bash
$ uiua test tests.ua
Test passed
```
