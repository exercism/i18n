# Bevezetés

A `string` a C#-ban egy objektum, amely változhatatlan szöveget reprezentál Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként. A dupla idézőjeleket `string` példányok definiálására használjuk:

```csharp
string fruit = "Apple";
```

A stringeket a string metódusainak meghívásával manipuláljuk. Miután létrehoztunk egy stringet, az értéke soha nem változhat. Bármely metódus, amely úgy tűnik, hogy módosítja a stringet, valójában egy új stringet ad vissza.

Több stringet össze lehet fűzni (hozzáadni). A legegyszerűbb ezt a `+` operátorral elérni.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Az egyszerű összefűzésnél bonyolultabb stringformázáshoz a string-interpolációt érdemes használni. Ahhoz, hogy interpolációt használj egy stringben, írd elé a dollár (`$`) jelet. Ezután kapcsos zárójelekkel (`{}`) érheted el a stringen belüli változókat.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
