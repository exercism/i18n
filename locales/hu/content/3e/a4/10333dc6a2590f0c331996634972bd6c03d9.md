# Bemutatás

A protokollok:

- Egy mechanizmus a polimorfizmus elérésére.
- A `defprotocol` segítségével definiáljuk őket.
- Egy adott adattípushoz a `defimpl` segítségével implementáljuk őket.

A protokollok nagy előnye, hogy egy protokoll adott adattípusra vonatkozó implementációját nem kell sem az adattípus, sem a protokoll definíciójával együtt szállítani. Így olyan könyvtárakat írhatunk, amelyeket a felhasználók könnyedén kiterjeszthetnek a saját egyedi adattípusaikra anélkül, hogy módosítaniuk kellene a könyvtárat.

## Implementálás

A protokollokat az összes Elixir-típushoz implementálhatjuk: `Tuple`, `Atom`, `List`, `BitString`, `Integer`, `Float`, `Function`, `PID`, `Map`, `Port`, `Reference`, `Any` és structok.

Egy protokoll egyszerre több típushoz is implementálható:

```elixir
defimpl Reversible, for: [Map, List] do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

Ha egy struct protokollját közvetlenül a structot definiáló modulon belül implementáljuk, a `:for` argumentum elhagyható:

```elixir
defmodule ShoppingCart do
  defstruct [:items]

  defimpl Reversible do
    def reverse(shopping_cart) do
      Enum.reverse(shopping_cart)
    end
  end
end
```

## Visszaesés az `Any` típusra

Alapértelmezés szerint, ha egy protokollt olyan adattípusra hívunk meg, amelyhez nem implementáltuk, `Protocol.UndefinedError` hibát kapunk:

```elixir
to_string({})
# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for {} of type Tuple
#        (elixir 1.10.3) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.3) lib/string/chars.ex:22: String.Chars.to_string/1
```

Ezt elkerülhetjük egy tartalék implementációval, amely ilyen esetben lép életbe. Ehhez a protokoll definiálásakor állítsd a `@fallback_to_any` modulattribútumot `true`-ra, és írj implementációt az `Any` típushoz:

```elixir
defprotocol Reversible do
  @fallback_to_any true
  def reverse(term)
end

defimpl Reversible, for: Any do
  def reverse(term) do
    term
  end
end
```

Vedd figyelembe, hogy a legtöbb esetben jobb, ha hibát dobunk, mert nehéz észszerű feltevéssel élni egy protokollról _az összes_ adattípus esetében.

## Néhány figyelemre méltó beépített protokoll

- [`Enumerable`][enumerable] - az `Enum` és `Stream` modul függvényei olyan adattípusokkal működnek, amelyek implementálják ezt a protokollt.
- [`Collectable`][collectable] - az [`Enum.into/2`][enum-into] függvény ezt a protokollt használja, hogy egy enumerable-t beillesszen egy gyűjteménybe.
- [`Inspect`][inspect] - ezt a protokollt implementálva megváltoztathatod, hogyan jeleníti meg a [`Kernel.inspect/2`][kernel-inspect] egy adott adattípust stringként.
- [`String.Chars`][string-chars] - ezt a protokollt implementálva megváltoztathatod, hogyan jeleníti meg a [`Kernel.to_string/1`][kernel-to-string] egy adott adattípust stringként.
