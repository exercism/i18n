# Bevezetés

A **word** a Factorban a függvény elnevezése. A `basics`-ban megismert adatveremre építve ez a fogalom arról szól, hogyan definiálhatsz saját wordöket: számítások elvégzése, rögzített értékek elnevezése, és wordök összeállítása más wordökből.

Egy definíció `:`-tal kezdődik, majd a veremhatás következik, utána a törzs, végül a `;`. A fordító ellenőrzi, hogy a törzs illeszkedik-e a megadott veremhatáshoz:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

Az egész számokkal dolgozó aritmetikai wordök, a `+`, a `-` és a `*` mindegyike két számot vesz le a veremről, és az eredményt teszi rá. A `math` szótárban élnek, ezért annak a fájlnak, amely használja őket, fel kell tüntetnie a `math`-et a `USING:` sorában. A verem teteje a jobb oldali operandus:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

A `CONSTANT:` rögzített értéket nevez el. A konstans maga is egy word: ha meghívod, az értéket teszi a veremre:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

Egy word törzse meghívhat bármely wordöt, amely már szerepel a scope-ban, köztük azokat is, amelyeket korábban ugyanabban a fájlban definiáltál:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

A kimeneteken a záró `?` a „boolean” jelölésének konvenciója, a wordök és a konstansok pedig egyaránt a `lowercase-kebab-case` írásmódot használják.
