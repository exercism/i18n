# Utasítások kiegészítése

## Regiszterek

| Regiszter | Használat | Típus      | Leírás                                                                             |
| --------- | --------- | ---------- | ---------------------------------------------------------------------------------- |
| `$a0`     | bemenet   | egész szám | az a oldal                                                                         |
| `$a1`     | bemenet   | egész szám | a b oldal                                                                          |
| `$a2`     | bemenet   | egész szám | a c oldal                                                                          |
| `$v0`     | kimenet   | egész szám | a háromszög típusa (`0` = különböző oldalú, `1` = egyenlő szárú, `2` = egyenlő oldalú, `3` = érvénytelen) |
| `$t0-9`   | ideiglenes | bármilyen | ideiglenes tárolásra használatos                                                   |
