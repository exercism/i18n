# Utasítások

Elyse, a leendő varázsló, folytatja a képzését. Több pakli kártyát kap, amelyekkel végre kell hajtania a trükkjeit.
Hogy egy kicsit könnyebb legyen, csak az 1-től 10-ig terjedő kártyákat használja.

Ebben a feladatban beépített metódusokkal elemezd egy tömb tartalmát.

## 1. Keresd meg egy kártya pozícióját

Elyse tudni szeretné egy kártya pozícióját (indexét) a pakliban.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. Állapítsd meg, hogy egy kártya jelen van-e

Elyse szeretné megállapítani, hogy egy kártya jelen van-e a pakliban, más szóval, hogy a pakli tartalmaz-e egy adott `number`-t.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. Állapítsd meg, hogy minden kártya páros-e

Elyse tudni szeretné, hogy minden kártya páros-e, más szóval, hogy a pakli minden száma páros `number`-e.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. Ellenőrizd, hogy a pakli tartalmaz-e páratlan értékű kártyát

Elyse tudni szeretné, hogy van-e páratlan szám a pakliban.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. Keresd ki az első páratlan kártyát a pakliból

Elyse tudni szeretné, mennyi az első páratlan kártya értéke.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. Állapítsd meg az első páros kártya pozícióját

Elyse tudni szeretné az első páros kártya pozícióját.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
