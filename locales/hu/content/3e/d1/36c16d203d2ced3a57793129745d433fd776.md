# Utasítások

Ebben a feladatban egy szépségszalon időpont-ütemezőjén fogsz dolgozni.

Három részfeladat vár rád, és mindegyik az időpontok dátumával foglalkozik.

## 1. Ellenőrizd, hogy az időpont már elmúlt-e

Készítsd el az `appointment_has_passed` szubrutint, amely egy dátumszöveget kap, és ellenőrzi, hogy az időpont a múltban volt-e:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

A dátumokat ISO 8601 dátum-idő formátumban kapod meg: `YYYY-mm-ddTHH:MM:SS`

A privát `_parse_datetime` szubrutint is meg kell valósítanod.
Néhány modult is ajánlunk:

- A [Time::Piece][time-piece] a Perl beépített modulja.
- A [DateTime::Tiny][datetime-tiny] a CPAN-ból érhető el.

## 2. Ellenőrizd, hogy az időpont délutánra esik-e

Készítsd el az `is_afternoon_appointment` függvényt, amely egy dátumszöveget kap, és ellenőrzi, hogy az időpont délutánra esik-e (>= 12:00 és < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. Írd le az időpont idejét és dátumát

Készítsd el a `describe_appointment` függvényt, amely egy dátumszöveget kap, és visszaad egy leírást arról a dátumról és időpontról:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

Figyeld meg, hogy az óra a 0-12 tartományba esik, és nincs vezető nullája vagy szóköze.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
