# Bevezetés a tömbökbe

A Bash kétféle paramétertípust különböztet meg: a „skalár” értékeket és a tömböket.
Egy skalár érték lehet string vagy szám; egyetlen „dolgot” reprezentál.

Az esetek többségében a skalár értékek elégnek az adataid tárolásához.
Néha azonban skalár értékek listáját kell tárolnod.
Ilyenkor _tömböt_ használsz.

Kétféle tömb létezik:

* A numerikusan indexelt tömböknél egy egész szám kulcshoz egy string érték tartozik.
  (Más nyelvekben ezt „lista” vagy „sorozat” néven ismerheted.)
* Az asszociatív tömböknél egy string kulcshoz egy string érték tartozik.
  (Más nyelvekben ezt „map” vagy „szótár” néven ismerheted.)

A dokumentum első néhány szakasza a numerikusan indexelt tömbökkel foglalkozik (a továbbiakban egyszerűen csak „tömbök”).
Az asszociatív tömbök részletei a végén kerülnek elő.

~~~~exercism/caution
A Bash tömbjei _kizárólag_ skalár értékeket tárolhatnak.
Kétdimenziós tömböt (tömbök tömbjét) nem lehet létrehozni.
~~~~

## Tömbváltozó deklarálása és inicializálása

Egy tömböt úgy inicializálhatsz, hogy egy zárójelek közé írt elemekből álló listát (ami akár üres is lehet) rendelsz egy változóhoz.

```bash
myarray=("one" "two" "three")
```

Ahogy minden értékadásnál, itt sem lehet szóköz az egyenlőségjel körül.

Vedd észre, hogy az elemek között nincs vessző elválasztó; ez egy szóközökkel elválasztott stringekből álló lista.

Valójában a zárójeleken belüli szóközök mennyisége teljesen tetszőleges.
A sortörések is megengedettek; annyit használj belőlük, amennyi az olvashatóságot javítja.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

Ha így rendelsz stringek listáját egy tömbváltozóhoz, az első string a nulladik indexre kerül, a következő az elsőre, az azt követő a másodikra, és így tovább.

Lehetőség van „ritka tömb” inicializálására is, ha megadod a szükséges indexeket.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
Még egyszer: a tömbindexek nullától indulnak.
Ez a kódrészlet „true” értéket ír ki:

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

A `declare` paranccsal (vagy függvényen belül a `local` paranccsal) megadhatod, hogy egy változó tömböt fog tárolni.

```bash
declare -a myarray
```

Idiomatikusabb egyszerűen egy (esetleg üres) zárójelek közé írt listát rendelni a változóhoz, ezzel inicializálva azt.

## Egy tömb elemeinek elérése

Ahogy a fenti megjegyzésben láttad, egy tömbelem elérésének szintaxisa `${myarray[$index]}`.
Az indexet szögletes zárójelben adod meg.
A kapcsos zárójelek kötelezők.

~~~~exercism/note
A numerikusan indexelt tömböknél az index egy aritmetikai kifejezés.
A Bash kézikönyve [azt írja][arithmetic]:

> Egy aritmetikai kifejezésen belül a shell-változókra névvel is hivatkozhatsz, a paraméter-kiterjesztés szintaxisának használata nélkül.

Ez azt jelenti, hogy „egyszerű” változó-kiterjesztésnél nincs szükség a `$` jelre.
Így is elérheted az elemeket, ami kicsit olvashatóbb:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

Ha a megadott index nem létezik a tömbben, a kiterjesztés eredménye egy üres string.

## Értékadás egy tömbnek

Ha egy adott tömbelemnek akarsz értéket adni, ezt a szintaxist használd:

```bash
myarray[10]="hello"
```

Ha _hozzá akarsz fűzni_ a tömbhöz, használd a `+=` összefűző értékadás operátort, és a zárójeleket:

```bash
myarray+=("new element 1" "new element 2")
```

## Iterálás egy tömbön

Általában egy tömb _értékei_ fölött kell iterálnod.
Használj for ciklust (amit a [Ciklus][looping] fogalomnál láttál):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

Figyeld meg a tömb kiterjesztéséhez használt speciális szintaxist: `"${myarray[@]}"`
A paraméter-kiterjesztés ezen formája külön szavakként helyettesíti be a tömb értékeit.
Ez nagyjából ezzel egyenértékű:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

A `"${myarray[@]}"` forma ritka tömbökkel is működik, és csak a definiált értékekre terjed ki.

Ez a speciális kiterjesztés, ahol az index egy és-jel (`@`), csak kettős idézőjeleken belül speciális.

#### További speciális paraméter-kiterjesztések

Íme még néhány speciális szintaxis-elem, amire a tömbön való iteráláshoz szükségünk van.
Ezeket a kézikönyv a [Shell-paraméter-kiterjesztés][man-expn] fejezetben írja le.

Egy tömb _hosszának_ meghatározásához használd a `${#myarray[@]}` kifejezést, a név előtt egy `#` jellel.
Egy tömb „hossza” a benne lévő elemek számát jelenti.

Egy tömb _indexeinek_ listájához használd a `"${!myarray[@]}"` kifejezést, a név előtt egy `!` jellel, a kiterjesztést pedig kettős idézőjelek között.
Numerikusan indexelt tömböknél az indexek numerikus sorrendben bővülnek.

### Iterálás a tömb indexein

Néha az érték mellett az indexre is szükséged van.
Erre néhány lehetőség kínálkozik.

1. Ha tudod, hogy az indexek megszakítás nélküli sorozatot alkotnak, használhatsz _aritmetikai_ for ciklust.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   Figyeld meg a `${#myarray[@]}` szintaxist: a `#` karakter a tömb neve előtt áll.
   Mivel a tömbök nullától indexelnek, a tömb utolsó indexe eggyel kisebb a tömb hosszánál.

2. Ha a tömb ritka, ezt a formát használhatod:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   Figyeld meg a `${!myarray[@]}` szintaxist: a `!` karakter a tömb neve előtt áll.

## Egy tömb megvizsgálása

Ha meg akarod nézni egy tömb tartalmát, használd a `declare` parancsot a `-p` kapcsolóval:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

Ez kanonikus shell-idézőjelekkel írja ki a tartalmat.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## Asszociatív tömbök

Még egyszer: az asszociatív tömbök indexként stringeket használnak, nem számokat.
Minden, ami fentebb szerepelt, az asszociatív tömbökre is érvényes, kisebb eltérésekkel.
Általában „kulcsról” beszélünk, nem „indexről”: az asszociatív tömbök kulcsokat rendelnek értékekhez.

### Asszociatív tömb deklarálása

A tömbökkel ellentétben az asszociatív tömböket **deklarálni kell**.
A `declare` (vagy függvényen belül a `local`) `-A` kapcsolóját használd:

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### Asszociatív tömb inicializálása

A kulcs-érték párokat a zárójelek közötti listában adod meg:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

Ennek a kimenete:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
Ne feledd, hogy az asszociatív tömbök **nem rendezettek**.
~~~~

A deklaráció és az inicializálás történhet egy sorban.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

Az újabb Bash-verziókban az inicializáláshoz használhatsz `(key value key value ...)` listát is.

```bash
declare -A mymap=(first foo second bar third baz)
```

### Értékek elérése

Az elemek eléréséhez ugyanazt a szintaxist használod, mint korábban: `${mymap[$key]}`.

Az asszociatív tömbök kulcsait nem aritmetikai környezetben értékeli ki a rendszer.
A szokásos paraméter-kiterjesztés szintaxist kell használni.

### Értékadás egy asszociatív tömbnek

Az értékadás ugyanazt a szintaxist használja, mint korábban:

```bash
mymap[$key]="$value"
```

### Iterálás

Egy `for value in "${mymap[@]}"` ciklussal tudsz iterálni.
Általában azonban az érték mellé a kulcsot is szeretnéd látni.

Használd a fentebb látott `"${!mymap[@]}"` szintaxist.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

Ennek a kimenete

```
second -> bar
first -> foo
third -> baz
```

Hangsúlyozzuk még egyszer: a kulcsoknak nincs sorrendjük.
