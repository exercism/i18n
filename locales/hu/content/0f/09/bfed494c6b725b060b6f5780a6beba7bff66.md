# Bevezetés a csővezetékekbe és a parancslistákba

Láttuk, hogyan írjunk egyszerű parancsokat, ahol a parancsot argumentumok követik.
Most pedig megnézzük, hogyan hozhatunk létre összetettebb parancsokat egyszerű parancsok összefűzésével.

## Bemenet és kimenet

Mielőtt belevágunk, ismerkedjünk meg röviden a bemenettel és a kimenettel.

A folyamatoknak szabványos bemeneti és kimeneti csatornái vannak.

* Egy folyamat _bemenetet_ tud fogadni a stdin csatornán.
* Egy folyamat _kimenetet_ tud kibocsátani a stdout csatornán.
* Egy folyamat _hibakimenetet_ tud kibocsátani a stderr csatornán.

A `tr` parancs erre nagyon tiszta példa.
Ez mindössze annyit tesz, hogy szöveget olvas a bemenetéről, karaktereket ír át, majd az így kapott szöveget a kimenetére írja.

A stdio csatornák kezeléséről később, a tanterv más részein lesz szó.

## Csővezetékek

Ez a shellprogramozás egyik legnagyobb dobása.
A csővezetékekkel kifinomult átalakításokat végezhetsz egy szövegfolyamon.

Ha a felhasználók rendezett listáját szeretnéd megkapni:

```bash
cat /etc/passwd | cut -d : -f 1 | sort
```

A cső jele (`|`) az egyik parancs kimenetét a másik bemenetéhez kapcsolja.
A `cut` a `cat` kimenetét olvassa, a `sort` pedig a `cut` kimenetét.

~~~~exercism/advanced
* Alapértelmezés szerint a csővezeték minden parancsa külön subshellben fut.
  (A subshell egy gyermekfolyamat, ami a futó shell másolata.)

* A csővezetékek futtatásának teljesítményköltsége van.
  Ha hosszú csővezetékeid vannak hasonló parancsokból, érdemes lehet őket egyetlen parancsba összevonni.
  Például a több `grep`, `cut`, `sed`, `awk` és `tr` példányt használó csővezetékek általában összevonhatók egyetlen `awk` paranccsá a hatékonyság érdekében.

* A csővezeték kilépési állapota a benne szereplő utolsó parancs kilépési állapota.
  Ez azt jelenti, hogy ha egy korábbi parancs hibával tért vissza, de az utolsó sikeres volt, akkor a teljes csővezeték kilépési állapota nulla.

  Ezt egy shell-beállítással meg lehet változtatni;
  ha a „pipefail” beállítás be van kapcsolva (a `set -o pipefail` paranccsal), akkor a csővezeték kilépési állapota a következő lesz:
  * nulla, ha minden parancs sikeres, egyébként
  * a csővezetékben szereplő parancsok _**utolsó** nem nulla kilépési állapota_.
~~~~

## Parancslisták

A parancslista csővezetékek sorozata, amelyeket `;` (vagy újsor), `&&` vagy `||` választ el egymástól.

* `A; B` egy parancslista, ahol `B` az `A` befejeződése után fut le.
* `A && B`, ahol `B` csak akkor fut le, ha `A` sikeres (nulla állapottal lép ki).
* `A || B`, ahol `B` csak akkor fut le, ha `A` sikertelen (nem nulla állapottal lép ki).

A parancslista kilépési állapota az utolsó lefutott parancs kilépési állapota.

A `&&` és `||` operátorok láncolhatók, így a következő parancs az előző parancsok állapota alapján feltételesen fut le.
Például

```bash
A && B && C && D || E
```

* `B` akkor fut le, ha `A` sikeres,
* `C` akkor fut le, ha `A` és `B` sikeres,
* `D` akkor fut le, ha `A`, `B` és `C` sikeres,
* `E` akkor fut le, ha `A`, `B`, `C` vagy `D` közül **bármelyik** sikertelen.

~~~~exercism/caution
Ezeket a logikai operátorokat mértékkel használd.
Gyorsan olvashatatlan kódhoz vagy nehezen átlátható logikához vezethetnek.

Például azt hiheted, hogy ezek ugyanazt teszik:

```bash
if A; then B; else C; fi
```

```bash
A && B || C
```

A különbség: mikor fut le a `C`?

* Az első részletben (az elágazásban) a `C` csak akkor fut le, ha `A` sikertelen.
* A második részletben a `C` akkor is lefut, ha `A` sikertelen, _vagy ha `A` sikeres, de `B` sikertelen_!
~~~~

### A parancslisták felhasználása

Íme néhány példa, ahol a parancslisták egyszerűbbé tehetik a kódot.

#### Sorblokkok beolvasása egy fájlból

Tegyük fel, hogy van egy háromszögekre vonatkozó adatokat tartalmazó adatfájlod, és egy háromszöget három külön sor jelöl, amelyek a háromszög oldalait tartalmazzák.

```bash
$ cat triangle.dat
3
4
5
9
12
14
```

Használhatsz egy `while` ciklust, amelynek feltétele három külön `read` parancs:

```bash
while read a && read b && read c; do
    if is_pythagorean "$a" "$b" "$c"; then
        echo "$a:$b:$c is pythagorean"
    else
        echo "$a:$b:$c is not pythagorean"
    fi
done < triangle.dat
```

Feltéve, hogy az `is_pythagorean` egy olyan parancs, amely megállapítja, hogy a három oldal kielégíti-e a Pitagorasz-egyenletet, a kimenet ez lenne:

```none
3:4:5 is pythagorean
9:12:14 is not pythagorean
```

#### Állítások

Sok programozási nyelvben létezik az állítás egy formája, ahol kivétel dobódik, ha valamilyen feltétel nem teljesül

```
assert(user == "Administrator", "wrong user");
```

Ezt a funkcionalitást utánozhatjuk egy OR operátorral a Bashben:

```bash
die () { # a little convenience function
    echo "$*" >&2
    exit 1
}

[[ $user == "Administrator" ]] || die "wrong user"
[[ $password == "secret!" ]]   || die "incorrect password"
```

## Stílusbeli szempontok

A hosszú parancslisták meglehetősen gyorsan olvashatatlanná válnak.
Az újsorok bőséges használata sokat segíthet.

Vegyük ezt a példát, ahol egy szót adunk egy tömbhöz, ha két feltétel teljesül.

```bash
[[ "$word" != "$topic" ]] && [[ "$key" == "$(sorted "$topic")" ]] && anagrams+=("$candidate")
```

A Bash lehetővé teszi, hogy újsort szúrj be egy cső vagy egy logikai operátor után.

```bash
[[ "$word" != "$topic" ]] &&
[[ "$key" == "$(sorted "$topic")" ]] &&
anagrams+=("$candidate")
```

Az operátor azonban könnyen elkerülheti a figyelmet a sor végén.
Egy _sorfolyatás_ segítségével az operátort a sor elejére teheted, ami nyilvánvalóbbá teszi, hogy a lista folytatódik:

```bash
[[ "$word" != "$topic" ]] \
&& [[ "$key" == "$(sorted "$topic")" ]] \
&& anagrams+=("$candidate")
```

~~~~exercism/note
A _sorfolyatás_ a „visszaperjel” és az „újsor” kétkarakteres sorozata (`\` + `\n`).
Amikor a Bash meglátja ezt a sorozatot, egyszerűen eltávolítja a kódból, és ezáltal _folytatja_ az aktuális sort a következő sorral.
Ügyelj rá, hogy ne kerüljön szóköz a visszaperjel és az újsor közé.
~~~~

Íme egy másik példa

```bash
printf "%s\n" "${numbers[@]}" | bc --mathlib | sort --general-numeric-sort
```

vagy 

```bash
printf "%s\n" "${numbers[@]}" \
| bc --mathlib \
| sort --general-numeric-sort
```
