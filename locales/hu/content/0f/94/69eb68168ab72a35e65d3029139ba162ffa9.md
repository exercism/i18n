# Bevezetés

A függvény jól szervezett, újrahasznosítható kódból álló blokk, amely valamilyen művelet végrehajtására szolgál.
A JavaScriptben többféleképpen is definiálhatsz függvényeket.
Most a _függvénydeklarációkat_ és a _függvénykifejezéseket_ nézzük meg.
Az olyan további lehetőségekkel, mint a [nyílfüggvények][concept-arrow-functions], más fogalmaknál foglalkozunk majd.

## Függvénydeklaráció

A JavaScriptben a függvények szabványos definiálási módja a _függvénydeklaráció_, amelyet _függvénydefiníciónak_ vagy _függvényutasításnak_ is neveznek.

A `function` kulcsszóból, a függvény nevéből, valamint a kerek zárójelben (`()`) szereplő, vesszővel elválasztott paraméterlistából áll.
Ezt követi a kapcsos zárójelbe (`{}`) foglalt függvénytörzs (az utasítások gyűjteménye, amely meghatározza, mit tesz a függvény).

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

A JavaScriptben egy függvényt úgy hívunk meg, hogy leírjuk a függvény nevét, majd zárójelben megadjuk az argumentumokat.

```javascript
someName(arg1, arg2, arg3);
```

## Paraméterek

Amikor a függvénytörzsön belül paraméterekkel dolgozol, figyelj a lehetséges mellékhatásokra.

- A [primitív adattípusok][mdn-primitives] értékei _megváltoztathatatlanok_.
  Az eredeti értéket soha nem befolyásolja, hogy mi történik az argumentummal a függvénytörzsben.
- Minden más érték (objektumok, tömbök, függvények) esetében az újraértékadás nem érinti az eredeti értéket.
  Ha azonban módosítasz egy ilyen argumentumot (például hozzáadsz egy kulcsot egy objektumhoz), az az átadott eredeti értéket is módosítja.

A JavaScriptben alapértelmezés szerint a függvénydeklarációban megadott összes paraméter elhagyható.
Ha kevesebb argumentumot adsz meg, mint amennyi paraméter van, a hiányzó argumentumok értéke `undefined` lesz a függvényen belül; erről lásd a [Null és undefined][concept-null-undefined] című részt.
Sok esetben érdemes a `undefined` helyett egy megfelelőbb alapértelmezett értéket adni.
Ezt úgy teheted meg, hogy közvetlenül a függvénydefinícióban adsz meg alapértelmezett paramétereket.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## A `return` utasítás

A `return` utasítás befejezi a függvény végrehajtását, és megadja a függvény hívójának visszaadandó értéket. Egy függvényben több `return` utasítás is lehet.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

A függvény visszatérési értékét eltárolhatod egy változóban.

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

Ha egy függvény nem ad vissza értéket, vagy nincs benne `return` utasítás, az eredménye `undefined` lesz.
A JavaScriptben nincsenek implicit `return` utasítások.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

A JavaScriptben pontosan egy értéket adhatsz vissza.
Ha több információt szeretnél átadni, először egyetlen egységbe kell foglalnod, általában egy [objektumba][concept-objects] vagy egy [tömbbe][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Függvénykifejezés

A függvénydeklaráció önálló utasítás.
Néha azonban hasznos, ha egy függvényt egy másik kifejezés részeként definiálsz, például egy értékadásban, függvényparaméterként ([callback][concept-callbacks]) vagy egy [objektum][concept-objects] értékeként.
Erre a függvénykifejezés szolgál.
A szintaxisa ugyanaz, mint a függvénydeklarációé, csak a függvénynév elhagyható, így _névtelen függvényt_ hozhatsz létre.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
