# Telepítés

## Milyen awk van a gépeden?

Az Exercism AWK kurzusa a `gawk`-ot használja, a GNU AWK-ját.
Lehet, hogy már telepítve van; az ellenőrzéshez futtasd ezt a parancsot:
```sh
awk --version
```

Ha ez a következőt adja vissza:

* valami ilyesmit: `GNU Awk 5.1.0 ...`
    - Már van GNU awk a gépeden, folytathatod a feladatokkal.

* valami ilyesmit: `awk version 20200816`
    - Ez a `nawk`, más néven BWK awk (Brian Kernighan után) vagy „one true awk”.
    - Ezt szállítja alapból a MacOS és a BSD-rendszerek.
    - A telepítési útmutatót lásd lentebb.

* a következő hiba: `awk: not an option: --version`
    - Valószínűleg `mawk`-od van.
    - Ellenőrizd ezzel: `awk -W version`, ami ezt adhatja vissza: `mawk 1.3.4 20200120`.
    - A mawk egy nagyon jó és gyors awk-implementáció, de nincs benne néhány olyan gawk-specifikus funkció, amit a kurzuson használni fogunk.
    - A telepítési útmutatót lásd lentebb.

* a következő hiba: `awk: unrecognized option: version`, amit a `BusyBox v1.35.0 ...` követ
    - Lehet, hogy Alpine Linuxot használsz.
    - A telepítési útmutatót lásd lentebb.

* egy „command not found” hiba
    - Ekkor vagy a PATH-od hibás, vagy egyszerűen nincs telepítve az awk.
    - A telepítési útmutatót lásd lentebb.

### Linux

A disztribúciód csomagkezelőjétől függ. Általában:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
Előfordulhat, hogy `sudo`-t kell használnod a megfelelő parancs futtatásához.

### MacOS

A [Homebrew][brew] lesz a barátod. Kövesd a linket a telepítéséhez, majd futtasd:
```sh
brew install gawk
```

### Windows

[WSL][wsl] esetén lásd a fenti Linuxos útmutatót.
cygwin esetén telepítsd a `gawk` csomagot.

### Fordítás forráskódból

A bátraknak: az útmutató [elérhető a `gawk` kézikönyvében][build].
