# Névjegy

A kivételek a hibakezelés egyik formája.
Azért hívják őket kivételnek, mert általában valamilyen váratlan esemény kapcsán jelennek meg.

A kódunk bármely pontján kivételt dobhatunk.
Ezt a `raise` metódussal tesszük: átadunk neki egy objektumot, általában egy Exception objektumot, de egyszerű stringeket is megadhatunk.
Például a feladatok vázában láthatod, hogy a beépített `RuntimeError`-ral jelezzük a Ruby-nak, hogy egy metódus még nincs megvalósítva.
Használhatod a `raise(ExceptionObject, params)` rövidített szintaxisát is.
Ha elhagyod a kivételosztályt, a Ruby alapértelmezés szerint a `RuntimeError`-t használja.

Például:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Amikor a Ruby ezt látja, a hibát a program tetejéig juttatja, majd a program kilép.

Például ha megpróbálsz elosztani valamit nullával, valami ilyesmit fogsz látni:

```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```

Fontos megjegyezni, hogy a kivételeket olyan esetekben érdemes használni, amikor valami rendkívüli történik, egy hiba, amely különleges kezelést igényel.
A kivételeket nem a program vezérlésére kell használni, mert az rossz tervezésnek számít, ami gyakran rossz teljesítményhez és karbantarthatósághoz vezet.

## Osztályhierarchia

A Ruby-ban a kivételek egy osztályhierarchiát követnek, amelyben az `Exception` az alaposztály.
Ezek a Ruby leggyakoribb beépített kivételei:

```
Exception
  NoMemoryError
  ScriptError
    LoadError
    NotImplementedError
    SyntaxError
  SignalException
    Interrupt
  StandardError
    ArgumentError
    IOError
    EOFError
    IndexError
    LocalJumpError
    NameError
      NoMethodError
    RangeError
      FloatDomainError
    RegexpError
    RuntimeError
    SecurityError
    SystemCallError
    SystemStackError
    ThreadError
    TypeError
    ZeroDivisionError
  SystemExit
```

Ha egy adott osztály hibáit elkapod, azzal a leszármazott osztályok hibáit is elkapod.
Ezért veszélyes lehet, ha az `Exception`-ből kapjuk el a kivételeket.
A Ruby a kivételeket arra is használja, hogy kezelje az operációs rendszer „jelzéseit”, például a `ctrl-c`-t.
Ez azt jelenti, hogy ha az `Exception`-ből kapjuk el a kivételeket, azok ezeket a rendszerjelzéseket is elkapják.
Ezért a váratlan viselkedés elkerülése érdekében az „összes hiba” elkapásának bevett módja, hogy a `StandardError`-ból kapjuk el őket.

## A rescue szintaxisa
A Ruby emellett kibővített rescue szerkezeteket is kínál azokra az esetekre, amelyek különleges kezelést igényelnek:

```ruby
begin
  # ...
rescue CustomError => error
  # This block is run if a CustomError occurs
rescue AnotherCustomError => error
  # This block is run if a AnotherCustomError occurs
else
  # This block is run if no exception occurred at all
ensure
  # This block always run, regardless of whether an exception occurred
end
```

Ez például hálózati IO esetén lehet hasznos, ahol mindig emlékeznünk kell a kapcsolat lezárására.

A Ruby rescue blokkjai használhatják a `retry` kulcsszót is, amely újrafuttat mindent a begin és a rescue között:

```ruby
counter = 0
begin
  counter += 1
  api_request
rescue
  retry if counter <= 3
end
```
