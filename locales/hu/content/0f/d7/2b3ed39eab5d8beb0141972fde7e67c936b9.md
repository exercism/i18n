A `+` operátorral végzett string-összefűzés járható megközelítés, de karbantartási és olvashatósági problémákat okozhat.
A [str.format()][str.format()] metódus vagy az [f-strings][f-strings] (_más néven „formatted string literals” vagy „interpolated strings”_) használata olyan lehetőségeket kínál, amelyek javítják a karbantarthatóságot, és világosabbá teszik a stringeken belüli változóbehelyettesítést.

A [String Formatting in Python][string formatting in python] blogbejegyzés jó kiindulópont ahhoz, hogy megértsd a Python összes stringformázási lehetőségét, a [Newer Python String Format Techniques][newer python string format techniques] pedig hasznos tippeket és trükköket kínál a `str.format()` és az `f-strings` használatához.
