# Utasítások kiegészítése

## Bemeneti formátum

A `board` paraméter, amely a játéktáblát képviseli, stringek tömbjének formátumában van.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

A string minden karaktere egy cellát jelöl.
A cella érvényes értékei:

- ` ` egy szóköz, amely egy üres cellának felel meg
- `B` a fekete játékos tulajdonában lévő cella
- `W` a fehér játékos tulajdonában lévő cella

## Kimeneti formátumok

A `getTerritory` függvénynek egy 2 tulajdonsággal rendelkező objektumot kell visszaadnia:

- `owner` A terület tulajdonosa (`NONE`, `BLACK` vagy `WHITE`)
- `territory` Egy koordinátákból álló tömb, amely a terület minden celláját képviseli.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

A `getTerritories` függvénynek egy 3 tulajdonsággal rendelkező objektumot kell visszaadnia:

- `territoryBlack` Egy koordinátákból álló tömb, amely a `BLACK` játékos tulajdonában lévő területeket képviseli
- `territoryWhite` Egy koordinátákból álló tömb, amely a `WHITE` játékos tulajdonában lévő területeket képviseli
- `territoryNone` Egy koordinátákból álló tömb, amely egyik játékos tulajdonában sem lévő területeket képviseli

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
