# Bevezetés

Emlékezz vissza, hogy a `jq` program egy _kifejezésekből álló csővezeték_.
**A változó-hozzárendelés** a következő szabályt követi: a _változó-hozzárendelés_ egy kifejezés, amely így néz ki:

```jq
... | expr as $varname | ...
```

## A szűrő a bemenetet adja ki

Akárcsak az _identitáskifejezés_ `.` esetében, a _változó-hozzárendelés_ kimenete is ugyanaz, mint a bemenete.
A változó értékének beállítása mellékhatás.

Példa, amely megmutatja, hogy a hozzárendelés utáni `.` ugyanaz, mint a kezdeti bemenet:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## A változó scope-ja

A változó scope-ja „lexikai”, azaz a változó a csővezeték hátralévő részében is benne marad a scope-ban.
A függvényekben definiált változók (a függvényekre később térünk rá) az adott függvényen belül „lokálisak”.

## A változók nevei

A változónak `$` jellel kell kezdődnie.
A változónév többi része egy **azonosító**: betűvel vagy aláhúzással kezdődik, amelyet betűk, számok vagy aláhúzások követnek.

## Destrukturáló hozzárendelés

A kézikönyvből:

> Több változó is deklarálható egyetlen `as` kifejezéssel, ha olyan mintát adunk meg, amely _illeszkedik a bemenet szerkezetéhez_ (ezt nevezik „destrukturálásnak”).

Példák:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Rövidebb megoldást kínál, ha a változó nevét az _objektumkulcshoz_ igazítjuk:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Konstansok

Ahogy a fenti példa mutatja, a változók kényelmesen használhatók konstansok tárolására.
Jobb nevet adni a konstansoknak, mint hagyni, hogy „mágikus számok” bukkanjanak fel a kódban.

## Gyakran nincs szükség változókra

Gyakran olvashatóbb, ha elhagyjuk a változókat.

Vegyük például egy számlista átlagának kiszámítását:

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

összevetve ezzel:

```jq
[2, 4, 8, 7] | add / length
```

Ez rávilágít a `jq` egyik legerősebb tulajdonságára: a szűrő bemenete _minden_ részkifejezés számára elérhető:

- a `[2,4,8,7]` bemeneti tömböt megkapja az `add` (amely úgy összegzi a számokat, hogy a `+` operátort alkalmazza az összes elemre)
- _ezzel párhuzamosan_ a `[2,4,8,7]` a `length` bemenete is lesz
- amikor ezek a részkifejezések befejeződnek, az eredményeiket elosztjuk egymással, és megkapjuk a bemeneti tömb számainak átlagát.
