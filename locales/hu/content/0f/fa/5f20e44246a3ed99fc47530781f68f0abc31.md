# Bevezetés

Az `if/elif/else` kifejezéssel feltételesen hajthatsz végre logikát. Az F#-nak azonban van egy másik, ennél is erősebb módja ugyanerre: a mintaillesztés. A mintaillesztés során egy értéket egy vagy több _minta_ ellen vizsgálhatsz meg. Ilyen minta például a _konstans minta_, amellyel egy értéket egy konstanshoz hasonlítasz (például `1` vagy `"hello"`).

Az F#-ban a mintaillesztés a `match` kulcsszóval történik:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Bár ez más nyelvek `switch` utasításaira hasonlít, a mintaillesztés akkor mutatja meg igazi erejét, amikor más mintákat is bevetesz. Egy ilyen minta a _változóminta_, amellyel egy értéket elkaphatsz:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

Előfordulhat, hogy további feltételt szeretnél fűzni egy mintához. Ez az úgynevezett _őr_ (feltétel), amelyet a `when` kulcsszóval adhatsz meg:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

A fenti példában nem minden lehetséges bemenethez tartozik illeszkedő minta. A fordító ezt észleli, és figyelmeztetést ír ki. Ezt nevezik _kimerítő ellenőrzésnek_. A figyelmeztetés megszüntetéséhez minden esetet kezelned kell. Erre a _wildcard minta_ szolgál, amely bármilyen értékre illeszkedik:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

A mintaillesztés fentről lefelé haladva vizsgálja meg az értéket az egyes mintákkal szemben, amíg nem talál egy illeszkedő mintát, és végre nem hajtja a hozzá tartozó logikát. A minták sorrendje számít!
