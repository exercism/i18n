# Bevezetés

## Structok

A structok a [map-ekre][exercism-maps] épülő kiterjesztések, amelyek fordítási idejű ellenőrzéseket és alapértelmezett értékeket biztosítanak. A struct arról a modulról kapja a nevét, amelyben definiálva van. Struct definiálásához használd a `defstruct` konstrukciót. A konstrukció általában közvetlenül a moduldefiníció után következik. A `defstruct` elfogad vagy atomok listáját (a `nil` alapértelmezett értékekhez) vagy kulcsszólistát (a megadott alapértelmezett értékekhez). Az alapértelmezett érték nélküli mezőknek meg kell előzniük az alapértelmezett értékkel rendelkezőket.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### Mezők elérése és frissítése

Mivel a structok map-ekre épülnek, a legtöbb map-függvényt használhatjuk értékek lekérésére és módosítására. A structoknál az _Access Behaviour_ **nincs** implementálva. A structmezők eléréséhez helyette a _statikus elérési operátor_ `.` használata javasolt.

- mezőértékek lekérése:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- mezőértékek frissítése

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### Mintailesztés

A structok használhatók mintailesztésben a struct nevével vagy anélkül is.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Ha a mintába belefoglalod a struct nevét, biztosíthatod, hogy a bal és a jobb oldal is ugyanolyan típusú struct legyen.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### A mezőértékek kezdőértékének kikényszerítése

A `@enforce_keys` modulattribútumot használhatjuk a mezőkulcsok listájával annak biztosítására, hogy az értékek inicializálva legyenek a struct létrehozásakor. Ha egy kulcs nincs a listában, az értéke `nil` lesz, mint a fenti példában. Ha egy kikényszerített kulcs nincs inicializálva, hiba keletkezik.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
