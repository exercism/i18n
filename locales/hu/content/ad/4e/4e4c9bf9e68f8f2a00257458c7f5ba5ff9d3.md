# Bevezetés

## Felsorolások

Eddig többnyire számokkal és stringekkel foglalkoztunk.
Ahhoz, hogy a való világot modellezzük, előfordulhat, hogy egy változó csak korlátozott számú értéket vehet fel.
Előfordulhat, hogy egy külön típusra vágysz, amelynek néhány megkülönböztethető értéke van, és mindegyiknek külön neve.
Például egy gördeszkagyárban a deszka anyaga csak juhar, bambusz vagy műanyag lehet.

Kódolhatnád ezeket az értékeket egész számokkal is, de extra kódot kellene írnod annak ellenőrzésére, hogy nem érkezik-e érvénytelen érték a rendszertől az anyagra.
Ezeknek a [_mágikus számoknak_][magic numbers] a jelentését nehéz nyomon követni a forráskódban, és könnyen össze is keverednek.
Az `enumerations` segítségével kifejezőbb kódot írhatsz, és visszaszoríthatod a véletlen összehasonlítási hibákat.

## Példahasználat

Az ilyen típusú felsorolás pontos megnevezése a `scoped enumeration`.
Az alábbi részlet megmutatja, hogyan írjunk egy `DeckMaterial` `enumeration`-t.
Figyeld meg az `enum class` kulcsszót és a definíció végén lévő `;`-t:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```
Most nézzük meg a gördeszkabolt árazó függvényét, és figyeld meg a hatókörfeloldó operátort (`::`), amellyel megadhatod, hogy az `enumeration` melyik `enumerator`-áról van szó:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## Scoping

Képzeld el, hogy van egy második `enumeration`-öd a kerék anyagához:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```
Bár a kerekek és a deszka is készülhet _műanyagból_, a kettőt mégsem lehet összekeverni.
Két különböző _típusról_ van szó: a `DeckMaterial` műanyagjáról és a `WheelMaterial` műanyagjáról.
Minden `enumeration` a saját scope-jában tartja az `enumerator`-ait - a saját `namespace`-ében.
Ezért hívják őket `scoped enumerations`-nek.

## Scope nélküli felsorolások

Talán arra gondolsz, hogy ha van `scoped`, akkor `unscoped` felsorolások is léteznek, és igazad van.
Az `Unscoped enumerations` egyre kevésbé népszerűek, mert mind ugyanazon a globális namespace-en osztoznak.
Az osztozás miatt nem lehetett volna két `unscoped enumerations`, amelyeknek ugyanazok az `enumerators`-ai, mint a fenti példában a _műanyag_.

Ráadásul az `unscoped enumerations` implicit módon egész számokká alakulnak.
Az alábbi példa meglepő eredményt mutat:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

Ha a `scoped enumerations`-t egész számokká szeretnéd alakítani, használhatod a `static_cast<int>`-et.
