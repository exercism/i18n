# Bevezetés

## Egyedi típusok

A Gleamben az egyedi típusokkal lehet új adattípusokat definiálni. Több _változatuk_ is lehet, mindegyiknek saját neve van.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Egy egyedi típus minden változata opcionálisan tartalmazhat adatot, és a különböző változatok különböző típusú adatokat tárolhatnak. Ha egy változat tartalmaz adatot, azt _rekordnak_ nevezzük.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Egy adott változat értékét úgy hozhatjuk létre, hogy a nevére hivatkozunk, ha nem tartalmaz további adatot (`Spring`), vagy függvényként hívjuk meg, ha tartalmaz (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

Az egyedi típusok, akárcsak a Gleam minden eleme, _strukturális egyenlőséggel_ rendelkeznek, ami azt jelenti, hogy két azonos változatú és azonos adattartalmú érték egyenértékű.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Az egyedi típusok változataira case kifejezésekkel lehet mintailleszteni.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
