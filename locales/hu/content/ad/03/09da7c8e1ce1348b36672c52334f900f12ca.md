# Utasítások

Lilly szeret főzni.
Pizzabulit szeretne rendezni a barátaival.
Hogy a lehető legtöbbet hozza ki a hozzávalókból, tudnia kell, mennyi kell mindegyikből, mielőtt elkezdi.

Hogy megoldja, Lilly megírt egy programot a tervezés automatizálására, de a befejezéséhez a segítségedet kéri.
Segítesz Lillynek megrendezni az arányosan tökéletes pizzabulit?

## 1. A tészta aránya

Lilly a vékony, ropogós pizzák kedvelője, vékonyabb tésztával.
A közepéhez legalább 200 g tészta kell, de minden további személy, akit kiszolgál, újabb 20 g tésztát igényel.

`grams = pizzas * ((persons * 20) + 200)`

Lillynek egy függvényre van szüksége, amely:

- megkapja a pizzák számát,
- megkapja azon személyek számát, akiket egy pizza kiszolgál,
- és a szükséges tésztát grammra kerekítve adja vissza.

Például 4 pizza elkészítéséhez, amely 8 embert lát el:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. Egy csepp szósz

Lilly aprólékos a szósz felkenésénél, de a pizzái mérete nem mindig egyforma.
Tapasztalatából tudja, hogy pizzánként 125 mL szószra van szükség.
Lillynek egy függvényre van szüksége, amely kiszámítja, hány doboz szószt kell venni.

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

Például, ha Lillynek 8 pizzát kell készítenie, és egy doboz 250 mL:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. Egy kis sajtot, kérem

A sajt tökéletes kockákban kapható, és méret szerint árulják.

A képlet, amit Lilly használ, nem a pizza területének képlete, mivel _nem_ szeretné, hogy a sajt a teljes felületet beborítsa.
Úgy döntött, hogy a következő képlettel határozza meg, hány adott átmérőjű (`diameter`) pizza készíthető egy adott oldalhosszúságú (`cheese_dimension`) sajtkockából:

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

Készíts egy függvényt, amely:

- megkapja egy sajtkocka oldalhosszát,
- megkapja a sajtréteg kívánt vastagságát,
- megkapja a pizza átmérőjét,
- és Lilly képletével visszaadja az elkészíthető pizzák számát lefelé kerekítve.

Például egy 25x25x25 cm-es sajtkocka, 0,5 cm vastag sajtréteg és 30 cm átmérőjű pizzák esetén:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. Igazságos elosztás

Végül Lilly szeretné, ha minden pizzája 8 szeletre oszlana, és egyenletesen eloszlanának a barátai között.

Készíts egy függvényt, amely:

- megkapja a pizzák számát és a barátok számát,
- és visszaadja a megmaradó szeletek számát, ha mindenki ugyanannyi szeletet vesz.

Például:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
