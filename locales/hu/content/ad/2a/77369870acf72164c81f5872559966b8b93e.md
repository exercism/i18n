# Bevezetés

## Típusaliasok

A Gleamben egy típusalias segítségével kényelmes nevet adhatsz egy létező típusnak, amelyet egyébként körülményes lenne leírni.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Ha `pub type`-tal írod le, az alias a modulon kívül is használható, amelyben definiáltad. Ha a `pub`-ot elhagyod, az alias privát lesz, és más modulokból nem hivatkozhatsz rá.
