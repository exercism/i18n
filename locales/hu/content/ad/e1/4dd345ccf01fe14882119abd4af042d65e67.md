# A tesztek futtatása

Válaszd ki az operációs rendszeredet:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Nyisd meg a Command Promptot.
2. Töltsd le az első feladatot:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Lépj be az exercism könyvtárba:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Futtasd a teszteket:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Ne aggódj, ha a tesztek eleinte elbuknak, minden feladatot így kezdesz.)_

5. Oldd meg a feladatot. Keresd meg és dolgozd át az `instructions.append.md` útmutatót ([megtekintés a GitHubon](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

Sok szerencsét! Jó szórakozást!

   ```sh

   ```

2. Lépj be a feladat könyvtárába:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. Futtasd a teszteket:
