# Bevezetés

A C++-ban a Boolean értékeket a `bool` típus jelöli.
Egy `bool` érték vagy `true`, vagy `false`.

## Logikai operátorok

A C++ három Boolean-operátort támogat: `!` (NEM), `&&` (ÉS) és `||` (VAGY).
A `not`, `and` és `or` alternatív változatokat is használhatod.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Elsőbbség

A három Boolean-operátor _elsőbbsége_ eltérő.
Emiatt a kiértékelés sorrendje a következő: először a `!`, aztán a `&&`, végül a `||`.
Ha más sorrendet szeretnél kikényszeríteni, zárójelbe teheted a Boolean-kifejezést (azaz `()`), ugyanis a zárójelek elsőbbsége még ennél is nagyobb.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Konverzió

Ha `true` vagy `false` értéket használsz ott, ahol egy számot vár a program, akkor azok `1`-re, illetve `0`-ra konvertálódnak.
Ha egy Boolean-műveletben számot használsz, akkor a `0` kivételével mindent `true`-ként kezel a program, még a negatív értékeket is.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
