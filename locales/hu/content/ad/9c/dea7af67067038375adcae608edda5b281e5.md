# Bevezetés

Amikor `n` értékből álló sorozatra van szükséged, ahol mindegyik az indexétől függ, a Factor az `<iota>`-t adja neked (a `0, 1, …, n-1` egészek virtuális sorozatát), valamint a `map` függvényt:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

Az `<iota>` nem foglalja le előre az egészeket; a `map` sorrendben végigmegy rajtuk, és mindegyikre alkalmazza a quotationt.

Ha a pozíciónkénti eredmény egy karakterkód, a `>string` stringgé alakítja az eredményt; ez a természetes módja annak, hogy karakterek sorát állítsd össze indexvezérelt döntésekből:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
