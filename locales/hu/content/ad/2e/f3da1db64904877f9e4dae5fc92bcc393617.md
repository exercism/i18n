# Bevezetés

## Matematikai függvények

A négyzetgyököket, a szögeket és a növekedési görbéket nehéz csupán `+`, `-`, `*` és `/` segítségével kiszámolni. A [`math.functions`][math.functions] szótárban vannak olyan szavak, amelyek helyetted kiszámolják ezeket, a [`math.constants`][math.constants] szótárban pedig ott van a π. Mint minden más szó, ezek is a veremről veszik a bemeneteiket, és ott hagyják a válaszukat.

## Négyzetgyökök

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

Egy 5 méter hosszú létra, amelynek a lába 3 méterre van a faltól, 4 méter magasan éri el a falat:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## Pi

A `pi` (a `math.constants` szótárból) a vermre teszi a π-t, azt a számot, ahányszor egy kör átmérője ráfér a kerületére:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## A szögek radiánban értendők

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

A `sin`, a `cos` és a `tan` szöget vár, de nem fokban. **Radiánt** használnak, ahol egy fél fordulat π, nem pedig 180. Ha fokot adsz nekik, az nem hiba: észrevétlenül rossz választ ad.

A `deg>rad` a fokokat radiánná alakítja, a `rad>deg` pedig visszaalakítja. Ugyanazt jelentik, mint a π-vel való szorzás és a 180-zal való osztás, vagy épp fordítva:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

A `sin` meghívása előtt alakítsd át a fokokat radiánná:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

Egy 10 méter hosszú, 30 fokos rámpa 5 métert emelkedik. A válasz `4.999999999999999`-ként jelenik meg, mert a matematikai függvények a legközelebbi lebegőpontos számot adják, nem a pontos értéket. Átalakítás nélkül a `30 sin` a 30-at radiánként kezeli (csaknem öt teljes fordulat), és a rámpa `-9.88` métert „emelkedne”.

## Szög meghatározása

A `fatan2` fordítva működik: ha megadod, mennyit mentünk felfelé és mennyit oldalra, megadja a szöget radiánban. A [`math.libm`][math.libm] szótárban található. Először a *felfelé* mért távolság kerül a veremre, aztán az *oldalra* mért távolság:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

A szöget a pozitív *oldaliránytól* mérjük. A `fatan2` mindkét távolság előjelét figyelembe veszi, ezért −180 és 180 fok között bárhol megadhatja a szöget.

## Tíz hatványai: 10^ és log10

A `10^` a 10-et emeli valamilyen hatványra:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

A `log10` visszafelé megy. Arra a kérdésre ad választ, hogy „a 10 hányadik hatványa adja ezt a számot?” Ez a válasz a szám **logaritmusa**:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ és log

Az `e^` és a `log` ugyanaz a pár, csak 10 helyett *e*-vel (körülbelül 2,718). Az `e^` az *e*-t emeli hatványra, a `log` pedig arra válaszol, hogy „*e* hányadik hatványa adja ezt a számot?”

```
e^  ( x -- y )
log ( x -- y )
```

A matematikusok az *e*-t mindenre használják, ami minden lépésben ugyanazzal a hányaddal nő vagy csökken. Erre egy példa a kamatozó pénz, egy másik pedig egy hűlő csésze tea:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

A `log` visszafordítja az `e^`-t. Ez fordítva teszi fel a kérdést: hány perc kell ahhoz, hogy a különbség 40 fokra csökkenjen?

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
