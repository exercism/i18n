# Névjegy

A [switch-kifejezések][switch-expressions] hasonlóan viselkednek a [concept:csharp/switch-statements]() fogalomnál tárgyalt [switch-utasításokhoz][switch-statements]. Egyfajta döntési táblázatot támogatnak, amely a bemeneti feltételeket műveletekhez vagy értékekhez rendeli.

A switch-kifejezés lényege a _mintaegyeztetés_. A programozási feladatban az értékeket `const` mintákra illesztettük. Ebben az esetben a `switch` bemenetei egy _tartománykifejezés_, amelyet `const` értékekhez illesztünk, valamint az esetfeltételek által használt értékek.

Az eseteket (más néven _switch-ágakat_) szöveges sorrendben értékeli ki, és amint egyezés adódik, a folyamat leáll, és a hozzá tartozó értéket adja vissza.

A listában utolsóként szereplő `_` eset arra szolgál, hogy biztosítsa az egyeztetés kimerítő voltát, és elkerülje a lehetséges futásidejű hibákat.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

A `switch` egy „ágát” akkor választja ki, ha a minta illeszkedik a tartományváltozóra, és bármelyik esetfeltétel igazra értékelődik.

A switch-kifejezés emellett [típusmintákat][pattern-matching] és rekurzív egyeztetést is támogat.
