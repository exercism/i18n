# Utasítások

Ebben a feladatban kódot írsz majd, amivel egy remek lasagnét készíthetsz el a kedvenc szakácskönyvedből.

Öt részfeladat vár rád, amelyek mind a lasagna elkészítésével töltött időhöz kapcsolódnak.

## 1. Határozd meg a várható sütési időt percben

Definiáld a `Lasagna.expected_minutes_in_oven/0` függvényt, amely nem vár argumentumot, és visszaadja, hány percig kell a lasagnának a sütőben lennie. A szakácskönyv szerint a várható sütési idő 40 perc:

```elixir
Lasagna.expected_minutes_in_oven()
# => 40
```

## 2. Számítsd ki a hátralévő sütési időt percben

Definiáld a `Lasagna.remaining_minutes_in_oven/1` függvényt, amely argumentumként a lasagna tényleges sütőben töltött perceit kapja, és visszaadja, hány percet kell még a sütőben maradnia, az előző részfeladat várható sütési ideje alapján.

```elixir
Lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. Számítsd ki az előkészítési időt percben

Definiáld a `Lasagna.preparation_time_in_minutes/1` függvényt, amely argumentumként a lasagnához adott rétegek számát kapja, és visszaadja, hány percet töltöttél a lasagna előkészítésével, feltéve, hogy egy réteg előkészítése 2 percet vesz igénybe.

```elixir
Lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. Számítsd ki a teljes munkával töltött időt percben

Definiáld a `Lasagna.total_time_in_minutes/2` függvényt, amely két argumentumot kap: az első argumentum a lasagnához adott rétegek száma, a második pedig az a perc, amennyit a lasagna már a sütőben töltött. A függvény adja vissza, összesen hány percet dolgoztál a lasagna elkészítésén, ami az előkészítési idő és a lasagna által a sütőben eddig eltöltött idő összege.

```elixir
Lasagna.total_time_in_minutes(3, 20)
# => 26
```

## 5. Készíts értesítést arról, hogy a lasagna elkészült

Definiáld a `Lasagna.alarm/0` függvényt, amely nem vár argumentumot, és egy üzenetet ad vissza arról, hogy a lasagna fogyasztásra kész.

```elixir
Lasagna.alarm()
# => "Ding!"
```
