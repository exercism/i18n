# Bevezetés

## Összehasonlító operátorok

Az [összehasonlító operátorok][comparison-operators] két azonos típusú értéket hasonlítanak össze, és egy `Bool` értéket (`true` vagy `false`) adnak vissza.
Ha különböző típusú értékeket próbálsz összehasonlítani, a fordító hibát jelez.

A Swift szabványos összehasonlító operátorai:

| Operátor | Leírás                   | Példa           |
| -------- | ------------------------ | --------------- |
| `==`     | egyenlő                  | `1 == 1` (igaz) |
| `!=`     | nem egyenlő              | `1 != 2` (igaz) |
| `<`      | kisebb, mint             | `4 < 5`  (igaz) |
| `<=`     | kisebb vagy egyenlő      | `4 <= 4` (igaz) |
| `>`      | nagyobb, mint            | `3 > 1`  (igaz) |
| `>=`     | nagyobb vagy egyenlő     | `2 >= 2` (igaz) |

## If és else elágazások

A [feltételes utasítás][conditional-statement] attól függően futtat kódot, hogy egy feltétel `true` vagy `false` értékre értékelődik-e ki.
A leggyakoribb feltételes utasítás az [elágazás][if], amely csak akkor futtat egy kódblokkot, ha a feltétel `true`.
Egy `if` elágazást az `if` kulcsszóval írsz le, utána a feltétel, majd a kapcsos zárójelbe zárt kódblokk következik:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Az `if` párosítható egy `else` ággal, hogy alternatív kódot futtass, amikor a feltétel `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Több feltétel egymás utáni ellenőrzéséhez láncold össze az elágazásokat `else if` segítségével.
Az `if` elágazáshoz nem kötelező `else` ág, de hozzáadhatsz egyet, hogy kezeld azokat az eseteket, amikor egyik feltétel sem teljesül:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## If-kifejezés

A modern Swiftben az `if` elágazások olyan kifejezésként is használhatók, amelyek értéket állítanak elő.
Minden ág egy értékre értékelődik ki, így könnyen rendelhetsz értéket feltételesen:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## Ternáris operátor

A [ternáris operátor][ternary-operator] az if-else elágazás rövidített formája.
Egy boolean kifejezést, valamint két, kettősponttal elválasztott kifejezést kap.
Ha a boolean kifejezés igaz, az első kifejezés értékelődik ki, egyébként a második.
A felépítése a következő: `Boolean-expression ? expression1 : expression2`.

A ternáris operátor remekül jön, ha az if-else elágazás rövid formájára van szükséged, és a kifejezések is rövidek:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

A fenti példa a lenti kód rövidített megfelelője:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
