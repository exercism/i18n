# Tesztek

A feladatok megoldásához használhatod az Exercism weboldalán található online szerkesztőt.
Vagy letöltheted a feladatokat a számítógépedre, megoldhatod őket helyben, majd beküldheted az Exercismre.
A dokumentum további része a helyi munkáról szól.

## Exercism CLI

A feladatok letöltéséhez és beküldéséhez szükséged lesz az `exercism` parancssori eszközre.
A letöltéséhez és beállításához kövesd [az Exercism CLI dokumentációját][exercism-cli].

Egy feladat letöltéséhez tedd a következőt:

```bash
exercism download --track 8th --exercise hello-world
```

És válts át a feladat könyvtárába:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

vagy ha Windowst használsz:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

Az `exercism configure` paranccsal megtudhatod, hol van az exercism munkaterületed.

## Helyi tesztelés

Egy feladat tesztjeinek futtatásához a megfelelő feladat könyvtárában kell lenned.
Ezután indítsd el a teszteket ezzel a paranccsal:

```bash
8th -f test.8th
```

## Kihagyott tesztek

Egy feladat megoldása azt jelenti, hogy minden tesztje sikeres lesz.
Alapértelmezésben csak egy teszt (az első) fut le, amikor futtatod a teszteket.
Ez szándékos, mert így arra tudsz összpontosítani, hogy az az egy teszt sikeres legyen.
Miután sikeres lesz, a következő tesztet úgy engedélyezheted, hogy a `SKIP-REST-OF-TESTS` sort a következő teszt alá helyezed.

### A kihagyások felülírása

Az összes teszt futtatásához, beleértve a `SKIP-REST-OF-TESTS` szó utániakat is, állítsd a `RUN_ALL_TESTS` környezeti változót `true` értékre.
Az egyik módja annak, hogy ezt csak a tesztek futásának időtartamára állítsd be (macOS és Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## Küldd be a megoldásodat

Ha az Exercism weboldalára szeretnéd feltölteni a megoldásodat az exercism eszközzel:

```bash
exercism submit
```

Vedd figyelembe, hogy a kódodat akkor is feltöltheted, ha nem megy át az összes teszten.
Ez akkor hasznos, ha elakadtál, és segítségre van szükséged egy mentortól.
