# Utasítások

Rendszergazdaként dolgozol egy nagy müncheni vállalatnál Németországban. Az egyik feladatod az e-mail-fiókok kezelése.

Több embertől is panaszt hallasz, hogy nem tudnak e-mailt írni Müller úrnak. Hamar rájössz, hogy a vállalat nagy része egy régi e-mail-klienst használ, amely a nem ASCII-karakter miatt nem ismeri fel a `müller@firma.de` címet érvényes e-mail-címként.

Arra kérni az embereket, hogy adják fel a kedvenc régi e-mail-kliensüket, reménytelen vállalkozás, ezért úgy döntesz, hogy minden e-mail-fiókhoz tisztított aliasokat készítesz.

## 1. Meglévő felhasználónevek tisztítása minden nem kisbetű karakter eltávolításával

Valósítsd meg a `sanitize/1` függvényt. A függvény egy felhasználónevet fogadjon el karakterlistaként, és olyan felhasználónevet adjon vissza, amelyből minden karaktert eltávolít a kisbetűk kivételével.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. Alulvonások engedélyezése

Bővítsd a `sanitize/1` függvényt. A függvény ne távolítsa el az alulvonásokat a felhasználónévből.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. Német karakterek helyettesítése

A német ábécében 4 nem ASCII-karakter található, és mindegyikhez tartozik egy közismert ASCII-helyettesítő.

| Német karakter | ASCII-helyettesítő |
| -------------- | ------------------ |
| ä              | ae                 |
| ö              | oe                 |
| ü              | ue                 |
| ß              | ss                 |

Bővítsd a `sanitize/1` függvényt. A függvény a táblázat szerint helyettesítse a német karaktereket. Nyugodtan feltételezheted, hogy minden felhasználónév már csupa kisbetű.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
