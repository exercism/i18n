# Leírás

A [Lua](https://lua.org) egy egyszerű, ám erőteljes, hatékony, könnyűsúlyú és beágyazható szkriptnyelv. 1993 óta a brazíliai [PUC-RIO](https://www.puc-rio.br/) egyetemen tervezi, valósítja meg és karbantartja Roberto Ierusalimschy, Waldemar Celes és Luiz Henrique de Figueiredo csapata.

## Megjegyzések

A Lua-ban az egysoros megjegyzések `--`-tal kezdődnek, a többsoros megjegyzések pedig `--[[`-tal kezdődnek és `]]`-vel végződnek.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

## Változók

A Lua-ban háromféle változó létezik: globális változók, lokális változók és táblamezők. Hogy egyszerű maradjon, itt csak a lokális változókat magyarázzuk el. Alapértelmezés szerint minden változó globális, ezért a lokális változókat a `local` kulcsszóval kell ilyenként deklarálnunk.
```lua
local x
```

Egy változóhoz az `=` operátorral rendelhetsz értéket.
```lua
local x = 1
```

A `local` változó scope-ja arra a blokkra korlátozódik, ahol deklaráltuk. Egy blokk lehet egy vezérlési szerkezet törzse, egy függvény törzse, vagy az a fájl vagy string, amelyben a változót deklaráltuk.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

## Függvények

Egy függvényt a `function` kulcsszóval deklarálunk, és a változókhoz hasonlóan alapértelmezés szerint globális. Egy függvénydefiníciónak van neve, paraméterlistája és törzse. A függvény akkor lép ki, amikor eléri a `return` kulcsszót, és visszaadja az utána felsorolt összes értéket. Ha nincs megadva `return`, a függvény `nil`-t ad vissza.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

## Táblák

A táblák jelentik az egyetlen adatszerkezeti mechanizmust a Lua-ban, és nagyon erőteljesek. Tömbök, halmazok, objektumok, modulok és még sok más ábrázolására használjuk őket. Lényegében a Lua-ban egy tábla asszociatív tömb.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

Ez csak egy apró ízelítő, amire a következő szakaszhoz szükség van. Erre a témára később részletesen visszatérünk.

## Modulok

Egy modul kódból álló gyűjtemény, amelyet egy `.lua` forrásfájlban tárolunk. Mindent, amit a modul exportál, egy táblában tárolunk, és ezt a táblát a fájl végén visszaadjuk. A tábla tehát lényegében egyfajta névtérként működik.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

Ez a modul aztán egy másik fájlba tölthető be a `require` függvénnyel, amely visszaadja a táblát.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

Amikor meglátjuk a `say.hello` kifejezést, arra gondolunk, hogy „a `hello` függvény a `say` modulból”. De ha tudjuk, hogy a `say-hello.lua` egy táblát ad vissza, és visszalapozunk a táblákról szóló részhez, észrevesszük, hogy a Lua-ban ez a kifejezés azt jelenti, hogy „a `say` tábla indexelése, a `hello` stringet kulcsként használva”.

Bár jó gyakorlat, hogy egy modul táblát adjon vissza, ugyanúgy visszaadhat bármilyen más típust is, például egy függvényt.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
