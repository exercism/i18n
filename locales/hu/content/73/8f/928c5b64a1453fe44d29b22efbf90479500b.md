# Utasítások

A feladatod kiszámítani egy szó Scrabble-értékét úgy, hogy összeadod a betűi értékét.

A betűk értéke a következő:

| Betű                         | Érték |
| ---------------------------- | ----- |
| A, E, I, O, U, L, N, R, S, T | 1     |
| D, G                         | 2     |
| B, C, M, P                   | 3     |
| F, H, V, W, Y                | 4     |
| K                            | 5     |
| J, X                         | 8     |
| Q, Z                         | 10    |

Például a „cabbage” szó 14 pontot ér:

- A C betű 3 pontot ér
- Az A betű 1 pontot ér
- A B betű 3 pontot ér
- A B betű 3 pontot ér
- Az A betű 1 pontot ér
- A G betű 2 pontot ér
- Az E betű 1 pontot ér
