# Bevezetés

Alapvetően kétféle ciklus létezik:

1. Addig ismétlünk, amíg egy feltétel teljesül.
2. Végigmegyünk egy gyűjtemény elemein.

Mindkettő lehetséges R-ben, bár az első gyakoribb lehet.

## `while` és `repeat`

Nyitott végű problémákra, ahol előre nem tudjuk, hányszor fut le a ciklus, az R-ben van a feltételes `while` ciklus, és a feltétel nélküli `repeat` ciklus (ami ugyanaz, mint a `while (TRUE)`).

Az alapforma meglehetősen egyszerű:

```R
while (condition) {
  do_something()
}
```

Ebben az esetben a program addig ismétli a ciklust, amíg a `condition` már nem `TRUE`.

Kétféleképpen lehet idő előtt kilépni a ciklusból:

- A `break` hatására a ciklus kilép, és a végrehajtás a ciklus záró kapcsos zárójele (`}`) utáni következő sorban folytatódik.
- A `return(x)` leállítja az aktuális függvény végrehajtását, és visszaadja a hívónak az `x` visszatérési értéket.

Ha ezek a lehetőségek rendelkezésre állnak, néha kényelmes lehet létrehozni egy „végtelen” ciklust a `repeat { ... }` segítségével, majd a ciklustörzsben keresni egy megállási feltételt, amely kivált egy `break` vagy `return` utasítást.

Ez a három változat egyenértékű, és mindegyik `x == 0.4444...` értékkel végződik.

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Iterálás vektorokon

Ez gyakran szükségtelen R-ben.
Ahogy más fogalmaknál is olvashattad, sok függvény egész vektorokon működik.

Előfordulhat azonban, hogy az explicit ciklusok elkerülhetetlenek.
Ez különösen akkor igaz, ha:

- A ciklustörzs mellékhatásokkal jár, például nyomtatás vagy fájl I/O.
- A ciklus addig folytatódik, amíg el nem ér egy bizonyos kritériumot, kiszámíthatatlan számú iteráció után.

A ciklus feltételét zárójelbe kell tenni.
A függvénytestekhez hasonlóan a kapcsos zárójelek elhagyhatók (de gyakran szerepelnek) egysoros ciklustesteknél.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Ha az aktuális iteráció nem teljesít valamilyen feltételt, a `next` utasítással azonnal átugorhatsz a következő iterációra:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

Ha szükség van a numerikus indexre, használd a `seq_along()` függvényt.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Az `i in 1:length(v)` használata _nem_ ajánlott, mert problémákat okozhat, ha a `length(v)` nulla.
Az `1:0` tartomány megegyezik a `c(1, 0)` értékkel, így a ciklustörzs lefut, és valószínűleg hibát okoz.
A `seq_along()` függvényt kifejezetten arra tervezték, hogy ezt az esetet helyesen kezelje.
