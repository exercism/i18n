# Részletesen

A Swift vezérlésátadó utasításokat biztosít a ciklusok és a switch utasítások végrehajtási menetének megváltoztatásához. A `return` mellett a Swift ismeri a `continue`, a `break`, a cikluscímkék és a `fallthrough` utasítást is.

## Continue

A `continue` utasítás arra kéri a ciklust, hogy hagyja abba az aktuális iteráció végrehajtását, és azonnal kezdje el a következőt.
`while` vagy `repeat-while` ciklusban egyenesen a feltétel ellenőrzéséhez ugrik.
`for-in` ciklusban a sorozat következő elemére lép tovább.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

A `break` utasítás azonnal kilép a teljes ciklusból vagy switch utasításból.
A végrehajtás a ciklus vagy a switch utáni első kódsoron folytatódik.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Címkézett utasítások

Egymásba ágyazott ciklusokban előfordulhat, hogy a `break` vagy a `continue` a legbelső ciklus helyett egy külső ciklusra hasson.
Egy ciklust úgy címkézhetsz meg, hogy egy nevet és egy kettőspontot írsz elé (`labelName:`).
Ezt a címkét aztán átadhatod a `break` vagy a `continue` utasításnak:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

A Swiftben a `switch` utasítások alapértelmezés szerint nem esnek át a következő case-re; a végrehajtás automatikusan megáll az egyező case végén.
Ha kifejezetten azt szeretnéd, hogy a végrehajtás a következő case-re lépjen anélkül, hogy kiértékelné annak mintáját, használd a `fallthrough` kulcsszót:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
