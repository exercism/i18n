# Bevezetés

## Alapok

A _nyelvet_ **AWK**-nak nevezzük, az AWK-programokat értelmező _futtatható programot_ pedig **`awk`**-nak vagy **`gawk`**-nak.

### Minták és műveletek

Egy AWK-program **minta-művelet párokból** áll.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

A **minta** lehet reguláris kifejezés, amelyet a bemenetre illesztünk.
Emellett bármilyen kifejezés lehet, amely igaz vagy hamis értéket ad eredményül.

A **művelet** egy vagy több AWK-parancs.
A körülvevő kapcsos zárójelek kötelezők.

Ha a minta eredménye _igaz_, akkor a hozzá tartozó művelet kiértékelődik.

### Rekordok és mezők

Az AWK a bemenetet **rekordok** sorozataként dolgozza fel.
Minden rekord nulla vagy több **mezőre** bomlik.

Az alapértelmezett viselkedés a következő:

- a bemenetet rekordokra bontja úgy, hogy a „rekordelválasztó” az újsor karakter, így minden _sor_ egy rekord.
- a rekordot mezőkre bontja úgy, hogy a „mezőelválasztó” a whitespace, így minden _szó_ egy mező.

### Minták és műveletek, folytatás

A minta elhagyható, ebben az esetben a művelet _minden bemeneti rekordra_ kiértékelődik.

A művelet is elhagyható, ilyenkor az alapértelmezett művelet az aktuális rekord kiírása.

#### Különleges minták

Két különleges minta is gyakran használatos.

- A `BEGIN` a hozzá tartozó műveletet még azelőtt kiértékeli, hogy bármilyen bemenetet feldolgoznánk.
- Az `END` a hozzá tartozó műveletet az összes bemenet feldolgozása után értékeli ki.

### Mezőváltozók

A mezőkre `$1`, `$2`, `$3` stb. formában hivatkozol.

Az aktuális rekord a `$0`.

Íme néhány más gyakran használt beépített változó.

#### A bemenet feldolgozását vezérlő beépített változók

- Az `RS` a bemenet rekordelválasztója.
  Ahogy említettük, alapértéke az újsor karakter.
- Az `FS` a bemenet mezőelválasztója.

Ezeket a változókat gyakran a `BEGIN` műveletblokkban állítjuk be.

#### Információt hordozó beépített változók

Ezeket a változókat az AWK automatikusan beállítja a program futása közben.

- Az `NF` az aktuális rekord mezőinek számát tárolja.
  - Az utolsó mező értékének megszerzéséhez használd a `$NF`-et.
- Az `NR` az aktuális rekordszámot tárolja.
  - Amikor több bemeneti fájlt dolgozunk fel, az `NR` az eddig feldolgozott rekordok összes számát tartalmazza.
- Az `FNR` az aktuális bemeneti fájl aktuális rekordszámát tárolja.
  - Az NR és az FNR közötti különbség érzékeltetésére itt egy gyakori AWK-idióma.
    ```awk
    NR == FNR {action}
    ```
    Ez annyit jelent, hogy „ha a felhalmozott rekordszám egyenlő az aktuális fájl rekordszámával”.
    Ez csak az _első bemeneti fájl_ rekordjaira lehet igaz.

### Igazságértelmezés

Az AWK ugyanazt az igazságértelmezést használja, mint a C.

- A `0` szám hamis.
- Minden más szám igaz.

Mivel az AWK szövegfeldolgozó nyelv, az igazságértékek kiterjednek a stringekre is.

- Az üres string `""` hamis.
- Minden nem üres string igaz.

### Megjegyzések

A megjegyzések a `#` karakterrel kezdődnek, és a sor végéig tartanak.

### Példák

A Unix-szerű rendszereken az `/etc/passwd` a felhasználókra vonatkozó információkat tartalmaz.
Minden felhasználó külön sorban szerepel, a mezőket kettőspontok választják el.

A felhasználónevek felsorolásához:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Figyeld meg, hogy a `{print $1}` művelethez nem tartozik minta, így minden rekordnál végrehajtódik.

Ha a kimenetet csak azokra a felhasználókra szeretnénk korlátozni, akik a bash-t használják bejelentkezési shellként, ezt így tehetjük:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
