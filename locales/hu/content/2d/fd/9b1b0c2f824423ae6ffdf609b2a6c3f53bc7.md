# Utasítások

Egy alacsony fogyasztású beágyazott rendszerre szánt játékon dolgozol, és több kényelmi függvényt kell írnod, amelyeket a játék más részei fognak használni.

## 1. Számítsd ki egy osztás hányadosát és maradékát

A hányados egy osztás eredménye.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

Példa:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. Válassz ki páros indexű elemeket egy iterátorból

A főnököd szerint ez majd segít egy képernyőpuffer-optimalizálást bevezetni.

Az iterátorok olyan elemek, amelyek az [`Iterator` trait](https://doc.rust-lang.org/std/iter/trait.Iterator.html) által definiált metódusokat teszik elérhetővé. Ez a dokumentáció meglehetősen terjedelmes, mert sok metódust kínálnak; íme a legfontosabb tulajdonságaik:

- Az iterátor egy tetszőleges hosszúságú elemfolyam
- Van egy [`enumerate` metódusuk](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate), amely minden értékhez egy `(i, val)` tuple-t ad vissza
- Van egy [`filter` metódusuk](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter), amely egy closure segítségével dönti el, hogy kiadjon-e egy elemet az iterátorból
- Van egy [`map` metódusuk](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map), amely egy closure segítségével módosítja az iterátor elemeit

Mivel a függvényed bármilyen típusú iterátoron futhat, `impl`-t használ annak jelzésére, hogy ez egy trait-példány, nem pedig egy egyszerű elem. Hasonlóképpen a `<Item=T>` szintaxis csupán azt jelenti, hogy nem számít, milyen típusú elemet állít elő az iterátor; a függvényed bármely iterátor páros indexű elemeit elő tudja állítani.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

Példák:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. Számítsd ki egy pozíció manhattan-távolságát az origótól

A könnyebb leképezés érdekében kapsz egy `Position` tuple-structot:

```rust
struct Position(i16, i16);
```

Implementálnod kell egy `manhattan` metódust a `Position` típuson, amely visszaadja az adott pozíció [manhattan-távolságát](https://en.wikipedia.org/wiki/Taxicab_geometry) az origótól (`Position(0, 0)`).

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

Példa:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
