# Bevezetés

## Boolean

A Boolean típusnak Lua-ban két hagyományos értéke van: `true` és `false`. Ezeket az értékeket hozzárendelheted egy változóhoz, kombinálhatod őket logikai operátorokkal (`and`, `or`, `not`), és feltételes vizsgálatokban is használhatod őket (például vezérlési szerkezetekben).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

A feltételes vizsgálatok és a logikai operátorok a Boolean `false`-t és a `nil`-t is hamisnak tekintik, minden mást pedig igaznak.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Az `and` és az `or` egyaránt *rövidzárásos kiértékelést* használ, ami azt jelenti, hogy a második operandusukat csak akkor értékelik ki, amikor arra szükség van. Minden művelet az [operátorok precedenciája](https://www.lua.org/manual/5.4/manual.html#3.4.8) szerint értékelődik ki, ahol a `not` az `and` és az `or` előtt értékelődik ki.
