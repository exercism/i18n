# Névjegy

A `|>` operátor neve [pipe operátor][pipe]. Segítségével úgy fűzhetsz össze függvényhívásokat, hogy az előző függvényhívás visszaadott értéke a következő függvényhívás első argumentumaként adódjon át.

```elixir
String.replace_suffix(String.upcase(String.duplicate("go ", 3)), " ", "!")

# versus

"go "
|> String.duplicate(3)
|> String.upcase()
|> String.replace_suffix(" ", "!")
```

Egyetlen sorban is használható:

```elixir
"go " |> String.duplicate(3) |> String.upcase() |> String.replace_suffix(" ", "!")
```

A `Kernel` függvényeit általában mindenhol a `Kernel` modulnév nélkül használjuk, de a pipe-láncban ezeknél a függvényeknél szükség van a modulnévre. Például a `2 * 3 == 6` így is felírható:

```elixir
2 |> Kernel.*(3) |> Kernel.==(6)
```

Ízlés kérdése, hogy mikor használod a pipe operátort és mikor nem. Néhány Elixir-fejlesztő szereti követni ezeket a szabályokat:

- Ne használd a pipe operátort, ha csak egyetlen függvényhívást végzel.

  ```elixir
  # do
  String.split("hello", "")

  # don't
  "hello" |> String.split("")
  ```

- Ne hozz létre névtelen függvényeket közvetlenül a pipe-láncban.

  ```elixir
  # do
  take_n_letters = fn n -> Enum.take(?a..?z, n) end
  2 |> Kernel.*(3) |> take_n_letters.()

  # don't
  2 |> Kernel.*(3) |> (fn n -> Enum.take(?a..?z, n) end).()
  ```

- A pipe-láncot mindig változóval vagy literál értékkel kezdd, ne függvényhívással.

  ```elixir
  # do
  "hello" |> String.upcase() |> String.split("")

  # don't
  String.upcase("hello") |> String.split("")
  ```
