# nincs nevesített export

Az [`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)
nem található. Enélkül a tesztek nem lesznek sikeresek.

Győződj meg róla, hogy `%{export.name}` létezik, és tedd elé az `export` kulcsszót:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
