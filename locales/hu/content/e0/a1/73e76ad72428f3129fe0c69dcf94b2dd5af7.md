# Névjegy

A Java elsődleges objektumorientált építőeleme az _osztály_, amely adatok ([_mezők_][fields]), más néven példányváltozók, és viselkedés ([_metódusok_][methods]) együttese.
Az osztály mezőit és metódusait együtt az osztály _tagjainak_ nevezzük.

A tagokhoz való hozzáférést hozzáférés-módosítókkal szabályozhatod; a két leggyakoribb közülük:

- [`public`][public]: a taghoz bármely kód hozzáférhet (nincs megkötés).
- [`private`][private]: a taghoz csak az ugyanabban az osztályban lévő kód férhet hozzá.

Java-ban, ha nem adsz meg hozzáférés-módosítót, az alapértelmezés a _csomag szintű láthatóság_.
Ebben az esetben a tag az ugyanabba a csomagba definiált összes osztály számára látható.

Az összetartozó adatok és viselkedés fenti csoportosítását, valamint a tagokhoz való hozzáférés korlátozását [_egységbe zárásnak_][encapsulation] nevezzük, ami az objektumorientált programozás egyik alapvető fogalma.

Az osztályra gondolhatsz úgy is, mint egy sablonra, amellyel az osztály példányait létrehozod.
Egy osztály [példányának létrehozásához][creating-objects] (más néven _objektum_) a [`new` kulcsszót][new] használjuk:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

A [mezőknek][fields] típusuk és nevük van (a név [camelCase][camel-case] írásmódú), és az osztályban bárhol definiálhatók (az osztály neve [PascalCase][pascal-case] írásmódú).

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Egy mezőnek opcionálisan kezdőértéket is adhatsz.
Ha egy mezőnek _nem_ adsz kezdőértéket, akkor a típusa [alapértelmezett értékét][default-values] kapja.
Egy példány mezőértékeit pontjelöléssel érheted el és frissítheted.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

A privát mezők általában egy metódus meghívásának mellékhatásaként frissülnek.
Az ilyen metódusok általában nem adnak vissza értéket; ebben az esetben a visszatérési típus [`void`][void] kell legyen:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field
        carsImported = carsImported + numberOfCars;
    }
}
```

Vedd figyelembe, hogy a Java-osztályokban nem szokás nyilvános mezőket használni.
Jellemzően privát mezőket használunk, amelyeket [_gettereken_ és _settereken_][so-getters-setters] keresztül érünk el.

Egy osztályon belül a [`this` kulcsszó][this] az aktuális osztályra hivatkozik.
Ez különösen akkor hasznos, ha egy paraméter neve megegyezik egy mező nevével:

```java
class CarImporter {
    private int carsImported;

    public void setImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```
