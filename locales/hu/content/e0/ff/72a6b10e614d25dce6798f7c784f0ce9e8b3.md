# Bevezetés

A `for` ciklus segítségével ismételten végrehajthatod ugyanazt a kódot, ameddig egy feltétel teljesül.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

A `for` ciklus négy részből áll:

1. A kezdőérték: a ciklusba való belépés előtt egyszer fut le. Általában a cikluson belül használt változók definiálására szolgál.
2. A feltétel: minden iteráció előtt kiértékelődik. A ciklus addig folytatódik, amíg ez az érték `true`.
3. A léptetés: minden iteráció után lefut. Általában a ciklusváltozó(k) módosítására (gyakran növelésére vagy csökkentésére) szolgál.
4. A ciklustörzs: az a kód, amely minden iterációban végrehajtódik.
