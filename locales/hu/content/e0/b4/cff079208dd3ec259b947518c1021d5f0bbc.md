# Bevezetés

Java-ban a `null` literál egy érték hiányát jelöli.

A Java primitív adattípusai mind rendelkeznek alapértelmezett értékkel, ezért soha nem lehetnek `null` értékűek. Konvenció szerint kisbetűvel kezdődnek, pl. `int`.

A referenciatípusok egy objektum memóriacímét tárolják, és értékük `null` is lehet. Általában nagybetűvel kezdődnek, pl. `String`.

Ha egy primitív változónak `null` értéket próbálunk adni, az fordítási idejű hibát eredményez, mert a változó mindig a hozzárendelt típus primitív értékét tárolja.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Ha egy referencaváltozónak `null` értéket adunk, az nem eredményez fordítási idejű hibát, mert a referencaváltozók felvehetnek `null` értéket.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
