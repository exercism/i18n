# Utasítások

Ebben a feladatban egy internetes fórum felhasználói fiókjainak jogosultságait fogod ellenőrizni. A fórum három különböző jogosultságot támogat:

- Read
- Write
- Delete

Háromféle fiók létezik, mindegyiknek más az alapértelmezett jogosultsága:

- Vendégek: olvashatják a bejegyzéseket.
- Felhasználók: olvashatják és írhatják a bejegyzéseket.
- Moderátorok: olvashatják, írhatják és törölhetik a bejegyzéseket, nekik minden jogosultságuk megvan.

Néha az egyes jogosultságok módosíthatók: például adhatsz egy vendégfióknak írási jogosultságot is, vagy ha visszavonod egy fiók összes jogosultságát, akkor egyetlen jogosultsága sem marad.

## 1. Egy fióktípus alapértelmezett jogosultságainak lekérése

Először definiálj egy `AccountType` felsorolást, amely a három fióktípust képviseli: `Guest`, `User` és `Moderator`.

Ezután definiálj egy `Permission` felsorolást, amely a három jogosultságtípust képviseli: `Read`, `Write` és `Delete`, valamint két továbbit: az `All`-t, ha minden jogosultsággal rendelkezik, és a `None`-t, ha egyetlen jogosultsággal sem.

Ezután implementáld a (_statikus_) `Permissions.Default()` metódust, amely egy adott fióktípus alapértelmezett jogosultságait adja vissza:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Jogosultság megadása

Implementáld a (_statikus_) `Permissions.Grant()` metódust, amely megad (hozzáad) egy jogosultságot:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Jogosultság visszavonása

Implementáld a (_statikus_) `Permissions.Revoke()` metódust, amely visszavon (eltávolít) egy jogosultságot:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Jogosultság ellenőrzése

Implementáld a (_statikus_) `Permissions.Check()` metódust, amely megkapja a fiók aktuális jogosultságait, és ellenőrzi, hogy a fiók jogosult-e egy adott jogosultságra:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
