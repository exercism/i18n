# Példa

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

A ponttal kezdődő sorok _direktívák_: az assemblernek szóló utasítások, nem a processzornak.
A `.equ` a 16 számhoz rendeli a `FRAME_SIZE` nevet.
A `.text` azt jelzi, hogy ami ezután következik, az kód.
A `.global` láthatóvá teszi az `is_triple` címkét ezen a fájlon kívül is, így más kód is hívhatja.
Találkozhatsz a `.globl` direktívával is, ami ugyanezt jelenti.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

Az `is_triple` azt ellenőrzi, hogy teljesül-e az `a² + b² = c²`; ha igen, 1-et ad vissza, egyébként 0-t.
Például a `(6, 8, 10)` bemenetre 1-et ad, mert `36 + 64 = 100`.
Az `is_triple` címke jelöli, hol kezdődik a függvény.
Az `a`, `b` és `c` értékét az `a0`, `a1` és `a2` regiszterekben kapja.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

Az `ra` regiszter a _visszatérési címet_ tárolja: azt a helyet a hívóban, ahová vissza kell ugrani, amikor végeztünk.
Minden `call` felülírja az `ra`-t, ezért először elmentjük a _verembe_.
A verem lefelé, a kisebb címek felé növekszik, ezért ha 16-ot kivonunk a `sp` veremmutatóból, az 16 bájtot foglal le nekünk.
(A `sp` értékének mindig 16 többszörösének kell lennie.)
A `b`-t és a `c`-t is elmentjük, mert egy általunk hívott függvény megváltoztathatja az `a` regisztereket.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

Az `a` már az `a0`-ban van, ahol a `square` a bemenetét várja.
A `call` az `ra`-t a következő utasításra állítja, és a `square`-re ugrik, ami az `a0`-ban adja vissza az eredményét.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

A `b`-t visszatöltjük a veremből, négyzetre emeljük, és hozzáadjuk az `a * a`-hoz.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

A különbség pontosan akkor nulla, ha `a² + b² = c²`.
A `seqz` (»set if equal to zero«, azaz állítsd be, ha nullával egyenlő) ezt 1-re vagy 0-ra alakítja.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

Visszaállítjuk az `ra`-t, és visszaadjuk a verem 16 bájtját.
A `ret` ezután az `ra`-ban lévő címre ugrik, vissza a hívóhoz.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

A `square` nem hív meg más függvényt, így az `ra` sértetlen marad, és nincs mit elmenteni.
Nincs `.global` jelöléssel ellátva, mert csak az `is_triple` használja.
