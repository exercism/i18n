# Utasítások

Folytatódik a távirányítós autó projektje. A telemetriai rendszer sávszélessége szűkös, ezért arra kértek, hogy valósíts meg egy üzenetprotokollt a telemetriai adatok továbbításához.

Az adatok pufferekben (byte-tömbökben) továbbítódnak. Egészek küldésekor a puffer mérete csökken az alább leírt protokoll alkalmazásával.

Minden értéket a lehető legkisebb egész típusban érdemes ábrázolni (a `byte` és `sbyte` típus nem szerepel, mert a megtakarítás elhanyagolható lenne):

| Ettől                     | Eddig                     | Típus    |
| ------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

Az értéket a hozzá rendelt típushoz tartozó megfelelő számú byte-ra kell átalakítani. A teljes puffer egy olyan byte-ból áll, amely a pufferben lévő további byte-ok számát jelzi (_prefix byte_), ezt követik az egészet tároló byte-ok (_payload bytes_).

Néhány típus ugyanannyi byte-ot használ (pl. a `uint` és az `int` típus). Normális esetben ugyanaz lenne a _prefix byte_-juk, de ez problémássá tenné a dekódolást. Ennek kiküszöbölésére a protokoll egy kis trükköt vezet be: előjeles típusoknál a _prefix byte_ értéke `256` mínusz a pufferben lévő további byte-ok száma.

A kommunikációban csak a prefix byte és az általa jelzett számú következő byte kerül elküldésre. Belül mind a küldő, mind a fogadó rutin egy 9 byte-os puffert használ (szükség esetén záró nullákkal).

## 1. Egész érték kódolása küldésre készen

Valósítsd meg a statikus `TelemetryBuffer.ToBuffer()` metódust, amely a metódusnak átadott paramétert veszi, és pufferré kódolja.

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. Fogadott puffer dekódolása

Valósítsd meg a statikus `TelemetryBuffer.FromBuffer()` metódust, amely dekódolja a fogadott puffert, és az értéket `long` formájában adja vissza.

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

Ha a prefix byte értéke nem várt, akkor `0`-t kell visszaadni.
