# Tesztek

## Clojure CLI

Az Exercism Clojure-feladataihoz egy `deps.edn` fájl jár, amelynek `:test` aliasa meghívja a [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) eszközt:

``` bash
$ clj -X:test
```

Ez végigfut a projekted `test` könyvtárán, megkeresi a `clojure.test` segítségével definiált teszteket, és lefuttatja őket.

## Leiningen

Egy feladat tesztjeinek futtatásához Leiningennel egyszerűen add ki a következőt:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
