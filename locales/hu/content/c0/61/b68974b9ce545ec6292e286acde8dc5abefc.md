# Bevezetés

Minden struktúra- vagy osztálypéldány rendelkezik egy implicit `self` nevű tulajdonsággal, amely magára a példányra utal.
A `self`-et leggyakrabban arra használjuk, hogy különbséget tegyünk egy példánytulajdonság és egy vele azonos nevű paraméter között:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

A Swift-típusok emellett egy nagybetűs `Self` kulcsszót is biztosítanak, amely nem magára a példányra, hanem a példány *típusára* utal.
