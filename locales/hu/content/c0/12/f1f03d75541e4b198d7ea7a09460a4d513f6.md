# Bemutatás

A `<dlist>` (a [`dlists`][dlists] szótárban) egy új, kétszeresen láncolt listát hoz létre. A műveletek a [`deques`][deques] szótárban élnek, és a [kétvégű sor protokoll][deque-protocol] alapján diszpécselnek, így más konténerek is megvalósíthatják őket, mindenekelőtt a `<dlist>`.

| szó             | hatás                               |
|-----------------|-------------------------------------|
| `<dlist>`       | `( -- dlist )` - új, üres kétvégű sor |
| `push-front`    | `( elt deque -- )` - beszúr az elejére |
| `push-back`     | `( elt deque -- )` - beszúr a végére  |
| `pop-front`     | `( deque -- elt )` - kivesz az elejéről |
| `pop-back`      | `( deque -- elt )` - kivesz a végéről  |
| `peek-front`    | `( deque -- elt )` - kiolvassa az elejét anélkül, hogy eltávolítaná |
| `peek-back`     | `( deque -- elt )` - kiolvassa a végét anélkül, hogy eltávolítaná  |
| `deque-empty?`  | `( deque -- ? )` - üres a kétvégű sor? |
| `dlist-length`  | `( dlist -- n )` - az elemek száma |

A push/pop műveletek mind helyben módosítják a kétvégű sort. Az a szokásos minta, hogy átadsz egy kétvégű sort egy rutinnak, majd újra olvasol belőle.

## Verem és sor

Két szokásos diszpécselési minta:

```
LIFO (stack): push-back + pop-back   (or push-front + pop-front)
FIFO (queue): push-back + pop-front  (or push-front + pop-back)
```

Ha csak a LIFO-sorrendre van szükséged, a `push` és `pop` szavakkal (a `mutation` szótárból) rendelkező vektor a helyes választás, mert a `<dlist>` láncoltlista-többletet hordoz. Akkor nyúlj a `<dlist>`-hez, ha *mindkét* végén O(1) idejű műveletre van szükséged, ami szinte mindig FIFO-sort jelent.

## BFS-minta

A szélességi keresés a FIFO klasszikus felhasználási módja:

```factor
:: reachable ( start graph -- visited )
    HS{ } clone :> visited
    <dlist>    :> frontier
    start visited adjoin
    start frontier push-back
    [ frontier deque-empty? ] [
        frontier pop-front graph at [
            dup visited in? [ drop ] [
                [ visited adjoin ] [ frontier push-back ] bi
            ] if
        ] each
    ] until
    visited ;
```

A kétvégű sor hordozza a keresési frontvonalat, a hash-set pedig a duplikátumok kiszűrését. Cseréld le a `pop-front`-ot `pop-back`-re, és ugyanez a felépítés mélységi kereséssé válik.

## `MEMO:` automatikus gyorsítótárazás

Néha drága lehet a BFS által hívott csúcsonkénti kikeresés. A Factor biztosítja a [`MEMO:`][memo-decl] szót, amely a `:` helyettesítője, és a szó eredményét a bemenetei alapján automatikusan gyorsítótárazza:

```factor
USING: memoize ;

MEMO: expensive-neighbours ( node -- nodes )
    ! ... slow computation ...
    ;
```

Egy `MEMO:` szó minden bemenet első előfordulásakor lefuttatja a törzsét, azután pedig a gyorsítótárazott eredményt adja vissza. A gyorsítótár az image teljes élettartamáig megmarad, és nincs sem idő-, sem méretalapú kiürítés. Tiszta függvényekhez használd, amelyek bemenetei véges, jól kezelhető halmazból származnak.
