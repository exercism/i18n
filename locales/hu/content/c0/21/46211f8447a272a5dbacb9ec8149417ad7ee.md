# Bevezetés

A Cairo a szótárakat az alapkönyvtárainak részeként biztosítja, amelyeket a `Felt252Dict<T>` típus képvisel.

A szótár kulcstípusa a Cairóban a `felt252`-re korlátozódik, ami eltér más nyelvektől, ahol magának a kulcstípusnak is megadható a típusa.

Egy szótár létrehozásához használhatod a `Default` trait `default` metódusát, így:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

A leggyakrabban használt alapműveletek a következők:

1. `insert(felt252, T) -> ()`, amellyel értékeket írhatsz egy szótárpéldányba, és
2. `get(felt252) -> T`, amellyel értékeket olvashatsz ki belőle.

Ezeket a műveleteket pedig így használnád:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

Ha olyan kulcshoz próbálod lekérni az értéket, amely nem létezik a szótárban, akkor az értéktípus nullaértékét adja vissza.

Ez összezavarhat, különösen akkor, ha az értéktípusod alapértelmezett értéke (például egy egész számnál a 0) érvényes érték.

Ez azt is jelenti, hogy nincs mód adat törlésére egy szótárból.

Erre érdemes figyelni, amikor ezt a struktúrát beépíted a kódodba.
