# Elágazások

A Pythonban az [`if`][if statement], az `elif` (_az 'else and if' összevonása_) és az `else` utasítások segítségével szabályozhatod a program végrehajtásának [menetét][control flow tools], és döntéseket hozhatsz benne.
Sok más programozási nyelvtől eltérően a Python 3.9-es és korábbi verziói nem kínálnak formális case-switch utasítást, helyette több `elif` utasítással érnek el hasonló eredményt.

A Python 3.10 egy `structural pattern matching` nevű, a case-switch-hez hasonló utasítást vezet be, amelyet egy másik fogalomban tárgyalunk majd külön.

A feltételes utasítások olyan kifejezéseket használnak, amelyeknek `True` vagy `False` értékre kell kiértékelődniük, akár úgy, hogy közvetlenül `bool` típust adnak vissza, akár úgy, hogy [„truthy” vagy „falsy”][truth value testing] értékként értékelődnek ki.

```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

Ha az `if`-fel együtt szerepel, az opcionális `else` kódblokk akkor fut le, amikor az eredeti `if` feltétel `False` értékre értékelődik ki:

```python
x = 5
y = 10

# The comparison '>' here returns the bool 'False',
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

Az `elif` segítségével több feltételt is kiértékelhetsz, illetve több ágra bonthatod a kódot.

```python
x = 5
y = 10
z = 20

# The 'elif' statement allows for the checking of more conditions.
if x > y:
    print("x is greater than y and z")
elif y > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

A [Boolean-műveleteket][boolean operations] és az [összehasonlításokat][comparisons] össze is kapcsolhatod feltételes utasításokkal, hogy összetettebb vizsgálatokat végezhess:

```python
>>> def classic_fizzbuzz(number):
        if number % 3 == 0 and number % 5 == 0:
            say = 'FizzBuzz!'
        elif number % 5 == 0:
            say = 'Buzz!'
        elif number % 3 == 0:
            say = 'Fizz!'
        else:
            say = str(number)
        
        return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
