# Bevezetés

A fájl nem más, mint egy névvel ellátott adatfolyam a lemezen. Az [`io.files`][io.files] szótár kétféleképpen teszi lehetővé, hogy egy fájllal dolgozz: kényelmi szavakkal, amelyek egyetlen hívásban beolvassák vagy kiírják a fájl teljes tartalmát, illetve adatfolyam-megnyitókkal, amikor fokozatosan szeretnél olvasni vagy írni.

Minden fájlhoz nyúló szó egy **kódolást** vár el, ez az a séma, amely a bájtokat karakterekké alakítja, és vissza. Szöveg esetén ez szinte mindig az `io.encodings.utf8` szótárból származó [`utf8`][utf8].

## Egy teljes fájl beolvasása

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

A `file-contents` az egész fájlt egyetlen stringként adja vissza; a `file-lines` a fájl sorait tartalmazó tömböt adja vissza, a sortöréseket levágva.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Egy teljes fájl kiírása

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Mindkettő **lecseréli** a fájl tartalmát (szükség esetén létre is hozza). A `set-file-contents` szó szerint kiír egy stringet; a `set-file-lines` egy sorozat minden elemét külön sorba írja, és helyetted hozzáadja a sortöréseket.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## Hozzáfűzés egy fájlhoz

Ha úgy szeretnél hozzáírni egy fájlhoz, hogy ne töröld ki a már meglévő tartalmát, nyisd meg egy `with-…` kombinátorral, és a quotation belsejében írj az aktuális adatfolyamba:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Mint minden `with-…` kombinátor, ezek is destruktor-hatókörök: a fájlkezelő bezárul, amikor a quotation befejeződik, még akkor is, ha kivételt dob.
