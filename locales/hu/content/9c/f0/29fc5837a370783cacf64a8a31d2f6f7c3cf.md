# Bevezetés

## Tömbök

A Java nyelvben a tömbök segítségével több azonos típusú értéket tárolhatsz egyetlen szerkezetben.
Más adatszerkezetektől eltérően a tömb mérete a létrehozás után rögzített.
Az elemeket index használatával rendelheted a tömbhöz, illetve kérdezhetsz le belőle.
A Java tömbök nullától induló indexelést használnak: az első elem indexe 0, a másodiké 1, és így tovább.

Íme a tömb inicializálásának szokásos szintaxisa:

```java
type[] variableName = new type[size];
```

A `type` a tömb elemeinek a típusa, ami lehet primitív típus (például `int`) vagy osztály (például `String`).

A `size` az elemek száma, amennyit ez a tömb tárolni fog (ez később nem változtatható meg).
A tömb létrehozása után az elemek az alapértelmezett értékükre inicializálódnak (jellemzően `0`, `false` vagy `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

A tömböket egy rövidített jelöléssel is definiálhatod, amellyel egyszerre hozhatod létre a tömböt és állíthatod be az értékeit:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

Mivel a fordító most már meg tudja állapítani, hogy hány eleme lesz a tömbnek, a hossz elhagyható.

A tömb elemeit szögletes zárójeles indexjelöléssel rendelheted hozzá és érheted el:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

Ha a tömb érvényes indexein kívül eső indexet érsz el, az `IndexOutOfBoundsException` kivételt eredményez.

A tömböket módosíthatod úgy, hogy egy tömbpéldány metódusait vagy tulajdonságait hívod meg, vagy úgy, hogy az `Arrays` osztályban definiált statikus metódusokat használod (ezeket jellemzően csak generikus kódban használják).
A `length` tulajdonság tartalmazza a tömb hosszát.
Így érheted el:

```java
int arrayLength = someArray.length;
```

A Java emellett egy hasznos segédosztályt is biztosít, a [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) osztályt, amely rengeteg hasznos, tömbökkel kapcsolatos metódust tartalmaz (például `Arrays.equals`).

A Java a [többdimenziós tömböket](https://www.programiz.com/java-programming/multidimensional-array) is támogatja, például `int[][] arr = new int[3][4];`, amelyek nagyon hasznosak lehetnek.

Az, hogy a tömb egyben _gyűjtemény_ is, azt jelenti, hogy az értékek index szerinti elérése mellett egy `for-each` ciklussal _az összes_ értékén végig is iterálhatsz:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

Ha nagyobb kontrollt szeretnél afölött, hogy mely értékeken iterálj, használhatsz `for` ciklust:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
