# Bevezetés

A típusdefiníció egy új, nevesített típust hoz létre, amely minden más típustól különbözik, még azoktól is, amelyeknek ugyanaz az alapul szolgáló típusuk.

## Típusok definiálása

A típusdefiníció a `type` kulcsszóval kezdődik, amelyet az új típus neve és annak alapul szolgáló típusa követ:

```go
type File []bool
```

A `File` itt a sakktábla egyetlen függőleges oszlopára utal, amelyet általában A-tól H-ig jelölnek.
Az oszlop minden mezőjét egy Boolean érték képviseli, amely azt jelöli, hogy foglalt-e vagy sem.
Most, hogy a `File` definiálva van, más definíciókban is használhatod:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

A `Chessboard` az oszlopazonosítókat `File` értékekhez rendeli.
Minden `File` Boolean-okból álló szelet, amely egy sakktábla adott oszlopának mezőit képviseli.
E típusdefiníciók nélkül a `board` egy `map[string][]bool` lenne, ami miatt nehezebb lenne megérteni, hogy mit ábrázolunk.
