# Utasítások

Wellington időjárásállomása a kézi hőmérséklet-rögzítő rendszerét egy új, digitális rendszerre cseréli.
A régi rendszerben a számításokat kézzel végezték.
Az új rendszerben ezeket már automatizálják.
A számítások közé tartozik a hőmérséklet átváltása Celsiusról Fahrenheitre és az átlaghőmérséklet kiszámítása.
Az új rendszerben érzékelők rögzítik a hőmérsékleti adatokat Celsius-fokban.

A wellingtoni időjárásállomás szeretné, ha segítenél nekik az új rendszerrel.

## 1. A hőmérséklet átváltása Celsiusról Kelvinre

Az időjárásállomás weboldalán van egy szakasz, amelyet a kutatóknak szántak.
A kutatókat a Kelvinben mért hőmérséklet érdekli.

A Kelvin a hőmérséklet mérésére használt mértékegység.
Ugyanaz a skála, mint a Celsiusé, de más a kezdőpontja.
A kezdőpontja az abszolút nulla, ami 0 K (Kelvin) vagy -273,15 °C (Celsius).

Az alábbi táblázat a Celsius és a Kelvin közötti átváltást mutatja:

| Celsius (°C) | Kelvin (K) |
| ----------- | --------- |
| -273,15     | 0         |
| -100        | 173,15    |
| 0           | 273,15    |
| 100         | 373,15    |

Az időjárásállomás szeretné, ha készítenél egy metódust, amely átváltja a hőmérsékletet Celsiusról Kelvinre.

Készítsd el a `Temperature#to_kelvin` metódust, amely egy `celsius` argumentumot kap, és úgy adja vissza a hőmérsékletet Kelvinben, hogy a megadott `celsius` értékhez hozzáad 273,15-öt.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. A hőmérséklet kerekítése

Az időjárásállomás hőmérséklet-érzékelője pontos.
A hőmérsékletet 0,0001 °C pontossággal tudja mérni.
Az időjárásállomás csak 1 tizedesjegyre kerekítve szeretné megjeleníteni a hőmérsékletet, mivel a legtöbb felhasználót nem érdekli ez a pontossági szint.

Az időjárásállomás szeretné, ha készítenél egy metódust, amely 1 tizedesjegyre kerekíti a hőmérsékletet.

Készítsd el a `Temperature#round` metódust, amely egy `celsius` argumentumot kap, és 1 tizedesjegyre kerekítve adja vissza a hőmérsékletet.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. A hőmérséklet átváltása Celsiusról Fahrenheitre

Az időjárásállomás weboldalán van egy szakasz, amelyet a turistáknak szántak.
A turistákat a Fahrenheitben mért hőmérséklet érdekli.

A Fahrenheit a hőmérséklet mérésének mértékegysége.
Más skálán alapul, mint a Celsius.
A 0 °C 32 °F-nak felel meg, és 1 Celsius-fok 1,8 Fahrenheit-fokkal egyenlő.

Az alábbi táblázat a Celsius és a Fahrenheit közötti átváltást mutatja:

| Celsius (°C) | Fahrenheit (°F) |
| ----------- | -------------- |
| -273,15     | -459,8         |
| -100        | -148           |
| 0           | 32             |
| 100         | 212            |

Az időjárásállomás szeretné, ha készítenél egy metódust, amely átváltja a hőmérsékletet Celsiusról Fahrenheitre.

Készítsd el a `Temperature#to_fahrenheit` metódust, amely egy `celsius` argumentumot kap, és a hőmérsékletet Fahrenheitben, egész számként adja vissza.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. A hiányzó érzékelők számának meghatározása

A hőmérséklet-érzékelők telepítése közben a karbantartók észrevették, hogy néhány érzékelő hiányzik.
Minden hőmérsékletmérő egységhez négy hőmérséklet-érzékelő kell.
A karbantartócsapat megszámolta, hány érzékelőjük van, de tudniuk kellett azt is, hány hiányzik.
Segítséget kérnek annak kiszámításához, hány érzékelőt kell venniük egy újabb teljes hőmérsékletmérő egység összeállításához.

Készítsd el a `Temperature#number_missing_sensors` metódust, amely egy `number_of_sensors` argumentumot kap, és visszaadja a hiányzó érzékelők számát.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
