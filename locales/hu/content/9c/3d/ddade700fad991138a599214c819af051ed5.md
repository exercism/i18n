# Bevezetés

A Go-ban minden változónak van értéke.
Ha egy változót értékadás nélkül deklarálsz, az a típusa nullaértékét kapja.

Az alapvető típusoknak, köztük a `bool`-nak, a numerikus típusoknak és a `string`-nek rögzített nullaértéke van:

| Típus                  | Nullaérték |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64, stb. | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

A mutatók, a függvények, az interfészek, a szeletek, a csatornák és a mapek nullaértéke `nil`.

A tömbök és a structok soha nem `nil`-ek, mert az adatot közvetlenül tárolják, nem pedig egy rá mutató referenciát.
A tömb minden eleme és a struct minden mezője a saját típusa nullaértékét veszi fel.
Például a `var a [3]int` a `[0, 0, 0]` tömböt hozza létre.

## Nullaértékek deklarálása

Deklaráláshoz használd a `var` kulcsszót:

```go
var myBool bool   // false
var mySlice []int // nil
```

Structokhoz használd a `T{}` összetett literált:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
