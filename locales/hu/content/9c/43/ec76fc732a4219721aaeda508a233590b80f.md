# Bevezetés

A tömbök a Factor elsődleges, rögzített hosszúságú sorozattípusai, amelyeket `{ … }` formában írunk le: az elemeket megváltoztathatod, a hosszúságot viszont nem. Az `arrays` és a `sequences` szókészlet együtt kis konstruktorokat ad, amelyek leveszik az értékeket a veremből, emellett mindennapi műveleteket kínál az összefűzéshez, a megfordításhoz és az elemek kikereséséhez.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
