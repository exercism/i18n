# Bevezetés

A Factorban az adatok többsége *sorozatokban* található. A tömbök, a vektorok és a stringek mind sorozatok, és ugyanazokat a szavakat használják a [`sequences`][sequences] szótárból.

## Tömb-literálok

A literál tömb `{ }`-t használ, az elemeket szóköz választja el:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

A tömbök hossza rögzített, ezért az olyan szavak, mint a `suffix` és a `remove-nth`, amelyek megváltoztatják az elemek számát, egy *új* sorozatot adnak vissza ahelyett, hogy az eredetit bővítenék.

## Hossz és indexelés

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

A `?nth` a határokra biztonságos változat: anélkül kérdezhetsz le egy pozíciót, hogy előbb ellenőriznéd a hosszt.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## Szeletelés

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

Mindkettő hibát dob, ha `n` nagyobb a sorozatnál. Ha `n` túl nagy, az `index-or-length` a sorozat hosszára csökkenti, így az utána következő szelet nem futhat túl a sorozat végén:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

A csillagos változatok, a `head*` és a `tail*`, a végétől számolnak: a `head*` eldobja az utolsó `n` elemet, a `tail*` megtartja az utolsó `n` elemet:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

Tetszőleges, két index közötti szelethez a `subseq` a *kezdő* (beleértve) és a *záró* (kizárva) indexet várja:

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

Ha *kezdőindexed és hosszad* van, add össze őket, hogy megkapd a záró indexet:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(Ez a `[2, 5)` indexintervallum, azaz három karakter a 2-es pozíciótól kezdve.)

A fordított kérdésre, hogy *hol* fordul elő egy részsorozat, a `subseq-index` ad választ: visszaadja az első egyezés kezdőindexét, vagy `f`-et, ha nincs egyezés:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## Feltöltés

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

Mindkettő addig bővíti a `seq`-et, amíg annak hossza el nem éri legalább az `n`-t. Ha a `seq` már ilyen hosszú, változatlanul adja vissza.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## Ugyanezek a szavak működnek stringeken

A string karakterek sorozata, így a fentiek mind működnek stringeken is, az eredmény csupán egy újabb string lesz tömb helyett:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## Összesítés

A `sum` és a `product` (a [`sequences`][sequences] szótárban) összeadja, illetve összeszorozza egy numerikus sorozat elemeit:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

A `count` egy predikátumot futtat a sorozaton, és visszaadja, hogy hány elem tette igazzá:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## Predikátumok a teljes sorozaton

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## Új sorozat építése

A `suffix` egy elemet fűz a sorozat végéhez, a `prefix` pedig egyet az elejéhez. Az `unclip` lehántja az első elemet, az `unclip-last` pedig az utolsót:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

Az `unclip-last` és a `suffix` kombinálásával az utolsó elemet nem destruktív módon frissítheted (az `unclip` és a `prefix` ugyanezt teszi az elsővel):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## Átalakítás a sorozattípusok között

A `>array`, a `>vector` és a `>string` (a [`arrays`][arrays] szótárban és a hozzá tartozó szótárakban) egy adott konkrét típusba kényszerítik a sorozatot. Akkor hasznos, ha egy művelet szeletet vagy általános sorozatot adott vissza, és tömböt (vagy stringet) szeretnél visszakapni.

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
