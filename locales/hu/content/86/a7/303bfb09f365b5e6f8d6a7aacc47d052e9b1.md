# Tesztek

A tesztek futtatásához állítsd össze és futtasd egy adott feladat tesztfuttató fájlját vagy a MARS szimulátor grafikus felületén, vagy a parancssorban. A parancssorban való futtatáshoz először a tesztfuttató fájlt, majd a saját implementációdat add meg, így:

    java -jar /path/to/mars.jar nc runner.mips impl.mips

A grafikus felületen való futtatáshoz az utolsó sor megjegyzésjelének eltávolításával `include`-old a saját implementációdat a „runner.mips” alján.

A tesztfuttató vagy egy „success” üzenettel fejeződik be, vagy leáll egy sikertelen teszten egy olyan üzenettel, amely megadja, milyen bemenetre bukott meg az a teszt.
