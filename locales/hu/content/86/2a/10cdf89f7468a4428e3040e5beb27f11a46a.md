# Tippek

Ez a feladat olyan módosítható állapotot vizsgál, amely több szálból is biztonságosan elérhető. A Scala számos módot kínál a módosítható állapot védelmére. A Java párhuzamosságban jártas fejlesztők a Scala segítségével igénybe vehetik a Java párhuzamossági támogatást, például a Java synchronized blokkot.

## Gyakori buktatók

A Scalában kétféleképpen lehet módosítható állapotot létrehozni: használj „var”-t vagy egy módosítható objektumot.
Két gyakori hiba ezzel kapcsolatban:
- Ne használj olyan „var”-t, amely egyben módosítható objektum is. Az egyik elég, de a kettő együtt nem.
- Ne tedd ki a „var”-t vagy a módosítható objektumot a külvilág számára. Tehát tedd őket „private” láthatóságúvá, és alakítsd a módosítható objektumot módosíthatatlanná, mielőtt értékként visszaadnád.
