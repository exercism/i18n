# Kiegészítő utasítások

## Tippek

Meg kell valósítanod a `rotate` függvényt, amely egy `Int` és egy `String` értéket vesz át,
majd rotációs rejtjellel kódolja azt.
Ha nem vagy biztos a típusokban, nyugodtan használd a megadott szignatúrát, de ne hagyd,
hogy az korlátozza a kreativitásodat.

Ez a feladat szöveges adatokkal dolgozik. Történelmi okokból a Haskell `String` típusa
ugyanazt jelenti, mint a `[Char]`, azaz karakterek listája. A szöveges adatok hatékonyabb
kezelésére a `Text` típus használható.

A feladat opcionális kiterjesztéseként a következőket teheted:

- olvass a Haskell [stringtípusairól](https://haskell-lang.org/tutorial/string-types).
- add hozzá a `- text` sort a `package.yaml` függőségi listájához.
- importáld a `Data.Text` modult [a következő
  módon](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- használd a `Text` típust, pl. `rotate :: Int -> Text -> Text`, és a `Data.Text`
  kombinátoraira például `T.pack` néven hivatkozz.
- keresd meg a
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) dokumentációját.
- cseréld le a RotationalCipher.hs fájlban a `String` minden előfordulását `Text`-re, azaz:

```haskell
rotate :: Int -> Text -> Text
```

Ez a rész teljesen opcionális.
