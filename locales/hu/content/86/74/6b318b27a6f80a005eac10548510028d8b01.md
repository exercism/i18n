# Utasítások

Ebben a feladatban egy New York-i szépségszalon időpont-ütemezőjén fogsz dolgozni, amely 2012. szeptember 15-én nyílt meg.

Négy részfeladatod van, és mindegyik egy időpont dátumával foglalkozik. A dátumok és az időpontok a következő három formátum egyikét használják:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

A tesztek automatikusan `en-US`-ra állítják a kultúrát, neked nem kell beállítanod vagy megadnod.

## 1. Időpont dátumának értelmezése

Valósítsd meg a (_statikus_) `Appointment.Schedule()` metódust, amely egy időpont szöveges reprezentációját értelmezi a megfelelő `DateTime` formátumba:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Annak ellenőrzése, hogy egy időpont már elmúlt-e

Valósítsd meg a (_statikus_) `Appointment.HasPassed()` metódust, amely egy időpont dátumát kapja, és ellenőrzi, hogy az időpont a múltban volt-e:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Annak ellenőrzése, hogy az időpont délutánra esik-e

Valósítsd meg a (_statikus_) `Appointment.IsAfternoonAppointment()` metódust, amely egy időpont dátumát kapja, és ellenőrzi, hogy az időpont délutánra esik-e (>= 12:00 és < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Az időpont dátumának és idejének leírása

Valósítsd meg a (_statikus_) `Appointment.Description()` metódust, amely egy időpont dátumát kapja, és visszaad egy leírást arról a dátumról és időről:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Az évforduló dátumának visszaadása

Valósítsd meg a (_statikus_) `Appointment.AnniversaryDate()` metódust, amely az idei évforduló dátumát adja vissza, ami szeptember 15-re esik:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
