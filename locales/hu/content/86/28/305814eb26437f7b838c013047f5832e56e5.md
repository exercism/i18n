# Bevezetés

Gyakran nagyon fontos tudni, hogy egy adat milyen típusú, hogy a kód gördülékenyen és hibák nélkül fusson.

A JavaScriptben többféleképpen is ellenőrizheted egy érték vagy objektum típusát.

```exercism/note
A JavaScript típusellenőrző mechanizmusai némileg megbízhatatlanok lehetnek.

A jobb típusbiztonság és az erősebb típusok érdekében valószínűleg a TypeScriptet érdemes használnod; ez egy olyan nyelv, amely a JavaScriptre épül, de egy statikusan típusos nyelv típusszintaxisával.
```

## A `typeof` operátor

A `typeof` operátor visszaadja az operandusa típusát.
A kimenet egy string, amely megegyezik az egyik [primitív adattípus][primitives] nevével, kivéve a `"null"` esetét.
Emellett `"function"` vagy `"object"` is lehet.

```javascript
typeof undefined;
// => "undefined"

typeof true;
// => "boolean"

typeof 42;
// => "number"

typeof 'Hello, World!';
// => "string"

typeof function () {
  return 'Hello, World';
};
// => "function"

typeof [1, 2, 3, 4];
// => "object"

typeof { city: 'Stockholm', country: 'Sweden' };
// => "object"
```

[Történelmi okokból][`typeof null` is `"object"`].

## Az `instanceof` operátor

Egy objektum típusának ellenőrzésére az `instanceof` operátort használhatod.
Az eredménye egy `boolean` érték attól függően, hogy a második operandus szerepel-e az első operandus [prototípusláncában][prototype chain].
Pontosabban, az `instanceof` azt adja vissza, hogy az első operandus a második operandusnak vagy annak valamelyik leszármazott osztályának a példánya-e.
Az `instanceof` csak objektumokon működik.

```javascript
class Beverage {
  // ...
}

// The Coffee class is a child of the Beverage class.
class Coffee extends Beverage {
  // ...
}

const java = new Coffee();

java instanceof Coffee;
// => true

java instanceof Beverage;
// => true
```

````exercism/advanced
Az `Array` osztálynak van egy `Array.isArray()` nevű metódusa, amely azt ellenőrzi, hogy az argumentuma tömb-e.

Bár az `instanceof Array` nem működik egy másik realmben létrehozott tömbbel, például egy weboldal `iframe`-jével, az `Array.isArray()` igen.

Ez azért van, mert az Array osztálynak minden realmben más a konstruktora, és minden `iframe`-nek saját realmje van, ami azt jelenti, hogy a prototípusláncban lévő függvény is más lesz, és emiatt az `instanceof Array` nem fog működni.
Az `Array.isArray()` képes ezt figyelmen kívül hagyni, és lehetőség szerint mindig ezt érdemes használni.

Az olyan téves pozitívokat is kiszűri, amikor egy objektum valójában nem `Array`, csupán az `Array` szerepel a prototípusláncában.

```javascript
({ __proto__: Array.prototype }) instanceof Array
// => true

Array.isArray({ __proto__: Array.prototype })
// => false
```

````

## Az `in` operátor

Az `in` operátor azt adja vissza, hogy az első operandus a második operandus tulajdonsága-e.
Nem ellenőrzi, hogy a tulajdonságnak van-e definiált értéke.
Egy `undefined` értékre állított tulajdonságot az `in` így is észlel.

```javascript
class Coffee {
  constructor() {
    this.temperature = 'hot';
    this.isDarkMatter = undefined;
  }

  coolDown() {
    this.temperature = 'warm';
  }
}

const espresso = new Coffee();

'temperature' in espresso;
// => true

'color' in espresso;
// => false

'isDarkMatter' in espresso;
// => true
```

````exercism/note
Az `in` `true`-t ad vissza az örökölt tulajdonságokra és metódusokra is.

```javascript
"coolDown" in espresso
// => true

"constructor" in espresso
// => true
```
````

## Az `Object.hasOwn()` függvény

Az `Object.hasOwn()` metódus azt adja vissza, hogy a megadott objektum _rendelkezik-e a megadott tulajdonsággal_ (azaz a tulajdonság nem örökölt és nem metódus).

```javascript
class Coffee {
  constructor() {
    this.temperature = 'hot';
  }

  coolDown() {
    this.temperature = 'warm';
  }
}
const cappuccino = new Coffee();

Object.hasOwn(cappucino, 'temperature');
// => true

Object.hasOwn(cappucino, 'constructor');
// => false

Object.hasOwn(cappucino, 'coolDown');
// => false
```
