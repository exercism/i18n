# Utasítások

Jól megy a new york-i szépségszalon, amelynek a Booking Up For Beauty feladatban segítettél, és sok vendége lett törzsvendég.
A törzsvendégek nem külön foglalnak minden egyes alkalomra, hanem állandó megállapodásuk van: „minden második kedd”, „a hónap utolsó péntekje” és így tovább.
A tulajdonos kért tőled egy segédet, ami kiszámolja ezeknek a megállapodásoknak a dátumait, valamint a szalon saját havi rutinjának dátumait is.

## 1. Keresd meg egy törzsvendég állandó időpontját

Készítsd el a `SalonCalendar.standingAppointment()` metódust, amely egy évet, egy hónapot, egy előfordulást (`1` az első, `2` a második, és így tovább) és egy hét napját kap.
A metódus visszaadja a hét adott napja adott előfordulásának dátumát a hónapon belül:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. Keresd meg egy törzsvendég hónap végi időpontját

Néhány törzsvendég inkább a hónap utolsó, a saját napjára eső időpontját választja.
Készítsd el a `SalonCalendar.lastAppointment()` metódust, amely egy évet, egy hónapot és egy hét napját kap, és visszaadja a hét adott napja utolsó előfordulásának dátumát a hónapon belül:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. Keresd meg a következő szabad napot egy bejelentkezés nélkül betérő vendégnek

Egy vendég a recepción a „következő szombatot” kéri.
Ha épp szombaton kérdezi, akkor magára aznapra gondol.
Készítsd el a `SalonCalendar.nextAvailable()` metódust, amely egy dátumot és egy hét napját kap, és visszaadja az első olyan dátumot, amely nem korábbi a megadott dátumnál, és a hét adott napjára esik:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. Keresd meg a könyvelési napot

A szalon minden hónap utolsó napján zárja a könyvelést.
Hétvégén azonban zárva van, ezért ha a hónap utolsó napja szombatra vagy vasárnapra esik, a könyvelést az előtte lévő pénteken zárják.
Készítsd el a `SalonCalendar.bookkeepingDay()` metódust, amely egy évet és egy hónapot kap, és visszaadja az adott hónap könyvelési napját:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. Használd újra a hétvégi szabályt a fizetésnaphoz

A munkatársak fizetése minden hónap 15-én van, ugyanezzel a hétvégi szabállyal: ha a 15. szombatra vagy vasárnapra esik, a fizetésnap az előtte lévő péntek.
Ahelyett, hogy másodszor is leírnád a szabályt, alakítsd újrahasznosítható korrekcióvá.

Készítsd el a `SalonCalendar.precedingWorkday()` metódust, amely egy `TemporalAdjuster` példányt ad vissza: ez a hétköznapot változatlanul hagyja, a szombatot vagy a vasárnapot pedig visszaviszi az előtte lévő péntekre.
Ezután készítsd el a `SalonCalendar.payday()` metódust, amely egy évet és egy hónapot kap, és ezt a korrekciót használja:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

Nyugodtan térj vissza, és használd ezt a korrekciót a `bookkeepingDay()` metódusban is.
