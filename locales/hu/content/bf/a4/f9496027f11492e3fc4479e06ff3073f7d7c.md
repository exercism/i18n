# Bevezetés

## Kommentek

Az Exercism x86-64 kurzusa a **NASM**-et (The Netwide Assembler) használja assemblerként.
A NASM-ben a kommenteket egy pontosvessző (`;`) vezeti be.

A kommentek a program bármely részén szerepelhetnek, és mindent, ami egy `;` után következik, figyelmen kívül hagy az assembler.

## Konstansok

A NASM-ben az **equ** segítségével definiálhatunk assembler-időben kiértékelt konstanst.
Ez például egy `UNIVERSE` nevű konstanst definiál `42` értékkel:

```x86asm
UNIVERSE equ 42
```

A konstansok értéke egyszer, a definiálásukkor kerül kiértékelésre, és később _nem_ definiálhatók újra.

## Általános célú regiszterek (GPR-ek)

Az assemblyben változók helyett jellemzően regisztereket használunk értékek tárolására.
A **CPU-regiszter** egy darab gyors memória a számítógép processzorában.
A számítások többsége a CPU regisztereiben zajlik.

Néhány regiszter sokféle számításhoz használható, ezeket **általános célú regisztereknek (GPR-ek)** nevezzük.
A többiek speciális vagy kijelölt célt szolgálnak.

Az x86-64-ben 16 darab 64 bites általános célú regiszter (GPR) van, amelyek 32, 16 vagy 8 bitesként is elérhetők.
A GPR-eket az alábbi táblázat írja le, ahol az `rn`-ben az `n` 8-tól 15-ig terjed: `r8`, `r9`, `r10`, `r11`, `r12`, `r13`, `r14` és `r15`.

| 64-bit | 32-bit | 16-bit | 8-bit |
| :----: | :----: | :----: | :---: |
|  rax   |  eax   |   ax   | ah/al |
|  rbx   |  ebx   |   bx   | bh/bl |
|  rcx   |  ecx   |   cx   | ch/cl |
|  rdx   |  edx   |   dx   | dh/dl |
|  rsi   |  esi   |   si   |  sil  |
|  rdi   |  edi   |   di   |  dil  |
|  rbp   |  ebp   |   bp   |  bpl  |
|  rsp   |  esp   |   sp   |  spl  |
|   rn   |  rnd   |  rnw   |  rnb  |

Ha 64 bitnél kevesebbet használunk, az elért bitek általában a regiszter alsó részéből származnak.
Kivételt jelentenek ez alól az `ah`, `bh`, `ch` és `dh` regiszterek, amelyek a regiszter 16 bites részének felső 8 bitjét érik el.

Az alábbi ábra azt mutatja, hogyan érhetők el a bitek a `rax` regiszter esetében:

```
+--------+---------------------------------------+
| 64-bit |                  rax                  |
+--------+-------------------+-------------------+
| 32-bit |                   |        eax        |
+--------+-------------------+---------+---------+
| 16-bit |                             |    ax   |
+--------+-----------------------------+----+----+
| 8-bit  |                             | ah | al |
+--------+-----------------------------+----+----+
```

Ezek közül néhány regisztert meg kell őrizni a függvényhívások során: `rbp`, `rsp`, `rbx`, `r12`, `r13`, `r14` és `r15`.
Ha nem őrizzük meg őket, az hibához vagy nem definiált viselkedéshez vezethet.

A többieket nem kell megőrizni, és szabadon használhatók: `rax`, `rcx`, `rdx`, `rdi`, `rsi`, `r8`, `r9`, `r10` és `r11`.

~~~~exercism/caution
A tanterv későbbi részében megtanulod, hogyan kell megőrizni a regisztereket.
Egyelőre csak a második típusú regisztereket használd: `rax`, `rcx`, `rdx`, `rdi`, `rsi`, `r8`, `r9`, `r10` és `r11`.
~~~~

## Utasítások

Az utasítások olyan műveletek, amelyeket a CPU végre tud hajtani.
Általában a következő formájuk van:

```x86asm
name destination, source
```

Az utasítás neve tehát az első, utána legalább egy szóköz következik, majd a céloperandus, egy vessző (`,`), végül pedig a forrásoperandus.
Az utasítás jellemzően nem módosítja a forrásoperandust, csak a céloperandust.

Mindkét operandusnak ugyanakkora méretűnek kell lennie, kivéve, ha másképp szerepel.
A céloperandusnak például szintén 16 bitesnek kell lennie, ha a forrásoperandus 16 bites.

Ha például egy értéket szeretnénk egy regiszterben tárolni, a `mov` utasítást használhatjuk:

```x86asm
mov rax, rdx  ; rax = rdx
              ; mov is the name, rax is the destination operand and rdx is the source operand
```

A fenti kódrészlet a forrásoperandus, `rdx` mind a 64 bitjének tartalmát átmásolja `rax` mind a 64 bitjébe, amely az utasítás céloperandusa.

A legtöbb utasításnál a forrásoperandus lehet konstans egész szám is (a céloperandus viszont nem):

```x86asm
mov rcx, 42 ; rcx = 42
            ; rcx is the destination operand and 42 is the source operand
```

Figyeld meg, hogy egy 32 bites regiszterbe írva a felső bitek is törlődnek, így a `mov eax, 42` ugyanaz, mint a `mov rax, 42`.
Ez a 16 és 8 bites regiszterekre nem igaz.

Az összeadás, kivonás és szorzás aritmetikai műveleteihez az `add`, `sub` és `imul` utasításokat használhatjuk:

```x86asm
add rax, rsi ; rax = rax + rsi
imul rax, rdi ; rax = rax * rdi
sub rax, r8 ; rax = rax - r8
```

## Függvények

Az utasítások függvényekbe szerveződnek.
Minden függvény a forrásfájl **section .text** részében kap helyet.

Egy függvény deklarációja a következőkből áll:

1. Egy címke a függvény nevével, utána egy `:`.
2. A függvényt megvalósító utasítások.
3. A visszatérési utasítás, a `ret`.

Ez a kurzus a System V AMD64 ABI hívási konvenciót használja, amelyben a függvénynek átadott első hat egész argumentum regiszterekben érkezik.
Ezek sorrendje a következő: `rdi`, `rsi`, `rdx`, `rcx`, `r8` és `r9`.

A függvény a visszatérési egész értéket a `rax` regiszterben adja vissza.

Egy függvény meghívásához a `call` utasítást használjuk.
Egy függvényt ugyanazon forrásfájl bármely pontjáról meg lehet hívni.
Ahhoz, hogy egy függvény más forrásfájlok számára is látható legyen, a `global` direktívát kell használni.

Ez például deklarál egy `sum` függvényt:

```x86asm
section .text ; functions are placed here

global sum ; sum is visible to other source files

sum:
    ; first argument is passed in rdi
    ; second argument is passed in rsi
    ; return value is placed in rax

    mov rax, rdi ; rax is now equal to rdi
    add rax, rsi ; rax = rax + rsi

    ret ; function return
```

Az alábbi kód pedig meghívja a `sum` függvényünket a 3 és 5 argumentummal:

```x86asm
mov rdi, 3  ; First argument in rdi
mov rsi, 5  ; Second argument in rsi
call sum

; The rax register now contains the value 8 (3 + 5), after sum returns
```
