# Bevezetés

A [`list`][list] egy módosítható gyűjtemény, amely elemeket tárol _sorrendben_.
 A legtöbb gyűjteményhez hasonlóan (_lásd a beépített [`tuple`][tuple], [`dict`][dict] és [`set`][set] típusokat_), a listák bármilyen (vagy akár többféle) adattípusra tárolhatnak hivatkozást, beleértve a többi listát is.
 A listák egészben vagy részben átmásolhatók [szeletelési jelöléssel][slice notation] vagy a `<list>.copy()` használatával.
 Ahogy bármelyik [sorozat][sequence type] esetében, a `lists` elemeire balról `0-based index` számmal, jobbról pedig `-1-based index` számmal hivatkozhatsz.

A listák mind az [általános][common sequence operations], mind a [módosítható][mutable sequence operations] sorozatműveleteket támogatják, például a `min(<list>)`/`max(<list>)`, a `<list>.index()`, a `<list>.append()` és a `<list>.reverse()` műveletet.
 A `list` elemein a `for item in <list>` szerkezettel iterálhatsz végig.
 A `for index, item in enumerate(<list>)` akkor használható, ha egyszerre van szükséged az elem indexére és az értékére is.

A Python emellett számos hasznos [lista-metódust][list-methods] is kínál a listákkal való munkához.
 Ezek közül a `list methods` néhányát az alábbiakban mutatjuk be.


Vedd figyelembe, hogy amikor egy `list-method` segítségével módosítasz egy `list` objektumot, **magát az átadott listát változtatod meg**.
 Ha nem szeretnéd módosítani az eredeti `list` objektumot, legalább egy `shallow copy`-t kell készítened róla szeleteléssel vagy a `<list>.copy()` hívásával.


## Elemek hozzáadása

Ha egy meglévő lista végére, azaz a „jobb oldalára” szeretnél elemet hozzáadni, használd a `<list>.append(<item>)` metódust:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

A `<list>.insert()` nem a végére fűzi az elemet, hanem lehetővé teszi, hogy a lista egy _adott indexére_ szúrd be.
Két paramétert vár:

1. az `<index>`, ahová az elemet be szeretnéd szúrni.
2. a beszúrandó `<item>`.

**Megjegyzés**: Ha a megadott `index` 0, az elem a `list` elejére (a „bal oldalára”) kerül.
 Ha a megadott `index` nagyobb, mint a `list` utolsó `index`e, az elem az utolsó helyre kerül, ami megegyezik a `<list>.append(<item>)` használatával.


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


A `<list>.extend(<item>)` egy meglévő lista összefűzésére használható egy másik iterálható objektum elemeivel (például `set`, `tuple`, `str` vagy `list`).
  Az iterálható objektum _kicsomagolásra_ kerül, és az elemei sorban hozzáfűződnek (_ha ilyenkor a `<list>.append(<item>)` metódust használnád, a teljes iterálható objektum **egyetlen elemként** kerülne be._).


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## Elemek eltávolítása

Egy elem törléséhez a listából használd a `<list>.remove(<item>)` metódust, és add át argumentumként az eltávolítandó elemet.
 A `<list>.remove(<item>)` `ValueError` kivételt dob, ha az elem nem szerepel a `list`-ben.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


A `<list>.pop(<index>)` metódus ezzel szemben az elemet **eltávolítja**, és a `return` segítségével vissza is adja, hogy felhasználhasd.


A `<list>.pop(<index>)` egy opcionális paramétert vár: az eltávolítandó és visszaadandó elem `index`ét.
 Ha az (opcionális) `index` argumentumot nem adod meg, a `list` utolsó eleme kerül eltávolításra és visszaadásra.
 Ha a megadott `index` nagyobb, mint az utolsó elem `index`e, `IndexError` kivétel keletkezik.


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

A `list` összes eleme eltávolítható a `list.clear()` metódussal. Ez nem vár paramétert.

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## Megfordítás és átrendezés

A `<list>.reverse()` metódus **helyben** megfordítja az elemek sorrendjét.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


Egy lista _**helyben**_ átrendezhető a [`<list>.sort()`][sort] segítségével.
Az alapértelmezett rendezési sorrend balról nézve _növekvő_.
A Python dokumentációja [további tippeket és technikákat kínál a rendezéshez][sorting how to].

~~~~exercism/note
 2002 és 2022 között a Python belsőleg egy [`Timsort`][timsort] nevű algoritmust használt a listák elrendezésére, a `Python 3.11`-től kezdve viszont a [`Powersort`][powersort] nevű algoritmusra váltott.

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Ha _csökkenő_ sorrendet szeretnél, add át a `reverse=True` argumentumot:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

Ha nem szeretnéd módosítani az eredeti listát, a beépített [`sorted(<iterable>)`][sorted] függvénnyel egy rendezett **másolatot** kaphatsz.


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## Egy elem előfordulásainak száma egy listában

Egy elem listában való előfordulásainak számát a `list.count(<item>)` segítségével számolhatod ki.
 Argumentumként a megszámolandó `item`-et várja, és visszaadja, hogy az adott elem összesen hányszor szerepel a `list`-ben.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## Elemek indexének megkeresése

A `<list>.index(<item>)` visszaadja az átadott elem _első előfordulásának_ `index` számát.
 Ha nincs előfordulás, `ValueError` kivétel keletkezik.
 Ha nincs szükséged az elem pontos pozíciójára, a beépített `in` operátor hatékonyabb annak ellenőrzésére, hogy egy lista tartalmaz-e egy adott értéket.


Az indexelés balról nullától indul, tehát az „első” elem pozíciója `0`.
Jobbról is indexelhetsz, ott a `-1`-től indul.


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

A `start` és `end` indexek megadásával a keresést a `list` egy adott szakaszára szűkítheted:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
