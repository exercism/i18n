# CLI

## Beállítás

A Purescript telepítésének legegyszerűbb módja a Node.js és az NPM használata.

Ha még nincs telepítve a Node.js a gépeden, letöltheted a [Node.js weboldaláról][nodejs-website]. Amint a Node.js fut, írd be ezt a parancsot a terminálba a PureScript fordító, valamint a Spago csomagkezelő és buildeszköz telepítéséhez.

```shell
npm install -g purescript spago
```

További információkat a [PureScript tárolójában][purescript-repository] találsz.

## Követelmények

Telepítsd a feladat függőségeit:

```shell
spago install
spago build
```

## A tesztek sikeres teljesítése

A teszteket a következővel futtathatod:

```shell
spago test
```

A tesztkészletekben az első kivételével minden teszt ki van kapcsolva. Ez segít abban, hogy a feladatot lépésről lépésre oldd meg.

Amint egy teszt sikeresen lefut, a következőt úgy kapcsolhatod be, hogy a `xit`-et `it`-re változtatod.

## A megoldás beküldése

Amint már egy teszt sincs kikapcsolva, és mindegyik sikeresen lefut, a következővel küldheted be a megoldásodat:

```shell
exercism submit src/<NAME>.purs
```

## Saját tesztek írása

Ha további, saját teszteket szeretnél írni, hozz létre egy új `test/Custom.purs` fájlt, és a megoldásoddal együtt küldd be az új fájlt is:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
