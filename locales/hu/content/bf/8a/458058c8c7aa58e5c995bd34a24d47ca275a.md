# Bevezetés

Eddig azt láttuk, hogy a metódusnak átadott argumentumok a metódusban deklarált paraméterekhez pozíciójuk alapján párosulnak. Más megközelítés is akad: ha egy rutin különösen sok argumentumot vár, a hívó a deklarált paraméter azonosítójának megadásával is párosíthatja az argumentumokat.

A következő példa a szintaxist mutatja be:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
