# Bevezetés

Pythonban [az `enum`][enum-docs] olyan nevek halmaza, amelyek egyedi `literal` vagy `constant` értékekhez vannak kötve.
Az `Enums` típusokat úgy definiálod, hogy egy `Enum` osztályból örökölsz vagy annak alosztályát hozod létre.
A beépített `enum` típusok az `enum` modulban érhetők el, az `Enum` osztályt pedig a `from enum import Enum` utasítással importálhatod.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

Jegyezd meg, hogy az `enum` tagjainak értékei bármilyen adattípusúak lehetnek, például `str`, `tuple`, `float` stb.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Ha ugyanazt az értéket rendeled egy `enum` két tagjához, a később hozzárendelt tag a korábbi tag álneve lesz. Nem használhatod ugyanazt a nevet egy `enum` két különböző tagjánál.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Az `enum` tagjain a szokásos `for member in` szintaxissal iterálhatsz:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Az `Enum` tagjai összehasonlíthatók a [`is` (_identitás operátor_)][identity-keyword] vagy az `is not` segítségével. A `==` vagy `!=` (_egyenlőségi operátorok_) ugyanígy működnek:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Egy adott értékhez tartozó `enum` tagot a `<EnumName>(<value>)` hívással érhetsz el:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
