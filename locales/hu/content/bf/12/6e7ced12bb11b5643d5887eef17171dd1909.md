# Utasítások

Leendő varázslóként Elyse-nek gyakorolnia kell néhány alapvető dolgot. Van egy pakli kártyája, amit szeretne kezelni.

Hogy kicsit könnyebb legyen, csak az 1-től 10-ig terjedő kártyákat használja.

A kártyapaklit egy `queue` reprezentálja, ahol a pakli alja a sor elején, a pakli teteje pedig a sor végén van.

## 1. Kártya beszúrása a pakli tetejére

Valósítsd meg az `insert_top` függvényt, amely a pakli egy másolatát adja vissza úgy, hogy a megadott új kártya a pakli tetejére kerül.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. A felső kártya eltávolítása a pakliból

Valósítsd meg a `remove_top_card` függvényt, amely a pakli egy másolatát adja vissza úgy, hogy a felső kártyáját eltávolítottad belőle. Ha a megadott pakli üres, az eredeti paklit kell visszaadni, változatlanul.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. Kártya beszúrása a pakli aljára

Valósítsd meg az `insert_bottom` függvényt, amely a pakli egy másolatát adja vissza úgy, hogy a megadott új kártya a pakli aljára kerül.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. Kártya eltávolítása a pakli aljáról

Valósítsd meg a `remove_bottom_card` függvényt, amely a pakli egy másolatát adja vissza úgy, hogy az alsó kártyáját eltávolítottad belőle. Ha a megadott pakli üres, az eredeti paklit kell visszaadni, változatlanul.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. A pakli méretének ellenőrzése

Valósítsd meg a `check_size_of_stack` függvényt, amely ellenőrzi, hogy a pakli mérete megegyezik-e a megadott `stack_size` értékkel vagy sem.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
