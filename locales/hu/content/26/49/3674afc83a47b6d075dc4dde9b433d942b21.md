# Telepítés

Ez a kurzus végig a [Wren Console][wren-console]-ra épül, hogy helyi futtatókörnyezetet biztosítson a Wrenhez. Ez azt jelenti, hogy feltételezzük: a számítógépeden minden Wren-futtatás a [Wren Console][wren-console] segítségével történik. Kérünk, ne keverd össze ezt a hivatalos Wren <abbr title="parancssori felület">CLI</abbr>-vel. Egy tökéletes világban használhatnád azt a futtatókörnyezetet, de jelenleg [számos](https://github.com/wren-lang/wren/pull/1006) [különböző](https://github.com/wren-lang/wren-cli/issues/108) [problémája](https://github.com/wren-lang/wren-cli/pull/105) [van](https://github.com/wren-lang/wren-cli/pull/74), így kevésbé ideális választás, ha az Exercismmel szeretnél Wrent tanulni.

A Wren Console a Wren CLI egy forkja, ami megoldja ezeket a problémákat, és olyan funkciókat ad hozzá, amelyek gördülékenyebbé teszik a tanulást. Ne aggódj: az itt megszerzett Wren-tudás és fogalmak a jövőben bárhol érvényesek lesznek, ahol Wrent szeretnél használni.

## A telepítés áttekintése

- Telepítsd a Gitet a `git` parancshoz
- Telepítsd a [Wren Console][wren-console]-t a `wrenc` parancshoz

### A Git telepítése

Telepítened kell a `git` binárist, és elérhetővé kell tenned a PATH-ban. A Wren Package így telepíti a csomagokat (például a feladataid teszteléséhez szükséges tesztkészletet).

- **Windows** - A hivatalos [Git-letöltés](https://git-scm.com/download/win) jó kiindulópont.
-  **Linux** - A kedvenc csomagkezelőd segít majd.
- **Mac** - A Mac OS minden újabb verziója alapból tartalmazza a `git`-et.

A `git --version` paranccsal ellenőrizheted, hogy a Git telepítve van-e:

```
$ git --version
git version 2.31.1
```

Ne aggódj, ha nem pontosan ez a verziószám jelenik meg, ez általában nem annyira kritikus.


### A Wren Console telepítése

#### Windows

Valószínűleg a [legújabb kiadást][releases] érdemes letöltened a GitHubról. Ezután ki kell tömörítened, és a `wrenc` futtatható fájlt a PATH-ba kell másolnod.

Visual Studio segítségével az is lehetséges, hogy [forrásból építsd fel][build-from-source].

#### Linux

[Letöltheted a legújabb kiadást][releases] a GitHubról, vagy [felépítheted forrásból][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

És gondoskodj róla, hogy elérhető legyen a `PATH`-ban.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

A legegyszerűbb telepítés az Exercism [Homebrew][homebrew] tapjének és formulájának a használata:

```
brew tap exercism/wren
brew install wren-console
```

Másképp megteheted, hogy [letöltöd a legújabb kiadást][releases] a GitHubról, és a Linuxnál leírtak szerint manuálisan telepíted. Ha jártas vagy az ilyesmiben, a forrásból való felépítés is meglehetősen egyszerű.

### A telepítés ellenőrzése

Miután úgy gondolod, hogy a bináris rendben telepítve van, érdemes letesztelni, hogy minden működik-e.

1. Nyiss meg egy _terminált_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. Futtasd a `wrenc -v` parancsot

Mind a `wrenc`, mind a Wren verziójának meg kell jelennie:

```
wrenc v0.3.1 (wren v0.4.0)
```

**Megjegyzés**: Fontos, hogy _új_ terminálablakot nyiss. A már nyitva lévő terminálablakok lehet, hogy nem frissültek a telepítés befejezése után. Emiatt ezek a nyitott terminálok nem tudják, hogy új program települt.

> _**Segítség**_: `'wrenc' is not recognised`
>
> Valószínűleg nem tetted a `wrenc`-et a PATH-ba... MacOS-en és Linuxon módosíthatod az elérési utad, ha a következőt hozzáadod a `~/.bash_profile` vagy a `~/.zshrc` fájlhoz:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **Fogalmam sincs, hogy ebből bármi helyes-e.**
> Windowson nyisd meg a Start menüt, és keress rá a „environment variables” kifejezésre. Itt szerkesztened kell a `PATH` bejegyzést, és _hozzáadnod_ a `wrenc` binárisok elérési útját.
> Általában ezek a `C:\Program Files\nodejs` mappában találhatók. Ha a `File Explorer`rel ide navigálsz, itt kell lennie a `node.exe`, `npm.bat` és `npx.bat` fájlnak.
>
> Csukd be a nyitott terminálokat, és nyiss egy újat.

## A feladatok követelményei

Az operációs rendszeredhez kövesd [ezeket az utasításokat][cli-walkthrough], hogy letöltsd az `exercism` CLI-t.

Miután a CLI be van állítva és konfigurálva, töltsd le az első feladatot, a `hello-world`-öt:

```bash
$ exercism download --exercise=hello-world --track=wren
```

Ezután minden feladathoz néhány Wren-csomagra van szükség a tesztek futtatásához. Ezeket úgy telepítheted, hogy a feladat könyvtárában futtatod a következő parancsot:

```bash
$ wrenc package.wren install
```
