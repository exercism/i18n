# Kiegészítés az utasításokhoz

## Szavak

Valósítsd meg:

- `grep ( pattern flags files -- lines )`

A `pattern` a keresett string, a `flags` egy tömb, amely nulla vagy több flag stringet tartalmaz: `"-n"`, `"-l"`, `"-i"`, `"-v"` és `"-x"`, a `files` pedig egy vagy több fájlnevet tartalmazó tömb. Add vissza az egyező sorokat (a kért fájlnév- és sorszám-előtagokkal együtt) stringek tömbjeként.

Ha a `-l` flag meg van adva, add vissza azon fájlok neveinek tömbjét, amelyek legalább egy egyezést tartalmaznak.

## Fájlok beolvasása

Olvasd be egy fájl sorait a `file-lines` függvénnyel, és adj meg egy kódolást:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

A három mellékelt fájl (`iliad.txt`, `midsummer-night.txt` és `paradise-lost.txt`) a feladattal együtt a munkakönyvtárban van, így elég a nevük alapján beolvasni őket.
