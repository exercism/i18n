# A fogalomról

A Swiftbeli [closure-ok][closures] önmagukban álló kódblokkok, amelyek paramétereket kaphatnak a számításuk elindításához, és értéket adnak vissza.
A closure-ok emellett értékeket rögzítenek a környezetükből, és felhasználják azokat a számításaikban.
Mivel önmagukban állnak, a programban úgy adhatók tovább, mint bármely más érték, illetve konstansokhoz és változókhoz rendelhetők.

A closure-ok elsőre nagyon hasonlíthatnak a Swift-függvényekhez, és ez valóban így van, méghozzá jó okkal.
A Swift-függvények a closure-ok speciális esetei: kötelező nevük van, és némileg más szintaxissal definiáljuk őket.

Bár a Swift-függvények technikailag closure-ok, amikor az emberek Swiftben „closure-okról” beszélnek, általában a [closure-kifejezésekre][closure-expressions] gondolnak.
A closure-kifejezés egy paraméterlista, amelyet a visszatérési típus, majd az `in` kulcsszó és a closure törzse követ, az egész pedig kapcsos zárójelpárba kerül:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Ez egy `(Double, Double) -> Double` típusú closure-kifejezést definiál, amely ugyanúgy végrehajtható, mint egy ilyen típusú függvény: alkalmazd a megfelelő típusú paraméterekre.

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Mivel nem túl kényelmes minden alkalommal kiírni a teljes closure-kifejezést, amikor végre akarjuk hajtani, a closure-ok nevekhez rendelhetők, akárcsak a Swift bármely más értéke.
Ezután a névre alkalmazva a paramétereket hívhatók meg:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Ahogy fentebb látható, a closure-ok a hagyományos függvényekhez hasonlóan elhagyhatják a `return` kulcsszót, ha a closure törzse egyetlen kifejezésből áll.

Leggyakrabban a closure-okat magasabb rendű függvényekkel együtt használjuk, akár paraméterként átadva, akár visszatérési értékként:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## A closure-típusok kikövetkeztetése

Ha a visszatérési típus vagy a paramétertípusok [a kontextusból kikövetkeztethetők][inferring-closure-types], akkor elhagyhatók a closure-kifejezésből.
Sőt, ha a paramétertípusok elhagyhatók, akkor a paraméternevek körüli zárójel is elhagyható:

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- Az első példában a típus a `mean` konstans típusmegjelöléséből következtethető ki.
- A másodikban a fordító a `makeAdder` definíciójából tudja, hogy a `base` egy int, és hogy a visszaadott függvény típusa `(Int) -> Int` kell legyen. Ebből meg tudja állapítani, hogy ha `x` egy `Int`, akkor a closure típusa `(Int) -> Int` lesz, így elhagyhatjuk a típusmegjelölést a closure-ban, hiszen a `(Int) -> Int` az egyetlen lehetséges érvényes szignatúra, amivel a closure rendelkezhet.
- A harmadik példa hasonló, de itt a fordítónak a típusinformáció egy részét abból a tömbből kell merítenie, amelyre a metódust alkalmazzuk. Tudja, hogy a `sorted(by:)` metódus paraméterként egy olyan closure-t vár, amelynek két paramétere ugyanolyan típusú, mint a rendezett gyűjtemény elemei, és amely `Bool`-t ad vissza, így a fordító kikövetkeztetheti, hogy a closure visszatérési típusa `Bool` kell legyen. És mivel a metódust egy String-tömbön használjuk, megállapíthatja, hogy az `s1` és `s2` paraméterek típusa is `String`.

## A closure-ok korlátai

Ahogy fentebb említettük, a függvények és a closure-ok nagyon hasonlóak a Swiftben, de van néhány fontos különbség:

- A closure-ok nem használhatnak külső argumentumcímkéket. Nincs mód ezek definiálására, és ha a closure meghívásakor egy paraméter nevét próbálod használni, az hibát eredményez:

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- A closure paramétereinek nem lehet alapértelmezett értékük.
- A closure paraméterei lehetnek variadikus paraméterek, de ekkor névvel és típusmegjelöléssel kell rendelkezniük.
