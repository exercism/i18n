# Bevezetés

A metódus egy függvény, amelynek van egy speciális _receiver_ argumentuma.
A receiver a saját argumentumlistájában jelenik meg, a `func` kulcsszó és a metódus neve között.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

Csak olyan receiverrel definiálhatsz metódust, amelynek típusa ugyanabban a csomagban van definiálva, mint maga a metódus.

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

Kétféle receiver létezik: érték receiver és pointer receiver.

Az érték receiverrel rendelkező metódusok a kapott érték egy másolatán dolgoznak, ami azt jelenti, hogy a metóduson belül a receiveren végzett módosítások nem láthatók a hívó számára.

Azért, hogy módosítani tudd azt az értéket, amelyre a receiver mutat, pointer receiverrel is deklarálhatsz metódusokat.
Ezt úgy csinálod, hogy a típusnév elé egy `*`-ot teszel; például a `rect` típus esetében a pointer receivert `*rect`-ként deklarálod.
Az ilyen módosítások a metódus hívója számára is láthatók.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
