# Bemutatás

A [`throw` kifejezések][throw-expressions] a `throw` utasítások alternatívái, és különösen a ternáris és más összetett kifejezések erejét növelhetik.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

Ha a fenti kódban a `str` értéke `null`, a program kivételt dob.

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
