# Utasítások

Mint szinte mindenkinek, akinek munkája van, Laylának, a Lisp-űrlénynek is néha jelentéseket kell készítenie, hogy másokat tájékoztasson. Arra kér, hogy segíts neki formázni azokat az adatokat, amelyek ezekhez a jelentésekhez a rendelkezésére állnak.

## 1. Negyedéves értékek formázása

Először is Laylának szüksége van egy függvényre: `format-quarter-value`, amely két paramétert vár: a naptári negyedévet és az értéket, és jelentéshez formázza őket. A függvény kiértékelésének eredménye egy string legyen.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. A két negyedévre vonatkozó jelentés

Layla megköszöni a `format-quarter-value` függvényt, és azt mondja, hogy nagyon hasznos lesz a *következő* szükséges függvényben.

A következő jelentésben két negyedév megnevezését és értékét kell két sorban megjeleníteni.

A kimenetnek emellett az első argumentumként megadott folyamba kell mennie.

Például: `(format-two-quarters t "last" 3.14 "this" 0)` a következőt írja a szabványos kimenetre:

```

The value last quarter: 3.14
The value this quarter: 0

```

Ügyelj a körülötte lévő üres sorokra.

## 3. Emberek és Lisp-űrlények számára olvasható

Layla elfelejtette megemlíteni, hogy a Lisp-űrlények szeretik a Lisp-adatként olvasható formában látni az értékeket. Ezért szükségük van egy új függvényre, amelynek kimenete Lisp-adatként olvasható (ismét a megadott folyamba):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
