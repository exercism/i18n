# Bevezetés

## Alapok

A C++-os utazásunkat változókkal, függvényhívásokkal és megjegyzésekkel kezdjük.

### Megjegyzések

A megjegyzéseknek két fajtája van: egysoros és többsoros.
A fordító figyelmen kívül hagy mindent, ami ugyanabban a sorban a `//` után következik.
A többsoros megjegyzéseket C-stílusú megjegyzéseknek is nevezik.
Ezeket `/*` és `*/` veszi körül.
Minden, ami ezek közé kerül, szintén figyelmen kívül marad.

### Változók

A C++ egy típusos nyelv.
Minden típust ismerni kell fordítási időben, és általában explicit módon meg kell adnod őket.
A változó típusa nem változhat.
Egy `years` nevű egész típusú változót így deklarálhatsz:

```cpp
int years;
```

Jó gyakorlat a változókat deklarációkor inicializálni.
A C++ különböző mechanizmusokat kínál erre.
A kapcsos zárójeles változat jobban illik a modern C++-hoz, de az egyenlőségjeles változat is nagyon gyakori.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
A C++ valóban engedélyezi a nem inicializált változók használatát.
Amíg a változónak szándékosan nem adsz értéket, addig definiálatlan, és bármit tartalmazhat.
A beállítás előtti használatból eredő hibák és a nem definiált viselkedés elkerülése érdekében tanácsos **mindig inicializálni**.
A nem definiált viselkedés a lehető legrosszabb pillanatban összeomlaszthatja a programodat, pedig korábban jól futott.
Nem lehet elégszer hangsúlyozni: kerüld a nem definiált viselkedést minden áron.
~~~~

### Aritmetikai műveletek

Az olyan aritmetikai operátorok, mint a `*`, a `+` vagy a `-`, részei lehetnek egy olyan kifejezésnek, mint a `3 * 2` vagy a `tomatoes + potatoes`.

### Változók frissítése

Újra értéket adhatsz a változóknak, amíg megőrzik a típusukat:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

### Függvények

A függvényeknek nevük, visszatérési típusuk és (esetleg üres) paraméterlistájuk van.
Egy `always_fortyseven` nevű függvény, amely mindig 47-et adna vissza, így nézne ki:

```cpp
int always_fortyseven() {
    return 47;
}
```

Íme a `vip_fee`, amelynek egy paramétere van:

```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Vagy itt van a `total_fee`, egy függvény három paraméterrel, amely meghív egy másik függvényt.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

A C++-ban a függvények nem a legutolsó utasítás értékét adják vissza, mint néhány más nyelvben.
A `return` kulcsszó szükséges ahhoz, hogy a kód leforduljon.

### Üres karakterek

Az üres karakterek a forráskód formázására szolgálnak, és ide tartoznak a szóközök, a tabulátorok vagy a sortörések.
Mivel a fordító figyelmen kívül hagyja a felesleges üres karaktereket, ezekkel tagolhatod a kódodat.
Az üres karakterek okos használata javíthatja a kód olvashatóságát.
Különböző formázási szabványok léteznek, de ezek mind konvencionálisak, és a fordító nem kényszeríti ki őket.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
