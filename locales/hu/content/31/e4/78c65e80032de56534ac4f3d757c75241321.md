# Bevezetés

A Go-ban egy alkalmazás csomagokból épül fel.
Egy csomag az ugyanabban a mappában található forrásfájlok gyűjteménye.
A mappában lévő összes forrásfájl elején ugyanaznak a csomagnévnek kell szerepelnie.
A konvenció szerint a csomag neve ugyanaz, mint a mappa neve, amelyben található.

```go
package greeting
```

A Go kiterjedt, csomagokból álló szabványos könyvtárat biztosít, amelynek csomagjait az `import` kulcsszóval használhatod fel a programodban.
A szabványos könyvtár csomagjait a nevükkel importálod.

```go
package greeting

import "fmt"
```

Az importált csomagra ezután a csomagnévvel hivatkozol:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

A Go a deklaráció módjából állapítja meg, hogy egy elem meghívható-e más csomagok kódjából.
Ahhoz, hogy egy függvény, típus, változó, konstans vagy struktúramező kívülről látható legyen (ezt nevezik _exportált_nak), a nevének nagybetűvel kell kezdődnie.
Ez hasonló ahhoz, ahogy más programozási nyelvek, például a Java, olyan hozzáférés-módosítókat használnak, mint a `public` és a `private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
