# Utasítások

Elaine egy új gyerekjátékon dolgozik, amelyben állatok és varázspálcák szerepelnek.
Itt az idő, hogy megírd a függvényeket a kockadobáshoz, a véletlenszerű pálcaenergia előállításához és egy szelet megkeveréséhez.

## 1. Kockadobás

Valósítsd meg a `RollADie` függvényt.

Ez lesz a hagyományos húszoldalú kocka, 1-től 20-ig terjedő számokkal.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. Pálcaenergia előállítása

Valósítsd meg a `GenerateWandEnergy` függvényt.
A pálcaenergia egy véletlenszerű lebegőpontos szám legyen, amely nagyobb vagy egyenlő, mint 0.0, és kisebb, mint 12.0.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. Egy szelet megkeverése

A játékban nyolc különböző állat szerepel:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

Írj egy `ShuffleAnimals` függvényt, amely egy szeletet ad vissza a nyolc állattal véletlenszerű sorrendben.
