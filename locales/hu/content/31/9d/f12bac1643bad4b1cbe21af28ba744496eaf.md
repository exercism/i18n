# Összehasonlító operátorok

A PHP-nak tíz beépített összehasonlító operátora van:

| Név  | Példa    | Eredmény                                             |
| ----- | ---------- | -------------------------------------------------- |
| Egyenlő | `$a == $b` | igaz, ha `$a` egyenlő `$b`-vel automatikus típuskonverzió után. |
| Azonos | `$a === $b` | igaz, ha `$a` egyenlő `$b`-vel, és ugyanaz a típusuk. |
| Nem egyenlő | `$a != $b` | igaz, ha `$a` nem egyenlő `$b`-vel automatikus típuskonverzió után. |
| Nem egyenlő | `$a <> $b` | igaz, ha `$a` nem egyenlő `$b`-vel automatikus típuskonverzió után. |
| Nem azonos | `$a !== $b` | igaz, ha `$a` nem egyenlő `$b`-vel, vagy nem ugyanaz a típusuk. |
| Kisebb, mint | `$a < $b` | igaz, ha `$a` szigorúan kisebb, mint `$b`. |
| Nagyobb, mint | `$a > $b` | igaz, ha `$a` szigorúan nagyobb, mint `$b`. |
| Kisebb vagy egyenlő | `$a <= $b` | igaz, ha `$a` kisebb vagy egyenlő, mint `$b`. |
| Nagyobb vagy egyenlő | `$a >= $b` | igaz, ha `$a` nagyobb vagy egyenlő, mint `$b`. |
| Spaceship | `$a <=> $b` | egy egész számot ad vissza, ami kisebb, egyenlő vagy nagyobb, mint `0`i, amikor `$a`. |

A PHP külön definíciókkal különbözteti meg az `equal` és az `identical` fogalmát. Az `identical`-t néha `strictly equal`-nak is nevezik.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
