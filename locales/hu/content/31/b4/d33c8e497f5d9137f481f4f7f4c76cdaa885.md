# Bevezetés

## Kivételek szűrése

A kivételek szűrésének kulcsszava a `when`. A catch utasítás után áll, és olyan Boolean-kifejezést fogadhat el, amelyben bármilyen, éppen hatókörben lévő érték szerepelhet. Ha a kifejezés értéke igaz, akkor a `catch` utasításhoz tartozó blokk hajtódik végre, ellenkező esetben pedig a következő `catch` utasítás kerül sorra, ha van ilyen.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## Felhasználó által definiált kivételek

A felhasználó által definiált kivétel minden olyan osztály, amelyet a kódodban definiálsz, és amely a `System.Exception`-ből származik. Az osztályöröklés minden szabálya vonatkozik rá, emellett azonban a fordító és a nyelv futtatókörnyezete különleges módon kezeli az ilyen osztályokat: lehetővé teszi, hogy a példányaikat a normál vezérlési folyamon kívül dobjuk és elkapjuk, ahogy arról az `exceptions` feladatban szó volt.

A felhasználó által definiált kivételeket gyakran arra használjuk, hogy további információt, például üzenetet és más releváns adatot adjunk át az elkapó rutinoknak.
