# Utasítások

Nagy modellvasút-rajongó vagy, és úgy döntöttél, hogy egy hírlevél elindításával megosztod a szenvedélyedet a világgal. Azzal kezded, hogy elküldöd a hírlevél első számát azoknak a barátaidnak és ismerőseidnek, akik osztoznak a hobbidban. Van egy szövegfájlod, amely az e-mail-címeik listáját tartalmazza.

## 1. E-mail-címek beolvasása egy fájlból

Valósítsd meg a `Newsletter.read_emails/1` függvényt. Paraméterként egy fájl elérési útját kapja. A fájl egy szövegfájl, amely újsorokkal elválasztott e-mail-címeket tartalmaz. A függvény adja vissza a fájlban szereplő e-mail-címek listáját.

```elixir
Newsletter.read_emails("/home/my_user/documents/model_train_friends_emails.txt")
# => ["rick@example.com", "choochoo42@example.com", "anna@example.com"]
```

## 2. Naplófájl megnyitása írásra

Egy e-mail elküldése sok kiszámíthatatlan okból meghiúsulhat, például egy elgépelt e-mail-cím vagy átmeneti hálózati problémák miatt. Ahhoz, hogy újra megpróbálhasd elküldeni az e-maileket mindenkinek, anélkül hogy duplikátumokat küldenél, naplóznod kell azokat az e-mail-címeket, amelyek már megkapták az e-mailt. Ehhez szükséged lesz egy naplófájlra.

Valósítsd meg a `Newsletter.open_log/1` függvényt. Paraméterként egy fájl elérési útját kapja, megnyitja a fájlt írásra, és visszaadja a fájlt kezelő folyamat PID-jét.

```elixir
Newsletter.open_log("/home/my_user/documents/newsletter_issue1_log.txt")
# => #PID<0.145.0>
```

## 3. Elküldött e-mail naplózása

Valósítsd meg a `Newsletter.log_sent_email/2` függvényt. Paraméterként a fájlt kezelő folyamat PID-jét és az e-mail-címet tartalmazó stringet kapja. Kiírja az e-mail-címet a fájlba, majd egy újsort.

```elixir
Newsletter.log_sent_email(pid, "joe@example.com")
# => :ok
```

## 4. A naplófájl bezárása

Valósítsd meg a `Newsletter.close_log/1` függvényt. Paraméterként a fájlt kezelő folyamat PID-jét kapja, és bezárja a fájlt.

```elixir
Newsletter.close_log(pid)
# => :ok
```

## 5. A hírlevél elküldése

Most, hogy megvan az e-mail-küldés minden építőeleme, egyetlen függvényben kell összekapcsolnod őket.

Valósítsd meg a `Newsletter.send_newsletter/3` függvényt. Paraméterként az e-mail-címeket tartalmazó fájl elérési útját, egy naplófájl elérési útját és egy névtelen függvényt kap, amely elküld egy e-mailt egy adott e-mail-címre. Beolvassa az összes e-mail-címet a megadott fájlból, és megpróbál e-mailt küldeni mindegyikre. Ha az e-mailt küldő névtelen függvény `:ok` értékkel tér vissza, írd ki az e-mail-címet a naplófájlba, majd egy újsort. Ezt mindenképpen rögtön az e-mail elküldése után tedd meg. Miután minden elküldéssel végeztél, zárd be a naplófájlt.

```elixir
Newsletter.send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  fn email -> :ok end
)

# => :ok
```
