# kódpont átalakítása közvetlenül stringgé

Egy karakter kódpontját a legegyszerűbben a `<<>>` speciális formával alakíthatod át az adott karaktert tartalmazó stringgé. Nincs szükség arra, hogy egy charlistet köztes lépésként használj.

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
