# Részletesen

Az [osztályok](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) az objektumorientált programozás elsődleges eszközei F#-ban.

Az F#-beli osztály mezőkből és metódusokból áll. Az osztály mezőit és metódusait együtt _tagoknak_ nevezzük.

Az osztályokat F#-ban a `type` kulcsszóval definiáljuk. A metódusokat a `member` kulcsszóval definiáljuk, és ezek mindig nyilvánosak. A (privát) mezők definiálásához `let` kötéseket használhatunk.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Az osztályok sablonok, amelyek alapján objektumokat hozunk létre. Egy osztály példányának létrehozásához hívd meg az osztály nevét függvényként. Egy osztály példányát _objektumnak_ is nevezik.

Egy objektum tagjait pontjelöléssel érheted el.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
