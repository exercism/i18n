# Utasítások

Ebben a feladatban naplósorok feldolgozásával foglalkozsz.

Minden naplósor egy string, amelynek formátuma a következő: `"[<LEVEL>]: <MESSAGE>"`.

Három különböző naplózási szint van:

- `INFO`
- `WARNING`
- `ERROR`

Három részfeladatot kapsz, mindegyik kap egy naplósort, és valamit tenned kell vele.

Szabadon választhatsz, hogy a base R régi függvényeit vagy a `stringr` csomagot használod, mindkettővel rövid, működő megoldást kaphatsz.

## 1. Üzenet kinyerése egy naplósorból

Valósítsd meg a `message` függvényt, amely egy naplósor üzenetét adja vissza:

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

A sor elején és végén lévő szóközöket el kell távolítani:

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. Naplózási szint kinyerése egy naplósorból

Valósítsd meg a `log_level` függvényt, amely egy naplósor naplózási szintjét adja vissza, méghozzá csupa kisbetűvel:

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. Naplósor újraformázása

Valósítsd meg a `reformat` függvényt, amely újraformázza a naplósort: az üzenet kerül előre, utána pedig zárójelben a naplózási szint következik:

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
