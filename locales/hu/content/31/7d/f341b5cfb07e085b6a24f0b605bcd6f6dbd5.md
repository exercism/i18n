# Telepítés

## A Node.js telepítése

**Windows- és OS X-felhasználók**: telepítsd a [Node.js][node]-t [csomagkezelővel][node-download].

**Linux-felhasználók**: telepítsd a [Node.js][node]-t a disztribúciódhoz tartozó, a [Node.js csomagkezelő][linstall] oldalon található utasítások szerint.

## A `jasmine-node` és a `coffeescript` telepítése

A legtöbb felhasználónak ez mindössze annyit jelent, hogy lefuttatja a következő parancsot:

```bash
$ npm install -g jasmine-node coffeescript
```

A beállításaidtól függően rendszergazdai jogosultságokra lehet szükséged ahhoz, hogy egy `npm` modult globálisan telepíts. Ez akkor fordul elő, ha a fentebb belinkelt hivatalos telepítőt használtad.
Ha az NPM azt a hibát írja ki, hogy nincs hozzáférésed, akkor írd a fenti parancs elé a `sudo`-t:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

Ha a hivatalos telepítőt használtad, a `PATH`-odat valószínűleg automatikusan beállította, de ha a shell nem találja a globálisan telepített moduljaidat, vagy ha a Node.js-t forrásból fordítottad, akkor frissítsd a `PATH`-ot, hogy tartalmazza az `npm` binárisokat. Ehhez add hozzá a következőt a `~/.bash_profile` vagy a `~/.zshrc` fájlhoz:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
