# Bemutatás

A kombinatorok a veremmozgatási mintákat nevesített, összeépíthető
szavakká alakítják. Ha már elég sokat írtál Factorban, egy idő után
nem azon gondolkodsz, hogy »`dup`-olni kell, aztán lefuttatni F-et,
aztán megtartani az eredetit«, hanem egyszerűen leírod ezt:
`[ F ] keep`.

| minta                                 | mozgatás                      | kombinator      |
|---------------------------------------|-------------------------------|-----------------|
| F alkalmazása, a bemenet megőrzése    | `dup F swap`                  | `[ F ] keep`    |
| egy bemenetre két függvény            | `dup F swap G`                | `[ F ] [ G ] bi`|
| egy bemenetre három függvény          | bonyolult                     | `[ F ] [ G ] [ H ] tri` |
| egy bemenetre sok függvény            | nagyon bonyolult              | `{ Fs … } cleave`|
| a verem teteje *alatti* értékeken dolgozik | `swap F swap`           | `[ F ] dip`     |
| ugyanaz a művelet két értéken         | `swap F swap F`               | `[ F ] bi@`     |
| különböző műveletek két értéken       | `swap F swap G`               | `[ F ] [ G ] bi*`|

A `2` előtagú család (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`,
`2nip`, `2swap`) ugyanezt teszi, amikor minden művelethez *két*
bemenet kell; a `3dup` és a `4dup` három vagy négy, a verem tetején
lévő értékre terjeszti ki a duplikálás idiómáját.

A cleave/dip/bi családon túl a [`kernel`][kernel] is kínál olyan
vezérlésfolyam-változatokat, amelyek tisztán továbbítják az `f`-et:

| szó         | hatás                                               |
|-------------|-----------------------------------------------------|
| `if*`       | az igaz ág látja az értéket, a hamis ág nem         |
| `?last`     | egy sorozat utolsó eleme, vagy `f`, ha üres         |
| `pop*`      | a `pop` eldobó változata (helyben módosítja a vektort) |
| `dupd`      | duplikálja a felülről *második* elemet              |
| `pick`      | a felülről *harmadik* elemet a verem tetejére másolja |
| `swapd`     | felcseréli a felülről második és harmadik elemet    |
| `rotd`      | elforgatja egy négymélységű verem alsó három elemét |
| `tuck`      | a legfelső elemet a felülről második alá másolja    |
| `with`      | beéget egy rögzített értéket egy idézetbe a HOS-hoz |
| `while`     | ciklus, amíg a predikátum igaz                      |
| `until`     | ciklus, amíg a predikátum igaz nem lesz             |

A megfelelő kombinator kiválasztása maga is egy készség. Az általános
szabály: ha egy definíció törzsében egymás után több mozgató szó
szerepel, akkor általában létezik olyan kombinator, amely jobban
kifejezi a szándékot.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
