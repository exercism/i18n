# Bevezetés

## Számok

A Pythonban három különböző beépített számtípus létezik: `ints`, `floats` és `complex`. Ebben a feladatban azonban csak `ints` és `floats` típusokkal fogsz foglalkozni.

### Egész számok

Az `ints` egész számok. Például: `1234`, `-10`, `20201278`.

A Pythonban az egészek [tetszőleges pontosságúak][arbitrary-precision], a számjegyek számát csak a gazdarendszer rendelkezésre álló memóriája korlátozza.

### Lebegőpontos számok

A `floats` olyan számok, amelyek tizedespontot tartalmaznak. Például: `0.0`, `3.14`, `-9.01`.

A lebegőpontos számok általában C-beli `double` típussal vannak megvalósítva a Pythonban (_15 tizedesjegy pontossággal_), de a reprezentációjuk a gazdarendszertől és más megvalósítási részletektől függően változhat. Ez meglepetéseket okozhat a lebegőpontos számokkal való munka során, de a legtöbb helyzetben „elég jó”.

## Aritmetika

A Python teljes mértékben támogatja az aritmetikát `ints` és `floats` között. A bináris aritmetikai operátorokkal (`+`, `-`, `*`, `/`, `//` és `%`) használva a szűkebb számokat a kevésbé szűk típusukhoz igazítja.

A Python az `ints` típust szűkebbnek tekinti, mint a `floats` típust. Ezért ha egy kifejezésben float szerepel, az eredmény is float lesz. Osztásnál azonban az eredmény mindig float lesz, még akkor is, ha csak egészeket használsz.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

Ha egész eredményre van szükség, a `//` operátorral csonkíthatod az eredményt.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

Ha egy float típust egésszé szeretnél alakítani, használhatod az `int()` függvényt. Ha egy egész típust float típussá szeretnél alakítani, használhatod a `float()` függvényt.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
