# Utasítások

Szenvedélyes madárfigyelő vagy, aki nyomon követi, hány madár járt a kertedben az elmúlt hét napban.

Hat részfeladat vár rád, és mindegyik a kertedbe látogató madarak számával foglalkozik.

## 1. Ellenőrizd a múlt heti számokat

Az összehasonlítás kedvéért mindig magadnál tartod a múlt heti számok másolatát, amelyek ezek voltak: 0, 2, 5, 3, 7, 8 és 4. Valósítsd meg a `BirdWatcher.getLastWeek()` metódust, amely a múlt heti számokat adja vissza:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Nézd meg, hány madár járt ma

Valósítsd meg a `BirdWatcher.getToday()` metódust, amely visszaadja, hány madár járt ma a kertedben. A madárszámok napok szerint rendezettek: az első elem a legrégebbi nap száma, az utolsó pedig a mai napé.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. Növeld a mai nap számát

Valósítsd meg a `BirdWatcher.incrementTodaysCount()` metódust, amely megnöveli a mai nap számát:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. Ellenőrizd, volt-e olyan nap, amikor egyetlen madár sem járt nálad

Valósítsd meg a `BirdWatcher.hasDayWithoutBirds()` metódust, amely `true` értéket ad vissza, ha volt olyan nap, amikor egyetlen madár sem járt a kertben; egyébként `false`-t ad vissza:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. Számítsd ki a látogató madarak számát az első napokra

Valósítsd meg a `BirdWatcher.getCountForFirstDays()` metódust, amely visszaadja, hány madár járt a kertedben a hét kezdete óta, de a számolást korlátozd a hét elejétől megadott számú napra.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. Számítsd ki a forgalmas napok számát

Néhány nap zsúfoltabb, mint a többi. Forgalmas nap az, amikor öt vagy több madár járt a kertedben.
Valósítsd meg a `BirdWatcher.getBusyDays()` metódust, amely visszaadja a forgalmas napok számát:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
