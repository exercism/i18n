# Bevezetés

A karakterek és a stringek alkotják a szöveges ábrázolás alapját Elmben.
A stringeket tekinthetjük karakterek listájának, és a legtöbb `List`-függvény megfelelője megtalálható a `String` modulban.

## Karakterek

A `Char` típus egyetlen unicode karaktert reprezentál szimpla idézőjelek között, például `'a'`.
A `Char` modul predikátumfüggvényeket (`Char -> Bool`) biztosít egy karakter tulajdonságainak vizsgálatához: `isUpper`, `isLower`, `isAlpha` és `isAlphaNum`.
A modul emellett függvényeket is nyújt egy karakter átalakításához (`toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`), valamint a numerikus unicode-értékére (`Int`) és onnan vissza a `toCode` és a `fromCode` segítségével.

## Stringek

A `String` típus beépített ábrázolást nyújt a hatékony stringkezeléshez, és bármilyen unicode karaktersorozatot képes reprezentálni.
A stringeket dupla idézőjelek jelölik: `"this is a string"`.
A többsoros stringeket három dupla idézőjel jelöli, és tartalmazhatnak escapeletlen idézőjeleket és sortöréseket.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## Stringek manipulálása

A `reverse : String -> String` megfordítja a stringet.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

A `repeat : Int -> String -> String` n-szer megismétli a stringet.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

A `replace : String -> String -> String -> String` lecseréli egy adott részstring összes előfordulását.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

A `append : String -> String -> String` összefűz két stringet.
Ugyanerre a `++` operátor is használható.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

A `concat : List String -> String` egy stringlistát fűz össze egyetlen stringgé.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

A `split : String -> String -> List String` egy stringet stringek listájára bont az adott elválasztónál.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

A `join : String -> List String -> String` egy stringlistát fűz össze egy adott elválasztóval.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

A `words : String -> List String` stringekre bontja a stringet, a whitespace-csoportoknál elválasztva.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

A `lines : String -> List String` sorokra bontja a stringet, a sortöréseknél elválasztva.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

A `cons : Char -> String -> String` egy karaktert fűz a string elejére.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

A `uncons : String -> Maybe ( Char, String )` egy nem üres stringet bont fel a fejére és a farkára.
Így pontosan úgy illeszthetsz mintát stringekre, ahogy listákra tennéd.
Az üres stringek `Nothing`-ot adnak vissza.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## Részstringek kinyerése

A `slice : Int -> Int -> String -> String` egy részstringet vesz ki egy kezdő- és egy záróindex alapján.
A negatív indexek a lista végétől számítódnak.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

A `left : Int -> String -> String` és a `right : Int -> String -> String` rendre n karaktert vesz ki a string bal, illetve jobb oldaláról.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

A `dropLeft : Int -> String -> String` és a `dropRight : Int -> String -> String` rendre n karaktert dob el egy string bal, illetve jobb oldaláról.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## Stringek tulajdonságainak vizsgálata

A `length : String -> Int` visszaadja egy string karaktereinek számát.
```elm 
length "Hello world." 
    --> 12
```

Az `isEmpty : String -> Bool` megállapítja, hogy egy string üres-e.
```elm 
isEmpty "Hello world." 
    --> False
```

A `contains : String -> String -> Bool` ellenőrzi, hogy a második string tartalmazza-e az elsőt.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

A `startsWith : String -> String -> Bool` és az `endsWith : String -> String -> Bool` ellenőrzi, hogy a második string egy adott részstringgel kezdődik-e, illetve végződik-e.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

Az `indexes : String -> String -> List Int` egy részstring összes kezdőindexének listáját adja vissza egy másik stringben.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## Stringek átalakítása
A `toInt : String -> Maybe Int` megpróbál egy stringet `Just Int`-té alakítani, és `Nothing`-ot ad vissza a helytelenül formázott stringekre.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

A `fromInt : Int -> String` egy egész számot stringgé alakít.
```elm
fromInt -42 
    --> "-42"
```

A `toFloat : String -> Maybe Float` megpróbál egy stringet tizedes törtté alakítani, és elbukik a helytelenül formázott stringeknél.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

A `fromFloat : Float -> String` egy tizedes törtet stringgé alakít.
```elm
fromFloat 3.9 
    --> "3.9"
```

A `toList : String -> List Char` és a `fromList : List Char -> String` rendre egy stringet karakterek listájává alakít, illetve vissza.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

A `fromChar : Char -> String` egy karaktert stringgé alakít.
```elm
fromChar 'a' 
    --> "a"
```

## Stringek formázása

A `toUpper : String -> String` és a `toLower : String -> String` rendre csupa nagy-, illetve csupa kisbetűssé alakítja a stringeket.
Hasznos a kis- és nagybetűre érzéketlen összehasonlításokhoz.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

A `pad : Int -> Char -> String -> String` a megadott `Char`-ral tölti fel egy string mindkét oldalát, amíg el nem éri az adott hosszúságot.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
Hasonlóképpen a `padLeft` és a `padRight` az egyik oldalon tölti fel a stringet, amíg el nem éri az adott hosszúságot.

A `trim : String -> String` eltávolítja a whitespace-t egy string mindkét oldaláról.
```elm
trim "  hats  \n" 
    --> "hats"
```
A `trimLeft` és a `trimRight` egy string egyik oldaláról távolítja el a whitespace-t.

## Magasabb rendű függvények

A `map : (Char -> Char) -> String -> String` egy string minden karakterét átalakítja a megadott függvénnyel.
Figyelj rá, hogy a megadott függvénynek `Char`-ból `Char`-ba kell képeznie.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

A `filter : (Char -> Bool) -> String -> String` csak azokat a karaktereket tartja meg, amelyek átmennek a teszten.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

A `foldl : (Char -> b -> b) -> b -> String -> b` balról indulva redukálja a stringet.
A függvény úgy hívódik meg, hogy az első karakter az első paramétere, a megadott kezdőérték pedig a második paramétere.
A függvény eredményének ugyanolyan típusúnak kell lennie, mint a megadott kezdőérték, és sorban minden karakterre alkalmazódik.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
A `foldr` ugyanezt teszi, de a string jobb oldaláról indulva.

Az `any : (Char -> Bool) -> String -> Bool` megállapítja, hogy bármelyik karakter `True`-t ad-e vissza a megadott predikátumra.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
Az `all : (Char -> Bool) -> String -> Bool` megállapítja, hogy egy string összes karaktere `True`-t ad-e vissza a megadott predikátumra.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
