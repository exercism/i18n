# Bevezetés

Szinte minden Factor program szavak sorozata, amelyek értékeket fogyasztanak és állítanak elő az *adatveremen*. Amikor a bemenetek és kimenetek szépen illeszkednek, a kód balról jobbra olvasható, minden gond nélkül. Amikor nem, a *shuffle szavakhoz* nyúlsz, és a kód gyorsan zajossá válik.

Ez a feladat végigvezet a Factor szabványos megoldásán: a kombinátorokon.

## Shuffle szavak

A leggyakoribb shuffle szavak a [`kernel`][kernel] szókészletben találhatók:

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

Valószínűleg már használtad a `dup` és `swap` szavakat. Az `over` lemásolja a *második* elemet a verem tetejéről, ami hasznos, ha ugyanazt a bemenetet két számításhoz kell felhasználni:

```factor
! Sum a number with twice itself: x + 2*x
: triple ( x -- 3x ) dup 2 * + ;
```

Ez egyetlen használat esetén rendben van. De egymás után fűzve a `dup`, `swap`, `over`, `rot` sorozatai gyorsan olvashatatlanná válnak.

## `keep`: a bemenet megőrzése

A `keep` (a [`kernel`][kernel] szókészletben) meghív egy quotationt a verem tetején, de az eredeti értéket az eredmény fölött hagyja:

```
keep ( x quot: ( x -- y ) -- y x )
```

```factor
5 [ 2 * ] keep .s
! => 10
! => 5
```

Ez lecseréli azt a mintát, amikor `dup` után valami, majd shuffle következik: ahol `dup something swap`-et írnál, egyszerűen azt mondhatod, hogy `[ something ] keep`.

## `bi`: két függvény ugyanarra a bemenetre

A `bi` (a [`kernel`][kernel] szókészletben) *két* quotationt alkalmaz ugyanarra az értékre, és mindkét eredményt a vermen hagyja:

```
bi ( x q1 q2 -- r1 r2 )
```

```factor
4 [ sq ] [ neg ] bi .s
! => 16
! => -4
```

A `bi` nélkül `dup sq swap neg`-et írnál, ami két műveletnél még olvasható, háromnál viszont már kellemetlen.

## `tri` és `cleave`: sok függvény ugyanarra a bemenetre

A `tri` három quotation használatára terjeszti ki a `bi`-t:

```
tri ( x q1 q2 q3 -- r1 r2 r3 )
```

A `cleave` (a [`combinators`][combinators] szókészletben) ugyanez az ötlet egy *tömbre*, amely tetszőleges számú quotationt tartalmaz:

```factor
4 { [ ] [ sq ] [ neg ] } cleave .s
! => 4
! => 16
! => -4
```

Az üres quotation, a `[ ]`, azonosságként viselkedik, ami akkor hasznos, ha a kiosztott kártya egyik helyén magának a bemenetnek kell állnia.

## `dip` és `2dip`: művelet a felszín alatt

A `dip` (a [`kernel`][kernel] szókészletben) egy quotationt hív meg a verem teteje *alatti* értékeken, a tetejét érintetlenül hagyva. A `2dip` ugyanezt teszi, de a legfelső *két* értéket védi:

```
dip  ( x   quot -- x   )
2dip ( x y quot -- x y )
```

```factor
9 10 11 [ + ] dip .s
! => 19      (9 + 10)
! => 11      (the protected top, restored)

9 10 11 12 [ + ] 2dip .s
! => 19      (9 + 10)
! => 11      (the protected y, originally 11)
! => 12      (the protected x, originally 12)
```

Itt a `dip` elrejtette a `11`-et, lefuttatta a `9 10 +`-t, majd visszatette a `11`-et a verem tetejére. A `2dip` elrejtette a `11 12`-t, alattuk lefuttatta a `9 10 +`-t, majd visszaállította a `11 12`-t.

A `dip` a megfelelő eszköz, amikor a természetes argumentumsorrend az átengedett értéket a verem tetején hagyja. Ezt használd a `swap … swap` szendvics helyett.

## `bi@`: ugyanaz a művelet két értéken

A `bi@` (a [`kernel`][kernel] szókészletben) egy quotationt alkalmaz két veremértékre:

```
bi@ ( x y quot -- r1 r2 )
```

```factor
3 4 [ sq ] bi@ .s
! => 9
! => 16
```

## `bi*`: különböző műveletek két értéken

A `bi*` (a [`kernel`][kernel] szókészletben) *különböző* quotationt alkalmaz a két veremértékre: az első quotationt az alsóbb értékre, a másodikat a verem tetejére:

```
bi* ( x y q1 q2 -- r1 r2 )
```

```factor
3 4 [ sq ] [ neg ] bi* .s
! => 9
! => -4
```

A `bi@`-t akkor használd, amikor mindkét érték ugyanazt a kezelést kapja, a `bi*`-ot pedig akkor, amikor mindegyiknek a sajátjára van szüksége.

## `tri*`: különböző műveletek három értéken

A `tri*` (a [`combinators`][combinators] szókészletben) kiterjeszti a `bi*`-ot három értékre és három quotation használatára, sorban mindegyik quotationt egy-egy értékre alkalmazva:

```
tri* ( x y z q1 q2 q3 -- r1 r2 r3 )
```

```factor
1 2 3 [ sq ] [ neg ] [ 10 * ] tri* .s
! => 1
! => -2
! => 30
```
