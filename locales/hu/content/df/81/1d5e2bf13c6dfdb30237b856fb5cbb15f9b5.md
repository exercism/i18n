# Részletesen

A Common Lisp Printer segítségével adatokat írhatunk folyamokba. Az egyik leggyakoribb függvény ebben a rendszerben a `format`.

A `format` két kötelező paramétert vár: egy folyamot, amelyre ír, és egy vezérlő stringet. A vezérlő string tartalma dönti el, hogy a további argumentumok hogyan használódnak fel.

Az első paraméternek két különleges értéke van: `t` és `nil`. A `t` azt jelenti, hogy a `*standard-output*`-hoz kötött folyamot kell használni, a `nil` pedig azt, hogy egy stringet kell létrehozni és visszaadni. A `format` értéke `nil` lesz, kivéve ha a folyam paraméter `nil`.

A vezérlő string formátumdirektívákat tartalmazhat, amelyeket egy `~` és az utána következő karakter jelöl (a karakter kis- vagy nagybetűs volta nem számít). A formátumdirektíva határozza meg, hogy felhasznál-e argumentumokat, és hogy ezek hogyan formázódnak a folyamra.

A fontosabb alapvető formátumdirektívák:

* `~A` - _esztétikus_, „ember által olvasható” formázás.
* `~S` - a _szabványos_, „géppel olvasható” formában formáz.
* `~%` - új sort ír ki.
* `~&` - új sort ír ki, kivéve ha már egy sor elején vagyunk.
* `~~` - tilde karaktert ír ki.

Példák:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
