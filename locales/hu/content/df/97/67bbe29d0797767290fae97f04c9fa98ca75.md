# Kivétel

Az ideális világban minden tökéletesen működik.
A való világban viszont a dolgok rosszul sülhetnek el, és az, hogy hogyan kezeljük ezeket a helyzeteket, fontos ahhoz, hogy a szoftverünk robusztus és megbízható legyen.
A kivételek kulcsfontosságú fogalom a programozásban, amely lehetővé teszi, hogy elegánsan kezeljük a hibákat és a váratlan helyzeteket.

Ha kiváltunk egy hibát, és nem kezeljük, a program leáll, és hibaüzenetet dob.
A legtöbb esetben nem szeretnéd, hogy a program leálljon, amikor hiba történik; inkább kezelni szeretnéd a hibát, és tovább futtatni a programot.

## Kivétel kiváltása

A Crystalben a kivételeket a `raise` kulcsszóval váltjuk ki, és vagy egy `String`, vagy egy `Exception` objektum adható meg neki.
Ha nem kezeljük, a program leáll, és kiírja a hibaüzenetet.

```crystal
raise "This is an error"
```

A Crystalben számos beépített kivétel van, például `ArgumentError`, `IndexError`, `KeyError`, `IOError`, `SystemCallError`, `TypeError`, `ZeroDivisionError` és még sok más.
Ezeknél meg kell adnod egy üzenetet a kivételnek.

```crystal
raise ArgumentError.new("This is an argument error")
```

## [Kivételek kezelése][exception-handling]

Nem szeretnénk, ha a programunk összeomlana, amikor kiváltunk egy kivételt.
Ezért, ha tudjuk, hogy egy kódrészlet hajlamos a hibákra, becsomagolhatjuk egy `begin` blokkba, és a `rescue` blokkal elkaphatjuk a kivételt.
A `begin` blokk jelöli annak a kódnak a kezdetét, amelyik kivételt válthat ki, a `rescue` blokk pedig kezeli a kivételt.

```crystal
begin
 raise "This is an error"
rescue
 puts "An error occurred!"
end
```

A `rescue` blokk egy változóval is megadható, így megkapod a kivétel objektumát.

```crystal
begin
 raise "This is an error"
rescue ex
 puts "An error occurred: #{ex.message}"
end
```

A `rescue` blokk megadható egy konkrét kivételtípussal is, hogy csak azt a kivételt kapd el.

```crystal
begin
 raise ArgumentError.new("This is an argument error")
rescue ArgumentError
 puts "An argument error occurred!"
end

# or

begin
 raise ArgumentError.new("This is an argument error")
rescue ex : ArgumentError
 puts "An argument error occurred: #{ex.message}"
end
```

Több `rescue` blokkal különböző típusú kivételeket kezelhetsz.
Az alábbi példában az első `rescue` blokk egy `ArgumentError`-t kap el, a második `rescue` blokk pedig minden más kivételt.

```crystal
begin
 raise ArgumentError.new("This is an argument error")
rescue ArgumentError
 puts "An argument error occurred!"
rescue
 puts "An error occurred!"
end
```

A `begin` blokkhoz tartozhat egy `else` blokk is, amely akkor fut le, ha nem váltunk ki kivételt.

```crystal
begin
 puts "No error occurred"
rescue
 puts "An error occurred!"
else
 puts "No error occurred"
end
```

Végül van egy `ensure` blokk, amely mindig lefut, függetlenül attól, hogy kiváltottunk-e kivételt.

```crystal
begin
 raise "This is an error"
rescue
 puts "An error occurred!"
ensure
 puts "This is always executed"
end
```

## Metóduskonvenció

Egyes metódusoknak két változata van: az egyik `!`-tal, a másik anélkül.
Ez két különböző dolgot jelenthet.
Az egyik, hogy a metódus módosítja az objektumot, a másik, hogy a metódus kivételt válthat ki.

De létezik egy másik konvenció is a metódusok `?`-lel való lezárására, amelyet a Boolean fogalomnál említettünk.
Egyes metódusok alapértelmezés szerint kivételt váltanak ki, de van egy `?`-lel végződő változatuk is, amely kivétel kiváltása helyett `nil`-t ad vissza.

Ez ideális, ha el akarod kerülni, hogy hibát váltsunk ki. 
Ez a teljesítménynek is jót tehet, mivel nem kell stacktrace-t létrehozni, és ha megfelelően van beállítva, biztonságosabbá teheti a kódot.

## Egyéni kivételek

Saját kivételeket is létrehozhatsz, ha a [`Exception`][exception] osztályból örökölsz.
Ekkor igény szerint felülírhatod az `initialize` metódust, hogy beállítsd a kivétel üzenetét.
Ezt úgy teheted meg, hogy a `@message` nevű példányváltozónak értékül adod az üzenetet.

```crystal
class MyException < Exception
 def initialize
   @message = "This is my exception"
 end
end

raise MyException.new
```
