# Utasítások

Tanár vagy.
Az év végén minden tanulódhoz kiszámoltál egy numerikus osztályzatot.
Most át kell alakítanod ezeket betűjegyekké, és meg kell számolnod, hány tanuló érte el az egyes betűjegyeket.

## 1. Alakítsd át a numerikus osztályzatot betűjeggyé

A `letter_grade` függvény bemenetként egy numerikus osztályzatot kap, és kiadja a hozzá tartozó betűt.
Ezeket a tartományokat használd:

| Betű | Osztályzat |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

Példa:

```jq
75 | letter_grade   # => "C"
```

## 2. Számold meg az egyes betűjegyekhez tartozó tanulók számát

A `count_letter_grades` függvény egy olyan objektumot kap, amely a tanulók nevét az osztályzataikhoz rendeli.
A kimenet egy olyan objektum lesz, amely minden betűjegyhez a hozzá tartozó tanulók számát rendeli.

Példa:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Ezt többféleképpen is meg lehet oldani.
Gyakorlásként használd a `reduce` szűrőt.
