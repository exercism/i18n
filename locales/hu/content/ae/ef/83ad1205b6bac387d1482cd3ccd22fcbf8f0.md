# Utasítások

Ebben a feladatban egy készletnyilvántartó rendszert fogsz kezelni.

A készletet az elemek neve szerint kell rendszerezni, és nyilván kell tartania a rendelkezésre álló elemek számát.

Arról is gondoskodnod kell, hogy elemeket lehessen hozzáadni egy készlethez.
Valahányszor egy elem megjelenik egy adott vektorban, a készletben az adott elem darabszámát `1`-gyel kell növelni.
Arról is gondoskodnod kell, hogy elemeket lehessen törölni egy készletből úgy, hogy kérésre `1`-gyel csökkented a darabszámukat.

Végül implementálnod kell egy függvényt, amely egy adott készlet összes kulcs-érték párját `pair`-ekből álló `vector` formájában adja vissza.

~~~~exercism/note
A feladat tesztjei nem foglalkoznak azzal, hogy a függvények módosítják-e a bemenetüket, a nevük viszont arra utal, hogy nem szabad módosítaniuk.
Ha a bevezetőben szereplő függvényeket szeretnéd használni anélkül, hogy módosítanád a bemenetet, a `copy()` függvény segítségedre lesz.
~~~~

## 1. Készlet létrehozása egy vektor alapján

Implementáld a `create_inventory(<input vector>)` függvényt, amely egy bemeneti, elemekből álló vektorból létrehoz egy „készletet”.
Egy `dict`-tel kell visszatérnie, amely az egyes elemneveket a hozzájuk tartozó darabszámmal párosítva tartalmazza.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Elemek hozzáadása egy vektorból egy meglévő szótárhoz

Implementáld az `add_items(<inventory dict>, <item vector>)` függvényt, amely egy elemvektort ad a kapott készlethez:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Elemek darabszámának csökkentése a készletben

Implementáld a `decrement_items(<inventory dict>, <items vector>)` függvényt, amely egy elemekből álló `vector`-t kap.
A függvényednek `1`-et kell levonnia egy elem darabszámából minden alkalommal, amikor az az elem szerepel a `vector`-ban:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

A készletben egy elem darabszáma nem csökkenhet 0 alá.
Ha egy elem többször szerepel a bemeneti `vector`-ban, mint amennyi a rendelkezésre álló darabszáma, akkor az elemhez tartozó mennyiség 0 marad.
Ha a darabszám már elérte a nullát, a további csökkentési kéréseket figyelmen kívül kell hagyni.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Egy bejegyzés teljes eltávolítása a készletből

Implementáld a `remove_item(<inventory dict>, <item>)` függvényt, amely teljesen eltávolít egy elemet és annak darabszámát a készletből:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Ha az elem nem található a készletben, a függvénynek az eredeti készletet kell változatlanul visszaadnia.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. A készlet teljes tartalmának visszaadása

Implementáld a `list_inventory(<inventory dict>)` függvényt, amely egy készletet kap, és `(item, quantity)` párokból álló vektort ad vissza.

A vektor csak az _elérhető_ elemeket tartalmazza (_amelyek darabszáma nagyobb nullánál_), és az elemeket ábécésorrendben kell rendezni:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
