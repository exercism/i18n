# Bevezetés

A C++-ban a feltételes elágazások hasonlóak más nyelvek feltételes elágazásaihoz.
Minden feltételes művelet mögöttes típusa a `bool` típus, amely a `true` vagy `false` értéket veheti fel.
A feltételes elágazásokat gyakran vezérlési mechanizmusként használjuk különböző feltételek ellenőrzésére.

Egy `if` elágazás használható, amely akkor futtatja a kódját, ha a mögöttes feltétel `true`, például így:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Több eset kezelésekor sok `if` elágazás fűzhető össze az `else if` és `else` elágazásokkal.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

A C++17 óta az `if` elágazások egy rövid inicializáló utasítást is tartalmazhatnak, amellyel az `if` elágazáshoz egy vagy több változó inicializálható.
Például:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Megjegyzés: az inicializálásban létrehozott változók az `if` elágazás vége után nem érhetők el.
