# Bevezetés a ciklusokba

A Bashben kétféle ciklus létezik:

* Ismételj meg néhány parancsot _egy elemekből álló lista minden elemére_,
* Ismételj meg néhány parancsot, _amíg egy feltétel igaz (vagy hamis)_.

## For-ciklusok

Egy lista elemein való végigiteráláshoz a `for` ciklust használjuk.

```bash
for varname in words; do COMMANDS; done
```

A `words` szófelbontással és fájlnévkiterjesztéssel bővül ki (erről a [Quoting fogalomban][quoting] tanultunk).
Minden szó sorra a `varname` változóba kerül, és a COMMANDS parancsok lefutnak.

Íme néhány példa, amelyek megmutatják, mikor lehet hasznos a for ciklus

* Végezz el néhány parancsot egy fájlcsoporton.

    ```bash
    # source all the bash library files in the current directory
    for file in ./*.bash; do
        source "$file"
    done
    ```

* Végezz el valamilyen parancsot egy szkript vagy függvény minden paraméterén.

    ```bash
    for arg in "$@"; do
        echo "argument: ${arg}"
    done
    ```

* Végezz el valamilyen parancsot egy parancs kimenetének minden whitespace-szel elválasztott szavára.

    ```bash
    for i in $(seq 10); do
        echo "${i} squared is $((i * i))"
    done
    ```

    Erre a stílusra később még látni fogunk néhány figyelmeztetést.

### Aritmetikai for-ciklus

A Bashben létezik aritmetikai ciklus is.
Ez némileg ismerős lesz más programozási nyelvekből.

```bash
for ((INITIALIZATION; CONDITION; INCREMENT)); do COMMANDS; done
```

A dupla zárójel a Bashben egy aritmetikai környezetet jelöl (a Bash aritmetikájáról egy későbbi fogalomban még látunk többet).
A fenti, `seq`-et használó példa így írható fel

```bash
for ((i = 1; i <= 10; i++)); do
    echo "${i} squared is $((i * i))"
done
```

### Mikor ne használjuk a for ciklust

[Ne olvass sorokat `for` ciklussal][bashfaq1].

Ez egy gyakran előforduló antiminta: végigiterálunk a `cat` kimenetén.

```bash
for line in $(cat some.file); do 
    do_something_with "$line"
done
```

Ez két okból is hibás.

1. A parancshelyettesítés nincs idézőjelek között, ezért alá van vetve a szófelbontásnak.
   A szófelbontás alapértelmezés szerint _whitespace_ mentén bont, nem csak sortöréseknél.
   Ez a for ciklus a fájl **szavain** iterál végig, nem a sorain.
2. A parancshelyettesítés nincs idézőjelek között, ezért ki van téve a fájlnévkiterjesztésnek is.
   A fájl minden szavát glob mintaként próbálja illeszteni.

Ahogy a [Quoting fogalomban][quoting] tanultuk, a szófelbontást az `IFS` változóval lehet szabályozni, a fájlnévkiterjesztést pedig ki lehet kapcsolni.
Ez azonban hajlamos törékeny megoldás lenni.
A `for` nem megfelelő módszer egy fájl sorain való végigiterálásra.
Egy fájl beolvasásának idiomatikus módja a `while` ciklus.

## While-ciklusok

A `while` segítségével ismételhetsz meg egy parancssorozatot, _amíg_ egy feltétel igaz.

```bash
while CONDITION_COMMANDS; do COMMANDS; done
```

Ahogy az `if` esetében is (amint a [Conditionals fogalomban][conditionals] tanultuk), a CONDITION_COMMANDS-hez nincs különleges szintaxis.
A parancslista kilépési státusza dönti el, hogy „igaz” vagy „hamis”.

## A ciklusok vezérlése

A `break` parancs kilép a ciklusból.
A vezérlés a ciklus `done` lezárója utáni paranccsal folytatódik.

A `continue` parancs a ciklus következő iterációjára ugrik.

## Egy fájl sorainak beolvasása

Ahogy említettük, egy fájl beolvasásának idiomatikus módja a while ciklus.

```bash
while IFS= read -r line; do
    do_something_with "$line"
done < some.file
```

* A fájl tartalmát a `<` átirányítással adjuk bemenetként a ciklusnak.
* A `read` parancs „igaz”-ot ad vissza, ha egy teljes sort be tud olvasni a bemenetéről.
  Amikor a bemenet elfogy, vagy ha az utolsó sor nem zárul sortöréssel, a read „hamis”-t ad vissza.
  * A _valóban_ idiomatikus módja egy fájl sorai beolvasásának, akkor is, ha az utolsó sor nem végződik sortöréssel, ez:

    ```bash
    while IFS= read -r line || [[ -n "$line" ]]; do ...
    ```

* A `-r` kapcsoló megmondja a `read`-nek, hogy ne helyettesítse a backslash-szekvenciákat: a backslash ekkor egyszerű karakter.
* Az `IFS=` csak a read parancs futási idejére rendeli az üres stringet az IFS-hez.
  Ez átmenetileg kikapcsolja a szófelbontást, így a bejövő szövegsor elején vagy végén lévő whitespace megmarad.

## Until

Az `until` szerkezet addig ismétel egy parancssorozatot, amíg egy feltétel **hamis**.
A ciklus addig ismétlődik, _amíg_ a feltétel igazzá nem válik.

```bash
until CONDITION_COMMANDS; do COMMANDS; done
```

Ritka, hogy `until`-t használunk.
Gyakoribb a „while not” ciklus használata.

```bash
while ! CONDITION_COMANDS; do ...
```

## Végtelen ciklusok

Néha örökké szeretnél ciklust futtatni.
Íme két módszer erre.

1. egy while ciklus olyan feltétellel, amelynek a kilépési státusza mindig sikeres

    ```bash
    while true; do ...
    ```

2.  egy aritmetikai for ciklus üres kifejezésekkel

    ```bash
    for ((;;)); do ...
    ```

## Do-While

Nincs külön do-while szerkezet, de ugyanezt a hatást elérheted:

```bash
while true; do
    COMMANDS

    if END_CONDITION; then
        break
    fi
done
```
