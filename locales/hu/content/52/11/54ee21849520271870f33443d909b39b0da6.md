# Bevezetés

A ciklusokat arra használjuk, hogy valamilyen logikát ismételten végrehajtsunk.
A két leggyakoribb típus a `while loop` (határozatlan ismétlés) és a `for loop` (határozott, azaz megszámlált ismétlés).
Van egy `for each` ciklus is, ami majd egy későbbi fogalomnál kerül elő.


## Általános szintaxis

A `for loop` egy fejlécből és egy kódblokkból áll, amely a ciklus kapcsos zárójelek közé zárt törzsét tartalmazza.
A fejléc három, pontosvesszővel (`;`) elválasztott részből áll: inicializáló utasítás, feltétel és egy másik kifejezés.
Ezek bármelyike lehet üres.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- Az **init** rész olyan kód, amely csak egyszer, a ciklus kezdete előtt fut le.
- A **feltétel** résznek olyan kifejezésnek kell lennie, amely Boolean értékre értékelődik ki, és meghatározza, mikor álljon le a ciklus.
A cikluson belüli kód mindaddig fut, amíg ez a feltétel igaz.
Amint ez a kifejezés hamisra értékelődik, a ciklus további iterációi nem futnak le.
- A **kifejezés** rész olyan kód, amely minden iteráció végén lefut.


A `while loop` mindaddig végrehajtja a törzsét, amíg a feltétel-ellenőrzése igaz.
Az alábbi kódrészlet megmutatja, hogyan alakítható át egy for ciklus while ciklussá.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## Közjáték: növelés és csökkentés

A ciklusokkal végzett munka során gyakran szükséges 1-et hozzáadni egy számlálóváltozóhoz, vagy kivonni belőle 1-et.
Ez annyira gyakori, hogy a művelethez külön operátorok vannak: `++` és `--`.

Két formájuk van: prefix és postfix.
A prefix az utasításban való felhasználás előtt módosítja a változót, a postfix pedig utána.
A legtöbbször valószínűleg a prefix formát szeretnéd használni.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## A for ciklus: egy példa

Az init rész általában beállít egy számlálóváltozót, a feltétel ellenőrzi, hogy folytatódjon vagy álljon le a ciklus, a post rész pedig általában minden ismétlés végén lépteti a számlálót.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Ez a ciklus összegzi az `1`-től `9`-ig terjedő számokat (a `9`-et is beleértve).

## break és continue

Egy ciklus törzsén belül a `break` kulcsszóval teljesen leállíthatod a ciklus végrehajtását:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Ezzel szemben a `continue` kulcsszó csak az aktuális iteráció végrehajtását állítja le, és a következővel folytatja:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> Megjegyzés: a ciklus logikáját általában könnyebb megérteni, ha a `break` és a `continue` használatát minimalizáljuk, vagy teljesen elkerüljük.
