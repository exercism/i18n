# Utasítások

A közösségi művészeti központban önkénteskedel, ahol éppen egy hosszú kerámiacsempe-mozaik készül a bejárat fölé. A tervezőcsapat **soronként** dolgozta ki a tervet: minden sor egy csempeszínekből álló tömb, a teljes mozaik pedig sorok tömbje.

Amíg az önkéntesek vágják, helyezik és rendezgetik a csempéket, te kis, újrafelhasználható szavakat írsz, amelyekkel a terv egyes darabjait felépíted, összekombinálod és kikeresed.

## 1. Egycsempés sáv

Definiáld a `tile-strip` szót úgy, hogy egy színt kapjon, és egy 1 elemű sort adjon vissza, amelyben csak az a szín szerepel.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. Három csempéből álló sor

Definiáld a `row-of-three` szót úgy, hogy három színt vegyen le a veremről, és egy 3 elemű sort adjon vissza.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. A sorok összefűzése egyetlen csempelistába

A tervezőcsapatnak ellenőriznie kell a színek összesített darabszámát a mozaik minden sorában. Definiáld a `combine-rows` szót úgy, hogy sorokból álló tömböt kapjon, és egyetlen sorozatot adjon vissza, amelyben minden csempe sorrendben szerepel.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. Sor tükrözése

A szimmetrikus panelekhez a csapat tükröz egy sort, mielőtt a másolatot a szemközti oldalra helyezné. Definiáld a `mirror-row` szót úgy, hogy fordított sorrendű sort adjon vissza.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. Hol van ez a szín a sorban?

Definiáld a `tile-position` szót úgy, hogy egy sort és egy színt kapjon, és visszaadja az adott színű első csempe indexét (0-tól számozva) a sorban. Ha a szín nincs benne a sorban, add vissza az `f` értéket.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. Tartalmazza ez a sor a színt?

Definiáld a `has-colour?` szót úgy, hogy egy sort és egy színt kapjon, és adjon vissza `t`-t, ha a szín a sorban bárhol előfordul, egyébként `f`-et.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
