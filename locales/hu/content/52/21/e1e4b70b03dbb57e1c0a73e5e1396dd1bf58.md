# Névjegy

Az `Option` típus az F# mechanizmusa az olyan értékek kezelésére, amelyek lehet, hogy léteznek, és lehet, hogy nem.
Típusbiztos alternatívát kínál a `null` használatával szemben, amely más nyelvekben gyakori az ilyen értékek kezelésére.
Számos szabványos F#-könyvtári függvény használja, ezért a megértése elengedhetetlen a szabványos F#-könyvtár hatékony használatához.

## Az `Option` típus használatának előnyei

* __Fordítási idejű biztonság__: Mivel az érték megléte vagy hiánya explicit módon megjelenik a típusrendszerben, a fordító biztosítani tudja, hogy kezeled a „nincs érték” esetet, és ezzel a null értékekkel előforduló hibák széles csoportját előzi meg.

* __Futási idejű biztonság__: A `null` helyett az F# a `None` értékkel jelöli az érték hiányát, így `NullReferenceException` nem fordulhat elő.

* __Explicit kezelésre kényszerít__: A típusrendszer megköveteli, hogy a kód explicit módon kezelje mind a `Some value`, mind a `None` esetet, így a kód robusztusabb és kiszámíthatóbb lesz.

* __Együttműködik a mintaillesztéssel__: Az `Option` értékek zökkenőmentesen működnek együtt az F# mintaillesztési idiómájával: tiszta és biztonságos módot kínálnak arra, hogy szétbontsd és kezeld az értéket, ha létezik, vagy más műveletet végezz, ha nem.

## Használat 

Az `Option` típus generikus típus (amelynek van egy mögöttes típusa).  
Az `Option` értékek vagy `Some value` alakúak, ami egy konkrét értéket jelöl, vagy `None`, ami azt jelöli, hogy nincs érték.

A következő függvény bemutatja, hogyan hozhatsz létre `Option` értéket:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
A `T option` a `Option<T>` postfix szintaktikai megfelelője; a két szintaktikai forma felcserélhetően használható.
Az F# Style Guide szerint azonban az Option típusoknál a postfix jelölést érdemes előnyben részesíteni (lásd az [F# Style Guide típusok és típusannotációk formázásáról szóló szakaszát](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

Az `Option` tipikus felhasználási esete a keresőfüggvények. 
Például a `List.tryFind` függvény `Some index` értéket ad vissza, ha az elem benne van a listában (ahol `index` a keresett érték helye a listában), és `None`-t, ha az elem nincs benne a listában.

## Az `Option` érték tartalmának kiolvasása

Az `Option` érték kiolvasásának idiomatikus módja a mintaillesztés, ahogy a következő példa mutatja:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Az `Option` értékek kicsomagolása alapértelmezett értékekkel

Az `Option` értékek „kicsomagolhatók” (a bennük tárolt típusra alakíthatók), ha az `Option.defaultValue` függvénnyel alapértelmezett értéket adsz meg. 
Ez különösen akkor hasznos, ha biztosítani szeretnéd, hogy az érték ne `None` legyen.
Például:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## További függvények az `Option` modulban

Az `Option` modul olyan függvényeket is tartalmaz, amelyek megfelelnek a listákhoz, tömbökhöz, sorozatokhoz és más gyűjteménytípusokhoz elérhető függvényeknek, például `Option.map`, `Option.iter`, `Option.forall`, `Option.count`. 
Ezekkel a függvényekkel az `Option` értékek úgy kezelhetők, mint egy nulla vagy egy elemből álló gyűjtemény.
