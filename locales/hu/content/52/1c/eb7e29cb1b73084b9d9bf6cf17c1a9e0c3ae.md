# Utasítások

Ebben a feladatban névjelvényeket nyomtató kódot írsz majd gyári alkalmazottak számára.
Az alkalmazottaknak van egy azonosítójuk, egy nevük és egy részlegnevük.
Az alkalmazotti jelvények címkéi a következő formátumot követik: `"[id] - name - DEPARTMENT"`.

## 1. Jelvény készítése egy alkalmazottnak

Valósítsd meg a `print_name_badge` függvényt. Egy azonosítót, egy nevet és egy részleget kap paraméterként.
A jelvény címkéjét adja vissza, a részleg nevével csupa nagybetűvel.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Jelvény készítése egy új alkalmazottnak

A számítógépes rendszer egy furcsasága miatt az új alkalmazottaknak néha még nincs azonosítójuk, amikor elkezdenek a gyárban dolgozni.
Mivel a jelvények kötelezőek, kapnak egy ideiglenes jelvényt az azonosító előtagja nélkül.

Egészítsd ki a `print_name_badge` függvényt. Ha hiányzik az azonosító, a jelvényt azonosító nélkül nyomtassa ki.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Jelvény készítése a tulajdonosnak

A gyár tulajdonosának is mindig jelvényt kell viselnie.
A tulajdonosnak azonban nincs részlege, és soha nem is lesz: minden részleg felett áll.
Ebben az esetben a címke a részleg neve helyett `"OWNER"` szöveget ír ki.

Egészítsd ki a `print_name_badge` függvényt. Ha a részleg `NULL`, feltételezd, hogy a jelvény a cég tulajdonosáé.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

Vedd figyelembe, hogy előfordulhat, hogy a tulajdonos egyben új alkalmazott is.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. Az azonosító nélküli alkalmazottak teljes fizetésének kiszámítása

Durva mérőszámként arra, hogy mennyire jól osztják ki az azonosítókat, szeretnéd látni az azonosító nélküli alkalmazottak együttes fizetését.
A magas érték azt jelenti, hogy sokan várnak, vagy a probléma a tapasztalt munkatársakat is érinti: mindkettő rossz.

Valósítsd meg a `salaries_no_id` függvényt, amely egy azonosítóvektort és egy hozzá tartozó fizetésvektort kap, és visszaadja azon emberek fizetéseinek összegét, akiknek még nincs azonosítójuk.
Mindkét vektor ugyanolyan hosszú.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_Kipróbálatlan, extra tanulási feladat:_ Ha nincs azonosító nélküli alkalmazott, mi az az „üres vektor”, amit összegzel?
