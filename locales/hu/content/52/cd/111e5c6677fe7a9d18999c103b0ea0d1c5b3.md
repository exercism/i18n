# Bevezetés

## Ciklusok

A ciklusok segítségével valamilyen logikát ismételten végre tudsz hajtani.
A két leggyakoribb típus a `while loop` (határozatlan ismétlés) és a `for loop` (határozott, azaz megszámlált ismétlés).
Létezik még a `for each` ciklus is, amellyel egy későbbi fogalomnál találkozol majd.

### Általános szintaxis

A `for loop` egy fejlécből és egy kódblokkból áll; utóbbi a ciklus törzsét tartalmazza, kapcsos zárójelek közé zárva.
A fejléc három részből áll, amelyeket pontosvessző `;` választ el: inicializáló utasítás, feltétel és egy további kifejezés.
Ezek bármelyike lehet üres.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- Az **init_statement** rész olyan kód, amely csak egyszer fut le, még a ciklus elindulása előtt.
- A **condition** rész egy olyan kifejezés kell hogy legyen, amelynek az értéke `boolean`, és ez szabályozza, hogy mikor álljon le a ciklus.
  A cikluson belüli kód addig fut le, amíg ez a feltétel `true` értékű.
  Amint ez a kifejezés `false` értékű lesz, a ciklus további iterációi már nem futnak le.
- Az **expression** rész olyan kód, amely minden iteráció végén lefut.

A `while loop` mindaddig végrehajtja a törzsét, amíg a **condition** ellenőrzése `true`.
Az alábbi kódrészlet megmutatja, hogyan alakíthatsz át egy `for` ciklust egy `while loop` ciklussá.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### Kitérő: növelés és csökkentés

Amikor ciklusokkal dolgozol, gyakran szükség van arra, hogy egy számlálóváltozóhoz hozzáadj 1-et vagy kivonj belőle 1-et; ez a változó tartja nyilván az iterációkat.
Ez annyira gyakori, hogy a növelésre és a csökkentésre külön operátorok vannak: `++` és `--`.

**prefix** és **postfix** formában léteznek.
A prefix még az utasításban való felhasználás előtt módosítja a változót, a postfix pedig utána.
A legtöbb esetben valószínűleg a prefix változatot szeretnéd használni.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### A for ciklus - egy példa

Az _init rész_ általában beállít egy számlálóváltozót, a _condition_ ellenőrzi, hogy a ciklust folytatni kell-e vagy leállítani, a _post rész_ pedig általában minden ismétlés végén növeli a számlálót.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Ez a ciklus a `1`-től `9`-ig terjedő számokat adja össze (a `9`-et is beleértve).

### A break és a continue

Egy ciklus törzsén belül a `break` kulcsszóval teljesen leállíthatod a ciklus végrehajtását:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Ezzel szemben a `continue` kulcsszó csak az aktuális iteráció végrehajtását állítja le, és a következővel folytatja:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
A ciklus logikáját általában könnyebb megérteni, ha a `break` és a `continue` használatát minimalizálod vagy teljesen elkerülöd.
Mindkét kulcsszó kihagyja a kód bizonyos részeit, és gyakran megnehezíti a nyomon követést.
~~~~
