# Feltételes elágazások

A Rubyban vannak úgynevezett vezérlési kifejezések, amelyekkel szabályozható, hogyan fut le a program, és igaz vagy hamis értéket vesznek fel.
Vannak operátorok, amelyekkel igaz vagy hamis értékeket hozhatunk létre, ezeket [összehasonlító operátoroknak][comparison-operators] nevezzük.

Két fő vezérlési kifejezés szabályozza, hogy melyik kód fusson le és melyik ne.
Más szóval, hogy melyik ág fut le.

Ez a kettő: az `if` és az `unless` kifejezés.

## Összehasonlító operátorok

Az [összehasonlító operátorok][comparison-operators] segítségével értékeket hasonlíthatunk össze, és `true` vagy `false` értéket adnak vissza.
A következő operátorokhoz két, azonos típusú értékre van szükség az összehasonlításhoz.
Ha az értékek nem azonos típusúak, akkor a fordító hibát dob.
Íme az operátorok listája, és egy példa arra, amikor `true` értéket adnak:

| Method | Description           | Example |
| ------ | --------------------- | ------- |
| <      | kisebb mint           | 4 < 5   |
| <=     | kisebb vagy egyenlő   | 4 <= 4  |
| >      | nagyobb mint          | 3 > 1   |
| >=     | nagyobb vagy egyenlő  | 2 >= 2  |

Az egyenlőség- és nem-egyenlőség-operátorokkal bármilyen típusú érték összehasonlítható, ellentétben a korábban említett operátorokkal.
A `==` operátorral ellenőrizhetjük, hogy két érték egyenlő-e, és ez magában foglalja az érték típusának ellenőrzését is.
A `!=` ugyanígy működik, de `true` értéket ad vissza, ha az értékek nem egyenlők, és `false` értéket, ha egyenlők.
Íme az egyenlőség- és nem-egyenlőség-operátorok listája, és egy példa arra, amikor `true` értéket adnak:

| Method | Description  | Example |
| ------ | ------------ | ------- |
| ==     | egyenlő      | 4 == 4  |
| !=     | nem egyenlő  | 5 != 4  |

## Az if elágazás

Az [`if`][if] elágazással ellenőrizhető, hogy egy adott feltétel „igaz” vagy „hamis” értékű-e.
Ha a feltétel igaz értékű, akkor lefut az if elágazáson belüli kód.
Az `if` elágazás az `end` kulcsszóval zárul.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Az unless elágazás

Az `unless` elágazás nagyon hasonlóan működik az `if` elágazáshoz, de akkor futtatja az `unless` elágazáson belüli kódot, ha a feltétel hamis értékű.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Az else elágazás

Az `else` elágazás az `if` elágazással együtt használható.
Az `else` elágazás akkor fut le, ha az `if` ág nem fut le.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## „Cascading-if” elágazások

Az `elsif` elágazás az if elágazással együtt használható.
Az `elsif` elágazás akkor fut le, ha az if ág nem fut le, és az elsif elágazás feltétele igaz értékű.
Az elsif elágazások láncba fűzhetők, és az első igaz feltétel fut le.
Az if elágazás végén egy else elágazás is állhat, amely akkor fut le, ha a korábbi elágazások egyike sem volt igaz.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
