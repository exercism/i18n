# Bevezetés

## For ciklusok

A `for` utasítás egy kódblokkot ismétel.
Az első sora határozza meg, hogy a blokk hányszor ismétlődik:

```go
for init; condition; post {
    // loop body
}
```

- Az **init** utasítás egyszer fut le, az első iteráció előtt. Gyakori, hogy itt deklarálod a ciklus által használt számlálóváltozót, és megadod a kezdőértékét.
- A **condition** egy Boolean-kifejezés, amelyet minden iteráció előtt kiértékelünk. A ciklus akkor áll le, amikor a kifejezés értéke `false` lesz.
- A **post** utasítás minden befejezett iteráció után fut le. Használható arra, hogy frissítsd a számlálót.

Ne rakd zárójelbe az `init; condition; post` részt.
A ciklus törzsét körülvevő kapcsos zárójelek `{ }` viszont mindig kötelezőek.

Ez a ciklus `1`-ről indítja az `i`-t, kiírja az `i` aktuális értékét, növeli a következő iterációhoz, és leáll, amikor az `i` eléri a `10`-et:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
