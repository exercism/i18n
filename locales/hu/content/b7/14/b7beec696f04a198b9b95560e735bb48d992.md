# Utasítások

Egy online divatbutikot vezetsz. Közeleg a nagy éves akció, ezért számba kell venned a készletedet, hogy biztosan felkészülj.

A készletben egyetlen elemet egy map reprezentál, a teljes készlet pedig az ilyen mapek listája.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Elemek rendezése ár szerint

Valósítsd meg a `sort_by_price/1` függvényt. A készletet kapja meg, és adja vissza ár szerint növekvő sorrendbe rendezve.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Az összes hiányzó árú elem megkeresése

Miután ár szerint rendezted a készletedet, észrevetted, hogy hibáztál a leltározásnál, és néhány elemnél elfelejtetted kitölteni az árat.

Valósítsd meg a `with_missing_price/1` függvényt. A készletet kapja meg, és adja vissza azon elemek listáját, amelyeknek nincs ára.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Elemnevek frissítése

Észrevetted, hogy néhány elem nevében szerepel egy szó, amit már nem szeretnél használni. Most frissítened kell minden olyan elemnevet, amelyben ez a szó szerepel.

Valósítsd meg az `update_names/3` függvényt. A készletet, az eltávolítani kívánt régi szót és a helyette használni kívánt új szót kapja meg. Adja vissza a frissített nevű elemek listáját.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Az elem mennyiségének növelése

Néhány elem különösen jól fogyott, ezért minden méretben rendeltél belőle többet.

Valósítsd meg az `increase_quantity/2` függvényt. Egyetlen elemet és egy `n` számot kap, és visszaadja azt az elemet, amelyben minden méret mennyisége `n`-nel nőtt.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Az elem teljes mennyiségének kiszámítása

Ahhoz, hogy tudd, mennyi helyre lesz szükséged a raktáradban, tudnod kell, hogy összesen hány darab van az egyes elemekből.

Valósítsd meg a `total_quantity/1` függvényt. Egyetlen elemet kap, és visszaadja, hogy összesen hány darabod van belőle, bármilyen méretben.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
