# Kiírás

A Cairoban a kiírás lehetővé teszi, hogy üzeneteket és értékeket jeleníts meg a konzolon, ami megkönnyíti a programok hibakeresését, és segít információt közölni a futás során.

A kiírási rendszer egyszerre sokoldalú és egyszerű: olyan eszközöket nyújt, amelyekkel különféle típusú adatokat formázhatsz és írhatsz ki.

## A kiírás alapjai

A Cairo két elsődleges makrót kínál szöveg konzolra írásához:

- **`println!`**: A kimenetet egy új sorba írja.
- **`print!`**: A kimenetet ugyanabba a sorba írja, új sor hozzáadása nélkül.

Mindkét makró első argumentumként egy `ByteArray`-t vár, ami lehet egyszerű string vagy helyőrzőket tartalmazó formázott string.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

A fenti példában:

- A `{}` helyőrzőket az `x` és `y` értéke helyettesíti.
- A `println!` gondoskodik róla, hogy a kimenet új sorral záruljon.

## Stringek formázása

Néha előfordulhat, hogy formázott stringet kell létrehoznod anélkül, hogy azonnal kiírnád.

Erre szolgál a `format!` makró.

Hasonlóan működik, mint a `println!`, de ahelyett, hogy a konzolra írna, egy `ByteArray`-t ad vissza.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

Ebben a példában:

- A `format!` egyetlen stringgé fűzi össze az `s1`, `s2` és `s3` változót, kötőjelekkel (`-`) elválasztva őket.
- A kapott stringet később újra felhasználhatod vagy kiírhatod.

## Egyedi adattípusok kiírása

Alapértelmezés szerint a Cairo csak alapvető típusokat, például egészeket és stringeket tud kiírni.

Ha egy egyedi típust, például egy structot próbálsz kiírni, hibát kapsz, hacsak a típus nem implementálja a `Display` vagy `Debug` traitet.

### A `Display` használata egyedi formázáshoz

A `Display` trait segítségével meghatározhatod, hogyan íródjon ki egy egyedi típus.

Nézzünk egy példát:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

Ebben a példában:

- A `fmt` függvény határozza meg, hogyan alakul a `Point` struct kiírható stringgé.
- A `write!` makró hozzáfűzi a formázott stringet a `Formatter`-hez.

### Hibakeresés a `Debug` segítségével

Hibakeresési célokra a Cairo biztosítja a `Debug` traitet.

A legtöbb típusnál automatikusan származtathatod, így gyorsan és egyszerűen kiírhatod a structjaid belső részleteit.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

Ebben a példában:

- A `#[derive(Debug)]` automatikusan legenerálja a `Debug` trait implementációját.
- A `{:?}` helyőrző megmondja a `println!`-nak, hogy a formázáshoz a `Debug` traitet használja.

## Kiírás hexadecimális formátumban

A Cairoban az egészeket hexadecimális formátumban is kiírhatod a `{:x}` helyőrzővel.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

Ez különösen hasznos, amikor alacsony szintű adatreprezentációkkal dolgozol.
