# Getterek és setterek

A getterek és a setterek olyan metódusok, amelyekkel egy objektum tulajdonságának értékét olvashatod és írhatod.
A Crystalban vannak makrók, amelyekkel könnyen definiálhatsz gettereket és settereket egy tulajdonsághoz.
A makrók segítségével fordítási időben generálhatsz kódot, amiről később, a makró fogalmánál lesz szó.

A Rubyban ezeket a metódusokat az `attr_reader`, `attr_writer` és `attr_accessor` metódusokkal definiálod, és első ránézésre nagyon hasonlítanak a Crystal megvalósításához.
A Crystal ezeket `getter`, `setter` és `property` makróként definiálta.

## Getterek

A getter egy olyan makró, amely definiál egy metódust, ami visszaadja egy példányváltozó értékét.
Ez azt jelenti, hogy többé nem kell `@`-t írnod a példányváltozó elé, amikor hozzá akarsz férni (a metódusokban, az initialize kivételével); helyette meghívhatod azt a metódust, amelyet a getter makró definiált.

A getter makró több példányváltozót is elfogad, ha vesszővel választod el őket.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Amint láthatod, a getter használatával kevesebb kódot írsz, és a kód olvashatóbb lesz.
A Ruby és a Crystal között az is különbség, hogy a Crystal a getter makró argumentumaként elfogadja mind a változónevet, mind a szimbólumot.
A szimbólumokról később, a szimbólum fogalmánál lesz szó.

## Setterek

A setter egy olyan makró, amely definiál egy metódust, ami beállítja egy példányváltozó értékét.
Ez a makró nem túl gyakori, helyette többnyire a `property` makrót használják.
A létrejövő metódusok így néznek ki: `name_of_method=`; az `=` teszi lehetővé, hogy a tulajdonság beállítható legyen.

Ez a metódusdefiníció kicsit különleges, mert a metódus az argumentumát az `=` jel után kapja.
A Crystalban több más különleges metódus is ezt a szintaxist használja, például a `+` metódus.

A getter makróhoz hasonlóan, miután definiáltál egy settert, a példányváltozó értékének frissítéséhez meghívhatod azt a metódust, amelyet a setter makró definiált.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

A property egy olyan makró, amely egyszerre definiál gettert és settert egy példányváltozóhoz.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
