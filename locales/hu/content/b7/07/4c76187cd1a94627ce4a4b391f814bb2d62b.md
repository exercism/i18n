# Tesztek

A `t/` könyvtárban található egy `.t` kiterjesztésű Perl-szkript, amellyel a megoldásodat tesztelheted.
A teszteket ezzel a paranccsal futtathatod:

```bash
`prove`
```

A tesztfájlokban használt állításokról a [Test2::Manual::Testing::Introduction][test2-manual] oldalon találsz dokumentációt.

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
