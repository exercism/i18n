# Bevezetés

A Swift a szintaxisa egy változatát kínálja a closure-ök kezelésekor: ezt nevezik trailing closure-öknek. Trailing closure-ök akkor jönnek létre, amikor egy függvény paraméterlistájának utolsó paramétere függvénytípusú. Ebben az esetben, ha closure-t adunk át, a closure a záró zárójel _után_ is írható, és az argumentumcímke elmarad. Jegyezd meg, hogy ha a függvénynek csak egyetlen paramétere van, a zárójelek teljesen elhagyhatók.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
