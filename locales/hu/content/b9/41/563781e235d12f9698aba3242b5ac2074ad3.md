# Tesztek

## Tesztek futtatása

Amikor egy feladat könyvtárában vagy, két alkönyvtárat kell látnod:

* `src` tartalmazza a feladatra adott megoldásodat
* `spec` tartalmazza a feladathoz futtatandó teszteket

Ha a megfelelő könyvtárban vagy (vagyis abban, amelyik a `src` és a `spec` könyvtárat tartalmazza), a feladat tesztjeit a `crystal spec` futtatásával indíthatod el:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Ez a `spec` könyvtárban lévő összes tesztfájlt lefuttatja.

Minden tesztfájlban az első kivételével az összes teszt ki van hagyva.

Amint egy teszt sikeresen lefut, a következő kihagyását úgy oldhatod fel, hogy a `pending`-et `it`-re módosítod.

## Crystal-formázás

Beküldés előtt érdemes lefuttatnod a `crystal tool format` parancsot a megoldásodon.

A jelenlegi könyvtáradban lévő összes fájlt így formázhatod:

```bash
$ crystal tool format ./
```

Vagy csak bizonyos fájlokat is formázhatsz:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## A megoldásod beküldése

A megoldásod beküldésekor mindenképp a `src` könyvtárban lévő forrásfájlt küldd be:

```bash
$ exercism submit src/<exercise>.cr
```
