# Bevezetés

A Common Lisp a legtöbb műveletnél a szokásos aritmetikai operátorokat használja, de némileg egyedi abban, hogy „prefix jelölést” használ a jóval ismertebb „infix jelöléssel” szemben.

Szemléletesebben:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Bár a prefix jelölés egyes műveleteket, például a `2 + 2`-t a kissé szokatlan `(+ 2 2)` formába írja át, sokkal könnyebbé teszi, hogy egyszerre több számon végezz műveletet.

## Alapműveletek

A Common Lispben megtalálható az összes szokásos függvény: a `+`, a `-`, a `*` és a `/` az összeadáshoz, kivonáshoz, szorzáshoz és osztáshoz.

Az osztásnál néha jó tudni az osztás maradékát; erre való a `mod` (modulo) függvény, amely egy számot és egy osztót vár argumentumként:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## Számok összehasonlítása

Végül érdemes lehet összehasonlítani a számokat olyan függvényekkel, mint a `=` (egyenlő), a `/=` (nem egyenlő) és a `>=` (nagyobb vagy egyenlő).
Ha ezek az összehasonlítások igazak (mint a `(= 1 1)` esetében), `T`-t adnak vissza, ha pedig nem (mint a `(> 0 1)` esetében), akkor `NIL`-t.
