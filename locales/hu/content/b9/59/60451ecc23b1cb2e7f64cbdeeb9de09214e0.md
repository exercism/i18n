# Bevezetés

## Időtartamok és periódusok

Az olyan osztályok, mint a `LocalDate` és a `LocalDateTime`, egy _időpontot_ írnak le.
A `java.time` csomagban két olyan osztály is van, amely egy _időmennyiséget_ ír le:

- A `java.time.Period` években, hónapokban és napokban mért időmennyiség, például „2 hónap és 5 nap”.
- A `java.time.Duration` órákban, percekben, másodpercekben, ezredmásodpercekben és nanoszekundumokban mért időmennyiség, például „1 óra és 30 perc”.

A `Period` a naptárt követi, ezért dátumokkal és dátum-időkkel használjuk.
A `Duration` pontos időt mér, ezért időkkel és dátum-időkkel használjuk, dátumokkal viszont nem.

```exercism/note
A többi `java.time` osztályhoz hasonlóan a `Period` és a `Duration` is megváltoztathatatlan.
A metódusok, amelyekről úgy tűnik, hogy megváltoztatják őket, valójában egy _új_ példányt adnak vissza.
```

### `Period`

A `Period` példányt az egyik statikus gyártómetódusával hozod létre:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

A `toString()` eredménye az [ISO-8601][iso-8601-durations] jelölést használja: a `P` (a „period” szóból), majd az évek (`Y`), a hónapok (`M`) és a napok (`D`) száma.

Egy periódust hozzáadhatsz egy dátumhoz, vagy kivonhatsz belőle:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Mivel a hónapok hossza eltérő, a hónapok hozzáadása olyan napra eshet, amely nem létezik.
Ilyenkor az eredmény visszakerül a hónap utolsó érvényes napjára:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

A `Period.between()` az egyik dátumtól (beleértve) a másikig (nem beleértve) tartó periódust adja vissza:

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### Egységek számlálása a `ChronoUnit` segítségével

A `Period` külön tartja számon az éveket, a hónapokat és a napokat.
Ezért a `getDays()` csak a periódus napokban mért _részét_ adja vissza, nem a napok összes számát.
Ha két dátum között egyetlen egység teljes mennyiségét akarod megszámolni, a [`java.time.temporal.ChronoUnit`][chronounit-docs] `between()` metódusát használd:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

Az eredmény negatív, ha a második dátum korábbi az elsőnél:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

A `Duration` példányt is statikus gyártómetódusokkal hozod létre:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

Az ISO-8601 jelölésben a `T` választja el a dátum részt az idő résztől, ezért írjuk az időtartamokat `PT...` alakban.

Egy időtartamot hozzáadhatsz egy dátum-időhöz, vagy kivonhatsz belőle:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

A `Duration.between()` a két dátum-idő közötti pontos időmennyiséget adja vissza:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Egy időtartamot egyetlen egységre válthatsz át olyan metódusokkal, mint a `toHours()`, a `toMinutes()` és a `toSeconds()`.
Ezek az adott egységben mért _teljes_ mennyiséget adják vissza, lefelé kerekítve:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Ha egy időtartamot fel akarsz bontani a részeire, ahogy egy órán, akkor helyette a `toXxxPart()` metódusokat használd:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
