# Bevezetés

A logikai érték azt fejezi ki, hogy egy feltétel `true` vagy `false`.
Go-ban a `bool` típus kizárólag ezt a két értéket veheti fel.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## Logikai operátorok

A logikai operátorok egy vagy két logikai értéken működnek, és logikai értéket adnak eredményül.

| Operátor | Név | Működés                                            |
| -------- | --- | -------------------------------------------------- |
| `!`      | NOT | Egy logikai érték ellentétét adja vissza           |
| `&&`     | AND | Csak akkor ad `true`-t, ha mindkét oldal `true`    |
| `\|\|`   | OR  | Akkor ad `true`-t, ha valamelyik oldal `true`      |

A `!` (NOT) operátort akkor használd, ha egy logikai érték ellentétére van szükséged:

```go
!isDoorLocked // false
```

A `&&` (AND) operátort akkor használd, ha mindkét feltételnek `true`-nak kell lennie:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

A `||` (OR) operátort akkor használd, ha legalább az egyik feltételnek `true`-nak kell lennie:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

A logikai operátorok kiértékelési sorrendje a következő: először a `!`, aztán a `&&`, végül a `||`.
Zárójelekkel csoportosíthatod a kódot, és szabályozhatod, hogy melyik művelet hajtódjon végre előbb:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
