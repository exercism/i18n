## General

Ne a `SimpleLinkedList` structot valósítsd meg egy `Vec` körüli burkolóként. Helyette a csomópontokat a heapen foglald le.

Ezt valahogy így lehet megvalósítani:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

A `head` mező a láncolt lista első elemére (Node) mutat.

Ennek a megvalósításnak szüksége van egy `Node` structra is, a következő mezőkkel:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

A `data` tárolja az adatot, a `next` pedig a következő csomópontra mutat (ha létezik), vagy None-ra.

## Miért `Option<Box<Node<T>>>` és miért nem csak `Option<Node<T>>`?

Próbáld ki magad. A következő hibát kapod:

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

A probléma az, hogy fordításkor a next méretének ismertnek kell lennie.
Mivel a `next` rekurzív (»egy csomópontnak van egy csomópontja, annak megint egy csomópontja...«), a fordító nem tudja, mennyi memóriát kell lefoglalni.
Ezzel szemben a [Box](https://doc.rust-lang.org/std/boxed/) egy meghatározott méretű heap-mutató.
