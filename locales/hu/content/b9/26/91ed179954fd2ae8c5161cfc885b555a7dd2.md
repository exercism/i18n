# Bevezetés

A kommentek segítségével jegyzeteket hagyhatsz a kódban anélkül, hogy az befolyásolná a program működését.
Az egysoros komment `//`-tal kezdődik, a többsoros kommentet pedig `/*` és `*/` fogja közre:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

A kommentek szerepe attól függ, hogy hol helyezkednek el a kódban.

## Kódkommentek

A kódkommentek azt magyarázzák meg, hogy valamit miért teszünk, nem azt, hogy mit.
Akkor érdemes őket használni, ha a döntés oka nem nyilvánvaló a kódból:

```go
results = results[1:] // skipping the header row
```

## Dokumentációs kommentek

A dokumentációs kommentek közvetlenül egy deklaráció előtt helyezkednek el, és nem választja el üres sor őket a deklarációtól.
A [`godoc`][godoc] ezeket feldolgozva állítja elő a csomag dokumentációját.
A dokumentációs komment legyen teljes mondat, amely az azonosító nevével kezdődik, és ponttal végződik.

A csomagkommentek a csomag nevével kezdődnek:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

A függvénykommentek a függvény nevével kezdődnek:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
