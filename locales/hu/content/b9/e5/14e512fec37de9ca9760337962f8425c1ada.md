De a dolgok kissé rendezetlenek: Azara koordinátái látszólag máshogy vannak formázva és rendezve, mint Ruiéi, és folyton egyik listáról a másikra kell pillantaniuk, hogy kitalálják, melyik kincs melyik helyszínhez tartozik.
Mivel feltörekvő pythonisták, hozzád fordultak segítségért, hogy írj egy kis programot (valójában függvények egy csoportját), amellyel jobban rendszerezhetik a vadászat adatait.


## 1. Koordináták kinyerése

Valósítsd meg a `get_coordinate()` függvényt, amely átvesz egy `(treasure, coordinate)` párt Azara listájáról, és csak a kinyert térképkoordinátát adja vissza.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. Koordináták formázása

Valósítsd meg a `convert_coordinate()` függvényt, amely átvesz egy "2A" formátumú koordinátát, és egy `("2", "A")` formátumú tuple-t ad vissza.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. Koordináták egyeztetése

Valósítsd meg a `compare_records()` függvényt, amely átvesz egy `(treasure, coordinate)` párt és egy `(location, coordinate, quadrant)` rekordot, majd összehasonlítja a bennük lévő koordinátákat.
Add vissza a **`True`** értéket, ha a koordináták „egyeznek”, és a **`False`** értéket, ha nem.
A pontos összehasonlításhoz formázd újra a koordinátákat, ahogy szükséges.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. Egyező rekordok összevonása

Valósítsd meg a `create_record()` függvényt, amely átvesz egy `(treasure, coordinate)` párt Azara listájáról és egy `(location, coordinate, quadrant)` rekordot Rui listájáról, majd visszaadja a `(treasure, coordinate, location, coordinate, quadrant)` értéket **ha a koordináták egyeznek**.
Ha a koordináták _nem_ egyeznek, add vissza a **"not a match"** szöveget.
A pontos összehasonlításhoz formázd újra a koordinátát, ahogy szükséges.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```

## 5. „Takarítás” és jelentés készítése az összes rekordról
