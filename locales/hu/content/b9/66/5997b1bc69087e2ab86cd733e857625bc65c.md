# Tesztek

## Beállítás

A szükséges függőségek telepítéséhez kövesd a WebAssembly [beállítási útmutatóját][docs-exercism-wasm].

## Követelmények

Telepítsd a feladat függőségeit:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## A tesztek sikeres teljesítése

Minden feladathoz tartozik tesztkészlet, amely segít ellenőrizni a megoldásodat a beküldés előtt.
A teszteket úgy futtathatod, hogy megnyitsz egy parancssort a feladat könyvtárában, majd lefuttatod a következőt:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

Némelyik tesztkészletben az elsőn kívül az összes teszt ki van kapcsolva.

Amint egy teszt sikeres lesz, a következőt úgy kapcsolhatod be, hogy az `xtest`-et `test`-re változtatod.

## Saját tesztek írása

Ha további, saját teszteket szeretnél írni, hozz létre egy új `custom.spec.js` fájlt, és az új fájlt a megoldásoddal együtt küldd be:

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
