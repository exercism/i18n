# Utasítások

Ez a feladat a naplófájlok elemzésével foglalkozik.

Egy nemrég lezajlott biztonsági felülvizsgálat után arra kértek, hogy tisztítsd meg a szervezet archivált naplófájljait.

A metódusoknak átadott összes string garantáltan nem null, és nem kezdődik vagy végződik szóközzel.

## 1. Azonosítsd a hibás naplósorokat

Valamilyen képet kell alkotnod arról, hogy az archívumodban hány naplósor nem felel meg a jelenlegi szabványoknak. Úgy gondolod, hogy egy egyszerű vizsgálat megmutatja, hogy egy naplósor érvényes-e. Ahhoz, hogy egy sor érvényesnek számítson, a következő stringek egyikével kell kezdődnie:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

Valósítsd meg a `LogParser.IsValidLine()` metódust úgy, hogy `false`-t adjon vissza, ha egy string nem érvényes, egyébként pedig `true`-t.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. Bontsd fel a naplósort

Egy új csapat csatlakozott a szervezethez, és azt tapasztalod, hogy a naplófájljaik furcsa elválasztót használnak a „mezőkhöz”. Ahelyett, hogy valami értelmeset használnának, például egy kettőspontot („:”), olyan stringet használnak, mint a „<--->” vagy a „<=>” (mert az szebb), sőt valójában bármilyen stringet, amelynek az első karaktere „<”, az utolsó pedig „>”, a közte lévő karakterek pedig a következők bármilyen kombinációjából állhatnak: „^”, „\*”, „=” és „-”.

Valósítsd meg a `LogParser.SplitLogLine()` metódust, amely egy sort kap, és stringek egy tömbjét adja vissza, amelyek mindegyike egy mezőt tartalmaz.

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. Számold meg az idézőjelbe zárt jelszót tartalmazó sorokat

A csapatnak tudnia kell az idézőjelbe zárt szövegben előforduló jelszavakról, hogy kézzel is megvizsgálhassák őket.

Valósítsd meg a `LogParser.CountQuotedPasswords()` metódust, hogy képet adjon a kézi vizsgálat várható nagyságrendjéről.

Azonosítsd azokat a naplósorokat, amelyekben a „password” literál string, amely bármilyen kis- és nagybetű-kombinációban állhat, idézőjelek között van.
Számolnod kell azzal a lehetőséggel is, hogy az idézőjelek között a „password” előtt és után további tartalom szerepel.

Az eljárásnak átadott sorok lehetnek érvényesek az 1. részfeladatban meghatározottak szerint, de nem is. Akár érvényesek, akár nem, ugyanúgy dolgozzuk fel őket.

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. Távolítsd el a naplóból a maradványokat

Felfedezted, hogy a naplók valamely korábbi feldolgozási lépése szétszórta a naplókban az „end-of-line” szöveget, amelyet egy sorszám követ (közbeeső szóköz nélkül).

Valósítsd meg a `LogParser.RemoveEndOfLineText()` metódust, amely egy stringet kap, eltávolítja belőle az end-of-line szöveget, és egy „tiszta” stringet ad vissza.

Az end-of-line szöveget nem tartalmazó sorokat változatlanul kell visszaadni.

Csak az end of line stringet távolítsd el. Ne próbáld módosítani a szóközöket.

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. Sorold fel a rendkívül gyenge jelszavakat tartalmazó sorokat, hogy megbüntethessük a bűnösöket

Mielőtt kitörölnénk a jelszavakat a fájlból, fel kell sorolnunk minden olyan esetet, ahol a jelszavak a „password” szöveggel kezdődnek.

Valósítsd meg a `LogParser.ListLinesWithPasswords()` metódust, amely kiírja a kifogásolt jelszót, majd utána a teljes sort.

Az idézőjelbe zárt jelszavakat tartalmazó sorokat már eltávolítottuk, és a sorokat attól függetlenül dolgozod fel, hogy érvényesek-e (az 1. részfeladat szerint).

A kifogásolt jelszót tartalmazó sorokat „<password>: ” előtaggal kell visszaadni.

A kifogásolt jelszót nem tartalmazó sorokat „--------: ” előtaggal kell visszaadni.

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
