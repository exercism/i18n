# Kiegészítés az utasításokhoz

## Beállítás

Nézd át a TypeScript beállítási útmutatóját a szükséges függőségek telepítéséhez:

[https://exercism.org/docs/tracks/typescript/installation](https://exercism.org/docs/tracks/typescript/installation)

## Követelmények

Telepítsd a feladat függőségeit:

```bash
$ yarn install
```

## A tesztcsomag sikeres teljesítése

Futtasd a teszteket ezzel:

```bash
$ yarn test
```

Sok tesztcsomagban az első kivételével az összes teszt le van tiltva.

Ha egy teszt sikeres lett, a következőt úgy aktiválhatod, hogy a `xit`-et `it`-re változtatod.

## Útmutató

Ez a szakasz lépésről lépésre útmutató a feladat megoldásához.

A feladatnak két fájlja van:

- hello-world.ts
- hello-world.test.ts

Az első fájlba írod a kódodat.
A másodikban vannak meghatározva a tesztek.

A tesztek ellenőrzik, hogy a kódod a megfelelő dolgot teszi-e.
Nem kell nulláról tesztcsomagot írnod, de hasznos megérteni, hogyan néz ki egy teszt, és mit csinál.

Nyisd meg a hello-world.test.ts tesztfájlt.
Egyetlen teszt van benne:

```typescript
it('says hello world', () => {
  expect(hello()).toEqual('Hello, World!')
})
```

Futtasd le a tesztet most, a következő parancssori utasítással:

```bash
$ yarn test
```

A teszt sikertelen, ami logikus, hiszen még nem írtál kódot.

A hiba így néz ki:

```
    × says hello world (5ms)

  ● Hello World › says hello world

    expect(received).toEqual(expected) // deep equality

    Expected: "Hello, World!"
    Received: "Goodbye, Mars!"

      4 |
      5 |   it('says hello world', () => {
    > 6 |     expect(hello()).toEqual('Hello, World!')
        |                     ^
      7 |   })
      8 |
      9 | })

      at Object.it (hello-world.test.ts:6:32)
```

És ezek azok a kódsorok, amelyek valószínűleg hibásak a `hello-world.test.ts` fájlban:

a 6. sor:

```typescript
    expect(hello()).toEqual('Hello, World!')
                    ^
```

Tehát a probléma a `hello()` függvényhívással van.
Láthatjuk, hogy a teszt a `'Hello, World!'` kimenetet várja, de helyette a `"Goodbye, Mars!"`-t kapja.

Nézzük meg most ezt a függvényt a `hello-worlds.ts` fájlban:

```typescript
export function hello(): string {
  return 'Goodbye, Mars!'
}
```

Most látjuk, hogy a függvény a helytelen stringet adja vissza, ami a hiba oka. Javítsuk ki a visszaadott érték megváltoztatásával:

```typescript
export function hello(): string {
  return 'Hello, World!'
}
```

Futtasd le újra a tesztet:

```bash
 PASS  ./hello-world.test.ts
  Hello World
    √ says hello world (4ms)
```

És sikeres!
