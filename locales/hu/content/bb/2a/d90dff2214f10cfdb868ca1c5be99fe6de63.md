# Névjegy

A C# típusok definiálhatók egy osztály vagy struktúra scope-ján belül. A tartalmazó típus egyfajta névteret biztosít. A típus a tartalmazó típuson keresztül érhető el pont szintaxissal.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Hozzáférési szintek

A hozzáférési szintek a belső típusokra is alkalmazhatók. Például ha egy osztály `private`, akkor nem látható a tartalmazó típus scope-ján kívül, és természetesen a példányai sem láthatók vagy használhatók a scope-ján kívül.

A külső osztály privát tagjai a belső osztály összes tagjának a scope-jába tartoznak, de csak a belső osztály nem privát tagjai tartoznak a külső osztály tagjainak a scope-jába. Ahhoz, hogy a belső osztály hozzáférjen a külső osztály tagjaihoz, a belső osztálynak kapnia kell egy példányt a külső osztályból.

Ez a következő példában látható:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Az önálló példányosítás megakadályozása

Van egy minta, amellyel megakadályozható, hogy egy példányosítható típus a tartalmazó típuson kívül jöjjön létre. Elérhetővé teszel egy nyilvános interfészt, de az implementáló osztályt privátként hagyod.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Megjegyzés Java-fejlesztőknek

A C# beágyazott osztályai a Java statikus beágyazott osztályainak és belső osztályainak a keverékei. A C#-ban a tartalmazó osztály privát tagjai a beágyazott osztály tagjainak a scope-jába tartoznak, de nincs különleges szintaxis arra, hogy példányosítsd őket, és a tartalmazó osztály egy példányához kapcsold őket. A fenti példákban bemutatott minta valamelyik változatát kell használnod.

A C#-ban valóban vannak statikus beágyazott osztályok, de ezek egyszerűen más osztályba zárt, statikus viselkedésű osztályok.
