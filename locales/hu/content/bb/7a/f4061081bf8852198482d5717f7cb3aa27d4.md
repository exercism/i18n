# Utasítások

A tervezőcsapatod néhány elrendezési feladatnál a CSS-transzformációkról áttér a Factorra. Hogy a csapat többi tagja is elégedett legyen, kicsi, újrahasznosítható transzformációkat készítesz quotation formájában, amelyek egy kétdimenziós pontot vesznek át, és egy kétdimenziós pontot adnak vissza.

Egy pont egy kételemű tömb (`{ x y }`).

## 1. A koordináták eltolása

Definiáld a `translate-2d` szót úgy, hogy két értéket, `dx`-et és `dy`-t vegyen le a veremről, és egy olyan quotationt adjon vissza, amely `(dx, dy)`-nal eltol egy pontot.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. A koordináták skálázása

A `scale-2d` szót ugyanígy definiáld: adjon vissza egy olyan quotationt, amely `(sx, sy)`-nal skáláz egy pontot.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. Két transzformáció összefűzése

Definiáld a `compose-transformations` szót úgy, hogy két transzformáció-quotationt, `f`-et és `g`-t vegyen át, és egyetlen olyan quotationt adjon vissza, amely először `f`-et, majd `g`-t alkalmazza.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. Transzformáció alkalmazása

Definiáld az `apply-transformation` szót úgy, hogy egy pontot és egy transzformáció-quotationt vegyen le a veremről, és a transzformált pontot adja vissza.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. Több pont átalakítása egyszerre

Definiáld a `transform-points` szót úgy, hogy egy ponttömböt és egy transzformáció-quotationt vegyen át, és a transzformált pontok tömbjét adja vissza.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
