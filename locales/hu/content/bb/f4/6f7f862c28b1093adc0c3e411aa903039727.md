# Utasítások

Ebben a feladatban ismét a távirányítós autókkal fogsz dolgozni.

Kifejlesztettek egy kísérleti autót, és a tesztpályát is át kell alakítani, hogy mind a sorozatgyártott, mind a kísérleti modelleket kezelni tudja.
A két autótípus már elkészült, és neked kell megoldást találnod arra, hogy a tesztpálya mindkettővel boldoguljon.

Ráadásul a sorozatgyártott autók kezdenek sikereket elérni.
A csapatfőnök szeretné fenntartani a versenyszellemet, ezért közzé akarja tenni a sorozatgyártott autók rangsorát.

## 1. Valósítsd meg az interfészt

Adj hozzá két metódust a `RemoteControlCar` interfészhez:

- `drive()`, amely nem ad vissza semmit, és
- `getDistanceTravelled()`, amely egy `int` értéket ad vissza.

Ezután gondoskodj róla, hogy a `ProductionRemoteControlCar` és az `ExperimentalRemoteControlCar` megvalósítsa a `RemoteControlCar` interfészt.
Ez magában foglalja az interfész által megkövetelt összes metódus megvalósítását is.

## 2. Vezetés

A `.drive()` minden egyes hívásakor az autónak egy bizonyos távolságot kell megtennie:

- egy `ProductionRemoteControlCar` 10 egységet tesz meg,
- egy `ExperimentalRemoteControlCar` pedig 20 egységet.

A `.getDistanceTravelled()` metódusnak azt kell visszaadnia, hány egységet tett meg az autó a teljes élettartama alatt.

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. Verseny

Valósítsd meg a `TestTrack.race(RemoteControlCar car)` metódust, amelyben a `car`-ok `drive()`-olhatnak.

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. Tedd rendezhetővé a sorozatgyártott autókat

Valósítsd meg a `Comparable<T>` interfészt a `ProductionRemoteControlCar` osztályban.
Az autók alapértelmezett rendezési sorrendje a győzelmek számának csökkenő sorrendje legyen.

Valósítsd meg a statikus `TestTrack.getRankedCars()` metódust, amely a kapott autókat a győzelmek számának csökkenő sorrendjében adja vissza.

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
