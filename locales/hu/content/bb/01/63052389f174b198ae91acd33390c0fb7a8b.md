# Bevezetés

## Case kifejezések

A Gleamben a `case` kifejezéssel feltételesen hajthatsz végre kódot. Egy case kifejezéssel egy értéket egy vagy több _mintával_ lehet összevetni. Ilyen minta például a _literál minta_, amely egy értéket egy literál értékkel vet össze (pl. `1` vagy `"hello"`).

A case kifejezéseket a `case` kulcsszóval írod le:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Bár ez más nyelvek `switch` utasításaira hasonlíthat, a mintaillesztés akkor mutatja meg igazi erejét, amikor más mintákat is használsz. Ilyen minta a _változóminta_, amellyel egy értéket rendelhetsz egy változóhoz. Ebben a példában az `i` változó a `number` értékét kapja, ha az nem `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Bizonyos esetekben további feltételt szeretnél adni egy mintához. Ezt nevezik _guardnak_ (klauzula), amelyet az `if` kulcsszóval adhatsz hozzá:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Teljesítménybeli okokból a guardokban csak alapvető matematikai és logikai operátorok engedélyezettek, más függvények nem használhatók guardokban.

A fenti példában nem minden lehetséges bemenethez tartozik illeszkedő minta. A fordító ezt észleli, és hibát jelez. Ezt nevezik _kimerítő ellenőrzésnek_. A figyelmeztetés megoldásához minden esetet kezelni kell. Erre az _eldobó minta_ használható, amely bármely értékre illeszkedik:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Egy klauzulában több mintát is össze lehet vetni, a mintákat a `|` választja el egymástól. Egy klauzulához csak egy guard adható:

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

A case kifejezések felülről lefelé vetik össze az értéket minden mintával, amíg illeszkedő mintát nem találnak, majd végrehajtják a hozzá tartozó logikát. A minták sorrendje számít!
