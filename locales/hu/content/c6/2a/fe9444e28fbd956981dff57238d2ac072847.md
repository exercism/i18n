# Bevezetés

## Bővítő metódusok

A bővítő metódusokkal metódusokat adhatsz meglévő típusokhoz anélkül, hogy új származtatott típust hoznál létre, újrafordítanád a kódot, vagy más módon módosítanád az eredeti típust. Statikus metódusként definiálod őket, de példánymetódus-szintaxissal hívod meg. Az első paraméterük előtt a `this` módosító szerepel, amely megadja, hogy a metódus melyik típuson működik; a metódusok pedig a névtér szintjén bekerülnek a scope-ba.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
