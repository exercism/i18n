# Stringtípusok

A Cairo nem rendelkezik natív adattípussal a stringek számára.
A stringtípusokat azonban kétféleképpen reprezentálhatjuk: rövid stringekként egyetlen `felt252`, illetve tetszőleges hosszúságú stringekként `ByteArray` segítségével.

## Rövid stringek

A rövid string egyszeres idézőjelek között jön létre, és a stringet alkotó minden karakter egyetlen bájton kódolódik, az [ASCII-szabvány][ascii-table] szerint.

ASCII-stringként például a `'abc'` a következő lesz:

- A `'a'` ugyanaz, mint a `0x61`
- A `'b'` ugyanaz, mint a `0x62`
- A `'c'` ugyanaz, mint a `0x63`
- Az `'abc'` ugyanaz, mint a `0x616263`

A Cairo a rövid stringeket a `felt252` adattípusban tárolja.
Mivel a `felt252` 251 bitet tartalmaz, egy rövid string legfeljebb 31 karakter hosszú lehet (31 \* 8 = 248 bit, ami a 8 legnagyobb olyan többszöröse, amely még belefér a 251 bitbe).

Példák rövid stringek deklarálására:

```rust
    let my_first_char = 'D';
    let my_first_char_in_hex = 0x44;

    let my_first_string = 'Hello world';
    let my_first_string_in_hex = 0x48656C6C6F20776F726C64;
```

### ByteArray

A ByteArray struct a Cairo 2.4.0-ban jelent meg.
A ByteArray stringeket dupla idézőjelek között írjuk, a következőképpen:

```rust
    let long_string: ByteArray = "this is a string which has more than 31 characters";
```

Technikailag a frissítés a `bytes31` típust is bevezette, amely 31 bájtot tárol, és elfér egy feltben.
A `ByteArray` struct lényegében úgy reprezentál egy hosszú stringet, hogy `bytes31` típusú értékek tömbjét használja az „egész szavakhoz” (vagyis azokhoz a szavakhoz, amelyek kitöltenek egy teljes feltet), valamint egyetlen felt mezőt egy „nem teljes szó” számára (a benne lévő bájtok számát egy külön hosszúságmező adja meg).

```rust
#[derive(Drop, Clone, PartialEq, Serde, Default)]
struct ByteArray {
    data: Array<bytes31>,
    pending_word: felt252,
    pending_word_len: usize,
}
```
