# Bevezetés

A JavaScriptben a _template stringek_ segítségével kifejezéseket ágyazhatsz a stringekbe, amit string-interpolációnak is neveznek.
Ez a lehetőség kibővíti a beépített [`String`][string-reference] globális objektum képességeit.

Template stringet úgy hozhatsz létre JavaScriptben, hogy a szöveget backtickek közé teszed.
Így a szöveg nemcsak új sorokat és más speciális karaktereket tartalmazhat, hanem változókat és más kifejezéseket is beágyazhatsz bele.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

A fenti példában a backtickek (<code>\`\`</code>) jelölik a template stringet. A `${...}` az a helyőrző, amelyet a behelyettesítéshez használsz.
A nem string típusú értékek _implicit módon_ alakulnak stringgé.
Ezzel a témával a [típuskonverzió][type-conversion-concept] fogalom foglalkozik.
Template stringekben bármilyen típusú kifejezést használhatsz.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Ha több sorba tördelve szeretnéd formázni a stringeket:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

A behelyettesítési lehetőségekkel logikát is vihetsz a folyamatba, hogy meghatározd, mi legyen a kimeneti string.

Erre példa a [ternáris operátor][ternary-operator] beágyazása.
Ez az operátor az `if/else` elágazás rövidített formája.
A szintaxis: `condition ? consequent-expression : alternative-expression`.
Ha a feltétel truthy, akkor a kettőspont bal oldalán álló operandus adódik vissza.
Ellenkező esetben a ternáris kifejezés eredménye a kettőspont jobb oldalán álló operandus.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
