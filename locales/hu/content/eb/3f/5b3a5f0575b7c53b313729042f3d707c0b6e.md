# Bevezetés

A Gleam az igaz és hamis értékeket a `Bool` típussal ábrázolja. Csak két érték létezik: `True` és `False`. Ezeket az értékeket egy változóhoz kötheted:

```gleam
let true_variable = True
let false_variable = False
```

A `&&`, `||` és `!` operátorokkal Boolean értékeket manipulálhatsz:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

A `&&` és `||` operátor rövidzár-kiértékelést végez, ami azt jelenti, hogy az operátor jobb oldalán álló kifejezés csak akkor értékelődik ki, ha szükséges.

Az egyes operátorok precedenciája eltérő: a `!` a `&&` és `||` előtt értékelődik ki. A kapcsos zárójelekkel elérheted, hogy a kifejezés egy része a többiek előtt értékelődjön ki:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
