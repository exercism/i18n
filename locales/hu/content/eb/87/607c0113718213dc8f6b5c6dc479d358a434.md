# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat     | Típus   | Leírás                                       |
| --------- | ------------- | ------- | -------------------------------------------- |
| `$a0`     | bemenet       | cím     | nullával lezárt név string, vagy null mutató |
| `$a1`     | bemenet/kimenet | cím   | nullával lezárt eredmény string              |
| `$t0-9`   | ideiglenes    | bármilyen | ideiglenes tárolásra                      |
