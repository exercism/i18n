# Részletek

A [ternáris operátor][ternary-operator] az if-else elágazás rövid formája.
Egy Boolean-kifejezést, valamint két, kettősponttal elválasztott kifejezést kap.
Ha a Boolean-kifejezés igaz, akkor az első kifejezés értékelődik ki, ellenkező esetben a második.
A felépítése a következő: `Boolean-expression ? expression1 : expression2`.

A ternáris operátor remek választás, ha az if-else elágazás rövid formájára vágysz, és a kifejezések is rövidek:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

A fenti példa az alábbi kód rövidített változata:
    
```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
