# Utasítások

Ebben a feladatban kódot írsz, hogy segíts elkészíteni egy remek lasagnét a kedvenc szakácskönyvedből.

Négy részfeladatod van, és mindegyik a lasagne elkészítésével töltött időhöz kapcsolódik.

## 1. Határozd meg a lasagne várható sütési idejét percekben

Definiáld a `Lasagna.expectedMinutesInOven()` metódust, amely nem vár paramétert, és visszaadja, hány percig kell a lasagnének a sütőben lennie. A szakácskönyv szerint a várható sütési idő 40 perc:

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. Számítsd ki a hátralévő sütési időt percekben

Definiáld a `Lasagna.remainingMinutesInOven()` metódust, amely paraméterként megkapja, hogy a lasagne hány perce van már a sütőben, és visszaadja, hogy az előző részfeladatban megadott várható sütési idő alapján hány percig kell még a sütőben maradnia.

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. Számítsd ki az előkészítési időt percekben

Definiáld a `Lasagna.preparationTimeInMinutes()` metódust, amely paraméterként megkapja a lasagnéba rakott rétegek számát, és visszaadja, hány percet töltöttél a lasagne előkészítésével, feltéve, hogy egy réteg előkészítése 2 percet vesz igénybe.

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. Számítsd ki az eltelt időt percekben

Definiáld a `Lasagna.elapsedTimeInMinutes()` metódust, amely két paramétert vár: az első paraméter a lasagnéba rakott rétegek száma, a második pedig az, hogy a lasagne hány perce van a sütőben. A függvénynek vissza kell adnia, hány percet dolgoztál a lasagne elkészítésén, ami az előkészítési idő és a lasagne által a sütőben eddig eltöltött idő összege.

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
