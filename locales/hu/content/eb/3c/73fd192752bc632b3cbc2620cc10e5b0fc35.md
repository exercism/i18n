# Bevezetés

Amikor az Elixir feloldja, hogy melyik függvényt hívja meg, a modul nevének segítségével keres. A keresés dinamikusan is elvégezhető, ha a modul nevét egy változóhoz kötjük.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Belül a modul neve egy atom. Az Elixirben minden modulatom automatikusan megkapja az `Elixir.` előtagot.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
