# rune index használata byte-okkal

Ebben az esetben biztonságos `runes` felett iterálni, és az indexszel egyes `bytes` értékeket kiolvasni,
mert a bemenet csupa ASCII-karakterből áll.
Ha látni akarod, mi történik nem ASCII-karakterek használatakor, add hozzá ezt a tesztesetet:

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
