# Névjegy

A Factorban az iterációt legtöbbször kombinátorokkal (`each`, `map`, `reduce`) fejezzük ki, de az explicit rekurziónak is megvan a maga helye: amikor a rekurzió nem listaalakú, amikor az alapeset nem triviális, vagy amikor te magad valósítasz meg egy kombinátort.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Néhány dolog, amit érdemes tudni:

- A sima `:`-os definíciók különleges szintaxis nélkül is rekurzívak lehetnek. A fordító a rekurzív híváson keresztül kikövetkezteti a veremhatásokat.
- A `loop ( quot -- )` segítségével iterálhatsz egy quotationt, amely Boolean értéket ad vissza; addig folytasd, amíg igaz.
- A farokhívások ugrásokká fordulnak, így a mélyen rekurzív szavak nem okoznak veremtúlcsordulást.

Az `unclip` / `if-empty` pár a szekvencia-rekurzió szokásos formája; a `cond` pedig a többesetű elágazás szokásos formája.
