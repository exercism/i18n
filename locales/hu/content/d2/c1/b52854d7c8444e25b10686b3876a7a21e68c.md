# Bevezetés

## Egész számok

Az egész számok olyan számok, amelyek a `{..., -2, -1, 0, 1, 2, ...}` halmazba tartoznak.
Egy egész szám maximumát és minimumát az a rendszer határozza meg, amelyen a PHP fut.
A legtöbb modern rendszeren ez jellemzően 64 bites érték, ami azt jelenti, hogy `-9_223_372_036_854_775_808` és `9_223_372_036_854_775_807` közötti értékeket tud ábrázolni, a határokat is beleértve.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Egész szám literálokat nem csak 10-es, hanem más számrendszerben is írhatsz, ha egy számrendszer-előtagot használsz:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> Forrás: a PHP [dokumentációja][syntax].

## Lebegőpontos számok

A PHP a lebegőpontos számokkal a valós számok egy részhalmazát ábrázolja.
Egy vagy több számjegyből állnak, amelyeket tizedesjel választ el.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### Gyakori buktatók

Nem minden szám és aritmetikai művelet végezhető el lebegőpontos számokkal.
Ha dollárt és centet lebegőpontos számokkal ábrázolsz, az kerekítési hibákhoz vezethet.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## Aritmetikai operátorok

A PHP számos operátort kínál aritmetikai műveletek elvégzéséhez. A PHP az aritmetikai operátorainál a szokásos matematikai műveleti sorrendet követi. A PHP által biztosított operátorok:

* Identitás (+)
* Negáció (-)
* Összeadás (+)
* Kivonás (-)
* Szorzás (*)
* Osztás (/)
* Modulo (%)
* Hatványozás (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```

[syntax]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.syntax
