# Bevezetés

## Modulok

A Gleam kódja modulokba szerveződik, és minden fájl egy-egy Gleam-modul.

Eddig a függvényeket a `pub fn` szintaxissal írtuk, ami egy más modulok számára nyilvánosan elérhető függvényt definiál. Az `fn`-nel definiált függvények csak abban a modulban érhetők el, amelyben definiáltad őket, más modulok nem használhatják őket.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

A Gleam-moduloknak nevük van, és a név a `src` vagy `test` könyvtáron belüli fájlútvonalon alapul.

Például egy `src\geometry\rectangle.gleam` (Windowson) vagy `src/geometry/rectangle.gleam` (UNIX-szerű operációs rendszereken) fájlban definiált modul neve `geometry/rectangle` lenne.

## Függvények importálása más modulokból

A más modulokban definiált függvényeket importokon keresztül érheted el.
Amikor importálsz egy modult, annak minden általa közzétett függvénye elérhetővé válik.
Az viszont, hogy hogyan éred el őket, attól függ, hogyan importáltad a modult.

A minősített import az alapértelmezett, és egy ilyen modulban lévő függvényt (például a `map` függvényt a `gleam/list` modulban) úgy érsz el, hogy a modul nevét előtagként írod elé (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Alapértelmezés szerint a modulra a nevének utolsó részével hivatkozol, ami ebben az esetben az `int`, de ezt az `as` kulcsszóval megváltoztathatod.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

A minősítés nélküli importok közvetlenül elérhetővé teszik a modul közzétett függvényeit, előtag nélkül.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

A minősített importot érdemes előnyben részesíteni, mert így az olvasó számára világosabb, honnan származik a függvény, és elkerülhetők a névütközések.


## Szabványos könyvtár

A Gleam szabványos könyvtára gazdag és jól dokumentált. A dokumentáció online elérhető itt: [hexdocs.pm/gleam_stdlib][docs]. Mentsd el valahova ezt a linket, sokat fogod használni!

A legtöbb beépített adattípushoz tartozik egy modul, amely függvényeket kínál az adott adattípus kezeléséhez; van például `gleam/int` modul az egész számokhoz, `gleam/string` modul a stringekhez, `gleam/list` modul a listákhoz és így tovább.

[docs]: https://hexdocs.pm/gleam_stdlib/
