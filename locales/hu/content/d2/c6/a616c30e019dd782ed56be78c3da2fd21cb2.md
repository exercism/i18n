# Ternáris operátor

A ternáris operátor alternatív szintaxist kínál egy `if..else..` összehasonlítás elvégzésére és egy érték visszaadására.

## Szintaxis

A PHP-ban az `if` utasítással egy művelet egy feltétel „igaz” volta alapján értékelhető ki.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

A ternáris operátorral ugyanez a művelet másképp is kifejezhető:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

Az összehasonlítás szintaxisa rövid: `(condition) ? (evaluate if true) : (evaluate if false);`.

## Előnyök

A ternáris operátor használatának nyilvánvaló előnye a rövidség: a feltételes kifejezést sokkal rövidebb leírni, mint egy `if..else..` utasítást, de több más előnye is van:

- Kifejezés, ezért egy másik kifejezésen belül is használható.
- Lehetővé teszi az egyes ágak lusta kiértékelését.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  Ebben a példában, ha nincs szükség a pontos válaszra, a költséges számítás nem hívódik meg.

## Hátrányok

A ternáris operátoroknak több hátrányuk is van, ezért érdemes megfontolni a használatukat:

- A ternáris operátor nehezebben olvasható, mert a megértése szimbólumok értelmezésén múlik, nem kulcsszavak használatán.
- A ternáris operátor véletlenül hibákhoz vezethet, mert a PHP-ban balra asszociatív, ellentétben a legtöbb modern nyelvvel (pl. C, Java, JavaScript).
- Az igaz vagy hamis ágban kiértékelt kifejezésnek vissza kell adnia egy értéket.

## Még rövidebb

A ternáris szintaxis tovább rövidíthető: `(condition) ?: (evaluate if falsey)`.
Az egyik felhasználási módja, hogy egy kifejezésben tartalék értéket adhatunk meg:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Ezt néha _Elvis-operátornak_ is nevezik (`?:`).
