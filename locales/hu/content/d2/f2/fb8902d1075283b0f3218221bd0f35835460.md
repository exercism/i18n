# Bemutatás

A Gleamben a függvények első osztályú értékek, ami azt jelenti, hogy a függvények hétköznapi értékek: hozzárendelheted őket változókhoz, átadhatod őket argumentumként, és más függvények is visszaadhatják őket.

Egy modulban definiált, névvel ellátott függvényre a nevével hivatkozhatsz.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

A Gleamben névtelen függvények is vannak, amelyeket más függvényeken belül definiálsz.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Egy függvény típusát a névtelen függvényekéhez hasonló szintaxissal írjuk le. Egy olyan függvény típusát, amely kap egy `Int`-et és egy `Float`-ot, majd visszaad egy `Int`-et, így írjuk le:

```gleam
fn(Int, Float) -> Int
```

A névtelen függvények hivatkozhatnak azokra a változókra, amelyek a definiálásukkor hatókörben voltak, így ezek _closure_-ök.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

A _függvénybefogás_ szintaxis kényelmes rövidítést kínál olyan névtelen függvények létrehozásához, amelyek egyetlen argumentumot adnak át egy függvénynek. Ez a két kifejezés egyenértékű:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
