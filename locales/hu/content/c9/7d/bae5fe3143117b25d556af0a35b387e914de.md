# Függvények túlterhelése

A Swift akkor tekint két függvényt különbözőnek, ha más a nevük, _vagy_ ha az alábbiak közül bármelyik igaz:

- Eltér a paramétereik száma
- Bármelyik külső argumentumcímke különbözik
- Bármelyik paraméter típusa különbözik

A következő függvények különbözőnek számítanak, ezért ugyanabban a programban is definiálhatók és használhatók:

```swift
// Original definition
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Int {
  // ...
}

// Different number of parameters
func add(_ x: Int, and y: Int) -> Int {
  // ...
}

// Different parameter type
func add(_ x: Double, and y: Int, doubleResult: Bool) -> Double {
    // ...
}

// Different argument label
func add(_ x: Int, and y: Int, doubleThat: Bool) -> Int {
    // ...
}
```

A függvények akkor is különbözőnek számítanak, ha csupán a visszatérési értékük tér el, bár sok esetben ilyenkor is meg kell adni a fordítónak egy tippet típusannotáció formájában, hogy tudja, a függvény melyik változatát hívja meg.
