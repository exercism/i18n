# Ajánlott tanulási források

Üdvözlünk a ColdFusion (CFML) tanulásában! A CFML egy dinamikus, lazán típusos szkriptnyelv, amely a Java virtuális gépen (JVM) fut. Két különböző fájltípusa van. A `.cfm` fájlok (ColdFusion markup)_ tisztán procedurálisak, és a címkealapú szintaxist használják HTML sablonozására. Ezeket nézetekhez használnád, ha webhelyet építesz:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

A másik fájltípus a `.cfc` (ColdFusion-komponens), amellyel egy osztályt deklarálsz. A komponenseket üzleti logikához, modellekhez és vezérlőkhöz használjuk. Ezek általában a szkriptszintaxist használják, ami a JavaScripthez hasonló.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
