# Bevezetés

A for-ciklus az egyik leggyakrabban használt utasítás arra, hogy valamilyen logikát ismételten végrehajtsunk.
JavaScriptben a `for` kulcsszóból, egy kerek zárójelbe (`()`) zárt _fejlécből_ és egy kapcsos zárójelbe (`{}`) zárt kódblokkból áll, amely a ciklus _törzsét_ tartalmazza.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

Az inicializálás általában beállít egy számlálóváltozót, a feltétel ellenőrzi, hogy folytatni vagy leállítani kell-e a ciklust, a léptetés pedig minden ismétlés végén növeli a számlálót.
A fejléc egyes részeit pontosvesszők választják el.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
