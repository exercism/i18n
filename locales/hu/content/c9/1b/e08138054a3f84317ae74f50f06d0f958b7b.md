# Tesztek

## Tesztek futtatása

A tesztek futtatásához hajtsd végre a következő parancsot:

```bash
dotnet test
```

Ha szeretnéd, hogy a tesztek automatikusan fussanak, valahányszor egy forrásfájl megváltozik, hajtsd végre a következő parancsot:

```bash
dotnet watch test
```

## A feladat megoldása

Egy feladat megoldása azt jelenti, hogy minden tesztje sikeres lesz. Alapértelmezés szerint csak egy teszt (az első) fut le, amikor futtatod a teszteket. Ez szándékos, mert így arra összpontosíthatsz, hogy csak azt az egy tesztet sikeressé tedd. Miután az a teszt sikeres lesz, engedélyezheted a következő tesztet úgy, hogy eltávolítod a `Skip = "Remove this Skip property to run this test"` részt a teszt `[Fact]` vagy `[Theory]` attribútumából. Amikor már minden teszt engedélyezve van, és a megoldásod mindet sikeressé teszi, megoldottad a feladatot!

Hogy könnyebben elindulj, minden feladathoz tartozik egy kezdetleges implementációs fájl. Ezt a fájlt kiindulópontként használhatod a megoldásod felépítéséhez. Nyugodtan törölheted vagy módosíthatod ezt a fájlt, ha úgy gondolod, hogy az a helyes.

## Csomagok használata

A legtöbb feladatot meg tudod oldani külső csomagok használata nélkül. Ha azonban olyan feladatot oldasz meg, ahol mégis szeretnél külső csomagot használni, a következő parancs futtatásával adhatod hozzá a projektedhez:

```bash
dotnet add package [package-name]
```
