# Kiegészítés az utasításokhoz

## Regiszterek

| Regiszter | Használat | Típus   | Leírás                                           |
| --------- | --------- | ------- | ------------------------------------------------ |
| `$a0`     | bemenet   | egész szám | az ellenőrizendő év                             |
| `$v0`     | kimenet   | boolean | a bemenet szökőév (`0` = `false`, `1` = `true`)  |
| `$t0-9`   | átmeneti  | bármi   | átmeneti tárolásra szolgál                       |
