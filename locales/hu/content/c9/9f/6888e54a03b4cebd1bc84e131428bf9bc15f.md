# Üzemanyag-átalakítás JSON-ba

## Problémafelvetés

Az ABC Corp minden alkalmazottja korlátlan üzemanyag-juttatást kap. Az alkalmazottaknak minden tankolás alkalmával be kell küldeniük egy bejegyzést. A bejegyzéseket ugyanahhoz a JSON-fájlhoz fűzik hozzá, és a hónap végén dolgozzák fel őket.

A digitális üzemeltetési csapat tagjaként a feladatod, hogy beolvasd ezt a JSON-fájlt, és az eredményeket egy másik JSON-fájlba írd. A kimeneti fájlnak minden alkalmazotthoz egy bejegyzést kell tartalmaznia a következő adatokkal:

- Alkalmazotti szám
- Tankolások száma
- Üzemanyag összköltsége
- Összes gallon
- Összes megtett mérföld

Két `string` argumentumot kapsz.

1. A bemeneti JSON-fájl elérési útja.
1. A kimeneti JSON-fájl elérési útja.

A bemeneti JSON-fájl JSON-objektumok tömbjét tartalmazza. Minden JSON-objektum a következő formájú.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

A feladatod, hogy a JSON-bemenetet a következő JSON-formátumra alakítsd, és a tartalmat a megadott elérési útra írd. A kimeneti fájlnak minden alkalmazotthoz egy bejegyzést kell tartalmaznia, az `employeeId` szerint növekvő sorrendbe rendezve.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## Megkötések

- A bemeneti JSON-fájlban lévő tankolási bejegyzések száma `n`:  0 <= n <= 1000
- A vállalat alkalmazottainak száma: 97
- A benzin ára gallononként értendő
- Nincs hiányzó tankolási bejegyzés

## Tippek

- A JSON-fájlok olvasásához és írásához használd a [`ballerina/io` modult](https://lib.ballerina.io/ballerina/io/latest).
- Alakítsd át a JSON-értékeket alkalmazásspecifikus típusokká, hogy típusbiztos módon dolgozhass az adatokkal. Erről a [Példa a felhasználó által definiált típusra való átalakításra](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) című leírásban olvashatsz a Ballerina By Examples (BBE) oldalon.

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- A [rekordok destrukturálása](https://ballerina.io/learn/by-example/destructure-records-using-query) hasznos lehet a kód terjengősségének csökkentésében.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- Egyetlen kifejezésből álló függvényeknél használj kifejezéstörzsű függvényeket. Például azoknál, amelyekben csak a visszatérési utasítás szerepel.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
