# Bevezetés

## Let

A `let` kifejezéssel helyi scope-ot hozhatsz létre, és néhány helyzetben hasznos lehet:

- Kifejezések egyszerűsítésére
- A közbenső kifejezések eredményeinek elnevezésére
- Egy kifejezés kisebb darabokra bontására, ha az kezd túl nagyra nőni

Egy `let` kifejezésen belül a legtöbb dolgot megteheted, például destrukturálhatsz is (erről bővebben a későbbi feladatokban olvashatsz), de új egyedi típust vagy típusaliast nem hozhatsz létre.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
