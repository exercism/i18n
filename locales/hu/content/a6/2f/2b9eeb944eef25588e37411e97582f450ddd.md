# Névjegy

A Gleam futhat az Erlang virtuális gépen (BEAM), vagy JavaScript-futtatókörnyezeteken. Sok más nyelv is ezeket a futtatókörnyezeteket használja, és gyakran hasznos, ha az ezeken a nyelveken írt kódot meg tudjuk hívni Gleamből.

A Gleam _külső függvények_ nevű szolgáltatásával más nyelveken írt függvényeket importálhatsz a Gleamba, és futásidejű többletköltség nélkül hívhatod meg őket.

Ha a Gleam-projekted az Erlang virtuális gépen fut, és az Erlang `lists` moduljából szeretnéd meghívni a `reverse` függvényt, akkor ezt úgy teheted meg, hogy hozzáadod a `@external` attribútumot egy Gleam-függvény fejlécéhez:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Ezután már hívhatod is, mint bármelyik közönséges Gleam-függvényt:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Ha ezt a kódot JavaScript-futtatókörnyezetekre próbálod lefordítani, hibaüzenettel elszáll, mert nincs hozzá JavaScript-implementáció. A JavaScript-futtatókörnyezetekhez megadhatsz egy másik implementációt:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Az is lehetséges, hogy Gleamben írj implementációt, amelyet akkor használ a fordító, ha az aktuális fordítási célhoz nincs külső implementáció:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
