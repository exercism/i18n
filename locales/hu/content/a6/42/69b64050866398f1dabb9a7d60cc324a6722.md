# Részletesen

A Go statikusan típusos nyelv, ezért minden változó típusa már fordításkor ismert. A változó típusa a deklaráció után nem változhat.

## Változó létrehozása

A `var` utasítással megadhatod egy új változó típusát, beállíthatod az értékét, vagy akár mindkettőt egyszerre:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

Függvényen belül a `:=` rövid értékadó utasítás is használható.

```go
count := 1 // Type implictly declared, value explicitly set
```

A Go-ban egy változónak mindig van értéke. Ha a deklarációnál nem adsz meg neki értéket, akkor a Go ad egyet, az úgynevezett [zéróértéket][zero-values], a változó típusa alapján.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Változó frissítése

Függvényen belül az `=` értékadó operátorral új értéket adhatsz egy már létező változónak:

```go
count := 1
count = 2
```

Az új érték típusának meg kell egyeznie a változóéval:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
