# Bevezetés

## Igaz és hamis értékek

A Common Lispben minden érték „igaz”, kivéve a `()`-t, amely „hamis”.
Két speciális állandó szimbólum létezik, a `t` és a `nil`, amelyek értéke rendre igaz, illetve hamis.

## Feltételes kifejezések

A Common Lisp többféle feltételes kifejezést kínál, amelyek főként az általuk támogatott ágak számában térnek el.

- A `when` és az `unless` egyetlen ágat enged meg:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

A feltételkifejezés utáni rész több kifejezésből is állhat.

- Az `if` a klasszikus if-then-else szerkezetet nyújtja:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Figyeld meg, hogy a then- és az else-ág is csak egyetlen kifejezést tartalmazhat.

- A `cond` lehetővé teszi, hogy több ágat használj anélkül, hogy `if` kifejezéseket ágyaznál egymásba:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Figyeld meg, hogy a feltételkifejezés utáni kifejezések számának nincs felső határa.

- A `case` a klasszikus „switch” stílusú szerkezetet nyújtja: egyetlen értéket vet össze több ággal:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Figyeld meg, hogy a `cond`-hoz hasonlóan a feltételkifejezés utáni kifejezések számának sincs felső határa.
