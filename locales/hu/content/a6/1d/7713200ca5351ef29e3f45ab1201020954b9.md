# Iteráció

A programozásban az [iteráció][iteration] egy kódrészlet többszöri ismétlését jelenti.
Ezt olyan fogalmak segítségével lehet megtenni, mint a while-ciklusok és az until-ciklusok.
Rekurzióval is megvalósítható, ami egy olyan függvény, amely önmagát hívja.

A leggyakrabban azonban egy gyűjtemény elemein szeretnél iterálni, például egy `Array`, `Range` vagy `String` esetében.
A Crystalben az `Array` és a `Range` osztály is tartalmazza az [`Enumerable`][enumerable] modult, amely számos metódust kínál az elemek fölötti iteráláshoz.
A `String` osztálynak eközben saját metóduskészlete van a karakterek fölötti iteráláshoz.

A Crystalben ráadásul nincs for-utasítás, ellentétben más nyelvekkel.
Ehelyett több metódust is kínál, amelyekkel iterálni lehet.

## Iterálás

A leggyakoribb módja annak, hogy egy gyűjteményen iterálj, az [`each`][each] metódus használata, amely a gyűjtemény minden elemét átadja egy blokknak.
Ez egy `Range` segítségével könnyedén megtehető.
Tegyük fel, hogy 1 és 3 között szeretnél ciklust futtatni; ekkor az `each` metódussal iterálhatsz a tartományon.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Még egyszerűbb, ha csak bizonyos számszor szeretnél iterálni: használhatod a [`times`][times] metódust, amely az `Int` osztályon érhető el.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Iterálás `String` fölött

A `String` karakterek sorozata, és nem tartozik az `Enumerable` modulhoz, ami azt jelenti, hogy saját metóduskészlettel rendelkezik a karakterek fölötti iteráláshoz.
A leggyakoribb módja a `String` fölötti iterálásnak az [`each_char`][each_char] metódus használata, amely a `String` minden karakterét átadja egy blokknak.

~~~~exercism/note
Az `each_char` metódus egy `Char` objektumot ad át a blokknak, nem egy `String` objektumot.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

A `String` fölötti iterálás másik módja az [`each_line`][each_line] metódus használata.
Ezt a metódust főleg akkor használjuk, amikor egy fájlt soronként olvasunk be.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Iterálás olyan objektumon, amely tartalmazza az `Enumerable` modult

Az [`Enumerable`][enumerable] modul számos metódust kínál egy gyűjtemény elemei fölötti iteráláshoz.
Olyan gyűjtemények tartalmazzák az `Enumerable` modult, mint az `Array`, a `Range`, a `Hash` és a `Set`; az utóbbiakat későbbi fogalmakban tárgyaljuk.

A leggyakoribb módja az `Array` fölötti iterálásnak az [`each`][each] metódus használata, amely az `Array` minden elemét átadja egy blokknak.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

A [`map`][map] metódus egy másik módja az `Array` fölötti iterálásnak: egy új `Array`-t ad vissza, amely annak eredményeit tartalmazza, hogy a blokkot minden elemre alkalmaztuk.
Hasonló az `each` metódushoz, de egy új `Array`-t ad vissza az átalakított elemekkel.
Az átalakítás nagyon hasznos, amikor egy függvényt szeretnél a gyűjtemény minden elemére alkalmazni, ami gyakori művelet.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Olyan vezérlési szerkezettel, mint az `if`, azt is szűrheted, hogy mely elemeket alakítsd át.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## Rövidített szintaxis

A Crystalben létezik egy rövidített szintaxis arra, hogy egy gyűjtemény minden elemén iterálj és alkalmazz egy metódust.
Ez akkor hasznos, ha egyszerű logikával dolgozol, amelyet csak egyetlen metódussal kell átalakítani.
Ezt a `&.` szintaxissal lehet megtenni, amelyet a metódus neve követ.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### Indexszel

Néha tudnod kell annak az elemnek az indexét, amelyen éppen iterálsz; erre az [`each_with_index`][each_with_index] vagy a [`map_with_index`][map_with_index] metódust használhatod.
Mindegyik elemet és annak indexét átadja egy blokknak; a metódus emellett egy opcionális argumentumot is elfogad a kezdőindex megadásához.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Ügyelj rá, hogy az [`each_char_with_index`][each_char_with_index] metódus `String` objektumokon is elérhető.

### sum

A [`sum`][sum] metódus a gyűjtemény összes elemének összegét adja vissza; emellett egy opcionális blokkot is elfogad, amellyel az elemeket az összegzés előtt átalakíthatod.
Egy opcionális argumentumot is elfogad az összeg kezdőértékének megadásához.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

A [`reduce`][reduce], amelyet más nyelvekben fold néven ismernek, egy olyan metódus, amely egy összevonó művelet és egy kezdőérték segítségével összekombinálja a gyűjtemény összes elemét.
A `reduce` metódusnak van egy akkumulátora, amelyet átad a blokknak; az akkumulátor az előző iteráció eredménye.
Így egy rekurzív folyamat jön létre, amely összekombinálja a gyűjtemény összes elemét.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

A `reduce` hasonlónak tűnhet a `sum`-hoz, de a `reduce` rugalmasabb, mert lehetővé teszi az akkumulátor kezdőértékének és az összevonó műveletnek a megadását.
A `reduce` segítségével megvalósítható a `sum`, a `count` és más metódusok.
