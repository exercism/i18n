# Bevezetés

## Címkézett mezők

Amikor egy egyedi típus egy változata adatot tárol, azt rekordnak nevezzük, és minden benne lévő érték egy _mezőben_ található.

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

A jobb olvashatóság érdekében a Gleam megengedi, hogy a mezőket névvel címkézzük.

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

A címkékkel tetszőleges sorrendben adhatunk argumentumokat egy rekord konstruktorának.

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

Amikor egy egyedi típusnak csak egy változata van, akkor a `.label` elérési szintaxissal lekérhetjük egy rekord mezőit.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

A rekordfrissítési szintaxis akkor használható, ha az egyedi típusnak egyetlen változata van, hogy egy meglévő rekordból új rekordot hozzunk létre, de néhány mezőt új értékekre cserélve.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

A címkéket mintaillesztéskor is használhatjuk, hogy értékeket nyerjünk ki rekordokból.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h >. 20.0 -> True
    _ -> False
  }
}
```

Ha csak néhány mezőre szeretnénk illeszkedni, használhatjuk a `..` spread operátort, hogy figyelmen kívül hagyjuk a többi mezőt.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
