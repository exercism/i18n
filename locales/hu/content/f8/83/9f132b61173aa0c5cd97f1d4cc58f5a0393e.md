# Bevezetés

## Címkézett argumentumok

Előfordul, hogy ha egy függvény sok argumentumot vár, nehéz megjegyezni, milyen sorrendben kell megadni őket. Az olvashatóság érdekében a Gleam lehetővé teszi, hogy az argumentumokat névvel címkézd meg.

Egy argumentum címkézéséhez a címke nevét az argumentum neve elé írd, szóközzel elválasztva.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Ha egy függvényt címkézett argumentumokkal hívsz meg, az argumentumokat tetszőleges sorrendben megadhatod. Az alábbi `replace` hívások mindegyike egyenértékű:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

A címkék mindig opcionálisak. Attól még, hogy egy függvénynek címkézett argumentumai vannak, címkék nélkül is meghívhatod.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
