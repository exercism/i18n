# Névjegy

A [tuple-ök][tuples] segítségével több értéket kombinálhatsz egyetlen összetett értékké, ahol az egyes értékek típusa eltérő lehet.
Az összetett érték típusa az egyes értékek típusainak kombinációja.
A tömbökhöz hasonlóan a tuple-ök is rendezett gyűjtemények.
A tömbökkel ellentétben azonban a tuple-ök mérete rögzített, ezért a tuple elemeinek számának megváltoztatásához új tuple-t kell létrehozni.

Egy tuple létrehozásához az értékeket zárójelbe teszed, vesszővel elválasztva:

```swift
let order = ("biscuits", 2.99, 3)
```

A tuple-ben az egyes értékek típusát is megadhatod:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Az egyes értékek tuple-ből való kinyeréséhez használhatod a `.n` szintaxist, ahol _n_ annak az elemnek az indexe, amelyet el szeretnél érni, 0-tól kezdve:

```swift
let orderItem = order.0
// Returns "biscuits"

let orderQuantity = order.2
// Returns 3
```

## Nevesített tuple-ök

A tuple-öket elnevezheted úgy, hogy minden egyes értékhez címkét adsz:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Ez hasznos lehet, hogy a tuple olvashatóbb és önmagyarázóbb legyen, különösen, amikor a tuple-t egy függvény visszatérési értékeként használod.

Ez azt is lehetővé teszi, hogy az egyes értékeket a nevük alapján elérd:

```swift
let orderItem = order.item
// Returns "biscuits"
let orderQuantity = order.quantity
// Returns 3
```

A nem nevesített tuple-ökhöz hasonlóan egy nevesített tuple-ben is megadhatod az egyes értékek típusát:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Tuple-ök módosítása

A tuple elemeit módosíthatod, ezt a `.n` szintaxissal teheted meg.

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

order
// Returns ("cookies", 1.99, 5)
```

## Több visszatérési érték

A Swift függvényei csak egyetlen értéket adhatnak vissza.
Mivel azonban a tuple egyetlen érték, több értéket is csomagolhatsz egy tuple-be, és azt a tuple-t visszaadhatod egy függvényből.
Ez lehetővé teszi, hogy gyakorlatilag [több értéket adj vissza egy függvényből][multiple-return-values].

Íme egy példa egy olyan függvényre, amely egy hányadost és maradékot tartalmazó tuple-t ad vissza:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
  let quotient = dividend / divisor
  let remainder = dividend % divisor
  return (quotient, remainder)
}
```

## Tuple-ök felbontása

A tuple-t felbonthatod az egyes összetevőire úgy, hogy annyi változót adsz meg, ahány elem van a tuple-ben.
A tuple-ök felbontásának használata növelheti a kódod olvashatóságát, mivel lehetővé teszi, hogy értelmes neveket adj az egyes értékeknek.

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

item
// Returns "biscuits"
```

A felbontás for-in ciklusokkal is elvégezhető:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
  print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
