# A Luhn fogalmai

A Luhn egy érvényesítő algoritmus, amely szöveges és numerikus állításokat kombinál. A Rust-megoldások a funkcionális megközelítéseket részesítik előnyben.

## Általános

### Primitívek

- `&str` és `char`
  - a tanulóknak meg kell érteniük az egyes `char` és a `&str` közötti különbséget, hogy helyesen kizárják vagy belefoglalják a megadott bemenet részeit
- egész szám
  - az egész számok megértése fontos a szükséges numerikus érvényesítés elvégzéséhez
- Boolean-ok
  - elengedhetetlenek az azonosságállításokhoz és a végső összehasonlításokhoz

### Az iterátor jellemzői

- láncolás
  - itt fontos megérteni az iterátorláncokat, hogy a feladatot rendezett módon oldjuk meg.
- `map`, `filter`, turbofish, esetleg `fold`
  - a `map` és a `filter` kombinálása alapvető tervezési mintát nyújt az ehhez hasonló érvényesítési feladatokhoz. A `fold`-os megoldások ráadásul további tömörséget nyújtanak.
  - egyes megoldásokban szükség van a turbofish-re, hogy megmondjuk a Rustnak, milyen típust hozunk létre egy láncolt kifejezésből

## 1. példamegoldás

york [megoldása](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d)

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## 2. példamegoldás

Kanonikus

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
