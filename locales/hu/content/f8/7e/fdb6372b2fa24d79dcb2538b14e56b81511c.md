# Névjegy

## Függvények

A Gleamben a függvényeket a `pub fn` szintaxissal definiálod.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Ez a függvény két argumentumot vár, mindkettő `Int` típusú, és egy `Int` típusú értéket ad vissza. A Gleamben nincs `return` kulcsszó: egy függvény utolsó kifejezésének értéke mindig _implicit módon visszaadódik_.

Az argumentumok típusmegjelölése és a visszatérési típus megadása is opcionális, a Gleam viszont mindig teljesen típusellenőrzi a kódodat. A Gleam-programozók általában az áttekinthetőség kedvéért megadják a függvényeik típusát, de nyugodtan el is hagyhatod őket.

```gleam
pub fn add(x, y) {
  x + y
}
```

Egy függvényt a `function_name(argument1, argument2)` szintaxissal hívhatsz meg.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Változók

A Gleamben a változókat a `let name = expression` szintaxissal definiálod.

```gleam
pub fn main() {
  let count = 1
}
```

A változókat típusmegjelöléssel is deklarálhatod. A függvényargumentumokhoz hasonlóan ez is opcionális, a legtöbb Gleam-programozó viszont elhagyja a változók típusmegjelölését.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## String literálok

A Gleamben a stringeket kettős idézőjelek közé írod.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Kódkommentek

A kommentekkel megjegyzéseket hagyhatsz a forráskódot olvasó többi fejlesztőnek. A Gleamben a kommentek egysorosak, és `//` áll előttük.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
