# Bevezetés

A JavaScript dinamikus nyelv, amely támogatja az objektumorientált, az imperatív és a deklaratív (például funkcionális programozási) stílusokat.

## Változók

A JavaScriptben néhány alapvető módon rendelhetsz értéket egy névhez: változókkal vagy konstansokkal.
Az Exercismen a változókat mindig [camelCase][wiki-camel-case] írásmóddal írjuk, a konstansokat pedig [SCREAMING_SNAKE_CASE][wiki-snake-case] stílusban.
Nincs hivatalos útmutató, amit követni kellene, a különböző cégeknek és szervezeteknek pedig különböző stílusútmutatóik vannak.
_Nyugodtan írd a változókat, ahogy szeretnéd._
Ha úgy írod őket, ahogy a feladatok elő vannak készítve, az az előnye, hogy a webes felületen és a legtöbb IDE-ben másképp lesznek kiemelve.

A JavaScriptben a változókat a [`const`][mdn-const], a [`let`][mdn-let] vagy a [`var`][mdn-var] kulcsszóval definiálhatod.

Ha `let`-et vagy `var`-t használsz, egy változó az élettartama során különböző értékekre hivatkozhat.
Például a `myFirstVariable` az `=` értékadó operátorral sokszor definiálható és újradefiniálható:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

A `let`-tel és a `var`-ral ellentétben a `const`-tal definiált változóknak csak egyszer adhatsz értéket.
Így definiálunk konstansokat a JavaScriptben.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## Függvénydeklarációk

A JavaScriptben a funkcionalitás egységeit _függvények_ zárják magukba, és ha összetartoznak, általában ugyanabban a fájlban csoportosítjuk őket.
Ezeknek a függvényeknek paramétereik vannak (így argumentumokat fogadhatnak), és a `return` kulcsszóval _visszaadhatnak_ egy értéket.
A függvényeket a `()` szintaxissal hívod meg.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

Ebben a példában a függvény neve `add`.
Két paramétere van: `num1` és `num2`.
Visszaad egy értéket: a `num1 + num2` kifejezés eredményét.

Ezután az `add` függvényt két argumentummal _hívjuk meg_: `1` és `3`.
A függvény eredménye, a visszaadott érték pedig `4`.

```exercism/note
💡 A JavaScriptben _sok_ különböző módon deklarálhatsz függvényt.
Néhány ilyen más mód másképp néz ki, mint a `function` kulcsszó használata.
A kurzus igyekszik fokozatosan bevezetni őket, de ha már ismered őket, nyugodtan használhatod bármelyiket.
A legtöbb esetben nem jobb vagy rosszabb az egyik vagy a másik használata.
```

## Elérhetővé tétel más fájlok számára

Ahhoz, hogy egy `function`, egy konstans vagy egy változó _más fájlokban_ is elérhető legyen, az `export` kulcsszóval [exportálnod][mdn-export] kell őket.
Egy másik fájl ezután az `import` kulcsszóval [importálhatja][mdn-import] ezeket.
Ezt nevezik modulrendszernek is.

Erre remek példa, ahogy az összes teszt működik.
Minden feladathoz tartozik legalább egy fájl, például a `lasagna.js`, amely az _implementációt_ tartalmazza.
Az _implementációt_ `export`-áljuk a fájlból, így az egy másik fájlban importálhatóvá válik.
Emellett legalább egy másik fájl is van, például a `lasagna.spec.js`, amely a _teszteket_ tartalmazza.
Ez a fájl `import`-álja a nyilvános (azaz `export`ált) entitásokat, hogy tesztelje az implementációt:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
