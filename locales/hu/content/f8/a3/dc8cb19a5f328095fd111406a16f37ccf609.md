# SQLite-ra vonatkozó utasítások

* A **candidates** oszlop egy JSON-kódolású stringekből álló listát tartalmaz.
  Például:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* A **result** oszlopnak szintén JSON-kódolású stringek listáját kell tartalmaznia.

## Táblaséma

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
