# Részletesen

A Kotlinban a Boolean értékeket a `Boolean` típus képviseli, amelynek értéke csak `true` vagy `false` lehet.

A Kotlin három beépített [Boolean-operátort][reference] támogat: a `!` (tagadás, más néven NOT), a `&&` (lusta konjunkció, más néven AND) és a `||` (lusta diszjunkció, más néven OR). A `&&` és a `||` operátor _rövidre záró kiértékelést_ használ, ami azt jelenti, hogy az operátor jobb oldala csak akkor értékelődik ki, amikor szükséges.

```kotlin
true || false // => true
true && false // => false
```

A három Boolean-operátor [_műveleti elsőbbsége_][precedence] eltérő. Ennek következtében a kiértékelésük sorrendje a következő: először a `!`, aztán a `&&`, végül a `||`. Ha „ki szeretnéd kerülni” ezeket a szabályokat, egy Boolean-kifejezést zárójelbe (`()`) tehetsz, mert a zárójelek elsőbbsége még ennél is nagyobb.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
