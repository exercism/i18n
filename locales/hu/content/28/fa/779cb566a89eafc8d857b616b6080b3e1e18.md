# Bevezetés

A Rubyben a **tömbök** rendezett, egész számokkal indexelt gyűjtemények, amelyek bármilyen objektumot tartalmazhatnak.
Az indexelés `0`-tól kezdődik.
A negatív index a tömb végétől számítva értendő, azaz a `-1` index a tömb utolsó elemére mutat, a `-2` a végétől a második elemre, és így tovább.
A Ruby tömbjei magukba foglalják az [Enumerable modult][enumerable-module], amely számos bejáró- és keresőmódszert ad hozzájuk, valamint a rendezés lehetőségét is.

## Tömb létrehozása

- A Rubyben egy tömb különböző típusú objektumokat tartalmazhat.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Elemek értékadása

Az elemek indexek segítségével érhetők el vagy módosíthatók.
A résztömböket úgy érheted el, hogy megadod a kezdő indexet és a méretet.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- A negatív indexek a tömb végétől visszafelé számolnak.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Elemek elérése

- A tömb elemei a #[] metódussal kérhetők le.
- Ez visszaadja az adott indexen lévő elemet, vagy egy résztömböt ad vissza, amely a kezdő indextől indul és a megadott hosszon át folytatódik.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- A negatív indexek a tömb végétől visszafelé számolnak (-1 az utolsó elem)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Információk lekérése egy tömbről

A tömbök mindig nyilván tartják a saját hosszukat.
Ha meg akarod tudni, hány elemet tartalmaz egy tömb, használd a length, count vagy size metódust.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Elemek hozzáadása tömbhöz

A tömb végéhez úgy adhatsz hozzá elemeket, hogy a `push` metódust vagy a `<<` operátort használod:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Elemek eltávolítása egy tömbből

A pop metódus eltávolítja a tömb utolsó elemét, és visszaadja azt:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
