# Utasítások

Ebben a feladatban egy „Wizards and Warriors” nevű szerepjátékot játszol.
A játékhoz egy általános célú kockadobó metódusra van szükséged, amellyel különböző kimeneteleket határozhatsz meg.
Ez a hagyományos 18 oldalú kocka lesz, 1-től 18-ig tartó számokkal.
A játékosoknak emellett véletlenszerű varázserőt is generálniuk kell.

## 1. Tedd lehetővé, hogy egy _Wizards and Warriors_ játékos kockát dobjon

Valósítsd meg a `RollDie()` metódust a `Player` osztályon.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. A játékosoknak szükségük van az erejükre. Adj módot a varázserő generálására

Valósítsd meg a `GenerateSpellStrength()` metódust a `Player` osztályon.
A varázserő 0.0 és 100.0 között van, utóbbit nem beleértve.

Vedd figyelembe, hogy a varázserőnek lebegőpontos számnak kell lennie (nem egész számnak), hogy csökkenjen a döntetlen esélye, amikor két ellenfél erejét összehasonlítják.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
