# Hibakeresés

A sok más nyelvtől eltérően a WebAssembly-kód nem fér hozzá automatikusan olyan globális erőforrásokhoz, mint a konzol. Az ilyen funkciókat ehelyett importként kell biztosítani.

Hogy a `console.log`-hoz hasonló működést és néhány más kényelmi funkciót nyújtson, az Exercism WebAssembly-kurzusa minden feladatban elérhetővé tesz egy szabványos függvénykönyvtárat.

Ezeket a függvényeket a WebAssembly-modulod elején kell importálnod, ezután pedig a WebAssembly-kódodból hívhatod meg őket.

A `log_mem_*` függvények elvárják, hogy hozzáférhessenek a WebAssembly-modulod lineáris memóriájához. Ez alapértelmezés szerint privát állapot, ezért hogy hozzáférhetővé tedd, a lineáris memóriádat a `mem` exportnév alatt kell exportálnod. Ezt a következőképpen teheted meg:

```wasm
(memory (export "mem") 1)
```

# Lokális és globális változók naplózása

A WebAssembly minden primitív típusához biztosítunk naplózó függvényeket. Ez hasznos a globális és lokális változók naplózásához.

## log_i32_s - 32 bites előjeles egész szám naplózása a konzolra

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```

# Naplózás a lineáris memóriából

A WebAssembly lineáris memóriája egy bájtcímezhető értéktömb. Ez a WebAssembly-programok virtuális memóriájának felel meg.

Naplózó függvényeket biztosítunk, amelyek a lineáris memórián belüli címek egy tartományát bizonyos típusú statikus tömbökként értelmezik. Ez hasonlóan működik, mint a JavaScript TypedArray-jei. A hossz paramétereket nem bájtban mérjük, hanem a függvényhez tartozó típus egymást követő elemeinek számában.

**Ahhoz, hogy ezek a függvények működjenek, a WebAssembly-modulodnak deklarálnia és exportálnia kell a lineáris memóriáját a „mem” elnevezett exporttal**

```wasm
(memory (export "mem") 1)
```

## log_mem_as_utf8 - UTF8-karakterek sorozatának naplózása a konzolra

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

## log_mem_as_i8 - előjeles 8 bites egész számok sorozatának naplózása a konzolra

```wasm
(module
  (import "console" "log_mem_as_i8" (func $log_mem_as_i8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (func $main
    (memory.fill (i32.const 128) (i32.const -42) (i32.const 10))
    ;; Logs an array of 10x -42 to console
    (call $log_mem_as_u8 (i32.const 128) (i32.const 10))
  )
)
```
