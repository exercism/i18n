# Tippek

## 1. Mutatkozz be

Az `introduce` függvénynek „ki kell csomagolnia” a `player.Name`-ben lévő értéket.
Érdemes lehet a [`Options.defaultValue` függvényt][defaultvalue] használnod, hogy a `player.Name`-et a „becsomagolt” értékére alakítsd, amikor az `Some`, illetve a szükséges alapértelmezett értékre, amikor `None`.

## 2. Valósítsd meg az újraélesítés mechanikáját

A `revive` függvénynek `Some <player>` vagy `None` értékkel kell visszatérnie, ahol a `<player>` egy `Player` rekord, esetleg néhány módosított mezővel.

## 3. Valósítsd meg a varázslás mechanikáját

Érdemes lehet egy match-kifejezéssel lefedned mind a `Some`, mind a `None` esetet, ahogy a következő példában:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
