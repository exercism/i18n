# Utasítások

Visszacsábítottak Hyperiába (a magas inflációval) egy fájdalmasan magas napi díjért.

A Központi Bank fontolgatja, hogy bevezeti az amerikai dollárt második pénznemként, ezért az összes számviteli rendszert hozzá kell igazítani, hogy több pénznemet is kezeljenek.

Felkértek, hogy implementáld a pénznemösszeg-objektumot.

## 1. Tedd lehetővé, hogy a pénznemösszeget egyenlőségre lehessen tesztelni

Módosítsd a `CurrencyAmount` structot úgy, hogy kezelje az egyenlőséget. Ha a két pénznemösszeg-struct pénzneme nem ugyanaz („USD” vagy „HD”), akkor `ArgumentException` kivételt kell dobni.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Hasonlítsd össze a pénznemösszegeket

Módosítsd a `CurrencyAmount` structot úgy, hogy kezelje az összehasonlításokat (`>` és `<`, csak ezeket). Ha a két pénznemösszeg-struct pénzneme nem ugyanaz („USD” vagy „HD”), akkor `ArgumentException` kivételt kell dobni.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Add össze és vond ki a pénznemösszegeket

Módosítsd a `CurrencyAmount` structot úgy, hogy kezelje az aritmetikai összeadást és kivonást (`+` és `-`, csak ezeket). Ha a két pénznemösszeg-struct pénzneme nem ugyanaz („USD” vagy „HD”), akkor `ArgumentException` kivételt kell dobni.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Szorozd meg és oszd el a pénznemösszegeket

Módosítsd a `CurrencyAmount` structot úgy, hogy kezelje az aritmetikai szorzást és osztást (`*` és `/`, csak ezeket).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Alakítsd át a pénznemösszeget double típusra

Módosítsd a `CurrencyAmount` structot, hogy egy példányát explicit módon `double` típusra lehessen alakítani.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Alakítsd át a pénznemösszeget decimal típusra

Módosítsd a `CurrencyAmount` structot, hogy egy példányát implicit módon `decimal` típusra lehessen konvertálni.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
