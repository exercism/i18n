# Bevezetés

## Típusaliasok

### Típusaliasok

A Gleamben egy típusalias segítségével kényelmes nevet adhatsz egy létező típusnak, amelyet egyébként körülményes lenne leírni.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Ha `pub type`-tal definiálod, az alias a saját modulján kívül is használható. Ha a `pub` elmarad, az alias privát lesz, és más modulokból nem lehet rá hivatkozni.

## Szótárak

A Gleamben a szótárak olyan adatszerkezetek, amelyek kulcs-érték párokban tárolják az információt. Más nyelvekben ezeket asszociatív tömböknek, hasheknek vagy szótáraknak is nevezhetik.

Egy szótárban a kulcsok és az értékek bármilyen típusúak lehetnek, és az sem garantált, hogy a bejegyzések sorrendje megmarad, amikor hozzáférsz hozzájuk vagy visszakapod őket.

### A szótárak használata

A szótárakat a `gleam/dict` modul függvényeivel hozod létre és módosítod.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
