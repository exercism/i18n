# Tesztek

A teszteket többféleképpen is futtathatod.

## Interaktívan, az Emacson belülről

1. Nyisd meg a tesztfájlt: `M-x eval-buffer RET`
2. Interaktívan, egyenként: `M-x ert RET test-name RET`
3. Interaktívan, egyszerre az összeset: `M-x ert RET t RET`
   Ne feledd, hogy ez az Emacsba éppen betöltött összes tesztet lefuttatja!
4. Ha bármit módosítottál, tesztelés előtt futtasd újra a `M-x eval-buffer RET` parancsot

Ha csak az aktuális bufferben szeretnéd futtatni a teszteket, hozzáadhatod ezt a `.emacs` vagy `init.el` fájlodhoz:

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

Az Emacs újraindítása után:

1. Nyisd meg a tesztfájlt
2. `M-x my-eval-and-run-all-tests-in-buffer RET`

## A terminálból

Ha a terminálból, batch módban szeretnéd lefuttatni az összes tesztet, futtasd ezt: `emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit`

A fenti parancs kissé nehézkes, ezért ha szeretnéd:

1. Hozz létre egy `ert-run` nevű fájlt a `$PATH`-on (valószínűleg a `~/bin` könyvtárban)
2. A fájl tartalma a következő legyen:
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. Tedd a fájlt futtathatóvá a `chmod +x ert-run` paranccsal

Ezután elég egyszerűen meghívnod az `ert-run *-test.el` parancsot, és a tesztek
batch módban lefutnak.

## További lehetőségek

További lehetőségeket a dokumentációban találsz: `C-h i m ert RET`.
