# Utasítások

Ebben a feladatban egy mérleget fogsz modellezni, amelynek mértékegysége a kilogramm.

Hat részfeladatot kapsz, amelyek mindegyikében egy vagy több tulajdonságot kell megvalósítanod:

## 1. A mérleg rendelkezzen pontossággal

A különböző igények kiszolgálása érdekében minden mérleg testre szabható egy pontossággal (a tizedesjel utáni számjegyek száma).
Valósítsd meg a `WeighingMachine` osztályt úgy, hogy legyen egy csak olvasható `Precision` tulajdonsága, amely a konstruktor `precision` argumentumának értékét veszi fel:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. A súly beállítható legyen a mérlegen

Valósítsd meg a `WeighingMachine.Weight` tulajdonságot úgy, hogy a súly lekérdezhető _és_ beállítható legyen:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. Gondoskodj a negatív bemeneti súly elutasításáról

Nyilvánvaló, hogy valakinek nem lehet negatív a súlya. 
Adj hozzá ellenőrzést a `WeighingMachine.Weight` tulajdonsághoz, hogy `ArgumentOutOfRangeException` kivételt dobjon, amikor negatív súlyra próbálják állítani:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. A tára-beállítás alkalmazható legyen a mérlegen

A tára-beállítás bármilyen érték lehet (akár negatív, vagy olyan érték, amely negatívvá teszi a kijelzett súlyt).
Valósítsd meg a `WeighingMachine.TareAdjustment` tulajdonságot, hogy a tára-beállítás beállítható legyen:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. A mérleg rendelkezzen alapértelmezett tára-beállítással

Alapos tesztelés után úgy tűnik, hogy egy gyártási hiba miatt minden mérleg hajlamos `5`-tel túlbecsülni a súlyt.
Módosítsd a `WeighingMachine.TareAdjustment` tulajdonságot úgy, hogy az alapértelmezett értéke `5` legyen.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. A súly lekérdezhető legyen

Valósítsd meg a `WeighingMachine.DisplayWeight` tulajdonságot, amely visszaad egy stringet, amely a tára-beállítás utáni súlyt mutatja, a megfelelő pontossággal és a hozzáadott mértékegységgel.
Vedd figyelembe, hogy:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
