# Névjegy

A [bitstringek][bitstring] segítségével a programozók hatékonyan dolgozhatnak bináris adatokkal.

- A [`<<>>` speciális forma][bitstring-form] segítségével elegánsan hozhatsz létre bitstringeket.

  ```elixir
  <<0b101::3>> == <<5::3>> and <<5::3>> == <<5::size(3)>>
  # => true

  first = <<0b110::3>>
  second = <<0b001::3>>
  combined = <<first::bitstring, second::bitstring>>
  # => <<49::size(6)>>
  ```

- A `<<>>` forma segítségével mintát illeszthetsz, és az így kapott illesztéssel tovább [bonthatod fel a bináris adatokat][bitstring-matching].

  ```elixir
  <<data_size::32, count::size(data_size)>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  data_size
  # => 8
  count
  # => 3
  ```

- A bitstring maradékára a `::bitstring` segítségével illeszthetsz mintát.

  ```elixir
  <<_::32, remainder::bitstring>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  remainder
  # => <<3>>
  ```

- A bináris adat *típus* a bitstring egy speciális fajtája, ahol a bitek száma osztható 8-cal.
  - Minden bináris bitstring, de nem minden bitstring bináris.
- Az Elixir szintaktikai cukrot kínál az [egész literálok][integer-literal] különböző formáival való munkához:
  - `0b1000001 = ?A = 65`
