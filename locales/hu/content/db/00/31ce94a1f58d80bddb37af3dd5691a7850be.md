# Bevezetés

Rustban a Boolean értékeket a `bool` típus képviseli, amelynek értéke `true` vagy `false` lehet.

A Rust hat összehasonlító operátort támogat: `==` (egyenlő), `!=` (nem egyenlő), `>` (nagyobb, mint), `<` (kisebb,
mint), `>=` (nagyobb vagy egyenlő), `<=` (kisebb vagy egyenlő). Segítségükkel nem Boolean értékek viszonyát
értékelheted ki Boolean értékké.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Más nyelvekkel ellentétben a `0` nem `false`, és a nullától eltérő érték nem `true`.

A Rust két Boolean operátort támogat: a `||` (vagy) és a `&&` (és) operátort. A jobb oldali operandusukat csak
akkor értékelik ki, ha a bal oldali operandus még nem határozza meg a kifejezés eredményét. Vagyis a `||` csak akkor
értékeli ki a jobb oldali operandusát, ha a bal oldali operandus `false` értékű, a `&&` pedig csak akkor, ha az `true`
értékű.
