# Utasítások

Ebben a feladatban egy olyan titkosító eszköz szoftverét kell megírnod, amely adatok átalakításával működik. Szükséged van egy módszerre, amellyel egyszerűbb függvények összekapcsolásával rugalmasan hozhatsz létre bonyolult függvényeket.

Minden részfeladatnál adj vissza egy névtelen függvényt, amelyet a hívó scope-ból meg lehet hívni.

Minden függvény egész szám típusú argumentumot várjon. Az egész számok Elixirben bitenkénti műveletek végzésére is alkalmasak.

## 1. Készíts egy összeadót

Valósítsd meg a `Secrets.secret_add/1` függvényt. A függvény adjon vissza egy olyan függvényt, amely egy argumentumot kap, és hozzáadja ehhez a `secret_add`-nak átadott argumentumot.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. Készíts egy kivonót

Valósítsd meg a `Secrets.secret_subtract/1` függvényt. A függvény adjon vissza egy olyan függvényt, amely egy argumentumot kap, és abból kivonja a `secret_subtract`-nak átadott titkot.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. Készíts egy szorzót

Valósítsd meg a `Secrets.secret_multiply/1` függvényt. A függvény adjon vissza egy olyan függvényt, amely egy argumentumot kap, és megszorozza a `secret_multiply`-nak átadott titokkal.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. Készíts egy osztót

Valósítsd meg a `Secrets.secret_divide/1` függvényt. A függvény adjon vissza egy olyan függvényt, amely egy argumentumot kap, és elosztja a `secret_divide`-nak átadott titokkal.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

Használj egész számok közötti osztást, hogy a kimenet kompatibilis legyen a többi függvény várt bemenetével.

## 5. Készíts egy „and” műveletet végző függvényt

Valósítsd meg a `Secrets.secret_and/1` függvényt. A függvény adjon vissza egy olyan függvényt, amely egy argumentumot kap, és bitenkénti _and_ műveletet végez rajta és a `secret_and`-nak átadott titkon.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. Készíts egy „xor” műveletet végző függvényt

Valósítsd meg a `Secrets.secret_xor/1` függvényt. A függvény adjon vissza egy olyan függvényt, amely egy argumentumot kap, és bitenkénti _xor_ műveletet végez rajta és a `secret_xor`-nak átadott titkon.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. Készíts egy függvényösszekapcsolót

Valósítsd meg a `Secrets.secret_combine/2` függvényt. A függvény adjon vissza egy olyan függvényt, amely egy argumentumot kap, és sorrendben alkalmazza rá a `secret_combine`-nak átadott két függvényt.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
