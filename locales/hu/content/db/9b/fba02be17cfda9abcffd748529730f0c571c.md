# Kiegészítés az utasításokhoz

## Szavak

Definiálj egy `stopwatch` tuple-t és egy `<stopwatch> ( -- stopwatch )` konstruktort, amely egy új stoppert ad vissza `"ready"` állapotban, eltelt idő és korábbi körök nélkül.

Add meg a következő, stoppern működő szavakat:

- `state ( stopwatch -- str )`: `"ready"`, `"running"` vagy `"stopped"`.
- `current-lap ( stopwatch -- str )`: az aktuális kör eltelt ideje `"HH:MM:SS"` formátumú stringként.
- `total ( stopwatch -- str )`: az aktuális kör és az összes korábbi kör együttes eltelt ideje `"HH:MM:SS"` formátumú stringként.
- `previous-laps ( stopwatch -- seq )`: a korábban rögzített körök tömbje, mindegyik `"HH:MM:SS"` formátumú stringként.
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )` és `lap ( stopwatch -- )`: a fenti táblázat négy parancsa. Ha az egyiket olyan állapotból hívod meg, amelyben nem engedélyezett, hibát kell `throw`-olnia.

Az időt a következővel léptetheted előre:

- `advance-time ( str stopwatch -- )`: add hozzá a `"HH:MM:SS"` időtartamot az aktuális körhöz. Ez csak akkor van hatással, amikor a stopper éppen fut.
