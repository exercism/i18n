# Alapok

A Haskell funkcionális programozási nyelv, benne a függvények első osztályú állampolgárnak számítanak.
Ez azt jelenti, hogy a függvényeket argumentumként átadhatod más függvényeknek, más függvények értékként visszaadhatják őket, és változókhoz is rendelheted őket.

## Függvények

A Haskellben a függvényeket a `=` operátorral definiáljuk.
A függvény nevét az argumentumai követik, szóközzel elválasztva.
Ez eléggé eltér a legtöbb más nyelvtől, ahol a függvénynév után zárójel következik, benne vesszővel elválasztott argumentumokkal.

```haskell
add number1 number2 = number1 + number2
```

A Haskell statikusan típusos nyelv, a ghc fordító ki tudja következtetni az argumentumok és a visszatérési érték típusát.
Azonban jó gyakorlat megadni az argumentumok és a visszatérési érték típusát.
Egy függvény típusának megadásához a `::` operátort használjuk.
A függvény nevét a `::` operátor követi, majd az argumentumok típusai `->` jelekkel elválasztva; az utolsó típus a visszatérési érték.

```haskell
justNumber :: Int
justNumber = 42

add :: Int -> Int -> Int
add number1 number2 = number1 + number2
```

## Függvények meghívása

Egy függvény meghívásához a függvény nevét írjuk le, majd szóközzel elválasztva az argumentumokat.

```haskell
add 1 2
```

Amikor egy függvényt argumentumként adunk át egy másik függvénynek, zárójelekkel kell megadnunk a kiértékelés sorrendjét.

```haskell
add (add 1 2) 3
```

Itt először az 1 2 értékelődik ki, majd az eredmény a külső add függvénynek adódik át, így a külső add függvény két argumentumot kap.

## Behúzás / jelentéssel bíró szóközök

A Haskell a szóközöket és a behúzást használja a kódrészek határainak megjelölésére.
***Az olyan kódot, amely valamely kifejezés része, beljebb kell húzni, mint a kifejezés kezdetét.***

- A modul-, az import- és a legfelső szintű függvénydefinícióknak a bal szélső oszlopban kell kezdődniük.
- Ha egy kifejezés több sorra bomlik, a kifejezés részét képező kódot legalább egy szóközzel beljebb kell húzni a kifejezés alatt.
- A kifejezés azon részeit, amelyek összetartoznak, ugyanannyi szóközzel érdemes behúzni.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## Modulok

A modulok függvényeket exportálnak.
Ez azt jelenti, hogy használhatod azokat a függvényeket, amelyeket a modul az export utasításában elérhetővé tesz.
Egy modul definiálhat függvényeket kizárólag belső használatra is.
Alapértelmezés szerint azokat a függvényeket, amelyeket nem exportálsz kifejezetten, nem lehet a modulon kívülről használni.

A modul elején megadjuk a modul nevét.
Ha van egy Calculator.hs nevű fájlunk, akkor a modulunk neve is Calculator legyen.
Ezután megadjuk, hogy mely függvényeket exportálja, és ezután kezdhetjük el írni a függvényeket.
Kezdjük tehát ezzel.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Kommentek

A komment olyan szöveg a Haskell-fájlban, amit nem kódként értelmezünk.
Elsősorban arra szolgál, hogy te és a többi programozó elolvassa.
Az egysoros kommentekhez van egy egyszerű szintaxis, amely két kötőjelen alapul.
Többsoros kommentekre is van lehetőség a `{-` és `-}` nyitó és záró elhatároló pár segítségével.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
