# Bevezetés

## Tömbök

A Cairo alaptára egy `Array` típust valósít meg.

Hasonló a más programozási nyelvekben megszokott tömbtípusokhoz, de néhány lényeges különbséggel:

- Az elemeket hatékonyan csak az `Array` típus végéhez lehet hozzáadni, és hatékonyan csak az elejéről lehet eltávolítani.
- A tömb indexével nem lehet egy elemet kézzel beállítani.

Tömböket az `ArrayTrait::new` függvénnyel és az `array!` makróval is létrehozhatsz:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

Az elemeket az `ArrayTrait::append` függvénnyel adhatod hozzá a tömbhöz:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

Az elemeket az `ArrayTrait::pop_front` függvénnyel távolíthatod el a tömbből:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

A Cairo emellett bevezet egy `Span` típust, amely az `Array` „pillanatképeként” viselkedik.

Minden `Array` átalakítható `Span` típussá a `ToSpanTrait::span` függvénnyel:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Egy tömb `Span` típussá alakítása nagyon hatékony, mert a `Span` valójában csak egy adatszerkezet, amely lehetővé teszi a Cairo számára, hogy „rálásson” a tömb egy szakaszára, és semmilyen módon nem módosítja azt.

Azzal, hogy egy tömböt `Span` típussá alakítasz, a Cairo több műveletet tesz lehetővé, mint amit az `Array` típuson közvetlenül megengedne, például egy elem eltávolítását a span elejéről.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Figyeld meg, hogy a `one_to_four_span` változót a `mut` kulcsszóval kellett módosíthatóvá tennünk ahhoz, hogy meghívhassuk a `pop_back` metódust, amely úgy módosítja a spant, hogy lerövidíti a tömbnek azt a szakaszát, amelyre a span „rálát”.
