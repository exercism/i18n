# Típusdeklaráció

A PHP-ban a típusdeklarációk futásidőben ellenőrzik a függvényargumentumok, a visszatérési értékek és az osztálytulajdonságok típusát.
A függvényeknél `void` visszatérési típust adhatsz meg annak jelzésére, hogy a függvény nem ad vissza értéket.
A deklarált típusok emellett futásidőben azt is ellenőrzik, hogy a függvények megfelelő típusú értéket adnak vissza.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## Típusuniók

Ha egy függvényargumentum, visszatérési érték vagy osztálytulajdonság egynél több típusú lehet, akkor uniós típust deklarálhatsz.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Kevert típusok

Amikor kóddal dolgozunk, előfordulhat, hogy nem tudunk típust megadni.
A PHP 8.0-tól kezdve van egy `mixed` nevű menekülőtípus.
A `mixed` egyenértékű a `object|resource|array|string|float|int|bool|null` uniós típussal.
