# Utasítások

Ebben a feladatban a [Blackjack][blackjack] néhány szabályát fogod megvalósítani, például azt, hogyan játsszák és pontozzák a játékot.

**Megjegyzés**: Ebben a feladatban az _`A`_ ászt, a _`J`_ bubit, a _`Q`_ dámát, a _`K`_ pedig királyt jelent.
A jokereket nem használjuk.
Egy [standard francia színes 52 lapos pakliból][standard_deck] indulunk ki, de a legtöbb változatban több paklit kevernek össze a játékhoz.

## 1. Egy kártya értékének kiszámítása

Blackjackben minden játékos maga dönti el, hogy az ász 1 vagy 11 pontot ér (_erről később még lesz szó_).
A figurás kártyák (`J`, `Q`, `K`) 10 pontot érnek, minden más kártya pedig a „pip” (_számérték_) értékét éri.

Definiáld a `value_of_card(<card>)` függvényt `card` paraméterrel.
A függvénynek vissza kell adnia az átadott kártya string _numerikus értékét_.
Mivel az ász több értéket is felvehet (1 **vagy** 11), ez a függvény egyelőre rögzítse az ász kártya értékét 1-ben.
Később megvalósítasz egy függvényt, amely egy meglévő kéz ismeretében meghatározza az ász kártya értékét.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. A nagyobb értékű kártya meghatározása

Definiáld a `higher_card(<card_one>, <card_two>)` függvényt `card_one` és `card_two` paraméterekkel.
Pontozás szempontjából a `J`, `Q` vagy `K` értéke 10.
A függvénynek vissza kell adnia, hogy melyik kártya értéke nagyobb a pontozás szempontjából.
Ha mindkét kártya értéke egyenlő, add vissza mindkettőt.
A két kártya visszaadásához vesszőt használhatsz a `return` utasításban:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

Az ász több értéket is felvehet, ezért ebben a részfeladatban a `A` kártyák értékét 1-ben rögzítjük.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. Az ász értékének kiszámítása

Ahogy korábban említettük, az ász _akár_ 1 **vagy** 11 pontot is érhet.
A játékosok a lehető legközelebb próbálnak kerülni a 21-hez, anélkül hogy _túllépnének_ 21-en (_azaz „besokallnának”_).

Definiáld a `value_of_ace(<card_one>, <card_two>)` függvényt `card_one` és `card_two` paraméterekkel; ezek egy pár kártya, amelyek már a kézben vannak, _mielőtt_ ász kártyát kapnál.
A függvényednek el kell döntenie, hogy a következő ász 1-es vagy 11-es értéket kap-e, és vissza kell adnia ezt az értéket.
Ne feledd: a kéz értékének az ásszal együtt a lehető legmagasabbnak kell lennie, _anélkül_ hogy meghaladná a 21-et.

**Tipp**: ha már van ász a kezünkben, akkor a következő ász értéke 1 lenne.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. A „Natural” vagy „Blackjack” kéz meghatározása

Ha a játékos első két lapként ászt (`A`) és tízest (10, `K`, `Q` vagy `J`) kap, akkor a pontszáma 21.
Ezt nevezik **blackjack** kéznek.


Definiáld az `is_blackjack(<card_one>, <card_two>)` függvényt `card_one` és `card_two` paraméterekkel; ezek egy pár kártya.
Döntsd el, hogy a kétkártyás kéz **blackjack**-e, és add vissza a Boolean `True` értéket, ha igen, egyébként `False`-t.

**Megjegyzés**: A pontszám _kiszámítása_ többféleképpen is elvégezhető.
De ha lehetséges, szeretnénk, ha ellenőriznéd, hogy van-e ász és tízes **_a kézben_** (_vagy egy adott pozícióban_), ahelyett hogy _összeadnád_ a kéz értékeit.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. Párok szétválasztása

Ha egy kéz első két lapja azonos értékű (_például két hatos vagy egy `Q` és `K`_), a játékos dönthet úgy, hogy két külön kézként kezeli őket.
Ezt nevezik „párok szétválasztásának”.

Definiáld a `can_split_pairs(<card_one>, <card_two>)` függvényt `card_one` és `card_two` paraméterekkel; ezek egy pár kártya.
Döntsd el, hogy ez a kétkártyás kéz szétválasztható-e két párra.
Ha a kéz szétválasztható, add vissza a Boolean `True` értéket, egyébként `False`-t.

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. Duplázás

Amikor az osztott első két lap összértéke 9, 10 vagy 11 pont, a játékos további tétet tehet, amely megegyezik az eredeti tétével.
Ezt nevezik „duplázásnak”.

Definiáld a `can_double_down(<card_one>, <card_two>)` függvényt `card_one` és `card_two` paraméterekkel; ezek egy pár kártya.
Döntsd el, hogy a kétkártyás kéz „duplázható”-e, és add vissza a Boolean `True` értéket, ha igen, egyébként `False`-t.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
