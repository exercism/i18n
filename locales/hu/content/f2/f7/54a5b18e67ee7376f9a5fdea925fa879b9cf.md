# Utasítások

Szenvedélyes madárfigyelő vagy, aki nyomon követi, hány madár járt a kertedben.
A madarakat általában egy füzetben rovásokkal szoktad megszámolni, de hogy jobban dolgozhass az adataiddal, digitalizáltad az elmúlt hetek madárszámait.

## 1. Határozd meg, összesen hány madarat számoltál eddig

Kezdjük az adatok elemzését egy átfogó képpel.
Nézzük meg, összesen hány madarat számoltál meg, amióta vezeted a naplóidat.

Készíts egy `totalBirdCount` függvényt, amely egy `Int`-ekből álló tömböt fogad, ami a napi madárszámokat tartalmazza.
A függvény adja vissza, hogy összesen hány madarat számoltál meg.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. Számold ki, hány madár látogatott el egy adott héten

Most, hogy már nagyjából átlátod a madárszámaidat, részletesebb elemzést szeretnél készíteni.

Készíts egy `birdsInWeek` függvényt, amely fogadja a napi madárszámok tömbjét és a hét sorszámát.

A függvény adja vissza, hogy összesen hány madarat számoltál meg abban a konkrét héten.
Feltételezheted, hogy a hetek mindig hiánytalanul vannak rögzítve.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. Javíts ki egy számolási hibát

Rájöttél, hogy amíg a madarakat próbáltad nyomon követni, egy madár a kert egy távoli zugában rejtőzött.

Kiderítetted, hogy ez a madár minden második napot a kertedben töltött.

Azt nem tudod pontosan, hol volt a köztes napokon, de az biztos, hogy nem a kertedben.

A madárfigyelői megérzésed azt is súgja, hogy a madár a listád első rögzített napján a kertedben volt.

Ezeknek az új információknak a birtokában írj egy `fixBirdCountLog` függvényt, amely argumentumként a naponta megszámolt madarak tömbjét kapja, és a számolási hiba kijavítása után visszaadja a tömböt.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
