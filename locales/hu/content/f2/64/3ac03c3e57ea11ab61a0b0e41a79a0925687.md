# Bevezetés

A castolás és a típuskonverzió két különböző módja annak, hogy egy kifejezést egyik adattípusból a másikba alakítsunk.

A cast operátorral (`(<type>)`) egy kifejezést más típusba castolhatsz.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Ha a típusok nem kompatibilisek, akkor `InvalidCastException` kivétel dobódik. Számok esetében ez azt jelenti, hogy a fogadó típus nem tudja ábrázolni a castolt értéket. Osztályok esetében az egyik típusnak a másikból kell származnia (ez triviálisan a struktúrákra is igaz).

A _castolás_ alternatívája a _típuskonverzió_, amely az `is` operátort használja. Ezt jellemzően referenciatípusokra és nullázható típusokra alkalmazzuk.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Ha egy objektum pontos típusát kell megállapítanod, akkor az `is` talán kicsit túl megengedő, mert igazat ad vissza egy osztályra, valamint minden olyan osztályra és interfészre is, amelyből az közvetlenül vagy közvetetten származik. Ilyenkor a `typeof` és az `Object.GetType()` jelenti a megoldást.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
