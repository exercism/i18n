# Utasítások

Adott egy életkor másodpercben. Számold ki, hány éves lenne valaki a Naprendszerünk egyik bolygóján.

Egy földi év 365,25 földi nappal, azaz 31 557 600 másodperccel egyenlő.
Ha valakiről azt mondanák, hogy 1 000 000 000 másodperces, akkor 31,69 földi éves lenne.

A többi bolygónál számításba kell venned a keringési idejüket földi években:

| Bolygó   | Keringési idő földi évben |
| -------- | ------------------------- |
| Merkúr   | 0.2408467                 |
| Vénusz   | 0.61519726                |
| Föld     | 1.0                       |
| Mars     | 1.8808158                 |
| Jupiter  | 11.862615                 |
| Szaturnusz | 29.447498               |
| Uránusz  | 84.016846                 |
| Neptunusz | 164.79132                |

~~~~exercism/note
A Föld Nap körüli egy teljes keringésének tényleges hossza közelebb van a 365,256 naphoz (1 sziderikus év).
A Gergely-naptárban átlagosan 365,2425 nap van.
Bár nem teljesen pontos, ebben a feladatban a 365,25-ös értéket használjuk.
