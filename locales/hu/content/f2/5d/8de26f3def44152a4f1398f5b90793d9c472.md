# Bevezetés

Az algebrai adattípus (ADT) névvel ellátott esetek rögzített számát képviseli.
Az ADT minden értéke pontosan az egyik névvel ellátott esetnek felel meg.

Az ADT-t a `data` kulcsszóval definiálod, az eseteket függőleges vonal (`|`) karakterekkel elválasztva.
Ha egyik esethez sem tartozik adat, az ADT hasonló ahhoz, amit más nyelvekben általában _felsorolásnak_ (vagy _enumnak_) neveznek.

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

Egy ADT minden esetéhez tartozhat opcionálisan adat, és a különböző esetekhez különböző típusú adat tartozhat.
Ha az esethez adat tartozik, konstruktorra van szükség.

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

Egy adott esethez tartozó értéket úgy hozhatsz létre, hogy a nevére hivatkozol (például `NInt 22`).
Mivel az esetnevek csupán konstruktorfüggvények, a hozzájuk tartozó adatot szokásos függvényargumentumként adhatod át.

Az ADT-knek _strukturális egyenlőségük_ van, ami azt jelenti, hogy két érték, amely ugyanahhoz az esethez tartozik, és ugyanaz az (opcionális) adatuk, egyenértékű.

Bár az ADT-kkel dolgozhatsz `if/else` kifejezésekkel is, a velük való munka ajánlott módja a mintaillesztés a _case_ utasítással:

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
