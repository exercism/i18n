# Bevezetés

A [`Set`][set-docs] egy rendezetlen gyűjtemény, amely a `List`-tel ellentétben garantáltan nem tartalmaz ismétlődő értékeket.

A `Set` interfész generikus típusparamétere a `Set`-ben tárolt elemek típusát jelöli:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

Vedd észre, hogy a `Set.of()` metódus egy [_módosíthatatlan_][unmodifiable-set-docs] `Set` példányt hoz létre.
Ha olyan metódusokat próbálsz meghívni rajta, mint az `add` és a `remove`, az futásidőben kivételt eredményez.

Módosítható `Set` létrehozásához egy olyan osztályt kell példányosítanod, amely megvalósítja a `Set` interfészt.
A leggyakrabban használt beépített osztály, amely megvalósítja ezt az interfészt, a [`HashSet`][hashset-docs] osztály.

```java
Set<Integer> ints = new HashSet<>();
```

A `Set` interfész a [`Collection`][collection-docs] és az [`Iterable`][iterable-docs] interfészből származik, ezért sok metódust oszt meg más gyűjteménytípusokkal.
A `Collection` interfésztől azonban van egy figyelemre méltó eltérés: az olyan metódusok, mint az `add` és a `remove`, `boolean` értékkel térnek vissza a `void` helyett, ami azt jelzi, hogy a metódus hívásakor az elem benne volt-e a halmazban:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
