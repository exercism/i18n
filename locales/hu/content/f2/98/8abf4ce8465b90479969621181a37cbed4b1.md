# Részletesen

A stringek olyan adattípusok, amelyek szöveges értéket képviselnek.
A [`Strings`][strings-and-characters] a Swiftben `Character`-ek gyűjteménye, amelyek maguk egy [Unicode skalárértéket][unicode-scalar-values] tartalmaznak.

Stringet string literál segítségével hozhatsz létre; a string literál olyan karaktersorozat, amelyet kettős idézőjelek (`"`) zárnak közre.
Többsoros stringekhez hármas idézőjeleket (`"""`) használhatsz.

```swift
let hello : String = "Hello, World!"

let poem : String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

A Swift stringjei emellett az [NSString][nsstring-docs] osztály minden funkciójával is rendelkeznek, amelyet eredetileg az Apple Objective-C könyvtáraiban használtak.

## Karakter

A `Character` olyan adattípus, amely egyetlen [Unicode skalárértéket][unicode-scalar-values] tárol, amely egy vagy több Unicode kódpontból áll.
A Unicode skalárérték bármely [Unicode-kód][unicode] pont a `U+0000` és `U+D7FF` közötti zárt tartományban, illetve a `U+E000` és `U+10FFFF` közötti zárt tartományban.

```swift
let aChar : Character = "A"
```

## Típuskövetkeztetés

A Swift képes kikövetkeztetni egy string literál típusát, és alapértelmezés szerint `String`-ként következteti ki.
Egy stringet explicit módon `Character`-ré nyilváníthatsz a `Character` típusannotációval, ami megköveteli, hogy az érték egyetlen karakter legyen.

```swift
let aString = "A"
let aChar: Character = "A"
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Összefűzés

A Swiftben a stringek a `+` operátorral [fűzhetők össze][concatenated].
A karaktereket **nem** lehet a `+` operátorral stringekhez fűzni anélkül, hogy előbb stringgé alakítanád a karaktert.

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Az [`append(_:)`][append] metódus módosítja a stringet úgy, hogy egy stringet vagy egy karaktert fűz a végére.

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## String interpoláció

A [string interpoláció][string-interpolation] olyan módja a String létrehozásának, amely különböző forrásokból, például változókból és kifejezésekből származó értékeken alapul.
Ahhoz, hogy string interpolációval értéket illessz be egy stringbe, a kifejezést vagy értéket zárójelbe teszed, amelyet egy visszaperjel előz meg.

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## A stringek és a karakterek tulajdonságai

A stringeknek és a karaktereknek többféle _tulajdonságuk_ van, amelyekkel információt kérdezhetsz le a stringről vagy a karakterről.

### A stringek tulajdonságai

Íme néhány a leggyakoribb stringtulajdonságok közül, de az összes megtalálásához nézd meg a [dokumentációt][string-docs].

| Tulajdonság | Leírás                                              | Példa                          |
| ----------- | --------------------------------------------------- | ------------------------------ |
| `isEmpty`   | `true`-t ad vissza, ha a string üres                | `"Hello".isEmpty equals false` |
| `count`     | A stringben lévő karakterek számát adja vissza      | `"Hello".count   equals 5`     |

### A karakterek tulajdonságai

Íme néhány a leggyakoribb karaktertulajdonságok közül, de az összes megtalálásához nézd meg a [dokumentációt][string-docs].

| Tulajdonság    | Leírás                                        | Példa                          |
| -------------- | --------------------------------------------- | ------------------------------ |
| `isLowercase`  | `true`-t ad vissza, ha a karakter kisbetűs    | `"a".isLowercase  equals true` |
| `isUppercase`  | `true`-t ad vissza, ha a karakter nagybetűs   | `"A".isUppercase  equals true` |
| `isNumber`     | `true`-t ad vissza, ha a karakter szám        | `"1".isNumber     equals true` |
| `isWhitespace` | `true`-t ad vissza, ha a karakter whitespace  | `" ".isWhitespace equals true` |

## Típuskonverzió

Ha egy típust stringgé szeretnél alakítani, használhatod a `String()` kezdőértéket, amely számos típust elfogad, többek között `Int`-et, `Double`-t, `Character`-t és egyebeket.

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Speciális karakterek

A Swiftben néhány [speciális karakter][special-characters] használható a stringekben.

| Érték    | Leírás                        |
| -------- | ----------------------------- |
| `\0`     | Null karakter                 |
| `\\`     | Visszaperjel                  |
| `\t`     | Vízszintes tabulátor          |
| `\n`     | Soremelés                     |
| `\r`     | Kocsivissza                   |
| `\'`     | Egyszeres idézőjel            |
| `\"`     | Kettős idézőjel               |
| `\uFFFF` | Hexadecimális Unicode-karakter |

```swift
let quote : String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode : Character = "\u{1F496}"
print(unicode) // Prints 💖
```
