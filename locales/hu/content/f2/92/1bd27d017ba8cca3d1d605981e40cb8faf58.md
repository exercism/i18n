# Névjegy

A C++-ban az elágazások hasonlóak más nyelvek elágazásaihoz.
Bármely elágazási művelet mögöttes típusa a `bool` típus, amelynek az értéke `true` vagy `false` lehet.
Az elágazásokat gyakran vezérlési mechanizmusként használjuk különféle feltételek ellenőrzésére.

Használhatsz egy `if` elágazást, amely akkor hajtja végre a kódját, ha a mögöttes feltétel `true`, például így:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Ha egynél több esetről van szó, több `if` elágazást is összefűzhetsz az `else if` és az `else` utasításokkal.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

A C++17 óta az `if` elágazások egy rövid utasítást is tartalmazhatnak, amellyel egy vagy több változót inicializálhatsz az `if` elágazás számára.
Például:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Megjegyzés: az inicializálásban létrehozott változók az `if` elágazás befejeződése után nem érhetők el.
