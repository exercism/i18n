# Utasítások

Ebben a feladatban különböző típusú távirányítós autók közötti versenyeket fogsz szervezni.
Minden autónak megvan a maga sebessége és akkumulátorfogyasztási jellemzője.

Az autók teljesen feltöltött (100%-os) akkumulátorral indulnak.
Valahányszor vezetsz egy autót a távirányítóval,
az megteszi az autó sebességét méterben, és az akkumulátorfogyasztás mértékével csökkenti a hátralévő akkumulátorszázalékot.

Ha egy autó akkumulátora az akkumulátorfogyasztás százaléka alá esik, nem tudod tovább vezetni az autót.

Minden versenypályának megvan a maga hossza.
Az autókat úgy tesztelik, hogy ki tudják-e futni a pályát anélkül, hogy kimerülne az akkumulátoruk.

## 1. Hozz létre egy távirányítós autót

Definiálj egy `Car` struktúrát a következő `int` típusú mezőkkel:

- battery
- batteryDrain
- speed
- distance

Hozz létre távirányítós autót egy `NewCar` függvény definiálásával, amely a két paramétereként az autó sebességét méterben
és az akkumulátorfogyasztás százalékát veszi át (mindkettő `int` típusú), majd visszaad egy `Car` példányt:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. Hozz létre egy versenypályát

Definiálj egy másik struktúratípust `Track` néven, amelynek `distance` mezője egész típusú.
Hozz létre versenypályát egy `NewTrack` függvény definiálásával, amely egyetlen paramétereként a pálya hosszát veszi át méterben (`int` típusú):

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. Vezesd az autót

Valósítsd meg a `Drive` függvényt, amely az autó sebessége alapján frissíti a megtett méterek számát, és az akkumulátorfogyasztásnak megfelelően csökkenti az akkumulátort.
Ha nincs elég akkumulátor még egy vezetéshez, az autó nem mozdul:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. Ellenőrizd, hogy egy távirányítós autó ki tud-e futni egy versenyt

Egy verseny kifutásához az autónak képesnek kell lennie megtenni a verseny távját.
Ez azt jelenti, hogy nem merül ki az akkumulátora, mielőtt átlépi a célvonalat.
Valósítsd meg a `CanFinish` függvényt, amely paramétereként egy `Car` és egy `Track` példányt vesz át, és `true`-t ad vissza, ha az autó ki tudja futni a versenyt; egyébként `false`-t ad vissza.

Tételezd fel, hogy éppen a verseny rajtvonalánál állsz, és beindítod az autó motorját a versenyhez.
Vedd figyelembe, hogy az autó akkumulátora nem feltétlenül van teljesen feltöltve, amikor a verseny elkezdődik:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
