# Bevezetés

A Kotlin `when` egy feltételes kifejezés, amellyel több lehetőség közül választhatsz.
Hasonló a Java `switch` szerkezetéhez, és rugalmasabb, mint az `if` ... `else if` ... `else` láncolata.

Az `if`-hez hasonlóan a `when` is használható kifejezésként, amely értéket ad vissza.

## Érték illesztése

A `when` után zárójelben add meg az illesztendő értéket.
Minden ág ezt az értéket veti össze a saját mintájával, amíg valamelyik illeszkedik:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Minden ág `pattern -> result` alakú.
- Az ágakat fentről lefelé haladva próbálja ki a program, amíg talál egyezést.
  Csak az első illeszkedő ág fut le.
- Ha az érték nincs a fentiek között, használd az `else` ágat (hasonlóan az `if`-lánc záró `else` ágához).

Ez a [mintaillesztés][pattern-matching] elvéhez hasonlít.
A `pattern` helyén állhat maga az illesztendő érték, de az `is` kulcsszóval típus szerint is illeszthetsz:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

vagy használhatod az `in` kulcsszót annak ellenőrzésére, hogy az érték benne van-e egy tartományban, egy kollekcióban, egy stringben vagy bármi másban, aminek van `contains` metódusa:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

~~~exercism/note
Az `in` más objektumokkal is használható, ha definiálod a `contains` [operátor-kiterjesztő függvényt][kotlin-operator-overloading].
Például egy [Regex][kotlin-regex] objektummal így:

```kotlin
operator fun Regex.contains(text: CharSequence): Boolean = this.matches(text)

fun replace(input: String) {
    return when(input) {
        in Regex("""ani*""") -> println("animal")
        in Regex("""fru.*""") -> println("fruit")
        in Regex("""num.*""") -> println("number")
        else -> println("unknown")
    }
}
```

## Őrfeltételek

Értékre illesztéskor a minta után egy `if` feltétellel további feltételeket is megadhatsz.
Ezeket a feltételeket őrfeltételeknek nevezzük.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

Még `else if` is használható.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Feltételek illesztése

Az értéket el is hagyhatod, és minden ágra logikai feltételt írhatsz:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Az ágak ellenőrzése itt is fentről lefelé halad, és csak az az első ág fut le, amelynek feltétele `true`.

## A `when` használata kifejezésként

Ha a `when`-t az eredményéért használod (változóhoz rendeled, függvényből adod vissza, és így tovább), minden lehetséges esetet le kell fedned.

- Értékre illesztéskor adj hozzá egy `else` ágat, hacsak nem fedted már le az összes lehetséges értéket (például egy `Boolean` vagy egy `enum` összes értékét).
- Feltételek illesztésekor kötelező egy `else` ág, mert a fordító nem tudhatja, hogy a feltételeid minden esetet lefednek.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
