# Bemutató

A _string_ a JavaScript azon adattípusa, amely szöveges adat tárolására szolgál.
Egyetlen karakternek nincs külön adattípusa.

## String létrehozása

Úgy hozol létre egy string [literált][literal], hogy a szöveget aposztrófok vagy idézőjelek közé teszed.
Az Exercism-ön aposztrófokat használunk.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

A szöveg néhány speciális karakterét visszaperjellel `\` kell megelőzni, lásd az [escape szekvenciákat az MDN-en][mdn-escape-sequences].

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

Az aposztrófokon és az idézőjeleken kívül úgy is létrehozhatsz stringet, hogy a szöveget backtickek közé teszed.
Ez a szintaxis lehetővé teszi, hogy aposztrófokat vagy idézőjeleket, sőt új sorokat is elhelyezz benne anélkül, hogy escape-elned kellene őket.
Kifejezéseket is beágyazhatsz vele, lásd a [Template Stringeket][mdn-template-strings] a részletekért.

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## A stringek mint karakterek listái

Egy string felfogható karakterek listájaként, ahol az első karakter indexe `0`.
Egy adott karakterhez a stringben szögletes zárójelekkel és a kívánt betű indexével férhetsz hozzá.
Vagy használhatod a `charAt` metódust is.

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

A string karaktereinek számát a `length` tulajdonság segítségével állapíthatod meg.

```javascript
'cat'.length;
// => 3
```

## Összefűzés és metódusok

A stringek összefűzésének legegyszerűbb módja a `+` összeadásoperátor használata.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

A stringek rengeteg segédmetódust kínálnak, a teljes listát az [MDN dokumentációjában a stringmetódusokról][mdn-string-methods] találod.
Az alábbi lista néhány gyakran használt segédmetódust mutat be.

- [`toUpperCase`][mdn-to-upper-case] és [`toLowerCase`][mdn-to-lower-case] - az összes karaktert kis- vagy nagybetűssé alakítja
- [`trim`][mdn-trim] - eltávolítja a szóközöket az elejéről és a végéről
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] és [`endsWith`][mdn-ends-with] - meghatározza, hogy egy másik string része-e az adott stringnek
- [`slice`][mdn-slice] - kivágja a string egy szakaszát

## A stringek megváltoztathatatlanok

A fenti metódusok alkalmazása soha nem változtatja meg az eredeti stringet. Ehelyett létrejön egy új string, és az lesz visszaadva.
A stringek (és más primitív adattípusok) megváltoztathatatlanok JavaScriptben.
Ez azt is jelenti, hogy a fent bemutatott zárójeles szintaxissal nem tudsz más karaktert rendelni egy adott indexhez (ahogyan tömböknél tennéd).

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
