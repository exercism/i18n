# Tartományok

A [tartományok][range] két érték közötti intervallumot jelölnek.
A leggyakoribb típusok, amelyek támogatják a tartományokat, az `Int`, a `Char` és a `String`.
Sok mindenre használhatók: gyűjtemények gyors létrehozására, stringek feldarabolására, annak ellenőrzésére, hogy egy érték benne van-e egy tartományban, és iterációra.
A `..` vagy a `...` tartományoperátorral hozhatók létre (az előbbi a záró értéket is beleérti, az utóbbi nem).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Azért van két tartományoperátor, hogy a záró értéket tartalmazó vagy nem tartalmazó tartományokat hozhassunk létre, ami például a nullától induló indexelésnél lehet hasznos.

A tartományokat a `Range` kezdőértékével is létrehozhatod.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Amikor a `..` vagy a `...` tartományoperátorral hozol létre tartományt Crystalban, és metódust szeretnél meghívni rajta, zárójelbe kell tenned a tartományt.
Ennek az az oka, hogy különben a metódus a tartományoperátor második argumentumán hívódna meg.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Részstringek kinyerése

Ha egy stringből részstringet szeretnél kinyerni, a tartományoperátorral megkaphatod.
Ehhez olyan tartományt hozz létre, amely a részstring kezdő- és záróindexét adja meg.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Negatív indexekkel a string végéről is kinyerheted a részstringet.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Tartománymetódusok

A tartományoknak van egy sor metódusuk, amelyekkel dolgozhatsz. Ezekkel például kiszámíthatod a tartomány összes értékének összegét, vagy ellenőrizheted, hogy a tartomány tartalmaz-e egy értéket.

| Method                  | Description                                                             | Example                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | A tartomány összes értékének összegét adja vissza                       | `(1..5).sum # => 15`            |
| [`size`][size]          | A tartomány méretét adja vissza                                         | `(1..5).size # => 5`            |
| [`includes?`][indludes] | `true`-t ad vissza, ha a tartomány tartalmazza a megadott értéket, egyébként `false`-t | `(1..5).includes?(3) # => true` |

## Végtelen és kezdet nélküli tartományok

A tartomány lehet végtelen és kezdet nélküli.
A végtelen vagy kezdet nélküli tartomány kezdő- vagy záróértéke `nil`, de a `nil` elhagyható a tartomány definiálásakor.

A kezdet nélküli és végtelen tartományok például akkor hasznosak, ha egy stringet az elejétől vagy a végéig szeretnél feldarabolni.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Ha nem gyűjteményen használod, a végtelen tartomány végtelen sorozatot eredményezhet, ezért óvatosan bánj vele.
~~~~

## Char-tartományok

A Char-ok használhatók tartományokban, és lehetővé teszik, hogy két karakter közötti intervallumot kapj.
Ez például akkor jön jól, ha az ábécét szeretnéd megkapni.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## String-tartományok

A stringek is használhatók tartományokban, így két string közötti stringintervallumot kaphatsz.
A viselkedése azonban némileg eltér a `Char`-étól, ha több karaktert használsz egy stringtartományban.
Bonyolultabb stringtartományoknál zavaróvá válhat a viselkedése, ezért légy óvatos.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## Egyéni objektumok tartományokban

~~~~exercism/advanced
A Crystal lehetővé teszi, hogy egyéni objektumokat használj tartományokban.
Ennek feltétele, hogy az objektum megvalósítsa a következőket:

- tartalmazza a `Comparable` modult
- `succ` metódus
- `<=>` metódus

Ezeknek a metódusoknak köszönhetően a tartomány végig tud iterálni az objektumon, és össze tudja hasonlítani a tartományban lévő objektumokat.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
