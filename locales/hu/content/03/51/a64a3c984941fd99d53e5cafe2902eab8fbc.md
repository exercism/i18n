# Bevezetés

A tuple-okkal könnyedén csoportosíthatsz egy rögzített számú, tetszőleges típusú adatot.
A tuple-oknak tetszőleges számú elemük lehet.
Az elemeket destrukturálással érheted el.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}

fn main() {
    let (x, y, z) = (500, 6, true);

    if y == 6 {
        println!("y is 6!");
    }
}
