# Bevezetés

## Alapok

A [Lua](https://lua.org) egy egyszerű, mégis nagy erejű, hatékony, könnyűsúlyú és beágyazható szkriptnyelv. 1993 óta a brazíliai [PUC-RIO](https://www.puc-rio.br/) egyetemen tervezi, valósítja meg és tartja karban Roberto Ierusalimschy, Waldemar Celes és Luiz Henrique de Figueiredo csapata.

### Megjegyzések

A Lua-ban az egysoros megjegyzések `--`-tal kezdődnek, a többsoros megjegyzések pedig `--[[`-tal kezdődnek és `]]`-vel végződnek.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### Változók

A Lua-ban háromféle változó létezik: globális változók, lokális változók és táblamezők. Az egyszerűség kedvéért itt csak a lokális változókról lesz szó. Alapértelmezés szerint minden változó globális, ezért a lokális változókat a `local` kulcsszóval kell lokálisként deklarálni.
```lua
local x
```

Egy változóhoz a `=` operátor segítségével rendelhetsz értéket.
```lua
local x = 1
```

Egy `local` változó scope-ja arra a blokkra korlátozódik, ahol deklarálták. Egy blokk lehet egy vezérlési szerkezet törzse, egy függvény törzse, vagy egy fájl, illetve string, amelyben a változót deklarálták.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### Függvények

Egy függvényt a `function` kulcsszóval deklarálsz, és a változókhoz hasonlóan alapértelmezés szerint globális. Egy függvénydefiníciónak van neve, paraméterlistája és törzse. A függvény akkor lép ki, amikor eléri a `return` kulcsszót, és visszaadja az utána felsorolt összes értéket. Ha nincs megadott `return`, a függvény `nil`-t ad vissza.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### Táblák

A táblák az egyetlen adatszerkezeti mechanizmus a Luában, és nagyon erőteljesek. Tömbök, halmazok, objektumok, modulok és még sok minden más ábrázolására használják őket. A Lua-ban egy tábla lényegében egy asszociatív tömb.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

Ez csak egy apró betekintés, amire a következő részhez szükség van. Erre a témára később részletesen visszatérünk.

### Modulok

Egy modul olyan kódgyűjtemény, amelyet egy `.lua` forrásfájlban tárolunk. Minden, amit a modul exportál, egy táblában van, és ezt a táblát a fájl végén adja vissza. A tábla tehát lényegében egyfajta névtérként működik.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

Ezt a modult aztán egy másik fájlba töltheted be a `require` függvénnyel, amely visszaadja a táblát.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

Amikor `say.hello`-t látunk, azt gondoljuk: „a `hello` függvény a `say` modulból”. De ha tudjuk, hogy a `say-hello.lua` egy táblát ad vissza, és visszalapozunk a táblákról szóló részhez, rájövünk, hogy Lua-ban ez a kifejezés azt jelenti: „a `say` tábla indexelése a `hello` string kulcsként való használatával”.

Bár egy modul esetében jó gyakorlat, hogy táblát adjon vissza, bármilyen más típust is visszaadhat, például egy függvényt.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
