# Utasítások

Ellen egy játékot készít, amelyben a játékosnak űrlényekkel kell harcolnia.
Épp most tanult az objektumorientált programozásról (OOP), és alig várja, hogy kihasználja, mit nyújthat a programjának az `classes` használata.

Ellen örömére felajánlottad a segítségedet, és ő rád bízta, hogy megprogramozd azokat az űrlényeket, amelyekkel a játékosnak meg kell küzdenie.


## 1. Az `Alien` osztály létrehozása

Definiáld az `Alien` osztályt egy konstruktorral, amely két `int` paramétert fogad, `x`-et és `y`-t, és ezeket az `x_coordinate`, illetve `y_coordinate` tagváltozókba teszi.
Minden űrlény `3` egészségszinttel is indul, ezért a `health` tagváltozót is inicializálni kell.

A `health` legyen privát tagváltozó.
Hogy a program más részei is olvashassák az egészségre vonatkozó információt, Ellen szeretne egy `public` `get_health()` metódust, amely egy `int`-et ad vissza.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

Mostantól minden űrlénynek képesnek kell lennie arra, hogy belsőleg nyomon kövesse a saját pozícióját és egészségét.

## 2. A `hit` függvény

Ellen szeretné, hogy az `Alien` `class` rendelkezzen egy `hit` metódussal, amely meghívásakor `1`-gyel csökkenti egy űrlény objektum egészségét.
Így egyszerűen meghívhatja a `some_alien_instance.hit()` metódust ahelyett, hogy kézzel kellene módosítania egy űrlény egészségét.
Ügyelj arra, hogy az egészségpontok ne csökkenjenek nulla alá.
A függvény `true` értékkel térjen vissza.
Ellen később pajzsokat szeretne bevezetni, amelyek akkor `false` értéket jelentenének, ha a pajzs fel van kapcsolva.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. Az `is_alive` függvény

Rájössz, hogy ha az egészség folyamatosan csökken, az valamikor valószínűleg eléri a `0`-t.
Jó ötlet lenne hozzáadni egy `is_alive` metódust, amelyet Ellen gyorsan meghívhat, hogy ellenőrizze, vajon az űrlény... nos... életben van-e. 😉
A `some_alien_instance.is_alive()` egy Boolean értéket adjon vissza.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. A `teleport` függvény

Ellen játékában az űrlények teleportálni tudnak!
Írnod kell egy `teleport` metódust, amely `x_new` és `y_new` értékeket vesz át, és ennek megfelelően módosítja az űrlény koordinátáit.
Egyelőre a függvény `true` értékkel térjen vissza.
Ellen későbbi szinteken teleportálást blokkoló bombákat szeretne hozzáadni, amelyek sikertelen teleportálási kísérletek esetén `false` értéket jelentenének.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. A `collision_detection` függvény

Ha az űrlényeket érheti valami találat, akkor képesnek kell lenniük érzékelni, mikor következhet be ilyen ütközés.
Ellennek tudnia kell, hogy két űrlény ugyanazokat a koordinátákat foglalja-e el.
A `collision_detection()` függvény egy másik űrlény objektumot vesz át argumentumként, és egy `bool` értéket ad vissza.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
