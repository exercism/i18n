# A representer normalizálásai

Az [F# representer][representer] a következő normalizálásokat végzi el:

## Megjegyzések eltávolítása

Minden megjegyzést eltávolít.

### Előtte

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### Utána

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## Importdeklarációk eltávolítása

Minden importdeklarációt eltávolít.

### Előtte

```fsharp
module Fake

open System
open System.IO

let message = "Hi"
```

### Utána

```fsharp
module Fake

let message = "Hi"
```

## A kód formázása

A kód formázásához a representer a [fantomas könyvtárat][fantomas] használja.
Ez az F# stílusútmutató szerint formázza a kódot.
A fantomas által végrehajtott átalakítások teljes listája [itt][fantomas-formatting] található.

### Előtte

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### Utána

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## Az azonosítók normalizálása

Az azonosítók egy helyőrző értékre normalizálódnak.

### Előtte

```fsharp
module Fake

let foo x = x + 1
```

### Utána

```fsharp
module PLACEHOLDER_1

let PLACEHOLDER_3 PLACEHOLDER_2 = PLACEHOLDER_2 + 1
```
