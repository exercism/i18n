# Bevezetés

A `Vectors` fogalomban láttuk, hogy egy vektor feltételes kifejezésben is használható, és logikai vektort ad eredményül.
Ez pedig olyan függvényekben használható, mint az `all()` és az `any()`.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

Ez a technika ennél sokkal többre képes.

## Vektorok részhalmazai

Egy vektor kiválasztott elemeit indexszámmal vagy indexvektorral nyerheted ki:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

Alternatívaként használhatsz logikai vektort az eredeti vektor szűrésére, ami visszaadja azon elemek részhalmazát, amelyek egy `TRUE` értékhez tartoznak:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

Innen már csak egy kis lépés, hogy a Boolean vektort feltételes kifejezéssel állítsd elő:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## Indexek keresése

A `which()` függvény egy Boolean argumentumot vesz át, és olyan indexek vektorát adja vissza, amelyek `TRUE` értéket adnak.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## Egy elem létezésének ellenőrzése

A korábbi részek arról szóltak, hogyan találhatunk meg bizonyos feltételnek megfelelő elemeket.

Ha csupán azt szeretnéd tudni, hogy a vektor tartalmaz-e egy adott elemet, a `%in%` operátort használhatod.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

Ez funkcionálisan egyenértékű a következő kóddal, de sokkal kényelmesebb:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
