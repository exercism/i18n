# Bevezetés

Az F#-ban, amikor egy értéket egy névhez rendelünk, azt _kötésnek_ nevezzük. A kötések nem módosíthatók, ami miatt hasonlítanak más nyelvek konstansaihoz. Mivel az F# statikusan típusos nyelv, minden kötésnek már fordítási időben van típusa.

A kötéseket a `let` kulcsszóval hozzuk létre. A kötés típusának megadása a legtöbb kötésnél nem kötelező, mivel az F# _típuskövetkeztetése_ az érték alapján általában kikövetkezteti a típust. Egy kötés így néz ki:

```fsharp
// Automatically inferred type
let fingers = 10
```

A függvények is közönséges kötések, csak egy vagy több paraméterrel. A függvény automatikusan visszaadja az utolsó kifejezését. A típuskövetkeztetés a legtöbb függvénynél is működik: elemzi, hogy milyen értékekkel hívjuk meg a függvényt, és milyen értéket ad vissza.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

A függvényt úgy hívjuk meg, hogy leírjuk a nevét, majd a függvény minden paraméteréhez átadunk egy-egy argumentumot.

```fsharp
let five = add 2 3
```

Ha egy kötés típusát nem lehet kikövetkeztetni, a fordító hibát jelez. Ez orvosolható, ha explicit típusmegjelölést adunk a kötéshez.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Az F#-ban egy kötést csak _azután_ használhatunk, hogy definiáltuk. Ha egy kötést a definiálása előtt használunk, fordítási hiba lesz belőle.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

Az F# a scope meghatározásához a jelentéssel bíró szóközöket használja. Ez azt jelenti, hogy a scope-ot a kód szóközökkel történő behúzása határozza meg, a kötést deklaráló sorhoz képest. Az alapértelmezett konvenció a négy szóközös behúzás:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Az F# kötéseit (köztük a függvényeket) általában modulokba szervezzük. A modul az összetartozó funkciókat csoportosítja, és a `module` kulcsszóval hozzuk létre. A modul definíciójának meg kell előznie a kötéseit:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

Az F# kétféle megjegyzést támogat. Az egysoros megjegyzéseket `//` előzi meg, a többsoros megjegyzéseket pedig `(*` és `*)` közé írjuk.
