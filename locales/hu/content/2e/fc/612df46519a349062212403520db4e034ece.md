# Bevezetés

## Magyarázat

A `number` és `string` primitív adattípusok mellett létezik egy másik fontos adattípus is a JavaScriptben, ez pedig az `object`.
Az objektumok kulcs-érték párokból állnak.
Ezért arra is használhatók, amit más nyelvekben gyakran mapnek vagy szótárnak neveznek.

Más nyelvekben egy map összes értékének gyakran ugyanolyan adattípusúnak kell lennie.
A JavaScriptben csak a kulcs típusa kötött: annak stringnek kell lennie.
Egy objektumon belül az értékek különböző típusúak lehetnek.
Lehetnek primitív típusok, például számok, de tömbök, más objektumok vagy akár függvények is.
Ez rendkívül sokoldalúvá teszi az objektumokat, ezért kulcsfontosságú elemei a JavaScript [objektumorientált programozásának][oop] (OOP) is.

A következőkben az objektumokra mint gyűjteményekre vagy mapekre összpontosítunk. Az objektumok egyéb felhasználási eseteit más fogalmak tárgyalják, lásd például az [Osztályok][concept-classes] című részt.

## Objektum létrehozása

Egy objektumot kapcsos zárójelekkel hozol létre.
Rögtön meg is adhatsz benne néhány bejegyzést.
Ehhez először a kulcsot add meg, majd egy kettőspontot és az értéket.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

Az utolsó bejegyzés utáni vessző a JavaScriptben elhagyható.

Felmerülhet benned a kérdés, hogy miért nincsenek a kulcsok idézőjelbe téve, pedig stringekről van szó.
Ez egy rövidített írásmód.
Ha a kulcs megfelel a JavaScript [azonosítóira][mdn-identifier] vonatkozó elnevezési szabályoknak, elhagyhatod az idézőjeleket.
Ha a kulcs nevében speciális karakterek vannak, a szokásos stringes írásmódot kell használnod.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Érték lekérése

Egy adott kulcs értékét kétféleképpen kérheted le: pontjelöléssel és zárójeles jelöléssel.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

A pontjelölés rövidítésként ugyanolyan megkötést jelent, mint az idézőjelek elhagyása.
Csak akkor működik, ha a kulcs megfelel az azonosítók elnevezési szabályainak.
Más szóval, ha a kulcsod nem egyetlen, csak betűkből álló szó, akkor a szögletes zárójeles jelölést kell használnod.

## Érték hozzáadása vagy módosítása

Egy értéket az `=` értékadó operátorral adhatsz hozzá vagy módosíthatsz.
Itt is a pont- és a zárójeles jelölés áll rendelkezésedre.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Bejegyzés törlése

Egy kulcs-érték párt a `delete` kulcsszóval törölhetsz egy objektumból.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Egy kulcs létezésének ellenőrzése

Egy objektumban a `hasOwnProperty` metódussal ellenőrizheted, hogy létezik-e egy adott kulcs.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Bejárás egy objektumon

Van egy speciális `for...in` ciklus, amellyel egy objektum összes kulcsán végigmehetsz.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

A nehezen észrevehető hibák elkerülése érdekében mindig abból indulj ki, hogy a `for...in` ciklus tetszőleges sorrendben járja be a kulcsokat.
Azt is tartsd szem előtt, hogy a `for...in` az [örökölt kulcsokat][concept-inheritance] is bevonja az iterációba.
