# Utasítások

Ebben a feladatban olyan kódot fogsz írni, amely nyomon követi azon programozási nyelvek listáját, amelyeket meg szeretnél tanulni az Exercism-ön.

Hat részfeladat vár rád, és mindegyikben listákkal fogsz foglalkozni.

## 1. Hozz létre egy új listát

Ahhoz, hogy nyomon követhesd azokat a nyelveket, amelyeket meg szeretnél tanulni, létre kell hoznod egy új listát. Definiáld a `new_list` függvényt, amely egy új, üres listát ad vissza.

```gleam
new_list()
// -> []
```

## 2. Definiálj egy létező listát

Jelenleg van egy papírlapod, amelyen felsorolva vannak a nyelvek, amelyeket meg szeretnél tanulni: Gleam, Go és TypeScript. Definiáld az `existing_list` függvényt, hogy ezt a listát adja vissza.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. Adj hozzá egy új nyelvet egy listához

Ahogy felfedezded az Exercism-öt, és egyre érdekesebb nyelveket találsz, szeretnéd felvenni őket a listádra. Valósítsd meg az `add_language` függvényt, amely egy új nyelvet szúr be a listád elejére.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. Számold meg a listában szereplő nyelveket

Egyesével megszámolni a nyelveket kényelmetlen. Valósítsd meg a `count_languages` függvényt, amely megszámolja a listádon lévő nyelveket.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. Fordítsd meg a listát

Egy ponton rájössz, hogy a listád valójában fordított sorrendben van! Valósítsd meg a `reverse_list` függvényt, amely megfordítja a listádat.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. Ellenőrizd, hogy izgalmas-e a lista

Bár minden nyelvet szeretsz, a Gleam különleges helyet foglal el a szívedben. Ezért igazán izgalmas számodra egy nyelvek listája, ha:

- A lista első eleme a Gleam.
- A lista második eleme a Gleam, és a listán két vagy három nyelv szerepel.

Valósítsd meg az `exciting_list` függvényt, amely ellenőrzi, hogy izgalmas-e egy nyelvlista:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
