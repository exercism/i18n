# Kiegészítés az utasításokhoz

## Tippek

Meg kell valósítanod a `decode` és `encode` függvényeket, amelyek Atbash-rejtjel segítségével dekódolnak, illetve kódolnak egy `String`-et.
Használhatod a megadott szignatúrát, ha nem vagy biztos a típusokban, de ne hagyd, hogy ez korlátozza a kreativitásodat.

Ez a feladat szöveges adatokkal dolgozik. Történelmi okokból a Haskell `String` típusa megegyezik a `[Char]` típussal, ami karakterek listája. A szöveges adatok hatékonyabb kezeléséhez használhatod a `Text` típust.

A feladat opcionális kiterjesztéseként a következőket teheted:

- olvass a [string típusokról](https://haskell-lang.org/tutorial/string-types) a Haskell nyelvben.
- vedd fel a `- text`-et a package.yaml fájlban lévő függőségeid listájára.
- importáld a `Data.Text` modult [a következőképpen](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- használd a `Text` típust, például `decode :: Text -> Text`, és hivatkozz a `Data.Text` kombinatoraira például a `T.pack` formában.
- nézd meg a [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) dokumentációját.
- cseréld le a `String` összes előfordulását `Text`-re az Atbash.hs fájlban, azaz:

```haskell
decode :: Text -> Text
decode cipherText = ...

encode :: Text -> Text
encode plainText = ...
```

Ez a rész teljesen opcionális.
