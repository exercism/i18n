# Névjegy

A Rustban az iterátor minden olyan érték, amely megvalósítja az [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) traitet.
Az iterátor értékeit manuálisan is továbbléptethetjük, ha meghívjuk rajta a `next` metódust.

```rust
trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
    // many built-in methods implemented
}
```

A Rust [`collections`](https://doc.rust-lang.org/std/collections/index.html) típusai közül sok megvalósítja az
[`IntoIterator`](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html)-t,
amely a kollekció értékeiből egy `Iterator`-t képes előállítani.

```rust
trait IntoIterator where Self::IntoIter: Iterator<Item=Self::Item> {
    type Item;
    type IntoIter: Iterator;
    fn into_iter(self) -> Self::IntoIter;
}
```

Vedd észre, hogy bár az `IntoIterator::into_iter` elfogyasztja a `self` típusát, annak a típusnak nem kell feltétlenül tulajdonolt értéknek lennie.
Ezért léteznek `IntoIterator` implementációk a [`Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-2),
a [`&'a Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator)
és a [`&'a mut Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-1) számára.
A tulajdonlás különböző fokaira vonatkozó implementációk hasznos rugalmasságot adnak.

Ehhez a fogalomhoz nem szükséges értened a `traits`-hoz, és lesz egy egész feladat, amelyben elsajátíthatod a `traits`-t.
Egyelőre csak ezeket jegyezd meg:

- Minden típust, amely megvalósítja az `IntoIterator`-t, _iterálhatónak_ nevezünk, mert iterátorrá alakítható.
- Minden típus, amely megvalósítja az `Iterator`-t, iterátor: értékeket _állít elő_, és _iterálhatunk rajta_.
- Bármely `IntoIterator`-t megvalósító típusból kaphatsz iterátort, ha meghívod az `into_iter` metódusát.
- Minden iterátor [megvalósítja az `IntoIterator`-t](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html#impl-IntoIterator-25), és önmagát állítja elő.
- A `for` ciklusok mindig iterátorokon működnek, és implicit módon meghívják az `IntoIterator`-t a tartomány argumentumukon.

## Az `into_iter` és a for ciklusok

Valószínűleg ismered a vektorokon végigfutó for ciklusokat:

```rust
// lor is a `Vec`, which implements `IntoIterator`
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
for people in &lor {
    println!("{people}");
}
```

Alapvetően a `for` ciklus nem más, mint rövidítés arra, hogy meghívjuk az argumentuma `into_iter` metódusát,
majd addig hívjuk a `next()`-et, amíg az már nem állít elő több elemet. Más szóval az előző ciklus így bomlik ki:

```rust
{
    let mut iterator = (&lor).into_iter();
    while let Some(people) = iterator.next() {
        println!("{people}");
    }
}
```

## Az `iter` és az `iter_mut` metódus

A legtöbb Rust kollekciótípus biztosít `iter` és `iter_mut` metódust.
Egy `T` típusú kollekció esetén ez a két metódus a konvenció szerint a következőt teszi:

- Az `iter` által visszaadott iterátor megváltoztathatatlanul kölcsönzött `&T` értékeket ad.
- Az `iter_mut` által visszaadott iterátor megváltoztathatóan kölcsönzött `&mut T` értékeket ad.

```rust
let mut v = vec![1, 2, 3];

// Using `iter` method
let mut iterator = v.iter();
assert_eq!(iterator.next(), Some(&1));
assert_eq!(iterator.next(), Some(&2));
assert_eq!(iterator.next(), Some(&3));
assert_eq!(iterator.next(), None);

// Using `iter_mut` method
for value in v.iter_mut() {
     *value *= *value;
}
println!("{v:?}");
// => [1, 4, 9]
```

## A különbség az `iter`, az `iter_mut` és az `into_iter` között

Ha az `iter`, az `iter_mut` és az `into_iter` mind iterátorokat állít elő, mi a különbség köztük?

- Az `iter` által visszaadott iterátor a konvenció szerint megváltoztathatatlanul kölcsönzött `&T` értékeket ad.
- Az `iter_mut` által visszaadott iterátor a konvenció szerint megváltoztathatóan kölcsönzött `&mut T` értékeket ad.
- Az `into_iter` által visszaadott iterátor a kontextusától függően `T`, `&T` vagy `&mut T` értéket adhat.

Mi az `into_iter` hívásának a kontextusa?
A `self` típusa.
Emlékezz rá, hogy léteznek `IntoIterator` implementációk a `Vec`, a `&'a Vec` és a `&'a mut Vec` számára.
Ezért:

- `(&v).into_iter()` ugyanaz, mint a `v.iter()` => `&T`-t ad vissza
- `(&mut v).into_iter()` ugyanaz, mint a `v.iter_mut()` => `&mut T`-t ad vissza
- `v.into_iter()` => `T`-t ad vissza, és áthelyezi az értékeket

Ez a for ciklusokban a legvilágosabb:

- `for num in &v {...}` => `&T`-t köt
- `for num in &mut v {...}` => `&mut T`-t köt
- `for num in v {...}` => `T`-t köt, és áthelyezi az értékeket

Gyakran világosabb `v.iter()`-t írni a `(&v).into_iter()` helyett.
Ezért ergonómiai okokból érdemes előnyben részesíteni az `iter` és az `iter_mut` metódust az `into_iter`-rel szemben.

## Az iterátorok beépített metódusainak használata

Az iterátorok számos beépített metódust kínálnak, például a `map`, a `filter` és a `collect` metódust.
Ezeket a metódusokat néha closure-ökkel együtt használjuk.

A `map` egy closure segítségével alakítja át az iterátor értékeit.
A `take` egy (esetleg végtelen) iterátort olyanná csonkít, amely legfeljebb a megadott számú elem után ér véget.

```rust
for even_number in (0..).into_iter().map(|x| x * 2).take(4) {
    let odd_number = even_number + 1;
    println!("{even_number} => {odd_number}");
}
// 0 => 1
// 2 => 3
// 4 => 5
// 6 => 7
```

A `filter` olyan iterátorrá alakítja át az iterátort, amely csak azokat az értékeket adja vissza, amelyekre a closure `true`-ra értékelődik ki.
A `count` elfogyasztja az iterátort, és visszaadja az előállított elemek számát.

```rust
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
let short_people = ["Dwarves", "Hobbits"];
let num_tall_people = lor.iter().filter(|people| !short_people.contains(people)).count();
assert_eq!(num_tall_people, 5);
```

A `flat_map` úgy alakít át egy iterátort, hogy a megadott closure segítségével minden elemet új iterátorrá alakít,
majd az így keletkezett új iterátorokat egymáshoz fűzve kilapítja.
A `collect` új kollekciót hoz létre,
amennyiben a kollekció típusa megvalósítja a [`FromIterator`](https://doc.rust-lang.org/std/iter/trait.FromIterator.html)-t.

```rust
let words = ["alpha", "beta", "gamma"];
// chars() returns an iterator
let merged: String = words.iter()
                          .flat_map(|s| s.chars())
                          .collect();
assert_eq!(merged, "alphabetagamma");
```

Az [`Iterator` trait](https://doc.rust-lang.org/std/iter/trait.Iterator.html) _sok_ ilyen hasznos iterátor-átalakítást kínál;
érdemes elolvasnod a dokumentációját, és megismerkedned velük.

## Lustaság

Fontos tudni, hogy a Rust iterátorai lusták:
nem állítanak elő értéket, amíg el nem fogyasztjuk az iterátort.
Ha megírod és lefuttatod a következő kódot:

```rust
(0..5).map(|x| x * x);
```

a következő fordítóhibát kapod:

```rust
 --> src/main.rs:2:5
  |
2 |     (0..5).map(|x| x * x);
  |     ^^^^^^^^^^^^^^^^^^^^^^
  |
  = note: `#[warn(unused_must_use)]` on by default
  = note: iterators are lazy and do nothing unless consumed
```

Ez azért van, mert a `map` egy adapter metódus, amely egy újabb iterátort ad vissza.

Egy iterátor elfogyasztásához vagy használj `for` ciklust, vagy olyan iterátormetódust, amely olyan értéket állít elő, amely maga nem iterátor.

Például a `collect` egy fogyasztó metódus (a szignatúrája nem iterátort, hanem egy generikus típust ad vissza):

```rust
//         Iterator   Adaptor        Consumer
//                |      |               |
let v: Vec<_> = (0..5).map(|x| x * x).collect();
```
