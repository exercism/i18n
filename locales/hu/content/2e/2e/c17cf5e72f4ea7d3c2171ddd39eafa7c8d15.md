# Bevezetés

A mintaillesztés meghatározó szerepet játszik a magabiztos, idiomatikus Elixir-kódban. Talán emlékszel rá, hogy a `=/2` operátort nem értékadó, hanem illesztő operátorként szokás leírni. Amikor az illesztő operátort használod, és a bal oldali minta illeszkedik a jobb oldalra, a bal oldali változók értéket kapnak, a kifejezés pedig a jobb oldal értékét adja vissza. Ha nincs illeszkedés, `MatchError` keletkezik.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

Ne feledd: az illesztés mindig jobbról balra történik.

Az utolsó példában, ha egy mintaillesztésben nincs szükség a változóra, elvethetjük úgy, hogy `_`-t használunk. Az `_`-val kezdődő változókat a futtatókörnyezet nem követi nyomon.

## Mintaillesztés nevesített függvényekben

A mintaillesztés több függvényklóz létrehozásakor is hasznos eszköz. A mintaillesztést a függvények argumentumain is használhatjuk, ez dönti el, hogy melyik függvényklóz hívódik meg: a fájl tetejétől indulunk, és lefelé haladva az első illeszkedésig. A változók a függvényfejben kaphatnak értéket, és a függvénytörzsben használhatók fel.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
