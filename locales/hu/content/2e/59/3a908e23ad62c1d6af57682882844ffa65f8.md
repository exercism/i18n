# Bevezetés

Bár a `readonly` módosító megakadályozza, hogy egy mező értéke vagy referenciája felülíródjon, a referenciatípus tagjait már nem védi.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Ahhoz, hogy egy referenciatípus minden tagja védve legyen, a mezőket `readonly` módosítóval láthatjuk el, az automatikus tulajdonságokat pedig `set` hozzáférő nélkül definiálhatjuk.

A Base Class Library (BCL) biztosít néhány csak olvasható gyűjteményváltozatot, ha meg kell akadályozni, hogy egy gyűjtemény tagjai frissüljenek. Ezek burkolók formájában érhetők el:

- A `ReadOnlyDictionary<T>` egy `Dictionary<T>`-t tesz csak olvashatóvá.
- A `ReadOnlyCollection<T>` egy `List<T>`-t tesz csak olvashatóvá.
