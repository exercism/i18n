# String

A `String` adattípus karakterek lineáris sorozata, amelyek UTF-8-ként vannak kódolva. Szöveges adatok tárolására kiválóan alkalmas.

## String létrehozása

Egy string létrehozható a `String::new()` vagy a `String::from()` társított függvénnyel. Sok típusnak van `to_string` metódusa, amellyel stringet készíthetsz, például egy számból.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### A `format!` makró

Mivel gyakori művelet, hogy kisebb adattípusokból egy nagy stringet állítunk elő, a Rustnak van egy rövidítése is, amely elrejti a `to_string` meghívásának részleteit: a `format!` makró. A fenti összetett string létrehozását például így egyszerűsíthetjük:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## String szeletek

A stringek szoros kapcsolatban állnak a string szeletekkel. A string szelet egy ismert méretű memóriaterületre mutató, megváltoztathatatlan referencia, amely UTF-8-ként kódolt karakterek lineáris sorozatát tartalmazza. Bármely stringet string szeletté alakíthatsz úgy, hogy a dereferencia (`&`) operátorral kölcsönzöd. Ha egy string szeletet stringgé szeretnél alakítani, a `to_string()` metódus és a `String::from` is megfelelő.

A Rust kódban a literál stringet kettős idézőjelek közé zárjuk. Ezek a string literálok mindig string szeletek, mert a program futtatható fájlján belüli, megváltoztathatatlan memóriaterületre hivatkoznak.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## String módosítása

Ha egyetlen karaktert szeretnél a stringhez fűzni, használd a `push` metódust. Ha egy string szeletet fűznél a stringhez, a `push_str` metódus vagy a `+` operátor a megfelelő.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## Karakterek elérése egy stringben

Mivel a Rust stringjei UTF-8-ként vannak kódolva, az egyes karakterek nem mind ugyanakkorák. Ezért a `String` adattípus nem biztosít indexelő operátort (`[]`). Ha egy string összes karakterét vagy egy adott karakterét szeretnéd elérni, a `chars()` metódust használhatod. Ez sorban végigmegy a string minden karakterén.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```
