# Tippek

## Általános

- Használd a beépített [(hivatkozott) listatípust][list].

## 1. Definiálj egy függvényt, amely egy üres nyelvlistát ad vissza

- A függvénynek `[]`-t kell visszaadnia.

## 2. Definiálj egy függvényt, amely hozzáad egy nyelvet a listához

- Egy elemet a `|` operátorral fűzhetsz a lista elejére.

## 3. Definiálj egy függvényt, amely eltávolít egy nyelvet a listából

- Az Elixir [biztosít egy függvényt][tl], amely az első elem nélküli listát adja vissza.

## 4. Definiálj egy függvényt, amely a lista első elemét adja vissza

- Az Elixir [biztosít egy függvényt][hd] a lista első elemének lekéréséhez.

## 5. Definiálj egy függvényt, amely visszaadja, hány nyelv van a listában

- Az Elixir [biztosít egy függvényt][length], amellyel megszámolhatod egy lista hosszát.

## 6. Definiálj egy függvényt, amely megállapítja, hogy a lista tartalmaz-e funkcionális nyelvet

- A függvényednek egy Boolean értéket kell visszaadnia, amely megmutatja, hogy az `"Elixir"` tagja-e a listának. Az Elixir [biztosít egy függvényt][in] a listabeli tagság vizsgálatára.

[list]: https://hexdocs.pm/elixir/lists-and-tuples.html#linked-lists
[hd]: https://hexdocs.pm/elixir/Kernel.html#hd/1
[tl]: https://hexdocs.pm/elixir/Kernel.html#tl/1
[length]: https://hexdocs.pm/elixir/Kernel.html#length/1
[in]: https://hexdocs.pm/elixir/Kernel.html#in/2
