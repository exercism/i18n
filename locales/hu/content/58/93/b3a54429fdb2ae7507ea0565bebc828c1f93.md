# Az őrökről

Az [őrök][guards] a [mintaillesztés][exercism-pattern-matching] kiegészítéseként használhatók. Ezt egy későbbi fogalomban tárgyaljuk. Az őrök lehetővé teszik, hogy egy függvénynek a bemeneti értéktől függően több különböző implementációja legyen. Összetettebb ellenőrzéseket tesznek lehetővé.

Az őr utasítást egy `|` (függőleges vonal) jel, majd egy logikai kifejezés, végül egy `=` (egyenlőségjel) jel és a függvény törzse alkotja. Egyetlen függvényhez több őr utasítás is tartozhat. Az őr utasítások kiértékelése fentről lefelé történik, és az első, amelyik `True` értéket adja, végrehajtódik. Egy őr utasításban használható egy `otherwise` utasítás is, amely gyűjtőként szolgál minden olyan értékre, amely nem illeszkedik a korábbi őr utasításokhoz.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

A függvényünket is definiálhatjuk, és felhasználhatjuk az őr utasításban.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
