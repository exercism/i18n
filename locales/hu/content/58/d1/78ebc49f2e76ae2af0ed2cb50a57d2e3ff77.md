# Bevezetés

A *diszjunkt halmaz* (egy union-find adatszerkezet) értékek egy gyűjteményét
tartja egymást nem átfedő csoportokra osztva, és gyorsan válaszol egy
kérdésre: ugyanabban a csoportban van ez a két érték? A
[`disjoint-sets`][disjoint-sets] szókészletben található.

## Diszjunkt halmaz felépítése

A `<disjoint-set>` egy üres szerkezetet hoz létre. Az értékeket, az
*atomokat*, vagy egyesével adod hozzá az `add-atom` szóval, vagy egy
sorozatból az `add-atoms` szóval. Minden atom egyedül, a saját csoportjában
indul.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

A diszjunkt halmaz *módosítható*: az `add-atom`, az `add-atoms` és az
`equate` helyben módosítja, ahelyett hogy egy újat adna vissza. A `keep`
akkor hasznos, ha vissza szeretnéd kapni a diszjunkt halmazt a veremre,
miután valamelyik ilyen szó elfogyasztotta.

## Csoportok egyesítése

Az `equate` egyesíti azt a két csoportot, amelyben a két atomja
található. Az egyesítés tranzitív: egyesíts két atomot, majd az egyiket egy
harmadikkal, és mindhárom ugyanabba a csoportba kerül.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Reprezentánsok

Minden csoportnak egyetlen kanonikus tagja van, a *reprezentánsa*.
A `representative` ezt adja vissza, és két atom pontosan akkor tartozik
ugyanahhoz a csoporthoz, ha a reprezentánsaik megegyeznek.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

Az, hogy egy csoport melyik atomot választja reprezentánsnak, belső
részlet. Soha ne arra számíts, hogy egy adott atomot választ, hanem csak
arra, hogy két, ugyanabba a csoportba tartozó atom reprezentánsa
megegyezik.
