## Használat

A widgetek bárhol használhatók, ahol a Markdown is, például dokumentációkban, megközelítésekben és tanulók és mentorok közötti beszélgetésekben.

A megjelenítésük a következő formátumban történik:

```md
[<type>:<id>]()
```

A `<type>` és `<id>` részek változóak, és attól függnek, hogy éppen melyik widgetet használod.

A hivatkozási célpontot, vagyis a `()` tartalmát az oldal figyelmen kívül hagyja. Karbantartási célból bármire mutathatnak.

## Feladatwidget

A hivatkozás formátuma: `[exercise:<track-slug>/<exercise-slug>]()`

### Példa

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## Fogalomwidget

A hivatkozás formátuma: `[concept:<track-slug>/<concept-slug>]()`

### Példa

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## Megközelítéswidget

A hivatkozás formátuma: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### Példa

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## Cikkwidget

A hivatkozás formátuma: `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### Példa

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
