# Bevezetés

Általában véve nem érdemes újra feltalálni a kereket a programozásban.
Sok szabványos algoritmus esetében lehet, hogy valaki már elvégezte helyetted a munkát.

## Include-ok

Ha más fájlok tartalmát szeretnéd beilleszteni, a C++ az `include` direktívát használja.
Ezeket az include-okat a fájl tetején kell megadni.
Fordításkor a direktívát tartalmazó sor helyére a megfelelő fájl tartalma kerül.
Az include-ok után a névterek ugyanúgy maradnak, ahogy az eredeti fájlban voltak.

## A szabványos könyvtár

A szabványos könyvtár rengeteg gyakori függvényt, algoritmust és adatstruktúrát kínál.
A szabványos könyvtár a `std` névteret használja.

Egy példa erre a C numerikus könyvtára, a `cmath`.
Ez számos gyakori matematikai műveletet biztosít.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
A szabványos könyvtárakat csúcsos zárójellel `<>` illesztjük be a kettős idézőjel `"` helyett.
A különbség az, hogy a fordító hol keresi a megfelelő fájlokat.
A csúcsos zárójeles változatnál kimarad a keresés az aktuális projektben, és a fordító egyből a rendszer include-könyvtáraiban kezd.
Ha helyi fájlokat szeretnél beilleszteni, kettős idézőjelet használsz: `#include "myfile"`
~~~~
