# váratlan kötelező paraméter

A(z) \`${'parameter.name'}\` paramétert a tesztekben hol értékkel, hol anélkül adják át, de _nincs opcionálisként megjelölve_, ami azt jelenti, hogy a tesztek nem lesznek sikeresek. A TypeScript-paramétert a `?` utótaggal is megjelölheted opcionálisként:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

Vagy megjelölheted úgy is, hogy alapértelmezett értéket adsz neki:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
