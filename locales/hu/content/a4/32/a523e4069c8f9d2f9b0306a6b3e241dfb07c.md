# Névjegy

## Típusaliasok

A Gleamben a típusalias segítségével kényelmes nevet adhatsz egy létező típusnak, amelyet egyébként körülményes lenne leírni.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Ha a `pub type` szintaxissal írod le, az alias azon a modulon kívül is használható, amelyben definiáltad. Ha elhagyod a `pub`-ot, az alias privát lesz, és más modulokból nem hivatkozhatsz rá.
