# Részletek

A [metódus-túlterhelés][method-overloading] kulcsfontosságú fogalom a Java-ban: lehetővé teszi, hogy egy osztályban több azonos nevű metódus is legyen, amíg mindegyikük paraméterlistája eltér.
Ez a lehetőség a Java objektumorientált programozásának egyik alapvető eleme, és módot ad arra, hogy hasonló műveleteket különböző típusú vagy számú bemenettel hajtsunk végre.
A metódus-túlterhelés javítja a kód olvashatóságát és szervezettségét, mert lehetővé teszi, hogy a hasonló funkciót betöltő metódusok ugyanazt a nevet kapják.
Fontos megjegyezni, hogy a túlterhelést a metódus szignatúrája dönti el, ami a metódus nevét és a paraméterlistát foglalja magában.

## Kulcspontok

- **A szignatúra számít**: A visszatérési típus nem része a metódus szignatúrájának, ezért ha csak egy metódus visszatérési típusát változtatod meg, az még nem jelent túlterhelést.
- **Eltérő paraméterek**: A túlterhelt metódusoknak a paraméterek számában vagy típusában kell eltérniük.
- **Használat**: A túlterhelést gyakran arra használjuk, hogy egy metódust különböző típusú bemenetekkel intuitívabb módon lehessen használni.

## Példák a metódus-túlterhelésre

Vegyünk egy `Calculator` osztályt, amely számokat tud összeadni.
A túlterhelés révén többféle összeadási műveletet is definiálhatunk:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## Bevált gyakorlatok

- **Átláthatóság**: A túlterhelt metódusokat úgy érdemes használni, hogy a kód intuitívabb legyen.
  - A túlterhelt metódusok viselkedése legyen egymáshoz kapcsolódó és következetes.
- **Kerüld a kétértelműséget**: Ügyelj arra, hogy minden túlterhelt metódusnak egyértelmű célja legyen, és hogy a paraméterlisták közötti eltérések elég jelentősek legyenek a félreértések elkerüléséhez.
- **Dokumentáció**: Megfelelően dokumentáld a túlterhelt metódusok mindegyik változatát.
  - A világos dokumentáció segít a többi fejlesztőnek megérteni az egyes metódusváltozatok célját és használatát.
- **Következetes visszatérési típusok**: Bár a túlterhelt metódusok visszatérési típusa eltérhet, általában jó gyakorlat, hogy ahol lehet, következetesek maradjanak, így elkerülve a félreértéseket.
- **A túlterhelés korlátozása**: Kerüld a metódus-túlterhelés túlzásba vitelét.
  - A túlzott túlterhelés nehezebben olvashatóvá és karbantarthatóvá teheti a kódot.

## Összegzés

A metódus-túlterhelés a Java egyik hatékony eszköze, amellyel helyesen használva jelentősen növelheted a kódod olvashatóságát és rugalmasságát.
Lehetővé teszi, hogy a metódusok sokoldalúbbak legyenek, és alkalmazkodjanak a különböző helyzetekhez, amitől a Java-programjaid modulárisabbak és könnyebben karbantarthatók lesznek.
