# Felsorolások

A felsorolások olyan Cairo-adattípusok, amelyekkel előre meghatározott variánsokat definiálhatsz a kód olvashatósága és biztonsága érdekében.
Cairo-ban az `enum` variánsai különböző adattípusokat tárolhatnak (egész számokat, struktúrákat, tuple-okat, más felsorolásokat stb.).

Az alábbi kódrészlet megmutatja, hogyan definiálhatók a felsorolások:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

A fentebb definiált `Direction` felsorolás egy egyszerű felsorolás négy variánssal: `North`, `East`, `South` és `West`.
Az elnevezési konvenció szerint a felsorolás variánsait PascalCase stílusban írjuk.
Minden variáns a `Direction` felsorolástípus egy-egy különálló értékét képviseli.
Ebben a konkrét felsoroláspéldában egyik variánsnak sincs társított értéke, és az alábbi szintaxissal példányosíthatók:

```rust
let direction = Direction::North;
```

Alább ugyanaz a `Direction` felsorolás látható, de olyan variánsokkal, amelyekhez társított érték tartozik, és ez az érték az irány pontos fokát tárolja:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

Ebből a példából jól látszik, hogy a `Direction` felsorolás minden variánsához `u128` típusú társított érték tartozik.
Ezt a fajta felsorolást így lehet példányosítani:

```rust
let direction = Direction::North(10);
```

## Összetett felsorolás példája egyedi típusokkal

A felsorolás definiálható úgy is, hogy a variánsai különböző adattípusok kombinációi.
Az alábbi példában az `Action` egy összetett felsorolás, amelynek variánsai: `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` és `ProfileState`.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## Trait-ek implementálása felsorolásokhoz

Cairo-ban a trait-ek egyedi felsorolásokon is definiálhatók és implementálhatók.
Ez lehetővé teszi, hogy a felsoroláshoz kapcsolódó metódusokat és attribútumokat definiálj.
Alább egy példa erre: definiálunk egy `Message` felsorolást, és implementálunk hozzá egy `Processing` trait-et:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

Így használhatod a trait-et egy `Quit` üzenet feldolgozására:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

Sok helyzetben hasznosak lehetnek a felsorolások, különösen akkor, ha a `match` vezérlési szerkezettel együtt használod őket, ahogy a fenti trait-implementációban is láttuk.
A `match` vezérlési szerkezetről bővebben a [The Cairo Book][match] című könyvben olvashatsz.

[match]: https://book.cairo-lang.org/ch06-02-the-match-control-flow-construct.html
