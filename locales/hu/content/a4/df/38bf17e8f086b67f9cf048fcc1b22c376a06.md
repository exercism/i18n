# Bevezetés

Az `import` speciális forma lehetővé teszi, hogy egy külső modul függvényeit a modul nevének használata nélkül használd.

Egy teljes külső modul importálása ütközéseket okozhat a meglévő helyi függvényekkel. Ennek elkerülésére két lehetőség áll rendelkezésre: `:except` és `:only`. Mindkettő egy kulcsszólistát vár, amelyben a kulcs a függvény neve, az érték pedig a függvény aritása.

Az importokat általában a moduldefiníció elején adjuk meg.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
