# Null

A null egy primitív értéktípus, amelynek mindössze egyetlen értéke van: `null`.
A nullt gyakran a semmi jelölésére használjuk.
„Hamis értékűnek” számít, de különbözik a `false`-tól és más hamis értékű értékektől.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Nullértékek kezelése

A PHP-ban a null értékek gyakori hibaforrások, mivel sokszor hibaállapot helyett vagy a semmi jelölésére adják vissza őket.
A hibák megelőzéséhez gyakran „null-ellenőrzésre” van szükség, hogy a művelet végrehajtása előtt megbizonyosodjunk róla, hogy az érték nem null.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

Az ismételt null-ellenőrzés könnyen hibához vezet, ezért a PHP két operátort kínál a null értékek kezelésére: a nullbiztos elérést biztosító `?->` operátort és a null-összevonó `??` operátort.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
