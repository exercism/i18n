# Utasítások kiegészítése

## Regiszterek

| Regiszter | Használat  | Típus      | Leírás                          |
| --------- | ---------- | ---------- | ------------------------------- |
| `$a0`     | bemenet    | cím        | első, null-terminált string     |
| `$a1`     | bemenet    | cím        | második, null-terminált string  |
| `$v0`     | kimenet    | egész szám | Hamming-távolság                |
| `$t0-9`   | ideiglenes | bármilyen  | ideiglenes tároláshoz           |
