# Utasítások kiegészítése

## Regiszterek

| Regiszter | Használat  | Típus       | Leírás                                                      |
| --------- | ---------- | ----------- | ----------------------------------------------------------- |
| `$a0`     | bemenet    | cím         | az első tömb elemei                                         |
| `$a1`     | bemenet    | egész szám  | az első tömb mérete szavakban                               |
| `$a2`     | bemenet    | cím         | a második tömb elemei                                       |
| `$a3`     | bemenet    | egész szám  | a második tömb mérete szavakban                             |
| `$v0`     | kimenet    | egész szám  | `0` = egyenlő, `1` = nem egyenlő, `2` = részlista, `3` = szuperlista |
| `$t0-9`   | ideiglenes | bármilyen   | ideiglenes tárolásra használatos                            |
