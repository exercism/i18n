# Utasítások

Ebben a feladatban naplósorok feldolgozásával fogsz foglalkozni.

Minden naplósor egy string, amelynek formátuma a következő: `"[<LEVEL>]: <MESSAGE>"`.

Három különböző naplózási szint van:

- `INFO`
- `WARNING`
- `ERROR`

Három részfeladat vár rád; mindegyik egy naplósort kap, és valamit kell vele tenned.
Sokféleképpen megoldhatod ezeket a részfeladatokat. Válaszd ki a kedvenc metódusaidat a fenti példákból, és nézd meg, mire jutsz.

## 1. Üzenet kinyerése egy naplósorból

Valósítsd meg a `LogLineParser#message` metódust, hogy visszaadja egy naplósor üzenetét:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

A kezdő és záró whitespace-t el kell távolítani:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Naplózási szint kinyerése egy naplósorból

Valósítsd meg a `LogLineParser#log_level` metódust, hogy visszaadja egy naplósor naplózási szintjét, kisbetűvel:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Naplósor újraformázása

Valósítsd meg a `LogLineParser#reformat` metódust, amely újraformázza a naplósort: az üzenet kerüljön előre, utána pedig zárójelben a naplózási szint következzen:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
