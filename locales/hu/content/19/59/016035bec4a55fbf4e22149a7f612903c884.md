# Bevezetés

A rekurzív függvények önmagukat meghívó függvények.

A rekurzív függvénynek legalább egy _alapesetre_ és legalább egy _rekurzív esetre_ van szüksége.

Az _alapeset_ egy értéket ad vissza anélkül, hogy újra meghívná a függvényt. A _rekurzív eset_ újra meghívja a függvényt, és úgy módosítja a bemenetet, hogy az előbb-utóbb megfeleljen az alapesetnek.

Nagyon gyakran minden eset a saját függvényklauzulájában szerepel.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
