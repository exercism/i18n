# Bevezetés

A `const` módosítót minden olyan mezőre alkalmazhatod (és általában alkalmaznod is kell), amelynek értéke fordítási időben ismert, és a program élettartama alatt nem változik.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

A `readonly` módosítót minden olyan mezőre alkalmazhatod (és általában alkalmaznod is kell), amely nem tehető `const`-tá, és amelynek értéke a program élettartama alatt nem változik, valamint vagy beágyazott kezdőértékkel, vagy példányosításkor (a konstruktor vagy a konstruktor által hívott metódus révén) kap értéket.

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
