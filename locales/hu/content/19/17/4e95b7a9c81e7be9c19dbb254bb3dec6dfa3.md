# Tippek

## Általános

- Az [int érték][ints] egy vagy több egymást követő számjegyként definiálható.
- A [string][string] literálok olyan karakterek sorozata, amelyeket kettős idézőjelek vesznek körül.

## 1. Add meg a sütő várható idejét percben

- Definiálnod kell egy [függvényt][functions] argumentumok nélkül.
- Egy [int][ints] értéket kell visszaadnod.

## 2. Számítsd ki a hátralévő sütési időt percben

- Definiálnod kell egy [függvényt][functions] egyetlen argumentummal.
- Egy függvényből int értéket kell visszaadnod.
- A függvény argumentuma egy [int][ints].
- Az értékek kivonásához használhatod a [kivonás matematikai operátorát][ints].

## 3. Számítsd ki az elkészítési időt percben

- Definiálnod kell egy [függvényt][functions] egyetlen argumentummal.
- Egy függvényből int értéket kell visszaadnod.
- A függvény argumentuma egy [int][ints].
- Az értékek szorzásához használhatod a [szorzás matematikai operátorát][ints].

## 4. Számítsd ki a teljes munkával töltött időt percben

- Definiálnod kell egy [függvényt][functions] két argumentummal.
- Egy függvényből int értéket kell visszaadnod.
- A függvény argumentuma egy [int][ints].
- Meghívhatod az egyik korábban definiált függvényt.
- Az értékek összeadásához használhatod az [összeadás matematikai operátorát][ints].

## 5. Készíts értesítést arról, hogy elkészült a lasagne

- Definiálnod kell egy [függvényt][functions] argumentumok nélkül.
- Egy [string][string] értéket kell visszaadnod.

[functions]: https://gleam.run/book/tour/functions.html
[ints]: https://gleam.run/book/tour/ints-and-floats.html
[string]: https://gleam.run/book/tour/strings.html
