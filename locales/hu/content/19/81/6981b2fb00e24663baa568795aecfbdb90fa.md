# Bevezetés

Az öröklés segítségével szülő-gyermek kapcsolatot hozhatunk létre osztályok között.
A gyermekosztály (néha _alosztálynak_ is nevezik) hozzáfér a szülőosztály (néha _ősosztálynak_ is nevezik) által definiált viselkedéshez és adatokhoz.

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

A gyermekosztály deklarációjában szereplő `extends` kulcsszó a [prototípusláncon][prototype-chain] keresztül kapcsolatot hoz létre a szülőosztállyal.

A gyermek konstruktorával létrehozott objektumok prototípusláncában ott lesz a szülőosztály prototípusa, így hozzáférnek a szülő által definiált metódusokhoz és adatokhoz.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
