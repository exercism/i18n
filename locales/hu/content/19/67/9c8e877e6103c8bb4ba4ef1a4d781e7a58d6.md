# Kiegészítés
## Bónusz

Őrizd meg a grafémafürtöket, azaz

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

Ehhez a bónuszfeladathoz valószínűleg jól jön a [`Unicode`][ref-unicode] szabványos könyvtár.

A graphemes teszt engedélyezéséhez add hozzá a `const TEST_GRAPHEMES = true` sort a fájlod globális scope-jához.

[ref-unicode]: https://docs.julialang.org/en/v1/stdlib/Unicode/
