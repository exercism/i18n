# Bevezetés

A Go-ban a függvények első osztályú értékek.
Ez azt jelenti, hogy a függvényekkel ugyanazokat a dolgokat teheted meg, mint bármely más értékkel: értékül adhatsz függvényeket változóknak, átadhatod őket argumentumként más függvényeknek, vagy akár függvényeket adhatsz vissza más függvényekből.

Az alábbiakban két függvényt hozunk létre, az `engGreeting` és az `espGreeting` függvényt, majd értékül adjuk őket a `greeting` változónak:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

A függvényértékek lehetőséget kínálnak arra, hogy a függvényeket ne csak adatokkal, hanem viselkedéssel is paraméterezzük.
A következő példában viselkedést adunk át a `dialog` függvénynek a `greetingFunc` paraméteren keresztül:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

Egy függvénytípusú, kezdőérték nélküli változó értéke `nil`.
Ezért ha meghívsz egy `nil` függvényértéket, az panic-hoz vezet.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

A függvényértékeket össze lehet hasonlítani a `nil`-lel.
Ez hasznos lehet, hogy elkerüljük a program szükségtelen panicjait.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Függvénytípusok

A függvényértékek használata a Go függvénytípusainak köszönhetően lehetséges.
Egy függvénytípus azon függvények halmazát jelöli, amelyeknek ugyanaz a paramétertípus-sorozata és ugyanaz az eredménytípus-sorozata.
A felhasználó által definiált típusok függvénytípusokra épülve is deklarálhatók.
Például a korábbi példákban szereplő `dialog` függvényt a következőképpen frissíthetjük:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Névtelen függvények

Egy másik hatékony eszköz, amely az első osztályú függvények támogatásának köszönhetően érhető el, a névtelen függvények.
A névtelen függvényeket ott definiáljuk, ahol használjuk, és nem követi őket név a `func` kulcsszó után.
Az ilyen függvények hozzáférnek a befoglaló függvény változóihoz.

Például:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

A `fib` meghívása deklarálja az `n1` és `n2` változókat, és visszaad egy névtelen függvényt, amely aztán minden egyes meghíváskor megváltoztatja ezeknek a változóknak az értékét.
A névtelen függvény N-edik meghívása a Fibonacci-sorozat N-edik számát adja vissza, 0-tól kezdve. A belső névtelen függvény hozzáfér a befoglaló `fib` függvény lokális változóihoz (`n1` és `n2`).
Ez remek módja annak, hogy a függvényértékek megtartsák az állapotukat a hívások között.
Azt mondjuk, hogy a névtelen függvény az `n1` és `n2` változók lezárása.
A [lezárások][closure] széles körben elterjedtek a programozásban, és más nyelvekben is találkozhatsz velük.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
