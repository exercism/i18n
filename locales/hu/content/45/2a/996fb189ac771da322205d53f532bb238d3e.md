# Utasítások

Az [Armstrong-szám](https://en.wikipedia.org/wiki/Narcissistic_number) olyan szám, amely egyenlő a saját számjegyeinek összegével, miután mindegyiket a számjegyek számának megfelelő hatványra emeltük.

Például:

- A 9 Armstrong-szám, mert `9 = 9^1 = 9`
- A 10 *nem* Armstrong-szám, mert `10 != 1^2 + 0^2 = 1`
- A 153 Armstrong-szám, mert: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- A 154 *nem* Armstrong-szám, mert: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

Írj kódot annak eldöntésére, hogy egy szám Armstrong-szám-e.
