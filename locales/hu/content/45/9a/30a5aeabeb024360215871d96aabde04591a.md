# Bevezetés

A [szótárak][dictionaries] a Swift három elsődleges gyűjteménytípusának egyike.
A szótárak _kulcsok_ és _értékek_ közötti leképezéseket tárolnak, ahol a kulcsok az egyik típus, az értékek pedig egy másik típus elemei (ami ugyanaz is lehet, mint a kulcsoké).

A szótárliterálok `key: value` párok sorozataként íródnak, vesszővel elválasztva, szögletes zárójelbe zárva.
Üres szótárakat úgy írhatunk le, hogy a szótár típusneve után egy zárójelpárt teszünk, például `[Int: String]()`, vagy ha a típus a kontextusból megállapítható, akkor csak egy kettőspontot körülvevő szögletes zárójelpárként, `[:]`.
A szótárak típusnevét kétféleképpen írhatjuk: `Dictionary<K, V>` vagy `[K: V]`, ahol `K` a szótárban lévő kulcsok típusa, `V` pedig az értékek típusa.
Üres szótár létrehozásakor meg kell adni a típust.

```swift
var addresses: Dictionary<String, String> = ["The Munsters": "1313 Mockingbird Lane", "The Simpsons": "742 Evergreen Terrace", "Buffy Summers": "1630 Revello Drive"]
var sequences: [String: [Int]] = ["Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4], "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37], "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]]
let constants = ["pi": 3.14159, "e": 2.71828, "phi": 1.618033, "avogadro": 6.02214076e23]
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

A szótár elemei indexelő jelöléssel érhetők el, ahol a szótár nevét szögletes zárójelek követik, amelyekbe a kulcsot írjuk, amelyhez a megfelelő értéket szeretnénk.

Vegyük észre azonban, hogy a visszaadott érték nem _Value_ típusú, hanem opcionális típusú, _Value?_.
Ez azért van, mert megadhatunk olyan kulcsot, amely nincs benne a szótárban.
Ilyen esetekben a Swift inkább `nil`-t ad vissza, mintsem hibát dobna.

```swift
let munster: String? = addresses["The Munsters"]
// Returns "1313 Mockingbird Lane"
let carmichael = sequences["Carmichael"]
// Returns [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
let planck = constants["planck"]
// Returns nil
```

Ha el akarjuk kerülni a visszatérési érték opcionális típusát, megadhatunk egy alapértelmezett értéket, amelyet akkor ad vissza, ha a kulcs nincs a szótárban.

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828
let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []
let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

Ez az indexelő jelölés használható arra, hogy lekérjük a kulcshoz tartozó értéket, és arra is, hogy beállítsuk a kulcshoz tartozó értéket, feltéve hogy a szótár változóként van definiálva (azaz `var`-ral).
Ezzel frissíthető a kulcshoz tartozó érték, vagy új _key: value_ pár adható a szótárhoz.

```swift
sequence["Euler's totient"]?.append(contentsOf: [6,4])
sequence["Euler's totient"]
// Returns [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]
addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."
constants["Gelfond's"] = 23.140692
// compiler error: "Cannot assign through subscript: 'constants' is a 'let' constant"
```

A tömbökhöz hasonlóan a szótár _key: value_ párjai egyenként bejárhatók egy for-in ciklussal.
Ez a fajta ciklus a szótár minden _key: value_ párját veszi, és a párt egy megadott névhez köti, hogy a ciklus törzsében tovább feldolgozható legyen.
A pár tuple-ként van ábrázolva, és más tuple-okhoz hasonlóan szétbontható, hogy minden elemet egy névhez rendeljünk. Például a címjegyzék kiírásához ezt írhatjuk:

```swift
for (name, address) in addresses {
  print("\(name) lives at \(address)")
}

// prints out:
// Betty Cooper lives at 111 Queens Ave.
// The Munsters lives at 1313 Mockingbird Lane
// The Simpsons lives at 742 Evergreen Terrace
// Buffy Summers lives at 1630 Revello Drive
```

A többi gyűjteménytípushoz hasonlóan a szótárak tetszőleges rendezési függvények szerint rendezhetők.
Ehhez először definiálni kell egy függvényt, amely két _key: value_ párt vesz át, tuple-ként ábrázolva, és egy `Bool` értéket ad vissza úgy, hogy a visszatérési érték `true` legyen, ha az első _key: value_ párnak a rendezett eredményben a második _key: value_ pár _előtt_ kell szerepelnie.

Ez a függvény aztán átadható a szótár `sorted(by:)` metódusának, amely a _key: value_ párok rendezett tömbjét adja vissza.
Például a `constants` szótár rendezéséhez a konstans értéke plusz a konstans nevében lévő karakterek száma szerint ezt írhatjuk:

```swift
func weirdSort(_ lhs: (String, Double), _ rhs: (String, Double)) -> Bool {
  let left = lhs.1 + Double(lhs.0.count)
  let right = rhs.1 + Double(rhs.0.count)
  return left < right
}

let sortedConstants = constants.sorted(by: weirdSort)
// returns [(key "e", value 2.71828), (key "phi", value 1.618033), (key "pi", value 3.14159), (key "avogadro", value 6.02214076e+22)]
```
