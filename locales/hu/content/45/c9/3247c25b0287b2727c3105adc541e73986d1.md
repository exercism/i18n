# Bevezetés

## Csomagok

A Go nyelvben az alkalmazások csomagokba szerveződnek.
A csomag az ugyanabban a mappában található forrásfájlok gyűjteménye.
Egy mappában minden forrásfájlnak ugyanazt a csomagnevet kell tartalmaznia a fájl elején.
A konvenció szerint a csomagokat ugyanúgy nevezik el, mint a mappát, amelyben találhatók.

```go
package greeting
```

A Go egy kiterjedt szabványos könyvtárat biztosít, amely csomagokból áll, és amelyeket a programodban az `import` kulcsszóval használhatsz.
A szabványos könyvtár csomagjait a nevükkel importálod.

```go
package greeting

import "fmt"
```

Ezután egy importált csomagra a csomag nevével hivatkozol:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

A Go a deklaráció módjából állapítja meg, hogy egy elem meghívható-e más csomagok kódjából.
Ahhoz, hogy egy függvény, típus, változó, konstans vagy struktúramező kívülről látható legyen (ezt _exportáltnak_ nevezik), a nevének nagybetűvel kell kezdődnie.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## String formázása

A Go biztosít egy beépített `fmt` nevű csomagot (formázócsomag), amely számos függvényt kínál a bemenet és a kimenet formázásának kezelésére.
A leggyakrabban használt függvény a `Sprintf`, amely olyan formázó igéket, például a `%s`-t használ, hogy értékeket illesszen egy stringbe, és visszaadja ezt a stringet.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

A Go-ban a lebegőpontos értékek kényelmesen formázhatók a `Sprintf` igéivel: `%g` (tömör ábrázolás), `%e` (kitevő) vagy `%f` (kitevő nélküli).
Mindhárom ige lehetővé teszi a mező szélességének és a numerikus pozíciónak a szabályozását.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Az elérhető igék teljes listáját a [formázócsomag dokumentációjában][fmt-docs] találod.

A `fmt` más, stringekkel dolgozó függvényeket is tartalmaz, például a `Println`-t, amely egyszerűen kiírja a kapott argumentumokat a konzolra, és a `Printf`-et, amely ugyanúgy formázza a bemenetet, mint a `Sprintf`, mielőtt kiírja.

[fmt-docs]: https://pkg.go.dev/fmt
