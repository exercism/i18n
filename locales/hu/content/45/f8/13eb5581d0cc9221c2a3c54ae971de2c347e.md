# Tesztek

## Beállítás

A szükséges függőségek telepítéséhez kövesd a [JavaScript beállítási útmutatóját][docs-exercism-javascript].

## Követelmények

Telepítsd a feladat függőségeit:

```shell
corepack pnpm install
```

Ha a `corepack` arra panaszkodik, hogy nincs engedélyezve, ezzel tudod engedélyezni:

```bash
corepack enable pnpm
```

## A tesztcsomag sikeres teljesítése

Minden feladathoz jár egy tesztcsomag, amivel a beküldés előtt ellenőrizheted a megoldásodat.
A teszteket úgy futtathatod, hogy megnyitsz egy parancssort a feladat könyvtárában, majd lefuttatod:

```bash
corepack pnpm test
```

Egyes tesztcsomagokban az első kivételével minden teszt ki van kapcsolva.

Amint egy teszt sikeresen lefut, a következőt úgy kapcsolhatod be, hogy az `xtest`-et `test`-re változtatod.

## Saját tesztek írása

Ha további, saját teszteket szeretnél írni, hozz létre egy új `custom.spec.js` fájlt, és a megoldásoddal együtt küldd be ezt az új fájlt is:

```shell
exercism submit numbers.js custom.spec.js
```
