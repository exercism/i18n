# Típusdeklaráció

A PHP _dinamikusan típusos_ nyelv, ami azt jelenti, hogy egy változó bármilyen típusú információt tartalmazhat.
A PHP ugyanakkor lehetővé teszi az _opcionális_ erős típusdeklarációt az osztálytulajdonságokhoz, a függvényargumentumokhoz és a függvények visszatérési értékéhez.
A PHP-ban az erős típusdeklarációk futásidőben ellenőrzik a típusokat, a PHP azonban megpróbálja automatikusan konvertálni a skaláris típusokat, hogy megfeleljenek a deklarációnak, ha erre van mód.
Az automatikus típuskonverzió kikapcsolható a fájl elején található `strict_types` deklarációval.

```php
<?php
declare(strict_types=1);
```

A függvények emellett `void` visszatérési típussal is jelezhetik, hogy nem adnak vissza értéket.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Típusuniók

Ha egy függvényargumentum, visszatérési érték vagy osztálytulajdonság egynél több típusú lehet, típusuniót deklarálhatsz.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Vegyes típusok

Amikor kóddal dolgozunk, előfordulhat, hogy nem tudunk típust megadni.
A PHP 8.0-tól kezdve létezik egy `mixed` nevű kiskapu-típus.
A `mixed` ekvivalens az `object|resource|array|string|float|int|bool|null` típusunióval.
