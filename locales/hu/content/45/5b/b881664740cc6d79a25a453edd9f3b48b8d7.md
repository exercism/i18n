# Utasítások

Ebben a feladatban naplósorokkal fogsz dolgozni.

Minden naplósor egy string, amelynek formátuma a következő: `"[<LEVEL>]: <MESSAGE>"`.

Három különböző naplózási szint létezik:

- `INFO`
- `WARNING`
- `ERROR`

Három részfeladat vár rád, és mindegyik kap egy naplósort, amellyel valamit tenned kell.

## 1. Keresd ki az üzenetet egy naplósorból

Valósítsd meg a `message` függvényt, amely egy naplósor üzenetét adja vissza:

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

Az esetleges vezető és záró szóközöket távolítsd el:

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. Keresd ki a naplózási szintet egy naplósorból

Valósítsd meg a `log-level` függvényt, amely egy naplósor naplózási szintjét kisbetűvel adja vissza:

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. Formázd át a naplósort

Valósítsd meg a `reformat` függvényt, amely átrendezi a naplósort: az üzenet kerül előre, utána pedig a naplózási szint zárójelben:

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
