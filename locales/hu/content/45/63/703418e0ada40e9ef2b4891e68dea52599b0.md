# Névjegy

Az Elixirben ahhoz, hogy véletlenszerű elemet válasszunk egy felsorolható adatszerkezetből (például listából, tartományból), az [`Enum.random/1`][enum-random] függvényt használjuk. Ez a függvény egyetlen elemet választ ki, méghozzá úgy, hogy minden elem azonos valószínűséggel kerüljön kiválasztásra. Egyetlen véletlen érték kiválasztása egy tartományból konstans idő alatt történik, anélkül hogy bejárnánk a teljes tartományt.

## Véletlen egész számok és betűk

- Véletlen egész szám kiválasztása
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- Véletlen betű kiválasztása stringként
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- Véletlen betű kiválasztása charlistként
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

Ha egynél több elemet szeretnél kiválasztani egy felsorolható adatszerkezetből, használd az [`Enum.take_random/2`][enum-take-random] függvényt. Ha egy felsorolható adatszerkezetet véletlen sorrendbe szeretnél rendezni, használd az [`Enum.shuffle/1`][enum-shuffle] függvényt.

## Véletlen tizedes törtek

Az Elixirnek nincsenek saját függvényei véletlen tizedes tört kiválasztására. Ehhez az Erlang [`rand`][erl-rand] modulját kell használnunk, amely egyébként pont az, amit az `Enum.random` a háttérben használ.

- Véletlen tizedes tört kiválasztása (nagyobb vagy egyenlő mint 0.0 és kisebb mint 1.0):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- Véletlen tizedes tört kiválasztása (nagyobb vagy egyenlő mint `a` és kisebb mint `b`):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## Normális eloszlás

A fent említett összes függvény úgy választ véletlen értéket, hogy minden lehetséges érték azonos valószínűséggel kerül kiválasztásra. Ezt _egyenletes eloszlásnak_ nevezzük. A `rand` modul emellett [`normal/0`][erl-rand-normal-0] és [`normal/2`][erl-rand-normal-2] függvényeket is kínál, amelyek [normális eloszlás][normal-distribution] szerinti véletlen tizedes törtet választanak.

## Mag

Fontos megérteni, hogy a „véletlen” értékeket egy [_álvéletlen_ számgenerátor][prng] állítja elő. A PRNG egy olyan algoritmus, amely egy _magnak_ nevezett kezdőértékből kiindulva olyan számsorozatot generál, amely véletlennek tűnik, de egyáltalán nem az.

Ez a tény hasznos lehet a hibakeresésnél. Rákényszerítheted az Erlang (és így az Elixir) álvéletlen számgenerátorát, hogy ugyanazokat a sorozatértékeket állítsa elő, ha visszaállítod a magját a [`:rand.seed/2`][rand-seed-2] segítségével. Az első argumentum egy konkrét PRNG-algoritmus, a második pedig egy három egész számból álló tuple, a mag.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## Kriptográfia

Az `Enum.random` és az Erlang `rand` modulja által visszaadott véletlen értékek [nem kriptográfiailag biztonságosak][cryptographically-secure-rng]. Ne használd őket kriptográfiai kulcsok, jelszavak vagy nonce-ok előállítására. Erre az esetre ott van az Erlang [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes] függvénye.
