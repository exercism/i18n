# Bevezetés

A Haskellben van egy `Num` típus, amely az összes numerikus típus alapja.
A számtípuson belül négy fő altípus található: [`Int`][int], [`Integer`][integer], [`Double`][double] és [`Float`][float].

A Haskellben kétféle egész típus van, amelyek egész számokat reprezentálnak.
Az `Int` egy rögzített méretű egész, az `Integer` pedig egy tetszőleges pontosságú egész.
Az `Integer` bármekkora számot tárolhat, egészen a géped memóriájának határáig, az `Int` pedig a 32 vagy 64 biten ábrázolható pozitív és negatív egészek halmazának felel meg (garantáltan legalább a -2^29 és a 2^29 - 1 közötti tartomány).

Figyelj arra, hogy negatív számok írásakor zárójelet használj a kétértelműség elkerülésére.

```haskell
1

(-1)
```

A `Float` a valós számok halmazának felel meg, amelyet a számítógép pontossága korlátoz.
A számokon értelmezett műveletek általában az egyik vagy a másik típuson működnek, de nem mindkettőn.
A `Double` egy kétszeres pontosságú lebegőpontos szám.

```haskell
10.5
```

## Az egészek és a lebegőpontos számok közötti átalakítás

A `toFloat` függvénnyel egy `Int` vagy `Integer` értéket `Float`-tá alakíthatsz.

```haskell
toFloat 1
-- -> 1.0
```

Létezik a `fromIntegral` is, amely bármilyen numerikus típust a szükséges, kikövetkeztetett numerikus típusra alakít.

```haskell
fromIntegral 1
-- -> 1.0
```

A `Float` `Int`-té alakításához használhatod a [`round`][round], [`floor`][floor] vagy [`ceiling`][ceiling] függvényt.
A `round` függvény a legközelebbi egészre kerekít, a `floor` lefelé, a `ceiling` pedig felfelé kerekít.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## Aritmetikai operátorok

A numerikus típusokon használhatod az [alapvető aritmetikai operátorokat][math].
Az operátorok: `+`, `-`, `*`, `/` és `%`.
Ezek használatakor a számok típusának meg kell egyeznie.
A `fromIntegral` függvény gondoskodik az átalakításról, hogy a típusok illeszkedjenek.

### Összeadás, kivonás és szorzás

A `+` operátor az összeadásra, a `-` a kivonásra, a `*` pedig a szorzásra szolgál.

| Operátor | Példa          |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Osztás

Az osztással számokat oszthatunk el.
Az osztásra a `/` operátort használjuk.
Az eredmény mindig lebegőpontos szám lesz.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
Egyes programozási nyelvekben a nullával való osztás eredménye hiba lesz.

Haskellben a nullával való osztás eredménye `Infinity` vagy `-Infinity`.
Az egyetlen kivétel a nulla osztása nullával, amelynek eredménye `NaN` (azaz nem szám).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## Egészosztás

Az egészosztás egész számok elosztására szolgál, és az eredmény egész részét adja vissza.
A Haskell két egészosztó függvényt kínál, amelyek abban különböznek, hogyan kerekítenek, ha az eredmény negatív:

- A `div` lefelé kerekít, a negatív végtelen felé.
- A `quot` a nulla felé kerekít.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Az egészosztásnál a nullával való osztás kivételt eredményez.
Ez eltér a normál osztástól.
~~~~

### Maradék

Az egészosztás maradékát a `mod` vagy a `rem` függvénnyel kaphatod meg.
Abban különböznek, milyen előjelű lesz az eredmény, ha az egyik szám negatív:

- A `mod` a `div` párja, és eredményének előjele az osztóéval egyezik.
- A `rem` a `quot` párja, és eredményének előjele az osztandóéval egyezik.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Bármely `x` és `y` esetén (ahol `y` nem nulla) teljesülnek a következő törvények:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Ha mindkét szám pozitív, a `div` és a `quot` ugyanazt az eredményt adja, ahogy a `mod` és a `rem` is.
Ebben az esetben a `quot` és a `rem` kissé hatékonyabb lehet, mert a `div` és a `mod` extra lépéseket igényel a negatív számok kezeléséhez.
~~~~

~~~~exercism/caution
A `mod` vagy a `rem` használatakor a nullával való osztás kivételt eredményez.
Ez eltér a normál osztástól.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## Hatványozás

A Haskellnek három „hatványra emelő” operátora van, amelyek másképp működnek, és más-más argumentumtípusokat fogadnak.

- A `**` két **lebegőpontos számot** fogad, és logaritmusokat használ a hatvány kiszámításához.
- A `^^` egy **lebegőpontos számot** emel pozitív vagy negatív **egész** kitevőre.
- A `^` **bármilyen numerikus típust** elfogad, és **pozitív egész** kitevőre emel.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## Prioritás és zárójelek

A Haskell lehetővé teszi a zárójelek (`()`) használatát, amelyekkel kifejezéseket csoportosíthatsz.
Ez akkor hasznos, ha meg szeretnéd változtatni a műveletek sorrendjét.

Több aritmetikai operátor használatakor a műveletek sorrendje ugyanaz, mint a matematikában, amit [PEMDAS][pemdas] néven is ismerünk.
A sorrend: zárójelek (`()`), kitevők (`**`), szorzás (`*`) és osztás (`/`), majd összeadás (`+`) és kivonás (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
