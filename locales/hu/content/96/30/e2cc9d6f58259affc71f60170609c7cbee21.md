# Utasítások

Sakkrajongóként szeretnéd megírni a játék saját változatát. Igaz, rengeteg sakkimplementáció elérhető már online, de a tiéd egyedi lesz!

Mielőtt azonban szabad folyást engednél a fantáziádnak, az alapokkal kell foglalkoznod. Kezdjük a tábla legenerálásával.

A sakktábla minden mezőjét egy betű-szám pár azonosítja. A mezők függőleges oszlopait, más néven a vonalakat A-tól H-ig betűk jelölik. A vízszintes sorokat, más néven a rangokat 1-től 8-ig számozzuk.

## 1. A rangtartomány meghatározása

Valósítsd meg a `rank_range/0` függvényt. A függvény egy egész számokból álló tartományt adjon vissza 1-től 8-ig.

```elixir
Chessboard.rank_range()
```

## 2. A vonaltartomány meghatározása

Valósítsd meg a `file_range/0` függvényt. A függvény egy egész számokból álló tartományt adjon vissza, a nagy A betű kódpontjától a nagy H betű kódpontjáig.

```elixir
Chessboard.file_range()
```

## 3. A rangtartomány átalakítása rangok listájává

Valósítsd meg a `ranks/0` függvényt. A függvény egy egész számokból álló listát adjon vissza 1-től 8-ig. Ne írd le kézzel a listát, hanem a `rank_range/0` függvény által visszaadott tartományból generáld.

```elixir
Chessboard.ranks()
# => [1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. A vonaltartomány átalakítása vonalak listájává

Valósítsd meg a `files/0` függvényt. A függvény betűk (stringek) listáját adjon vissza „A”-tól „H”-ig. Ne írd le kézzel a listát, hanem a `file_range/0` függvény által visszaadott tartományból generáld.

```elixir
Chessboard.files()
# => ["A", "B", "C", "D", "E", "F", "G", "H"]
```
