# Bevezetés

## Változók

Az Elixir dinamikusan típusos nyelv, ami azt jelenti, hogy egy változó típusát csak futásidőben ellenőrzi. A `=` illesztő operátorral bármilyen típusú értéket hozzáköthetünk egy változónévhez:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## Modulok

Az Elixir [funkcionális programozási nyelv][functional-programming], és minden elnevezett függvényt egy _modulban_ kell definiálni. A `defmodule` kulcsszóval definiálhatunk egy modult. Futásidőben minden modul elérhető az összes többi modul számára, és nem igényel _hozzáférés-módosítót_ ahhoz, hogy a program többi része láthassa őket. Egy _modul_ más programozási nyelvek _osztályához_ hasonlít.

```elixir
defmodule Calculator do
  # ...
end
```

## Elnevezett függvények

Az _elnevezett függvényeket_ egy modulban kell definiálni. A `def` kulcsszóval _nyilvános_ elnevezett függvényt definiálhatunk.

Minden függvénynek nulla vagy több argumentuma lehet. A függvény az utolsó kifejezés értékét mindig _implicit módon adja vissza_.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

Egy függvényt úgy hívunk meg, hogy megadjuk a modulját és a függvény nevét, majd minden argumentumához átadunk egy értéket.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

A `def` helyett a `defp` kulcsszóval _privát_ függvényt definiálhatunk. A privát függvényeket csak abból a modulból lehet használni, amelyik definiálta őket.

Ha egy függvényt abban a modulban hívunk meg, ahol definiáltuk, a modul nevét elhagyhatjuk.

Rövid függvényeket egysoros szintaxissal is írhatsz (figyeld meg a `do` kulcsszó körüli vesszőt `,` és kettőspontot `:`).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## A függvények aritása

Gyakori, hogy a függvényekre az _aritásukkal_ hivatkozunk. Egy függvény _aritása_ a befogadott argumentumok száma.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## Elnevezési konvenciók

A modulneveket `PascalCase` stílusban írd. A modulnévnek nagybetűvel `A-Z` kell kezdődnie, és tartalmazhat betűket `a-zA-Z`, számokat `0-9` és aláhúzásjeleket `_`.

A változó- és függvényneveket `snake_case` stílusban írd. A változó- vagy függvénynévnek kisbetűvel `a-z` vagy aláhúzásjellel `_` kell kezdődnie, tartalmazhat betűket `a-zA-Z`, számokat `0-9` és aláhúzásjeleket `_`, és végződhet kérdőjellel `?` vagy felkiáltójellel `!`.

## Szabványos könyvtár

Az Elixirnek nagyon gazdag és jól dokumentált szabványos könyvtára van. A dokumentáció elérhető online a [hexdocs.pm/elixir][docs] címen. Mentsd el ezt a linket valahova, sokat fogod használni!

A legtöbb beépített adattípushoz tartozik egy megfelelő modul, amely függvényeket kínál az adott adattípus kezeléséhez, például egészekhez az `Integer`, szövegekhez a `String`, listákhoz a `List` modul, és így tovább.

Figyelemre méltó modul a `Kernel`. Ez nyújtja azokat az alapvető képességeket, amelyekre a szabványos könyvtár többi része épül, például az aritmetikai operátorokat, a vezérlési folyamhoz tartozó makrókat és még sok minden mást. A `Kernel` modul függvényei automatikusan importálódnak, így a `Kernel.` előtag nélkül is használhatod őket.
