# Utasítások

A fedélzetmester naponta eligazítást tart a fedélzeten az őrségnek: egy köszöntés, a szolgálatban lévő legénység névsorolvasása, majd egy záró elengedés. Az eligazítást kis, elnevezett sorokra bontod, és ezekből állítod össze.

Ebben a feladatban **két fájlt** fogsz szerkeszteni:

- `bosuns-briefing/helpers/helpers.factor` — kis, újrahasznosítható darabok. Szókészlet: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor` — a fő fájl, amely a segédszavakat összeállítja. Szókészlet: `bosuns-briefing`.

## 1. Köszöntés

A `helpers.factor` fájlban definiáld a `greeting` szót úgy, hogy a fix nyitó sztringet adja vissza: `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Legénységsor

A `helpers.factor` fájlban definiáld a `crew-line` szót úgy, hogy átvegyen egy név sztringet, és a nevet a `"  - "` előtaggal (két szóköz, egy kötőjel, egy szóköz) adja vissza.

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Zárás

A `helpers.factor` fájlban definiáld a `closing` szót úgy, hogy a fix záró sztringet adja vissza: `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. Névsor

A `bosuns-briefing.factor` fájlban definiáld a `roster` szót úgy, hogy átvegyen egy legénységnevekből álló tömböt, és egyetlen, több soros sztringet adjon vissza, amelyben minden nevet a `crew-line` formáz, a neveket pedig sortörések választják el egymástól.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Eligazítás

A `bosuns-briefing.factor` fájlban definiáld a `briefing` szót úgy, hogy átvegyen egy legénységnevekből álló tömböt, és a teljes eligazítást egyetlen sztringként adja vissza: az első sorban a köszöntést, a következő sorokban a névsort, az utolsó sorban pedig a zárást. Használd a segédszavakat és a `roster` szót.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
