# Részletesen

Amikor olyan adatot modellezünk, amely csak bizonyos lehetséges állapotok meghatározott halmazát veheti fel, például a hét napjait, az égtájakat vagy egy vezérlő gombjait, az olyan alaptípusoknak, mint az `Int` vagy a `String`, komoly hátrányaik vannak.
Ha inteket vagy stringeket használsz, a kódodnak folyamatosan ellenőriznie kell az érvénytelen értékeket (például egy `999`-es állapotkódot vagy egy `"leftt"` elgépelést), és az emberi olvasók sem tudják könnyen megmondani, mit jelképeznek a számok.

A Swift ezt a problémát a [_felsorolásokkal_][enumerations] oldja meg (gyakran csak _enumnak_ rövidítve).
A felsorolás közös típust definiál összetartozó, elnevezett értékek egy csoportjának. Mivel a fordító előre ismeri az összes lehetséges esetet, fordítási időben ellenőrizni tudja a kódod helyességét és teljességét.
A felsorolásokhoz emellett metódusok, kezdőértékek és számított tulajdonságok is tartozhatnak.

## Felsorolások definiálása

A felsorolást az `enum` kulcsszóval definiálod, amelyet a típus neve követ, az eseteket pedig a kapcsos zárójelek közé írod.
A Swift konvenciója szerint a típusnév `UpperCamelCase`, az egyes esetek pedig `lowerCamelCase` formában íródnak:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

Több esetet egyetlen sorba is írhatsz, vesszővel elválasztva:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Egy felsorolásesetre úgy hivatkozol, hogy leírod a felsorolás típusnevét, egy pontot (`.`) és az eset nevét. Ha a típus ismert, vagy a fordító ki tudja következtetni, elhagyhatod a típusnevet, és használhatod a rövidebb pontjelölést:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Felsorolások és `switch` utasítások

A felsorolások gördülékenyen működnek együtt a [`switch` utasításokkal][enums-and-switches].
Mivel a Swiftben a `switch` utasításnak ki kell merítőnek lennie, a fordító gondoskodik róla, hogy minden lehetséges esetet kezelj:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Ha kihagysz egy esetet anélkül, hogy `default` esetet adnál meg, a fordító hibát jelez:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Gyakran jobb minden esetet explicit módon felsorolni, mint `default`-ot használni. Így ha a jövőben új esetet adsz hozzá, a fordító azonnal figyelmeztet, hogy frissítsd az összes `switch` utasítást, amely ezt a felsorolást kezeli.

## Metódusok és kezdőértékek

A felsorolások ugyanúgy definiálhatnak metódusokat és saját kezdőértékeket, mint az osztályok és struktúrák. Egy felsorolás metódusán belül a `self` az aktuális esetértékre utal:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Nyers értékek

A felsorolás esetei előre kitölthetők alapértelmezett értékekkel, amelyeket [_nyers értékeknek_][raw-values] nevezünk.
Egy felsorolásban minden nyers értéknek ugyanolyan típusúnak kell lennie (például `Int`, `String` vagy `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

A felsorolást nyers értékből az `init(rawValue:)` segítségével inicializálhatod. Mivel érvénytelen nyers értéket is megadhatsz, ez a kezdőérték opcionálist ad vissza:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

A Swift automatikusan hozzárendelhet nyers értékeket `String` és `Int` típusú felsorolásokhoz:

- `String` típusú felsorolásoknál minden eset nyers értéke alapértelmezésben az eset neve.
- `Int` típusú felsorolásoknál a nyers értékek `0`-tól indulnak, és eggyel nőnek, hacsak másképp nem adod meg.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Kapcsolódó értékek

A felsorolás esetei emellett különböző típusú egyedi értékeket is tárolhatnak az egyes esetek mellett; ezeket [_kapcsolódó értékeknek_][associated-values] nevezzük:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Egy felsorolásnak vagy nyers értékei, vagy kapcsolódó értékei lehetnek, de egyszerre a kettő nem.

## Rekurzív felsorolások

A [rekurzív felsorolás][recursive-enumerations] olyan felsorolás, amelynél egy vagy több eset kapcsolódó értéke magának a felsorolásnak egy másik példánya.
A rekurzió engedélyezéséhez jelöld meg az esetet (vagy az egész felsorolást) az `indirect` kulcsszóval:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
