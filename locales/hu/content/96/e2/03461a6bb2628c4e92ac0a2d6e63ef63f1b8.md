# Kiegészítés az utasításokhoz

## A Stream képességről

A `Stream` egy Unison-képesség, amely értékek kibocsátására szolgál.

A `Stream` képességet akkor használhatod, ha van egy függvényed, amelynek hívása közben mellékhatásként értékeket kell előállítania. Ez a függvény például visszaadja a lista utolsó értékét, de minden egyes elem láttán kibocsát egy futó összeget:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

A Streamet előállító függvény visszatérési értéke mellett egy képességkezelővel listaként materializálhatjuk azt:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
