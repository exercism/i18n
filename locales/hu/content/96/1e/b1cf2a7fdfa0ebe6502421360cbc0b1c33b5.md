# Részletek

A C#-ban a [`null` literál][null-keyword] az érték hiányát jelöli. A _nullázható_ típus olyan típus, amely megengedi a `null` értékeket.

A C# 8.0 előtt a referenciatípusok mindig nullázhatók voltak, az értéktípusok viszont nem. Az [értéktípusból viszont nullázható típust csinálhatsz][nullable-value-types] úgy, hogy a végére egy kérdőjelet (`?`) teszel.

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Egy olyan változó tagjának az elérése, amelynek az értéke `null`, lefordul ugyan, futásidőben viszont `NullReferenceException` dobódik:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

Az ilyen gyakori hibák ellen a C# 8-ban [bekapcsolhatsz egy olyan szolgáltatást][nullable-csharp-8], amely [a referenciatípusokat alapértelmezés szerint nem nullázhatóvá teszi][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Ahhoz, hogy [biztonságosan dolgozhass a nullázható értékekkel][nullable-types-tutorial], előbb ellenőrizd, hogy nem `null`-e:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

A [`??` operátor][null-coalescing-operator] segítségével akkor is visszaadhatsz egy alapértelmezett értéket, ha az érték `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

A [`?.` operátor][null-conditional-operator] segítségével egy esetleg `null` érték tagjait is biztonságosan hívhatod meg:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

Ha a fordító úgy gondolja, hogy egy érték lehet `null`, te viszont biztos vagy benne, hogy nem az, a [`!.` operátor][null-forgiving-operator] segítségével elnyomhatod a figyelmeztetést. Ezt az operátort viszont csak végső esetben használd.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
