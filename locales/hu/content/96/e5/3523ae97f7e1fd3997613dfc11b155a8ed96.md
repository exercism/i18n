# felesleges elágazás

Ahelyett, hogy létrehoznál egy `if (...) {}` blokkot, használd ki közvetlenül a Boolean értéket, amit a paraméter értékének ellenőrzése ad vissza.

Például a következő:

```javascript
if (param === true) {
  return true;
}
```

átalakítható erre:

```javascript
return param === true;
```
