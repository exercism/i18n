# Bevezetés

## Konstansok és függvények

A Haskell programok definíciókból és kifejezésekből épülnek fel.

Egy konstans értéket a `name = expression` alakban definiálunk.

```haskell
five = 5

six = 3 + 3
```

A függvényeket `name parameters... = expression` formában definiáljuk, a paramétereket pedig csak szóköz választja el egymástól.

```haskell
add number1 number2 = number1 + number2
```

Egy függvény meghívása szintén kifejezés, és úgy történik, hogy megadjuk a függvény nevét, majd minden paraméteréhez átadunk egy argumentumot, szóközzel elválasztva, akárcsak a függvénydefinícióknál.

```haskell
five = add 2 3
```

Egy kifejezés kiértékelési sorrendjét zárójelekkel adhatjuk meg.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Behúzás / a whitespace jelentősége

A Haskell a kódrészek határait whitespace és behúzás segítségével jelöli ki.
***Az olyan kódot, amely valamely kifejezés része, beljebb kell húzni, mint ahol az a kifejezés kezdődik.***

- A modul-, import- és legfelső szintű függvénydefinícióknak a bal szélső oszlopban kell kezdődniük.
- Ha egy kifejezés több sorra tagolódik, akkor a kifejezéshez tartozó kódot legalább egy szóközzel beljebb kell húzni a kifejezés alatt.
- A kifejezés azon részeit, amelyek összetartoznak, ugyanannyi szóközzel érdemes behúzni.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## Modulok

A modulok függvényeket exportálnak.
Ez azt jelenti, hogy használhatod azokat a függvényeket, amelyeket a modul az export utasításában elérhetővé tesz.
Egy modul definiálhat függvényeket kizárólag belső használatra is.
Alapértelmezés szerint azok a függvények, amelyeket nem exportálunk kifejezetten, a modulon kívülről nem használhatók.

A modul elején megadjuk a modul nevét.
Ha van egy Calculator.hs nevű fájlunk, akkor a modulunkat Calculator-nek kell elneveznünk.
Ezután megadjuk azokat a függvényeket, amelyeket exportál, és ezt követően hozzáfoghatunk a függvények megírásához.
Kezdjük tehát ezzel.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Kommentek

A komment olyan szöveg a Haskell-fájlban, amelyet a program nem kódként értelmez.
Elsősorban arra való, hogy te és a többi programozó olvassátok.
Az egysoros kommentekhez van egy egyszerű szintaxis, amely két egymás utáni kötőjelen alapul.
A többsoros kommentek is lehetségesek a `{-` és `-}` nyitó és záró határoló párral.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
