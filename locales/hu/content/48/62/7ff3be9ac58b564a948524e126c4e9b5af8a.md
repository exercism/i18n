# Tippek

## Általános

- A [`Set` API dokumentációja][set-docs] tartalmazza a `Set` interfészen elérhető metódusok listáját.

## 1. Kezdj el gyűjteményt építeni

- A [`HashSet` osztály][hashset-docs] rendelkezik egy konstruktorral, amely egy `Collection`-t fogad.

## 2. Növeld a gyűjteményt

- Nézd meg a `Set` interfészen definiált [`add` metódus][set-add-docs] szignatúráját.

## 3. Kezdj el kereskedni

- Egy `Set` másolatát úgy hozhatod létre, hogy egy `new HashSet<>()`-be csomagolod.
- A [`Set` interfész][set-docs] rendelkezik egy metódussal, amely eltávolít minden olyan elemet, amit egy másik `Collection` tartalmaz.

## 4. Azonosítsd a közös kártyákat

- Egy `Set` másolatát úgy hozhatod létre, hogy egy `new HashSet<>()`-be csomagolod.
- A [`Set` interfész][set-docs] rendelkezik egy metódussal, amely megtart minden olyan elemet, amit egy másik `Collection` tartalmaz.

## 5. Az összes kártya

- Egy `Set` másolatát úgy hozhatod létre, hogy egy `new HashSet<>()`-be csomagolod.
- A [`Set` interfész][set-docs] rendelkezik egy metódussal, amely hozzáad minden olyan elemet, amit egy másik `Collection` tartalmaz.
