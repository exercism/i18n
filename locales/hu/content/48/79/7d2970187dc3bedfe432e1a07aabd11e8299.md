# Utasítások

Ebben a feladatban középiskolás szerelmeseknek segítesz, hogy a közösségi médiában nyilvánosan szerelmet valljanak: készíts egy ASCII-dobozt a kezdőbetűikkel:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. Kérd le a név első betűjét

Valósítsd meg a `HighSchoolSweetheart.first_letter/1` függvényt. A függvény egy nevet kap, és annak első betűjét adja vissza. A névből a felesleges szóközöket is távolítsa el.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. Formázd kezdőbetűvé az első betűt

Valósítsd meg a `HighSchoolSweetheart.initial/1` függvényt. A függvény egy nevet kap, és visszaadja annak első betűjét nagybetűvel, ponttal a végén. Ügyelj rá, hogy újra felhasználd a `HighSchoolSweetheart.first_letter/1` függvényt, amelyet az előző lépésben definiáltál.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. Bontsd fel a teljes nevet keresztnévre és vezetéknévre

Valósítsd meg a `HighSchoolSweetheart.initials/1` függvényt. A függvény egy teljes nevet kap, amely egy keresztnévből és egy vezetéknévből áll, szóközzel elválasztva, és visszaadja a kezdőbetűket. Ügyelj rá, hogy újra felhasználd a `HighSchoolSweetheart.initial/1` függvényt, amelyet az előző lépésben definiáltál.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. Helyezd a kezdőbetűket az ASCII-dobozba

Valósítsd meg a `HighSchoolSweetheart.pair/2` függvényt. A függvény két teljes nevet kap, és a kezdőbetűket egy ASCII-dobozban adja vissza. A dobozt nem kell magadnak megrajzolnod: használd a kódkommentben található dobozt. Ügyelj rá, hogy újra felhasználd a `HighSchoolSweetheart.initials/1` függvényt, amelyet az előző lépésben definiáltál.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
