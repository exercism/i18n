# Bevezetés

## Nyílfüggvények

A függvénydeklarációk és a függvénykifejezések mellett a JavaScriptnek van egy másik, nagyon tömör szintaxisa is függvények definiálására.
Ezeket a függvényeket _nyílfüggvényeknek_ nevezzük.

Íme egy összehasonlítás egy függvénydeklaráció és egy nyílfüggvény között.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Ha a függvény törzse csak egy `return` utasítást tartalmaz, mint a fenti példában, akkor a `{}` és a `return` kulcsszó elhagyható.
Ha csak egy paraméter van, a zárójel (`()`) is elhagyható.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

A nyílfüggvényeket gyakran arra használjuk, hogy rövid visszahívó függvényeket közvetlenül a függvényhívásban definiáljunk.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## Tömbök elemzése

A [tömböknek][arrays-concept] beépített metódusaik vannak a tartalmuk elemzésére.
Ezek a metódusok többsége olyan függvényt vár argumentumként, amely igaz vagy hamis értéket ad vissza.
Az ilyen függvényt [`predicate`][predicate_in_programming]-nek nevezzük.

A beépített metódusokat _a `for` ciklus_ vagy a beépített `forEach` metódus helyett érdemes használni:

Példa elemzésre for ciklussal:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Példa elemzésre beépített metódussal:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Az alábbiakban néhány további hasznos beépített metódust mutatunk be, amelyekkel tömböket elemezhetsz.
A tömbmetódusok teljes listáját lásd az [MDN][mdn-array-methods] oldalán.

### `includes`

Az `includes(value)` metódus megállapítja, hogy egy tömb tartalmaz-e egy adott értéket.
`true`-t ad vissza, ha az érték benne van, egyébként `false`-t.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

Az `every(predicate)` metódus olyan függvényt vár, amely _predicate_.
Azt vizsgálja, hogy a tömb minden eleme `true`-t ad-e vissza, amikor átadjuk a predicate-nek.
Más szóval: a metódus azt ellenőrzi, hogy minden eleme átmegy-e a függvényhívásnak átadott teszten.
`true`-t ad vissza, ha minden elem átmegy a predicate-teszten, egyébként `false`-t.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

A `some(predicate)` metódus ugyanaz, mint az `every` metódus, de `true`-t ad vissza, ha a tömb legalább egy eleme átmegy a _predicate_-teszten.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

A `find(predicate)` metódus a tömb első olyan elemének értékét adja vissza, amely átmegy a `predicate`-teszten.
Míg a `some()` `true`-t ad vissza, ha átmegy, addig a `find()` a tömb tényleges értékét adja vissza.
A metódus `undefined`-ot ad vissza, ha a tömb egyetlen eleme sem megy át a _predicate_-teszten.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

A `findIndex(predicate)` ugyanaz, mint a `find()` metódus, de a _predicate_-teszten átmenő elem (első) _indexét_ adja vissza a `value` helyett.
A metódus `-1`-et ad vissza, ha a tömb egyetlen eleme sem megy át a _predicate_-teszten.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
