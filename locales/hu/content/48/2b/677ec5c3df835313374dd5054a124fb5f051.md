## Általános szintaxis

A `<?php` PHP nyitó tag jelöli a PHP-kód kezdetét.
Minden utasítást `;`-vel kell lezárni az utasítások elválasztásához.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

A könnyebb olvashatóság érdekében a kódpéldákból hiányzik a `<?php` PHP nyitó tag.

## Megjegyzések

A `//` jelzi az egysoros megjegyzés kezdetét.

```php
// Single line comment
```

## Értékek és változók

Az értékadó `=` operátorral értéket rendelhetsz egy változóhoz.
A változóneveknek egy dollárjellel (`$`) kell kezdődniük, és követniük kell a [névadási konvenciókat][exercism-concept-naming-conventions].

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## Függvények és metódusok

Értékeket és változókat adhatsz át függvényeknek.
A függvény argumentumai új változókká válnak, amelyek a kapott értékeket tárolják.
A függvények a `return` kulcsszóval bármilyen értéket visszaadhatnak.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

Az osztályokon belüli, valamint a példányokon elérhető függvényeket metódusoknak nevezzük.
Egy metódus meghívásához a metódus neve elé a példányt és egy `->` jelet írunk.
A metódusok hozzáférnek a különleges `$this` változóhoz, amely az aktuális példányra hivatkozik.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
