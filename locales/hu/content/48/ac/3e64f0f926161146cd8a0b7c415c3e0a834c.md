# Bevezetés

A [`Rational numbers`][rational] olyan törtek, amelyeknek a számlálója és a nevezője is egész szám.

Például a `2//3` pontos törtként tárolható a közelítő `Float64` érték, a `0.6666...` helyett.

Ennek az az előnye, hogy (leszámítva az [integer overflow][integer-overflow] szélsőséges esetét) a racionális szám pontos marad, és elkerüli azokat a kerekítési hibákat, amelyek a lebegőpontos számoknál gyakran elkerülhetetlenek.

További részletek a Julia [vonatkozó kézikönyvoldalán][julia-rational] olvashatók.

A racionális számok meglehetősen egyszerű numerikus típus, és pontosan úgy működnek, ahogy várnád.
Mivel a Julia korai verziói óta szabványos típus, a legtöbb függvény ugyanúgy elfogadja őket bemenetként, mint az egész számokat és a lebegőpontos számokat.

## Racionális számok létrehozása

A létrehozáshoz nem kell több, mint a `//` jelet két egész szám közé írni.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

A közös tényezőket automatikusan eltávolítja, és a törtet a [„legegyszerűbb alakjába”][lowest-terms] hozza, ami nem más, mint a törtet pontosan reprezentáló legkisebb egész számok, nem negatív nevezővel.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

A végtelen eredmények elfogadottak, a `NaN` viszont nem.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Műveletek racionális számokkal

A szokásos [`arithmetic operators`][operators], azaz a `+ - * / ^ %` ugyanúgy működnek a racionális számokkal, mint a többi numerikus típussal.

Az egész számokat és más `Rational` értékeket is beleveheted a műveletbe, és az eredmény `Rational` lesz.
Ha `float` kerül a kifejezésbe, az eredmény is `float` lesz, ami (esetleg) pontosságvesztéssel jár.

Ha `float`-ra van szükséged, egyszerűen a `float()` függvénnyel alakítsd át a racionális számot.
Teljesen megszokott, hogy egy hosszú számítás során a pontosság megőrzéséhez racionális számokat használunk, majd a végén `float`-ra alakítunk.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

A racionális számokat és a [komplex számokat][complex] is kombinálhatod.
A komplex számokról egy [külön fogalom][complex-concept] szól.

## Egyéb műveletek

Juliában a racionális számok egyszerűen csak számok.
A fordító általában szükség szerint átalakítja a típusokat.

Vigyázz azonban arra, hogy az összehasonlítás csak olyan törteknél működik, amelyeknek véges a tizedestört alakja:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Egyébként viszont az összehasonlításhoz a `Rational` értéket `Float`-ra kell alakítani:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

A matematikai függvények racionális számokat fogadnak bemenetként, de az eredményük lebegőpontos lehet:

```julia-repl
julia> sqrt(9//16)
0.75
```
