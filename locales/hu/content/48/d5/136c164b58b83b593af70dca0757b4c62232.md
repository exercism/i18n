# Tesztek

Telepítsd a függőségeket.

```sh
dart pub get
```

Futtasd a teszteket.

```sh
dart test
```

Részletesebb, tesztenkénti kimenethez használd az expanded riportert.

```sh
dart test -r expanded
```

A legtöbb feladatban több teszt van, és alapértelmezés szerint az első kivételével mindegyik ki van hagyva.
Ha egyesével szeretnéd végigvenni a teszteket, haladás közben minden tesztnél írd át a `skip: true` értéket `skip: false`-ra.

Vagy futtasd le az összes tesztet egyszerre anélkül, hogy szerkesztenéd a fájlt.

```sh
dart test --run-skipped
```

Beküldéskor az online tesztfuttató minden tesztet lefuttat, a kihagyottakat is.
