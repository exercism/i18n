# A nyelvről

Az Arturo egy függetlenül fejlesztett, modern programozási nyelv, amely néhány nagyon egyszerű és egyértelmű elvet követ:

* A code csak szavak, szimbólumok és literálértékek listája.
  
* A szavak és szimbólumok egy blokkon belül - szükség esetén - a kontextusnak megfelelően értelmeződnek.
  
* Nincsenek fenntartott szavak vagy kulcsszavak - keresd őket, amennyire csak tudod; egyáltalán nincsenek.
