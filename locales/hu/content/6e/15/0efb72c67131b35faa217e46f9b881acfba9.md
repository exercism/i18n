# Bevezetés

A JavaScriptben az értékek különböző típusúak lehetnek. Egy változó típusát explicit _típuskonverzióval_ lehet megváltoztatni.
Ezen kívül a JavaScript _automatikus típuskonverziót_ (implicit típuskonverziót) is végez, amikor a kontextus megkívánja.

## Típuskonverzió

A JavaScriptben, sok más nyelvvel ellentétben, nincs olyan szerkezet, amellyel egy értéket egy (másik) típusba lehetne átalakítani, helyette viszont néhány beépített segédeszköz használható.
A legfontosabbak: a `Boolean`, a `Number` és a `String` függvényként használható ahhoz, hogy egy értéket a megfelelő típussá alakíts.

### Átalakítás Boolean értékké (truthy/falsy értékek)

A `Boolean(value)` segítségével bármilyen értéket logikai értékké alakíthatsz.
Van egy rögzített értékhalmaz, az úgynevezett _falsy_ értékek, amelyek `false`-ra konvertálódnak.
A legfontosabbak: a `false`, a `0`, az üres string, a `null`, az `undefined` és a `NaN` _falsy_.

Minden más értékre a `Boolean` `true`-t ad vissza.
Ezeket az értékeket _truthy_-nak nevezzük.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

Figyeld meg, hogy a leírt szabályok miatt a `'0'`, a `'false'`, a `[]` és a `{}` **truthy** érték a JavaScriptben.

### Átalakítás számmá

A `Number(value)` segítségével egy értéket számmá alakíthatsz.
A string elején és végén álló szóközök figyelmen kívül maradnak, az üres string pedig `0`-vá konvertálódik.
Ha nem primitív értéket vagy olyan stringet próbálsz átalakítani, amely nem számot reprezentál, az eredmény `NaN` ([Not-A-Number][mdn-nan]).

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### Átalakítás stringgé

A `String(value)` segítségével egy értéket stringgé alakíthatsz.
Primitív értékek esetén pont azt kapod, amire számítasz.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

Tömbök esetén a `String` függvény minden elemre alkalmazza a stringkonverziót, majd az eredményeket vesszővel fűzi össze.
A [`join` metódust][mdn-join] magad is alkalmazhatod, például hogy testre szabd az elválasztót.
Figyeld meg, hogy ezekben az esetekben a `null` és az `undefined` üres stringgé konvertálódik.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

Objektumok esetén a `String` alapértelmezés szerint egy semmitmondó szöveget ad vissza.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## Automatikus típuskonverzió

Bizonyos kontextusokban a JavaScript automatikusan átalakít egy értéket egy másik adattípusra, mielőtt kiértékelne egy utasítást.
Ezt az implicit átalakítást _automatikus típuskonverziónak_ nevezzük.

### Boolean-kontextus

Amikor egy nem logikai értéket logikai kontextusban használunk, a JavaScript ugyanazokat a szabályokat alkalmazza, mint a `Boolean` függvény, hogy implicit módon átalakítsa az értéket.

Logikai értékké alakítás gyakran történik a következő esetekben:

- egy [elágazás][concept-conditionals] feltétele
- a [ternáris operátor][mdn-ternary] `?` első operandusa
- a logikai NOT operátor `!` operandusa
- a logikai AND `&&` és OR `||` operátorok operandusai (a kifejezés eredménye az egyik operandus, nem feltétlenül logikai érték)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### String-kontextus

Ha az összeadás `+` operátort primitív értékekre használjuk, és az egyik operandus string, akkor a másik is stringgé konvertálódik.
A konverzió logikája ugyanaz, mint a `String` függvény használatakor.
Ezután a két string összefűződik.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### Numerikus kontextus

Sok operátor a fentebb bemutatott `Number` függvény logikája szerint számmá konvertálja az operandusokat (ha szükséges).

- Aritmetikai operátorok: `+` (ha nincs benne string), `-`, `*`, `/`, `%`, `**`
- Az egyoperandusú plusz és negáció operátorok: `+`, `-`
- Relációs operátorok (nem string operandusok esetén): `>`, `>=`, `<`, `<=`
- Bitenkénti operátorok: `|`, `&`, `^`, `~`

Ha bármelyik operátorról többet szeretnél megtudni, nézd meg az [MDN operátorlistáját][mdn-operators].

A hibák elkerülése érdekében jó gyakorlat, ha ezen operátorok alkalmazása előtt mindig explicit módon meghívod a `Number` függvényt.
