# Névjegy

A [rekordok][records] olyan adatszerkezetek, amelyek az összetartozó információkat címkékkel együtt csoportosítják.
Hasonlítanak a JavaScript vagy a Java objektumaihoz, illetve a C vagy a Rust structjaihoz, de néhány lényeges dologban különböznek tőlük.

## Rekordok létrehozása

A rekordokat [kapcsos zárójelekkel hozzuk létre][create], az elemeiket pedig vessző választja el.

```elm
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

A rekord típusát is hasonló szintaxissal definiáljuk, azzal a különbséggel, hogy az egyenlőségjeleket (`=`) kettőspontok (`:`) váltják fel.

```elm
firefly : { name : String, creator : String, episodes : Int }
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

Ezeket a típusdefiníciókat ismételgetni körülményes, ezért gyakori megoldás, hogy egy [típusálnevet][record-types] használunk a definíció megosztására.

```elm
type alias TvSeries =
    { name : String
    , creator : String
    , episodes : Int
    }

firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

A típusálnév emellett automatikusan biztosít egy konstruktorfüggvényt is a rekordhoz.
Ez néha meglepő, mivel az Elmben a függvények nevének kisbetűvel kell kezdődnie, a típuskonstruktorok viszont ez alól kivételt jelentenek.

```elm
firefly : TvSeries
firefly = TvSeries "Firefly" "Joss Whedon" 14
```

## A rekordmezők elérése

A leggyakoribb módja annak, hogy [elérjük egy rekordpéldány valamelyik mezőjének értékét][access], a pontjelölés használata, például `firefly.creator`.
Az Elm-fordító emellett támogatja az olyan speciális elérési függvényeket is, amelyek ponttal (`.`) kezdődnek, mint például a `.creator`, és minden olyan rekordon működnek, amelyben van ilyen nevű mező.
Ez a második kivétel az alól a szabály alól, hogy a függvények nevének kisbetűvel kell kezdődnie.
Valójában a felhasználó által definiált függvények nevének is kisbetűvel kell kezdődnie, a két most megismert példát viszont nem a programozó, hanem a fordító állítja elő.

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

firefly.name
    --> "Firefly"

.creator firefly
    --> "Joss Whedon"
```

A rekordokat kötésekben is fel lehet _destrukturálni_ a [rekordok mintailesztésének][pattern-matching] segítségével.
A destrukturálás minden olyan rekordon működik, amelyben megvannak a megfelelő nevű mezők.

```elm
episodesCount : TvSeries -> Int
episodesCount { episodes } =
    episodes

complicatedCopy : TvSeries -> TvSeries
complicatedCopy show =
    let
        { name, creator } = show
    in
    { name = name
    , creator = creator
    , episodes = episodesCount show
    }
```

## Rekordok frissítése

A rekordok megváltoztathatatlanok, mint az Elmben minden, ezért ha egyszer definiáltunk egy rekordot, a mezőértékei soha nem változhatnak meg.
Létezik [egy speciális szintaxis, amellyel egy meglévő rekord másolatát hozhatjuk létre úgy, hogy közben egy vagy több mezőjét megváltoztatjuk][update].
Ez a szintaxis a függőleges vonal (`|`) jelölést használja, hogy megkülönböztesse az eredeti rekordot a megváltozó mezőktől, például így: `{ oldRecord | field1 = newValue }`.

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

updatedFirefly : TvSeries
updatedFirefly =
    { firefly | creator = "J Whedon", episodes = 15 }
```

## Rekordok összehasonlítása

Az Elm a [strukturális egyenlőséget][equality] használja, ami azt jelenti, hogy ugyanannak a rekordnak két, azonos értékekkel rendelkező példánya egyenlő.

```elm
firefly1 = TvSeries "Firefly" "Joss Whedon" 14
firefly2 = TvSeries "Firefly" "Joss Whedon" 14

firefly1 == firefly2
    --> True
```

## Kiterjeszthető rekordok

Az Elm a [strukturális típusosságot][structural-typing] is támogatja, ami azt jelenti, hogy ha egy függvény egy x és y mezővel rendelkező rekordot vár, akkor minden olyan rekorddal működik, amelyben megvannak ezek a mezők, például a 2D-s pontokkal, a 3D-s pontokkal, az űrhajókkal stb.
Az ilyen rekordtípusok definíciójában függőleges vonal (`|`) szerepel, például `{ a | x : Float, y : Float }`, és az Elm szóhasználatában „kiterjeszthető rekordoknak” nevezzük őket.
Ügyelj a különbségre egy típusdefinícióban szereplő függőleges vonal (`|`), amely kiterjeszthető rekord definícióját jelenti (`{ a | x : Int }`), és egy tényleges rekordpéldányban szereplő függőleges vonal (`|`) között, amely azt jelzi, hogy a rekord néhány mezőjét frissítjük.

```elm
point2d = { x = 1, y = 2 }
point3d = { x = 3, y = 4, z = 7 }

.x point2d --> 1
.x point3d --> 3

length : { a | x : Float, y : Float } -> Float
length vector =
    sqrt (vector.x * vector.x + vector.y * vector.y)

length point2d --> 2.236068
length point3d --> 5

translateX : { a | x : Float } -> { a | x : Float }
translateX vector =
    { vector | x = vector.x + 1 }

translateX point2d --> { x = 2, y = 2 }
translateX point3d --> { x = 4, y = 4, z = 7 }
```
