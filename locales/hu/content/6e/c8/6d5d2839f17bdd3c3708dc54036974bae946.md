# Bevezetés

Az Elixir elegáns szintaxist kínál a bináris adatokkal való munkához, ahogy azt a [bitstringek][exercism-bitstrings] kezelésére szolgáló `<<>>` speciális formánál már láttuk.

A binary típus a bitstring típus egy specializációja. A bitstringek tetszőleges hosszúak lehetnek (tetszőleges számú [bit][wiki-bit]), a binaryknél viszont a bitek számának maradék nélkül oszthatónak kell lennie 8-cal. Vagyis amikor binarykkel dolgozunk, gyakran [byte][wiki-byte] (8 bit) egységekben gondolkodunk. Egy byte `0` és `255` közötti egész számokat tud reprezentálni. A byte-értékekkel gyakran [hexadecimális][wiki-hexadecimal] formában dolgozunk: `0x00 - 0xFF`.

A binary literálokat a bitstring `<<>>` speciális formájával definiáljuk. Egy binary literál definiálásakor egész és string literálokat használhatunk. A 255-nél nagyobb egész értékek túlcsordulnak, és csak az egész szám utolsó 8 bitje kerül felhasználásra. Alapértelmezés szerint az értékre a `::binary` módosító kerül. A binaryket a `<>/2` operátorral fűzhetjük össze.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

A _null-byte_ a `<<0>>` másik neve.

## Mintázatillesztés bináris adatokon

A [mintázatillesztés][exercism-pattern-matching] a binarykre is kiterjed: egy bináris adat egy részére ugyanúgy illeszthetünk mintázatot, mint egy lista esetében.

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

A mintázatillesztés többi fajtájához hasonlóan ezt függvényszignatúrákban is használhatjuk arra, hogy több függvényklóz közül válasszunk.
