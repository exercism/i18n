# Utasítások

Ebben a feladatban segédfüggvények egy részét valósítod meg, hogy segíts egy fejlesztőnek megtisztítani az azonosítóneveket.

A 6 részfeladatban fokozatosan építed fel a `transform` függvényt, amely egyetlen karaktert alakít át, és a `clean` függvényt, amely stringeket alakít át.

Egy érvényes azonosító nulla vagy több betűből, aláhúzásjelből, kötőjelből, kérdőjelből és emojiból áll.

Ha üres stringet adsz át a `clean` függvénynek, akkor üres stringet kell visszaadnia.

## 1. Cseréld a kötőjeleket aláhúzásjelekre

Valósítsd meg a `transform` függvényt úgy, hogy a kötőjeleket aláhúzásjelre cserélje.

```fsharp
transform '-'  // => "_"
```

## 2. Távolítsd el az összes whitespace-t

Távolítsd el az összes whitespace karaktert.
Ebbe beletartozik a szöveg elején és végén lévő whitespace is.

```fsharp
transform ' '  // => ""
```

## 3. Alakítsd át a camelCase-t kebab-case formátumra

Módosítsd a `transform` függvényt, hogy a camelCase-t kebab-case formátumra alakítsa

```fsharp
transform 'D'  // => "-d"
```

## 4. Hagyd ki a számjegyeket

Módosítsd a `transform` függvényt, hogy elhagyja a számjegy karaktereket.

```fsharp
transform '7'  // => ""
```

## 5. Cseréld a görög kisbetűket kérdőjelekre

Módosítsd a `transform` függvényt, hogy a „α” és „ω” közötti görög betűket lecserélje.

```fsharp
transform 'β' // => "?"
```

## 6. Vond össze ezeket a műveleteket, hogy egy stringen működjenek

Valósítsd meg a `clean` függvényt, hogy ezeket a műveleteket egy teljes stringre alkalmazza.

A szabályokon kívül eső karaktereket változatlanul kell átengedni.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## String összeállítása karakterekből

Ezt a témát a tanterv későbbi részében részletesen is tárgyaljuk.

Egyelőre hasznos lehet tudni, hogy létezik egy [magasabb rendű függvény][higher-order-function], a [`String.collect`][string-collect], amely `char`-ok gyűjteményét alakítja stringgé egy általad megadott függvény segítségével.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```

[higher-order-function]: https://exercism.org/tracks/fsharp/concepts/higher-order-functions
[string-collect]: https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-stringmodule.html#collect
