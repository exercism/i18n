# Áttekintés

A Haskellben van egy `Num` nevű típus, amely az összes numerikus típus alaptípusa.
A Number típuson belül négy fő altípus található: [`Int`][int], [`Integer`][integer], [`Double`][double] és [`Float`][float].

A Haskellben kétféle egész típus létezik, amelyek egész számokat reprezentálnak.
Az `Int` rögzített méretű egész, míg az `Integer` tetszőleges pontosságú egész.

Az `Integer` bármekkora számot tárol, egészen a géped memóriájának határáig, míg az `Int` a 32 vagy 64 biten kifejezhető pozitív és negatív egészek halmazának felel meg (garantáltan legalább a -2^29 és 2^29 - 1 közötti tartományban).

Negatív számok írásakor használj zárójelet, hogy elkerüld a kétértelműséget.

```haskell
1

(-1)
```

A `Float` a valós számok halmazának felel meg, a számítógép pontossága által korlátozva.
A számokon definiált műveletek általában vagy az egyik, vagy a másik típuson működnek, de nem mindkettőn.
A `Double` kétszeres pontosságú lebegőpontos szám.

```haskell
10.5
```

## Átalakítás egészek és lebegőpontos számok között

A `toFloat` függvénnyel egy `Int` vagy `Integer` értéket `Float`-tá alakíthatsz.

```haskell
toFloat 1
-- -> 1.0
```

Létezik a `fromIntegral` is, amely bármilyen numerikus típust a szükséges, kikövetkeztetett numerikus típusra alakít.

```haskell
fromIntegral 1
-- -> 1.0
```

Ha egy `Float`-ot `Int`-té szeretnél alakítani, használhatod a [`round`][round], a [`floor`][floor] vagy a [`ceiling`][ceiling] függvényt.
A `round` függvény a legközelebbi egészre kerekít, a `floor` lefelé, a `ceiling` pedig felfelé kerekít.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## Aritmetikai operátorok

A numerikus típusokon használhatod az [alapvető aritmetikai operátorokat][math].
Az operátorok: `+`, `-`, `*`, `/` és `%`.
Amikor ezeket az operátorokat használod, a számok típusának meg kell egyeznie.
A `fromIntegral` függvény átalakítja az értékeket, hogy a típusok egyezzenek.

### Összeadás, kivonás és szorzás

A `+` operátor az összeadásra, a `-` operátor a kivonásra, a `*` operátor pedig a szorzásra szolgál.

| Operátor | Példa          |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Osztás

Az osztással számokat oszthatsz el.
Az osztást a `/` operátor végzi.
Az eredmény mindig lebegőpontos szám lesz.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
Egyes programozási nyelvekben a nullával való osztás eredménye hiba.

A Haskellben a nullával való osztás eredménye `Infinity` vagy `-Infinity`.
Az egyetlen kivétel a nulla osztása nullával, aminek az eredménye `NaN` (Not a Number).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## Egészosztás

Az egészosztás egész számok elosztására szolgál, és az eredmény egész részét adja vissza.
A Haskellben két egészosztó függvény van, amelyek abban különböznek, hogyan kerekítenek, ha az eredmény negatív:

- A `div` lefelé, a negatív végtelen felé kerekít.
- A `quot` a nulla felé kerekít.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Ha egészosztásnál nullával osztasz, az kivételhez vezet.
Ez eltér a szokásos osztástól.
~~~~

### Maradék

Egy egészosztás maradékát a `mod` vagy a `rem` segítségével kaphatod meg.
Abban különböznek, hogy milyen előjelű az eredmény, ha az egyik szám negatív:

- A `mod` a `div`-hez tartozik, és az eredményének előjele az osztóéval egyezik.
- A `rem` a `quot`-hoz tartozik, és az eredményének előjele az osztandóéval egyezik.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Bármely `x` és `y` esetén (ahol `y` nem nulla) érvényesek a következő törvények:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Ha mindkét szám pozitív, a `div` és a `quot` ugyanazt az eredményt adja, akárcsak a `mod` és a `rem`.
Ebben az esetben a `quot` és a `rem` kicsit hatékonyabb lehet, mert a `div`-nek és a `mod`-nak plusz lépésekre van szüksége a negatív számok kezeléséhez.
~~~~

~~~~exercism/caution
Ha a `mod` vagy a `rem` használatakor nullával osztasz, az kivételhez vezet.
Ez eltér a szokásos osztástól.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## Hatványozás

A Haskellnek három „hatványozó” operátora van, amelyek másképp működnek, és más-más argumentumtípusokat fogadnak.

- `**` Két **lebegőpontos számot** fogad, és logaritmus segítségével számítja ki a hatványt.
- `^^` Egy **lebegőpontos** számot vesz át, és pozitív vagy negatív **egész** kitevőre emeli.
- `^` **Bármilyen numerikus típust** fogad, és **pozitív egész** kitevőre emeli.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## A műveletek sorrendje és a zárójelek

A Haskell engedi a zárójelek (`()`) használatát, amelyekkel kifejezéseket csoportosíthatsz.
Ez akkor hasznos, ha meg szeretnéd változtatni a műveletek sorrendjét.

Ha több aritmetikai operátort használsz, a műveletek sorrendje ugyanaz, mint a matematikában, más néven [PEMDAS][pemdas].
Ez a zárójelek (`()`), a kitevők (`**`), a szorzás (`*`) és az osztás (`/`), majd az összeadás (`+`) és a kivonás (`-`) sorrendjét követi.

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
