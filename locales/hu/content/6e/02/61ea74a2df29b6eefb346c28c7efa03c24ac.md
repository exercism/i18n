# Bevezetés

A Common Lispben egy függvénynek lehetnek opcionális argumentumai. Ezeket a lambda-listában az `&optional` lambda-lista kulcsszó jelöli. Ha egy paramétert nem adunk meg, akkor az a `nil` értéket kapja. Ha több opcionális paraméter van, azok sorrendben kapják meg az értéküket. Az opcionális paraméterekhez alapértelmezett érték is megadható. Végül minden opcionális paraméterhez megadható egy szimbólum, amely igaz vagy hamis értéket vesz fel attól függően, hogy a függvény hívója megadta-e az adott paramétert (ezt nevezik „supplied-p paraméternek”).

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
