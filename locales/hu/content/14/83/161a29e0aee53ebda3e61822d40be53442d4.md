# Bevezetés

A `MACRO:` deklaráció olyan, mint a `:`, de a törzse *fordítási időben* fut le, és egy quotationt kell visszaadnia. A fordító ezt a visszaadott quotationt illeszti be a makróhívás helyére. Mivel a törzs közönséges Factor-kód, az eredményül kapott quotation felépítése nem más, mint szavak sorozatainak a manipulálása.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

A makró bemenetei *a hívás helyén szereplő literálok*. Ha nem literál értéket adsz át, a fordító megtagadja a specializálást, mert a makró törzsének fordítási időben van szüksége az értékre, nem futásidőben.

Közeli rokona a `<< … >>` beolvasáskor kiértékelt blokk, amely tetszőleges Factor-kódot futtat fordítási időben, anélkül hogy be kellene tartania a quotation visszaadására vonatkozó szerződést. Mindkettő a Factor [`macros`][macros] gépezetéhez tartozik.

[macros]: https://docs.factorcode.org/content/vocab-macros.html
