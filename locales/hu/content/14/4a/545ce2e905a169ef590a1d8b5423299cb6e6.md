# Részletesen

A string szöveges adatot képvisel.
A Swiftben a [`String`][strings-and-characters] `Character` értékek rendezett gyűjteménye, ahol minden karakter egy Unicode-karaktert képvisel.

Stringet string literál segítségével hozhatsz létre; a string literál olyan karaktersorozat, amelyet kettős idézőjelek (`"`) zárnak közre.
Többsoros stringekhez használj három kettős idézőjelet (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

A Swift stringjei zökkenőmentesen illeszkednek a Foundation keretrendszer [`NSString`][nsstring-docs] osztályához, ami kiterjedt szövegfeldolgozási lehetőségeket kínál.

## Karakterek

A `Character` egyetlen kiterjesztett grafémklasztert képvisel, azaz egy ember által olvasható karaktert, amely egy vagy több [Unicode skalárértékből][unicode-scalar-values] áll.
A Unicode skalárérték egy 21 bites kódpont a `U+0000` és `U+D7FF` közötti zárt tartományban, illetve a `U+E000` és `U+10FFFF` közötti zárt tartományban.

```swift
let aChar: Character = "A"
```

## Típuskövetkeztetés

Amikor string literált írsz, a Swift automatikusan `String`-ként következteti ki a típusát.
Ahhoz, hogy egyetlen karaktert `Character`-ként tárolj, explicit típusannotációt kell megadnod:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Összefűzés

A stringeket a `+` összeadásoperátorral fűzheted össze:

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Egy `Character`-t nem fűzhetsz közvetlenül egy `String`-hez a `+` használatával anélkül, hogy előbb stringgé alakítanád a karaktert.
A [`append(_:)`][append] metódussal viszont közvetlenül egy módosítható stringhez fűzhetsz egy stringet vagy egy karaktert:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## String interpoláció

A [string interpoláció][string-interpolation] segítségével string literálokba ágyazott konstansokból, változókból, literálokból és kifejezésekből építhetsz fel egy stringet.
Minden kifejezést zárójelbe teszel, amelyet egy visszaperjel előz meg (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## A stringek és a karakterek tulajdonságai

A stringek és a karakterek több tulajdonságot kínálnak a tartalmuk vizsgálatához.

### A stringek tulajdonságai

A gyakori stringtulajdonságok közé tartozik például:

| Tulajdonság | Leírás                                         | Példa                                  |
| ----------- | ---------------------------------------------- | -------------------------------------- |
| `isEmpty`   | `true`-t ad vissza, ha a stringnek nincs karaktere | `"Hello".isEmpty` értéke `false`       |
| `count`     | A stringben lévő karakterek számát adja vissza | `"Hello".count` értéke `5`             |

A tulajdonságok teljes listájáért nézd meg az [Apple String dokumentációját][string-docs].

### A karakterek tulajdonságai

A gyakori karaktertulajdonságok közé tartozik például:

| Tulajdonság    | Leírás                                        | Példa                                 |
| -------------- | --------------------------------------------- | ------------------------------------- |
| `isLowercase`  | `true`-t ad vissza, ha a karakter kisbetűs    | `"a".isLowercase` értéke `true`       |
| `isUppercase`  | `true`-t ad vissza, ha a karakter nagybetűs   | `"A".isUppercase` értéke `true`       |
| `isNumber`     | `true`-t ad vissza, ha a karakter számjegy    | `"1".isNumber` értéke `true`          |
| `isWhitespace` | `true`-t ad vissza, ha a karakter whitespace  | `" ".isWhitespace` értéke `true`      |

A tulajdonságok teljes listájáért nézd meg az [Apple Character dokumentációját][character-docs].

## Típuskonverzió

Más típusokat a `String(_:)` kezdőértékkel alakíthatsz stringgé, amely támogatja az olyan szabványos típusokat, mint az `Int`, a `Double` és a `Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Speciális karakterek

A Swift string literáljai több [escape-szekvenciát][special-characters] is támogatnak a speciális karakterekhez:

| Szekvencia | Leírás                               |
| ---------- | ------------------------------------ |
| `\0`       | Null karakter                        |
| `\\`       | Visszaperjel                         |
| `\t`       | Vízszintes tabulátor                 |
| `\n`       | Soremelés (újsor)                    |
| `\r`       | Kocsivissza                          |
| `\'`       | Egyszeres idézőjel                   |
| `\"`       | Kettős idézőjel                      |
| `\u{n}`    | Tetszőleges Unicode skalár (hexadecimális) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
