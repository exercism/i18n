# Telepítés

Ez a kurzus a ReScript 12-t használja, és a [Node.js][nodejs] 22-es vagy újabb verziójára épül.
Sok rendszeren ez már előre telepítve van, vagy korábban esetleg egy másik kurzushoz már telepítetted.

Nyiss egy terminált, és futtasd:

```sh
node -v
```

Ha a Node nincs telepítve, vagy régebbi verzió szerepel, kövesd a platformodhoz tartozó [hivatalos Node.js-telepítési útmutatót][nodejs-install].

## A függőségek telepítése

Minden ReScript-feladat egy önálló npm-projekt.
Miután az [Exercism CLI][exercism-cli] segítségével letöltöttél egy feladatot, telepítsd a projekt függőségeit, köztük a ReScriptet, és már kezdheted is:

```sh
cd /path/to/exercise
npm install
```
