# Utasítások

Az Isaac's Asteroid Exploration Co. igénylési osztálya rád bízta, hogy javítsd a birtokigénylő rendszerük teljesítményét.

Valahányszor egy aszteroida kitermelésre készen áll, a spekulátorokat meghívják, hogy igényt tartsanak egy földterületre. Az aszteroida földterülete nem átfedő, téglalap alakú parcellákra van felosztva. A méreteik eltérőek, de mindegyik oldala párhuzamos a koordinátatengelyekkel. A spekulátorok a koordináták megadásával igénylik meg az egyik parcellát.

A célod, hogy egy nagy teljesítményű rendszert fejlessz ki, amely kezeli a földrohamot, ami a múltban a weboldal összeomlását okozta.

A mértékegység 100 méter, de ezeknél a feladatoknál figyelmen kívül hagyható.

## 1. Definiálj egy pontot

Definiálj egy `struct` típust, amely az `x` és `y` koordinátákat tárolja.
Ezek meglehetősen kis, nem negatív egészek, ezért használd a `UInt16` típust.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Definiálj egy Plot típust

Mivel minden parcellának téglalap alakúnak kell lennie, vízszintes és függőleges oldalakkal, ezért csak két szemközti sarokra van szükség a meghatározásukhoz.

Valósítsd meg a `Plot` structot, amely a konstruktorában két Coord structot fogad.

A `Plot` legyen kulcsszavas struct, `bottom_left` és `top_right` mezőkkel.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Ellenőrizd, hogy az igényedet már bejegyezték-e

Nagy a verseny ezekért az igényekért, ezért mielőtt a tiédet elfogadják, összevetik a nyilvántartásban szereplő meglévő igényekkel.

Valósítsd meg az `is_claim_staked()` függvényt, amely megállapítja, hogy egy igényt már bejegyeztek-e.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. A spekulátorok a parcella sarokkoordinátáinak megadásával igényelhetik a területüket

Valósítsd meg a `stake_claim!()` módosító függvényt, amellyel egy igény bejegyezhető.

Ha ugyanazt az igényt már bejegyezték, add vissza a `false` értéket.

Ha egy új igény lehetséges, add hozzá a nyilvántartáshoz, és add vissza a `true` értéket.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Keresd meg egy parcella hosszabbik oldalának hosszát.

Valósítsd meg a `get_longest_side()` függvényt, amely visszaadja egy igény hosszabbik oldalát (vízszintes vagy függőleges).

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Keresd meg a leghosszabb oldalú igényelt parcellát kutatási célokra

Valósítsd meg a `get_claim_with_longest_side()` függvényt, amely megvizsgálja az összes bejegyzett igényt, és visszaadja a leghosszabb oldalú igényt vagy igényeket.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

A Plot(oka)t `Set`-ként add vissza: egy elemmel, ha egyetlen leghosszabb parcella van, többel, ha holtverseny alakul ki.
