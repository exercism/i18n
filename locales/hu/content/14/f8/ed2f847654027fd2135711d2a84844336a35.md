# Bevezetés

Go-ban egy `slice` elemein `for` és egy index segítségével is végigmehetsz, de használhatod a `range`-et is.
A `range` segítségével egy `map` vagy egy `channel` elemein is végigmehetsz.
Ez a fogalom a `map` feletti iterálást mutatja be, a `channel` feletti iterálás viszont nem része ennek a fogalomnak.

Minden iteráció két értéket ad vissza: az indexet/kulcsot és az adott indexen/kulcson lévő elem egy másolatát.

## Iterálás egy `slice` felett

Gyerekjáték: végigmegy a `slice` elemein, a várt sorrendben.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Iterálás egy `map` felett

A `map` feletti iterálás új problémát vet fel.
A sorrend most véletlenszerű.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
Úgy tűnhet, hogy a fenti kimenet hibás, hiszen az ember arra számítana, hogy a `map` deklarálásakor szereplő első kulcs-érték pár, `9 10`, lesz az elsőként kiírt, és nem az utolsó.
A `map` azonban természeténél fogva rendezetlen: nincs első és utolsó kulcs-érték pár.
Ezért amikor egy `map` bejegyzésein iterálsz, a bejegyzések bejárási sorrendje véletlenszerű lesz, és nem követ semmilyen meghatározott mintát.
Ez azt jelenti, hogy a fenti kimenet lehetséges, de eltérhet attól, amit akkor kapsz, ha magad is lefuttatod a kódot.
Ha többet szeretnél megtudni erről, lásd a [Go nyelvi specifikáció: range záradék](https://go.dev/ref/spec#RangeClause) oldalt.
~~~~

## Iterálás a kulcs vagy az érték kihagyásával

Go-ban egy fel nem használt változó hibát okoz fordításkor.
Néha csak az értékre van szükséged, ahogy az első példában is:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Az `i`-t lecserélheted `_`-ra, ami megmondja a fordítónak, hogy nem használjuk ezt az értéket:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Ha csak az indexet szeretnéd kiírni, lecserélheted az `x`-et `_`-ra, vagy egyszerűen elhagyhatod a deklarációt:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

Végül, de nem utolsósorban: ha végre kell hajtanod valamilyen műveletet, de nem érdekelnek sem a `slice`, sem a `map` értékei és kulcsai, akkor mind az indexet, mind az értéket elhagyhatod:

```go
xi := []int{10, 20, 30}
count := 0
for range xi {
  count++
}
// count value:
// 3
```
