# Utasítások

Izzy szenvedélyes madárfigyelő, aki számon tartja, hány madár járt a kertjében az egyes napokon.

Most téged kért meg, hogy segíts új szintre emelni a madárfigyelését, és hogy készíts néhány eszközt, amelyek segítenek neki nyomon követni és feldolgozni az adatokat.

Úgy döntöttél, hogy az adatokat egész számok listájaként tárolod. A lista első száma azoknak a madaraknak a száma, amelyek ma jártak a kertedben, a második a tegnapi, és így tovább.

## 1. Ellenőrizd, hány madár járt ma

Valósítsd meg a `today` függvényt. Ez egy napi madárszámokat tartalmazó listát kap, és visszaadja a mai nap számát. Ha a lista üres, `0`-t adjon vissza.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Növeld eggyel a mai nap számát

Valósítsd meg az `increment_day_count` függvényt. Ez egy napi madárszámokat tartalmazó listát kap, és a mai naphoz tartozó számot eggyel növeli. Ha a lista üres, `[1]`-et adjon vissza.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Ellenőrizd, volt-e olyan nap, amikor egyetlen madár sem járt a kertben

Valósítsd meg a `has_day_without_birds` függvényt. Ez egy napi madárszámokat tartalmazó listát kap. Adjon vissza `True`-t, ha legalább egy olyan nap volt, amikor egyetlen madár sem járt a kertben, egyébként pedig `False`-t. Ha a lista üres, az úgy számít, hogy _még_ nem jegyeztél fel madarat; ekkor `False`-t adjon vissza.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Számítsd ki, összesen hány madár járt a kertben

Valósítsd meg a `total` függvényt. Ez egy napi madárszámokat tartalmazó listát kap, és visszaadja, hogy összesen hány madár járt a kertedben attól fogva, hogy elkezdted gyűjteni az adatokat.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Számítsd ki a forgalmas napok számát

Némelyik nap forgalmasabb, mint a többi. Forgalmas nap az, amikor legalább öt madár járt a kertedben.

Valósítsd meg a `busy_days` függvényt. Ez egy napi madárszámokat tartalmazó listát kap, és visszaadja a forgalmas napok számát.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
