# Üzemanyag-támogatás

## A probléma leírása

Az ABC Corp minden munkavállalója korlátlan üzemanyag-támogatást kap. A munkavállalóknak minden alkalommal rekordot kell küldeniük, amikor megtankolják a járművüket. Ezek a rekordok ugyanabba a CSV-fájlba kerülnek, és a hónap végén dolgozzák fel őket.

A digitális üzemeltetési csapat tagjaként a feladatod, hogy beolvasd ezt a CSV-fájlt, és az eredményeket egy másik CSV-fájlba írd. A kimeneti fájlban minden munkavállalóhoz szerepeljen egy bejegyzés a következő adatokkal:

- Munkavállaló száma
- Tankolások száma
- Teljes üzemanyagköltség
- Összes gallon
- Összes megtett mérföld

Két `string` argumentumot kapsz.

1. A bemeneti CSV-fájl elérési útja
1. A kimeneti CSV-fájl elérési útja

A bemeneti CSV-fájl `n` sort tartalmaz, és minden sor a következő formában van.

| Oszlop neve      | Ballerina-típus |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

A kimeneti fájlban minden munkavállalóhoz szerepeljen egy bejegyzés, `employee_id` szerint növekvő sorrendbe rendezve. Minden sor a következő formában van:

| Oszlop neve      | Ballerina-típus |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Megkötések

- A bemeneti CSV-fájl sorainak száma `n`: 2 <= n <= 1000
- A cég munkavállalóinak száma: 97
- Az üzemanyag ára gallononként értendő
- Nincsenek hiányzó tankolási rekordok

## 1. példa

- Bemenet: `example01_input.csv`


```csv

```

## Tippek

- A CSV-fájlok beolvasásához és írásához használd a [`ballerina/io` modult](https://lib.ballerina.io/ballerina/io/latest)
- A bemeneti és a kimeneti fájl nem tartalmaz, és nem is tartalmazhat fejlécet
