# Részletesen

Az `assocs` egy [protokoll][assoc-protocol], nem egyetlen adattípus. A hashtáblák (`H{ }`),
az asszociációs listák (`{ key value }` párok sorozatai) és a fa alapú térképek is mind
megvalósítják, és a legtöbb, assoc-okra vonatkozó word ugyanúgy működik mindegyikükön.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

A teljes felület széles: rendezett iteráció, leképezés, szűrés. A feladatok szintjén
viszont a legtöbbször csak egy kis halmazra van szükség:

| word        | hatás                                         |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` megkülönbözteti az f értéket a hiányzótól |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`, módosítja           |
| `change-at` | `( key assoc quot -- )`, ahol a `quot` `( old -- new )` |
| `inc-at`    | `( key assoc -- )`, `+1`, és beszúrja az `1` értéket, ha még nincs benne |
| `delete-at` | `( key assoc -- )`, módosítja                 |
| `>alist`    | `( assoc -- pairs )`                          |

A `sort-keys` és a `sort-values` (a `sorting` modulban) a választott mező szerint rendezi
az asszociációs listát.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
