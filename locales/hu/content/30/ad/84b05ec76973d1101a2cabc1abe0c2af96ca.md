# Bevezetés

Egy tiszta funkcionális nyelvben, mint az Elm, egy ugyanazokkal az argumentumokkal meghívott függvénynek mindig ugyanazt az értéket kell visszaadnia.
Ezért egy `rand : Int` típusszignatúrájú függvényt csak `rand = 4`-ként lehet megvalósítani, ami nem sok jót ígér véletlen egészek generálásához.

Szóval hogyan generálunk véletlen értékeket Elmben?
Két részre bontjuk a problémát: először leírjuk a `Random.Generator a` segítségével, hogy milyen értéket szeretnénk generálni, aztán generálunk egy értéket.

Az első módja az értékgenerálásnak, hogy létrehozunk egy `Random.Seed`-et az `initialSeed : Int -> Seed` segítségével, majd használjuk a `step : Generator a -> Seed -> ( a, Seed )` függvényt, amely visszaad egy értéket és egy új magot.
Vegyük észre, hogy mindkét függvény tiszta, így ha kétszer hívjuk meg őket ugyanazokkal az argumentumokkal, ugyanazokat az értékeket kapjuk.

A második módja az értékgenerálásnak a `generate : (a -> msg) -> Generator a -> Cmd msg` használata, de ezt csak egy Elm-alkalmazáson belül lehet megtenni.
Ebben az esetben az Elm futtatókörnyezet a `step` mellett külső, nem tiszta erőforrásokat is használhat magok generálásához.

Mostantól a generátorokra összpontosítunk.

Képzeljük el a példák kedvéért, hogy az `initialSeed` és a `step` segítségével definiáltunk egy `generate : Int -> Generator a -> List a` függvényt, amely egy generátorból adott számú értéket generál.

A `Random` modul két alapvető generátort biztosít egészek és lebegőpontos számok generálására egy adott tartományon belül:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

Ezeket az értékeket kombinálhatjuk tuple-ökké vagy értéklistákká:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

Az `elm-community/random-extra` csomag sokkal több generátort kínál különféle adatszerkezetekhez: stringekhez, dátumokhoz, szótárakhoz, tömbökhöz, halmazokhoz stb.

Létrehozhatunk olyan generátorokat, amelyek csak egyetlen értéket adnak vissza, a `Random.constant` használatával:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

Egyenlő valószínűséggel választhatunk véletlenszerűen a megadott elemek közül a `Random.uniform` segítségével:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

A `Random.uniform` két argumentumot vesz fel (`Red` és `[Green, Blue]`), hogy garantálja, hogy legalább egy választható érték legyen, mivel egyetlen lista üres is lehet.

A valószínűségeket a `Random.weighted` segítségével is módosíthatjuk:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

Az értékeknek nem kell 100-at kiadniuk, úgyis újranormalizálódnak.

A `Random.map` segítségével elérhetjük egy generátor belsejét:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

A `Random.map2`-től egészen a `Random.map5`-ig használhatjuk ezeket több generátor kombinálására:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

Bonyolultabb felhasználásokhoz itt van a `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, amely egy generátor által generált értéket használhat fel egy másik létrehozásához:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

Néha hasznos egy generátort rekurzívan önmagára hivatkozva definiálni.
Ilyen esetekben szükség lehet a `Random.lazy` használatára, hogy a fordító ne göngyölítse ki végtelenül a generátort.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

Ez a példa kicsit nehéz, úgyhogy bontsuk szét.

A `Peano` egy olyan típus, amely pozitív egészeket reprezentál: a `Zero` a 0, a `Next(Zero)` az 1, a `Next(Next(Zero))` a 2, stb.
A `peano` definiálásával véletlen `Peano` számot kapunk.

Először is jegyezzük meg, hogy a `Random.lazy` nem tesz hozzá semmit a logikához, csupán megakadályozza a fordítót abban, hogy a `peano`-t vég nélkül `peano`-ba írja.

A `Random.uniform` segítségével választunk a nulla (50% valószínűséggel) és egy másik `Peano` szám plusz egy (50% valószínűséggel) között.
Az előző példától eltérően azonban a `Random.uniform` nem értékek közül választ (mint a `Zero`), hanem generátorok közül (mint a `Random.constant Zero`), mert magát a `peano`-t szeretnénk használni.
Ez azt jelenti, hogy a `Random.uniform` egy `Generator (Generator Peano)` típusú értéket ad vissza, ami nem az, amire szükségünk van.

A generátor „kilapításához” átküldjük azt a `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` függvénybe, ahol a `b` a `Peano` legyen.
Mivel a `Generator a` itt `Generator (Generator Peano)`, az `a` szükségszerűen `Generator Peano`, és az `(a -> Generator b)` függvény típusa `(Generator Peano -> Generator Peano)` kell legyen.
Nem akarunk semmit módosítani, ezért az `identity` a megfelelő választás.

Végül milyen számokat fog a `peano` generálni?
Tudjuk, hogy az esetek 50%-ában 0-t ad, vagy az esetek 50%-ában önmaga egy másik iterációját plusz egyet.
Ez azt jelenti, hogy a számok 0 (az esetek 50%-ában), 1 (25%-ában), 2 (12%-ában), 3 (6%-ában) stb. lesznek.
A `peano` tetszőlegesen nagy számokat generálhat, de exponenciálisan csökkenő valószínűséggel.
