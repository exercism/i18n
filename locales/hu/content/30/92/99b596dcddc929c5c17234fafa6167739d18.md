# Utasítások

Ebben a feladatban egy New York-i szépségszalon időpontütemezőjén fogsz dolgozni, amely 2012. szeptember 15-én nyílt meg.

Öt részfeladatod van, amelyek mindegyike az időpontok dátumaival foglalkozik.
Az időpontok 24 órás időformátumban vannak (nincs AM/PM).

## 1. A csupa számból álló időpont dátumának értelmezése

Valósítsd meg a `schedule_appointment()` függvényt, amely egy időpont szöveges reprezentációját a megfelelő `DateTime` formátumba alakítja.

Vedd figyelembe, hogy a bemenet amerikai stílusú hónap/nap/év sorrendben van.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Annak ellenőrzése, hogy egy időpont már elmúlt-e

Valósítsd meg a `has_passed()` függvényt, amely egy időpontot kap, és ellenőrzi, hogy az időpont a múltban van-e:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Annak ellenőrzése, hogy az időpont délutánra esik-e

Valósítsd meg az `is_afternoon_appointment()` függvényt, amely egy időpontot kap, és ellenőrzi, hogy az időpont délutánra esik-e (>= 12:00 és < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Az időpont dátumának és idejének leírása

Valósítsd meg a `description()` függvényt, amely egy időpontot kap, és visszaadja az adott dátum és idő leírását:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. Az évforduló dátumának visszaadása

Valósítsd meg az `anniversary_date()` függvényt, amely visszaadja az idei évforduló dátumát, ami szeptember 15.

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
