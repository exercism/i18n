# Részletesen

Az Elm [`Array`][array] típusa gyors, módosíthatatlan gyűjtemény, amely nulla vagy több azonos típusú értéket tartalmaz.
Mivel a tömbök módosíthatatlanok, ha egyszer létrehoztál egy tömböt, az értéke soha nem változik.
A tömböknek nincs literál szintaxisa (ellentétben a listával), ezért helyette az Array.fromList szintaxist használjuk.
Például egy `Array`, amelyben „a”, „b” és „c” található, általában így jelenik meg: `Array.fromList ["a", "b", "c"]`.
Ezt láthatod a konzol kimenetén, a debuggerben és más hasonló helyeken.

A `List`-tel ellentétben, amely [alapértelmezés szerint importált][default-imports], az `Array` modult explicit módon importálni kell, az `import Array` utasítással vagy hasonlóval.

A listák típusmegjelölése a következőképpen adható meg

```elm
Array String --> an array of String
Array Int --> an array of Int
```

A tömbök a következőképpen hozhatók létre:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

Egy tömbhöz az `Array.push` függvénnyel adhatsz hozzá elemeket:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

A tömböket az `Array.append` függvénnyel fűzheted össze:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

Egy tömb elemének lekéréséhez az `Array.get` függvényt használod:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

Egy tömb elemét az `Array.set` függvénnyel állíthatod be:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

A tömböket a [`Array` modulban][array-module] definiált függvényekkel kezelheted.

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

Minden függvény és operátor, amely úgy tűnik, hogy módosít egy `Array`` (such as adding an element), will actually return a new `Array`-t ad vissza.
A teljesítmény általában mégsem jelent problémát, mert az `Array` implementációja megakadályozza a szükségtelen allokációkat és másolásokat.
