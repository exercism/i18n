# Névjegy

Az objektuminicializálók a konstruktorok alternatívái. A szintaxis nem más, mint vesszővel elválasztott név=érték párok listája, ahogy az alábbi példa mutatja:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

A gyűjteményeket is inicializálhatod ezzel a módszerrel. Ez általában vesszővel elválasztott listákkal történik, ahogy itt látható:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Ez a megközelítés (és szintaxis) bármely olyan osztállyal használható, amely megvalósítja az `IEnumerable` interfészt, és rendelkezik `Add()` metódussal.

A mezőket tetszőleges sorrendben felsorolhatod, vagy akár teljesen el is hagyhatod.

A szótárak a következő szintaxist használják:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

Az inicializált mezőknek elérhetőnek kell lenniük a hívó számára. Ez általában azt jelenti, hogy `public` vagy `internal` láthatóságúnak kell lenniük.

A nyelv tervezői és a vezető szakemberek körében erős törekvés mutatkozik a változtathatatlanság felé, ezért az így inicializált objektumok változtathatóságát hátrányként tartják számon. Vannak javaslatok arra, hogy a nyelv következő verziójában, a C# 9-ben bevezessenek egy `init` záradékot, ami orvosolhatja ezt.

- Az [objektuminicializáló][object-initializers] dokumentációja leírja, hogyan kell használni az inicializálókat.
- A [gyűjteményinicializáló][collection-initializers] dokumentációja betekintést ad abba, hogyan használhatók az inicializálók szótárakhoz és listákhoz hasonló gyűjteményekkel.
