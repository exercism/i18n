# Bevezetés

A Clojure-ben egy érték névhez kötését _var_-nak nevezik. A legfelső szintű (globális) var-ok hasonlítanak más nyelvek konstansaihoz, de a dinamikus fejlesztés megkönnyítése érdekében gyakran újra szokták definiálni őket.

A legfelső szintű var-okat a `def` segítségével definiáljuk:

```clojure
(def fingers 10)
```

A `defn` makróval nulla vagy több argumentumot fogadó függvényt definiálhatunk. Egy függvény mindig a törzsében szereplő utolsó kifejezés eredményét adja vissza.

```clojure
(defn add [x y]
  (+ x y))
```

Egy függvény meghívásához meg kell adni a nevét, és minden paraméteréhez át kell adni egy argumentumot.

```clojure
(def five (add 2 3))
```

A Clojure-ben egy függvényt vagy értéket csak _azután_ használhatsz, hogy definiáltad. Ha még a definiálása előtt használod, fordítási hibát kapsz.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

A Clojure-ben a whitespace-nek a formázáson kívül nincs jelentősége.

A Clojure függvényei és var-jai névterekbe szerveződnek. Egy névtér összetartozó funkcionalitást csoportosít, és a `ns` makróval definiáljuk:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

A Clojure kétféle kommentet támogat. Az egysoros kommenteket `;` előzi meg, a `comment` forma pedig arra szolgál, hogy megakadályozza a `(comment` és a `)` közötti minden kifejezés kiértékelését.
