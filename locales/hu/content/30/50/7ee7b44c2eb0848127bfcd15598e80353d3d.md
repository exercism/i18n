# Kiegészítés az útmutatóhoz

## Tippek

A feladat teljesítéséhez implementálnod kell a `score` függvényt,
amely egy bowling-*dobásokból* álló sorozatot vesz át, és visszaadja a
végeredményt vagy a megfelelő hibát:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Ezeket a definíciókat már megtalálod a kódban, de magát a függvényt
neked kell definiálnod.

Ne feledd, hogy a tesztkészlet a dobásokat nullától kezdve számozza.
