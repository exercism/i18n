# Tesztek

A mellékelt teszteket DrRacketben vagy a parancssorból is futtathatod.

Ha DrRacketben szeretnéd futtatni a tesztet, egyszerűen nyisd meg a tesztfájlt, és kattints a jobb felső sarokban lévő „Run” gombra.

Ha a parancssorból szeretnéd futtatni a tesztet, egyszerűen futtasd a feladat könyvtárából. Ha például a tesztcsomag neve `hello-world-test.rkt`, akkor a következő parancsot futtathatod:

```
raco test hello-world-test.rkt
```

ami a következőt jeleníti meg:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
