# Bevezetés

A structok a [map-ekre][exercism-maps] épülő kiterjesztések, amelyek fordítási idejű ellenőrzéseket és alapértelmezett értékeket biztosítanak. A struct a nevét arról a modulról kapja, amelyben definiálják. Structot a `defstruct` konstrukcióval definiálhatsz. Ez a konstrukció általában közvetlenül a moduldefiníció után következik. A `defstruct` vagy atomok listáját fogadja el (ilyenkor az alapértelmezett érték `nil`), vagy kulcsszólistát (megadott alapértelmezett értékekkel). Az alapértelmezett érték nélküli mezőknek meg kell előzniük az alapértelmezett értékkel rendelkező mezőket.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Mezők elérése és frissítése

Mivel a structok map-ekre épülnek, a legtöbb map-függvénnyel lekérhetjük és módosíthatjuk az értékeket. A structokhoz az _Access Behaviour_ **nincs** implementálva. Helyette a structmezők eléréséhez a _statikus elérési operátor_ `.` használata javasolt.

- mezőértékek lekérése és kiolvasása:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- mezőértékek frissítése

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Mintailesztés

A structok mintailesztésben használhatók a struct nevével vagy anélkül is.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Ha a mintába beleteszed a struct nevét, biztosíthatod, hogy a bal és a jobb oldal is ugyanolyan típusú struct legyen.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## A mezőértékek kötelező megadása

A `@enforce_keys` modulattribútummal megadhatod a mezőkulcsok listáját, hogy a struct létrehozásakor ezek az értékek biztosan meg legyenek adva. Ha egy kulcs nem szerepel a listában, az értéke `nil` lesz, ahogy a fenti példában is látszik. Ha egy kikényszerített kulcshoz nem adsz értéket, hiba keletkezik.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
