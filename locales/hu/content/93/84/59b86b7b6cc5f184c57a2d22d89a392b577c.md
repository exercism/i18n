# Bevezetés a típusállításokba

A Go interfészei miatt nem mindig egyértelmű, milyen mögöttes típusról van szó.
A típusállítással kinyerhetjük az interfészérték mögöttes konkrét értékét a következő szintaxissal: `interfaceVariable.(concreteType)`.

Például:

```go
var input interface{} = 12
number := input.(int)
```

MEGJEGYZÉS: ez pánikot okoz, ha az interfészváltozó nem a konkrét típus értékét tartalmazza.

Azt, hogy egy interfészérték egy adott konkrét típust tartalmaz-e, a típusállítás mindkét visszatérési értékével ellenőrizhetjük: a mögöttes értékkel és egy Boolean értékkel, amely megmondja, sikerült-e az állítás.
Például:

```go
str, ok := input.(string) // no panic if input is not a string
```

Ha az `input` tartalmaz `string`-et, akkor a `str` lesz a mögöttes érték, az `ok` pedig igaz.
Ha az `input` nem tartalmaz `string`-et, akkor a `str` a `string` típus zéróértéke lesz (azaz `""`, az üres string), az `ok` pedig hamis.
Egyik esetben sem történik pánik.

## Típus szerinti switch

A **típus szerinti switch** több típusállítást is elvégezhet egymás után.
Ugyanaz a szintaxisa, mint egy típusállításnak (`interfaceVariable.(concreteType)`), de a `concreteType` helyére a `type` kulcsszó kerül.
Nézzünk egy példát:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
