# Típuszsonglőrködés

A típuszsonglőrködést automatikus típuskonverziónak is nevezik.
Típuszsonglőrködésről akkor beszélünk, amikor egy művelet elvégzéséhez két különböző típusú értéket ugyanarra a típusra alakítunk át.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

A kifejezés kiértékelésekor a string érték implicit módon `int`-té alakul, hogy megfeleljen a `*` operátor elvárásának.
Hogy melyik típusra történik az átalakítás, azt a PHP a művelet szabályai szerint dönti el, és ezek a szabályok nagyon változatosak.

Automatikus típuskonverzió függvények és metódusok hívásakor is előfordul:

```php
strlen(12321);
# => 5
```

## Típusátalakítás

Ahelyett, hogy az implicit átalakításra hagyatkoznánk, a `C`-stílusú típusátalakítással kifejezetten kényszeríthetünk egy értéket arra, hogy egy adott típusként értékelődjön:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Ez az értéket a zárójelben (`(...)`) megadott típussá alakítja.
Célttípusként az összes primitív típus használható: `bool`, `int`, `float`, `string`, `array`, `object`.

## Az átalakítás csak ideiglenes

A típuszsonglőrködés vagy a típusátalakítás **nem változtatja meg** a változóban tárolt érték típusát.
Csak a művelet bemenete alakul át.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## Információvesztés

Amikor egy értéket más típussá alakítunk, a folyamat során információvesztés léphet fel:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

Ha kifejezetten vagy implicit módon a típusátalakításra hagyatkozunk, az egy nagyobb rendszerben hibákat okozhat.

## Explicit típusátalakítás `array` és `object` típusra

Az értékeket `array` és `object` típusra is átalakíthatjuk.
Ha egy érték nem tömb és nem objektum, és `array` típusra alakítjuk, akkor egyetlen elemként kerül egy tömbbe:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

Amikor `object` típusra alakítjuk, az érték egy `scalar` nevű nyilvános tulajdonságba kerül:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> A `stdClass` a PHP-be beépített névtelen osztály típusa.
