# Részletek

A Perl egy programozási nyelv, amelyet Larry Wall alkotott meg, és amely először 1987-ben jelent meg.

## Csomagok és modulok

A csomag kódból álló gyűjtemény, amelyet gyakran egy ugyanilyen nevű, `.pm` kiterjesztésű modulfájl tartalmaz.
A modul ezután beimportálható egy másik fájlba, jellemzően a `use` kulcsszóval.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Változók

Léteznek skalár (`$foo`), tömb (`@bar`) és hash (`%baz`) változók.
Az egyszerűség kedvéért itt csak skalár változókat használunk.
Egy skalár érték a következő lehet: string, szám, Boolean vagy egy [hivatkozás][perlreftut] valamire.
Az érték hiányát az `undef` jelöli.


A `my` és `our` kulcsszavak lexikai scope-ban deklarálnak egy változót, pl. `my $foo;`.
Az `our` esetén a változó ugyanilyen nevű csomagváltozóra is hivatkozik.
A változók deklarálásának más módjai is léteznek, amelyeket itt nem tárgyalunk.

A `=` operátorral értéket rendelhetsz egy változóhoz, pl. `$foo = 1;`, amit a változó deklarálásával egy időben is megtehetsz, pl. `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Szubrutinok

A `sub` kulcsszó [szubrutint][perlsub] deklarál.
A `return` kulcsszó kilép a szubrutinból, visszaadva a megadott értékeket, vagy üres listát, ha nincs megadva semmi.
Megadott `return` nélkül a visszaadott értéket a használt szubrutin kontextusa (skalár, lista vagy void) és annak utolsó utasítása határozza meg.

```perl
sub hello () {
    return 'Hello, World!';
}
```

A Perl újabb verzióiban formális paramétereket adhatsz meg egy [szignatúrában][perlsubsig].
A paraméterlista skalár, tömb vagy hash változókat tartalmazhat.
Az üres paraméterlista azt jelenti, hogy a szubrutin nulla argumentumot fogad el.
A Perl régebbi verzióiban az argumentumokat a speciális `@_` változóból kellett kiolvasni, amit itt nem tárgyalunk.
