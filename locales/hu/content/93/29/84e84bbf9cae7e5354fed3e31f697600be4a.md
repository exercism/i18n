# Bevezetés

## Listák

Az F#-ban a `list` egy nulla vagy több értékből álló, módosíthatatlan gyűjtemény. A listában minden értéknek ugyanolyan típusúnak kell lennie. Mivel a listák módosíthatatlanok, miután létrehoztál egy listát, annak értéke soha nem változhat meg. Minden olyan függvény és operátor, amely úgy tűnik, hogy módosítja a listát (például elemet ad hozzá), valójában új listát ad vissza.

A listákat a következőképpen definiálhatod:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

A leggyakoribb módja annak, hogy elemet adj egy listához, a `::` (cons) operátoron keresztül történik:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Az F#-listának van egy _feje_ (az első elem) és egy _farka_ (minden, ami az első elem után következik). A lista farka maga is egy lista.

A listákat vagy a `List` modulban definiált függvényekkel és operátorokkal kezelheted, vagy kézzel, mintaillesztéssel, a _lista_ és _cons_ minták használatával:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Mintaillesztéskor egy értéket _el is dobhatsz_; ha egy adott esetben _nem_ érdekel egy érték (azaz nem fogod _használni_), egy alulvonással (`'_'`) jelezheted ezt:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Az egyetlen `'_'` mintaillesztéskor mindig _utolsóként_ szerepeljen; minden értéket, amely _nem_ illeszkedik a többi eset egyikéhez sem, ez az eset fog kezelni.
