# Modulo

A modulo összehasonlítás teljesen rendben van a Crystalben, de az osztás maradékát olvashatóbban is összehasonlíthatod a [`divisible_by?`][divisible_by] metódussal.
Például:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
