# Részletesen

A C#-ban a listák primitív értékek, illetve struktúrák vagy osztályok példányainak gyűjteményei. Az alaposztály-könyvtárban a [`List<T>`][lists-docs] valósítja meg őket, ahol a `T` a listában tárolt elem típusa. Az API gazdag metóduskészletet kínál a listák létrehozásához és módosításához.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

A gyűjtemény definíciójában általában szerepel egy helyőrző csúcsos zárójelben, amelyet a konvenció szerint gyakran `T`-nek neveznek. Így a gyűjtemény használója megadhatja, milyen típusú elemeket tároljon a gyűjtemény.

A [concept:csharp/arrays]() fogalommal ellentétben a listák dinamikusan tudják átméretezni magukat.

## LINQ

Bár a `List<T>` beépített API-ja gazdag (olyan leképezéseket és szűrőket is tartalmaz, mint a `ConvertAll`, a `FindAll` és a `Foreach`), és a [ciklusszintaxisa][for-each] is nagyon világos, ezzel az API-val mindenképpen tisztában kell lenned. Sok feladathoz viszont a Language Integrated Query ([LINQ][linq]) áll rendelkezésre, amely még nagyobb tudású és széles körben használt, ráadásul egységes felületet biztosít a könyvtári gyűjtemények, a harmadik féltől származó gyűjtemények és a saját osztályaid számára.
