# Utasítások

Egy olyan rendszert üzemeltetsz, amely több alkalmazásból áll, és ezek rengeteg naplót állítanak elő. Szeretnél írni egy kis programot, amely összesíti ezeket a naplókat, és súlyossági szintjüknek megfelelő címkékkel látja el őket. A rendszeredben minden alkalmazás ugyanazokat a naplókódokat használja, de néhány régi alkalmazás nem támogatja az összes kódot.

| Naplókód             | Naplócímke | Támogatott a régi alkalmazásokban? |
|----------------------| ---------- | ---------------------------------- |
| 0                    | trace      | nem                                |
| 1                    | debug      | igen                               |
| 2                    | info       | igen                               |
| 3                    | warning    | igen                               |
| 4                    | error      | igen                               |
| 5                    | fatal      | nem                                |
| egyéb / nem támogatott | unknown  | -                                  |

## 1. Határozd meg a naplócímkét

Valósítsd meg a `LogLevel.to_label/2` függvényt. A függvény egy egész szám típusú kódot és egy Boolean jelzőt kap, amely megmondja, hogy a napló régi alkalmazásból származik-e, visszatérési értéke pedig a naplósor címkéje atomként.

A táblázatban nem szereplő naplókódok _unknown_ címkét adjanak vissza. Azok a naplókódok is _unknown_ címkét adjanak vissza, amelyek a táblázatban a régi alkalmazásokban nem támogatottként szerepelnek, ha a napló régi alkalmazásból érkezett.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Küldj riasztást

Ha valami váratlan történik, arról valakinek értesülnie kell.

Valósítsd meg a `LogLevel.alert_recipient/2` függvényt, amely meghatározza, kinek kell elküldeni a riasztást. A függvény egy egész szám típusú kódot és egy Boolean jelzőt kap, amely megmondja, hogy a napló régi alkalmazásból származik-e, és a címzett nevét adja vissza atomként.

Használd az előző részfeladatban megírt `LogLevel.to_label/2` függvényt. Ha a naplócímke _error_ vagy _fatal_, a riasztást az _ops_ csapatnak küldd. Ha egy régi rendszerből _unknown_ címkével érkező naplót kapsz, a riasztást a _dev1_ csapatnak küldd; minden más unknown címkét a _dev2_ csapatnak kell elküldeni. Minden más naplócímkét nyugodtan figyelmen kívül hagyhatsz, ilyenkor _false_ a visszatérési érték.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
