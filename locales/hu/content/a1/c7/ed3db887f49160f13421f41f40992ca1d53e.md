# Tartományok

A [tartományok][range] két érték közötti intervallumot jelölnek.
A leggyakoribb típusok, amelyek támogatják a tartományokat, az `Int`, `String` és `Date`.
Sok mindenre használhatók, például gyorsan létrehozhatsz velük egy gyűjteményt, szeletelhetsz egy tömböt, ellenőrizheted, hogy egy érték benne van-e egy tartományban, és iterálhatsz.
A `...` vagy `..<` tartományoperátorral hozhatók létre (előbbi zárt, utóbbi nyílt).

```swift
1...5 // A range containing 1, 2, 3, 4, 5
1..<5 // A range containing 1, 2, 3, 4
```

Két tartományoperátor azért van, hogy a végértéket tartalmazó vagy nem tartalmazó tartományokat hozhassunk létre; ez hasznos lehet például a nulla alapú indexekkel való munka során.

~~~~exercism/note
Ha Swiftben a `...` vagy `..<` tartományoperátorral hozol létre tartományt, és metódust szeretnél meghívni rajta, a tartományt zárójelbe kell tenned.
Ez azért van, mert különben a metódus a tartományoperátor második argumentumán hívódik meg.

```swift
(1...5).contains(3) // Returns true
1...5.contains(3) // => Error: value of type 'Int' has no member 'contains'
```
~~~~

## Tartomány átalakítása tömbbé

Ha egy tartományt tömbbé szeretnél alakítani, használhatod az `Array` kezdőértékét.
Ez akkor lehet hasznos, ha értékek gyűjteményét szeretnéd létrehozni anélkül, hogy ki kellene írnod őket.

```swift
let range = 1...5
let array = Array(range)
// Returns [1, 2, 3, 4, 5]
```

## Tömb szeletelése

Egy tömb szeleteléséhez tartományokat használhatsz.

```swift
let array = [1, 2, 3, 4, 5]
// Returns [1, 2, 3, 4, 5]
let slice = array[1...3]
// Returns [2, 3, 4]
```

## Tartomány metódusai

A tartományokhoz tartozik egy sor metódus, amelyekkel dolgozhatsz.
Például ezekkel a metódusokkal megkaphatod a tartomány összes értékének összegét, vagy ellenőrizheted, hogy a tartomány tartalmaz-e egy értéket.

| Metódus                 | Leírás                                                                  | Példa                                 |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------------- |
| `count`                 | Visszaadja a tartomány méretét                                          | `(1...5).count // returns 5`          |
| [`contains`][contains]  | Visszaadja a `true` értéket, ha a tartomány tartalmazza a megadott értéket, egyébként `false` | `(1...5).contains(3) // Returns true` |

## Végtelen és kezdet nélküli tartományok

Egy tartomány lehet végtelen és kezdet nélküli.

A végtelen és kezdet nélküli tartományok akkor hasznosak, ha például egy tömböt az elejétől vagy a végéig szeretnél szeletelni.

~~~~exercism/caution
Ha nem gyűjteményen használod, a végtelen tartomány végtelen sorozatot eredményezhet, ezért légy óvatos.
~~~~

## String-tartományok

A string használható tartományokban, és segítségével két string közötti intervallumot kaphatsz.
Ez például akkor lehet hasznos, ha meg szeretnéd kapni az ábécét.

```swift
"a"..."z" // A range containing ["a", "b", "c", ..., "z"]
```
