# A MoonScript telepítése

Először kövesd [a Lua-kurzus][lua-install] telepítési útmutatóját, hogy telepítsd a Lua-t és a bustedet.

Ezután telepítsd a MoonScriptet a következő paranccsal:

```console
$ luarocks install --local moonscript
```

[lua-install]: https://exercism.org/docs/tracks/lua/installation
