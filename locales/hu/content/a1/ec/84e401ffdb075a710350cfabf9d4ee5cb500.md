# Bevezetés

A Gleam szabványos könyvtára egy `Queue` típust valósít meg a `gleam/queue` modulban. Ez hasonló a `List` típushoz, de néhány lényeges különbség van köztük:

- A `Queue` típusnak nincs olyan literál szintaxisa, amellyel sorokat lehetne létrehozni vagy mintaillesztést végezni rajtuk.
- A `Queue` típus elejéhez és végéhez is hatékonyan lehet elemeket hozzáadni és elvenni, míg a `List` típusnál ez csak az elején hatékony.

A legtöbbször a `List` típust érdemes használnod, de ha egy gyűjtemény végéről is szeretnél elemeket hozzáadni és elvenni, akkor a `Queue` típus jó választás.

Sorokat a `queue.new` és a `queue.from_list` függvénnyel hozhatsz létre:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Elemeket a `queue.push_front` és a `queue.push_back` függvénnyel adhatsz a sorhoz:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Elemeket a `queue.pop_front` és a `queue.pop_back` függvénnyel vehetsz el a sorból:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Egy sort a `queue.to_list` függvénnyel alakíthatsz listává:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## A sorok egyenlősége

A sorok megvalósítása miatt előfordulhat, hogy két sor, amely ugyanazokat az elemeket ugyanabban a sorrendben tartalmazza, mégsem egyenlő a `==` operátor szerint, amely az értékeket strukturálisan hasonlítja össze. Például:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Ha két sort egyenlőség szempontjából szeretnél összehasonlítani, használhatod a `queue.is_logically_equal` függvényt.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
