# Tesztek

## Tesztek futtatása

Futtasd a tesztspecifikációt ezzel:

```bash
$ gradle test
```

## További tesztek engedélyezése

Miután a kódod minden aktív teszten átmegy, engedélyezhetsz egy másik tesztet úgy, hogy eltávolítod a következő, téged érdeklő teszt előtti `@Ignore`-t. Ezt úgy teheted meg, hogy törlöd az `@Ignore` sort, vagy kikommenteled úgy, hogy két perjelet teszel a sor elejére.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
