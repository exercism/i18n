# Utasítások

Segíteni fogsz a középiskolás szerelmeseknek kifejezni a szerelmüket a közösségi médiában azzal, hogy a kezdőbetűikből Unicode-szívet generálsz:

```
❤ J.  +  M. ❤
```

## 1. A név megtisztítása

Definiáld a `cleanupname` szót, amely egy nevet vesz le a veremből. Cserélj minden `-` karaktert szóközre, majd távolítsd el a szöveg elejéről és végéről a felesleges szóközöket.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. A név első betűjének lekérése

Definiáld a `firstletter` szót, amely egy nevet vár. Használd újra az előző részfeladatból a `cleanupname` szót, majd vedd az eredmény első karakterét, és add vissza egykarakteres stringként.

```factor
"Jane" firstletter .
! => "J"
```

## 3. Az első betű formázása kezdőbetűvé

Definiáld az `initial` szót, amely egy nevet vár. Használd újra az előző részfeladatból a `firstletter` szót, alakítsd nagybetűssé, majd fűzz hozzá egy `.` jelet.

```factor
"Robert" initial .
! => "R."
```

## 4. A kezdőbetűk elhelyezése a szívben

Definiáld a `couple` szót, amely két nevet vesz le a veremből. Használd újra az előző részfeladatból az `initial` szót mindkét névre, majd állítsd össze az eredményt:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
