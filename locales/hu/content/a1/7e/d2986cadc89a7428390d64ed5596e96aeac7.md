# Tesztek

A PonyTestet használjuk a standard könyvtárból, hogy megírjuk azokat a teszteket, amelyek a megoldásodat tesztelik. A megoldásod teszteléséhez fordítsd le és futtasd a kódodat.

Például a „Helló, világ!” munkameneted így nézhet ki:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
