# Bevezetés

## Változók definiálása

Egy változó definiálása azt jelenti, hogy értéket rendelünk egy névhez. A Scalában kétféle változó létezik: a val és a var.

Egy `val` módosíthatatlan, ezért az értéke az első értékadás után már nem változtatható meg:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

A `var`-t ezzel szemben újra hozzárendelhetjük egy ugyanolyan típusú értékhez:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

A Scala statikusan típusos nyelv, ami azt jelenti, hogy mindennek már fordítási időben van típusa. Egy változót definiálhatunk úgy, hogy explicit módon megadjuk a típusát, vagy úgy is, hogy hagyjuk, hogy a Scala fordítója a hozzárendelt érték alapján következtessen a típusára (ezt nevezik típuskövetkeztetésnek). Ezért a következő két változódefiníció egyenértékű:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

Miután definiáltuk, egy változó típusa soha nem változhat meg.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## Metódusok definiálása osztályon belül

A Scala egy _objektumorientált nyelv_, amelyben minden metódust egy _osztályon_ belül kell definiálni. Egy osztály definiálásához a `class` kulcsszót használjuk.

```scala
class Calculator {
  // ...
}
```

Egy osztályon belül a metódusokat a `def` kulcsszóval kezdve, majd egy névvel definiálhatjuk. Minden metódusnak lehet nulla vagy több paramétere, amelyeket vesszővel elválasztva, kerek zárójelek között sorolunk fel. Minden paraméter típusát explicit módon meg kell adni, a paramétereknél nincs típuskövetkeztetés. A paraméterlista után egy újabb kettősponttal elválasztva adjuk meg a metódus visszatérési típusát.

A metódusdefiníciót egy `=` jel követi, amellyel a metódus törzse kezdődik. A következő példában a metódus törzse két utasításból áll, amelyeket kapcsos zárójelek vesznek körül.

A metódus az utolsó kifejezés értékét adja vissza, ebben az esetben az `add` metódus a `sum` változó értékét adja vissza:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

Néhány fejlesztéssel lerövidíthetjük ezt a metódust az olvashatóság javítása érdekében:

- mivel a `sum` változóhoz csak egyszer férünk hozzá, hogy visszaadjuk az értékét, el is hagyható
- az egyetlen utasításból álló metódusokhoz nem kellenek kapcsos zárójelek
- a metódus visszatérési típusát ugyanúgy következtetheti a fordító, mint a változók típusát

Így a következő egysoros metódust kapjuk, ugyanazzal a funkcionalitással:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## Osztályok példányosítása és metódusok hívása

Egy metódus meghívásához először létre kell hoznunk az osztály egy példányát, majd meg kell hívnunk a metódust ezen a példányon, argumentumokkal:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Megjegyzések

A Scala kétféle megjegyzést támogat: az egysoros és a többsoros megjegyzéseket:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
