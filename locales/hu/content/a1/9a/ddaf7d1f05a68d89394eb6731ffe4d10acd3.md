# Bevezetés

A *deque* (kétvégű sor) mindkét végén támogatja a push és a pop műveletet O(1) idő alatt. A Factor standard megvalósítása a `<dlist>` (kétszeresen láncolt lista) a [`dlists`][dlists] szótárban; a műveletek a [`deques`][deques] szótárban találhatók.

## A deque API-ja

```
<dlist>       ( -- dlist )
push-front    ( elt deque -- )
push-back     ( elt deque -- )
pop-front     ( deque -- elt )
pop-back      ( deque -- elt )
deque-empty?  ( deque -- ? )
dlist-length  ( dlist -- n )
clear-deque   ( deque -- )
```

A `clear-deque` helyben üríti ki a deque-et, így újra felhasználhatod anélkül, hogy újra kellene foglalni a memóriát.

Ha ugyanazon a végén pusholsz és popolsz, LIFO vermet kapsz. Ha az egyik végén pusholsz és a másikon popolsz, FIFO sort kapsz:

```factor
USING: deques dlists ;

<dlist>
"alpha" over push-back
"bravo" over push-back
"charlie" over push-back
dup pop-front .   ! => "alpha"   (FIFO — oldest first)
dup pop-front .   ! => "bravo"
pop-front .       ! => "charlie"
```

LIFO-hoz inkább egy vektort (`V{ }`) használnál a `push`/`pop` műveletekkel, mert annak kisebb a műveletenkénti többletköltsége. Akkor nyúlj a `<dlist>`-hez, ha *mindkét* végén O(1)-re van szükséged, ami szinte mindig FIFO sor esetén fordul elő.

## Szélességi keresés

A FIFO használat teszi a deque-eket a *BFS* (szélességi keresés) megfelelő határvonalává. Egyetlen csomópontból indulsz, a szomszédokat a végére pusholod, a jelölteket az elejéről popolod, az ismétlődéseket pedig egy hash-set segítségével szűröd ki:

```factor
! DOCTEST: SKIP
USING: deques dlists hash-sets sets ;

! ... visited adjoin and frontier push-back ...
[ frontier deque-empty? ] [
    frontier pop-front ! ... look up neighbours, push unseen ones ...
] until
```

A régebbi jelölteket előbb vizsgálod meg, mint az újabbakat, így a keresés rétegenként halad kifelé a kiindulóponttól. Ez adja a BFS legrövidebb út tulajdonságát: amikor először érsz el egy célcsomópontot, az mindig minimális lépésszámú útvonalon történik.

## `MEMO:` - automatikus gyorsítótárazás

Néha a BFS által hívott csomópontonkénti keresés drága. A Factor [`memoize`][memoize] szótára adja a `MEMO:`-t, amely a `:` egy az egyben kicserélhető helyettesítője, és gyorsítótárazza a szó eredményét a bemenetei alapján:

```factor
USING: memoize ;

MEMO: gold-count ( cove -- n )
    ! ... slow lookup ...
    ;
```

A `MEMO:` szó először minden bemenetre lefuttatja a törzsét, azután a gyorsítótárazott eredményt adja vissza. Ugyanaz a felület, a hívás helyén nincs plusz hívás, ismétlődés esetén csak gyorsabb.
