# Részletesen

A Go-ban a függvények első osztályú értékek.
Ez azt jelenti, hogy a függvényekkel ugyanazokat a dolgokat teheted meg, mint bármely más értékkel: értékül adhatod őket változóknak, átadhatod őket argumentumként más függvényeknek, vagy akár függvényt is visszaadhatsz egy másik függvényből.

Az alábbi kódban két függvényt hozunk létre, az `engGreeting` és az `espGreeting` függvényt, majd értékül adjuk őket a `greeting` változónak:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

A függvényértékek lehetővé teszik, hogy a függvényeket ne csak adatokkal, hanem viselkedéssel is paraméterezd.
A következő példában viselkedést adunk át a `dialog` függvénynek a `greetingFunc` paraméteren keresztül:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

Ha egy függvénytípusú változónak nincs kezdőértéke, az értéke `nil`.
Ezért egy `nil` függvényérték meghívása panic-ot vált ki.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

A függvényértékek összehasonlíthatók a `nil`-lel.
Ez segíthet elkerülni a felesleges panic-okat a programban.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Függvénytípusok

A függvényértékeket a Go függvénytípusainak köszönhetően használhatod.
Egy függvénytípus azon függvények halmazát jelöli, amelyeknek ugyanaz a paramétertípus-sorozata és ugyanaz az eredménytípus-sorozata.
Függvénytípusokra felhasználó által definiált típusokat is építhetsz.
A korábbi példák `dialog` függvényét például így frissítheted:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Névtelen függvények

Egy másik hatékony eszköz, amelyet az első osztályú függvények támogatása tesz elérhetővé, a névtelen függvények.
A névtelen függvényeket ott definiálod, ahol használod, és nem követi név a `func` kulcsszót.
Az ilyen függvények hozzáférnek a befoglaló függvény változóihoz.

Például:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

A `fib` meghívása deklarálja az `n1` és `n2` változókat, majd visszaad egy névtelen függvényt, amely minden meghíváskor megváltoztatja ezeknek a változóknak az értékét.
A névtelen függvény N-edik meghívása a 0-tól induló Fibonacci-sorozat N-edik tagját adja vissza. A belső névtelen függvény hozzáfér a `fib` befoglaló függvény lokális változóihoz (`n1` és `n2`).
Ez remek módja annak, hogy a függvényértékek megtartsák az állapotukat a hívások között.
Azt mondjuk, hogy a névtelen függvény az `n1` és `n2` változók closure-e.
A [closure-ök][closure] széles körben használatosak a programozásban, és más nyelvekben is találkozhatsz velük.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
