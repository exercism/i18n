# Névjegy

A kötés azt írja le, hogy a kód melyik részéről érhető el egy azonosító.
A blokk, függvény vagy függvényprototípus scope-pal rendelkező értékeknek nincs kötésük.
Ez azt jelenti, hogy a scope-jukon kívülről nem érhetők el.
A scope-pal kapcsolatos további részletekért lásd a [scope fogalmat](../scope/introduction.md#Introduction).

## Külső kötés

A fájl scope-pal rendelkező azonosítók alapértelmezés szerint külső kötésűek.
A külső kötésű azonosítót a program bármelyik fájljából meg lehet hívni.

## Belső kötés

A fájl scope-pal rendelkező azonosítót a `static` módosítóval belső kötésűvé tehetjük.
A belső kötésű azonosító csak a saját fájlján belül használható.

Például

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

A statikus kötést nem szabad összekeverni a statikus tárolási időtartammal.
A statikus tárolási időtartamról további részletekért lásd a [tárolási időtartam fogalmat](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).

Ha egy értéket (szemben egy függvénnyel) egy fejlécben deklarálnak, de a forrásfájlban `static`, fájl scope-pal rendelkező, inicializált értékkel bíró azonosítóként definiálják, akkor az inicializált értéke a forrásfájlján kívülről nem lesz elérhető.
Lehet, hogy hiba nélkül lefordul, linkelődik és lefut, de az érték az azonosító nullaértéke lesz, még akkor is, ha az értéket `extern`-nel deklarálják.
(Az `extern`-ről további részletekért lásd az [extern fogalmat](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit).)
A forrásfájlban `static`-ként megjelölt, fájl scope-pal rendelkező azonosítót nem szabad a fejlécfájljában deklarálni.
