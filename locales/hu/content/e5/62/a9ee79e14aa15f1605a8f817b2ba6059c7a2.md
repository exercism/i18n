# Bevezetés

A *reguláris kifejezés* (regex) egy kis minta, amely leírja, hogyan nézzen ki egy szöveg. Ahelyett, hogy karakterenként ellenőriznéd a stringet, egyszer leírod a kívánt formát, és a Factorra bízod az illesztést. A Factor regex eszközei a [`regexp`][regexp] szótárban találhatók.

## Minta írása

A Factorban a regexet `R/ ` és `/` közé írod:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

A mintában a legtöbb karakter önmagát jelenti. A `R/ cat/` például a `cat` szövegre illeszkedik. Az erejét néhány speciális elem adja, amelyek karakterek *fajtáit* vagy *számát* jelölik.

### Karakterosztályok: „egy karakter egy halmazból”

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

Egy osztály pontosan *egy* karakterre illeszkedik. A `[A-Z]` illeszkedik a `Q`-ra, de a `QQ`-ra nem.

### Kvantorok: „hány”

Tegyél egyet ezek közül egy darab *után*, hogy megmondd, hányszor ismétlődhet:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

Tehát a `\d{4}` négy egymást követő számjegyet jelent, a `[A-Z]+` pedig egy vagy több nagybetűt. Ezeket összerakva a `R/ [A-Z]+-\d+/` olyan formát ír le, mint „egy vagy több nagybetű, egy kötőjel, majd egy vagy több számjegy”, például a `SALE-2024` szöveget. A `-` itt egy hétköznapi karakter: a `[ ]`-en kívül a kötőjel egyszerűen egy kötőjelre illeszkedik (egy osztályon belül, mint a `[A-Z]`-ben, tartományt jelöl).

## Teljes string illesztése

A `matches?` arra ad választ, hogy „ez a *teljes* string illeszkedik-e a mintára?” A mintának minden karaktert le kell fednie, az elejétől a végéig:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

Bár a `SALE-2024` benne van a `"GET SALE-2024"` stringben, a `matches?` mégis `f`-et ad: a plusz karakterek a string részei, és nem illeszkednek a mintára. Amikor csak az számít, hogy a minta *valahol* megjelenik-e, használd a `re-contains?` szót: ez pontosan ott ad `t`-t, ahol a `matches?` `f`-et adott:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## Illeszkedések keresése hosszabb szövegben

A `re-contains?` csak azt mondja meg, hogy a minta *benne van-e* a szövegben. A következő szavak belenéznek a szövegbe, és megmondják, *mi* illeszkedett: az `all-matching-subseqs` visszaadja az összes helyet, ahol a minta illeszkedik, stringek sorozataként, a `count-matches` pedig csak megszámolja őket:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## Illeszkedések cseréje

A `re-replace` minden illeszkedést kicserél egy csere-szövegre, és visszaadja az új stringet:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

A `regexp` szótárban több hasznos szó is van. A részletekért kövesd a linkeket: [`first-match`][first-match] (csak az első illeszkedés) és [`re-split`][re-split] (a string felosztása mindenhol, ahol a minta illeszkedik).
