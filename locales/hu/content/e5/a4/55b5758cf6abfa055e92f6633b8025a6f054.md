# Az utasítások kiegészítése

## Regiszterek

| Regiszter | Használat | Típus      | Leírás                                          |
| --------- | --------- | ---------- | ----------------------------------------------- |
| `$a0`     | bemenet   | cím        | bináris karakterekből álló, nullával lezárt string |
| `$v0`     | kimenet   | egész szám | a bemeneti string tízes számrendszerbeli értéke |
| `$t0-9`   | ideiglenes | bármilyen  | ideiglenes tárolásra használt                   |
