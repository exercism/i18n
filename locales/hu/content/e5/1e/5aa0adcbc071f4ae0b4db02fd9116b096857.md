# Kiegészítés az utasításokhoz

~~~~exercism/note

A fenti leírás a [_matematikai halmazok_][math-sets] témakörét említi, de azt is, hogy egy pitagoraszi számhármas {a, b, c} _**csak úgy**_ lehet rendezett, hogy a < b < c (_növekvő sorrend_).

Emiatt a Python [`set` típusa][python-sets] nem alkalmas erre a feladatra, mivel alapvetően _nem rendezett_.
Helyette egy [`list`][python-list]-et kell visszaadnod, amely `list`-eket tartalmaz (pl. `[[a, b, c]]`).
Magukat a hármasokat tetszőleges sorrendben generálhatod, mert a külső `list` sorrendjét a tesztek figyelmen kívül hagyják.

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
