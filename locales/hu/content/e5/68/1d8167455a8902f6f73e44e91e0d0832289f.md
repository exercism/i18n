# Tesztek

Minden példánál a következő általános lépéseket kell követni.

Először lépj be abba a feladatba, amelyet gyakorolni szeretnél, esetünkben a `bob` feladatba.

```bash
$ cd </path/to/exercism>/lfe/bob
```

Ezután futtasd a teszteket.  A `test` make-cél a `compile`-tól függ,
így a `make test` futtatása gondoskodik róla, hogy a forrásod le legyen fordítva,
 majd ezután lefuttatja a teszteket.


```bash
$ make test
```

Gratulálunk! Sikertelen tesztjeid vannak!!!

Most olvasd el a `README.md`-t, hogy megtudd, mit kell tenned ahhoz,
hogy minden teszted sikeres legyen.


Javítsd ki az első hibát, amelyet a teszt jelzett, majd futtasd újra a teszteket.

```bash
$ make test
```

Folytasd a következő sikertelen teszt kijavításával a forráskódodban, és
futtasd a tesztet, amíg minden teszt sikeres nem lesz.

Amint minden teszted sikeres, vess egy utolsó pillantást a `src`
könyvtárban lévő kódodra, hogy megbizonyosodj róla, elégedett vagy vele, majd
küldd be áttekintésre.

Kérj visszajelzést, javítsd a megoldásodat, küldd be, próbáld ki a következő
feladatot, és ismételd mindezt, amíg el nem éred az LFE megvilágosodást.
