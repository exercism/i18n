# Bevezetés

## Általános szintaxis

A for ciklus az egyik leggyakrabban használt utasítás, amellyel ismételten végrehajthatunk valamilyen logikát.
Go-ban a `for` kulcsszóból, egy fejlécből és egy kódblokkból áll, amely a ciklus törzsét tartalmazza kapcsos zárójelek között.
A fejléc 3 komponensből áll, amelyeket pontosvessző `;` választ el: init, feltétel és post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- Az **init** komponens olyan kód, amely csak egyszer fut le, a ciklus kezdete előtt.
- A **feltétel** komponensnek olyan kifejezésnek kell lennie, amely Boolean értéket ad vissza, és meghatározza, mikor álljon le a ciklus.
  A ciklus belsejében lévő kód addig fut, amíg ez a feltétel igaz.
  Amint ez a kifejezés hamis lesz, a ciklus már nem fut tovább.
- A **post** komponens olyan kód, amely minden iteráció végén lefut.

**Megjegyzés:** Más nyelvektől eltérően a fejléc három komponensét nem veszi körül zárójel `()`.
Sőt, ha mégis odaírsz egy ilyen zárójelet, az fordítási hiba.
A ciklus törzsét körülvevő kapcsos zárójelek `{ }` viszont mindig kötelezőek.

## For ciklusok - egy példa

Az init komponens általában beállít egy számlálóváltozót, a feltétel ellenőrzi, hogy folytatódjon-e a ciklus vagy álljon le, a post komponens pedig általában növeli a számlálót minden ismétlés végén.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Ez a ciklus kiírja az `1`-től `9`-ig terjedő számokat (a `9`-et is beleértve).
A lépésköz megadása gyakran növelő vagy csökkentő utasítással történik, ahogy a fenti példa is mutatja.
