# Tesztek

Futtasd a teszteket ezzel:

```shell
npm run test
```

A Jestet „watch” módban is futtathatod, ami automatikusan újrafuttatja a tesztjeidet, amikor a kódban vagy a tesztmodulban mentesz egy változtatást:

```shell
npm run watch
```

## A tesztek kihagyásának megértése

A skip metódus arra utasítja a tesztkészletet, hogy ne futtasson le egy tesztet; ez a függvény az alábbi álneveken is használható: `it.skip(name, fn)` vagy `xit(name, fn)` vagy `xtest(name, fn)`

- Miért vannak kihagyva?

Hogy a felhasználók egyszerre egy tesztre összpontosíthassanak, és a megoldás fejlesztése közben egyenként engedélyezhessék őket.

- Hogyan engedélyezzük őket?

Cseréld a `xtest`-et `test`-re.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
