# Utasítások

Ebben a feladatban megtakarítási számlákkal fogsz dolgozni.
A megtakarítási számlád egyenlege minden évben a kamatlába alapján frissül.
A bank által adott kamatláb a számládon lévő pénz összegétől (az egyenlegtől) függ:

- 3,213% negatív egyenleg esetén (az egyenleg még negatívabb lesz).
- 0,5% a `1000` dollárnál kisebb pozitív egyenleg esetén.
- 1,621% a `1000` dollárnál nagyobb vagy azzal egyenlő, és `5000` dollárnál kisebb pozitív egyenleg esetén.
- 2,475% az `5000` dollárnál nagyobb vagy azzal egyenlő pozitív egyenleg esetén.

Négy részfeladat vár rád, mindegyik az egyenlegeddel és annak kamatlábával foglalkozik.

## 1. Számítsd ki a kamatlábat

Valósítsd meg a `SavingsAccount.interest_rate()` metódust, amely argumentumként egy egyenleget kap.
A metódus adja vissza a megadott egyenleghez tartozó kamatlábat.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. Számítsd ki a kamatot

Valósítsd meg a `SavingsAccount.interest()` metódust, amely argumentumként egy egyenleget kap.
A metódus adja vissza a megadott egyenleghez tartozó kamatot.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. Számítsd ki az éves egyenlegfrissítést

Valósítsd meg a `SavingsAccount.annual_balance_update()` metódust, amely argumentumként egy egyenleget kap.
A metódus adja vissza az egy év utáni egyenleget.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. Számítsd ki, hány év kell a kívánt egyenleg eléréséhez

Valósítsd meg a `SavingsAccount.years_before_desired_balance()` metódust, amely argumentumként egy egyenleget és egy cél-egyenleget kap.
A metódus adja vissza, hány évbe telne elérni a cél-egyenleget.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
Amikor egyszerű kamatot számítunk egy tőkeegyenlegre, az egyenleget megszorozzuk a kamatlábbal, és a kettő szorzata adja a kamat összegét.

A kamatos kamat ezzel szemben rendszeres kamatozással működik.
Minden egyes alkalmazáskor kiszámítjuk a kamat összegét, és hozzáadjuk a tőkeegyenleghez, így a későbbi kamatszámítások már nagyobb tőkeegyenlegre vonatkoznak.
~~~~
