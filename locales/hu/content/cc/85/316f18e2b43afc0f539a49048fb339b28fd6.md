# Részletek

A C++-ban a Boolean értékeket a `bool` típus képviseli.
Egy `bool` vagy `true`, vagy `false`.

## Logikai operátorok

A C++ három Boolean-operátort támogat: a `!` (NOT), a `&&` (AND) és a `||` (OR) operátort.
Használhatod a `not`, `and` és `or` alternatív változatokat is.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Precedencia

A három Boolean-operátor _operátorprecedenciája_ eltérő.
Ennek következtében ebben a sorrendben értékelődnek ki: először a `!`, aztán a `&&`, végül a `||`.
Ha más sorrendet szeretnél kikényszeríteni, egy Boolean-kifejezést zárójelbe tehetsz (azaz `()`), mert a zárójelnek még nagyobb az operátorprecedenciája.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Konverzió

Ha `true` vagy `false` értéket használsz ott, ahol számot várunk, akkor azok `1`-gyé, illetve `0`-vá alakulnak.
Ha számot használsz egy Boolean-műveletben, akkor a `0` kivételével mindent `true`-ként kezel a nyelv, még a negatív értékeket is.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
