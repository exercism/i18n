# Bevezetés

A bináris adatokkal való munka trükkös lehet, ezért a Gleam egy `BitArray` típust és a hozzá tartozó szintaxist kínál bináris adatok létrehozásához és mintaillesztéséhez.

A bittömb literálokat a `<<>>` szintaxissal definiálod. Amikor egy bittömb literált definiálsz, az szegmensekből áll. Minden szegmens egy értékből és egy annotációból áll, amelyeket egy `:` választ el. Az annotáció megadja, hány bitet használunk az érték kódolására, és teljesen el is hagyható; ilyenkor alapértelmezésben egy 8 bites egész értéket kapunk.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

A `:1` típusként való megadása rövidítése a `:size(1)` kiírásának. A hosszabb szintaxist kell használnod, ha a bitméret egy változóból származik.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## Bináris

Amikor bináris egész literálokat írunk, közvetlenül kettes számrendszerben is leírhatjuk őket, ha a literál elé `0b`-t teszünk. Ne feledd, hogy tízes számrendszerbeli számként jelennek meg, amikor a tesztekben vagy a programodban kiíródnak.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## Csonkolás

Ha a szegmens értéke meghaladja a szegmens típusának kapacitását, akkor balról csonkolódik.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## Eléfűzés és hozzáfűzés

A bittömb szintaxissal egy meglévő bittömb elé és mögé is fűzhetsz. A meglévő bittömbhöz a `:bits` annotációt kell használnod.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## Összefűzés

A szintaxissal változókban tárolt bittömböket is összefűzhetsz. Két változó méretű bittömb összefűzésekor a `:bits` annotációt kell használnod.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## Mintaillesztés

A bittömbből értékeket mintaillesztéssel is kinyerhetsz. Tudnod kell, hány bitet szeretnél kinyerni minden egyes darabnál, egyetlen kivétellel: a `:bits` annotációval ismeretlen méretű bittömbre is illeszthetsz mintát, de ezt csak az utolsó darabnál használhatod.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## Bittömbök vizsgálata

~~~~exercism/note
A bittömbök esetleg más formátumban íródnak ki, mint amilyenben létrehoztad őket.
Ez gyakran zavart okoz, amikor az ember a bittömböket tanulja.
~~~~

Alapértelmezésben a bittömbök 8 bites darabokban (egy bájt) jelennek meg, még akkor is, ha más méretű darabokkal hoztad létre őket.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Ha olyan bittömböt hozol létre, amely egy nyomtatható UTF-8-kódolású stringet reprezentál, előfordulhat, hogy az olyan függvények, mint az `io.debug`, stringként jelenítik meg. Ez annak az implementációs részletnek köszönhető, hogy a Gleam hogyan ábrázolja belsőleg a stringeket.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
