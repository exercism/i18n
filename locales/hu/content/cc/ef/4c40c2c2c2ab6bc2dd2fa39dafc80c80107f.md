# Az Armstrong-számok fogalmai

> Az [Armstrong-szám](https://en.wikipedia.org/wiki/Narcissistic_number) olyan szám, amely egyenlő a saját számjegyei összegével, miután mindegyiket a számjegyek számának megfelelő hatványra emeltük.

## Példamegoldás

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## Fogalmak

- függvények: elengedhetetlenek a megoldás ellenőrzéséhez és a logika megírásához
- Tesztcsomagok: a megoldás ellenőrzéséhez kellenek
- egész számok: u32 az argumentumhoz és az egyenlőségvizsgálatokhoz
- `&str`: a szám hosszának megszámolásához kell, mivel a Rust erősen típusos
- `Option<T>`: a `char::to_digit` tényleges értékének eléréséhez kell
- típuskonverzió: az aritmetikai műveletek elvégzéséhez szükséges
- iterátorok jellemzői:
  - turbofish, amivel egyetlen kifejezésből álló megoldás írható
  - `map` és `sum`, hogy a kifejezést kényelmesen redukáljuk arra, amit ellenőrizni akarunk
