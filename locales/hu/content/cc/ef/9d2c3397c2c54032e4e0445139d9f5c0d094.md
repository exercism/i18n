# Bevezetés

A PowerShell a Microsoft dinamikusan implicit típusos (az erősen típusos változókat is támogató) szkriptnyelve, amely elsősorban a feladatautomatizálásra és a konfigurációkezelésre összpontosít.

A PowerShell támogatja az imperatív, a funkcionális és az objektumorientált programozást, sőt a pipeline-stílust is.

A PowerShell a .NET platformra épült, és először 2006-ban jelent meg.
Minden modern Windows operációs rendszerben alapértelmezés szerint megtalálható, Macre és Linuxra pedig telepíthető.


## Változók

A PowerShellben két gyakori módja van a változó definiálásának.

A változó nevének a PowerShellben `$` jellel kell kezdődnie, és az értékadó operátorral (`=`) kötöd a változó nevét egy értékhez.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

A változó típusát explicit módon is megadhatod, ha egy adott [típust][strong typed] szeretnél kikényszeríteni.
A PowerShell megpróbálja a lehető legjobban átalakítani az értéket egyik típusból a másikba, ha lehetséges.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Konstansok

A konstansok a PowerShellben csak olvasható változók, amelyeket a definiálásuk után **nem lehet eltávolítani**.
Ez vezet el minket a változók definiálásának második módjához, a `New-Variable` parancsmag használatához.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Ha részletesebben és haladóbb módon szeretnél új változót létrehozni különféle beállításokkal, nézd meg a [New-Variable][New-Variable] parancsmagot.


## Függvények

A [függvényeket][functions] a PowerShellben a `function` kulcsszóval definiálod.
Minden függvénynek lehet nulla vagy több formális [paramétere][parameters] a `()` zárójelben, ezt követi a saját [scope][scope]-ja, amely `{` jellel kezdődik és `}` jellel végződik.

```powershell
function Greeting {
    return "Hello!"
}
```

A PowerShell függvényei explicit módon is visszaadhatnak értékeket a `return` kulcsszóval, miután a `FuncName $Arg` szintaxissal meghívtad őket.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

A részletes függvénydefiníció megírásának haladóbb áttekintését, valamint azt, hogy a függvények hogyan adhatnak vissza értékeket implicit módon, a `Functions` fogalommodulban tárgyaljuk.


## Megjegyzések

Az egysoros megjegyzés a PowerShellben `#` jellel kezdődik, és a sor végéig tart.
A megjegyzésblokk a PowerShellben `<#` jellel kezdődik és `#>` jellel végződik.
A megjegyzésblokkok haladó bemutatását, amellyel Comment-Based Help hozható létre, a `Functions` fogalommodulban tárgyaljuk.

```powershell
function Main() {
    #This is a comment
}
```
