# Bevezetés

## Az interfész mint metódushalmaz

A legegyszerűbb formájában az **interfésztípus** metódusszignatúrák halmaza.
Íme egy példa egy interfészdefinícióra, amely két metódust tartalmaz, `Add`-ot és `Value`-t:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Az olyan paraméternevek, mint az `increment`, elhagyhatók az interfészdefinícióból, de gyakran növelik az olvashatóságot.

A Go-ban az interfésznevek nem tartalmazzák az `Interface` vagy az `I` szót.
Ehelyett gyakran `er`-re végződnek, például `Reader`, `Stringer`.

## Interfész megvalósítása

Minden típus, amely definiálja az interfész metódusait, automatikusan, implicit módon „megvalósítja” az interfészt.
A Go-ban nincs `implements` kulcsszó.

A következő típus valósítja meg a fentebb látott `Counter` interfészt.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Az interfész megvalósítása szempontjából nem számít, hogy a metódusnak érték vagy pointer receiver-e van.
(Nézd át a [metódusokkal kapcsolatos fogalmakat][concept-methods], ha bizonytalan vagy ezekben.)

> Az interfésztípusú érték bármilyen értéket tárolhat, amely megvalósítja ezeket a metódusokat. [^1]

Ez azt jelenti, hogy a `Stats` mostantól mindenhol használható, ahol a `Counter` interfészt várják.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Mivel az interfészek implicit módon valósulnak meg, egy típus könnyedén megvalósíthat több interfészt is.
Ehhez csak az összes szükséges metódust kell definiálnia.

## Az üres interfész

A Go-ban van egy nagyon különleges interfésztípus, az **üres interfész**, amely nulla metódust tartalmaz.
Az üres interfészt így írjuk: `interface{}`.
A Go 1.18 óta az `any` a `interface{}` aliasa, és gyakrabban használják.

Mivel az üres interfésznek nincsenek metódusai, minden típus implicit módon megvalósítja.
Ez hasznos olyan függvény definiálásához, amely általánosan bármilyen értéket elfogadhat.
Ebben az esetben a függvény paramétere az üres interfésztípust használja.
