# Bevezetés

## Tömbök

Az `array` az F#-ban nulla vagy több értékből álló, rögzített hosszúságú, módosítható gyűjtemény. Ez azt jelenti, hogy miután létrehoztál egy tömböt, a mérete nem változhat, de az értékei igen. Egy tömbben minden értéknek ugyanolyan típusúnak kell lennie. A tömböket így definiálhatod:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Az elemeket index használatával rendelhetsz hozzá egy tömbhöz, illetve kérdezhetsz le belőle. Az F# tömbjei nullától indexeltek, ami azt jelenti, hogy az első elem indexe mindig nulla:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

A tömböket vagy az `Array` modulban definiált függvényekkel és operátorokkal módosíthatod, vagy kézzel, az _array_ mintát használó mintaillesztéssel:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Mintaillesztéskor egy értéket _el is dobhatsz_; ha egy adott esetben _nem_ érdekel egy érték (azaz nem fogod _használni_), egy alulvonással (`'_'`) jelezheted ezt:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Az egyetlen `'_'` mintaillesztéskor mindig _utolsóként_ szerepeljen; minden olyan értéket, amely _nem_ illeszkedik a többi eset egyikére sem, ez az eset kezel.
