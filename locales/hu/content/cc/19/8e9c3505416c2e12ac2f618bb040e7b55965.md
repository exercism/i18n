# Utasítások

Ebben a feladatban néhány függvényen fogsz dolgozni, hogy időpontokat kezelj.
A rendszer mindent ISO 8601 formátumú stringekben tárol, de az emberek nem így használják a naptárat.
A különböző formátumok közötti átalakításhoz több függvényre van szükség.

## 1. Hozz létre egy időpontot

Hozz létre egy időpontot `n` nappal későbbre, az aktuális időben.
A függvény `n` napot vár, és visszaadja az `n` nappal későbbi időpontot.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

Ha a második `now` paraméter nincs megadva, akkor helyette az aktuális időt kell használni.

## 2. Alakítsd át a dátumot időbélyeggé

Számos eszköz csak a nemzetközileg szabványosított ISO 8601 formátummal működik.
Írd meg a `getAppointmentTimestamp` függvényt, amely egy dátumot vesz át, és egy ilyen formátumú stringet ad vissza.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. Kérd le egy időpont részleteit

Az időbélyegeket nehéz olvasni, ebben segíthet egy függvény, amely lekéri az időpont részleteit.
A `getAppointmentDetails` függvény egy ISO 8601 formátumú időbélyeget vesz át, és visszaadja az évet, a hónapot, a napot, az órát és a percet.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. Frissítsd az időpontot a megadott opciókkal

A függvény első argumentuma az időpont, a második pedig egy objektum, amely néhány opciót tartalmaz.
Az objektumban lévő opciók szerint frissítened kell az időpontot, és vissza kell adnod az új időpont dátumát.
Az opciókat tartalmazó objektumban több opció is lehet.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. Számítsd ki a két időpont közötti rendelkezésre álló időt

A függvény két időpontot (időbélyeget) kap argumentumként.
A két időpont közötti különbséget másodpercben kell visszaadnod.

Mivel a fél másodperc szinte semmit sem jelent, kerekítsd a számot, mielőtt visszaadod.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. Ellenőrizd, hogy egy időpont érvényes-e

Végül, amikor az időpontot létrehozzák, a rendszernek ellenőriznie kell, hogy érvényes-e.
Más szóval az időpontnak a jövőben kell lennie, nem a múltban.

Írd meg az `isValid` függvényt, amely két argumentumot vár: egy időpont-időbélyeget (string) és az aktuális időt mint időbélyeget (string), és `true`-t ad vissza, ha az időpont a jövőben van az aktuális időhöz képest.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
