# Utasítások

Elena egy újsággyár új minőségmenedzsere. Mivel nemrég érkezett a céghez, úgy döntött, hogy áttekinti a gyár néhány folyamatát, hátha talál valamit, amin javítani lehet.
Rájött, hogy a technikusok rengeteg minőségellenőrzést végeznek kézzel.
Jó lehetőséget lát az automatizálásra, ezért felkér téged, szabadúszó fejlesztőt, hogy fejlessz egy szoftvert néhány gép felügyeletére.

## 1. Figyeld a helyiség páratartalmát

Az első küldetésed, hogy írj egy szoftvert, amely a termelőhelyiség páratartalmát figyeli. Már van egy érzékelő, amely a cég szoftveréhez csatlakozik, és rendszeresen visszaadja a helyiség páratartalmát százalékban.

A szoftverben implementálnod kell egy függvényt, amely hibát dob, ha a páratartalom túl magas.
A függvény neve `checkHumidityLevel` legyen, és a páratartalmat paraméterként kapja.

Dobj hibát (az üzenet nem fontos), ha a százalék meghaladja a 70%-ot.

```javascript
checkHumidityLevel(60);
// => undefined
```

```javascript
checkHumidityLevel(100);
// Throws an error
```

## 2. Ismerd fel a túlmelegedést

Elena nagyon elégedett az első feladatoddal, és arra kér, hogy foglalkozz a gépek hőmérsékletének figyelésével.
Amikor Greg technikussal beszélgetsz, megtudod, hogy ha egy gép hőmérséklete meghaladja az 500°C-ot, a technikusok aggódni kezdenek a túlmelegedés miatt.

A gép fel van szerelve egy érzékelővel, amely a belső hőmérsékletét méri.
Tudd, hogy az érzékelő nagyon érzékeny, és gyakran elromlik.
Ilyenkor a technikusoknak ki kell cserélniük.

A feladatod, hogy implementálj egy `reportOverheating` függvényt, amely paraméterként kapja a hőmérsékletet, és hibát dob, ha az érzékelő elromlott, vagy ha a gép túlmelegedni kezd.
Mivel később a hiba függvényében máshogy kell majd reagálnod, szükséged lesz egy mechanizmusra, amellyel meg tudod különböztetni a kétféle hibát.
Támaszkodhatnál a hibaüzenetekre, de ez törékennyé tenné a kódodat, mert elromlana, ha az üzenet megváltozik.
Ahhoz, hogy ezt rendesen meg tudd oldani, különböző hibaosztályok példányait fogod dobni.

- Ha az érzékelő elromlott, a hőmérséklet `null` lesz.
  Ebben az esetben egy `ArgumentError`-t kell dobnod.
- Ha minden rendben működik, és a hőmérséklet meghaladja az 500°C-ot, egy `OverheatingError`-t kell dobnod.
  Ezt a hibaosztályt egy hőmérséklet argumentummal példányosítjuk.
  Ügyelj rá, hogy a dobott `OverheatingError`-hez tartozzon egy temperature tulajdonság.

```javascript
reportOverheating(null);
// Throws an ArgumentError
```

```javascript
reportOverheating(800);
// Throws an OverheatingError
```

## 3. Figyeld a gépet

Most, hogy a géped fel tudja ismerni a hibákat, implementálj egy függvényt, amely különbözőképpen reagál ezekre a hibákra:

- Ha az érzékelő elromlott, értesítened kell egy technikust.
- Ha a hőmérséklet túl magas, akkor leállítod a gépet, ha meghaladja a 600°C-ot, vagy felkapcsolsz egy figyelmeztető lámpát, ha ez alatt marad.
- Ha más hiba történik, újradobod azt.

Implementálj egy `monitorTheMachine` függvényt, amely egy `actions` argumentumot kap.

Az `actions` egy objektum, amelynek 4 tulajdonsága van:

| tulajdonság        | leírás                                                                              |
| ------------------ | ----------------------------------------------------------------------------------- |
| `check`            | egy _*függvény*_. Ellenőrzi a gép hőmérsékletét. Különféle hibákat dobhat.          |
| `alertDeadSensor`  | egy _*függvény*_. Értesíti a technikust, hogy a hőmérséklet-érzékelő tönkrement.    |
| `alertOverheating` | egy _*függvény*_. Felkapcsolja a gépen a figyelmeztető lámpát.                       |
| `shutdown`         | egy _*függvény*_. Kikapcsolja a gépet.                                               |

A `monitorTheMachine(actions)` függvénynek belül meg kell hívnia a `check()`-et.
Ha az ellenőrzés sikeres, a függvény ne adjon vissza semmit.
Ha viszont `throw`-mal dob hibát, más viselkedésre számíthatsz:

| kivétel            | várt viselkedés                      |
| ------------------ | ------------------------------------ |
| `ArgumentError`    | hívd meg az `alertDeadSensor` függvényt. |
| `OverheatingError` | hajtsd végre a túlmelegedési protokollt. |
| _(bármi más)_      | dobd tovább a hibát                  |

**Túlmelegedési protokoll**
Ha a hőmérséklet kevesebb, mint 600 °C, kapcsold fel a figyelmeztető lámpát az `alertOverheating` függvény meghívásával.
Ha a hőmérséklet meghaladja a 600 °C-ot, a helyzet kritikus, ezért hívd meg a `shutdown` függvényt.

```javascript
monitorTheMachine({
  check,
  alertDeadSensor,
  alertOverheating,
  shutdown,
});
```
