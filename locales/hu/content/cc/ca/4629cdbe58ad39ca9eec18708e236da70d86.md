# Névjegy

A [guardok][guards] a [mintaillesztés][exercism-pattern-matching] kiegészítéseként szolgálnak. Segítségükkel összetettebb ellenőrzéseket is végezhetsz. [Némelyik, de nem mindegyik olyan helyzetben][where-guards-can-be-used] használhatók, ahol a mintaillesztés is, például függvényklózokban vagy `case`-ágakban.

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- A guardok a `when` kulcsszóval kezdődnek, amelyet egy Boolean-kifejezés követ.
- A guardkifejezések speciális függvények, amelyek:
  - [tisztának][pure-function] kell lenniük, és nem módosíthatnak semmilyen globális állapotot.
  - szigorúan `true` vagy `false` értéket kell visszaadniuk.
- A gyakori guardok listája az [Elixir dokumentációjában][kernel-guards] található. Ezek közé tartoznak:
  - Típusellenőrzések: [`is_integer/1`][guard-is-integer], [`is_list/1`][guard-is-list], [`is_nil/1`][guard-is-nil] stb.
  - Aritmetikai operátorok: [`+/2`][guard-plus], [`-/2`][guard-minus] stb.
  - Összehasonlítások: [`==/2`][guard-equals], [`>/2`][guard-greater], [`</2`][guard-less] stb.
  - Boolean-operátorok: [`and/2`][guard-and], [`or/2`][guard-or], [`not/1`][guard-not]
  - Tagsági operátor: [`in/2`][guard-in]
- Saját guardot is definiálhatsz a [`defguard`][defguard] segítségével.

  - Az Elixir [elnevezési konvenciója][naming] szerint a guardnevek `is_`-sel kezdődjenek.

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
