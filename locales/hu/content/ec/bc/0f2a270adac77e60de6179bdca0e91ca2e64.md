# Bevezetés

A szótár olyan elemek gyűjteménye, amelyben minden elem egy kulcsból és egy értékből áll, és ha átadunk egy kulcsot a szótár valamelyik metódusának, az visszaadja a hozzá tartozó értéket. Ugyanazt a szerepet tölti be, mint más nyelvekben a leképezések vagy az asszociatív tömbök.

Egy szótárt így hozhatsz létre:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Vagy:

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Fontos, hogy a kulcs és az érték típusa is a szótár definíciójának a része.

A létrehozás után a bejegyzéseket a szótár beépített `Add` és `Remove` metódusával adhatod hozzá vagy távolíthatod el.

Egy szótár értékeit kulcs segítségével indexelve kérheted le vagy frissítheted:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Azt, hogy egy érték létezik-e a szótárban, így ellenőrizheted:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Ha végigiterálsz egy szótáron, annak kulcs-érték párjain iterálsz végig. A szótáraknak vannak olyan tulajdonságaik is, amelyekkel a kulcsai vagy az értékei fölött iterálhatsz végig.
