# Bevezetés

## Map-ek

Az Elixirben a map-ek az adatszerkezet, amely kulcs-érték párokban tárolja az információt. Más nyelvekben ezeket asszociatív tömböknek (PHP), hash-eknek (Perl 5, Raku) vagy szótáraknak (Python) is nevezhetik.

A kulcsok és az értékek bármilyen adattípusúak lehetnek, de ha a kulcs atom, használhatunk rövidített szintaxist. A map-ek nem garantálják a bejegyzések sorrendjét sem eléréskor, sem visszaadáskor.

### Literál formák

Egy üres mapet egyszerűen a `%{}` szintaxissal deklarálunk. Ha elemeket szeretnénk hozzáadni egy map literálhoz, két formát használhatunk:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Bár nincs kanonikus formátum, válassz egy következetes módot a kulcs-érték literálpárok ábrázolására.

### A Map modul függvényei

Az Elixir számos függvényt kínál a map-ekkel való munkához a _Map modulban_. A _Map modul_ egyes függvényei _névtelen_ függvényt várnak paraméterként, amely segít a map átalakításában.

## Modulattribútumok mint konstansok

Az Elixirben definiálhatunk modulattribútumokat, amelyek konstansként használhatók a függvényeinkben.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Amikor modulkonstansok definiálására használjuk őket, az attribútumok bármilyen kifejezés lehetnek, amely kiértékelhető fordítási időben. A fordítás után a modulattribútumok nem érhetők el, mert a fordítás során kifejtődnek, akárcsak a C-hez hasonló nyelvekben a definiált makrók.
