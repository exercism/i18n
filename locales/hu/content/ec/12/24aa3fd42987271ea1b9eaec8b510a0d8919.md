# Bevezetés

Emlékeztetőül: a `jq` ugyanazokat az adattípusokat támogatja, mint a JSON.
A JSON a **stringeket** így írja le:

> A string nulla vagy több Unicode-karakterből álló sorozat, amelyet kettős idézőjelek zárnak közre, backslash escape-eket használva.

## Escape-szekvenciák

A stringen belül a backslash karakterrel „különleges” karaktereket ágyazhatsz be:

- `\"` egy szó szerinti idézőjel,
- `\\` egy szó szerinti backslash,
- whitespace karakterek `\n`, `\t`, `\r`, `\f`, `\b`
- unicode karakterek `\uAAAA`, ahol `A` egy hexadecimális számjegy

## String hossza

A karakterek számának megállapításához használd a `length` függvényt.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## Részstringek

A **szeletelés** jelöléssel részstringeket lehet kinyerni.
A szintaxis `.[i:j]`.
A visszaadott részstring hossza `j - i`, és az `i` indextől (beleértve) a `j` indexig (kizárólag) adja vissza a karaktereket.
Bármelyik index lehet negatív, ilyenkor a string végétől visszafelé számol.
Bármelyik index elhagyható, ilyenkor a string elejére vagy végére utal.
Az indexek nullától kezdődnek.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## Összefűzés

A stringek összefűzéséhez használd a `+` operátort:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Ha stringek tömbjét kapod, használd az `add` függvényt:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## Szétvágás és összefűzés

A szétvágáshoz a `split/1` függvényt vagy a `/` operátort használhatod:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

A `split/1` inverze a `join/1`.

Gyakran előfordul, hogy egy stringet karakterek tömbjévé kell alakítani.
Kétféleképpen teheted meg:

1. szétvágás üres stringre

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` egy _kódpontokból_ álló tömbbé

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   Az `implode` az `explode` inverze.

## Részstring indexének megkeresése

Használd az `index/1` függvényt; az index nullától kezdődik.

```jq
"hello" | index("el")'   # => 1
```

Ha a részstring nincs benne a stringben, az eredmény `null`

```jq
"hello" | index("elk")   # => null
```

## String-interpoláció

A stringen belül a `\(expression)` szekvencia beágyazza az adott kifejezés _eredményét_ [a stringbe][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## Kis- és nagybetű-átalakítás

Használd az `ascii_downcase` és `ascii_upcase` függvényeket.

A `jq` széles körű támogatást nyújt a reguláris kifejezésekhez: erről egy későbbi leckében lesz szó.
