# Break, Continue

Amikor ciklust vagy iteráló vezérlőszerkezetet használsz, a `break` és `continue` kulcsszavak segíthetnek a program folyamatának szabályozásában.
A `break` kulcsszó kilép a ciklus kontextusából a külső scope-ba, ezzel megszakítva a ciklust.
A `continue` kulcsszó kihagyja az aktuális iteráció hátralévő részét, és a ciklust a következő iteráció elején folytatja.
Bár ritkán fordul elő, a kulcsszóhoz megadható egy szám, amellyel szabályozható, hogy hány kontextusból lépjen ki, illetve hány szintet ugorjon a következő iterációra.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

Az előző példában a `continue` ötször (5) lefut, de a hatodik (6) iterációnál a `break` lefut, ami miatt a kód kilép a ciklusból.
