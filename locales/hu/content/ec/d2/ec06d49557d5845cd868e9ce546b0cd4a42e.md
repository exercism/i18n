# A fogalomról

A Factor bemenete és kimenete egyetlen [protokollra][stream-protocol] épül, amelyet bármely adatforrás vagy nyelő megvalósíthat. A beépített streamek (`<file-reader>`, `<file-writer>`, `<string-reader>`, `<string-writer>`, hálózati socketek, bájttömbök, tty-k) mind olyan osztályok, amelyek ugyanazt a néhány generikus szót valósítják meg az [`io`][io] szótárból, és kiterjesztik a [`destructors`][destructors] szótárból származó `disposable`-t.

```factor
USING: io ;

GENERIC: stream-read1        ( stream -- elt/f )
GENERIC: stream-read-unsafe  ( n buf stream -- count )
GENERIC: stream-write1       ( elt stream -- )
GENERIC: stream-write        ( seq stream -- )
GENERIC: stream-flush        ( stream -- )
GENERIC: stream-element-type ( stream -- type )
```

A `stream-read-unsafe` az alacsony szintű, kötegelt olvasást végzi: megtölti a hívó által megadott puffert, és visszaadja, hogy hány elemet írt bele. A nyilvános `stream-read` és `stream-read-partial` erre épül, és ők végzik a memóriafoglalást. A felhasználó által definiált streamek többsége vagy a `stream-read1`, vagy a `stream-read-unsafe` generikus szót valósítja meg: az előbbit akkor, ha az olvasás egyszerre egy elemet érint, az utóbbit akkor, ha az olvasás kötegelve történhet.

A `stream-element-type` két szingleton token egyikét adja vissza: `+byte+` a bájtstreameknél (fájlolvasók, socketek), `+character+` pedig a karakterstreameknél (stringolvasók, tty-k). A wrapper stream rendszerint egyszerűen továbbadja a feladatot a mögöttes streamnek.

## Csatlakozás a mixinekhez

```factor
INSTANCE: my-stream input-stream
INSTANCE: my-stream output-stream
```

Egy osztály lehet az egyik, a másik, vagy mindkettő. A mixinhez csatlakozva az `input-stream` / `output-stream` alapértelmezett metódusai a te osztályodra diszpécselnek, ugyanúgy, ahogy a `sets` szótárbeli `set` nyílt mixin mintája esetében.

## A disposable keretrendszer

A `new-disposable ( class -- disposable )` egy friss példányt regisztrál az aktuális destruktor-hatókörbe, így ha az erőforrások beállítása közben kivétel keletkezik, minden tisztán lezárul:

```factor
USING: destructors ;

[
    "log.txt" utf8 <file-writer>   ! registered automatically
    "log.txt" utf8 <file-reader>   ! and so is this one
    ! ... use them ...
] with-destructors
! both files closed even if an error is thrown above
```

A `dispose` a nyilvános szó; a `dispose*` az a generikus szó, amelyet az osztály megvalósít. Az alosztályban felülírt `dispose*` először takarítsa el a saját állapotát, majd szabadítsa fel a birtokában lévő erőforrásokat:

```factor
M: my-stream dispose* underlying>> dispose ;
```

A keretrendszer garantálja, hogy a `dispose*` objektumonként legfeljebb egyszer fut le: az ismételt `dispose` hívások nem csinálnak semmit.

## Hatókörhöz kötött accessorok

Három kombinator állítja be azt a globális „aktuális bemeneti/kimeneti streamet”, amelyet a `print`, a `read1` és hasonlók használnak:

```
with-input-stream   ( stream quot -- )    ! reads in quot use stream
with-output-stream  ( stream quot -- )    ! writes in quot use stream
with-disposal       ( disposable quot -- )! generic — any disposable
```

Mindegyik felszabadítja az erőforrást kilépéskor, akkor is, ha a quotation kivételt dob. A legtöbb kód így használ egyéni streamet, ahelyett hogy minden híváson keresztülvezetné.
