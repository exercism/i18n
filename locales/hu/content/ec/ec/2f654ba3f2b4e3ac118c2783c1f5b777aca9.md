# Részletek

## Struct típusok

Már találkoztunk struct típusokkal; összefoglalva, a `struct` névvel ellátott elemek sorozata, amelyeket _mezőknek_ nevezünk, és minden mezőnek van neve és típusa.
Egy mező nevének egyedinek kell lennie a structon belül.
A `Structs` az objektumorientált programozás _osztály_ fogalmához hasonlítható.

Új struct létrehozásához a `type` és a `struct` kulcsszavakat használod, majd explicit módon megadod a mezők nevét és típusát, ahogy az alábbi példán látható.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Nem struct típusok

Nem struct típusokat is definiálhatsz, amelyeket beépített típusdeklarációk aliasaként használhatsz.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Olyan nem struct típusokat is definiálhatsz, amelyek tömbökből és map-ekből állnak.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
