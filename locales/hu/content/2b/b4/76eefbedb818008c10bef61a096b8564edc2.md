# Bevezetés

## Tömbök

A Common Lispben, akárcsak más nyelvekben, a tömb elemek halmaza, amelyeket egész számú indexekkel érünk el.
Az elemek típusai különbözőek lehetnek.
A tömb lehet többdimenziós (nem csupán egydimenziós).

### Létrehozás

A `make-array` segítségével tömböket hozhatsz létre.
Számos beállítással rendelkezik, de az egyszerűbb formáival N-dimenziós tömböket hozhatsz létre úgy, hogy minden elem egyetlen értékre van inicializálva, vagy a tömb egy másik sorozat (például egy lista) értékeit kapja. 
Az első argumentuma egy lista, amely az egyes dimenziók méretét adja meg.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Figyeld meg, hogy az N-dimenziós tömbök a dimenziók számával együtt jelennek meg nyomtatáskor.)

A tömböket ugyanabban a formátumban is létrehozhatod, ahogyan nyomtatáskor megjelennek: 

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### Elemek elérése

Egy vektor elemeinek eléréséhez az `aref` függvényt használd; az indexek nullától kezdődnek. 
A megadott indexek számának meg kell egyeznie a tömb rangjával.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
