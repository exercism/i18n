# Utasítások

Egy olyan projekten dolgoztál, amely lehetővé teszi a felhasználóknak, hogy fájlokat töltsenek fel a szerverre, hogy más felhasználókkal megosszák azokat. Az a feladatod, hogy írj egy függvényt, amely ellenőrzi, hogy a feltöltött fájl megfelel-e a [médiatípusának][mimetype]. Utánanézel a dolgoknak, és rájössz, hogy egy fájl első néhány bájtja általában az adott fájltípusra jellemző, afféle aláírást adva neki.

Használd az alábbi táblázatot referenciaként:

| Fájltípus | Gyakori kiterjesztés | Médiatípus                   | bináris „aláírás”                                |
| --------- | -------------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`              | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`              | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`              | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`              | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`              | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. Kiterjesztés alapján add vissza a várt médiatípust

Valósítsd meg a `type_from_extension/1` függvényt. Bemenetként egy fájlkiterjesztést (string) vesz át, és visszaadja a médiatípust (string), vagy nil-t, ha a kiterjesztés nem egyezik a vártak egyikével sem.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. Bináris fájl alapján add vissza a várt médiatípust

Valósítsd meg a `type_from_binary/1` függvényt. Bemenetként egy fájlt (binary) vesz át, és visszaadja a médiatípust (string), vagy nil-t, ha a fájl aláírása nem egyezik a vártak egyikével sem.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

Ne foglalkozz azzal, hogy binárisként olvasd be a fájlt. Tekintsd úgy, hogy ezt már megtették helyetted, és a tesztek argumentumként adják át.

## 3. Kiterjesztés és bináris fájl alapján ellenőrizd, hogy a fájl a várt típusú-e

Valósítsd meg a `verify/2` függvényt. Bemenetként egy fájlt (binary) és egy kiterjesztést (string) vesz át, és egy `:ok` vagy `:error` tuple-t ad vissza.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
