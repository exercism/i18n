# Névjegy

A Lua két reprezentációt használ a számokhoz: 64 bites egész számokat és dupla pontosságú lebegőpontos számokat.

~~~exercism/note
Az 5.3-as verzió előtt a Lua minden számot dupla pontosságú lebegőpontos formátumban ábrázolt.
~~~

A számok felírhatók opcionális tizedesrésszel, valamint opcionális tizedes kitevővel.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

A tizedespontot vagy kitevőt tartalmazó szám lebegőpontosnak számít, a nélküle írt szám pedig egész számként kezelődik, de mindkettő típusa 'number'.
```lua
type(1)         --> number
type(2.0)       --> number
```

Ha meg akarjuk különböztetni a lebegőpontos számokat az egész számoktól, használhatjuk a `math` modul `type` függvényét.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## Összehasonlítás

Az azonos értékű egész és lebegőpontos számok egyenlőnek számítanak:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## Aritmetika

A Lua támogatja a szokásos aritmetikai operátorokat: összeadás, kivonás, szorzás, osztás és negáció. Ezenkívül támogatja a padlóosztást, a modulót és a hatványozást.

### Összeadás, kivonás, szorzás és negáció

Ha mindkét operandus egész szám, a művelet eredménye egész szám. Ugyanez érvényes a lebegőpontos számokra is.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

Ha az egyik operandus lebegőpontos szám, a többi egész szám is lebegőpontossá alakul, és a művelet eredménye lebegőpontos szám lesz.
```lua
1.0 + 2   --> 3.0
```

### Osztás

Az osztás mindig lebegőpontos számokon működik, és lebegőpontos eredményt ad.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

A nullával való osztás `inf` vagy `-inf` eredményt ad. A nulla nullával való osztása `-nan` eredményt ad.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### Padlóosztás

Ha egész eredményre van szükség, padlóosztást használhatunk. A padlóosztás mindig mínusz végtelen felé kerekíti a hányadost, így minden operandus esetén egész eredményt biztosít.

~~~exercism/note
Az 5.3-as verzió előtt a Luában nem volt aritmetikai operátor a padlóosztáshoz.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

A padlóosztás ugyanazokat a szabályokat követi, mint az összeadás, kivonás, szorzás és negáció operátorai: ha mindkét operandus egész szám, a művelet eredménye egész szám, egyébként az eredmény lebegőpontos szám.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

Ha padlóosztással osztunk nullával, a Lua hibát dob.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### Modulo

A modulo két operandus osztásának maradékát adja meg.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### Hatványozás

Az osztáshoz hasonlóan a hatványozás is lebegőpontos számokon működik, és lebegőpontos eredményt ad.
```lua
10 ^ 2    --> 100.0
```

## Műveleti sorrend

Minden művelet a [műveleti sorrend](https://www.lua.org/manual/5.4/manual.html#3.4.8) szerint értékelődik ki. Zárójelekkel módosítható egy kifejezés műveleti sorrendje.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## Kerekítés

A `math` modul három kerekítő függvényt biztosít: a `floor` „lefelé” kerekít (mínusz végtelen felé), a `ceil` „felfelé” kerekít (plusz végtelen felé), a `modf` pedig nulla felé kerekít.

### `math.floor`

A `floor` mínusz végtelen felé kerekít.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

A `ceil` plusz végtelen felé kerekít.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

A `modf` nulla felé kerekít. A függvény visszaadja a kerekített értéket, valamint a szám tört részét, amely mindig lebegőpontos szám.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## Átalakítás

Ha egész számot szeretnénk lebegőpontos számmá alakítani, hozzáadhatunk `0.0`-t.
```lua
1 + 0.0         --> 1.0
```

Ha lebegőpontos számot szeretnénk egész számmá alakítani, bitenkénti VAGY műveletet végezhetünk vele nullával, vagy használhatjuk a `math` modul `tointeger` függvényét.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

Ha a szám nem alakítható egész számmá, a VAGY operátor hibát dob, a `tointeger` függvény pedig `nil`-t ad vissza.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## Hexadecimális

Mint sok más programozási nyelv, a Lua támogatja a hexadecimális számokat azzal, hogy `0x` előtagot tesz eléjük, de sok más programozási nyelvtől eltérően a Lua a lebegőpontos hexadecimális számokat is támogatja. Ezek rendelkezhetnek tört résszel és bináris kitevővel, amelyet 'p' vagy 'P' előtag jelöl.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
