# Utasítások

Elena, az újsággyár új minőségbiztosítási vezetője arra kér, hogy írj egy kis szoftvert a termelőterem felügyeletére.

## 1. Definiálj egy egyedi hibát

Definiálj egy `machine-error` hibatuple-osztályt az `ERROR:` feldolgozó szóval. Nem igényel slotokat.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. Ellenőrizd a páratartalmat

Definiáld a `check-humidity` szót. Levesz a veremről egy páratartalom-értéket, és `throw`-val dobja a `"humidity too high"` stringet, ha az érték szigorúan nagyobb, mint `70`. Egyébként nem ad vissza semmit.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. Ellenőrizd a hőmérsékletet

Definiáld a `check-temperature` szót. Levesz egy hőmérséklet-értéket, és `throw`-val dobja a `"temperature too high"` stringet, ha az érték szigorúan nagyobb, mint `500`. Egyébként nem ad vissza semmit.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. Figyeld a gépet

Definiáld a `monitor` szót úgy, hogy levegyen a veremről egy páratartalmat és egy hőmérsékletet, és lefuttassa mindkét ellenőrzést. Ha valamelyik ellenőrzés dob, a `monitor` helyette egy friss `machine-error`-t dobjon. Ha mindkettő sikeres, a `monitor` nem ad vissza semmit.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. Figyelj egy adag mérést

Definiáld a `monitor-batch` szót úgy, hogy levegyen a veremről egy `{ humidity temperature }` mérésekből álló tömböt, és adja vissza, hány hibázna közülük (azaz hány okozná, hogy a `monitor` dob).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
