# Telepítés

Ahhoz, hogy futtasd ezeket a feladatokat, mindössze a [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) és a [Java 8](https://java.com/en/download/) telepítésére lesz szükséged. A CommandBox CLI támogatott Macen, Linuxon és Windowson, a telepítési útmutatót pedig itt találod:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

Íme egy példa a CommandBox CLI beállítására, ha Macen Homebrew-t használsz:

```bash
brew install commandbox
```

Miután telepítetted a parancssori felületet, játszhatsz a REPL-lel:

```bash
box repl
```

Közvetlenül futtathatsz .cfm oldalakat:

```bash
box exec myTest.cfm
```

Sőt, akár webszervert is indíthatsz a merevlemezed bármelyik könyvtárában:

```bash
box server start
```

A CommandBox rendelkezik egy interaktív shell-lel, amelyet használhatsz; ez fejlettebb tab-kiegészítést kínál, és gyorsabban fut. Beléphetsz úgy, hogy egyszerűen lefuttatod a `box` binárist argumentumok nélkül.

```bash
box
```
