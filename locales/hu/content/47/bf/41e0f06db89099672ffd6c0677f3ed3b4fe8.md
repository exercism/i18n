# Telepítés

Az elm jelenlegi verziója a 0.19.1.
A telepítési útmutatók a nyelv fejlődésével változnak.
A naprakész telepítési útmutatóért keresd fel az [elm útmutató telepítési leírását][elm-install].

[elm-install]: https://guide.elm-lang.org/install/elm.html

## További eszközök

**elm-test**

A parancssori tesztek futtatásához használt eszköz neve elm-test.
Jelenleg az elm-test használatához Node.js és npm szükséges, ezért ha még nem tetted meg, először [telepítsd a Node.js-t és az npm-et][npm-install].
Ha már telepítetted az npm-et, az elm-testet a következővel telepítheted:

```shell
npm install --global elm-test@latest-0.19.1
```

További információ az [elm-test npm-oldalán][elm-test].

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

A legtöbb elm programozó az elm-formatot használja az elm kód formázására.
Ez egy konfigurációmentes kódformázó eszköz.
Eleinte kissé frusztrálónak tűnhet, ha nem szoktál hozzá az automatikus formázóeszközökhöz, de miután megszoktad, elkezded azon gondolkodni, hogyan kódolhattál korábban nélküle.
Ez is telepíthető npm segítségével:

```shell
npm install --global elm-format@latest-0.19.1
```

További információ az [elm-format GitHub-oldalán][elm-format].

[elm-format]: https://github.com/avh4/elm-format

**Szövegszerkesztő**

Az elm támogatása jó legalább az [IntelliJ][intellij] esetében, valamint az olyan szövegszerkesztőknél, amelyek kompatibilisek az [elm nyelvi szerverrel][els], például a VS Code, a Sublime Text vagy a Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## Engedélyhibák az npm használatakor

Előfordulhat, hogy EACCESS engedélyhibába ütközöl az npm használatakor, amikor az elm-testet vagy az elm-formatot telepíted.
Ha ez a helyzet, kövesd az npm weboldalán található utasításokat.
[Az EACCES engedélyhibák megoldása csomagok globális telepítésekor][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
