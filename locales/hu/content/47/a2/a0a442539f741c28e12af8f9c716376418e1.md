# Bevezetés

## Generikus típusok

### Bevezetés

A generikus típusok olyan nyelvi funkció, amely lehetővé teszi a kód újrafelhasználását.
Például egy lista hosszának kiszámításához nem számít, hogy a lista milyen típust tárol.
Ezért a `length` függvény egy generikus `a` típusparamétert használ a típusszignatúrájában.

```elm
length : List a -> Int
```

### Paraméterek a típusokban

Amikor egy típus generikus egy másik típus fölött, akkor arra a másik típusra kisbetűs nevet használunk, és típusparaméternek nevezzük.
Gyakori példák a `List`, a `Maybe` és a `Result` egyedi típusok.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

A típusparaméterek nevével kapcsolatban fontos megjegyzés, hogy több karakterből is állhatnak.
Az egyetlen megkötés, hogy kisbetűs neveknek kell lenniük.
Ezért amikor hasznos, igyekszünk beszédes neveket adni nekik.

Egy típus több másik típus fölött is lehet generikus, és így több típusparamétere is lehet.
Ebben az esetben minden független típus más kisbetűs nevet kap.
Az, hogy függetlenek, nem akadályozza meg, hogy ugyanaz a típus legyen belőlük, csak lehetővé teszi, hogy különbözőek legyenek.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

A rekordtípus-aliasoknak is lehetnek típusparamétereik, bár ez kevésbé gyakori.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### Típusparaméterek a függvényekben

Mivel a típusok lehetnek generikusak, a függvények is azok lehetnek.
Készíthetünk olyan függvényeket, amelyek generikus típusokkal dolgoznak, például a `Maybe.withDefault`-ot.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Azokat a függvényeket, amelyek más függvényeket vesznek át paraméterként, magasabb rendű függvényeknek nevezzük, és ezek is lehetnek generikusak.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
