# függvényfejléc használata

[comment]: # (Ez a hiba akkor jelenik meg, ha a megoldás függvényfejlécet használ)

Függvényfejléc (vagyis törzs nélküli függvénydefiníció) csak akkor kell, ha egy függvénynek alapértelmezett argumentumai vannak, és ezek több klauzulában is szerepelnek.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

Ha egy alapértelmezett argumentumokkal rendelkező függvénynek csak egyetlen klauzulája van, akkor az alapértelmezett argumentumokat közvetlenül ebben a klauzulában adhatod meg.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

A `two_fer/1` függvénynek elég egyetlen klauzula, így nincs szüksége függvényfejlécre.
