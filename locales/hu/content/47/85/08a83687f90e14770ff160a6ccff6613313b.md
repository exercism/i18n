# Tuple-ök

A tuple-ök könnyűsúlyú módja annak, hogy rögzített számú, tetszőleges típusú adatot fogjunk össze egy csoportba. Egy tuple-nek nincs saját neve; ha nevet adunk egy adatszerkezetnek, azzal `struct`-tá alakítjuk. A tuple mezőinek sincs nevük; a mezők elérése destrukturálással vagy pozíció alapján történik.

## Szintaxis

A tuple zárójelek közé írt mezők listája:

- A `()` az `unit type`, ami egy [különleges eset](https://doc.rust-lang.org/std/primitive.unit.html)
- A **(** _kifejezés_ **,)** egy egyelemű tuple-kifejezés
- A **(** _Típus_ **,)** egy egyelemű tuple-típus
- A **(** _kifejezés_ **,** ... **)** egy általános tuple-kifejezés
- A **(** _Típus_ **,** ... **)** egy általános tuple-típus

### Létrehozás

A tuple-öket mindig tuple-kifejezéssel hozzuk létre:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

A tuple-öknek tetszőleges számú elemük lehet.

### Elérés destrukturálással

A tuple elemeihez destrukturálással is hozzáférhetünk. Ez nem jelent mást, mint hogy a tuple egyes elemeihez külön változóneveket rendelünk, amivel a tuple-t felhasználjuk.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Elérés pozíció szerint

A tuple elemeihez numerikus pozíció szerinti indexeléssel is hozzáférhetünk. Az indexelés, mint mindig, 0-tól kezdődik.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Tuple struktúrák

A tuple struktúrákkal is fogsz dolgozni. A normál struktúrákhoz hasonlóan ezek is nevesített típusok, a normál struktúráktól eltérően viszont névtelen mezőkkel rendelkeznek. A szintaxisuk nagyon hasonlít a normál tuple-szintaxishoz. Mind a destrukturálás, mind a pozíció szerinti elérés használható.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### Mezők láthatósága

A névtelen tuple-ök minden mezője mindig nyilvános. A tuple struktúrák mezői viszont külön-külön láthatósággal rendelkeznek, amely alapértelmezésben privát, akárcsak a normál struktúrák mezői. A mezőket a `pub` módosítóval teheted nyilvánossá, ugyanúgy, ahogy egy normál struktúrában.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
