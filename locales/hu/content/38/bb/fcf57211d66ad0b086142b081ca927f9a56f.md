# Bevezetés

## Metódus-túlterhelés

A Java nyelvben a metódus-túlterhelés egy olyan lehetőség, amelynek segítségével egy osztálynak több azonos nevű metódusa is lehet, ha a paraméterlistáik eltérnek.
A fordítási idejű (vagy statikus) polimorfizmushoz kapcsolódik.
Ez a fogalom kulcsfontosságú ahhoz, hogy hasonló feladatokat ellátó, de eltérő bemenetű metódusokat hozzunk létre.

### Miért érdemes túlterhelni a metódusokat?

A metódus-túlterhelés növeli a program olvashatóságát.
Különböző metódusoknak lehet ugyanaz a nevük, de eltérő paramétereik vannak.
A paraméterek számától vagy típusától függően a megfelelő metódus hívódik meg.

### Hogyan terheljük túl a metódusokat?

A metódus-túlterhelés kulcsa a metódus szignatúrája.
Két metódus akkor számít különbözőnek, ha eltér a szignatúrájuk.
Kétféleképpen terhelhetünk túl egy metódust:

1. **Eltérő paraméterszám**: A metódusoknak lehet ugyanaz a nevük, de eltérő lehet a paraméterszámuk.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Eltérő paramétertípusok**: A metódusoknak lehet ugyanaz a nevük és ugyanannyi paraméterük, de eltérő típusúak.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### Fontos tudnivalók

- A túlterhelt metódusoknak meg kell változtatniuk az argumentumlistát.
- A túlterhelt metódusok a visszatérési típust is megváltoztathatják, de pusztán a visszatérési típus megváltoztatása önmagában még nem metódus-túlterhelés.
- A metódusok ugyanabban az osztályban vagy egy alosztályban is túlterhelhetők.

E fogalom során a metódus-túlterhelés különféle példáit és árnyalatait járjuk körbe Java nyelven.
