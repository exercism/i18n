# Bevezetés

## Hibák

A hibákat érdemes jelezni, ha valami hibás vagy váratlan dolog történik egy programban vagy egy kódrészletben.

Ezek JavaScript-objektumok.

Az objektum legfontosabb tulajdonsága a `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

A `throw` szintaxissal hibát dobhatsz.

```javascript
throw new Error('Oops');
```

Amikor egy hiba eldobódik, a jelenlegi végrehajtás leáll, és a hívási verem első catch blokkjában folytatódik.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## Öröklődés

Az öröklődés lehetőséget ad arra, hogy szülő-gyermek kapcsolatot hozz létre osztályok között.
A gyermekosztály (amit néha _alosztálynak_ neveznek) hozzáfér a szülőosztály (amit néha _ősosztálynak_ neveznek) által meghatározott viselkedéshez és adatokhoz.

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

Az `extends` kulcsszó a gyermekosztály deklarációjában a [prototípusláncon][prototype-chain] keresztül teremt kapcsolatot a szülőosztállyal.

A gyermek konstruktorával létrehozott objektumok prototípusláncában ott lesz a szülőosztály prototípusa, így hozzáférnek a szülő által meghatározott metódusokhoz és adatokhoz.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

Ahogy a JavaScript minden osztályánál, az alosztályok örökölhetnek az `Error` osztályból, hogy az `extends` kulcsszóval egyedi hibákat hozzanak létre.
Az `instanceof` szintaxis ellenőrzi, hogy az elkapott hiba az `Error` egy adott alosztályának példánya-e.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
