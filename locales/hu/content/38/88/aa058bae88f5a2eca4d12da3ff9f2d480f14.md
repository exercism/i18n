# Névjegy

A Swiftnek van egy beépített [`Bool`][bools] típusa, amely az igazságértékeket reprezentálja: a `true` és a `false` értéket.

## Logikai operátorok

A Swiftben három [logikai operátor][logical-operators] van (`!`, `&&` és `||`), amelyekkel Boolean-kifejezéseket lehet kombinálni és kiértékelni.

### Logikai ÉS (`&&`)

Az [_és_ operátor][and] (`&&`) csak akkor ad vissza `true`-t, ha mindkét operandus `true`.
Ha valamelyik operandus `false`, akkor `false`-t ad vissza.
A `&&` jel mindkét oldalára egy-egy kifejezést vagy Boolean értéket tegyél:

```swift
true && true  // true
true && false // false
```

### Logikai VAGY (`||`)

A [_vagy_ operátor][or] (`||`) akkor ad vissza `true`-t, ha az operandusok közül **legalább az egyik** `true`.
Csak akkor ad `false`-t, ha mindkét operandus `false`.
A `||` jel mindkét oldalára egy-egy kifejezést vagy Boolean értéket tegyél:

```swift
true || true   // true
true || false  // true
false || false // false
```

### Logikai NEM (`!`)

A [_nem_ operátor][not] (`!`) megfordítja a Boolean értékét.
`true`-t ad vissza, ha az érték `false`, és `false`-t, ha az érték `true`.
A `!` operátort közvetlenül az érték vagy a kifejezés elé írd:

```swift
!true  // false
!false // true
```

## A zárójelek használata (`()`)

A [zárójelekkel][explicit-parentheses] kifejezéseket csoportosíthatsz, és szabályozhatod a kiértékelés sorrendjét.
A Swiftben először a zárójelben lévő kifejezések értékelődnek ki:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

A zárójelezés azt is meghatározza, hogy a NEM operátor hogyan érvényesül az összetett kifejezésekben:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Akkor használj zárójelet, ha tisztázni szeretnéd a kiértékelés sorrendjét, vagy olvashatóbbá akarsz tenni egy összetett feltételt.
Kerüld a felesleges zárójeleket, ha az alapértelmezett precedencia egyébként is világos.
~~~~
