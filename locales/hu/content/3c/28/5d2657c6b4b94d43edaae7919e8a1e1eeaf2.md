# Bevezetés

## Rekurzió

A rekurzív függvények olyan függvények, amelyek meghívják önmagukat.

Egy rekurzív függvénynek legalább egy _alapesetre_ és legalább egy _rekurzív esetre_ van szüksége.

Az _alapeset_ úgy ad vissza egy értéket, hogy nem hívja meg újra a függvényt. A _rekurzív eset_ újra meghívja a függvényt, és közben úgy módosítja a bemenetet, hogy az előbb-utóbb megfeleljen az alapesetnek.

Nagyon gyakran külön függvényklózban írjuk meg az egyes eseteket.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
