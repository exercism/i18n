# Bevezetés

Az objektumok _példányváltozók_ beállításával tárolhatják saját állapotukat. A példányváltozókat úgy hozzuk létre, hogy egy változónév elé `@` jelet írunk.

```ruby
@name = 2
```

Az objektumok rendszerint az `initialize` metódusban állítják be a kezdeti állapotukat, amely automatikusan meghívódik, amikor meghívjuk a `new`-t egy osztályon.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

Az `initialize` metódus argumentumokat is kaphat, így minden példány egyedi állapottal indulhat:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

A _példányváltozókat_ tekintsd privátnak külső olvasás és írás szempontjából. A példányváltozók lekérdezésére és beállítására _példánymetódusokat_ érdemes használni:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
