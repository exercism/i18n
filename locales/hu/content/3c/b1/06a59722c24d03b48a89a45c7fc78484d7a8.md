# Bevezetés

A `let` kifejezés egy lokális scope létrehozására szolgál, és néhány helyzetben hasznos:

- Kifejezések egyszerűsítésére
- Közbenső kifejezések eredményeinek elnevezésére
- Egy kifejezés kisebb részekre bontására, ha az már túl nagyra nő

A `let` kifejezésen belül a legtöbb dolgot megteheted, beleértve a destrukturálást is (erről a későbbi feladatokban lesz részletesebben szó), de új Custom Type-ot vagy Type Alias-t nem definiálhatsz.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
