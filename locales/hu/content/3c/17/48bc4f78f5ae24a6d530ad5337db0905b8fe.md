# Bevezetés

## Összehasonlító operátorok

A Julia összehasonlító operátorai sok más nyelvéhez hasonlítanak, de a matematikakedvelőknek néhány extra lehetőséget is kínálnak.

Az egyenlőség vizsgálatára a `==` (egyenlő), valamint a `!=` vagy `≠` (nem egyenlő) operátor szolgál.

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

Emellett ott vannak a különféle nagyobb/kisebb operátorok is.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Ahogy a Juliában gyakran, egy megfelelő szerkesztő megkönnyíti a matematikai szimbólum használatát. Írd be a `\ne`, `\le` vagy `\ge` karaktersorozatot, majd nyomd meg a `TAB` billentyűt, és megkapod a `≠`, `≤` vagy `≥` jelet.

Az előző példa csak számokat használ, de a tanterv más részein látni fogjuk, hogy számos további típusnak is van rendezési viszonya, és vizsgálhatók nagyobb/kisebb relációban.

Az összehasonlító operátorok láncolhatók, ami világos és tömör szintaxist tesz lehetővé:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

Az előző példa ugyanaz, mint a `1 ≤ n && n ≤ 5`.

## Elágazás `if`-fel

Ez az elágazás teljes formája:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

Nincs szükség zárójelekre `()` vagy kapcsos zárójelekre `{}`, a behúzás pedig „csak” az olvashatóságot javítja _(de az olvashatóság nagyon fontos!)_. 

Az `elseif` és az `else` is elhagyható, és több `elseif` blokk is lehet.
Az `end` viszont kötelező.

Az elágazások egymásba ágyazhatók, bár az olvashatóság érdekében érdemes átgondoltan használni a zárójeleket, a behúzásokat és a megjegyzéseket.

Az elágazás legrövidebb formája valahogy így néz ki:

```julia
if n < 0
    n = 0
end
```

Emlékeztetőül: feltételként csak olyan kifejezéseket használhatsz, amelyek kiértékelése `true` vagy `false` eredményt ad.
A Julia szándékosan kerüli a „truthiness” bármilyen fogalmát, így a nullértékek, az üres stringek és az üres tömbök _nem_ egyenértékűek a `false` értékkel. 

## A ternáris operátor

Egyszerű és gyakori helyzet, amikor egy feltétel alapján két érték közül kell választani.

A Julia sok más nyelvhez hasonlóan rendelkezik ternáris operátorral, hogy ezt tömörebbé tegye.

A szintaxis: `conditional ? value_if_true : value_if_false`.

Így az előző példa átírható:

```julia
n = n < 0 ? 0 : n
```

A fordító nem követeli meg a zárójeleket, de azok javíthatják az olvashatóságot.
