# Bevezetés

A metódus egy olyan függvény, amelynek van egy speciális _receiver_ argumentuma.
A receiver a saját argumentumlistájában, a `func` kulcsszó és a metódus neve között jelenik meg.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

Csak olyan receiverrel definiálhatsz metódust, amelynek típusa ugyanabban a csomagban van definiálva, mint maga a metódus.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

A struktúrához tartozó metódust pontszintaxissal hívhatod meg.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

Figyeld meg, ahogy a `Greetings()` metódust meghívtuk a `p` nevű `Person` példányon.
Pontosan úgy, ahogy egy objektumorientált programozási nyelvben hívod meg a metódusokat.

Ne feledd: a metódus nem más, mint egy függvény receiver argumentummal.
A metódusok segítenek elkerülni a névütközéseket: mivel egy metódus egy adott receiver típushoz kötődik, ugyanazt a metódusnevet használhatod különböző típusokon.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

Kétféle receiver létezik: érték szerinti és mutató szerinti.

Az eddig látott metódusok mind érték szerinti receivert használnak, ami azt jelenti, hogy a metódusnak átadott érték egy másolatát kapják meg, így a metóduson belül a receiveren végzett módosítások nem láthatók a hívó számára.

Mutató szerinti receiverrel is deklarálhatsz metódusokat, hogy módosítani tudd azt az értéket, amelyre a receiver mutat.
Ezt úgy éred el, hogy a típusnév elé egy `*`-ot teszel.
Például a `rect` típusnál egy mutató szerinti receiver így nézne ki: `*rect`.
Az ilyen módosítások a metódus hívója számára is láthatók.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
