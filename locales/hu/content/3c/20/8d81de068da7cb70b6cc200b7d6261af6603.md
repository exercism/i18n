# Névjegy

## Escaping függvények

Van úgy, hogy egy magasabb rendű függvény paraméterként kap egy másik függvényt, és úgy használja fel, hogy az átadott függvény a magasabb rendű függvény lefutása _után_ hívódik meg. Ezt nevezzük a magasabb rendű függvényből való escapingnek, az átadott függvény pedig az [escaping függvény][escaping] nevet kapja.

Ez legtöbbször aszinkron kódban fordul elő, de olyan magasabb rendű függvényeknél is előfordulhat, amelyek visszaadják az átadott függvényt (vagy egy olyan függvényt, amely meghívja azt). Például:

```swift
func emptyKitchen(_ order: String) -> String {
  "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}
```

Itt a `prepare` függvény egy függvényt fogad el a `kitchen` paraméteréhez, majd létrehoz egy új `newKitchen` függvényt, amely meghívhatja a `kitchen`-t. A `newKitchen` függvényt ezután visszaadja a hívónak. Ha Swiftben megpróbálod megírni ezt a függvényt, ezt a hibát kapod: _Escaping local function captures non-escaping parameter 'kitchen'_

A Swift azért jelez hibát ebben az esetben, mert vannak olyan helyzetek, amikor az egymásba ágyazott vagy az átadott függvény elkaphat egy olyan értéket, amely memóriaszivárgáshoz vezethet. Az, hogy ez hogyan történik, és hogyan lehet megelőzni ezeket a szivárgásokat, meghaladja ennek a feladatnak a kereteit. Ez a hiba azonban orvosolható azzal, hogy az `@escaping` attribútumot az átadott függvény típusa elé tesszük.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}

let restaurant =
  prepare(order: "sandwich",
          kitchen: prepare(order: "chicken",
                           kitchen: prepare(order: "steak",
                                            kitchen: emptyKitchen)))

restaurant("pork chop")
// => "Sorry, we're all out of pork chop."
restaurant("chicken")
// => "One chicken coming up!"
```

Ez az attribútum jelzi a Swift-fordítónak, hogy a szerző tisztában van vele: ha engedélyezi ennek a függvénynek az escapingjét, memóriaszivárgás fordulhat elő.

[escaping]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID546
