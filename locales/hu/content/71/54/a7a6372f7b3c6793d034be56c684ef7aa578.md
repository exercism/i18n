# Utasítások

Kezdő bűvészként Elyse-nek gyakorolnia kell néhány alapvető dolgot.
Van egy pakli kártyája, amit szeretne ügyesen kezelni.

Hogy egy kicsit könnyebb legyen a dolga, csak az 1-től 10-ig terjedő kártyákat használja.

## 1. Készíts egy slice-ot bizonyos kártyákból

Amikor a kártyáival gyakorol, Elyse szeret a pakli három kedvenc kártyájával kezdeni: a 2-essel, a 6-ossal és a 9-essel.
Írj egy `FavoriteCards` nevű függvényt, amely egy slice-ot ad vissza ezekkel a kártyákkal, ebben a sorrendben.

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. Kérj le egy kártyát a pakliból

Add vissza a megadott pakliból az `index` pozícióban lévő kártyát.

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

Ha az index a pakli határain kívül esik (azaz negatív, vagy a pakli vége után van), akkor `-1`-et adunk vissza:

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
A Go-ban megszokás, hogy hibaértéket adunk vissza a „tartományon kívüli” érték helyett.
Itt a „tartományon kívüli” érték a `-1`, amikor pozitív egész számot várunk.
Hiba visszaadásakor idiomatikusnak számít a hiba mellett a [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/) értéket is visszaadni.
Hogy hogyan adjunk vissza hibát a megfelelő visszatérési értékkel, arról egy későbbi feladatban lesz szó.
~~~~

## 3. Cserélj ki egy kártyát a pakliban

Cseréld ki a pakliban az `index` pozícióban lévő kártyát a megadott új kártyára, és add vissza a módosított paklit.
Figyelj rá, hogy ez módosítani fogja a bemeneti slice-ot, ami az elvárt viselkedés.

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

Ha az index a pakli határain kívül esik (azaz negatív, vagy a pakli vége után van), akkor az új kártyát a pakli végéhez fűzzük:

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. Adj kártyákat a pakli tetejére

Add hozzá a `value` paraméterben megadott kártyát vagy kártyákat a pakli tetejéhez.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

Ha a `value` paraméterhez nem adunk meg argumentumot, akkor az eredmény megegyezik az eredeti slice-szal.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. Vegyél ki egy kártyát a pakliból

Távolítsd el a pakliból az `index` pozícióban lévő kártyát, és add vissza a paklit.
Figyelj rá, hogy ez módosíthatja a bemeneti slice-ot, és ez így rendben van.

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

Ha az index a pakli határain kívül esik (azaz negatív, vagy a pakli vége után van), akkor a paklit változatlanul hagyjuk:

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
