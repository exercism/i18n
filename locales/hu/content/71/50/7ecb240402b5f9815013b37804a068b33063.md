# Tesztek

## Tesztek futtatása

Amikor egy feladat könyvtárában vagy, két alkönyvtárat kell látnod:

* `Sources/<Exercise>` tartalmazza a feladat megoldását
* `Tests/<Exercise>Tests` tartalmazza a feladathoz futtatandó teszteket

Ha a megfelelő könyvtárban vagy (vagyis abban, amelyik tartalmazza a `Sources` és a `Tests` könyvtárat), akkor a feladat tesztjeit a `swift test` futtatásával indíthatod el:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Amikor egy teszt sikeresen lefut, távolítsd el a `.enabled(if: RUNALL)` részt a `@Test` utasításból, hogy engedélyezd a következő tesztet. Másik lehetőség, hogy az összes tesztet lefuttatod úgy, hogy a `RUNALL` környezeti változót `true` értékre állítod Linuxon vagy macOS-en:

```bash
$ export RUNALL=true
```

Vagy ha Windows-on PowerShellt használsz:

```powershell
set RUNALL=true
```

## A megoldásod beküldése

Ahhoz, hogy feltölts egy megoldást az Exercismre, abban a könyvtárban kell lenned, amelyik tartalmazza a `Sources` és a `Tests` könyvtárat.

```bash
$ exercism submit 
```
