# Utasítások

Ebben a feladatban egy szerepjáték mechanikáit fogod megvalósítani.
A játékos karakterét a következő típus írja le:

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

A játékban a játékosoknak el kell érniük a 10. szintet, hogy feloldják a manapooljukat, és elkezdhessenek varázslatokat szórni.
Ebben a játékban két funkcióval foglalkozol: a feltámasztás és a varázslás mechanikájával.

## 1. Mutatkozz be

Írd meg az `introduce` függvény tartalmát.
A lopakodó játékosok elrejthetik a nevüket, és `"Mighty Magician"` néven mutatkoznak be.
Egyébként egyszerűen a saját neveddel mutatkozz be.

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. Valósítsd meg a feltámasztás mechanikáját

A `revive` függvénynek ellenőriznie kell, hogy a játékos karaktere valóban halott-e (az életereje elérte a 0-t).
Ha igen, egy új `Player` példányt kell visszaadnia 100 életerővel.
Ellenkező esetben, ha a játékos karaktere nem halott, a `revive` függvény `Nothing`-t ad vissza.

Ha a játékos szintje 10 vagy annál magasabb, akkor 100 manával kell feltámasztani.
Ha a játékos szintje 10 alatt van, a manája `Nothing` legyen.
A `revive` függvénynek meg kell őriznie a játékos szintjét.

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

Ha a `revive` metódust olyan játékoson hívod meg, akinek az életereje 1 vagy annál több, akkor a függvénynek `Nothing`-t kell visszaadnia.

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. Valósítsd meg a varázslás mechanikáját

A `castSpell` függvény argumentumként egy `Int`-et kap, amely megadja, mennyi manába kerül a varázslat, valamint egy `Player`-t.
Visszaadja a frissített játékost, valamint az elszórt varázslat által okozott sebzés mértékét.
Egy sikeres varázslás a varázslat manaköltségének kétszeresével egyenlő sebzést okoz.
Ha azonban a játékosnak nincs elég manája, semmi sem történik, a játékos változatlan marad, és nem keletkezik sebzés.
Ha a játékosnak még manapoolja sincs, a varázslás kísérletekor az életereje a varázslat manaköltségével csökken, és nem okoz sebzést.

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
