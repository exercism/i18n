# Bevezetés

## Alapok

A Java statikusan típusos nyelv, ami azt jelenti, hogy egy változó típusa fordítási időben ismert.
Egy érték névhez rendelését a változó definiálásának nevezzük.
A változót úgy definiáljuk, hogy explicit módon megadjuk a típusát.

```java
int explicitVar = 10;
```

A változó értékének frissítése a `=` operátorral történik.
Itt a `=` nem matematikai egyenlőséget jelöl.
Egyszerűen értéket rendel egy változóhoz.
A változó típusa a definiálás után soha nem változhat.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

A Java egy [objektumorientált nyelv][object-oriented-programming], és megköveteli, hogy minden függvény egy _osztályban_ legyen definiálva.
A `class` kulcsszó egy osztály definiálására szolgál.

```java
class Calculator {
    // ...
}
```

Egy osztályon belüli függvényt _metódusnak_ nevezünk.
Minden metódusnak lehet nulla vagy több paramétere.
Minden paraméter típusát explicit módon meg kell adni, a paramétereknél nincs típuskövetkeztetés.
Hasonlóképpen a visszatérési típust is explicit módon meg kell adni.
A metódusok az értékeket a `return` kulcsszóval adják vissza.
Ahhoz, hogy egy metódust más osztályok is meghívhassanak, hozzá kell adni a `public` hozzáférés-módosítót.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Egy metódus meghívása úgy történik, hogy megadjuk az osztályát és a metódus nevét, valamint argumentumokat adunk át a metódus minden paraméteréhez.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

A scope Javában a `{` és `}` karakterek között van definiálva.

A Java kétféle kommentet támogat.
Az egysoros kommenteket `//` előzi meg, a többsoros kommenteket pedig `/*` és `*/` közé kell illeszteni.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
