# Bevezetés

A legtöbb szekvenciakezelő Factor-szó *új* szekvenciát ad vissza, a bemeneteit pedig érintetlenül hagyja, de a tömbök és a vektorok is támogatják a **helyben történő módosítást**, ha olyan állapotot akarsz rögzíteni, ami idővel változik.

A `set-nth` és a `change-nth` egy-egy helyet módosít helyben, és ugyanúgy működik tömbön és vektoron is. Az `<array>` egy rögzített hosszúságú, módosítható tömböt hoz létre; a `V{ }` literálok, a `<vector>`, a `push` és a `pop` a csak vektoroknál használható készlet, mert a tömbök hossza nem változtatható. A `clone` lemásolja a szekvenciát, így a további módosítások nem szivárognak át az eredetibe.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
