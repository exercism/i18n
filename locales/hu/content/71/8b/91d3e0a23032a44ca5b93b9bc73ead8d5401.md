# Utasítások

Ebben a feladatban egy készletnyilvántartó rendszert fogsz kezelni.

A készletet a tételnév szerint kell rendszerezni, és nyilván kell tartania a rendelkezésre álló tételek számát.

Foglalkoznod kell a tételek hozzáadásával is.
Valahányszor egy tétel megjelenik egy adott listában, a tétel mennyiségét `1`-gyel kell növelni a készletben.
Azzal is foglalkoznod kell, hogy tételeket törölj a készletből úgy, hogy kérésre `1`-gyel csökkented a mennyiségüket.

Végül implementálnod kell egy függvényt, amely egy adott készlet összes kulcs-érték párját `tuples`-ok `list`-jeként adja vissza.


## 1. Készlet létrehozása egy lista alapján

Implementáld a `create_inventory(<input list>)` függvényt, amely egy bemeneti tétellistából létrehoz egy „készletet”.
Egy `dict`-et adjon vissza, amely minden tételnevet a hozzá tartozó mennyiséggel párosítva tartalmaz.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Tételek hozzáadása egy listából egy meglévő szótárhoz

Implementáld az `add_items(<inventory dict>, <item list>)` függvényt, amely egy tétellistát ad hozzá a kapott készlethez:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Tételek csökkentése a készletben

Implementáld a `decrement_items(<inventory dict>, <items list>)` függvényt, amely egy tétellistát kap.
A függvényed minden alkalommal vonjon le `1`-et egy tétel darabszámából, amikor az a tétel szerepel a `list`-ben:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

A készletben a tételszámok nem csökkenhetnek 0 alá.
Ha egy tétel többször szerepel a bemeneti `list`-ben, mint amennyi a rendelkezésre álló darabszám, akkor a tételhez tartozó mennyiség 0 maradjon.
A további csökkentési kéréseket figyelmen kívül kell hagyni, miután a darabszám elérte a nullát.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Egy bejegyzés teljes eltávolítása a készletből

Implementáld a `remove_item(<inventory dict>, <item>)` függvényt, amely egy tételt és annak darabszámát teljesen eltávolítja a készletből:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Ha a tétel nem található a készletben, a függvény az eredeti készletet adja vissza változatlanul.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. A készlet teljes tartalmának visszaadása

Implementáld a `list_inventory(<inventory dict>)` függvényt, amely egy készletet kap, és egy `(item, quantity)` tuple-okból álló listát ad vissza.
A lista csak az _elérhető_ tételeket tartalmazza (_amelyek mennyisége nagyobb nullánál_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
