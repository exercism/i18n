# Bevezetés

A Gleamben a stringek módosíthatatlan szövegek, amelyeket idézőjelek zárnak közre. Támogatják a Unicode-karaktereket, és akár több sorosak is lehetnek.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

A stringeket a `<>` operátorral fűzheted össze:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

A szabványos könyvtár [`gleam/string`][stdlib] modulja függvényeket kínál a stringekkel való munkához.

A stringekre `case` kifejezésekben is illeszthetsz mintát:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Ha egy string elejére szeretnél illeszteni egy mintát, a maradékot pedig egy változóhoz rendelnéd, használhatod a `<>` operátoros mintát:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
