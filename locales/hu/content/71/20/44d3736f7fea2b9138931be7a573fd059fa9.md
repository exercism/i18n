# Bevezetés

A `list` az F#-ban nulla vagy több értékből álló, változhatatlan gyűjtemény. Egy listában minden értéknek ugyanolyan típusúnak kell lennie. Mivel a listák változhatatlanok, miután létrehoztál egy listát, az értéke soha többé nem változhat meg. Bármely függvény vagy operátor, amely úgy tűnik, hogy módosítja a listát (például elemet ad hozzá), valójában egy új listát ad vissza.

A listákat így definiálhatod:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

Egy listához a leggyakrabban a `::` (cons) operátorral adhatsz hozzá elemet:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Egy F# listának van _feje_ (az első elem) és _farka_ (minden, ami az első elem után következik). A lista farka maga is egy lista.

A listákat vagy a `List` modulban definiált függvényekkel és operátorokkal módosíthatod, vagy kézzel, mintaillesztéssel, a _lista_ és _cons_ minták segítségével:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Mintaillesztéskor egy értéket _el is dobhatsz_; ha egy adott esetben _nem_ érdekel egy érték (vagyis nem fogod _használni_), egy alulvonással (`'_'`) jelezheted ezt:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Az alulvonás (`'_'`) minta mindig _utolsóként_ álljon mintaillesztéskor: minden értéket, amely _nem_ illeszkedik a többi eset egyikéhez sem, ez az eset fog kezelni.
