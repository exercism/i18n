# Bevezetés

A függvényargumentumok alapjairól lásd a [függvény fogalmat][function concept].

## Paraméternevek

A [paraméternevek][parameters] a változónevekhez hasonlóan csak betűvel vagy aláhúzással kezdődhetnek, és tartalmazhatnak betűket, aláhúzásokat vagy számokat.
A paraméternevek nem tartalmazhatnak szóközt vagy írásjelet.


## Pozicionális argumentumok

A pozicionális argumentumok olyan értékek, amelyeket a függvénynek ugyanabban a sorrendben adunk át, mint amilyen sorrendben a hozzájuk tartozó paraméterek állnak.
Opcionálisan a paraméternevük segítségével is átadhatók:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

A concat első hívása pozíció szerint adja át az argumentumokat.
A concat második hívása _név_ szerint adja át az argumentumokat, így a sorrendjük felcserélhető.

Ne feledd, hogy a pozicionális argumentumok nem követhetik a név szerint átadott argumentumokat (_amelyeket [kulcsszavas argumentumoknak][keyword-arguments] is neveznek. **Nem** tévesztendők össze a változó számú pozicionális paraméterekkel vagy a [**kwargs][kwargs] paraméterrel_).

Ez az argumentumhalmaz:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

a következő hibát eredményezi:

```
SyntaxError: positional argument follows keyword argument
```

## Alapértelmezett argumentumértékek

A paraméterlistában egy vagy több argumentumhoz is megadhatsz [alapértelmezett értéket][default arguments].
Így szükség esetén _kevesebb_ argumentummal is meghívhatod a függvényt.
Az alapértelmezett értékek felülírhatók, ha a függvényt az alapértékek helyett új argumentumokkal hívod meg:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## Kulcsszavas argumentumok

A kulcsszavas argumentumok a paraméter nevét használják, amikor argumentumot adsz át egy függvénynek.
Opcionálisan pozíció szerint is hivatkozhatsz rájuk:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
