# Részletesen

Az alapvető `try .. rescue` konstrukció kiterjeszthető úgy, hogy támogassa az `else` és `after` ágat is:

- Az `else` blokk:
  - Itt történik a mintaillesztés a try-blokk sikeres eredményén.
- Az `after` blokk:
  - Itt hívódnak meg a függvények, akár sikeres a try-blokk, akár kivételkezelésbe kerül sor, amíg a program fut.
  - Az `after` blokk eredménye nem adódik vissza a hívó scope-ba.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
