# Szálak

Ez a feladat bemutatja a szálakat, hogy kiderüljön, mennyire strapabíró a bankszámlád az
egyidejű műveletekkel szemben. Néhány olvasnivaló a Tcl-szálakról:

* [Tcl szálkezelési modellje](https://www.tcl.tk/doc/howto/thread_model.html)
* [Szálak, ahogy kell… Tcl-lel](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Többszálú Tcl-szkriptek](http://www.beedub.com/book/4th/Threads.pdf),
  a _Practical Programming in Tcl and Tk, 4th Ed._ egyik fejezete,
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * Megjegyzés: ez a fejezet azt állítja, hogy „a Tcl legtöbb bináris disztribúciója nem támogatja a szálakat”. Ez ma már nem igaz: a Tcl-disztribúciók ma száltámogatással épülnek (lásd [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* [A Thread csomag parancsai](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) a Tcl dokumentációjából.

## Telepítés

Egyes Tcl-disztribúciók alapértelmezés szerint nem tartalmazzák a Tcl Thread csomagját: külön kell telepíteni.
Így ellenőrizheted:
```bash
$ echo 'package require Thread' | tclsh
```
Ha ez _nem ír ki semmit_, akkor a Thread csomag már telepítve van.

Szükség szerint futtasd az `apt install tcl-thread` (vagy `dnf install tcl-thread`) parancsot.
