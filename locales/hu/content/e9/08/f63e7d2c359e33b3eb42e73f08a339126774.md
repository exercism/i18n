# Névjegy

- A [bináris][binary] típus a [bitstring][bitstring] típus egy specializációja.
- A binárisok [bájtokból][wiki-byte] állnak.
  - A bájtok 8 [bitből][wiki-bit] állnak.
  - A bájtokkal a `0` és `255` közötti számokat ábrázolhatod.
  - A bájtokkal végzett munka során gyakoriak a [hexadecimális][wiki-hexadecimal] egészértékek: `0x00` és `0xFF` között.
- A bináris literálokat a [`<<>>` speciális formával][special-form] definiálod.
  - Ha egy bájthoz `255`-nél nagyobb egész számot adsz meg, csak az utolsó 8 bitet veszi figyelembe, hacsak a [`::`][type-operator] operátorral meg nem adod a [használandó egységet és/vagy méretet][bin-size].
- A [`<>/2`][bin-concat] a bitstringek, binárisok és stringek összefűzésére használható.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

A _nullbájt_ a `<<0>>` másik elnevezése.

## A stringek kódolt bináris adatok

- A stringek [UTF-8][wiki-utf8] formátumban kódolt bináris adatok.
  - A kódolásuk 8 bites (egybájtos) egységekben történik, és akár 4 bájtot is használhatnak több mint 255 karakter ábrázolásához.
  - Egy string [hossza][string-length] nem feltétlenül egyezik meg a [bájtméretével][byte-size].

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## Mintázatillesztés bináris adatokon

- A binárisokra [illeszthetsz mintázatot egészükben, vagy a speciális formával][special-form] akár csak egyetlen részükre is.
  - Egy mintázatillesztésben csak az utolsó rész mérete lehet változó.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

Ugyanez stringekkel is megtehető:

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
