# Tesztek

A mellékelt tesztek futtatásához szükséged lesz a Minitest gemre. Nyiss egy terminálablakot, és futtasd a következő parancsot a minitest telepítéséhez:

```
gem install minitest
```


A teszteket a feladat könyvtárából futtathatod a következő paranccsal:

```
ruby <snake-case-exercise>_test.rb
```

A `<snake-case-exercise>` részt cseréld le a feladatod snake_case írásmódú nevére.

## Színes kimenet

A `require 'minitest/pride'` utasítással vagy a következő parancs futtatásával színes kimenetet kapsz:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
