# Bevezetés

A [`Basics`][basics] fogalom két módot mutatott be egy függvény definiálására.

A legáltalánosabb a többsoros forma:

```julia
function muladd(x, y, z)
    x * y + z
end
```

Az „értékadó”, másképp „egysoros” forma rövid definíciókhoz:
```julia
muladd(x, y, z) = x * y + z
```

Egy harmadik, még rövidebb formában név nélkül hozhatunk létre egy rövid, egyszer használatos függvényt:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

Ebben az esetben az `x -> 2x` egy „névtelen függvény”.
Ez ugyanaz, amit más nyelvek „lambda-függvénynek” neveznek.

Figyeld meg, hogy több argumentum esetén zárójelek kellenek, mint a `(x, y) -> x * y` példában.

A névtelen függvények gyakoriak a Julia-kódban, különösen magasabb rendű függvényekkel, például a `map()` és `filter()` függvénnyel kombinálva.

## A függvény argumentumai

A tantervben eddig csak olyan függvényekkel találkoztunk, amelyeknek pontosan meghatározott számú argumentumuk van, és a hívásukhoz mindet meg kell adni, a helyes sorrendben.
Ez meglehetősen korlátozó és kényelmetlen lenne, ezért több más lehetőség is létezik.

### Opcionális argumentumok

Ahogy sok más nyelv, a Julia is lehetővé teszi, hogy a függvénydefinícióban alapértelmezett értéket adjunk az egyes argumentumokhoz.

A függvényhívás ekkor vagy megad egy értéket ehhez az argumentumhoz, vagy elhagyja, és az alapértelmezett értékre támaszkodik.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

Minden _alapértelmezés nélküli_ argumentumnak az _alapértelmezéssel rendelkezők_ előtt kell állnia, tehát az `f(x=2, y)` érvénytelen lenne.

### Kulcsargumentumok

Az eddigi példák mind `positional arguments`-et használnak, ahol a függvényhívásban megadott értékek sorrendjének meg kell egyeznie a függvénydefinícióban szereplő megfelelő argumentumok sorrendjével.

Ahogy sok más nyelv, a Julia is támogatja a `keyword arguments` használatát.
A függvényhívásban meg kell adni az argumentum nevét, de több kulcsargumentum ezután tetszőleges sorrendben szerepelhet.

A Julia sajátos jellemzője, hogy a függvénydefinícióban a kulcsargumentumokat (ha vannak) egy pontosvesszőnek `;` kell megelőznie, hogy elválassza őket a pozíciós argumentumoktól.
A függvényhívásban az utolsó pozíciós argumentum és az első kulcsargumentum között a `;` és a `,` közül bármelyik állhat.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

Az alapértelmezett értékek opcionálisan megadhatók, pontosan úgy, mint a pozíciós argumentumoknál.

Gyakran előfordul, hogy egy függvényhívásban olyan szintaxist kapunk, mint a `myarg=myarg`, amikor egy, a paraméterrel azonos nevű változót már előre kiszámoltunk.
Ilyenkor egy rövidített szintaxis is engedélyezett:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat és slurp

Ezek a szokásos elnevezései a Julia szintaxis egy hasznos elemének, ha esetleg tűnődtél volna rajta.
Mindkettő a `...` operátorra utal.

#### Splat

A splatolást függvény_hívásoknál_ használjuk arra, hogy egy kollekciót azokra az egyedi értékekre bontsunk, amelyeket a függvény megkövetel.

Ezt könnyebb bemutatni, mint elmagyarázni:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

Néhány „függvényhívás” szintaktikai cukor mögé rejtőzik, ezért a splatolás kevésbé nyilvánvaló módokon is használható.

Például a többszörös értékadás belül egy tuple-konstruktor függvényt használ:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

A kulcsargumentumok is megadhatók splatolással, jellemzően egy `named tuple` segítségével.
Egy `Dict` is működik, de a kulcsoknak symboloknak kell lenniük (a stringek nem működnek).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

A slurpolást a függvény_definícióban_ használjuk arra, hogy tetszőleges számú egyedi értéket egy kollekcióba csomagoljunk.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

A slurpolt argumentum neve (ebben az esetben `more`) nem számít.
Ennek a változónak a típusát a fordító választja meg, de pozíciós argumentumok esetén valószínűleg `tuple` vagy valami hasonló lesz.

A kulcsargumentumok is slurpolhatók, ekkor egy `Dict`-et (vagy hasonlót) kapunk.

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

A hívásban bármilyen kulcsargumentum szerepelhet.
A függvénydefiníció dönti el, hogy mely kulcsszavakra reagál, és melyeket hagy figyelmen kívül.
