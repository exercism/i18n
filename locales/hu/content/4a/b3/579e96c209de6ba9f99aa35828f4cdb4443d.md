# Bevezetés

Gyakran hasznos, ha egy csomó elemet csoportosítunk, és az így kapott csoportokat egységként kezeljük. Rustban az ilyen csoportot struct-nak, az egyes elemeket pedig a struct egy-egy mezőjének nevezzük. A struct meghatározza a rendelkezésre álló mezők általános körét, a struct egy konkrét előfordulását viszont példánynak nevezzük.

Ráadásul a struct-okhoz metódusokat is definiálhatunk, amelyek hozzáférnek a mezőkhöz. Ilyenkor magára a structra `self` néven hivatkozunk. Amikor egy metódus `&mut self`-et használ, a mezők módosíthatók. Amikor egy metódus `&self`-et használ, a mezők nem módosíthatók: megváltoztathatatlanok. A módosíthatóság szabályozása segít a kölcsönzés-ellenőrzőnek abban, hogy bizonyos párhuzamossági hibacsoportok egyszerűen elő se fordulhassanak Rustban.

Ebben a feladatban kétféle metódust fogsz megvalósítani egy struct-on. Az elsőket általában gettereknek nevezik: hozzáférhetővé teszik a struct mezőit a külvilág számára, anélkül hogy bárki más módosíthatná az értéküket. Rustban ezek a metódusok szokás szerint ugyanazt a nevet kapják, mint a mező, amelyet hozzáférhetővé tesznek. Ha például van egy getter metódusunk, amely egy `name` nevű mezőt kér le, akkor a metódus egyszerűen a `name()` nevet kapja.

Egy másik fajta metódust is meg fogsz valósítani, ezeket általában settereknek nevezik. Ezek megváltoztatják a mező értékét. A setterek nem túl gyakoriak Rustban: ha egy mezőt szabadon lehet módosítani, akkor inkább egyszerűen publikussá tesszük. Akkor viszont hasznosak, ha a mező frissítésének mellékhatása kell legyen, vagy hozzáférés-szabályozáshoz: egy `pub(crate)` jelölésű setter lehetővé teszi, hogy ugyanazon crate más moduljai is frissítsenek egy privát mezőt, amelyre a külvilág nem hathat.

A struct-oknak három fajtája van: a nevesített mezőkkel rendelkező struct-ok, a tuple struct-ok és a unit struct-ok. Ebben a tanulófeladatban az első változatot járjuk körül: a nevesített mezőkkel rendelkező struct-okat.

A struct-okat a `struct` kulcsszóval definiáljuk, amelyet a leírt típus nagy kezdőbetűs neve követ:

```rust
struct Item {}
```

Ezután további típusokat viszünk be a struct testébe a struct _mezőiként_, mindegyiket a saját típusával:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Végül a struct-okon `impl` blokkon belül definiálhatunk metódusokat:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```
