# Részletesen

A Go-ban a [`Time`][time] egy időpillanatot leíró típus.
A dátum- és időinformációk a metódusain keresztül érhetők el, hasonlíthatók össze és módosíthatók, de néhány függvényt magán a `time` csomagon hívunk meg.
Az aktuális dátumot és időt a [`time.Now`][now] függvénnyel kérheted le.

A [`time.Parse`][parse] függvény stringeket alakít `Time` típusú értékekké.
A Go-ban különleges módon adod meg, milyen formátumot vársz az értelmezéshez.
Ehhez egy példát kell leírnod a formátumra, a következő különleges időbélyegző értékeit használva:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

Például:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

A [`Time.Format()`][format] metódus az idő egy string reprezentációját adja vissza.
A `Parse` függvényhez hasonlóan a célformátumot is egy példával adod meg, amely a különleges időbélyegző értékeit használja.

Például:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## Formátumbeállítások

Egyéni formátumhoz ezeknek a beállításoknak a kombinációját használd.
A Go-ban emellett előre definiált dátum- és időbélyegző-[formátumkonstansok][const] is elérhetők.

| Idő         | Beállítások                                    |
| ----------- | ---------------------------------------------- |
| Év          | 2006 ; 06                                      |
| Hónap       | Jan ; January ; 01 ; 1                         |
| Nap         | 02 ; 2 ; \_2 (vezető nullához)                 |
| A hét napja | Mon ; Monday                                   |
| Óra         | 15 ( 24 órás időformátum ) ; 3 ; 03 (de. vagy du.) |
| Perc        | 04 ; 4                                         |
| Másodperc   | 05 ; 5                                         |
| de./du. jel | PM                                             |
| Az év napja | 002 ; \_\_2                                    |

A `time.Time` típusnak számos metódusa van egy adott idő eléréséhez, például óra: [`Time.Hour()`][hour], hónap: [`Time.Month()`][month].
Erről bővebben a [hivatalos dokumentációban][time] olvashatsz.

A [`time`][time] csomagban van egy másik típus is, a [`Duration`][duration], amely az eltelt időt reprezentálja, emellett támogatja az időzónákat, az időzítőket és más kapcsolódó funkciókat, amelyeket egy másik fogalomban tárgyalunk.
