# Tippek

## Általános

- Olvass az `Enum` modulról a [hivatalos Első lépések útmutatóban][getting-started-enum] vagy az [elixirschool.com oldalon][elixir-school-enum].
- Nézd meg a dokumentációban az [`Enum` modul összes függvényének listáját][enum-functions].

## 1. Rendezd a termékeket ár szerint

- Van egy [beépített függvény][enum-sort-by], amivel egy rendezőfüggvény segítségével rendezhetsz felsorolható elemeket.

## 2. Keresd meg az összes terméket, amelyiknek hiányzik az ára

- Van egy [beépített függvény][enum-filter] a felsorolható elemek szűrésére.

## 3. Frissítsd a termékek nevét

- Van egy [beépített függvény][enum-map], amivel egy felsorolható minden elemét átalakíthatod.
- Van egy [beépített függvény][string-replace], ami egy string összes előfordulását lecseréli egy másikra.

## 4. Növeld a termék mennyiségét

- A map-ek megvalósítják a felsorolható protokollt.
- Az `Enum` függvényei a map-eket `{key, value}` tuple-ök listájává alakítják.
- Két különböző függvény is van, amelyek egy transzformációs függvény segítségével visszaalakítanak egy `{key, value}` tuple-ökből álló listát map-pé. [Az egyik mindig új map-et ad vissza][map-new], míg [a másiknál kiválaszthatod a gyűjthetőt][enum-into].

## 5. Számítsd ki a termék teljes mennyiségét

- A map-ek megvalósítják a felsorolható protokollt.
- Az `Enum` függvényei a map-eket `{key, value}` tuple-ök listájává alakítják.
- Van egy [beépített függvény][enum-reduce], amivel egy felsorolható elem egyetlen értékké redukálható.
