# Névjegy

Sok operátor használható [összetett értékadásként][compound-assignment] is. Ezek rövidített jelölések, ahol `x = op y` helyett `x op= y` írható:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
