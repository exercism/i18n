# Bevezetés

A függvények alapértelmezés szerint külső kapcsolódásúak, és a projekt bármely más fájljából meghívhatók.
A kapcsolódásról bővebben lásd a [kapcsolódás fogalmát](../linkage/introduction.md#Introduction).
Egy `static` függvény csak abban a forrásfájlban hívható meg, amelyben definiálták.

Például:

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```
