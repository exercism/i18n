# Bevezetés

## Diszkriminált uniók

A diszkriminált unió típus névvel ellátott esetek egy rögzített halmazát reprezentálja. A diszkriminált unió minden értéke pontosan az egyik névvel ellátott esetnek felel meg.

A diszkriminált uniót a `type` kulcsszóval definiálod, az eseteket pedig függőleges vonal (`|`) karakterek választják el egymástól:

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

A diszkriminált unió minden esetéhez opcionálisan kapcsolódhat adat, és a különböző esetekhez különböző típusú adat tartozhat. Ha egyik esethez sem kapcsolódik adat, a diszkriminált unió ahhoz hasonló, amit más nyelvek általában _felsorolásnak_ (vagy _enum_-nak) neveznek.

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Egy adott esethez tartozó értéket úgy hozhatsz létre, hogy a nevére hivatkozol (például `Success`). Mivel az esetnevek csupán konstruktorfüggvények, a kapcsolódó adatot hagyományos függvényargumentumként adhatod át. Ha egy másik diszkriminált unió már definiált egy ugyanilyen nevű esetet, a teljes nevét kell használnod (például `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

A diszkriminált uniók _strukturális egyenlőséggel_ rendelkeznek, ami azt jelenti, hogy két érték, amely ugyanahhoz az esethez tartozik és ugyanazzal az (opcionális) adattal rendelkezik, egyenértékű.

Bár a diszkriminált uniókkal `if/elif/else` kifejezésekkel is dolgozhatsz, a velük való munka ajánlott módja a mintaillesztés, méghozzá az _azonosító minta_ használatával:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
