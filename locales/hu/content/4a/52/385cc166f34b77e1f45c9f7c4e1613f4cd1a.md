# Bevezetés

## Importálás

Bár a Swift rengeteg funkciót tartalmaz a szabványos könyvtárában, ennél jóval több funkció érhető el külső könyvtárak formájában.
Ezek a könyvtárak származhatnak magából a Swift-projektből, például a [Swift Argument Parser][argument-parser], lehetnek zárt forrású könyvtárak cégektől, mint az Apple [Network Framework][network-framework], vagy külső felek könyvtárai, mint a [Swifty Beaver][swifty-beaver].

Néhány ilyen modul, például a Network Framework vagy a [Foundation][apple-foundation] (amely valószínűleg a leggyakrabban használt könyvtár a Swiftben), a Swift-disztribúcióddal együtt érkezik.
A külső, harmadik féltől származó könyvtárakat hozzá kell adnod a projektedhez, mielőtt importálhatnád őket, ez azonban kívül esik ennek a feladatnak a keretein.

A modulok importálása úgy történik, hogy leírod az `import` kulcsszót, majd utána a modul nevét. A Foundationt például így importálhatod a programodba:

```swift
import Foundation
```

Ez hozzáférést ad a modulban található összes típushoz, értékhez és funkcióhoz; ha például a `components(separatedBy:)` String-metódust szeretnéd használni, ez a metódus ezzel az importtal elérhetővé válik a `String` számára.

Bár az import utasítások a kódban bárhol elhelyezhetők, mielőtt a modul valamelyik tartalmát használó kódrészlet következik, a nagyobb olvashatóság érdekében általában annak a fájlnak az elején szokás őket elhelyezni, amelyik használja őket.

## Stringek indexelése

Egy `String` egyes karaktereit ugyanúgy érheted el indexeléssel, mint egy tömb elemeit.
A stringekhez használt [indexek][string-indices] azonban _nem_ egész számok, és nem lehet velük közvetlenül dolgozni.
Ehelyett egy másik ismert index alapján kell kiszámítanod őket, például a `startIndex` segítségével, amely egy nem üres string első karakterének pozíciójára mutat; ezt a [`String`][string-docs] és az [`NSString`][nsstring-docs] könyvtárban elérhető metódusokkal teheted meg (amikor a `Foundation` modul importálva van, a Swiftben a stringek hozzáférnek az NSString összes tulajdonságához és metódusához).

Vegyük például a következő stringet:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Nem írhatod azt, hogy `csv[21]`, hogy megkapd az „orange” „g” betűjét, hanem ki kell számítanod egy `String.Index` típusú értéket, és azt kell megadnod indexként.
Jegyezd meg, hogy ezeket az indexeket önmagukban nem arra szánták, hogy az ember megértse őket.
Ők az úgynevezett _átlátszatlan indexek_, mivel az embernek nem kell tudnia, mi van bennük.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Jegyezd meg azonban, hogy ha az eltolás nem érvényes index, azaz ha a `startIndex` előtti vagy az `endIndex` utáni indexet adná vissza, a művelet hibát vált ki, és összeomlik tőle a program.
Ennek a problémának a megelőzésére megadhatsz egy korlátozó indexet.
Ez egy opcionális indexet ad vissza, és egyébként érvénytelen indexek esetén nil-t ad vissza.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Ráadásul az indexek nem oszthatók meg a stringek között.
Például ha a fent kiszámított „orange” „g” betűjének `index`-ét használod arra, hogy a `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"` stringbe indexelj, azaz `fam[index]`, az összeomlasztja a programodat.

Sok oka van mindennek, de ezek alapvetően mind arra vezethetők vissza, hogy „a Unicode trükkös”.

Általánosságban, ha az egyes karakterekhez véletlenszerű hozzáférésre van szükséged, valószínűleg más adatszerkezetet érdemes használnod, például az `Array<Character>`-t.

### Néhány hasznos metódus

A Swiftben a `first` és a `last` metódussal kaphatod meg egy string első és utolsó karakterét.
Ezek a metódusok opcionális karaktert adnak vissza, tehát ha a string üres, nil-t adnak vissza.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

A `prefix` és a `suffix` metódussal egy string egy részstringjét is megkaphatod.
Ezek a metódusok egy egész számot vesznek argumentumként, és egy olyan részstringet adnak vissza, amely a string első vagy utolsó n karakterét tartalmazza.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Stringmetódusok

A stringekkel való munka gyakori feladat a programozásban.
Ezért a Swift számos metódust kínál a stringek kezelésére.
Ez a dokumentum a leggyakoribb stringmetódusok és -tulajdonságok közül mutat be néhányat; némelyikük megköveteli a Foundation keretrendszer importálását.

### [`components(separatedBy:)`][components]

Amikor egy stringet részstringek tömbjére szeretnél bontani, használhatod a `components(separatedBy:)` metódust.
Ha például egy mondat minden szavát meg szeretnéd kapni, elválasztóként a szóköz karaktert használhatod.

```swift
let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

### [`hasPrefix(_:)`][hasPrefix], [`hasSuffix(_:)`][hasSuffix]

Amikor ellenőrizni szeretnéd, hogy egy string egy adott részstringgel kezdődik-e vagy végződik-e, a `hasPrefix(_:)` és a `hasSuffix(_:)` metódust használhatod.
Mindkét metódus egy stringet vesz argumentumként, és egy logikai értéket ad vissza, amely megmutatja, hogy a string a megadott részstringgel kezdődik-e vagy végződik-e.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

### [`lowercased`][lowercased], [`uppercased`][uppercased], [`capitalized`][capitalized]

Amikor egy string kis- és nagybetűsségét szeretnéd megváltoztatni, a `lowercased`, `uppercased` és `capitalized` tulajdonságot használhatod.
A `lowercased` tulajdonság egy új stringet ad vissza, amelyben minden karakter kisbetűs, az `uppercased` tulajdonság egy új stringet ad vissza csupa nagybetűvel, a `capitalized` tulajdonság pedig egy új stringet ad vissza, amelyben minden szó első karaktere nagybetűs.

```swift
let greeting = "hello, world!"
print(greeting.lowercased)  // Prints "hello, world!"
print(greeting.uppercased)  // Prints "HELLO, WORLD!"
print(greeting.capitalized) // Prints "Hello, World!"
```

### [`replacingOccurrences(of:with:)`][replacingOccurrences]

Amikor egy stringben egy részstring minden előfordulását le szeretnéd cserélni egy másik részstringre, a `replacingOccurrences(of:with:)` metódust használhatod.
Ez a metódus két stringet vesz argumentumként: a lecserélendő részstringet és azt a részstringet, amelyre lecseréli. Egy új stringet ad vissza, amelyben a megadott részstring minden előfordulása le van cserélve.

```swift
let greeting = "Hello, world!"
let newGreeting = greeting.replacingOccurrences(of: "world", with: "Swift")
print(newGreeting) // Prints "Hello, Swift!"
```

### [`joined(separator:)`][joined]

Ez nem a String, hanem az Array típus metódusa.
Amikor egy stringtömböt egyetlen stringgé szeretnél összefűzni egy megadott elválasztóval, a `joined(separator:)` metódust használhatod.
Ez a metódus egy stringet vesz argumentumként, és egy új stringet ad vissza, amelyben a tömb minden eleme össze van fűzve, a megadott stringgel elválasztva.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
