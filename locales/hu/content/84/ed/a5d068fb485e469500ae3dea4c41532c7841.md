# Kiegészítés az utasításokhoz

## Bemeneti formátum

Minden dominó egyetlen bájtban tárolódik, a bal felét a magas, a jobb felét pedig az alacsony [nibble] tartalmazza. Például a `[2|1]`, `[2|3]` és `[1|3]` köveket a `0x21 0x23 0x13` bájtok jelölik.

## Regiszterek

| Regiszter | Használat | Típus   | Leírás                                            |
| --------- | --------- | ------- | ------------------------------------------------- |
| `$a0`     | bemenet   | cím     | kőbájtok tömbje                                   |
| `$a1`     | bemenet   | egész szám | kövek száma                                     |
| `$v0`     | kimenet   | boolean | a dominók láncba fűzhetők (`0` = `false`, `1` = `true`) |
| `$t0-9`   | ideiglenes | bármilyen | ideiglenes tárolásra szolgál                     |


[nibble]: https://en.wikipedia.org/wiki/Nibble
