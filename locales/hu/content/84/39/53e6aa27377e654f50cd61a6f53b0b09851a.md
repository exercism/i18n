# Utasítások

Ebben a feladatban középiskolás szerelmeseknek segítesz, hogy szerelmet valljanak a közösségi médiában. Ehhez egy ASCII szívet generálsz a kezdőbetűikkel:

```
❤ J.  +  M. ❤
```

## 1. Tisztítsd meg a nevet

Valósítsd meg a `HighSchoolSweetheart.clean_up_name` metódust.
A metódus vegyen egy nevet, távolítsa el belőle az összes `-` karaktert, és cserélje le őket szóközre.
A név elejéről és végéről is távolítsa el a szóközöket.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. Kérd le a név első betűjét

Valósítsd meg a `HighSchoolSweetheart.first_letter` metódust.
A metódus vegyen egy nevet, és adja vissza annak első betűjét.
Ügyelj rá, hogy újra felhasználd az előző lépésben definiált `HighSchoolSweetheart.clean_up_name` metódust.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. Formázd az első betűt kezdőbetűvé

Valósítsd meg a `HighSchoolSweetheart.initial` metódust.
A metódus vegyen egy nevet, és adja vissza annak első betűjét nagybetűvel, mögötte egy ponttal.
Ügyelj rá, hogy újra felhasználd az előző lépésben definiált `HighSchoolSweetheart.first_letter` metódust.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. Tedd a kezdőbetűket a szív belsejébe

Valósítsd meg a `HighSchoolSweetheart.pair` metódust.
A metódus vegyen két nevet, és adja vissza a kezdőbetűket, körülöttük emoji szívekkel.
Ügyelj rá, hogy újra felhasználd az előző lépésben definiált `HighSchoolSweetheart.initial` metódust.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
