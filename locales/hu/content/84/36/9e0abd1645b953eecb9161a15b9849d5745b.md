# Alapok

## Első lépések

### Változók

Egy [változó][variables] deklarálásához használd a `=` értékadó operátort.
A Crystalban a változók neve [snake_case][snake-case] formátumú legyen.

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### Konstansok

A [konstansokat][constants] ugyanazzal a `=` értékadó operátorral deklaráljuk, de a nevük csupa nagybetű, amit SCREAMING_SNAKE_CASE-nek hívunk.

```crystal
NUMBER = 1
puts NUMBER # => 1
```

Ha egy már definiált konstansnak adunk értéket, az fordítási idejű hibát eredményez.

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### Típusok

A Crystal egy fordított nyelv, ami azt jelenti, hogy minden változó és metódusargumentum típusa fordítási időben dől el.
A fordító képes kikövetkeztetni egy változó vagy metódusargumentum típusát.
Bizonyos esetekben azonban szükség van a típus megadására.
Azokat az eseteket, amelyekben meg kell adni a típust, a későbbi fogalmakban mutatjuk be.

### Metódusok

A [metódusok][methods] segítségével utasítások egy csoportját foghatjuk össze, hogy újra felhasználhassuk őket.
A Crystalban a metódusokat általában osztályon, modulon vagy struktúrán belül definiáljuk.
A metódusokat azonban osztályon, modulon vagy struktúrán kívül is definiálhatjuk.
A metódusokat a `def` kulcsszóval deklaráljuk, amit a metódus neve követ.
A Crystalban a metódusok nevét snake_case formátumban érdemes írni.
Ha egy metódusnak nincsenek argumentumai, a zárójeleket elhagyhatod.
A metódus végét az `end` kulcsszóval jelölöd.

```crystal
def hello
  puts "Hello World!"
end
```

Ha olyan metódust használsz, amely nem létezik a változó vagy a metódusargumentum típusához, az fordítási idejű hibát eredményez.

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### Argumentumok

A metódusoknak lehetnek [argumentumai][arguments].
Az argumentumok olyan adatok, amelyeket átadunk egy metódusnak.
Ahhoz, hogy egy metódusnak argumentumot adhass, meg kell adnod az argumentum nevét.
A Crystalban az argumentumok nevét snake_case formátumban érdemes írni.
Egy metódusnak több argumentuma is lehet, de az argumentumokat vesszővel kell elválasztani.

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

A metódusoknak több argumentumuk is lehet.
Ebben az esetben az argumentumokat vesszővel kell elválasztani.

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### Metódusok hívása

Amikor egy osztályhoz, modulhoz vagy struktúrához tartozó metódust hívsz meg, a pont operátort (`.`) kell használnod.
A formátum: `<ClassName>.<method_name>`.
Ha egy metódus nem tartozik osztályhoz, modulhoz vagy struktúrához, egyszerűen a nevének leírásával meghívhatod.
A metódusok mindig implicit módon visszaadják az utolsó kifejezés értékét.

Ha egy metódusnak vannak argumentumai, a metódus hívásakor és definiálásakor zárójeleket használhatsz az argumentumok megadásához, például így: `<method_name>(<argument_1>, <argument_2>, ...)`.
Ha egy metódusnak nincsenek argumentumai, a zárójeleket hagyd el.

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

Amikor több argumentummal hívsz meg egy metódust, az argumentumokat vesszővel válaszd el.
Az argumentumokat ugyanabban a sorrendben kell megadni, mint a metódus argumentumait.

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

Ha egy metódust rossz számú argumentummal hívsz meg, az fordítási idejű hibát eredményez.

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### Összeadás, kivonás és szorzás

A Crystalban a `+` operátorral két számot adhatsz össze.
A `-` operátorral két számot vonhatsz ki.
A `*` operátorral pedig két számot szorozhatsz össze.

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### Megjegyzések

A Crystalban a [megjegyzéseket][comments] a `#` karakterrel írjuk, amit egy szóköz, majd maga a megjegyzés követ.
A megjegyzéseket a kód dokumentálására használjuk.
A fordító nem hajtja végre a megjegyzéseket.

```crystal
# This is a comment
```
