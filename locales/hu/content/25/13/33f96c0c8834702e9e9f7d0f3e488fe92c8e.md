# Utasítások

Ebben a feladatban egy helyi hírcsatorna számára készítesz időjárás-jelentéseket.

## Időjárás-jelentések készítése

Kezdetnek néhány vázolt függvényt és a következő enumot kapod:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

Egy időjárás-jelentést a következő formában kell megformáznod: `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."`.
Implementálnod kell azt a függvényt, amely a megfelelő időjárási viszonyokat írja ki.

Például az alábbi kódrészlet egy „esős” nap várható kimenetét mutatja be a `get_weather_report` függvény esetében.

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

És egy „napos” napra:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
