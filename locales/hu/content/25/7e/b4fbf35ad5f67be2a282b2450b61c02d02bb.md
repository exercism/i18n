# Utasítások

Amikor a Lisp-űrlakók először érkeztek a Földre, számtalan fura és csodálatos dologgal találkoztak, de az egyik legjobban tetsző felfedezésük a „kis kedvencek" voltak. Legyünk őszinték: melyik űrlakó ne olvadna el egy kiskutya vagy egy kiscica láttán?

Ludwig a nemrég véget ért földi nyaralása után úgy döntött, hogy saját kis kedvencet szeretne! Az egyetlen gond? Túl sok a választási lehetőség! Talán írnál egy programot, ami segít Ludwignek megtalálni és gondozni a következő bújós barátját?

## 1. Pajtás választása

Bár Ludwig elhatározta, hogy kis kedvencet szerez, nagyjából idáig jutott a dolgok átgondolásában. Az első lépés tehát annak eldöntése, milyen fajta kis kedvencet válasszon!

Ludwig olyan pajtást szeretne találni, akinek az egyénisége kiegészíti a sajátját. Írnál Ludwignek egy `pal-picker` nevű függvényt, ami kap egy személyiségjegyet (kulcsszót), és visszaadja az adott jellemvonású kis kedvenc fajtáját (stringként)?

Ebben az esetben:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

Más, ismeretlen személyiségek esetén a függvény eredménye ez legyen: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. Természetes élőhelyükön

Most, hogy Ludwig új barátra tett szert, kell neki egy hely, ahol lakhat! Segítesz Ludwignek kiválasztani a megfelelő méretű ágyat / tartályt / ketrecet a kis kedvence számára?

Itt Ludwignak egy `habitat-fitter` nevű függvényre van szüksége, amely a kis kedvence kilogrammban mért súlyából (egész számból) kiválasztja a megfelelő élőhelyméretet (kulcsszót).

Az egyes méretekhez tartozó élőhelyek:

- Legalább 40kg -> `:massive`
- 20kg-tól 39kg-ig bezárólag -> `:large`
- 10kg-tól 19kg-ig bezárólag -> `:medium`
- 1kg-tól 9kg-ig bezárólag -> `:small`
- Legfeljebb 0kg -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. Most pedig jöhet a lakoma!

Egy dolog, ami minden földi kis kedvencben közös: szükségük van ételre! Ez a fogalom viszont némileg idegen Ludwig számára, mert hajlamos megfeledkezni arról, hogy újratöltse a kis kedvence etetőtálját.

Ludwignak jól jönne egy egyszerű `feeding-time` nevű függvény, ami figyelmezteti, amikor újra kell tölteni a tálat. A függvény egy töltöttségi százalékot (egész számot) kapna, és egy üzenetet adna vissza string formájában.

Ha az étel szintje:

- 20% felett -> `"All is well."`
- 20% vagy az alatt -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. Viselkedési szabályzat

Miután minden alapvető dolog a helyére került, Ludwig izgatottan várja, hogy kipróbáljon néhány izgalmas dolgot, például a „simogatást" és az „apportírozást". Ugyanakkor nem minden kis kedvenc alkalmas ezekre a tevékenységekre.

Ludwig szeretne két függvényt, a `pet`-et és a `play-fetch`-et, amelyek a kis kedvenc fajtáját (stringként) kapják, és vagy nem adnak vissza semmit, vagy egy ilyen üzenetet adnak vissza: `"Maybe not with this pet..."`, ha a művelet nem illik hozzá.

Feltételezzük, hogy csak a `"Dog"`-ok apportíroznak, és hogy a `"Fish"`-en kívül minden kis kedvenc megsimogatható.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
