# Bemutató

A [tuple](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) névtelen, de rendezett értékek _változtathatatlan_ csoportja.
A tuple-ök bármilyen (vagy akár többféle) adattípust tárolhatnak, akár más tuple-öket is.

A tuple-öket vesszővel elválasztott értékekként definiálod a `(` és `)` karakterek között: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Csak az azonos hosszúságú és azonos (ugyanabban a sorrendben álló) típusú tuple-ök hasonlíthatók össze.
A tuple-öknél strukturális egyenlőség érvényesül, ami azt jelenti, hogy _csak_ akkor egyenlők, ha minden értékük egyenlő.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

[Háromféleképpen nyerhetsz ki értékeket egy tuple-ből](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values):

- Az `fst` és `snd` függvény
- A tuple szétbontása
- A mintaillesztés

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
Technikailag egy tuple értékéhez hozzáférhetsz a `.Item1`, `.Item2`, ... tulajdonságaival is, de ez nem ajánlott, és a fordító figyelmeztetést ad rá.
~~~~

## Fontos tudnivalók a tuple-ökről

Néhány fontos dolog, amit érdemes tudni a tuple-ökről:

- Egy adott tuple-típus egyetlen objektum, hasonlóan mondjuk a C# kételemű tömbjéhez. Amikor függvényekkel használod őket, egyetlen paraméternek számítanak. Az egyetlen kivétel, ha nem F#-kódot hívsz meg több paraméterrel: ilyenkor egy tuple-t adsz át, és az értékei automatikusan a megfelelő paraméterértékekké alakulnak.
- A tuple-típusoknak nem adhatsz kifejezett nevet. A tuple-típus „neve” az együtt szereplő típusok kombinációjából adódik.
- Nem a zárójel, hanem a vessző az a kulcsfontosságú jel, amely a tuple-t meghatározza. Zárójel nélkül is definiálhatsz tuple-t, bár ez néha megtévesztő lehet. F#-ban, ha vesszőt látsz, az valószínűleg egy tuple része.
- A tuple-öket használhatod függvény argumentumaként és visszatérési értékeként is.
