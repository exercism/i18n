# Utasítások

Napi darabszámokat vezetsz arról, hány madár látogatja meg a kertedet. Az adatokat egész számok tömbjeként tároljuk, ahol **az első elem a mai nap darabszáma**.

## 1. A mai nap darabszáma

Definiáld a `today` szót úgy, hogy levegyen a veremről egy napi darabszámokat tartalmazó tömböt, és adja vissza a mai nap darabszámát, vagy `f`-et, ha a tömb üres.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Növeld a mai nap darabszámát

Definiáld az `increment-day-count` szót úgy, hogy adjon vissza egy új tömböt, amelyben a mai nap darabszáma eggyel megnőtt. Ha a bemenet üres, akkor `{ 1 }`-et adjon vissza.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. Volt olyan nap, amikor nem járt madár?

Definiáld a `has-day-without-birds?` szót úgy, hogy adjon vissza `t`-t, ha legalább egy napon nulla madarat számoltál, egyébként `f`-et.

**Használj rekurziót** az `any?` vagy más magasabb rendű sorozatszavak helyett.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Összes madár a kezdés óta

Definiáld a `total` szót úgy, hogy adja vissza az összes darabszám összegét.

**Használj rekurziót** a `sum` helyett.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Forgalmas napok

Egy forgalmas nap az, amikor öt vagy több madár járt nálad. Definiáld a `busy-days` szót úgy, hogy adja vissza a forgalmas napok számát.

**Használj rekurziót** a `count` helyett.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
