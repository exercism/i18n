# Bevezetés

## Tömbök

A tömbök a PHP-ban rendezett leképezések.
A leképezés olyan adatszerkezet, amely egy kulcshoz egy értéket rendel.
A tömbök sokoldalúak, és kezelhetők lineáris tömbként (mint a `C`-ben vagy `Java`-ban), listaként [vektor], hash-táblaként, szótárként, gyűjteményként, veremként vagy sorként.

A kulcs megadása nem kötelező, de ha meg van adva, akkor `int` vagy `string` típusúnak kell lennie.
Amikor nincs megadva kulcs, a PHP alapértelmezés szerint növekvő sorrendű, `0`-tól kezdődő egész szám típusú kulcsokat használ.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

A tömb bármilyen típusú értéket tárolhat.
Az egyes értékek különböző típusúak lehetnek.

### Tömbök használata

A tömbök deklarálhatók literálként (a kódban leírva, ahogy fent is tettük), vagy létrehozhatók és módosíthatók függvényekkel.
Az értékek eléréséhez, hozzárendeléséhez és hozzáfűzéséhez használd az indexoperátort:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## Változó hosszúságú argumentumok

A függvény argumentumai megadhatók úgy, hogy a függvény bármennyi argumentumot elfogadjon:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
