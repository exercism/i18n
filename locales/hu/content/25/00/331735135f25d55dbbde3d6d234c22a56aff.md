# Részletesen

A C# stringjeiről a legfontosabb, amit érdemes megjegyezned, hogy módosíthatatlan objektumok, amelyek Unicode-karakterek (betűk, számjegyek, írásjelek stb.) sorozataként ábrázolják a szöveget. Egy `string` példányt kettős idézőjelek közé írva hozol létre:

```csharp
string fruit = "Apple";
```

Egy stringet úgy módosíthatod, hogy meghívod valamelyik [metódusát][methods] vagy [tulajdonságát][properties]. Mivel a string értékei a létrehozásuk után soha nem változnak, minden stringmanipuláló metódus új stringet ad vissza.

A stringet kettős idézőjel (`"`) karakterek zárják közre. Néhány speciális karaktert [escape-elni][escaping] kell a fordított perjel (`\`) segítségével. A stringek elé odaírhatod a `@` jelet is, ettől [verbatim string][verbatim] lesz belőlük, amely figyelmen kívül hagyja az escape-elt karaktereket.

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

Ha csak egy string egy részére van szükséged, a [`Substring()` metódussal][substring] kiemelheted pontosan azt a részt:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

A [`IndexOf`() metódussal][indexof] megkeresheted, hogy egy `string` melyik indexen fordul elő először egy másik `string`ben; ha a megadott érték nem található, `-1`-et ad vissza:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

Végül [többféleképpen is összefűzheted a stringeket][concatenation]. A legegyszerűbb, ha a [`+` operátort][plus-operator] használod.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Ha az egyszerű összefűzésnél bonyolultabb stringformázásra van szükséged, a [string-interpolációt][interpolation] érdemes választani. Ahhoz, hogy egy stringben interpolációt használhass, írd elé a dollárjelet (`$`).

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
