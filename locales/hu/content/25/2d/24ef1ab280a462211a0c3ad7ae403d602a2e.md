# Bevezetés

## Példányváltozók

Az objektumok saját állapotot tárolhatnak _példányváltozók_ beállításával.
Ezek a változók egy objektumon belül élnek, és általában valamilyen belső állapot tárolására szolgálnak.

A példányváltozók mindig egy `@` jellel kezdődnek.
Új példányváltozót úgy hozhatsz létre, hogy beállítasz egy `@` jellel kezdődő változót.
Például:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

Az objektumok általában az `initialize` metódusban állítják be a kezdeti állapotukat, amely automatikusan meghívódik, amikor egy osztályon meghívjuk a `new` metódust.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

Az `initialize` metódus argumentumokat is fogadhat, hogy minden példány egyedi állapottal indulhasson:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Jó gyakorlat, ha a _példányváltozókat_ privátnak tekintjük a külső olvasástól és írástól.
Helyettük metódusokat definiálunk az értékük lekérdezésére és beállítására.
Például:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

A [Nil][nil-dictionary] egy angol szó, amelynek jelentése „semmi” vagy „nulla”.
Rubyban a `nil` egy objektum _hiányát_ fejezi ki.
Más programozási nyelvekben a `null` vagy `none` értékek hasonló szerepet tölthetnek be.

```ruby
# I do not have a favorite color
favorite_color = nil
```

A Ruby minden példányváltozónak a `nil` alapértéket adja, amikor először találkozik vele, amíg más értéket nem adunk neki.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
