# Bevezetés a bitmanipulációba

A Javában operátorok segítségével manipulálhatod egy `byte`, `short`, `int`, `long` vagy `char` bitjeit.

## Eltolás operátorok

A bitek balra tolásához a `<<`, jobbra tolásához pedig a `>>` operátort használd.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

A `<<` operátor a jobb oldalon mindig 0-kat szúr be.
A `>>` viszont ugyanazt a bitet illeszti be, mint amilyen a legbaloldalibb bit (1, ha a szám negatív, 0, ha pozitív).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

Helyette a `>>>` operátort használd, ha jobbra tolásnál 0-kat kell a bal oldalra beszúrni.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

## Bitenkénti műveletek

### Bitenkénti ÉS

A bitenkénti ÉS (`&`) operátor két értéket fogad, és minden biten elvégzi az ÉS műveletet.
Az első érték minden bitjét összehasonlítja a második érték ugyanabban a pozícióban lévő bitjével.
Ha mindkettő 1, akkor az eredmény bitje 1.
Ellenkező esetben az eredmény bitje 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

### Bitenkénti VAGY

A bitenkénti VAGY (`|`) operátor két értéket fogad, és minden biten elvégzi a VAGY műveletet.
Az első érték minden bitjét összehasonlítja a második érték ugyanabban a pozícióban lévő bitjével.
Ha valamelyik bit 1, akkor az eredmény bitje 1.
Ellenkező esetben 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

### Bitenkénti XOR

A bitenkénti XOR operátor (`^`) két értéken végez bitenkénti XOR-t.
A bitenkénti ÉS és VAGY operátorhoz hasonlóan az első érték minden bitjét a második érték ugyanabban a pozícióban lévő bitjével hasonlítja össze.
Ha közülük csak az egyik 1, akkor az eredményül kapott bit 1.
Ellenkező esetben 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

### Bitenkénti NEM(`~`)

Végül a bitenkénti NEM operátor (`~`) minden bitet megfordít.
A korábbi operátorokkal ellentétben ez egyoperandusú operátor, amely csak egyetlen értéken hat.

```java
~0b0110_0101;
// # => 0b1001_1010
```
