# Névjegy

Amikor egy függvény paraméterként elfogad egy másik függvényt (vagy closure-t), az így átadott closure alapértelmezés szerint *non-escaping*.
Egy closure akkor *escaping*, ha a függvény visszatérése után hívódik meg.

Ez a helyzet leggyakrabban akkor fordul elő, amikor:

- A closure egy külső változóban vagy tulajdonságban tárolódik.
- A closure egy művelet befejeződése után aszinkron módon fut le.
- A closure a függvény visszatérési értékeként kerül vissza, hogy később hívjuk meg.

Nézzük a következő példát:

```swift
func emptyKitchen(_ order: String) -> String {
    "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}
```

Ebben a kódban a `prepare` elfogad egy `kitchen` nevű függvényt, létrehoz egy új `newKitchen` függvényt, amely meghívja a `kitchen`-t, majd visszaadja a `newKitchen`-t.
Ha megpróbálod lefordítani ezt a kódot, ezt a hibát kapod: `Escaping local function captures non-escaping parameter 'kitchen'`.

Mivel a `newKitchen` tovább él, mint a `prepare`, a `kitchen` closure escaping lesz.
Hogy ezt engedélyezd, lásd el a paraméter típusát az `@escaping` attribútummal.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}

let restaurant = prepare(
    order: "sandwich",
    kitchen: prepare(
        order: "chicken",
        kitchen: prepare(order: "steak", kitchen: emptyKitchen)
    )
)

print(restaurant("pork chop"))
// Prints "Sorry, we're all out of pork chop."

print(restaurant("chicken"))
// Prints "One chicken coming up!"
```

Az `@escaping` attribútum jelzi a Swift-fordítónak, hogy a closure tovább él, mint az aktuális függvényhívás, így a Swift megfelelően tudja kezelni a memóriát és az elkapott referenciákat.
