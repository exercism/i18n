# Tippek

## 1. Új lista létrehozása

- Az üres lista definiálásának módját [ezen az oldalon][create-and-initialize] találod.

## 2. Meglévő lista definiálása

- A több elemből álló lista definiálásának és inicializálásának módját [ezen az oldalon][create-and-initialize] találod.

## 3. Új nyelv hozzáadása egy listához

- A listák összefűzésére [többféle mód][combine] is létezik.

## 4. A listában lévő nyelvek megszámolása

- A `List` modulban van egy függvény, amivel [megszámolhatod a lista elemeit][length].

## 5. A lista megfordítása

- A `List` modulban van egy függvény, amivel [megfordíthatod a listát][reverse].

## 6. Ellenőrizd, hogy izgalmas-e a lista

- A [mintaillesztés][list-destructuring] segítségével adott listaszerkezetekre illeszkedhetsz.
