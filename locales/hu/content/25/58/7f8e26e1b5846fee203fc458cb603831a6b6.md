# Utasítások

Egy webfejlesztő csapattal dolgozol együtt egy helyi kosárlabdacsapat weboldalának karbantartásán. A webfejlesztő csapat kevésbé ismeri az Elixirt, és egy függvényt kérnek, amellyel adatokat nyerhetnek ki egymásba ágyazott map adatszerkezetek sorozatából, hogy felgyorsítsák a fejlesztést.

## 1. Adatok kinyerése egymásba ágyazott map adatszerkezetből

Valósítsd meg az `extract_from_path/2` függvényt, amely két argumentumot vár:

- `data`: egy egymásba ágyazott map adatszerkezet, amely a kosárlabdacsapat adatait tartalmazza.
- `path`: pontokkal elválasztott kulcsokból álló string, amellyel az utolsó kulcshoz tartozó értéket kapod meg.

Ha az érték vagy a kulcs az útvonal bármely pontján nem létezik, `nil`-t kell visszaadni.

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

Használd az _Access Behaviour_-t, amikor ezt a függvényt megvalósítod.

Ne használd a `Map` vagy a `Kernel` modul egyetlen függvényét sem az egymásba ágyazott map adatszerkezet kezeléséhez.

## 2. Refaktorálás beépített függvényekkel

A kollégád, aki átnézi a kódodat, elmondja, hogy a `Kernel` modulnak van egy függvénye, amely nagyon hasonló ahhoz, amit te megvalósítottál.

Valósítsd meg a `get_in_path/2` függvényt úgy, hogy ezt a `Kernel` modulfüggvényt használja.

A várt argumentumok ugyanazok, mint az 1. részben.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
