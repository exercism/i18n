# التعليمات

أنت تواصل العمل على نظام إدارة المخزون الذي بنيته سابقًا.
وبعد أن اكتشفت `OpenStruct` واختصارات الكتل، قررت إعادة هيكلة الكود قليلًا.
فبدلًا من تخزين العناصر كـ `Hash`، ستستفيد من مهاراتك الجديدة.

## 1. السماح باسترجاع العناصر

تريد أن تواصل استرجاع قائمة العناصر الموجودة في المخزون، لكن هذه المرة يجب أن تكون كائنات يمكن استدعاء الطُرق عليها.

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. إعادة هيكلة `item_names`

أعد هيكلة `item_names` لتستخدم اختصار الكتل الجديد الذي تعلمته بدلًا من `Hash`.
وللتذكير، يجب أن تُرجع الطريقة ما يلي:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. إعادة هيكلة `total_stock`

أعد هيكلة `total_stock` لتستخدم طريقة `OpenStruct`، بدلًا من الإشارة إلى `Hash`.
وللتذكير، يجب أن تُرجع الطريقة ما يلي:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

# => 36
```
