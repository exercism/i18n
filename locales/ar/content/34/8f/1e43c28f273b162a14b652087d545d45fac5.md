# مقدمة

تُمثَّل القيم المنطقية في Java بالنوع `boolean`، ويمكن أن تكون قيمها إما `true` أو `false`.

تدعم Java ثلاثة عوامل منطقية:

- `!` (النفي): يعكس القيمة المنطقية
- `&&` (العطف): يأخذ قيمتين منطقيتين وينتج صحيحًا إذا كانتا صحيحتين معًا
- `||` (الفصل): ينتج صحيحًا إذا كانت إحدى القيمتين المنطقيتين صحيحة

## أمثلة

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
