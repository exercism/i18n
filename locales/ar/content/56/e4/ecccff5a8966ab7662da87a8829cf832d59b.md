# مقدمة

التعبير المنطقي سؤال يُطرح على قيمة واحدة أو أكثر، ويمكن الإجابة عنه بـ `true` أو `false`.
التعبير الصحيح يُرجع `1`، والتعبير الخاطئ يُرجع `0`.
كذلك، للأعداد قيم صحيحة وخاطئة. فالصفر يُعتبر `false`، وأي عدد غير الصفر يُعتبر `true`.

في كود C القديم، إما أن يُستخدم النوع `int` مباشرةً مع القيم المنطقية، أو أن يكون المبرمج قد عرّف ثوابت مثل `TRUE` و`FALSE` لربط `1` و`0` بتمثيل منطقي.

مع الإصدار C99، أُضيف النوع `_Bool`.
يعرّف ملف الترويسة `stdbool.h` ثلاثة رموز منطقية جديدة: `bool` و`true` و`false`.
`true` يقابل `1`، و`false` يقابل `0`، و`bool` يقابل `_Bool`.
لذا، وبدلًا من استخدام النوع `int` مباشرةً أو ابتكار تعيينات منطقية خاصة بهم، يمكن للمبرمجين الآن تضمين `stdbool.h` والحصول تلقائيًا على رموز منطقية في كودهم.

## عوامل المقارنة

تدعم لغة C ستة عوامل مقارنة: `==` (يساوي)، و`!=` (لا يساوي)، و`>` (أكبر من)، و`<` (أصغر من)، و`>=` (أكبر من أو يساوي)، و`<=` (أصغر من أو يساوي).
تقارن هذه العوامل العلاقات بين القيم وتحوّلها إلى قيم منطقية.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## العوامل المنطقية

تدعم لغة C ثلاثة عوامل منطقية: `||` (أو)، و`&&` (و)، و`!` (ليس).

يُستخدم `!` مع قيمة واحدة.
فهو يعكس قيمتها المنطقية.
على سبيل المثال، `0` تساوي `false`، لكن `!0` تساوي `true`.

أما `||` و`&&` فيُستخدمان مع قيمتين.
لا تُقيَّم القيمة على اليمين إلا حين لا تحدّد القيمة على اليسار نتيجة التعبير مسبقًا.
أي أن `||` لا يقيّم القيمة التي على يمينه إلا عندما تُقيَّم القيمة التي على يساره إلى `false`.
و`&&` لا يقيّم القيمة التي على يمينه إلا عندما تُقيَّم القيمة التي على يساره إلى `true`.
