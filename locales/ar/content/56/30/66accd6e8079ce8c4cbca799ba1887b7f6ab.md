# ملحق التعليمات

## لا يضع `Print` علامات اقتباس حول السلاسل النصية

يتضمن هذا التمرين التعامل مع درجات عددية.
#[a: 1]` and `#[a: "1"]` ليسا متماثلين:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

من الممارسات الشائعة عند تصحيح الأخطاء استخدام `print` لطباعة القيم.
لكن الإخراج لن يضيف علامات اقتباس حول السلاسل النصية.
لذلك، تظهر سلسلة نصية عددية مثل `"1"` عند طباعتها كما يظهر العدد الصحيح `1`.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
في مخرجات الاختبار لهذا التمرين، قد ترى نتيجة مثل `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`.
يبدو القاموسان المقارَنان متماثلين عند طباعتهما.
لكن القاموس الأول يحتوي على قيم سلاسل نصية عددية، بينما يحتوي الثاني على قيم عددية صحيحة، لذا هما ليسا متماثلين.
وعند تصحيح الأخطاء، يمكن استخدام `inspect` للتحقق من محتويات القاموس.

## يضع `Express` علامات اقتباس حول السلاسل النصية

تُحوّل `express` قيمة إلى كود Arturo وتُرجع سلسلة نصية تمثّل ذلك الكود.
وفي تلك النتيجة، ستُوضع علامات اقتباس حول كل السلاسل النصية.
ونتيجة لذلك، ستُرجع `express "1"` القيمة `"1"`، وليس `1`.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
