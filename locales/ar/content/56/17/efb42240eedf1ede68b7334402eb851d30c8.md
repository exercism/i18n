# التعليمات

في هذا التمرين، ستطبّق [قواعد لعبة Go](https://matmoore.github.io/learngo/). القواعد نفسها مكتوبة بالفعل، وكل ما عليك هو تطبيقها لتحديث Game ومعالجة أي أخطاء أو مخالفات للقواعد.

تُمثَّل اللعبة كما يلي:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

هناك 4 قواعد في اللعبة:

- لا يمكن أن يكون على كل نقطة سوى حجر واحد.
- يمكن أسر أحجار الخصم.
- لا يمكنك وضع حجر في موضع يؤدي إلى أسره لنفسه.
- لا يمكنك استخدام النقطة نفسها مرتين.

## 1. طبّق القواعد

اكتب محتوى الدالة `apply_rules`، التي تأخذ قيمة `Game` ابتدائية ومجموعة من القواعد، وتُرجع قيمة `Game` الجديدة بعد تطبيق القواعد.

ثلاث من القواعد تتحقق من مخالفات القواعد وقد تُرجع خطأً، ولذلك يكون نوع الإرجاع لديها `Result(Game, String)`. إذا فشلت أي من هذه القواعد، يجب إرجاع اللعبة الأصلية، لكن مع تحديث حقل `error` بالخطأ ذي الصلة.

أما القاعدة الأخرى فلا تتحقق من المخالفات ولذلك لا يمكن أن تفشل (وإن كان يمكنها أن تُرجع قيمة `Game` متغيّرة)، ولذلك يكون نوع الإرجاع لديها `Game`.

إذا نجحت جميع القواعد، فيجب الاحتفاظ بكل التغييرات التي أُجريت على `Game` بفعل القواعد، مع تبديل اللاعب.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
