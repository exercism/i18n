# مقدمة

## السلاسل النصية

السلسلة النصية هي تتابع من المحارف تحيط بها علامات الاقتباس.
يدعم PHP علامات الاقتباس المفردة والمزدوجة.

```php
<?php

$where = "Spain";
$what = 'rain';
```

### توسّع المتغيرات داخل السلسلة النصية

في السلاسل النصية المزدوجة الاقتباس، إذا أُشير إلى متغير وهو داخل النطاق، فإن قيمته تُدرج في السلسلة النصية.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### دعم ترميز المحارف

تاريخيًا، كانت دوال السلاسل النصية في PHP تدعم محارف ASCII فقط ولم تكن تدعم ترميزات Unicode الحديثة.
كل محرف ASCII يشغل بايت واحد، بينما قد يتراوح طول محرف Unicode بين 1 و4 بايتات.
إذا احتجت إلى التعامل مع السلاسل النصية بترميز Unicode بأمان، فراجع [النسخ المتعددة البايتات][multi-byte-fns] من الدوال القديمة.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
