# التثبيت

للحصول على تعليمات التثبيت الموصى بها لمنصّتك،
توجّه إلى [موقع Rust الرسمي].

تثبيت سلسلة الأدوات ليس كل شيء!
فدعم بيئة التطوير المتكاملة يمنح دفعة إنتاجية هائلة أصبح معظم المطوّرين يتوقّعونها.
إذا كنت تستخدم Visual Studio Code، فراجع [توثيق دعم Rust][vscode].
كما نوصيك بكل حماس بتفعيل [فحص الكود باستخدام clippy][vscode-linting]!

[موقع Rust الرسمي]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
