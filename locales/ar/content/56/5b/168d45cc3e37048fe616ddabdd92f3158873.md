# مقدمة

لغة Go ذات أنواع ثابتة، لذلك سيكون لكل متغير نوع معروف في وقت التصريف. وبعد الإعلان عن المتغير، لا يمكن تغيير نوعه.

## إنشاء متغير

تستطيع العبارة `var` أن تُعلن نوع متغير جديد، أو تضبط قيمته، أو تفعل الأمرين معًا:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

وداخل دالة، يمكن أيضًا استخدام عبارة الإسناد القصيرة `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

لكل متغير في Go قيمة دائمًا.
إذا لم تُضبط قيمة عند الإعلان، يوفّر Go واحدة [تُسمى قيمة صفرية][zero-values]، اعتمادًا على نوع المتغير.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## تحديث متغير

داخل دالة، يمكن لعامل الإسناد `=` أن يضبط قيمة جديدة لمتغير موجود:

```go
count := 1
count = 2
```

يجب أن تكون القيمة الجديدة من نفس نوع المتغير:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
