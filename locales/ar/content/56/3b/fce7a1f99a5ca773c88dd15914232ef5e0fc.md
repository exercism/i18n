# نبذة

[المصفوفات][list] نوع بيانات أساسي في Haskell لحفظ مجموعة من القيم.
المصفوفات _غير قابلة للتعديل_، أي أنه لا يمكن تغييرها.
أي عملية تغيّر مصفوفة ما تُرجع مصفوفة جديدة.
وتوجد في `Prelude` عدة دوال تتيح لك التعامل مع المصفوفات.

تُنفَّذ المصفوفات في Haskell على هيئة [مصفوفات مترابطة][linked-list-wiki]، لا كمصفوفات تشغل مواقع ذاكرة متجاورة.
ولذلك، يستغرق الوصول إلى عنصر في المصفوفة وقتًا خطيًا يتوقف على طول المصفوفة.

يمكن كتابة المصفوفات بالصيغة الحرفية، أو بصيغة الرأس والذيل (التي تستخدم عامل `cons` وهو `:`)، أو بمزيج من الاثنين:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

يمكن استخدام صيغة الرأس والذيل لإضافة عناصر إلى مصفوفة.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

يُعدّ إضافة عناصر إلى مصفوفة أثناء التكرار نمطًا مضادًا.
تتطلب إضافة عنصر المرور على المصفوفة بالكامل وإضافة العنصر في نهايتها، ولذلك فإن إضافة عنصر جديد في كل تكرار تتطلب المرور على المصفوفة بالكامل في كل تكرار.

يمكننا تحقيق النتيجة نفسها بإضافة العنصر إلى مقدمة المصفوفة المعكوسة، ثم عكس النتيجة. الإضافة إلى المقدمة عملية سريعة وتستغرق وقتًا ثابتًا.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

توجد عدة دوال شائعة في `Prelude` للتعامل مع المصفوفات:

- تُرجع [`head`][head] _رأس_ المصفوفة، أي العنصر _الأول_ فيها.
- تُرجع [`tail`][tail] _ذيل_ المصفوفة، أي المصفوفة _دون_ العنصر _الأول_.
- تُرجع [`length`][length] عدد العناصر في المصفوفة.
- تُرجع [`elem`][elem] قيمة منطقية تشير إلى ما إذا كان العنصر موجودًا في المصفوفة.

وهناك أيضًا [وحدة `Data.List`][list].

## أنواع المصفوفات

في Haskell، المصفوفات **متجانسة**.
وهذا يعني أن جميع عناصر المصفوفة لها النوع نفسه.
وعندما تحاول وضع عناصر من أنواع مختلفة في المصفوفة نفسها، فستحصل على خطأ في النوع.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

إشارة النوع للمصفوفة هي `[a]` حيث `a` هو النوع الذي تحمله المصفوفة، مثل `String` أو `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
