# نبذة

في Haxe، تُعدّ الاستثناءات طريقة آمنة للتعامل مع الأخطاء التي تحدث أثناء تشغيل الكود. ينبغي أن يحتوي كل استثناء على رسالة تصف الخطأ. يمكننا _إطلاق_ الاستثناءات باستخدام الكلمة المفتاحية `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

عند إطلاق استثناء، يبحث الكود عن جزء مُخصَّص لمعالجة الخطأ. وإذا لم يجد أحدًا، فسيعرض رسالة الخطأ مع إيقاف تنفيذ البرنامج في الوقت نفسه.

لمعالجة الاستثناءات في Haxe، نستخدم كتلة `try-catch`. تتكوّن عبارة الكتلة هذه من كتلة `try` واحدة وواحدة أو أكثر من كتل `catch`. فكتلة `try` _تحاول_ تنفيذ جزء من الكود، بينما تنتظر كتلة `catch` في حال إطلاق استثناء _لتلتقطه_، فلا يتوقف التنفيذ. وعندما تلتقط كتلة `catch` استثناءً، فإنها تنفّذ أيضًا كل ما داخل الكتلة:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

يجب حذف نوع وسيط كتلة `catch`.

من المهم ملاحظة أن الاستثناءات ينبغي استخدامها في الحالات التي يحدث فيها أمر استثنائي، أي خطأ يحتاج إلى معالجة خاصة. ولا ينبغي استخدامها في التحكم في مسار تنفيذ البرنامج، لأن ذلك يُعدّ تصميمًا سيئًا، وغالبًا ما يؤدي إلى ضعف الأداء وصعوبة الصيانة.
