# المعاملات المتغيّرة

تسمح *[المعاملات المتغيّرة][variadic-parameters]* في Swift بتمرير صفر أو أكثر من القيم من النوع نفسه إلى معامل واحد في دالة. ويُشار إلى ذلك بإضافة `...` إلى توصيف نوع المعامل.

تُجمَّع هذه القيم تلقائيًا في مصفوفة عناصرها من النوع نفسه الذي عليه المعامل المتغيّر.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

لاحظ أن لـ Swift قيدًا عند استخدام المعاملات المتغيّرة.
إذا كانت للدالة معاملات تأتي بعد المعامل المتغيّر في التعريف، فيجب أن تحمل أول معامل يلي المعامل المتغيّر تسمية وسيط.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
