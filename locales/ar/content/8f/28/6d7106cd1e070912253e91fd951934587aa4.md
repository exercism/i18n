# مقدمة

يُعدّ استخدام `try..rescue` تركيبًا قويًا لالتقاط الأخطاء عند حدوثها. ويتيح التقاط الأخطاء للدوال إرجاع قيم محددة عندما يكون ذلك ضروريًا. كما يقدّم لنا تركيب `try..rescue` ميزتين إضافيتين يمكننا الاستفادة منهما:

- كتلة `else`
  - عندما تنجح كتلة `try`، تُطابَق النتيجة مع هذه الكتلة.
- كتلة `after`
  - سواء نجحت كتلة `try` أم أطلقت خطأً، فإن الكود الموجود في كتلة `after` يُنفَّذ دائمًا ما دام البرنامج يعمل عند هذه النقطة.
  - لا تُرجع نتيجة كتلة `after` إلى نطاق الاستدعاء.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
