# عامل تحديد النطاق

يسمح لنا عامل تحديد النطاق (`::`) بالإشارة إلى صنف للوصول إلى ثوابته الاسمية أو خصائصه الساكنة أو طرقه الساكنة.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## استخدام `self` و`static` مع عامل تحديد النطاق

قد يحتاج الكائن إلى الإشارة إلى نطاقه الخاص. ولتسهيل ذلك، تتيح الكلمة المفتاحية `self` للصنف الإشارة إلى نطاقه الخاص. واستخدام الكلمة المفتاحية `self` يفصل الصنف عن اسمه الخاص، مما يسهّل صيانة الكود مع مرور الوقت.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

استخدم الكلمة المفتاحية `static` مع عامل تحديد النطاق من أجل "الربط المتأخر" للإشارة إلى الصنف الوارث الحالي.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## استخدام `parent` مع عامل تحديد النطاق

تُستخدم الكلمة المفتاحية `parent` للإشارة إلى ثوابت الصنف الأب أو خصائصه أو طرقه، وكثيرًا ما تُستخدم لاستدعاء بانية الصنف الأب عند إنشاء كائن من الصنف.

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## تحذيرات

### ظهور الثوابت والخصائص والطرق

لا يزال عامل تحديد النطاق يتبع القواعد التي تحددها محددات الظهور `public` و`private` و`protected`.
