# تهيئة الموظفين الجدد في قاعدة البيانات

## بيان المسألة

تخطط شركة ABC Corp للاحتفاظ بمعلومات جميع مدفوعات المصروفات النثرية للموظفين في قاعدة بيانات. وأنت تساعد قسم المالية في ABC Corp على تنفيذ ذلك. ولأن ABC Corp توسّع عملياتها، فإن إضافة موظفين جدد إلى النظام متطلب شائع بسبب التعيينات الجديدة.

مهمتك هي إضافة بيانات الموظف الجديد المقدَّمة إلى جدول `Employee` في قاعدة البيانات، وإرجاع قيمة العمود `employee_id` المولَّد تلقائيًا دون إرسال استعلام آخر إلى قاعدة البيانات للعثور عليه. وإذا حدث خطأ أثناء التنفيذ، فيجب إرجاع `-1`.

## تفاصيل قاعدة البيانات

استخدم قاعدة بيانات H2 المقدَّمة لهذه المسألة.

> ملف قاعدة البيانات النموذجي هو `gofigure.mv.db`، واسم قاعدة البيانات هو `gofigure`. وهي موجودة داخل مجلد `db`.

الجداول التالية موجودة بالفعل في قاعدة بيانات H2 النموذجية مع بعض البيانات النموذجية. أسماء الأعمدة وأنواع البيانات موضحة أدناه.

**اسم الجدول** : `Employee`

| **الأعمدة:**      | النوع |
| -----------       | ----------- |
| `employee_id`     | عدد صحيح، مفتاح أساسي يزداد تلقائيًا       |
| `name`            | سلسلة نصية        |
| `city`            | سلسلة نصية        |
| `department`      | سلسلة نصية        |
| `age`             | عدد صحيح        |

**اسم الجدول**: `Payment`

| **الأعمدة:**      | النوع |
| -----------       | ----------- |
| `payment_id`      | عدد صحيح، مفتاح أساسي يزداد تلقائيًا       |
| `date`            | تاريخ        |
| `amount`          | عدد عشري        |
| `employee_id`     | عدد صحيح        |
| `reason`          | سلسلة نصية        |

* ملف قاعدة البيانات هو `gofigure.mv.db`. استخدم عنوان JDBC URL بالشكل `jdbc:h2:file:/path/to/db/file`
* اسم المستخدم: `root`
* كلمة المرور: `root`

## القيود

* استخدم ملف قاعدة بيانات H2 المقدَّم في مجلد `db` للتحقق من الاستعلامات ومن مثال Ballerina
* استخدم أسلوب معاملات تبعيات maven لإضافة مشغّل قاعدة بيانات H2 كتبعية منصة في ملف Ballerina.toml
* لا ترسل استعلامًا آخر إلى قاعدة البيانات للعثور على المعرّف المولَّد تلقائيًا


## بيئة الاختبار

* يمكنك تشغيل الاختبارات باستخدام `bal test`، وستُشغِّل الاختبارات على قاعدة البيانات النموذجية المقدَّمة.

## أمثلة

### المثال 1

**المدخلات** : dbFilePath: `"./db/gofigure"`, name : `“John Doe”`, city: `“Omaha”`, department : `“Sales”`, age: `24`

**المخرجات** : `4`

### المثال 2

**المدخلات** : dbFilePath: `"./db/invalidDB"`, name : `“John"`, city: `"Colombo"`, department : `"HR"`, age: `25`

**المخرجات** : `-1`

## تلميحات

* استخدم وحدة [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) للتعامل مع قاعدة البيانات
