## التعليمات

مهمتك هي إنشاء المتاهات المثالية لميكي ومينيرفا، تلك التي لها حل واحد فقط ولا تحتوي على أقسام معزولة.
إليك ما تحتاج إلى معرفته:

- المتاهة لها شكل مستطيل مع فتحة عند البداية والنهاية.
- تحتوي المتاهة على غرف وممرات تتقاطع بزوايا قائمة.
- يجب أن يقبل البرنامج معاملين: الصفوف والأعمدة. ويجب أن يكون حجم المتاهة بين 5 و100 خلية.
- المتاهة التي يبلغ عرضها `x` عمودًا وارتفاعها `y` صفًا يجب أن يكون عرضها `2x + 1` حرفًا وارتفاعها `2y + 1` حرفًا.
- إذا لم تُقدَّم بذرة، فأنشئ متاهة عشوائية. وإذا قُدِّمت البذرة نفسها عدة مرات، فيجب أن تكون المتاهة الناتجة هي نفسها في كل مرة.
- استخدم أحرف [رسم الصناديق][Box-drawing] لرسم الجدران، ورمز سهم (⇨) للمدخل على اليسار والمخرج على اليمين.

حان الوقت لإنشاء بعض المتاهات المثالية لهذين الفأرين المغامرين!

### أمثلة

1. المتاهة المربعة الصغيرة 5x5 خلية (أو 11x11 حرفًا)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. المتاهة المستطيلة 6x18 خلية
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
