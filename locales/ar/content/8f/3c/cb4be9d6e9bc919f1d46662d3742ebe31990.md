# التعليمات

إنه عيد الحب. لدى شريكك بضع أفكار لأنشطة، وهو يطلب منك تقييم كل واحدة منها: `yes` أو `no` أو `maybe`.

تُمثَّل الأنشطة بمصفوفات من عنصرين `{ tag value }`، حيث يكون `tag` واحدًا من `board-game` أو `chill` أو `movie` أو `restaurant` أو `walk`.

| activity                  | shape                       |
| ------------------------- | --------------------------- |
| العب لعبة لوحية           | `{ board-game f }`          |
| استرخِ                    | `{ chill f }`               |
| شاهد فيلمًا من نوع `genre` | `{ movie genre }`           |
| تناول الطعام في مكان يقدّم `cuisine` | `{ restaurant cuisine }` |
| امشِ `km` كيلومترًا       | `{ walk km }`               |

النوع واحد من `crime` أو `horror` أو `romance` أو `thriller`. والمطبخ إما `korean` أو `turkish`.

## 1. قيّم المطبخ

عرّف `rate-restaurant` لتأخذ مطبخًا من المكدّس وتُرجع موافقتك:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. قيّم نوع الفيلم

عرّف `rate-movie` لتأخذ نوعًا وتُرجع:

- `romance` → `yes`
- أي شيء آخر → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. قيّم المشي

عرّف `rate-walk` لتأخذ عددًا من الكيلومترات وتُرجع:

- أكثر من `11` → `yes`
- أكثر من `6`، وحتى `11` → `maybe`
- وإلا → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. قيّم النشاط

عرّف `rate-activity` لتأخذ نشاطًا على شكل `{ tag value }` من المكدّس وتُرجع موافقتك. أعد استخدام الدوال المساعدة أعلاه:

- `board-game`، `chill` → دائمًا `no`
- `movie` → أحِل الأمر إلى `rate-movie`
- `restaurant` → أحِل الأمر إلى `rate-restaurant`
- `walk` → أحِل الأمر إلى `rate-walk`

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. أحصِ الموافقات

عرّف `approval-counts` لتأخذ قائمة من الأنشطة وتُرجع مصفوفة من 3 عناصر `{ yes-count maybe-count no-count }` تُبيّن عدد الأنشطة التي قُيّمت بكل طريقة.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
