# مقدمة

تحتاج برامج كثيرة إلى قيم (شبه) عشوائية لمحاكاة أحداث من الواقع.

من الأمثلة الشائعة والمألوفة:

- رمي قطعة نقدية: قيمة عشوائية من بين ('H'، 'T').
- رمي حجر نرد: عدد صحيح عشوائي من 1 إلى 6.
- خلط رزمة أوراق اللعب: ترتيب عشوائي لقائمة الأوراق.
- إنشاء الأشجار والشجيرات في محاكاة رسوميات ثلاثية الأبعاد.

يُعد توليد قيم عشوائية حقًا باستخدام الحاسوب [تحديًا تقنيًا صعبًا بشكل مفاجئ][why-randomness-is-hard]، ولهذا توجد أيضًا مولدات "شبه عشوائية".

## توليد الأرقام العشوائية

في JavaScript، يمكنك توليد أرقام شبه عشوائية باستخدام الدالة [`Math.random()`][Math.random].
وهي تُرجع عددًا عشريًا شبه عشوائي بين 0 (ضمنا) و1 (دون تضمين).

للحصول على عدد عشوائي بين _min_ (ضمنا) و_max_ (دون تضمين)، يمكنك استخدام دالة على غرار ما يلي:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## توليد الأعداد الصحيحة العشوائية

لتوليد عدد صحيح عشوائي، يمكنك استخدام `Math.floor()` أو `Math.ceil()` لتحويل عدد مولَّد عشوائيًا إلى عدد صحيح.

[why-randomness-is-hard]: https://www.malwarebytes.com/blog/news/2013/09/in-computers-are-random-numbers-really-random
[Math.random]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random
