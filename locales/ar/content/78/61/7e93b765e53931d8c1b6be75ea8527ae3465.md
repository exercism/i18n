# مقدمة

## الأعداد

يوجد في C# نوعان مختلفان من الأعداد:

- الأعداد الصحيحة: أعداد لا توجد فيها أي أرقام بعد الفاصلة العشرية (الأعداد الكاملة). أمثلة عليها: `-6`، `0`، `1`، `25`، `976` و`500000`.
- الأعداد العشرية: أعداد تحتوي على صفر أو أكثر من الأرقام بعد الفاصلة العشرية. أمثلة عليها: `-2.4`، `0.1`، `3.14`، `16.984025` و`1024.0`.

النوعان الرقميان الأكثر شيوعًا في C# هما `int` و`double`. فالنوع `int` عدد صحيح بطول 32 بت، والنوع `double` عدد عشري بطول 64 بت.

تُجرى العمليات الحسابية باستخدام عوامل الحساب القياسية. ويمكن مقارنة الأعداد باستخدام عوامل المقارنة الرقمية القياسية، إضافة إلى عاملي المساواة (`==`) وعدم المساواة (`!=`).

يوجد في C# نوعان من تحويلات الأعداد:

1. التحويلات الضمنية: لا تُفقد أي بيانات ولا يلزم أي تركيب إضافي.
2. التحويلات الصريحة: قد تُفقد البيانات ويلزم تركيب إضافي على شكل _تحويل قسري_.

ولأن النوع `int` أقل دقة من النوع `double`، فإن التحويل من `int` إلى `double` آمن، ولذلك يُعدّ تحويلًا ضمنيًا. أما التحويل من `double` إلى `int` فقد يعني فقدان بيانات، لذلك يتطلب تحويلًا صريحًا.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## الجمل الشرطية

في هذا التمرين عليك تنفيذ منطق بشكل شرطي. والأسلوب الأكثر شيوعًا لفعل ذلك في C# هو استخدام جملة `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

يجب أن يكون شرط الجملة الشرطية `if` من النوع `bool`. ولا يوجد في C# مفهوم للقيم _التي تُعدّ صحيحة_.
