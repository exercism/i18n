# ملحق التعليمات

## التنفيذ

تُمثَّل العناصر بـ[السجلات](https://lfe.gitbooks.io/reference-guide/content/16.html)، المعرّفة في `item.lfe`.
استخدم `item-weight` للحصول على الوزن، و`item-value` للحصول على القيمة.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
