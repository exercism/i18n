# التعليمات

في هذا التمرين ستكتب كودًا لتتبّع مصفوفة من لغات البرمجة التي تريد تعلّمها على Exercism.

لديك ست مهام، وكلها ستتضمن التعامل مع المصفوفات.

## 1. إنشاء مصفوفة جديدة

لتتبّع اللغات التي تريد تعلّمها، ستحتاج إلى إنشاء مصفوفة جديدة. عرّف الارتباط `newList` الذي يحتوي على مصفوفة جديدة فارغة.

```fsharp
newList
// => []
```

## 2. تعريف مصفوفة موجودة

حاليًا، لديك ورقة مكتوب عليها اللغات التي تريد تعلّمها: F# وClojure وHaskell. عرّف الارتباط `existingList` ليمثّل هذه المصفوفة.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. إضافة لغة جديدة إلى مصفوفة

بينما تستكشف Exercism وتجد لغات أكثر إثارة للاهتمام، تريد إضافتها إلى مصفوفتك. نفّذ الدالة `addLanguage` لإضافة لغة جديدة إلى بداية مصفوفتك.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. عدّ اللغات في المصفوفة

عدّ اللغات واحدة واحدة غير مريح. نفّذ الدالة `countLanguages` لعدّ عدد اللغات في مصفوفتك.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. عكس المصفوفة

في مرحلة ما، تدرك أن مصفوفتك مرتّبة بالعكس في الواقع! نفّذ الدالة `reverseList` لعكس مصفوفتك.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. التحقق مما إذا كانت المصفوفة مثيرة

مع أنك تحب جميع اللغات، فإن F# له مكانة خاصة في قلبك. لذلك، تتحمس كثيرًا لمصفوفة من اللغات إذا:

- كان العنصر الأول في المصفوفة هو F#.
- كان العنصر الثاني في المصفوفة هو F#، وتحتوي المصفوفة على لغتين أو ثلاث لغات.

نفّذ الدالة `excitingList` للتحقق مما إذا كانت مصفوفة من اللغات مثيرة:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
