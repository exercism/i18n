# ملحق التعليمات

## القابل للاستدعاء

يوجد في PHP مفهوم [القابل للاستدعاء](https://www.php.net/manual/en/language.types.callable.php).

ويمكن أن تتخذ هذه عدة أشكال، لكننا سنركز على [الدوال المجهولة](https://www.php.net/manual/en/functions.anonymous.php).

يمكنك إنشاء دالة مجهولة وإسنادها إلى متغير ثم استدعاؤها مع وسائط:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
