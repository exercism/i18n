# التثبيت

للعمل على التمارين، ستحتاج إلى هذه البرمجيات:

1. [`OPAM`، مدير حزم OCaml](https://opam.ocaml.org/)

   راجع [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)
   لمعرفة كيفية تثبيت `OPAM` وإعداده لنظام التشغيل الذي تستخدمه.

2. مترجم OCaml

   اطّلع على قائمة الإصدارات المتاحة:

   ```bash
   opam switch
   ```

   إذا كان لديك بالفعل `switch` لـ OCaml 5.1، فإما أن تُحمّله بتشغيل `opam switch <switch-name>`، أو أن تُنشئ `switch` جديدًا بتشغيل:

   ```bash
   opam switch create exercism 5.4.0
   ```

   اسم `exercism` هنا اختياري، لكن من الممارسات الجيدة تسمية الـ `switch` الخاص بك.

3. ثبّت المكتبات القياسية الموسّعة ومكتبات الاختبار

   شغّل ما يلي لتثبيت التبعيات التي يتطلبها هذا المسار:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   بعض التمارين تستخدم المكتبة القياسية لـ OCaml فقط، وبعضها يستخدم المكتبتين الموسّعتين من Jane Street وهما Base و Core_kernel.
   مكتبة الاختبار تُسمى OUnit، وبعض التمارين تستخدم إضافةً إلى ذلك مكتبة QCheck للاختبارات القائمة على الخصائص.
   تشغيل الأمر أعلاه سيُثبّت هذه المكتبات.

4. ثبّت واستخدم الصدفة التفاعلية (اختياري)

   ملخّص عن [Setting up and using `utop`](https://dev.realworldocaml.org/install.html):

   ```bash
   opam install utop
   ```

   أنشئ ملفًا جديدًا باسم `.ocamlinit` في مجلدك الرئيسي وأضف إليه الأسطر التالية:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. ثبّت الأدوات في VS Code (اختياري)

   إذا كنت تستخدم VS Code:
   - ثبّت خادم لغة OCaml من [هنا](https://github.com/ocaml/ocaml-lsp).
   - ثبّت إضافة OCaml لـ VS Code من [هنا](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform)، أو ابحث عن `OCaml Platform` من Ocaml Labs.
