# مقدمة

يوفّر ABAP عدة أنواع عددية. في هذا التمرين، ستستخدم اثنين منها:

- `i` للقيم الصحيحة، مثل عدد الأيام.
- `p` للقيم العشرية المحزومة، مثل أجر الساعة أو الخصم.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

تحدّد الأعداد المحزومة طولها الأقصى وعدد منازلها العشرية. وعادةً ما تُكتب القيم العشرية الحرفية كقيم نصية، ثم يحوّلها المترجم إلى النوع العشري المستهدف، أو تُحوَّل باستخدام `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

يوفّر ABAP دوال عددية مدمجة للتقريب. فالدالة `floor` تُقرّب إلى أقرب عدد صحيح للأسفل، والدالة `ceil` تُقرّب إلى أقرب عدد صحيح للأعلى.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
