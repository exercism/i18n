# مقدمة

## السلاسل النصية

السلاسل النصية في Gleam هي نصوص غير قابلة للتغيير محاطة بعلامات اقتباس مزدوجة. وهي تدعم محارف يونيكود، ويمكن أن تمتد على عدة أسطر.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

يمكن ضم السلاسل النصية معًا باستخدام العامل `<>`:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

توفّر وحدة [`gleam/string`][stdlib] في المكتبة القياسية دوالًا للتعامل مع السلاسل النصية.

يمكن مطابقة السلاسل النصية في تعبيرات `case`:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

إذا أردت المطابقة على بداية سلسلة نصية وإسناد الباقي إلى متغير، فيمكنك استخدام نمط العامل `<>`:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
