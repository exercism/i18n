# الأعداد

`INT` هو نوع Sather للأعداد الصحيحة: `0`، `7`، `-3`. والإجراء الذي يُجيب بعدد صحيح يذكر ذلك بعد النقطتين، تمامًا كما يذكر الإجراء الذي يُجيب بنصٍّ `STR`.

```sather
   goals : INT is
      return 42;
   end;
```

يمكن للإجراءات أن تأخذ **وسائط**، وهي قيم تُمرَّر عند استدعاء الإجراء. يُسمّى كل وسيط ويُعطى نوعًا، بين الأقواس الهلالية بعد اسم الإجراء:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

عندما يكون للوسيطين النوع نفسه، يمكنك تسميتهما معًا:

```sather
   total(first, second : INT) : INT is
```

استدعِه بوضع القيم بين الأقواس الهلالية:

```sather
SCORES::total(3, 4)     -- this is 7
```

العوامل الحسابية الخمسة هي `+`، `-`، `*`، `/` و`%`.

`/` بين عددين من نوع `INT` هو **قسمة صحيحة**: فهو يتجاهل أي باقٍ بدل أن يُعطي كسرًا.

```sather
7 / 2      -- 3, not 3.5
```

`%` يعطي ما يتبقّى من تلك القسمة.

```sather
7 % 2      -- 1
```

الاثنان مترابطان: `7` يساوي `3` مجموعات من `2` مع تبقّي `1`.
