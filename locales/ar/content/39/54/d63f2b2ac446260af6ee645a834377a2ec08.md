# نبذة

تتضمّن PHP عددًا من بنى التحكم التكرارية المدمجة، مثل `while`. الصيغة الأساسية لجملة `while` هي:

```php
while (expr) {
  // statements
}
```

طالما أن التعبير (_expr_) يُقيَّم إلى قيمة _صحيحة_، فإن العبارات الموجودة داخل الحلقة ستُنفَّذ بشكل متكرر. وإذا كان التعبير (_expr_) يُقيَّم إلى خطأ قبل التكرار الأول، فلن تُنفَّذ العبارات إطلاقًا.

بدلًا من ذلك، يمكنك استخدام حلقة `do-while`، وهي تنفّذ العبارات داخل الحلقة مرة واحدة قبل تقييم التعبير (_expr_).

```php
do {
  // statements
} while (expr);
```
