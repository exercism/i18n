# الصفوف

يمكن للصفوف في Elm أن تحمل قيمتين أو ثلاث قيم، ويمكن أن يكون لكل قيمة أي نوع.
وفي Elm، تُستخدم الصفوف في الغالب للأنواع المؤقتة البسيطة.
ولهذا السبب لا تحمل الصفوف أكثر من 3 قيم، وكتشجيع إضافي على ذلك لا تُوفَّر دوال مساعدة إلا للقيمتين.
أما البيانات الأكثر تعقيدًا، فمن الأفضل الانتقال إلى السجلات.
ومن الاستخدامات الشائعة أنك تحتاج إلى إرجاع أكثر من قيمة واحدة من دالة.
لا تملك حقول الصف أسماء؛ إذ يتم الوصول إليها عبر التفكيك أو عبر الموضع.

يمكنك قراءة [مقدمة موجزة عن الصفوف][tuples-concise].
وهناك أيضًا [مقدمة أكثر تعمقًا][tuples-in-depth]، كما تحتوي [وثائق API لوحدة `Tuple`][tuple-core] على أمثلة برمجية وتوثيق مفصّل.

## الإعلان

تُنشأ أنواع الصفوف باستخدام الأقواس الهلالية، وتُفصل أنواع عناصرها بفواصل.

```elm
type alias IntStringTuple = (Int, String)
```

### الإنشاء

تُنشأ الصفوف باستخدام الأقواس الهلالية، وتُفصل عناصرها بفواصل.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

يمكنك أيضًا استخدام `Tuple.pair` لإنشاء صف يحوي قيمتين.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### الوصول

وهناك أيضًا دوال للوصول إلى قيم الصف حسب موضعها، وهما `Tuple.first` و`Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

يمكن _تفكيك_ الصفوف في الارتباطات باستخدام مطابقة أنماط الصفوف.
ويمكن التفكيك في تعبيرات `let` وتعريفات الدوال وعبارات `case`.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

كما تتيح لك مطابقة الأنماط في عبارة `case` المطابقة على محتوى القيم:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
