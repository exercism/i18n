# ملحق التعليمات

## الدوال والاختبار

لديك تعريف بدئي للدالة `SayHi`.

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

يأخذ مشغّل الاختبارات هذه الدالة ويشغّلها، ثم يقارن القيمة التي [تُرجعها][returns] بالقيمة التي يتوقعها.
استخدم تعريف الدالة البدئي هذا أساسًا لحلك.

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
