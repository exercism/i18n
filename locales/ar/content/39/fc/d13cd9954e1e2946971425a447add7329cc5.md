# مقدمة

من المفيد الإبلاغ عن الأخطاء عندما يكون هناك خطأ أو أمر غير متوقع في برنامج أو قطعة من الكود.

إنها كائنات JavaScript.

الخاصية الرئيسية لهذا الكائن هي `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

باستخدام صيغة `throw`، يمكنك رمي خطأ.

```javascript
throw new Error('Oops');
```

عندما يتم رمي `Error`، يتوقف التنفيذ الحالي ويستأنف في أول كتلة `catch` من مكدس الاستدعاءات.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

كما هو الحال مع أي صنف في JavaScript، يمكن للأصناف الفرعية أن ترث من `Error` لإنشاء أخطاء مخصصة باستخدام الكلمة المفتاحية `extends`.
ستتحقق صيغة `instanceof` مما إذا كان الخطأ الملتقط نسخة من صنف فرعي معين من `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
