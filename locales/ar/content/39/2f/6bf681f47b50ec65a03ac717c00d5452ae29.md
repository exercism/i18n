# مقدمة

## الاسم المستعار

لمشاركة الكود بين وحدات Elixir مختلفة داخل المشروع نفسه، تحتاج إلى الإشارة إلى الوحدة الخارجية باسمها الكامل. لكن ماذا لو كان هذا الاسم طويلًا جدًا أو مربكًا؟

تتيح لك الصيغة الخاصة `alias` تقصير الاسم الذي تشير به إلى وحدة خارجية أو تغييره. وعند استخدامها بدون أي وسائط، فإنها تختصر اسم الوحدة إلى مقطعه الأخير، على سبيل المثال يتحول `MyApp.Logger.Settings` إلى `Settings`. ويمكن تحديد اسم مخصص عبر الخيار `:as`.

عادةً تُضاف الأسماء المستعارة في بداية تعريف الوحدة.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## الاستيراد

تتيح لك الصيغة الخاصة `import` استخدام دوال من وحدة خارجية دون كتابة اسم الوحدة.

قد يؤدي استيراد وحدة خارجية بالكامل إلى تعارضات مع الدوال المحلية الموجودة. ولتجنب ذلك، يتوفر خياران: `:except` و`:only`. وكلاهما يتوقع قائمة كلمات مفتاحية، يكون فيها المفتاح اسم الدالة والقيمة عدد معاملاتها.

عادةً تُضاف الاستيرادات في بداية تعريف الوحدة.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
