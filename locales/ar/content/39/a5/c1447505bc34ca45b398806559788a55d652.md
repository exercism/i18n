# مقدمة

القائمة `list` في R هي مجموعة مرتبة من العناصر، وتختلف عن المتجهات `vectors` في عدة نواحٍ:

- يمكن أن تكون العناصر من أنواع مختلفة (مثل خلط `numeric` مع `character`).
- يمكن أن تكون العناصر بُنى معقدة (مثل المتجهات أو القوائم الأخرى، وما إلى ذلك).
- توجد صيغة مختلفة بعض الشيء للوصول إلى العناصر.

المقارنات مع لغات أخرى ليست دقيقة.
تشبه القائمة `list` في R إلى حد ما قاموس Python، لكن القائمة مرتبة ويمكن الوصول إليها عبر فهرس رقمي.
وهي تشبه إلى حد ما `struct` في C، إلا أنه يمكن توسيع القائمة بسهولة أثناء التشغيل.

## إنشاء القوائم

إعطاء أسماء (يُطلق عليها غالبًا «الوسوم») للعناصر أكثر شيوعًا مع القوائم منه مع المتجهات:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

لكن الوسوم اختيارية، وحينها تُستخدم أرقام الفهارس فقط:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## الوصول إلى عناصر القائمة

هناك ثلاثة أساليب للقيام بذلك، ولكل منها فائدتها في سياقات مختلفة.

### 1. باستخدام صيغة `$tag`

شائع جدًا إذا كانت أسماء الوسوم معروفة مسبقًا.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. باستخدام صيغة `[[tag]]`

ميزته أن اسم الوسم يمكن اختياره أثناء التشغيل.
لاحظ الأقواس المربعة المزدوجة.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. باستخدام فهرس الموضع

يعمل هذا سواء كانت للقائمة وسوم أم لم تكن.
ومرة أخرى، الأقواس المربعة مزدوجة.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## إضافة العناصر وحذفها

بسيط: الإسناد إلى عنصر يعدّله إن كان موجودًا أو يدرجه إن كان جديدًا.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

للحذف، أسنِد `NULL` إلى العنصر غير المرغوب فيه.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
