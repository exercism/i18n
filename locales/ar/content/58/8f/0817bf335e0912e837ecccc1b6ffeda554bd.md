# نبذة

[D](https://dlang.org) لغة برمجة أنظمة لها بنية نحوية شبيهة بلغة C وتنميط ساكن. وهي تجمع بين الكفاءة والتحكم وقوة النمذجة مع الأمان وإنتاجية المبرمج. طوّرها في الأصل [والتر برايت](https://en.wikipedia.org/wiki/Walter_Bright) و[أندريه ألكساندريسكو](https://en.wikipedia.org/wiki/Andrei_Alexandrescu) منذ الإصدار الثاني من D.

‏D هي حصيلة عقود من الخبرة في بناء المترجمات لعديد من اللغات المتنوعة، وتتميز بعدد كبير من [المزايا الفريدة](http://dlang.org/overview.html):

- تراكيب عالية المستوى تمنح قوة نمذجة كبيرة
- لغة مترجَمة عالية الأداء
- تنميط ساكن
- تطوّر من C++ (بلا أخطائها)
- واجهة مباشرة مع واجهات API لنظام التشغيل والعتاد
- أزمنة ترجمة فائقة السرعة
- تسمح ببرمجة آمنة من ناحية الذاكرة (SafeD)
- الكود قابل للصيانة وسهل الفهم.
- منحنى تعلّم قصير (بنية نحوية شبيهة بلغة C، ومشابهة لـ Java وغيرها)
- متوافقة مع واجهة التطبيقات الثنائية الخاصة بلغة C
- متعددة الأنماط (الأمرية، والبنيوية، والكائنية التوجه، والبرمجة العامة، ونقاء البرمجة الوظيفية، وحتى لغة التجميع)
- حماية مدمجة من الأخطاء (العقود، واختبارات الوحدة)

‏D Language Foundation هي المنظمة المكرّسة لتطوير لغة D والنهوض بها.
