# مقدمة

توفّر الحزمة `math/rand` دعمًا لتوليد أعداد شبه عشوائية.

إليك كيفية توليد عدد صحيح عشوائي بين `0` و`99`:

```go
import "math/rand"

n := rand.Intn(100) // n is a random int, 0 <= n < 100
```

تُرجع الدالة `rand.Float64` عددًا عشريًا عشوائيًا بين `0.0` و`1.0`:

```go
f := rand.Float64() // f is a random float64, 0.0 <= f < 1.0
```

هناك أيضًا دعم لخلط عناصر شريحة (أو بنى بيانات أخرى):

```go
x := []string{"a", "b", "c", "d", "e"}
// shuffling the slice put its elements into a random order
rand.Shuffle(len(x), func(i, j int) {
	x[i], x[j] = x[j], x[i]
})
```

## البذور

تسلسلات الأعداد التي تولّدها الحزمة `math/rand` ليست عشوائية حقًا.
فعند إعطاء قيمة معيّنة للبذرة، تصبح النتائج حتمية تمامًا.

في Go 1.20 وما بعده، تُختار البذرة تلقائيًا وبشكل عشوائي، لذا سترى تسلسلًا مختلفًا من الأعداد العشوائية في كل مرة تشغّل فيها برنامجك.

في الإصدارات السابقة من Go، كانت البذرة `1` افتراضيًا.
لذا للحصول على تسلسلات مختلفة في كل تشغيل للبرنامج، كان عليك أن تزرع مولد الأعداد العشوائية يدويًا، على سبيل المثال بالوقت الحالي، قبل الحصول على أي أعداد عشوائية.

```go
rand.Seed(time.Now().UnixNano())
```
