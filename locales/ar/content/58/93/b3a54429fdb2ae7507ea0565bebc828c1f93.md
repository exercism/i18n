# نبذة

تُستخدم [الحراس][guards] مكمّلةً لـ[مطابقة الأنماط][exercism-pattern-matching]، وسنغطيها في مفهوم لاحق. تتيح لنا الحراس تعريفات مختلفة للدالة حسب قيمة المدخل. كما تتيح فحوصات أكثر تعقيدًا.

تُعرَّف عبارة الحارس بخط عمودي `|` يتبعه تعبير منطقي، وتنتهي بعلامة يساوي `=` وجسم الدالة. ويمكن أن توجد عدة عبارات حارس لدالة واحدة. تُقيَّم عبارات الحارس من الأعلى إلى الأسفل، وأول عبارة تكون قيمتها `True` هي التي تُنفَّذ. وتسمح عبارة الحارس بوجود عبارة `otherwise`، وهي تلتقط أي قيمة لا تطابق عبارات الحارس السابقة.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

يمكننا أيضًا تعريف دالتنا واستخدامها داخل عبارة الحارس.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
