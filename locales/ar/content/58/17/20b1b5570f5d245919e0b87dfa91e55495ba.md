# معامل مطلوب غير متوقَّع

يُستدعى المعامل `${'parameter.name'}` في الاختبارات بقيمة وبدون قيمة، لكنه
_غير مُعلَّم كاختياري_، وهذا يعني أن الاختبارات لن تنجح. يمكن تعليم معامل
TypeScript كاختياري صراحةً باستخدام اللاحقة `?`:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

أو بدلًا من ذلك، بإسناد قيمة افتراضية:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
