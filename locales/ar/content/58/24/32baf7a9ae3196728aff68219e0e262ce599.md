# السلسلة النصية

نوع البيانات `String` هو تسلسل خطي من المحارف المُرمَّزة بترميز UTF-8. وهو مفيد لتخزين البيانات النصية.

## إنشاء سلسلة نصية

يمكن إنشاء سلسلة نصية باستخدام الدوال المرتبطة `String::new()` أو `String::from()`. ولدى أنواع كثيرة طريقة `to_string` لإنتاج سلسلة نصية، مثلًا من عدد.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### ماكرو `format!`

لأن إنتاج سلسلة نصية كبيرة من مجموعة من أنواع بيانات أصغر عملية شائعة، فإن Rust توفر أيضًا صيغة مختصرة تختصر تفاصيل استدعاء `to_string`: وهي ماكرو `format!`. على سبيل المثال، يمكننا تبسيط بناء السلسلة النصية المركبة أعلاه على النحو التالي:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## الشرائح النصية

ترتبط السلاسل النصية ارتباطًا وثيقًا بالشرائح النصية. الشرائح النصية هي مراجع غير قابلة للتغيير إلى منطقة من الذاكرة بحجم معروف، تحتوي على تسلسل خطي من المحارف المُرمَّزة بترميز UTF-8. ويمكن تحويل أي سلسلة نصية إلى شريحة نصية عبر الاستعارة باستخدام عامل إلغاء الإشارة (`&`). ولتحويل شريحة نصية إلى سلسلة نصية، يمكنك استخدام طريقة `to_string()` أو `String::from`.

في كود Rust، تُوضع السلسلة النصية الحرفية بين علامات تنصيص مزدوجة. وهذه السلاسل النصية الحرفية هي دائمًا شرائح نصية، لأنها تشير إلى منطقة غير قابلة للتغيير في الذاكرة ضمن الملف التنفيذي للبرنامج.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## تعديل سلسلة نصية

لدمج محرف واحد بسلسلة نصية، استخدم طريقة `push`. ولدمج شريحة نصية بسلسلة نصية، استخدم طريقة `push_str` أو عامل `+`.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## الوصول إلى المحارف في سلسلة نصية

بما أن سلاسل Rust مُرمَّزة بترميز UTF-8، فليست كل المحارف الفردية بالحجم نفسه. لذلك لا يوفر نوع البيانات `String` عامل فهرسة (`[]`). وللوصول إلى جميع المحارف أو إلى محرف محدد في سلسلة نصية، يمكن استخدام طريقة `chars()`. فهي تمر على كل محرف في السلسلة النصية، بالتتابع.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```

## المزيد

السلسلة النصية نوع بيانات غني، وقد بُنيت حولها عدة طُرق وماكروات. اطّلع على [وثائق المكتبة القياسية](https://doc.rust-lang.org/std/string/struct.String.html) للاطلاع على جميع طرق الأعضاء والوظائف التي توفرها السلسلة النصية.
