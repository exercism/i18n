# التعليمات

بصفتها ساحرةً ناشئة، تحتاج إيليز إلى التمرّن على بعض الأساسيات.
لديها رزمة من البطاقات تريد أن تتعامل معها.

ولتسهيل الأمور قليلًا، لا تستخدم سوى البطاقات من 1 إلى 10، لذا يمكن تمثيل رزمتها من البطاقات بمتجه من الأعداد.
ويقابل موضع كل بطاقة معينة الفهرسَ في المتجه.

## 1. استرجع بطاقة من الرزمة

لاختيار بطاقة، أرجِع البطاقة عند الفهرس `position` من الرزمة المعطاة.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. استبدل بطاقة في الرزمة

قم ببعض خفّة اليد واستبدل البطاقة عند الفهرس `position` ببطاقة الاستبدال المعطاة.
وأرجِع الرزمة المعدَّلة.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. أدرج بطاقة في أعلى الرزمة

اجعل بطاقة تظهر بإدراج بطاقة جديدة في أعلى الرزمة.
وأرجِع الرزمة المعدَّلة.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. أزل بطاقة من الرزمة

اجعل بطاقة تختفي بإزالة البطاقة عند الموضع `position` المعطى من الرزمة.
وأرجِع الرزمة المعدَّلة.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. أزل البطاقة العليا من الرزمة

اجعل بطاقة تختفي بإزالة البطاقة التي في أعلى الرزمة.
وأرجِع الرزمة المعدَّلة.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. أدرج بطاقة في أسفل الرزمة

اجعل بطاقة تظهر بإدراج بطاقة جديدة في أسفل الرزمة.
وأرجِع الرزمة المعدَّلة.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. أزل بطاقة من أسفل الرزمة

اجعل بطاقة تختفي بإزالة البطاقة التي في أسفل الرزمة.
وأرجِع الرزمة المعدَّلة.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. تحقق من حجم الرزمة

تحقق مما إذا كان حجم الرزمة يساوي `stack_size` أم لا.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
